Reductions Between Code Equivalence Problems
Mahdi Cheraghchi, Nikhil Shagrithaya, Alexandra Veliche

Abstract
In this paper we present two reductions between variants of the Code Equivalence problem. We give polynomial-time Karp reductions from Permutation Code Equivalence ( PCE ) to both Linear Code Equivalence ( LCE ) and Signed Permutation Code Equivalence ( SPCE ). Along with a Karp reduction from SPCE to the Lattice Isomorphism Problem ( LIP ) proved in a paper by Bennett and Win (2024), our second result implies a reduction from PCE to LIP .



1
Introduction

The
Code Equivalence
(
CE
) problem asks if two given codes
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are “equivalent” in some metric-preserving way; variants of the
CE
problem specify the type of equivalence.

Permutation Code Equivalence
(
PCE
) asks if the codes are the same up to permutation of the coordinates of codewords, while
Signed Permutation Code Equivalence
(
SPCE
) allows equivalence up to signed permutations.
Still more generally,
Linear Code Equivalence
(
LCE
) allows an equivalence up to permutation and multiplication by a (non-zero) constant.
The variants of
CE
belong to a larger class of isomorphism problems that ask the following question: Given two objects of the same kind, is there an isomorphism that transforms one object into the other?
Other examples of such problems include Matrix Code Equivalence and Graph Isomorphism.

Besides being interesting problems in their own right,
CE
problems have many important applications.
Perhaps most notably, the conditional hardness of
CE
variants has been used as a security assumption for several cryptographic schemes proposed to be post-quantum.
These include the seminal McEliece public-key encryption scheme
[
McE78
]
, a recent NIST post-quantum standardization submission called “Classic McEliece”
[
ABC+22
]
, and the more recent LESS identification scheme
[
BBPS21
,
BBPS22
]
.

Given the relevance of these problems to cryptography, there has been a considerable amount of work on designing efficient algorithms that solve these problems.
Leon
[
Leo82
]
introduced an algorithm for the search version of
PCE
that works well for a large number of codes, but still requires exponential time in the worst case.
The Support Splitting Algorithm developed by Sendrier in
[
Sen00
]
and extended by Sendrier and Simos in
[
SS13a
]
gives an algorithm for linear codes that is efficient for codes with small hull, where the hull of a code is defined by the intersection of the code and its dual.
This algorithm, however, does not work for the case where the dimension of the hull is zero, but this case was later handled by Bardet, Otmani, and Saeed-Taha in
[
BOS19
]
.
In the latter paper, the authors reduce the problem of deciding
PCE
to a weighted version of Graph Isomorphism, and then use a variant of Babai’s algorithm for solving the latter problem
[
Bab16
]
to give a quasi-polynomial time algorithm that computes
PCE
for the zero hull case.

On the other side of the cryptographic coin, considerable attention has been devoted towards understanding the computational hardness of these problems.
Petrank and Roth in
[
PR97
]
showed that Graph Isomorphsim reduces to
PCE
, and that
PCE
is not
NP
-complete unless the polynomial hierarchy collapses.
This was used as evidence for the computational hardness of
PCE
until Babai introduced his quasi-polynomial time algorithm for deciding Graph Isomorphism
[
Bab16
]
.
Even under the assumption that the polynomial hierarchy does not collapse, however, it is still possible that both Graph Isomorphism and
PCE
cannot be decided in polynomial time.

The Matrix Code Equivalence problem is concerned with code equivalence in the rank metric.
Couvreur, Debris-Alazard and Gaborit in
[
CDG20
]
give a reduction from
LCE
to Matrix Code Equivalence, thus showing that determining code equivalence under the rank metric is at least as hard as determining equivalence under the Hamming metric.

In
[
SS13a
]
, Sendrier and Simos give a reduction from
LCE
to
PCE
that runs in time polynomial in the blocklength
n
and alphabet size
q
of the codes.
The closure of a code
\mathcal{C}\subseteq{\mathbb{F}}_{q}^{n}
is the set defined by taking every codeword and multiplying each of its
n
coordinates with all the non-zero field elements to produce a new vector of length
n(q-1)
.
Then using the fact that multiplication by any non-zero field element induces a permutation on the elements in
{\mathbb{F}}_{q}^{*}
, they reframe scalar multiplication as a permutation over
{\mathbb{F}}_{q}^{*}
.
In
[
DG23
]
, Ducas and Gibbons use a specific form of this closure to prove a reduction from
SPCE
to
PCE
.
Biasse and Micheli in
[
BM23
]
give a search-to-decision reduction for
PCE
, which implies that the decision version of
PCE
is at least as hard as the search version.
Bennett and Win in
[
BW24
]
give several reductions between
CE
variants and other isomorphism problems.
They extend the closure technique from
[
SS13a
]
to give a reduction from
LCE
to
SPCE
, and also give a reduction from
SPCE
to the
Lattice Isomorphism Problem
(
LIP
).

LIP
is an analogous problem to
CE
for lattices.
A
lattice
is an infinite discrete additive subgroup of Euclidean space that is generated by all integer linear combinations of some
k
linearly independent vectors; these vectors form a
basis
for the lattice.
Two lattices are said to be
isomorphic
if there exists an orthogonal transformation that transforms one lattice (basis) into the other.

LIP
asks if such an isomorphism exists.
In their reduction from
SPCE
to
LIP
, Bennet and Win use a well-known construction (called Construction A) that lifts a linear code over a prime finite field
{\mathbb{F}}_{p}
to a lattice in
{\mathbb{R}}^{n}
.
Because this construction is only well-defined for prime fields, the reduction only works for prime fields.
It remains an open problem to find a reduction from any
CE
variant to
LIP
for non-prime fields.

1.1
Results

Now we state our main results and place them into context of the prior work described above.
In
[
BW24
]
, the authors prove Karp reductions from
LCE
to
PCE
and from
LCE
to
SPCE
.
In our work, we show a reverse Karp reduction from
PCE
to
LCE
.

Theorem 1.1

(
PCE
reduces to
LCE
, informal)
.

For linear codes with blocklength
n
over a field of size
q
, there is a Karp reduction from
PCE
to
LCE
that runs in
\mathrm{poly}(n,\log q)
time.

The formal statement is given in
Theorem

3.1
.
This result, along with the Karp reduction in
[
SS13b
,
BW24
]
from
LCE
to
PCE
running in
\mathrm{poly}(n,q)
time, implies that the problems
LCE
and
PCE
are computationally equivalent up to factors in the runtime that are polynomial in
n
and
q
.

Additionally, the Karp reduction from
LCE
to
SPCE
detailed in
[
BW24
, Theorem 4.4, Corollary 4.5]
combines with our result to give a reduction from
PCE
to
SPCE
running in
\mathrm{poly}(n,q)
time.
In situations where
q
is much larger than
n
(as is the case for Reed-Solomon codes, for example), it is desirable to have the runtime depend only logarithmically on
q
.
Note that at least
\log q
time is required to express a single element of the field, so the dependence on
q
cannot be smaller than
\log q
.
Our second result is a Karp reduction from
PCE
to
SPCE
whose runtime depends only logarithmically on
q
.

Theorem 1.2

(
PCE
reduces to
SPCE
, informal)
.

For linear codes with blocklength
n
over a field of size
q
, there is a Karp reduction from
PCE
to
SPCE
that runs in
\mathrm{poly}(n,\log q)
time.

The formal statement is given in
Theorem

3.2
.
This result, together with a Karp reduction from
SPCE
to
PCE
from
[
DG23
, Lemma 10]
running in
\mathrm{poly}(n,\log q)
time, implies that
PCE
and
SPCE
are computationally equivalent problems up to factors in the runtime that are polynomial in
n
and
\log q
.

Finally, by combining the above result with the Karp reduction from
SPCE
over prime fields to
LIP
from
[
BW24
, Theorem 5.1]
, we obtain the following corollary.

Corollary 1.3

(
PCE
reduces to
LIP
)
.

For any prime
p
, there is a Karp reduction from
PCE
over a field of order
p
to
LIP
that runs in
\mathrm{poly}(n,\log p)
time.

Preliminaries

Let
\mathbb{N}
denote the set of all positive integers.
For any
n,m\in\mathbb{N}
such that
n<m
, we use the notation
[n,m]
to denote the set of integers
\{n,n+1,\ldots,m\}
.
For
n\in\mathbb{N}
, we use the abbreviated notation
[n]\mathrel{\mathop{\ordinarycolon}}=[1,n]
.
For any prime power
q\in\mathbb{N}
, we use
{\mathbb{F}}_{q}
to denote the field of size
q
.
For any commutative ring
R
, we denote its multiplicative subgroup by
R^{*}
; for a field
{\mathbb{F}}
, we have
{\mathbb{F}}^{*}={\mathbb{F}}\setminus\{0\}
.

We use boldface lowercase letters, such as
\mathbf{v}
, to denote vectors and boldface uppercase letters, such as
\mathbf{A}
, to denote matrices.
We use
\mathbf{e}_{i}
to denote the column vector containing a one in the
i
-th position and zeros everywhere else, and
\mathbf{0}
will denote the all zeroes column vector.
For any matrix
\mathbf{A}
with
n
columns and
i\in[n]
, we use
\mathbf{A}[i]
to denote the
i
-th column.
We also use
\mathbf{A}[i,j]
to denote the entry in the
i
-th row and
j
-th column.
To denote the block submatrix of a matrix
\mathbf{A}
spanned by rows
r_{i}
through
r_{j}
(inclusive) and columns
c_{k}
through
c_{\ell}
(inclusive), we use the notation
\mathbf{A}[r_{i}\mathrel{\mathop{\ordinarycolon}}r_{j},c_{k}\mathrel{\mathop{\ordinarycolon}}c_{\ell}]
.

2.1
Matrix Groups

For any field
{\mathbb{F}}
and
n\in\mathbb{N}
, we use the following notation for special sets of
n\times n
matrices over
{\mathbb{F}}
:

\mathrm{GL}_{n}({\mathbb{F}})
denotes the group of invertible matrices,
\mathcal{P}_{n}({\mathbb{F}})
denotes the set of permutation matrices,
\mathcal{S}\mathcal{P}_{n}({\mathbb{F}})
denotes the set of signed permutation matrices, and
\mathcal{M}_{n}({\mathbb{F}})
denotes the set of monomial matrices.
A
permutation
matrix
\mathbf{P}\in\mathcal{P}_{n}({\mathbb{F}})
contains exactly one
1
in each row and column and
0
s everywhere else.
A
signed permutation
matrix
\mathbf{P}\in\mathcal{S}\mathcal{P}_{n}({\mathbb{F}})
contains exactly one non-zero entry in each row and column, but each of these can be either
1
or
-1
.
A
monomial
matrix
\mathbf{M}\in\mathcal{M}_{n}({\mathbb{F}})
contains exactly one non-zero entry in each row and column, but these can take values in
{\mathbb{F}}^{*}
; any monomial matrix
\mathbf{M}
can be written as
\mathbf{M}=\mathbf{D}\mathbf{P}
for some diagonal matrix
\mathbf{D}=\text{diag}(d_{1},...,d_{n})
, where
d_{i}\in{\mathbb{F}}^{*}
, and permutation matrix
\mathbf{P}\in\mathcal{P}_{n}({\mathbb{F}})
.
Each of these sets of matrices forms a group under matrix multiplication.
Furthermore, these satisfy
\mathcal{P}_{n}({\mathbb{F}})\subseteq\mathcal{S}\mathcal{P}_{n}({\mathbb{F}})\subseteq\mathcal{M}_{n}({\mathbb{F}})\subseteq\mathrm{GL}_{n}({\mathbb{F}})
.
If it is clear from context, we do not specify the field for these matrix groups.
For any permutation matrix
\mathbf{P}\in\mathcal{S}\mathcal{P}_{n}
, we denote the corresponding permutation map over the set of column indices by
\sigma_{\mathbf{P}}\colon[n]\to[n]
.

The following observation will be useful for our reduction in
Section

3
.

Observation 2.1
.

Any invertible matrix
\mathbf{S}\in\mathrm{GL}_{k}({\mathbb{F}})
induces a bijective map on
{\mathbb{F}}^{k}
.
In particular, for any
\mathbf{x},\mathbf{y}\in{\mathbb{F}}^{k}
, we have
\mathbf{S}\mathbf{x}=\mathbf{S}\mathbf{y}
if and only if
\mathbf{x}=\mathbf{y}
.
Then when
\mathbf{S}
is multiplied by some matrix
\mathbf{A}
of the appropriate dimension, it maps identical (distinct) columns in
\mathbf{A}
to identical (distinct) columns in
\mathbf{S}\mathbf{A}
.

2.2
Codes

A
linear code
is a finite-dimensional vector space over a finite field.
Let
{\mathbb{F}}_{q}
be a finite field of size
q
for some prime power
q\in\mathbb{N}
.
Using the standard notation for linear codes, we say that
\mathcal{C}\subseteq{\mathbb{F}}_{q}^{n}
is a
[n,k,d]_{q}
-code
for some
q,n,k,d\in\mathbb{N}
, where
q
is the
alphabet size
,
n
is the
blocklength
given by the length of the codeword vectors,
k
is the
dimension
of
\mathcal{C}
as a linear subspace of
{\mathbb{F}}_{q}^{n}
, and
d
is the
minimum distance
given by the minimum Hamming weight over all non-zero codewords of
\mathcal{C}
.
Any linear code
\mathcal{C}
can be expressed as the row span of a
generator
matrix
\mathbf{G}\in{\mathbb{F}}_{q}^{k\times n}
.
Note that the generator is not unique (since elementary row operations leave the span of
\mathbf{G}
unchanged).

2.3
Equivalence Problems

Two codes
\mathcal{C},\mathcal{C}^{\prime}\subseteq{\mathbb{F}}_{q}^{n}
are said to be
permutation equivalent
if there exists a permutation of the coordinates of
\mathcal{C}
that gives
\mathcal{C}^{\prime}
.
We formalize this notion and define two generalizations of the corresponding computational problems below.

Definition 2.2

(
PCE
)
.

For
n,k\in\mathbb{N}
and field
{\mathbb{F}}_{q}
of size
q
, the
Permutation Code Equivalence
problem, denoted by
PCE
, is the following decision problem:
Given a pair of generator matrices
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
, decide whether there exist an invertible matrix
\mathbf{S}\in\mathrm{GL}_{k}({\mathbb{F}}_{q})
and a permutation matrix
\mathbf{P}\in\mathcal{P}_{n}({\mathbb{F}}_{q})
for which
\mathbf{S}\mathbf{G}\mathbf{P}=\mathbf{H}
.

If we allow code equivalence up to
signed
permutations, we can consider the following problem.

Definition 2.3

(
SPCE
)
.

For
n,k\in\mathbb{N}
and field
{\mathbb{F}}_{q}
of size
q
, the
Signed Permutation Code Equivalence
problem, denoted by
SPCE
, is the following decision problem:
Given a pair of generator matrices
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
, decide whether there exist an invertible matrix
\mathbf{S}\in\mathrm{GL}_{k}({\mathbb{F}}_{q})
and a signed permutation matrix
\mathbf{P}\in\mathcal{S}\mathcal{P}_{n}({\mathbb{F}}_{q})
for which
\mathbf{S}\mathbf{G}\mathbf{P}=\mathbf{H}
.

More generally, we can consider code equivalence up to permutation and multiplication by any non-zero constant.

Definition 2.4

(
LCE
)
.

For
n,k\in\mathbb{N}
and field
{\mathbb{F}}_{q}
of size
q
, the
Linear Code Equivalence
problem, denoted by
LCE
, is the following decision problem:
Given a pair of generator matrices
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
, decide whether there exist an invertible matrix
\mathbf{S}\in\mathrm{GL}_{k}({\mathbb{F}}_{q})
and a monomial matrix
\mathbf{M}\in\mathcal{M}_{n}({\mathbb{F}}_{q})
for which
\mathbf{S}\mathbf{G}\mathbf{M}=\mathbf{H}
.

For brevity, we say that two matrices are in
PCE
(or
SPCE
,
LCE
) if they satisfy the conditions required for the pair to be a YES instance of the problem.

Theorem 3.1

(
PCE
reduces to
LCE
)
.

There is a reduction from
PCE
to

that runs in
\mathrm{poly}(n,\log q)

n

Theorem 3.2

(
PCE
reduces to

)
.

There is a reduction from
PCE
to

We will use the following three lemmas to justify why certain assumptions about the input can be made without loss of generality.

Lemma 3.3

(adapted from
[
Mac33

)
.

For any prime power
q
and matrices
\mathbf{A},\mathbf{B}
over
{\mathbb{F}}_{q}
, the equivalence
\mathbf{A}=\mathbf{P}\mathbf{B}\mathbf{Q}
holds for some
\mathbf{P},\mathbf{Q}
over
{\mathbb{F}}_{q}
if and only if
\mathbf{A}
and
\mathbf{B}
have equal rank.

Lemma 3.4
.

Let
k,n\in\mathbb{N}
and
q
be a prime power.
For any matrices
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
, if
(\mathbf{G},\mathbf{H})\in\textsf{PCE}
, then no column of
\mathbf{G}
appears in
\mathbf{G}
more times than a column of
\mathbf{H}
appears in
\mathbf{H}
.

Proof.

By definition, there must be some
\mathbf{S}\in\mathrm{GL}_{k}
and
\mathbf{P}\in\mathcal{P}_{n}
such that
\mathbf{S}\mathbf{G}\mathbf{P}=\mathbf{H}
.
By
2.1
,
\mathbf{S}
takes identical columns in
\mathbf{G}
to identical columns in
\mathbf{S}\mathbf{G}
.
When multiplied with
\mathbf{G}
on the right,
\mathbf{P}
only permutes the columns of
\mathbf{G}
and so does not change the frequency with which any column appears in the matrix
\mathbf{S}\mathbf{G}
.
Therefore for every column
\mathbf{c}
in
S\mathbf{G}
, its corresponding column in
\mathbf{H}
must appear the same number of times as
\mathbf{c}
appears in
\mathbf{S}\mathbf{G}
.
∎

Lemma 3.5
.

For any
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
, let

and
\overline{\mathbf{H}}
be the submatrices of
\mathbf{G}
and
\mathbf{H}

Then

\overline{\mathbf{G}}

This lemma follows from the following trivial reduction:
If
\mathbf{G}
and
\mathbf{H}
satisfy the

\mathbf{S}\in\mathrm{GL}_{k}
and
\mathbf{P}\in\mathcal{P}_{n}
such that
\mathbf{S}\mathbf{G}\mathbf{P}=\mathbf{H}
.
Because
\mathbf{S}
is a linear map, it will always map
\mathbf{0}\in{\mathbb{F}}_{q}^{k}

\mathbf{S}
and a permutation submatrix of
\mathbf{P}
for which
\overline{\mathbf{G}}
and
\overline{\mathbf{H}}
satisfy the

3.1
From
PCE
to
LCE

First we show the forward direction.
We prove that our construction preserves the permutation equivalence of the input pair, which gives the following stronger result.

Lemma 3.7
.

For any
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
,
if
\mathbf{G}
and
\mathbf{H}
are in
PCE
, then
\mathbf{G}^{\prime}
and
\mathbf{H}^{\prime}
are in
PCE
(and therefore in
LCE
).

Proof.

By definition,
\mathbf{G},\mathbf{H}
is in
PCE
if and only if there exist an invertible matrix
\mathbf{S}\in\mathrm{GL}_{k}
and a permutation matrix
\mathbf{P}\in\mathcal{P}_{n}
such that
\mathbf{S}\mathbf{G}\mathbf{P}=\mathbf{H}
.
From these matrices we will construct
\mathbf{S}^{\prime}\in\mathrm{GL}_{k+1}
and
\mathbf{P}^{\prime}\in\mathcal{P}_{n^{\prime}}
such that
\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}=\mathbf{H}^{\prime}
.
Define
\mathbf{S}^{\prime}\in\mathrm{GL}_{k+1}
such that the top-left block submatrix is
\mathbf{S}^{\prime}[1\mathrel{\mathop{\ordinarycolon}}k,1\mathrel{\mathop{\ordinarycolon}}k]=\mathbf{S}
, the bottom-right entry is
\mathbf{S}^{\prime}[k+1,k+1]=1
, and all other entries are zero.

Let
\sigma_{\mathbf{P}}\colon[n]\to[n]
be the permutation map described by
\mathbf{P}
.
Define a new permutation
\sigma_{\mathbf{P}^{\prime}}\colon[n^{\prime}]\to[n^{\prime}]
that permutes the first
n
columns of
\mathbf{G}^{\prime}
among each other according to
P
, i.e.
\sigma_{\mathbf{P}^{\prime}}(x)\mathrel{\mathop{\ordinarycolon}}=\sigma_{\mathbf{P}}(x)
for all
x\in[n]
.
We also define
\sigma_{\mathbf{P}^{\prime}}
such that it permutes each of the
nm
columns in the second block according to how its corresponding column was permuted in the first block.
Formally, for every
x\in[n+1,n+nm]
, we write
x=n+m(i-1)+j
uniquely for
i\in[n]
and
j\in[m]
and set
\sigma_{\mathbf{P}^{\prime}}(x)\mathrel{\mathop{\ordinarycolon}}=n+m(\sigma_{\mathbf{P}}(i)-1)+j
.
Lastly, we define
\sigma_{\mathbf{P}^{\prime}}
such that it sends each of the last
nm+1
columns identically to itself, i.e.
\sigma_{\mathbf{P}^{\prime}}(x)\mathrel{\mathop{\ordinarycolon}}=x
for every
x\in[n+nm+1,n+2nm+1]
.
Finally we let
\mathbf{P}^{\prime}\in\mathcal{P}_{n^{\prime}}
be the permutation matrix defined by
\sigma_{\mathbf{P}^{\prime}}
.

We claim that
\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}=\mathbf{H}^{\prime}
.
This holds if and only if
\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}[x]=\mathbf{H}^{\prime}[x]
for every column
x\in[n^{\prime}]
.
We show that this is the case for every column in each of the three blocks.
For every
x\in[n]
, by the definition of
\sigma_{\mathbf{P}^{\prime}}
, the fact that each column in the first block has 1 as the last entry, and the
PCE
assumption,

\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}[x]=\mathbf{S}^{\prime}\mathbf{G}^{\prime}[\sigma_{\mathbf{P}^{\prime}}(x)]=\mathbf{S}\mathbf{G}[\sigma_{\mathbf{P}}(x)]\ \|\ 1=\mathbf{S}\mathbf{G}[x]\mathbf{P}\ \|\ 1=\mathbf{S}\mathbf{G}\mathbf{P}[x]\ \|\ 1=\mathbf{H}[x]\ \|\ 1=\mathbf{H}^{\prime}[x].

Here “
\|
” denotes concatenation of an additional entry at the end of the column vector.
For
x\in[n+1,n+nm]
, we can write
x=n+m(i-1)+j
for some
i\in[n]
and
j\in[m]
.
Then by the definition of
\sigma_{\mathbf{P}^{\prime}}
, the fact that each column in the second block has 0 as the last entry, and the
PCE
assumption,

\displaystyle\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}[x]

\displaystyle=\mathbf{S}\mathbf{G}[\sigma_{\mathbf{P}^{\prime}}(x)]\ \|\ 0=\mathbf{S}\mathbf{G}[n+m(\sigma_{\mathbf{P}}(i)-1)+j]\ \|\ 0=\mathbf{S}\mathbf{G}[\sigma_{\mathbf{P}}(i)]\ \|\ 0

\displaystyle=\mathbf{S}\mathbf{G}\mathbf{P}[i]\ \|\ 0=\mathbf{H}[i]\ \|\ 0=\mathbf{H}[n+m(i-1)+j]\ \|\ 0=\mathbf{H}^{\prime}[x].

Lastly, for all
x\in[n+nm+1,n+2nm+1]
, by definition of
\sigma_{\mathbf{P}^{\prime}}
, the fact that each column in the last block is identical to
\mathbf{e}_{k+1}
, and the
PCE
assumption,

\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{P}^{\prime}[x]=\mathbf{S}\mathbf{G}[\sigma_{\mathbf{P}^{\prime}}(x)]\ \|\ 1=\mathbf{S}\mathbf{G}[x]\ \|\ 1=\mathbf{S}\mathbf{G}\mathbf{P}[x]\ \|\ 1=\mathbf{H}[x]\ \|\ 1=\mathbf{H}^{\prime}[x].

Therefore,
\mathbf{G}^{\prime}
and
\mathbf{H}^{\prime}
are in
PCE
.
∎

Now we prove the other direction, and show that if the constructed matrices
\mathbf{G}^{\prime}
and

This requires some careful analysis of how the change-of-basis matrix

First we show that for any monomial matrix
\mathbf{M}=\mathbf{D}\mathbf{P}
for which

and

Lemma 3.8
.

For any
\mathbf{G},\mathbf{H}\in{\mathbb{F}}_{q}^{k\times n}
,
if
\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{M}^{\prime}=\mathbf{H}^{\prime}
for some
\mathbf{S}^{\prime}\in\mathrm{GL}_{k+1}
and
\mathbf{M}^{\prime}=\mathbf{D}^{\prime}\mathbf{P}^{\prime}\in\mathcal{M}_{n^{\prime}}
, where
\mathbf{P}^{\prime}\in\mathcal{P}_{n^{\prime}}
,
the corresponding permutation map
\sigma_{\mathbf{P}^{\prime}}\colon[n^{\prime}]\to[n^{\prime}]
satisfies the following:

1.

For every
i\in[1,n]
,
\sigma_{\mathbf{P}^{\prime}}(i)\in[1,n]
.

2.

For every
i\in[n+1,n+mn]
,
\sigma_{\mathbf{P}^{\prime}}(i)\in[n+1,n+mn]
.

3.

For every
i\in[n+nm+1,n^{\prime}]
,
\sigma_{\mathbf{P}^{\prime}}(i)\in[n+mn+1,n^{\prime}]
.

Proof.

As a result of
Lemma

3.5
, we can assume without loss of generality that
\mathbf{G}
and
\mathbf{H}
do not contain a zero column.
Suppose
\mathbf{S}^{\prime}\in\mathrm{GL}_{k+1}
and
\mathbf{M}^{\prime}=\mathbf{D}^{\prime}\mathbf{P}^{\prime}\in\mathcal{M}_{n^{\prime}}
satisfy
\mathbf{S}^{\prime}\mathbf{G}^{\prime}\mathbf{M}^{\prime}=\mathbf{H}^{\prime}
.
By definition,
\mathbf{S}^{\prime}
has an inverse
\mathbf{S}^{\prime-1}\in\mathrm{GL}_{k+1}
, so we can rewrite

\mathbf{G}^{\prime}\mathbf{M}^{\prime}=\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}.

(3.1)

By
2.1
,
\mathbf{S}^{\prime-1}
maps identical columns in
\mathbf{H}^{\prime}
to identical columns in
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}
.
To prove each part of the claim, we analyze the effect of
\mathbf{S}^{\prime-1}
on each block
\mathbf{H}^{\prime}_{1},\mathbf{H}^{\prime}_{2},\mathbf{H}^{\prime}_{3}
of matrix
\mathbf{H}^{\prime}
.

First we prove part (iii).
By construction, the last
nm+1
columns of
\mathbf{H}^{\prime}
, contained in
\mathbf{H}^{\prime}_{3}
are identical to
\mathbf{e}_{k+1}
.
By assumption,
\mathbf{H}
does not contain a zero column, so no other column in
\mathbf{H}^{\prime}
outside of the block
\mathbf{H}^{\prime}_{3}
is equal to
\mathbf{e}_{k+1}
.
Then each of the
nm+1
columns in
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{3}
, and no other column of
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}
, is equal to
\mathbf{S}^{\prime-1}\mathbf{e}_{k+1}
.

By
Equation

3.1
, the last
nm+1
columns of
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
must be identical and equal to
\mathbf{S}^{\prime-1}\mathbf{e}_{k+1}
.
Since
\mathbf{M}^{\prime}=\mathbf{D}^{\prime}\mathbf{P}^{\prime}
for some diagonal matrix
\mathbf{D}^{\prime}
and permutation
\mathbf{P}^{\prime}
,
it maps each column in
\mathbf{G}^{\prime}
to a (possibly) scaled permutation of that column in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
.
Thus, the matrix
\mathbf{M}^{\prime}
must scale and permute the columns of
\mathbf{G}^{\prime}
to produce
nm+1
identical columns in the last block of
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
.
We claim that multiplying by
\mathbf{M}^{\prime}
cannot cause the number of copies of a column in
\mathbf{G}^{\prime}
to increase in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
.
In particular, no two columns from different blocks of
\mathbf{G}^{\prime}
can be scaled to produce identical columns in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
.
By construction, the last row of
\mathbf{G}^{\prime}
ensures that no column of
\mathbf{G}^{\prime}_{1}
can be scaled to produce a column of
\mathbf{G}^{\prime}_{2}
, so
\mathbf{M}^{\prime}
cannot map columns from
\mathbf{G}^{\prime}_{1}
and
\mathbf{G}^{\prime}_{2}
to identical columns in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
.
Additionally,
\mathbf{M}^{\prime}
maps every
\mathbf{e}_{k+1}
column in
\mathbf{G}^{\prime}_{3}
to a scaling of
\mathbf{e}_{k+1}
in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
,
and since no column in
\mathbf{G}^{\prime}_{1}
or
\mathbf{G}^{\prime}_{2}
can be scaled to produce a multiple of
\mathbf{e}_{k+1}
, all scalings of
\mathbf{e}_{k+1}
in
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
can only come from
\mathbf{G}^{\prime}_{3}
.
The only column in
\mathbf{G}^{\prime}
that appears
nm+1
times is
\mathbf{e}_{k+1}
from
\mathbf{G}^{\prime}_{3}
.
In this way,
\mathbf{M}^{\prime}
can only produce
nm+1
identical columns in the last block of
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
by mapping from the
nm+1
columns of
\mathbf{G}^{\prime}_{3}
.
Therefore,
\sigma_{\mathbf{P}^{\prime}}(i)
maps every column with index in
[n+mn+1,n^{\prime}]
to a column with index in
[n+mn+1,n^{\prime}]
.

Next we show part (ii).
By part (iii), any column with index
i\in[n+1,n+mn]
is permuted to a column with index
\sigma_{\mathbf{P}^{\prime}}(i)\leq n+mn
, so it is enough to show that
\sigma_{\mathbf{P}^{\prime}}(i)\geq n+1
.
Suppose for the sake of contradiction that there is a column with index
i\in[n+1,n+nm]
in
\mathbf{G}^{\prime}
that is mapped to a column with index
\sigma_{\mathbf{P}^{\prime}}(i)\in[1,n]
.
By design, the last entry of the columns in
\mathbf{G}^{\prime}_{1}
is 1 and differs from the last entry 0 of the columns in
\mathbf{G}^{\prime}_{2}
, so each column in
\mathbf{G}^{\prime}_{1}
appears strictly less than
m
times.
Then, if
\mathbf{M}^{\prime}
permutes any number of columns from
\mathbf{G}^{\prime}_{1}
with the same number of columns in
\mathbf{G}^{\prime}_{2}
, there will be some column in the second block of
\mathbf{G}^{\prime}\mathbf{M}^{\prime}
that appears less than
m
times.
But by
2.1
, every column in
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{2}
appears at least
m
times, and since the second block of
\mathbf{G}^{\prime}\mathbf{P}^{\prime}
must be equal to
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{2}
, this gives a contradiction.

Finally, part (i) follows immediately from parts (ii) and (iii).

Lemma 3.10
.

For any

\mathbf{S}^{\prime}

k
entries.

3.

The entry
\mathbf{S}^{\prime}[k+1,k+1]
is non-zero.

Proof.

By definition,
\mathbf{S}^{\prime}
has an inverse
\mathbf{S}^{\prime-1}\in\mathrm{GL}_{k+1}
, so we can write
\mathbf{G}^{\prime}\mathbf{M}^{\prime}=\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}
.
By
2.1
,
\mathbf{S}^{\prime-1}
maps identical columns in
\mathbf{H}^{\prime}
to identical columns in
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}
.
To prove each part of the claim, we analyze the effect of
\mathbf{S}^{\prime-1}
on each block
\mathbf{H}^{\prime}_{2}
and
\mathbf{H}^{\prime}_{3}
in the right-hand side of the equation.

By
Corollary

3.9
, we know that
\mathbf{M}^{\prime}
is comprised of three block matrices
\mathbf{M}_{1}\in\mathcal{M}_{n}
,
\mathbf{M}_{2}\in\mathcal{M}_{nm}
, and
\mathbf{M}_{3}\in\mathcal{M}_{nm+1}
that affect the first
n
, next

columns of
\mathbf{G}^{\prime}

This allows us to write

\mathbf{G}^{\prime}_{3}\mathbf{M}_{3}=\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{3}

For part (i), consider the equation
\mathbf{G}^{\prime}_{3}\mathbf{M}_{3}=\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{3}

By construction, all columns of
\mathbf{G}^{\prime}_{3}
and
\mathbf{H}^{\prime}_{3}

\mathbf{e}_{k+1}
.
Since
\mathbf{M}_{3}
permutes all columns of
\mathbf{G}^{\prime}_{3}

\mathbf{G}^{\prime}_{3}\mathbf{M}_{3}

for some non-zero

, all columns of
\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{3}

Then for any column

\mathbf{G}^{\prime}_{3}\mathbf{M}_{3}

.
If any of the first
k
entries of the last column of
\mathbf{S}^{\prime}
is non-zero, then the corresponding entry in
\mathbf{S}^{\prime}(a\cdot\mathbf{e}_{k+1})=\mathbf{e}_{k+1}
must be non-zero, but this is not the case.
Therefore, the last column of
\mathbf{S}^{\prime}
must contain zeros in the first
k
entries.

For part (ii), consider the equation
\mathbf{G}^{\prime}_{2}\mathbf{M}_{2}=\mathbf{S}^{\prime-1}\mathbf{H}^{\prime}_{2}
.
By construction, the last rows of
\mathbf{G}^{\prime}_{2}
and
\mathbf{H}^{\prime}_{2}
only contains zeros.
By

, no columns in
\mathbf{G}^{\prime}_{2}\mathbf{M}_{2}
could have been mapped from outside
\mathbf{G}^{\prime}_{2}

\mathbf{G}^{\prime}_{2}\mathbf{M}_{2}

k
.

k

k

Then the first

\mathbf{G}^{\prime}_{2}\mathbf{M}_{2}

4
Conclusion

Our results imply that the
CE
variants described above are nearly computationally equivalent, from the perspective of polynomial-time algorithms.
In particular, we have shown that
LCE
and
SPCE
are at least as hard as
PCE
, so in order to study the hardness of the former two problems, it suffices to focus on the hardness of
PCE
.
We now have more reductions among the
CE
variants, and in consequence, from these variants to
LIP
, yet it remains an open problem to reduce
LIP
to any
CE
problem.
While there has been some small progress in this direction, namely Ducas and Gibbons’ Turing reduction from
LIP
for Construction A lattices to
SPCE
for codes with zero hull
[
DG23
]
, no other progress has yet been made.

Another interesting open problem is to improve the runtime of the reduction from
LCE
to
PCE
proven in
[
SS13a
]
from
\mathrm{poly}(n,q)
to
\mathrm{poly}(n,\log q)
.
Their reduction requires time polynomial in the alphabet size
q
because the closure (see
Section

1
for details) increases the blocklength of the codes from
n
to
(q-1)n
.
Any reduction running in
\log q
time would either need to use a new type of closure that requires only a
\log q
increase in blocklength, or a more efficient way to transform scalar multiplication operations into permutations.
