Local enegy decay for 2 2 -D wave equations with variable coefficients
Ryo Ikehata

Abstract
This paper addresses the two-dimensional initial value problem in 𝐑 2 {\bf R}^{2} for the wave equation with varying spatial coefficients in the main part. Assuming compactness in the support of the initial value, we report that the corresponding local energy decays to an order of magnitude of, for example, O ⁡ ( t − 1 ​ log ⁡ t ) O(t^{-1}\sqrt{\log t}) after sufficiently large time. For the two-dimensional whole space case, it is crucial to establish the optimal L 2 L^{2} -estimate for the solution itself, skillfully avoiding the difficulty of not being able to use useful inequalities such as Hardy-type inequalities in higher dimensional case. We also consider cases where the variable coefficients are slightly generalized. These proofs are developed using the multiplier method.

Theorem 1.1

Remark 1.1

Condition

\leq\frac{1}{2}\|u_{0}\|_{L^{2}}^{2}+C_{\varepsilon}\int_{|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx.

(2.15)

Note that

\int_{|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx<+\infty

for each
t\geq 0
because of
h\in C^{2}({\bf R}^{2})
. By choosing the parameter
\varepsilon>0
small enough one can get the crucial estimate because of
v_{t}=u
.

\|u(t,\cdot)\|_{L^{2}}^{2}\leq\|u_{0}\|_{L^{2}}^{2}+2C_{\varepsilon}\int_{|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx.

(2.16)

Let us estimate the second term of the right hand side of (
2.16
) by using Lemma
2.4
. First, we see that

\int_{|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx=I_{h}+\int_{2L\leq|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx.

(2.17)

Thus, from Lemma
2.4
it follows that

\int_{2L\leq|x|\leq 2L+k_{1}t}|\nabla h(x)|^{2}dx\leq C^{2}\|u_{1}\|_{L^{1}}^{2}\int_{2L\leq|x|\leq 2L+k_{1}t}\frac{1}{|x|^{2}}dx

=2\pi C^{2}\|u_{1}\|_{L^{1}}^{2}\int_{2L}^{2L+k_{1}t}\frac{r}{r^{2}}dr=2\pi C^{2}\|u_{1}\|_{L^{1}}^{2}\left(\log(2L+k_{1}t)-\log(2L)\right)

\leq 2\pi C^{2}\|u_{1}\|_{L^{1}}^{2}\log(2L+k_{1}t)\quad(t\geq 0).

(2.18)

Therefore, by (
2.17
) and (
2.18
) one has arrived at the desired estimate.

\Box

Finally, let us estimate

It is important to point out that the integral region of the quantity

The lemma below has also already been discussed in

Lemma 2.6

For the function
h(x)
defined in (
2.11

I_{h}=\int_{|x|\leq 2L}|\nabla h(x)|^{2}dx\leq C_{L}\|u_{1}\|_{L^{\infty}}^{2}

with some constant
C_{L}>0

Proof.
For an arbitrarily fixed

, and we set

|\nabla h(x_{0})|\leq\frac{1}{2\pi}\int_{{\bf R}^{2}}\frac{|u_{1}(y)|}{|x_{0}-y|}dy=\frac{1}{2\pi}\int_{|y|\leq L}\frac{|u_{1}(y)|}{|x_{0}-y|}dy

=\frac{1}{2\pi}\int_{B_{L}(x_{0})}\frac{|u_{1}(x_{0}-z)|}{|z|}dz

\leq\frac{\|u_{1}\|_{L^{\infty}}}{2\pi}\int_{B_{L}(x_{0})}\frac{1}{|z|}dz.

(2.19)

It should be noticed that in the case of

sufficiently. Thus, we get

(2.20)

Put
x_{0}
back into

to get the following by (
2.19
) and (
2.20

|\nabla h(x)|\leq 4L\|u_{1}\|_{L^{\infty}}\quad\forall x\in B_{2L}.

Therefore, one can obtain the desired estimate.

4
Generalization of the Conditions for
K(x)

In this section, we generalize the condition
(K-2)
assuming monotonicity. Therefore, we will replace
(K-2)
with the following condition.

(K-4)
There exists a real number
\gamma_{0}\in[0,1)
such that
x\cdot\nabla K(x)\leq\gamma_{0}K(x)
for all
x\in{\bf R}^{2}
.

One can state the following slightly generalized version of Theorem
1.1
.

Theorem 4.1

Assume (
1.3
) on the initial data
u_{j}\in C_{0}^{\infty}({\bf R}^{2})

(
j=0,1
)
and the conditions
(K-1)
,
(K-3)
and
(K-4)
. Let
R>r_{0}
be an arbitrarily fixed real number. Then, for the solution
u(t,x)
to problem (
1.1
)-(
1.2
) it holds that

E_{u,R}(t)=O(t^{\gamma_{0}-1}\sqrt{\log t})\quad(t\gg 1).

Proof.
Let
R>r_{0}
. Then, as in the proof of Theorem
1.1
it follows from
(K-3)
and Lemma
2.1
that

tE_{u}(t)\leq J_{0}+C_{3}\sqrt{E_{u}(0)}\left(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1}\right)\sqrt{\log t}

+\frac{R}{\sqrt{k_{m}}}E_{u,R}(t)+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx+t\int_{|x|\geq R}e(t,x)dx+\gamma_{0}\int_{0}^{t}E_{u,R}(s)ds.

This implies

(t-\frac{R}{\sqrt{k_{m}}})E_{u,R}(t)\leq A_{0}(t)+\gamma_{0}\int_{0}^{t}E_{u,R}(s)ds\quad(t\gg 1),

(4.1)

where

A_{0}(t):=J_{0}+C_{3}\sqrt{E_{u}(0)}\left(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1}\right)\sqrt{\log t}+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx.

Let us solve the differential inequality (
4.1
). For this set

w(t):=(t-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}\int_{0}^{t}E_{u,R}(s)ds.

Then, by differentiating
w(t)
one finds that

w^{\prime}(t)=(t-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}\left((t-\frac{R}{\sqrt{k_{m}}})E_{u,R}(t)-\gamma_{0}\int_{0}^{t}E_{u,R}(s)ds\right)

\leq A_{0}(t)(t-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}\quad(a.e.\,\,t\gg 1).

Integration it over
[t_{0},t]
with large fixed
t_{0}\gg 1
, we see that

w(t)\leq w(t_{0})+\left(J_{0}+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx\right)\int_{t_{0}}^{t}(s-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}ds

+\left(C_{3}\sqrt{E_{u}(0)}(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1})\right)\int_{t_{0}}^{t}\sqrt{\log s}(s-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}ds\quad(t\geq t_{0}).

Here, note that

\int_{t_{0}}^{t}\sqrt{\log s}(s-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}ds\leq\sqrt{\log t}\int_{t_{0}}^{t}(s-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}-1}ds

\leq\frac{1}{\gamma_{0}}\sqrt{\log t}(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}\quad(t\geq t_{0}).

Therefore, one can get

w(t)\leq w(t_{0})+\left(J_{0}+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx\right)\frac{1}{\gamma_{0}}(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}

+\left(C_{3}\sqrt{E_{u}(0)}(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1})\right)\frac{1}{\gamma_{0}}(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}\sqrt{\log t}.

(4.2)

Additionally, from (
4.1
) we can get

(t-\frac{R}{\sqrt{k_{m}}})E_{u,R}(t)\leq A_{0}(t)+\gamma_{0}\int_{0}^{t}E_{u,R}(s)ds

=A_{0}(t)+\gamma_{0}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}}w(t).

(4.3)

By combining (
4.2
) and (
4.3
) it follows that

(t-\frac{R}{\sqrt{k_{m}}})E_{u,R}(t)\leq A_{0}(t)+\gamma_{0}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}}w(t_{0})

+\left(J_{0}+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx\right)(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}}

+\left(C_{3}\sqrt{E_{u}(0)}(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1})\right)(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}}\sqrt{\log t}.

This gives

E_{u,R}(t)\leq A_{0}(t)(t-\frac{R}{\sqrt{k_{m}}})^{-1}+\gamma_{0}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}-1}w(t_{0})

+\left(J_{0}+\frac{C_{r_{0}}}{\sqrt{k_{m}}}\int_{{\bf R}^{2}}(1+|x|)e(0,x)dx\right)(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}-1}

+\left(C_{3}\sqrt{E_{u}(0)}(\|u_{0}\|+\|u_{1}\|_{\infty}+\|u_{1}\|_{1})\right)(t_{0}-\frac{R}{\sqrt{k_{m}}})^{-\gamma_{0}}(t-\frac{R}{\sqrt{k_{m}}})^{\gamma_{0}-1}\sqrt{\log t},

which implies the desired estimate

E_{u,R}(t)=O(t^{\gamma_{0}-1}\sqrt{\log t})\quad(t\gg 1).

Note that
A_{0}(t)\sim\sqrt{\log t}
.

\Box

Remark 4.1

To justify the proof of the above theorem, note the following.

Since the class of solutions under consideration is at least
u\in C([0,\infty);H^{1}({\bf R}^{2}))\cap C^{1}([0,\infty);L^{2}({\bf R}^{2}))
, the continuity of the function

Similarly, the continuity of the function
t\mapsto\|\sqrt{K(\cdot)}\nabla u(t)\|_{L^{2}(B_{R})}
for each
R>0
can be checked under the condition that

. These imply the continuity of the mapping
t\mapsto E_{u,R}(t)
.
