Abstract
A parasitic reconfigurable antenna array is a low-power approach for beamforming using passive tunable elements. Prior work on reconfigurable antennas in communication theory is based on ideal radiation pattern abstractions. It does not address the problem of physical realizability. Beamforming with parasitic elements is inherently difficult because mutual coupling creates non-linearity in the beamforming gain objective. We develop a multi-port circuit-theoretic model of the hybrid array with parasitic elements and antennas with active RF chain validated through electromagnetic simulations with a dipole array. We then derive the beamforming weight of the parasitic element using the theoretical beam pattern expression for the case of a single active antenna and multiple parasitic elements. We show that the parasitic beamforming is challenging because the weights are subject to coupled magnitude and phase constraints. We simplify the beamforming optimization problem using a shift-of-origin transformation to the typical unit-modulus beamforming weight. With this transformation, we derive a closed-form solution for the reconfigurable parasitic reactance. We generalize this solution to the multi-active multi-parasitic hybrid array operating in a multi-path channel. Our proposed hybrid architecture with parasitic elements outperforms conventional architectures in terms of energy efficiency.

Motivation and challenges

Reconfigurable parasitic antennas have the potential to enable low-cost, energy-efficient beamforming for larger arrays

The current on a parasitic element depends on the active antenna current via the reconfigurable load, complicating the beamforming gain optimization by creating non-linearity in the objective function.
We focus on developing a low-complexity approach for beamforming optimization, analyze the spectral efficiency and energy efficiency of a parasitic array system, and compare with conventional architectures.

I-C

Contributions

We use the multi-port circuit theory approach from
[
31
]
to formulate the multiple-input-single-output (MISO) model for a reconfigurable parasitic array with multiple active and parasitic elements operating in a multi-path wireless channel. We validate the derived theoretical beamforming gain expression through electromagnetic simulations which enables its use in formulating an optimization problem.
We solve the LOS channel beamforming optimization problem for the single active and multiple parasitic antenna case. Since the beamforming optimization problem is mathematically intractable in its original form, we propose a relaxed objective function that leads to a tractable closed-form expression for the reconfigurable parasitic reactance. We validate the accuracy of this solution by comparing it with the numerical approach from the MATLAB optimization toolbox.
For the beamforming optimization problem with a hybrid multi-active multi-parasitic array operating in a multi-path channel, we propose a near-optimal closed-form solution for the active antenna current and the parasitic reactances for beamforming.
We compare the spectral and energy efficiency of the hybrid parasitic array beamforming with that of the fully digital array without any parasitic elements. We show that parasitic elements improve the spectral efficiency without any additional power overhead. This demonstrates that beamforming with hybrid parasitic arrays is an energy-efficient approach.

We highlight the novelty of our paper by comparing it to prior studies. The communication-theoretic approaches in
[
22
,
23
,
24
]
employ realistic system models, such as multi-path channels, but rely on generic abstractions of reconfigurable antenna radiation patterns and numerical optimization methods. The circuit-theoretic approaches in
[
37
,
38
]
utilize multi-port models for parasitic arrays, but are limited to providing closed-form design guidelines for parasitic impedances in the form of inequalities. They do not derive optimal solutions and are also restricted to LOS channels.
In this paper, we formulate a beamforming optimization problem for a parasitic reconfigurable hybrid array operating in a multi-path propagation environment. We derive closed-form solutions for both the parasitic reactances and the active antenna currents, providing a comprehensive and tractable framework for system analysis.

II-B

Parasitic antenna array model with one active element

The array implementation dictates the constraints on the current vector. Beamforming in an antenna array is achieved by configuring the current vector
\bm{{\mathsf{i}}}_{\mathsf{TX}}

\bm{{\mathsf{i}}}_{\mathsf{TX}}

In contrast, parasitic arrays create beam patterns using a combination of active phase control and mutual coupling with parasitic elements that have variable loads. These antennas, known as parasitic elements, are reconfigured by altering their variable loads. Changing the termination of these elements dynamically modifies their radiative properties, enabling beamforming but imposing additional constraints on
\bm{{\mathsf{i}}}_{\mathsf{TX}}

Parasitic array beamforming problem formulation

We develop an algorithm to adjust the weights to maximize the beamforming gain in the direction of

Reconfiguring with varactor or PIN diodes is generally abstracted as terminating the parasitic element with reconfigurable reactive components

These reactive components can be either inductors or capacitors

[
7
,
38
]
. We propose a closed-form solution that yields design insights by analyzing the dependence of the parasitic reactance on parameters like the mutual impedance vector, array steering vector, and self-impedance of the parasitic element.

The beam pattern has a complicated dependence on the reconfigurable load
\bm{\mathsf{Z}}_{\mathsf{R}}
. The matrix
\bm{\mathsf{Z}}_{\mathsf{R}}
is inside an inverse term in (
8
) which makes it difficult to solve
P1
in its current form.
In a conventional array beamsteering problem, the pattern depends on a linear combination of beamforming weights.
To obtain a linear relation in (
8
), we simplify the matrix inverse via a diagonal approximation.
From antenna array literature, we know that the self-impedance is generally higher in magnitude compared to the mutual impedance
[
40
]
. With this observation, we separate all self-impedances of the parasitic array by defining
\bm{\mathsf{D}}_{\mathsf{P}}=\mathsf{diag}\{\bm{\mathsf{Z}}_{\mathsf{P}}\}
and the hollow matrix
\bm{\mathsf{E}}_{\mathsf{P}}=\bm{\mathsf{Z}}_{\mathsf{P}}-\bm{\mathsf{D}}_{\mathsf{P}}
which includes all mutual impedances.
The matrix
\bm{\mathsf{Z}}_{\mathsf{R}}
is diagonal based on the parasitic array design defined in Section
II-B
.
We combine the two diagonal matrices
\bm{\mathsf{Z}}_{\mathsf{R}}
and
\bm{\mathsf{D}}_{\mathsf{P}}
by defining the parasitic beamforming weight matrix
{\mathbf{W}}
which is also diagonal as

{\mathbf{W}}^{-1}=\bm{\mathsf{D}}_{\mathsf{P}}+\bm{\mathsf{Z}}_{\mathsf{R}}.

(10)

With these definitions, we write the inverse term in (
8
) as
(\bm{\mathsf{Z}}_{\mathsf{P}}+\bm{\mathsf{Z}}_{\mathsf{R}})^{-1}=(\bm{\mathsf{E}}_{\mathsf{P}}+\bm{\mathsf{D}}_{\mathsf{P}}+\bm{\mathsf{Z}}_{\mathsf{R}})^{-1}=(\bm{\mathsf{E}}_{\mathsf{P}}+{\mathbf{W}}^{-1})^{-1}
.
For small
N_{\mathsf{P}}
, as
\|\bm{\mathsf{E}}_{\mathsf{P}}\|_{\mathrm{F}}
is small relative to
\|{\mathbf{W}}^{-1}\|_{\mathrm{F}}
, we further expand the term
(\bm{\mathsf{E}}_{\mathsf{P}}+{\mathbf{W}}^{-1})^{-1}
using perturbation theory as

(\bm{\mathsf{E}}_{\mathsf{P}}+{\mathbf{W}}^{-1})^{-1}={\mathbf{W}}-{\mathbf{W}}\bm{\mathsf{E}}_{\mathsf{P}}{\mathbf{W}}+\mathcal{O}(\|\bm{\mathsf{E}}_{\mathsf{P}}\|^{2}_{\mathrm{F}}).

(11)

Using the first order term from (
11
), we approximate the objective
\mathcal{G}(\theta_{1},\bm{\mathsf{Z}}_{\mathsf{R}})
by defining
\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}})
in terms of
{\mathbf{W}}
as

\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}})=|1-{\mathbf{a}}^{\mathrm{T}}_{\mathsf{P}}(\theta_{1}){\mathbf{W}}\bm{{\mathsf{z}}}_{{\mathsf{m}}}|^{2}.

(12)

The approximate objective
\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}})
is easier to optimize because
{\mathbf{W}}
is a diagonal matrix.
This motivates us to use
\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}})
as the new objective function instead of
\mathcal{G}(\theta_{1},\bm{\mathsf{Z}}_{\mathsf{R}})
. In Appendix
A
, we show that
\mathcal{G}(\theta_{1},\bm{\mathsf{Z}}_{\mathsf{R}})\rightarrow\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}})
for small
\|\bm{\mathsf{E}}_{\mathsf{P}}\|_{\mathrm{F}}
.

III-B

Coupled magnitude and phase constraint

In a conventional active array beamforming problem, the magnitude and phase of the beamforming weight can be tuned independently.
For parasitic arrays, we analyze the beamforming weight matrix
{\mathbf{W}}
and show that the phase and magnitude are coupled that makes the optimization problem challenging.
The
i
th diagonal element of the matrix
{\mathbf{W}}
is
[{\mathbf{W}}]_{ii}=\frac{1}{[\bm{\mathsf{D}}_{\mathsf{P}}]_{ii}+[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}}.

The phase of
[{\mathbf{W}}]_{ii}
is

\displaystyle\angle([{\mathbf{W}}]_{ii})

\displaystyle=\mathsf{atan2}(\mathcal{I}\{[{\mathbf{W}}]_{ii}\},\mathcal{R}\{[{\mathbf{W}}]_{ii}\}),

(13)

\displaystyle\stackrel{{\scriptstyle(a)}}{{=}}\mathsf{tan}^{-1}\left(\frac{-(\mathcal{I}\{[\bm{\mathsf{D}}_{\mathsf{P}}]_{ii}\}+\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\})}{(\mathcal{R}\{[\bm{\mathsf{D}}_{\mathsf{P}}]_{ii}\}+\mathcal{R}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\})}\right),

where
(a)
follows from the fact that the real part is always positive as it is a resistance term.
We define
\zeta_{i}=\frac{1}{(\mathcal{R}\{[\bm{\mathsf{D}}_{\mathsf{P}}]_{ii}\}+\mathcal{R}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\})}
and
\varphi_{i}=\angle([{\mathbf{W}}]_{ii})
. The beamforming weight
[{\mathbf{W}}]_{ii}
is expressed in terms of
\varphi_{i}
and
\zeta_{i}
as

[{\mathbf{W}}]_{ii}=\zeta_{i}\cos(\varphi_{i})e^{{\mathsf{j}}\varphi_{i}}.

(14)

From (
14
), the magnitude of
[{\mathbf{W}}]_{ii}
varies as a sinusoidal function of the phase angle, which complicates the beamforming problem.

We visualize the beamforming weight
[{\mathbf{W}}]_{ii}
in the complex domain by plotting its locus.
We assume that the parasitic elements are identical. Hence,
the self-impedances of all parasitic elements are same, i.e.,
[\bm{\mathsf{Z}}_{\mathsf{P}}]_{ii}=[\bm{\mathsf{D}}_{\mathsf{P}}]_{ii}=Z_{\mathsf{P}}
. We define
\zeta=(\mathcal{R}\{Z_{\mathsf{P}}\}+\mathcal{R}\{Z_{\mathsf{R}}\})^{-1}
and set
\zeta_{i}=\zeta~\forall~i
.
We plot the locus of the normalized beamforming weight
{[{\mathbf{W}}]_{ii}}/{\zeta}
in complex domain as a function of the phase angle
\varphi_{i}
in Fig.
4
. The locus of
{[{\mathbf{W}}]_{ii}}/{\zeta}
is a circle with center at
\left(0.5,0\right)

and a radius of
0.5
. The phase angle
\varphi_{i}
has a limited phase range
[-\pi/2,\pi/2]
.
This constraint is known as the Lorentzian constraint.
It also appears in the literature on dynamic metasurface antennas (DMA)
[
41
,
42
,
43
]
.

We reformulate the optimization problem based on the Lorentzian constraint observation to leverage the solution approach developed in
[
41
,
42
,
43
]
.
From (
13
) and the definition of
\zeta
, we can express the optimization variable
\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\}
in terms of the phase angle
\angle([{\mathbf{W}}]_{ii})
as

\displaystyle\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\}=-\mathcal{I}\{Z_{\mathsf{P}}\}-\frac{\tan(\angle([{\mathbf{W}}]_{ii}))}{\zeta}.

(15)

In (
15
), we see that there is a one-to-one mapping between
\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\}
and the approximate beamforming weight phase angle.
We formulate the beamforming problem using the approximate objective
\widehat{\mathcal{G}}(\theta,{\mathbf{W}})
as

P2:

\displaystyle\underset{{\mathbf{W}}}{\mbox{ max }}\widehat{\mathcal{G}}(\theta_{1},{\mathbf{W}}),

(16a)

\displaystyle\text{ s.t. }{[{\mathbf{W}}]_{ii}}/{\zeta}=\cos(\varphi_{i})e^{{\mathsf{j}}\varphi_{i}},

(16b)

\displaystyle\varphi_{i}\in\left[-{\pi}/{2},{\pi}/{2}\right].

(16c)

The constraints of problem
P2
are similar to the beamforming constraints of a DMA
[
41
,
42
,
43
]
. This inspires us to use an optimization solution approach similar to
[
43
]
.

In
[
43
]
, the DMA beamforming weight is transformed from a unit-modulus beamforming weight to simplify the optimization problem. We express the normalized parasitic beamforming weight in terms of a unit-modulus beamforming weight
e^{{\mathsf{j}}{\phi}_{i}}
by applying a shift-of-origin transformation as

\displaystyle\frac{[{\mathbf{W}}]_{ii}}{\zeta}=\frac{1}{2}(1+e^{{\mathsf{j}}{\phi}_{i}}).

(17)

Equating the magnitude and phase of the right hand side of (
16b
) and (
17
), we obtain the relation between
{\phi}_{i}
and
\varphi_{i}
as

\displaystyle\phi_{i}=2\varphi_{i}=2\angle([{\mathbf{W}}]_{ii}).

(18)

The geometric interpretation of (
17
) and (
18
) is shown in Fig.
4
.

As
\phi_{i}
has range
[-\pi,\pi]
, it is easier to solve problem

P2
in terms of
\phi_{i}
instead of
\varphi_{i}
. Let
\bm{\Phi}=\mathsf{diag}\{[e^{{\mathsf{j}}\phi_{1}},\dots,e^{{\mathsf{j}}\phi_{N_{\mathsf{P}}}}]^{\mathrm{T}}\}
. We express
{\mathbf{W}}
in terms of
\bm{\Phi}
as

\displaystyle{\mathbf{W}}=\frac{\zeta}{2}({\mathbf{I}}_{N_{\mathsf{P}}}+\bm{\Phi}).

(19)

By substituting
{\mathbf{W}}
from (
19
) in (
12
), we obtain

\displaystyle\widehat{\mathcal{G}}(\theta_{1},\bm{\Phi})=\left|1-\frac{\zeta}{2}{\mathbf{a}}^{\mathrm{T}}_{\mathsf{P}}(\theta_{1})({\mathbf{I}}_{N_{\mathsf{P}}}+\bm{\Phi})\bm{{\mathsf{z}}}_{{\mathsf{m}}}\right|^{2}.

(20)

The problem

P2
is then equivalent to

P3:

\displaystyle\underset{\bm{\Phi}}{\mbox{ max }}\widehat{\mathcal{G}}(\theta_{1},\bm{\Phi}),

(21a)

\displaystyle\text{ s.t. }\angle([\bm{\Phi}]_{ii})\in[-\pi,\pi].

(21b)

We solve
P3
in terms of
\bm{\Phi}
and then obtain the closed-form expression of parasitic reactance using (
15
) and (
18
).

Fig. 4
:
The locus of the parasitic beamforming weight in the complex plane is a circle centered at
(0.5,0)
with radius
0.5
. We use a shift-of-origin transformation that reformulates the optimization in terms of the unit magnitude beamforming weight to avoid dealing with the coupled magnitude and phase constraint.

III-C

Closed-form solution for the reconfigurable parasitic load reactance

We follow a mathematical approach similar to
[
43
]
to derive the closed-form solution for
\bm{\Phi}
. In the following theorem, we provide the closed-form solution to
P3
.

Theorem 1

The closed-form solution to problem
P3
is

\displaystyle\angle([\bm{\Phi}]_{ii})\!=\!\angle\bigg(\!\!1\!-\!\frac{\zeta{\mathbf{a}}^{\mathrm{T}}_{\mathsf{P}}(\theta_{1})\bm{{\mathsf{z}}}_{{\mathsf{m}}}}{2}\!\!\!\bigg)\!-\!\angle\left([{\mathbf{a}}_{\mathsf{P}}(\theta_{1})]_{i}[\bm{{\mathsf{z}}}_{{\mathsf{m}}}]_{i}\right)\!+\!(2m\!+\!1)\pi\!,

(22)

where
m
is any integer.

Proof:

See Appendix
B
for the proof.
∎

From the closed-form expression of
\bm{\Phi}
in (
22
), the term
\angle\left(1-{\zeta}{\mathbf{a}}^{\mathrm{T}}_{\mathsf{P}}(\theta_{1})\bm{{\mathsf{z}}}_{{\mathsf{m}}}/{2}\right)
is common across all parasitic elements. In standard beamforming problems, the optimal solution is unaffected by common phase shifts
[
40
]
. For beamforming architectures like parasitic antennas or DMAs, which have coupled magnitude and phase constraints as in (
16b
), the reformulation introduces an offset term in the objective function that is independent of the beamforming weights, as shown in (
20
). This parasitic constraint alters the problem, causing the optimal phase angle solution to depend on common phase rotations.

We derive a closed-form expression that explicitly shows the dependence of the
i
th element’s load reactance on the array steering vector, mutual impedance vector, self-impedance of the parasitic element, and real part of the parasitic load.

Theorem 2

The closed-form solution for the optimal reactance obtained from the solution to
P3
is

\displaystyle\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\}=-\mathcal{I}\{Z_{\mathsf{P}}\}-\frac{\cot\left(\frac{\angle([{\mathbf{a}}_{\mathsf{P}}(\theta_{1})]_{i}[\bm{{\mathsf{z}}}_{{\mathsf{m}}}]_{i})-\angle(1-\frac{\zeta}{2}{\mathbf{a}}^{\mathrm{T}}_{\mathsf{P}}(\theta_{1})\bm{{\mathsf{z}}}_{{\mathsf{m}}})}{2}\right)}{\zeta}.

(23)

Proof:

Using (
15
), (
18
), and (
22
), and
\tan\left(\frac{2m+1}{2}\pi-\theta\right)=\cot(\theta)~\forall~m\in{\mathbb{Z}}
, we obtain the desired result.
∎

From (
23
), we see that the first term in the expression of
\mathcal{I}\{[\bm{\mathsf{Z}}_{\mathsf{R}}]_{ii}\}
is negative of the self reactance of the parasitic element.
We observe that this first term is the same for all parasitic elements.
This means the proposed solution can be implemented with a simple hardware design for the reconfigurable load that has a common fixed reactance to cancel out the parasitic antenna self reactance connected in series with a tunable reactance given by the second term in (
23
) which depends on the steering vector.

The closed-form parasitic reactance expression is optimal for
N_{\mathsf{P}}=1
because the approximation error
\widetilde{\mathcal{G}}(\theta,Z_{\mathsf{R}})=0
.
For
N_{\mathsf{P}}>1
, the closed-form expression in (
23
) is sub-optimal for problem
P1
because the optimization is based on the approximate objective
\widehat{\mathcal{G}}(\theta,{\mathbf{W}})
.
In the numerical results section, we show that the proposed closed-form solution is nearly-optimal for
N_{\mathsf{P}}=2
by comparing it with the solution obtained from the MATLAB Global search toolbox. As the value of
N_{\mathsf{P}}
increases beyond 2, the approximation is worse. For practical designs, however, it suffices to use
N_{\mathsf{P}}=2
as shown in Section
V
.

IV
Beamforming with hybrid multi-active and multi-parasitic array in a multi-path channel

A hybrid architecture combining multiple active antennas with parasitic elements offers a practical solution to adding parasitics.
It overcomes the problem that
as inter-element spacing grows, the mutual coupling effect diminishes, leading to reduced performance gains. This architecture leverages the benefits of active antennas for improved control and parasitic elements for cost efficiency, making them well-suited for large-scale deployments.
In this section, we generalize the circuit model derived previously to the case of multi-active and multi-parasitic array. Then, we formulate the SNR maximization problem under radiated power constraint. Finally, we derive a low-complexity closed-form solution for jointly optimizing active antenna currents and parasitic reactances in Section
IV-C
.

IV-A

Multi-port circuit model and channel model generalization

We extend the multi-port circuit model from Fig.
2
, to now accommodate multiple active antennas. Let the array consist of
N_{\mathsf{A}}
active antennas, each paired with
N_{\mathsf{P}}
parasitic elements, resulting in a total of
N_{\mathsf{A}}N_{\mathsf{P}}
parasitic elements. Let the
N_{\mathsf{A}}\times~1
active antenna current vector be
\bm{{\mathsf{i}}}_{\mathsf{A}}=[\mathsf{i}_{\mathsf{A},1},\dots,\mathsf{i}_{\mathsf{A},N_{\mathsf{A}}}]^{\mathrm{T}}
and
N_{\mathsf{A}}N_{\mathsf{P}}\times 1
parasitic element current vector be

\bm{{\mathsf{i}}}_{\mathsf{P}}=[\mathsf{i}_{1,1},\dots,\mathsf{i}_{N_{\mathsf{P}},1},\dots,\mathsf{i}_{1,N_{\mathsf{A}}},\dots,\mathsf{i}_{N_{\mathsf{P}},N_{\mathsf{A}}}]^{\mathrm{T}}
. The current beamforming vector across all active and parasitic elements is denoted as
\bm{{\mathsf{i}}}_{\mathsf{TX}}=[\bm{{\mathsf{i}}}_{\mathsf{A}}^{\mathrm{T}},\bm{{\mathsf{i}}}_{\mathsf{P}}^{\mathrm{T}}]^{\mathrm{T}}
.

The mutual impedance matrix of dimension
N_{\mathsf{P}}N_{\mathsf{A}}\times N_{\mathsf{A}}
between the parasitic elements and active antennas is
\bm{\mathsf{Z}}_{{\mathsf{m}}}
.
We denote the mutual coupling vector between the
j
th active antenna and the
N_{\mathsf{P}}
parasitic elements belonging to the row of the
i
th active antenna as
\bm{{\mathsf{z}}}_{{\mathsf{m}},i,j}\in{\mathbb{C}}^{N_{\mathsf{P}}\times 1}
.
We express
\bm{\mathsf{Z}}_{{\mathsf{m}}}
in terms of the block-matrix notation as

\displaystyle\bm{\mathsf{Z}}_{{\mathsf{m}}}=\begin{bmatrix}\bm{{\mathsf{z}}}_{{\mathsf{m}},1,1}&\dots&\bm{{\mathsf{z}}}_{{\mathsf{m}},1,N_{\mathsf{A}}}\\
\vdots&\ddots&\vdots\\
\bm{{\mathsf{z}}}_{{\mathsf{m}},N_{\mathsf{A}},1}&\dots&\bm{{\mathsf{z}}}_{{\mathsf{m}},N_{\mathsf{A}},N_{\mathsf{A}}}\end{bmatrix}.

(24)

The matrix
\bm{\mathsf{Z}}_{\mathsf{A}}
of dimension
N_{\mathsf{A}}\times N_{\mathsf{A}}
is the mutual impedance between all active antennas and matrix
\bm{\mathsf{Z}}_{\mathsf{P}}
of dimension
N_{\mathsf{P}}N_{\mathsf{A}}\times N_{\mathsf{P}}N_{\mathsf{A}}
is the mutual impedance between all parasitic antennas.
We combine these matrices into a single mutual impedance matrix for the hybrid array and denote as
\bm{\mathsf{Z}}_{\mathsf{TX}}
. Using block matrix notation, we have
\bm{\mathsf{Z}}_{\mathsf{TX}}=\begin{bmatrix}\bm{\mathsf{Z}}_{\mathsf{A}}&\bm{\mathsf{Z}}_{{\mathsf{m}}}^{\mathrm{T}}\\
\bm{\mathsf{Z}}_{{\mathsf{m}}}&\bm{\mathsf{Z}}_{\mathsf{P}}\end{bmatrix}.

Let the variable load at the port of the

i
th parasitic element corresponding to the
j
th active antenna be

{Z_{\mathsf{R},i,j}}

\displaystyle\bm{\mathsf{Z}}_{\mathsf{R}}\!=\!\mathsf{diag}\{[\underbrace{Z_{\mathsf{R},1,1},\dots,Z_{\mathsf{R},N_{\mathsf{P}},1}}_{\mathsf{diag}\{\bm{\mathsf{Z}}_{\mathsf{R},1,1}\}},\dots,\underbrace{Z_{\mathsf{R},1,N_{\mathsf{A}}},\dots,Z_{\mathsf{R},N_{\mathsf{P}},N_{\mathsf{A}}}}_{\mathsf{diag}\{\bm{\mathsf{Z}}_{\mathsf{R},N_{\mathsf{A}},N_{\mathsf{A}}}\}}]^{\mathrm{T}}\!\}\!.

(25)

Following the steps similar to (
4
), we express the parasitic beamforming current vector as

\displaystyle\bm{{\mathsf{i}}}_{\mathsf{P}}=-(\bm{\mathsf{Z}}_{\mathsf{P}}+\bm{\mathsf{Z}}_{\mathsf{R}})^{-1}\bm{\mathsf{Z}}_{{\mathsf{m}}}\bm{{\mathsf{i}}}_{\mathsf{A}}.

(26)

From (

), we see that the parasitic array beamforming vector depends on the reconfigurable load matrix
\bm{\mathsf{Z}}_{\mathsf{R}}
and the active antenna current beamforming vector
\bm{{\mathsf{i}}}_{\mathsf{A}}

(27b)

SNR maximization under radiated power constraints

Using
\bm{{\mathsf{i}}}_{\mathsf{TX}}

\displaystyle\mathsf{SNR}(\bm{{\mathsf{i}}}_{\mathsf{A}},\bm{\mathsf{Z}}_{\mathsf{R}})

\displaystyle=\frac{|\bm{{\mathsf{i}}}_{\mathsf{TX}}^{\mathrm{T}}\bm{{\mathsf{z}}}_{\mathsf{RT}}|^{2}}{\sigma^{2}},

(28)

\bm{{\mathsf{i}}}_{\mathsf{P}}\end{bmatrix}.

(30)

\bm{{\mathsf{i}}}_{\mathsf{A}}

\displaystyle=\underset{\bm{{\mathsf{i}}}_{\mathsf{A}}\in{\mathbb{C}},\mathcal{I}\{\bm{\mathsf{Z}}_{\mathsf{R}}\}\in{\mathbb{R}}}{\mbox{ argmax }}\mathsf{SNR}(\bm{{\mathsf{i}}}_{\mathsf{A}},\bm{\mathsf{Z}}_{\mathsf{R}}),

VI
Conclusions and future work

In this paper, we applied a circuit theory modeling approach to a hybrid reconfigurable parasitic array with multiple active antennas and several parasitic elements controlled through tunable reactance.
As validated through the Feko software, the circuit theory approach is useful because we can use the proposed model for different parasitic configurations instead of doing repetitive simulations.
From the closed-form solution of the optimal reconfigurable parasitic reactance for a LOS channel, we identify a fixed reactance term common to all antennas and a dynamic term depending on the target angle.
For the general case of the hybrid array, we leverage this closed-form solution for parasitic reactance. We configure the active antenna currents to satisfy the transmitted power constraint based on the parasitic reactance configuration.
Using this closed-form solution, we simulate the spectral efficiency and energy efficiency of the hybrid architecture for different array dimensions and element spacings.
Compared to conventional benchmarks like fully digital array and hybrid sub-connected phase shifter architectures, the proposed parasitic reconfigurable array is more energy-efficient. The same spectral efficiency performance is achievable with a reduced number of RF chains and transmit power by adding reconfigurable parasitic elements to a fully digital array. We also identified a moderate inter-element spacing region for the parasitic array design to provide higher spectral efficiency.

In future work, we propose extending the MISO parasitic array to the MIMO case with reconfigurable parasitic antennas on both the transmitter and receiver.
Analyzing reconfigurable parasitic arrays with realistic matching network constraints is an important future direction. Another open challenge is a wideband generalization with frequency-selective models for parasitic antennas and matching networks
[
48
]
.

\widetilde{\mathcal{G}}(\theta,\bm{\mathsf{Z}}_{\mathsf{R}})=\mathcal{G}(\theta,\bm{\mathsf{Z}}_{\mathsf{R}})-\widehat{\mathcal{G}}(\theta,{\mathbf{W}})=|\Psi_{2}|^{2}+2\mathcal{R}\{\Psi_{1}^{\mathrm{c}}\Psi_{2}\}-\mathcal{O}(\|\bm{\mathsf{E}}_{\mathsf{P}}\|^{2}_{\mathrm{F}})

|\Psi_{2}|<\|{\mathbf{a}}_{\mathsf{P}}(\theta)\|\|{\mathbf{W}}\|^{2}_{\mathrm{F}}\|\bm{{\mathsf{z}}}_{{\mathsf{m}}}\|\|\bm{\mathsf{E}}_{\mathsf{P}}\|_{\mathrm{F}}=\kappa\|\bm{\mathsf{E}}_{\mathsf{P}}\|_{\mathrm{F}}

\|{\mathbf{W}}\|_{\mathrm{F}}
, and
\|\bm{{\mathsf{z}}}_{{\mathsf{m}}}\|
. As
\|\bm{\mathsf{E}}_{\mathsf{P}}\|_{\mathrm{F}}\rightarrow 0

\widetilde{\mathcal{G}}(\theta,\bm{\mathsf{Z}}_{\mathsf{R}})\rightarrow 0

\mathcal{G}(\theta,\bm{\mathsf{Z}}_{\mathsf{R}})\rightarrow\widehat{\mathcal{G}}(\theta,{\mathbf{W}})
