Filling some gaps on the edge coloring problem of split graphs
Fernanda Couto a, Diego Amaro Ferraz b , Sulamita Klein b

Abstract
A split graph is a graph whose vertex set can be partitioned into a clique and an independent set. A connected graph G G is said to be t t -admissible if admits a spanning tree in which the distance between any two adjacent vertices of G G is at most t t . Given a graph G G , determining the smallest t t for which G G is t t -admissible, i.e., the stretch index of G G denoted by σ ⁡ ( G ) \sigma(G) , is the goal of the t t -admissibility problem . Split graphs are 3 3 -admissible and can be partitioned into three subclasses: split graphs with σ = 1 , 2 \sigma=1,2 or 3 3 . In this work we consider such a partition while dealing with the problem of coloring the edges of a split graph. Vizing proved that any graph can have its edges colored with Δ \Delta or Δ + 1 \Delta+1 colors, and thus can be classified as Class 1 or Class 2 , respectively. The edge coloring problem is open for split graphs in general. In previous results, we classified split graphs with σ = 2 \sigma=2 and in this paper we classify and provide an algorithm to color the edges of a subclass of split graphs with σ = 3 \sigma=3 .

2
The edge coloring problem

A proper edge coloring of a graph consists in an assignment of colors to the edges of a graph
G=(V,E)
such that edges incident to the same vertex are colored with different colors. From now on, any coloring we refer in the text is proper. The smallest number of colors needed to color the edges of a graph
G
is called the
chromatic index
of
G
and is denoted by
\chi^{\prime}(G)
. Note that it is easy to see that the maximum degree
\Delta
of a graph
G
is a lower bound for
\chi^{\prime}(G)
as we need
\Delta
different colors to color the edges incident to a
\Delta
-vertex. In 1964, Vizing
[
Vizing
]
proved that
\Delta+1
is an upper bound for the chromatic index of any graph
G
, and thus, graphs can be classified either as
Class 1
, if they are
\Delta
-colorable, or as
Class 2
, otherwise. This problem is also known as the
classification problem
. Surprisingly, even with only two possible values for
\chi^{\prime}(G)
, the problem is proved to be
\mathsf{NP}
-complete
[
Holyer1981TheNO
]
, in general. However, it is open for several graph classes, for instance split graphs, the class we deal in this paper.

2.1
Known results

Although the

is open for split graphs, some partial results are known. In this subsection, we summarize some of these results.

Theorem 2.1

(
[

]
)
.

Let

be a complete graph

. If

is Class 1. Otherwise,

is Class 2.

Using an algorithm derived from Theorem

Theorem 2.2

(
[
Behzad
]
)
.

Let

be a graph with an universal vertex and an even number of vertices. Then

is Class 1.

For graphs with an odd number of vertices and a universal vertex, we have the following theorem.

Theorem 2.3

(Plantholt’s Result
[

]
)
.

Let
G
be a graph with an universal vertex and an odd number of vertices. Then

is Class 2 if, and only if,

is subgraph-overfull.

The technique presented by Plantholt
[

]
colors with

colors the edges of any graph

(not overfull) with an odd number of vertices such that
\Delta(G)=|V(G)|-1
. The algorithm colors the edges of a graph

with the same maximum degree and number of vertices of

\displaystyle{\Delta(G)\cdot\left\lfloor\frac{|V(G)|}{2}\right\rfloor}
edges. We call

into an overfull graph. Note that

can already be a saturated graph. The main idea of Plantholt’s method is: if we can color the edges of

colors, then we can color the edges of any subgraph of

(which maintains the number of vertices and the maximum degree of

\Delta(H)
colors, since removing edges cannot increase the chromatic index of a graph.
Chen et. al
[

]
provided an algorithm to color the edges of any split graph with an odd maximum degree.

Theorem 2.4

(
[
Chen
]
)
.

Let

be a split graph with an odd maximum degree. Then

is Class 1.

Almeida et. al
[

]
presented a sufficient condition for a split graph

Theorem 2.5

(
[

]
)
.

Let
