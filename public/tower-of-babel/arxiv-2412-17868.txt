1  Introduction

Arithmetic Ramsey theory deals with the monochromatic patterns found in any given finite coloring of the
integers or of the natural numbers
\mathbb{N}
. Here “coloring” means disjoint partition and a set is called “monochromatic” if it is included in one piece of the partition. A collection
\mathcal{F}
of subsets of
\mathbb{N}
is called partition regular if, for every finite coloring of
\mathbb{N}
, there exists a monochromatic element
F\in\mathcal{F}
. In
[
3
, Question 31]
asked the following question.

Question 1.1
.

Is
\{a,b,a(b+1)\}
partition regular?

However, he conjectured that the answer to this question should be negative. Here we prove the following theorem.

Theorem 1.2
.

For any finite coloring of
\mathbb{N}
, there exists
a,b
such that
\{a,b,ab,(a+1)b\}
is monochromatic.

Preliminaries

Before we prove our original proof we need some technical results that we use in our proof.

Ultrafilters are set-theoretic objects which are intimately related to the Ramsey theory. In this section, we give a brief introduction to this theory. For details, we refer to the book
[
1
]
to the readers.

•

A
filter

\mathcal{F}
over any nonempty set
X
is a collection of subsets of
X
such that

1.

\emptyset\notin\mathcal{F}
, and
X\in\mathcal{F}
,

2.

A\in\mathcal{F}
, and
A\subseteq B
implies
B\in\mathcal{F},

3.

A,B\in\mathcal{F}
implies
A\cap B\in\mathcal{F}.

Using Zorn’s lemma we can guarantee the existence of maximal filters which are called ultrafilters. Any ultrafilter
p
has the following property:

•

if
X=\bigcup_{i=1}^{r}A_{i}
is any finite partition of
X
, then there exists
i\in\{1,2,\ldots,r\}
such that
A_{i}\in p.

Due to this finite decomposability nature, to prove the partition regularity of a pattern, it is sufficient to prove the existence of ultrafilters witnessing the solutions of equations.

Denote by
\beta\mathbb{N}
be the collection of ultrafilters. For any
p,q\in\beta\mathbb{N},
define
p+q\in\beta\mathbb{N}
by

A\in p+q\iff\left\{x:\{y:x+y\in A\}\in q\right\}\in p.

One can show that
(\beta\mathbb{N},+)
is compact right topological semigroup. Using Zorn’s lemma one can show that
(\beta\mathbb{N},+)
contains idempotent elements. Each member of idempotent elements is called
IP
set. A set is said to be a
IP^{\star}
set if it is a member of all idempotent ultrafilters. Note that if
A\in p=p+p,
then
\{x:-x+A\in p\}\in p.
Denote by
A^{\star}=A\cap\{x:-x+A\in p\}\in p.
From
[
1
, Lemma 4.14]
, it is clear that if
A\in p
and
x\in A^{\star},
then
-x+A^{\star}\in p.
Now we will prove our Theorem.

2  Proof of Theorem
1.2

Before we proceed to our proof, we want to note that recently in
[
2
]
, J. Moreira proved that the pattern
\{x,x+y,xy\}
is monochromatic. The technique of Moreira’s proof does allow us to bring
y
in the same color. So to control the color of
y^{\prime}s
we need to improve that argument. Here, to prove our result, we improved the technique, by using the notions of additive
IP
sets.
And to control over
y^{\prime}s
we made sure that at each step of our induction, the
y^{\prime}s
come from the same sets, where we need the idempotents of
\beta\mathbb{N}.

Proof of Theorem
1.2
:

Let
\mathbb{N}=\bigcup_{i=1}^{r}A_{i}\cup\bigcup_{j=1}^{m}B_{j},
be a finite coloring of
\mathbb{N},
where for each
i\in\{1,2,\ldots,r\},
the set
A_{i}
is
IP
, and for each
j\in\{1,2,\ldots,m\},

B_{j}
is not
IP
. Clearly
\cup_{j=1}^{m}B_{j}
is not an
IP
set and
\cup_{i=1}^{r}A_{i}
is an
IP^{\star}
set. Define
D_{0}=A_{1}.
Choose
y_{1}\in A_{1}^{\star}
such that
-y_{1}+A_{1}\cap A_{1}
is
IP
. Define
C_{1}=y_{1}^{-1}\left(-y_{1}+A_{1}\cap A_{1}\right).

From
[
1
, Lemma 5.19.2]
, we have
C_{1}
is an
IP
set. So there exists
i_{1}\in\{1,2,\ldots,r\}
such that

D_{1}=C_{1}\cap A_{i_{1}}=y_{1}^{-1}\left(-y_{1}+A_{1}\cap A_{1}\right)\cap A_{i_{1}}

is
IP
.
Now choose
y_{2}\in D_{1}^{\star}
and define
C_{2}=y_{2}^{-1}\left(-y_{2}+D_{1}\cap D_{1}\right).
Then choose
i_{2}\in\{1,2,\ldots,r\}
such that
D_{2}=C_{2}\cap A_{i_{2}}
is
IP
. Proceeding inductively, we define for each
n\in\mathbb{N},

1.

choose
y_{n}\in D_{n-1}^{\star},
and

2.

the set
D_{n}=y_{n}^{-1}\left(-y_{n}+D_{n-1}\cap D_{n-1}\right)\cap A_{i_{n}}
is an
IP
set.

Now from the Pigeonhole principle, there exists
k\in\{1,2,\ldots,r\}
such that
A_{i_{j}}=A_{i_{n}}=A_{k}
for some
j<n.
Now choose
x\in D_{n}\subseteq A_{i_{n}}=A_{k}.

Clearly from
(2),

xy_{n}\in D_{n-1}\subseteq y_{n-1}^{-1}D_{n-2}\subseteq\cdots\subseteq y_{n-1}^{-1}\cdots y_{j+1}^{-1}D_{j}.

Hence

xy_{n}\cdots y_{j+1}\in D_{j}\subseteq A_{i_{j}}=A_{k}.

Again
y_{n}\in D_{n-1},
and so from the above argument

y_{n}\cdots y_{j+1}\in D_{j}\subseteq A_{i_{j}}=A_{k}.

Again note that
xy_{n}+y_{n}\in D_{n-1},
and so from the above argument

(xy_{n}+y_{n})y_{n-1}\cdots y_{j+1}\in D_{j}\subseteq A_{i_{j}}.

Define

1.

a=x;
and

2.

b=y_{n}\cdots y_{j+1}.

Then
a,b\in A_{k},
and

xy_{n}\cdots y_{j+1}=ab\in A_{k}.

And

(xy_{n}+y_{n})y_{n-1}\cdots y_{j+1}\in D_{j}=(a+1)b\in A_{k}.

Hence
\{a,b,ab,(a+1)b\}\subset A_{k}.

This completes the proof.

∎
