UICE-MIRNet guided image enhancement for underwater object detection
Authors: Pratima Sarkar, Sourav De, Sandeep Gurung, Prasenjit Dey
Published: 2024

ABSTRACT
AbstractUnderwater object detection is a crucial aspect of monitoring the aquaculture resources to preserve the marine ecosystem. In most cases, Low-light and scattered lighting conditions create challenges for computer vision-based underwater object detection. To address these issues, low-colorfulness and low-light image enhancement techniques are explored. This work proposes an underwater image enhancement technique called Underwater Image Colorfulness Enhancement MIRNet (UICE-MIRNet) to increase the visibility of small, multiple, dense objects followed by underwater object detection using YOLOv4. UICE-MIRNet is a specialized version of classical MIRNet, which handles random increments of brightness features to address the visibility problem. The proposed UICE-MIRNET restrict brightness and also works on the improvement of the colourfulness of underwater images. UICE-MIRNet consists of an Underwater Image-Colorfulness Enhancement Block (UI-CEB). This block enables the extraction of low-colourful areas from underwater images and performs colour correction without affecting contextual information. The primary characteristics of UICE-MIRNet are the extraction of multiple features using a convolutional stream, feature fusion to facilitate the flow of information, preservation of contextual information by discarding irrelevant features and increasing colourfulness through proper feature selection. Enhanced images are then trained using the YOLOv4 object detection model. The performance of the proposed UICE-MIRNet method is quantitatively evaluated using standard metrics such as UIQM, UCIQE, entropy, and PSNR. The proposed work is compared with many existing image enhancement and restoration techniques. Also, the performance of object detection is assessed using precision, recall, and mAP. Extensive experiments are conducted on two standard datasets, Brackish and Trash-ICRA19, to demonstrate the performance of the proposed work compared to existing methods. The results show that the proposed model outperforms many state-of-the-art techniques.Keywords: Computer Vision, Deep Neural Network, MIRNet, Object Detection, Underwater Image Enhancement, YOLOv4Subject terms: Ocean sciences, Engineering

Introduction

The growing scarcity of marine resources and the growth of the world economy make marine environment exploration very popular1. Intelligent underwater vehicles are used to classify and locate underwater objects for various activities. Image-dependent object detection became popular in recent years in the area of underwater computer vision. Underwater object detection is different from typical computer vision-related research. It has some unique challenges, like poor resolution images, dense or small object detection, and lower computation power for the vehicles etc. Even though deep learning based techniques are achieving great success in the area of object detection on land images but underwater object detection using deep learning techniques is one of the challenging tasks due to unclear images2. So, image enhancement is one of the important task before object detection.

Colour correction and contrast enhancement are two basic components of image enhancement for underwater images. Colour correction algorithms have included the white balance method, grey world assumption3 etc. These techniques calculate the illuminance of images and then based on that improves colorfulness of images. Histogram equalization, fusion-based techniques4 are popular techniques for contrast enhancement. Existing state-of-the-arts have adopted different techniques like image background subtraction algorithm, colour reimbursement histogram, equalization saturation, illumination intensity stretching, and bilateral filtering method to deal with the issues of image enhancement. These types of transform domain image enhancement techniques perform well with smearing noise but not well in case of low contrast, detail loss, and colour deviation images5. In recent years, Convolutional Neural Networks (CNNs) based image enhancement techniques have also gained success in image enhancement and restoration. CNN-based algorithm take a set of input images to generate feature maps and uses those feature maps for image enhancement. Even though some CNN-based image enhancement techniques work well on land images, those algorithms are not suitable for underwater images6. According to current state-of-the-arts, the key difficulty while dealing with underwater image enhancement is the balancing between contrast, resolution, and colorfulness of images, which is determined to be a significant problem4. The findings acquired by these technologies need to be revised for underwater images as visibility of underwater images are very low.

Object detection models are primarily dependent on deep neural networks and these are mainly categorized into two parts, i.e. two-stage object detector and single-stage object detector. Single-stage object detectors works faster than two-stage object detectors7. Two-stage object detectors take longer to detect objects than single-stage object detectors. The region proposal stage is skipped by single-stage object detection models, which conduct detection immediately over object localization. Object localization produces a score for concerning the presence of objects. After determining the scores, intersection over union is used to select the perfect score. Additionally, the network generates multi-resolution many feature maps to deal with detection of objects of different sizes. A high-end model like Faster Region based Convolution Neural Network (R-CNN) first generates so-called region proposals for areas of the image that potentially contain an object. Then it makes a separate prediction for each region8. The two-stage detectors are slower since they first create bounding boxes for every object before classifying those objects during the second scanning. Elimination of region proposal is the fundamental cause of speed improvement in single-stage object detectors. In this work our objective is to propose a single stage object detection model, which is fast as well as generates efficient classification performance as compared to other single-stage object detectors.

The existing underwater object detection model lack in small and dense object detection7 as well as take long training time9. Moreover, the similarity between the colours of the backgrounds and the colours of the creatures can seriously impede recognition10. The work focuses on increasing the visibility of images prior to object detection, which aids in small item detection and cuts down on overall training time, in order to overcome these issues. The proposed methodology is segregated into two parts, viz. underwater image enhancement and underwater object detection. To improve the visibility of images, the proposed work modified the existing MIRNet-based image enhancement technique and named it UICE-MIRNet that is suitable for underwater image enhancement. The primary motivation behind selecting MIRNet6 is that it got good results during enhancement of low-resolution images. Existing popular object detection techniques are Single shot multibox detector(SSD)11, Tiny YOLO12, YOLOv213, YOLOv314, YOLOv415, and YOLOv516 etc. Out of all these techniques, proposed work used YOLOv4 for object detection as it keeps a proper balance between detection speed and accuracy17. Two well-known datasets named Brackish18 and Trash-ICRA1919 are applied to show the supremacy of the proposed model over the existing models. The experimental results have shown that the proposed model outperformed state-of-the-art models with respect to both image enhancement and object detection.

Literature review

In this section, a review is performed on image enhancement, image restoration and object detection. This work includes extensive survey on image enhancement techniques, followed by a study on object detection techniques.

Image enhancement and restoration techniques

Image enhancement focus on enhancing contrast, sharpness, and colorfulness. The popular image enhancement techniques are based on fuzzy logic20,21, evolutionary model22, and CNN-based approaches6. Several prominent image enhancement techniques include Contrast Limited Adaptive Histogram Equalization (CLAHE)23, Histogram Equalization (HE), Integrated Colour Model (ICM)24 and Relative Global Histogram Stretching (RGHS)25. HE based techniques are mostly used for contrast enhancement in an image. HE mostly over amplifies noise by increasing contrast. CLAHE solves the issue of excessively increasing the difference in brightness between areas of a image that have similar levels of brightness, preventing the amplification of unwanted visual disturbances. The ICM employed a dual strategy centered around slide stretching. Intensity stretching of Hue, Saturation, and Intensity (HSI) is utilized in ICM to enhance the genuine colour while, contrast stretching is employed to balance the colour contrast and saturation. In order to correct the global image, Rayleigh stretch restricted contrast adaptive histogram equalization was utilized by Smith et al26. The improvement of underwater images can be achieved through techniques such as color balance and fusion-based image enhancement. Color balance is used to correct the underwater image, while fusion techniques are commonly used for white balance and contrast enhancement. Some popular techniques for underwater image enhancement include the adaptive color perception balance and multi-scale weighted fusion technique27,28, multi-scale fusion technique4, and color-guided adaptive feature fusion technique29.

Image restoration mainly focus on reducing effect of underwater environment like light attenuation and light scattering on images. This is an objective approach which formulate mathematical model to restore images. Some of the popular image restoration techniques Dark Channel Prior (DCP)30, Removal of Water Scattering (RoWS)31, Maximum Intensity Prior (MIP)32, Image Restoration Based on Image Blurriness and Light Absorption (IBLA)33, Underwater Dark Channel Prior (UDCP)34 and Underwater Light Attenuation Prior (ULAP)35 etc. In DCP red channel compensation method is used to provide colour correction and improve visibility. The DCP algorithm utilizes blue-green channel dehazing and red channel correction. RoWS is a dark channel prior image restoration technique. RoWS uses local patches of water to detect depth of turbid water after that it removes effect of turbid water in images. MIP works on attenuation of lights, it calculates strong attenuation difference for underwater images and estimate depth of image scene to restore images. To restore images IBLA also calculates depth of underwater scene by measuring blurriness and light absorption. Whereas UDCP is developed a physical model that considers the primary factors contributing to image deterioration, including absorption, scattering, and back-scattering of light. This technique uses statistical priors to enhance the visual quality of images captured in common underwater situations. Another image restoration technique, ULAP employs learning-based supervised linear regression to train the model coefficients.

Learning-based approach are also used for image denoising. DnCNN model36 is a deep learning based approach, proposed to handle Gaussian noise at different level. This work uses neural network to clean images using hidden layers. With it to speed up training and improve denoising performance, batch normalization and residual learning are combined. Another approach to recover resolution by filling up with correct values using compressed sensing techniques37. Fuzzy logic has great importance in the selection of filters and it also works well with removing impulse noise, preserving edges and salient structure38 but not suitable for low resolution images. Peng et al39 proposed an image enhancement technique for sandstorm, underwater and hazy images. They used depth dependent colour change to estimate ambient light. Then used the difference between observed intensity and ambient light for colour correction. This colour correction is used for the generation image formation model which removes colour cast during contrast enhancement. It is difficult to obtain high-quality ground truth, which is the major difficulty with deep learning-based image enhancement approaches. In order to improve degraded regions, this approach first determined what the ideal ground truth should be based on previous approaches40. Some of the work used generator and discriminator based model as FUnIE-GAN network41 for image enhancement. Another most popular Generative Adversarial Network(GAN) based approach is Sea-Pix-GAN42 which transferred color, content, and style by using generators. Generator consists of encoder, decoder and L1 loss function to transfer style. Like Sea-Pix-GAN, URD-UIE43 algorithm separates the content information and style information from underwater images. It uses separated information to create a distortion-free image that matches the desired goal. It incorporates various loss functions to enforce specific restrictions on the output results of each module. This ensures the structural consistency of underwater images before and after enhancement. PU-GAN44 is a Generative Adversarial Network that is directed by a physical model. Firstly, authors developed a Parameters Estimation subnetwork to acquire the parameters needed for physical model inversion. Then, utilizes the resulting color enhancement image as supplementary data for TSIE-subnet. Shuaixin Liu et al45 introduced an approach aims to address the issues of catastrophic forgetting and mode collapse during image enhancement. The image-to-image diffusion model and the CLIP-Classifier mostly operate in regions with high frequencies. Hence, the authors have suggested a novel fine-tuning approach that exclusively targets high-frequency regions, resulting in a substantial enhancement in the speed of fine-tuning, with improvements of up to 10-fold. UWFormer,46 a Multi-Scale Transformer based Network designed to improve images at various frequencies using semi-supervised learning. The paper introduces a Nonlinear Frequency-aware Attention mechanism and a Multi-Scale Fusion Feed-forward Network specifically for enhancing low-frequency details.

The main goal of this work is to address the limitation found in conventional image enhancement and learning-based systems by utilizing the flexibility of MIRNet.

Object detection techniques

CNN based approaches are more popular in the area of object detection. CNN-based detection techniques consist of two components, i.e. backbone and head13. The popularly used techniques for two-stage object detectors are RCNN47, fast RCNN8, faster RCNN48, and R-FCN49. Two-stage detector scans the entire image twice for object detection. First, it identifies all anchor boxes on the first scan and then labels the boxes or classifies the objects. However, the main disadvantage of two-stage detectors is that they are not suitable for real-time applications. Another type of object detection is a single-stage detector in which the entire image is scanned once. During scanning, finds anchor box also identifying the class of different objects. The popular models for single-stage detectors are SSD11 and different YOLO versions14,15,50. These techniques are faster than two-stage detectors. These detectors include one or more layers between the backbone and head, is called neck. The neck is used for feature collection or aggregation purposes. Some of the popularly known single-stage anchor box-free networks are Path Aggregation Networks (PAN)51, Spatial Pyramid Pooling (SPP)52, Feature Pyramid Networks (FPN)53, Bidirectional Feature Pyramid Networks (BiFPN)54 etc. Out of different existing single-stage object detectors, YOLOv4 does proper balance between speed and mAP during object detection. YOLOv415 uses the SPP as a neck for feature collection. Zhang et al16 proposed a modified model of YOLOv5 for detection of marine organisms namely Real-Time Models for Object Detection (RTMDet)’s. The Cross-Stage Partial Layer (CSPLayer) module was then added, allowing the detection network to accurately and completely gather contextual data. A common convolution layer is additionally added to the stem layer in order to efficiently extract additional relevant data from the images. The performance of the detection network and dense target detection are then improved by the addition of the BoT3 module with the multi-head self-attention mechanism to the YOLOv5 neck module. The YOLOv5 is light weight model but lacking in achieving good mAP. KPE-YOLOv555 proposed a technique to detect small objects from drone captured images. KPE-YOLOv5 used K-means++ for anchor box size detection and added attention block to YOLOv5 which helps in improving small object detection rate. Another modified version of YOLOv5 is UTD-YOLOv556. The task include an alternate anchor box similarity calculation method, adding the visual channel attention mechanism module, and replacing the original backbone with a two-stage cascaded CSP (CSP2). To make lightweight object detection model, YOLOv757 proposed bag-of-freebies technique. The bag-of-freebies strategy is a collection of techniques used to raise the overall accuracy of a machine learning model during training while keeping the inference cost relatively low, it is also used in YOLOv4.

The quality of underwater images and the recognition of small and dense objects are the key problems when addressing underwater object detection. Another challenge of underwater object detectors are balancing between speed and mAP. From the existing literature it has been observed that, all the higher versions55,57 are lightweight architecture but lacks in achieving good mAP. When the YOLOv5 model was modified and improved, some versions resulted in a significant computational cost16. Additionally, it has been found that some approaches do not effectively detect big objects55.

Proposed methodology

Objective of the proposed work is to detect underwater objects from blurry, not-so-clear underwater images. To improve the detection of these objects, enhancing the quality underwater images is an essential step and main contribution of this articles. For this purpose, Underwater Image colorfulness Enhancement Network (UICE-MIRNet) is proposed in this article to enhance the quality of the images. The proposed UICE-MIRNet is an network inspired by MIRNet6, which enhances the underwater images quite efficiently. MIRNet has existing Multi scale-Resolution Block (MRB) which is dedicated to attention and fusion techniques. However, the MRB is not capable of balancing between contrast and brightness. Sometimes, it increases resolution so high which is the cause of losing visibility of objects. The enhanced version of MIRNet i.e. UICE-MIRNet is capable of generating high-resolution with balanced brightness and enhanced colorfulness enhanced images. After enhancing the underwater images, object detection is performed. The well-known architecture, YOLOv4 is selected for the detection of objects from underwater images. The main motivation behind selecting YOLOv4 is that it gives better mAP with optimal speed. Thus, the entire work is mainly divided into two phases image enhancement and object detection. In Section 3.1, the detail of the proposed UICE-MIRNet is discussed and the underwater object detection using YOLOv4 is illustrated in Section 3.2.

Underwater image colorfulness enhancement MIRNet (UICE-MIRNet)

UICE-MIRNet is a learning-enriched, convolutional neural network-based architecture. It is a low-light image enhancement technique that improves the resolution and colorfulness of the images by limiting over-brightness. The CNN learns in such a way that it preserves contextual information and high-resolution spatial details of image. Recursive Residual Block(RRB) is the main component of UICE-MIRNet. Further, multiple UI-CEBs are the fundamental component of RRB. It has some unique properties, viz. (a) neurons’ receptive fields are not fixed, (b) the size of the image does not matters during training (c) low-colorfulness images can be converted into high-colorfulness images.

The basic architecture of UICE-MIRNet is depicted in Figure 1. As shown in Figure 1, the input image (I) is first applied to the convolution layer and extracts low-level features X0 where, X0∈RW×H×3. The low-level feature X0 passes through three RRB blocks and gives output as X3. Each RRB consists of two UI-CEB blocks. UI-CEB is used for retrieving highly contextual information from low-resolution images. The main component of UI-CEB is Feature Selection and Fusion Block (FSFB) and Spatial Channel Attention Block (SCAB) as shown in Figure 2. FSFB exchanges information between all the components of FSFB and consolidates high-resolution information. It also adjusts the receptive field dynamically using two operations, fuse and select. Where as, SCAB is used for suppressing less helpful information and passing more useful information through the network. Underwater image-colorfulness enhancement block (UI-CEB)

The primary branch of UI-CEB is intended to preserve spatially accurate high-resolution and maintaining colorfulness representations throughout the network, and the complementary set of parallel branches offer better contextualized information. UI-CEB is used to identify low-colourful areas from underwater images then enhance colorfulness and reduce bluish or greenish colour tint of those areas. The UI-CEB is a modification of MRB of MIRNet. In the MIRNet, the actual colour of the images is lost due to the highly increased brightness of the images. So we have re-configured MRB as shown in Figure 2. UI-CEB consists of four layers and each one of them communicates using fully convolution stream. In this work, input image I is passing through down-sampling operations and generating three feature matrices i. e., L1, L2, and L3. After that, one input image and three feature matrices pass through SCAB, FSFB and up-sampling functions as shown in Figure 2. Then generated four feature matrices and they are concatenated using FSFB. Finally, feature matrix again passes through the convolution layer with kernel size 1×1, which is used by the RRB.

This module adaptively performs feature fusion using CNN which later helps in better flow of information. It is a nonlinear procedure of feature fusion. Results and discussions

In this section, the experimental results are reported and shown that the proposed work outperformed the other existing state-of-the-art models. The results are exhibited in two stages first the proposed UICE-MIRNet is applied to enhance the images and second the detection is done using the YOLOv4 network. Trash-ICRA1919 and Brackish underwater dataset18 are used to perform the experiment on underwater images. Qualitative and quantitative analysis have been done on proposed image enhancement technique. Quantitative analysis and ablation experiments on enhanced images are performed by using UIQM, UCIQE, entropy and PSNR.

Ablation experiments are illustrated in Table 3 and when base model is combined with UI-CEB + FSFB instead of MRB, achieved 30%, 13%, 9% and 8% improvement in UIQM, UCIQE, entropy and PSNR respectively for Brackish dataset whereas for Trash-ICRA19 dataset found 20% improvement in UIQM , 33% improvement in UCIQE and 4% improvement in entropy, PSNR both. The main reason behind introducing UI-CEB module is that it carry out effective communication between each FSFB modules and identifies low colorfulness areas whereas FSFB perform feature fusion and feature section by using softmax activation function which helps to improve performance. SCAB module recalibrate features by sharing information between channel and spatial attention block. This block also improve feature selection by discarding irrelevant features and it is introduced in existing module to make proposed UICE-MIRNet more accurate. After adding SCAB proposed work achieved 10%, 5%, 0.5%, 0.3% increase in UIQM, UCIQE, entropy and PSNR respectively for Brackish dataset, similarly 5% increase in UIQM and UCIQE both, 0.4% increase in entropy and 7% increase in PSNR for Trash-ICRA19 dataset.

Conclusion

This research offered a technique for object detection from underwater images based on image enhancement. Due to the low image resolution and low colorfulness, as well as the fact that underwater objects are frequently small, dense, obstructed, and hidden, underwater object detection is a difficult process. As underwater object detection plays a vital role in underwater object detection, a new image enhancement technique named UICE-MIRNet is applied to improve the quality of the underwater images. UICE-MIRNet is a deep learning-based underwater image enhancement technique that helps to improve image colorfulness without losing contextual information. UI-CEB block is introduced in UICE-MIRNet which make a proper balance between contrast and resolution. The proposed work is tested on Brackish and Trash-ICRA19 datasets. The research results of UICE-MIRNet derived from datasets clearly suggest that the produced images accurately depict the target data. In both the cases average UIQM, UCIQE, entropy and PSNR values increased by more than 5% in both the datsets for most of the cases. After enhancing the underwater images, the underwater objects are detected with the help of the well-known YOLOv4 algorithm. YOLOv4 is applied to the enhanced dataset and calculated performance metrics like precision, recall, F1-score and mAP. The proposed work achieved overall 5%-10% improvement on mAP than existing work. Lack of labelled data is an major issue while working with underwater dataset. So in future, semi-supervised learning technique can be incorporated during object detection.
