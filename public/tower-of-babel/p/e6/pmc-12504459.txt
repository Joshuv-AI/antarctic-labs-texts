Recommendation of deep reinforcement learning based on value function considering error reduction
Authors: JinLian Zhou, DeRong Shen, Ying Guo, Yan Wu, JianHua Ma
Published: 2025

ABSTRACT
AbstractDeep reinforcement learning (DRL) algorithms have been widely applied in user cold-start recommender systems because they can gradually capture users’ dynamic interest preferences. Deep Q-Networks (DQN) have become the most popular reinforcement learning (RL) method due to their simple update strategy and excellent performance. In many user cold-start scenarios, the action space is gradually reduced to avoid recommending duplicate items to users. However, current DQN-based RL recommender systems output the entire action space fixedly, inevitably leading to discrepancies with the gradually shrinking action space. This paper demonstrates that such discrepancies cause a decrement error in the action space corresponding to the temporal difference (TD) in the original RL, rendering standard DQN reinforcement learning methods inaccurate in Q-value estimation. Moreover, in long-term recommendation scenarios, the differences in the lengths of interactions recommended to different users are significant, making it difficult to ignore such errors, thereby challenging the applicability of these methods in scenarios where the action space gradually reduces. To address this issue, this paper introduces a new algorithm called Q-AD (Q-learning Action Decrease), which is based on DQN and aims to mitigate the reduction error in the action space by buffering the Q-value estimation error at each update. Q-AD augments the standard DQN with an error reduction term for TD updates. Through experiments, it was observed that the Q-AD algorithm significantly reduces value estimation errors and achieves better accuracy and efficiency compared to previous methods across different datasets.Keywords: Knowledge graph, Reinforcement learning, Proximal policy optimization, Recommendation systemSubject terms: Computer science, Information technology

Introduction

Personalized recommender systems play a crucial role in helping people navigate through the vast array of online products. Essentially, the interaction between recommender systems and users is a continuous process1. This process demands that recommender systems continuously adapt to users’ changing interests and maximize user satisfaction with recommended products from a long-term perspective (long-term reward). However, current supervised learning-based personalized recommender systems focus primarily on maximizing user satisfaction with immediate recommendations, completely overlooking the role of these products in long-term recommendation scenarios. Therefore, traditional supervised learning-based recommender systems cannot guarantee the maximization of long-term rewards in the recommendation process2. Additionally, supervised-based recommender systems struggle to address the user cold-start problem, where recommendations are made without any interaction information from users. Recently, the inherent capability of reinforcement learning (RL) to maximize long-term rewards has led to significant applications and breakthroughs in personalized recommender systems3.

In RL-based recommender systems, the continuous interaction between the recommender system (agent) and the user (environment) is formulated as a Markov Decision Process (MDP). The goal of RL-based recommender systems is to maximize the long-term reward for users in the recommendation process based on user feedback on recommended items. Specifically, at each time step t, the RL-based recommender system recommends an item based on the current user state s (the recommended item is also referred to as an action) and receives feedback (reward) from the user regarding this recommended item. Based on the user’s feedback on the item, the user’s state is updated to +1, and the recommender system subsequently recommends the next item based on the new state. This RL-based recommender system can adaptively build user interest preferences based on the recommendation process, making it highly suitable for user cold-start scenarios4.

Despite the significant success achieved by RL-based recommender systems, they still face a major challenge: the gradual reduction of the action space. Typically, in practical recommendation scenarios, recommender systems avoid recommending duplicate items to the same user to ensure user trust and continuous system usage5. For example, in news recommendation systems, the system does not recommend duplicate news to users to prevent them from losing interest and abandoning the recommendation service. Similarly, the same game is not recommended to the same user repeatedly on a gaming platform to avoid redundant purchases. Therefore, many recommender systems based on user cold-start settings incorporate a gradually decreasing optional action space. Consequently, as the recommendation proceeds, the set of optional actions for the user gradually decreases6.

Among numerous RL algorithms, Deep Q-Networks (DQN) are the most widely recommended value-based algorithms for recommender systems. The basic idea of DQN is to estimate the Q-value function using Temporal Difference (TD) updates, where the value function estimation is updated using estimations of subsequent state-action values. Unfortunately, current DQN algorithms are designed to handle fixed action spaces, meaning that there is a complete set of optional actions in any state, such as in robot control scenarios7. Specifically, DQN represents the Q-value function parametrically using neural network parameters (where represents the parameters of the Q-network), with states as inputs and Q-values for the entire action space as outputs. This paper discovers that the standard DQN algorithm fails to train in recommendation systems with decreasing action spaces. This failure is due to the discrepancy between the fixed action space output in the Q-value network and the decreasing action space in recommendation scenarios. This paper theoretically reveals that this discrepancy introduces estimation errors in the TD updates, termed action decrement errors. These errors make it difficult to directly eliminate estimation errors in Q-value estimation and lead to error accumulation with TD updates. Therefore, traditional DQN algorithms fail to learn accurate Q-value estimations, ultimately resulting in suboptimal policies8.

Recent citations suggest that reducing estimation errors in each TD update can effectively mitigate error accumulation. Inspired by this, this paper, under some mild assumptions, derives modified TD update formulas by reducing estimation errors in each TD update. Based on this conclusion, this paper proposes a new error-reducing DQN algorithm, Q-AD (Q-learning Action Decrease), to address Q-value estimation errors caused by decreasing action spaces. Specifically, the Q-AD algorithm augments the standard DQN algorithm with an error reduction term for TD updates. In particular, in this paper, DQ-AD represents an extension of the Double DQN (DDQN) algorithm with an error reduction term for TD updates. DDQN reduces overestimation of high values in the DQN algorithm by decomposing the target maximum action operation in TD updates into action selection and action evaluation. The Q-AD algorithm proposed in this paper effectively mitigates the shortcomings of the original DQN algorithm in environments with decreasing action spaces9.

To sum up, our contributions in this paper are as follows:

Theoretical proof that reduction of the action space introduces estimation errors in standard TD updates. Experiments also confirm that these errors result in overestimation of Q-values, leading to suboptimal policies in the original DQN algorithm.

Extensive experimental evaluations demonstrate that the proposed error-reduction strategy effectively mitigates user cold-start recommendation challenges in standard DQN models across four real-world datasets. Additionally, experiments show that the proposed Q-AD algorithm not only produces more accurate value estimates but also generates better-performing policies. Furthermore, this paper’s experiments reveal the relationship between Q-value estimation variance and learned policies.

Related work

In modern recommendation systems, researchers are constantly exploring new technologies and methods to improve the accuracy and user satisfaction of recommendations. With the development of big data and artificial intelligence (AI) technologies, knowledge graphs, as structured semantic knowledge bases, have attracted widespread attention for their ability to capture and represent relationships between entities. The application of knowledge graphs in recommendation systems mainly involves mining various connections between users and items to provide richer and more personalized recommendations. Therefore, among the many recommendation system methods, those based on knowledge graphs stand out for their ability to leverage additional structured information. Specifically, path-based application of knowledge graphs focuses on the associative paths between users and between users and items, and makes inferences on the knowledge graph based on these paths to predict the matching degree between users and items. Compared with traditional vector-based representation methods, these methods offer better interpretability.

The path-based application of knowledge graphs in recommendation systems primarily aims to uncover various relationships between users and items by leveraging the graph structure10. The additional information in the knowledge graph can also be obtained by analyzing the paths between nodes11. The path-based method focuses on considering the associative paths between users and between users and items, and makes inference on the knowledge graph based on paths to predict the matching degree between users and items12,13. Capturing user preference paths and designing path propagation and mining methods to represent user preferences are key aspects of applying knowledge graph-based techniques in recommendation systems. Compared to vector representation-based methods, these approaches offer better interpretability. Some researchers mine user-centered neighborhood information to provide personalized recommendations. The proposed RippleNet first takes an item clicked by a user as the “seed node” of the network, and then takes the seed node as the triplet of the head entity to form the first ring “ripple set”, in which the tail entity is the “ripple entity” of the first ring14. Some researchers use a path-based approach to introduce knowledge graph information15,16. Different from traditional recommendation tasks, it takes into account the time of historical user interaction data when constructing paths at each time node to avoid information leakage. Self-attention network is used to model user interaction data sequence for prediction17. M et al. proposed a neural network recommendation system based on rule induction and rule guidance, which generalizes common multi-hop relationship patterns based on the item-related knowledge graph, deduces new associations between different items, and can propose an easily understood and interpretable recommendation system18. Some researchers propose a policy-guided path reasoning (PGPR) method, which turns the recommendation problem into a problem of finding a path with the user as the starting point and the item as the end point in knowledge graph, and then provides recommendation reasons accordingly19.

Reinforcement learning is an adaptive method based on an exploration-interaction generation strategy, and its strong exploration is suitable for the search process of a recommendation system. Google’s research on applying RL to YouTube recommendations gives industry hope. In terms of search result ranking, Ali proposed a ranking strategy that maximizes the expected cumulative reward by using reinforcement learning based on considering the association of non-synchronous ranking results. On this basis, the author proves that there is a close relationship between the ordering of different steps, rather than being independent of each other, by demonstrating the necessity of maximizing the cumulative return22. Microsoft Research Asia and the University of Pennsylvania have proposed a recommendation framework based on deep reinforcement learning (DRL) for personalized news recommendations. This recommendation model not only considers users’ feedback on current recommendations, but also considers the long-term impact of recommendations on users23. Since news is time-sensitive and users’ interest in news will change over time, researchers use DQN to model the dynamic change of news recommendations and users’ expected rewards in the future. Zhao modeled the serialized interaction behavior between users and the recommendation system as an MDP, built a recommendation system with automatic feature extraction and strategy trial-and-error optimization by using DRL technology, and pre-trained the parameters of the model by using simulators before it was put into use27. The accuracy of the recommendation is improved.

The authors proposed MSRec, a multi-view self-supervised learning framework for heterogeneous graph neural networks (HGNNs) to improve recommendation performance28. The method uses a maximum entropy path sampler to extract meta-paths with structural context and applies both local- and global-view contrastive learning to fully leverage unlabeled information for node embeddings. The authors in29 introduced KMDCL, a mask diffusion-based contrastive learning method for knowledge-aware recommendation. Their approach uses a diffusion model with locally masked input to generate knowledge views from both global and local perspectives, helping the model generalize better across different data distributions while reducing knowledge noise. They also designed a conditional inference process guided by user intentions and a collaborative knowledge diffusion loss to better match generated data with user behavior. The authors proposed a feature-decorrelation adaptive contrastive learning method for knowledge-aware recommendations30. The approach addresses two major issues in GNN-based KG models: feature loss from iterative aggregation and noise from irrelevant high-order knowledge. It introduces a feature-decorrelation constraint to improve representation quality, an adaptive knowledge refinement module to extract meaningful high-order semantics, and a contrastive learning strategy to focus on relevant recommendation topics. The authors introduced DiffuFair, a fairness-aware recommendation framework that leverages the dynamic equilibrium of diffusion models31. It tackles two major issues in existing debiasing methods: the loss of semantic information from explicit feature removal and semantic distortion caused by adversarial conflicts. Additional mechanisms, such as interest fusion and bias-controlled rounding, further balance fairness and utility.

In research article32 proposed MeLU, a method designed to tackle the cold-start problem in recommender systems. MeLU leverages meta-learning to quickly adapt to new users by learning an initial user preference model from a small amount of interaction data. The authors demonstrate that by using meta-learning, MeLU can effectively estimate user preferences even in the absence of extensive historical data, improving recommendation accuracy for new users. Through experiments, they show that MeLU outperforms traditional collaborative filtering techniques. The authors of33 introduced TCKT, a novel method aimed at addressing the cold-start problem in POI recommendation systems. TCKT leverages cross-domain knowledge transfer by utilizing decision trees to model and transfer knowledge between different domains, helping to recommend POIs for new users with limited interaction history. Through extensive experiments, the authors demonstrate that TCKT significantly outperforms existing methods. Article34 proposed a novel approach based on Large Language Model Simulator (LLMS) for addressing the cold-start problem in recommender systems. LLMS uses large language models to simulate user preferences by leveraging textual data, allowing the system to make accurate recommendations for new users with limited interaction history. The model captures user intent and preferences by analyzing available textual information, such as product descriptions or user reviews, and then infers recommendations based on this simulated data.

Knowledge graphs are valuable in recommendation systems for representing complex relationships between users, items, and contextual factors, improving recommendation accuracy, especially in sparse data scenarios. While they offer static insights into user-item associations, RL is more effective in dynamic settings where the action space shrinks over time, as it learns from user feedback and adapts to evolving preferences. Combining these approaches can leverage the strengths of both: knowledge graphs can guide RL exploration by providing context, while RL can handle the dynamic nature of action spaces. In our work, we explore the differences between these methods and suggest that integrating them could offer a more robust solution for dynamic recommendation systems.

In this section, we propose a Markov Decision Process (MDP)-based long-term recommendation model based on action space reduction. The MDP is built upon the setting of top-k recommendations, as the top-k setting is widely used in practical recommendation scenarios. The recommendation process is modeled as a continuous decision-making process, where the system recommends a top-k list of items to the user at each step. To simulate and simplify the interaction between the actual recommender system and users, two principles of user behavior in long-term top-k recommendation scenarios are provided:

(1) Top-k Action Selection Principle: The top-k recommended item list at each time step t is obtained based on the top-k actions corresponding to the maximum values. Each user can select at most one item from a top-k recommendation list as a positive item. If no item is selected by the user, then the item corresponding to the maximum value is considered a negative sample.

Discussion of assumption on Q-values of available actions

In this paper, we assume that the Q-values of available actions are higher than those of unavailable actions, particularly in the context of the dynamic action space in recommendation systems. While this assumption is commonly made in reinforcement learning algorithms, we recognize that it may not always hold true in real-world scenarios. In particular, the dynamics of user preferences and interactions in recommendation systems can lead to situations where unavailable actions may have higher Q-values due to factors such as initial biases or the exploration-exploitation trade-off. We acknowledge that this assumption introduces a level of idealization that may not fully capture the complexity of real-world recommendation environments. Specifically, as users interact with the system over time, the Q-values of available actions may fluctuate based on user feedback, the evolution of user preferences, and the decreasing action space. This variability could challenge the assumption that the Q-values of available actions are consistently higher, especially in cases where the system’s exploration phase leads to suboptimal or counterintuitive action selections. To address these potential limitations, future work could focus on empirically validating this assumption by examining real-world recommendation scenarios. For instance, researchers could conduct experiments to compare the Q-values of available and unavailable actions in dynamic environments, considering factors such as user demographics, item diversity, and contextual factors. Additionally, it would be valuable to explore alternative methods that relax this assumption, such as using exploration strategies that account for action uncertainties or incorporating a more nuanced model of user preferences that better reflects the inherent variability in Q-value estimates.

In summary, while the assumption that Q-values of available actions are higher than those of unavailable actions serves as a useful simplification in this study, we recognize that its applicability in real-world dynamic recommendation environments requires further investigation. We hope that this discussion opens avenues for future research to explore more robust approaches to handle the complexities of evolving action spaces in recommendation systems.

Limitations of this assumption

We recognize that Assumption 2, which sets the immediate reward for unsampled actions to zero, is a simplification. In real-world recommendation systems, unsampled actions may still have value, especially for items that could become relevant in future interactions. By assuming that unsampled actions are irrelevant, we overlook the potential long-term relevance of these items, which could depend on changing user preferences or contextual factors. Future work should explore more nuanced approaches, such as using historical data, contextual information, or adaptive methods to better estimate the rewards for unsampled actions, rather than assuming they are always zero. This would provide a more realistic and dynamic way of modeling user interactions and improving recommendation accuracy.

Action-decreasing error reduction algorithm(Q-AD)

In the previous section, it is demonstrated that the original Q-value-based policy update algorithm would induce estimation errors in the case of a decreasing action space. Previous studies have shown that any type of estimation error in reinforcement learning algorithms combined with maximum Q-value selection (i.e., Q-learning) will lead to sustained overestimation bias. Using such inaccurate TD update formulas, the value function based on Q-values is unlikely to learn correct value estimates. False value estimates exacerbate the inherent function approximation error in neural networks, thereby reducing the efficiency of Q-value iteration. In cold-start recommendation scenarios, where there is little to no prior interaction history, reinforcement learning (RL) helps build and refine user preferences through a trial-and-error exploration and feedback update mechanism. Initially, the system explores a wide range of recommended items to gather early feedback, which is used to adjust the recommendation policy. As the system receives more feedback, it learns which items the user prefers, refining its understanding of user preferences using Temporal Difference (TD) updates. This continuous exploration-exploitation balance allows the system to improve its Q-value estimates and adapt dynamically to changing user interests, even without prior data. Over time, the RL system gradually provides more accurate and personalized recommendations based on user interactions.

In this study, we compare the proposed Q-AD algorithm with two baseline methods: DDPG-KNN and PG-IAM. Both of these methods address large action spaces in reinforcement learning-based recommendation systems, but they tackle the problem differently. DDPG-KNN uses an Actor-Critic architecture and transforms discrete action spaces into continuous ones, while PG-IAM adjusts the policy through continuous updates. Despite their advantages, both methods fall short when faced with dynamically shrinking action spaces, a common scenario in real-world recommendation systems. Q-AD, on the other hand, consistently outperforms these baselines by incorporating an error reduction term in the TD updates, which accounts for the shrinking action space, leading to more accurate Q-value estimations and improved recommendation performance. DDPG-KNN struggles to handle shrinking action spaces effectively. Although it reduces action space dimensionality using K-Nearest Neighbor (KNN) methods, it does not adapt to the real-time reduction of the action set. This limitation causes mismatches between the estimated Q-values and the actual available actions, leading to suboptimal performance, particularly in long-term recommendations where user preferences evolve. In contrast, Q-AD dynamically adjusts the Q-value estimates during TD updates, accounting for the reduction in available actions. This approach prevents error accumulation and ensures more stable and accurate recommendations. Similarly, while PG-IAM handles large action spaces by adjusting the policy, it struggles when the action space decreases over time, leading to inefficient exploration. Q-AD overcomes this issue by stabilizing learning and minimizing over-exploration in unavailable actions, making it better suited for long-term, dynamic recommendation tasks.

Ablation study

The ablation study evaluates the impact of key components on the performance of the Q-AD algorithm by progressively removing them. “Q-AD” represents the complete algorithm, including both the error reduction term and the action space scaling factor. “w/o ERT” refers to the algorithm without the error reduction term, allowing us to observe the effect on performance. “w/o ASF” removes the scaling factor to evaluate its contribution to the algorithm’s effectiveness. Finally, “w/o ERT+ASF” represents the algorithm without both components, highlighting how performance is affected when these key elements are excluded.

Despite the reductions, the Q-AD model still performs better than the variants in most cases, highlighting its effectiveness when both components are present.

The core principle of Q-AD, which is the error reduction in temporal difference (TD) updates, can be extended beyond DQN by adapting the algorithm to account for different value estimation strategies used in these paradigms. For example, in Policy Gradient-based methods, where the policy is directly parameterized, the Q-value update can be adjusted by scaling the reward signals based on the dynamically shrinking action space. Similarly, for Actor-Critic methods, the error reduction term can be incorporated into the value function estimation or advantage function calculation. This opens the possibility for future research to explore how the general concept of error reduction in TD updates can be integrated into these alternative paradigms, improving their ability to handle action space reduction in recommendation systems and other real-world RL applications.

Complexity analysis

In terms of computational complexity, we analyzed both the time complexity and space complexity of Q-AD. Since Q-AD builds upon DQN, the time complexity of Q-AD is similar to that of DQN, which is O(n * m), where n is the number of states and m is the number of actions. The key difference lies in the additional scaling of Q-values for available actions, which adds a constant factor related to the ratio of available actions to the total action space. The space complexity of Q-AD is also similar to DQN, i.e., O(n * m), as the primary storage requirement is for the Q-value table (or neural network weights) and experience replay buffer. The only additional space requirement in Q-AD is the storage for the action space scaling factor, which is minimal.

Conclusion

This paper demonstrates that in scenarios with a decreasing action space, DQN and DDQN algorithms generate Q estimation errors, further compromising the learned policy. Specifically, the difference between the decreasing action space and the full action space output by the Q-value network with fixed parameters is analyzed theoretically, revealing an estimation error in TD updates termed as action space decreasing error. Subsequently, based on Q-value estimates in practical recommendation scenarios, an error reduction strategy is devised for TD updates, resulting in the construction of the action-decreasing error reduction algorithm, Q-AD. Analysis of experiments indicates that the action decreasing error serves as a source of noise, causing persistent overestimation bias in Q-values within the original DQN, leading to suboptimal policies. In contrast, it is observed experimentally that the Q-AD algorithm significantly alleviates the estimation errors and achieves better accuracy and efficiency than previous methods across different datasets. Furthermore, extensive ablation experiments further validate the effectiveness of the proposed error reduction algorithm. Future work will explore the generalization of Q-AD to non-DQN architectures, such as Proximal Policy Optimization (PPO) and Soft Actor-Critic (SAC). Additionally, we aim to investigate its applicability in multi-agent reinforcement learning scenarios where action spaces dynamically shrink due to coordination constraints. The Q-AD algorithm, while effective in addressing action space reduction in DQN-based recommender systems, is primarily tested in specific recommendation scenarios, limiting its generalizability to other environments. The algorithm’s extension to non-DQN architectures like PPO and SAC requires further exploration. Additionally, the performance improvements observed in the experiments may not apply universally across all datasets, especially those with noisy or incomplete data.
