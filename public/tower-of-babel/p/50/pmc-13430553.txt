Figure 3: “Network plot showing the geometry of treatment comparisons included in the analysis. Nodes represent interventions; numbers on connecting lines indicate the number of trials directly comparing each pair.”

Figure 4: “Forest plot for BMI change showing network meta-analysis estimates versus placebo.”

Figure 5: “Forest plot for waist circumference change showing network meta-analysis estimates versus placebo.”
