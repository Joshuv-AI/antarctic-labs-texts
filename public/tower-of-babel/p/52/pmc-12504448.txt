A dynamic confrontational game model of uav’s data link in the complicated electromagnetic environment
Authors: Peiwei Gao, Yongfeng Zhi
Published: 2025

ABSTRACT
To select the optimal confrontational strategy for an unmanned aerial vehicle’s (UAV) data link in the complicated electromagnetic environment of the battlefield, based on the non-cooperative game theory, this paper builds a dynamic confrontational game model for the UAV data link. Firstly, it analyzes the confrontational game processes of the UAV data link and then designs its dynamic confrontational game algorithm. Secondly, through constructing the confrontational game matrix, it uses the equilibrium method to solve the Nash equilibrium solution of the game matrix and form the optimal confrontational game model of the data link. Finally, the simulation results verify the effectiveness of the built model, which provides a foundation for enhancing the game confrontational capability of the data link in its complicated electromagnetic environment.

Introduction

Having the strong points of low cost, high flexibility, convenient deployment, good stealth and no casualties, a UAV plays an important role in battlefield reconnaissance, intelligence collection, battlefield assessment and so on. The informatized combat with UAV’s as the confrontational main body is the trend. In order to accomplish a set task, real-time and reliable command and data transmission is needed between a UAV and its ground stations and among UAV’s. A UAV’s data link is an important means for information transmission, thus called its ‘lifeline’. A UAV faces a complicated confrontational electromagnetic environment in the battlefield, being manifested in the deterioration of the reliability and stability of the UAV data link’s information transmission, weak confrontational game capability etc., which further affect the UAV’s operational effectiveness. In recent years, attention has been paid to the application of the game theory to the confrontational game of UAV’s and other related systems, mainly to intelligent anti-jamming, UAV combat resource allocation and multi-UAV cooperative strategy and other aspects. For example, Ref1. classified the existing modeling and solving methods of autonomous air combat maneuvering decision into three categories: game theory-based methods, optimization theory-based methods and data-driven methods, and systematically sorts out and summarizes the research branches, characteristics, advantages and disadvantages of each method. Ref2. has gave a distributed optimization method based on game theory, and introduces the research status of five commonly used game models, such as matching game and evolutionary game. Ref3. introduced the most representative swarm intelligence algorithms in chronological order based on 127 research literatures. Ref4. pioneered a framework specifically designed for UAV maneuvering decisions. This approach optimized the decision-making process of UAV maneuvers through recommendation systems, enhancing the decision-making efficiency during UAV maneuvering. Ref5. proposed a random forest-eXtreme gradient boosting (RF-XGBoost) algorithm to solve the problem of multi-round game confrontation for unmanned aerial vehicles (UAV) under unbalanced air combat database, conducting research on attack-defense game decision-making. Ref6. explored the dynamic game with incomplete information for UAV swarm confrontation. Ref7. introduced a method for generating effective strategies for UAV swarms in a game-based adversarial environment, which was proposed by the Georgia Institute of Technology in the United States in 2018. Ref8. abstracted the dynamic game process between two sides of electronic countermeasures as a Markov process, introduced the Markov chain into the prediction simulation of electromagnetic behavior in electronic countermeasures, and constructed a Markov chain model-based behavior prediction simulation model for electromagnetic environment construction equipment. Ref9. analyzed and verified the discrete UAV air combat confrontational simulation model with the game theory. Ref10. put forward a cooperative countermeasure decision algorithm of UAV cluster based on dynamic non-zero-sum game, which effectively improved the cooperative countermeasure ability of UAV cluster. Ref11. introduced a UAV swarm confrontation game method based on counter-factual multi-agent policy gradients, the UAV swarms of the red and blue sides adopt different confrontation game methods. Ref12. comprehensively considered factors such as the number of UAV’s, weapon deployment and ground defense system and discussed the resource allocation and tactical synergy in the UAV ground attack. Ref13. analyzed the characteristics of game between the multi-robot patrol formation and the patrolled object and proposed a distributed dynamic cooperative method based on the game theory. Ref14. studied the UAV multi-domain joint anti-jamming intelligent decision-making algorithm, modeled the game strategy for the suppress confrontation in the channel power domain and derived the optimal interference transmission power so as to reduce the UAV overhead brought about by frequent channel switching. Few of above references studied the dynamic game model of a data link in its complicated electromagnetic environment. To select the optimal confrontational strategy for the UAV data link in the complicated electromagnetic environment, this paper builds a dynamic confrontational game model for the UAV data link and developed its optimal confrontational strategy. This paper focuses on the problem of selecting the countermeasure strategy of the UAV data link in a complex electromagnetic environment. which were verified through simulation, thus enhancing the game confrontational capability of the data link in its complicated electromagnetic environment.

Analyzing the UAV data link’s confrontational game processes

The UAV data link comprises ground-to-air data link and airborne inter-UAV link and faces complicated and dynamic electromagnetic interference in the battlefield environment. The UAV data link and the enemy electromagnetic interference are involved in the data link electromagnetic confrontational game processes, as shown in Fig. 1.

Fig. 1Schematic diagram of UAV data link’s electromagnetic interference confrontation.

Schematic diagram of UAV data link’s electromagnetic interference confrontation.

In the battlefield electromagnetic confrontational environment, the actions of the UAV data link and the enemy electromagnetic interference are not sequential. Namely when the two select their confrontational strategies, they cannot know in advance the strategy that the other will take. Only after confrontational action and through detection can they know the action strategy that the other has taken. Therefore, it is no longer an effective confrontational method to adjust our data link confrontational strategy with the change of the enemy electromagnetic interference strategy because the enemy can also quickly detect the change of our data link operation mode and immediately respond. Frequent strategy changes will fall into a fruitless dead cycle. Therefore, the use of the game theory to study the game strategy with mutual influential relationship does not need to take action according to the feedback of the opponent but decides its own strategy through predicting the opponent’s action. In this way the UAV data link can adopt its own optimal anti-jamming strategy by predicting the enemy’s electromagnetic interference strategy. In addition, the prediction results on the confrontational game can be used to pre-evaluate the effects of the enemy’s electromagnetic interference and guide the UAV data link’s strategy selection. In the UAV data link’s confrontational game process, the purpose of enemy electromagnetic interference is to interfere with the communication processes of our data link by adopting different interference modes. Our data link then applies different anti-jamming means to reduce the impact of enemy interference. Therefore, the game theory is an effective method for analyzing the UAV data link confrontational game processes.

Building the UAV data link dynamic confrontational game model

Therefore, the UAV data link’s electromagnetic confrontational game belongs to the typical non-cooperative zero-sum game. In building the data link confrontational game model, the same function should be taken as the utility function of the two sides. One side of confrontational game pursues the maximization of the utility function, and the other pursues its minimization. (3) Selecting the utility function.

A utility function is the behavioral criterion of a game. Different utility functions produces different game results. Selecting different utility functions may directly affect the action strategies of game participants.

For UAV data link, the optional utility functions mainly include error rate, transmission rate, energy efficiency, etc. Different utility functions will lead to different choices of communication strategies (that is, anti-jamming strategies), and then affect its anti-jamming effect.

If the utility function is bit error rate, focus on the reliability of UAV data link communication, and choose communication strategies with strong anti-jamming ability, such as spread spectrum communication, frequency hopping communication, spatial diversity technology, etc. The above strategies can maintain low bit error rate in interference environment and effectively improve the anti-jamming effect of data link.

If the utility function is the transmission rate, the communication strategy chooses the strategy of improving the transmission rate, such as high-order modulation mode (MQAM, MFSK, MPSK, etc.), increasing the signal transmission power, etc. High-order modulation mode can improve the transmission rate when the signal-to-noise ratio is high, but the anti-jamming effect is relatively weak. Increasing the transmission power can enhance the anti-jamming ability to a certain extent, but it may cause stronger interference from the interfering party, which is not applicable to the energy-limited UAV platform.

If the utility function is energy efficiency, the communication strategy chooses energy-saving modulation and coding methods, such as OFDM and TCM technology, etc. The above strategies have some sacrifices in anti-jamming performance, and make a certain degree of balance between energy efficiency and anti-jamming ability.

To guarantee the reliable and accurate communication of our UAV data link, the bit error rate (BER) should be used as the utility function because it most straightly indicates the accuracy of data link communication. The data link side’s goal is to ensure the correct transmission of information by reducing the data link’s BER with the game strategy. The electromagnetic interference side, on the other hand, maximizes the BER of the data link and reduces the reception accuracy of the data link side and even leads to communication interruption. In the different combinations of electromagnetic interference confrontational strategies, BER is the ultimate quantitative comparison value and can tell the merits and demerits of different strategy combinations. Therefore, BER is selected as the utility function for the data link electromagnetic interference confrontational game.

Designing game confrontational algorithm

Based on the game confrontational model building principles described in Sect. 2.1, with the complexity of electromagnetic interference considered, the UAV data link interference analysis model is established to predict the value of its utility function (data link BER) when different electromagnetic interference strategies are used, thus deriving the game payment matrix. The equilibrium method is used to find the equilibrium solution of the game payment matrix and to obtain the game strategy of the data link.

The dynamic confrontational game algorithm

In the condition that the game model and the utility function are determined, the dynamic confrontational game algorithm is designed based on the non-cooperative zero-sum game to evaluate the interference effect. Through analyzing the interference and utility values of the data link in the condition that its different interference combinations are set and under different anti-jamming strategies, the payment matrix of the confrontational game is solved and its Nash equilibrium solution is calculated. The block diagram of the algorithm designed is shown in Fig. 3.

Fig. 3The flowchart of the data link electromagnetic countermeasure algorithm based on game theory.

The flowchart of the data link electromagnetic countermeasure algorithm based on game theory.

In Fig. 3, first of all, the action strategy sets of both sides of interference confrontation should be determined, namely the interference mode of the interference side and the anti-jamming mode of the communication side and the BER utility function. Then the BER of different interference confrontation combinations should be calculated so as to obtain the payment matrix of the game. Furthermore, the following two cases should be considered: the existence of the Nash equilibrium solution of the pure strategy and the non-existence of its Nash equilibrium solution. In the latter case, the Nash equilibrium solution of the mixed strategy should be solved. Finally, the behavioral strategy of interference confrontation should be selected according to the Nash equilibrium solution of the non-cooperative game.

The complexity of the designed model is mainly related to the number of game participants and the size of strategy space. The designed model is solved by linear programming, which belongs to a P-type problem. The complexity of the model is O((m + n)3.5), where m and n are the number of strategies of both sides of the game.When m and n increase, the complexity of the model increases sharply, and sparse matrix technology can be used to reduce the complexity of the designed model.

The designed model in this paper is the link layer model, in the real UAV network scene. The network layer game model must be designed. This model is the basis of the network layer game model design. This model can be implemented in the real UAV network scene through the following steps, the main steps are as follows:

2) Secondly, The game states of all communication links in the network are input to the network layer game model.

3) Finally, Based on the game state of the link layer, the game strategy of the network layer is selected through the network layer game model. For example, the nodes of the network layer can choose the optimal network path according to the network topology and the game state of the link layer, so as to improve the network throughput and reduce the network delay.

Simulation and analysis

The data link antagonism game model designed in this paper, in which both sides of the game are completely antagonistic.The interfere tries to maximize that communication BER by optimize the interference strategy. The data link side minimizes BER by adjusting the anti-jamming strategy of the data link.The strategies of both sides play each other and achieve stability through Nash equilibrium.

According to different signal interference strategies (such as single frequency interference, noise interference, pulse interference, FM interference, etc.), the bit error rate (BER) can be optimized by adjusting the anti-jamming strategy of data link.The main anti-jamming strategies include direct sequence spread spectrum, adaptive frequency hopping, adaptive modulation and channel coding, MIMO spatial diversity and other technologies.For example, according to the bandwidth of the jamming signal, anti-jamming can be carried out by adjusting the spreading factor or frequency hopping rate, For pulse interference, anti-jamming can be carried out by optimizing the coding rate and interleaving depth of data link channel coding, etc.On the above basis, based on the designed game model, by expanding the strategy set of both sides of the game, a new utility function matrix is solved, and the strategy combination that both sides of the game can not improve their own benefits by unilaterally changing their strategies, that is, Nash equilibrium solution, is obtained.

Description of simulation conditions

Settings of the game confrontation strategy set: for the non-cooperative zero-sum game communication confrontation, both sides of the game can have multiple action sets. In order to simplify the analysis, the strategy set of the data link is set into direct sequence spread frequency, frequency hopping and spreading, and Multilevel spread frequency. The enemy interference strategy set is single-frequency interference, wideband noise interference, narrowband noise interference, digital FM interference (FSK interference), pulse interference. The single-frequency interference is an aiming single-frequency interference. The wideband noise interference is a blocking noise interference. The narrowband noise interference frequency band is 1/10 of the signal frequency band. The digital FM interference is FSK interference. The pulse interference is broadband pulse modulation interference. The data link communication system parameter settings are: direct sequence spread frequency, BPSK modulation, spread frequency code length M = 128. Frequency hopping and spreading: BPSK modulation, frequency hopping rate is 60, Multilevel spread frequency: BPSK modulation, 32-numeration spread frequency, spread frequency code length M = 128.

Conclusion

The UAV’s safe application in the battlefield electromagnetic environment has been focused on the study of the confrontational decision-making problem of its data link. Based on the reasonable assumptions of the attack and defense game strategy of the UAV data link, this paper builds a dynamic confrontational game model of the UAV data link by combining the non-cooperative zero-sum game theory with the data link’s attack and defense reality. It analyzes the confrontational game processes of the data link and then designs its dynamic confrontational game algorithm. It uses the equilibrium method to solve the Nash equilibrium solution of the game matrix and forms the optimal confrontational strategy model of the UAV data link. The simulation results verify the effectiveness of the proposed model. A methodology is provided for enhancing the game confrontational capability of the data link in its battlefield electromagnetic environment.
