Analyzing anonymous activities using Interrupt-aware Anonymous User-System Detection Method (IAU-S-DM) in IoT
Authors: Hani Alshahrani, Mohd Anjum, Sana Shahab, Mana Saleh Al Reshan, Adel Sulaiman, Asadullah Shaikh
Published: 2024

ABSTRACT
The intrusion detection process is important in various applications to identify unauthorized Internet of Things (IoT) network access. IoT devices are accessed by intermediators while transmitting the information, which causes security issues. Several intrusion detection systems are developed to identify intruders and unauthorized access in different software applications. Existing systems consume high computation time, making it difficult to identify intruders accurately. This research issue is mitigated by applying the Interrupt-aware Anonymous User-System Detection Method (IAU-S-DM). The method uses concealed service sessions to identify the anonymous interrupts. During this process, the system is trained with the help of different parameters such as origin, session access demands, and legitimate and illegitimate users of various sessions. These parameters help to recognize the intruder’s activities with minimum computation time. In addition, the collected data is processed using the deep recurrent learning approach that identifies service failures and breaches, improving the overall intruder detection rate. The created system uses the TON-IoT dataset information that helps to identify the intruder activities while accessing the different data resources. This method’s consistency is verified using the metrics of service failures of 10.65%, detection precision of 14.63%, detection time of 15.54%, and classification ratio of 20.51%.

Introduction

The Internet of Things (IoT) refers to a network of physical devices, vehicles, home appliances, and other objects embedded with sensors, software, and connectivity to exchange data and perform tasks automatically. IoT provides users with various communication and interaction services, allowing them to control, monitor, and automate their environment and access new services and information. IoT also presents significant security and privacy challenges, as many connected devices and the vast amount of data they generate create new opportunities for cyberattacks and data breaches1. An intrusion detection system (IDS) is important in securing IoT devices and networks by detecting and alerting potential security threats and attacks. Because IoT devices often have limited computing power and memory, IDS solutions for IoT must be lightweight, efficient, and scalable2. Intrusion detection is a complicated task that needs to be performed in IoT. The main aim of intrusion detection is to identify suspicious activities or behaviours that may indicate a security threat or intrusion has occurred3. An IDS monitors the entire system, including the network, devices, and applications, for signs of security threats or malicious activity4. IDS is commonly used in IoT systems to detect security threats and vulnerabilities that may arise due to the unique characteristics of IoT devices and networks5. It produces a set of characteristics or features used in the detection process to identify potential security threats or intrusions. IDS maximizes the overall accuracy in intrusion detection, enhancing the performance and efficiency range of IoT-based applications6. When an IDS detects a potential intrusion or security threat, it typically generates an alert or notification, providing details about the type of intrusion and its location. The information provided by the IDS is generally used for further analysis and investigation.

Dimensionality reduction algorithms are commonly used in IDS for IoT to improve their performance and efficiency7. Several dimensionality reduction algorithms are used in IDS for IoT, including principal component analysis, independent component analysis, and linear discriminant analysis8. These algorithms reduce the dimensionality of the data while retaining the most important information relevant to intrusion detection9. Then, these algorithms transform the data into a new coordinate system that captures the maximum amount of variance in the data with the minimum number of components. This transformation results in a lower-dimensional representation of the original data, which can be more easily processed and analyzed by IDS10. By reducing the dimensionality of the data, IDS processes and analyzes large volumes of data in real-time, which helps to improve their performance and efficiency and reduces the time consumption in the computation process11. In addition, dimensionality reduction also helps to improve the accuracy of intrusion detection, as it can help to identify the most important features that are indicative of potential security threats or intrusions12.

Anonymous user classification is a technique to detect or classify users without access to their personally identifiable information. IDS-based user classification methods are used in IoT to identify unauthorized users or anomalies in the network13. Anonymous user classification is a crucial task to perform in every IoT-based application. Therefore, using them with other security measures, such as authentication and access controls, is important to ensure that unauthorized users cannot gain access to the system in the first place14. An authentication and key agreement (AKA) scheme is provided to the user, sharing secret keys and values for the authentication process15. AKA scheme uses IDS, which gathers necessary information from monitoring systems. The secret key contains the important data required for the proper authentication process. AKA scheme ensures user safety and security from anonymous users in IoT applications16. A lightweight anonymous user, AKA scheme, is used in IoT. A three-factor authentication scheme secures sensitive data and privacy from third-party members17. The lightweight authentication scheme provides passwords, biometric information, and smart cards to the users for authentication18. The three-factor authentication process improves users’ security and privacy range in IoT applications. IDS also produces optimal information for authentication and anonymous user classification processes19.

Service failure is a major issue that can occur in any IoT application. It causes severe damage while performing tasks in IoT networks. Various methods and techniques are used to identify service failure20. An energy-efficient scheduling algorithm is applied in an IoT environment. The scheduling algorithm provides necessary resources and factors based on priorities21. The actual servers are provided to the system, reducing the service failure rate. The algorithm identifies active and failure nodes, which detects the service failure in the early stage22. The scheduling algorithm improves the performance and efficiency range of IoT systems. The scheduling algorithm also provides replacement nodes for service failure, enhancing the system’s reliability level23. A service failure mitigation technique is also used for the detection process in IoT environments24. The mitigation technique identifies the failures based on conditions. Artificial intelligence (AI) technology is used in the mitigation technique to predict failures in IoT networks. The AI-based technique increases the quality of service and feasibility level of IoT-based applications25. An IDS is frequently used at network gateways to identify and stop malicious traffic. It keeps a close eye on all the data flowing across the network, looking for anything out of the ordinary that may indicate a security risk. The IDS uses signature-based and anomaly-based attack detection methods as well as scheduling algorithm for enhancing the systems reliability. But the above-mentioned algorithm fails for detecting the particular malicious activity in a network or system. Hence in the prospect of strengthening intrusion detection with instantaneous security, an Interrupt-aware Anonymous User-System Detection Method (IAU-S-DM) is designed.

Related works

The use of IDS in IoT networks has gained significant attention in recent years due to the growing concerns over the security of IoT-based applications. IoT networks may detect and classify approved and illegal users using IDS. Integrating blockchain and intrusion detection has been a major field of study in improving data privacy and identifying IoT cyberattacks. Learning-based ensemble models may recognize complicated harmful events and preserve data privacy for cloud virtual machine live migration and IoT network protection. Therefore, Alkadi et al.26 developed a deep blockchain framework-based collaborative intrusion detection method for the IoT and cloud systems. The developed method detected the intrusion and secured the cloud network from third-party members. In27, authors proposed a deep convolutional generative adversarial network approach for intrusion detection. These methods provided proper privacy-preserving policies to the users and reduced the complexity of intrusion detection, enhancing the system efficiency range.

IoT environments contain heterogeneous, scattered devices with limited processing capabilities, storage, and battery life. Thus, lightweight and efficient solutions that operate in such contexts without straining limited resources are needed. Latif et al.28 introduced a new intrusion detection framework based on IoT systems dense random neural networks (DnRaNN). The DnRaNN worked efficiently in a limited resources environment due to its inherent scalable and distributed nature. In29, authors designed an adaptive particle swarm optimization convolutional neural network (APSO-CNN) based security threats detection to detect various types of cyber-attacks accurately. The developed approach identified the multi-layer parameters using a convolutional neural network. In addition, the PSO algorithm adaptively optimized the structure parameters of a one-dimensional convolutional neural network. Both methods enhanced the efficiency and robustness of the intrusion detection process.

Li et al.30 introduced a collaborative intrusion detection method for IoT environments. Disagreement-based semi-supervised learning was employed in the proposed scheme to mitigate intrusion issues. The proposed method minimized the energy consumption level in the detection process. Furthermore, when evaluated using datasets and real IoT network environments, the false alarm rate in the intrusion detection process was reduced more than that of other methods. In31, authors developed a two-step ensemble approach for detecting and identifying IoT devices. First, traffic analysis was performed using an Extra tree binary classifier to identify suspicious events precisely. In the second stage, the ensemble approach analyzed the suspicious data. The extra binary tree classifier optimized the overall accuracy of the intrusion identification process. The literature analysis shows that Fog computing has also been applied as a promising solution for developing intrusion detection algorithms32. Fog computing is a distributed computing paradigm that extends cloud computing to the network edge. It provides low-latency and high-accuracy detection by deploying a detection model on fog nodes closer to the IoT devices33. Therefore, Chen et al.34 designed a novel intrusion detection method for the IoT network in a Fog computing environment. The proposed model applied a multi-objective evolutionary convolutional neural network. This model employed a convolutional neural network as a classifier for the detection process. Experimental results showed that the proposed method achieved high accuracy in the intrusion detection process.

Blockchain technology has the potential to enhance the security and trustworthiness in cyber security systems by secure and decentralized storage of intrusion data and detection models, ensuring the integrity and immutability of the data35. This process can enhance the transparency of the detection process and reduce the risk of tampering or manipulation. Sarhan et al.36 introduced a hierarchical blockchain-based federated learning framework for IoT intrusion detection. The framework addressed data privacy issues, secure architectures, and scalable deployments in existing ML-based intrusion detection frameworks. In37, authors developed a two-stage intrusion detection system (TS-IDS) for software-defined IoT networks. The wrapper feature extraction technique was used to extract the important patterns and features. The developed approach minimizes detection latency, enhancing efficiency. Li et al.38 proposed a butterfly optimization algorithm-based intrusion detection method for medical IoT systems. An artificial neural network was used to extract and select the features to prevent the users from unknown intrusions. The implemented network was applied to identify the traffic in IoT applications.

Zhou et al.39 introduced a novel intrusion attack defence strategy for IoT heterogeneous perceptual networks. The particle swarm optimization algorithm was used in the introduced system to balance detection efficiency and energy consumption. The introduced method was an optimal defence strategy that maximized IoT user security and privacy levels and addressed the security and energy consumption challenges. In40, authors developed a novel intrusion defence framework for IoT-based smart environment security using ensemble learning. The DL (Deep Learning) technique was used to detect the anomalies present in the network. The developed framework provided a proper authentication scheme for the users, improving the system’s security level. Fatani et al.41 proposed an efficient IDS based on transient search optimization and DL techniques. Furthermore, a novel selection approach was developed by modifying transient search optimization using a differential evolution algorithm.

Comparative study

This study presents the Interrupt-aware Anonymous User-System Detection Method (IAU-S-DM) for intrusion detection systems to identify intruders and unauthorized access in different software applications. A comparative analysis is presented using the metrics of service failure, detection time, precision, classification ratio, and service distribution. The sessions (5–60) and users (20–240) are varied for the above metrics. Along the proposed method, DnRaNN28, APSO-CNN29, and TS-IDS37 from the related works section are considered. All deep recurrent learning models have a completely linked layer of 16 neurons. All neurons in a given layer are connected to all the neurons in the next layer if and only if that layer is fully connected. The ReLU activation mechanism was employed in a fully connected layer, and a single neuron was used in the output layer for attack detection, while SDN-IoT datasets were used. Concluding remark

The article proposes an anonymous user-system detection method that considers interruptions to counteract the negative effects of adversaries during service distribution sessions. Time and response failures are key to determining the user type to prevent failures. In the training process, the previous classification and the current behaviour of the user’s systems are considered to identify and segregate their anonymity. The training and learning are recurrent through previous classifications for preventing any hike in in-service failures. The comparative analysis shows that the proposed method reduces service failure by 10.65% and detection time by 15.54%, whereas it leverages detection precision of 14.63%, classification of 20.51%, and service distribution of 14.85%, respectively. With real-time security, the suggested technique can improve intrusion detection by spotting hostile behaviour in a network or system. An IDS monitors networks well, and managing detection tools and acting on ineffective hazards is not a good additional layer of defence.

IDS are vulnerable to the same protocol-based attacks as network hosts since they examine collected protocols in real-time. However, the limitations of this study include the protocol analyzer issues, and incorrect data may cause an IDS to crash. An adaptive traffic-aware IDS with blockchain support will extend this classification process in future studies. Such a design improves the pre-classification of user/ system traffic without causing passive service distributions.
