Protocol for quantifying vertebral column morphology for the statistical analysis of scoliosis severity in zebrafish
Authors: Brittney Voigt, Ece Atayeter, Ron Sistrunk, Ryan S. Gray
Published: 2026

ABSTRACT
SummaryHere, we present a protocol for quantifying zebrafish vertebral column morphology using micro-computed tomography (microCT) datasets for scoliosis researchers. We describe steps for orientation of skeletal and cranial microCT datasets in DataViewer, vertebral position measurements in ImageJ/Fiji, and analysis of vertebral position in R. The approach described here graphically depicts vertebral position while providing a means to quantify scoliosis severity and perform statistical analysis of differences in vertebral column morphology in zebrafish.For complete details on the use and execution of this protocol, please refer to Voigt et al.1

Before you begin

Scoliosis is the most common human musculoskeletal disorder and presents as an abnormal curvature of the spine.2 Cobb angle has long been the standard for measuring scoliosis severity,3,4 with curvatures greater than 10° meeting diagnosis criteria. However, this method is subject to high interobserver variability and relies on subjective selection of vertebrae.5 Other approaches, such as vertebral centroid measurement, offer improved reproducibility but still require complex geometric calculations and subjective assessment.6,7 Moreover, these two-dimensional methods cannot adequately capture the complexity of 3D spinal curvatures. Classification systems such as the Lenke system8 incorporate curve type and sagittal modifiers to better describe spinal morphology, but this system remains qualitative and is not readily applicable to model organisms.

Zebrafish have emerged as a valuable scoliosis model9,10 and exhibit complex curvatures in the dorsoventral (DV),11,12 mediolateral (ML),13 or both14,15,16 planes. However, quantification of scoliosis severity has not been standardized across the field. Although Cobb angle has been applied to zebrafish, it shares the same limitations observed in human studies and does not allow for robust statistical comparisons or clear visualization of spine defects (Figures 1A and 1B). To address these limitations, we developed a reliable and accessible protocol that graphically depicts vertebral column shape, quantifies DV and ML displacement relative to controls, and enables statistical comparison of scoliosis severity across genetic or environmental conditions. In Voigt et al., this method was used to compare vertebral position of inppl1a mutants to wild-type controls and demonstrated that mechanical stress exacerbates scoliosis severity.1 Although originally developed for adult zebrafish, this approach can be adapted for earlier developmental stages that attenuate naturally or when enhanced with contrast agents.17 This protocol can also be modified to accommodate 2D imaging modalities, other fish species, or even mouse or human datasets.

Innovation

The method described in Voigt et al.1 utilized DV positional data from all vertebrae posterior to the Weberian apparatus (Figure 1C). Datasets were aligned to enable quantitative comparison of DV vertebral position across samples using an approach analogous to residual analysis in linear regression.18 Rather than a line of best fit, a line connecting the first abdominal vertebrae (V1) and the most posterior vertebrae common to all datasets (Vposterior) was used (Figure 1D), since total vertebral number differed across samples. Each vertebra was repositioned based on its vertical distance (residual) from this line (Figures 1E and 1F). To control for size differences, the datapoints were normalized to parasphenoid length, which correlates with standard length.1,17

The Residual method worked well for inppl1a mutants, which exhibit primarily DV curvatures.1 However, many scoliotic mutants display curvatures in both planes.10,14,15 Additionally, residual-based alignment can distort the original geometry, particularly when datasets are not pre-aligned along orthogonal planes. To address these limitations, we updated the method to incorporate ML position and to use 3D rotation for dataset alignment (Figures 1G and 1H). This Rotation method preserves the original distances, angles, and overall structure of the data, providing a more faithful geometric reorientation. When datasets are pre-aligned along orthogonal planes, the methods perform similarly (Figure 2A, R=0.993), but under artificial misalignment, the Rotation method (Figures 2C–2E and 2G) consistently outperforms the Residual method (Figures 2B–2D and 2F).Figure 2Comparing the precision of the Rotation and Residual methods for vertebral position alignment(A) Pearson correlation plot of the calculated dorsoventral position using the Residual (x-axis) and Rotation (y-axis) methods (R = 0.993, p-value < 2.2e-16 for all plots, n = 692 for all plots).(B and C) Pearson correlation plots of the calculated dorsoventral position using the Residual (B) (R = 0.997) or Rotation (C) (R = 0.999) method on input data that is orthogonally aligned (X-axis) and artificially misaligned by 15 degrees (Y-axis).(D and E) Pearson correlation plots of the calculated dorsoventral position using the Residual (D) (R = 0.900) or Rotation (E) (R = 0.978) method on input data that is orthogonally aligned (X-axis) and artificially misaligned by 30 degrees (Y-axis).(F and G) Pearson correlation plots of the calculated dorsoventral position using the Residual (F) (R = 0.751) or Rotation (G) (R = 0.848) method on input data that is orthogonally aligned (X-axis) and artificially misaligned by 45 degrees (Y-axis). This protocol details orthogonal alignment of microCT datasets; collection of 3D vertebral position data; and the rotation, visualization, and statistical analysis of vertebral column morphology. We demonstrate its utility by analyzing the stl438 mutant, which exhibits curvatures in both planes.

Orthogonal orientation of skeletal microCT datasets in DataViewer

Timing: 3–5 min per sample

Timing: 3–5 min per sample

This section describes the procedures required to orient the vertebral column in zebrafish skeletal microCT datasets along orthogonal anatomical planes using DataViewer by Bruker. Completion of this section will result in uniformly oriented datasets (Sagittal JPEG image series for each specimen) suitable for downstream vertebral position data collection and quantitative analysis.1.Open DataViewer.2.Open the reconstructed microCT dataset:a.Actions > Open.b.Navigate to the directory containing the reconstructed microCT dataset.c.Select any of the reconstruction files (.bmp or.dcm), except for the very first file > Open.Note: Once the dataset has loaded, several panels will appear (Figure 4). The Toolbar is located at the top of the window (Figure 4A). The Image Control Panel is located on the top left side of the window (Figure 4B). This adjusts the Color/Data range of the dataset (it is not recommended to adjust these parameters) and the Position within the dataset (X, Y, and Z). The Reference Image is located on the bottom left of the window (Figure 4C). This allows for visualization of the transaxial position at which the current viewpoint is located (this will only be loaded if an.spr file is included in the directory). The Dataset should be open on the righthand side of the window in three orthogonal planes (Figure 4D): the Coronal View (X-Z) located on the top view, the Transaxial View (X-Y) located on the bottom left view, and the Sagittal View (Y-Z) located on the bottom right view. The Status bar is located along the bottom of the window (Figure 4E). This displays information about the dataset and current viewing parameters.d.Zoom in and out of the dataset using the “+” and “–“ buttons on the keyboard.Note: The authors highly suggest using a mouse rather than a trackpad for this section of the protocol. If using a mouse, zooming can be accomplished by scrolling up and down.e.Navigate within the dataset by clicking on any point in any of the three orthogonal planes, which will position all three planes at the cross-section of that point.3.Reorient the dataset to align the vertebral column along orthogonal anatomical planes:a.Align the transaxial view so that the ventral side is facing downward:i.Double click on the Reference Image to move the red line such that it crosses the pectoral fins and the spine.Note: This should only change the transaxial view of the dataset. The pectoral fins are used an easy reference to distinguish dorsal from ventral sides of the fish.ii.In the Transaxial plane, double click on the center of the vertebrae in view to move the vertical blue line to this position.iii.While holding down the Control key, click and hold the left mouse button to rotate the transaxial image such that the ventral side of the fish is facing downward.Note: Use the blue line as a reference to fully straighten the image in this field of view (Figure 5A).iv.Select OK if an “Attention!” dialog box appears.b.Align the coronal view so that the anterior side (the head) is facing downward:i.In the Coronal view, double click on the center of the spine in view to move the vertical blue line to this position.ii.While holding down the Control key, click and hold the left mouse button to rotate the Coronal image such that the anterior side of the fish is facing downward.Note: Once again, use the blue line as a reference to roughly center the image along the spine (Figure 5B).c.Align the sagittal view such that the anteroposterior (AP) axis runs from left to right (head is facing left).Note: This should already be roughly correct based on the previous alignments.i.In the Sagittal view, double click near the first abdominal vertebrae to move the horizontal green line to this position.ii.While holding down the Control key, click and hold the left mouse button to rotate the Sagittal image such that the first abdominal and last vertebrae are roughly aligned along the green line (Figure 5C).d.Fine tune the alignment such that first abdominal and last vertebrae are roughly in line with each other in both the Sagittal (along the green line) and Coronal (along the blue line) planes (Figure 5D).4.Once satisfied with the alignments, export the aligned Sagittal sections as a series of jpeg files:a.Actions > Save > Sagittal(Z-Y) Images as a Dataset.b.Select Yes if an “Attention!” dialog box appears.c.Navigate to the desired save location for the dataset.d.Create a new directory in which to save the dataset and name it accordingly.Note: It is recommended to use a consistent naming style, for example: SampleID_Sag. Each sample will need its own directory.e.Double click into the new directory.f.Change “Save as type:” to “(8-bit)JPG (∗.jpg).”g.Select Save.Note: This action may take a few minutes to complete.Figure 4Overview of the DataViewer homepageAfter opening a dataset in DataViewer, the following panels can be seen: (A) Toolbar (green outline) with several drop-down menus, (B) Image Control Panel (pink outline) in upper lefthand corner for adjusting the color and datarange and navigating to different X, Y, and Z positions of the dataset, (C) Reference Image (orange outline) on the bottom lefthand side for quickly visualizing the location of the current transaxial view, (D) Dataset (yellow outline) on the right hand side with Coronal (X-Z) view on the top left, Transaxial (X-Y) view on the bottom left, and the Sagittal (Y-Z) view on the bottom right, (E) Status Bar (blue outline) along the bottom of the window displaying information about the dataset and current viewing parameters.Figure 5Reorienting datasets along orthogonal planes(A) Example of a microCT dataset aligned in the transaxial view with dorsal above the ventral side with pectoral fins as a guide and blue reference line aligned with the vertebra.(B) Example of dataset aligned in the coronal view with posterior above the anterior side and blue reference line roughly aligned with the spine.(C) Example of dataset aligned in the sagittal view with anterior left of the posterior side and the green reference line roughly aligned with the spine.(D) Example of the final fine-tuned alignment such that the green and blue reference lines are roughly aligned with the spine.

Expected outcomes

Upon completion of this protocol, the user will be able to align microCT datasets along orthogonal planes and export a series of sagittal sections from which the 3D coordinates of vertebral centra can be measured. In R, the user will be able to import these datasets and perform matrix rotation of the 3D coordinates to align the vertebral columns of groups of fish for comparison. The user will also be able to visualize the dorsoventral and mediolateral vertebral column shapes of individuals and groups to identify trends (Figures 11A–11F). Finally, the user will be able to perform statistical analysis on vertebral position to determine whether a statistically significant difference exists between groups and which, if any, vertebrae are significantly displaced (Figures 11G–11I).

Quantification and statistical analysis

As described above, a two-way ANOVA was performed on the aligned vertebral position datasets to analyze the effect of group and vertebral number, vert, on normalized vertebral position (the final series of either the DV (y), ML (z), or absolute ML (abs_z)). A significant difference was found in vertebral displacement between wild type (n = 382 vertebrae, N = 15 fish) and the stl438 mutant (n = 368, N = 14 fish) when comparing dorsoventral (F-value = 120.8, p-value < 0.0001) and absolute mediolateral (F-value = 371.6, p-value < 0.0001) vertebral column morphology, however raw mediolateral displacement was not statistically significant (F-value = 1.6, p-value = 0.2). This is likely due to the lack of a consistent left-right pattern in the dataset, causing the mean displacement to average around 0. When assessing displacement of specific vertebrae, vertebrae 9–17 (truly V13-V21) were significantly displaced in the ventral direction compared to wild-type controls (adjusted p-value < 0.05). When comparing the absolute mediolateral displacement, ignoring right versus left curvatures, vertebrae 10–22 (truly V14-V26) are significantly displaced in stl438 mutants compared to wild-type controls (adjusted p-value < 0.05). All data required to replicate these results can be found in Data S1.

Limitations

The outcome of the method largely depends on proper alignment along the orthogonal planes. When the raw positional data was artificially misaligned out of orthogonal alignment by 15, 30, and 45 degrees in silico, the precision of the method progressively declined (Figure 2); therefore, the pre-alignment of microCT datasets is crucial to the success of this method. Unfortunately, Bruker’s DataViewer is not an open-source software and is only available by purchase. However, any software that allows the user to rotate microCT datasets along orthogonal planes and export a series of sagittal sections (one slice per pixel of depth) should suffice. The authors recommend 3D Slicer21 as an alternative to DataViewer for this purpose. The DeLeon Lab in the Anthropology Department at the University of Florida has published a useful video tutorial describing this process.29

Problem 4

The import and alignment (import() function) of the raw vertebral position data fails on the dataset (Related to Step 38).

Potential solution

This may be due to 1) an imperfect match between files, variables, columns, etc. Keep in mind that R is case-sensitive, so all variable names must match exactly to the code provided here. Alternatively, 2) the matrix rotations may not perform as expected depending on the individual datasets. To visualize which steps of the process are deficient and to make the appropriate adjustments, it is useful to visualize the data transformations and rotations step-by-step. To facilitate this, code is provided at the end of the supplemental document, Document S1, to reproduce the stepwise plots from Figure 10 for every sample in the dataset. Common fixes include ensuring that all required packages are loaded, ensuring that the id_Sag_Results.csv files are in the proper format without any typos, altering the identity matrix I for your dataset, changing which sin(θ) value of the rotation matrices (Rz and Ry) is negative, and changing the sign of the θ values.

Problem 5

The plotting is not working for the dataset. (Related to Steps 43–46, 49, and 50).

Potential solution

When writing the code for the plots, the authors attempted to limit any hard coding that could vary across user datasets; however, it is possible that some adjustments may need to be made. Faceted plots are all coded with the group variable, so make sure the key.csv file contains that column and contains the desired comparison groups. Also make sure the comparison groups are an exact match (case-sensitive) across the key.csv file to limit errors. For example, wild type and wildtype would be considered as two different groups in R.

If the dimensions of any plot need to be altered, change the width and height variables of the ggsave() function within the various plotting functions. To better understand the grammar of ggplot() objects or to personalize the plots, reference the online books, R for Data Science30 and ggplot2: Elegant Graphics for Data Analysis.31
