Adaptive DSP for progressive transceivers in 6G: a fully software-defined, AI enhanced DSP framework
Authors: R. Sathishkumar, D. Vijendra Babu
Published: 2026

ABSTRACT
The upcoming 6G networks require digital signal processing (DSP) systems which need to adapt their operations for unanticipated changes in communication channel conditions and system environmental factors because the demand for high-speed communication demands both quick response times and dependable service. The fixed processing chains of traditional DSP systems which engineers built for 5G networks together with their requirement for specific hardware usage create limits that prevent effective operation under changing environmental conditions. The paper presents ADaPT-6 (Adaptive DSP for Progressive Transceivers in 6G) as a solution to these obstacles through its entire software-based AI-powered digital signal processing system which enables real-time transceiver operation changes through intelligent learning. The ADaPT-6 system operates through two fundamental components which use FlexiTune Modulation Adaptation to enable systems to select their best modulation methods based on current channel conditions while the Signal State Evolution Engine predicts system behavior to modify system operations of filtering and equalization and synchronization. The framework achieves better spectral efficiency through its implementation of adaptive modulation together with its ability to predict signal states which improves system reliability and operational efficiency. The research shows through extensive testing in practical 6G fronthauling situations that both traditional fixed DSP systems and DSP systems with limited adaptation capabilities face performance difficulties across multiple performance metrics including bit error rate and statistical reliability and throughput and energy efficiency and latency and outage probability. The evaluation process used SNR values ranging from 0 to 20 dB while measuring EVM in percentage terms and ACLR in decibels and average throughput in Mbps and latency in milliseconds and energy efficiency in bits per Joule. Quantitative evaluation demonstrates that ADaPT-6 achieves significant performance improvements over conventional DSP frameworks, including a ~ 20.8% increase in throughput (57.37 Mbps vs. 47.47 Mbps), ~ 23.7% reduction in latency (20.52 ms vs. 26.88 ms), and ~ 44.5% improvement in energy efficiency (0.678 vs. 0.469 bits/Joule). Additionally, the framework consistently achieves lower BER and EVM across the entire SNR range (0–20 dB), confirming its robustness under dynamic channel conditions. The results confirm that ADaPT-6 operates as an effective digital signal processing solution which works on any hardware platform and can be implemented at any scale. The system functions as the best solution for future AI-native 6G transceiver systems.

Introduction

Wireless communication systems serve as the fundamental infrastructure which enables digital connectivity throughout contemporary society, enabling various applications which include mobile broadband and Internet of Things (IoT) systems and autonomous systems and mission-critical communication networks1. The growing demand for data-intensive applications which require low latency has created an urgent need for wireless systems that can deliver dependable high-capacity transmission2. Wireless communication systems adapt their channel capabilities because research demonstrates that various factors including noise interference and user mobility patterns and fading and signal strength degradation create unpredictable signal strength which blocks systems from building reliable communication links. Research demonstrates that organizations achieve improved system performance through adaptive communication methods which operate effectively under dynamic channel conditions3. Adaptive systems implement real-time channel data analysis to optimize transmission parameters which leads to better spectral performance and greater system dependability and enhanced service delivery according to4. Operators of communication systems now use software-defined radio (SDR) and programmable digital signal processing (DSP) platforms to create real-time operational systems because these platforms enable system intelligence to detect environmental changes which occur in real-time5. The adaptive modulation and coding schemes use channel state information (CSI) and signal quality indicators to choose suitable modulation formats which achieve a balance between data transmission rate and data transmission reliability according to6. The signal processing pipeline of these schemes uses channel awareness to enable communication systems to handle temporary changes in channel conditions according to research7, 8. The implementation of channel-aware adaptation techniques has emerged as an effective solution to combat performance deterioration which occurs during fading conditions and when there is high interference in various environmental settings.

Software-defined DSP frameworks offer flexible options to redesign their filtering and equalization and synchronization functions which assist in eliminating disturbances caused by channel interference9, 10. The combination of adaptive modulation strategies with programmable DSP operations creates a system that produces intelligent processing for end-to-end signal transmission11, 12. The dynamic wireless environment presents a challenging problem because the system cannot achieve perfect coordination between its two functions which control channel-aware modulation adaptation and its signal evolution process13. Existing adaptive communication techniques have achieved some progress but current methods still handle modulation adaptation and signal processing as separate tasks that are only loosely connected. The system uses channel state information to select modulation and coding methods while its downstream DSP processes depend on fixed settings that have been predetermined14. The system cannot achieve its maximum performance because real-time signal and channel changes do not connect with each other. The present frameworks use static or simplified channel models which cannot show how signal characteristics change during different transmission phases. The process of adaptive decision-making fails to match the fast changes which occur in communication channels because this approach leads to poor selection of modulation techniques and greater error rates and reduced system stability during extremely active operational periods. The design of many adaptive systems remains incomplete because they lack a single control system which manages both modulation choices and software-defined DSP functions. The system requires an integrated signal evolution model which provides effective feedback but it currently hinders system responsiveness and limits its ability to scale across different communication environments which experience changing conditions. The study introduces an integrated adaptive framework which models channel conditions and signal evolution and modulation control through a software-defined processing architecture that enables real-time system adaptation across different operational layers.

Literature review

The development of 6G networks requires advanced systems that can handle multiple sensing and communication and computing tasks. To satisfy these requirements current research studies are investigating the combined use of advanced signal processing and edge intelligence and adaptive communication methods. As a result, research studies have started to focus on intelligent radio systems which combine radio technology with integrated sensing and communication and physical-layer design that uses artificial intelligence.

Liu et al.15 presented a comprehensive survey on Integrated Sensing and Edge AI (ISEA), starting with technical preliminaries for sensing and new communication paradigms. The study examined real-world applications of ISEA which demonstrated existing industrial development and standardization. The study examines essential design principles together with performance metrics and architectural trade-offs of ISEA systems. The study examines ISEA through three core technologies which include digital air interface and over-the-air computation and advanced signal processing. The study examined how ISEA interacts with 6G technologies while presenting future research directions which include foundation model integration and ultra-low-latency ISEA needs. The research remains primarily theoretical because it lacks a complete adaptive signal processing system which combines channel-aware modulation with real-time DSP control.

Zhu et al.16 presented advancement about optical transmission methods which enable 6G development by showing beyond-200-Gb/s/λ optical systems that use intensity-modulation direct-detection (IM-DD) PAM4 technology. The research revealed that fiber optic systems could reach distances between 20 and 40 km which creates difficulties because of fiber dispersion. The experimental results proved that the low-complexity optoelectronic feedforward equalization method (OE-FFE) achieves 224 Gb/s capacity over a 41 km distance when used together with dispersion mitigation techniques. The systems support high-capacity operation which enables them to achieve 10 Tb/s CPRI equivalent throughput and more than 300 Gb/s wireless data rate peaks which meet the requirements for 6G high-capacity scenarios. The method depends on optical-domain optimization but fails to provide support for adaptive modulation and cross-layer control systems during periods when wireless channels experience varying conditions.

Hossain et al.17 developed a secure millimetre-wave (mmWave) CP-less multi-user orthogonal chirp division multiplexing (OCDM) transceiver system which supports four users and a passive eavesdropper. The hyperchaotic encryption algorithm increases physical layer security (PLS) protection. The researchers employed multiple channel coding approaches which encompassed LDPC and TURBO to improve bit error rate (BER) results. The simulation results demonstrated successful PLS defense through the combination of low correlation coefficients and a secrecy rate which could be achieved with minimum signal-to-interference and noise ratio (SINR) and an out-of-band (OOB) power emission of 341 dB. The system detected a spectral power difference of 7.68 dB together with peak-to-average power ratios (PAPRs) which ranged from 7 to 7.5 dB. The users achieved a BER of 1 × 10 − 4 through RA channel coding and 16-QAM modulation at 17 dB SNR. The system maintains its existing modulation and signal processing settings because it does not modify these settings when channel conditions change.

Dixit et al.18 evaluated the performance of a new progressive pattern interleaver (PPI) which enables user identification in interleaved division multiple access (IDMA) systems that 3GPP developed for NOMA and SC-FDMA and OFDM. The two systems successfully handle inter-symbol interference (ISI) while multiple users access their system through orthogonal sub-carrier technology. The simulation results demonstrated that PPI delivers sufficient performance in SC-FDMA-IDMA and OFDM-IDMA systems because it meets the bit error rate (BER) requirements during multipath testing. PPI demonstrates better performance than traditional random interleavers (RI) because it consumes less bandwidth and requires fewer resources to implement. The existing framework needs a single adaptive system that can combine channel-based modulation methods with signal evolution modeling.

You et al.19 analyzed Next Generation Air Traffic (NGAT) technology development through three different research perspectives. The article starts by presenting an overview of new-field NGAT technology which establishes its progression from traditional far-field channel models to modern near-field channel models. The text then discussed three new NGAT technologies which include reconfigurable intelligent surfaces and flexible antennas and holographic multi-input multi-output MIMO systems together with their respective design difficulties. The study presented recent developments in semantic-aware NGAT technologies which created new evaluation standards for advanced transceiver architecture. The research team discovered several new transceiver technologies which must be investigated by future researchers. The study focuses on architectural development patterns but it does not provide an operational adaptive framework which combines modulation management with ongoing signal analysis. Proposed methodology

The demand for high-speed and low-latency networks which operate at optimal spectral efficiency has increased because 6G systems require these networks to handle massive data transmission and advanced edge technology. The current DSP solutions which were developed for 5G systems do not provide the required adaptability because they cannot handle the variable digital communication patterns which 6G systems will experience. The design of current DSP systems requires specific hardware components and fixed signal processing paths which limits their effectiveness in situations where both modulation patterns and channel conditions and AI networking methods will be used. Real-time DSP-based 5G receivers have been successfully implemented on hardware platforms yet they still lack the capability to adapt their operation when faced with unexpected signal alterations. The low-complexity DSP systems which power LAN-WDM and IM-DD front-haul systems maintain high operational efficiency despite their design limitations which prevent them from adapting intelligent systems. The absence of a self-optimizing modular DSP framework which operates independently of hardware components and can adapt to 6G system changes through real-time optimization remains a fundamental research obstacle.

The existing DSP frameworks which depend on specific hardware resources and require minimal system requirements create restrictions which need to be removed for developing 6G signal processing systems. The new technologies which include terabit-scale LAN-WDM fronthaul and AI-assisted modulation recognition and dynamic spectrum access need DSP systems which can handle shifting conditions instead of using fixed processing systems and dedicated hardware. The previous research achieved high-speed transmission through simple DSP systems which used flexible modulation approaches, yet their performance remained limited because their systems depended on unchangeable designs. The combination of software-defined radios with AI-native 6G networks creates a requirement for developing an intelligent DSP framework which operates across different hardware platforms and includes built-in learning capabilities. The study presents ADaPT-6 (Adaptive DSP for Progressive Transceivers in 6G) as a software-defined DSP system which automatically adjusts to changes in channels and system performances to meet the needs of high-speed transmission and dynamic signal processing capabilities. ADaPT-6 contains two main components which operate as FlexiTune Modulation Adaptation (FTMA) real-time modulation scheme optimization system and Signal State Evolution Engine (SSEE) predictive engine that uses learning to automatically modify filtering and equalization and synchronization settings. The framework conducts its evaluation through testing under simulated 6G fronthaul conditions and through its separate modules which include FTMA and SSEE while its performance results compare against current DSP architectures through measurements of spectral efficiency and flexibility and power consumption and BER, which results in a proof-of-concept intelligent DSP stack suitable for future 6G networks.

System model

The proposed ADaPT-6 (Adaptive DSP for Progressive Transceivers in 6G) framework considers a software-defined transceiver which operates under highly dynamic 6G fronthaul and access channel conditions. Let the discrete-time baseband input signal be represented as:1x(t)=s(t)*h(t)+n(t)where s(t) denotes the transmitted digitally modulated signal, h(t) represents the time-varying wireless channel impulse response, and n(t) is additive white Gaussian noise (AWGN). The channel is assumed to exhibit rapid fluctuations due to mobility, multipath fading, bandwidth variation, and environmental dynamics, making static DSP pipelines ineffective. As illustrated in Fig. 1, the received signal is processed through a software-defined DSP chain consisting of adaptive filtering, equalization, synchronization, and modulation control blocks. The ADaPT-6 system introduces its adaptive system for signal processing through its loop system which uses real-time channel information and signal state forecasts to adjust its operation. The system continuously monitors channel state information and signal quality indicators like SNR and BER together with environmental context information which it sends to the control modules that learn through their training. The system comprises two distinct units that operate together as one functional system through the connection between FTMA and SSEE. FTMA uses instant channel data and future signal patterns to choose the best modulation method while SSEE uses temporal signal and channel state data to adjust DSP system settings. The system operates through a software-defined DSP layer that works with any hardware system which enables users to change the system without needing to modify their physical equipment. The ADaPT-6 system model enables the system to automatically adjust its transceiver settings in real time which helps maintain reliable operation with better spectral efficiency and protection against unexpected channel changes. ADaPT-6 (Adaptive DSP for progressive transceivers in 6G)

ADaPT-6 functions as a software-driven framework for digital signal processing which enables 6G communication systems to operate under changing wireless transmission conditions. ADaPT-6 uses a modular design approach which allows its system components to operate with any hardware platform and enables users to change processing settings based on real-time channel and system performance changes. The framework integrates two core components, FTMA and the SSEE, to jointly perform adaptive modulation control and predictive signal state adjustment. ADaPT-6 uses continuous physical-layer feedback to dynamically change its modulation and filtering and equalization and synchronization settings which results in improved performance for high-speed and low-latency 6G transceiver operations.

Signal state evolution engine (SSEE)

The increasing usage of machine learning technology for channel prediction work has produced better results since artificial intelligence technology made rapid progress during the last several years. The methods develop into two groups because they use different amounts of artificial intelligence technology: The first method improves existing real-time systems through artificial intelligence-based solutions which treat system deficiencies. The second method uses an end-to-end system that eliminates physical modeling through the implementation of neural networks. The automatic calibration process for electromagnetic parameters uses artificial intelligence technology for its operation. The material properties of the study area undergo calibration through gradient-based techniques which produce models that use neural networks. Deep neural networks create three-dimensional environmental models which include electrical data obtained from point cloud information. The researchers developed a super-resolution (SR) model which predicts cluster patterns with their respective CIR results. The NN models use extensive datasets to forecast path loss by using environmental data and transceiver location information without needing real-time algorithms.

AI technology improves RT system performance through its ability to enhance operational efficiency which enables systems to operate in various environmental conditions. The two methods both operate within certain boundaries of their respective systems. The first method needs physical models to operate because it depends on established scientific equations to create simulations that model actual radio wave transmission patterns through three-dimensional space but the system still faces challenges with accuracy because the simulated results do not match real-world conditions. The system maintains low performance in difficult real-time situations even after multiple acceleration methods have been tested. The standard RT method uses traditional techniques which do not allow it to adjust its operations based on different environmental conditions or work requirements through self-optimization processes which results in operational constraints. The second method depends entirely on data but it fails to consider physical principles which demand substantial amounts of high-quality training data to function effectively. The system shows low interpretability because it operates as a “black box” system. The current AI models present as compact solutions which handle specific tasks and they demonstrate limitations to their capacity for broader applicability.

The Signal State Evolution Engine (SSEE) is designed to predict future channel and signal states and adapt DSP parameters proactively, enabling robust transceiver performance under dynamic 6G environments.

These parameters are applied to dynamically reconfigure the software-defined DSP chain for improved signal reconstruction and reliability.

The FTMA system and SSEE system operate as separate entities until their total output reaches a main control center for system unification. The FTMA module uses present signal characteristics to select the best modulation method whereas SSEE forecasts upcoming channel conditions and produces optimal DSP settings including filter coefficients and equalizer taps and synchronization thresholds. The coordination unit uses its output control system to establish matching patterns between modulation signals and signal processing equipment. The decision system uses this determination to modify the software-defined DSP chain through dynamic reconfiguration which enables automatic switching between various channel conditions.

Integration of FTMA–SSEE

The FTMA and SSEE modules operate in a coordinated closed-loop framework to enable adaptive transceiver control under dynamic channel conditions. The SSEE first predicts the future channel state and corresponding SNR, which is provided to the FTMA module for proactive modulation selection. Based on this prediction, FTMA selects the optimal modulation scheme to maximize data rate while satisfying reliability constraints. Simultaneously, SSEE updates DSP parameters such as equalizer weights, filter coefficients, and synchronization offsets to minimize signal distortion. This joint coordination ensures real-time adaptation, improved reliability, and stable performance in rapidly varying 6G communication environments.

Discussion

The ADaPT-6 framework assessment tests the system’s ability to sustain efficient signal processing performance during various 6G communication condition changes. The experimental results show that fixed digital signal processing systems lose their ability to produce accurate results when they encounter various wireless signal conditions which become most troublesome during low and medium SNR scenarios. The FTMA-only approach and SSEE-only approach both show performance enhancements through their partial adaptive capability, but both methods establish restrictions because they function in separate modes. ADaPT-6 system design is adaptive modulation and predictive state evolution of the signal state to allow digital signal processing chains to make decisions based on the current and future channel variations. The evaluation indicates that ADaPT-6 keeps its errors rates at any SNR values which yield improved performances than conventional DSP systems. This process of joint adaptation proves to be better as it has been shown to be better than the fixed methods and optimization methods which have weak relationships. The adaptive modulation element identifies the appropriate modulation formats that contribute to the effective spectral management and the signal state evolution mechanism improves the receiver processing via continuous improvement that leads to improved performance of detection and reduced error transmission. The CDF analysis of BER yields other results as they indicate that ADaPT-6 improves average performance along with performance reliability by improving performance variability. The change of the CDF curve to the left indicates that the end-users will record a lower BER since the suggested framework will be more consistent in terms of performance compared to its competitor strategies. This feature is necessary in the 6G use cases that rely on ultra-reliable low-latency communications as these must deliver service of the same quality at all times. The obtained evaluation outcomes contrasting ADaPT-6 with fixed 5G DSP, IM-DD DSP, SDR-based DSP, and AI-assisted DSP systems illustrate that ADaPT-6 is more effective and needs a smaller amount of computing power. The intelligent adaptive design of the proposed framework enables better throughput, energy efficiency and outage performance, while maintaining low processing requirements. The results of the study establish ADaPT-6 as a software-defined DSP solution which effectively meets the reliability and efficiency and adaptability demands of future 6G wireless systems. While the results demonstrate consistent improvements across multiple performance metrics, it is important to note that the evaluation is conducted under controlled simulation environments. Although the adopted channel models capture key characteristics of 6G fronthaul scenarios, they may not fully reflect all real-world impairments such as hardware non-linearities, synchronization errors, and environmental uncertainties. Therefore, the observed performance gains should be interpreted as indicative rather than absolute, highlighting the potential effectiveness of the proposed framework.

Conclusion

The research presents ADaPT-6, which serves as a new software-defined adaptive DSP framework designed specifically for upcoming 6G communication networks. ADaPT-6 uses FlexiTune Modulation Adaptation (FTMA) together with the Signal State Evolution Engine (SSEE) to create a system which allows real-time intelligent DSP chain adjustments according to changing channel conditions and system operational state. The proposed framework demonstrates better performance than fixed and partially adaptive DSP systems because it maintains system reliability and robustness across all observed SNR conditions. The BER–SNR trends together with CDF analysis and complexity–performance trade-off evaluation show that joint adaptation together with predictive intelligence functions as an essential technology for achieving high-performance 6G front haul and wireless links. ADaPT-6 achieves performance improvements through its hardware-agnostic design which maintains computational efficiency thus making it ideal for use in upcoming programmable transceiver systems. The test used parameter values which covered an SNR range from 0 to 20 dB with EVM assessed in percentage (%), ACLR measured in decibels (dB), average throughput evaluated in Mbps, latency calculated in milliseconds (ms), and energy efficiency determined in bits per Joule. The study demonstrates several strengths but also shows specific research limitations. First, the evaluation uses simulation-based channel models to assess performance although these models fail to represent all hardware defects which exist in actual deployment conditions. The learning components of SSEE use predefined training datasets for their operations but their performance decreases when facing extreme testing situations which involve unknown channel conditions. The system suffers from latency issues which result from the continuous model updates and feedback loops although the latency time remains low because the system was not designed to achieve ultra-low-latency performance. The upcoming research work will develop ADaPT-6 into a system that enables real-time hardware validation through SDR and optical fronthaul testbed assessments which test system performance under real-world limitations. The research team will investigate online learning and continual learning methods to enhance system performance during periods of rapid environmental changes. The research will examine cross-layer optimization which combines MAC layer feedback with network layer feedback and develops energy-efficient and security-efficient DSP systems to improve the overall functionality of ADaPT-6 for comprehensive 6G system development.
