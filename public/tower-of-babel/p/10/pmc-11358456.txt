Computer vision based cargo boxes pose adjustment system for two-dimensional conveyor platform
Authors: Kai Liu, Hui Zhang, Zhiguo Zhou, Jian Zhou, Linhan Ma
Published: 2024

ABSTRACT
AbstractFor enhancing the accuracy of cargo box position and angle recognition on the conveyor platform, this paper proposes a cargo box attitude detection and adjustment method based on instance segmentation and image processing. This approach involves generating Mask data through target detection of the cargo box using Mask R-CNN. Using image processing algorithms to generate a minimum rectangle according to the Mask data, and the minimum rectangle data is aligned with the Bbox data of Maks R-CNN. The position and angle of the cargo box are detected based on the minimum rectangular data, and the conveyor platform is adjusted to control the cargo box attitude using the Bbox data. Nine attitude acquisition and comparison experiments were conducted on the cargo box using an angle sensor, and the deviation of the method was consistently <0.6∘, with a relative error of 1.27% for the nine total changes. Importantly, the image processing technique in this study avoids external image processing, reducing ambient light impact and enhancing cargo box recognition and attitude feedback functionality on the conveyor platform. Throughout the entire cargo box adjustment experiment, the cargo box’s can be stabilized to reach the set angle.Subject terms: Electrical and electronic engineering, Engineering

Introduction

The surge in sorting cargo boxes across various logistics enterprises, driven by the advancements in industrial automation and the rising standards of living1, has necessitated a reevaluation of traditional linear conveyor belt systems. These systems face limitations such as fixed lines, lack of attitude adjustment capabilities, and complete shutdown in case of failures. Consequently, linear conveyor belt-type conveyor platforms are no longer sufficient to meet the evolving demands of the current scenario. As a solution, intelligent material transfer platforms are gaining significant attention from both governments and enterprises2,3.

Researchers have investigated a variety of multi-module cooperative conveyor platforms and found that they all rely on the gravity of the cargo and multiple rolling wheels underneath the cargo to realize the conveyor operation of the cargo. Multi-module cooperative operation of conveyor platforms was first proposed in a study4 in 2009, which proposed a cellular conveyor called “Flexconveyor”, which proposed a decentralized control system for a modular transport system, where each module is equipped with RF-ID (Radio Frequency Identification) and proximity sensor for detecting the position of the goods on the conveyor platform. Keek et al. proposed an E-pattern omni wheel cellular conveyor (EOCC), which still uses a modular design and uses a camera as a feedback sensor for detecting the cargo, which improves the feedback system and increases the accuracy of the control system5. BIBA developed an omnidirectional wheeled conveyor platform called “celluveyor”, which is based on a modularized transport system using cellular conveyor technology6. The modularized transfer system is made up of modules assembled in a hexagonal shape fitted with three omnidirectional wheels. For the hexagonal conveyor platform, Sun et al. used infrared sensors mounted underneath each module to detect the position of the goods based on the celluveyor conveyor platform7. Bangal et al. used OpenCV image processing for machine vision to process the cargo to obtain the position and angle of the cargo to make the system closed loop8. The use of machine vision as a feedback system for the conveyor platform has improved the efficiency of the conveyor platform considerably, so research on how to improve the cargo identification and feedback system will help to improve the overall efficiency of the conveyor platform.

Cargo box attitude recognition and adjustment is a more important part in the process of cargo box transportation on the conveyor platform. The current method of applying machine vision to the conveyor platform is more focused on image processing technology, Zhou et al. studied a fusion algorithm based on point cloud and image processing technology, in which the image processing technology uses edge detection, Hough transform to find the longest straight line to obtain the angle; the point cloud technology is to obtain the angle from any edge line drawn from the point cloud through the iterative fitting mechanism of RAN-SAC9. Shishira et al. introduced a cargo detection system with feature extraction, which mainly obtains the angle of the cargo through image filtering, contour detection, ellipse detection, etc10. Anand et al. proposed an object position and attitude detection based on OpenCV, which mainly obtains the position of the cargo through edge detection and finding contours11. Although image processing techniques have achieved high accuracy in some scenes, image processing methods are prone to various drawbacks, such as image processing techniques are easily affected by ambient light when dealing with external images, so researchers designed a target detection model based on Convolutional Neural Networks (CNN) to address the limitations of image processing12,13. There have been researchers applying deep learning in the field of conveyor platforms, El-sayed et al. studied two systems based on image processing techniques and deep learning14, the system based on image processing is mainly used to calculate the angle of the cargo and tracking the cargo position through feature detection and threshold segmentation methods, and the target detection system based on deep learning is mainly used for tracking the position of the cargo but cannot perform angle detection. Although both systems show high accuracy in some scenes, they are still not able to get rid of the limitations of image processing in detecting the angle of the cargo in the conveyor platform.

This paper investigates the accurate identification of angles and the adjustment process for a cargo box on a two-dimensional transfer platform during transportation. A novel two-dimensional transfer platform is introduced, specifically designed for the transportation and adjustment of cargo boxes. Regarding the attitude recognition of the cargo box, we propose a method that combines instance segmentation and image processing to acquire and adjust the pose of the cargo box. In this approach, the image processing technique is not directly engaged in the processing of external images, thereby minimizing the impact of ambient light and overcoming the limitations associated with image processing techniques.

Conveyor platform mechanical structure and control system

Mechanical structure design

In this paper, we present the design of an orthogonal omnidirectional wheeled transfer platform featuring a modularized structure. This design not only offers enhanced convenience for post-inspection and replacement but also significantly improves transfer efficiency. Each modular unit is equipped with 1 controller and 9 motors. Each of these 9 motors is fitted with 9 omnidirectional wheels, each having a diameter of 60mm and a mounting angle of either 0 or 90 degrees. The prototype comprises 20 modular units, totaling 180 omnidirectional wheels. Figure 1 illustrates the mechanical design of the conveyor platform.

Mechanical structure design of the conveyor platform.

In the design of omnidirectional wheel distribution, we begin by drawing a circle with a radius of 100mm. The left and right positions of the omnidirectional wheel are placed vertically within this circle, while the upper and lower positions are arranged horizontally, as illustrated in Figure 2a. When the four omnidirectional wheels move in a circle at the same speed, they generate the same angular velocity, causing the cargo box above to undergo identical circular motion.

(a) Omnidirectional wheel circular distribution design diagram (b) Omnidirectional wheel overall distribution design diagram.

To achieve higher transfer accuracy, the omnidirectional wheels at the center of each circle are deliberately staggered both horizontally and vertically, as shown in black in Fig. 2b. The omnidirectional wheels at all four corner locations of the circular outer rectangle are placed longitudinally, depicted in orange in Fig. 2b. This configuration ensures that each omnidirectional wheel consistently finds another wheel that is orthogonal to it. Such an arrangement not only preserves transportation flexibility but also facilitates cargo adjustment.

As shown in Fig. 2b in green, additional longitudinal omnidirectional wheels are added at the inbound cargo end (upper side) to push the cargo box inside the platform. Orthogonal omnidirectional wheels are also added on both sides to prevent the cargo box from inclining during longitudinal movement at the boundary position. This setup allows for easy lateral movement to push the cargo box into the platform.

Control system design

Within the control unit, an STM32 microcontroller serves as the control chip, and a motor driver chip with the model number A4950 is used to control the motor. Given the limited interfaces in the microcontroller, two distinct analog switch chips are utilized in this study. They are applied to extend the encoder input and PWM output, respectively.

The control unit adopts a master-slave control mode with CAN communication. In this configuration, the master controller receives information from the host computer and issues commands to the slave controllers. These commands instruct the motors to execute the necessary actions for the transportation and adjustment of the cargo box. Figure 3 illustrates the circuit diagram of the module control unit.

Module control unit.

This study employs a centralized control system, connecting 20 module units through CAN communication. In the following sections, the controller used for each module unit is collectively referred to as the “Module Controller”, and a single CAN host is used for control, referred to as the “Master Controller”. Utilizing control based on omnidirectional wheels, each omnidirectional wheel is not specific to a module unit, and the speed of each omnidirectional wheel is independently calculated from the other omnidirectional wheels within the module, as illustrated in Fig. 4. Each omnidirectional wheel is assigned a corresponding Module ID (MID) and Motor ID (OID), as depicted in Figure 5.

Mask R-CNN object detection and processing of mask data

Mask R-CNN consists RPN and Fast R-CNN two stages. To facilitate the batch input of differently sized RoI feature maps extracted by RPN into the subsequent R-CNN, a RoI Pooling layer is introduced between these two stages. This layer ensures that feature maps of arbitrary sizes can be transformed into specified output sizes15. Mask R-CNN introduces a corresponding ROIAlign strategy to address issues like pixel bias present in the original algorithm. Additionally, with the precise pixel MASK of FCN, it becomes possible to achieve high accuracy16. The structure is illustrated in Fig. 11.

Mask R-CNN algorithm framework.

Deep learning techniques are used in computer vision for the detection of objects for cargo box position and angle acquisition. The dataset in deep learning is 300 RGB images intercepted from the video capturing the movement of the cargo box on the conveyor platform, and the annotation work on the dataset is carried out using Labelme, which is an open source and free annotation application. 80% of the dataset is randomly selected as a training set and 20% as a test set. Subsequently, this dataset is used to train the Mask R-CNN deep learning model. During the training phase, RGB images with a resolution of 1024x1024 pixels are input, and the model is trained for 80 epochs.

The curve illustrating the change in model accuracy and loss rate with training iterations during experimental training is shown in Fig. 12. From Fig. 12a, it can be observed that the accuracy reached 99.48% after 10 training iterations, and further increases in training iterations result in minimal improvement in accuracy. Figure 12b shows that the loss was 0.096 after 15 training iterations, continuously decreasing and quickly converging. These training results signify that the model obtained from this training is effective and performs well for cargo box recognition.

(a) Accuracy recognition curve (b) Model loss variation curve.

The coordinates described in the following text are pixel coordinates, where the origin is at the top-left corner of the image, with the x-axis pointing right and the y-axis pointing down.

Mask R-CNN generates an array of results (RS data) for the candidate region, providing two key pieces of information. The first set of details includes the coordinates (top-left and bottom-right) of the red Bbox rectangle, as depicted in Fig. 13, along with the corresponding confidence level. The second output is the Mask data for the target, visually represented by the white masked area on the cargo box in Fig. 13. The Mask data denotes pixels that are masked by Mask R-CNN for the regions of interest, where True corresponds to pixels requiring masking, and False corresponds to pixels not needing masking.

Recognition results and output data of Mask R-CNN.

In the object detection program, the generation of some noisy images with low confidence is inevitable. To mitigate this issue, we filter out the Bbox positive rectangular box information and Mask data associated with candidate regions exhibiting low confidence from the obtained RS data. Subsequently, the two components (Bbox positive rectangular box information and Mask data) are stored separately.

In this paper, the cargo box’s angle is determined through individual processing of Mask data. The process involves utilizing image processing techniques to avoid spatial redundancy within the image. A pure black canvas, matching the original image’s pixels, is created. Subsequently, the Mask data is overlaid onto this black canvas, and further image processing is applied to grayscale and binarize the composite image, resulting in the Mask image. Rotating calipers algorithm for obtaining the minimum rectangle

From the obtained Mask image, the minimum rectangle is derived, and the angle of this minimum rectangle represents the actual angle of the cargo box. Figure 15 illustrates the steps for obtaining the minimum rectangle using a polygon as an example. Initially, the original image is processed, as depicted in Fig. 15a, to acquire four initial points. These points are shown in Fig. 15b after the acquisition. The counterclockwise direction is chosen for the rotation, and the rotation angles of the four initial points with respect to the coordinate axis are calculated and labeled as a∘, b∘, c∘, and d∘, as shown in Fig. 15c.

Steps for obtaining the minimum rectangle, using a polygon as an example.

Next, the minimum angle, denoted as a, is selected, and the positive rectangle is rotated by a∘. This ensures that the sides of the polygon and the positive rectangle become co-linear, as illustrated in Fig. 15d. Following the principle that, in the polygonal minimum rectangular box, at least one side of the polygon coincides with the minimum rectangle, the state meets the conditions for generating the polygonal minimum rectangle, and the area of the rectangle is calculated. At this stage, assuming A(xa, ya), B(xb, yb), C(xc, yc), D(xd, yd), and the proximal point coextensive with A is noted as A′(xa′,ya′). Let the vector AA′′ be perpendicular to the vector AA′, as shown in Fig. 15e. The height h is equal to the length of the projection of the AC vector onto the AA′′ vector.

In Fig. 15e, the width w can be obtained by projecting vector DB onto vector AA′.

Calculate the area of the rectangle, then rotate the rectangle counterclockwise to align it with the next edge, calculate the new area, and record it. Repeat the above steps until all edges are examined. Compare and find the rectangle with the minimum area, which is the minimum rectangle.

Finally, following the above approach, obtain the minimum rectangle from the Mask image and draw it onto the original image. The recognition results are shown in Fig. 16, where the green box outlines represent the found minimum rectangle, referred to as the rotation box in the following text.

The coordinates of the four corners of the rotated bounding box have been determined in the above steps. To obtain the angle, it is only necessary to obtain the angle of the longest side. Due to the parallel and equal characteristics of the opposite sides of the rectangle, compare the lengths of the adjacent two lines, identify the longest side of the cargo box, and calculate the initial angle θ. Cargo box attitude adjustment

When the cargo box needs to adjust the angle, from the width (w) and height (h) of the Bbox positive rectangle box, the Bbox positive rectangle box is divided into a 3*3 grid by h/3 and w/3. It can be divided into four regions, which are upper region, lower region, left region and right region. The region division and the omnidirectional wheel data of each region are shown in Fig. 22.

Omnidirectional wheel information for the bottom four regions obtained from cargo box image data.

The upper computer sends the cargo box angle information (message 1) and the MID and OID of the omnidirectional wheels of the four regions (message 2) to the master controller through serial communication. When the cargo box is adjusted, it is controlled according to the message 1 and message 2 to realize the adjustment angle by differential control based on the opposite rotation of the omni-directional wheels of the relative areas, as shown in the flow chart of the cargo box attitude adjustment in Fig. 23.

Conclusions

This paper uses the combination of Mask R-CNN instance segmentation and image processing algorithms to obtain the position and angle of a cargo box in a conveyor platform. Only the Mask data of Mask R-CNN is processed by the image processing technique which avoids the directly process of the external image. First, the minimum rectangle is recognized according to the Mask data, aligning it with the Bbox data of Mask R-CNN. Second, the cargo box position and angle are detected based on the minimum rectangular data, and the conveyor platform is adjusted to control the cargo box attitude based on the Bbox data. At present, the existing conveyor platform for the cargo box angle recognition method is through image processing techniques such as Hough variation, edge detection, etc., but the ambient light on this cargo box angle detection method has a great impact. This method effectively reduces the influence of ambient light, and when the environment changes drastically, the detection accuracy can be improved by increasing the size of the training data set. In addition, if different types of crates need to be recognized, it is only necessary to add the crate data to the dataset. The cargo box angle recognition method proposed in this study has low complexity, wide adaptability, high accuracy, and practical applicability value. In future research, we plan to based on the conveyor platform proposed in this study, introduce the path planning algorithm to transport the cargo box from the starting point to the goal, and adjust the angle of the cargo box according to the real-time angle of the cargo box in the process of transportation, so that the cargo box can be transported to the target point with a fixed attitude.
