CLOVER: An analysis protocol for visualization and identification of cell clusters through cluster overlaying for imaging mass cytometry
Authors: Suthicha Kanacharoen, Sarah M Shin, Yanyi Sun, Courtney D Cannon, Laura D Wood, Won Jin Ho
Published: 2026

ABSTRACT
SummaryImaging mass cytometry (IMC) enables spatial single-cell analysis on formalin-fixed paraffin-embedded (FFPE) sections. Here, we present a protocol for visualizing and identifying cell clusters through cluster overlaying of IMC data. We outline steps to source and preprocess images, compile and format data frames, and generate cluster-specific overlays in a high-throughput manner. We then describe procedures to composite these overlays onto corresponding reference images and export finalized visualizations. This workflow integrates high-dimensional data with ground-truth tissue images to support more accurate cell-type classification within tissue microenvironments.For complete details on the sample data used for the execution of this protocol, please refer to Bever et al.1Subject areas: Single Cell, Mass Cytometry, Cancer, Immunology, Microscopy

Before you begin

This protocol describes a computational imaging visualization pipeline, CLOVER, which overlays cell clusters onto corresponding reference images such as pseudo-colored representative images exported from MCDViewer, ImageJ/Fiji, or QuPath. This allows users to spatially confirm cell identities, annotate clusters, and visualize spatially resolved expression of specific markers.

The preparation for analysis and visualization of unsupervised cell clusters based on specimen stained with imaging mass cytometry (IMC) requires the following major steps.

Prior to staining, ensure that IMC antibodies for cell segmentation are included to enable accurate cell segmentation and downstream single cell analysis. For this protocol, FFPE slides were stained with Iridium 191 and 193 (intercalator) for 45 min at room temperature or nuclear stain. 195, 196, and 198 pan-membranous cocktail antibodies (Standard BioTools) were added to a customized IMC antibody panel to broadly capture as much membrane staining as possible. If cells with asymmetrical morphology are anticipated, e.g., macrophages or fibroblasts, it is recommended to include appropriate antibodies for those specific cell types.

There are many ways to obtain reference images for cluster overlaying. An option is to generate pseudo-colored representative images from raw IMC data. The CLOVERef script provided in the CLOVER package can be run to efficiently batch-output representative images from 32-bit multi-channel OMETIFFs exported from MCDViewer.

Alternatively, a serial section adjacent to the IMC-stained slide can be stained with hematoxylin and eosin (H&E). For best spatial alignment, choose the nearest serial section (e.g., section 99 or 101 if the IMC-stained section is 100). Digitally scan the H&E slides through high-resolution whole slide imaging scanner. These files are then viewed using digital histology platforms such as Concentriq or Aperio ImageScope to generate reference images for downstream spatial validation.

After antibody staining, slides are acquired by either Hyperion or Hyperion XTi, and the raw data is saved in.mcd format. Following acquisition, cell segmentation can be performed using established pipelines such as Mesmer2 or ImcSegmentationPipeline.3

Segmented data for each ROI should include a unique cell ID, expression values for all IMC markers, and spatial X and Y coordinates. The data can then be clustered using unsupervised methods such as PhenoGraph4 to generate unannotated cell clusters (Figure S1A). Use these outputs to generate spatial CLOVERPlots of either unannotated or annotated cell clusters. Through CLOVERLayer, overlay CLOVERPlots onto the corresponding source images to produce a final CLOVERLayer image stack.

In the ‘before you begin’ section below, we also provide simplified instructions for one of the publicly available standard cell segmentation and clustering workflows. A detailed end-to-end workflow has previously been covered.3 This protocol is applied to raw.mcd files acquired via Hyperion. Although the focus of this protocol does not include IMC staining, a detailed IMC staining protocol that was utilized to generate our example data, including all relevant reagents and storage conditions, can be referenced.5,6 Additionally, all antibodies used to stain the samples in our example data are listed in a previously published manuscript.1 The remainder of the current protocol details the CLOVER visualization pipeline.

Innovation

CLOVER provides a simple and accessible workflow for spatial visualization and evaluation of Imaging Mass Cytometry (IMC) data. The method combines custom ImageJ macros and R scripts to generate spatial cluster overlays from IMC datasets without requiring proprietary software or high-performance computing resources. Because the workflow uses only ImageJ and R – both free and widely available programs – it can be easily implemented by laboratories and collaborators who may not have access to licensed image analysis software. The computational requirements are low, allowing the pipeline to run efficiently on standard desktop computers.

The CLOVER pipeline is organized into sequential scripts that pass outputs directly to the next step (CLOVERef → CLOVERPlot → CLOVERLayer). This structure reduces the need for manual file handling and minimizes user error from moving or renaming files. Batch processing allows regions of interest (ROIs) across the entire dataset to be processed simultaneously, converting tasks that normally require several hours of manual work into a process that can be completed in minutes while maintaining consistent processing and minimizing human error.

In addition to improving workflow efficiency, CLOVER assists with interpretation of clustering results. Spatial overlay plots allow investigators to examine unlabeled clusters in their histological context, helping identify likely cell identities and detect potential clustering or segmentation errors. Because the visualization is based on IMC data compiled into a single dataframe, users can easily filter any subset of cells, including specific subclusters, marker-defined populations, or cells filtered by morphological or neighborhood features. This allows quantitative findings to be evaluated directly against tissue architecture, improving confidence in spatial analyses.

Expected outcomes

The CLOVER pipeline provides a user-friendly script and macro that efficiently batch-processes and overlays single-cell spatial coordinates derived from imaging mass cytometry onto adjacent source H&E or MCD images in two steps.

Firstly, the CLOVERPlot R script (CLOVERPlot.R) processes IMC data and generates a cluster plot containing dot overlays marking the identity and location of cells for each cluster. Cluster plots for unannotated or annotated cell clusters within the same ROI are saved together in a single folder.

Secondly, the CLOVERLayer macro (CLOVERLayer_AnnotatedClusters.ijm or CLOVERLayer_UnannotatedClusters.ijm) combines the cluster overlays from the CLOVERPlot folder (Figure S2A) with the images in the ‘Source’ image folder (Figure S2B) and exports, for each ROI, a stacked CLOVERLayer TIFF in which each unique cluster plot is overlaid on the source image. The user can export the final CLOVERLayer image to any chosen folder, such as ‘Output’ (Figure S2C).

Limitations

There are several upstream limitations to consider when applying the CLOVER analysis pipeline for IMC-based single-cell analysis and spatial visualization of cell types. A critical determinant is the quality and accuracy of cell segmentation for downstream single-cell analysis. Though this is not a direct limitation of CLOVER itself, poor cell segmentation may limit the accuracy and findings relevant to single cell analyses and may weaken the project as a whole. However, in these cases, CLOVER would help to visually highlight whether cluster inaccuracies stem from improper cell segmentation and/or technical artifacts during IMC staining (Figures S1B and S1C).

In addition, the user should consider which cell segmentation pipeline would be most applicable and beneficial for their project. As the first-pass option, we generally recommend using pre-trained Mesmer algorithm2 to segment cells. However, when focusing on cell types known to have asymmetrical borders, such as myeloid cells and fibroblasts, we recommend ImcSegmentationPipeline3 as it allows for extensive manual training. Accurate cell segmentation is also highly dependent on the quality of pan-membranous and nuclear staining. Incomplete or weak staining of the cell membrane or nucleus can result in poor segmentation boundaries, leading to inaccurate identification of individual cells.

Another upstream limitation may involve misalignment between H&E-stained tissue sections and IMC-stained sections. This misalignment can result from differences in rotational axes, poor cropping alignment, or a distant serial H&E-stained section. It is therefore most ideal to stain H&E on an adjacent serial slide of the IMC-stained section. Other environmental or technical factors separate from the CLOVER pipeline, such as tissue folding or nonspecific staining of IMC markers, may interfere with both staining quality and cell clustering. It is recommended to spatially “gate out” technical staining artifacts as it may skew the clustering of the dataset. Users should conduct rigorous quality control at each stage, including IMC antibody validation, verifying ablated.mcd images, and generating segmentation masks, to ensure the biological accuracy of clustering results.

The CLOVER analysis pipeline also has several direct limitations within the FIJI macro, CLOVERLayer.ijm. Due to FIJI’s inherent color limitations, the macro supports a maximum of seven overlay colors, meaning that composite (ALL) images work best when less than seven clusters are stacked. Additional limitations include dot visibility on cluster plots – reference images with a largely white background may cause cluster plot dots to blend in. Furthermore, the file naming of ROIs should be exact and consistent with the ROI naming used in data_full, otherwise CLOVERLayer.ijm will error out. A common mistake is the addition of a space ( ) within the source image file name, which will cause an error that may be overlooked. The cluster order in CLOVER image stacks in “CLOVERLayer_UnannotatedClusters.ijm” and “CLOVERLayer_AnnotatedClusters.ijm” is fixed to a numerical and alphabetical order respectively and does not support a custom cluster order. Finally, the CLOVER analysis pipeline is intended to be used as a qualitative validation tool and to visually confirm quantitative findings.

Troubleshooting

Problem 1

Weak or absent pan-membranous staining (before you begin: Step 5).

Potential solution

If pan-membranous markers stained weakly or were missed, a broader cocktail of membrane antibodies can be used to increase segmentation accuracy. At a post-acquisition stage, multiple membranous markers may be combined (e.g., Pan-Keratin, CD68, CD45, PM2/3/4) into a single-color channel in MCDViewer to maximize membrane detection during segmentation.

Problem 2

Batch effects or variable staining across ROIs (before you begin: Step 13).

Potential solution

The staining and expression levels of IMC antibodies may be highly variable across different specimens, samples, or ROIs based on technical factors. Depending on the context of the analysis, it may be preferable to cluster ROIs separately. Alternatively, batch correction algorithms used for single-cell analysis may be employed as described previously.3

Problem 3

Unannotated cell clusters contain high expression of canonical markers of multiple cell types (before you begin: Step 14).

Potential solution

Ambiguous clusters, such as clusters showing canonical markers for multiple cell types, can be further subclustered to improve cluster resolution and better delineate cell phenotypes. A list of specific canonical markers will need to be included for subclustering. For example, a cluster that is seemingly positive for both granulocytic and macrophage markers could be further subclustered using a more limited set of markers that includes CD15 and CD68; guided subclustering may help distinguish cell subtypes expected in a given dataset.

Problem 4

Poor alignment of H&E-stained reference images with IMC-stained ROIs (Step-by-Step Method: Step 1).

Potential solution

Misalignment between H&E-stained reference images and IMC-stained ROIs can arise from multiple factors. These may include rotational axis discrepancies between tissue sections, poor manual cropping, or a distant serial H&E-stained section. Computational co-registration offers a more robust alternative compared to manual alignment of different tissue sections. Open-source tools such as PIVOT9 provide this computational ability for multi-modal and serial section registration.

Problem 5

There are multiple ROIs with different size dimensions within the same project (Step-by-Step Method: Step 15).

Potential solution

There may be multiple ROIs of different size dimensions within the same project. CLOVERLayer.ijm will alert the user if there is a size mismatch between the inputted size dimension and the batch of ROIs the user will run. If any ROIs differ from the inputted dimensions, CLOVERLayer.ijm will automatically skip them and generate a list identifying the skipped ROIs. In such cases, users can run the CLOVERLayer.ijm multiple times, once for each unique set of size dimensions. The resulting CLOVER image stacks can be exported into the same output folder as other ROIs.

Problem 6

CLOVERLayer.ijm encounters a “file not found” error when running and reports the error as the name of the first overlay generated by CLOVERPlot.R (Step-by-Step Method: Steps 12–13).

Potential solution

This error is due to a mismatch in naming between the source image (IMC representative image or H&E) and folder generated by CLOVERPlot.R. Inspect the Output folder generated by CLOVERLayer.ijm to find the last file name before the error and double-check the name of the corresponding source image in the source folder. A common error is a residual space within the file name (e.g., ROI1 .tiff instead of ROI1.tiff), which interferes with the file path matching. Rename the source image as appropriate, and re-run CLOVERLayer.ijm.
