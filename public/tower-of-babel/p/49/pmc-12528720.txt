Enhanced intrusion detection system IoT network security model by feed forward neural network and machine learning
Authors: Abdullah Mujawib Alashjaee, Fahad Alqahtani
Published: 2025

ABSTRACT
AbstractThe security of IoT networks has become a significant concern owing to the increasing count of cyber threats. Traditional Intrusion Detection Systems (IDS) struggle to detect sophisticated attacks in real-time due to resource constraints and evolving attack patterns. This study proposes a novel IDS that integrates deep learning (DL) and machine learning (ML) approaches to improve IoT security. The main objective is to develop a hybrid IDS combining Feed Forward Neural Networks (FFNN) and XGBoost to improve attack detection accuracy while minimizing computational overhead. The proposed methodology involves data preprocessing, feature selection utilizing Principal Component Analysis (PCA), and classification employing FFNN and XGBoost. The model is trained and evaluated on the CIC IoT 2023 dataset, which comprises real-time attack data, ensuring its practical relevance. The proposed model is estimated on the CIC IoT 2023 dataset, demonstrating superior accuracy (99%) compared to existing IDS techniques. This study provides valuable insights into improving IDS models for IoT security, addressing challenges such as dataset imbalance, feature selection, and classification accuracy. Results demonstrate that the hybrid FFNN-XGBoost model outperforms standalone FFNN and XGBoost classifiers, achieving an accuracy of 99%. Compared to existing IDS models, the proposed approach significantly enhances precision, recall, and F1-score, ensuring robust intrusion detection. This research contributes to IoT security by introducing a scalable and efficient hybrid IDS model. The findings offer a strong basis for future advancements in intrusion detection using DL and ML approaches.Keywords: Internet of things, Intrusion detection system, Feed forward neural networks, XGBoost, Cyber risksSubject terms: Mathematics and computing, Information technology

Introduction

In modern times, the IoT is defined as a network of interconnected computing de-vices that can share data via predefined protocols over the Internet. The IoT is a rela-tively new development that incorporates sensors and gadgets that are at the forefront of the domains of contemporary computing and communication. Currently, IoT sacri-fices security for its increased comfort and positive impact on human life. As an added bonus, hackers and intruders find this structure particularly appealing. Intrusion de-tection (ID) is the hardest thing to do in an IoT setting.

Nowadays, most computer networks implement IDS to monitor user behavior and automatically anticipate attacks by collecting and analyzing data1. Using cryptographic approaches for IoT security causes a lot of communication and processing overhead since IoT devices are resource constrained. The development and implementation of IDS may resolve this problem. Consequently, IoT contexts extensively employ IDS to detect imposters and ensure secure IoT communication2.

In an IoT network, an IDS main function is to identify along with report any devi-ation from the expected behaviour of the system. When something goes wrong with the system, anomaly-based IDS will raise alarms because they are constantly checking the normal profile. It generates a lot of false alerts but works well against unknown threats. Owing to the developments in ML, a number of solutions have emerged; these solutions are able to continuously learn as well as adapt to new environments3. Over the last several years, many analytical approaches have been suggested for visualizing and pa-rameterizing neural networks’ loss functions in the space indicated by their weights. Many sophisticated network topologies employ feed-forward neural networks (FFNNs) as a classifier to tackle different kinds of large-scale prediction and classification issues. Most intricate network designs include the feed-forward layer4.

The IoT may be genuinely omnipresent without actively seeking knowledge and data patterns, owing to ML, which enables it to glean hidden insights from the treasure trove of sensed data. Without widespread use of ML, the IoT will not be able to meet the demands of governments, organizations, as well as individuals in the future. In order to automate decision-making using intelligent approaches that resemble human deci-sion-making, the main objective of the IoT is to sense what’s going on. Only by applying ML to its gadgets the IoT become truly pervasive. It is possible that AI with human-like intelligence is based on ML’s pattern-finding tendency. This can learn more about the world by generalizing these patterns into useful insights as well as trends5. The ML real goal in the IoT is to achieve full automation by increasing learning, which in turn ena-bles intelligence through smarter things. Prior art IDS make the assumption that all IoT devices have the similar pattern of features as well as packet forms. In contrast, IoT devices differ in several ways. These include their computing capacity, the features they can generate, and the hardware features and functionality they provide6.

A vast array of networked objects, such as public facilities, wearable technology, drones, etc., make up the IoT due to the technology’s many potential uses. There are very serious security concerns, despite the fact that technology greatly improves the quality of life. Due to its massive size and intricate nature, the IoT network is notoriously dif-ficult to administer. When it comes to security flaws, IoT devices are easier targets than conventional networks7. One of the primary security mechanisms included in modern networks is IDS, which are able to detect attacks, illegal incursions, and negative activities inside networks. When an IDS detects unusual or out-of-the-ordinary behaviour on a host or network, it will notify the system administrator. While much work has been done, the IoT and dispersed networks are changing things. Errors are more likely to occur in more complicated networks. Insiders take benefit of their authorized access to the network to launch attacks, leaving little suspicious evidence behind. New attacks are continually being devised. Intelligent, data-driven systems will soon replace the older, more knowledge-based IDS. Instead of comparing traffic to a fixed signatures set as well as patterns, these systems should be able to study from data, see statistical regularities along with patterns, and spot intrusions that don’t fit with normal traffic8. Muhammad Sajid et al.9 proposed a method that used CNNs as well as Extreme Gradient Boosting (XGBoost) to do feature extraction and then used Long Short-Term Memory (LSTM) networks for classification. Recent developments in cloud computing, the IoT, and automotive networks have led to a rise in the data quantity sent via communication infrastructures. As communication technology advances, network systems communicate varied and heterogeneous data in distributed settings. The reliability and security of the information provided by network security systems are crucial to the communications and everyday interactions that rely on these networks. Mean-while, malicious actors are making more noise about their efforts to compromise net-work infrastructure. An IDS is crucial because new technologies bring with them new forms of attack and security flaws. To overcome these restrictions, they have built a hybrid model for ID that combines DL as well as ML approaches.

Louai A. Maghrabi10 suggested an Automated Network ID(NID) using the UNSW-NB15 dataset obtained from Kaggle and a well-known ML model called RF. NID systems notify system administrators of security breaches. An autonomous NID may better protect IoT networks against a variety of threats. Several ID methods exist; however, it is challenging to use them due to the dataset’s performance issues and class imbalance. An improvement in ID accuracy is necessary to raise detection rates while decreasing false alarms. This approach was used in an effort to accomplish this.

Priyanka Singh et al.11 put out a strategy for using feed-forward deep neural network (FFDNN) hidden layers to extract deep features. The extraction of deep characteristics from hidden layers signifies a dataset with improved generalizability for malware detection. They used the Gaussian error linear unit (GeLU) activation function to pass the deep feature from one hidden layer to the next. To train FFDNN, this work uses the GeLU activation function, which considers the combined deep features of all hidden layers along with the deep characteristics of individual layers. They train and test the ML classifiers in a similar manner, using both deep features from individual layers and concatenated ones. They also examined the highly effective ML classifiers, including RF, k-nearest neighbour (k-NN), trees as well as support vector machine (SVM). Using a huge dataset that is statistically significant, they show how well their model performs.

Ayoob Almotairi et al.12 created a stack classifier model for IoT data using heterogeneous ML. This model solved the problem of finding intrusions in the IoT, which can be hard to do. In order to study and improve critical classification metrics for ID of IoT data, the model uses ensemble modelling and feature selection. This method con-sists of two main parts: building an ensemble model using several classic ML models and using the K-Best method to select features (i.e., extracting the top fifteen most significant ones). By bringing these parts together, it may improve classification performance by using data from chosen characteristics and by combining the power of distinct models.

Jing Li et al.13 did a study to see how ML-based attack categorization frameworks compare selection for IoT network ID as well as feature extraction. It uses binary and multiclass classification to examine performance metrics on the Network TONNE-IoT dataset, which contains heterogeneous IoT devices, such as accuracy, f1-score, runtime, etc. Since there are fewer characteristics to work with in feature extraction, it outperforms feature selection in terms of detection performance. Furthermore, compared to selection, feature extraction exhibits less feature reduction and is less susceptible to variations in the quantity of characteristics. In contrast to its alternative, feature selection reduces the amount of time needed for inference along with model training. In addition, when the number of characteristics changes, there is greater room to enhance the accuracy of selection rather than extraction.

Hossein Asgharzadeh et al.14 developed FECNNIoT, an algorithm for IoT anomaly detection that utilizes feature extraction with CNN. They also developed BMEGTO, a binary multi-objective optimizer for Gorilla troops, to achieve feature se-lection. Finally, the introduction of a hybrid approach, CNN-BMEGTO-KNN, combines FECNNIoT with BMEGTO along with KNN algorithm-based classification techniques. The next stage was to apply it to TON-IoT as well as NSL-KDD datasets.

Alejandro Domínguez Campos et al.15 demonstrated how to analyze an IoT network in order to identify threats by using side-channel methods that track the de-vices’ power consumption. They demonstrate the use of a ML-driven monitoring system to detect intrusions while maintaining the regular operation of the devices. Several scenarios pass the tests, including custom-made datasets, models identifying novel at-tacks, and real-time testing. As mentioned in Table 1 though the existing works have several advantages such as better performance in terms of classification accuracy some limitations are identified.

Despite numerous IDS techniques, existing models face challenges including high computational complexity, low detection accuracy, and inefficiency in working with real-time attacks. Most existing works do not effectively integrate DL and ML for improved performance. Furthermore, class imbalance issues persist unaddressed, leading to biased detection. This research presents a hybrid model that overcomes these gaps by leveraging FFNN and XGBoost, attaining superior accuracy and real-time adaptability.

Dataset

The CIC IoT Dataset 2023, a relatively new dataset, serves as the foundation for the development of IoT security analytics tools21. This carried out seven types of attacks on 105 IoT devices: DDoS, Denial of Service (DDoS), Reconnaissance, Spoofing, Mirai, Web-based, and Brute Force. Malicious IoT devices launch these attacks on other IoT devices. By overpowering a single source with traffic, denial-of-service attacks impair services. Web-based attacks employ methods like XSS to target web applications as well as SQL injection. Brute force attacks attempt to gain unauthorized access via a series of trials. A spoofing attack is one that alters network traffic or pretends to be an entity. Last but not least, Mirai attacks use techniques such as UDPPlain along with GREIP Flood attacks, that target IoT devices. It also provides a comprehensive summary of network attacks, where the frequency of attacks is represented by the number of rows, as well as the types of attacks themselves are classified22.

Conclusion and future work

This research enhances IoT network security by developing a robust and scalable IDS capable of addressing the evolving landscape of cyber threats. A hybrid FFNN–XGBoost model is proposed that combines the deep feature learning capabilities of FFNN with the classification precision of XGBoost. Through systematic preprocessing, including class imbalance handling and PCA-based feature selection, the model achieves high detection accuracy, precision, recall, and F1-scores on the CIC IoT 2023 dataset. The findings show that dropout layers and L2 regularization effectively reduce the overfitting issue, while the resampling approach ensures balanced learning across attack classes. Comparative analysis is done with recent existing IDS models, which confirms the proposed method effectiveness with both binary and multiclass datasets. The implications of this work are twofold: it provides a scalable and adaptable IDS framework for real-world IoT deployments, and it demonstrates that combining DL with boosting-based classifiers can yield significant performance gains. Future research will focus on integrating k-fold cross-validation and early stopping to further enhance generalization, as well as extending the model to handle encrypted IoT traffic and real-time detection environments.
