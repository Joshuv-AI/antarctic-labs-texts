Protocol for stable isotope tracing of primary human peripheral blood mononuclear cells
Authors: Samantha N. Hart, Holden Williams, William B. Inabnet, Joshua P. Steiner, Varun Jain, Philip A. Kern, Cecily R. Wood, Barbara S. Nikolajczyk, Lance A. Johnson
Published: 2026

ABSTRACT
SummaryStable isotope tracing gives direct insight into the rate of metabolic reactions occurring in cells by analyzing the incorporation of labeled carbons into metabolic pathways. Here, we present a protocol for stable isotope tracing of primary human peripheral blood mononuclear cells (PBMCs). We describe the steps for culturing and exposing PBMCs to stable isotopes U13C glucose and U13C glutamine. We then detail procedures for derivatization, metabolite purification, and tracing analysis via single-quadrupole gas chromatography-mass spectrometry (GC-MS).

Before you begin

This protocol is intended for primary human peripheral blood mononuclear cells (PBMCs). This application is also appropriate for immune cell subsets i.e., CD4+ T cells, and other sensitive cells that grow in suspension. This protocol outlines the full workflow of stable isotope tracing PBMCs, from obtaining and processing fresh primary human samples to the downstream GC-MS analysis, encompassing cell culture and proper PBMC stimulation, stable isotope exposure, and final derivatization and metabolite extraction for GC-MS.

Innovation

Current published methodology for primary human immune cells requires a high-performance liquid chromatography-MS/MS system when using PBMCs. Here, we establish a complete protocol for simplified, entry-level metabolomic analysis of human PBMCs that allows for the use of more affordable MS systems. This protocol provides optimization of stable isotope tracing in a new sample type.

Institutional permissions

This protocol uses primary human immune cells from subjects with obesity ± Type 2 Diabetes; we strictly adhered to all GCP guidelines, and all work associated with this protocol was approved by the University of Kentucky Institutional Review Board (IRB) in accordance with the Declaration of Helsinki. Timing: 1–2 days (4 h to separate fractions, 4 h to dry samples, 2–3 h for derivatization, variable time for GC-MS run)

Expected outcomes

In this protocol, we analyzed key metabolic pathways in human PBMCs using stable isotope tracing via GC-MS. This approach allows for the analysis of 13C’s incorporation into metabolites of interest via fractional enrichment, which indicates the rate of metabolic processes. With this approach, multiple pathways can be investigated simultaneously (Figure 3). This protocol can detect > 60 metabolites, highlighting the usefulness of untargeted approaches; this is conducive to both exploratory experiments and adequate analyses of pathways of interest. A full list of metabolites detected through this protocol is provided in Table 1. The abundance of each peak for a metabolite’s fractional enrichment can also be added together to give the total abundance of that metabolite. Quantification and statistical analysis

Raw data from this study can be found in NMDR: ST004356.7 The raw data output of GC-MS analysis is in.CDF format. These files are then analyzed on Data Extraction for Stable Isotope-labelled metabolites (DExSI), a common software package used in this type of workflow.8 A reference metabolite library is first uploaded to DExSI. Baseline correction is applied, with structural element (min) = 1.5. The retention time window is set to a negative minimum = 0.2 and a positive minimum = 0.8. Peak detection is set to 1 point either side of apex, and a scan window = 1. Peak filtering is set to minimum library-defined ions per peak = 1 and minimum intensity cut-off = 1. CDF files are then extracted according to these specifications. The peak areas are confirmed for each metabolite by comparing the mass spectrum generated through this protocol against publicly available spectra.9 It is important to check the peak for each sample for every metabolite; left and right integration limits may need to be manually reset, and ions may need to be manually added to peaks. The observed retention time (RT) must be compared to the expected RT, and adjustments to which peak belongs to which metabolite may need to be made. After confirming the peaks for every sample for each metabolite, the data is exported in a.csv file.

Normalize data to 2IPM, the internal standard used, which is added at a known concentration in each sample and across runs. To normalize to 2IPM abundance, the area under the peak for each individual metabolite are divided by the area under the peak for 2IPM, the internal standard in this protocol. To calculate the concentration of these metabolites within the sample, multiply the normalized value for the metabolite of interest by the concentration of 2IPM. The same concentration of 2-IPM should be added to each sample, thus this value should not change. The data can then be graphed using GraphPad Prism to visualize the fractional enrichment and total abundance of metabolites detected. This file type is also compatible with multiple downstream analyses, i.e., MetaboAnalyst,10 if desired.

Limitations

The goal of this protocol is to develop a standardized method of analyzing metabolomic profiles and metabolic flux in primary human immune cells. This protocol has thus far only been tested using primary human PBMCs. Alterations may need to be made for immune cell lines. Cells archived for over 1 year should also be checked for viability prior to using this protocol. A major benefit of this protocol is that there are many points at which samples can be frozen for months at a time. However, to reduce the number of variables, it is recommended to prepare samples in a shorter window of time based on previous works using other cell types i.e., cell lines,11 prioritizing using the same lot number of all materials, buffers, etc.

This approach provides a thorough initial analysis of a person’s immune cell metabolic profile; however, it analyzes arbitrary units of each metabolite, as opposed to absolute concentrations. Absolute quantification would require supplementary targeted methods utilizing standards and separate protocols. This technique also requires a significant number of cells. Proper ways to account for this are detailed in subsequent sections.

A limitation of this protocol, and all ex vivo studies, is that this provides a “snapshot” of the immune cells’ metabolic profile at the time of sample collection. In the development of this technique, samples were obtained from individuals with obesity ± T2D. It is well established that chronic inflammation is present, and that there are metabolic shifts occurring as a normal glucose tolerant individual develops T2D.12 As the degradation of metabolic health is gradual, the disease progression is most often not sampled. Furthermore, factors such as age, sex, and comorbidities i.e., cardiovascular disease must be considered when analyzing immune cell metabolism.

Cell viability may decrease during stimulation in step 7, during isotope tracing in step 13, or after washing in steps 11 and 16. Using an automatic hemocytometer is beneficial, as it indicates cell viability whereas manual counting may be less accurate.

Potential solutions

Failure to do so WILL decrease cell viability. 1xDPBS should be used at 25°C, and 0.9% NaCl should be used at 4°C.

Problem 3: Readout variability

Metabolomic profiles and 13C incorporation into metabolites of interest analyzed through the quantification and statistical analysis section of this protocol vary significantly between replicates.

Potential solutions

Variability in 13C incorporation and/or metabolite abundance can either be due to technical or biological issues.•Compare 2IPM/chosen internal standard between replicates; if there is high variability in 2IPM between technical replicates, there was an issue with sample preparation and that sample preparation should be repeated with a new aliquot of cells.•If 2IPM variability is minimal between technical replicates but 13C incorporation between technical replicates is highly variable, there may be an issue with resuspending the cell pellets in tracer media (Exposing PBMCs to Stabler Isotope Tracers, Step 10), or with the preparation of the tracer media itself. If technological and biological replicates show high 13C variability, there was likely an issue with the tracer media, and the media must be remade, and the run must be repeated. If 13C incorporation is only variable for technical replicates of 1 subject, there was likely an issue with the subject or sample itself.•If abundance of metabolites is highly variable between technical replicates, there may have been an issue with cell counting at each step, or cells may have died during the washing steps at various parts of this protocol. It is imperative to accurately count the cells, putting 10 million cells in each technical replicate, and you also must correctly dilute each washing solution at the right temperature (specifications found in KRT).

Problem 4: High background/noise

High background, as seen as “noise”, or unclear peaks visualized in the quantification and statistical analysis section of this protocol may be found in the CDF files for metabolite(s).

Potential solutions

•Quality control samples and blanks should always be run before and after experimental samples on the GC-MS. To reduce noise and eliminate background signal, the total value for a metabolite in a sample is subtracted by the value of that metabolite seen in the blank samples.•Normalize all samples to the 2IPM that is spiked into the 50% MeOH during metabolite extraction. This should reduce the background seen and is a recommended practice for all mass spectrometry.
