Protocol for comparative gene expression data analysis between brains and organoids using a cloud-based web app
Authors: Xiang Huang, Pubudu Kumarage, Soraya Sandoval, Xinyu Zhao, Daifeng Wang
Published: 2024

ABSTRACT
SummaryHere, we present a protocol for using Brain and Organoid Manifold Alignment (BOMA), a cloud-based web app for comparative gene expression data analysis between brains and organoids. We describe steps for performing a global alignment of developmental gene expression data from both brains and organoids. We then detail procedures for investigating both shared and distinctive developmental pathways across brains and organoids by refining alignment locally using manifold learning. This protocol is applicable for working with single-cell and bulk RNA sequencing data.For complete details on the use and execution of this protocol, please refer to He et al.1

Before you begin

Overview

The Brain and Organoid Manifold Alignment (BOMA) method utilizes manifold alignment to analyze both bulk and single-cell transcriptomic data from human and non-human primate (NHP) brain regions and organoids. This technique highlights similarities and differences in developmental patterns between these systems, offering insights for further experimental validations. The method has been successfully applied to align gene expression data from human brains and organoids, providing a more streamlined and efficient approach for gene expression analysis compared to previous methods.

BOMA’s manifold alignment not only compares and analyzes gene expression data from diverse sources like human/NHP brain regions and organoids, but also enhances the efficiency of identifying developmental patterns and distinctions. These insights facilitate deeper understanding and guide further experimental validations, contributing significantly to advances in neuroscience research by elucidating developmental trends and discrepancies observed across different systems.

For more detailed technical information about the BOMA method and the preloaded datasets, refer to the publication "BOMA - a machine learning framework for comparative gene expression analysis across brains and organoids", Cell Reports Methods, 2023.1 Descriptions about several technical terms used in this manuscript and in boma web-app are included as supplemental information in Table S1.

Software downloads and prerequisites

BOMA is accessible via a web dashboard at https://boma.daifengwanglab.org/. This protocol illustrates the steps to use the BOMA web dashboard. Specific instructions are provided for preparing the input files, with examples included to assist users in manually preparing their files for analysis.

Expected outcomes

The BOMA web-app has been developed to provide users with an intuitive tool for exploring brain and organoid datasets. This web-app allows biologists and bioinformaticians to interactively investigate their developmental data. BOMA’s user-friendly interface empowers researchers to visualize and analyze these complex datasets effectively. However, users will need to prepare the data files by selecting the types of cells and features they want to align with.

The Brain Organoid Mapping Algorithm (BOMA) employs a two-step alignment process to harmonize brain tissue and organoid data. In the initial global alignment step, BOMA constructs a correspondence matrix that considers the entire dataset comprehensively. Subsequently, in the local alignment step, the algorithm fine-tunes the alignment by leveraging local features within the datasets. During the alignment phase, BOMA conducts a comparative analysis between brain tissue and organoids, projecting them onto a shared latent space. The quality of alignment is quantitatively evaluated using the Latent Trajectory Assessment (LTA) score. Notably, the trajectories and distributions of data points across time reveal a correlation between the datasets at sampled time points. This correlation potentially provides valuable insights into how organoid development mirrors brain development. The integration of BOMA’s alignment methodology with temporal data underscores its significance in unraveling the intricate dynamics of neural tissue modeling. Following this stage, users can download the alignment data. This dataset comprises Euclidean coordinates resulting from the projection of higher-dimensional alignment. Each sample, single cell, or pseudocell is mapped to a point within the 3D space. Researchers can leverage this data to generate plots and evaluate the alignment quality, ultimately contributing to scientific publications.

In the subsequent stage, the BOMA framework facilitates users in clustering the aligned datasets and assessing alignment quality. This evaluation occurs both visually and through rigorous statistical metrics. The clustering process unveils the inherent groupings within the data, while the heatmap offers a fine-grained perspective on alignment. By doing so, researchers can effectively gauge the correspondence between datasets across the studied conditions.

Limitations

BOMA web-app, currently deployed as an Elastic Beanstalk AWS EC2 instance, represents a critical tool for biologists exploring brain and organoid datasets. However, resource limitations—specifically, using an instance with 8 virtual CPUs and 32 gigabytes of RAM—pose challenges when processing large datasets exceeding 1000 cells. To address this, we introduce a feature: pseudocell-generation.

When confronted with substantial data volumes (e.g., 10,000 cells), pseudocell-generation dynamically resizes the dataset. By aggregating information from multiple cells into a smaller set of pseudocells (typically 500–1,000), we strike a balance between computational efficiency and data fidelity. This reduction significantly accelerates the alignment algorithm while maintaining an acceptable level of quality based on the original data features.

BOMA currently accepts input files in the .csv format. However, it does not support formats such as loom, h5ad, RData or rds. Notably, BOMA aligns datasets with respect to the temporal development of cells. As such, users must provide time development information as metadata to ensure accurate alignment results.

BOMA has been completely deployed as an online web-app. It does not have an offline counterpart. Consequently, users must ensure they have a stable internet connection, and a web browser installed to access the application. Web-app’s layout and design are non-responsive, rendering it incompatible with mobile devices. For optimal usability, it is recommended that users employ a personal computer (PC) or a laptop with sufficient screen space to navigate through the web-app’s pages, upload data, and execute alignment tasks. These considerations are crucial for an efficient and effective user experience in utilizing the BOMA web-app for their scientific endeavors.

Troubleshooting

Problem 1

Fail to upload the input datasets.

Potential solution

If the dataset is properly uploaded, a summary of the file will be shown in Step-1 Specify Datasets tab of the web-app which gives the number of cells and features. Make sure to strictly follow the format of both expression matrix and metadata files.

Problem 2

Users may encounter situations where no alignment results are produced.

Potential solution

The first step is to scrutinize the input files. Ensure that they contain an adequate number of cells and features. For instance, uploading a file with only one cell and zero features will yield no output. A meaningful alignment necessitates sufficient data.

Problem 3

After selecting the data files, users attempted the clustering step, but no output was generated for the clustering analysis.

Potential solution

It is essential to verify whether the alignment process has been completed before attempting clustering. Clustering results will not be available if alignment has not been successfully executed.

Problem 4

Web-app doesn’t work when used for the second time to do an alignment.

Potential solution

Results of the previous alignment may remain and hence it is recommended to reset the web-app before starting another analysis.

Problem 5

No data is downloaded when clicked the "Download Aligned Data" or "Download Clustered Data".

Potential solution

Make sure to run the alignment and clustering steps before downloading data.
