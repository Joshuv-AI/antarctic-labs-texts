Protocol for automated analysis of biological images using Python code
Authors: Benjamin Sacks, Jiya Mody, Yiming Huang, Sunghoo Jung, Robert Kimelman, Elena Eubanks, Elyse Guadagno, Jose Cevallos, Ananya Guntur, Neeharika Rao Suvvari, Aryan Doshi, Nitya Ravinutala, Alejandro Mosera, Alessandro Crimi, Eleanna Kara
Published: 2026

ABSTRACT
SummaryImage analysis in Python provides greater flexibility and an open-source alternative to commercially available software. In this protocol, we present steps for quantifying features in various common biological images in a manner that is tailored to scientists with little coding background. Using example experiments, we outline steps to read in a variety of image file types and prepare them for quantitative analysis. We then discuss approaches for segmenting images, extracting measurements from segmented images, and exporting data.For complete details on the use and execution of this protocol, please refer to Eubanks et al.1

Before you begin

The advent of high content microscopy has resulted in the generation of large imaging datasets that require standardized and automated analyses. This is typically challenging to achieve through commercially available software or web-based browsers. Computer vision in the Python programming language provides automation and flexibility with microscopic image quantification for a variety of experiments examining subcellular structures and cellular functions. Additionally, installing and getting started with Python is more user-friendly than other programming languages, which is further facilitated by several pre-existing libraries. Python and code editors (e.g., Visual Studio Code) can both be downloaded for free, and the Jupyter Notebook extension and file type integrate code and output into sequential fragments.2

Image analysis requires an understanding of fundamental aspects of Python programming, including strings, conditionals, and iteration (i.e., loops). Collections of characters are stored as strings, denoted with quotation marks and used to represent file paths or image information. Conditionals, syntactically represented with if, allow certain commands to execute only when a particular requirement is met. Lastly, iteration allows a set of commands to be run multiple times without repeating the code written. Iteration falls into two categories: while loops, which repeatedly execute until a provided conditional is no longer met, and for loops, which run commands for each piece of data in a collection. Iteration allows many images to be run through the same analysis with little additional effort.

While various methods for preprocessing and measuring images are described, analysis procedures in this protocol follow a general structure of reading, preprocessing, measuring, and reporting. When processing an image, the file must first be read into the Python environment. While file types will vary based on the microscope used, many Python libraries exist for reading image files.3,4,5,6 Read files are represented as multidimensional arrays, which can be prepared using numpy.7 Two-dimensional arrays can then be preprocessed by applying filters (e.g., Gaussian blur), standardization (i.e., contrast adjustment), and finally thresholding to separate the foreground and background of the image.8 This generates a segmented image that can be measured and reported. The following describes the pipeline of image analysis using Python, highlighting options for image preprocessing and measurement of cell function and morphology. While the general pipeline remains the same, there is flexibility in preprocessing and measurement when using Python for image analysis that offers greater versatility when compared to other software. While much of the protocol is written for a variety of applications, some optional sections outline specific methods used for the analysis of intracellular structures, such as proteinaceous inclusions with fluorescent labeling in cultured cells.

This protocol represents a step-by-step guide for the analysis of confocal microscopy images using real life examples published in our recent manuscript1 and builds upon existing protocols and resources.9 In particular, it focuses on the most commonly used analyses, which can be challenging to accurately implement through ImageJ or other software: z-stack volumetric quantifications, mean fluorescence intensity quantifications, colocalization analysis, object identification and quantification of size and shape. Additionally, this protocol gradually scales from basic segmentation techniques to more modern methods for segmentation, introducing readers to a variety of segmentation methods and providing a general “crash course” on various approaches. Original code and data used in the protocol is available at https://doi.org/10.5281/zenodo.17757130 as well as https://github.com/eleannakara/Kara-Lab/tree/main/image_analysis_methods_2025.

Innovation

This protocol outlines the complete process for reading, preprocessing, and measuring features of microscopic biological images. This process requires an understanding of computer programing in Python, which we introduce to the user in a manner that is friendly for those who are new to programming.

This includes an introduction to machine learning based segmentation tools. Several pre-trained image segmentation models are listed and organized alongside code for setup and basic use to facilitate comparison between multiple options. A list of publicly available image databases is also included for reference and model testing. As an example, a custom UNet model designed for the segmentation of microscopic images at a cellular level is also detailed both for use and as a foundation for further customization, if required.

After detailing how to segment images, we provide examples of feature extraction and measurement of segmented images used in basic biological research. These examples come from the associated publication to further contextualize how image analysis can be used to answer real research questions.

Bilinear interpolation is used for upsampling through four blocks (up 1 through 4), each followed by a skip connection and double convolution that halves the number of channels (conv 1 through 4). The final convolution applies the extracted features to the number of channels provided. Attributes: down(1-4): downsample the given module and double the number of channels using double convolution mid: double the number of channels up to 512 up(1-4): upsample a module to twice its previous size using bilinear interpolation conv(1-4): Use double convolution to merge the previous block and a skip connection, halving the number of feature channels from the previous block. """ def __init__(self, n_classes): """ Initialize a UNet model object Parameters: n_classes (int): the number of classes for segmentation """ super().__init__() self.down1 = DoubleConv(1, 32) self.down2 = DoubleConv(32, 64) self.down3 = DoubleConv(64, 128) self.down4 = DoubleConv(128, 256) self.mid = DoubleConv(256, 512) # >class DoubleConv(nn.Module):

"""

Module that performs convolution on itself twice

Attributes:

in_c (int): number of channels the current module has

out_c (int): number of output channels to produce

"""

# initialization

def __init__(self, in_c, out_c):

""" Initialize a module with a method for double convolution with given number of input and output channels """

super().__init__()

self.double_conv = nn.Sequential(

nn.Conv2d(in_c, out_c, kernel_size=3, padding=1),

nn.BatchNorm2d(out_c),

nn.ReLU(inplace=True),

nn.Conv2d(out_c, out_c, kernel_size=3, padding=1),

nn.BatchNorm2d(out_c),

nn.ReLU(inplace=True),

)

17.Define the class structure for the custom UNet model architecture.

Define the class structure for the custom UNet model architecture.

>class UNet(nn.Module):

"""

UNet image segmentation model that includes four sequential downsampling blocks with double convolution (down 1 through 4) followed by a double convolution to 512 channels (mid). Bilinear interpolation is used for upsampling through four blocks (up 1 through 4), each followed by a skip connection and double convolution that halves the number of channels (conv 1 through 4). The final convolution applies the extracted features to the number of channels provided.

Attributes:

down(1-4): downsample the given module and double the number of channels using double convolution

mid: double the number of channels up to 512

up(1-4): upsample a module to twice its previous size using bilinear interpolation

conv(1-4): Use double convolution to merge the previous block and a skip connection, halving the number of feature channels from the previous block.

"""

def __init__(self, n_classes):

"""

Initialize a UNet model object

Parameters:

n_classes (int): the number of classes for segmentation

"""

super().__init__()

self.down1 = DoubleConv(1, 32)

self.down2 = DoubleConv(32, 64)

self.down3 = DoubleConv(64, 128)

self.down4 = DoubleConv(128, 256)

self.mid = DoubleConv(256, 512)

# Use Upsample instead of ConvTranspose2d

self.up4 = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)

self.conv4 = DoubleConv(512 + 256, 256)

self.up3 = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)

self.conv3 = DoubleConv(256 + 128, 128)

self.up2 = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)

self.conv2 = DoubleConv(128 + 64, 64)

self.up1 = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)

self.conv1 = DoubleConv(64 + 32, 32)

self.final = nn.Conv2d(32, n_classes, kernel_size=1)

def forward(self, x):

"""

Send image through each step of the UNet model

Parameters:

x (Tensor): image tensor to send through the model

Outputs:

self.final (Tensor): a segmentation map of the given image

"""

d1 = self.down1(x)

d2 = self.down2(F.max_pool2d(d1, 2))

d3 = self.down3(F.max_pool2d(d2, 2))

d4 = self.down4(F.max_pool2d(d3, 2))

mid = self.mid(F.max_pool2d(d4, 2))

u4 = self.up4(mid)

if u4.size() != d4.size():

u4 = F.interpolate(u4, size=d4.shape[2:], mode='bilinear', align_corners=True)

u4 = self.conv4(torch.cat([u4, d4], dim=1))

u3 = self.up3(u4)

if u3.size() != d3.size():

u3 = F.interpolate(u3, size=d3.shape[2:], mode='bilinear', align_corners=True)

u3 = self.conv3(torch.cat([u3, d3], dim=1))

u2 = self.up2(u3)

if u2.size() != d2.size():

u2 = F.interpolate(u2, size=d2.shape[2:], mode='bilinear', align_corners=True)

u2 = self.conv2(torch.cat([u2, d2], dim=1))

u1 = self.up1(u2)

if u1.size() != d1.size():

u1 = F.interpolate(u1, size=d1.shape[2:], mode='bilinear', align_corners=True)

u1 = self.conv1(torch.cat([u1, d1], dim=1))

return self.final(u1)

Note: This UNet model uses bilinear interpolation instead of the default two-dimension convolution for map upsampling. Bilinear interpolation is more memory efficient and prevents checkerboard artifacts. After upsampling, a skip connection is used to integrate information from each layer of the encoder and decoder. This is then passed to a double convolution block for feature refinement. Decoder feature maps are interpolated to match the size of their paired encoder block prior to concatenation. Finally, the output segmentation label is generated from a 1X1 convolution of the decoder block’s output onto a binary classification.

Limitations

Depending on the quality of each image in a set, some images will not segment properly. In our experience, roughly eighty percent of a set will segment well and provide useful data. Additionally, Python does not include a graphical user interface by default unlike other software (e.g., ImageJ, ZEN). Subsequently, manual annotation or segmentation of images requires additional programming in Python. Manual annotations can be added to images in Python through libraries such as Napari, though this requires the installation of additional modules and further programming.26 In some cases, manual annotations can be read along with the image data, though this requires additional processing (see step 5).

This procedure can also be very computationally intensive, particularly for large datasets or images containing many slices or time points. Certain filtering algorithms, including Gaussian filtering and local thresholding algorithms increase the time required to process images. Machine learning approaches are also computationally intensive. This is especially true if GPUs are not available for training and using machine learning models, as GPUs can process the many small commands required for machine learning at a faster rate than a CPU. This difference in using a GPU can reduce the time required for training and use of a machine learning model (possibly by hours or days) depending on the size of the dataset. Additionally, image file types are often large and storing many images may require a substantial amount of memory on both the hard drive and RAM.
