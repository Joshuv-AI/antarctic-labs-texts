Bio-inspired elephant herd optimization based method for building adaptive ensemble of transfer learning based classifiers
Authors: Om Prakash Suthar, Vijay Katkar, Krunal Vaghela
Published: 2025

ABSTRACT
Transfer learning has become an important method for image classification when training data is limited. This paper introduces a novel method to build an adaptive ensemble of transfer learning-based classifiers by employing Elephant Herd Optimization (EHO) to enhance image classification performance. Initially ‘n’ classifiers are built using transfer learning method, then their probabilistic outputs are combined into a single feature matrix. Afterward EHO is used to reveal which classifiers yield maximum contribution to the final decision. These discovered classifiers are then utilized to form ensemble of classifiers. The primary contributions of the proposed methodology include:•Reducing duplication and improving image classification accuracy by utilizing bio-inspired EHO based method to adaptively choose the most efficient subset of transfer learning-based classifiers•Method to build a combined feature matrix by combining probability outputs from several classifiers, which enables the ensemble of classifiers to function on richer, decision-level features.Experiments performed on benchmarked GAIT image dataset and Ocular Disease detection ODIR-5K dataset indicates that this method outperforms classical ensemble strategies, enhancing both accuracy and efficiency.

Background

The collection or procurement of training data remains challenging or prohibitively expensive in numerous practical classification applications. Limited data availability poses significant obstacles for implementing deep learning models which require separate training from substantial available datasets [1]. Transfer learning solves this concern by using pretrained models to build a finetuned classifier model, {C}, which outputs vector p(x)=[p1(x),p2(x),….,pk(x)] with ∑k=1Kpk(x)=1, where ‘K’ is number of classes in dataset [2]. Ensemble learning combines outputs from several such models (C1,C2,…,CM,) to enhance classification performance [3,4]. In soft voting, the prediction of ensemble of classifier (i.e. y^(x)) is based on averaged (or weighted) probabilities [5] as shown in Eq. 1, where pm(x) is output probability of class ‘k’ by pretrained model ‘Cm’ when ‘x’ is given as input to the model Cm:(1)y^(x)=arg1M∑m=1Mpm(x)

One can assess the performance of an ensemble using a loss function ℓ(·) or an accuracy measure. For instance, accuracy, loss on the labelled dataset D is determined using (2), (3) respectively as:(2)Acc=1N∑i=1NI(y^(xi)=yi),while a generic loss is calculated as:(3)L=1N∑i=1Nl(y^(xi),yi)where lower values of L indicate better performance.

For hard-voting, the final prediction for input x is calculated using Eq. 4 as:(4)y^(x)=arg∑m=1MI(Cm(x)=k)where I is the indicator function (1 if true, 0 if false) and each model Cm, maps an input x to class label instead of providing class probability, pm(x) [6].

Bagging Ensemble method begins with Bootstrap Sampling where, from the original training set {(xi,yi)}i=1N, M bootstrap samples are drawn. Each bootstrap sample is the same size N but sampled with replacement from the original dataset. After that ‘M’ number of classifiers Cm, are trained on the m-th bootstrap sample. Finally, at inference time, each Cm is evaluated on the test point x. The final bagging prediction typically uses either hard voting or soft voting [7,8].

The unguided utilization of multiple transfer-learned models without a structured method results in redundant information sharing while increasing training time and reducing accuracy gains. A bio-inspired optimization powered methods serves as the main solution to remedy these limitations [9,10]. Proposed method produces a concise yet precise result by converting probabilities from each classifier to joint features followed by discriminating the optimal outputs selected from the ensemble. This method establishes both theoretical value for unifying probability estimations with mathematical optimization methods and practical advantages for use with limited data sets.

Motivation

Models such as ResNet, EfficientNet, Inception which are trained on many medical images, are now the world’s top choice for image classification in Parkinson’s disease detection [11,12] or Alzheimer’s disease prediction [13]. On the other hand, including every model in a single ensemble can cause the algorithm to use too much time and may still include predictors that are redundant or not very important. Most ensemble techniques tend to treat every model the same which means they don’t adjust well to different types of data [14]. To solve this, the methodology creates an adaptive ensemble by choosing which classifiers to include according to their probabilities through Elephant Herd Optimization (EHO).

It converts each classifier’s probability guess into a vector and then combines all these vectors side by side in a matrix. A binary selection vector chooses which features (and classifiers) should be included in the ensemble. EHO [[15], [16], [17]] makes efficient use of the high-dimensional binary space by imitating elephants which aids in picking the best set of classifiers. It is most helpful when many different models are used and mixing them to achieve top results is not simple. The outcome is an ensemble that is more refined and better matched to what the target dataset requires.

Method details

This section presents in detail the method used to build an adaptable ensemble of transfer learning-based classifiers that have been tuned using a bio-inspired approach. The goal of the proposed method is to improve the accuracy of image classification by employing an intelligent feature selection method to find the classifier outputs that give the most useful information for forming ensemble.

Method validation

This study utilized two benchmark datasets to do validation experiments on the proposed method to see how well it works and how strong it is in a variety of difficult categorization situations. Each dataset is a different area with its own set of problems. For example, recognizing age and gender in a person's stride might be very different, and classifying diseases can be very different depending on the type of eye image used. The goal of these experiments is to show that the proposed ensemble method can be used in many different situations. This study also compares exists of proposed method with results of existing ensemble methods using criteria like accuracy, precision, recall, and F1-score. Also, one-way ANOVA statistical validation makes sure that the differences in evaluation metrics that were observed are real and important [18].

Using OULP dataset

This study utilized well-known OULP-age dataset as a benchmark for research in gait-based age recognition purposes [19]. This OULP-age dataset presents a high complexity because participants with shared age display minor walking behavior variations and significant individual movement variations that stem from diverse walking speed types and outfit choices and environmental changes [20,21]. Hierarchies within demographic features result in overlapping distribution of characteristics through which age detection suffers major difficulties. Proposed method effectively manages various challenging characteristics of classification problems. Using ODIR-5K dataset

The Ocular Disease Intelligent Recognition (ODIR) is a comprehensive ophthalmic database comprising data from 5,000 patients [22]. It includes age information, color fundus images of both right and left eyes. Fundus images in these institutions are captured using different cameras available in the market, including models from Canon, Zeiss, and Kowa, leading to different resolutions of images. Annotations were assigned labels by trained human readers, accompanied by quality control management procedures. Patients are classified into eight categories, which include: Normal(N), Diabetes(D), Glaucoma(G), Cataract(C), Age-related Macular Degeneration(A), Hypertension(H), Pathological Myopia(M), Other diseases/abnormalities(O). The ODIR-5K dataset makes it hard to provide correct diagnoses because it has problems including class imbalance, multi-label classification, and changing image quality. It also has problems with visual similarities across classes, noisy labels, and not being able to be used with a wide range of populations [[23], [24], [25]]. Proposed method effectively manages these challenging characteristics of classification problems. Limitations

1.Dependence on Pretrained Models' Diversity: The effectiveness of the ensemble mostly relies on the variety and quality of the initial transfer learning models. The ensemble might not reach notable performance increases if its underlying models are too similar or prejudiced.2.Scalability Challenges with EHO: Despite EHO is good for classifier subset selection, its efficiency may suffer in high-dimensional feature spaces or when the search area becomes too wide. In large-scale applications, this could call for careful parameter adjustment and more computing time to guarantee convergence.
