A single-echo/multi-echo BOLD fMRI test-retest dataset
Authors: Taylor Salo, S. Parker Singleton, Corey Horien, Matthew Cieslak, Elizabeth A. Flook, Sage Rush, Brooke L. Sevchik, Tien T. Tong, Manuel Taso, M. Dylan Tisdall, David R. Roalf, Theodore D. Satterthwaite
Published: 2026

ABSTRACT
Functional MRI (fMRI) remains one of the primary tools for non-invasive studies of brain activity and organization in humans. Recently, multi-echo imaging has generated interest due to the improved signal-to-noise and potential for superior denoising. In parallel, developments in MRI processing techniques, such as the use of phase data and advanced denoising methods, have continued to advance the field. An important step towards adopting these methodologies is directly comparing them to existing techniques using real-world data. We present a neuroimaging dataset that allows for within-subject comparison of single-echo vs multi-echo imaging with cutting-edge imaging acquisition parameters such as magnitude and phase reconstruction and no-excitation (noise only) volumes. The sample includes test-retest data from eight young adults. Each session includes a T1-weighted anatomical scan, four resting-state functional MRI scans (two each for single-echo and complex multi-echo), and a multi-echo task-based functional MRI scan from a fractal n-back working memory task. Raw imaging files are released, as well as derivatives from our open-source processing pipelines. These rich data provide opportunities for direct comparison of single-echo and multi-echo methodologies. Moving forward, the data facilitate studies of evaluating how advanced image acquisition and processing impact test-retest reliability.

Background

Multi-echo functional magnetic resonance imaging (fMRI) encodes multiple echo times per MRI volume. Prior work has shown that multi-echo fMRI improves the reliability of functional connectivity-based measures compared to single-echo fMRI, which is the current field standard. Multi-echo improves the detection of noise, including improved R2* estimation [1] and dynamic distortion correction [2]. Although multi-echo imaging represents an exciting advancement in fMRI, it has not yet been widely adopted and many commonly-used image-processing pipelines have not yet incorporated multi-echo processing options.

Here, we release a multi-echo dataset to address this gap. Specifically, the sample includes test–retest data, allowing researchers to assess the reliability of multi-echo denoising techniques and evaluate other image processing methods. The dataset also includes single-echo fMRI scans acquired with the widely-used ABCD protocol [12], allowing for comparison between single-echo and multi-echo protocols. The data described in this manuscript were collected as a pilot study for an ongoing study examining mood and sleep in adolescents and young adults [13]. However, that study did not include single-echo scans nor the fractal n-back task. Thus, the present dataset comprises a unique sample, allowing the study of many unaddressed questions regarding multi-echo fMRI.

Data Description

All raw data files, derivatives of the processing pipeline, and quality control indices are available on OpenNeuro (https://openneuro.org/datasets/ds007637/versions/1.0.0). The raw data include T1-weighted, resting-state functional MRI, and task-based functional MRI (fractal n-back task) from eight participants. The data are organized using Brain Imaging Data Structure (BIDS) specification. The participant is identified as sub-* in the files, the session number is identified as ses-* in the files, and task is identified as either task-rest (resting state) or task-fracback (fractal n-back task). All files have accompanying .json files containing metadata of the file. Experimental Design, Materials and Methods

Participants

These data include eight participants (50% female) aged 21 to 30 years old (M = 24.5, SD = 2.4).

MRI acquisition

MR data were acquired using a 3-Tesla Siemens Prisma MRI scanner using a 64-channel head-neck coil. At the start of each scanning session, a T1-weighted anatomical scan was collected with the following parameters: 256 slices; repetition time (TR) = 1900 ms; echo time (TE) = 2.93 ms; flip angle (FA) = 9 degrees; field of view (FOV) = 176×262×144 mm3, matrix size = 176×256; voxel size = 1×0.977×0.977 mm3.

The anatomical image was followed by a series of five fMRI scans. Two runs of eyes-open resting-state five-echo BOLD were collected (72 slices; TR=1761 ms; TEs=14.2, 38.93, 63.66, 88.39, 113.12 ms; FA=68 degrees; FOV=220×220 mm2, matrix size=110×110; voxel size=2×2×2 mm3; multiband acceleration factor=6). Each run was 5:59 min including three volumes at the end of the scan that lacked radiofrequency excitation (“no-RF” scans). Following these multi-echo scans, two runs of eyes open resting-state single-echo BOLD data were acquired according to the ABCD protocol [14] (60 slices; TR=800 ms; TE=30 ms; FA=52 degrees; FOV=216×216 mm2, matrix size=90×90; voxel size=2.4×2.4×2.4 mm3; multiband acceleration factor=6). Each run was 6:00 min. Finally, we acquired one run of Penn fractal n-back task [15] using the same multi-echo fMRI protocol as for the first two resting-state multi-echo scans. The block design was fixed order: 0-back, 2-back, 2-back, 0-back, 2-back, 0-back. Each block lasted 48 s. The run was 7:03 min, including the three no-RF volumes at the end.

Two sets of field maps were acquired for the multi-echo fMRI scans. Each set consisted of a multi-echo field map and a pseudo-single-echo field map, in which the first echo of the multi-echo field map was extracted. The first set was a multiband, multi-echo gradient echo PEpolar-type field map (acq-MEGE), acquired with the same parameters as the multi-echo fMRI scans (except without phase reconstruction enabled); the pseudo-single echo was designated as the primary field map. The other set was a multi-echo spin-echo PEpolar-type field map (acq-MESE), with the pseudo-single echo map designated as a standard field map. The pseudo-single-echo copies of both the acq-MEGE and the acq-MESE field maps have B0FieldIdentifier fields and IntendedFor fields, though we used the acq-MESE field maps for the B0FieldSource fields of the multi-echo fMRI scans. Tools which leverage the B0* fields, such as fMRIPrep, should use the pseudo-single-echo acq-MESE scans for distortion correction. For distortion correction of the single-echo fMRI data, we acquired single-echo PEpolar-type EPI field maps (acq-SESE) with parameters matching the single-echo fMRI scan.

Data processing

All imaging data were converted to NifTI-1 format with dcm2niix v1.0.20220505 [16], using HeuDiConv 0.13.1 [17]. Structural images were anonymized using AFNI’s refacer [18] and subsequently released with all other imaging data via OpenNeuro [19]. We utilized the University of Pennsylvania’s CUBIC computing resource, a RedHatEnterprise Linux-based HPC cluster for processing the raw neuroimaging data. Raw data were downloaded from the OpenNeuro dataset [19] and processed in BIDS Apps using the BIDS-App Bootstrap software [20] (BABS, v0.5.4), which uses DataLad to provide a full audit trail and enhance reproducibility. Limitations

These data have three primary limitations. First, this dataset is small. Second, the amount of time between scanning sessions is not consistent (ranging from starting immediately after the first session to 14 days later). Third, the functional scans were collected under only two task conditions (rest and Penn fractal n-back).

Beyond these primary limitations, other characteristics warrant discussion. The PEpolar-style field maps acquired for multi-echo fMRI data include multiple echos. Because multi-echo field maps of this type are not supported by BIDS and cannot be used by fMRIPrep, we have created a pseudo-single-echo version of each field map using the data from the first echo. Subject 08 completed a scanning session without the head-coil plugged in (‘ses-noHC’ on OpenNeuro). The data for this session are released in the event they might provide some utility, but they should not be used in analyses across the entire sample. Subject 04 terminated session two, so the participant required a third session to obtain the remainder of the scans. This participant does not have the no-radio-frequency-noise scans for session two. One participant was not able to complete the second session. In total, seven participants have complete data across all sessions.
