POLAR-DETR: Polarized occlusion-aware local-global attention real-time detection transformer for total laboratory automation
Authors: Yunqin Zu, Siqi Li, Lixun Zhang
Published: 2026

ABSTRACT
AbstractThe deployment of Total Laboratory Automation (TLA) systems in medical production lines faces challenges including spatial constraints, dense object distributions, and severe occlusions, rendering traditional detection methods inadequate. This paper proposes POLAR-DETR (Polarized Occlusion-aware Local-global Attention Real-time Detection Transformer), an efficient real-time end-to-end detection framework for medical production scenarios. First, we design a Polarized Occlusion-aware Hierarchical Feature Encoder (POHFE) incorporating polar linear attention and dynamic nonlinear feature modulation, enhancing spatial-contextual awareness and detail representation. Second, we introduce a Multi-level Hierarchical Attention Fusion (MHAF) module that strengthens semantic associations between multi-scale features through hypergraph computation. Additionally, we develop a Hierarchical Dual-branch Attention Fusion (HDAF) module for precise discrimination of local details and global information. To optimize deployment efficiency, we devise a Hessian matrix-based pruning strategy reducing network redundancy. Furthermore, we construct the Augmented Medical Production Line (AMPL) dataset, comprising 5040 high-resolution images with 85,797 annotated instances. Experimental results demonstrate that POLAR-DETR achieves 70.0% Average Precision (AP) on AMPL while maintaining 68.4 FPS. Compared to baseline, our approach improves AP by 4.7% while reducing parameters and computational complexity by 20.5% and 22.6% respectively, providing an efficient visual detection solution for medical production automation.Keywords: Total Laboratory Automation, Real-time Object Detection, Attention Mechanism, Feature Fusion, Model PruningSubject terms: Engineering, Mathematics and computing

Introduction

Total Laboratory Automation (TLA)1 demonstrates substantial advantages in laboratory process standardization, operational efficiency optimization, human error mitigation, turnaround time reduction, and biosafety risk management. However, spatial constraints2 within laboratory environments emerge as a critical bottleneck impeding TLA system deployment. Consequently, the development of vision-based intelligent specimen transportation robotics as an alternative to conventional conveyor systems represents a pivotal innovation trajectory for transcending current TLA technological limitations. Moreover, specimen preprocessing and transportation, serving as fundamental pillars within the TLA framework, have traditionally relied upon implementations involving encoders, decoders, and numerous limit switches. This conventional architecture inevitably engenders procedural complexity in automation workflows, significantly compromising system maintainability and reliability. Against this backdrop, computer vision technology emerges as a transformative enabler, providing crucial technological underpinning for intelligent advancement and efficiency optimization of TLA systems.

The proliferation of automation technologies has driven the adoption of deep learning across various industrial applications, from pallitating data distribution shifts in equipment fault monitoring3 to optimizing object detection tasks in medical production domains. Consequently, intensifying attention has been directed toward object detection tasks in medical production lines, particularly those centered on computer vision technologies. While conventional object detection methodologies, exemplified by the YOLO series, have demonstrated remarkable achievements in real-time performance and detection precision across numerous practical applications, these approaches typically rely on manually designed post-processing components such as Non-Maximum Suppression (NMS). Such dependencies not only impose additional computational overhead but may also induce fluctuations in inference precision and speed. Moreover, the medical production line environment presents distinctive challenges characterized by dense object distributions, small-scale objects, and severe occlusions, rendering traditional detection methods inadequate for practical deployment requirements. As illustrated in Fig. 1, the prevalent occurrence of densely distributed objects (such as closely arranged test tubes) and significant occlusion phenomena in medical production lines substantially amplifies the complexity of detection tasks.

Challenges in augmented medical production line dataset.

Recent advances in object detection have been marked by the emergence of RT-DETR4, a Transformer-based real-time end-to-end detector, offering novel solutions to aforementioned challenges. RT-DETR pioneered efficient real-time object detection without NMS dependency, demonstrating superior performance in both accuracy and real-time capabilities compared to traditional YOLO models. However, current RT-DETR implementations exhibit limitations in feature representation capabilities within medical production line scenarios, particularly in addressing dense occlusions and small-scale object detection.

To address these limitations, we propose POLAR-DETR, an efficient real-time end-to-end detection framework specifically designed for medical production line imagery. Our framework introduces several innovative components: First, we design a Polar Occlusion-aware Hierarchical Feature Encoder (POHFE) that incorporates polar linear attention mechanisms and dynamic nonlinear feature modulation, significantly enhancing spatial-contextual awareness and detail representation in complex scenarios. Additionally, we introduce a Multi-level Hierarchical Attention Fusion (MHAF) module that strengthens high-order semantic associations between multi-scale and spatial features through hypergraph computation and modulated attention fusion. Furthermore, we develop a Hierarchical Dual-branch Attention Fusion (HDAF) module, enabling precise discrimination and integration of local textural details and global semantic information. To optimize deployment efficiency and enhance generalization capabilities, we devise a Hessian matrix-based global pruning strategy that effectively reduces network redundancy. Related works

Object detection in total laboratory automation

Addressing the multifaceted challenges in laboratory automation, Badiger et al.5. introduced a vision-based gantry vacuum tube filling robotic system. However, their visual module implementation exhibits considerable limitations, being confined to vacuum tube center positioning while lacking the capability to accommodate the diverse array of vessels in medical production lines. Moreover, their continued reliance on traditional encoder-decoder mechanisms for object recognition fails to address the fundamental technological constraints inherent in conventional TLA systems.

Current research landscape reveals significant gaps in the integration of computer vision technologies within TLA systems. Brown et al.6 further elucidate that the evolutionary progression of TLA systems has led to exponential growth in architectural complexity, posing increasingly formidable challenges to system safety and stability. Consequently, the imperative for substantial development and innovative integration of computer vision modules has emerged as a critical necessity, not merely for system optimization but for facilitating sustainable TLA advancement beyond simple technological augmentation.

Real-time end-to-end object detection

YOLO-series models have gained widespread adoption across diverse object detection domains, owing to their remarkable ability to strike an optimal balance between performance and real-time capabilities7–9. However, these models inherently rely on NMS for post-processing, which not only impedes inference speed but also introduces hyperparameters that can lead to inconsistent performance in both speed and accuracy. Furthermore, their shallow features and relatively simplistic architecture struggle to extract subtle feature distinctions between densely occluded objects, making them less effective in real-world medical laboratory scenarios where severe occlusion is commonplace.

In contrast, RT-DETR4 emerges as a groundbreaking achievement, representing the first object detector to simultaneously achieve real-time performance and end-to-end detection while eliminating the need for NMS. Its sophisticated hybrid encoder demonstrates exceptional efficiency in processing multi-scale features, coupled with uncertainty-minimized query selection, enabling it to surpass even the robust YOLO models. Leveraging transformer architecture, RT-DETR employs global attention mechanisms to capture long-range dependencies and contextual information, effectively mitigating the challenges posed by dense object distributions and occlusions. Compared to YOLO-series models, its end-to-end design philosophy renders it particularly suitable for deployment on vision TLA platforms.

Feature fusion

Feature fusion techniques play a pivotal role in enhancing object detection accuracy, particularly in scenarios involving small objects and dense occlusions10. The efficient integration of cross-scale features has emerged as a critical determinant of model performance. Contemporary object detection methodologies predominantly employ straightforward progressive fusion strategies, such as direct summation11,12 or cascade13,14 of feature maps. However, these approaches fail to adequately address the intricate semantic and spatial correlations across different scales and spatial locations, potentially leading to feature misalignment and information degradation. Moreover, these methods are generally constrained by their direct manipulation of spatial domain features, demonstrating suboptimal performance in modeling high-order semantic relationships and cross-scale interactions.

To address these limitations, several studies15–17 have introduced more sophisticated attention mechanisms, including channel attention and spatial attention, to enhance semantic correlations among features at different scales. Nevertheless, these approaches primarily focus on local optimization within the spatial feature domain, lacking sufficient capacity to capture deeper high-order semantic relationships. While some research18,19 has incorporated advanced feature modeling methods such as hypergraph computation to explicitly represent high-order semantic relationships among features, achieving notable improvements, the adaptability of these methods in specialized application scenarios, such as medical production lines, remains inadequately validated.

The proposed method aims to overcome the limitations of conventional feature fusion methods by introducing two innovative modules: the MHAF module and the HDAF module. The MHAF module explicitly constructs high-order semantic relationships between features through hypergraph computation, significantly enhancing the efficiency of cross-scale and cross-spatial feature interactions. Complementarily, the HDAF module strengthens the precise discrimination and fusion of local textural features and global semantic features, effectively addressing the challenge of fine-grained control in cross-scale feature fusion within complex scenarios. These innovative fusion mechanisms have demonstrated substantial performance improvements and practical advantages in object detection tasks within medical production line environments.

Materials and methods

POLAR-DETR is an end-to-end real-time detection network built upon the RT-DETR framework, specifically optimized to address the challenges of dense occlusion and small object detection in medical production line scenarios. As illustrated in Fig. 2, while retaining RT-DETR’s efficient hybrid encoder and query selection mechanism, the architecture introduces three key innovative modules. The code for the core module and the AMPL dataset are publicly available at https://github.com/yunqinzu9-creator/POLAR-DETR.

Overview of POLAR-DETR.

POHFE replaces the AIFI module. The original AIFI module in RT-DETR employs a standard Transformer encoder, which suffers from positional encoding constraints, uniform attention distribution, and limited multi-scale perception. POHFE addresses these limitations by incorporating polarized linear attention mechanisms and dynamic nonlinear feature modulation, establishing a hierarchical feature representation system across four dimensions: temporal processing, spatial scale, feature abstraction, and cognitive processing. This significantly enhances the model’s capability to perceive spatial-contextual relationships and occlusion information.

The MHAF module enhances cross-scale feature interaction. To overcome the limited receptive field and lack of high-order semantic modeling in RT-DETR’s CCFM module, MHAF explicitly constructs high-order semantic associations between features through hypergraph computation. Combined with a modulation fusion module that adaptively emphasizes salient regional features, it effectively resolves feature entanglement issues in dense scenarios.

The HDAF module refines feature fusion. Through a local-global dual-branch architecture that separately processes fine-grained textural features and long-range dependencies, this module achieves precise discrimination and fusion of local details and global semantic information, further improving the accuracy of cross-scale feature fusion.

Hessian matrix-based global pruning strategy. To optimize deployment efficiency, we employ second-order derivative information to precisely assess parameter importance, achieving reduction in computational and parameter compression while maintaining detection accuracy.

As illustrated in Fig. 2, the proposed POLAR-DETR architecture follows a streamlined end-to-end detection pipeline. Given an input image, multi-scale features are first extracted via a standard backbone network. These features are then enhanced by the POHFE encoder, which replaces the traditional intra-scale interaction module to capture polarized spatial contexts. Subsequently, the features pass through a hybrid fusion stage comprising MHAF and HDAF modules, where cross-scale semantic relationships and local-global details are progressively integrated. Finally, the refined features are fed into the transformer decoder and prediction heads to generate bounding boxes and class labels. To ensure deployment efficiency, the entire architecture undergoes a Hessian-based Global Pruning process post-training to eliminate structural redundancy. The augmented medical production line dataset

Despite the increasing adoption of automation in medical production lines, there exists a notable research gap in computer vision-based automated monitoring systems for such environments. Furthermore, the scarcity of publicly available datasets specifically targeting medical production line equipment poses a significant challenge for research advancement in this domain.

To address this limitation, we conducted comprehensive data collection in an operational medical production line environment, as illustrated in Fig. 3. The image acquisition was performed using dual camera setups: an iPhone camera (3024 × 4032 pixels) and a Realme camera (4608 × 2080 pixels). Polarized occlusion-aware hierarchical feature encoder

The AIFI module, fundamentally based on the standard Transformer encoder architecture, operates by flattening 2D feature maps into 1D sequences for self-attention computation, utilizing sinusoidal positional encoding to preserve spatial information and implementing global attention mechanisms for intra-scale feature interaction. However, this implementation paradigm exhibits several inherent limitations:

Positional Encoding Constraints. The sinusoidal positional encoding scheme, while globally defined, exhibits limitations in local spatial perception and lacks explicit occlusion modeling mechanisms. This encoding framework demonstrates insufficient discriminative capability in position representation, particularly in dense object scenarios characteristic of medical production environments. The absence of precise boundary localization capacity poses challenges in addressing dense object detection tasks.

Uniform Attention Distribution Issue. The AIFI module’s implementation of standard self-attention mechanisms allocates equal attention opportunities across all positions, lacking adaptive conditioning based on object significance. This uniform attention distribution paradigm proves problematic in medical production environments with dense object distributions, potentially leading to attention dispersion and suboptimal feature focus.

Limited Multi-scale Perception. The module’s confinement to single-scale feature interaction significantly constrains its capability to simultaneously capture fine-grained details and global contextual information. This limitation particularly impacts its adaptability to the AMPL dataset, where objects exhibit dramatic scale variations, resulting in suboptimal feature representation across different spatial scales.

In response to the limitations inherent in the AIFI module and drawing inspiration from the Transformer architecture, we propose a novel encoder framework called POHFE (Polarized Hierarchical Feature Encoder) to address the challenges of density and occlusion in medical production line imagery. Multi-level hierarchical attention fusion

Through an in-depth structural analysis of RT-DETR, we observe that while its CNN-based Cross-scale Feature Fusion Module (CCFM) demonstrates satisfactory performance in conventional detection scenarios, the CNN-centric feature fusion mechanism exhibits several inherent limitations:

Constrained receptive field impeding information integration. The CCFM’s reliance on localized convolution operations restricts its ability to capture semantic correlations beyond immediate spatial neighborhoods, thereby compromising fusion effectiveness. In medical production line scenarios characterized by densely distributed objects, this limited receptive field potentially impairs the network’s capacity to differentiate features of small-scale objects and occluded objects.

Insufficient cross-scale and cross-spatial feature interaction. Although CCFM implements progressive cross-scale feature fusion, it lacks explicit mechanisms for modeling direct, high-order correlations across different scales and spatial locations. In scenarios with high object density and frequent occlusions, features can become entangled across scales, diminishing their discriminative power and subsequently affecting detection accuracy.

Inadequate high-order information capture. The architectural design of RT-DETR’s CCFM does not explicitly incorporate mechanisms for capturing high-order correlations between features, instead relying solely on linear convolution operations for feature fusion. This limitation becomes particularly pronounced in medical production line applications, where occlusions introduce complex non-linear high-order relationships that cannot be effectively represented through linear convolution-based fusion.

To address these limitations, we propose a novel fusion methodology that integrates Hypergraph Computation with Attention-based Modulation Fusion. The hypergraph computation module, inspired by the recent Hyper-YOLO22 network, establishes dynamic high-order feature associations to resolve cross-scale and cross-spatial information fusion challenges. Additionally, we incorporate a Modulation Fusion Module (MFM)23, adapted from single-image dehazing networks, which employs adaptive weighting mechanisms to emphasize salient regional features and mitigate feature entanglement issues. Furthermore, the introduction of attention modulation mechanisms effectively addresses feature contamination and ambiguity issues in medical production line scenarios where high precision is paramount.

Global channel pruning

While the aforementioned high-order fusion mechanisms substantially enhance detection performance in medical production line scenarios, they concurrently introduce increased model complexity and parametric scale, presenting deployment challenges in industrialized environments with constrained computational resources. Furthermore, deep networks often generate redundant channels during training, which may carry duplicated information or contribute minimally to recognition tasks, potentially leading to the model “memorizing” unnecessary features and subsequently causing overfitting phenomena. To address these challenges, we implement global pruning strategies specifically tailored to our designed network architecture. This optimization aims to reduce network redundancy and computational overhead while maximally preserving the original high-precision performance, enabling more efficient deployment in actual medical production line environments.

Experiments

Extensive ablation and comparative experiments were conducted on the AMPL dataset obtained from a real-world medical production line environment. All training, testing, and inference experiments were performed using an NVIDIA GeForce RTX 4090 GPU. The versions of PyTorch and CUDA employed were 2.2.1 and 12.1, respectively. Our network was trained for 200 epochs using the AdamW optimizer, with an initial learning rate of 0.0001, a momentum of 0.9, a weight decay of 0.0001, and a batch size of 4. To ensure the reproducibility of our experiments, we fixed the random seed to 1 for training processes.

A critical observation from Table 6 is the superior computational efficiency of POLAR-DETR. With only 44.1G FLOPs and 15.81 M parameters, our method achieves the optimal trade-off between accuracy and efficiency. Notably, FBRT-YOLO-M achieves the lowest parameter count (7.36 M) among all methods, yet falls short of our detection accuracy by 1.7% AP75 and 2.7% AP, indicating that our architectural design more effectively leverages model capacity.

The experimental results reveal several key insights: (1) Traditional two-stage detectors, despite utilizing pre-trained weights, exhibit suboptimal performance on the AMPL dataset, with Cascade R-CNN achieving only 62.1% AP despite its 69.21 M parameters, suggesting their limited adaptability to medical production line scenarios. (2) DETR-based methods generally demonstrate superior performance, with DDQ-DETR, CO-DETR, and Align-DETR exceeding 65% AP, validating the effectiveness of transformer architectures in handling complex spatial relationships. (3) The Fine-tuning based methods (D-Fine-M and DEIM-D-Fine-M) show promising results with identical FLOPs (58.4G) but different performance characteristics, where DEIM-D-Fine-M achieves 1.2% higher AP75 through improved architectural design. (4) Among YOLO variants, YOLOv13-L achieves the highest accuracy (76.5% AP75, 68.9% AP) but requires 84.3G FLOPs, nearly double our computational cost.

The performance gap between POLAR-DETR and competing methods is particularly pronounced in the AP75 metric, which demands higher localization precision. Our method’s 77.8% AP75 represents a significant advancement, surpassing the second-best method (YOLOv13-L) by 1.3% points and the efficient FBRT-YOLO-M by 1.7% points. This improvement is especially meaningful in medical production line applications where precise localization is crucial for robotic manipulation tasks.

Conclusion

This research successfully develops the POLAR-DETR real-time end-to-end object detection framework, effectively addressing critical technical challenges in medical production line environments, including dense occlusion, dramatic scale variations, and small object detection. Through systematic architectural innovations and optimization strategies, we achieve an optimal balance between detection accuracy and computational efficiency. Specifically, the Polarized Occlusion-Aware Hierarchical Feature Encoder significantly enhances model comprehension of complex scenes through its multi-level spatial-semantic processing mechanism. The synergistic effect of the Multi-level Hierarchical Attention Fusion module and Hierarchical Dual-Branch Attention Fusion module effectively improves the precision and semantic correlation capabilities of cross-scale feature fusion. Furthermore, the Hessian matrix-based global pruning strategy substantially reduces model complexity while enhancing generalization performance. This research not only provides crucial technical support for the intelligent upgrade of fully automated laboratory systems but also pioneers new research directions for Transformer-based real-time object detection in medical applications. Future work will explore multimodal information fusion and adaptive learning mechanisms to address increasingly complex and dynamic real-world application scenarios.
