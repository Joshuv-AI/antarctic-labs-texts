Prospective and concurrent metamemory of familiarity and working memory by rhesus monkeys
Authors: Jad Nasrini, Tara Dove-VanWormer, Robert R Hampton
Published: 2025

ABSTRACT
AbstractMonkeys sometimes accurately predict their memory accuracy, a form of metamemory. The memory signals that support this ability may differ between memory systems and depend on when memory judgments are made. Working memory requires active maintenance through the delay interval. Familiarity allows recognition without active maintenance and is triggered by representation of memoranda at test. We measured metamemory prospectively, during delay intervals, and concurrently, at the time of tests, while six male rhesus monkeys performed tasks that favored working memory or familiarity. Metamemory was accurate at both times in both tasks, and highest for concurrent judgments in the familiarity task.

Memory manifests as multiple dissociable systems that process different types of information (Tulving 1972; Sherry and Schacter 1987; Gabrieli et al. 1995; Squire 2004). For example, working memory is a limited-capacity store that actively holds and manipulates information (Cowan 2008; Baddeley 2010; Oberauer 2019), whereas familiarity refers to a memory process that distinguishes previously seen items from novel items without active maintenance (Yonelinas 2002). These two memory systems can be dissociated in monkeys (Basile and Hampton 2013; Brady and Hampton 2018; Brown and Hampton 2020).

Monkeys sometimes demonstrate metamemory, accurately predicting their performance in memory tests (Hampton 2001; Hampton et al. 2004, 2020; Kornell et al. 2007; Smith 2009; Beran et al. 2016). These metamemory judgments may be based on different signals from different memory systems. In one set of experiments, monkeys studied sample images and then chose to accept or decline match-to-sample memory tests either prospectively, during the delay interval and before seeing the test, or concurrently, while viewing the test display. Monkeys were more accurate on trials in which they could choose whether to accept the test compared to trials in which the only option was to complete the trial, indicating a metamemory benefit (Brown et al. 2019). Monkeys in that study also reaped more metamemory benefit when they chose to accept or decline trials concurrently, while viewing the test display, compared to prospective choices made in the delay interval.

Monkeys may reap more metamemory benefit from concurrent judgments because more information about the difficulty of a given test is available when viewing the test than is available during the delay interval. Brown et al. (2019) hypothesized that prospective metamemory judgments are largely based on assessment of working memory, whereas concurrent judgments involve assessment of working memory plus additional information about the relative familiarity of the test stimuli that only becomes available when the test display is presented. In the Brown et al. (2019) study, monkeys were tested using a small set of repeating images. Using a small set of images emphasized working memory over familiarity because repetition makes targets and distractors similarly familiar at test (Basile and Hampton 2013; Brady et al. 2021).

Our study extends Brown et al. (2019) by manipulating the relative contribution of working memory and familiarity across conditions. We did this by using a small and a large set of images in different sessions of trials. Match-to-sample tests using small sets of repeating images emphasized the contribution of working memory maintenance during the delay interval because frequently repeated images are all familiar at test. In contrast, tests using the large set of images emphasized the contribution of relative familiarity signals evoked at the time of test because monkeys could discriminate the familiar sample image from the unfamiliar distractor images at test. Thus, in the case of tests with the small set of images, working memory is necessary for accurate choice, whereas in tests with the large set of images, working memory is not needed (Basile and Hampton 2013; Brady and Hampton 2018; Brown and Hampton 2020; Brady et al. 2021). Monkeys performed memory tasks that favored working memory or familiarity and made either prospective or concurrent metamemory judgments (Fig. 1).

Match-to-sample memory tests with prospective choice (A) and concurrent choice (B). Prospective judgments occurred at the end of the delay interval, before monkeys had seen the test. Concurrent judgments occurred in the presence of the test images. Monkeys touched a self-start button twice to make a sample image appear. The sample image stayed on screen until it was touched twice. The screen was black for the memory delay. On two-thirds of trials, monkeys were given the choice to either accept the trial by selecting the checkmark symbol or decline the test by selecting the thumbs down symbol. On the remaining one-third of trials, the decline option was omitted. Pressing the accept button resulted in a memory test consisting of the sample image along with three distractors. On accepted trials, monkeys received a high reward for correctly identifying the sample, or no reward for an incorrect response. Pressing the decline button resulted in a red bar that monkeys had to press several times to receive a guaranteed but smaller food reward. On concurrent trials, the test images appeared dimly while monkeys chose to accept or decline, then reverted to full brightness if the monkey accepted the test (B). Tests that emphasized working memory (using a small set of four images) or familiarity (using a large set of rarely repeating images) were conducted in separate blocks of trials.

We used these procedures to test two hypotheses about the contributions of working memory and familiarity to metamemory judgments. First, if prospective metamemory judgments depend largely on working memory, then the metamemory benefit should be higher in the small set condition, which emphasizes working memory, than in the large image set condition, which favors familiarity. Second, if the additional metamemory benefit garnered from concurrent metamemory judgments is largely supported by familiarity, then the concurrent metamemory benefit should be higher in the large set condition, which favors familiarity.

We studied six adult male rhesus macaques (Macaca mulatta, mean age at the start of the Experiment = 14.34 years, SD = 2.07). Monkeys were tested in their home cages, where they had visual and auditory contact with other adult male monkeys. These monkeys had long histories of cognitive testing, including match-to-sample and metamemory tests. Testing was completed on touchscreens (Elo Touch Solutions, Milpitas, CA) connected to laptop computers and automated food dispensers (Med Associates, Fairfax, VT). Custom testing programs were written for the experiments using Visual Basic. Monkeys were rewarded for correct responses with fruit-flavored primate food pellets (TestDiet, Richmond, IN). Monkeys worked ad libitum from about 10 a.m. to 5 p.m., 6 days per week, and the calories from food rewards earned during testing were subtracted from each monkey’s daily caloric allowance, which was determined by veterinary staff.

We used delayed match-to-sample (DMTS) tasks in which monkeys studied sample images that they had to identify among distractors after a delay (Fig. 1). On two-thirds of trials, monkeys chose to either decline the memory test to receive a small reward or accept the test and receive a greater reward if correct, or no reward if incorrect. Thus, monkeys could maximize rewards by accepting tests on which memory of the sample was good and avoiding tests on which memory was poor. The remaining third of trials lacked the decline response option, and monkeys had to proceed to the memory test. These “forced” trials provided a measure of baseline accuracy. Half of choice trials presented the metamemory choice prospectively, before the test (Fig. 1A), and the other half concurrently, in the presence of the test (Fig. 1B). Each monkey’s accuracy was individually titrated by adjusting the delay interval until they made between 45% and 70% correct responses on “forced” trials. The number of touches to the red bar required to complete declined trials was also titrated until each monkey declined between 35% and 70% of trials. Monkeys were first tested using this procedure with a small set of four full-color images, which were repeated on every trial in the small image set. In this condition, the sample was chosen pseudo-randomly from the four images on each trial, and all four images appeared in each memory test. A similar procedure was then repeated using a large set of 12,000 images. In this testing, a novel image was selected as the studied sample on each trial, and was presented with three novel distractors at test. These images only repeated after all 12,000 images had been used. The maximum number of large set sessions needed to complete the study was 99 sessions of 120 trials, or 47,520 stimulus presentations, so no image from the large set was repeated more than four times in the study, while each image in the small set was repeated several thousand times. To titrate memory accuracy on trials using the large set of images, large set images were degraded in addition to titrating the memory delay until accuracy was in the same criterion range (Supplemental Fig. S1). Degrading the images was necessary because monkeys were much more accurate initially in tests using the large set of images. Finally, to evaluate whether any differences between performance with the large set and small set of images were due to degradation of the large set of images, we repeated the procedure a third time using a small set of four images that were degraded using the same process. For each of the three iterations of the experiment, data were collected for 30 sessions of 120 trials, while behavior was in the criterion ranges. The full experimental procedure is described in greater detail in the Supplemental Material.

Thus, metamemory was evaluated prospectively and concurrently in tests using three image set types: small set of full color images, large set of degraded images, and small set of degraded images. For each image set type, we calculated metamemory benefit by subtracting each monkey’s accuracy on forced tests from their accuracy on accepted tests. Monkeys made accurate metamemory judgments to the extent that this score is greater than zero; that is, to the extent that they chose to take tests when memory was good and declined tests when memory was poor.

Monkeys made accurate metamemory judgments both prospectively and concurrently, and in all three image set conditions, indicated by metamemory benefit scores above 0. The fact that monkeys showed a prospective metamemory benefit even in tests with the large set of images suggests that some information about memory accuracy was available to the monkeys during the delay, even when the task emphasized relative familiarity. While there is evidence that working memory maintenance is not necessary in these tests emphasizing familiarity (Basile and Hampton 2013), monkeys may have actively maintained images in memory anyway, making working memory available for metamemory judgments. But given that prior evidence indicates attenuated working memory in tests with a large set of images (Brady and Hampton 2018), we might expect an attenuated metamemory. Instead, we found similar prospective metamemory benefits in tests with small and large sets of images. Another explanation for the lack of difference might be that monkeys did not make metamemory judgments on the basis of memory per se, but instead responded to some “public” or external predictors of accuracy that would be common to tests with both size image sets (Hampton 2009). While use of such cues is possible, multiple studies conducted under similar conditions suggest that memory monitoring was more likely to predict whether a monkey declines a memory test or seeks additional information before a test (e.g., Hampton 2001; Basile et al. 2015).

To evaluate whether prospective and concurrent metamemory judgments operated similarly with small and large image sets, we fit a mixed effects logistic regression model using monkey identity as a random factor, and stimulus set (small set full color, large set degraded, small set degraded), metamemory choice (accepted trials, forced trials), and choice timing (prospective, concurrent) as fixed effects, along with their two-way and three-way interactions (Fig. 2B; Supplemental Table S1). In addition to this regression analysis, we initially analyzed these data using a 3 × 2 two-way repeated-measures analysis of variance (ANOVA) using the difference scores between accepted and forced trials we calculated as described previously. There was no significant interaction between the two factors in the ANOVA, but the test was likely statistically underpowered to detect such an interaction with six subjects. Nevertheless, we report this analysis in greater detail in the Supplemental Material for comparison to the analysis reported below.

Using a baseline of forced trials with a prospective timing and the small set of full color images, we found a significant main effect of metamemory choice showing that monkeys were more likely to be accurate on accepted trials overall (Fig. 2B, accepted compared to forced trials; β = 0.289, 95% CI = [0.191, 0.387], P < 0.0001). Monkeys therefore showed a metamemory benefit across all conditions, replicating our first analysis and the data in Figure 2A. We also found a significant three-way interaction showing a significant increase in accuracy from the baseline to trials from the large image set, which were accepted after seeing the test (Fig. 2B, orange line in the middle panel; β = 0.222, 95% CI = [0.020, 0.424], P = 0.031). This interaction indicates that the metamemory benefit was strongest after seeing the test stimuli particularly on trials with the large set of images. In tests with the large set of images, the entire set of 12,000 images was used before any were used again. Because four images are used in each test, using the entire set required 3000 trials. Thus, the sample image would be relatively familiar at test because it had just been seen during study, and the three distractor images would not be familiar, allowing monkeys to identify the correct image using familiarity alone. As such, the added metamemory benefit seen in concurrent tests with the large set of images may be driven largely by familiarity. Finally, the intercept was also a significant predictor in the model, indicating that monkeys were more likely to be correct than incorrect across all trials (Fig. 2B, all points are above 0.5; β = 0.567, 95% CI = [0.416, 0.718], P < 0.001). No other main effects or interactions were significant predictors in the model (Supplemental Table S1), and the pattern of results we found in the aggregate data is consistent with the data from individual monkeys in the study (Supplemental Fig. S2A reflects the analysis by t-test described in the text, and Supplemental Fig. S2B reflects the generalized linear mixed model analysis).

The fact that overall accuracy was titrated by changing the memory retention interval across stimulus sets for individual monkeys (Supplemental Fig. S3) certainly constrained accuracy in the main matching to sample task. This was done with the intention of producing a fair comparison among conditions. However, it is possible that titration of accuracy also constrained the effects of metamemory judgments. This may have masked differences in accuracy among the metamemory conditions, biasing results toward finding no differences among the different metamemory and image set conditions. Nevertheless, overall performance was not at floor or ceiling within any of the task conditions (Supplemental Fig. S4), and we did find an additional metacognitive benefit on concurrent trials in the large set, which would have been detectable in any of the other stimulus conditions (Fig. 2). Thus, while the titration procedure may be a limitation of this study, we believe it was used with good justification.

Monkeys made more accurate concurrent than prospective metamemory judgments only when tested with the large set of images (Supplemental Table S1). This differs from Brown et al. (2019) who found superior metamemory in the concurrent condition using a small set of images. In that study, Brown et al. suggested that even with a small set of repeating images in which all of the images are quite familiar, there may still be a small relative difference in familiarity because the sample image was the image seen most recently. One potential reason we did not obtain the same result is that our titration and data collection phases were significantly longer than that those in the Brown et al. study. Extended training may have more fully saturated the familiarity of the repeating images, eliminating any residual relative familiarity caused by study in a given trial.

In summary, we found that monkeys make accurate metamemory judgments across image set sizes and at both prospective and concurrent time points. This result highlights the generality and robustness of monkey metamemory. We did not sharply dissociate metamemory in tests putatively more dependent on working memory from those more dependent on familiarity. This result may indicate that working memory is engaged and subject to cognitive monitoring even in tests with the large set of images that favor familiarity and could be completed accurately without working memory maintenance (Brady and Hampton 2018). We found some evidence that familiarity contributes to concurrent metamemory judgments more than prospective judgments in tests that emphasized familiarity. This result is consistent with a greater contribution of familiarity over working memory at the time of test in tasks low in proactive interference. Further work should be conducted to isolate the contributions of specific memory systems to performance and to track the extent to which metamemory judgments are supported by these different memory systems.
