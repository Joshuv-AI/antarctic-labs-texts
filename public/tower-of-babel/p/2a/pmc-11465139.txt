Comprehensive maintenance dataset of building facilities for planned preventive and unplanned maintenance in North American universities
Authors: Ashish Kumar Pampana, JungHo Jeon, Soojin Yoon, Theodore J Weidner
Published: 2024

ABSTRACT
AbstractHistorical building maintenance data were collected from twelve universities in the United States (U.S.) and Canada, spanning from the year 2002 to 2021, with a particular focus on Planned Preventive Maintenance (PPM) and Unplanned Maintenance (UPM). The collected data underwent preprocessing and organization based on the Facility Management Unified Classification Code (FMUCO), Fig. 1 which was developed to classify heterogeneous building maintenance data. The resulting dataset comprises nine attribute groups (university, building, system, subsystem, component, work order, work order cost, work order labor, and weather) and their corresponding data attributes. The dataset aims to (1) provide insights into the current status of building management for campus-sized institutions and (2) facilitate data-driven analyses of facility management.Keywords: Facility management, Maintenance, Planned preventive maintenance (PPM), Unplanned maintenance (UPM), Database, FMUCD

Background

Multi-asset management for campus-size institutions, such as universities and government offices, is challenging not only in prioritizing maintenance, repair, and replacement (MR&R) but also in allocating resources (e.g., budget). Insufficient facility maintenance, including deferred maintenance and Unplanned Maintenance, have accelerated facility deterioration at most universities in North America [3]. Furthermore, an unexpected component (or equipment) failure can cost a significant amount of money or time to restore, which results in uncertainty in budget allocation in the facility management [4,5]. Therefore, there is a need to explore and identify best practices and trends in Mega data of building management focusing on the use of Computerized Maintenance Management Systems (CMMS) for monitoring work order assignments. The dataset aims to provide insights into (1) the current status of building management for campus-sized institutions and (2) support data-driven analyses of facility management. The proposed dataset was developed based on the facility management data (e.g., work orders and labor hours) collected from twelve universities. This will shed light on the factors influencing work order estimates and critical system failure components. This dataset contributes valuable information for understanding best practices and challenges in university asset management.

Experimental Design, Materials and Methods

Data was collected from twelve universities following interviews with facility managers in Excel Workbook format. The collected data was preprocessed and organized where each row of raw data includes building, system, subsystem, component, work order description, work order cost, work order labor hours, weather information, etc. Each work order was classified to have unique identifier codes for the system, subsystem, and component corresponding to the work order details. The identifier codes were developed in the “Facility Management Unified Classification Code (FMUCO)” (Fig. 1) [6] by combining the “Uniformat II” classification system [7] and component details provided in “Whitestone Facility Maintenance and Repair Cost Reference” [8]. The individual Excel workbooks were combined and converted to Comma-separated values (CSV) text files with Python. The combined database is named “Facility Management Unified Classification Database (FMUCD).” A general overview of FMUCD database is presented in Table 2. Summary statistics for the FMUCD database are presented in Table 3, Table 4, and Table 5. These statistics were obtained using the ‘NumPy’ library in Python [9].

To visualize the relationship between variables and the variability in data objects from different universities, table plots for both Planned Preventive Maintenance (PPM) and Unplanned Maintenance (UPM) were generated using the ‘tabplot’ package in R [10]. The PPM dataset, comprising 2,224,663 objects with 1,500 row bins, included variables such as University ID, Building ID, System Description, Descriptive Code, Labor Cost, Labor Hours, and Minimum Temperature shown in Fig. 2. Similarly, the UPM dataset contained 1,469,204 objects with 1,200 row bins, utilizing the same variables shown in Fig. 3.

Table plot for planned preventive maintenance (PPM).

Table plot for unplanned maintenance (UPM).

The data distribution shows that some universities contribute more data than others, and there is a wide range of buildings and systems being maintained. The log-transformed labor cost and labor hours highlight the diverse maintenance efforts and associated costs, with a broad range of values indicating different levels of maintenance activity. Additionally, the minimum temperature data varies significantly, reflecting the geographic and temporal differences in the dataset. These visualizations provide valuable insights into the distribution and relationships between key variables, illustrating the comprehensive nature of the data collected. The table plots reveal significant variability in data objects across different universities and highlight the availability of specific variables like Labor Cost, which is available for nine out of twelve universities.

Limitations

The data for our study was collected from multiple universities, each of which may have different data collection methodologies, schedules, and criteria. This variability can introduce inconsistencies in the dataset, affecting its uniformity and reliability. The accuracy of the collected data is dependent on the methods used by each university. Discrepancies in data entry, reporting errors, and other inaccuracies can affect the overall quality of the dataset. Also, integrating data from various sources posed significant challenges, particularly in terms of aligning different formats, definitions, and units of measurement. This process required extensive data cleaning and transformation, which could introduce errors or inconsistencies. Additionally, ensuring the completeness of data across all participating universities was challenging. Some institutions might have incomplete records or missing data points, which can affect the robustness of the analysis.
