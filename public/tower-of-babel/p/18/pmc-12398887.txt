Dataset of personal protective equipment
Authors: Mei-Ling Huang, Ying Cheng
Published: 2025

ABSTRACT
Personal Protective Equipment (PPE) is critical to the safety and health of workers, especially in high-risk environments such as construction sites and manufacturing facilities. PPE such as helmets and reflective vests play an important role in protecting workers from potential hazards. To protect workers, we have developed a dataset specifically for PPE target detection. The dataset contains 2286 images. These images come from a wide variety of public data platforms and real-life scenarios to ensure a broad representation of applications. In addition, this dataset is annotated according to the official YOLO specification and is seamlessly compatible with popular object detection frameworks such as YOLOv8 and YOLOv11. This dataset improves construction site security and promotes better industrial safety standards.

Background

The motivation for creating this dataset arose from challenges identified in existing datasets related to PPE, such as hard hats and reflective vests. Many publicly available datasets were found to have incomplete or inconsistent annotations, making them unsuitable for training reliable machine learning models. In some cases, the annotations were entirely missing, leading to inaccuracies in model development.

To address these issues, this dataset was developed with a focus on completeness and clarity. It includes fully annotated images across four categories: Helmet, NoHelmet, NoVest, and Vest. The data were sourced from platforms like GitHub, Kaggle, Roboflow, and real-world photos taken by authors. This ensures a diverse and representative dataset, designed to support the training and evaluation of computer vision models for industrial safety applications. By prioritizing annotation quality, this dataset aims to overcome the limitations of previous resources and serve as a valuable tool for researchers and developers.

Data pre-processing

The dataset removes duplicate and low-quality images to improve the overall quality of the dataset. Follow the standard annotation format of the YOLO model. ALL photos were resized as a resolution of 640×640. Each image is labelled and categorized according to the official YOLO specification, and I have classified the data into four categories: (0) Helmet, (1) NoHelmet, (2) NoVest and (3) Vest. The annotation files are stored in the labels folder and provided in .txt format. The annotation rules are as follows: 〈class_id〉 〈x_center〉 〈y_center〉 〈width〉 〈height〉. The 〈class_id〉 is the class code; 〈x_center〉 and 〈y_center〉 represent the normalized coordinates of the center point of the bounding box on the x-axis and y-axis respectively; and 〈width〉 and 〈height〉 represent the width and height of the bounding box respectively. Fig. 1 is an example for the file 00034_jpg.rf.1c38acedce297348597042dcbfa21a39.txt. The content description is as follows: “0” represents the category of the image as a helmet, “0.646875” is the normalized coordinate of the center of the bounding box on the x-axis, “0.1609375” is the normalized coordinate of the center of the bounding box on the y-axis, “0.19921875” is the width of the bounding box, “0.17734375” is the height of the bounding box The content contains normalized bounding box coordinates and class IDs, which are structured data to facilitate the training and validation of machine learning models in object inspection tasks.Fig. 1Example of the Data Pre-processing.Fig 1

Training and validation images

The data is divided into two subsets: train and validation, each of which contains an images folder for storing training and validation images. These images cover workers wearing or not wearing PPE in multiple scenarios.

Training and validation labels

Each subset also contains a labels folder for storing annotation files (.txt format). Each labelled file corresponds to a single image and follows the format specified by YOLO, making it easy to use directly in the YOLOv8, YOLOv11 object inspection frameworks.

Types of tags

The labels in the dataset were classified into the following four categories: (0) Helmet: workers wearing helmets, (1) NoHelmet: workers not wearing helmets, (2) NoVest: workers not wearing reflective vests, and (3) Vest: workers wearing reflective vests.

The dataset contains a total of 2286 photos with a resolution of 640×640, including 1646 photos from the GDUT-HWD public dataset [1], which was also adopted in Wu et al. [2], 134 photos from the HelmetVest Computer Vision Project public dataset [3], which was also used by Li et al. [4], 306 photos from the Safety Helmet and Reflective Jacket public dataset [5], and 200 real-world photos taken by authors from different scenes.

The total number of images in this dataset is 2286, and does not include augmented images. The images have been randomly assigned as training images (1829 images, 80 %) and validation images (457 images, 20 %) for training and validation of machine learning models. Experimental Design, Materials and Methods

The annotation tool used in the study is Roboflow Annotate. The authors manually marked objects in the image and then export them into a YOLO format annotation file (.txt). The process is as follows:Step 1.Upload all images to Roboflow.Step 2.Manually mark the bounding box for whether the person is wearing a helmet or a reflective vest, and divide it into four labels: Helmet, NoHelmet, Vest, and NoVest.Step 3.Double check and make corrections for any errors after the labeling is completed.Step 4.Automatically generate two folders. The first folder contains the images, and the second folder contains the labeling files (.txt) corresponding to each image through Roboflow system. The file names of these labeling files will be the same as the images, so that they can be correctly matched during model training.Step 5.Use python to divide the labeled files into train and validation folders, and then divide them into images/ and labels to be directly used for YOLO model training.

The YOLOv8 model is developed based on the YOLOv5 model, which uses anchor-free detection and a new convolutional architecture to improve the accuracy of feature fusion and object detection. YOLO11 uses a new module and deep separable convolution to enhance the ability of feature extraction. It also optimizes GPU computing and parameter simplification to improve detection accuracy and speed. The experiments carried out using this dataset are briefly presented in Table 4. The Precision, Recall, mAP50 and mAP50–95 of the YOLOv8 model are 0.593, 0.692, 0.664 and 0.474, respectively in the detection of the PPE dataset. The Precision, Recall, mAP50 and mAP50–95 of the YOLOv11 model are 0.589, 0.730, 0.691 and 0.483, respectively. The structure and annotated format and data within the dataset are directly applicable to the YOLOv8 and YOLOv11 object inspection frameworks, making it a valuable resource for researchers, developers and practitioners. The dataset can be applied to improve industrial safety monitoring systems and enhance construction site safety.

Limitations

This dataset is limited to equipment commonly found on construction sites and does not include protective equipment found in other industrial environments. This dataset covers only four categories: Helmet, NoHelmet, NoVest and Vest. while comprehensive for PPE detection in construction contexts, do not account for other critical safety equipment or scenarios in different industries.
