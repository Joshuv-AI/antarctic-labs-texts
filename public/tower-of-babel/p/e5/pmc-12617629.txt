Persistent memory in network topologies following temporary stimuli
Authors: Federico Sevlever, Ariel Waisman, Santiago Miriuka, Alejandra C Ventura
Published: 2025

ABSTRACT
SummaryMolecular memory in signaling and gene regulatory networks shapes how cells respond to transient inputs. Here, we present a mathematical framework to quantify memory as changes in system state after temporary stimulation. Using computational models, we show that circuits with positive feedback loops, particularly those enabling bistability, sustain long-term memory, while certain negative feedbacks can erase it. We further identify minimal network motifs that reliably confer memory, revealing symmetry between activating and inactivating mechanisms. In addition, oscillatory circuits can encode memory even without positive feedback, storing information in the phase of their oscillations. Applying this approach to mouse embryonic stem cells exposed to transient differentiation cues, we find that different genes display distinct degrees of memory retention, with some reflecting partial reversion and others indicating commitment to differentiation. This framework provides a unified way to compare memory across systems and highlights how circuit architecture influences information storage in biology.Subject areas: Bioinformatics, Systems biology, Computermodeling

Introduction

In the context of cellular signaling and gene regulatory networks, memory is a key determinant factor underlying molecular mechanisms.1,2,3,4,5,6 In the cited studies, cellular systems are first exposed to priming inputs, followed by a time window, and then the stimuli. Observations indicate that the response to the stimuli depends on the priming inputs, suggesting that each system retains memory of the priming for at least the duration of the time window. In this work, we study molecular memory, in the sense that the physical storage is the concentration of a given molecule, a general mechanism found in plants,7,8 animals,9,10,11 fungi12 and bacteria.13

From a general perspective, memory is the capacity to store information from the past. It is typically defined in a context-dependent manner. In computing, memory refers to the amount of information a device can store. In complex systems, it is the dependence of the final state or position on its history, often associated with bi- or multi-stability or system hysteresis.14 In molecular biology, memory is associated to the capacity of storing information from past stimuli,14,15 or, what is the same, to the stationary response to a transient stimulus.16

A priori, these definitions can appear different, but they have common fundamentals. A computer memory device stores information in magnetic cells. These cells are magnetized with a transient stimulus and keep a stationary magnetization for a long time,17 due to hysteresis and bistability. The history of the stimulus dictates the magnetization value.

It is well known that positive feedback loops can provide bistability, hysteresis and memory.2,4,5,14,15,18,19,20,21,22,23 However, the varying definitions of memory, despite sharing a fundamental concept, lead to different measurement methods that are not directly comparable. For instance, in molecular biology, studies often take a binary approach to determine whether a system has memory or not, making it difficult to assess if a signaling pathway remembers one stimulus more than another. Additionally, comparing the memory of different pathways is challenging when they involve different numbers of molecular components.

In this work, we aim to provide a general mathematical and unified definition of system memory, along with the associated measurable observables to quantify it. We first propose this general definition for dynamical complex networks as our broadest approach. Next, we computationally test this definition across all possible 1-, 2-, and 3-node circuits, identifying circuits with memory and uncovering their underlying mechanisms. The approached we followed has been proven before24 and consists of making an exhaustive integration of all possible combinations of circuits and parameters. Then, scoring each one with our memory quantifier in order to finish with an ordered list of memory capability. This methodology successfully identify circuits that achieve biochemical adaptation,24 morphogen gradients detection,25 fold-change detection26 or multistability and stepwise stochastic transitions.27 Finally, we measure memory in the gene regulatory network of mouse embryonic stem cells, finding evidence of positive feedback loops, and discuss additional examples in biological networks.

Results

Proposed memory quantifier

The aim of this section is to devise a quantifier of the memory of any circuit. We introduce a quantifier for the memory of a system in response to a transient stimulus (M¯stimulus), where X¯(t) denotes the system’s state at time t:

It is important to remark that both X¯withstimulus and X¯withoutstimulus cannot coexist. In practice, the first corresponds to a stimulated system or experiment and the second to a control experiment with no stimulation.

Figure 1 illustrates the computation of M¯(t) using the simplest toy model with memory. It is a vector with the dimension of the system. In our toy example, it has dimension 1 because we have only one node for clarity purposes. Each coordinate of M¯ is the difference of the value of each variable with and without the stimulus. If M¯=0, the state of the system is equal with or without the stimulus, so it corresponds to no memory. Notice that each M¯ coordinate can be positive or negative. This accounts that the system can remember a stimulus no matter if it activates or inhibits some variable.

Bistability, hysteresis, and memory

Effect of increasing positive feedback strength from A–C using the toy model shown at the top of the three panels. For each case, both dose-response and time-response curves are presented, generated using step and square pulse inputs, respectively. For the dose-response analysis, we apply step inputs where the stimulus transitions from a low value I0 = 10−1 to I1 = 102. The reverse path scans decreasing values from high to low. For the time-response analysis, we use square pulses with the same range of values as transient stimuli.

(A) The dose-response curve displays a sharp transition but no hysteresis, indicating weak feedback. The system operates just below a saddle-node bifurcation, so responses always decay back to zero after the stimulus ends. This results in no long-term memory. The gap between the ascending and descending curves is due to the bifurcation ghost phenomenon (32), reflecting the system’s proximity to a saddle-node bifurcation.

(B) Moderate feedback induces reversible hysteresis in the dose-response curve. As the input decreases, the system switches off at a lower threshold, revealing bistability. However, time-response curves still decay to zero after transient stimulation, indicating the absence of long-term memory. The hysteresis delays deactivation, extending the transient response duration.

(C) Strong feedback gives rise to irreversible hysteresis in the dose-response curve. The system remains in a high state even as the input drops to low values, preventing deactivation. This sustained activation reflects bistability and results in persistent memory: time-response curves do not decay after stimulus removal.

The model (Equation 2) represents a dynamical model where some variable has an active (A) and inactive (1-A) states. The total amount of A is conserved and normalized to 1, with no loss of generality.28 This model is widely used in enzymatic reactions, where A represents, for example, an active or phosphorylated protein proportion.

The variable A is a continuous quantity that ranges between 0 and 1, and it cannot take negative values. Conceptually, A represents the fraction of molecules in an active (or phosphorylated) state within a population. Although individual molecules are binary—each being either active or inactive—A captures the ensemble behavior, reflecting the proportion of the total molecular pool that is active at a given time. Accordingly, 1-A represents the fraction of inactive (or dephosphorylated) molecules. Even though each node is described as having two reversible states, what is modeled is the continuous population-level variable A, not the binary state of individual molecules.

The model includes three terms: the stimulus (I, first term), autoactivation (second term), and basal repression (last term). Each of these terms follows Michaelis-Menten kinetics28 and are characterized by two parameters (kij and Kij). The autoactivation introduces a positive feedback loop, which, depending on its relative strength, can lead to bistability.19 Einh represents the concentration of the basal repression enzyme.

Figure 1 summarizes how memory emerges from a saddle-node bifurcation,29 increasing a positive feedback strength. Panels A-C depict the dose and time responses of the model to sustained or transient square pulse stimuli, respectively, while increasing the strength. Panel A shows weak feedback, which is not sufficient to provide bistability or hysteresis, and after the transient stimulation, the system cannot remain activated. Panel B shows stronger feedback, which provides hysteresis and bistability as the stimulus drives the system through a saddle node bifurcation,30 and a new stable fixed point emerges. As a result, temporal responses exhibit a delay, and the system “remembers” the transient stimulus as it remains activated for a short time. However, the system eventually inactivates, as the feedback is still not strong enough to maintain activation. Panel C shows feedback strong enough to keep the system activated even in the complete absence of stimulus. This implies that, if the transient stimulus exceeds a certain threshold, the system will continue to activate itself indefinitely, achieving long-term memory.

This example points out that bistability provides memory to a system, in the way that each fixed stable point stores some information about the past, M¯ is marked in every scenario. This quantifier can also be obtained from quantifying if the temporal curves from different stimulus intensities are joining or separating in time. If two curves are closer than the experimental resolution, we would not be able to distinguish them, losing information about the past. In this way, the quantifier is analogous to measuring how much information we are retaining in time. This idea is further described in STAR Methods > method details > the memory quantifier measures information retained from initial condition.

It is important to emphasize the vectorial nature of M¯. M¯ captures multi-dimensional differences in system state, and its magnitude provides a summary of how far the system moves in state space as a consequence of the stimulus.

The state vector X¯ represents the full state of the system at a given time. Each component of X¯ can represent any measurable variable of interest, such as concentrations of proteins, RNA molecules, or other molecular species relevant to the system under study.

The system has memory if M¯≠0, i.e., at least one component of M¯ is nonzero (in an ideal-theoretical system). This provides a concrete and general numerical tool to assess how much the system’s state has been altered by a stimulus. Its vectorial nature allows both flexibility across systems and comparisons of memory storage across components.

Since each component of X¯ represents a potentially different variable—such as a protein concentration or an RNA count—normalization is typically performed individually for each variable. In practice, this often involves normalizing each variable to its value under a control (non-stimulated) condition. This ensures that the differences captured by the memory vector M¯ reflect relative changes induced by the stimulus, rather than absolute magnitudes that may be difficult to compare across variables of different nature.

For comparisons across components of different nature, each component of M¯ can be normalized by the resolution of the measurement system (e.g., the minimal detectable difference for each variable or the standard deviation of a noisy variable), which has the same units. This normalization yields a nondimensional version of M¯ that enables consistent and interpretable cross-component and cross-system comparisons of memory. In this form, a component of M must exceed 1 to indicate that memory is detectable by the measurement system. If any component lies between 0 and 1, this suggests that the stimulus has not activated the corresponding variable in a manner distinguishable from stochastic drift, or not strongly enough for reliable detection. In such cases, traditional statistical tests or repeated measurements may be necessary to determine whether the stimulated system is in a significantly different state from its non-stimulated counterpart.

The key interpretation of M¯ is indeed that a significant non-zero value indicates the presence of memory in the system. However, beyond this binary assessment, the magnitude of M¯ reflects the degree of memory—namely, how much the system’s state is altered by the stimulus and, therefore, how much information about that stimulus is retained.

A larger M¯ indicates a greater difference between the stimulated and non-stimulated states, which in turn suggests that the memory is stronger in the sense that it may be more easily detectable—either experimentally or by downstream systems that readout the state. On the other hand, a small (but non-zero) M¯ reflects a weaker form of memory, which could still be meaningful but harder to detect, particularly in noisy or low-resolution conditions.

Algorithm for assessing long-term memory in circuits

In this section, this quantifier will be applied to identify mechanisms that can provide systems with long-term memory.

The main strategy, as first proposed to find systems with biochemical adaptation,24 is to integrate every possible circuit composed by 1, 2 or 3 nodes, taking into account all combinations of activations and repressions between each other and with themselves. We stimulate all circuits and compare their responses against the same systems with no stimulation, then compute M¯. Finally, we select those with long-term memory and look at their topologies.

Figure 2 illustrates an example of this massive integration for just two toy model circuits, one of which has a well-characterized memory, as it is capable of a permanent response to a transient stimulus,18 while the other does not. Both have basal activation and inhibition, and the difference is that one of them has a positive autoregulation (Figure 2B, left), the same model as in Figure 1. Autoregulation provides positive feedback leading to bistability and memory, as shown in the previous section.

We computationally integrated these models with and without a square transient stimulus, for 10000 sets of parameters for each one, using Latin Hypercube Sampling31 (Figures 2A and 2B, center-left). Then, we computed M¯(t) (Figures 2A and 2B, center) and saved, for each model and for each set of parameters, M¯ at final time (Figures 2A and 2B, center-right). Finally, we analyzed the distribution of M¯(tSS) (Figures 2A and 2B, right), where tSS is the time when the system reaches a stationary state. We analyzed the final value of M¯ because we are interested in classifying circuits according to their long-term memory, understood as the situation in which the system never returns to its pre-stimulus state.

An important step consists of deciding which threshold identifies circuits with memory from those without. Histograms in Figures 2A and 2B, right, show the two thresholds – Tsets and TM – we choose to define if a circuit has memory or not. A circuit has memory if it has more parameter sets than Tsets, where each one has a higher value of |M¯| than TM.

1, 2, and 3-node mechanisms for long-term memory

This section focuses on the resulting circuits after the massive integration explained in the previous section. We consider all potential circuits involving 1, 2, and 3 nodes. Each node within these circuits can either activate, inhibit, or remain non-interacting with other nodes and itself (refer to STAR Methods). Nodes with no activations or inhibitions from the others receive a basal one, as illustrated in Figure 3A. The total number of circuits examined is 3, 54, and 16,038 for 1, 2, and 3 nodes, respectively (Figure 3B). Circuits where the input receiving node is not interacting directly or indirectly with the output node, i.e., they are totally disconnected, are discarded.

After the application of the filtering thresholds, we found thousands of circuits with long-term memory (∼9000). We analyzed these large number of circuits and discovered that all of them had positive feedback connections; the majority had many but each of them had at least one. As we are interested in finding the minimal or simpler mechanisms that provide memory, we wish to discard those circuits which are just combinations of simpler ones.

We developed a method, detailed in the STAR Methods section and named Minimal Circuit Identification (MCI), to discard redundant circuits (Figure 4 and STAR Methods). An example subset of the original set of circuits found is illustrated in Figure 4 (light blue panel). Many of these circuits exhibit redundancies, involving two or more positive feedback loops. The developed method takes one circuit as input, then a new set of subcircuits is generated by eliminating just one different interaction of the original circuit (red and green panels). If any of the resulting subcircuits also belong to the original set (the light blue panel), it means that the input circuit is not minimal, as it contains at least one redundant interaction. In this case, the circuit is discarded (shadow circuits in the bottom dark blue panel). On the contrary, if no subcircuit is repeated, the original circuit passes the filter.

There is a perfect analogy between the two groups, allowing us to map circuits from one group to the other by simply inverting the type of regulatory arrow (activation for inhibition or vice versa) involving the node that switches from activation to inactivation to record the stimulus. This suggests that circuits capable of storing memory come in opposing pairs: one where the stimulus irreversibly activates a node and another where it irreversibly inactivates it.

The minimal circuit highlighted in Figure 5C has been found in Bacillus subtilis, responsible for differentiation into a transient competent state.13

In summary, we have found all possible combinations where the stimulated node is involved in one positive feedback. These circuits were modeled using Michaelian equations, which are widely used to describe signaling pathways and also transcriptional interactions when effective nonlinearities and saturation are present. Nevertheless, to directly test whether our results generalize to transcriptional regulation, we selected a representative set of circuits from Figure 5C3 and simulated them using a well-established framework for RNA dynamics.34 Specifically, we implemented standard transcriptional models in which gene expression is governed by the interplay of activators and repressors acting on transcriptional nodes. We applied the same analytical pipeline described in Figure 3C and found that all tested circuits reproduced the memory behavior observed in the Michaelian models. As a negative control, we used the same set of circuits but disrupted their positive feedback loops by removing a single key regulatory interaction. This allowed us to test the pipeline on circuits that are structurally similar but lack the feedback required for memory. Consistent with our expectations, none of these modified circuits exhibited memory under the transcriptional model framework. This analysis and the corresponding results are explained in detail in STAR Methods > method details > results can be extended to transcriptional models.

Following this, the next question we investigate is whether every type of positive feedback improves the memory of a given circuit or not, and if it is the only kind of network architecture that can provide memory.

Comparative analysis of neighboring circuits: Positive feedback enhances memory, negative feedback erases it

In this section, we use our quantifier to evaluate the memory contribution of a specific motif within a circuit, where a motif is a pattern of interactions between network nodes that appears multiple times within a network.35 Starting with our database of integrated circuits (Figure 3B), we applied a new algorithm that compares the memory of two similar circuits: one containing the motif and the other identical except for the removal of one regulatory connection within the motif. Since we are particularly interested in minimal motifs—where every regulatory interaction contributes to an emergent property—the motif is considered broken if any regulation is missing.

To identify all these pairs of circuits, we consider the space of circuits as a meta-network for each set of 1-, 2-, and 3-node circuits, encompassing all possible configurations (Figure 6A). This meta-network is a directed network where the nodes represent circuits, and an edge represents the addition of a regulation. In this meta-network, we can transition from one circuit to another if they differ by only one regulation, with the edge arrow indicating the direction of adding the regulation. Moving against the arrow indicates the elimination of the regulation. Additionally, we can classify edges into two types: green arrows indicate the addition of an activation, while red arrows indicate the addition of an inhibition.

Since there is only one possible regulation for the 1-node circuits, the meta-network is one-dimensional. For 3-node circuits, there are 9 possible regulation arrows, resulting in a meta-network with 9 possible directions to move from any circuit node. The topology of this network resembles a 9-dimensional hypercube, where each dimension has three states: inhibition, no regulation, and activation.

The meta-network allows us to define distances and regions of similarity between circuits. For instance, if we want to consider all 2-node circuits where the magenta node has positive autoregulation, we can achieve this by drawing a plane that cuts perpendicularly through the hypercubic network along the axis corresponding to the addition of the desired autoregulation. Figure 6B illustrates this process: every circuit to the right of the black vertical line includes the regulation, while none to the left do. Note that the line divides pairs of neighboring circuits. In each pair, the circuits are identical except for the chosen regulation, making them the comparable circuit pairs we were looking for. The circuits on the left lack the motif (positive autoregulation), while those on the right include it.

Figure 6C compares the temporal curves of neighboring circuits, where we can see that each circuit with the motif exhibits long-term memory, while its neighboring circuits lacking the motif do not. The parameter set was chosen to provide a clear example; however, it is important to note that all 10,000 parameter sets were considered for each pair.

The Neighboring Circuits Comparative Algorithm we have designed relies on comparing these neighboring circuits (see STAR Methods) to determine whether a specific regulation enhances or diminishes a circuit’s memory. This concept can be extended to apply the algorithm to a motif composed of multiple regulations. Suppose the motif includes both the autoregulation of the magenta node and an activation from this node to the green node. This motif involves two regulations, requiring a cutting plane for each one. The region containing the analyzed motif is the intersection of both cutting planes, which includes both regulations. In Figure 6B, this is represented by the circuit at the top right, as it lies at the intersection of the right column and the top row of the network. The resulting intersection contains only one circuit in the image, but in the case of the 3-node meta-network with 9 dimensions, which has 39 circuits, there are 39−n circuits in the region, where n is the number of regulations in the motif.

We applied this algorithm to every positive and negative feedback motif in the 2- and 3-node meta-networks (Figures 7A and 7B, respectively). The main conclusion is that positive feedbacks provide memory to a circuit, while some negative feedback can remove it. This observation is due to the fact that negative feedbacks shorten the dynamic range.36 Notably, the most effective negative feedback connections for suppressing memory are those in which the stimulated node (green) is directly inhibited—corresponding to the first motif from left to right. Conversely, the most effective positive feedback connections for enhancing memory are those in which the output node (magenta) is directly activated. It is important to note that these circuits are not symmetrically equivalent to those in Figure 5, because in this analysis we have only taken the memory in the magenta node as output. Figure 7C shows an example where the green node has a positive autoregulation, which provides bistability, hysteresis, and memory. The green node also activates the magenta node, and we compare two neighboring circuits that differ only in the magenta node repressing the green node. The circuit with this repression has a negative feedback loop coupled with positive feedback. Consequently, when the stimulus activates the green node, it turns on both feedback connections, leading to the repression of the green node, which then cannot activate enough to reach the higher fixed point. As a result, the circuit will no longer “remember” the stimulus.

Positive feedback enhances memory, while negative feedback erases it

Results from applying the neighboring circuits comparison algorithm (see Figure 6) to all positive (left) and negative (right) feedback motifs in 2-node circuits. Each bar represents the computed memory difference (CNM, Equation 4) for the specified motif. Light blue bands indicate control values, showing the 95% and 50% confidence intervals. All positive feedback motifs yield positive CNM values, with three out of four exceeding or approaching the 95% band—indicating a consistent memory-enhancing effect. Conversely, all negative feedback motifs produce negative CNM values, with two falling near the lower 95% threshold—suggesting that negative feedbacks generally erase memory.

(B) Impact of feedback motifs in 3-node circuits. Each bar corresponds to the CNM value for a distinct positive (top) or negative (bottom) feedback motif in 3-node circuits. As in panel A, light blue bands represent the 95% and 50% control intervals. Nearly all positive feedback motifs yield CNM values above the 95% control band, while nearly all negative feedback motifs fall below it. These results strongly support the general principle that positive feedback promotes memory, while negative feedback suppresses it. Exceptions in the positive group may arise when the stimulus-receiving green node is repressed, thereby limiting its activation and memory potential. Motif diagrams associated with each bar are shown below, along the horizontal axis, with arrows linking each to its corresponding value.

(C) Example of memory disruption by negative feedback. Two toy models (left) illustrate how adding a single repression can eliminate memory. The upper model contains a positive feedback loop via the green node’s autoactivation and no negative feedback. It retains long-term memory, as both green and magenta nodes are irreversibly activated following the stimulus (top plots). In contrast, the lower model includes a repression from the magenta node to the green node, forming a negative feedback loop. This repression limits the green node dynamic range, preventing it from reaching its autoactivation threshold. As a result, autoactivation fails, and the system no longer exhibits memory (bottom plots).

Memory encoding through oscillatory dynamics

So far, we have established that positive feedback connections can provide memory, which typically arises from bi- or multi-stability, where a stimulus transitions the circuit from one stable steady-state to another (Figure 1). In this section, we explore whether multistability is the sole cause of memory or if other dynamic features can also provide it.

We applied the memory quantifier to one of the simplest circuits capable of oscillation (Figure 8A, upper panel). This oscillation is facilitated by a mechanism known as frustrated bistability,37 which is observed in natural systems38 and generates robust oscillations through coupled positive and negative feedbacks.

Oscillating circuits enable alternative memory mechanisms

(A) Three example circuits demonstrate different ways in which oscillatory dynamics can encode memory. The top circuit features coupled positive and negative feedback loops. The negative feedback induces sustained oscillations, while the positive feedback stabilizes the green node in an active state once the stimulus is applied. This activation becomes irreversible due to the positive feedback, and the oscillations are permanently halted, thereby encoding the memory of the transient stimulus. The middle circuit is similar, except that the stimulus represses the green node rather than activating it. This repression irreversibly disables the autoactivation, allowing the system to pass to the oscillatory regime permanently once the stimulus is removed, effectively producing long-term memory. In the bottom circuit, which lacks a positive feedback loop, the green node is transiently activated by the stimulus. After the stimulus ends, oscillations resume, but potentially with a shifted phase. This phase shift retains information about the stimulus, representing a form of memory that does not involve irreversible activation nor positive feedbacks.

(B) Bifurcation mechanisms underlying the memory behaviors observed in panel A, illustrated through dose–response curves. In the top panel, the full circuit containing both feedback types transitions between an oscillatory regime and a fixed point. This transition represents a distinct bifurcation mechanism from the saddle-node bifurcation seen in earlier figures (e.g., Figure 1), with memory arising from the interplay between the two feedback loops. The middle panel shows the circuit after removal of the negative feedback loop, achieved by disconnecting the magenta-to-green activation. Without the feedback cycle, the system can no longer oscillate and instead exhibits bistable dynamics governed by a classical saddle-node bifurcation. In the bottom panel, the positive feedback is removed while the negative loop is retained. The resulting circuit preserves oscillations but loses irreversibility: the green node’s activation is reversible, and the system reenters the oscillatory regime once the stimulus dissipates. These examples demonstrate how different combinations of feedback structures govern the stability and reversibility of regimes.

(C) All 3-node circuits capable of producing oscillations in the absence of positive feedback. These oscillations are enabled by time delays introduced through a third node. The left panel shows circuits composed entirely of inhibitory interactions, while the right panel features circuits with two activating and one inhibitory interaction. The upper and lower circuits in each group are symmetric with respect to the direction of interaction (clockwise versus counterclockwise), and in the right panel group, there is additional symmetry under node permutation. In both categories, only one distinct mechanism is responsible for generating oscillations, represented by the two circuits highlighted in black. The bottom graph presents the distribution of memory values across all oscillating parameter sets (10,000 per circuit). Inset plots show the memory distributions for 100 control groups of non-oscillating parameter sets, all of which yield zero memory. These results indicate that oscillatory circuits, even in the absence of positive feedback, can encode memory of a stimulus, through changes in oscillation phase as shown in panel A.

This circuit exhibits memory because a stimulus can activate the positive autoregulation,38 making the green node independent of activation from the magenta node. This prevents the green node from inactivating, irreversibly ending the oscillations. This mechanism allows the circuit to remember a stimulus despite lacking distinct, stable fixed points. The stimulus drives the system from a limit cycle to a stable fixed point (Hopf bifurcation). Figure 8B illustrates this mechanism. The coupling between positive and negative feedback provides both irreversibility and oscillations, respectively (upper panel). If negative feedback is removed, the system loses oscillations (middle panel), while removing positive feedback results in the loss of irreversibility (bottom panel).

In addition, we investigated the reverse mechanism: from a fixed point to a limit cycle. We found memory emerging from this mechanism using the same circuit (Figure 8A, middle panel). The main difference is that the stimulus represses the green node, consequently inactivating its positive autoregulation and irreversibly initiating oscillations.

So far, we have shown that memory can arise from bistability, which requires positive feedback. Now, we have also discovered circuits with no bistability— in the sense of having two stable fixed points—that also exhibit memory. These two different mechanisms share the need for positive feedback. Moving forward, we now explore whether there are other memory mechanisms that do not require positive feedback.

To address this question, we examine oscillating circuits that lack positive feedback. It is well-established that oscillating circuits lacking positive feedback require, instead, a delay between the activation of a node and its subsequent inhibition.36,39 This delay can be introduced by a third node in the negative feedback loop. Two-node circuits cannot oscillate unless positive feedback provides the bistability that compensates for the lack of delay. We focused on a three-node circuit composed solely of a negative feedback mechanism, depicted in Figure 7A (bottom panel). Since no two-node circuit can oscillate without positive feedback, this circuit is one of the simplest that can oscillate while lacking positive feedback.

In this scenario, the system is oscillating, and the stimulus temporarily disrupts this oscillatory state. Since there is no positive feedback, the disruption is reversible, and the system resumes oscillating once the stimulus is removed. Although the system returns to the same oscillatory regime, the oscillations exhibit a phase shift due to the stimulus. If the stimulus duration is appropriately matched to the oscillation period, it can leave the system in a counter-phase state compared to its non-stimulated condition. This phase shift is a measurable parameter that retains information about the past stimulus, thereby serving as a form of memory.

This new mechanism of memory allows us to test our quantifier in a totally different scenario. In order to prove its generality, we took all these simple oscillating 3-node circuits lacking positive feedback connections. They can be classified into two groups: two repressilators (Figure 8C, left dashed panel) and six positive-positive-negative regulators (Figure 8C, right dashed panel), both extensively studied.38,40,41 The repressilators exhibit clockwise – anticlockwise symmetry. Similarly, the six positive-positive-negative regulators also exhibit this symmetry, along with rotation among the three regulation arrows.

From each symmetric group, we selected one circuit and subjected it to integration over 10,000 sets of randomly chosen parameters using Latin Hypercube Sampling.31 Each parameter set for each circuit was integrated twice: once with a stimulus and once without, to compute M¯(t) and its integral over a specified time period.

After integration, we categorized parameter sets automatically as either oscillating or non-oscillating. Figure 8C (dark gray panels) displays distributions of the integral of M¯(t) for the oscillating group and for 100 groups of non-oscillating sets. Each non-oscillating group was randomly selected from all non-oscillating sets and contained the same number of sets as the oscillating group.

For both circuits, only the sets classified as oscillating exhibit memory, regardless of the magnitude. None of the non-oscillating sets from any group exhibit a memory value greater than zero (Figure 8C, dark gray panels insets). This leads to the conclusion that the memory quantifier is useful even with these mechanisms, providing evidence of its generality.

To test these findings, we must consider that the oscillation phase may be sensitive to intrinsic stochastic fluctuations in biochemical systems. The key question is: how long can memory encoded in phase information persist, and how do fluctuations erase it?

Figure 9 summarizes a simulated experiment addressing this question, using the Gillespie algorithm42 to incorporate stochastic effects.

Stochastic oscillatory systems can retain phase memory for multiple cycles

(A) Presents an example of a purely negative feedback circuit that exhibits phase memory despite lacking positive feedback, as previously illustrated in Figure 8. This circuit was used to evaluate how long phase information persists following a transient stimulus. On the left, the structure of the oscillatory circuit is shown. On the right, the temporal response of the green node is displayed for multiple single-cell simulations following the application of a transient square pulse. Each cell trace represents a distinct initial condition but shares the same parameters. Dashed colored lines indicate the mean timing of successive oscillatory peaks (from period 0 to period 9) across cells. Immediately after the stimulus, the system is fully synchronized, but stochastic effects gradually lead to desynchronization, as reflected in the spreading of peak times. Simulations were performed using the Gillespie algorithm.42

(B) Exploration of the impact of molecular noise on phase memory retention. The left column shows representative time traces for the three nodes at three levels of molecular abundance: 30 (high noise), 300 (intermediate), and 3000 molecules (low noise). As expected, fluctuations diminish as the number of molecules increases. The middle column presents the distribution of peak times for the green node across 100 cells, plotted over periods 0 through 9. Dashed lines indicate mean peak times per period. With higher noise (fewer molecules), peak times from different periods begin to overlap more quickly, indicating a faster loss of phase coherence. The right column summarizes these distributions using violin and boxplots. Medians of peak times align with integer multiples of the period, while the overlap between distributions narrows as noise decreases, illustrating prolonged phase memory at higher molecular abundances.

(C) Illustration of a simulated experimental protocol to quantify the duration of phase memory. Two cell populations are shown, non-stimulated (top) and stimulated (bottom). Initially, both populations are unsynchronized, as shown by the diverse activation states of the green node (gray-to-green color gradient). A transient stimulus (yellow pulse) synchronizes the stimulated population. After a variable number of oscillatory cycles, a second, phase-sensitive stimulus (dark yellow) is applied. Only cells in a specific phase—those whose green node activity exceeds a defined threshold (dark blue dashed line)—respond to the second stimulus (highlighted in blue). As expected, only half of the non-stimulated cells respond because of their totally random phase distribution. On the other hand, 60% of the stimulated cells respond, due to the remaining synchronization after stochastic drifts.

(D) Outcomes of the simulated experiment presented in C. The left graph shows the fraction of responsive cells as a function of molecular abundance, scanned logarithmically from 30 to 3000 molecules. Each curve corresponds to a different delay between the two stimuli, ranging from period 0 to period 9. At period 0, all cells respond due to initial synchrony. As more time elapses, the response fraction decreases due to increasing desynchronization. However, higher molecule numbers support longer-lasting synchrony, maintaining a higher response fraction over time. A response near 50% indicates complete desynchronization, as the activation threshold is based on the mean. The right graph plots the same data as a function of period delay, with curves representing different molecule numbers. The duration over which a large fraction of cells retains phase memory increases with molecular abundance. For instance, more than two-thirds of cells (magenta dashed line) respond up to: one period with 100 molecules, two periods with 320 molecules, three periods with 560 molecules, and more than four periods with 1000 or more molecules.

Figure 9A shows the model circuit from Figure 8, which exhibits phase memory in the absence of positive feedback. Several representative cells are shown following stimulation: the input synchronizes their oscillations for several cycles. Since memory is stored in the phase of these oscillations, it persists as long as synchrony is maintained—gradually diminishing over time due to stochastic fluctuations.

Figure 9B illustrates the precision of oscillation peaks over time for different molecular copy numbers, which modulate the strength of intrinsic noise. With only 30 molecules, the standard deviation of peak times approaches the oscillation period, making it difficult to distinguish between peaks from consecutive cycles—even between the first and second cycles after stimulation. In contrast, with 3000 molecules, oscillations are significantly more precise, allowing clear separation between peak times in later cycles, such as periods 9 and 10.

Figure 9C outlines the simulated experiment protocol: an initially unsynchronized population is first exposed to a priming stimulus, which synchronizes the cells. After some time, a second phase-dependent stimulus is applied. Only cells in a responsive phase will activate. If the population is completely desynchronized, the expected response is 50%, as half the cells will fall above and half below the activation threshold. A response significantly above 50% indicates that some degree of phase synchrony remains, meaning the population retains memory of the priming stimulus and can still be selectively controlled.

Figure 9D presents the results as a function of molecule number and number of cycles after the priming stimulus. Notably, with 1000 molecules—a biologically plausible value—memory is retained for more than four cycles.

In summary, these results demonstrate that an oscillatory system can store memory of a past stimulus in its phase. This mechanism may offer new insights into molecular systems governed by biological rhythms.

In developmental biology, it has been proposed that stem cells respond to differentiation signals only during the G1 phase of the cell cycle.43,44,45 Similarly, circadian oscillations have been linked to phase-dependent responses during adipose tissue differentiation.46,47,48 In both cases, cells exhibit different responses to identical stimuli depending on their phase, suggesting that priming stimuli can alter phase dynamics and thereby affect future cellular outcomes.

Mouse embryonic stem cells remember transient differentiation stimulus

Mouse embryonic stem cells (mESCs), derived from the developing blastocyst,49 possess the ability to self-renew indefinitely in vitro while retaining the potential to give rise to all embryonic lineages—an ability known as “naive” pluripotency.50 This naive state can be sustained by supplementing the culture medium with two small-molecule inhibitors (referred to as 2i) that block the differentiation pathways of MEK1/2 and GSK3α/β.32,51 mESCs cultured under 2i conditions exhibit transcriptional profiles similar to those of 4.5-day-old embryonic cells and are thus considered to be in a naive ground state of pluripotency.52,53

Upon withdrawal of 2i, mESCs initiate differentiation programs that mirror early embryonic development and lead to the emergence of terminally differentiated cell types.54 These cells remain pluripotent but are described as being in a “primed” state, reflecting their expression of early lineage-specification markers.32

In summary, mESCs can be maintained as homogeneous populations in the ground state of pluripotency, with every cell having similar, robust, and stable gene expression. Release from this with 2i withdrawal allows for the generation of primed cells, providing an important developmental model for studying cell differentiation.

In this section, we apply the proposed memory quantifier to investigate whether mESCs can retain a memory of a differentiation stimulus, and for how long. To this end, we cultured the cells in the naive state using 2i conditions, and then removed 2i for either 24 or 48 h to induce differentiation toward a primed state,55 where lineage commitment occurs. This removal is defined as our square-pulse ‘differentiation stimulus.’ The goal of this test is to provide a simple application example for our quantifier, while also illustrating the new perspective it offers on transcriptional responses.

Given the stability of the pluripotent state in 2i, a single measurement of the unstimulated condition is sufficient. Any potential drift is negligible compared with the strong fold changes observed upon stimulation, which have been widely reported during the 2i medium establishment.32,51 Moreover, our RT-qPCR measurements—averaged across the cell population—are inherently less sensitive to small fluctuations than single-cell methods.

Figure 10A shows time course experiments giving a 24 h or 48 h transient differentiation pulse to naive cells and tests if they go on the differentiation path or return to naive state. We tested cellular identities by RT-qPCRs for five marker genes: Nanog and Klf4, which are expressed in naive state, Oct6 and Fgf5, expressed in the primed state, and Brachyury, a mesendoderm lineage marker, expressed after the primed state.

mESCs remember a transient differentiation stimulus

(A) Time-course experiments designed to test whether mouse embryonic stem cells (mESCs) retain memory of a transient differentiation stimulus. The square-shaped pulses represent the withdrawal of 2i (two inhibitors that maintain pluripotency). Cells are exposed to transient differentiation pulses lasting 24 h or 48 h, followed by re-exposure to 2i medium for 24 h or 48 h, respectively. RNA expression levels are measured via RT-qPCR for each condition, shown using a black-to-green color scale.

(B) RT-qPCR results are shown as fold changes relative to the baseline condition (first black point), where cells are cultured continuously in 2i medium. The black dashed line represents the baseline (unstimulated) condition, where cells were maintained in 2i medium without exposure to differentiation signals. Black and green circles indicate the corresponding time points. Light gray and yellow arrows mark 24 h of culture in medium with or without 2i, respectively. Light and dark blue arrows represent the M¯(t) component for each gene, measured 24 h or 48 h after the stimulus, respectively. We measured mRNA expression for five genes: two associated with the naive state (Nanog, Klf4), two with the primed state (Oct6, Fgf5), and one involved in lineage commitment (Brachyury).

(C) RT-qPCR results from B grouped by gene pairs. For Nanog, Klf4, Oct6, and Fgf5, the expression patterns suggest that cells might be returning to their original state after the transient stimulus is removed, retracing the same path. In contrast, Brachyury expression follows a distinct trajectory, indicating that cells have committed to a new state—evidence that they “remember” the transient differentiation signal.

Figure 10B shows a fold change of these gene expressions relative to the initial naive state. Each arrow represents 24 h of culture with (-2i, yellow) or without (+2i, gray) the stimulus. Nanog and Klf4 both downregulate, as expected, during the differentiation pulse, and then partially revert the tendency after pulse ends. For Oct6 and Fgf5, we obtained analogous results, but genes first upregulate with the pulse and then downregulate, as expected because they are primed state markers.

The value of M¯ was computed based on the assumption that cells maintained in 2i medium (without stimulation) retain a stable pluripotent state, a well-documented observation in the field. Multiple studies have shown that under these conditions, gene expression remains homogeneous and constant.56 The memory quantifier (blue arrows) shows, for these four genes, that cells partially remember the pulse, as they do not completely recover their initial expression values. However, the amount of memory is higher 24 h post stimulus than 48 h after it for all cases, and this might be evidence of some memory loss. For Brachyury, the dynamic is qualitatively different. It upregulates, but only once the transient stimulus has ended. This implies that cells are committed to differentiation even when the stimulus has passed, and so they remember it. Our quantifier shows more memory after 48 h than 24 h, consistent with this commitment. These findings are consistent with a positive feedback that has recently been found between Nanog and Oct6, which might be responsible for the memory of this system.57

All five genes analyzed exhibit non-zero fold changes at both 24 h and 48 h post-stimulation, which indicates the presence of memory. However, the magnitude and direction of the fold change over time provide further insights into the dynamics of this memory. For most genes, memory decreases between 24 h and 48 h. This suggests that the system may be slowly reverting to the pluripotent state, potentially “forgetting” the stimulus, but further experiments over a longer time period must be done to determine this memory loss. In contrast, Brachyury shows a continued increase in fold change at 48 h, suggesting a reinforcement of the differentiation signal rather than a return to the baseline state. This divergence from the other genes makes Brachyury a particularly interesting case—it may act as a marker of irreversible commitment to differentiation, as opposed to genes whose responses fade over time.

Figure 10C shows the same data as in Figure 10B, but grouping genes in pairs. We can see that for every combination of Nanog, Klf4, Oct6, and Fgf5, the expression dynamic remains approximately in the same linear path and goes forward and back. This represents the partial loss of memory, as the expressions tend to go back to the initial point. In contrast, Brachyury expression pulls the dynamic out of a straight line. This reflects the advantage of the vectorial nature of the memory quantifier. It could happen that memory appears to be lost by just looking at some components of M¯(t) (or some nodes of the system). However, for the whole picture, we need to measure the relevant components, the nodes that are physically responsible for maintaining memory. Notice that another advantage is that it is not necessary to measure every node of a system. In this example, the measurement of Brachyury alone would be sufficient to determine the system’s memory of the pulse.

Discussion

This study presents a comprehensive mathematical framework to define and quantify memory in complex dynamical networks, with particular emphasis on signaling pathways and gene regulatory networks. Later in discussion, we summarize the key contributions and findings.

Definition of memory

We propose a new memory quantifier that offers a standardized, comparative, and comprehensive measure to capture the memory of a dynamic system in response to transient stimuli. This quantifier is derived by analyzing the system’s state evolution over time, both in the presence and absence of the stimulus. Building upon previous works,1,2,3,4,5,6,20,58 the key advancement here lies in the formal mathematical approach, which enables quantitative comparisons of memory across different systems and mechanisms.

Scope of the memory quantifier

It is important to emphasize that our memory quantifier is broadly applicable in principle to any dynamical system that responds to a transient stimulus – beyond the biological networks analyzed in this work. For example, although we do not explicitly study epigenetic memory mechanisms such as DNA methylation or histone modifications, these could, in theory, be incorporated within our framework. In this context, the addition or removal of methyl groups could be treated as the stimulus, and the quantifier would capture the resulting change in system state—e.g., the degree of methylation—reflecting a form of memory. This example may also be interpreted as an irreversible bistable switch, with methylated and unmethylated DNA representing two stable fixed points maintained by a positive feedback loop.

We note, however, that the direct numerical comparison of M¯ across systems involving different variables or measurement methods, must be approached with caution. In its unnormalized form, M¯ retains the units of each variable, making cross-system comparisons potentially misleading. To address this, we propose normalizing each component by the resolution of its corresponding measurement (e.g., standard deviation, detection limit), yielding a nondimensional version of M¯. This enables qualitative comparisons of memory detectability or robustness across systems, rather than absolute quantitative equivalence.

More broadly, the versatility of our framework allows it to be adapted to a wide range of systems – biological or otherwise – where memory arises from dynamic responses to transient inputs. Applications could include neuroscience, ecology, synthetic biology, and engineered control systems. In all cases, however, proper interpretation of M¯ depends on system-specific characteristics, including noise levels, the nature of the measured variables, and the design of control conditions. Rather than offering a universal absolute scale of memory, M¯ provides a structured and interpretable approach for probing how systems retain information over time.

Validation using toy models

The proposed memory quantifier was validated with established toy models,4,14,18,59 specifically focusing on a single-node system governed by positive feedback regulation. This model, traditionally used to illustrate how bistability induced by positive feedback loops results in memory, serves as a foundation. Our work formalizes this concept and extends the framework to a broader range of dynamical mechanisms.

Algorithm for long-term memory and minimal circuits

We developed an algorithm to determine whether a dynamical system exhibits long-term memory. This process involves calculating memory across different parameter sets and establishing thresholds to categorize circuits based on their memory retention. Through this method, we identify minimal circuits responsible for long-term memory. The results highlight that positive feedback loops play a crucial role in memory formation. Minimal circuit designs for one-, two-, and three-node systems are illustrated and analyzed in detail.

These findings are consistent with previous evidence in the literature.4,13,14,15,18,19,20,21,22,23,59 The proposed algorithm serves as a foundation for investigating memory in increasingly complex systems. Notably, the identified symmetry between activating and inactivating nodes may extend to other processing functions, such as adaptation or fold-change response. The key insight is that for every circuit exhibiting a specific function, there exists a symmetrical counterpart with equivalent capabilities. This concept can be formalized through group theory, and further research may uncover new mechanisms associated with particular processing features.

Comparison of circuits with positive and negative feedback

Our research introduced a comparative algorithm to evaluate whether circuits with positive feedback exhibit greater memory retention than those without. The results indicate that positive feedback enhances memory by providing bistability to the system. A transient stimulus can irreversibly drive the system from one stable state to another. Conversely, certain negative feedback connections can diminish memory by constraining the dynamic range, preventing the system from transitioning between distinct fixed points.

Beyond these findings, the neighbor circuits comparative algorithm can be applied to any motif or computational function of interest, addressing the broader question of whether a specific motif enhances or diminishes particular features.

Oscillations and memory

This study investigates the mechanisms of memory encoding in oscillatory circuits, demonstrating that memory can arise not only from bistable systems, as traditionally assumed,60 but also from non-bistable systems. We found that oscillations induced by feedback mechanisms—whether negative or a combination of positive and negative—can encode memory even in the absence of multistability. Specifically, oscillating circuits with positive feedback exhibit irreversible responses to stimuli, while circuits relying solely on negative feedback, without bistability, can also store information through phase shifts in oscillatory patterns.

The results indicate that the presence of oscillations is sufficient for memory encoding in biological circuits. This mechanism could have significant implications for understanding cellular behaviors that depend on cyclic processes, such as cell differentiation, the cell cycle, or circadian rhythms, where the phase of oscillation dictates cellular responses to stimuli. The generality of this memory mechanism was confirmed through extensive parameter sampling, revealing that only oscillating systems retain memory. This insight broadens our understanding of how dynamic systems can encode information, with potential applications in developmental biology and other fields where oscillatory behavior is crucial. In the context of steady-state dynamics, oscillations represent a higher level of complexity than fixed points. Their ability to store memory illustrates the potential for complex systems, characterized by more nodes or non-linear effects, to exhibit enhanced processing capabilities.

Experimental calculation of memory in mouse embryonic stem cells

We applied the proposed memory quantifier to experimental data from mouse embryonic stem cells (mESCs) subjected to transient differentiation stimuli. The results show that mESCs retain memory of the stimulus, with different genes exhibiting varying degrees of memory.

The goal of the experiments was to test the practical application of the memory quantifier, provide a straightforward example to support replicability, and illustrate the insights it can offer for transcriptional analysis. Although RT-qPCR is a widely used technique, we found no previous studies that quantified and visualized cellular memory using this approach. Importantly, the analytical perspective introduced by the memory quantifier is readily applicable to other biomolecule detection methods, such as immunofluorescence, Western blotting, or RNA-seq.

The vector M¯ represents memory as a five-dimensional profile across the genes studied, and each component of this vector is shown in the corresponding panel of Figure 10B (light blue for 24 h, dark blue for 48 h). The experimental observation of sustained and gene-specific memory profiles led us to hypothesize the existence of a positive feedback loop – specifically involving Nanog and Oct6 – which could stabilize certain gene expression states. This hypothesis was later experimentally confirmed and published by our group.57 The interaction corresponds to a double-negative feedback motif, which matches one of the minimal memory-generating motifs predicted in Figure 5B.

Concluding remarks

Studying molecular memory provides insights into the dynamics of cellular responses, and it is crucial for understanding how biological systems store and process information at the molecular level. Molecular memory helps explain how cells can “remember” signals, which influence their future behavior, such as gene expression patterns and responses to environmental changes.

In some scenarios, a sustained response to transient stimulation can be detrimental as it implies the loss of the system’s ability to return to its resting state, becoming desensitized to further signals. Additionally, a sustained response often requires constant use of cellular resources. This can lead to resource depletion and impair the cell’s ability to maintain homeostasis or perform other essential functions. Even for these detrimental consequences, the study of molecular memory is important and deserves attention.

This work presents a comprehensive framework for defining, quantifying, and studying memory in complex dynamical networks, with applications in gene regulatory circuits. The integration of mathematical modeling, computational analysis, and experimental calculation provides deeper insights into the mechanisms of memory in biological systems. Future research may uncover additional dynamical mechanisms using the same quantifier or explore other computational features through the developed neighboring circuits algorithm or the symmetry between activation and inactivation.

Limitations of the study

While the proposed memory quantifier M¯ can be applied to a wide range of dynamical systems, its interpretation requires careful consideration of system-specific characteristics. In its unnormalized form, M¯ retains the units of each variable, making direct numerical comparisons across systems with different variables or measurement methods potentially misleading. Normalization by the resolution of each measurement (e.g., detection limits, variability) yields a nondimensional M¯ that supports qualitative comparisons of memory detectability or robustness, but not absolute quantitative equivalence. Moreover, when components of M¯ fall below the detectability threshold, additional statistical analyses or replicates may be needed to confirm the presence of memory. Ultimately, the validity of conclusions drawn from M¯ depends on factors such as noise levels, measurement precision, and the appropriateness of control conditions.

Method details

Construction of all 1, 2, and 3-node circuits

For this study, we analyzed 1-, 2-, and 3-node circuits using a strategy inspired in previous works.24,59,62,63,64,65,66,67 We focused on enzymatic regulations modeled by Michaelis-Menten equations. This assumes no cooperativity, but it has been shown that this strategy extends to both cooperative enzymes, transcriptional models and mass action kinetics,24,60 which we have tested particularly for transcriptional models (See SI2. results can be extended to transcriptional models).

Each node exhibits two reversible states: active (A) and inactive (1-A), with a fixed total concentration. State interconversion is governed by interactions with other nodes. Nodes can activate, not regulate, or inhibit one another, resulting in three possibilities for each directed link between nodes.

1-node circuits feature only one autoregulation link. 2-node circuits include 4 links: both autoregulations and two where each node regulates the other. 3-node circuits involve 9 links: 3 autoregulations and 6 internode links – two regulation links per node with other nodes. Initially, this yields 31 = 3, 34 = 81 and 39 = 19,683 combinations for 1-, 2- and 3-node circuits, respectively. However, some combinations result in the output node being disconnected from the input. After excluding these disconnected circuits, we identified 3, 54, and 16,038 valid combinations for 1-, 2-, and 3-node circuits, respectively.

Equation 2 applies to a one-node network, while the equations for 3-node circuits are expressed in Equation 3. Coupling is introduced through the sums in X and Y, which are computed over specific node combinations {A,B,C} for each circuit, where X denotes activation nodes and Y denotes inhibition nodes. Each node has only one directed link to another: if Aactivates B, then A cannot inhibit B, although B can regulate A.

Taking the top equation for the dAdt as example, and since all regulations follow Michaelis-Menten dynamics, kXA and kYA represent the strength of the regulatory arrows but not their signs, which are explicitly defined in Equation 3 (e.g., the ∑Y={A,B,C} term is always negative). Both kXA and kYA are always positive. As Michaelian regulations are hyperbolic and could be sigmoidal, kXA and kYA define the strength of the regulatory arrows, while KXA and KYA represent equilibrium ratios—the values of nodes X or Y that provide exactly half the activation of node A at equilibrium. While kXA and kYA set the maximum values for the sigmoids (ranging from 0 to kXA or kYA), KXA and KYA determine the values of X and Y, respectively, where the sigmoid has the greatest slope and sensitivity. All these affirmations are analogous to the middle and bottom equations for dBdt and dCdt.

Some combinations lack incoming activation or inhibition for certain nodes. In these instances, we assume reversibility by incorporating a basal activation or inhibition. For these nodes ({A,B,C} = ∅), basal regulation terms +Eactkact1−X1−X+Kact and −EinhkinhYY+Kinh are added for activation and inhibition enzymes, respectively. Node A receives the input so includes an additional activation term and then never receives a basal enzyme activation.

The parameters kact and kinh are analogous to kYA, but they correspond to basal activation or repression, respectively. These regulations are also Michaelian and are included only if a node lacks activating or repressing arrows from other nodes.

Each term in the model is characterized by 2 parameters (kXA and KXA), resulting in two times the number of regulatory terms (#tearms) parameters for each circuit. The minimum number of termsincludes just one activation and one inhibition for each node: 2#nodes, including the input. The maximum number of terms occurs, for example, when each node activates itself and all other nodes, plus one basal inhibition term for each node plus the input: #notes2+#notes+1. In summary, the number of parameters ranges from 4 to 6 for 1-node circuits, 8 to 14 for 2-node circuits, and 12 to 26 for 3-node circuits. We performed an exhaustive parameter scan with 10,000 random sets for each circuit topology, selected using Latin Hypercube Sampling.31 Each parameter follows a log-uniform distribution, where each kXA ranges from 10−1 to 101 and each KYA from 10−2 to 102. In total, we integrated (3 + 54 + 16,038) ∗ 10,000 = 160,950,000 different circuits for this study.

The complete algorithm and parameters used are published in GitHub (See key resources table).

Numerical integration and memory computation

We quantify memory by numerically integrating each circuit through three stages (low, high, low) of a square pulse input, as depicted in Figures 2A and 2B, middle panels. Throughout integration, the low input value is set to 0.1 and the high to 5. Initially, all nodes start at zero for the first stage, with subsequent stages using the final values of each node from the previous stage as initial conditions to ensure continuity.

To accommodate circuits with diverse timescales, we employ an adaptive step Runge-Kutta method in Python for efficient integration. Integration in each stage continues until a steady state is achieved, defined as when each node’s change from one step to the next is less than 10−5. This criterion may fail in circuits with nodes possessing very long timescales (approximately 1% of cases), where integration may halt before steady state is fully reached. However, increasing the threshold extends integration times. The choice of 10−5 minimizes such errors while keeping integration times manageable for solving all 160,950,000 circuits within a reasonable time frame.

The complete algorithm and parameters used are published in GitHub (See key resources table).

We compute the long-term memory of each circuit’s parameter set for each topology using Equation 1. X¯withstimulus(tSS) represents the vector of values for 1, 2, or 3 nodes at the final time of the third integration stage. X¯withoutstimulus(tSS) denotes the value at the final time of the first stage, equivalent to the steady state without the square pulse stimulus. This approach avoids re-integrating each circuit without any loss.

We store these vectors for all circuits, forming the complete dataset as illustrated in Figure 3B table.

Determining arbitrary thresholds

Figure 2 depicts the algorithm devised to determine if a given circuit topology exhibits long-term memory. This determination hinges on two distinct thresholds, illustrated in the histograms of the right panels in Figures 2A and 2B. These thresholds are designed to exclude slower circuits where M¯stimulus(tSS)>0, which can result from interrupted integrations rather than genuine memory due to bistability or other mechanisms. This circuit has memory in the sense that its inactivation takes a long time, but it is not the mechanism we are interested in.

To characterize this artifact in memory computation, we analyzed the two simple circuit topologies depicted in the left panels of Figures 2A and 2B. Panel A circuit shows no memory, while panel B can exhibit bistability under certain parameter sets, resulting in memory. We measured the distributions of M¯stimulus(tSS) for 10,000 parameter sets for each topology and categorized each set based on whether the integration reached a steady state or was interrupted before. These labels were defined by observing the final states of circuits and adding time steps to the integration process. This operation, while time-consuming for all 160,950,000 circuits, was feasible for just these two topologies. Each topology’s distribution was divided into two groups: circuits that reached steady state (fully stationary) and those that were interrupted (non-stationary). Results are presented in the histograms of the right panels in Figures 2A and 2B.

As expected, panel A shows no integrated circuits with memory, confirming its lack of bistability. Any sets with M¯stimulus(tSS)>0 are artifacts of interrupted integrations. In contrast, panel B’s distribution reveals fully integrated circuits with M¯stimulus(tSS)>0, indicating genuine memory due to bistability.

In summary, we sum both labeled distributions to identify circuits with M¯stimulus(tSS)>0 but no actual memory. For circuits without memory, even slower ones, M¯stimulus(t)→t→∞0 must hold true. Therefore, these artificial cases have a low probability of M¯stimulus(tSS)≈1. To establish a threshold TM, we chose the minimum value greater than any M¯stimulus(tSS) in panel A’s circuit distribution affected by this artifact, resulting in TM = 0.8.

For stricter criteria across all topologies with memory, we introduce an additional threshold Tsets based on the number of parameters sets that cross TM. A topology must have more than Tsets circuits where M¯stimulus(tSS)>TM to qualify as having long-term memory. This threshold was fixed at Tsets = 3, inspired by the histograms in Figure 2. In conclusion, topologies with bistability typically exhibit numerous sets with M¯stimulus(tSS)>TM, as demonstrated in Figure 2B. Conversely, topologies lacking any memory rarely exceed two circuits with M¯stimulus(tSS)>TM.

Summarizing, both TM and Tsets are threshold parameters introduced to distinguish networks with true permanent memory from those that only exhibit slow decay due to parameter choices. These thresholds are arbitrary but were chosen based on empirical observations and the behavior of two example networks—one with memory and one without.

TM represents the minimum value that any component of the memory vector M¯ must exceed for a given circuit to be considered as exhibiting memory. Tsets then defines the minimum number of such parameter sets a network must have to be classified as possessing memory. In other words: a circuit has memory if it has more than Tsets parameter sets satisfying that any of the components of M¯ exceeds TM. In short, the thresholds were selected to reliably separate networks with permanent memory from those with only transient memory or slow decay, using a conservative and reproducible criterion.

Minimal circuits identification

The goal of this analysis presented in Figure 4 is to identify and isolate minimal motifs—networks that rely on a single, essential positive feedback loop to produce memory. Networks that contain multiple, independently functioning feedback loops are considered redundant, because their memory capability can be attributed to a combination of simpler, constituent mechanisms.

To perform this filtering, we analyzed each memory-capable network using the following algorithm.

Comparative neighboring memory

The purpose of this algorithm is to evaluate the influence of a motif in providing a specific quantifiable property to a circuit, focusing particularly on memory as defined in Equation 1. This algorithm takes a motif as input and computes a metric, CNM (Comparative Neighboring Memory), which indicates how much more or less memory this motif imparts to circuits that contain it.

Note that CNM can be either positive or negative. A motif with a positive CNM indicates that, on average, it contributes memory to a circuit. A negative CNM implies it removes memory, while a CNM near zero suggests the motif is not related to memory.

To determine how different a CNM must be from zero to associate a motif with memory, we designed a control measure. This involves summing over neighboring pairs but randomizing which term of each set is positive and which negative – with or without motif. We generate 10,000 randomized CNMs for each analyzed motif. These distributions were centered around zero as expected, allowing us to compare its deviation with the original CNM. Figures 6A and 6B shows the 50% and 95% confidence intervals from these distributions as light and lighter blue bands respectively. Bars above these bands indicate that the motif significantly contributes to memory, while bars below indicate that it significantly erases it.

Stochastic simulations

Stochastic simulations for Figure 9 were performed using Gillespie’s algorithm42 applied to the model in Figure 9A. This Monte Carlo method captures chemical system dynamics in low–molecule-number regimes, where interactions are infrequent and concentrations fluctuate stochastically.

The total number of molecules per node (active + inactive) was fixed and varied from 30 to 3000 to assess how noise intensity affects circuit behavior. Higher counts reduced fluctuation amplitude, approaching the deterministic regime.

At each step, the algorithm calculates the propensity of every possible reaction event—proportional to the terms in the deterministic formulation (e.g., Figure 3A)—draws the time to the next event from an exponential distribution, selects one event based on relative probability, and updates both time and molecular counts. This process iterates until the predefined simulation time is reached.

The complete implementation and parameters are available on GitHub (see key resources table).

The memory quantifier measures information retained from initial condition

In the introduction of this work, we presented various definitions of memory and discussed their relationships and equivalences. In this section, we mathematically prove that the amount of information retained from the past is precisely what the proposed quantifier measures. This quantifier is mathematically equivalent to the difference between a system’s state with and without having received a transient stimulus.

Imagine that we want to determine whether a system has received a transient stimulus. To do so, the system’s state must differ sufficiently from its state without the stimulus, according to our measurement resolution. This implies that if some measured variable, in the stimulated state, is too close to its value without the stimulation, we would not be able to distinguish between the two states. This led us to quantify how much two different states converge or diverge over time.

Equation 5 measures this for a 1-node (A) system. Starting at a given initial condition A0, the time derivative dAdt(A0,t) represents the direction the system is going at, for a given time t. The second derivative with respect to A0 measures the change of this direction between curves from neighboring initial conditions.

Figure S1B introduces our memory quantifier, which captures how the distance between nearby trajectories changes over time. Specifically, ddA0dAdt reflects the rate of convergence or divergence of trajectories with slightly different initial conditions. A positive value indicates that nearby initial states evolve into distinguishable responses, meaning the system can retain information about past inputs.

We applied the quantifier at time t and around five initial conditions A0 near zero and one (i), near ½ (ii), and in between (iii). In condition (i), each A0 is close to attracting fixed points, so the curves in this region converge over time, making our quantifier negative. As time progresses, we lose information from the initial conditions, as the converging curves require higher resolution to distinguish them. This corresponds to the negative sign.

In condition (ii), A0 is near an unstable fixed point, so the curves separate exponentially over time, making the quantifier positive. As time progresses, we gain information from the initial conditions, as the diverging curves require less resolution to distinguish them. This corresponds to the positive sign.

In condition (iii), each A0 is between a stable and an unstable fixed point, so the curves run parallel, making our quantifier close to zero. As time progresses, we neither gain nor lose information from the initial conditions, which corresponds to the null value.

Panels C–F in this figure analyze how this convergence/divergence behavior changes when integrated: over time (to assess how long differences persist), over initial conditions (to evaluate which states are most informative), or both. These integrations help identify where and when memory is strongest, and whether memory is localized to specific initial conditions or distributed more broadly across state space.

Figure S1C shows a colormap representing the application of Equation 5 to the toy model from Figure S1A for each pair (A0,t). Following the trajectory of A0 from curve (i) over time, we observe that the quantifier is initially negative and then becomes zero. The minimum value corresponds to the time when the curve converges to the stable fixed point, aligning with other curves that have already converged. These cone-shaped negative bands represent this event across different initial conditions.

For A0 in curve (ii), we see that the quantifier remains positive for an extended period before rapidly turning negative and then zero. The initial positive interval corresponds to the curve staying near the unstable fixed point while neighboring curves diverge in opposite directions. If A0 is not exactly at the fixed point, it eventually diverges as well and converges with nearly all other curves, indicating a significant loss of information.

The expression in Equation 5 provides a local quantifier of how much information we are gaining or losing at a given time point and from a specific initial condition. However, it is not useful if we want to know the total amount of information lost during an entire experiment or from a specific stimulus. To address this, we can integrate the expression over time to obtain the total convergence or divergence of curves from a given initial time, such as when the stimulus starts (t0), to the final time, when the measurement is taken (t). Equation 6 quantifies the net convergence or divergence within this time interval around A0.

For A0 in curve (ii), we see that the quantifier stays positive for an extended period before rapidly turning negative. If A0 is not exactly at the fixed point, it eventually diverges as well and converges with nearly all other curves. The final net value is negative for every curve because half of the curves converge near one stable point and the other half near the other. Results can be extended to transcriptional models

All the simulated circuits in the main text of this article were modeled using Michaelis-Menten dynamics (28), which are widely used for enzymatic reactions and for modeling signaling pathways. Although existing evidence suggests that our results can be extended to transcriptional models, most of this evidence focuses on adaptive circuits (62)(61) rather than circuits with memory. To demonstrate that our results can be extended, we tested a sample set of our circuits. Specifically, we selected each circuit from Figure 5C3 and computed its behavior using widely used transcriptional models for RNA dynamics (34). We applied the same pipeline shown in Figure 3C and found that each circuit effectively surpassed both the TM and TSets thresholds, thereby recapitulating the results obtained with enzymatic models.

Equation 10 presents the equations for a general three-node circuit. Analogous to Equation 3, each node activation is computed as the sum over X, where X represents the activating nodes, which are selected from {A,B,C}. Figure S2A illustrates an example of a specific circuit along with its corresponding equations. Inhibitions are incorporated as multiplicative factors, with one factor per repressing node selected from {A,B,C}. Additionally, since nodes represent mRNAs, we included a degradation rate for each node (ϕi), which is inversely proportional to its decay time. The arguments in the exponentials are sigmoids that range from zero to 1 and represent the proportion of DNA occupied binding sites for transcription factors that control the transcription.

Each activation has two parameters, kXiandKXi, which correspond to the maximum activation rate and the activation threshold, respectively. Each repression has a single parameter, KYi, which represents the repression threshold. The repression factors always range between 0 (complete inhibition) and 1 (no inhibition).

As same as for Michaelian models, we add basal activation +kactB(1−e−EactBKactB+EactB) or basal repression ∗(1−e−KinhCKinhC+EinhC) if a node is not activated or inhibited by itself or another node.

Figure S2B shows integrated sample circuits. As expected, every circuit exhibiting memory with Michaelis-Menten models also exhibits memory with transcriptional models. As a negative control, we used the same sample circuits but disrupted their positive feedback loops by eliminating a single regulatory interaction. This allowed us to test the pipeline with the most similar circuits that lack memory, and we found that none of these circuits exhibited memory.
