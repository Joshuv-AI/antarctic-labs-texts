Privacy-aware continuous federated biometric authentication (PACFBA) using federated deep learning: a novel usable security framework
Authors: Abdulwahid Al Abdulwahid
Published: 2026

ABSTRACT
AbstractWith the rapid growth of mobile, IoT, and edge-based ecosystems, the need for secure, seamless, and privacy-preserving authentication mechanisms has become increasingly critical. Traditional authentication methods, such as passwords and single-step biometrics, verify users only at the initial login stage and fail to ensure continuous user verification throughout an active session, exposing systems to significant security risks. To address this limitation, this study proposes the Privacy-Aware Continuous Federated Biometric Authentication (PACFBA) framework, a novel Federated Learning (FL)-based approach for continuous, decentralized user authentication. PACFBA integrates a hybrid Convolutional Neural Network (CNN) and Long Short-Term Memory (LSTM) architecture to jointly capture spatial and temporal biometric patterns, improving adaptability in heterogeneous environments. To ensure secure model updates and protect user data, PACFBA incorporates Differential Privacy (DP) and Homomorphic Encryption (HE) within the FL process, preventing the transfer of sensitive biometric information to central servers. Experimental results demonstrate that PACFBA achieves an accuracy of 92.5%, precision of 90.8%, recall of 91.2%, and an F1-score of 0.91, while reducing communication overhead by 20% and improving privacy preservation by 35% compared to centralized models. These results confirm PACFBA’s potential for enhancing continuous authentication in mobile, IoT, and edge-based environments. However, further empirical validation using large-scale, heterogeneous, real-world datasets is necessary before the framework can be considered fully deployment-ready. Introduction

Continuous authentication has become an essential component of modern cybersecurity, driven by increasing cyber threats and the rapid proliferation of mobile and IoT devices1. Traditional methods such as passwords and single-step biometrics verify users only at login and fail to provide ongoing session security, creating significant vulnerabilities2,3. This has led to growing demand for dynamic, real-time authentication solutions that verify users continuously without disrupting the user experience4,5. Existing approaches struggle with three critical limitations. First, centralized biometric authentication requires sharing raw user data with a central server, posing serious privacy risks unsuitable for privacy-sensitive environments6. Second, current federated learning-based frameworks — while preserving privacy — often sacrifice accuracy and struggle with scalability across heterogeneous devices and real-world network conditions7,8. Third, recent FL-based security solutions such as FEDDBN-IDS9 focus on intrusion detection rather than continuous user authentication, leaving gaps in real-time identity verification across heterogeneous mobile and IoT environments. To address these gaps, this paper proposes PACFBA, a Privacy-Aware Continuous Federated Biometric Authentication framework combining a hybrid Convolutional Neural Network (CNN) and Long Short-Term Memory (LSTM) architecture within a Federated Learning (FL) paradigm, secured by Differential Privacy (DP) and Homomorphic Encryption (HE). PACFBA enables secure, adaptive, real-time user verification without transferring sensitive biometric data to any central server.

The principal novelty of PACFBA relative to existing federated continuous authentication frameworks is threefold. First, the hybrid CNN-LSTM architecture captures spatial biometric features (touch pressure σ = 0.3 N, keystroke heatmaps) and temporal behavioural sequences (inter-key timing µ = 180ms, σ = 35ms) jointly — a combination not previously applied to federated continuous authentication — achieving 4.8% and 6.7% accuracy improvements over CNN-only8 and LSTM-only10 baselines respectively. Second, a three-layer privacy architecture — (ε = 0.5, δ = 10⁻⁵)-differential privacy, 2048-bit Paillier homomorphic encryption, and secure aggregation — provides formal privacy guarantees beyond those in6(no DP) and11(weak ε = 5.0), achieving DPS = 0.95 and reducing MIA success from 78.5% to 52.3%. Third, heterogeneous device scalability is validated across 10,000 users spanning ARM Cortex-M4 IoT sensors to Intel Xeon E5 edge servers, extending prior evaluations limited to 10–50 homogeneous devices12,13.

The main contributions of this work are as follows:

Hybrid Architecture Design:

This study introduces PACFBA, a novel privacy-aware continuous authentication framework that integrates federated learning with a hybrid Convolutional Neural Network (CNN) and Long Short-Term Memory (LSTM) architecture, designed to perform secure and adaptive real-time user verification across heterogeneous mobile, IoT, and edge environments without transferring sensitive biometric data to a central server. Unlike existing CNN-only or LSTM-only approaches that capture either spatial or temporal features in isolation, PACFBA’s hybrid design synergistically combines both dimensions, enabling comprehensive behavioral biometric modeling. This architectural innovation addresses the limitation of single-modality approaches identified in prior work8,14,15, achieving 4.8% and 6.7% accuracy improvements over CNN-only and LSTM-only baselines respectively. CNN-only architectures capture static spatial patterns but lack sequential memory for session-level behavioural drift; LSTM-only architectures model temporal sequences but cannot extract position-sensitive spatial feature maps from raw sensor arrays. The hybrid design eliminates both limitations simultaneously, yielding 4.8% accuracy gain over CNN-only and 6.7% over LSTM-only under identical training conditions.

Layered Privacy-Preserving Mechanisms:

The framework implements a three-layer privacy architecture combining (ε, δ)-differential privacy (ε = 0.5, δ = 10^−5), Paillier homomorphic encryption (2048-bit keys), and secure aggregation with secret sharing. This multi-layered approach addresses the inadequate privacy guarantees in existing federated authentication systems6,11,16, which typically implement only single-layer protection. Experimental evaluation demonstrates 35% improvement in privacy scores (DPS = 0.95 vs. 0.70 for centralized approaches) and significant resistance to membership inference attacks (52.3% success rate vs. 78.5% without protection).

Heterogeneous Device Scalability:

PACFBA is validated across heterogeneous devices spanning high-end mobile (Snapdragon 888), mid-range tablets (MediaTek Dimensity), low-power IoT sensors (ARM Cortex-M4), and edge servers (Intel Xeon E5), demonstrating simulation-validated feasibility across heterogeneous device classes pending real-world pilot confirmation. Existing federated authentication frameworks12,13,17,18 lack evaluation beyond 50 devices or homogeneous environments. The comprehensive evaluation across 10,000 simulated users and 1,000 physical devices confirms scalability with acceptable encryption overhead (35-597ms per round) even on resource-constrained IoT devices.

Training Stability Analysis:

Through user distribution heterogeneity analysis, this study identifies and quantify the root cause of centralized model instability—high variance in training batches (σ = 25 WPM typing speed, 42/28/20/10 geographic imbalance)—and demonstrate how PACFBA’s local clustering reduces variance by 50–53%, eliminating catastrophic forgetting and overfitting oscillations observed in centralized approaches. This theoretical contribution, validated through empirical training loss curves, explains the 21% performance improvement (final loss 0.095 vs. 0.12) and provides design principles for stable federated authentication systems.

Comprehensive Security Evaluation: The framework provides the first comprehensive security assessment of federated biometric authentication covering four attack categories (replay, impersonation, model poisoning, gradient inversion) with detection rates ranging from 78.9% to 91.2%, representing 3–4× improvement over baseline defenses (23.1–31.5% detection). Unlike prior work focusing on single attack types, the holistic evaluation demonstrates PACFBA’s resilience across the threat landscape, validated through 12-month simulation with 1,000 attacks per category. These contributions collectively target three measurable goals: authentication accuracy ≥ 90% across heterogeneous devices, formal privacy guarantees with ε ≤ 1.0, and ≥ 15% communication overhead reduction versus centralized approaches, all validated at p < 0.05 statistical significance.

Literature review

Continuous authentication using biometric and behavioral data has gained significant attention due to its ability to provide seamless and secure identity verification across diverse environments. Several studies have explored different approaches, datasets, and methodologies to enhance system accuracy, scalability, and privacy while addressing usability challenges.

Recent continuous authentication research has explored smartphone sensors1, cloud-based frameworks2, and mobile behavioral analytics7,8,19, achieving accuracies of 85–89%. However, these centralized approaches require raw data transmission, posing privacy risks. Federated learning-based authentication has emerged to address privacy concerns6,11,12,20. Existing frameworks face three critical limitations: (1) scalability challenges with heterogeneous devices12,13, lacking evaluation beyond 50 devices; (2) inadequate privacy guarantees, with most omitting differential privacy6 or using weak encryption11; and (3) limited temporal modeling, relying on CNN-only8 or LSTM-only14 architectures rather than hybrid approaches. Methodology and model framework

Continuous authentication problem formulation

The continuous authentication problem can be formulated as a classification problem, where the goal is to continuously verify whether a user is authentic based on their behavioral data collected over time. This behavioral data can include information such as keystroke dynamics, mouse movement, or device usage patterns. The objective is to build a predictive model that outputs a probability p, indicating whether the user is legitimate (y = 1) or an imposter (y = 0) at any given time.

The PACFBA model employs a hybrid CNN-LSTM architecture within a federated learning pipeline — CNN extracts spatial biometric features (touch pressure, keystroke heatmaps) while LSTM models temporal behavioural sequences (typing rhythm, gait dynamics) — using specific hyperparameters: 2 convolutional layers (3 × 3 kernels, ReLU, max-pool 2 × 2), 2 LSTM layers (64 and 32 hidden units, dropout = 0.3), 1 dense layer (64 units, ReLU), sigmoid output, Adam optimiser (lr = 0.001), trained in TensorFlow 2.11. Proposed model: PACFBA model

PACFBA model is a novel federated deep learning model designed to enhance the scalability, privacy, and performance of continuous authentication frameworks. This model integrates adaptive learning rates, privacy-preserving mechanisms, and a hybrid neural network architecture to handle the complexity of biometric and behavioral data. The model aims to authenticate different users across various devices while maintaining privacy. The authentication framework verifies the identity of each user in real-time, ensuring that only legitimate users can access the services or resources on their devices. This model is particularly useful in environments where multiple users are operating across distributed networks or devices, such as corporate settings, IoT environments, or cloud-based platforms. Privacy-preserving mechanisms

PACFBA enforces privacy through three layered mechanisms — (ε = 0.5, δ = 10⁻⁵)-DP noise added to gradients, Paillier homomorphic encryption of local updates (234 ± 25ms encryption, 276 ± 30ms decryption on ARM Cortex-M4, reducing to 120 ± 14ms on Snapdragon 888), and secure aggregation preventing server-side reconstruction — with post-optimisation IoT overhead reduced from 597ms to 382ms (36% improvement) via adaptive 1024/2048-bit key sizing, 40% gradient compression, and asynchronous encryption overlapped with local training. Edge efficiency is further achieved through micro-batching (batch = 4 on IoT vs. 32 on mobile), 40% CNN pruning with < 0.3% accuracy loss, 16-bit quantisation halving model size (12 MB→6 MB), top-K gradient sparsification reducing payload by 60% (10 MB→4 MB), and adaptive participation skipping rounds for low-battery (< 20%) or high-latency (> 500ms) devices, collectively reducing per-round time by 25% and energy consumption by 35% on constrained devices. Security considerations

PACFBA assumes an honest-but-curious server and up to 20% compromised clients with white-box model knowledge, defending against four attack vectors through layered mechanisms — (ε = 0.5)-DP with gradient clipping (norm = 1.0), 2048-bit Paillier encryption, anomaly filtering (3σ threshold), temporal hashing, and secure aggregation — achieving spoofing detection 78.9% (vs. 31.5% baseline), model poisoning detection 82.1% with < 1.2% accuracy degradation under 20% malicious devices, gradient inversion PSNR reduced from 22.7dB to 8.2dB (data correlation 0.76→0.31), and replay attack detection 85.3% (full attack-by-attack breakdown in Table SI-3, Supplementary Information), with no single attack vector succeeding above 21% — satisfying NIST SP 800-63B’s < 30% attack success threshold under simulation-validated conditions, pending formal compliance certification. Gradient inversion is neutralised through (ε = 0.5)-DP (σ = 4.0), Paillier encryption, and secure aggregation, reducing reconstruction PSNR from 22.7dB to 8.2dB and data correlation from 0.76 to 0.31 (unrecognizable patterns at PSNR<10dB); replay attacks are mitigated via temporal hashing (timestamp+nonce), behavioral drift detection, and challenge-response prompts, achieving 85.3% detection rate with only 5.2% false positives (Table SI-3, Supplementary Information), collectively ensuring no single attack vector exceeds 21% success satisfying NIST SP 800-63B’s < 30% threshold.

To ensure transparency, this study explicitly distinguishes between real-world public data and simulated FL-Sim simulated dataset. The public datasets (Behavioral Biometric Dataset and CICIoT2023) provide 3,200 real user sessions collected from actual devices. The simulated synthetically generated enterprise-scenario data, generated using FL-Sim and TensorFlow Federated, synthetically models 6,800 user profiles across heterogeneous devices to evaluate scalability. While simulation enables controlled experimentation across diverse conditions, it is acknowledged that it may not fully capture real-world behavioral drift, environmental noise, or unpredictable user patterns observed in production deployments.

The data was collected using a federated simulation tool that mimics real user interaction across mobile and IoT devices. Each of the 10,000 users generated interaction data via simulated typing behavior, mouse movements, and touch gestures. Ground truth labels were assigned as follows: every device session initiated by the true account holder was labeled as legitimate (label = 1), while injected sessions mimicking unauthorized access were marked as imposter (label = 0). Imposter events were synthetically introduced using altered behavioral profiles (e.g., changes in typing rhythm or touch angle). Data was partitioned such that each device had local training and test sets maintaining a 70:30 split. All datasets were time-stamped and anonymized in accordance with GDPR and HIPAA compliance standards. Validation data was manually inspected in random samples to ensure the integrity of legitimate vs. imposter labeling.

Ethical Compliance and Data Collection Protocol:

This research utilized two categories of data: Public Datasets: The Behavioral Biometric Dataset and CICIoT2023 were obtained from Kaggle under open-access licenses. These datasets were published with prior ethical clearance from their original data providers, and no additional IRB approval was required for their use in secondary research. Simulated Federated Environment Data: The FL-Sim simulated dataset referenced in this study was generated through controlled simulation using the FL-Sim federated learning (FL) simulator and TensorFlow Federated platform. This simulated dataset mimics realistic user interaction patterns based on statistical distributions derived from published behavioral biometrics literature but does not contain actual human participant data. No human subjects were recruited, no personally identifiable information was collected, and no experiments were conducted on human participants during this research. Since this study relied entirely on publicly available datasets and synthetically generated simulation data, direct human participant involvement was not applicable. Therefore, IRB approval was not required, as confirmed by institutional research ethics guidelines.

Discussions

From a deployment perspective, PACFBA is well-suited for mobile devices, IoT ecosystems, and cloud-based infrastructures. A detailed dimension-by-dimension comparison of PACFBA against the state-of-the-art is provided in Table SI-4 (Supplementary Information). In mobile applications, PACFBA supports continuous, privacy-preserving authentication without relying on passwords. For IoT environments with limited processing power, the framework enables secure on-device model training, reducing risks of sensitive data exposure. In cloud platforms and enterprise networks, PACFBA facilitates cross-device authentication while ensuring data confidentiality and access control.

While PACFBA demonstrates strong performance under controlled simulation conditions, several limitations require acknowledgement. The dataset comprises 32% real-world public data (Behavioral Biometric Dataset, CICIoT2023) and 68% synthetically generated FL-Sim data; this composition may not fully capture real-world behavioral drift, contextual variability (multitasking, fatigue, environmental noise), or the diversity of non-Western input methods and accessibility configurations — and therefore all accuracy claims should be interpreted as simulation-validated rather than production-validated. Additionally, the current 50-round evaluation under controlled network conditions does not reflect the challenges of intermittent mobile connectivity (dead zones, mid-session handoffs, VPN interference) inherent in real federated edge deployments. The Paillier encryption overhead (597 ms on ARM Cortex-M4) also presents challenges for sub-100 ms latency requirements, and formal NIST/GDPR/HIPAA compliance certification requires third-party security audits not conducted here. Future work will target: (i) a 12-month real-world pilot across healthcare, finance, and smart home sectors with > 10,000 genuine users; (ii) multimodal biometric fusion (keystroke dynamics, voice, facial biometrics) to improve resilience against spoofing across large-scale heterogeneous IoT deployments; and (iii) lightweight post-quantum cryptographic alternatives to reduce encryption overhead on constrained devices.

Until real-world pilot data is available, all performance claims should be interpreted as “simulation-validated under controlled conditions” rather than “production-ready.

Conclusion

This research presented the Privacy-Aware Continuous Federated Biometric Authentication (PACFBA) framework, a federated deep learning-based solution for secure, adaptive, and continuous user verification in decentralized environments. By leveraging a hybrid Convolutional Neural Network (CNN) and Long Short-Term Memory (LSTM) architecture, PACFBA effectively learns both spatial and temporal biometric patterns, enabling improved detection of legitimate users in heterogeneous mobile, IoT, and edge ecosystems. Unlike conventional centralized authentication models, PACFBA eliminates the need to share sensitive raw biometric data with a central server, thus mitigating privacy risks while ensuring scalability across distributed infrastructures.

PACFBA integrates federated learning with differential privacy and homomorphic encryption, providing a secure, privacy-preserving approach for model training and gradient aggregation. Experimental results demonstrate that PACFBA achieves an accuracy of 92.5%, precision of 90.8%, recall of 91.2%, and an F1-score of 0.91, outperforming centralized approaches by a relative margin of 5% in accuracy while reducing communication overhead by 20% and improving privacy preservation by 35%.

These results illustrate PACFBA’s potential to enhance continuous authentication across diverse environments, including mobile applications, enterprise networks, and IoT-enabled ecosystems. A structured summary of all contributions and their quantified impacts is provided in Table SI-5 (Supplementary Information). The proposed framework demonstrates strong relevance for privacy-critical deployment scenarios, particularly in mobile banking, healthcare IoT systems, corporate VPNs, and smart home platforms. Future large-scale real-world pilot studies and the integration of lightweight cryptographic alternatives will further validate and optimize PACFBA for distributed authentication ecosystems.
