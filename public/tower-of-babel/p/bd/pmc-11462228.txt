Protocol to detect spatio-molecular profiles underlying neuroimaging features in the human cerebellum
Authors: Yaping Wang, Kaikai Wang, Kristoffer Hougaard Madsen, Congying Chu, Lingzhong Fan
Published: 2024

ABSTRACT
SummaryImaging transcriptomics offers opportunities to uncover the genetic profiles underlying brain imaging-derived phenotypes (IDPs) but lacks explanation from gene to IDPs. Here, we present a protocol for combining imaging transcriptomics with gene set variation analysis (GSVA) to detect spatio-molecular profiles underlying IDPs in the human cerebellum. We describe the steps for data preparation, model training, model evaluation, key gene identification, and GSVA. Our protocol broadens the way to interpret the biological pathways shaping a wide range of neuroimaging-derived cerebellar properties.For complete details on the use and execution of this protocol, please refer to Wang et al.1

Before you begin

This protocol allows the user to identify patterns of gene expression that correlate with specific cerebellar IDPs and perform GSVA2 to inform the intermediate biological interpretation from gene to IDPs.

In the following sections, we provide a comprehensive, step-by-step guide on performing prediction of any cerebellar IDP input by the user based on transcriptomics and related GSVA2 analysis from start to finish. Such analyses necessitate extensive data on gene expression across the cerebellum of the post-mortem human brain, which is available through the Allen Human Brain Atlas (AHBA).3 Ultimately, this protocol provides a list of genes significantly engaged in predicting the IDP and identifies the spatio-molecular profiles underlying the IDP using state-of-the-art methods that account for the bias induced by the spatial autocorrelation of the data.

To fully use the cerebellar transcriptomic data, we choose to do the analysis at the sample-wise level, so the IDP should be mapped into the same space as the AHBA sample data. The cerebellar sample-wise gene expression data was achieved by using the get_samples_in_mask function of the abagen4 toolbox. For the neuroimaging data, we assigned an IDP value to each cerebellar sample by averaging the IDP values of voxels less than 4 mm away from the sample coordinates.

Based on the pre-processed cerebellar sample-wise gene expression matrix, we leveraged the partial least squares regression (PLSR) model to predict the cerebellar sample-wise IDP. The optimal component number and the PLSR’s generalizability were separately and successively validated by 10-fold cross-validation. The significance of the prediction performance was tested by Brain Surrogate Maps with Autocorrelated Spatial Heterogeneity (BrainSMASH),5 which preserves the spatial auto-correlation of the IDP.

The regression coefficient of each gene in the PLSR model represented the degree of contribution of each gene to the prediction of the IDP. Thus, the regression coefficient could act as the gene contribution indicator (GCI). The significance of the GCI and the genes with significant GCI, i.e., GCIsig, were identified by the same nulls from BrainSMASH.

Since the GCIsig contributes significantly to the cerebellar IDP, how does it work? A bin-based GSVA2 strategy was utilized to uncover the underlying spatio-molecular profile that the GCIsig might leveraged in shaping the IDP. GSVA detects subtle biological activity changes by transforming gene expression data into a gene set × sample matrix,2 enabling a functional gene-unit-centric analysis that explores the underlying biological principles behind brain features. Incorporating GSVA with imaging-transcriptomics presents a promising opportunity to identify microscale mechanisms underlying any human brain IDP.Note: See Wang et al.1 as a detailed example.

Quantification and statistical analysis

The generalizability of the PLSR model is evaluated using an embedded 10-fold CV, with the correlation between actual and predicted IDP as the prediction performance. The significance of the prediction performance is determined by the BrainSMASH,5 which controls the spatial auto-correlation (psa). The significance of GCI is determined by psa < 0.05 after Bonferroni correction for multiple comparisons.

Limitations

We validated this procedure in the human cerebellum. However, we recognize that specific research questions may require other brain regions. In this case, the user can modify the original code to use different regions, and the gene expression matrix must be recalculated (e.g., using abagen-exported sample information to retrieve gene expression in the region of the user’s choice). In addition, AHBA includes gene expression data from six donor left hemispheres and two donor right hemispheres. While this is a general limitation of the field and not a limitation of this specific work, this aspect may cause problems when a particular IDP has strong laterality in the right hemisphere.

Troubleshooting

Problem 1

The R package is not in the current channel (related to step 1). An error occurred when installing the R language using the conda command “conda create -n Gene2Cere -f Gene2Cere-env.yaml”.

Potential solution

First, use the conda ‘conda create -n Gene2Cere -f Gene2Cere-env.yaml’ command to create a conda environment, and then use the ‘pip’ command or “BiocManager::install(“xxx”)” command to install additional R package as referred by “requirements_r.yaml”.

Problem 2

The python module named abagen cannot be found (related to step 2). When executing Step01_Input() function to obtain the matrix with IDP, the getLogger(‘abagen') method of the underlying Allen class will be called to find the abagen object.

Potential solution

Change the name of the abagen_cere folder under the Toolbox folder to abagen. Modify ‘from abagen_cere import allen’ to ‘from abagen import allen’ in Gene2Cere.py.

The palette dictionary is missing keys: {'10′, ‘5′, ‘7′, ‘9′, ‘8′, ‘4′, ‘6'} (related to step 3).
