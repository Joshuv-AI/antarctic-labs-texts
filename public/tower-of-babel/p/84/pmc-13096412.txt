ABSTRACT
Wireless Sensor Networks (WSN) are widely used across various fields. WSN is composed of many low-cost, high-performance, plug-and-play sensor nodes. WSN is used across a wide range of applications. Distributed Denial-of-Service (DDoS) attacks that overwhelm targeted resources, denying access to legitimate users. It prevents web servers from serving resources to clients. One type of DDoS is an HTTP flood attack, in which an attacker targets network resources, such as bandwidth (the amount of data a network can carry) and CPU processing (a central processing unit’s ability to compute). The attacker sends multiple HTTP POST requests to the server to transmit data. In addition, the attacker sends multiple HTTP GET requests to retrieve data from the server. Previous work identified HTTP TRACE flood attacks that misuse the HTTP TRACE method. The HTTP TRACE method returns the received HTTP request, thereby exposing sensitive data. These attacks employ static URLs, which degrade the overall performance of the WSN. To address these issues, introduce the proposed method, the Enhanced Deep Spectral Multi-Layer Convolutional Neural Network (EDSMCNN), a deep learning model designed to improve CPU performance, handle multiple URL requests, and predict TRACE attack traffic based on the maximum-weighted features. First, input the HTTP flood attack dataset, which is available online. The initial step is preprocessing: analyzing and preparing data. The datasets are preprocessed to reduce the dimensionality (number of input features) of non-redundant data. Average weightage scaling feature to filter using the spider algorithm (an optimization technique based on social spider behavior) selects relevant features based on Lattice Service Rate Access Values (LSRAV, a metric evaluating service rate in the system) and observes Trace flood Traffic, considering parameters such as URL, protocol, and IP address (unique network identifier). Social spiders compare feature selection patterns with rank results. Next, SoftMax (a mathematical function that converts numbers to probabilities) generates logistic neurons using the Logistic Activation Function (SLAF, an activation mechanism for neural networks) for HTTP POST and GET requests to prevent trace attacks. Compared to standard convolutional methods, the system achieves high efficiency in detecting HTTP-TRACE flooding attacks. Experimental results show the proposed system improves CPU performance and reduces computation time, helping avoid traffic in one or more HTTP requests. In WSN, security is of paramount importance, and the emergence of novel attack vectors poses significant challenges. This abstract highlight a concerning scenario in which sensor nodes are targeted by a TRACE attacker via the injection of a backdoor entry file. Once compromised, the attacker gains unauthorized access to the WSN web server, potentially exposing sensitive data or gaining control over the network. This sophisticated attack underscores the need for robust security measures in WSNs, including intrusion detection systems, encryption, and authentication protocols, to safeguard against such threats and ensure the integrity and confidentiality of data transmitted and collected within these networks. Developing effective countermeasures to address these emerging attack vectors is crucial for the continued deployment and reliability of WSN in various critical applications

Research motivation

WSN increasingly interacts with web-based services, exposing them to application-layer attacks. Among these, HTTP TRACE flooding attacks are particularly problematic because they mimic legitimate traffic while exploiting the TRACE method’s echo functionality to exhaust limited network resources and expose sensitive information. Existing detection approaches largely focus on generic HTTP flooding or network-layer attacks and are typically designed for resource-rich environments, making them unsuitable for WSN. Moreover, many methods rely on redundant features and computationally intensive models, which increase energy consumption and processing delays. These limitations create a clear need for a TRACE-aware, resource-efficient detection framework that can accurately identify malicious behavior without compromising WSN performance. This study is motivated by the need to address this gap through an efficient deep learning–based solution tailored to WSN constraints.

Methodological innovations

This study proposes a TRACE-aware intrusion detection framework tailored for Wireless Sensor Networks. A lattice service rate–based feature evaluation mechanism is introduced to capture HTTP TRACE traffic characteristics that are typically overlooked by conventional detectors. To reduce redundancy and computational cost, a Spider Optimization Average Weighted Feature Selection (SOAWFS) strategy is employed. The framework further integrates an Enhanced Deep Spectral Multi-Layer Convolutional Neural Network (EDSMCNN) that combines spectral learning with multi-layer convolutional neural networks to model complex traffic patterns. Unlike existing approaches, the proposed method emphasizes computational efficiency and energy awareness while maintaining high detection accuracy.

Research gap statement

Existing detection methods largely overlook TRACE specific echo behavior, static URL exploitation, and their disproportionate impact on CPU and energy consumption in WSNs. Moreover, current approaches lack optimized feature selection and service-rate-aware learning mechanisms tailored to WSN environments. This study addresses these gaps by proposing an Enhanced Deep Spectral Multi-Layer Convolutional Neural Network (EDSMCNN) that integrates lattice service rate evaluation, spider optimization–based feature selection, and TRACE-aware deep learning for efficient and accurate attack detection.

The experimental evaluation assessed the effectiveness and efficiency of the proposed EDSMCNN framework for detecting HTTP TRACE flooding attacks in Wireless Sensor Networks. Dataset applicability and limitations

The CIC-DDoS2019 dataset was used for baseline comparisons because it provides a diverse range of modern DDoS attacks, including application-layer WebDDoS traffic. However, the publicly released labels and CSV feature sets do not explicitly identify HTTP method types (e.g., GET, POST, TRACE). Therefore, CIC-DDoS2019 does not guarantee the presence of TRACE-method attack samples. For experiments that specifically target HTTP TRACE flood behavior, we either (a) derive method-level samples from the original PCAPs by searching for TRACE requests, or (b) simulate TRACE floods. This limitation is acknowledged and discussed when interpreting results.

Limitations

We have systematically clarified that existing approaches for detecting application-layer DDoS and HTTP-based attacks suffer from several inherent constraints when applied to WSN. Signature-based detection mechanisms rely on predefined attack patterns and are therefore ineffective against evolving or previously unseen HTTP TRACE attack behaviors. Threshold-based and statistical techniques primarily depend on traffic volume or request frequency, making them unsuitable for detecting low-rate TRACE attacks that exploit protocol-level reflection rather than high traffic intensity. Traditional machine learning models often assume balanced, stationary traffic distributions, leading to degraded performance under highly dynamic, imbalanced WSN traffic conditions. Moreover, many deep learning-based solutions do not explicitly model protocol-specific features, such as request echoing and header leakage, that are intrinsic to HTTP TRACE attacks. Finally, the computational and energy overhead associated with existing detection frameworks restricts their deployment in resource-constrained WSN environments.
