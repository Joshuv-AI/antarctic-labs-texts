Federated learning for network attack detection using attention-based graph neural networks
Authors: Wu Jianping, Qiu Guangqiu, Wu Chunming, Jiang Weiwei, Jin Jiahe
Published: 2024

ABSTRACT
Federated Learning is an effective solution to address the issues of data isolation and privacy leakage in machine learning. However, ensuring the security of network devices and architectures deploying federated learning remains a challenge due to network attacks. This paper proposes an attention-based Graph Neural Network for detecting cross-level and cross-department network attacks. This method enables collaborative model training while protecting data privacy on distributed devices. By organizing network traffic information in chronological order and constructing a graph structure based on log density, enhances the accuracy of network attack detection. The introduction of an attention mechanism and the construction of a Federated Graph Attention Network (FedGAT) model are used to evaluate the interactivity between nodes in the graph, thereby improving the precision of internal network interactions. Experimental results demonstrate that our method achieves comparable accuracy and robustness to traditional detection methods while prioritizing privacy protection and data security.

Introduction

With the rapid development of information technology and the increasing complexity of network threats, network security remains a key issue in the field of information technology, and traditional security measures have proven to be insufficient. Especially in the emerging field of federated learning (FL)citeww1,ww45, effective detection and mitigation of cyberattacks has become an urgent challenge. Intrusion Detection Systems (IDS)3 are viable tools for detecting network intrusions. It can distinguish the characteristics of intrusion behavior and intrusion actions from the host data. However, in actual scenarios, the network system of an organization or enterprise only generates less high-quality attack sample data for training. Based on these data, deep intrusion detection models have limited detection capabilities4. An effective way to solve this problem is to collect data samples from different enterprises to a central server and train deep learning models on this basis. Regardless, the fact is that organizations are often reluctant to share their network traffic data with others because their data often contain sensitive information and involve internal privacy5. At the same time, most existing IDS are based on deep learning technologies such as convolutional neural networks (CNN)6,7 or recurrent neural networks (RNN)8–10, which model network traffic into Euclidean data structures such as images or sequences. , ignoring the fact that its essence is a graph data structure leads to the problem of low detection rate and high false alarm rate. In particular, the widespread application of large language models has led to lower attack thresholds, expanded attack surfaces, and enhanced destructiveness. Therefore, it is very important to build a cross-level, cross-department, cross-domain, and cross-system collaborative defense mechanism to prevent new attack technologies based on large language models. Graph neural network (GNN)11 is good at capturing the complex relationships between nodes in the network structure and has been widely used in related fields.

This paper aims to construct a graph data structure based on log density information of timestamps, and utilize GNN (GAT) with attention mechanism12 to improve the accuracy and robustness of network attack detection in a federated learning environment. By using GNN to analyze complex relationships within network graphs, potential malicious activities can be effectively identified and network security defenses strengthened.

Related work

This section presents some related research on network intrusion detection and federated learning.

Network intrusion detection

Intrusion Detection System (IDS)3 is a proactive security protection technology that can effectively perceive network attacks by monitoring the network in real time and providing response decisions for security managers. Currently, intrusion detection is widely used in military13,14, medical15,16, transportation17–19, Internet of Things20–22 and other fields. Although intrusion detection technology plays a certain role in some security scenarios, with the continuous upgrading of hacker attack methods and the massive network data faced, traditional machine learning methods are no longer suitable for new network intrusion detection scenarios. In recent years, with the emergence of big data technology, deep learning, reinforcement learning, visualization and other technologies have been widely used and have achieved great success in fields such as natural language processing, image recognition, and video detection. There is a surge of interest in developing machine learning-based IDS using centralized environments, where endpoints provide information for model creation. However, as mentioned before, this approach raises privacy concerns, so decentralized settings need to be explored. The subsequent sections will delve into federated learning (FL), a promising approach aimed at mitigating these privacy issues in the context of next-generation IDS.

Graph neural networks

Traditional neural networks can only handle regular Euclidean structured data. As shown in Fig. 1a, fixed arrangement rules and order of nodes characterize the Euclidean data structure. However, more and more practical application problems need to consider non-Euclidean data. As shown in Fig. 1b, there is no fixed arrangement rule and order of nodes in the non-Euclidean data structure, which means that traditional deep learning models cannot be directly applicable to the task of processing non-Euclidean structured data23. For graph data with irregular spatial structure, researchers7–10 tried to generalize neural networks to handle graphs with arbitrary structures, thus introducing graph neural networks11. Graph neural networks extend existing neural network models and are suitable for processing data that can be represented as graphs. Graph neural networks regard actual problems as connection and message propagation problems between nodes in the graph, and model the dependencies between nodes so that they can handle graph structure data well. Graphs are typical non-Euclidean data with points and edges. In practice, various non-Euclidean data problems can be abstracted into graph structures.Figure 1Euclidean data structure (a) and non-euclidean data structure (b)23.

Euclidean data structure (a) and non-euclidean data structure (b)23.

At the same time, researchers24–26 found that graph neural networks are easily affected by some small perturbations, which are called adversarial perturbations. Adversarial attacks occur during the testing phase of the model. The attacker carefully designs tiny perturbations based on the model structure and adds them to the original data, thereby causing the graph neural network model to misjudge and achieve the purpose of fooling the graph neural network model. Therefore, the private data information of GNN training data is at risk of being leaked. These weaknesses hinder the application of GNN in the real world, especially in high-risk scenarios such as finance and medical care. Therefore, we aim to build trustworthy GNN models to address privacy challenges.

Federated learning

Federated Learning (FL) is a distributed machine learning framework that was proposed by Google’s McMahan et al.1 in 2017 and implemented in the language prediction model on smartphones, achieving the goal of not leaking user personal data. Under the premise, a unified machine learning model is trained using data sets distributed on different mobile phones. The aggregation process of federated learning is shown in Fig. 2. After each FL client is trained locally, the computed updates are transmitted to a central entity called an aggregator. This aggregator is responsible for generating a refined global model by processing the received updates using aggregate functions.Figure 2Federated learning framework27.

Federated learning framework27.

As highlighted previously, although machine learning and deep learning combined with intrusion detection systems have gained significant momentum in the field of intrusion detection, privacy and security aspects may be compromised due to the need for storing and transmitting data to a centralized server. On the contrary, federated learning (FL) is highly suitable as a privacy-preserving distributed learning technique because it does not transmit data but trains models locally and transmits the parameters to the centralized server28. Therefore, federated learning (FL) plays a key role in the development of next-generation intrusion detection systems (IDS). This approach eliminates the need to share data directly and helps detect cyberattacks without compromising sensitive data privacy1,29. The applicability of FL in IDS is not limited to limited-scale, targeted attack detection scenarios. It can establish a cross-industry and cross-field cooperation environment to realize the sharing of network security information without compromising confidentiality. In today’s increasingly connected society30, information sharing about information and communications technology (ICT) product vulnerabilities or critical infrastructure attacks is crucial to facilitate cooperation in cyber attack detection31,32. However, stakeholders still have reservations as the shared information may contain sensitive data. FL offers compelling solutions to these challenges. Furthermore, the integration of FL in IDS development is expected to reduce latency in cyberattack detection, as data processing no longer needs to be transmitted to centralized cloud data centers. It is worth noting that the aggregation process can be performed at edge network nodes to accelerate decision-making capabilities.

Intrusion detection based on federated learning

The federated learning-based network intrusion detection model can acquire the features of intrusion data from multiple parties, thereby preventing the model trained by individual participants from converging to local optima and enhancing the overall detection capability. Moreover, this approach ensures data privacy, leverages scarce intrusion data resources, and boosts the model’s generalization ability for intrusion detection.

Currently, there is ongoing research on the application of federated learning in intrusion detection. For instance, Zhao et al.33 introduced the MT-DNN-FL, a multitask federated learning model used for VPN traffic recognition, abnormal traffic detection, and traffic classification. Li et al.34 developed a federated deep learning model tailored for industrial cyber-physical systems to identify attacks, along with secure communication protocols for safeguarding model parameter transfer. In the same period, Sun et al.35 proposed an adaptive intrusion detection system employing piecewise federated learning. This system trains multiple similar networks within a unified global model and facilitates the sharing of multiple global models among participants. Additionally, Zhao et al.36 put forward an intelligent intrusion detection model utilizing federated learning, specifically based on long short-term memory (LSTM). Compared to traditional models, this LSTM-based approach exhibited higher precision and better consistency. Furthermore, Man et al.37 introduced FedACNN for network intrusion detection, which incorporates weighted aggregation of local models by measuring the Euclidean distance between global and local models from the previous round. This method reduces the number of communication rounds by 50% compared to FedAvg.

The application of federated learning in the field of network intrusion detection shows obvious advantages. Obtaining the characteristics of intrusion data from multiple parties, it avoids the model trained by a single party from falling into a local optimal solution and improves the overall detection capability. This method ensures data privacy, utilizes intrusion data resources, and enhances the generalization ability of the intrusion detection model.

However, despite significant advancements in privacy protection and model efficiency achieved by current federated learning methods, there are still some limitations in complex network environments across different levels, departments, and domains. These limitations are mainly manifested in the high cost of intrusion detection analysis on massive data and the high heterogeneity of collected network traffic data instances.Figure 3Illustrations of sub-scenarios in the centralized FedGNNs (the dotted lines represent relationships among clients)38.

Illustrations of sub-scenarios in the centralized FedGNNs (the dotted lines represent relationships among clients)38.

Graph neural networks are a powerful graph representation technique based on deep learning. They have significant advantages in leveraging graph structures and have been used for detection tasks in multiple domains. Graph attention networks can learn important relationships between nodes in data relationship graphs, which helps in better understanding and utilizing the complex structures of network data. Currently, there is research on the fusion application of federated learning and graph neural networks in academia. Liu et al.38 provided an overview of FedGNNs, analyzing the representation of graph data in federated learning (FL), as well as GNN training methods and GNN aggregation techniques under different FL system architectures. As shown in Fig. 3. Wu et al.39proposed the FedPerGNN framework for effective and privacy-preserving personalized applications. Tian et al.40 proposed a Privacy-Preserving Cross-Domain Recommendation (PPCDR) based on federated graph learning, which can capture user preferences based on distributed multi-domain data and improve recommendation performance in all domains without revealing privacy. Kong et al.41 proposed a model heterogeneous Federated Graph Learning (FGL) framework based on prototype learning and local data augmentation. It generates better local prototypes through a node generation method based on global prototypes and local structures, thereby mitigating the issue of local data imbalance. It addresses the issue of domain deviation by creating specific global prototypes and utilizing contrastive learning methods to offer more personalized and precise guidance for each client’s training. Al-Huthaifi et al.42 proposed the Federated Graph Ordinary Differential Equations model (FedGODE), which facilitates real-time updates of the global model, ensures adaptability to dynamic traffic conditions, and reduces network inefficiency by only transmitting model updates. It plays a crucial role in optimizing intelligent transportation systems and alleviating traffic congestion in smart cities. Wang et al.43 proposes a federated graph method based on knowledge distillation, named FedKG, for social bot detection. The specific approach involves adjusting the models on both the client and server sides. They train a global generator to generate pseudo-samples based on the knowledge of local data distribution, to correct the optimization direction of the client-side classification models. Additionally, they integrate the knowledge of client-side classification models on the server side to guide the training of the global classification model.

Therefore, future research could investigate the integration of graph attention networks into federated learning models to enhance the accuracy and efficiency of intrusion detection, thus fostering advancement and innovation in this domain.

Proposed method

Graph neural networks for network attack detection

Initially, the model organizes the system-recorded network traffic information in chronological order. Through sorting, this paper derives a chronological sequence of logs. Subsequently, this paper defines the density of system behavior as the number of logs within adjacent timestamps, reflecting the intensity of system activity in those periods, i. e. the number of logs generated during that period.

This paper constructs a graph structure based on the log density information of timestamps. In this representation, each node corresponds to a timestamp, and an edge denotes a connection between adjacent timestamps. If two timestamps are consecutive and there is system activity during that time, an edge is established between them. Thus, the graph’s topology mirrors the time series relationship of system logs, with node connections illustrating the time series evolution of system behavior.

We consider a set of preprocessed network traffic features, denoted as (C), which includes information from (m) independent network traffic events. Each event (i) consists of multiple instances of network traffic, where the (j)-th instance specifies a particular network flow. The feature (C) thus comprises a series of such events.

Upon inputting the feature (C) containing a multitude of events, a graph structure is constructed to represent the relationships between different elements in the data. This graph structure allows us to capture the dependencies and interactions between various components within the network traffic data.

We can represent the graph structure as follows: Let (G = (V, E)) be a graph where (V) represents the set of nodes corresponding to different elements in the network traffic data, and (E) represents the set of edges indicating connections between these elements.Figure 4The graph structure of the time-stamped information flow is built up one by one.

Leveraging the constructed graph structure, this paper conducts in-depth analysis of correlations between different timestamps in the system. At this juncture, the article concentrates on features such as mutations, isolated nodes, and abnormal connections in the graph, as these frequently signify abnormal behavior.

GNN with attention mechanism in federated learning framework

In the described context, integrating GNN with attention mechanisms in a federated learning framework tackles the challenges of deep learning in situations with limited labeled data and data silos.

Deep learning typically relies on large amounts of labeled data for effective feature extraction and model training. However, in practical applications, much of the generated data is unlabeled and cannot be directly utilized for training models. This limitation is especially pronounced for small to medium-sized enterprises or units that generate limited amounts of single-type data.

To overcome these challenges and aggregate more diverse data sources,this paper employs FL to enable multi-user distributed learning. FedGAT, a model that combines GNN with federated learning. In a FL setting, multiple local devices collaborate to share computational resources with a central server. Each local device maintains its own local model and computational resources for training, ensuring privacy and security of individual data.Figure 5Federated learning framework based on FedGAT.

Federated learning framework based on FedGAT.

During each round of updates in FL, as shown in Fig. 5, heterogeneous computational resources are integrated at the cloud server. This integration allows for collaborative model training across distributed devices while preserving data privacy and security.

Different from deep learning-based network intrusion detection, GNN-based intrusion detection further considers the interdependence between data instances and the robustness of data structures. In terms of dependence, if an abnormal data instance is detected in the graph structure, other abnormal data instances based on this abnormal one can also be detected. In terms of robustness, attackers can usually only attack specific data instances or their contextual data instances, having limited impact on the global view of the entire graph, and it is difficult for abnormal data instances to blend into the graph. Therefore, in complex cross-layer network environments, GNN-based intrusion detection performs better than CNN-based methods.

Experiments

Data acquisition

For the evaluation of the model we proposed in this paper, NSL-KDD44 dataset is used. The NSL-KDD dataset is an enhanced version of KDD cup 9945 dataset, which is widely used in network attack detection experiments and has been considered as a benchmark dataset.

Each record of the NSL-KDD data set contains a vector of 41 features and 1 label. The 41 features can be divided into 3 categories: basic features, content features, and traffic features, including two smaller groups (same host function and same service function). The label marks the attack type of the connection. The attack types include Denial-Of-Service(DoS), Surveillance or probe(Probe),User to Root(U2R), and Remote to Local(R2L).

The NSL-KDD data set includes four data sets: KDDTrain, KDDTrain 20%, KDDTest and KDDTest-21. KDDTrain 20% is the 20% subset of KDDTrain, and KDDTest-21 is the subset of KDDTest that does not contain the record marked 21. In order to illustrate the accuracy and versatility of the model based on the convolutional neural network algorithm, this paper uses the KDDTrain, KDDTest and KDDTest-21 data sets. Data preprocessing

The NSL-KDD and KDD Cup 99 datasets contain both numerical and categorical features, which need to be preprocessed to work with machine learning algorithms. Categorical features, like protocol types (e.g., TCP, UDP, and ICMP), don’t have numerical representation and must be converted into numerical data for effective processing. This involves assigning unique numerical values to each category (e.g., TCP = 1, UDP = 2, ICMP = 3) to ensure consistent representation of these features in both training and testing datasets.

In addition, attack classes and normal traffic classifications in the dataset also need to be converted into numerical representations. For example, a common labeling scheme uses numerical labels: 1 for DoS attacks, 2 for Probe attacks, extending to 4 for U2R attacks, and 5 for normal traffic. This transformation helps machine learning algorithms effectively utilize the categorical data for intrusion detection.

This section examines the computational efficiency of the proposed Graph Neural Network (GNN) model. It analyzes the Floating-Point Operations (FLOPs) required for each individual layer in the network architecture. Figure 9 depicts the FLOPs values associated with each split layer, encompassing layers one through twenty-three.

Our examination of FLOPs across the GNN’s split layers reveals a discernible trend of escalating values. This observation aligns with the established principle that deeper neural networks, characterized by a greater number of layers, generally necessitate more computational resources to process data effectively. Higher FLOPs values directly translate to increased computational demands, potentially impacting both the training time and overall performance of the model. In essence, deeper layers with substantially higher FLOPs may require significantly longer training periods, consequently affecting the model’s overall efficiency.

It is essential to consider the distribution of computational load across different layers during the training process. By identifying and focusing efforts on the more computationally intensive layers, it is possible to optimize the overall model performance. The FLOPs values also shed light on scalability considerations when deploying deep GNN models on resource-constrained devices or systems. Efficient allocation of resources and suitable hardware are crucial for ensuring optimal performance in such scenarios. By conducting a comprehensive analysis based on FLOPs values for each split layer, informed decisions can be made regarding hardware resources and overall system design. This approach can enhance the efficiency and effectiveness of training GNN models for various applications, including network attack detection within a federated learning framework.

In addition, the FL method is used to distribute the training process of the model across multiple local devices or nodes, avoiding the problem of centralized learning that requires all data to be centralized in one place. Each local device or node only needs to update its own model parameters, and then aggregate the updated parameters into the global model, which greatly reduces communication and computing costs. Conclusions and future work

In this paper, we proposed a novel approach for federated learning-based network intrusion detection using attention-based GNN. This approach addresses the inherent security and privacy concerns associated with traditional methods by training the model on distributed local datasets, leveraging the power of GNN and an attention mechanism for effective attack pattern recognition. We emphasized the critical role of robust data acquisition and preprocessing methodologies, transitioning from the KDD Cup 99 dataset to the refined NSL-KDD dataset to ensure high-quality data for constructing a sophisticated 23-layer GNN model.

Our research environment, meticulously designed to mirror real-world network scenarios, provided valuable insights into intrusion detection within practical settings. By analyzing computational performance metrics and local device data responses across different layers, we unraveled essential dynamics in resource utilization and computational burdens within the FL framework. Furthermore, our investigation into detection accuracy under various conditions shed light on the model’s learning capabilities over iterations. Factors like restart probability, fingerprint range, and attention scope emerged as crucial influences, impacting information propagation and interaction patterns within the GNN, ultimately enhancing detection accuracy.

By integrating these research components, we have not only deepened our understanding of network attack evaluation methodologies but also established a foundation for optimizing system performance through informed resource allocation strategies. This comprehensive approach paves the way for advancing cybersecurity frameworks and fortifying network defense mechanisms against evolving threats in distributed computing environments. While this study offers valuable insights, further research could explore the scalability of the proposed approach to even larger-scale network infrastructures.
