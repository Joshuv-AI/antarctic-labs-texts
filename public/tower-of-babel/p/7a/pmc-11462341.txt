A two-stage recommendation optimization algorithm based on item popularity and user features
Authors: Jun Wang, Rongjie Hu
Published: 2024

ABSTRACT
Financial product recommendation algorithms are mainly product-centered. This article proposes a two-stage recommendation optimization algorithm based on item popularity and user features, named CPCF-TSP, that can make full use of the demographic characteristics of users and mitigate the problem of users being more inclined to choose “hot” financial products. A popularity weight factor is introduced to normalize popularity and modify Pearson's similarity function. The modified Pearson's similarity function is combined with popularity normalization and user features to improve modeling performance. The two-stage recommendation optimization procedure was combined with a collaborative filtering algorithm to improve recommendation precision. CPCF-TSP fully considers user features in building a hybrid recommendation model and solves the problem of user cold-start. It can also mitigate popularity deviations and improve recommendation precision. MovieLens data and Santander Bank client trading data were used in a case study. The results show that the algorithm reduces inaccuracy in the calculation of the weights for recommendation popularity and similarity and is especially suitable for recommending financial products in which user information can be easily collected and the number of users is far greater than the number of products considered.

Introduction

Increased use of the Internet has led to the generation of large amounts of user data, and it is critical that these data are used appropriately. Recommendation algorithms, which automatically offer recommendations to users, are key tools for data processing in recommendation systems. To encourage more users to browse applications and extend their browsing time, many applications are equipped with recommendation systems for popularity and propaganda. These applications involve nearly all aspects of users' interests, such as movies [1], music [2], books [3], tourism [4] and so on. Recommendation algorithms have gradually become indispensable to people's engagement with the Internet. However, application research in the financial industry remains in its preliminary stages.

With the rapid development of financial management, the number and scale of wealth management products are increasing, and people can feel at a loss when faced with choosing among various financial wealth management products and news sources [5]. Some user groups tend to buy popular financial products. The process of browsing irrelevant information and the herd mentality of users cause losses of time and money for financial companies and users. Therefore, tapping into user preferences and providing users with satisfactory recommendation services have become critical issues that need to be addressed for platforms selling funds or financial products. As a popular area of research, the recommendation algorithm effectively aids users in better utilizing Internet information, enhancing user loyalty, and promoting products. Yujun and Taghavi et al. have individually proposed new, optimized recommendation algorithms specifically for stock recommendations. These algorithms have achieved commendable results on their respective datasets, relying primarily on user behavior or item attributes. Our study, however, places greater emphasis on user characteristics and behaviors, along with the influence of popular products on recommendation effectiveness. For further applications of recommendation algorithms in the financial industry, please refer to Section 2.4.

As complex data and challenges are faced in practical applications, research on financial recommendation algorithms shows huge potential and scope for development, such as algorithm optimization targeted at large-scale financial datasets and data fusion and weighting involving multiple factors. Thus, research on financial recommendation algorithms is a hot spot in finance and is indispensable for improving the performance and service level of financial institutions.

Collaborative filtering (CF), the best-known recommendation algorithm, can adapt to changing environments because it does not require feature engineering. In recommendation systems, feature engineering is very expensive because it requires periodic updating of data regarding users, items, categories, and brands. CF algorithms can learn from data, adapt to changing environments, and be used in various scenarios. CF algorithms can process sparse datasets efficiently. In recommendation systems, when data are sparse, users only rate, collect, or buy some of the available items. CF recommendation algorithms can process sparse data without having to fill in unrated items. The main idea of CF algorithms is to find similarities between users and items to recommend products. The algorithms can be easily understood because the underlying principle is simple. CF algorithms have been in use for many years and are among the most effective and widely used recommendation algorithms because of their high efficiency, precision, and individualization.

However, CF recommendation algorithms have certain limitations. First, they cannot effectively solve the cold-start problem. When a system lacks data, the similarity between users or items can be difficult to determine, leading to cold-start problem. This is a problem with CF recommendation algorithms. The second limitation is the popularity deviation. CF recommendation algorithms tend to recommend items that are popular or well rated. This implies that these algorithms may miss items that are more personalized and refined. The final concerns are safety and privacy. With CF algorithms, user privacy may be put at risk by an open dataset. Therefore, safety and privacy should be considered when using these algorithms.

Practical applications of CF algorithms encounter large development spaces and challenges. Researchers are exploring new techniques and methods to overcome these limitations and optimize the performance and precision of these algorithms. In 2013, Zhao et al. introduced a two-step recommendation algorithm that notably demonstrated enhanced prediction accuracy. Recommendation algorithms essentially aim to provide users with precise recommendations, and thus, enhancing recommendation accuracy remains one of our primary objectives.

Given this background, current financial product recommendation algorithms mainly focus on products and rarely consider the demographic information of users. To address this issue, the large proportion of popular recommendations made, and the inaccuracy of similarity computation, we modified and optimized the collaborative filtering algorithm and two-stage recommendation procedure used in this study in three ways.(1)An item popularity weight factor was introduced based on traditional recommendation algorithms. This factor mitigates the effect of popular items on the recommended results using a user–item rating matrix. The number of users with interactive behaviors among the items was then used as an index, and item popularity was defined and introduced into the rating matrix. Finally, the similarity function was modified to reduce the effects of popular products on the similarity computation and final recommendation.(2)A hybrid recommendation model was built by considering user features and was used to solve the cold-start problem. Demographic and collaborative filtering recommendations were combined to form a hybrid recommendation algorithm based on popularity and user features (CPCF). Specifically, the predicted score based on user features and that determined by collaborative filtering were linearly combined. The weights of the two values were measured based on the precision of the recommendation algorithms.(3)To improve the recommendation precision, a two-stage recommendation algorithm with high precision based on popularity normalization and user features (CPCF-TSP) is proposed. CPCF-TSP optimizes each of the two steps in the two-stage recommendation algorithm. In the first step, user features are introduced as weighting factors in the prediction and selection of the item rating probability. In the second step, during the prediction of the score of the selected item, the hybrid recommendation model CPCF built as described in Section 2 is used to achieve the CPCF-TSP proposed in this study.

Related works

This section presents a review of the literature in four subsections. The first subsection reviews the improvement and basic framework of collaborative filtering algorithms. The second subsection reviews the improvement of filtering algorithms for demographics. The third subsection discusses the proposed improvement of two-step recommendation algorithms. The fourth subsection discusses the application of recommendation algorithms in the field of financial products.

Modification and basic procedure of collaborative filtering algorithms

Collaborative filtering recommendation algorithms are among the most effective and widely used because of their high efficiency, precision, and individualization [6,7]. Nakagawa and Ito [8] proposed a system that recommends user documents and files of interest through collaborative filtering. Yu et al. [9] proposed a collaborative filtering algorithm for e-commerce. Park et al. [10] proposed a rapid collaborative filtering algorithm using the k-nearest maps. Wu et al. [11] used a collaborative filtering algorithm to improve the predictive precision of large-scale recommendation systems. Applications of collaborative filtering recommendation technology are common in the Internet industry.

Researchers have recently modified collaborative filtering algorithms using social network data, context information, and deep learning. Zhang et al. [12] put forward a recommendation algorithm based on social network data using between-user relationships in social networks. This algorithm was used to modify the collaborative filtering algorithms based on matrix decomposition and achieved good results in experiments. Wu et al. [13] proposed an object recommendation algorithm based on context information that merges historical user behavior data and context information to better predict user behaviors. The results showed that this algorithm was more accurate than traditional recommendation algorithms. He et al. [14] proposed a neural network-based recommendation algorithm that utilizes feature vectors of users and items and learns and represents them through neural networks. The experimental results show that this algorithm had higher accuracy and efficiency than those of traditional recommendation algorithms. The modified algorithms outperformed traditional collaborative filtering algorithms, thereby promoting the development of recommendation algorithms.

Many traditional CF algorithms are based on user ratings and regard the recommendation problem as a score prediction problem. These algorithms are based on rating history and utilize artificial intelligence recommendation techniques, such as matrix decomposition [[15], [16], [17]], probability matrices [18,19] and other traditional recommendation algorithms or deep learning [20,21]. In the financial sphere, for example, these algorithms rate commodities that are not rated by the target users and then recommend the top N commodities with the highest scores. However, in practical applications, high-precision recommendation systems do not provide satisfactory results to users. In general, to improve arithmetic precision, recommendation results are usually concentrated on a small group of hot products [22].

Collaborative filtering refers to the preference of users for the history of other users based on their similar interests. The similarity between users is computed according to the historical scores of each user. Collaborative filtering can be classified as user-based or item-based collaborative filtering (Fig. 1).Fig. 1Main frame structure of collaborative filtering algorithm.Fig. 1

This study focused on the optimization of a user-based collaborative filtering algorithm, which is more applicable to products loved by groups with similar interests and thus recommends more popular results. User-based CF is feasible for recommendation systems with many users [23].

Similarity is another notable direction for the modification of recommendation algorithms. Mahara [24] proposed a similarity measurement method based on the mean deviation. Jain et al. [25] provided new clues for similarity algorithms and attempted to store the absolute differences between users within the same item in a user similarity matrix. Xu et al. [26] proposed a new similarity measurement method that considers the user confidence level and time contexts to improve the between-user similarity computation.

In a recommendation system, between-user similarity can be computed using four methods: cosine similarity, adjusted cosine similarity, Pearson similarity [27], and Jaccard similarity [28]. In the procedure proposed in this article, the Pearson similarity is used to compute the joint rating of an item between any two users, and the user feature similarity is calculated using cosine similarity. In summary, existing traditional recommendation algorithms cannot guarantee user satisfaction with the recommendation results under the premise of ensuring high accuracy and are more inclined to recommend popular products, resulting in a lack of personalization of the recommendation results. Moreover, the traditional similarity calculation method may have shortcomings that affect the accuracy of a collaborative filtering algorithm. Researchers have proposed a series of methods for improving recommendation algorithms. By introducing more information sources and improving the similarity calculation method, a collaborative filtering algorithm can be made more accurate and personalized, and user satisfaction with the recommendation system can be improved.

Improvement of demographic-based recommendation

Demographic-based recommendation (DF) aims to screen and filter recommended information according to the basic attributes of users, such as gender, age, education, occupation, and region. This method effectively reduces redundant user information, improves the precision of recommendations, saves time and labor, and increases the reliability and application value of the system. However, it also has some limitations, such as omission of recommended information and inaccurate judgment of user demand. Therefore, it must be further improved and optimized.

Recently, DF has attracted widespread attention, and many studies have been conducted to improve its efficiency and precision. Nasiri et al. [29] studied personalized recommendations for services and commodities using a Bayesian classifier and achieved satisfactory results. Shi et al. [30] proposed a recommendation filtering algorithm based on coefficient similarity and filtered and screened the recommended information by computing the similarity coefficient, achieving high precision in recommendations. Using a clustering analysis algorithm, Zhan et al. [31] proposed a recommendation strategy based on personalized clustering, which effectively reduced recommendation redundancy and repetition, and improved the quality and efficiency of the recommended information. Wang et al. [32] built a recommendation filtering model based on a neural network and improved the recommendation precision and user satisfaction by combining user and commodity attributes.

DF recommendation algorithms have been successful to some extent. However, Jihene et al. [33] pointed out that the cold-start problem arises when the system lacks rating records for new users or items. Therefore, DF recommendation algorithms need further research and exploration are required to improve the predictive precision of recommendation systems.

Improvement of two-stage recommendation algorithm

Typical collaborative filtering recommendation algorithms are based on user ratings. Rating prediction methods hold that the recommendation quality is higher when the rating prediction is more accurate. However, this premise ignores one situation: some users may not rate items of interest. User rating data are produced by two behaviors: (1) users choose to rate one item, and (2) they rate the chosen item.

Zhao et al. [34] proposed a two-stage recommendation procedure based on improved predictive precision. The predictions obtained by this procedure proved to be significantly more precise. Zhao et al. observed that traditional recommendation algorithms usually predicted or rated scores directly according to the grades or rating order but ignored the selection behavior. Subsequently, Zhao et al. [35] used normalized popularity to improve the diversity and novelty of recommendations and proposed two indices to measure them.

In summary, existing two-stage recommendation algorithms analyze and evaluate user behaviors represented by data and synthesize user grades and item popularity to recommend items. In this way, users save considerable time and labor and select their favorite and most appropriate items rather than only choosing the "best-seller” products. Two-stage recommendation procedures have high recommendation precision and are worthy of further research.

Application of recommendation algorithms in the financial industry

Recommendation algorithms have only recently been developed specifically for the financial industry, and most financial product recommendation systems are still product-centered rather than user-centered. To conserve time and energy, users tend to choose “hot” financial products.

Stocks are the most common type of investment considered in current financial recommendation systems. Yujun et al. [36] proposed a stock recommendation algorithm based on a large-order form of inflow. They formulated a blur algorithm to recommend stocks selected by similar users. Taghavi et al. [37] designed a classic stock ranking recommendation system. They combined a hybrid technique with various information collection agencies. In addition to financial product recommendation algorithms based on technical indicators, other algorithms exist that are based on deep learning. Sezer et al. [38] proposed an algorithm based on neural networks and used it to predict the stock prices of trading systems displaying technical analysis indices. Tsai et al. [39] formulated a new convolution and RNN model (FineNet) to predict and recommend unconventional stocks. The above algorithms have achieved good results for the respective datasets to which they have been applied, and the majority of the data were based on user behavior or item attributes.

CPCF-TSP focuses on user features and behaviors, as well as the effect of popular products on recommendations. Moreover, before the purchase of financial products, user statistics can be easily collected during user risk tests, which enables CPCF-TSP to achieve good recommendation results.

Two-stage recommendation based on item popularity and user features

This section presents a two-stage recommendation optimization theory based on item popularity and user features. First, the main concepts of the two-stage recommendation procedure are introduced, and the optimization procedure and achievement of the two-stage recommendation are discussed. Second, based on the two-stage recommendation procedure, a two-stage procedure (CPCF-TSP) based on commodity popularity and client features is introduced.

Procedure for application of the two-stage recommendation optimization algorithm

Typical collaborative filtering recommendation algorithms are based on user ratings. Generally, higher accuracy in rating prediction results in better recommendation quality. However, this ignores one situation: some users may not rate items of interest. User rating data are produced by two behaviors: (1) users choose to rate one item, and (2) they rate the chosen item. Zhao (2013) proposed two-stage recommendation algorithms (UTS) and observed that traditional recommendation algorithms usually predicted scores or rated them directly according to the scores or rating order but ignored the first item: selection behavior. Two-stage recommendation algorithms can predict unknown user behaviors because the two steps involve simulations of user ratings. The main concepts of the two-stage recommendation procedure are as follows.

The first step is to pretest rating behavior. Historical rating behaviors are related to the next rating, and the rating value is not related. Thus, only the rating behavior is used to predict the probability in the first step of the two-stage recommendation procedure. Specifically, a latent Dirichlet allocation model (LDA) that generates only example texts is introduced into the prediction. In the second step, the historical rating data for all users (including rating behavior and rating levels) are used to predict unknown levels. Existing techniques targeting rating prediction can be used in this step. Thus, UTS involves singular value decomposition (SVD).

SVD decomposes the rating information of a resource using a user's previous rating records. It decomposes the rating matrix into two low-dimensional matrices, a user feature matrix and an item feature matrix, which represent the degree of the user's preference for each of the latent features and the degree to which the item contains these features, respectively. Each row of the user matrix represents a vector of users, and each column of the item matrix represents a vector of resources. The matrix decomposition algorithm predicts the ratings of all blanks in the matrix and makes the size of the predicted score reflect the degree of user preference. The larger the predicted score is, the more likely the user is to like the item. Thus, the item with the highest predicted scores can be recommended to the user.

The existing optimization algorithms for two-stage recommendation procedures target two aspects: improving the diversity of recommendations and improving recommendation precision. Given these objectives, in the first step, when these algorithms predict the probability of users choosing a certain item, they ignore the users' personal information. In addition, the improved diversity of recommendations may reduce recommendation precision.

When a recommendation system makes a recommendation to users, the first step is to predict the probability of users evaluating a certain commodity. In the second step, a concrete evaluation score for each item is predicted. Finally, a recommendation list is formed according to the first N items that most interest users. To solve the two-stage recommendation problem, we optimized each step. Optimization of popularity normalization

Pearson's similarity function treats all items equally. However, as previously mentioned, users' item rating behavior varies according to item popularity. Thus, a best-selling weight was introduced into the function for Pearson's similarity to normalize popularity. The weight of item i is computed as follows:(2)δi=log|N(u)||1+N(i)|,where δi is the weight of product i, N(u) is the set of all users in the system, and N(i) is the set of users who bought product i. When N(u) is constant, a larger N(i) implies a smaller δi. In other words, when δi is larger, the weights of unpopular products can be increased to improve the diversity of the recommendation results.

The similarity after popularity normalization is computed as follows:(3)Simuser(u,v)=∑i∈I(Ru,i×δi−R‾u)×(Rv,i×δi−R‾v)∑i∈I(Ru,i×δi−R‾u)2∑i∈I(Rv,i×δi−R‾v)2,where Simuser(u,v) is the similarity between users u and v based on demographic features and δi is the weight of item i and reflects the popularity of the item. As in Eq. (3), Ru,i and Rv,i are the scores of item i by users u and v, respectively; R‾u and R‾v are the scores of all items by users u and v, respectively; and I is the set of all items.

This modified version clearly shows that items with different popularities act differently in the computation of similarity because less popular items are more influential than more popular items.

Popularity weight mixing factor and user feature hybrid recommendation algorithm

People living in the same region often have similar lifestyles and habits, but those living in different regions may differ significantly in their lifestyles and habits. Similarly, if two persons have similar features (e.g., age, gender, profession), their interests may be more similar. The clues of user-based collaborative filtering design are that between-user similarity is evaluated by analyzing historical data on user behaviors. The neighbor with the highest similarity to a certain user is thereby determined, and on this basis, a recommendation is made. Thus, user features are introduced, and similar products are recommended to users with similar features. The recommendation effect can thereby be ensured. Jeong [40], for example, built a simple recommendation model based on demographic features. The model evaluates between-user similarity according to user features (e.g., age, education, and income) and thereby guides recommendation activities that fully utilize user features.

Given the above problem, we use a weighted merging method to mix user-based collaborative filtering and demographic recommendations, and we propose a mixed algorithm for analyzing user features and behaviors (CPCF). The two recommendation techniques yielded different prediction results for the same dataset. Two-stage recommendation optimization algorithm based on popularity normalization and user features

In recommendation tasks, two-stage recommendation algorithms show outstanding performance and precision and are suitable for use in generating recommendations. However, the recommendation lists they produce tend to focus on popular products and ignore user information. We merged user features and normalized popularity and optimized each step of the two-stage recommendation algorithm. Thus, a two-stage recommendation algorithm based on normalized popularity and user features is proposed. The CPCF-TSP procedure is illustrated in Fig. 2. The algorithmic principle is as follows.

The first step is to pretest rating behavior. In a traditional two-stage recommendation algorithm, the historical rating behaviors of users are used directly to predict the probability of rating a certain product. The user rating behavior data are binary and can be expressed as follows:(9)BU(u)=(b1,b2,…,bn),where bi={1,i∈I(u)0,i∉I(u)(i∈[1,n]).

Users can be described by an n-dimensional vector, where 1 represents a rated item, 0 represents an unrated item, and I(u) is the set of all the items rated by user u. The probability of a final predicted rating can be expressed as follows:(10)Pˆ(u,i)=1|N(u)|∑a∈N(u)BU(a)[i],where BU(a)[i] is element i in the binary user model for user a and N(u) is the set of neighbors most similar to user u.

This probability reflects the possibility of neighbors rating a certain item for a given user. Visually, this algorithm is inclined toward popular items with high scores. Simultaneously, no precise probability is available for new users without historical behavioral data.

To solve this problem, user features are merged, and user similarity is included. The modified probability prediction equation is as follows:(11)Pˆ(u,i)=∑a∈N(u)Simchar(u,v)·BU(a)[i]|N(u)|·∑a∈N(u)Simchar(u,v),where Simchar(u,v) denotes the similarity between users u and v (Eq. (8)).

The second step is to predict the ratings. The CPCF hybrid recommendation algorithm proposed in Section 3 is used in this step. A popularity weight factor (Eq. (2)) is introduced to modify the similarity. Subsequently, a modified similarity function (Eq. (3)) is used to modify the user-based collaborative filtering algorithm (Eq. (6)). Finally, the predicted demographic scores are combined with the modified collaborative filtering scores predicted using Eq. (7).

Overall, with CPCF-TSP, the probability Pˆ(u,i) of user u rating product i is used for prediction. The second step is to predict the score Pu,i of user u over product i.

Experiments

Instruments

The data used to evaluate the CPCF-TSP were MovieLens 100K and client trading data from Santander Bank. MovieLens 100K includes 100,000 ratings (from one to five stars) of 1682 movies by 943 users. The client trading dataset from Santander Bank includes the holding situations of 14,576,924 clients for more than 24 financial products. Users include customers with one or more purchases and new customers without any trades. Financial products include both new and old products.

Banco Santander is the largest bank in Spain and the second-largest bank in Europe. The bank generates a large amount of data on customer behavior every month and is constantly expanding with new financial products. This phenomenon makes it easy to use data-mining techniques to explore the patterns behind customer behavior, analyze customers' propensity to buy products and recommend potential products that meet their needs. Enabling every Santander customer to receive financial product recommendations, rather than limiting such recommendations to a small group of customers, not only improves the user experience but also increases the profitability of the bank's business, yielding a “win-win” situation for both the user and the bank.

There are two customer data sets released by Santander Bank: the training set (train_ver2.csv) and the test set (test_ver.csv). The user's behavioral timesteps and the specific data distribution are organized as follows:

Each row of data in the training set represents a customer's personal information and holdings of the 24 financial products in a given month, and each row of data in the test set represents a customer's 24 characteristics. Users include regular customers who have made one or more purchases and new customers who have never made a transaction. The financial products are categorized into old and new products.

In the second step of the two-stage recommendation optimization procedure, product ratings by users are predicted. To compare the performances of different recommendation algorithms, we adopted the first step of the two-stage recommendation optimization procedure illustrated in Fig. 2 and chose the basic recommendation algorithms of matrix decomposition, probability statistics, and deep learning. Moreover, the CPCF was introduced. Fig. 5 shows the precision, recall rate, and NDCG results for SVD, BPR, NCF, and CPCF for the MovieLens 100K and Santander datasets. The results show that CPCF provides the best recommendation for both datasets.

Specifically, the recommendation results of BPR and CPCF were better, and the differences in the evaluation indices were within 1 % and 3 %, respectively (Fig. 5(a)). Unlike global rating optimization using SVD, BPR sorts according to the product preferences of a sole user. For actual products, preference-based recommendation sorting, which selects only a small amount of mass data, is outstanding. Hence, BPR performed better on MovieLens 100K, as shown in Fig. 5(b).

NCF outperformed SVD, but both outperformed CPCF to some extent. This is because NCF focuses on implicit feedback and acquires user preferences by allowing users to watch videos, purchase products, and click to select items. As a result, it has a high recall rate (0.279). In comparison, SVD computes the preferences for items and the inclusive level of item factors using existing rating data and can traverse the display/hidden factors that affect the rating. Therefore, more meaningful relationships are identified. However, SVD requires a dense rating matrix, which means that the direct use of the original SVD is very difficult with huge numbers of users and items in a recommendation system. Thus, SVD performed the worst on both datasets, as the results in Fig. 6 show.

In the optimized collaborative filtering algorithm (CPCF), the demographic features of users are integrated into the recommendation, and the computation of user similarity is modified. Therefore, CPCF is feasible for recommendation scenarios in which the number of users is far larger than the number of items. Analysis of the Santander Bank dataset showed that CPCF performed better in terms of precision, recall, and NDCG, indicating that CPCF can also be used to recommend financial products when the number of users is far larger than the number of items. Before purchasing financial products, statistics can easily be provided to users during risk tests. Because the number of users in the Santander dataset is much larger than the number of items, there are many intersective choices between users, which makes the data denser. Thus, CPCF is applicable to recommendation scenarios in which user information can be easily collected and the number of users is far larger than the number of items. This hybrid recommendation algorithm based on collaborative filtering and user statistics has the potential to play a critical role in recommendation systems in the age of big data.

Selection of hybrid coefficient

As stated in Section 3, hybrid recommendation models integrate and use various recommendation algorithms comprehensively to improve the performance and predictive precision of recommendation systems. The determination of combined weights is an important research problem to ensure that the best recommendation results are obtained. Recommendation algorithms may exhibit varying advantages and limitations across different datasets. For this reason, a comparative analysis was conducted with the Santander trading dataset and the MovieLens movie rating dataset for different scenarios.

The predictive precision of CPCF-TSP exhibited a single-peak shape for each of the two datasets. When α=0, the CPCF is transformed into a user-based collaborative filtering algorithm. When the demographic data of users were not considered, only the interactions between users and items were considered. When α=1, the algorithm is transformed into a demographic-based recommendation algorithm that finds similar users according to statistical features. Secondly, when α=1 or α=0, the recommendation effect of the algorithm worsened. This is because the prediction precision of the recommendation algorithm was the lowest, as shown in the figures. When α∈(0,1), the prediction precision improves significantly. The optimal α values for the two datasets were both greater than 0.5, which again demonstrates that introducing user features can improve the predictive precision. The results obtained with α=0.78 were the best for the Santander dataset, indicating that demographic-based filtering algorithms account for the largest proportion of hybrid models' performance. This is because the number of users in a bank trading scenario is far larger than the number of products, and between-user interactive behaviors are more likely to intersect. In this situation, the demographic features of users (e.g., age, gender, and income) are more likely to affect the next behavior of users and thus have a greater influence on the recommendation result.

Overall, the results of the experiment suggest that different recommendation algorithms have different advantages and limitations for different datasets. Hence, the value selected for the hybrid coefficient is critical to improving the recommendation performance. The combination of demographic and collaborative filtering can significantly improve recommendation precision, and the introduction of demographic features can provide more precise recommendations for users.

Conclusions

Current recommendation technology is relatively mature and has been widely used in e-commerce, music news, and other Internet industries. However, research on targeted recommendation strategies in the financial products industry is still insufficient. Financial trading platforms generate a large amount of user behavior data daily, and recommendation algorithms can mine customer information, analyze customer consumption tendencies, and provide accurate financial products. At this stage, the recommendation algorithms for financial wealth management products are mainly product-centered and seldom consider users’ demographic information.

CPCF-TSP was modified and optimized using a collaborative filtering algorithm and a two-stage recommendation procedure to solve the problems of hot item inclination and low similarity computation accuracy. CPCF-TSP is best suited to financial product recommendation scenarios in which user information is easy to collect and the number of users is much greater than the number of products. This modification can be performed in three ways.

With respect to the large proportion of popular products among the recommended products, traditional recommendation algorithms were modified in two ways. (1) The demographic features of the users were considered. Specifically, a popularity weight factor was introduced to normalize the popularity and modify Pearson's similarity function. (2) The similarity was modified using popularity normalization. The modified Pearson's similarity function was combined with popularity normalization and user features to improve the modeling performance. Finally, to improve the recommendation accuracy, a recommendation algorithm integrating user features and popularity normalization was combined with a two-stage recommendation procedure. Therefore, a two-stage recommendation optimization algorithm based on item popularity and user features (CPCF-TSP) is proposed. User features and normalized popularity were combined to optimize each step of the two-stage recommendation algorithm. In the first step, a user feature weight factor was introduced to predict and select the item rating probability. In the second step, a recommendation model was used to predict the ratings of the selected items.

To validate the effectiveness of CPCF-TSP and CPCF under different scenarios, we used MovieLens movie rating data and Santander Bank client trading data in experiments and validated them using precision, recall, and NDCG as evaluation indices.
