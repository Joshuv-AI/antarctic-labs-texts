A benchmark dataset for primitive Indian paddy field images with deep learning based classification
Authors: Prabira Kumar Sethy, Ranjith Pamerelli, Santi Kumari Behera, Bibhuti Ranjan Behera, Aseel Smerat, Anita Khanna
Published: 2026

ABSTRACT
AbstractWe introduce a primitive Indian paddy field image benchmark dataset and deep-learning-based classification baseline for automated variety identification task. The dataset (sethy, PRABIRA; Pamirelli, Ranjith (2026), “Primitive Indian Paddy On-Field Images”, Mendeley Data, V1, https://doi.org/10.17632/jthrm4mj5r.1) includes 33 primitive rice varieties each consisting of 100 field images (3400 images in total). The images were captured from Regional Research and Technology Transfer Station (RRTTS), Chiplima field margins and native habitats. RRTTS-Chiplima is one of the regional centres under Orissa University of Agriculture & Technology (OUAT), Sambalpur, Odisha, India. We utilize deep features learnt from pretrained NASNet-Large model (input image size: 224 × 224) and train one-vs-all linear Error Correcting Output Codes (ECOC) classifier using features from prediction layer of the network. We split the data stratified with 80% training images and 20% test images.Results include accuracy of 0.9424, sensitivity of 0.9424, specificity of 0.9982, precision of 0.9536, false positive rate of 0.0018, F1-score of 0.9439, Matthews correlation coefficient (MCC) of 0.9443 and Cohen's kappa of 0.9203. The total computation time for this pipeline is ∼82,811 s. We hope that this benchmark dataset and the baseline results reported here will help the researchers working towards crop monitoring, crop varietal identification and precision agriculture research.Keywords: Paddy field images, Primitive rice varieties, NASNet-Large, Deep feature classification, Precision agriculture

Value of the Data

The dataset provides a benchmark of 3400 in‑field images covering 33 primitive Indian rice varieties (100 images per variety), enabling development and evaluation of computer‑vision and deep‑learning methods for varietal recognition. Images were captured under real field conditions with background clutter, varying illumination, and differing phenological stages, making the collection suitable for testing model robustness and domain‑adaptation techniques. This resource is useful for precision agriculture, germplasm conservation, automated phenotyping, and yield‑forecasting applications, and its public availability supports reproducible research and comparative studies.

Background

Accurate in‑situ identification of rice varieties supports management decisions, breeding programs, and conservation of genetic resources, but traditional visual inspection is time‑consuming and requires expert knowledge. Automated image‑based classification can scale monitoring and reduce subjectivity; however, existing datasets often lack representation of primitive varieties and realistic field variability. To address this gap, we assembled a diverse set of field images from a research station in Odisha, India, and demonstrate a baseline approach using deep convolutional features from a pretrained model combined with a lightweight classifier to provide an initial reference for multi‑class varietal recognition under practical conditions.

Data Description

The dataset contains 33 classes (primitive rice varieties) with 100 RGB field images per class (3300 images total). All images were collected from paddy fields at the Regional Research and Technology Transfer Station (RRTTS), Chiplima, a unit of Orissa University of Agriculture & Technology (OUAT), Sambalpur, Odisha, India. Images are organized into class‑specific subfolders and labeled by folder name; they reflect natural in‑field variation (lighting, background, plant growth stages). The collection is publicly hosted at the provided Mendeley Data link. (sethy, PRABIRA; Pamirelli, Ranjith (2026), “Primitive Indian Paddy On-Field Images”, Mendeley Data, V1, https://doi.org/10.17632/jthrm4mj5r.1). The sample of images are illustrated in Fig. 1. For this dataset we use “primitive” to refer to traditional rice landraces or local cultivars that meet all of the following criteria: (1) maintained and cultivated by local farmers over multiple generations, (2) have no documented history of formal breeding or release as modern/improved cultivars, (3) are commonly known by local (vernacular) names, and (4) exhibit distinct morpho‑agronomic characteristics and adaptation to native habitats (Table 1).

Experimental Design, Materials and Methods

Images for baseline experiments were loaded into ‘imageDatastore’ with labels specified from subfolder names. Data splitting and validation — Images were partitioned using MATLAB’s ‘splitEachLabel’ function with stratification by class so that each of the 33 classes has 80 training and 20 test images. The random number generator was fixed using rng(1) to make the split fully reproducible. Reported baseline results are obtained on this held‑out test set. To assess sensitivity to the choice of split, we also performed 5‑fold stratified cross‑validation. This show consistent performance with low variance, indicating the baseline is not an artifact of a single data split. Images were resized to input dimensions required by network (224 × 224) using ‘augmentedImageDatastore’ (colorpreproc was used when preprocessing images). Deep features [1,2] were extracted using activations function from a pretrained NASNet‑Large [3] network specifying the layer used for predictions. We collected deep features as column vectors (MiniBatchSize=32) [4,5]. Classification was performed with multiclass framework Error‑Correcting Output Codes (ECOC) implemented by ‘fitcecoc’ using linear SVM binary learners ('Learner'='Linear', 'Coding'='one-Vs-all'). Briefly, ECOC [[6], [7]] decomposes the multiclass problem into several binary linear SVM [[7], [8]] problems and decodes the combination of outputs from each binary problem to create a multiclass prediction. Predictions were made on test features, and results were summarized using a confusion matrix and metrics including accuracy, sensitivity/recall, specificity, precision, false positive rate, F1‑score, MCC, and Cohen's kappa. Baseline values are: Accuracy = 0.9424, Sensitivity =0.9424, Specificity =0.9982, Precision =0.9536, FPR =0.0018, F1score =0.9439, MCC =0.9443, Kappa =0.9203. Total elapsed time through entire pipeline was ∼82,811 s. MATLAB implementation utilizes Image Processing and Deep Learning toolboxes: ‘imageDatastore’, ‘augmentedImageDatastore’, activations, ‘fitcecoc’ [[9], [10]]. To reproduce baseline results, follow provided workflow illustrated in Fig. 2. The Confusion matrix is illustrated in Fig. 3. Although the dataset contains equal nominal class counts (100 images per variety), in-field variability (illumination, background clutter and phenological stage; Fig. 1) can create effective class imbalance where some classes are harder to learn. To mitigate this problem, we applied data augmentation [11].

Data augmentation was applied only to training images to increase intra‑class variability and mitigate effective class imbalance. Augmentations included random horizontal flip (p = 0.5), random rotation (±15°), random scale/crop (scale 0.9–1.1), color jitter (brightness ±20 %, contrast ±20 %, saturation ±15 %), Gaussian blur (σ up to 1.0 with p = 0.2), and random translation (±10 % image size).
