PanGraphRNA: An efficient and flexible bioinformatics platform for graph pangenome‐based RNA‐seq data analysis
Authors: Yifan Bu, Zhixu Qiu, Wen Sun, Yishui Han, Yifan Liu, Jing Yang, Minggui Song, Zenglin Li, Songyu Liu, Yuzhou Zhang, Chuang Ma
Published: 2026

ABSTRACT
ABSTRACTTranscriptome deep sequencing (RNA‐seq) data analysis is often affected by reference bias introduced by the use of a single linear reference (SLR) genome. Graph‐based pangenomes can mitigate this bias by integrating the SLR genome with complex genetic variations within a species; however, their application remains limited owing to a lack of dedicated analytical tools. Here, we present PanGraphRNA, an integrated bioinformatics platform for RNA‐seq data analysis using a graph pangenome as reference. Built on the Galaxy web‐based framework, PanGraphRNA provides functional modules for constructing, evaluating, and applying graph pangenomes across different population scales, thus enabling accessibility, traceability, and reproducibility throughout the analysis. Applied to both real and simulated RNA‐seq data sets from Arabidopsis (Arabidopsis thaliana), PanGraphRNA outperformed the SLR approach, achieving higher read alignment accuracy and more precise gene expression quantification. PanGraphRNA enabled the identification of drought stress‐induced genes and flowering time‐related quantitative trait loci that were previously missed with the conventional SLR approach. Furthermore, we successfully applied PanGraphRNA to process RNA‐seq data sets from rice (Oryza sativa) and maize (Zea mays). By providing standardized, containerized workflows, PanGraphRNA will facilitate transcriptomic research in key plant species, including Arabidopsis, rice, and maize.Keywords: galaxy, graph pangenome, population, reference bias, RNA sequencing

INTRODUCTION

High‐throughput transcriptome sequencing has become an indispensable tool in environmental and agricultural research, enabling comprehensive gene expression profiling across diverse samples and large populations. Population‐scale transcriptome analysis typically starts by aligning transcriptome deep sequencing (RNA‐seq) reads to a single linear reference (SLR) genome, which only harbors one reference allele at sites that might be polymorphic across different accessions. A key limitation of this strategy, therefore, is the frequent occurrence of reads that cannot be properly mapped to the reference genome or that are incorrectly mapped. These errors arise in part owing to the presence of non‐reference alleles in sequencing data and sequence variations among the genomes of individuals. This problem, commonly called “reference bias” (Chen et al., 2021; Lin et al., 2024), affects downstream analyses, including the calculation of the number of mapped reads (Brandt et al., 2015), quantification of gene expression (Adduri and Kim, 2024), and mapping of expression quantitative trait loci (eQTLs) (Gobet et al., 2022). Therefore, reducing or addressing reference bias is essential to ensuring the accuracy of RNA‐seq data analysis (Kaminow et al., 2022; Zhang et al., 2025).

A pangenome serves as a superior reference that mitigates the reference bias associated with the SLR approach by capturing sequence diversity across multiple individuals. One relatively simple approach for building a pangenome is to include all possible genomic variants at each polymorphic position from a limited number of genomes along a linear sequence (Eizenga et al., 2020). Compared to the SLR approach, pangenomes improve read alignment accuracy by reducing the number of unmapped or misassigned reads (Lee et al., 2018; Kaminow et al., 2022). Indeed, this enhancement allows some previously unaligned reads when using an SLR to become correctly aligned, thereby facilitating the assembly of transcripts that are absent in the SLR (Li et al., 2023). Additionally, the improved alignments enable the identification of genetic variants overlooked by the SLR analysis, providing opportunities to uncover previously missed signals by genome‐wide association study (GWAS) (Gui et al., 2022). Linear pangenomes have been successfully applied in population‐scale studies (Hu et al., 2025). In the rice (Oryza sativa) study, this approach enabled the comprehensive characterization of genetic variation, the discovery of novel genes, and the study of domestication patterns across diverse rice populations (Wang et al., 2018). Despite these advantages, such linear concatenation‐based representations still treat the genome essentially as a single, topology‐free sequence. This depiction limits their flexibility in trying to capture genomic diversity and integrate non‐reference sequences into the coordinate system of a single reference genome (Eizenga et al., 2020; Kopalli et al., 2025).

Unlike linear representations, a graph‐based pangenome (also known as graph pangenome or pangenome graph) integrates a reference genome and sequence variations into a unified graph structure, in which genomic coordinate information is embedded as graph bubbles (multiple paths connect a common head and tail node) (Eizenga et al., 2020). These bubbles allow positional information to be retrieved by tracing paths through the sequence graph. Graph pangenomes can be constructed using a variety of methods, such as PanVC (Valenzuela et al., 2018), vg (Garrison et al., 2018), HISAT2 (Kim et al., 2019), GraphTyper2 (Eggertsson et al., 2019), minigraph (Li et al., 2020), minigraph‐cactus (Hickey et al., 2024), and PGGB (Garrison et al., 2024). By incorporating non‐reference variant paths, graph pangenomes effectively reduce reference bias and improve the alignment of reads containing multiple single‐nucleotide polymorphisms (SNPs) or insertion–deletion mutations (InDels) relative to the SLR genome (Rakocevic et al., 2019). Graph pangenomes provide a powerful framework for identifying allele‐specific epigenomic modifications (Grytten et al., 2019; Groza et al., 2020) and for mapping trait‐associated genomic variations (Liu et al., 2020; Zhou et al., 2022). In rice, for example, analyses using graph pangenomes have uncovered extensive structural and copy‐number variations linked to domestication‐ and adaptation‐related agronomic traits (Qin et al., 2021). Moreover, graph pangenomes hold great potential for elucidating the genetic basis of heterosis because they jointly represent parental haplotypes, structural variants, and presence/absence variation within a unified framework, enabling direct comparison of allele combinations in hybrids (Kong et al., 2024). Such variant‐resolved representations can also guide crop genetic improvement (Zhou et al., 2022). Despite these advances in the field of genomics, the application of graph pangenomes to transcriptomic data remains largely underexplored (Sibbesen et al., 2023; Wu et al., 2024). A major obstacle is the scarcity of dedicated bioinformatics toolkits and optimized analysis pipelines, hindering the systematic assessment of the effectiveness and applicability of graph pangenomes in RNA‐seq studies across diverse biological contexts.

In this study, we introduce PanGraphRNA, an integrated bioinformatics platform for graph pangenome‐based transcriptome analysis. Using Arabidopsis (Arabidopsis thaliana) as a case study, we used PanGraphRNA to construct multiple graph pangenomes that incorporate genetic variations at the individual, subpopulation, and population levels, and we systematically evaluated their influence on read alignment accuracy. We assessed the performance of these graph pangenomes in terms of efficiency of read mapping and accuracy of gene expression quantification through the analysis of simulated and real Arabidopsis RNA‐seq data sets. Furthermore, we applied PanGraphRNA to mine RNA‐seq data sets for drought stress‐related genes and flowering time‐related expression quantitative trait loci (eQTLs) in Arabidopsis. We also extended the application of PanGraphRNA to the crop species rice and maize (Zea mays L.). To enhance accessibility, we established a Docker‐based Galaxy utility that offers a portable and user‐friendly environment for conducting complex transcriptomic analysis using graph pangenomes as the reference.

RESULTS

Overview of PanGraphRNA

PanGraphRNA is composed of four functional modules, one each for graph pangenome preparation, construction, evaluation, and application (Figure 1). These modules can be sequentially executed via the developed web‐based Galaxy platform (Jalili et al., 2020).

PanGraphRNA workflow

Module I illustrates the preparation of input data for graph pangenome analysis, which comprises data upload for the reference genome, gene annotation, variant, and RNA‐seq files, as well as quality control and preprocessing of RNA‐seq data to ensure high‐quality input. Module II depicts the construction of graph pangenomes at the individual, subpopulation, or population scale using HISAT2, which integrates accession‐specific variants to generate efficient graph‐based indexes. Module III presents the evaluation framework for graph pangenomes, in which read alignment performance is assessed using multiple mapping‐related metrics based on real and simulated RNA‐seq data. Module IV demonstrates downstream applications of graph pangenomes, including quantification of gene expression levels, differential expression analysis, and detection of expression quantitative trait loci (eQTLs).

The graph pangenome preparation module (Module I) prepares input files required for downstream graph pangenome analysis. It accepts and processes necessary input files with in‐house scripts. These include a FASTA file of the SLR genome, a gene transfer format (GTF) file with gene annotations, a variant call format (VCF) file containing genetic variations, and a set of RNA‐seq data in FASTQ format. Additionally, the module examines the quality of RNA‐seq data sets using fastp (v. 0.20.0) (Chen et al., 2018), which removes sequencing adapters, trims low‐quality bases, and removes low‐quality reads.

The graph pangenome construction module (Module II) builds graph pangenomes at the individual, subpopulation, or population level by implementing the fast, memory‐efficient toolkit HISAT2 (v. 2.2.1) (Kim et al., 2019). It first extracts variation data for a list of user‐specified accession(s) using bcftools (v. 1.13) (Danecek et al., 2021) and then stores the constructed graph pangenomes as a graph Ferragina–Manzini index (GFM‐index) file. We note that the GFM index is optimized for efficient read alignment and is not well suited for characterizing graph‐based topological properties such as node number, edge number, or path complexity. Nevertheless, by facilitating the analysis of alignment results, this representation enables the evaluation of how incorporated variants affect mapping accuracy. We also integrate the genome browser JBrowse (https://jbrowse.org/jb2) to provide an interactive visualization module for intuitively displaying read alignments, thus enabling direct comparison of gene‐level alignments across different graph pangenomes. The read alignments are stored in binary alignment map (BAM) format.

The graph pangenome evaluation module (Module III) assesses the performance of graph pangenomes against that of the SLR strategy by using six read‐mapping metrics: unique alignment rate, multiple alignment rate, mapping error rate, F1 score, recall, and precision (see MATERIALS AND METHODS). To conduct this evaluation, Module III establishes the ground truth by aligning real or simulated RNA‐seq reads (from accession X) to the corresponding linear reference genome for that individual accession (X_linear) using HISAT2. Simulated reads with precise genomic coordinates are generated using Flux (v. 1.2.1) (Griebel et al., 2012).

The graph pangenome application module (Module IV) performs several applications of graph pangenomes, including quantification of gene expression levels from RNA‐seq data, differential expression analysis, and identification of eQTL. Within this module, user‐provided RNA‐seq data are aligned to different graph pangenomes with HISAT2, with outputs in the form of sequence alignment map (SAM) or BAM files. Gene expression is quantified as transcripts per million (TPM) with StringTie (v. 2.1.5) (Pertea et al., 2015). Differential expression analysis is performed using DESeq. 2 (v. 1.34.0) (Love et al., 2014), and eQTL analysis is accomplished with MatrixEQTL (v. 2.1.0) (Shabalin, 2012). These analyses enable researchers to identify functional genes that would otherwise be undetectable using an SLR strategy. In addition, the expression matrix generated by PanGraphRNA can be easily adapted for other downstream applications, providing flexibility for various transcriptomics and genomics analyses.

PanGraphRNA was developed based on the web‐based Galaxy framework, providing a user‐friendly graphical user interface (GUI), as well as ensuring accessibility, traceability, and reproducibility. The source codes for PanGraphRNA and its dependencies are packaged into a standardized container using the Docker platform. Through standardized packaging techniques, users can deploy the PanGraphRNA Docker container regardless of their informatics expertise on their local servers for graph pangenome‐based analysis of large‐scale RNA‐seq data. In addition, to accommodate a wider range of computational environments, we provide a fully functional command‐line version (https://github.com/cma2015/PanGraphRNA/tree/main/command-line) alongside the GUI‐based Galaxy framework. This command‐line version should enable the seamless integration of PanGraphRNA into automated workflows and deployment in high‐performance computing (HPC) environments. For user convenience, comprehensive user documents are also provided at the project webpage.

A graph pangenome approach improves RNA‐seq read alignment by integrating genetic variations at the individual level

We assessed the efficacy of the graph pangenome approach by mapping RNA‐seq reads derived from four Arabidopsis accessions, namely, Antwerpen 1 (An‐1), Cape Verde Island (Cvi‐0), Landsberg erecta (Ler), and Shahdara (Sha). These accessions were selected based on the availability of chromosome‐level genome assemblies (Table S1; Jiao and Schneeberger, 2020) and public RNA‐seq data sets from multiple experimental conditions (Table S2). For a given accession (X denoting the accession identifier), we constructed a graph pangenome (X_graph) with HISAT2, using the TAIR10 reference genome for Columbia (Col‐0; Col0_linear) as the backbone sequence and integrating those genetic variants from accession X within genic regions as alternative branches (Figures 2A, S1). We then compared read‐mapping rates and metrics against three references (the linear Col‐0 genome [Col0_linear], the graph pangenome for accession X [X_graph], and the linear genome for accession X [X_linear]) to assess whether a graph pangenome can serve as a viable and superior alternative for analyzing RNA‐seq data from accessions without high‐quality or missing genomes.

Compared to the mapping rates obtained against the Col0_linear genome, mapping using the relevant graph pangenome resulted in overall higher alignment rates of RNA‐seq samples from the An‐1, Cvi‐0, Ler, and Sha accessions by 1.81%, 3.25%, 2.26%, and 2.06% on average, respectively (Figures 2B, S2; Table S2). Notably, these enhancements brought the overall alignment rates when using graph pangenomes (~96.74%) closer to those observed when reads were mapped to their corresponding individual high‐quality genomes (~97.27%) (Table S2). The higher read alignment rate was mainly due to the increase in the number of uniquely mapped reads. For example, the Cvi0_graph graph‐based pangenome returned 1,068,452 uniquely mapped reads, a number about 13‐fold that obtained against the Col0_linear genome (81,127) (Figure 2C; Table S2). Further analysis revealed that these uniquely mapped reads identified when using graph pangenomes are mainly associated with variant‐containing genomic regions, as illustrated with RNA‐seq data (NCBI accession no. ERR754056) from the Cvi‐0 accession (Figures 2D, S3).

Using the results of alignment to the X_linear genome as ground truth, the graph pangenome approach reduced the overall error rates (see MATERIALS AND METHODS) by an average of 2.68%, 4.72%, 3.54%, and 2.97% for the An‐1, Cvi‐0, Ler, and Sha accessions, respectively, compared to the results obtained with the Col0_linear genome (Figures 2E, F, S4). The types of mapping errors that saw the steepest drops when using the graph pangenomes were mainly of two types: Mapped to UnMapped (M‐UM) and Different Mapping Loci (DML). The percentages of the M‐UM error type were on average 1.80%, 3.24%, 2.26%, and 2.04% (An1_graph, Cvi0_graph, Ler_graph, and Sha_graph, respectively) lower for RNA‐seq alignments using a graph pangenome than those obtained with the Col0_linear genome. The DML error type reached rates lower by 0.89%, 1.35%, 1.38%, and 0.96% (An1_graph, Cvi0_graph, Ler_graph, and Sha_graph, respectively) when RNA‐seq reads were aligned to the graph pangenomes as the reference relative to the Col0_linear genome as the reference (Figure 2F). Taking the At3g21770 gene as an example, sequence differences between the Ler and Col‐0 accessions led to misalignments of RNA‐seq reads obtained from samples in the Ler background when using the Col0_linear genome (Figure 2G). By contrast, the Ler_graph correctly mapped these reads, as it included the Ler‐specific sequence variation for the At3g21770 locus (Figure 2G).

These differences in read mapping between the two approaches (SLR and graph pangenome) also resulted in differences in the number of reads mapping to each gene. Using an RNA‐seq data set (NCBI accession number: SRR4113389) from the Ler accession as an example, the Ler_graph produced a lower mapping error rate for approximately 64% of all annotated genes (Figure 2H), leading to higher (50.59% or 12,496 genes) or lower (6.51% or 1,607 genes) read counts mapping to genes (Figure 2I). Across 54 tested RNA‐seq data sets, > 58% of all genes had fewer or more reads mapping to them when using the relevant graph pangenome than when using the Col0_linear genome (52.29% increased; 5.80% decreased) (Figure S5A), with > 27% changing by more than 30 read counts (Figure S5B). This shift was strongly driven by genes with greater read counts when using a graph pangenome, indicating that mapping RNA‐seq with graph pangenomes reshapes read distribution and captures more reads per gene.

Overall, these results support the notion that graph pangenomes, which take into account sequence variation information, can help correct the mapping errors that arise when using an SLR genome and thus improve the accuracy of read alignment and gene expression quantification.

Subpopulation‐level graph pangenomes are suitable for population‐level RNA‐seq analysis

The Arabidopsis 1001 Genomes Project sequenced a worldwide panel of 1,135 Arabidopsis accessions, which were categorized into 10 subpopulations based on population structure and geographical origin (Alonso‐Blanco et al., 2016). This massive data set provided us with an opportunity to explore the capability of graph pangenomes for population‐level RNA‐seq analysis. Not surprisingly, the computation cost of graph pangenomes scaled with the number of genetic variations included (Table S3). The 1001G_graph, encompassing 3,851,498 SNPs and 432,115 InDels, demanded 18.4 GB of memory and > 600 min for computation, markedly exceeding the resources needed for subpopulation‐level graph pangenomes based on subsets of this large population (Table S3). This observation prompted us to investigate whether subpopulation‐level graph pangenomes offered a computationally efficient alternative for RNA‐seq analysis at the population level.

We selected the Sha accession from the Asian subpopulation and performed simulations to compare read‐mapping performance of four genome references: Col0_linear, the graph pangenome for Sha (Sha_graph), a graph pangenome for the Asian subpopulation (Asia_graph), and the graph pangenome for the full 1001 genomes (1001G_graph). The sets of genetic variants used to construct the Sha_graph, Asia_graph, and 1001G_graph graph‐based pangenomes are shown in Figure 3A. Using Flux simulator (v. 1.2.1), we simulated reads for 15 RNA‐seq data sets, each containing 1 million 100‐bp reads (Figure 3B). We aligned these simulated reads to Sha_linear to obtain ground truth alignments, against which we tested the performance of Col0_linear and the three graph‐based pangenomes Sha_graph, Asia_graph, and 1001G_graph. The Asia_graph‐ and 1001G_graph graph‐based pangenomes achieved comparable overall and unique alignment rates, and consistently outperformed Sha_graph and Col0_linear in terms of overall alignment rates, unique mapping rates, and F1 scores (Figure 3C). The Asia_graph and 1001G_graph graph‐based pangenomes also showed relatively lower M‐UM and DML mapping error rates than Sha_graph and Col0_linear (Figure 3D).

Furthermore, the rates of Unique to MultiMapper (U‐MM) mapping errors were lower when mapping reads to the Asia_graph graph‐based pangenome than when mapping to the 1001G_graph graph‐based pangenome (Figure 3D). While mapping the simulated RNA‐seq reads to other subpopulation‐level graph pangenomes (Table S3), we noticed that all graph pangenomes substantially outperformed Col0_linear in terms of unique alignment rates (Figure 3E) and F1 scores (Figure 3F), even when using graph‐based pangenomes that did not include variations from Sha. Notably, mapping reads to subpopulation‐level graph pangenomes effectively mitigated the issue of incorrect multiple alignments that arose from redundant variation information in the more complex 1001G_graph graph‐based pangenome (Figure 3G). Figure 3H illustrates one representative example involving a difficult read that differs from the Col0_linear reference sequence at six nucleotides over the interval 22,609,171–22,609,270 bp on chromosome 1. This region carries six SNPs between Col‐0 and Sha, precluding the alignment of reads derived from this region when using the Col0_linear genome. By contrast, graph pangenomes successfully aligned the same read by using the additional variation paths that they contained: The Asia_graph and 1001G_graph graph‐based pangenomes comprised one graph path and three graph paths for this region, respectively. Crucially, only Asia_graph correctly assigned the Sha‐specific read as a uniquely mapping read, whereas it was mapped three times when using 1001G_graph as the reference, demonstrating the ability of this subpopulation‐level graph pangenome to reduce erroneous multiple alignments that arise from redundant variation information contained in 1001G_graph.

Simulation experiments performed on five additional Arabidopsis accessions (An‐1, Cvi‐0, Ler, Eringsboda [Eri‐1], and Coimbra [C24]) consistently demonstrated the superiority of graph pangenomes over the Col0_linear genome when mapping reads (Figure S6). We further examined alignment performance at the population scale using 1,050 real Arabidopsis RNA‐seq data sets (Table S4), randomly subsampling 100,000 reads from each data set. Subpopulation‐level graph pangenomes consistently achieved high rankings in unique alignment rates, whereas Col0_linear achieved the lowest ranking in the overall alignment rate for 1,042 out of 1,050 data sets (or 99.24% of total) (Figure 4A, B). The pattern remained similar when the analysis was scaled from 100,000 reads to the full data sets (Figure 4C, D). These results collectively indicate that mapping RNA‐seq reads to subpopulation‐level graph pangenomes represents an effective strategy for population‐level RNA‐seq analysis, at least in Arabidopsis.

Graph pangenomes support the analysis of population‐scale RNA‐seq data from rice and maize

To assess the broader applicability of PanGraphRNA, we evaluated its performance on RNA‐seq data sets from the rice accession Minghui 63 (NCBI accession no. PRJNA940508; Zhu et al., 2024) and 13 maize accessions (NCBI accession no. PRJEB67964; Torres‐Rodríguez et al., 2024). We aligned the reads from these data sets to graph pangenomes for each species at different resolutions: for rice, at the single‐accession level (MingHui63_graph), subpopulation level (Indica_II_graph), and population level (RiceVarMap2_graph), and for maize, at the population level, including 510 inbred lines (510G_graph). Compared to alignments against the relevant linear reference genome (IRGSP_linear for rice and B73_linear for maize), PanGraphRNA achieved higher read alignment rates in both species (Figures S7, S8). These results are relatively consistent with the Arabidopsis results and confirm that the benefits of graph pangenome‐based alignment extend from a model plant to key crop species.

Case studies

Application of PanGraphRNA to mine RNA‐seq data for drought stress‐related genes

We exposed Arabidopsis seedlings from the Sha accession to drought stress experiment and performed RNA‐seq sequencing to evaluate the ability of graph pangenomes to identify differentially expressed genes (DEGs). Sha plants were grown under drought‐stressed (DS) and well‐watered (WW) conditions, with each RNA sample representing a pooled biological sample from three plants. It is important to note that, with only two replicates per condition, the subsequent differential expression analysis is intended for methodological assessment of linear genomes and graph‐based pangenomes rather than for drawing definitive biologically relevant conclusions. To confirm any biological insights generated from this study, additional replicates and molecular experiments will be necessary.

We aligned RNA‐seq reads and performed differential gene expression analysis using two different reference genomes: The Col0_linear genome and the Asia_graph graph‐based pangenome, as the Sha accession belongs to this subpopulation. The subpopulation‐level graph pangenome (Asia_graph) outperformed the single‐accession‐level graph pangenome (Sha_graph) (Figure 3). After mapping the reads to the Asia_graph genome, we identified 2,085 DEGs between the DS and WW samples, 106 of which were not among the DEGs when the reads were mapped to the Col0_linear genome; similarly, 86 DEGs were uniquely detected when the reads were mapped to the Col0_linear genome and were not among the DEGs when the reads were mapped to Asia_graph (Figure 5A). Notably, in all three categories (Graph‐specific, Linear‐specific, and Union DEGs), more reads were misaligned when using the linear reference than when using the graph pangenome (Figure 5B). Indeed, compared to the Col0_linear genome, the Asia_graph graph‐based pangenome achieved higher read‐mapping accuracy, particularly for Graph‐specific DEGs, suggesting that we identified these DEGs owing to improved read alignments (Figure 5B). We also examined the patterns of read mapping for Graph‐specific and Linear‐specific DEGs. For Graph‐specific DEGs, approximately 18,701 (DS) and 12,116 (WW) reads aligned exclusively to Asia_graph, whereas only about 916 and 1,011 reads uniquely mapped to Col0_linear. The vast majority of Graph‐specific reads failed to align to Col0_linear, reaching 98.95% (DS) and 98.14% (WW) mapping error rates against the Col0_linear genome, primarily owing to M‐UM errors. By contrast, Linear‐specific DEGs had far fewer specific reads in the DS and WW samples, with ~816 and ~1,089 reads, respectively, of which ~664 and ~440 failed to map to the Asia_graph graph‐based pangenome. Notably, more reads mapped to these regions when using Asia_graph (~25,909 in DS and ~17,260 in WW) with lower mapping error rates (5.04% and 3.54%) than when using Col0_linear (99.49% and 99.15%).

The differences in read alignment rates between Col0_linear and Asia_graph also led to discrepancies in the estimation of expression levels (Figure 5C, D). We identified 48 DEGs (Table S5) in Sha seedlings with an expression divergence (ED) value greater than 1, defined as ED = |TPMgraph−TPMlinear|TPMlinear+1, with TPM graph and TPM linear representing the averaged expression values estimated using Asia_graph and Col0_linear, respectively. Among the DEGs specifically identified when using Asia_graph for mapping was ETHYLENE‐RESPONSIVE FACTOR 6 (ERF6; At4g17490), which has been reported to suppress leaf growth in Arabidopsis under drought stress via a gibberellin‐DELLA‐dependent pathway (Dubois et al., 2013). This gene was not among the DEGs detected when mapping the reads to the Col0_linear genome, which lost 70.30% and 62.39% of reads in WW and DS samples, respectively. Asia_graph recovered these missing reads and correctly identified ERF6 as being differentially expressed (Figure 5E). We validated the differential expression of ERF6 under drought‐stress conditions via reverse‐transcription quantitative PCR (RT‐qPCR) (Figure 5F). Additional RT‐qPCR experiments confirmed significant expression changes in other highly divergent DEGs (with ED > 1), namely, At5g49600, At2g12190, and At1g66250 (Figure 5G–I). These results highlight the advantage of the subpopulation‐level graph pangenome in capturing stress‐related DEGs that would otherwise be overlooked when using a standard linear reference genome for mapping RNA‐seq reads.

Application of PanGraphRNA to identify flowering time‐related eQTLs

We re‐analyzed a population‐scale RNA‐seq data set from 800 Arabidopsis accessions using both Col0_linear and the biologically representative graph pangenome Iberian_graph (Alonso‐Blanco et al., 2016), the latter yielding superior read‐mapping performance (Figure S9). When we compared the alignment characteristics of RNA‐seq reads, we observed significantly greater unique mapping rates (~86.88%, D = 0.417, P‐value = 2.75 × 10−61) and overall alignment rates (~93.33%, D = 0.698, P‐value = 9.34 × 10−170) when using the graph‐based pangenome than when using Col0_linear (Figure S10). To quantify the effect of alignment bias, we assessed the number of mismatches and soft‐clipped bases within the reads uniquely mapping to Iberian_graph or Col0_linear. As shown in Figure S10 and Table S6, the graph pangenome yielded fewer reads with more mismatches or soft‐clipped bases, indicative of higher alignment precision. By contrast, alignment to the linear reference genome resulted in lower mapping rates and higher frequencies of mismatches and soft clipping, reflecting a reduced alignment quality.

To evaluate how alignment strategies affect downstream analysis, we compared the gene expression levels estimated by the two methods, using RNA‐seq data for 800 Arabidopsis accessions. On average, the expression levels of 6,405 genes showed substantial differences for each accession between the two methods, using a threshold of |ΔTPM | > 1 (Figure 6A). For instance, analysis of an RNA‐seq sample from the accession Tos‐95‐393 revealed 10,222 genes with differences in TPM values greater than 1 (Figure 6B). These differences can influence eQTL identification. Indeed, we uniquely identified over 26,000 eQTLs (13,105 cis‐eQTLs and 13,651 trans‐eQTLs) when using the graph pangenome for read alignment (Figure 6C, D). These results suggest that improved alignment accuracy can lead to a marked difference in the quantification of expression levels and that Graph‐specific eQTLs may offer new variant sites for genotype–phenotype studies.

DISCUSSION

PanGraphRNA is a unified toolkit designed to overcome the limitations of RNA‐seq analysis based on a single linear reference (SLR) genome, especially for biological samples generated from an accession for which a specific genome assembly is not available. It integrates the construction, evaluation, and application of graph pangenomes, and is openly available (GitHub/Docker) for flexible implementation. Using PanGraphRNA, we demonstrated that graph pangenomes achieved higher accuracy of read alignment than SLR genomes across multiple population scales of Arabidopsis accessions. The platform enabled robust gene expression quantification and led to the identification of new candidate genes induced by drought stress and flowering time‐related eQTLs in Arabidopsis. In addition, the user manual provides practical guidance for applying PanGraphRNA to large, polyploid, and highly heterozygous genomes. Moreover, PanGraphRNA was proven to be applicable to population‐scale RNA‐seq studies in the crop species rice and maize. These results underscore the broad applicability of PanGraphRNA, offering a practical framework for RNA‐seq analysis.

PanGraphRNA was designed as a flexible framework that supports the incorporation of different graph pangenome constructors, including but not limited to HISAT2, minigraph, minigraph‐cactus, PGGB, and vg. Performance benchmarks on RNA‐seq data sets from four Arabidopsis accessions (Figure S11; Table S8) provided guidance for this choice. Evaluation of the results showed that minigraph, minigraph‐cactus, and vg yielded higher read alignment rates than the other methods, whereas HISAT2 excelled in accuracy metrics (recall, precision, and F1 score) and computational efficiency, using only ~30% of the memory and running ~10 times faster (Tables S9, S10). For large‐scale RNA‐seq data analysis, we recommend that users jointly consider the accuracy of read alignment and computational efficiency (Tables S11, S12).

Different pangenome constructors typically use distinct graph indexing strategies, which affects read representation and downstream RNA‐seq quantification. PanGraphRNA leverages HISAT2's hierarchical graph FM index by integrating variants into compressed indexes on a linear reference. This design supports efficient alignment, consistent transcript definitions, and annotation compatibility. A key limitation, however, is that the linear backbone may limit complex structural variant representation, potentially reducing sensitivity to haplotype‐specific or structurally complex transcripts. On the other hand, graph‐based methods like vg use a Graph BWT to model haplotype paths explicitly, offering superior capture of structural variation and haplotype context. However, they could hinder cross‐sample comparability because haplotype‐specific transcripts are defined within specific path contexts (Sibbesen et al., 2023). These trade‐offs motivate the development of more sophisticated algorithms for graph indexing and graph‐aware quantification.

PanGraphRNA also supports the integration of diverse genomic variants, from SNPs and small InDels to larger structural variants (SVs) such as insertions, deletions, and inversions. We validated this capability in a preliminary test using Arabidopsis graph pangenomes (Table S13). Effectively leveraging these integrated SVs poses new challenges, including the accurate projection of graph‐based alignments onto linear reference coordinates. Improved algorithms and standardized benchmarking will be essential to enable the routine use of structural variant‐aware graph pangenomes in RNA‐seq analysis.

PanGraphRNA is worthy of further exploration. We made pre‐built graph pangenomes for three major plant species (Arabidopsis, rice, and maize) publicly available on figshare (https://figshare.com/projects/PanGraphRNA_-_Graph_pangenome_index/252995), supporting pangenome‐based analytical applications including differential expression analysis and eQTL mapping. We also encourage users to apply these graph pangenomes to other areas, such as exploring the functional diversity of gene families (Wang et al., 2026) and discovering genes of functional importance (Lin et al., 2023). Beyond bulk RNA‐seq, PanGraphRNA could be adapted for single‐cell RNA‐seq studies, as suggested by a preliminary analysis of single‐cell data for the Ws‐2 (Wassilewskija) accession (NCBI accession no. GSE198394; Oliva et al., 2022; Figures S12, S13). Quantification of expression levels using a graph pangenome was globally more consistent with the Wassilewskija linear reference genome (Lian et al., 2024) than with that for Col‐0. Although highly variable gene sets identified using graph‐based and linear Col‐0 references overlapped substantially, both differed from the set based on the Wassilewskija reference. These observations suggest that single‐cell RNA‐seq analysis with graph pangenomes is promising but may require further methodological development.

The PanGraphRNA project is ongoing, and future work should focus on extending its capabilities to a broader range of RNA‐seq data types by developing tailored analytical strategies that address current limitations. We also plan to incorporate more complex variants and improve algorithmic efficiency. In parallel, we aim to broaden the applicability of our platform to a wider range of plant species, including those with large and complex genomes. Through these developments, we expect to enable large‐scale, high‐resolution RNA‐seq analysis across diverse plant systems.

MATERIALS AND METHODS

Variation data collection and preprocessing

The chromosome‐level genome assembly and genome annotation files of A. thaliana were obtained from the links provided in Table S1. Genetic variants for a worldwide collection of 1,135 Arabidopsis accessions were downloaded from the Arabidopsis 1001 Genome Project (https://1001genomes.org/data/GMI-MPI/releases/v3.1) (Weigel and Mott, 2009). This study focused on genetic variations located within genic regions. Gene annotations for Arabidopsis were obtained from the Araport11 database (Cheng et al., 2017).

For rice, the reference genome (accession number: GCF_001433935.1) and its genome annotation file in gene transfer format (GTF) for the Nipponbare cultivar, IRGSP version 1.0 (Kawahara et al., 2013), were collected from the NCBI assembly database. Variation information data for 4,726 rice accessions were collected from the comprehensive rice genome variation database RiceVarMap V2.0 (Zhao et al., 2021).

For maize, the reference genome from the maize inbred line B73 NAM 5.0 version and its GTF genome annotation file were obtained from the NAM genome database (https://maizegdb.org/NAM_project) (Hufford et al., 2021). This study collected variation information data for 510 maize accessions originating from tropical, subtropical, and temperate zones (Yang et al., 2011; Fu et al., 2013; Wen et al., 2014; Yang et al., 2019).

bcftools was used to filter the variation information with the parameter [‐i ‘DP > 30’]. bcftools was used to extract variation information (parameter: [‐‐force‐samples]) from VCF files for specific Arabidopsis accessions. Variant calling was performed using the genome assemblies as input files with minimap2 (v. 2.24‐r1122) (Li, 2018) and paftools (v. 2.26‐r1175) (Li, 2018).

RNA‐seq data collection, preprocessing, and alignment

For single‐accession‐level graph pangenome analysis, 54 RNA‐seq data sets for the Arabidopsis accessions An‐1, Cvi‐0, Ler, and Sha were downloaded from the SRA database at NCBI (Table S2). For population‐level RNA‐seq analysis, 1,050 RNA‐seq data sets from 800 Arabidopsis accessions were retrieved from the GEO database at NCBI under the accession numbers GSE54680 (Dubin et al., 2015) and GSE80744 (Kawakatsu et al., 2016; Ferrero‐Serrano et al., 2022).

fastp (v. 0.20.0) (Chen et al., 2018) was used to remove adapters and low‐quality reads from the raw RNA‐seq data, with the parameters [‐5 ‐3 ‐r ‐‐detect_adapter_for_pe ‐‐n_base_limit 0 ‐‐average_qual 20]. seqtk (v. 1.3‐r106) (Shen et al., 2016) was used to randomly extract a subset of reads from RNA‐seq data sets of interest. HISAT2 (v. 2.2.1) (Kim et al., 2019) was used to align clean reads to different genomes, using the alignment parameters [‐‐mm ‐‐min‐intronlen 40 ‐‐max‐intronlen 2000 ‐k 20 ‐‐mp 9,3].

RNA‐seq data simulation and alignment

Genetic variants from An‐1, C24, Cvi‐0, Eri‐1, Ler, and Sha (https://1001genomes.org/data/MPIPZ/MPIPZJiao2020/releases/current/strains) (Jiao and Schneeberger, 2020) were used to construct pseudo genomes (Figure S14). Flux (v. 1.2.1) (Griebel et al., 2012) was used to generate simulated RNA‐seq data based on the pseudo genome, which was constructed by introducing the genetic variants for one accession into the Arabidopsis TAIR10 reference genome for Col‐0. The Araport11 annotation of the TAIR10 reference genome was converted into pseudo genome through coordinate transfer using the LiftOver tool of UCSC (Nassar et al., 2023). Each pseudo genome retains accession‐specific variant information while remaining anchored to the genome coordinates of the SLR, thereby avoiding potential bias introduced by coordinate transformation. Pseudo genomes were generated for the six Arabidopsis accessions An‐1, C24, Cvi‐0, Eri‐1, Ler, and Sha (Figure S14). HISAT2 was used to align RNA‐seq reads, with the same parameters as above.

Graph pangenome construction

The hisat2‐build tool in HISAT2 was used to construct graph pangenomes by adding “snp” and “haplotype” to the Arabidopsis TAIR10 reference genome. The “snp” and “haplotype” information was generated from VCF files using the hisat2_extract_snps_haplotypes_VCF.py script, with parameters [‐‐non‐rs ‐‐ inter‐gap 1024 ‐‐intra‐gap 150].

Plant growth conditions and RNA‐seq

Seeds for the Arabidopsis accession Sha (N76382) were sown in containers. For each accession, two biological replicates were set up, with seeds sown at a density of three seeds per container. The containers were transferred to a greenhouse maintained at 22°C with 16 h of light (140 μmol m−2 s−1) per day. After 3 weeks of growth, the seedlings were subjected to either well‐watered (WW) or drought stress (DS) treatment. For the WW treatment, seedlings were consistently watered to maintain the same conditions as those during the initial growth period. For the DS treatment, watering was withheld. Plant development was continuously monitored, and samples were collected after 10 days of treatment. The three plants in each container were pooled into a single sample for RNA‐seq.

Messenger RNA (mRNA) was purified from total RNA using poly‐T oligo‐attached magnetic beads. After fragmentation, first‐strand cDNA was synthesized using random hexamer primers, followed by second‐strand cDNA synthesis. RNA‐seq libraries were prepared by end repair, A‐tailing, adapter ligation, size selection, amplification, and purification. After library quality control, quantified libraries were pooled and sequenced on an Illumina instrument.

Assessment of read alignment accuracy

Basic alignment statistics

R scripts were used to extract basic alignment information for each read–genome alignment result, including the unique alignment rate and multiple alignment rate.

Measurement of mapping error rate

The R package CNEr (v. 1.28.0) (Tan et al., 2019) was used to perform whole‐genome alignments between the linear reference genomes of individual accessions and that of the accession Col‐0 (Col0_linear), generating chain files for genome coordinate transformation with the parameters (lastz(assemblyTarget, assemblyQuery, outputDir = axtDir, binary = “lastz”, chrsTarget = c(‘chr01’,‘chr02’,‘chr03’,‘chr04’,‘chr05’), chrsQuery = c(‘chr01,’‘chr02,’‘chr03,’‘chr04,’‘chr05’), distance = “near’)). The LiftOver tool of UCSC and the CrossMap (v. 0.6.4) tool (Zhao et al., 2014) were used to convert the alignment results into Col0_linear genome coordinates (Figure S15A). Finally, the alignment results for Col0_linear and graph pangenomes were compared with the ground truth (X_linear); the five error types were defined according to read alignment type and position (Figure S15B), based on the definition of Kaminow (Kaminow et al., 2022).

Normalization of gene expression and differential expression analysis

Unique mapping reads were extracted from the mapping SAM files, and featureCounts (v. 2.0.2) (Liao et al., 2014) was used to quantify read counts using the Arabidopsis Araport11 annotation files (https://www.arabidopsis.org/download/file?path=Genes/Araport11_genome_release/archived/Araport11_GTF_genes_transposons.Mar202021.gtf.gz). StringTie (v. 2.1.5) (Pertea et al., 2015) was used to quantify expression levels as TPM (transcripts per million). The R package DESeq. 2 (v. 1.34.0) (Love et al., 2014) was used to identify differentially expressed genes (DEGs) based on the criteria of P‐value < 0.05 and | Log2(fold‐change) | > 1, after removing genes with 0 read counts from the raw read count matrix.

Association analysis

The variants were filtered using bcftools with the parameters [‐‐min‐ac 60:minor ‐i ‘AN ≥ 400’] for eQTL analysis, resulting in a total of 1,880,319 SNPs and 2,381 InDels as the output. Genotype information from at least 200 accessions was retained. Subsequently, eQTL analysis was conducted using MatrixEQTL (v. 2.1.0) (Shabalin, 2012). To account for potential confounding effects of population structure, principal component analysis (PCA) was conducted on the genotype data, and the top 100 principal components were included as covariates in MatrixEQTL via the cvrt parameter.

GWAS results from 22 studies were downloaded from the AraGWAS Catalog (https://aragwas.1001genomes.org/#/top-associations), from which 89,785 significant SNPs were extracted. Using positional information of GWAS‐associated SNPs, the corresponding variants were extracted from the VCF files for 800 accessions. Subsequently, linkage disequilibrium (LD, r 2) was calculated between the GWAS loci and eQTLs using PopLDdecay (v. 3.41) (Zhang et al., 2019). eQTLs with r 2 values of 0.5 or greater were defined as GWAS‐linked eQTLs, based on the potential shared genetic architecture underlying these traits.

RT‐qPCR analysis

The cDNA sequences of method‐specific DEGs were mapped to the Sha reference genome using GMAP (v. 2020‐10‐14) (Wu and Watanabe, 2005). Candidate genes were selected for experimental validation using four criteria: DEGs specifically identified using either the graph‐based or the linear‐based approach; genes with an expression divergence (ED) value greater than 1; genes expressed as a single transcript and with one‐to‐one orthologous relationship between the Sha and Col‐0 genomes; and orthologous gene pairs with high sequence identity (> 80%) and high alignment coverage (> 80%). Finally, RT‐qPCR analysis was performed on three Sha genes. Total RNA was extracted from samples using a SteadyPure Plant RNA Extraction Kit. A 5× Evo M‐MLV RT Master Mix (Evo M‐MLV RT Premix for qPCR; Accurate Biology, China; Cat no. AG11706) was used for first‐strand cDNA synthesis according to the manufacturer's instructions. A SYBR Green Premix Pro Taq HS qPCR Kit was used for quantitative PCR (qPCR) of target genes; gene expression levels were quantified using the 2−ΔΔCT method. ACTIN 2 was used as an internal control. All data are based on three technical replicates. The primers used are listed in Table S14.
