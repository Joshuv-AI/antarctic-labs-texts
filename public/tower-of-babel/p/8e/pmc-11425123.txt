Integer PI, fractional PI and fractional PI data trained ANFIS speed controllers for indirect field oriented control of induction motor
Authors: Girma Kassa Alitasb
Published: 2024

ABSTRACT
AbstractInduction motor drives with variable speed applications that employ vector control are quite popular nowadays because they provide strong dynamic performance and flexible speed control. By decoupling the torque-producing current components of stator current from the rotor flux, Indirect Field Oriented Control is recognized for generating excellent performance in induction motor drives. This investigation is being done to show the effectiveness of the novel FPI input-output data-trained ANFIS controller and compare the three controllers' performance in terms of load variation capabilities, motor parameter variation, and speed tracking. Consequently, a comparison of the three controllers is important to select which controller performs high in induction motor drive. Indirect Field Oriented Control of induction motor with Fractional Proportional Integral (FPI), Integer Proportional Integral (IPI), and Adaptive Neuro-Fuzzy Inference System (ANFIS) controllers are all discussed in this work along with their designs and comparative analysis. The square of error was used as a fitness function to genetically optimize the FPI and IPI controller parameters. The suggested Adaptive Neuro-Fuzzy Inference System (ANFIS) controller uses a hybrid learning approach. It is trained by the FPI controller's input-output data. Using the results of MATLAB simulations under various operating situations, the performance of the ANFIS controller was compared with FPI and IPI controllers. Because of FPI controller includes an extra parameter for adjustment, namely integration order, it performed better than IPI controller for speed control of the induction motor. According to the simulation findings, the percentage peak overshoots while employing ANFIS, FPI, and IPI controllers were 0.495 %, 12.062 %, and 14.699 % respectively. As a result, ANFIS exhibits a drastic reduction in overshoot. Additionally, with the ANFIS controlled induction motor drive, the speed achieves the required set value at 0.14 s. For no load, constant, and changing loads, the induction motor drive's performance has been examined.Keywords: Induction motor, Indirect field oriented control, Fractional PI, ANFIS, Integer PI

Introduction

The most widely used method of controlling induction motors is field-oriented control. The torque formulation for the independently excited DC machine is equivalent to the torque formulation for the smooth air gap machine in the particular reference frames. A separately excited DC machine and an inverter-supplied induction motor drive have similar steady state performance in field-oriented control of induction motor. However, compared to DC machines, the dynamic performance of an induction motor with uncomplicated controls like flux and torque control and voltage/Hz control is significantly slower [1,2]. This flaw has limited the use of induction motor drives in sectors that demand high performance. Improved performance with torque and speed variation is the primary goal of field-oriented control [3,4].

Conventional control systems require a complex mathematical model of the motor to design controllers for variables like position, speed, and torque. Intelligent controllers are being created to avoid the unfavorable traits that traditional control techniques have by nature. Fuzzy Logic Controllers (FLC) map the connection between the input and output based on human understanding rather than a precise mathematical representation of the system, and they may thus manage nonlinearities that are typically challenging to predict [[5], [6], [7]]. The main problem with fuzzy controllers is that they largely rely on the expert's understanding of a number of the parameters connected to the membership functions and the rules. In addition, Artificial Neural Network (ANN) alone is insufficient if there isn't enough training data to cover all of the operational modes [[8], [9], [10]].

The drawbacks of Fuzzy Logic and Artificial Neural Network control can be resolved by employing an Adaptive Neuro-Fuzzy Inference System [11]. One of the finest trade-offs between neural and fuzzy systems is ANFIS, which offers flexibility via ANN backpropagation and smooth control via FLC interpolation. Model compactness, a reduced training set size need, and quicker convergence than traditional feed-forward ANN are some of the benefits of ANFIS [12,13]. ANFIS combines the knowledge representation capabilities of fuzzy logic with the learning capacity of neural networks [14].

In the context of a neural network, learning is the act of modifying the weights and biases so that the right outputs are obtained for a given input. In supervised learning, input-output training data is given to the network. The weights are then changed until the error between the intended and actual outputs reaches a predetermined minimal value. An Artificial Neural Network can be trained via supervised learning using the backpropagation algorithm. It optimizes using a gradient descent technique. A hybrid learning algorithm combines the least square estimator and the backpropagation algorithm. For quick parameter identification, a hybrid learning technique combines the least square estimator and the steepest descent. This is the reason this work uses a hybrid learning algorithm [15].

The concept of a derivative of non-integer (fractional) order is introduced in fractional order calculus, which provides a unique modelling strategy for systems with unusual dynamical features [16,17]. It is asserted that fractional order differential equations are more suited for describing systems seen in the actual world [18]. In control theory, it is useful to consider the design of fractional controller for system modelled with integer order [19].

There are numerous techniques to control the induction motor's speed, according to several scholars. In Ref. [20] presented fuzzy logic controller (FLC) to improve the speed control of an induction machine with the least amount of loss. They found that FLC exhibits less overshoot than PI controller, demonstrating the efficiency and dependability of FLC. Even yet, there is still room for further overshoot minimization [21]. proposed Integral plus Proportional (IP) controller to resolve the high initial speed overshoot, sensitivity to controller gains, and slow response brought on by an abrupt change in load torque [22]. suggested PI controller where the gains are adjusted using an iterative technique based on linear matrix inequality to achieve quick convergence and effective design, yet the outcome has a settling period of around 1sec [23]. presented PI controller design by separating the stator currents for an induction motor with indirect vector control. Such PI based decoupling controllers, however, are unable to deliver the desired performance with a constrained control bandwidth [24]. By Ref. [25] for the sensorless speed control of induction motor, a fractional order controller was introduced. They do not use any optimization mechanism to determine the parameters of the controller. As presented by Ref. [26] fractional order PI controllers has superior speed tracking, shorter settling times, greater disturbance rejection, and reduced speed tracking error as compared to integer order PI controllers [27]. presented a fuzzy logic controller for vector-controlled induction motor drive. In the presence of disturbances, it is observed that fuzzy logic-based speed controllers perform significantly better than PID based speed controllers for three-phase induction motors. As presented in Ref. [28] ANN controller is more robust than PI and fuzzy logic controller for Indirect Vector Controlled induction motor when load disturbances occurred with settling time of 1.4 s [29]. utilized training data from a conventional PI controller, a Neuro-Fuzzy Controller for Indirect Vector-Controlled Induction Motor Drive is described [30]. presented indirect vector-controlled induction motor drive with a modified type 2 neuro-fuzzy torque controller and they got a satisfactory result.

All in all, for monitoring the speed of induction motors, ANN, FLC, and ANFIS controllers have been extensively studied in the literature. However, nobody ever used the input and output data of a Fractional Proportional Integral (FPI) controller to train ANFIS controller. According to this study, by using the FPI controller's input-output data as training data, the ANFIS control capability can be improved. The effectiveness of ANFIS controller and FPI controller is compared to that of the traditional integer proportional integral controller (IPI). This work aims to design and provide a comparative analysis of fractional and integer order PI controllers tuned by genetic algorithm, with the purpose of controlling the speed of an indirect field-oriented controlled induction motor. Specifically, the ANFIS controller is trained using the input and output data of a genetic algorithm-tuned fractional order PI controller. Design of FPI and IPI speed controllers using genetic algorithm

The Genetic Algorithm (GA) is the most widely used optimization technique. The chromosome is the fundamental component of GA. Basic information for a specific solution is contained in the chromosome, which is commonly encoded as a binary string. At first, the population of chromosomes assembled at random represents the variety of possible answers to a particular issue. The population's top candidates are chosen using a fitness function to have offspring who will make up the following generation [39].

The fitness function must be established before the GA optimization can be put into practice. The objective function that has to be reduced is the cost function. The square of the difference between the desired and the actual output serves as the cost function in this study. In addition, the variables to be optimized are Kp and Ki for IPI speed controller and Kp, Ki and λ for FPI speed controller to guarantee the induction motor's best possible control performance. Integral Time Absolute Error (ITAE) penalizes larger errors for longer periods of time and gives emphasis on minimizing errors during the initial transient response. Applications requiring quick response and settling time can benefit from this requirement. Due to error value squaring, Integral Square Error (ISE) emphasizes reducing large errors over small errors. This criterion can lead to a quick response, but it may also require more control effort. The Integral Time Square Error (ITSE) contains elements of both ISE and ITAE, punishing larger errors during transient response. This criterion causes greater oscillatory behavior. If the application requires a quick response and settling time for control optimization, ITAE or ISE may be a better fit [40]. Design of ANFIS using FPI input-output data

The benefits of neural networks and fuzzy logic systems are combined in neuro-fuzzy systems. Fuzzy logic systems are given connectionist structure and learning capabilities by neural networks, and Fuzzy if-then rules at a high level provide a structural framework for neural networks using fuzzy logic systems. A growing trend in the control of nonlinear systems is neuro-fuzzy, which uses neural networks' learning capabilities to implement fuzzy logic inference systems [41]. ANFIS is one approach that has been suggested for integrating fuzzy logic and artificial neural networks. The structure of the Adaptive Neuro-Fuzzy Inference System is shown in Fig. 3. ANFIS is made up of five building elements with different role.

ANFIS controller structure with two inputs [42].

ANFIS is a straightforward data learning method that employs fuzzy logic to convert inputs into desired outputs. ANFIS does this by converting numerical inputs into outputs utilizing highly integrated neural network processing units and weighted information connections. ANFIS works by using neural network learning techniques to adjust a fuzzy inference system's parameter. Because it provides the needed data set, a wider range of membership functions to choose from, strong generalization capabilities, outstanding explanation capabilities through fuzzy rules, and ease of integration of both language and numerical information for problem-solving, ANFIS is very successful [43].

The specific requirement is that when Fuzzy Inference System (FIS) is launched as a controller, the membership function parameters should be refined in a way that ensures the plant will work at its best. ANFIS has speed error and rate of change of speed error as an input, and command torque as an output. The suggested controller employs a five-layer ANN structure and the Sugeno Fuzzy Model. Controllers performance under motor parameter variation

The impacts of temperature, frequency, and saturation may cause changes in the induction motor's parameters. The rotor resistance (Rr), mutual inductance (Lm), rotor self-inductance (Llr) all affect the IFOC controller's performance. Particularly, the value of the rotor resistance varies by 100 % with frequency and temperature. The flux and torque depart from the values that were established as a result. As a result of machine losses, which induce temperature variation, induction motor experiences changes in resistance. The efficiency of controllers declines when the resistance changes with temperature. The performance of controllers for IFOC control of induction motor are studied under its nominal value (Rr) and 50 % decrease,50 % increase and 100 % increase from Rr (rotor resistance) of induction motor, the results are observed in Fig. 13(a–c).

Fig. 13(a),(b) and 13(c) show the speed responses of an induction motor drive employing ANFIS, FPI and IPI controllers, respectively. Changes in controller performance measures, such as rising and settling time, steady state error, and peak overshoot of induction motor drive employing the three controllers, occur as the resistance rises from 1/2Rr to 2Rr. However, the extent of the alterations varies from controller to controller. To observe the controllers' responses and the degree of the performance criteria's numerical change, take 1.5Rr. Using IPI, FPI, and ANFIS controllers, the rising times have changed by 0.072164sec., 0.00183sec., and 0.00585sec., respectively. As compared to FPI and ANFIS controllers, the result demonstrates that IPI controller has a high rising time change. In terms of percentage overshot utilizing Rr and 1.5Rr, 2.831 % is recorded when using IPI controller, 0.032 % when using FPI controller, and 0 % when using ANFIS controller. Overall, the simulation findings indicate that IPI controller is more influenced by rotor resistance change than FPI and ANFIS controllers.

Conclusion and recommendation

Conclusion

This study compared the simulation outcomes for the induction motor drive using different controller types, such as the IPI, FPI, and ANFIS controllers. The tasks performed in this study include designing FPI and IPI controllers that are genetic algorithm optimized as well as designing an ANFIS controller that is trained using data from the genetic algorithm optimized FPI controller for IFOC control of integer order model induction motor drive. At last, a comparison of the three controllers mentioned above has been done using the outputs from MATLAB/Simulink.

The effectiveness of genetic algorithm optimized FPI controller is compared to genetic algorithm optimized IPI controller for IFOC induction motor. As compared to IPI, the robustness and tracking capability of FPI controller during steady state and rapid load fluctuations have been proven by the simulation results. This is because the FPI controller also enables to change the integration order (λ) which is absent in IPI controller. Simulation findings demonstrate that the FPI controller outperforms the IPI controller for IFOC induction motor drive with an integer order model. It was found that the speed reaches the required value rapidly, in a shorter amount of time, and with minimal overshoot when the ANFIS controller is used in the induction motor drive, as opposed to the FPI and IPI controllers. Since ANFIS exhibits high performance in reference tracking, small overshoot of 0.495 % and smooth operation at transient period, it is suitable for loads which needs high reference tracking accuracy at steady state and smooth operation at transient period like electric vehicles. All in all, the proposed ANFIS controller outperformed the fixed parameter FPI and IPI controllers in terms of capability.

Recommendation

ANFIS cannot identify which kind of membership function is appropriate for the presented data, even though it does reduce undesirable trial and error in finding parameters of membership functions. As a result, more research is required to establish the kind of membership function used by the ANFIS controller. Furthermore, in this work the parameters of current controllers for direct and quadrature axis components are tuned manually using the trial and error method, other researchers can determine the parameters of current controllers using optimization techniques for further investigation.
