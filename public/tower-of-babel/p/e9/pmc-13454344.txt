Echo state network-based model reference adaptive predefined time control for magnetic levitation linear synchronous motor
Authors: Yunpeng Sun, Wanning Bai, Zelai Xu, Anying Chai, Haoluan Li, Jiarun Wang
Published: 2026

ABSTRACT
AbstractTo enhance the transient performance and robustness of a magnetic levitation linear synchronous motor, this paper proposes an echo state network (ESN)-based model reference adaptive predefined-time control. The proposed preset time speed error reference model enables users to define the decay rate of the tracking error and the convergence time required for the speed error to reach zero. The ESN is employed to compensate for mismatched unknown disturbances, and to expedite the convergence of the ESN, a predefined-time adaptation law is designed. By integrating predefined-time stability theory with model reference adaptive control, a model reference adaptive predefined-time speed tracking controller is developed, where the convergence time is determined by a single tunable parameter and independent of the initial conditions of the system state. Theoretical analysis demonstrates that the error between the actual tracking error and the reference model output converges to a neighborhood around the origin within the predefined time. Finally, simulation results validate the efficacy and superiority of the proposed controller in achieving robust and fast transient performance.Subject terms: Engineering, Mathematics and computing

Introduction

Linear motors directly convert electrical energy into linear motion, eliminating the need for intermediate mechanical transmission mechanisms compared to rotary motors. This characteristic enables linear motors to achieve high reliability and long service life, making them widely applicable in industrial productio1–3. However, the control accuracy of linear motors is highly susceptible to external disturbances. Therefore, suitable control methods are needed, such as active disturbance rejection control (ADRC)4, sliding mode control (SMC)5, neural network-based control (NNC)6.

Neural networks have emerged as a powerful tool for approximating complex nonlinear functions, enabling effective mitigation of disturbance impacts on motor control systems7. Reference8 proposed a neural network adaptive robust control scheme using multilayer neural networks to estimate unknown nonlinear functions. Reference9 proposes a model-free optimal control scheme based on policy iteration for the Two-Wheeled Inverted Pendulum system, verifying the effectiveness and distinct performance characteristics of On-policy and Off-policy Q-learning algorithms in achieving self-balancing stability and robustness. Reference10 investigates the tracking control problem for discrete-time systems with external disturbances, proposing model-free On-policy and Off-policy Q-learning algorithms within a zero-sum game framework to verify their convergence and effectiveness in robust tracking through modified output optimal control. Reference11 proposes a prescribed-time distributed Model Reference Adaptive Control strategy for nonlinear multi-agent systems with unknown disturbances, which integrates a prescribed-time observer, Closed-loop Reference Model (CRM), and event-triggered mechanism. Reference12 addresses the leader-following formation control problem by proposing a hierarchical distributed control framework based on actor-critic reinforcement learning. Reference13 proposes a novel multivariate nonlinear adaptive control strategy (H-MRAC) based on Hyper-stability Theory for induction motors with parameter uncertainties. Reference14 proposes a novel finite-time neural adaptive nonlinear 3D sliding pursuit guidance law for fixed-wing combat UAVs, which integrates SMC with neural networks and Total Least Squares Estimation (TLSE) to address parameter uncertainties. Reference15 proposes a robust neural adaptive control strategy for bipedal walking robots by integrating nonlinear dynamic inversion with RBF neural networks. Reference16 introduced a B-Spline wavelet neural network adaptive control method, leveraging gradient descent algorithms to approximate system uncertainties. Radial basis function neural networks (RBFNNs) have also been widely used, such as in Reference17, where RBFNNs were employed to compensate for unmodeled load disturbances in adaptive backstepping control. Similarly, Reference18 utilized RBFNNs to address modeling errors and uncertain disturbances, thereby improving tracking performance and anti-interference capabilities. Elman neural networks have been applied to reduce chattering in sliding mode control by estimating system uncertainties19. Reference20 proposed a self-evolving probabilistic fuzzy neural network for intelligent tracking control, effectively handling system uncertainties. Additionally, Reference21 introduced an intelligent second-order sliding mode control method using a recurrent radial basis function neural network (RRBFNN) to estimate unknown terms and enhance system robustness. Unlike static Feedforward Neural Networks (FNNs), which rely exclusively on instantaneous inputs and lack the inherent memory to model temporal dynamics, Recurrent Radial Basis Function Neural Networks (RRBFNNs) introduce a feedback mechanism that reintegrates the lagged output into the hidden layer. This architecture endows the network with superior local approximation capabilities and the ability to capture nonlinear dynamic mappings. While conventional FNNs fail to utilize internal state information for weight updates, Recurrent Neural Networks (RNNs) fundamentally address this limitation through internal feedback loops. These loops allow RNNs to store historical information and model the dynamic response of a system without relying on delayed external feedback, thereby demonstrating robust control performance even in the presence of uncertainties. However, the substantial computational burden associated with training conventional RNNs poses a significant challenge. To resolve this trade-off between dynamic modeling capacity and training efficiency, Echo State Networks (ESNs)-a prominent paradigm of reservoir computing—have emerged. By fixing the input and internal reservoir weights, ESNs circumvent the complexity of gradient-based training, offering a computationally efficient alternative for processing complex time-series data. This makes ESNs particularly effective as function approximators in anti-disturbance control applications22,23. However, existing NNC often neglect the transient performance of the system.

Model reference adaptive control (MRAC) provides a framework to predetermine transient performance by designing a reference model that describes the desired dynamic response of the system. MRAC typically consists of a reference model, a controller, and an adaptive law. The adaptive law adjusts controller parameters to minimize the discrepancy between the plant output and the reference model output, thereby enhancing system dynamic performance. Reference24 proposed a neural network-based model reference adaptive control, using a first-order linear model as a reference model to set the expected speed dynamic response. Reference25 designed a reference model to improve the dynamic performance of the system, and at the same time used an adaptive Hermite fuzzy neural network that can adjust the weights online to estimate the system’s lumped uncertainty. Reference26 proposed a reference model that makes the speed error decay exponentially. However, the adaptive law-based disturbance rejection mechanism requires a large adaptive gain to achieve the anti-disturbance effect, which will generate high-frequency control signals and even make the system unstable27. Reference28 proposed a super-twisting sliding-mode observer-based model reference adaptive controller. The super-twisting sliding-mode observer can converge to the disturbance in a finite time and improve the robustness of the system. To improve the transient response of the MRAC, reference29 proposed closed-loop reference models. Reference30 used a proportional-integral (PI) compensator in the feedback loop of the closed loop MRAC architecture to improve its robustness. However, the above control methods can only achieve the asymptotic convergence of the tracking error. To address this limitation, finite-time and fixed-time MRAC methods have been proposed. Reference31 introduced a finite-time MRAC scheme to accelerate tracking error convergence, though the convergence time remains dependent on initial conditions. Reference32 proposed a fixed-time adaptive model reference sliding mode control, which combines sliding mode control with MRAC, and the convergence time is independent of the initial conditions. Although finite-time and fixed-time control strategies have improved convergence rates, they face inherent limitations. Finite-time convergence relies heavily on initial system states, making the settling time unpredictable in the presence of large fluctuations. Fixed-time control addresses this by bounding the settling time, but the relationship between the convergence time and controller parameters is often complex and conservative. In contrast, predefined-time control offers a distinct advantage by allowing the settling time to be an explicit, user-defined parameter in the control law, independent of initial condition33,34. This characteristic is particularly critical for MLLSM applications requiring precise temporal synchronization. Therefore, it is necessary to combine the predefined-time control with MRAC to improve the speed of the actual output of the system converging to the output of the reference model.

Inspired by the above references, the goal of this paper is to propose an echo state network-based model reference adaptive predefined-time control (ESNMRAPTC) for magnetic levitation linear synchronous motor (MLLSM) to improve the transient performance and robustness. Operation mechanism and mathematical model of MLLSM

Operation mechanism of MLLSM

The structure of MLLSM is shown in Fig. 1. The DC current flows into the excitation winding and generates a constant excitation magnetic field in the air gap. The mover core will be attracted vertically upward under the action of magnetic field. When the electromagnetic force is equal to the gravity of the feed platform, stable suspension can be achieved. The three-phase symmetrical alternating current in the armature winding will generate a sinusoidal traveling wave magnetic field in the air gap. The interaction between traveling wave magnetic field and excitation magnetic field will produce electromagnetic thrust to promote the horizontal operation of the platform.

Remark 1

As a type of RNN, compared with the FNN, the ESN can utilize historical input information for dynamic estimation, demonstrating stronger short-term memory capabilities. In comparison to other RNNs, the ESN has distinct advantages in online learning and approximating nonlinear functions. This is because it does not require adjusting the weights between the input layer and the hidden layer, and the connection weights of the reservoir network remain unchanged during the training phase. Consequently, the ESN is more suitable for use in the speed control of the MLLSM where online estimation of unknown disturbances is required.

Remark 4

To achieve optimal control performance, the following guidelines for selecting the control parameters are recommended in practical applications:

Predefined time constant : determines the convergence speed. It is recommended to start with a relatively conservative (larger) value to prevent initial control voltage saturation. Then, progressively decrease to accelerate the transient response until the physical capability limit of the actuator is reached or high-frequency chattering begins to appear.

Adaptive gain scaling factor h: This parameter balances estimation accuracy against noise sensitivity. One should initially set h to a moderate value. If singularity issues or chattering are observed near the equilibrium point, χ should be slightly increased, bearing in mind that this will marginally expand the final residual set.

Remark 5

By adaptively adjusting only the gain, the network’s ability to fine-tune the direction of the compensation vector is limited. This may result in a slightly larger residual tracking error compared to a fully adaptive network. However, its advantage lies in guaranteeing global stability and achieving a faster convergence rate.

Remark 6

To avoid the ’explosion of complexity’ and the amplification of measurement noise caused by direct analytical differentiation, a linear tracking differentiator is employed to obtain the smooth estimate of . The proposed singularity-avoidance function ensures that the term is replaced by a smooth function. Consequently, the derived control laws and are continuous everywhere within the operation domain.

Remark 7

References42,43 employed the ESN for online estimation of unknown disturbances. Weight adaptation in standard neural network control requires updating an matrix. The adaptive law only needs to update a single scalar parameter . Moreover, by introducing the predefined-time stability theory into the design of the adaptive law, the convergence rate of parameter estimation is effectively improved.

Remark 8

The proposed ESNMRAPTC method significantly reduces computational complexity compared to traditional neural network-based strategies by utilizing an Echo State Network (ESN) with fixed input and internal reservoir weights, thereby circumventing intensive gradient-based training. Furthermore, instead of requiring online updates for full N × N weight matrices, the predefined-time adaptive law updates only a single scalar parameter. This drastic reduction in computational overhead not only ensures high efficiency and easy deployment on standard embedded processors to strictly satisfy the real-time execution requirements of the MLLSM control loop, but also endows the method with excellent scalability. Consequently, this lightweight computational advantage makes the approach highly suitable for future extensions into complex high-order systems and multi-axis control scenarios.

Remark 9

Recent research has been conducted on predefined-time or predefined-performance control for nonlinear systems, including backstepping-based designs and other time-constrained tracking frameworks. For example, Reference44 proposes a learning-based predefined-performance control strategy constructed within the backstepping framework, while Reference45 presents a predefined-time tracking scheme for underwater robots. Compared with the aforementioned studies, the proposed ESNMRAPTC method exhibits three structural features that are particularly suitable for MLLSM control. First, a linear tracking differentiator is introduced to avoid repeated analytical differentiation of virtual control signals, thereby alleviating the explosion-of-complexity issue commonly encountered in recursive designs. Second, a smooth singularity-avoidance term is incorporated into the virtual control law, and the boundedness of the closed-loop signals and actual control inputs is established in the stability analysis, which improves implementability. Third, the ESN is used to approximate mismatched disturbances online, so the method combines explicit predefined-time tracking performance with disturbance-learning capability. Therefore, the main advantage of the proposed framework lies not in a general claim of superiority over all existing predefined-time methods, but in the integration of predefined-time convergence, disturbance estimation, and reduced online implementation burden within a unified MLLSM-oriented control structure.

Conclusion

For the motor control system, in order to improve its transient performance and robustness, this paper proposes a predefined-time controller based on the ESN. A predefined-time speed-error reference model is established, enabling the tracking error to converge to zero at a specified convergence rate within a preset time. The ESN is utilized to estimate external disturbances, thereby enhancing the robustness. Quadratic functions are formulated with embedded singularity avoidance mechanisms in the virtual control design. An adaptive law and a controller are designed to improve the response speed. At the same time, the singularity problem of the virtual control law is avoided. Rigorous theoretical analysis indicates that the tracking error can converge to a neighborhood around zero within the predefined time. Comparative simulation results fully demonstrate the effectiveness and superiority of the proposed controller. Future work will focus on developing an anti-windup predefined-time control law that accounts for input saturation, as well as applying this control strategy to high-order and multi-axis systems.
