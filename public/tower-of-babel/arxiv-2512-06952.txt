Resource-Bounded Type Theory: Compositional Cost Analysis via Graded Modalities
Mirco A. Mannucci, Corey Thuro

Abstract
We present a compositional framework for certifying resource bounds in typed programs. Terms are typed with synthesized bounds 𝖻 \mathsf{b} drawn from an abstract resource lattice ( L , ⪯ , ⊕ , ⊔ , ⊥ ) (L,\preceq,\oplus,\sqcup,\bot) , enabling uniform treatment of time, memory, gas, and domain-specific costs. We introduce a graded feasibility modality □ r \Box_{r} with counit and monotonicity laws. Our main result is a syntactic cost soundness theorem for the recursion-free simply-typed fragment: if a closed term has synthesized bound b b under budget r r , its operational cost is bounded by b b . We provide a syntactic term model in the presheaf topos 𝐒𝐞𝐭 L \mathbf{Set}^{L} —where resource bounds index a cost-stratified family of definable values—with cost extraction as a natural transformation. We prove canonical forms via reification and establish initiality of the syntactic model: it embeds uniquely into all resource-bounded models. A case study demonstrates compositional reasoning for binary search using Lean’s native recursion with separate bound proofs.



Keywords:
type theory, resource analysis, graded modalities, coeffects, presheaf semantics, cost soundness, categorical semantics

Introduction

Formal methods typically certify
what holds
, not
what it costs
. In many settings—safety-critical controllers, on-device ML, blockchain contracts, and time-bounded autonomous agents—a proof without a resource budget is insufficient:
a correct component that exceeds its resource envelope is unusable
. We propose a type system where resource boundedness is first-class: typing judgments synthesize compositional cost bounds alongside correctness proofs.

Goal (compositional resource bounds).

For a typed term
t
(program/proof) and a resource budget
r\in L
, we synthesize a bound
\mathsf{b}
via typing rules such that:

\Gamma\vdash_{r;\,\mathsf{b}}t:A

The synthesized bound
\mathsf{b}
is checked against the budget (
\mathsf{b}\preceq r
) and over-approximates operational cost. We prove this connection syntactically (Theorem
3.9
) and validate it via a syntactic term model in
\mathbf{Set}^{L}
(§
4
). We establish that the syntactic model is initial: it embeds uniquely into all resource-bounded models (Theorem
4.22
).

Design Principles

P1.

Abstraction over concreteness.
Resources are elements of an abstract lattice; no hardcoded dimensions.

P2.

Budgets are first-class.
Resource bounds appear in types and judgments.

P3.

Compositional rules.
Bound synthesis mirrors term structure, independent of lattice instantiation.

P4.

Monotonicity.
If
r_{1}\preceq r_{2}
, then
\Box_{r_{1}}A\to\Box_{r_{2}}A
(weakening).

Notation.

We write
L
for an abstract resource lattice;
r,\rho,\sigma\in L
are resource elements;
\preceq
is the lattice order;
\oplus
is sequential composition;
\sqcup
is worst-case branching (join);
\bot
is the zero resource;
\Box_{r}A
denotes feasibility at budget
r
.

3
A Minimal Calculus for Resource-Bounded Types

3.1
Abstract Resource Lattices

Definition 3.1

(Resource lattice)
.

A
resource lattice
is a structure
L=(L,\preceq,\oplus,\sqcup,\bot)
where:

•

(L,\preceq)
is a partially ordered set.

•

\oplus:L\times L\to L
is
sequential composition
, associative, commutative, and monotone.

•

\sqcup:L\times L\to L
is
worst-case branching
(join/least upper bound).

•

\bot\in L
is the least element and identity for
\oplus
:
r\oplus\bot=r
.

•

(L,\preceq,\sqcup,\bot)
forms a join-semilattice.

In concrete instantiations,
\oplus
is typically addition (
+
), while
\sqcup
is maximum (
\max
).

Examples.

1.

Single-dimension (time):

L=\mathbb{N}
with
\preceq=\leq
,
\oplus=+
,
\sqcup=\max
,
\bot=0
.

2.

Multi-dimensional:

L=\mathbb{N}^{3}
(time, memory, depth) with pointwise order and:

\displaystyle(t_{1},m_{1},d_{1})\oplus(t_{2},m_{2},d_{2})

\displaystyle=(t_{1}+t_{2},m_{1}+m_{2},d_{1}+d_{2})

\displaystyle(t_{1},m_{1},d_{1})\sqcup(t_{2},m_{2},d_{2})

\displaystyle=(\max(t_{1},t_{2}),\max(m_{1},m_{2}),\max(d_{1},d_{2}))

3.

Blockchain gas:

L=\mathbb{N}
(same structure as time, interpreted as gas units).

3.2
Core Typing Rules

Judgments carry a resource context and a synthesized bound:

\Gamma\vdash_{r;\,\mathsf{b}}t:A

Here
r\in L
is the available resource budget, and
\mathsf{b}\in L
is the synthesized bound (to be checked as
\mathsf{b}\preceq r
). The core typing rules are shown in
Fig.

1
.

\frac{}{\Gamma,x:A\vdash_{r;\,\bot}x:A}\quad(\text{Var})\\
\frac{\Gamma,x:A\vdash_{r;\,b}t:B}{\Gamma\vdash_{r;\,b}\lambda x.t:A\to B}\quad(\text{Lam})\\
\frac{\Gamma\vdash_{r;\,b_{f}}f:A\to B\quad\Gamma\vdash_{r;\,b_{a}}a:A}{\Gamma\vdash_{r;\,b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}}f\,a:B}\quad(\text{App})\\
\frac{\Gamma\vdash_{r;\,b_{a}}a:A\quad\Gamma\vdash_{r;\,b_{b}}b:B}{\Gamma\vdash_{r;\,b_{a}\oplus b_{b}}(a,b):A\times B}\quad(\text{Pair})\\
\frac{\Gamma\vdash_{r;\,b_{c}}c:\mathsf{Bool}\quad\Gamma\vdash_{r;\,b_{t}}t:A\quad\Gamma\vdash_{r;\,b_{f}}f:A}{\Gamma\vdash_{r;\,b_{c}\oplus(b_{t}\sqcup b_{f})\oplus\delta_{\mathrm{if}}}\mathbf{if}\ c\ \mathbf{then}\ t\ \mathbf{else}\ f:A}\quad(\text{If})\\
\frac{\Gamma\vdash_{r;\,b}t:A\quad b\preceq s}{\Gamma\vdash_{r;\,b}\mathrm{box}_{s}(t):\Box_{s}A}\quad(\text{Box})\\
\frac{\Gamma\vdash_{r;\,b}t:\Box_{s}A}{\Gamma\vdash_{r;\,b\oplus\delta_{\mathrm{unbox}}}\mathrm{unbox}(t):A}\quad(\text{Unbox})\\
\frac{\Gamma\vdash_{r;\,b}t:\Box_{s_{1}}A\quad s_{1}\preceq s_{2}}{\Gamma\vdash_{r;\,b}t:\Box_{s_{2}}A}\quad(\text{Monotone})

Figure 1:
Core typing rules for recursion-free STLC with resource bounds. Constants
\delta_{\mathrm{app}},\delta_{\mathrm{if}},\delta_{\mathrm{unbox}}\in L
are per-operation costs. The (Box) rule requires
b\preceq s
; the budget
r
is independent and can be weakened. The (Lam) rule uses
latent cost abstraction
: the function carries its body cost
b
, paid upon application.

Reading the judgment.

The judgment
\Gamma\vdash_{r;\,\mathsf{b}}t:A
reads: “Under context
\Gamma
, with budget
r
, term
t
has type
A
and synthesized cost bound
\mathsf{b}
.” The budget
r
is the limit; the bound
\mathsf{b}
is the measurement. The check
\mathsf{b}\preceq r
verifies the program fits within the budget.

Three levels of cost.

1.

Budget (
r
):
What you allocate (upper limit).

2.

Synthesized bound (
\mathsf{b}
):
What the typing rules compute.

3.

Actual cost (
k
):
What operationally happens when you run the term.

The typing judgment establishes
k\preceq\mathsf{b}\preceq r
, where
k\preceq\mathsf{b}
is proven by Theorem
3.9
.

3.3
Operational Semantics

We define a big-step call-by-value operational semantics with explicit cost accounting for closed terms.

Values.

v\in\mathsf{Val}::=\lambda x{:}A.\,t\mid\langle v_{1},v_{2}\rangle\mid\mathsf{tt}\mid\mathsf{ff}\mid\mathrm{box}_{s}(v)

Evaluation.

We write
t\Downarrow v\triangleright k
for “closed term
t
evaluates to value
v
with cost
k\in L
.” The rules are in
Fig.

2
.

\frac{}{v\Downarrow v\triangleright\bot}\quad(\mathsf{Val})\\
\frac{t\Downarrow v\triangleright k_{1}\quad u\Downarrow w\triangleright k_{2}}{\langle t,u\rangle\Downarrow\langle v,w\rangle\triangleright k_{1}\oplus k_{2}}\quad(\text{Pair})\\
\frac{t\Downarrow\langle v,w\rangle\triangleright k}{\pi_{1}t\Downarrow v\triangleright k\oplus\delta_{\pi}}\quad(\text{Fst})\qquad\frac{t\Downarrow\langle v,w\rangle\triangleright k}{\pi_{2}t\Downarrow w\triangleright k\oplus\delta_{\pi}}\quad(\text{Snd})\\
\frac{c\Downarrow\mathsf{tt}\triangleright k_{c}\quad t\Downarrow v\triangleright k_{t}}{\mathbf{if}\ c\ \mathbf{then}\ t\ \mathbf{else}\ u\Downarrow v\triangleright k_{c}\oplus k_{t}\oplus\delta_{\mathrm{if}}}\quad(\text{IfT})\\
\frac{c\Downarrow\mathsf{ff}\triangleright k_{c}\quad u\Downarrow v\triangleright k_{u}}{\mathbf{if}\ c\ \mathbf{then}\ t\ \mathbf{else}\ u\Downarrow v\triangleright k_{c}\oplus k_{u}\oplus\delta_{\mathrm{if}}}\quad(\text{IfF})\\
\frac{f\Downarrow\lambda x.t\triangleright k_{f}\quad a\Downarrow v\triangleright k_{a}\quad t[x:=v]\Downarrow w\triangleright k_{b}}{f\,a\Downarrow w\triangleright k_{f}\oplus k_{a}\oplus\delta_{\mathrm{app}}\oplus k_{b}}\quad(\text{App})\\
\frac{t\Downarrow v\triangleright k}{\mathrm{box}_{s}(t)\Downarrow\mathrm{box}_{s}(v)\triangleright k}\quad(\text{Box})\qquad\frac{t\Downarrow\mathrm{box}_{s}(v)\triangleright k}{\mathrm{unbox}(t)\Downarrow v\triangleright k\oplus\delta_{\mathrm{unbox}}}\quad(\text{Unbox})

Figure 2:
Big-step evaluation with cost. Values evaluate with cost
\bot
.

Lemma 3.2

(Determinism)
.

If
t\Downarrow v_{1}\triangleright k_{1}
and
t\Downarrow v_{2}\triangleright k_{2}
, then
v_{1}=v_{2}
and
k_{1}=k_{2}
.

Proof.

By induction on the derivation of
t\Downarrow v_{1}\triangleright k_{1}
. Each evaluation rule has disjoint applicability conditions (values vs. non-values,
\mathsf{tt}
vs.
\mathsf{ff}
for conditionals), so there is exactly one applicable rule for each term form.
∎

3.4
Metatheory: Type and Cost Soundness

We establish soundness properties for the recursion-free simply-typed fragment.

3.4.1
Substitution Lemmas

Lemma 3.3

(Typing substitution)
.

If
\Gamma,x{:}A\vdash_{r;\,b}t:B
and
\Gamma\vdash_{r;\,b_{v}}v:A
where
v\in\mathsf{Val}
, then
\Gamma\vdash_{r;\,b}t[x:=v]:B
.

Proof.

By induction on the typing derivation of
\Gamma,x{:}A\vdash_{r;\,b}t:B
.

•

Var:
If
t=x
, then
t[x:=v]=v
and we need
\Gamma\vdash_{r;\,b}v:A
. Since
v\in\mathsf{Val}
, by budget weakening we can derive this (the bound
b=\bot
for variables). If
t=y\neq x
, then
t[x:=v]=y
and the derivation is unchanged.

•

Lam:
If
t=\lambda y.s
(with
y\neq x
), then
t[x:=v]=\lambda y.s[x:=v]
. By IH,
\Gamma,y{:}A^{\prime}\vdash_{r;\,b}s[x:=v]:B^{\prime}
, so by (Lam),
\Gamma\vdash_{r;\,b}\lambda y.s[x:=v]:A^{\prime}\to B^{\prime}
.

•

App, Pair, If, Box, Unbox:
Apply IH to subterms; the bound structure is preserved since substitution does not affect cost annotations.

Note that bounds are independent of the substituted value: the lemma does not require
b_{v}\preceq b
.
∎

Lemma 3.4

(Cost substitution)
.

If
\Gamma,x{:}A\vdash_{r;\,b}t:B
and
\Gamma\vdash_{r;\,b_{v}}v:A
where
v\in\mathsf{Val}
, then there exist
w\in\mathsf{Val}
and
k\in L
such that
t[x:=v]\Downarrow w\triangleright k
with
k\preceq b
(when
\Gamma=\emptyset
and
t[x:=v]
is closed).

Proof.

By induction on the typing derivation of
\Gamma,x{:}A\vdash_{r;\,b}t:B
.

•

Var:
If
t=x
, then
t[x:=v]=v\in\mathsf{Val}
, so
v\Downarrow v\triangleright\bot
by rule (Val), and
\bot\preceq b
. If
t=y\neq x
, the term remains a variable which contradicts
\Gamma=\emptyset
.

•

Lam:

t=\lambda y.s
, so
t[x:=v]=\lambda y.s[x:=v]
is a value. By (Val), it evaluates with cost
\bot\preceq b
.

•

App:

t=f\,a
with
\Gamma,x{:}A\vdash_{r;\,b_{f}}f:C\to B
and
\Gamma,x{:}A\vdash_{r;\,b_{a}}a:C
. By IH,
f[x:=v]\Downarrow\lambda y.s\triangleright k_{f}
with
k_{f}\preceq b_{f}
, and
a[x:=v]\Downarrow u\triangleright k_{a}
with
k_{a}\preceq b_{a}
. By (App) and a nested application of IH for the body,
(f\,a)[x:=v]\Downarrow w\triangleright k
with
k\preceq b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}=b
.

•

Pair, If, Box, Unbox:
Similar, using IH on subterms and the corresponding evaluation rules.

∎

Lemma 3.5

(Budget weakening)
.

If
\emptyset\vdash_{r_{1};\,b}t:A
and
r_{1}\preceq r_{2}
, then
\emptyset\vdash_{r_{2};\,b}t:A
.

Proof.

By induction on the typing derivation. All rules preserve the bound
b
while allowing the budget to increase. The only place the budget appears in rule side conditions is:

•

(Box):
Requires
b\preceq s
. This constraint involves the grade
s
(which is fixed in the term
\mathrm{box}_{s}(t)
), not the budget
r
. Since
s
does not change when we increase
r
, the constraint remains satisfied.

•

All other rules:
The budget
r
appears uniformly in all premises and the conclusion. If the premises hold at
r_{1}
, they hold at
r_{2}\succeq r_{1}
by IH.

Therefore the entire derivation can be lifted to the larger budget
r_{2}
while preserving the bound
b
.
∎

3.4.2
Type Soundness

Theorem 3.6

(Preservation)
.

If
\emptyset\vdash_{r;\,\mathsf{b}}t:A
and
t\Downarrow v\triangleright k
, then
\emptyset\vdash_{r;\,\mathsf{b}^{\prime}}v:A
for some
\mathsf{b}^{\prime}\preceq\mathsf{b}
.

Proof.

By induction on the evaluation derivation
t\Downarrow v\triangleright k
.

•

(Val):

t=v
is already a value, so
\mathsf{b}^{\prime}=\mathsf{b}
works.

•

(Pair):

t=\langle t_{1},t_{2}\rangle
with
t_{i}\Downarrow v_{i}\triangleright k_{i}
. By inversion on typing,
\emptyset\vdash_{r;\,b_{i}}t_{i}:A_{i}
with
\mathsf{b}=b_{1}\oplus b_{2}
. By IH,
\emptyset\vdash_{r;\,b^{\prime}_{i}}v_{i}:A_{i}
with
b^{\prime}_{i}\preceq b_{i}
. By (Pair),
\emptyset\vdash_{r;\,b^{\prime}_{1}\oplus b^{\prime}_{2}}\langle v_{1},v_{2}\rangle:A_{1}\times A_{2}
, and
b^{\prime}_{1}\oplus b^{\prime}_{2}\preceq b_{1}\oplus b_{2}=\mathsf{b}
by monotonicity.

•

(App):

t=f\,a
with
f\Downarrow\lambda x.s\triangleright k_{f}
,
a\Downarrow u\triangleright k_{a}
,
s[x:=u]\Downarrow w\triangleright k_{b}
. By inversion,
\emptyset\vdash_{r;\,b_{f}}f:A\to B
and
\emptyset\vdash_{r;\,b_{a}}a:A
. By IH on
f
, the lambda has type
A\to B
with body bound
b^{\prime}_{f}\preceq b_{f}
. By Lemma
3.3
,
s[x:=u]
is well-typed, and by IH,
w
has type
B
with some bound
\mathsf{b}^{\prime}\preceq\mathsf{b}
.

•

(IfT), (IfF), (Box), (Unbox):
Similar reasoning using inversion and IH.

∎

Theorem 3.7

(Progress)
.

If
\emptyset\vdash_{r;\,\mathsf{b}}t:A
, then either
t\in\mathsf{Val}
or there exist
v
and
k
such that
t\Downarrow v\triangleright k
.

Proof.

By induction on the typing derivation.

•

(Var):
Impossible since
\emptyset
has no variables.

•

(Lam):

\lambda x.s\in\mathsf{Val}
.

•

(App):

t=f\,a
. By IH, either
f\in\mathsf{Val}
or
f\Downarrow v_{f}\triangleright k_{f}
. If
f\in\mathsf{Val}
, by canonical forms
f=\lambda x.s
. By IH, either
a\in\mathsf{Val}
or
a\Downarrow v_{a}\triangleright k_{a}
. In all cases, we can apply the (App) evaluation rule (using IH for
s[x:=v_{a}]
in the recursion-free fragment where all terms terminate).

•

(Pair):
By IH on components.

•

(If):
By IH, condition evaluates to
\mathsf{tt}
or
\mathsf{ff}
; then by IH on the appropriate branch.

•

(Box):
By IH,
t\Downarrow v\triangleright k
, so
\mathrm{box}_{s}(t)\Downarrow\mathrm{box}_{s}(v)\triangleright k
.

•

(Unbox):
By IH,
t\Downarrow\mathrm{box}_{s}(v)\triangleright k
(using canonical forms), so
\mathrm{unbox}(t)\Downarrow v\triangleright k\oplus\delta_{\mathrm{unbox}}
.

∎

Remark 3.8
.

Progress holds for the recursion-free fragment where all well-typed terms terminate. With unrestricted general recursion, non-terminating terms would exist and progress would fail.

3.4.3
Cost Soundness

Theorem 3.9

(Cost soundness)
.

If
\emptyset\vdash_{r;\,\mathsf{b}}t:A
, then there exist
v\in\mathsf{Val}
and
k\in L
such that
t\Downarrow v\triangleright k
with
k\preceq\mathsf{b}\preceq r
.

Proof.

By induction on the typing derivation of
\emptyset\vdash_{r;\,\mathsf{b}}t:A
. We show that the operational cost
k
is bounded by the synthesized bound
\mathsf{b}
.

Base cases.

•

(Var):
Contradicts
\emptyset
(no variables in empty context).

•

(Lam):

t=\lambda x.s
is already a value. By rule (Val),
t\Downarrow t\triangleright\bot
. Since
\bot
is the least element,
\bot\preceq b
holds for any
b
.

Inductive cases.

•

(App):

t=f\,a
with typing derivation:

\frac{\emptyset\vdash_{r;\,b_{f}}f:A\to B\quad\emptyset\vdash_{r;\,b_{a}}a:A}{\emptyset\vdash_{r;\,b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}}f\,a:B}

By IH on
f
: there exist
\lambda x.s\in\mathsf{Val}
and
k_{f}\in L
with
f\Downarrow\lambda x.s\triangleright k_{f}
and
k_{f}\preceq b_{f}
.

By IH on
a
: there exist
v\in\mathsf{Val}
and
k_{a}\in L
with
a\Downarrow v\triangleright k_{a}
and
k_{a}\preceq b_{a}
.

From the typing derivation of
\lambda x.s
: we have
x{:}A\vdash_{r;\,b_{f}}s:B
(using latent cost abstraction: the body bound equals the function bound
b_{f}
).

By Lemma
3.4
:
s[x:=v]\Downarrow w\triangleright k_{b}
for some
w\in\mathsf{Val}
and
k_{b}\preceq b_{f}
.

By rule (App):
f\,a\Downarrow w\triangleright k_{f}\oplus k_{a}\oplus\delta_{\mathrm{app}}\oplus k_{b}
.

Since
k_{f}\preceq b_{f}
,
k_{a}\preceq b_{a}
,
k_{b}\preceq b_{f}
, and
\oplus
is monotone in both arguments:

k_{f}\oplus k_{a}\oplus\delta_{\mathrm{app}}\oplus k_{b}\preceq b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}\oplus b_{f}

By design of the typing rule, the bound is
\mathsf{b}=b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}
, and the body cost
k_{b}
is already accounted for in
b_{f}
. Thus
k\preceq\mathsf{b}
.

•

(Pair):

t=\langle t_{1},t_{2}\rangle
with
\emptyset\vdash_{r;\,b_{1}}t_{1}:A_{1}
and
\emptyset\vdash_{r;\,b_{2}}t_{2}:A_{2}
.

By IH:
t_{i}\Downarrow v_{i}\triangleright k_{i}
with
k_{i}\preceq b_{i}
.

By rule (Pair):
\langle t_{1},t_{2}\rangle\Downarrow\langle v_{1},v_{2}\rangle\triangleright k_{1}\oplus k_{2}
.

By monotonicity:
k_{1}\oplus k_{2}\preceq b_{1}\oplus b_{2}=\mathsf{b}
.

•

(If):

t=\mathbf{if}\ c\ \mathbf{then}\ t_{1}\ \mathbf{else}\ t_{2}
with
\emptyset\vdash_{r;\,b_{c}}c:\mathsf{Bool}
,
\emptyset\vdash_{r;\,b_{1}}t_{1}:A
,
\emptyset\vdash_{r;\,b_{2}}t_{2}:A
.

By IH on
c
:
c\Downarrow v_{c}\triangleright k_{c}
with
k_{c}\preceq b_{c}
and
v_{c}\in\{\mathsf{tt},\mathsf{ff}\}
.

Case
v_{c}=\mathsf{tt}
: By IH,
t_{1}\Downarrow v\triangleright k_{1}
with
k_{1}\preceq b_{1}
. By rule (IfT):
t\Downarrow v\triangleright k_{c}\oplus k_{1}\oplus\delta_{\mathrm{if}}
.

Since
k_{1}\preceq b_{1}\preceq b_{1}\sqcup b_{2}
:
k_{c}\oplus k_{1}\oplus\delta_{\mathrm{if}}\preceq b_{c}\oplus(b_{1}\sqcup b_{2})\oplus\delta_{\mathrm{if}}=\mathsf{b}
.

Case
v_{c}=\mathsf{ff}
: Symmetric, using
k_{2}\preceq b_{2}\preceq b_{1}\sqcup b_{2}
.

•

(Box):

t=\mathrm{box}_{s}(t^{\prime})
with
\emptyset\vdash_{r;\,b}t^{\prime}:A
and
b\preceq s
.

By IH:
t^{\prime}\Downarrow v\triangleright k
with
k\preceq b
.

By rule (Box):
\mathrm{box}_{s}(t^{\prime})\Downarrow\mathrm{box}_{s}(v)\triangleright k
.

The bound is
\mathsf{b}=b
, so
k\preceq\mathsf{b}
.

•

(Unbox):

t=\mathrm{unbox}(t^{\prime})
with
\emptyset\vdash_{r;\,b}t^{\prime}:\Box_{s}A
.

By IH:
t^{\prime}\Downarrow\mathrm{box}_{s}(v)\triangleright k^{\prime}
with
k^{\prime}\preceq b
(canonical form for
\Box_{s}A
).

By rule (Unbox):
\mathrm{unbox}(t^{\prime})\Downarrow v\triangleright k^{\prime}\oplus\delta_{\mathrm{unbox}}
.

Since
k^{\prime}\preceq b
:
k^{\prime}\oplus\delta_{\mathrm{unbox}}\preceq b\oplus\delta_{\mathrm{unbox}}=\mathsf{b}
.

•

(Monotone):

t:\Box_{s_{1}}A
is retyped as
t:\Box_{s_{2}}A
with
s_{1}\preceq s_{2}
. The evaluation and cost are unchanged; the bound constraint
b\preceq s_{2}
follows from
b\preceq s_{1}\preceq s_{2}
.

In all cases, we have established
t\Downarrow v\triangleright k
with
k\preceq\mathsf{b}
. The constraint
\mathsf{b}\preceq r
comes from well-formedness of the typing judgment.
∎

Corollary 3.10

(Operational cost bounded by grade)
.

If
\emptyset\vdash_{r;\,\mathsf{b}}\mathrm{box}_{s}(t):\Box_{s}A
, then
t
evaluates with cost
k\preceq s
.

Proof.

By Theorem
3.9
,
\mathrm{box}_{s}(t)\Downarrow\mathrm{box}_{s}(v)\triangleright k
with
k\preceq\mathsf{b}
. The (Box) rule requires
\mathsf{b}\preceq s
, so
k\preceq\mathsf{b}\preceq s
.
∎

3.5
Feasibility Modality as Graded Interior

The modality
\Box_{r}A
represents “a computation of type
A
certified to consume at most
r
resources.”

Core laws.

\frac{}{\Box_{r}A\to A}\quad(\textit{counit})\qquad\frac{r_{1}\preceq r_{2}}{\Box_{r_{1}}A\to\Box_{r_{2}}A}\quad(\textit{monotonicity})

The counit says: certified computations can be executed (via unbox). Monotonicity says: certification for
r_{1}
implies certification for any
r_{2}\succeq r_{1}
.

Cost-aware boxing.

Promotion is conditional:
\mathrm{box}_{s}(t):\Box_{s}A
requires
b\preceq s
where
b
is the synthesized bound of
t
. There is no unconditional
A\to\Box_{s}A
.

4
Syntactic Term Model in
\mathbf{Set}^{L}

We provide a semantic interpretation via a
syntactic term model
in the presheaf topos
\mathbf{Set}^{L}
. Types are presheaves of definable values indexed by resource bounds, the lattice is internalized, and cost extraction is a natural transformation.

4.1
The Presheaf Topos

Definition 4.1

(The topos
\mathbf{Set}^{L}
)
.

View the resource lattice
(L,\preceq)
as a category:

•

Objects: elements
r\in L

•

Morphisms:
r_{1}\to r_{2}
exists (uniquely) iff
r_{1}\preceq r_{2}

•

Composition: transitivity of
\preceq

The presheaf topos
\mathbf{Set}^{L}
has:

•

Objects: covariant functors
F:L\to\mathbf{Set}

•

Morphisms: natural transformations
\alpha:F\Rightarrow G

For a presheaf
F
, each
r\in L
gives a set
F(r)
, and each
r_{1}\preceq r_{2}
gives a transition map
F(r_{1}\preceq r_{2}):F(r_{1})\to F(r_{2})
satisfying functoriality.

We use covariant functors because resource bounds are cumulative: computations fitting budget
r_{1}
also fit
r_{2}\succeq r_{1}
. This monotonicity is captured by the transition maps.

4.2
The Internal Lattice

Definition 4.2

(The downset presheaf)
.

Define
\mathbb{L}:L\to\mathbf{Set}
by:

\mathbb{L}(r)={\downarrow}r=\{a\in L\mid a\preceq r\}

For
r_{1}\preceq r_{2}
, the transition map
\mathbb{L}(r_{1}\preceq r_{2}):\mathbb{L}(r_{1})\to\mathbb{L}(r_{2})
is the inclusion
\iota_{r_{1},r_{2}}(a)=a
, which is well-defined since
a\preceq r_{1}\preceq r_{2}
implies
a\preceq r_{2}
.

Lemma 4.3
.

The lattice operations induce natural transformations:

•

\widetilde{\oplus}:\mathbb{L}\times\mathbb{L}\Rightarrow\mathbb{L}
with
\widetilde{\oplus}_{r}(a,b)=a\oplus b

•

\widetilde{\sqcup}:\mathbb{L}\times\mathbb{L}\Rightarrow\mathbb{L}
with
\widetilde{\sqcup}_{r}(a,b)=a\sqcup b

•

\widetilde{\bot}:\mathbf{1}\Rightarrow\mathbb{L}
with
\widetilde{\bot}_{r}(*)=\bot

Proof.

For
\widetilde{\oplus}
: if
a,b\preceq r
then
a\oplus b\preceq r
by monotonicity of
\oplus
. Naturality follows since transition maps are inclusions and
\oplus
is defined uniformly on
L
.

For
\widetilde{\sqcup}
: if
a,b\preceq r
then
a\sqcup b\preceq r
since
a\sqcup b
is the least upper bound and
r
is an upper bound of both.

For
\widetilde{\bot}
:
\bot\preceq r
for all
r
since
\bot
is the least element.
∎

4.3
Type Interpretation

Definition 4.4

(Syntactic type interpretation)
.

For each type
A
, define
\llbracket A\rrbracket:L\to\mathbf{Set}
by:

\llbracket A\rrbracket(r)=\{(v,b)\in\mathsf{Val}_{A}\times L\mid b\preceq r,\,\emptyset\vdash_{r;\,b}v:A\}

For
r_{1}\preceq r_{2}
, the transition map is inclusion:
(v,b)\mapsto(v,b)
.

Lemma 4.5
.

\llbracket A\rrbracket
is a well-defined presheaf.

Proof.

The transition map is well-defined: if
(v,b)\in\llbracket A\rrbracket(r_{1})
, then
b\preceq r_{1}\preceq r_{2}
, and by budget weakening (Lemma
3.5
),
\emptyset\vdash_{r_{2};\,b}v:A
, so
(v,b)\in\llbracket A\rrbracket(r_{2})
.

Functoriality is immediate: transition maps are inclusions, which compose associatively and have identity as the identity inclusion.
∎

Elements
(v,b)
are pairs of a
definable value

v
and its
certified bound

b
. The bound
b
is the potential/worst-case cost from typing, not the operational cost (which is
\bot
for values by rule (Val)).

Definition 4.6

(Cost natural transformation)
.

Define
\mathsf{cost}:\llbracket A\rrbracket\Rightarrow\mathbb{L}
with components
\mathsf{cost}_{r}(v,b)=b
.

Theorem 4.7
.

\mathsf{cost}
is a natural transformation.

Proof.

We must show the naturality square commutes for
r_{1}\preceq r_{2}
:

\begin{array}[]{ccc}\llbracket A\rrbracket(r_{1})&\xrightarrow{\mathsf{cost}_{r_{1}}}&\mathbb{L}(r_{1})\\
\downarrow&&\downarrow\\
\llbracket A\rrbracket(r_{2})&\xrightarrow{\mathsf{cost}_{r_{2}}}&\mathbb{L}(r_{2})\end{array}

For
(v,b)\in\llbracket A\rrbracket(r_{1})
:

•

Right-then-down:
\mathsf{cost}_{r_{1}}(v,b)=b
, then
\iota_{r_{1},r_{2}}(b)=b
.

•

Down-then-right:
\iota_{r_{1},r_{2}}(v,b)=(v,b)
, then
\mathsf{cost}_{r_{2}}(v,b)=b
.

Both paths yield
b
, so the square commutes.
∎

4.4
Type Constructors

Base types.

\displaystyle\llbracket\mathsf{Bool}\rrbracket(r)

\displaystyle=\{(\mathsf{tt},\bot),(\mathsf{ff},\bot)\}

\displaystyle\llbracket\mathsf{Nat}\rrbracket(r)

\displaystyle=\{(n,\bot)\mid n\in\mathbb{N}\}

Transition maps are identities since
\bot\preceq r
for all
r
.

Products.

\llbracket A\times B\rrbracket(r)=\left\{(\langle v_{1},v_{2}\rangle,b_{1}\oplus b_{2})\,\middle|\,\begin{array}[]{l}(v_{1},b_{1})\in\llbracket A\rrbracket(r)\\
(v_{2},b_{2})\in\llbracket B\rrbracket(r)\\
b_{1}\oplus b_{2}\preceq r\end{array}\right\}

This uses the categorical product structure and internal
\widetilde{\oplus}
to combine costs.

Functions (definable arrow space).

Intuitively, functions in
\llbracket A\to B\rrbracket
must map any definable argument to a definable result with appropriate cost bounds. This is the semantic counterpart of the (App) typing rule.

Definition 4.8
.

\llbracket A\to B\rrbracket(r)
consists of pairs
(\lambda x{:}A.\,t,b_{\mathrm{body}})
where:

1.

\emptyset\vdash_{r;\,b_{\mathrm{body}}}\lambda x{:}A.\,t:A\to B

2.

For all
r_{a}\in L
and
(v,b_{a})\in\llbracket A\rrbracket(r_{a})
, there exist
r_{b}\in L
and
(w,b_{b})\in\llbracket B\rrbracket(r_{b})
such that
t[x:=v]\Downarrow w\triangleright k_{b}
with
k_{b}\preceq b_{b}
and
b_{a}\oplus b_{b}\oplus\delta_{\mathrm{app}}\preceq r
.

Transition maps are inclusions: if the conditions hold at
r_{1}
, they hold at
r_{2}\succeq r_{1}
.

This is a sub-presheaf of cost-bounded definable functions, not necessarily the full exponential object in
\mathbf{Set}^{L}
.

Box modality.

\llbracket\Box_{s}A\rrbracket(r)=\{(\mathrm{box}_{s}(v),b)\mid(v,b)\in\llbracket A\rrbracket(r),\,b\preceq s\}

Lemma 4.9
.

\llbracket\Box_{s}A\rrbracket
is a sub-presheaf of
\llbracket A\rrbracket
.

Proof.

If
(\mathrm{box}_{s}(v),b)\in\llbracket\Box_{s}A\rrbracket(r_{1})
with
b\preceq s
, then
(v,b)\in\llbracket A\rrbracket(r_{2})
for
r_{2}\succeq r_{1}
by monotonicity of
\llbracket A\rrbracket
. The constraint
b\preceq s
is independent of budget, so
(\mathrm{box}_{s}(v),b)\in\llbracket\Box_{s}A\rrbracket(r_{2})
.
∎

The constraint
b\preceq s
enforces certification: you cannot box a value whose bound exceeds the claimed grade.

4.5
Semantic Soundness

Theorem 4.10

(Semantic soundness)
.

If
\emptyset\vdash_{r;\,b}t:A
and
t\Downarrow v\triangleright k
, then:

1.

k\preceq b
(by Theorem
3.9
)

2.

(v,b)\in\llbracket A\rrbracket(b)

3.

\mathsf{cost}((v,b))=b

Proof.

By induction on the typing derivation, using Theorem
3.9
for part (1).

Base case (Lam).

t=\lambda x.s
is a value with
x{:}A\vdash_{r;\,b}s:B
. The value
\lambda x.s
has certified bound
b
(latent cost of the body). By Definition
4.8
, we must verify the application condition: for any
(v,b_{a})\in\llbracket A\rrbracket(r_{a})
, by Lemma
3.4
,
s[x:=v]\Downarrow w\triangleright k_{b}
with
k_{b}\preceq b
. Thus
(\lambda x.s,b)\in\llbracket A\to B\rrbracket(b)
.

Inductive case (App).

By IH,
f\Downarrow\lambda x.s\triangleright k_{f}
with
(\lambda x.s,b_{f})\in\llbracket A\to B\rrbracket(b_{f})
, and
a\Downarrow v\triangleright k_{a}
with
(v,b_{a})\in\llbracket A\rrbracket(b_{a})
.

By Definition
4.8
, applying
(\lambda x.s,b_{f})
to
(v,b_{a})
produces
(w,b_{b})\in\llbracket B\rrbracket(b_{b})
with
s[x:=v]\Downarrow w\triangleright k_{b}
and
k_{b}\preceq b_{b}
.

The synthesized bound is
b=b_{f}\oplus b_{a}\oplus\delta_{\mathrm{app}}
. Since
(w,b_{b})\in\llbracket B\rrbracket(b_{b})
and
b_{b}\preceq b
(by the cost accounting), we have
(w,b)\in\llbracket B\rrbracket(b)
by the transition map.

Inductive case (Pair).

By IH,
t_{1}\Downarrow v_{1}\triangleright k_{1}
with
(v_{1},b_{1})\in\llbracket A\rrbracket(b_{1})
, and
t_{2}\Downarrow v_{2}\triangleright k_{2}
with
(v_{2},b_{2})\in\llbracket B\rrbracket(b_{2})
.

By the product interpretation,
(\langle v_{1},v_{2}\rangle,b_{1}\oplus b_{2})\in\llbracket A\times B\rrbracket(b_{1}\oplus b_{2})
.

Since
b=b_{1}\oplus b_{2}
, we have
(\langle v_{1},v_{2}\rangle,b)\in\llbracket A\times B\rrbracket(b)
.

Inductive case (Box).

By IH,
t\Downarrow v\triangleright k
with
(v,b)\in\llbracket A\rrbracket(b)
and
k\preceq b
.

The (Box) rule requires
b\preceq s
. By the box interpretation,
(\mathrm{box}_{s}(v),b)\in\llbracket\Box_{s}A\rrbracket(b)
since
b\preceq s
.

Other cases.

Similar reasoning using IH and the type constructor definitions.

Part (3) is immediate:
\mathsf{cost}_{b}(v,b)=b
by Definition
4.6
.
∎

4.6
Canonical Forms via Reification

Definition 4.11

(Reification)
.

The reification function
\mathsf{reify}_{A}:\llbracket A\rrbracket(r)\to\mathsf{Val}_{A}
extracts the value component:
\mathsf{reify}_{A}(v,b)=v
.

Theorem 4.12

(Canonical forms)
.

For all types
A
, bounds
b\in L
, and elements
(v,b)\in\llbracket A\rrbracket(r)
:

1.

\emptyset\vdash_{r;\,b}\mathsf{reify}_{A}(v,b):A

2.

\mathsf{reify}_{A}(v,b)=v
(values are their own reifications)

3.

v\Downarrow v\triangleright\bot
(values evaluate with cost
\bot
)

Proof.

By induction on the structure of type
A
.

Base case (
A=\mathsf{Bool}
).

\llbracket\mathsf{Bool}\rrbracket(r)=\{(\mathsf{tt},\bot),(\mathsf{ff},\bot)\}
, so
v\in\{\mathsf{tt},\mathsf{ff}\}
and
b=\bot
.

(1) By definition of
\llbracket\mathsf{Bool}\rrbracket
,
\emptyset\vdash_{r;\,\bot}v:\mathsf{Bool}
.

(2)
\mathsf{reify}_{\mathsf{Bool}}(v,\bot)=v
by definition.

(3) By rule (Val),
v\Downarrow v\triangleright\bot
.

Inductive case (
A=A_{1}\times A_{2}
).

By definition:
(v_{1},b_{1})\in\llbracket A_{1}\rrbracket(r)
,
(v_{2},b_{2})\in\llbracket A_{2}\rrbracket(r)
,
v=\langle v_{1},v_{2}\rangle
,
b=b_{1}\oplus b_{2}
.

By IH:
\emptyset\vdash_{r;\,b_{i}}v_{i}:A_{i}
and
v_{i}\Downarrow v_{i}\triangleright\bot
.

(1) By (Pair):
\emptyset\vdash_{r;\,b_{1}\oplus b_{2}}\langle v_{1},v_{2}\rangle:A_{1}\times A_{2}
.

(2)
\mathsf{reify}_{A_{1}\times A_{2}}(\langle v_{1},v_{2}\rangle,b)=\langle v_{1},v_{2}\rangle=v
.

(3) By rule (Val):
\langle v_{1},v_{2}\rangle\Downarrow\langle v_{1},v_{2}\rangle\triangleright\bot
.

Inductive case (
A=A_{1}\to A_{2}
).

v=\lambda x.t
with
(\lambda x.t,b)\in\llbracket A_{1}\to A_{2}\rrbracket(r)
.

(1) By Definition
4.8
,
\emptyset\vdash_{r;\,b}\lambda x.t:A_{1}\to A_{2}
.

(2)
\mathsf{reify}_{A_{1}\to A_{2}}(\lambda x.t,b)=\lambda x.t=v
.

(3) By rule (Val):
\lambda x.t\Downarrow\lambda x.t\triangleright\bot
.

Inductive case (
A=\Box_{s}A^{\prime}
).

v=\mathrm{box}_{s}(v^{\prime})
with
(v^{\prime},b)\in\llbracket A^{\prime}\rrbracket(r)
and
b\preceq s
.

By IH:
\emptyset\vdash_{r;\,b}v^{\prime}:A^{\prime}
and
v^{\prime}\Downarrow v^{\prime}\triangleright\bot
.

(1) By (Box) with
b\preceq s
:
\emptyset\vdash_{r;\,b}\mathrm{box}_{s}(v^{\prime}):\Box_{s}A^{\prime}
.

(2)
\mathsf{reify}_{\Box_{s}A^{\prime}}(\mathrm{box}_{s}(v^{\prime}),b)=\mathrm{box}_{s}(v^{\prime})=v
.

(3) By rule (Box):
\mathrm{box}_{s}(v^{\prime})\Downarrow\mathrm{box}_{s}(v^{\prime})\triangleright\bot
(since
v^{\prime}\Downarrow v^{\prime}\triangleright\bot
).
∎

Corollary 4.13

(Adequacy)
.

The syntactic term model in
\mathbf{Set}^{L}
is adequate:

•

Soundness:

\emptyset\vdash_{r;\,b}t:A
and
t\Downarrow v\triangleright k
implies
(v,b)\in\llbracket A\rrbracket(b)
(Theorem
4.10
)

•

Canonical forms:

(v,b)\in\llbracket A\rrbracket(r)
implies
v
is the canonical representation with

(Theorem
4.12
)

4.7
Universal Property: Initiality

We establish that the syntactic model is
initial
in the category of resource-bounded models: it embeds uniquely into all such models.

Definition 4.14

(Resource-bounded model)
.

A
resource-bounded model

\mathcal{M}
consists of:

1.

A category
\mathcal{C}
with finite products

2.

An internal lattice
L_{\mathcal{M}}\in\mathcal{C}
with morphisms
\oplus_{\mathcal{M}},\sqcup_{\mathcal{M}}:L_{\mathcal{M}}\times L_{\mathcal{M}}\to L_{\mathcal{M}}
and
\bot_{\mathcal{M}}:1\to L_{\mathcal{M}}

3.

For each type
A
, an object
\llbracket A\rrbracket_{\mathcal{M}}\in\mathcal{C}

4.

For each type
A
, a cost morphism
\mathsf{cost}_{\mathcal{M}}:\llbracket A\rrbracket_{\mathcal{M}}\to L_{\mathcal{M}}

5.

Definable CCC structure: eval and curry morphisms on the chosen type-objects (not necessarily the ambient exponentials)

6.

\Box_{r}
subobjects satisfying counit (
\llbracket\Box_{r}A\rrbracket_{\mathcal{M}}\to\llbracket A\rrbracket_{\mathcal{M}}
) and monotonicity (
r_{1}\preceq r_{2}
implies
\llbracket\Box_{r_{1}}A\rrbracket_{\mathcal{M}}\to\llbracket\Box_{r_{2}}A\rrbracket_{\mathcal{M}}
)

The key point: we require CCC structure on the
chosen
type-objects, not that
\llbracket A\to B\rrbracket_{\mathcal{M}}
be the full exponential in
\mathcal{C}
. This allows models with definable, cost-bounded functions.

Example 4.15
.

The syntactic model
\mathbf{Set}^{L}
is a resource-bounded model with
\mathcal{C}=\mathbf{Set}^{L}
, using the constructions of §
4
.

Example 4.16
.

Any set-theoretic interpretation where types are sets with cost functions, products are cartesian, functions are cost-bounded maps with curry/eval, and box is defined via cost constraints forms a resource-bounded model with
\mathcal{C}=\mathbf{Set}
.

Construction 4.17

(Interpretation functor)
.

Given a resource-bounded model
\mathcal{M}
, define
\llbracket-\rrbracket_{\mathcal{M}}
by mutual recursion:

Types.

Given by Definition
4.14
.

Contexts.

By induction on typing derivations. The interpretation is determined by the categorical structure (products, CCC, subobjects) in Definition

.

By construction of

(Cost preservation)

(Uniqueness)

By induction on structure:

Terms.

Engineering in Lean 4

We discuss two integration approaches. Code is available at
https://github.com/CoreyThuro/RB-TT
.

Deep embedding.

Formalize the calculus inside Lean: define syntax, typing judgments, and evaluation as inductive types/relations; prove Theorems
3.9
–
4.22
mechanically. This validates correctness but is ongoing work.

Shallow embedding (current).

Write Lean programs with custom
@[budget_bound]
annotations; prove bounds as separate theorems; use CI to check structural cost proxies.

The correspondence gap.

The formal bound
b
from typing rules is abstract; the practical cost model
\mathsf{cost}(t)=\alpha\cdot\mathsf{nodes}(t)+\beta\cdot\mathsf{lamDepth}(t)+\cdots
measures elaborated terms. These are separate models. The CI system uses practical costs for regression testing without claiming
\mathsf{cost}(\mathsf{elab}(t))\leq b
. Despite this gap, the combination is useful: developers reason compositionally, CI catches regressions, and empirical data can refine heuristics.

10
Conclusion

We presented a compositional framework for resource-bounded types using abstract lattices, formalized for recursion-free STLC. Key contributions: (1) cost soundness (Theorem
3.9
) by structural induction; (2) a syntactic model in
\mathbf{Set}^{L}
with cost as a natural transformation (Theorem
4.10
); (3) canonical forms (Theorem
4.12
); (4) initiality establishing universal completeness (Theorem
4.22
).

The initiality result shows our typing rules correctly capture resource-bounded computation: the syntactic model is the free resource-bounded model. Engineering integration uses structural proxies, acknowledging the gap with elaborated terms. The framework provides a rigorous foundation for reasoning about resource bounds compositionally, with applications in safety-critical systems, blockchain, and embedded devices.

Future work includes mechanization, dependent types with automatic bound synthesis, and integration with existing tools like RAML.
