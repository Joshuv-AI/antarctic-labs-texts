Fast Ramsey Quantifier Elimination in LIRA (with applications to liveness checking)
Kilian Lichtner, Pascal Bergsträßer, Moses Ganardi, Anthony W. Lin, Georg Zetzsche

Abstract
Ramsey quantifiers have recently been proposed as a unified framework for handling properties of interests in program verification involving proofs in the form of infinite cliques, which are not expressible in first-order logic. Among others, these include liveness verification and monadic decomposability. We present the tool REAL, which implements an efficient elimination of Ramsey quantifiers in existential linear arithmetic theories over integers (LIA), reals (LRA), and the mixed case (LIRA). The tool supports a convenient input format, which is an extension of SMT-LIB over the aforementioned theories with Ramsey quantifiers. We also demonstrate a substantial speedup from the original prototype. As an application, we provide an automatic translation from FASTer (a tool for verifying reachability over infinite-state systems) output format to our extension of SMT-LIB and show how our tool extends FASTer to liveness checking.



1
Introduction

Satisfiability Modulo Theories (SMT) (cf.
[
6
]
) is a highly successful
automated
reasoning framework that is based on first-order theorem proving. In particular,
building on the success of propositional SAT-solvers, SMT-solvers support
numerous first-order theories including linear arithmetics, array
theory, string theory, bitvector theory, and Equality logic with Uninterpreted
Functions (EUF), to name a few. The SMT framework is also suitable for reasoning
about programs with respect to safety properties, e.g., using Constraint Horn
Clauses
[
9
,
5
]
. Proving liveness (e.g. termination), however,
typically requires an extension of the SMT framework with reasoning about
well-foundedness, which is not first-order definable even with the help of
recursive predicates (equivalently, second-order quantifiers).

In recent years, Ramsey quantifiers have been proposed

[
4
,
3
]
as a uniform framework for handling
properties of interests in program verification involving infinite

cliques
. These include, among others, liveness
[
12
,
13
,
3
]
and
monadic decomposability
[
14
]
. In essence, we extend an SMT with formulas of the form

\psi(\vec{z}):=\exists^{\text{ram}}\vec{x},\vec{y}\colon\varphi(\vec{x},\vec{y},\vec{z})

(1)

with
|\vec{x}|=|\vec{y}|
and with the semantics that it is true under the
valuation
\vec{z}\mapsto\vec{c}
iff the graph
\varphi(\vec{x},\vec{y},\vec{c})

has an infinite directed clique, i.e., there is
an infinite sequence
\vec{a}_{1},\vec{a}_{2},\dots
of pairwise distinct vectors
such that
\varphi(\vec{a}_{i},\vec{a}_{j},\vec{c})
holds for all
1\leq i<j
.
To see how Ramsey quantifiers can be used to encode liveness properties, assume
that
R\subseteq\mathbb{R}^{k}\times\mathbb{R}^{k}
is the reachability relation
(i.e. transitive closure) of some transition relation
T\subseteq\mathbb{R}^{k}\times\mathbb{R}^{k}
. Then
T
terminates iff both

\exists\vec{z}\colon Start(\vec{z})\wedge\exists^{\text{ram}}\vec{x},\vec{y}\colon R(\vec{z},\vec{x})\wedge R(\vec{x},\vec{y})
and

\exists\vec{x},\vec{y}\colon Start(\vec{x})\wedge R(\vec{x},\vec{y})\wedge R(\vec{y},\vec{y})

are not satisfied.

It was shown in
[
4
]
that Ramsey
quantifiers can be eliminated in polynomial time for the existential fragments
of LIA (Linear Integer Arithmetic), LRA (Linear
Real Arithmetic) and LIRA (Linear Integer Real Arithmetic). Despite this, only a
very prototypical implementation of the algorithms

[
4
]
exists for LIA and LRA, and
no implementation so far exists for LIRA. In particular, scalability test was
done only on a small micro-benchmark. Furthermore, the current implementation
depends very much on the Z3 Python API, and the user cannot
simply specify the constraint in an SMT-LIB-like format, which can be reduced to
any SMT-solver.

Contributions.

In this paper, we present REAL — Ramsey Elimination for Arithmetic Logic — a solver-agnostic elimination procedure for Ramsey quantifiers. REAL allows constraints to be specified in an extension of SMT-LIB with Ramsey quantifiers and significantly improves elimination speeds. REAL also improves on resulting formula sizes and solving times (see
Fig.

4
and
Appendix

0.D
). Finally, REAL outputs the resulting formula as an SMT-LIB file, which can then be solved by any SMT solver supporting LIA, LRA or LIRA.

To demonstrate efficacy of the tool, we apply REAL to liveness verification.

2.1
Alchemist

Alchemist
is a transpiler for the output of FASTer,
which is a subset of Armoise, to SMT-LIB. We refer to
Appendix

0.F
for an Armoise example and its transpiled version. The main challenge in the translation comes from affine linear transformations.
Let
S
be a set of vectors, then Armoise is able to express affine linear transformations

S^{\prime}:=s\cdot S+\vec{c}
, where
s
is an arbitrary integer constant and
\vec{c}
a constant vector. Meaning
S^{\prime}
represents the set
\{s\cdot\vec{v}+\vec{c}|\vec{v}\in S\}
.
We can express this in LIA using existential quantifiers. To see this, let
\varphi_{S}
be the already translated formula testing set membership in
S
, then set membership of
S^{\prime}
can be tested in LIA using
\varphi_{S^{\prime}}(\vec{x}):=\exists\vec{y}\colon\vec{x}=s\cdot\vec{y}+\vec{c}\land\varphi_{S}(\vec{y})
, where the existential quantifier can subsequently be eliminated, this however requires the inling of definitions, leading to a blowup in formula sizes. It then remains to translate all set based operators to their logical counterpart and to inline/translate the LIA formulas in the guards of set comprehensions.

2.2
REAL

The algorithm presented in
[
4
]
takes a formula
\psi
as in
Eq.

1
,
where
\varphi
is an existential formula in LIRA, and
computes a formula equivalent to
\psi
that only contains existential quantifiers, i.e.,
where the Ramsey quantifier is eliminated.
To this end, the existentially quantified variables in
\varphi
are first replaced with additional Ramsey quantified variables.
Then
[
4
]
identifies sufficient and necessary conditions
that can be formulated in existential LIRA for the existence of an infinite clique.
For example, let

\varphi(\vec{x},\vec{y},z):=y_{1}>x_{1}\wedge x_{1}+x_{2}<z

be a formula in LIA.
One can observe that
\exists^{\text{ram}}\vec{x},\vec{y}\colon\varphi(\vec{x},\vec{y},z)
is equivalent to
the existence of a sequence
\vec{a},\vec{a}+\vec{b},\vec{a}+2\vec{b},\dots
such that

a_{1}+a_{2}<z
,
b_{1}>0
, and
b_{1}+b_{2}\leq 0
,
which can be stated by the existential LIA formula

\exists\vec{x},\vec{y}\colon x_{1}+x_{2}<z\wedge y_{1}>0\wedge y_{1}+y_{2}\leq 0.

REAL
improves the prototype implementation in three main categories:

1.

Enabling input formulas from a convenient extension of SMT-LIB (removing previous strict restrictions)
and producing formulas in SMT-LIB format,

2.

Using more efficient data structures and procedures to speed up the elimination process
(e.g. caching and sharing (sub)formulas, more efficient atom shape normalization, combining duplicate tree walks),

3.

Producing more compact and structured formulas, e.g., by handling integer equalities and non-strict real inequalities directly, sharing common subexpressions in the Boolean abstraction, and
replacing unnecessary theory variables with Boolean variables where possible.

For
1
, REAL extends PySMT’s
[
8
]
abstract syntax tree with the Ramsey quantifier, enabling both parsing from and exporting to an
extended SMT-LIB syntax
.
We extend the SMT-LIB grammar (following the conventions in
[
2
]
) as follows, where
...
denotes existing production rules:

\displaystyle{\color[rgb]{0,1,0}\langle\text{term}\rangle}

\displaystyle::=\ldots

\displaystyle\mid{\color[rgb]{0,0,1}(\textbf{ramsey}\ (}{\color[rgb]{0,1,0}\langle\text{sorted\_var}\rangle}^{+}{\color[rgb]{0,0,1})}\ {\color[rgb]{0,0,1}(}{\color[rgb]{0,1,0}\langle\text{sorted\_var}\rangle}^{+}{\color[rgb]{0,0,1})}\ {\color[rgb]{0,1,0}\langle\text{term}\rangle}{\color[rgb]{0,0,1})}

\displaystyle\mid{\color[rgb]{0,0,1}(\textbf{ramsey}}\ {\color[rgb]{0,1,0}\langle\text{sort}\rangle}\ {\color[rgb]{0,0,1}(}{\color[rgb]{0,1,0}\langle\text{symbol}\rangle}^{+}{\color[rgb]{0,0,1})}\ {\color[rgb]{0,0,1}(}{\color[rgb]{0,1,0}\langle\text{symbol}\rangle}^{+}{\color[rgb]{0,0,1})}\ {\color[rgb]{0,1,0}\langle\text{term}\rangle}{\color[rgb]{0,0,1})}

Here, blue marks terminal symbols and green marks non-terminals. The first rule is for mixed quantifiers, and the second offers a shorthand for integer or real-only quantifiers.
The new symbol
ramsey
has the semantics of
\exists^{\text{ram}}
as defined above.

3
Benchmarks and Experiments

All benchmarks were run on an Arch Linux machine with 33 Gi of RAM and an AMD Ryzen 7 2700X, the final formula was checked for satisfiability using Z3 version 4.15.1. FASTer used the PresTAF solver from the TaPAS suite, timings of external tools(z3 and FAST(er)) were recorded using the time command.

3.1
Pipeline

We evaluated our verification pipeline on a selection of both classical and practical examples, chosen to represent a broad range of system behaviors.

Sliding Window Protocol:

We verify the liveness property for a TCP-like system, ensuring that the message window (size 3) advances infinitely often.

Lamport’s Bakery Algorithm.

[
7
]

We model this mutual-exclusion algorithm for two concurrent processes. Without a fairness assumption, verification returns sat, showing that starvation-freedom does not hold.

McCarthy 91 Function.

The McCarthy 91
[
11
]
function is a classical example in program verification, defined as:

M(n)=\begin{cases}n-10&\text{if }n>100,\\
M(M(n+11))&\text{if }n\leq 100.\end{cases}

We verify the first part of the termination condition, namely the absence of an infinite clique, for
n\geq 0
.

4
Conclusion and Future Work

We presented a modular verification pipeline that combines Armoise specifications, the Alchemist transpiler, and REAL. Benchmarks on classical and practical examples demonstrate that the approach efficiently handles infinite-state systems.

The case of mixed linear integer real arithmetic still leaves room for improvement,
as the overhead compared to pure LIA and LRA remains substantial,
due to the separation of integer and real variables in the current approach.
Moreover, replacing FASTer with a tool that directly targets reachability relations, or streamlining FASTer’s ergonomics, could significantly reduce the size and redundancy of SMT encodings.
Finally, we propose to extend the pipeline to counter systems over the reals (and the mixed case).
