Optimistic vs Pessimistic Uncertainty Model Unfalsification
Jannes Hühnerbein, Jad Wehbeh, Eric C. Kerrigan

Abstract
We present a novel, input-output data-driven approach to uncertainty model identification. As the true bounds and distributions of system uncertainties ultimately remain unknown, we depart from the goal of identifying the uncertainty model and instead look for minimal concrete statements that can be made based on an uncertain system model and available input-output data. We refer to this as unfalsifying an uncertainty model. Two different unfalsification approaches are taken. The optimistic approach determines the smallest uncertainties that could explain the given data, while the pessimistic approach finds the largest possible uncertainties suggested by the data. The pessimistic problem is revealed to be a semi-infinite program, which is solved using the local reduction algorithm. It is also shown that the optimistic and pessimistic approaches to uncertainty model unfalsification are mathematical duals. Finally, both approaches are tested using an uncertain linear model with data from a simulated nonlinear system.



I
Introduction

I-A

Motivation

In classical control theory, controllers are initially designed for nominal systems without considering uncertainties or disturbances.
The problem of controller synthesis for nominal, undisturbed systems is a well-studied one. In many cases, a nominal controller features sufficient stability margins, such that it works even in the presence of uncertainties and disturbances.
However, if robustness is a more critical concern,
the controller is modified based on an uncertainty model to ensure stability and, optionally, constraint satisfaction despite worst-case disturbances.
Therefore, it is of high importance to have an understanding of disturbances and uncertainties that can arise in a given system.

Data-driven approaches are commonly used to identify at least an approximate uncertainty model.
However, as the
true
nature of uncertainties ultimately remains unknown, the notion of
identifying
an uncertainty
model is misleading.
No amount of data, no matter how large, is able to fully reflect system uncertainty. If that were the case, it would not be uncertain. For this reason, we look for ways to
unfalsify
an uncertainty model instead.

I-B

Related Work

The term
unfalsification
originates from
Logic of Scientific Discovery
by Austrian-British philosopher Karl Popper
[
1
]
.
In his work, Popper calls for
falsifiability
as a necessary property for any acceptable scientific hypothesis.
Popper’s work can be understood as a proposal to solve David Hume’s
Problem of Induction

[
2
]
by postulating that scientific theories are only acceptable if they are falsifiable, i. e. if they can be disproven.
All acceptable scientific hypotheses that have not yet been falsified are not
validated
, but merely
unfalsified
.

In the context of this paper, model unfalsification refers to the process of systematically challenging mathematical models of dynamical systems based on available data to gain confidence in their validity.

Optimal vs Feasible Parameters

As

It is important to note that system identification problems are not always set up in a way that enables the model to

This distinction separates system identification from model unfalsification.
System identification strives for

in some sense, whereas unfalsification only
requires

but is more strict regarding the
exact
reproducibility of the data.

Extensions of the Idea

The previous paragraphs make it seem like model unfalsification is always a binary problem, where a model is either falsified or unfalsified.
While this is true in principle, the idea can be extended to also include secondary conditions and objectives.
One way of doing so is to see model unfalsification as a special case of system identification that requires the model to be exact
and
in some sense
optimal

The majority of publications on model unfalsification date from the late 1990s and early 2000s.
It was during this period that the concept, previously regarded as rather philosophical,

Since then, fewer publications have specifically mentioned the problem, which served as motivation for this paper.

I-B
3
Semi-Infinite Programming & Local Reduction

Semi-infinite programs (SIPs) that are also considered in this paper consist of a finite number of optimization variables and an infinite number of constraints; hence the name
semi-infinite
.
The theory of SIP is described in more depth by
[
16
]
, who also provides applied examples with basic solution approaches.

A more general solution approach to SIPs is given by
[
17
]
. They introduce
the
local reduction
algorithm as a sequential approach of solving SIPs using subsets of
constraints with finite cardinality.
This idea was extended by
[
18
]
to a scenario-based approach that
aims at finding worst-case scenarios that reduce the infinite number of constraints in the problem
to a finite set of constraints that govern the “worst case”.

These kinds of scenario-based approaches are not entirely new and were previously presented in the context of probabilistic solution techniques for robust
controller design
[
19
,
20
]
. When solving SIPs, however, new scenarios are not generated
at random but in a strategic way, such that the algorithm terminates at a local solution. This is referred to as
automatic scenario generation
by
[
18
]
.

Another notable contribution to local reduction is made by
[
21
]
by accounting for existence constraints and non-unique optimization variable trajectories.

I-C

Contributions

The main contribution of this paper is a novel optimization-based framework for data-driven uncertainty model unfalsification.
Two formulations of this problem —
optimistic
and
pessimistic
— are proposed, each providing a different perspective on disturbances and uncertainties, recognizing that uncertainty models can never fully capture true system uncertainty.
The framework also critiques conventional methods that either impose overly conservative bounds, sacrificing performance, or rely on unjustified assumptions (such as Gaussian noise).

Both the optimistic and pessimistic uncertainty model unfalsification formulations were tested
by applying an uncertain linear model formulation to nonlinear simulation data.

II
Problem Formulation

Before the topic is discussed in detail, the most general model unfalsification problem is formulated without any further assumptions.
This formal definition is then used as the basis for several subproblems and derivations.

Assume a very general uncertain discrete-time model of a physical plant given by

\displaystyle 0

\displaystyle=\hat{f}(\hat{x}_{k+1},\hat{x}_{k},u_{k},\hat{w}_{k},\hat{\theta})

(1a)

\displaystyle\hat{y}_{k}

\displaystyle=\hat{g}(\hat{x}_{k},u_{k},\hat{w}_{k},\hat{\theta})

(1b)

\displaystyle\hat{w}_{k}

\displaystyle\in\hat{\mathcal{W}}(\hat{\gamma}),

(1c)

where
\hat{f}
is a discrete-time model of the state dynamics
\hat{x}_{k}
,
\hat{g}
models the measurements
\hat{y}_{k}
,
\hat{\theta}
denotes the model parameters,
\hat{w}_{k}
denotes the model uncertainties according to some uncertainty model
\hat{\mathcal{W}}
and
u_{k}
represents the system inputs.

Definition II.1

(Model Unfalsification)
.

The model (
1
) is said to be unfalsified by the
N
-point data set
(U,Y)\coloneq((u_{0},\dots,u_{N-1}),(y_{0},\dots,y_{N-1}))
if and only if there exists
a parameter configuration
\hat{\theta}\in\hat{\Theta}
and an
N
-point sequence of
disturbances
W=\{\hat{w}_{i}\sim\hat{\mathcal{W}}(i,\hat{\gamma})\;\colon\;i=0,1,\dots,N-1\}
with some
\hat{\gamma}\in\hat{\Gamma}
,
such that all prediction errors
e_{k}\coloneq y_{k}-\hat{y}_{k},k=0,\dots,N-1
are zero.

The problem of uncertainty model unfalsification in its purest form can be formulated as the feasibility problem

find

\displaystyle\bar{x}_{0},\dots,\bar{x}_{N-1},{\bar{w}}_{0},\dots,{\bar{w}}_{N-1},{\bar{\theta}},\bar{\gamma}

(2a)

s. t.

\displaystyle 0=\hat{f}(\bar{x}_{i+1},\bar{x}_{i},u_{i},{\bar{w}}_{i},{\bar{\theta}}),\quad\;i=0,\dots,N-2

(2b)

\displaystyle y_{i}=\hat{g}(\bar{x}_{i},u_{i},{\bar{w}}_{i},{\bar{\theta}}),\quad\;i=0,\dots,N-1

(2c)

\displaystyle{\bar{w}}_{i}\in\hat{\mathcal{W}}(\bar{\gamma}),\quad\;i=0,\dots,N-1

(2d)

\displaystyle{\bar{\theta}}\in\hat{\Theta}(U,Y),

(2e)

\displaystyle\bar{\gamma}\in\hat{\Gamma}(U,Y),

(2f)

which can only be solved if there exists a series of
uncertainties
{\bar{W}}^{*}=({\bar{w}}^{*}_{0},\dots,{\bar{w}}^{*}_{N-1})
in accordance with the
uncertainty model
\hat{\mathcal{W}}
that results in an
exact
match between
the given data
(U,Y)
and the model
(\hat{f},\hat{g},\hat{\mathcal{W}})
. In other words, the
model is
unfalsified
for the parameters
({\bar{\theta}}^{*},\bar{\gamma}^{*})
.

For simplicity, it is assumed that
\hat{\mathcal{W}}(\bar{\gamma})
is a time-invariant parametrized set with parameters
\bar{\gamma}
. However, more complex uncertainty models are also possible.

Then, the basic concept of uncertainty model unfalsification is developed further to allow
for optimization over the uncertainty model
\hat{\mathcal{W}}(\bar{\gamma})
.
As a consequence, two general optimization problems can be
formulated: the “optimistic” and the “pessimistic” uncertainty model
unfalsification problem.

In the
optimistic
case, the optimal uncertainty model
\hat{\mathcal{W}}(\bar{\gamma}^{*})

is computed by minimizing some uncertainty metric
function
r(\bar{\gamma})
. This yields the optimistic problem formulation

\displaystyle\min_{{\bar{W}},{\bar{\theta}},\bar{\gamma}}\quad

\displaystyle r(\bar{\gamma})

(3a)

s. t.

\displaystyle{\bar{W}}\in\Omega_{\bar{\theta}}(\hat{f},\hat{g},U,Y)

(3b)

\displaystyle{\bar{w}}_{i}\in\hat{\mathcal{W}}(\bar{\gamma}),

\displaystyle\quad i=0,\dots,N-1

(3c)

\displaystyle{\bar{\theta}}\in\hat{\Theta}(U,Y),

(3d)

\displaystyle\bar{\gamma}\in\hat{\Gamma}(U,Y),

(3e)

where
\Omega_{\bar{\theta}}(\hat{f},\hat{g},U,Y)
denotes the set of permissible uncertainty trajectories given the model, parameters and data set

\displaystyle\Omega_{\bar{\theta}}(\hat{f},\hat{g},U,Y)

\displaystyle\coloneqq

\displaystyle\{\hat{W}\;\colon\;\exists\hat{X}

\displaystyle\subseteq\mathcal{X}\;|\;0=\hat{f}(\hat{x}_{k+1},\hat{x}_{k},u_{k},\hat{w}_{k},{\bar{\theta}}),

\displaystyle y_{k}=\hat{g}(

\displaystyle\hat{x}_{k},u_{k},\hat{w}_{k},{\bar{\theta}}),k=0,\dots,N-1\}.

(4)

The solution of problem (
3
)
consists of the uncertainty trajectory
{\bar{W}}^{*}
that results in the optimal
uncertainty model
\hat{\mathcal{W}}(\bar{\gamma}^{*})
with respect to the uncertainty
metric function
r(\bar{\gamma})
.
The optimal state trajectory
\bar{X}^{*}
is computed as a byproduct since it
is needed for computing the set
\Omega_{\bar{\theta}}
.

Since only a single, but not necessarily unique, optimal uncertainty trajectory
{\bar{W}}^{*}
is considered in this problem formulation,
it tends to result in very optimistic uncertainty models; hence the name.

Conversely, a
pessimistic
approach can be taken for the same underlying problem.
In this case the goal is not to determine
one
uncertainty trajectory that fits the model, but to make sure that the optimal uncertainty model captures
all
possible uncertainty trajectories allowed by the given data
(U,Y)
and the model
(\hat{f},\hat{g})
.
This is achieved by adding a “for all” constraint to the optimization problem resulting in the following semi-infinite optimization program (SIP)

\displaystyle\min_{\begin{subarray}{c}\bar{\gamma}\in\hat{\Gamma}(U,Y),\\
{\bar{\theta}}\in\hat{\Theta}(U,Y)\end{subarray}}\quad

\displaystyle r(\bar{\gamma})

(5a)

s. t.

\displaystyle W\subseteq\hat{\mathcal{W}}(\bar{\gamma}),\,\forall W\in\Omega_{\bar{\theta}}(\hat{f},\hat{g},U,Y),

(5b)

where the set
\Omega_{\bar{\theta}}
represents the set of all uncertainty trajectories that are permissible under the given model and data set for a parametric configuration
{\bar{\theta}}
.

III
Theoretical Analysis

III-A

Optimistic Uncertainty Model Unfalsification

Non-Uniqueness of Solutions

The optimistic uncertainty model unfalsification determines a “minimum-volume”
set
\hat{\mathcal{W}}(\bar{\gamma}^{*})
with respect to the given “volume”
function
r(\bar{\gamma})

enclosing all elements of
a
permissible uncertainty trajectory
{\bar{W}}^{*}
.
Hence, the uncertainty realization
{\bar{W}}^{*}
and the model parameters
(\bar{\gamma}^{*},{\bar{\theta}}^{*})
leading to the minimum-volume enclosing set
\hat{\mathcal{W}}(\bar{\gamma}^{*})
are not necessarily unique. In practice, non-unique solutions mostly arise in very small problems.

Monotonicity of the Optimal Objective Value

The number of constraints in problem (
3
) is driven
by the number of data points
(U,Y)
. Hence, it is worth investigating how the optimistic
uncertainty model
\hat{\mathcal{W}}(\bar{\gamma}^{*})
and the optimal objective
value
r^{*}\coloneqq r(\bar{\gamma}^{*})
behave when more data is added.

Proposition III.1
.

Given a data set
(U,Y)
and a solution to the optimistic problem (
3
)
with optimal value
r^{*}
,
a larger data set
(U_{+},Y_{+})
with
U\subset U_{+}

and
Y\subset Y_{+}
will lead to an optimal value
r^{*}_{+}

that is larger or equal to the original optimal
objective value, i. e.
r^{*}\leq r^{*}_{+}
.

Proof.

Adding data points to the data set
(U,Y)
adds constraints to the set of permissible uncertainty trajectories
\Omega
, and previously permissible trajectories may no longer be allowed.
The resulting set
\Omega_{+}
is smaller or equal to the original set, i. e.
\Omega_{+}\subseteq\Omega
. Hence, the feasible region of problem (
3
) either remains the same,
if all previously permissible uncertainty trajectories remain permissible, or the feasible region shrinks.
As a result, the optimal objective value
r^{*}
also either remains the same or increases if the added data
rules out solutions that were previously feasible.
∎

III-B

Pessimistic Uncertainty Model Unfalsification

Necessary Conditions for Feasibility

The “for all” constraint in the pessimistic uncertainty model unfalsification
problem (
5
) can only be satisfied if
the set
\Omega
is bounded. Hence, this is a necessary condition for feasibility.
In order to formalize the relationship between the model
(\hat{f},\hat{g})
, the given data
(U,Y)
and the
bounds of the set
\Omega
, we introduce the concept of
bounded uncertainty inferability
.

Definition III.1
.

If the set of all permissible uncertainty trajectories
\Omega
defined
in (
II
) is bounded for some data
set
D\coloneqq(U,Y)
,
bounded uncertainty
is
inferable
from
the data
D
for the model
(\hat{f},\hat{g})
.

Without specific knowledge about
(\hat{f},\hat{g})
and
(U,Y)
it is difficult
to determine whether bounded uncertainty inferability holds.
A more concrete statement can be made for linear systems, which will be presented later on in section
III-D
.

From here on, we assume that bounded uncertainty inferability is satisfied and the feasibility of the pessimistic uncertainty unfalsification problem is given.

Strict Order Reflection

Assume that the uncertainty metric function
r(\gamma)
for the uncertainty model
\hat{\mathcal{W}}(\gamma)
satisfies
monotonicity

\displaystyle\hat{\mathcal{W}}(\gamma_{1})\subseteq\hat{\mathcal{W}}(\gamma_{2})\;\implies\;r(\gamma_{1})\leq r(\gamma_{2}),

(6)

i. e. if regions are added to a set its uncertainty metric function must also increase.
This condition is automatically satisfied if
r(\gamma)
is a valid set measure
of
\hat{\mathcal{W}}(\gamma)
.

If the converse is true as well, namely the uncertainty metric function
r(\gamma)
is strictly order-reflecting with respect
to the set
\hat{\mathcal{W}}(\gamma)
, i. e.

\displaystyle r(\gamma_{1})\leq r(\gamma_{2})\;\implies\;\hat{\mathcal{W}}(\gamma_{1})\subseteq\hat{\mathcal{W}}(\gamma_{2}),\,\forall\gamma_{1},\gamma_{2}\in\Gamma,

(7)

then (
5
) can be written as an equivalent min-max problem

\displaystyle\min_{\begin{subarray}{c}\bar{\gamma}\in\hat{\Gamma}(U,Y)\\
{\bar{\theta}}\in\hat{\Theta}(U,Y)\end{subarray}}\max_{{\bar{W}}}\quad

\displaystyle r(\bar{\gamma})

(8a)

s. t.

\displaystyle{\bar{W}}\in\Omega_{\bar{\theta}}(\hat{f},\hat{g},U,Y)

(8b)

\displaystyle{\bar{w}}_{i}\in\hat{\mathcal{W}}(\bar{\gamma}),\quad i=0,\dots,N-1,

(8c)

since the solution is fully determined by a single “worst-case” uncertainty trajectory.

This problem poses significant challenges of its own, but has a finite number of constraints and optimization variables. Therefore, no SIP solving algorithms need to be used.

Proposition III.2
.

If
(\hat{f},\hat{g})
and

Proof.

Let

, denoted as

Hence,
\gamma^{*}_{k}

\displaystyle\gamma^{*}_{k}\in\argmin_{\bar{\gamma}\in\hat{\Gamma}(U,Y)}\quad

\displaystyle r(\bar{\gamma})

(9a)

s. t.

\displaystyle w_{i}\in\hat{\mathcal{W}}(\bar{\gamma}),\quad i=0,\dots,N-1

(9b)

\displaystyle W=\Omega_{\theta,k}(\hat{f},\hat{g},U,Y).

(9c)

Let
\gamma^{*}_{\textnormal{max}}

\displaystyle r(\gamma^{*}_{\textnormal{max}})\geq r(\gamma^{*}_{k}),\;\forall\gamma^{*}_{k}\in\Gamma^{*}_{\Omega},\gamma^{*}_{\textnormal{max}}\in\Gamma^{*}_{\Omega},

where

Since bounded uncertainty inferability is assumed to be satisfied,

Since

III-C

Duality of Optimistic and Pessimistic Problems

Proposition III.3
.

Strong duality between the optimistic and pessimistic uncertainty model unfalsification problems holds if the permissible uncertainty realization is unique, i. e.
\textrm{cardinality}(\Omega)=1
.

Proof.

Assuming that there exists exactly one permissible uncertainty realization, i. e.
\Omega=\{W_{\textnormal{unique}}\}
, the optimistic problem (
3
) can be rewritten as

\displaystyle\min_{\bar{\gamma}}\quad

\displaystyle r(\bar{\gamma})

(12a)

s. t.

\displaystyle W_{\textnormal{unique}}\subseteq\hat{\mathcal{W}}(\bar{\gamma}),

(12b)

and the pessimistic problem (
5
) becomes

\displaystyle\min_{\bar{\gamma}}\quad

\displaystyle r(\bar{\gamma})

(13a)

s. t.

\displaystyle W\subseteq\hat{\mathcal{W}}(\bar{\gamma}),\;\forall W\in\{W_{\textnormal{unique}}\},

(13b)

which is identical to the reformulated optimistic problem (
12
).

Hence, given the uniqueness of the permissible uncertainty realization, the optimistic and pessimistic problem formulations are identical,
therefore, strong duality must hold.
∎

The more useful result is that – with mild assumptions – a similar statement can be made about weak duality of the optimistic and pessimistic problems.

Proposition III.4
.

Suppose that the following holds:

1.

both the optimistic and pessimistic problems are feasible and have unique solutions.

2.

the set
\hat{\mathcal{W}}(\gamma)
is convex for all
\gamma
.

3.

\hat{\mathcal{W}}^{*}_{\mathcal{X}}
enclosing a set
\mathcal{X}
with minimum volume
r
satisfies monotonicity, i. e.
\mathcal{A}\subseteq\mathcal{B}\implies\hat{\mathcal{W}}^{*}_{\mathcal{A}}\subseteq\hat{\mathcal{W}}^{*}_{\mathcal{B}}
.

4.

the function
r(\gamma)
satisfies monotonicity, i. e.
\hat{\mathcal{W}}(\gamma_{1})\subseteq\hat{\mathcal{W}}(\gamma_{2})\implies r(\gamma_{1})\leq r(\gamma_{2})
.

then weak duality between the optimistic and the pessimistic uncertainty model unfalsification problems holds.

Proof.

Given a set of permissible uncertainty trajectories
\Omega
, let
(\bar{\gamma}_{\textnormal{opt}}^{*},{\bar{W}}_{\textnormal{opt}}^{*})
be the solution of the optimistic problem with
optimal objective value
r(\bar{\gamma}_{\textnormal{opt}}^{*})
, whereas the solution of the pessimistic problem is assumed to be given by
\bar{\gamma}_{\textnormal{pess}}^{*}
with optimal
objective value
r(\bar{\gamma}_{\textnormal{pess}}^{*})
.
From the optimistic problem follows that
{\bar{W}}_{\textnormal{opt}}^{*}\subseteq\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{opt}}^{*})
and
since
{\bar{W}}_{\textnormal{opt}}^{*}\in\Omega
,
{\bar{W}}_{\textnormal{opt}}^{*}\subseteq\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*})
must also be satisfied.

By construction of the pessimistic problem, the set
\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*})
must contain
at least
the trajectory
{\bar{W}}_{\textnormal{opt}}^{*}
.
In the special case where
\Omega
solely consists of a unique uncertainty trajectory, strong duality holds, as proven above.
In this case, the unique uncertainty trajectory is equivalent to
{\bar{W}}_{\textnormal{opt}}^{*}
. If
\textrm{cardinality}(\Omega)>1
, the set
\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*})
remains a superset of
{\bar{W}}_{\textnormal{opt}}^{*}
, but also contains all other trajectories given in
\Omega
.
This implies that
\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*})
must contain at least one point that is not contained in
\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{opt}}^{*})
, assuming that trajectories in
\Omega
are mutually distinct.

However, given monotonicity of the set
\hat{\mathcal{W}}^{*}_{\mathcal{X}}
, the pessimistic enclosing set
\hat{\mathcal{W}}(\bar{\gamma}^{*}_{\textnormal{pess}})
must fully contain
the optimistic enclosing set
\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{opt}}^{*})

\displaystyle\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{opt}}^{*})\subseteq\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*}).

(14)

Then, by monotonicity of
r
, the optimal objective value of the pessimistic problem upper bounds any solution of the optimistic problem

\displaystyle\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{opt}}^{*})\subseteq\hat{\mathcal{W}}(\bar{\gamma}_{\textnormal{pess}}^{*})\implies r(\bar{\gamma}_{\textnormal{opt}}^{*})\leq r(\bar{\gamma}_{\textnormal{pess}}^{*}),

(15)

and therefore the two problems satisfy weak duality.
∎

III-D

Linear Systems

The previously introduced concept of bounded uncertainty inferability shares some similarities to observability in classical control theory.
Therefore the
uncertainty observability matrix
is introduced analogously to the
observability matrix.

Definition III.2

(Uncertainty Observability Matrix)
.

Given the linear system

\displaystyle x_{k+1}

\displaystyle=Ax_{k}+Bu_{k}+Ew_{k}

(16a)

\displaystyle y_{k}

\displaystyle=Cx_{k}+Du_{k}+F\hat{v}_{k},

(16b)

the measurements
Y
can be related to the system inputs by the system of linear equations

\displaystyle y_{k}

\displaystyle-C\sum_{i=0}^{k-1}A^{i}Bu_{k-i-1}-Du_{k}-F\hat{v}_{k}

\displaystyle=CA^{k}\hat{x}_{0}+C\sum_{i=0}^{k-1}A^{i}E\hat{w}_{k-i-1},\,\,k=0,\dots,N-1.

(17)

Based on this system of equations, the
uncertainty observability matrix

\mathcal{E}
is defined as

\displaystyle\mathcal{E}

\displaystyle\coloneq\begin{bmatrix}C&0&0&\cdots&0\\
CA&CE&0&\cdots&0\\
CA^{2}&CAE&CE&\cdots&0\\
\vdots&\vdots&\vdots&\ddots&\vdots\\
CA^{N-1}&CA^{N-2}E&CA^{N-3}E&\cdots&CE\end{bmatrix}.

(18)

Remark
.

Input feedthrough
Du_{k}
has no effect on
\mathcal{E}
.

Fact III.1
.

For
\hat{v}_{k}\equiv 0
, the system of
equations (
III.2
) has a unique solution if
and only if
\mathcal{E}
is square and nonsingular.

Fact III.2
.

If
\mathcal{E}
is nonsingular and all measurement noise is zero (
\hat{v}_{k}\equiv 0)
, the set of permissible uncertainty trajectories
\Omega
contains exactly one uncertainty trajectory.

With
A\in\mathbb{R}^{n\times n}
,
C\in\mathbb{R}^{p\times n}
and
E\in\mathbb{R}^{n\times d_{w}}
, the dimensions of
\mathcal{E}
are
p(N+1)\times(n+d_{w}N)
.
Hence, for specific cases, it is possible for
\mathcal{E}
to be square and nonsingular.
In a lot of practical cases, however,
\mathcal{E}
is reducible and results in a slightly shorter matrix after reduction.
Then, the system of equations (

) is under-determined and therefore has unbounded solutions. In this case, additional assumptions are necessary in order to ensure bounded uncertainty inferability.

Fact III.3
.

If
\hat{v}_{k}\equiv 0
and
\mathcal{E}
are irreducible and short (fewer rows than columns) then
\Omega
is unbounded, and bounded uncertainty inferability is not satisfied.

Facts

Proposition III.5
.

For linear models of the form (

)

Take the system of equations (

)

.
Then, since

\displaystyle\begin{bmatrix}\hat{x}_{0}\\

is a linear combination of elements in the data set
(U,Y)
and elements
from the measurement noise trajectory

Take a linear combination of two vectors

V
Conclusions

In this paper, we proposed a novel framework for data-driven uncertainty model unfalsification to allow for
better justification of assumptions regarding system uncertainties.

We present two possible techniques of choosing an unfalsified uncertainty model: an optimistic and a pessimistic one.
The proposed optimistic uncertainty model unfalsification approach determines the least conservative uncertainty model
that explains the available data.
In contrast, the pessimistic approach consists of computing the set of all permissible uncertainty trajectories given
the data, and determines the uncertainty model that represents all of those uncertainty trajectories. It was
shown that this problem is a semi-infinite program and can be solved using the local reduction algorithm.

Additionally, theoretical analysis revealed that the pessimistic uncertainty model unfalsification problem
is feasible under the assumption of bounded uncertainty inferability and bounded measurement noise.
Finally, it was shown that the optimistic uncertainty model represents a
strict
lower bound, thereby falsifying all
uncertainty models that are less conservative, while the pessimistic uncertainty model can be taken as a loose upper bound.
This duality between the two problems was investigated in more detail.
