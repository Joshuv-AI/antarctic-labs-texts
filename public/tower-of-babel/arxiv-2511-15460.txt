Dynamic Matroids: Base Packing and Covering
Tijn de Vos, ⓡ, Mara Grilnberger

Abstract
In this paper, we consider dynamic matroids, where elements can be inserted to or deleted from the ground set over time. The independent sets change to reflect the current ground set. As matroids are central to the study of many combinatorial optimization problems, it is a natural next step to also consider them in a dynamic setting. The study of dynamic matroids has the potential to generalize several dynamic graph problems, including, but not limited to, arboricity and maximum bipartite matching. We contribute by providing efficient algorithms for some fundamental matroid questions. In particular, we study the most basic question of maintaining a base dynamically, providing an essential building block for future algorithms. We further utilize this result and consider the elementary problems of base packing and base covering. We provide a deterministic algorithm that maintains a ( 1 ± ε ) (1\pm\varepsilon) -approximation of the base packing number Φ \Phi in O ⁡ ( Φ ⋅ poly ​ ( log ⁡ n , ε − 1 ) ) O(\Phi\cdot\text{poly}(\log n,\varepsilon^{-1})) queries per update. Similarly, we provide a deterministic algorithm that maintains a ( 1 ± ε ) (1\pm\varepsilon) -approximation of the base covering number β \beta in O ⁡ ( β ⋅ poly ​ ( log ⁡ n , ε − 1 ) ) O(\beta\cdot\text{poly}(\log n,\varepsilon^{-1})) queries per update. Moreover, we give an algorithm that maintains a ( 1 ± ε ) (1\pm\varepsilon) -approximation of the base covering number β \beta in O ⁡ ( poly ​ ( log ⁡ n , ε − 1 ) ) O(\text{poly}(\log n,\varepsilon^{-1})) queries per update against an oblivious adversary. These results are obtained by exploring the relationship between base collections , a generalization of tree-packings, and base packing and covering respectively. We provide structural theorems to formalize these connections, and show how they lead to simple dynamic algorithms.

Matroids.

Formally, a matroid is defined as a tuple
\mathcal{M}=(E,\mathcal{I})
, where

is a finite

\mathcal{I}\subseteq\mathcal{P}(E)
a family of

1) Non trivial:

2) Downward closure: if

and

, then
A^{\prime}\in\mathcal{I}

3) Exchange property: if
A,B\in\mathcal{I}
and
|A|>|B|

such that
B\cup\{e\}\in\mathcal{I}

We denote

to be the size of the ground set. The
rank
of a set

is defined as the size of the largest independent set it contains:

\rk(A):=\max\limits_{\begin{subarray}{c}A^{\prime}\in\mathcal{I}\text{ s.t.}\\
A^{\prime}\subseteq A\end{subarray}}|A^{\prime}|
.

We say that

is a

\mathcal{M}
if it is a maximal independent set, i.e.,
\rk(B)=|B|=\rk(E)
. Given a weight function on the elements, a

is a base of the smallest total weight.
Since
\mathcal{I}
can be as large as
2^{|E|}

rank oracle
, which provides
\rk(A)

A\subseteq E

Dynamic Matroids.

For dynamic matroids, we consider element insertions and deletions to the ground set.
2
2

2

The decremental version of this has been studied in
[
4
]

When an element
e
is deleted, the independent sets
\mathcal{I}
simply restrict to the sets without
e

\{I\in\mathcal{I}:e\notin I\}
. In other words,
\mathcal{M}
is restricted to
E\setminus\{e\}
. When an element
E
is inserted, the adversary also decides on a collection
\mathcal{I}_{e}
such that
(E\cup\{e\},\mathcal{I}\cup\mathcal{I}_{e})
is a matroid and
e\in I
for every
I\in\mathcal{I}_{e}

An alternative definition of dynamic matroids could be as follows. One could allow for updates to
\mathcal{I}
that do not stem from an element deletion or insertion. However, if we can completely change
\mathcal{I}
in a single update, then we could go from any matroid on
n
elements to any other matroid on
n
elements. This means that any lower bound for a static algorithm carries over to
each
update of the dynamic algorithm. Hence, recomputing from scratch is the best one could do. On the other extreme, we could only allow adding or deleting
a single set

I
from
\mathcal{I}
. We note that, in general, such a change to
\mathcal{I}
will no longer guarantee that it is a matroid: consider adding
I
to
\mathcal{I}
. By the downward closure property, all subsets of
I
also have to be in
\mathcal{I}
. We consider the most restrictive (and hence most general) version of this, where we only add
I
if
I\setminus\{e\}
is already in
\mathcal{I}
for some element
e
. The alternative view is that the element
e
is added to the ground set
3
3

3

If
e

We distinguish two types of adversaries: an

fixes the updates beforehand, independent of the random choices in the algorithm, while an
adaptive adversary
determines the next update depending on the current state of the algorithm. In this paper, our algorithms are either deterministic, hence hold against an adaptive adversary, or are randomized and hold against an oblivious adversary.

Minimum Weight Base.

First, we give our result for maintaining a minimum weight base.

There exists a deterministic algorithm that, given a dynamic matroid

Packing and Covering.

The other two problems we treat in this paper are
base packing
and
base covering
. In
base packing
the goal is to pack as many disjoint bases in
\mathcal{M}
as possible. Formally, we define the
(fractional) packing number

\Phi_{\mathcal{M}}
of a matroid
\mathcal{M}
as follows

\Phi_{\mathcal{M}}:=\min_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}.

The integral packing number is
\lfloor\Phi_{\mathcal{M}}\rfloor
. Edmonds
[
16
]
showed that
\lfloor\Phi_{\mathcal{M}}\rfloor
equals the number of disjoint bases that can be packed in
\mathcal{M}
.

Dual to base packing, in
base covering
the goal is to cover
\mathcal{M}
by as few bases as possible.
Formally, we define the
(fractional) covering number

\beta_{\mathcal{M}}
of a matroid
\mathcal{M}
as follows

\beta_{\mathcal{M}}:=\max_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
A\neq\emptyset\end{subarray}}\frac{|A|}{\rk(A)}.

We define the integral covering number as
\lceil\beta_{\mathcal{M}}\rceil
. Edmonds
[
17
]
showed that
\lceil\beta_{\mathcal{M}}\rceil
equals the minimum number of bases necessary to cover
\mathcal{M}
.
We omit the subscript if the matroid is clear from the context.

In this paper, we give the first dynamic algorithms for approximating the fractional packing number and the fractional covering number.

1.2
.

Let
\varepsilon\in(0,1/2)
be a parameter and let
\mathcal{M}
be a dynamic matroid that at any moment contains at most
n

\Phi
is bounded by
\Phi_{\max}
, we can deterministically maintain a
(1\pm\varepsilon)
-approximation of the fractional packing number with
O(\Phi_{\max}^{2}\cdot\varepsilon^{-4}\cdot\log^{3}n)
worst-case rank-queries per update or
O(\Phi_{\max}\cdot\varepsilon^{-4}\cdot\log^{3}n)
amortized rank-queries per update.

Since we give the first dynamic algorithm, our result can only be compared to using the deterministic static algorithm from Chekuri and Quanrud
[
9
]
to recompute the fractional packing number from scratch after every update. This would take
\tilde{O}(n\Phi_{\max}/\varepsilon^{2})
independence-queries per update. Hence, our algorithm provides an exponential improvement in terms of
n

1.3
.

Let
\varepsilon\in(0,1/2)
be a parameter and let
\mathcal{M}
be a dynamic matroid that at any moment contains at most
n

\beta

\beta_{\max}

(1\pm\varepsilon)

1.1.1
Base Collections.

An important tool for dynamic arboricity is tree-packing. This concept has first appeared in the seminal works by Nash-Williams
[
45
]
and Tutte
[
55
]
. It has also been well studied in its relation to the minimum cut of the graph
[
24
,
36
,
51
,
53
,

,
8
,

.
We generalize the concept of tree-packings to matroids, and call it a
base collection
, to avoid confusion with respect to packing disjoint bases.

A
base collection

\mathcal{B}
is a family of bases
B
for the matroid
\mathcal{M}
, allowing multiple occurrences of the same base. The
load
of an element
e\in E
is defined as
L^{\mathcal{B}}(e):=|\{B\in\mathcal{B}:e\in B\}|
. The
relative load
is defined as
\ell^{\mathcal{B}}(e)=L^{\mathcal{B}}(e)/|\mathcal{B}|
. Whenever the base collection is clear from context, we omit the superscript.

Next, we want to define some ‘ideal’ relative load. Hereto, we first prove a corollary using Edmond’s theorem on base packing (
Theorem

A.1
).
We show that the lowest possible maximum load in base collections relate to the base packing number.

1.5
.

We have that
\max_{\mathcal{B}}\frac{1}{\max\limits_{e\in E}\ell^{\mathcal{B}}(e)}=\Phi_{\mathcal{M}}
.

However, for purpose of analysis, we would like a
specific
packing with this property. More precisely, we would like the
loads
corresponding to that packing. This we call the
ideal relative loads
, a generalization of the ‘ideal tree-packing’ for the graphic matroid
[
53
]
.

Ideal Relative Loads.

We define the concept of ideal loads, which are hard to compute, but capture the structural properties of the graph well.
First, we define the
restricted matroid

\mathcal{M}|A
as
\mathcal{M}|A:=(A,\mathcal{I}\;|\;A)
, where
\mathcal{I}|A:=\{X\in\mathcal{I}\;|\;X\subseteq A\}
.
Then, we assign ideal relative loads
\ell^{*}(e)
for all
e\in E
:

•

Let
A_{0}\subset E
be a set such that
\frac{|A_{0}|}{\rk(E)-\rk(\overline{A_{0}})}=\Phi_{\mathcal{M}}
.

•

For all
e\in A_{0}
, set
\ell^{*}(e)=1/\Phi_{\mathcal{M}}
.

•

Recurse on the matroid
\mathcal{M}|\overline{A_{0}}
.

We show that this is well-defined in
Appendix

A
.

Greedy Base Collections.

In this paper, we consider base collections
\mathcal{B}=\{B_{1},\ldots,B_{k}\}
built greedily as follows: the
i
-th base
B_{i}
is a minimum weight base where the weights for each element are given by the relative loads induced by the base collection up until this base
\{B_{1},\ldots,B_{i-1}\}
.

In the graphic matroid, it has been shown
[
53
]
that a greedy tree-packing
\mathcal{T}
of size
\Theta(\Phi\log|V|/\varepsilon^{2})
approximates the ideal packing well since

|\ell^{\mathcal{T}}(e)-\ell^{*}(e)|\leq\varepsilon/\Phi

(1)

for all
e\in E
.
We show a stronger statement for general matroids, for which we introduce the parameter
\gamma
to provide a better trade-offs between the error and the number of greedy bases.

1.6
.

Let
\gamma\in[\Phi,\beta]
and let
\mathcal{B}
be a greedy base collection with
|\mathcal{B}|\geq 3\gamma\log n/\varepsilon^{2}
. Then

|\ell^{\mathcal{B}}(e)-\ell^{*}(e)|\leq\varepsilon\ell^{*}(e)

(2)

for all
e\in E
with
\ell^{*}(e)\geq 1/\gamma
and

|\ell^{\mathcal{B}}(e)-\ell^{*}(e)|\leq\varepsilon/\gamma

(3)

for all
e\in E
with
\ell^{*}(e)\leq 1/\gamma
.

The improvement over
[
53
]
in the special case of the graphic matroid can be seen as follows:

Equation

1
can be reformulated to obtain
|\ell^{\mathcal{B}}(e)-\ell^{*}(e)|\leq\varepsilon/\gamma
. However, it needs
|\mathcal{B}|=\Theta\left(\tfrac{\gamma^{2}}{\Phi}\log n/\varepsilon^{2}\right)
bases.
That is, it has a
quadratic
dependence on
\gamma
, where we obtain a
linear
dependence.

In other words, Thorup
[
53
]
showed that the values are an
additive approximation
, since the error is independent of
\ell^{*}(e)
. We show a
multiplicative approximation
, since the error depends linearly on
\ell^{*}(e)
. For our application, the latter leads to stronger results. To be precise,
Lemma

1.6
shows that a collection of at least
3\beta\log n/\varepsilon^{2}
bases directly gives a
(1\pm\varepsilon)
-approximation of the covering number. Using Thorup
[
53
]
gives
|\mathcal{B}|=\Theta\left(\tfrac{\beta^{2}}{\Phi}\log n/\varepsilon^{2}\right)
.

The proof of
Lemma

1.6
utilizes a technique by Young
[
59
]
. We consider a distribution of bases, such that picking the bases for a base collection randomly from this distribution would result in the relative loads being ideal in expectation. Then we analyze the number of times the relative load
of an element does not approximate its ideal load well. We do this by replacing the randomly picked bases one after the other using a greedy approach to compute the new base. During this process, we consider pessimistic estimators for the number of violations at every step and show that they cannot be increased when a greedy base is added. This is also where the main difference to the graph case lies, as we need to consider the matroids restricted to elements or contracted to elements with certain ideal loads. The proof using the contraction is complicated by the fact that there is no notion of vertices in a general matroid. However, it still holds that any minimum weight base of
\mathcal{M}
contains a minimum weight base for the matroid contracted to a subset.

To the best of our knowledge, the community was not aware of this property for the graphic matroid either. In particular, it means that we simplify the result of de Vos and Christiansen
[
13
]
for arboricity. They introduce an intricate procedure to artificially maintain
\Phi\approx\beta
by adding virtual edges.

Dynamic Data Structure for Base Collections.

Similar to the case of the graphic matroid, we show that we can maintain a greedy base collection efficiently under dynamic updates. The main building block for this is maintaining a dynamic minimum weight base,
Proposition

1.1
. We maintain this by exploiting their greedy properties, combined with a binary search, to design a simple, efficient algorithm. For details, see
Section

2

We then build a greedy base collection, by maintaining a minimum weight base for every base in the collection. We show how to handle the updates themselves and the recourse from changes in the weights due to the update.
This gives the following result.

1.7
.

There exists a deterministic algorithm that, given a matroid
\mathcal{M}
, maintains a greedy base collection
\mathcal{B}
of size
|\mathcal{B}|
with
O(|\mathcal{B}|^{2}\log(|\mathcal{B}|n))
worst-case rank-queries per update.

1.1.2
Structural Results.

Next, we consider how (ideal) base collections are related to packing and covering.

Note that, by the definition of
\ell^{*}
, the maximum load in base collections is related to the base packing number.

1.8
.

We have that
\frac{1}{\max\limits_{e\in E}\ell^{*}(e)}=\Phi_{\mathcal{M}}
.

We also show that the minimum load in base collections is related to the base covering number. This generalizes the result of de Vos and Christiansen
[
13
]
, who show the analogous result in the graphic matroid, where the covering number is called the arboricity. This insight is the base of the recent breakthrough by Cen et al.
[
6
]
that gives the first improvement on the running time of computing the arboricity in thirty years.

1.9
.

We have that

\frac{1}{\min\limits_{e\in E}\ell^{*}(e)}=\max\limits_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
A\neq\emptyset\end{subarray}}\frac{|A|}{\rk(A)}
.

The proof follows the same lines as
[
13
]
, but has some more subtleties. To see this, we recall that the covering number is defined as

\beta_{\mathcal{M}}:=\max_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
A\neq\emptyset\end{subarray}}\frac{|A|}{\rk(A)}.

For the special case of graphic matroids, the arboricity of a graph
G=(V,E)
is defined as
\max_{\begin{subarray}{c}S\subseteq V\ \rm{s.t.}\\
|S|>1\end{subarray}}\frac{|E(S)|}{|S|-1}
,
where
E(S)
is the set of edges of
G[S]
.
The fact that the denominator of the equation changes from the size of a set to the rank of a set impacts the proof. The reason is that
|S\mathbin{\mathchoice{\vtop{\halign{\hfil$\m@th\displaystyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\textstyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\scriptstyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\scriptscriptstyle#$\hfil\cr\cup\cr\cdot\crcr}}}}T|=|S|+|T|
but we do not always have
\rk(A\mathbin{\mathchoice{\vtop{\halign{\hfil$\m@th\displaystyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\textstyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\scriptstyle#$\hfil\cr\cup\cr\cdot\crcr}}}{\vtop{\halign{\hfil$\m@th\scriptscriptstyle#$\hfil\cr\cup\cr\cdot\crcr}}}}B)\neq\rk(A)+\rk(B)
.
We show that the
submodularity
of the rank function (see, e.g,
[
50
]
) suffices, i.e.,

\rk(A\cup B)+\rk(A\cap B)\leq\rk(A)+\rk(B).

Dynamic Packing and Covering.

Using the results thus far, the worst-case result for dynamic base packing,

Remark

1.8
, we know that the packing number can be expressed in terms of the ideal relative loads. We can approximate this by a greedy base collection, see
Lemma

1.6
. And finally, we know how to maintain this under dynamic updates using
Lemma

1.7
.

The amortized result in
Theorem

1.2
uses the fact that an element is not contained in every base of the collection, and hence a better recourse argument is possible. This follows the same lines of argument as the case of the graphic matroid
[
13
]
but has some nuances. We want to highlight a special case: an insertion can
decrease

\Phi
(similarly, a deletion can
increase

\Phi
). Note that in graphs, this does not appear: such updates change the graph from disconnected to connected and the packing number of a disconnected graph is 0.
In a matroid, the addition of this element needs to increase the overall rank, the packing number is not 0 and
e
is part of
any
base in
\mathcal{M}
after the update. This breaks some of the argumentation for graphic matroids. In
Section

3.1
we show how to handle such technicalities efficiently.

The deterministic result for dynamic base covering,
Theorem

1.3
, is obtained in a similar manner. The number of worst-case rank-queries depends on the value known to upper bound the covering number at any point in time. To remove this dependency we make use of a sampling technique.

Sampling.

We use
uniform sampling
, where every element is sampled with equal probability. This a standard technique in designing (graph) algorithms (see e.g.
[
41
]
). The approach is similar to the sampling in multi-graphs when maintaining the arboricity
[
13
]
.
Although the sampling itself is the same as for multi-graphs – it is uniform sampling over the elements – the analysis is more involved for matroids.

The idea is to sample with
p=\frac{\log n}{\varepsilon^{2}\beta}
, such that the covering number in the sampled matroid becomes
\Theta(\log n/\varepsilon^{2})
with high probability. The
\log n/\varepsilon^{2}
stems from the use of Chernoff bounds. That means we are considering expressions of the form
\frac{|S|}{\rk(S)}
under uniform sampling. Obviously,
|S|
behaves as expected.
The hard part is showing that
\rk(S)
behaves well under sampling, i.e., does not change with the right choice of
p
.
For graphic matroids, the expression simplifies by
\rk(S)=\#\text{vertices}
, which is clearly not affected by sampling. Hence these complications only occurs for general matroids.

To investigate this, we first fix a rank
r
and consider all sets
S
of
\rk(S)=r
. When inspecting
\frac{|S|}{\rk(S)}
, we remark for our applications that we are only interested in the
maximum
among such sets, which restricts the number of possible sets to
n^{r}
. This allows us to use a union bound to obtain our result. For more details, see
Section

3.1

For the case of base packing a similar approach cannot be used.
Again, the goal is to show how
\frac{|S|}{\rk(E)-\rk(\overline{S})}
behaves under uniform sampling, where
|S|
behaves as expected. However, with the techniques known to us, it seems hard to show that
\rk(E)-\rk(\overline{S})
behaves well
with high probability
. It remains an open question to obtain a dynamic base packing algorithm that updates independent of the packing number.

For graphic matroids,
[
13
]
show a trick against
adaptive adversaries
, where each vertex has ownership over some of the edges. Whenever one of its edges is affected by an update, it resamples all its edges. It turns out that this is strong enough to obtain results against adaptive adversaries. For general matroids, it is unclear how to bucket the elements in a way such that resampling one bucket every update protects against an adaptive adversary. It remains an open question how to design efficient algorithms in this case.

Organization

In
Section

2
, we show how to maintain a minimum weight base dynamically.
In
Section

3
, we show that dynamic base collections can be used to obtain the dynamic packing and covering results.
Hereto, we show the structural results on base packing, base covering, and their connection to base collections in
Appendix

A
). And finally, we show that greedy base collections approximate the ideal base collections and how to maintain them in
Appendix

2
Maintaining a Dynamic Minimum Weight Base

In this section, we give an algorithm to maintain a minimum weight base.

Minimum Weight Base.

Given a universe
E
, and weight function
w\colon E\to[1,\dots,W]
, a
minimum weight base
is a base
B
of minimum total weight
w(B)=\sum_{e\in B}w(e)
. Note that if the weights are unique, the minimum weight base is unique. We can force this by lexicographical tie-breaking, essentially changing the maximum weight to
nW
. The minimum weight base of a matroid can be computed using a simple greedy approach as shown in
[
25
,
18
]
.

For a
dynamic minimum weight base
, the goal is to maintain a minimum weight base under element insertions and deletions.
More generally, we can also allow for weight increases or decreases, but this can also be modeled by deleting the element and inserting it again with the new weight.

Preliminaries.

The
span
of a set
A\subseteq E
is denoted by
\Span(A)
and is defined as the set
\{e\in E|\rk(A)=\rk(A+e)\}
. We say that the set
A
spans element
e\in E
or that
A
spans a set
B\subseteq E
if
e\in\Span(A)
or
B\subseteq\Span(A)
, respectively. The set
A
always spans itself as well as all other elements that can be added to
A
without increasing the size of the maximal independent subset.

A
circuit

C\subseteq E
is an inclusion-wise minimal dependent set of elements, i.e.,
C\notin\mathcal{I}
and for every
x\in C
,
C\setminus\{x\}\in\mathcal{I}
. The unique circuit in
S+e
for
S\in\mathcal{I}
and
S+e\not\in\mathcal{I}
is denoted by
C(S+e)
. We have the following lemma concerning circuits.

2.1
[
50
]
.

Let
C
and
C^{\prime}
be circuits. If
x\in C\cap C^{\prime}
and
y\in C\setminus C^{\prime}
, then there exists a circuit in
(C\cup C^{\prime})\setminus\{x\}
containing
y
.

Algorithm.

We base our algorithm on two fundamental properties of minimum spanning trees (see e.g.,
[
38
]
), which also hold for minimum weight bases in matroids.

•

The
cycle property
: For any cycle, the edge with the largest weight cannot be in the MST.

•

The
cut property
: For any cut, the edge with the smallest weight that crosses the cut is in the MST.

In the proof below, we implicitly use and prove these properties for matroids. Note that in this context, a ‘cut’ is a minimal set of elements that reduces the rank.

See
1.1

Proof.

Without loss of generality, we assume that the weights are unique. We can do tie-breaking of elements with equal weight by lexicographic order.

We introduce the following notation:
B_{\leq t}:=\{f\in B:w(f)\leq t\}
and similarly
{E_{\leq t}:=\{f\in E:w(f)\leq t\}}
. Let us first consider element insertion. Suppose
e
is inserted, finding the circuit in
B+e
can be costly. However, we just need to find the element
f
of highest weight on this circuit (possibly
e
itself if it was inserted with a high weight). Formally, we do this as follows.

•

Find min
t
s.t.
\rk(B_{\leq t})=\rk(B_{\leq t}+e)
.

•

Output the unique element
f
with weight
t
.

Note that now
f
is the element of highest weight on the circuit of
B+e
.
Next, we show correctness. We assume that before the insertion
B
was a base with minimum weight. Note that all subsets of
E
that were previously independent, are still independent after the addition of
e
to the matroid. The algorithm outputs the element
f
. In case (a)
w(f)>w(e)
the maintained base
B^{\prime}
is set to
B-f+e
, otherwise in case (b)
w(f)<w(e)

B^{\prime}=B
remains unchanged. Now assume towards a contradiction that after the insertion there is another base
B^{\prime\prime}
such that
w(B^{\prime\prime})<w(B^{\prime})
. Note that
e\in B^{\prime\prime}
, otherwise
B
would not have been a minimum weight base. Further, there is an element
e^{\prime}
in
C(B+e)-e
with
B^{\prime\prime}-e+e^{\prime}\in\mathcal{I}
. To see this, let
E_{c}
be the set of elements of
c-B^{\prime\prime}
for a circuit
c
. If adding an element of
E_{C(B+e)}
to
B^{\prime\prime}
results in a circuit containing
e
, we are done. Otherwise, we know that
e\not\in C(B^{\prime\prime}+e^{\prime\prime})
for any
e^{\prime\prime}\in E_{C(B+e)}
. Considering such an element
e_{1}
from
E_{C(B+e)}
, by
Lemma

2.1
we know that there is a circuit
c_{1}\subseteq(C(B^{\prime\prime}+e_{1})+C(B+e))-e_{1}
with
e\in c_{1}
. If
|E_{c_{1}}|=1
we are done, otherwise (since
c_{1}\subseteq B^{\prime\prime}+E_{C(B+e)}-e_{1}
) we can continue by removing the next element
e_{2}\in c_{1}\setminus B^{\prime\prime}
in the same way to find a circuit
c_{2}\subseteq(C(B^{\prime\prime}+e_{2})+c_{1})-e_{2}\subseteq B^{\prime\prime}+E_{c_{1}}-e_{2}
with
e\in c_{2}
. We can continue in the same way, further restricting the number of elements in the next circuit that are not from
B^{\prime\prime}
until we get a circuit
c^{\prime}\subseteq B^{\prime\prime}+e_{j}
with
e\in c^{\prime}
. Hence, for the element
e_{j}\in C(B+e)-e
we have
B^{\prime\prime}-e+e_{j}
is a base even before the insertion of
e
. Since
e_{j}\in C(B+e)
, we have
w(e_{j})\leq w(f)
.
Now, in case (a) where the maintained base was set to
B-f+e
we get

\displaystyle w(B^{\prime\prime}-e+e_{j})

\displaystyle=w(B^{\prime\prime})-w(e)+w(e_{j})<w(B-f+e)-w(e)+w(e_{j})

\displaystyle=w(B)-w(f)+w(e_{j})\leq w(B).

In case (b) where
B
remained unchanged we have

w(B^{\prime\prime}-e+e_{j})=w(B^{\prime\prime})-w(e)+w(e_{j})<w(B),

where the last inequality is due to
w(e_{j})\leq w(f)<w(e)
. In either case, this contradicts the assumption that
B
was a base of minimum weight before the insertion.

Next, we consider the deletion of an element
e
, which restricts the matroid to
E-e
.
The update is similar to before.

•

Find min
t
s.t.
\rk(B-e+E_{\leq t})=\rk(B-e)+1
.

•

Output the unique element
f
with weight
t
.

Again, assume that before the insertion
B
was a base with minimum weight and also that
e\in B
otherwise
B
stays a minimum weight base. Then
f
is the element of smallest weight that is not already spanned by
B-e
(if no such element exists,
e
was part of all bases before the deletion and
B-e
is still the minimum weight base). It remains to argue that
B^{\prime}=B-e+f
has the smallest total weight after the deletion. Assume there was another base
B^{\prime\prime}
for the restricted matroid with
w(B^{\prime\prime})<w(B-e+f)
. Then
B^{\prime\prime}+e
contains a cycle
C
and there is an element
e^{\prime}\in C
that is not in
B
. Note that
\{b\in B|w(b)<w(e)\}=\{b\in B^{\prime\prime}|w(b)<w(e)\}
and therefore
w(e^{\prime})>w(e)
. Now we consider the base for the original matroid
B^{\prime\prime}+e-e^{\prime}
. But then
B
would not have been a minimum weight base before the deletion, since

w(B^{\prime\prime}+e-e^{\prime})=w(B^{\prime\prime})+w(e)-w(e^{\prime})<w(B^{\prime})+w(e)-w(e^{\prime})\leq w(B^{\prime})+w(e)-w(f)=w(B)

where the last inequality follows from
w(f)\leq w(e^{\prime})
, which remains to be argued. We do so by showing that
e^{\prime}
is also an element along with
f
that is not spanned by
B-e
. Assume towards a contradiction that
B-e
spans
e^{\prime}
. Then there is a circuit
C=C(B-e+e^{\prime})
where
e^{\prime}
has the highest weight out of all elements on the circuit. Since the circuit
c
also exists in the matroid after the deletion of
e
,
B^{\prime\prime}
cannot be a minimum weight base after the deletion, as it contains
e^{\prime}
. This is because there is an element of smaller weight on
C
that can be exchanged for
e^{\prime}
in
B^{\prime\prime}
. Similar to the argument in the case of an insertion, we consider the circuit
C(B^{\prime\prime}+d)
for some

. If
e^{\prime}
is on that circuit we have found the element to exchange
e^{\prime}
with. Otherwise there is a circuit
C^{\prime}
in

that contains
e^{\prime}
. If
C^{\prime}
contains only one element not from
B^{\prime\prime}
, we are done. Otherwise we can find a new circuit containing
e^{\prime}
with less elements from
C-B^{\prime\prime}
as described above until there is only one element left. Hence,
e^{\prime}
is not spanned by
B-e
and
B^{\prime}
is the new minimum weight base.

For the number of queries, note that we can find the minimum with a binary search over the space of all weight
[1,\dots,Wn]
, where the factor
n
compared to maximum weight

comes from the fact that we add the lexicographical order.

Dynamic Packing and Covering

In this section, we combine the structural results from
Appendix

A
with the results on (dynamic) base collections from

and

to obtain efficient algorithms for base packing and base covering.

3.1
Dynamic Matroid Packing

Next, we combine our results thusfar to obtain our dynamic base packing results.
By
Remark

1.8
,
Lemma

1.6
, and
Lemma

1.7
, we obtain the worst-case result almost directly. To obtain better bounds with amortization, some more work is required.

See
1.2

Proof.

We maintain a base collection
\mathcal{B}
of
\Theta\left(\frac{\Phi_{\max}\log(n)}{\varepsilon^{2}}\right)
greedy bases and maintain the maximum
\ell^{\mathcal{B}}(e)
using a max-heap directly giving the approximation.

First, we argue that the maintained value is indeed a
(1\pm\varepsilon)
-approximation of the packing number. We want to show

(1-\varepsilon)\Phi\leq\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}\leq(1+\varepsilon)\Phi.

We show the left hand side, the right hand side is then analogous.

From
Lemma

1.6
we know that if we maintain a base collection of size
\Omega(\Phi\log n/\varepsilon^{\prime 2})
,
\ell^{\mathcal{B}}(e)\geq\ell^{*}(e)-\frac{\varepsilon^{\prime}}{\Phi}
for all
e\in E
. This gives

\max_{e\in E}\ell^{\mathcal{B}}(e)\geq\max_{e\in E}\ell^{*}(e)-\frac{\varepsilon^{\prime}}{\Phi}.

So for
\varepsilon^{\prime}:=\varepsilon/(1+\varepsilon)
we get

\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}\leq\frac{1}{\max_{e\in E}\ell^{*}(e)-\frac{\varepsilon}{(1+\varepsilon)\Phi}}=\frac{1}{\frac{1}{\Phi}-\frac{\varepsilon}{(1+\varepsilon)\Phi}}=(1+\varepsilon)\Phi,

using that
\max_{e\in E}\ell^{*}(e)=\Phi^{-1}
, see also
Remark

1.8
. Similarly,

\displaystyle\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}

\displaystyle\geq\frac{1}{\max_{e\in E}\ell^{*}(e)+\frac{\varepsilon}{(1+\varepsilon)\Phi}}=\frac{1}{\frac{1}{\Phi}+\frac{\varepsilon}{(1+\varepsilon)\Phi}}=\left(\frac{1+\varepsilon}{1+\varepsilon+\varepsilon}\right)\Phi

\displaystyle=\left(1-\frac{\varepsilon}{1+2\varepsilon}\right)\Phi\geq(1-\varepsilon)\Phi,

Next, we consider the number of queries per update. As updating
\mathcal{B}
can require
|\mathcal{B}|^{2}
updates to a greedy base in
\mathcal{B}
maintaining the base collection takes
O\left(\frac{\Phi_{\max}^{2}\log^{2}(n)\log(nW)}{\varepsilon^{4}}\right)
queries for any update (worst-case), see
Lemma

1.7
.
Since
W\leq|\mathcal{B}|=O(\poly n)
, we can write
\log(Wn)=O(\log n)
and hence we have
O\left(\frac{\Phi_{\max}^{2}\log^{3}(n)}{\varepsilon^{4}}\right)
queries for any update (worst-case).

For an amortized update time, we can reduce this using a technique by
[
13
]
.
We note that any element
e
is in

L^{\mathcal{B}}(e)=\ell^{\mathcal{B}}(e)|\mathcal{B}|\leq\max_{e^{\prime}\in E}\ell^{\mathcal{B}}(e^{\prime})|\mathcal{B}|\leq\frac{|\mathcal{B}|}{(1+\varepsilon)\Phi}\leq\frac{|\mathcal{B}|}{\Phi}

bases.
We want to exploit this fact, together with the fact that we only need to consider the first
\Theta(\Phi\log n/\varepsilon^{2})
bases of
\mathcal{B}
when the base packing number is
\Phi
.

To exploit this, we partition the bases of
\mathcal{B}
into buckets of size
2^{i}
. At any point in time when the packing number is
\Phi
and
3\Phi\log n/\varepsilon^{2}\in(2^{i},2^{i+1}]
, we can process an update
e
in the bases of the buckets efficiently. Denote
\Phi
for the packing number before the update and
\Phi^{\prime}
for the packing number after the update.

First, we consider an insertion such that
\Phi^{\prime}\geq\Phi
. We have
\Phi^{\prime}\leq\Phi+1\leq 2\Phi
. Note that after insertion,
e
will be contained in at most
2\cdot 2^{i+2}/\Phi^{\prime}=\Theta(\log n/\varepsilon^{2})
bases. When
e
is part of some base
B_{j}
, this can lead to at most
|\mathcal{B}|
recourse in all of
\mathcal{B}
. So inserting
\mathcal{B}
takes at most
|\mathcal{B}|+\Theta(|\mathcal{B}|\log n/\varepsilon^{2})=\Theta(|\mathcal{B}|\log n/\varepsilon^{2})
, where the first factor
\mathcal{B}
is due to determining which bases to insert
e
in.

It remains to show how to make the changes to bases in the buckets
j>i
. That is where the amortization comes in: rather than performing these updates now. We initialize a priority queue of updates for each bucket. We claim that when a bucket
j
becomes relevant, i.e.,
3\Phi\log n/\varepsilon^{2}\in(2^{j},2^{j+1}]
, we can perform all updates from the queue in
\Theta(|\mathcal{B}|\log n/\varepsilon^{2})
queries per update. Hereto, we first perform all insertions from the queue, and then all deletions.

Rather than performing one insertion at a time, we consider each base of the matroid, and perform all necessary insertions, where we prioritize the elements with a smaller weight – this is easily done by maintaining the queue as a min-heap. This means that each inserted element will only be part of
O(\log n/\varepsilon^{2})
bases, since this process is equivalent to computing the greedy bases from scratch. Each such insertion leads to a recourse of
O(|\mathcal{B}|)
. Hence in total, we use
O(|\mathcal{B}|\log n/\varepsilon^{2})
queries per insertion.

The insertions now have ensured that the packing number in the matroid is actually high enough, so each element that is deleted, is part of
O(\log n/\varepsilon^{2})
bases.

Note that the case that the update is a deletion
e
such that
\Phi^{\prime}\leq\Phi
is analogous.

We are left with two cases: the update is an insertion and
\Phi^{\prime}<\Phi
, or the update is a deletion and
\Phi^{\prime}>\Phi
. Note that in graphs, this does not appear: such updates change the graph from disconnected to connected and the packing number of a disconnected graph is 0.

Consider an insertion
e
such that
\Phi^{\prime}<\Phi
. The addition of this element needs to increase the overall rank of the matroid. In this case,
e
is part of
any
base in
\mathcal{M}
after the insertion. To see this, consider the insertion of an element
e
and let
E
be the set of elements before the insertion with packing number
\Phi
. In the following, we do not need to consider sets
S\subseteq E+e
that do not contain
e
since in that case we have

\frac{|S|}{\rk(E+e)-\rk((E+e)\setminus S)}=\frac{|S|}{\rk(E+e)-\rk((E\setminus S)+e)}\geq\frac{|S|}{\rk(E)-\rk((E)\setminus S)}.

This is immediately obvious in the case where
\rk(E+e)=\rk(E)
. Otherwise
\rk(E+e)=\rk(E)+1
but in this case
\rk((E\setminus S)+e)=\rk(E\setminus S)+1
as well. Hence, these sets cannot be the reason the
\Phi
-value decreases. Now, we want to show that if it decreases, the rank of the matroid must increase. To this end, assume that
\rk(E+e)=\rk(E)
and consider any
S\subseteq E
with
S\neq\emptyset
. Then we have

\frac{|S+e|}{\rk(E+e)-\rk((E+e)\setminus(S+e))}=\frac{|S|+1}{\rk(E)-\rk((E\setminus S))}>\Phi.

It remains to consider the set
\{e\}
. By the definition, this cannot be the set giving the new
\Phi^{\prime}
as
\rk((E+e)\setminus\{e\})=\rk(E)=\rk(E+e)
. Hence, the rank of the matroid has to increase when
\Phi
decreases after the insertion of an element
e
. Further, we have that in this case we also
\Phi^{\prime}=1
and therefore
e
is in every base. This is because when
\rk(E+e)=\rk(E)+1
we have

\frac{|\{e\}|}{\rk(E+e)-\rk(E)}=1.

For any other set
S
containing
e
we have that

\frac{|S+e|}{\rk(E+e)-\rk((E+e)\setminus(S+e))}=\frac{|S|+1}{\rk(E)-\rk((E\setminus S))+1}\geq 1.

where the last inequality follows from
|S|\geq\rk(S)
and the submodularity of the rank-function.

Let
E^{\prime}
be the new ground set
E^{\prime}=E+e
and let
\mathcal{M}^{\prime}
be the matroid after the insertion. Assume that
e
is not in all bases after the insertion. Then there is a set
B
that is a base of the matroid before and after the insertion of
e
. Hence, the overall rank does not change i.e.
\rk_{\mathcal{M}}(E)=\rk_{\mathcal{M}^{\prime}}(E^{\prime})
. Now, consider the set
A
that gives
\Phi^{\prime}=|A|/(\rk_{M^{\prime}}(E^{\prime})-\rk_{\mathcal{M}^{\prime}}(E^{\prime}\setminus A)
. The element
e\not\in A
since otherwise we would have
\rk_{\mathcal{M}^{\prime}}(E^{\prime}\setminus A)=\rk_{\mathcal{M}^{\prime}}(E\setminus(A-e))
and therefore the set
A-e
would give a smaller
\Phi^{\prime}
compared to
A
. Hence,
\rk_{\mathcal{M}^{\prime}}(E^{\prime}\setminus A)\geq\rk_{\mathcal{M}^{\prime}}(E\setminus A)=\rk_{\mathcal{M}}(E\setminus A)
and we further get

\Phi>\frac{|A|}{\rk_{\mathcal{M}^{\prime}}(E^{\prime})-\rk_{\mathcal{M}^{\prime}}(E^{\prime}\setminus A)}\geq\frac{|A|}{\rk_{\mathcal{M}}(E)-\rk_{\mathcal{M}}(E\setminus A)}.

As this would give a smaller packing number than
\Phi
for the matroid before the insertion, we get that
e
must be in all bases of the new matroid after the insertion.
This update is performed easily, since adding to all bases
B\in\mathcal{B}
can be done in
|\mathcal{B}|
updates to the corresponding minimum weight base – where this update has no recourse. So it takes
O(|\mathcal{B}|\log n)
rank-queries by
Proposition

1.1
.

Consider a deletion
e
such that
\Phi^{\prime}>\Phi
. As argued for the previous case, this means that
e
was part of
every
base in
\mathcal{M}
, so we can remove it easily from any
B\in\mathcal{B}
n
|\mathcal{B}|
updates to the corresponding minimum weight base – where this update has no recourse. So it takes
O(|\mathcal{B}|\log n)
rank-queries by
Proposition

1.1
.

We obtain a total of
O\left(\frac{\Phi_{\max}\log^{3}(n)}{\varepsilon^{4}}\right)
amortized rank-queries for any update.

Dynamic Matroid Covering

Similar to the previous section, we now present our results for dynamic base covering.

3.2.1
Deterministic

First, we provide a deterministic result.
We note that for base packing, we also have an algorithm with an amortized bound that depends linearly on
\Phi
. For base covering, we could obtain a result in a similar manner that would depend on
\beta_{\max}^{2}/\Phi
. However, in this case, we cannot relate
\Phi
and
\beta_{\max}
:
\Phi
can be constant, even if
\beta_{\max}
is polynomial.

See
1.3

Proof.

Analogously to the packing case, we maintain a base collection
\mathcal{B}
of
\Theta\left(\frac{\beta_{\max}\log(n)}{\varepsilon^{2}}\right)
greedy bases and maintain the minimum
\ell^{\mathcal{B}}(e)
using a heap directly giving the approximation.

Again, we argue that the maintained value is a
(1\pm\varepsilon)
-approximation of the covering number. From
Lemma

1.6

(1-\varepsilon)\frac{1}{\beta}\leq\min_{e\in E}\ell^{B}(e)\leq(1+\varepsilon)\frac{1}{\beta}.

By using
\varepsilon^{\prime}:=\frac{\varepsilon}{1+\varepsilon}
to determine the size of the base collection we get, as for
Theorem

:

(1-\varepsilon)\beta\leq\frac{1}{\min_{e\in E}\ell^{\mathcal{B}}(e)}\leq(1+\varepsilon)\beta.

Maintaining the base collection takes
O\left(\frac{\beta_{\max}^{2}\log^{3}(n)}{\varepsilon^{4}}\right)
queries for any update (worst-case), see
Lemma

1.7
.
Since
W\leq|\mathcal{B}|=O(\poly n)
, we can write
\log(Wn)=O(\log n)
and hence we have
O\left(\frac{\beta_{\max}^{2}\log^{3}(n)}{\varepsilon^{4}}\right)
queries for any update (worst-case).
∎

3.2.2
Oblivious adversary

Next, we show how uniform sampling can help us to obtain update times independent of
\beta
against oblivious adversaries. The approach uses a standard sampling technique (see, e.g.,
[
41
]
) and is similar to the sampling to maintain arboricity in multigraphs, as shown in
[
13
]
.
See
1.4

Proof.

We create
O(\log n)
matroids
\mathcal{M}_{i}
by sampling each element with probability
{p_{i}=\frac{24c\log n}{2^{i}\varepsilon^{2}}}
(for some constant
c\geq 2
to be set later and
i
such that
p_{i}<1
) to get the respective universe.
\mathcal{M}_{i}
is then given by the restriction of the original matroid to the sampled elements
\mathcal{M}_{i}=\mathcal{M}|E_{i}
.
Now we want to show that if
\beta\in[2^{i-1},2^{i+2})
then the
\frac{1}{p_{i}}\beta_{i}
is a
(1\pm\varepsilon)
-approximation of
\beta
. We show this in two parts.

First, we argue that
\frac{1}{p_{i}}\beta_{i}\geq(1-\varepsilon)\beta
. Consider a set
S\subseteq E
with
\beta=\frac{|S|}{\rk_{\mathcal{M}}(S)}
. Let
S_{i}=S\cap E_{i}
, then we get

\Pr\left(\frac{|S_{i}|}{p_{i}\rk_{\mathcal{M}_{i}}(S_{i})}<(1-\varepsilon)\beta\right)=\Pr\left(|S_{i}|<(1-\varepsilon)p_{i}\beta\rk_{\mathcal{M}_{i}}(S_{i})\right).

Since
\rk_{\mathcal{M}_{i}}(S_{i})\leq\rk_{\mathcal{M}}(S)=\frac{|S|}{\beta}
and
\mathbb{E}(|S_{i}|)=p_{i}|S|
we get by a Chernoff bound

\displaystyle\Pr\left(|S_{i}|<(1-\varepsilon)p_{i}\beta\rk_{\mathcal{M}_{i}}(S_{i})\right)

\displaystyle\leq\Pr\left(|S_{i}|<(1-\varepsilon)p_{i}\beta\rk_{\mathcal{M}}(S)\right)=\Pr\left(|S_{i}|<(1-\varepsilon)p_{i}|S|\right)

\displaystyle\leq e^{-\varepsilon^{2}p_{i}|S|/2}=e^{-\varepsilon^{2}p_{i}\beta\rk_{\mathcal{M}}(S)/2}\leq e^{-\varepsilon^{2}p_{i}2^{i-1}\rk_{\mathcal{M}}(S)/2}

\displaystyle\leq n^{-c\rk_{\mathcal{M}}(S)}.

Hence

\displaystyle\Pr\left(\frac{|S_{i}|}{p_{i}\rk_{\mathcal{M}_{i}}(S_{i})}<(1-\varepsilon)\beta\right)\leq n^{-c\rk_{\mathcal{M}}(S)}.

Now note that
\beta_{i}=\max_{\emptyset\neq S^{\prime}\subseteq E_{i}}\frac{|S^{\prime}|}{\rk_{\mathcal{M}_{i}}(S^{\prime})}\geq\frac{|S_{i}|}{\rk_{\mathcal{M}_{i}}(S_{i})}
, so w.h.p.
\frac{1}{p_{i}}\beta_{i}\geq(1-\varepsilon)\beta
.

Second, we need to show that with high probability the covering number is bounded as follows
\frac{1}{p_{i}}\beta_{i}\leq(1+\varepsilon)\beta
.

Let
S_{i}\subseteq E_{i}
be any non-empty subset. We will show that w.h.p.
\frac{|S_{i}|}{p_{i}\rk_{\mathcal{M}_{i}}(S_{i})}\leq(1+\varepsilon)\beta
.
Hereto, we consider each possible rank
1\leq r\leq\rk_{\mathcal{M}}(E_{i})=\rk(\mathcal{M}|E_{i})
of a non-empty subset of
E_{i}
separately. Let
S_{i}
be the subset of
E_{i}
with rank
r
with maximum
|S_{i}|
. Note that for any other set
A\subseteq E_{i}
with the same rank we have
\frac{|A|}{p_{i}\rk_{\mathcal{M}_{i}}(A)}\leq\frac{|S_{i}|}{p_{i}\rk_{\mathcal{M}_{i}}(S_{i})}
.

Now we consider the set
S:=\Span_{\mathcal{M}}(S_{i})
. For this set we have (a)
\rk_{\mathcal{M}}(S)=\rk_{\mathcal{M}}(S_{i})=\rk_{\mathcal{M}_{i}}(S_{i})
since
S_{i}\subseteq E_{i}
and (b)
S\cap E_{i}=S_{i}
since no element of
E_{i}
can be added to
S_{i}
without an increase in the rank. Therefore we get

\displaystyle\Pr\left(\frac{|S_{i}|}{p_{i}\rk_{\mathcal{M}_{i}}(S_{i})}>(1+\varepsilon)\beta\right)

\displaystyle=\Pr\left(\frac{|S\cap E_{i}|}{p_{i}\rk_{\mathcal{M}}(S)}>(1+\varepsilon)\beta\right)

\displaystyle=\Pr\left(|S\cap E_{i}|>(1+\varepsilon)p_{i}\beta\rk_{\mathcal{M}}(S)\right).

Further, since
\beta\rk_{\mathcal{M}}(S)\geq|S|
, using a Chernoff bound we get

\displaystyle\Pr\left(|S\cap E_{i}|>(1+\varepsilon)p_{i}\beta\rk_{\mathcal{M}}(S)\right)

\displaystyle\leq e^{-\varepsilon^{2}p_{i}\beta\rk_{\mathcal{M}}(S)/3}=e^{-\varepsilon^{2}24c\log(n)\beta\rk_{\mathcal{M}}(S)/3\varepsilon^{2}2^{i}}

\displaystyle\leq e^{-4c\log(n)\rk_{\mathcal{M}}(S)}\leq n^{-c(\rk_{\mathcal{M}}(S)+2)}

where the second to last inequality follows since
\beta\geq 2^{i-1}
. Note that for such a set
S
we have that
S=\Span_{M}(S)
. Also, among the sets of maximum size with rank
r
the set
S
is unique. If there was another set
S_{j}\neq S_{i}
with
\Span(S_{j})=S
, then
S_{j}\subseteq S
and we would have an element
e\in S_{j}\setminus S_{i}
and
|S_{i}+e|>|S_{i}|
while
\rk_{\mathcal{M}}(S_{i}+e)=\rk_{M}(S_{i})
. This contradicts the choice of
S_{i}
. Hence, for any rank
r
it suffices to union bound over all sets
S
with
S=\Span(S)
and
\rk(S)=r
, there are at most
n^{r}
such sets. So the statements holds for all such
S
with probability
n^{-2c}
.

This allows us to then union bound over all possible ranks
r
, there are at most
\rk_{\mathcal{M}}(E)
many and
n
updates, so the statement holds with probability
n^{-2c}\cdot n\cdot n=n^{2-2c}\leq n^{-c}
.

Hence, we get that
\beta_{i}\leq(1+\varepsilon)\beta p_{i}\leq 2^{3}\frac{24c\log n}{\varepsilon^{2}}=O\left(\frac{\log n}{\varepsilon^{2}}\right)
when
\beta\leq 2^{i+2}
. The algorithm maintains a greedy base collection of size
\Theta\left(\frac{\log^{2}n}{\varepsilon^{4}}\right)
for each of the
O(\log n)
matroids
\mathcal{M}_{i}
and one for
G
itself. Whenever
\beta\in[2^{i-1},2^{i+2})
the collection corresponding to
\mathcal{M}_{i}
gives the correct approximation. All other collections might give values that differ drastically from
\beta
and are simply disregarded. At any point in time to know which
\mathcal{M}_{i}
gives the correct value it suffices to consider the estimate from the previous update. This is because if the old estimate
\frac{\beta_{i}}{p_{i}}
was in
[2^{i},2^{i+1})
, then after the update we have that
\beta<(1+\varepsilon)\frac{\beta_{i}}{p_{i}}+1\leq 2^{i+2}
and similarly
\beta\geq(1-\varepsilon)\frac{\beta_{i}}{p_{i}}-1\geq 2^{i-1}
. If the current estimate is in
\Theta(\log n/\varepsilon^{2})
the estimate on the original matroid is considered, otherwise the interval
[2^{i},2^{i+1})
that contains the previous estimate determines the base collection
\mathcal{M}_{i}
that is used for the estimate after the next update. Now it remains to analyze the runtime. For each matroid
\mathcal{M}_{i}
we maintain a greedy base collection of size
O\left(\frac{\log^{2}n}{\varepsilon^{4}}\right)
.

There are
O(\log n)
matroids that could be affected by an update, so by
Lemma

1.7
, an update requires
O\left(\frac{\log^{6}(n)}{\varepsilon^{8}}\right)
rank-queries in the worst-case.
∎

Appendix A
Packing, Covering, and Base Collections

In this section, we provide some structural results regarding base packing, base covering, and their relationship to base collections. These results are the foundation for the algorithms of
Section

3
.

A.1
Base Packing

First, we examine how the largest possible relative load of any element in all possible base collections relates to the packing number. Recall that the following theorem gives the integral packing number of a matroid.

A.1
[
16
]
.

A matroid
\mathcal{M}
can pack
k
disjoint bases if and only if for every subset
A\subseteq E
we have
|A|\geq k(\rk(E)-\rk(\overline{A}))
.

To relate this to the graphic matroid, let
\mathcal{P}
be a vertex partition of a graph
G=(V,E)
. Then the value
\frac{|A|}{\rk(E)-\rk(\overline{A})}
corresponds to
\frac{|E(G/\mathcal{P})|}{|\mathcal{P}|-1}
, called the
partition value
of
\mathcal{P}
.

Next, we use this theorem to show a duality between this value and base collection.

See
1.5

Proof.

We prove the two inequalities "
\leq
" and "
\geq
", starting with the former, which follows directly without using
Theorem

A.1
.

"
\leq
". Let
A^{*}\subseteq E
be such that
\frac{|A^{*}|}{\rk(E)-\rk(\overline{A^{*}})}=\min\limits_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}
. This means that any base
B
needs to contain
\rk(E)-\rk(\overline{A^{*}})
elements from
A^{*}
. So for any base collection
\mathcal{B}
, we have
\sum_{e\in A^{*}}\ell^{\mathcal{B}}(e)\geq\rk(E)-\rk(\overline{A^{*}})
. This means that on average for
e\in A^{*}
we have
\ell^{\mathcal{B}}(e)\geq\frac{\rk(E)-\rk(\overline{A^{*}})}{|A^{*}|}
. In particular
\max_{e\in E}\ell^{\mathcal{B}}(e)\geq\max_{e\in A^{*}}\ell^{\mathcal{B}}(e)\geq\frac{\rk(E)-\rk(\overline{A^{*}})}{|A^{*}|}
. Equivalently, we get that for any base collection
\mathcal{B}

\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}\leq\frac{|A^{*}|}{\rk(E)-\rk(\overline{A^{*}})}.

Now we see that

\max_{\mathcal{B}}\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}\leq\frac{|A^{*}|}{\rk(E)-\rk(\overline{A^{*}})}=\min_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}.

"
\geq
". W.l.o.g., we assume that
\min\limits_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}
is an integer. This can be achieved by copying each element in the matroid
\rk(E)!
times, since
\rk(E)-\rk(\overline{A^{*}})\in\{1,2,\dots\rk(E)\}
.
This has no impact on the analysis as it blows up the values on the left and right equally.

Now suppose that
\min\limits_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}=k
, by
Theorem

A.1
this means that we can pack
k
disjoint bases. Let
\mathcal{B}
be the base collection consisting of these
k
bases. Then for each element
e\in B\in\mathcal{B}
, we have
\ell^{\mathcal{B}}(e)=1/k
. For other elements, we have
\ell^{\mathcal{B}}(e)=0
. Hence we have
\max_{e\in E}\ell^{\mathcal{B}}(e)=1/k
. Equivalently

\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}=k=\min_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}.

Hence clearly

\max_{\mathcal{B}}\frac{1}{\max_{e\in E}\ell^{\mathcal{B}}(e)}\geq k=\min_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
\rk(\overline{A})<\rk(E)\end{subarray}}\frac{|A|}{\rk(E)-\rk(\overline{A})}.\qed

However, for purpose of analysis, we would like a
specific
packing with this property. More precisely, we would like the
loads
corresponding to that packing. Hence, we use the ideal relative loads.

Ideal Relative Loads.

Next, we want to show that the ideal relative loads are well-defined. Hereto, we first show that they will be non-decreasing.

A.2
.

Let
\mathcal{M}_{0}=\mathcal{M}
, and for
i\geq 1
let
\mathcal{M}_{i}
be the matroid considered in the
i
-th recursive step while assigning the ideal relative loads. The values of
\Phi
are non-decreasing, meaning
\Phi_{\mathcal{M}_{i}}\leq\Phi_{\mathcal{M}_{i+1}}
for all
i\geq 0
.

Proof.

Consider an arbitrary step
i
where the matroid
\mathcal{M}_{i}=(E,\mathcal{I})
is processed and let in the following
\Phi:=\Phi_{\mathcal{M}_{i}}
. Let further
A_{0}
be a set that gives
|A_{0}|/(\rk(E)-\rk(E\setminus A_{0}))
. Assume that there is a set
A_{1}\subset E\setminus A_{0}
such that
\frac{|A_{1}|}{\rk(E\setminus A_{0})-\rk((E\setminus A_{0})\setminus A_{1})}<\Phi
, or equivalently
\rk(E\setminus A_{0})-\rk((E\setminus A_{0})\setminus A_{1})>|A_{1}|/\Phi
. By definition of
\Phi
, we also have
\frac{|A_{0}|}{\rk(E)-\rk(E\setminus A_{0})}=\Phi
, or equivalently:
\rk(E)-\rk(E\setminus A_{0})=|A_{0}|/\Phi
.

Since
A_{0}\cap A_{1}=\emptyset
, we get

\displaystyle\frac{|A_{1}\cup A_{0}|}{\rk(E)-\rk(E\setminus(A_{0}\cup A_{1}))}

\displaystyle=\frac{|A_{0}|+|A_{1}|}{\rk(E)-\rk(E\setminus A_{0})+\rk(E\setminus A_{0})-\rk((E\setminus A_{0})\setminus A_{1})}

\displaystyle<\frac{|A_{0}|+|A_{1}|}{\frac{|A_{0}|}{\Phi}+\frac{|A_{1}|}{\Phi}}=\Phi,

which contradicts the choice of
|A_{0}|
.
∎

Now we are ready to show the following lemma.

A.3
.

The ideal relative loads are well-defined.

Proof.

Suppose we have two sets
S
and
T
such that

\frac{|S|}{\rk(E)-\rk(E\setminus S)}=\Phi=\frac{|T|}{\rk(E)-\rk(E\setminus T)}.

(4)

We need to show that all elements
e\in T
get value
\ell^{*}(e)=1/\Phi
, even if we first recurse on
E\setminus S
. In other words, we need to show that

\frac{|T\cap(E\setminus S)|}{\rk(E\setminus S)-\rk((E\setminus S)\setminus(T\cap(E\setminus S)))}=\Phi.

By
Lemma

A.2
, we already know that it is at least
\Phi
. So it remains to show that it is at most
\Phi
. For contradiction, assume

\frac{|T\cap(E\setminus S)|}{\rk(E\setminus S)-\rk((E\setminus S)\setminus(T\cap(E\setminus S)))}>\Phi.

(5)

Then we will show that

\frac{|T\setminus(E\setminus S)|}{\rk(E)-\rk(E\setminus(T\setminus(E\setminus S)))}<\Phi,

contradicting the value of
\Phi
, which was minimal.
First, we consider the numerator:

\displaystyle|T\setminus(E\setminus S)|

\displaystyle=|T|-|T\cap(E\setminus S)|

\displaystyle<\Phi(\rk(E)-\rk(E\setminus T))-\Phi(\rk(E\setminus S)-\rk((E\setminus S)\setminus(T\cap(E\setminus S)))),

by
Equation

4
and
Equation

5

\displaystyle=\Phi(\rk(E)-\rk(E\setminus T)-\rk(E\setminus S)+\rk((E\setminus S)\cap(E\setminus T)))

\displaystyle\leq\Phi(\rk(E)-\rk((E\setminus S)\cup(E\setminus T))),

by submodularity of the rank function.
Finally, we note that

(E\setminus S)\cup(E\setminus T)=E\setminus(S\cap T)=E\setminus(T\setminus(E\setminus S)).

So we conclude that

\frac{|T\setminus(E\setminus S)|}{\rk(E)-\rk(E\setminus(T\setminus(E\setminus S)))}<\frac{\Phi(\rk(E)-\rk(E\setminus(T\setminus(E\setminus S))))}{\rk(E)-\rk(E\setminus(T\setminus(E\setminus S)))}=\Phi,

which finishes the proof.
∎

A.2
Base Covering

As shown in
[
17
]
, the number of bases that are needed to cover all elements of

are given by

\left\lceil\max_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
A\neq\emptyset\end{subarray}}\frac{|A|}{\rk(A)}\right\rceil.

To obtain a similar result as for base packing, we relate the optimal base collection to the covering number. This generalizes the arboricity result of de Vos and Christiansen
[
13
, Theorem 25]
, which is the statement in the special case of graphic matroids.
See
1.9

Proof.

Let
E_{i}:=E\setminus\bigcup_{j<i}A_{j}
and let
\mathcal{M}_{i}=\mathcal{M}|E_{i}
for all recursion levels denoted by the indices
i\in I
. First, we note that
1/\min_{e}\ell^{*}(e)=\max_{i\in I}\Phi_{\mathcal{M}_{i}}
over all recursion levels
i
. Let
j
be the last iteration in which
\Phi_{\mathcal{M}_{i}}
is maximized. Since the
\Phi
-values are non-decreasing, see
Lemma

A.2
, this also has to be the last level of the recursion and therefore
E_{j+1}=E_{j}\setminus A_{j}=\emptyset
and
\rk(E_{j})=\rk(A_{j})
. We get

1/\min_{e}\ell^{*}(e)=\frac{|A_{j}|}{\rk(E_{j})-\rk(E_{j}\setminus A_{j})}=\frac{|A_{j}|}{\rk(A_{j})}\leq\max_{\begin{subarray}{c}A\subseteq E\ \rm{s.t.}\\
A\neq\emptyset\end{subarray}}\frac{|Y|}{\rk(Y)}.

Now, we go on to show
1/\min_{e}\ell^{*}(e)\geq\frac{|Y|}{\rk(Y)}
for any subset

. Note that the recursively defined sets

for

are disjoint and that

. Hence, we get

|Y|=\sum_{i\in I}|A_{i}\cap Y|\leq\sum_{i\in I}\Phi_{\mathcal{M}_{i}}\rk(A_{i}\cap Y)

where it remains to show the inequality

for any

. Assume towards a contradiction that there is a level

Since the rank function is submodular we get

\displaystyle\Phi^{\prime}

\displaystyle\leq\frac{|A_{k}|-|A_{k}\cap Y|}{\rk(E_{k})-\rk(\overline{A_{k}})-\rk(A_{k}\cap Y)}.

By our assumption that

This contradicts the choice of
A_{k}
, as picking

\Phi
-value. Next, we show that

Now it remains to show that
\rk(A_{i}\cap Y)\leq\rk(E_{i}\cap Y)-\rk(\overline{A_{i}}\cap Y)
for all
i\in I
. In the following, consider an arbitrary

. Note that if
\Phi_{\mathcal{M}_{i}}
is an integer then

\rk(A_{i}\cap Y)\leq\frac{|A_{i}\cap Y|}{\Phi_{\mathcal{M}_{i}}}

\mathcal{M}_{i}

\frac{|A_{i}\cap Y|}{\rk(E_{i}\cap Y)-\rk(\overline{A_{i}}\cap Y)}\leq\Phi_{\mathcal{M}_{i}}.

Greedy Base Collection

First, let us define a greedy base collection as follows:
let the weight of an element be the number of bases
an element belongs to, and require that the base in the collection form successive minimum weight bases. This is a natural generalization of the notion for graphic matroids called ‘greedy tree-packing’
5
5

5

We opt for ‘collection’ instead of ‘packing’ to avoid any confusion with base packing as in
Theorem

A.1
.
, see, e.g.,
[
53
]
.

In this section, we show how to maintain a greedy base collection. Then, we show that when we compute a greedy base collection
\mathcal{B}
that is large enough, it approximates the ideal relative loads well.

B.1
Dynamic Greedy Base Collection

We show how to maintain a greedy base collection under dynamic updates. This lemma is rather straightforward.

See
1.7

Proof.

Given a greedy base collection
\mathcal{B}
, let there be an insertion or deletion
e
. The element
e
was/will be part of at most
|\mathcal{B}|
bases. For each base it was/will be a part of, we get at most
|\mathcal{B}|
changes to other bases. Note that this is non-trivial; at a first glance, the changes over bases could add up. However, we note that if an element
f
gets an increased weight because it was used in some base, and later this increased weight means that in another base
g
was chosen instead of
f
, then the weight of
f
is unchanged compared to before the update. Hence there can be at most one change per base in the collection, so
|\mathcal{B}|
in total.

Since each update to a minimum weight base uses at most

queries per update by

B.2
Greedy Approximates Ideal Base Collection

Now, we show that when we compute a greedy base collection
\mathcal{B}
that is large enough, its relative loads
\ell^{\mathcal{B}}(\cdot)
give good approximations to the ideal relative loads
\ell^{*}(\cdot)
. This generalizes the result for packing trees
[
53
]
to matroids, so the proof follows the approach used for the graph case. It utilizes a technique by Young
[
59
]
. The idea is to consider a distribution of bases such that picking the bases for a base collection randomly from this distribution would result in the relative loads being ideal in expectation. Now, the number of violations, where the relative load of an element does not approximate its ideal load well, is analyzed. This is done while replacing the randomly picked trees one after the other by trees computed greedily. For the analysis, we consider a pessimistic estimator for the number of violations at every step of the process and show that its value cannot increase when a greedy tree is added.

Now, consider
\Pi_{\mathcal{M}}
, a distribution of bases of
\mathcal{M}
constructed simultaneously with the assignment of the ideal relative loads. In the following, we generalize the proof of Lemma 13 from
[
53
]
.

B.1
.

For each
e\in E
, we have

\underset{R\in\Pi_{\mathcal{M}}}{\Pr}(e\in R)=\ell^{*}(e).

Proof.

Let
\mathcal{B}^{*}
be a base collection for
\mathcal{M}
with
\frac{1}{\max_{e\in E}\ell^{\mathcal{B}^{*}}(e)}=\Phi_{\mathcal{M}}
. To pick a random base from
\Pi_{\mathcal{M}}
, pick a base
B
from
\mathcal{B}^{*}
uniformly at random. Then, pick an independent set
B^{\prime}
randomly from the recursively defined distribution
\Pi_{\mathcal{M}|\overline{A_{0}}}
. We construct a base
B^{\prime\prime}:=(B\cap A_{0})\cup B^{\prime}
. First, we show that
B^{\prime\prime}
is indeed a base for
\mathcal{M}
.

By the exchange property there is a set
S\subseteq B
such that
B^{\prime}\cup S\in\mathcal{I}
and
|B^{\prime}\cup S|=|B|
, making this set a base. It remains to show that
S=B\cap A_{0}
. Since
B^{\prime}
was a base for
\mathcal{M}|\overline{A_{0}}
and therefore spans
\overline{A_{0}}
, we have
S\subseteq B\cap A_{0}
with
|S|=\rk(E)-\rk(\overline{A_{0}})
. Any set in
\mathcal{B}^{*}
is a base for
\mathcal{M}
. Hence, every such base contains at least
\rk(E)-\rk(\overline{A_{0}})
elements from
A_{0}
, giving a lower bound on the total load of all elements in
A_{0}
. So, the average relative load over
A_{0}
is then at least
\frac{\rk(E)-\rk(\overline{A_{0}})}{|A_{0}|}=\frac{1}{\Phi_{\mathcal{M}}}
. This equals the maximum relative load of elements in
A_{0}
. Hence, all relative loads in
A_{0}
are the same and no base in
\mathcal{B}^{*}
, including
B
, can contain more than
\rk(E)-\rk(\overline{A_{0}})
elements from
A_{0}
. Hence, we get
S=B\cap A_{0}
and
B^{\prime\prime}
is indeed a base for
\mathcal{M}
.

Further, for an element
e\in A_{0}
we have

\Pr_{B^{\prime\prime}\in\Pi_{\mathcal{M}}}(e\in B^{\prime\prime})=\Pr_{B\in B^{*}\rm{u.a.r.}}(e\in B)=\ell^{\mathcal{B}^{*}}(e)=1/\Phi_{\mathcal{M}}=\ell^{*}(e).

For an element
e\in\overline{A_{0}}
we instead get

\Pr_{B^{\prime\prime}\in\Pi_{\mathcal{M}}}(e\in B^{\prime\prime})=\Pr_{B^{\prime}\in\Pi_{\mathcal{M}|\overline{A_{0}}}}(e\in B^{\prime})=\ell^{*}(e)

where the last equality follows by induction.
∎

Note that any
B\in\Pi_{\mathcal{M}}
is a minimum weight base with respect to the ideal relative loads
\ell^{*}(\cdot)
as by induction
B\cap\overline{A_{0}}
is given by a minimum weight base picked from
\Pi_{\mathcal{M}|\overline{A_{0}}}
. Further, the
\ell^{*}(\cdot)
-values of elements in
\overline{A_{0}}
are smaller or equal compared to elements in
A_{0}
.

Now, we go on to show that a large enough greedy base collection approximates the ideal one.

See
1.6

We first show that
Equation

3
holds for all
e\in E
with
\ell^{*}(e)\leq 1/\gamma
and then argue that we have
Equation

2
for all
e\in E
with
\ell^{*}(e)\geq 1/\gamma
. The proof follows the structure of the special case
(
3
)
of the graphic matroid, i.e., trees, for
\gamma=\Phi
from
[
53
, Proposition 16]
using the distribution of bases from above. Many parts are direct generalizations for matroids; all are included here for completeness.

We show the statement in two separate parts, proving
\ell^{\mathcal{B}}(e)\leq\ell^{*}(e)+\varepsilon/\gamma
and
\ell^{\mathcal{B}}(e)\geq\ell^{*}(e)-\varepsilon/\gamma
using the following approach. We consider an estimator for the number of violations for the statement above, while we construct the greedy base collection one base at a time. We assume that the remaining bases are from the distribution
\Pi_{\mathcal{M}}
. The proof is comprised of showing the following three properties: (i) initially the value of the estimator is below
1
, (ii) adding a greedy base does not increase the value, and (iii) having a value below
1
at the end of the process implies the desired property for each element. The proofs of the first two properties closely follow the corresponding parts from
[
53
]
, we include the version for matroids for completeness. The main difference is in the proof of the last property.

B.2
.

For all elements
e\in E
with
\ell^{*}(e)\leq 1/\gamma
we have

\ell^{\mathcal{B}}(e)\leq\ell^{*}(e)+\varepsilon/\gamma.

(8)

Proof.

We show that
\ell^{\mathcal{B}}(e)\leq d+\varepsilon/\gamma
holds for all elements
e\in E
with
\ell^{*}(e)\leq d
for an arbitrary
d\leq 1/\gamma
. Consider the set
A
containing all such elements for the given
d
,
A:=\{e\in E\;|\;\ell^{*}(e)\leq d\}
. Now, we analyze the change of the value of the estimator, where
t
denotes the total number of bases in the collection at the end of the process,

\sum_{e\in A}\frac{(1+\varepsilon)^{L^{\mathcal{B}}(e)}(1+\varepsilon d)^{t-|\mathcal{B}|}}{(1+\varepsilon)^{dt+\varepsilon t/\gamma}}.

(9)

First, we show (i) that in the beginning, when the greedy base collection is still empty, the value of the estimator is below
1
. When
\mathcal{B}=\emptyset
, the estimator (
9
) becomes

\sum_{e\in A}\frac{(1+\varepsilon d)^{t}}{(1+\varepsilon)^{dt+\varepsilon t/\gamma}}.

Analogous to
[
53
]
we get

\sum_{e^{\prime}\in A}\frac{(1+\varepsilon d)^{t}}{(1+\varepsilon)^{dt+\varepsilon t/\gamma}}<n\left(\frac{e^{\varepsilon}}{(1+\varepsilon)^{(1+\varepsilon)}}\right)^{t/\gamma}\leq ne^{-\varepsilon^{2}t/3\gamma}=ne^{-\log n}=1.

The inequalities follow from
(1+\varepsilon d)\leq e^{\varepsilon d}
,
d\leq 1/\gamma
and
t=3\gamma\log n/\varepsilon^{2}
.

Now we consider the end of the greedy base collection process, when
|\mathcal{B}|=t
to show (iii). If the estimators value is smaller than
1
,
Equation

8
holds for all elements in
A
, since at this point, (
9
) becomes

\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}}(e)-dt-\varepsilon t/\gamma}.

Assume there was an element
e\in A
for which
\ell^{\mathcal{B}}(e)>d+\varepsilon/\gamma
, then the value of the estimator,
Equation

9
, would also be at least
1
.

Finally, we need to consider the greedy addition of a new base to the collection and show that it cannot increase the value of the estimator to get (ii). We consider the step that adds the greedy base
B
to
\mathcal{B}
. The new value of the estimator becomes

\sum_{e\in A}\frac{(1+\varepsilon)^{L^{\mathcal{B}\cup\{B\}}(e)}(1+\varepsilon d)^{t-|\mathcal{B}|-1}}{(1+\varepsilon)^{dt+\varepsilon t/\gamma}}.

The difference between the value before and after the deletion is then given by

\sum_{e\in A}\frac{((1+\varepsilon)^{L^{\mathcal{B}}(e)}(1+\varepsilon d)-(1+\varepsilon)^{L^{\mathcal{B}\cup\{B\}}(e)})(1+\varepsilon d)^{t-|\mathcal{B}|-1}}{(1+\varepsilon)^{dt+\varepsilon t/\gamma}}.

Hence, it suffices to show the following upper bound for the quantity

q(B):=\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}\cup\{B\}}(e)}\leq\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}}(e)}(1+\varepsilon d).

If
B
was a base randomly picked from
\Pi_{\mathcal{M}}
the expected value of the quantity would be

\displaystyle\mathbb{E}_{B\in\Pi_{\mathcal{M}}}q(B)

\displaystyle=\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}}(e)}((1+\varepsilon)\Pr_{B\in\Pi_{\mathcal{M}}}(e\in B)+1-\Pr_{B\in\Pi_{\mathcal{M}}}(e\in B))

\displaystyle\leq\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}}(e)}(1+\varepsilon d).

The inequality follows from
Lemma

B.1
because every element
e\in A
has ideal relative load
\ell^{*}(e)\leq d
. The next step is to show that the greedy base has a smaller quantity
q
than for any base in
\Pi_{\mathcal{M}}
. We also have

q(B)=\sum_{e\in A}(1+\varepsilon)^{L^{\mathcal{B}}(e)}+\varepsilon\sum_{e\in B\cap A}(1+\varepsilon)^{L^{\mathcal{B}}(e)}.

Hence going forward, it suffices to compare the values of the latter sum. We write

c(B):=\sum_{e\in B}(1+\varepsilon)^{L^{\mathcal{B}}(e)}.

We need to show

c(B\cap A)\leq\min_{B^{\prime}\in\Pi_{\mathcal{M}}}c(B^{\prime}\cap A).

Now, we want to find a set
S
, such that
c(S)
is an upper bound for
c(B\cap A)
as well as a lower bound for
\min_{B^{\prime}\in\Pi_{\mathcal{M}}}c(B^{\prime}\cap A)
. A suitable set is given by a minimum weight base
B_{A}
for the restricted matroid
\mathcal{M}|A:=(A,\mathcal{I}\;|\;A)
, where
\mathcal{I}|A:=\{X\in\mathcal{I}\;|\;X\subseteq A\}
.

B.3
.

For any minimum weight base
B
of
\mathcal{M}
with respect to the loads
L^{\mathcal{B}}(\cdot)
and a set
A\subseteq E
there is a minimum weight base
B_{A}
with respect to the loads
L^{\mathcal{B}}(\cdot)
for
\mathcal{M}|A
, such that
B\cap A\subseteq B_{A}
.

Proof.

Given a minimum weight base
B
for
\mathcal{M}
we show how to construct a suitable base
B_{A}
using the greedy algorithm for computing a minimum weight base. First we relabel the elements of
E
to be increasing according to the following order: for
a,b\in E
we have
e<_{B}f
if and only if

•

L^{\mathcal{B}}(e)<L^{\mathcal{B}}(f)
; or

•

L^{\mathcal{B}}(e)=L^{\mathcal{B}}(f)
and

–

e\in B\land f\not\in B
; or otherwise

–

e<f
lexicographically.

Note that the relabeling of the elements in this way results in a non-decreasing order with respect to
L^{\mathcal{B}}(\cdot)
regardless of the choice of
B
.
Now we build sets
S_{E}
and
S_{A}
using the greedy algorithm that iterates over the elements in
E
according to the order given by the new labels. At the end of the algorithm
S_{E}
will be the base
B
, and
S_{A}
will be a minimum weight base of
\mathcal{M}|A
, such that
B\cap A\subseteq S_{A}
. Initially both sets are empty. In iteration
i
, when
e_{i}\in E
is considered, do:

•

if
S_{E}+e_{i}\in\mathcal{I}
, add
e_{i}
to
S_{E}
;

•

if
e_{i}\in A
and
S_{A}+e_{i}\in\mathcal{I}
, add
e_{i}
to
S_{A}
.

The elements of both
E
and
A
are processed in non-decreasing order, simultaneously computing a minimum weight base for
\mathcal{M}
as well as
\mathcal{M}|A
with respect to
L^{\mathcal{B}}(\cdot)
.
First, we show that at any point of the algorithm
S_{E}
spans
S_{A}
. Initially, this is true as both sets are empty. Consider iteration
i
processing element
e_{i}
. If
S_{A}
is not altered the claim stays true. If
e_{i}
is added to
S_{A}
then
e_{i}
is either added to
S_{E}
as well, or
S_{E}+e_{i}
was not in
\mathcal{I}
. In both cases
e_{i}
is spanned by
S_{E}
which proves the claim. Further, we get that
\Span(S_{A})\subseteq\Span(S_{E})
and hence we have for all
e_{i}\in E
that
S_{E}+e_{i}\in\mathcal{I}
implies
S_{A}+e_{i}\in\mathcal{I}
. Therefore all
e_{i}\in A
that are added to
S_{E}
are added to
S_{A}
as well.

Now it remains to prove that after all elements have been processed indeed
S_{E}=B
. Again, the proof is by induction. Let
B_{i}:=\{e\in B|e<_{B}e_{i}\}+e_{i}
and show that after processing iteration
i
we have
S_{E}=B_{i}
. In the case that
e_{i}\in B
, we have that
S_{E}+e_{i}\in\mathcal{I}
holds and
e_{i}
is added to
S_{E}
. Now consider the case that
e_{i}\not\in B
. If
S_{E}+e_{i}\not\in\mathcal{I}
then
e_{i}
is not added to
S_{E}
and the claim holds.
S_{E}+e_{i}\in\mathcal{I}
cannot hold as otherwise we could create a base
B^{\prime}
by adding elements from
B
to
S_{E}+e_{i}
according to the exchange property. We would get
B^{\prime}=(B-b)+e_{i}
for some element
b\in B\setminus S_{E}
to be processed in a future iteration. Hence,
e_{i}<_{B}b
and since
e_{i}\not\in b
and
b\in B
that is only possible if
L^{\mathcal{B}}(e_{i})<L^{\mathcal{B}}(b)
and
B
would not have been a minimum weight base.

Putting both properties of the algorithm together, after processing the last element, we get that
B\cap A\subseteq S_{A}
and
S_{A}
is a minimum weight base for
\mathcal{M}|A
.
∎

Now, we get the following:

c(B\cap A)\leq c(B_{A})\leq\min_{B^{\prime}\in\Pi_{\mathcal{M}}}c(B^{\prime}\cap A),

where the first inequality holds due to
B.3
and for the second inequality we note that, for any
B^{\prime}\in\Pi_{\mathcal{M}}
, we have that
B^{\prime}\cap A
is a base for
\mathcal{M}|A
. Otherwise
B^{\prime}\cap A
would not span
A
and there would be an element
e\in A\setminus B^{\prime}
such that
(B^{\prime}\cap A)+e\in\mathcal{I}
. By the exchange property we could add elements from
B
to
(B^{\prime}\cap A)+e
until we have another base for
\mathcal{M}
. Since the new base contains all elements from
B
except for one element from
e^{\prime}\in E\setminus A
with
\ell^{*}(e^{\prime})>d
that is replaced with
e
with
\ell^{*}(e)\leq d
this contradicts that
B^{\prime}
is a minimum weight base with respect to the ideal relative loads
\ell^{*}(\cdot)
. Therefore, for any base
B^{\prime\prime}
of
\mathcal{M}|A
, specifically also for
B^{\prime}\cap A
, we have
c(B_{A})\leq c(B^{\prime\prime}\cap A)
as
B_{A}
is also a minimum weight base with respect to
(1+\varepsilon)^{L^{\mathcal{B}}(\cdot)}
since the ordering between the elements stays the same if this value is considered instead of
L^{\mathcal{B}}(\cdot)
.
∎

B.4
.

For all elements
e\in E

\ell^{*}(e)\leq 1/\gamma

\ell^{\mathcal{B}}(e)\geq\ell^{*}(e)-\varepsilon/\gamma.

Again, we consider
d

B.5
.

Let
B_{\overline{A}}

B.6
.

Let

be bases of

\{X\subseteq A\;|\;X\cup B\in\mathcal{I}\}=\{X\subseteq A\;|\;X\cup B^{\prime}\in\mathcal{I}\}.

Let
X\subseteq A
