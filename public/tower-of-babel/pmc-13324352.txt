Federated ConvNeXt-swin temporal fusion network for malware and botnet detection in IoT systems
Authors: Faisal S Alsubaei, Abdulwahab Ali Almazroi, Nasir Ayub
Published: 2026

ABSTRACT
AbstractThe rapid expansion of Internet of Things (IoT) infrastructures has significantly increased the exposure of edge devices to malware and botnet attacks. Conventional intrusion detection systems are largely centralized and struggle to operate effectively in decentralized, heterogeneous, and privacy-sensitive IoT environments, thereby limiting scalability and robustness. To address these challenges, this study proposes the Federated ConvNeXt–Swin Temporal Fusion Network (F-CSTFNet), a federated deep learning framework designed for distributed IoT malware and botnet detection. The proposed architecture integrates ConvNeXt-based convolutional feature extraction with Swin Transformer temporal attention to capture both local traffic patterns and long-range behavioral dependencies within network flows. This hybrid convolution–attention design enables the detection of short-term anomalies as well as evolving attack dynamics directly from network telemetry. In addition, a channel-adaptive feature recalibration mechanism enhances robustness when learning from heterogeneous and noisy client data. The model is trained using a federated learning paradigm that enables multiple IoT clients to collaboratively learn a global model without sharing raw data, thereby preserving data privacy and locality. Extensive experiments conducted on the IoT-23 and N-BaIoT datasets demonstrate that F-CSTFNet outperforms several state-of-the-art centralized and federated baselines in terms of detection accuracy, convergence stability, and client-level fairness. The framework also achieves low performance variance across clients, a high Jain’s Fairness Index (JFI), and reduced inequality during distributed training. These results demonstrate the effectiveness of the proposed architecture as a scalable, privacy-preserving, and resilient intrusion detection framework for next-generation IoT security systems.Keywords: Internet of Things security, Botnet detection, Federated learning, ConvNeXt, Swin Transformer, Intrusion detectionSubject terms: Engineering, Mathematics and computing

Related work

The current research demonstrates scientists’ dedication to developing advanced systems that protect Internet of Things (IoT) networks against malware and botnet attacks through intelligent intrusion detection systems. Researchers have surveyed lightweight machine learning models and hybrid deep learning architectures together with optimization-based frameworks to achieve better detection accuracy while preserving computational efficiency in resource-constrained IoT networks.

The researchers developed a lightweight detection system which utilizes the Quantized XGBoost (Q-XGB) method according to the findings of the study11. The approach aimed to enable Botnet detection within IoT systems that operate under limited resources through its reduced model size and shortened inference time. The framework used histogram-based post-training quantization to XGBoost classifier for faster prediction and maintained classification accuracy. The experimental evaluation proved strong performance across all benchmark datasets. The technique uses traditional gradient boosting methods but fails to identify temporal dependencies which exist in network traffic patterns. The researchers developed a hybrid deep learning framework named Hybrid Stacked Deep Learning (HSDL) according to their findings which detects botnet attacks within IoT networks. The framework aimed to enhance detection accuracy through its combination of spatial and temporal feature learning methods. The technique uses Vectorized Convolutional Neural Networks (VCNN) for feature extraction together with Stacked Long Short-Term Memory (SLSTM) networks which capture sequential patterns found in network traffic. Hyperparameter optimization occurs through Harris Hawks Optimization (HHO) methods. The proposed architecture achieved high detection accuracy but its stacked deep learning structure created computational challenges which restricted its real-time use on resource-limited IoT devices. The research developed a machine learning detection system named ML-BoTDAM according to its presentation in research work15. The framework enables IoT infrastructure to detect Botnet in real time while generating automated alerts about these threats. The system uses machine learning classifiers which have been trained on large datasets of IoT attacks to detect malicious behaviors and inform system administrators. The framework shows accurate detection results but it mainly depends on traditional machine learning algorithms without any advanced deep representation learning capabilities.

The researchers introduced a hybrid detection model named SSRNN-ELM, which detects botnet attacks within software-defined IoT systems through their investigation16. The proposed method aimed to enhance classification efficiency while sustaining high detection accuracy. The architecture uses Recurrent Neural Networks (RNN) to learn features, which Extreme Learning Machines (ELM) use for classification tasks. The classifier parameters undergo optimization through the application of the American Zebra Optimization Algorithm (AZOA). The approach achieved better detection results than traditional models, but the hybrid architecture needed precise parameter tuning, which caused operational issues within massive heterogeneous IoT frameworks. Another study developed a deep learning framework named AdvBiTrans, which uses Bidirectional Long Short-Term Memory networks in combination with Transformer layers according to their research from study17. The model aims to detect advanced botnet attacks that target Industrial Internet of Things (IIoT) environments. The technique uses Pearson correlation for feature selection together with Projected Gradient Descent (PGD) adversarial training to enhance model robustness. The experimental results demonstrated improved detection accuracy on benchmark datasets. The transformer-based architecture requires more computational resources and memory storage, which creates difficulties for deployment in low-power IoT device environments. The researchers presented a lightweight detection framework that uses Stacked Ensemble Learning according to their work in another study18. The study aimed to create a Botnet detection system that meets the computational needs of IoT systems operating with restricted resources. The technique uses Multilayer Perceptron (MLP) and Random Forest classifiers for feature extraction, while Lasso regression selects features and logistic regression functions as the meta-learner. The stacked ensemble approach created high classification performance with lower computational costs, yet the framework failed to create explicit models that tracked temporal patterns of network traffic.

The researchers developed a hybrid deep learning framework named BoT-EnsIDS, which serves as a detection system according to their research from study19. The method aims to enhance detection accuracy through its combination of deep learning techniques and bio-inspired optimization methods. The architecture uses Convolutional Neural Networks (CNN) and Long Short-Term Memory (LSTM) networks to extract features while modeling time-based information. The system uses Particle Swarm Optimization and Gorilla Troops Optimization algorithms for both feature selection and hyperparameter tuning. The system employs Generative Adversarial Networks to create additional data for training purposes. The multi-stage optimization process enhances detection capabilities, but it makes systems more complex and increases the time needed for training. The study in20 proposed hybrid CNNF deep stacked autoencoder, which serves as a machine learning framework for detecting IoT botnet attacks. The framework uses machine learning classifiers to differentiate between malicious Botnet traffic and normal network traffic through analysis of the CICIoT2023 dataset. The classification model can identify various attack types which include DoS attacks, DDoS attacks, reconnaissance attacks, and Mirai-based attacks. The experimental results show that the system achieves maximum detection capacity through its ability to detect threats with more than 97% accuracy while maintaining strong performance in precision, recall, and F1-score measurements. The method depends on standard machine learning models which restrict its capacity to detect advanced temporal and behavioral patterns present in IoT traffic according to the capabilities of deep learning-based systems. The study21 established an intrusion detection system known as INIDS (Intelligent Network Intrusion Detection System). The study aimed to enhance detection capabilities that operate in real time for all attack types. The system uses Pearson correlation to choose features, which it combines with various machine learning models for detecting harmful network activity. INIDS showed better detection performance, yet the system lacks advanced deep learning methods that handle complicated traffic pattern analysis.

The research study of22 developed a spatiotemporal detection architecture that uses ConvLSTM networks. The framework was designed to detect both spatial and temporal connections within network traffic data. Convolutional Neural Networks extract spatial traffic characteristics from the data while Long Short-Term Memory networks learn the time-related patterns present in sequential traffic flows. The architectural design enhances detection capabilities; however, ConvLSTM networks need both extensive training durations and substantial data volumes. The research team presented IBLLNet as a hybrid deep learning framework in their study23. The architecture aims to boost representation learning abilities, which scientists use to detect Botnet activities. The method extracts deep traffic features through Bidirectional LSTM networks, which connect to a LinkNet-style backbone system. The LinkNet backbone enables better detection results, but it raises both computational demands and model design challenges. The researchers created Attention CNN-BiLSTM as a deep learning model that uses attention mechanisms24. The framework seeks to boost classification accuracy by concentrating on the traffic segments that carry the highest informational value. The framework employs convolutional layers to extract features and Bidirectional LSTM networks to handle sequential learning, while attention mechanisms help identify vital features. Attention-based frameworks need high amounts of computational power to operate.

The author in25 developed a hybrid architectural design, which they named CNN-ConvNeXt-Tiny IDS. The model aims to enhance feature representation while ensuring the system can be deployed efficiently in its lightweight form. The framework uses traditional convolutional neural networks together with the ConvNeXt-Tiny architecture to create a system that extracts multi-level traffic features. The method achieves better results through its implementation, yet ConvNeXt-based models require GPU resources to achieve their training proficiency. The research study introduced VAE-MLP as a new generative learning system. The framework aims to extract hidden network traffic signals that enhance attack classification performance. The system uses Variational Autoencoders to create condensed feature representations, which are then classified by a Multilayer Perceptron classifier. The use of generative models enhances feature learning capabilities; however, they make the training process more complicated. The study explored a detection system based on graph technology, which employs Graph Attention Networks (GAT). The approach aims to identify how IoT devices interact with each other and with the rest of the network. The model creates graph representations that transform network traffic through attention-based message passing for identifying malicious conduct. Graph-based models enhance relational learning performance, yet network graph development and management result in higher computational requirements. Researchers have made progress in federated learning-based intrusion detection systems by developing privacy features and technological resilience and better detection capabilities for distributed IoT networks. The researchers in26 developed an FDA framework which uses frequent itemset mining to create compact traffic patterns which enhance system resilience against various data types yet the system shows limited success in stage-wise classification. The MOAT framework27 uses IP and port-based behavioral modeling together with federated aggregation to achieve better generalization results across Mirai and Bashlite IoT botnets yet the system does not support deep learning of spatiotemporal characteristics. The Research work in28 presents a reliable privacy-preserving federated framework (RPFL) which uses homomorphic encryption and blockchain technology together with digital signatures for security purposes but these protective measures make the system more complex. The research team of29 developed a decentralized two-tier federated learning architecture which uses edge-based aggregation with cryptographic protection to remove the need for centralized operations yet this system causes additional computational load. The current methods have not yet reached success because they cannot handle three simultaneous requirements which include effective spatiotemporal modeling and non-IID data resilience and performance that scales effectively. The proposed F-CSTFNet uses a hybrid ConvNeXt–Swin architecture together with adaptive feature recalibration and optimized federated learning to overcome the existing limitations. In addition, early work on distributed service evaluation such as the FEWSS framework30 addressed service suitability and privacy considerations in distributed web service environments, highlighting the importance of privacy-aware evaluation in decentralized systems. Problem statement

The digital attack surface has expanded because Internet of Things (IoT) technologies spread to smart homes and industrial systems and healthcare infrastructures and critical networks. The growing network of interconnected devices leads to the production of enormous amounts of varied network traffic, which cyber adversaries use to execute advanced malware and botnet attacks. The development of intrusion detection systems needs to address data processing demands for distributed IoT systems which operate in limited resource environments11.

The research examined different detection methods which used both lightweight machine learning techniques and hybrid deep learning framework systems. The researchers developed quantized gradient boosting methods which decrease inference time and storage requirements for edge deployment11. Hybrid deep learning framework systems which use both convolutional networks and sequential networks successfully learn spatial and temporal patterns from IoT traffic data according to research studies22,31. The various frameworks use optimization methods together with ensemble learning techniques to improve their ability to classify and select important features18,19. The detection methods produce better results but they face three main problems which include needing advanced computing power and requiring many parameter adjustments and having limited ability to handle large-scale IoT environments.

The detection system enhancements in several recent architectures rely on transformer-based models which use attention mechanisms and deep feature extraction networks for their detection capabilities17,23,24. The methods boost representation learning because they can detect complex traffic dependencies in network data. The transformer and attention-based architectures create higher computing demands together with greater memory needs, which makes their implementation difficult on lightweight IoT devices. The research explored two modeling methods which use generative approaches and graph-based methods for creating latent traffic models and representing device connections32,33. The methods enable flexible modeling but they need additional computing power and the execution of complex graph building tasks.

The existing detection systems face two main problems which include needing centralized training systems to operate. The network traffic data requires aggregation into a single training space, which leads to privacy risks and extra network transmission demands when used in distributed IoT networks. Centralized systems become unworkable for actual implementations because they need organizations to maintain data privacy and limited bandwidth and their network devices with different types of devices. Federated learning provides multiple advantages which help solve the existing challenges present in IoT environments. The system protects data privacy by storing original network traffic at edge devices while only transmitting model parameters. The system decreases communication expenses which central data collection requires while permitting organizations to learn from their remote Internet of Things devices. The federated learning system develops its capacity to generalize by using various client traffic patterns which helps improve detection accuracy in real-world IoT systems that operate with non-IID data.

The research presented F-CSTFNet, which serves as a solution to solve security problems in IoT environments through its implementation of a federated deep learning framework for malware and Botnet detection. The system uses convolution-based methods for traffic feature extraction together with transformer-based methods for attention mechanisms to analyze both local traffic patterns and distant attack patterns. The ConvNeXt-based modules develop spatial representations which can differentiate between spatial patterns found in network telemetry data. The Swin Transformer layers create traffic volume patterns from network data without needing recurrent structures. The framework enables model development to occur through federated training for multiple IoT clients, which allows secure data processing without compromising user information. The system design enables the proposed system to deliver scalable intrusion detection operations which protect user privacy across different IoT devices that have limited resources.

Proposed system model

The proposed system detects malware and botnet threats in extensive Internet of Things (IoT) networks while maintaining data privacy. The increasing expansion of IoT networks creates advanced cyber threats which need security systems that can intelligently identify intrusions at scale. The proposed system uses a complete analytical pipeline which combines data preprocessing with feature transformation and federated learning and deep classification and adaptive optimization. The process starts with the combination of network traffic samples which come from different benchmark datasets according to the diagram presented in Fig. 1. The preprocessing stage removes missing values and duplicate records while normalizing feature distributions and using Adaptive Synthetic Sampling (ADASYN) to address class imbalance. The data preprocessing tasks establish data consistency which helps to strengthen the learning process that follows. The traffic data undergo preprocessing which results in structured feature representations that deep learning can process. The F-CSTFNet architecture implements hierarchical feature extraction together with temporal pattern modeling capabilities. A ConvNeXt-based encoder captures localized traffic characteristics and short-term behavioral patterns within network telemetry. The model uses this convolutional representation to discover spatial relationships which exist between different traffic features.

Proposed system model for malware and botnet detection using F-CSTFNet.

The Swin Transformer attention mechanism captures temporal relationships within traffic sequences. The shifted-window attention structure allows the model to efficiently learn temporal interactions across traffic sequences without relying on recurrent architectures. The framework uses a hybrid convolution–attention design which enables simultaneous learning of short-term anomalies and long-term malicious activity patterns in IoT network traffic. The model trains distributed IoT environments through a federated learning training method which maintains user privacy. The client device performs local model training with its traffic data while only sending model parameters to the central aggregation server. The global model updates through the Federated Averaging (FedAvg) algorithm which enables shared learning between parties without the need for raw data exchange. The decentralized training method maintains data in its original location while allowing the system to scale up and protecting user privacy. The Marine Predator-Aided Gorilla Troops Optimization (MPAGTO) algorithm improves model performance through its use in hyperparameter tuning. MPAGTO achieves efficient hyperparameter space exploration through its combination of global exploration and local exploitation methods which lead to faster convergence times and better detection results in environments with limited resources.

The benchmark dataset provides complete traffic datasets which researchers use to study malware attacks and unusual network activities occurring in IoT systems. Each capture session (e.g., CTU-IoT-4-2, CTU-IoT-60-2) corresponds to a specific malware scenario, including variants such as Okiru, Mirai, Gafgyt, and Linux Hajime, which were collected under controlled experimental conditions by Stratosphere Laboratories. The fourth client who trained on the second part of N-BaIoT achieved top results through his 98.9% accuracy and 0.019 FCV and 0.948 TPSS performance. The model maintained high performance throughout the client period according to this evidence. The framework establishes its distributed IoT environment strength through its minor client performance differences which prove its system equity and system reliability. Our findings show that the F-CSTFNet + MPAGTO model enables privacy-preserving federated learning to support scalable IoT applications while delivering precise results and maintaining steady performance.

Conclusion and future work

The security of IoT systems requires better protection because malware and botnet attacks have increased due to their widespread adoption. This research introduced F-CSTFNet which serves as a distributed IoT intrusion detection system that uses a federated ConvNeXt–Swin temporal fusion framework. The model uses convolutional feature extraction together with transformer-based temporal attention to identify local traffic anomalies and long-range attack patterns while federated learning allows data sharing for training purposes without exposing raw data. The MPAGTO optimization strategy enables stable convergence behavior across different client environments. The proposed framework demonstrates high detection accuracy together with temporal consistency and client-level fairness improvements which were validated through experiments on the IoT-23 and N-BaIoT datasets. Edge devices experience resource limitations while large-scale federated systems face communication overhead problems and their performance suffers from non-IID data distributions. The distributed learning design together with the hybrid architecture and adaptive optimization strategy enables the framework to maintain strong scalability and adaptability which applies to all operational environments.

Future work will demonstrate how F-CSTFNet operates in actual IoT environments through its testing in extensive real-world scenarios. The assessment will expand to multiple operational locations through testing which uses streaming data that requires real-time processing and cross-domain validation across different IoT systems. The study will assess edge computing platform deployment and multi-access edge computing (MEC) environment testing through their implementation in real-world settings to evaluate system performance under actual operational conditions. The development of lightweight model optimization and communication-efficient federated learning and continual learning mechanisms will enable researchers to create systems which can better resist IoT security threats that keep changing.
