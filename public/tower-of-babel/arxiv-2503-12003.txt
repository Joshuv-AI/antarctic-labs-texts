Safety for Time-Varying Parameterized Sets Using Control Barrier Function Methods
James Usevitch, Jackson Sahleen

Abstract
A fundamental and classical problem in mobile autonomous systems is maintaining the safety of autonomous agents during deployment. Prior literature has presented techniques using control barrier functions (CBFs) to achieve this goal. These prior techniques utilize CBFs to keep an isolated point in state space away from the unsafe set. However, various situations require a non-singleton set of states to be kept away from an unsafe set. Prior literature has addressed this problem using nonsmooth CBF methods, but no prior work has solved this problem using only “smooth” CBF methods. This paper addresses this gap by presenting a novel method of applying CBF methods to non-singleton parameterized convex sets. The method ensures differentiability of the squared distance function between ego and obstacle sets by leveraging a form of the log-sum-exp function to form strictly convex, arbitrarily tight overapproximations of these sets. Safety-preserving control inputs can be computed via convex optimization formulations. The efficacy of our results is demonstrated through multi-agent simulations.



I
Introduction

Maintaining safety is a fundamental task of mobile autonomous systems.
A popular family of methods used in prior literature to accomplish this task is that of control barrier functions (CBFs) combined with online convex optimization to compute safety-preserving control inputs.
These methods have mainly been used to keep a single point or state within a safe set and away from the opposing unsafe set.
CBF methods have proven to be powerful in a variety of settings including multi-agent collision avoidance

[

.
A more complete overview of applications may be found in

.

There are situations, however, in which it is necessary to guarantee safety for an entire
set of points
rather than a single point.
Examples include a robot with a polytope-shaped body that must avoid collisions with external obstacles, or a set of multiple agents collaboratively carrying a heavy object in a formation where the convex hull must avoid collisions. Maintaining safety in these scenarios may be accomplished in specific cases by defining an ellipsoid-shaped safe set CBF surrounding a single point, but these overapproximations may be too conservative for certain scenarios. This motivates the problem of generalizing CBF methods to
guarantee safety for
entire sets
rather than single points in the state space.
This problem was first considered in
[
13
,
14
,
15
]
, which presented methods to guarantee safety and compute safety-preserving control inputs for convex ego sets. However, these methods rely on nonsmooth control barrier functions (NCBFs) which require special considerations when implementing in practice such as tracking the almost active constraints and a potentially increased number of QP constraints.

This paper considers the following question: Is it possible to apply CBF methods to guarantee safety of sets without resorting to NCBF techniques? Our results answer this question in the affirmative. More specifically, given a time-varying parameterized ego set, we present a novel method to compute control inputs that prevent the ego set from intersecting with an unsafe set. Our method does not require the use of NCBF methods, and control inputs can be computed using convex optimization formulations.
Our specific contributions in this paper are summarized as follows:

•

We present a novel method to compute safety-preserving control inputs for an ego set using convex optimization. Our method does not require the use of discontinuous systems theory and can be applied to a large class of compact sets defined by convex inequalities.

•

We present a novel method to approximate the squared distance between convex sets in a differentiable form. The approximation can be made arbitrarily tight, has guaranteed unique optimal points, and is differentiable with respect to the set parameters.

Problem Formulation

We consider the state space

We also consider a convex and compact parameterized ego set

where
{\color[rgb]{0,0,0}\bm{\lambda}_{E}}:\mathbb{R}\rightarrow\mathbb{R}^{M_{E}}

\displaystyle{\color[rgb]{0,0,0}\dot{\bm{\lambda}}_{E}}=\bm{f}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})+\bm{g}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\bm{u}.

(2)

The functions

,
\bm{g}:\mathbb{R}^{N_{E}}\rightarrow\mathbb{R}^{N_{E}\times P_{E}}
are assumed to be locally Lipschitz continuous in their argument.
The ego set’s dependence on
{\color[rgb]{0,0,0}\bm{\lambda}_{E}}(t)
will be omitted for brevity when the context is clear.

Definition 2
.

We say that a set-valued map
S:\mathbb{R}^{M^{\prime}}\to 2^{\mathbb{R}^{N}}
satisfies the standard conditions if all of the following properties hold:

1)

The set
S(\bm{\lambda}^{\prime})
is convex, compact and has nonempty interior for all
\bm{\lambda}^{\prime}\in\mathbb{R}^{M^{\prime}}
.

2)

There exist convex functions

such that

,
\forall k=1,\ldots,n_{F}
where

3)

The functions
\frac{\partial F^{k}}{\partial x}
are continuously differentiable in

and twice continuously differentiable in
\bm{x}
.

Assumption 2
.

The sets
S_{E}
and
\overline{S}_{j}\ \forall j\in\{1,\ldots,J\}

For brevity, we define

Assumption 3

The gradient matrices

The work in

(3)

III-C

Computation of Safety-Preserving Control Inputs Using Convex Optimization

We are now ready to derive a solution to Problem
1
.
The objective of ensuring
S_{E}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\subset S(\bm{\lambda})\ \forall t\geq t_{0}
is equivalent to ensuring that the ego set never intersects with the unsafe set; i.e.,
S_{E}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\cap\overline{S}(\bm{\lambda})=\emptyset\ \forall t\geq t_{0}
. By Assumption 1, a sufficient condition for this is that the ego set never intersects with any of the unsafe subsets
\overline{S}_{j}(\bm{\lambda}_{j})
; i.e.,
S_{E}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\cap\overline{S}_{j}(\bm{\lambda}_{j})=\emptyset\ \forall j\in\{1,\ldots J\},\ \forall t\geq t_{0}
.

Let
R>0
be a specified safety distance and consider the following family of
functions describing each unsafe subset indexed by
j
:

\displaystyle h_{j}({\color[rgb]{0,0,0}\bm{\lambda}_{E}(t)},\bm{\lambda}_{j}(t))\triangleq d_{\epsilon}^{+}({\color[rgb]{0,0,0}\bm{\lambda}_{E}(t)},\bm{\lambda}_{j}(t))-R.

(17)

It follows that
h_{j}({\color[rgb]{0,0,0}\bm{\lambda}_{E}},\bm{\lambda}_{j})\geq 0
implies safety in the sense that
S_{E}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\cap\overline{S}_{j}(\bm{\lambda}_{j})=\emptyset
.
The following well-known Lemma establishes conditions on
\dot{h}_{j}
to guarantee that
h_{j}({\color[rgb]{0,0,0}\bm{\lambda}_{E}},\bm{\lambda}_{j})\geq 0
for forward time
t\geq t_{0}
.

Lemma 8

(
[
25
]
, Lemma 2 )
.

Let
\alpha:\mathbb{R}\rightarrow\mathbb{R}

\mathcal{K}

In light of Lemma
8
, we seek to ensure that
\dot{h}_{j}(t)\geq-\alpha(h_{j}(t))

\mathcal{K}

\alpha

{\color[rgb]{0,0,0}\dot{\bm{\lambda}}_{E}}=\bm{f}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})+\bm{g}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\bm{u}

The gradients

Since the left hand side of (

\displaystyle\text{s.t. }\frac{\partial h_{j}}{\partial{\color[rgb]{0,0,0}\bm{\lambda}_{E}}}\left(\bm{f}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})+\bm{g}({\color[rgb]{0,0,0}\bm{\lambda}_{E}})\bm{u}\right)+\frac{\partial h_{j}}{\partial\bm{\lambda}_{j}}\dot{\bm{\lambda}}_{j}\geq-\alpha(h_{j}({\color[rgb]{0,0,0}\bm{\lambda}_{E}},\bm{\lambda}_{j})).

In addition, (
18

As per Assumption
1

IV
Simulations

In this section, we demonstrate the efficacy of our method in computing safety-preserving control inputs for robot agents with the results of our simulations.

Our demonstrative simulation is run in Python version 3.12.

Our code uses the JAX package
[
27
]
for automatic differentiation and solving Quadratic Programs (QP) as well as the cvxpy and cvxpylayers packages
[
28
,
29
]
to solve non-QP convex optimization problems.

Our simulation consists of four robot agents with convex polytope-shaped bodies
traversing the environment
to reach their respective goal states.
Each individual agent
i\in 1,\ldots,4
, is represented as an ego set of points
S_{E}^{i}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})\subset\mathbb{R}^{2}
with a parameter vector
{\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}}=\begin{bmatrix}x_{c1}^{i}&x_{c2}^{i}&\theta^{i}\end{bmatrix}^{\intercal}
, where
\bm{x}_{c}^{i}=\begin{bmatrix}x_{c1}^{i}&x_{c2}^{i}\end{bmatrix}^{\intercal}
is the Euclidean position of the agent and
\theta^{i}
is the orientation of the agent as an angle
counterclockwise from the positive x-axis in radians
.
The set
S_{E}^{i}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})
has the form of a rigid polytope, i.e., halfspace inequalities in the form
A^{i}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})\bm{x}+\bm{b}^{i}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})\leq 0
,
\bm{x}\in\mathbb{R}^{2}
, with position and orientation determined by the values of
{\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}}
.

The agents have unicycle dynamics in
\mathbb{R}^{2}
with its state being the origin frame of its set.
The unicycles are controlled by input-output linearization
[
30
]
with each agent having the output
\bm{y}^{i}=\begin{bmatrix}y_{1}^{i}&y_{2}^{i}\end{bmatrix}^{\intercal}
defined as
\begin{bmatrix}y_{1}^{i}\\
y_{2}^{i}\end{bmatrix}=\begin{bmatrix}x_{c1}^{i}+b\cos{\theta^{i}}\\
x_{c2}^{i}+b\sin{\theta^{i}}\end{bmatrix},\ b>0
.
The output
\bm{y}^{i}
is treated as having single integrator dynamics
\dot{\bm{y}^{i}}=\bm{u}^{i}=\begin{bmatrix}u_{1}^{i}&u_{2}^{i}\end{bmatrix}^{\intercal}
.
The control inputs for the unicycle dynamics
\begin{bmatrix}v^{i}&\omega^{i}\end{bmatrix}^{\intercal}
are then computed using the transformation
\begin{bmatrix}v^{i}\\
\omega^{i}\end{bmatrix}=T^{-1}(\theta^{i})\bm{u}^{i}=\begin{bmatrix}\cos{\theta^{i}}&\sin{\theta^{i}}\\
-\frac{\sin{\theta^{i}}}{b}&\frac{\cos{\theta^{i}}}{b}\end{bmatrix}\begin{bmatrix}u_{1}^{i}\\
u_{2}^{i}\end{bmatrix}.

During the simulation, each agent is nominally controlled by a go-to-goal control law defined as
\bm{u}_{nom}^{i}=-k_{u}(\bm{x}_{c}^{i}-\bm{x}_{c,goal}^{i})
; where
k_{u}>0
is a scalar control gain and
\bm{x}_{c,goal}^{i}=\begin{bmatrix}x_{c1,goal}^{i}&x_{c2,goal}^{i}\end{bmatrix}^{\intercal}
is the agent’s goal position.
The agents each minimally modify their nominal control input
\bm{u}_{nom}
using the functions
h_{j}
as described in algorithm
1
.
Each agent
i\in 1,\ldots,4
runs the algorithm with
\overline{S}^{i}(\bm{\lambda})=\bigcup_{j\neq i}S_{E}^{j}(\bm{\lambda}_{j})
where
\bm{\lambda}_{j}={\color[rgb]{0,0,0}\bm{\lambda}_{E}^{j}}
.
Since the control input of the input-output linearized dynamics is in terms of
\dot{\bm{y}}
, we made the following adjustment to the dynamics equations to account for this:
{\color[rgb]{0,0,0}\dot{\bm{\lambda}}_{E}^{i}}=\bm{f}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})+\tilde{\bm{g}}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})\bm{u}^{i},

\tilde{\bm{g}}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})=\bm{g}({\color[rgb]{0,0,0}\bm{\lambda}_{E}^{i}})T^{-1}(\theta^{i}).

The matrix
T^{-1}(\theta^{i})
is the transform matrix that converts from
\dot{\bm{y}}^{i}
back to
\begin{bmatrix}v&\omega\end{bmatrix}^{\intercal}
.
This form allows us to use the functions

V
Conclusion

This paper presented a novel method to compute control inputs that prevent a parameterized time-varying ego set from intersecting with an unsafe set using convex optimization formulations. The method leveraged a log-sum-exp-based approximation of the squared minimum distance between sets that can be tightened to an arbitrary degree. Future work will investigate extensions of this method to multi-robot systems with high relative degree safety constraints.
