Abstract
. We study linear orderings expanded by functions for successor and predecessor. In particular, the sp-homogeneous and weakly sp-homogeneous linear orderings are those which are homogeneous or weakly homogeneous with this additional structure. We demonstrate that these orderings are always relatively Δ 4 \Delta_{4} categorical and determine exactly which ones are (uniformly) relatively Δ 3 \Delta_{3} categorical. We also provide a classification for sp-homogeneity and weak sp-homogeneity. We establish that this is the best possible classification by showing that the set of sp-homogeneous linear orderings is Π 5 0 \Pi_{5}^{0} -complete and that the set of weakly sp-homogeneous linear orderings is Σ 6 0 \Sigma_{6}^{0} -complete. This result is obtained in two different ways, one using a hands-on computability theoretic approach and another using more abstract descriptive set theory. In understanding the categoricity and classification of sp-homogeneous orderings, we define a sequence of strong homogeneity notions that approximate sp-homogeneity called C n , m C_{n,m} -homogeneity. For finite values of n , m n,m there are only finitely many C n , m C_{n,m} -homogeneous orderings, and these are very closely related to the homogeneous colored linear orderings with finitely many colors. We provide an analytic-combinatorial analysis of the number of C n , m C_{n,m} -homogeneous orderings and the number of homogeneous colored linear orderings with k k colors, resulting in precise asymptotic bounds for these sequences.



1.
Introduction

Mathematical logic provides various precise methods of understanding what the simplest structures of a given theory are.
One of the most well known and well studied simplicity notions comes from model theory.
A structure
\mathcal{A}
is said to be
homogeneous
, if any isomorphism
between finitely generated substructures extends to an automorphism
of
\mathcal{A}
.
Homogeneous structures were first studied
by Fraïssé
[
7
]
, who defined the
age
of a structure

\mathcal{A}
to be the family of finitely generated substructures of
\mathcal{A}
and
gave properties that characterized the age of a homogeneous
structure.
In the many years since then, the study of homogeneous structures has developed into an important endeavor in model theory and, perhaps more surprisingly, computable structure theory (see, for example,
[
11
,
12
]
).
In
[
1
]
, Adams and Cenzer defined the notion of
weakly homogeneous
structures,
where
\mathcal{A}
is weakly homogeneous if there is a
finite (
exceptional
) set of elements
a_{1},\dots,a_{n}
of
\mathcal{A}
such that any isomorphism between finitely generated substructures
\mathcal{A}
which maps each
a_{i}
to itself may be extended to an automorphism of the structure.
This extension appreciably expands the class of homogeneous structure while still maintaining many of the properties enjoyed by homogeneous structures.

Considerable progress has been made concerning the analysis of weakly homogeneous structures.
The initial analysis in
[
1
]
focused on linear orderings, equivalence structures, injection structures, and trees.
In each case, the weakly homogeneous structures were characterized.
For instance, it is well known that the only countable, homogeneous linear ordering is
(\mathbb{Q},<)
, the order type of the rationals. It was shown that the only weakly homogeneous linear orderings are those with finitely many successivities.
These are also known to be the linear orderings that are relatively computably categorical, i.e., such that any two copies
\mathcal{A}
and
\mathcal{B}
have an isomorphism
f:\mathcal{A}\to\mathcal{B}
that can be given by an algorithm based only on the information of
\mathcal{A}
and
\mathcal{B}
.
This is not a coincidence.
The key result of
[
1
]
shows that there is an interesting connection between weak homogeneity and computability-theoretic properties of a structure.

1.1
.

(1)

If a structure
\mathcal{A}
is weakly homogeneous, then it is relatively
\Delta^{0}_{2}
categorical.

(2)

If a structure
\mathcal{A}
is locally finite and weakly homogeneous, then it is relatively computably categorical.

The notion of relative computable categoricity is well studied in computable structure theory as an alternate notion of simplicity for structures.
Extensions of this idea, such as the relative
\Delta_{2}^{0}
categoricity mentioned above, form a hierarchy of complexity above relative computable categoricity with each level allowing more computational power to calculate isomorphisms between copies of the given structure.
The above theorem connects the purely model theoretic notion of weak homogeneity and the computability theoretic categoricity hierarchy, suggesting that this fortuitous connection merits further investigation.
An important problem here is whether the converse of this result holds in general or for certain classes of structures.
As we observed for plain linear orderings, the converse of the above result holds.
This is also the case for equivalence relations.
It was shown in
[
1
]
that this is not the case for trees under the predecessor function, and that not every relatively
\Delta^{0}_{2}
categorical injection structure is weakly homogeneous, even though every computably categorical injection structure is.
More recent work in
[
2
]
analyzed Boolean algebras and abelian
p
-groups.
In both classes, they provided characterizations of the weakly homogeneous structures.
The main result in
[
2
]
was that there are computably categorical abelian
p
-groups that are not weakly homogeneous, yet every computable categorical Boolean algebra is weakly homogeneous.

With all of this in mind, we take a different approach to weak homogeneity in this paper.
We consider linear orderings, but not the plain linear orderings considered in
[
1
]
.
Instead, we analyze linear orderings with additional structure; we add a function that outputs the successor of each point, should it exist, or returns the same point if there is no successor and an analogous function for the predecessor.
We study linear orderings that become homogeneous or weakly homogeneous when enriched with this additional structure, or so-called
sp-homogeneous
or
weakly sp-homogeneous
orderings.

It is considerably more interesting to study
sp
-homogeneity for linear orderings over plain homogeneity.
It is simply a far richer class of orderings.
Most saliently, sp-homogeneous linear orderings pierce farther into the categoricity hierarchy than their plainly homogeneous cousins.
We see in this paper that all weakly sp-homogeneous orderings are relatively
\Delta_{4}
categorical, and many of them achieve this level of categoricity.
Only the
\Delta_{1}
and
\Delta_{2}
levels of relative categoricity are well understood for linear orderings (see
[
14
,
13
]
), and, indeed all orderings at these levels are

-homogeneous.
There is good reason to believe that even relative
\Delta_{3}
categoricity for linear orderings is fundamentally difficult to understand in full generality.
This was first argued in
[
13
]
;
[
9
]
puts a point on this by showing a uniform way to transform any relatively computable categorical structure into a relatively
\Delta_{3}
categorical linear ordering.
This means that analyzing specific subclasses of orderings at the
\Delta_{3}

sp
-homogeneous linear orderings and weakly

-homogeneous linear orderings provide a large class of tangible examples that allow the exploration of these difficult-to-understand levels of complexity.
We provide a full classification of the categoricity levels of the

-homogeneous linear orderings.
Because the

Another key tool used to understand

It is perhaps surprising to see the study of categoricity and homogeneity interact non-trivially with analytic enumerative combinatorics.
This occurs because the countably infinite objects that we study are in bijection with some finite objects.
In particular, this bijection arises naturally when striving to understand the categoricity level of the orderings in question.
Once this bijection is fixed and it is clear that there are only finitely many linear orderings satisfying these homogeneity conditions, it is in fact very natural to try to enumerate these objects and understand their growth rates.

The paper is structured in seven sections, including this one containing introductory material.
The second section structurally classifies

In the third section, we show that this classification is best possible from a computability-theoretic perspective using index sets.
The fourth section mirrors the third and shows that our classification is best possible from a boldface, descriptive set-theoretic perspective.
The fifth section offers an alternate approach to our characterization by establishing a bijection between the

The sixth section regards relational approximations to

It uses these tools to begin to understand the issue of categoricity level for these orderings, and, in connection with the established material from the fifth section, provides the enumerative combinatorics analyzing the number of

Lastly, the seventh section finishes the analysis of categoricity level for

4.
Boldface Hardness

This section is dedicated to proving the boldface version of the results seen in Section
3
.
Instead of index sets for computable orderings, we work directly with presentations of countable linear orderings in the Polish space
Mod(LO)
.
While uniform relativization of the approach in Section
3
represents a possible approach to prove the theorems in this section, we instead offer a development more native to the descriptive set-theoretic viewpoint.
Our main tool is the boldface pair of structures theorem, a descriptive set-theoretic corollary of the classical result of Ash and Knight
[
4
]
.
This approach has been taken before, see for example
[
10
]
Theorem 2.2 or Section 5 of
[
5
]
.
The key to this approach is that there is a connection between boldface hardness theorems at the standard, asymmetric back-and-forth relations.

4.1
.

The standard asymmetric back-and-forth relations
\leq_{\alpha}
, for a countable ordinal
\alpha<\omega_{1}
, are defined by the following:

•

(\mathcal{M},\bar{a})\leq_{0}(\mathcal{N},\bar{b})
if
\bar{a}
and
\bar{b}
satisfy the same quantifier-free formulas from among the first
|\bar{a}|
-many formulas.

•

For
\alpha>0
,
(\mathcal{M},\bar{a})\leq_{\alpha}(\mathcal{N},\bar{b})
if for each
\beta<\alpha
and
\bar{d}\in\mathcal{N}
there is
\bar{c}\in\mathcal{M}
such that
(\mathcal{N},\bar{b}\bar{d})\leq_{\beta}(\mathcal{M},\bar{a}\bar{c})
.

We define
\bar{a}\equiv_{\alpha}\bar{b}
if
\bar{a}\leq_{\alpha}\bar{b}
and
\bar{b}\leq_{\alpha}\bar{a}
.

These relations are usually conceptualized as a game between the Spoiler, who moves first and picks a tuple of elements in alternating structures, and the Duplicator, who moves in response to this choice of tuple in the other structure.
The Spoiler attempts to copy the behavior exhibited by the Spoiler’s choices and wins if they can do this until an ordinal clock expires.
This is useful for our purposes because of the aforementioned pair of structures theorem.

4.2
[
4
]
.

\mathcal{A}\leq_{\alpha}\mathcal{B}
if and only if
(Copies(\mathcal{A}),Copies(\mathcal{B}))
is
(\mathbf{\Sigma}_{\alpha}^{0},\mathbf{\Pi}_{\alpha}^{0})-
hard.

This means that we can arrive at our desired result by carefully considering the back-and-forth relations between selected countable linear orderings.
The following are fundamental and extremely useful facts about calculating the back-and-forth relations for linear orderings seen in Lemma 15.8 of
[
3
]
.

4.3
[
3

Suppose

\mathcal{A}\leq_{1}\mathcal{B}

For

\mathcal{A}\leq_{\alpha}\mathcal{B}

with endpoints in

We begin by comparing the following two closely related shuffle sums.

4.5
.

Sh(\omega+1)\leq_{4}Sh(\omega).

Proof.

We provide a winning strategy for Duplicator in this game.
Let
\iota:Sh(\omega)\to Sh(\omega+1)
be the natural embedding whose image is all of the blocks of finite size.
Say that Spoiler plays
\bar{p}

Duplicator can respond with the play of
\iota(\bar{p})

Note that the non-empty intervals defined by

are all isomorphic to
Sh(\omega)

Similarly, the non-empty itervals defined by
\iota(\bar{p})
are all isomorphic to
Sh(\omega+1)

Therefore, this first move wins if and only if

Sh(\omega)\leq_{3}Sh(\omega+1).

Say that Spoiler plays
\bar{q}_{1}<\cdots<\bar{q}_{n}
as their first move in this new game, where each
\bar{q}_{i}
is a set of successors.
Without loss of generality, if
\bar{q}_{i}
is in a finite block, it saturates this block, and if it is in a block of order type
\omega

\omega

In response to this move, Duplicator plays
\bar{r}_{1}<\cdots<\bar{r}_{n}

If
\bar{q}_{i}
is from a finite block the interval after it has order type

is from an
\omega

are all isomorphic to

Sh(\omega)\geq_{2}Sh(\omega+1)\text{ and }Sh(\omega)\geq_{2}\omega+Sh(\omega+1).

5.

The purpose of this section is to establish a correspondence between

The purpose of this is twofold.
First, it aims to give an explicit method of constructing

The general method of Coefficient Asymptotics for meromorphic functions applies.

7.18
