A Note on Fine-Grained Quantum Reductions for Linear Algebraic Problems
Kyle Doney, Cameron Musco

Abstract
We observe that any T ⁡ ( n ) T(n) time algorithm (quantum or classical) for several central linear algebraic problems, such as computing det ( 𝐀 ) \det(\mathbf{A}) , tr ⁡ ( 𝐀 3 ) \mathrm{tr}(\mathbf{A}^{3}) , or tr ⁡ ( 𝐀 − 1 ) \mathrm{tr}(\mathbf{A}^{-1}) for an n × n n\times n integer matrix 𝐀 \mathbf{A} , yields a O ⁡ ( T ⁡ ( n ) ) + O ~ ​ ( n 2 ) O(T(n))+\tilde{O}(n^{2}) time quantum algorithm for n × n n\times n matrix-matrix multiplication. That is, on quantum computers, the complexity of these problems is essentially equivalent to that of matrix multiplication. Our results follow by first observing that the Bernstein-Vazirani algorithm gives a direct quantum reduction from matrix multiplication to computing tr ⁡ ( 𝐀𝐁𝐂 ) \mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C}) for n × n n\times n inputs 𝐀 , 𝐁 , 𝐂 \mathbf{A},\mathbf{B},\mathbf{C} . We can then reduce tr ⁡ ( 𝐀𝐁𝐂 ) \mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C}) to each of our problems of interest. For the above problems, and many others in linear algebra, their fastest known algorithms require Θ ⁡ ( n ω ) \Theta(n^{\omega}) time, where ω ≈ 2.37 \omega\approx 2.37 is the current exponent of fast matrix multiplication. Our finding shows that any improvements beyond this barrier would lead to faster quantum algorithms for matrix multiplication. Our results complement existing reductions from matrix multiplication in algebraic circuits [ BCS13 ] , and reductions that work for standard classical algorithms, but are not tight – i.e., which roughly show that an O ⁡ ( n 3 − δ ) O(n^{3-\delta}) time algorithm for the problem yields an O ⁡ ( n 3 − δ / 3 ) O(n^{3-\delta/3}) matrix multiplication algorithm [ WW10 ] .

Introduction

For many linear algebraic problems, such as matrix inversion, linear system solving, determinant computation, and the computation of function traces like
\mathrm{tr}(\mathbf{A}^{3})
or
\mathrm{tr}(\mathbf{A}^{-1})
, the best known algorithms for general
n\times n
input matrices run in
O(n^{\omega})
time, where
\omega\approx 2.37
is the exponent of fast matrix multiplication
[
AW24
]
. That
O(n^{\omega})
time is an upper bound for these problems is not surprising: all of them can be readily reduced to matrix multiplication with small overhead
[
BCS13
,
DDH07
]
. But the question is – why can’t we do better? Why do all of these problems seem to be as hard as matrix multiplication?

Reductions for Matrix-Output Problems.

For some problems, where the output is an
n\times n
matrix, one can readily answer this question by proving that their asymptotic complexity is equivalent to matrix multiplication via a reduction. E.g, we can observe that for any
\mathbf{A},\mathbf{B}
,

\small{\begin{pmatrix}\mathbf{I}&\mathbf{A}&\mathbf{0}\\
\mathbf{0}&\mathbf{I}&\mathbf{B}\\
\mathbf{0}&\mathbf{0}&\mathbf{I}\end{pmatrix}^{-1}=\begin{pmatrix}\mathbf{I}&-\mathbf{A}&\mathbf{A}\mathbf{B}\\
\mathbf{0}&\mathbf{I}&-\mathbf{B}\\
\mathbf{0}&\mathbf{0}&\mathbf{I}\end{pmatrix}}.

That is, by forming the
3n\times 3n
matrix on the lefthand side and inverting it, one can read off the matrix product
\mathbf{A}\mathbf{B}
. So, any algorithm for matrix inversion running in faster than
O(n^{\omega})
time would directly yield a faster matrix multiplication algorithm.

Reductions for Scalar-Output Problems.
For problems like
\det(\mathbf{A})
or
\mathrm{tr}(\mathbf{A}^{3})
, where the output is a scalar, establishing equivalence to matrix multiplication is harder. In the algebraic circuit model, one can use the Baur-Strassen theorem
[
BS83
]
to show that a circuit of size
T(n)
for these and many related problems yields an
O(T(n))
sized matrix multiplication circuit, establishing equivalence
[

,
BCS13
]
.
However, our understanding outside algebraic circuits is more limited.

Williams and Williams
[

]
show via a reduction that an

time algorithm for

implies an

time algorithm for Boolean matrix multiplication.

1.1
Tight Quantum Reductions From Matrix Multiplication

We observe that for many linear algebraic problems, tight reductions from matrix multiplication can be given by leveraging quantum computing. We first prove a result for
\mathrm{tr}(\mathbf{A}^{3})
, when
\mathbf{A}
is symmetric with bounded integer entries.
2

2

Requiring
\mathbf{A}

\mathbf{A}

Theorem 1
.

If there exists an algorithm (classical or quantum) that, given symmetric

with entries bounded in magnitude by
\mathrm{poly}(n)

\mathbf{A}\mathbf{B}
in time

Theorem

1
shows that the complexity of matrix multiplication and

,

would lead to progress on fast quantum matrix multiplication.

We can apply the reductions of

1.2
Proof Summary

Theorem

1
follows from an application of the powerful Bernstein-Vazirani theorem
[
BV93
]
, which shows that, given black-box access to a linear function
f(\mathbf{x})=\langle\mathbf{s},\mathbf{x}\rangle
, one can recover the coefficient vector
\mathbf{s}
using a single quantum query to the function with an equal superposition of all inputs.

First, we observe that the problem of computing
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
given
n\times n
integer matrices
\mathbf{A}
,
\mathbf{B}
, and
\mathbf{C}
can be reduced to computing
\mathrm{tr}(\mathbf{A}^{3})
with just a constant factor overhead. In particular, one can check that
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})=\frac{1}{6}\mathrm{tr}(\mathbf{M}^{3})
for the
3n\times 3n
symmetric matrix

\small\mathbf{M}=\begin{pmatrix}0&\mathbf{A}&\mathbf{C}^{T}\\
\mathbf{A}^{T}&0&\mathbf{B}\\
\mathbf{C}&\mathbf{B}^{T}&0\end{pmatrix}.

With this observation in hand, we turn our attention to reducing matrix multiplication to computing
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
. We can write
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})=\sum_{i,j}(\mathbf{A}\mathbf{B})_{ij}\mathbf{C}_{ji}
as a linear function in the entries of
\mathbf{C}
. In the algebraic circuit model, this immediately yields a reduction from matrix multiplication: given a circuit of size
T
for computing
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
, by the Baur-Strassen theorem
[
Pan78
,
BS83
]
, we can construct a circuit of size
O(T)
that computes all partial derivatives of this function as well. Since
\frac{\partial\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})}{\partial\mathbf{C}_{ji}}=(\mathbf{A}\mathbf{B})_{ij}
, this circuit thus directly outputs all entries of the matrix product
\mathbf{A}\mathbf{B}
.

For a quantum reduction, we will use exactly the same idea, except instead of applying Baur-Strassen, we apply the Bernstein-Vazirani theorem. That is, we think of
\mathbf{A}
and
\mathbf{B}
as fixed and use a single query to the linear function
f(\mathbf{C})=\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
(for which we have assumed we have an efficient algorithm) with an equal superposition over all possible
\mathbf{C}
. From this query, we can recover all coefficients of the function – i.e., all entries of
\mathbf{A}\mathbf{B}
. Accounting for the
\tilde{O}(n^{2})
cost overhead of implementing this method, including preparing the equal superposition of all inputs, yields
Theorem

1
. Using the techniques of
[
MNS+18
]
we can reduce computing
\mathrm{tr}(\mathbf{A}^{3})
, and in turn
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
to many other scalar-output linear algebra problems, yielding
Corollary

1
.

Preliminaries

2.1
Notation

Let
\mathbb{F}_{q}
denote the finite field containing
q
elements. Let
\Z
denote the integers. We represent matrices with bold uppercase letters – e.g.,
\mathbf{A}
.
\mathbf{A}_{ij}
denotes the
(i,j)
entry of
\mathbf{A}
. We denote the inner product over vectors
\mathbf{x},\mathbf{y}
in either
\mathbb{F}_{q}^{n}
or
\mathbb{Z}^{n}
as
\langle\mathbf{x},\mathbf{y}\rangle=\sum_{i=1}^{n}\mathbf{x}_{i}\mathbf{y}_{i}
.
Recall that for
n\times n
matrices
\mathbf{X}
and
\mathbf{Y}
the natural inner product is given by
\langle\mathbf{X},\mathbf{Y}\rangle=\mathrm{tr}(\mathbf{X}\mathbf{Y}^{T})=\sum_{i=1}^{n}\sum_{j=1}^{n}\mathbf{X}_{ij}\mathbf{Y}_{ij}
. Plugging in
\mathbf{X}=\mathbf{A}\mathbf{B}
and
\mathbf{Y}=\mathbf{C}^{T}
, we have
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})=\sum_{i=1}^{n}\sum_{j=1}^{n}(\mathbf{A}\mathbf{B})_{ij}\mathbf{C}_{ji}.

2.2
Computational Model and Representation of Numerical Values

Our results use the Bernstein-Vazirani algorithm to reduce matrix multiplication in a blackbox way to computing
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
. All other reductions, from
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
to
\mathrm{tr}(\mathbf{A}^{3})
and other linear algebraic problems are classical. Thus, we require only that, given an underlying algorithm for computing a function with runtime
T(n)
, we can implement a
phase oracle
(see
Appendix

A
for a formal definition) for computing that function on a quantum computer with cost
O(T(n))
. If the underlying algorithm is implemented in a standard random-access machine, this means that we need access to a quantum random-access memory with unit-cost read/write operations, along with standard quantum gates that can be run at unit cost. Prior work on quantum algorithms for linear algebraic computation uses similar models
[
LG12b
,
CGdW25
,
JKLGM16
]
.

For simplicity, we focus on integer input matrices with entries bounded in magnitude by
n^{c}
for any fixed
c>0
, or entries in
\mathbb{F}_{q}
with
q
bounded by
n^{c}
. The entries of these matrices and their products can be represented exactly using
O(\log(n))
bits – note that if
\mathbf{A},\mathbf{B}\in\Z^{n\times n}
have entries bounded in magnitude by
n^{c}
,
\mathbf{A}\mathbf{B}
has entries bounded in magnitude by
n^{2c+1}
. Arithmetic operations (e.g., multiplication, addition) on these entries can be performed in
\tilde{O}(\log(n))
time.

Our result in
Corollary

1
involves functions like
\mathrm{tr}(\mathbf{A}^{-1})
,
\log\det(\mathbf{A})
, and
\det(\mathbf{A})
that do not necessarily take integer values, and/or may take values exponentially large in
n
. Nevertheless, we can represent a
\frac{1}{\mathrm{poly}(n)}
relative error approximation (as required by
Corollary

1
) to any of these quantities using a floating point representation with an
O(\log n)
bit significand and an
O(\log n
bit exponent. We can again perform arithmetic operations on such representations in
\tilde{O}(\log n)
time, which is all our reductions require.

2.3
The Bernstein-Vazirani Theorem

The key quantum primitive that we use is the Bernstein-Vazirani theorem
[
BV93
]
, which allows recovering the coefficients of a linear function with just a single quantum query to the function. Traditionally, the theorem is stated for functions over
\mathbb{F}_{2}^{n}
. We use a simple generalization to
\mathbb{F}_{q}^{n}
, which we prove for completeness in
Appendix

A
. Our results for bounded integer matrices follow by working over a sufficiently large finite field to represent the range of possible integer outputs.

Theorem 2

(Bernstein-Vazirani Theorem)
.

For any
f:\mathbb{F}_{q}^{n}\rightarrow\mathbb{F}_{q}
of the form
f(\mathbf{x})=\langle\mathbf{s},\mathbf{x}\rangle
, where
\mathbf{s}\in\mathbb{F}_{q}^{n}
is a fixed vector, there exists a quantum algorithm that outputs
\mathbf{s}
with probability
1
using just a single call to an algorithm computing
f
and
\tilde{O}(n\log q)
additional time.

As a direct consequence of
Theorem

2
, we have the following reduction from matrix multiplication over
\mathbb{F}_{q}
to computing the trilinear form
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
,
which can be viewed as the function
f(\mathbf{C})=\sum_{i=1}^{n}\sum_{j=1}^{n}(\mathbf{A}\mathbf{B})_{ij}\mathbf{C}_{ji}=\langle\mathbf{A}\mathbf{B},\mathbf{C}^{T}\rangle
. This result mirrors what can be shown in the algebraic circuit model using e.g., the Baur-Strassen theorem
[
Pan78
,
BS83
]
.

Theorem 3

(Matrix Mult. to Trilinear Form)
.

If there exists an algorithm (classical or quantum) that, given
\mathbf{A},\mathbf{B},\mathbf{C}\in\mathbb{F}_{q}^{n\times n}
for
q=\mathrm{poly}(n)
computes
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
in
T(n)
time, then there exists a quantum algorithm that given
\mathbf{A},\mathbf{B}\in\mathbb{F}_{q}^{n\times n}
, computes
\mathbf{A}\mathbf{B}
in
T(n)+\tilde{O}(n^{2})
time.

Proof.

We directly apply
Theorem

2
where we ‘flatten’
\mathbf{A}\mathbf{B}
and
\mathbf{C}
and represent them as vectors
\mathbf{s}
and
\mathbf{x}
respectively in
\mathbb{F}_{q}^{n^{2}}
. A single call to our algorithm for computing
f(\mathbf{C})=\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})=\langle\mathbf{s},\mathbf{x}\rangle
allows us to recover
\mathbf{s}\in\mathbb{F}_{q}^{n^{2}}
, which we can then rearrange into the matrix product
\mathbf{A}\mathbf{B}\in\mathbb{F}_{q}^{n\times n}
.
∎

3.1
Classical Linear Algebraic Reductions

We first show that the problem of computing
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
can be reduced to computing
\mathrm{tr}(\mathbf{M}^{3})
for a constant sized larger symmetric matrix
\mathbf{M}
.

Proposition 1

(Trilinear Form to
\mathrm{tr}(\mathbf{A}^{3})
)
.

If there exists a
T(n)
time algorithm that given any symmetric
\mathbf{M}\in\mathbb{F}_{q}^{n\times n}
for
q=\mathrm{poly}(n)
outputs
\mathrm{tr}(\mathbf{M}^{3})
, then there exists a
T(3n)+\tilde{O}(n^{2})
time algorithm that, given any
\mathbf{A},\mathbf{B},\mathbf{C}\in\mathbb{F}_{q}^{n\times n}

outputs
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
.

Proof.

Given
\mathbf{A}
,
\mathbf{B}
,
\mathbf{C}\in\mathbb{F}_{q}^{n\times n}
, we first form the
3n\times 3n
symmetric matrix:

\small\mathbf{M}=\begin{pmatrix}0&\mathbf{A}&\mathbf{C}^{T}\\
\mathbf{A}^{T}&0&\mathbf{B}\\
\mathbf{C}&\mathbf{B}^{T}&0\end{pmatrix}.

This takes
\tilde{O}(n^{2})
time, accounting for the
O(\log n)
bit complexity of representing our matrix entries. The cube of
\mathbf{M}
is equal to:

\displaystyle\small\mathbf{M}^{3}=\begin{pmatrix}0&\mathbf{A}&\mathbf{C}^{T}\\
\mathbf{A}^{T}&0&\mathbf{B}\\
\mathbf{C}&\mathbf{B}^{T}&0\\
\end{pmatrix}^{3}

\displaystyle=\begin{pmatrix}\mathbf{AA}^{T}+\mathbf{C}^{T}\mathbf{C}&\mathbf{C}^{T}\mathbf{B}^{T}&\mathbf{A}\mathbf{B}\\
\mathbf{B}\mathbf{C}&\mathbf{A}^{T}\mathbf{A}+\mathbf{BB}^{T}&\mathbf{A}^{T}\mathbf{C}^{T}\\
\mathbf{B}^{T}\mathbf{A}^{T}&\mathbf{C}\mathbf{A}&\mathbf{CC}^{T}+\mathbf{B}^{T}\mathbf{B}\\
\end{pmatrix}\begin{pmatrix}0&\mathbf{A}&\mathbf{C}^{T}\\
\mathbf{A}^{T}&0&\mathbf{B}\\
\mathbf{C}&\mathbf{B}^{T}&0\\
\end{pmatrix}

\displaystyle=\begin{pmatrix}\mathbf{C}^{T}\mathbf{B}^{T}\mathbf{A}^{T}+\mathbf{A}\mathbf{B}\mathbf{C}&\_&\_\\
\_&\mathbf{B}\mathbf{C}\mathbf{A}+\mathbf{A}^{T}\mathbf{C}^{T}\mathbf{B}^{T}&\_\\
\_&\_&\mathbf{B}^{T}\mathbf{A}^{T}\mathbf{C}^{T}+\mathbf{C}\mathbf{A}\mathbf{B}\\
\end{pmatrix},

where in the last line, we do not calculate the off-diagonal blocks as they do not impact the trace.
From the cyclic property of trace, we have that
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})=\mathrm{tr}(\mathbf{B}\mathbf{C}\mathbf{A})=\mathrm{tr}(\mathbf{C}\mathbf{A}\mathbf{B})
. Further, since the trace is linear and since taking the transpose of a block does not change its trace, we have
\mathrm{tr}(\mathbf{M}^{3})=6\cdot\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
. Thus, since we can compute
\mathrm{tr}(\mathbf{M}^{3})
in
T(3n)
time, we can compute
\mathrm{tr}(\mathbf{A}\mathbf{B}\mathbf{C})
in
T(3n)+\tilde{O}(n^{2})
time as desired. ∎

We also state the following basic reduction, which allows us to reduce matrix multiplication over bounded integer matrices to multiplication over a sufficiently large finite field
\mathbb{F}_{q}
. Note that a reduction in the opposite direction (reducing finite field matrix multiplication to integer matrix multiplication) follows from the properties of modular arithmetic: one can simply take the output modulo
q
at the end of the computation.

Proposition 2

(Integer Multiplication via Finite Field Multiplication)
.

If there exists an algorithm that given any
\mathbf{A},\mathbf{B}\in\mathbb{F}_{q}^{n\times n}
for
q=\mathrm{poly}(n)
, computes
\mathbf{A}\mathbf{B}
in time
O(T(n))
time, then there exists an algorithm that, given
\mathbf{A},\mathbf{B}\in\mathbb{Z}^{n\times n}
, with entries bounded in magnitude by
\mathrm{poly}(n)
, computes
\mathbf{A}\mathbf{B}
in time
O(T(n))+\tilde{O}(n^{2})
.

Proof.

Assume that
\mathbf{A}
and
\mathbf{B}
are nonnegative with entries bounded in magnitude by
w=\mathrm{poly}(n)
. Fix
q=2^{k}
such that
w^{2}n\leq q\leq 2w^{2}n
so that
\mathbb{F}_{q}
is a finite field. One can check that the entries of
\mathbf{A}\mathbf{B}
are bounded by
w^{2}n
. Thus,
\mathbf{A}\mathbf{B}\mod q=\mathbf{A}\mathbf{B}
. So, if we simply let
\mathbf{A}_{q},\mathbf{B}_{q}\in\mathbb{F}_{q}^{n\times n}
represent
\mathbf{A}
and
\mathbf{B}
with their entries interpreted as elements in
\mathbb{F}_{q}
, we can compute
\mathbf{A}_{q}\mathbf{B}_{q}=\mathbf{A}\mathbf{B}\mod q=\mathbf{A}\mathbf{B}
in
O(T(n))
time, since
q=O(w^{2}n)=\mathrm{poly}(n)
. This gives the result in this case.

To handle
\mathbf{A},\mathbf{B}\in\Z^{n\times n}
with negative entries, we can simply shift them. Let
\mathbf{1}
be the
n\times n
all ones matrix. Let
\mathbf{A^{\prime}}=\mathbf{A}+w\mathbf{1}
and
\mathbf{B^{\prime}}=\mathbf{B}+w\mathbf{1}
. Since
\mathbf{A}^{\prime}
and
\mathbf{B}^{\prime}
are nonnegative with entries bounded in magnitude by
2w=\mathrm{poly}(n)
, we can multiply them in time
O(T(n))
using the reduction above. We can then extract the matrix product
\mathbf{A}\mathbf{B}
using the formula:

\displaystyle\mathbf{A}^{\prime}\mathbf{B}^{\prime}

\displaystyle=\mathbf{A}\mathbf{B}+w(\mathbf{A}\mathbf{1})+w(\mathbf{B}\mathbf{1})+w^{2}\mathbf{1}^{2}

\displaystyle\mathbf{A}\mathbf{B}

\displaystyle=\mathbf{A}^{\prime}\mathbf{B}^{\prime}-w(\mathbf{A}\mathbf{1})-w(\mathbf{B}\mathbf{1})-w^{2}\mathbf{1}^{2}.

We can compute
w(\mathbf{A}\mathbf{1})
,
(w\mathbf{B}\mathbf{1})
and
w^{2}\mathbf{1}^{2}
all in
\tilde{O}(n^{2})
time since all columns of
\mathbf{1}
are identical to each other. Thus, from the matrix product
\mathbf{A}^{\prime}\mathbf{B}^{\prime}
we can extract
\mathbf{A}\mathbf{B}
in
\tilde{O}(n^{2})
time. The total runtime is
O(T(n))+\tilde{O}(n^{2})
, giving the proposition
∎

If there exists an algorithm that, given symmetric
\mathbf{A}\in\Z^{n\times n}
with entries bounded in magnitude by
\mathrm{poly}(n)
computes a
\frac{1}{\mathrm{poly}(n)}
relative error approximation to any of the following functions in time
O(T(n))
, then there exists an algorithm that, given
\mathbf{A},\mathbf{B}\in\Z^{n\times n}
with entries bounded in magnitude by
\mathrm{poly}(n)
, computes
\mathbf{A}\mathbf{B}
in time
O(T(n))+\tilde{O}(n^{2})
.

•

\det(\mathbf{A})
,
\log\det(\mathbf{A})

•

\mathrm{tr}(\mathbf{A}^{-1})
for non-singular
\mathbf{A}
,
\mathrm{tr}(\exp(\mathbf{A}))
,
\mathrm{tr}(\mathbf{A}^{p})
for integer
p\geq 3

•

The
p^{th}
Schatten norm,
\|\mathbf{A}\|_{p}^{p}=\sum_{i=1}^{n}\sigma_{i}(\mathbf{A})^{p}
for any fixed
p\neq 1,2
.

•

The SVD entropy
\sum_{i=1}^{n}\sigma_{i}(\mathbf{A})\cdot\log\sigma_{i}(\mathbf{A}))
for non-singular
\mathbf{A}
.

Above
\sigma_{1}(\mathbf{A}),\ldots,\sigma_{n}(\mathbf{A})\geq 0
are the singular values of
\mathbf{A}
.

Proof.

We apply Theorem 15 (and the resulting corollaries) of
[
MNS+18
]
with a few minor modifications. They state their reduction from triangle counting (i.e., determining if
\mathrm{tr}(\mathbf{A}^{3})>0
for symmetric binary
\mathbf{A}
) rather than computing
\mathrm{tr}(\mathbf{A}^{3})
. However, it is not hard to check that the reduction indeed exactly computes
\mathrm{tr}(\mathbf{A}^{3})
and holds as long as
\mathbf{A}
is symmetric and has integer entries bounded by
\mathrm{poly}(n)
. Additionally, their reductions determine
\mathrm{tr}(\mathbf{A}^{3})
by computing
f(\mathbf{B})
for
\mathbf{B}=\mathbf{I}-\delta\mathbf{A}
where
\delta=\frac{1}{\mathrm{poly}(n)}
. In our setting, we need
\mathbf{B}
to have integer entries. So, we instead work with
\mathbf{B}=\frac{1}{\delta}\mathbf{I}-\mathbf{A}
, which is integer, with
\mathrm{poly}(n)
bounded entries. Finally,
[
MNS+18
]
uses the real-RAM model, and thus does not consider the cost of representing the entries in
f(\mathbf{B})
. As discussed,
f(\mathbf{B})=\det(\mathbf{B})
and
f(\mathbf{B})=\mathrm{tr}(\mathbf{B}^{-1})
can potentially be as large as
\exp(\mathrm{poly}(n))
. Nevertheless, using a floating point representation, we can represent
f(\mathbf{B})
to
\frac{1}{\mathrm{poly}(n)}
relative accuracy using
O(\log n)
bits, and perform arithmetic operations on its value in
\tilde{O}(\log n)
time.
∎

3.2
Proof of Main Results

With the above preliminaries in place, we now prove our main results,

1
and
Corollary

.

Proof of
Theorem

1
.

Given
\mathbf{A},\mathbf{B}\in\Z^{n\times n}
with
\mathrm{poly}(n)
bounded entries, we apply
Proposition

2
to reduce computing their product to computing the product of
\mathbf{A}_{q},\mathbf{B}_{q}\in\mathbb{F}_{q}^{n\times n}
for some
q=\mathrm{poly}(n)
. We in turn reduce computing this product to computing
\mathrm{tr}(\mathbf{A}_{q}\mathbf{B}_{q}\mathbf{C}_{q})
for
\mathbf{A}_{q},\mathbf{B}_{q},\mathbf{C}_{q}\in\mathbb{F}_{q}^{n\times n}
via Bernstein-Vazirani, i.e.,
Theorem

3
. Finally, we reduce
\mathrm{tr}(\mathbf{A}_{q}\mathbf{B}_{q}\mathbf{C}_{q})
to computing
\mathrm{tr}(\mathbf{M}_{q}^{3})
for symmetric
\mathbf{M}_{q}\in\mathbb{F}_{q}^{3n\times 3n}
by

. This operation trivially reduces to computing
\mathrm{tr}(\mathbf{M}^{3})
for symmetric
\mathbf{M}\in\Z^{n\times n}
with
\mathrm{poly}(n)
bounded entries by taking the result modulo
q
. Each reduction incurs just a constant factor multiplicative runtime increase plus an additive
\tilde{O}(n^{2})
, giving our final claimed runtime of
O(T(n))+\tilde{O}(n^{2})
.
∎

Proof of
Corollary

1
.

We reduce computing
\mathbf{A},\mathbf{B}\in\Z^{n\times n}
with
\mathrm{poly}(n)
bounded entries to computing
\mathrm{tr}(\mathbf{M}^{3})
for symmetric
\mathbf{M}
with
\mathrm{poly}(n)
bounded entries via

. We in turn reduce this problem to any of the listed problems via

∎

4
Conclusion and Open Questions

Our observations help improve our understanding of why the complexity of solving many scalar-output linear algebra problems to high precision seems to be limited by
O(n^{\omega})
. There are many interesting open questions concerning the fine-grained complexity of these linear algebraic problems, on both classical and quantum computers, including:

•

Can we give a quantum reduction from matrix multiplication to computing
\mathbf{A}^{-1}\mathbf{x}
(i.e., solving a linear system)? One approach is to use Bernstein-Vazirani to extract
\mathbf{A}^{-1}
from the product
\mathbf{A}^{-1}\mathbf{x}
, and then use the classic reduction from matrix-multiplication to inversion. A similar idea with matrix-vector products has been used e.g., in
[
CHL21
,
LSZ21
]
. However, the challenge becomes that any algorithm for computing
\mathbf{A}^{-1}\mathbf{x}
will inherently be approximate, and the robustness of Bernstein-Vazirani to approximation error is unclear. For related work giving a classical reduction from the problem of rank finding (for which our best algorithms run in
O(n^{\omega})
time) to linear system solving, see
[
BV21
]
. It is not known how to reduce matrix multiplication to rank finding on a classic computer or an algebraic circuit – can we find such a reduction on quantum computers?

•

Related to the above, a noise robust version of Bernstein-Vazirani would conceivably allow computing the gradient of any function using just two black-box calls to the function via finite differencing. This would allow us to translate the Baur-Strassen theorem for algebraic circuits (and any reductions that it implies) to quantum computers. For related work on the connection between Bernstein-Vazirani and gradient computation, see
[
Jor05
]
.

•

Can we give any classical or quantum reduction from matrix multiplication to computing the spectral norm
\|\mathbf{A}\|_{2}
(i.e., the largest singular value of
\mathbf{A}
) to
\frac{1}{\mathrm{poly}(n)}
relative error? This quantity is notably not covered by the reductions of
[
MNS+18
]
.

•

Finally, an appealing but potentially difficult open question is to improve existing classical reductions. We know that an
O(n^{3-\delta})
time algorithm for
\mathrm{tr}(\mathbf{A}^{3})
gives an
O(n^{3-\delta/3})
time algorithm for Boolean matrix multiplication. Can we tighten this?

Appendix A
Bernstein-Vazirani Over Finite Fields

For completeness, we include a proof of the Bernstein-Vazirani theorem
[
BV93
]
for linear functions over
\mathbb{F}_{q}
. We start with some basic quantum computing preliminaries.

Quantum Representations of Field Elements.
We will represent
k\in\{0,\ldots,q-1\}
as an element in
\mathbb{F}_{q}
using
\lceil\log_{2}(q)\rceil
qubits. The corresponding quantum state will be written as
\ket{k}=\ket{k_{1},k_{2},...k_{\lceil\log_{2}(q)\rceil}}=\ket{k_{1}}\otimes\ket{k_{2}}\otimes...\otimes...\ket{k_{\lceil\log_{2}(q)\rceil}}
, where each
k_{i}
is a qubit representing a binary value and
\otimes
is the tensor product. For
\mathbf{y}\in\mathbb{F}_{q}^{n}
, its quantum state representation will be written as
\ket{\mathbf{y}}=\ket{\mathbf{y}_{1},\mathbf{y}_{2},\ldots,\mathbf{y}_{n}}=\ket{\mathbf{y}_{1}}\otimes\ket{\mathbf{y}_{2}}\otimes\ldots\otimes\ket{\mathbf{y}_{n}}
, where
\mathbf{y}_{1},\ldots,\mathbf{y}_{n}\in\mathbb{F}_{q}
are the entries of
\mathbf{y}
.

Definition A.1

(Quantum Fourier Transform over
\mathbb{F}_{q}
)
.

Let
\omega_{q}=e^{\frac{2\pi i}{q}}
. The quantum Fourier transform
QFT_{q}
maps any state
\ket{x}=\sum_{k=0}^{q-1}x_{k}\ket{k}
to
QFT_{q}\ket{x}=\sum_{j=0}^{q-1}y_{j}\ket{j}
, with

y_{j}=\dfrac{1}{\sqrt{q}}\sum_{k=0}^{q-1}x_{k}\omega^{jk}_{q}.

(1)

The inverse quantum Fourier transform
QFT_{q}^{-1}
similarly maps
\ket{x}
to
QFT_{q}^{-1}\ket{x}=\sum_{j=0}^{q-1}y_{j}\ket{j}
with
y_{j}=\frac{1}{\sqrt{q}}\sum_{k=0}^{q-1}x_{k}\omega_{q}^{-jk}
.
The cost of computing
QFT_{q}
or
QFT_{q}^{-1}
with a quantum circuit is
O(\log q\cdot\log(\log q)^{2}\cdot\log\log\log q)

[
CW00
]
.

The QFT is extended to length-
n
vectors via tensoring. In particular, for
\ket{\mathbf{x}}\in\mathbb{F}_{q}^{n}
,
QFT_{q}^{\otimes n}\ket{\mathbf{x}}=\bigotimes_{i=1}^{n}QFT_{q}\ket{\mathbf{x}_{i}}
. The runtime of computing this operation is just the runtime of computing each of the
n
individual QFTs, so
\tilde{O}(n\log q)
time. The extension of
QFT_{q}^{-1}
to vectors is analogous.

Definition A.2

(Phase Oracle)
.

A phase oracle for a function
f:\mathbb{F}_{q}^{n}\rightarrow F_{q}
is a unitary transformation
U_{f}
defined by
U_{f}\ket{\mathbf{x}}=\omega_{q}^{f(\mathbf{x})}\ket{\mathbf{x}}
for
\omega_{q}=e^{\frac{2\pi i}{q}}
.

We can now state the Berstein-Vazirani theorem over general finite fields.
Theorem

2
is a simplified version of this full statement.

Theorem 5

(Bernstein-Vazirani Theorem)
.

For any
f:\mathbb{F}_{q}^{n}\rightarrow\mathbb{F}_{q}
of the form
f(\mathbf{x})=\langle\mathbf{s},\mathbf{x}\rangle
, where
\mathbf{s}\in\mathbb{F}_{q}^{n}
is a fixed vector, there exists a quantum algorithm that outputs
\mathbf{s}
with probability
1
using just a single call to an phase oracle (
Definition

A.2
) for
f
and
\tilde{O}(n\log q)
additional time.

Proof.

The algorithm start with the all zeros vector
\ket{0}^{\otimes n}
. After applying the quantum Fourier transform to each entry, we obtain an equal superposition over all vectors in
\mathbb{F}_{q}^{n}
:

QFT_{q}^{\otimes n}\ket{\mathbf{x}}=QFT_{q}^{\otimes n}\ket{0}^{\otimes n}=\left[\dfrac{1}{\sqrt{q}}\sum_{y=0}^{q-1}\ket{y}\right]^{\otimes n}=\dfrac{1}{\sqrt{q^{n}}}\sum_{\mathbf{z}\in\mathbb{F}_{q}^{n}}\ket{\mathbf{z}}.

We then apply our phase oracle for
f(\mathbf{x})=\langle\mathbf{s},\mathbf{x}\rangle
to obtain:

U_{f}\;QFT_{q}^{\otimes n}\ket{0}^{\otimes n}=\dfrac{1}{\sqrt{q^{n}}}\sum_{\mathbf{z}\in\mathbb{F}_{q}^{n}}\omega_{q}^{f(\mathbf{z})}\ket{\mathbf{z}}=\dfrac{1}{\sqrt{q^{n}}}\sum_{\mathbf{z}\in\mathbb{F}_{q}^{n}}\omega_{q}^{\langle\mathbf{s},\mathbf{z}\rangle}\ket{\mathbf{z}}.

(2)

Since
\omega_{q}^{\langle\mathbf{s},\mathbf{z}\rangle}=\prod_{i=1}^{n}\omega_{q}^{\mathbf{s}_{i}\mathbf{z}_{i}}
we can expand (
2
) as a tensor product to obtain:

\displaystyle U_{f}\;QFT_{q}^{\otimes n}\ket{0}^{\otimes n}

\displaystyle=\sum_{\mathbf{z}\in\mathbb{F}_{q}^{n}}\bigotimes_{i=1}^{n}\left(\frac{1}{\sqrt{q}}\omega_{q}^{\mathbf{s}_{i}\mathbf{z}_{i}}\ket{\mathbf{z}_{i}}\right)

\displaystyle=\bigotimes_{i=1}^{n}\left(\sum_{z=0}^{q-1}\frac{1}{\sqrt{q}}\omega_{q}^{\mathbf{s}_{i}z}\ket{z}\right)

\displaystyle=\bigotimes_{i=1}^{n}QFT_{q}\ket{\mathbf{s}_{i}}=QFT_{q}^{\otimes n}\ket{\mathbf{s}}.

(3)

We now simply apply the inverse quantum Fourier transform to extract the vector
\mathbf{s}
. I.e., plugging into (
A
), we have
QFT_{q}^{-1\otimes n}\;U_{f}\;QFT_{q}^{\otimes n}\ket{0}^{\otimes n}=QFT_{q}^{-1\otimes n}\;QFT_{q}^{\otimes n}\ket{\mathbf{s}}=\ket{\mathbf{s}}.

The algorithm for computing
\mathbf{s}
thus requires one call to the phase oracle
U_{f}
along with one application each of
QFT_{q}^{\otimes n}
and
QFT_{q}^{-1\otimes n}
, taking time
\tilde{O}(n\log q)
.
∎
