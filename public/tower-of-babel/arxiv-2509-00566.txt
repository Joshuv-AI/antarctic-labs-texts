Sequences of surfaces in 4 4 -manifolds
Marina Ville

Abstract
Let ( Σ n ) (\Sigma_{n}) be a sequence of surfaces immersed in a 4 4 -manifold M M which converges to a branched surface Σ 0 \Sigma_{0} . We denote by k p T k^{T}_{p} (resp. k p N k^{N}_{p} ) the amount of curvature of the tangent bundles T ​ Σ n T\Sigma_{n} (resp. normal bundles N ​ Σ n N\Sigma_{n} ) which concentrates around a branch point p p of Σ 0 \Sigma_{0} when n n goes to infinity. Alternatively k T ± k N k^{T}\pm k^{N} measures how much the twistor degrees drop when we go from Σ n \Sigma_{n} to Σ 0 \Sigma_{0} . For complex algebraic curves, k T + k N = 0 k^{T}+k^{N}=0 .. In some instances - 1) if Σ 0 \Sigma_{0} is made up of at most 3 3 branched disks or 2) if Σ 0 \Sigma_{0} is area minimizing or 3) if the Σ n \Sigma_{n} ’s are minimal - we show that − k T ≥ | k N | -k^{T}\geq|k^{N}| and we investigate the equality case. When the second fundamental forms of the Σ n \Sigma_{n} ’s have a common L 2 L^{2} bound, we relate k T k^{T} and k N k^{N} to the bubbling-off of a current C C in the Grassmannian G 2 + ​ ( M ) G_{2}^{+}(M) . If the Σ n \Sigma_{n} ’s are minimal, C C is a complex curve.

k^{T}=-k^{N}=-3
. For every
\epsilon
glue to
\Gamma_{\epsilon}
a little handle closer and closer to the origin. This will not change
k^{N}
but
k^{T}
will become
-5
.

7.2
Immersed minimal disks

We recall (see for example [S-V3]) that a minimal disk in
\mathbb{R}^{4}
is given locally by a map from the disk
\mathbb{D}

F:\mathbb{D}\longrightarrow\mathbb{R}^{4}\cong\mathbb{C}^{2}

F:z\mapsto\Big(f_{1}(z)+\overline{f_{2}}(z),f_{3}(z)+\overline{f_{4}}(z)\Big)

(33)

where
f_{1},...f_{4}
are holomorphic functions verifying

f^{\prime}_{1}f^{\prime}_{2}+f^{\prime}_{3}f^{\prime}_{4}=0

(34)

After identifying
\mathbb{S}^{2}
to
\mathbb{C}P^{1}
and taking a stereographic projection, the Gauss maps
\gamma_{\pm}:\mathbb{D}\longrightarrow Z_{\pm}
are

\gamma_{+}=\frac{f^{\prime}_{3}}{f^{\prime}_{2}}\ \ \ \ \ \ \ \gamma_{-}=-\frac{f^{\prime}_{4}}{f^{\prime}_{2}}

(35)

\mbox{We pick}\ \ \ \ \ \ \ \ \ \ \ \ f^{\prime}_{1}=z^{2},f^{\prime}_{2}=z^{5},f^{\prime}_{3}=z^{3},f^{\prime}_{4}=-z^{4}

(36)

and derive a minimal map

z\mapsto(\frac{1}{3}z^{3}+\frac{1}{6}\bar{z}^{6},\frac{1}{4}z^{4}-\frac{1}{5}\bar{z}^{5})

(37)

Note that the knot of the branch point is a
(3,4)
torus knot.

We define a sequence of minimal immersions converging to (
37
) by

h^{(n)^{\prime}}_{1}=(z-\frac{1}{n})(z+\frac{1}{n}),h^{(n)^{\prime}}_{2}=z^{5},h^{(n)^{\prime}}_{3}=z^{2}(z-\frac{1}{n}),h^{(n)^{\prime}}_{4}=-z^{3}(z+\frac{1}{n})

(38)

Using (
35
), we see that the Gauss maps of the minimal surfaces defined by (
38
) are

\gamma^{(n)}_{+}=\frac{1}{z^{3}}(z-\frac{1}{n})\ \ \ \ \ \ \ \ \gamma^{(n)}_{-}=\frac{1}{z^{2}}(z+\frac{1}{n})

We notice that

\gamma^{(n)}_{+}(\frac{1}{n})=0\ \ \ \ \gamma^{(n)}_{+}(0)=\infty\ \ \ \ \ \ \gamma^{(n)}_{-}(-\frac{1}{n})=0\ \ \ \ \gamma^{(n)}_{-}(0)=\infty

So the limiting currents in
Z_{+}
and
Z_{-}
each contain at least two points; we derive from the proof of Proposition
7
1. that
k^{N}+k^{T}
and
k^{N}-k^{T}
are both non zero.
