Unbiased Single-Queried Gradient for Combinatorial Objective
Thanawat Sornwanee

Abstract
In a probabilistic reformulation of a combinatorial problem, we often face an optimization over a hypercube, which corresponds to the Bernoulli probability parameter for each binary variable in the primal problem. The combinatorial nature suggests that an exact gradient computation requires multiple queries. We propose a stochastic gradient that is unbiased and requires only a single query of the combinatorial function. This method encompasses a well-established REINFORCE (through an importance sampling), as well as including a class of new stochastic gradients.

Introduction

Many combinatorial optimization problems are easiest to interact with through a
pointwise oracle
: given a candidate binary vector
y\in\{0,1\}^{d}
, we can evaluate a quantity
Q(y)

Q

A natural way to bring gradient-based optimization to this setting is to relax discrete decisions into probability space, which is continuous. We consider a product-Bernoulli relaxation by considering a random variable

\displaystyle Y\sim P_{x}:=\bigotimes\text{Bernoulli}\left(x_{i}\right)

with

, and define the multilinear extension

\displaystyle v(x):

\displaystyle=\mathbb{E}_{Y\sim P_{x}}\left[Q(Y)\right]

\displaystyle=\sum_{y\in\{0,1\}^{d}}\left(Q(y)\prod_{i=1}^{d}\left[x_{i}y_{i}+(1-x_{i})(1-y_{i})\right]\right).

Since the domain of
Q
is finite,
v
is well-defined, and infinitely smooth.

In principle, gradient-based methods can optimize this relaxation, and then round back to a discrete solution. In practice, however, gradient estimation is the bottleneck when

Concretely, we construct a single-queried stochastic evaluation whose pathwise derivative exists and whose expected gradient matches

Why the obvious approach fails.

It is easy to obtain an unbiased value estimator with one query: sample a key
K(x)\sim P_{x}
(e.g., thresholding uniform noise) and return
V(x)=Q(K(x))
, so that
\mathbb{E}\left[V(x)\right]=v(x)
. It is then tempting to think that, with sufficient regularity,

\displaystyle\mathbb{E}\left[\nabla V(x)\right]=\nabla\mathbb{E}\left[V(x)\right]=\nabla v(x)=g(x),

so, by choosing
G(x)
to be
\nabla V(x)
, we have already solved the problem.
However, differentiating such an estimator pathwise is futile:
K(x)
is discrete, so
\nabla Q(K(x))
is either zero or undefined
2
2

2

In thresholding uniform noise method, it is zero almost surely since the boundary has zero measure.
, so

\displaystyle\mathbb{E}\left[\nabla V(x)\right]=0\neq\nabla\mathbb{E}\left[V(x)\right]

in general.

This is the core obstacle: we want single-query gradients, but the most natural single-query evaluations are not differentiable in a way that will be compatible to machine learning or optimization methods.

2.1
Score-function estimators and variance reduction

A standard tool for discrete random variables is the score-function estimator, widely known as REINFORCE

However, we will have that we cannot interpret

Our work is close in spirit to this line—seeking unbiased (or provably controlled-bias) gradients—while targeting a different regime where the oracle

3
Stochastic Gradient

The computation of the gradient
g(x)
itself may require multiple query to the function
Q
, so we relax the requirement into finding a “stochastic” gradient
G:(0,1)^{d}\to\mathbb{R}
where
G(x)
is defined upon the same random space for all
x\in(0,1)^{d}
such that

\displaystyle\mathbb{E}\left[G(x)\right]=g(x),

while only require a single query of
Q
per realization of
G(x)
. This also has to be universal across any oracle
Q:\{0,1\}^{d}\to\mathbb{R}
.

Note that, we have also relaxed the requirement of the domain from
[0,1]^{d}
to
(0,1)^{d}
, which will later be useful for defining the function. However, this relaxation is not problematic given that the corollary
B.2
implies continuity of gradient.

As we have seen earlier, an easy motivated example of the existence of such stochastic gradient is from that stochastic evaluation is trivial. However, if we want pathwise differentiation to exist in a correct way, we need more conditions, such as continuity after the thresholding.

To give some sufficient condition, we will first rigorously define a stochastic valuation with single query, and then provide some condition to ensure that we can define a stochastic gradient with single query
G(x)
to just be
\nabla V(x)
.

Throughout, we consider
\left(\Omega,\mathcal{F},\mathbb{P}\right)
to be a probability space, to be specified, and consider the function to be measurable with respect to
\left(\Omega,\mathcal{F}\right)
or jointly measurable with respect to an appropriate measurable space created by a combination of
\left(\Omega,\mathcal{F}\right)
, Borel
\sigma
-algebra, and powerset of a finite set

We want the function to be universal with respect to the query function
Q:\{0,1\}^{d}\to\mathbb{R}
, so we redefine
v:[0,1]^{d}\times\mathbb{R}^{\left(\{0,1\}^{d}\right)}\to\mathbb{R}
and
g:[0,1]^{d}\times\mathbb{R}^{\left(\{0,1\}^{d}\right)}\to\mathbb{R}^{d}
such that, for any
x\in[0,1]^{d}
,
Q:\{0,1\}^{d}\to\mathbb{R}
,

\displaystyle v(x;Q):

\displaystyle=\mathbb{E}_{Y\sim P_{x}}\left[Q(Y)\right]

\displaystyle=\sum_{y\in\{0,1\}^{d}}\left(Q(y)\prod_{i=1}^{d}\left[x_{i}y_{i}+(1-x_{i})(1-y_{i})\right]\right),

and

\displaystyle g(x;Q):=\nabla_{x}v(x;Q),

which is well-defined given the corollary
B.2
.

Definition 3.1
.

A function
G:(0,1)^{d}\times\Omega\times\mathbb{R}^{\left(\{0,1\}^{d}\right)}\to\mathbb{R}^{d}
is a single-queried stochastic gradient function with respect to
\left(\Omega,\mathcal{F},\mathbb{P}\right)
if there exists some key function
K:(0,1)^{d}\times\Omega\to\{0,1\}^{d}
, and some main function
f_{\text{g}}:(0,1)^{d}\times\Omega\times\mathbb{R}
such that, for every
x\in(0,1)^{d}
, and every
Q:\{0,1\}^{d}\to\mathbb{R}
,

\displaystyle G(x;\omega,Q):=f_{\text{g}}(x,\omega,Q(K(x;\omega)))

for
\mathbb{P}
-almost surely
\omega\in\Omega
,

\displaystyle\mathbb{E}\left[G(x;\omega,Q)\right]=g(x;Q).

Definition 3.2
.

A function
V:(0,1)^{d}\times\Omega\times\mathbb{R}^{\left(\{0,1\}^{d}\right)}\to\mathbb{R}
is a single-queried stochastic evaluation function with respect to
\left(\Omega,\mathcal{F},\mathbb{P}\right)
if there exists some key function
K:(0,1)^{d}\times\Omega\to\{0,1\}^{d}
, and some main function
f_{\text{v}}:(0,1)^{d}\times\Omega\times\mathbb{R}
such that, for every
x\in(0,1)^{d}
, and every
Q:\{0,1\}^{d}\to\mathbb{R}
,

\displaystyle V(x;\omega,Q):=f_{\text{v}}(x,\omega,Q(K(x;\omega)))

for
\mathbb{P}
-almost surely
\omega\in\Omega
,

\displaystyle\mathbb{E}\left[V(x;\omega,Q)\right]=v(x;Q).

This definition suggests the following necessary and sufficient condition:

Proposition 3.3
.

With respect to
\left(\Omega,\mathcal{F},\mathbb{P}\right)
,
V
is a stochastic evaluation function w with
f_{v}
and
K
as in the definition
3.2
if and only if, for all

,

, and

\displaystyle\mathbb{E}\left[f_{\text{v}}(x,\omega,q)\mathbf{1}_{K(x;\omega)=y}\right]=q\prod_{i=1}^{d}\left[x_{i}y_{i}+(1-x_{i})(1-y_{i})\right].

Recall that the gradient of the expected stochastic evaluation function may not be the same as the expected gradient of the stochastic evaluation function. If we want to have this property, we have to restrict it to a smaller class of stochastic functions.

Definition 3.4
.

A single-queried stochastic evaluation function

and any

\displaystyle\mathbb{E}\left[\nabla_{x}V(x;\omega,Q)\right]=\nabla_{x}v(x;Q),

and
\nabla_{x}V(x;\omega,Q)
exists for every
Q:\{0,1\}^{d}\to\mathbb{R}
, every
x\in(0,1)^{d}
, and
\mathbb{P}
-almost surely
\omega\in\Omega

Note that, we require almost surely

With respect to

3.1

We restrict the search to a simple formulation of the stochastic evaluation to find one that is gradientable. From the proposition

\displaystyle\mathbb{E}\left[\hat{f}_{\text{v}}(x,\omega)\mathbf{1}_{K(x;\omega)=y}\right]=\prod_{i=1}^{d}\left[x_{i}y_{i}+(1-x_{i})(1-y_{i})\right].

Calibration

4.1
Easy Stochastic Gradient is not Calibrated

A single-queried stochastic evaluation function
V
and a single-queried stochastic gradient function
G
requires a single query through the stochastic key
K
.

A possible conjecture as well as desiderata in some scenario is that
K(x)\sim P_{x}
, meaning that we check the query in the same way as the nature would have done.

Definition 4.1
.

(Calibrated Key)
With respect to
\left(\Omega,\mathcal{F},\mathbb{P}\right)
,
a single-queried stochastic evaluation function
V
is calibrated if there is a key function
K
via the definition
3.2
, and

\displaystyle K(x)\sim P_{x}

for all
x\in(0,1)^{d}
.
Similarly, a single-queried stochastic gradient function
G
is calibrated if there is a key function
K
via the definition
3.1
, and
K(x)\sim P_{x}
for all
x\in(0,1)^{d}
.

Thus, the stochastic evaluation of a form
V(x;\omega)=Q(K(x;\omega))
is always calibrated. However, so far, we have not established whether there exists a calibrated single-queried gradientable stochastic evaluation function. To explore this, we start by consider a class of easy stochastic evaluation function as introduced in the theorem
3.9
. We have that whether such evaluation is calibrated can be simply tested from the underlying good tuple
\left(f,\sigma,\hat{\sigma}\right)

.

A good stochastic evaluation function

\left(f,\sigma,\hat{\sigma}\right)

\sigma=\hat{\sigma}
.

Proof.

This comes directly from the lemma

, and how the key function is determined in the theorem
3.9
.
∎

Lemma 4.3

There is no good tuple

6
Conclusion

We proposed
Easy Stochastic Gradient (ESG)
, a new class of unbiased, single-queried gradient estimators for optimizing combinatorial objectives through their product-Bernoulli (multilinear) relaxation. The key idea is to construct a value estimator that is also pathwise differentiable, which reduce variance in some regime. Our framework unifies and connects to classical score-function methods (REINFORCE) via importance sampling, and it naturally generates a family of new estimators through the choice of underlying “good tuples”. In proof-of-concept experiments,
Single Query Descent (SQD)
instantiated with ESG achieved strong empirical performance relative to established unbiased estimators, while maintaining the critical property that each iteration requires only a single oracle evaluation.

Several directions remain open. First, developing
adaptive selection rules
that choose among unbiased estimators (or tune tuple families) based on the current state and observed history may further reduce variance and improve robustness across tasks. Second, extending the construction beyond product-Bernoulli structure could broaden applicability. Together, these results suggest that one-query, unbiased, autodiff-compatible optimization is a practical and promising avenue for large-scale combinatorial problems where oracle calls dominate cost.

Corollary B.1
.

The function
v:[0,1]^{d}\to\mathbb{R}
is well-defined and Lipschitz continuous.

Proof.

First, we note that
\sup_{y\in\{0,1\}^{d}}\left|Q(y)\right|<\infty
, so, for any
x\in[0,1]^{d}
,

\displaystyle\mathbb{E}_{Y\sim P_{x}}\left[\left|Q(Y)\right|\right]\leq\sup_{y\in\{0,1\}^{d}}\left|Q(y)\right|<\infty,

making

well-defined and bounded.

For any
x,x^{\prime}\in[0,1]^{d}
, we have that, for all
i\in\{1,2,\dots,d\}
,

\displaystyle\left\|\left[P_{x^{\prime}}\right]_{i}-\left[P_{x}\right]_{i}\right\|_{\text{TV}}=\left\|\text{Bernoulli}(x^{\prime}_{i})-\text{Bernoulli}(x_{i})\right\|_{\text{TV}}=\left|x^{\prime}_{i}-x_{i}\right|,

where
\left[\mu\right]_{i}
denotes the marginal distribution of
\mu\in\Delta\left(\left[0,1\right]^{d}\right)
on the

\displaystyle P_{x}=\bigotimes_{i=1}^{d}\left[P_{x}\right]_{i},

making

\displaystyle\left\|P_{x^{\prime}}-P_{x}\right\|_{\text{TV}}=\left\|\bigotimes_{i=1}^{d}\left[P_{x^{\prime}}\right]_{i}-\bigotimes_{i=1}^{d}\left[P_{x}\right]_{i}\right\|_{\text{TV}}\leq\sum_{i=1}^{d}\left\|\left[P_{x^{\prime}}\right]_{i}-\left[P_{x}\right]_{i}\right\|_{\text{TV}}=\left\|x^{\prime}-x\right\|_{1}.

Thus, we have that

\displaystyle\left|v(x^{\prime})-v(x)\right|\leq\left[\sup_{y\in\{0,1\}^{d}}Q(y)-\inf_{y\in\{0,1\}^{d}}Q(y)\right]\left\|P_{x^{\prime}}-P_{x}\right\|_{\text{TV}}\leq\left[\sup_{y\in\{0,1\}^{d}}Q(y)-\inf_{y\in\{0,1\}^{d}}Q(y)\right]\left\|x^{\prime}-x\right\|_{1},

so
v
is Lipschitz continuous.
∎

Appendix C
1-Dimensional Distribution

Definition C.1
.

A distribution
\sigma\in\Delta\left(\mathbb{R}\right)
is monotone in the interior region if, for any
z,z^{\prime}\in\mathbb{R}
with
z^{\prime}>z
and
\sigma(z)>0
, we have that
\sigma(z^{\prime})>\sigma(z)
.

Corollary C.2
.

If a distribution
\sigma
is monotone in the interior region, then
\text{support}(\sigma)
is a closed interval.

Proof.

Let
\underaccent{\bar}{z}
be
\inf\left(\left\{z\in\mathbb{R}:\sigma(z)>0\right\}\right)
, and
\bar{z}
be
\sup\left(\left\{z\in\mathbb{R}:\sigma(z)<1\right\}\right)
. Thus,
\text{support}(\sigma)\subseteq\left[\underaccent{\bar}{z},\bar{z}\right]
. Next, we will show that
\text{support}(\sigma)=\left[\underaccent{\bar}{z},\bar{z}\right]\cap\mathbb{R}
.

Since the support is closed by definition, we will have that, if
\text{support}(\sigma)\neq\left[\underaccent{\bar}{z},\bar{z}\right]\cap\mathbb{R}
, then, there exists a non-zero measure closed interval
[a,b]\subseteq\left(\underaccent{\bar}{z},\bar{z}\right)
such that
[a,b]\cap\text{support}(\sigma)=\emptyset
. However, since
\sigma(a)>0
, so
\sigma(b)>\sigma(a)
, contradicting with
[a,b]\cap\text{support}(\sigma)=\emptyset
.

Therefore,
\text{support}(\sigma)=\left[\underaccent{\bar}{z},\bar{z}\right]\cap\mathbb{R}
, which is a closed interval.
∎

Definition C.3
.

A distribution
\sigma\in\Delta\left(\mathbb{R}\right)
is non-atomic, if there does not exists any
z\in\mathbb{R}
with
\sigma\left(\{z\}\right)>0

Corollary C.4
.

If a distribution
\sigma
is non-atomic, then the CDF
\sigma
is continuous.

Proof.

Since CDF is right-continuous by definition, it then suffices to show that
\sigma
is left-continuous. This is true since, for any
z\in\mathbb{R}

\displaystyle\lim_{z^{\prime}\to z^{-}}\sigma(z)=\sigma\left(\bigcup_{z^{\prime}<z}\left(-\infty,z^{\prime}\right]\right)=\sigma\left(\left(-\infty,z\right)\right)=\sigma\left(\left(-\infty,z\right]\right)-\sigma\left(\{z\}\right)=\sigma(z)-0.

∎

Definition C.5
.

A distribution
\sigma\in\Delta\left(\mathbb{R}\right)
is well-invertible if, there exists a function
f:(0,1)\to\mathbb{R}
such that

\displaystyle z=f(\sigma(z))

for any
z\in\text{int}\left(\text{support}(\sigma)\right)
, and

\displaystyle x=\sigma\left(f(x)\right)

for any
x\in(0,1)
.

Proposition C.6
.

A distribution
\sigma\in\Delta\left(\mathbb{R}\right)
is well-invertible if and only if
\sigma
is monotone in the interior region and non-atomic.

Proof.

We first prove the backward direction. Assume that
\sigma
is monotone in the interior region and non-atomic. Define
\left(\underaccent{\bar}{z},\bar{z}\right)=\left(\inf(\text{support}(\sigma)),\sup(\text{support}(\sigma))\right)
, and a function
\hat{\sigma}:\left(\underaccent{\bar}{z},\bar{z}\right)\to[0,1]
such that
\hat{\sigma}
agrees with
\sigma
everywhere in its domain. We will have that
\hat{\sigma}
is an increasing function with range being
(0,1)
. Thus, by redefining
\hat{\sigma}:\left(\underaccent{\bar}{z},\bar{z}\right)\to(0,1)
, we will have that
\hat{\sigma}
is bijective, and a function
\hat{\sigma}^{-1}
is well-defined in a conventional inverse function sense. By choosing
f
to be
\hat{\sigma}^{-1}
, we will have that
\sigma
is invertible.

Next, we prove the forward direction. We assume that
\sigma
is well-invertible. Since the range of
\sigma
is a superset of
(0,1)
if and only if
\sigma
is non-atomic, so it is non-atomic. Assume that
\sigma
is not monotone in the interior. There exists
(a,b)\in\mathbb{R}^{2}
with

\sigma(a)=\sigma(b)\in(0,1)
. Since
\sigma
is non-atomic, we have that
a,b\in\text{int}(\text{support}(\sigma))
, but

\displaystyle a=f(\sigma(a))=f(\sigma(b))=b>a,

creating a contradiction. Thus,
\sigma
is monotone in the interior.
∎

Note that, if we only require the first condition, then the definition will be different. For example, there can be a point mass at
\inf(\text{support}(\sigma))
and
\sup(\text{support}(\sigma))

D.3
Technical Lemma

Lemma D.3
.

Assume
v:\mathcal{X}\to\mathbb{R}
for some
\mathcal{X}
is a set product of
d\in\mathbb{N}
non-empty open intervals, and
\nabla_{x}:\mathcal{X}\to\mathbb{R}^{d}
exists and is bounded.
For a probability space
\left(\Omega,\mathcal{F},\mathbb{P}\right)
, if
V:\mathcal{X}\times\Omega\to\mathbb{R}
be such that

\displaystyle\mathbb{E}\left[V(x;\omega)\right]=v(x)

for all
x\in\mathcal{X}
, and the following conditions hold:

1.

For
\mathbb{P}
-almost surely
\omega\in\Omega
, the function
V(\cdot;\omega)
is absolutely continuous;

2.

For all
x\in\mathcal{X}
, the gradient
\nabla_{x}V(x;\omega)
exists for
\mathbb{P}
-almost surely
\omega\in\Omega
;

3.

There exists an
L^{1}(\Omega)
function
g
such that

\displaystyle\left\|\nabla_{x}V(x;\omega)\right\|_{\infty}\leq g(\omega)

for all
x\in\mathcal{X}
,
\omega\in\Omega
,

then, for all
x\in\mathcal{X}
,

\displaystyle\nabla v(x)=\mathbb{E}\left[\nabla_{x}V(x;\omega)\right].

Proof.

For any
\omega\in\Omega
, where the function
V(\cdot,\omega)
is absolutely continuous, we have that there exists
\nabla_{x}V(x,\omega)
for almost every
x
, and, for any
x\in\mathcal{X}
, and any
e\in\mathbb{R}^{d}
with
\left\|e\right\|_{2}=1
, and
h>0
such that
x+he\in\mathcal{X}
, we will have that

\displaystyle V(x+he,\omega)-V(x,\omega)=\int_{t=0}^{1}he^{\top}\nabla_{x}V(x+the,\omega)dt.

Since this holds for
\mathbb{P}
-almost surely
\omega\in\Omega
,

\displaystyle\frac{v(x+he)-v(x)}{h}=\mathbb{E}\left[\frac{V(x+he,\omega)-V(x,\omega)}{h}\right]=\mathbb{E}\left[\int_{t=0}^{1}e^{\top}\nabla_{x}V(x+the,\omega)dt\right].

Since
\left\|e\right\|_{2}=1
, we have that, for all
t\in[0,1]
where the gradient exists,

\displaystyle\left|e^{\top}\nabla_{x}V(x+the,\omega)\right|\leq d\left\|\nabla_{x}V(x+the,\omega)\right\|_{\infty}\leq dg(\omega).

Thus, we have that

\displaystyle\mathbb{E}\left[\int_{t=0}^{1}e^{\top}\nabla_{x}V(x+the,\omega)dt\right]

\displaystyle=\int_{\omega\in\Omega}\int_{t=0}^{1}e^{\top}\nabla_{x}V(x+the,\omega)dt\mathbb{P}(d\omega)

\displaystyle\leq\int_{\omega\in\Omega}\int_{t=0}^{1}dg(\omega)dt\mathbb{P}(d\omega)

\displaystyle=\int_{\omega\in\Omega}dg(\omega)\mathbb{P}(d\omega)

\displaystyle<\infty.

Note that
\nabla_{x}V(x,\omega)
is jointly measurable in
\mathcal{B}\left(\mathbb{R}^{d}\right)\times\mathcal{F}
, so
e^{\top}\nabla_{x}V(x+the,\omega)
is jointly measurable in
\mathcal{B}([0,1])\times\mathcal{F}
. We can then apply Fubini’s theorem to get that

\displaystyle\frac{v(x+he)-v(x)}{h}=\int_{t=0}^{1}\mathbb{E}\left[e^{\top}\nabla_{x}V(x+the,\omega)dt\right],

making

\displaystyle\lim_{h\to 0}\frac{v(x+he)-v(x)}{h}=\lim_{h\to 0}\int_{t=0}^{1}\mathbb{E}\left[e^{\top}\nabla_{x}V(x+the,\omega)dt\right].

We further apply dominated convergence to get that

\displaystyle\lim_{h\to 0}\int_{t=0}^{1}\mathbb{E}\left[e^{\top}\nabla_{x}V(x+the,\omega)\right]dt

\displaystyle=\int_{t=0}^{1}\mathbb{E}\left[e^{\top}\left(\lim_{h\to 0}\nabla_{x}V(x+the,\omega)\right)\right]dt

\displaystyle=\int_{t=0}^{1}\mathbb{E}\left[e^{\top}\nabla_{x}V(x,\omega)\right]dt

\displaystyle=\mathbb{E}\left[e^{\top}\nabla_{x}V(x,\omega)\right].

Thus, we have that

\displaystyle e^{\top}\nabla v(x)=\lim_{h\to 0}\frac{v(x+he)-v(x)}{h}=\mathbb{E}\left[e^{\top}\nabla_{x}V(x,\omega)\right]=e^{\top}\mathbb{E}\left[\nabla_{x}V(x,\omega)\right].

From that
\mathcal{X}
is open, this holds for any direction
e
, so

\displaystyle\nabla v(x)=\mathbb{E}\left[\nabla_{x}V(x,\omega)\right].

∎

E.2
Modified Knapsack Experiment

Here, we provide some preliminary results for modified Knapsack problem. In this problem, we randomly assign weights
w
from
\{1,2,\dots,9\}
uniformly and independently to each index
i\in\{1,2,\dots,d\}
.

We denote the sum of elements chosen given
y\in\{0,1\}^{d}
to be
S(y)=\sum_{i=1}^{d}y_{i}w_{i}
, and define the payoff to be

\displaystyle Q(y)=\begin{cases}20&\text{if }T-2\leq S(y)\leq T+2\\
-5&\text{ if }S(y)>T+2\\
0&\text{ if }S(y)<T-2\end{cases}

where the target
T=\left\lfloor\frac{1}{2}\sum_{i=1}^{d}w_{i}\right\rfloor
.
