Hybrid Convolution and Vision Transformer NAS Search Space for TinyML Image Classification
Mikhael Djajapermana, Moritz Reiber, Daniel Mueller-Gritschneder, Ulf Schlichtmann

Abstract
Hybrids of Convolutional Neural Network (CNN) and Vision Transformer (ViT) have outperformed pure CNN or ViT architecture. However, since these architectures require large parameters and incur large computational costs, they are unsuitable for tinyML deployment. This paper introduces a new hybrid CNN-ViT search space for Neural Architecture Search (NAS) to find efficient hybrid architectures for image classification. The search space covers hybrid CNN and ViT blocks to learn local and global information, as well as the novel Pooling block of searchable pooling layers for efficient feature map reduction. Experimental results on the CIFAR10 dataset show that our proposed search space can produce hybrid CNN-ViT architectures with superior accuracy and inference speed to ResNet-based tinyML models under tight model size constraints.



1
Introduction

In recent years, Vision Transformer has become an increasingly popular Deep Neural Network architecture for computer vision tasks since it can outperform Convolutional Neural Network-based methods
[
9
,
33
]
. The main feature of Vision Transformer is the Multi-Head Self-Attention, which allows efficient learning of global dependencies. However, Vision Transformer-based architectures typically require large training data since Vision Transformers lack local inductive biases that are prevalent in Convolutional Neural Networks. Several works combined Convolutional Neural Network and Vision Transformer to form superior hybrid architectures
[
24
,
25
]
. Neural Architecture Search has been used to automate the hybrid Convolutional Neural Network-Vision Transformer design process
[
19
,
36
]
. A representative work is BossNAS
[
19
]
, which proposes an efficient Neural Architecture Search framework to search on a hybrid Convolutional Neural Network and Transformer search space with searchable downsampling positions.

The performance growth of Vision Transformers and hybrid Convolutional Neural Network-Vision Transformers has been coupled with the increase in model size, computations, and memory requirements, thus hindering their deployment in resource-constrained edge devices or even Micro-Controller Units, known as tinyML. The efficiency bottleneck in Vision Transformers stems mainly from the Multi-Head Self-Attention, whose computational and memory costs scale quadratically with the input resolution
[
34
]
. Prior works reduced this quadratic complexity by introducing linear complexity Multi-Head Self-Attention
[
35
,
23
,
4
]
. A recent work ported Vision Transformer-based architecture to Micro-Controller Units. For this, TinyFormer
[
36
]
proposes a framework consisting of SuperNAS, SparseNAS, and TinyEngine to generate and deploy efficient Vision Transformer-based architectures for image classification.

In this paper, we present a hybrid Convolutional Neural Network-Vision Transformer search space for Neural Architecture Search that combines the capabilities of Convolutional Neural Network and Vision Transformer in tinyML model size scale for image classification. We consider diverse Convolutional Neural Network blocks based on popular architectures, such as ResNet
[
13
]
and MobileNetv2
[
32
]
, and include the linear Multi-Head Self-Attention in our Vision Transformer blocks. The Convolutional Neural Network blocks effectively capture local information, while the Vision Transformer blocks excel at learning long-range dependencies. Convolutions are often accompanied by pooling layers to extract the dominant features and reduce the feature map resolution. However, most Neural Architecture Search search spaces ignore the search for the parameters and type of the pooling layers. We argue that the pooling layers have a non-negligible impact on the model performance and introduce the searchable Pooling block in our search space. A good choice of pooling layers can improve the accuracy and efficiency of our hybrid Convolutional Neural Network-Vision Transformers. We show that a Neural Architecture Search framework can easily leverage our proposed search space to produce a range of efficient hybrid architectures for tinyML image classification tasks. The generated models from our hybrid search space can be easily deployed with the help of existing Deep Neural Network compiler tool, such as TVM
[
7
]
.

In summary, the main contributions of this paper are as follows:

•

A more diverse search space for hybrid Convolutional Neural Network-Vision Transformer, containing diverse Convolutional Neural Network blocks and Vision Transformer blocks with ReLU-based linear Multi-Head Self-Attention for better inference latency on Micro-Controller Units. The models generated from our hybrid search space can be straightforwardly deployed using existing frameworks such as TVM.

•

The novel Pooling block enables the creation of hybrid Convolutional Neural Network-Vision Transformer architecture with much-improved inference latency compared to other search spaces that do not consider searchable pooling layers.

The search space is implemented in the HANNAH NAS framework
[
11
]
, using TVM to deploy the generated model to a RISC-V processor.
Experimental results on the CIFAR10 dataset
[
18
]
show that the proposed hybrid search space allows the discovery of hybrid Convolutional Neural Network-Vision Transformers that can outperform ResNet-based tinyML models in terms of latency and accuracy under tight model size constraints.

2
Related Works

2.1
Neural Architecture Search (NAS)

Neural Architecture Search is a method to automate and speed up the neural network architecture design process. Standard Neural Architecture Search comprises three parts: search space, search algorithm, and performance estimator
[
10
]
. The search space defines the set of possible building blocks to form the network. The search algorithm explores the search space, generating architecture candidates and selecting the top candidates based on the ranking given by the performance estimator. Many different search algorithms have been employed, such as evolutionary search
[
31
]
, reinforcement learning
[
37
]
, and differentiable supernet-based methods
[
22
]
. For tinyML applications, the generated models should be able to operate on devices with limited memory, occasionally even with tight latency requirements. To consider the target device and requirements, Hardware Aware NAS searches for well-performing architectures under hardware-related constraints, such as model size and latency. Hardware Aware NAS methods have successfully identified efficient architectures with better trade-offs than manual designs, e.g., in image classification
[
14
,
5
,
3
]
.
Many Hardware Aware NAS methods target the deployment on edge devices.
MCUNet
[
21
]
optimizes the search space to fit the hardware target, trains a supernet with all possible sub-networks, and performs an evolutionary search to find the best sub-network for the target Micro-Controller Units.

\mu
NAS
[
20
]
uses Aging Evolution
[
31
]
to search for the best architecture considering accuracy, RAM usage, model size, and latency.
A differentiable Neural Architecture Search is employed in MicroNets
[
2
]
to find networks with low memory usage and operation counts. MicroNets achieve state-of-the-art results on three tinyML benchmarks: visual wake words, audio keyword spotting, and anomaly detection.
HANNAH
[
11
]
proposes a framework for automated hardware/software co-design of deep neural networks and neural network accelerators. HANNAH finds the best networks using an evolutionary search with randomized scalarization
[
29
]
based on power consumption and accuracy on audio classification tasks.
Once-for-all (OFA)
[
3
]
proposes the progressive shrinking technique to efficiently train the supernet. An evolutionary algorithm is performed to find a specialized sub-network from the OFA supernet based on the target hardware and latency constraints.

2.2
Multi-Head Self-Attention (MHSA) in Transformer

Transformer
[
34
]
is a popular deep-learning architecture for Natural Language Processing tasks, while Vision Transformer (ViT)
[
9
]
is a variant designed for computer vision tasks. Their key feature is the Multi-Head Self-Attention mechanism, which enables efficient learning of global dependencies. Multi-Head Self-Attention operates on three different linear projections of the input
x
, namely
Q=x\cdot W_{Q}
,
K=x\cdot W_{K}
,
V=x\cdot W_{V}
. Then, the attention score is calculated as
A(x)=\text{softmax}\left(\frac{QK^{\top}}{\sqrt{d}}\right)V
, where
d
is the dimension of
K
. The attention score is multiplied by a linear weight
W_{A}
to produce the output
\text{MHSA}(x)=A(x)\cdot W_{A}
.

A typical ViT encoder block is formed by stacking a Multi-Head Self-Attention layer and a feed-forward layer with residual connection:
\text{ViT}_{\text{enc}}(x)=x+\text{FF}(x+\text{MHSA}(x))
. The feed-forward layer
FF
consists of two linear weights with ReLU in between:
\text{FF}(x)=\text{ReLU}(x\cdot W_{1})\cdot W_{2}
. The first linear weight
W_{1}
expands the channel dimension, while the second linear weight
W_{2}
reduces the dimension back to the input channel dimension.

2.3
Convolution and Transformer NAS Search Space

BossNAS
[
19
]
proposes a Neural Architecture Search framework with the HyTra search space, which is a Convolutional Neural Network and Transformer search space with searchable downsampling positions. To create the architecture candidates, the HyTra search space allows Convolutional Neural Network and Transformer building blocks to be chosen in each layer. In contrast, we provide a macro skeleton to form the hybrid architecture by placing the Convolutional Neural Network blocks at the earlier layers and our hybrid Vision Transformer blocks at the subsequent layers. In BossNAS, the positional encoder performs the downsampling operation using convolutions. In our work, we also use convolutions as an implicit positional encoder, but we additionally introduce the Pooling block to explicitly downsample and reduce the feature map resolution. Furthermore, BossNAS does not target tinyML applications, while our work focuses on tinyML with much more restrictive model size and memory constraints.

TinyFormer
[
36
]
proposes a framework to develop and deploy efficient Transformers on MCUs. The framework consists of three parts: SuperNAS, SparseNAS, and SparseEngine. TinyFormer employs a search space consisting of MobileNetV2 and Transformer blocks for image classification. In our search space, we consider not only the MobileNetV2 block but also other popular Convolutional Neural Network building blocks. For our Transformer block, we additionally consider ViT blocks with ReLU-based linear Multi-Head Self-Attention inspired by
[
4
]
. Our diversified search space enables the search for architectures with better trade-offs. TinyFormer performs well on MCUs but requires a specialized inference engine for deployment. In contrast, our model does not require a specialized inference engine for deployment while still providing inference speed benefits.

A well-designed search space may enable efficient search. For this, architectural properties from popular, well-performing models can be incorporated to reduce the search space size and simplify the search
[
6
]
. This work explores the design of hybrid Convolutional Neural Network-Vision Transformer search space for Neural Architecture Search to generate efficient hybrid architectures for tinyML image classification.

3
Hybrid Convolutional Neural Network-Vision Transformer Search Space with Pooling Block

Figure 1
:
Overview of our proposed hybrid search space.

This section presents the proposed hybrid Convolutional Neural Network-Vision Transformer search space. As illustrated in
Figure 1
, our hybrid search space provides a macro architecture skeleton that consists of a Convolutional Neural Network stage, a Pooling block, a Hybrid Vision Transformer stage, and a classification block.
The CNN stage operates as the local feature extractor, while the Hybrid Vision Transformer stage learns to extract global features. Similar to CPVT
[
8
]
and BossNAS
[
19
]
, our Convolutional Neural Network stage also serves as the positional encoder for the subsequent Hybrid Vision Transformer stage.
Our search space has a hierarchical structure where each
stage
consists of several
blocks
of its type, and the optimal number of blocks needs to be searched. The CNN and the Hybrid Vision Transformer blocks are described further in
Section 3.1
and
Section 3.3
, respectively. The Pooling block (
Section 3.2
) consists of searchable pooling layers to reduce the feature map resolution and, thus, the computation costs of the subsequent layers. Finally, the classification block outputs the predicted probabilities of the classification classes. The classification block consists of an average pooling layer and a linear layer without searchable architectural parameters.

Our search space covers many hybrid Convolutional Neural Network-Vision Transformer designs with diverse structures and complexities. In particular, the blocks within a stage are not forced to be uniform, i.e., one block in a stage may choose different parameters from another. Furthermore, each Convolutional Neural Network, Pooling, and Hybrid Vision Transformer block contains several independent searchable parameters.

.
Each Convolutional Neural Network block can search for its kernel size, stride, output channel, and group. When group
>1
, the Convolutional Neural Network block performs the grouped convolution operation. The inverted bottleneck block is implemented with the depth-wise convolution
[
15
]
. For the residual connection, a
1\times 1
convolution operation is placed on the skip branch to ensure that the outputs of the two branches are of compatible shape for the addition.

As illustrated in

, we consider three pooling operations: 1) max pooling, 2) average pooling, and 3) a combination of max and average pooling by averaging their outputs.
The purpose of the Pooling block is to explicitly reduce the feature map resolution by selecting the most critical information using searchable pooling layers. This contrasts the Convolutional Neural Network blocks, which implicitly reduce the feature map resolution if a convolution stride larger than
1
is applied.

3.3
Hybrid Vision Transformer Block

(a)

ViT Block.

(b)

CNN-ViT Block.

(c)

Pool-ViT Block.

Figure 4
:
Types of Hybrid ViT Blocks.
The (a) ViT Block comprises an MHSA Block and an optional Feed-Forward (FF) Block.

The Hybrid Vision Transformer block always contains the Vision Transformer encoder block, with the optional Convolutional Neural Network or Pooling block preceding the encoder block.
Thus, we consider three types of Hybrid Vision Transformer Blocks: ViT, CNN-ViT, and Pool-ViT, as illustrated in
Figure 4
.
The Vision Transformer block (
4(a)
) consists of a Multi-Head Self-Attention sub-block and an optional feed-forward sub-block. The Multi-Head Self-Attention sub-block consists of a Multi-Head Self-Attention layer and a normalization layer with a residual connection. The feed-forward sub-block follows the same design but uses a feed-forward layer instead of a Multi-Head Self-Attention layer.
The searchable parameters of the Vision Transformer block are the number of attention heads, the
Q
-
K
-
V
dimensions, the choice to include the feed-forward block, and the feed-forward dimension. The feed-forward layer and the
Q
-
K
-
V
projector in the Multi-Head Self-Attention layer are implemented with a
1\times 1
convolution.
Batch normalization
[
16
]
is utilized instead of layer normalization since it can be folded into the preceding convolution in inference, offering a runtime advantage
[
4
]
.
For the activation function inside the feed-forward layer, we utilize ReLU
[
27
]
instead of Swish
[
30
]
or HardSwish
[
14
]
, which are more commonly used in the recent Vision Transformer designs but may not be well-supported by the Deep Neural Network deployment tool.

The Vision Transformer block is especially beneficial when placed after the Pooling block. We name this block combination the Pool-ViT block.
In the Pool-ViT block, the Vision Transformer block operates on a feature map with reduced resolution, which decreases the computational cost of the Multi-Head Self-Attention operation that depends quadratically on its input resolution.
We empirically show the benefits of the Pool-ViT blocks on inference efficiency and accuracy performance in
Section 4.2
.
This design is similar to the ResNet
[
13
]
design and light-weight Vision Transformer designs with pyramidal network structure
[
8
,
12
,
28
]
, which applies strong resolution reductions on its initial layers to reduce the computational costs of subsequent layers.

Moreover, inspired by EfficientViT
[
4
]
, we implement a ReLU-based linear Multi-Head Self-Attention variant that avoids the Softmax function, as follows:

\displaystyle Q^{\prime}=\text{ReLU}(x\cdot W_{Q}),\;K^{\prime}=\text{ReLU}(x\cdot W_{K}),\;V=x\cdot W_{V},

\displaystyle\text{MHSA}_{\text{linear}}(x)=Q^{\prime}\cdot(K^{\prime\top}V)\cdot W_{A}

Avoiding Softmax improves the inference speed by removing the time-consuming calculation of the negative exponential
[
36
]
.
During the architecture search, the Multi-Head Self-Attention sub-block inside our Vision Transformer block can choose either the standard Multi-Head Self-Attention with Softmax or the ReLU-based linear Multi-Head Self-Attention operation.

4
Experiments

4.1
Experiment Setup

For evaluation, we implement our proposed hybrid Convolutional Neural Network-Vision Transformer search space in an existing Neural Architecture Search framework called HANNAH
[
11
]
. HANNAH provides the tool to intuitively build complex search space designs and targets the tinyML use cases. We consider the image classification task with the CIFAR10 dataset
[
18
]
. We employ the evolutionary search in HANNAH to find a set of architecture candidates with the highest possible accuracy under a model size constraint of 100k parameters. During the search, the architecture candidates are trained for
{\sim}10
epochs, and the validation accuracy is utilized as a performance proxy for the fully trained models. After the search is finished and the best candidate is found, we re-train the best candidate for 500 epochs to obtain its best accuracy performance.

We compare our proposed hybrid search space defined in
Section 3
to other search space designs. As the baseline comparison, we build a ResNet-like search space by replacing the hybrid ViT stage with a CNN stage on our hybrid search space. Then, we define two separate modifications on our hybrid search space: 1) by removing the Pool-ViT block from the search space definition, and 2) by using only the ReLU-based linear Multi-Head Self-Attention in the Vision Transformer block. In total, we consider four search space designs for our comparison and use the following notations for the search spaces:
\mathcal{R}=
ResNet-like,
\mathcal{H}=
proposed hybrid Convolutional Neural Network-Vision Transformer,
\mathcal{H}_{\text{WP}}=\mathcal{H}
without the Pool-ViT block,
\mathcal{H}_{\text{L}}=\mathcal{H}
with only linear Multi-Head Self-Attention.

MLonMCU
[
17
]
, a TinyML deployment and benchmarking tool, is utilized to deploy the best model to an ETISS target simulating RISC-V processor
[
26
]
. All generated models from HANNAH are in PyTorch. We convert the best-found models to ONNX format, which are then compiled using TVM and benchmarked with the help of MLonMCU. The benchmark results are presented in
Section 4.2
.

5
Conclusion

This paper provides a search space for use in a Neural Architecture Search framework to design efficient hybrid Convolutional Neural Network-Vision Transformer network architectures with searchable Pooling blocks. Our search space design utilizes Convolutional Neural Network and Vision Transformer blocks to learn local and global information. The Pooling blocks effectively reduce the feature map resolution and, thus, the computation costs of the subsequent blocks. Implemented in the HANNAH Neural Architecture Search framework, our proposed search space can generate hybrid Convolutional Neural Network-Vision Transformer architectures that achieve superior accuracy and inference speed to the generated networks from the ResNet search space in tinyML model size regions.

For future work, orthogonal techniques that compress existing networks, such as quantization and pruning, can be applied to further improve the efficiency of the generated networks. Knowledge distillation methods could improve the accuracy of the hybrid models under tight model size constraints. Furthermore, the model deployment process can be extended by considering NPU co-processing.
