Parameterized Approximation for Capacitated d d -Hitting Set with Hard Capacities
Daniel Lokshtanov and Abhishek Sahu and Saket Saurabh and Vaishali Surianarayanan and Jie Xue

Abstract
In the Capacitated d d -Hitting Set problem input is a universe U U equipped with a capacity function 𝖼𝖺𝗉 : U → ℕ \mathsf{cap}:U\rightarrow\mathbb{N} , and a collection 𝒜 \mathcal{A} of subsets of U U , each of size at most d d . The task is to find a minimum size subset S S of U U and an assignment ϕ : 𝒜 → S \phi:\mathcal{A}\rightarrow S such that, for every set A ∈ 𝒜 A\in\mathcal{A} we have ϕ ⁡ ( A ) ∈ A \phi(A)\in A and for every x ∈ U x\in U we have | ϕ − 1 ​ ( x ) | ≤ 𝖼𝖺𝗉 ⁡ ( x ) |\phi^{-1}(x)|\leq\mathsf{cap}(x) . Here ϕ − 1 ​ ( x ) \phi^{-1}(x) is the collection of sets in 𝒜 \mathcal{A} mapped to x x by ϕ \phi . Such a set S S is called a capacitated hitting set . When d = 2 d=2 the problem is known under the name Capacitated Vertex Cover . In Weighted Capacitated d d -Hitting Set each element of U U has a positive integer weight and the goal is to find a capacitated hitting set of minimum weight. Approximation algorithms for Capacitated Vertex Cover were first studied by Chuzhoy and Naor [SICOMP 2006], who gave a factor 3 3 approximation algorithm for Capacitated Vertex Cover and showed that the weighted version does not admit an o ⁡ ( log ⁡ n ) o(\log n) -approximation unless P=NP. After a series of improvements spanning a period of 15 years, Kao [SODA 2017] and Wong [SODA 2017] independently obtained d d -approximation algorithms for Capacitated d d -Hitting Set . This matches the ratio for the classic d d -Hitting Set problem, and therefore cannot be improved to d − ϵ d-\epsilon for any ϵ > 0 \epsilon>0 assuming the Unique Games Conjecture. Capacitated Vertex Cover is also well understood from the perspective of parameterized algorithms: van Rooij and van Rooij [SOFSEM 2019] gave a k k ​ | U | O ⁡ ( 1 ) k^{k}|U|^{O(1)} time algorithm to determine whether there exists a solution S S of size at most k k , showing that the unweighted problem is fixed parameter tractable (FPT) parameterized by the solution size k k . In this paper we initiate the study of parameterized (approximation) algorithms for Capacitated d d -Hitting Set . An easy reduction shows that, as opposed to Capacitated Vertex Cover , unweighted Capacitated d d -Hitting Set for d ≥ 3 d\geq 3 does not admit an FPT algorithm unless FPT=W[1]. Our main result is a parameterized approximation algorithm that runs in time ( k ϵ ) k ​ 2 k 𝒪 ⁡ ( k ​ d ) ​ ( | U | + | 𝒜 | ) O ⁡ ( 1 ) \left(\frac{k}{\epsilon}\right)^{k}2^{k^{\mathcal{O}(kd)}}(|U|+|\mathcal{A}|)^{O(1)} and either concludes that there is no solution of size at most k k or outputs a solution S S of size at most 4 / 3 ⋅ k 4/3\cdot k and weight at most 2 + ϵ 2+\epsilon times the minimum weight of a solution whose size is at most k k . We note that while the running time of our algorithm depends on d d , the approximation ratio does not. Thus this parameterized approximation algorithm achieves a ratio smaller than what can be achieved by polynomial time approximation algorithms with a running time that is faster than what can be achieved by an algorithm solving the problem exactly. We complement our algorithmic results by showing that there exists a constant c > 1 c>1 such that for every d ≥ 3 d\geq 3 , assuming the Exponential Time Hypothesis, there is no FPT-approximation algorithm for unweighted Capacitated d d -Hitting Set with approximation factor c c , and no factor 2 − ϵ 2-\epsilon FPT-approximation algorithm for weighted Capacitated d d -Hitting Set . These hardness results even hold for Capacitated Vertex Cover in multigraphs. On the way we show that a variant of multi-dimensional Knapsack is hard to FPT-approximate within a factor 2 − ϵ 2-\epsilon . This result may be of independent interest.

Introduction

In the classic
Vertex Cover
problem, the input is a graph
G
, and the task is to find a minimum size vertex subset
S
such that every edge of
G
has at least one endpoint in
S
. In the more general
Hitting Set
problem input is a universe
U
, and a family
{\cal A}
of subsets of
U
. The task is to find a minimum size subset
S
of
U
such that every set in
{\cal A}
has non-empty intersection with
U
. When every set in
{\cal A}
has size upper bounded by some fixed constant
d
, this problem is called
d
-
Hitting Set
.
Hitting Set
(and
d
-
Hitting Set
) are also known under the name
Hypergraph Vertex Cover
(in
d
-regular hypergraphs). Indeed,
2
-
Hitting Set
is equivalent to
Vertex Cover
.

Guha et al.
[
GHKO03
]
, motivated by an application in glycobiology, initiated the study of a capacitated version of
d
-
Hitting Set
.
In
Capacitated
d
-Hitting Set
the input additionally contains a capacity function
\mathsf{cap}:U\rightarrow\mathbb{N}
and a multiplicity function
M:U\rightarrow\mathbb{N}
.
The task is to find a subset
S
of
U

and an assignment
\phi:{\cal A}\rightarrow S
such that

\textsf{size}(S,\phi)=\sum_{v\in S}\lceil\frac{|\phi^{-1}(v)|}{\mathsf{cap}(v)}\rceil
is minimized
and for every
v\in U
it holds that
\lceil\frac{|\phi^{-1}(v)|}{\mathsf{cap}(v)}\rceil\leq M(v)
.
Here
\phi^{-1}(v)
is the subset of
{\cal A}
that is mapped to
v
by
\phi
.
Informally we can buy each element
v
of
U
up to
M(v)
many times, and each time we buy
v
we choose up to
\mathsf{cap}(v)
sets in
{\cal A}
that get covered by
v
. We now briefly consider the different variants of the problem that have been studied.

Weighted vs Unweighted:
In
Weighted Capacitated
d
-Hitting Set
input additionally comes with a weight function
w:(u)\rightarrow\mathbb{N}
and the weight of a solution
(S,\phi)
is
\textsf{weight}(S,\phi)=\sum_{v\in S}w(v)\cdot\lceil\frac{|\phi^{-1}(v)|}{\mathsf{cap}(v)}\rceil
. The task is to find a solution of minimum weight.

Soft vs Hard Constraints:
In the version of the problem with
soft constraints

M(v)=\infty
for every
v
, so each vertex can be bought an arbitrary number of times. The general case, with “hard constraints”, is assumed by default unless stated otherwise.

Simple Graphs vs Multigraphs:
By default we will allow
{\cal A}
to be a
multi-family
, that is the same set
A
can occur in
{\cal A}
multiple times, and each occurrence of
A
needs to be covered separately. In the
simple
version of
Capacitated
d
-Hitting Set
each set in
{\cal A}
is required to occur at most once, so
{\cal A}
is a normal set family.

Guha et al.
[
GHKO03
]
obtain a factor
d
approximation algorithm for
Weighted Capacitated
d
-Hitting Set
with soft constraints.
Chuzhoy and Naor
[
CN06
]
initiated the study of
Capacitated
2
-Hitting Set
(under the name
Capacitated Vertex Cover
, and give a factor
3
approximation for simple
Capacitated Vertex Cover
.
They show that (simple)
Weighted Capacitated Vertex Cover
is as hard to approximate as
Hitting Set
, and therefore does not admit a
o(\log n)
-approximation unless
\mathsf{P}=\mathsf{NP}

[
Mos15
]
.
Subsequently Gandhi et al.
[
GHK+06
]
obtained a factor
2
approximation algorithm for simple
Capacitated Vertex Cover
.

Chuzhoy and Naor
[
CN06
]
posed as open problems whether it is possible to achieve a constant factor approximation for
Capacitated
d
-Hitting Set
for every
d
, and whether the requirement that
{\cal A}
be simple can be dropped.has
Both problems were resolved in the affirmative by Saha and Khuller
[
SK12
]
, who achieved a ratio of
38
for
Capacitated Vertex Cover
and
\max(6d,65)
for
Capacitated
d
-Hitting Set
for
d\geq 3
, respectively. This naturally led to the question of whether it is possible to achieve a ratio for
Capacitated
d
-Hitting Set
which comes close to (or matches) the (optimal, assuming the Unique Games Conjecture
[
KR08
,
DGKR05
]
) ratio of
d
for
d
-Hitting Set
. Making progress towards this goal, Cheung, Goemans and Wong
[
CGW14
]
gave algorithms with ratio
2.1555
for
d=2
and
2d
for

respectively.
The approximability of
Capacitated
d
-Hitting Set
was settled completely by Kao
[
Kao17
,
Kao21
]
and Wong
[
Won17
]
, who simultaneously and independently obtained
d
-approximation algorithms for the problem.

The
Capacitated Vertex Cover
problem in simple graphs with hard constraints
M(v)=1
for every vertex
v
has also been studied from the perspective of parameterized algorithms
[
CFK+15
,
DF13
]
. Guo, Niedermeier and Wernicke
[
GNW07
]
gave an algorithm with running time
2^{O(k^{2})}n^{O(1)}
for finding a solution
S
of size at most

, thereby showing that the problem is

(FPT) with respect to the parameter

. Dom et al.
[
DLSV08
]
gave an improved algorithm with running time
k^{3k}n^{O(1)}
, this was in turn further improved to
k^{k}n^{O(1)}
by van Rooij and van Rooij
[

]
. Prior to our work no versions of
Capacitated
d
-Hitting Set
for
d\geq 3
have been studied from the perspective of parameterized algorithms.

We initiate the study of parameterized (approximation) algorithms for
Capacitated
d
-Hitting Set
parameterized by the solution size
k
. An easy reduction from the
Partial Vertex Cover
(the exact same reduction as Theorem 6.1 of
[
CGW14
]
) shows that, unless
FPT
=
W[1]
,
Capacitated
d
-Hitting Set
does not admit an FPT algorithm for every
d\geq 3
, even when there are no multi-edges,
M(x)=1
for every vertex
x
and all weights are 1.
Our main result is a parameterized algorithm that simultaneously achieves an approximation ratio of
4/3
in terms of the size of the solution, and an approximation ratio of
2+\epsilon
for the weight.

Theorem 1.1
.

There exists an algorithm that takes as input an instance

(U,{\cal A},\mathsf{cap},M,w)
of
Weighted Capacitated
d
-Hitting Set
, an integer
k
and rational
\epsilon>0
,
runs in time

\left(\frac{k}{\epsilon}\right)^{k}2^{k^{\mathcal{O}(kd)}}(n+m)^{\mathcal{O}(1)}

and either outputs that
(U,{\cal A},\mathsf{cap},M,w)
has no solution of size at most
k
,
or outputs a solution
(S,\phi)
with
\textsf{size}(S,\phi)\leq 4/3\cdot k
and
w(S,\phi)\leq(2+\epsilon)\cdot w(S^{\star},\phi^{\star})
, where
(S^{\star},\phi^{\star})
is a minimum weight solution to the instance out of all solutions of size at most
k
.

The algorithm of Theorem
1.1
works for the default version of
Capacitated
d
-Hitting Set
with arbitrary vertex multiplicities and when
{\cal A}
is allowed to be a multiset. The algorithm of Theorem
1.1
is a
4/3
approximation algorithm for unweighted instances, and a
(2+\epsilon)
approximation for finding a solution whose weight is compared to the minimum weight instance of size at most
k
. It achieves both goals simultaneously with one solution.
Note that the
W[1]
-hardness result for finding exact solutions of size at most
k
in instances with
w(v)=1
for every
v
implies that any algorithm with running time
f(k,d)(|U||{\cal A}|)^{O(1)}
must incur some loss
both
in the size and in the weight of the solution that it outputs.
The approximation guarantees achieved by our algorithm in FPT time are far better than what is possible for the problem if only polynomial time is allowed:
4/3
-approximation vs
(d-\epsilon)
hardness for unweighted instances, and
2
-approximation vs
o(\log n)
-hardness for weighted ones.

We complement our algorithm by showing that, assuming the Exponential Time Hypothesis
[
IPZ01
]
(ETH), the
4/3
-approximation guarantee for unweighted instances cannot be made arbitrarily close to
1
, and that the ratio
2+\epsilon
for weighted instances is essentially tight. We first state the FPT-inapproximability result for unweighted instances.

Theorem 1.2
.

There exists a constant
c>1

such that for every integer
d\geq 2
, assuming the ETH there is no FPT (with parameter
k
) algorithm that distinguishes between instances
(U,{\cal A},\mathsf{cap},M,k)
of
Capacitated
d
-Hitting Set
that have a solution of size at most
k
or have no solution of size at most
c\cdot k
.

The hardness result of Theorem
1.2
holds even when
M(v)=1
for every element
v
. For
d\geq 3
it holds even for simple instances where
M(v)=1
for every element
v
.
Note that Theorem
1.2
implies that (assuming the ETH) there is no FPT algorithm for
Capacitated Vertex Cover
in multigraphs, even when
M(v)=1
for every element
v
, in stark contrast to the FPT algorithms for unweighted simple graphs
[
GNW07
,
DLSV08
,
vRvR19
]
. Next, we state our FPT-inapproximability result for weighted instances.

Theorem 1.3
.

For every real
c<2
and integer
d\geq 2
, assuming the ETH, there is no FPT (with parameter
k
) algorithm that distinguishes between instances
(U,{\cal A},\mathsf{cap},M,w,k,W)
of
Weighted Capacitated
d
-Hitting Set
that have a solution of size at most
k
and weight at most
W
or have no solution of weight at most
c\cdot W
.

Similarly to Theorem
1.2
, the hardness result of Theorem
1.3
holds even when
M(v)=1
for every element
v
. For
d\geq 3
it holds even for simple instances where
M(v)=1
for every element
v
.

On the way to proving Theorems
1.2
and
1.3
we show hardness of FPT-approximating
Multi-Dimensional Knapsack

[
GRR19
]
. Here input consists of
n

Theorem 1.4
.

There exists a real

Theorem 1.5
.

For every real

) algorithm that distinguishes between instances

of

k
or have no solution of size at most

Preliminaries

For a graph
G
, we use
V(G)
and
E(G)
to denote the set of vertices and the edges of
G
, respectively.
For a vertex
v\in V(G)
,
N_{G}(v)
denotes the set of neighbors of
v
in
G
and
N_{G}[v]
=
N_{G}(v)\cup\{v\}
. For a set
X\subseteq V(G)
,
N_{G}(X)=\bigcup_{v\in X}N_{G}(v)\setminus X
, and
N_{G}[X]=N_{G}(X)\cup X
. When the graph
G
is clear from context, we drop the subscript
G
, and simply write
N(\cdot)
and
N[\cdot]
. If
X\subseteq V(G)
, then we let
G[X]
denote the subgraph induced by
X
.
The
degree
of a vertex
v\in V(G)
is the number of neighbors it has. This is denoted by
{\sf deg}(v)
. Let
[n]
denote the set
\{1,\dots,n\}
.

A formal definition of the unweighted version of the problem that we work with is provided below. The weighted and multiplicity case fairly easily reduced to the unweighted case.

Capacitated
d
-Hitting Set

Parameter:

k

Input:
A universe
U
equipped with a capacity function
\mathsf{cap}:U\rightarrow\mathbb{N}
, and a collection
\mathcal{A}
of subsets of
U
each of which has size at most
d
.

Goal:
Find a subset
S\subseteq U
of size at most
k
and a map
\phi:\mathcal{A}\rightarrow S
such that
\phi(A)\in A
for all
A\in\mathcal{A}
and
|\phi^{-1}(\{x\})|\leq\mathsf{cap}(x)
for all
x\in S
.

Let
\mathcal{A}^{\prime}\subseteq\mathcal{A}
and
a\in U
, we denote by
\mathcal{A}^{\prime}\odot a
the sets in
\mathcal{A}\in\mathcal{A}^{\prime}
that contain
a
, i.e.
\mathcal{A}^{\prime}\odot a=\{A~:~A\in\mathcal{A^{\prime}},a\in A\}
.
Given a subset
S\subseteq U
, an assignment of
\mathcal{A}
to
S
is a mapping
\phi:\mathcal{A}\rightarrow S
such that
|\phi^{-1}(x)|\leq\mathsf{cap}(x)
. Given an element
e\in S
and a set
\mathcal{A}^{\prime}\subseteq\mathcal{A}
, we define
\mathsf{cov}_{\phi}(e,\mathcal{A}^{\prime}):=|\phi^{-1}(e)\cap\mathcal{A}^{\prime}|
as the number of sets in
\mathcal{A}^{\prime}
that are mapped to
e
. We also extend this notation naturally to each set
S^{\prime}\subseteq S
as
\mathsf{cov}(S^{\prime},\mathcal{A}^{\prime}):=|\phi^{-1}(S^{\prime})\cap\mathcal{A}^{\prime}|
.

We prove a simple result on a special red-blue dominating set instance that we will use in our algorithm.

Lemma 2.1
.

Let
G=R_{0}\uplus B_{0}
be a bipartite graph, where
|R_{0}|=r
,
|B_{0}|=b
,
r<2b
and for all vertex
v\in B_{0}
, we have that
{\sf deg}(v)\geq 2
. Then, there exists
D\subseteq R_{0}
of size at most
(b+r)/3
, such that
N(D)=B_{0}
.

Proof.

We prove the above by constructing a set
D
with the desired properties. We include a vertex in each round into
D
and modify the input instance as follows.
If there is a vertex
r\in R_{i}
with at least two neighbors in
B_{i}
, we include
r
in
D
. Following this inclusion, we update the instance by deleting
r
and all its neighbors from the instance, i.e.,
R_{i+1}=R_{i}\setminus\{r\}
,
B_{i+1}=B_{i}\setminus N(r)
,
G_{i+1}=G[R_{i+1}\uplus B_{i+1}]
. Note that as long as
|R_{i}|\leq 2|B_{i}|
, there is always a vertex in
R_{i}
with degree at least
2
. Suppose that the inclusion process ends after
a
rounds. Then,
|R_{a+1}|\geq 2|B_{a+1}|
. Observe that the degree of a vertex in
B_{0}
never changes throughout the process.

Let
F_{i}
be any two arbitrary vertices deleted in round
i
from
B_{0}
and
B^{\prime}=((\bigcup_{i=1}^{a}F_{i})\cup B_{a+1})\subseteq B
. We denote the size of
B^{\prime}
by
b^{\prime}
. Now, we extend
D
to a set of size
(b^{\prime}+r)/3
where
b^{\prime}=|B^{\prime}|
and
N(D)=B_{0}
. For every vertex
v\in B_{a+1}
, we add one of its neighbor to
D
.
Note that
|B_{a+1}|=b^{\prime}-2a
(from construction) and
r-a=|R_{a+1}|\geq 2B_{a+1}
. Putting these two equations together we get,
r-a\geq 2(b^{\prime}-2a)\implies a\geq(2b^{\prime}-r)/3
.
But,
|D|\leq a+|B_{a+1}|\leq b^{\prime}-a\leq(b^{\prime}+r)/3
. This consequently bounds the size of
D
by
(b+r)/3
. And,
N(D)=B_{0}
as every vertex in
B_{0}\setminus B_{a+1}
has at least one neighbor among all the vertices added to
D
in the
a
rounds, and every vertex in
B_{a+1}
also has a neighbor in
D
by construction.
∎

Technical Overview of
\frac{4}{3}
-approximation algorithm

In this section we give a technical overview of our approximation algorithm. In the next section, we give a formal definition of the algorithm, argue its correctness and analyze the running time of the algorithm.

Consider an unweighted instance
(U,\mathsf{cap},\mathcal{A})
of
Capacitated

So, our tuple currently consists of

For each element

\left\{\left\lceil\left(1+\frac{1}{3k}\right)^{p}\right\rceil~:~p\in\{1,\ldots,t=\lceil\log_{1+1/3k}m\rceil\}\right\}

Filtering the candidate elements in each

.

In this step we go through each element

To obtain a lower bound on the number of additional sets

\mathsf{score}(v,s):=\min\bigg(\mathsf{n}(v,s),\mathsf{cap}(v)-\sum_{s^{\prime}\in S,s^{\prime}\neq s}\gamma(i,s)\bigg)\text{ for each $s\in S$}

in our solution.

For each star

Definition 3.3
.

An extended annotated tuple is a tuple

2.

\tau_{1},\tau_{2}:S\rightarrow[k-|S|]

,

. Observe that in the second case we

Definition 3.4
.

Given an extended annotated tuple
(S,X,\pi,\gamma,\tau_{1},\tau_{2})

•

At this stage, we branch on the fact that

,
i\in[r]
, or

is disjoint from all the selected elements. In the first case, we make progress as the size of

X_{i}^{\prime\prime}

in the set

. The only reason

does not pick the elements we have kept is that the sets they may see have a large overlap. To compensate for the overlap, we select additional elements that lead to the size of the solution

.

We first show how we can select two additional vertices in each of the color classes

such that it leads to a factor
2

as follows. The vertex set

. We add an edge between two vertices

if there is some vertex

such that

|\mathcal{A}^{\pi}_{s}\odot u\cap|\mathcal{A}^{\pi}_{s}\odot v|\geq\frac{1}{\rho=k^{4}}\min\bigg(|\mathcal{A}^{\pi}_{s}\odot u|,|\mathcal{A}^{\pi}_{s}\odot v|\bigg).

That is, there is a significant overlap of these two vertices in a star. Taking advantage of the fact that every color class is substantially large as a function of
k
and
d
, and recognizing that the graph
H
exhibits sparsity, being
(kd)^{\mathcal{O}(1)}
degenerate (where each subgraph of

contains a vertex with a degree no greater than
(kd)^{\mathcal{O}(1)}

is a solution of size at most

.

We improve on this bound as follows. We find an independent set, as above, but we do not select all the vertices in our solution.

•

If there exists a color class
i
, such that
|\tau^{-1}_{1}(i)|\geq 2
, then we select both elements in
I
from this class to
S
, and discard the stars corresponding to

\tau^{-1}_{1}(i)
.

•

So assume that for every class

. In this case, we construct a bipartite graph

and

. That is,

We can combine both steps and show that the resulting solution has size at most

,
E\in\mathcal{P}_{d}(S)

•

We lose a factor of

when we guessed

•

Secondly, we lose because the elements that we select overlap a lot.

The way we handle losses is as follows. For each equivalence class, we have two elements that try to take care of this loss. Since our selected elements are independent in

We know that
Capacitated Vertex Cover
admits a FPT algorithm when the input graph is simple (that is, has no parallel edges). In this section, we show the parameterized inapproximability of unweighted
Capacitated Vertex Cover
with multi-edges. The reduction happens in two steps, in the first we step we reduce from
3
-Regular
2
-CSP
to
Multi-Dimensional Knapsack
and in the second step we reduce

to
Capacitated Vertex Cover
with multi-edges.

5.1
Parameterized Inapproximability of
3
-Regular
2
-CSP

We first define our source problem. Toward that we first define constraint satisfaction problems (CSPs) of arity two (also called binary constraints).) We follow the notation and definitions of
the seminal paper of Guruswami et al.
[
GLR+24
]
.
Formally, a CSP instance
G
is a quadruple
(V(G),E(G),\Sigma,\{C_{e}\}_{e\in E(G)})
, where:

•

V(G)
is for the set of variables.

•

E(G)
is for the set of constraints.
Each constraint
e=\left\{u_{e},v_{e}\right\}\in E(G)
has arity
2
and is related to two distinct variables
u_{e},v_{e}\in V(G)
.
The
constraint graph
is the undirected graph on the vertices
V(G)
and the edges
E(G)
. Note that we allow multiple constraints between the same pair of variables and thus the constraint graph may have parallel edges.

•

\Sigma
is for the alphabet of each variable in
V(G)
. We use
\Sigma=[n]
.

•

Given a constraint
e\in E(G)
,
C_{e}\subseteq\Sigma\times\Sigma=[n]\times[n]
. Furthermore, given
\{C_{e}\}_{e\in E(G)}
, we can define
\{\Pi_{e}\}_{e\in E(G)}
, the set of validity functions of constraints.
Given a constraint
e\in E(G)
, the validity function
\Pi_{e}(\cdot,\cdot)\colon\Sigma\times\Sigma\to\{0,1\}
checks whether the constraint
e
between
u_{e}
and
v_{e}
is satisfied. That is,
\Pi_{e}(\cdot,\cdot)
assigns
1
if and only of the tuple is in
C_{e}
.

We use
|G|=(|V(G)|+|E(G)|)\cdot|\Sigma|
to denote the
size
of a CSP instance
G
.

Assignment and Satisfaction Value.

An
assignment
is a function
\sigma\colon V(G)\to\Sigma
that assigns to each variable a value from the alphabet. The
satisfaction value
for a mapping
\sigma
, denoted as
\mathsf{val}(G,\sigma)
, represents the proportion of constraints that
\sigma
satisfies, i.e.,

\mathsf{val}(G,\sigma)=\frac{1}{|E|}\sum_{e\in E}\Pi_{e}(\sigma(u_{e}),\sigma(v_{e})).

The satisfaction value for

For a family

denotes the set of elements in the union

Let

of size

\displaystyle\Pr{\big(\mathcal{F}\text{ is not an $(\alpha,\beta,r)$-universe covering family}\big)}

\displaystyle\leq\Pr{\big(\exists\mathcal{Z}\subseteq\mathcal{F}\text{ s.t. }|{\sf cover}({\cal Z})|\leq(1-\beta)n\big)}

\displaystyle\leq\binom{n/\alpha}{n}\Pr(|{\sf cover}({\cal Z})|\leq(1-\beta)n)

\displaystyle\leq\binom{n/\alpha}{n}\Pr{(\exists X\text{ s.t. }{\sf cover}({\cal Z})\subseteq X\subseteq U)}

\displaystyle\leq\binom{n/\alpha}{n}\cdot\binom{n}{(1-\beta)n}\cdot(1-\beta)^{nr}

\displaystyle\leq{\left(\frac{e}{\alpha}\right)^{n}}\cdot{\left(\frac{e}{1-\beta}\right)^{(1-\beta)n}}\cdot(1-\beta)^{nr}

\displaystyle\leq{\left(\frac{e}{\alpha}\right)^{n}}\cdot{\left(\frac{e}{1-\beta}\right)^{n}}\cdot(1-\beta)^{nr}

\displaystyle\leq{\left(\frac{e}{1-\beta}\right)^{n}\cdot(1-\beta)^{nr}\cdot\left(\frac{e}{\alpha}\right)^{n}}

\displaystyle\leq{(e^{2}/\alpha\cdot(1-\beta)^{r})}^{n}\hskip 25.0pt

\displaystyle<1

6.2
Reducing
Multi-Dimensional Knapsack
to
Weighted Capacitated Vertex Cover

In this section, we give a gap-preserving reduction from
Multi-Dimensional Knapsack
to
Weighted Capacitated Vertex Cover
, which will show that the latter problem is hard to approximate in FPT time. We start with the desired construction.

Construction:
The construction is same as the one used in Theorem
5.3
with weights being introduced.
Given an instance
(\mathbb{V},\mathfrak{t},k)
of
Multi-Dimensional Knapsack
, we construct an instance
(G,\mathsf{cap},M,w,k+d,W)
of
Weighted Capacitated Vertex Cover
with multi-edges as follows. Here,
d=k^{\mathcal{O}(1)}
.
Reacll that
\mathbb{V}=\{\mathfrak{v}_{1},\ldots,\mathfrak{v}_{n}\}
, such that
each
\mathfrak{v}_{i}\in\{0,1,\ldots,M\}^{d}
, and the target vector
\mathfrak{t}\in\{0,1,\ldots,M\}^{d}
.
We first define the sum of values at each coordinate.
Let
x_{i}=\sum_{\mathfrak{v}\in\mathbb{V}}\alpha_{i}
, where
\mathfrak{v}=(\alpha_{1},\ldots,\alpha_{d})
. That is,
x_{i}
is the sum of values at
i
-th coordinate in the input vectors.

•

We introduce
2d

D=\{d_{1},\cdots,d_{d}\}
and
D^{\prime}=\{d_{1}^{\prime},\cdots,d_{d}^{\prime}\}
(two for each dimension) and a vertex

in
U
for each
\mathfrak{v}\in\mathbb{V}
, i.e,
V(G)=U\uplus D\uplus D^{\prime}
.

•

We add edges as follows. For every
i\in[d]
, we add one edge
(d_{i},d_{i}^{\prime})
. For every vertex

where
\mathfrak{v}=(\alpha_{1},\cdots,\alpha_{d})

\alpha_{i}

•

For each

,

. Here,

is the

-th coordinate of the target vector

. And, the capacity of every vertex from

•

Multiplicity function

•

Every vertex in

•

This concludes the construction.

Theorem 6.5
.

Unless ETH fails, for every constant

\eta>0
, such that no algorithm that takes as input
(G,\mathsf{cap},M,w,k,W)
of
Capacitated Vertex Cover
with multi-edges, runs in
f(k,d)n^{\mathcal{O}(1)}

k

(G,\mathsf{cap},M)

Proof.

We first show soundness followed by completeness.

Soundness.
Let
(\mathbb{V},\mathfrak{t},k)
be a yes instance of
Multi-Dimensional Knapsack
with a solution
\mathbb{V}^{\prime}\subseteq\mathbb{V}

k
. Let

. We claim

is a solution to
(G,\mathsf{cap},M,k+d,W)
of
Capacitated Vertex Cover
with multi-edges. Here,
d
could be
k^{\mathcal{O}(1)}
.

Note that
S(\mathbb{V}^{\prime})=\sum_{\mathfrak{v}\in\mathbb{V}^{\prime}}\mathfrak{v}\geq\mathfrak{t}
. The vertices
u_{\mathfrak{v}}
corresponding to the vectors
\mathfrak{v}\in\mathbb{V}^{\prime}
have
\infty
capacities. Each such vertex can cover all edges incident on it, and hence they collectively cover at least
t_{i}
many edges incident on each
d_{i}
. Each vertex
d_{i}
with its (coverage) capacity of

U^{\prime}
(
x_{i}-t_{i}
many) and the edge
(d_{i},d_{i}^{\prime})

is at most

a feasible solution for
(G,\mathsf{cap},M,w,k+d,k)
of
Capacitated Vertex Cover
with multi-edges.

Completeness.
Let
(\mathbb{V},\mathfrak{t},k)
be an instance of
Multi-Dimensional Knapsack
such that every solution has size at least
(2-\delta)k
, here
\delta
is an absolute constant mentioned in Theorem
6.3
. In this case, we will show that there exists an absolute constant

(G,\mathsf{cap},M,w,k+d,W)
of

with multi-edges does not have a solution of at most

For a contradiction, assume that
(G,\mathsf{cap},M,w,k+d,W)
have an inclusion-wise minimal set

of weight
(2-\epsilon)k

are the only vertices capable of covering edges of the form

has
0

that uses one of its coverage capacity to cover

many edges incident on

This together with the fact that every vertex

7
Conclusion

We gave a parameterized approximation algorithm for the
Capacitated
d
-Hitting Set
problem. The algorithm outputs a single solution which simultaneously achieves an approximation ratio of
4/3
for the size of the solution, and
2+\epsilon
for the weight.

Our approximation algorithm can also be made to work for the related
Partial Capacitated
d
-Hitting Set
problem. Here input additionally comes with an integer
t
and the task is to cover at least
t
sets using the minimum number of elements. Indeed the reduction of Cheung et al.
[
CGW14
]
that reduces
Partial Capacitated
d
-Hitting Set
to
Capacitated
(d+1)
-Hitting Set
combined with our algorithm does the job. Note that, as opposed to
polynomial time
approximation algorithms for these problems our approximation ratio does not depend on
d
. Thus, from the perspective of FPT-approximation
Partial Capacitated
d
-Hitting Set
appears no harder than
Capacitated
d
-Hitting Set
.

We also showed that, assuming the ETH, for
size
no FPT-approximaition algorithm can achieve an approximation ratio arbitrarily close to
1
, and for
weight
no FPT-approximaition algorithm can achieve an approximation ratio arbitrarily below
2
. Hence our algorithm achieves the best possible approximation ratio one can hope for in terms of weight, and is not too far off in terms of size. On the way to showing the hardness result for
Capacitated
d
-Hitting Set
we also obtain a tight factor
2-\epsilon
inapproximability result for FPT-approximating
Multi-Dimensional Knapsack
which may be of independent interest.

It is an intriguing open problem whether it is possible to close the gap and identify the smallest
c
such that unweighted
Capacitated
d
-Hitting Set
admits an
FPT-approximaition algorithm with factor
c
, and prove hardness (under ETH or another plausible assumption) of
(c-\epsilon)
-approximation. This would likely also lead to improved understanding of FPT-approximation and FPT-inapproximability of fundamental parameterized problems such as
3-Regular 2-CSP
.
