Correction: Continuous glucose monitoring reveals periodontitis-induced glucose variability, insulin resistance, and gut microbiota dysbiosis in mice
Authors: Moyuka Kubota-Takamori, Kazuhiro Omori, Chiaki Kamei-Nagata, Fumiko Kiyama, Takayuki Ishii, Masaaki Nakayama, Kazuyoshi Gotoh, Kimito Hirai, Yuki Shinoda-Ito, Keisuke Okubo, Shin Nakamura, Atsushi Ikeda, Tsugumichi Saito, Jun Wada, Shogo Takashiba
Published: 2025

Correction to: Scientific Reports 10.1038/s41598-025-18594-7, published online 06 October 2025

The original version of this Article contained an error in Figure 4 where the y-axis labels for TNF-α were inadvertently mislabelled in panel (c). The original Figure 4 and accompanying legend appear below.

Fig. 4Changes in Concentrations of Serum Insulin, Inflammatory Cytokines, and Serum Amyloid A The concentrations were measured using ELISA. (A) serum insulin concentration: control: n = 13, periodontitis: n = 11; (B) SAA: control: n = 13, periodontitis: n = 11; (C) TNF-α: control: n = 13, periodontitis: n = 11). SAA, serum amyloid A. Statistical analysis was performed using the Mann–Whitney U test. **, p < 0.05. ***, p < 0.001. Note: TNF-α was above detection limits (TNF-α, 0.1 pg/µL).

Statistical analysis was performed using the Mann–Whitney U test. **, p < 0.05. ***, p < 0.001. Note: TNF-α was above detection limits (TNF-α, 0.1 pg/µL).

(A) Relative blood glucose levels in control and periodontitis groups during glucose tolerance test (GTT). Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). (B) Relative blood glucose levels in control and periodontitis groups during insulin tolerance test (ITT). Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). (C) Serum insulin concentrations before and 30 min after glucose administration for glucose tolerance test in control and periodontitis groups. Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). BGL, blood glucose level. now reads:

“Changes in blood glucose levels during tolerance tests and serum insulin concentration during the glucose tolerance test.

(A) Relative blood glucose levels in control and periodontitis groups during the glucose tolerance test (GTT). Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). Statistical analysis was performed using the Mann–Whitney U test.

(B) Relative blood glucose levels in control and periodontitis groups during the insulin tolerance test (ITT). Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). Statistical analysis was performed using the Mann–Whitney U test.

(C) Serum insulin concentrations before and 30 min after glucose administration during the GTT in control and periodontitis groups. Means and standard deviations are shown (control: n = 4, periodontitis: n = 4). Statistical analysis was performed using one-way ANOVA followed by Bonferroni’s multiple comparison test. BGL, blood glucose level. *, p < 0.05; **, p < 0.01.”

The original Article has been corrected.
