Theorem 20

Proof.

Let

We claim

Let

Denote

and assume

for

There are

is infinite.

We prove the claim by induction. For

we can take any

Assume the claim is true for

Fix

is infinite.
Since

we know that

Furthermore, since

To summarize the previous proof, we assign an elementary submodel to each
increasing tower. We then show that the family consisting of the tower
elements indexed by the corresponding model’s height is centered. We aim to
apply this same approach in a forcing extension. However, we now face the
challenge that the Continuum Hypothesis (which was essential for invoking
Lemma
14

issue, we will work from the ground model using names for increasing towers
rather than the towers themselves. Naturally, this introduces several
additional complications. A significant portion of the work is devoted to
developing an appropriate method for “transferring” names between models. Another crucial aspect
is that we will need to impose stronger requirements on the elementary
submodels we work with, as we will see in the next section.

-name (for

5.

\mathbb{P}\left(\omega_{l}\right)
forces that

We will need another result from

Proposition 37
(
CH
)

Let
M,N\in

Sub
\left(\kappa\right)

I\in M\cap\left[\omega_{l}\right]^{\omega}

\dot{a}\in M

We now have the following:

Proposition 38
(
CH
)

Let
\left(\overline{M},\overline{W},\overline{P}\right)
be
a nice pattern (
\overline{M}=\left\langle M_{0},...,M_{n}\right\rangle,

\overline{W}=\langle\dot{W}_{0},....,\dot{W}_{n}\rangle,

P=\left\langle P_{i}\mid i\leq n\right\rangle

\mathcal{A}=\{\dot{A}_{\alpha}\mid\alpha\in\omega_{1}\}

\mathbb{P}\left(\omega_{l}\right)

an increasing tower,
N
an

\mathcal{A}\in N,

\delta_{n}<\delta_{N}
and

L\in N,

\beta\in\omega_{1}
and
R=\left\langle R_{i}\mid i\leq n+1\right\rangle
with the
following properties:

1.

L\in

Sub
\left(\kappa\right),

\delta_{n}<\delta_{L}

and
\beta,\mathcal{A},X\in L.

2.

R_{i}\preceq P_{i}
for every
i\leq n.

3.

(M_{0},...,M_{n},L,\dot{W}_{0},....,\dot{W}_{n},\dot{A}_{\beta},R)
is
a nice pattern.

Proof.
By Proposition
33
(with
D=\emptyset
) we know there are

L\in N
a submodel and
R=\left\langle R_{i}\mid i\leq n+1\right\rangle

with the following properties:

1.

\delta_{n}<\delta_{L}
and
X,\mathcal{A}\in L.

2.

R
is a decisive partition for
\left\langle M_{0},...,M_{n},L\right\rangle.

3.

R_{i}\preceq P_{i}
for every
i\leq n.

We can assume that
R_{n+1}
consists exactly of the elements of

\bigcup\limits_{i\leq n}R_{i}
that are in
L.
Since
\mathcal{A}\in L
and
each
\dot{A}_{\alpha}
has a countable support, we can find
\gamma\in L\cap\omega_{l}
such that for every
\alpha\in\omega_{1},
the name
\dot{A}_{\alpha}
has a support contained in
\gamma
(recall that
l>1
). We can
now apply Lemma
35
and find a
\triangle:\omega_{l}\longrightarrow\omega_{l}
with the following properties:

1.

If
B\in R_{n+1},
then
\triangle\upharpoonright B
is the identity mapping.

2.

If
B\in\bigcup\limits_{i\leq n}R_{i},
then the following holds:

(a)

\triangle\upharpoonright B
is increasing.

(b)

\triangle\left[B\right]\in L.

(c)

\triangle\left[B\right]\cap\gamma=\emptyset.

By Proposition
37
, we conclude that
\triangle_{\ast}(\dot{W}_{0}),...,\triangle_{\ast}(\dot{W}_{n})\in L.
Since
\mathbb{P}\left(\omega_{l}\right)
forces that
\dot{W}_{0}\cap....\cap\dot{W}_{n}

is infinite and
\triangle_{\ast}
is an automorphism, we get that

\triangle_{\ast}(\dot{W}_{0})\cap...\cap\triangle_{\ast}(\dot{W}_{n})
is
also forced to be infinite (see Proposition
17
).
Now, since
\mathcal{A}\in L,

\mathbb{P}\left(\omega_{l}\right)
is ccc
and
\mathcal{A}
is forced to be an increasing tower, we know that there is

\beta\in L\cap\omega_{1}
for which
\mathbb{P}\left(\omega_{l}\right)

forces that
\bigcap\limits_{i\leq n}\triangle_{\ast}(\dot{W}_{i})\cap\dot{A}_{\beta}
is infinite. Let
sup
(\dot{A}_{\beta})\in L
be a
countable support of
\dot{A}_{\beta}
and
I=

sup
(\dot{A}_{\beta})\setminus\bigcup R_{n+1}
. Define
\sigma_{0}:I\cup\bigcup\bigcup\limits_{i\leq n+1}R_{i}\longrightarrow\omega_{l}
with the following properties:

1.

\sigma_{0}\upharpoonright I
is the identity

2.

\sigma_{0}\upharpoonright J=\triangle\upharpoonright J
if
J\in\bigcup\limits_{i\leq n+1}R_{i}.

We claim that
\sigma_{0}
is injective. Since
\triangle
is injective, it
remains to check that if
\alpha\in I
and
\xi\in J
(for some
J\in\bigcup\limits_{i\leq n+1}R_{i}
), then
\sigma_{0}\left(\alpha\right)\neq\sigma_{0}\left(\xi\right).
We proceed by cases. If
J\notin L,
then

\sigma_{0}\left(\alpha\right)=\alpha<\gamma,
while
\sigma_{0}\left(\xi\right)\geq\gamma.
While if
J\in L,
we know that
\sigma_{0}\left(\alpha\right)=\alpha
and
\sigma_{0}\left(\xi\right)=\xi,
so we are

Claim 39

1.

\sigma\upharpoonright

sup
(\dot{A}_{\beta})
is the identity.

2.

\sigma_{\ast}(\dot{A}_{\beta})=\dot{A}_{\beta}.

3.

\sigma_{\ast}(\dot{W}_{i})=\triangle_{\ast}(\dot{W}_{i})

The second and third points are consequence of the first one and Lemma

If

we conclude that
\sigma\left(\alpha\right)=\triangle\left(\alpha\right)=\alpha.
This finishes the proof of the claim.

We already knew that
\mathbb{P}\left(\omega_{l}\right)
forces that

\bigcap\limits_{i\leq n}\triangle_{\ast}(\dot{W}_{i})\cap\dot{A}_{\beta}=

\bigcap\limits_{i\leq n}\dot{W}_{i}\cap\dot{A}_{\beta}

Finally, define

It

\langle R_{0},...,R_{n},\overline{R}_{n+1}\rangle

Theorem 40
(
CH
)

Let
l\in\omega.

\mathbb{P}\left(\omega_{l}\right)
forces
that there is an ultrafilter that intersects all increasing towers.

Proof.
If
l\leq 1,
the forcing extension will be a model of
CH,
so the
result follows by Theorem
1
, so we now assume
l>1.
Let

\mathbb{T}
be the the collection of all
\mathbb{P}\left(\omega_{l}\right)
-names for increasing towers. For
\mathcal{A}\in\mathbb{T},
we
enumerate it as
\mathcal{A=\{}\dot{A}_{\alpha}(\mathcal{A})\mid\alpha\in\omega_{1}\mathcal{\}}
(recall Theorem

1.

N(\mathcal{A})

\mathcal{A\in}

\delta\left(\mathcal{A}\right)=\delta_{N\left(\mathcal{A}\right)}.

\dot{A}_{\mathcal{A}}=\dot{A}\mathcal{{}_{\delta\left(\mathcal{A}\right)}(\mathcal{A})}.

\mathcal{B=\{}\dot{A}\mathcal{{}_{\mathcal{A}}\mid A}\in\mathbb{T}\mathcal{\}}.
We claim that
\mathcal{B}
is forced to be a centered family.

Claim 41

Let
\mathcal{A}_{0},...,\mathcal{A}_{n}\in\mathbb{T}
such that

\delta(\mathcal{A}_{0})\leq...\leq\delta(\mathcal{A}_{n}).
There

8
No covering with nowhere dense P-sets

It is well-known that Cohen forcing preserves towers. Moreover, in a Cohen
extension (over a model of
CH
) for every tall
P
-ideal

\mathcal{I}
in the extension, we can find an intermediate model where the
Continuum Hypothesis holds and
\mathcal{I}
remains a tall
P
-ideal.
Consequently, by Proposition
10
it contains an
increasing tower, which remains a tower in the final extension (see

[
7
]
and
[
5
]
for more
details). This leads to the following result:

Proposition 42
(
CH
)

In any Cohen extension, every tall
P
-ideal contains an
increasing tower.

When combined with Theorem
40
, we get the following:

Theorem 43
(
CH
)

Let
l\in\omega.

\mathbb{C}\left(\omega_{l}\right)
forces
that
\omega^{\ast}
can not be covered by nowhere dense
P
-sets.

What about random forcing? While it is true that all towers in the random
models have length
\omega_{1}
, Proposition
42

fails for random forcing. The issue is that Random forcing may fail to
preserve towers. Specifically, random forcing diagonalizes the
summable
ideal

\mathcal{J}_{\frac{1}{n}}=\{A\subseteq\omega\mid\sum\limits_{n\in A}\frac{1}{n+1}<\infty\}
(see
[
12
]
).
Since
\mathcal{J}_{\frac{1}{n}}
is a
P
-ideal
,
it contains
an increasing tower (assuming
CH
), which will be destroyed after
adding a single random real. Consequently, if we add at least
\omega_{2}

random reals to a model of
CH,
the summable ideal will be a

P
-ideal that does not contain an increasing tower.
