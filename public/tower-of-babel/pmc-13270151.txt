Higher-order neuromorphic Ising machines—autoencoders and Fowler-Nordheim annealers are all you need for scalability
Authors: Faiek Ahsan, Saptarshi Maiti, Zihao Chen, Jakob Kaiser, Ankita Nandi, Madhuvanthi Srivatsav, Johannes Schemmel, Andreas G Andreou, Jason Eshraghian, Chetan Singh Thakur, Shantanu Chakrabartty
Published: 2026

ABSTRACT
AbstractWe report that an autoencoder-based neuromorphic architecture, combined with Fowler-Nordheim annealing, is sufficient to implement scalable higher-order Ising machines. We show that these machines can consistently produce state-of-the-art solutions with high reliability and with competitive time-to-solution metrics. The autoencoder captures higher-order interactions by decomposing Ising clauses and Ising spins into encoder-decoder layers of spiking neurons, thereby keeping the resource complexity independent of the interaction order for sparse problems. An annealing process based on the dynamics of Fowler-Nordheim quantum mechanical tunneling extrapolates between an O(1/t) annealing schedule and an O(1/log(t)) annealing schedule. This not only ensures fast convergence towards high-quality solutions but also guarantees asymptotic convergence to the Ising ground state. To demonstrate the advantages of the proposed higher-order neuromorphic Ising machine, we systematically solved benchmark combinatorial optimization problems such as MAX-CUT and MAX-SAT, comparing the results to those obtained using a second-order Ising machine employing the same annealing process.Subject terms: Electrical and electronic engineering, Computational science

Introduction

Recently, there has been considerable interest in application domains where neuromorphic architectures can demonstrate significant performance advantages compared to conventional hardware architectures based on central processing units (CPUs), graphics processing units (GPUs), and tensor processing units (TPUs)1–3. Combinatorial optimization is one such domain, where the physics of the problem can be directly mapped onto a neuromorphic Ising architecture4. In a neuromorphic Ising machine, spin interactions are realized by synaptic coupling between a network of integrate-and-fire neurons. Neuronal spikes correspond to Ising spin flips (or state changes) and are generated asynchronously and routed to target neurons, which fire (or update their state) according to local thresholding criteria. The resulting spiking dynamics and the attractor states of the spiking network encode possible solutions to an underlying optimization problem4, 5. When the dynamics of the network are combined with noise, annealing, and random fluctuations to escape local attractor states, an Ising machine epitomizes several unique and advantageous features of neuromorphic architecture compared to other hardware architectures, which include: (a) asynchronous event-based computing; (b) massive parallelism; and (c) noise-driven dynamics. As a result, the neuromorphic advantage for Ising problems has been demonstrated in terms of time-to-solution metrics6, 7, energy-to-solution metrics4, 6–8, and reliability/quality of solution metrics4. The functional isomorphism between spike-based dynamics and Ising spin flips can be used to scale Ising machines on large neuromorphic hardware platforms. Examples of such platforms include SpiNNaker and SpiNNaker29, 10, Intel’s Loihi and Loihi 2, and the Hala-Point neuromorphic supercomputer11–13, IBM’s TrueNorth2 and NorthPole1 platforms, the BrainScaleS/BrainScaleS-2 accelerated mixed-signal systems14, and mixed analog-digital systems such as NeuroGrid and Tianjic15, 16.

However, similar to other Ising solvers based on superconducting quantum annealers17, 18, optical and CMOS oscillators19–22, and stochastic magnetic-tunnel junctions23, 24, current neuromorphic Ising machines capture only pairwise interactions between spin variables. In-silico, pairwise interactions are straightforward to implement in hardware via resistive6, 25–27 and capacitive7, 28, 29 couplings in analog hardware, or via point-to-point connections in digital hardware11, 30–32. However, the direct implementation of higher-order (three-body or beyond) terms is more challenging, even though higher-order terms inevitably appear when encoding general combinatorial objectives as Ising energy polynomials33. To address this, numerous quadratization techniques have been developed to reduce higher-order polynomials to second-order by introducing auxiliary variables34–36. From an implementation standpoint, this requires increasing both the total number of spins and the precision and dynamic range of the pairwise coupling coefficients compared to the original higher-order weights.

This concept is depicted in Fig. 1a, using a 3-variable XOR-SAT problem where the Ising Hamiltonian is described using a single third-order term. Quadratization yields a second-order network with one auxiliary spin and six pairwise couplings, as shown in Fig. 1a. While the quadratization overhead incurred for this and other small-scale examples may be modest, it grows rapidly with the order of the original optimization objective polynomial. As shown in Fig. 1b, the ratio of variables and the interconnection ratio (see Methods Section 4.1 for definition) in the Ising model’s energy function (after quadratization) grow exponentially with the interaction order for MAX-SAT problems of orders 3, 5, 7, 9, and 11, respectively (see Methods Section “Methodology for resource comparison”). Reference 37, 38 also discuss similar scaling of resources for higher-order cost function compared to the quadratized counterpart. The exponential increase in the variable ratio signifies that quadratization expands the search space exponentially and may introduce additional ruggedness in the energy landscape, impacting solver performance in terms of convergence and time-to-solution39, 40. Additionally, because the interconnection ratio directly correlates with hardware resource requirements, the hardware resources to implement a quadratized Ising solver compared to a direct higher-order solver also grow exponentially with the problem order, as also discussed in ref. 37. In this regard, a direct implementation of higher-order interactions (without quadratization) offers a more scalable and resource efficient solution.

Recent approaches for implementing higher-order Ising machines are based on two computing methods: classical annealing and dynamical system evolution. Examples of these include probabilistic bit (p-bit) based higher-order Ising machines41 and memristor-based higher-order Hopfield optimization solvers for classical annealing42, and coupled oscillator-based higher-order Ising machines for dynamical system evolution43. Classical annealing methods like p-bit stochastic solvers relax binary constraints and leverage intrinsic noise to find solutions, using the stochastic properties of p-bits for efficient computation, and memristor-based networks exploit device stochasticity to achieve low metrics in terms of energy-to-solution and time-to-solution. Dynamical system evolution methods, such as coupled oscillator-based approaches, evolve more rapidly than thermal or adiabatic timescales, driving the system towards low-energy configurations quickly. While the benefits of these higher-order approaches can be fully realized when implemented in analog hardware, computational precision, device mismatch and dynamic range for readout circuits limit the scaling to large problems. Also, there is no theoretical assurance of outperforming current state-of-the-art solutions or consistently converging to the true ground state. Digital implementations can avoid some of these issues30, 44–46 but require careful calibration of noise statistics to achieve competitive performance. A promising recent development is the neuromorphic Ising machine named NeuroSA4, that leverages advances in asynchronous neuromorphic hardware to achieve scalability for solving second-order Ising problems. Furthermore, the NeuroSA Ising machines provide an asymptotic guarantee of converging to the Ising ground state which leads to higher reliability in producing and discovering state-of-the-art solutions.

In this work, we propose a scalable higher-order Neuromorphic Ising machine that overcomes the limitations of quadratization. We also show that the Fowler-Nordheim annealer which was important for producing state-of-the-art solutions in the NeuroSA architecture, is also the key for the proposed higher-order Ising machine to achieve state-of-the-art results. In the standard Ising-based minimization of Eq. (1), one explores the space of spin states to identify the configuration that yields the lowest energy. At each step of this sampling process, the change in energy, ΔE, must be recalculated for a potentially new spin configuration. In an all-to-all topology based reconfigurable implementation, for a p-th order Hamiltonian, computing ΔE directly from the full spin vector s incurs a cost of O(Np), which rapidly becomes intractable as both the total spin count N and the interaction order p increase. In refs. 48, 49, it is noted that practically relevant Polynomial unconstrained binary optimization (PUBO) instances are sparse in the sense that only a small fraction of the possible monomials/clauses Tk are present. Moreover, this monomial-level sparsity increases with problem size: as the total number of variables grows, the fan-in of each variable—that is, the number of monomials/clauses in which it participates—remains much smaller than the total number of variables. Therefore, if ΔE can be reformulated in terms of the clause outputs Tk, then it becomes possible to navigate the energy landscape directly within the sparse Tk-space (T ∈ {−1, 1}M). By doing so, the exact higher-order interactions of the original Ising model are retained while circumventing the O(Np) bottleneck. However, the clause outputs Tk are not independent, so the naive way of sampling directly in the M-dimensional Tk-space to minimize energy is inefficient—adjusting one output usually forces changes in several others. To address this, the proposed autoencoder-based model (Fig. 1c) projects the high-dimensional Tk vector into a lower-dimensional spin vector of size N, with N < M. In this reduced spin space, each spin is considered to be independent, so sampling an N-element spin vector immediately yields a consistent clause-output configuration. These spin variables thus serve as the latent space (or bottleneck) of our autoencoder.

Sampling in the latent space uses the projection of clause outputs to spin space according to Eq. (2). Concretely, the outer layers of neurons of the autoencoder correspond to the M clauses and the inner layer (or, latent layer) of neurons correspond to the N spin variables. Note that the summation in Eq. (2) is exactly the weighted integration of clause outputs in the encoder stage (Fig. 1c). In particular, the i-th column of H indicates which previous clause outputs Tk,n−1 connect to the i-th latent neuron—each contribution being weighted by its coupling strength Jk. Each latent neuron does more than simply sum its inputs: if its aggregated input exceeds a noisy threshold μi,n, it emits a spike qi,n. This thresholded nonlinearity precisely mirrors the acceptance-rejection step of the Simulated Annealing algorithm. In the discrete-time version, a spike can be either represented by digital pulses or the transition from 0 to 1 denoting events, especially for the proposed fully neuromorphic based on ON-OFF neuron (shown in SI Section S2). Though, for our digital emulation, spike can be defined as the binary event (qi,n = 1) at time step (n) when the neuron’s net input (weighted sum of its connected spins/clauses) crosses its stochastic threshold, and (qi,n = 0) otherwise.

In the decoder stage, each p-th order clause output Tk is reconstructed by combining the spikes from the p associated latent neurons. In hardware, we initialize Tk,0 from the initial spin configuration and subsequently update Tk,n from its previous state Tk,n−1 according to the decoder neuron model. The decoder neuron implements a toggle operation which can be mapped onto a standard neuromorphic architecture using a pair of ON-OFF integrate-and-fire neurons4 (see SI Section S1 for details on this mapping). In a fully neuromorphic implementation based on such ON-OFF neurons (see SI Section S2), we propagate only the changes in the clause outputs (ΔTk,n+,ΔTk,n−), and these are initialized consistently with the initial spin assignments. For the sake of brevity and clarity, the algorithm and implementation in this paper will directly use toggle neurons. Also, in a practical implementation, the latent neuron outputs qi,n could be a spike-train or a continuous value rather than the idealized binary (0/1) state. Consequently, applying the threshold θ at the decoder neurons ensures that small, unintended variations in the latent neurons do not trigger a response.

Note that prior higher-order Ising implementations, such as41, also address the O(Np) scaling by embedding sparse higher-order problems, but they compute higher-order spin products explicitly using AND-type logic and then sum these products to evaluate the energy change ΔEi at each spin. However, the use of explicit combinational units to form spin products followed by summation is not directly compatible with neuromorphic operations and architecture, thus, making the direct mapping onto standard neuromorphic platforms non-trivial.

We anneal the noisy thresholds of each latent neuron (μi,n) over time using a Fowler-Nordheim (FN) annealer (see Methods Section “FN Annealer based dynamical systems”). As shown in ref. 4 for a second-order Ising machine, the FN-annealer produces an optimal annealing schedule that guarantees asymptotic convergence to the ground state of the underlying combinatorial optimization problem. From the perspective of implementing higher-order Ising solvers, this work also confirms the importance of the FN-annealing dynamics in a manner that transitions between 1/t dynamics over a short time-scale and 1/logt dynamics over a longer time-scale. As discussed in Methods Section “FN Annealer based dynamical systems”, in the high-temperature regime the FN-annealer schedule is well approximated by a 1/t decay, allowing the dynamics to follow the local gradient; this is illustrated by the white trajectory in Fig. 1e. By contrast, when no gradient information is available to direct the optimization trajectory, finding the ground state necessitates the transition to a slower 1/logt annealing schedule50. In this low-temperature regime (after a critical temperature), the FN dynamics can be modeled as a 1/logt schedule, enabling sporadic, noise-driven exploration of nearly flat regions of the landscape; this behavior is depicted by the orange trajectories in Fig. 1e.

The FN-dynamics may be realized either by a physical FN-tunneling device51 or via a digital emulation of the FN-tunneling dynamical systems. In this work, we employ the digital emulation to achieve the precision required for simulated annealing in the low-temperature regime. Similar to ref. 4, the FN dynamics are combined with independent and identically distributed (i.i.d.) noise variables, Ni,nE and Ni,nB, to produce the time-varying threshold μi,n. Here, Ni,nE is drawn from an exponential distribution, while Ni,nB is sampled from a Bernoulli distribution on {0, 1}. This combination ensures that every neuron maintains a nonzero probability of firing, satisfying the irreducibility and aperiodicity requirements of simulated annealing.

As pointed out earlier, since most practical combinatorial-optimization problems lead to sparse interconnection matrices, our architecture leverages this sparsity via graph-coloring of the spin variables. Although computing an optimal coloring is NP-hard, we follow the approach of Aadit et al.24 by using a fast greedy heuristic during preprocessing. While it does not guarantee optimality, it is efficient for our purposes. In the colored graph, latent neurons sharing the same color—or that are conditionally independent—are updated simultaneously, while neurons of other colors are held at a very high threshold. Consequently, the latent neurons require only the annealed exponential noise as their effective threshold. This graph-coloring strategy enables massively parallel updates across these neurons at each time step.

A complementary line of work37, 52 directly implements the monomials/clauses of SAT-like optimization problems on crossbar arrays. In these designs, the crossbar computes clause outputs or monomial sums given a binary variable assignment, and additional stages then use these intermediate quantities to compute gradients or energy differences. While this yields a MAC-type primitive at the array level, the overall pipeline still relies heavily on explicit variable assignments to (i) drive the crossbar in the forward pass to obtain clause outputs, and (ii) feed conditional inputs to subsequent crossbars for gradient computation. This introduces auxiliary peripheral circuitry (requires additional sense/comparator and gating circuitry between crossbar stages, and in experimental demonstrations, these currents are digitized, incurring extra A/D conversion) for conditional input in between stages and recomputation of the gradient from the variable assignments at every update step. In contrast, by representing variables as spins and formulating the dynamics directly in terms of clause outputs Tk, our architecture computes local gradients from the clause space itself using synaptic operations, and does so without requiring any conditional peripheral logic based on the spin assignments. This leads to a more inherently neuromorphic mapping in which synaptic weights encode clause memberships, and the membrane potentials of latent neurons encode the incremental energy changes.

Moreover, in all of the above prior designs, including the unified framework of Bhattacharya et al.38, the local gradient or energy change is recomputed from the instantaneous spin/variable assignments at each iteration. In our fully neuromorphic implementation based on ON-OFF neurons (see SI Section S2), we instead propagate only the changes in the clause outputs (ΔTk,n+,ΔTk,n−) and incrementally update the latent membrane potentials (and hence ΔEi,n) from these sparse events, rather than recomputing ΔEi,n afresh from Tk,n at every step. This is directly analogous to the optimized simulated-annealing strategy advocated in ref. 53, where for most Ising problems, typical acceptance rates ~ 15% make it more efficient to cache ΔEi and update it only when spin i or one of its neighbors flips. In our setting, the events are clause-output changes, which are spike-like and sparse; transmitting only these events and performing event-driven updates substantially reduces switching activity and arithmetic overhead while preserving the exact higher-order Ising energy. The second key ingredient, in addition to synapses, is the use of IF neurons to realize clause outputs. Implementing clause neurons as IF elements with an appropriate threshold θ and finite integration window makes the clause dynamics robust to device-level noise and small fluctuations in the latent layer (see Discussion Section 3 and SI Section S2), and also naturally supports an asynchronous realization with only coarse synchrony constraints (finite integration windows shared across neuron populations at the same level). Although we do not explicitly re-benchmark these robustness advantages in our results, they have already been demonstrated in prior work: in ref. 4, the ON–OFF IF implementation of simulated-annealing dynamics was shown to admit a one-to-one mapping onto general neuromorphic platforms such as SpiNNaker, for which the robustness and energy-efficiency benefits of IF-based architectures are already well established.

Finally, the proposed architecture differs fundamentally from prior higher-order SAT/Ising accelerators in its convergence guarantees. Designs such as37, 38, 52 employ stochastic local search (SLS)-style update rules driven by massively parallel gradient evaluations, which, while empirically powerful, do not guarantee convergence to the global optimum. Similarly, the higher-order p-bit based solver of ref. 41 relies on adaptive parallel tempering to solve 3-regular 3-XORSAT instances, again without an asymptotic optimality guarantee. By contrast, our higher-order neuromorphic Ising machine is functionally isomorphic to optimal simulated annealing, with the temperature schedule generated by the Fowler-Nordheim (FN) annealer. This schedule satisfies the classical 1/logt convergence conditions, ensuring asymptotic convergence to the true Ising ground state. As we demonstrate empirically, for intrinsically higher-order combinatorial problems such as MAX-3SAT, and second-order problems such as MAXCUT that even finite-duration runs of our architecture consistently produce state-of-the-art solutions with competitive time-to-solution. Furthermore, for planted higher-order benchmarks such as 3R-3X, we show that the scaling of the time-to-solution with problem size under our FN-based schedule is comparable to that of alternative solvers that employ faster, heuristic annealing schedules, while retaining the theoretical convergence guarantees. Detailed quantitative comparisons with these prior works on standard benchmarks are presented in the following sections.

Results

First, we analyze the dynamics of our neuromorphic higher-order Ising machine on a small 3R-3X problem, where the search dynamics is easily visualized54. The main objective of this experiment is to compare against the second-order Ising machine. Next, we employ a well-established MAX-CUT benchmark to showcase the benefits of graph coloring, and we compare our hardware implementation (on an FPGA) against other reported solutions to demonstrate its performance even on inherently second-order problems. Finally, we assess our higher-order neuromorphic Ising machine on MAX-SAT instances to quantify its edge over a second-order solver when addressing optimization tasks with intrinsic higher-order interactions.

Experiment on small 3R-3X problem

Our neuromorphic higher-order Ising machine was initially tested on a small 3-Regular-3-XORSAT (3R-3X) instance comprising 10 variables and 10 clauses. Although this problem can be solved in O(n3) time by Gaussian elimination, its regular structure induces an NP-hard, egg-carton-like energy landscape55, making it an ideal problem for probing network-dynamics trajectories even at small scales. The higher-order optimization objective polynomial yields the interconnection matrix H, and the corresponding clause weight matrix J appears in Fig. 1f. After applying quadratization, the resulting second-order Hamiltonian Q is displayed in Fig. 1g. A detailed description of the equation-planting procedure and the mapping from 3R-3X to both the higher-order and second-order interconnection matrices is provided in SI Section S3. Comparison of Fig. 1f–g readily reveals the increased precision and expanded range of the pairwise coupling coefficients following quadratization.

We then solve this instance using two approaches: directly on the higher-order interaction matrix H with the proposed higher-order Ising machine, and on the quadratized Hamiltonian Q with NeuroSA4, a previously reported neuromorphic second-order Ising machine. Since both implementations are asynchronous event-based, we can visualize their search dynamics by aggregating spike rates (or event-rates). For NeuroSA, we use the total spiking rate of each neuron, while for our architecture, we use the aggregated spike rates from each latent neuron. These aggregated rates are computed over a moving time window. We then project the resulting population-firing dynamics onto a reduced three-dimensional space spanned by the three dominant principal components, as shown in Fig. 1h. This principal-component-analysis (PCA)-based approach is standard in spiking-data analysis56; details are described in Methods Section “Generation of the population firing dynamics using PCA”. To ensure a fair comparison, the annealing schedules and initial spin configurations are identical for both Ising machines, eliminating any artifacts from differing parameters. Due to the unique energy landscape of the 3R-3X problem, the solvers do not exhibit long dwell times even upon reaching the global minimum. Therefore, we plot the population-firing trajectories for each Ising machine up to the moment it first attains the ground state and remains there briefly. As illustrated in Fig. 1h, the higher-order trajectory (HO Trajectory) rapidly converges to the ground state, whereas the second-order trajectory (SO Trajectory) undergoes an extended random-walk before finding the global minimum. This behavior directly reflects the larger search space and additional ruggedness introduced by quadratization in the second-order solver, as also discussed in refs. 39, 40.

Experiments using MAX-CUT

Next, our algorithm is applied to a problem of MAX-CUT, whose ground state is unknown but for which the State-of-the-art (SOTA) is well documented. We select the G15 graph—an 800-node, binary-weighted planar instance57—for which the current SOTA is 3050 cuts58. The mapping for MAX-CUT problems to the Ising formulation required for our architecture is detailed in SI Section S4. Since MAX-CUT is the simplest case of an XORSAT problem (two-variable clauses), it provides a clear means to analyze our algorithm’s behavior on a relatively large graph. To assess the impact of graph coloring, we compare the dynamics of our algorithm on G15 both with and without coloring. We color the graph using the DSATUR, as a heuristic graph-coloring algorithm59. As shown in Fig. 2a, DSATUR assigns seven distinct colors to G15. These simulations were performed on a CPU-based platform. We observe that both implementations—colored and uncolored—converge steadily toward the SOTA of 3050 cuts as shown in Fig. 2b.

The dynamics naturally split into two regimes—high temperature and low temperature—based on the noisy threshold μ(t) provided by the FN annealer, which follows an annealing schedule τn~1/log(n). In the high-temperature phase (initial iterations), the noise threshold values (τnlog(un), see Methods Section “Derivation of the Autoencoder Based Model”) are large and negative, so the system evolves primarily along the gradient of the Ising energy. With graph coloring, multiple independent variables can flip simultaneously, yielding larger gradient steps toward convergence compared to the asynchronous, single-spin flips in the uncolored case. This effect is evident in the high-temperature trajectories (Δ1) shown in Fig. 2.b.

As the temperature decreases, the search becomes confined to a local minimum. The FN annealing dynamics maintain a finite probability of escape even in the low-temperature regime, so the behavior is dominated by a combination of random walks and sporadic escapes, without a preferred direction. These occasional escapes allow the algorithm to continue exploring and potentially reach the global optimum. However, in this regime, graph coloring offers less advantage: the inset of Fig. 2.b shows that both colored and uncolored runs arrive at the SOTA level while maintaining an offset of approximately 5 × 105 iterations (Δ2), and this offset remains roughly constant throughout the low-temperature region.

Next, we benchmark our neuromorphic higher-order Ising machine implementation on dedicated hardware for solving MAX-CUT problems. We implemented our higher-order Ising machine with graph coloring on the RFSoC 4 × 2 FPGA Kit featuring the Zynq UltraScale+ RFSoC XCZU48DR-2FFVG1517E core. Design choices and architectural details are provided in Methods Section “Acceleration on Synchronous Systems”. An important design detail to note here is that the noisy thresholds μ(t) in the FPGA implementation use 16-bit signed integers. However, all CPU-based algorithmic experiments reported in this work (unless otherwise specified) employed 64-bit floating-point thresholds. As shown in ref. 4, reducing noise-threshold precision increases the time required to reach a given solution quality. For all the experiments in this work, the FPGA runs at a 100 MHz clock frequency.

To evaluate the performance benefits of our implementation even on problems that naturally map to second-order interactions, we compared the FPGA-based higher-order Ising machine with graph coloring against NeuroSA4 (both CPU and SpiNNaker2 implementations) and the state-of-the-art simulated bifurcation machine by Toshiba60. We conducted these comparisons on three graph instances from the Gset benchmark57. The left barplot in Fig. 2c compares the best cuts achieved—expressed as a percentage of the SOTA—using the reported results from the other two implementations. The right barplot in Fig. 2c presents the time-to-solution (TTS) (see Methods Section “Benchmark problems and simulation methodology” for the definition of TTS in this context) for each implementation to reach its respective best cut. Detailed results are provided in Table S1 in the SI Section. Our implementation attains substantially lower TTS than previously reported second-order neuromorphic Ising machines and even outperforms NeuroSA on the G4 and G15 graphs in terms of best-cuts (achieving state-of-the-art for all three instances, unlike NeuroSA). Remarkably, our TTS is comparable to—and, for certain graphs, better than—that of the simulated bifurcation machine60. This performance advantage arises from optimized annealing given by FN annealer, sparse problem embedding, efficient clause-based traversal, and acceleration afforded by graph coloring during the high-temperature phase. For the detailed methodology of the TTS evaluation, see Methods Section “Benchmark problems and simulation methodology”.

Importantly, this scaling does not degrade despite our use of a 1/logt annealing schedule. When estimating TTS, we optimize the sampling period Δ (which controls the effective annealing rate) to minimize the median TTS for each problem size. Discussions

In this work, motivated by the resource efficiency of higher-order Ising machines, both in terms of the number of Ising variables and the number of connections, compared to second-order Ising machines, we present a neuromorphic higher-order Ising machine using an autoencoder architecture. We extended the isomorphic implementation of simulated annealing on a neuromorphic architecture onto a higher-order Ising machine using a Fowler-Nordheim annealer. The functional isomorphism ensures that the Ising machine can theoretically reach the ground state of the problem; however, in practice, this feature also ensures that high-quality solutions can be reliably generated across multiple runs.

The autoencoder-based architecture captures higher-order interactions by treating the clause outputs as the dynamic variables. For a p-body fully dense Hamiltonian, the total number of clause outputs M can scale as poorly as O(Np), where N is the number of spin variables. In such dense scenarios, each spin participates in q=O(Np−1) clauses, so even with our architecture the encoder hardware resources (interconnect) scale as O(N×Np−1), i.e., O(Np) overall. However, as noted in previously reported works48, 49, most practical higher-order optimization problem instances are sparse in the set of possible monomials/clauses Tk that are actually present. If the corresponding hypergraph is q-sparse, i.e., each spin appears in at most q clauses, then a worst-case upper bound on the number of clauses is M≤Nq. For a regular or near-regular sparse hypergraph with typical clause size close to p, this implies M≈Nqp. So, M effectively scales O(N) for fixed q and p as this monomial-level sparsity becomes more pronounced as the problem size grows: even as the total number of variables increases, the fan-in (q) remains much smaller than the total variable count (N)49. Just for an estimate, for randomly generated p-SAT instances at the phase-transition ratio (see Eq. (6)), asymptotically the typical number of clauses scales as M=O(2pN), which for fixed p is still linear in N (see SI Section S5). In this regime, even for a reconfigurable implementation, the resource complexity of a fully provisioned interconnect scales as O(N2), independent of the interaction order p. We use the term reconfigurable to denote a fixed, programmable architecture that is synthesized once with an upper bound on the number of clauses M and the maximum spin neighborhood q, and that can subsequently be programmed to realize any problem instance within those bounds. A straightforward way to guarantee this flexibility is to provision connectivity so that each spin can, in principle, receive input from all clauses, with the actual interconnections configured according to the specific instance. At large scale, even this O(N2) dependence can become prohibitive. By contrast, under a fully sparse problem embedding, the encoder stage only requires N × q interconnections. Whereas, the reconstruction in the decoder stage then incurs a resource cost on the order of M × p.

We also use this sparsity of the interconnection matrix to have massively parallel event generation across multiple latent neurons using techniques such as approximate graph coloring. We see from Fig. 2 that this graph coloring can help to quickly converge towards the solution in the high-temperature region. The limitation for this kind of technique is when the graph is sufficiently dense. For example, an all-to-all connected network would require O(N) colors, which would reduce the parallel event generation to a serial one. In those cases to satisfy the ergodicity property of simulated annealing we have to run it following the implementation we presented without coloring (see Algorithm 1 in Supplementary Information) which uses the asynchronous update mechanism given by the noise threshold incorporating the Bernoulli random variable (Ni,nB) as described in Methods Section “Derivation of the Autoencoder Based Model”. Or, another potential way out is to sparsify the graph using sparsification techniques as a preprocessing step24. But, since these techniques introduce auxiliary variables, this would be interesting to see whether parallel updates on sparse higher-order Ising machines with more variables would be advantageous than the one having serial updates with original objective polynomials.

To show the advantage of the higher-order Ising machine compared to the second-order Ising machine, we chose few satisfiable instances of MAX-3SAT problems from well-studied66, 67 benchmark dataset SATLIB61. The clause to variable ratio being equal to the phase-transition ratio makes them a hard problem for systematic SAT solver, stochastic local search-based solver as well as Ising-based solver68. We see from the results in Fig. 3, that the higher-order Ising machine outperforms the second-order Ising machine in both solution quality as well as time-to-solution (TTS). We also see that graph coloring further improves both solution quality as well as the TTS.

One may note that Eq. (2), came from the most general weighted Ising formula with any order of interactions, having many applications. Since H is a binary matrix, we can absorb the coupling coefficients or weights Jk into the row of H as discussed in Methods Section “Derivation of the Autoencoder Based Model”. So, embedding this weighted Ising formula translates to weighted integration of the clause outputs at the latent neurons. We presented an FPGA-based implementation utilizing the parallel updates utilizing the sparsity. For these implementations, we can binarize the clause outputs as mentioned in SI Section S8. This enables us to perform these weighted integrations at the inputs of latent neurons without the need for any multiplier. To compute this, we just need an adder tree of depth log(q) for each latent neuron (where q is the maximum neighborhood for that spin).

We further show, via the TTS-vs-problem-size scaling for 3R3X, that our higher-order Ising machine with an FN-annealer-driven 1/logt schedule achieves scaling comparable to that of previously reported sparse higher-order solvers that employ faster annealing schedules. For the benchmark instances considered here, most problems exhibit a relatively clear local gradient all the way to the planted optimum. As a result, when we optimize the annealing parameters to minimize TTS, the corresponding optimal runtime typically leads to convergence before the system enters the asymptotically slow, low-temperature regime where the schedule behaves strictly as 1/logt. In the high-temperature regime, the FN schedule is well approximated by a 1/t decay, which explains why our TTS remains competitive compared to prior results with faster schedules.

We emphasize, however, that this favorable scaling need not hold for worst-case NP-hard instances whose energy landscapes have little or no gradient information near the global optimum. In such settings, TTS scaling becomes strongly landscape dependent. Classical results by Hajek50 show that, for general landscapes, what determines whether simulated annealing can provably reach the global minimum is not the detailed shape of the schedule but whether it is slow enough relative to a landscape-dependent depth (barrier) parameter. In particular, it is both necessary and sufficient that the temperature decay be no faster than C/log(1+t), with C at least as large as this depth parameter. Thus, for easier problems with modest landscape depth, one does not need to realize the full asymptotic slowness of a 1/logt schedule in the low-temperature regime to obtain high success probabilities, which is consistent with our competitive TTS scaling. Conversely, for harder instances with large depth, the FN annealer can, in principle, be slowed to satisfy Hajek’s criterion, in which case a 1/logt schedule yields optimal asymptotic TTS scaling. We note that, in our TTS experiments, the annealing parameters were chosen to minimize empirical TTS rather than to satisfy Hajek’s sufficient conditions for guaranteed convergence.

In Section “Benchmarking MAX-3SAT and k-Regular-k-XORSAT on FPGA”, along with the results for the satisfiable SAT problem based on this FPGA implementation, we also show the results for unsatisfiable problem instances from SATLIB (see SI Section S16 for the detailed result). Many incomplete algorithms (Stochastic Local Search (SLS)) based Professional SAT solver perform worse on unsatisfiable problem instances compared to satisfiable SAT problems69. We note from our results that with an optimal annealing schedule, our higher-order Ising machine can find the ground state (since it reaches SAT which is = #clauses-1) even for the problem instance of the largest size from SATLIB in a short time.

It has been reported that70, generating high-quality random noise consumes significant energy and many neuromorphic architectures resort to physical noise (noise intrinsic in devices) as an efficient source of randomness. In our previous works51, 71, 72 we have reported a silicon-compatible device that is capable of producing O(1/log) decay required by the FN annealer. This device integrates the current due to single electrons tunneling through a Fowler-Nordheim tunneling barrier to generate this annealing behavior. Future work will investigate how to leverage these discrete single-electron events to produce exponentially distributed random variable NnE. Now, for the temperature annealing part, these physical FN-tunneling devices could be used as an extrinsic or intrinsic device. The sampling and scaling of the FN-decay can be chosen arbitrarily and is only limited by the resolution of the single-electron tunneling process (quantum uncertainty). This can be mitigated by choosing a larger size device or by modulating the voltage of the device. The time scale of the O(1/log) decay can therefore be adjusted to fit the scheduling presented in the algorithm. Note that even with the optimal noise schedule, higher precision sampling would be required. Due to the requirement of higher precision sampling of the FN device, we have resorted to a digital emulation of the FN-tunneling device on the FPGA platform. Note that our previously reported FN-devices51 could have been used for this purpose, but only in conjunction with analog-to-digital converters with more than 16-bit precision. The scope of this work is limited to developing a neuromorphic architecture incorporating efficient embedding of higher-order interaction that can utilize the FN-annealing dynamics.

In the autoencoder-based architecture proposed in this work, we avoid recomputing the clause outputs Tk,n from the full spin configuration at every step. Instead, we treat spin flips qi,n as the primary dynamic events and update the clause outputs incrementally. This spike-based representation is advantageous from an energy-to-solution perspective: only a small subset of spins flips at each time, so the number of switching events and associated hardware transitions is significantly reduced compared to recomputing all Tk,n from {si,n} on every iteration. A potential caveat, however, is that noise can occasionally induce a spurious flip in a clause output—i.e., a clause neuron may toggle even though no genuine spin in that clause should have flipped—leading to getting stuck in an inconsistent state in the clause space. In our discrete-time emulation, we address this in two ways. First, the noisy threshold at each latent neuron, μi,n, is chosen so that at most one spike is effectively accumulated at any decoder neuron within a given time step. This is enforced either by a global arbiter that selects a single spike among all candidate events, or, in the graph-colored case, by ensuring that spins sharing the same color never co-occur in the same clause. Second, at the decoder stage, we impose an additional threshold θ on the summed input, so that only sufficiently large, coherent inputs trigger a clause toggle. In the digital emulation used in this work we set θ = 0 to detect a valid spike, whereas in a practical neuromorphic instantiation θ would be chosen relative to the baseline noise level and spike amplitude of the underlying integrate-and-fire (IF) neurons. With such IF implementations of the clause neurons (see SI Section S2), the combination of μi,n and θ makes the clause dynamics robust to small, noisy perturbations in the latent layer and substantially reduces the probability of spurious clause flips. This robustness is also what motivates the ON-OFF IF realization of the toggle neurons.

For a fully neuromorphic implementation (see SI Section S2), spikes at the latent layer, qi,n, are generated by comparing the incrementally updated membrane potentials (which implement ΔEi,n) with the noisy thresholds μi,n. These membrane potentials are themselves updated only in response to changes in the clause outputs, encoded as (ΔTk,n+,ΔTk,n−) events. Because spin flips in an Ising machine are intrinsically stochastic, an occasional spurious fluctuation in (ΔTk,n+,ΔTk,n−) may perturb ΔEi,n, but such rare local errors have negligible impact on the global traversal of the energy landscape and therefore do not impose additional stringent constraints on μi,n. By contrast, the readout path for the spin variables must faithfully integrate the spike events qi,n into the corresponding spin states si,n within a finite time window. A natural way to enforce this is to employ an additional IF neuron per spin at the readout stage, whose integration window and threshold θ ensure reliable, noise-robust accumulation of the spin-flip spikes. Since the latent layer already enforces that at most one effective spike is delivered to any decoder neuron within a coarse integration window, the same threshold θ can be reused across the ON-OFF decoder pairs and the spin-readout IF neurons, provided there is coarse synchrony in their integration windows. Importantly, the interconnect complexity from latent neurons to decoder neurons is substantially higher than the one-to-one routing from latent neurons to spin readout, so the time needed to reliably collect readout spikes is typically much shorter than the time needed to collect clause spikes at the decoder. Thus, the integration window of these IF neurons can be chosen to upper-bound the worst-case propagation delay from any latent-layer neuron to any of its connected decoder neurons.

We, however, note that in a purely digital emulation of the proposed architecture based on the ON-OFF decoder pair, where spikes are represented as discrete digital pulses, there is no need to integrate inputs from the latent neurons at the clause-output layer and also at the spin readouts. Consequently, the changes in the clause outputs, encoded as (ΔTk,n+,ΔTk,n−), can be updated directly without an IF-neuron-based implementation and without thresholding. In this setting, errors that would create inconsistencies between the spin states and the clause-output states are therefore very unlikely.

The proposed autoencoder architecture can also be naturally mapped onto a dendritic computing model and hardware73, 74. This mapping is detailed in SI Section S17. In this mapping, the weighted aggregation of clause outputs at each latent neuron (encoder stage) corresponds directly to synaptic integration along individual dendritic branches. Likewise, the decoder stage—which reconstructs clause outputs from the latent space spins—parallels how the soma collects signals from multiple dendritic branches to generate each clause output. When the total synaptic input on a dendritic branch exceeds a noisy threshold, the local membrane potential undergoes a nonlinear amplification instead of remaining a purely linear sum of its inputs. Similar to our architecture in Fig. 1.d, the soma integrates these nonlinear dendritic events and compares the result against a somatic threshold θ. Whenever the summed dendritic contributions cross θ, we can likewise interpret this as a discrete spike at the dendritic branches—precisely mirroring the gating mechanism in our autoencoder. A subtlety of such dendritic architectures is that the order of synaptic arrivals can affect integration (due to temporal dynamics and location-dependent attenuation). However, for our autoencoder-to-dendrite mapping, we simplify by assuming that only the total synaptic charge within a fixed integration window matters. In other words, regardless of individual arrival times, if the cumulative input from all relevant clauses in that time window exceeds the branch threshold, the dendrite emits a spike. This implies a need for coarse synchrony—each dendritic branch must maintain an integration window so that inputs arriving in any order are summed appropriately. Beyond this requirement for synchronized integration windows, all other operations in our autoencoder correspond directly to dendritic processing stages.

Building on this dendritic architecture, implementing such architecture in hardware also can help us circumvent the limits of planar device scaling. As planar device miniaturization nears its fundamental limits, extending functionality into the third dimension has become an attractive path for boosting device density and expanding computational throughput. Notably, recent demonstrations of FeFET-based nanodendritic structures73 showcase how vertically stacked, dendrite-inspired pathways can deliver thermally robust, massively parallel processing within a neuromorphic 3D architecture. We envision that adopting these nanodendritic structures—whose design faithfully emulates the arborized signal integration and local nonlinear processing of biological dendrites—will empower such mapping to dendritic-computation-based neuromorphic higher-order Ising machine to overcome the scaling ceilings imposed by purely two-dimensional devices.

For spin readout, in the GF(2) representation, if the matrix H has full column rank (rank(H) = N), then the spin configuration {si} can be uniquely recovered from the clause outputs T (assuming the clause outputs are free of spurious errors) using, for example, Gaussian elimination over GF(2) at the end of the run, with computational complexity O(N3). In general, however, this uniqueness need not hold, since H may fail to have full column rank over GF(2) (e.g., when its columns are linearly dependent). Therefore, for general-purpose operation, it is preferable to update the spins si,n directly from the spin-flip events qi,n, starting from the initial assignment si,0. For a discussion of the proposed faithful readout of spin assignments in the fully neuromorphic implementation based on IF neurons, please refer to the Discussion Section 3.

FN Annealer based dynamical systems

To generate the noisy thresholds for the latent layer neurons, we employ the dynamical system model of a Fowler-Nordheim (FN) Annealer as detailed in ref. 4. This FN Annealer provides the required annealed random threshold in the form μi,n=τnNnE+ANi,nB, as needed for our autoencoder-based model discussed in Section “Derivation of the Autoencoder Based Model”.

Eq. (24) naturally separates the FN-annealer schedule into two asymptotic regimes. For t ≪ C, we have log(1+t/C)≈t/C, so τ(t)≈τ0Ct, i.e., the schedule is effectively proportional to 1/t. This high-temperature regime is illustrated by the white trajectory in Fig. 1e, where a clear gradient in the energy contour allows the dynamics to descend rapidly toward lower energies. In contrast, for t ≫ C we have log(1+t/C)≈log(t/C), so τ(t)≈τ0logt−logC∝1logt, recovering the asymptotically slow 1/logt schedule. This low-temperature regime, depicted by the orange trajectories in Fig. 1e, supports slow, noise-driven exploration near the valley where little or no gradient information is available, and is the regime that underpins the asymptotic convergence guarantees of simulated annealing.

For experiments carried out on both the CPU and the FPGA, we discretize the continuous cooling schedule τ(t) by sampling at tn = 1 + n Δ, and we vary the sampling period Δ, which directly controls the speed of the annealing process. For the experiments in Fig. 3a, Fig. 3b, Fig. 3d and Fig. 4d, since our objective was to obtain the intended solution with a high success probability, we ran these experiments with a slow annealing schedule. Therefore, in these experiments, the parameter C was set to 8 × 104, τ0 was set to 0.15625, and the mean value of the random variable NnE was set to − 0.083703 accordingly. For experiment in Fig. 3.a and Fig. 3.b the sampling period Δ was chosen to be 2 × 10−3. And, since for the unsatisfiable benchmarking experiment in Fig. 4d our goal was to search for the ground state for a particular instance of a problem across multiple runs in FPGA, we ran that experiment with a 10 × slower annealing schedule with sampling period Δ of 2 × 10−4. For the experiments in Fig. 4a–b, τ0 was set to 5 × 10−4, and the mean value of the random variable NnE was set to − 1. Generation of the population firing dynamics using PCA

To illustrate and visualize the network dynamics for the 3R-3X problem (Section “Experiment on small 3R-3X problem”), we applied principal component analysis (PCA) to perform dimensionality reduction on the population dynamics, following a procedure similar to that in ref. 56. The population spiking activity, represented by aggregate spiking rates, directly reflects the search behavior based on latent layer neuron events.

Spike-iteration recordings were collected for both higher-order (HO) and second-order (SO) network architectures under the conditions described in Section “Experiment on small 3R-3X problem”. Each neuron’s (only latent neuron’s for HO) list of spike timestamps was converted into a continuous firing-rate representation using a sliding-window estimator: instantaneous firing rates were obtained by counting spikes within overlapping, fixed-width windows that traverse the iteration axis. This process produced time-indexed rate vectors for all neurons. The resulting high-dimensional firing-rate matrices were then subjected to PCA to extract the principal three-dimensional trajectory that captures the majority of the population variance.

Note that the SO solver’s spiking activity spanned 20 neurons, whereas the HO Ising machine’s activity involved 10 latent neurons. Finally, the real-valued vector sequence was projected onto the three principal components, yielding the 3D trajectories shown in Fig. 1h. To suppress high-frequency fluctuations, each of the three principal component coordinates was smoothed with a short moving-average filter. This PCA based projection approach provides a concise, low-dimensional representation of how collective spiking activity evolves over iterations for each network architecture.

Acceleration on synchronous systems

While a fully asynchronous architecture would be ideal for our neuromorphic higher-order Ising machine, most existing accelerators are clocked—either fully synchronous with address-event-routing packet switching, or globally asynchronous but locally clocked via interrupt-driven units. In these clocked systems, we exploit the mutual independence and i.i.d. properties of the random variables NE and NB. Accordingly, in both variants of our higher-order Ising machine (with and without graph coloring), we use only the annealed exponential random variable NnE as the threshold μn for each neuron in latent layer. At each simulation step, multiple latent neurons may generate spike; those that do so synchronously are termed active latent-neurons.

In the colored version, conditionally independent active latent-neurons of the same color are processed in parallel, enabling a massively parallel update. In the uncolored version, to preserve ergodicity, we employ a global arbiter: first, all latent neurons undergo parallel thresholding to identify active ones; then the arbiter selects one active latent-neuron uniformly at random and discards the others. This rejection-free sampling boosts acceptance probability compared to the original simulated-annealing framework and is used in solvers such as DAU78. The full algorithmic implementation for both variants is given in SI Section S8.

For the results in Fig. 2c and Fig. 4, we implemented the graph-colored higher-order Ising machine on an FPGA (see SI Section S9 for details). The on-board Processing System (PS), controlled via PYNQ’s Python interface, configures, drives, and communicates with the Programmable Logic (PL) core solver. The PS master streams configuration bits and generated 16-bit random noise samples to the PL, emulating Fowler-Nordheim annealer behavior. Within the PL fabric, an AMD LogiCORE AXI DMA IP core manages bidirectional data transfer. Since the FPGA logic consumes one noise sample per clock cycle, the total clock cycle count in the core solver equals the number of samples dispatched by the PS. As each sample is sent, the Python controller increments a global counter.

For all the TTS experiments in Fig. 2c and Fig. 4, we run the FPGA for a fixed number of samples, which is determined by the grid of sampling period (Δ) for each problem size. We keep track of this total number of samples using the global counter and read out the total satisfied clause count (SAT count) for every sample. If it has found the solution within this total number of samples, we record a hit and restart for another independent run. For Fig. 4b, we preload a target SAT count in the Python master at configuration time; on each cycle the PS master monitors the SAT count sent by the FPGA slave over DMA and if it matches with the target SAT count, records the counter value, yielding the runtime. This measurement excludes communication overhead (e.g., DMA interrupt latency, software noise generation), which is included in the FPGA initialization phase. All the experiments on FPGA were run at a 10 ns clock period to meet timing constraints.

For CPU comparison in Fig. 4b, we implemented the same logic with same noise threshold precision in Python (VS Code v1.100.2, Python 3.11.9) on an Intel Ultra 9 Processor 185H (up to 5.10 GHz). Runtime was measured using the built-in function time.perf_counter_ns() to obtain nanosecond precision for the runtime to reach the intended solution.
