A Fast Binary Splitting Approach for Non-Adaptive Learning of Erdős–Rényi Graphs
Hoang Ta and Jonathan Scarlett

Abstract
We study the problem of learning an unknown graph via group queries on node subsets, where each query reports whether at least one edge is present among the queried nodes. In general, learning arbitrary graphs with n n nodes and k k edges is hard in the non - adaptive setting, requiring Ω ⁡ ( min ⁡ { k 2 ​ log ⁡ n , n 2 } ) \Omega\big(\min\{k^{2}\log n,\,n^{2}\}\big) tests even when a small error probability is allowed. We focus on learning Erdős–Rényi (ER) graphs G ∼ ER ⁡ ( n , q ) G\sim\mathrm{ER}(n,q) in the non - adaptive setting, where the expected number of edges is k ¯ = q ​ ( n 2 ) \overline{k}=q\binom{n}{2} , and we aim to design an efficient testing–decoding scheme achieving asymptotically vanishing error probability. Prior work (Li–Fresacher–Scarlett, NeurIPS 2019) presents a testing–decoding scheme that attains an order - optimal number of tests 𝒪 ⁡ ( k ¯ ​ log ⁡ n ) \mathcal{O}(\overline{k}\log n) but incurs Ω ⁡ ( n 2 ) \Omega(n^{2}) decoding time, whereas their proposed sublinear-time algorithm incurs an extra log ⁡ k ¯ ⋅ log ⁡ n \log\overline{k}\cdot\log n factor in the number of tests. We extend the binary splitting approach—recently developed for non - adaptive group testing—to the ER graph learning setting, and prove that the edge set can be recovered with high probability using 𝒪 ⁡ ( k ¯ ​ log ⁡ n ) \mathcal{O}(\overline{k}\log n) tests while attaining decoding time 𝒪 ⁡ ( k ¯ 1 + δ ​ log ⁡ n ) \mathcal{O}(\overline{k}^{1+\delta}\log n) for any fixed δ > 0 \delta>0 .

Introduction

One of the central problems in learning theory and combinatorial inference is to recover the structure of an unknown graph from indirect observations. In many settings of interest, edges are not observed directly; instead, one has access to a query mechanism. In this paper, we focus on the case that we can query subsets of vertices and learn whether at least one edge is present among them. We refer to this task as
graph learning via edge-detecting queries
. This problem arises in applications such as identifying which chemicals react with each other using tests that only detect whether any reaction occurs
[
13
]
, and it is closely related to the widely studied group testing problem
[
5
]
.

The objective is to design a testing–decoding scheme that minimizes the number of queries while ensuring efficient recovery. Two testing models are commonly considered. In the
adaptive
setting, queries are issued in rounds and may be chosen based on previously observed outcomes; at each round, the next query is selected as a function of the outcomes so far until sufficient information has been accumulated for reconstruction. In this setting, the problem is well understood
[
22
]
, and can be solved using
\mathcal{O}(k\log n)
queries for arbitrary graphs with
n
nodes and
k
edges. In the
non
-
adaptive
setting, all query subsets are fixed in advance and evaluated in a single batch, with no dependence on intermediate outcomes. An impossibility result
[
2
]
shows that, in the worst case over graphs with a bounded number of edges, significantly more non
-
adaptive tests are required: Any non
-
adaptive scheme that identifies arbitrary graphs with
n
nodes and
k
edges must use at least
\Omega\big(\min\{k^{2}\log n,\,n^{2}\}\big)
tests, even under a small-error criterion.

To circumvent the difficulty of worst-case graphs, a natural starting point is to study the Erdös–Rényi random graph model
\mathrm{ER}(n,q)
, in which each possible edge appears independently with probability
q
. Under this model, prior work
[
25
]
in the non
-
adaptive setting presents several designs that achieve asymptotically vanishing error with
\mathcal{O}(\overline{k}\log n)
tests (where
\overline{k}=q\binom{n}{2}
is the expected number of edges), but with decoding time that is not sublinear in
n
(e.g.,
\mathcal{O}(n^{2}\,\overline{k}\log n)
). Moreover, a general converse shows that any non
-
adaptive test design achieving asymptotically vanishing error must use at least
\Omega\big(\overline{k}\log(n^{2}/\overline{k})\big)
tests, implying that the
\mathcal{O}(\overline{k}\log n)
scaling is information-theoretically optimal in most regimes of
\overline{k}
. The same work also introduces a testing–decoding scheme based on the GROTESQUE algorithm from group testing
[
15
]
, achieving sublinear decoding time
\mathcal{O}\big(\overline{k}\log^{2}\overline{k}+\overline{k}\log n\big)
, but this comes at the expense of requiring
\mathcal{O}\big(\overline{k}\log\overline{k}\cdot\log^{2}n\big)
tests.

In this paper, we continue this line of work and propose a testing–decoding scheme that requires
\mathcal{O}(\overline{k}\log n)
tests while achieving a decoding time of
\mathcal{O}(\overline{k}^{1+\delta}\log n)
for any fixed
\delta>0
. This attains (nearly) the best of both objectives in terms of the number of tests and the decoding time. To achieve this goal, we extend the
binary splitting
approach for non
-
adaptive group testing, introduced in
[
31
]
, to the graph-learning setting. Despite the conceptual similarity, the details become significantly different and challenging in this setting for several inter-related reasons, e.g.:

•

An item being an a negative test is not in itself conclusive of anything. Rather, we can only detect
non-edge pairs
in negative tests.
Thus, we need a careful design that ensures most non-edge pairs will be at least one test
without
any edge pairs, and this consideration of pairs complicates matters compared to that of individual items in standard group testing.

•

When we group items into “nodes” at various levels following
[
31
]
, internal edges within such a node makes all of its tests positive and thus lacking in information on non-edge pairs.

•

Our initial solution incurs
\overline{k}^{1.5}
dependence in the decoding time due to checking
\Omega(\sqrt{\overline{k}})
tests for each of
\Omega(\overline{k})
pairs, and bringing the decoding time down to
\overline{k}^{1+\delta}
requires further refinements based on carefully splitting the graph learning problem into smaller subproblems.

1.1
Related Work

The problem of learning a graph via edge-detecting queries can be viewed as a form of group testing with structural constraints
[
5
, Section 5.8]
. In standard group testing, the goal is to identify
K
defective items among
N
items by querying subsets, and many variants have been studied (e.g., noisy vs. noiseless, as well as various pooling constraints). A particularly important distinction is that between the small-error setting, which allows an asymptotically vanishing failure probability (see
[
5
]
for a survey), and the zero-error setting, which requires exact identification in all instances (see
[
17
]
for a survey). These two settings lead to very different test requirements: in the small-error case
\mathcal{O}(K\log N)
tests suffice, whereas in the zero-error case
\Omega(\min\{N,\,K^{2}\})
tests are required. Graph learning with edge-detecting queries can be seen as a form of constrained group testing in which the “items” are potential edges and the admissible query sets are restricted by the graph structure. Throughout this work, we focus on the small-error setting and study the learning of Erdős–Rényi graphs, which is a fundamental subclass of general graphs.

Early work on graph learning with edge-detecting queries first focused on finding a single hidden edge
[
4
,
3
]
, and later on finding multiple edges
[
22
]
in a more general scenario in which the “defective” graph
G
is known to be a subgraph of a larger graph
H
. In particular, an adaptive procedure was proposed that recovers
G
using
k\log_{2}\big(\tfrac{|E(H)|}{k}\big)+\mathcal{O}(k)
tests, which is optimal up to the lower-order
\mathcal{O}(k)
term, where
k
is the number of edges of
G
. Beyond this general setup, several works analyze specific families such as matchings, stars, and cliques
[
19
,
7
,
6
]
. While the adaptive setting is relatively well understood, the non
-
adaptive setting
[
2
,
23
]
and adaptive strategies with a small number of stages
[
21
,
14
,
2
]
remain more challenging. In the Erdős–Rényi model
G\sim\mathrm{ER}(n,q)
, where the expected number of edges is
\overline{k}=q\binom{n}{2}
, prior work
[
25
]
in the non
-
adaptive setting shows that asymptotically vanishing error can be achieved with
\mathcal{O}(\overline{k}\log n)
tests, but with decoding time that is at least quadratic in
n
. As noted above, they also propose a sublinear-time algorithm based on GROTESQUE
[
15
]
, but it incurs an extra
\log\overline{k}\cdot\log n
term in the number of tests. The problem has also been generalized to hypergraphs; see
[
8
,
9
,
18
,
1
]
, and an Erdős–Rényi–type model for hypergraphs has likewise been explored
[
10
]
.

The binary splitting approach in group testing was first developed in the adaptive setting
[
20
]
, where it achieves near-optimal test complexity by recursively bisecting positive pools to isolate defectives. More recently, this method has been adapted to the non
-
adaptive setting—retaining the spirit of binary splitting through carefully designed test matrices and efficient decoders—and notably achieves
\mathcal{O}(k\log n)
scaling in both the number of tests and decoding time
[
31
,
16
,
30
,
32
]
.

1.2
Overview of Techniques and Contributions

We extend the binary splitting approach to the non
-
adaptive setting of graph learning via edge-detecting queries in the Erdős–Rényi model
\mathrm{ER}(n,q)
, where
n
is the number of vertices and
q=\Theta\big(n^{-2(1-\theta)}\big)
for
\theta\in(0,1)
is the edge probability. Let
\overline{k}
denote the expected number of edges in
G\sim\mathrm{ER}(n,q)
, namely
\overline{k}=q\binom{n}{2}
. By analogy with group testing, we also refer to edges as
defective pairs
of vertices. We propose a testing–decoding scheme that uses
\mathcal{O}(\overline{k}\log n)
tests and, with high probability, guarantees (i) recovery of the edge set of
G
, and (ii) decoding time
\mathcal{O}\big(\overline{k}^{1+\delta}\log n\big)
for any arbitrarily small
\delta>0
. Our method is summarized as follows:

•

Building on the binary splitting idea in
[
31
,
16
]
, we organize the vertices into a binary hierarchy of groups over levels
\ell=\log_{2}\sqrt{\overline{k}},\,\log_{2}\sqrt{\overline{k}}+1,\,\dotsc,\,\log_{2}n
, where level
\ell
has
2^{\ell}
blocks (groups)
\{\mathcal{G}^{(\ell)}_{1},\dots,\mathcal{G}^{(\ell)}_{2^{\ell}}\}
of size
n/2^{\ell}
. At each level, we run
\Theta(\sqrt{\overline{k}})
independent repetitions; within each repetition, blocks are assigned uniformly at random to one of
\Theta(\sqrt{\overline{k}})
tests, where placing a block means including all of its item in the test. With
\mathcal{O}(\log n)
levels, the total number of tests is
\mathcal{O}(\overline{k}\log n)
.

Given all test outcomes, the decoder proceeds deterministically from coarse to fine levels: it maintains a set of possible defective (PD) pairs, eliminates any block pair ruled out by a negative test, and otherwise refines surviving pairs into child–child pairs. At the leaf level (singletons), all remaining pairs not ruled out by a negative test are declared as edges. In Theorem
1
, we show that, with high probability, this pipeline recovers all edges of
G
using
\mathcal{O}(\overline{k}\log n)
tests, and the decoder runs in time
\mathcal{O}(\overline{k}^{1.5}\log\overline{k}\,\log n)
for
\theta>1/2
and
\mathcal{O}(\overline{k}^{1.5}\log^{2}\overline{k}\,\log n)
for
\theta\leq 1/2
; the
\mathcal{O}(\overline{k}^{1.5})
factor arises from checking
\Theta(\sqrt{\overline{k}})
candidate tests per retained pair across levels.

•

To overcome the
\mathcal{O}(\overline{k}^{1.5})
decoding bottleneck of the above approach, inspired by group testing ideas from
[
24
]
(but with very different details), we first partition the vertex set
V
into balanced parts
\mathcal{S}_{1},\dots,\mathcal{S}_{m}
and apply the binary splitting design separately to each induced subgraph
G_{ij}=G[\mathcal{S}_{i}\cup\mathcal{S}_{j}]
. Working on these smaller instances sharply reduces the number of edges per subproblem, and hence the per–pair checking cost in decoding. However, a naive union bound over all
G_{ij}
may still yield a poor overall success probability, so we incorporate a permutation amplification step: for each
G_{ij}
, we apply a small collection of random permutations to its vertices and run the non–adaptive design under each permutation. This guarantees that at least one permutation produces a favorable block structure for each
G_{ij}
, allowing a union bound across subgraphs while keeping the total number of tests at
\mathcal{O}(\overline{k}\log n)
. We will formalize the permutation based block construction, prove concentration bounds for edge counts and block degrees, introduce a notion of typicality that holds with high probability, and then present the resulting testing–decoding scheme. As stated in Theorem
2
, with high probability our method recovers the edge set of
G
using
\mathcal{O}(\overline{k}\log n)
tests and achieves decoding time
\mathcal{O}(\overline{k}^{1+\delta}\log n)
for any fixed
\delta>0
.

Problem Setup and Preliminaries

We consider the problem of learning the edge structure of an unknown undirected graph
G=(V,E)
.
The vertex set is
V=[n]:=\{1,2,\dots,n\}
, while the edge set
E\subseteq\binom{V}{2}
is random.
Specifically, under the Erdős–Rényi (ER) model
[
25
]
, each potential edge
(i,j)\in\binom{V}{2}
is included independently with probability
q=q(n)
, so that
G\sim\mathrm{ER}(n,q)
.
Once drawn, the graph remains fixed but is unknown, and the learner has no direct access to
E
.
Information about
G
is obtained through
edge-detecting queries
:
given a subset
S\subseteq V
, a query returns one bit indicating whether there exists an edge of
E
fully contained in
S
. The objective is to design a
non-adaptive
collection of such queries—fixed in advance—together with a decoder that reliably reconstructs
E
.

The problem setting is described in more detail as follows. The edge set is to be recovered through a sequence of binary queries.
A query is represented by a vector
X\in\{0,1\}^{n}
, where
X_{i}=1
indicates the inclusion of vertex
i
.
The corresponding outcome is

Y\;=\;\bigvee_{(i,j)\in E}\bigl(X_{i}\land X_{j}\bigr),

that is, the output equals one if at least one edge of
E
is entirely contained in the selected set of vertices, and zero otherwise.
In the
non-adaptive
setting, the collection of test vectors

X^{(1)},\dots,X^{(t)}
must be fixed in advance, without access to intermediate outcomes, which renders the reconstruction task more difficult than in the adaptive case.

Given the observed outcomes
\{Y^{(i)}\}_{i=1}^{t}
,
a decoder produces an estimate
\widehat{G}=(V,\widehat{E})
.
The performance is measured by the error probability

P_{e}\;\coloneqq\;\mathbb{P}\big[\,\widehat{E}\neq E\,\big],

where the probability is taken over both the Erdős–Rényi graph and the randomness of the test design.
The objective is to design a procedure such that
P_{e}\to 0
as
n\to\infty
.

2.1
Sparsity Regime

We focus on sparse graphs, which commonly arise in applications such as biological interaction networks, road networks, and sensor graphs.
Sparsity is parameterized by a constant
\theta\in(0,1)
via

q\;=\;\Theta\bigl(n^{-2(1-\theta)}\bigr),

so that the expected number of edges satisfies

\overline{k}\;=\;q\binom{n}{2}\;=\;\Theta\bigl(n^{2\theta}\bigr).

Equivalently, as
\theta
ranges over
(0,1)
, we have
n^{-2}\ll\;q\ll\;1
, and thus
1\ll\overline{k}\ll n^{2}
,
where
f(n)\ll g(n)
abbreviates
f(n)=o\bigl(g(n)\bigr)
.

These sparsity regimes are well studied in random-graph theory and information-theoretic learning.
For example, the very sparse case
\theta\leq\tfrac{1}{2}
is relevant to connectivity thresholds and percolation
[
11
]
, and the denser range
\theta>\tfrac{1}{2}
appears in social-network modeling and large-scale biological systems
[
29
]
.

2.2
Mathematical and Computational Assumptions

Throughout the paper, we work in the unit-cost word-RAM model. With
n
vertices and
T
tests, reading any integer in
\{1,\dots,n\}
, performing basic arithmetic on such integers, and retrieving any test outcome (indexed by
\{1,\dots,T\}
) each take
\mathcal{O}(1)
time.

Without loss of generality, we assume that
n
is a power of two. When this is not the case, the graph can be augmented by adding up to
2^{\lceil\log_{2}n\rceil}-n
dummy vertices so that the total number of vertices equals the next power of two. Since these additional vertices are isolated and introduce no edges, they do not affect the test outcomes or the recovery procedure. Consequently, all subsequent results remain valid under this assumption.

2.3
Level Graphs

As we have already hinted, our algorithm considers groups of nodes at various levels that are always tested together, starting with larger groups that are recursively split into smaller groups until the final level containing only singletons. We will provide further details when describing our algorithm; see in particular Figure
1
in Section
3
. For now, we only give a brief description to the extent required in the next subsection.

For each
level

\ell\in\{\lceil\log_{2}\sqrt{\overline{k}}\rceil,\dots,\log_{2}n\}
, let
g\coloneqq 2^{\ell}
, and let
\{\mathcal{G}_{1},\dots,\mathcal{G}_{g}\}
be a balanced partition of
V
into
g

\mathcal{G}_{i}\coloneqq\big\{\,(i-1)\tfrac{n}{g}+1,\ \dots,\ i\tfrac{n}{g}\,\big\},\qquad i\in[g].

We call a block
\mathcal{G}_{i}

if it contains at least one edge of
G
, and we call

a

if

contains at least one edge of

. Then, we introduce the following quantities that we will use regularly:

•

•

, where

3
Binary Splitting Approach for Graph Learning

We now present our first algorithm for non-adaptive graph recovery. The method builds upon ideas from hierarchical binary splitting for standard group testing
[
31
,
16
]
. It consists of the construction of a sequence of tests, and a decoding procedure that recovers the edge set from the test outcomes. The main idea is to partition the vertex set hierarchically and perform tests on blocks to determine whether edges exist between them. Here, placing a block into a test means placing all of its items, essentially creating a “super-item”.

As illustrated in Figure
1
, at each level of the hierarchy, we divide the vertex set into smaller blocks (groups). We then use randomized test assignments to probe the presence or absence of edges. Negative test outcomes allow us to rule out large numbers of candidate edge pairs efficiently. When two larger blocks (say
\mathcal{G}_{1},\mathcal{G}_{2}
in generic notation) are not ruled out and thus believed to (potentially) have an edge between them, and we split them both into smaller blocks (say
\mathcal{G}_{1}^{(L)},\mathcal{G}_{1}^{(R)}
and
\mathcal{G}_{2}^{(L)},\mathcal{G}_{2}^{(R)}
of half the size), we treat all combinations of resulting edges as potentially possible: (i) an internal edge in one of the 4 smaller groups; (ii) a “formerly internal” edge between
\mathcal{G}_{i}^{(L)}
and
\mathcal{G}_{i}^{(R)}
for
i\in\{1,2\}
; or (iii) a “cross-group” edge between some
\mathcal{G}_{1}^{(\cdot)}
and some
\mathcal{G}_{2}^{(\cdot)}
.

\ell\in\{0,1,2,3,4\}

3.1
Testing Procedure

As outlined above (and in Section
2.3
), we construct a binary tree of vertex groups across levels
\ell=\lceil\log_{2}\sqrt{\bar{k}}\rceil,\lceil\log_{2}\sqrt{\bar{k}}\rceil+1,\dotsc,\log_{2}n
. Each node in the tree corresponds to a block of vertices. At level
\ell
, there are
2^{\ell}
blocks
\{\mathcal{G}^{(\ell)}_{1},\dotsc,\mathcal{G}^{(\ell)}_{2^{\ell}}\}
, each containing
n/2^{\ell}
vertices. We perform randomized testing as follows for some constants
C_{1},C_{2}>0
to be chosen later:

•

Create
C_{2}\sqrt{\overline{k}}
sequences of tests (“repetitions” or “iterations”), each of length
C_{1}\sqrt{\overline{k}}
;

•

Within each repetition, each group is assigned uniformly at random to one of these
C_{1}\sqrt{\overline{k}}
tests.

Intuitively, the reason for choosing
\mathcal{O}(\sqrt{\overline{k}})
tests per repetition and
\mathcal{O}(\sqrt{\overline{k}})
repetitions is that this amounts having
\mathcal{O}(k)
tests total and an
\mathcal{O}(\frac{1}{k})
probability of a given test containing a given
pair
of nodes. These both match the scalings that arise in standard group testing
[
31
]
, in particular ensuring that the probability of a given test being positive is bounded away from 0 and 1, implying non-vanishing entropy per test. See Algorithm
1
for a full description of the test design.

3.2

The decoder is deterministic and proceeds in a coarse-to-fine manner over levels

possible defectives

that may still contain a true edge at the current resolution. A pair
(\mathcal{G}_{i},\mathcal{G}_{j})

and
\mathcal{G}_{j}

and
\mathcal{G}_{j}

(\mathcal{G}_{i}^{(L)},\mathcal{G}_{j}^{(L)}),\;(\mathcal{G}_{i}^{(L)},\mathcal{G}_{j}^{(R)}),\;(\mathcal{G}_{i}^{(R)},\mathcal{G}_{j}^{(L)}),\;(\mathcal{G}_{i}^{(R)},\mathcal{G}_{j}^{(R)}),\;(\mathcal{G}_{i}^{(L)},\mathcal{G}_{i}^{(R)}),\;(\mathcal{G}_{j}^{(L)},\mathcal{G}_{j}^{(R)}).

(5)

\ell=\log_{2}n
, we conduct
\mathcal{O}\big(\sqrt{\overline{k}}\log n\cdot|\mathcal{PD}^{(\ell)}|\big)
outcome checks.

As shown above, with probability at least
1-\mathcal{O}\big(\frac{\log n}{\sqrt{\overline{k}}}\big)
, we have
|\mathcal{PD}^{(\ell)}|\leq 48\overline{k}
for all
\ell\in\{\lceil\log_{2}\sqrt{\overline{k}}\rceil,\dots,\log_{2}n\}
. Therefore, the total number of outcome checks in the decoding procedure is at most
\mathcal{O}(\overline{k}^{1.5}\log n)
, with probability at least
1-\mathcal{O}\big(\frac{\log n}{\sqrt{\overline{k}}}\big)
.

A similar argument applies to the case
\theta\leq\frac{1}{2}
, with at most
\mathrm{E}_{\max}=2\overline{k}\log^{2}\overline{k}
(see (
2
)) defective pairs at each level.

•

Decoding time with pre-processing:
At each level
\ell
, for each pair
(u,v)\in[g]\times[g]
with
g=2^{\ell}
, let
\mathrm{IND}^{\ell}(u,v)
be the set of test indices that contain both
u
and
v
. Recall that in each round (among
C_{2}\sqrt{\overline{k}}
rounds), the probability that
u
and
v
appear in the same test is
\frac{1}{C_{1}\sqrt{\overline{k}}}
. The
C_{2}\sqrt{\overline{k}}
iterations are independent, and using
C_{2}=C_{1}^{2}
, we have

\mathbb{E}\!\big[\,|\mathrm{IND}^{\ell}(u,v)|\,\big]\;=\;\frac{C_{2}\sqrt{\overline{k}}}{C_{1}\sqrt{\overline{k}}}\;=\;C_{1}.

Therefore, by the Chernoff bound (see (
30
) in Appendix
A
), we have

\mathbb{P}\big[\,|\mathrm{IND}^{\ell}(u,v)|>3\log n\,\big]\;\leq\;\Big(\frac{eC_{1}}{3\log n}\Big)^{3\log n}\;=\;\mathcal{O}\!\Big(\frac{1}{\log n}\Big)^{\log n}.

Taking a union bound over at most
\log_{2}n
levels, each with at most

pairs, we obtain that for all
\ell\in\{\lceil\log_{2}\sqrt{\overline{k}}\rceil,\dots,\log_{2}n\}
and all
(u,v)\in[g]\times[g]
with
g=2^{\ell}
, we have

\mathbb{P}\big[\,|\mathrm{IND}^{\ell}(u,v)|\leq 3\log n\,\big]\;\geq\;1-\mathcal{O}\!\Big(n^{2}\log n\cdot\big(\tfrac{1}{\log n}\big)^{\log n}\Big),

(17)

which in turn behaves as
1-o(1)
.

After fixing the test design, at each level
\ell
and for each pair
(u,v)\in[g]\times[g]
, we can find
\mathrm{IND}^{\ell}(u,v)
in
\mathcal{O}(\sqrt{\overline{k}})

C_{2}\sqrt{\overline{k}}
tests at level
\ell
. Hence, the total time to compute all sets
\mathrm{IND}^{\ell}(u,v)
over all
\mathcal{O}(\log n)
levels and all
\mathcal{O}(n^{2})
pairs is
\mathcal{O}(n^{2}\sqrt{\overline{k}}\log n)
.

With this pre-processing, for every potentially defective pair at each level, the decoder only needs to check at most
3\log n
test outcomes, rather than
\mathcal{O}(\sqrt{\overline{k}})
of them as we did before. Therefore, the scaling of the decoding time decreases by a factor of
\frac{\sqrt{\overline{k}}}{\log n}
, meaning it becomes
\mathcal{O}(\overline{k}\log^{2}n)
for
\theta>1/2
, and
\mathcal{O}(\overline{k}\log^{2}\overline{k}\,\log^{2}n)
for
\theta\leq 1/2
.

•

Error probability:
As shown above (in the analysis of Decoding Time), we have

\mathbb{P}\Big[\max_{\ell_{\min}\leq\ell\leq\log_{2}n}\big|\mathcal{PD}^{(\ell)}\big|\leq 12\mathrm{E}_{\max}\Big]\;\geq\;1-\mathcal{O}\Big(\tfrac{\log n}{\sqrt{k}}\Big)\,,

(18)

where we recall that

for

for

.

(u,v)
in
\mathcal{PD}^{(\log_{2}n)}
at the final level, over a given sequence of

) in Lemma

\displaystyle\mathbb{P}\big[(u,v)\text{ is not identified among }C_{1}C_{2}\overline{k}\text{ tests}\big]\;\leq\;\exp\big(-(C_{1}-23)\big)\,.

Since we perform

repetitions with

, we have

\displaystyle\mathbb{P}\big[(u,v)\text{ is not identified at the final level}\big]\;\leq\;\mathcal{O}(n^{-C^{\prime}})\,.

(19)

Combining Lemma

•

4
Improved Decoding Time via Partitioning and Permutations

The binary splitting approach in the previous section ensures recovery with an order–optimal number of tests, but the
\overline{k}^{1.5}
dependence in the decoding time (in the absence of pre-processing) has room for improvement. The bottleneck arises because the decoder needs to check
\mathcal{O}(\sqrt{\overline{k}})
tests for each pair in the set of possible defectives. To address this, we will partition the vertex set
V
into equal-size subsets
\mathcal{S}_{1},\dots,\mathcal{S}_{m}
and apply the binary-splitting approach to each induced subgraph formed by taking the union of pairs of these, i.e.,
G_{ij}=G[\mathcal{S}_{i}\cup\mathcal{S}_{j}]
. On these smaller graphs, the number of edges is much smaller, and thus the per-pair checking time in decoding is significantly reduced.

The general idea of solving multiple smaller problems has been explored in non-adaptive group testing
[
24
]
. In short, their idea is to create multiple subproblems, and randomly place each item in a constant number of subproblems and “zero out” the rest, creating a problem with very few defectives, which is solved using binary splitting. They decode each item via a combined “vote” over the (few) subproblems it was placed in. However, there are at least two major issues in applying their approach to our setting: (i) It is difficult for us to use
random
placements into subproblems while ensuring that
pairs
of items (rather than just individual items) appear together in sufficiently many of them; and (ii) the error probability of each subproblem is harder to control tightly in our setting, and this lack of tightness can lead to a total exceeding 1 upon applying a union bound over subproblems.

To alleviate such issues, we incorporate a small collection of random permutations into the design: Before applying the non–adaptive tests on each
G_{ij}
, we permute its vertices several times and run the binary splitting algorithm under each permutation. This technique of
permutation amplification
has been employed in various settings to boost the probability of success in randomized algorithms
[
28
]
. Here it ensures that at least one permutation yields a favorable block structure for each
G_{ij}
, so that a union bound across all subgraphs guarantees high overall success probability. Crucially, the total number of tests remains
\mathcal{O}(\overline{k}\log n)
.

We begin by formalizing the subgraph approach and introducing the permutation–based block construction. We then establish concentration bounds for edge counts and block degrees under random permutations. Next, we define the notion of a typical set of graphs with permutations and prove that such typicality holds with high probability. Finally, we present the permutation–based testing and decoding procedures and conclude with the main theorem on its guarantees.

4.1
Subgraphs and Random Permutations

Definitions of subgraphs.
Let
G\sim\mathrm{ER}(n,q)
with
q=\Theta\big(n^{-2(1-\theta)}\big)
for some
\theta\in(0,1)
, and let
\overline{k}=q\binom{n}{2}=\Theta(n^{2\theta})
. Fix
\gamma\in\big(0,\min\{1,\tfrac{1-\theta}{3\theta}\}\big)
(arbitrarily close to zero) and partition

into

\displaystyle m\coloneqq\ \sqrt{\tfrac{\overline{k}}{\overline{k}^{\gamma}}}\ =\ \overline{k}^{\frac{1-\gamma}{2}}

\mathcal{S}_{1},\dots,\mathcal{S}_{m}
. For each

with

be the subgraph induced by

\displaystyle k_{ij}\coloneqq\ |E(G_{ij})|\,,\text{ and }n_{ij}\coloneqq\ |V(G_{ij})|=2n\cdot\overline{k}^{\frac{\gamma-1}{2}}\,.

Let

denote the expected number of edges in
G_{ij}

2.2

We again use the idea of partitioning in levels (Section
2.3
). We denote the index of the smallest level by

(and its number of groups by

\displaystyle\ell_{0}\coloneqq\lceil\log_{2}\overline{k}^{2\gamma}\rceil,\text{ and }g_{0}\ \coloneqq\ 2^{\ell_{0}}\ \leq\ n_{ij},

(20)

where

follows from

. This choice is slightly higher in the sense that Section
3
would suggest using

instead of

below, and the resultant condition (C2) in Definition

For each pair

and level

with

.
Following Section

U_{v}\coloneqq\big\{\,(v-1)\tfrac{n_{ij}}{g}+1,\ \dots,\ v\tfrac{n_{ij}}{g}\,\big\},\qquad v\in[g].

Pairwise independent permutation family.
Let
N\geq 1
be an integer. A

\pi

is a bijection
\pi:[N]\to[N]
. Let

denote the set of all permutations on

is a

if, when a random permutation

and every distinct

\mathbb{P}_{\pi\sim\mathrm{Unif}(\mathcal{F}_{N})}\big[\pi(x_{1})=y_{1}\,,\,\pi(x_{2})=y_{2}\big]\;=\;\frac{1}{N(N-1)}.

That is, the pair
(\pi(x_{1}),\pi(x_{2}))
is uniformly distributed over
\binom{N}{2}
pairs.

When working with a family
\mathcal{F}_{N}\subseteq\mathcal{S}_{N}
, explicitly storing an arbitrary permutation from
\mathcal{F}_{N}
requires
N
entries (i.e.,
\Theta(N\log N)
bits). However, it is possible to design

so that each permutation is described by only a constant number of parameters, yielding an

-bit representation while still retaining the desired randomness properties (e.g., pairwise independence). In particular, if

is a power of two, one can construct such a family

using affine permutations over the finite field of order

,
\mathbb{F}_{N}
. For

and

, define

\pi_{a,b}(x)=ax+b,

where all operations are over
\mathbb{F}_{N}
. Then each
\pi_{a,b}
is a permutation of
\mathbb{F}_{N}
. Fix a bijection between
[N]
and
\mathbb{F}_{N}
, which we write as
[N]\cong\mathbb{F}_{N}
. Under this bijection, the family
\mathcal{F}_{N}
is parameterized by
(a,b)\in(\mathbb{F}_{N}\setminus\{0\})\times\mathbb{F}_{N}
. The construction details are given in Appendix
C
. Most importantly for our purposes, (i) the set
\{\pi_{ab}\}
forms a pairwise independent permutation family, and (ii) for any input

, both
\pi_{a,b}(x)
and the inverse
\pi_{a,b}^{-1}(x)
can be computed in
\mathcal{O}(1)
time in the word-RAM model.

To simplify notation, assume (for now) that the vertex set

is labeled as
\{1,2,\dots,n_{ij}\}
. Draw

from a pairwise independent permutation family on

. For any fixed

where

for all

.
Since

is a bijection,

Let
\pi
be a generic permutation on

. We define the

(with

) as follows: its vertex set

consists of the

(r,s)\in E\big(H_{ij}^{(\pi,\ell)}\big)\ \iff\ \exists\,x\in\pi(U_{r}),\ \exists\,y\in\pi(U_{s})\ \text{such that }(x,y)\in E(G_{ij}).

(21)

Analogous to Section

, we introduce the following definitions:

•

: the number of

•

. Here, for convenience, the maximum is taken over all blocks at level

4.2
High-Probability Graph and Permutation Properties

In the following lemmas, we establish high-probability properties of the random subgraphs and random permutations, some of which serve as counterparts to those used in Section
3
. Note that we sometimes study the randomness of edges (for a fixed permutation) and sometimes study the randomness of permutations (for a fixed graph); we will accordingly take care when combining these properties in Section
4.3
.

Lemma 5
.

Under the preceding setup, with probability
1-o(1)
, we have

\displaystyle\overline{k}^{\gamma}\leq k_{ij}\coloneqq|E(G_{ij})|\leq 12\overline{k}^{\gamma},\quad\forall(i,j)\in[m]\times[m],

where
m=\overline{k}^{\frac{1-\gamma}{2}}
.

Proof.

Each
G_{ij}
has
n_{ij}
vertices, so

\overline{k}_{ij}\coloneqq\mathbb{E}[k_{ij}]=q\cdot\binom{n_{ij}}{2}\,,

and recalling
n_{ij}=2n\cdot\overline{k}^{\frac{\gamma-1}{2}}
, this implies

q\cdot n^{2}\cdot\overline{k}^{\gamma-1}\leq\overline{k}_{ij}\leq 2q\cdot n^{2}\cdot\overline{k}^{\gamma-1}\,.

Substituting
\overline{k}=q\binom{n}{2}\in\big[\frac{1}{4}qn^{2},\frac{1}{2}qn^{2}\big]
, we obtain

2\overline{k}^{\gamma}\leq\overline{k}_{ij}\leq 8\overline{k}^{\gamma}.

(22)

The edges are independently generated, so by the Chernoff bound, we have

\mathbb{P}\left[|k_{ij}-\overline{k}_{ij}|\geq\frac{1}{2}\overline{k}_{ij}\right]\leq\exp\big(-\Omega(\overline{k}^{\gamma})\big)\,.

Therefore, for each
(i,j)
, we have

\mathbb{P}[\overline{k}^{\gamma}\leq k_{ij}\leq 12\overline{k}^{\gamma}]\geq 1-\exp\big(-\Omega(\overline{k}^{\gamma})\big)\,.

(23)

There are at most
\binom{m}{2}\leq m^{2}=\overline{k}^{1-\gamma}
pairs, so by union bound, we have

\mathbb{P}\left[\exists(i,j):k_{ij}>12\overline{k}^{\gamma}\text{ or }k_{ij}<\overline{k}^{\gamma}\right]\leq m^{2}\exp\big(-\Omega(\overline{k}^{\gamma})\big)\to 0.

Therefore, with probability
1-o(1)
, we have
\overline{k}^{\gamma}\leq k_{ij}\leq 12\overline{k}^{\gamma}
for all
(i,j)
.
∎

Recall that
\mathcal{T}(\epsilon_{n})
denotes the typical set of graphs defined in Section
2.4
, and
\nu_{g}\big(H_{ij}^{(\pi,\ell)}\big)
denotes the number of defective vertices (blocks) in
H_{ij}^{(\pi,\ell)}
, with
g=2^{\ell}
. The following lemma shows that, for any fixed graph
G\in\mathcal{T}(\epsilon_{n})
and any fixed pair
(i,j)\in[m]\times[m]
, if
\pi
is chosen uniformly at random from a pairwise independent permutation family, then with high probability the block graph
H_{ij}^{(\pi,\ell_{0})}
contains no defective vertices, where
\ell_{0}=\lceil\log_{2}\overline{k}^{2\gamma}\rceil
.

Lemma 6
.

Fix
G=(V,E)\in\mathcal{T}(\epsilon_{n})
and a pair
(i,j)\in[m]\times[m]
.
Let
\pi
be drawn uniformly from a pairwise independent permutation family on
[n_{ij}]
, and let
H_{ij}^{(\pi,\ell_{0})}
denote the level–
\ell_{0}
block graph (see (
21
)), where
\ell_{0}\coloneqq\lceil\log_{2}\overline{k}^{2\gamma}\rceil
and
g_{0}\coloneqq 2^{\ell_{0}}
. Then

\displaystyle\mathbb{P}\Big[\nu_{g_{0}}\big(H_{ij}^{(\pi,\ell_{0})}\big)=0\,\Big|\,G_{ij}\Big]

\displaystyle\ \geq\ 1-\frac{k_{ij}}{g_{0}}\,,

where
k_{ij}=|E(G_{ij})|
.
Moreover, if
\pi_{1},\ldots,\pi_{c}
are i.i.d. permutations drawn uniformly from a pairwise independent permutation family on
[n_{ij}]
, then

\displaystyle\mathbb{P}\Big[\exists\,t\in[c]:\ \nu_{g_{0}}\big(H_{ij}^{(\pi_{t},\ell_{0})}\big)=0\,\Big|\,G_{ij}\Big]

\displaystyle\ \geq\ 1-\Big(\frac{k_{ij}}{g_{0}}\Big)^{c}.

Proof.

Index the unpermuted blocks by
v\in[g_{0}]
, and define the indicator variable that the permuted block
\pi(U_{v})
is defective:

\displaystyle D_{v}\coloneqq\ \mathbf{1}\left\{\exists\,e=(x,y)\in E(G_{ij})\ \text{ such that }\ \{x,y\}\subset\pi(U_{v})\right\}.

For a fixed edge
e=(x,y)\in E(G_{ij})
, let

X_{v,e}\coloneqq\mathbf{1}\{\{x,y\}\subset\pi(U_{v})\}=\mathbf{1}\{\{\pi^{-1}(x),\pi^{-1}(y)\}\subset U_{v}\}.

Since
\pi
is pairwise independent, the unordered pair
(\pi^{-1}(x),\pi^{-1}(y))
is uniform over
\binom{n_{ij}}{2}
pairs. Hence,

\displaystyle\mathbb{P}\big[X_{v,e}=1\big]\ =\ \frac{\binom{|U_{v}|}{2}}{\binom{n_{ij}}{2}}\ \leq\ \frac{\binom{n_{ij}/g_{0}}{2}}{\binom{n_{ij}}{2}}\ \leq\ \frac{1}{g_{0}^{\,2}}.

By definition,
D_{v}\leq\sum_{e\in E(G_{ij})}X_{v,e}
, and hence

\displaystyle\mathbb{E}[D_{v}]\ \leq\ \sum_{e\in E(G_{ij})}\mathbb{E}[X_{v,e}]\ \leq\ k_{ij}\cdot g_{0}^{-2}.

Summing over
v
and using linearity of expectation,

\displaystyle\mathbb{E}\left[\nu_{g_{0}}\big(H_{ij}^{(\pi,\ell_{0})}\big)\right]\ =\ \sum_{v=1}^{g_{0}}\mathbb{E}[D_{v}]\ \leq\ g_{0}\cdot\frac{k_{ij}}{g_{0}^{2}}\ =\ \frac{k_{ij}}{g_{0}}.

By Markov’s inequality,
\mathbb{P}[\nu_{g_{0}}\geq 1]\leq k_{ij}/g_{0}
, which yields the first part of the lemma. The second part follows directly from the independence of
\{\pi_{t}\}_{t=1}^{c}
across
t
.
∎

The following lemma shows that, for any pair
(i,j)\in[m]\times[m]
, the maximum degree of

is at most

with high probability, where we recall that

Lemma 7
.

Fix
\theta\in(0,1)
and
(i,j)\in[m]\times[m]
. Let
G\sim\mathrm{ER}(n,q)
for some
q=\Theta(n^{-2(1-\theta)})
, and let
\pi
be a fixed permutation on
[n_{ij}]
. For each
\ell\in\{\ell_{0},\ell_{0}+1,\dots,\log_{2}(n_{ij})\}
, let
g\coloneqq 2^{\ell}
, and let
H_{ij}^{(\pi,\ell)}
denote the level-
\ell
block graph (see (
21

\overline{k}_{ij}\coloneqq q\binom{n_{ij}}{2}=\Theta(\overline{k}^{\gamma})
. Under the preceding setup and definitions, we have

\mathbb{P}\Big[d_{g}\big(H_{ij}^{(\pi,\ell)}\big)>\sqrt{\overline{k}_{ij}}\Big]\ \leq\ n_{ij}\cdot\left(\frac{16e}{\overline{k}^{3\gamma/2}}\right)^{\overline{k}^{\gamma/2}}\,.

Proof.

Fix a particular block
U
(a vertex of
H_{ij}^{(\pi,\ell)}
), and let
Z\coloneqq d_{g}(U)
denote its degree in
H_{ij}^{(\pi,\ell)}
. For notational convenience, suppose that
U
is the
g
-th block, and for each
i\in[g-1]
, let
Z_{i}
be the indicator random variable for the event that there is at least one edge between the two blocks
U
and
U_{i}
. By definition,

\displaystyle Z=\sum_{i=1}^{g-1}Z_{i}\,.

Since each edge is generated independently, we have

\displaystyle\mathbb{P}[Z_{i}=1]=1-(1-q)^{|U|^{2}}\,.

Since
|U|=\tfrac{n_{ij}}{g}
, similar to (
32
), substituting
n_{ij}=2n\,\overline{k}^{(\gamma-1)/2}
and
q=\tfrac{\overline{k}}{\binom{n}{2}}
, and using the standard bound
\tfrac{q|U|^{2}}{2}\leq 1-(1-q)^{|U|^{2}}\leq q|U|^{2}
(for

), we obtain

\displaystyle\mathbb{P}[Z_{i}=1]\;

\displaystyle\leq\;\frac{16\overline{k}^{\gamma}}{g^{2}},

\displaystyle\mathbb{E}[Z]\;

\displaystyle\leq\;\frac{16\overline{k}^{\gamma}}{g}\,.

From

, it follows that

\mathbb{E}[Z]\leq\frac{16\overline{k}^{\gamma}}{g}\leq 16\overline{k}^{-\gamma}
, and we also recall that
\sqrt{\overline{k}_{ij}}\geq\overline{k}^{\gamma}
(see (

)).
Combining these with the Chernoff bound ((
30
) in Appendix
A
) gives

\displaystyle\mathbb{P}\Big[Z\geq\sqrt{\overline{k}_{ij}}\Big]

\displaystyle\leq\Big(\frac{e\mathbb{E}[Z]}{\sqrt{\overline{k}_{ij}}}\Big)^{\sqrt{\overline{k}_{ij}}}

\displaystyle\leq\Big(\frac{16e}{\overline{k}^{3\gamma/2}}\Big)^{\overline{k}^{\gamma/2}}.

The proof is completed by applying a union bound over the
n_{ij}
vertices of
G_{ij}
.

4.3
Typical Graphs Under Shared Permutations

Recall that
\ell_{0}\coloneqq\lceil\log_{2}\overline{k}^{2\gamma}\rceil
and
g_{0}\coloneqq 2^{\ell_{0}}
. For each pair

For every level

Lemma 8
.

Fix
\theta\in(0,1)
and
\gamma\in\bigl(0,\min\{1,\tfrac{1-\theta}{3\theta}\bigr)\}
, and let
c>1/\gamma
. Let
\Pi=(\pi_{1},\ldots,\pi_{c})
denote
c
i.i.d. permutations drawn uniformly from a pairwise independent permutation family on
[n_{ij}]
together with
G\sim\mathrm{ER}(n,q)
, where
q=\Theta(n^{-2(1-\theta)})
. Under the preceding setup and definitions, there exists a nonnegative sequence
\epsilon_{n}\to 0
such that

\displaystyle\mathbb{P}\Big[(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)\Big]\ \to\ 1\quad\text{as }n\to\infty.

Proof.

From Lemma
1
, with probability at least
1-o(1)
we have
G\in\mathcal{T}(\epsilon_{n})
.

For (C1):
By Lemma
5
, with probability
1-o(1)
, for all
(i,j)
we have

\overline{k}^{\gamma}\leq k_{ij}\leq 12\,\overline{k}^{\gamma}.

Similar to (
31
), we have

\mathbb{P}\big[k_{ij}>2\overline{k}_{ij}\big]\leq\exp\big(-\Omega(\overline{k}_{ij})\big)=\exp\big(-\Omega(\overline{k}^{\gamma})\big)\,.

Taking a union bound over
\binom{m}{2}\leq m^{2}=\overline{k}^{1-\gamma}
pairs, we obtain that, with probability at least
1-o(1)
,
k_{ij}\leq 2\overline{k}_{ij}\text{ for all }(i,j)\in[m]\times[m]\,
.

For (C2):
By Lemma
6
,

\mathbb{P}_{\Pi}\Big[\exists\,t\in[c]:\ \nu_{g_{0}}\big(H^{(t,\ell_{0})}_{ij}\big)=0\ \Big|\ G\Big]\ \geq\ \max\Big\{0,\ 1-\Big(\tfrac{k_{ij}(G)}{g_{0}}\Big)^{c}\Big\}\,,

where
k_{ij}(G)
denotes the number of edges in
G_{ij}
. By the law of total probability,

\displaystyle\mathbb{P}_{G,\Pi}\left[\exists\,t\in[c]:\,\nu_{g_{0}}\left(H^{(t,\ell_{0})}_{ij}\right)=0\right]

\displaystyle=\mathbb{E}_{G}\left[\,\mathbb{P}_{\Pi}\left(\exists\,t\in[c]:\,\nu_{g_{0}}\left(H^{(t,\ell_{0})}_{ij}\right)=0\,\middle|\,G\right)\right]

\displaystyle\geq\mathbb{E}_{G}\left[\max\Big\{0,\ 1-\Big(\tfrac{k_{ij}(G)}{g_{0}}\Big)^{c}\Big\}\right]

\displaystyle\geq 1-\mathcal{O}\left(\frac{1}{\overline{k}^{c\gamma}}+\exp(-c^{\prime}\overline{k}^{\gamma})\right)\,,

where in the last inequality we used
g_{0}\geq\overline{k}^{2\gamma}
and (
23
) in Lemma
5
,
which states that
\mathbb{P}[\overline{k}^{\gamma}\leq k_{ij}(G)\leq 12\overline{k}^{\gamma}]\geq 1-\exp\big(-\Omega(\overline{k}^{\gamma})\big)
. Since
c>1/\gamma
, taking a union bound over the
\binom{m}{2}\leq m^{2}=\overline{k}^{1-\gamma}
pairs
(i,j)
shows that, with probability at least
1-o(1)
, condition (C2) holds.

For (C3):
By Lemma
7
, for any level
\ell
and permutation
\pi_{t}
(applied to
G_{ij}
via
\pi_{t}^{(i,j)}
), we have

\mathbb{P}_{G}\Big[\,d_{g}\big(H^{(t,\ell)}_{ij}\big)>\sqrt{\overline{k}_{ij}}\ \Big|\ \pi_{t}\Big]\ \leq\ n_{ij}\left(\frac{16e}{\overline{k}^{3\gamma/2}}\right)^{\overline{k}^{\gamma}/2}.

Applying a union bound over the
c
permutations and at most
\log_{2}n
levels
\ell\in\{\ell_{0},\ldots,\log_{2}n_{ij}\}
yields

\mathbb{P}_{G}\Big[\,\exists\,t\in[c],\ \exists\,\ell\geq\ell_{0}:\ d_{g}\big(H^{(t,\ell)}_{ij}\big)>\sqrt{\overline{k}_{ij}}\ \Big|\ \Pi\Big]\ \leq\ c\log_{2}n\cdot n_{ij}\left(\frac{16e}{\overline{k}^{3\gamma/2}}\right)^{\overline{k}^{\gamma}/2}.

By the law of total probability and
n_{ij}=2n\cdot\overline{k}^{\frac{\gamma-1}{2}}
, we have

\displaystyle\mathbb{P}_{G,\Pi}\Big[\,\exists\,t,\ell:\ d_{g}\big(H^{(t,\ell)}_{ij}\big)>\sqrt{\overline{k}_{ij}}\Big]

\displaystyle=\mathbb{E}_{\Pi}\Big[\ \mathbb{P}_{G}\big(\exists t,\ell:\ d_{g}>\sqrt{\overline{k}_{ij}}\ \big|\ \Pi\big)\ \Big]

\displaystyle\leq\ c\log_{2}n\cdot n_{ij}\left(\frac{16e}{\overline{k}^{3\gamma/2}}\right)^{\overline{k}^{\gamma}/2}

\displaystyle\leq\ c\log_{2}n\cdot 2n\cdot\overline{k}^{\frac{\gamma-1}{2}}\left(\frac{16e}{\overline{k}^{3\gamma/2}}\right)^{\overline{k}^{\gamma}/2}\,.

Taking a union bound over the
\binom{m}{2}\leq m^{2}=\overline{k}^{1-\gamma}
pairs
(i,j)
shows that, with probability
1-o(1)
, condition (C3) holds.
∎

•

For every level

Lemma 9
.

Fix
(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)
and a pair
(i,j)\in[m]\times[m]
, meaning the subgraph
G_{ij}
is also fixed. For some
C_{3}\geq 3e
, consider the
5C_{3}\overline{k}_{ij}\log n
(random) tests formed in Lines 9–12 in Algorithm
3
for a fixed permutation index
t
and repetition

. Let
H
denote the corresponding block graph at level
\ell_{0}
(implicitly depending on
(i,j,t,r)
; see (
26
)). Then, there exists a procedure for using the test results to decide whether
\nu_{g_{0}}(H)=0
or
\nu_{g_{0}}(H)>0
that, with probability
1-\mathcal{O}\left(\frac{\overline{k}^{2\gamma}}{n^{5}}\right)
, returns the correct answer and runs in time
\mathcal{O}\big(\overline{k}^{2\gamma}\log n\big)
. The probability is taken over the randomness of the tests.

Proof.

We proceed in several steps.

Decision rule.

At the base level
\ell_{0}
, for each block
U
of
H
, check the
5\log n
tests that contain
U
.
Declare
U
non–defective if there exists at least one test containing
U
with a negative outcome.
Declare
\nu_{g_{0}}(H)=0
if every block is identified as non–defective; otherwise declare
\nu_{g_{0}}(H)>0
. Note that this procedure will always correctly declare
\nu_{g_{0}}(H)>0
for defective blocks (since their tests results are all positive), so we only need to study the non-defective blocks.

Analysis.

Let
U
be a non–defective block at level
\ell_{0}
.
We will bound the probability that
U
is not identified. We proceed similarly to the proof of (
8
) in Lemma
2
.
Consider a test that contains
U
.
Let
\mathcal{B}_{1}
be the event that some defective block among the
g_{0}
blocks is included in the test,
let
\mathcal{B}_{2}
be the event that some defective pair
(U^{\prime},V^{\prime})
with both
U^{\prime}
and
V^{\prime}
being (individually) non
-
defective is included in the test,
and let
\mathcal{B}_{3}
be the event that some block
V^{\prime}
among the
g_{0}
blocks for which the pair
(U,V^{\prime})
is defective is included in the test. We have

\mathbb{P}\left[U\text{ is not identified in }C_{3}\overline{k}_{ij}\text{ tests}\right]\ \leq\ \mathbb{P}[\mathcal{B}_{1}]+\mathbb{P}[\mathcal{B}_{2}]+\mathbb{P}[\mathcal{B}_{3}]\,.

(27)

Since
(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)
, we have
k_{ij}\leq 2\overline{k}_{ij}
, where
k_{ij}
denotes the number of edges in
G_{ij}
.
Using the fact that the number of defective blocks among the

, we get

\mathbb{P}[\mathcal{B}_{1}]\leq\tfrac{k_{ij}}{C_{3}\overline{k}_{ij}}\leq\tfrac{2}{C_{3}}
.
Moreover, there are at most
k_{ij}
edges in the block graph

, and hence

\mathbb{P}[\mathcal{B}_{2}]\leq\tfrac{k_{ij}}{C_{3}^{2}\overline{k}_{ij}^{2}}\leq\tfrac{2}{C_{3}^{2}\overline{k}_{ij}}
. Since the maximum degree of

, we also have
\mathbb{P}[\mathcal{B}_{3}]\leq\tfrac{\sqrt{\overline{k}_{ij}}}{C_{3}\overline{k}_{ij}}
. Therefore, by (

), we have for sufficiently large

that

\mathbb{P}\left[U\text{ is not identified in }C_{3}\overline{k}_{ij}\text{ tests}\right]\leq\frac{3}{C_{3}}\,.

Hence, under the condition

, over

Running time.

At level
\ell_{0}
, there are
g_{0}=\Theta(\overline{k}^{2\gamma})
blocks.
Each block is included in
5\log n
tests.
Thus, the total checking time is
\mathcal{O}\big(\overline{k}^{2\gamma}\log n\big)
.

Overall success probability.

By the bound above, the failure probability for a fixed non–defective block is
\mathcal{O}\big(\tfrac{1}{n^{5}}\big)
.
A union bound over all
g_{0}=\Theta(\overline{k}^{2\gamma})
blocks yields a total failure probability

\mathcal{O}\big(\tfrac{\overline{k}^{2\gamma}}{n^{5}}\big)
, so the algorithm succeeds with probability at least

1-\mathcal{O}\big(\tfrac{\overline{k}^{2\gamma}}{n^{5}}\big)
.

∎

Lemma 10
.

Fix
(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)
along with a pair
(i,j)\in[m]\times[m]
and

such that the block graph

where
\ell_{0}\coloneqq\lceil\log_{2}\overline{k}^{2\gamma}\rceil

. Consider the decoding procedure from Steps 5–14 of Algorithm

on

\ell_{0}
up to level
\log_{2}n_{ij}

1.

Conditioned on the

possibly defective pairs, i.e.,

With probability at least
1-\mathcal{O}\big(\tfrac{\log_{2}n_{ij}}{\overline{k}^{\gamma/2}}\big)

(i,j,t)
is
\mathcal{O}(\overline{k}^{4.5\gamma}\log n_{ij})
.

All probability statements are over the randomness of the test design.

Proof.

For the first part, fix any
\ell\in\{\ell_{0},\dots,\log_{2}n_{ij}-1\}
and assume that

T\coloneqq\bigl|\mathcal{PD}_{ij}^{(t,\ell)}\bigr|\leq 7\overline{k}^{4\gamma}

H_{ij}^{(t,\ell)}
. Let
\mathrm{E}_{u,v}
be the indicator random variable that a non-defective pair

\begin{split}\mathbb{E}\left[\sum_{u,v}\mathrm{E}_{u,v}\right]&\leq\frac{T}{24}\leq\frac{\overline{k}^{4\gamma}}{2}\,,\\

where the sum is over all non-defective pairs in
\mathcal{PD}_{ij}^{(t,\ell)}

4

Theorem 2
.

Fix
\theta\in(0,1)
and let
G\sim\mathrm{ER}(n,q)
for some

.
Let
\gamma\in\big(0,\min\{1,\tfrac{1-\theta}{3\theta}\}\big)
be fixed.
Under the preceding setup and definitions, Algorithms
3
and
4
with suitably-chosen parameters
c,c^{\prime},C_{3}
(and
C_{1},C_{2},C^{\prime}
in the subroutine from Algorithm
1
) use
\mathcal{O}\big(\overline{k}\log n\big)
tests and, with probability
1-o(1)
, guarantee the following:

1.

Algorithm
4
returns
\widehat{E}=E
.

2.

The decoding time is
\mathcal{O}\big(\overline{k}^{1+3.5\gamma}\log n\big)
.

Proof.

By Lemma
8
, if
c>1/\gamma
, then with probability
1-o(1)
as
n\to\infty
the pair
(G,\Pi)
—where
\Pi
consists of

[n_{ij}]
—belongs to
\mathcal{T}(\epsilon_{n},c,\gamma)
(see Definition

, which also implies
G\in\mathcal{T}(\epsilon_{n})
from Definition

).
All subsequent analysis proceeds under the condition that
(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)

Decoding time.

Since
(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)
, for each
(i,j)\in[m]\times[m]
there exists

such that
\nu_{g_{0}}\big(H^{(t^{\star},\ell_{0})}_{ij}\big)=0
and

for all
\ell\in\{\ell_{0},\dots,\log_{2}n_{ij}\}

By Lemma
9
, with probability at least
1-\mathcal{O}\left(\frac{\overline{k}^{2\gamma}}{n^{5}}\right)

t^{\star}
in time
\mathcal{O}(\overline{k}^{2\gamma}\log n)

c
permutations, because
c
is constant.

Fix such
(i,j)
and
t^{\star}
.
For each test design for
G_{ij}
using
\pi_{t^{\star}}^{(i,j)}
, Lemma
10
shows that the decoder succeeds with probability at least
1-\mathcal{O}\big(\tfrac{\log n_{ij}}{\overline{k}^{\gamma}}\big)

\mathcal{O}(\overline{k}^{4.5\gamma}\log n_{ij})

4
then performs
c^{\prime}
decoding executions on the
c^{\prime}
given test designs for

using
\pi_{t^{\star}}^{(i,j)}

Therefore, with probability at least

(i,j)

, we immediately discard that round.

, we apply

. Because the possible defective set at the final level has size at most

\mathcal{O}(1)

\mathcal{O}(1)

In summary, with probability at least

1-\mathcal{O}\bigl((\tfrac{\log n_{ij}}{\overline{k}^{\gamma/2}})^{c^{\prime}}\bigr)-\mathcal{O}\bigl(\tfrac{\cdot\overline{k}^{2\gamma}}{n^{5}}\bigr)

with probability at least
1-o(1)
when

For each

\mathbb{P}\Big[\,E_{ij}=\widehat{E}_{ij}\ \bigm|\ (G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma),\ \big|\mathcal{PD}_{ij}^{(\log_{2}n_{ij})}\big|\leq 7\overline{k}^{4\gamma}\Big]\ \geq\ 1-\mathcal{O}\Big(\tfrac{\overline{k}^{4\gamma}}{n_{ij}^{C^{\prime}}}\Big),

\mathbb{P}\Big[\,\big|\mathcal{PD}_{ij}^{(\log_{2}n_{ij})}\big|\leq 7\overline{k}^{4\gamma}\ \bigm|\ (G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)\Big]\ \geq\ 1-\mathcal{O}\Bigl(\big(\tfrac{\log n_{ij}}{\overline{k}^{\gamma/2}}\big)^{c^{\prime}}\Bigr)-\mathcal{O}\Big(\frac{\overline{k}^{2\gamma}}{n^{5}}\Big),

\mathbb{P}\big[\widehat{E}=E\,\bigm|\,(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)\big]\ \geq\ 1-\mathcal{O}\Bigl(\overline{k}^{1-\gamma}\cdot\big(\big(\tfrac{\log n_{ij}}{\overline{k}^{\gamma/2}}\big)^{c^{\prime}}+\frac{\overline{k}^{2\gamma}}{n^{5}}+\tfrac{\overline{k}^{4\gamma}}{n_{ij}^{C^{\prime}}}\big)\Bigr)\,.

\mathbb{P}\big[\widehat{E}=E\,\bigm|\,(G,\Pi)\in\mathcal{T}(\epsilon_{n},c,\gamma)\big]=1-o(1).

Since the event

(Lemma

\mathbb{P}\big[\widehat{E}=E\big]=1-o(1).

In Algorithm
3
, for each
(i,j)\in[m]\times[m]
, we apply the non-adaptive design of Algorithm

to

under permutation
\pi_{t}^{(i,j)}
, repeating it
c^{\prime}

contains no defective blocks. Then, at every level

tests; at the final level

(with
\theta
and

In addition, we have
c>1/\gamma

with permutation

we use Algorithm

to design

Therefore, each pair
(i,j)
leads to
\mathcal{O}\big(c\,c^{\prime}\,\overline{k}^{\gamma}\log n_{ij}\big)+\mathcal{O}(c\,c^{\prime}\,\overline{k}^{\gamma}\log n)\;=\;\mathcal{O}(\overline{k}^{\gamma}\log n_{ij}+\overline{k}^{\gamma}\log n)

pairs and recalling

, the total number of tests in Algorithm

\overline{k}^{1-\gamma}\cdot\mathcal{O}\big(\overline{k}^{\gamma}\log n_{ij}+\overline{k}^{\gamma}\log n\big)\;=\;\mathcal{O}\big(\overline{k}\log n\big).

∎

5
Conclusion

We have extended the fast binary splitting approach in group testing for non-adaptive learning of Erdős–Rényi graphs, achieving a number of tests
\mathcal{O}(\overline{k}\log n)
and a decoding time of
\mathcal{O}(\overline{k}^{1+\delta}\log n)
for any fixed small
\delta>0
. This attains (nearly) the best of both objectives in terms of the number of tests and the decoding time. This suggests several possible directions for future research, including: (i) improving the decoding time, ideally reducing it to
\mathcal{O}(\overline{k}\log n)
; (ii) attaining (significantly) improved constants in the number of tests (e.g., see
[
32
]
in the context of group testing); (iii) extending this approach to the problem of learning random hypergraphs, as studied earlier in
[
10
]
; and (iv) considering noisy versions of the problem of learning random graphs and hypergraphs.

Bounding
\nu_{g}

For each

.

Bounding
d(G_{g})
.
For the first level with
g=2^{\lceil\log_{2}\sqrt{\overline{k}}\rceil}
, it is immediate that
d(G_{g})\leq g
, which we see is at most
\min\{2\sqrt{\overline{k}},\frac{10\overline{k}}{g}\}
by substituting this
g
value. It remains to consider the remaining levels after the first one.

Fix a level
\ell\in\{\lceil\log_{2}\sqrt{\overline{k}}\rceil+1,\dots,\log_{2}n-1\}
, and consider a given block
\mathcal{G}_{u}
. If this block is defective (i.e., has internal edges), then by definition it does not affect
d(G_{g})
; thus, for our purposes here, we may condition on the event that
\mathcal{G}_{u}
is non-defective.
For each
i\in[g]
, let
Z_{i}
be the indicator that
(\mathcal{G}_{u},\mathcal{G}_{i})
is defective.
Then
d_{g}(u)=\sum_{i=1}^{g}Z_{i}
.
Having conditioned (implicitly) on
\mathcal{G}_{u}
being non-defective, the number of possible edges in
\mathcal{G}_{u}\cup\mathcal{G}_{i}
is
\tfrac{n^{2}}{g^{2}}+\binom{n/g}{2}
. We thus have

\mathbb{P}[Z_{i}=1]=1-(1-q)^{\tfrac{n^{2}}{g^{2}}+\binom{n/g}{2}}\,.

By similar reasoning to (
32
), for
n
sufficiently large and
g\in[2\sqrt{\overline{k}},n/2]
, we have

\frac{5\overline{k}}{4g^{2}}\leq\mathbb{P}[Z_{i}=1]\leq\frac{4\overline{k}}{g^{2}}.

Therefore,
\frac{5\overline{k}}{4g}\leq\mathbb{E}[d_{g}(u)]\leq\frac{4\overline{k}}{g}
. We now consider two cases:

•

Case 1:
\theta>\tfrac{1}{2}
.
By the Chernoff bound, similar to (
35
), we have

\mathbb{P}\left[d_{g}(u)>\tfrac{10\overline{k}}{g}\right]\leq\exp\left(-\Omega(n^{2\theta-1})\right).

Applying a union bound over at most
g\leq n
nodes, we obtain

\mathbb{P}[d(G_{g})>\tfrac{10\overline{k}}{g}]\leq n\cdot\exp\left(-\Omega(n^{2\theta-1})\right).

•

Case 2:
\theta\leq\tfrac{1}{2}
.

Analogous to (
36
), we have

\mathbb{P}[d_{g}(u)>8\sqrt{\overline{k}}]\leq\exp\left(-\Omega(n^{\theta})\right).

and taking a union bound over
g\leq n
nodes gives

\mathbb{P}[d(G_{g})>8\sqrt{\overline{k}}]\leq n\cdot\exp\left(-\Omega(n^{\theta})\right)\,.

Since the above bounds decay to zero strictly faster than
\frac{1}{\log n}
, we may take a further union bound over all levels
\ell
(with at most
\log_{2}n
levels). It follows that with probability
1-o(1)
, (
4
) holds for all
\ell
.

Combining the above results, we conclude that all conditions in the definition of
\mathcal{T}(\epsilon_{n})
hold with probability at least
1-o(1)
as
n\to\infty
. This completes the proof.

Appendix C
Construction of a Pairwise Independent Permutation Family

In this appendix, we provide our required pairwise independent hash function that can be evaluated in
\mathcal{O}(1)
time. Throughout our paper, we consider a number of nodes equaling a power of two (rounding up via “dummy nodes” with no edges if needed), but it is instructive to first consider permuting a
prime number

p
of elements, say labeled
\{0,1,\dotsc,p-1\}
. In this case, a straightforward choice of random permutation is

\pi(x)=ax+b\quad(\mathrm{mod}\penalty\ p),

where
(a,b)
are uniformly random over the
p(p-1)
combinations with
a\neq 0
. Under this choice, it is straightforward to verify that for any
x\neq x^{\prime}
, the pair
(\pi(x),\pi(x^{\prime}))
is uniform over the
p(p-1)
possible pairs. Specifically, this is seen by subtracting two equations
ax+b=y
and
ax^{\prime}+b=y^{\prime}
and using the invertibility of
x-x^{\prime}
(mod
p
) to determine
a
from
(y,y^{\prime})
, which in turn determines
b
, thus establishing that all
p(p-1)
pairs
(y,y^{\prime})
are equally likely.

Powers of two can be handled in essentially the same manner, but using more general finite field arithmetic, namely,
\mathbb{F}_{2^{m}}
instead of
\mathbb{F}_{p}
. While these ideas are not new, we provide a self-contained treatment for completeness.

Setting.

Let
N=2^{m}
for some integer
m\geq 1
. Fix the finite field
\mathbb{F}_{2^{m}}
via a monic irreducible polynomial
f(t)\in\mathbb{F}_{2}[t]
of degree
m
, so that

\mathbb{F}_{2^{m}}\cong\mathbb{F}_{2}[t]/(f(t))
with the polynomial basis
\{1,t,\dots,t^{m-1}\}
.
Let
\varphi:[N]\to\mathbb{F}_{2^{m}}
be the bijection that maps the binary expansion

x=\sum_{i=0}^{m-1}c_{i}2^{i},\qquad c_{i}\in\{0,1\},

to the corresponding polynomial-basis representation

\varphi(x)\;=\;\sum_{i=0}^{m-1}c_{i}t^{i}\pmod{f(t)}.

We write
\varphi^{-1}
for the inverse map: if

z=\sum_{i=0}^{m-1}c_{i}t^{i}
with
c_{i}\in\{0,1\}
, then

\varphi^{-1}(z)=\sum_{i=0}^{m-1}c_{i}2^{i}
.
For background on the isomorphism
\mathbb{F}_{2^{m}}\cong\mathbb{F}_{2}[t]/(f(t))
, see
[
27
]
.

Construction.

Let
\mathbb{F}_{2^{m}}^{\times}\coloneqq\mathbb{F}_{2^{m}}\setminus\{0\}
.
For each
a\in\mathbb{F}_{2^{m}}^{\times}
and
b\in\mathbb{F}_{2^{m}}
, define

\widetilde{\pi}_{a,b}:\mathbb{F}_{2^{m}}\to\mathbb{F}_{2^{m}},\qquad\widetilde{\pi}_{a,b}(z)=az+b,

with operations taken in
\mathbb{F}_{2^{m}}
.
Transporting to
[N]
via
\varphi
, define

\pi_{a,b}\;:=\;\varphi^{-1}\circ\widetilde{\pi}_{a,b}\circ\varphi\;:\;[N]\to[N].

Now set

\mathcal{F}_{N}\;:=\;\{\pi_{a,b}\,:\,a\in\mathbb{F}_{2^{m}}^{\times},\;b\in\mathbb{F}_{2^{m}}\}.

Since
a\neq 0
, each
\widetilde{\pi}_{a,b}
is a bijection on
\mathbb{F}_{2^{m}}
; hence
\pi_{a,b}
is a bijection on
[N]
.
Thus
\mathcal{F}_{N}\subseteq\mathcal{S}_{N}
and
|\mathcal{F}_{N}|=N(N-1)
.

Lemma 11
.

If
\pi
is sampled uniformly from
\mathcal{F}_{N}
, then for all distinct
x_{1},x_{2}\in[N]
and all distinct
y_{1},y_{2}\in[N]
,

\mathbb{P}_{\pi\sim\mathrm{Unif}(\mathcal{F}_{N})}\bigl[\pi(x_{1})=y_{1}\,,\,\pi(x_{2})=y_{2}\bigr]\;=\;\frac{1}{N(N-1)}.

As a consequence,
\mathcal{F}_{N}
is a pairwise independent family of permutations on
[N]
.

Proof.

The proof is standard and can be found in most texts on the construction of pairwise independent hash families (e.g. see
[
26
]
). We include it here for the reader’s convenience. Let
z_{i}=\varphi(x_{i})
and
w_{i}=\varphi(y_{i})
for
i=1,2
. Then

\pi(x_{1})=y_{1},\qquad\pi(x_{2})=y_{2}

are equivalent to

\widetilde{\pi}_{a,b}(z_{1})=w_{1},\qquad\widetilde{\pi}_{a,b}(z_{2})=w_{2},

i.e.,

az_{1}+b=w_{1},\qquad az_{2}+b=w_{2}\quad\text{in }\mathbb{F}_{2^{m}}.

(37)

Because
x_{1}\neq x_{2}
we have
z_{1}\neq z_{2}
, and because
y_{1}\neq y_{2}
we have
w_{1}\neq w_{2}
.
Subtracting the two equations in (
37
) gives

a(z_{1}-z_{2})=w_{1}-w_{2},

which has the unique solution

a=\frac{w_{1}-w_{2}}{\,z_{1}-z_{2}\,}\in\mathbb{F}_{2^{m}}^{\times}.

Then
b
is uniquely determined by
b=w_{1}-az_{1}
. Thus there is exactly one pair

(a,b)\in\mathbb{F}_{2^{m}}^{\times}\times\mathbb{F}_{2^{m}}
that satisfies (
37
). Since
|\mathcal{F}_{N}|=N(N-1)
and the sampling is uniform, the probability equals
1/(N(N-1))
.

∎

Evaluation and storage.

We work in the word
-
RAM model: reading a single integer in
\{0,\dots,N-1\}
from memory and performing arithmetic on such integers each takes constant time.
Since elements of
\mathbb{F}_{2^{m}}
have bit
-
length
m=\Theta(\log N)
, we can encode each element in
\mathcal{O}(1)
machine words under this model.
Each
\pi_{a,b}
is specified by
(a,b)
(and we store
a^{-1}
once), so the description uses
\mathcal{O}(\log N)
bits.

Cost of
\varphi
and
\varphi^{-1}
.

Packing/unpacking the
m
base
-
2 digits of
x
(or the coefficient vector) and converting to/from the polynomial
-
basis representation modulo
f(t)
takes
\mathcal{O}(1)
time in this model.
Writing
T(\cdot)
for the computation time on a single input under the word
-
RAM model (unit
-
cost arithmetic on integers in
\{0,\dots,N-1\}
), it follows that

T(\varphi)=T(\varphi^{-1})=\mathcal{O}(1).

Field operations over
\mathbb{F}_{2^{m}}
.

With the above encoding, coefficient
-
wise XOR (addition) and one field multiplication followed by reduction modulo the fixed irreducible
f(t)
are each counted as
\mathcal{O}(1)
time on the word
-
RAM.
For any
x\in[N]
,

\pi_{a,b}(x)=\varphi^{-1}\big(a\cdot\varphi(x)+b\big),\qquad\pi_{a,b}^{-1}(x)=\varphi^{-1}\big(a^{-1}\cdot(\varphi(x)-b)\big).

Each query performs one
\varphi
operation, one field multiplication, one field addition, and one
\varphi^{-1}
operation; hence,

T\big(\pi_{a,b}(x)\big)=T\big(\pi_{a,b}^{-1}(x)\big)=\mathcal{O}(1).

Storage.

We can store
(a,b,a^{-1})
using
\mathcal{O}(\log N)
bits.
The irreducible polynomial
f(t)\in\mathbb{F}_{2}[t]
of degree
m
requires
m
bits for its non
-
leading coefficients, i.e.,
\mathcal{O}(\log N)
bits.
