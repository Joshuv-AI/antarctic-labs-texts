BLaST: High Performance Inference and Pretraining using BLock Sparse Transformers
Patrik Okanovic 1* , Sameer Deshmukh 2* , Grzegorz Kwasniewski 1* , Kentaro Katayama 2 , Takumi Honda 2 , Maciej Besta 1 , Torsten Hoefler 1

Abstract
. The energy consumption of large-scale ML models is dominated by data movement - shuffling billions of parameters across memory hierarchies and data centers. Effective sparsification to prune redundant parameters is still challenging: existing methods incur significant accuracy degradation, performance overhead, or both. We introduce (Bl)ock (a)nd (S)parse (T)ransformers (BLaST), a general, robust, and reliable sparsification method applicable to linear layers in all settings. Our method iteratively sparsifies weight matrices into a block sparsity pattern suitable for efficient sparse matrix-matrix (SpMM) multiplication. BLaST achieves up to 95% sparsity in MLP weights with negligible accuracy loss. Our fused, highly optimized Sparse MLP kernel delivers up to 16.7x speedup over dense MLPs across 9 architectures and 8 datasets, resulting in up to 1.6x inference speedup, 1.11x pretraining speedup and up to 3.12x inference memory usage reduction. BLaST enables the next generation of large-scale AI systems by reducing energy use, memory footprint, and latency.

3.2.
Blocked Prune and Grow

The “early bird” lottery ticket hypothesis
(
Chen2021
;
You2022
)
proposes that certain weights are more important than others, and that they can be selected during pretraining without significantly affecting the model’s accuracy. According to this hypothesis, winning weights are chosen by pruning the weights with the smallest magnitudes
(
Frankle2019
;
Chen2021a
;
Chen2021
;
You2022
)
. RigL
(
Evci2021
;
Evci2022
)
demonstrated that the pruned model’s accuracy can be further improved by incorporating gradient flow information to select the winning weights. This improvement is achieved by applying the same pruning function,
S()
, to both the weights and their corresponding gradients. In the final step, a weight is retained if it meets one of two conditions: it is either directly preserved by the function
S()
or regrown based on gradient information.

Using RigL on CNNs
(
Evci2021
;
Evci2022
)
results in fine-grained unstructured sparsity of the weight matrices. Although this results in a reduced number of floating point operations during the forward and backward propagation, it does not translate into improved performance due to memory bandwidth limitations of modern GPUs
(
Abdelfattah2024
;
naumov2010cusparse
;

)

3.3.
BSpMM Kernel

We now introduce our custom BSpMM kernel - the elementary algebraic building block that secures maximal speedup over dense baselines.
The BSpMM kernel, while being part of our BLaST framework, can also be used independently as a stand-alone SpMM kernel, paving
the road for fast, sparse linear algebra kernels across various domains.
We then further extend it to the MLP blocks inside Transformer architectures to capture the most common compute pattern in ML workloads.

SMaT is an SpMM library that exploits Tensor Cores (TCs) for the efficient multiplication of unstructured sparse matrices. The block
-

The main difference between BLaST BSpMM and SMaT BSpMM is that the sparsity structure is not imposed by the unstructured CSR input but rather arises from our custom sparsification strategy. As a result, we can bypass the key performance bottlenecks identified by Okanovic et al.

(

The carefully tuned rectangular block shape results from optimizing shared memory and register usage, while minimizing accuracy loss due to overly aggressive sparsification. The two block dimensions—
blk_M

(1)

blk_N
determines the sparse block size. When the block is smaller, the sparsification strategy has more freedom to choose the best blocks to prune—resulting in a more fine-grained masking process. Conversely, larger blocks enable more efficient computation. We empirically select the largest block sizes that preserve high accuracy. This will be further explored in
Section

(2)

(
kwasniewski2019red
)
to derive the optimal block size, given hardware constraints such as the number of available registers, shared memory capacity, and warps per threadblock.

3.3.3.
Block Sparse MLP

In the MLP block, the linear layer is followed by a nonlinear operator. In most of machine learning, nonlinear operators
fall into two categories – element-wise nonlinearities, such as ReLU, GeLU, SiLU, and row-wise operators, that perform some
type of reduction, usually over the embedding dimension. Examples of such nonlinear operators are LayerNorm
(
Ba2016
)
or RMSNorm
(
Zhang2019
)
.

While tensor contractions are usually compute-bound (even in the sparse case), nonlinear operators are memory-bound.
The arithmetic intensity — the ratio of arithmetic operations per loaded element — is a small constant, usually 1 or 2.
Therefore, to prevent a memory bottleneck, nonlinear operators have to be fused with the compute-bound operations.

Our optimized BSpMM kernel for MLPs fuses the nonlinearities that follow the SpMM operator into one kernel. Our implementation supports
all common nonlinearities, further improving performance and reducing data movement.

5.1.
BLaST BSpMM Speedup

We begin by analyzing the speedup achieved by the BLaST BSpMM kernel relative to state-of-the-art matrix multiplication algorithms. Throughout this section, we report the speedup as the ratio

t_{cuBLAS}
denotes the time for cuBLAS, and

is the execution time for our method. In all experiments, we present the results for
blk_M = blk_N

\in\{32,64,128\}
which coincides to the TC MMA input sizes (see
Section

3.3
) as the sparsity level increases.

Note that BLaST BSpMM supports all data types supported by Triton

5.2.
BLaST for Inference

Pretraining neural networks from scratch demands substantial computational resources, especially for large dense models. Given the widespread availability of pretrained LLMs—which embody significant compute investments—there is a strong incentive to leverage these models rather than retrain a network from scratch. Our approach is capable of knowledge transfer by initializing the network with weights from an existing pretrained dense model. These pretrained weights may originate either from a dense network trained on the same dataset (the post-training compression setting) or from a network pretrained on a different dataset (the fine tuning setting).
When training with pretrained dense weights, we have observed that, in cases involving large vocabulary sizes, utilizing a knowledge distillation loss improves the final accuracy
(
muralidharan2024compact
;
blakeman2025nemotron
)
. That is, rather than using solely the cross-entropy loss
L_{CE}
, we backpropagate using a combined loss
\alpha L_{CE}+\beta L_{KL}
, where
L_{KL}
represents the Kullback-Leibler divergence computed between the BLaST logits and those of the dense pretrained model, with weighting coefficients
\alpha,\beta\in\mathbb{R}
.
In our experiments, we do not conduct an ablation study on the effect of knowledge distillation, as it is beyond the scope of this paper; instead, we report the best performance achieved between using, and not using the knowledge distillation loss.

In all experiments, we iteratively sparsify the model while simultaneously training it to recover the accuracy of the dense version (see
Section

3
). BLaST yields a model that maintains high accuracy while benefiting from faster inference and a reduced memory footprint.
We demonstrate the capability of BLaST to recover the full accuracy of a pretrained dense network on downstream tasks.

7.
Conclusion

This paper introduces BLaST, a general, scalable, and widely applicable end-to-end method that greatly reduces memory footprint, hardware cost of running contemporary extreme-scale LLMs, while simultaneously reducing runtime in all scenarios, both training- and inference-related.
BLaST iteratively sparsifies the weights of the MLP layers inside the Transformer blocks, achieving up to 95% sparsity. Additionally, we introduce a highly efficient SpMM kernel that can be used as a standalone sparse linear algebra primitive, beyond ML workloads.
We perform a comprehensive performance study of the proposed sparse kernel on state-of-the-art neural network architectures. We show a speedup of matrix multiplication of up to 16.7x, and we also demonstrate a speedup in the MLP block, achieving up to 8.8x improvement on the Llama-3.1 405B model. For Llama-3.2 1B, we show a 1.6x speedup in inference compared to the dense model, as well as a 1.1x speedup in pretraining. BLaST leads to memory savings of up to 3.12x during inference, translating into 2.9x lesser investment on GPUs and lower operating costs for data centers.
We evaluate BLaST on 9 Transformer models across 8 datasets in both the text and vision domains, showing negligible accuracy losses compared to dense models.
The presented results confirm that BLaST can be used as a drop-in method to scale up, and improve the efficiency of any Transformer-based architecture.
