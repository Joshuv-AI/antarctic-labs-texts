Abstract
We investigate the use of modern code-agnostic decoders to convert CA-SCL from an incomplete decoder to a complete one. When CA-SCL fails to identify a codeword that passes the CRC check, we apply a code-agnostic decoder that identifies a codeword that satisfies the CRC. We establish that this approach gives gains of up to 0.2 0.2 dB in block error rate for CA-Polar codes from the 5G New Radio standard. If, instead, the message had been encoded in a systematic CA-polar code, the gain improves to 0.2 ∼ 1 0.2\sim 1 dB. Leveraging recent developments in blockwise soft output, we additionally establish that it is possible to control the undetected error rate even when using the CRC for error correction.



I
Introduction

Polar codes were introduced by Arıkan in 2008 and are capacity achieving for binary-input discrete memoryless channel (B-DMC)
[
3
]
.
When concatenated with a cyclic redundancy check (CRC) as an outer code, the resulting CRC-Aided polar (CA-polar) codes were adopted in the 5G New Radio (NR) standard for all control channel communications
[
6
]
. CRC-Aided Successive Cancellation List (CA-SCL) decoding, e.g.
[
19
,
27
]
, is a prominent decoder for CA-polar codes. It operates by first providing a list of candidates using SCL decoding followed by performing CRC checks for each candidate. If no candidate passes the CRC check, a decoding failure is declared. A complete decoder always provides a codeword while an incomplete one does not
[
7
]
. As a result, CA-SCL is an incomplete decoder.

While the CRC in CA-polar codes is used for error detection, it can be more extensively leveraged for error correction using recent advances. Guessing Random Additive Noise Decoding (GRAND)
[
10
,
26
,
12
]
and Guessing Codeword Decoding (GCD)
[
18
,
30
]
are code-agnostic and Maximum Likelihood (ML), or near ML, decoders that can efficiently decode a broad class of codes, including CRC codes. Those algorithms can be highly parallelized and many efficient circuits and chips have been published for GRAND variants,
e.g.
[
2
,
9
,
8
,
21
,
1
,
17
]
, which can be further accelerated by using techniques from
[
22
,
23
,
20
]
. In this paper, we investigate the application of one of these recent code-agnostic decoders as an outer decoder that uses the CRC code for error correction when CA-SCL fails. This results in a complete decoder that we call Complete CA-SCL (CCA-SCL).

Compared to the standard polar codes, systematic polar codes provide an advantage in terms of bit error rate (BER) while guaranteeing the same block error rate (BLER)
[
4
]
. The decoding process of systematic polar codes remains the same, except that the information bits are directly available in the encoded codeword. A systematic polar code concatenated with a CRC code results in a systematic CA-polar code. Our results demonstrate that additional improvement can be achieved using the proposed decoding scheme if
a systematic CA-polar code is used.

One motivation for adopting CA-polar codes in 5G NR was to support Ultra-Reliable Low-Latency Communication (URLLC). Recently, Soft output (SO) variants of GRAND, GCD, and SCL have been introduced, which are known as SOGRAND
[
16
,
29
]
, SO-GCD
[
11
]
and SO-SCL
[
28
]
, respectively. These variants can provide blockwise SO in the form of an accurate estimate of the likelihood that each proposed decoding in a list is correct. The key enhancement over earlier approaches, e.g.
[
14
]
, is the development of a per-decoding estimate of the likelihood that the transmitted codeword is not in the decoded list, which removes the requirement of list decoding while enabling near-optimal SO compared to a exhaustively computed SO,
[
13
]
. In addition to using the outer decoder, we employ these SO algorithms to provide reliable SO for undetected error rate (UER) control, which facilitates the use of the CRC for error correction as well as detection. In particular, accurate SO for CA-SCL can be adapted from SO-SCL by leveraging the CRC outer code as detailed in Section
III-B
.

The remainder of this paper is organized as follows. Section
II
introduces the basic setups. Section
III
describes the CCA-SCL decoding pipeline, with simulation results given in Section
IV
. A conclusion is given in Section
V
.

II
Preliminaries

Consider a binary message denoted as
\Phi^{M}=(\Phi_{1},\cdots,\Phi_{M})\in\mathbb{F}_{2}^{M}
where
M
is the number of information bits. The encoding process of a CA-polar code can be described as follows. The message
\Phi^{M}
is first encoded using an outer CRC code that is systematic, which is specified by the generator matrix

.

. The sequence
\Phi^{K}

G_{\text{I}}
with dimension
K
by
N

X^{N}=(X_{1},\cdots,X_{N})=\Phi^{K}G_{\text{I}}=\Phi^{M}G_{\text{O}}G_{\text{I}}
.

The polar code specified by
G_{\text{I}}
can be equivalently described by the following: Let
\mathcal{F}\subset\{1,\cdots,N\}
record the locations of the frozen bits in a sequence with length
N=2^{n}
for some
n
and
|\mathcal{F}|=N-K
. We define
\mathcal{A}=\{1,\cdots,N\}\setminus\mathcal{F}
where
\setminus
is the set minus operation. Denote
G_{[K,N]}
to be the
K
by
N
matrix such that the columns in the set
\mathcal{F}
form a
K
by
N-K
zero matrix and the rest of the columns form a
K
by
K
identity matrix. The sequence
\Phi^{K}
is first expanded by
U^{N}=\Phi^{K}G_{[K,N]}
, where the subsequence
U_{\mathcal{A}}
records
\Phi^{K}
and the subsequence
U_{\mathcal{F}}
is a zero sequence. Let
F^{\otimes n}
denote the
n

F

\displaystyle F=\begin{bmatrix}1&0\\

Then the expanded sequence is encoded by

, resulting in
\Phi^{K}G_{\text{I}}=\Phi^{K}G_{[K,N]}F^{\otimes n}
. Note that
F^{\otimes n}
is its own inverse.

After the encoding,
X^{N}
is transmitted via
N

Y^{N}\in\mathbb{R}^{N}
. Given knowledge of the channel, the conditional pdf of
Y

i
-th received bit is denoted as

\displaystyle\mathscr{L}_{\text{I},i}=\log\frac{f_{Y|X}(Y_{i}|X_{i}=1)}{f_{Y|X}(Y_{i}|X_{i}=0)}.

and we denote
\mathscr{L}_{\text{I}}=(\mathscr{L}_{\text{I},1},\cdots,\mathscr{L}_{\text{I},N})
, where
I
is used to indicate that the LLR is related to the
N
bits resulting from encoding through the inner code.

A SCL decoder
[
27
]
decodes and provides a list of
L
candidates
\hat{U}^{N,1},\hat{U}^{N,2},\cdots,\hat{U}^{N,L}
for
U^{N}
. Let
\mathcal{V}
denote the set of candidates. A LLR-based SCL decoder provides a path metric (PM)
[
5
]
for each of the candidates to indicate which candidate is more reliable. For each candidate
\hat{U}^{N,i}
, SO-SCL
[
28
]
provides a corresponding SO,
S_{i}\in[0,1]
, which serves as a probability estimate for whether the candidate is correct, i.e., whether
\hat{U}^{N,i}={U}^{N}
. Note that the rank order of the PM for each candidate is the same as the rank order of the SO for each candidate. Let
0
denote the zero vector. Each candidate in
\mathcal{V}
is examined by the CRC check. Denote
\mathcal{V}^{\prime}=\{\hat{U}^{N,i}|\hat{U}^{N,i}\in\mathcal{V},H_{\text{O}}(\hat{U}^{N,i}_{\mathcal{A}})^{T}=\textbf{0}\}
to be the subset of
\mathcal{V}
such that
\mathcal{V}^{\prime}
contains all the candidates that pass the CRC check. Let
S^{*}=\max\{S_{i}|\hat{U}^{N,i}\in\mathcal{V}^{\prime}\}
denote the maximum SO within the remaining candidates and the corresponding candidate
\hat{U}^{N,*}\in\{\hat{U}^{N,i}|S_{i}=S^{*}\}\subseteq\mathcal{V}^{\prime}
will be the decoded message. If
\mathcal{V}^{\prime}=\emptyset
, a decoding failure is declared.

III-A

Decoding using outer decoder

When CA-SCL fails to decode, we apply an outer decoder to estimate
\Phi^{K}
with the following inputs: LLRs corresponding to
\Phi^{K}=U_{\mathcal{A}}
called
outer LLR
and the CRC parity check matrix
H_{\text{O}}
. However, the outer LLR can not be directly observed from
\mathscr{L}_{\text{I}}
since the polar code is not systematic, leading to the following calculation. Conditioned on the channel LLR, the likelihood that
X_{i}=1
, denoted as
B_{\text{I},i}
, can be calculated as

\displaystyle B_{\text{I},i}=P(X_{i}=1|\mathscr{L}_{\text{I}})=\frac{1}{1+e^{-\mathscr{L}_{\text{I},i}}}.

(1)

Let
\pi(i)
denote the position in
U^{N}=\Phi^{K}G_{[K,N]}
that records the value of
\Phi_{i}
. Let
F^{\otimes n}_{i,j}
denote the entry of
F^{\otimes n}
at the
i
-th row and the
j
-th column. Since
\Phi^{K}G_{[K,N]}F^{\otimes n}=\Phi^{K}G_{\text{I}}=X^{N}
,
\Phi^{K}G_{[K,N]}=U^{N}=X^{N}F^{\otimes n}
. Hence the likelihood that
\Phi_{i}=1
conditioned on the channel LLR can be calculated using Lemma
1
of
[
15
]
, i.e.,

\displaystyle B_{\text{O},i}=P(\Phi_{i}=1|\mathscr{L}_{\text{I}})=\frac{1}{2}-\frac{1}{2}\prod_{j=1}^{N}\left(1-2B_{\text{I},j}F^{\otimes n}_{j,\pi(i)}\right),

(2)

which can be converted to outer LLR
\mathscr{L}_{\text{O},i}
for the
K
bits in
\Phi^{K}
analogously to eq. (
1
). This calculation leads to two consequences that impact the performance of the outer decoder, which are presented in Lemmas
1
and
2
.

Lemma 1
.

Let
|\mathscr{L}_{\text{I},j}|
denote the reliability of the hard decision for
X_{j}
based on
\mathscr{L}_{\text{I},j}
. Similarly, let
|\mathscr{L}_{\text{O},i}|
denote the reliability of the hard decision for
\Phi_{i}
based on
\mathscr{L}_{\text{O},i}
. Denote
\mathcal{X}_{i}=\{s|F^{\otimes n}_{s,\pi(i)}=1\}
so that
\Phi_{i}=\bigoplus_{s\in\mathcal{X}_{i}}Y_{s}
where
\bigoplus
denotes the summation in
\mathbb{F}_{2}
.
\mathcal{X}_{i}
represents the set of bits in
X^{N}
that can be used to recover
\Phi_{i}
. Then

|\mathscr{L}_{\text{O},i}|\leq|\mathscr{L}_{\text{I},j}|
for all
i,j
such that
j\in\mathcal{X}_{i}
.

Proof.

By eq. (
1
),

\left|1/2-B_{\text{I},i}\right|=({e^{|\mathscr{L}_{\text{I},i}|}-1})/({2e^{|\mathscr{L}_{\text{I},i}|}+2})
,
which implies that
|1/2-B_{\text{I},i}|
is a monotone increasing function of the reliability for the corresponding bit. A parallel statement holds for
|1/2-B_{\text{O},i}|
. Hence it suffices to show
|1/2-B_{\text{O},i}|\leq|1/2-B_{\text{I},j}|
for all
i,j
such that
j\in\mathcal{X}_{i}
:

\displaystyle\left|\frac{1}{2}-B_{\text{O},i}\right|=2^{|\mathcal{X}_{i}|-1}\prod_{j\in\mathcal{X}_{i}}\left|\frac{1}{2}-B_{\text{I},j}\right|\leq\left|\frac{1}{2}-B_{\text{I},j}\right|

for all
j
such that
j\in\mathcal{X}_{i}
.
∎

Lemma
1
implies that
\mathscr{L}_{\text{O},i}
converted from
\mathscr{L}_{\text{I}}
is generally less reliable than
\mathscr{L}_{\text{I},j}
that is used to calculate
\mathscr{L}_{\text{O},i}
. The inequality is strict if
U_{i}
corresponds to multiple bits in
X^{N}
through eq. (
2
). Fig.

Lemma 2
.

For any pair of
(i,j)
, let
\mathcal{X}_{i,j}=\mathcal{X}_{i}\cap\mathcal{X}_{j}
. Define
p_{i\setminus j}:=\frac{1}{2}-\frac{1}{2}\prod_{s\in\mathcal{X}_{i}\setminus\mathcal{X}_{i,j}}(1-2B_{\text{I},s})
and
p_{i\setminus j}:=0
if
\mathcal{X}_{i}\subseteq\mathcal{X}_{j}
. Define
p_{i,j}:=\frac{1}{2}-\frac{1}{2}\prod_{s\in\mathcal{X}_{i,j}}(1-2B_{\text{I},s})
and
p_{i,j}:=0
if
\mathcal{X}_{i,j}=\emptyset
. Then the covariance
\text{Cov}(\Phi_{i},\Phi_{j}|\mathscr{L}_{\text{I}})=0
if and only if one of the following holds: 1)
p_{i,j}\in\{0,1\}
; or 2)
p_{i\setminus j}=\frac{1}{2}
or
p_{j\setminus i}=\frac{1}{2}
.

Proof.

We will omit the notation for conditioning on
\mathscr{L}_{\text{I}}
throughout the proof as all calculations will be done with the conditioning. Given a pair
i
and
j
, notice that
\Phi_{i}=\left(\bigoplus_{s\in\mathcal{X}_{i}\setminus\mathcal{X}_{i,j}}X_{s}\right)\oplus\left(\bigoplus_{s\in\mathcal{X}_{i,j}}X_{s}\right)
and similarly for
\Phi_{j}
. Let
\bigoplus_{s\in\mathcal{X}}X_{s}=0
if
\mathcal{X}=\emptyset
. The same approach as in eq. (
2
) leads to
P\left(\bigoplus_{s\in\mathcal{X}_{i,j}}X_{s}=1\right)=p_{i,j}
,
P\left(\bigoplus_{s\in\mathcal{X}_{i}\setminus\mathcal{X}_{i,j}}X_{s}=1\right)=p_{i\setminus j}
, and
P\left(\bigoplus_{s\in\mathcal{X}_{j}\setminus\mathcal{X}_{i,j}}X_{s}=1\right)=p_{j\setminus i}
.
The covariance can then be calculated directly, yielding
\text{Cov}(\Phi_{i},\Phi_{j})=p_{i,j}(1-p_{i,j})(1-2p_{i\setminus j}-2p_{j\setminus i}+4p_{i\setminus j}p_{j\setminus i})
.
∎

Condition 1) is satisfied when the demodulated bits with indices in
\mathcal{X}_{i,j}
have infinite reliability or
\Phi_{i},\Phi_{j}
are affected by disjoint sets of
X^{N}
so that
\mathcal{X}_{i,j}=\emptyset
. However, in polar coding,
\mathcal{X}_{i,j}\neq\emptyset
by the construction of
F^{\otimes n}
. Therefore, condition 1) happens with probability zero. Condition 2) is satisfied when all the bits with indexes in
\mathcal{X}_{i\setminus j}\cup\mathcal{X}_{j\setminus i}
have reliabilities equal to zero, which has probability zero. Therefore, after converting the channel LLRs to LLRs corresponding to
\Phi^{K}
, the converted LLRs are correlated, resulting in degradation if the outer decoder assumes
\Phi_{i},\Phi_{j}
are independent for all
i,j
.

While simulation results will be given in Section
IV
, Lemmas
1
and
2
indicate that it is possible to achieve higher performance if the two issues can be resolved. In this paper, we demonstrate that systematic polar code
[
4
]
can be used to avoid both issues. The encoding process of a systematic polar code can be done by methods described in
[
25
,
24
]
, which enables the outer LLR to be directly observed from the channel LLR. Instead of recording the message
\Phi^{K}
in
U_{\mathcal{A}}
, let
X_{\mathcal{A}}
record
\Phi^{K}
. The usual polar encoding is performed for the first time to get
U^{N}=X_{\mathcal{A}}G_{\text{I}}
. Then only the part
U_{\mathcal{A}}
is encoded for the second time by
X^{N}=U_{\mathcal{A}}G_{\text{I}}
. The resulting
X_{\mathcal{A}}
maintains the record of
\Phi^{K}
with
X_{\mathcal{F}}
representing the redundant bits. A SCL decoder can decode with the same procedure as decoding non-systematic polar codes except that the information bits are now recorded in
X_{\mathcal{A}}
instead of
U_{\mathcal{A}}
. Applying systematic polar code in CA-polar, the CRC-encoded message is then recorded in
X_{\mathcal{A}}=\Phi^{K}
instead, whose corresponding LLRs can be directly observed from
\{\mathscr{L}_{\text{I},i}|i\in\mathcal{A}\}
, avoiding the degradation caused by conversion. Simulation results in Section
IV
demonstrate the improvement extracted using systematic CA-polar codes.

III-B

Managing UER with SO-SCL adapted to CA-polar

When a decoded message is provided with a blockwise SO
S^{*}
, the decoding can be tagged for erasure if
S^{*}<1-\epsilon
. This threshold test can be used to control UER with the targeted UER
\epsilon
. In CCA-SCL, the outer decoder SOGRAND or SO-GCD is used to provide blockwise SO for error detection through the threshold test. In this section, we will adapt the SO-SCL calculation to CA-SCL so that all decoded codewords produced in the pipeline are paired with a blockwise SO, which can be used to control UER.

We first give an overview of SO-SCL
[
29
]
for polar-like codes. We denote
U^{i}
to be the subsequence of
U^{N}
such that
U^{i}=(U_{1},\cdots,U_{i})
. Assume the observed channel output is
Y^{N}=y^{N}
. Let
Q_{U^{N}|Y^{N}}
denote an auxiliary conditional probability mass function (PMF) as described in
[
28
]
. The SC decoding performs a greedy search and identifies a sequence
\hat{u}^{N}
such that
\hat{u}^{N}_{\mathcal{F}}=\textbf{0}
. For SCL, up to
L
paths are explored in parallel, resulting in
L
candidates as output which are recorded in
\mathcal{V}
. The decoding process can be represented by a tree search with depth
N
. Each path with length
N
in the tree represents a sequence
\hat{u}^{N}\in\mathbb{F}_{2}^{N}
. SCL keeps a record of
L
paths that satisfy the frozen constraints, hence dividing the tree into three parts:

a)

Visited paths
denote the
L
paths provided by SCL, where all of them satisfy the frozen constraints.

b)

Unvisited valid paths
are the paths that satisfy the frozen constraints but have not been fully explored due to memory and complexity issues.

c)

Invalid paths
are the paths that do not meet the frozen constraints, where a path
\hat{u}^{N}\in\mathbb{F}_{2}^{N}
is invalid if
\hat{u}^{N}_{\mathcal{F}}\neq\textbf{0}.

In this paper, the term
valid
refers to whether the path satisfies the frozen constraints without considering the CRC. Recall that
\mathcal{V}
is the set of
L
visited paths. We denote
\mathcal{W}
to be the set of all unvisited valid paths. The optimal blockwise SO for polar-like codes with the knowledge of all possible codewords is given by
\Gamma\left(y^{N},\hat{u}^{N}\right)=

\displaystyle\frac{Q_{U^{N}|Y^{N}}\left(\hat{u}^{N}\left|y^{N}\right.\right)}{\sum\limits_{u^{N}\in\mathcal{V}}Q_{U^{N}|Y^{N}}\left(u^{N}\left|y^{N}\right.\right)+\sum\limits_{u^{N}\in\mathcal{W}}Q_{U^{N}|Y^{N}}\left(u^{N}\left|y^{N}\right.\right)}.

(3)

The numerator in (
3
) represents the likelihood of a decoded sequence
\hat{u}^{N}
while the denominator represents the sum of likelihoods of all possible decoding paths satisfying the frozen constraints. The denominator is called the codebook probability. Forney’s approximation
[
14
]
to equation (
3
) is given by

\displaystyle\frac{Q_{U^{N}|Y^{N}}(\hat{u}^{N}|y^{N})}{\sum\limits_{u^{N}\in\mathcal{V}}Q_{U^{N}|Y^{N}}(u^{N}|y^{N})},

(4)

where the second summation in the denominator of (
3
) is omitted, i.e., the SO is calculated conditioned on the transmitted codeword being in the list of visited paths. Note that the assumption requires that the list size is at least two.

In contrast,
[
28
]
considers the omitted term in (
4
), which represents the likelihood of unvisited valid paths. The omitted term
\sum_{u^{N}\in\mathcal{W}}Q_{U^{N}|Y^{N}}\left(u^{N}\left|y^{N}\right.\right)
is approximated by a quantity
Q^{*}_{\mathcal{W}}
which can be readily calculated through the decoding process (see
[
28
]
for details). This leads to the approximation for (
3
) as

\displaystyle\Gamma\left(y^{N},\hat{u}^{N}\right)\approx\Gamma^{*}\left(y^{N},\hat{u}^{N}\right)=\frac{Q_{U^{N}|Y^{N}}(\hat{u}^{N}|y^{N})}{\sum\limits_{u^{N}\in\mathcal{V}}Q_{U^{N}|Y^{N}}(u^{N}|y^{N})+Q^{*}_{\mathcal{W}}}.

(5)

It is verified in
[
28
]
that the blockwise SO using equation (
5
) is accurate and outperforms Forney’s approximation for polar-like codes. Note that each
\hat{U}^{N}
corresponds to a unique sequence of
\hat{X}^{N}
. This ensures that the same SO calculation can be applied in systematic polar codes.

For CA-polar codes, we can leverage the outer code to improve the accuracy of SO-SCL since not all the valid decoding paths in SCL can pass the CRC check. For any valid decoding path that violates the CRC check, its likelihood of being the transmitted codeword is zero. Recall that
\mathcal{V}^{\prime}\subseteq\mathcal{V}
denotes the set of visited paths that pass the CRC check. The summation
\sum_{u^{N}\in\mathcal{V}}
in (
5
) is hence replaced by
\sum_{u^{N}\in\mathcal{V}^{\prime}}
.

Recall that the length of the CRC is
K-M
, and
\mathcal{W}
denotes the set of unvisited valid paths, which covers the
2^{K}-L
paths satisfying the frozen constraints. Note that
Q^{*}_{\mathcal{W}}
approximates the sum of likelihood of the
2^{K}-L
unvisited valid paths regardless of the CRC check. Within the unvisited valid paths, around
[2^{M}-L,2^{M}]
out of
2^{K}-L
of them are valid codewords that can pass the CRC check. By assuming that the unvisited valid paths satisfying the CRC check are uniformly distributed within all unvisited valid paths,
2^{M-K}Q^{*}_{\mathcal{W}}
can be used to approximate the sum of the likelihood of the unvisited valid paths that can pass the CRC check. Combining the two modifications yields (
6
), which provides the blockwise SO calculation for CA-polar codes using SO-SCL.

V
Conclusion

In this paper, we investigate a decoding pipeline based on CA-SCL with additional decoding step using an outer decoder that makes for a complete decoder. By leveraging the recently developed SO formulae that consider likelihood of unvisited codewords, the pipeline can also provide blockwise SO for UER control. Simulations show that CCA-SCL has around
0.2
dB gain in BLER when using CA-polar code under 5G NR standard. In addition, the same decoder can lead to
0.2\sim 1
dB gain when the CA-polar code is encoded in systematic format.
