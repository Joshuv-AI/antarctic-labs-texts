In this paper we prove and discuss some new ( H p , w ​ e ​ a ​ k − L p ) \left(H_{p},weak-L_{p}\right) type inequalities of maximal operators of T T means with respect to Vilenkin systems with monotone coefficients. 2.
Preliminaries

Denote by
\mathbb{N}_{+}
the set of the positive integers,
\mathbb{N}:=\mathbb{N}_{+}\cup\{0\}.
Let
m:=(m_{0,}

m_{1},...)
be a sequence of the positive
integers not less than 2. Denote by

Z_{m_{k}}:=\{0,1,...,m_{k}-1\}

the additive group of integers modulo
m_{k}
.

Define the group
G_{m}
as the complete direct product of the groups
Z_{m_{i}}
with the product of the discrete topologies of
Z_{m_{j}}`
s.

The direct product
\mu
of the measures

\mu_{k}\left(\{j\}\right):=1/m_{k}\text{ \ \ \ }(j\in Z_{m_{k}})

is the Haar measure on
G_{m_{\text{ }}}
with
\mu\left(G_{m}\right)=1.

In this paper we discuss bounded Vilenkin groups,

i.e. the case
when
\sup_{n}m_{n}<\infty.

The elements of
G_{m}
are represented by sequences

x:=\left(x_{0},x_{1},...,x_{j},...\right),\ \left(x_{j}\in Z_{m_{j}}\right).

It is easy to give a base for the neighborhood of
G_{m}:

I_{0}\left(x\right):=G_{m},\text{ \ }I_{n}(x):=\{y\in G_{m}\mid y_{0}=x_{0},...,y_{n-1}=x_{n-1}\},

where
x\in G_{m},

n\in\mathbb{N}.

Denote
I_{n}:=I_{n}\left(0\right)
for
n\in\mathbb{N}_{+},
and
\overline{I_{n}}:=G_{m}

\backslash

I_{n}
.

If we define the so-called generalized number system based on
m

in the following way :

M_{0}:=1,\ M_{k+1}:=m_{k}M_{k}\,\,\,\ \ (k\in\mathbb{N}),

then every
n\in\mathbb{N}
can be uniquely expressed as
n=\sum_{j=0}^{\infty}n_{j}M_{j},
where
n_{j}\in Z_{m_{j}}

(j\in\mathbb{N}_{+})
and only a finite number of
n_{j}`
s differ from zero.

Next, we introduce on
G_{m}
an orthonormal system which is called the
Vilenkin system. At first, we define the complex-valued function
r_{k}\left(x\right):G_{m}\rightarrow\mathbb{C},
the generalized Rademacher functions, by

r_{k}\left(x\right):=\exp\left(2\pi ix_{k}/m_{k}\right),\text{ }\left(i^{2}=-1,x\in G_{m},\text{ }k\in\mathbb{N}\right).

Now, define the Vilenkin system
\,\,\,\psi:=(\psi_{n}:n\in\mathbb{N})
on
G_{m}
as:

\psi_{n}(x):=\prod\limits_{k=0}^{\infty}r_{k}^{n_{k}}\left(x\right),\,\,\ \ \,\left(n\in\mathbb{N}\right).

Specifically, we call this system the Walsh-Paley system when
m\equiv 2.

The norms (or quasi-norms) of the spaces
L_{p}(G_{m})
and
weak-L_{p}\left(G_{m}\right)

\left(0<p<\infty\right)
are respectively defined by

\left\|f\right\|_{p}^{p}:=\int_{G_{m}}\left|f\right|^{p}d\mu\ \ \ \text{and}\ \ \ \left\|f\right\|_{weak-L_{p}}^{p}:=\underset{\lambda>0}{\sup}\lambda^{p}\mu\left(f>\lambda\right)<+\infty.

The Vilenkin system is orthonormal and complete in
L_{2}\left(G_{m}\right)
(see
[
18
]
).

Now, we introduce analogues of the usual definitions in Fourier-analysis. If

f\in L_{1}\left(G_{m}\right)
we can define the Fourier coefficients, the
partial sums of the Fourier series, the Dirichlet kernels with respect to
the Vilenkin system in the usual manner:

\widehat{f}\left(n\right):=\int_{G_{m}}f\overline{\psi}_{n}d\mu\,\ \ \ \ \ \ \,\left(n\in\mathbb{N}\right),

S_{n}f:=\sum_{k=0}^{n-1}\widehat{f}\left(k\right)\psi_{k},\text{ \ \ }D_{n}:=\sum_{k=0}^{n-1}\psi_{k\text{ }},\text{ \ \ }\left(n\in\mathbb{N}_{+}\right)

respectively. Recall that

(1)

D_{M_{n}}\left(x\right)=\left\{\begin{array}[]{ll}M_{n},&\text{if\thinspace\thinspace\thinspace}x\in I_{n},\\
0,&\text{if}\,\,x\notin I_{n}.\end{array}\right.

The
\sigma
-algebra generated by the intervals
\left\{I_{n}\left(x\right):x\in G_{m}\right\}
will be denoted by
\digamma_{n}\left(n\in\mathbb{N}\right).
Denote by
f=\left(f^{\left(n\right)},n\in\mathbb{N}\right)
a martingale with respect to
\digamma_{n}\left(n\in\mathbb{N}\right)
(for details see e.g.
[
19
]
).

For
0<p<\infty
the Hardy martingale spaces
H_{p}\left(G_{m}\right)

consist of all martingales for which

\left\|f\right\|_{H_{p}}:=\left\|f^{\ast}\right\|_{p}<\infty,\ \ \ \text{where}\ \ \ f^{\ast}:=\sup_{n\in\mathbb{N}}\left|f^{(n)}\right|.

A bounded measurable function
a
is called a p-atom, if there exists an interval
I
, such that

\int_{I}ad\mu=0,\text{ \ \ }\left\|a\right\|_{\infty}\leq\mu\left(I\right)^{-1/p},\text{ \ \ supp}\left(a\right)\subset I.

Weisz
[
21
]
proved that the Hardy spaces
H_{p}
have atomic characterizations. In particular the following is true:

Proposition 1
.

A martingale
f=\left(f^{\left(n\right)},n\in\mathbb{N}\right)
is in
H_{p}\left(0<p\leq 1\right)
if and only if there exists a sequence
\left(a_{k},k\in\mathbb{N}\right)
of p-atoms and a sequence
\left(\mu_{k},k\in\mathbb{N}\right),
of real numbers, such that, for every
n\in\mathbb{N},

(2)

\qquad\sum_{k=0}^{\infty}\mu_{k}S_{M_{n}}a_{k}=f^{\left(n\right)},\ \ \ \ \ \ \ \sum_{k=0}^{\infty}\left|\mu_{k}\right|^{p}<\infty.

Moreover,

\left\|f\right\|_{H_{p}}\backsim\inf\left(\sum_{k=0}^{\infty}\left|\mu_{k}\right|^{p}\right)^{1/p},

where the infimum is taken over all decomposition of

f

of the form
(
2
).
We also need the following result of Weisz
[
21
]
:

Proposition 2
.

Suppose that the operator
T
is
\sigma
-linear and for some
0<p<1

\left\|Tf\right\|_{weak-L_{p}}\leq c_{p}\left\|f\right\|_{H_{p}},

then
T
is of weak type-(1,1) i.e.

\left\|Tf\right\|_{weak-L_{1}}\leq c\left\|f\right\|_{1}.

If
f=\left(f^{\left(n\right)},n\in\mathbb{N}\right)
is a martingale, then the Vilenkin-Fourier coefficients must be
defined in a slightly different manner:

\widehat{f}\left(i\right):=\lim_{k\rightarrow\infty}\int_{G_{m}}f^{\left(k\right)}\overline{\psi}_{i}d\mu.

Let
\{q_{k}:k\geq 0\}
be a sequence of non-negative numbers. The
n
-th Nörlund and
T
means for a Fourier series of
f
are respectively defined by

t_{n}f=\frac{1}{Q_{n}}\overset{n}{\underset{k=1}{\sum}}q_{n-k}S_{k}f,

and

(3)

T_{n}f:=\frac{1}{Q_{n}}\overset{n-1}{\underset{k=0}{\sum}}q_{k}S_{k}f,

where
Q_{n}:=\sum_{k=0}^{n-1}q_{k}.

It is obvious that

T_{n}f\left(x\right)=\underset{G_{m}}{\int}f\left(t\right)F_{n}\left(x-t\right)d\mu\left(t\right),

where
F_{n}:=\frac{1}{Q_{n}}\overset{n}{\underset{k=1}{\sum}}q_{k}D_{k}
is called the
T
kernel.

We always assume that
\{q_{k}:k\geq 0\}
is a sequence of non-negative numbers and
q_{0}>0.
Then the summability method (
3
) generated by
\{q_{k}:k\geq 0\}
is regular if and only if
\lim_{n\rightarrow\infty}Q_{n}=\infty.

If we invoke Abel transformation we get the following identities, which are very important for the investigations of
T
summability:

(4)

\displaystyle Q_{n}

\displaystyle:=

\displaystyle\overset{n-1}{\underset{j=0}{\sum}}q_{j}=\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j+q_{n-1}{(n-1)}

and

(5)

F_{n}=\frac{1}{Q_{n}}\left(\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)jK_{j}+q_{n-1}(n-1)K_{n-1}\right).

The well-known example of Nörlund summability is the so-called
\left(C,\alpha\right)
-mean (Cesàro means), which are defined by

\sigma_{n}^{\alpha}f:=\frac{1}{A_{n}^{\alpha}}\overset{n}{\underset{k=1}{\sum}}A_{n-k}^{\alpha-1}S_{k}f,\qquad 0<\alpha<1,

where

A_{0}^{\alpha}:=0,\qquad A_{n}^{\alpha}:=\frac{\left(\alpha+1\right)...\left(\alpha+n\right)}{n!},\qquad\alpha\neq-1,-2,...

We also consider the "inverse"
\left(C,\alpha\right)
-means, which is an example of a
T
-means:

U_{n}^{\alpha}f:=\frac{1}{A_{n}^{\alpha}}\overset{n-1}{\underset{k=0}{\sum}}A_{k}^{\alpha-1}S_{k}f,\qquad 0<\alpha<1.

Let
V_{n}^{\alpha}
denote
the
T
mean, where
\left\{q_{0}=1,\ q_{k}=k^{\alpha-1}:k\in\mathbb{N}_{+}\right\},

that is

V_{n}^{\alpha}f:=\frac{1}{Q_{n}}\overset{n}{\underset{k=1}{\sum}}k^{\alpha-1}S_{k}f,\qquad 0<\alpha<1.

The
n
-th Riesz‘s logarithmic mean
R_{n}
and the Nörlund logarithmic mean

L_{n}
are defined by

R_{n}f:=\frac{1}{l_{n}}\sum_{k=1}^{n-1}\frac{S_{k}f}{k}\text{ \ \ \ and \ \ \ }L_{n}f:=\frac{1}{l_{n}}\sum_{k=1}^{n-1}\frac{S_{k}f}{n-k},

respectively, where
l_{n}:=\sum_{k=1}^{n-1}1/k.

Up to now we have considered
T
means in the case when the sequence
\{q_{k}:k\in\mathbb{N}\}
is bounded but now we consider
T
summabilities with unbounded sequence
\{q_{k}:k\in\mathbb{N}\}
. Let
\alpha\in\mathbb{R}_{+},\ \ \beta\in\mathbb{N}_{+}
and

\log^{(\beta)}x:=\overset{\beta\text{times}}{\overbrace{\log...\log}}x.

If we define the sequence
\{q_{k}:k\in\mathbb{N}\}
by

\left\{q_{0}=0,\ q_{k}=\log^{\left(\beta\right)}k^{\alpha}:k\in\mathbb{N}_{+}\right\},

then we get the class of
T
means with non-decreasing coefficients:

B_{n}^{\alpha,\beta}f:=\frac{1}{Q_{n}}\sum_{k=1}^{n}\log^{\left(\beta\right)}k^{\alpha}S_{k}f.

We note that
B_{n}^{\alpha,\beta}
are
well-defined for every
n\in\mathbb{N}

B_{n}^{\alpha,\beta}f=\sum_{k=1}^{n}\frac{\log^{\left(\beta\right)}k^{\alpha}}{Q_{n}}S_{k}f.

It is obvious that
\frac{n}{2}\log^{\left(\beta\right)}\frac{n^{\alpha}}{2^{\alpha}}\leq Q_{n}\leq n\log^{\left(\beta\right)}n^{\alpha}.
It follows that

(6)

\displaystyle\frac{q_{n-1}}{Q_{n}}\leq\frac{c\log^{\left(\beta\right)}n^{\alpha}}{n\log^{\left(\beta\right)}n^{\alpha}}=O\left(\frac{1}{n}\right)\rightarrow 0,\text{ \ as \ }n\rightarrow\infty.

We also define the maximal operator
T^{*}
of
T
means by

\displaystyle T^{\ast}f:=\sup_{n\in\mathbb{N}}\left|T_{n}f\right|.

Some well-known examples of maximal operators of
T
means are the maximal operator of Fejér
\sigma^{*}
and Riesz
R^{*}
logarithmic means, which are defined by:

\displaystyle\sigma^{\ast}f:=\sup_{n\in\mathbb{N}}\left|\sigma_{n}f\right|,\ \ \ \ \ R^{\ast}f:=\sup_{n\in\mathbb{N}}\left|R_{n}f\right|.

We also define some new maximal operators
U^{\alpha,\ast},V^{\alpha,\ast},B^{\alpha,\beta,\ast},\ \ (\alpha\in\mathbb{R_{+}},\beta\in\mathbb{N_{+}})
by:

\displaystyle U^{\alpha,\ast}f:=\sup_{n\in\mathbb{N}}\left|U_{n}^{\alpha}f\right|,\ \ \ V^{\alpha,\ast}f:=\sup_{n\in\mathbb{N}}\left|V_{n}^{\alpha}f\right|,\ \ \ B^{\alpha,\beta,\ast}f:=\sup_{n\in\mathbb{N}}\left|B_{n}^{\alpha,\beta}f\right|.
