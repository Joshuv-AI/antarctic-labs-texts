Derandomizing Isolation In Catalytic Logspace
V. Arvind, Srijan Chakraborty, Samir Datta

Abstract
A language is said to be in catalytic logspace if we can test membership using a deterministic logspace machine that has an additional read/write tape filled with arbitrary data whose contents have to be restored to their original value at the end of the computation. The model of catalytic computation was introduced by Buhrman et al [STOC 2014]. As our first result, we obtain a catalytic logspace algorithm for computing a minimum weight witness to a search problem, with small weights, provided the algorithm is given oracle access for the corresponding weighted decision problem. This reduction of Search to Decision is similar in spirit to the Anari-Vazirani result [ITCS 2020], adapted to catalytic logspace (instead of 𝖭𝖢 {\mathsf{NC}} ), that applies to a large class of search problems (instead of just perfect matching). The search to decision reduction crucially uses the isolation lemma of Mulmuley et al [Combinatorica 1987], but sidesteps the Anari-Vazirani machinery [J. ACM 2020, ITCS 2020] for showing planar perfect matching in 𝖭𝖢 {\mathsf{NC}} and the search to decision reduction [ITCS 2020] for perfect matching. In particular, our reduction yields catalytic logspace algorithms for the search versions of the following three problems: planar perfect matching, planar exact (or red-blue) perfect matching and weighted arborescences in general weighted digraphs. Our second set of results concern the oracle complexity class 𝖢𝖫 2 ​ -round 𝖭𝖯 {\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}} (defined in Section 4 ). We show that 𝖢𝖫 2 ​ -round 𝖭𝖯 {\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}} contains 𝖲𝖾𝖺𝗋𝖼𝗁𝖲𝖠𝖳 {\mathsf{SearchSAT}} and the complexity classes 𝖡𝖯𝖯 , 𝖬𝖠 {\mathsf{BPP}},{\mathsf{MA}} and 𝖹𝖯𝖯 𝖭𝖯 ⁡ [ 1 ] {\mathsf{ZPP}}^{{\mathsf{NP}}[1]} . While 𝖲𝖾𝖺𝗋𝖼𝗁𝖲𝖠𝖳 {\mathsf{SearchSAT}} is shown to be in 𝖢𝖫 2 ​ -round 𝖭𝖯 {\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}} using the isolation lemma, the other three containments, while based on the compress-or-random technique, use the Nisan-Wigderson [JCSS 1994] (and Impagliazzo-Wigderson [STOC 1997]) hardness vs randomness based pseudo-random generator. These containments show that 𝖢𝖫 2 ​ -round 𝖭𝖯 {\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}} resembles 𝖹𝖯𝖯 𝖭𝖯 {\mathsf{ZPP}}^{\mathsf{NP}} more than 𝖯 𝖭𝖯 \mathsf{P}^{\mathsf{NP}} , providing some weak evidence that 𝖢𝖫 {\mathsf{CL}} is more like 𝖹𝖯𝖯 {\mathsf{ZPP}} than 𝖯 \mathsf{P} . For our third set of results we turn to isolation well inside catalytic classes. We consider the catalytic class 𝖢𝖳𝖨𝖲𝖯 ​ [ 𝗉𝗈𝗅𝗒 ⁡ ( n ) , log ⁡ n , log 2 ⁡ n ] 𝖴𝖫 {\mathsf{C}}{\mathsf{TISP}}[{\mathsf{poly}}(n),\log n,\log^{2}n]^{{\mathsf{UL}}} which uses only 𝒪 ⁡ ( log 2 ⁡ n ) \mathcal{O}(\log^{2}{n}) catalytic space along with 𝒪 ⁡ ( log ⁡ n ) \mathcal{O}(\log{n}) work space, with 𝖴𝖫 {\mathsf{UL}} given as an oracle, while staying inside polynomial time. We show that this class contains reachability, and therefore 𝖭𝖫 {\mathsf{NL}} . This is a catalytic version of the result of van Melkebeek & Prakriya [SIAM J. Comput. 2019]. Building on their result, we also show a tradeoff between the workspace of the unambiguous oracle machine and the catalytic space i.e. placing reachability in 𝖢𝖳𝖨𝖲𝖯 ​ [ 𝗉𝗈𝗅𝗒 ⁡ ( n ) , log ⁡ n , log 2 − α ⁡ n ] 𝖴𝖳𝖨𝖲𝖯 ⁡ [ 𝗉𝗈𝗅𝗒 ⁡ ( n ) , log 1 + α ⁡ n ] {\mathsf{C}}{\mathsf{TISP}}[{\mathsf{poly}}(n),\log{n},\log^{2-\alpha}{n}]^{{\mathsf{U}}{\mathsf{TISP}}[{\mathsf{poly}}(n),\log^{1+\alpha}n]} where 0 ≤ α ≤ 0.5 0\leq\alpha\leq 0.5 . Finally, we extend these catalytic upper bounds to 𝖫𝗈𝗀𝖢𝖥𝖫 {\mathsf{LogCFL}} by placing it in 𝖢𝖳𝖨𝖲𝖯 ​ [ 𝗉𝗈𝗅𝗒 ⁡ ( n ) , log ⁡ n , log 2 − α ⁡ n ] 𝖴𝖠𝗎𝗑𝖯𝖣𝖠 ​ - ​ 𝖳𝖨𝖲𝖯 ​ [ 𝗉𝗈𝗅𝗒 ⁡ ( n ) , log 1 + α ⁡ n ] {\mathsf{C}}{\mathsf{TISP}}[{\mathsf{poly}}(n),\log{n},\log^{2-\alpha}{n}]^{{\mathsf{U}}{\mathsf{AuxPDA}}\text{-}{\mathsf{TISP}}[{\mathsf{poly}}(n),\log^{1+\alpha}n]} for α ∈ [ 0 , 0.5 ] \alpha\in[0,0.5] .

Introduction

Space-bounded computation is conventionally studied using the Turing
machine model that consists of a read-only input tape and a
space-bounded work-tape, sometimes with additional resources such as
randomness or non-determinism. Catalytic computation is a relatively
new paradigm of space-bounded computation introduced about a decade
ago by Buhrman, Cleve, Koucky, Loff, Speelman
[
7
]
that
allows the Turing machine additional work-space: this is a
full
tape
of storage (often exponentially larger than the work tape). The
machine can use this additional work-tape for both reads and
writes. But the important restriction is that the initial tape
contents must be restored when the machine halts. In a sense, this
additional tape catalyses the computation without any change to it
after the machine halts. Hence, this extra storage tape is called the
catalytic tape. We should mention here that this model of computation
is inspired by a seminal paper by Ben-Or and Cleve
[
6
]

in algebraic computation showing that
3
-register algebraic
straight-line programs suffice for evaluating arithmetic formulas.

The first paper
[
7
]
proved that catalytic logspace
{\mathsf{CL}}
is
apparently more powerful than conventional logspace
{\mathsf{L}}
. Indeed, it
even contains non-deterministic Logspace
{\mathsf{NL}}
. In fact,
{\mathsf{CL}}
can
simulate
{\mathsf{TC}}^{1}
i.e. languages recognized by threshold circuits of
logarithmic depth. On the other hand, we do not even know whether

{\mathsf{CL}}
is contained in polynomial time with the best known upper bound
for
{\mathsf{CL}}
being
{\mathsf{ZPP}}
.

Catalytic logspace,
{\mathsf{CL}}
can be augmented with nondeterminism
(essentially, an
{\mathsf{NL}}
machine with a polynomially bounded catalytic
tape) to define the class
{\mathsf{CNL}}
. Randomized catalytic logspace can
also be considered (essentially, languages accepted by
{\mathsf{BPL}}
machines
with a polynomially bounded catalytic tape) to define
{\mathsf{CBPL}}
. These
classes were studied in
[
15
,
12
]
. Unambiguous
{\mathsf{CL}}

(languages accepted by unambiguous logspace machines with a
polynomially bounded catalytic tape) is considered in
[
20
,
16
]
. It
turns out, as shown by Koucky, Mertz, Pyne and Sami in
[
24
]
,
that these new classes coincide with
{\mathsf{CL}}
. These properties show

{\mathsf{CL}}
to be a robust complexity class.

A different thread of research in catalytic computation, that was
focused on improved catalytic space upper bounds for the
{\mathsf{TreeEval}}
,
led to a major breakthrough by Cook and Mertz
[
13
,
14
]
. They
showed that
{\mathsf{TreeEval}}
requires only catalytic space

\mathcal{O}(\log{n}\log{\log{n}})
in
[
14
]
. This is an important
example of a catalytic bound that yields the best known space bound
(catalysed or otherwise) on a problem. Using this result,
[
38
]
proved that every multitape Turing machine running in time
t
can
be simulated in space only
\mathcal{O}(\sqrt{t\log t})
.

Building on Nisan’s seminal result that
{\mathsf{BPL}}\subseteq{\mathsf{SC}}^{2}
, Pyne

[
30
]
has shown that
{\mathsf{BPL}}
is contained in simultaneous
\log

space, catalytic
\log^{2}
space and polynomial time i.e.

{\mathsf{CTISP}}[n^{\mathcal{O}(1)},\log{n},\log^{2}{n}]
. Further, he has shown a
smooth tradeoff between space and catalytic space i.e. it was shown
that
{\mathsf{BPL}}
is contained in

{\mathsf{CSPACE}}[\log^{1+\alpha}{n},\log^{2-\alpha}{n}]
for every
\alpha\in[0,0.5]
.

As a new addition to upper bound results, Agarwala and Mertz
[
2
]

have shown that Bipartite Matching Search is in
{\mathsf{CL}}
. This is the
first problem not known to be in deterministic
{\mathsf{NC}}
that is placed
inside
{\mathsf{CL}}
making it a remarkable result.

The last two upper bound results, mentioned above, use the so-called

compress-or-random
framework which interprets the catalytic
tape contents as random bits – if this assumption is correct and the
bits “behave like” random bits as required by the algorithm, then the
randomized algorithm succeeds and the problem is solved. On the other
hand, if the bits are not really random in a prescribed sense, then
the catalytic tape can be efficiently compressed in a manner that they
can be efficiently decompressed at the end of the algorithm. This
compression frees up space on the catalytic tape that can be
essentially used for any polynomial-space computation.

The field of Catalytic Logspace has seen numerous other contributions
in the last year or so. Without being comprehensive, here is a sampling

[
1
,
3
,
11
,
34
,
38
]
. We would like to point out two papers that are
related to our work. The first one,
[
1
]
shows a generalisation of

[
2
]
by proving that linear matroid intersection is in
{\mathsf{CL}}
. The other,
initiates the study of oracle based catalytic classes by proving the
existence of an oracle
O
such that
{\mathsf{CL}}^{O}={\mathsf{EXP}}^{O}
thus showing that a
relativizing proof of
{\mathsf{CL}}=\mathsf{P}
cannot exist.

1.1
Technical Overview and Consequences

Reducing search to weighted decision

Mulmuley, Vazirani and Vazirani
[
28
]
gave a randomized
{\mathsf{NC}}
(also
{\mathsf{ZPP}}
) algorithm
that reduces search to weighted decision with polynomially bounded weights in the context
of Perfect Matching. The reduction works by using the isolation lemma to isolate a minimum
weight matching that can then be extracted with multiple parallel queries to the decision
oracle.

This general recipe works for broader class of search problems. Indeed, the recipe can be
applied to reduce search to weighted decision with polynomially bounded
weights for every language with a witness verifiable in
\mathsf{P}
(i.e. for languages in
{\mathsf{NP}}
).
In fact, in
Section

3
, we show in a more general setting that search reduces to
weighted decision with polynomially bounded weights, where the reduction is computable in

catalytic logspace
. Thus, in a sense, we can derandomize the isolation lemma in
these applications using catalytic logspace.

This presents some (weak) evidence that
{\mathsf{CL}}
is closer to
{\mathsf{ZPP}}
than
\mathsf{P}
.

This also enables us to place several problems in
{\mathsf{CL}}
. Important
examples include search for the following:

•

Planar Perfect Matching: known to be in
{\mathsf{NC}}
by recent breakthroughs
[
5
,
33
]
which we do not need to invoke in our proof.

•

Planar Exact Matching: in
\mathsf{P}

[
39
]
but not known to be in
{\mathsf{NC}}

or even
{\mathsf{quasiNC}}
,

•

Min-wt Arborescence in digraphs: known to be in
{\mathsf{NC}}

[
25
]

•

Some other examples follow from
[
27
]
, from various applications of Linear Pfaffian Matroid Parity.

Let
\mathcal{L}
be a language in
{\mathsf{NP}}
. Thus, there exists a predicate
R_{\mathcal{L}}
such that
a word
x\in\mathcal{L}
iff there exists a witness
y
satisfying that
R_{\mathcal{L}}(x,y)
holds
true for

x\in\{0,1\}^{*}
and
y\in\{0,1\}^{m(|x|)}
where
m(\cdot)
is a polynomial.
The decision version for
\mathcal{L}
, on input
x
asks if there exists a witness
y

such that
(x,y)
satisfies the relation

R_{\mathcal{L}}
. The search version requires to find such a
y
. One strategy to find a
witness is to isolate one by using a weight function such that the min weight
witness becomes unique and then can be extracted using a weighted decision oracle.
We amplify on this strategy below.

Given a
y\in\{0,1\}^{m}
, consider the set
F_{y}=\{e:y_{e}=1\}\subseteq[m]
.
A weight function
{W}:[m]\to\{0,1,\ldots,{{\mathsf{poly}}(n)}\}
, naturally extends to
subsets
S\subseteq[m]
as
{W}(S)=\sum_{e\in S}{{W}(e)}
.
The weighted decision oracle takes as input
(x,{W},w)
and outputs a
1
iff
there is a witness
y
of weight
{W}(F_{y})\leq w
.
We can find
\min_{y:R_{\mathcal{L}}(x,y)=1}W(F_{y})
by sequentially querying the decision
oracle for all
w\in[0,{\mathsf{poly}}(n)]
until the oracle returns
1
.

Under the assumption that the minimum weight
w
of
y
is unique we can use the oracle
to even find this
y
by modifying the weight assignment
{W}
. In particular
we define the weight function
{W}|_{e\leftarrow a}
as being identical to
{W}
except
that for bit
e
the weight is set to
a
. Since we assume that
y
is unique so

e\in F_{y}
iff
\min_{y:R_{\mathcal{L}}(x,y)=1}{W}|_{e\leftarrow\infty}(F_{y})>w
. Notice that this
is similar to the strategy used by
[
28
]
to isolate and extract a perfect matching,
The difference is that instead of deleting
e
we set its weight to
\infty
.

Thus, we are left to deal with the case that the isolating assumption on the minimum
weight
y
does not hold. In this case, we can detect a “threshold” element
e

that occurs in one minimum weight witness but does not occur in another minimum weight
witness. A threshold element indicates that the weight
function
{W}
is compressible because we can recreate the weight
{W}(e)
knowing
only the weights
{W}(e^{\prime})
for
e^{\prime}\neq e
and in fact from
{W}|_{e\leftarrow 0}

and
{W}|_{e\leftarrow\infty}
simply as the the difference of the weights of the
minimum weight witnesses under the preceding two weight assignments.

In the catalytic logspace setting we consider weight assignments, one by one,
from the catalytic storage. If we find an isolating assignment we can
use the oracle to find the minimum weight witness. On the other hand if we find
a non-isolating weight assignment we can compress the weight function by
\mathcal{O}(\log{n})

with access to the weighted decision oracle. Thus, examining polynomially many
weight assignments, if we are unable to find an isolating assignment among them,
we would have saved polynomial space by the compression sketched above, and can use
any polynomial space algorithm to find the solution. As
\mathcal{L}\in{\mathsf{NP}}
such an algorithm
clearly exists.

Catalytic Logspace with an
{\mathsf{NP}}
oracle

It is shown in
[
7
]
that
{\mathsf{CL}}\subseteq{\mathsf{ZPP}}
. In fact, this containment relativizes.
That is, for any oracle
A
we have
{\mathsf{CL}}^{A}\subseteq{\mathsf{ZPP}}^{A}
. In particular, we have

{\mathsf{CL}}^{{\mathsf{NP}}}\subseteq{\mathsf{ZPP}}^{{\mathsf{NP}}}
. In this section, we consider a variant of the class
{\mathsf{CL}}^{{\mathsf{NP}}}

in which the queries are asked in a non-adaptive fashion in rounds, which we need to carefully define.

We first observe that the reduction from search to weighted decision directly implies that
{\mathsf{SearchSAT}}\in{\mathsf{CL}}^{{\mathsf{NP}}}
where
{\mathsf{SearchSAT}}
is the search version of
{\mathsf{SAT}}
. That is, given a CNF formula
\phi
,
{\mathsf{SearchSAT}}
is the problem of computing a satisfying assignment for a given input formula
\phi
, if it is satisfiable. This easily follows as the weighted decision queries can be simulated using a
{\mathsf{NP}}
oracle. It is shown in
[
35
]
that there is a polynomial-time randomized reduction from
{\mathsf{SAT}}
to unique-
{\mathsf{SAT}}
, where unique-
{\mathsf{SAT}}
asks whether a formula
\phi
is in
{\mathsf{SAT}}
or not, conditioned on
\phi
having at most one satisfying assignment. The isolating lemma of
[
28
]
can be used to provide a different proof that
{\mathsf{SAT}}
is randomly reducible to unique-
{\mathsf{SAT}}
. Our result on
{\mathsf{SearchSAT}}
is essentially a derandomization of this randomized reduction based on catalytic isolation. With a careful analysis of the above reduction, we show that the search problem
{\mathsf{SearchSAT}}
can be solved using a
{\mathsf{CL}}
machine with

two parallel rounds
of polynomially many
{\mathsf{NP}}
queries.

introduced in Nisan and Wigderson (strengthened subsequently by Impagliazzo-Wigdereson)

can stretch

pseudorandom strings that can fool all

{\mathsf{E}}
(which denotes DTIME

is that there is

L\in{\mathsf{DTIME}}[2^{O(n)}]={\mathsf{E}}

L

This idea was used by Goldreich-Zuckerman
[

to show that
{\mathsf{BPP}}

{\mathsf{ZPP}}^{\mathsf{NP}}

{\mathsf{NP}}

T

C

Catalytic isolation for Reachability and Semi-unbounded circuit evaluation

In the previous sections we saw that the isolation lemma of
[
28
]
can be
derandomized in the context of
{\mathsf{CL}}
and
{\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}}
. In this section we
derandomize the isolation lemma as applied to reachability and evaluation of
semi-unbounded circuits. Notice that both these problems are well inside
the entire
{\mathsf{CL}}
(since
{\mathsf{NL}}\subseteq{\mathsf{LogCFL}}\subseteq{\mathsf{TC}}^{1}\subseteq{\mathsf{CL}}
)
so we have to explore subclasses of
{\mathsf{CL}}
for this to make sense.
For this we consider variants of
{\mathsf{CL}}

by further restricting the catalytic space and with access to unambigious low space oracles. The ensuing fine grained classes form upper bounds for several
natural and
interesting problems/classes. This includes the result from
[
30
]

simulating
{\mathsf{BPL}}
in catalytic space
\mathcal{O}(\log^{2}{n})
while persisting with

\mathcal{O}(\log{n})
work space and polynomial time.
Also, an upper bound for
{\mathsf{BPL}}
that is a tradeoff result between
catalytic and work space without preserving polynomial time. A third example is

{\mathsf{TreeEval}}
for which, an intriguing
\mathcal{O}(\log{n}\log{\log{n}})

catalytic and work space bound is shown in
[
14
]
.

However, notice that it is not viable to show
{\mathsf{NL}}
in small catalytic space
and work space while preserving polynomial time – such a proof would imply

{\mathsf{NL}}\subseteq{\mathsf{SC}}
resolving a venerable open problem.
In this backdrop, we aim to show similar results for
{\mathsf{NL}}
and
{\mathsf{LogCFL}}
by
modifying the techniques originating from
[
31
]
which was in turn inspired
by
[
18
]
.
It was shown in
[
31
]
that logspace non-determinism can be made
unambiguous at least non-uniformly by crucially using the isolation lemma. In the same spirit, we show that
{\mathsf{NL}}
is contained in the catalytic class with
\mathcal{O}(\log^{2}{n})
catalytic
space and
\mathcal{O}(\log{n})
work space with access to a
{\mathsf{UL}}
oracle (notice that this is different from catalytic unambiguous classes mentioned in
[
24
]
). We are also
able to prove a tradeoff result between catalytic space and the workspace of the oracle, for
{\mathsf{NL}}
.
Notably, our results are all in simultaneous polynomial time.
They are, in fact, catalytic adaptations of the results of
[
36
]
.
Historically,
[
36
]
is based on the results of
[
22
,
17
]
which yield
a partial derandomization of the isolation lemma in the context of reachability
and bipartite perfect matching respectively.
We are able to extend the results of
[
36
]
on
{\mathsf{LogCFL}}
to the catalytic
setting as well.

The results are based on derandomizing the isolation lemma for reachability
and semi-unbounded circuit evaluation problem, respectively for
{\mathsf{NL}},{\mathsf{LogCFL}}
. A brief description of our strategy is given below.

Given a layered directed acyclic graph
G
,
[
36
]
gives a procedure to give vertex weights so as to isolate min unique
s-t
paths for all
s,t\in V(G)
. They use several logspace hash functions, where the seed length is logarithmic, to construct these weight assignments. When
[
36
]
require a new hash function, they iterate over all hash functions to find a ‘good’ hash that works for their purposes. Once they have found a ‘good’ hash, they store it, and either have found enough hash functions, or move on to find the next hash function. Once the minimum weight path has been isolated, reachability can be computed in unambiguous logspace (if the weights are larger, then in logarithmic space in the magnitude of weights), as shown by
[
31
]
. The same techniques have been adapted for the semi-unbounded circuit evaluation problem for logarithmic depth circuits in
[
31
]
and
[
36
]
.

Instead, we interpret the catalytic tape contents as hash functions. When we need a new hash function, we assume the corresponding block of catalytic tape to be the hash function. We check if this hash function is indeed ‘good’ or not using an unambiguous oracle. If it is, we can proceed following the algorithm in
[
36
]
. Otherwise, we observe that the number of ‘bad’ hash functions is substantially smaller than the number of ‘good’ hash functions. Hence, we replace the ‘bad’ hash function from the tape, and replace it with its index among the set of all bad hash functions. In this process, we end up saving some space. If by the end of this process, we have found a sufficient number of hash functions, we construct the required weight assignments efficiently. Instead, if we have not been able to find the correct number of hashes, we have ended up saving enough space to run
[
36
]
directly. Later, we restore the catalytic tape contents to its initial configuration, again by replacing the indices of the bad hash functions with the corresponding hash functions.

In
[
36
]
, it is required to sample
\mathcal{O}(\log^{0.5}n)
many hash functions, each hash requiring
\mathcal{O}(\log n)
bits of space. In fact, a finer analysis of
[
36
]
shows that, for all
\alpha\in[0,0.5]
, using
\mathcal{O}(\log^{1-\alpha}n)
many hash functions, we can find isolating weight assignments such that the weight of every vertex is of bitlength
\mathcal{O}(\log^{1+\alpha}n)

Interestingly, our result also shows that

{\mathsf{CSPACE}}[\log n,\log^{2}n]

{\mathsf{UL}}

{\mathsf{CSPACE}}[\log n,\log^{2}n]

Lemma 4.1
.

For any oracle

Proof.

Let

Claim.
For

Proof of claim.
Suppose, for contradiction, that for some

uniquely determined
3
3

3

When the machine enters the query state

\square

Observe that the total number of logspace worktape configurations possible is

.

In this section we revisit the isolation lemma as applied to the

Recall that a boolean circuit

\wedge

Definition 6.1

7
Concluding remarks

We have shown new applications of the
compress-or-random
pradigm in
catalytic computation. In particular, using the isolation lemma we obtain
a general search to decision reduction that is computable in catalytic
logspace, thereby showing several natural search problems are in
catalytic logspace. With a different use of this paradigm, we obtain
containments of several complexity classes in
{\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}}
, showing that

{\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}}
is closely related to
{\mathsf{ZPP}}^{\mathsf{NP}}
. Finally, we explore the
question of simulating
{\mathsf{NL}}
using
\mathcal{O}(\log^{2}n)
catalytic space and
similar catalytic space upper bounds for
{\mathsf{LogCFL}}
.

We are left with many intriguing questions, such as:

1.

Can Savitch be made purely catalytic i.e. can we prove:

{\mathsf{NL}}\subseteq{\mathsf{CSPACE}}[\log n,\log^{2}n]
? Notice that from
Corollary

5.6.1
, it suffices to show that
{\mathsf{UL}}\subseteq{\mathsf{CSPACE}}[\log n,\log^{2}n]
.

2.

What is the relationship between
{\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}}
and
{\mathsf{S_{2}^{P}}}
? They seem to have
similar lower and upper bounds.

3.

For the containments in
{\mathsf{CL}}^{{\mathsf{NP}}}_{2\text{-round}}
of the classes
{\mathsf{BPP}}
,
{\mathsf{MA}}
,
and
{\mathsf{ZPP}}^{{\mathsf{NP}}[1]}
shown in Section
4
can we improve it to containment
in
{\mathsf{CL}}^{{\mathsf{NP}}}_{1\text{-round}}
?
