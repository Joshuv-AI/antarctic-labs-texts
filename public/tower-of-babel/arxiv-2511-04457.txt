Abstract
We study ranking and selection under input uncertainty in settings where additional data cannot be collected. We propose the Nonparametric Input-Output Uncertainty Comparisons (NIOU-C) procedure to construct a confidence set that includes the optimal solution with a user-specified probability. We construct an ambiguity set of input distributions using empirical likelihood and approximate the mean performance of each solution using a linear functional representation of the input distributions. By solving optimization problems evaluating worst-case pairwise mean differences within the ambiguity set, we build a confidence set of solutions indistinguishable from the optimum. We characterize sample size requirements for NIOU-C to achieve the asymptotic validity under mild conditions. Moreover, we propose an extension to NIOU-C, NIOU-C:E, that mitigates conservatism and yields a smaller confidence set. In numerical experiments, NIOU-C provides a smaller confidence set that includes the optimum more frequently than a parametric procedure that takes advantage of the parametric distribution families.



1
Introduction

Stochastic simulation is widely used for decision-making owing to its flexibility and ability to model randomness. Simulation outputs depend on input random vectors from models estimated using data. When data collection is costly or limited to a single batch, input models are subject to finite-sample error, introducing extra uncertainty beyond run-to-run variability. This additional uncertainty, called
input uncertainty
(IU)
(
Barton et al. 2022
)
, cannot be reduced when further data collection is infeasible.

We consider ranking and selection (R&S) where the goal is to find the solution with the largest expected system output, represented by the simulation output mean.
This setting arises when additional input data collection is infeasible or far costlier than simulation replications. For instance,
General Motors uses simulation to compare vehicle content portfolios, with input models estimated from one-time consumer survey data
(
Song et al. 2020
)
.
Identifying the best solution is challenging when the performance measures differences are marginal
(
Song et al. 2015
)
.
Throughout the paper, we assume that the simulated optimum under the true distributions is the system optimum.

Our goal is to infer the solution by constructing a confidence set of solutions that contains the solution with a user-specified probability, accounting for IU and simulation error in the performance measure estimates, and ensuring asymptotic validity as sample sizes grow.
A similar problem is studied in
Song and Nelson 2019
, which introduces the Input–Output Uncertainty Comparisons (IOU-C) and assumes the input distributions have known parametric distribution functions.
This assumption simplifies input modeling to parameter estimation and enables parametric response models (e.g., regression) to link input and output. Consequently, quantifying IU reduces to characterizing the sampling distribution of the parameter estimator and fitting the response model.

However, parametric assumptions on the input distribution are often unrealistic. Without strong physical justification, the parametric input model is typically chosen by fitting a number of candidate distributions to the data and picking the best goodness-of-fit test score.
Misspecification can severely impact decisions. For instance,
Song et al. 2024
empirically show that fitting an exponential distribution to bimodal service times in a queueing model causes severe undercoverage of confidence intervals (CIs) for the mean performance measure.
Moreover, bias from an incorrect parametric model persists even with a large input data size.

We propose a nonparametric framework to construct the confidence set directly from the input data.
Using empirical likelihood (EL)
(
Owen 2001
)
, we quantify the uncertainty about the true input distributions without parametric assumptions.
EL enables constructing an ambiguity set of input models, which asymptotically contains a distribution function yielding the correct simulation output means for all
k
solutions with a given probability as input size grows. Leveraging this result, we adapt the classical multiple comparisons with the best (MCB) procedure
(
Chang and Hsu 1992
)
by computing the confidence region of simulation output mean differences through
k(k-1)
optimization problems, each maximizing the pairwise mean difference subject to the ambiguity set.

Solving these optimization problems is challenging as the objectives must express the simulation output mean as a functional of each input model in the ambiguity set. Therefore, we approximate the objectives using first-order functional Taylor expansions, where dependence on the input models is represented by influence functions
(
Hampel 1974
)
estimated via simulations. This yields convex problems, which can be solved to arbitrary precisions at a low computational cost. The CI bounds are then estimated by running simulations at the maximizers. We formalize this procedure as an algorithmic framework, Nonparametric IOU-C (NIOU-C). We show that NIOU-C returns the confidence set including the optimum with asymptotically correct coverage probability provided that simulation sample sizes grow faster than the input data size. In numerical studies, NIOU-C delivers the correct empirical confidence with a smaller confidence set than an IOU-C algorithm in all experiments. Notably, even if the algorithm correctly assumes the parametric input distributions, NIOU-C still outperforms it.

1.1
Literature Review

Our work extends and builds on a number of research fields, which we briefly review below.

Nonparametric IU quantification

Prior work on nonparametric IU quantification mainly constructs confidence intervals for a single simulation output mean; see Section 17.3.2 of
Barton et al. 2022
for a review. Most approaches adopt bootstrap to approximate the input data’s sampling distribution
(
Song et al. 2024
)
.
Our work is closest to
Lam and Qian 2016
,
Lam and Qian 2017
, which also use EL to construct CIs accounting for IU.
However, their inference is one-dimensional, while we extend EL to multiple dimensions for joint inference on all R&S solutions.

Simulation optimization under IU

Existing work either consider fixed input batches or allow for additional data collection.
A detailed discussion on the latter can be found in
He and Song 2024
.
For fixed batches,
Corlu and Biller 2013
,
Corlu and Biller 2015
,
Song and Nelson 2019
study the confidence set inference for parametric input models.

Pearce and Branke 2017
,
Wang et al. 2020
instead optimize expected simulation output accounting for simulation error and IU via Bayesian optimization,
representing risk-neutral approaches. On the other hand,
Gao et al. 2017
,
Fan et al. 2020
consider robust formulations modeling IU with a finite set of candidate distributions. They aim to find the solution with the best worst-case performance and propose sequential sampling algorithms.
Wu et al. 2018
study R&S with risk measures (e.g. quantiles) under parametric Bayesian IU without providing specific solution algorithms. These frameworks
assume known parametric families of input models, or restrict candidate distributions to finite sets.

Distributionally robust optimization (DRO)

In DRO, ambiguity sets represent distributional uncertainty in stochastic optimization.
Delage and Ye 2010
use moment-based ambiguity sets,
Ben-Tal et al. 2013
employ
f
-divergence ball, and

Esfahani and Kuhn 2018
adopt Wasserstein balls for high-probability coverage.

Lam 2019
further links EL-based ambiguity sets to Burg entropy. While we also use ambiguity sets, our focus differs: rather than optimizing decisions under worst-case distributions, we evaluate worst-case pairwise performance differences within the ambiguity set to form a confidence region for solution means, from which we construct the confidence set.

1.2
Contribution Summary

We propose a data-driven procedure for R&S under IU that provides a confidence set containing the unknown best with a user-specified probability.
Our main contributions are fourfold:

(i)
We provide the first nonparametric framework for R&S under IU, improving real-world applicability.

(ii)
Using EL, we model uncertainty in solution comparisons via an ambiguity set, and approximate simulation-based performance measures using influence functions.
To build the confidence set, we then formulate optimization problems solvable with standard solvers.

(iii)
We prove that the confidence set provides an asymptotically valid coverage when simulation sample sizes grow faster than the input data size regardless of the number of data sources or the dimensionality of the input data.

(iv)
We benchmark against IOU-C on examples where it either correctly specifies or misspecifies the distribution families. Our confidence set achieves correct coverage with the same simulation budget while IOU-C fails
under misspecification and becomes conservative otherwise.

A conference version of this work appeared in
Gonzalez et al. 2024
,
which we extend in several directions.
First, we establish a rigorous theoretical foundation for NIOU-C and prove that the proposed procedure achieves the desired coverage guarantee in the limit.
Second, we propose NIOU-C:E, an efficiency-oriented variant designed to reduce the conservatism in confidence sets.
Third, we expand the empirical study by conducting a comprehensive sensitivity analysis to examine how approximation errors affect the performance of NIOU-C and NIOU-C:E under varying input sizes, simulation budgets, and the numbers of solution.

Problem Description

We consider an R&S problem with
k\in\mathbb{N}
candidate solutions, evaluated by a stochastic simulator.
The system’s randomness is modeled by a collection of input distributions,
\boldsymbol{F}^{c}\triangleq\{F_{p}^{c}\}_{p\in[m]}
,
where each
F_{p}^{c}
is a probability density function
defined on a subset
\Xi_{p}
of Euclidean space, and
[m]\triangleq\{1,\ldots,m\}
. We assume that the input distributions are mutually independent, meaning that the random inputs
\mathbf{X}_{1},\ldots,\mathbf{X}_{m}
, with
\mathbf{X}_{p}\sim F_{p}^{c}
, are statistically independent across
p\in[m]
.

For each Solution
i
, the simulation output
Y_{i}(\boldsymbol{F})
depends on an arbitrary input model
\boldsymbol{F}\triangleq\{F_{p}\}_{p\in[m]}
. A replication of
Y_{i}(\cdot)
requires
T_{ip}
independent and identically distributed (i.i.d.) realizations,
\boldsymbol{Z}^{i}_{p}(1),\ldots,\boldsymbol{Z}^{i}_{p}(T_{ip})\sim F_{p}
, denoted by
\mathbf{Z}^{i}_{p}\triangleq\{\boldsymbol{Z}^{i}_{p}(t)\}_{t\in[T_{ip}]}
from each
p\in[m]
. We formalize the input-output relationship and a bounded moment condition on
h_{i}
below.

Assumption 1

For each
i\in[k]
,
Y_{i}(\boldsymbol{F})=h_{i}(\mathbf{Z}^{i}_{1},\ldots,\mathbf{Z}^{i}_{m})
, where
h_{i}\colon\Xi_{1}^{T_{i1}}\times\cdots\times\Xi_{m}^{T_{im}}\to\mathbb{R}
is the output function of Solution
i
and
0<T_{ip}<\infty
is a known constant for each
p\in[m]
. Furthermore, for each
i\in[k]
,
h_{i}

is measurable and satisfies

\int|h_{i}(\boldsymbol{x}_{1},\ldots,\boldsymbol{x}_{m})|^{2}\,\prod\nolimits_{p=1}^{m}\prod\nolimits_{t=1}^{T_{ip}}\mathrm{d}F_{p}^{c}(\boldsymbol{x}_{p,t})<\infty
.

In general,
h_{i}
does not have an analytical expression. For instance,
h_{i}
may be an abstract representation of how inputs are mapped to the summary statistic computed at the end of a replication of a discrete-event simulator. While we adopt both
Y_{i}(\boldsymbol{F})
and
h_{i}(\mathbf{Z}^{i}_{1},\ldots,\mathbf{Z}^{i}_{m})
to denote the output, we use the latter whenever we need to explicitly represent the dependence on the inputs.
We define the performance measure of Solution
i
,
\eta_{i}(\boldsymbol{F})
, as the expectation of the simulation output, which can explicitly be rewritten in an integral form under
1
:

\eta_{i}(\boldsymbol{F})\triangleq\mathrm{E}[Y_{i}(\boldsymbol{F})]=\int h_{i}(\boldsymbol{x}_{1},\ldots,\boldsymbol{x}_{m})\,\prod\nolimits_{p=1}^{m}\prod\nolimits_{t=1}^{T_{ip}}\mathrm{d}F_{p}(\boldsymbol{x}_{p,t}),\quad\text{where}\quad\boldsymbol{x}_{p}=\{\boldsymbol{x}_{p,t}\}_{t\in[T_{ip}]}.

The goal
is to find the solution with the largest performance measure when
\boldsymbol{F}^{c}
is the input model:

i^{c}\triangleq\arg\max\nolimits_{i\in[k]}\eta_{i}(\boldsymbol{F}^{c}).

(1)

We assume
i^{c}
to be unique in this work, i.e.,
\eta_{i^{c}}(\boldsymbol{F}^{c})\neq\eta_{i}(\boldsymbol{F}^{c})
for all
i\in[k]\setminus\{i^{c}\}
.

The true input model
\boldsymbol{F}^{c}
is typically unknown, but may be estimated from data. For each
p\in[m]
, we assume access to a fixed
batch of
n_{p}
i.i.d. samples,
\{\boldsymbol{X}_{pj}\}_{j\in[n_{p}]}
, from
F_{p}^{c}
, collected independently across
p\in[m]
.
Let

n\triangleq(1/m)\sum_{p=1}^{m}n_{p}
denote the average sample size from
m
sources.
Although our methodology is specifically designed for problems where additional data collection is infeasible, in later sections we analyze the asymptotic behavior as
n\to\infty
to assess the precision of statistical inference under increasing data availability.
To this end, we make the
following assumption.

Assumption 2

There exists
\beta_{p}>0
such that
n_{p}/n\to\beta_{p}
as
n\to\infty
.

While one could plug in the empirical estimates of
\boldsymbol{F}^{c}
to solve (
1
), this may not reliably identify the correct solution
i^{c}
with a high probability
(
Song et al. 2015
)
. Instead, we take an inference approach, constructing a data-driven, computationally tractable confidence set
I_{n}\subset[k]
such that

\liminf\nolimits_{n\to\infty}\Pr\{i^{c}\in I_{n}\}\geq 1-\alpha.

(2)

To construct
I_{n}
, we first establish the following lemma, generalizing Theorem 1.1 in
Chang and Hsu 1992
to construct MCB CIs without requiring point estimates of
\eta_{i}(\boldsymbol{F}^{c})
, and to allow for asymptotic coverage guarantees.
For
x\in\mathbb{R}
, let
x^{+}\triangleq\max\{0,x\}
and
x^{-}\triangleq\max\{0,-x\}
.

Lemma 1
(Asymptotic MCB-CI)

Let
\alpha\in(0,1)
.
If for each
i\in[k]
there exists a sequence of random variables

\{U_{i\ell,n}\}_{n\geq 1,\ell\neq i}
such that

\liminf_{n\to\infty}\Pr\big\{\eta_{i}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c})\leq U_{i\ell,n},\forall\ell\neq i\big\}\geq 1-\alpha,

(3)

then

\liminf_{n\to\infty}\Pr\big\{\eta_{i}(\boldsymbol{F}^{c})-\max\nolimits_{\ell\neq i}{\eta_{\ell}(\boldsymbol{F}^{c})}\in[D_{i,n}^{-},D_{i,n}^{+}],\forall i\in[k]\big\}\geq 1-\alpha,

(4)

where
D_{i,n}^{+}\triangleq\big(\min_{\ell\neq i}\{U_{i\ell,n}\}\big)^{+}
,

I_{n}\triangleq\{i\in[k]:D_{i,n}^{+}>0\}
, and

D_{i,n}^{-}=0
if
I_{n}=\{i\}
, and

D_{i,n}^{-}=-\big(\min_{\ell\in I_{n}:\ell\neq i}\{-U_{\ell i,n}\}\big)^{-}
,
otherwise.
Moreover,

\liminf_{n\to\infty}\Pr\{i^{c}\in I_{n}\}\geq 1-\alpha
.

Lemma

1
states that if, for each
i\in[k]
, we construct simultaneous
1-\alpha
CIs for the
k-1
pairwise differences
\{\eta_{i}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c})\}_{\ell\neq i}
, then we can construct MCB CIs that cover the difference between each solution’s mean and the best of the rest with the same probability.
To obtain the bounds
\{U_{i\ell,n}\}_{\ell\neq i}
satisfying (
3
), we proceed in three steps.
(i) We define a data-driven ambiguity set
\mathcal{U}_{\alpha}

to capture uncertainty in
\boldsymbol{F}^{c}
using EL.
(ii) We introduce a tractable linear model
\eta_{i}^{L}(\boldsymbol{F})
of
\eta_{i}(\boldsymbol{F})
for
\boldsymbol{F}\approx\boldsymbol{F}^{c}
.
(iii) We construct a confidence region for
\{\eta_{i}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c})\}_{\ell\neq i}
for each
i\in[k]
by solving worst-case optimization problems with
\{\eta_{i}^{L}(\boldsymbol{F})-\eta_{\ell}^{L}(\boldsymbol{F})\}_{\ell\neq i}
as objectives subject to
\boldsymbol{F}\in\mathcal{U}_{\alpha}
and derive
I_{n}
from the maximizers via
Lemma

1
.

Assumption 4

For each

\sup_{\boldsymbol{w}\in\mathcal{U}_{\alpha}}\mathrm{E}_{\boldsymbol{w}}\big[|h_{i}(\mathbf{Z}^{i}_{1},\ldots,\mathbf{Z}^{i}_{m})|^{4}\big]<\infty

7
Extension with Tighter Bounds

We computed a polyhedral set containing
C_{\alpha}
(see (
14
)) using the optimal values
\{U_{i\ell,n}\}_{i\neq\ell}
from (
12
). While this method ensures coverage, it becomes increasingly conservative as
k
grows, leading to overcoverage of the joint CI in (
3
).
To mitigate this, we propose an alternative approach for computing
\{U_{i\ell,n}\}_{i\neq\ell}
. We adapt the technique developed in Section 5.1 of
Lam 2019
, originally developed for tight statistical guarantees in EL-based DRO with multiple expectation constraints.

As shown in
Theorem

1
, twice the negative log empirical likelihood under the true mean constraint converges to
\chi^{2}_{q}
. To reduce conservatism,
Lam 2019
models the
q
dimensions as correlated
\chi^{2}_{1}
variables and uses the
1-\alpha
quantile of their maximum—rather than
\chi^{2}_{q,1-\alpha}
—to construct a tighter confidence region for the mean vector in (
6
).
To apply this modification to NIOU-C, we estimate the corresponding quantile for each Solution
i
.
Let us define

\upsilon_{\ell}(\boldsymbol{X}_{pj})\triangleq\mathrm{IF}_{ip}(\boldsymbol{X}_{pj};\boldsymbol{F}^{c})-\mathrm{IF}_{\ell p}(\boldsymbol{X}_{pj};\boldsymbol{F}^{c})

and let
q_{n}
be the
1-\alpha
quantile of
\sup_{\ell\neq i}J_{\ell}
, where for each
\ell\neq i
,
J_{\ell}\triangleq G_{\ell}^{2}
,
G_{\ell}\sim\mathrm{N}(0,1)
, and

\mathrm{Corr}(G_{\ell},G_{\ell^{\prime}})=\frac{\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\mathrm{Cov}(\upsilon_{\ell}(\boldsymbol{X}_{p}),\upsilon_{\ell^{\prime}}(\boldsymbol{X}_{p}))}{\sqrt{\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\mathrm{Var}(\upsilon_{\ell}(\boldsymbol{X}_{p}))\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\mathrm{Var}(\upsilon_{\ell^{\prime}}(\boldsymbol{X}_{p}))}},\quad\ell^{\prime}\in[k]\backslash\{i,\ell\}.

(19)

Marginally,
J_{\ell}\sim\chi^{2}_{1}
and (
19
) describes the correlations among the
k-1
such
\chi^{2}_{1}
random variables. The variance and covariance terms in (
19

Algorithm

2

Since the influence function estimator from the main experiment is utilized here, its estimation error induces bias into

replaces

\widehat{R}=(\widehat{R}_{\ell\ell^{\prime}})_{1\leq\ell,\ell^{\prime}\leq d}

\widehat{R}_{\ell\ell^{\prime}}=\frac{\widehat{\Sigma}_{\ell\ell^{\prime}}}{\sqrt{\widehat{\Sigma}_{\ell\ell}\,\widehat{\Sigma}_{\ell^{\prime}\ell^{\prime}}}}=\frac{\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\sum_{j=1}^{n}\big(\widehat{\upsilon}_{\ell}(\boldsymbol{X}_{pj})-\widehat{\mu}^{(p)}_{\ell}\big)\big(\widehat{\upsilon}_{\ell^{\prime}}(\boldsymbol{X}_{pj})-\widehat{\mu}^{(p)}_{\ell^{\prime}}\big)}{\sqrt{\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\sum_{j=1}^{n}\big(\widehat{\upsilon}_{\ell}(\boldsymbol{X}_{pj})-\widehat{\mu}^{(p)}_{\ell}\big)^{2}\sum_{p=1}^{m}\frac{n_{p}}{n_{p}-1}\sum_{j=1}^{n}\big(\widehat{\upsilon}_{\ell^{\prime}}(\boldsymbol{X}_{pj})-\widehat{\mu}^{(p)}_{\ell^{\prime}}\big)^{2}}}.

4:

Let
\boldsymbol{\xi}\sim\mathrm{N}(0,\widehat{R})
.
Generate
M
independent realizations
\boldsymbol{\xi}^{(1)},\dots,\boldsymbol{\xi}^{(M)}
, each of dimension
k-1
.

5:

For each
t\in[M]
, compute

S_{t}=\max_{\ell\neq i}\big(\xi^{(t)}_{\ell}\big)^{2}.

6:

Let
\widehat{q}_{n}
be the empirical
(1-\alpha)
quantile of
\{S_{t}:t\in[M]\}
.

7:

return

\widehat{q}_{n}
.

8.2
Queueing System

We compare IOU-C and NIOU-C using a tandem queue simulation with three first-in-first-out servers. Arrivals follow a Poisson process with
\lambda=6.67
, and independent mean service times are
\mu_{1}=0.73
,
\mu_{2}=0.7
, and
\mu_{3}=0.8
.
The first server has infinite queue capacity; the second and third have capacities of 2 and 3, introducing potential blocking.
Each server starts with a base capacity of 4, and extra capacity can be added at costs
\boldsymbol{c}=(2,5,6)
within a budget of 9, producing
k=9
feasible solutions.
The objective is to minimize the average total waiting time of the first 100 customers.
We estimate service time distributions from data. For each macro-run and
p\in[3]
, we generate i.i.d. samples of size
n_{p}=n\in\{100,400\}
from the true service time distribution. IOU-C assumes exponential distributions and obtains rates via maximum likelihood estimation (MLE).
We chose
1-\alpha=0.9
, and NIOU-C and IOU-C use CRNs. Each replication generates
100
variates per input, as each customer visits all three servers, i.e.,
T_{ip}=100
for
i\in[k]
,
p\in[3]
.

We test two IOU-C variants:
IOU-C: All-in
(IOU-C:A) and
IOU-C: Plug-in
(IOU-C:P). Both fit a linear regression model for
\eta_{i}
in the parameter vector of the input models, but IOU-C:A accounts for coefficient estimation error in MCB CIs, making it more conservative and yielding larger
\widehat{I}_{n}
than IOU-C:P.

To ensure a fair comparison, all methods use the same total simulation runs. For IOU-C,
Song and Nelson 2019
recommend running replications proportional to
n
at each solution with
\widehat{\boldsymbol{F}}
as the input model and sample
D\propto n^{1.1}
design points from the MLEs’ asymptotic distribution, with one replication per point to fit the regression model. Following their guidance, we run
4n
replications of each solution with
\widehat{\boldsymbol{F}}
and
D=4\lceil n^{1.1}\rceil
.
The total simulations per solution is

9
Conclusion

We propose the NIOU-C framework to account for IU in the R&S problem under limited input data.
NIOU-C constructs a confidence set of solutions with an asymptotic guarantee that the optimum is contained in the set with the user-defined confidence level. We provide guidance on the simulation sample sizes to facilitate the asymptotic consistency and demonstrate that employing CRNs can significantly improve the finite-sample performance.
To mitigate the conservatism exhibited by NIOU-C in large-scale problems, we propose an alternative procedure, NIOU-C:E.
Empirical results suggest that both NIOU-C and NIOU-C:E correctly include the optimum in the confidence set with adequate simulation effort and show robust performance compared to methods that rely on parametric assumptions.

Several extensions remain open. First, considering performance measures other than simulation output means such as quantiles or conditional value-at-risk could offer a more comprehensive risk assessment introduced by IU. A key challenge in this direction is the development of consistent influence function estimators tailored to these alternative risk metrics.
Extending the nonparametric treatment to accommodate more complex input distributions, such as time-varying arrival processes, could be another research direction.
Lastly, the NIOU-C framework may be extended to the case with streaming input data, where the decision maker can leverage the confidence set to stop additional data collection and return the optimum.

Proof of

.
In the proof of Theorem 1.1 of
Chang and Hsu 1992
it is shown that, if
\widehat{\eta}_{i}
is a point estimator of
\eta_{i}(\boldsymbol{F}^{c})
for all
i\in[k]
, then
E_{1}\subseteq E_{2}
, where
E_{1}\triangleq\{\widehat{\eta}_{i^{c}}-\widehat{\eta}_{\ell}-(\eta_{i^{c}}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c}))\geq-q_{i\ell},\forall\ell\neq i\}
,
E_{2}\triangleq\{\eta_{i}(\boldsymbol{F}^{c})-\max\nolimits_{\ell\neq i}{\eta_{\ell}(\boldsymbol{F}^{c})}\in[D_{i}^{-},D_{i}^{+}],\forall i\in[k]\}
, and

D_{i}^{+}\triangleq\big(\min_{\ell\neq i}\{\widehat{\eta}_{i}-\widehat{\eta}_{\ell}+q_{i\ell}\}\big)^{+}
.
Moreover

I\triangleq\{i\in[k]:D_{i}^{+}>0\}
,

D_{i}^{-}=0
if
I=\{i\}
, and

D_{i}^{-}=-\big(\min_{\ell\in I:\ell\neq i}\{\widehat{\eta}_{i}-\widehat{\eta}_{\ell}-q_{\ell i}\}\big)^{-}
otherwise, where
\{q_{i\ell}\}_{i\neq\ell}
are fixed quantities.
We observe that
E_{1}=\{\eta_{i^{c}}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c})\leq\widehat{\eta}_{i^{c}}-\widehat{\eta}_{\ell}+q_{i\ell},\forall\ell\neq i\}
.
Below, we apply this result to our framework.

If we denote
U_{i\ell,n}=\widehat{\eta}_{i}-\widehat{\eta}_{\ell}+q_{i\ell}
, then
E_{1}^{n}\triangleq\{\eta_{i^{c}}(\boldsymbol{F}^{c})-\eta_{\ell}(\boldsymbol{F}^{c})\leq U_{i^{c}\ell,n},\forall\ell\neq i\}
and
E_{2}^{n}\triangleq\{\eta_{i}(\boldsymbol{F}^{c})-\max\nolimits_{\ell\neq i}{\eta_{\ell}(\boldsymbol{F}^{c})}\in[D_{i,n}^{-},D_{i,n}^{+}],\forall i\in[k]\}
. Therefore
E_{1}^{n}\subseteq E_{2}^{n}
. The lemma’s hypotheses ensure
1-\alpha\leq\liminf_{n\to\infty}\Pr\{E_{1}^{n}\}
. Hence
1-\alpha\leq\liminf_{n\to\infty}\Pr\{E_{2}^{n}\}
.
The event
E_{2}^{n}
implies that no solution satisfying

is optimal, yielding
i^{c}\in I_{n}
. Hence
\Pr\{E_{2}^{n}\}\leq\Pr\{i^{c}\in I_{n}\}
.
Taking limits, we obtain
1-\alpha\leq\liminf_{n\to\infty}\Pr\{i^{c}\in I_{n}\}
.

\square

Proofs for

We first establish properties of the optimization problem in (
5
). First,
-\log R(\boldsymbol{0})
is equal to the optimal value of

\min_{\begin{subarray}{c}\boldsymbol{w}_{p},\,\boldsymbol{\mu}_{p}\\
p\in[m]\end{subarray}}\;-\sum\nolimits_{p=1}^{m}\sum\nolimits_{j=1}^{n_{p}}\log(n_{p}w_{pj})\quad\text{s.t.}\quad\sum\nolimits_{j=1}^{n_{p}}\boldsymbol{Y}_{pj}w_{pj}=\boldsymbol{\mu}_{p},\;\sum\nolimits_{j=1}^{n_{p}}w_{pj}=1,\;p\in[m],\;\sum\nolimits_{p=1}^{m}\boldsymbol{\mu}_{p}=\boldsymbol{0}.

(21)

In (
21
), as opposed to (
5
), we introduce slack variables
\boldsymbol{\mu}_{p}\in\mathbb{R}^{q}
, and drop the nonnegativity constraints on
\boldsymbol{w}_{p}
because they are implicitly imposed in the objective function.

Let us introduce some notation.
Let
\{\boldsymbol{w}^{*}_{p}\}_{p\in[m]}
and
\{\boldsymbol{\mu}_{p}^{*}\}_{p\in[m]}
be minimizers of (
21
), and let
\boldsymbol{\lambda}^{*}
be the Lagrangian multiplier associated with the constraint
\sum\nolimits_{p=1}^{m}\boldsymbol{\mu}_{p}=\boldsymbol{0}
.
Let
\overline{\boldsymbol{Y}}_{p}\triangleq(1/n_{p})\sum\nolimits_{j=1}^{n_{p}}\boldsymbol{Y}_{pj}
be the sample mean of the observations of each input distribution
p\in[m]
. In addition, we define
v_{pj}\triangleq\big(\boldsymbol{\lambda}^{*}/n_{p}\big)^{\top}(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})
,
\mathbf{S}_{p}\triangleq(1/n_{p})\sum\nolimits_{j=1}^{n_{p}}(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})^{\top}
and
\boldsymbol{\nu}_{p}\triangleq(1/n_{p})\sum\nolimits_{j=1}^{n_{p}}\frac{(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})v_{pj}^{2}}{1+v_{pj}}
.
To compute
-\log R(\boldsymbol{0})
, we use the following proposition that characterizes minimizers of (
21
), along with the convergence rate of the Lagrangian multipliers.

Proposition 4

Each minimizer
\boldsymbol{w}^{*}\triangleq\{\boldsymbol{w}^{*}_{p}\}_{p\in[m]}
and
\boldsymbol{\mu}^{*}\triangleq\{\boldsymbol{\mu}_{p}^{*}\}_{p\in[m]}

of (
21
) satisfies
w_{pj}^{*}=(1/n_{p})\cdot 1/(1+v_{pj})
.
In addition,

\boldsymbol{\mu}_{p}^{*}\xrightarrow{P}\boldsymbol{0}
,
\|\boldsymbol{\lambda}^{*}\|/n=O_{p}(n^{-1/2})
,

\boldsymbol{\lambda}^{*}=\big(\sum\nolimits_{p=1}^{m}(\mathbf{S}_{p}/n_{p})\big)^{-1}\sum\nolimits_{p=1}^{m}(\overline{\boldsymbol{Y}}_{p}+\boldsymbol{\nu}_{p})
,
and
\boldsymbol{\nu}_{p}=o_{p}(n^{-1/2})

as
n\to\infty
.

Proof.
Let
\boldsymbol{w}^{*}\triangleq\{w^{*}_{pj}\}_{j\in[n_{p}],p\in[m]}
and
\boldsymbol{\mu}^{*}\triangleq\{\boldsymbol{\mu}_{p}^{*}\}_{p\in[m]}
be the minimizers of (
21
), and
\{\boldsymbol{\lambda}^{*}_{1p},\lambda_{2p}^{*}\}_{p\in[m]}
and
\boldsymbol{\lambda}^{*}
be the corresponding Lagrangian multipliers.
This proof consists of four steps. In Step 1, we obtain an expression for
\boldsymbol{w}^{*}
. In Step 2, we establish the convergence rate of the Lagrangian multiplier
\boldsymbol{\lambda}^{*}
, while in Step 3, we determine the convergence rate of
\boldsymbol{\mu}_{p}^{*}
to the true mean of each input distribution
p
. Lastly, in Step 4, we obtain an expression for
\boldsymbol{\lambda}^{*}
.

Step 1
: Since the problem in (
21
) has linear constraints and the objective function is convex, the Karush–Kuhn–Tucker (KKT) conditions are necessary and sufficient optimality conditions. The KKT conditions are given by:

-\frac{1}{w^{*}_{pj}}+(\boldsymbol{\lambda}^{*}_{1p})^{\top}\boldsymbol{Y}_{pj}+\lambda^{*}_{2p}=0,\,j\in[n_{p}];\,-\boldsymbol{\lambda}^{*}_{1p}+\boldsymbol{\lambda}^{*}=\boldsymbol{0},\,\sum\nolimits_{j=1}^{n_{p}}\boldsymbol{Y}_{pj}w^{*}_{pj}=\boldsymbol{\mu}^{*}_{p},\,\sum\nolimits_{j=1}^{n_{p}}w^{*}_{pj}=1,\,p\in[m];\sum\nolimits_{p=1}^{m}\boldsymbol{\mu}^{*}_{p}=\boldsymbol{0},

(22)

where
(\lambda^{*}_{1p},\lambda^{*}_{2p})
are the multipliers corresponding to the first two constraints of (
21
), and
\boldsymbol{\lambda}^{*}
is that of the last constraint.

The values for
\boldsymbol{w}^{*},\boldsymbol{\mu}^{*}
and
\boldsymbol{\lambda}^{*}
can be obtained by solving (
22
).
From the second equation in (
22
),
\boldsymbol{\lambda}^{*}_{1p}=\boldsymbol{\lambda}^{*}
and plugging this into the first KKT condition and
multiplying both sides by
w^{*}_{pj}
gives

\lambda_{2p}^{*}w^{*}_{pj}=1-(\boldsymbol{\lambda}^{*})^{\top}\boldsymbol{Y}_{pj}w^{*}_{pj},\quad p\in[m],j\in[n_{p}].

(23)

Summing (
23
) over all
j\in[n_{p}]
and using the fourth KKT equation, we obtain

\lambda_{2p}^{*}=n_{p}-(\boldsymbol{\lambda}^{*})^{\top}\boldsymbol{\mu}_{p}^{*}
,
p\in[m]
.
We plug
\boldsymbol{\lambda}^{*}_{1p}
and
\lambda_{2p}^{*}
into the first KKT condition
to obtain

w_{pj}^{*}=1/\big(n_{p}+(\boldsymbol{\lambda}^{*})^{\top}(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})\big)=(1/n_{p})\cdot 1/(1+v_{pj}).

Step 2:
We characterize the convergence rate of
\|\boldsymbol{\lambda}^{*}\|/n
as
n\to\infty
.
Let
\Theta
be the set of all unit vectors in
\mathbb{R}^{q}
.
Let
\boldsymbol{\lambda}^{*}=\|\boldsymbol{\lambda}^{*}\|\boldsymbol{\theta}
for some

\boldsymbol{\theta}\in\Theta
.
Note that we have
w_{pj}^{*}=(1/n_{p})\cdot 1/(1+v_{pj})
and
1/(1+v_{pj})=1-v_{pj}/(1+v_{pj})
.
Inserting
w_{pj}^{*}
into the third KKT condition and using the definition of
v_{pj}
, we get

\frac{1}{n_{p}}\sum\nolimits_{j=1}^{n_{p}}\frac{\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*}}{1+(\frac{\boldsymbol{\lambda}^{*}}{n_{p}})^{\top}(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})}=\boldsymbol{0}.

(24)

Rewriting (
24
) yields

\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*}=\frac{1}{n_{p}}\sum\nolimits_{j=1}^{n_{p}}\frac{(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})^{\top}}{1+v_{pj}}\bigg(\frac{\boldsymbol{\lambda}^{*}}{n_{p}}\bigg).

Taking the inner product with
\boldsymbol{\theta}
and defining
\widetilde{\mathbf{S}}_{p}\triangleq(1/n_{p})\sum\nolimits_{j=1}^{n_{p}}\frac{(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})^{\top}}{1+v_{pj}}

\boldsymbol{\theta}^{\top}(\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*})=\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\boldsymbol{\theta}^{\top}\widetilde{\mathbf{S}}_{p}\boldsymbol{\theta}.

(25)

Let
K^{*}\triangleq\max_{p\in[m],j\in[n_{p}]}\{\|\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*}\|\}

\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\boldsymbol{\theta}^{\top}\mathbf{S}_{p}\boldsymbol{\theta}\leq\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\boldsymbol{\theta}^{\top}\widetilde{\mathbf{S}}_{p}\boldsymbol{\theta}(1+\max_{j\in[n_{p}]}|v_{pj}|)\leq\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\boldsymbol{\theta}^{\top}\widetilde{\mathbf{S}}_{p}\boldsymbol{\theta}\bigg(1+\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}K^{*}\bigg)=\boldsymbol{\theta}^{\top}(\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*})\bigg(1+\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}K^{*}\bigg).

for sufficiently large

. From

, we also have

\frac{\|\boldsymbol{\lambda}^{*}\|}{\overline{c}n}\boldsymbol{\theta}^{\top}\mathbf{S}_{p}\boldsymbol{\theta}\leq\boldsymbol{\theta}^{\top}(\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*})\Big(1+\frac{\|\boldsymbol{\lambda}^{*}\|}{\underline{c}n}K^{*}\Big),

which can be rewritten as

\frac{\|\boldsymbol{\lambda}^{*}\|}{\overline{c}n}\bigg[\boldsymbol{\theta}^{\top}\mathbf{S}_{p}\boldsymbol{\theta}-\frac{\overline{c}}{\underline{c}}K^{*}\boldsymbol{\theta}^{\top}(\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*})\bigg]\leq\boldsymbol{\theta}^{\top}(\overline{\boldsymbol{Y}}_{p}-\boldsymbol{\mu}_{p}^{*}).

Summing over
p\in[m]
and using the last equation in (

\frac{\|\boldsymbol{\lambda}^{*}\|}{\overline{c}n}\Bigg[\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\mathbf{S}_{p}\bigg)\boldsymbol{\theta}-\frac{\overline{c}}{\underline{c}}K^{*}\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}\bigg)\Bigg]\leq\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}\bigg).

(26)

Observe that, for each
p\in[m]

\boldsymbol{\theta}^{\top}\mathbf{S}_{p}\boldsymbol{\theta}=\boldsymbol{\theta}^{\top}\big(\widehat{\mathbf{V}}_{p}-2\boldsymbol{\mu}_{p}^{*}(\overline{\boldsymbol{Y}}_{p})^{\top}+\boldsymbol{\mu}_{p}^{*}{\boldsymbol{\mu}_{p}^{*}}^{\top}\big)\boldsymbol{\theta}\geq\boldsymbol{\theta}^{\top}\big(\widehat{\mathbf{V}}_{p}-2\boldsymbol{\mu}_{p}^{*}(\overline{\boldsymbol{Y}}_{p})^{\top}\big)\boldsymbol{\theta}

Therefore,

\frac{\|\boldsymbol{\lambda}^{*}\|}{\overline{c}n}\Bigg[\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\widehat{\mathbf{V}}_{p}\bigg)\boldsymbol{\theta}-2\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\boldsymbol{\mu}_{p}^{*}(\overline{\boldsymbol{Y}}_{p})^{\top}\bigg)\boldsymbol{\theta}-\frac{\overline{c}}{\underline{c}}K^{*}\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}\bigg)\Bigg]\leq\boldsymbol{\theta}^{\top}\bigg(\sum\nolimits_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}\bigg).

\mathrm{E}[\boldsymbol{Y}_{p}]=\boldsymbol{0}

\widehat{\mathbf{V}}_{p}\xrightarrow{\text{a.s.}}\mathbf{V}_{p}
. Also, since

.

\frac{\|\boldsymbol{\lambda}^{*}\|}{\overline{c}n}\bigg(\boldsymbol{\theta}^{\top}\Big(\sum\nolimits_{p=1}^{m}\widehat{\mathbf{V}}_{p}\Big)\boldsymbol{\theta}-o(n^{1/2})O_{p}(n^{-1/2})-o(n^{1/2})O_{p}(n^{-1/2})\bigg)=O_{p}(n^{-1/2}),

Step 3:
We show that
\boldsymbol{\mu}_{p}^{*}\xrightarrow{P}\boldsymbol{0}
as

(27)

Then, the right-most term in (

\displaystyle\|\boldsymbol{\nu}_{p}\|

\displaystyle\leq\frac{1}{n_{p}}\sum\nolimits_{j=1}^{n_{p}}v_{pj}^{2}\bigg\|\frac{(\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*})}{1+v_{pj}}\bigg\|\leq\bigg(\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\bigg)^{2}\frac{1}{n_{p}}\sum\nolimits_{j=1}^{n_{p}}\|\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*}\|^{3}\bigg|\frac{1}{1+v_{pj}}\bigg|

\displaystyle\leq\bigg(\frac{\|\boldsymbol{\lambda}^{*}\|}{n_{p}}\bigg)^{2}\frac{1}{\min_{j\in[n_{p}]}1+v_{pj}}\cdot\frac{1}{n_{p}}\sum\nolimits_{j=1}^{n_{p}}\|\boldsymbol{Y}_{pj}-\boldsymbol{\mu}_{p}^{*}\|^{3}=O_{p}(n^{-1})\frac{1}{1+o_{p}(1)}o(n^{1/2})=o_{p}(n^{-1/2}).

Summing over
p\in[m]
and rearranging terms,

\boldsymbol{\lambda}^{*}=\bigg(\sum\nolimits_{p=1}^{m}\frac{\mathbf{S}_{p}}{n_{p}}\bigg)^{-1}\sum\nolimits_{p=1}^{m}\big(\overline{\boldsymbol{Y}}_{p}+\boldsymbol{\nu}_{p}\big).\hfill

\square

We have

From

By the mean value theorem and a second-order Taylor’s expansion, for each

\phi_{pj}\triangleq\frac{v_{pj}^{3}}{3(1+\xi_{pj}v_{pj})^{3}}
for some
\xi_{pj}\in(0,1)
. Then, using the definition of
v_{pj}
and
\boldsymbol{\lambda}^{*}

\displaystyle-2\log{R(\boldsymbol{0})}

\displaystyle=2(\boldsymbol{\lambda}^{*})^{\top}\bigg(\sum_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}\bigg)-(\boldsymbol{\lambda}^{*})^{\top}\bigg(\sum_{p=1}^{m}\frac{\mathbf{S}_{p}}{n_{p}}\bigg)\boldsymbol{\lambda}^{*}+2\sum_{p=1}^{m}\sum_{j=1}^{n_{p}}\phi_{pj}

(28)

random variable in distribution, and the remaining terms are

which presents a multivariate triangular array version of the Lindeberg–Feller CLT. Let

,
\overline{\mathbf{V}}_{n}\triangleq\sum\nolimits_{p=1}^{m}(1/n_{p})\mathbf{V}_{p}

\boldsymbol{z}_{N}=\sum\nolimits_{i=1}^{N}\boldsymbol{x}_{Ni}=(\overline{\mathbf{V}}_{n})^{-1/2}\sum\nolimits_{p=1}^{m}\overline{\boldsymbol{Y}}_{p}

2

and for all sufficiently large

using the fact that
N=n\cdot m
and
\underline{c}N/m\leq n_{p}
for all sufficiently large
n
, we verify the conditions: For each
\epsilon>0

\displaystyle\sum\nolimits_{i=1}^{N}\mathrm{E}\Big[\|\boldsymbol{x}_{Ni}\|^{2}\delta\{\|\boldsymbol{x}_{Ni}\|\geq\epsilon\}\Big]

\displaystyle=\sum\nolimits_{p=1}^{m}\sum\nolimits_{j=1}^{n_{p}}\mathrm{E}\Bigg[\bigg\|\frac{(\overline{\mathbf{V}}_{n})^{-1/2}\boldsymbol{Y}_{pj}}{n_{p}}\bigg\|^{2}\mathbf{1}\Big\{\big\|(\overline{\mathbf{V}}_{n})^{-1/2}\boldsymbol{Y}_{pj}\big\|\geq\epsilon n_{p}\Big\}\Bigg]

\displaystyle\leq\sum\nolimits_{p=1}^{m}C_{1}\mathrm{E}\Big[\|\boldsymbol{Y}_{p1}\|^{2}\mathbf{1}\big\{\|\boldsymbol{Y}_{p1}\|\geq\epsilon C_{2}N^{1/2}\big\}\Big]\to 0.

Here,

The second inequality results from

as

,

.

Lemma 7
