On Minimax Optimal Dual Control for Fully Actuated Systems
Anders Rantzer

Abstract
A multi-variable adaptive controller is derived as the explicit solution to a minimax dynamic game. The minimizing player selects the control action as a function of past state measurements and inputs. The maximizing player selects disturbances and model parameters for the underlying linear time-invariant dynamics. This leads to a Bellman equation that can be solved explicitly for the case with unitary B-matrix known up to a sign and no input penalty. The minimizing policy is a dual controller that optimizes the tradeoff between exploration and exploitation.

Problem:

Given a number
\alpha>0
and state dimension

, determine

\displaystyle J^{*}(x_{0})

\displaystyle:=\inf_{\mu}\underbrace{\sup_{A,B}\sup_{w}\mathbb{E}\sum_{t=0}^{\infty}\left(|x_{t}|^{2}-\gamma^{2}|w_{t}|^{2}\right)}_{J_{\mu}(x_{0})}

(1)

AA^{\top}=\alpha^{2}I
,

, the state

\displaystyle x_{t+1}

\displaystyle=Ax_{t}+Bu_{t}+w_{t}

(2)

\displaystyle u_{t}

\displaystyle=\mu_{t}(x_{0},\ldots,x_{t},u_{0},\ldots,u_{t-1}).

(3)

The main contribution of this paper is to formulate an exact solution to the Bellman equation that proves and generalizes a conjecture stated by Vinnicombe for scalar systems in
[

]

Given

VI
Optimal Exploration/Exploitation

Theorem 4

Consider
x\in\mathbb{R}^{n}
,
g\in\mathbb{R}_{+}
and
Y\in\mathbb{R}^{n\times(3n)}
. Let
y(A,i):=\left\langle Y,\begin{bmatrix}A&iI&iA\end{bmatrix}\right\rangle
. Then

\displaystyle\min_{u}\max_{A,i}\max\Big\{\mathbb{E}|Ax+iu|^{2}+y(A,i),(g+2)|Ax|^{2}-g\,\mathbb{E}|u|^{2}\Big\}

\displaystyle=\max_{A,i}\max\left\{y(A,i),2|\alpha x|^{2}\right\}

(13)

where minimization is over random vectors
u\in\mathbb{R}^{n}
and maximization is over
A\in\mathbb{R}^{n\times n}
with
A^{\top}A=\alpha^{2}I
and
i=\pm 1
. Let
(\hat{A},\hat{i}):=\argmax y(A,i)
.
Then a minimizing argument
\bar{u}
of (
13
) is given by

\displaystyle\begin{cases}\bar{u}=-\hat{i}\hat{A}x&\text{if }y(\hat{A},\hat{i})\geq 2|\alpha x|^{2}\\
\mathbb{E}\bar{u}=\frac{-y(\hat{A},\hat{i})}{2|\alpha x|^{2}}\hat{A}x,\;\mathbb{E}|\bar{u}|^{2}=|\alpha x|^{2}&\text{otherwise.}\end{cases}

Remark 1.

The term
y(\hat{A},\hat{i})
represents infomation about the uncertain parameters
A
and
i
based on previous data. If
y(\hat{A},\hat{i})\geq 2|\alpha x|^{2}
, the minimizing argument is regarded as the true value and the ”certainty equivalence” controller
\bar{u}=-\hat{i}\hat{A}x
is used. If not, a randomized component is added to learn the parameters by ”exploration”.

Proof.

Define

f(x,Y)
as the value of the left hand side in (
13
) and notice that

\displaystyle\max_{i}\left(\mathbb{E}|Ax+iu|^{2}+y(A,i)\right)

\displaystyle\geq|Ax|^{2}+\mathbb{E}|u|^{2}=|\alpha x|^{2}+\mathbb{E}|u|^{2}

\displaystyle f(x,Y)

\displaystyle\geq\min_{u}\max_{A}\max\left\{|\alpha x|^{2}+\mathbb{E}|u|^{2},(g+2)|Ax|^{2}-g\,\mathbb{E}|u|^{2}\right\}

\displaystyle=\min_{u}\max\left\{|\alpha x|^{2}+\mathbb{E}|u|^{2},(g+2)|\alpha x|^{2}-g\,\mathbb{E}|u|^{2}\right\}

\displaystyle=2|\alpha x|^{2},

where the minimum is attained for
\mathbb{E}|u|^{2}=|\alpha x|^{2}
.
Moreover,

\displaystyle f(x,Y)

\displaystyle\geq\max_{A,i}\left(\mathbb{E}|Ax+iu|^{2}+y(A,i)\right)\geq\max_{A,i}y(A,i).

Combining the two lower bounds gives

\displaystyle f(x,y)

\displaystyle\geq\max_{A,i}\max\left\{y(A,i),2|\alpha x|^{2}\right\}.

For the opposite inequality, two cases need to be considered:

Case 1:
y(\hat{A},\hat{i})\geq 2|\alpha x|^{2}

Let
\bar{u}:=-\hat{i}\hat{A}x
. Then

\displaystyle\max\left\{|Ax+i\bar{u}|^{2}+y(A,i),(g+2)|Ax|^{2}-g|\bar{u}|^{2}\right\}

\displaystyle=\max\left\{|Ax|^{2}+|\bar{u}|^{2}+2i\bar{u}^{\top}Ax+y(A,i),2|\alpha x|^{2}\right\}

\displaystyle=\max\left\{2|\alpha x|^{2}+2i\bar{u}^{\top}Ax+y(A,i),2|\alpha x|^{2}\right\}

\displaystyle\leq\max\left\{2|\alpha x|^{2}+2\hat{i}\bar{u}^{\top}\hat{A}x+y(\hat{A},\hat{i}),2|\alpha x|^{2}\right\}

(14)

\displaystyle=\max\left\{y(\hat{A},\hat{i}),2|\alpha x|^{2}\right\}

\displaystyle=\max_{A,i}\max\left\{y(A,i),2|\alpha x|^{2}\right\}.

Case 2:
0\leq y(\hat{A},\hat{i})\leq 2|\alpha x|^{2}

Let
\bar{u}
be random with
\mathbb{E}\bar{u}=\frac{y(\hat{A},\hat{i})}{2|\alpha x|^{2}}\hat{A}x
,
\mathbb{E}|\bar{u}|^{2}=|\alpha x|^{2}
. Then

\displaystyle\max\left\{\mathbb{E}|Ax+i\bar{u}|^{2}+y(A,i),(g+2)|Ax|^{2}-g\,\mathbb{E}|\bar{u}|^{2}\right\}

\displaystyle=\max\left\{|Ax|^{2}+|\bar{u}|^{2}+2i\bar{u}^{\top}Ax+y(A,i),2|\alpha x|^{2}\right\}

\displaystyle=\max\left\{2|\alpha x|^{2}+2i\bar{u}^{\top}Ax+y(A,i),2|\alpha x|^{2}\right\}

\displaystyle\leq\max\left\{2|\alpha x|^{2},2|\alpha x|^{2}\right\}

(15)

\displaystyle=2|\alpha x|^{2}.

Hence, in both cases

\displaystyle f(x,y)

\displaystyle\leq\max_{A,i}\max\left\{y(A,i),2|\alpha x|^{2}\right\},

so the proof is complete (except that the inequalities (
14
) and (
15
) deserve further elaboration in future versions.)

\Box

VII
Value Iteration

Let
V(x,Z)
be a real-valued function of the state
(x,Z)
. Define the operators
{\mathcal{F}}
and
{\mathcal{F}}_{u}
according to

\displaystyle{\mathcal{F}}V(x,Z)

\displaystyle:=\min_{u}\underbrace{\max_{v}\left\{|x|^{2}+V\left(v,Z+\mathbb{E}{\small\begin{bmatrix}-v\\
x\\
u\end{bmatrix}\begin{bmatrix}-v\\
x\\
u\end{bmatrix}^{\top}}\right)\right\}}_{\mathcal{F}_{u}V(x,Z)}.

(with value
+\infty
if the supremum is unbounded for all
u
) and define the sequence
V^{(0)},V^{(1)},V^{(2)}\ldots
according to

\displaystyle V^{(0)}(x,Z)

\displaystyle:=-\gamma^{2}\min_{A,B}\big\|\begin{bmatrix}I\;\;A\;\;\,B\end{bmatrix}^{\top}\big\|^{2}_{Z}

\displaystyle V^{(N+1)}(x,Z)

\displaystyle:={\mathcal{F}}V^{(N)}(x,Z).

Standard dynamic programming arguments (Proposition
7
in the Appendix) gives

V^{(0)}\leq V^{(1)}\leq\ldots\leq\lim_{N\to\infty}V^{(N)}=V_{*}.

This will now be used to derive the formula for
V_{*}
.

VIII
Lower Bound on th Optimal Cost

Define the sequence
t_{0}\leq t_{1}\leq t_{2}\ldots
by

\displaystyle t_{N+1}

\displaystyle:=1+\frac{\gamma^{2}\alpha^{2}}{\gamma^{2}-t_{N}},\qquad\;\;t_{0}:=0.

(16)

and let

\displaystyle V^{0,N}_{A,B}(x,Z)

\displaystyle:=t_{N}|x|^{2}-\frac{\gamma^{2}}{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iI\end{bmatrix}^{\top}\right\|^{2}_{Z}.

The limit is finite if and only if
(\gamma^{2}-t_{*})(t_{*}-1)=\gamma^{2}\alpha^{2}
has a real valued solution
t_{*}
. In other words

\displaystyle 4\gamma^{2}\alpha^{2}

\displaystyle=(\gamma^{2}-1)^{2}-(\gamma^{2}+1-2t_{*})^{2}

\displaystyle 4\gamma^{2}\alpha^{2}

\displaystyle\leq(\gamma^{2}-1)^{2}

\displaystyle 2\gamma\alpha

\displaystyle\leq\gamma^{2}-1

\displaystyle\alpha^{2}+1

\displaystyle\leq(\gamma-\alpha)^{2},

which happens if and only if
\gamma\geq\gamma_{*}
.

Theorem 5
(Lower bound)

\displaystyle V^{(N)}

\displaystyle\geq\max_{A,B}\max\left\{V_{A,B}^{0,N},V_{A,B}^{1}\right\}

(17)

for all
N
.
In particular, the value of (
1
) is infinite if
\gamma<\gamma_{*}
.

Remark 2.

Vinnicombe
[
Vin04
]
proved for the case
n=1
that the value of (
1
) is finite if

\gamma\geq\alpha+\sqrt{1+\alpha^{2}}
. He also conjectured that the reverse implication holds. Theorem
5
shows that this conjecture was correct.

Proof.

First note that

\displaystyle V^{(1)}

\displaystyle={\mathcal{F}}V^{(0)}=\max_{A,B}V_{A,B}^{1}=\max_{A,B}\max\left\{V_{A,B}^{0,N},V_{A,B}^{1}\right\},

so the inequality (
17
) holds for
N=1
. It will now be proved for all
N
by induction.
Assume that the inequality holds for some
N\geq 1
. To prove that it holds also for
N+1
, notice that for arbitrary (random)
u\in\mathbb{R}^{n}
we have

\displaystyle\mathcal{F}_{u}V^{(N)}(x,Z)

\displaystyle\geq\mathcal{F}_{u}\max_{A,B}\max\left\{V_{A,B}^{0,N}(x,Z),V_{A,B}^{1}(x,Z)\right\}

\displaystyle=\max\left\{\max_{A,B}\mathcal{F}_{u}V_{A,B}^{0,N}(x,Z),\max_{A,B}\mathcal{F}_{u}V_{A,B}^{1}(x,Z)\right\}

\displaystyle\mathcal{F}_{u}V_{A,B}^{0,N}(x,Z)-|x|^{2}+\gamma^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z}/2

\displaystyle=\max_{v}\left\{t_{N}|v|^{2}-\gamma^{2}\sum_{i=\pm 1}\mathbb{E}|Ax+iBu-v|^{2}/2\right\}

\displaystyle=\max_{v}\left\{t_{N}|v|^{2}-\gamma^{2}\left(|Ax-v|^{2}+\mathbb{E}|Bu|^{2}\right)\right\}

\displaystyle=(t_{N}^{-1}-\gamma^{-2})^{-1}|Ax|^{2}-\gamma^{2}\mathbb{E}|u|^{2}

\displaystyle\max_{B}\mathcal{F}_{u}V_{A,B}^{1}(x,Z)-|x|^{2}+\gamma^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z}/2

\displaystyle\geq\frac{1}{2}\sum_{i=\pm 1}\left(\mathcal{F}_{u}V_{A,iB}^{1}(x,Z)-|x|^{2}+\gamma^{2}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z}\right)

\displaystyle=\frac{1}{2}\sum_{i=\pm 1}\max_{v}\left(|v|^{2}-\gamma^{2}\mathbb{E}|Ax+iBu-v|^{2}\right)\quad

\displaystyle=\frac{1}{2}\sum_{i=\pm 1}\frac{\mathbb{E}|Ax+iBu|^{2}}{1-\gamma^{-2}}

\displaystyle=(1-\gamma^{-2})^{-1}\left(|Ax|^{2}+\mathbb{E}|u|^{2}\right).

Hence

\displaystyle\min_{u}\mathcal{F}_{u}V^{(N)}(x,Z)-|x|^{2}+\gamma^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z}/2

\displaystyle\geq\min_{u}\max\left\{\frac{|Ax|^{2}}{t_{N}^{-1}-\gamma^{-2}}-\gamma^{2}\mathbb{E}|u|^{2},\frac{|Ax|^{2}+\mathbb{E}|u|^{2}}{1-\gamma^{-2}}\right\}

\displaystyle=\frac{\gamma^{2}|Ax|^{2}}{\gamma^{2}-t_{N}}=(t_{N+1}-1)|x|^{2}

\displaystyle=V_{A,B}^{0,N+1}(x,Z)-|x|^{2}+\gamma^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z}/2,

so
V^{(N+1)}=\min_{u}\mathcal{F}_{u}V^{(N)}\geq V_{A,B}^{0,N+1}
and the induction argument is complete.
For the final statement, we note that
t_{N}\to\infty
when
\gamma\leq\gamma_{*}
. Hence
\lim_{N\to\infty}V^{(N)}
is unbounded and the same is true for the optimal cost
V^{*}
.

\Box

IX
Upper Bound on th Optimal Cost

Theorem 6
(Upper bound)

If
\gamma\geq\gamma_{*}
, then

\displaystyle V^{(N)}

\displaystyle\leq\max_{A,B}\max\left\{V_{A,B}^{0},V_{A,B}^{1}\right\}

for all
N
.
When
N\to\infty
, combination with Theorem
5
gives

\displaystyle V_{*}

\displaystyle=\max_{A,B}\max\left\{V_{A,B}^{0},V_{A,B}^{1}\right\}.

Proof.
We prove the expression for
V^{(N+1)}(x,Z)
by induction over
N
. It holds by definition for
N=0
. Assume that it holds for some
N\geq 0
.
Straightforward calculations give

\displaystyle\mathcal{F}_{u}V_{A,B}^{1}(x,Z)-|x|^{2}+\gamma_{*}^{2}\left\|\begin{bmatrix}I\;\;A\;\;\,B\end{bmatrix}^{\top}\right\|^{2}_{Z}

\displaystyle=\max_{v}\left\{|v|^{2}-\gamma_{*}^{2}\,\mathbb{E}|Ax+Bu-v|^{2}\right\}

\displaystyle=\frac{\mathbb{E}|Ax+Bu|^{2}}{1-\gamma_{*}^{-2}}

\displaystyle\mathcal{F}_{u}V_{A,B}^{0,N}(x,Z)-|x|^{2}+\gamma_{*}^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z/2}

\displaystyle=\max_{v}\bigg\{t_{N}|v|^{2}-\gamma_{*}^{2}\sum_{i=\pm 1}\mathbb{E}|Ax+iBu-v|^{2}/2\bigg\}

\displaystyle=\max_{v}\bigg\{t_{N}|v|^{2}-\gamma_{*}^{2}|Ax-v|^{2}-\gamma_{*}^{2}\mathbb{E}|u|^{2}\bigg\}

\displaystyle=\frac{|Ax|^{2}}{t_{N}^{-1}-\gamma_{*}^{-2}}-\gamma_{*}^{2}\mathbb{E}|u|^{2}

\displaystyle V^{(N+1)}(x,Z)-|x|^{2}

\displaystyle=\mathcal{F}V^{(N)}(x,Z)-|x|^{2}

\displaystyle\leq\min_{u}\max_{A,B}\max\left\{\mathcal{F}_{u}V_{A,B}^{1}(x,Z),\mathcal{F}_{u}V_{A,B}^{0}(x,Z)\right\}-|x|^{2}

\displaystyle=\min_{u}\max_{A,B}\max\bigg\{\frac{|Ax+Bu|^{2}}{1-\gamma^{-2}}-\gamma^{2}\left\|\begin{bmatrix}I\;\;A\;\;\,B\end{bmatrix}^{\top}\right\|^{2}_{Z},

\displaystyle\qquad\frac{|Ax|^{2}}{t_{*}^{-1}-\gamma^{-2}}-\gamma^{2}|u|^{2}-\gamma^{2}\sum_{i=\pm 1}\left\|\begin{bmatrix}I\;\;A\;\;\,iB\end{bmatrix}^{\top}\right\|^{2}_{Z/2}\bigg\}

\displaystyle=\max_{A,B}\max\left\{V_{A,B}^{1}(x,Z),V_{A,B}^{0}(x,Z)\right\}-|x|^{2}

Here the critical last equality is given by Theorem
4
. This completes the induction proof.

\Box

The curve illustrates that the matrix convergence slows down after synchronization, since less data is then obtained. It should be noted that synchronization occurs after almost exactly
n
time steps, when enough data has been collected to estimate all matrix directions.

XI
Conclusions

An exact solution to the Bellman has been derived for an adaptive optimal control problem, leading to optimal tradeoff between exploration and exploitation in a dynamic setting. The problem formulation is general enough to cover state equations of arbitrary order, but several restrictions have been made. These include full state measurements, absence of control penalty and unitary
B
-matrix known except for the sign. However, the basic ideas are general, so we expect that the restrictions can be relaxed significantly in the future.
