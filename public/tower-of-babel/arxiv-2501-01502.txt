Block components of generalized quaternion group codes
Nadja Willenborg

Abstract
Codes in the generalized quaternion group algebra 𝔽 q ​ [ Q 4 ​ n ] \mathbb{F}_{q}[Q_{4n}] are considered. Restricting to char ​ 𝔽 q ∤ 4 ​ n \textnormal{char}\mathbb{F}_{q}\nmid 4n the structure of an arbitrary code C ⊆ 𝔽 q ​ [ Q 4 ​ n ] C\subseteq\mathbb{F}_{q}[Q_{4n}] is described via the Wedderburn decomposition. Moreover it is known that in this case every code C ⊆ 𝔽 q ​ [ Q 4 ​ n ] C\subseteq\mathbb{F}_{q}[Q_{4n}] has a generating idempotent λ ∈ 𝔽 q ​ [ Q 4 ​ n ] \lambda\in\mathbb{F}_{q}[Q_{4n}] . Given the generating idempotent of a code C C we determine the different components in its decomposition C ≅ ⨁ j = 1 r + s C j ⊕ ⨁ i = 1 k + t C i ′ . C\cong\bigoplus_{j=1}^{r+s}C_{j}\oplus\bigoplus_{i=1}^{k+t}C^{\prime}_{i}. Afterwards we apply this result to describe the blocks of codes induced by cyclic group codes.

Main result

Theorem 2.1
.

Let
\gcd(4n,q)=1
and consider an arbitrary code
C\subseteq\mathbb{F}_{q}[Q_{4n}]
generated by its idempotent
\lambda\in\mathbb{F}_{q}[Q_{4n}]
. Suppose that

\displaystyle\phi_{j}

\displaystyle=\lambda e_{f_{j}}(x),\,1\leq j\leq r+s,\quad

\displaystyle\tilde{\phi}_{j}=\lambda e_{f_{j}^{*}}(x),\,r+1\leq j\leq r+s,

\displaystyle\psi_{i}

\displaystyle=\lambda e_{g_{i}}(x),\,1\leq i\leq k+t,\quad

\displaystyle\tilde{\psi}_{i}=\lambda e_{g_{i}^{*}}(x),\,t+1\leq i\leq k+t,

and let
\rho(C)=\displaystyle\bigoplus_{j=1}^{r+s}C_{i}\oplus\bigoplus_{i=1}^{k+t}C_{i}^{{}^{\prime}}
be the code decomposition. Then the code blocks
(C_{j})_{1\leq j\leq r+s},(C_{i}^{\prime})_{1\leq i\leq t+k}
are determined by the elements
\phi_{j},\tilde{\phi}_{j},\psi_{i},\tilde{\psi}_{i},1\leq j\leq r+s,1\leq i\leq t+k
as follows:

(i)

For
1\leq j\leq\delta(n)

C_{j}=\begin{cases}I_{j}(1,0)\quad&\textnormal{if $\phi_{j}=\tfrac{1+y}{2}e_{f_{j}}(x)$,}\\
I_{j}(0,1)\quad&\textnormal{if $\phi_{j}=\tfrac{1-y}{2}e_{f_{j}}(x)$,}\\
0\quad&\textnormal{if $\phi_{j}=0$,}\\
A_{j}\quad&\textnormal{if $\phi_{j}=e_{f_{j}}(x)$.}\end{cases}

(ii)

For
\delta(n)+1\leq j\leq r

C_{j}=\begin{cases}0\quad&\textnormal{if $\phi_{j}=0$,}\\
A_{j}\quad&\textnormal{if $\phi_{j}=e_{f_{j}}(x)$.}\end{cases}

(iii)

For
r+1\leq j\leq r+s
and
u_{j},\tilde{u_{j}},v_{j},\tilde{v_{j}}\in\mathbb{F}_{q}[x]
such that

\phi_{j}=u_{j}(x)+yv_{j}(x),\quad\tilde{\phi_{j}}=\tilde{u_{j}}(x)+y\tilde{v_{j}}(x),

we have

\displaystyle C_{j}=\begin{cases}I_{j}(\tilde{v_{j}}(\alpha_{j}^{-1}),-u_{j}(\alpha_{j}))\quad&\textnormal{if $(\tilde{v_{j}}(\alpha_{j}^{-1}),u_{j}(\alpha_{j}))\neq(0,0)$,}\\
I_{j}(\tilde{u_{j}}(\alpha_{j}^{-1}),-v_{j}(\alpha_{j}))\quad&\textnormal{if $\tilde{v_{j}}(\alpha_{j}^{-1})=u_{j}(\alpha_{j})=0\wedge(\tilde{u_{j}}(\alpha_{j}^{-1}),v_{j}(\alpha_{j}))\neq(0,0)$,}\\
0\quad&\textnormal{if $\tilde{u_{j}}(\alpha_{j}^{-1})=v_{j}(\alpha_{j})=\tilde{v_{j}}(\alpha_{j}^{-1})=u_{j}(\alpha_{j})=0$,}\\
A_{j}\quad&\textnormal{if $\tilde{v_{j}}=v_{j}=0\wedge u_{j}(x)=e_{f_{j}}(x)\wedge\tilde{u_{j}}(x)=e_{f_{j}}(x)$.}\end{cases}

(iv)

For
1\leq i\leq\mu(n)
and
q\equiv 1\pmod{4}

\displaystyle C^{\prime}_{i}=\begin{cases}J_{i}(1,0)\quad&\textnormal{if $\psi_{i}=-\left(\tfrac{e_{g_{i}}(x)-\sqrt{-1}y}{2}\right)$,}\\
J_{i}(0,1)\quad&\textnormal{if $\psi_{i}=-\left(\tfrac{e_{g_{i}}(x)+\sqrt{-1}y}{2}\right)$,}\\
0\quad&\textnormal{if $\psi_{i}=0$,}\\
B_{i}\quad&\textnormal{if $\psi_{i}=-e_{g_{i}}(x)$.}\end{cases}

For
1\leq i\leq\mu(n)
and
q\equiv 3\pmod{4}

\displaystyle C^{\prime}_{i}=\begin{cases}0\quad&\textnormal{if $\psi_{i}=0$,}\\
B_{i}\quad&\textnormal{if $\psi_{i}=-e_{g_{i}}(x)$.}\end{cases}

(v)

For
\mu(n)+1\leq i\leq t

C^{\prime}_{i}=\begin{cases}0\quad&\textnormal{if $\psi_{i}=0$,}\\
B_{i}\quad&\textnormal{if $\psi_{i}=-e_{g_{i}}(x)$.}\end{cases}

(vi)

For
t+1\leq i\leq t+k
and
u_{i},\tilde{u_{i}},v_{i},\tilde{v_{i}}\in\mathbb{F}_{q}[x]
such that

\psi_{i}=u_{i}(x)+yv_{i}(x),\quad\tilde{\psi_{i}}=\tilde{u_{i}}(x)+y\tilde{v_{i}}(x),

we have

\displaystyle C^{\prime}_{i}=\begin{cases}J_{i}(\tilde{v_{i}}(\beta_{i}^{-1}),-u_{i}(\beta_{i}))\quad&\textnormal{if $(\tilde{v_{i}}(\beta_{i}^{-1}),u_{i}(\beta_{i}))\neq(0,0)$,}\\
J_{i}(\tilde{u_{i}}(\beta_{i}^{-1}),-v_{i}(\beta_{i}))\quad&\textnormal{if $\tilde{v_{i}}(\beta_{i}^{-1})=u_{i}(\beta_{i})=0\wedge(\tilde{u_{i}}(\beta_{i}^{-1}),v_{i}(\beta_{i}))\neq(0,0)$,}\\
0\quad&\textnormal{if $\tilde{u_{i}}(\beta_{i}^{-1})=v_{i}(\beta_{i})=\tilde{v_{i}}(\beta_{i}^{-1})=u_{i}(\beta_{i})=0$,}\\
B_{i}\quad&\textnormal{if $\tilde{v_{i}}=v_{i}=0\wedge u_{i}(x)=e_{g_{i}}(x)\wedge\tilde{u_{i}}(x)=e_{g_{i}}(x)$.}\end{cases}

Proof.

Let
\delta_{ij}
be the Kronecker delta, i.e.,
\delta_{ij}=1
if
i=j
and
\delta_{ij}=0
if
i\neq j.

Using the central irreducible idempotents obtained in
[
5
]
, Theorem 3.2 and Theorem 3.8, together with (
1.3
) and (
1.4
) we have

\sum_{j=1}^{r}e_{f_{j}}+\sum_{j=r+1}^{r+s}(e_{f_{j}}+e_{f_{j}^{*}})-\sum_{i=1}^{t}e_{g_{i}}-\sum_{i=t+1}^{t+k}(e_{g_{i}}+e_{g_{i}^{*}})=1.

Let

\rho(\lambda)=\displaystyle\bigoplus_{j=1}^{r+s}\lambda_{j}\oplus\bigoplus_{i=1}^{t+k}\lambda^{\prime}_{i},\quad\lambda_{j}\in A_{j},\lambda^{\prime}_{i}\in B_{i},

giving for
1\leq j\leq r

\rho(\phi_{j})=\displaystyle\bigoplus_{i=1}^{r+s}\lambda_{j}\delta_{ij}

and for
r+1\leq j\leq r+s

\rho(\phi_{j}+\tilde{\phi_{j}})=\displaystyle\bigoplus_{i=1}^{r+s}\lambda_{j}\delta_{ij}.

Similarly for
1\leq i\leq t

\rho(\psi_{i})=\displaystyle\bigoplus_{j=1}^{t+k}\lambda^{\prime}_{i}\delta_{ij}

and for
t+1\leq i\leq t+k

\rho(\psi_{i}+\tilde{\psi_{i}})=\displaystyle\bigoplus_{j=1}^{t+k}\lambda^{\prime}_{i}\delta_{ij}.

Thus the elements
(\lambda_{j})_{1\leq j\leq r+s},(\lambda^{\prime}_{i})_{1\leq i\leq t+k}
can be calculated from
\phi_{j},\tilde{\phi_{j}},\psi_{i},\tilde{\psi_{i}}.
It follows from

\rho(C)=\rho(\mathbb{F}_{q}[Q_{4n}]\lambda)=\displaystyle\bigoplus_{j=1}^{r+s}A_{j}\lambda_{j}\oplus\bigoplus_{i=1}^{t+k}B_{i}\lambda^{\prime}_{i}

that
C_{j}=A_{j}\lambda_{j}
, respectively
C^{\prime}_{i}=B_{i}\lambda^{\prime}_{i}.

Cases
(i),(ii),(iv)
and
(v)
can easily be deduced from

\rho(\phi_{j})=\bigoplus_{j=1}^{r+s}\lambda_{j}\delta_{ij},\quad\rho(\psi_{i})=\bigoplus_{i=1}^{t+k}\lambda^{\prime}_{i}\delta_{ij},

and Theorem 3.2, Theorem 3.8 from
[

]
where the central irreducible idempotents covering the possible values of

which works similar as case
(iii)
If

\psi_{i}=u_{i}(x)+yv_{i}(x),\quad\tilde{\psi_{i}}=\tilde{u_{i}}(x)+y\tilde{v_{i}}(x),

then

\lambda^{\prime}_{i}\begin{pmatrix}1&0\\
0&0\end{pmatrix}=\begin{pmatrix}u_{i}(\beta_{i})&0\\
v_{i}(\beta_{i})&0\end{pmatrix},\quad\lambda^{\prime}_{i}\begin{pmatrix}0&0\\

\lambda^{\prime}_{i}=\begin{pmatrix}u_{i}(\beta_{i})&\tilde{v_{i}}(\beta_{i}^{-1})\\

Obviously, if
\psi_{i}=\tilde{\psi_{i}}=0,
then

\end{cases}

) one can define the idempotent

Theorem 3.2
.

Set
\hat{C}_{h}=(h)
and let
C=\mathbb{F}_{q}[Q_{4n}]\Omega(\hat{C_{h}})
be the code induced by
\hat{C}_{h}
. Then
C
decomposes as

C\cong\bigoplus_{j=1}^{r+s}C_{j}\oplus\bigoplus_{i=1}^{t+k}C^{\prime}_{i},

where

C_{j}=\begin{cases}A_{j}\quad&j\in S_{1},\\
I_{j}(0,1)\quad&j\in S_{2},\\
I_{j}(1,0)\quad&j\in S_{3},\\
0\quad&j\notin S_{1}\cup S_{2}\cup S_{3},\end{cases}\quad C^{\prime}_{i}=\begin{cases}B_{i}\quad&i\in S_{4},\\
J_{i}(0,1)\quad&i\in S_{5},\\
J_{i}(1,0)\quad&i\in S_{6},\\
0\quad&i\notin S_{4}\cup S_{5}\cup S_{6},\end{cases}

and

\displaystyle S_{1}

\displaystyle=\{j\in\{1,\dots,r+s\}:f_{j}(x)\nmid h(x^{\ell})\wedge f_{j}^{*}(x)\nmid h(x^{\ell})\},

\displaystyle S_{2}

\displaystyle=\{j\in\{\delta(n)+1,\dots,r+s\}:f_{j}(x)\nmid h(x^{\ell})\wedge f_{j}^{*}(x)\mid h(x^{\ell})\},

\displaystyle S_{3}

\displaystyle=\{j\in\{\delta(n)+1,\dots,r+s\}:f_{j}(x)\mid h(x^{\ell})\wedge f_{j}^{*}(x)\nmid h(x^{\ell})\},

\displaystyle S_{4}

\displaystyle=\{i\in\{1,\dots,k+t\}:g_{i}(x)\nmid h(x^{\ell})\wedge g_{i}^{*}(x)\nmid h(x^{\ell})\},

\displaystyle S_{5}

\displaystyle=\{i\in\{\mu(n)+1,\dots,k+t\}:g_{i}(x)\nmid h(x^{\ell})\wedge g_{i}^{*}(x)\mid h(x^{\ell})\},

\displaystyle S_{6}

\displaystyle=\{i\in\{\mu(n)+1,\dots,k+t\}:g_{i}(x)\mid h(x^{\ell})\wedge g_{i}^{*}(x)\nmid h(x^{\ell})\}.

Proof.

Recalling the generating idempotent
e_{g}(x)
given in (
1.1
) and that for
g\in\mathbb{F}_{q}[x]/(x^{2n}-1)
, a monic divisor of
x^{2n}-1
with
g=g_{1}\cdot g_{2}
, it holds
e_{g}(x)=e_{g_{1}}(x)+e_{g_{2}}(x)
,
the generating idempotent of the code
\hat{C_{h}}
has the form:

\hat{e}_{\hat{C_{h}}}(\hat{x})=\left(\sum_{\begin{subarray}{c}j=1\\
\hat{f}_{j}(\hat{x})\nmid h(\hat{x})\end{subarray}}^{r+s}\hat{e}_{\hat{f}_{j}}(\hat{x})\right)+\left(\sum_{\begin{subarray}{c}j=1\\
\hat{f}_{j}^{*}(\hat{x})\nmid h(\hat{x})\end{subarray}}^{r+s}\hat{e}_{\hat{f}_{j}^{*}}(\hat{x})\right)+\left(\sum_{\begin{subarray}{c}i=1\\
\hat{g}_{i}(\hat{x})\nmid h(\hat{x})\end{subarray}}^{t+k}\hat{e}_{\hat{g}_{i}}(\hat{x})\right)+\left(\sum_{\begin{subarray}{c}i=1\\
\hat{g}_{i}^{*}(\hat{x})\nmid h(\hat{x})\end{subarray}}^{t+k}\hat{e}_{\hat{g}_{i}^{*}}(\hat{x})\right).

This gives:

C=\mathbb{F}_{q}[Q_{4n}]\Omega(\hat{C_{h}})=\mathbb{F}_{q}[Q_{4n}]\Omega\left(\mathbb{F}_{q}[\hat{x}]/(\hat{x}^{\frac{2n}{\ell}}-1)e_{\hat{C_{h}}}(\hat{x})\right)=\mathbb{F}_{q}[Q_{4n}]e_{\hat{C_{h}}}(x^{\ell})

and from Lemma
3.1
we have

\displaystyle\hat{e}_{\hat{C}_{h}}(x^{\ell})=\left(\sum_{\begin{subarray}{c}j=1\\
f_{j}(x)\nmid h(x^{\ell})\end{subarray}}^{r+s}e_{f_{j}}(x)\right)+\left(\sum_{\begin{subarray}{c}j=r+1\\
f_{j}^{*}(x)\nmid h(x^{\ell})\end{subarray}}^{r+s}e_{f_{j}^{*}}(x)\right)+\left(\sum_{\begin{subarray}{c}i=1\\
g_{i}(x)\nmid h(x^{\ell})\end{subarray}}^{t+k}e_{g_{i}}(x)\right)+\left(\sum_{\begin{subarray}{c}i=t+1\\
g_{i}^{*}(x)\nmid h(x^{\ell})\end{subarray}}^{t+k}e_{g_{i}^{*}}(x)\right).

Applying Theorem
2.1
the statement follows.

4
Conclusion

The block components
(C_{j})_{1\leq j\leq r+s},(C_{i}^{\prime})_{1\leq i\leq t+k}
of a code
C\subseteq\mathbb{F}_{q}[Q_{4n}]
with decomposition
C\cong\bigoplus_{j=1}^{r+s}C_{j}\oplus\bigoplus_{i=1}^{k+t}C^{\prime}_{i}
were identified via its generating idempotent. Afterwards this result is applied to establish the structure of codes induced
by cyclic groups. Understanding the structure and decomposition of such induced codes is a key
step for the construction of lifted product codes as demonstrated in
[
10
]
.
Similarly as one can determine the blocks of codes induced by cyclic group codes one can also obtain the blocks of codes in
\mathbb{F}_{q}[Q_{4n}]
induced by dihedral group codes, see
[
10
]
. However this case requires a rigourous computation of the generating idempotent of dihedral codes, see
[
8
]
, resulting in a more detailed analysis, see
[
5
,
2
]
. As already demonstrated in
[
9
]
where the bases, the generating and the check matrices of the dihedral codes are constructed one can use the algebra homomorphisms
(\tau_{j})_{1\leq j\leq r+s},(\eta_{i})_{1\leq i\leq t+k}
explicitly given in
[
5
]
, to extend this to the generalized quaternion group algebra
\mathbb{F}_{q}[Q_{4n}].
