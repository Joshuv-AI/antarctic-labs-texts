Minimal Subsampled Rank-1 Lattices for Multivariate Approximation with Optimal Convergence Rate
Felix Bartel, Alexander D. Gilbert, Frances Y. Kuo, Ian H. Sloan

Abstract
In this paper we show error bounds for randomly subsampled rank-1 lattices. We pay particular attention to the ratio of the size of the subset to the size of the initial lattice, which is decisive for the computational complexity. In the special case of Korobov spaces, we achieve the optimal polynomial sampling complexity whilst having the smallest initial lattice possible . We further characterize the frequency index set for which a given lattice is reconstructing by using the reciprocal of the worst-case error achieved using the lattice in question. This connects existing approaches used in proving error bounds for lattices. We make detailed comments on the implementation and test different algorithms using the subsampled lattice in numerical experiments. MSC2020: 41A25, 94A20

Introduction

This paper mainly deals with the question of approximating functions from partial rank-1 lattices.
Rank-1 lattices have their origin as a Quasi-Monte Carlo (QMC) method and have been thoroughly studied in various settings ever since, see e.g.,
[
39
,
21
,
22
,
36
,
6
,
7
]
.
The lattice point sets are given by
\bm{X}=\{\tfrac{k}{n}\bm{z}\bmod{}1\}_{k\in\{0,\dots,n-1\}}
, where
\bm{z}\in\mathds{Z}^{d}
is known as the generating vector and it controls the quality of the point set, and
\bmod\,1
denotes a component-wise fractional part of a vector.
The study of partial or subsampled rank-1 lattices has only begun recently, cf.
[
1
]
.
Such point sets have the form

\bm{X}_{J}=\Big\{\tfrac{k}{n}\bm{z}\bmod{}1\Big\}_{k\in J}\quad\text{with}\quad J\subseteq\{0,\dots,n-1\}\,.

An example is depicted in
Figure

1
.

Figure 1:
Left: rank-1 lattice with generating vector
\bm{z}=(1,21)
and lattice size
n=55
.

Right: subsampled rank-1 lattice with
|J|=\lceil\sqrt{n}\,\log\sqrt{n}\,\rceil=15
.

The structure of lattice point sets allows for the application of fast Fourier methods when approximating functions whilst the subsampling improves the approximation properties, cf.
[
2
]
.
We investigate the worst-case setting, where the point set and algorithm are fixed and are used to approximate every function from a given function class
H
.
The
worst-case error
for a general algorithm
A
measured in
L_{2}
-norm is defined by

e^{\mathrm{wor-app}}(A)\coloneqq\sup_{\|f\|_{H}\leq 1}\|f-Af\|_{L_{2}}\,,

where
\|\cdot\|_{H}
denotes the norm in
H
.

For full lattices
\bm{X}=\bm{X}_{\{0,\dots,n-1\}}
there are two main approaches to control the worst-case error:

(i)

Based on the function space
H
and a lattice size
n
, one computes a generating vector
\bm{z}
directly minimizing (a computable upper bound on) the worst-case error.
It was shown in e.g.,
[
33
,
6
]
that, for certain Korobov spaces with smoothness parameter
\alpha>1/2
, a component-by-component (CBC) construction achieves a decay rate

e^{\mathrm{wor-app}}(A_{\mathcal{A}}^{\bm{X}})\lesssim n^{-\alpha/2+\varepsilon}\,,

(1.1)

where
\varepsilon>0
,
A_{\mathcal{A}}^{\bm{X}}
is the “classical lattice algorithm” (see (
2.1
) below), and
A\lesssim B
means there exists a constant
C>0
independent of
n
such that
A\leq CB
.
When
\alpha
is an integer it is the number of available square-integrable derivatives in each coordinate.

(ii)

Another approach was taken in e.g.,
[
21
,
22
]
where one first constructs a suitable frequency index set in the Fourier domain and then uses a CBC construction to end up with a “reconstructing lattice” (see precise definition in (
3.1
) below).
This enables one to exactly reconstruct every trigonometric polynomial supported on the given frequencies.
The “aliasing”, i.e., the error arising from frequencies outside of the index set, is then controlled via an error bound.
The resulting decay rate is the same as in (
1.1
).

In this paper we connect both approaches by finding a frequency index set for which a lattice is reconstructing in
Theorem

3.2
below.
These frequencies solely depend on the worst-case error achievable using any algorithm and the lattice in question.
In that way, lattices constructed according the first approach can be investigated with respect to their reconstructing property, and tools from the second approach become available.

Regardless of the approach, there is a lower bound on the error rate using a full lattice of
n^{-\alpha/2}
, which is half the polynomial optimal rate of decay
n^{-\alpha}
when there is no restriction for the point set used, cf.
[
3
]
.
This seems to be an intrinsic problem with redundant information in the full lattice and motivates only using a subsampled lattice.
This was already investigated in the paper
[
1
]
.

For unweighted Korobov spaces known as periodic Sobolev spaces with dominating mixed smoothness
\alpha>1/2
, a combination of random and deterministic subsampling was used in
[
1
, Corollary 1.2]
, yielding the bound

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})\lesssim|J|^{-\alpha}(\log|J|)^{(d-1)\alpha+\frac{1}{2}}\quad\text{with}\quad n\sim|J|^{\frac{2}{1-1/(2\alpha)}}\,,

(1.2)

where
S_{\mathcal{B}}^{\bm{X}_{J}}
is the “least squares approximation” to be defined precisely in (
4.1
) below and
A\sim B
means
A\lesssim B
and
B\lesssim A
holds simultaneously.

This method achieves the optimal polynomial order
|J|^{-\alpha+\varepsilon}
up to
\varepsilon>0
in terms of sampling complexity.
However, the computational complexity is determined by
n
.
Since an algorithm using a subsampled lattice is inherently still using the lattice of size
n
, the lower bound from
[
3
]
still applies, and achieving the rate
|J|^{-\alpha+\varepsilon}
implies the lower bound

n\gtrsim|J|^{2-\frac{2\varepsilon}{\alpha}}\,.

With respect to the size of
|J|
, (
1.2
) is off by a polynomial order depending on the smoothness
\alpha
.

In this paper, in
Theorem

5.3
below, we show that we can go arbitrarily close to the squared number of points independently of the smoothness, i.e., we have

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})\lesssim\Big(\frac{|J|}{\log|J|}\Big)^{-\alpha+\varepsilon}\quad\text{with}\quad\Big(\frac{|J|}{\log|J|}\Big)^{2{\sqrt{1-\varepsilon/\alpha}}}\lesssim\,n\lesssim\Big(\frac{|J|}{\log|J|}\Big)^{\frac{2}{\sqrt{1-\varepsilon/\alpha}}}\,,

for
0<\varepsilon<\alpha
.
This result is optimal in the sense that it achieves the best polynomial sampling complexity whilst having the smallest initial lattice size.

This paper is organized as follows.
We start by introducing the classical lattice algorithm and the kernel method in
Section

2
.
Then we investigate the projection property of approximation algorithms in
Section

3
, where we also prove a connection between the worst-case error and the reconstructing property of lattices in
Theorem

3.2
, which appears to be a new result.
In
Section

4
we show general error bounds for the randomly subsampled lattice, which we apply to the Korobov space setting in
Section

5
.
After some comments on different implementations in
Section

6
, we present some numerical experiments in
Section

7
and give concluding remarks in
Section

8
.

2
Classical lattice algorithm versus kernel method

A
rank-1 lattice
point set
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}
is defined by a
generating vector

\bm{z}\in\mathds{Z}^{d}
and the
lattice size

n\in\mathds{N}
.
Rank-1 lattices were first studied as a Quasi-Monte Carlo (QMC) method to compute integrals, see e.g.,
[
39
]

\int_{\mathds{T}^{d}}f(\bm{x})\;\mathrm{d}\bm{x}\approx\frac{1}{n}\sum_{k=0}^{n-1}f(\tfrac{k}{n}\bm{z}\bmod{}1)\,,

which corresponds to approximating the Fourier coefficient
\widehat{f}_{\bm{0}}
of a function with the Fourier series

f=\sum_{\bm{h}\in\mathds{Z}^{d}}\widehat{f}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\,,\quad\text{where}\quad\widehat{f}_{\bm{h}}=\int_{\mathds{T}^{d}}f(\bm{x})\exp(-2\pi\mathrm{i}\langle\bm{h},\bm{x}\rangle)\;\mathrm{d}\bm{x}\,.

Doing this for multiple frequencies
\bm{h}
from a prescribed frequency index set
\mathcal{A}\subseteq\mathds{Z}^{d}
, one may construct the trigonometric polynomial approximation to
f
which we refer to as the
classical lattice algorithm

A_{\mathcal{A}}^{\bm{X}}f\coloneqq\sum_{\bm{h}\in\mathcal{A}}\Big(\underbrace{\frac{1}{n}\sum_{k=0}^{n-1}f(\tfrac{k}{n}\bm{z}\bmod{}1)\exp(-2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h},\bm{z}\rangle)}_{\eqqcolon\,\widehat{g}_{\bm{h}}}\Big)\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\,,

(2.1)

see e.g.,
[
33
,
22
,
21
,
36
,
6
,
7
]
.
To get a feeling for this method, we have a look at the Fourier coefficients of the approximation
A_{\mathcal{A}}^{\bm{X}}f\eqqcolon g=\sum_{\bm{h}\in\mathcal{A}}\widehat{g}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)
in terms of the Fourier coefficients of
f
.
By the
character property

\frac{1}{n}\sum_{k=0}^{n-1}\exp(2\pi\mathrm{i}m\tfrac{k}{n})=\delta_{m\equiv_{n}0}
, we have for
\bm{h}\in\mathcal{A}

\displaystyle\widehat{g}_{\bm{h}}

\displaystyle=\frac{1}{n}\sum_{k=0}^{n-1}\Big(\sum_{\bm{\ell}\in\mathds{Z}^{d}}\widehat{f}_{\bm{\ell}}\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{\ell},\bm{z}\rangle)\Big)\exp(-2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h},\bm{z}\rangle)

\displaystyle=\sum_{\bm{\ell}\in\mathds{Z}^{d}}\widehat{f}_{\bm{\ell}}\,\frac{1}{n}\sum_{k=0}^{n-1}\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{\ell}-\bm{h},\bm{z}\rangle)

\displaystyle=\sum_{\begin{subarray}{c}\bm{\ell}\in\mathds{Z}^{d}\\
\langle\bm{\ell},\bm{z}\rangle\equiv_{n}\langle\bm{h},\bm{z}\rangle\end{subarray}}\!\!\!\!\!\!\widehat{f}_{\bm{\ell}}\,.

(2.2)

Thus, the classical lattice approximation has an aliasing effect where multiple frequencies of the target function are mapped to a single frequency of the approximation.
In order to control this error we have to demand some prior smoothness assumptions on the function
f
.
This is usually done by enforcing a decay in the Fourier coefficients as follows

f\in H=\Big\{f\colon\mathds{T}^{d}\to\mathds{C}:\|f\|_{H}^{2}=\sum_{\bm{h}\in\mathds{Z}^{d}}r(\bm{h})\,|\widehat{f}_{\bm{h}}|^{2}<\infty\Big\}\,,

(2.3)

where
r(\bm{h})\to\infty
for
\|\bm{h}\|_{2}\to\infty
.
Specific choices of the function
r(\cdot)
lead to e.g., the Korobov spaces in
Section

5
.
Obviously there are good and bad choices for the frequency index set
\mathcal{A}\subseteq\mathds{Z}^{d}
and the generating vector
\bm{z}\in\mathds{Z}^{d}
.
The following theorem gives an error bound for the classical lattice algorithm and follows
[
6
, Section 2.4]
.

Theorem 2.1
.

Let
H
be the function space defined in (
2.3
),
\bm{X}=\{\tfrac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
a lattice, and

\mathcal{A}=\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})\leq M\}
for some radius
M>0
.
Then for the classical lattice algorithm defined in (
2.1
), we have

e^{\mathrm{wor-app}}(A_{\mathcal{A}}^{\bm{X}})^{2}<\frac{1}{M}+M\mathcal{S}_{n}(\bm{z})\,,

(2.4)

with

\mathcal{S}_{n}(\bm{z})=\sum_{\bm{h}\in\mathds{Z}^{d}}\frac{1}{r(\bm{h})}\sum_{\begin{subarray}{c}\bm{\ell}\in\mathds{Z}^{d}\setminus\{\bm{0}\}\\
\langle\bm{\ell},\bm{z}\rangle\equiv_{n}0\end{subarray}}\frac{1}{r(\bm{h}+\bm{\ell})}\,.

(2.5)

In particular, with the optimal choice
M=1/\sqrt{\mathcal{S}_{n}(\bm{z})}
, which minimizes (
2.4
), we have

e^{\mathrm{wor-app}}(A_{\mathcal{A}}^{\bm{X}})^{2}<\frac{2}{M}=2\sqrt{\mathcal{S}_{n}(\bm{z})}\,.

(2.6)

We have stated (
2.4
) and (
2.6
) as strict inequalities.
This can be seen from the derivation of the quantity
\mathcal{S}_{n}(\bm{z})
, see e.g.,
[
6
, Formula (2.7)]
, where infinitely many positive terms with index
\bm{h}\notin\mathcal{A}
were added.

For weighted Korobov spaces (see
Section

5
below) and a given lattice size
n\in\mathds{N}
, component-by-component (CBC) constructions for generating vectors
\bm{z}
are known, controlling
\mathcal{S}_{n}(\bm{z})
as in
Theorem

5.1
below, which is
[
30
, Theorem 3.3]
.
Fast CBC implementations are given in
[
6
,
14
]
.

Next we comment on the kernel method, which is often used in practice and benefits from the lattice structure, cf.
[
20
, Section 5]
.
For kernel methods we need to assume that
H
is a reproducing kernel Hilbert space, i.e., function evaluations are continuous, which is a common and natural assumption.
By the Moore–Aronszajn theorem
H
has a corresponding reproducing kernel
K\colon\mathds{T}^{d}\times\mathds{T}^{d}\to\mathds{C}
, which is symmetric and positive definite.
The
kernel approximation
of
f
based on the lattice
\bm{X}
is defined by

A_{\text{ker}}^{\bm{X}}f\coloneqq\sum_{k=0}^{n-1}a_{k}\,K(\cdot,\tfrac{k}{n}\bm{z}\bmod{}1)\quad\text{with}\quad\bm{a}=[a_{k}]_{k\in\{0,\dots,n-1\}}=\bm{K}^{-1}\bm{f}\,,

(2.7)

where
\bm{K}=[K(\tfrac{k}{n}\bm{z}\bmod{}1,\tfrac{k^{\prime}}{n}\bm{z}\bmod{}1)]_{k,k^{\prime}\in\{0,\dots,n-1\}}
is the kernel matrix, and the vector
\bm{f}=[f(\tfrac{k}{n}\bm{z}\bmod{}1)]_{k\in\{0,\dots,n-1\}}
consists of the function evaluations on the lattice
\bm{X}
.
Since
K(\bm{x},\bm{y})=K(\bm{x}-\bm{y},\bm{0})
, we have that
\bm{K}
is a circulant matrix

\bm{K}=\Big[K(\tfrac{k}{n}\bm{z}\bmod{}1,\tfrac{k^{\prime}}{n}\bm{z}\bmod{}1)\Big]_{k,k^{\prime}\in\{0,\dots,n-1\}}=\Big[K(\tfrac{k-k^{\prime}}{n}\bm{z}\bmod{}1,\bm{0})\Big]_{k,k^{\prime}\in\{0,\dots,n-1\}}\,.

Thus, it is possible to diagonalize it by a discrete Fourier transform (DFT) matrix
\bm{F}=[\exp(2\pi\mathrm{i}\,k\,k^{\prime}/n)]_{k,k^{\prime}\in\{0,\dots,n-1\}}

\bm{K}=\frac{1}{n}\bm{F}\Diag(\bm{F}^{\ast}\bm{c})\bm{F}^{\ast}\quad\text{and}\quad\bm{K}^{-1}=\frac{1}{n}\bm{F}\Diag(\bm{F}^{\ast}\bm{c})^{-1}\bm{F}^{\ast}\,,

with
\bm{c}=[K(\frac{k}{n}\bm{z}\bmod{}1,\bm{0})]_{k\in\{0,\dots,n-1\}}
.
The kernel approximation with lattices is therefore computable using three fast Fourier transforms in
\mathcal{O}(n\log n)
arithmetic operations.

In terms of the error it is known that for any given set of points, the kernel approximation (
2.7
) is optimal among all (linear or nonlinear) algorithms using function values at the same point set in the worst-case setting with respect to any error norm, cf.
[
20
]
.
In particular, we have that the worst-case error of the kernel approximation is bounded by the worst-case error of the classical lattice algorithm (
2.1
)

e^{\mathrm{wor-app}}(A_{\text{ker}}^{\bm{X}})\leq e^{\mathrm{wor-app}}(A_{\mathcal{A}}^{\bm{X}})\,.

Thus, the bound from
Theorem

2.1
applies to the kernel method as well.

3
Projection property of approximation algorithms

A projection is a linear, idempotent map, meaning that the projection is equal to its composition with itself.
In this section we derive a condition under which the classical lattice algorithm
A_{\mathcal{A}}^{\bm{X}}
defined in (
2.1
) is a projection.

Clearly we have linearity for
A_{\mathcal{A}}^{\bm{X}}
but the idempotence is not always present.
For instance, if there are two aliasing frequencies, i.e.,
\bm{h},\bm{h}^{\prime}\in\mathcal{A}
with
\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle
, we can take
f\coloneqq\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)+\exp(2\pi\mathrm{i}\langle\bm{h}^{\prime},\cdot\rangle)
.
We then have
f\in\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{A}}
yet by (
2.2
)

\displaystyle A_{\mathcal{A}}^{\bm{X}}f=2f\neq f\,.

Thus, to ensure idempotence it is necessary that there are no aliasing frequencies in the index set, that is, no indices have the same inner product with the generating vector
\bm{z}
modulo
n
.

A lattice
\bm{X}=\{\tfrac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
is said to have the
reconstructing property
on
\mathcal{B}\subseteq\mathds{Z}^{d}
if

\langle\bm{h},\bm{z}\rangle\not\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle\quad\text{for all}\quad\bm{h},\bm{h}^{\prime}\in\mathcal{B}\,.

(3.1)

This is also sufficient for the idempotence as the following theorem shows.
For ease of readability, we will write
\mathcal{B}\subseteq\mathds{Z}^{d}
when we have the reconstructing property and
\mathcal{A}\subseteq\mathds{Z}^{d}
for a generic frequency index set.

Theorem 3.1
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property (
3.1
).
Then the classical lattice algorithm
A_{\mathcal{B}}^{\bm{X}}
defined in (
2.1
) is a projection onto
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
.

Proof.

By definition we have that
A_{\mathcal{B}}^{\bm{X}}
is linear and maps onto
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
.
Combining the aliasing formula (
2.2
) with the reconstructing property of
\bm{X}
on
\mathcal{B}
as in (
3.1
), we obtain
\widehat{g}_{\bm{h}}=\widehat{f}_{\bm{h}}
for all
\bm{h}\in\mathcal{B}
and confirm the idempotence.
∎

There are CBC constructions that compute a generating vector
\bm{z}
for a given frequency index set
\mathcal{B}
and
n\in\mathds{N}
large enough that the reconstructing property holds, see e.g.,
[
24
,
25
]
.
We investigate the opposite question: given a lattice, what is the set of frequencies on which we have the reconstructing property, or equivalently what is the space on which the lattice algorithm is a projection.

Theorem 3.2
.

Let
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
be a lattice.
Further, let
H
be the function space from (
2.3
) and
A^{\bm{X}}
a (linear or non-linear) approximation algorithm using samples of
\bm{X}
.
Then
\bm{X}
is a lattice with reconstructing property (
3.1
) for the frequency index set

\Big\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})<(e^{\mathrm{wor-app}}(A^{\bm{X}}))^{-2}\Big\}\,.

(3.2)

In particular, the above holds for the best possible worst-case error achievable by any (linear or non-linear) algorithm using points from the lattice
\bm{X}
.

Proof.

The proof uses ideas from
[
3
, Theorem 3.2]
, which showed a lower bound on the worst-case error using samples from lattices in function spaces of dominating mixed smoothness.

We will show that for any two aliasing frequencies, at least one must lie outside of the proposed frequency index set.

Let
\bm{h},\bm{h}^{\prime}\in\mathds{Z}^{d}
with
\bm{h}\neq\bm{h}^{\prime}
,
\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle
, and
r(\bm{h})\leq r(\bm{h}^{\prime})
.
We define the fooling function

f\coloneqq\frac{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)-\exp(2\pi\mathrm{i}\langle\bm{h}^{\prime},\cdot\rangle)}{\sqrt{r(\bm{h})+r(\bm{h}^{\prime})}}\,,

so that

\|f\|_{H}=\sqrt{\frac{r(\bm{h})+r(\bm{h}^{\prime})}{r(\bm{h})+r(\bm{h}^{\prime})}}=1\quad\text{and}\quad\|f\|_{L_{2}}=\sqrt{\frac{2}{r(\bm{h})+r(\bm{h}^{\prime})}}\,.

Because of the aliasing frequencies, this function evaluates to zero on the lattice
\bm{X}
, i.e.,

f(\tfrac{k}{n}\bm{z}\bmod{}1)=\frac{\exp(2\pi\mathrm{i}\frac{k}{n}\langle\bm{h},\bm{z}\rangle)-\exp(2\pi\mathrm{i}\frac{k}{n}\langle\bm{h}^{\prime},\bm{z}\rangle)}{\sqrt{r(\bm{h})+r(\bm{h}^{\prime})}}=0\quad\text{for}\quad k\in\{0,\dots,n-1\}\,.

If
A^{\bm{X}}
were to be linear, we would have
A^{\bm{X}}(f)\equiv 0
and
\|f\|_{L_{2}}=\|f-A^{\bm{X}}(f)\|_{L_{2}}\leq e^{\mathrm{wor-app}}(A^{\bm{X}})
.
Since we also include non-linear algorithms we only have
A^{\bm{X}}(f)=A^{\bm{X}}(-f)
and need an intermediate step for the same result:

\displaystyle\|f\|_{L_{2}}

\displaystyle=\frac{1}{2}\|f-A^{\bm{X}}(f)+f+A^{\bm{X}}(-f)\|_{L_{2}}

\displaystyle\leq\frac{1}{2}\Big(\|f-A^{\bm{X}}(f)\|_{L_{2}}+\|(-f)-A^{\bm{X}}(-f)\|_{L_{2}}\Big)

\displaystyle\leq\max\Big\{\|f-A^{\bm{X}}(f)\|_{L_{2}},\|(-f)-A^{\bm{X}}(-f)\|_{L_{2}}\Big\}

\displaystyle\leq e^{\mathrm{wor-app}}(A^{\bm{X}})\,.

Thus

\frac{1}{r(\bm{h}^{\prime})}\leq\frac{2}{r(\bm{h})+r(\bm{h}^{\prime})}=\|f\|_{L_{2}}^{2}\leq e^{\mathrm{wor-app}}(A^{\bm{X}})^{2}\,.

Since this holds for any two aliasing frequencies, at least one of the two aliasing frequencies must lie outside of the proposed frequency index set (
3.2
), which is equivalent to the reconstructing property.
∎

Applying this to the classical lattice algorithm, we obtain the following result.

Corollary 3.3
.

Let
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
be a lattice and
\mathcal{S}_{n}(\bm{z})
be defined as in (
2.5
).
Then
\bm{X}
has the reconstructing property on

\Big\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})\leq\frac{1}{2\sqrt{\mathcal{S}_{n}(\bm{z})}}\Big\}\,.

(3.3)

Proof.

Using the classical lattice algorithm (
2.1
) in
Theorem

3.2
, we obtain the reconstructing property on

\Big\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})<(e^{\mathrm{wor-app}}(A_{\mathcal{A}}^{\bm{X}}))^{-2}\Big\}\,.

Now we plug in the bound (
2.6
), which only makes the frequency index set smaller, not losing the reconstructing property.
We have
\leq
insead of
<
in (
3.3
) since equality is not attained in (
2.1
).
∎

Note, the frequency index set (
3.3
) has half of the radius of the frequency index set used in the classical lattice algorithm in
Theorem

2.1
, where we have
M=1/\sqrt{\mathcal{S}_{n}(\bm{z})}
.
With the latter choice we do not have the guarantee for the reconstructing property.
This difference could be an artifact of the proof, however.

4
Error bounds for subsampled rank-1 lattices

In this section we investigate what happens to the projection property as well as to error bounds if we use only a subset of the lattice points
\bm{X}_{J}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k\in J}
for
J\subseteq\{0,\dots,n-1\}
.
Instead of using the classical lattice algorithm, we will use a
least squares approximation

S_{\mathcal{B}}^{\bm{X}_{J}}f\coloneqq\Argmin_{g\in\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}}\sum_{k\in J}\Big|g(\tfrac{k}{n}\bm{z}\bmod{}1)-f(\tfrac{k}{n}\bm{z}\bmod{}1)\Big|^{2}\,.

(4.1)

Note that it is necessary for
\bm{X}
to have the reconstructing property on
\mathcal{B}
as otherwise there would be functions with aliasing frequencies having the same function values along the lattice and subsequently also along the subsampled lattice.
This would result in the non-uniqueness of the least squares approximation.
Furthermore, bad choices in
J
would not work as well.
For instance, we need at least
|J|\geq|\mathcal{B}|
, otherwise we could construct a non-zero function that evaluates to zero on
\bm{X}_{J}
, again, yielding non-uniqueness.

Throughout this paper we will use multisets for
J
, meaning that elements may repeat.
For the cardinality
|J|
, elements are counted according to their repeated appearance, e.g.
|\{1,1\}|=2
.
Note that for the actual number of points used, or equivalently, the number of function evaluations used, it is not necessary to count by repeated appearance but it always provides an upper bound.

Lemma 4.1
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property.
For
J\subseteq\{0,\dots,n-1\}
a multiset with
|J|\geq|\mathcal{B}|
, suppose that

\bm{L}_{J,\mathcal{B}}\coloneqq\Big[\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h},\bm{z}\rangle)\Big]_{k\in J,\,\bm{h}\in\mathcal{B}}\in\mathds{C}^{|J|\times|\mathcal{B}|}

(4.2)

has full rank
|\mathcal{B}|
, and let
\bm{f}_{J}\coloneqq[f(\frac{k}{n}\bm{z}\bmod{}1)]_{k\in J}
for
f\colon\mathds{T}^{d}\to\mathds{C}
.
Then for the least squares approximation

S_{\mathcal{B}}^{\bm{X}_{J}}f=\sum_{\bm{h}\in\mathcal{B}}\widehat{g}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)

defined in (
4.1
), we have the Fourier coefficients

\bm{\widehat{g}}_{\mathcal{B}}\coloneqq[\widehat{g}_{\bm{h}}]_{\bm{h}\in\mathcal{B}}=(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{f}_{J}\,.

Proof.

The definition of the least squares approximation (
4.1
) can be rewritten in matrix-vector form using the wanted Fourier coefficients

\Argmin_{\bm{\widehat{g}}_{\mathcal{B}}\in\mathds{C}^{|\mathcal{B}|}}\|\bm{L}_{J,\mathcal{B}}\,\bm{\widehat{g}}_{\mathcal{B}}-\bm{f}_{J}\|_{2}^{2}\,.

Computing this minimum, one uses the normal equation

\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}}\,\bm{\widehat{g}}_{\mathcal{B}}=\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{f}_{J}\,.

By assumption the left-hand side matrix
\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}}
has full rank and can therefore be inverted, yielding the assertion.
∎

Note, that the full rank condition already implies that
\bm{X}
has to have the reconstructing property on
\mathcal{B}
and
|J|\geq|\mathcal{B}|
.
Next we show that given full rank of
\bm{L}_{J,\mathcal{B}}
, the least squares approximation still maintains the projection property.

Lemma 4.2
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property.
For
J\subseteq\{0,\dots,n-1\}
a multiset with
|J|\geq|\mathcal{B}|
, suppose
\bm{L}_{J,\mathcal{B}}
from (
4.2
) has full rank
|\mathcal{B}|
.
Then the least squares approximation
S_{\mathcal{B}}^{\bm{X}_{J}}
defined in (
4.1
), with the subsampled lattice
\bm{X}_{J}
is a projection onto
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
.

Proof.

By definition we have that
S_{\mathcal{B}}^{\bm{X}_{J}}
maps linearly into
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
.
To show the idempotence, we use the Fourier representation of a function supported on
\mathcal{B}

f=\sum_{\bm{h}\in\mathcal{B}}\widehat{f}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\in\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}

and collect the Fourier coefficients in the vector
\bm{\widehat{f}}_{\mathcal{B}}=[\widehat{f}_{\bm{h}}]_{\bm{h}\in\mathcal{B}}
.
From the reconstructing property, there holds
\bm{f}_{J}=\bm{L}_{J,\mathcal{B}}\,\bm{\widehat{f}}_{\mathcal{B}}
.
By
Lemma

4.1
we have for the Fourier coefficients of the least squares approximation

\bm{\widehat{g}}_{\mathcal{B}}=(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{f}_{J}=(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}}\,\bm{\widehat{f}}_{\mathcal{B}}=\bm{\widehat{f}}_{\mathcal{B}}\,,

where the inverse exists because of the assumptions on
\bm{L}_{J,\mathcal{B}}
having full rank.
The Fourier coefficients of the least squares approximation coincide with those of the function
f
.
Thus, they are the same functions, which proves the assertion.
∎

Before commenting on a specific choice in
J
, we relate the worst-case error of the least squares approximation to the spectral properties of certain matrices.

Theorem 4.3
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property.
For
J\subseteq\{0,\dots,n-1\}
a multiset with
|J|\geq|\mathcal{B}|
, suppose
\bm{L}_{J,\mathcal{B}}
in (
4.2
) has full rank, and define

\bm{\Phi}_{J,\mathcal{B}}\coloneqq\Big[\frac{\exp(2\pi\mathrm{i}\frac{k}{n}\langle\bm{h},\bm{z}\rangle)}{\sqrt{r(\bm{h})}}\Big]_{k\in J,\,\bm{h}\notin\mathcal{B}}\,.

(4.3)

Then the worst-case error of the least squares approximation defined in (
4.1
) with respect to the function space defined in (
2.3
) satisfies the bound

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\frac{\|\bm{\Phi}_{J,\mathcal{B}}\|_{2}^{2}}{\sigma_{\min}^{2}(\bm{L}_{J,\mathcal{B}})}\,,

where
\sigma_{\min}(\bm{L}_{J,\mathcal{B}})
denotes the smallest singular value of
\bm{L}_{J,\mathcal{B}}
.

Proof.

For
f\in H
we write
f-S_{\mathcal{B}}^{\bm{X}_{J}}f=(f-P_{\mathcal{B}}f)+(P_{\mathcal{B}}f-S_{\mathcal{B}}^{\bm{X}_{J}}f)
, where
P_{\mathcal{B}}f=\sum_{\bm{h}\in\mathcal{B}}\widehat{f}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)
is the
L_{2}
-projection of
f
onto
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
.
This decomposition is orthogonal because by definition
S_{\mathcal{B}}^{\bm{X}_{J}}f=P_{\mathcal{B}}\,S_{\mathcal{B}}^{\bm{X}_{J}}f
.
Thus,

\|S_{\mathcal{B}}^{\bm{X}_{J}}f-f\|_{L_{2}}^{2}=\|f-P_{\mathcal{B}}f\|_{L_{2}}^{2}+\|P_{\mathcal{B}}f-S_{\mathcal{B}}^{\bm{X}_{J}}f\|_{L_{2}}^{2}\,,

(4.4)

For the first summand of (
4.4
) we use

\|f-P_{\mathcal{B}}f\|_{L_{2}}^{2}=\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}\,r(\bm{h})\,|\widehat{f}_{\bm{h}}|^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}\,\|f\|_{H}^{2}\,.

Now we estimate the second summand of (
4.4
).
By
Lemma

4.2
,
S_{\mathcal{B}}^{\bm{X}_{J}}
is a projection onto
\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}
and we obtain using
Lemma

4.1

\displaystyle\|P_{\mathcal{B}}f-S_{\mathcal{B}}^{\bm{X}_{J}}f\|_{L_{2}}^{2}

\displaystyle=\|S_{\mathcal{B}}^{\bm{X}_{J}}P_{\mathcal{B}}f-S_{\mathcal{B}}^{\bm{X}_{J}}f\|_{L_{2}}^{2}=\|S_{\mathcal{B}}^{\bm{X}_{J}}(P_{\mathcal{B}}f-f)\|_{L_{2}}^{2}

\displaystyle\leq\Big\|(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\Big[(P_{\mathcal{B}}f-f)(\tfrac{k}{n}\bm{z}\bmod{}1)\Big]_{k\in J}\Big\|_{2}^{2}

\displaystyle\leq\|(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\|_{2}^{2}\,\sum_{k\in J}\Big|(P_{\mathcal{B}}f-f)(\tfrac{k}{n}\bm{z}\bmod{}1)\Big|^{2}\,.

By
[
23
, Proposition 3.1]
, we have
\|(\bm{L}_{J,\mathcal{B}}^{\ast}\,\bm{L}_{J,\mathcal{B}})^{-1}\bm{L}_{J,\mathcal{B}}^{\ast}\|_{2}=1/\sigma_{\min}(\bm{L}_{J,\mathcal{B}})
.
On the other hand, we have

\displaystyle\sum_{k\in J}\Big|(f-P_{\mathcal{B}}f)(\tfrac{k}{n}\bm{z}\bmod{}1)\Big|^{2}

\displaystyle=\sum_{k\in J}\Big|\sum_{\bm{h}\notin\mathcal{B}}\widehat{f}_{\bm{h}}\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h},\bm{z}\rangle)\Big|^{2}

\displaystyle=\sum_{k\in J}\Big|\sum_{\bm{h}\notin\mathcal{B}}\sqrt{r(\bm{h})}\,\widehat{f}_{\bm{h}}\,\frac{1}{\sqrt{r(\bm{h})}}\,\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h},\bm{z}\rangle)\Big|^{2}

\displaystyle=\|\bm{\Phi}_{J,\mathcal{B}}\,[\sqrt{r(\bm{h})}\,\widehat{f}_{\bm{h}}]_{\bm{h}\notin\mathcal{B}}\|_{2}^{2}

\displaystyle\leq\|\bm{\Phi}_{J,\mathcal{B}}\|_{2}^{2}\,\|f\|_{H}^{2}\,.

Combining the two estimates completes the proof
∎

We have seen in
Lemma

4.2
that it is possible to reconstruct trigonometric polynomials from values at a subsampled lattice
\bm{X}_{J}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k\in J}\subseteq\mathds{T}^{d}
,
J\subseteq\{0,\dots,n-1\}
given that
\bm{L}_{J,\mathcal{B}}
has full rank.
The following lemma quantifies this for a randomly selected subset
J
.

Lemma 4.4
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property.
Further, let
t>0
and
J\subseteq\{0,\dots,n-1\}
be a multiset of uniformly i.i.d. drawn integers with

|J|\geq 12\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)\,.

(4.5)

For
\bm{L}_{J,\mathcal{B}}
defined as in (
4.2
) we have the following two inequalities, each holding with probability exceeding
1-\exp(-t)
,

\frac{|J|}{2}\leq\sigma_{\min}^{2}(\bm{L}_{J,\mathcal{B}})\quad\text{and}\quad\sigma_{\max}^{2}(\bm{L}_{J,\mathcal{B}})\leq\frac{3|J|}{2}\,.

(4.6)

For
|J|\geq 3
,
\bm{\Phi}_{J,\mathcal{B}}
as in (
4.3
), and
\bm{\Phi}_{\mathcal{B}}=\bm{\Phi}_{\{0,\dots,n-1\},\mathcal{B}}
, we have with probability exceeding
1-2^{3/4}\exp(-t)
that

\|\bm{\Phi}_{J,\mathcal{B}}\|_{2}^{2}\leq 21\,(\log|J|+t)\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+2\frac{|J|}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}\,.

(4.7)

Proof.

By
[
1
, Lemma 2.2]
the reconstructing property of
\bm{X}
corresponds to an exact
L_{2}
-Marcinkiewicz–Zygmund inequality, i.e.,

\|f\|_{L_{2}}^{2}=\frac{1}{n}\sum_{k=0}^{n-1}|f(\tfrac{k}{n}\bm{z}\bmod{}1)|^{2}\quad\text{for all}\quad f\in\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}\,.

With the logarithmic oversampling assumption (
4.5
) on
J
, we are able to use the technique of
[
1
, Theorem 3.1]
, which yields that the subsampled points fulfill an
L_{2}
-Marcinkiewicz–Zygmund inequality with constants
1/2
and
3/2
, i.e.,

\frac{1}{2}\|f\|_{L_{2}}^{2}\leq\frac{1}{|J|}\sum_{k\in J}|f(\tfrac{k}{n}\bm{z}\bmod{}1)|^{2}\leq\frac{3}{2}\|f\|_{L_{2}}^{2}\quad\text{for all}\quad f\in\Span\{\exp(2\pi\mathrm{i}\langle\bm{h},\cdot\rangle)\}_{\bm{h}\in\mathcal{B}}\,,

where from their proof each bound holds with probability
1-\exp(-t)
, respectively.
This random technique uses a matrix Chernoff concentration inequality
[
42
, Theorem 1.1]
with one of the first applications in the sampling context in
[
5
, Theorem 2.1]
.
Using
[
1
, Lemma 2.2]
again converts this to the desired bounds on the singular values in (
4.6
).

For
k\in\{0,\dots,n-1\}
, we define the sequences

\bm{y}^{k}\coloneqq\Big[\frac{\exp(-2\pi\mathrm{i}\frac{k}{n}\langle\bm{h},\bm{z}\rangle)}{\sqrt{r(\bm{h})}}\Big]_{\bm{h}\notin\mathcal{B}}\,,

with
\|\bm{y}^{k}\|_{2}^{2}\leq\sum_{\bm{h}\notin\mathcal{B}}1/r(\bm{h})
, so that

\frac{1}{|J|}\sum_{k\in J}\bm{y}^{k}(\bm{y}^{k})^{\ast}=\frac{1}{|J|}\sum_{k\in J}\Big[\frac{\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h}^{\prime}-\bm{h},\bm{z}\rangle)}{\sqrt{r(\bm{h})r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\notin\mathcal{B}}=\frac{1}{|J|}\bm{\Phi}_{J,\mathcal{B}}^{\ast}\bm{\Phi}_{J,\mathcal{B}}\,.

The set
J
gives us a random set of sequences
\{\bm{y}^{k}\}_{k\in J}
for which we know

\mathds{E}_{k}(\bm{y}^{k}(\bm{y}^{k})^{\ast})=\frac{1}{n}\sum_{k=0}^{n-1}\Big[\frac{\exp(2\pi\mathrm{i}\frac{k}{n}\langle\bm{h}^{\prime}-\bm{h},\bm{z}\rangle)}{\sqrt{r(\bm{h})\,r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\notin\mathcal{B}}=\frac{1}{n}\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\,,

where the expectation is taken with respect to the discrete random variable
k
uniformly sampled from
\{0,\dots,n-1\}
.
Applying
[
34
, Proposition 3.8]
on these random sequences (with
n
there replaced by
|J|\geq 3
) yields with probability exceeding
1-2^{3/4}|J|^{1-\beta}
for
\beta>1
that

\Big\|\frac{1}{|J|}\bm{\Phi}_{J,\mathcal{B}}^{\ast}\bm{\Phi}_{J,\mathcal{B}}-\frac{1}{n}\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\Big\|_{2}\leq\max\Big\{\frac{21\beta\log|J|}{|J|}\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})},\,\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\|_{2}\Big\}\,.

Setting
\beta=(\log|J|+t)/\log|J|
for
t>0
, this gives with probability exceeding
1-2^{3/4}\exp(-t)
that

\Big\|\frac{1}{|J|}\bm{\Phi}_{J,\mathcal{B}}^{\ast}\bm{\Phi}_{J,\mathcal{B}}-\frac{1}{n}\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\Big\|_{2}\leq\max\Big\{\frac{21\,(\log|J|+t)}{|J|}\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})},\,\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\|_{2}\Big\}\,,

from which the assertion (
4.7
) follows by basic arithmetic operations.
∎

Using these spectral bounds in the general error bound for least squares approximation yields the following theorem.

Theorem 4.5
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a nonempty frequency index set for which the lattice
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
has the reconstructing property.
Further, let
t\geq 4
and
J\subseteq\{0,\dots,n-1\}
be a multiset of uniformly i.i.d. drawn integers with

|J|:=\lceil 12\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)\rceil\,.

Then the least squares approximation defined in (
4.1
) using samples on the subsampled lattice
\bm{X}_{J}
satisfies with probability exceeding
1-3\exp(-t)
that

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\frac{42\,(\log|J|+t)}{|J|}\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\frac{4}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}\,,

with respect to the function space defined in (
2.3
) and
\bm{\Phi}_{\mathcal{B}}=\bm{\Phi}_{\{0,\dots,n-1\},\mathcal{B}}
as in (
4.3
). Additionally we have

\frac{6\,(\log|J|+t)}{|J|}\leq\frac{1}{|\mathcal{B}|}\leq\frac{13\,(\log|J|+t)}{|J|}\,.

(4.8)

Proof.

We use the bound of the smallest singular value of
\bm{L}_{J,\mathcal{B}}
and the bound on the spectral norm of
\bm{\Phi}_{J,\mathcal{B}}
of
Lemma

4.4
.
By Boole’s inequality, the overall probability exceeds
1-\exp(-t)-2^{3/4}\exp(-t)\geq 1-3\exp(-t)
, which is the claimed probability.
Plugging in the spectral bounds into
Theorem

4.3
, we obtain

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\frac{2}{|J|}\Big(21\,(\log|J|+t)\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+2\frac{|J|}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}\Big)\,.

It remains to estimate the scaling factor for the sum.

We first show that for
b\geq 1
and
t\geq 4
we have

12\,b\,(\log b+t)\leq b^{2}\exp(t)\,.

(4.9)

Since
\log b\leq b-1
this follows from the stronger assertion

12\,(b-1+t)\leq b\exp(t)\quad\Leftrightarrow\quad(\exp(t)-12)\,b+12-12t\geq 0\,.

The left-hand side is non-decreasing in
b
since
t\geq 4\geq\log(12)
.
With
b\geq 1
, it remains to check the non-negativity for
b=1
, which is satisfied for
t\geq 4
showing (
4.9
).

We are ready to prove an upper bound on
(\log j+t)/j
in terms of
1/b
when
j:=\lceil\,12\,b\,(\log b+t)\,\rceil\geq 12\,b\,(\log b+t)
.
Since
(\log j+t)/j
is increasing with decreasing
j
, it suffices to show an estimate for
\ell\leq j
such that

12\,b\,(\log b+t)\leq\ell\leq b^{2}\exp(t)\,.

Such a value of
\ell\in\mathds{R}
exists due to (
4.9
).
Then it follows that

\frac{\log j+t}{j}\leq\frac{\log\ell+t}{\ell}\leq\frac{2\,(\log b+t)}{12\,b\,(\log b+t)}=\frac{1}{6\,b}\,.

Finally we prove an upper bound on
1/b
in terms of
(\log j+t)/j
.
Since
b\geq 1
and
t\geq 4
, we have
12\,b\,(\log b+t)\geq\frac{48}{49}\lceil 12\,b\,(\log b+t)\rceil
.
Thus

\frac{1}{b}\leq\frac{49}{48}\frac{12\,(\log b+t)}{\lceil 12\,b\,(\log b+t)\rceil}\leq\frac{13\,(\log j+t)}{j}\,,

where we used
j>12\,b\geq b
for
\log b<\log j
and
49\cdot 12/48<13
.
This completes the proof.
∎

In
Theorem

4.5
the spectral norm of an infinite-dimensional matrix
\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}
occurs.
We have

\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}=\|\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\|_{2}=\|\bm{\Phi}_{\mathcal{B}}\,\bm{\Phi}_{\mathcal{B}}^{\ast}\|_{2}\,,

where the first matrix product is infinite-dimensional, whereas the second matrix-product is finite-dimensional (may be used for computing the spectral norm numerically).
In the following lemma we use the former to show that this quantity can be upper bounded in terms of the known quantity
\mathcal{S}_{n}(\bm{z})
from (
2.5
).
Note that the reconstructing property is not needed in this lemma.

Lemma 4.6
.

Let
\mathcal{B}\subseteq\mathds{Z}^{d}
be a frequency index set and
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
a lattice.
Further let
\bm{\Phi}_{\mathcal{B}}\coloneqq\bm{\Phi}_{\{0,\dots,n-1\},\mathcal{B}}
be as in (
4.3
) and
\mathcal{S}_{n}(\bm{z})
as in (
2.5
).
Then

\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\sqrt{\mathcal{S}_{n}(\bm{z})}\,.

Proof.

By the definition of
\bm{\Phi}_{\mathcal{B}}
, we have

\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}=\Big\|\frac{1}{n}\bm{\Phi}_{\mathcal{B}}^{\ast}\,\bm{\Phi}_{\mathcal{B}}\Big\|_{2}=\Big\|\Big[\frac{1}{n}\sum_{k=0}^{n-1}\frac{\exp(2\pi\mathrm{i}\tfrac{k}{n}\langle\bm{h}^{\prime}-\bm{h},\bm{z}\rangle)}{\sqrt{r(\bm{h})\,r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\notin\mathcal{B}}\Big\|_{2}\,.

By the character property
\frac{1}{n}\sum_{k=0}^{n-1}\exp(2\pi\mathrm{i}m\tfrac{k}{n})=\delta_{m\equiv_{n}0}
this evaluates to

\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}=\Big\|\Big[\frac{\delta_{\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle}}{\sqrt{r(\bm{h})\,r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\notin\mathcal{B}}\Big\|_{2}\,.

Now we split this matrix into its diagonal and off-diagonal terms

\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}\leq\Big\|\Diag\Big(\frac{1}{r(\bm{h})}\Big)_{\bm{h}\notin\mathcal{B}}\Big\|_{2}+\Big\|\Big[\frac{\delta_{\bm{h}\neq\bm{h}^{\prime}}\delta_{\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle}}{\sqrt{r(\bm{h})\,r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\notin\mathcal{B}}\Big\|_{2}\,.

The spectral norm of the diagonal matrix is known and for the off-diagonal matrix we estimate it by the Frobenius norm

\displaystyle\frac{1}{n}\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}

\displaystyle\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\Big\|\Big[\frac{\delta_{\bm{h}\neq\bm{h}^{\prime}}\delta_{\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle}}{\sqrt{r(\bm{h})\,r(\bm{h}^{\prime})}}\Big]_{\bm{h},\bm{h}^{\prime}\in\mathds{Z}^{d}}\Big\|_{F}

\displaystyle=\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\Big(\sum_{\bm{h}\in\mathds{Z}^{d}}\sum_{\begin{subarray}{c}\bm{h}^{\prime}\in\mathds{Z}^{d}\\
\bm{h}^{\prime}\neq\bm{h}\end{subarray}}\frac{\delta_{\langle\bm{h},\bm{z}\rangle\equiv_{n}\langle\bm{h}^{\prime},\bm{z}\rangle}}{r(\bm{h})\,r(\bm{h}^{\prime})}\Big)^{1/2}

\displaystyle=\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\Big(\sum_{\bm{h}\in\mathds{Z}^{d}}\frac{1}{r(\bm{h})}\sum_{\begin{subarray}{c}\bm{\ell}\in\mathds{Z}^{d}\setminus\{\bm{0}\}\\
\langle\bm{\ell},\bm{z}\rangle\equiv_{n}0\end{subarray}}\frac{1}{r(\bm{h}+\bm{\ell})}\Big)^{1/2}\,,

where the second term is exactly
\sqrt{\mathcal{S}_{n}(\bm{z})}
as claimed.
∎

Now we fix the frequency set
\mathcal{B}
to be as in
Corollary

3.3
, where we have guaranteed reconstructing property, allowing us to omit it in the assumptions.

Theorem 4.7
.

Let
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
be a lattice and
\mathcal{S}_{n}(\bm{z})
as in (
2.5
).
Further, let
H
be the function space defined in (
2.3
) and fix

\mathcal{B}\coloneqq\Big\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})\,\leq\,\frac{1}{2\sqrt{\mathcal{S}_{n}(\bm{z})}}\Big\}\,.

For
t\geq 4
, let
J\subseteq\{0,\dots,n-1\}
be a multiset of uniformly i.i.d. drawn integers with

|J|:=\lceil 12\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)\rceil\,.

Then the least squares approximation defined in (
4.1
) using samples on the subsampled lattice
\bm{X}_{J}
satisfies with probability exceeding
1-3\exp(-t)
that

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq 14\sqrt{\mathcal{S}_{n}(\bm{z})}+\frac{7}{|\mathcal{B}|}\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}\,.

Proof.

By
Corollary

3.3
we know that
\bm{X}
has the reconstructing property for
\mathcal{B}
.
Thus, we can apply
Theorem

4.5
, where we plug in
Lemma

4.6
for estimating
\|\bm{\Phi}_{\mathcal{B}}\|_{2}^{2}
and obtain with the desired probability

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\frac{7}{|\mathcal{B}|}\sum_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+4\Big(\sup_{\bm{h}\notin\mathcal{B}}\frac{1}{r(\bm{h})}+\sqrt{\mathcal{S}_{n}(\bm{z})}\Big)\,.

By the definition of
\mathcal{B}
, we have
\sup_{\bm{h}\notin\mathcal{B}}1/r(\bm{h})\leq 2\sqrt{\mathcal{S}_{n}(\bm{z})}
, which, when plugged in the above estimate, yields the assertion.
∎

Remark 4.8
.

Following the same proof, it is easily seen, that
Theorem

4.7
still holds if we replace
\mathcal{S}_{n}(\bm{z})
by any upper estimate, even though it changes the definition of
\mathcal{B}
and with that the underlying method.

Note that the occurrence of the quantity
1/|\mathcal{B}|\sum_{\bm{h}\notin\mathcal{B}}1/r(\bm{h})
in
Theorem

4.7
is natural, since there exist function spaces where this is a lower bound on the sampling numbers with
|\mathcal{B}|
samples, cf.
[
18
, Theorem 2]
.
Comparing the full lattice algorithm
Theorem

2.1
with
Theorem

4.7
, both bounds depend on the term
\sqrt{\mathcal{S}_{n}(\bm{z})}
.
The difference is in the number of used samples being
|J|
in the new algorithm instead of
n
, with
|J|
usually far less than
n
, as we will see in
Section

5
.

5
Application to weighted Korobov spaces

In this section we apply the general theory to weighted Korobov spaces to obtain double the main rate of convergence for the subsampled lattice in comparison to the full lattice.
For dimension
d\in\mathds{N}
, smoothness
\alpha>1/2
, and weight parameters
\bm{\gamma}=\{\gamma_{\mathfrak{u}}\}_{\mathfrak{u}\subseteq\mathds{N}}
, the
weighted Korobov space
is defined by

H_{d,\alpha,\bm{\gamma}}\coloneqq\Big\{f\colon\mathds{T}^{d}\to\mathds{C}:\|f\|_{d,\alpha,\bm{\gamma}}^{2}=\sum_{\bm{h}\in\mathds{Z}^{d}}r_{d,\alpha,\bm{\gamma}}(\bm{h})\,|\widehat{f}_{\bm{h}}|^{2}<\infty\Big\}\,,

(5.1)

with

r_{d,\alpha,\bm{\gamma}}(\bm{h})\coloneqq\gamma_{\Supp(\bm{h})}^{-1}\prod_{j\in\Supp(\bm{h})}|h_{j}|^{2\alpha}\quad\text{and}\quad\Supp(\bm{h})\coloneqq\Big\{j\in\{1,\dots,d\}:h_{j}\neq 0\Big\}\,.

(5.2)

Here, the weight
\gamma_{\mathfrak{u}}
controls the importance of the part of the function
f
which only depends on the variables
\bm{x}_{\mathfrak{u}}=[x_{j}]_{j\in\mathfrak{u}}
.
We fix
\gamma_{\emptyset}\coloneqq 1
such that
\|1\|_{d,\alpha,\bm{\gamma}}=\|1\|_{L_{2}}
.
For integer
\alpha\in\mathds{N}
it is known that

\|f\|_{d,\alpha,\bm{\gamma}}^{2}=\sum_{\mathfrak{u}\subseteq\{1,\dots,d\}}\frac{1}{(2\pi)^{\alpha|\mathfrak{u}|}}\frac{1}{\gamma_{\mathfrak{u}}}\int_{[0,1]^{|\mathfrak{u}|}}\Big|\int_{[0,1]^{d-|\mathfrak{u}|}}\Big(\prod_{j\in\mathfrak{u}}\frac{\partial}{\partial x_{j}}\Big)^{\alpha}f(\bm{x})\;\mathrm{d}\bm{x}_{\{1,\dots,d\}\setminus\mathfrak{u}}\Big|^{2}\;\mathrm{d}\bm{x}_{\mathfrak{u}}\,.

Korobov spaces describe a wide class of functions, with various forms of weights
\bm{\gamma}
used throughout literature, such as

•

\gamma_{\mathfrak{u}}=1
for all
\mathfrak{u}\subseteq\mathds{N}
: these spaces coincide with classical (unweighted) periodic Sobolev spaces with dominating mixed smoothness, see e.g.,
[
13
]
;

•

\gamma_{\mathfrak{u}}=\prod_{j\in\mathfrak{u}}\gamma_{j}
with a positive sequence
(\gamma_{j})_{j\geq 1}
: these are called product weights, see e.g.,
[
40
,
44
]
;

•

\gamma_{\mathfrak{u}}=\Gamma_{|\mathfrak{u}|}
for a sequence
(\Gamma_{\ell})_{\ell\geq 0}
: they are called order dependent weights, see e.g.,
[
11
]
;

•

combining product and order dependent weights yield POD weights
\gamma_{\mathfrak{u}}=\Gamma_{|\mathfrak{u}|}\prod_{j\in\mathfrak{u}}\gamma_{j}
, see e.g.,
[
32
,
15
,
31
,
16
]
;

•

further including the smoothness parameter yields smoothness driven product and order dependent (SPOD) weights
\gamma_{\mathfrak{u}}=\sum_{\bm{\nu}_{\mathfrak{u}}\in\{1,\dots,\alpha\}^{|\mathfrak{u}|}}\Gamma_{\|\bm{\nu}_{\mathfrak{u}}\|_{1}}\prod_{j\in\mathfrak{u}}\gamma_{j,\nu_{j}}
, see e.g.,
[
9
,
10
,
19
]
.

For the classical periodic Sobolev spaces of dominating mixed smoothness, it is known that the worst-case error behaves asymptotically as
n^{-\alpha}(\log n)^{\alpha(d-1)}
when the approximation is based on
n
measurements from arbitrary linear functionals.
This includes function evaluations as well as Fourier coefficients, see e.g.,
[
38
]
or
[
13
, Section 4.1]
.
It was finally shown in
[
12
]
that the same rate of convergence can be attained when the approximation was limited to use function evaluations.
This result is a non-constructive existence result for the points used in the approximation.

On the other hand, it was shown in
[
3
, Proposition 3.3]
that for an approximation based on a full lattice the worst-case error can be bounded from below by
n^{-\alpha/2}
.
Thus, using the full lattice halves the polynomial rate of convergence.

It was already shown in
[
1
]
, that the optimal polynomial rate can be recovered using a subset of the initial lattice given that the initial lattice is large enough.
In particular, in
[
1
]
a lattice of size
n\gtrsim|J|^{2/(1-1/(2\alpha))}
is necessary.
We will show in
Theorem

5.3
that the optimal polynomial rate
(|J|/\log|J|)^{-\alpha+\varepsilon}
can be recovered using only an initial lattice of size
n\lesssim\,(|J|/\log|J|)^{2/\sqrt{1-\varepsilon/\alpha}}
for any
0<\varepsilon<\alpha
.

In order to apply our general result on subsampled lattices, we first present known results for the full lattice.
Note that the parameter
\alpha
in
[
30
]
is
2\alpha
in this paper.

Theorem 5.1

(
[
30
, Theorem 3.3]
)
.

Given
n\geq 2
,
d\in\mathds{N}
,
\alpha>1/2
and weights
\bm{\gamma}=\{\gamma_{\mathfrak{u}}\}_{\mathfrak{u}\subseteq\mathds{N}}
, the generating vector
\bm{z}
obtained from the CBC construction following
[
30
, Algorithm 3.2]
satisfies

\frac{2\zeta(2\alpha)\gamma_{\{1\}}}{n^{2\alpha}}\leq\mathcal{S}_{n}(\bm{z})\leq\Big(\frac{\tau_{\lambda}\,C_{\lambda}^{2}}{\varphi(n)}\Big)^{1/\lambda}\quad\mbox{for all}\quad\tfrac{1}{2\alpha}<\lambda\leq 1\,,

where
\varphi(n)=|\{z\in\{1,\ldots,n\}:\gcd(z,n)=1\}|
is the Euler totient function (e.g.,
\varphi(n)=n-1
for
n
prime),
\zeta(x)=\sum_{h=1}^{\infty}h^{-x}
is the Riemann zeta function,
\tau_{\lambda}=2^{4\alpha\lambda+1}+1
, and

C_{\lambda}=C_{d,\alpha,\bm{\gamma},\lambda}\coloneqq\sum_{\mathfrak{u}\subseteq\{1,\dots,d\}}\max\{1,|\mathfrak{u}|\}\,\gamma_{\mathfrak{u}}^{\lambda}\,(2\zeta(2\alpha\lambda))^{|\mathfrak{u}|}\,.

(5.3)

Proof.

The trivial lower bound is obtained by keeping only the
\bm{h}=\bm{0}
and
{\bm{\ell}}=[\ell_{1},0,\ldots,0]
terms in (
2.5
) together with
z_{1}=1
.
A CBC upper bound for
\mathcal{S}_{n}(\bm{z})
was first proved in
[
8
]
for product weights, in
[
6
]
for general weights, both for prime
n
, and in
[
30
]
for composite
n
.
∎

Applying the estimate on
\mathcal{S}_{n}(\bm{z})
from
Theorem

5.1
to
Theorem

2.1
achieves the order of convergence
n^{-\alpha/2+\varepsilon}
for the full lattice, which is half the optimal order.

Lemma 5.2

(
[
30
, Lemmata 5.2 and 5.3]
)
.

Let
M\geq 1
,
\alpha>1/2
, and

\mathcal{A}_{d,\alpha,\bm{\gamma},M}\coloneqq\Big\{\bm{h}\in\mathds{Z}^{d}:r_{d,\alpha,\bm{\gamma}}(\bm{h})\leq M\Big\}\,.

Then we have for
1/(2\alpha)<\lambda<1

and
C_{\lambda}=C_{d,\alpha,\bm{\gamma},\lambda}
from (
5.3
) that

(\gamma_{\{1\}}M)^{1/(2\alpha)}\leq|\mathcal{A}_{d,\alpha,\bm{\gamma},M}|\leq C_{\lambda}M^{\lambda}

and

\frac{1}{|\mathcal{A}_{d,\alpha,\bm{\gamma},M}|}\sum_{\bm{h}\notin\mathcal{A}_{d,\alpha,\bm{\gamma},M}}\frac{1}{r_{d,\alpha,\bm{\gamma}}(\bm{h})}\leq\Big(\frac{C_{\lambda}^{1/\lambda}}{\gamma_{\{1\}}^{1/(2\alpha\lambda)}}\cdot\frac{\lambda}{1-\lambda}\Big)\Big(\frac{1}{M}\Big)^{-\frac{1}{2\alpha\lambda}}\,.

Note, in the original
[
30
, Lemma 5.2]
the constant
C_{\lambda}
equals
\sum_{\mathfrak{u}\subseteq\{1,\dots,d\}}\gamma_{\mathfrak{u}}^{\lambda}\,(2\zeta(2\alpha\lambda))^{|\mathfrak{u}|}
.
Here we used an upper estimate (
5.3
) to simplify our presentation.

We now present the main result of this section which bounds the worst-case error for a subsampled lattice achieving optimal polynomial rate using the smallest initial lattice size.

Theorem 5.3
.

Let
H
be the Korobov function space defined in (
5.1
) with
\alpha>1/2
and weights
{\bm{\gamma}}=({\bm{\gamma}}_{\mathfrak{u}})_{j\in{\mathfrak{u}}}
.
Let
\bm{X}=\{\frac{k}{n}\bm{z}\bmod{}1\}_{k=0}^{n-1}\subseteq\mathds{T}^{d}
be a lattice with
n\geq 7

sufficiently large so that
\mathcal{S}_{n}({\bm{z}})=\mathcal{S}_{d,\alpha,{\bm{\gamma}},n}({\bm{z}})\leq 1/4
, and let

\mathcal{B}\coloneqq\mathcal{B}_{d,\alpha,{\bm{\gamma}},n}\coloneqq\Big\{\bm{h}\in\mathds{Z}^{d}:r_{d,\alpha,\bm{\gamma}}(\bm{h})\leq\frac{1}{2\sqrt{\mathcal{S}_{n}(\bm{z})}}\Big\}\,.

For
t\geq 4
, let
J\subseteq\{0,\dots,n-1\}
be a multiset of uniformly i.i.d. drawn integers with

|J|\coloneqq\lceil 12\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)\rceil\,.

Then the least squares approximation defined in (
4.1
) using samples on the subsampled lattice
\bm{X}_{J}
satisfies with probability exceeding
1-3\exp(-t)
that

e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}\leq 7\Big(1+\frac{C_{\lambda}^{1/\lambda}}{\gamma_{\{1\}}^{1/(2\alpha\lambda)}}\cdot\frac{\lambda}{1-\lambda}\Big)\,(13\,C_{\lambda})^{\frac{1}{2\alpha\lambda^{2}}}\,\Big(\frac{\log|J|+t}{|J|}\Big)^{\frac{1}{2\alpha\lambda^{2}}}

(5.4)

for all
1/(2\alpha)<\lambda<1
, with
C_{\lambda}=C_{d,\alpha,\bm{\gamma},\lambda}
from (
5.3
).
Moreover, if
\bm{z}
is constructed according to
[
30
, Algorithm 3.2]
, we have (with
\varphi(n)
again denoting the Euler totient function)

(\varphi(n))^{\frac{1}{4\alpha\lambda}}\,\log\varphi(n)\lesssim|J|\lesssim n^{\alpha\lambda}\log n\,,

(5.5)

and hence

\Big(\frac{|J|}{\log|J|}\Big)^{\frac{1}{\alpha\lambda}}\lesssim n\quad\mbox{and}\quad\varphi(n)\lesssim\Big(\frac{|J|}{\log|J|}\Big)^{4\alpha\lambda}

(5.6)

Proof.

For the index set
{\mathcal{B}}
with radius
M:=1/(2\sqrt{\mathcal{S}_{n}({\bm{z}})})\geq 1
,
Lemma

5.2
gives for all
1/(2\alpha)<\lambda<1
,

(\gamma_{\{1\}}\,M)^{1/(2\alpha)}\leq|{\mathcal{B}}|\leq C_{\lambda}\,M^{\lambda}\quad\Leftrightarrow\quad\frac{\gamma_{\{1\}}}{|{\mathcal{B}}|^{2\alpha}}\leq\frac{1}{M}\leq\Big(\frac{C_{\lambda}}{|{\mathcal{B}}|}\Big)^{1/\lambda}\,.

Theorem

4.7
and
Lemma

5.2
then yield

\displaystyle e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})^{2}

\displaystyle\leq\frac{7}{M}+7\Big(\frac{C_{\lambda}^{1/\lambda}}{\gamma_{\{1\}}^{1/(2\alpha\lambda)}}\cdot\frac{\lambda}{1-\lambda}\Big)\Big(\frac{1}{M}\Big)^{\frac{1}{2\alpha\lambda}}

\displaystyle\leq 7\Big(1+\frac{C_{\lambda}^{1/\lambda}}{\gamma_{\{1\}}^{1/(2\alpha\lambda)}}\cdot\frac{\lambda}{1-\lambda}\Big)\Big(\frac{C_{\lambda}}{|{\mathcal{B}}|}\Big)^{\frac{1}{2\alpha\lambda^{2}}}\,,

from which the bound (
5.4
) is obtained using the upper bound on
1/|{\mathcal{B}}|
in (
4.8
).

Next we relate
|{\mathcal{B}}|
to the bounds on
M=1/(2\sqrt{\mathcal{S}_{n}(\bm{z})})
from
Theorem

5.1
, to obtain

\Big(\frac{\varphi(n)}{\tau_{\lambda}\,C_{\lambda}^{2}}\Big)^{\frac{1}{4\alpha\lambda}}\Big(\frac{\gamma_{\{1\}}}{2}\Big)^{\frac{1}{2\alpha}}\leq\Big(\frac{\gamma_{\{1\}}}{2\sqrt{\mathcal{S}_{n}(\bm{z})}}\Big)^{\frac{1}{2\alpha}}\leq|\mathcal{B}|\leq C_{\lambda}\Big(\frac{1}{2\sqrt{\mathcal{S}_{n}(\bm{z})}}\Big)^{\lambda}\leq\frac{C_{\lambda}\,n^{\alpha\lambda}}{(8\zeta(2\alpha)\gamma_{\{1\}})^{\lambda/2}}\,.

Since
12\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)\leq|J|\leq 13\,|\mathcal{B}|\,(\log|\mathcal{B}|+t)
, we obtain (
5.5
) and (
5.6
).
∎

In particular, for
n
prime, we have
(|J|/\log|J|)^{1/(\alpha\lambda)}\lesssim n\lesssim(|J|/\log|J|)^{4\alpha\lambda}
. Substituting

for

, we obtain the convergence rate
(|J|/\log|J|)^{-\alpha+\varepsilon}
with

(|J|/\log|J|)^{2\sqrt{1-\varepsilon/\alpha}}\lesssim n\lesssim(|J|/\log|J|)^{2/\sqrt{1-\varepsilon/\alpha}}
, where the exponent is arbitrarily close to
2
.

Note that for small
n
it is possible for the theoretically defined value of
|J|
to be bigger than
n
. Additionally, the constants in the asymptotic bounds (
5.5
) and (
5.6
) are quite loose. Later in our numerical experiments we will choose instead
|J|=\lceil\sqrt{n}\,\log(n)\rceil
.

6
Implementation and computational cost

The goal of subsampling from a lattice is to make use of the underlying structure, where fast and memory-efficient algorithms are applicable.
Without that structure uniformly generated random points would suffice for a similar error bound, cf.
[
29
,
27
]
.

Both the least squares approximation and the kernel method involve solving a system of equations.
For the full lattice closed form solutions are known, but for the subsampled lattice it seems that an analytical inverse is not available.
Direct solvers would have a cubic runtime with respect to the number of points
|J|
.
Instead, we will apply iterative methods: the least squares (
LSQR
)
[
35
]
and the conjugate gradient (
CG
)
[
17
]
methods, where only matrix-vector products are needed.
The following result bounds the number of necessary iterations depending on the desired accuracy.

Theorem 6.1

(
[
17
, Theorem 3.1.1]
)
.

Let
\bm{A}
be a Hermitian positive definite matrix with condition number
\kappa_{2}(\bm{A})=\lambda_{\max}(\bm{A})/\lambda_{\min}(\bm{A})
.
Further, let
\bm{x}^{(i)}
be the
i
-th iterate of the conjugate gradient (
CG
) method applied to the system of equations
\bm{A}\bm{\tilde{x}}=\bm{b}
.
Then it holds

\frac{\|\bm{x}^{(i)}-\bm{\tilde{x}}\|_{2}}{\sqrt{\kappa_{2}(\bm{A})}\|\bm{\tilde{x}}\|_{2}}\leq\sqrt{\frac{(\bm{x}^{(i)}-\bm{\tilde{x}})^{\ast}\bm{A}\,(\bm{x}^{(i)}-\bm{\tilde{x}})}{(\bm{\tilde{x}})^{\ast}\bm{A}\,\bm{\tilde{x}}}}\leq 2\Big(\frac{\sqrt{\kappa_{2}(\bm{A})}-1}{\sqrt{\kappa_{2}(\bm{A})}+1}\Big)^{i}\leq 2\exp\Big(-\frac{2i}{\sqrt{\kappa_{2}(\bm{A})}}\Big)\,.

Proof.

The first inequality follows from
\lambda_{\min}(\bm{B})\|\bm{x}\|_{2}\leq\|\bm{B}\bm{x}\|_{2}\leq\lambda_{\max}(\bm{B})\|\bm{x}\|_{2}
for any Hermitian positive definite matrix
\bm{B}
and vector
\bm{x}
.
The second inequality is the statement of
[
17
, Theorem 3.1.1]
.
For the last inequality, we need that for
x\geq 1

\frac{x-1}{x+1}\leq\exp\Big(\!-\frac{2}{x}\,\Big)\,,

or equivalently

g(x)\coloneqq\log\Big(\frac{x-1}{x+1}\Big)+\frac{2}{x}\leq 0\,.

For
x
approaching
1
the statement is true.
For
x>1
, we have
g^{\prime}(x)>0
.
Together with
\lim_{x\to\infty}g(x)=0
this gives the assertion.
∎

The
LSQR
method is analytically equivalent to applying
CG
to the normal equation but in a numerically more stable manner, cf.
[
35
]
.
Thus the iteration bound in
Theorem

6.1
holds for
LSQR
with the minimal and maximal eigenvalue replaced by the squared singular numbers.

6.1
Fast least squares approximation with subsampled lattices

In this section we discuss how to compute the least squares approximation for a subsampled lattice making use of the Fast Fourier Transform (
FFT
).
Let
\mathcal{B}\coloneqq\{\bm{h}\in\mathds{Z}^{d}:r(\bm{h})\leq M\}

The approximation is computed once the Fourier coefficients

Because of the downward-closed structure, this can be set up incrementally in dimension.
For the step from dimension

Note, when using the full lattice an iterative solver is not needed, since we have by the reconstructing property
(\bm{L}_{\mathcal{B}}^{\ast}\,\bm{L}_{\mathcal{B}}^{\ast})^{-1}=(1/n)\,\bm{I}
.
This can be also viewed as
LSQR
converging with one iteration because
\kappa_{2}(\bm{L}_{\mathcal{B}}^{\ast}\,\bm{L}_{\mathcal{B}})=1
in
Theorem

6.1
.
Thus, using the full lattice has computational cost
\mathcal{O}(n\log n)
as well.

6.2
Fast kernel method with subsampled lattices

We further comment on the kernel method, which we introduced in
Section

2
for the full lattice.
Since
H_{d,\alpha,\bm{\gamma}}
is a reproducing kernel Hilbert space, it has an associated reproducing kernel
K(\cdot,\cdot)=K_{d,\alpha,\bm{\gamma}}(\cdot,\cdot)
.
For integer smoothness
\alpha\in\mathds{N}
, a simple closed form is known:

K(\bm{x},\bm{y})=\!\!\sum_{\mathfrak{u}\subseteq\{1,\dots,d\}}\!\!\gamma_{\mathfrak{u}}\prod_{j\in\mathfrak{u}}\eta_{\alpha}(x_{j},x_{j}^{\prime})\quad\text{with}\quad\eta_{\alpha}(x,x^{\prime})=\frac{(2\pi)^{2\alpha}B_{2\alpha}((x-x^{\prime})\bmod{}1)}{(-1)^{\alpha+1}(2\alpha)!}\,,

where
B_{2\alpha}
is the Bernouilli polynomial of degree
2\alpha
.

The
kernel approximation
of
f
based on the sampling set
\bm{X}_{J}
is defined analogously to (
2.7
) by

A_{\text{ker}}^{\bm{X}_{J}}f\coloneqq\sum_{k\in J}a_{k}\,K(\cdot,\tfrac{k}{n}\bm{z}\bmod{}1)\quad\text{with}\quad\bm{a}=(a_{k})_{k\in J}=\bm{K}_{J}^{-1}\bm{f}_{J}

(6.2)

where
\bm{K}_{J}=[K(\tfrac{k}{n}\bm{z}\bmod{}1,\tfrac{k^{\prime}}{n}\bm{z}\bmod{}1)]_{k,k^{\prime}\in J}
is the so-called kernel matrix and
\bm{f}_{J}=[f(\tfrac{k}{n}\bm{z}\bmod{}1)]_{k\in J}
.

As discussed in
Section

2
, the kernel method is optimal in the worst-case setting for any given set of points.
In particular, the bound from
Theorem

5.3
applies as well, since
e^{\mathrm{wor-app}}(A_{\text{ker}}^{\bm{X}_{J}})\leq e^{\mathrm{wor-app}}(S_{\mathcal{B}}^{\bm{X}_{J}})
.
Similar to
\bm{L}_{J,\mathcal{B}}
, a fast multiplication with the kernel matrix for the full lattice is known, since
\bm{K}_{\{0,\dots,n-1\}}
is a circulant matrix, cf.
[
20
, Table 1]
, with a computational cost of

\mathcal{O}(n\log n)\text{ flops and }\mathcal{O}(n)\text{ memory requirements}.

The algorithm for the full lattice can be used for the subsampled kernel matrix as well.
We have

\bm{K}_{J}=\bm{P}\bm{K}_{\{0,\dots,n-1\}}\bm{P}^{\ast}\,,

with
\bm{P}
as in (
6.1
).
The cost for evaluating the kernel will depend on the structure of the weights
\gamma_{\mathfrak{u}}
, ranging from linear in
d
for product weights to quadratic in
d
for POD and SPOD weights, see
[
20
, Table 1]
.

In contrast to the least squares matrix
\bm{L}_{J,\mathcal{B}}
, the condition number of the kernel matrix
\bm{K}_{J}
grows in the number of points, resulting in the need for many iterations or the necessity of preconditioning, cf.
[
43
, Section 12.2]
.
Thus, the number of necessary
CG
iterations cannot be bounded by a general constant according to
Theorem

6.1
.

With
|J|\sim\sqrt{n}\log n
as in
Theorem

5.3
, we obtain the computational cost in the lower two rows of
Table

1
when using the
FFT
compared to the naive matrix-vector product when using
r
iterations.

6.3
Comparison to full-lattice methods

From
Theorem

5.3
we know that subsampling allows for a better sampling complexity.
However, picking the best method in regards to computational cost also depends on whether functions evaluations are expensive.
To discuss this balancing, we split the computations into five steps and address their individual computational cost.
This gives the following for the least squares approximation and the kernel method with the full and subsampled lattice, which is summarized in
Table

2
.

(i)

Point construction.

All methods use the CBC construction from
[
14
]
with different cost depending on the type of weights as shown in the first row of
Table

2
.
The additional cost for creating the subsampled indices is negligible.

(ii)

The sampling of the function to approximate.

When
f_{\text{cost}}
models the cost of a single function evaluation, this has to be multiplied by the number of samples used by the approximation.
For the full lattice these are
n
points and for the subsampled lattice we have
|J|\sim\sqrt{n}\log n
points, cf.
Theorem

5.3
.

(iii)

The function-independent setup.

These computations may depend on a pre-defined function class but can be used for any function thereof.
This becomes important when multiple instances need to be approximated.

For the least squares approximation this involves the construction of the frequency index set
\mathcal{B}
and the computation of the inner products with the generating vector
\bm{z}
.
As discussed in
Section

6.1
this can be done incrementally in dimension with a cost of
d\,|\mathcal{B}|
, where
|\mathcal{B}|\sim\sqrt{n}
in our case.

For the kernel method the entries of the kernel matrix
\bm{K}_{J}
have to be computed, where the cost of one single kernel evaluation depends on the weight parameters, cf.
[
20
, Table 1]
.
Because we have
K(\frac{k}{n}\bm{z}\bmod{}1,\frac{k^{\prime}}{n}\bm{z}\bmod{}1)=K(\frac{k-k^{\prime}}{n}\bm{z}\bmod{}1,\bm{0})
, the number of different values equals
|\{(k-k^{\prime})\bmod n:k,k^{\prime}\in J\}|
.
For the full lattice this evaluates to
n
.
For the randomly subsampled lattice with
|J|\sim\sqrt{n}\log n
we might have
|\{(k-k^{\prime})\bmod n:k,k^{\prime}\in J\}|=n
as well.

(iv)

The computation of the coefficients.

At this step the approximation is obtained from the sampled function values using the function-independent setup and encoded in a respective representation.
The least squares approximation is described by its Fourier coefficients
[\widehat{g}_{\bm{h}}]_{\bm{h}\in\mathcal{B}}
and the kernel method by the coefficients
[a_{k}]_{k\in J}
(where
J=\{0,\dots,n-1\}
for the full lattice).
These coefficients are defined by the solution of the systems of equations in
Lemma

4.1
and (
2.7
), respectively.
For the full lattice the involved inverse matrices are known in closed form as discussed in
Section

6.1
and
Section

2
, which results in a computational cost of an
FFT
for the computation of the coefficients.

For the subsampled methods we use the iterative schemes described in
Section

6.1
and
Section

6.2
.
In case of the least squares method, the number of iterations is bounded and by a general constant.
For kernel method more iterations are needed when the number of points increases, as the kernel matrix is worse conditioned for an increasing number of points.
In
Table

2
the number of iterations for the kernel method is denoted by
r
.

(v)

The evaluation of the approximation.

This describes the cost of evaluating the approximation in a single unseen data point
\bm{x}\in\mathds{T}^{d}
.
For the least squares approximation this involves evaluating

(S_{\mathcal{B}}^{\bm{X}_{J}}f)(\bm{x})=\sum_{\bm{h}\in\mathcal{B}}\widehat{g}_{\bm{h}}\exp(2\pi\mathrm{i}\langle\bm{h},\bm{x}\rangle)

with a cost of
d\,|\mathcal{B}|
, with
|\mathcal{B}|\sim\sqrt{n}
in our case.

For the kernel method we need to evaluate
\sum_{k\in J}a_{k}\,K(\bm{x},\tfrac{k}{n}\bm{z}\bmod{}1)
, which needs
|J|
evaluations of the kernel with
|J|=\{0,\dots,n-1\}
for the full lattice.

Note that for a given
n

\sqrt[4]{S_{n}(\bm{z})}
, cf.
Theorems

2.1
and
5.3
.

7
Numerical results

In this section we test the proposed algorithms in order to verify our theoretical results by comparing

•

the classical lattice algorithm (
2.1
) using the full lattice, with frequency index set
\mathcal{A}=\{\bm{h}\in\mathds{Z}^{d}:r_{d,\alpha,\bm{\gamma}}(\bm{h})\leq M\}
and
M=1/\sqrt{\mathcal{S}_{n}(\bm{z})}
,

•

the least squares approximation (
4.1
) using the full and subsampled lattice where the frequency index set
\mathcal{B}=\{\bm{h}\in\mathds{Z}^{d}:r_{d,\alpha,\bm{\gamma}}(\bm{h})\leq M\}
and
M=1/(2\sqrt{\mathcal{S}_{n}(\bm{z})})
is chosen as in
Theorem

5.3
, and

•

the kernel method (
2.7
) with both the full and subsampled lattice.

With
n
being the next biggest prime from a power of 2, we compute the generating vector for a lattice using the CBC algorithm from
[
14
]
rather than the original algorithm from
[
6
]
.
The new algorithm has the advantages that it is much simpler to implement, is extensible to any dimension
d
, and (especially for SPOD weights) is cheaper to run.
Empirically it gives similar
L_{2}
-approximation error bounds, but equivalent theoretical error bounds are yet to be proven.
For the methods using subsampled points, we generate a random subset of size
|J|=\lceil\sqrt{n}\,\log n\rceil
, which is of the same order as in
Theorem

5.3
but ignores the involved constants.
The
L_{2}
-error is then estimated using
50
random shifts of the initial lattice,

\int_{\mathds{T}^{d}}|(f-A(f))(\bm{x})|^{2}\;\mathrm{d}\bm{x}\approx\frac{1}{50n}\sum_{i=1}^{50}\sum_{k=0}^{n-1}|(f-A(f))((\tfrac{k}{n}\bm{z}+\bm{\Delta}_{i})\bmod{}1)|^{2}\,,

where
\bm{\Delta}_{i}\in\mathds{T}^{d}
for
i=1,\dots,50
are chosen independently and uniformly random.
For the kernel method the evaluation at the shifted lattice can be done by the same fast methods as for the original lattice used in the approximation, cf.
[
20
, Section 5]
.
The least squares approximation can be evaluated at any lattice fast using the
LFFT
.

The implementation is done in Julia with the
CG
and
LSQR
implementation used from
[
4
]
.
All the computations were carried out on a high performance computer cluster
[
37
]
with eight parallel threads.

8
Concluding remarks

In this paper we used random subsampling to regain the optimal polynomial order of convergence for lattices while still maintaining the structure to apply fast Fourier algorithms.
The focus is on having a small initial lattice size, which determines the computational complexity of the approximation algorithms. We used the least squares approximation and the kernel method.
For Korobov spaces we achieve the optimal polynomial order of convergence
(|J|/\log|J|)^{-\alpha+\varepsilon}
for
0<\varepsilon<\alpha
, with the initial lattice size
n\lesssim(|J|/\log|J|)^{2/\sqrt{1-\varepsilon/\alpha}}
, which is arbitrarily close to quadratic in terms of the actual subsampled point set size
|J|
.
This improves on earlier results in
[
1
]
, where there is a polynomial gap for the initial lattice size.

Similar to
[
1
]
one could use further subsampling techniques from
[
2
]
or even the non-constructive techniques from
[
12
]
in order to improve on the logarithmic rate in the error bound.
Further, in the numerics the constants for the oversampling were ignored while still achieving the theoretical error rates.
This indicates possible improvement for the constants.
