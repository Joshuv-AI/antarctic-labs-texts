Graph-based Signal Sampling with Adaptive Subspace Reconstruction for Spatially-irregular Sensor Data
Darukeesan Pakiyarajah, Eduardo Pavez, Antonio Ortega

Abstract
Choosing an appropriate frequency definition and norm is critical in graph signal sampling and reconstruction. Most previous works define frequencies based on the spectral properties of the graph and use the same frequency definition and ℓ 2 \ell_{2} -norm for optimization for all sampling sets. Our previous work demonstrated that using a sampling set-adaptive norm and frequency definition can address challenges in classical bandlimited approximation, particularly with model mismatches and irregularly distributed data. In this work, we propose a method for selecting sampling sets tailored to the sampling set adaptive GFT-based interpolation. When the graph models the inverse covariance of the data, we show that this adaptive GFT enables localizing the bandlimited model mismatch error to high frequencies, and the spectral folding property allows us to track this error in reconstruction. Based on this, we propose a sampling set selection algorithm to minimize the worst-case bandlimited model mismatch error. We consider partitioning the sensors in a sensor network sampling a continuous spatial process as an application. Our experiments show that sampling and reconstruction using sampling set adaptive GFT significantly outperform methods that used fixed GFTs and bandwidth-based criterion.

2.1
Graph signals and
({\bf M},{\bf Q})
-GFTs

Let
{\cal G}=({\cal V},{\cal E})

is the vertex set, and

is the weight of the edge between vertex

m_{ij}=0

(i,j)\notin{\cal E}

\langle{\bf x},{\bf y}\rangle_{\bf Q}={\bf y}^{\top}{\bf Q}{\bf x}
with induced
{\bf Q}
-norm
\|{\bf x}\|_{\bf Q}^{2}=\langle{\bf x},{\bf x}\rangle_{\bf Q}
where
{\bf Q}\succ 0
. The
({\bf M},{\bf Q})
-GFT
[
13
]
is defined as the generalized eigenvectors of
{\bf M}
which solves
{\bf M}{\bf u}_{k}=\lambda_{k}{\bf Q}{\bf u}_{k}

where
0\leq\lambda_{1}\leq\ldots\leq\lambda_{N}
are the graph frequencies and the columns of
{\bf U}=[{\bf u}_{1},\ldots{\bf u}_{N}]
forms a
{\bf Q}
-orthonormal (i.e.,
{\bf U}^{\top}{\bf Q}{\bf U}={\bf I}
) basis for
\mathbb{R}^{N}
. This corresponds to the decomposition
{\bf Q}^{-1}{\bf M}={\bf U}\boldsymbol{\Lambda}{\bf U}^{\top}{\bf Q}
, where
\boldsymbol{\Lambda}=\text{diag}(\lambda_{1},\ldots,\lambda_{N})
. The
({\bf M},{\bf Q})
-GFT representation of a signal
{\bf x}
is defined as
\hat{\bf x}={\bf U}^{\top}{\bf Q}{\bf x}
and the corresponding inverse transform is given by
{\bf x}={\bf U}\hat{\bf x}
.

3.1
Sampling set selection

Let
{\bf x}
be a random signal drawn from a distribution with covariance

We formulate the sampling set selection problem as choosing the subset that minimizes the worst-case bandlimited model mismatch error (E-optimal) of the signal with respect to the
({\bf M},{\bf Q}({\cal S}))
-GFT interpolator with SF introduced in
[
11

We first define three frequency domain subspaces associated with the SF
({\bf M},{\bf Q}({\cal S}))
-GFT.
We define
{\mathscr{L}}=\text{span}\{{\bf u}_{i}:0\leq\lambda_{i}<1\}

{\mathscr{M}}=\text{span}\{{\bf u}_{i}:\lambda_{i}=1\}

{\mathscr{H}}=\text{span}\{{\bf u}_{i}:1<\lambda_{i}\leq 2\}

{\cal L}=\{i:0\leq\lambda_{i}<1\}

{\cal M}=\{i:\lambda_{i}=1\}

{\cal H}=\{i:1<\lambda_{i}\leq 2\}

Without loss of generality, we assume that

\text{dim}({\mathscr{M}})=|{{\cal S}^{c}}|-|{\cal S}|

[
18
]

{\cal S}
.

Any signal

can be decomposed as

\Delta\hat{\bf x}_{h}({\cal S})={\bf U}_{{\cal V}{\cal H}}^{\top}{\bf Q}({\cal S}){\bf x}

CONCLUSION

In this work, we proposed a graph sampling method for interpolation using a sampling-adaptive GFT. We showed that the error in reconstruction with the sampling set adaptive interpolator depends only on the high-frequency energy of the signal. Using this, we proposed a sampling algorithm that minimizes the worst-case bandlimited model mismatch error with respect to the sampling set-adaptive GFT. Our primary application involved partitioning sensor networks into multiple representative subsets, with each subset using its own sampling set-adapted GFT for interpolation. Experimental results showed that this approach outperforms traditional methods based on fixed subspace. Future work could focus on extending this partitioning algorithm for distributed implementation in large-scale sensor networks.
