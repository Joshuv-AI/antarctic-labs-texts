In the original publication [1], Table 4 (Aneurysm-related characteristics) contains incorrect data, as values from Table 3 (Patient-related characteristics) were inadvertently transferred into it. Since these values do not correspond to the parameters intended for Table 4, the table requires revision. The corrected version of Table 4 appears below. The authors state that the scientific conclusions are unaffected. This correction was approved by the Academic Editor. The original publication has also been updated.
