An effective Key Frame Extraction technique based on Feature Fusion and Fuzzy-C means clustering with Artificial Hummingbird
Authors: Sumandeep Kaur, Lakhwinder Kaur, Madan Lal
Published: 2024

ABSTRACT
Key frame extraction is very important in video summarization and content-based video analysis to address the problem of data redundancy in a video. Key frame extraction enables quick navigation and expert video arrangement in many applications. The visually impaired can benefit from the use of key frame extraction for rapid object recognition and tracking. Most key frame extraction techniques consider only a single visual feature instead of multiple features or full pictorial information of the video. This study proposes a key frame extraction method from a video that (i) first removes insignificant frames by pre-processing, (ii) second, four visual and structural feature differences among the consecutive frames are extracted and aggregated to identify informative frames, (iii) third, to cluster the obtained frames, a hybrid FCM-AHA method is proposed by combining Fuzzy C-means(FCM) with artificial hummingbird optimization algorithm (AHA) to circumvent the local minima trapping problem of FCM, and finally, from each cluster, the two frames having greatest Euclidean distance from all the other frames within a cluster is selected as key frames to remove redundant frames. Experimental results on the Open video and YouTube datasets show that the suggested method outperforms state-of-the-art methods both in terms of subjective qualitative analysis and objective quantitative evaluation, e.g., Precision, Recall, and F-score. Further, results are also taken on real video to demonstrate its applicability in real-life applications.

Introduction

Digital video is described as a visual multimedia source on electronic media as a continuous sequence of frames per second. With the advancement of video-capturing technology, there is huge rise in video data which lead to the need of its efficient representation so as to speed up processing as well as reduce storage requirement1. When editing and analyzing video, key frame extraction is a way to find and choose important frames from a video sequence. A key frame is a single frame that summarises the video section or gives important information about it. Key frame extraction is often used for tasks like summarization of videos, classification, content-based searching and compressing videos.

The key frame extraction method can be divided into static and dynamic2–5. The static key frame extraction method uses a small collection of representative images extracted from the video, and dynamic key frame extraction combines time-ordered image frames with audio information. Static key frame extraction plays an important role in navigation and browsing in various ways as it isn’t affected by problems faced by a dynamic method, such as timing and synchronization problems2. This paper is based on the static key frame extraction technique, which includes various steps like sampling, shot segmentation and scene segmentation6. The key frame extraction method can also effectively select the representable frames from a video in the object detection field to process faster.

Key frame extraction methods can be divided into two types - Traditional and Convolutional Neural Network (CNN) based methods. Traditional methods mainly focus on extracting low-level features. Based on these features, frames are selected to minimize the repetition and best capture the visual information in the video. Figure 1 shows the basic steps used in traditional key extraction techniques. The input video is divided into frames. Features such as color, motion, texture etc. are extracted from the frames and most representative frames known as key frames are extracted based on some criteria.

A Convolutional Neural Network (CNN) used deep learning to extract high-level semantic features from the video. Convolutional neural networks, or CNNs, are useful for classifying frames and for identifying keyframes by detecting notable changes between frames without human interference. The input video is divided into different frames which are fed into the CNN to analyse frames. CNN layer consists of convolutional layers used to extract spatial information, the pooling layer reduces dimensionality and the fully connected layer classifies significant features. These extracted features are fed to the classification layer to classify features and finally, the most relevant frames are selected as keyframes. Some of the most common traditional ways to find key frames are based on shots7–9, significant differences between the contents10,11, and clustering12–19. In shot-based key frame extraction, different shots in the original movie are first found, and then one or more key frames are taken from each shot. The second method calculates each frame’s low-level features (like color histogram difference, motion features and texture features). The frame’s features are compared with consecutive frames, and if there is a significant difference between the previous and current frames, then the current frame is selected as the key frame. In clustering-based techniques, similar frames are grouped into different clusters based on their low-level features. Then, a few key frames are chosen from these clusters. Deep learning methods20 as classified into supervised, unsupervised and reinforcement learning-based methods. Supervised learning involves training a model using labelled data in which the input data has corresponding labelled output. The objective is to minimize the error between the predicted output and actual output as the model learns to map the input to the proper output. Commonly used architecture in supervised learning are Recurrent Neural Networks (RNNs)21, Long Short-Term Memory (LSTM)22, Fully Connected Networks (MLPs)23. Unsupervised learning24means training a model without labelled data. The goal is to discover the underlying structure or distribution in the data, often used for clustering, dimensionality reduction, or anomaly detection. Common models used are Autoencoders, Generative Adversarial Networks (GANs)25, Restricted Boltzmann Machines (RBMs)26, Self-Organizing Maps (SOMs)27. Reinforcement learning28,29 entails instructing an agent to execute a series of choices via interaction with an environment. The agent receives feedback via rewards or punishments contingent upon its behaviours, to maximise the total reward.

But, all these conventional methods have a few limitations. Shot-based methods can only be used in organized videos such as sports and news videos. However, these methods fail for consumer videos as they usually don’t have a pre-imposed structure. It is also hard to find a shot border for fade-and-dissolve shots. In the second method, as it relies on the difference between the low-level features of the frames, some of the details of each frame may be missed, which doesn’t make key frames a proper representative. The above problems mostly do not affect clustering-based techniques, but the algorithms used in some schemes are computationally expensive, especially on long videos.

Related work

In the literature, two types of key frame extraction-based video summarization algorithms are available: static and dynamic summary. Static summaries are a group of summaries that don’t change over time, like still pictures and text. A short video summary of a movie is called a “dynamic summary”. A dynamic summary can be seen as a single clip from a video30. A static video summary algorithm creates a video summary by combining several key frames from a video13,18,31–33, where motion and audio are not considered. The static video summary is easier to read and can be used as a preliminary step before getting a video. A comprehensive survey can be found in34–36. Some of the main approaches related to the static summary from the literature are discussed below.

Key frame extraction methods can be classified as traditional and convolutional neural network (CNN) based methods. Traditional methods are mostly emphasising the selection of frames that most effectively encapsulate the video’s visual information while minimising redundancy. These methods extract low-level features such as color, texture, motion, optical flow etc. Cluster-based approach11,18,19,33,37 involves clustering frames according to similarities, such as pixel values or colour histograms. Each cluster is denoted by a centroid, and the frame nearest to the centroid is designated as the keyframe. Feature fusion2,38,39 combines different low-level features to improve the accuracy of key frame extraction. CNN-based methods24,28,40,41 automatically learn high-level features from the frames of a video. The accuracy of the former method depends on the handcrafted features and its computational resources requirement is low and can run on simple devices whereas the CNN-based method’s computational resources requirement is high, it needs graphical processing units (GPUs) with significant computational powers. Implementation of traditional methods is simple as it needs manual feature extraction with minimum data requirement, but the CNN-based method has complex computational complexity as it requires a large amount of labelled data for training. So, in general, traditional methods are used when computational efficiency, ease of implementation and interpretability are important. On the other hand, CNN-based methods are better in terms of accuracy, and ability to handle complex video content but have high computational cost and complexity.

The most popular technique for key frame extraction is based on the difference among the features of consecutive frames. The frames whose differences are more than a predefined threshold are selected as key frames. Various low-level features like color histogram, correlation, and edges are used for this purpose11. Pal and Leigh10 used fuzzy geometrical and information measures as image features. The weighted distance between the measured features calculates frame similarity. DeMenthon et al.42 developed an algorithm to extract key frames by finding discontinuities on a trajectory curve representing a video sequence. Ejaz et al.43 presented an efficient key frame extraction technique based on a visual attention framework. This framework was based on the computation of bottom-up static and temporal visual saliencies. The application of temporal gradients effectively replaced the previously employed typically optical flow-oriented features. The non-linear weighted fusion system incorporated the advantages of prior schemes. Yang G et al.44 developed an algorithm for key frame extraction for online aerobics training using the video’s colour components (RGB) and a non-uniform quantized HSV space approach. A one-dimensional feature vector was introduced to convert an online aerobics training video into a one-dimensional histogram of 72 bins, allowing video shot segmentation and reducing the impact of shot conversion. After the segmentation process, the grey values of the histogram pixels in the movie are sorted, as are the dynamic frames of the aerobics online training video. The sequence search algorithm produced the processing dynamic frame, extracted the video sequence’s feature vector, and then utilized the multi-layer core aggregation algorithm was utilized to extract the key frame of the video action based on the extracted feature vector. In45, the Local Binary Pattern (LBP) approach extracted binarized edge information from frames for texture characterization to detect abrupt shots based on histogram characteristics, and an adjustable threshold detects abrupt shots. The Sobel operator extracted magnitude gradients from each segmented shot frame during key frame extraction. Next, magnitude values were converted into Z-scores, which describe each pixel’s distance from the mean in standard deviation units for each frame. Finally, the coefficient of variation was calculated for each frame, and the frame with the highest value was picked as a key frame for each shot. Then, integrate the positive activities. It resulted in an efficient and informative summary of activities.

The challenge of detecting smooth video transitions was explored in46. The proposed method was a fuzzy-rule-based system which uses a set of fuzzy rules. The video frame features were extracted first, and then fuzzy rules were applied to each frame to find the subtle changes. Its detection accuracy also increases with time. In addition, while prior methods of progressive detection relied heavily on a threshold component, the suggested approach was rule-based. Rashmi B et al.47 proposed a method by using fuzzy sets, Sobel gradient, a block based on mean cumulative sum histogram (MCSH), and the relative standard deviation (RSD) measure to detect abrupt and incremental video transitions. The algorithm employed RSD measurement on each MCSH histogram in conjunction with a threshold mechanism to identify transitions. Sandhu and Agarwal48 have devised an automatic method for VSUMM for video summarization that uses both the structural similarity (SSIM) measure and visual features from the red-green-blue (RGB) channel of the features, Color histograms, Moment of inertia, and texture, have been extracted from the video by looking at its visual characteristics. Similarity between two frames can be used to retain the distinct frames. Mei S et al.49 demonstrated that L2,1- norm-based sparse selection (SS) has several limitations when applied to key frame extraction. One such limitation is the difficulty in guaranteeing the dictionary’s sparseness due to the videos’ size. The video SS-based framework automatically selects key frames based on the minimization of reconstruction error but does not account for information redundancy between the selected key frames. As a consequence, the extracted key frames contain multiple duplicate images, which should ideally be eliminated. The authors presented a method based on L0 norms for selecting critical frames from a global perspective. They proposed offline (OffMSR) and online (OnMSR) key frame extraction algorithms that are computationally efficient. Ejaz et al.38 presented a method that employs an aggregation mechanism to combine the visual features extracted from the correlation of RGB colour channels, colour histogram, and moments of inertia to extract key video frames. Three comparison measures are combined using an aggregation mechanism to determine inter-frame changes in the current and preceding iteration. Utilizing the adaptive formula produces a seamless output function and reduces redundancy. The frame is selected as a key frame if its aggregation value exceeds a threshold. Meaningless frames are removed if the frames’ standard deviation is near zero. Guan et al.50 developed an algorithm named key point-based key frames (KBKS), which extracts the scale-invariant feature transform (SIFT) features and a local feature vector is formed from all the frames of the video. The key frames are selected from the vector pool by preserving information in the local feature vector pool.

Many researchers have used the clustering approach to cluster the frames according to some similarity metric and then pick one key frame from each cluster. Hanjalic and Zhang19 described a method for summarising any video sequence based on the cluster-validity analysis method, which works without human supervision. Mundur et al.12 developed a method in which frames from a video are grouped on the basis of the Delaunay Triangulation (DT). After the pre-sampling of the video, HSV histograms are calculated for each frame and concatenated into a matrix. PCA reduces this matrix’s dimensionality. Then, the Delaunay diagram is prepared. Separating Delaunay diagram edges yields clusters. One key frame from each cluster that is closest to its centre is selected. Gong and Liu37 proposed a technique based on Singular Value Decomposition (SVD). After pre-processing, color histograms in RGB color space are concatenated to form a feature vector. Then, a feature frame matrix A is created, and SVD is applied to it. Each column vector in the output matrix represents a refined feature space frame. Next, the cluster closest to the revised feature space origin is discovered, its content value is computed, and this value is used as the threshold for clustering the remaining frames. The system chooses the key frame from each cluster that is closest to the cluster centre. Furini et al.18 introduced STIMO (STIll and MOving video storyboard), which produces on-the-fly video storyboards. It works in three phases. In the first phase, HSV color histograms are created. Then, a 256-dimensional vector is taken for each frame and stored in the matrix. In the second phase, a clustering algorithm is used to group the frames. Triangular inequalities are used to remove useless distance computations. The number of clusters is obtained from the pairwise distance of consecutive frames. If the distance is greater than the threshold, the number of clusters is incremented. In the third and last phase, meaningless video frames are removed to produce a summary. Avila et al.33 described VSUMM as a mechanism for creating static video summaries. In this, after the pre-sampling of a video, color features are extracted from HSV color space. After removing the useless key frames, frames were grouped based on k means clustering. Then, one frame from each cluster was selected as a key frame. They also contributed a novel method for evaluating video static summaries. Users generate video summaries manually, which is used to compare the output of different approaches.

Yang S et al.16 proposed an algorithm on the notion that more important content may demand more attention and will last for a longer period of time. The unsupervised clustering technique is used to separate frames inside a shot into clusters, and then a key frame is chosen from each possible cluster. The authors used a statistical model to calculate the threshold, which makes the algorithm independent of the video sequence. As the key frame, the suggested technique may capture the important yet salient content. Pan et al.6 used a better method for finding key frames based on the Fuzzy C-means clustering method. The algorithm selects the frames with the largest entropy value from each cluster. Multilevel clustering was used in17 for key frame selection in surveillance video. Orientation computation, Markov chain-based clustering, and adjacent matrix-based clustering were used to identify activities. Clustering based on the Markov chain was used to analyze group adjacent activities efficiently. Clustering based on an adjacent matrix ensured interdependence among the activities. Fei M et al.15 proposed a hybrid key frame extraction framework that utilizes sparse selection (SS) and mutual information-based agglomerative hierarchical clustering (MIAHC). The original video sequences are initially processed with the SS algorithm to extract the best possible key frames in the proposed framework. Then, several key frames are quickly chosen and clustered as a first step in the analysis by minimizing content loss and rating representativeness. After initial processing, unnecessary images are removed, and final key frames are generated by a postprocessor, which is an enhanced version of MIAHC. In51, authors presented a technique based on superpixel segmentation to calculate image similarity. Superpixel segmentation clusters the pixels locally by calculating the optical flow displacement field between successive frames and extracts the final key frames for the video summarization process. Singh Y and Kaur L52 proposed a key frame extraction method based on the benefits of Thepade’s sorted ternary block truncation coding (TSTBTC) in conjunction with the binary bat algorithm (BBA). In order to determine the degree of similarity between any two given frames, the TSTBTC algorithm is used to still images retrieved from the input video database. Four color spaces —RGB, Kekre’s LUV color space, YCbCr color system, and YUV color space are used to process the input data, and the BBA algorithm is used to optimize the threshold value. Liang B et al.53 developed a technique to extract SURF features from video and match features of the adjacent frames. Then, the similarity score between the adjacent frames is calculated to detect the gradual and abrupt boundaries of the shot. After that, an improved clustering technique is used to cluster the frames based on HSV within the shot. Smaller clusters are merged, and frames closer to the cluster centre are selected as key frames.

Recently, deep learning techniques have been widely used in computer vision54. In the filed of key frame extraction, various deep learning approaches are recently used which are briefly described in55,56. Zhang et. al57 developed a supervised learning method that accounts for video sequence structure and uses long short-term memory (LSTM) to model variable range dependence among video frames to provide a video summary. In24, An unsupervised generative adversarial architecture including a summariser and a discriminator was developed to produce summaries. Both the generator and the discriminator were Long Short-Term Memory (LSTM) networks. A variation termed sum-gan was developed with the use of sparse regularisation. Zhao et al.58 presented a structured video summarisation method that integrates shot segmentation and video summarisation into a hierarchical structure adaptive recurrent neural network, termed HSA-RNN. Zhang et al.39. presented a 3D convolutional Multi-scale Spatiotemporal Feature Fusion Network (MSFF-Net) maximizing spatiotemporal features. A Bi-directional Temporal-Spatial Feature Pyramid (BiTSFP) is presented that uses a bi-directional fusion architecture, which combines shallow location information with deep semantic information. Instead of addition and concatenation, an Attention-Guided Fusion (AGF) mechanism is constructed that adaptively learns the fusion weights of nearby features to integrate them. The Frame-wise Attention (FA) module selectively emphasises relevant frames, enhancing multi-scale temporal information to be fused. In59, authors introduced a framework for attentive and distributionally consistent video summarisation (ADSum). The system addressed short-term contextual attention deficiencies and distribution inconsistencies with deep attentive models and a distribution consistency learning approach. Zhang et. al60 introduced a unique Attention-Guided Multi-Granularity Fusion Model (AMFM) that optimises the modelling process via context capture and fusion. AMFM consists of three primary components: a content-aware enhancement (CAE) module, a multi-granularity encoder (MGE), and a scale-adaptive fusion (SAF) module. CAE dynamically augments pre-trained visual features by learning the possible visual relationships between frame-level and video-level embeddings. Subsequently, MGE concurrently models coarse-grained and fine-grained contextual information inside the same representational space by a mix of self-attention and temporal convolution techniques. Moreover, the multi-granularity representations, which exhibit a substantial disparity in semantic scale, are adaptively integrated by SAF. These methods heavily depend on the thorough analysis of precollected historical video samples, requiring large data support to achieve high accuracy, and thus demonstrating reduced effectiveness when historical data is insufficient.

The literature survey shows that key frame extraction methods have used several visual features and statistics, affecting both video summary quality and computation. Few researchers tried to combine multiple visual features to obtain good-quality key frames, whereas others used clustering techniques with single visual features. The fusion of visual and structural features provides non-redundant good-quality key frames. The main advantage of clustering methods is that they generate fewer redundant summaries as they are based on consecutive frame differences. So, we tried to incorporate the best features of both the fusion of visual and structural features to obtain aggregate value with an optimized clustering method.

Proposed framework

The proposed approach consists of three major steps (shown in Fig. 4): (i) pre-processing to reduce the computational time by selecting a lesser number of informative frames only from the video, (ii) feature fusion (to discard less informative frames) by computing cumulative comparison value by extracting four visual features from every set of two consecutive frames and (iii) the remaining frames are clustered by using fuzzy C means clustering with an artificial hummingbird algorithm based upon HSV (Hue, Saturation and Value) histograms. Finally, the key frames are selected from each cluster using the Euclidean distance between the frames.

Pre-processing of frames

Pre-processing is the first step in key frame extraction techniques. In this step, first, the video stream has been pre-sampled so as to represent it with a fewer number of manageable frames and then from the remaining frames, informative frames have been identified and considered for further processing.

Pre-sampling.

Pre-sampling.

Pre-sampling.

The size of Vin is huge, which requires a large computational time to process the video. The number of video frames that need to be evaluated is first reduced by employing a sample rate to address this issue. The choice of sample rate is critical because the higher the sampling rate, the more time required to process the frames. At the same time, an extremely low sample rate might result in poor quality that may remove vital video information. Presampling is advantageous when the size of a video is very large, but it may lose important information when it is applied to smaller videos. In the proposed approach, the sampling rate is selected as one frame per second26 so that the number of frames to be extracted is proportional to the video’s duration in seconds. For instance, the total number of frames to be extracted from a three-minute video with a frame rate of 30 frames/s (5400 frames) is 180 (5400/30) frames.

Retaining Informative Frames.

Retaining Informative Frames.

Retaining Informative Frames.

It has been observed that a video typically contains some monochromatic/meaningless frames, such as those that are completely black, completely white, or faded etc., as shown in Fig. 5. These frames are due to the fade-in fade-out effect or the use of flashes, which is very common in capturing videos. It is a chance that these frames may be selected as key frames because they are significantly different from consecutive frames. To address this issue, these frames are eliminated using a simple step that Furini et al.2 have employed for the same purpose. The standard deviation of each frame/image is computed from its pixel values; if this computed value is zero or sufficiently close to zero, the frame is considered meaningless and discarded before further processing. Many authors22,38 have used this step as post-processing, but there is no point in using this meaningless frame for further evaluation. However, in the present work, this step has been employed as a pre-processing step before feature extraction and clustering.

Extraction and Fusion of feature vectors

The proposed algorithm for key frame extraction is based on comparing every two sets of consecutive frames. Most existing techniques have used a single feature vector to represent the full video details. But in general, a single feature vector is insufficient to estimate all the details about the video, so multiple color and structural features have been used in the present work to effectively represent each retained frame of the video. Four comparison metrics have been used to capture the distinct frame: color histogram, inter-frame correlation of RGB color channels, the mutual information of RGB color channels and moments of inertia.

Let F(t) and F(t + 1) be two different candidate frames taken from the set of candidate frames obtained after pre-processing, each of size m x n. These frames are further divided into Tb non-overlapping blocks of size p x q where p < m and q < n38, and the difference between the respective blocks of the current and previous frames are computed using the following four feature measures.

Color Histogram frame difference measure

Color histograms are very popular in key extraction techniques as they are simple and robust against small changes in camera motions. It represents the distribution of colors in an image. HSV histograms are used to measure the color histograms of an image. After obtaining color histograms, color quantization is applied to reduce the size of the histograms. The color quantization is set to hue component as 16 bins, saturation and intensity as 8 bins each. Then, the values of histograms are normalized in the range of 0–1 by dividing it by the maximum value in the respective component. All three histogram components are combined to get the final histogram of size 32. The above process is repeated for each color channel and section. Proposed clustering algorithm (FCM-AHA) based on Fuzzy C-Mean and Artificial Hummingbird algorithm

Fuzzy c means (FCM) is a well-known unsupervised clustering technique. During execution, it iteratively improves the initial cluster’s centroid, and the final cluster’s centroid is obtained, which is relatively near to the actual cluster’s centroid. However, as the FCM employ a local search technique known as the gradient method, it is trapped in the local minima63. Clustering results will deteriorate if the final selected cluster’s centroid is considerably distant from the actual cluster’s centroid. However, the population-based artificial hummingbird algorithm (AHA) is a recently developed global optimization algorithm in which foraging and flights of hummingbirds inspire random search, and the results of the algorithms proved it better than other metaheuristic algorithms like particle swarm optimization (PSO), grey wolf optimization (GWO) and others64. To overcome the problem of FCM, we have proposed a hybrid FCM-AHA algorithm that incorporates the outstanding characteristics of FCM and AHA to circumvent the local minima trapping problem of FCM and achieve the promising results of AHA. The hybrid FCM-AHA algorithm uses the AHA global search method to compute the centroid of clusters, whereas the objective function of the FCM algorithm defines the fitness function in the hybrid FCM-AHA algorithm.

Fuzzy C-mean clustering

Hybrid approach FCM-AHA for clustering

This section proposes a hybrid FCM-AHA algorithm that combines the FCM with the AHA algorithm to circumvent the local minima trapping problem of FCM. The AHA global search method is used to compute the centroid of clusters, whereas the objective function of the FCM algorithm has been used as the fitness function in the hybrid FCM-AHA algorithm. One drawback of the clustering algorithm is that it needs the number of clusters, but it can’t be fixed as it depends on video length and its variation. Hence, to find the number of clusters in the proposed method, a pairwise distance between the consecutive frames is calculated using Euclidean distance. If the calculated distance exceeds the selected threshold, the cluster number is increased by one. The threshold value used is 0.533. Conclusion

This paper proposes a key frame extraction technique to represent the video with fewer informative frames The work starts with pre-sampling to remove insignificant frames, followed by extraction and fusion of four features: correlation, histogram, Moment of inertia and mutual information among the RGB colour channels of consecutive frames to retain only informative frames. Key frames are selected by comparing the cumulative value of all features with a threshold. Next, a hybrid FCM-AHA method (combination of Fuzzy C-means (FCM) with artificial hummingbird optimization algorithm (AHA)) is proposed to form the clusters of selected key frames (by using their HSV value). This method further helps reduce redundant frames, thereby picking two significant frames from each cluster based on the highest Euclidean distance among the frames within the same cluster. The performance of the proposed method has been evaluated on the Open video, YouTube datasets and real-life video both qualitatively and quantitatively in terms of Precision, Recall and F-score metrics. The experimental results reveal that the proposed method outperforms the state-of-the-art methods visually and in terms of performance metrics.

This work is useful in different applications like video summarization, quick video navigation/management, and quick object detection from extracted keyframes as prepocessing step, which can aid visually impaired persons in signalling them about obstacles in their path. Moreover, key frame extraction aids in reducing the processing time and storage space required for the video. This research can be expanded to single/multiple object detection applications in the future.
