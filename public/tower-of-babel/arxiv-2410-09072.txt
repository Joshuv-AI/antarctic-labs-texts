iTeach : Interactive Teaching for Robot Perception using Mixed Reality
Jishnu Jaykumar P Cole Salvato Vinaya Bomnale Jikai Wang Yu Xiang

Abstract
We introduce iTeach , a human-in-the-loop Mixed Reality (MR) system that enhances robot perception through interactive teaching. Our system enables users to visualize robot perception outputs such as object detection and segmentation results using a MR device. Therefore, users can inspect failures of perception models using the system on real robots. Moreover, iTeach facilitates real-time, informed data collection and annotation, where users can use hand gesture, eye gaze and voice commands to annotate images collected from robots. The annotated images can be used to fine-tune perception models to improve their accuracy and adaptability. The system continually improves perception models by collecting annotations of failed examples from users. When applied to object detection and unseen object instance segmentation (UOIS) tasks, iTeach demonstrates encouraging results in improving pre-trained vision models for these two tasks. These results highlight the potential of MR to make robotic perception systems more capable and adaptive in real-world environments 1 1 1 Project page at https://irvlutd.github.io/iTeach .

Introduction

Robot perception plays a vital role across various robotic applications. In robot manipulation, for instance, perception enables the detection and recognition of objects for successful grasping and interaction
[
1
,
2
,
3
]
. In robot navigation, it allows for obstacle detection and semantic understanding of the environment, particularly in object-goal navigation
[
4
,
5
,
6
]
. However, achieving robust robot perception is highly challenging due to the wide diversity of objects and scenes. The performance of perception models—such as object detection or segmentation—can be significantly influenced by lighting conditions, background complexity, and environmental clutter.

One strategy to improve perception models is to leverage large-scale data to train these models. For example, the computer vision community has used images on the Internet to train object detection or segmentation models such as Grounding DINO
[
7
]
and SAM
[
8
]
. By training with millions of images on the web, these models exhibit zero-shot generalization performance for object recognition using images collected from robot cameras. For example,
[
9
]
used Grounding DINO for the detection and segmentation of novel objects, which was tested on a real robot. However, these pre-trained vision models still have errors when using them on real robots.
The key question that we would like to address in this paper is how to improve pre-trained vision models for robot perception.

To address this question, we introduce an interactive teaching system named
iTeach
in which a user can use the system to teach robot object recognition and improve perception models. First of all, we need to know when a pre-trained vision model will fail when using it on a real robot. Our system leverages a Mixed Reality (MR) device such as a Microsoft HoloLens 2 headset
[
10
]
as the interface between humans and robots. As demonstrated in Fig.
1
(a), a user can see the output from the robot perception model, e.g., object detection or segmentation, from the HoloLens display. Consequently, the user can work alongside the mobile robot and inspect perception failures in various environments. For example, the user can navigate the robot to see different objects to test the performance of a pre-trained vision model in the real world.

Second, our system supports image annotation using the mixed reality device. When users notice perception failures from the MR device display such as errors in object detection or segmentation, they can annotate the image from the point view of the robot using the MR device. For object detection, the system supports using hand gesture to draw bounding boxes of objects on the image. For object segmentation, we provide point labeling of objects using eye gaze and voice commands as illustrated in Fig.
1
(b). These labeled points are used as prompts for the SAM model
[
8
]
to generate segmentation masks of objects. Furthermore, in order to obtain more labeled images, the user can interact with objects such as separating cluttered objects, and a video of the human-object interaction from the robot camera will be recorded. After that, the user labels the last frame of the video with the MR device, and we utilize SAM2
[
11
]
to propagate segmentation masks to all video frames. In this way, we obtain a sequence of video frames with segmentation masks.

Once the fine-tuning is finished, the new model will be directly deployed to the robot. Consequently, the user can inspect failures of the new model using the MR display, and our
iTeach
system can continuously improve the perception model by collecting annotated real images for fine-tuning.

To demonstrate the effectiveness of our system for interactive teaching, we conducted two case studies with the system: object detection of doors and handles, and Unseen Object Instance Segmentation (UOIS)
[
12
]
. These two perception tasks are valuable. Recognizing doors and handles in indoor environments can facilitate opening and closing doors with robots
[
13
,
14
]
, while UOIS can be combined with robot grasping and manipulation
[
15
,
1
]
. Our experiments demonstrate that our system can be used to collect real-world images with annotations to correct failures of pre-trained perception models for these two tasks.

In summary, our contributions of this work are as follows:
(i)
We introduce the
iTeach
system that enables users to use a mixed reality device to improve the perception capability of robots in the real world,
(ii)
We showed that the
iTeach
system improved pre-trained models for detection of doors and handles and unseen object instance segmentation on a Fetch mobile manipulator and
(iii)
Through our system, we have explored and demonstrated the potential of using mixed reality in interactive teaching between humans and robots.

Related Work

Augmented Visualization of Robotic Applications.
Mixed reality enhances human-robot interaction by visualizing robot intentions through Head-Mounted Displays (HMDs). Prior work has used MR to display motion plan trajectories for robot arms
[
16
]
, omnidirectional aerial vehicles
[
17
]
, and armless robots using virtual arrows
[
18
]
. Motion plan waypoints have also been represented as pose holograms
[
19
]
. These methods improve transparency and intuitiveness in human-robot interaction. Our work extends this by enabling real-time correction of robot perception via an MR interface, allowing users to label, tag and categorize the displayed image observations.

Robot Programming using Mixed Reality.
Mixed reality enhances robot programming by providing intuitive visualization and user interfaces. Prior work has enabled users to define and edit robot motions using waypoints in MR
[
20
,
21
,
22
]
, improved task planning through projection-based MR visualization
[
23
]
, and utilized hand gestures to manipulate digital twin holograms for programming
[
24
]
. Overall, MR simplifies robot programming by visually defining tasks. While previous approaches use MR to specify robot actions, our method leverages MR to create an interactive training loop for refining robot perception. By iteratively correcting object detection and segmentation within the robot’s view, we aim to effectively “teach” the robot to perceive its environment more accurately, enhancing its task performance.

Robot Control and Teleoperation using Mixed Reality.
MR is also utilized for robot control and teleoperation. One approach involves creating a digital twin of the robot, where actions on the virtual model directly control the real robot
[
25
,
26
,
27
]
. Another integrates MR visualization with user interaction for control, such as using head motion for robot grasping
[
28
,
29
]
or hand gestures to control multiple robots
[
30
]
. Like MR-based robot programming, MR-driven control benefits from interactive visualization.

Robot Teaching using Mixed Reality.
MR-based robot control and teleoperation can facilitate human demonstrations for robot learning, such as MR-guided grasping demonstrations
[
31
,
32
]
. Additionally, MR enables interactive robot teaching by visualizing robot intentions and perception results. For instance, MR has been used to display object categorization results, allowing users to correct misclassified objects
[
33
]
, and to represent task execution graphs, enabling users to teach new actions via an AR interface
[
34
]
. Unlike these approaches, we leverage MR to visualize real-time robot perception results and provide an interactive interface for on-the-fly annotation and fine-tuning of perception models, directly within the robot’s operational environment.

The
iTeach
System

3.1
System Components

Figure 2:
System architecture. HoloLens, Robot, and PC are integrated for interactive teaching and data collection.

Our
iTeach
system comprises three core components that work together to enable real-time robot perception correction: a robot, a mixed reality device, and a computer system (PC) (Fig.
2
). The robot (e.g., a Fetch mobile manipulator in our setup) serves as the primary sensing unit, capturing RGB-D images and streaming them via an ROS TCP endpoint to other components while managing both labeled and unlabeled data. The MR device (e.g., a Microsoft HoloLens 2) offers a mixed reality interface for intuitive visualization and annotation through hand gesture, voice, and eye gaze. We built a custom Unity application that allows users to visualize model predictions, interactively label failure cases, and transmit corrected data back to the robot and the PC. The computer system acts as the central coordinator, running modules for perception inference, communication, and online learning, while also maintaining structured directories to store model checkpoints and labeled datasets. Together, these components support a seamless human-in-the-loop pipeline for continuous iterative perception model improvement.

3.2
Task-space Setup and Visualization

The goal of the
iTeach
system is to enhance robot perception. To use the system, a perception network is run on the PC, such as an object detection or segmentation model. The network processes images from the robot’s camera and performs inference on them. For perception feedback, the user wears a mixed reality headset (e.g., Microsoft HoloLens 2), which streams the robot’s RGB view along with model predictions (e.g., detections or segmentations) directly into the user’s field of view. Fig.
3
shows the visualization of these model predictions via HoloLens 2. This real-time overlay enables users to evaluate model performance in situ. As a result, users can identify and inspect perception failures in real-world scenarios. When incorrect predictions are observed, users can annotate them directly using the MR device.

With a mobile robot, the user can navigate the robot to different environments and visualize the perception output. In our setup, we used a PS4 controller to navigate the Fetch robot and move its camera orientation. For door and handle detection, we navigated the robot to see different doors and handles in different buildings as shown in Fig.
3
(a). For unseen object segmentation, we intentionally placed objects in different environments to test the segmentation model as shown in Fig.
3
(b). In this way, failures of the perception models can be discovered.

3.3
Human Interaction and Annotation

The
iTeach
system provides flexible and multimodal human annotation capabilities through mixed reality interfaces. Users can provide annotations when they see errors from perception models. It supports three primary modes of interaction: (i)
hand gestures
for direct spatial input such as drawing bounding boxes, (ii)
eye gaze
for precise object targeting, and (iii)
voice commands
for hands-free control of annotation and data collection. These input modalities are designed to empower users with a natural and efficient means to annotate robot-collected visual data in real time, directly from the point of view of the robot. Please check the supplementary for the application flow.

Figure 4:
An example of bounding box annotations using the MR device for doors and handles.

Hand Gesture for Bounding Box Annotation.
We have developed the MR interface that allows users to draw bounding boxes directly in the HoloLens view using pinch-and-drag gestures as illustrated in Fig.
4
. The interface provides mode selection buttons (e.g., Label Door or Label Handle), undo functionality for error correction, and a save mechanism to transmit finalized annotations to the connected PC. This gesture-based interface is especially suitable for labeling rigid, structured object categories and enables intuitive, in-situ annotation without relying on traditional screen-based tools. (write cons for screen based tools; loss of mobility and human interaction with the objects).

Eye Gaze and Voice Commands for Point Annotation.

To support hands-free and rapid annotation, our system provides point annotation using eye gaze and voice commands. The system incorporates real-time eye gaze tracking to determine the user’s focal point and overlays a cursor within the MR view. The focal point indicates a point annotation on the robot view image as illustrated in Fig.
5
. To register this point annotation, the user can use a voice command “true label” and to trigger the storage of the point annotation ”save label”. To check whether the annoataion gives good masks, ”send label” command. These annotated points can be used to generate segmentation masks of objects. For example, we used the annotated points as prompts for the SAM2
[
11
]
to generate segmentation masks. Since SAM2 can also take negative points as prompts, i.e., points that are not on the target object, we also annotated several negative points using the eye gaze and voice command ”false label”, in order to obtain accurate segmentation masks of objects.

Figure 5:
An example of point annotation using eye gaze and voice command.

Furthermore, to obtain more annotated images, our system supports recording a video of the user interacting with objects. A voice command “begin capture” initiates the recording. The user then interacts with the objects, as shown in Fig.
5
, and says “stop capture” to end the session. During interaction, cluttered objects are intentionally separated. The goal is to transition from cluttered to clean scenes where objects are spaced apart (Fig.
5
). After recording, the video is saved, and the user annotates objects in the final frame using eye-gazing and voice commands to collect object point prompts. These point prompts are converted into bounding box prompts using SAM2
[
11
]
in real time. We perform this conversion because bbox prompts yield more robust mask propagation across frames. Finally, the annotations guide SAM2
[
11
]
, which propagates segmentation masks throughout the video sequence (Fig.
5
). This results in a video with segmentation masks for all frames.

3.4
Iterative Model Fine-tuning

After obtaining images with human annotations (Fig.
6
), we use these data to fine-tune pre-trained perception models. We introduce an interactive refinement loop to improve a pre-trained model
M_{0}
in real time. As the robot processes streaming inputs, a human monitors the model’s predictions via the MR display. Upon identifying a failure case, the human provides corrective labels, which are added to a temporary dataset
\mathcal{D}
containing samples where the model underperforms. Once a sufficient number of samples have been collected, the human manually initiates fine-tuning through the MR interface. The model is then fine-tuned on
\mathcal{D}
to produce a refined version
M_{i}^{\prime}
, where
i=1,2,3,\dots
denotes the
i
-th fine-tuning round. Here,
M_{i}
refers to the current model prior to fine-tuning, and
M_{i}^{\prime}
is the updated model after fine-tuning. The refined model
M_{i}^{\prime}
is evaluated against
M_{i}
, and if it demonstrates improved performance, it replaces
M_{i}
; otherwise, the update is discarded. This process continues iteratively until the human deems the model’s performance satisfactory. Evaluation follows standard metrics, specifically: (i) mean average precision (mAP) for object detection, and (ii) Combined score (C) for UOIS (see Section
4.2
for details).

5
Limitations

(i) After each fine-tuning cycle, the best-performing model is selected, and new data is collected and labeled based on its predictions. However, as shown in Table
2
,
3
, and
4
, model performance does not improve monotonically—it can fluctuate depending on the quality and diversity of the collected data. (ii) The UOIS mask propagation pipeline is particularly sensitive to the performance of SAM2
[
11
]
, which, in highly cluttered scenes, can produce masks with reduced contextual integrity, degrading segmentation quality for some objects. Although this was observed in only a few cases, it highlights the pipeline’s sensitivity to occlusion and scene complexity. This can be mitigated by choreographing human-robot interaction to reduce occlusions, thereby ensuring the collection of higher-quality data during demonstrations.

6
Conclusion and Future Work

We introduce an interactive teaching system,
iTeach
, designed to enhance robot perception through human interaction. The system utilizes HoloLens2, a mixed reality device, enabling users to visualize perception predictions and provide corrective annotations. These user-level annotations facilitate the iterative fine-tuning of the perception module, driving continuous improvement. We demonstrate the effectiveness of
iTeach
through real-world case studies on door and handle detection, as well as unseen object instance segmentation. For future work, we aim to extend
iTeach
to teach robots manipulation skills. An exciting possibility is to leverage mixed reality to visualize the robot’s field of view, ensuring that human demonstrations are adequately captured from the robot’s perspective.
