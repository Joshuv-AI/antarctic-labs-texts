Enhanced Angle-Range Cluster Parameter Estimation in Full-Duplex ISAC Systems Thanks: This project is funded by Continental Automotive Technologies GmbH under grant DG-088181.
Muhammad Talha, Besma Smida, David González G

Abstract
This work studies an integrated sensing and communication (ISAC) framework for targets that are spread both in the angle and range domains. We model each target using a cluster of rays parameterized by a specific density function, and propose a truncated Multiple Signal Classification (MUSIC) spread (TMS) algorithm to accurately estimate the parameters of the density function. Unlike the conventional MUSIC spread (CMS), TMS restricts the signal subspace rank based on the eigen decomposition of the received-signal autocorrelation. We also propose a discrete Fourier transform (DFT) based algorithm for estimating the distance and range spread of each target. Leveraging these estimates, we then develop a dynamic transmit beamforming algorithm that successfully illuminates multiple targets while also serving multiple downlink (DL) users. Simulation results demonstrate the superiority of our proposed algorithms over baseline schemes in both low and high signal-to-noise ratio (SNR) regimes as well as under a wide angular spread regime.

In an effort to address these limitations, we use a parametric

Realizing the computational complexities of target modeling in recent works

We propose a fast dynamic beam pattern synthesis algorithm that maximizes expected radar

III
Parameter Estimation

At the

III-A

Proposed Subspace-based
TMS

For estimating the angular parameters, we use the autocorrelation matrix of the received signal at the

\displaystyle=\kappa\sum_{k,r}\lvert\alpha_{k,r}\rvert^{2}\mathbf{J}(\theta_{k},\sigma_{\theta_{k}}),

\displaystyle\approx\mathbf{A}(\sin(\theta_{k}))\odot\mathbf{A}(\tilde{\theta}_{k,r}\cos(\theta_{k}))

\displaystyle\mathbf{A}(\tilde{\theta}_{k,r}\cos(\theta_{k}))\mathbf{D}^{\mathrm{H}}(\sin(\theta_{k})).

\displaystyle\times\mathrm{vec}\left(\mathbf{R}_{\mathbf{X}}\right)\Bigr),

(8)

\displaystyle f_{k}

\displaystyle=\left\lvert\left\lvert\mathbf{E}_{n}^{\mathrm{H}}\mathbf{J}(\theta_{k},\sigma_{\theta_{k}})\right\rvert\right\rvert_{\mathrm{F}}^{2}

III-B

Low Complexity
TMS
for angular parameters

Using the approximation defined on (

III-C

Range Parameters Estimation

We assume a symmetric range distribution around the mean distance (
d_{k}
) for each target, and therefore we can express the distance of the

ray of the target

as

\tilde{d}_{k,r}
is a random symmetric perturbation around

. In particular, in our setting we assume that
\tilde{d}_{k,r}
follows a uniform distribution, that is,
\tilde{d}_{k,r}\sim\mathcal{U}(-\delta_{d_{k}},\delta_{d_{k}})
, where
\delta_{d_{k}}=\sqrt{3}\sigma_{d_{k}}
.
In order to estimate the parameters, we begin with the expression (
17

\bar{\mathbf{y}}_{p}^{k}=\mathbf{J}_{\mathrm{app}}(\theta_{k},\sigma_{\theta_{k}})\mathbf{x}_{p}
. Then the expected value of
\omega_{k,r}^{p}
can be evaluated as
\mathbb{E}(\omega_{k,r}^{p})=\psi_{d_{k,r}}(l_{p})=\mathbb{E}(e^{-j2\pi p\Delta f\frac{2d_{k,r}}{c}})=e^{-jl_{p}}\psi_{\tilde{d}_{k,r}}(l_{p})
,
where
\psi_{\tilde{d}_{k,r}}(t)
is the characteristic function of
\tilde{d}_{k,r}
and is given as:
\psi_{\tilde{d}_{k,r}}(t)={\mathrm{sinc}}(4\pi p\Delta f\delta_{d_{k}}/c)
. Inserting these values in (
17
) will yield

\displaystyle\mathbb{E}\left(\mathbf{y}_{p}|\mathbf{x}_{p},\mathbf{z}_{p}\right)=\sqrt{\kappa}\sum_{k,r}\alpha_{k,r}\psi_{d_{k,r}}(l_{p})\bar{\mathbf{y}}_{p}^{k}+\mathbf{z}_{p}

(21)

Using the estimated
\theta_{k}

\sigma_{\theta_{k}}

\bar{\mathbf{y}}_{p}^{k}
and divide the received signal by it i.e.,

\displaystyle\tilde{\boldsymbol{\mu}}_{p}^{k}

\displaystyle=\sqrt{\kappa}\sum_{r=1}^{N_{p}}\alpha_{k,r}\psi_{d_{k,r}}(l_{p})\bar{\mathbf{y}}_{p}^{k}./\hat{\bar{\mathbf{y}}}_{p}^{k}

\displaystyle+\sqrt{\kappa}\sum_{k^{\prime}\neq k,r}\alpha_{k^{\prime},r}\psi_{d_{k,r}}(l_{p})\bar{\mathbf{y}}_{p}^{k^{\prime}}./\hat{\bar{\mathbf{y}}}_{p}^{k}+\mathbf{z}_{p}./\hat{\bar{\mathbf{y}}}_{p}^{k},

where

\displaystyle\mathcal{F}\left(\mathrm{rect}\left(\frac{t-\tau}{2\delta}\right)\right)\to 2\delta{\mathrm{sinc}}\left(2\pi f\delta\right)e^{-j2\pi f\tau}

(23)

where

\displaystyle Q(p^{\prime})=\left\lvert\sum_{p=1}^{P}(\mathbf{1}^{\mathrm{T}}\tilde{\boldsymbol{\mu}}_{p}^{k})e^{j2\pi pp^{\prime}/P}\right\rvert^{2}

\displaystyle\overset{*}{p^{\prime}}_{\mathrm{min}}

\displaystyle\overset{*}{p^{\prime}}_{\mathrm{max}}

(27)

IV
Optimization Problem and its solution

In this section, we will present a framework for optimizing the transmit beamformer
\mathbf{V}
in order to maximize radar
SNR
from each target as well as to satisfy user data rate constraints. The optimization problem we aim to solve is:

\displaystyle\max_{\mathbf{V}}\quad

\displaystyle\gamma_{\mathrm{rad}}=\frac{\mathbb{E}\left[\left\lvert\left\lvert\mathbf{H}_{\mathrm{rad}}^{p}\mathbf{V}\right\rvert\right\rvert_{\mathrm{F}}^{2}\right]}{\sigma_{b}^{2}}

(29a)

s.t.

\displaystyle\Gamma_{u}=\log_{2}\left(1+\gamma_{u}^{\mathrm{sinr}}\right)\geq\gamma_{u},\quad\forall u\in\mathcal{L},

(29b)

\displaystyle\quad\left\lvert\left\lvert\mathbf{V}\right\rvert\right\rvert_{\mathrm{F}}^{2}\leq\mathrm{P}_{b},

(29c)

where
\gamma_{u}^{\mathrm{sinr}}=\frac{\left\lvert\left\lvert\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}\right\rvert\right\rvert_{2}^{2}}{\sum_{u^{\prime}\neq u}^{N_{b}}\left\lvert\left\lvert\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u^{\prime}}\right\rvert\right\rvert_{2}^{2}+\sigma_{u}^{2}}
. Note that, unlike
[
15
,
14
]
, we don’t have an explicit beam pattern matching constraint for each target; the desired beam pattern requirement is implicitly present in the objective function of (
29
).

To solve (
29
), we first reformulate the objective function and evaluate the expectation operator involved in
\gamma_{\mathrm{rad}}
. We denote the numerator of
\gamma_{\mathrm{rad}}
as
\gamma_{\mathrm{rad}}^{\mathrm{sig}}\triangleq\mathbb{E}\left[\left\lvert\left\lvert\mathbf{H}^{p}_{\mathrm{rad}}\mathbf{V}\right\rvert\right\rvert_{\mathrm{F}}^{2}\right]
. We simplify this term as follows

\displaystyle\gamma_{\mathrm{rad}}^{\mathrm{sig}}=\mathrm{Tr}\left(\mathbf{V}^{\mathrm{H}}\mathbb{E}\left[(\mathbf{H}^{p}_{\mathrm{rad}})^{\mathrm{H}}\mathbf{H}^{p}_{\mathrm{rad}}\right]\mathbf{V}\right)

\displaystyle\mathbb{E}\bigl[(\mathbf{H}^{p}_{\mathrm{rad}})^{\mathrm{H}}\mathbf{H}^{p}_{\mathrm{rad}}\bigr]=\kappa\mathbb{E}\Bigl[\sum_{k,r}\sum_{k^{\prime},r^{\prime}}\mathbb{E}((\omega_{k,r}^{p})^{*}\omega_{k^{\prime},r^{\prime}}^{p})

\displaystyle\times\alpha_{k,r}^{*}\alpha_{k^{\prime},r^{\prime}}\mathbf{A}^{\mathrm{H}}(\sin(\theta_{k,r})\mathbf{A}(\sin(\theta_{k^{\prime},r^{\prime}}))\Bigr]

\displaystyle\overset{(c)}{\approx}\kappa\sum_{k,r}\left\lvert\left\lvert\boldsymbol{\alpha}_{k}\right\rvert\right\rvert^{2}\mathbf{J}_{\mathrm{app}}(\theta_{k},\sigma_{\theta_{k}}),

(30)

where in
(c)
we used the angle approximation as well as the law of large numbers on the independence of reflection coefficients. Apart from this, we only assume the knowledge of angular parameters estimates, i.e.,
\hat{\boldsymbol{\eta}}_{1}
. Hence, we define the matrix
\hat{\mathbf{M}}
as
\hat{\mathbf{M}}=\sum_{k=1}^{K}\mathbf{J}_{\mathrm{app}}(\hat{\theta}_{k},\hat{\sigma}_{\theta_{k}})
and use the following estimated metric

\displaystyle\hat{\gamma}_{\mathrm{rad}}

\displaystyle=\frac{\hat{\gamma}_{\mathrm{rad}}^{\mathrm{sig}}}{\sigma_{b}^{2}}=\frac{\mathrm{Tr}\left(\mathbf{V}^{\mathrm{H}}\hat{\mathbf{M}}\mathbf{V}\right)}{\sigma_{b}^{2}}

(31)

Note that we aim to maximize the radar
SNR
, which is a non-convex problem. To find a good solution, we choose
\mathbf{V}
as the eigen vectors of
\hat{\mathbf{M}}
, i.e.,
\mathbf{V}_{c}=\mathbf{Q}_{\hat{\mathbf{M}}}
, where
\mathbf{V}_{c}
represents the candidate beamformer and the matrix
\hat{\mathbf{M}}
is decomposed as
\hat{\mathbf{M}}=\mathbf{Q}_{\hat{\mathbf{M}}}\boldsymbol{\Lambda}_{\hat{\mathbf{M}}}\mathbf{Q}_{\hat{\mathbf{M}}}^{\mathrm{H}}
. Then, we reformulate the objective function as a least squares problem as follows

\displaystyle\min_{\mathbf{V}}\quad

\displaystyle\quad\left\lvert\left\lvert\hat{\boldsymbol{\Lambda}}_{\hat{\mathbf{M}}}^{1/2}\left(\mathbf{V}-\sqrt{\mathrm{P}_{b}}\mathbf{V}_{c}\right)\right\rvert\right\rvert_{\mathrm{F}}^{2}.

(32)

Now the objective functions defined in (
32
) and (
29a
) are equivalent in the sense that the optimal point for both functions is the same. However, the rate constraint looks like a non-convex set, but following the strategy described in
[
20
,
21
]
, we can reformulate the constraints as a convex set. The procedure is as follows

\displaystyle\log_{2}\left(1+\frac{\left\lvert\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}\right\rvert^{2}}{\sum_{u^{\prime}\neq u}^{N_{b}}\left\lvert\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u^{\prime}}\right\rvert^{2}+\sigma_{u}^{2}}\right)\geq\gamma_{u}

\displaystyle\left\lvert\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}\right\rvert^{2}\geq(2^{\gamma_{u}}-1)\left(\sum_{u^{\prime}\neq u}^{N_{b}}\left\lvert\mathbf{h}^{\mathrm{H}}_{u}\mathbf{v}_{u}^{\prime}\right\rvert^{2}+\sigma_{u}^{2}\right)

The last inequality is non-convex in general; however, the phase of the term
\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}
does not affect the optimal value of the constraint
[
20
]
, hence, we can only focus on the linear part of
\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}
, i.e.,
\Re\{\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}^{\mathrm{H}}\}
. Define the matrix
\tilde{\mathbf{V}}_{u}=\mathbf{V}\left(\mathbf{I}-\mathrm{diag}(\mathbf{e}_{u})\right)
, where
\mathbf{e}_{u}
is the
u^{\mathrm{th}}
column of identity matrix. Then the rate constraint can be reformulated as
second order cone (SOC)

\displaystyle\begin{bmatrix}\tilde{\mathbf{V}}_{u}^{\mathrm{H}}\mathbf{h}_{u}\\
\sigma_{u}\\
\sqrt{\frac{1}{2^{\gamma_{u}}-1}}\Re\left\{\mathbf{h}_{u}^{\mathrm{H}}\mathbf{v}_{u}\right\}\end{bmatrix}

\displaystyle\succeq_{\mathrm{SOC}}0,\quad\forall\,u\in\mathcal{L}

(33)

Hence, using (
32
) and (
33
), we can write the convex reformulation of the original optimization problem as follows

\displaystyle\min_{\mathbf{V}}\quad

\displaystyle\quad\left\lvert\left\lvert\hat{\boldsymbol{\Lambda}}_{\hat{\mathbf{M}}}^{1/2}\left(\mathbf{V}-\sqrt{\mathrm{P}_{b}}\mathbf{V}_{c}\right)\right\rvert\right\rvert_{\mathrm{F}}^{2}

(34)

s.t.

\displaystyle\quad\eqref{eq:Rate_Constraint},

\displaystyle\quad\tilde{\mathbf{V}}_{u}=\mathbf{V}\left(\mathbf{I}-\mathrm{diag}(\mathbf{e}_{u})\right),

(35)

\displaystyle\quad\left\lvert\left\lvert\mathbf{V}\right\rvert\right\rvert_{\mathrm{F}}^{2}\leq\mathrm{P}_{b}.

(36)

VI
Conclusion

This work focuses on the
ISAC
system with computationally efficient
CR
target modeling. In particular, we assume that each target has some angular (with mean direction and angular spread) as well as range (with mean range and range spread) densities. To estimate these distribution parameters, we propose algorithms based on
TMS
(for angular parameters) and
DFT
(for range parameters). We also propose a fast dynamic beam pattern synthesis algorithm that adapts to different angular spread requirements subject to users’ data rate constraints. The numerical results demonstrate that the proposed algorithms achieve performance superior to that of the baseline scheme in different simulation settings.
