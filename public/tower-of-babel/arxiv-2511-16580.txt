Block-Separated Overpartitions and Their Fibonacci-Type Structure
El-Mehdi Mehiri mehiri314@gmail.com

Abstract
We introduce and study a new restricted family of overpartitions, called block-separated overpartitions, in which no two consecutive distinct part-size blocks may both be overlined. Using a two-state transfer-matrix automaton, we derive a closed matrix-product expression for the ordinary generating function, establish an Euler-type factorization, and obtain an explicit normalized recurrence suitable for computation of arbitrary coefficients. We further prove that the possible overlining patterns on the distinct blocks are counted by Fibonacci numbers, giving natural bijections with independent sets on paths, pattern-avoiding binary words, and Fibonacci tilings. Keywords: Overpartitions; restricted partitions; automaton; generating function; Fibonacci numbers; q-series; Euler product; pattern-avoiding. MSC 2020: 11P81, 11P84, 05A17, 05A15.

Transfer-matrix formulation with a two-state automaton

In this subsection we give a detailed transfer-matrix description of
block-separated overpartitions, based on the per-size block generating functions

S_{j}(q)
and a simple two-state automaton that encodes the
constraint “no two consecutive distinct blocks are both overlined”.

Definition 3
.

We scan the possible part-sizes in increasing order

j=1,2,3,\ldots,

and decide, at each
j
, whether to use the part
j
in the partition (and
if so, whether the block of
j
’s is overlined or not). We maintain a

state
in
\{0,1\}
defined as follows:

•

State
0
: the last
present
block (if any) is
not overlined
;

•

State
1
: the last present block
is overlined
.

Thus state
1
represents the situation where the most recent distinct
part-size used so far was overlined, so the next present block is forbidden to be overlined.

Remark 1
.

If we skip some part-size
j
(i.e., no parts of size
j
appear), the state
does not change, since no new block is created. Only when we actually use the
part-size
j
do we update the state according to whether the block is
overlined or not.

Proposition 1
.

Fix a part-size
j\geq 1
. At this size, there are three combinatorial choices:

\begin{array}[]{ll}\text{{(A)} Block $j$ absent:}&\text{no parts of size }j\text{ appear},\\[3.0pt]
\text{{(B)} Block $j$ present, plain:}&\text{at least one }j\text{ appears, but the first $j$ is not overlined},\\[3.0pt]
\text{{(C)} Block $j$ present, overlined:}&\text{at least one }j\text{ appears, and the first $j$ is overlined}.\end{array}

The contributions of these choices to the
q
-weights and the state transitions
are:

(A)

Block
j
absent: Weight 1 and state unchanged.

(B)

Block
j
present and plain:
The block consists of
m\geq 1
parts of size
j
,
so the total size contribution is
mj
, and the generating function is
S_{j}(q)
.

Since this block is
not
overlined, the new last present block is plain,
and the next state is
0
, regardless of the current state.

(C)

Block
j
present and overlined:
Again the multiplicity
m\geq 1
contributes weight
S_{j}(q)
.
However, because the first occurrence is overlined, this choice is allowed
only if the current state is
0
, i.e., the previously present block was
not overlined. The next state is then
1
.

Lemma 1

Let

be the matrix whose entry

(2)

Proof.

By Proposition

•

From state
0

0

4
Generating Function

The global generating function is obtained by composing all local transitions
for
j=1,2,3,\ldots
. We start with no blocks and hence in state
0
, encoded
by the row vector
(1,0)
. After processing all sizes, we sum over both
possible final states, encoded by the column vector
\bigl(\begin{smallmatrix}1\\
1\end{smallmatrix}\bigr)
.

Theorem 1

(Matrix formulation)
.

The ordinary generating function of block-separated overpartitions is

\mathcal{F}(q)=\begin{pmatrix}1&0\end{pmatrix}\left(\prod_{j\geq 1}M_{j}(q)\right)\begin{pmatrix}1\\
1\end{pmatrix},

(3)

where
M_{j}(q)
is the transfer matrix of Lemma
1
.

Proof.

By construction, for each fixed size
j
, the matrix
M_{j}(q)
encodes all
legal transitions between states
0
and
1
with the correct
q
-weights:
each allowed choice (absent, present plain, present overlined) contributes a
monomial
q^{\text{contribution}}
multiplied by the generating function

S_{j}(q)
when the block is present, and the block-separated condition is
enforced by disallowing the transition
1\to 1
via an overlined block.

The product
\prod_{j\geq 1}M_{j}(q)
is taken in increasing order of
j
, and
matrix multiplication corresponds to concatenating choices at each size. The
row vector
(1,0)
represents the unique starting configuration before any
part-size is considered: no blocks have been chosen and the last present block
is (vacuously) plain. Multiplying from the left by
(1,0)
propagates all
legal sequences of choices across all sizes. Finally, multiplying on the right
by
\bigl(\begin{smallmatrix}1\\
1\end{smallmatrix}\bigr)
sums the contributions from
both possible final states, since the final state (whether the last block is
overlined or not) does not matter for the total count. Thus the coefficient
of
q^{n}
in

\begin{pmatrix}1&0\end{pmatrix}\left(\prod_{j\geq 1}M_{j}(q)\right)\begin{pmatrix}1\\
1\end{pmatrix}

is precisely the number of block-separated overpartitions of
n
.
∎

Proposition 2

(Euler factorization)
.

We have

\mathcal{F}(q)=\frac{1}{(q)_{\infty}}\left(\widehat{F}_{0}^{(\infty)}(q)+\widehat{F}_{1}^{(\infty)}(q)\right),

(4)

with
(q)_{\infty}=\prod_{j\geq 1}(1-q^{j})
, and where the modified sequences
\widehat{F}_{0}^{(n)},\widehat{F}_{1}^{(n)}
satisfy

\displaystyle\widehat{F}_{0}^{(n)}

\displaystyle=\widehat{F}_{0}^{(n-1)}+\widehat{F}_{1}^{(n-1)},

\displaystyle\widehat{F}_{1}^{(n)}

\displaystyle=q^{n}\widehat{F}_{0}^{(n-1)}+(1-q^{n})\widehat{F}_{1}^{(n-1)},

with initial conditions
\widehat{F}_{0}^{(0)}=1,\ \widehat{F}_{1}^{(0)}=0.

Proof.

A key feature of the transfer matrix
M_{j}(q)
is that the upper-left entry is simply a y classical Euler factor
\dfrac{1}{1-q^{j}}
, which is precisely the
j
-th factor in the Euler product

(q)_{\infty}=\prod_{j\geq 1}(1-q^{j}).

Extracting these factors from the infinite product

\prod_{j\geq 1}M_{j}(q)
leads to a clean normalization of the transfer-matrix
recurrence.

To make this precise, define the
normalized
matrices

\widehat{M}_{j}(q)\;=\;(1-q^{j})\,M_{j}(q)=\begin{pmatrix}1&q^{j}\\[4.0pt]
q^{j}&1-q^{j}\end{pmatrix}.

Then for any row vector
V=(V_{0},V_{1})
we have

VM_{j}(q)=\frac{1}{1-q^{j}}\,V\widehat{M}_{j}(q).

It follows that

(1,0)\!\left(\prod_{j\geq 1}M_{j}(q)\right)=\left(\prod_{j\geq 1}\frac{1}{1-q^{j}}\right)(1,0)\!\left(\prod_{j\geq 1}\widehat{M}_{j}(q)\right)=\frac{1}{(q)_{\infty}}\,(1,0)\!\left(\prod_{j\geq 1}\widehat{M}_{j}(q)\right).

Let
\bigl(\widehat{F}_{0}^{(n)}(q),\widehat{F}_{1}^{(n)}(q)\bigr)
denote the row vector
obtained after multiplying the normalized matrices
\widehat{M}_{1}(q),\ldots,\widehat{M}_{n}(q)
, that is,

\bigl(\widehat{F}_{0}^{(n)},\widehat{F}_{1}^{(n)}\bigr)=(1,0)\,\widehat{M}_{1}(q)\,\widehat{M}_{2}(q)\cdots\widehat{M}_{n}(q).

Therefore, we have the recurrence

\bigl(\widehat{F}_{0}^{(n)},\widehat{F}_{1}^{(n)}\bigr)=\bigl(\widehat{F}_{0}^{(n-1)},\widehat{F}_{1}^{(n-1)}\bigr)\begin{pmatrix}1&q^{n}\\[4.0pt]
q^{n}&1-q^{n}\end{pmatrix},

which yields the component-wise system

\displaystyle\widehat{F}_{0}^{(n)}

\displaystyle=\widehat{F}_{0}^{(n-1)}+q^{n}\,\widehat{F}_{1}^{(n-1)},

\displaystyle\widehat{F}_{1}^{(n)}

\displaystyle=q^{n}\,\widehat{F}_{0}^{(n-1)}+(1-q^{n})\,\widehat{F}_{1}^{(n-1)}.

The initial conditions come from
(1,0)
before any matrices are applied:

\widehat{F}_{0}^{(0)}=1,\qquad\widehat{F}_{1}^{(0)}=0.

Finally, summing over both terminal states gives

\mathcal{F}(q)=\begin{pmatrix}1&0\end{pmatrix}\!\left(\prod_{j\geq 1}M_{j}(q)\right)\begin{pmatrix}1\\
1\end{pmatrix}=\frac{1}{(q)_{\infty}}\,\Bigl(\widehat{F}_{0}^{(\infty)}(q)+\widehat{F}_{1}^{(\infty)}(q)\Bigr),

proving the normalized Euler-type factorization.
∎

5
Fibonacci-type internal combinatorics

A striking feature of block-separated overpartitions is the appearance of the
classical Fibonacci numbers in their internal structure. This phenomenon arises
from the fact that, once the distinct part-sizes have been chosen, the
overlining pattern on these blocks is governed by the constraint that no two
consecutive blocks may both be overlined. This turns the decoration process
into a problem of counting binary words with forbidden consecutive
1
’s, a
combinatorial problem whose solution is known to be Fibonacci-like.

Binary words avoiding the pattern
\bm{11}
.

Suppose a block-separated overpartition uses exactly
r
distinct part-sizes.
Label the corresponding blocks in decreasing order of size as positions

\{1,\ldots,r\}
. Each block may be either
plain
or
overlined
,
and this choice can be encoded by a binary word

w=w_{1}w_{2}\cdots w_{r},\qquad w_{i}\in\{0,1\},

where
w_{i}=1
means that the block in position
i
is overlined. The
block-separated condition is exactly the constraint

w_{i}w_{i+1}=0\quad\text{for all }1\leq i<r,

i.e. the word
w
contains no consecutive
1
’s.

It is well known (and easy to prove by a standard recurrence argument) that the
number of length-
r
binary words with no occurrence of the pattern
11
is
the Fibonacci number
F_{r+2}
. One may view such a word as a tiling of a
board of length
r
using the tiles:
[formula]
and
[formula]
, corresponding to plain and overlined blocks, respectively. Reading from left to
right, every legal word admits a unique decomposition into these tiles. This
bijection immediately yields the recurrence

a_{r}\;=\;a_{r-1}+a_{r-2},\qquad a_{0}=1,\ a_{1}=2,

which is solved by
a_{r}=F_{r+2}
.

Connection with independent sets on a path.

An equivalent viewpoint is obtained by identifying the block positions

\{1,\ldots,r\}
with the vertices of a path graph
P_{r}
. Choosing which
blocks are overlined is equivalent to selecting an
independent set
of
vertices (no two adjacent), because overlined blocks may not appear in
consecutive positions. The number of independent sets of size
m
in a path
of length
r
is

\binom{r-m+1}{m},

and summing over all
m
yields

\sum_{m\geq 0}\binom{r-m+1}{m}=F_{r+2}.

This independent-set interpretation is particularly useful in the symmetric
function expansion given in Proposition
3
.

The quantity
F_{r+2}
is exactly the number of legal independent subsets of a
path of length
r
, i.e., the number of admissible decoration patterns for an

r
-block part-size set.

Automaton and Fibonacci polynomials.

Viewed through the two-state automaton of Figure

, the

Consequences for the global generating function.

The Fibonacci decoration mechanism leads directly to the the following representation.

Proposition 3
.

We have

\mathcal{F}(q)=\sum_{r\geq 0}F_{r+2}\,e_{r}(S_{1},S_{2},S_{3},\ldots),

6
Conclusion and Further Directions

We introduced
block-separated overpartitions
, a new class of restricted
overpartitions in which no two consecutive distinct blocks may both be
overlined.
The enumeration is governed by a simple two-state transfer matrix, yielding: a matrix-product formula for the generating function
F(q)
, an Euler-type factorization, a normalized recurrence suitable for explicit computation, and a Fibonacci interpretation of the internal overlining structure.

Several questions and research directions arise from the resulting structure: the extension to
k
-separated
overpartitions forbidding runs of
k
consecutive overlined blocks; the derivation of explicit
q
-difference equations or continued-fraction expansions of
\mathcal{F}(q)
; and the study of congruence properties of
b(n)
modulo small primes.

We expect block-separated overpartitions to provide a fertile new setting for the study of restricted
partition families,
q
-series expansions, and Fibonacci-type combinatorial structures.
