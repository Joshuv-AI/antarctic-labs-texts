Controlling dynamical systems into unseen target states using machine learning
Daniel Köglmayr, Alexander Haluszczynski, Christoph Räth

Abstract
We present a novel, model-free, and data-driven methodology for controlling complex dynamical systems into previously unseen target states, including those with significantly different and complex dynamics. Leveraging a parameter-aware realization of next-generation reservoir computing, our approach accurately predicts system behavior in unobserved parameter regimes, enabling control over transitions to arbitrary target states. Crucially, this includes states with dynamics that differ fundamentally from known regimes, such as shifts from periodic to intermittent or chaotic behavior. The method’s parameter-awareness facilitates non-stationary control, ensuring smooth transitions between states. By extending the applicability of machine learning-based control mechanisms to previously inaccessible target dynamics, this methodology opens the door to transformative new applications while maintaining exceptional efficiency. Our results highlight reservoir computing as a powerful alternative to traditional methods for dynamic system control.

Discussion

In this work, we proposed a model-free, data-driven machine learning methodology for smoothly controlling dynamical systems into previously unseen target states, including those with fundamentally different behaviors. By leveraging a parameter-aware machine learning model, we demonstrated the ability to interpolate and extrapolate system dynamics across unexplored parameter regimes. This approach enables transitions to target states that differ significantly from the observed dynamics, offering a novel framework for controlling complex systems. We utilize a stationary prediction of the target dynamic to define a threshold value, such a as the running correlation dimension, to quantify and avoid turbulent behaviors during transitions. By generating multiple non-stationary transition trajectories and filtering for predictions that don’t exhibit turbulence, we ensure smooth transition to the target dynamics. The control approach is generalizable under the condition that the underlying model extrapolates the bifurcation behavior correctly.
The next-generation reservoir computing (NGRC) approach used stands out for its exceptional data efficiency, as further confirmed by our experiments on the Lorenz system. Compared to traditional reservoir computing, NGRC requires more than an order of magnitude less training data while maintaining accurate predictions
[
30
]
. This makes it particularly suitable for scenarios where data is sparse or expensive to collect. Additionally, NGRC’s concise architecture allows for hardware implementation on platforms such as FPGAs
[
35
]
. The current state in this field allows for NGRC hardware implementations with a single control target state. Notably, the method presented here extends the number of achievable target states per hardware implementation and enables non-stationary control, a key advantage for edge computing applications where real-time adaptability is crucial. However, several limitations warrant further discussion. A notable challenge of the underlying NGRC model is its susceptibility to stability issues during prediction if the hyperparameters are not well optimized. This sensitivity can pose challenges to its adaptability in more complex scenarios. Future work will focus on this issue by refining the two core building blocks of reservoir computing, the reservoir itself and its optimization algorithm, to further progress its adaptability while maintaining high data efficiency with architectural simplicity.
Additionally, exploring the integration of NGRC with other machine learning paradigms and testing its performance across a wider range of more complex dynamical systems will further validate its applicability and uncover new potential use cases.
By addressing these challenges, the proposed methodology holds promise as a transformative tool for controlling complex dynamical systems, opening pathways to applications where traditional methods fall short.

Methods

Next-Generation Reservoir Computing

Next-generation reservoir computing (NGRC) is a machine learning framework that enhances traditional reservoir computing by leveraging deterministic structures derived from nonlinear vector autoregression (NVAR). Instead of utilizing a randomly weighted internal network, NGRC constructs its feature vectors through a library of unique monomials of time-shifted input variables from the input data. This process involves concatenating
k
past time series data points, each separated by
s
time steps, to form a linear time-delay state vector. The final feature vector
\mathbf{r}_{i}
is created by generating unique monomials of orders
O
from this state vector, introducing nonlinearity into the model.
[
25
]

This way given a d-dimensional time series
\mathbf{X}
, a matrix of feature vectors
\mathbf{R}(\mathbf{X},k,s,O)=(\mathbf{r}_{1},\mathbf{r}_{2},\ldots,\mathbf{r}_{n})
can be generated. Training is simplified by optimizing only the output layer
\mathbf{W}_{out}
which maps the feature vectors onto the difference between the current point and the next point in time using ridge regression, such that

\mathbf{x}_{i+1}=\mathbf{x}_{i}+\mathbf{W}_{out}\mathbf{r}_{i+1}.

(1)

To parameterize the feature vector of the NGRC, the approach introduced in
[
29
]
is followed, wherein the parameter
\theta
multiplied by a scaling factor
\gamma
is added to each element of the feature vector, resulting in
\mathbf{r}_{i}^{\prime}=\mathbf{r}_{i}+\gamma\theta
. Additionally,
\mathbf{r}_{i}^{\prime}
is expanded by including its own powers up to order
O_{\text{states}}
to generate the parametrized feature vector
\widetilde{\mathbf{r}}_{i}
. To employ this architecture for multiple stationary dynamics during training, the concept of multifunctionality is leveraged
[
36
]
. Therefore, for each time series
\mathbf{X}_{m}
and its parameter
\theta_{m}
, the parametrized feature vectors
\widetilde{\mathbf{R}}_{m}=(\widetilde{\mathbf{r}}_{m,1},\widetilde{\mathbf{r}}_{m,2},\ldots,\widetilde{\mathbf{r}}_{m,n})
are generated along with their corresponding training targets
\mathbf{Y}_{m}
.
To optimize the output layer with this setup, the parametrized feature matrices
\widetilde{\mathbf{R}}_{m}
and the training target matrices
\mathbf{Y}_{m}
are concatenated into single matrices
\widetilde{\mathbf{R}}_{M}
and
\mathbf{Y}_{M}
, respectively. This allows the output layer
\mathbf{W}_{\text{out}}
to be learned via ridge regression by solving the optimization

\mathbf{W}_{\text{out}}=\mathbf{Y}_{M}\widetilde{\mathbf{R}}_{M}^{T}\left(\widetilde{\mathbf{R}}_{M}\widetilde{\mathbf{R}}_{M}^{T}+\beta\mathbf{I}\right)^{-1},

(2)

where
\mathbf{I}
is the identity matrix and
\beta
is the regularization parameter. If the training is successful, the structure allows the parameter
\theta
to change during the prediction, so that the prediction is performed under
\theta_{i}

\mathbf{x}_{i+1}=\mathbf{x}_{i}+\mathbf{W}_{\text{out}}\widetilde{\mathbf{r}}_{i+1}(\theta_{i+1}).

(3)

In this way, both stationary and non-stationary dynamics can be predicted, even for parameter ranges that were not seen during training. The results were obtained using a NGRC architecture with parameters
k=2
,
s=47
,
O=[1,2,3]
,
O_{\text{states}}=3
, and
\gamma=0.18
. Additionally a bias feature of
1
was included in the parameterized feature vector.

Control

Control theory refers to the study and application of methods for influencing the behavior of dynamical systems such that a desired target state is achieved. In the context of chaotic systems, these approaches are able to stabilize unstable periodic orbits by applying small perturbations through external forces. Traditional methods, such as OGY control
[
37
]
and delayed feedback control
[
38
]
, typically rely on phase space techniques, requiring detailed knowledge of the system’s underlying equations or extensive datasets. These approaches are typically limited to steering systems toward simple dynamical target states. While various extensions have been proposed
[
39
]
, including methods to "chaotify" periodic or synchronized dynamics
[
40
]
, the ability to reach arbitrary dynamical target states has only recently been demonstrated
[
28
]
. In further research
[
27
]
, this novel approach was used to compare traditional reservoir computing with next-generation reservoir computing (NGRC) in terms of the data requirements for effective control. NGRC demonstrated superior performance, requiring ten times less training data while achieving comparable control capabilities.

In this paper, we build on the control mechanism introduced in
[
28
,
27
]
to guide dynamical systems into previously unseen target states. This general framework is not restricted to the next-generation reservoir computer employed here and can also be implemented with alternative methods, such as the minimal reservoir computer, traditional reservoir computing techniques, or other suitable machine learning techniques. The core idea is to train the machine learning method to predict the desired dynamics of the system, represented as the state
\textbf{X}(\rho_{i})
at a given system parameter
\rho_{i}
. Notably, the dynamics of the desired state
\textbf{X}(\rho_{i})
do not need to be recorded beforehand for training. Instead, the system can leverage the ability to predict unseen states, as explained in the previous Section, and be trained using the available data. If the system instead evolves to a different state
Y
— due to external influences or changes in its bifurcation parameters
\rho_{j}
— an external force
\textbf{F}(t)
is applied to guide the dynamics back to the desired state
\textbf{X}(\rho_{i})
. Without this intervention, the system would persist in state
Y
, following its natural trajectory
\textbf{u}(t)
.

To compute the appropriate control force
\textbf{F}(t)
, it is necessary to predict how the system trajectory
\textbf{u}(t)
would evolve if it were in the desired state
\textbf{X}(\rho_{i})
. This hypothetical trajectory is defined as
\textbf{v}(t)
. Assuming the reservoir computer has been trained effectively, it can accurately forecast the future trajectory
\textbf{v}(t)
as if the system were in state
\textbf{X}(\rho_{i})
. By comparing this predicted trajectory to the actual system evolution in state
Y
, the control force is computed based on the difference between the actual and hypothetical trajectories:

\displaystyle\textbf{F}(t)=K(\textbf{u}(t)-\textbf{v}(t))\ ,

(4)

where
K
is a scaling parameter for the force which is set to
K=200
. This control force depends only on the observed actual system coordinates and the predicted coordinates, requiring no knowledge of the system’s underlying equations. This feature makes the approach highly versatile and applicable to real-world problems where precise mathematical models are unavailable. For a thorough analysis, we demonstrate this control strategy on a mathematical example system simulated using its known equations instead of observing a real system. In this case, the control force is incorporated by adding it to the system’s differential equations
\dot{f}
. The updated equations are then solved at each time step, incorporating the control force into the system’s evolution

\displaystyle\textbf{u}(t+\Delta{t})=\int_{t}^{t+\Delta{t}}(\dot{f}(\textbf{u}(\tilde{t}))+\textbf{F}(\tilde{t}))d\tilde{t}\ .

(5)

To ensure a smooth transition to the system’s target state without turbulence occurring, a prediction of the target state must be selected that does not exhibit turbulent behavior. Multiple prediction realizations are generated for a given target state, and their correlation dimension is calculated. If the correlation dimension of a prediction is below the
rcd
-cutoff value, which represents the highest correlation dimension of the stationary target dynamics, it is considered free of turbulence and can be used for control. Depending on the reservoir computing method used, various strategies can generate multiple prediction realizations for a given target state. In our approach, we varied the initial conditions slightly and selected the turbulence-free prediction that starts closest to the system’s current coordinates when applying the control force.

Lorenz System

We selected the Lorenz system
[
41
]
as an example to demonstrate the functionality of the control mechanisms. In the analyzed bifurcation parameter range of
\rho
, the Lorenz system exhibits periodic behavior for
\rho>100
, undergoes period doubling for
\rho<100
and transitions to chaotic behavior.
The system of equations
\dot{f}(\mathbf{x}(t,\rho))
is given by

\dot{x}=\sigma(y-x),\\
\dot{y}=x(\rho-z)-y,\\
\dot{z}=xy-\beta z,

(6)

where the parameters are set to
\sigma=10
and
\beta=\frac{8}{3}
. These equations are solved for the simulation results using the fourth-order Runge-Kutta method with a time step size of
\Delta t=0.005
.

Running window correlation dimension

To determine whether the system undergoes a smooth transition during the non-stationary process, we employ a running correlation dimension approach computed over a defined window length. This technique captures the system’s dynamic spatial complexity over time. For periodic dynamics, the running correlation dimension values remain close to 1, whereas they exceed 1 when the dynamics exhibit chaotic behavior. In the case of the chaotic target dynamics of the example Lorenz system with
\rho=99.5
, this value remains below
1.21
. During non-stationary simulation, prediction, and control, we detect a non-smooth transition if the running correlation dimension surpasses
1.21
, indicating possible turbulence, while a smooth transition is considered if it remains below this threshold. For each windowed trajectory the correlation dimension
\nu
quantifies the fractal dimensionality of the trajectory’s phase space
[
42
]
.

\displaystyle C(r)

\displaystyle={\frac{1}{W^{2}}\sum^{W}_{i,j=1}\theta(r-|\textbf{x}_{i}-\textbf{x}_{j}|)}

(7)

where
\theta
is the Heaviside function. The states are considered to be close to each other if their distance is less than the threshold distance
r
. The dimension
\nu
is determined from the scaling relation:

\displaystyle C(r)\propto r^{\nu}.

(8)

We compute
\nu
using the Grassberger–Procaccia algorithm
[
33
]
and use a window length of
W=500
time steps for the Lorenz system.
