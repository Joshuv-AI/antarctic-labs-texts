Near-Optimal Deterministic Network Decomposition and Ruling Set, and Improved MIS
Mohsen Ghaffari, Christoph Grunau

Abstract
This paper improves and in two cases nearly settles, up to logarithmically lower order factors, the deterministic complexity of some of the most central problems in distributed graph algorithms, which have been studied for over three decades: • Near-Optimal Network Decomposition : We present a deterministic distributed algorithm that computes a network decomposition in O ~ ​ ( log 2 ⁡ n ) \widetilde{O}(\log^{2}n) rounds with O ⁡ ( log ⁡ n ) O(\log n) diameter and O ⁡ ( log ⁡ n ) O(\log n) colors. This round complexity is near-optimal in the following sense: even given an ideal network decomposition, using it (in the standard way) requires round complexity equal to the product of diameter and number of colors, and that is known to be Ω ~ ​ ( log 2 ⁡ n ) \widetilde{\Omega}(\log^{2}n) . We find this near-optimality remarkable, considering the rarity of optimal deterministic distributed algorithms and that for network decomposition, even the first polylogarithmic round algorithm was achieved only recently, by Rozhon and Ghaffari [STOC 2020], after three decades. • Near-Optimal Ruling Set : We present a deterministic distributed algorithm that computes an O ⁡ ( log ⁡ log ⁡ n ) O(\log\log n) ruling set—i.e., an independent set such that each node is within its O ⁡ ( log ⁡ log ⁡ n ) O(\log\log n) distance—in O ~ ​ ( log ⁡ n ) \widetilde{O}(\log n) rounds. This is an exponential improvement on the O ⁡ ( log ⁡ n ) O(\log n) ruling set of Awerbuch, Goldberg, Luby, and Plotkin [FOCS’89], while almost matching their O ⁡ ( log ⁡ n ) O(\log n) round complexity. Our result’s round complexity nearly matches the Ω ~ ​ ( log ⁡ n ) \widetilde{\Omega}(\log n) lower bound of Balliu, Brandt, Kuhn, and Olivetti [STOC 2022] that holds for any poly ⁡ ( log ⁡ log ⁡ n ) \operatorname{\text{{\rm poly}}}(\log\log n) ruling set. • Improved Maximal Independent Set (MIS) : We present a deterministic distributed algorithm for computing an MIS in O ~ ​ ( log 5 / 3 ⁡ n ) \widetilde{O}(\log^{5/3}n) rounds. This improves on the O ~ ​ ( log 2 ⁡ n ) \widetilde{O}(\log^{2}n) complexity achieved by Ghaffari and Grunau [STOC 2023] and breaks the log-squared barrier necessary for any method based on network decomposition. By known reductions, the O ~ ​ ( log 5 / 3 ⁡ n ) \widetilde{O}(\log^{5/3}n) round complexity also applies to deterministic algorithms for maximal matching, Δ + 1 \Delta+1 vertex coloring, and ( 2 ​ Δ − 1 ) (2\Delta-1) edge coloring. Also, via the shattering technique, the improvement spreads also to randomized complexities of these problems, e.g., the new state-of-the-art randomized complexity of Δ + 1 \Delta+1 vertex coloring is now O ~ ​ ( ( log ⁡ log ⁡ n ) 5 / 3 ) \widetilde{O}((\log\log n)^{5/3}) .

Introduction

We present improved deterministic algorithms for three of the central problems in the area of distributed graph algorithms, which have been studied for over three decades:
Network Decomposition
(ND),
Ruling set
(RS), and
Maximal Independent Set
(MIS).
For the network decomposition and ruling set problems, our algorithms almost settle the round complexity up to logarithmically smaller factors. For MIS, our algorithm breaks a natural barrier of previous methods.

1.1
Context

Distributed model.

We work with the standard synchronous message-passing model of distributed computing, often referred to as the
\mathsf{LOCAL}
model, due to Linial
[
Lin87
]
. The network is abstracted as an
n
-node undirected graph
G=(V,E)
, where each node represents one processor and an edge between two nodes indicates that those two processors can communicate directly. Each processor has a unique
b
-bit identifier, where we typically assume
b=O(\log n)
. Initially, nodes do not know the network topology
G
, except for potentially knowing some global parameters such as a polynomial upper bound
N\in[n,\operatorname{\text{{\rm poly}}}(n)]
on
n
. Computations and communications take place in synchronous rounds. Per round, each process/node can send one message to each of its neighbors, receives their messages, and then performs arbitrary computations. In the
\mathsf{LOCAL}
model, the message sizes are not bounded. The model variant where message sizes are limited to
O(\log n)
-bits is called
\mathsf{CONGEST}

[
Pel00
]
. At the end of the computation, each node should know its own output, e.g., in the MIS problem, each node should know whether it is in the computed independent set.

Deterministic distributed algorithms.

Devising efficient deterministic distributed algorithms is known to be challenging. Linial, in his celebrated work
[
Lin87
,
Lin92
]
, wrote “
Getting a deterministic polylog-time algorithm for MIS seems hard, though simple randomized distributed algorithms are known.
” The latter referred to
O(\log n)
round randomized MIS algorithms of Luby
[
Lub86a
]
and Alon, Babai, and Itai
[
ABI86
]
. For a long time, the best known deterministic complexity was
2^{O(\sqrt{\log n})}

[
AGLP89
,
PS92
]
. The first
\operatorname{\text{{\rm poly}}}(\log n)
round deterministic MIS algorithm was presented by Rozhon and Ghaffari
[
RG20
]
. The key ingredient was a deterministic
\operatorname{\text{{\rm poly}}}(\log n)
round algorithm for network decomposition. There have been improvements since then, some
[
GGR21
,
EHRG22
]
based on refinements of
[
RG20
]
, and others via different methods
[
GK21
,
GGH+23
,
FGG+23
,
GG23
]
. Our work contributes to, and partially closes, this line with new technical ingredients that nearly settle the complexity for network decomposition and ruling set, and break a barrier for MIS.

1.2
Network Decomposition

Network decomposition was defined in the pioneering work of Awerbuch, Goldberg, Luby, and Plotkin
[
AGLP89
]
as a general and powerful tool for devising distributed algorithms, especially deterministic ones (though it also has wide applications in randomized algorithms). Given an
n
-node graph
G=(V,E)
, a
Network Decomposition
(ND) of it with
c(n)
colors
and
d(n)
diameter
is a partitioning of vertices into sets
V_{1},V_{2},\dots,V_{c(n)}
such that, in the subgraph
G[V_{i}]
induced by each
color class
V_{i}
, each connected component has diameter at most
d(n)
.

General recipe for using network decomposition.

If we are given an ND with small
c(n)
and
d(n)
, it vastly simplifies the task of building a distributed algorithm, often boiling down the problem to (a few iterations of) those in low-diameter graphs, where global coordination is easy. For instance, we can compute an MIS easily in
O(c(n)\cdot d(n))
rounds: we have
c(n)
stages, one for each color class. In stage
i
, we compute an MIS
S_{i}
of the (non-eliminated) nodes in
V_{i}
in
O(d(n))
rounds, by leveraging the diameter of each component of
G[V_{i}]
, and we then add
S_{i}
to the output MIS and mark as
eliminated
all neighbors of
S_{i}
in color classes
V_{i+1}
,
V_{i+2}
, …,
V_{c(n)}
.

More generally, it is simple and known that one can use this ND-based approach as a general recipe to turn
any sequential local algorithm
(formally, an algorithm in the
\mathsf{SLOCAL}
model, and informally including any greedy algorithm where we decide about different elements sequentially, each based on the decisions made already in its constant-hop neighborhood) into
a distributed local algorithm
, in the
\mathsf{LOCAL}
model, with
O(c(n)\cdot d(n))
round complexity. See
[
GKM17
]
for details.

Existential bounds.

For any
n
-node graph, there exists a network decomposition with
c(n)=O(\log n)
colors and
d(n)=O(\log n)
diameter
[
AP90
,
LS93
]
. These are often regarded as the ideal bounds. Once given, the time to use such a decomposition—in the standard way, as done above—is
O(c(n)\cdot d(n))=O(\log^{2}n)
. It is also known that this is roughly the right bound, in the sense if we have
c(n)
color and
d(n)
diameter network decomposition for all
n
-node graphs, then
c(n)\cdot d(n)=\widetilde{\Omega}(\log^{2}n)
: on one hand, since there are graphs with chromatic number
\Omega(\log^{2}n)
and girth
\Omega(\log n/\log\log n)
[
Bol04
]
, if
d(n)=o(\log n/\log\log n)
, we must have
c(n)=\Omega(\log^{2}n)
. The reason is that if
d(n)
is below the girth, each component of each color class induces a tree and thus can be
2
colored, which means that the chromatic number is at most
2c(n)
.
On the other hand, Linial and Saks
[
LS93
, Theorem 3.2]
showed a graph where if
c(n)=o(\log n/\log\log n)
, then we must have
d(n)=\Omega(\log^{2}n)
. Hence, the worst-case bound is
c(n)\cdot d(n)=\Omega((\frac{\log n}{\log\log n})^{2})
.

The early work of Awerbuch et al.
[
AGLP89
]
and its later sharpening by Panconesi and Srinivasan
[
PS92
]
gave a

distributed algorithm that computes a decomposition with
2^{O(\sqrt{\log n})}

2^{O(\sqrt{\log n})}
diameter in
2^{O(\sqrt{\log n})}
rounds. Linial and Saks
[
LS93
]
gave an
O(\log^{2}n)
round
randomized
algorithm for computing an ideal decomposition with
O(\log n)
colors and
O(\log n)
diameter.

One can make their construction run
artificially
in
O(\log n)
rounds, by building the colors in parallel, but this does not seem to have any benefits once we come to using the decomposition. Moreover, the diameter in their work was based on a weaker definition, where distances are measured in the original graph rather than in the induced subgraph, but that was ironed out by Elkin and Neiman

It took over three decades, until the work of Rozhon and Ghaffari

. The state of the art algorithm gives a decomposition with

Our contribution.

We present a deterministic distributed algorithm that almost settles this long line of research, by constructing a network decomposition with
O(\log n)
colors and
O(\log n)
diameter in the round complexity of
\widetilde{O}(\log^{2}n)
.

Theorem 1.1
.

There is a deterministic distributed algorithm that in any
n
-node graph
G=(V,E)
computes a network decomposition with
O(\log n)
colors and
O(\log n)
diameter in
\widetilde{O}(\log^{2}n)
rounds of the
\mathsf{LOCAL}
model.

We view this complexity as reaching a
near-optimality
, in the following particular sense: One may construct such a decomposition faster, but the overall complexity of the construction and usage will remain
\widetilde{\Omega}(\log^{2}n)
, since just using the decomposition (in the standard way) requires
c(n)\cdot d(n)=\widetilde{\Omega}(\log^{2}n)
rounds in the worst case.

Theorem

1.1
leads to
\widetilde{O}(\log^{2}n)
-round deterministic distributed algorithms for a wide range of other problems. In particular,
\widetilde{O}(\log^{2}n)
is now the state-of-the-art complexity for all problems in the class
\mathsf{SLOCAL}(1)
, in the terminology of Ghaffari, Kuhn, and Maus
[
GKM17
]
, which roughly denotes problems solvable by sequential algorithms where each decision depends on its
O(1)
neighborhood. Here are two example problems: (I)
greedy coloring
[
GKK+09
]
: properly color vertices subject to the constraint that a node can have color
i
only if colors
1
to
i-1
are present among its neighbors. (II)
maximal set without forbidden subgraphs
: Given a constant size forbidden subgraph
H
, compute a maximal set
S
of vertices of our graph
G=(V,E)
such that the induced subgraph
G[S]
does not have a copy of
H
. For both problems, this
\widetilde{O}(\log^{2}n)
deterministic complexity almost matches the state-of-the-art randomized complexity
O(\log^{2}n)
. The best current randomized algorithms are also based on network decomposition. This
\widetilde{O}(\log^{2}n)
complexity is (nearly) the best that one can achieve via the generic network decomposition recipe.

General distributed derandomizations and their slow down.

Network decomposition is also central to general derandomizations of distributed algorithms. For any locally checkable problem (roughly meaning a problem where the solution can be verified in constant rounds)
[
NS95
]
, any
r(n)
-round randomized algorithm can be transformed into a deterministic algorithm with
O(r(n)\cdot c(n)\cdot d(n)+r(n)\cdot t(n))
round complexity
[
GKM17
,
GHK18
]
, assuming there is a
t(n)
-round algorithm for computing a network decomposition with
c(n)
colors and
d(n)
diameter. This is roughly based on the general recipe of using network decompositions along with a method of conditional expectations.
Theorem

1.1
gives the best known efficiency for such a general derandomization of distributed graph algorithms. It achieves a slow-down factor of
\widetilde{O}(\log^{2}n)
, which is nearly the best possible via (the standard usage of) network decomposition. It is also known that an
\Omega(\log n/\log\log n)
slow down is necessary, in the worst case, for such a general derandomization: e.g., the sinkless orientation problem has tight randomized complexity
\Theta(\log\log n)

[
CKP16
,
GS17
,
BFH+16
]
and tight deterministic complexity
\Theta(\log n)
[
CKP16
,
GS17
]
.

1.3
Ruling Set

Ruling Set is a generalization/relaxation of Maximal Independent Set, defined by Awerbuch et al.
[
AGLP89
]
to achieve similar functionalities while admitting more efficient computation. One canonical way of using MIS in distributed computation is as a collection of non-adjacent
centers
such that each node of the graph has one of them nearby, namely in its direct neighborhood. Ruling sets are defined in this vein, as follows: A
\beta
-ruling set is an independent set
S\subseteq V
such that for each
v\in V
, we have
dist(S,v)\leq\beta
. In particular, an MIS is a
1
-ruling set.
2
2

2

Some literature uses the more general definition of
(\alpha,\beta)
-ruling set as a set
S\subset V
where every two nodes in
S
have distance at least
\alpha
, and each node
v\in V
has a node in
S
within its
\beta
-hops. In this terminology, a (2,1)-ruling set is simply an MIS. One can require distance at least
\alpha
in
G
with independence in the graph power
G^{\alpha-1}
. Thus, up to small rounding imprecisions, it suffices for us to fix
\alpha=2
and use the simpler notation
\beta
-ruling set.
Naturally, we are primarily interested in very small values of
\beta
.

Known results.

The work of Awerbuch et al.
[
AGLP89
]
showed a deterministic algorithm for computing an
O(\log n)
ruling set in
O(\log n)
rounds. Before our work, there was no known (polylogarithmic-time) deterministic algorithm for smaller
\beta
values, except the trivial case of the MIS problem itself, which required higher polylogarithmic complexity, as we discuss in the next subsection.
In contrast, there is a randomized algorithm that computes an
O(\log\log n)
ruling set in
O(\log\log n)
rounds
[
SEW13
]
, and this is frequently used, e.g., in the shattering frameworks
[
BEPS16
,
Gha16
]
. See
[
Gha16
,
BBKO22
]
for tradeoff results, and a survey of other work focusing on graphs with small maximum degree
\Delta
.

Our contribution.

We present a deterministic algorithm that computes an
O(\log\log n)
ruling set in
\widetilde{O}(\log n)
rounds. This is an exponentially better
\beta
parameter compared to Awerbuch et al.
[
AGLP89
]
, in essentially the same complexity.

Theorem 1.2
.

There is a deterministic distributed algorithm that in any
n
-node graph
G=(V,E)
computes an
O(\log\log n)
ruling set in
\widetilde{O}(\log n)
rounds of the
\mathsf{LOCAL}
model.

The round complexity of this algorithm almost matches a lower bound of Balliu et al.
[
BBKO22
]
: They showed that deterministically computing an
O(\log\log n)
ruling set requires
\Omega(\frac{\log n}{\log^{2}\log n})
rounds and more generally, for any
\beta\leq\Theta(\sqrt{\frac{\log n}{\log\log n}})
, any deterministic
\beta
-ruling set algorithm requires at least
\Omega(\frac{\log n}{\beta\log\log n})
rounds.

1.5
An overview of the new ingredients

Our work builds on top of several recently developed techniques, e.g., the local rounding method for distributed derandomization of algorithms analyzed with pairwise independence
[
GK21
,
FGG+23
]
, derandomizations
[
GGH+23
]
of MPX-style network decomposition
[
MPX13
]
, and efficient computation of MIS by interweaving fast decomposition constructions with local rounding
[
GG23
]
. Our improvements involve three new major ingredients, along with smaller ideas throughout. We provide a brief overview of these main novelties here.

The first ingredient, which we discuss in
Section

1.5.1
, is a stronger deterministic “
sampling
” mechanism. It allows us to deterministically select a sparse subset of vertices, such that it has the “
right proportion
” of intersection with almost all neighborhoods. This sampling plays a key role in all our results, and in particular, it leads almost directly to our near-optimal ruling set algorithm (via smaller manipulations). Our network decomposition and maximal independent set results both involve two additional ingredients.

The second ingredient, which we discuss in
Section

1.5.2
, is a novel method for derandomizing network decomposition constructions based on
head start
values (in the style of the randomized algorithm of Miller, Peng, and Xu
[
MPX13
]
). This ingredient together with our stronger sampling result gives a novel method to build a network decomposition. However, with just these, the round complexity remains
\widetilde{O}(\log^{3}n)
.

The third ingredient, which we discuss in
Section

1.5.3
, is a careful recursive computation structure for network decomposition and maximal independent set. For instance, in network decomposition, this ingredient effectively constructs different colors of network decomposition simultaneously, sharing a lot of computation work among them. This recursion also leverages the computational structure provided by the new network decomposition derandomization of the second ingredient.

1.5.1
Stronger deterministic sampling, with simultaneous upper and lower bounds

A key ingredient for our results is a stronger method for deterministically computing a sparse “
sample
” subset, which approximately mimics guarantees of randomized sampling with probability
p
. Consider for instance the setup of a bipartite graph
H=(U\sqcup V,E)
with the promise that
\min_{u\in U}|\Gamma_{H}(u)|\geq\Omega(1/p)^{2}
. We would like to choose a subset
V^{\prime}\subseteq V
so that, for nearly all vertices
u\in U
, we have
\frac{|\Gamma_{H}(u)\cap V^{\prime}|}{|\Gamma_{H}(u)|}\in[p^{1.01},p]
. Our new deterministic sampling achieves this, in roughly
\widetilde{O}(\log(1/p))
rounds modulo
O(\log^{*}n)
factors. The fraction, or more generally the importance-weighted fraction, of nodes
u
that do not satisfy the condition is
\operatorname{\text{{\rm poly}}}(p)
. See
Section

3
for the precise statement and proofs. We comment that a similar sampling scheme was a key ingredient in the
\widetilde{O}(\log^{2}n)
-round MIS algorithm of Ghaffari and Grunau
[
GG23
]
, but with one major caveat: they could ensure a
lower bound
for most
\frac{|\Gamma_{H}(u)\cap V^{\prime}|}{|\Gamma_{H}(u)|}
but not a simultaneous
upper bound
. Instead, they worked with one global upper bound of
\frac{|V^{\prime}|}{|V|}\leq p
. Achieving the lower and upper bounds simultaneously, for all but
\operatorname{\text{{\rm poly}}}(p)
fraction of neighborhoods, and especially in roughly
\widetilde{O}(\log(1/p))
rounds is a key source of strength in our sampling result. This is evidenced by how it almost directly leads to our near-optimal ruling set algorithm, which we present in
Section

4
. The sampling builds in part on the local rounding method for distributedly derandomizing pairwise analysis
[
GK21
,
FGG+23
]
, along with a recursive pipelining/bootstrapping approach that approximately enforces the upper and lower bounds simultaneously.

1.5.2
A novel derandomization approach to MPX-style network decomposition

The
\widetilde{O}(\log^{3}n)
round deterministic network decomposition algorithm of
[
GGH+23
]
is based on derandomizing the randomized clustering algorithm of Miller, Peng, and Xu (MPX)
[
MPX13
]
. We first review the randomized MPX algorithm. Then, we sketch the derandomization of MPX given in
[
GGH+23
]
. Afterward, we sketch our new derandomization approach.

MPX Clustering.

The randomized clustering of Miller, Peng, and Xu (MPX) computes a partition of the vertices into clusters of diameter
O(\log n)

[
MPX13
]
, such that in expectation at most half of nodes have neighbors in other clusters. By removing such nodes, one can also get non-adjacent low-diameter clustering for half of the nodes. The algorithm computes the clustering in two steps:

1.

Random Head Starts:
Each vertex
v
is assigned a random head start
h(v)
drawn from a geometric distribution with parameter
1/2
.

2.

Partition based on Head Starts:
Each node
u
joins the cluster of the node
v
that minimizes
d(u,v)-h(v)
, favoring nodes with larger identifier. This means nodes prefer to join clusters with closer centers and larger head starts.

The resulting partition has strong-diameter at most
\max_{v\in V(G)}h(v)
, and therefore
O(\log n)
with high probability. More generally, if one assigns each vertex
v
a random head start
h(v)
from a geometric distribution with parameter
p=n^{-1/k}
, then the resulting partition has diameter
O(k)
, with high probability. For
k\leq\log^{1-\varepsilon}(n)
, the resulting partition has the property that each node neighbors at most
n^{O(1/k)}
clusters, with high probability. Ghaffari and Grunau provided a deterministic algorithm that computes a partition that almost matches these guarantees: It has diameter
O(k)
and each node neighbors at most
n^{\widetilde{O}(1/k)}
different clusters. Their algorithm computes the partition in
\widetilde{O}(k^{2}\log n)
rounds
[
GG23
]
. They used this partition, for
k=\sqrt{\log n}
, to derandomize each of the
O(\log n)
rounds of Luby’s randomized MIS algorithm in
\widetilde{O}(\log n)
rounds, leading to a deterministic MIS algorithm with round complexity
\widetilde{O}(\log^{2}n)
rounds.

Deterministic head start computation of
[
GGH+23
]

The random head start
h(v)
assigned to a given node can be determined by repeatedly flipping a coin until the first time it comes up tails;
h(v)
is the total number of heads before the first tail. The algorithm of
[
GGH+23
]
derandomizes these coin flips one by one. It first determines for all nodes whether the first coin flip of each of them comes up heads or tails. Next, it determines the second coin flip of all nodes whose first coin was heads, and so on. Each of the
O(\log n)
derandomization steps boils down, informally, to the following hitting set problem: Given a bipartite graph
H=(U\sqcup V,E)
, compute a subset
V^{\prime}\subseteq V
with
|V^{\prime}|\leq|V|/2
such that at most a
\frac{1}{100\log(n)}
-fraction of the nodes in
U
are bad. Here we call a node
u\in U

bad
if the following holds:
u
has at least
\operatorname{\text{{\rm poly}}}(\log\log n)
neighbors but none of them is in
V^{\prime}
. They gave an algorithm to compute such a subset in
\operatorname{\text{{\rm poly}}}(\log\log n)
rounds in
H
. The input graph
H
to the hitting set instance is a virtual graph on top of the actual graph
G
, and simulating each round in
H
takes
O(\log n)
rounds. Therefore, each of the
O(\log n)
derandomization steps takes
\widetilde{O}(\log n)
rounds, leading to a complexity of
\widetilde{O}(\log^{2}n)
rounds.

Our new deterministic head start computation

We provide a new way to compute the head starts using our stronger deterministic sampling result, leading to an alternative MPX derandomization with the same round complexity. The maximum head start assigned to any node is
O(\log n)
, with high probability. Therefore, each head start can be represented in binary using
\approx\log\log(n)
bits. Our derandomization fixes the bits in the binary representation one by one, starting with the most significant bit. This reduces the number of derandomization steps from
O(\log n)
to
O(\log\log n)
. However, determining each bit in the binary representation boils down to a more complicated deterministic sampling problem. For example, determining the most significant bit roughly boils down to the following sampling problem: Given a bipartite graph
H=(U\sqcup V,E)
, compute a subset
V^{\prime}\subseteq V
such that at most a
\frac{1}{100\log\log(n)}
-fraction of the nodes in
U
are bad, where we call a node
u\in U

bad
if one the following holds: (1)
u
has at least
{n^{0.5+\varepsilon}}
neighbors and none of them are included in
V^{\prime}
, or (2)
u
has
{n^{0.5+\varepsilon}}
neighbors in
V^{\prime}
. Here, the reader can imagine
\varepsilon
as a tiny positive constant, though in our technical results, we will make it and use it as a subconstant. We can compute such a subset
V^{\prime}
in
\widetilde{O}(\log n)
rounds in
H
using our new deterministic sampling result. The input graph
H
is again a virtual graph on top of the actual graph
G
, and simulating each round in
H
takes
O(\log n)
rounds in
G
. Therefore, determining the most significant bit takes
\widetilde{O}(\log^{2}n)
rounds.

1.5.3
Simultaneous (recursive) constructions sharing work

The standard way to build a network decomposition is as follows: one clusters at least half of the yet uncolored nodes into non-adjacent clusters with diameter
d(n)
. Then, one assigns all of the clustered nodes the same new color. After
O(\log n)
iterations, each node is assigned a color, and therefore one obtains a
(c(n),d(n))
-network decomposition with
c(n)=O(\log n)
. All of the previous
\operatorname{\text{{\rm poly}}}(\log n)
-round deterministic network decomposition algorithms follow this template. For example, the MPX derandomization of
[
GGH+23
]
presented in the previous section leads to a deterministic algorithm that clusters at least half of the nodes into non-adjacent clusters of diameter
O(\log n)
running in
\widetilde{O}(\log^{2}n)
rounds. Plugging this algorithm into the template above therefore indeed leads to a network decomposition algorithm with round complexity
\widetilde{O}(\log^{3}n)
.

Our new derandomization of MPX can similarly be used to obtain a new network decomposition algorithm with the same round complexity of
\widetilde{O}(\log^{3}n)
. However, our new derandomization scheme opens the door to further improve this complexity to
\widetilde{O}(\log^{2}n)
.

Recall that our derandomization fixes the
\approx\log\log n
bits of the binary representation of the head starts one by one, starting with the most significant bit. Determining the most significant bit already takes
\widetilde{O}(\log^{2}n)
rounds. However, each subsequent bit can be determined faster and faster, and the least significant bit can be determined in just
\widetilde{O}(\log n)
rounds. Assigning each node one of
c(n)=O(\log n)
colors boils down to computing
c(n)
different head starts for each node, one for each color. Let
v
be a node and
h_{1}(v),\ldots,h_{c(n)}(v)
such that
h_{i}(v)
is the head start assigned to
v
for determining which of the yet uncolored nodes receive color
i
. Instead of computing
h_{i}(v)
from scratch, we manage to share and reuse much of computational work among these: in particular, in our approach,
h_{i}(v)
is partially determined by the previous head starts assigned to
v
. For instance, the most significant bit of
h_{i}(v)
actually coincides with the most significant bit of
h_{1}(v)
. This in particular leverages the property of our deterministic sampling mechanism that the fraction of
bad nodes
in the samplings used for the earlier bits is considerably lower. In general, across the
c(n)
iterations, we recompute the
j
-th most significant bit only
2^{j}
times in total. Computing the
j
-th most significant bit takes
\widetilde{O}(\log^{2}(n)/2^{j})
rounds, and therefore we spend in total
\widetilde{O}(\log^{2}n)
rounds for the
2^{j}
times we recompute the
j
-th most significant bit. As there are
O(\log\log n)
bits, we spend
\widetilde{O}(\log^{2}n)
rounds for computing the
O(\log n)
different head start values for each node. This ultimately leads to a network decomposition with an improved round complexity of
\widetilde{O}(\log^{2}n)
.

The above describes the process for our network decomposition algorithm. We use a similar scheme of sharing work, and in particular the recursive structure of the computations, in our algorithm for the maximal independent set problem.

2.1
Clustering and head start functions

We formally define clusterings and their various properties, along with head start functions in MPX-style decomposition (mentioned previously in
Section

1.5.2
) and how they give rise to clustering.

Definition 2.1

(Clustering, Partition, Cluster Degree of a Vertex, and Cluster Diameter)
.

A subset
C\subseteq V(G)
is called a cluster. The (strong)-diameter of a cluster is defined as
\max_{u,v\in C}d_{G[C]}(u,v)
.
A clustering
\mathcal{C}
is a set of disjoint clusters. We refer to
\mathcal{C}
as a partition if
\bigcup_{C\in\mathcal{C}}C=V(G)
. The diameter of a clustering
\mathcal{C}
is defined as the maximum diameter of all its clusters.
For a node
u\in V(G)
and a clustering
\mathcal{C}
, we define the degree of
u
with respect to
\mathcal{C}
as
deg_{\mathcal{C}}(u)=|\{C\in\mathcal{C}\colon d(C,u)\leq 1\}|
. We sometimes refer to
\max_{u\in V(G)}\deg_{\mathcal{C}}(u)
as the degree of this clustering.

Definition 2.2

(Head start function and its Badness
bad_{h,d}(u)
)
.

Consider a head start function
h\colon V(G)\mapsto\mathbb{N}
,
d\in\mathbb{N}
and
u\in V(G)
. For any
d^{\prime}\in\mathbb{N}
, we define

S_{d^{\prime}}(u)=\{v\in V(G)\colon dist_{G}(u,v)=d^{\prime}\}.

That is,
S_{d^{\prime}}(u)
consists of all nodes in
G
of distance exactly
d^{\prime}
to
u
. We define the related badness

bad_{h,d}(u)=\max_{d^{\prime}\in\{0,1,\ldots,d\}}\left|\left\{v\in S_{d^{\prime}}(u)\colon h(v)=\max_{v^{\prime}\in S_{d^{\prime}}(u)}h(v^{\prime})\right\}\right|.

The next lemma shows how a given head start function with small headstart values and small badness leads to a partition with small cluster diameters and small cluster degrees:

Lemma 2.1

(Partition given Head Starts)
.

Let
D\in\mathbb{N}
and consider a head start function
h\colon V(G)\mapsto\mathbb{N}_{0}
with
\max_{v\in V(G)}h(v)\leq D
. There exists a distributed algorithm that computes in
O(D)
rounds a partition
\mathcal{C}
with diameter at most
5D
such that for any node
u\in V(G)
, the degree of
u
with respect to
\mathcal{C}
is at most
10D\cdot bad_{h,10D}(u)
.

Proof Sketch.

Put each node
u
in the cluster centered at node
v
where
v
minimizes
dist(u,v)-5h(v)
. Ties in this measure are broken arbitrarily but consistently, e.g., always toward the node
v
with the smallest identifier.

Since
h(u)\geq 0
, we have
dist(u,u)-5h(u)\leq 0
. Hence, for each node
u
, its distance to its cluster center
v
—which minimizes
dist(u,v)-5h(v)
— satisfies
dist(u,v)\leq 5h(v)\leq 5D
. Since ties are broken consistently, each cluster has strong-diameter at most
5D
. The reason is that the node
v^{\prime}
one step closer to
v
on the shortest path from
u
to
v
must have also chosen
v
as its cluster center.

For each node
u
, we know that its degree
deg_{\mathcal{C}}(u)=|\{C\in\mathcal{C}\colon d(C,u)\leq 1\}|
in this clustering is at most
10D\cdot bad_{h,10D}(u)
. The reason is that for each particular distance value
d^{\prime}\in[0,10D]
, there are at most
bad_{h,10D}(u)
centers at distance exactly
d^{\prime}
from
u
whose cluster can be within distance
1
of
u
. The reason for this is that, since
h
has been multiplied by
5
, only nodes
v^{\prime}\in\left\{v\in S_{d^{\prime}}(u)\colon h(v)=\max_{v^{\prime}\in S_{d^{\prime}}(u)}h(v^{\prime})\right\}
can be centers at distance exactly
d^{\prime}
from
u
who are the centers of clusters within distance
1
of
u
. Those that are not in this set and have a distance exactly
d^{\prime}
from
u
will have
dist(u,v^{\prime})-5h(v^{\prime})
at least
5
units smaller than
d^{\prime}-h(v)
, and thus they cannot be directly neighboring
u
or including it (the center of the cluster of
u
provides a better minimizer for the neighbors of
u
).
∎

Definition 2.3

[Pairwise Utility and Cost Functions]

For a probabilistic/fractional assignment of labels to vertices

[cf. Lemma 2.5 of

c

H

\{1,2,\ldots,N\}

\Delta_{U}\in\mathbb{R}_{\geq 0}

3.1
Sampling with Probability
1-\varepsilon

Our starting point is the following result that, intuitively speaking, derandomizes pairwise sampling with probability
1-\varepsilon
. The result follows by a straightforward application of the local rounding framework developed in
[
GK21
,
FGG+23
]
.

Lemma 3.2
.

Let
H
be a bipartite graph with a given bipartition
V(H)=U\sqcup V
, where each vertex in
V
has a unique identifier from
\{1,2,\ldots,N\}
for some
N\in\mathbb{N}
. Let
imp\in\mathbb{R}^{U}_{\geq 0}
be a vector that assigns each node in
U
an importance and
\varepsilon\in(0,0.1]
.

There exists a deterministic distributed
\mathsf{LOCAL}
algorithm that computes in
O(\log^{*}(N)+\operatorname{\text{{\rm poly}}}(1/\varepsilon))
rounds a subset
V^{sub}\subseteq V
such that for

\displaystyle U^{bad}=\left\{u\in U\colon|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}\text{ and }\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\notin[1-\varepsilon-\varepsilon^{2},1-\varepsilon+\varepsilon^{2}]\right\}

it holds that

\sum_{u\in U^{bad}}imp(u)\leq\varepsilon^{2}\sum_{u\in U}imp(u).

In fact, the guarantees are a bit weaker compared to what pairwise independent sampling would provide, in particular if the neighborhood size of each node
u
is much larger than
\operatorname{\text{{\rm poly}}}(1/\varepsilon)
.

Proof Outline

We first define a cost function
c
that assigns each subset
V^{\prime}\subseteq V
a cost
c(V^{\prime})=\sum_{u\in U}c_{u}(V^{\prime})
.
If one includes each node
v
in
V^{\prime}
independently with probability
1-\varepsilon
, then the expected cost is small.
Namely, for any
u\in U
, the expected cost contribution
\E[c_{u}(V^{\prime})]
of
u
is
(1-\varepsilon)\cdot imp(u)
and by linearity of expectation the expected total cost is
\E[c(V^{\prime})]=(1-\varepsilon)\sum imp(u)
.
Using the rounding framework developed in
[
GK21
,
FGG+23
]
, one can compute in
O(\log^{*}(N)+\operatorname{\text{{\rm poly}}}(1/\varepsilon))
rounds a subset
V^{sub}\subseteq V
whose cost is only a
(1+\operatorname{\text{{\rm poly}}}(\varepsilon))
-factor larger compared to the expected cost incurred by random sampling.
In particular,
c(V^{sub})\leq(1-\varepsilon+\varepsilon^{6})\sum_{u\in U}imp(u)
.
Using simple but tedious calculations, one can show that
c_{u}(V^{sub})\geq 1-\varepsilon-\varepsilon^{6}+\varepsilon^{3}\mathds{1}_{\{u\in U^{bad}\}}
for every
u\in U
with
|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}
.
Assuming that
|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}
for every
u\in U
, these properties are sufficient to show that

\sum_{u\in U^{bad}}imp(u)\leq 2\varepsilon^{3}\sum_{u\in U}imp(u)\leq\varepsilon^{2}\sum_{u\in U}imp(u).

Moreover, note that one can assume without loss of generality that
|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}
for every
u\in U
, which we will assume from now on.

Cost Functions

Fix some subset
V^{\prime}\subseteq V
. For some
u\in U
, we define the cost that
u
incurs by
V^{\prime}
as

\displaystyle c_{u}(V^{\prime})=\frac{imp(u)}{\binom{|\Gamma_{H}(u)|}{2}}\left(\binom{|V^{\prime}\cap\Gamma_{H}(u)|}{2}+\frac{1-\varepsilon}{\varepsilon}\binom{|(V\setminus V^{\prime})\cap\Gamma_{H}(u)|}{2}\right)

and the overall cost as

c(V^{\prime})=\sum_{u\in U}c_{u}(V^{\prime}).

Random Subsampling

Fix some
u\in U
and assume we choose
V^{\prime}\subseteq V
randomly by including each vertex
v\in V
independently with probability
1-\varepsilon
. We next show that the expected cost that
u
incurs by
V^{\prime}
is at exactly
(1-\varepsilon)imp(u)
. First, note that we can further break down the cost into

c_{u}(V^{\prime})=\sum_{f\in\binom{{\Gamma_{H}(u)}}{2}}\left(\mathds{1}_{\{f\subseteq V^{\prime}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{f\cap V^{\prime}=\emptyset\}}\right)\frac{imp(u)}{\binom{|\Gamma_{H}(u)|}{2}}.

Now, using that

\E\left[\mathds{1}_{\{f\subseteq V^{\prime}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{f\cap V^{\prime}=\emptyset\}}\right]=(1-\varepsilon)^{2}+\frac{1-\varepsilon}{\varepsilon}\varepsilon^{2}=1-\varepsilon,

we directly get that
\E[c_{u}(V^{\prime})]=(1-\varepsilon)imp(u)
.

Derandomization

Random sampling gives a set with small expected cost. We next explain how to
deterministically
compute a subset
V^{sub}\subseteq V
whose cost is at most the expected cost by random sampling.
Concretely, a standard application of the local rounding framework in
[
GK21
,
FGG+23
]
gives that, for a given
R
, one can compute in
O(\log^{*}(N)+R)
rounds a subset
V^{sub}\subseteq V
satisfying that

c(V^{sub})\leq(1-\varepsilon)\sum_{u\in U}imp(u)+\frac{1}{R}\frac{1-\varepsilon}{\varepsilon}\sum_{u\in U}imp(u).

Note that term
(1-\varepsilon)\sum_{u\in U}imp(u)
is equal to the expected cost when sampling with probability
1-\varepsilon
and the term
\frac{1-\varepsilon}{\varepsilon}\sum_{u\in U}imp(u)
is equal to
c(\emptyset)
, the largest cost incurred by any subset.
We next give a high-level describtion of the approach. Let
H
be the graph with vertex set
V(H)=V
and where any two nodes in
V
are connected by an edge if they have a common neighbor in
U
. Namely,
E(H)=\bigcup_{u\in U}\binom{\Gamma_{H}(u)}{2}
. Now, for any
e\in E(H)
, define

w(e)=\sum_{u\in U\colon e\subseteq\Gamma_{H}(u)}\frac{imp(u)}{\binom{|\Gamma_{H}(u)|}{2}}.

Note that
\sum_{e\in E(H)}w(e)=\sum_{u\in U}imp(u)
.
There is algorithm that computes in
O(\log^{*}(N)+R)
rounds a coloring with
O(R)
colors such that the total weight of monochromatic edges is at most a
\frac{1}{R}
-fraction of the overall weight
[
GK21
]
. Let
E(H)=E_{mono}\sqcup E_{bi}
be the partition into monochromatic and bichromatic edges. We have

\sum_{e\in E_{mono}}w(e)\leq\frac{1}{R}\sum_{e\in E(H)}w(e)=\frac{1}{R}\sum_{u\in U}imp(u).

For a given subset
V^{\prime}\subseteq V
, we can break down the cost into

\displaystyle c(V^{\prime})

\displaystyle=

\displaystyle\sum_{e\in E(H)}\left(\mathds{1}_{\{e\subseteq V^{\prime}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{e\cap V^{\prime}=\emptyset\}}\right)w(e)

\displaystyle\leq

\displaystyle\sum_{e\in E_{bi}}\left(\mathds{1}_{\{e\subseteq V^{\prime}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{e\cap V^{\prime}=\emptyset\}}\right)w(e)

\displaystyle+\frac{1-\varepsilon}{\varepsilon}\sum_{e\in E_{mono}}w(e)

\displaystyle\leq

\displaystyle\sum_{e\in E_{bi}}\left(\mathds{1}_{\{e\subseteq V^{\prime}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{e\cap V^{\prime}=\emptyset\}}\right)w(e)

\displaystyle+\frac{1}{R}\frac{1-\varepsilon}{\varepsilon}\sum_{u\in U}imp(u).

Moreover, by sequentially iterating through the
O(R)
colors and using the method of conditional expectation, one can compute in
O(R)
rounds a subset
V^{sub}\subseteq V
satisfying that

\displaystyle\sum_{e\in E_{bi}}\left(\mathds{1}_{\{e\subseteq V^{sub}\}}+\frac{1-\varepsilon}{\varepsilon}\mathds{1}_{\{e\cap V^{sub}=\emptyset\}}\right)w(e)

\displaystyle\leq(1-\varepsilon)\sum_{u\in U}imp(u).

Note that any
\mathsf{LOCAL}
algorithm in
H
can be simulated in
G
with the same asymptotic round complexity. Thus, by setting
R=\lceil(1/\varepsilon^{7})\rceil
, we can conclude that there exists a deterministic algorithm that computes in
O(\log^{*}(N)+\operatorname{\text{{\rm poly}}}(1/\varepsilon))
rounds a subset
V^{sub}\subseteq V
with

\displaystyle c(V^{sub})

\displaystyle\leq(1-\varepsilon)\sum_{u\in U}imp(u)+\frac{1}{\lceil(1/\varepsilon^{7})\rceil}\frac{1-\varepsilon}{\varepsilon}\sum_{u\in U}imp(u)

\displaystyle\leq(1-\varepsilon+\varepsilon^{6})\sum_{u\in U}imp(u).

Lower Bounding the Cost

We next derive a lower bound on the cost incurred by
V^{sub}
in terms of
U^{bad}
. In particular, we show that

c(V^{sub})\geq(1-\varepsilon-\varepsilon^{6})\sum_{u\in U}imp(u)+\varepsilon^{3}\sum_{u\in U^{bad}}imp(u).

In particular, we show that

c_{u}(V^{sub})\geq(1-\varepsilon+\varepsilon^{3}\mathds{1}_{\{u\in U^{bad}\}}-\varepsilon^{6})imp(u)

for every
u\in U
(
|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}
).

Fix some
u\in U
and consider the function
f(\delta)=\delta^{2}+\frac{1-\varepsilon}{\varepsilon}(1-\delta)^{2}
. A simple but tedious calculation, given below, gives a lower bound on
c_{u}(V^{sub})
in terms of
f
. In particular,

c_{u}(V^{sub})\geq imp(u)\left(f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right)-\varepsilon^{6}\right).

Using simple calculus, one can show that
f(\delta)\geq 1-\varepsilon+\varepsilon^{3}\mathds{1}_{\{\delta\notin[1-\varepsilon-\varepsilon^{2},1-\varepsilon+\varepsilon^{2}]\}}
for every
\delta\in[0,1]
, which directly leads to the desired lower bound of

c_{u}(V^{sub})\geq(1-\varepsilon+\varepsilon^{3}\mathds{1}_{\{u\in U^{bad}\}}-\varepsilon^{6})imp(u).

It remains to show that indeed

c_{u}(V^{sub})\geq imp(u)\left(f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right)-\varepsilon^{6}\right)

for every
u\in U
. First, note that

\displaystyle\left(|\Gamma_{H}(u)\cap V^{sub}|\right)^{2}+\frac{1-\varepsilon}{\varepsilon}\left(|\Gamma_{H}(u)\setminus V^{sub}|\right)^{2}

\displaystyle=\;

\displaystyle(|\Gamma_{H}(u)|)^{2}f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right).

Therefore,

\displaystyle c_{u}(V^{sub})=

\displaystyle\sum_{e\in E(H)\cap\binom{V^{sub}}{2}}w_{u}(e)+\sum_{e\in E(H)\cap\binom{V\setminus V^{sub}}{2}}\frac{1-\varepsilon}{\varepsilon}w_{u}(e)

\displaystyle=\frac{imp(u)}{\binom{|\Gamma_{H}(u)|}{2}}\left(\binom{|\Gamma_{H}(u)\cap V^{sub}|}{2}+\frac{1-\varepsilon}{\varepsilon}\binom{|\Gamma_{H}(u)\setminus V^{sub}|}{2}\right)

\displaystyle=\frac{1}{2}\frac{imp(u)}{\binom{|\Gamma_{H}(u)|}{2}}\left((|\Gamma_{H}(u)\cap V^{sub}|)^{2}-|\Gamma_{H}(u)\cap V^{sub}|+\frac{1-\varepsilon}{\varepsilon}\left((|\Gamma_{H}(u)\setminus V^{sub}|)^{2}-|\Gamma_{H}(u)\setminus V^{sub}|\right)\right)

\displaystyle\geq\frac{imp(u)}{|\Gamma_{H}(u)|^{2}}\left((|\Gamma_{H}(u)\cap V^{sub}|)^{2}+\frac{1-\varepsilon}{\varepsilon}(|\Gamma_{H}(u)\setminus V^{sub}|)^{2}-\left(|\Gamma_{H}(u)\cap V^{sub}|+\frac{1-\varepsilon}{\varepsilon}|\Gamma_{H}(u)\setminus V^{sub}|\right)\right)

\displaystyle\geq\frac{imp(u)}{|\Gamma_{H}(u)|^{2}}\left(|\Gamma_{H}(u)|^{2}f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right)-\frac{1}{\varepsilon}|\Gamma_{H}(u)|\right)

\displaystyle=imp(u)f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right)-\frac{imp(u)}{\varepsilon|\Gamma_{H}(u)|}

\displaystyle\geq imp(u)\left(f\left(\frac{|\Gamma_{H}(u)\cap V^{sub}|}{|\Gamma_{H}(u)|}\right)-\varepsilon^{6}\right),

where the last inequality follows from our assumption
|\Gamma_{H}(u)|\geq(1/\varepsilon)^{7}
.

Conclusion

The algorithm computes a subset
V^{sub}\subseteq V
with cost at most

c(V^{sub})\leq(1-\varepsilon+\varepsilon^{6})\sum_{u\in U}imp(u).

On the other hand, we have shown that the cost of
V^{sub}
is at least

c(V^{sub})\geq(1-\varepsilon-\varepsilon^{6})\sum_{u\in U}imp(u)+\varepsilon^{3}\sum_{u\in U^{bad}}imp(u).

Combining both inequalities gives

\sum_{u\in U^{bad}}imp(u)\leq 2\varepsilon^{3}\sum_{u\in U}imp(u)<\varepsilon^{2}\sum_{u\in U}imp(u),

where the last inequality follows from the input assumption
\varepsilon\leq 0.1
.

3.3
Pipelining

Next, we derive our most general result in this section. In the statement below,

to the number of inner subsampling steps, and

3.3.1
The Algorithm

Overview

. In the recursive call that further subsamples, the number of outer subsampling steps is decreased by one, i.e.,

. In the recursive call that subsamples anew, the number of repetitions is reduced by one, i.e.,
T^{\prime\prime}_{rep}=T_{rep}-1
. Therefore, the algorithm only performs recursive calls where

. For example, the first subsampling step to compute

Finally, let us discuss a key aspect in the design of this recursion: each of the three procedures used— the refinement of the headstart function, and also the two recursive calls to almost-maximal IS— drop a fraction of nodes (e.g., do not reduce their badness or have them in the neighborhood of the computed independent set) and this is also the reason that the overall scheme remains

The clustering

Thus, it remains to show that we can compute

B.1
Partial Rounding Lemma

One ingredient of

Lemma B.1

(Partial Rounding Lemma)
.

Let
\mathcal{S}
be a finite collection of sets with

for every

, where

It follows by a simple application of the Chernoff bound, which we restate here for convenience:

Theorem B.2

(Chernoff Bound)
.

Let
X:=\sum_{i\in[n]}X_{i}
, where
X_{i}
,
i\in[n]
, are independently distributed and
0\leq X_{i}\leq 1
. Then, for a given

Pr[|X-\E[X]|\geq\delta\E[X]]\leq 2e^{-\frac{\min(\delta,\delta^{2})\E[X]}{3}}.

We are now ready to prove
Lemma

B.1

Proof of
Lemma

B.1
.

First, note that we can assume without loss of generality that
x_{j}<q
for every

, which we will assume from now on. Let
(Y_{j})_{j\in S_{ground}}
be a collection of fully independent

\Pr[Y_{j}=1]=x_{j}/q
for every

. Fix some

and note that

\mathbb{E}[Z_{S}]=\sum_{j\in S}\mathbb{E}[Y_{j}]=\frac{1}{q}\sum_{j\in S}x_{j}.

Also, let

\delta_{S}=\frac{0.01\sum_{j\in S}x_{j}+10^{6}q\log(2|\mathcal{S}|)}{\sum_{j\in S}x_{j}}\geq 0.01.

By applying the Chernoff Bound from Theorem

\displaystyle\Pr\left[\left|qZ_{S}-\sum_{j\in S}x_{j}\right|\geq 0.01\sum_{j\in S}x_{j}+10^{6}q\log(2|\mathcal{S}|)\right]

\displaystyle=\Pr\left[\left|Z_{S}-\frac{1}{q}\sum_{j\in S}x_{j}\right|\geq\delta_{S}\mathbb{E}[Z_{S}]\right]

\displaystyle\leq 2e^{-\frac{\min(\delta_{S},\delta_{S}^{2})\mathbb{E}[Z_{S}]}{3}}\leq 2e^{\frac{-0.01\delta_{S}\mathbb{E}[Z_{S}]}{3}}<\frac{1}{|\mathcal{S}|}.

Thus, with positive probability, for every

\left|qZ_{S}-\sum_{j\in S}x_{j}\right|\leq 0.01\sum_{j\in S}x_{j}+10^{6}q\log(2|\mathcal{S}|).

We define the vector

Proof of

Luby’s Randomized MIS Algorithm.

The starting point is to recall Luby’s classic randomized algorithm from
[
Lub86b
]
.
The first round of Luby’s algorithm works as follows:
We mark each node
u\in V(G)
with probability
1/(20\deg(u))
. Then, for each edge
\{u,v\}\in E(G)
, let us orient the edge as
u\rightarrow v
if and only if
\deg(u)<\deg(v)
or
\deg(u)=\deg(v)
and
ID(u)<ID(v)
. For each marked node
u
, we add
u
to the independent set if and only if
v
does not have a marked out-neighbor. It is well-known that removing all nodes in the independent set along with its neighbors results in a constant fraction of edges being removed, in expectation. We next show how to get this guarantee in a deterministic manner.

Derandomizing Luby via Rounding.

We denote by
\vec{x}\in\{0,1\}^{V(G)}
the indicator vector of whether different nodes are marked, that is, we have
x_{v}=1
if
v
is marked and
x_{v}=0
otherwise. Let
R_{v}(\vec{x})
be the indicator variable of the event that
v
gets removed, for the marking vector
\vec{x}
. Let
Z(\vec{x})
be the corresponding number of removed edges. Luby’s algorithm determines the markings
\vec{x}
randomly. Our task is to derandomize this and select the marked nodes in a deterministic way such that when we remove nodes added to the independent set (those marked nodes that do not have a marked out-neighbor) and their neighbors, along with all the edges incident on these nodes, at least a constant fraction of edges gets removed.

Good and bad nodes and prevalence of edges incident on good nodes.

We call any node
v\in V(G)

good
if and only if it has at least
\deg(v)/3
incoming edges. A node
v
that is not good is called bad. It holds that

\displaystyle\sum_{\textit{good vertex\;}v}\deg(v)\geq|E(G)|/2.

(1)

Let us use
IN(u)
and

to denote in-neighbors and out-neighbors of a vertex
u

v
and consider all its incoming neighbors
u

u
such that
(\deg(u),ID(u))<(\deg(v),ID(v))
. Since
v
is good, it has at least
\deg(v)/3
such neighbors.
Hence, we have

\sum_{\textit{incoming neighbor}\;u}\frac{1}{\deg(u)}\geq 1/3.

Choose a subset

of incoming neighbors such that

\displaystyle\sum_{u\in IN^{*}(v)}\frac{1}{\deg(u)}\in[1/3,4/3].

(2)

Notice that such a subset

exists since the summation over all incoming neighbors is at least

and each neighbor contributes at most
1
to the summation.
On the other hand, notice that for any node

\displaystyle\sum_{w\in OUT(u)}\frac{1}{\deg(w)}\leq 1.

(3)

This is because
|OUT(u)|\leq\deg(u)
and for each

A sufficient event

is marked and no other node in

is marked.
By union bound, this event’s indicator is lower bounded by

x_{u}-\sum_{u^{\prime}\in IN^{*}(v),u\neq u^{\prime}}x_{u}\cdot x_{u^{\prime}}-\sum_{w\in OUT(u)}x_{u}\cdot x_{w}.

Furthermore, the events
\mathcal{E}(v,u_{1}),\mathcal{E}(v,u_{2}),\dots,\mathcal{E}(v,u_{|IN^{*}(v)|})
are mutually disjoint for different

u_{|IN^{*}(v)|}\in IN^{*}(v)

Hence, we can sum over these events for different

and conclude that

\displaystyle R_{v}(\vec{x})\geq\sum_{u\in IN^{*}(v)}\bigg(x_{u}-\sum_{u^{\prime}\in IN^{*}(v),u\neq u^{\prime}}x_{u}\cdot x_{u^{\prime}}-\sum_{w\in OUT(u)}x_{u}\cdot x_{w}\bigg)

\displaystyle=\sum_{u\in IN^{*}(v)}x_{u}-\sum_{u,u^{\prime}\in IN^{*}(v)}x_{u}\cdot x_{u^{\prime}}-\sum_{u\in IN^{*}(v)}\sum_{w\in OUT(u)}x_{u}\cdot x_{w}.

\displaystyle Z(\vec{x})\geq

\displaystyle\sum_{\textit{good vertex \,}v}(\deg(v)/2)\cdot R_{v}(\vec{x})

\displaystyle\geq

\displaystyle\sum_{\textit{good vertex \,}v}(\deg(v)/2)\cdot\bigg(\sum_{u\in IN^{*}(v)}x_{u}-\sum_{u,u^{\prime}\in IN^{*}(v)}x_{u}\cdot x_{u^{\prime}}-\sum_{u\in IN^{*}(v)}\sum_{w\in OUT(u)}x_{u}\cdot x_{w}\bigg).

Now, consider that we relax the label assignment such that it also allows for a fractional assignment

\displaystyle\left(\frac{\deg(v)}{2}\right)\cdot\bigg(\sum_{u\in IN^{*}(v)}y_{u}\cdot\left(1-\frac{1}{3}-\frac{1}{4}\right)\bigg)

\displaystyle\geq

\displaystyle\left(\frac{\deg(v)}{2}\right)\cdot\bigg(\sum_{u\in IN^{*}(v)}y_{u}\cdot\frac{5}{12}\bigg).

Finally, combining these deductions for all good vertices
v
, we obtain

\displaystyle\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y})

\displaystyle\geq

\displaystyle\sum_{\textit{good vertex \,}v}\left(\frac{\deg(v)}{2}\right)\cdot\bigg(\sum_{u\in IN^{*}(v)}y_{u}\cdot\frac{5}{12}\bigg)\geq\mathbf{u}(\vec{y})/3.

∎

Hence, we can apply
Lemma

2.2
on these fractional assignments with
\lambda_{min}=\Omega\left(\frac{1}{DEG\log(n)}\right)
. The local rounding procedure runs in
O(\log^{2}(DEG\log n))
rounds in
G^{2}
, and hence can be simulated with no asymptotic overhead in
G
, and as a result we get an integral label assignment
\vec{b}\in\{0,1\}^{V(G)}
which satisfies
\mathbf{u}(\vec{b})-\mathbf{c}(\vec{b})\geq 0.5(\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y}))
. We know that
Z(\vec{b})=\mathbf{u}(\vec{b})-\mathbf{c}(\vec{b})\geq(1/2)\cdot(\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y})).
Next, we argue that this implies
Z(\vec{b})\geq|E(G)|/24000
.

Claim B.5
.

For the fractional label assignment
\vec{y}\in[0,1]^{V(G)}
computed during the intra-cluster rounding step we have
Z(\vec{y})=\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y})\geq|E(G)|/12000
. Hence, for the integral marking assignment
\vec{b}
we obtain from rounding
\vec{y}
, we have

Z(\vec{b})=\mathbf{u}(\vec{b})-\mathbf{c}(\vec{b})\geq(1/2)\cdot(\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y}))\geq|E(G)|/24000.

Proof.

From
Claim

B.4
, we have
Z(\vec{y})=\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y})\geq\mathbf{u}(\vec{z})/3
. Hence,

\displaystyle Z(\vec{y})

\displaystyle\geq\mathbf{u}(\vec{y})/3

\displaystyle=\sum_{\textit{good vertex \,}v}(\deg(v)/2)\bigg(\sum_{u\in IN^{*}(v)}y_{u}/3\bigg)

\displaystyle\geq\sum_{\textit{good vertex \,}v}(\deg(v)/2)\cdot(1/3000)\geq|E(G)|/12000,

where we first used
Claim

B.3
that says that
\sum_{u\in IN^{*}(v)}y_{u}\geq 1/1000
and then we used
Eq.

1
that bounds
\sum_{\textit{good vertex \,}v}\deg(v)\geq|E(G)|/2
.

Since
Z(\vec{b})=\mathbf{u}(\vec{b})-\mathbf{c}(\vec{b})\geq(1/2)\cdot(\mathbf{u}(\vec{y})-\mathbf{c}(\vec{y}))
, the claim follows.
∎

Conclusion

From the rounding procedure described above, which runs in
O(D+\log^{2}(DEG\log n))
rounds of the
\mathsf{LOCAL}
model, we get an integral marking assignment
\vec{b}
with the following guarantee: if we add marked nodes
u
that have no marked out-neighbor to the independent set and remove them along with their neighbors, we remove at least a
1/24000
-fraction of the edges in
G
.
