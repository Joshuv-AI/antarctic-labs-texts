Supported Abstract Argumentation for Case-Based Reasoning
Adam Gould, Gabriel de Olim Gaul, Francesca Toni

Abstract
We introduce Supported Abstract Argumentation for Case-Based Reasoning (sAA-CBR) , a binary classification model in which past cases engage in debates by arguing in favour of their labelling and attacking or supporting those with opposing or agreeing labels. With supports, sAA-CBR overcomes the limitation of its precursor AA-CBR, which can contain extraneous cases (or spikes ) that are not included in the debates. We prove that sAA-CBR contains no spikes, without trading off key model properties.

Appendix A
Supported Abstract Argumentation for Case-Based Reasoning Definition

A
bipolar argumentation framework (BAF)

(
Cayrol and Lagasquie-Schiex 2005
)
extends the argumentation framework with the addition of a
supports
relation. A BAF is represented as
\langle\mathcal{A},\rightarrow,\Rightarrow\rangle
, where
\mathcal{A}
is a set of arguments and
\rightarrow\subseteq\mathcal{A}\times\mathcal{A}
is the attack relation and
\Rightarrow\subseteq\mathcal{A}\times\mathcal{A}
is the support relation. A BAF can be represented graphically, wherein arguments are represented by nodes and edges are represented by attacks and supports.

Definition A.1

(Supported AA-CBR)
.

Let
D\subseteq X\times Y
be a finite
casebase
of labelled examples where
X
is a set of
characterisations
and
Y=\{\delta,\bar{\delta}\}
is the set of possible outcomes. Each example is of the form
(x,y)
. Let
(x_{\delta},\delta)
be the
default argument
with
\delta
the
default outcome
. Let
N
be an
unlabelled example
of the form
(x_{N},y_{?})
with
y_{?}
an unknown outcome.
Let
\succcurlyeq
and
\nsim
be a partial order (specifying exceptionalism) and binary relation (specifying irrelevance) defined over
X
, respectively.
The bipolar argumentation framework
BAF(D,{x_{N}})
mined from
D
and
x_{N}
is
\langle\mathcal{A},\rightarrow,\Rightarrow\rangle
in which:

•

\mathcal{A}=D\cup\{(x_{\delta},\delta)\}\cup\{N\}

•

, and

2.

Appendix B
sAA-CBR Semantics

To compute which arguments are accepted, we first translate the model to an
Argumentation Framework (AF)

Dung 1995
, which can be defined as a BAF with no supports and only attacks. To do this, we make use of
supported attacks
and
secondary attacks

Cayrol and Lagasquie-Schiex 2013
.

Definition B.1

(adapted from
Cayrol and Lagasquie-Schiex 2013
)
.

Supported and secondary attacks are defined as:

•

There is a supported attack from
a\in\mathcal{A}
to
b\in\mathcal{A}
iff there is sequence
a_{1}\Rightarrow\ldots\Rightarrow a_{n-1}\rightarrow a_{n}
where
a_{1}=a
and
a_{n}=b
. That is, there is a supported attack between
a
and
b
iff there is a sequence of supports from
a
until some argument
a_{n-1}
that attacks
b
.

•

There is a secondary attack from
a\in\mathcal{A}
to
b\in\mathcal{A}
iff there is sequence
a_{1}\rightarrow\ldots\rightarrow a_{n-1}\Rightarrow a_{n}
where
a_{1}=a
and
a_{n}=b
. That is, there is a secondary attack between
a
and
b
iff there is a sequence of attacks from
a
until some argument
a_{n-1}
that supports
b
.

We can then remove all supports from the BAF and construct the AF using only the attacks, supported attacks, and secondary attacks.

When used with sAA-CBR, these
complex attacks
will always occur from more exceptional to less exceptional cases. The literature also defines other forms of attacks, such as mediated attacks
Cayrol and Lagasquie-Schiex 2013
, in which if an argument
a
attacks
b
, then
a
will also attack all arguments in the sequence of supporters of
b
. However, this clearly would lead to attacks from less exceptional to more exceptional cases, violating a key principle of AA-CBR, so we do not include these attacks.

Once the BAF has been translated to an AF, we compute the grounded semantics
Dung 1995
, telling us which arguments to accept. We say a set of arguments
E\subseteq\mathcal{A}

defends
an argument
b\in\mathcal{A}
if for all
a\rightarrow b
there exists
c\in E
such that
c\rightarrow a
. The set of accepted arguments, called the
grounded extension
, can be iteratively computed as
\mathbb{G}=\bigcup_{i\geq 0}G_{i}
, where
G_{0}
is the set of unattacked arguments and
\forall i\geq 0
,
G_{i+1}
is the set of all arguments that
G_{i}
defends.

Finally, we have sAA-CBR
(D,x_{N})=\delta
if
(x_{\delta},\delta)\in\mathbb{G}
and
\bar{\delta}
otherwise, where
\mathbb{G}
is the grounded extension of
AF(D,{N})
.

Appendix C
Spikes

We can now prove that sAA-CBR contains no spikes. We begin by defining spikes formally as:

Definition C.1
.

Given a BAF
\langle\mathcal{A},\rightarrow,\Rightarrow\rangle
generated by sAA-CBR, then
a\in\mathcal{A}
is a spike iff there is no path in
\langle\mathcal{A},\rightarrow,\Rightarrow\rangle
from
a
to
(x_{\delta},\delta)
.

We have the following theorem:

Theorem C.1
.

Given a BAF
\langle\mathcal{A},\rightarrow,\Rightarrow\rangle
generated by sAA-CBR where
x_{\delta}
is the least element of
\succcurlyeq
, then the BAF contains no spikes.

Proof.

Consider an argument
(x_{a},y_{a})\in\mathcal{A}
. We have that either
(x_{a},y_{a})
attacks or supports
(x_{\delta},\delta)
, which is possible as
x_{a}\succ x_{\delta}
, in which case
(x_{a},y_{a})
is not a spike, or there exists some case
(x_{b},y_{b})
such that
x_{a}\succ x_{b}
. Either,
(x_{b},y_{b})
is minimal to
(x_{a},y_{a})
, in which case
(x_{a},y_{a})
must attack or support
(x_{b},y_{b})
or there is some other case,
(x_{c},y_{c})
that is more minimal to
(x_{a},y_{a})
. In either case,
(x_{a},y_{a})
must have at least one attack or support from another argument to one that it is most minimal to. The same reasoning applies for the arguments
(x_{b},y_{b})
and
(x_{c},y_{c})
, which must either attack or support the default or have at least one other argument, most minimal to them, that they attack or support. This subsequent argument must either attack or support the default or another argument. We can keep applying this reasoning until the default argument is the only one to attack or support, that is, until the default argument is the most minimal to the argument we are considering. Thus, every argument has a path to the default argument.
