Abstract
. A set of reals X X is 𝔟 \mathfrak{b} -concentrated if it has cardinality at least 𝔟 \mathfrak{b} and it contains a countable set D ⊆ X D\subseteq X such that each closed subset of X X disjoint with D D has size smaller than 𝔟 \mathfrak{b} . We present ZFC results about structures of 𝔟 \mathfrak{b} -concentrated sets with the Hurewicz covering property using semifilters. Then we show that assuming that the semifilter trichotomy holds, then each 𝔟 \mathfrak{b} -concentrated set is Hurewicz and even productively Hurewicz. We also show that the appearance of Hurewicz 𝔟 \mathfrak{b} -concentrated sets under the semifilter trichotomy is somewhat specific and the situation in the Laver model for the consitency of the Borel Conjecture is different.

1.
Introduction

1.1.
Sets of reals and covering properties

We work in the realm of
sets of reals
, i.e., infinite topological spaces which are homeomorphic to subspaces of the Cantor cube
{2^{\omega}}
.
A set of reals
X
is
Menger

[
11
]
if for each sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dots
of open covers of
X
, there are finite sets
\mathcal{F}_{0}\subseteq\mathcal{U}_{0},\mathcal{F}_{1}\subseteq\mathcal{U}_{1},\dotsc
such that the family
\bigcup_{n\in\omega}\mathcal{F}_{n}
covers
X
.
If in addition the above sets
\mathcal{F}_{n}
are singletons, then the set
X
is
Rothberger

[
18
]
and if for each
x\in X
, the sets
\{\,n:x\in\bigcup\mathcal{F}_{n}\,\}
are co-finite then the set
X
is
Hurewicz

[
7
]
.
They are central properties considered in the topological selections theory and we have the following implications between them.

{\lx@inpgf@ignorespaces\begin{matrix}\sigma\text{-compact}\\
\aleph_{1}\end{matrix}}
{\lx@inpgf@ignorespaces\begin{matrix}\text{Hurewicz}\\
\mathfrak{b}\end{matrix}}
{\lx@inpgf@ignorespaces\begin{matrix}\text{Menger}\\
\mathfrak{d}\end{matrix}}
{\lx@inpgf@ignorespaces\begin{matrix}\text{Rothberger}\\
\operatorname{cov}(\mathcal{M})\end{matrix}}

Each of these properties has its own combinatorial characterization using a structure of the Baire space
{\omega^{\omega}}
.
For functions
a,b\in{\omega^{\omega}}
, we write
a\leq^{*}b
if the set
\{\,n:a(n)\leq b(n)\,\}
is cofinite.
Let
A\subseteq{\omega^{\omega}}
.
The set
A
is
bounded
, if there is a function
b\in\omega^{\omega}
such that
a\leq^{*}b
for all
a\in A
.
A subset of
{\omega^{\omega}}
is
unbounded
, if it is not bounded.
The set
A
is
dominating
, if for each function
x\in{\omega^{\omega}}
, there is a function
a\in A
such that
x\leq^{*}a
.
The set
A
is
guessable
if there is a function
g\in{\omega^{\omega}}
such that for each function
x\in A
, the sets
\{\,n:x(n)=g(n)\,\}
are infinite.
We have the following characterizations of sets of reals with the above properties.

Theorem 1.1

(Recław
[
17
, Propositions 1, 2, 4]
)
.

A set of reals
X
is Hurewicz (Menger, Rothberger) if and only if each continuous image of
X
into
{\omega^{\omega}}
is bounded (not dominating, guessable).

Let
\mathfrak{b}
be the minimal cardinality of an unbounded subset of
{\omega^{\omega}}
and
\mathfrak{d}
be the minimal cardinality of a subset of
{\omega^{\omega}}
which is dominating.
By the result of Keremedis
[
3
, Theorem 2.4.5]
, the minimal cardinality of a subset of
{\omega^{\omega}}
which is not guessable is equal to
\operatorname{cov}(\mathcal{M})
which is the minimal cardinality of a family of meager sets in
{\omega^{\omega}}
which covers
{\omega^{\omega}}
.
Theorem
1.1
leads to the conclusion that each of the considered properties has a
critical cardinality
that is the minimal cardinality of a subset of
{\omega^{\omega}}
which does not have the given property.
Those critical cardinalities were pointed out in the diagram above.

By the result of Bartoszyński–Shelah
[
4
]
there is a uniform construction of a Hurewicz set which does not contain a homeomorphic copy of the Cantor cube
{2^{\omega}}
.
By the result of Tsaban–Zdomskyy there is also a uniform construction of a Menger set which is not Hurewicz
[
25
]
.
In both cases, constructed sets are nontrivial with respect to the given property, i.e., they have cardinalities greater or equal than the critical cardinalities for the given properties, in these cases
\mathfrak{b}
and
\mathfrak{d}
, respectively.
For the Rothberger property, the situation is more subtle and the existence of a nontrivial Rothberger set is independent from ZFC.
In the Laver model for the consistency of the Borel conjecture
[
9
]
all Rothberger sets are countable.
On the other hand if the Continuum Hypothesis holds, an uncountable Rothberger set exists
[
7
]
.

1.2.
Realm of concentrated sets

In the paper we focus on sets with the following structure.

Definition 1.2
.

Let
\kappa
be an infinite cardinal number.
A set of reals
X
is
\kappa
-concentrated on a set

D\subseteq X
, if
\left|X\right|\geq\kappa
and for each open set
U
containing
D
, we have
|X\setminus U|<\kappa
.
A set is
\kappa
-concentrated
if it is concentrated on its countable subset.

These kinds of sets play a crucial role in considering combinatorial covering properties.
In ZFC there is a
\mathfrak{d}
-concentrated set
[
5
, Lemma 17]
and each such a set is Menger
[
26
, Corollary 1.14]
.
Also each
\operatorname{cov}(\mathcal{M})
-concentrated set is Rothberger but the existence of such a set is independent from ZFC.
In the case of the Hurewicz property it is independent from ZFC, that each
\mathfrak{b}
-concentrated set is Hurewicz
:

On the one hand, assuming that
\mathfrak{b}=\mathfrak{d}
, there is a
\mathfrak{b}
-concentrated set which is not Hurewicz
[
25
]
;

On the other hand, in the Miller model, each
\mathfrak{b}
-concentrated set is Hurewicz (
[
19
, Theorem 15]
,
[
24
, Theorem 3.1]
).

Let
{\operatorname{P}(\omega)}
be the power set of the set of natural numbers
\omega
.
We identify each element of
{\operatorname{P}(\omega)}
with its characteristic function, an element of
{2^{\omega}}
and in that way introduce a topology in
{\operatorname{P}(\omega)}
.
Let
{\operatorname{P}(\omega)}={[\omega]^{\omega}}\cup\mathrm{Fin}
, where
{[\omega]^{\omega}}
is the family of all infinite subsets of
\omega
and
\mathrm{Fin}
is the family of all finite subsets of
\omega
.
Identifying each element of
{[\omega]^{\omega}}
with increasing enumeration of its elements, we can view
{[\omega]^{\omega}}
as a subset of the Baire space
{\omega^{\omega}}
.
The topologies in
{[\omega]^{\omega}}
inherited from
{\operatorname{P}(\omega)}
and
{\omega^{\omega}}
are identical.
We refer to the elements of
{[\omega]^{\omega}}
as sets or functions, depending on contexts.
For practical reasons we mainly work with subspaces of
{\operatorname{P}(\omega)}
.

An example of a Hurewicz
\mathfrak{b}
-concnetrated set is a set based on a so called
\mathfrak{b}
-scale:
a set
X=\{\,x_{\alpha}:\alpha<\mathfrak{b}\,\}\subseteq{[\omega]^{\omega}}
is a
\mathfrak{b}
-scale
, if it is unbounded and for all
\alpha<\beta<\mathfrak{b}
, we have
x_{\alpha}\leq^{*}x_{\beta}
.
A
\mathfrak{b}
-scale exists in ZFC.
If
X\subseteq{[\omega]^{\omega}}
is a
\mathfrak{b}
-scale, then the set
X\cup\mathrm{Fin}
is
\mathfrak{b}
-concentrated on
\mathrm{Fin}
and it is Hurewicz
[
4
]
, which is a set constructed by Bartoszyński–Shelah, mentioned above.
In fact such a set is even
productively Hurewicz

[
13
, Theorem 6.5]
, i.e., for each Hurewicz set
Y
, the product space
(X\cup\mathrm{Fin})\times Y
is Hurewicz.

1.3.
Semifilters

Considering
\mathfrak{b}
-concentrated sets we need the following notion of semifilters.
For sets
a,b
, we write
a\subseteq^{*}b
, if the set
a\setminus b
is finite.
A nonempty set
S\subseteq{[\omega]^{\omega}}
is a
semifilter

[
2
]
, if for any sets
a\in S
and
b\in{[\omega]^{\omega}}
such that
a\subseteq^{*}b
, we have
b\in S
.
Examples of semifilters are the Frécht filter
\mathrm{cFin}
of all co-finite subsets of
\omega
, any free ultrafilter on
\omega
or the full semifilter
{[\omega]^{\omega}}
.
Let
S\subseteq{[\omega]^{\omega}}
be a semifilter.
For functions
a,b\in{[\omega]^{\omega}}
, we write
a\leq_{S}b
, if
\{\,n:a(n)\leq b(n)\,\}\in S
.
If
S
is not closed under finite intersections of its elements, then the relation
\leq_{S}
is not transitive which is the case for
S={[\omega]^{\omega}}
.
The relation
\leq^{*}
is the same as
\leq_{\mathrm{cFin}}
and we write
\leq^{\infty}
instead of
\leq_{{[\omega]^{\omega}}}
.
A set
A\subseteq{[\omega]^{\omega}}
is
\leq_{S}
-bounded
, if there is a function
b\in{[\omega]^{\omega}}
such that
a\leq_{S}b
for all functions
a\in A
.
A set
A\subseteq{[\omega]^{\omega}}
is
\leq_{S}
-unbounded
, if it is not
\leq_{S}
-bounded.
Using the above terminology a set
A\subseteq{[\omega]^{\omega}}
is
\leq_{\mathrm{cFin}}
-unbounded if it is unbounded and it is
\leq_{[\omega]^{\omega}}
-unbounded if it is dominating.
Let
\operatorname{\mathfrak{b}}(S)
be the minimal cardinality of a
\leq_{S}
-unbounded set in
{[\omega]^{\omega}}
.
We have
\operatorname{\mathfrak{b}}(\mathrm{cFin})=\mathfrak{b}
and
\operatorname{\mathfrak{b}}({[\omega]^{\omega}})=\mathfrak{d}
.
Moreover
\mathfrak{b}\leq\operatorname{\mathfrak{b}}(S)\leq\mathfrak{d}
.

By a recent result of Pawlikowski, Szewczak and Zdomskyy
[
15
, Theorem 6.1]
, in the Miller model any
\mathfrak{d}
-concentrated set has a specific combinatorial structure.
Let
U\subseteq{[\omega]^{\omega}}
be an ultrafilter.
A set
X\subseteq{[\omega]^{\omega}}
is a
U
-scale
, if
|X|\geq\operatorname{\mathfrak{b}}(U)
and for each function
b\in{[\omega]^{\omega}}
there is a set
A\subseteq X
of size smaller than
\operatorname{\mathfrak{b}}(U)
such that
b\leq_{U}x
for all functions
x\in X\setminus A
.
Let
X\subseteq{[\omega]^{\omega}}
.
In the Miller model, the set
X\cup\mathrm{Fin}
is
\mathfrak{d}
-concentrated on
\mathrm{Fin}
if and only if there is an ultrafilter
U\subseteq{[\omega]^{\omega}}
such that
X
is a
U
-scale.
In fact, in the Miller model, the above set
X
is a
U
-scale for any ultrafilter
U\subseteq{[\omega]^{\omega}}
.
By the result of Szewczak–Tsaban–Zdomskyy, this situation from the Miller model is not the case if we assume regularity of
\mathfrak{d}
and
\mathfrak{d}\leq\mathfrak{r}
, where
\mathfrak{r}
is the reaping number.
We refer to the work of Blass
[
6
]
about cardinal characteristics of the continuum and relations between them.

In Section 2 we present ZFC results about structures of
\mathfrak{b}
-concentrated Hurewicz sets using semifilters.
In Section 3, we show that assuming that the semifilter trichotomy holds

, then each
\mathfrak{b}
-concentrated set is Hurewicz and even productively Hurewicz.
In Section 3, we consider
\mathfrak{b}
-concentrated sets in the Laver model for the consistency of the Borel conjecture.
We also show that the appearance of Hurewicz
\mathfrak{b}
-concentrated sets under the semifilter trichotomy is somewhat specific and the situation in the Laver model is different.
We finish the paper with comments and open problems.

2.
ZFC results

Writing that a semifilter
S\subseteq{[\omega]^{\omega}}
is meager we mean that it is a meager subset of
{[\omega]^{\omega}}
.

Definition 2.1
.

A set
X\subseteq{[\omega]^{\omega}}
is
meager-unbounded
if
\left|X\right|\geq\mathfrak{b}
and for each function
b\in{[\omega]^{\omega}}
, there are a meager semifilter
S(b)
and a set
A\subseteq X
of size smaller than
\mathfrak{b}
such that
b\leq_{S(b)}x
for all functions
x\in X\setminus A
.

Theorem 2.2
.

Let
X\subseteq{[\omega]^{\omega}}
.
Then the following assertions are equivalent.

(1)

The set
X
is meager-unbounded.

(2)

For each
G_{\delta}
-set
G\subseteq{\operatorname{P}(\omega)}
containing
\mathrm{Fin}
, there is a
\sigma
-compact set
F\subseteq{\operatorname{P}(\omega)}
such that
F\subseteq G
and
\left|X\setminus F\right|<\mathfrak{b}
.

(3)

The set
X\cup\mathrm{Fin}
is
\mathfrak{b}
-concentrated on
\mathrm{Fin}
and for each set
A\subseteq X
of size smaller than
\mathfrak{b}
, the set
(X\setminus A)\cup\mathrm{Fin}
is Hurewicz.

In order to prove Theorem
2.2
we need the following notions and auxiliary results.

For natural numbers
n,m
with
n<m
, let
[n,m):=\{\,i:n\leq i<m\,\}
.
For sets
x\in{[\omega]^{\omega}}
,
S\subseteq{[\omega]^{\omega}}
and a function
h\in{[\omega]^{\omega}}
, define

x/h:=\{\,n\in\omega:x\cap[h(n),h(n+1))\neq\emptyset\,\}\quad\text{and}\quad S/h:=\{\,x/h:x\in S\,\}.

Lemma 2.3

(Talagrand
[
23
, Theorem 21]
)
.

A semifilter
S\subseteq{[\omega]^{\omega}}
is meager if and only if, there is a function
h\in{[\omega]^{\omega}}
such that
S/h
is the Fréchet filter
\mathrm{cFin}
.

Let
\kappa
be an uncountable cardinal number and
X\subseteq{[\omega]^{\omega}}
.
The set
X
is
\kappa
-unbounded
if
\left|X\right|\geq\kappa
and for each function
b\in{[\omega]^{\omega}}
there is a set
A\subseteq X
of size smaller than
\kappa
such that
b\leq^{\infty}x
for all functions
x\in X\setminus A
.

The next lemma is straightforward.

Lemma 2.4
.

Let
\kappa
be a cardinal with
\mathit{cof}(\kappa)>\omega
and
X\subseteq{[\omega]^{\omega}}
.
Then the set
X\cup\mathrm{Fin}
is
\kappa
-concentrated on
\mathrm{Fin}
if and only if the set
X
is
\kappa
-unbounded.

Let
\omega+1
be a space with the order topology, the one point compactification of
\omega
and consider
(\omega+1)^{\omega}
with the Tychonoff product topology.
Let
Q
be the family of all functions
f\in(\omega+1)^{\omega}
with a property that there is
n\in\omega
such that
f\restriction n
is an increasing function of natural numbers and
f(k)=\omega
for all
k\geq n
.
Then a set
(\omega+1)^{\uparrow\omega}:={[\omega]^{\omega}}\cup Q
is a closed subset of
(\omega+1)^{\omega}
and thus it is compact.
Moreover, there is a natural homeomorphism between
{\operatorname{P}(\omega)}
and
(\omega+1)^{\uparrow\omega}
which identifies a set
a\in\mathrm{Fin}
with a function
a^{\frown}\langle\omega,\omega,\dotsc\rangle
from
Q
, where we treat
a
as an increasing sequence of elements from the set
a
.
In that way we can view elements from
{\operatorname{P}(\omega)}
as those from
(\omega+1)^{\uparrow\omega}
and for all elements
a,b\in{\operatorname{P}(\omega)}
consider a set
[a<b]:=\{\,n:a(n)<b(n)\,\}
.
E.g., for
a\in{[\omega]^{\omega}}
and
b\in\mathrm{Fin}
the set
[a<b]
is cofinite.

For a set
Y
let
\operatorname{P}(Y)
be the power set of
Y
.
Let
X
and
Y
be spaces and
\psi\colon X\to\operatorname{P}(Y)
be a map such that for each
x\in X
, the set
\psi(x)
is a compact subset of
Y
and for each
x\in X
and an open set
V\subseteq Y
such that
\psi(x)\subseteq V
, there is an open set
U\subseteq X
such that
x\in U
and
\bigcup\{\,\psi(x^{\prime}):x^{\prime}\in U\,\}\subseteq V
.
Then the map
\psi
will be called
compact valued upper semicontinuous
(
cusco
) and the notation
\psi\colon X\Rightarrow Y
will be used. Define
\psi[X]:=\bigcup\{\,\psi(x):x\in X\,\}
.

Lemma 2.5

(
[
22
, Proposition 4.3]
)
.

Cusco maps preserve the Hurewicz property, i.e., if
X
is a Hurewicz space,
Y
is a space and
\psi\colon X\Rightarrow Y
is a cusco map then the set
\psi[X]
is Hurewicz.

We have the following topological characterization of the Hurewicz property due to Just–Miller–Scheepers–Szeptycki

]

Lemma 2.6

(Just–Miller–Scheepers–Szeptycki
[

)
.

A set
X\subseteq{\operatorname{P}(\omega)}

G_{\delta}
-set
G\subseteq{\operatorname{P}(\omega)}
containing
X
, there is a
\sigma
-compact set
F\subseteq{\operatorname{P}(\omega)}
such that

.

For

and a relation

Applications under the semifilter trichotomy

Definition 3.1
.

The
semifilter trichotomy
is the statement that for any semilfilter
S\subseteq{[\omega]^{\omega}}
, there is a function
h\in{[\omega]^{\omega}}
such that
S/h
is the Fréchet filter
\mathrm{cFin}
, an ultrafilter or the full semifilter
{[\omega]^{\omega}}
.

The semifilter trichotomy is a statement independent from ZFC which holds, e.g., in the Miller model
[
14
]
.
The aim of this section is to prove the following result.

Theorem 3.2
.

Assume that the semifilter trichotomy holds.
Let
X\subseteq{[\omega]^{\omega}}
.
Then the following statements are equivalent.

(1)

The set
X\cup\mathrm{Fin}
is
\mathfrak{b}
-concentrated on
\mathrm{Fin}
.

(2)

The set
X\cup\mathrm{Fin}
is
\mathfrak{b}
-concentrated on
\mathrm{Fin}
and Hurewicz.

(3)

The set
X\cup\mathrm{Fin}
is
\mathfrak{b}
-concentrated on
\mathrm{Fin}
and it is productively Hurewicz.

(4)

The set

is meager-unbounded.

We shall prove Theorem
3.2
by using several auxiliary results.

Lemma 3.3
.

Let
X\subseteq{[\omega]^{\omega}}
and
\kappa
be a cardinal with
\mathit{cof}(\kappa)>\omega
.
Assume that
X\cup\mathrm{Fin}
is
\kappa
-concentrated on
\mathrm{Fin}
and
\{\,\mathcal{U}_{n}:n\in\omega\,\}
is a sequence of open covers of
X\cup\mathrm{Fin}
.
Then there is a set
A\subseteq X
of size smaller than
\kappa
and for every

there is

such that for all

the set
\{\,n\in\omega:x\in U_{n}\,\}
is infinite.

Proof.

Enumerate the given sequence of open covers as
\{\,\mathcal{U}_{\langle n,m\rangle}:n,m\in\omega\,\}
.
Fix
n\in\omega
and pick for every
m\in\omega
a set
U_{\langle n,m\rangle}\in\mathcal{U}_{\langle n,m\rangle}
so that
\{\,U_{\langle n,m\rangle}:m\in\omega\,\}
covers the set
\mathrm{Fin}
.
Let

V_{n}:=\bigcup_{m\in\omega}U_{\langle n,m\rangle}\quad\text{ and }\quad A:=\bigcup_{n\in\omega}X\setminus V_{n}.

Since the set
X\cup\mathrm{Fin}
is
\kappa
-concentrated on
\mathrm{Fin}

and
\mathit{cof}(\kappa)>\omega
, the set
A
has size smaller than
\kappa
.
By definition, we already know that for all
y\in\mathrm{Fin}
holds
y\in U_{\langle n,m\rangle}
for infinitely many
\langle n,m\rangle
.
If
x\in X\setminus A
, then

x\in\bigcap_{n\in\omega}V_{n}=\bigcap_{n\in\omega}\bigcup_{m\in\omega}U_{\langle n,m\rangle}.

Thus, if we enumerate the family
\{\,U_{\langle n,m\rangle}:n,m\in\omega\,\}
as
\{\,U_{n}:n\in\omega\,\}
, we have that for all
x\in(X\setminus A)\cup\mathrm{Fin}
the set
\{\,n\in\omega:x\in U_{n}\,\}
is infinite.
∎

Recall that a set
F\subseteq{\omega^{\omega}}
is
guessable
if there exists

g\in\omega^{\omega}
such that
[g=f]
is infinite for all
f\in F
.

Lemma 3.4
.

Let
X\subseteq{[\omega]^{\omega}}
and
\kappa
be a cardinal with
\mathit{cof}(\kappa)>\omega
..
Assume that
X\cup\mathrm{Fin}
is
\kappa
-concentrated on
\mathrm{Fin}
and
\varphi\colon X\cup\mathrm{Fin}\to{[\omega]^{\omega}}
is a continuous function.
Then there is a set
A\subseteq X
of size smaller than
\kappa
such that the set
\varphi[(X\setminus A)\cup\mathrm{Fin}]
is guessable.

Proof.

Fix
n\in\omega
.
Let us consider the open cover of the Baire space

\mathcal{V}_{n}:=\{\,V^{n}_{m}:m\in\omega\,\},\text{ where }V^{n}_{m}:=\{\,f\in{[\omega]^{\omega}}:f(n)=m\,\}.

The family
\mathcal{U}_{n}:=\{\,\varphi^{-1}[V^{n}_{m}]:m\in\omega\,\}
is an open cover of
X\cup\mathrm{Fin}
.
By Lemma
3.3
, there are a set
A\subseteq X
of size smaller than
\kappa
and a function
g\in{\omega^{\omega}}
such that the family

\{\,\varphi^{-1}[V^{n}_{g(n)}]:n\in\omega\,\}

fulfills that for every

the set

\{\,n\in\omega:x\in\varphi^{-1}[V^{n}_{g(n)}]\,\}=\{\,n\in\omega:\varphi(x)\in V^{n}_{g(n)}\,\}=\{\,n\in\omega:\varphi(x)(n)=g(n)\,\}

is infinite.
Thus, the image
\varphi[(X\setminus A)\cup\mathrm{Fin}]
is guessable by
g
.
∎

A set
A\subseteq{[\omega]^{\omega}}
is a
base
for a semifilter
S\subseteq{[\omega]^{\omega}}
, if

S=\{\,b\in{[\omega]^{\omega}}:a\subseteq^{*}b\text{ for some }a\in A\,\}.

Proposition 3.5
.

Let
X\subseteq{[\omega]^{\omega}}
and
\kappa
be a cardinal with
\mathit{cof}(\kappa)>\omega
.
Assume that
X\cup\mathrm{Fin}
is
\kappa
-concentrated on
\mathrm{Fin}
and
\varphi\colon X\cup\mathrm{Fin}\to{[\omega]^{\omega}}
is a continuous function. Then there is a set
A\subseteq X
of size smaller than
\kappa
such that
\varphi[(X\setminus A)\cup\mathrm{Fin}]
is neither a base for an ultrafilter nor for the full semifilter
{[\omega]^{\omega}}
.

Proof.

Let
Y:=\varphi[X\cup\mathrm{Fin}]
and fix
y\in Y
.
Let

y^{\prime}:=\langle\{y(0),y(1)\},\{y(2),y(3),y(4),y(5)\},\dotsc\rangle\in\Pi_{n\in\omega}[\omega]^{2^{n+1}},

where in
\Pi_{n\in\omega}[\omega]^{2^{n+1}}
we consider the product topology and the spaces
[\omega]^{2^{n+1}}
are discrete.
Then
Y^{\prime}:=\{\,y^{\prime}:y\in Y\,\}
is a homeomorphic copy of
Y
in
\Pi_{n\in\omega}[\omega]^{2^{n+1}}
.
So in particular,
Y^{\prime}=\psi[X\cup\mathrm{Fin}]
for some continuous function
\psi
.
By Lemma
3.4
, there is a set
A\subseteq X
of size smaller than
\kappa
such that
\psi[(X\setminus A)\cup\mathrm{Fin}]
is guessable by some function
g\in\Pi_{n\in\omega}[\omega]^{2^{n+1}}
.
By the definition of
\Pi_{n\in\omega}[\omega]^{2^{n+1}}
, for every
n\in\omega
we have

|g(n)\setminus\bigcup_{i<n}g(i)|\geq 2.

There are disjoint sets
a,b\in[\omega]^{\omega}
such that for every
n\in\omega
we have

a\cap g(n)\neq\emptyset\quad\text{ and }\quad b\cap g(n)\neq\emptyset.

For each
y\in\varphi[(X\setminus A)\cup\mathrm{Fin}]
we have
|a\cap y|=\omega
and
|b\cap y|=\omega
.
Therefore,

a,\omega\setminus a\notin\{\,x\in{[\omega]^{\omega}}:\exists y\in\varphi[(X\setminus A)\cup\mathrm{Fin}]\enskip(y\subseteq^{*}x)\,\},

and thus the above set, which is a semifilter generated by
\varphi[(X\setminus A)\cup\mathrm{Fin}]
, is not an ultrafilter nor
{[\omega]^{\omega}}
.
∎

Let
\mathfrak{u}
be the minimal cardinality of a base for an ultrafilter in
{[\omega]^{\omega}}
.

Lemma 3.6
.

Let
X\subseteq{[\omega]^{\omega}}
.

(1)

If

is a base for an ultrafilter

and
A\subseteq X
is a set of size smaller than

, then the set

is also a base for

.

(2)

is a base for the full semifilter

and

is a set of size smaller than
\mathfrak{c}
, then the set
X\setminus A
is also a base for
{[\omega]^{\omega}}
.

Proof.

(1) Fix a set
u\in U
.
Since the set
U^{\prime}:=\{\,u\cap u^{\prime}:u^{\prime}\in U\,\}
is an ultrafilter on

, the set
\{\,x\in X:x\subseteq^{*}u\,\}
, a base for

, has cardinality at least
\mathfrak{u}
.
Then there is a set

such that

.
It follows that

is a base for

.

(2) Fix a set
u\in{[\omega]^{\omega}}
. Then there is a family
\{\,u_{\alpha}:\alpha<\mathfrak{c}\,\}
of infinite subsets of

such that the sets

are finite for all
\alpha<\beta<\mathfrak{c}
.
Since the set

has size smaller than
\mathfrak{c}
, there are a set

and

.

is a base for
{[\omega]^{\omega}}
.
∎

For a set

Proof of Theorem

.

In the light of Theorem

∎

A set
X\subseteq{\operatorname{P}(\omega)}
has
strong measure zero
, if for any sequence
{\langle\,\epsilon_{n}:n\in\omega\,\rangle}
of positive numbers, there is a sequence
{\langle\,I_{n}:n\in\omega\,\rangle}
of subsets of
{\operatorname{P}(\omega)}
such that
\operatorname{diam}(I_{n})<\epsilon_{n}
and the family
\{\,I_{n}:n\in\omega\,\}
covers

.
Each Rothberger subset of
{\operatorname{P}(\omega)}
has strong measure zero.

Let
Y
be a metrizable space and let
\Iso(Y)
denote the set of all isolated points of
Y
.
For the Cantor–Bendixson process on
Y
we use the following notation:
Y^{(0)}:=Y
,
Y^{(\alpha+1)}:=Y^{(\alpha)}\setminus\Iso(Y^{(\alpha)})
and for limit ordinals
\lambda

Y^{(\lambda)}:=\bigcap_{\xi<\lambda}Y^{(\xi)}
.
The space
Y
is called
scattered
if every
subspace of
Y
has an isolated point.
Let
Y
be a scattered space.
The cardinal number
\height(Y):=\min\{\,\alpha:Y^{(\alpha)}=\emptyset\,\}
is the
height
of
Y
.
For
y\in Y
let
\height(y):=\min\{\,\alpha:y\in Y\setminus Y^{(\alpha+1)}\,\}
.
We shall need the following folklore fact.

Theorem 3.7
.

Let
X
be a metrizable space and let
Y\subseteq X
be a scattered subspace such that
\height(Y)
is countable.
Then
Y
is a
G_{\delta}
-subset of
X
.
In particular, every scattered subspace of a separable metrizable space
X
is a
G_{\delta}
-subset of
X
.

Proof.

Let
\beta=\height(Y)
.
Since all
Y^{(\alpha)}
are closed in
Y
, we can find an increasing sequence
{\langle\,O_{\alpha}:\alpha\leq\beta\,\rangle}
of open subsets of
X
with
O_{0}:=\emptyset
and
O_{\lambda}:=\bigcup_{\alpha<\lambda}O_{\alpha}
for limit ordinals
\lambda\leq\beta
such that for all
\alpha<\beta
, we have
O_{\alpha}\cap Y=Y\setminus Y^{(\alpha)}
.
For all
\alpha<\beta
let
Z_{\alpha}:=Y\cap(O_{\alpha+1}\setminus O_{\alpha})
. We have

Z_{\alpha}=(Y\cap O_{\alpha+1})\setminus(Y\cap O_{\alpha})=(Y\setminus Y^{(\alpha+1)})\setminus(Y\setminus Y^{(\alpha)})=\{\,y\in Y:\height(y)=\alpha\,\}.

Since
Z_{\alpha}=\Iso(Y^{(\alpha)})
, the space

is discrete.
Let us observe that

Y=\bigcup_{\alpha<\beta}\Iso(Y^{(\alpha)})=\bigcup_{\alpha<\beta}Y\cap(O_{\alpha+1}\setminus O_{\alpha}).

Hence we can write

X\setminus Y=(X\setminus O_{\beta})\cup\bigcup_{\alpha<\beta}((O_{\alpha+1}\setminus O_{\alpha})\setminus Y)=(X\setminus O_{\beta})\cup\bigcup_{\alpha<\beta}((O_{\alpha+1}\setminus O_{\alpha})\setminus Z_{\alpha}).

Since

is metrizable, every discrete subspace is a
G_{\delta}
-subset and every open subset is an
F_{\sigma}
-subset.
By the above it follows that
X\setminus Y
is
F_{\sigma}
-subset.

.

Let

Let

be a countable set such that

\kappa
-concentrated on

.
By the Cantor–Bendixson procedure, we can write

,

and

Let

Theorem 3.9
.

In the Miller model, each
\mathfrak{b}
-concentrated set is productively Rothberger.

Proof.

Let
Y\subseteq{[\omega]^{\omega}}
be a
\mathfrak{b}
-concentated set.
By Lemma
3.8
and since
\mathfrak{b}=\omega_{1}
, there are a countable set

and

such that

In this section we show that the appearance of the Hurewicz

By the result of the third author we have the following characterization of Hurewicz sets in the Laver model.

Theorem 4.1

(Zdomskyy
[

)
.

In the Laver model the Hurewicz property is equivalent to

.
For a set

and

C\subseteq Y

By the assumption the set

such that

By Theorem

\mathcal{K}
of compact sets in
{\operatorname{P}(\omega)}
of size smaller than
\mathfrak{b}
which covers

and
\mathcal{K}

For each

(2)

Proposition 4.5
.

Assume that
\mathfrak{b}=\mathfrak{d}
.
Then there is a set

We start by constructing an increasing sequence

For each

For each

k_{s_{2}}\in\omega

Let

S_{3}:=\{\,{s_{2}}^{\frown}n_{2}:s_{2}\in S_{2},n_{2}\geq k_{s_{2}}\,\}.

Fix
m\in\omega
and assume that a compact set

and a set
S_{m}
of increasing sequences of natural numbers of length

have been defined like above.

If

s\in S_{m}
, there is
k_{s}\in\omega
such that the set

If

is even, then for each sequence

k_{s}\in\omega

K_{m+1}:=K_{m}\cup{\bigl\{\,[s(0),s(1))\cup[s(2),s(3))\cup\dotsb\cup[s(m-2),s(m-1))\cup[s(m),\omega):s\in S_{m+1}\,\bigr\}}

Claim 4.6
.

For every function

and sequence
{\langle\,\epsilon_{n}:n\in\omega\,\rangle}

Pick

Fix

\langle i_{0},\dotsc,i_{n}\rangle
of natural numbers such that

and
2^{-h(i_{l})}<\epsilon_{l}
for all

Pick
i_{n+1}>k_{s_{n}}
such that
2^{-h(i_{n+1})}<\epsilon_{n+1}
.
Then
h(i_{n+1})>k_{s_{n}}
, and thus
{s_{n}}^{\frown}h(i_{n+1})\in S_{n+2}

Put

Claim 4.7

Let
