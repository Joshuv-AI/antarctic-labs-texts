NOCTIS: Novel Object Cyclic Threshold based Instance Segmentation
Max Gandyra, Alessandro Santonicola, Michael BeetzAICOR Institute for Artificial IntelligenceUniversity Bremen28359 Bremen, Germany

Abstract
Instance segmentation of novel objects instances in RGB images, given some example images for each object, is a well known problem in computer vision. Designing a model general enough to be employed, for all kinds of novel objects, without (re-) training, has proven to be a difficult task. To handle this, we propose a simple, yet powerful, framework, called: Novel Object Cyclic Threshold based Instance Segmentation (NOCTIS). This work stems from and improves upon previous ones like CNOS, SAM-6D and NIDS-Net; thus, it also leverages on recent vision foundation models, namely: Grounded-SAM 2 and DINOv2. It utilises Grounded-SAM 2 to obtain object proposals with precise bounding boxes and their corresponding segmentation masks; while DINOv2’s zero-shot capabilities are employed to generate the image embeddings. The quality of those masks, together with their embeddings, is of vital importance to our approach; as the proposal-object matching is realized by determining an object matching score based on the similarity of the class embeddings and the average maximum similarity of the patch embeddings. Differently to SAM-6D, calculating the latter involves a prior patch filtering based on the distance between each patch and its corresponding cyclic /roundtrip patch in the image grid. Furthermore, the average confidence of the proposals’ bounding box and mask is used as an additional weighting factor for the object matching score. We empirically show that NOCTIS, without further training/fine tuning, outperforms the best RGB and RGB-D methods on the seven core datasets of the BOP 2023 challenge for the ‘‘Model-based 2D segmentation of unseen objects’’ task. 1 1 1 Code available at: https://github.com/code-iai/noctis

Introduction

Instance segmentation (and detection) is one of the key problems in robotics perception and augmented reality applications, because it tries to identify and locate object instances in images or videos via bounding boxes and segmentation masks; e.g. a robot wants to identify a specific object instance on a conveyor belt.
Classical supervised deep learning methodologies as
[
1
,
2
,
3
,
4
,
5
]
have achieved good performances, however, for each target object they require an expensive (re-) training or, at least, a fine-tuning step.
Hence, most of the time, adding novel/unseen objects begs for additional training data, either synthetic or real, with (human made) annotations.
This makes the usage of said supervised methods unfeasible for industry, especially for short-time prototype development cycles, where the target object changes constantly.

The main problem that Novel Object Cyclic Threshold based Instance Segmentation (NOCTIS) wants to solve is to perform the instance segmentation of RGB query images, where all novel objects are represented only by some given multi-view templates, without any further training.
Our approach includes the following steps: (1) proposal generation from query images; (2) visual descriptor assignment for the proposals and the object templates; and (3) matching the proposal against the template descriptors for classification.

In light of the success of recent models like
[
6
,
7
,
8
,
9
]
; we have also chosen to utilise some foundation models, i.e. Grounded-SAM 2
[
10
]
and DINOv2
[
11
]
.
Grounded-SAM 2, with the text prompt “objects”, serves as a state-of-the-art open-world detector to obtain object proposals from an RGB input image.
This choice is motivated by its robustness, w.r.t. Segment Anything Model (SAM)
[
12
]
or FastSAM
[
13
]
, in the generation of object proposals, rather than region-based ones.
Note that, these region-based proposals can wrongfully divide single objects into multiple object part proposals or mistake some background regions for foreground objects, which causes issues in the later matching step.

On top of that, DINOv2’s zero-shot capabilities, to embed both proposals and templates, are employed to be able to compute the object matching score composed of three components: a semantic one; an appearance based one and a segmentation mask confidence score (see Section
3.3
for more details).
Like in previous works
[
7
,
8
,
9
]
, DINOv2’s
cls token
based semantic score represents a degree of similarity between the templates and a specific query object instance.
Whenever two images show the same object, albeit with different viewpoints on it, this score should be high.
Conversely, when two images are showing different objects, their similarity score should drop.

However, there might be cases where we have different objects, e.g. two food cans, which, despite their different appearances, are still semantically similar to each other.
To handle this issue, a modified version of the appearance score, see SAM-6D
[
8
, Section 3.1.2]
for the original one, is used.
This score measures the average maximum similarity of the DINOv2’s
patch tokens
between two images.
We compute it for all the templates of an object, instead of only one; moreover, a prior patch filtering, based on the distance between each patch and its corresponding
cyclic
/roundtrip patch in the image grid, removes noisy patch pairs.

As an added novelty w.r.t. previous works, for each proposal, we have included the average confidence of its bounding box and segmentation mask as an additional weighting factor to the object matching score.
Finally, we assign object labels and their corresponding confidence values to all query image proposals, using the Argmax function across all object matching scores per proposal.

We test our approach over the seven core datasets of the BOP 2023 challenge
[
14
]
for the “2D instance segmentation of unseen objects” task; and we show that our method NOCTIS, without further training, performs better than all the other RGB and RGB-D methods in terms of the Average Precision (AP) metric.
We surpass the best publicly disclosed method NIDS-Net
[
9
]
by a significant margin of absolute
3.4\%
AP and the best undisclosed one by
0.8\%
AP.

Our contributions are summarized as follows:

•

We propose NOCTIS, a zero-shot framework for novel objects instance segmentation, that uses pretrained vision foundation models and outperforms the current state-of-the-art.

•

We utilize Grounded-SAM 2 to obtain object proposals.

•

We modify the appearance score, with an added patch filtering step, to improve its robustness.

•

We include the proposal mask confidence as a weight for the matching step.

Related work

Pretrained models for visual features

The usage of pretrained foundation models has become pervasive due to their strong performance across diverse downstream tasks.
Notably, research efforts such as Visual Transformers (ViT)

Among these, we chose to use DINOv2
[

Segment anything

Another task in which foundation models currently prevail, is image segmentation/semantic mask generation; with Segment Anything (SAM)
[
12
]
, a ViT based model, being the forerunner.
However, since it has large computation costs, other (sub-) versions/variations, replacing some components with smaller ViT models

,

Notably, its successor, SAM 2
[
24
]
, while having some additional features like video tracking; achieves a higher quality, in terms of Mean Intersection over Union (mIoU), than SAM and is also more efficient computation- and memory-wise.
In recent times, it has become an established practice to combine the strengths of multiple models in a modular way to solve complex problems.
Image segmentation tasks are now solved by combining an open-set object detector
[
25
,
26
,
27
,
28
]
with one variant of SAM. Grounded-SAM 2
[

, being one of such combinations, was adopted to generate all novel objects masks for each image.

Segmentation of unseen objects

Traditionally, instance segmentation methods, like Mask R-CNN
[
2
]
or similar
[

,
3
,
5
]
, used to be fine-tuned on specific target objects

.
Even though, these methods have been demonstrated to be robust in challenging scenarios with heavy occlusions and lighting conditions, they lack the flexibility to handle novel objects without retraining, known as “closed- world” setting; a limitation that significantly hinders their applicability in real-world settings.
To overcome this limitation, progress was made in the task of novel object instance segmentation, where ZeroPose

Drawing inspiration from these works, we chose to adopt this architecture as the starting point for our approach.

3
Method

In this section, we explain our approach for performing the instance segmentation, i.e. generating segmentation masks and labeling them, for all novel objects
\mathcal{O}=\{\mathit{O}_{k}\}_{k=1}^{N_{O}}
within an RGB query image
\mathit{I}\in\mathbb{R}^{3\times\text{W}\times\text{H}}
; given just a set of RGB template images of said objects and without any (re-)training.

Our approach, as shown in Figure
1
, is carried out in three steps, similarly to
[
7
,
8
,
9
]
. Starting with the onboarding stage in Section
3.1
, visual descriptors are extracted from the template images; followed by the proposal stage in Section
3.2
, where all possible segmentation masks and their descriptors, from the query RGB image, are generated with Grounded-SAM 2
[
10
]
and DINOv2, respectively.
Lastly, in Section
3.3
, the matching stage, each proposed mask is given an object label and a confidence value, based on the determined object scores using the visual descriptors.

:

3.1
); proposal stage (Section

), where Grounded-SAM 2 generates proposals as masks and DINOv2 their descriptors from the query RGB image; lastly, in the matching stage, object labels and confidences are assigned to each proposal based on their descriptors (Section
3.3
).

3.1
Onboarding stage

The goal of the onboarding stage is to generate multiple visual descriptors to represent each of the
N_{O}
different novel objects
\mathcal{O}
.
In detail, each object
\mathit{O}_{k}
is represented by a set of
N_{T}
template images
\mathcal{T}_{k}:=\{\mathit{T}_{i}^{k}\}_{i=1}^{N_{T}}
, with
\mathit{T}_{i}^{k}\in\mathbb{R}^{3\times\text{W}^{\prime}\times\text{H}^{\prime}}
, and their corresponding ground truth segmentation masks showing the object from different predefined viewpoints.
Given some fixed viewpoints, there are multiple possible sources for these templates and masks, e.g. pre-render them with renderers like Pyrender
[
29
]
or BlenderProc
[
30
]
; extract them out of some selected frames from annotated videos/scenes, where the object is not too occluded and has a viewpoint close to a predefined one.

In a preprocessing step, the segmentation masks are used to remove the background and to crop the object instance in each template, then, the crop size is unified via resizing and padding.
Afterwards, the instance crops are fed into DINOv2
[
11
]
, an image foundation network, creating a class embedding/
cls token

\mathbf{f}_{\mathit{T}_{i}^{k}}^{\mathit{cls}}\in\mathbb{R}^{N_{\mathit{cls}}^{dim}}
and
N_{\mathit{T}_{i}^{k}}^{\mathit{patch}}
patch embeddings/
patch tokens

\mathbf{f}_{\mathit{T}_{i}^{k}}^{\mathit{patch}}:=\{\mathbf{f}_{\mathit{T}_{i}^{k},j}^{\mathit{patch}}|j=1,\dots,N_{\mathit{T}_{i}^{k}}^{\mathit{patch}}\}
with
\mathbf{f}_{\mathit{T}_{i}^{k},j}^{\mathit{patch}}\in\mathbb{R}^{N_{\mathit{patch}}^{dim}}
for each template
\mathit{T}_{i}^{k}
, where
N_{\mathit{T}_{i}^{k}}^{\mathit{patch}}
denotes the number of patches within the cropped template mask (
N_{\mathit{T}_{i}^{k}}^{\mathit{patch}}\leq N_{\mathit{patch}}
).
The cropped templates are internally divided into
N_{\mathit{patch}}=256
patches, on a
16\times 16
grid, for the
patch tokens
.
The
cls token
and
patch tokens
, together, form the visual descriptor of the template.

3.2
Proposal stage

At this stage, all object proposals from the query image
\mathit{I}
are acquired.
Since Grounded-SAM
[
10
]
, with the text prompt “objects”, as shown in NIDS-Net
[
9
]
, is a better proposal generator than SAM
[
12
]
or FastSAM
[
13
]
; which were used by previous works
[
31
,
32
,
6
,
7
,
8
]
; we decided to use a modified version of it, called Grounded-SAM 2.
The original Grounded-SAM obtains the bounding boxes of all objects from Grounding-DINO
[
28
]
, a pretrained zero-shot detector, matching a given text prompt; then, it uses these as a prompt for SAM to create masks.
Grounded-SAM 2 replaces the SAM component, in Grounded-SAM, with the qualitative (w.r.t. mIoU) and performance-wise improved SAM 2
[
24
]
.
While, having access to an upgraded Grounding-DINO model, like T-Rex2
[
26
]
or Grounding-DINO 1.5
[
27
]
would have been better; this was not possible, at the time of writing, as those models are not available offline.

We then apply Grounded-SAM 2, with the text prompt “objects”, on the query image to extract all foreground object proposals
\mathcal{P}
. Each of the
N_{P}
proposals
\mathit{p}\in\mathcal{P}
consists of a bounding box, a corresponding segmentation mask and a confidence score for both of them; note that
N_{P}
changes according to
\mathit{I}
.
All proposals whose confidence scores are lower than a threshold value or are too small, relative to the image size, are filtered out.
The visual descriptors, for the proposals, are created using the pipeline from the previous section.
For the proposal
\mathit{p}
, the preprocessing step creates the image crop
\mathit{I}_{\mathit{p}}
, which is then used by DINOv2 to generate the
cls token

\mathbf{f}_{\mathit{I}_{\mathit{p}}}^{\mathit{cls}}
and
patch tokens

\mathbf{f}_{\mathit{I}_{\mathit{p}}}^{\mathit{patch}}
.

3.3
Matching stage

At the matching stage, we calculate for each proposal-object pair their corresponding matching score, using the previously gathered visual descriptors; then, we assign to each proposal the most fitting object label and a confidence score, if it is high enough.

The object matching score
\mathit{s}_{p,k}^{\mathit{obj}}
, between a proposal
\mathit{p}
and an object
\mathit{O}_{k}
, represented by its templates
\mathcal{T}_{k}
, is made of different components; namely: the semantic score
\mathit{s}_{p,k}^{\mathit{sem}}
, the appearance score
\mathit{s}_{p,k}^{\mathit{appe}}
and a proposal confidence
\mathit{conf}_{\mathit{p}}
.

Semantic score

The semantic score
\mathit{s}_{p,k}^{\mathit{sem}}
was established as a robust measure of semantic matching and is defined as the top-
5
average of the
N_{T}
cosine similarity values between
\mathbf{f}_{\mathit{I}_{\mathit{p}}}^{\mathit{cls}}
and all
\mathbf{f}_{\mathit{T}_{i}^{k}}^{\mathit{cls}}
embeddings
[
7
]
, where the cosine similarity is defined as:

\displaystyle\mathit{cossim}(\mathbf{a},\mathbf{b})=\frac{\langle\mathbf{a},\mathbf{b}\rangle}{\|\mathbf{a}\|\cdot\|\mathbf{b}\|}\text{,}

with
\langle,\rangle
denoting the inner product.
If the vectors point in the same direction, they have a
\mathit{cossim}
value of
1
,
-1
for opposite directions and
0
for orthogonality.
It was shown in CNOS Section 4.3, that using the top-
5
average, as an aggregating function, is the most robust option out of: Mean; Max; Median and top-K Average.

Appearance score with cyclic threshold

Our definition of the appearance score
\mathit{s}_{p,k}^{\mathit{appe}}
can be seen as a way to discriminate between objects which are semantically similar, but with different patch/part-wise appearance.
Instead of using only the template with the best semantic value, as in SAM-6D Section 3.1.2, we compute the sub-appearance scores for all the
N_{T}
templates and aggregate them.
The sub-appearance score
\mathit{s}_{p,k,i}^{\mathit{appe}}
, for template
\mathit{T}_{i}^{k}
, is defined as:

\displaystyle\mathit{s}_{p,k,i}^{\mathit{appe}}=\frac{1}{N_{\mathit{I}_{\mathit{p}}}^{\mathit{patch}}}\sum_{l=1}^{N_{\mathit{I}_{\mathit{p}}}^{\mathit{patch}}}\max_{j=1,\dots,N_{\mathit{T}_{i}^{k}}^{\mathit{patch}}}\big(\mathit{cossim}(\mathbf{f}_{\mathit{I}_{\mathit{p}},l}^{\mathit{patch}},\mathbf{f}_{\mathit{T}_{i}^{k},j}^{\mathit{patch}})\big)\cdot\chi_{\mathit{cdist}^{\mathit{I}_{\mathit{p}},\mathit{T}_{i}^{k}}(l)\leq\delta_{\mathit{CT}}}\text{,}

(1)

where
\chi
represents the indicator function, which is used to filter out certain patches. To aggregate all the sub-appearance scores into a final appearance score, we use the Max function.
Our rationale behind this, is supported by the inherent sensitivity of the appearance score to the visible parts of the object instances; thus to the viewpoint differences.
It was shown in CNOS Section 4.4, that the
cls token
contains insufficient information about matching viewpoints, potentially leading to low appearance values.

From patch

\mathit{A}
, we find
t
, the most similar patch of it in
\mathit{B}
, via the following function:

\displaystyle\mathit{bestMatchIndex}(\mathbf{f}_{\mathit{A}}^{\mathit{patch}},\mathbf{f}_{\mathit{B}}^{\mathit{patch}},i)=\underset{j=1,\dots,N_{\mathit{B}}^{\mathit{patch}}}{\mathrm{argmax}}\mathit{cossim}(\mathbf{f}_{\mathit{A},i}^{\mathit{patch}},\mathbf{f}_{\mathit{B},j}^{\mathit{patch}})\text{,}

where
t=\mathit{bestMatchIndex}(\mathbf{f}_{\mathit{A}}^{\mathit{patch}},\mathbf{f}_{\mathit{B}}^{\mathit{patch}},s)
using the DINOv2
patch tokens
of
\mathit{A}
and
\mathit{B}
.
Vice versa, starting from
t
, its best match in
\mathit{A}
is patch
u
; by using the same function.
We, therefore, call
u
the
cyclic
/roundtrip patch of
s
and their euclidean distance, on the grid, the
cyclic
distance of
s
, namely
\mathit{cdist}
.

Ideally, each patch of the image crop should match one from the template, if both are the most similar to each other (also known as mutual nearest neighbours), their matching would be more robust w.r.t. rotation/scale/noise.
As a simple example, imagine that the image crop and template show a similar looking cube.
It is reasonable, that, the patches showing the corners should be matched together; resulting in all of the image’s corners patches having their own “corner” patch in the template, without multiple assigned patches.
In the worst case, all of the image’s corner patches are matched with only one template corner patch, which, obviously, does not really describe/represent the visual appearance of the object anymore.
Thus, having
\mathit{cdist}
equal to zero for each crop patch would be desirable, but, in practice, this is often not the case.

Therefore using the previously defined
cyclic
distance, our addition to the appearance score lies in the application of a patch filter, represented by the indicator function
\chi
in equation (
1
), to increase the score’s reliability/expressiveness; which allows for a kind of “softened” mutual nearest neighbours matching.
The function
\chi_{\mathit{cdist}^{\mathit{I}_{\mathit{p}},\mathit{T}_{i}^{k}}(l)\leq\delta_{\mathit{CT}}}
internally calculates the
\mathit{cdist}
for patch
l
of image crop
\mathit{I}_{\mathit{p}}
and template
\mathit{T}_{i}^{k}
, then checks if it is smaller than a predefined cyclic threshold,
\delta_{\mathit{CT}}
(CT).
The default value for it is
\delta_{\mathit{CT}}=5
, see also the ablation studies Section
4.3
, where the effects of using different threshold values are discussed.

Bounding box and segmentation mask confidence

Proposals might contain a high number of false positives, indeed, background regions and object parts might be misinterpreted as complete objects.
To account for this, for each proposal
\mathit{p}
, the proposal confidence
\mathit{conf}_{\mathit{p}}
, as the average confidence value of its bounding box and segmentation mask, is included as a weighting factor for the object matching score in the next paragraph.

Object matching score

By combining the previously mentioned scores and the proposal confidence, the object matching score
\mathit{s}_{p,k}^{\mathit{obj}}
is determined as follows:

\displaystyle\mathit{s}_{p,k}^{\mathit{obj}}=\frac{\mathit{s}_{p,k}^{\mathit{sem}}+w_{\mathit{appe}}*\mathit{s}_{p,k}^{\mathit{appe}}}{1+1}*\mathit{conf}_{p}\text{,}

(2)

where an appearance weight
w_{\mathit{appe}}=1
computes the average.
The object matching scores of all the
N_{P}
proposals, over all possible
N_{O}
objects, are stored in the
N_{P}\times N_{O}
instance score matrix.

Note that, using the
\mathit{cdist}
based filtering squashes down the appearance scores for small CT values.
We compensate that by setting
w_{\mathit{appe}}=2
and clamping its values back to the
[0,1]
interval, to balance the contribution of both scores.

Object label assignment

In the last step, we simply apply the Argmax function row-wise on the instance score matrix.
Each proposal gets assigned an object label and its object matching score as its corresponding confidence.

Eventually, we obtain proposals consisting of: a bounding box of the object instance; its corresponding modal segmentation mask, which covers the visible instance part
[
14
]
; and an object label with a confidence score.
As some of these proposals may be incorrectly labeled, a confidence threshold
\delta_{\mathit{conf}}
can be applied to remove them.
The default value we use in our testing is
\delta_{\mathit{conf}}=0.2
.
Moreover, Non-Maximum Suppression is applied to eliminate redundant proposals.

Experimental setup

Datasets

We evaluate our method on the seven core datasets of the BOP 2023 challenge: LineMod Occlusion (LM-O)

To generate the proposals, we use Grounded-SAM 2

The corresponding regions of interest (ROIs) are resized to

Mimicking the approaches in

We use the “PBR-BlenderProc4BOP” pipeline with the same

, to select the templates representing every dataset object.
See also the ablation studies

The main code is implemented in Python 3.8 using Numpy
[

4.4
Discussion and limitations

The memory usage for determining object matching scores, for a query image, has two bottlenecks; each of them requires calculating a large matrix at some point.
A
N_{P}\times N_{O}\times N_{T}
matrix for the semantic score, before the aggregation, like in CNOS; and a
N_{P}\times N_{O}\times N_{T}\times N_{\mathit{patch}}\times N_{\mathit{patch}}
matrix for the appearance score before filtering, averaging and the agglomeration.
The size of the latter could be the reason why SAM-6D, originally, computed the appearance score only for the semantic best template per object.
Besides, as the
cyclic
distance is also determined using this huge matrix, its additional computation costs are rather small.
To reduce the CUDA memory requirements, we make use of mini batches on the
N_{P}
and
N_{O}
dimension, but this comes with an increase in computation time.
As a side note, until the templates remain the same between different runs; their visual descriptors stay the same after the onboarding stage
3.1
, since DINOv2 is deterministic, thus they can be stored and cheaply reloaded later.

Our method is only evaluated on the seven core BOP 2023 datasets, this is done due to, on one hand, lack of data for the BOP classic Extra datasets (LM
[
44
]
; HOPEv1
[
45
]
; RU-APC
[
46
]
; IC-MI
[
47
]
and TYO-L
[
35
]
); on the other hand, because the BOP 2024
[
48
]
and 2025
[
49
]
challenges are targeting only a detection task.
But, as mentioned in Section
4.1
, the chosen datasets include many different scenes, so their evaluation should still be reliable.

As seen in column
4
from Figure
3
, our method does not perform at its highest when the objects are similar looking but different sized, e.g. all the clamps from YCB-V
[
39
]
; or they are untextured (see column
6
), e.g. the industrial models from ITODD
[
37
]
.
While these issues might be solved by using depth data, it does not seem that easy, as e.g. SAM-6D is still not able to solve this issue.

5
Conclusion

In this paper we presented NOCTIS, a new framework for zero-shot novel object instance segmentation; which leverages on architectures/ideas already proven to be effective as Grounded-SAM 2
[
10
]
and DINOv2
[
11
]
-based visual descriptors paired with different matching scores.
The novelties introduced in Section
3
have proven to be simple to adapt but largely effective, indeed, NOCTIS was able to perform better than all the other methodologies, disclosed or not, on the seven core datasets of the BOP 2023 benchmark
[
14
]
. This shows that it is not necessary to have overly complicated scores to achieve good performance.
We hope that our work can be used as a new standard baseline to improve upon, especially regarding the formulation of a better scoring rule.
