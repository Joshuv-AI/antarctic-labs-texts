Solutions of equation (1.7)

In the following proposition we give the solutions formulas for the functional equation

\int_{S}f(x\sigma(y)t)d\mu(t)=f(x)f(y),\;x,y\in S

(3.1)

which has been solved on semigroups by Elqorachi
[

for

Proposition 3.1
.

Let
f:S\longmapsto\mathbb{C}
be a solution the functional equation (
3.1
). Then we have the following.

(a)
\int_{S}f(t)d\mu(t)\neq 0
if and only if
f\neq 0.

(b)
f=[\int_{S}\chi(t)d\mu(t)]\chi,
where
\chi:S\longrightarrow\mathbb{C}
is a multiplicative function such that
\chi\circ\sigma=\chi
.

Proof.

(a) If
f=0
then
\int_{S}f(t)d\mu(t)=0
. Conversely, if
\int_{S}f(t)d\mu(t)=0
then,
by replacing
x
by
xs
and
y
by
xk
in (
3.1
) and integrating the two members of equation with respect to

s
and
k
we obtain

\int_{S}\int_{S}\int_{S}f(xs\sigma(xk)t)d\mu(s)d\mu(k)d\mu(t)=\left(\int_{S}f(xk)d\mu(k)\right)^{2}.

(3.2)

By using (
3.1
) the left hand side of (
3.2
) can be written as

\begin{split}&\int_{S}\int_{S}\int_{S}f(xs\sigma(xk)t)d\mu(s)d\mu(k)d\mu(t)\\
&=\int_{S}\int_{S}\int_{S}f(xs\sigma(x)\sigma(k)t)d\mu(s)d\mu(k)d\mu(t)\\
&=\int_{S}\int_{S}\left[\int_{S}f(xs\sigma(x)\sigma(k)t)d\mu(t)\right]d\mu(s)d\mu(k)\\
&=\int_{S}f(xs\sigma(x))d\mu(s)\int_{S}f(k)d\mu(k)\\
&=0.\end{split}

In view of (
3.2
) we deduce that

\int_{S}f(xk)d\mu(k)=0
for all
x\in S
, and from equation (
3.1
) we get

\int_{S}f(x\sigma(y)t)d\mu(t)=f(x)f(y)=0
for all
x,y\in S.
This implies that
f=0
.

(b) Assume that
f\neq 0
. By replacing
y
by
yzs
in (
3.1
) and integrating the result obtained with respect to
s
we get that

\begin{split}&\int_{S}\int_{S}f(x\sigma(yzs)t)d\mu(s)d\mu(t)=\int_{S}\left[\int_{S}f(x\sigma(y)\sigma(zs)t)d\mu(t)\right]d\mu(s)\\
&\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\,\,\,\,=f(x\sigma(y))\int_{S}f(zs)d\mu(s)\end{split}

and

\begin{split}&\int_{S}\int_{S}f(x\sigma(yzs)t)d\mu(s)d\mu(t)=\int_{S}\left[\int_{S}f(x\sigma(yz)\sigma(s)t)d\mu(t)\right]d\mu(s)\\
&\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\,\,\,\,=f(x\sigma(yz))\int_{S}f(s)d\mu(s).\end{split}

So,

f(x\sigma(y))\int_{S}f(zs)d\mu(s)=f(x\sigma(yz))\int_{S}f(s)d\mu(s)

(3.3)

for all
x,y,z\in S.

Now, replacing
z
by
\sigma(k)
in (
3.3
) and integrating the result obtained with respect to
k

we obtain

\begin{split}&f(x\sigma(y))\int_{S}\int_{S}f(\sigma(k)s)d\mu(k)d\mu(s)=\int_{S}f(x\sigma(y)k)d\mu(k)\int_{S}f(s)d\mu(s)\\
&\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\,=f(x)f(y)\int_{S}f(s)d\mu(s).\end{split}

(3.4)

Since
\int_{S}f(s)d\mu(s)\neq 0
and
f\neq 0
, we get that
\int_{S}\int_{S}f(\sigma(k)s)d\mu(k)d\mu(s)\neq 0
. Hence equation (
3.4
) can be written as follows

f(x\sigma(y))=\alpha f(x)f(y),

(3.5)

where
\alpha:=\dfrac{\int_{S}f(s)d\mu(s)}{\int_{S}\int_{S}f(\sigma(k)s)d\mu(k)d\mu(s)}\neq 0
. From equation (
3.5
) we get
f(x\sigma(yz))=\alpha f(x)f(yz)=f((x\sigma(y)\sigma(z))=\alpha^{2}f(x)f(y)f(z).

Since
f\neq 0
, then we deduce that

f(yz)=\alpha f(y)f(z)
for all
y,z
, which implies that
\alpha f:=\chi
, where
\chi
is an exponential. By using again (
3.5
) we get

\chi(x)\chi\circ\sigma(y)=\chi(x\sigma(y))=\chi(x)\chi(y),

so
\chi\circ\sigma=\chi
.
Now, by substituting
f=\dfrac{\chi}{\alpha}
into (
3.1
) we obtain

\dfrac{1}{\alpha}\chi(x)\chi(y)\int_{S}\chi(t)d\mu(t)=\dfrac{\chi(x)}{\alpha}\dfrac{\chi(y)}{\alpha},
which implies that
\dfrac{1}{\alpha}=\int_{S}\chi(t)d\mu(t)
. Finally,
f=[\int_{S}\chi(t)d\mu(t)]\chi
.
The converse is straightforward verification. This completes the proof.
∎

Lemma 3.2
.

Let

be a solution of equation (

Proof.

\int_{S}f(t)d\mu(t)\neq 0

y
by

in (
1.7
) and integrating the result obtained with respect to

\begin{split}&\int_{S}\int_{S}\int_{S}f(x\sigma(y\sigma(s)k)t)d\mu(t)d\mu(k)d\mu(s)\\
&=f(x)\int_{S}\int_{S}g(y\sigma(s)k)d\mu(k)d\mu(s)-g(x)\int_{S}\int_{S}f(y\sigma(s)k))d\mu(k)d\mu(s)\\
&=\int_{S}\int_{S}\int_{S}f(x\sigma(y\sigma(s))\sigma(k)t)d\mu(k)d\mu(s)d\mu(t)\\
&=\int_{S}f(x\sigma(y\sigma(s)))d\mu(s)\int_{S}g(k)d\mu(k)-\int_{S}f(k)d\mu(k)\int_{S}g(x\sigma(y\sigma(s)))d\mu(s).\end{split}

Then,

\begin{split}&\int_{S}g(k)d\mu(k)[f(x)g(y)-f(y)g(x)]-\int_{S}f(k)d\mu(k)\int_{S}g(x\sigma(y)s)d\mu(s)\\
&=f(x)\int_{S}\int_{S}g(y\sigma(s)k)d\mu(k)d\mu(s)\\
&\quad-g(x)\left[f(y)\int_{S}g(s)d\mu(s)-g(y)\int_{S}f(s)d\mu(s)\right],\end{split}

which can rewritten as follows

\int_{S}f(t)d\mu(t)\left[\int_{S}g(x\sigma(y)k)d\mu(k)+g(x)g(y)\right]

(3.6)

=f(x)\left[-\int_{S}\int_{S}g(y\sigma(k)t)d\mu(k)d\mu(t)+g(y)\int_{S}g(t)d\mu(t)\right].

By assumption

then, from equation (
3.6

\int_{S}g(x\sigma(y)t)d\mu(t)=f(x)h(y)-g(x)g(y),

where

h(y):=-\dfrac{\int_{S}\int_{S}g(y\sigma(k)s)d\mu(k)d\mu(s)-g(y)\int_{S}g(t)d\mu(t)}{\int_{S}f(t)d\mu(t)}.

Now, by substituting (
3.7

3.6
) we obtain

f(x)h(y)\int_{S}f(t)d\mu(t)=f(x)\left[-\int_{S}h(t)d\mu(t)f(y)+2g(y)\int_{S}g(t)d\mu(t)\right].

Since
\int_{S}f(t)d\mu(t)\neq 0
and
f\neq 0
we derive from the identity above that

h=\alpha f+\beta g
,
where
\alpha:=-\dfrac{\int_{S}h(t)d\mu(t)}{\int_{S}f(t)d\mu(t)}
and
\beta:=\dfrac{2\int_{S}g(t)d\mu(t)}{\int_{S}f(t)d\mu(t)}
.
Then

\alpha=-\dfrac{\int_{S}h(t)d\mu(t)}{\int_{S}f(t)d\mu(t)}=-\dfrac{\alpha\int_{S}f(t)d\mu(t)+\beta\int_{S}g(t)d\mu(t)}{\int_{S}f(t)d\mu(t)}=-\alpha-\dfrac{\beta^{2}}{2}.

So,
\alpha=-{\beta^{2}}/{4}
and
h(y)=-\dfrac{\beta^{2}}{4}f(y)+\beta g(y).

Now, equation (
3.7
) can be written as follows

\int_{S}g(x\sigma(y)t)d\mu(t)=-g(x)g(y)-\dfrac{\beta^{2}}{4}f(x)f(y)+\beta f(x)g(y).

(3.8)

From (
1.7
) and (
3.8
) we obtain

\int_{S}(g-\dfrac{\beta}{2}f)(x\sigma(y)t)d\mu(t)=-(g-\dfrac{\beta}{2}f)(x)(g-\dfrac{\beta}{2}f)(y).

(3.9)

for all
x,y\in S.

By applying Proposition
3.1
to (
3.9
), and taking into account that
f,g
is linearly independent, we derive that there exists an exponential
\chi
on
S
such that
\chi\circ\sigma=\chi
and

.

By putting
x=s
and
y=t
in (

s
and

we get

\int_{S}\int_{S}\int_{S}g(s\sigma(t)k)d\mu(s)d\mu(k)d\mu(t)=0.

(3.10)

By replacing

by

and

by

in (

Lemma 3.5

Let

Lemma 4.1

by

from which we derive

(4.3)
