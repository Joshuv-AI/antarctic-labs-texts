String Consensus Problems with Swaps and Substitutions
Estéban Gabory, Laurent Bulteau, Gabriele Fici, Hilde Verbeek

Abstract
String consensus problems aim at finding a string that minimizes some given distance with respect to an input set of strings. In particular, in the Closest String problem, we are given a set of strings of equal length and a radius d d . The goal is to find a new string that differs from each input string by at most d d substitutions. We study a generalization of this problem where, in addition to substitutions, swaps of adjacent characters are also permitted, each operation incurring a unit cost. Amir et al. showed that this generalized problem is NP -hard, even when only swaps are allowed. In this paper, we show that it is FPT with respect to the parameter d d . Moreover, we investigate a variant in which the goal is to minimize the sum of distances from the output string to all input strings. For this version, we present a polynomial-time algorithm.

Introduction

Consensus problems aim at finding, given a collection of objects and a distance function, an object that is as close as possible to each and every object in the collection. In the

[

[

Betzler et al.

give an algorithmic framework to show that the median problem (i.e., the sum-only variant) for various distances is
FPT
for the average distance between input objects.

[
8

3

In this paper, we consider not only substitution operations, but also

Swaps are used as an extension to the Levenshtein distance (yielding the Damerau–Levenshtein distance), e.g., in spell checkers where they help improve predictions

Importantly, their formalism enforces that swaps are pairwise disjoint, hence some pairs of strings may be incomparable even if they use the same multi-set of characters

The aim of this paper is to study the parameterized complexity of

Preliminaries

Parameterized Complexity.

We use general notions of parameterized complexity and kernels
[
11
,
12
]
. In a nutshell (omitting some technical difficulties not irrelevant to our case), for a parameterized problem
P(k)
, an
FPT algorithm
is an exact algorithm solving
P
in
f(k)\mathrm{poly}(n)
time where
n
is the instance size and
k
is the parameter. A
kernel
is a polynomial-time algorithm reducing an instance of
P(k)
to another instance with size
f(k)
. Such a kernel is
polynomial
if
f
is polynomial.
It is known that there exists a kernel for
P(k)
if and only if
P(k)\in{\sf FPT}
, but having a polynomial kernel is seemingly more restrictive. Finally, the
parameterized reductions
we use in this paper are polynomial-time reductions that also preserve the value of the parameter (up to some polynomial). In other words, a parameterized reduction from
P(k)
to
Q(k^{\prime})
is a function
f
with:
(i)

(x,k)
is a yes-instance for
P
if and only if
(x^{\prime},k^{\prime})=f(x,k)
is a yes-instance for
Q
, and
(ii)

k^{\prime}\leq\mathrm{poly}(k)
. With such a parameterized reduction, any
FPT
(resp. polynomial kernel) for
Q(k^{\prime})
can be carried over as an
FPT
algorithm (resp. polynomial kernel) for
P(k)

[
6
]
.

Strings.

Let
\Sigma^{n}
be the set of
strings

s=s[1]\cdots s[n]
of
length

|s|=n
over an alphabet
\Sigma

. Given a letter
\texttt{a}\in\Sigma

|s|_{\texttt{a}}=|\{p\in[1\mathinner{.\,.}n]~|~s[p]=\texttt{a}\}
|. The

of a string

is the string

. Given an arbitrary interval
I=[i\mathinner{.\,.}j]\subseteq[1\mathinner{.\,.}n]
, we write
s[I]=s[i\mathinner{.\,.}j]
for the
substring
of
s
starting at position
i
and ending at position
j
, and we write
s[j\mathinner{.\,.}i]=s[i\mathinner{.\,.}j]^{r}
. A
prefix
of

is a substring of the form
s[1\mathinner{.\,.}p]
and a
suffix
of
s
is a substring of the form
s[p\mathinner{.\,.}|s|]
, for some
p
. By

we denote the

of two strings
s_{1}
and
s_{2}
, i.e.,
s_{1}\cdot s_{2}=s_{1}[1]\cdots s_{1}[|s_{1}|]\cdot s_{2}[1]\cdots s_{2}[|s_{2}|]
. We say that two strings
s_{1}
,
s_{2}
are
matching
at a position

if
s_{1}[p]=s_{2}[p]
, and that they are
mismatching
otherwise. We say that
s_{2}
is obtained from
s_{1}
by a

at position
p
with letter

if
s_{1}[p]\neq s_{2}[p]=\texttt{a}
and
s_{1}[p^{\prime}]=s_{2}[p^{\prime}]
when
p^{\prime}\neq p
. Given a set
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
containing strings having the same length, we call
p
th column
the set
\mathcal{S}[p]=\{s[p]|~s\in\mathcal{S}\}
. We say that
\mathcal{S}[p]
is
dirty
if it contains at least two distinct elements; otherwise, we say that it is
clean
. We also write
\mathcal{S}[i\mathinner{.\,.}j]
for the

of
\mathcal{S}
between
i
and
j
, which is defined as the set
\{s[i\mathinner{.\,.}j],s\in\mathcal{S}\}
. Given two binary strings

and
h_{2}
, we write

for the string obtained by taking the position-wise

of both input strings.

Swaps.

Given an integer
n
, we denote by
\mathfrak{S}_{n}
the set of all permutations of
[n]=[1\mathinner{.\,.}n]
.
Given an integer
p
, the
swap at positions
(p,p+1)
(or simply at position
p
) is the operation transforming a string
s
into
s[1]\cdots s[p-1]\cdot s[p+1]\cdot s[p]\cdot s[p+2]\cdots s[|s|]
. Two swaps at positions
p
and
q
respectively are
disjoint
or
compatible
if
|p-q|\geq 2
(in which case, the two operations commute).
A
swap permutation
of size
m
is a set of
m
pairwise-compatible swaps (it can also be seen as a permutation of
\mathfrak{S}_{n}
consisting of
m
support-disjoint adjacent transpositions). The
swap string

h_{\sigma}
of a swap permutation
\sigma
is the length-
(n-1)
binary string
h
such that
h[p]=\texttt{1}
if
\sigma
contains a swap at position
(p,p+1)
, and
h[p]=\texttt{0}
otherwise.

Two strings
s_{1}
and
s_{2}
are
matching
if there exists a swap permutation transforming
s_{1}
into
s_{2}
. To ensure the uniqueness of the swap permutations between strings, we say that such a permutation is
valid
if it never swaps two identical letters: any swap permutation can be made valid by removing such superfluous swaps. In that case, we write
\mathfrak{S}_{s_{1},s_{2}}
for this permutation and
h_{s_{1},s_{2}}
for the corresponding swap string. We state the following lemma:

Lemma 1

Given two matching strings
s_{1}
and
s_{2}
,
\mathfrak{S}_{s_{1},s_{2}}
and
h_{s_{1},s_{2}}
are unique and can be computed in linear time.

Proof

Let
\sigma
and
\tau
be two swap permutations between
s_{1}
and
s_{2}
. Since permutations have a unique decomposition into support-disjoint cycles (here, transpositions)
[
10
]
, the string
h_{s_{1},s_{2}}
is well-defined and unique if and only if
\sigma=\tau
.

If
\sigma\neq\tau
, let
(p,p+1)
be the last positions that are swapped by exactly one of the permutations, without loss of generality,
\sigma
swaps
(p,p+1)
but not
\tau
. By definition, it implies that
s_{2}[p+1]=s_{1}[p]\neq s_{1}[p+1]=s_{2}[p]
. But since
s_{2}[p+1]=s_{1}[\tau(p+1)]
, we necessarily have
\tau(p+1)\neq p+1
, and since
(p,p+1)
is, by assumption, not swapped by
\tau
, then
(p+1,p+2)
has to be a swapped by
\tau
. But since
\sigma
swaps
(p,p+1)
, that is incompatible with
(p+1,p+2)
, those positions are swapped by exactly one of the permutations. This contradicts our initial assumption.

We can compute
h_{s_{1},s_{2}}
in linear time by reading the string from left to right, and starting to swap at the first unmatching symbol. Indeed, if for some
p_{0}
with
s_{1}[p_{0}]\neq s_{2}[p_{0}]
we have
s_{1}[p]=s_{2}[p]
for every
p\leq p_{0}-1
, there cannot be a swap at positions
(p_{0}-1,p_{0})
, so there is a swap at positions
(p_{0},p_{0}+1)
if the strings are matching. We conclude by induction.
∎

We say that matching strings

and
s_{2}
have a

at position
(p,p+1)
(or simply at position

) if
\mathfrak{S}_{s_{1},s_{2}}
contains the corresponding swap (i.e.,
h_{s_{1},s_{2}}[p]=\texttt{1}
), and we write
(p,p+1)\in\mathfrak{S}_{s_{1},s_{2}}
. Note that this is more precise than simply having
s_{1}[p]=s_{2}[p+1]
and
s_{2}[p+1]=s_{1}[p]
, as can be seen in the following example.

Example 1

Let
s_{1}=\texttt{abab}
and
s_{2}=\texttt{baba}
.
One has

(so their swap distance is

and

do not have a swap at position 2, even though

and

Lemma 2

Given three strings
s_{1},s_{2},s_{3}
such that both
s_{1},s_{2}
and
s_{2},s_{3}
are matching, let
h=h_{s_{1},s_{2}}\oplus h_{s_{2},s_{3}}
.
If
h
does not have two consecutive

s_{1}
and
s_{3}
are matching and

.
If

has two consecutive

and

for some

(i.e.,

and

do not match, and for any string

and

we have

.

Proof

For the first statement, one can observe that if

does not have two consecutive

are compatible. Those swaps are exactly those that

and

s_{2}
and

have, but not both. Since swaps are involutions, we obtain

For the second statement, let us assume that

Distances.

Given two strings
s_{1}
and
s_{2}
, the
Adjacent Swap Distance

\partial_{\texttt{S}}(s_{1},s_{2})
(or simply

We first consider the case where all strings are pairwise matching (corresponding to steps 5-7 in the figure). In this case, we show that each of the studied consensus problems under the swap distance reduces to the same problem under the Hamming distance.

Given a set of strings
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
all of length
n
, we call
\mathcal{C}_{\mathcal{S}}
the set of strings from
\Sigma^{n}
that are matching each and all strings in
\mathcal{S}
. We use the following result:

Lemma 3

Given a set of pairwise matching strings
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
, for any string
s^{*}\in\mathcal{C}_{\mathcal{S}}
, and any
s_{i}\in\mathcal{S}
, we have
\partial_{\texttt{S}}(s^{*},s_{i})=\partial_{\texttt{Ham}}(h_{s_{1},s^{*}},h_{s_{1},s_{i}})
.

Proof

One can observe that for any pair of binary strings
h_{1},h_{2}
, one has
\partial_{\texttt{Ham}}(h_{1},h_{2})=|h_{1}\oplus h_{2}|_{1}
, since
(h_{1}\oplus h_{2}[p])=\texttt{1}
if and only if
h_{1}[p]\neq h_{2}[p]
. One also observes that, since the swap strings have ones exactly on the swap positions, we have
\partial_{\texttt{S}}(s_{1},s_{2})=|h_{s_{1},s_{2}}|_{\texttt{1}}
. Finally, since swaps are involutions, we also have
h_{u,v}=h_{v,u}
for any pair of matching strings
u,v
.

The result is now immediate: if
s_{1},s^{*},s_{i}
are pairwise matching, Lemma
2
, we obtain the following:
\partial_{\texttt{S}}(s^{*},s_{i})=|h_{s^{*},s_{i}}|_{1}=|h_{s^{*},s_{1}}\oplus h_{s_{1},s_{i}}|_{1}=\partial_{\texttt{Ham}}(h_{s_{1},s^{*}},h_{s_{1},s_{i}})
.
∎

\mathcal{S}
admits a
(r,
\partial_{\texttt{S}}
)
-

(resp.

d
(resp. for
D

\mathcal{S}_{h}
admits a
\text{\texttt{(r,$\partial_{\texttt{Ham}}$)}}-\allowbreak\text{{\sc Consensus}}
(resp.
\text{\texttt{(s,$\partial_{\texttt{Ham}}$)}}-\allowbreak\text{{\sc Consensus}}

We consider now the more general case where input strings are not pairwise matching. Note that this does not trivially lead to no-instances, since only the solution needs to match with all input strings (not necessarily other input strings). However, a necessary condition for a yes-instance is that

We show a two-step method for solving swap-distance consensus problems. First, in linear time we transform

, we reduce

to a variant of the consensus problem under Hamming distance, and prove that this variant admits a polynomial reduction to the standard Hamming-distance consensus problem.

Let
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
. If for some

one has
(p,p+1)\in\mathfrak{S}_{s^{*},s}
for every

is

for

of

if
(i)
the strings from
\mathcal{S}^{\prime}
are pairwise matching, and
(ii)
for each

and

are matching and the permutation
\mathfrak{S}_{s_{i},s_{i}^{\prime}}
contains only necessary swaps for

.

Lemma 4

Let
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
be a set of strings such that
\mathcal{C}_{\mathcal{S}}\neq\emptyset
. Then,
\mathcal{S}
admits a disentanglement, which can be constructed in
\mathcal{O}(kn)
time.

Proof

Assume
\mathcal{C}_{\mathcal{S}}\neq\emptyset
, and let

. Although we do not have access to

, its existence provides structural information about
\mathcal{S}
.

An interval

of length at least

is

such that

. If no tangled interval exists, then by Lemma
2

\mathcal{S}
are pairwise matching and there are no necessary swaps.

If

2
implies that all strings in
\mathcal{C}_{\mathcal{S}}
agree on

and

within

.

Assume a tangled interval exists, and let

be the initial position of the first one. By definition, there exists
s_{j}\in\mathcal{S}
with

. Similarly,
s^{*}[i_{0}+1]\neq s^{*}[i_{0}+2]
. Let

with

. We consider two cases:

•

\mathcal{S}[i_{0},i_{0}+1]=\{\texttt{ba},\texttt{ac}\}
.

•

, then

.

In either case, a necessary swap at position

occurs for

if and only if

or
s_{j}[i_{0}]=s_{j}[i_{0}+1]
. In particular, for such

, one has

.

We now describe how to compute
\mathcal{S}^{\prime}
(see Figure
3

such that

for distinct letters
\texttt{a},\texttt{b}
. If this holds for all dirty columns, then there is no tangled interval and we set
\mathcal{S}^{\prime}=\mathcal{S}
.

Otherwise, let
i_{0}
be the first column violating this condition. Namely, the column
i_{0}
is dirty and there is at least one
s_{j}\in\mathcal{S}
with
s_{j}[i_{0}+1]\not\in\mathcal{S}[i_{0}]
or
s_{j}[i_{0}+1]=s_{j}[i_{0}]
.
Then,
i_{0}
is the initial position of a tangled interval. Based on the earlier characterization, we can deduce
s^{*}[i_{0}+1,i_{0}+2]
for any
s^{*}\in\mathcal{C}
, hence all necessary swaps at
i_{0}
: namely, we swap
s_{j}
at

if and only if
s_{j}[i_{0},i_{0}+1]=s^{*}[i_{0}+1,i_{0}+2]
. After applying these swaps, we identify the strings requiring swaps at
i_{0}
—namely, those not matching at
i_{0}+1
with the updated strings. At this step, we computed
s^{*}[i_{0},i_{0}+1,i_{0}+2]
and every necessary swap at position
i_{0}
and
i_{0}+1
. If, after those swaps, there are still strings that do not match with
s^{*}
at position
i_{0}+2

i_{0}+2
, and hence we also know
s^{*}[i_{0}+3]
. By continuing this procedure as long as unmatched strings remain—progressively resolving each next position—we eventually reach the end of the tangled interval, or the end of
\mathcal{S}
. Let
\tilde{\mathcal{S}}
be the set obtained after performing each of those necessary swaps. Then

.

This process takes
\mathcal{O}(k)

\mathcal{O}(n)
time, we eventually construct

with no tangled intervals.

\partial_{\texttt{Ham}}(\texttt{00}^{x},a_{s})=\partial_{\texttt{Ham}}(\texttt{00}^{x},b_{s})=x_{s}

Conversely, let
\tilde{s}
be a solution for
(rs,
\partial_{\texttt{Ham}}
)

Consensus

4
Algorithms for the Swap+Hamming distance

4.1
Fixed parameter complexity of
(r,
\partial_{\texttt{SH}}
)
-
Consensus

In this section, we study the parameterized complexity of
\text{\texttt{(r,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}
. We start by stating two basic results:

Lemma 6

Given two strings
s_{1},s_{2}
both of length
n
, the distance
\partial_{\texttt{SH}}
can be computed in linear time as follows: If
s_{1}[i,i+1]=s_{2}[i+1,i]
, we count a swap at position
i
if and only if we did not count a swap at position
i-1
. The distance
\partial_{\texttt{SH}}
is then the number of mismatches not resolved by a swap.

Proof

This greedy strategy gives a valid transformation. To prove optimality, observe that swapping at
i
when
s_{1}[i,i+1]\neq s_{2}[i+1,i]
leaves at least one mismatch, so only valid swaps reduce cost. Now, skipping a swap at
i
to allow a later swap (e.g., in a pattern like
\texttt{ab}\mathinner{.\,.}\texttt{ba}
) gains at most one, matching the loss from skipping the swap at
i
. Thus, the greedy left-to-right strategy is optimal.

∎

Lemma 7

Given two strings
s_{1},s_{2}
both of length
n
, the following inequality holds:

\partial_{\texttt{SH}}(s_{1},s_{2})\leq\partial_{\texttt{Ham}}(s_{1},s_{2})\leq 2\partial_{\texttt{SH}}(s_{1},s_{2}).

As a consequence, given
3
strings
s_{1},s_{2},s_{3}
all of length
n
, a
weakened triangle inequality
holds:

\partial_{\texttt{SH}}(s_{1},s_{3})\leq\min\{2\partial_{\texttt{SH}}(s_{1},s_{2})+\partial_{\texttt{SH}}(s_{2},s_{3}),\partial_{\texttt{SH}}(s_{1},s_{2})+2\partial_{\texttt{SH}}(s_{2},s_{3})\}.

Proof

The first statement follows from the fact that a swap transformation modifies two letters, and that any transformation that performs only substitutions is also valid for the Swap+Hamming distance (even if it is not optimal in general).

For the second statement, one may notice that given
s_{1},s_{2},s_{3}
, it holds that
\partial_{\texttt{SH}}(s_{1},s_{3})\leq\partial_{\texttt{SH}}(s_{1},s_{2})+\partial_{\texttt{Ham}}(s_{2},s_{3})
. Indeed, composing a transformation that performs swaps and substitutions and a transformation that performs only substitutions gives a valid Swap+Hamming transformation. However, this does not hold if both transformations involve swaps, as those swaps might be incompatible. The second statement then follows from the first one by noticing that the roles of
s_{1}
and
s_{3}
are symmetrical.
∎

Our result is mainly based on the following Lemma, which is already central in the proof of the corresponding theorem for the Hamming distance.

Lemma 8
(
[
14
]
)

Let
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
be a set of strings having length
n
,
s^{*}
a string satisfying
\max_{s\in\mathcal{S}}\partial_{\texttt{Ham}}(s^{*},s)\leq d
, and
\tilde{s}
a string such that for at least one
s\in\mathcal{S}
we have
\partial_{\texttt{Ham}}(\tilde{s},s)\geq d+1
. Let us fix a set
P
of
d+1
positions
p
such that
\tilde{s}[p]\neq s[p]
for each
p\in P
. Then, for at least one
p\in P
,
s[p]=s^{*}[p]
.

We now prove our main result on
\text{\texttt{(r,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}
:

Theorem 4.1

\text{\texttt{(r,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}(d)\in{\sf FPT}
.

Proof

We adapt the algorithm from
[
14
]
, with additional branchings that take swapped pairs of letters from one of the strings in
\mathcal{S}
. Namely, let us assume that we are given a candidate string
\tilde{s}
such that, for some fixed
s\in\mathcal{S}
, we have
\partial_{\texttt{SH}}(\tilde{s},s)>d
, and that there exists a consensus string
s^{*}
with
\max_{s\in\mathcal{S}}\partial_{\texttt{SH}}(s,s^{*})\leq d
. We first show that, similarly to the Hamming distance, we can always find a set of
\mathcal{O}(d)
strings where at least one is strictly closer (in Hamming distance) from
s^{*}
than
\tilde{s}
is.

Let us first assume that
\partial_{\texttt{Ham}}(\tilde{s},s)\geq 2d+1
. Then, from Lemma
7
, we know that
\max_{s\in\mathcal{S}}\partial_{\texttt{Ham}}(s,s^{*})\leq 2d
, hence from Lemma
8
, for any fixed set
M
of
2d+1
mismatch positions between
\tilde{s}
and
s
, the strings
s
and
s^{*}
must match on at least one position from
M
. We can then obtain a suitable set by defining for each
p\in M
a string obtained from
\tilde{s}
by replacing
\tilde{s}[p]
by
s[p]
. Let us now assume that
\partial_{\texttt{Ham}}(\tilde{s},s)\leq 2d
. By hypothesis and by Lemma
7
, we also have
\partial_{\texttt{Ham}}(\tilde{s},s)\geq d+1
. Let
M
be the set of mismatching positions between
\tilde{s}
and
s
, with
|M|=\mathcal{O}(d)
. If for some
p\in M
, one has
s[p]=s^{*}[p]
, we obtain the set of
\mathcal{O}(d)
strings as before. On the other hand, if for every
p\in M
, one has
s[p]\neq s^{*}[p]
, then the strings
s
and
s^{*}
have
d+1
mismatches, and since
\partial_{\texttt{SH}}(s,s^{*})\leq d
, there is at least one swap between
s
and
s^{*}
involving a position from
M
. So for some pair
(p,p+1)
with
p
or
p+1
in
M
, one has
s[p,p+1]=s^{*}[p+1,p]
. What remains to show is that for at least one such pair, one has
\tilde{s}[p,p+1]\neq s^{*}[p,p+1]
: if this is not the case, then each mismatch (resp. swap) from
\tilde{s}
to

is also a mismatch (resp. swap) from
s
and
s^{*}
, hence
\partial_{\texttt{SH}}(s,s^{*})\geq\partial_{\texttt{SH}}(s,s^{\prime})\geq d+1
, a contradiction. In that case, the
\mathcal{O}(d)
strings are constructed by replacing
\tilde{s}[p,p+1]
with

, or
\tilde{s}[p-1,p]
with

for each

.

We can now describe an

algorithm for
(r,
\partial_{\texttt{SH}}
)
-
Consensus
: we start with a candidate
\tilde{s}\in\mathcal{S}
and explore each branch as described (if
\partial_{\texttt{Ham}}(\tilde{s},s)\geq 2d+1
, we consider only

\mathcal{O}(d)
of them since we impose

. The depth of the branching tree is also in
\mathcal{O}(d)
: since
\tilde{s}\in\mathcal{S}
, one has
\partial_{\texttt{Ham}}(\tilde{s},s^{*})\leq 2\partial_{\texttt{SH}}(\tilde{s},s^{*})\leq 2d
(Lemma

), and we can conclude because this distance decreases for at least one branch at each step. Therefore, after
i

from a solution, hence at Hamming distance at most

from any string in
\mathcal{S}
(by Lemma

and the standard triangle inequality for the Hamming distance). Therefore, we can ignore the search branches that cannot lead to a solution by trimming any instance such that
\partial_{\texttt{Ham}}(\tilde{s},s)\geq 4d-i+1

is the depth of the current recursion in the search tree.∎

Finally, we study the kernelization of the consensus problems under

Theorem 4.2

Neither
\text{\texttt{(r,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}(d,n,|\Sigma|)

Given an instance

of

for

We start with the following Lemma. Informally, it implies that a solution for

\partial_{\texttt{SH}}
)

Consensus
can be obtained from a solution for
(s,
\partial_{\texttt{Ham}}
)

by the repeated operations of replacing its letters by swapped letters taken from strings in

Lemma 9

Let
\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
be a set of strings all having length
n
and admitting a solution to
\text{\texttt{(s,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}
with sum of distances
D
. Let
s^{*}_{H}
be the lex-minimal solution to
\text{\texttt{(s,$\partial_{\texttt{Ham}}$)}}-\allowbreak\text{{\sc Consensus}}
. Then, if
s^{*}_{SH}
is the lex-minimal solution to
\text{\texttt{(s,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}
for
\mathcal{S}
, the following holds: for each
1\leq i\leq n
, if one has
s^{*}_{SH}[i]\neq s^{*}_{H}[i]
, then one has
SW(\mathcal{S},s^{*},i-1)\neq\emptyset
or
SW(\mathcal{S},s^{*},i)\neq\emptyset
.

Proof

Let
i
be such that
s^{*}_{SH}[i]\neq s^{*}_{H}[i]
. If for every
j
, the strings
s^{*}_{SH}
and
s_{j}
have no swap at positions

, nor at position

, then one has:

\displaystyle\sum_{j\leq n}\partial_{\texttt{SH}}(s^{*}_{SH},s_{j})

\displaystyle=\sum_{j\leq n}\partial_{\texttt{SH}}(s^{*}_{SH}[1\mathinner{.\,.}i-1],s_{j}[1\mathinner{.\,.}i-1])

\displaystyle+\sum_{j\leq n}\partial_{\texttt{Ham}}(s^{*}_{SH}[i],s_{j}[i])

\displaystyle+\sum_{j\leq n}\partial_{\texttt{SH}}(s^{*}_{SH}[i+1\mathinner{.\,.}n],s_{j}[i+1\mathinner{.\,.}n])

But by definition of

, one has

\sum_{j\leq n}\partial_{\texttt{Ham}}(s^{*}_{H}[i],s_{j}[i])\leq\sum_{j\leq n}\partial_{\texttt{Ham}}(s^{*}_{SH}[i],s_{j}[i]),

and by optimality of

and

, both sides are equal. Since each strings is also lex-minimal, we obtain

.
∎

Given
\mathcal{S}
, we consider the set
\mathcal{S}_{i}
of length

\mathcal{S}
. We define a dynamic programming table

as follows: Let

Remark 2

Consider a set of

\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}
, and a pair

Lemma 10

\mathcal{S}=\{s_{1},\mathinner{.\,.},s_{k}\}

, and the sets

is clear, because for those cases, the constraints on the admissible strings define a unique candidate.

For the recurrence relation, we write
t=\Tf[i+1,W]
. We prove, by induction, that we necessarily have
t\in\pre(i,W)
, which directly implies the claim. Let us write
W^{\prime}=SW(\mathcal{S}_{i},t,i)
. First assume
W^{\prime}\neq\emptyset
. We write
\Tf[i,W]=t\cdot\texttt{b}
. Extending from
t
to
t\cdot\texttt{b}
adds a cost of
1
for each
j
such that
s_{j}[i+1]\neq\texttt{b}
, unless a swap at
i
occurs (i.e.,
j\in W
), which cancels the mismatch. The net change is the number of mismatches at
i+1
minus the number of swaps at
i
; hence, we have

\sum_{s\in S_{i}}\partial_{\texttt{SH}}(\Tf[i,W],s)=\sum_{s\in S_{i-1}}\partial_{\texttt{SH}}(t,s)+|\{\,j\in[k]\colon s_{j}[i+1]\neq b\}|-|W|.

Then if

\sum_{s\in S_{i-1}}\partial_{\texttt{SH}}(t,s)\geq\sum_{s\in S_{i-1}}\partial_{\texttt{SH}}(\Tf[i-1,W^{\prime}],s),

one has

\sum_{s\in S_{i}}\partial_{\texttt{SH}}(\Tf[i,W],s)\geq\sum_{s\in S_{i}}\partial_{\texttt{SH}}(\Tf[i-1,W^{\prime}]\cdot b,s),

and both sides are equal by optimality of
\Tf[i,W]
. Since ties are broken lexicographically, it follows that
t=\Tf[i-1,W^{\prime}]
, and

\Tf[i,W]=t\cdot\texttt{b}\in\pre(W)
.
Now if
W^{\prime}=\emptyset
, we write
\Tf[i,W]=t\cdot ba

(note that
ab
is entirely determined by
W^{\prime}
and
W
). In that case, one obtains:

\sum_{s\in S_{i}}\partial_{\texttt{SH}}(\Tf[i,W],s)=\sum_{s\in S_{i-2}}\partial_{\texttt{SH}}(t,s)+\sum_{s\in S}\partial_{\texttt{SH}}(\texttt{ab},s[i,i+1]).

and by optimality of
\Tf[i,W]
, writing
\tilde{W}=SW(\mathcal{S},t,i-2)
, we have
t=\Tf[i-2,\tilde{W}]
, and
T[i-2,\tilde{W}]\cdot\texttt{ab}
reaches
\emptyset
at
i-1
and
W
at
i
. Hence,
\Tf[i,W]=\Tf[i-2,\tilde{W}]\cdot\texttt{ab}\in\pre(i,W)
.

Theorem 4.3

One can solve
(s,
\partial_{\texttt{SH}}
)
-
Consensus
in
\mathcal{O}(k^{3}n^{2})
or
\mathcal{O}(|\Sigma|k^{2}n^{2})
time.

Proof

We use dynamic programming with the table
\Tf[i,W]
. We first compute
s^{*}_{H}
, a lexicographically minimal solution for
(s,
\partial_{\texttt{Ham}}
)
-
Consensus
, and we initialize the lines
0
and
1
of
\Tf
as described in Lemma
11
. We then compute
\Tf
inductively using the relation from Lemma
11
. More precisely, for each reachable
(i,W)
we construct all the strings that are extensions of
t=\Tf[i,W]
and are contained in
\pre(i^{\prime},W^{\prime})
for some
W^{\prime}
that is reachable at position
i^{\prime}=i+1
or
i^{\prime}=i+2
. By definition, those strings are exactly the strings of the form
t\cdot\texttt{a}
for
\texttt{a}\in\mathcal{S}[i+1]
that reach
W\neq\emptyset
at position
i+1
, the string
t\cdot s_{H}^{*}[i+2]
if it reaches
\emptyset
at position
i+1
, and the strings of the form
t\cdot\texttt{ab}
reaching
\emptyset
at position
i+1
, with
\texttt{ba}\in\mathcal{S}[i+2,i+3]
. Note that for the special case
\Tf[0,\emptyset]=s_{H}^{*}[1]
, we compute only this last type of extensions, as the other ones would correspond to elements of the first line of the table, which is already computed during initialization.

For each such
t^{\prime}
, we compute its partial score
d_{t^{\prime}}
(the sum of distances up to
i+1
), and store the tuple
(i^{\prime},W^{\prime},t^{\prime},d_{t^{\prime}})
, where
W^{\prime}
is the set reached by
t^{\prime}
on position
i^{\prime}=|t^{\prime}|-1
. We maintain only the best-scoring string for each
(i^{\prime},W^{\prime})
, and for every position
i^{\prime}
we sort tuples lexicographically by the indicator vector of
W^{\prime}\subseteq[k]
. By construction, and by Lemma
11
, after processing every
i<i^{\prime}
, the only tuple corresponding to
(i^{\prime},W^{\prime})
contains
\Tf[i^{\prime},W^{\prime}]
.

From Lemma
10
, we have at most
\mathcal{O}(kn)
partial solutions per step. Each of them can be extended in at most
\mathcal{O}(k)
or
\mathcal{O}(|\Sigma|)
ways (extensions are always taken from
\mathcal{S}[i,i+1]
, or
s_{H}[i]
). Updating distances and computing swap sets both take
\mathcal{O}(k)
time. Thus, the total time complexity is
\mathcal{O}(k^{3}n^{2})
, or
\mathcal{O}(|\Sigma|k^{2}n^{2})
. ∎

Example 3

Let
s_{1}=\texttt{baba},~s_{2}=\texttt{cabc},~s_{3}=\texttt{abca}
and

t

\emptyset

5
Open questions

We leave the following questions open:

•

Is
\text{\texttt{(rs,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}(d)\in{\sf FPT}
?

•

Can one find conditional lower bounds, or a more efficient algorithm, for
\text{\texttt{(s,$\partial_{\texttt{SH}}$)}}-\allowbreak\text{{\sc Consensus}}
?

•

Can our algorithms be generalized to allow deleting a certain number of outlier strings or columns in
\mathcal{S}
such that the resulting substrings admit a solution (cf.
[
7
]
)?

•

As the
FPT
algorithms for those problems (even the classical algorithm from
[
14
]
for the Hamming distance) start with some given candidate, could they be studied from the perspective of learning-augmented algorithms?
