Single-Source Shortest Path Problem in Weighted Disk Graphs
Shinwoo An, Eunjin Oh, Jie Xue

Abstract
In this paper, we present efficient algorithms for the single-source shortest path problem in weighted disk graphs. A disk graph is the intersection graph of a family of disks in the plane. Here, the weight of an edge is defined as the Euclidean distance between the centers of the disks corresponding to the endpoints of the edge. Given a family of n n disks in the plane whose radii lie in [ 1 , Ψ ] [1,\Psi] and a source disk, we can compute a shortest path tree from a source vertex in the weighted disk graph in O ⁡ ( n ​ log 2 ​ n ​ log ⁡ Ψ ) O(n\log^{2}n\log\Psi) time. Moreover, in the case that the radii of disks are arbitrarily large, we can compute a shortest path tree from a source vertex in the weighted disk graph in O ⁡ ( n ​ log 4 ​ n ) O(n\log^{4}n) time. This improves the best-known algorithm running in O ⁡ ( n ​ log 6 ​ n ) O(n\log^{6}n) time presented in ESA’23 [ 14 ] .

Introduction

Geometric intersection graphs are a fundamental class of graphs representing spatial relationships among geometric objects. In this paper, we focus on the intersection graph of disks in the plane.
More formally, for a set
P
of
n
points in the plane, where each point
v\in P
has an associated radius
r_{v}
,
the
disk graph

G
of
P
is defined as the graph where each vertex corresponds to a point
P
,
and two vertices
u
and
v
of
P
are connected by an edge if and only if the disks with center

and radii
r_{u},r_{v}
intersect.
For an
edge-weighted
disk graph, the weight of an edge

is defined as
|uv|
.
In the special case that all radii are the same, the disk graph is also called a

.
Disk graphs can be used as a model for broadcast networks: The disks of
P
represent transmitter-receiver stations with transmission power.
One can view a broadcast range of a transmitter as a disk.

In this paper, we consider the

(SSSP) problem for edge-weighted disk graphs:
Given a set

One straightforward way to deal with a disk graph is to construct

However, a disk graph might have complexity

in the worst case
even though it can be (implicitly) represented as
n
disks.
Therefore, it is natural to seek faster algorithms for a disk graph implicitly represented as its underlying set of disks.
Besides the SSSP problem, many graph-theoretic problems have much more efficient solutions in disk graphs than in general graphs

2.1
Sketch of Our Algorithm

We review the well-known Dijkstra’s algorithm that computes a shortest path tree from a source vertex.
Initially, the algorithm sets all dist-values to infinity except a source vertex, and sets
Q=P
. The algorithm sequentially applies the following steps until

is empty.

•

(D1)
Pick the vertex

with smallest dist-value.

•

(D2)
For all neighbors
v\in Q
of

\text{dist}(v)\leftarrow\min\{\text{dist}(v),\text{dist}(u)+|uv|\}
.

•

(D3)
Remove

from

In the worst case, Dijkstra’s algorithm takes quadratic time since a disk graph can have

In our algorithm, we simultaneously update the dist-values of several vertices by the

[

]

For any two vertex set

does the following: For all

•

(U1)
Compute

s.t.

is an edge of

.

•

(U2)
Update
\text{dist}(v)\leftarrow\min\{\text{dist}(v),\text{dist}(u)+|uv|\}

That is, the subroutine updates the dist-values of all vertices of
V
using the dist-values of the vertices of

.
The subroutine gets input

and

from a

.

We use

Basic strategy of
[
22
]
.

We utilize the strategic adaptation of Dijkstra’s algorithm in a cell-by-cell manner with
P_{\text{small}}(\cdot)
and
P_{\text{mid}}(\cdot)

This strategy was used in

]
to design an efficient algorithm for the weighted SSSP problem on unit disk graphs.
For concreteness, we describe the details of the strategy below.
Let

be the vertex with the smallest dist-value among all vertices not processed so far. As an invariant, we shall guarantee that all vertices of
G
which have been processed
have correct dist-values, and

has a correct dist-value if its predecessor in the shortest

-

We want to process not only

However, notice that, at this moment, the vertices in

Thus, as a first step, we compute the correct dist-values for all vertices in
P_{\text{mid}}(c_{v})

If the predecessor

in the shortest

-
v^{\prime}

However, it is possible that

has not been processed yet so far and does not have the correct dist-value.
Fortunately, even in this case, we can show that

has a correct dist-value.
To see this, let

be the predecessor of

in the shortest
s
-

Then

The last inequality follows since the concatenation of

Now

Due to the invariant,

Consequently, we can update the dist-values of all vertices of

The second step is to transmit the correct dist-values of

Main obstacles and lazy update scheme.

The complexity of this strategy primarily depends on the cost of searching all neighbors of
P_{\text{mid}}(c_{v})
.
This was not a big deal in
[
22
]

In the case of disk graphs, however, a vertex with radius
\Theta(\Psi)
can be adjacent to vertices in
P_{\text{mid}}(c)
for

distinct grid cells

To avoid polynomial dependency on
\Psi
, we handle regular edges and irregular edges separately.
More specifically, we can search all regular edges by considering
P_{\text{mid}}(c)
for all
c\in\boxplus_{c_{v}}
by Lemma

Since
\boxplus_{c_{v}}
consists of

\Psi

However, the same approach cannot be used to search all irregular edges as up to

sets of

in the worst case.
We address this issue with a novel approach, which we call

We say

of a vertex

if

Furthermore, we say

of a cell

In the basic strategy, we transmit the correct dist-value of

to

In the lazy update scheme, we postpone the transmission to

for all cells

is a

We handle several postponed update requests at once at some point.
More specifically,

We transmit the dist-values of

into

Algorithm

In this section, we

More specifically, we use a

This approach has been applied to design efficient algorithms on disk graphs of arbitrary radius ratios, such as the dynamic connectivity problem
[

]
and the unweighted single-source shortest path problem

]

By integrating this approach with our lazy update scheme in a more sophisticated way, we can design an

Proof.

First, we analyze the time complexity of insert operations.
Since we always insert a single vertex into the data structure, the size of each binary tree of the data structure is always a power of two, and we always merge two binary trees of equal size.
Recall that from the analysis of

Therefore, all merging steps take

Next, we analyze the time complexity of a query operation.
For each

Since each nearest neighbor query takes
