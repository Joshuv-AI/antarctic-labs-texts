Approximating splits for decision trees quickly in sparse data streams Thanks: This research is supported by the Academy of Finland projects MALSOME (343045)
Nikolaj Tatti

Abstract
Decision trees are one of the most popular classifiers in the machine learning literature. While the most common decision tree learning algorithms treat data as a batch, numerous algorithms have been proposed to construct decision trees from a data stream. A standard training strategy involves augmenting the current tree by changing a leaf node into a split. Here we typically maintain counters in each leaf which allow us to determine the optimal split, and whether the split should be done. In this paper we focus on how to speed up the search for the optimal split when dealing with sparse binary features and a binary class. We focus on finding splits that have the approximately optimal information gain or Gini index. In both cases finding the optimal split can be done in 𝒪 ( d ) \mathit{\mathcal{O}}\mathopen{}\left(d\right) time, where d d is the number of features. We propose an algorithm that yields ( 1 + α ) (1+\alpha) approximation when using conditional entropy in amortized 𝒪 ( α − 1 ( 1 + m log d ) log log n ) \mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}(1+m\log d)\log\log n\right) time, where m m is the number of 1s in a data point, and n n is the number of data points. Similarly, for Gini index, we achieve ( 1 + α ) (1+\alpha) approximation in amortized 𝒪 ( α − 1 + m log d ) \mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}+m\log d\right) time. Our approach is beneficial for sparse data where m ≪ d m\ll d . In our experiments we find almost-optimal splits efficiently, faster than the baseline, overperforming the theoretical approximation guarantees.

Introduction

Decision trees are one of the most popular classifiers in the machine learning literature.
While the most well-known decision tree learning
algorithms
[
14
,
13
,
3
]

treat data as a batch, numerous algorithms have been proposed
to construct decision trees from a data stream.
In the streaming setup points arrive one-by-one, and the tree is updated on the fly.
A core step in almost every such learner is to determine the optimal split after a new data point.
A baseline approach for finding the optimal split is to test every feature, and by maintaining certain counters
this can be done in
\mathit{\mathcal{O}}\mathopen{}\left(d\right)
time, where
d
is the number of features.

In this paper we consider two scenarios where we can speed up this step.
We focus on binary features and binary labels, and our goal is to speed up selecting features
when the features are sparse. Such case can occur when dealing for example with text data,
where the dictionary of words can be large while the actual inputs, for example, bag-of-word representations
of sentences, do not contain many active features.

First, we consider optimizing information gain.
We propose an algorithm that—after adding a data
point—finds a
(1+\alpha)
-approximate optimal feature in
\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}(1+m\log d)\log\log n\right)

amortized time, where
m
is the number of 1s in a data point.
This speeds up the search if
m\ll d
which is the case for sparse data.

Roughly speaking, the approach is based on grouping features with similar
probabilities
p(y=1\mid j=0)
. That is, each group
i
has an interval, say
B_{i}
,
and if
p(y=1\mid j=0)\in B_{i}
, then feature
j
will be stored in group
i
.
Features in each group are then stored in a search tree using a specific key.
To find the approximate feature we search each tree for the optimal value, and then select the
best feature among the candidates.

It turns out that we can only have
\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}\log\log n\right)
such search trees,
and updating the key for a feature
i
is required only if we encounter a data point with
x_{i}=1
.
This will eventually lead to the stated running time.

In the second setup,
we optimize Gini index.
We propose an algorithm that
finds a
(1+\alpha)
-approximate optimal feature in
\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}+m\log d\right)

amortized time.

Our approach is similar to the approach for information gain with few technical differences.
Roughly speaking, when using information gain we do not need to delete
features from their outdated groups as
p(y=1\mid j=0)
is changing. The same does not hold
for Gini index: the features need to be removed from their old groups, potentially increasing the update time
significantly. Luckily, we can mitigate the issue by allowing the intervals
B_{i}
associated with the groups to overlap.

Related work

Numerous algorithms have been proposed to construct decision trees as data arrives in a stream.

16
proposed an algorithm that monitors existing nodes
and the moment a split becomes suboptimal, the sub-tree is replaced with the new split.

18
and
17
proposed a variant of this approach, except that
the sub-tree is not thrown away but rather modified such that the split is updated.

6

proposed a popular choice for growing decision trees incrementally. The
algorithm ignores the previous data points when starting a new leaf, thus allowing to maintain only the label counters.
As a criterion, the authors propose to compare the best and the second best split, and used a Hoeffding bound
to decide whether to split. Unfortunately,
15

showed that the assumptions used to derive the bound were incorrect, and thus can only be used as a
heuristic. Moreover, the authors propose a more conservative bound based on McDiarmid’s inequality.

12
,
11

introduced a variant that also monitors the non-leaf nodes, and if another
split becomes optimal (based on comparing the best and the second best feature) then the current sub-tree is
replaced with the new split.

10
proposed a test by estimating the entropy difference
with a normal distribution. A similar approach was also considered by
7
.

4
and
5
proposed maintaining decision trees
in a data stream within an
additive
error. Here, the goal is orthogonal to
ours: the authors’ goal is to maintain a decision tree, done by reducing the number of split updates, while
our goal is to—under certain conditions—speed up the split. The algorithms proposed by the authors are linear
w.r.t. the number of features. Combining their approach with ours with the goal of obtaining a sublinear
update time is an interesting line of future work.

A popular related line of work is building decision trees while the underlying data stream distribution is changing.

9

proposed an algorithm that adapts a decision tree to a changing data stream.
Here, the decision tree is based on data in a sliding window. If a non-leaf node becomes
suboptimal, an alternative tree is grown from that node, possibly replacing the current sub-tree.
Alternative approaches, where a user does not need to specify the window size, were considered by
1
.
Moreover,
2
proposed constructing an ensemble of trees of increasing sizes in order to adapt better to changes.

Preliminary notation

Assume that we are given a multiset
D
of pairs
(x,y)
, where
x
are the features
and
y
is the class of the sample.
Assume that features are binary and define
the counters

n(D)={\left|D\right|}\quad\text{and}\quad n_{iv}(D)={\left|\left\{(x,y)\in D\mid x_{i}=v\right\}\right|}\quad.

We also define the counters associated with each label,

\begin{split}c_{k}(D)&={\left|\left\{(x,y)\in D\mid y=k\right\}\right|}\quad\text{and}\quad\\
c_{ivk}(D)&={\left|\left\{(x,y)\in D\mid x_{i}=v,y=k\right\}\right|}\ .\end{split}

If
D
is known from the context, we will often drop
D
from the notation and write

n
,
n_{iv}
,
n_{ivk}
, and
c_{k}
.

The entropy and the conditional entropy of a feature
i
are defined as

\begin{split}\mathit{H}\mathopen{}\left(D\right)&=-\sum_{k}\frac{c_{k}(D)}{n(D)}\log\frac{c_{k}(D)}{n(D)}\ \text{ and }\ \\
\mathit{H}\mathopen{}\left(D\mid i\right)&=-\sum_{v}\sum_{k}\frac{c_{ivk}(D)}{n(D)}\log\frac{c_{ivk}(D)}{n_{iv}(D)},\end{split}

where the standard notation
0\times\log 0=0
applies.

A common criterion for the goodness of a feature is the information gain,

\mathit{I}\mathopen{}\left(i,D\right)=\mathit{H}\mathopen{}\left(D\right)-\mathit{H}\mathopen{}\left(D\mid i\right)
. Thus,
finding the optimal split is equal to finding a feature with the smallest conditional entropy
\mathit{H}\mathopen{}\left(D\mid i\right)
.

We also consider a popular alternative, namely a Gini index. The Gini index
\mathit{G}\mathopen{}\left(D\right)
and the conditional Gini index
\mathit{G}\mathopen{}\left(D\mid i\right)

are defined as

\begin{split}\mathit{G}\mathopen{}\left(D\right)&=\sum_{k}\frac{c_{k}(D)}{n(D)}\bigg(1-\frac{c_{k}(D)}{n(D)}\bigg)\ \text{ and }\\
\mathit{G}\mathopen{}\left(D\mid i\right)&=\sum_{v,k}\frac{c_{ivk}(D)}{n(D)}\bigg(1-\frac{c_{ivk}(D)}{n_{iv}(D)}\bigg)\ .\end{split}

When using Gini index, the best feature for a split is the one that minimizes
\mathit{G}\mathopen{}\left(D\mid i\right)
.

4
Approximate splits when using entropy

In this section we provide a method that approximates the best binary feature for the split quickly.
We will assume throughout this section that the output variable
y
is binary.
We should stress that this assumption is crucial.
For notational simplicity, we also assume that all our features are binary. Naturally, if we have
features that are binary, categorical, or numerical, we can combine different search strategies,
and select the best out of three.

Let us first define

(4.1)

\begin{split}\mathit{H}\mathopen{}\left(D\mid i,\theta\right)=&-\frac{c_{i00}}{n}\log(1-\theta)-\frac{c_{i01}}{n}\log\theta\\
&-\frac{c_{i10}}{n}\log\frac{c_{i10}}{n_{i1}}-\frac{c_{i11}}{n}\log\frac{c_{i11}}{n_{i1}}\ .\end{split}

Note that
\mathit{H}\mathopen{}\left(D\mid i,\theta\right)\geq\mathit{H}\mathopen{}\left(D\mid i,c_{i01}/n_{i0}\right)=\mathit{H}\mathopen{}\left(D\mid i\right)
, since the first two terms in Eq.
4.1
form a negative,
scaled log-likelihood of a Bernoulli model, for which the optimal parameter is
c_{i01}/{n_{0}}
.

Proposition 4.1

The conditional entropy can be decomposed into two parts,

\mathit{H}\mathopen{}\left(D\mid i,\theta\right)=\frac{1}{n}\left(C(c_{0},c_{1},\theta)+K(c_{i10},c_{i11},\theta)\right),

where

\begin{split}C(c_{0},c_{1},\theta)&=-c_{0}\log(1-\theta)-c_{1}\log\theta,\quad\text{and}\\
K(c_{i10},c_{i11},\theta)&=-c_{i10}\log\frac{c_{i10}}{n_{i1}(1-\theta)}-c_{i11}\log\frac{c_{i11}}{n_{i1}\theta}\quad.\end{split}

Note that the definition of
K
depends on
n_{i1}
but
n_{i1}=c_{i10}+c_{i11}
, so
K
is well-defined.

The claim follows immediately by using the identities
c_{i00}=c_{0}-c_{i10}
and
c_{i01}=c_{1}-c_{i11}

together with Eq.
4.1
, and rearranging the terms.

Note that, for a
fixed

\theta
, the term
C(\cdot)
does not depend on the feature
i
.
The term
K(\cdot)
depends only on
c_{i10}
and
c_{i11}
(and
\theta
),
changes only for a feature
i
when we process a data point
(x,y)
with
x_{i}=1
.

Our high-level strategy is as follows:
we construct a set of real numbers
\left\{\mu_{i}\right\}
, and to each
\mu_{i}
we assign a set of features. We then find a feature with the smallest
K(\cdot,\cdot,\mu_{i})
, and
among these candidates we select the feature
j
with the smallest
\mathit{H}\mathopen{}\left(D\mid j\right)
.

To be more specific, assume
\alpha>0
and let
D
be a dataset with
n
data points.
We define a set of intervals
B_{-1},B_{-2},\ldots,B_{-\ell}
as

B_{i}=[s_{i},t_{i}],\ \text{where}\ s_{i}=2^{-(1+\alpha)^{-i}},\ t_{i}=2^{-(1+\alpha)^{-i-1}},

for
i=-1,\ldots,-\ell
,
and
\ell
is set such that
s_{-\ell}\leq 1/n<t_{-\ell}
. We also set

B_{-\infty}=[s_{-\infty},t_{-\infty}]=[0,0]
.
We extend the definition to
B_{i}
for

by setting
B_{i}=[s_{i},t_{i}]
, where
s_{i}=1-t_{-i}
and
t_{i}=1-s_{-i}
.
Finally, for each bin
B_{i}
, we define a centroid
\mu_{i}=s_{i}
for
i<0
and

\mu_{i}=t_{i}
for

.

Proposition 4.2

Let
\alpha
,
D
,
n
,
\left\{B_{i}\right\}
, and
\ell
as defined above.
Let
j
be a feature and let
\rho=c_{j01}/n_{j0}
.
For any
B_{i}
such that
\rho\in B_{i}
, we have
\mathit{H}\mathopen{}\left(D\mid j,\mu_{i}\right)\leq(1+\alpha)\mathit{H}\mathopen{}\left(D\mid j\right)
.
Moreover, there is
B_{i}
such that
\rho\in B_{i}
.
The number of intervals
{\left|\left\{B_{i}\right\}\right|}
is in

\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}\log\log n\right)
.

Let us first prove the first claim.
Note that
\mathit{H}\mathopen{}\left(D\mid j\right)=\mathit{H}\mathopen{}\left(D\mid j,\rho\right)
.
If
\rho=0
, then
\rho\in B_{-\infty}
and

is the only one containing
\rho

The case for
\rho=1
is similar.

Assume that

. Then
1/n\leq\rho\leq 1-1/n
, and thus there is
B_{i}
such that
\rho\in B_{i}
.

Assume that

. Then
\mu_{i}=s_{i}\leq\rho
, and
\rho\leq t_{i}=\mu_{i}^{(1+\alpha)^{-1}}
implying
\rho^{1+\alpha}\leq\mu_{i}
.
Let

4.1

Then

\begin{split}\mathit{H}\mathopen{}\left(D\mid j,\mu_{i}\right)&=A-\frac{c_{j00}}{n}\log(1-\mu_{i})-\frac{c_{j01}}{n}\log\mu_{i}\\
&\leq A-\frac{c_{j00}}{n}\log(1-\rho)-(1+\alpha)\frac{c_{j01}}{n}\log\rho\\
&\leq(1+\alpha)(A-\frac{c_{j00}}{n}\log(1-\rho)-\frac{c_{j01}}{n}\log\rho)\\

To continue, note that

Proposition 4.4

Let

be the number of features,

be the number of data points,

Let

To prove the approximation guarantee,
let

be the optimal feature, and let

guarantees that the invariant is maintained,
and thus there is

such that

the updates to

in the first for-loop,
or in other words,
\Delta_{j}\in\mathit{\mathcal{O}}\mathopen{}\left(h\sum_{x\in D}x_{j}\right)
. Each update requires
\mathit{\mathcal{O}}\mathopen{}\left(\log d\right)
time.
In summary, adding
n
data points requires
\mathit{\mathcal{O}}\mathopen{}\left(hn+h\sum_{j}\Delta_{j}\log d+h\sum_{x\in D,j}x_{j}\log d\right)\subseteq\mathit{\mathcal{O}}\mathopen{}\left(hn+h\sum_{x\in D,j}x_{j}\log d\right)
time.

Finally, the last three lines require
\mathit{\mathcal{O}}\mathopen{}\left(h\right)
time, proving the proposition.

5
Approximate splits when using Gini index

Our strategy for selecting a feature with an approximately best Gini index is similar.
As before we assume that we are dealing with binary features and binary labels.
Let

\mathit{G}\mathopen{}\left(D\mid j,\theta\right)=2\frac{c_{j10}}{n}\frac{c_{j11}}{n_{j1}}+\frac{2}{n}\begin{cases}c_{j00}\theta&\theta\geq 1/2\\
c_{j01}(1-\theta)&\theta<1/2\\
\end{cases}\quad.

Note that
\mathit{G}\mathopen{}\left(D\mid j,c_{j01}/n_{j0}\right)=\mathit{G}\mathopen{}\left(D\mid j\right)
.
Similar to Proposition
4.1
, we can decompose
\mathit{G}\mathopen{}\left(D\mid j,\theta\right)

into two components, one not depending the feature
j
.

Proposition 5.1

The Gini index can be written as

\mathit{G}\mathopen{}\left(D\mid j,\theta\right)=\frac{1}{n}\left(C(c_{0},c_{1},\theta)+K(c_{j10},c_{j11},\theta)\right),

where

\begin{split}C(c_{0},c_{1},\theta)&=\begin{cases}2c_{0}\theta&\theta\geq 1/2\\
2c_{1}(1-\theta)&\theta<1/2\\
\end{cases}\quad\text{and}\\
K(c_{j10},c_{j11},\theta)&=2c_{j10}\frac{c_{j11}}{n_{j1}}-\begin{cases}2c_{j10}\theta&\theta\geq 1/2\\
2c_{j11}(1-\theta)&\theta<1/2\ .\\
\end{cases}\end{split}

As with the entropy, we define a set of intervals
\left\{B_{i}\right\}
and centroids
\left\{\mu_{i}\right\}
,
and estimate the Gini index of a feature
j
such that
\frac{c_{j01}}{n_{j0}}\in B_{i}
with
\mathit{G}\mathopen{}\left(D\mid j,\mu_{i}\right)
.

More specifically, assume that we are given
\alpha>0
.
Define
\beta=\frac{\alpha}{\alpha+2}
.
Define the intervals
B_{0},\ldots,B_{\ell}
as

\begin{split}B_{i}&=[s_{i},t_{i}],\quad\text{where}\quad\\
s_{i}&=(i/2-1/4)\beta,\ t_{i}=(i/2+3/4)\beta,\ i=0,\ldots,\ell,\end{split}

where
\ell
is set such that
s_{\ell}<1\leq t_{\ell}
.
With each
B_{i}
we associate a centroid,
\mu_{i}=(s_{i}+t_{i})/2=(i/2+1/4)\beta
.
Note that the intervals are overlapping, and shifted by
1/4
to the left.
Both properties will be needed later in Proposition
5.3
when proving the running time.

Next we show that we can use
\mathit{G}\mathopen{}\left(D\mid j,\mu_{i}\right)
to approximate
\mathit{G}\mathopen{}\left(D\mid j\right)
.

Proposition 5.2

Let
\left\{B_{i}\right\}
and
\left\{\mu_{i}\right\}
as defined above.
Assume two features
j
and
k
such that
\frac{c_{j01}}{n_{j0}},\frac{c_{k01}}{n_{k0}}\in B_{i}
for some
B_{i}
.
If
\mathit{G}\mathopen{}\left(D\mid j,\mu_{i}\right)\leq\mathit{G}\mathopen{}\left(D\mid k,\mu_{i}\right)
, then
\mathit{G}\mathopen{}\left(D\mid j\right)\leq(1+\alpha)\mathit{G}\mathopen{}\left(D\mid k\right)
.

Assume
\mu_{i}\geq 1/2
. Then
s_{i}\geq 1/2-\beta/2=(\alpha+2)^{-1}
.
Given a feature
a

\rho_{a}=\frac{c_{a01}}{n_{a0}}
and

A_{a}=2\frac{c_{a10}}{n}\frac{c_{a11}}{n_{a1}}
.

Let
\Delta_{1}=\max(\rho_{j}/\mu_{i},1)

and
\Delta_{2}=\max(\mu_{i}/\rho_{k},1)

We have

\begin{split}\mathit{G}\mathopen{}\left(D\mid j\right)&=A_{j}+2\frac{c_{j00}}{n}\rho_{j}\leq A_{j}+\Delta_{1}2\frac{c_{j00}}{n}\mu_{i}\\
&\leq\Delta_{1}(A_{j}+2\frac{c_{j00}}{n}\mu_{i})=\Delta_{1}\mathit{G}\mathopen{}\left(D\mid j,\mu_{i}\right)\end{split}

and similarly,

\mathit{G}\mathopen{}\left(D\mid k,\mu_{i}\right)\leq\Delta_{2}\mathit{G}\mathopen{}\left(D\mid k\right)
, leading to

\begin{split}\mathit{G}\mathopen{}\left(D\mid j\right)&\leq\Delta_{1}\mathit{G}\mathopen{}\left(D\mid j,\mu_{i}\right)\\
&\leq\Delta_{1}\mathit{G}\mathopen{}\left(D\mid k,\mu_{i}\right)\leq\Delta_{1}\Delta_{2}\mathit{G}\mathopen{}\left(D\mid k\right)\quad.\end{split}

A straightforward calculation leads to

\Delta_{1}\Delta_{2}\leq\frac{\max(\mu_{i},\rho_{j})}{\min(\mu_{i},\rho_{k})}\leq\frac{t_{i}}{s_{i}}=1+\frac{\alpha}{(2+\alpha)s_{i}}\leq 1+\alpha,

proving the claim for
\mu_{i}\geq 1/2
. The case for
\mu_{i}<1/2
is similar.

Concluding remarks

In this paper we considered estimating splits when constructing decision trees.
We focused on sparse data with binary labels, and
showed that we can estimate the optimal split for sparse data when information gain is used in
\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}(1+m\log d)\log\log n\right)
time,
where
n
is the number of data points,
d
is the number of features and
m
is the number of 1s in a data point.
When Gini index is used, we can estimate the split in
\mathit{\mathcal{O}}\mathopen{}\left(\alpha^{-1}+m\log d\right)
time.
If
m\ll d
, then
this is significantly faster than the
\mathit{\mathcal{O}}\mathopen{}\left(d\right)
baseline approach.

Speeding up incremental construction of decision trees by approximating splits
yields several potential future lines of work. One of the key assumptions is that the
labels are binary. If this assumption does not hold, then a different appproach is required as adopting the described approach is most likely not feasible.
Moreover, our main focus was time complexity and our algorithms have the same space complexity as the baseline approaches. Reducing the space
complexity is a potential future line of work.
