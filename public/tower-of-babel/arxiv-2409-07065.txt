Fast Simulation of Cellular Automata by Self-Composition
Joseph Natal, Oleksiy Al-saadi

Abstract
It is shown that computing the configuration of any one-dimensional cellular automaton at generation n n can be accelerated by constructing and running a composite one with a radius proportional to log ⁡ n \log n . The new automaton is the original automaton whose local rule function is composed with itself. The asymptotic time complexity to compute the configuration of generation n n is reduced from O ⁡ ( n 2 ) O(n^{2}) operations to O ⁡ ( n 2 / log ⁡ n ) O(n^{2}/\log n) on a given machine with O ⁡ ( n 2 ) O(n^{2}) memory usage. Experimental results are given in the case of Rule 30 30 .



Keywords—
cellular automata, time-complexity, Rule 30, nonlinear systems

1
Introduction

Compositions of cellular automata have been discussed in different contexts since their inception decades ago
[
Wol84
]
, but their relevance for time-complexity improvements has yet to be fully determined using formal asymptotic analysis. Perhaps the most similar algorithm in concept to the one described herein is given by a hashed implementation of the Game of Life
[
Gos84
]
. This algorithm memoizes local recurrent space-time patterns for Life-like automata, but performs poorly for chaotic structures. Our focus on Rule
30
in this paper stems from its notoriously chaotic nature and perceived lack of structure. The naive method of computing the configuration at generation
n
of an ECA is simply to update row by row, requiring
O(n^{2})
boolean operations. In contrast, CAs with nested patterns such as the well-studied Rule
90
or Rule
150
contain a fractal structure which allows for a given space-time coordinate to be determined in
O(\log n)
operations
[
CID89
]
. The following simple result sets a precedent for further complexity reductions with possible implications for problems relating to cryptography, automata theory, and nonlinear dynamical systems.

of the CA: the number of neighbor cells to the left and right of the current cell which are taken into account when applying the rule icon. These cells are sometimes referred to as a

30
shows that the rule has radius
1
(see the above rule icon).

We will restrict our study of CA to those with two colors by defining
\Sigma=\mathbb{Z}_{2}=\{0,1\}=\{\square,\blacksquare\}

2
-color. If a
2
-color CA
\mathcal{F}
has radius
1
then we call
\mathcal{F}
an
elementary cellular automaton
(ECA). Wolfram popularized a systematic numbering scheme for ECA where for any given Rule
k

k
and assigning them as outputs to the set of binary
3

0

A

. We explicitly define the

of a configuration as

\begin{split}X_{n+1}^{\mathcal{F}}=\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-\infty}^{\infty}f\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r}^{r}x^{n}_{i+j}\big)\end{split}

(1)

and for an individual cell in
X_{n+1}^{\mathcal{F}}

x^{n+1}_{i}=f\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r}^{r}x^{n}_{i+j}\big)

(2)

where
\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}
denotes concatenation of cells. Borrowing from physics terminology,
n
reflects a dimension in time while spatial dimension is reflected by the
i

X_{n}^{\mathcal{F}}
. A CA
\mathcal{F}
has a
simple seed
if
X_{1}^{\mathcal{F}}=\langle\cdots\square,\square,\square,\blacksquare,\square,\square,\square,\cdots\rangle
.

The rule icons of any CA with radius
r
can be equivalently represented through an algebraic form as a function
f:\Sigma^{2r+1}\rightarrow\Sigma
. For example, for any generation
n+1
and index
i
, the color
x^{n+1}_{i}
of Rule
150
can be expressly computed by the following trivariate function:

x_{i}^{n+1}=x_{i-1}^{n}+x_{i}^{n}+x_{i+1}^{n}\mod 2

(3)

The Rule
150
CA is well known for its fractal self-symmetry and its algebraic form is similarly straightforward. Meanwhile, the following non-linear discrete dynamical equation governs Rule
30

x^{n+1}_{i}=\overbrace{x^{n}_{i-1}+x^{n}_{i}+x^{n}_{i+1}}^{\text{Rule 150}}\;\;\;+\overbrace{x^{n}_{i}x^{n}_{i+1}}^{\text{non-linear term}}\;\;\mod 2

(4)

or equivalently, using boolean algebra:

x_{i}^{n+1}=x_{i-1}^{n}\oplus(x_{i}^{n}\lor x_{i+1}^{n})

(5)

Notice that the rule function of Rule
30
contains the algebraic form of Rule
150
. Although this component of the function is rather simple in and of itself, the abrupt complexity of Rule
30
arises from the nonlinear term. The runtime of any cellular automaton is dependent on the underlying machine which is simulating it. For example, a
random-access memory
(RAM) machine can simulate a single-tape Turing machine with no extra runtime or memory, but for a RAM machine simulating a single-tape Turing machine this generally does not hold and incurs both memory and runtime costs
[
Sav97
]
. For the algorithm presented herein, the RAM model is useful insofar as it offers constant-time access to any memory address. In particular, the boolean output of a radius
r
composite rule will need to be accessed in a time that doesn’t scale with
r
, leveraging a time-memory tradeoff. For completeness, we claim this algorithm can also be implemented with alternative machines, such as a contrived multi-tape Turing machine. A sketch of the proof is provided as the implementation details are outside of the scope of this work (see Appendix).

Automata Self-Composition

In this section, we show the local rule function of a cellular automata can be composed with itself in order to create a new CA satisfying special constraints on its configurations.

Definition 1
.

Let the composition of two rules with functions
f_{1}
and
f_{2}
be defined as

\displaystyle(f_{2}\circ f_{1})(X):\big\{\Sigma^{2(r_{1}+r_{2})+1}\rightarrow\Sigma:X\;\mapsto\;f_{2}\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-r_{2}}^{r_{2}}f_{1}(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r_{1}}^{r_{1}}x_{i+j})\big)\big\}

(6)

This composite rule is therefore a local rule with radius
r_{1}+r_{2}
.

By Definition
1
, the composite rule
f_{2}\circ f_{1}
consists of applying
f_{1}
to all contiguous subarrays of length
2r_{1}+1
in
X
with truncated boundary conditions in indexed order and then
f_{2}
to the concatenated results. In short, the configuration is updated according to
f_{1}
, then
f_{2}
.

The next lemma is vital to the correctness of our algorithm.

Lemma 2
.

Given a CA
\mathcal{H}
with local rule
h
and radius
r
, there exists a CA
\mathcal{G}
with local rule
g
and radius
2r
such that for every
n\in\mathbb{N}
we have that
X_{2n-1}^{\mathcal{H}}=X_{n}^{\mathcal{G}}
. It can be computed in
O(r2^{2(2r)})
-time on a machine with random-access memory.

Proof.

For self-composition, Eq.
6
is reduced to

\displaystyle(h\circ h)(X):\big\{\Sigma^{4r+1}\rightarrow\Sigma:X\;\mapsto\;h\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-r}^{r}h(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r}^{r}x_{i+j})\big)\big\}

(7)

Replacing
h
with
h\circ h
in the global update (Eq.
1
) and assigning a generation
n
gives

\begin{split}X^{\mathcal{G}}_{n+1}=\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-\infty}^{\infty}(h\circ h)\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-2r}^{2r}x^{n}_{i+j}\big)=\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-\infty}^{\infty}h\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r}^{r}h(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{k=-r}^{r}x^{n}_{i+j+k})\big)\end{split}

(8)

and substituting
x^{n+1}_{i+j}=h(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{k=-r}^{r}x^{n}_{i+j+k})
from Eq.
2

\begin{split}=\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{i=-\infty}^{\infty}h\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{j=-r}^{r}x^{n+1}_{i+j}\big)=X^{\mathcal{H}}_{n+2}\end{split}

(9)

Then the composite update is simply two global updates according to
h
in sequence. Hence, we construct
\mathcal{G}
as follows: Let
g=h\circ h
be the local rule function of
\mathcal{G}
with the same initial configuration as
\mathcal{H}
(i.e.
X_{1}^{\mathcal{H}}=X_{1}^{\mathcal{G}}
). Then we have that
X_{3}^{\mathcal{H}}=X_{2}^{\mathcal{G}}
by Eq.
9
. It follows that by repeated application of the global update for
\mathcal{G}
for
n=1,2,3,\ldots
, the evolution for
\mathcal{H}
will have
1,3,5,7,\ldots=2n-1
and
X_{2n-1}^{\mathcal{H}}=X_{n}^{\mathcal{G}}
. Intuitively, running
\mathcal{G}
for a single generation provides the same output configuration as running
\mathcal{H}
for two generations (Fig.
1
).

To store
g
in memory, one can use a brute-force computation on

using Eq.
7

2^{2r+1}
possible outputs for a
2

2r+1
cells. Each evaluation of

is a constant-time lookup. Therefore, the complexity is
\sim r\times 2^{2(2r+1)}\sim O(r2^{2(2r)}
).

We define a new terminology to describe CA that are of a similar type:

Definition 3
.

Given a CA
\mathcal{H}
with local rule
h
and a CA
\mathcal{F}
with local rule
f
, let
h_{i}=h
for each
1\leq i
. We say that
\mathcal{F}
is a
k
-fold composition of
\mathcal{H}
if
f=h_{1}\circ h_{2}\circ\dots\circ h_{k-1}\circ h_{k}
. Equivalently, we write
f=h^{(k)}
.

It follows by the conclusion of Lemma
2
that
\mathcal{G}
is a
2
-fold composition of
\mathcal{H}
. It is obvious self-composition is associative because the composing functions are identical by definition.

Lemma 4
.

Given a CA
\mathcal{F}
that is a
k
-fold composition of
\mathcal{H}
, if
X_{1}^{\mathcal{F}}=X_{1}^{\mathcal{H}}
then
X_{kn-1}^{\mathcal{H}}=X_{n}^{\mathcal{F}}
. The composite local rule
f
has radius
kr
and is computable with a naive algorithm in
O\big(k^{2}2^{2rk}\big)
operations on a machine with random-access memory.

Proof.

The
k
-fold composition of
h
is

\displaystyle h^{(k)}(X):\big\{\Sigma^{2(kr)+1}\rightarrow\Sigma:X\;\mapsto\;h\big(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{\alpha_{1}=-r}^{r}h(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{\alpha_{2}=-r}^{r}\ldots\;h(\mathop{\mathchoice{\textstyle\bigoplus}{\textstyle\bigoplus}{\scriptstyle\bigoplus}{\scriptscriptstyle\bigoplus}}_{\alpha_{k}=-r}^{r}x_{\alpha_{1}+\alpha_{2}+\ldots+\alpha_{k}})\big)\big\}

(10)

The proof is given by induction on repeated application of Lemma
2
. Instead of two updates (
k=2
), there are
k
configuration updates per input configuration corresponding to the number of nested applications of
h
by Eq.
10
. This adds a factor of
k
to the time-complexity, and so multiplying by the result from Lemma
2
gives
k\times kr\times 2^{2(kr)+1}\sim O\big(rk^{2}2^{2kr}\big)
. Observe that the concatenation operations run to
r
in the above equation and that
r
is a constant. Indeed, it is the scaling with
k
that is trying to be resolved, so
r
solely changes the base of the exponent and we obtain
O\big(k^{2}2^{2kr}\big)
run-time complexity. ∎

Example.
We illustrate the time-complexity of the above lemma with a concrete example for
r=1
,
k=3
and
h
as Rule
30
. This is a
3
-fold composition of Rule 30. Since we have
2(kr)+1=7
, there are
2^{7}
possible input configurations. Let
X=\langle\square,\square,\blacksquare,\blacksquare,\square,\blacksquare,\square\rangle\in\Sigma^{7}
. Applying the rule
h
once to
X
in accordance with Definition
1
gives
\langle\blacksquare,\blacksquare,\square,\square,\blacksquare\rangle
. Applying
h
twice more gives
\langle\square,\blacksquare,\blacksquare\rangle
and then
\blacksquare
. So
h^{(3)}(X)=\blacksquare
. Clearly, there is a
O(k^{2})
array of cells which have been updated and this must be repeated for each of the
2^{2kr+1}-1
other possible inputs.

In Lemma
4
, radius
r
is kept in the asymptotic run-time complexity for further analysis. We will show independence of
r
and complete our main result:

Theorem 5
.

Let
\mathcal{H}
be a CA with an arbitrary initial configuration, a local rule
h
, and radius
r
. The configuration
X_{n}^{\mathcal{H}}
can be computed in
O(n^{2}/\log n)
-time using a machine with random-access memory.

Proof.

By Lemma
4
, we require
O(k^{2}2^{2kr})
-time to perform
k
-fold composition of a rule
h
with radius
r
. From a simple geometric argument it follows that the
k
-fold composition
h^{(k)}
reduces the time-complexity from
O(n^{2})
to
O(n^{2}/k)
: for each row that is computed,
k
are skipped relative to the original rule. Then there exists an optimal maximum
k
such that the time-complexity to run the simulation from the initial configuration to
n
and compose the rule is equivalent:

\frac{n^{2}}{k}=c\;k^{2}2^{2kr}

(11)

where
c
is an arbitrary constant. It is assumed that
n,k
are much larger than
r
. If the time-complexities are equal, the total complexity is the complexity of either operation multiplied by a constant factor. The solution to this equation is the Lambert
W
function (also called the “product logarithm”)

k(n)=\frac{3}{2r\ln(2)}W_{0}\bigg(\frac{2\ln(2)}{3c^{1/3}}rn^{2/3}\bigg)\sim\frac{1}{r}\log_{2}n

(12)

by using
W_{0}(n)\sim\ln n
for large
n
and simplifying. The prefactor in front of
\log_{2}n
is exactly
1/r
and is important for determining the proper memory scaling. The prefactor
k^{2}
in
k^{2}2^{2kr}
can be any finite polynomial in
k
and not change the asymptotic behavior, as it is dominated by the exponential function.
∎

Corollary 6
.

The configuration
X_{n}^{\mathcal{H}}
satisfying the conclusion of Theorem
5
can be computed using
O(n^{2})
-space.

Proof.

Storing
2^{2kr+1}
outputs where
k=\frac{1}{r}\log_{2}n
gives
O(n^{2})
.
∎

Experimental Results

In this section, we present experimental results of the method described in Theorem
5
, managing to remove a
\log
factor from the base run-time complexity of trivially running an ECA. The results are presented in Fig.
2
and the code is given in the Appendix. Its practicality on the general-purpose computer is limited by two things: 1. Memory access is not sequential and so is not cache-friendly 2. RAM is limited. This problem could be reduced if contiguous memory was indexed in a de Bruijn sequence
[
Wei
]
of order
2r+1
on the alphabet
\Sigma
. This is because, given a rule input
\langle\blacksquare,\square,\blacksquare\rangle
, the adjacent one in the configuration is either
\langle\square,\blacksquare,\blacksquare\rangle
or
\langle\square,\blacksquare,\square\rangle
which is a bit-shift left and rewriting of the right-most bit (flipped depending on the endianness). If the index in memory is
q
, then the next transition will map to memory location
\lfloor q/2\rfloor
or
\lfloor q/2\rfloor+2^{2r}
which may be a large jump. For 2-color cellular automata with an equal probability of being black or white, there would be an equal chance that the next state would be in the neighboring memory address if the memory was instead laid out in a de Bruijn sequence. The corresponding data structure is the de Bruijn graph, which is used for DNA sequence assembly, and so optimization and compression of these graphs is an active area of research
[
MBN+17
]
. In the context of cellular automata, we use the definition provided in
[
Wol84
]
(see Fig. 2.1) and show de Bruijn graphs of compositions of Rule 30 in Fig.
3
. Custom machines based on these graphs would also address the aforementioned memory problems, as described in the Appendix.

5.1
Notes on formal machines

At the risk of running into the issues described in
[
Knu73
]
, we investigate theoretical machines for algorithm implementation. A surmountable problem for implementing this algorithm on one multi-tape Turing machine is that it is composed of two disparate operations; the generation of the
k
-fold rule and evolution of the initial configuration using this rule. Thus there can be tapes which signal to begin transition from former to the latter, and also signal completion of the
n
-th generation of the CA. The
O(1)
access the output of the
k
-fold rule is solved by noting that for a multi-tape machine, every tape has access to every other tape as well as the index of that tape at every step. Then
2^{2r+1}
tapes to store the output of the rule for every local configuration for a CA with radius
r
can effectively emulate constant-time access to memory.

Another possible instantiation of the algorithm is by the extension of the finite-state machines for cellular automata described in detail in
[
Wol84
]
to finite-state transducers such as Moore or Mealy machines. These transitions of a given CA as it rasters a space-time diagram can be modeled by de Bruijn graphs. Following the definition provided by
[
Wol84
]
(Fig. 2.1), updating a configuration is equivalent to taking a path along this graph according to an input configuration, and the output (encoded by the colors red or green in Fig.
3
) is written to a tape as the successor configuration. These machines would then be “hard-wired” such that a state transition would take constant time.
