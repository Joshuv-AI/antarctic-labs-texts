To recall a notion of approximate Jensen convexity (introduced in the paper
[
22
]
), given a convex set
D\subseteq X
, we define the difference set
D_{\Delta}
by
D_{\Delta}:=\{x-y:x,y\in D\}
. Then
D_{\Delta}
is also a convex set which is symmetric with respect to the origin, i.e., it satisfies
D_{\Delta}=-D_{\Delta}
and hence it contains the origin of
X
. Let
\varphi:\frac{1}{2}D_{\Delta}\to\mathbb{R}
be a given function, which we will refer to as an
error function
. We say that a function
f:D\to\mathbb{R}
is
\varphi
-Jensen convex on
D
(or
\varphi
-midconvex on
D
) if

(3)

\displaystyle f\Big(\frac{x+y}{2}\Big)\leq\frac{1}{2}f(x)+\frac{1}{2}f(y)+\varphi\Big(\frac{x-y}{2}\Big)\qquad(x,y\in D).

Interchanging the variables
x
and
y
in (
3
), we get

\displaystyle f\Big(\frac{x+y}{2}\Big)\leq\frac{1}{2}f(x)+\frac{1}{2}f(y)+\varphi\Big(\frac{y-x}{2}\Big)\qquad(x,y\in D),

Combining this inequality with (
3
), it follows that

\displaystyle f\Big(\frac{x+y}{2}\Big)\leq\frac{1}{2}f(x)+\frac{1}{2}f(y)+\min\Big(\varphi\Big(\frac{x-y}{2}\Big),\varphi\Big(\frac{y-x}{2}\Big)\Big)\qquad(x,y\in D).

Therefore, we may assume that
\varphi
is an even function, i.e., for all
u\in\frac{1}{2}D_{\Delta}
, we have
\varphi(u)=\varphi(-u)
. If
x=y
, then (
3
) is equivalent to the inequality
0\leq\varphi(0)
, thus we may also assume that
\varphi(0)=0
.

If
\varphi
is nonnegative, then we usually speak about the
approximate convexity of
f
. On the other hand, if
\varphi
is nonpositive, then the inequality (
3
) implies the standard Jensen convexity of
f
, therefore, in this case we may speak about
strong Jensen convexity of
f
. A tipical choice in the setting of strong convexity is when
\varphi(u)=-\varepsilon\|u\|^{2}
for some positive
\varepsilon
and
X
is an inner product space.

In the case when
\varphi
is nonnegative, the zero function
f=0
is always
\varphi
-Jensen convex on
D
. However, if
\varphi
can take negative values, then there may not exist a
\varphi
-Jensen convex function over
D
. Motivated by this, an even function
\varphi:\frac{1}{2}D_{\Delta}\to\mathbb{R}
which satisfies
\varphi(0)=0
and for which there exists at least one
\varphi
-Jensen convex function over
D
will be called an
admissible error function
. In what follows, let
\mathscr{A}(D_{\Delta})
denote the family of all admissible error functions
\varphi:\frac{1}{2}D_{\Delta}\to\mathbb{R}
.

The basic problem related to a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
is to deduce its further approximate convexity properties. More precisely, for a given
\varphi\in\mathscr{A}(D_{\Delta})
, we search for an
extended error function

\Phi:[0,1]\times D_{\Delta}\to(-\infty,\infty]
such that the inequality

(4)

\displaystyle f(\lambda x+(1-\lambda)y)\leq\lambda f(x)+(1-\lambda)f(y)+\Phi(\lambda,x-y)\qquad(\lambda\in[0,1],\,x,y\in D).

be valid for all
\varphi
-Jensen convex functions
f:D\to\mathbb{R}
.
If this inequality holds, then we say that
f
is a
\Phi
-convex function on
D
. Clearly, the extended error function
\Phi:[0,1]\times D_{\Delta}\to(-\infty,\infty]
defined by

\displaystyle\Phi(\lambda,u):=\begin{cases}\varphi\big(\tfrac{1}{2}u\big)&\mbox{if }\lambda=\tfrac{1}{2}\mbox{ and }u\in D_{\Delta},\\[5.69054pt]
0&\mbox{if }\lambda\in\{0,1\}\mbox{ and }u\in D_{\Delta}\mbox{ or }\lambda\in[0,1]\mbox{ and }u=0,\\[5.69054pt]
\infty&\mbox{otherwise}\end{cases}

is a trivial solution to this problem, because then (
4
) is equivalent to (
3
). It is not obvious if there is an extended error function satisfying (
4
) which is finite for
\lambda\in\big\{\tfrac{1}{3},\tfrac{2}{3}\big\}
. To see that this is possible, let
x,y\in D
be fixed. Now observe that
\tfrac{2x+y}{3}
is the midpoint of the segment
\big[x,\frac{x+2y}{3}\big]
and
\tfrac{x+2y}{3}
is the midpoint of the segment
\big[\frac{2x+y}{3},y\big]
. Therefore, applying (
3
) twice in these settings, we can get that

\displaystyle f\Big(\frac{2x+y}{3}\Big)

\displaystyle\leq\frac{1}{2}f(x)+\frac{1}{2}f\Big(\frac{x+2y}{3}\Big)+\varphi\Big(\frac{x-y}{3}\Big),

\displaystyle f\Big(\frac{x+2y}{3}\Big)

\displaystyle\leq\frac{1}{2}f\Big(\frac{2x+y}{3}\Big)+\frac{1}{2}f(y)+\varphi\Big(\frac{x-y}{3}\Big).

Using the second inequality, the first inequality yields that

\displaystyle f\Big(\frac{2x+y}{3}\Big)

\displaystyle\leq\frac{1}{2}f(x)+\frac{1}{2}\bigg(\frac{1}{2}f\Big(\frac{2x+y}{3}\Big)+\frac{1}{2}f(y)+\varphi\Big(\frac{x-y}{3}\Big)\bigg)+\varphi\Big(\frac{x-y}{3}\Big).

After simplifications, we get

\displaystyle f\Big(\frac{2x+y}{3}\Big)

\displaystyle\leq\frac{2}{3}f(x)+\frac{1}{3}f(y)+2\varphi\Big(\frac{x-y}{3}\Big).

In a similar manner, we can also obtain that

\displaystyle f\Big(\frac{x+2y}{3}\Big)

\displaystyle\leq\frac{1}{3}f(x)+\frac{2}{3}f(y)+2\varphi\Big(\frac{x-y}{3}\Big).

Thus, we have proved that (
4
) holds with
the extended error function
\Phi:[0,1]\times D_{\Delta}\to(-\infty,\infty]
defined by

\displaystyle\Phi(\lambda,u):=\begin{cases}\varphi\big(\tfrac{1}{2}u\big)&\mbox{if }\lambda=\tfrac{1}{2}\mbox{ and }u\in D_{\Delta},\\[5.69054pt]
2\varphi\big(\tfrac{1}{3}u\big)&\mbox{if }\lambda\in\big\{\tfrac{1}{3},\tfrac{2}{3}\big\}\mbox{ and }u\in D_{\Delta},\\[5.69054pt]
0&\mbox{if }\lambda\in\{0,1\}\mbox{ and }u\in D_{\Delta}\mbox{ or }\lambda\in[0,1]\mbox{ and }u=0,\\[5.69054pt]
\infty&\mbox{otherwise}.\end{cases}

In the context of
\varphi
-Jensen convexity, under regularity assumptions that are similar to those in the theorem of Bernstein and Doetsch, the following result was established in
[
22
]
.

Theorem 1.4
.

Let
X
be a topological linear space and let
D\subseteq X
be a nonempty open and convex set. Let
f:D\to\mathbb{R}
be locally bounded from above at a point of
D
and let
\varphi:\tfrac{1}{2}D_{\Delta}\to\mathbb{R}_{+}
be nondecreasing. Then
f
is
\varphi
-Jensen convex on
D
if and only if, for all
\lambda\in[0,1]
and
x,y\in D
,

\displaystyle f(\lambda x+(1-\lambda)y)\leq\lambda f(x)+(1-\lambda)f(y)+\sum_{n=0}^{\infty}\frac{1}{2^{n}}\varphi\big(d_{\mathbb{Z}}(2^{n}\lambda)(x-y)\big),

where the function
d_{\mathbb{Z}}:\mathbb{R}\to\mathbb{R}
is defined by

(5)

\displaystyle d_{\mathbb{Z}}(x):=\dist(x,\mathbb{Z}):=\inf\{|x-k|\mid k\in\mathbb{Z}\}\qquad(x\in\mathbb{R}).

The basic question concerning the above result is that what happens if we drop the local upper boundedness assumption on
f
and also the monotonicity property of
\varphi
. These questions will be addressed in Section 3 of this paper. In Section 2, we collect some material which will be instrumental for establishing our results.

Auxiliary results

Motivated by Theorem
1.4
, we first establish some properties of the function
d_{\mathbb{Z}}
defined by (
5
) and of the map
\boldsymbol{\langle}\cdot\boldsymbol{\rangle}:\mathbb{Q}\to\mathbb{N}
given by

\displaystyle\boldsymbol{\langle}\lambda\boldsymbol{\rangle}:=\min\{m\in\mathbb{N}\mid m\lambda\in\mathbb{Z}\}.

Observe that, for all
n\in\mathbb{Z}
,
x\in\mathbb{R}
, and
\lambda\in\mathbb{Q}
the following obvious properties hold:

\displaystyle d_{\mathbb{Z}}(n\pm x)=d_{\mathbb{Z}}(x),\qquad\boldsymbol{\langle}n\pm\lambda\boldsymbol{\rangle}=\boldsymbol{\langle}\lambda\boldsymbol{\rangle}\qquad\mbox{and}\qquad\boldsymbol{\langle}n\lambda\boldsymbol{\rangle}\leq\boldsymbol{\langle}\lambda\boldsymbol{\rangle}.

For the function
d_{\mathbb{Z}}
, we have the following
easy-to-see properties

(6)

\displaystyle 0\leq d_{\mathbb{Z}}(x)\leq\tfrac{1}{2}\quad(x\in\mathbb{R}),\qquad d_{\mathbb{Z}}(x)=\min(x,1-x)\quad(x\in[0,1]).

The next lemma establishes a “recursive” formula for
d_{\mathbb{Z}}
.

Lemma 2.1
.

For all
x\in\mathbb{R}
,

(7)

\displaystyle d_{\mathbb{Z}}(2x)=d_{\mathbb{Z}}(2d_{\mathbb{Z}}(x))=\min\big(2d_{\mathbb{Z}}(x),1-2d_{\mathbb{Z}}(x)\big)=\begin{cases}2d_{\mathbb{Z}}(x)&\mbox{if }d_{\mathbb{Z}}(x)\leq\frac{1}{4},\\[5.69054pt]
1-2d_{\mathbb{Z}}(x)&\mbox{if }d_{\mathbb{Z}}(x)>\frac{1}{4}.\end{cases}

Furthermore, for all
k\in\mathbb{N}
and
x\in\mathbb{R}
,

(8)

\displaystyle d_{\mathbb{Z}}(2^{k}x)=\big(d_{\mathbb{Z}}\circ(2d_{\mathbb{Z}})^{k}\big)(x).

Proof.

We need to show the first equality in (
7
), the remaining two equalities easily follow from (
6
). Let
x\in\mathbb{R}
be fixed. To prove the first equality in (
7
), we have to distinguish two cases.

If
d_{\mathbb{Z}}(x)\leq\frac{1}{4}
, then there exists an
n\in\mathbb{N}
such that
n-\frac{1}{4}\leq x\leq n+\frac{1}{4}
. This implies that
2n-\frac{1}{2}\leq 2x\leq 2n+\frac{1}{2}
, therefore

\displaystyle d_{\mathbb{Z}}(2x)=|2x-2n|=2|x-n|=2d_{\mathbb{Z}}(x).

If
d_{\mathbb{Z}}(x)>\frac{1}{4}
, then there exists an
n\in\mathbb{N}
such that
n+\frac{1}{4}<x<n+\frac{3}{4}
. Therefore, we have that
(2n+1)-\frac{1}{2}<2x<(2n+1)+\frac{1}{2}
. Consequently,

\displaystyle d_{\mathbb{Z}}(2x)=|2x-(2n+1)|=1-2\big(\tfrac{1}{2}-|n+\tfrac{1}{2}-x|\big)=1-2d_{\mathbb{Z}}(x).

The equality (
8
) can be obtained by induction with respect to
k
. The equality holds for
k=1
according to the first part of this lemma. If it holds for some
k
, then applying (
7
) first and then the inductive hypothesis, we get

\displaystyle d_{\mathbb{Z}}(2^{k+1}x)

\displaystyle=d_{\mathbb{Z}}(2\cdot 2^{k}x)=d_{\mathbb{Z}}\big(2d_{\mathbb{Z}}(2^{k}x)\big)

\displaystyle=d_{\mathbb{Z}}\big(2\big(d_{\mathbb{Z}}\circ(2d_{\mathbb{Z}})^{k}\big)(x)\big)=d_{\mathbb{Z}}\big((2d_{\mathbb{Z}})^{k+1}(x)\big)=\big(d_{\mathbb{Z}}\circ(2d_{\mathbb{Z}})^{k+1}\big)(x).

This completes the proof of the lemma.
∎

The following result and its subsequent corollary will play an important role in the comparison of the various upper bounds obtained for approximate convexity with rational convex combinations.

Lemma 2.2
.

Let
\psi:\big[0,\frac{1}{2}\big]\to\mathbb{R}
be bounded [continuous] and define the function
T_{\psi}:[0,1]\to\mathbb{R}
by

(9)

\displaystyle T_{\psi}(\lambda):=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k}\lambda)\big).

Then
f=T_{\psi}
is the unique bounded [continuous] solution of the functional equation

(10)

\displaystyle f(\lambda)=\begin{cases}\frac{1}{2}f(2\lambda)+\psi(\lambda)&\mbox{if }\lambda\in\big[0,\frac{1}{2}\big],\\[8.53581pt]
\frac{1}{2}f(2\lambda-1)+\psi(1-\lambda)&\mbox{if }\lambda\in\big(\frac{1}{2},1\big]\end{cases}

also satisfying the condition
f(0)=f(1)
.

Proof.

The sequence of functions
\lambda\mapsto\psi\big(d_{\mathbb{Z}}(2^{k}\lambda)\big)
is [continuous] and is uniformly bounded by
\|\psi\|_{\infty}
(over
\big[0,\frac{1}{2}\big]
). Therefore, the series on the right hand side of (
9
) is majored by the numerical series
\sum_{k=0}^{\infty}\frac{1}{2^{k}}\|\psi\|_{\infty}=2\|\psi\|_{\infty}<\infty
. This yields that the series is uniformly convergent, whence it follows that the sum of the series is a bounded [continuous] function, i.e.,
T_{\psi}
is bounded [continuous]. Furthermore, we also have that

\displaystyle T_{\psi}(0)=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k}\cdot 0)\big)=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(0\big)=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k}\cdot 1)\big)=T_{\psi}(1).

If
\lambda\in\big[0,\frac{1}{2}\big]
, then

\displaystyle T_{\psi}(2\lambda)=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k+1}\lambda)\big)=2\sum_{k=1}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k}\lambda\big)\big)=2\big(T_{\psi}(\lambda)-\psi(\lambda)\big),

while, for
\lambda\in\big(\frac{1}{2},1\big]
,

\displaystyle T_{\psi}(2\lambda-1)

\displaystyle=\sum_{k=0}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k+1}\lambda-2^{k})\big)

\displaystyle=2\sum_{k=1}^{\infty}\frac{1}{2^{k}}\psi\big(d_{\mathbb{Z}}(2^{k}\lambda)\big)=2\big(T_{p}(\lambda)-\psi(1-\lambda)\big).

These two equalities show that the function
f=T_{\psi}
satisfies the functional equation (
10
).

We now show that
f=T_{\psi}
is the unique solution of the functional equation (
10
) satisfying also the condition
f(0)=f(1)
.

Let
\mathscr{B}\big([0,1],\mathbb{R}\big)
and

\mathscr{C}\big([0,1],\mathbb{R}\big)
denote normed spaces of bounded and continuous real valued functions defined on the interval
[0,1]
(equipped with the supremum norm), respectively. Then these spaces are Banach spaces, furthermore, the functions belonging to theses spaces and satisfying the condition
f(0)=f(1)
form closed subspaces, which we will denote by
\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
and

\mathscr{C}_{0}\big([0,1],\mathbb{R}\big)
, respectively.

We point out that the right hand side of the functional equation (
10
) defines a contraction on these Banach subspaces. To see this, for a bounded [continuous] function
f:[0,1]\to\mathbb{R}
, define the transformed function
\mathscr{T}_{\psi}(f):[0,1]\to\mathbb{R}
by

\displaystyle\mathscr{T}_{\psi}(f)(\lambda)=\begin{cases}\frac{1}{2}f(2\lambda)+\psi(\lambda)&\mbox{if }\lambda\in\big[0,\frac{1}{2}\big],\\[8.53581pt]
\frac{1}{2}f(2\lambda-1)+\psi(1-\lambda)&\mbox{if }\lambda\in\big(\frac{1}{2},1\big].\end{cases}

It is easy to see that if
\psi
is bounded [continous], then
\mathscr{T}_{\psi}
maps the space
\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
[resp.
\mathscr{C}_{0}\big([0,1],\mathbb{R}\big)
] into itself. Indeed, if
f(0)=f(1)
, then

\displaystyle\mathscr{T}_{\psi}(f)(0)=\frac{1}{2}f(0)+\psi(0)=\frac{1}{2}f(1)+\psi(0)=\mathscr{T}_{\psi}(f)(1).

If
\psi
and
f
are bounded, then
\mathscr{T}_{\psi}(f)
is also bounded by
\frac{1}{2}\|f\|_{\infty}+\|\psi\|_{\infty}
, which shows that
\mathscr{T}_{\psi}(f)
maps the subspace
\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
into itself.

If
\psi
and
f
are continuous, then the continuoity of
\mathscr{T}_{\psi}(f)
on
\big[0,\frac{1}{2}\big)\cup\big(\frac{1}{2},1\big]
is obvious. It remains to check the continuity at
\lambda=\frac{1}{2}
.

\displaystyle\lim_{\lambda\to\frac{1}{2}-}

\displaystyle\mathscr{T}_{\psi}(f)(\lambda)=\lim_{\lambda\to\frac{1}{2}-}\Big(\tfrac{1}{2}f(2\lambda)+\psi(\lambda)\Big)=\tfrac{1}{2}f(1)+\psi\big(\tfrac{1}{2}\big)

\displaystyle=\tfrac{1}{2}f(0)+\psi\big(\tfrac{1}{2}\big)=\lim_{\lambda\to\frac{1}{2}+}\Big(\tfrac{1}{2}f(2\lambda-1)+\psi(1-\lambda)\Big)=\lim_{\lambda\to\frac{1}{2}+}\mathscr{T}_{\psi}(f)(\lambda).

Finally, we show that
\mathscr{T}_{\psi}
is a contraction with contraction factor
q=\frac{1}{2}
.
To see this, let
f,g\in\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
.
Then, for
\lambda\in\big[0,\frac{1}{2}\big]
,

\displaystyle\big|\mathscr{T}_{\psi}(f)(\lambda)-\mathscr{T}_{\psi}(g)(\lambda)\big|=\big|\tfrac{1}{2}f(2\lambda)-\tfrac{1}{2}g(2\lambda)\big|\leq\tfrac{1}{2}\|f-g\|_{\infty},

while, for
\lambda\in\big(\frac{1}{2},1\big]
,

\displaystyle\big|\mathscr{T}_{\psi}(f)(\lambda)-\mathscr{T}_{\psi}(g)(\lambda)\big|=\big|\tfrac{1}{2}f(2\lambda-1)-\tfrac{1}{2}g(2\lambda-1)\big|\leq\tfrac{1}{2}\|f-g\|_{\infty}.

These two inequalities yield that

\displaystyle\big\|\mathscr{T}_{\psi}(f)-\mathscr{T}_{\psi}(g)\big\|_{\infty}\leq\tfrac{1}{2}\|f-g\|_{\infty},

which shows that
\mathscr{T}_{\psi}
is a
\frac{1}{2}
-contraction on
\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
, indeed.

It is obvious that
f:[0,1]\to\mathbb{R}
is a solution of the functional equation (
10
) if and only if
f
is a fixed point of
\mathscr{T}_{\psi}
. According to the Banach Fixed Point Theorem,
\mathscr{T}_{\psi}
has a unique fixed point, and this completes the proof of the unique solvability of the functional equation (
10
) in the subspaces
\mathscr{B}_{0}\big([0,1],\mathbb{R}\big)
[and
\mathscr{C}_{0}\big([0,1],\mathbb{R}\big)
].
∎

The function
T_{\psi}
defined in (
9
) is called the
Takagi-type function related to
\psi
. In the particular case when
\psi(x)=x
it is the classical continuous but nowhere differentiable function introduced by Takagi
[
41
]
. In what follows, we compute
T_{\psi}
for the case when
\psi(x)=x^{2}
. We note that this is the only power function for which
T_{\psi}
is smooth on
\mathbb{R}\setminus\mathbb{Z}
.

Corollary 2.3
.

For all
\lambda\in[0,1]
,

(11)

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}d_{\mathbb{Z}}(2^{k}\lambda)^{2}=\lambda(1-\lambda).

Proof.

We apply the Lemma
2.2
for the function
\psi(t):=t^{2}
(
t\in\big[0,\frac{1}{2}\big]
). According to this lemma,
f=T_{\psi}
is the unique solution continous of the functional equation

(12)

\displaystyle f(\lambda)=\begin{cases}\frac{1}{2}f(2\lambda)+\lambda^{2}&\mbox{if }\lambda\in\big[0,\frac{1}{2}\big],\\[8.53581pt]
\frac{1}{2}f(2\lambda-1)+(1-\lambda)^{2}&\mbox{if }\lambda\in\big(\frac{1}{2},1\big],\end{cases}

which also satisfies
f(0)=f(1)
. To verify the equality (
11
), it is sufficient to show that the function
f(\lambda)=\lambda(1-\lambda)
is also a solution to (
12
).

If
\lambda\in\big[0,\frac{1}{2}\big]
, then

\displaystyle f(\lambda)=\lambda(1-\lambda)=\tfrac{1}{2}(2\lambda)(1-2\lambda)+\lambda^{2}=\tfrac{1}{2}f(2\lambda)+\lambda^{2},

while, for
\lambda\in\big(\frac{1}{2},1\big]
,

\displaystyle f(\lambda)=\lambda(1-\lambda)=\frac{1}{2}(2\lambda-1)(1-(2\lambda-1))+(1-\lambda)^{2}=\frac{1}{2}f(2\lambda-1)+(1-\lambda)^{2}.

These two identities show that the function
f(\lambda)=\lambda(1-\lambda)
also satisfies the functional equation (
12
). By the unique solvability of (
12
), it follows that the equality (
11
) holds for all
\lambda\in[0,1]
.
∎

In what follows, let the symbol
\phi
denote Euler’s totient function. Recall that, according to Euler’s celebrated result,

n\mid(a^{\phi(n)}-1)
if
n
and
a
are coprime natural numbers. The next statement sharpens Euler’s theorem in some particular cases. The authors are grateful to Professor Lajos Hajdu for providing some ideas for its proof.

Lemma 2.4
.

Let
a,n\in\mathbb{N}
be coprime numbers such that
n\geq 3
is an odd number, and let
\ell:=\frac{1}{2}\phi(n)
. Then either
n\mid(a^{\ell}-1)
or
n\mid(a^{\ell}+1)
.

Proof.

We note that the assumption
n\geq 3
yields that
\phi(n)
is even, i.e.,
\ell
is an integer.

Assume first that
n
is a prime power, say
n=p^{k}
, where
p
is an odd prime and
k>1
is an integer. According to Euler’s Theorem,
n\mid(a^{\phi(n)}-1)
, i.e.,
n\mid(a^{\ell}-1)(a^{\ell}+1)
. The greatest common divisor of the numbers
(a^{\ell}-1)
and
(a^{\ell}+1)
is
2
if both of them are even, otherwise they are coprime because their difference is divisible by
2
.

Since
p
is an odd prime, then
p
cannot divide both of
(a^{\ell}-1)
and
(a^{\ell}+1)
, therefore
n=p^{k}
must be a divisor either of
(a^{\ell}-1)
or of
(a^{\ell}+1)
.

Assume now that
n
is not a power of a prime number. Then
n
is of the form
n=km
, where
k,m\geq 3
and
k,m
are coprime odd numbers which are also coprime to
a
. To complete the proof of the lemma, we show that
k
and
m
are divisors of
(a^{\ell}-1)
. By the multiplicativity of Euler’s totient function, we have that
\phi(n)=\phi(k)\phi(m)
.
Therefore,
\ell=\phi(k)\cdot\frac{\phi(m)}{2}=\phi(m)\cdot\frac{\phi(k)}{2}
. Thus,
\phi(k)
and
\phi(m)
are divisors of
\ell
. This implies that
a^{\phi(k)}-1
and
a^{\phi(m)}-1
are divisors of
a^{\ell}-1
. On the other hand, acording to Euler’s theorem,
k\mid(a^{\phi(k)}-1)
and
m\mid(a^{\phi(m)}-1)
, which then yields that
k,m\mid(a^{\ell}-1)
.
Using that
k
and
m
are coprime numbers, we can conclude that
n=km\mid(a^{\ell}-1)
.
∎

The role of the function
\mu_{n}
introduced in the following lemma will be clarified in Proposition
2.6
below.

Lemma 2.5
.

Let
n\geq 3
be an odd integer and let
M_{n}
denote the set of those integers
m\in\big\{1,\dots,\frac{n-1}{2}\big\}
that are coprime to
n
. Define the mapping
\mu_{n}:M_{n}\to\mathbb{Z}
defined by

\displaystyle\mu_{n}(m):=\min(2m,n-2m).

Then
\mu_{n}
is a bijection of the set
M_{n}
, furthermore, for all
m\in M_{n}
and
k\in\mathbb{N}
,

(13)

\displaystyle\{\mu_{n}^{k}(m)\}=\Big(\big\{2^{k}m-in\mid i\in\{0,\dots,2^{k-1}-1\}\big\}\cup\big\{in-2^{k}m\mid i\in\{1,\dots,2^{k-1}\}\big\}\Big)\cap M_{n},

and the equality
m=\mu_{n}^{\ell}(m)
holds for all
m\in M_{n}
, where
\ell:=\frac{1}{2}\phi(n)
.

Proof.

If
m\in M_{n}
, then
m
is coprime to
n
, therefore
2m
and
n-2m
are also coprimes to
n
. On the other hand, the inequalities
1\leq m\leq\frac{n-1}{2}
imply that
1\leq\min(2m,n-2m)=\mu_{n}(m)
and
\mu_{n}(m)=\min(2m,n-2m)<\frac{2m+(n-2m)}{2}=\frac{n}{2}
and hence
\mu_{n}(m)\leq\frac{n-1}{2}
. Thus, we have proved that
\mu_{n}(m)\in M_{n}
. To see that
\mu_{n}
is injective, assume that, for some
m,m^{\prime}\in M_{n}
, we have that
\mu_{n}(m)=\mu_{n}(m^{\prime})
, i.e.,
\min(2m,n-2m)=\min(2m^{\prime},n-2m^{\prime})
. This equality implies that one of the following equalities must be valid:

\displaystyle 2m=2m^{\prime},\qquad 2m=n-2m^{\prime},\qquad n-2m=2m^{\prime},\qquad n-2m=n-2m^{\prime}.

The second and third equalities contradict the oddness of
n
. Therefore, either the first or the last equality must hold, which imply that
m=m^{\prime}
. This shows that
\mu_{n}
is injective.

To prove the equality (
13
), we first verify by induction on
k
that

(14)

\displaystyle\mu_{n}^{k}(m)\in\big\{2^{k}m-in\mid i\in\{0,\dots,2^{k-1}-1\}\big\}\cup\big\{in-2^{k}m\mid i\in\{1,\dots,2^{k-1}\}\big\}.

For
k=1
, we have

\displaystyle\mu_{n}(m)=\min(2m,n-2m)\in\{2m,n-2m\}=\{2m-0\cdot n\}\cup\{1\cdot n-2m\},

which is the inclusion (
14
) in the particular case
k=1
.

Assume that (
14
) is valid for some
k\in\mathbb{N}
. Then

\displaystyle\mu_{n}^{k+1}(m)=\mu_{n}\big(\mu_{n}^{k}(m)\big)=\min\big(2\mu_{n}^{k}(m),n-2\mu_{n}^{k}(m)\big)\in\big\{2\mu_{n}^{k}(m),n-2\mu_{n}^{k}(m)\big\}

\displaystyle\subseteq\big\{2^{k+1}m-2in\mid i\in\{0,\dots,2^{k-1}-1\}\big\}\cup\big\{2in-2^{k+1}m\mid i\in\{1,\dots,2^{k-1}\}\big\}

\displaystyle\cup\big\{(2i+1)n-2^{k+1}m\mid i\in\{0,\dots,2^{k-1}-1\}\big\}\cup\big\{2^{k+1}m-(2i-1)n\mid i\in\{1,\dots,2^{k-1}\}\big\}

\displaystyle=\big\{2^{k+1}m-in\mid i\in\{0,\dots,2^{k}-1\}\big\}\cup\big\{in-2^{k+1}m\mid i\in\{1,\dots,2^{k}\}\big\},

which proves the assertion for
k+1
.

Since,
\mu_{n}
maps
M_{n}
into itself, we have that
\mu_{n}^{k}(m)\in M_{n}
for all
k\in\mathbb{N}
and
m\in M_{n}
, whence it follows that

\displaystyle\{\mu_{n}^{k}(m)\}\subseteq\Big(\big\{2^{k}m-in\mid i\in\{0,\dots,2^{k-1}-1\}\big\}\cup\big\{in-2^{k}m\mid i\in\{1,\dots,2^{k-1}\}\big\}\Big)\cap M_{n}.

To show that here the equality holds, it suffices to prove that the set on the right hand side of this inclusion is a singleton.
Let
p
be an element of the right hand side of the above inclusion. Then either
p=2^{k}m-in
for some
i\in\{0,\dots,2^{k-1}-1\}
or
p=in-2^{k}m
for some
i\in\{1,\dots,2^{k-1}\}
.
In both cases, due to the oddness of
n
, it follows that
p
and
n
are coprime. Therefore
p
belongs to
M_{n}
if and only if the inequalities
0<p<\frac{n}{2}
holds. In the first, resp. in the second case these inequalities hold if and only if

(15)

\displaystyle 2^{k}\frac{m}{n}-\frac{1}{2}<i<2^{k}\frac{m}{n},\qquad\mbox{resp.}\qquad 2^{k}\frac{m}{n}<i<2^{k}\frac{m}{n}+\frac{1}{2}.

Thus, the number
i
has to be the unique integer in the open interval
\big]2^{k}\frac{m}{n}-\frac{1}{2},2^{k}\frac{m}{n}+\frac{1}{2}\big[
(whose length is equal to 1). In the case when the first inequality is valid in (
15
), then
p
is of the form
p=2^{k}m-in
, in the other case
p=in-2^{k}m
. Thus
p
is uniquely determined and this verifies the equality (
13
).

Observe that (by the definition of the totient function) the cardinality of the set
M_{n}
equals
\ell=\frac{1}{2}\phi(n)
. For every
m\in M_{n}
, we have that
m,\mu_{n}(m),\mu_{n}^{2}(m),\dots,\mu_{n}^{\ell}(m)\in M_{n}
, therefore, according to the pigeonhole principle, there exist
0\leq i<j\leq\ell
such that
\mu_{n}^{i}(m)=\mu_{n}^{j}(m)
. Consequently,
m=\mu_{n}^{j-i}(m)
, i.e.,
m=\mu_{n}^{k}(m)
for some
k\in\{1,\dots,\ell\}
. We may assume that
k
is the smallest such exponent.
Using the inclusion (
13
), it follows that if
m=\mu_{n}^{k}(m)
, then one of the following equalities must hold:

\displaystyle(2^{k}-1)m=in\qquad(i\in\{1,\dots,2^{k-1}-1\}),\qquad(2^{k}+1)m=in\qquad(i\in\{1,\dots,2^{k-1}\}).

Using that
m
is coprime to
n
, it follows that
m\mid i
and either
n\mid(2^{k}-1)
or
n\mid(2^{k}+1)
.

In what follows, we are going to prove that
k\mid\ell
. If this were not be true, then
\ell=dk+r
would hold for some
d,k\in\mathbb{N}
with
0<r<k
. According to Lemma
2.4
, we have that either
n\mid(2^{\ell}-1)
or
n\mid(2^{\ell}+1)
. Thus, we can distinguish the following four cases:

Case I:
n\mid(2^{k}-1)
and
n\mid(2^{\ell}-1)
. Then
n\mid(2^{dk}-1)
. Thus
n\mid(2^{\ell}-2^{dk})=2^{dk}(2^{r}-1)
, hence
n\mid(2^{r}-1)
(because
n
is odd).

Case II:
n\mid(2^{k}-1)
and
n\mid(2^{\ell}+1)
. Then
n\mid(2^{dk}-1)
. Thus
n\mid(2^{\ell}+2^{dk}\big)=2^{dk}(2^{r}+1)
, hence
n\mid(2^{r}+1)
.

Case III:
n\mid(2^{k}+1)
and
n\mid(2^{\ell}-1)
. Then
n\mid(2^{dk}-(-1)^{d})
. Thus
n\mid(2^{\ell}+(-1)^{d}2^{dk})=2^{dk}(2^{r}-(-1)^{d})
, hence
n|(2^{r}+(-1)^{d})
.

Case IV:
n\mid(2^{k}+1)
and
n\mid(2^{\ell}+1)
. Then
n\mid(2^{dk}-(-1)^{d})
. Thus
n\mid(2^{\ell}-(-1)^{d}2^{dk})=2^{dk}(2^{r}+(-1)^{d})
, hence
n\mid(2^{r}-(-1)^{d})
.

These cases show that either
n\mid(2^{r}-1)
or
n\mid(2^{r}+1)
.
This implies that

\displaystyle\frac{m}{n}\in\bigg\{\frac{1}{2^{r}-1},\dots,\frac{2^{r-1}-1}{2^{r}-1}\bigg\}\cup\bigg\{\frac{1}{2^{r}+1},\dots,\frac{2^{r-1}}{2^{r}+1}\bigg\}.

The above inclusion yield that

\displaystyle m\in\Big(\big\{2^{r}m-in\mid i\in\{1,\dots,2^{r-1}-1\}\big\}\cup\big\{in-2^{r}m\mid i\in\{1,\dots,2^{r-1}\}\big\}\Big)\cap M_{n},

which, according to the second assertion of this lemma, implies that
m=\mu_{n}^{r}(m)
. Since
r<k
, this contradicts the minimality of
k
. The contradiction so obtained shows that
k
is a divisor of
\ell
and hence
m=\mu_{n}^{\ell}(m)
. (In other words,
\mu_{n}^{\ell}
is the identical self map of the set
M_{n}
).
∎

In the next statement, we establish a connection between the functions
d_{\mathbb{Z}}
and
\mu_{n}
.

Proposition 2.6
.

Let
n\geq 3
and let
M_{n}
and
\mu_{n}
denote the set and function introduced in Lemma
2.5
. Then, for
m\in M_{n}
and
k\geq 0
,

(16)

\displaystyle d_{\mathbb{Z}}(2^{k}\tfrac{m}{n})=\tfrac{1}{n}\mu_{n}^{k}(m).

Proof.

We prove the statement of the proposition applying induction on
k
.

The equality (
16
) is obvious for
k=0
because both sides are equal to
\tfrac{m}{n}
. For
k=1
, we can use formula (
7
) of Lemma
2.1
with
x=\tfrac{m}{n}
. Then

\displaystyle d_{\mathbb{Z}}(2\tfrac{m}{n})

\displaystyle=\min(2d_{\mathbb{Z}}(\tfrac{m}{n}),1-2d_{\mathbb{Z}}(\tfrac{m}{n}))

\displaystyle=\min(2\tfrac{m}{n},1-2\tfrac{m}{n})=\tfrac{1}{n}\min(2m,n-2m)=\tfrac{1}{n}\mu_{n}(m),

which yields that (
16
) is valid for
k=1
.

Assume now that the equality (
16
) holds for some
k\geq 1
. Then, applying formula (
8
) with
x=\tfrac{m}{n}
twice and the inductive hypothesis (also twice), we get

\displaystyle d_{\mathbb{Z}}(2^{k+1}\tfrac{m}{n})

\displaystyle=(d_{\mathbb{Z}}\circ(2d_{\mathbb{Z}})^{k+1})(\tfrac{m}{n})=(d_{\mathbb{Z}}\circ(2d_{Z})\circ(2d_{\mathbb{Z}})^{k})(\tfrac{m}{n})

\displaystyle=d_{\mathbb{Z}}\big(2(d_{Z}\circ(2d_{\mathbb{Z}})^{k})(\tfrac{m}{n})\big)=d_{\mathbb{Z}}\big(2d_{\mathbb{Z}}(2^{k}\tfrac{m}{n})\big)

\displaystyle=d_{\mathbb{Z}}\big(\tfrac{2}{n}\mu_{n}^{k}(m)\big)=\tfrac{1}{n}\mu_{n}(\mu_{n}^{k}(m))=\tfrac{1}{n}\mu_{n}^{k+1}(m).

This shows that the equality (
16
) holds for
k+1
(instead of
k
), and this completes the induction.
∎

Finally, we prove a certain periodicity property of the sequence
d_{\mathbb{Z}}(2^{k}\lambda)
.

Proposition 2.7
.

Let
n\geq 3
be an odd number,
m\in\mathbb{Z}
be coprime to
n
and let
\ell:=\frac{1}{2}\phi(n)
. Then, for all nonnegative
k\in\mathbb{Z}
,

(17)

\displaystyle d_{\mathbb{Z}}(\tfrac{m}{n})=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m}{n}).

Consequently, the sequence
\big(d_{\mathbb{Z}}(2^{k}\cdot\tfrac{m}{n})\big)_{k\geq 0}
is
\ell
-periodic.

Proof.

Then
\ell
is an integer since
\phi(n)
is even for
n\geq 2
. The value of the function
d_{\mathbb{Z}}
at
\frac{m}{n}
is rational number of the form
\frac{m^{\prime}}{n}\in\big(0,\frac{1}{2}\big)
such that either
n\mid(m-m^{\prime})
or
n\mid(m+m^{\prime})
. Therefore, there exists
d\in\mathbb{Z}
such that either
m=dn+m^{\prime}
or
m=dn-m^{\prime}
. Since
m
is coprime to
n
, it follows that
m^{\prime}
is also coprime to
m
. Therefore,
m^{\prime}\in M_{n}
, and according to the last assertion of Lemma
2.5
, for all
k\geq 0
, we have that
m^{\prime}=\mu_{n}^{k\ell}(m^{\prime})
.

In the case when
m=dn+m^{\prime}
, using Proposition
2.6
, we get

\displaystyle d_{\mathbb{Z}}(\tfrac{m}{n})

\displaystyle=d_{\mathbb{Z}}(\tfrac{dn+m^{\prime}}{n})=d_{\mathbb{Z}}(d+\tfrac{m^{\prime}}{n})=d_{\mathbb{Z}}(\tfrac{m^{\prime}}{n})=\tfrac{1}{n}m^{\prime}=\tfrac{1}{n}\mu_{n}^{k\ell}(m^{\prime})

\displaystyle=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m^{\prime}}{n})=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m-dn}{n})=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m}{n}-2^{k+\ell}d)=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m}{n}).

In the case when

, using Proposition
2.6
, we get

\displaystyle d_{\mathbb{Z}}(\tfrac{m}{n})

\displaystyle=d_{\mathbb{Z}}(\tfrac{dn-m^{\prime}}{n})=d_{\mathbb{Z}}(d-\tfrac{m^{\prime}}{n})=d_{\mathbb{Z}}(-\tfrac{m^{\prime}}{n})=d_{\mathbb{Z}}(\tfrac{m^{\prime}}{n})=\tfrac{1}{n}m^{\prime}=\tfrac{1}{n}\mu_{n}^{k\ell}(m^{\prime})

\displaystyle=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m^{\prime}}{n})=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{dn-m}{n})=d_{\mathbb{Z}}(2^{k\ell}d-2^{k\ell}\cdot\tfrac{m}{n})=d_{\mathbb{Z}}(-2^{k\ell}\cdot\tfrac{m}{n})=d_{\mathbb{Z}}(2^{k\ell}\cdot\tfrac{m}{n}).

Thus, we have proved that (
17
) holds in both cases.
∎

3.
Main results

In our first result, we show that
\varphi
-Jensen convexity implies further convexity properties for rational convex combinations of the variables.

Theorem 3.1
.

Let
\varphi\in\mathscr{A}(D_{\Delta})
. If
f:D\to\mathbb{R}
is
\varphi
-Jensen convex, then, for all
n,k\in\mathbb{N}
and
x,y\in D
,

(18)

\displaystyle f\Big(\dfrac{nx+ky}{n+k}\Big)\leq\frac{n}{n+k}f(x)+\frac{k}{n+k}f(y)+kn\varphi\bigg(\frac{x-y}{n+k}\bigg).

Proof.

We are going to show this inequality by induction with respect to
m=n+k
.

If
m=n+k=2
, then
n=k=1
and (
18
) is equivalent to the
\varphi
-Jensen convexity of
f
.

Let
m\geq 2
and assume that the inequality (
18
) is valid for all
n,k\in\mathbb{N}
such that
n+k\leq m
. Let
n,k\in\mathbb{N}
such that
n+k=m+1
. Then

\displaystyle\max(n,k)\geq\frac{m+1}{2}\geq\frac{3}{2},

so
\max(n,k)\geq 2
. Without loss of generality, we may assume that
n\geq 2
. Observe that

\displaystyle\frac{nx+ky}{n+k}=\frac{m-k}{m}\cdot x+\frac{k}{m}\cdot\frac{x+my}{n+k}.

Therefore, by the inductive hypothesis, we can apply the inequality (
18
) for
(m-k,k)\in\mathbb{N}^{2}
and
\big(x,\frac{x+my}{m+1}\big)\in D^{2}
, and we obtain

(19)

\displaystyle f\bigg(\frac{nx+ky}{n+k}\bigg)

\displaystyle\leq\frac{m-k}{m}f(x)+\frac{k}{m}f\bigg(\frac{x+my}{n+k}\bigg)+(m-k)k\varphi\bigg(\frac{1}{(m-k)+k}\Big(x-\frac{x+my}{n+k}\Big)\bigg)

\displaystyle\leq\frac{m-k}{m}f(x)+\frac{k}{m}f\bigg(\frac{x+my}{n+k}\bigg)+(m-k)k\varphi\bigg(\frac{x-y}{n+k}\bigg).

On the other hand, we also have that

\displaystyle\frac{x+my}{n+k}=\frac{1}{n}\cdot\frac{nx+ky}{n+k}+\frac{n-1}{n}\cdot y.

Notice that
1+(n-1)=n=m+1-k\leq m
.
Thus, by the inductive assumption, we can apply the inequality (
18
) for
(1,n-1)\in\mathbb{N}^{2}
and
\big(\frac{nx+ky}{n+k},y\big)\in D^{2}
, and we get

\displaystyle f\bigg(\frac{x+my}{n+k}\bigg)

\displaystyle\leq\frac{1}{n}f\bigg(\frac{nx+ky}{n+k}\bigg)+\frac{n-1}{n}f(y)+1\cdot(n-1)\varphi\bigg(\frac{1}{1+(n-1)}\Big(\frac{nx+ky}{n+k}-y\Big)\bigg)

\displaystyle=\frac{1}{n}f\bigg(\frac{nx+ky}{n+k}\bigg)+\frac{n-1}{n}f(y)+(n-1)\varphi\bigg(\frac{x-y}{n+k}\bigg).

Using this inequality, (
19
) yields that

\displaystyle f\bigg(\frac{nx+ky}{n+k}\bigg)\leq\frac{m-k}{m}f(x)

\displaystyle+\frac{k}{mn}f\bigg(\frac{nx+ky}{n+k}\bigg)+\frac{k(n-1)}{mn}f(y)

\displaystyle+\bigg(\frac{k(n-1)}{m}+(m-k)k\bigg)\varphi\bigg(\frac{x-y}{n+k}\bigg).

Rearranging this inequality, we can conclude that

\displaystyle f\bigg(\frac{nx+ky}{n+k}\bigg)\leq\frac{n(m-k)}{mn-k}f(x)+\frac{k(n-1)}{mn-k}f(y)+kn\frac{(n-1)+m(m-k)}{mn-k}\varphi\bigg(\frac{x-y}{n+k}\bigg).

Using that
mn-k=(n-1)(n+k)
, it immediately follows that the inequality (
18
) holds if
n+k=m+1
.
∎

In what follows, we sharpen the inequality (
18
) by lowering the error function. Given
\varphi:\tfrac{1}{2}D_{\Delta}\to\mathbb{R}
, we define
\varphi^{*}:\tfrac{1}{2}D_{\Delta}\to[-\infty,\infty)
by

\displaystyle\varphi^{*}(u):=\inf_{m\in\mathbb{N}}m^{2}\varphi\Big(\frac{u}{m}\Big).

Lemma 3.2
.

Let
\varphi:\tfrac{1}{2}D_{\Delta}\to\mathbb{R}
. Then
\varphi^{*}\leq\varphi
and, for all
k\in\mathbb{N}
,
u\in\tfrac{1}{2}D_{\Delta}
,

(20)

\displaystyle\varphi^{*}(u)\leq k^{2}\varphi^{*}\Big(\frac{u}{k}\Big).

Consequently,
\varphi^{**}:=(\varphi^{*})^{*}=\varphi^{*}
.
In addition, if
\varphi(0)=0
, then
\varphi^{*}(0)=0
and if
\varphi
is even, then
\varphi^{*}
is also even.

Proof.

The inequality
\varphi^{*}\leq\varphi
is obvious. To verify (
20
), let
k\in\mathbb{N}
,
u\in\tfrac{1}{2}D_{\Delta}
. Then

\displaystyle k^{2}\varphi^{*}\Big(\frac{u}{k}\Big)=k^{2}\inf_{m\in\mathbb{N}}m^{2}\varphi\Big(\frac{u}{km}\Big)=\inf_{m\in\mathbb{N}}(km)^{2}\varphi\Big(\frac{u}{km}\Big)\geq\inf_{n\in\mathbb{N}}n^{2}\varphi\Big(\frac{u}{n}\Big)=\varphi^{*}(u),

which proves (
20
). In view of the inequality (
20
), for all
u\in\tfrac{1}{2}D_{\Delta}
, we have that

\displaystyle\varphi^{*}(u)=\inf_{k\in\mathbb{N}}k^{2}\varphi^{*}\Big(\frac{u}{k}\Big)=\varphi^{**}(u).

Thus,
\varphi^{**}=\varphi^{*}
. It is obvious that if
\varphi(0)=0
, then
\varphi^{*}(0)=0
and if
\varphi
is even, then
\varphi^{*}
is also even.
∎

Corollary 3.3
.

Let
\varphi\in\mathscr{A}(D_{\Delta})
. Then, for all
n,k\in\mathbb{N}
and
x,y\in D
,

(21)

\displaystyle f\Big(\dfrac{nx+ky}{n+k}\Big)\leq\frac{n}{n+k}f(x)+\frac{k}{n+k}f(y)+kn\varphi^{*}\bigg(\frac{x-y}{n+k}\bigg).

Consequently, any
\varphi
-Jensen convex function is also
\varphi^{*}
-Jensen convex and
\varphi^{*}\in\mathscr{A}(D_{\Delta})
.

Proof.

Let
n,k\in\mathbb{N}
and
x,y\in D
.
By replacing
(n,k)
by
(mn,mk)
in (
18
), for all
m\in\mathbb{N}
, it follows that,

\displaystyle f\Big(\dfrac{nx+ky}{n+k}\Big)\leq\frac{n}{n+k}f(x)+\frac{k}{n+k}f(y)+knm^{2}\varphi\bigg(\frac{x-y}{m(n+k)}\bigg).

Therefore, by the definition of
\varphi^{*}
,

\displaystyle f\Big(\dfrac{nx+ky}{n+k}\Big)

\displaystyle\leq\frac{n}{n+k}f(x)+\frac{k}{n+k}f(y)+kn\inf_{m\in\mathbb{N}}m^{2}\varphi\bigg(\frac{x-y}{m(n+k)}\bigg)

\displaystyle=\frac{n}{n+k}f(x)+\frac{k}{n+k}f(y)+kn\varphi^{*}\bigg(\frac{x-y}{n+k}\bigg),

which shows that (
21
) is valid.

By applying the inequality (
21
) for
n=k=1
, it follows that
f
is also
\varphi^{*}
-Jensen convex.

If
\varphi
is admissible, then
\varphi
is even,
\varphi(0)=0
and there exists
\varphi
-Jensen convex
function, which will also be
\varphi^{*}
-Jensen convex.
This observation combined with last statements of the previous lemma, yields that
\varphi^{*}
is also admissible.
∎

For
\varphi\in\mathscr{A}(D_{\Delta})
, define the
extended error function

\mathscr{E}[\varphi]:[0,1]\times D_{\Delta}\to[-\infty,\infty]
by

(22)

\displaystyle\mathscr{E}[\varphi](\lambda,u):=\sup\big\{

\displaystyle f(\lambda x+(1-\lambda)y)-\lambda f(x)-(1-\lambda)f(y)

\displaystyle\mid\mbox{$f:D\to\mathbb{R}$ is $\varphi$-Jensen convex},\ x,y\in D,\,x-y=u\big\}.

Since
\varphi\in\mathscr{A}(D_{\Delta})
, it follows that
\mathscr{E}[\varphi]
cannot take the value
-\infty
.
According to this construction,
\mathscr{E}[\varphi]:[0,1]\times D_{\Delta}\to(-\infty,\infty]
is the smallest function which, for all
\lambda\in[0,1]
,
x,y\in D
and for all
\varphi
-Jensen convex functions
f:D\to\mathbb{R}
satisfies the inequality

(23)

\displaystyle f(\lambda x+(1-\lambda)y)\leq\lambda f(x)+(1-\lambda)f(y)+\mathscr{E}[\varphi](\lambda,x-y).

Given
\varphi\in\mathscr{A}(D_{\Delta})
, the most important properties of the function
\mathscr{E}[\varphi]
are contained in the following result. As a consequence of it, we will see that
\mathscr{E}[\varphi]
has finite values over the set
[0,1]_{\mathbb{Q}}\times D_{\Delta}
.

Theorem 3.4
.

Let
\varphi\in\mathscr{A}(D_{\Delta})
. Then

(i)

For all
\lambda\in[0,1]
and
u\in D_{\Delta}
,
\mathscr{E}[\varphi](\lambda,0)=\mathscr{E}[\varphi](0,u)=\mathscr{E}[\varphi](1,u)=0
.

(ii)

For all
\lambda\in[0,1]
and
u\in D_{\Delta}
,
\mathscr{E}[\varphi](\lambda,u)=\mathscr{E}[\varphi](1-\lambda,-u)
.

(iii)

For all
n,k\in\mathbb{N}
and
u\in D_{\Delta}
,

\displaystyle\mathscr{E}[\varphi]\Big(\frac{n}{n+k},u\Big)\leq nk\varphi^{*}\Big(\frac{u}{n+k}\Big).

(iv)

For all
\lambda\in[0,1]\setminus\mathbb{Q}
and
u\in D_{\Delta}\setminus\{0\}
,
\mathscr{E}[\varphi](\lambda,u)=\infty
.

(v)

For all
\lambda,\mu\in[0,1]
and
u\in D_{\Delta}
,

(24)

\displaystyle\mathscr{E}[\varphi](\lambda\mu,u)\leq\lambda\mathscr{E}[\varphi]\big(\mu,u\big)+\mathscr{E}[\varphi]\big(\lambda,\mu u\big).

Proof.

The property (i) directly follows from the definition of
\mathscr{E}[\varphi]
.

To prove (ii), observe that, for all
(\lambda,u)\in[0,1]\times D_{\Delta}
,

\displaystyle\mathscr{E}[\varphi](\lambda,u)

\displaystyle=\sup\big\{f(\lambda x+(1-\lambda)y)-\lambda f(x)-(1-\lambda)f(y)

\displaystyle\mid\mbox{$f:D\to\mathbb{R}$ is $\varphi$-Jensen convex},\ x,y\in D,\,x-y=u\big\}

\displaystyle=\sup\big\{f((1-\lambda)y+\lambda x)-(1-\lambda)f(y)-\lambda f(x)

\displaystyle\mid\mbox{$f:D\to\mathbb{R}$ is $\varphi$-Jensen convex},\ x,y\in D,\,y-x=-u\big\}

\displaystyle=\mathscr{E}[\varphi](1-\lambda,-u).

In order to show that (iii) is valid, let
n,k\in\mathbb{N}
,
u\in D_{\Delta}
, and let
c<\mathscr{E}[\varphi]\big(\tfrac{n}{n+k},u\big)
be arbitrary. Then there exists a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
and
x,y\in D
such that
x-y=u
and

\displaystyle c<f\Big(\frac{n}{n+k}x+\frac{k}{n+k}y\Big)-\frac{n}{n+k}f(x)-\frac{k}{n+k}f(y).

According to Corollary
3.3
,
f
is
\varphi^{*}
-Jensen convex and satisfies (
21
), therefore,

\displaystyle c<nk\varphi^{*}\Big(\frac{x-y}{n+k}\Big)=nk\varphi^{*}\Big(\frac{u}{n+k}\Big).

Upon taking the limit
c\to\mathscr{E}[\varphi]\big(\tfrac{n}{n+k},u\big)
, the inequality in condition (iii) follows.

To show that (iv) is valid, let
\lambda\in[0,1]\setminus\mathbb{Q}
and
u\in D_{\Delta}\setminus\{0\}
be fixed.
Then there exists
x,y\in D
such that
u=x-y
.
Using that
\varphi\in\mathscr{A}(D_{\Delta})
, we can choose a
\varphi
-Jensen convex function
f_{0}:D\to\mathbb{R}
.

Consider
X
as a vector space over the field
\mathbb{Q}
. Then
u
and
\lambda u
are linearly independent elements of this space. Indeed, if for some nonzero pair
(\alpha,\beta)\in\mathbb{Q}^{2}
, we have that
\alpha u+\beta(\lambda u)=0
, then
\alpha+\beta\lambda=0
, which is impossible by the irrationality of
\lambda
. Then, according to Hamel’s theorem, there exists a Hamel base
H
of
X
(over the field
\mathbb{Q}
), which contains
u
and
\lambda u
, furthermore, every function
a:H\to\mathbb{R}
admits a unique additive extension
A:X\to\mathbb{R}
. Let
\alpha\in\mathbb{R}
and define now an additive function
A_{\alpha}:X\to\mathbb{R}
via the conditions:

\displaystyle A_{\alpha}(\lambda u):=\alpha,\qquad A_{\alpha}(h):=0\quad(h\in H\setminus\{\lambda u\}).

In particular,
A_{\alpha}(u)=0
.
Then the function
f_{\alpha}:=f_{0}+A_{\alpha}|_{D}
is
\varphi
-Jensen convex and

\displaystyle f_{\alpha}(\lambda x+(1-\lambda)y)

\displaystyle-\lambda f_{\alpha}(x)-(1-\lambda)f_{\alpha}(y)

\displaystyle=f_{0}(\lambda x+(1-\lambda)y)-\lambda f_{0}(x)-(1-\lambda)f_{0}(y)

\displaystyle+A_{\alpha}(\lambda x+(1-\lambda)y)-\lambda A_{\alpha}(x)-(1-\lambda)A_{\alpha}(y)

\displaystyle=f_{0}(\lambda x+(1-\lambda)y)-\lambda f_{0}(x)-(1-\lambda)f_{0}(y)+A_{\alpha}(\lambda u)-\lambda A_{\alpha}(u)

\displaystyle=f_{0}(\lambda x+(1-\lambda)y)-\lambda f_{0}(x)-(1-\lambda)f_{0}(y)+\alpha.

Therefore,

\displaystyle\mathscr{E}[\varphi]

\displaystyle(\lambda,u)

\displaystyle\geq\sup\big\{f(\lambda x+(1-\lambda)y)-\lambda f(x)-(1-\lambda)f(y)\mid\mbox{$f:D\to\mathbb{R}$ is $\varphi$-Jensen convex}\big\}

\displaystyle\geq\sup\big\{f_{\alpha}(\lambda x+(1-\lambda)y)-\lambda f_{\alpha}(x)-(1-\lambda)f_{\alpha}(y)\mid\alpha\in\mathbb{R}\big\}

\displaystyle=\sup\big\{f_{0}(\lambda x+(1-\lambda)y)-\lambda f_{0}(x)-(1-\lambda)f_{0}(y)+\alpha\mid\alpha\in\mathbb{R}\big\}

\displaystyle=f_{0}(\lambda x+(1-\lambda)y)-\lambda f_{0}(x)-(1-\lambda)f_{0}(y)+\sup\mathbb{R}=\infty.

To prove (v), let
u\in D_{\Delta}
and
\lambda,\mu\in[0,1]
and choose
c<\mathscr{E}[\varphi](\lambda\mu,u)
arbitrarily. Then there exists a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
and
x,y\in D
such that
x-y=u
and

(25)

\displaystyle c<f(\lambda\mu x+(1-\lambda\mu)y)-\lambda\mu f(x)-(1-\lambda\mu)f(y)

holds. By the construction of
\mathscr{E}[\varphi]
, we obtain that

\displaystyle f(\lambda\mu x

\displaystyle+(1-\lambda\mu)y)

\displaystyle=f\big(\lambda(\mu x+(1-\mu)y)+(1-\lambda)y\big)

\displaystyle\leq\lambda f(\mu x+(1-\mu)y)+(1-\lambda)f(y)+\mathscr{E}[\varphi](\lambda,(\mu x+(1-\mu)y)-y)

\displaystyle\leq\lambda\Big(\mu f(x)+(1-\mu)f(y)+\mathscr{E}[\varphi]\big(\mu,x-y\big)\Big)+(1-\lambda)f(y)+\mathscr{E}[\varphi](\lambda,\mu u)

\displaystyle=\lambda\mu f(x)+(1-\lambda\mu)f(y)+\lambda\mathscr{E}[\varphi](\mu,u)+\mathscr{E}[\varphi](\lambda,\mu u).

Using inequality (
25
), we obtain that

\displaystyle c\leq\lambda\mathscr{E}[\varphi](\mu,u)+\mathscr{E}[\varphi](\lambda,\mu u).

Upon taking the limit as
c\to\mathscr{E}[\varphi](\lambda\mu,u)
, we get that inequality (
24
) holds.
∎

The essential properties of the set
\mathscr{A}(D_{\Delta})
and the functional
\mathscr{E}:\mathscr{A}(D_{\Delta})\to(-\infty,\infty]^{[0,1]\times D_{\Delta}}
are collected in the following result.

Theorem 3.5
.

Let
D\subseteq X
be a nonempty convex set. Then
\mathscr{A}(D_{\Delta})
is a convex cone (i.e.,
\mathscr{A}(D_{\Delta})
is closed with respect to multiplication by positive scalars and addition), which is also invariant with respect to the mapping
\varphi\mapsto\varphi^{*}
. Furthermore, for all
t>0
and
\varphi\in\mathscr{A}(D_{\Delta})
,

(26)

\displaystyle\mathscr{E}[t\varphi]=t\mathscr{E}[\varphi],

and, for all
\varphi\in\mathscr{A}(D_{\Delta})
,

(27)

\displaystyle\mathscr{E}[\varphi]=\mathscr{E}[\varphi^{*}].

Proof.

First we prove that
\mathscr{A}(D_{\Delta})
is closed with respect to multiplication by positive scalars. Let
t>0
,
\varphi\in\mathscr{A}(D_{\Delta})
. Then there exists a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
, i.e., (
3
) holds. Multiplying this inequality by
t
side by side, we can see that
tf
is a
(t\varphi)
-Jensen convex function. Furthermore,
0\leq(t\varphi)(0)
and
(t\varphi)
is also even. Therefore,
t\varphi
is also an admissible error function.

To show that (
26
) holds, let
\lambda\in[0,1]
and
u\in D_{\Delta}
, and let
c<\mathscr{E}[\varphi](\lambda,u)
be arbitrary. Then there exist
x,y\in D
and a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
such that
u=x-y
and

(28)

\displaystyle c<f(\lambda x+(1-\lambda)y)-\lambda f(x)-(1-\lambda)f(y).

Multiplying this inequality by
t
side by side, and observing that
tf
is
(t\varphi)
-Jensen convex, we can see that

\displaystyle tc<(tf)(\lambda x+(1-\lambda)y)-\lambda(tf)(x)-(1-\lambda)(tf)(y)\leq\mathscr{E}[t\varphi](\lambda,u).

Upon taking the limit
c\to\mathscr{E}[\varphi](\lambda,u)
, for all
t>0
,
\varphi\in\mathscr{A}(D_{\Delta})
,
\lambda\in[0,1]
, and
u\in D_{\Delta}
, it follows that

(29)

\displaystyle t\mathscr{E}[\varphi](\lambda,u)\leq\mathscr{E}[t\varphi](\lambda,u).

On the other hand, using this inequality

\displaystyle\mathscr{E}[t\varphi](\lambda,u)=t\cdot\frac{1}{t}\mathscr{E}[t\varphi](\lambda,u)\leq t\mathscr{E}[\tfrac{1}{t}\cdot(t\varphi)](\lambda,u)=t\mathscr{E}[\varphi](\lambda,u),

which shows that (
29
) holds with equality.
This shows that (
26
) is also valid.

Next we point out that
\mathscr{A}(D_{\Delta})
is closed with respect to addition. Let
\varphi,\psi\in\mathscr{A}(D_{\Delta})
. Then there exist a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
and a
\psi
-Jensen convex function
g:D\to\mathbb{R}
. It is immediate to see that
f+g
is a
(\varphi+\psi)
-Jensen convex function. Furthermore,
0\leq(\varphi+\psi)(0)
and
\varphi+\psi
is also even. Therefore,
\varphi+\psi
is also an admissible error function.

In view of the last statement of Corollary
3.3
, if
\varphi\in\mathscr{A}(D_{\Delta})
, then
\varphi^{*}\in\mathscr{A}(D_{\Delta})
. The inequality
\varphi^{*}\leq\varphi
implies that
\mathscr{E}[\varphi^{*}]\leq\mathscr{E}[\varphi]
. To prove the reversed inequality, let
\lambda\in[0,1]
and
u\in D_{\Delta}
, and let
c<\mathscr{E}[\varphi](\lambda,u)
be arbitrary. Then there exist
x,y\in D
and a
\varphi
-Jensen convex function
f:D\to\mathbb{R}
such that
u=x-y
and the inequality (
28
) holds. By Corollary
3.3
, we have that
f
is also
\varphi^{*}
-Jensen convex, hence

\displaystyle f(\lambda x+(1-\lambda)y)-\lambda f(x)-(1-\lambda)f(y)\leq\mathscr{E}[\varphi^{*}](\lambda,u).

Therefore,
c<\mathscr{E}[\varphi^{*}](\lambda,u)
. Upon taking the limit
c\to\mathscr{E}[\varphi](\lambda,u)
, it follows that the inequality
\mathscr{E}[\varphi](\lambda,u)\leq\mathscr{E}[\varphi^{*}](\lambda,u)
is valid for all
\lambda\in[0,1]
and
u\in D_{\Delta}
. Consequently,
\mathscr{E}[\varphi]\leq\mathscr{E}[\varphi^{*}]
. Thus, the equality
(
27
) is proved.
∎

In the following result we establish an upper estimate for
\mathscr{E}[\varphi](\lambda,u)
obtained in assertion (iii) of Theorem
3.4
in terms of a Takagi-type function related to the map
t\mapsto\varphi^{*}(tu)
, where
u\in D_{\Delta}
is fixed.

Theorem 3.6
.

Let
\varphi\in\mathscr{A}(D_{\Delta})
. Then, for all
\lambda\in[0,1]_{\mathbb{Q}}
and
u\in D_{\Delta}
,

(30)

\displaystyle\mathscr{E}[\varphi](\lambda,u)\leq\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big),

furthermore, the series on the right hand side of (
30
) is absolutely convergent and if
\lambda=\frac{n}{n+m}
for some
n,m\in\mathbb{N}
, then, for all
u\in D_{\Delta}
,

(31)

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)\leq nm\varphi^{*}\Big(\frac{u}{n+m}\Big).

Proof.

First, we verify that the series on the right hand side of (
30
) is absolutely convergent for all
\lambda\in[0,1]_{\mathbb{Q}}
and
u\in D_{\Delta}
. For
\lambda\in[0,1]
, define the set
S(\lambda)\subseteq\big[1,\frac{1}{2}\big]
by

\displaystyle S(\lambda):=\big\{d_{\mathbb{Z}}(2^{k}\lambda)\colon k\in\mathbb{N}\cup\{0\}\big\}.

We claim that this set is finite for all
\lambda\in[0,1]_{\mathbb{Q}}
. If
\lambda\in\{0,1\}
, then
d_{\mathbb{Z}}(2^{k}\lambda)=0
for all
k\in\mathbb{N}\cup\{0\}
, whence we get that
S(0)=S(1)=\{0\}
. Thus, we may assume that
\lambda\in(0,1)_{\mathbb{Q}}
. In this case
\lambda
can be written uniquely in the form
\lambda=2^{\ell}\frac{m}{n}
, where
\ell\in\mathbb{Z}
and
n,m
are odd coprime natural numbers. If
k\geq-\ell
the denominator of
2^{k}\lambda=2^{k+\ell}\frac{m}{n}
is equal to
n
. Therefore, the distance of
2^{k}\lambda
from
\mathbb{Z}
is a rational number whose denominator equals
n
, i.e.,

\displaystyle\big\{d_{\mathbb{Z}}(2^{k}\lambda)\colon k\in\mathbb{N}\cup\{0\},\,k\geq-\ell\}\subseteq\big\{\tfrac{i}{n}\colon i\in\big\{0,1,\dots,\big\lfloor\tfrac{n}{2}\big\rfloor\big\}\big\}.

Therefore,

\displaystyle S(\lambda)

\displaystyle=\big\{d_{\mathbb{Z}}(2^{k}\lambda)\colon k\in\mathbb{N}\cup\{0\},\,k<-\ell\}\cup\big\{d_{\mathbb{Z}}(2^{k}\lambda)\colon k\in\mathbb{N}\cup\{0\},\,k\geq-\ell\}

\displaystyle\subseteq\big\{d_{\mathbb{Z}}(2^{k}\lambda)\colon k\in\mathbb{N}\cup\{0\},\,k<-\ell\}\cup\big\{\tfrac{i}{n}\colon i\in\big\{0,1,\dots,\big\lfloor\tfrac{n}{2}\big\rfloor\big\}\big\},

which shows that
S(\lambda)
is covered by union of two finite sets. Thus
S(\lambda)
is finite as well.

Now we are able to show that,
\lambda\in[0,1]_{\mathbb{Q}}
and
u\in D_{\Delta}
, the series on the right hand side of (
30
) is absolutely convergent. Indeed,

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\big|\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)\big|\leq\sum_{k=0}^{\infty}\frac{1}{2^{k}}\max_{s\in S(\lambda)}\big|\varphi^{*}(su)\big|=2\max_{s\in S(\lambda)}\big|\varphi^{*}(su)\big|<\infty.

In what follows, we prove by induction with respect to
n\in\mathbb{N}
that, for all
\lambda\in[0,1]_{\mathbb{Q}}
and
u\in D_{\Delta}
,

(32)

\displaystyle\mathscr{E}[\varphi](\lambda,u)\leq\sum_{k=0}^{n-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\frac{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}^{2}}{2^{n+2}}\max_{1\leq m\leq\boldsymbol{\langle}\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|.

If
\lambda=\frac{n}{n+k}
, where
n,k\in\mathbb{N}
are coprime numbers, then
\boldsymbol{\langle}\lambda\boldsymbol{\rangle}=n+k
.
By the inequality
nk\leq\frac{1}{4}(n+k)^{2}
and assertion (iii) of Theorem
3.4
, it follows that

\displaystyle\mathscr{E}[\varphi](\lambda,u)

\displaystyle\leq nk\varphi^{*}\bigg(\frac{u}{n+k}\bigg)\leq nk\left|\varphi^{*}\bigg(\frac{u}{n+k}\bigg)\right|

\displaystyle\leq\frac{(n+k)^{2}}{4}\left|\varphi^{*}\bigg(\frac{u}{n+k}\bigg)\right|=\frac{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}^{2}}{2^{2}}\left|\varphi^{*}\bigg(\frac{u}{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}}\bigg)\right|\leq\frac{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}^{2}}{2^{2}}\max_{1\leq m\leq\boldsymbol{\langle}\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|,

which proves the inequality (
32
) for
n=0
.

Assume that we have proved (
32
) for some
n\geq 0
. First let
\lambda\in[0,\frac{1}{2}]_{\mathbb{Q}}
and let
u\in D_{\Delta}
be fixed. By assertion (v) of Theorem
3.4
, we have

(33)

\displaystyle\mathscr{E}[\varphi](\lambda,u)=\mathscr{E}[\varphi](\tfrac{1}{2}\cdot(2\lambda),u)\leq\tfrac{1}{2}\mathscr{E}[\varphi]\big(2\lambda,u\big)+\mathscr{E}[\varphi]\big(\tfrac{1}{2},2\lambda u\big).

By assertion (iii) of Theorem
3.4
, we have that

(34)

\displaystyle\mathscr{E}[\varphi]\big(\tfrac{1}{2},2\lambda u\big)\leq\varphi^{*}\big(\lambda u\big)=\varphi^{*}\big(d_{\mathbb{Z}}(\lambda)u\big).

In view of the inductive hypothesis, we can obtain

(35)

\displaystyle\frac{1}{2}\mathscr{E}[\varphi]\big(2\lambda,u\big)

\displaystyle\leq\frac{1}{2}\bigg(\sum_{k=0}^{n-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}(2\lambda))u\big)+\frac{\boldsymbol{\langle}2\lambda\boldsymbol{\rangle}^{2}}{2^{n+2}}\max_{1\leq m\leq\boldsymbol{\langle}2\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|\bigg)

\displaystyle=\sum_{k=1}^{n}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda))u\big)+\frac{\boldsymbol{\langle}2\lambda\boldsymbol{\rangle}^{2}}{2^{n+3}}\max_{1\leq m\leq\boldsymbol{\langle}2\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|

\displaystyle\leq\sum_{k=1}^{n}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda))u\big)+\frac{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}^{2}}{2^{n+3}}\max_{1\leq m\leq\boldsymbol{\langle}\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|.

Applying the inequalities (
34
) and (
35
), the inequality (
33
) implies that (
32
) holds for all
\lambda\in[0,\frac{1}{2}]_{\mathbb{Q}}
,
u\in D_{\Delta}
and for
n+1
(instead of
n
).

Now assume that
\lambda\in[\frac{1}{2},1]_{\mathbb{Q}}
and let
u\in D_{\Delta}
be fixed. Then
1-\lambda\in[0,\frac{1}{2}]_{\mathbb{Q}}
. Using assertion (ii) of Theorem
3.4
, and then what we have proved in the previous case, we get

\displaystyle\mathscr{E}[\varphi](\lambda,u)

\displaystyle=\mathscr{E}[\varphi](1-\lambda,-u)

\displaystyle\leq\sum_{k=0}^{n-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}(1-\lambda))(-u)\big)+\frac{\boldsymbol{\langle}1-\lambda\boldsymbol{\rangle}^{2}}{2^{n+2}}\max_{1\leq m\leq\boldsymbol{\langle}1-\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{-u}{m}\bigg)\right|

\displaystyle\leq\sum_{k=0}^{n-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\frac{\boldsymbol{\langle}\lambda\boldsymbol{\rangle}^{2}}{2^{n+2}}\max_{1\leq m\leq\boldsymbol{\langle}\lambda\boldsymbol{\rangle}}\left|\varphi^{*}\bigg(\frac{u}{m}\bigg)\right|.

Thus, (
32
) also holds for all
\lambda\in[\frac{1}{2},1]
,
u\in D_{\Delta}
and for
n+1
(instead of
n
).

This completes the proof of inequality (
32
) on the indicated domain. Upon taking the limit
n\to\infty
, we can conclude that the asserted inequality is valid for all
\lambda\in[0,1]_{\mathbb{Q}}
,
u\in D_{\Delta}
.

Finally, we show that the inequality (
31
) is also valid. Assume that
\lambda=\frac{n}{n+m}
for some
n,m\in\mathbb{N}
. Then
(n+m)d_{\mathbb{Z}}(2^{k}\lambda)
is an integer number for all
k\in\mathbb{N}
. Therefore, due to the inequality (
20
), we have that

\displaystyle\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)=\varphi^{*}\Big((n+m)d_{\mathbb{Z}}(2^{k}\lambda)\frac{u}{n+m}\Big)\leq(n+m)^{2}d_{\mathbb{Z}}(2^{k}\lambda)^{2}\varphi^{*}\Big(\frac{u}{n+m}\Big).

Therefore, using Corollary
2.3
, we get

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)

\displaystyle\leq\sum_{k=0}^{\infty}\frac{(n+m)^{2}d_{\mathbb{Z}}(2^{k}\lambda)^{2}}{2^{k}}\varphi^{*}\Big(\frac{u}{n+m}\Big)

\displaystyle\leq\bigg(\sum_{k=0}^{\infty}\frac{d_{\mathbb{Z}}(2^{k}\lambda)^{2}}{2^{k}}\bigg)(n+m)^{2}\varphi^{*}\Big(\frac{u}{n+m}\Big)

\displaystyle=\lambda(1-\lambda)(n+m)^{2}\varphi^{*}\Big(\frac{u}{n+m}\Big)=nm\varphi^{*}\Big(\frac{u}{n+m}\Big).

This completes the proof of the inequality (
31
).
∎

In our last result, we establish a closed formula for the computation of the Takagi-type function given by the infinite series on the right hand side of the inequality (
30
).

Theorem 3.7
.

Let
\varphi\in\mathscr{A}(D_{\Delta})
and
\lambda:=\frac{m}{2^{j}n}
, where
m,j\geq 0
are integers,
n\geq 1
is an odd integer,
m\leq 2^{j-1}n
, furthermore,
m
and
2^{j}n
are coprime numbers. Denote
\ell:=\left\lfloor\frac{1}{2}\phi(n)\right\rfloor
. Then, for all
u\in D_{\Delta}
,

(36)

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\sum_{k=j}^{j+\ell-1}\frac{1}{2^{k}-2^{k-\ell}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big).

Proof.

If
n=1
, then, for
k\geq j
, the product
2^{k}\lambda
is an integer. Thus,
d_{\mathbb{Z}}(2^{k}\lambda)=0
, which implies that
\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)=\varphi^{*}(0)=0
. Therefore,

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big).

This shows that (
36
) holds in the case
n=1
.

In the rest of the proof, we assume that
n\geq 3
. Then
\ell=\frac{1}{2}\phi(n)
(since
\phi(n)
is even for
n\geq 2
). Based on Proposition
2.7
, for
i,k\geq 0
, we have that

\displaystyle d_{\mathbb{Z}}(\tfrac{2^{k}\cdot m}{n})=d_{\mathbb{Z}}(2^{i\ell}\cdot\tfrac{2^{k}\cdot m}{n}).

From this equality it follows that, for
i\geq 0
and
k\geq j
,

\displaystyle d_{\mathbb{Z}}(2^{k}\lambda)=d_{\mathbb{Z}}(2^{k+i\ell}\lambda).

In view of this equality, we obtain

\displaystyle\sum_{k=0}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)

\displaystyle=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\sum_{k=j}^{\infty}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)

\displaystyle=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\sum_{k=j}^{j+\ell-1}\sum_{i=0}^{\infty}\frac{1}{2^{k+i\ell}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k+i\ell}\lambda)u\big)

\displaystyle=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\sum_{k=j}^{j+\ell-1}\bigg(\sum_{i=0}^{\infty}\frac{1}{2^{k+i\ell}}\bigg)\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)

\displaystyle=\sum_{k=0}^{j-1}\frac{1}{2^{k}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big)+\sum_{k=j}^{j+\ell-1}\frac{1}{2^{k}-2^{k-\ell}}\varphi^{*}\big(d_{\mathbb{Z}}(2^{k}\lambda)u\big),

which completes the proof of the formula (
36
).
∎

In what follows, we present a few particular cases of the combination of inequality (
