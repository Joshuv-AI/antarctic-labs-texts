Abstract
An n n -vertex, d d -regular graph can have at most 2 n / 2 + o d ​ ( n ) 2^{n/2+o_{d}(n)} independent sets. In this paper we address what happens with this upper bound when we impose the further condition that the graph has independence number at most α \alpha . We give upper and lower bounds that in many cases are close to each other. In particular, for each 0 < c ind ≤ 1 / 2 0<c_{\rm ind}\leq 1/2 we exhibit a constant k ⁡ ( c ind ) k(c_{\rm ind}) such that • If ( G n ) n ∈ ℕ (G_{n})_{n\in{\mathbb{N}}} is a sequence of graphs with G n G_{n} d d -regular on n n vertices and with maximum independent set size at most α \alpha , with d → ∞ d\rightarrow\infty and α / n → c ind \alpha/n\rightarrow c_{\rm ind} as n → ∞ n\rightarrow\infty , then G n G_{n} has at most k ​ ( c ind ) n + o ⁡ ( n ) k(c_{\rm ind})^{n+o(n)} independent sets, and • there is a sequence ( G n ) n ∈ ℕ (G_{n})_{n\in{\mathbb{N}}} of graphs with G n G_{n} d d -regular on n n vertices ( d ≤ n / 2 d\leq n/2 ) and with maximum independent set size at most α \alpha , with α / n → c ind \alpha/n\rightarrow c_{\rm ind} as n → ∞ n\rightarrow\infty and with G n G_{n} having at least k ​ ( c ind ) n + o ⁡ ( n ) k(c_{\rm ind})^{n+o(n)} independent sets. We also consider the regime 1 / 2 < c ind < 1 1/2<c_{\rm ind}<1 . Here for each 0 < c deg ≤ 1 − c ind 0<c_{\rm deg}\leq 1-c_{\rm ind} we exhibit a constant k ⁡ ( c ind , c deg ) k(c_{\rm ind},c_{\rm deg}) for which an analogous pair of statements can be proven, except that in each case we add the condition d / n → c deg d/n\rightarrow c_{\rm deg} as n → ∞ n\rightarrow\infty . Our upper bounds are based on graph container arguments, while our lower bounds are constructive.

A much older variant of the extremal enumerative question for independent sets involves putting an upper bound on the independence number of
G
. Denote by

The main point of this paper is to consider what happens when the two restrictions discussed above — regularity and upper bound on the size of the maximum independent set — are combined.

Say that a graph is an

-graph if it is an

-graph and has largest independent size at most

We also note that if

All bipartite

Sapozhenko

Kirsch and Radcliffe
[
14
]
have considered the problem of maximizing the number of cliques (in fact, the number of cliques of each given size) in graphs with bounded maximum degree and with bounded clique number. Taking graph complements, this is the same as bounding the number of independent sets in a graph, in the presence of a lower bound on degrees, and an upper bound on the size of the maximum independent set. One of their main results (
[
14
, Theorem 3.6]
) gives asymptotically matching upper and lower bounds on the maximum number of independent sets (of each fixed size) in such graphs. A key difference between our work here, and the work of Kirsch and Radcliffe, is that Kirsch and Radcliffe require the size of the largest independent set to be absolutely bounded in order to obtain asymptotically tight results, whereas here we are interested mostly in the case where the size of the largest independent set grows with the number of vertices.

G

Another ingredient in the proof is a result of Zykov
[
24
]
(Theorem
3.2
below, alluded to in the introduction) that generalizes Turán’s Theorem. For integers
\alpha
and
n
with
1\leq\alpha\leq n
, the
Zykov graph

Z(n,\alpha)
is the disjoint union of
\alpha
cliques, as near equal in size as possible. Note that the graph complement of
Z(n,\alpha)
is the
n
-vertex Turán graph with
\alpha
classes — the complete multipartite graph on
n
vertices with
\alpha
partite classes, as near equal in size as possible. If
\alpha
divides
n
then
Z(n,\alpha)
is the disjoint union of
\alpha
cliques of size
n/\alpha
. Otherwise,
Z(n,\alpha)
consists of
\alpha\left\lceil n/\alpha\right\rceil-n
cliques of size
\left\lfloor n/\alpha\right\rfloor
and
n-\alpha\left\lfloor n/\alpha\right\rfloor

cliques of size
\left\lceil n/\alpha\right\rceil
.

For a positive integer
t
and a graph
G
denote by
i_{t}(G)
the number of independent sets in
G
of size
t
.

Theorem 3.2

(
[
24
]
)
.

Let
G
be a graph on
n
vertices with maximum independent set size at most
\alpha
. We have

i(G)\leq i(Z(n,\alpha))

and more generally for all
1\leq t\leq n
we have

i_{t}(G)\leq i_{t}(Z(n,\alpha)).

Setting
t=2
and taking graphs complements, Theorem
3.2
reduces to Turán’s Theorem.

Now let
G
be an
(n,d,\alpha)
-graph. By Lemma
3.1
there is a set
{\mathcal{D}}
of size at most
\sum_{i\leq n/\varphi}\binom{n}{i}
such that each independent set in
G
is contained in some
D\in{\mathcal{D}}
, and so is an independent set in the subgraph
G[D]
of
G
induced by
D
. Since any induced subgraph of
G
inherits the property from
G
that its maximum independent set size is at most
\alpha
, we have from Theorem
3.2
that for any such
D

i(G[D])\leq i(Z(|D|,\alpha))\leq i(Z(\left\lfloor nd/(2d-\varphi)\right\rfloor,\alpha)).

(3)

The second inequality in (
3
) above follows from that fact that
|D|\leq\left\lfloor nd/(2d-\varphi)\right\rfloor
for all
D\in{\mathcal{D}}
, and from a simple monotonicity observation regarding
i(Z(\cdot,\alpha))
. In (
3
) we use only the first inequality from Lemma
3.3
below; the second inequality will be useful later.

Lemma 3.3
.

For any
n
and
\alpha
with
1\leq\alpha\leq n
, and any positive integer
k
,

i(Z(n,\alpha))\leq i(Z(n+k,\alpha))\leq(3/2)^{k}i(Z(n,\alpha)).

Proof.

The structural difference between
Z(n+1,\alpha)
and
Z(n,\alpha)
is that one of the smaller cliques (one of the cliques of size
\left\lfloor n/\alpha\right\rfloor
) in
Z(n,\alpha)
becomes a clique of size
\left\lfloor n/\alpha\right\rfloor+1
in
Z(n+1,\alpha)
. This implies that

i(Z(n+1,\alpha))=\frac{(2+\left\lfloor n/\alpha\right\rfloor)}{(1+\left\lfloor n/\alpha\right\rfloor)}i(Z(n,\alpha)).

(4)

The right-hand inequality of the lemma now follows by induction from (
4
) and from the fact that
(2+x)/(1+x)\leq 3/2
for
x\geq 1
. The left-hand inequality of the lemma follows by induction from (
4
) and from the fact that
(2+x)/(1+x)\geq 1
for
x>-1
.
∎

We have obtained

i(G)\leq\left(\sum_{i\leq n/\varphi}\binom{n}{i}\right)i(Z(\left\lfloor nd/(2d-\varphi)\right\rfloor,\alpha)).

(5)

In the sequel we will select a value for
\varphi
that is both
\omega(1)
and
o(d)
as
d\rightarrow\infty
. With this choice of
\varphi
we have

\displaystyle\sum_{i\leq n/\varphi}\binom{n}{i}

\displaystyle\leq

\displaystyle\sum_{i\leq n/\varphi}\frac{n^{i}}{i!}

(6)

\displaystyle=

\displaystyle\sum_{i\leq n/\varphi}\frac{(n/\varphi)^{i}}{i!}\varphi^{i}

\displaystyle\leq

\displaystyle e^{n/\varphi}\varphi^{n/\varphi}

\displaystyle\leq

\displaystyle 2^{O\left(\frac{n\log\varphi}{\varphi}\right)}

and

\displaystyle\left\lfloor\frac{nd}{2d-\varphi}\right\rfloor

\displaystyle\leq

\displaystyle\frac{n}{2}+O\left(\frac{n\varphi}{d}\right).

(7)

From (
7
) and the left-hand inequality in Lemma
3.3
we have

i(Z(\left\lfloor nd/(2d-\varphi)\right\rfloor,\alpha))\leq i(Z(\left\lfloor n/2+O(n\varphi/d)\right\rfloor,\alpha)).

(8)

Applying the right-hand inequality of Lemma
3.3
to (
8
) we obtain

i(Z(\left\lfloor nd/(2d-\varphi)\right\rfloor,\alpha))\leq i(Z(\left\lfloor n/2\right\rfloor,\alpha))2^{O\left(\frac{n\varphi}{d}\right)}.

(9)

Inserting (
6
) and (
9
) into (
5
) we get

i(G)\leq i(Z(\left\lfloor n/2\right\rfloor,\alpha))2^{O\left(\frac{n\log\varphi}{\varphi}+\frac{n\varphi}{d}\right)}.

Setting
\varphi=\left\lfloor\sqrt{d\log d}\right\rfloor
we obtain Theorem
2.1
.

3.1.2
Deriving
UB1
from Theorem
2.1

We now study the behavior of
i(Z(\left\lfloor n/2\right\rfloor,\alpha))
, in order to derive

from Theorem
2.1
. Our goal is to establish the following lemma.

Lemma 3.4
.

i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))=k(c_{\rm ind})^{n+o(n)}

when
\alpha_{n}=c_{\rm ind}n+o(n)
as
n\rightarrow\infty
, where recall

k(c_{\rm ind})=\begin{cases}\left(1+\frac{1}{2c_{\rm ind}}\right)^{c_{\rm ind}}&\text{if }1/(2c_{\rm ind})\text{ is an integer}\\
\left(1+\left\lfloor\frac{1}{2c_{\rm ind}}\right\rfloor\right)^{c_{\rm ind}\left\lceil\frac{1}{2c_{\rm ind}}\right\rceil-1/2}\left(1+\left\lceil\frac{1}{2c_{\rm ind}}\right\rceil\right)^{1/2-c_{\rm ind}\left\lfloor\frac{1}{2c_{\rm ind}}\right\rfloor}&\text{otherwise.}\end{cases}

Proof.

Recall that if
\alpha
divides
N
then
Z(N,\alpha)
is the disjoint union of
\alpha
cliques of size
N/\alpha
. Otherwise,
Z(N,\alpha)
consists of
\alpha\left\lceil N/\alpha\right\rceil-N
cliques of size
\left\lfloor N/\alpha\right\rfloor
and
N-\alpha\left\lfloor N/\alpha\right\rfloor

cliques of size
\left\lceil N/\alpha\right\rceil
. It follows that for arbitrary
n
and
\alpha
we have

i(Z(\left\lfloor n/2\right\rfloor,\alpha))=\begin{cases}\left(1+\frac{\left\lfloor n/2\right\rfloor}{\alpha}\right)^{\alpha}&\text{if }\alpha\mid\left\lfloor n/2\right\rfloor\\
\left(1+\left\lfloor\frac{\left\lfloor n/2\right\rfloor}{\alpha}\right\rfloor\right)^{\alpha\left\lceil\frac{\left\lfloor n/2\right\rfloor}{\alpha}\right\rceil-\left\lfloor\frac{n}{2}\right\rfloor}\left(1+\left\lceil\frac{\left\lfloor n/2\right\rfloor}{\alpha}\right\rceil\right)^{\left\lfloor\frac{n}{2}\right\rfloor-\alpha\left\lfloor\frac{\left\lfloor n/2\right\rfloor}{\alpha}\right\rfloor}&\text{otherwise.}\end{cases}

A useful observation in all of what follows is that
\alpha_{n}=c_{\rm ind}n+o(n)
(together with
\left\lfloor n/2\right\rfloor=n/2+o(1)
) implies that

\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}=\frac{1}{2c_{\rm ind}}+o(1).

(10)

We consider first the case when
1/(2c_{\rm ind})
is an integer. By (
10
) we may assume that
n
is large enough that

\frac{1}{2c_{\rm ind}}-\frac{1}{3}\leq\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}\leq\frac{1}{2c_{\rm ind}}+\frac{1}{3}

(
1/3
is quite arbitrary here — anything strictly less than
1
will do).

We treat three subcases — first
\left\lfloor n/2\right\rfloor/\alpha_{n}=1/(2c_{\rm ind})
, then
\left\lfloor n/2\right\rfloor/\alpha_{n}>1/(2c_{\rm ind})
, and finally
\left\lfloor n/2\right\rfloor/\alpha_{n}<1/(2c_{\rm ind})
.

•

If
\left\lfloor n/2\right\rfloor/\alpha_{n}=1/(2c_{\rm ind})
(so
\alpha_{n}
divides
\left\lfloor n/2\right\rfloor
) we have immediately

i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))=\left(1+\frac{1}{2c_{\rm ind}}\right)^{c_{\rm ind}n+o(n)}=k(c_{\rm ind})^{n+o(n)}.

•

If
\left\lfloor n/2\right\rfloor/\alpha_{n}>1/(2c_{\rm ind})
then we have

\left\lfloor\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}\right\rfloor=\frac{1}{2c_{\rm ind}}~~~\mbox{and}~~~\left\lceil\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}\right\rceil=1+\frac{1}{2c_{\rm ind}}.

This, together with
\left\lfloor n/2\right\rfloor=n/2+o(1)
says that

\displaystyle i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))

\displaystyle=

\displaystyle\left(1+\frac{1}{2c_{\rm ind}}\right)^{(c_{\rm ind}n+o(n))(1/(2c_{\rm ind})+1)-(n/2)+o(1)}

(11)

\displaystyle~~~~~~~~~~~~~~~~~~\times\left(2+\frac{1}{2c_{\rm ind}}\right)^{n/2+o(1)-(c_{\rm ind}n+o(n))/(2c_{\rm ind})}

\displaystyle=

\displaystyle\left(1+\frac{1}{2c_{\rm ind}}\right)^{c_{\rm ind}n+o(n)}

\displaystyle=

\displaystyle k(c_{\rm ind})^{n+o(n)},

the main point being that the second term on the right-hand side of (
11
) collapses to
2^{o(n)}
.

•

If
\left\lfloor n/2\right\rfloor/\alpha_{n}<1/(2c_{\rm ind})
then we have

\left\lfloor\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}\right\rfloor=\frac{1}{2c_{\rm ind}}-1~\mbox{and}~\left\lceil\frac{\left\lfloor n/2\right\rfloor}{\alpha_{n}}\right\rceil=\frac{1}{2c_{\rm ind}},

and again we get
i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))=k(c_{\rm ind})^{n+o(n)}
(this time because the first term in the analog of (
11
) collapses).

So in this case (
1/(2c_{\rm ind})
an integer) we always have
i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))=k(c_{\rm ind})^{n+o(n)}
, as claimed.

Next we consider the case where
1/(2c_{\rm ind})
is not an integer. By (
10
) we may assume that
n
is large enough that
\left\lfloor n/2\right\rfloor/\alpha_{n}
and
1/(2c_{\rm ind})
share the same floor and the same ceiling, and that moreover
\alpha_{n}
does not divide
\left\lfloor n/2\right\rfloor
. We have immediately that

\displaystyle i(Z(\left\lfloor n/2\right\rfloor,\alpha_{n}))

\displaystyle=

\displaystyle\left(1+\left\lfloor\frac{1}{2c_{\rm ind}}\right\rfloor\right)^{(c_{\rm ind}n+o(n))\left\lceil\frac{1}{2c_{\rm ind}}\right\rceil-n/2+o(1)}

\displaystyle~~~~~~~~~~~~~~~~~~\times\left(1+\left\lceil\frac{1}{2c_{\rm ind}}\right\rceil\right)^{n/2+o(1)-(c_{\rm ind}n+o(n))\left\lfloor\frac{1}{2c_{\rm ind}}\right\rfloor}

\displaystyle=

\displaystyle k(c_{\rm ind})^{n+o(n)}.

∎

This completes the derivation of
UB1
from Theorem
2.1

5

In this section we establish

(and

). As with Section

(n,d,\alpha)

as an induced subgraph. We don’t quite achieve this goal, but we cover enough ground to deduce

.

We have two constructions, covering different ranges of

. In Section
5.3
we consider
2n/3\lessapprox d<n
and in Section
5.4
we describe a construction valid for

for all claimed values of

and

Both constructions will start with two disjoint copies of

we commit to adding no more edges, thus ensuring that

appears as an induced subgraph. Finally we add edges inside the other copy of

, inside the remaining set of

\alpha
.

is an
(n-d)
-regular graph with independence number
\alpha
. To see that the independence number is
\alpha
, note that there is an independent set of size
\alpha
in each of the copies of

, and there can be no larger independent set contained completely within
X
or completely within
Y
. Suppose that an independent set includes vertices from both
X
and
Y
. If
x\in X_{i}
is in the independent set, then the vertices from
Y
must come from
Y_{i}
, and there can be at most one such, say
y
. It is an easy check that
\{x,y\}
cannot be extended as an independent set inside
X\cup Y
. Finally, recall from the introduction that we are assuming
\alpha\geq 2
.

5.2
Preliminary regular graph constructions

To aid in the two constructions of
G(n,d,\alpha)
, in addition to
G_{1}(n,d,\alpha)
we will make use of two closely related families of regular graphs, defined below. In each case the graphs are described on vertex set
\{v_{0},\ldots,v_{m-1}\}
(of size
m
) and are
r
-regular.

•

R(m,r)
:

–

If
r
is even, then
v_{i}v_{j}
is an edge if and only if
i-j\in[1,r/2]\cup[-r/2,-1]\pmod{m}
, and

–

if
r
is odd (and so
m
is even), then
v_{i}v_{j}
is an edge if and only if either
i-j\in[1,(r-1)/2]\cup[-(r-1)/2,-1]\pmod{m}
or
i-j=m/2\pmod{m}
.

In other words, with the vertices arranged cyclically each vertex is adjacent to an equal number of vertices immediately to its right and immediately to its left, and also (if necessary) to a single vertex immediately opposite it.

•

R(m,r,g)
:

–

If
r
is even, then
v_{i}v_{j}
is an edge if and only if
i-j\in[g+1,g+r/2]\cup[-g-r/2,-g-1]\pmod{m}
, and

–

if
r
is odd (and so
m
is even), then
v_{i}v_{j}
is an edge if and only if either
i-j\in[g+1,g+(r-1)/2]\cup[-g-(r-1)/2,-g-1]\pmod{m}
or
i-j=m/2\pmod{m}
.

In other words, with the vertices arranged cyclically each vertex is adjacent to an equal number of vertices immediately to its right and immediately to its left, not including the
g
vertices nearest it on either side, and also (if necessary) to a single vertex immediately opposite it. Note that a necessary condition here for this graph to actually be
r
-regular is that
g+\left\lfloor r/2\right\rfloor\leq m/2-1
.

Note that
R(m,r,0)
is simply
R(m,r)
.

Lemma 5.1
.

Let
\alpha(G)
denote the independence number of a graph
G
. We have:

\alpha(R(m,r))\leq\left\lceil\frac{m}{1+\left\lfloor r/2\right\rfloor}\right\rceil

(13)

and more generally

\alpha(R(m,r,g))\leq(g+1)\left\lceil\frac{m}{g+1+\left\lfloor r/2\right\rfloor}\right\rceil.

(14)

Proof.

We only consider (
14
) since this reduces to (
13
) when
g=0
.

Suppose
I\subset\{v_{0},\ldots,v_{m-1}\}
is an independent set in
R(m,r,g)
. If
v_{i}\in I
, then
S_{i}:=\{v_{i},\ldots,v_{i+g+\left\lfloor r/2\right\rfloor\pmod{m}}\}
forms a set of
1+g+\left\lfloor r/2\right\rfloor
consecutive vertices of which at most
g+1
are in
I
(specifically,
v_{i},\ldots,v_{i+g\pmod{m}}
). It immediately follows that

\alpha(R(m,r,g))\leq(g+1)\left\lceil\frac{m}{g+1+\left\lfloor d/2\right\rfloor}\right\rceil.

∎

5.3
A construction for
2n/3\lessapprox d<n

Theorem 5.2
.

Fix
n,d
and
\alpha
with
2n/3\leq d<n
,
nd
even,

\left\lceil\frac{2d-n}{1+\left\lfloor\frac{3d-2n}{2}\right\rfloor}\right\rceil\leq\alpha,

(15)

and
\alpha\leq n-d
. There is an
(n,d,\alpha)
-graph
G(n,d,\alpha)
that has
Z(n-d,\alpha)
as an induced subgraph.

Note that if
d=2n/3
then (
15
) becomes
\alpha\geq\left\lceil n/3\right\rceil
. Since the largest independent set in an
(n,2n/3)
-graph has size at most
n/3
, it follows that for this choice of
d
Theorem
5.2
gives no information. On the other hand if
d=(2/3+\Omega(1))n
then (
15
) becomes
\alpha\geq\Omega(1)
, and so (given that we are considering the situation where
\alpha
and
d
scale linearly with
n
) Theorem
5.2
conveys useful information. This explains the
d\gtrapprox 2n/3
in the section title.

Proof.

(Proof of Theorem
5.2
.)
We begin our construction with
G_{1}(n,d,\alpha)
, as described in Section
5.1
. Noting that

•

the evenness of
nd
implies that
(2d-n)(3d-2n)=6d^{2}-7nd+2n^{2}
is even,

•

that
d\geq 2n/3
implies
3d-2n\geq 0
, and

•

that
d<n
implies
2d-n>3d-2n
,

we see that the graph
R(2d-n,3d-2n)
exists. We add edges to
W
so that
W
induces a copy of
R(2d-n,3d-2n)
, and we add all edges of the form
uw
where
u\in X\cup Y
and
w\in W
. Call the resulting graph
G(n,d,\alpha)
.

The degree of each vertex in
X\cup Y
is
(n-d)+(2d-n)=d
, and the degree of each vertex in
W
is
(3d-2n)+2(n-d)=d
, so
G(n,d,\alpha)
is
d
-regular. The subgraphs induced by both
X
and
Y
are isomorphic to
Z(n-d,\alpha)
. There are no independent sets in
G(n,d,\alpha)
that use vertices from both
X\cup Y
and
W
, and, as observed in Section
5.1
there is no independent set of size greater than
\alpha
in
X\cup Y
. So to show that
G
is an
(n,d,\alpha)
-graph it remains to show that there is no independent set of size greater than
\alpha
in
W
.
By (
13
) we have

\alpha(R(2d-n,3d-2n))\leq\left\lceil\frac{2d-n}{1+\left\lfloor\frac{3d-2n}{2}\right\rfloor}\right\rceil,

and this is at most
\alpha
by (
15
).

5.4
A construction for
n/2\leq d\lessapprox n

As we will see in Section
5.5
, the construction of this section is enough to establish
LB3
. But this construction has a somewhat unsatisfying gap when
d
is close to
n
; we therefore have included the simpler construction of Section
5.3
to close this gap.

Theorem 5.3
.

Fix
n,d
and
\alpha
with
n/2\leq d<n
,
nd
even,

\left\lceil\frac{n-d}{\alpha}\right\rceil+\left\lfloor\frac{2d-n}{2}\right\rfloor\leq\frac{d}{2}-1,

(16)

\left(\left\lceil\frac{n-d}{\alpha}\right\rceil+1\right)\left\lceil\frac{d}{\left\lceil\frac{n-d}{\alpha}\right\rceil+1+\left\lfloor\frac{2d-n}{2}\right\rfloor}\right\rceil\leq\alpha,

(17)

and
\alpha\leq n-d
. There is an
(n,d,\alpha)
-graph
G(n,d,\alpha)
that has
Z(n-d,\alpha)
as an induced subgraph.

Note that as
n\rightarrow\infty
with
\alpha,d=\Theta(n)
(as is the situation in
LB3
), the bound (
17
) is immediate (it becomes
\alpha\geq\Omega(1)
), and (
16
) becomes
d\leq n-o(1)
, justifying the
d\lessapprox n
in the title of this section.

Proof.

(Proof of Theorem
5.3
.)
As in Section
5.3
we start out with
G_{1}(n,d,\alpha)
. We then put a complete bipartite graph between
Y
and
W
. This ensures that all vertices in
Y
have degree
(n-d)+(2d-n)=d
, while all vertices in
X\cup W
have degree
n-d
. We will complete the construction by putting the edges of a
(2d-n)
-regular graph on the vertex set
X\cup W
(a set of size
d
), that doesn’t use any of the currently used edges. Specifically we we add the edges of a copy of
R(d,2d-n,\left\lceil(n-d)/\alpha\right\rceil)
, where the vertices of
X\cup W
are labeled so that
v_{0},\ldots,v_{|X_{1}|-1}
are the vertices in
X_{1}
, the next
|X_{2}|
indices cover the vertices in
X_{2}
, and so on, with the final
2d-n
indices covering
W
.

Note that
2d-n\geq 0
(since
d\geq n/2
) and
2d-n<d
(since
d<n
), and that the evenness of
d(2d-n)
follows from the evenness of
nd
, so a
(d,2d-n)
-graph exists. To specifically ensure that
R(d,2d-n,\left\lceil(n-d)/\alpha)\right\rceil)
exists, we also need the condition that

\left\lceil\frac{n-d}{\alpha}\right\rceil+\left\lfloor\frac{2d-n}{2}\right\rfloor\leq\frac{d}{2}-1,

which is (
16
).

Next we check that adding the edges of
R(d,2d-n,\left\lceil(n-d)/\alpha)\right\rceil)
to
X\cup Y
does not create a duplicate edge (recall that inside
X
there are already the edges of
Z(n-d,\alpha)
). We use that in
R(d,2d-n,\left\lceil(n-d)/\alpha)\right\rceil)
, on either side of each vertex in the cyclic ordering
v_{0},\ldots,v_{m-1}
, there is a collection of
\left\lceil(n-d)/\alpha\right\rceil
consecutive vertices that the vertex is not adjacent to. So, noting that the pre-existing edges in
X
form cliques on consecutive vertices of orders
\left\lfloor(n-d)/\alpha\right\rfloor
and
\left\lceil(n-d)/\alpha\right\rceil
, we have our required condition by the choice of
g=\left\lceil(n-d)/\alpha\right\rceil
.

We have completed our construction of a graph
G(n,d,\alpha)
that is
d
-regular and on
n
vertices, and that has
Z(n-d,\alpha)
as an induced subgraph (the subgraph induced by
Y
).

We finally need to check that
G(n,d,\alpha)
has no independent set of size greater than
\alpha
. As before, any independent set that includes some vertices from
Y
has size at most
\alpha
. And any independent set drawn fully from
X\cup W
is an independent set in
R(d,2d-n,\left\lceil(n-d)/\alpha\right\rceil)
, and so by (
14
) has size at most

\left(\left\lceil\frac{n-d}{\alpha}\right\rceil+1\right)\left\lceil\frac{d}{\left\lceil\frac{n-d}{\alpha}\right\rceil+1+\left\lfloor\frac{2d-n}{2}\right\rfloor}\right\rceil.

That this is at most
\alpha
comes from (
17
).
∎

Here we establish
LB3
. Recall that we are given
1/2\leq c_{\rm deg}<1
and

, and that (as observed after the statement of Theorem

), in the presence of Theorem

we may assume that

.

Let

be the set of even numbers (so that for
n\in N
we can be sure that

is always even). Let
(d_{n})_{n\in N}
be any sequence of integers such that

as

(\alpha_{n})_{n\in N}
be any sequence of integers such that
\alpha_{n}/n\rightarrow c_{\rm ind}

).
For all sufficiently large

16
) and (

5.3
shows that there is an

the equality coming from (

6
Discussion and open questions

We have established two approximate results. First, for each
0<c_{\rm ind}\leq 1/2
we have found a constant
k(c_{\rm ind})
with the following property: the greatest number of independent sets admitted by an
n
-vertex
d
-regular graph with maximum independent set size at most
\alpha
, where
\alpha\sim c_{\rm ind}n
,
d\lesssim n/2
and
d=\omega(1)
, is
k(c_{\rm ind})^{n+o(n)}
. Second, for each
1/2\leq c_{\rm deg}<1
and
0<c_{\rm ind}\leq 1-c_{\rm deg}
we have found a constant
k(c_{\rm ind},c_{\rm deg})
with the following property: the greatest number of independent sets admitted by an
n
-vertex
d
-regular graph with maximum independent set size at most
\alpha
, where
\alpha\sim c_{\rm ind}n
and
d\sim c_{\rm deg}n
, is
k(c_{\rm ind},c_{\rm deg})^{n+o(n)}
.

Both of these results are in the spirit of Granville’s conjecture (
1
) and Alon’s resolution of the same, for independent sets in
n
-vertex,
d
-regular graphs. An open problem is to obtain a more precise result, in the spirit of Kahn and Zhao’s strengthening of (
1
) to the statement that if
G
is an
n
-vertex,
d
-regular graph with
2d
dividing
n
, then
i(G)\leq i(G_{n,d})
, where
G_{n,d}
is the disjoint union of
n/(2d)
copies of
K_{d,d}
.

Question 6.1
.

Let
(n,d,\alpha)
be a triple for which
n
-vertex,
d
-regular graphs with maximum independent set sizes at most
\alpha
exist. Which such graph admits the most independent sets?

There is an even more fundamental open problem in this direction. As observed earlier, the bound
i(G)\leq i(G_{n,d})
for
n
-vertex
d
-regular graphs is tight when
2d|n
and
d\leq n/2
; but when
d>n/2
it is far from tight. In Claim
1.2
we have established that

i(G)\leq 2^{n-d+\log_{2}n}

for
n
-vertex
d
-regular graphs
G
with
n/2<d<n
and
nd
even, and shown that there are examples of
n
-vertex
d
-regular graphs
G
with
n/2<d<n
and
nd
even that satisfy
i(G)\geq 2^{n-d}
. But it is open to identify, for each pair
(n,d)
with
n/2<d<n
and
nd
even, the specific
n
-vertex
d
-regular graph that maximizes the number of independent sets. A conjecture has recently been made by Cambie, Goedgebeur and Jooken
[
2
]
:

Conjecture 6.2
.

Let
n
and
d
with
nd
even satisfy
n\geq 1
and
d+1\leq n\leq 2d
. Among
n
-vertex
d
-regular graphs, the graph maximizing
i(G)
is the mutual join of copies of
E_{n-d}
and a graph
H
whose order is strictly less than
2(n-d)
.

Another direction to pursue is to consider not the total count of independent sets, but the number of independent sets of various fixed sizes. For
n
-vertex
d
-regular graphs this is a well-studied problem, with the best results to date due to Davies, Jenssen and Perkins
[
5
]
. The techniques of this paper can easily be used to give some results in this direction for
n
-vertex
d
-regular graphs with maximum independent set size at most
\alpha
, owing to the fact that Zykov’s Theorem (Theorem
3.2
) addresses independent set of each fixed size. For example,

•

for each
0<c_{\rm ind}\leq 1/2
and
0<t\leq c_{\rm ind}
we can exhibit an optimal constant
k(c_{\rm ind},t)
such that the maximum number of independent sets of size
tn+o(n)
in an
n
-vertex,
d
-regular graph with maximum independent size at most
\alpha
, where
\alpha=c_{\rm ind}n+o(n)
, is
k(c_{\rm ind},t)^{n+o(n)}
, and

•

for each
1/2\leq c_{\rm deg}<1
,
0<c_{\rm ind}\leq 1-c_{\rm deg}
and
0<t\leq c_{\rm ind}
we can exhibit an optimal constant
k(c_{\rm ind},c_{\rm deg},t)
such that the maximum number of independent sets of size
tn+o(n)
in an
n
-vertex,
d
-regular graph with maximum independent size at most
\alpha
, where
d=c_{\rm deg}n+o(n)
and
\alpha=c_{\rm ind}n+o(n)
, is
k(c_{\rm ind},c_{\rm deg},t)^{n+o(n)}
.

We omit the details.

A final open question concerns our constructions in Section

and

Question 6.3
