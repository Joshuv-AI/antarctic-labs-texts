Dynamic teaching path generation for quadruped robot programming by integrating R-GCN and SBERT
Authors: Hualiang Wu
Published: 2026

ABSTRACT
To address the problems of knowledge circular dependency and learning path ambiguity in quadruped robot programming learning, a dynamic teaching path generation method that integrates structural and semantic information is proposed. A domain knowledge graph covering core knowledge and prerequisite relationships is constructed. R-GCN (Relational Graph Convolutional Network) is used to generate structured node embeddings through link prediction tasks. SBERT (Sentence-Bidirectional Encoder Representations from Transformers) is also used to generate semantic vector representations of knowledge points and user tasks. For a given programming task, seed nodes are retrieved based on semantic similarity, and a priori knowledge subgraph is constructed by back-tracing. The number of seed nodes is fixed to the top 5 knowledge points ranked by semantic similarity. The similarity threshold is implicitly determined by this ranking strategy rather than a fixed value. The weighting coefficients used in edge scoring and node prioritization are set to α = 0.6 and β = 0.7 based on validation experiments described in Sect. 2.4 and 2.5. All models are implemented using PyTorch and trained on a single NVIDIA RTX 3090 GPU. The batch size is set to 512, and early stopping is applied based on validation loss with a patience of 10 epochs. Relationship strength is quantified by calculating the dot product of the embedding vectors, automatically identifying and pruning the weakest links in circular dependencies to achieve intelligent link breaking. During topological sorting, nodes with high semantic match to the task are prioritized for learning path generation. Experiments show that the proposed method achieves superior performance in the quadruped robot programming task, with a Top-3 score of 0.88, higher than CompGCN’s 0.73, a mean reciprocal rank of 0.68, and path integrity and structural rationality reaching 0.85 and 0.88, respectively. This method performs well in knowledge association modeling and path recommendation, effectively supports structured, task-driven programming teaching, and provides cognitively coherent learning support for beginners.

Introduction

As an important branch of intelligent robotics research, quadruped robots have been widely used in education, scientific research, and engineering practice. The programming learning process is directly related to the depth and efficiency of learners’ mastery of core technologies such as motion control, sensory fusion, and task planning. Programming instruction not only requires learners to master grammar and logical structure but also involves a knowledge system of algorithm design, modular programming, and system integration. Knowledge points are highly dependent and progressive1–3. Without a reasonable learning path, learners are prone to knowledge gaps or path redundancy during cognitive structure construction, which reduces learning effectiveness4,5. Constructing dynamic, reasonable, and task-driven learning paths is crucial for improving programming teaching quality and promoting cognitive continuity6,7.

The main difficulties currently faced in quadruped robot programming instruction lie in the complexity of relationships between knowledge points and the ambiguity of learning paths. Although knowledge graphs can depict prerequisite dependencies, they suffer from circular dependencies in complex multi-relationship scenarios, making path generation instability8–10. In task-oriented learning, learners often find it difficult to quickly locate the starting node relevant to the task from a large set of knowledge points, which affects learning efficiency11,12. Existing path generation methods generally rely on manually set rules or static topological relationships and lack a mechanism for dynamically adjusting paths based on the task, making it difficult to meet the needs of personalized learning and task-oriented instruction13–15.

Existing research has attempted to address these issues to some extent. Traditional knowledge representation methods such as Node2Vec model graph structures through random walks, but do not consider multi-relational information and have limited expressive power16,17. Graph neural network-based methods such as GCN (Graph Convolutional Network) and GAT (Graph Attention Network) can extract structural features using graph convolution, but their performance is insufficient when processing multi-relational knowledge graphs18–20. Relational expansion models such as CompGCN (Composition-based GCN) improve representational capabilities by jointly modeling relations and nodes. Knowledge graph embedding methods such as TransE (Translating Embeddings for Modeling Multi-relational Data) and RotatE (Rotational Embedding) have advantages in multi-relational embedding, but they focus on static link prediction and lack guidance for path generation21,22. The latest path modeling method, TIGT (Transformer-based Inductive Graph Transformer), emphasizes task-related path reasoning but still has shortcomings in handling circular dependencies and semantic matching. These methods have failed to effectively address the problems of knowledge circular dependencies and the lack of task relevance of learned paths.

To address the issues of knowledge circular dependencies and insufficient task semantic alignment, this paper proposes a dynamic teaching path generation method that integrates structural and semantic information. In the knowledge representation stage, a domain knowledge graph covering the core knowledge and prerequisites of quadruped robot programming is constructed. Link prediction is performed using R-GCN to generate structured embeddings. In the semantic modeling stage, SBERT is used to convert knowledge point text and user-entered programming tasks into high-dimensional semantic vectors, which serve as the basis for determining task relevance. In the path construction stage, seed nodes are retrieved based on semantic similarity and then reversely expanded based on prerequisite dependencies to form task-related subgraphs. In the dependency resolution stage, loops are detected on the generated subgraphs. Edge importance is comprehensively assessed using the embedding dot product and semantic similarity, automatically pruning the weakest dependencies and eliminating closed loops. In the path generation stage, acyclic subgraphs are topologically sorted, and a semantic priority mechanism is applied in parallel node selection to ensure that the sorting results both meet cognitive laws and closely align with task requirements. This method organically integrates structural embedding, semantic matching, and path generation, providing a new approach for constructing task-driven, dynamically adaptive, and cognitively rational learning paths.

Algorithm design

Domain knowledge graph construction and representation learning

In quadruped robot programming instruction, complex prerequisite dependencies exist between knowledge points. Without clear structured modeling, the learning path suffers from circular dependencies and ambiguous hierarchies23–25. To solve this problem, core concepts, grammatical points, control logic, and task objectives in the programming field are organized based on three authoritative sources: the textbook Basic Principle and Development Tutorial of the Quadruped Bionic Robot (Tsinghua University Press, 2023), the Mobile Robots course (FSI-0MR) from Brno University of Technology, and the Robot Skill Graph (RSG) framework for methodological guidance. Knowledge points are defined as nodes, and prerequisite dependencies are defined as edges by a domain expert team through a Delphi consensus process, thereby constructing a domain knowledge graph26,27. The data used for knowledge graph construction are derived from three structured sources, including the designated textbook, formal course materials, and technical documentation associated with the Robot Skill Graph framework. All textual materials are preprocessed through unified segmentation, terminology normalization, and redundancy removal before annotation. The annotation protocol follows a two-stage procedure. In the first stage, two annotators independently identify knowledge points and prerequisite relationships according to a predefined annotation guideline. In the second stage, all inconsistent annotations are reviewed and resolved through expert discussion involving senior instructors with domain teaching experience. Only the annotations that reach full agreement are retained in the final knowledge graph, ensuring the consistency and reliability of the constructed dataset. This graph includes one-to-one prerequisite relationships and also covers complex many-to-many relationships, allowing subsequent path generation to cover the entire cognitive chain. Before constructing the graph, the knowledge text in the quadruped robot programming domain is segmented; stop words are removed; synonyms are merged. The resulting graph contains 312 knowledge point nodes and 864 prerequisite relationship edges, with six relationship types covering core content such as grammatical rules, control logic, sensor fusion, and motion planning.

After the knowledge graph modeling is completed, the nodes need to be embedded in the vector space to capture the structural characteristics of multi-type dependency relationships. The relational graph convolutional network is used to model the multi-relational graph, and the structural representation of the knowledge points is achieved through neighbor aggregation and relation transformation. Semantic encoding of knowledge points and tasks

In the generation of dynamic teaching paths for quadruped robot programming, structured representation ensures the rationality of the dependencies between knowledge points. However, learning tasks are often input in natural language and require precise semantic matching with knowledge points in the knowledge graph. To this end, Sentence-BERT is used to encode knowledge point descriptions and user task texts to obtain a unified high-dimensional semantic representation. This method maps the text information of knowledge points to the vector space through the pre-trained language model and the semantic embedding mechanism of the double-tower structure, making similar tasks and related knowledge points closer in spatial distance.

Task-driven seed node identification and prioritization subgraph construction

After completing the structured embedding and semantic representation of knowledge points, it is necessary to associate user tasks with the knowledge graph to generate cognitively plausible learning subgraphs. The semantic similarity between tasks and knowledge points is the core criterion for retrieving seed nodes. After calculating semantic relevance scores and sorting them by score, a set of highly relevant nodes is selected as the seed node set. This set serves as the starting point for subgraph construction, ensuring that path generation is closely integrated with the learning task.

After obtaining the seed nodes, it is necessary to expand backward along the prioritization dependency relationships in the knowledge graph, recursively tracing back to the underlying knowledge points to form a subgraph that covers all the prior knowledge. The combination of task-driven semantic retrieval and hierarchical expansion of the graph structure ensures that the generated learning subgraph contains both task-related high-level knowledge and essential low-level concepts, thus ensuring the logical integrity of the learning path.

Circular dependency identification and intelligent breaking

In the pre-learning subgraph generated by task-driven expansion, closed loops often appear, where multiple knowledge points are interdependent. If left unaddressed, these circular dependencies prevent the path ordering from being in an ordered sequence, thus affecting the logical integrity of the teaching path. Therefore, loop detection and breaking operations are necessary to maintain the loop-free nature of the pre-learning subgraph.

Loop detection is achieved by decomposing the pre-learning subgraph into strongly connected components. During the loop elimination process, the edge with the smallest weight within the loop component is selected and pruned until all loops are broken. This not only ensures the acyclicity of the subgraph, but also maximizes the retention of task-related and structurally strong dependencies.

To verify the stability of the results, the random chain breaking method and the intelligent chain breaking method are run three times each, and their performance is recorded. The results show that random chain breaking fluctuates significantly across different runs, with instances of excessive chain breaks or missing paths. Semantic-guided path generation and sorting

After the circular dependency is processed, the pre-training subgraph has been transformed into a directed acyclic graph, and a teaching path that conforms to the learning logic needs to be generated through topological sorting. Traditional topological sorting relies only on structural information. When there are multiple candidate nodes that can be selected at the same time, it cannot reflect the relevance to the task. This method applies a semantic priority mechanism in the topological sorting process and adjusts the node selection order by the similarity score between the task semantic embedding and the knowledge point embedding, so that the generated path takes into account both cognitive rationality and task orientation.

Experiments and verification

Experimental design

The experimental design incorporates a rigorous validation process to demonstrate the effectiveness of the dynamic teaching path generation method combining R-GCN and SBERT. During the data preparation phase, a domain knowledge graph covering core knowledge points and prerequisite dependencies is constructed for quadruped robot programming, ensuring the integrity of the multi-relational topology. To create a representative test task set, fifty real-world programming tasks are selected and standardized as text input in the form of user requirement descriptions. The fifty programming tasks were collected from four instructional sources used in undergraduate quadruped robot programming education, including laboratory assignments, course project specifications, controller debugging exercises, and motion planning practice tasks. All tasks were rewritten into a unified natural language description format through terminology normalization and duplicate removal. The final dataset contains twelve motion control tasks, ten sensor fusion tasks, fourteen task planning tasks, eight system integration tasks, and six debugging and testing tasks. Each task description contains three mandatory fields: task objective, required robot capability, and expected control behavior. To ensure reproducibility, all task descriptions, preprocessing rules, node mapping records, and benchmark learning paths have been released as supplementary material together with the annotation guideline used during expert revision. The dataset identifiers and corresponding knowledge graph node indices are also provided in the supplementary file to support independent reconstruction of the experimental environment. To construct a reliable assessment benchmark, the research team employed a hybrid approach, developing a standard 20-step learning path for each of the fifty programming tasks. Each step in the standard learning path corresponds to one atomic knowledge point or one primitive programming operation that a learner must master. The atomic knowledge point is defined as a smallest teachable unit that cannot be further decomposed without losing its pedagogical meaning, such as “definition of a joint angle variable” or “syntax of a conditional branch in the quadruped control loop”. The primitive programming operation is defined as a single executable action in the robot programming environment, for example “calling the walk function” or “reading an IMU sensor value”. Every step is annotated with a unique identifier linking to the corresponding node in the constructed domain knowledge graph. The total number of steps varies across tasks because different programming tasks require different amounts of prerequisite knowledge, but for each task the path length is fixed to the number of knowledge points necessary to complete that task from the entry level. The 20-step length mentioned in the text refers to the average path length across all fifty tasks after normalization, where each path is truncated or padded to a uniform length of twenty steps using a no-operation placeholder for padding to enable fair comparison across tasks of different inherent complexity. The construction of the reference learning paths follows a controlled expert-driven protocol. The initial paths generated by the language model are treated as preliminary drafts. All drafts are independently reviewed and revised by multiple domain experts based on teaching logic and prerequisite dependency correctness. The final reference paths are determined through a consensus process among the experts, ensuring that each path strictly follows domain knowledge structure and instructional coherence. The role of the initial model-generated paths is limited to providing structural suggestions, while the final benchmark is fully validated and confirmed by human experts. First, a high-performance language model (Gemini) generated an initial learning path from the student learner’s perspective. Subsequently, three domain experts with over five years of experience in teaching quadrupedal robot programming independently reviewed and refined the generated paths. The expert panel reached a consensus to determine the final standard path. The consensus process followed a structured Delphi procedure. Each expert first independently reviewed the draft path generated by the language model and produced a revised version. The three revised versions were then submitted to a facilitator who compiled all differences between the versions without revealing the identity of the reviser. The compiled differences were sent back to the three experts for a second round of independent review, where each expert was asked to either keep their original revision or adopt one of the other versions for each conflicting step. After the second round, any remaining disagreement was resolved through a synchronous online meeting where the three experts discussed each disputed step based on the textbook syllabus and the prerequisite dependency rules defined in the knowledge graph. The final standard path was recorded only after all three experts verbally confirmed their acceptance of every step in the sequence. The entire procedure was documented, and the meeting minutes for all disputed steps are available as supplementary material. The complete benchmark construction records, task descriptions, expert revision logs, and final reference paths are publicly archived in the supplementary repository submitted together with the manuscript. Independent researchers can reproduce the benchmark generation process by following the released preprocessing protocol, annotation specification, and path validation procedure. The sequence overlap ratio is computed by aligning two paths step by step. For each position from one to twenty, if the knowledge point at that position is identical between the two paths, a match is counted. The sequence overlap ratio equals the total number of matched positions divided by twenty. This metric treats the learning path as an ordered list and directly measures positional agreement, which reflects how well two paths maintain the same sequential structure. The results of this consistency assessment are shown in Table 6. The table reports the mean, standard deviation, and range of sequence overlap ratios for each expert individually, as well as the average across the three experts. Across all 50 tasks, the average sequence overlap ratio reached 0.84, indicating a high degree of consistency in learning path ordering. This hybrid construction process ensured that the assessment benchmark reflected both pedagogical rationale and task relevance.

The experimental comparison setup encompasses various structural embedding methods to validate the structural modeling advantages of R-GCN in multi-relational knowledge graphs. The comparison methods include homogeneous graph embedding models Node2Vec, GCN, GAT, and GraphSAGE, and multi-relational graph embedding models CompGCN, TransE, RotatE, and the latest path modeling method TIGT. While maintaining consistency in the subgraph construction, circular dependency detection and pruning, and semantically guided ranking processes, R-GCN is replaced with the control models to generate node embeddings, and their outputs are directly used in subsequent steps to ensure consistent experimental conditions and comparable results.

The evaluation system consists of multiple metrics. Hits@K measures the model’s hit rate on key nodes when recommending the next learning point; the mean reciprocal rank reflects the overall quality of the correct knowledge point’s position in the ranking results; path integrity measures the extent to which the generated path fully covers the actual prerequisite knowledge; structural rationality assesses the topological consistency of the generated path with the standard path using normalized edit distance. Path integrity is defined as the ratio between the number of prerequisite knowledge nodes correctly covered in the generated path and the total number of prerequisite nodes in the reference path. Structural rationality is defined as one minus the normalized edit distance between the generated path sequence and the reference path sequence, where the edit distance is divided by the maximum path length to ensure comparability across tasks. All experiments are run using the same hardware and training hyperparameter configuration to ensure fair comparison of computing resources, training time, and parameter size. Each experiment is conducted over multiple independent runs with different random initializations, and the final results are reported using the mean and standard deviation of the evaluation metrics. In addition, statistical significance tests are applied to compare different methods, ensuring that the reported performance differences are consistent and reliable. Through these designs, the validation scheme systematically verifies the comprehensive performance of the proposed method in knowledge association modeling, loop structure resolution, semantic relevance ranking, and cross-model robustness, providing a reliable basis for subsequent results analysis.

Cross-task transfer evaluation

In the cross-task transfer experiment, to test the adaptability of the constructed path generation method in different data environments, the model is evaluated on two public datasets, Foursquare and Gowalla, comparing four core metrics: Hits@3, MRR, path integrity, and structural rationality. The experimental design maintains the same task scale and evaluation process, only varying the dataset source, to observe the performance fluctuations of the model in cross-task scenarios. For the Foursquare and Gowalla datasets, the original location check-in sequences are transformed into graph structures where each node represents a point of interest and each directed edge encodes a user transition between two locations. The task of predicting the next location a user visits is mapped to the task of predicting the next knowledge point in quadruped robot programming learning, as both require modeling sequential dependencies in a graph. The graph construction logic follows the same multi‑relational schema used for the programming domain: each edge is assigned a relation type derived from the category similarity of the two locations and the temporal order of check‑ins. The evaluation on these datasets serves to measure whether the proposed method maintains path prediction performance when applied to graph‑structured tasks from a different domain, using the same four metrics of Hits@3, mean reciprocal rank, path integrity, and structural rationality. The results are plotted as radar charts on the two datasets to visually demonstrate the performance differences between different models across multiple metrics, as shown in Fig. 7.

The same trend continues in the Gowalla dataset, with R-GCN and TIGT maintaining their lead. Models like GCN and GAT fall in the middle in terms of Hits@3 and integrity, while TransE and Node2Vec are generally in the lower range. Overall, these results suggest that models that can simultaneously model both structural and semantic relationships exhibit more stable generalization performance in cross-task transfer scenarios.

Conclusions

This paper proposes a dynamic teaching path generation method for quadruped robot programming by integrating R-GCN and SBERT. By constructing a multi-relational knowledge graph and incorporating semantic information, this method achieves task-driven learning path optimization. Experimental results show that this method achieves a Top-3 score of 0.88, compared to CompGCN’s 0.73, demonstrating the effectiveness of combining structural and semantic embeddings. The overall mean reciprocal rank score is 0.68, compared to Node2Vec’s 0.42, demonstrating its greater robustness and stability under multi-relational modeling. Path integrity and structural rationality scores of 0.85 and 0.88, respectively, surpass those of traditional methods such as GCN and GAT, ensuring the logical coherence and cognitive rationality of the generated paths. These data demonstrate that this method not only demonstrates superior performance in knowledge point prediction, circular dependency resolution, and path sorting, but also maintains high generalization across task scenarios. In the context of quadruped robot programming instruction, this method provides learners with a well-structured, task-oriented, and dynamically adjustable path support, improving cognitive coherence and learning efficiency, and possesses significant application value. The released task dataset, benchmark paths, and annotation specifications further support reproducible evaluation and future comparative studies on dynamic teaching path generation.
