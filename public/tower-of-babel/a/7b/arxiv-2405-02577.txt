A combinatorial problem related to the classical probability
Jiang Zhou

Abstract
In the classical probability model, let f ⁡ ( n ) f(n) be the maximum number of pairwise independent events for the sample space with n n sample points. The determination of f ⁡ ( n ) f(n) is equivalent to the problem of determining the maximum cardinality of specific intersecting families on the set { 1 , 2 , … , n } \{1,2,\ldots,n\} . We show that f ⁡ ( n ) ≤ n + 1 f(n)\leq n+1 , and f ⁡ ( n ) = n + 1 f(n)=n+1 if there exists a Hadamard matrix of order n n .

Theorem 2.1

For any positive integer

Proof.

\displaystyle(B)_{ij}=\begin{cases}1~~~~~~~~~~~~~~~~~~\mbox{if}~i\in A_{j},\\

\displaystyle B^{\top}B=n^{-1}uu^{\top}+D,

\displaystyle>

\displaystyle 0~(i=1,2,\ldots,t-1),

\displaystyle=

\displaystyle 0.

\displaystyle x^{\top}B^{\top}Bx

\displaystyle=

\displaystyle n^{-1}x^{\top}uu^{\top}x+x^{\top}Dx

Remarks

The
