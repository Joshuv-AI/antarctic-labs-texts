Positive Green’s functions for some fractional-order boundary value problems
Douglas R. Anderson

Abstract
. We use the newly introduced conformable fractional derivative, which is different from the Caputo and Riemann-Liouville fractional derivatives, to reformulate several common boundary value problems, including those with conjugate, right-focal, and Lidstone conditions. With the fractional differential equation and fractional boundary conditions established, we find the corresponding Green’s functions and prove their positivity under appropriate assumptions.



2010 Mathematics Subject Classification
26A33

1.
Introduction

The search for the existence of positive solutions and multiple positive solutions to nonlinear fractional boundary value problems has expanded greatly over the past decade; for some recent examples please see [1-7,9,12-16]. In all of these works and the references cited therein, however, the definition of the fractional derivative used is either the Caputo or the Riemann-Liouville fractional derivative, involving an integral expression and the gamma function. Recently
[
8
,
9
,
12
]
a new definition has been formulated and dubbed the conformable fractional derivative. In this paper, we use this fractional derivative of order
\alpha
, given by

D^{\alpha}f(t):=\lim_{\varepsilon\rightarrow 0}\frac{f(te^{\varepsilon t^{-\alpha}})-f(t)}{\varepsilon},\quad D^{\alpha}f(0)=\lim_{t\rightarrow 0^{+}}D^{\alpha}f(t);

(1.1)

note that if
f
is differentiable, then

D^{\alpha}f(t)=t^{1-\alpha}f^{\prime}(t),

(1.2)

where
f^{\prime}(t)=\lim_{\varepsilon\rightarrow 0}[f(t+\varepsilon)-f(t)]/\varepsilon
.
Using this new definition of the fractional derivative, we reformulate several common boundary value problems, including those with conjugate, right-focal, and Lidstone conditions. With the fractional differential equation and fractional boundary conditions established, we find the corresponding Green’s functions and prove their positivity under appropriate assumptions. This work thus sets the stage for using fixed point theorems to prove the existence of positive and multiple positive solutions to nonlinear fractional problems based on the conformable fractional derivative and these boundary value problems, as the kernel of the integral operator is often Green’s function.

2.
Two Iterated Fractional Derivatives

We begin by considering two iterated fractional derivatives in the differential operator, together with two-point boundary conditions, as illustrated in the nonlinear boundary value problem

\displaystyle-D^{\beta}D^{\alpha}x(t)=f(t,x(t)),\qquad 0\leq t\leq 1,

(2.1)

\displaystyle\gamma x(0)-\delta D^{\alpha}x(0)=0=\eta x(1)+\zeta D^{\alpha}x(1),

(2.2)

where
\alpha,\beta\in(0,1]
and the derivatives are conformable fractional derivatives (
1.1
), with
\gamma,\delta,\eta,\zeta\geq 0
and
d:=\eta\delta+\gamma\zeta+\gamma\eta/\alpha>0
. To verify the existence of positive solutions to this problem, one often finds the corresponding Green’s function, shows that it is non-negative, and then uses a fixed point theorem on an integral operator whose kernel is Green’s function. Throughout this and subsequent sections, we will state the fractional boundary value problem, find Green’s function for it, and prove that it is positive except at various boundary points.

Theorem 2.1
.

Let
\alpha,\beta\in(0,1]
. The corresponding Green’s function for the homogeneous problem

-D^{\beta}D^{\alpha}x(t)=0

satisfying boundary conditions (
2.2
) is given by

G(t,s)=\begin{cases}\frac{1}{d}\left[\delta+\frac{\gamma}{\alpha}t^{\alpha}\right]\left[\zeta+\frac{\eta}{\alpha}\left(1-s^{\alpha}\right)\right]&:t\leq s\\
\frac{1}{d}\left[\delta+\frac{\gamma}{\alpha}s^{\alpha}\right]\left[\zeta+\frac{\eta}{\alpha}\left(1-t^{\alpha}\right)\right]&:s\leq t\end{cases}

(2.3)

where we assume with
\gamma,\delta,\eta,\zeta\geq 0
and
d=\eta\delta+\gamma\zeta+\gamma\eta/\alpha>0
.

Proof.

Let
h
be any continuous function. We will show that

x(t)=\int_{0}^{1}G(t,s)h(s)s^{\beta-1}ds,

for
G
given by (
2.3
), is a solution to the linear boundary value problem

-D^{\beta}D^{\alpha}x(t)=h(t)

with boundary conditions (
2.2
).

For any
t\in[0,1]
, using the branches of (
2.3
) we have

\displaystyle x(t)

\displaystyle=

\displaystyle\frac{1}{d}\left[\zeta+\frac{\eta}{\alpha}\left(1-t^{\alpha}\right)\right]\int_{0}^{t}\left[\delta+\frac{\gamma}{\alpha}s^{\alpha}\right]h(s)s^{\beta-1}ds

\displaystyle+\frac{1}{d}\left[\delta+\frac{\gamma}{\alpha}t^{\alpha}\right]\int_{t}^{1}\left[\zeta+\frac{\eta}{\alpha}\left(1-s^{\alpha}\right)\right]h(s)s^{\beta-1}ds.

Taking the
\alpha
-fractional derivative yields

\displaystyle D^{\alpha}x(t)

\displaystyle=

\displaystyle-\frac{\eta}{d}\int_{0}^{t}\left[\delta+\frac{\gamma}{\alpha}s^{\alpha}\right]h(s)s^{\beta-1}ds+\frac{\gamma}{d}\int_{t}^{1}\left[\zeta+\frac{\eta}{\alpha}\left(1-s^{\alpha}\right)\right]h(s)s^{\beta-1}ds.

Checking the first boundary condition, we see that

\gamma x(0)-\delta D^{\alpha}x(0)=0.

Moreover, in checking the second boundary condition we get

\eta x(1)+\zeta D^{\alpha}x(1)=0.

Taking the
\beta
-fractional derivative of the
\alpha
-fractional derivative yields

\displaystyle D^{\beta}D^{\alpha}x(t)

\displaystyle=

\displaystyle-\frac{\eta}{d}\left[\delta+\frac{\gamma}{\alpha}t^{\alpha}\right]h(t)t^{\beta-1}t^{1-\beta}-\frac{\gamma}{d}\left[\zeta+\frac{\eta}{\alpha}\left(1-t^{\alpha}\right)\right]h(t)t^{\beta-1}t^{1-\beta}

\displaystyle=

\displaystyle-\frac{1}{d}h(t)\left[\eta\delta+\gamma\zeta+\frac{\gamma\eta}{\alpha}\right]=-h(t),

which is what we set out to prove.
∎

Corollary 2.1

(Fractional Conjugate and Right-Focal Problems)
.

The corresponding Green’s function for the homogeneous problem

-D^{\beta}D^{\alpha}x(t)=0

satisfying the conjugate boundary conditions
x(0)=x(1)=0
is given by

G(t,s)=\begin{cases}\frac{1}{\alpha}t^{\alpha}\left(1-s^{\alpha}\right)&:t\leq s,\\
\frac{1}{\alpha}s^{\alpha}\left(1-t^{\alpha}\right)&:s\leq t,\end{cases}

(2.4)

and the corresponding Green’s function for the homogeneous problem

-D^{\beta}D^{\alpha}x(t)=0

satisfying the right-focal-type boundary conditions
x(0)=D^{\alpha}x(1)=0
is given by

G(t,s)=\begin{cases}\frac{1}{\alpha}t^{\alpha}&:t\leq s,\\
\frac{1}{\alpha}s^{\alpha}&:s\leq t.\end{cases}

(2.5)

Remark 2.1
.

Note that the fractional Green’s function given above for the conjugate boundary conditions in (
2.4
) differs from that found for example in Bai and Lü
[
1
]
.

Theorem 2.2
.

For
G(t,s)
given in (
2.3
), we have that

g(t)G(s,s)<G(t,s)\leq G(s,s)

(2.6)

for
t,s\in[0,1]
, where

g(t):=\min\left\{\frac{\alpha\delta+\gamma t^{\alpha}}{\alpha\delta+\gamma},\frac{\alpha\zeta+\eta\left(1-t^{\alpha}\right)}{\alpha\zeta+\eta}\right\}.

(2.7)

Proof.

It is straightforward to see that

\frac{G(t,s)}{G(s,s)}=\begin{cases}\displaystyle\frac{\delta+\frac{\gamma}{\alpha}t^{\alpha}}{\delta+\frac{\gamma}{\alpha}s^{\alpha}},&t\leq s,\\
&\\
\displaystyle\frac{\zeta+\frac{\eta}{\alpha}(1-t^{\alpha})}{\zeta+\frac{\eta}{\alpha}(1-s^{\alpha})},&s\leq t;\end{cases}

this expression yields both inequalities in (
2.6
) for
g
as in (
2.7
).
∎

Remark 2.2
.

It is also common to skip the Green’s function representation and to express solutions directly. For instance, let
\alpha,\beta\in(0,1]
. The motivated reader can verify that the fractional boundary value problem

-D^{\beta}D^{\alpha}x(t)=h(t),\quad t\in(0,1),

satisfying the three-point boundary conditions

x(0)=0,\quad\delta x(\eta)=x(1),

where
h
is a continuous function,
\eta\in(0,1)
and
0<\delta\eta^{\alpha}<1
, is given by

\displaystyle x(t)

\displaystyle=

\displaystyle\frac{-1}{\alpha}\int_{0}^{t}\left(t^{\alpha}-s^{\alpha}\right)h(s)s^{\beta-1}ds-\frac{\delta t^{\alpha}}{\alpha\left(1-\delta\eta^{\alpha}\right)}\int_{0}^{\eta}\left(\eta^{\alpha}-s^{\alpha}\right)h(s)s^{\beta-1}ds

\displaystyle+\frac{t^{\alpha}}{\alpha\left(1-\delta\eta^{\alpha}\right)}\int_{0}^{1}\left(1-s^{\alpha}\right)h(s)s^{\beta-1}ds.

3.
Three Iterated Fractional Derivatives

Next we consider the three iterated fractional derivative nonlinear right-focal problem

\displaystyle D^{\gamma}D^{\beta}D^{\alpha}x(t)=f(t,x(t)),\qquad 0\leq t\leq 1,

(3.1)

\displaystyle x(0)=D^{\alpha}x(\tau)=D^{\beta}D^{\alpha}x(1)=0,

(3.2)

where
\alpha,\beta,\gamma\in(0,1]
with
0<\tau<1
. One could impose further the conditions
\alpha+\beta\in(1,2]
and
\alpha+\beta+\gamma\in(2,3]
if one wishes to explore a fractional problem of order
(2,3]
. Our approach to the existence of positive solutions would again involve Green’s function for this problem. Once the following three theorems are established, an interested reader could then apply a fixed point theorem to get positive solutions to (
3.1
), (
3.2
), although the details are omitted here.

Theorem 3.1

(Fractional Right-Focal Problem)
.

Let
\alpha,\beta,\gamma\in(0,1]
and
0<\tau<1
. The corresponding Green’s function for the homogeneous problem

D^{\gamma}D^{\beta}D^{\alpha}x(t)=0

satisfying boundary conditions (
3.2
) is given by

G(t,s)=\begin{cases}s\in[0,\tau]&:\begin{cases}u(t,s)&:t\leq s\\
x(0,s)&:s\leq t\end{cases}\\
&\\
s\in[\tau,1]&:\begin{cases}u(t,\tau)&:t\leq s\\
u(t,\tau)+x(t,s)&:s\leq t\end{cases}\\
\end{cases}

(3.3)

where

u(t,s)=\frac{(\alpha+\beta)t^{\alpha}s^{\beta}-\alpha t^{\alpha+\beta}}{\alpha\beta(\alpha+\beta)}

(3.4)

and
x(\cdot,\cdot)
is the Cauchy function given

x(t,s)=\frac{\alpha t^{\alpha}\left(t^{\beta}-s^{\beta}\right)+\beta s^{\beta}\left(s^{\alpha}-t^{\alpha}\right)}{\alpha\beta(\alpha+\beta)}.

(3.5)

Proof.

Let
h
be any continuous function. We will show that

x(t)=\int_{0}^{1}G(t,s)h(s)s^{\gamma-1}ds,

for
G
given by (
3.3
), is a solution to the linear boundary value problem

D^{\gamma}D^{\beta}D^{\alpha}x(t)=h(t)

with boundary conditions (
3.2
).

First let
t\in[0,\tau]
. Then

x(t)=\int_{0}^{t}x(0,s)h(s)s^{\gamma-1}ds+\int_{t}^{\tau}u(t,s)h(s)s^{\gamma-1}ds+\int_{\tau}^{1}u(t,\tau)h(s)s^{\gamma-1}ds;

(3.6)

clearly
x(0)=0
by (
3.4
). Differentiating (
3.6
), we have

\displaystyle D^{\alpha}x(t)

\displaystyle=

\displaystyle x(0,t)h(t)t^{\gamma-1}t^{1-\alpha}+\int_{t}^{\tau}\left(\frac{s^{\beta}-t^{\beta}}{\beta}\right)h(s)s^{\gamma-1}ds

\displaystyle-u(t,t)h(t)t^{\gamma-1}t^{1-\alpha}+\int_{\tau}^{1}\left(\frac{\tau^{\beta}-t^{\beta}}{\beta}\right)h(s)s^{\gamma-1}ds

\displaystyle=

\displaystyle\frac{1}{\beta}\int_{t}^{\tau}\left(s^{\beta}-t^{\beta}\right)h(s)s^{\gamma-1}ds+\frac{1}{\beta}\int_{\tau}^{1}\left(\tau^{\beta}-t^{\beta}\right)h(s)s^{\gamma-1}ds.

Clearly the second boundary condition
D^{\alpha}x(\tau)=0
is met. Differentiating again, we have

\displaystyle D^{\beta}D^{\alpha}x(t)

\displaystyle=

\displaystyle\frac{1}{\beta}\int_{t}^{\tau}\left(-\beta t^{\beta-1}t^{1-\beta}\right)h(s)s^{\gamma-1}ds+\frac{1}{\beta}\int_{\tau}^{1}\left(-\beta t^{\beta-1}t^{1-\beta}\right)h(s)s^{\gamma-1}ds

\displaystyle=

\displaystyle\int_{1}^{t}h(s)s^{\gamma-1}ds.

It follows that
D^{\beta}D^{\alpha}x(1)=0
and
D^{\gamma}D^{\beta}D^{\alpha}x(t)=h(t)
, proving the claim in this case.

Next let
t\in[\tau,1]
. Then

x(t)=\int_{0}^{\tau}x(0,s)h(s)s^{\gamma-1}ds+\int_{\tau}^{t}x(t,s)h(s)s^{\gamma-1}ds+u(t,\tau)\int_{\tau}^{1}h(s)s^{\gamma-1}ds;

(3.7)

again
x(0)=0
by (
3.4
). Differentiating (
3.7
), we have

\displaystyle D^{\alpha}x(t)

\displaystyle=

\displaystyle\frac{1}{\beta}\int_{\tau}^{t}\left(t^{\beta}-s^{\beta}\right)h(s)s^{\gamma-1}ds+\left(\frac{\tau^{\beta}-t^{\beta}}{\beta}\right)\int_{\tau}^{1}h(s)s^{\gamma-1}ds.

The second boundary condition
D^{\alpha}x(\tau)=0
is clearly met. Differentiating again, we have

\displaystyle D^{\beta}D^{\alpha}x(t)

\displaystyle=

\displaystyle\int_{1}^{t}h(s)s^{\gamma-1}ds;

as in the previous case,
D^{\beta}D^{\alpha}x(1)=0
and
D^{\gamma}D^{\beta}D^{\alpha}x(t)=h(t)
, proving the claim in this case as well.
∎

Theorem 3.2
.

For
G(t,s)
given in (
3.3
), we have that

0<G(t,s)\leq G(\tau,s)

(3.8)

for
t\in(0,1]
and
s\in(0,1]
, provided the condition
u(1,\tau)>0
is met for
u
in (
3.4
), that is to say the inequality

\tau>\left(\frac{\alpha}{\alpha+\beta}\right)^{1/\beta}

(3.9)

holds.

Proof.

Referring to (
3.3
), (
3.4
), and (
3.5
), we see that

u(s,s)=x(0,s),\quad x(0,\tau)=u(t,\tau)+x(t,\tau),

ensuring that
G(t,s)
is a well-defined function; we also see that
G(t,s)=0
if
t=0
or
s=0
. From (
3.4
) specifically,
u(0,s)=0
for all
s
and

\frac{d}{dt}u(t,s)=\frac{t^{\alpha-1}(s^{\beta}-t^{\beta})}{\beta}\geq 0,\quad s\geq t.

Moreover, from (
3.5
) we have
x(s,s)=0
and

\frac{d}{dt}x(t,s)=\frac{t^{\alpha-1}(t^{\beta}-s^{\beta})}{\beta}\geq 0,\quad t\geq s,

so that
G(t,s)
is non-decreasing on
[0,\tau]
and non-increasing on
[\tau,1]
. Thus (
3.8
) will hold if
G(1,\tau)>0
holds, which occurs if
u(1,\tau)>0
. This is equivalent to (
3.9
), completing the proof.
∎

Theorem 3.3
.

For all
t,s\in[0,1]
,

g(t)G(\tau,s)\leq G(t,s)\leq G(\tau,s)

(3.10)

where

g(t):=\min\left\{\frac{t^{\alpha}}{\beta\tau^{\alpha+\beta}}\left[(\alpha+\beta)\tau^{\beta}-\alpha t^{\beta}\right],\frac{1-t}{1-\tau}\right\}.

(3.11)

Proof.

From the preceeding theorem, we have
G(t,s)\leq G(\tau,s)
for all
t,s\in[0,1]
. For the lower bound, we proceed by cases on the branches of the Green’s function (
3.3
), that is we use (
3.4
) and (
3.5
).

(i)

0\leq t\leq s\leq\tau
: Here
G(t,s)=u(t,s)
,
G(\tau,s)=x(0,s)=\frac{1}{\alpha(\alpha+\beta)}s^{\alpha+\beta}
. For these
t,s
we have

\frac{u(t,s)}{x(0,s)}\geq\frac{u(t,\tau)}{x(0,\tau)}\geq\frac{t^{\alpha}}{\beta\tau^{\alpha+\beta}}\left[(\alpha+\beta)\tau^{\beta}-\alpha t^{\beta}\right]

which implies

G(t,s)\geq\frac{t^{\alpha}}{\beta\tau^{\alpha+\beta}}\left[(\alpha+\beta)\tau^{\beta}-\alpha t^{\beta}\right]G(\tau,s).

(ii)

0\leq t\leq\tau\leq s\leq 1
: In this case
G(t,s)=u(t,\tau)
and
G(\tau,s)=u(\tau,\tau)
, so again we have

G(t,s)\geq\frac{t^{\alpha}}{\beta\tau^{\alpha+\beta}}\left[(\alpha+\beta)\tau^{\beta}-\alpha t^{\beta}\right]G(\tau,s).

(iii)

0\leq s\leq t\leq\tau
or
0\leq s\leq\tau\leq t\leq 1
:
Since
G(t,s)=G(\tau,s)=\frac{1}{\alpha(\alpha+\beta)}s^{\alpha+\beta}
, it follows that

G(t,s)=G(\tau,s).

(iv)

\tau\leq t\leq s\leq 1
: As in
(ii)
,
G(t,s)=u(t,\tau)
and
G(\tau,s)=u(\tau,\tau)
. Define

\displaystyle w(t)

\displaystyle:=u(t,\tau)-\left(\frac{1-t}{1-\tau}\right)u(\tau,\tau)

(3.12)

\displaystyle=G(t,s)-\left(\frac{1-t}{1-\tau}\right)G(\tau,s).

Now
w(\tau)=0
,
w^{\prime}(\tau)>0
, and
w(1)=G(1,s)>0
by (
3.9
).
Since
w
is concave down,
w(t)\geq 0
on
[\tau,1]
, hence

G(t,s)\geq\left(\frac{1-t}{1-\tau}\right)G(\tau,s).

(v)

\tau\leq s\leq t\leq 1
: Note that
G(\tau,s)=u(\tau,\tau)
, while

G(t,s)=u(t,\tau)+x(t,s)\geq u(t,\tau)
;
consequently, the employment of
w
as in (
3.12
) yields

G(t,s)\geq\left(\frac{1-t}{1-\tau}\right)G(\tau,s).

∎

4.
Four Iterated Fractional Derivatives

In this final section we consider four iterated fractional derivatives in the differential operator, with two types of boundary conditions. First, consider the nonlinear two-point cantilever beam eigenvalue problem

\displaystyle D^{\delta}D^{\gamma}D^{\beta}D^{\alpha}x(t)=\lambda a(t)f(x),\qquad 0\leq t\leq 1,

(4.1)

\displaystyle x(0)=D^{\alpha}x(0)=D^{\beta}D^{\alpha}x(1)=D^{\gamma}D^{\beta}D^{\alpha}x(1)=0,

(4.2)

where
\alpha,\beta,\gamma,\delta\in(0,1]
, and with
\alpha+\beta\in(1,2]
,
\alpha+\beta+\gamma\in(2,3]
, and
\alpha+\beta+\gamma+\delta\in(3,4]
if one wishes to explore this problem as a fractional order between 3 and 4. The theme throughout this work has been to approach the existence of positive solutions to (
4.1
), (
4.2
) by involving Green’s function for this problem. To obtain symmetry in Green’s function below we must take
\gamma=\alpha
in the fractional differential equation, but we will maintain the more general form (
\gamma
not necessarily equal to
\alpha
) in the proofs to follow.

Theorem 4.1

(Fractional Cantilever Beam)
.

Let
\alpha,\beta,\gamma,\delta\in(0,1]
. The corresponding Green’s function for the homogeneous problem

D^{\delta}D^{\gamma}D^{\beta}D^{\alpha}x(t)=0

(4.3)

satisfying boundary conditions (
4.2
) is given by

G(t,s)=\begin{cases}\displaystyle\frac{t^{\alpha+\beta}}{\gamma}\left[\frac{s^{\gamma}}{\beta(\alpha+\beta)}-\frac{t^{\gamma}}{(\beta+\gamma)(\alpha+\beta+\gamma)}\right]&:t\leq s,\\
\displaystyle\frac{s^{\beta+\gamma}}{\alpha}\left[\frac{t^{\alpha}}{\beta(\beta+\gamma)}-\frac{s^{\alpha}}{(\alpha+\beta)(\alpha+\beta+\gamma)}\right]&:s\leq t.\end{cases}

(4.4)

Proof.

Let
h
be any continuous function. We will show that

x(t)=\int_{0}^{1}G(t,s)h(s)s^{\delta-1}ds,

for
G
given by (
4.4
), is a solution to the linear boundary value problem

D^{\delta}D^{\gamma}D^{\beta}D^{\alpha}x(t)=h(t)

with boundary conditions (
4.2
).

For any
t\in[0,1]
, using the branches of (
4.4
) we have

\displaystyle x(t)

\displaystyle=

\displaystyle\int_{0}^{t}\frac{s^{\beta+\gamma}}{\alpha}\left[\frac{t^{\alpha}}{\beta(\beta+\gamma)}-\frac{s^{\alpha}}{(\alpha+\beta)(\alpha+\beta+\gamma)}\right]h(s)s^{\delta-1}ds

\displaystyle-\frac{t^{\alpha+\beta}}{\gamma}\int_{1}^{t}\left[\frac{s^{\gamma}}{\beta(\alpha+\beta)}-\frac{t^{\gamma}}{(\beta+\gamma)(\alpha+\beta+\gamma)}\right]h(s)s^{\delta-1}ds;

clearly
x(0)=0
. Taking the
\alpha
-fractional derivative yields

\displaystyle D^{\alpha}x(t)

\displaystyle=

\displaystyle\frac{1}{\beta(\beta+\gamma)}\int_{0}^{t}s^{\beta+\gamma+\delta-1}h(s)ds-\frac{t^{\beta}}{\beta\gamma}\int_{1}^{t}s^{\gamma+\delta-1}h(s)ds

\displaystyle+\frac{t^{\beta+\gamma}}{\gamma(\beta+\gamma)}\int_{1}^{t}s^{\delta-1}h(s)ds.

It is easy to see that
D^{\alpha}x(0)=0
. Taking the
\beta
-fractional derivative of the
\alpha
-fractional derivative yields

\displaystyle D^{\beta}D^{\alpha}x(t)

\displaystyle=

\displaystyle\frac{1}{\gamma}\int_{1}^{t}\left(t^{\gamma}-s^{\gamma}\right)s^{\delta-1}h(s)ds,

so that
D^{\beta}D^{\alpha}x(1)=0
. Next,

D^{\gamma}D^{\beta}D^{\alpha}x(t)=\int_{1}^{t}s^{\delta-1}h(s)ds,

from which we have
D^{\gamma}D^{\beta}D^{\alpha}x(1)=0
, and

D^{\delta}D^{\gamma}D^{\beta}D^{\alpha}x(t)=h(t).

This finishes the proof.
∎

Theorem 4.2
.

For all
t,s\in[0,1]
, Green’s function given by (
4.4
) satisfies

0\leq G(t,s)\leq G(1,s).

Proof.

Note that

\frac{d}{dt}G(t,s)=\begin{cases}\frac{t^{\alpha+\beta-1}}{\beta\gamma(\beta+\gamma)}\left[\gamma s^{\gamma}+\beta\left(s^{\gamma}-t^{\gamma}\right)\right]&:t\leq s,\\
\frac{s^{\beta+\gamma}t^{\alpha-1}}{\beta(\beta+\gamma)}&:s\leq t.\end{cases}

(4.5)

Fix
s\in[0,1]
. By the first boundary condition
G(0,s)=0
, and
\frac{d}{dt}G(t,s)
as given above implies that
G(\cdot,s)
is monotone increasing on
(0,1]
. In particular,
G(1,s)\geq G(t,s)\geq 0
for all
t\in[0,1]
.
∎

Finally, we will end the present discussion by considering another common set of boundary conditions, namely the so-called Lidstone conditions. Unlike the argument used below, one could also approach this problem as the conjunction of two conjugate problems, whose Green’s function is given in (
2.4
).

Theorem 4.3

(Fractional Lidstone)
.

Let
\alpha,\beta\in(0,1]
. The symmetric Green’s function for the homogeneous problem

D^{\beta}D^{\alpha}D^{\beta}D^{\alpha}x(t)=0

(4.6)

satisfying the Lidstone-type boundary conditions

x(0)=0=D^{\beta}D^{\alpha}x(0),\quad x(1)=0=D^{\beta}D^{\alpha}x(1)

(4.7)

is given by

G(t,s)=\begin{cases}u(t,s)&:t\leq s,\\
u(s,t)&:s\leq t,\end{cases}

(4.8)

where

u(t,s)=\frac{t^{\alpha}}{\alpha\beta(\alpha+\beta)(2\alpha+\beta)}\left[2\alpha s^{\alpha}\left(1-s^{\beta}\right)-\beta\left(1-s^{\alpha}\right)\left(t^{\alpha+\beta}+s^{\alpha+\beta}\right)\right].

(4.9)

Proof.

In this proof we construct Green’s function from scratch, modifying the classical approach, found for example in
[
11
, Chapter 5]
.
Let
x(t,s)
be the Cauchy function associated with (
4.3
), namely a function satisfying

x(s,s)=D^{\alpha}x(s,s)=D^{\beta}D^{\alpha}x(s,s)=0,\quad D^{\gamma}D^{\beta}D^{\alpha}x(t,s)=1.

(Note that we will use
\gamma
for now, and take
\gamma=\alpha
for symmetry purposes at the conclusion.) Using (
1.2
) at each step, it is easy to verify that here the Cauchy function is given by

x(t,s)=\frac{1}{\gamma}\int_{s}^{t}\int_{s}^{\tau}\left(\xi^{\gamma}-s^{\gamma}\right)\xi^{\beta-1}\tau^{\alpha-1}d\xi d\tau,

(4.10)

and Green’s function takes the form of

G(t,s)=\begin{cases}u(t,s)&:t\leq s,\\
u(t,s)+x(t,s)&:s\leq t,\end{cases}

where
u(t,s)

Theorem 4.4
.

For all
t,s\in(0,1)
, Green’s function given by (

Proof.

Clearly
u(1,s)=u(t,1)=0

u(t,s)\geq\frac{2s^{\alpha}t^{\alpha}}{\alpha\beta(\alpha+\beta)(2\alpha+\beta)}\left[\alpha\left(1-s^{\beta}\right)-\beta\left(1-s^{\alpha}\right)s^{\beta}\right]
