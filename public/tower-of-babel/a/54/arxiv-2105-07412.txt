Global asymptotic stability for Gurtin-MacCamy’s population dynamics model
Zhaohai Ma, Pierre Magal

Abstract
In this paper, we investigate the global asymptotic stability of an age-structured population dynamics model with a Ricker’s type of birth function. This model is a hyperbolic partial differential equation with a nonlinear and nonlocal boundary condition. We prove a uniform persistence result for the semi-flow generated by this model. We obtain the existence of global attractors and we prove the global asymptotic stability of the positive equilibrium by using a suitable Lyapunov functional. Furthermore, we prove that our global asymptotic stability result is sharp, in the sense that Hopf bifurcation may occur as close as we want from the region global stability in the space of parameter.

Lemma 3.3

For each

\int_{0}^{\infty}\Gamma^{\pm}(a)u_{\pm}(t,a)\mathrm{d}a=e^{\lambda^{\pm}t}\int_{0}^{\infty}\Gamma^{\pm}(a)u_{0}(a)\mathrm{d}a.

\frac{\mathrm{d}}{\mathrm{d}t}\int_{0}^{\infty}\Gamma^{\pm}(a)u_{\pm}(t,a)\mathrm{d}a=\int_{0}^{\infty}\Gamma^{\pm}(a)[-\partial_{a}u_{\pm}(t,a)-\mu u_{\pm}(t,a)]\mathrm{d}a.

Using integration by parts, it follows that

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\int_{0}^{\infty}\Gamma^{\pm}(a)u_{\pm}(t,a)\mathrm{d}a

\displaystyle=

\displaystyle\Gamma^{\pm}(0)u_{\pm}(t,0)+\int_{0}^{\infty}(\Gamma^{\pm})^{\prime}(a)u_{\pm}(t,a)\mathrm{d}a

\displaystyle-\int_{0}^{\infty}\Gamma^{\pm}(a)\mu u_{\pm}(t,a)\mathrm{d}a.

In practice, the number

corresponds to the maximal value at which individuals can reproduce.

Theorem 3.5

Let Assumption
1.1
be satisfied. The domains
\left[0,\infty\right)\times\widehat{M}_{0}
and
\left[0,\infty\right)\times\partial\widehat{M}_{0}

\int_{0}^{a^{\star}}u_{0}(a)\mathrm{d}a>0\Rightarrow\int_{0}^{a^{\star}}u(t,a)\mathrm{d}a>0,\forall t\geq 0,

and

\int_{0}^{a^{\star}}u_{0}(a)\mathrm{d}a=0\Rightarrow\int_{0}^{a^{\star}}u(t,a)\mathrm{d}a=0,\forall t\geq 0.

Moreover if
\int_{0}^{a^{\star}}u_{0}(a)\mathrm{d}a=0

\int_{0}^{\infty}\beta(a)u(t,a)\mathrm{d}a=0,\forall t\geq 0,

Proof.
Assume first
u_{0}\in\partial\widehat{M}_{0}
. Then,

\int_{0}^{\infty}\Gamma^{+}(a)u_{0}(a)\mathrm{d}a=0.

Moreover,

\int_{0}^{\infty}\Gamma^{+}(a)u(t,a)\mathrm{d}a\leq\int_{0}^{\infty}\Gamma^{+}(a)u_{+}(t,a)\mathrm{d}a=e^{\lambda^{+}t}\int_{0}^{\infty}\Gamma^{+}(a)u_{0}(a)\mathrm{d}a=0{.}

Hence,

u(t,.)\in\partial\widehat{M}_{0},\forall t\geq 0.

Assume next that

\int_{0}^{\infty}\Gamma^{-}(a)u(t,a)\mathrm{d}a\geq\int_{0}^{\infty}\Gamma^{-}(a)u_{-}(t,a)\mathrm{d}a=e^{\lambda^{-}t}\int_{0}^{\infty}\Gamma^{-}(a)u_{0}(a)\mathrm{d}a>0.

Thus,

u(t,.)\in\widehat{M}_{0},\forall t\geq 0.

Let
u_{0}\in\widehat{M}_{0}

By using the previous assumption, we should consider two different cases: 1)

Proposition 3.6

Let Assumption
1.1
be satisfied. For each
u_{0}\in\widehat{M}_{0}
, there exists

b(t)>0,\forall t\geq t_{0}.

Due to the fact that

where

and

By using the continuity of the shift operator in

, we deduce that the map

t\to\int_{t}^{\infty}\beta(a)u_{0}(a-t)\mathrm{d}a

First part of the proof:
Let

\int_{t}^{t+\Delta t}\int_{0}^{\infty}\beta(\sigma+\theta)u_{0}(\sigma)\mathrm{d}\sigma\mathrm{d}\theta=\int_{0}^{\infty}\int_{t}^{t+\Delta t}\beta(\sigma+\theta)\mathrm{d}\theta u_{0}(\sigma)\mathrm{d}\sigma.

Then, by using the definition of

, we deduce that there exists

such that

\int_{0}^{\infty}\beta(\sigma+t^{*})u_{0}(\sigma)\mathrm{d}\sigma>0\Leftrightarrow F_{-}(t^{*})>0.

Second part of the proof:
In order to prove this theorem, we observe that for all

\int_{t}^{t+\Delta t}B_{-}(\theta)\mathrm{d}\theta=\int_{t}^{t+\Delta t}F_{-}(\theta)\mathrm{d}\theta+\int_{t}^{t+\Delta t}\int_{0}^{t}\gamma(\theta-a)B_{-}(a)\mathrm{d}a\mathrm{d}\theta.

Then, by using Fubini’s theorem, we obtain for all

\int_{t}^{t+\Delta t}B_{-}(l)\mathrm{d}l=\int_{t}^{t+\Delta t}F_{-}(l)\mathrm{d}l+\int_{0}^{t}\int_{t-a}^{t-a+\Delta t}\gamma(\theta)\mathrm{d}\theta B_{-}(a)\mathrm{d}a.

Now, you can work like if

were a continuous function, and we deduce that the length of the support

increases from
(0,a^{*})
to
(a^{*},2a^{*})

Asymptotic smoothness of the semiflow

In this section, we prove that the semiflow generated by (
1.1
) is asymptotically smooth. Define

u_{1}(t,a)=\left\{\begin{array}[]{cc}e^{-\mu t}u_{0}(a-t),&\text{ if }a\geq t,\\
e^{-\mu a}b_{1}(t-a),&\text{ if }a\leq t,\end{array}\right.

and

u_{2}(t,a)=\left\{\begin{array}[]{cc}0,&\text{ if }a\geq t,\\
e^{-\mu a}b_{2}(t-a),&\text{ if }a\leq t,\end{array}\right.

where

\begin{array}[]{l}b_{1}(t)=\alpha\left[f\left(B(t)\right)-f(B_{2}(t))\right],\quad b_{2}(t)=\alpha f(B_{2}(t)),\end{array}

and

B(t)=\int_{0}^{\infty}u(t,a)\mathrm{d}a=\underset{B_{1}(t)}{\underbrace{e^{-\mu t}\int_{t}^{\infty}\beta(a)u_{0}(a-t)\mathrm{d}a}}+\underset{B_{2}(t)}{\underbrace{\int_{0}^{t}\beta(a)e^{-\mu a}b(t-a)\mathrm{d}a}}.

Theorem 4.1

The semiflow generated by (
1.1
) is asymptotically smooth. Moreover, precisely the semiflow
U(t)
generated by (
1.1
) on
L^{1}_{+}
can be decomposed into

U(t)u_{0}=C(t)u_{0}+V(t)u_{0},\forall t\geq 0,\forall u_{0}\in L^{1}_{+},

where
C(t):L^{1}_{+}\to L^{1}
and
V(t):L^{1}_{+}\to L^{1}
are defined by

C(t)u_{0}=u_{2}(t,.),\text{ and }V(t)u_{0}=u_{1}(t,.),\forall t\geq 0,\forall u_{0}\in L^{1}_{+}.

Then we have the following properties

(i)

The nonlinear operator
C(t):L^{1}_{+}\to L^{1}
is completely continuous for each
t\geq 0
;

(ii)

There exists a constant
\chi>0
such that

\|V(t)u_{0}\|\leq\chi e^{-\mu t},\forall t\geq 0.

Proof.

Proof of (i):
It is sufficient to observe that
t\to B_{2}(t)
is uniformly continuous on
[0,\tau]
uniformly with respect to
b(t)
. Indeed, we have
\forall t,s\in[0,\tau]
(with
t\geq s
)

|B_{2}(t)-B_{2}(s)|\leq\sup_{\sigma\in[0,\tau]}|b(\sigma)|\left[\int_{0}^{t-s}g(l)\mathrm{d}l+\int_{0}^{s}|g(t-s+l)-g(l)|\mathrm{d}l\right],

where
g(a)=\beta(a)e^{-\mu a}
. By applying Arzela-Ascoli’s theorem, it follows that
C(t)
maps the bounded sets into relatively compact sets.

Proof of (ii):
Moreover, since
f(u)
is Lipschitz continuous on
[0,\infty)
, we deduce that

\|u_{1}(t,.)\|_{L^{1}}\leq e^{-\mu t}\|u_{0}\|_{L^{1}}+\|e^{-\mu.}\|_{L^{1}}\alpha\|f^{\prime}\mid_{[0,\infty)}\|_{\infty}B_{1}(t).

Thus, there exists a constant
\chi=1+\|e^{-\mu.}\|_{L^{1}}\alpha\|f^{\prime}\mid_{[0,\infty)}\|_{\infty}\|\beta\|_{L^{\infty}}
such that

\|u_{1}(t,.)\|_{L^{1}}\leq\chi e^{-\mu t}\|u_{0}\|_{L^{1}},\forall t\geq 0.

The proof is completed.

Theorem 4.2

The semiflow generated by (
1.1
) is asymptotically smooth. That is to say that

\lim_{t\to\infty}\kappa\left(U(t)B\right)=0,

where
\kappa
is the Kuratovsky’s measure of non-compactness defined by

\kappa(B)=\inf\left\{\varepsilon>0:B\text{ can be covered by a finite number of balls of radius }\leq\varepsilon\right\},

for any bounded set

of
L^{1}_{+}(0,\infty)
.

Proof.
For each bounded set
B\subset L^{1}_{+}(0,\infty)
, we have the Kuratovsky’s measure of non-compactness satisfies

\kappa(U(t)B)\leq\kappa(V(t)B)+\kappa(C(t)B)=\kappa(V(t)B)\leq\chi e^{-\mu t}\sup_{u\in B}\|u\|_{L^{1}}.

The proof is completed.

Thus,

\lim_{t\to+\infty}\|u(t,\cdot)\|_{L^{1}}\geq\lim_{t\to\infty}\int_{0}^{\infty}\Gamma^{-}(a)u(t,a)\mathrm{d}a=+\infty,

which contradicts to (
5.1
).

Since the semiflow
U
is asymptotically smooth, point dissipative and positive orbits of compact subsets of
\widehat{M}_{0}
are bounded, we deduce that
U
has a compact global attractor
\mathcal{A}_{0}
in
\widehat{M}_{0}
.

Proposition 5.3

Let Assumption
1.1
be satisfied. There exists
\delta>0
such that

\int_{0}^{+\infty}\beta(a)u_{0}(a)\mathrm{d}a\geq\delta,\quad\forall u_{0}\in\mathcal{A}_{0}.

Proof.
Let

be the solution to (

is continuous.
Also, the mapping

is continuous.
Thus, there exists

(independent of

Theorem 5.4

6
Global stability result

In this section, we use a Lyapunov functional to show that all solutions of (
1.1
) for which the population is initially present tend to the positive equilibrium under the Assumption
6.2
.

Define

V(u(t,\cdot))=\int_{0}^{+\infty}\gamma(a)g\left(\frac{u(t,a)}{\bar{u}(a)}\right)\mathrm{d}a,

(6.1)

where

\gamma(a)=\int_{a}^{+\infty}\beta(\sigma)e^{-\mu\sigma}\mathrm{d}\sigma,\quad g(u)=(u-1)^{2}.

Remark 6.1

We observe that
V
is well-defined on the attractor
\mathcal{A}_{0}
for every
t\geq 0
, while
V
is not well-defined on
L^{1}(0,+\infty)
because of the function
g
under the integral.

Assumption 6.2

We assume that
1<\alpha\leq e^{2}
.

The following Lemma is due to Fisher and Goh
[
1
]
.

Lemma 6.3

Let Assumption
6.2
be satisfied. Then for each
u\geq 0
,

\left|{\alpha f(u)-\overline{u}(0)}\right|=\left|{\alpha f(u)-\alpha f(\overline{u}(0))}\right|\leq\left|{u-\overline{u}(0)}\right|.

(6.2)

Moreover the above inequality is strict whenever
u\neq 0
and
u\neq\overline{u}(0)
.

Proposition 6.4
(Lyapunov function)

Let Assumptions
1.1
and
6.2
be satisfied. Assume that
t\to u(t,a)
is a complete orbit of the system (
1.1
) satisfying

\gamma_{-}\leq\int_{0}^{a_{*}}u(t,a)\mathrm{d}a\leq\gamma_{+},\forall t\in\mathbb{R},

for some
\gamma_{+}>\gamma_{-}>0
.
Then the function
t\to V(u(t,\cdot))
is decreasing. Moreover,
t\to V(u(t,\cdot))
is constant if

u(t,a)=\overline{u}(a),\forall t\in\mathbb{R}.

Proof.
We have

\displaystyle\frac{\mathrm{d}V(u(t,\cdot))}{\mathrm{d}t}=

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\int_{0}^{+\infty}\gamma(a)g\left(\frac{u(t,a)}{\bar{u}(a)}\right)\mathrm{d}a=\frac{\mathrm{d}}{\mathrm{d}t}\int_{0}^{+\infty}\gamma(a)g\left(\frac{b(t-a)}{\bar{u}(0)}\right)\mathrm{d}a

\displaystyle=

\displaystyle\frac{\mathrm{d}}{\mathrm{d}t}\int_{-\infty}^{t}\gamma(t-s)g\left(\frac{b(s)}{\bar{u}(0)}\right)\mathrm{d}s

\displaystyle=

\displaystyle\int_{-\infty}^{t}\gamma^{\prime}(t-s)g\left(\frac{b(s)}{\bar{u}(0)}\right)\mathrm{d}s+\gamma(0)g\left(\frac{b(t)}{\bar{u}(0)}\right).

It follows from the definition of
\gamma(a)
that
\gamma^{\prime}(a)=-\beta(a)e^{-\mu a}
and
\gamma(0)=1
.
Then,

\frac{\mathrm{d}V(u(t,\cdot))}{\mathrm{d}t}=g\left(\frac{b(t)}{\bar{u}(0)}\right)-\int_{0}^{+\infty}\beta(a)e^{-\mu a}g\left(\frac{b(t-a)}{\bar{u}(0)}\right)\mathrm{d}a.

(6.3)

By using Lemma
6.3
, we have

\begin{array}[]{ll}g\left(\dfrac{b(t)}{\bar{u}(0)}\right)=&\dfrac{1}{\bar{u}^{2}(0)}\left[\alpha f\left(\displaystyle\int_{0}^{+\infty}\beta(a)e^{-\mu a}b(t-a)\mathrm{d}a\right)-\bar{u}(0)\right]^{2}\\
&\leq\dfrac{1}{\bar{u}^{2}(0)}\left[{\displaystyle\int_{0}^{+\infty}\beta(a)e^{-\mu a}b(t-a)\mathrm{d}a-\bar{u}(0)}\right]^{2}.\end{array}

(6.4)

Thus,

g\left(\frac{b(t)}{\bar{u}(0)}\right)\leq g\left(\int_{0}^{+\infty}\beta(a)e^{-\mu a}\frac{b(t-a)}{\bar{u}(0)}\mathrm{d}a\right).

(6.5)

Substituting the inequality (
6.5
) to (
6.3
), we obtain

\displaystyle\frac{\mathrm{d}V(u(t,\cdot))}{\mathrm{d}t}\leq

\displaystyle g\left(\int_{0}^{+\infty}\beta(a)e^{-\mu a}\frac{b(t-a)}{\bar{u}(0)}\mathrm{d}a\right)-\int_{0}^{+\infty}\beta(a)e^{-\mu a}g\left(\frac{b(t-a)}{\bar{u}(0)}\right)\mathrm{d}a,

and we deduce that

\frac{\mathrm{d}V(u(t,\cdot))}{\mathrm{d}t}\leq 0

by using Jensen’s inequality and the fact that
g
is a convex function.

To prove the last part of the proposition, it is sufficient to observe that by Lemma
6.3
, the inequality (
6.4
) is strict whenever
\int_{0}^{+\infty}\beta(a)e^{-\mu a}b(t-a)\mathrm{d}a\neq\overline{u}(0)
. Therefore, the function
t\to V(u(t,\cdot))
is constant if and only if

\int_{0}^{+\infty}\beta(a)e^{-\mu a}b(t-a)\mathrm{d}a=\overline{u}(0),\forall t\in\mathbb{R},

and the result follows by using (
5.2
) and (
5.3
).

Theorem 6.5

Let Assumptions
1.1
and
6.2
be satisfied. Then, the positive equilibrium
\bar{u}(a)
of the system (
1.1
) is global asymptotically stable.

Proof.
Let
u(t,\cdot)
be a complete solution to (
1.1
) that lies in the attractor
\mathcal{A}_{0}\subset\widehat{M}_{0}
.
It follows from Proposition
5.3
that there exist
\delta_{1},\delta_{2}>0
such that

\delta_{1}\leq\frac{u(t,a)}{\bar{u}(a)}\leq\delta_{2},\quad\forall a\geq 0,t\in\mathbb{R}.

(6.6)

By the definition of the function
g
in (
6.1
), we observe that
g:(0,+\infty)\to\mathbb{R}_{+}
is decreasing for
u\in(0,1)
and is increasing for

and has global minimum

.
It follows from (
6.6
) that

Thus, the Lyapunov functional

Furthermore, by Proposition

Thus, we have now shown that the arbitrary complete solution
