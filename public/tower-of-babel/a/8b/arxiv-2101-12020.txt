(Stochastic) Model Predictive Control - a Simulation Example
Tim Brüdigam

Abstract
This brief introduction to Model Predictive Control specifically addresses stochastic Model Predictive Control, where probabilistic constraints are considered. A simple linear system subject to uncertainty serves as an example. The Matlab code for this stochastic Model Predictive Control example is available online.



1
Introduction

In the following, we provide details on an (S)MPC simulation example. The Matlab code for this simulation example is available at
https://github.com/tim283/smpc_example
. The main purpose of this document is to introduce the idea of considering uncertainty in constraints within
Model Predictive Control (MPC)
. This document is not necessarily a step-by-step manual, nor does it explain code in detail.

In Section
2
, we first introduce the deterministic system, constraints, and MPC optimal control problem. We then introduce uncertainty into the system dynamics and provide a brief overview of how to handle constraints subject to uncertainty, also called chance constraints.

Section
3
provides a more elaborate derivation of the chance constraint reformulation, both for normally distributed uncertainties and general probability distributions.

2
Simulation Example

We consider the system example described in
[
LDTA17
]
to illustrate the concept of MPC. Based on the MPC toolbox of
[
GP17
]
, the introduced system may then be controlled.

While this example system is considered here without any physical context, the system represents a linearization of a Buck-Boost DC–DC converter
[
LHR+08
,
CKRC11
]
.

2.1
System and Constraints

We first consider the system

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}u_{k}

(1)

with states
\bm{x}_{k}=[x_{1,k},~x_{2,k}]^{\top}
and input
u_{k}
. Here, we choose

\displaystyle\bm{A}=\begin{bmatrix}1&0.0075\\
-0.143&0.996\end{bmatrix},~~\bm{B}=\begin{bmatrix}4.798\\
0.115\end{bmatrix}

(2)

for the system and input matrix. In addition, we consider input constraints

\displaystyle-0.2\leq u_{k}\leq 0.2

(3)

and a state constraint limiting the state
x_{1}
by

\displaystyle x_{1,k}\leq x_{1,\text{lim}}

(4)

where
x_{1,\text{lim}}=2.8
is the limit.

2.2
Model Predictive Control

The MPC optimal control problem, solved at each time step, subject to only input constraints is given by

\displaystyle\min_{\bm{U}}

\displaystyle\sum_{k=0}^{N-1}\bm{x}_{k}^{\top}\bm{Q}\bm{x}_{k}+u_{k}^{\top}\bm{R}u_{k}

(5a)

s.t.

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}u_{k},

\displaystyle~k\in\{0,...,N-1\}

(6a)

\displaystyle|u_{k}|\leq 0.2,

\displaystyle~k\in\{0,...,N-1\}

(7a)

with
\bm{U}=[u_{0},...u_{N-1}]
, horizon
N=11
, and sampling time
\Delta t=0.1
, where the weighting matrices are

\displaystyle\bm{Q}=\begin{bmatrix}1&0\\
0&10\end{bmatrix},~~\bm{R}=1.

(8)

If no state constraints are present, starting at the initial state
\bm{x}_{0}=[2.5,~4.8]^{\top}
results in a curved motion towards the origin, where
x_{1}
first increases (beyond the value
2.8
). By introducing the state constraint (
4
), the MPC optimal control problem is extended to

\displaystyle\min_{\bm{U}}

\displaystyle\sum_{k=0}^{N-1}\bm{x}_{k}^{\top}\bm{Q}\bm{x}_{k}+u_{k}^{\top}\bm{R}u_{k}

(9a)

s.t.

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}u_{k},

\displaystyle~k\in\{0,...,N-1\}

(10a)

\displaystyle|u_{k}|\leq 0.2,

\displaystyle~k\in\{0,...,N-1\}

(11a)

\displaystyle x_{1,k}\leq 2.8,

\displaystyle~k\in\{1,...,N\}

(12a)

causing
x_{1}
to increase until the value
2.8
is reached. Then, the states move towards the origin along the constraint.

2.3
Stochastic MPC for Systems with Uncertainty

Now, uncertainty is introduced into the system, yielding

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}u_{k}+\bm{D}\bm{w}_{k}

(13)

with

\displaystyle\bm{D}=\begin{bmatrix}1&0\\
0&1\end{bmatrix}.

(14)

and the Gaussian uncertainty
\bm{w}_{k}\sim\mathcal{N}(\bm{0},\bm{\Sigma}_{w})
with covariance matrix

\displaystyle\bm{\Sigma}_{w}=\begin{bmatrix}0.08&0\\
0&0.08\end{bmatrix}.

(15)

Assuming we now used (
5a
) to control the actual system (
13
), the MPC would not account for uncertainty and the state constraint may be violated, as the prediction model does not account for the actual uncertainty. In order to cope with this, an SMPC approach is employed, accounting for the uncertainty
\bm{w}_{k}
. Therefore, the state constraint is transformed into a chance constraint

\displaystyle\mathrm{Pr}(x_{1,k}\leq 2.8)\geq\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(16)

where
β
is a risk parameter. The constraint (
4
) is not required to hold always, but only up to a level specified by the predefined risk parameter. The higher the risk parameter is chosen, the lower the risk allowed. Sometimes, the risk parameter is defined as
\tilde{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}=1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}
, where
\beta
in (
16
) is replaced with
1-\tilde{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}
. It then holds that increasing the risk parameter
\tilde{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}
also increases risk.

This chance constraint is required to be reformulated in order to be used within the optimal control problem, yielding

\displaystyle x_{1,k}\leq 2.8-\gamma

(17a)

\displaystyle\gamma=\sqrt{2[1,0]^{\top}\bm{\Sigma}^{\text{e}}_{k}[1,~0]}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)

(18a)

which is an approximation of (
16
)
[
FGS16
]
. In other words, the state constraint is tightened by the tightening parameter
\gamma
, which itself depends on the risk parameter
β
and the error covariance matrix
\bm{\Sigma}^{\text{e}}_{k}
that is derived in the following. The vector
[1,0]
is required as only the error affecting
x_{1}
is important. A more extensive derivation of the chance constraint reformulation is provided in Section
3
. In short, the term
\sqrt{[1,0]^{\top}\bm{\Sigma}^{\text{e}}_{k}[1,~0]}
considers the uncertainty (and the resulting error) variance and
\sqrt{2}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)
follows from the uncertainty distribution (here the normal distribution) and the risk parameter.

The state of the system dynamics (
13
) may be split into a deterministic and a probabilistic part

\displaystyle\bm{x}_{k}=\bm{z}_{k}+\bm{e}_{k}

(19)

and the input is adapted to

\displaystyle u_{k}=-\bm{K}\bm{x}_{k}+v_{k}

(20)

where
\bm{K}
is a stabilizing state feedback matrix obtained by an LQR approach. Here,
\bm{K}\bm{x}_{k}
controls the deterministic part of the system dynamics, while the new decision variable
v_{k}
accounts for uncertainty.

MPC requires propagating the error for the prediction, yielding the error covariance matrix

\displaystyle\bm{\Sigma}^{\text{e}}_{k+1}=\left(\bm{A}-\bm{B}\bm{K}\right)\bm{\Sigma}^{\text{e}}_{k}\left(\bm{A}-\bm{B}\bm{K}\right)^{\top}+\bm{D}\bm{\Sigma}_{w}{\bm{D}}^{\top}

(21)

for every prediction step with

\displaystyle\bm{\Sigma}^{\text{e}}_{0}=\mathrm{diag}(0,0).

(22)

Therefore, the error covariance matrix depends on the previous error propagated through the system, as well as the covariance of the uncertainty additionally added at each step. Note the difference between the uncertainty covariance matrix
\bm{\Sigma}_{w}
and the error covariance matrix
\bm{\Sigma}^{\text{e}}_{k}
, which is computed for every prediction step
k
, based on the prediction model and on
\bm{\Sigma}_{w}
.

The full SMPC optimal control problem is

\displaystyle\min_{\bm{V}}

\displaystyle\sum_{k=0}^{N-1}\bm{x}_{k}^{\top}\bm{Q}\bm{x}_{k}+(v_{k}-\bm{K}\bm{x}_{k})^{\top}\bm{R}(v_{k}-\bm{K}\bm{x}_{k})

(23a)

s.t.

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}(v_{k}-\bm{K}\bm{x}_{k}),

\displaystyle k\in\{0,...,N-1\}

(24a)

\displaystyle|v_{k}-\bm{K}\bm{x}_{k}|\leq 0.2,

\displaystyle k\in\{0,...,N-1\}

(25a)

\displaystyle x_{1,k}\leq 2.8-\gamma_{k},

\displaystyle k\in\{1,...,N\}

(26a)

\displaystyle\gamma_{k}=\sqrt{2[1,0]\bm{\Sigma}^{\text{e}}_{k}[1,~0]^{\top}}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1),

\displaystyle k\in\{1,...,N\}

(27a)

where
\bm{V}=[v_{0},...v_{N-1}]
replaces the decision variables
\bm{U}
.

If (
23a
) is applied to control the actual system (
13
), the states do not exactly reach the state constraint, but a margin is established, providing space to account for uncertainty (the constraint is tightened). Increasing the risk parameter
β
increases the required distance towards the state constraint, again resulting in less constraint violation.

\displaystyle\min_{\bm{U}}

\displaystyle\sum_{k=0}^{N-1}\bm{x}_{k}^{\top}\bm{Q}\bm{x}_{k}+u_{k}^{\top}\bm{R}u_{k}

(28a)

s.t.

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}u_{k},

\displaystyle~k\in\{0,...,N-1\}

(29a)

\displaystyle|u_{k}|\leq 0.2,

\displaystyle~k\in\{0,...,N-1\}

(30a)

\displaystyle x_{1,k}\leq 2.8,

\displaystyle~k\in\{1,...,N\}

(31a)

3
Details on SMPC with Chance Constraints

In the following, a brief derivation of chance constraints in SMPC is provided. First, the system, constraint, and chance constraint setup are introduced.

We consider a linear system with additive uncertainty
\bm{w}_{k}

, i.e.,

\displaystyle\bm{x}_{k+1}=\bm{A}\bm{x}_{k}+\bm{B}\bm{u}_{k}+\bm{D}\bm{w}_{k}.

(32)

The system state is split into a deterministic state
\bm{z}_{k}
and a probabilistic error
\bm{e}_{k}
. The input is also split into two parts, a feedback law stabilizing the deterministic system, as well as a new input
\bm{v}_{k}
accounting for uncertainty. These considerations yield

\displaystyle\bm{x}_{k}

\displaystyle=\bm{z}_{k}+\bm{e}_{k}

(33a)

\displaystyle\bm{u}_{k}

\displaystyle=\bm{K}\bm{x}_{k}+\bm{v}_{k}

(34a)

Splitting the system state results in the new system models

\displaystyle\bm{z}_{k+1}

\displaystyle=\bm{\Phi}\bm{z}_{k}+\bm{B}\bm{v}_{k}

(35a)

\displaystyle\bm{e}_{k+1}

\displaystyle=\bm{\Phi}\bm{e}_{k}+\bm{D}\bm{w}_{k}

(36a)

with
\bm{\Phi}=\bm{A}+\bm{B}\bm{K}
.

We consider the linear constraint

\displaystyle\bm{g}^{\top}_{k}\bm{x}_{k}\leq h_{k}.

(37)

Comparing (
37
) to the simulation example in Section
2
, we obtain
\bm{g}_{k}^{\top}=[1,0]^{\top}
and
h_{k}=2.8
.

As the system state is subject to (unbounded) uncertainty, it is not possible to guarantee constraint satisfaction in all cases. Therefore, we introduce a probabilistic constraint (chance constraint), which bounds the constraint violation probability depending on a risk parameter
\beta
, yielding

\displaystyle\mathrm{Pr}\left(\bm{g}^{\top}_{k}\bm{x}_{k}\leq h_{k}\right)\geq\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}.

(38)

With the deterministic and error states, we obtain

\displaystyle\mathrm{Pr}\left(\bm{g}^{\top}_{k}\bm{z}_{k}+\bm{g}^{\top}_{k}\bm{e}_{k}\leq h_{k}\right)\geq\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}.

(39)

The chance constraint (
39
) is not a deterministic expression. It is necessary to reformulate the chance constraint, such that a tractable expression is obtained, which is then used to solve the optimization problem. For zero uncertainty, the deterministic part of the state must satisfy the state constraint. However, if uncertainty is present, the constraint must be tightened by a tightening parameter
\gamma_{k}
. This tightening parameter is determined depending on the uncertainty and the risk parameter
\beta
. We therefore reformulate the chance constraint (
39
) into

\displaystyle\bm{g}^{\top}_{k}\bm{z}_{k}

\displaystyle\leq h_{k}-\gamma_{k}

(40a)

\displaystyle\mathrm{Pr}\left(\bm{g}^{\top}_{k}\bm{e}_{k}\leq\gamma_{k}\right)

\displaystyle=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(41a)

where (
41a
) ensures that the tightening parameter is chosen in such a way, that the uncertainty only causes constraint violations as allowed by the risk parameter.

It is to note that (
40a
) is still not a deterministic expression. In the following, we derive how (
41a
) is reformulated into a deterministic approximation, based on the underlying uncertainty distribution.

3.1
Normally Distributed Uncertainty

First, we analyze the chance constraint reformulation for an uncertainty
\bm{w}_{k}
subject to a normal distributions with zero mean, i.e,
\bm{w}_{k}\sim\mathcal{N}\left(0,\bm{\Sigma}\right)
. Similar reformulations are also used in
[
BOW11
,
OW08
,
FGMS15
,
CGLB14
,
BOLW18
]
.

Given the normal distribution with zero mean, the error is also normally distributed according to

\displaystyle\bm{e}_{k}\sim\mathcal{N}\left(0,\bm{\Sigma}^{e}_{k}\right)

(42)

with
\bm{\Sigma}^{e}_{0}=0\bm{I}
and

\displaystyle\bm{\Sigma}_{k+1}^{e}=\bm{\Phi}\bm{\Sigma}_{k}^{e}\bm{\Phi}^{\top}+\bm{D}\bm{\Sigma}_{w}\bm{D}^{\top}.

(43)

It follows that the constraint state expression is also normally distributed according to

\displaystyle\bm{g}^{\top}\bm{e}_{k}\sim\mathcal{N}\left(0,\bm{g}^{\top}\bm{\Sigma}^{e}_{k}\bm{g}\right)

(44)

where we assume that
\bm{g}^{\top}\bm{e}_{k}
is scalar and abbreviate the variance with
\sigma^{2}=\bm{g}^{\top}\bm{\Sigma}^{e}_{k}\bm{g}

3.1.1
Chance constraint reformulation

Based on the
cumulative distribution function (cdf)
of a normal distribution

\displaystyle\mathrm{Pr}\left(\bm{g}^{\top}_{k}\bm{e}_{k}\leq\gamma_{k}\right)=\frac{1}{2}\left[1+\mathrm{erf}\left(\frac{\gamma_{k}}{\sigma\sqrt{2}}\right)\right]=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(45)

it is possible to find a deterministic expression for the tightening parameter
\gamma_{k}
with the following reformulation:

\displaystyle\frac{1}{2}\left[1+\mathrm{erf}\left(\frac{\gamma_{k}}{\sigma\sqrt{2}}\right)\right]

\displaystyle=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(46a)

\displaystyle\mathrm{erf}\left(\frac{\gamma_{k}}{\sigma\sqrt{2}}\right)

\displaystyle=2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1

(47a)

\displaystyle\frac{\gamma_{k}}{\sigma\sqrt{2}}

\displaystyle=\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)

(48a)

\displaystyle\gamma_{k}

\displaystyle=\sqrt{2}\sigma~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)

(49a)

Details on the
cdf
of a normal distribution are found in Appendix
A.1
.

Inserting the variance
\sigma^{2}=\bm{g}^{\top}\bm{\Sigma}^{e}_{k}\bm{g}
, we obtain the tightening parameter

\displaystyle\gamma_{k}

\displaystyle=\sqrt{2}\sqrt{\sigma^{2}}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)

(50a)

\displaystyle=\sqrt{2}\sqrt{\bm{g}^{\top}\bm{\Sigma}^{e}_{k}\bm{g}}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)

(51a)

\displaystyle=\sqrt{2\bm{g}^{\top}\bm{\Sigma}^{e}_{k}\bm{g}}~\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1).

(52a)

3.1.2
Discussion

In general, the risk parameter is bounded by
0.5\leq\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}<1
. If the state is exactly on the constraint, given the normal distribution, the probability of violating the constraint in the next step without tightening the constraint is exactly
50\%
. Therefore, no constraint tightening corresponds to a risk parameter of
\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}=0.5
. A risk parameter
\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}=1
would guarantee constraint satisfaction. Given the unbounded uncertainty due to the normal distribution, it would follow that
\gamma_{k}=\infty
(as
\mathrm{erf}^{-1}(1)=\infty
). Obviously, this is not practical. While it is mathematically possible to choose
\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}<0.5
, this does not make sense, as this equals loosening the original hard constraint (constraint loosening instead of constraint tightening).

Furthermore, it is to note that the resulting constraint satisfaction may by larger than specified by the risk parameter, depending on the system and constraints. At first glance, this is surprising, as a normal distribution allows finding an exact reformulation of the chance constraint. However, the tightening parameter
\gamma_{k}
increases with increasing prediction steps. To account for this, the realized tightening (due to predicting multiple MPC steps) may be larger than the tightening
\gamma_{1}
required to hold for the next step. The chance constraint satisfaction considers only individual prediction steps, not the probability of violating the constraint over an entire trajectory.

3.2
General Probability Distributions

A chance constraint reformulation is also possible for general probability distributions. Here, we consider univariate distributions with zero mean and variance
\sigma_{w}^{2}
. While a normal distribution allows an exact reformulation, chance constraints for general distributions may only be approximated. An overview is found in
[
FGS16
]
.

Based on the Cantelli’s inequality, see Appendix
A.2
, it is possible to determine a bound on the
cdf
, yielding

\displaystyle\mathrm{Pr}\left(e_{k}<\gamma_{k}\right)\geq 1-\frac{\sigma^{2}}{\gamma_{k}^{2}+\sigma^{2}}=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(53)

where the risk parameter represents the required bound and
\sigma
represents the variance of the error, similar to
\bm{\Sigma^{e}}
before.

Reformulating results in

\displaystyle 1-\frac{\sigma^{2}}{\gamma_{k}^{2}+\sigma^{2}}

\displaystyle=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(54a)

\displaystyle\frac{\sigma^{2}}{\gamma_{k}^{2}+\sigma^{2}}

\displaystyle=1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(55a)

\displaystyle\sigma^{2}

\displaystyle=(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})(\gamma_{k}^{2}+\sigma^{2})

(56a)

\displaystyle\sigma^{2}

\displaystyle=\gamma_{k}^{2}(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})+\sigma^{2}(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})

(57a)

\displaystyle\sigma^{2}+\sigma^{2}(\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}-1)

\displaystyle=\gamma_{k}^{2}(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})

(58a)

\displaystyle\sigma^{2}(1+\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}-1)

\displaystyle=\gamma_{k}^{2}(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})

(59a)

\displaystyle\gamma_{k}^{2}

\displaystyle=\sigma^{2}\frac{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}{1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}

(60a)

\displaystyle\gamma_{k}

\displaystyle=\sigma\sqrt{\frac{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}{1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}}}

(61a)

representing a constraint tightening parameter for general probability distributions. We can rewrite this expression as

\displaystyle\gamma_{k}=\sigma Q(\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})

(62)

where the quantile function
Q(\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})
may be considered as the inverse
cdf
.

Unlike the reformulation for the norm constraint, the risk parameter here may take values
0\leq\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}<0
.

A comparison between constraint tightening based on (
52a
), i.e,
\sqrt{2}\mathrm{erf}^{-1}(2\lx@glossaries@gls@link{symbols}{rp_{b}rackets}{{{}}\beta}-1)
, and (
61a
), i.e.,
\sqrt{\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}/(1-\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta})}
, is shown in Figure
1
. Note that the constraint tightening in Figure
1
is not
\gamma_{k}
, as variance is not considered. It is obvious that the constraint tightening for general probability distributions according to (
61a
) is more conservative.

3.3
Normal Distributions with Non-zero Mean

For non-zero mean probability distributions, the chance constraint must be reformulated slightly.

For a normal distribution with non-zero mean
\bm{\mu}
, (
40a
) must be adapted to

\displaystyle\bm{g}^{\top}_{k}\bm{z}_{k}

\displaystyle\leq h_{k}-\mathrm{E}\left(\bm{g}^{\top}_{k}\bm{e}_{k}\right)-\gamma_{k}

(63a)

\displaystyle\mathrm{Pr}\left(\bm{g}^{\top}_{k}\bm{e}_{k}-\mathrm{E}\left(\bm{g}^{\top}_{k}\bm{e}_{k}\right)\leq\gamma_{k}\right)

\displaystyle=\lx@glossaries@gls@link{symbols}{rp}{{{}}\beta}

(64a)

where the scalar expectation value
\mathrm{E}\left(\bm{g}^{\top}_{k}\bm{e}_{k}\right)
represents an additional constraint tightening to account for the non-zero mean
\bm{\mu}
.

Appendix A
Probability Theory Basics

A.1
Normal Distributions

A normal distribution (also known as a Gaussian distribution) is characterized by its mean
\bm{\mu}
and its covariance
\bm{\Sigma}
, abbreviated by
\mathcal{N}\sim(\bm{\mu},\bm{\Sigma})
. A special case is given by the standard normal distribution where
\bm{\mu}=\bm{0}
and
\bm{\Sigma}=\bm{I}
with identity matrix
\bm{I}
. In the following, we consider the univariate normal distribution with mean
\mu
, variance
\sigma^{2}
, and standard deviation
\sigma
.

The
probability density function (pdf)
is given by

\displaystyle f(x)=\frac{1}{\sigma}\frac{1}{\sqrt{2\pi}}\mathrm{exp}\left(-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)\right)

(65)

where it holds that

\displaystyle\int_{-\infty}^{\infty}f(x)\mathrm{d}x=1.

(66)

The factor
\frac{1}{\sigma}
accounts for the adjusted variance compared to the standard normal distribution.

For a continuous distribution, the
pdf
at a specific point
x
does not yield a probability. Therefore, we introduce the
cdf
with random variable
X

\displaystyle\mathrm{Pr}(X\leq x)=\Phi(x)=\int_{-\infty}^{x}f(x)\mathrm{d}x

\displaystyle=\frac{1}{2}\left[1+\mathrm{erf}\left(\frac{x-\mu}{\sigma\sqrt{2}}\right)\right]

(67a)

\displaystyle=\frac{1}{2}+\frac{1}{2}\mathrm{erf}\left(\frac{x-\mu}{\sigma\sqrt{2}}\right).

(68a)

For
x=\mu
, the cumulative probability is exactly
0.5
.

In the
cdf
, only one side of the distribution is considered. If we consider both sides, we obtain

\displaystyle\mathrm{Pr}(-x\leq X\leq x)

\displaystyle=\int_{-x}^{x}f(x)\mathrm{d}x

(69a)

\displaystyle=\int_{-x}^{0}f(x)\mathrm{d}x+\int_{0}^{x}f(x)\mathrm{d}x

(70a)

\displaystyle=2\int_{0}^{x}f(x)\mathrm{d}x

(71a)

\displaystyle=2\left(\int_{-\infty}^{x}f(x)\mathrm{d}x-\int_{-\infty}^{0}f(x)\mathrm{d}x\right)

(72a)

\displaystyle=2\left(\left(\frac{1}{2}+\frac{1}{2}\mathrm{erf}\left(\frac{x-\mu}{\sigma\sqrt{2}}\right)\right)-\frac{1}{2}\right)

(73a)

\displaystyle=\mathrm{erf}\left(\frac{x-\mu}{\sigma\sqrt{2}}\right).

(74a)

A.2
Chebyshev’s Inequality

Chebyshev’s inequality provides a bound for probability distributions. Chebyshev’s inequality indicates how likely it is that a random variable differs from the mean given a certain threshold
c
.

For zero mean distributions, i.e.,
\mu=0
, and variance
\sigma^{2}
, it holds that

\displaystyle\mathrm{Pr}\left(|X|\geq c\right)\leq\frac{\sigma^{2}}{c^{2}}

(75)

where
c>0
. Complementary, it holds that

\displaystyle\mathrm{Pr}\left(|X|<c\right)\geq 1-\frac{\sigma^{2}}{c^{2}}.

(76)

Note the change from
\geq
to
<
.

The zero mean results may be extended to distributions with mean
\mu\neq 0
, yielding

\displaystyle\mathrm{Pr}\left(|X-\mu|\geq c\right)

\displaystyle\leq\frac{\sigma^{2}}{c^{2}}

(77a)

\displaystyle\mathrm{Pr}\left(|X-\mu|<c\right)

\displaystyle\geq 1-\frac{\sigma^{2}}{c^{2}}.

(78a)

Cantelli’s Inequality

The one-sided Chabyshev’s inequality is also known as the Cantelli’s inequality where only a single tail of the distribution is considered. Cantelli’s inequality for zero mean and non-zero mean distributions is given by

\displaystyle\mathrm{Pr}\left(X\geq c\right)

\displaystyle\leq\frac{\sigma^{2}}{\sigma^{2}+c^{2}}

(79a)

\displaystyle\mathrm{Pr}\left(X-\mu\geq c\right)

\displaystyle\leq\frac{\sigma^{2}}{\sigma^{2}+c^{2}}.

(80a)

from which it follows that

\displaystyle\mathrm{Pr}\left(X<c\right)=1-\mathrm{Pr}\left(X-\mu\geq c\right)\geq 1-\frac{\sigma^{2}}{\sigma^{2}+c^{2}}

(81a)

\displaystyle\mathrm{Pr}\left(X-\mu<c\right)=1-\mathrm{Pr}\left(X-\mu\geq c\right)\geq 1-\frac{\sigma^{2}}{\sigma^{2}+c^{2}}.

(82a)
