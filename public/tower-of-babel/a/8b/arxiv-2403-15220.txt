Modelling with Discretized Variables
Felix Chan † , László Mátyás ‡ and Ágoston Reguly

Abstract
This paper deals with econometric models in which the dependent variable, some explanatory variables, or both are observed as censored interval data. This discretization often happens due to confidentiality of ‘sensitive’ variables like income. Models using these variables cannot point identify regression parameters as the conditional moments are unknown, which led the literature to use interval estimates. Here, we propose a discretization method through which the regression parameters can be point identified while preserving data confidentiality. We demonstrate the asymptotic properties of the OLS estimator for the parameters in multivariate linear regressions for cross-sectional data. The theoretical findings are supported by Monte Carlo experiments and illustrated with an application to the Australian gender wage gap.

Introduction

Over the last decade, there has been an explosion in the amount of data collected on individuals, firms, the economy, and society. Governments and the private sector gather large amounts of information that researchers and analysts use on a daily basis. Privacy constraints often prevent access to sensitive data in its original form. One common practice is to discretize sensitive data and provide observations that refer to intervals rather than the actual values.

Discretized explanatory variable

Discretization on both sides

3
Split Sampling

The key to our approach is the use of split sampling, which recovers the marginal distribution of
Z
even if it is discretized. We achieve convergence in distribution with the use of multiple discretization schemes with different thresholds for each interval. As we increase the number of discretization schemes to
infinity
along with the number of observations, we reduce the widths of the intervals to zero, which leads to mapping the required marginal distributions. This split sampling method can be viewed as a nonparametric estimator of the marginal distribution. Similarly, as before, we first discuss the univariate case and then extend our approach to the multivariate case.

We create multiple samples (
s=1,\dots,S
) and discretize them through different schemes while fixing the number of intervals (
M
) within each split sample. The reason for fixing
M
is simple: in the case of data protection, it allows to keep the values non-recognizable.
20
20

20

In the case of questionnaires, fixing small

is also advisable as one needs to account for restricted human cognitive capacity.
After generating the data for each split sample, we collect the different outcomes of the discretizations for the ‘

’. This ‘

We show that we can create a synthetic variable

asymptotically converges to
f_{Z}(\cdot)
for the ‘shifting method’. It is possible to introduce alternative split sampling methods, and we refer the reader to the
online supplement
, Section A.4, where we discuss an alternative of shifting method in detail.

3.2
The shifting method

The shifting method takes the original discretization as given with fixed interval widths, and shifts the boundaries of the intervals with a certain value. The interval widths for the different split samples remain the same, except for the boundary intervals. As one increases the number of split samples the size of the shift becomes smaller and smaller. This enables to mapping of the marginal probability distribution at the limit using inductive logic. First, we introduce the discretization process proposed for the shifting method and as a second step, we show how to use the realizations of this discretization to create a synthetic variable that maps the original variable’s marginal distribution.

To derive the properties of the shifting method, we define the uniform class widths for the first split sample as
\frac{a_{u}-a_{l}}{M-1}
. We split these intervals into
S

S

h=\frac{a_{u}-a_{l}}{S(M-1)}\,.

This implies that the number of intervals in the working sample is
B=S(M-1)
.
The boundary points for each split sample are given by

c^{(s)}_{m}=\begin{cases}a_{l}\text{ or }-\infty,&\text{ if }m=0,\\
a_{l}+(s-1)\frac{a_{u}-a_{l}}{S(M-1)}+(m-1)\frac{a_{u}-a_{l}}{M-1}&\text{ if }0<m<M,\\
a_{u}\text{ or }\infty,&\text{ if }m=M.\\
\end{cases}

For the working sample we get
c^{WS}_{b}=a_{l}+b\frac{a_{u}-a_{l}}{S(M-1)}
with the following class widths:

||C^{(s)}_{m}||=\begin{cases}0,&\text{ if }s=1\text{ and }m=1,\\
\frac{a_{u}-a_{l}}{M-1},&\text{ if }1<m<M,\\
(s-1)\frac{a_{u}-a_{l}}{S(M-1)},&\text{ otherwise}.\end{cases}

Here each interval width is uniformly given by
||C^{WS}_{b}||=\frac{a_{u}-a_{l}}{S(M-1)}
.
Some remarks on these boundary points:

•

The interval widths for the working sample shrink, i.e.,
||C^{WS}_{b}||\to 0
as
S\to\infty
.

•

The interval widths
C^{(s)}_{2},C^{(s)}_{3},\dots,C^{(s)}_{M-1}
for all
s
are fixed and independent from the number of split samples.

•

The boundary classes’ widths,
C^{(s)}_{1},C^{(s)}_{M}
for
s\notin\left\{2,S\right\}
are a function of the number of split samples.

•

C^{(2)}_{1}\cong C^{WS}_{1},C^{(S)}_{M}\cong C^{WS}_{B}
are congruent. In the case of data protection if
h
is too small, individuals falling into these intervals might be identifiable.

•

C^{(1)}_{1}
has size 0 and does not exist in practice. It is induced by the formalism we use.

3.3
Further remarks

Other split sampling methods

Here, we have discussed one particular split sampling method, the shifting method. However, it is possible to work out other discretization schemes that can map the underlying marginal distribution of
Z
. In fact, in the
online supplement
, Section A.4, we introduce the
magnifying method
, which offers an alternative method to learn
f_{Z}(z;a_{l},a_{u})
. The key to all potential split sampling methods is to achieve convergence in distribution. Different discretizations may yield different speeds of convergence and other data protection properties.
25
25

25

For example, the magnifying method can not maintain data protection properties for certain individuals as it achieves convergence in distribution by narrowing specific parts of the domain to zero at the limit, revealing the actual value of
Z
. See more details in
online supplement
, Section A.4.

Multivariate case

One can extend the shifting method to learn the joint distribution of
\mathbf{Z}
. The shifting method in the multivariate case utilizes the initial discretization scheme with
\mathbf{C}_{m}
and shifts the boundary points of the grids with
\mathbf{h}=\frac{\mathbf{a}_{u}-\mathbf{a}_{l}}{S(M-1)}
. This results in
(S(M-1))^{P}
different grids in the working sample, which is much larger than the initial
M^{P}
. Changing the grids’ boundary points allows for mapping the underlying distribution using the same inductive logic to prove convergence in distribution. For the proof, we need the same assumptions extended to the multivariate case,
N/S\to c,\int^{\mathbf{b}}_{\mathbf{a}}\mathbf{f}_{\mathbf{Z}}(\mathbf{z})d\mathbf{z}>0
for any
(\mathbf{a},\mathbf{b})\subset[\mathbf{a}_{l},\mathbf{a}_{u}]
and
\Pr(\mathbf{z}\in\mathcal{S}_{s})=1/S
. See the detailed argument in the
online supplement
, Section A.2.3.

Infinite support

As a last point, we consider the case when
Z
has infinite support. If we set the first and last intervals’ boundary points to infinity, we are facing censoring. As we show in Section
4.4
, one can extend our approach for censoring by using the continuous mapping theorem. However, this is beyond the scope of this paper, and we would rather discuss here a simpler solution: removing those observations that fall into the first or last intervals
(C^{(s)}_{1},C^{(s)}_{M})
of the discretized variable. This way, one needs to truncate not only
Z
, but all other observed variables. The flip side of this process is that for the truncated distribution, all previous derivations and results apply.

Step 2.

4.5
Panel data and perception effect

In the case of panel data, the extension of this methodology is relatively straightforward. The most important difference is in the identification. If the interval of an individual does not change over the time periods covered, the individual effects in the panel and the parameter associated with the choice variable cannot be identified separately. The within transformation would wipe out the interval variable as well. When the interval does change over time, but not much, then we are facing weak identification, i.e., in fact very little information is available for identification, so the parameter estimates are going to be highly unreliable. (See more in
online supplement
, Section A.5.6.)

To extend our method towards fixed effect type of estimators, let us discuss a further phenomenon that we call the
perception effect
. The perception effect is relevant if the discretization happens through surveys. There is much evidence in the behavioral literature that the answers to a question may depend on the way the question is asked (see, e.g.,
Diamond and Hausman, 1994
,
Haisley et al., 2008
and
Fox and Rottenstreich, 2003
).

\hat{\boldsymbol{\beta}}=\left(\tilde{\mathbf{X}}^{\prime}\mathbf{M}_{\mathbf{T}}\tilde{\mathbf{X}}\right)^{-1}\tilde{\mathbf{X}}^{\prime}\mathbf{M}_{\mathbf{T}}\tilde{\mathbf{y}}^{**}

While the above discussion focuses on discretization happening with the outcome variable, similar extensions can be done when discretization happens with one or more explanatory variables or discretization is present on both sides of the regression equation. In the
online supplement

B_{sm}

7
Conclusion

This paper deals with econometric models where variables are continuous but observed through a discretization process that results in interval censored data. Discretization is becoming increasingly common in practice, particularly when dealing with sensitive data where discretization protects privacy (e.g., income). Modeling with such variables in a regression framework is problematic as the conditional expectation is unknown and the parameters of interest cannot be point identified.

Instead of following the partial identification approach, which provides set intervals for the parameters of interest, we propose new techniques to point identify the parameters of interest. Our approach hinges on
split sampling
, which enables the mapping of the underlying variables’ distributions while preserving the data privacy requirements. We utilize the mapped (marginal) distribution and modify the original regression model, which allows the transformed variables to point identify the original parameters of interest. Identification depends on where the discretization happens: i) the discretized variable is an explanatory variable; ii) the discretized variable is the outcome; and iii) when discretization happens on both sides. The three cases require different types of transformations of the variables. We examine the methods of identifying strategies in all instances, initially using univariate examples and subsequently expanding them to encompass multivariate cases.

During the identification, we assumed the marginal distributions were known, which is not true in practice. As the next step, we describe an implementation of split sampling, the
shifting method
, which systematically shifts the boundary points of each interval while preserving data confidentiality. We show convergence in distribution for the underlying unknown variable by the shifting method, which reduces the size of the shift towards zero by increasing the number of split samples. This mechanism allows us to nonparametrically identify the marginal distribution.

For the three modeling purposes, we can use the mapped distribution of the underlying variable. We derive different consistent estimators based on the mapped marginal distribution, which leads to consistent parameter estimates for all cases in a cross-sectional setup. We show the asymptotic properties of these estimators and discuss extensions to nonlinear models, panel data and fixed effect type of estimators. We provide Monte Carlo evidence to show that our methods have superior finite sample properties compared to the ‘usual’ methods. Finally, we investigate our method in practice using the case study of the Australian gender wage gap. Results show that with the shifting method, we get close estimates for the gender wage gap parameter even when the number of intervals is small, only 3 or 5.
