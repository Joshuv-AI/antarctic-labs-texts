A finite element method to a periodic steady-state problem for an electromagnetic field system using the space-time finite element exterior calculus Journal: Jounal of L a T e X Templates
Masaru Miyashita, Norikazu Saito

Abstract
This paper proposes a finite element method for solving the periodic steady-state problem for the scalar-valued and vector-valued Poisson equations, a simple reduction model of the Maxwell equations under the Coulomb gauge. Introducing a new potential variable, we reformulate two systems composed of the scalar-valued and vector-valued Poisson problems to a single Hodge-Laplace problem for the 1 1 -form in ℝ 4 \mathbb{R}^{4} using the standard de Rham complex. Consequently, we can apply the Finite Element Exterior Calculus (FEEC) theory in ℝ 4 \mathbb{R}^{4} directly to deduce the well-posedness, stability, and convergence. Numerical examples using the cubical element are reported to validate the theoretical results.

4.3
Arrow–Hurwicz Algorithm (AHA)

As is stated in §
3.2
, the periodic steady-state problem (
1
) is equivalent to the
\mathcal{B}_{1}^{*}
problem of the Hodge Laplace problem (
34
);

u=dx_{0}\wedge\phi+A\in\mathcal{B}_{1}^{*},\quad\operatorname{D}_{2}^{*}\operatorname{D}^{1}u=F,

(57)

where
F=dx_{0}\wedge\bar{\rho}+\bar{j}\in\mathcal{B}_{1}^{*}=\mathcal{R}(\operatorname{D}_{2}^{*})
. We recall that
\mathcal{B}_{1}^{*}
is defined as
\mathcal{B}_{1}^{*}=\mathcal{R}(\operatorname{D}_{2}^{*})\subset\mathcal{N}(\operatorname{D}_{1}^{*})
.
If
F\in\mathcal{B}_{1}^{*}
is given exactly (in a suitable discrete sense), we can obtain the solution
u
by solving the full Hodge Laplace problem (
34
). However, it is difficult to ensure
F\in\mathcal{B}_{1}^{*}
in the actual computation. Therefore, it is useful to formulate (
57
) as a saddle point problem of the action
\mathcal{S}
defined as

\mathcal{S}(v,\tau)=\frac{1}{2}\langle{\operatorname{D}^{1}v,\operatorname{D}^{1}v}\rangle_{2}-\langle{v,\operatorname{D}^{0}\tau}\rangle_{1}-\langle{F,v}\rangle_{1}\quad(v\in HM^{1},\tau\in HM^{0}).

(58)

Recall that
(u,\sigma)\in HM^{1}\times HM^{0}
is called a saddle point of
\mathcal{S}
if it satisfies

\mathcal{S}(u,\tau)\leq\mathcal{S}(u,\sigma)\leq\mathcal{S}(v,\sigma)\qquad(\forall(v,\tau)\in HM^{1}\times HM^{0}).

(59)

To be more specific, we state the following theorem.

Theorem 4
.

A couple of differential forms
(u,\sigma)\in HM^{1}\times HM^{0}
is a a saddle point of
\mathcal{S}
if and only if it solves the mixed weak form of (
57
) given as

\displaystyle\langle{\operatorname{D}^{1}u,\operatorname{D}^{1}v}\rangle_{2}+\langle{\operatorname{D}^{0}\sigma,v}\rangle_{1}

\displaystyle=\langle{F,v}\rangle_{1}

\displaystyle(\forall v\in H{M}^{1}),

(60a)

\displaystyle\langle{u,\operatorname{D}^{0}\tau}\rangle_{1}

\displaystyle=0

\displaystyle(\forall\tau\in H{M}^{0}).

(60b)

Proof.

Let
(u,\sigma)\in HM^{1}\times HM^{0}
satisfy (
59
).
For any
\epsilon\in\mathbb{R}
and
(v,\tau)\in HM^{1}\times HM^{0}
, we have

0\leq\mathcal{S}(u+\epsilon v,\sigma)-\mathcal{S}(u,\sigma)=\frac{\epsilon^{2}}{2}\langle{\operatorname{D}^{1}v,\operatorname{D}^{1}v}\rangle_{2}+\epsilon[\langle{\operatorname{D}^{1}u,\operatorname{D}^{1}v}\rangle_{2}+\langle{v,\operatorname{D}^{0}\tau}\rangle_{1}-\langle{F,v}\rangle_{1}].

Therefore, letting
\epsilon\downarrow 0
, we obtain

\langle{\operatorname{D}^{1}v,\operatorname{D}^{1}v}\rangle_{2}+\langle{\operatorname{D}^{0}\tau,v}\rangle_{1}-\langle{F,v}\rangle_{1}\leq 0,

and, letting
\epsilon\uparrow 0
,

\langle{\operatorname{D}^{1}v,\operatorname{D}^{1}v}\rangle_{2}+\langle{\operatorname{D}^{0}\tau,v}\rangle_{1}-\langle{F,v}\rangle_{1}\geq 0.

Consequently, we deduce (
60a
).
Moreover, (
60b
) is verified using

0\geq\mathcal{S}(u,\sigma+\epsilon q)-\mathcal{S}(u,\sigma)=-\epsilon\langle{u,\operatorname{D}^{0}\tau}\rangle_{1}.

The converse is proved in the similar way.
∎

We have shown that the Hodge Laplacian problem can be formulated as a saddle point problem. After a discretization, the saddle point formulation be written as a matrix form,

\begin{bmatrix}\begin{array}[]{rr}\bm{A}&\bm{B}^{T}\\
\bm{B}&\bm{0}\end{array}\end{bmatrix}\begin{bmatrix}\bm{u}\\
\bm{\sigma}\\
\end{bmatrix}=\begin{bmatrix}\bm{F}\\
0\\
\end{bmatrix}.

(61)

Since the coefficient matrix is in general indefinite, a special solver is required.
There are many methods for solving matrix equations.
In this study, we employed the Arrorw-Hurwicz Algorithm, a kind of Uzawa-type iterative solution method developed in economics
[
17
,
18
]
.

Arrorw-Hurwicz Algorithm (AHA)

1.

Chose an initial guess
\bm{u}^{0}
and
\bm{\sigma}^{0}
.

2.

For k=0,1,2,…., until convergence of iterative error Do:

3.

\bm{\sigma}^{k+1}=\bm{\sigma}^{k}+\delta\bm{B}\bm{u}^{k}

4.

\bm{u}^{k+1}=\bm{u}^{k}+\omega(\bm{F}-\bm{A}\bm{u}^{k}-\bm{B}^{T}\bm{\sigma}^{k+1})

5.

EndDo

The
\bm{A}
matrix is the main part of the Laplacian and contains the scalar Laplacian and the vector Laplacian.
The
\bm{B}
matrix is the term that represents
\operatorname{div}A=0
.
The potential
\phi
term has degenerated.
Since
\bm{A}
alone is an indefinite problem, it is an iterative method that oscillates toward the unique saddle point while taking
\operatorname{div}A=0
into account.

Conclulding Remarks

In this paper, the periodic steady-state of electromagnetic fields is calculated using differential forms in 4-dimensional space-time.
In the conventional method, the scalar potential 0-form and the vector potential 1form are considered separately on the three-dimensional de Rham Complex.
In the proposed formulation, the scalar potential 0-form and the vector potential 1-form are treated simultaneously as 1-form in the 4-dimensional spacetime.

And the proposed formulation is equivalent to the weakly mixed formulation of the Hodge-Laplacian in the 4-dimensional spacetime.
Then, the wellposedness of this 4-dimensional Hodge-Laplacian is shown using the FEEC framework.
For the function space of the discrete solution, we considered the direct product space of shifted (k-1)-form space(cubical element space) in the 3-dimension and k-form space(cubical element space).
It was also shown that this product space coincides with the 4-dimensional cubical element space.
The unbounded cochain map between a 4-dimensional complex and its approximate complex exists by using the approximate map from the cubical element spaces to the differential form space on the 3-dimensional space.
Then, we show the well-posedness of the formulation of the weakly mixed problem using the framework of FEEC theory.

We have tested the proposed method on two example problems.
The example 1, the exact solution exists, the discrete solution converges to the exact solution in optimal order by the proposed method.
The more concrete example2 shows that the proposed method can solve problems with non-zero boundary conditions for the scalar potential.
These results support our theoretical analysis and the usefulness of our proposed method.
In this paper, we have focused on a model in which the time derivative term is neglected.
In the future, it is expected that calculate Maxwell’s equations with time terms taken into account and develop another periodic steady problem such as fluid fields
Furthermore, extend to the coupled problems of electromagnetic and fluid fields for plasma simulation.
