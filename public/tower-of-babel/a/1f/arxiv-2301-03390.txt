Space-Query Tradeoffs in Range Subgraph Counting and Listing
Shiyuan Deng, Shangqi Lu, Yufei Tao

Abstract
This paper initializes the study of range subgraph counting and range subgraph listing , both of which are motivated by the significant demands in practice to perform graph analytics on subgraphs pertinent to only selected, as opposed to all, vertices. In the first problem, there is an undirected graph G G where each vertex carries a real-valued attribute. Given an interval q q and a pattern Q Q , a query counts the number of occurrences of Q Q in the subgraph of G G induced by the vertices whose attributes fall in q q . The second problem has the same setup except that a query needs to enumerate (rather than count) those occurrences with a small delay. In both problems, our goal is to understand the tradeoff between space usage and query cost , or more specifically: (i) given a target on query efficiency, how much pre-computed information about G G must we store? (ii) Or conversely, given a budget on space usage, what is the best query time we can hope for? We establish a suite of upper- and lower-bound results on such tradeoffs for various query patterns.

From “Delays with Duplicates” to “Delays under Distinctness”.
Let us consider a duplicate-removal scenario often encountered in designing algorithms with small delays. Suppose that we have an algorithm

for enumerating a set

By modifying a

\alpha\cdot\Delta

6
6

6

Recall that “time” in the RAM model is defined as the number of atomic operations (e.g., addition, multiplication, comparison, accessing a memory word, etc.) executed. Each epoch is essentially a sequence of
\alpha\cdot\Delta
such operations.
. As
\mathcal{A}
runs, we use a

to stash the set of distinct elements that have been found by
\mathcal{A}
but not yet reported. Every time
\mathcal{A}
finds an element

, we check whether

(this takes

B

has terminated, we simply output the remaining elements in

always contains at least one element at the end of each epoch. To see why, consider the end of the

. At this moment,

Next, we will attack Problem 1 by allowing

Problem 2: Arbitrary Subgraphs

We now proceed to tackle Problem 2 for an arbitrary query pattern
Q
. We will, in fact, solve the range join problem defined in Section
1.2.2
. As shown in Appendix
D
, it is relatively easy to convert our structure to prove Theorem

For a relation
R\in\mathcal{R}
(recall that
\mathcal{R}
is the set of input relations; see Section
1.2.2
) its scheme,
\mathit{scheme}(R)
, is the set of attributes in

. Let
\mathcal{X}=\bigcup_{R\in\mathcal{R}}\mathit{scheme}(R)
. The input size

can now be expressed as
\sum_{R\in\mathcal{R}}|R|
. We will assume, w.l.o.g., that (i) the relations in
\mathcal{R}
have distinct schemes, (ii)

is a power of 2, and (iii) each attribute
X\in\mathcal{X}
has a domain
\mathit{dom}(X)
comprising the integers in
[1,N]
. Given an interval
q=[x_{1},x_{2}]
, a query lists every tuple

in
\mathit{join}(\mathcal{R})
— the natural join result on
\mathcal{R}
— satisfying

for all

, where

is the tuple’s value under attribute

It will be convenient to work with a hypergraph
\mathcal{G}=(\mathcal{X},\mathcal{E})
where
\mathcal{E}=\{\mathit{scheme}(R)\mid R\in\mathcal{R}\}
. Given an edge

, we use

to denote the (only) relation

whose scheme is

. For a function

that assigns a non-negative weight

to every

, its

is
\sum_{e\in\mathcal{E}}W(e)
. The function

is a

if
\sum_{e\in\mathcal{E}:X\in e}W(e)\geq 1
holds on every attribute
X\in\mathcal{X}
. The
fractional edge covering number

{\rho^{*}}
of
\mathcal{G}
is the smallest lump-sum of all fractional edge coverings. Henceforth, we will use

to represent an optimal assignment function with lump-sum

The section’s main result is:

Theorem 5.1
.

For the range join problem (see Section

), given any
\Delta\geq 1
, there is a structure of
\tilde{O}(N+N^{\rho^{*}}/\Delta)

5.1
A Generalization of the AGM Bound

The classical AGM bound
[
4
]
states that
|\mathit{join}(\mathcal{R})|\leq\prod_{e\in\mathcal{E}}|R_{e}|^{W(e)}
. Next, we will present a more general version of this inequality.

Set
d=|\mathcal{X}|
and impose an arbitrary ordering on the
d
attributes:
X_{1},X_{2},...,X_{d}
. Given intervals
I_{1},I_{2},...,I_{d}
where
I_{i}\subseteq\mathit{dom}(X_{i})
for each

, define
B(I_{1},...,I_{d})
as the
d

I_{1}\times...\times I_{d}
. For a relation
R\in\mathcal{R}
, we use
R\ltimes B(I_{1},...,I_{d})
to represent the set of tuples
t\in R
such that
t[X_{i}]\in I_{i}
for every
i
satisfying
X_{i}\in\mathit{scheme}(R)
.

We prove in Appendix
C
:

Lemma 5.2
.

Let
\textrm{\boldmath${\mathcal{I}}$}_{i}
,
i\in[1,d]
, be a set of disjoint intervals in
\mathit{dom}(X_{i})
. Then:

\displaystyle\sum_{I_{1}\in\textrm{\boldmath${\mathcal{I}}$}_{1}}\sum_{I_{2}\in\textrm{\boldmath${\mathcal{I}}$}_{2}}...\sum_{I_{d}\in\textrm{\boldmath${\mathcal{I}}$}_{d}}\prod_{e\in\mathcal{E}}|R_{e}\ltimes B(I_{1},...,I_{d})|^{W(e)}\leq\prod_{e\in\mathcal{E}}|R_{e}|^{W(e)}.

(1)

To see how (
1
) captures the AGM bound, consider the special
\textrm{\boldmath${\mathcal{I}}$}_{i}
with size
|\mathit{dom}(X_{i})|
, namely, each interval in
\textrm{\boldmath${\mathcal{I}}$}_{i}
is a value in
\mathit{dom}(X_{i})
and vice versa. Thus,
|R_{e}\ltimes B(I_{1},...,I_{d})|
is either 0 or 1 such that the left hand side of (
1
) is precisely
|\mathit{join}(\mathcal{R})|
. The real power of (
1
), however, comes from allowing
\textrm{\boldmath${\mathcal{I}}$}_{i}
to be an arbitrary set of disjoint intervals, a feature crucial for us to prove Theorem
5.1

A remark is in order about why Lemma

is not trivial. It would be if the term
\prod_{e\in\mathcal{E}}|R_{e}\ltimes B(I_{1},...,I_{d})|^{W(e)}
in (

) was replaced by the output size of the join on the relations in
\{R_{e}\ltimes B(I_{1},...,I_{d})\mid e\in\mathcal{E}\}
. By the AGM bound, the term
\prod_{e\in\mathcal{E}}|R_{e}\ltimes B(I_{1},...,I_{d})|^{W(e)}
is an
upper bound
on the size of the join
\{R_{e}\ltimes B(I_{1},...,I_{d})\mid e\in\mathcal{E}\}
. The non-trivial goal is to show that the summation of all those

bounds (i.e., the left hand side of (

\prod_{e\in\mathcal{E}}|R_{e}|^{W(e)}
.

This subsection serves as a proof of Theorem

6.1
The Range Triangle Edges Problem

This subsection will discuss the following standalone problem.

Range Triangle Edges (RTE).
Let
G

; and (ii)
\Theta(m^{*})

is the number of edges reported in (i).

We will develop a structure of
O(m)
space that can answer a query in
\tilde{O}(m^{*})

m^{*}

\Theta(m^{*})

.

Let us represent a triangle occurrence in
G
as
\mathit{triangle}(u,v,w)
where
u,v,
and
w
are the triangle’s vertices. Ordering is important: we will always adhere to the convention
A_{u}<A_{v}<A_{w}
. Given an interval
q
, we denote by
E^{*}_{q}
the set of edges showing up in at least one triangle of
G_{q}
. Hence,
m^{*}=|E^{*}_{q}|
. If
\mathit{triangle}(u,v,w)
appears in

, we call
\{u,v\}
a type-1 edge,
\{v,w\}
a type-2 edge, and
\{u,w\}
a type-3 edge. The total number of edges of all three types is between
m^{*}
and
3m^{*}
.
9
9

9

An edge can be of different types in various triangle occurrences.
. Next, we explain how to extract the edges of each type in
G_{q}
.

Type 1 and 2.
We will discuss only type 1 because type 2 is symmetric. For each edge
\{u,v\}
in
G
(assume, w.l.o.g.,

), identify a
sentinel

for

as follows:

•

has no occurrence of the form
\mathit{triangle}(u,v,w)
;

•

otherwise,
w^{*}
has the smallest attribute among all the vertices

\mathit{triangle}(u,v,w)
in
G
.

Consider any interval
q=[x_{1},x_{2}]
. Observe that
\{u,v\}
is a type-1 edge for
q
if and only if
x_{1}\leq A_{u}
and
A_{w^{*}}\leq x_{2}
. This motivates us to convert type-1 edge retrieval to range reporting on 2D points (introduced in Section

P

(A_{u},A_{w^{*}})
for every

whose sentinel

is not null. Attach edge

to the point
(A_{u},A_{w^{*}})
so that the former can be fetched along with the latter. The size of

is at most
m
. Given

, we can find all the type-1 edges by enumerating the points of
P
inside the rectangle
[x_{1},\infty)\times(-\infty,x_{2}]

in a Chazelle’s structure (see Section

A similar approach works for type 3. Let
\{u,w\}

if and only if
x_{1}\leq A_{u}

We run the algorithm of Bjorklund et al.

\displaystyle S^{i}_{\mathit{no}}=S^{i-1}_{\mathit{no}}\cup S^{i-1}_{\mathit{yes}}\text{ and then }S^{i}_{\mathit{yes}}

\displaystyle=

\displaystyle S^{i}_{\mathit{raw}}\setminus S^{i}_{\mathit{no}}.

Run

\displaystyle\alpha\cdot\frac{m^{\frac{3(\omega-1)}{\omega+1}}k_{i}^{\frac{3-\omega}{\omega+1}}}{|S^{i-1}_{\mathit{yes}}|}

(4)

\displaystyle\tilde{O}\left(\frac{m^{\frac{3(\omega-1)}{\omega+1}}}{k_{i}^{\frac{2\omega-2}{\omega+1}}}\right)=\tilde{O}\left(m^{\frac{\omega-1}{\omega+1}}\right)

(5)

For

\displaystyle|S^{i-1}_{\mathit{yes}}|
