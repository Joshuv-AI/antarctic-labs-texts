The complex mKdV equation with step-like initial data: Large time asymptotic analysis
Zhaoyu Wang, Kai Xu, Engui Fan

Abstract
In this paper, we study large-time asymptotics for the complex modified Korteveg-de Vries equation u t + 1 2 ​ u x ​ x ​ x + 3 ​ | u | 2 ​ u x = 0 , u_{t}+\frac{1}{2}u_{xxx}+3|u|^{2}u_{x}=0, (0.1) with the step-like initial data u ⁡ ( x , 0 ) = u 0 ​ ( x ) = { 0 , x ≥ 0 , A ​ e i ​ B ​ x , x < 0 . u(x,0)=u_{0}(x)=\begin{cases}0,&{x\geq 0,}\\ Ae^{iBx},&{x<0.}\end{cases} (0.2) It is shown that the step-like initial problem can be described by a matrix Riemann-Hilbert problem. F_{-}(k)F_{+}(k)=\begin{cases}-if(k)\delta^{-2}(k)=a^{-1}_{-}(k)a^{-1}_{+}(k)\delta^{-2}(k),\;k\in\gamma_{g},\\

Let

\frac{F(k)}{a(k)},\;k\in\mathbb{C}^{-}\backslash\bar{\gamma}_{g}.\end{cases}

\left[\frac{\log H(k)}{X(k)}\right]_{+}-\left[\frac{\log H(k)}{X(k)}\right]_{-}=\begin{cases}\frac{\log\delta^{-2}(k)}{X_{+}(k)},\;k\in\gamma_{g}\cup\bar{\gamma}_{g},\\
\frac{\log a^{2}(k)}{X(k)},\;k\in\mathbb{R}.\end{cases}

Using the Sokhotski-Plemelj formula, we have

H(k)=\exp\left\{\frac{X(k)}{2\pi i}\left[\int_{\gamma_{g}\cup\bar{\gamma}_{g}}\frac{\log\delta^{-2}(s)}{s-k}\frac{\mathrm{d}s}{X_{+}(s)}+\int_{\mathbb{R}}\frac{\log a^{2}(s)}{s-k}\frac{\mathrm{d}s}{X(s)}\right]\right\}.

(4.20)

(4.21)

Asymptotic behavior:

\displaystyle M^{(1)}(k;x,t)=I+\mathcal{O}(k^{-1}),\quad k\to\infty.

It is easy to prove that

has the following unique solution

\displaystyle M^{(1)}(k;x,t)=I+\frac{1}{2\pi i}\int_{L_{1}\cup L_{2}}\frac{\mu(s)\left(V^{(1)}(s)-I\right)}{s-k}\mathrm{d}s,

where

. We assume that as

,
M^{(1)}(k;x,t)=I+\frac{M^{(1)}_{1}(x,t)}{k}+O(k^{-2})
, then we can find

\displaystyle M^{(1)}_{1}=-\frac{1}{2\pi i}\int_{L_{1}\cup L_{2}}\mu(s)\left(V^{(1)}(s)-I\right)\mathrm{d}s

\displaystyle=-\frac{1}{2\pi i}\int_{L_{1}\cup L_{2}}\left(V^{(1)}(s)-I\right)\mathrm{d}s-\frac{1}{2\pi i}\int_{L_{1}\cup L_{2}}\left(\mu(s)-I\right)\left(V^{(1)}(s)-I\right)\mathrm{d}s.

For convenience, we take the following special line as an example, other cases can be proved in a similar way.
Define
k_{2}

\displaystyle\left|\frac{1}{2\pi i}\int_{L_{1}^{L}}\left(V^{(1)}(s)-I\right)\mathrm{d}s\right|

\displaystyle<\left|\frac{1}{2\pi}e^{f(\sqrt{6\xi})}\int_{L_{1}^{L}}e^{-12\sqrt{6\xi}\re^{2}s}\mathrm{d}s\right|\lesssim t^{-\frac{1}{2}}e^{12\sqrt{6}t\xi^{\frac{3}{2}}}
