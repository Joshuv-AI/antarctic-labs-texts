SSM-Net: feature learning for Music Structure Analysis using a Self-Similarity-Matrix based loss


Abstract
In this paper, we propose a new paradigm to learn audio features for msa ( msa ). We train a deep encoder to learn features such that the ssm ( ssm ) resulting from those approximates a ground-truth ssm . This is done by minimizing a loss between both ssm s. Since this loss is differentiable w.r.t. its input features we can train the encoder in a straightforward way. We successfully demonstrate the use of this training paradigm using the auc ( auc ) on the RWC-Pop dataset.

SSM-Net Loss.

We apply the same encoder
f^{\theta}
to each input
\mathbf{X}_{i}
.
We then obtain the corresponding sequence of embeddings
\{\mathbf{e}^{\theta}_{i}\}_{i\in\{1\ldots T\}}=f^{\theta}(\{\mathbf{X}_{i}\}_{i\in\{1\ldots T\}})
.
We can then easily construct an estimated
ssm

\mathbf{\hat{S}}_{ij}^{\theta}
, using a distance/similarity
g

\mathbf{\hat{S}}_{ij}^{\theta}=g(\mathbf{e}^{\theta}_{i}=f^{\theta}(\mathbf{X}_{i}),\mathbf{e}^{\theta}_{j}=f^{\theta}(\mathbf{X}_{j})),\;\;\;\forall i,j

(1)

g
is here a simple cosine-similarity which we scale to
[0,1]
:

\mathbf{\hat{S}}_{ij}^{\theta}=1-\frac{1}{4}\lVert\mathbf{e}^{\theta}_{i}-\mathbf{e}^{\theta}_{j}\rVert_{2}^{2}\;\;\;\in[0,1]

(2)

It is then possible to compare
\mathbf{\hat{S}}_{ij}^{\theta}
to a ground-truth binary
ssm
,
\mathbf{S}_{ij}
.
We formulate this as a multi-class problem (a set of
T^{2}
binary classifications) and minimize the sum of
bce
(
bce

We compensate the class unbalancing by using a weighting factor
\lambda

\mathbf{S}_{ij}
.

\mathcal{L}^{\theta}\!=\!-\!\sum_{i,j=1}^{T}\!(1\!-\lambda)\!\left[\mathbf{S}_{ij}\!\log(\!\mathbf{\hat{S}}_{ij}^{\theta}\!)\!\right]\!+\!\lambda\!\left[\!(\!1\!-\!\mathbf{S}_{ij}\!)\!\log\!(\!1\!-\!\mathbf{\hat{S}}_{ij}^{\theta}\!)\!\right]

(3)

Since the computation of the
ssm

\mathbf{\hat{S}}_{ij}^{\theta}

, we can compute
\frac{\partial\mathcal{L}^{\theta}}{\partial\theta}

\frac{\partial\mathcal{L}^{\theta}}{\partial\theta}=\sum_{i,j=1}^{T}\frac{\partial\mathcal{L}^{\theta}}{\partial\mathbf{\hat{S}}_{ij}^{\theta}}\left(\frac{\partial\mathbf{\hat{S}}_{ij}^{\theta}}{\partial\mathbf{e}^{\theta}_{i}}\frac{\partial\mathbf{e}^{\theta}_{i}}{\partial\theta}+\frac{\partial\mathbf{\hat{S}}_{ij}^{\theta}}{\partial\mathbf{e}^{\theta}_{j}}\frac{\partial\mathbf{e}^{\theta}_{j}}{\partial\theta}\right)

(4)
