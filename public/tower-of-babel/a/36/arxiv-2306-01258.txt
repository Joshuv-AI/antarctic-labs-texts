On-shell action of T T ¯ \bar{\text{T}} -deformed Holographic CFTs
Jia Tian

Abstract
In this work, we study the holographic dual of the T T ¯ \overline{\text{T}} deformation following the mixed boundary condition proposal. We point out that a boundary term should be included in the gravity action in the holographic dictionary. In particular, we consider the deformed CFT defined on a sphere (dS) or AdS background and explain the difference between the holographic results and field theory results.

2.1
Setup

The T
\overline{\text{T}}
deformation of 2d field theory with action

is defined by the flow equation

\displaystyle\frac{dS^{[\mu]}_{\text{CFT}}}{d\mu}=\int d^{2}x\sqrt{\gamma}\,\text{T}\bar{\text{T}}^{[\mu]},

(2.1)

where in principle the 2d background can be arbitrary. In the linear order, the deformation is just a double trace deformation

\displaystyle S_{CFT}^{[\mu]}=S_{CFT}+\mu\int d^{2}x\sqrt{\gamma}\,\text{T$\overline{\text{T}}$ }+\mathcal{O}(\mu^{2}).

(2.2)

The double trace deformation does two things to the generating function. It shifts the source by the expectation value of the dual operator and it shifts the generating function (or the on-shell action) by
subtracting
the double trace operator,
i.e.

\displaystyle W^{[\mu]}=W_{0}-\mu\int d^{2}x\sqrt{\gamma}\,\text{T$\overline{\text{T}}$ }.

(2.3)

Using the defining property of the generating function
\delta W=\frac{1}{2}\int d^{2}x\sqrt{\gamma}T_{\alpha\beta}\delta\gamma^{\alpha\beta}
, we can obtain a flow equation

\displaystyle\frac{1}{2}\partial_{\mu}\left(\int d^{2}x\sqrt{\gamma^{[\mu]}}T_{\alpha\beta}^{[\mu]}\delta\gamma_{\alpha\beta}^{[\mu]}\right)=-\delta\left(\int d^{2}x\sqrt{\gamma^{[\mu]}}\text{T}\bar{\text{T}}^{[\mu]}\right),

(2.4)

\displaystyle\gamma_{\alpha\beta}^{[\mu]}=\gamma_{\alpha\beta}^{[0]}+\frac{1}{2}\mu\hat{T}_{\alpha\beta}^{[0]}+\frac{1}{16}\mu^{2}\hat{T}_{\alpha\rho}^{[0]}\hat{T}_{\sigma\beta}^{[0]}{\gamma^{[0]}}^{\rho\sigma},

(2.5)

\displaystyle\hat{T}^{[\mu]}_{\alpha\beta}=\hat{T}^{[0]}_{\alpha\beta}+\frac{1}{4}\mu\hat{T}_{\alpha\rho}^{[0]}\hat{T}_{\sigma\beta}^{[0]}{\gamma^{[0]}}^{\rho\sigma},

Sphere background in the vacuum state

To fix
\gamma_{\alpha\beta}^{[\mu]}
to be a sphere, one should start from the general metric (
3.20
) and solve the Einstein equation
R^{[\mu]}=-\Lambda,\,\Lambda<0
. However, for the special case
L=\bar{L}=0
which corresponds to the ground state, it turns out that if the boundary metric
g_{\alpha\beta}^{[0]}
is a sphere then
\gamma_{\alpha\beta}^{[\mu]}
is also a sphere but with a different radius. The boundary Einstein equation
R^{(0)}=-\Lambda_{0}
is much simpler to solve because it is just the famous Liouville equation

\displaystyle 4\partial_{y}\partial_{\bar{y}}\phi-e^{\phi}\Lambda_{0}=0,

(3.25)

whose solution is

\displaystyle\phi=-2\log(1+y\bar{y})+\log(\frac{-8}{\Lambda_{0}}),\quad\Lambda_{0}<0.

(3.26)

The resulting 3d metric can be written as

\displaystyle ds^{2}=\frac{d\rho^{2}}{4\rho^{2}}+\frac{(8+\Lambda_{0}\rho)^{2}}{(-8\Lambda_{0})(1+\kappa^{2})^{2}\rho}(d\kappa^{2}+\kappa^{2}d\varphi^{2}),\quad y=\kappa e^{\text{i}\varphi},

(3.27)

which can be transformed into the AdS global coordinates

\displaystyle ds^{2}={d\tilde{\rho}^{2}}+\sinh^{2}\tilde{\rho}(d\theta^{2}+\sin^{2}\theta d\varphi^{2})

(3.28)

via the coordinate transformation

\displaystyle\theta=2\arctan\kappa,\quad\sinh\tilde{\rho}=\frac{8+\Lambda_{0}\rho}{\sqrt{-32\Lambda_{0}\rho}}.

(3.29)

Using the dictionary (
1
) one can easily find that deformed metric

\displaystyle ds^{2}=-\frac{(8+\Lambda_{0}\rho_{c})^{2}}{8\Lambda_{0}(1+y\bar{y})^{2}}dyd\bar{y}\equiv-\frac{8}{\Lambda}\frac{dyd\bar{y}}{(1+y\bar{y})^{2}},

(3.30)

indeed describes a sphere with a different radius given by

\displaystyle\Lambda_{0}=-\frac{8(\rho_{c}\Lambda-4+2\sqrt{4-2\rho_{c}\Lambda})}{\rho_{c}^{2}\Lambda}.

(3.31)

Ignoring the universal Weyl anomaly divergent term for a moment, the on-shell action (
2.24
) for this geometry is

\displaystyle I_{\text{bulk}}^{[\mu]}=-\frac{c}{6}\left(1+\log\frac{8}{-\Lambda_{0}}\right)=\frac{c}{6}\left(1+\log\frac{\rho_{c}^{2}\Lambda}{\Lambda\rho_{c}-4+2\sqrt{4-2\Lambda\rho_{c}}}\right),

(3.32)

\displaystyle I_{\text{bdy}}^{[\mu]}=\frac{\mu}{4096G_{N}^{2}\pi^{2}}\int\sqrt{g^{[0]}}e^{-2\phi}R_{\phi}^{2}=-\frac{c\Lambda_{0}\rho_{c}}{48},

(3.33)

\displaystyle I_{\text{on-shell}}^{[\mu]}=I_{\text{bulk}}^{[\mu]}+I_{\text{bdy}}^{[\mu]}=-\frac{c}{6}\left(1+\log\frac{8}{-\Lambda}\right)+\frac{c\Lambda\rho_{c}}{48}+\mathcal{O}(\rho_{c}^{2}).

(3.34)

Comparing with the results (
C.8
) of the field theory we see that they are different by a
\mu

6

\Lambda\to-\frac{2}{r^{2}}

\displaystyle I_{\text{on-shell}}^{[\mu]}-S_{QFT}^{\mu}=\frac{c}{6}\log\frac{24\pi}{c\mu}.

(3.35)

This is because instead choosing the limit condition
S_{QFT}^{\mu}(r=0)=0

\displaystyle I_{\text{on-shell}}^{[\mu]}(\Lambda=-\infty)=\frac{c}{6}\log\frac{24\pi}{c\mu}.

(3.36)

The decision to set
S_{QFT}^{\mu}(r=0)=0
in

S_{QFT}^{\mu}

In our approach, there is an ambiguity to choose the UV cut-off when we define the regulated on-shell action and we have specially chosen the one which has an undeformed limit. By using the replica trick, one can show that shifting the on-shell action will shift the entanglement entropy as

\displaystyle I_{\text{on-shell}}\rightarrow I_{\text{on-shell}}+\alpha,\quad S_{A}\rightarrow S_{A}-\alpha.

(3.37)

Usually, this constant can be absorbed into the UV cut-off when the constant is finite. When

It is useful to compute the undeformed entanglement entropy first.
Let us consider a single interval with two endpoints. Using the isometry of the sphere we can always choose them to be

The situation is very similar to the one with the sphere background. For negative Ricci curvature, the solution of the Liouville equation is

4
Conclusion and Discussion

In this paper, we want to emphasize that in the holographic dictionary (
1
) of the T
\overline{\text{T}}
-deformed CFTs the gravity action should also include an additional boundary term. This appearance of this boundary term inherits from the fact that the leading order T
\overline{\text{T}}
deformation is a double trace deformation. We confirm this observation in some explicit examples including the BTZ, conical spacetime and the vacuum state of a holographic CFT defined in a sphere background.

This observation suggests that the RT formula may be modified to correctly compute the holographic entanglement entropy of the T
\overline{\text{T}}
deformed theories. We will address that in future work.

Appendix A
Convention and Notation

We are interested in 2d Euclidean spacetime and we define the holomorphic and anti-holomorphic coordinates as

\displaystyle z=x+\text{i}y,\quad\bar{z}=x-\text{i}y.

(A.1)

The partition function is defined via the path integral

\displaystyle Z=\int\mathcal{D}[\phi(x,y)]e^{-S[\phi(x,y)]},

(A.2)

where
\phi(x,y)
denotes all the dynamical fields and
S[\phi]
is the action. Assuming that the background metric is
ds^{2}=g_{\alpha\beta}dx^{\alpha}dx^{\beta}
then the energy-momentum tensor is defined as

\displaystyle T^{\alpha\beta}=-\frac{2}{\sqrt{g}}\frac{\delta S}{\delta g_{\alpha\beta}}.

(A.3)

In the coordinate of
(z,\bar{z})
, the energy-momentum tensor is

\displaystyle T_{zz}=\frac{1}{4}\left(T_{11}-T_{22}-\text{i}T_{12}-\text{i}T_{21}\right),

(A.4)

\displaystyle T_{\bar{z}\bar{z}}=\frac{1}{4}\left(T_{11}-T_{22}+\text{i}T_{12}+\text{i}T_{21}\right),

(A.5)

\displaystyle T_{z\bar{z}}=T_{\bar{z}z}=\frac{1}{4}\left(T_{11}+T_{22}\right)\equiv\Theta.

(A.6)

For later convenience, we also introduce the renormalized energy-momentum tensor

\displaystyle T=-2\pi T_{zz},\quad\bar{T}=-2\pi T_{\bar{z}\bar{z}}.

(A.7)

The T
\overline{\text{T}}
composite operator is defined as

\displaystyle\text{T$\overline{\text{T}}$ }\equiv\frac{1}{8}\left(T_{\alpha\beta}T^{\alpha\beta}-(T^{\alpha}_{\alpha})^{2}\right)=T_{zz}\bar{T}_{\bar{z}\bar{z}}-\Theta^{2}.

(A.8)

We will also assume T
\overline{\text{T}}
satisfies the factorization property

\displaystyle\langle\text{T$\overline{\text{T}}$ }\rangle=\frac{1}{8}\left(\langle T^{\alpha\beta}\rangle\langle T_{\alpha\beta}\rangle-\langle T^{\alpha}_{\alpha}\rangle^{2}\right),

(A.9)

which is true for field theories living on infinite Euclidean planes and cylinders or in holographic CFTs. Then the deformed theory can also be defined through the flow equation
[
9
,
29
]
:

\displaystyle\langle T^{\alpha}_{\alpha}\rangle=\frac{c}{24\pi}R+\frac{\mu}{4}\left(\langle T^{\alpha\beta}\rangle\langle T_{\alpha\beta}\rangle-\langle T^{\alpha}_{\alpha}\rangle^{2}\right)

(A.10)

together with the conservation equation
\nabla_{\alpha}\langle T^{\alpha\beta}\rangle=0
.

Sphere partition functions

\displaystyle\sigma\rightarrow\sigma+\delta\sigma,\quad e^{\sigma}\rightarrow(1+\delta\sigma)e^{\sigma},

(C.1)

\displaystyle g_{\alpha\beta}\rightarrow(1+\delta\sigma)g_{\alpha\beta}

\displaystyle\delta S=-\frac{1}{2}\int\sqrt{g}\delta\sigma T^{\alpha}_{\alpha}d^{2}x\quad\rightarrow\quad\frac{\delta S}{\delta\sigma}=\frac{\delta S}{\delta r}\frac{\delta r}{\delta\sigma}=-\frac{1}{2}\int\sqrt{g}T^{\alpha}_{\alpha}d^{2}x

\displaystyle\frac{d}{dr}\log Z=\frac{1}{r}\int d^{2}x\sqrt{g}T_{\alpha}^{\alpha}.

(C.4)

More generally if we include the boundary then

\displaystyle\delta\log Z=\frac{1}{2}\int_{M}d^{2}x\sqrt{g}T_{\alpha}^{\alpha}\delta\sigma+\frac{c}{24\pi}\int_{\partial M}K\delta\sigma dl

(C.5)

where

A.10

\displaystyle\alpha=\frac{\sqrt{\frac{c\mu}{6\pi r^{2}}+4}-2}{\mu}.

(C.6)

thus

\displaystyle\frac{d\log Z}{dr}=\frac{8\pi r\left(\sqrt{\frac{c\mu}{6\pi r^{2}}+4}-2\right)}{\mu}=-\frac{dS_{\text{QFT}}^{\mu}}{dr}.

(C.7)

Integrating both sides and imposing the initial condition

gives

\displaystyle S_{\text{QFT}}^{\mu}

\displaystyle=

\displaystyle-\frac{i\pi c\mu+4\sqrt{6\pi}r^{2}\sqrt{\frac{c\mu}{r^{2}}+24\pi}+2c\mu\tanh^{-1}\left(\sqrt{\frac{c\mu}{24\pi r^{2}}+1}\right)-48\pi r^{2}}{6\mu}

\displaystyle-4\sqrt{\frac{2\pi c}{3\mu}}r+\frac{8\pi r^{2}}{\mu}+\mathcal{O}(r^{3})

(C.9)

\displaystyle S_{\text{QFT}}^{\mu}=-\frac{c}{6}+\frac{c}{6}\log\frac{c\mu}{96\pi r^{2}}-\frac{c^{2}\mu}{576\pi r^{2}}+\mathcal{O}(\mu^{2})

(C.10)
