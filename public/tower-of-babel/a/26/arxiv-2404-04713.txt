Faster Algorithms for Fair Max-Min Diversification in ℝ d \mathbb{R}^{d} Note: This work was partially supported by CAHSI-Google IRP.
Yash Kurkure, Miles Shamo, Joseph Wiseman, Sainyam Galhotra, Stavros Sintos

Abstract
. The task of extracting a diverse subset from a dataset, often referred to as maximum diversification, plays a pivotal role in various real-world applications that have far-reaching consequences. In this work, we delve into the realm of fairness-aware data subset selection, specifically focusing on the problem of selecting a diverse set of size k k from a large collection of n n data points (FairDiv). The FairDiv problem is well-studied in the data management and theory community. In this work, we develop the first constant approximation algorithm for FairDiv that runs in near-linear time using only linear space. In contrast, all previously known constant approximation algorithms run in super-linear time (with respect to n n or k k ) and use super-linear space. Our approach achieves this efficiency by employing a novel combination of the Multiplicative Weight Update method and advanced geometric data structures to implicitly and approximately solve a linear program. Furthermore, we improve the efficiency of our techniques by constructing a coreset. Using our coreset, we also propose the first efficient streaming algorithm for the FairDiv problem whose efficiency does not depend on the distribution of data points. Empirical evaluation on million-sized datasets demonstrates that our algorithm achieves the best diversity within a minute. All prior techniques are either highly inefficient or do not generate a good solution.

Introduction

In numerous real-world scenarios, including data summarization, web search, recommendation systems, and feature selection, it is imperative to extract a diverse subset from a dataset (often referred to as maximum diversification). The decisions made in these domains have significant consequences. Therefore, it is crucial to guarantee that the outcomes are not only diverse but also unbiased. For instance, while a primary objective of data summarization is to select a representative sample that encapsulates analogous data points, conventional summarization techniques have been identified to exhibit biases against minority groups, leading to detrimental repercussions. In this work, we study the problem of fairness-aware maximum diversification, where the goal is to choose a diverse set of representative data points satisfying a group fairness constraint.

High-level idea.

Assume that

Before we continue with our method, we note that there has been a lot of work related to implicitly solving special classes of LPs in computational geometry using the MWU method

)

or

Before we describe the actual rounding algorithm we describe a modified BBD tree that we are going to use to sample efficiently.
For every point
p_{i}\in P
, we define its weight
\hat{x}_{i}
.
Let
\Xi
be a BBD tree constructed over a weighted set
P
. We modify
\Xi
so that we can sample a point
p_{i}
with probability
\frac{\hat{x}_{i}}{\sum_{j\in F}\hat{x}_{j}}
, where

is a subset of

.
For each node
u
of
\Xi
, we store the value
u_{s}=\sum_{p_{\ell}\in\square_{u}\cap P}\hat{x}_{\ell}
, i.e., sum of
\hat{x}_{i}

Initially

.
We sample as follows: Assume any node

having two children
v,e
. We visit

with probability

and we visit

with probability
e_{s}/(u_{s}+e_{s})
. When we insert a point
p_{i}
in

, we start from the leaf node that stores

and we visit the tree bottom up updating the values

of the nodes

we traverse. In this way, we ”remove“ the weight of point
p_{i}
from the tree and it is not considered in the next iterations of sampling. It is straightforward to see that this procedure guarantees that each point
p_{i}
is selected with probability
\frac{\hat{x}_{i}}{\sum_{j\in F}\hat{x}_{j}}
.
In order to make sure that we do not select two nearby points, for every node

.
If

it means that our algorithm has not sampled a point that lies in
\square_{u}\cap P

in a previous iteration so we should not re-consider node

to get a new sample.

Let

Using

.

Lemma 3.1.

The minimum pairwise distance in

is
\frac{\gamma}{2(1+\varepsilon)}

\mathbb{E}[|S(c_{j})|]\geq\frac{k_{j}}{1+\varepsilon}

Proof.

First, we show that the minimum pairwise distance in
S
is
\frac{\gamma}{2(1+\varepsilon)}
. Let
p_{i},p_{\ell}
be a pair of points with distance less than
\frac{\gamma}{2(1+\varepsilon)}
. Without loss of generality assume that
p_{i}
was added to
S
first. Assume that
p_{\ell}
is selected as a sample in a subsequent iteration. Since
||p_{i}-p_{\ell}||<\frac{\gamma}{2(1+\varepsilon)}
, by definition, there exists a unique node

such that
p_{i}\in\square_{u}\cap P
. Hence,
p_{i}
lies in a leaf node of the subtree rooted at
u
. Since
p_{i}
has already been selected we have that
u_{b}=0
(because
u
is an ancestor of the leaf node of

), so
p_{\ell}
is not inserted in

.

Next, we argue about the fairness requirement.
Let
p_{\ell}
be a point with
\hat{x}_{\ell}>0
. Let

be the event that the first point included in

from the set

is the point from the

Then,

\displaystyle\Pr[p_{\ell}\in S]

\displaystyle=\sum_{t=1}^{n}\Pr[\sigma(t)=p_{\ell}\mid V_{t}]\Pr[V_{t}]=\sum_{t=1}^{n}\frac{\hat{x}_{\ell}}{\sum_{p_{i}\in S_{p_{\ell}}^{\varepsilon}}\hat{x}_{i}}\Pr[V_{t}]

\displaystyle=\frac{\hat{x}_{\ell}}{\sum_{p_{i}\in S_{p_{\ell}}^{\varepsilon}}\hat{x}_{i}}\sum_{t=1}^{n}\Pr[V_{t}]=\frac{\hat{x}_{\ell}}{\sum_{p_{i}\in S_{p_{\ell}}^{\varepsilon}}\hat{x}_{i}}\geq\frac{\hat{x}_{\ell}}{1+\varepsilon}.

The last inequality holds because
\sum_{p_{i}\in S_{p_{\ell}}^{\varepsilon}}\hat{x}_{i}\leq 1+\varepsilon
from Constraints (

\mathbb{E}[|S(c_{j})|]\geq\sum_{p_{i}\in P(c_{j})}\frac{\hat{x}_{i}}{1+\varepsilon}\geq\frac{k_{j}}{1+\varepsilon}
.
∎

We transform the near-optimal fractional solution

Recall that

We show that our method finds a solution

Rounding

The rounding procedure is similar to the rounding in Subsection

to sample points from

we check if another point has already been selected in a previous iteration in the area of
\Xi(p_{i},\frac{\gamma}{6(1+\varepsilon)^{3}})

3

3

For technical reasons we set the denominator to

(1+\varepsilon)^{2}
.
.
Using the proof of Lemma

, we get that for any pair

in the set we return, we have
\min_{p,q\in S}||p-q||_{2}\geq\frac{\gamma}{6(1+\varepsilon)^{3}}

otherwise. Using the same proof, we get
\mathbb{E}\left[\sum_{p_{i}\in S(c_{j})}Y_{i}\right]\geq\frac{k_{j}}{1+\varepsilon}
for each color

. By definition, all variables

are independent, so we can apply the Chernoff bound to get a bound on the number of points of each color with high probability. In particular, if

\Pr[\sum_{p_{i}\in S(c_{j})}Y_{i}\leq(1-\varepsilon)\frac{k_{j}}{1+\varepsilon}]\leq\frac{1}{2m}

\sum_{p_{i}\in S(c_{j})}Y_{i}\geq(1-\varepsilon)\frac{k_{j}}{1+\varepsilon}

with probability at least

\log\frac{1}{\delta}

O(n\log(\frac{1}{\delta})(\log n+\varepsilon^{-d}))
.

Finally, as we had in Subsection
3.1
, recall that we run a binary search on the WSPD set

such that

Putting everything together, and setting

Extensions

The main goal of this comparison is to identify techniques that maximize diversity within a reasonable amount of time. Two extreme algorithms are:

Random selection

Exhaustive search
would exhaustively consider all possible subsets to calculate diversity and return the best solution. This approach may return a highly accurate solution but would be highly inefficient. This approach would not scale to millions sized datasets.

The key goal of this experiment is to identify a technique that returns the best solution within a reasonable amount of time.

Related work

In
(
41
)
the authors define the FairDiv problem and propose algorithms for general metric spaces. In particular, when
m=2
, they showed an

time algorithm with

For any number of colors

In
(

-approximation satisfying the fairness constraints in expectation, i.e., the expected number of points from color

it uses

The same algorithm is extended to return a

is at least
{k_{j}}/{1-\varepsilon}

In the same paper they also propose a greedy algorithm, called Fair-Greedy-Flow, that returns an

-approximation in

\varepsilon

In the Euclidean metric, in

7

Using the coreset, they also design a Fair-Euclidean algorithm that returns a constant approximation in

8.
Future work

There are multiple interesting open problems derived from our work. Is it possible to get a constant approximation for the FairDiv problem satisfying the fairness exactly? The goal is to get at least
k_{j}
points instead of at least
\frac{k_{j}}{1-\varepsilon}
points, from each color
c_{j}\in C
. It will also be interesting to check whether the new techniques from this paper can be used to accelerate the other version of the FairDiv problem
(
52
)
where we have both a lower bound
k_{j}^{-}
and an upper bound
k_{j}^{+}
for each color
c_{j}\in C
. Finally, it is interesting to study whether other data structures can be used, to get constant approximation in metrics with bounded doubling dimension.
