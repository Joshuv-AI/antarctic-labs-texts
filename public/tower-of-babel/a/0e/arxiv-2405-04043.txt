Scalable Vertical Federated Learning via Data Augmentation and Amortized Inference
Conor Hassan, Matthew Sutton, Antonietta Mira, Kerrie Mengersen

Abstract
Vertical federated learning (VFL) has emerged as a powerful paradigm for collaborative model estimation across multiple clients, each holding a distinct set of covariates. This paper introduces the first comprehensive framework for fitting Bayesian models in the VFL setting. We propose a novel approach that leverages data augmentation techniques to transform VFL problems into a form compatible with existing Bayesian federated learning algorithms. We present an innovative model formulation for specific VFL scenarios where the joint likelihood factorizes into a product of client-specific likelihoods. To mitigate the dimensionality challenge posed by data augmentation, which scales with the number of observations and clients, we develop a factorized amortized variational approximation that achieves scalability independent of the number of observations. We showcase the efficacy of our framework through extensive numerical experiments on logistic regression, multilevel regression, and a novel hierarchical Bayesian split NN model. Our work paves the way for privacy-preserving, decentralized Bayesian inference in vertically partitioned data scenarios, opening up new avenues for research and applications in various domains.



1
Introduction

ederated learning (FL)
(
McMahan et al., 2017a
;
Yang et al., 2019a
;
Kairouz et al., 2021a
)
has revolutionized the field of privacy-preserving and communication-efficient learning, enabling collaborative model training across multiple
clients
under the coordination of a
server
, without the need for data sharing. This paradigm has unlocked new possibilities for leveraging decentralized data while maintaining strict privacy constraints, paving the way for innovative applications in various domains.

While the majority of FL algorithms focus on the
horizontal
FL
(
Yang et al., 2020a
)
setting, where each client possesses a complete set of covariates for a unique subset of observations, the
vertical
FL (VFL)
(
Liu et al., 2019a
;
Wei et al., 2022a
)
setting remains relatively unexplored. In VFL, each client holds only a subset of desired covariates for all observations. This work considers two settings: (1) the response variable is shared among clients, and (2) the response variable is private to the server, and the clients send updates to the server to fit the desired statistical model.

In this paper, we aim to approximate the posterior distribution of the unknown variables given the observed data. The challenge in the VFL setting is that the likelihood function is not separable across clients, unlike in horizontal FL, where conditional independence is often assumed and exploited to create distributed or private algorithms. This non-separability arises from the fact that each client only possesses a subset of the covariates, making it impossible to compute the likelihood of any single client independently. Often, each client must contribute a value to a summation term required to evaluate the likelihood
(
Hardy et al., 2017a
;
Weng et al., 2020a
;
Chen et al., 2021a
)
. Secure
multi-party computation
(MPC)
(
Cramer & Damgård, 2015a
;
Li et al., 2020a
;
Byrd & Polychroniadou, 2020a
)
is often employed to address this challenge, but it can significantly impact the scalability of the proposed methods, leaving room for further research. Moreover, to our knowledge, there is currently no literature on Bayesian modeling and inference in the VFL setting.

To overcome this challenge, we reframe the target posterior distribution via
asymptotically-exact data augmentation
(AXDA)
(
Vono et al., 2019a
;
Vono et al., 2020a
;
Vono et al., 2022a
)
. This approach introduces auxiliary variables that create conditional independence between the client-specific parameters, allowing for independent updates on each client. The augmented-variable model decouples the unknown variables from the likelihood, enabling local updates on each client independently of the others. This interpretation can be seen as the probabilistic analog of an optimization problem that solves subproblems requiring information unique to each client, similar to the alternating direction method of multipliers (ADMM)
(
Boyd et al., 2011a
)
.

Under the augmented-variable model, recently developed algorithmic schemes intended for hierarchical models in the horizontal FL setting, such as structured federated variational inference (SFVI)
(
Hassan et al., 2023a
)
, can be adapted to update the client-specific parameters. For the setting where the clients share the response variable, we develop a novel model formulation that expresses the likelihood as a product of client-specific contributions.

The auxiliary variable schemes used here require the addition of variables to the model that are equal in size to the number of observations times the number of clients. To address this, we propose a factorized amortized variational approximation, removing the increase in computational cost due to the dimensionality of the auxiliary variables per client. We provide numerical examples showcasing performance on logistic regression, multilevel regression, and a novel hierarchical Bayes split NN
(
Poirot et al., 2019a
;
Ceballos et al., 2020a
;
Thapa et al., 2022a
)
.

2
Preliminaries

This section provides the necessary background for auxiliary variable methods and structured federated variational inference.

2.1
Asymptotically-Exact Data Augmentation

In this paper, we are interested in targeting the
posterior distribution

\pi(\bm{\theta}|\bm{y})\propto p(\bm{y}|\bm{\theta})p(\bm{\theta})
where
\bm{\theta}\in\mathbb{R}^{d}
is an unknown parameter, with prior distribution
p(\bm{\theta})
and
p(\bm{y}|\bm{\theta})
is the likelihood of the observed data
\bm{y}\in\mathbb{R}^{n}
. Direct inference of the posterior distribution can often be intractable or computationally expensive.
Data augmentation
(DA)
(
Van & Meng, 2001a
)
is a common approach to address this issue by introducing auxiliary variables
\bm{z}\in\mathbb{R}^{m}
into the statistical model through a model-specific joint density
\pi(\bm{\theta},\bm{z}|\bm{y})
. This joint density is chosen to be simpler to compute and satisfies the marginalization property,

\displaystyle\pi(\bm{\theta}|\bm{y})=\int\pi(\bm{\theta},\bm{z}|\bm{y})\mathrm{d}\bm{z}.

(1)

Asymptotically-exact data augmentation
(AXDA)
(
Vono et al., 2020a
)
is a flexible form of DA that relaxes the marginalization property in (
1
) by introducing an augmented distribution
p(\bm{z}|\bm{\theta};\rho)
that depends on a positive scalar hyperparameter
\rho>0
. The resulting augmented posterior distribution is given by

\displaystyle\pi(\bm{\theta}|\bm{y};\rho)=\int\pi(\bm{\theta},\bm{z}|\bm{y};\rho)\mathrm{d}\bm{z},

(2)

where
\pi(\bm{\theta},\bm{z}|\bm{y};\rho)\propto p(\bm{y}|\bm{z},\bm{\theta})p(\bm{z},\bm{\theta};\rho)
, with augmented likelihood
p(\bm{y}|\bm{z},\bm{\theta})
and prior
p(\bm{z},\bm{\theta};\rho)=p(\bm{z}|\bm{\theta};\rho)p(\bm{\theta})
. The conditional distribution
p(\bm{z}|\bm{\theta};\rho)
is chosen to be a Gaussian with mean equal to a function of
\bm{\theta}
and variance
\rho^{2}
. The key property of AXDA is that, under the assumption that the mean function of
\bm{z}|\bm{\theta};\rho
is chosen correctly, the augmented posterior distribution
\pi(\bm{\theta}|\bm{y};\rho)
converges to the original posterior distribution
\pi(\bm{\theta}|\bm{y})
as
\rho\rightarrow 0
,
i.e.

\lim_{\rho\rightarrow 0}\pi(\bm{\theta}|\bm{y};\rho)=\pi(\bm{\theta}|\bm{y})
. This property justifies the name
“asymptotically-exact”
and ensures that the AXDA framework can provide a valid approximation to the original posterior distribution. AXDA offers several advantages over traditional data augmentation methods. It provides a flexible framework that can be applied to a wide range of models without requiring model-specific choices. Additionally, the introduction of the hyperparameter
\rho
allows for a trade-off between computational tractability and the accuracy of the approximation.

2.2
Structured Federated Variational Inference

Variational inference (VI)
(
Blei et al., 2017a
;
Zhang et al., 2018a
)
is a powerful algorithmic framework for approximating intractable posterior distributions
\pi(\bm{\theta}|\bm{y})
. The core idea behind VI is to introduce a family of tractable distributions
q_{\bm{\phi}}(\bm{\theta})
, parameterized by variational parameters
\bm{\phi}
, and find the member of this family that best approximates the true posterior.

The optimal variational approximation is found by minimizing the Kullback-Leibler (KL) divergence between
q_{\bm{\phi}}(\bm{\theta})
and
\pi(\bm{\theta}|\bm{y})
, which is equivalent to maximizing the evidence lower bound (ELBO),

\displaystyle\mathcal{L}(\bm{\phi})=\mathbb{E}_{\bm{\theta}\sim q_{\bm{\phi}}}[\log p(\bm{y},\bm{\theta})-\log q_{\bm{\phi}}(\bm{\theta})].

(3)

The ELBO is a lower bound on the log marginal likelihood
\log p(\bm{y})
and can be used as a surrogate objective function for optimization. If the variational approximation
q_{\bm{\phi}}(\bm{\theta})
exactly recovers the true posterior
\pi(\bm{\theta}|\bm{y})
, the ELBO is equal to the log marginal likelihood.

To optimize the ELBO, VI methods typically employ gradient-based optimization algorithms
(
Ruder, 2017a
)
. A key challenge in VI is to obtain low-variance, unbiased gradient estimates of the ELBO with respect to the variational parameters
\bm{\phi}
. The reparameterization trick
(
Kingma & Welling, 2013a
;
Rezende et al., 2014a
)
has emerged as a powerful technique for addressing this challenge, which allows for an efficient and potentially low-variance estimate of the ELBO. The reparameterization involves expressing a sample of
\bm{\theta}
drawn from
q_{\bm{\phi}}(\bm{\theta})
as a deterministic function of
\bm{\phi}
by transforming random noise
\bm{\epsilon}
:
\bm{\theta}=f_{\bm{\phi}}(\bm{\epsilon})
. The noise variable
\bm{\epsilon}
is drawn from a distribution
q_{\bm{\epsilon}}
, which is independent of
\bm{\phi}
. In this context,
f_{\bm{\phi}}
might be, for example, a location-scale transform. Given this formulation, a resulting single-sample unbiased Monte Carlo estimator of the desired gradient vector is the
sticking-the-landing
(STL) estimator
(
Roeder et al., 2017a
)
,

\displaystyle\hat{\nabla}_{\bm{\phi}}\mathcal{L}:={\frac{\partial f_{\bm{\phi}}(\bm{\epsilon})}{\partial\bm{\phi}}}^{\top}\nabla_{\bm{\theta}}[\log p(\bm{\theta},\bm{y})-\log q_{\bm{\phi}}(\bm{\theta})].

(4)

Structured Federated Variational Inference (SFVI)
(
Hassan et al., 2023a
)
is a framework that uses structured approximations
(
Hoffman & Blei, 2015a
;
Ranganath et al., 2016a
;
Tan et al., 2020a
)
to fit hierarchical Bayesian models in the horizontal FL setting. The models considered have a joint probability distribution of the form,

\displaystyle p(\bm{y},\bm{z},\bm{\theta})=p(\bm{z})\prod_{j=1}^{J}p(\bm{\theta}_{j}|\bm{z})p(\bm{y}|\bm{\theta}_{j},\bm{z}),

where
\bm{\theta}=(\bm{\theta}_{1}^{\top},\ldots,\bm{\theta}_{J}^{\top})^{\top}
such that the parameters
\bm{\theta}_{j}
only appear in the likelihood contribution from the
j
-th client and are conditionally independent across clients, while
\bm{z}
are shared global parameters that appear in all likelihood contributions across clients. SFVI proposes to use a factorized variational approximation,

\displaystyle q_{\bm{\phi}}(\bm{z},\bm{\theta})=q_{\bm{\phi}_{\bm{z}}}(\bm{z})\prod_{j=1}^{J}q_{\bm{\phi}_{j}}(\bm{\theta}_{j}|\bm{z}),

where
q_{\bm{\phi}_{z}}(\bm{z})
is Gaussian distributed, parameterized by
\bm{\phi}_{z}
,
and each
q_{\bm{\phi}_{j}}(\bm{\theta}_{j}|\bm{z})
is Gaussian distributed, parameterized by
\bm{\phi}_{j}
respectively, and potentially include dependencies on
\bm{z}
.

Hassan et al., 2023a
derive two algorithms, SFVI and SFVI-Avg, for combinations of models and algorithms that share this form. Both of these algorithms enable the updating of the local variational parameters
\bm{\phi}_{j}
for each client in parallel and
privately
(
i.e.
they are not shared with the server), only requiring communicating gradient information regarding
\bm{\phi}_{z}
to the server at each iteration.

The SFVI framework provides an effective way to apply VI in the horizontal FL setting, allowing for efficient and privacy-preserving model fitting. In the following sections, we will discuss how the concepts of AXDA and SFVI can be leveraged to develop methods for the vertical FL setting.

3
Auxiliary Variable Methods for Vertical Federated Learning

This section introduces
asymptotically-exact data augmentation
(AXDA), similar in flavor to that of
Vono et al., 2019a
;
Vono et al., 2020a
;
Vono et al., 2022a
;
Rendell et al., 2020a
, for vertical FL. This scheme incorporates
auxiliary variables
based on the
features
(e.g., covariates), facilitating the construction of a VFL algorithm for specific classes of statistical models. We then present an alternative modeling approach for specific vertical FL settings. As both the augmented-variable model (presented in Section
3.2
) and the power-likelihood model (presented in Section
3.3
) satisfy the same asymptotically-exact property as AXDA, the theory presented for AXDA is equally applicable for the two following models presented.

3.1
Vertical Federated Learning Motivation and Setting

We aim to perform inference for the unknown variable of interest
\bm{\theta}\in\mathbb{R}^{p}
. In the vertical federated learning (VFL) setting, the joint data matrix
\bm{x}\in\mathbb{R}^{n\times p}
is distributed across
J
clients, such that it can be written as
\bm{x}=(\bm{x}_{1},\ldots,\bm{x}_{J})
, where each
\bm{x}_{j}\in\mathbb{R}^{n\times p_{j}}
and
\sum_{j=1}^{J}p_{j}=p
. This distribution of the data matrix occurs because each client holds a subset of the features for all observations, necessitating collaboration among clients to perform inference on the complete set of features. We also assume that the parameter vector
\bm{\theta}
is distributed across clients as
\bm{\theta}=(\bm{\theta}_{1}^{\top},\ldots,\bm{\theta}_{J}^{\top})^{\top}
. In this paper, we aim to approximate models of the form

\displaystyle\pi(\bm{\theta}|\bm{y})\propto\exp\left(\log p\bigg(\bm{y}\bigg|\sum_{j=1}^{J}g_{j}(\bm{x}_{j},\bm{\theta}),\bm{\gamma}\bigg)+\sum_{j=1}^{J}\log p_{j}(\bm{\theta}_{j})\right),

(5)

in the VFL setting, where each client
j
has the choice to set their own prior distribution
p(\bm{\theta}_{j}):\mathbb{R}^{p_{j}}\rightarrow\mathbb{R}
, for the parameters
\bm{\theta}_{j}
associated with their subset of the data matrix
\bm{x}_{j}
, and
\bm{\gamma}
is an unknown parameter shared across the clients. The challenge arises in evaluating the likelihood
p(\bm{y}|\sum_{j=1}^{J}g_{j}(\bm{x}_{j},\bm{\theta}),\bm{\gamma})
in the VFL setting because each client only has access to a subset of the data and parameters, making it impossible to compute the likelihood independently.

Running example:
Consider linear regression with unknown mean and variance, where
J
clients hold the desired covariates. By setting
\bm{\theta}_{j}=\bm{\beta}_{j}
for all
J
clients,
\bm{\gamma}=\sigma^{2}
, and
g_{j}(\bm{x},\bm{\theta})=\bm{x}_{j}^{\top}\bm{\theta}_{j}
, the likelihood
f
can be can be expressed as
\bm{y}|\bm{\beta},\sigma^{2}\sim\mathcal{N}(\sum_{j=1}^{J}\bm{x}_{j}^{\top}\bm{\beta}_{j},\sigma^{2})
.

Inference of such a target density is difficult in the VFL setting because each client
j
would be required to share the value of their likelihood contribution
g_{j}(\bm{x},\bm{\theta})
. Thus, it would not be possible to perform multiple computation steps updating
\bm{\theta}_{j}
on client
j
without communicating with the server. This issue motivates us to formulate the target density in an alternative manner to enable the use of an existing FL algorithm that can handle the unique challenges posed by the VFL setting while maintaining privacy.

3.2
Augmented-Variable Model

Here, we present an AXDA setting suitable for VFL. Let
\bm{z}=(\bm{z}_{1}^{\top},\ldots,\bm{z}_{J}^{\top})^{\top}
, where
\bm{z}_{j}\in\mathbb{R}^{n}
denotes the
auxiliary variables
introduced with respect to client
j
. The joint posterior of
\bm{\theta}
and
\bm{z}
in the
augmented-variable model
is proportional to

\displaystyle\pi(\bm{\theta},\bm{z}|\bm{y};\rho)\propto\exp\left(\log p(\bm{y}|\bm{z},\bm{\gamma})+\sum_{j=1}^{J}\log p(\bm{z}_{j}|\bm{\theta}_{j};\rho)+\sum_{j=1}^{J}\log p(\bm{\theta}_{j})\right),

(6)

where
p(\bm{y}|\bm{z},\bm{\gamma}):=p(\bm{y}|\sum_{j=1}^{J}g_{j}(\bm{x}_{j},\bm{\theta}_{j}),\bm{\gamma})
is the likelihood, with each
g_{j}(\bm{x}_{j},\bm{\theta}_{j})=\bm{z}_{j}
. This formulation effectively decouples the likelihood from the original parameters
\bm{\theta}
, making it a function of the auxiliary variables
\bm{z}
.

The conditional distribution
\bm{z}_{j}|\bm{\theta}_{j};\rho
is chosen to be a Gaussian distribution with mean equal to
g_{j}(\bm{x}_{j},\bm{\theta}_{j})
, and variance
\rho^{2}
. This choice of conditional distribution is motivated by the AXDA framework, which allows for a flexible and computationally tractable augmented posterior distribution. The conditional distribution of
\bm{\theta}_{j}
is proportional to
p(\bm{\theta}_{j}|\bm{\theta}_{-j},\bm{z};\rho)\propto p(\bm{z}_{j}|\bm{\theta}_{j};\rho)p(\bm{\theta}_{j})
, depending only on the auxiliary variable
\bm{z}_{j}
and the prior
p_{j}(\bm{\theta}_{j})
.

Running example:
Consider a linear regression with unknown mean and variance, where
J
clients hold the desired covariates. Setting
\bm{\gamma}=\sigma^{2}
and
\bm{\theta}_{j}=\bm{\beta}_{j}
,
g_{j}(\bm{x}_{j},\bm{\theta}_{j})=\bm{x}_{j}^{\top}\theta_{j}
, for all
J
clients,
the augmented-variable model can be written as

\displaystyle\bm{y}|\bm{z}

\displaystyle\sim\mathcal{N}\big(\sum_{j=1}^{J}\bm{z}_{j},\sigma\big),

\displaystyle\bm{z}_{j}|\bm{\theta}_{j}

\displaystyle\sim\mathcal{N}(\bm{x}_{j}^{\top}\bm{\beta}_{j},\rho),\quad j=1,\ldots,J,

\displaystyle\bm{\theta}_{j}

\displaystyle\sim p(\bm{\theta}_{j}),\quad j=1,\ldots,J.

As in AXDA, the augmented posterior distribution
\pi(\bm{\theta}|\bm{y};\rho)
of this model converges to the original posterior distribution
\pi(\bm{\theta}|\bm{y})
as
\rho\rightarrow 0
,
i.e.

\lim_{\rho\rightarrow 0}\pi(\bm{\theta}|\bm{y};\rho)=\pi(\bm{\theta}|\bm{y})
. Given the formulation of the augmented-variable model, it follows that, for all pairs of clients
i,k
, we have the conditional independence property
\bm{\theta}_{i}\perp\!\!\!\perp\bm{\theta}_{k}|\bm{z}_{i},\bm{z}_{k}
, meaning that the elements of
\bm{\theta}
can be updated in parallel.

In addition to satisfying the above conditional independence property, the augmented-variable model can be fit in two FL scenarios:

1.

The response variable
\bm{y}
is shared across clients; clients can either update their respective
\bm{z}_{j}
and send it to the server or send the necessary gradient to the server, where the server carries out the update; the server is responsible for redistributing updated values of
\bm{z}
among clients.

2.

The response variable
\bm{y}
is not shared and is only available to the server; the clients send the server the necessary gradients to update their
\bm{z}_{j}
; the server updates all
\bm{z}
and redistributes to the clients.

3.3
Power-Likelihood Model

The likelihood contribution
g_{j}(\bm{\theta}_{j},\bm{x}_{j})
is known locally to client
j
in the VFL setting. This allows for an alternative formulation of the target density, where the likelihood evaluated at client
j
is a function of
g_{j}(\bm{x}_{j},\bm{\theta}_{j})
rather than the auxiliary variable
\bm{z}_{j}
, as in the augmented-variable model. This leads to a log-likelihood that is a weighted summation of
J
client-specific log-likelihood contributions. We write the target density as

\displaystyle\pi(\bm{\theta},\bm{z}|\bm{y};\rho)\propto\exp\left(\frac{1}{J}\sum_{j=1}^{J}\log p(\bm{y}|\bm{g}_{j}(\bm{\theta}_{j},\bm{x}_{j}),\bm{z}_{-j})+\sum_{j=1}^{J}\log p(\bm{\theta}_{j})+\sum_{j=1}^{J}\log p(\bm{z}_{j}|\bm{\theta};\rho)\right).

(7)

It is important to note that the likelihood in the power-likelihood model has a different form compared to the augmented-variable model. In the power-likelihood model, the likelihood is a product of
J
client-specific likelihood contributions, each raised to the power of
1/J
. This formulation differs from the general framework presented in Section
3.2
, where the likelihood is a function of the sum of the
g_{j}
functions.

Running example:
Consider the linear regression with unknown mean and variance. The
power-likelihood model
can be written as

\displaystyle\bm{y}|\bm{\theta},\bm{z}

\displaystyle\sim\prod_{j=1}^{J}\mathcal{N}\bigg(\bm{x}_{j}^{\top}\bm{\beta}_{j}+\sum_{k\neq j}^{J}\bm{z}_{k},\sigma\bigg)^{1/J},

\displaystyle\bm{z}_{j}|\bm{\theta}_{j}

\displaystyle\sim\mathcal{N}(\bm{x}_{j}^{\top}\bm{\beta}_{j},\rho),\quad j=1,\ldots,J,

\displaystyle\bm{\theta}_{j}

\displaystyle\sim p(\bm{\theta}_{j}),\quad j=1,\ldots,J.

Despite the difference in the likelihood formulation, the power-likelihood model still maintains the AXDA property, where the augmented posterior distribution converges to the original posterior distribution as
\rho\rightarrow 0
,
i.e.

\lim_{\rho\rightarrow 0}\pi(\bm{\theta}|\bm{y};\rho)=\pi(\bm{\theta}|\bm{y})
.

Unlike the augmented-variable model, the power-likelihood model can only be fit in the setting where the response variable
\bm{y}
is known to the clients, and the clients share the necessary gradients with the server to update their respective variables
\bm{z}_{j}
. This limitation arises because the likelihood of the power-likelihood model has an
explicit
dependence on the data
\bm{x}
and the parameters
\bm{\theta}
.

Figure
1
graphically illustrates the flow of information and the dependency structure required for the
augmented-variable
and the
power-likelihood
models, respectively.

The power-likelihood model provides an alternative formulation for the VFL setting that prioritizes improved modeling by allowing the likelihood evaluated at each client to be a function of their local likelihood contribution. However, this comes at the cost of reduced flexibility in the settings where the model can be fit, as it requires the clients to know the response variable. In contrast, the augmented-variable model offers more flexibility regarding the settings where it can be applied, albeit with a different likelihood formulation.

4
Algorithm details

This section describes how the augmented-variable model in Section
3.2
and the power-likelihood model in Section
3.3
can be inferred in the VFL setting. Typically, one would estimate the posterior distribution
\pi(\bm{\theta},\bm{z}|\bm{y};\rho)
using
Markov chain Monte Carlo
(MCMC) methods
(
Brooks et al., 2011a
)
. However, updating the auxiliary variables specific to each client in the VFL setting requires the conditional distribution
\bm{z}_{j}|\bm{z}_{-j},\bm{\theta}_{j}
. Assuming that we want to reduce communication of data-related quantities, such as gradients of log densities, from clients to the server, we use alternative algorithms that can exploit the conditional independence structure among the clients given
\bm{z}
.

Two such algorithms are
structured federated variational inference
(SFVI)
(
Hassan et al., 2023a
)
and the
stochastic optimization via unadjusted Langevin
(SOUL)
(
De et al., 2021c
;
Kotelevskii et al., 2022c
)
algorithm. These algorithms leverage the conditional independence structure by allowing for local updates on each client and reducing the need for frequent communication between the clients and the server. In this section, we will focus on describing SFVI in detail, while the discussion of SOUL is provided in Appendix
A
.

We will explore two variational approximations suitable for the FL setting:

1.

A
structured variational approximation
that employs ideas from amortized inference. This approximation leverages the conditional independence structure of the model and enables efficient local updates on each client.

2.

A
mean-field variational approximation
, which assumes independence among the variables in the approximation.

4.1
Amortized Structured Variational Approximation

For the structured variational approximation, we choose a similar form to
Hassan et al., 2023a
, such that

\displaystyle q_{\bm{\phi},\bm{\psi}}(\bm{\theta},\bm{z})=\prod_{j=1}^{J}q_{\bm{\phi}_{j}}(\bm{\theta}_{j})q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j}),

where
q_{\bm{\phi}_{j}}(\bm{\theta}_{j})
and
q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})
are the variational distributions for the parameters
\bm{\theta}_{j}
and auxiliary variables
\bm{z}_{j}
of client
j
, parameterized by variational parameters
\bm{\phi}_{j}
and
\bm{\psi}_{j}
respectively.

For the parameterization of the variational approximation of
\bm{\theta}_{j}
, we choose that
q_{\bm{\phi}_{j}}(\bm{\theta}_{j})=\mathcal{N}(\bm{\mu}_{\bm{\theta}_{j}},\bm{\Sigma}_{\bm{\theta}_{j}})
, where
\bm{\phi}_{j}=(\bm{\mu}_{\bm{\theta}_{j}}^{\top},\text{vec}(\bm{\Sigma}_{\bm{\theta}_{j}})^{\top})^{\top}
with the reparameterization applied such that
\bm{\theta}_{j}=\bm{\mu}_{\bm{\theta}_{j}}+\bm{\Sigma}_{\bm{\theta}_{j}}\bm{\epsilon}_{j}
. For the parameterization of the variational approximation of
\bm{z}_{j}
, we propose different parameterizations for the augmented-variable and power-likelihood models. In the augmented-variable model, we choose
q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})=\mathcal{N}\big(\bm{\mu}_{j}(\bm{x}_{j}^{\top}\bm{\theta}_{j}),\bm{\sigma}_{j}(\bm{x}_{j}^{\top}\bm{\theta}_{j})\big)
. For the power-likelihood model, we choose
q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})=\mathcal{N}\big(\bm{\mu}_{j}(\bm{y},\bm{x}_{j}^{\top}\bm{\theta}_{j}),\bm{\sigma}_{j}(\bm{y},\bm{x}_{j}^{\top}\bm{\theta}_{j})\big)
. In both cases,
\bm{\mu}_{j}(\cdot)
and
\bm{\sigma}_{j}(\cdot)
are output by a NN parameterized by
\bm{\psi}_{j}
for
j=1,\ldots,J
. Using a neural network allows for a flexible and expressive parameterization of the variational approximation for
\bm{z}_{j}
, enabling it to capture complex dependencies between
\bm{z}_{j}
and
\bm{\theta}_{j}
.

As a consequence of the choice of factorization,
we apply the appropriate joint reparameterization,

\displaystyle\bm{\theta}_{j}

\displaystyle=\bm{\mu}_{\bm{\theta}_{j}}+\bm{\Sigma}_{\bm{\theta}_{j}}\bm{\epsilon}_{j},\quad j=1,\ldots,J,

(8)

\displaystyle\bm{z}_{j}

\displaystyle=\bm{\mu}_{j}(\bm{x}_{j}^{\top}\bm{\theta}_{j})+\bm{\sigma}_{j}(\bm{x}_{j}^{\top}\bm{\theta}_{j})\cdot\bm{\tau}_{j},\quad j=1,\ldots,J,

(9)

where the vectors
\big\{(\bm{\tau}_{j},\bm{\epsilon}_{j})\big\}_{j=1}^{J}
are drawn from a standard Gaussian distribution.

The amortized structured variational approximation is efficient because the cost of representing
q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})
scales with the size of the neural network parameterization
\bm{\psi}_{j}
, rather than the dimension of
\bm{z}_{j}
or the number of observations. The variational approximation’s computational cost and memory footprint remain manageable even when dealing with high-dimensional auxiliary variables or large datasets, making it suitable for a wide range of practical applications.

4.2
Mean-field Variational Approximation

The mean-field approximation that we parameterize takes the form

\displaystyle q_{\bm{\phi},\bm{\psi}}(\bm{\theta},\bm{z})=\prod_{j=1}^{J}q_{\bm{\phi}_{j}}(\bm{\theta}_{j})q_{\bm{\psi}_{j}}(\bm{z}_{j}),

where the only difference with Section
4.1
is that we choose
q_{\bm{\psi}_{j}}(\bm{z}_{j})
such that
q_{\bm{\psi}_{j}}(\bm{z}_{j})=\mathcal{N}(\bm{\mu}_{\bm{z}_{j}},\bm{\sigma}_{\bm{z}_{j}})
where
\bm{\psi}_{j}=(\bm{\mu}_{\bm{z}_{j}}^{\top},\bm{\sigma}_{\bm{z}_{j}}^{\top})^{\top}
such that the variational approximation for
\bm{z}_{j}
no longer has dependence on
\bm{\theta}_{j}
. This form of variational approximation simplifies the reparameterization,

\displaystyle\bm{z}_{j}=\bm{\mu}_{\bm{z}_{j}}+\bm{\sigma}_{\bm{z}_{j}}\cdot\bm{\tau}_{j},\quad j=1,\ldots,J,

(10)

where
g
is now only parameterized by
\bm{\psi}_{j}
rather than both
\bm{\psi}_{j}
and
\bm{\phi}_{j}
.

4.3
Algorithm details for Augmented-variable model

This section describes the algorithm steps required to fit the augmented-variable model using the structured or mean-field variational approximation.
We begin by considering the evidence lower bound (ELBO) of the augmented-variable model using the structured variational approximation,

\displaystyle\mathcal{L}

\displaystyle=\mathbb{E}_{\prod_{j=1}^{J}q(\bm{z}_{j}|\bm{\theta}_{j})q(\bm{\theta}_{j})}\bigg[\underbrace{\log p(\bm{y}|\bm{z})}_{{\color[rgb]{1,0,0}\text{dependent}}}+\sum_{j=1}^{J}\bigg[\underbrace{\log\frac{p(\bm{z}_{j}|\bm{\theta}_{j})}{q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})}+\log\frac{p(\bm{\theta}_{j})}{q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}}_{{\color[rgb]{0,0,1}\text{independent}}}\bigg]\bigg]

\displaystyle=\mathbb{E}_{\prod_{j=1}^{J}q(\bm{z}_{j}|\bm{\theta}_{j})}\bigg[\log p(\bm{y}|\bm{z})\bigg]+\sum_{j=1}^{J}\mathbb{E}_{q(\bm{z}_{j}|\bm{\theta}_{j})q(\bm{\theta}_{j})}\bigg[\log\frac{p(\bm{z}_{j}|\bm{\theta}_{j})}{q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})}+\log\frac{p(\bm{\theta}_{j})}{q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}\bigg]

\displaystyle={\color[rgb]{1,0,0}\mathcal{L}_{0}}+\sum_{j=1}^{J}{\color[rgb]{0,0,1}\mathcal{L}_{j}}.

The ELBO decomposes into a term,
\mathcal{L}_{0}
(in
red
), which involves the likelihood
p(\bm{y}|\bm{z})
and requires global information depending on all the parameters and auxiliary variables, and an independent terms,
\mathcal{L}_{j}
(in
blue
), which can be computed locally by each client. Due to the structure in both the model and the variational approximation, the following gradients are equal to

\frac{\partial\mathcal{L}}{\partial\bm{\theta}}_{j}=\frac{\partial\mathcal{L}_{j}}{\partial\bm{\theta}_{j}}\quad\quad\text{and}\quad\quad\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}}=\frac{\partial\mathcal{L}_{0}}{\partial\bm{z}_{j}}+\frac{\partial\mathcal{L}_{j}}{\partial\bm{z}_{j}}.

Exploiting the sparsity in the Jacobian matrix of the reparameterization, the gradient estimate of
\widehat{\nabla}_{\bm{\phi}_{j}}\mathcal{L}
can be expressed as

\displaystyle\widehat{\nabla}_{\phi_{j}}\mathcal{L}

\displaystyle=\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{\theta}_{j}}+\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}_{j}}{\partial\bm{\theta}_{j}}}+{\color[rgb]{0,0,1}\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\psi}_{j}}}\bigg[{\color[rgb]{1,0,0}\frac{\partial\mathcal{L}_{0}}{\partial\bm{z}_{j}}}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{j}}{\partial\bm{z}_{j}}}\bigg],

(11)

and the gradient
\widehat{\nabla}_{\bm{\psi}_{j}}\mathcal{L}
is given by

\displaystyle\widehat{\nabla}_{\bm{\psi}_{j}}\mathcal{L}

\displaystyle=\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\psi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}}\bigg[{\color[rgb]{1,0,0}\frac{\partial\mathcal{L}_{0}}{\partial\bm{z}_{j}}}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{j}}{\partial\bm{z}_{j}}}\bigg],

(12)

where, following the same color coding introduced above, terms in
blue
can be computed independently by each client, and terms in
red
must be computed on the server.

When using the mean-field variational approximation, the dependency of the auxiliary variables
\bm{z}_{j}
on the variational parameters
\bm{\phi}_{j}
vanishes, resulting in a simplified gradient for
\widehat{\nabla}_{\bm{\phi}_{j}}\mathcal{L}
,

\displaystyle\widehat{\nabla}_{\phi_{j}}\mathcal{L}

\displaystyle=\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{\theta}_{j}}+\underbrace{\cancel{\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}}}}_{\text{dependency removed}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}_{j}}{\partial\bm{\theta}_{j}}}.

(13)

Having derived the necessary gradients for updating the variational parameters
\bm{\phi}_{j}
and
\bm{\psi}_{j}
, we now present Algorithm
1
for fitting the augmented-variable model using either the amortized structured or the mean-field variational approximation. The algorithm follows an iterative scheme where, at each iteration, the server calculates the gradient of the likelihood with respect to the auxiliary variables and sends the respective gradients to the clients. The clients then compute the required terms to update their parameters
\bm{\theta}_{j}
and auxiliary variables
\bm{z}_{j}
locally and return the updated auxiliary variables to the server. This process is repeated for a specified number of iterations or until convergence.

Algorithm details for Power-likelihood Model

The ELBO of the power-likelihood model with the amortized structured variational approximation is

\displaystyle\mathcal{L}

\displaystyle=\mathbb{E}_{\prod_{j=1}^{J}q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}\bigg[\frac{1}{J}\sum_{j=1}^{J}\underbrace{\log p(\bm{y}|\bm{\theta}_{j},\bm{z}_{-j})}_{{\color[rgb]{1,0,0}\text{dependent}}}+\sum_{j=1}^{J}\bigg[\underbrace{\log\frac{p(\bm{z}_{j}|\bm{\theta}_{j})}{q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})}+\log\frac{p(\bm{\theta}_{j})}{q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}}_{{\color[rgb]{0,0,1}\text{independent}}}\bigg]\bigg]

\displaystyle=\sum_{j=1}^{J}\frac{1}{J}\mathbb{E}_{q_{\bm{\phi}_{j}}(\bm{\theta}_{j})\prod_{k\neq j}^{J}q_{\bm{\psi}_{k}}(\bm{z}_{j}|\bm{\theta}_{j})}\bigg[\log p(\bm{y}|\bm{\theta}_{j},\bm{z}_{-j})\bigg]

(14)

\displaystyle\qquad\qquad+\sum_{j=1}^{J}\mathbb{E}_{q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}\bigg[\log\frac{p(\bm{z}_{j}|\bm{\theta}_{j})}{q_{\bm{\psi}_{j}}(\bm{z}_{j}|\bm{\theta}_{j})}+\log\frac{p(\bm{\theta}_{j})}{q_{\bm{\phi}_{j}}(\bm{\theta}_{j})}\bigg]

\displaystyle=\sum_{j=1}^{J}{\color[rgb]{1,0,0}\mathcal{L}_{0,j}}+\sum_{j=1}^{J}{\color[rgb]{0,0,1}\mathcal{L}_{1,j}}.

Due to the dependence structure in the ELBO, the following gradients are equal to

\frac{\partial\mathcal{L}}{\partial\bm{\theta}}_{j}=\frac{\partial\mathcal{L}_{0,j}}{\partial\bm{\theta}_{j}}\ +\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{\theta}_{j}}

and

\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}}=\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{z}_{j}}+\sum_{k\neq j}^{J}\bigg[\frac{\partial\mathcal{L}_{0,k}}{\partial\bm{z}_{j}}\bigg].

Due to the sparsity in the Jacobian matrix of the reparameterization used by the amortized structured variational approximation, the gradient of the ELBO with respect to the variational parameters
\bm{\phi}_{j}
can be written as

\displaystyle\widehat{\nabla}_{\bm{\phi}_{j}}\mathcal{L}

\displaystyle=\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{\theta}_{j}}+\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}}\bigg[{\color[rgb]{1,0,0}\frac{\partial\mathcal{L}_{0,j}}{\partial\bm{\theta}_{j}}}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{\theta}_{j}}}\bigg]+{\color[rgb]{0,0,1}\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}}\bigg[{\color[rgb]{1,0,0}\sum_{k\neq j}^{J}\bigg[\frac{\partial\mathcal{L}_{0,k}}{\partial\bm{z}_{j}}\bigg]}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{z}_{j}}}\bigg],

(15)

where terms in blue can be computed on a particular client with no added information from other clients required, and terms in red mean that information from other clients is required to calculate this term. The gradient of the ELBO with respect to the variational parameters
\bm{\psi}_{j}
are

\displaystyle\widehat{\nabla}_{\bm{\psi}_{j}}\mathcal{L}

\displaystyle=\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\psi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\psi}_{j}}}\bigg[{\color[rgb]{1,0,0}\sum_{k\neq j}^{J}\bigg[\frac{\partial\mathcal{L}_{0,k}}{\partial\bm{z}_{j}}\bigg]}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{z}_{j}}}\bigg].

(16)

Similar to the mean-field approximation with the auxiliary-variable model, when using the mean-field approximation with the power-likelihood model, the gradient of the ELBO with respect to
\bm{\phi}_{j}
simplifies to

\displaystyle\widehat{\nabla}_{\bm{\phi}_{j}}\mathcal{L}

\displaystyle=\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{\theta}_{j}}+\underbrace{\cancel{\frac{\partial g(\bm{\tau}_{j},\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}\frac{\partial\mathcal{L}}{\partial\bm{z}_{j}}}}_{\text{dependency removed}},

\displaystyle={\color[rgb]{0,0,1}\frac{\partial f(\bm{\epsilon}_{j})^{\top}}{\partial\bm{\phi}_{j}}}\bigg[{\color[rgb]{1,0,0}\frac{\partial\mathcal{L}_{0,j}}{\partial\bm{\theta}_{j}}}+{\color[rgb]{0,0,1}\frac{\partial\mathcal{L}_{1,j}}{\partial\bm{\theta}_{j}}}\bigg].

(17)

\bm{\phi}_{j}
and
\bm{\psi}_{j}

\bm{z}_{j}

\bm{z}

The server aggregates the gradients and sends the respective sums to each client. Finally, the clients update their variational parameters and auxiliary variables locally and send the updated auxiliary variables back to the server. This process is repeated for a specified number of iterations or until convergence.

5.2
Poisson Multilevel Regression

In this example, we demonstrate the application of a multilevel Poisson regression model to analyze a synthetic dataset designed to emulate the complexities of real-world health data associated with Australian geography at the Statistical Area 2 (SA2) level, which includes approximately
N=2000
areas. Our analysis focuses on cancer diagnosis counts per area as the response variable
\mathbf{y}\in\mathbb{R}^{n}
, inspired by the data representation in the
Australian Cancer Atlas

(
Duncan et al., 2019a
)
.
We consider a scenario where two clients each hold a unique set of SA2-level health-related covariates, represented as
\bm{x}_{1}\in\mathbb{R}^{N\times 2}
and
\bm{x}_{2}\in\mathbb{R}^{N\times 2}
. This setup reflects the real-world challenges of efficiently combining disparate health datasets while addressing logistical and privacy concerns. Additionally, we incorporate two publicly available variables: the population count per SA2 area (
\text{pop}_{i}
) and a remoteness level indicator (
r_{i}
) for each area
i
. The log of the population count serves as an offset term to model the rate of cancer diagnoses per area. At the same time, the remoteness indicator allows us to explore how associations vary across different levels of remoteness.

The motivation for this example is twofold. First, we aim to demonstrate the feasibility of fitting multilevel models in the vertical federated learning (VFL) setting using the auxiliary variable approaches described in this paper. Second, fitting multilevel models such as these might enable individual clients to randomly choose the multilevel structure they want to model their data with to hide information about their underlying data while still obtaining meaningful estimates of the covariate effects of interest.

We examine two models in this example: the true underlying Poisson multilevel model from which we simulate the synthetic dataset and the equivalent augmented-variable model. The specification for the Poisson multilevel regression model is

\displaystyle y_{i}

\displaystyle\sim\text{Poisson}(\lambda_{i}),\quad i=1,\ldots,N,

\displaystyle\log(\lambda_{i})

\displaystyle=b+\log(\text{pop}_{i})+\sum_{j=1}^{J}\bm{x}_{ij}^{\top}\bm{\beta}_{ij}^{r_{i}},\quad i=1,\ldots,N,\quad j=1,\ldots,J,

\displaystyle\bm{\beta}_{ij}^{r_{i}}

\displaystyle\sim\mathcal{N}(\bm{\mu}_{j}^{r_{i}},\bm{\sigma}_{j}^{r_{i}}),\quad j=1,\ldots,J,

\displaystyle\bm{\mu}_{j}^{r_{i}}

\displaystyle\sim\mathcal{N}(0,1),\quad j=1,\ldots,J,

\displaystyle\bm{\sigma}_{j}^{r_{i}}

\displaystyle\sim\mathcal{HN}(1),\quad j=1,\ldots,J,

\displaystyle b

\displaystyle\sim\mathcal{N}(0,1).

The specification for the equivalent augmented-variable model is

\displaystyle y_{i}

\displaystyle\sim\text{Poisson}(\lambda_{i}),\quad i=1,\ldots,N,

\displaystyle\log(\lambda_{i})

Hierarchical Bayes Split Neural Net

Split NN
(
Poirot et al., 2019a
;
Ceballos et al., 2020a
;
Thapa et al., 2022a
)
are a specific model developed for vertical FL applications whereby clients may not have access to the response variable; sometimes this task is referred to as
split learning
. In this section, we consider a classification task with two classes. The split NN variant of a logistic regression model is

\displaystyle y_{i}

\displaystyle\sim\text{Bernoulli}(\lambda_{i}),\quad i=1,\ldots,N,

\displaystyle\text{logit}(\lambda_{i})

\displaystyle=\sum_{j=1}^{J}z_{ij},\quad i=1,\ldots,N\,

\displaystyle z_{ij}

\displaystyle=f_{\bm{\phi}_{j}}(\bm{x}_{ij}),\quad i=1,\ldots,N,\quad j=1,\ldots,J,

where each
f_{\bm{\phi}_{j}}
is a client-specific NN parameterized by
\bm{\phi}_{j}
, that outputs
\bm{z}_{j}\in\mathbb{R}^{N}
. In order to fit the above model via gradient descent using automatic differentiation, updating the parameters
\bm{\phi}_{j}
requires each client to calculate
\frac{\partial p(y_{i}|\lambda_{i})}{\partial z_{ij}}\frac{\partial z_{ij}}{\partial\bm{\phi}_{j}}
. If each client communicates
z_{ij}
to the server, the server can calculate and return
\frac{\partial p(y_{i}|\lambda_{i})}{\partial z_{ij}}
to each client. Each client can independently calculate
\frac{\partial h_{ij}}{\partial\bm{\phi}_{j}}

and thus have the necessary gradient information to calculate the required update.

\displaystyle y_{i}

In this hierarchical Bayes variant, the final-layer weights
\bm{w}_{j}
of the function
f_{\bm{\phi}_{j}}
are treated as random variables and assigned a prior distribution. The dot product the hidden vector

\bm{h}_{ij}
with the weights
\bm{w}_{j}
parameterizes the mean of the prior distribution for auxiliary variable
\bm{z}_{ij}
. Each client sends their respective parameters
\bm{z}_{j}
to the server, and the server performs the same steps as in the standard split NN. Figure

Bayesian models offer advantages such as natural probabilistic interpretations of uncertainty and more accurately calibrated estimates, especially when trained on limited data. In this FL context, the Bayesian analog of split
NNs provides two specific benefits related to privacy and efficient computation. First, the random variable
z_{ij}
has a Gaussian prior distribution with a standard deviation equal to the hyperparameter
\rho
; this allows the client to send a noisy estimate of the function output of
f_{\bm{\phi}_{j}}
to the server, enhancing privacy. Second, the hierarchical Bayes variant offers computational advantages. In a split NN, only one gradient step can be taken for the weights
\bm{\phi}_{j}
per communication round with the server, as the value

is required at each step. The hierarchical Bayes variant benefits from

being a stochastic function of
x_{ij}
and the conditional independence of the parameters
\bm{\phi}_{j}
and local latent variables from the likelihood function given
\bm{z}_{j}
. This allows for multiple updates of
\bm{\phi}_{j}
and
\bm{w}_{j}
for a fixed value of
\bm{z}_{j}
without requiring communication with the server.

6
Discussion

This paper represents, to our knowledge, the first contribution to the literature on Bayesian methods in the VFL setting. We formulated auxiliary variable methods for fitting Bayesian models in VFL and designed a new model type tailored for specific VFL settings, demonstrating improved performance over existing augmented-variable models. The auxiliary variable methods used in this paper increase the dimensionality of the model, with the number of additional parameters equaling the product of the number of observations and clients. To address this, we propose a factorized amortized approximation that prevents the dimensionality of the inference task from scaling with the number of observations while improving performance over standard Gaussian variational approximations, exhibiting faster convergence and enabling subsampling.

We showcase the proposed methods through three illustrative examples. First, we fit a logistic regression model and compare the estimates from the actual, augmented-variable, and novel power-likelihood models using both MCMC and variational approximations, assessing performance with varying values of the privacy-aiding hyperparameter
\rho
and a varying number of clients. Second, we fit a complex multilevel regression model, demonstrating the ease of fitting multilevel models and the ability of clients to create an additional multilevel structure unknown to other clients or the server, potentially enhancing data privacy while maintaining accurate parameter estimates. Lastly, we introduce a novel hierarchical Bayes split NN and compare it to a split NN, showcasing the scalability of the proposed Bayesian auxiliary variable methods with the amortized approximation, handling large numbers of observations and incorporating sub-sampling. The hierarchical Bayes variant exhibits similar test accuracy but a higher average test log-likelihood than the original, indicating better-calibrated estimates. Additional benefits of the hierarchical Bayes variant include the addition of the
\rho
hyperparameter, aiding privacy and enabling more computationally and communication-efficient algorithmic schemes by exploiting the conditional independence created.

This work opens up numerous promising avenues for future investigation. While the current algorithms are not embarrassingly parallel for updating the parameters
\bm{z}
, specific schemes like the SOUL algorithm
(
De et al., 2021c
)
, for which we provide derivations in Appendix
A
, or other EM-style algorithms
(
Kuntz et al., 2023a
;
Sharrock et al., 2023a
;
Gruffaz et al., 2024a
)
can fit the same models with fewer iterations for estimating
\bm{z}
. However, the SOUL algorithm provides only maximum a posteriori (MAP) estimates for
\bm{z}
, resulting in narrower posterior distributions for
\bm{\theta}
conditional on
\bm{z}
rather than marginalizing over
\bm{z}
. Moreover, using algorithms like SOUL would make the inference problem’s scaling dependent on the dimensionality of
\bm{z}
, potentially causing issues as SOUL was initially used in low-dimensional
\bm{z}
scenarios.

Another promising research direction involves developing mechanisms to estimate weight parameters for each client’s likelihood contributions, aiding model selection and ranking the importance of variables and clients. Asynchronous client updates, an open question in most distributed Bayesian inference settings
(
Winter et al., 2024a
)
, represent another avenue to elevate the framework’s practical utility. In contrast to the conventional synchronous approach, where client updates are coordinated, leading to bottlenecks as the client count increases, asynchronous updates allow clients to submit updates independently without strict synchronization demands. Asynchronous updates offer reduced latency, increased resilience, and enhanced scalability, making the proposed methods more suitable for real-world applications and industry settings.

\displaystyle\widehat{\nabla}_{\bm{z}_{j}}\log p(\bm{y}|\bm{z},\rho)=\frac{1}{m}\sum_{m=1}^{M}\nabla_{\bm{z}_{j}}\log p(\bm{\theta}_{k}^{(m)},\bm{y}|\bm{z};\rho),\quad\bm{\theta}^{(m)}\sim p(\bm{\theta}_{j}|\bm{y},\bm{z};\rho),\quad m=1,\ldots,M.
