A 1024 RV-Cores Shared-L1 Cluster with High Bandwidth Memory Link for Low-Latency 6G-SDR
Yichao Zhang 1 , Marco Bertuletti 1 , Chi Zhang 1 , Samuel Riedel 1 , Alessandro Vanelli-Coralli 1 2 and Luca Benini 1 2

Abstract
We introduce an open-source architecture for next-generation Radio-Access Network baseband processing: 1024 1024 latency-tolerant 32-bit RISC-V cores share 4 MiB 4\text{\,}\mathrm{MiB} of L1 memory via an ultra-low latency interconnect ( 7 7 - 11 11 cycles), a modular Direct Memory Access engine provides an efficient link to a high bandwidth memory, such as HBM2E ( 98 % 98\text{\,}\mathrm{\%} peak bandwidth at 910 GBps 910\text{\,}\mathrm{G}\mathrm{B}\mathrm{p}\mathrm{s} ). The system achieves leading-edge energy efficiency at sub- ms \mathrm{ms} latency in key 6G baseband processing kernels: Fast Fourier Transform ( 93 GOPS / W 93\text{\,}\mathrm{GOPS}\text{/}\mathrm{W} ), Beamforming ( 125 GOPS / W 125\text{\,}\mathrm{GOPS}\text{/}\mathrm{W} ), Channel Estimation ( 96 GOPS / W 96\text{\,}\mathrm{GOPS}\text{/}\mathrm{W} ), and Linear System Inversion ( 61 GOPS / W 61\text{\,}\mathrm{GOPS}\text{/}\mathrm{W} ), with only 9 % 9\text{\,}\mathrm{\%} data movement overhead.
