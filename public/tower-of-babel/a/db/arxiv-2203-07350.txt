Abstract
Аннотация We consider self-similar constructions of transformations that preserve the sigma-finite measure. Their properties and spectra of induced Gaussian and Poisson dynamical systems are studied. An orthogonal operator corresponding to such a transformation has the following property: some of its powers is a nontrivial direct sum of operators isomorphic to the original one. For any set M ⊂ 𝐍 M\subset{\mathbf{N}} , there is a Poisson suspension with spectral multiplicity set of the form M ∪ { ∞ } M\cup\{\infty\} . There is Gaussian flow S t S_{t} such that the automorphism S p n S_{p^{n}} has spectral multiplicities { 1 , ∞ } \{1,\infty\} as n ≤ 0 n\leq 0 , and { p n , ∞ } \{p^{n},\infty\} as n > 0 n>0 , its infinite tensor power T t T_{t} is so that automorphisms T p n T_{p^{n}} have different spectral types for n ≤ 0 n\leq 0 , but all automorphisms T p n , n > 0 , T_{p^{n}},n>0, are isomorphic. We also consider the constructions of self-similar flows and discuss the problems that arise in connection with them. В заметке рассматриваются самоподобные конструкции преобразований, сохраняющих сигма-конечную меру, изучаются их свойства и спектры индуцированных гауссовских и пуассоновских динамических систем. Ортогональный оператор, отвечающий такому преобразованию, обладает свойством: некоторая его степень является нетривиальной прямой суммой операторов, изоморфных исходному. Получены следующие результаты. Для любого подмножества M M натурального ряда в классе пуасоновских надстроек реализованы наборы спектральных кратностей вида M ∪ { ∞ } M\cup\{\infty\} . Предъявлен гауссовский поток S t S_{t} такой, что автоморфизмы S p n S_{p^{n}} обладают набором спектральных кратностей { 1 , ∞ } \{1,\infty\} , если n ≤ 0 n\leq 0 , и наборами кратностей { p n ​ ∞ } \{p^{n}\infty\} при n > 0 n>0 ; бесконечная тензорная степень T t T_{t} потока S t S_{t} такова, что автоморфизмы T p n T_{p^{n}} обладают различными спектральными типами при n ≤ 0 n\leq 0 , но все автоморфизмы T p n , n > 0 , T_{p^{n}},n>0, попарно изоморфны между собой.
