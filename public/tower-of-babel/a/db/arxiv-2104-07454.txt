Memory Capacity of Recurrent Neural Networks with Matrix Representation
Animesh Renanse, Alok Sharma, Rohitash Chandra

Abstract
It is well known that canonical recurrent neural networks (RNNs) face limitations in learning long-term dependencies which have been addressed by memory structures in long short-term memory (LSTM) networks. Neural Turing machines (NTMs) are novel RNNs that implement the notion of programmable computers with neural network controllers that can learn simple algorithmic tasks. Matrix neural networks feature matrix representation which inherently preserves the spatial structure of data when compared to canonical neural networks that use vector-based representation. One may then argue that neural networks with matrix representations may have the potential to provide better memory capacity. In this paper, we define and study a probabilistic notion of memory capacity based on Fisher information for matrix-based RNNs. We find bounds on memory capacity for such networks under various hypotheses and compare them with their vector counterparts. In particular, we show that the memory capacity of such networks is bounded by N 2 N^{2} for N × N N\times N state matrix which generalizes the one known for vector networks. We also show and analyze the increase in memory capacity for such networks which is introduced when one exhibits an external state memory, such as NTMs. Consequently, we construct NTMs with RNN controllers with matrix-based representation of external memory, leading us to introduce Matrix NTMs. We demonstrate the performance of this class of memory networks under certain algorithmic learning tasks such as copying and recall and compare it with Matrix RNNs. We find an improvement in the performance of Matrix NTMs by the addition of external memory, in comparison to Matrix RNNs.

Intuitively, one might argue that such matrix representations might always be better than vector representations in terms of memory capacity. Background

2.1
Memory Capacity in Neural Networks

We note that conventional neural networks follow vector-based representation, and our focus in this paper is matrix-based neural networks. The broader work on the memory capacity and the general capacity of conventional neural networks provides multiple notions of the memory capacity of neural networks. Baldi and Vershynin
[
30
]
defined
\log_{2}\left|S\right|
as the memory capacity of the architecture, where
S
is the set of all functions that it can realize. It has been shown that for a recurrent neural network with
N
total neurons, the
memory capacity is proportional to
N^{3}

[
30
]
. Furthermore, the same definition is used to derive that the capacity of a usual
L
layered neural network with only threshold activation is upper bounded by a cubic polynomial in size of each layer with bottleneck layers limiting this upper bound
[
31
]
. However, the definition of capacity in this case from a memory standpoint is only
expressive
in the sense that it does not refer to any capability of the network to
remember
the past inputs. A stronger argument has been
for the definition of
memory capacity
where the existence of a realizable function such that the given architecture can perfectly remember past inputs
[
30
]
. That is, the largest value of
K
such that there exists a function
F
in the space of all functions realizable by the given architecture
S
, so that for a given set of data
x_{i}
and label
y_{i}
,
\{(x_{1},y_{1}),\dots,(x_{K},y_{K})\}
, it’s true that

F(x_{i})=y_{i}\;\;\text{for all }\;i=1,\dots,K.

This definition has been used to develop the memory capacity of multilayered neural networks with threshold and rectifier linear unit (ReLU) activation functions
[
32
]
, where it was shown that the memory capacity is lower bounded by the number of total weights. This definition allows deeper mathematical analysis as visible by the remarkable results in other works
[
32
]
. However, this definition is not easily portable to higher-order representations and their analysis. We gather that most of the analysis done
[
32
]
depends on the vector representations retrieved from the affine transform
{\bm{W}}{\bm{x}}+{\bm{b}}
, whereas this paper focuses on the bilinear transform
{\bm{U}}^{T}{\bm{X}}{\bm{V}}+{\bm{B}}
to generate matrix representations of input data. Apart from this, the set of functions realized by the bilinear transforms are fundamentally different from affine transformation. The extension of the theory would at the very least need extension of the probabilistic view of the realizable function
F
to their matrix counterpart, which further makes the situation unmanageable
[
31
,
32
]
.

Some of the earlier works on neural networks from a dynamical systems viewpoint provides a possible alternative definition of the memory capacity purely in terms of a statistic. A discrete-time recurrent system
[
33
,
26
]
is given by

\begin{split}{\bm{x}}(n)={\bm{W}}{\bm{x}}(n-1)+{\bm{v}}s(n)+{\bm{z}}(n)\end{split}

(2)

where
{\bm{W}}
is the recurrent connectivity matrix and the time-dependent scalar signal
s(n)
is passed through this system via feedforward connection
{\bm{v}}
which contains an additive noise content
{\bm{z}}(n)
. Additionally, we can consider an output layer that transforms the state
{\bm{x}}(n)
of length
N
to an output vector
{\bm{y}}(n)
of length
M
such that
y_{i}(n)={\bm{x}}(n)^{T}{\bm{u}}_{i}
for
i=1,\dots,M
. The objective of the system is to have output
y_{j}(n)
equal to the past signal observed
s(n-j)
. Given this premise in place, the memory trace
m(k)
has been defined
[
33
]
as

\begin{split}m(k)=\mathbb{E}\left[s(n-k)y_{k}(n)\right]\end{split}

(3)

where expectation is over time. The (asymptotic) memory capacity can be now defined naturally as the following extension of Eq.
3
,

m_{tot}=\sum_{k=0}^{\infty}m(k).

(4)

Using this definition, we are only shifting our focus on a particular task of past recall, which is orthogonal to our aim of determining the memory capacity of the system itself, invariant of the task it’s performing. To achieve this aim, we clearly need to focus more on the memory capacity induced by the state transition of the system. There has been an extension to a more general notion of memory capacity
[
26
]
, with the trace of the Fisher Information Matrix (FIM) or equivalently the Fisher Memory Matrix (FMM). This depends upon the context of interpretation of the state
{\bm{x}}(n)
with the vector of temporal scalar inputs
{\bm{s}}
, as the parameters of the conditional
p({\bm{x}}(n)|{\bm{s}})
.

Hence, the Fisher information matrix of
p({\bm{x}}(n)|{\bm{s}})
measures the memory capacity by the capability of past inputs
s(i)
for
i\leq n
to perturb the current state
{\bm{x}}(n)
, which in turn shows the reluctance or permeability of the state
{\bm{x}}(n)
to change under a new
{\bm{s}}
. Note that such a measure does not depend explicitly on the structure of the state
{\bm{x}}(n)
as that information is portrayed by
p({\bm{x}}(n)|{\bm{s}})
. Thus, as long as we are able to determine the conditional for a given type of state and discrete dynamics (even for matrix representations shown in Eq.
5
), we can use this definition for obtaining a measure of memory capacity. However, its reliance on statistical information about the sensitivity of state rather than an explicit measure of the maximum size of the input data which the architecture can map correctly, makes this definition weaker
than that given by Vershynin
[
32
]
for artificial neural networks. However, due to its invariance on the state structure explicitly, and dependence only on the conditional distribution of the current state given past inputs, it becomes ideal for analysis on a much more diverse set of representations in neural networks.

{\bm{J}}
which signifies the Fisher information that the state
{\bm{X}}\left(n\right)
retains about a pulse entering the network
k
time steps in the past. Thus, using this concept, one can define the memory decay of previous inputs by considering the set
\left\{{\bm{J}}\left(i\right)={\bm{J}}_{i,i}|\;0\leq i<\infty\right\}
of all diagonal elements of
{\bm{J}}
, hence the FMC as described in Eq.
12
.

2.4
The Memory Capacity

The FMC shown in Eq.
12
identifies the decay of information in the state
{\bm{X}}\left(n\right)
about the past signals. However, in order to capture the memory capacity of the system, we would need to measure the amount of information remaining in
{\bm{X}}\left(n\right)
for all the previous inputs as this will tell us the exact amount of Fisher information that the system has encoded about all the prior inputs. This can be represented by summing over all
i
in Eq.
12
, thus yielding us the following definition of the memory capacity.

Definition 1
.

(Memory Capacity) The asymptotic memory capacity of a recurrent system is defined as the sum of the Fisher information stored for all of the past input signals in the current state of the system

\begin{split}{\bm{J}}_{tot}&=\sum_{i=0}^{\infty}{\bm{J}}\left(i\right).\end{split}

(15)

Given this definition, the memory capacity of the matrix representation of RNN as defined in Eq.
5
with no non-linearity (
f=\text{id}
) is

{\bm{J}}_{tot}=\sum_{i=0}^{\infty}\Tr\left(\mathbf{\Sigma}^{-1}{\bm{V}}^{iT}{\bm{W}}^{T}{\bm{U}}^{i}\mathbf{\Psi}^{-1}{\bm{U}}^{iT}{\bm{W}}{\bm{V}}^{i}\right).

(16)

This definition of memory capacity is general but doesn’t give much insight into the limit or bounds of the capacity directly. Motivated by the study of vector representation on the similar assumptions given in
[
26
]
,
we now discuss two cases. Firstly, we consider the case when the recurrent connectivity matrices are assumed to be normal, and secondly, the case when they are not. We discuss the latter with a reformed view of Eq.
12
.

2.4.1
Capacity of Normal Networks

The form of
{\bm{J}}\left(i\right)
in Eq.
12
doesn’t allow much room for direct analysis, thus, we make certain assumptions to dissect it further. One important assumption that we will continue to deal with is that of normal recurrent connectivity i.e. matrices
{\bm{U}}^{T}
and
{\bm{V}}
are assumed to be normal, that is they commute with their transpose. This assumption simplifies the FMC and provides insights into the interaction between the connectivity matrices. Hence, we can write Eq.
12
as the eigendecomposition of
{\bm{U}}
and
{\bm{V}}

\begin{split}{\bm{J}}(i)&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left(\left({\bm{I}}-\mathbf{\Lambda}^{2}_{V}\right)\mathbf{\Lambda}_{V}^{i}{\bm{B}}^{H}\mathbf{\Lambda}_{U}^{i}\left({\bm{I}}-\mathbf{\Lambda}_{U}^{2}\right)\mathbf{\Lambda}_{U}^{i}{\bm{B}}\mathbf{\Lambda}_{V}^{i}\right)\end{split}

(17)

where
{\bm{E}}_{V}
,
\mathbf{\Lambda}_{V}
and
{\bm{E}}_{U}
,
\mathbf{\Lambda}_{U}
are the corresponding orthogonal eigenvector and diagonal eigenvalue matrices for
{\bm{V}}
and
{\bm{U}}
respectively and for clarity, we define
{\bm{B}}:={\bm{E}}_{U}^{H}{\bm{W}}{\bm{E}}_{V}
. The form in Eq.
17
can be achieved by substituting Eq.
9

in Eq.
12
and taking all matrices inside the inverse introduced by
\mathbf{\Sigma}
and
\mathbf{\Psi}
.

Deriving the capacity
{\bm{J}}_{tot}
is now straightforward from Eq.
17
, and the calculations
are shown as follows
.

Theorem 2
.

(Capacity of Normal Matrix Networks) Given the dynamical system
5
and that both the connection matrices
{\bm{U}}
and
{\bm{V}}
are normal, the memory capacity of the system is given as the following.

\begin{split}{\bm{J}}_{tot}&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\sum_{j=1}^{N}\sum_{k=1}^{N}\frac{\left(1-\left|\lambda_{V_{k}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{k}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}|b_{jk}|^{2}\end{split}

(18)

where
\lambda_{V_{k}}
,
\lambda_{U_{j}}
are the respective eigenvalues of
{\bm{V}}
and
{\bm{U}}
and
b_{jk}
is the
(j,k)^{th}
element of
{\bm{B}}
.

Proof.

To derive the form of
{\bm{J}}_{tot}
as in Eq.
18
from
{\bm{J}}\left(i\right)
(Eq.
17
), we would first need to notice that the sum over Trace is just Trace of the sum, enabling us to write,

\begin{split}{\bm{J}}_{tot}&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left(\sum_{i=0}^{\infty}\left({\bm{I}}-\mathbf{\Lambda}_{V}^{2}\right)\mathbf{\Lambda}_{V}^{i}{\bm{B}}^{H}\mathbf{\Lambda}_{U}^{2i}\left({\bm{I}}-\mathbf{\Lambda}_{U}^{2}\right){\bm{B}}\mathbf{\Lambda}_{V}^{i}\right).\end{split}

(19)

Since the
{\bm{J}}_{tot}
above includes
{\bm{B}}
and its transpose in between the diagonal eigenvalue matrices, thus there will be off-diagonal interaction terms in between the eigenvalues, which would complicate the sum. However, one can note that we can write a matrix equation of the form
{\bm{D}}_{\bm{x}}{\bm{B}}^{H}{\bm{D}}_{\bm{y}}{\bm{B}}{\bm{D}}_{\bm{z}}
where
{\bm{D}}_{\bm{x}}
,
{\bm{D}}_{\bm{y}}
and
{\bm{D}}_{\bm{z}}
are diagonal matrices formed by column vectors
{\bm{x}}
,
{\bm{y}}
and
{\bm{z}}
respectively as follows

\begin{split}{\bm{D}}_{\bm{x}}{\bm{B}}^{H}{\bm{D}}_{\bm{y}}{\bm{B}}{\bm{D}}_{\bm{z}}&=\sum_{j=1}^{N}{\bm{y}}_{j}\left({\bm{x}}\odot{\bm{b}}_{j}^{H}\right)\left({\bm{z}}^{H}\odot{\bm{b}}_{j}\right)\\
&=\sum_{j=1}^{N}{\bm{y}}_{j}\left({\bm{x}}{\bm{z}}^{H}\right)\odot\left({\bm{b}}_{j}^{H}{\bm{b}}_{j}\right)\end{split}

where
{\bm{b}}_{j}
is the
j^{th}
row of
{\bm{B}}
. Hence, we can represent
19
by letting
{\bm{x}}^{i}=\text{vec}\left(\left({\bm{I}}-\mathbf{\Lambda}_{V}^{2}\right)\mathbf{\Lambda}_{V}^{i}\right)
,
{\bm{y}}^{i}=\text{vec}\left(\left({\bm{I}}-\mathbf{\Lambda}_{U}^{2}\right)\mathbf{\Lambda}_{U}^{2i}\right)
and
{\bm{z}}^{i}=\text{vec}\left(\mathbf{\Lambda}_{V}^{i}\right)

\begin{split}{\bm{J}}_{tot}&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left(\sum_{i=0}^{\infty}\sum_{j=1}^{N}{\bm{y}}_{j}^{i}\left({\bm{x}}^{i}({\bm{z}}^{i})^{H}\right)\odot\left({\bm{b}}_{j}^{H}{\bm{b}}_{j}\right)\right)\\
&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left(\sum_{j=1}^{N}\sum_{i=0}^{\infty}{\bm{y}}_{j}^{i}\left({\bm{x}}^{i}({\bm{z}}^{i})^{H}\right)\odot\left({\bm{b}}_{j}^{H}{\bm{b}}_{j}\right)\right)\\
&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left(\sum_{j=1}^{N}\underbrace{\left(\sum_{i=0}^{\infty}{\bm{y}}_{j}^{i}\left({\bm{x}}^{i}\left({\bm{z}}^{i}\right)^{H}\right)\right)}_{\text{An $N\times N$ Matrix $\mathbf{\Lambda}_{j}$}}\odot\left({\bm{b}}_{j}^{H}{\bm{b}}_{j}\right)\right)\end{split}

(20)

where
\mathbf{\Lambda}_{i}
is the matrix of interaction between the eigenvalues of
{\bm{U}}
and
{\bm{V}}
obtained after taking the infinite geometric sum present in each of its elements, which can be represented as the following matrix

\begin{split}\mathbf{\Lambda}_{j}=\begin{bmatrix}\frac{\left(1-\left|\lambda_{V_{1}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{1}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}&\cdots&\frac{\left(1-\left|\lambda_{V_{1}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{1}}\right|\left|\lambda_{V_{N}}\right|\left|\lambda_{U_{j}}\right|^{2}}\\
\vdots&\ddots&\vdots\\
\frac{\left(1-\left|\lambda_{V_{N}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{1}}\right|\left|\lambda_{V_{N}}\right|\left|\lambda_{U_{j}}\right|^{2}}&\cdots&\frac{\left(1-\left|\lambda_{V_{N}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{N}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}\end{bmatrix}\end{split}

(21)

where
\lambda_{V_{k}}
and
\lambda_{U_{l}}
for
k,l\in\left\{1,\cdots,N\right\}
are the eigenvalues of
{\bm{V}}
and
{\bm{U}}
respectively.

The matrix
\mathbf{\Lambda}_{j}
essentially represents the
weight
of each entry in the
N\times N
matrix
{\bm{b}}_{j}^{H}{\bm{b}}_{j}
, where
\sum_{j=1}^{N}{\bm{b}}_{j}^{H}{\bm{b}}_{j}={\bm{B}}^{H}{\bm{B}}={\bm{E}}_{V}^{H}{\bm{W}}^{T}{\bm{W}}{\bm{E}}_{V}
. Note that
{\bm{W}}{\bm{E}}_{V}
is the projection of each row of
{\bm{W}}
onto the eigenspace of
{\bm{V}}
. This is similar to the case
[
26
]
, where the authors obtained the projection of feedforward connection vector onto the eigenspace of recurrent connectivity. However, in this case, these projections does not add up to
1
unless we constrain
{\bm{W}}
to be unitary, in which case
{\bm{B}}^{H}{\bm{B}}={\bm{I}}
. However, such a constraint will not be beneficial as in essence, we are restricting the input signal to only be visible to the diagonal elements of the state matrix after transformation by
{\bm{U}}
and
{\bm{V}}
. This has an attenuation effect on the signal entering the state due to the matrix product, which can affect the information negatively in the long term. In Corollary
2.1
, we show this effect of such constraint by proving a bound on
{\bm{J}}_{tot}
which shows the inability of such constraint to store past information.

Now using
\mathbf{\Lambda}_{j}
, we can find a form of
{\bm{J}}_{tot}
which is a bit simpler

\begin{split}{\bm{J}}_{tot}&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\sum_{j=1}^{N}\Tr\left(\mathbf{\Lambda}_{j}\odot{\bm{b}}_{j}^{H}{\bm{b}}_{j}\right)\end{split}

(22)

or equivalently, we can represent it as the sum of all sums of weighted diagonal elements of
{\bm{b}}_{j}^{H}{\bm{b}}_{j}

\begin{split}{\bm{J}}_{tot}&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\sum_{j=1}^{N}\sum_{k=1}^{N}\frac{\left(1-\left|\lambda_{V_{k}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{k}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}|b_{jk}|^{2}\end{split}

(23)

where
b_{jk}
is the corresponding element of matrix
{\bm{B}}
. This completes the proof.
∎

Remark 3
.

The form in Eq.
23
now can be explored analytically, especially due to the fact that the function of eigenvalues in Eq.
23
,
\frac{\left(1-\left|\lambda_{V_{k}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{k}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}
can easily seen to be
\leq 1
, if
\left|\lambda_{V_{k}}\right|
,
\left|\lambda_{U_{k}}\right|

\leq 1
, which informally implies that the weights for the elements
|b_{jk}|^{2}
are
\leq 1
which can be used to create bounds for
{\bm{J}}_{tot}
.

As visible from Eq.
18
, the total capacity is dependent on the mixture of eigenvalues of the connectivity matrices, unlike the capacity in normal vector representation networks where the eigenvalues of the recurrent connectivity all add up to 1, thus yielding
{\bm{J}}_{{tot}_{rel}}=1
relative to the input Fisher information. On the other hand, in the case of our recurrent system in Eq.
5
, we have the input Fisher information given through the following lemma.

Lemma 2
.

(Input Fisher Information) The Fisher information received by the state of the recurrent system in Eq.
5
with no non-linearity (
f=\text{id}
) at each timestep is given by,

\begin{split}\mathcal{I}\left({\bm{W}}\right)&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\|{\bm{W}}\|_{F}^{2}\end{split}

(24)

where
\|.\|_{F}
is the Frobenius norm.

Proof.

The Fisher Information for a random variable
x
is given as

\begin{split}\mathcal{I}\left(\theta\right)&=-\mathbb{E}\left[\frac{\partial^{2}}{\partial\theta^{2}}\log f_{{\textnormal{x}}}\left(x;\theta\right)\right]\end{split}

(25)

where
f_{{\textnormal{x}}}\left(x;\theta\right)
is the density function of
x
under the regularity condition that
\log f_{{\textnormal{x}}}(x;\theta)
is twice differentiable.

Consider now the timestep
t
, where the input is given to the state via the following,

\begin{split}{\bm{X}}\left(t\right)={\bm{W}}{\bm{s}}_{0}+{\mathbf{Z}}.\end{split}

Note that
{\bm{s}}_{0}={\bm{s}}\left(t-0\right)
and
{\mathbf{Z}}\sim\mathcal{MN}_{n\times p}\left(\mathbf{0},\text{diag}\left(\varepsilon_{1}\right),\text{diag}\left(\varepsilon_{2}\right)\right)
. Hence,
{\bm{X}}
will also be a random matrix with mean
{\bm{W}}{\bm{s}}_{0}
and same covariance matrices,

\begin{split}{\mathbf{X}}\left(t\right)\sim\mathcal{MN}_{n\times p}\left({\bm{W}}{\bm{s}}_{0},\text{diag}\left(\varepsilon_{1}\right),\text{diag}\left(\varepsilon_{2}\right)\right).\end{split}

We can now calculate Fisher information of
{\mathbf{X}}\left(t\right)
parameterized by
{\bm{s}}_{0}
simply by using Eq.
25
to get

\begin{split}\mathcal{I}\left({\bm{s}}_{0}\right)&=-\mathbb{E}\Biggl[\frac{\partial^{2}}{\partial{\bm{s}}_{0}^{2}}\Biggl(-\log\left(\left(2\pi\right)^{\frac{1}{2}np}\left|\text{diag}(\varepsilon_{1})\right|^{\frac{1}{2}p}\left|\text{diag}(\varepsilon_{2})\right|^{\frac{1}{2}n}\right)\\
&\;\;\;-\frac{1}{2}\Tr\left(\text{diag}(\varepsilon_{2})^{-1}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)^{T}\text{diag}(\varepsilon_{1})^{-1}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)\right)\Biggl)\Biggl]\\
&=-\mathbb{E}\left[\frac{\partial^{2}}{\partial{\bm{s}}_{0}^{2}}\left(-\frac{1}{2\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{I}}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)^{T}{\bm{I}}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)\right)\right)\right]\\
&=\frac{1}{2\varepsilon_{1}\varepsilon_{2}}\mathbb{E}\left[\frac{\partial^{2}}{\partial{\bm{s}}_{0}^{2}}\Tr\left(\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)^{T}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)\right)\right]\\
&=\frac{1}{2\varepsilon_{1}\varepsilon_{2}}\mathbb{E}\left[\Tr\left(\frac{\partial^{2}}{\partial{\bm{s}}_{0}^{2}}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)^{T}\left({\bm{X}}-{\bm{W}}{\bm{s}}_{0}\right)\right)\right]\\
&=\frac{1}{2\varepsilon_{1}\varepsilon_{2}}\mathbb{E}\left[\Tr\left(2{\bm{W}}^{T}{\bm{W}}\right)\right]\\
&=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{W}}^{T}{\bm{W}}\right).\end{split}

This completes the proof.
∎

Given the input Fisher information, we now see an interesting case arising from Theorem
2
when
{\bm{U}}
and
{\bm{V}}
are further assumed to be convergent apart from being normal. In particular, we observe that
g\left(\left|\lambda_{V_{k}}\right|,\left|\lambda_{U_{j}}\right|\right)=\frac{\left(1-\left|\lambda_{V_{k}}\right|^{2}\right)\left(1-\left|\lambda_{U_{j}}\right|^{2}\right)}{1-\left|\lambda_{V_{k}}\right|^{2}\left|\lambda_{U_{j}}\right|^{2}}\in(0,1)
as
0<\left|\lambda_{V_{k}}\right|,\left|\lambda_{U_{j}}\right|<1
due to convergent condition and
\frac{1}{\varepsilon_{1}\varepsilon_{2}}\sum_{j=1}^{N}\sum_{k=1}^{N}|b_{jk}|^{2}=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{B}}^{H}{\bm{B}}\right)=\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)
due to normal condition. Hence, we arrive at the following corollary of Theorem
2
.

Corollary 2.1
.

(Capacity of Normal Convergent Matrix Networks) Given the dynamical system
5
and that both the connection matrices
{\bm{U}}
and
{\bm{V}}
are normal as well as convergent, the memory capacity of the system is limited by the following inequality

\begin{split}{\bm{J}}_{tot}<\frac{1}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\end{split}

(26)

which is equivalent to stating that the memory capacity of dynamical system in Equation
5
with respect to instantaneous input Fisher information is

\begin{split}{\bm{J}}_{tot_{rel}}=\frac{{\bm{J}}_{tot}}{\mathcal{I}({\bm{W}})}<1\end{split}

(27)

where
\mathcal{I}({\bm{W}})
is the input Fisher information as in Lemma
2
.∎

The bound in Eq.
26
implies that the amount of information stored in the state of Eq.
5
about all the previous input signals is less than the amount of input information at the current instance. Eq.
27
further implies that the normal convergent matrix representation in recurrent neural networks cannot efficiently redistribute the total past information with respect to the information just observed. Thus, the memory capacity of such a network would be suboptimal and would not perform well on short/long term recall tasks and also will be likely to fail in generalizing over those respective tasks. A final issue to note about the assumption of convergence is that it is not required in the case of vector representation networks, as the magnitude of all eigenvalues has to be less than 1 due to asymptotic stability criterion
[
26
]
.

2.4.2
Capacity of General Non-Normal Networks

So far, we have seen the inability of normal convergent connectivity in matrix
RNNs in the storage of information about past signals.
However, we have only dealt under the constraint of normal connectivity matrices. It is not yet clear how the performance might change if we relax this constraint (whether
{\bm{J}}_{tot}
’s upper bound increases or decreases even further). Relaxing this constraint, however, is not straightforward, as can be seen from the difficulty in the direct analysis of Eqs.
12
and
15
. Under similar challenges, Ganguli et. al
[
26
]
defined a broader form of FMM, known as
space-time FMM
. Here, the temporal signal
{\bm{s}}_{k}
was assumed to be supported also by the spatial dimension introduced by the feedforward connectivity vector for each signal at each time. This formulation depends on the fact that the form of
{\bm{J}}_{i,j}
turns out to be simpler in the case of vector representations as seen in Eq.
14
, unlike Eq.
13
. Specifically, the vector feedforward connection
{\bm{v}}
in
14
acts on
{\bm{W}}^{iT}{\bm{C}}_{n}^{-1}{\bm{W}}^{j}
which can be seen as a matrix storing the information regarding all the elements of
{\bm{v}}
(which can be regarded as the spatial dimension) for each time step, which leads to the formulation of
{\bm{J}}_{(i,m),(j,n)}^{st}=\left[{\bm{W}}^{iT}{\bm{C}}_{n}^{-1}{\bm{W}}^{j}\right]_{(m,n)}
(keep in mind the different context of
{\bm{W}}
for vector dynamics). The introduction of
{\bm{J}}^{st}
makes the analysis of
{\bm{J}}\left(i\right)
for vector representation dynamics for non-normal connectivity much more accessible.

The formulation of an equivalent paradigm in matrix representation dynamics seems to be a non-trivial task; however, especially due to the fact that we can’t separate the feedforward connection matrix
{\bm{W}}
from the matrix products inside the
trace operator
in Eq.
13
. The presence of
{\bm{W}}
in between the products indicates the presence of complicated interaction terms between the feedforward connection and the recurrent connections. This interaction might be a result of using structured matrix representations, which we explain further.

The spatial dimension in matrix representations should correspond to the signal
{\bm{s}}_{i}=s\left(n-i\right)
reaching each neuron in the state matrix
{\bm{X}}\left(n\right)
. Note that the input signal is a scalar
{\bm{s}}_{k}
, thus for vector representations, the
k^{th}
neuron receives
{\bm{v}}_{k}s\left(n-i\right)
as the signal. Similarly, in matrix representations, the
(k,l)^{th}
neuron will receive
{\bm{W}}_{k,l}s\left(n-i\right)
, thus
{\bm{W}}
provides structure to input signal to reach the neuron. Without this structural support, the signal can clearly not reach the state neuron. Thus, it seems logical that the capacity of matrix representations would directly depend upon the matrix that stratifies the input signal to each neuron.

We can see this effect if we assume that each recurrent connectivity matrix
{\bm{U}}
and
{\bm{V}}
induces their respective spatio-temporal FMM
{\bm{J}}^{st}_{V}
and
{\bm{J}}^{st}_{U}
, which are similar in structure as in the vector representations as discussed in the beginning.
Hence
{\bm{J}}^{st}_{V_{(i,j)}}
and
{\bm{J}}^{st}_{U_{(i,j)}}
, store the Fisher information that
{\bm{X}}\left(n\right)
contains about the interference of the input signals which appears
i
and
j
time steps in the past along all their respective spatial dimensions for the respective connection matrices
{\bm{U}}
and
{\bm{V}}
, as defined below concretely

\begin{split}{\bm{J}}^{st}_{V_{(i,j)}}&:={\bm{V}}^{j}\mathbf{\Sigma}^{-1}{\bm{V}}^{iT}\\
{\bm{J}}^{st}_{U_{(i,j)}}&:={\bm{U}}^{i}\mathbf{\Psi}^{-1}{\bm{U}}^{jT}.\end{split}

(28)

Using Eq.
28
, we can reform Eq.
13
in a much simpler form which shows the effect of each of these matrices on the
{\bm{J}}_{i,j}
. We first write

\begin{split}{\bm{J}}_{i,j}&=\Tr\left({\bm{W}}{\bm{J}}^{st}_{V_{\left(i,j\right)}}{\bm{W}}^{T}{\bm{J}}^{st}_{U_{\left(i,j\right)}}\right)\end{split}

(29)

and thus, the
{\bm{J}}_{tot}
becomes

\begin{split}{\bm{J}}_{tot}&=\sum_{i=0}^{\infty}\Tr\left({\bm{W}}{\bm{J}}^{st}_{V_{\left(i,i\right)}}{\bm{W}}^{T}{\bm{J}}^{st}_{U_{\left(i,i\right)}}\right).\end{split}

(30)

Thus, the FMM
{\bm{J}}_{i,j}
depends upon the interaction between each of the spatio-temporal FMM along with the feedforward connection which connects the input signal to the state neurons. Now, since each spatio-temporal matrix is positive definite and
\varepsilon_{2}\sum_{i=0}^{\infty}\Tr{\bm{J}}^{st}_{V_{\left(i,i\right)}}=\varepsilon_{1}\sum_{i=0}^{\infty}\Tr{\bm{J}}^{st}_{U_{\left(i,i\right)}}=N
, we can retrieve a fundamental bound on the memory capacity
{\bm{J}}_{tot}
of Eq.
5
when there are no non-linearity, which we state as the following theorem.

Theorem 3
.

(Capacity of General Networks) Given the recurrent system in Eq.
5
with no non-linearity (
f(\cdot)=\text{id}(\cdot)
), the memory capacity of the system is fundamentally limited by the following inequality

\begin{split}{\bm{J}}_{tot}\leq\frac{N^{2}}{\varepsilon_{1}\varepsilon_{2}}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\end{split}

(31)

which in terms of instantaneous relative capacity is,

\begin{split}{\bm{J}}_{{tot}_{rel}}\leq N^{2}.\end{split}

(32)

Proof.

We have that,

\begin{split}{\bm{J}}_{tot}&=\sum_{i=0}^{\infty}\Tr\left({\bm{W}}{\bm{J}}_{V_{(i,i)}}^{st}{\bm{W}}^{T}{\bm{J}}^{st}_{U_{(i,i)}}\right)\end{split}

where
\varepsilon_{2}\sum_{i=0}^{\infty}\Tr\left({\bm{J}}_{V_{(i,i)}}^{st}\right)=\varepsilon_{1}\sum_{i=0}^{\infty}\Tr\left({\bm{J}}_{U_{(i,i)}}^{st}\right)=N
. Now to obtain the inequality in Eq.
31
, we proceed as follows,

\begin{split}{\bm{J}}_{tot}&=\sum_{i=0}^{\infty}\Tr\left({\bm{W}}{\bm{J}}_{V_{(i,i)}}^{st}\left({\bm{J}}_{U_{(i,i)}}^{st}{\bm{W}}\right)^{T}\right).\end{split}

Since the norm induced by Frobenius inner product
\langle{\bm{A}},{\bm{B}}\rangle_{F}=\Tr\left({\bm{A}}^{T}{\bm{B}}\right)
will obey Cauchy-Schwarz inequality, i.e.
\left|\langle{\bm{A}},{\bm{B}}\rangle_{F}\right|\leq\|{\bm{A}}\|_{F}\|{\bm{B}}\|_{F}
, we hence get,

\begin{split}{\bm{J}}_{tot}&\leq\sum_{i=0}^{\infty}\sqrt{\Tr\left({\bm{W}}{\bm{J}}_{V_{(i,i)}}^{st}{\bm{J}}_{V_{(i,i)}}^{st\;T}{\bm{W}}^{T}\right)\Tr\left({\bm{W}}^{T}{\bm{J}}_{U_{(i,i)}}^{st}{\bm{J}}_{U_{(i,i)}}^{st\;T}{\bm{W}}\right)}\\
&=\sum_{i=0}^{\infty}\sqrt{\Tr\left({\bm{W}}^{T}{\bm{W}}{\bm{J}}_{V_{(i,i)}}^{st}{\bm{J}}_{V_{(i,i)}}^{st\;T}\right)\Tr\left({\bm{W}}{\bm{W}}^{T}{\bm{J}}_{U_{(i,i)}}^{st}{\bm{J}}_{U_{(i,i)}}^{st\;T}\right)}\\
\end{split}

Now since
{\bm{W}}^{T}{\bm{W}}
,
{\bm{J}}_{V_{(i,i)}}^{st}{\bm{J}}_{V_{(i,i)}}^{st\;T}
and
{\bm{J}}_{U_{(i,i)}}^{st}{\bm{J}}_{U_{(i,i)}}^{st\;T}
are positive semi-definite and
\Tr\left({\bm{J}}_{V_{(i,i)}}^{st}\right)=\Tr\left({\bm{V}}^{i}{\bm{V}}^{iT}\mathbf{\Sigma}^{-1}\right)\geq 0
as
{\bm{V}}^{i}{\bm{V}}^{iT}
and
\mathbf{\Sigma}^{-1}
are positive semi-definite, hence we can get,

\begin{split}{\bm{J}}_{tot}&\leq\sum_{i=0}^{\infty}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\sqrt{\Tr\left({\bm{J}}_{V_{(i,i)}}^{st}{\bm{J}}_{V_{(i,i)}}^{st\;T}\right)\Tr\left({\bm{J}}_{U_{(i,i)}}^{st}{\bm{J}}_{U_{(i,i)}}^{st\;T}\right)}\\
&\leq\sum_{i=0}^{\infty}\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\sqrt{\Tr^{2}\left({\bm{J}}_{V_{(i,i)}}^{st}\right)\Tr^{2}\left({\bm{J}}_{U_{(i,i)}}^{st}\right)}\\
&=\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\sum_{i=0}^{\infty}\left|\Tr\left({\bm{J}}_{V_{(i,i)}}^{st}\right)\right|\left|\Tr\left({\bm{J}}_{U_{(i,i)}}^{st}\right)\right|\\
&\leq\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\left(\sum_{i=0}^{\infty}\left|\Tr\left({\bm{J}}_{V_{(i,i)}}^{st}\right)\right|\right)\left(\sum_{i=0}^{\infty}\left|\Tr\left({\bm{J}}_{U_{(i,i)}}^{st}\right)\right|\right)\\
&=\Tr\left({\bm{W}}^{T}{\bm{W}}\right)\frac{N^{2}}{\varepsilon_{1}\varepsilon_{2}}.\end{split}

This completes the proof.
∎

Therefore, the memory capacity of a matrix representation of linear recurrent networks is fundamentally bounded by the size of the state matrix. It’s interesting to note that besides the apparent flaw in capacity under normal connectivity constraints for matrix representation networks, the capacity in the general case at least seems to be in line with the trend first observed with vector representation recurrent networks, where the
{\bm{J}}_{tot_{rel}}\leq N

{\bm{W}}
. However, one can argue for the case of high

and
\|{\bm{V}}\|_{F}
which becomes apparent from Eq.

In our analysis of the memory capacity of matrix representation networks so far, we assumed that Eq.
5
works under linear dynamics; that is,
f({\bm{X}})={\bm{X}}
. However, in practice, some type of non-linearity is used for learning efficient and diverse representations. The same can be said for biological neurons as their activations are not unbounded, hence the finite dynamic range. We next show that adding a saturating non-linearity like

or
\tanh(x)
causes the capacity to also be bounded by a multiple of the same range.

2.5
Effects of finite dynamic range

So far, we’ve seen the asymptotic effects on the memory capacity of the linear dynamics matrix representation networks. However, it still remains to be answered the effects on the capacity of the system when the dynamics are restricted to some finite dynamic range as in the biological neurons through other saturating non-linearities commonly used in the machine learning community.

2.5.1
Memory Capacity is upper-bounded by the norm of state

To see whether such non-linearities increase or decrease the memory capacity, we first assume that the network architecture is such that neural activity of each neuron in
{\bm{X}}\left(n\right)
is limited between
-\sqrt{R}
and
\sqrt{R}
; hence, restricting
\Tr\left({\bm{X}}^{T}{\bm{X}}\right)<N^{2}R

Looking at the average of the state norm of Eq.
5
which is further shown in Eq.
2.5.1

\Tr\left({\bm{X}}^{T}{\bm{X}}\right)<N^{2}R
implies that each of its components are also bounded by

\begin{split}\mathbb{E}\left[\Tr\left({\bm{X}}^{T}{\bm{X}}\right)\right]&=\sum_{k=0}^{\infty}\|{\bm{U}}^{kT}{\bm{W}}{\bm{V}}^{k}\|_{F}^{2}+\varepsilon_{1}\varepsilon_{2}\sum_{k=0}^{\infty}\Tr\left({\bm{V}}^{kT}{\bm{V}}^{k}\right)\Tr\left({\bm{U}}^{kT}{\bm{U}}^{k}\right)\end{split}

which implies that
\sum_{k=0}^{\infty}\|{\bm{U}}^{kT}{\bm{W}}{\bm{V}}^{k}\|_{F}^{2}<N^{2}R

On the other hand, since
\mathbf{\Sigma}^{-1}
and
\mathbf{\Psi}^{-1}
are positive definite, we see that the capacity
16
of the matrix network is

\begin{split}{\bm{J}}_{tot}&=\Tr\left(\sum_{i=0}^{\infty}\mathbf{\Sigma}^{-1}{\bm{V}}^{iT}{\bm{W}}^{T}{\bm{U}}^{i}\mathbf{\Psi}^{-1}{\bm{U}}^{iT}{\bm{W}}{\bm{V}}^{i}\right)\\
&=\Tr\left(\mathbf{\Sigma}^{-1}\sum_{i=0}^{\infty}{\bm{V}}^{iT}{\bm{W}}^{T}{\bm{U}}^{i}\mathbf{\Psi}^{-1}{\bm{U}}^{iT}{\bm{W}}{\bm{V}}^{i}\right)\\
&\leq\Tr\left(\mathbf{\Sigma}^{-1}\right)\Tr\left(\mathbf{\Psi}^{-1}\right)\left(\sum_{i=0}^{\infty}\Tr\left({\bm{V}}^{iT}{\bm{W}}^{T}{\bm{U}}^{i}{\bm{U}}^{iT}{\bm{W}}{\bm{V}}^{i}\right)\right)\\
&=\Tr\left(\mathbf{\Sigma}^{-1}\right)\Tr\left(\mathbf{\Psi}^{-1}\right)\left(\sum_{i=0}^{\infty}\|{\bm{U}}^{iT}{\bm{W}}{\bm{V}}^{i}\|_{F}^{2}\right)\\
&\leq\Tr\left(\mathbf{\Sigma}^{-1}\right)\Tr\left(\mathbf{\Psi}^{-1}\right)\mathbb{E}\left[\Tr\left({\bm{X}}^{T}{\bm{X}}\right)\right]\\
&<\Tr\left(\mathbf{\Sigma}^{-1}\right)\Tr\left(\mathbf{\Psi}^{-1}\right)N^{2}R.\end{split}

(33)

Hence, when we restrict the neuronal dynamic range of activation between certain thresholds, the memory capacity of the network is also limited by that same threshold with appropriate constants. This implies that in the case of saturating non-linearities such as sigmoid or
\tanh
. The memory capacity
{\bm{J}}_{tot}
may decrease whereas, for non-saturating non-linearities such as ReLU and its derivatives, this bound doesn’t create a problem from a memory standpoint.

So far, we’ve seen an analysis of the memory capacity for matrix representation recurrent network as described by the linear dynamics of Eq.
5
. We first considered memory capacity under the constraint of normal connectivity matrices, in which we proved the limited capability of such a network. We did this under further convergence assumption by storing information about past signals which turns out to be worse than conventional vector representation of RNNs under the same constraints.

We then further discussed the general case and showed the information stored in the state relative to input information cannot exceed the number of neurons, which thus seems to generalize from the similar results obtained for vector representation recurrent neural network. The question that now naturally arises is whether there are ways in which
J_{tot}
can be increased. One obvious way of achieving that is through the addition of an external memory resource to the recurrent neural network which on an intuitive level does increase the memory capacity of the network. Even though there has been very in-depth work on the memory of the non-linear vector neural networks, there hasn’t been any that extends those ideas to architectures that have external memory available to exploit, let alone the higher-order representations that we deal with in this paper. We thus explore the idea of quantifying the memory capacity of an exceedingly simple memory network with matrix representation through the definitions introduced in previous sections and provide the absolute minimum increase in memory that one would expect from such a memory architecture.

3
The Effects of External State Memory on State Dynamics

We earlier saw the memory capacity shown in Eq.
18
of the dynamical system Eq.
5

3.1
Direct ways to increase the capacity

We start by first noting the FMM in Theorem
1

(a)
increase the mean
{\bm{M}}
or
(b)
decrease the covariances
\mathbf{\Sigma}
and
\mathbf{\Psi}

{\bm{M}}
, we can try adding more terms to it, which can be done easily if we note the state solution in Eq.
10
is obtained via solving the recurrence relation in Eq.
5
in the linear case. Hence, if we add any term in the state dynamics (Eq.
5
), then we would get the resultant in Eq.
10
. We note
that if we give the state at time step
n
of RNN with access to past states,
then the state solution would feature information from each of
those past states, thus increasing the terms in the state solution. This answers the question of what we should add to the RNN
state in Equation
5
to have a larger mean. Note that such a structure can be named under the well-explored memory networks
[
29

24

27

28

Note that such memory should have a queue-like behavior. We explore this idea in detail now and derive the corresponding capacity of such an architecture.

3.2
Addition of State Memory to State Dynamics

In this section, we modify Eq.
5
by adding a generic finite queue memory that stores the past state representations for the current state as an additional input. The motivation behind this is to access past representations for the current state in order to simplify the task of encoding each past input signal for that state. The main goal now is to find the best representation only for a small previous neighborhood of current input signal instead of all past signals, while encoding minimal to no information for those past signals as they are readily available through this type of memory. We further show that even with a bounded memory size of just one slot, the memory capacity becomes an infinite matrix series sum which is at the very least upper bounded by four times the capacity of the matrix representation networks without memory access at each time step as given in Eq.
12
. Hence, we mathematically prove the increase in capacity such a memory structure will have for matrix representation in RNNs.

The change in dynamics

Consider the following recurrent system

\begin{split}{\bm{X}}\left(n\right)&={\bm{U}}^{T}{\bm{X}}\left(n-1\right){\bm{V}}+{\bm{W}}s\left(n\right)+{\bm{Q}}_{\text{READ}}\left(n\right)+{\mathbf{Z}}\left(n\right)\end{split}

, which occurs mainly due to inclusion of complicated infinite sums over
m
, where each sum is itself a distorted version of
{\bm{J}}\left(k\right)
, as visible from
43
which do not lend itself to same analysis techniques derived in this paper so far and in Ganhuli et. al
[
26
]
; hence, more work might be needed in this direction.

However, we can still generalize Eq.
43
by using Woodbury identity again on all four terms inside
\Tr
operator instead of just
{\bm{J}}^{\prime}_{1}
which yields us the following

\begin{split}{\bm{J}}\left(k\right)^{\prime}=\Tr\Biggl(&\mathbf{\Sigma}^{-1}_{\text{MF}}\mathbf{\Sigma}^{-1}_{\text{STATE}}\left(\partial_{{\bm{s}}_{k}}{\bm{M}}_{\text{MEM}}^{T}\right)\mathbf{\Psi}^{-1}_{\text{MF}}\mathbf{\Psi}^{-1}_{\text{STATE}}\left(\partial_{{\bm{s}}_{k}}{\bm{M}}\right)\\
&+\mathbf{\Sigma}^{-1}_{\text{MF}}\mathbf{\Sigma}^{-1}_{\text{STATE}}\left(\partial_{{\bm{s}}_{k}}{\bm{M}}^{T}\right)\mathbf{\Psi}^{-1}_{\text{MF}}\mathbf{\Psi}^{-1}_{\text{STATE}}\left(\partial_{{\bm{s}}_{k}}{\bm{M}}_{\text{STATE}}\right)\Biggl)\end{split}

(46)

where,

\begin{split}\mathbf{\Sigma}^{-1}_{\text{MF}}&={\bm{I}}-\mathbf{\Sigma}^{-1}_{\text{STATE}}\left(\mathbf{\Sigma}^{-1}_{\text{MEM}}+\mathbf{\Sigma}^{-1}_{\text{STATE}}\right)^{-1}\\
\mathbf{\Psi}^{-1}_{\text{MF}}&={\bm{I}}-\mathbf{\Psi}^{-1}_{\text{STATE}}\left(\mathbf{\Psi}^{-1}_{\text{MEM}}+\mathbf{\Psi}^{-1}_{\text{STATE}}\right)^{-1}.\end{split}

(47)

This completes the proof.
∎

Here,
\mathbf{\Sigma}^{-1}_{\text{MF}}
can be understood as the fraction of precision provided by memory
{\bm{Q}}
via
\mathbf{\Sigma}^{-1}_{\text{MEM}}
, similarly for
\mathbf{\Psi}^{-1}_{\text{MF}}
. Note that
\mathbf{\Sigma}^{-1}_{\text{STATE}}
and
\mathbf{\Psi}^{-1}_{\text{STATE}}
are the same set of precision matrices as in the case when there was no memory
{\bm{Q}}
given by Theorem
1
. Due to this, one can say that addition of queue-like state memory
{\bm{Q}}
marginalizes the precision to
effective
precision matrices
\mathbf{\Sigma}^{-1}_{\text{MF}}\mathbf{\Sigma}^{-1}_{\text{STATE}}
and
\mathbf{\Psi}^{-1}_{\text{MF}}\mathbf{\Psi}^{-1}_{\text{STATE}}
based on the respective precision contributed due to inclusion of
{\bm{Q}}
, i.e.
\mathbf{\Sigma}^{-1}_{\text{MEM}}
and
\mathbf{\Psi}^{-1}_{\text{MEM}}
.

Given the point of view of the FMC
{\bm{J}}\left(k\right)^{\prime}
with respect to mean
{\bm{M}}
, the
{\bm{J}}\left(k\right)^{\prime}
is divided among the contribution from the mixture of the derivative of the complete mean
{\bm{M}}
and the contribution to mean via memory
{\bm{M}}_{\text{MEM}}
and from the derivative of
{\bm{M}}
again with mean contributed via state
{\bm{M}}_{\text{STATE}}
. The presence of derivatives of different parts of mean
{\bm{M}}
in each of the matrices inside the trace operator in Eq.
46
unlike Corollary
1.1
in which the derivative of the same mean was taken both times. This implies a stark difference in the underlying structure of
{\bm{J}}\left(k\right)^{\prime}
compared to
{\bm{J}}\left(k\right)
where the same derivative is taken in the only term present inside the trace operator.

We note that the
space-time
analogy introduced previously in Section
2.4.2
would not be feasible with Eq.
46

and hence combined with the above discussion on marginalization of covariance, in this context, deriving a general bound is not trivial. Due to our first assumption that the capacity would increase with more amount of slots
p
, we thus conclude that adding the queue-like state memory
{\bm{Q}}
increases the
memory
capacity of
matrix RNNs.

In summary, we introduced the queue-like state memory
{\bm{Q}}
to the state dynamics as defined by Eq.
34
. We then derived the FMC for such a memory augmented dynamics and showed its complex structure, showing that the worst-case upper bound of the capacity with just one slot of state memory is 4 times higher than that of the matrix networks without memory. Finally, we gave more insights into the structure of the FMC by deriving even a general form of FMC (Eq.
46
) and posing some insights about its basic structure.

4
Matrix Representation in Neural Memory of Recurrent Neural Networks

In the previous section, we revealed how the addition of state memory to a matrix RNNs will affect the memory capacity of the system. In particular, we derived the FMC
{\bm{J}}\left(i\right)^{\prime}
to evaluate the memory capacity
{\bm{J}}_{tot}^{\prime}
and argued that it is larger than the
{\bm{J}}_{tot}
as derived earlier for matrix representation networks without the memory structure
{\bm{Q}}_{n}
(Theorem
3
).

We need to note that a higher memory capacity doesn’t necessarily imply that a neural network architecture can efficiently transfer stored knowledge in its hidden representations to achieve the desired output. The memory structure
{\bm{Q}}_{n}
introduced earlier in Section
3.2

only serves the purpose of increasing the memory capacity, not the efficiency of representations in encoding past inputs clearly
[
16
]
.

It thus can be argued that the dynamical system in Eq.
34
is not suited for real-life tasks where one immediate problem often faced is the similarity of input sequences fed across a considerably long time span. One would expect the memory structure
{\bm{Q}}_{n}
to handle such cases and in fact, use the previously seen representation of the same input in the current time step to generate the new representation for the current time step. Hence, an obvious flaw with this structure is the lack of coherence of the hidden representations. Now for a similar input, we have two different representations, one when the first input arrived long ago in the past and the new
updated
representation which is a result of current similar input and that past state. However, this will only be the case if the past representation is not
\verb|deque()|
out of the memory
{\bm{Q}}_{n}
. That is, the time span between the similar signals is not more than the memory size
p
of
{\bm{Q}}_{n}
and even if the time span between the inputs is less than the memory size, the sequence
\left\{\alpha_{n}\right\}
should be such that all weight is given to the slot, where the past representation is currently stored which can only be the case if
\left\{\alpha_{n}\right\}
is learned to look at the correct
address
in the memory
{\bm{Q}}_{n}
. It can also be seen that this problem is only exaggerated if there are multiple similar inputs in the input sequence whose periodicity is greater than the memory size
p
of
{\bm{Q}}_{n}
which can be the case in recall and copy tasks.

There can be multiple ways to solve the above problem. The memory can act as a placeholder for storing similar or correlated input representation in one slot only, thus all the information about similar inputs is available in one place and can be decoded accordingly, perhaps like an encoder-decoder structure
[
42
]
. Thus, instead of storing the current state in its entirety, one can instead use it to determine the closest representation already available in the memory and the updates it may need to fit the representation of a similar group of inputs. We can use weights as a unique address of each slot for finding the location of the closest representation in memory. Hence, the weights should somehow be able to look at each slot and determine which one is closest to the current representation.

We note that this problem of finding techniques for efficient storage and retrieval of memory elements is not new in the machine learning research community and there have been multiple proposals for achieving efficient storage and retrieval for different domains
[
28
,
43
,
44
]
. One of the simplest of these proposals is the Neural Turing Machine (NTM) and the
memory addressing mechanism it proposes. We thus propose to use the same addressing mechanisms for the memory which now stores matrix representations
[
20
]
as opposed to vector representations as originally proposed in NTM. This leads to our proposed Matrix Neural Turing Machine (MNTM) which takes in and stores matrix-sized sequences into a bounded memory. We now formally introduce MNTM and later argue that even though the modifications are in the overall memory structure as compared to the simple
{\bm{Q}}_{n}
introduced earlier for theoretic evaluations of the effect of memory, the capacity doesn’t decrease in comparison while making matrix representations and storage feasible.

Storing the feature vector in a differentiable memory can be traced back to Das et. al

Consider a sequence of input matrices

The addressing by content (Step 1. in Figure

mechanism to the content addressing mechanism in the case when there is no clear representation in the memory closest to the key. 7
Discussion and Future Work

We studied the memory capacity of a new class of RNNs introduced by Gao et. al
[
20
]
for incorporating matrix representations using a bilinear map. We discussed various existing definitions of memory capacity and how most of the definitions prove to be not easily generalizable to matrix representations. We hence use a probabilistic model of the memory capacity using Fisher information as introduced by Ganguli et. al
[
26
]
. We investigated how the memory capacity for matrix representation networks is limited under various constraints, and in general, without any constraints. In the case of memory capacity without any constraints, we found that the upper bound on memory capacity is
N^{2}
for
N\times N
state matrix. This seems to generalize the similar upper bound for vector representation RNNs (
N
for state vector of length
N
). Moreover, we demonstrated that the inclusion of saturating non-linearities over the state transition may further bind the total memory capacity even tighter.

We note that the proposed method is based on a Gaussian assumption. The main equation (Eq. 5) is based solely on the assumption that the noise channel is a Gaussian matrix with zero mean matrix and covariance matrices (for rows and columns) which are diagonal with all eigenvalues equal (introduction of Sec. 3). The main reason of taking Gaussian distribution is due to the literature (Ganguli et. al.
[
26
]
) which uses the Gaussian assumption on the noise. Corollary 10 shows that the relative memory capacity of Eq. 5 is lower than 1 which is based on the same assumptions as that of Ganguli et. al
[
26
]
which used the vector representation rather than matrix representation. The main theorem from which our analysis of Section 3 begins would not be possible without the Gaussian assumption. The FMM of Eq. 5, as calculated in Theorem 2, would not have been possible without the Gaussian distribution. Even in that case, we had to compute the KL-divergence of a Gaussian random matrix distribution (Lemma 3) and as the proof shows, it is not at all clear how we can do the same for any other distribution.

In Figures 5 and 7, we find that the values of MatNTM fluctuate more largely than those of Matrix RNNs. Although we don’t have a definite answer to explain the main reason behind the difference, some of the reasons could be as follows. It was our general observation that we had to take an unusually small learning rate during backpropagation for MatNTM in order to avoid not a number (NaN). We had to fine-tune our settings too much, for we saw that under certain random seeds, we were not able to converge to a minimum. Even then, as is visible in Figure 5 and 7, the loss fluctuates a lot. This indicates that the loss landscape is quite chaotic for matrix representations with memory and is very sensitive to starting conditions. This is to be expected since Eq. 5 introduces a quadratic form in the recurrent system (as compared to vector representation networks) which is expected to make the loss landscape quite a lot more sensitive to fine differences in initial conditions. Memory networks in general have a rather chaotic loss curve due to the increase in complexity of the model that comes from having a differentiable memory which is visible in the literature (Graves et. al
[
27
]
).

The theoretical study and subsequent simulations hence reveal the fundamental bounds on memory capacity as revealed by the proposed definition and the striking increase in memory capacity induced by external memory, which is in line with basic intuition, but quantitatively has been a difficult task to ascertain. Moreover, we used a notion of memory capacity based only on Fisher Information, whereas much of the recent work is focused on functional & probabilistic definitions
[
32
]
. Counter-acting the difficulty of extending such notions to the domain of matrix representations would be the obvious next step.

One of the recent developments in the class of neural network architectures has been memory-augmented neural networks. However, quantifying the increase in actual memory capacity induced by such an external memory hasn’t been discussed yet. Given this motivation, we derived the memory trace of a linear matrix recurrent network with queue-like state memory, which provides the current state with the information of not just the state at
t-1
timestep, but states at
t-p
timesteps for a fixed
p\geq 1
. We note that this is very similar to the work of Soltani and Jiang
[
50
]
dubbed as Higher Order RNNs, which also provide the current state with a fixed number of past states, though in vector-based representation.

In terms of mathematical limitations, we note that the focus of our study was a linearized version of Eq. 5 which is not suited to understand the general behavior of such networks under non-linearities. The notion of memory capacity used in our study is not explicit, and in literature, there are various other notions of memory capacity that include analytic definitions as well, which in some sense is more explicit (see Section 2). We chose to work with a probabilistic definition, as we were able to develop the tools required for the analysis of matrix representations under such a definition in a rather straightforward manner. We along with others who studied matrix neural networks
[
51
,
22
]
argue that it prevents the loss of spatial coherence introduced by vectorizing two-dimensional data. Unfortunately, as of now, we don’t have any way of proving/disproving this mathematically. The major experimental limitation we faced was the extreme sensitivity of MatNTM to starting conditions and hyperparameters. This greatly inhibits our potential to carry out a diverse set of experiments on MatNTM, as is done by others in the field of memory networks. We note that memory networks such as NTMs already are quite difficult to train, and the addition of more complicated representations makes the training process much harder.

There is a high increase in the complexity of our model by the introduction of matrix representation when compared to conventional vector representation. In particular, for Eq. 5, we see that one can view that matrix recurrent system as a stacked version of feedforward neural networks, one for rows of
X
and the other for columns of
X
. Let us explain. The main part of the equation that affects the state is
X(n)=U^{TX(n-1)V}
. One can view

which acts on each column of
X(n-1)

U^{TX(n-1)}
,
V
is simply as another feed-forward network with weight matrix
V^{T}
which acts on the rows of the resultant matrix
U^{TX(n-1)}
. It is in this manner that matrix networks can be thought of as classical feed-forward networks stacked both row-wise and column-wise. It clearly appears that even a simple matrix network has more complexity than its vector-based simple neural network counterpart. Adding to this external memory, one can expect that the complexity of the model increases substantially. Another way of looking at this could be as follows. In Table 1, we see that both Matrix RNNs and MatNTMs do not require too many parameters (compare this to vector counterparts, where NTM with feedforward controller requires 17162 parameters to learn basic copy task

. This indicates that, in particular, MatNTM learns the same task in a much smaller number of parameters than its vector counterpart (NTM). This is only possible when the complexity of the model itself is such that it allows the model training even under such constraints posed by a low number of parameters. Hence, one can conclude that the complexity of any model which is learning a task with fewer parameters than some other one is bound to be more complicated. But it is important to keep in mind that this is not for free as we suffer greatly while finding the right hyperparameters to train a complex model such as MatNTM.

Proof of Lemma
1

Consider two normally distributed random matrices
{\mathbf{X}}_{1}\sim\mathcal{MN}_{n\times p}\left({\bm{M}}_{1},{\bm{A}}_{1},{\bm{B}}_{1}\right)
and
{\mathbf{X}}_{2}\sim\mathcal{MN}_{n\times p}\left({\bm{M}}_{2},{\bm{A}}_{2},{\bm{B}}_{2}\right)
. We have that

\begin{split}&p\left({\mathbf{X}}_{i}\right)=\\
&(2\pi)^{-\frac{1}{2}np}\left|{\bm{A}}_{i}\right|^{-\frac{1}{2}p}\left|{\bm{B}}_{i}\right|^{-\frac{1}{2}n}\exp\left[-\frac{1}{2}\Tr\left({\bm{B}}_{i}^{-1}\left({\bm{X}}-{\bm{M}}_{i}\right)^{T}{\bm{A}}_{i}^{-1}\left({\bm{X}}-{\bm{M}}_{i}\right)\right)\right]\end{split}

for both
i\in\left\{1,2\right\}
.

The KL-divergence between two distributions
p_{1}
and
p_{2}
is given by (note
\log
here is the natural logarithm),

\begin{split}D_{\mathrm{KL}}\left(p_{1}\|p_{2}\right)=\mathbb{E}_{p_{1}}\left[\log\frac{p_{1}}{p_{2}}\right].\end{split}

Hence, the KL-divergence between
p\left({\mathbf{X}}_{1}\right)
and
p\left({\mathbf{X}}_{2}\right)
can be calculated as,

\begin{split}D_{\mathrm{KL}}\left(p\left({\mathbf{X}}_{1}\right)\|p\left({\mathbf{X}}_{2}\right)\right)&=\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{1}\right)-\log p\left({\mathbf{X}}_{2}\right)\right]\\
&=\underbrace{\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{1}\right)\right]}_{\text{PART 1}}-\underbrace{\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{2}\right)\right]}_{\text{PART 2}}.\end{split}

We first calculate PART 2 as follows,

\begin{split}&\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{2}\right)\right]\\
&=\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\Biggl[-\underbrace{\log\left(\left(2\pi\right)^{\frac{1}{2}np}\left|{\bm{A}}_{2}\right|^{\frac{1}{2}p}\left|{\bm{B}}_{2}\right|^{\frac{1}{2}n}\right)}_{\text{constant : }C_{2}}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;-\frac{1}{2}\Tr\left({\bm{B}}_{2}^{-1}\left({\bm{X}}-{\bm{M}}_{2}\right)^{T}{\bm{A}}_{2}^{-1}\left({\bm{X}}-{\bm{M}}_{2}\right)\right)\Biggl]\\
&=-C_{2}-\frac{1}{2}\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\Tr\left(\left({\bm{X}}-{\bm{M}}_{2}\right)^{T}{\bm{A}}_{2}^{-1}\left({\bm{X}}-{\bm{M}}_{2}\right){\bm{B}}_{2}^{-1}\right)\right]\\
&=-C_{2}-\frac{1}{2}\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}\left(x_{ti}-m_{2;ti}\right)\left(x_{kj}-m_{2;kj}\right)u_{2;tk}^{-1}v_{2;ji}^{-1}\right]\\
&=-C_{2}-\frac{1}{2}\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\Biggl[\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{2;tk}v^{-1}_{2;ji}\Biggl(x_{ti}x_{kj}-m_{2;ti}x_{kj}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-m_{2;kj}x_{ti}+m_{2;ti}m_{2;kj}\Biggl)\Biggl]\end{split}

Now, using the fact that
\mathbb{E}\left[x_{i_{1}j_{1}}x_{i_{2}j_{2}}\right]=a_{i_{1}i_{2}}b_{j_{1}j_{2}}+m_{i_{1}j_{1}}m_{i_{2}j_{2}}
and
\mathbb{E}\left[x_{i_{1}j_{1}}\right]=m_{i_{1}j_{1}}

(Theorem
2
.3.3,
[
34
]
)
after taking expectation inside the sum, we get:

\begin{split}&\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{2}\right)\right]\\
&=-C_{2}-\frac{1}{2}\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{2;tk}v^{-1}_{2;ji}a_{1;tk}b_{1;ij}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+m_{1;ti}m_{1;kj}u^{-1}_{2;tk}v^{-1}_{2;ji}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-u^{-1}_{2;tk}v^{-1}_{2;ji}m_{2;ti}m_{1;kj}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-u^{-1}_{2;tk}v^{-1}_{2;ji}m_{2;kj}m_{1;ti}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+u^{-1}_{2;tk}v^{-1}_{2;ji}m_{2;ti}m_{2;kj}\\
&=-C_{2}-\frac{1}{2}\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{2;tk}v^{-1}_{2;ji}a_{1;tk}b_{1;ij}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+v^{-1}_{2;ji}m_{1;kj}u^{-1}_{2;tk}m_{1;ti}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-v^{-1}_{2;ji}m_{1;kj}u^{-1}_{2;tk}m_{2;ti}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-v^{-1}_{2;ji}m_{2;kj}u^{-1}_{2;tk}m_{1;ti}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+v^{-1}_{2;ji}m_{2;kj}u^{-1}_{2;tk}m_{2;ti}\\
&=-C_{2}-\frac{1}{2}\Bigl(\Tr({\bm{B}}_{2}^{-1}{\bm{M}}_{1}^{T}{\bm{A}}_{2}^{-1}{\bm{M}}_{1}-{\bm{B}}_{2}^{-1}{\bm{M}}_{1}^{T}{\bm{A}}_{2}^{-1}{\bm{M}}_{2}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-{\bm{B}}_{2}^{-1}{\bm{M}}^{T}_{2}{\bm{A}}_{2}^{-1}{\bm{M}}_{1}+{\bm{B}}_{2}^{-1}{\bm{M}}_{2}^{T}{\bm{A}}_{2}^{-1}{\bm{M}}_{2})\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+\Tr\left({\bm{A}}^{-1}_{2}{\bm{A}}_{1}\right)\Tr\left({\bm{B}}_{2}^{-1}{\bm{B}}_{1}\right)\Bigl).\end{split}

Note that we interchanged the order of summation of traces in the last line only for the purpose of better representation. After some more rearrangement of terms inside the first trace, we get the following solution of PART 2,

\begin{split}&\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{2}\right)\right]\\
&=-C_{2}-\frac{1}{2}\Tr\left({\bm{A}}^{-1}_{2}{\bm{A}}_{1}\right)\Tr\left({\bm{B}}_{2}^{-1}{\bm{B}}_{1}\right)\\
&\;\;\;-\frac{1}{2}\Tr\left({\bm{B}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)^{T}{\bm{A}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)\right)\end{split}

Calculating PART 1 in a similar path yields us the following,

\begin{split}&\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{1}\right)\right]\\
&=\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\Biggl[-\underbrace{\log\left(\left(2\pi\right)^{\frac{1}{2}np}\left|{\bm{A}}_{1}\right|^{\frac{1}{2}p}\left|{\bm{B}}_{1}\right|^{\frac{1}{2}n}\right)}_{\text{constant : }C_{1}}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;-\frac{1}{2}\Tr\left({\bm{B}}_{1}^{-1}\left({\bm{X}}-{\bm{M}}_{1}\right)^{T}{\bm{A}}_{1}^{-1}\left({\bm{X}}-{\bm{M}}_{1}\right)\right)\Biggl]\\
&=-C_{1}-\frac{1}{2}\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\Biggl[\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{1;tk}v^{-1}_{1;ji}\Biggl(x_{ti}x_{kj}-m_{1;ti}x_{kj}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-m_{1;kj}x_{ti}+m_{1;ti}m_{1;kj}\Biggl)\Biggl].\end{split}

Using the same two theorems used in calculations for PART 2, we get the following solution of PART 1,

\begin{split}&\mathbb{E}_{p\left({\mathbf{X}}_{1}\right)}\left[\log p\left({\mathbf{X}}_{1}\right)\right]\\
&=-C_{1}-\frac{1}{2}\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{1;tk}v^{-1}_{1;ji}\Bigl(a_{1;tk}b_{1;ij}+m_{1;ti}m_{1;kj}-m_{1;ti}m_{1;kj}\\
&\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-m_{1;kj}m_{1;ti}+m_{1;ti}m_{1;kj}\Bigl)\\
&=-C_{1}-\frac{1}{2}\sum_{i=1}^{p}\sum_{j=1}^{p}\sum_{k=1}^{n}\sum_{t=1}^{n}u^{-1}_{1;tk}v^{-1}_{1;ji}a_{1;tk}b_{1;ij}\\
&=-C_{1}-\frac{1}{2}\Tr\left({\bm{A}}_{1}^{-1}{\bm{A}}_{1}\right)\Tr\left({\bm{B}}_{1}^{-1}{\bm{B}}_{1}\right)\\
&=-C_{1}-\frac{1}{2}np\end{split}

Thus, combining the solutions of both PART 1 and PART 2 yields us,

\begin{split}&D_{\mathrm{KL}}\left(p\left({\mathbf{X}}_{1}\right)\|p\left({\mathbf{X}}_{2}\right)\right)\\
&=-C_{1}-\frac{1}{2}np+C_{2}+\frac{1}{2}\Tr\left({\bm{A}}^{-1}_{2}{\bm{A}}_{1}\right)\Tr\left({\bm{B}}_{2}^{-1}{\bm{B}}_{1}\right)\\
&\;\;\;\;+\frac{1}{2}\Tr\left({\bm{B}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)^{T}{\bm{A}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)\right)\end{split}

Substituting the values of
C_{1}
and
C_{2}
back in their respective places, we finally get the required form,

\begin{split}&D_{\mathrm{KL}}\left(p\left({\mathbf{X}}_{1}\right)\|p\left({\mathbf{X}}_{2}\right)\right)\\
&=\log\frac{\left|{\bm{A}}_{2}\right|^{\frac{1}{2}p}\left|{\bm{B}}_{2}\right|^{\frac{1}{2}n}}{\left|{\bm{A}}_{1}\right|^{\frac{1}{2}p}\left|{\bm{B}}_{1}\right|^{\frac{1}{2}n}}-\frac{1}{2}np+\frac{1}{2}\Tr\left({\bm{A}}^{-1}_{2}{\bm{A}}_{1}\right)\Tr\left({\bm{B}}_{2}^{-1}{\bm{B}}_{1}\right)\\
&\;\;\;\;+\frac{1}{2}\Tr\left({\bm{B}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)^{T}{\bm{A}}_{2}^{-1}\left({\bm{M}}_{2}-{\bm{M}}_{1}\right)\right)\end{split}

This proves Lemma
1
.∎
