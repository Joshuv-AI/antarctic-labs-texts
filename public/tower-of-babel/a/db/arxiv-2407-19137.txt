Completely greedy coin sets
Andrew J. Young

Abstract
We show that the binary coin set minimizes the number of coins needed to guarantee the ability to make change in any one transaction and its asymptotic uniform average cost is no worse than that of any completely greedy coin set.



1
Introduction

For our purposes, a
coin set
is a set of positive integers containing
1
, and a
sub-coin set
is a subset of a coin set that is also a coin set, i.e. it contains
1
.
When enumerated, a coin set is always written in increasing order and its
k
th element is a reference to this order.
Let
\mathcal{C}
be a coin set.
An element
c\in\mathcal{C}
is a
coin
.
One is said to
make change
at a positive integer
n
by choosing a
representation
in
\mathcal{C}
, collection of coins
c\in\mathcal{C}
that sum to
n
, i.e.
n=\sum_{c\in\mathcal{C}}\alpha_{c}c
for some
\alpha_{c}\in\mathbb{N}
.
A representation is
minimal
if it uses the least possible number of coins,
\sum_{c\in\mathcal{C}}\alpha_{c}
is minimized.
We say a coin set is
greedy
if successively choosing the greatest lower bounding coin provides a minimal representation for every positive integer
n
.
A coin set
\mathcal{C}
is said to be
totally greedy

[
1
]
if the first
k
elements of
\mathcal{C}
are greedy for all
1\leq k\leq\lvert\mathcal{C}\rvert
.
A
transaction
is a positive integer of interest.

One problem is that of
optimal denomination
, the coin set minimizing the average coins per transaction.
Under the greedy and totally greedy settings the following pathological issue arises.
Suppose one is interested in making change for transactions in
\{1,2,\ldots,N\}
, for some
N
, then without any further restrictions the optimal denomination is
\{1,2,\ldots,N\}
.
To combat this pathology we introduce completely greedy coin sets.

A coin set is said to be
completely greedy
if all of its sub-coin sets are greedy.
With this restriction the maximum number of coins in a coin set is at most logarithmic in
N
, see Lemma
5
and its succeeding remarks.
Completely greedy coin sets are characterized by specific subsets of cardinality
3
(Proposition
4
), and greediness of subsets of cardinality
3
can be quickly verified (Corollary
3
).
Moreover, the binary coin set, i.e.
\{1,2,\ldots,2^{k},\ldots\}
, is completely greedy, completely unique (Proposition
6
), minimizes coin purse size (Proposition
1
), and is asymptotically optimal in some sense (Theorem
7
).

While complete greediness is a rather strong condition, we believe it is justified by its resilience to the loss of elements of a coin set different from
1
.
More specifically, suppose a store makes change using some coin set
\mathcal{C}
.
For practical purposes, as making change is in general
NP
-hard
[
2
]
, a greedy coin set is desirable.
However, without complete greediness, this property may be lost if the store were to run out of some non-unit denominations.

2
Minimal coin purse

We begin by studying the minimum number of coins needed to guarantee the ability to make change in any one transaction.
To that end, given a coin set
\mathcal{C}
, an
optimal coin purse for
\mathcal{C}
is the smallest list of elements of
\mathcal{C}
such that any one transaction can be represented using elements of that list.
Further minimizing over all possible coin sets provides a
minimal coin purse
.
Let
f_{N}(\mathcal{C})
denote the size of an optimal coin purse for a coin set
\mathcal{C}
used in making change for transactions in
\{1,2,\ldots,N\}
, and

f_{N}^{\ast}:=\min_{\mathcal{C}}f_{N}(\mathcal{C})

the size of a corresponding minimal coin purse.

Proposition 1
.

f_{N}^{\ast}=\lceil\log_{2}(N+1)\rceil
.

Proof.

Let
\mathcal{C}
be a coin set.
For a list
\ell=(\ell_{k})_{1\leq k\leq n}
with
\ell_{k}\in\mathcal{C}
, let

\mathcal{S}(\ell)=\left\{\sum_{k=1}^{n}\beta_{k}\ell_{k}:\beta_{k}\in\{0,1\},\,\exists\beta_{k}\neq 0\right\}.

Then
\lvert\mathcal{S}(\ell)\rvert\leq 2^{n}-1
.
Moreover,
f_{N}^{\ast}
is the length of a minimal list
\ell
such that
\mathcal{S}(\ell)\supset\{1,\ldots,N\}
.
Thus
f_{N}^{\ast}\geq\lceil\log_{2}(N+1)\rceil
and the binary coin set
\mathcal{C}_{0}=\{1,2,\ldots,2^{\lceil\log_{2}(N+1)\rceil-1}\}
achieves this bound.
∎

For
N=99
this is
f_{99}^{\ast}=7
achieved by
\{1,2,4,8,16,32,64\}
using
3.19
coins on average.
The optimal, unrestricted, coin set of cardinality
7
uses
2.68
coins on average
[
2
]
.

3
Complete greediness

Let
\mathcal{C}
be a coin set.
In addition to greediness we shall consider uniqueness.

\mathcal{C}
is said to be
unique
if every positive integer has only one minimal representation, e.g.,
\{1,2,3\}
is not unique
4=2+2=3+1
, for
\lvert\mathcal{C}\rvert\leq 3
see
[

Total and complete uniqueness of coin sets are defined in the same manor as for greediness.

\text{opt}(\cdot\,;\,\mathcal{C})
and
\text{grd}(\cdot\,;\,\mathcal{C})
denote the
optimal and greedy cost functions
, i.e. number of elements in an optimal and the greedy representations under

A few remarks about greediness of coin sets.
Greediness does not imply total greediness

]
,
\{1,2,4,5,8\}
is greedy but
\{1,2,4,5\}
is not, does not imply complete greediness,
\{1,3,5,7\}
is totally greedy but
\{1,5,7\}
is not greedy.
All cardinality

\mathcal{C}=\{c_{1},\ldots,c_{n}\}
is not greedy the least violator is in

Theorem 2
.

[
5
,
1
]

Let
\mathcal{C}=\{c_{1},\ldots,c_{n}\}
be a greedy coin set,
c_{n+1}>c_{n}
and
m=\lceil\frac{c_{n+1}}{c_{n}}\rceil
.
Then
\mathcal{C}^{\prime}=\mathcal{C}\cup\{c_{n+1}\}
is greedy if and only if
\mathrm{opt}(mc_{n}\,;\,\mathcal{C}^{\prime})=\mathrm{grd}(mc_{n}\,;\,\mathcal{C}^{\prime})
if and only if
\mathrm{grd}(mc_{n}\,;\,\mathcal{C}^{\prime})\leq m
.

Corollary 3
.

[
4
,
1
]

A coin set
\mathcal{C}=\{1,a,b\}
is greedy if and only if
b\geq\lceil\frac{b}{a}\rceil(a-1)+1
.

Proposition 4
.

Let
\mathcal{C}=\{c_{1},\ldots,c_{n}\}
be a coin set.
The following are equivalent.

(i)

\mathcal{C}
is completely greedy;

(ii)

All sub-coin sets of cardinality
3
are greedy;

(iii)

For all
k\geq 3
,
\{c_{1},c_{k-1},c_{k}\}
is greedy.

Proof.

If
\lvert\mathcal{C}\rvert=1
or
2
, then
\mathcal{C}
is completely greedy and
(ii)
,
(iii)
are vacuously true.
Suppose
\lvert\mathcal{C}\rvert\geq 3
.
We begin with a technical result.
For
a,b\geq 0
,
\lceil ab\rceil\leq\lceil a\rceil\lceil b\rceil
.

(iii)\Longrightarrow(ii)

Let
\{1,c_{i},c_{j}\}
be a sub-coin set.
Then by assumption, for all
i<k\leq j
,
\{1,c_{k-1},c_{k}\}
is greedy and by Corollary
3

c_{k}\geq\lceil\frac{c_{k}}{c_{k-1}}\rceil(c_{k-1}-1)+1
.
Thus

c_{j}\geq\left\lceil\frac{c_{j}}{c_{j-1}}\right\rceil(c_{j-1}-1)+1\geq\left(\prod_{k=i+1}^{j}\left\lceil\frac{c_{k}}{c_{k-1}}\right\rceil\right)(c_{i}-1)+1\geq\left\lceil\frac{c_{j}}{c_{i}}\right\rceil(c_{i}-1)+1,

where the last inequality is the beginning result.
Hence
\{1,c_{i},c_{j}\}
is greedy by Corollary
3
.

(ii)\Longrightarrow(i)

Let
\mathcal{C}_{k}=\{c_{1},\ldots,c_{k}\}
.

\mathcal{C}_{1}
is completely greedy.
Suppose
\mathcal{C}_{k-1}
is.
Let
\mathcal{S}
be a sub-coin set of
\mathcal{C}_{k}
containing
c_{k}
, otherwise
\mathcal{S}
is greedy by the inductive statement.
Thus
\mathcal{S}\backslash\{c_{k}\}
is greedy.
Let
c^{\ast}=\max\{c:c\in\mathcal{S}\backslash\{c_{k}\}\}
and
m=\lceil\frac{c_{k}}{c^{\ast}}\rceil
.
Then
\text{grd}(mc^{\ast}\,;\,\mathcal{S})\leq\text{grd}(mc^{\ast}\,;\{1,c_{k}\})=1+mc^{\ast}-c_{k}\leq m
by greediness of
\{1,c^{\ast},c_{k}\}
and Corollary
3
.
Hence
\mathcal{S}
is greedy by Theorem
2
.
∎

Lemma 5
.

Let
\mathcal{C}=\{c_{1},\ldots,c_{n}\}
be a coin set.
If
\mathcal{C}
is completely greedy and totally unique, then, for all
1\leq k\leq n
and
0\leq i\leq k-1
,
c_{k}\geq 2^{i}c_{k-i}
.

Proof.

Obvious for
c_{1}=1
and
c_{2}\geq 2
.
For all
k\geq 3
, by complete greediness,
\{1,c_{k-1},c_{k}\}
is greedy.
Thus
c_{k}\geq 2c_{k-1}-1
by Corollary
3
, but
\{1,\ldots,c_{k-1},2c_{k-1}-1\}
is not unique at
2c_{k-1}
.
Hence
c_{k}\geq 2c_{k-1}
.
The rest follows by induction.
∎

For a coin set
\mathcal{C}=\{c_{1},\ldots,c_{m}\}
, let

n(N):=\max\{n:c_{n}\leq N\}.

If
\mathcal{C}
is completely greedy and totally unique then
c_{n}\geq 2^{n-1}
and
n(N)\leq\lceil\log_{2}(N+1)\rceil
.
If the uniqueness is dropped
c_{n}\geq 2^{n-2}+1
, for
n\geq 2
, and
n(N)\leq\lfloor\log_{2}(N-1)\rfloor+2
, for
N\geq 2
.

Proposition 6
.

Let
\mathcal{C}=\{c_{1},\ldots,c_{n}\}
be a coin set.
If
c_{k}|c_{k+1}
, for all
1\leq k\leq n-1
, then
\mathcal{C}
is completely greedy and completely unique.

Proof.

By Proposition
4
and Corollary
3
,
\mathcal{C}
is completely greedy.
It suffices to show that
\mathcal{C}
is unique.
Suppose not.
Let
N
be the least violator and
c_{a}
its greatest lower bounding coin.
Then
N=\sum_{k=1}^{b}\alpha_{k}c_{k}
for some
b<a
, otherwise
N-c_{a}
would be a lesser violator.
As the representation is minimal and
c_{k}\lvert c_{k+1}
, for all
1\leq k\leq b
,
\alpha_{k}c_{k}<c_{k+1}
implies
(\alpha_{k}+1)c_{k}\leq c_{k+1}
and
\sum_{i=1}^{k}\alpha_{i}c_{i}<c_{k+1}
.
Hence
\sum_{k=1}^{b}\alpha_{k}c_{k}<c_{b+1}\leq c_{a}\leq N
.
∎

The binary coin set is the only completely greedy totally unique coin set using one coin of each denomination to make change.
Let
\mathcal{C}=\{c_{1},\ldots,c_{n}\}
be a coin set.
Then, for

f_{N}(\mathcal{C})\geq\left\lfloor\frac{N}{c_{n}}\right\rfloor+\sum_{k=1}^{n-1}\left\lfloor\frac{c_{k+1}-1}{c_{k}}\right\rfloor.

(1)

Make change at

or
\lfloor\frac{c_{k+1}-1}{c_{k}}\rfloor c_{k}
.
If
\mathcal{C}
is greedy, then this is tight.
Thus for a greedy coin set
\lfloor\frac{N}{c_{n}}\rfloor

are needed and
\lfloor\frac{c_{k+1}-1}{c_{k}}\rfloor
of
c_{k}
.
If
\mathcal{C}
is completely greedy and totally unique
c_{k+1}\geq 2c_{k}
by Lemma

and for any

must be used more than once.

4
Asymptotics

Let

\text{cost}(N\,;\,\mathcal{C}):=\sum_{k=1}^{N}\text{opt}(k\,;\,\mathcal{C})=\sum_{k=1}^{N}\text{grd}(k\,;\,\mathcal{C}),

where the last equality holds if
\mathcal{C}
is greedy, and
\text{cost}(0\,;\,\mathcal{C}):=0
.
A coin set is said to be infinite if
n(N)\rightarrow\infty
.
An infinite coin set is said to be (completely) greedy/unique if the first
n
terms are (completely) greedy/unique for any finite
n
.
Let
\mathcal{B}:=\{1,2,\ldots,2^{n},\ldots\}
denote the infinite binary coin set.
Then
[
6
]

\text{cost}(N\,;\,\mathcal{B})=\frac{1}{2}N\log_{2}N+NF\left(\log_{2}N\right),

where
F
is a continuous nonpositive nowhere differentiable function of period
1
.
Thus

\lim_{N\rightarrow\infty}\frac{\text{cost}(N\,;\,\mathcal{B})}{n(N)N}=\frac{1}{2},

where
n(N)=\lceil\log_{2}(N+1)\rceil
.

Theorem 7
.

Let
\mathcal{C}
be an infinite completely greedy coin set.
Then

\limsup_{N\rightarrow\infty}\frac{\mathrm{cost}(N\,;\,\mathcal{C})}{\left(\lfloor\log_{2}(N-1)\rfloor+2\right)N}\geq\frac{1}{2}.

Proof.

Dropping to a subsequence

\limsup_{N\rightarrow\infty}\frac{\mathrm{cost}(N\,;\,\mathcal{C})}{\left(\lfloor\log_{2}(N-1)\rfloor+2\right)N}\geq\limsup_{n\rightarrow\infty}\frac{\mathrm{cost}(c_{n+1}-1\,;\,\mathcal{C})}{\left(\lfloor\log_{2}\left(c_{n+1}-2\right)\rfloor+2\right)(c_{n+1}-1)}.

By Lemma
9

\mathrm{cost}(c_{n+1}-1\,;\,\mathcal{C})\geq\frac{1}{2}c_{n+1}\log c_{n+1}+o(nc_{n+1})
and, for a completely greedy coin set,
n=n(c_{n+1}-1)\leq\lfloor\log_{2}(c_{n+1}-2)\rfloor+2
.
∎

.

Let
\mathcal{C}=\{c_{1},\ldots,c_{n},\ldots\}
