Maximally recoverable local reconstruction codes from subspace direct sum systems
Shu Liu, Chaoping Xing

Abstract
. Maximally recoverable local reconstruction codes (MR LRCs for short) have received great attention in the last few years. Various constructions have been proposed in literatures. The main focus of this topic is to construct MR LRCs over small fields. An ( N = n ​ r , r , h , δ ) (N=nr,r,h,\delta) -MR LRC is a linear code over finite field 𝔽 ℓ \mathbb{F}_{\ell} of length N N , whose codeword symbols are partitioned into n n local groups each of size r r . Each local group can repair any δ \delta erasure errors and there are further h h global parity checks to provide fault tolerance from more global erasure patterns. MR LRCs deployed in practice have a small number of global parities such as h = O ⁡ ( 1 ) h=O(1) . In this parameter setting, all previous constructions require the field size ℓ = Ω h ​ ( N h − 1 − o ⁡ ( 1 ) ) \ell=\Omega_{h}(N^{h-1-o(1)}) . It remains challenging to improve this bound. In this paper, via subspace direct sum systems, we present a construction of MR LRC with the field size ℓ = O ⁡ ( N h − 2 + 1 h − 1 − o ⁡ ( 1 ) ) \ell=O(N^{h-2+\frac{1}{h-1}-o(1)}) . In particular, for the most interesting cases where h = 2 , 3 h=2,3 , we improve previous constructions by either reducing field size or removing constraints. In addition, we also offer some constructions of MR LRCs for larger global parity h h that have field size incomparable with known upper bounds. The main techniques used in this paper is through subspace direct sum systems that we introduce. Interestingly, subspace direct sum systems are actually equivalent to 𝔽 q \mathbb{F}_{q} -linear codes over extension fields. Based on various constructions of subspace direct sum systems, we are able to construct several classes of MR LRCs.



1.
Introduction

For a distributed storage system, data is partitioned and stored in different servers as each serve has only a small storage capacity of a few terabyte. A server may crash or become temporarily unavailable due to system updates/network bottlenecks. Thus, we have to design well-structured architectures to overcome these two problems. In the case of crash, we have to repair the lost data stored in the crashed servers. In the second case of temporary unavailability, we have to service user requests with low latency despite some servers becoming temporarily
unavailable. Instead of just replicating data which is wasteful, distributed storage systems use
erasure codes. In view of this demand, Local Reconstruction Codes (LRCs for short)
were invented
[
19
,
6
]
precisely for achieving the objectives of local computations while still maintaining storage efficiency
and have been implemented in several large scale systems such as Microsoft Azure
[
20
]
and
Hadoop
[
27
]
. These codes can recover quickly from a
small number of erasures by reading only a small number of available servers; and at the same
time, they can also recover from the unlikely event of a large number of erasures (but can do so
less efficiently). Locality in distributed storage was first introduced in
[
19
,
6
]
, but locally reconstruction codes
were first formally defined and studied in
[
10
]
and
[
25
]
.

The current paper concerns a much stronger requirement on global fault-tolerance, called
Maximal Recoverability
(MR for short). This requires that the code should simultaneously correct every erasure pattern that is information-theoretically possible to correct, given the locality conditions imposed on the codeword symbols. Let us describe it more formally. Define an
(N,r,h,\delta)_{\ell}
-LRC to be a linear code over
\mathbb{F}_{\ell}
of length
N

whose
N
codeword symbols are partitioned into
n
disjoint groups each of which include
\delta
local parity checks capable of locally correcting
\delta
erasures. The codeword symbols further obey
h
heavy (global) parity checks. With this structure of parity checks, it is not hard to see that the erasure patterns one can hope to correct are precisely those which consist of up to
\delta
erasures per local group plus up to
h
additional erasures anywhere in the codeword. An MR LRC is a
single
code that is capable of simultaneously correcting
all
such patterns.

Since encoding a linear code and decoding it from erasures involve performing numerous finite field arithmetic operations, it is highly desirable to have codes over small fields (preferably of characteristic 2). Obtaining MR LRCs over finite fields of minimal size has therefore emerged as a central problem in the area of codes for distributed storage.

1.3.
Our idea and techniques

The idea is to construct a proper parity-check matrix over
\mathbb{F}_{\ell}
. To have a required parity-check matrix, we divide columns of the bottom matrix of a parity-check into
n
blocks
D_{1},D_{2},\dots,D_{n}
(see (
8
)). Let
\mathbb{F}_{q}
be a subfield of
\mathbb{F}_{\ell}
with
\ell=q^{m}
. We define
D_{i}
to be a
(q,\ell)
-Moore matrix. Let
V_{i}
be the
\mathbb{F}_{q}
-subspace spanned by the first row of the
i
th block
D_{i}
. To obtain the desired MR LRCs, we require that any
h
subspaces out of
V_{1},V_{2},\dots,V_{n}
form a direct sum. To have small field size
\ell
, we want that the elements of
D_{i}
belong to a small finite field
\mathbb{F}_{\ell}
, i.e., small
m
. Thus, we define a subspace direct sum system to be a set
\{V_{i}\}_{i=1}^{n}
with each
V_{i}\subseteq\mathbb{F}_{q^{m}}
such that any
h
subspaces form a direct sum. Hence, to have an MR LRC over small field
\mathbb{F}_{\ell}
, we require a subspace direct sum system with small
m
.

To get constructions and some bounds on subspace direct sum systems, we convert subspace direct sum systems to
\mathbb{F}_{q}
-linear block codes over extension fields with large block Hamming weight. We then explore various constructions of such
\mathbb{F}_{q}
-linear block codes over extension fields to obtain subspace direct sum systems with reasonable parameters. Finally, we present a construction of MR LRCs via subspace direct sum systems. Based on those subspace direct sum systems that we obtain in this paper, we give a few classes of MR LRCs.

1.4.
Organization of the paper

The paper is organized as follows. In Section 2, we present some preliminaries including definition of MR LRCs, their generator and parity-check matrices, Moore matrices, algebraic geometry codes, etc. In Section 3, we introduce subspace direct sum system and then show that such a system is equivalent to a linear block code. We then derive some upper and lower bounds on subspace direct sum systems. We provide some constructions of subspace direct sum systems in Section 3 as well. In the last section, we show how to make use of subspace direct sum systems to construct MR LRCs and then construct MR LRCs over small field through subspace direct sum systems provided in Section 3.

2.1.
Maximally recoverable codes

Let
\ell
be a prime power.
An
\ell
-ary linear code
\mathcal{C}
of length
n
is an
\mathbb{F}_{\ell}
-subspace of
\mathbb{F}_{\ell}^{n}
. We denote by
[N,k,d]_{q}
a
q
-ary linear code with length
N
, dimension
k
and minimum distance

. Then the classical Singleton bound says that an
\ell
-ary
[N,k,d]
-linear code must obey

(5)

k+d\leqslant N+1.

Now we show that linear independence of columns of a matrix remains unchanged regardless of row operations.

Lemma 2.1
.

Let
H=({\bf u}_{1},{\bf u}_{2},\dots,{\bf u}_{N})
be a matrix in
\mathbb{F}_{\ell}^{m\times N}
. Let
H^{\prime}=({\bf u}^{\prime}_{1},{\bf u}^{\prime}_{2},\dots,{\bf u}^{\prime}_{N})
be a matrix obtained from
H
by elementary row operations. Then for a subset
I\subseteq[N]
, the vectors
\{{\bf u}_{i}\}_{i\in I}
are linearly independent if and only if
\{{\bf u}^{\prime}_{i}\}_{i\in I}
are linearly independent.

Proof.

Assume that
\{{\bf u}_{i}\}_{i\in I}
are linearly independent.
As
H^{\prime}
is obtained from
H
by elementary row operations, there exists an invertible matrix
A\in\mathbb{F}_{\ell}^{m\times m}
such that
AH=H^{\prime}
, i.e.,
{\bf u}^{\prime}_{i}=A{\bf u}_{i}
. Hence,
\{{\bf u}_{i}\}_{i\in I}
are linearly independent if and only if
\{{\bf u}^{\prime}_{i}=A{\bf u}_{i}\}_{i\in I}
are linearly independent. Conversely, it is also true.
∎

Now we start to introduce definition of locally repairable codes. In this paper, we consider disjoint recovery sets only. Hence, we divide
[N]
into
n

with each group

having

. For an integer

-linear code

-locality if the projection
\mathcal{C}|_{R_{i}}
of
\mathcal{C}
at each

is a code of distance at least

-locally repairable code with locality

says that

(6)

d\leqslant n-k+1-\left(\left\lceil\frac{k}{r-\delta}\right\rceil-1\right)\delta.

An

[N,k,d]
-locally repairable code with locality

Informally, an
(N,r,h,{\delta})_{\ell}
maximally recoverable code is an

-ary linear code such that erasure errors at any
{\delta}
positions in each group and other

Definition 1
.

Let
\ell
be a prime power. Let

be a partition of

.

\mathcal{C}

\hline\cr\vdots&\vdots&\ddots&\vdots\\
\hline\cr O&O&\cdots&C_{n},E_{n}\\
\hline\cr O,K_{1}-L_{1}C_{1}^{-1}E_{1}&O,K_{2}-L_{2}C_{2}^{-1}E_{2}&\dots&O,K_{n}-L_{n}C_{n}^{-1}E_{n}\end{array}\right),

As
H_{2}
is still a parity-check matrix of
\mathcal{C}
, the matrix
(O,K_{1}-L_{1}C_{1}^{-1}E_{1}|O,K_{2}-L_{2}C_{2}^{-1}E_{2}|\dots|O,K_{n}-L_{n}C_{n}^{-1}E_{n})
has rank
h
, i.e.,

H_{3}:=(K_{1}-L_{1}C_{1}^{-1}E_{1}|K_{2}-L_{2}C_{2}^{-1}E_{2}|\dots|K_{n}-L_{n}C_{n}^{-1}E_{n})

has rank
h
. We can see that
H_{3}
is in fact a parity-check matrix of the code obtained from
\mathcal{C}
by puncturing
{\delta}
positions in each
R_{i}
. This implies that any
h
columns of
H_{3}
are linearly independent. Hence, the first
{\delta}
columns in
H_{2}
together with any other
h
columns of
H_{2}
are linearly independent. As
H_{2}
is obtained from
H
by elementary row operations, by Lemma
2.1
, we conclude that (b) in part (ii) holds.

If
\mathcal{C}
has a parity-check matrix of the form (
8
) satisfying (a) and (b) in (ii), by using a similar argument given above, we can show that puncturing any
{\delta}
positions in each

gives an

-MDS code.
This completes the proof.

2.2.
Moore matrix

Let
\ell
be a power of
q
. For elements
\alpha_{1},\dots,\alpha_{n}\in\mathbb{F}_{\ell}
, a
(q,\ell)
-Moore matrix of size
h\times n
is defined by

M(\alpha_{1},\dots,\alpha_{n})=\left(\begin{array}[]{cccc}\alpha_{1}&\alpha_{2}&\cdots&\alpha_{n}\\
\alpha_{1}^{q}&\alpha_{2}^{q}&\cdots&\alpha_{n}^{q}\\
\vdots&\vdots&\ddots&\vdots\\
\alpha_{1}^{q^{h-1}}&\alpha_{2}^{q^{h-1}}&\cdots&\alpha_{n}^{q^{h-1}}\end{array}\right)\in\mathbb{F}_{\ell}^{h\times n}.

If
n=h
, then
M(\alpha_{1},\dots,\alpha_{h})
is a square matrix. In this case,
the determinant
\det(M(\alpha_{1},\dots,\alpha_{h}))
is given by the following formula

\det(M(\alpha_{1},\dots,\alpha_{h}))=\prod_{(c_{1},\dots,c_{h})}(c_{1}\alpha_{1}+\cdots+c_{h}\alpha_{h}),

where
(c_{1},\dots,c_{h})
runs over a complete set of direction vectors in
\mathbb{F}_{q}^{h}
, made specific by having the last non-zero entry equal to 1, i.e.

\det(M(\alpha_{1},\dots,\alpha_{h}))=\prod_{1\leqslant i\leqslant h}\prod_{(c_{1},\dots,c_{i-1})}(c_{1}\alpha_{1}+\cdots+c_{i-1}\alpha_{i-1}+\alpha_{i}).

Thus,
\det(M(\alpha_{1},\dots,

\alpha_{h}))\neq 0
if and only if
\alpha_{1},\dots,\alpha_{h}
are
\mathbb{F}_{q}
-linearly independent.

Lemma 2.3
.

Let
K,L
be two
(q,\ell)
-Moore matrices of size
h\times n
. Let
A
be a matrix in
\mathbb{F}_{q}^{n\times m}
. Then we have

(i)

K-L
is a
(q,\ell)
-Moore matrix of size
h\times n
.

(ii)

KA
is a
(q,\ell)
-Moore matrix of size
h\times m
. Furthermore, every element in the first row of
KA
is an
\mathbb{F}_{q}
-linear combination of all the elements in the first row of
K
.

Proof.

Let
K,L
be Moore matrices
M(\alpha_{1},\dots,\alpha_{n})
and
M(\beta_{1},\dots,\beta_{n})
for some
\alpha_{i},\beta_{j}\in\mathbb{F}_{\ell}
, respectively. Then it is straightforward to verify that
K-L
is equal to the Moore matrix
M(\alpha_{1}-\beta_{1},\dots,\alpha_{n}-\beta_{n})
. This completes the proof for Part (i).

Now let
A=(a_{ij})_{1\leqslant i\leqslant n,1\leqslant j\leqslant m}\in\mathbb{F}_{q}^{n\times m}
. Then an easy computation shows that

KA=M\left(\sum_{i=1}^{n}a_{i1}\alpha_{i},\dots,\sum_{i=1}^{n}a_{im}\alpha_{i}\right).

Note that we use the fact that
a_{ij}=a_{ij}^{q}
in the above identity.
∎

3.
Subspace direct sum system

Let us define subspace direct sum system first.

Definition 2
.

A subspace direct sum system consists of a set of
\mathbb{F}_{q}
-subspaces
\{V_{1},V_{2},\dots,V_{n}\}
of
\mathbb{F}_{q}^{m}
such that (i)
\dim(V_{i})=r
for every
1\leqslant i\leqslant n
, and (ii) any
h
subspaces
\{V_{i_{1}},V_{i_{2}},\dots,V_{i_{h}}\}
with
1\leqslant i_{1}<i_{2}<\cdots<i_{h}\leqslant n
form a direct sum. We denote such a subspace direct sum system by
{\mathbb{S}}_{q}(n,m,r,h)
.

Remark 1
.

Note that when
r=1
, then a subspace direct sum system
{\mathbb{S}}_{q}(n,m,1,h)
is equivalent to a
q
-ary
[n,k\geqslant n-m,d\geqslant h+1]
-linear code. To see this, we choose a nonzero vector
{\bf v}_{i}
(viewed as a column vector) from each subspace
V_{i}
and form a matrix
H=({\bf v}_{1},{\bf v}_{2},\dots,{\bf v}_{n})
. Then the code with
H
as a parity-check matrix has the desired parameters. Conversely, given a
q
-ary
[n,k\geqslant n-m,h+1]
-linear code, we can form one-dimensional spaces
V_{i}
spanned by the
i
th column of a parity-check matrix. Thus, we obtain a subspace direct sum system
{\mathbb{S}}_{q}(n,m,1,h)
.

In the case of
r=1
, for given
q,n,h
, we want the code dimension
k=n-m
to be large. In other words, we would like to have small
m
. In view of this fact, we have the following definition.

Definition 3
.

For given
q,n,h,r
, we denote by
m_{q}(n,r,h)
the smallest
m
such that there exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
.

Remark 2
.

For a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
, as the dimension of a direct sum of
h
subspaces is
hr
, we must have
m\geqslant hr
. Thus, a trivial lower bound on
m_{q}(n,r,h)
is
m_{q}(n,r,h)\geqslant hr
.

In this section, we are interested in the value
m_{q}(n,r,h)
.

3.1.
Bounds

In this subsection, we mainly study upper and lower bounds on
m_{q}(n,r,h)
. For our constructions of maximally recoverable codes, we are mainly interested in upper bounds on
m_{q}(n,r,h)
. However, to see how small the value
m_{q}(n,r,h)
could be, we also study some lower bounds. Let us give the standard upper bound, i.e., the Gilbert-Varshamov bound.

Lemma 3.1

(Gilbert-Varshamov bound)
.

There exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with
h\geqslant 1
if

(11)

q^{m}>q^{r-1}\sum_{i=0}^{h-1}{n-1\choose i}(q^{r}-1)^{i}.

Proof.

We shall prove that, if (
11
) holds, then there exists a matrix

H=({\bf u}_{11},\dots,{\bf u}_{1r},\dots,{\bf u}_{n1},\dots,{\bf u}_{nr})\in\mathbb{F}_{q}^{m\times nr}

such that any
h
groups
\{{\bf u}_{i_{1}1},\dots,{\bf u}_{i_{1}r}\},\dots,\{{\bf u}_{i_{h}1},\dots,{\bf u}_{i_{h}r}\}
are linearly independent. Thus, we let
V_{i}
be the subspace spanned by
\{{\bf u}_{i1},\dots,{\bf u}_{ir}\}
and we obtain the desired subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
.

First of all, we take
hr
linearly independent vectors
\{{\bf u}_{11},\dots,{\bf u}_{1r},\dots,{\bf u}_{h1},\dots,{\bf u}_{hr}\}\subseteq\mathbb{F}_{q}^{m}
. For any
h+1\leqslant i\leqslant n
and
1\leqslant j\leqslant r
, let
{\bf u}_{ij}
be any vector that is not in the linear span of any
h-1
groups
\{{\bf u}_{k_{1}1},\dots,{\bf u}_{k_{1}r}\},\dots,\{{\bf u}_{k_{h-1}1},\dots,{\bf u}_{k_{h-1}r}\}
(
1\leqslant k_{1}<\cdots<k_{h-1}\leqslant i-1
) and
\{{\bf u}_{i1},\dots,{\bf u}_{i,j-1}\}
. The number of vectors in the linear span is upper bounded by

(12)

\sum_{t=0}^{h-1}{i-1\choose t}(q^{r}-1)^{t}q^{j-1}\leqslant\sum_{t=0}^{h-1}{n-1\choose t}(q^{r}-1)^{t}q^{r-1}.

Thus, by (
11
), we can always find such a vector
{\bf u}_{ij}
that is not a linear combination of vectors in these
h-1
blocks and
\{{\bf u}_{i1},\dots,{\bf u}_{i,j-1}\}
. Hence, the matrix
H
is constructed and the desired result follows.
∎

Corollary 3.2
.

For given prime power
q
and positive integers
n,h,r
,
there exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with

(13)

m:=r+\left\lfloor\log_{q}\left(\sum_{i=0}^{h-1}{n-1\choose i}(q^{r}-1)^{i}\right)\right\rfloor.

Proof.

It is easy to verify that inequality (
11
) holds for
m=r+\left\lfloor\log_{q}\left(\sum_{i=0}^{h-1}{n-1\choose i}(q^{r}-1)^{i}\right)\right\rfloor
. Hence, by Lemma
3.1
, there exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
. The desired result follows.
∎

To derive other upper bounds and Hamming bound, we will establish a connection between subspace direct sum systems and linear block codes.
Let us introduce block Hamming weight.

Definition 4
.

The block Hamming weight
{\rm wt}_{B}({\bf c})
of a vector
{\bf c}=({\bf c}_{1},{\bf c}_{2},\dots,{\bf c}_{n})\in\mathbb{F}_{q}^{nr}
with each
{\bf c}_{i}\in\mathbb{F}_{q}^{r}
is defined to be
{\rm wt}_{B}({\bf c}):=|\{1\leqslant i\leqslant n:\;{\bf c}_{i}\neq{\bf 0}\}|
. The block Hamming distance between two vectors
{\bf u},{\bf v}\in\mathbb{F}_{q}^{nr}
is defined to be
d_{B}({\bf u},{\bf v})={\rm wt}_{B}({\bf u}-{\bf v})
.

Lemma 3.3
.

The block Hamming distance
d_{B}
defined in Definition
4
is indeed a distance.

Proof.

Let
\phi
be an
\mathbb{F}_{q}
-isomorphism between
\mathbb{F}_{q}^{r}
and
\mathbb{F}_{q^{r}}
. Then the block Hamming weight
{\rm wt}_{B}({\bf c})
is exactly the Hamming weight of
\phi({\bf c})=(\phi({\bf c}_{1}),\phi({\bf c}_{2}),\dots,\phi({\bf c}_{n}))
. Thus, The block Hamming distance in
\mathbb{F}_{q}^{nr}
is in fact the Hamming distance in
\mathbb{F}_{q^{r}}^{n}
.
∎

Now we define block codes (we abuse the notation “block codes” here as a classical linear code is also called a linear block code).

Definition 5
.

A linear block code
\mathcal{C}
is an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q}^{nr}
. The minimum distance
d_{B}(\mathcal{C})
of
\mathcal{C}
is defined to be
\min\{d_{B}({\bf u},{\bf v}):\;({\bf u},{\bf v})\in\mathcal{C}\times\mathcal{C},\ {\bf u}\neq{\bf v}\}
. A
q
-ary linear block code
\mathcal{C}
in
\mathbb{F}_{q}^{nr}
with dimension
k
and minimum distance
d
is denoted by
[(n,r),k,d]_{q}
.

Next result shows connection between subspace direct sum system and linear block codes.

Lemma 3.4
.

There exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with
h\geqslant 1
if and only if there is an
[(n,r),k\geqslant nr-m,d\geqslant h+1]_{q}
-block code.

Proof.

Suppose that there is subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with
h\geqslant 1
. Let
V_{1},\dots,V_{n}\subseteq\mathbb{F}_{q}^{m}
be such a subspace direct sum system. Let
\{{\bf u}_{i1},{\bf u}_{i2},\dots,{\bf u}_{ir}\}
be an
\mathbb{F}_{q}
-basis of
V_{i}
and define a matrix

H=({\bf u}_{11},{\bf u}_{12},\dots,{\bf u}_{1r},\dots,{\bf u}_{n1},{\bf u}_{n2},\dots,{\bf u}_{nr}).

Define the code

\mathcal{C}=\{{\bf c}\in\mathbb{F}_{q}^{nr}:\;{\bf c}H^{T}=\b{0}\}.

Then
\mathcal{C}
is an
[(n,r),k\geqslant nr-m]
-block code. As any
h
subspaces out of
\{V_{1},\dots,V_{n}\}
are direct sum, the block Hamming weight of a nonzero of codeword in
\mathcal{C}
is at least
h+1
.

Conversely, if there exists an
[(n,r),k\geqslant nr-m,d\geqslant h+1]_{q}
-block code. Let
\mathcal{C}^{\perp}
be the Euclidean dual of
\mathcal{C}
. Then the generator matrix
H
is an
(nr-k)\times nr
matrix. We partition column vectors of
H
into
n
groups from left to right, each has
r
column vectors. As the minimum Hamming weight of
\mathcal{C}
is at least
h+1
, any
h
groups of column vectors of
H
are linearly independent. Let
V_{i}
be the vector space spanned by the
i
th group, then we obtain the desired subspace direct sum system
{\mathbb{S}}_{q}(n,nr-k,r,h)
. As
nr-k\leqslant m
, we can embed
\mathbb{F}_{q}^{nr-k}
into
\mathbb{F}_{q}^{m}
. The desired result follows.
∎

For a vector
{\bf c}\in\mathbb{F}_{q}^{nr}
and an integer
d
with
0\leqslant d\leqslant n
, define the ball

\mathcal{B}({\bf c},d):=\{{\bf u}\in\mathbb{F}_{q}^{nr}:\;d_{B}({\bf u},{\bf c})=d\}.

Then the size of
|\mathcal{B}({\bf c},d)|
is independent of the center
{\bf c}
and given by
\sum_{i=0}^{d}{n\choose d}(q^{r}-1)^{i}
.

Lemma 3.5

(Hamming bound)
.

If there exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with
h\geqslant 2
, then

(14)

q^{m}\geqslant\sum_{i=0}^{\left\lfloor\frac{h}{2}\right\rfloor}{n\choose i}(q^{r}-1)^{i}.

This implies that

(15)

m_{q}(n,r,h)\geqslant\log_{q}\left(\sum_{i=0}^{\left\lfloor\frac{h}{2}\right\rfloor}{n\choose i}(q^{r}-1)^{i}\right).

Proof.

By Lemma
3.4
, there exists an
[(n,r),k\geqslant nr-m,d=h+1]_{q}
-block code
\mathcal{C}=\{{\bf c}_{1},\dots,{\bf c}_{M}\}
with
M=q^{k}\geqslant q^{nr-m}
. Consider the balls
\mathcal{B}({\bf c}_{i},\left\lfloor\frac{h}{2}\right\rfloor)
. As
\mathcal{C}
has distance
h+1
, these balls are pairwise disjoint. Since
\bigcup_{i=1}^{M}\mathcal{B}({\bf c}_{i},\left\lfloor\frac{h}{2}\right\rfloor)\subseteq\mathbb{F}_{q}^{nr}
, we have

q^{nr}\geqslant\sum_{i=1}^{M}\left|\mathcal{B}\left({\bf c}_{i},\left\lfloor\frac{h}{2}\right\rfloor\right)\right|=M\sum_{i=0}^{\left\lfloor\frac{h}{2}\right\rfloor}{n\choose i}(q^{r}-1)^{i}\geqslant q^{nr-m}\sum_{i=0}^{\left\lfloor\frac{h}{2}\right\rfloor}{n\choose i}(q^{r}-1)^{i}.

The desired result follows.
∎

Lemma 3.6

(Singleton bound)
.

If there exists an
[(n,r),k,d]
-block code, then

(16)

k\leqslant r(n-d+1).

This implies that

(17)

m_{q}(n,r,h)\geqslant hr.

Proof.

Deleting the last
d-1
blocks of length
r
of
\mathcal{C}
to obtain a block code
\mathcal{C}^{\prime}
that is a subset of
\mathbb{F}_{q}^{r(n-d+1)}
. It is clear that
\mathcal{C}^{\prime}
has the same size as
\mathcal{C}
since
\mathcal{C}
has the block distance
d
. This gives

q^{k}=|\mathcal{C}|=|\mathcal{C}^{\prime}|\leqslant q^{r(n-d+1)}.

The desired result follows.

Since we have a subspace direct sum system
{\mathbb{S}}_{q}(n,m,r,h)
with
m=m_{q}(n,r,h)
,
by Lemma
3.4
, there exists an
[(n,r),k\geqslant nr-m,d=h+1]_{q}
-block code. Thus, we have

nr-m\leqslant k\leqslant r(n-h),

i.e.,
m\geqslant hr
.
∎

3.2.
Construction

In the previous subsection, we studied some bounds on subspace direct sum systems. In particular, we derive an existence result, i.e., the Gilbert-Varshamov bound. In this subsection, we provide some explicit constructions of subspace direct sum systems.

Theorem 3.7
.

If

4.
Maximally recoverable codes

In this section, we present constructions of maximally recoverable codes via subspace direct sum systems that have been investigated before. We first give a direct construction of maximally recoverable codes without concatenating with classical linear codes. As locality

decreases. To decrease the field size, our idea is to construct MR codes of block length
r
from a subspace direct sum system
{\mathbb{S}}_{q}(n,m,s,h)
with
s<r
. The other motivation comes from the fact that in Subsection
4.1
, most of MR codes has relatively small block length
r
. Thus, to get larger block length
r
, we start with a subspace direct sum system
{\mathbb{S}}_{q}(n,m,s,h)
with
s<r
and then concatenate with a classical code to obtain an MR code of block length
r
.

From our proof of Theorem
4.1
, it is sufficient to make any
h+{\delta}
elements in the first row of each
D_{i}

\mathbb{F}_{q}
-linearly independent. This is equivalent to the fact that first row of
D_{i}
is a parity-check matrix of a
[r,r-s,d\geqslant h+{\delta}+1]_{q}
-linear code.

Theorem 4.5
.

Let
q
be a prime power with
q\geqslant r-1
. If there exists a subspace direct sum system
{\mathbb{S}}_{q}(n,m,s,h)
and a
q
-ary
[r,r-s,d\geqslant h+{\delta}+1]_{q}
-linear code, then there exists an
(N=nr,r,h,{\delta})_{\ell}
-MR code with
\ell=q^{m}
. In particular, there exists an
(N=nr,r,h,{\delta})_{\ell}
-MR code with

\ell:=q^{m_{q}(n,h,s)}
provided that there exists a
q
-ary
[r,r-s,d\geqslant h+{\delta}+1]_{q}
-linear code.

Proof.

Note that in the proof of Theorem
4.1
, we only require that the first row of
K_{i}
and
L_{i}
are
\mathbb{F}_{q}
-linearly independent. As the number of columns of
(K_{i},L_{i})
is at most
{\delta}+h
. It is sufficient to require that any
{\delta}+h
elements of the first row of
D_{i}
are
\mathbb{F}_{q}
-linearly independent.

Now let
V_{1},V_{2},\dots,V_{n}
be a subspace direct sum system
{\mathbb{S}}_{q}(n,m,s,h)
with
\dim_{\mathbb{F}_{q}}(V_{i})=s
. Due to the fact that there exits a
q
-ary
[r,r-s,d\geqslant h+{\delta}+1]_{q}
-linear code, we can choose
\beta_{i1},\dots,\beta_{ir}\subseteq V_{i}\subseteq\mathbb{F}_{q^{m}}
such that any
{\delta}+h
elements from
\{\beta_{i1},\dots,\beta_{ir}\}
are
\mathbb{F}_{q}
-linearly independent. Put

D_{i}=\begin{pmatrix}\beta_{i1}&\beta_{i2}&\dots&\beta_{ir}\\
\beta^{q}_{i1}&\beta^{q}_{i2}&\dots&\beta^{q}_{ir}\\
\dots&\dots&\dots&\dots\\
\beta^{q^{h-1}}_{i1}&\beta^{q^{h-1}}_{i2}&\dots&\beta^{q^{h-1}}_{ir}\end{pmatrix}

and the desired result follows.
∎

Theorem 4.7

Proof.

4.1

(i) Applying the
q
-ary linear code

, we obtain a
\ell
-ary

-MR code with
