Gradient flow exact renormalization group
\name \fname Hidenori \surname Sonoda1 and \name \fname Hiroshi \surname Suzuki2,∗

Abstract
The gradient flow bears a close resemblance to the coarse graining, the guiding principle of the renormalization group (RG). In the case of scalar field theory, a precise connection has been made between the gradient flow and the RG flow of the Wilson action in the exact renormalization group (ERG) formalism. By imitating the structure of this connection, we propose an ERG differential equation that preserves manifest gauge invariance in Yang–Mills theory. Our construction in continuum theory can be extended to lattice gauge theory.

\displaystyle=e^{\tau n(D-2)/2}\left\langle\exp\left[-\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]B_{\mu_{1}}^{a_{1}}(t,x_{1}e^{\tau})\dotsb B_{\mu_{n}}^{a_{n}}(t,x_{n}e^{\tau})\right\rangle_{S_{\tau=0}}.

3.2
Gauge invariance

We next show that
S_{\tau}[A]
defined by Eq. (
3.1
) is invariant
under any infinitesimal gauge transformation of the scaled gauge potential

\widetilde{A_{\mu}^{a}}(x)\equiv\lambda A_{\mu}^{a}(x),

(3.9)

where

\lambda\equiv e^{-\tau(D-4)/2}.

(3.10)

The
\tau
-dependent factor
\lambda
acts like a coupling constant: An
infinitesimal gauge transformation on
\widetilde{A}
is

\widetilde{A}_{\mu}^{a}(x)\longrightarrow\widetilde{A}_{\mu}^{a}(x)+\partial_{\mu}^{x}\omega^{a}(xe^{\tau})+f^{abc}\widetilde{A}_{\mu}^{b}(x)\omega^{c}(xe^{\tau}),

(3.11)

but the corresponding gauge transformation on
A
is modified by
\lambda
as

A_{\mu}^{a}(x)\longrightarrow A_{\mu}^{a}(x)+\lambda^{-1}\partial_{\mu}^{x}\omega^{a}(xe^{\tau})+f^{abc}A_{\mu}^{b}(x)\omega^{c}(xe^{\tau}).

(3.12)

(See the Appendix for an alternative normalization of
A
.)

To see the invariance of
S_{\tau}[A]
, we first note that the first factor
in Eq. (
3.1
)

\exp\left[\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]

(3.13)

is invariant under the transformation (
3.12
) because the functional
derivative transforms in the adjoint representation
under Eq. (
3.12
):

\frac{\delta}{\delta A_{\mu}^{a}(x)}\longrightarrow f^{abc}\frac{\delta}{\delta A_{\mu}^{b}(x)}\omega^{c}(xe^{\tau}).

(3.14)

We next examine the argument of the delta function in Eq. (
3.1
).
Under the transformation (
3.12
), we find (we write
x^{\prime}
as
x
for
simplicity)

\displaystyle A_{\nu}^{b}(x)-e^{\tau(D-2)/2}B_{\nu}^{\prime b}(t,xe^{\tau})

\displaystyle\longrightarrow A_{\nu}^{b}(x)+\lambda^{-1}\partial_{\nu}^{x}\omega^{b}(xe^{\tau})+f^{bcd}A_{\nu}^{c}(x)\omega^{d}(xe^{\tau})-e^{\tau(D-2)/2}B_{\nu}^{\prime b}(t,xe^{\tau})

\displaystyle=A_{\nu}^{b}(x)-e^{\tau(D-2)/2}\left[B_{\nu}^{\prime b}(t,xe^{\tau})-e^{-\tau}\partial_{\nu}^{x}\omega^{b}(xe^{\tau})-f^{bcd}e^{-\tau(D-2)/2}A_{\nu}^{c}(x)\omega^{d}(xe^{\tau})\right]

\displaystyle=A_{\nu}^{b}(x)-e^{\tau(D-2)/2}\left[B_{\nu}^{\prime b}(t,xe^{\tau})-\partial_{\nu}\omega^{b}(xe^{\tau})-f^{bcd}B_{\nu}^{\prime c}(t,xe^{\tau})\omega^{d}(xe^{\tau})\right]

\displaystyle=A_{\nu}^{b}(x)-e^{\tau(D-2)/2}\left[B_{\nu}^{\prime b}(t,xe^{\tau})-D_{\nu}^{\prime}\omega^{b}(xe^{\tau})\right].

(3.15)

In the third line above, we can replace
e^{-\tau(D-2)/2}A_{\nu}^{c}(x)

by
B_{\nu}^{\prime c}(t,xe^{\tau})
since
\omega
is infinitesimal, and the two are
equal when
\omega=0
. The last line implies that the gauge
transformation (
3.12
) on the external variable
A
induces a gauge
transformation on
B_{\nu}^{\prime b}(t,xe^{\tau})
with the gauge
function
-\omega^{b}(xe^{\tau})
:

B_{\mu}^{\prime a}(t,x)\longrightarrow B_{\mu}^{\prime a}(t,x)-D_{\mu}^{\prime}\omega^{a}(x).

(3.16)

In the functional integral (
3.1
), the integration variable
A^{\prime}
and
the diffused gauge field
B^{\prime}
are related by the flow
equation (
3.3
). We wish to show that there is a gauge transformation
on
A^{\prime}
that gives the gauge transformed
B^{\prime}
, given by Eq. (
3.16
),
as the solution of the diffusion equation (
3.3
). To show this, let
us consider an infinitesimal gauge transformation on the diffused field
B

that
depends
on the flow time
s
(we save
t
for
t=e^{2\tau}-1
):

B_{\mu}^{a}(s,x)\longrightarrow B_{\mu}^{a}(s,x)-D_{\mu}\xi^{a}(s,x).

(3.17)

This changes the flow equation (
3.3
) to

\partial_{s}B_{\mu}^{a}(s,x)=D_{\nu}G_{\nu\mu}^{a}(s,x)+\alpha_{0}D_{\mu}\partial_{\nu}B_{\nu}^{a}(s,x)+D_{\mu}(\partial_{s}-\alpha_{0}D_{\nu}\partial_{\nu})\xi^{a}(s,x).

(3.18)

If we choose
\xi
as the solution to the linear diffusion equation,

(\partial_{s}-\alpha_{0}D_{\nu}\partial_{\nu})\xi^{a}(s,x)=0,\qquad\xi^{a}(s=t,x)=\omega^{a}(x),

(3.19)

Eq. (
3.18
) reduces to the original diffusion
equation (
3.3
) (with
s
replacing
t
). Note that we must solve
Eq. (
3.19
)
backward
against the flow time;
\xi
is
specified at
s=t
rather than the usual
s=0
. Thus, if we gauge-transform the
integration variable
A^{\prime}
by

A_{\mu}^{\prime a}(x)\longrightarrow A_{\mu}^{\prime a}(x)-D_{\mu}^{\prime}\xi^{a}(s=0,x),

(3.20)

the diffusion equation (
3.3
) gives the gauge-transformed
B^{\prime}
given
by Eq. (
3.16
).

We have shown that the gauge transformation (
3.12
) on the external
variable
A
induces the ordinary gauge transformation (
3.20
) on the
integration variable
A^{\prime}
. Now, the functional measure
[dA^{\prime}]

in Eq. (
3.1
) can be and is defined to be gauge invariant (by
dimensional regularization, for example). The factor

\exp\left[-\int d^{D}x^{\prime\prime}\,\frac{1}{2}\frac{\delta^{2}}{\delta A_{\rho}^{\prime c}(x^{\prime\prime})\delta A_{\rho}^{\prime c}(x^{\prime\prime})}\right]

(3.21)

is invariant just as the factor (
3.13
) is. We thus conclude that, if
the original “bare” action
S_{\tau=0}[A]
in Eq. (
3.1
) is
invariant under the gauge transformation, then the Wilson action
S_{\tau}[A]
is
invariant under the
\lambda
-dependent (hence
\tau
-dependent) gauge
transformation (
3.12
). This is how our definition of the Wilson
action preserves manifest gauge invariance.

8

8

To compute the correlation
functions of elementary fields such as Eq. (

. In lattice gauge

3.3

We now derive an ERG differential equation satisfied by the above Wilson

\displaystyle\frac{\partial}{\partial\tau}\,e^{S_{\tau}[A]}

\displaystyle=\exp\left[\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]

\displaystyle\qquad{}\times\int d^{D}x^{\prime}\,\frac{\delta}{\delta\widetilde{A_{\nu}^{b}}(x^{\prime})}\left[-2\widetilde{D_{\rho}F_{\rho\nu}^{b}}(x^{\prime})-2\alpha_{0}\widetilde{D_{\nu}\partial_{\rho}A_{\rho}^{b}}(x^{\prime})-\left(\frac{D-2}{2}+x_{\rho}^{\prime}\partial_{\rho}^{\prime}\right)\widetilde{A_{\nu}^{b}}(x^{\prime})\right]

\displaystyle\qquad\qquad\qquad{}\times\exp\left[-\int d^{D}x^{\prime\prime\prime}\,\frac{1}{2}\frac{\delta^{2}}{\delta A_{\lambda}^{\prime d}(x^{\prime\prime\prime})\delta A_{\lambda}^{\prime d}(x^{\prime\prime\prime})}\right]e^{S_{\tau=0}[A^{\prime}]}

\displaystyle=\exp\left[\lambda^{2}\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta\widetilde{A_{\mu}^{a}}(x)\delta\widetilde{A_{\mu}^{a}}(x)}\right]

\displaystyle\qquad{}\times\int d^{D}x^{\prime}\,\frac{\delta}{\delta\widetilde{A_{\nu}^{b}}(x^{\prime})}\left[-2\widetilde{D_{\rho}F_{\rho\nu}^{b}}(x^{\prime})-2\alpha_{0}\widetilde{D_{\nu}\partial_{\rho}A_{\rho}^{b}}(x^{\prime})-\left(\frac{D-2}{2}+x_{\rho}^{\prime}\partial_{\rho}^{\prime}\right)\widetilde{A_{\nu}^{b}}(x^{\prime})\right]

\displaystyle\qquad\qquad{}\times\exp\left[-\lambda^{2}\int d^{D}x^{\prime\prime}\,\frac{1}{2}\frac{\delta^{2}}{\delta\widetilde{A_{\sigma}^{c}}(x^{\prime\prime})\delta\widetilde{A_{\sigma}^{c}}(x^{\prime\prime})}\right]e^{S_{\tau}[A]},

(3.22)

where the gauge potential
A_{\mu}^{a}(x)
under the tilde
(
\widetilde{\phantom{x}}
) is replaced by the rescaled potential,
Eq. (
3.9
).

Using a relation analogous to Eq. (

) (with
\delta^{(D)}(x)

\exp\left[\lambda^{2}\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta\widetilde{A_{\mu}^{a}}(x)\delta\widetilde{A_{\mu}^{a}}(x)}\right]\widetilde{A_{\nu}^{b}}(x^{\prime})=\widehat{\widetilde{A_{\nu}^{b}}}(x^{\prime})\exp\left[\lambda^{2}\int d^{D}x\,\frac{1}{2}\frac{\delta^{2}}{\delta\widetilde{A_{\mu}^{a}}(x)\delta\widetilde{A_{\mu}^{a}}(x)}\right],

where we define the hat (

\displaystyle\frac{\partial}{\partial\tau}\,e^{S_{\tau}[A]}

\widetilde{A_{\mu}^{a}}(x)

3.24

\displaystyle\frac{\partial}{\partial\tau}e^{S_{\tau}[A]}

\displaystyle\qquad\qquad{}-2\alpha_{0}\Biggl[\widetilde{D_{\mu}\partial_{\nu}A_{\nu}^{a}}(x)+\lambda^{2}\partial_{\mu}\partial_{\nu}\frac{\delta}{\delta\widetilde{A_{\nu}^{a}}(x)}+\lambda^{2}f^{abc}\widetilde{A_{\mu}^{b}}(x)\partial_{\nu}\frac{\delta}{\delta\widetilde{A_{\nu}^{c}}(x)}

\displaystyle\qquad\qquad{}-\left(\frac{D-2}{2}+x_{\nu}\partial_{\nu}\right)\left[\widetilde{A_{\mu}^{a}}(x)+\lambda^{2}\frac{\delta}{\delta\widetilde{A_{\mu}^{a}}(x)}\right]\Biggr\}\,e^{S_{\tau}[A]}.

(3.26)

\displaystyle\qquad\qquad\qquad\qquad{}+\lambda f^{abc}A_{\nu}^{b}(x)A_{\mu}^{c}(x)+\lambda f^{abc}\left[A_{\nu}^{b}(x)\frac{\delta}{\delta A_{\mu}^{c}(x)}-A_{\mu}^{b}(x)\frac{\delta}{\delta A_{\nu}^{c}(x)}\right]

\displaystyle\qquad\qquad{}-2\lambda f^{abc}\left[A_{\nu}^{b}(x)+\frac{\delta}{\delta A_{\nu}^{b}(x)}\right]

\displaystyle\qquad\qquad{}-\left(\frac{D-2}{2}+x_{\nu}\partial_{\nu}\right)\left[A_{\mu}^{a}(x)+\frac{\delta S_{\tau}}{\delta A_{\mu}^{a}(x)}\right]\Biggr).

(3.28)

) then gives

\displaystyle\frac{\partial}{\partial\tau}\frac{1}{2}w_{2,\mu\nu}^{ab}(x,y)

\displaystyle=-2\partial_{\rho}\partial_{\rho}w_{2,\mu\nu}^{ab}(x,y)+(1-\alpha_{0})\left[\partial_{\mu}\partial_{\rho}w_{2,\rho\nu}^{ab}(x,y)+\partial_{\nu}\partial_{\rho}w_{2,\mu\rho}^{ab}(x,y)\right]

\displaystyle\qquad{}+\left[\frac{D+2}{2}+\frac{1}{2}(x-y)_{\rho}\partial_{\rho}\right]w_{2,\mu\nu}^{ab}(x,y)

\displaystyle\qquad{}+\int d^{D}z\,w_{2,\mu\rho}^{ac}(x,z)\left[\delta_{\rho\sigma}(-2\partial_{\lambda}^{z}\partial_{\lambda}^{z}+1)+2(1-\alpha_{0})\partial_{\rho}^{z}\partial_{\sigma}^{z}\right]w_{2,\sigma\nu}^{cb}(z,y).

(3.32)

In deriving this, we have neglected
\delta^{(D)}(x=0)
assuming dimensional
regularization. Imposing the translational and rotational invariance and
global gauge invariance, we can write

w_{2,\mu\nu}^{ab}(x,y)=\delta^{ab}\int_{p}e^{ip(x-y)}\left[T(p)(p^{2}\delta_{\mu\nu}-p_{\mu}p_{\nu})+L(p)p_{\mu}p_{\nu}\right],

(3.33)

where
T(p)
and
L(p)
are functions of
p^{2}
. Equation (
3.32
)
then gives

\displaystyle\frac{1}{2}\frac{\partial}{\partial\tau}T

\displaystyle=-p^{2}\frac{\partial}{\partial p^{2}}T+p^{2}(2p^{2}+1)T^{2}+2p^{2}T,

\displaystyle\frac{1}{2}\frac{\partial}{\partial\tau}L

\displaystyle=-p^{2}\frac{\partial}{\partial p^{2}}L+p^{2}(2\alpha_{0}p^{2}+1)L^{2}+2\alpha_{0}p^{2}L.

(3.34)

The general solution is given by

T(\tau,p)=-\frac{1}{C(pe^{-\tau})e^{-2p^{2}}+p^{2}},\qquad L(\tau,p)=-\frac{1}{D(pe^{-\tau})e^{-2\alpha_{0}p^{2}}+p^{2}},

(3.35)

where
C(p)
and
D(p)
are arbitrary functions of
p^{2}
. Locality demands that

C(p)
and
D(p)
can be expanded in powers of
p^{2}
at
p=0
:

C(p)=C_{0}+C_{1}p^{2}+\frac{1}{2}C_{2}(p^{2})^{2}+\dotsb,\qquad D(p)=D_{0}+D_{1}p^{2}+\frac{1}{2}D_{2}(p^{2})^{2}+\dotsb.

(3.36)

Unitary demands
C_{0}>0
and
D_{0}>0
.

As
\tau\to+\infty
, the action
S_{\tau}[A]
approaches an infrared fixed
point
S^{*}[A]
, corresponding to constants
C_{0}
and
D_{0}
:

T^{*}(p)=-\frac{1}{C_{0}e^{-2p^{2}}+p^{2}},\qquad L^{*}(p)=-\frac{1}{D_{0}e^{-2\alpha_{0}p^{2}}+p^{2}}.

(3.37)

Since
C_{0}>0
and
D_{0}>0
are arbitrary, their variations give marginal
operators:

\delta T(p)=\frac{\delta C_{0}e^{-2p^{2}}}{(C_{0}e^{-2p^{2}}+p^{2})^{2}},\qquad\delta L(p)=\frac{\delta D_{0}e^{-2\alpha_{0}p^{2}}}{(D_{0}e^{-2\alpha_{0}p^{2}}+p^{2})^{2}}.

(3.38)

It can be seen that these correspond to the change of normalization of the
gauge field
A
(see the Appendix).
10
10

10

\delta D_{0}
corresponds to an
infinitesimal change of the gauge-fixing parameter.
Infinitesimal
C_{n}

and
D_{n}
, on the other hand, give

\displaystyle\delta T(\tau,p)

\displaystyle\equiv T(\tau,p)-T^{*}(p)\simeq\frac{C_{n}(p^{2}e^{-2\tau})^{n}e^{-2p^{2}}}{(C_{0}e^{-2p^{2}}+p^{2})^{2}},

\displaystyle\delta L(\tau,p)

\displaystyle\equiv L(\tau,p)-L^{*}(p)\simeq\frac{D_{n}(p^{2}e^{-2\tau})^{n}e^{-2\alpha_{0}p^{2}}}{(D_{0}e^{-2\alpha_{0}p^{2}}+p^{2})^{2}},

(3.39)

where
n=1
,
2
, …, which correspond to irrelevant operators at the fixed
point.

If we make the particular choice of
C_{0}=1
and
D_{0}=\infty

in Eq. (
3.36
), the fixed-point action becomes transverse:

S_{\tau}^{*}[A]=-\frac{1}{2}\int d^{D}x\int d^{D}y\,\int_{p}e^{ip(x-y)}\frac{1}{e^{-2p^{2}}+p^{2}}(p^{2}\delta_{\mu\nu}-p_{\mu}p_{\nu})A_{\mu}^{a}(x)A_{\nu}^{a}(y),

(3.40)

and the marginal operator at the fixed point is given by

\mathcal{O}_{0}=\int d^{D}x\int d^{D}y\,\int_{p}e^{ip(x-y)}\frac{e^{-2p^{2}}}{(e^{-2p^{2}}+p^{2})^{2}}(p^{2}\delta_{\mu\nu}-p_{\mu}p_{\nu})A_{\mu}^{a}(x)A_{\nu}^{a}(y).

(3.41)

It is important to pursue the above analysis to higher orders in
\lambda
to
see how the ordinary beta function arises in our formalism.

4
Lattice gauge theory

In the previous section, we have constructed a gauge-invariant Wilson action
and its associated ERG equation for a generic Yang–Mills theory in
continuum
\mathbb{R}^{4}
. We now tailor the construction for lattice gauge
theory.
11
11

11

Many versions of the renormalization group transformation have
been proposed for lattice gauge theory. We cite
Refs.
[
31
,
32
]
as the pioneering works. Some
of the more recent works are Refs.
[
33
,
34
]
.
For
simplicity, we consider an infinite volume lattice
\mathbb{Z}^{4}
. The discrete
coordinates on
\mathbb{Z}^{4}
render our ERG transformation discrete. This
discreteness is introduced through “block-spins.” Let us pick a fixed
“block-spin” factor
b
from one of the integers
2
,
3
, …. We then
define a “block-spin” link variable by

\mathcal{U}(x,\mu)\equiv U(x,\mu)U(x+\hat{\mu},\mu)\dotsb U(x+(b-1)\hat{\mu},\mu),\qquad x\in b\mathbb{Z}^{4},

(4.1)

where
U(x,\mu)
is a conventional link variable on the
\mathbb{Z}^{4}
lattice;
here,
\hat{\mu}
denotes the unit vector in the
\mu
direction. This

\mathcal{U}(x,\mu)
is regarded as a link variable on the coarse
lattice
b\mathbb{Z}^{4}
scaled by the factor
b
.

We then divide the range of the scale factor
\tau
, originally continuous
in
0\leq\tau<\infty
, into the contiguous intervals

n\Delta\tau<\tau\leq(n+1)\Delta\tau,\qquad n=0,1,2,\dotsc,

(4.2)

where

\Delta\tau\equiv\ln b.

(4.3)

The
n
th interval corresponds to the scaling of
x
by a factor between
b^{n}

and
b^{n+1}
. Multiplying a lattice coordinate
x\in\mathbb{Z}^{4}

by
e^{\Delta\tau}=b
gives the coordinate
bx
on the coarse
lattice
b\mathbb{Z}^{4}
.

Now, we consider a continuous change of the Wilson action within one of the
intervals in Eq. (
4.2
). A natural extension of Eq. (
3.1
)
for the interval
\tau=(n\Delta\tau,(n+1)\Delta\tau]
would be the discrete
transformation from
S_{n}
to
S_{n+1}
, given by
12
12

12

Note that the
formula (
3.1
) can be used to relate the Wilson actions between two
non-zero
\tau
values.

\displaystyle e^{S_{n+1}[U]}

\displaystyle=\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\int[dU^{\prime}]\,\prod_{x^{\prime},\nu}\delta\left(U(x^{\prime},\nu)-W_{\Delta\tau}^{\prime}(bx^{\prime},\nu)\right)

\displaystyle\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,b}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{b}\partial_{x^{\prime\prime},\rho}^{b}\right)e^{S_{n}[U^{\prime}]}.

(4.4)

This needs a fair amount of explanation, which we give below.

First,
\partial_{x,\mu}^{a}
is a link differential operator defined by (see also
Appendix A of Ref.
[
3
]
)

\partial_{x,\mu}^{a}\mathcal{F}[U]\equiv\left.\frac{d}{ds}\mathcal{F}[e^{sX}U]\right|_{s=0},\qquad X(y,\nu)=\begin{cases}T^{a}&\text{if $(y,\nu)=(x,\mu)$},\\
0&\text{otherwise},\\
\end{cases}

(4.5)

where
T^{a}
denotes a (anti-hermitian) generator of the gauge group. The
exponentiated link differential operator in Eq. (
4.4
) is an
analogue of the exponentiated functional differential operator
in Eq. (
3.1
).

Secondly,
W_{\tau}^{\prime}(bx^{\prime},\nu)
in Eq. (
4.4
) is the
solution of the lattice flow equation
[
2
,
3
]
on
the coarse lattice
x\in b\mathbb{Z}^{4}
:

\frac{\partial}{\partial\tau}W_{\tau}^{\prime}(x,\mu)=-2\partial_{x,\mu}S_{w}[W_{\tau}^{\prime}]\cdot W_{\tau}^{\prime}(x,\mu),

(4.6)

where
\partial_{x,\mu}\equiv T^{a}\partial_{x,\mu}^{a}
. The initial value
at
\tau=0
is given by the “block-spin” link
variable (
4.1
) constructed from the integration variable
U^{\prime}

defined on
\mathbb{Z}^{4}
:

W_{\tau=0}^{\prime}(x,\mu)=\mathcal{U}^{\prime}(x,\mu)\equiv U^{\prime}(x,\mu)U^{\prime}(x+\hat{\mu},\mu)\dotsb U^{\prime}(x+(b-1)\hat{\mu},\mu),\quad x\in b\mathbb{Z}^{4}.

(4.7)

It is the value of
W_{\tau}
at
\tau=\Delta\tau
that appears in the delta
function. A possible choice of
S_{w}[W]
is the plaquette action,

S_{w}[W]\equiv\sum_{p}\Re\tr[1-W(p)],

(4.8)

where the sum runs over the plaquettes
p
belonging to the coarse
lattice
b\mathbb{Z}^{4}
, and
W(p)
is the product of the “block-spin” link
variables around
p
. Note that the lattice flow equation (
4.6
) is
written in terms of the scale factor
\tau
rather than the flow
time
t=b^{2n}e^{2\tau}-1
. We have used
\partial/\partial t=b^{-2n}e^{-2\tau}(\partial/2\partial\tau)
and absorbed the
factor
b^{2n}e^{2\tau}
into the right-hand side; this prescription is natural
because we have rescaled the lattice coordinates by the factor
b^{2n}e^{2\tau}

compared with
n=0
. Thanks to this prescription, the ERG
transformation (
4.4
) from
S_{n}
to
S_{n+1}
does not depend on
n

explicitly.

We obtain the lattice Wilson action
S_{n+1}[U]
by successive applications
of Eq. (
4.4
) on the “bare” action
S_{0}[U]
. The preservation of
the partition function and the gauge invariance, both demonstrated
in Sect.
3
on the basis of perturbation theory, now hold true
non-perturbatively, as we explain below.

First, we consider the partition function. If
[dU]
is the group-invariant
Haar measure such that
[d(e^{\eta}U)]=[dU]
for infinitesimal Lie algebra
elements
\eta_{\mu}(x)
, we find, for any functional
\mathcal{F}[U]
,

\displaystyle\int[dU]\,\mathcal{F}[U]

\displaystyle=\int[d(e^{\eta}U)]\,\mathcal{F}[e^{\eta}U]

\displaystyle=\int[dU]\,\mathcal{F}[e^{\eta}U]

\displaystyle=\int[dU]\left[\mathcal{F}[U]+\sum_{x}\eta_{\mu}^{a}(x)\partial_{x,\mu}^{a}\mathcal{F}[U]\right].

(4.9)

This implies
\int[dU]\,\partial_{x,\mu}^{a}\mathcal{F}[U]=0
. Using this
identity for Eq. (
4.4
), we obtain

\int[dU]\,e^{S_{n+1}[U]}=\int[dU]\,e^{S_{n}[U]}.

(4.10)

Hence, the partition function is preserved just as in Eq. (
3.4
).

As for the gauge invariance, we first note that a gauge transformation is
given by

U(x,\mu)\longrightarrow U^{g}(x,\mu)\equiv g(x)U(x,\mu)g(x+\hat{\mu})^{-1},\qquad g(x)\equiv e^{\omega(x)}.

(4.11)

If
\omega
is infinitesimal, the link differential operator transforms in the
adjoint representation,

\left(\partial_{x,\mu}^{a}\mathcal{F}[U]\right)_{U\to U^{g}}=\partial_{x,\mu}^{a}\mathcal{F}[U^{g}]+f^{abc}\omega^{b}(x)\partial_{x,\mu}^{c}\mathcal{F}[U],

(4.12)

where the link differential operator acts on
U^{g}
on the left-hand side, but
it acts on
U
of
U^{g}
on the right. This shows that

(\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\mathcal{F}[U])_{U\to U^{g}}=\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\mathcal{F}[U^{g}]
, and
in Eq. (
4.4
) the gauge transformation on
U
and the first
exponentiated link differential operator commute.

The gauge transformation (
4.11
) acts on the delta function
in Eq. (
4.4
) as (we set
x^{\prime}\to x
for simplicity)

\displaystyle\delta\left(U(x,\nu)-W_{\Delta\tau}^{\prime}(bx,\nu)\right)

\displaystyle\longrightarrow\delta\left(g(x)U(x,\nu)g(x+\hat{\nu})^{-1}-W_{\Delta\tau}^{\prime}(bx,\nu)\right)

\displaystyle=\delta\left(U(x,\nu)-g(x)^{-1}W_{\Delta\tau}^{\prime}(bx,\nu)g(x+\hat{\nu})\right).

(4.13)

This shows that the gauge transformation (
4.11
) on
U
induces an
inverse gauge transformation
W^{g^{-1}}_{\Delta\tau}
on
W_{\Delta\tau}^{\prime}
defined
on the coarse lattice
b\mathbb{Z}^{4}
. Now, if
W_{\tau}^{\prime}
is the solution of the
lattice flow equation (
4.6
) with the initial
condition
\mathcal{U}^{\prime}
, given by Eq. (
4.7
), then

W_{\tau}^{\prime g^{-1}}
is the solution with the initial
condition
\mathcal{U}^{\prime g^{-1}}
as long as
g
does not depend on
\tau
;
this follows from the property (
4.12
). Hence, the gauge
transformation
g
on
U
induces the inverse gauge transformation
g^{-1}
on
the initial condition
\mathcal{U}^{\prime}
. To obtain this transformation
on
b\mathbb{Z}^{4}
, we can introduce the following gauge transformation
on
\mathbb{Z}^{4}
:

U^{\prime}(x,\mu)\longrightarrow h(x)^{-1}U^{\prime}(x,\mu)h(x+\hat{\mu}),\qquad h(x)=\begin{cases}g(y)&\text{if $x=by$ for~$y\in\mathbb{Z}^{4}$},\\
1&\text{otherwise}.\\
\end{cases}

(4.14)

This gauge transformation commutes with the second exponentiated link
differential operator in Eq. (
4.4
) and, as long as
S_{n}[U^{\prime}]
is
gauge invariant, the resulting Wilson action
S_{n+1}[U]
is also gauge
invariant. This completes our argument for the gauge invariance of the lattice
ERG transformation.

The structure of our Wilson action defined recursively by Eq. (
4.4
)
resembles the “lattice effective action” that has been advocated and studied
in Refs.
[
8
,
9
]
. Our definition is different
in two crucial aspects, however: Eq. (
4.4
) has exponentiated link
differential operators, and the lattice points are rescaled in each step of
the ERG transformation. As we have emphasized in the previous section, these
two are essential ingredients for obtaining an ERG differential equation that
is non-linear in the Wilson action and entails scale transformation of space.

Finally, let us derive an ERG differential equation in lattice gauge theory
that follows from the definition (
4.4
) of the Wilson action. For
this, we define
S_{n+1}(\tau)[U]
by

\displaystyle e^{S_{n+1}(\tau)[U]}

\displaystyle\equiv\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\int[dU^{\prime}]\,\prod_{x^{\prime},\nu}\delta\left(U(x^{\prime},\nu)-W_{\tau}^{\prime}(bx^{\prime},\nu)\right)

\displaystyle\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,b}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{b}\partial_{x^{\prime\prime},\rho}^{b}\right)e^{S_{n}[U^{\prime}]}.

(4.15)

We have introduced a diffusion factor
\tau
so that

S_{n+1}(\Delta\tau)[U]=S_{n+1}[U].

(4.16)

As
\tau\to 0+
,
S_{n+1}(\tau)
reduces essentially to
S_{n}
, written for the
block-spin link variables
\mathcal{U}
defined by Eq. (
4.7
):

\displaystyle e^{S_{n+1}(\tau\to 0+)[U]}

\displaystyle\equiv\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\int[dU^{\prime}]\,\prod_{x^{\prime},\nu}\delta\left(U(x^{\prime},\nu)-\mathcal{U}^{\prime}(bx^{\prime},\nu)\right)

\displaystyle\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,b}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{b}\partial_{x^{\prime\prime},\rho}^{b}\right)e^{S_{n}[U^{\prime}]}.

(4.17)

The dependence of
S_{n+1}(\tau)
on the diffusion factor
\tau
is given by
the differential equation,

\displaystyle\frac{\partial}{\partial\tau}e^{S_{n+1}(\tau)[U]}

\displaystyle=\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\int[dU^{\prime}]\,\sum_{y,\sigma,c}(-2)\partial_{y,\sigma}^{c}S_{w}[W_{\tau}^{\prime}]\cdot\partial_{y,\sigma}^{\prime c}\prod_{x^{\prime},\nu}\delta\left(U(x^{\prime},\nu)-W_{\tau}^{\prime}(bx^{\prime},\nu)\right)

\displaystyle\qquad\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,b}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{b}\partial_{x^{\prime\prime},\rho}^{b}\right)e^{S_{n}[U^{\prime}]}

\displaystyle=2\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\sum_{y,\sigma,c}\partial_{y,\sigma}^{c}\left(\partial_{y,\sigma}^{c}S_{w}[U]\right)\int[dU^{\prime}]\,\prod_{x^{\prime},\nu}\delta\left(U(x^{\prime},\nu)-W_{\tau}^{\prime}(bx^{\prime},\nu)\right)

\displaystyle\qquad\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,b}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{b}\partial_{x^{\prime\prime},\rho}^{b}\right)e^{S_{n}[U^{\prime}]}.

(4.18)

For the first equality above, we have used the lattice flow
equation (
4.6
) in evaluating
\frac{\partial}{\partial\tau}\mathcal{F}[W_{\tau}^{\prime}]=\sum_{y,\sigma,c}[(\partial/\partial\tau)W_{\tau}^{\prime}(y,\sigma)\cdot W_{\tau}^{\prime}(y,\sigma)]^{c}\,\partial_{y,\sigma}^{\prime c}\mathcal{F}[W_{\tau}^{\prime}]
, which follows from the
definition of the link differential operator (
4.5
). It is
understood that the operator
\partial_{y,\sigma}^{\prime c}
acts on
W_{\tau}^{\prime}
.
For the second equality, we have rewritten
\partial_{y,\sigma}^{\prime c}
as
the derivative on
U
,
\partial_{y,\sigma}^{\prime c}\to-\partial_{y,\sigma}^{c}
;
this identity holds because the link differential operator acts on the delta
function as
d/ds\,\delta(U(x^{\prime},\nu)-e^{sT^{a}}W_{\tau}^{\prime}(bx^{\prime},\nu))=d/ds\,\delta(e^{-sT^{a}}U(x^{\prime},\nu)-W_{\tau}^{\prime}(bx^{\prime},\nu))
. This link differential
operator on
U
can be put outside to act on the integral over
U^{\prime}
. Then, we
can replace
\partial_{y,\sigma}^{c}S_{w}[W_{\tau}^{\prime}]
by
\partial_{y,\sigma}^{c}S_{w}[U]

thanks to the delta function. Therefore, from Eq. (
4.15
), we get an
ERG differential equation

\displaystyle\frac{\partial}{\partial\tau}e^{S_{n+1}(\tau)[U]}

\displaystyle=\exp\left(\sum_{x,\mu,a}\frac{1}{2}\partial_{x,\mu}^{a}\partial_{x,\mu}^{a}\right)\sum_{x^{\prime},\nu,b}\partial_{x^{\prime},\nu}^{b}\left[\partial_{x^{\prime},\nu}^{b}S_{w}[U]\right]

\displaystyle\qquad{}\times\exp\left(-\sum_{x^{\prime\prime},\rho,c}\frac{1}{2}\partial_{x^{\prime\prime},\rho}^{c}\partial_{x^{\prime\prime},\rho}^{c}\right)e^{S_{n+1}(\tau)[U]}.

(4.19)

By integrating this from
\tau=0+
to
\tau=\Delta\tau
, we restore the finite
change of the Wilson action in Eq. (
4.4
).

Thus, our ERG transformation in lattice gauge theory consists of the rescaling
of lattice points by Eq. (
4.17
) and the diffusion from
\tau=0+

to
\tau=\Delta\tau
by Eq. (
4.19
) (see Eq. (
4.16
)). As
we have shown, this transformation preserves the partition function and
manifest gauge-invariance of the Wilson action. It is important to note that
neither Eq. (
4.17
) nor Eq. (
4.19
) depends explicitly
on
n
. This implies a possibility of finding a fixed point solution,

S_{n+1}=S_{n}
. The technique in Ref.
[
2
]
appears helpful to
the study of such questions.

5
Conclusion

Imitating the structure of the Wilson action in scalar field theory, expressed
by the field diffused by the flow equation, we have constructed a manifestly
gauge-invariant Wilson action and its associated ERG differential equation in
Yang–Mills theory. The construction, extended to lattice gauge theory,
provides a non-perturbative gauge-invariant Wilson action of Yang–Mills
theory. We have presented only the basic idea and basic relations in this
paper; we expect many future applications including analytical or numerical
searches for non-trivial RG fixed points in gauge theory. We can also expect
extensions in various directions, such as inclusion of matter fields and
search for a reparametrization-invariant ERG formulation of quantum gravity.
It should be also interesting to clarify a possible relation to the other
gauge-invariant ERG formulations of gauge theory
[
35
,
36
,
37
,
38
,
39
]
.

Normalization of the gauge field

In Sect.
3

A_{\mu}^{a}(x)
so that
the rescaled field
\widetilde{A_{\mu}^{a}}(x)\equiv\lambda A_{\mu}^{a}(x)
, defined

3.11
). In fact this is not the only choice of

A_{\mu}^{a}(x)
arbitrarily so
that the rescaled field is given by

\widetilde{A_{\mu}^{a}}(x)=\lambda z(\tau)A_{\mu}^{a}(x).

(A.1)

Let
S_{z,\tau}[A]
be the Wilson action of this field. We should then obtain

\displaystyle z(\tau)^{n}\left\langle\exp\left[-\frac{1}{2}\int d^{D}x\,\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]A_{\mu_{1}}^{a_{1}}(x_{1})\dotsb A_{\mu_{n}}^{a_{n}}(x_{n})\right\rangle_{S_{z,\tau}}

\displaystyle=\left\langle\exp\left[-\frac{1}{2}\int d^{D}x\,\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]A_{\mu_{1}}^{a_{1}}(x_{1})\dotsb A_{\mu_{n}}^{a_{n}}(x_{n})\right\rangle_{S_{\tau}}.

(A.2)

This implies
[
26
]

e^{S_{z,\tau}[A]}=\exp\left[\frac{1-1/z(\tau)^{2}}{2}\int d^{D}x\,\frac{\delta^{2}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]\exp\left(S_{\tau}[z(\tau)A]\right).

(A.3)

For

z(\tau)=1+\epsilon

(A.4)

where
\epsilon
is infinitesimal, we obtain

\displaystyle S_{z,\tau}[A]-S_{\tau}[A]

\displaystyle=\epsilon\int d^{D}x\,\left\{\left[\frac{\delta S_{\tau}}{\delta A_{\mu}^{a}(x)}\frac{\delta S_{\tau}}{\delta A_{\mu}^{a}(x)}+\frac{\delta^{2}S_{\tau}}{\delta A_{\mu}^{a}(x)\delta A_{\mu}^{a}(x)}\right]+A_{\mu}^{a}(x)\frac{\delta S_{\tau}}{\delta A_{\mu}^{a}(x)}\right\}

\displaystyle\equiv-\epsilon\mathcal{N}_{\tau}[A].

(A.5)

Hence,
S_{z,\tau}
satisfies the same ERG equation (
3.25
)
as
S_{\tau}
except with the addition of

-\frac{dz(\tau)}{d\tau}\mathcal{N}_{\tau}[A]

(A.6)

on the right-hand side. We can interpret
-[dz(\tau)]/d\tau
as the
anomalous dimension of the gauge field.

The marginal operator
\mathcal{O}_{0}(p)
(
3.41
) that we have found
at the end of Sect.
3
is in fact the operator
\mathcal{N}
