Solvability of a sixth-order boundary value problem with multi-point and multi-term integral boundary conditions
Nourredine Houari, Faouzi Haddouchi

Abstract
. This paper aims to investigate the existence and uniqueness of solutions for a sixth order differential equation involving nonlocal and integral boundary conditions. Firstly, we obtain the properties of the relevant Green’s functions. The existence result of at least one nontrivial solution is obtained by applying the Krasnoselskii-Zabreiko fixed point theorem. Moreover, we also establish the existence of unique solution to the considered problem via Hölder and Minkowski inequalities and Rus’s theorem. Finally, two examples are included to show the applicability of our main results.

Lu(t)=\int_{0}^{1}\bigg[G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\Big(K(\eta_{i+1},s)-K(\eta_{i},s)\Big)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg]\gamma p(s)u(s)ds,\ t\in J.

Obviously, the fixed point of the bounded linear operator
L
is a solution of the boundary value problem (
3.2
)-(
1.2
) and conversely.
First, we will show that
1
is not an eigenvalue for
L
. If,
\gamma=0
, then the Boundary value problem (
3.2
)-(
1.2
) has no nontrivial solution. So, let us assume
\gamma\neq 0
and suppose on the contrary that the problem (
3.2
)-(
1.2
) has a nontrivial solution
u\in X
and
\|u\|>0
, then, by (H2), we have

\displaystyle\lVert u\rVert

\displaystyle=

\displaystyle\max_{t\in J}\lvert Lu(t)\rvert

\displaystyle=

\displaystyle\max_{t\in J}\bigg\lvert\int_{0}^{1}\bigg[G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\bigg(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\bigg)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg]\gamma p(s)u(s)ds\bigg\rvert

\displaystyle\leq

\displaystyle\lvert\gamma\rvert p^{*}\lVert u\rVert\bigg(1+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m-1}\lvert\alpha_{i}\rvert(\eta_{i+1}-\eta_{i})+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m}\lvert\beta_{i}\rvert\bigg)\int_{0}^{1}G(1,s)ds

\displaystyle\leq

\displaystyle\lvert\gamma\rvert M\lVert u\rVert<\lVert u\rVert,

which is a contradiction. Hence,
1
is not an eigenvalue of
L
.

Next, we will show that (
2.1
) is satisfied. Using hypothesis (H1), for all
\varepsilon>0
there exists
\rho>0
such that

\lvert g(u)-\gamma u\rvert<\varepsilon\lvert u\rvert,\ \text{for all}\ \lvert u\rvert>\rho.

Let
g^{\star}=\max_{|u|\leq\rho}|g(u)|
, so we can choose
\theta>0
such that
\big(g^{\star}+|\gamma|\rho\big)<\varepsilon\theta
.

Now, let us define

J_{1}=\big\{t\in J:|u(t)|\leq\rho\big\},\ J_{2}=\big\{t\in J:|u(t)|>\rho\big\}.

Then for all
u\in X
with
\|u\|>\theta
, there hold the estimates

\lvert g(u(t))-\gamma u(t)\rvert\leq|g(u(t))|+|\gamma||u(t)|\leq g^{\star}+|\gamma|\rho<\varepsilon\theta<\varepsilon\|u\|,\ \forall t\in J_{1}.

Similarly, for all
u\in X
with
\|u\|>\theta
, we have

\lvert g(u(t))-\gamma u(t)\rvert<\varepsilon\|u\|,\ \forall t\in J_{2}.

From (
3.1
) and (
3.3
), we get

\displaystyle\lvert Au(t)-Lu(t)\rvert

\displaystyle=

\displaystyle\bigg\lvert\int_{0}^{1}\bigg[G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\bigg(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\bigg)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg]

\displaystyle\times\Big(p(s)g(u(s))-\gamma p(s)u(s)\Big)ds\bigg\rvert

\displaystyle\leq

\displaystyle M\int_{0}^{1}\lvert g(u(s))-\gamma u(s)\rvert ds

\displaystyle\leq

\displaystyle M\varepsilon\lVert u\rVert.

Thus, we obtain

\lim_{\lVert u\rVert\rightarrow\infty}\frac{\lVert Au-Lu\rVert}{\lVert u\rVert}=0.

Now, if we take
u=0
, then
0^{(6)}=-p(t)g(0)=0,\ t\in J
, which contradicts the hypothesis (H1).
Consequently, by Krasnoselskii-Zabreiko’s fixed point Theorem
2.5
,
A
has at least one fixed point
u\in X
which is a nontrivial solution of the boundary value problem (
1.1
)-(
1.2
).
∎

Next, we present our second existence result of unique solution to the problem (
1.1
)-(
1.2
) which relies on Rus’s fixed point theorem.

Now, for any
u_{1},\ u_{2}\in X=C(J,\mathbb{R})
, consider the following two metrics on
X
:

\displaystyle d(u_{1},u_{2})

\displaystyle=

\displaystyle\max_{t\in J}\lvert u_{1}(t)-u_{2}(t)\rvert,

\displaystyle\sigma(u_{1},u_{2})

\displaystyle=

\displaystyle\bigg(\int_{0}^{1}\lvert u_{1}(t)-u_{2}(t)\rvert^{p}dt\bigg)^{\frac{1}{p}},\ p>1.

Theorem 3.3
.

Let
f:J\times\mathbb{R}\rightarrow\mathbb{R}
be a continuous function and assume that the following assumptions are satisfied

(H3)

There exists a constant
L>0
such that

\lvert f(t,u_{1})-f(t,u_{2})\rvert<L\lvert u_{1}-u_{2}\rvert,\ \forall t\in J,\ u_{1},u_{2}\in{\mathbb{R}},

(H4)

L\Phi<1,

where

\displaystyle\Phi

\displaystyle=

\displaystyle\bigg(\int_{0}^{1}\lvert G(1,s)\rvert^{p}ds\bigg)^{\frac{1}{p}}+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m-1}\lvert\alpha_{i}\rvert\bigg(\int_{0}^{1}\Big\lvert\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\Big\rvert^{p}ds\Big)^{\frac{1}{p}}

\displaystyle+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m}\lvert\beta_{i}\rvert\bigg(\int_{0}^{1}\lvert G(\eta_{i},s)\rvert^{p}ds\bigg)^{\frac{1}{p}},\ p>1.

Then the boundary value problem (
1.1
)-(
1.2
) has a unique solution.

Proof.

Here, one should use Theorem
2.4
.
By using Hölder and Minkowski inequalities, for all
u_{1},u_{2}\in{\mathbb{R}}
and
t\in J
, we have

\displaystyle\lvert(Au_{1})(t)-(Au_{2})(t)\rvert

\displaystyle=

\displaystyle\bigg\lvert\int_{0}^{1}\bigg[G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\bigg(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\bigg)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg]

\displaystyle\times\big(f(s,u_{1}(s))-f(s,u_{2}(s))\big)ds\bigg\rvert

\displaystyle\leq

\displaystyle\int_{0}^{1}\bigg\lvert G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\bigg(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\bigg)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg\rvert

\displaystyle\times\lvert f(s,u_{1}(s))-f(s,u_{2}(s))\rvert ds

\displaystyle\leq

\displaystyle L\int_{0}^{1}\bigg\lvert G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\bigg(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\bigg)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg\rvert\lvert u_{1}(s)-u_{2}(s)\rvert ds

\displaystyle\leq

\displaystyle L\bigg(\int_{0}^{1}\bigg\lvert G(t,s)+\frac{1}{\mu}\sum_{i=1}^{m-1}\alpha_{i}\Big(\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\Big)+\frac{1}{\mu}\sum_{i=1}^{m}\beta_{i}G(\eta_{i},s)\bigg\rvert^{p}ds\bigg)^{\frac{1}{p}}

\displaystyle\times\bigg(\int_{0}^{1}\lvert u_{1}(s)-u_{2}(s)\rvert^{q}ds\bigg)^{\frac{1}{q}}

\displaystyle\leq

\displaystyle L\bigg[\bigg(\int_{0}^{1}\lvert G(1,s)\rvert^{p}ds\bigg)^{\frac{1}{p}}+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m-1}\lvert\alpha_{i}\rvert\bigg(\int_{0}^{1}\Big\lvert\int^{\eta_{i+1}}_{\eta_{i}}G(\tau,s)d\tau\Big\rvert^{p}ds\bigg)^{\frac{1}{p}}

\displaystyle+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{m}\lvert\beta_{i}\rvert\bigg(\int_{0}^{1}\lvert G(\eta_{i},s)\rvert^{p}ds\bigg)^{\frac{1}{p}}\bigg]\sigma(u_{1},u_{2}),

then

\lvert(Au_{1})(t)-(Au_{2})(t)\rvert\leq L\Phi\sigma(u_{1},u_{2}).

Thus

d(Au_{1},Au_{2})\leq\xi\sigma(u_{1},u_{2}),

where
\xi=L\Phi>0.

On the other hand, for all
u_{1},u_{2}\in X
, we have

d(Au_{1},Au_{2})\leq\xi\sigma(u_{1},u_{2})\leq\xi d(u_{1},u_{2}).

Then, for any
\varepsilon
we can choose
\delta=\varepsilon\xi^{-1}
so that
d(Au_{1},Au_{2})<\varepsilon
, whenever
d(u_{1},u_{2})<\delta
, which means that
A
is continuous on
X
with respect to the metric
d
.
Further, for all
u_{1},u_{2}\in X
, we get

\int_{0}^{1}\lvert(Au_{1})(t)-(Au_{2})(t)\rvert^{q}dt\leq(L\Phi\sigma(u_{1},u_{2}))^{q},

and hence

\sigma(Au_{1},Au_{2})\leq\nu\sigma(u_{1},u_{2}),

where
\nu=L\Phi,0<\nu<1.

Thus,
A
is contractive on
X
with respect to the metric
\sigma
. Consequently, by Theorem
2.4
,
A
has a unique fixed point in
X
which is the unique (nontrivial) solution of the boundary value problem (
1.1
)-(
1.2
).
∎

Example 4.1
.

We consider the following boundary value problem

(4.1)

\begin{cases}u^{(6)}(t)+t+10^{3}\arctan u=0,\ t\in(0,1),\\
u^{\prime}(0)=u^{\prime\prime}(0)=u^{(3)}(0)=u^{(4)}(0)=u^{\prime\prime}(1)=0,\\
u(0)=\int^{\frac{1}{3}}_{\frac{1}{4}}u(s)ds+3u(\frac{1}{4})+4u(\frac{1}{3}),\end{cases}

where

f(t,u)=t+10^{3}\arctan u\in C(J\times\mathbb{R},\mathbb{R})
and
\alpha=1,\beta_{1}=3,\beta_{2}=4,\eta_{1}=\frac{1}{4},\eta_{2}=\frac{1}{3}

\mu=-\frac{73}{12}.

For all
u_{1},u_{2}\in\mathbb{R}
, and

, we have

\displaystyle\lvert f(t,u_{1})-f(t,u_{2})\rvert

\displaystyle=

\displaystyle\lvert 10^{3}(\arctan u_{1}-\arctan u_{2})\rvert

\displaystyle\leq L\lvert u_{1}-u_{2}\rvert,

where
L=10^{3}
.

On the other hand, by choosing
p=2
, we obtain

\displaystyle\Phi

\displaystyle=

\displaystyle\bigg(\int_{0}^{1}\lvert G(1,s)\rvert^{2}ds\bigg)^{\frac{1}{2}}+\bigg|\frac{\alpha}{\mu}\bigg|\bigg(\int_{0}^{1}\lvert K(\eta_{2},s)-K(\eta_{1},s)\rvert^{2}ds\bigg)^{\frac{1}{2}}

\displaystyle+\frac{1}{\lvert\mu\rvert}\sum_{i=1}^{2}\lvert\beta_{i}\rvert\bigg(\int_{0}^{1}\lvert G(\eta_{i},s)\rvert^{2}ds\bigg)^{\frac{1}{2}}

\displaystyle=

\displaystyle\bigg(\int_{0}^{1}\lvert G(1,s)\rvert^{2}ds\bigg)^{\frac{1}{2}}+\bigg|\frac{\alpha}{\mu}\bigg|\bigg(\int_{0}^{\eta_{1}}\lvert K(\eta_{2},s)-K(\eta_{1},s)\rvert^{2}ds+\int_{\eta_{1}}^{\eta_{2}}\lvert K(\eta_{2},s)-K(\eta_{1},s)\rvert^{2}ds

\displaystyle+\int_{\eta_{2}}^{1}\lvert K(\eta_{2},s)-K(\eta_{1},s)\rvert^{2}ds\Big)^{\frac{1}{2}}+\frac{1}{\lvert\mu\rvert}\bigg[\lvert\beta_{1}\rvert\bigg(\int_{0}^{1}\lvert G(\eta_{1},s)\rvert^{2}ds\bigg)^{\frac{1}{2}}+\lvert\beta_{2}\rvert\bigg(\int_{0}^{1}\lvert G(\eta_{2},s)\rvert^{2}ds\bigg)^{\frac{1}{2}}\bigg]

\displaystyle=

\displaystyle\approx

\displaystyle 0,000902884.

Therefore,
L\Phi<1
.

Hence, based on Theorem
3.3
, the boundary value problem (
4.1
) has a unique solution.
