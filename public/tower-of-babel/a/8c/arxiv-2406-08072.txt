LQR control for a system describing the interaction between a floating solid and the surrounding fluid
Marius Tucsnak, Zhuo Xu

Abstract
This paper studies an infinite time horizon LQR optimal control problem for a system describing, within a linear approximation, the vertical oscillations of a floating solid, coupled to the motion of the free boundary fluid on which it floats. The fluid flow is described by a viscous version of the linearized Saint-Venant equations (shallow water regime). The major difficulty we are facing is that the domain occupied by the fluid is unbounded so that the system is not exponentially stable. This fact firstly raises challenges in proving the wellposedness, requiring the combined use of analytic semigroup theory and of an interpolation technique. The main contribution of the paper is that we show that, in spite of the lack of exponential stabilizability, we can define a wellposed LQR problem for which a Riccati based approach to design feedback controls can be implemented. Key words: floating solid; shallow water equations; analytic semigroup; strong stability; Riccati equation. AMS subject classification: 93C20, 93B52, 35Q35, 49J21.

In the present work, the fluid flow is supposed to be viscous and to obey the shallow water regime. The corresponding system (without inputs) has been considered in

The novelty we bring in this work is, besides introducing an input function, which we consider the situation in which the fluid is not bounded (of obvious interest when we aim at describing a point absorber situated in the ocean) and that we discuss an optimal control problem, with an input acting on the solid. One of the main difficulties which have to be tackled when solving this problem is that the semigroup corresponding to the system with no inputs is not exponentially stable. This type of control is of interest for wave energy converters in order to synchronize the oscillations of the rigid floating object and of the incoming waves, see Korde and Ringwood

More precisely, we are concerned with an infinite horizon LQR optimal control problem for the system obtained by linearizing the equations which describe the interaction of a floating solid with the fluid on which it floats. Some background on LQR problems

As shown below in Section

For the reader’s convenience, in this section we provide, following the references above, the necessary background on infinite horizon LQR problems, with focus on systems which are strongly stable.

Let

, input space

and output space

\displaystyle\dot{z}(t)=Az(t)+Bu(t)

\displaystyle(

\displaystyle t>0),

(2.1)

\displaystyle z(0)=z_{0},

(2.2)

\displaystyle y(t)=Cz(t)

\displaystyle(

\displaystyle t>0),

(2.3)

),

.
According to a classical result, see for instance,
[
5
, Theorem 6.2.4]
, under the appropriate assumptions (including optimizability) the considered LQR problem admits a unique solution

and there exists a self-adjoint, nonnegative operator

. Under supplementary assumptions (which imply, in particular, that

[
5
, Theorem 6.2.7]
). As already mentioned, exponential stabilizability does not hold for the system we consider in the forthcoming sections. Therefore, in order to apply a Riccati type theory, we use the approach developed in
[
2
]
,

[
4
]
and
[
16
]
, for systems which are only strongly stable. To state the result, we need the following definition.

Definition 2.1
.

For every

, the output map
\Psi_{t}:

{X}\to L^{2}((0,\infty);Y)
is defined by

(\Psi_{t}z_{0})(\sigma)=\begin{cases}C\mathbb{T}(\sigma)z_{0}&\qquad\qquad(\sigma\in(0,t],\ z_{0}\in X),\\
0&\qquad\qquad(\sigma>t,\ z_{0}\in X).\end{cases}

The system (
2.1
)-(
2.3
) is called output stable if there exists
\Psi\in\mathcal{L}\left({X},\;L^{2}((0,\,\infty);\;Y)\right)
such that

\lim_{t\to\infty}\|\Psi_{t}-\Psi\|_{\mathcal{L}\left(X,\;L^{2}((0,\,\infty);\;Y)\right)}=0.

Remark 2.2
.

According to the terminology introduced in Tucsnak and Weiss
[
18
, Section 4.6]
, if operators

and

are as in the above definition, we say that

is an infinite-time admissible observation operator for

and we design

An essential tool in proving our second main result is the proposition below, for which we refer again to
[

]
.

Proposition 2.3
.

Suppose that there exists an operator

such that the operator

generates a strongly stable semigroup

and with the system

The sense which

\rho^{2}\sin(2\phi)+\rho^{3}\sin(\phi)=\rho^{2}\sin(\phi)(2\cos(\phi)+\rho)\neq 0,

where

\phi\in\left(-\frac{\pi}{2}-\theta,\;\frac{\pi}{2}+\theta\right)\verb|\|\{0\}\qquad{\rm and}\qquad\rho\geqslant\frac{4}{1-\sin(\theta)}.

The above three formulas imply that the imaginary part of
\frac{\lambda^{2}}{1+\lambda}
, with
\lambda=\rho\exp(i\phi)
and
\rho\geqslant\frac{4}{1-\sin(\theta)}
vanishes iff
\phi=0
. On the other hand, formula (
6.13
) clearly yields that
{\rm Re}\,\frac{\lambda^{2}}{1+\lambda}>0
. We have thus proved that (
4.1
) holds.

We still prove that formula (
4.2
) holds for
\mu=1
. To this aim, we first recall the classical formula

{\rm Re}\,\sqrt{z}=\frac{1}{\sqrt{2}}\sqrt{|z|+{\rm Re}\,z}\qquad\qquad\quad(z\in\mathbb{C}\verb|\|\mathbb{R}_{-}).

(6.14)

We next apply the above formula for
z=\frac{\lambda^{2}}{1+\lambda}
and
\lambda=\rho\exp(i\phi)
, with

\rho\geqslant\frac{4}{1-\sin(\theta)}\qquad{\rm and}\qquad\phi\in\left(-\frac{\pi}{2}-\theta,\,\frac{\pi}{2}+\theta\right).

(6.15)

Combining (
6.14
), (
6.15
) and (
6.13
), we obtain that

\displaystyle 2\left[{\rm Re}\,\left(\sqrt{\frac{\lambda^{2}}{1+\lambda}}\right)\right]^{2}

\displaystyle=\frac{\rho^{2}\sqrt{1+\rho^{2}+2\rho\cos(\phi)}}{1+\rho^{2}+2\rho\cos(\phi)}+\frac{\rho^{2}\cos(2\phi)+\rho^{3}\cos(\phi)}{1+\rho^{2}+2\rho\cos(\phi)}

\displaystyle=\frac{\rho^{2}}{1+\rho^{2}+2\rho\cos(\phi)}\left(\sqrt{1+\rho^{2}+2\rho\cos(\phi)}+\cos(2\phi)+\rho\cos(\phi)\right),

(6.16)

for every
\lambda=\rho\exp(i\phi)
with
\rho
and
\phi
satisfying (
6.15
). Moreover, since
\rho>1
, we have

\displaystyle\sqrt{1+\rho^{2}+2\rho\cos(\phi)}+\cos(2\phi)+\rho\cos(\phi)

\displaystyle\geqslant

\displaystyle\rho-1+\cos(2\phi)+\rho\cos(\phi)

\displaystyle\geqslant

\displaystyle\rho(1-\sin(\theta))-2

\displaystyle\geqslant

\displaystyle\frac{1}{2}\rho(1-\sin(\theta)).

Using the above equation and (
6.16
), for every
\lambda=\rho\exp(i\phi)
satisfying (
6.15
), it follows that

2\left[{\rm Re}\,\left(\sqrt{\frac{\lambda^{2}}{1+\lambda}}\right)\right]^{2}\geqslant\frac{\rho^{3}(1-\sin(\theta))}{2(1+\rho^{2}+2\rho\cos(\phi))}\geqslant\frac{\rho^{3}(1-\sin(\theta))}{2(1+\rho)^{2}}\geqslant\frac{\rho(1-\sin(\theta))}{8},

which ends the proof of Lemma
4.1
.
∎

Proof of Lemma
4.2
.

From Lemma
3.3
, we find for every
\lambda
satisfying (
4.4
), the matrix
\mathcal{M}_{\lambda}
defined in (
3.45
) is invertible. Moreover, from the definition (
3.45
) of
\mathcal{M}_{\lambda}
, we have

\lambda^{-1}\mathcal{M}_{\lambda}=\left[\begin{gathered}1+\frac{8a^{3}}{3}\qquad\quad-1+\frac{4a^{3}}{3}\\
-1+\frac{4a^{3}}{3}\qquad\quad 1+\frac{8a^{3}}{3}\end{gathered}\right]+2a\left(\frac{\mu}{\lambda}+\frac{1}{\lambda^{2}}\right)\left[\begin{gathered}1\quad-1\\
-1\quad 1\end{gathered}\right]+\frac{4a^{2}}{\omega_{\lambda}}\left[\begin{gathered}1\quad 0\\
0\quad 1\end{gathered}\right].

The above formula can be rewritte,

\lambda^{-1}\mathcal{M}_{\lambda}=\left[\begin{gathered}1+\frac{8a^{3}}{3}\qquad-1+\frac{4a^{3}}{3}\\
-1+\frac{4a^{3}}{3}\qquad 1+\frac{8a^{3}}{3}\end{gathered}\right]+\mathcal{P}_{\lambda},

where

\mathcal{P}_{\lambda}=2a\left(\frac{\mu}{\lambda}+\frac{1}{\lambda^{2}}\right)\left[\begin{gathered}1\quad-1\\
-1\quad 1\end{gathered}\right]+\frac{4a^{2}}{\omega_{\lambda}}\left[\begin{gathered}1\quad 0\\
0\quad 1\end{gathered}\right].

Using next Lemma
4.1
we see that there exists a constant
\tilde{K}(\theta,\,\mu)>0
such that

\|\mathcal{P}_{\lambda}\|\leqslant\frac{\tilde{K}(\theta,\,\mu)}{\sqrt{|\lambda|}}\qquad\qquad\qquad\left(\lambda\in\Sigma_{\theta},\;|\lambda|\geqslant R(a,\,\mu,\,\theta)\right).

Moreover, after a simple calculation, we see that the inverse of the matrix
M
defined in (
3.18
) is

\displaystyle M^{-1}=\left[\begin{gathered}1+\frac{8a^{3}}{3}\qquad\quad-\left(1-\frac{4a^{3}}{3}\right)\\
-\left(1-\frac{4a^{3}}{3}\right)\qquad\quad 1+\frac{8a^{3}}{3}\end{gathered}\right],

Consequently,

\displaystyle\|\lambda\mathcal{M}^{-1}_{\lambda}\|

\displaystyle=

\displaystyle\left\|(M^{-1}+\mathcal{P}_{\lambda})^{-1}\right\|

\displaystyle\leqslant

\displaystyle\left\|M^{-1}\right\|\left\|\left(\mathbb{I}+\frac{\mathcal{P}_{\lambda}}{M^{-1}}\right)\right\|

\displaystyle\leqslant

\displaystyle\left\|M^{-1}\right\|\left\|\frac{1}{1-\left\|\frac{\mathcal{P}_{\lambda}}{\left\|M^{-1}\right\|}\right\|}\right\|\qquad\qquad\left(\lambda\in\Sigma_{\theta},\;|\lambda|\geqslant R(a,\,\mu,\,\theta)\right).

(6.17)

The above formula implies the inequality (
4.5
).
∎
