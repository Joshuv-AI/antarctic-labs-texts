ℓ 1 \ell_{1} -norm quantile regression screening rule via the dual circumscribed sphere
Pan Shang, Lingchen Kong

Abstract
ℓ 1 \ell_{1} -norm quantile regression is a common choice if there exists outlier or heavy-tailed error in high-dimensional data sets. However, it is computationally expensive to solve this problem when the feature size of data is ultra high. As far as we know, existing screening rules can not speed up the computation of the ℓ 1 \ell_{1} -norm quantile regression, which dues to the non-differentiability of the quantile function/pinball loss. In this paper, we introduce the dual circumscribed sphere technique and propose a novel ℓ 1 \ell_{1} -norm quantile regression screening rule. Our rule is expressed as the closed-form function of given data and eliminates inactive features with a low computational cost. Numerical experiments on some simulation and real data sets show that this screening rule can be used to eliminate almost all inactive features. Moreover, this rule can help to reduce up to 23 times of computational time, compared with the computation without our screening rule.

Introduction

The availability of high-dimensional data sets has been achieved with the help of advanced technologies. In order to capture different characteristics in these data sets, there are plenty of works about the regularized linear regression, composing of loss function and regularizer. Instead, heuristic screening rules do not possess this advantage, but they can be more efficient by checking the Karush-Kuhn-Tucker (KKT) condition. For example, Tibshirani et al.

[
6

proposed the safe screening rules for the regularized Huber regression. To the best of our knowledge, existing screening rules mainly focus on regularized models with differentiable loss functions, such as the quadratic function, logistic function and Huber function. However, the quantile function/pinball loss is not differentiable, which means that the existing screening rules can not be directly applied to the
\ell_{1}
-norm quantile regression.

The core of an efficient screening rule is the easily expressed estimation of the dual solution, but the non-differentiability of the quantile function cause a difficulty to estimate the dual solution of the
\ell_{1}
-norm quantile regression. In this paper, we introduce the dual circumscribed sphere technique to estimate the dual solution and build up a safe feature screening rule. In order to do so, we first present the dual problem of the
\ell_{1}
-norm quantile regression, which maximizes a linear function under some linear constraints. With the help of duality theory, we obtain a screening test for the
\ell_{1}
-norm quantile regression based on its dual solution. This is the basic screening result that can be used to identity the inactive features, but it may be complex to get the dual solution if the data is high-dimensional. To make this screening test implementable, we estimate the dual solution via a region composing with two half spaces and some box constraints. In order to obtain the analytical form of the screening test, we introduce the dual circumscribed sphere technique. With the help of this technique, we develop an easily implementable screening rule for the
\ell_{1}
-norm quantile regression, which has a closed-form formula of given data. As far as we know, this is the first time to use this technique in screening rules. According to this screening rule, we can eliminate the inactive features in data sets and reduce the computational cost of algorithms. For the purpose of illustrating the efficiency of our screening rule, we do some numerical experiments on simulation data and real data. The experiments present that the screening rule can not only help to eliminate inactive features efficiently, but also save the computational time up to 23 times. Note that we adopt the proximal ADMM (Gu et al.
[
12
]
) to solve the
\ell_{1}
-norm quantile regression. Nevertheless, our screening rule can be embedded into any algorithm or solver for solving this model.

The rest of this paper is organized as follows. We review basic concepts and results of the
\ell_{1}
-norm quantile regression in Section 2. In Section 3, we build up the
\ell_{1}
-norm quantile regression screening rule via the dual circumscribed sphere technique. In Section 4, we present the numerical results of some simulation data and real data. Some conclusions are given in Section 5.

II
Preliminaries

Some basic concepts and results of the
\ell_{1}
-norm quantile regression are reviewed in this section. See Rockafellar
[
32
]
and Beck
[
3
]
for more details. First, we present the quantile function/pinball loss as follows. For any
\xi\in\mathbb{R}
,

\rho_{\tau}(\xi)=\begin{cases}\tau\xi,&\xi>0;\\
(\tau-1)\xi,&\xi\leq 0.\end{cases}

(1)

Here
\tau\in(0,1)
indicates the quantile of interest. Obviously, the quantile function is not differentiable at 0, so we introduce the concept of subdifferential.

Definition II.1
.

Let
f:\mathbb{R}^{n}\rightarrow(-\infty,+\infty]
be a proper closed convex function and let
\textbf{x}\in\mathbb{R}^{n}
. A vector
\textbf{g}\in\mathbb{R}^{n}
is called a subgradient of
f
at
x
if

f(\textbf{y})\geq f(\textbf{x})+\langle\textbf{g},\textbf{y}-\textbf{x}\rangle
,
\forall\textbf{y}\in\mathbb{R}^{n}
.

The set of all subgradients of
f
at
x
is called the subdifferential of
f
at
x
and is denoted by
\partial f(\textbf{x})
, that is

\partial f(\textbf{x})=\left\{\textbf{g}\in\mathbb{R}^{n}:f(\textbf{y})\geq f(\textbf{x})+\langle\textbf{g},\textbf{y}-\textbf{x}\rangle,\forall\textbf{y}\in\mathbb{R}^{n}\right\}
.

According to this definition, we get the subdifferential of the quantile function.

Lemma II.1
.

Let
\rho_{\tau}:\mathbb{R}\rightarrow(-\infty,+\infty)
be the quantile function with
\tau\in(0,1)
. For any
\xi\in\mathbb{R}
, the subdifferential of
\rho_{\tau}
at
\xi
is

\partial{\rho_{\tau}(\xi)}=\begin{cases}\{\tau\},&\xi>0;\\
\left[\tau-1,\tau\right],&\xi=0;\\
\{\tau-1\},&\xi<0.\end{cases}

For any
\textbf{{x}}=(x_{1},x_{2},\cdots,x_{n})^{T}\in\mathbb{R}^{n}
, the
\ell_{1}
norm of
x
is defined as
\|\textbf{{x}}\|_{1}=\sum\limits_{i=1}^{n}|x_{i}|
. By simply calculation, the subdifferential of
\|\textbf{{x}}\|_{1}
is

\partial\|\textbf{{x}}\|_{1}=\left\{\left(\partial|x_{1}|,\cdots,\partial|x_{n}|\right)^{T}\right\}
,
where

\partial|x_{i}|=\begin{cases}\{1\},&x_{i}>0;\\
\left[-1,1\right],&x_{i}=0;\\
\{-1\},&x_{i}<0.\end{cases}

Now, we review the definition of the conjugate function.

Definition II.2
.

Let
f:\mathbb{R}^{n}\rightarrow(-\infty,+\infty]
be a proper closed convex function. The conjugate function of
f
is denoted as
f^{*}
and
f^{*}:\mathbb{R}^{n}\rightarrow(-\infty,+\infty]
is defined as

f^{*}(\textbf{y})=\underset{\textbf{x}\in\mathbb{R}^{n}}{\max}\left\{\langle\textbf{y},\textbf{x}\rangle-f(\textbf{x})\right\}
,
\forall\textbf{y}\in\mathbb{R}^{n}.

Based on this definition, we can get the conjugate of the quantile function.

Lemma II.2
.

Let
\rho_{\tau}:\mathbb{R}\rightarrow(-\infty,+\infty)
be the quantile function with
\tau\in(0,1)
. For any
\nu\in\mathbb{R}
, the conjugate of
\rho_{\tau}
at
\nu
is

\rho^{*}_{\tau}(\nu)=\underset{\xi}{\max}\left\{\xi\nu-\rho_{\tau}(\xi)\right\}=\begin{cases}0,&\tau-1\leq\nu\leq\tau;\\
+\infty,&\rm{otherwise}.\end{cases}

In addition, the conjugate of
\ell_{1}
norm is the indictor function of
\ell_{\infty}
norm. That is, for any
\textbf{{y}}\in\mathbb{R}^{n}
,

\|\textbf{{y}}\|^{*}_{1}=\underset{\textbf{{x}}\in\mathbb{R}^{n}}{\max}\left\{\langle\textbf{{y}},\textbf{{x}}\rangle-\|\textbf{{x}}\|_{1}\right\}=\delta_{\|\cdot\|_{\infty}\leq 1}(\textbf{{y}})=\begin{cases}0,&\|\textbf{{y}}\|_{\infty}\leq 1;\\
+\infty,&\rm{otherwise},\end{cases}

where
\|\textbf{{y}}\|_{\infty}
is defined as

\|\textbf{{y}}\|_{\infty}=\max\{|y_{1}|,\cdots,|y_{n}|\}.

Another norm that we use in this paper is
\ell_{2}
norm. For any
\textbf{{x}}=(x_{1},\cdots,x_{n})^{T}\in\mathbb{R}^{n}
,
\|\textbf{{x}}\|_{2}=\sqrt{x^{2}_{1}+x^{2}_{2}+\cdots+x^{2}_{n}}
.

Definition II.3
.

Let
f:\mathbb{R}^{n}\rightarrow(-\infty,+\infty]
be a proper closed convex function. The proximal mapping of
f
is the operator given by

prox
{}_{f}(\textbf{x})=\underset{\textbf{u}\in\mathbb{R}^{n}}{\arg\min}\left\{f(\textbf{u})+\frac{1}{2}\|\textbf{u}-\textbf{x}\|^{2}_{2}\right\},
for any
\textbf{x}\in\mathbb{R}^{n}
.

Based on this definition, we review the proximal mapping of
\ell_{1}
norm (Beck
[
3
]
) in the following lemma.

Lemma II.3
.

Denote
f=\lambda\|\textbf{x}\|_{1}:\mathbb{R}^{n}\rightarrow(-\infty,+\infty)
. For any
\textbf{x}\in\mathbb{R}^{n}
, the proximal mapping of
f
is

prox
{}_{f}(\textbf{x})=[|\textbf{x}|-\lambda e]_{+}\odot\textit{sign}(\textbf{x}),

where
\odot
denotes the Hadamard product and
\textit{sign}(\textit{{x}})=(\textit{sign}(\textit{x}_{1}),\textit{sign}(\textit{x}_{2}),\cdots,\textit{sign}(\textit{x}_{n}))^{T}
with

\textit{sign}(\textit{x}_{i})=\begin{cases}1,&x_{i}>0\\
0,&x_{i}=0\\
-1,&x_{i}<0\end{cases}.

By simple calculation, we get the proximal mapping of quantile function.

Lemma II.4
.

Let
\rho_{\tau}:\mathbb{R}\rightarrow(-\infty,+\infty)
be the quantile function with
\tau\in(0,1)
. For any
\xi\in\mathbb{R}
, the proximal mapping of
\rho_{\tau}
at
\xi
is

\displaystyle\textit{prox}_{\rho_{\tau}}(\xi)

\displaystyle=\underset{\upsilon\in R}{\arg\min}\left\{\rho_{\tau}(\upsilon)+\frac{1}{2}(\xi-\upsilon)^{2}\right\}

\displaystyle=\begin{cases}\xi-\tau,&\xi\geq\tau;\\
0,&\tau-1<\xi<\tau;\\
\xi-(\tau-1),&\xi\leq\tau-1.\end{cases}

III
\ell_{1}
-norm quantile regression screening rule

In this section, we build up the
\ell_{1}
-norm quantile regression screening rule. At first, we introduce the dual circumscribed sphere technique, which is used to estimate the dual solution. With the help of this technique, we obtain the safe feature screening rule in this paper.

The
\ell_{1}
-norm quantile regression (Li and Zhu
[
24
]
) is

\underset{\beta}{\min}\sum\limits_{i=1}^{n}\rho_{\tau}(y_{i}-\textbf{{x}}^{T}_{i}\beta)+\lambda\|\beta\|_{1},

(2)

where
\beta=(\beta_{1},\cdots,\beta_{p})^{T}\in\mathbb{R}^{p}
is the unknown coefficient vector and
\lambda>0
is the tuning parameter. For ease of expression, we denote the response variable
\textbf{{y}}=(y_{1},\cdots,y_{n})^{T}\in\mathbb{R}^{n}
and the prediction matrix
X=\left(\textbf{{x}}_{1},\textbf{{x}}_{2},\cdots,\textbf{{x}}_{n}\right)^{T}=(X_{\cdot 1},\cdots,X_{\cdot p})\in\mathbb{R}^{n\times p}
, where
\textbf{{x}}_{i}\in\mathbb{R}^{p}
denotes the
i_{th}
sample and
X_{\cdot j}\in\mathbb{R}^{n}
the
j_{th}
feature. In order to emphasize that the solution of (
2
) relies on the choice of
\lambda
, we denote
\beta^{*}(\lambda)
as it. If
\beta^{*}_{j}(\lambda)=0
, the
j_{th}
feature is uncorrelated to the
\tau_{th}
quantile of
y
and we call it the inactive feature. Since that the quantile function is not differentiable, existing screening rules can not be directly applied to the
\ell_{1}
-norm quantile regression (
2
). To overcome the challenge of the non-differentiability of the quantile function, we propose the dual circumscribed technique, which is used to estimate the dual solution. In order to do so, we introduce a variable
\alpha=(\alpha_{1},\cdots,\alpha_{n})^{T}\in\mathbb{R}^{n}
and transform the model (
2
) to a constraint problem as below.

\begin{split}&\underset{\beta,\alpha}{\min}\sum\limits_{i=1}^{n}\rho_{\tau}(\alpha_{i})+\lambda\|\beta\|_{1}\\
&s.t.\quad y_{i}-\textbf{{x}}^{T}_{i}\beta-\alpha_{i}=0,i=1,\cdots,n.\end{split}

(3)

Similarly, the solution of (
3
) is denoted as
(\beta^{*}(\lambda),\alpha^{*}(\lambda))
, where
\beta^{*}(\lambda)
is the solution of (
2
). By introducing the Lagrangian multiplier

\theta=(\theta_{1},\cdots,\theta_{n})^{T}\in\mathbb{R}^{n},

we obtain the Lagrangian function of the model (
3
), which is

\textit{L}\left(\beta,\alpha,\theta\right)=\sum\limits_{i=1}^{n}\rho_{\tau}(\alpha_{i})+\lambda\|\beta\|_{1}+\sum\limits_{i=1}^{n}\theta_{i}(y_{i}-\textbf{{x}}^{T}_{i}\beta-\alpha_{i}).

By direct computation, we obtain that

\displaystyle\underset{\beta,\alpha}{\min}\textit{L}\left(\beta,\alpha,\theta\right)

\displaystyle=\underset{\beta}{\min}\left\{\lambda\|\beta\|_{1}-\langle X^{T}\theta,\beta\rangle\right\}+\sum\limits_{i=1}^{n}\underset{\alpha_{i}}{\min}\left\{\rho_{\tau}(\alpha_{i})-\theta_{i}\alpha_{i}\right\}+\langle\theta,\textbf{{y}}\rangle

\displaystyle=-\delta_{\|\cdot\|_{\infty}\leq\lambda}\left(X^{T}\theta\right)-\sum\limits_{i=1}^{n}\delta_{\tau-1\leq\theta_{i}\leq\tau}\left(\theta_{i}\right)+\langle\theta,\textbf{{y}}\rangle,

where the last equality is based on the result of Lemma 2.2 and the argument after it. Therefore, the Lagrangian dual form of the model (
2
) is

\underset{\theta}{\max}\underset{\beta,\alpha}{\min}\textit{L}\left(\beta,\alpha,\theta\right).

That is,

\begin{split}&\underset{\theta}{\max}\quad\langle\theta,\textbf{{y}}\rangle\\
&s.t.\quad\left\|X^{T}\theta\right\|_{\infty}\leq\lambda,\\
&\quad\quad\quad\tau-1\leq\theta_{i}\leq\tau,\quad i=1,\cdots,n.\end{split}

(4)

Denote the solution of the dual problem (
4
) as
\theta^{*}(\lambda)
. The Karush-Kuhn-Tucker (KKT) system of (
3
) and (
4
) is

\displaystyle\begin{cases}X^{T}\theta\in\lambda\partial\|\beta\|_{1},\\
y_{i}-\textbf{{x}}^{T}_{i}\beta-\alpha_{i}=0,\\
\theta_{i}\in\partial{\rho_{\tau}}(\alpha_{i}),\quad i=1,2,\cdots,n.\end{cases}

(5)

If a pair
\left(\beta(\lambda),\alpha(\lambda),\theta(\lambda)\right)
satisfies the KKT system, it is called the KKT point of (
3
) and (
4
). Note that
(0,\textbf{y})
is a feasible point of the problem (
3
). Slater constraint qualification (Rockafellar
[
32
]
) holds on this problem. Hence, we easily show the following duality theorem.

Theorem III.1
.

(
Strong duality theorem
) The optimal solutions of problems (
3
) and (
4
) compose a KKT point. Moreover, the optimal values of these two problems are same.

According to Theorem
III.1
, for any
\lambda>0
, the solutions of problems (
3
) and (
4
) satisfies that

X^{T}\theta^{*}(\lambda)\in\lambda\partial\|\beta^{*}(\lambda)\|_{1}
.

This, together with the subdifferential of
\ell_{1}
norm, leads to the basic idea of our screening test.

Theorem III.2
.

Let
j\in\{1,\cdots,p\}
. For any tuning parameter
\lambda>0
, if the solution of (
4
) satisfies that

|X_{\cdot j}^{T}\theta^{*}(\lambda)|<\lambda,

then
\beta_{j}^{*}(\lambda)=0
, which means that
X_{\cdot j}
is uncorrelated to the
\tau_{th}
quantile of
y
.

In this paper, we call
|X_{\cdot j}^{T}\theta^{*}(\lambda)|<\lambda
as the screening test. For any tuning parameter
\lambda>0
, according to this theorem, some inactive features can be eliminated. Therefore, this screening test reduces the computational cost of solving the model (
2
) when the dual solution is known. However, the dual solution is unknown in most cases and it may need high computational cost to solve the dual problem in high-dimensional settings. So, we estimate the dual solution in the following part.

Before estimating the dual solution, we present the lower bound of the tuning parameter such that the solution of (
2
) is zero.

Let
\theta_{max}=(\theta^{(1)}_{max},\cdots,\theta^{(n)}_{max})^{T}\in\mathcal{F}\subset\mathbb{R}^{n}
with

\theta^{(i)}_{max}=\partial\rho_{\tau}(y_{i})=\begin{cases}\{\tau\},&y_{i}>0\\
\left[\tau-1,\tau\right],&y_{i}=0,\quad i=1,2,\cdots,n.\\
\{\tau-1\},&y_{i}<0\end{cases}

(6)

Denote

\displaystyle I_{1}=\left\{i\Big|y_{i}>0,i=1,2,\cdots,n\right\},I_{2}=\left\{i\Big|y_{i}<0,i=1,2,\cdots,n\right\}

(7)

and
\Delta=(\Delta_{1},\Delta_{2},\cdots,\Delta_{p})^{T}\in\mathbb{R}^{p}
with

\Delta_{j}=\max~\begin{Bmatrix}\zeta_{j}+\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}\geq 0}\tau X_{ij}+\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}<0}(\tau-1)X_{ij},\\
-\zeta_{j}-\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}\geq 0}(\tau-1)X_{ij}-\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}<0}\tau X_{ij}\end{Bmatrix}

(8)

where
\zeta_{j}=\tau\sum\limits_{i\in I_{1}}X_{ij}+(\tau-1)\sum\limits_{i\in I_{2}}X_{ij}
and
j=1,2,\cdots,p
. We then obtain the next lemma.

Lemma III.1
.

Denote
\lambda_{max}=\|\Delta\|_{\infty}
. The following statements hold.

(i) If
\beta^{*}(\lambda)=0
, then
\lambda\geq\lambda_{max}
.

(ii) If
\lambda>\lambda_{max}
, then
\beta^{*}(\lambda)=0
.

Proof.

(i) Let
\beta^{*}(\lambda)=0
. By Theorem
III.1
and the KKT system (
5
), we know that
\textbf{{y}}=\alpha
,
\theta^{*}(\lambda)\in\mathcal{F}
and
\lambda\geq\|X^{T}\theta_{max}\|_{\infty}
with any
\theta_{max}\in\mathcal{F}
defined in (
6
).
Because
\mathcal{F}
is a set,
\lambda
needs to satisfy that
\lambda\geq\underset{\theta_{max}\in\mathcal{F}}{\max}\|X^{T}\theta_{max}\|_{\infty}
.
By the definition of the
\|\cdot\|_{\infty}
, we know that

\displaystyle\underset{\theta_{max}\in\mathcal{F}}{\max}\|X^{T}\theta_{max}\|_{\infty}

\displaystyle=\underset{\theta_{max}\in\mathcal{F}}{\max}~\underset{j}{\max}~|X_{.j}^{T}\theta_{max}|

\displaystyle=\underset{j}{\max}~\underset{\theta_{max}\in\mathcal{F}}{\max}~|X_{.j}^{T}\theta_{max}|.

Based on (
6
) and (
7
), we know that

\displaystyle\underset{\theta_{max}\in\mathcal{F}}{\max}~|X_{.j}^{T}\theta_{max}|

\displaystyle=\underset{\tau-1\leq\kappa_{i}\leq\tau}{\max}~\Big|\underset{\zeta_{j}}{\underbrace{\tau\sum\limits_{i\in I_{1}}X_{ij}+(\tau-1)\sum\limits_{i\in I_{2}}X_{ij}}}+\sum\limits_{i\notin I_{1}\cup I_{2}}\kappa_{i}X_{ij}\Big|

\displaystyle=\underset{\tau-1\leq\kappa_{i}\leq\tau}{\max}~|\zeta_{j}+\sum\limits_{i\notin I_{1}\cup I_{2}}\kappa_{i}X_{ij}|

\displaystyle=\max~\left\{\zeta_{j}+\sum\limits_{i\notin I_{1}\cup I_{2}}\underset{\tau-1\leq\kappa_{i}\leq\tau}{\max}\kappa_{i}X_{ij},-\zeta_{j}+\sum\limits_{i\notin I_{1}\cup I_{2}}\underset{\tau-1\leq\kappa_{i}\leq\tau}{\max}-\kappa_{i}X_{ij}\right\}

\displaystyle=\max~\begin{Bmatrix}\zeta_{j}+\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}\geq 0}\tau X_{ij}+\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}<0}(\tau-1)X_{ij},\\
-\zeta_{j}-\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}\geq 0}(\tau-1)X_{ij}-\sum\limits_{i\notin I_{1}\cup I_{2},X_{ij}<0}\tau X_{ij}\end{Bmatrix}

\displaystyle=\Delta_{j}.

Therefore,

\displaystyle\lambda\geq\underset{\mathcal{F}}{\max}~\|X^{T}\theta_{max}\|_{\infty}=\underset{j}{\max}~\Delta_{j}=\|\Delta\|_{\infty}=\lambda_{max}.

(ii) Let
\lambda>\lambda_{max}
. Denote
f_{\lambda}(\beta^{*}(\lambda))
as the optimal value of the problem (
2
),
g_{\lambda}(\theta^{*}(\lambda))=\langle\theta^{*}(\lambda),\textbf{{y}}\rangle
as the objective function of the problem (
4
) and

\displaystyle g

\displaystyle=\underset{\theta}{\max}\left\{\langle\theta,\textbf{{y}}\rangle\Big|\tau-1\leq\theta_{i}\leq\tau,\quad i=1,\cdots,n\right\}

\displaystyle=\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i}.

It is clear that
g\geq g_{\lambda}(\theta^{*}(\lambda))
, because there are more constraints of
\theta
when calculating the value of
g_{\lambda}(\theta^{*}(\lambda))
. Based on
\lambda>\lambda_{max}
, we know that any
\theta_{max}\in\mathcal{F}
is a feasible point of the problem (
4
) and
g_{\lambda}(\theta^{*}(\lambda))\geq\langle\theta_{max},\textbf{y}\rangle=g
. Therefore, for any
\lambda>\lambda_{max}
,
g=g_{\lambda}(\theta^{*}(\lambda))
and any
\theta_{max}\in\mathcal{F}
is a solution of the problem (
4
). Replacing
\theta_{max}
into the KKT system (
5
), we obtain the results (a), (b) and (c).

(a) If
y_{i}>0
, we have
\theta^{(i)}_{max}=\{\tau\}
, which leads to
\alpha^{*}_{i}(\lambda)\geq 0
and
y_{i}-x^{T}_{i}\beta^{*}(\lambda)\geq 0
. Therefore,

\rho_{\tau}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))=\tau(y_{i}-x^{T}_{i}\beta^{*}(\lambda)).

(b) If
y_{i}=0
, we have
\theta^{(i)}_{max}=\left[\tau-1,\tau\right]
, which leads to
\alpha^{*}_{i}(\lambda)=0
and
y_{i}-x^{T}_{i}\beta^{*}(\lambda)=0
. Therefore,

\rho_{\tau}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))=0.

(c) If
y_{i}<0
, we have
\theta^{(i)}_{max}=\{\tau-1\}
, which leads to
\alpha^{*}_{i}(\lambda)\leq 0
and
y_{i}-x^{T}_{i}\beta^{*}(\lambda)\leq 0
. Therefore,

\rho_{\tau}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))=(\tau-1)(y_{i}-x^{T}_{i}\beta^{*}(\lambda)).

According to these three results, we have

f_{\lambda}(\beta^{*}(\lambda))=\tau\sum\limits_{i\in I_{1}}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))+(\tau-1)\sum\limits_{i\in I_{2}}(y_{i}-x^{T}_{i}\beta^{*}(\lambda)).

Based on the strong duality theorem, we know that

f_{\lambda}(\beta^{*}(\lambda))=g_{\lambda}(\theta_{max}),

which means

\displaystyle\tau\sum\limits_{i\in I_{1}}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))+(\tau-1)\sum\limits_{i\in I_{2}}(y_{i}-x^{T}_{i}\beta^{*}(\lambda))

\displaystyle=\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i}.

Clearly,
\beta^{*}(\lambda)=0
is a solution of (
2
) when
\lambda>\lambda_{max}
. Moreover, based on
X^{T}\theta_{max}\in\lambda\partial\|\beta\|_{1}
and
\lambda>\lambda_{max}
,
\beta^{*}(\lambda)=0
is the unique solution.
∎

Remark III.1
.

In Lemma 3.1, the expression of
\lambda_{max}
seems complex, while it can be determined by the given data
X
and
y
. The complex expression of
\lambda_{max}
is due to that
\mathcal{F}
is a set. In the special case that all elements of
y
are not zero,
\mathcal{F}=\{\theta_{\max}\}
is a singleton and
\lambda_{max}=\|X^{T}\theta_{max}\|_{\infty}
.

According to this result, we consider about
\lambda\in(0,\lambda_{max}]
in the rest of this paper. Next, we estimate the dual solution when
\lambda\in(0,\lambda_{max}]
, via relaxing the dual box constraints.

Lemma III.2
.

For any
\lambda\in(0,\lambda_{max}]
, the solution of the problem (
4
)
\theta^{*}(\lambda)
satisfies that

\displaystyle\theta^{*}(\lambda)\in\Theta=\left\{\theta\Big|\langle\theta,\textbf{{y}}\rangle\leq b_{1},\langle\theta,\textbf{{y}}\rangle\geq b_{2},\|\theta\|_{2}\leq\rho\right\},

(9)

where
\rho=\frac{\sqrt{n}}{2},

b_{1}=\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i}-(\tau-\frac{1}{2})\sum\limits_{k=1}^{n}y_{k}

and

b_{2}=\frac{\lambda}{\lambda_{max}}\left(\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i}\right)-(\tau-\frac{1}{2})\sum\limits_{k=1}^{n}y_{k}.

Proof.

For any tuning parameter
\lambda\in(0,\lambda_{max}]
, the dual solution
\theta^{*}(\lambda)
satisfies that

\|X^{T}\theta^{*}(\lambda)\|_{\infty}\leq\lambda
and
\tau-1\leq\theta^{*}_{i}(\lambda)\leq\tau,i=1,\cdots,n
.

It is sure that the
\hat{\theta}(\lambda)=\frac{\lambda}{\lambda_{max}}\theta_{max}
satisfies these constraints for any
\theta_{max}\in\mathcal{F}
, so the dual solution must satisfy that

\langle\theta^{*}(\lambda),\textbf{{y}}\rangle\geq g_{\lambda}(\hat{\theta}(\lambda))=\frac{\lambda}{\lambda_{max}}\left(\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i}\right).

In addition,

\langle\theta^{*}(\lambda),\textbf{{y}}\rangle\leq g=\tau\sum\limits_{i\in I_{1}}y_{i}+(\tau-1)\sum\limits_{i\in I_{2}}y_{i},

where
I_{1}
and
I_{2}
are defined in (
7
). This means

\displaystyle\theta^{*}(\lambda)\in\left\{\theta\Big|\langle\theta,\textbf{y}\rangle\leq g,\langle\theta,\textbf{y}\rangle\geq g_{\lambda}(\hat{\theta}(\lambda)),\{\tau-1\leq\theta_{i}\leq\tau\}_{i=1}^{n}\right\}.

(10)

To simplify the computation of
|X_{\cdot j}^{T}\theta^{*}(\lambda)|
in the screen test, let

\displaystyle\mathcal{\Theta}_{1}=\left\{\theta\Big|\langle\theta,\textbf{y}\rangle\leq g,\langle\theta,\textbf{y}\rangle\geq g_{\lambda}(\hat{\theta}(\lambda)),\{\tau-1\leq\theta_{i}\leq\tau\}_{i=1}^{n}\right\}.

(11)

The dual solution
\theta^{*}(\lambda)
must be in this set.

Introducing

\tilde{\theta}\in\mathbb{R}^{n}
with
\tilde{\theta}_{i}=\theta_{i}-(\tau-\frac{1}{2})
,
then
\mathcal{\Theta}_{1}
can be expressed as

\displaystyle\mathcal{\Theta}_{2}=\left\{\tilde{\theta}\Big|\langle\tilde{\theta},\textbf{y}\rangle\leq b_{1},\langle\tilde{\theta},\textbf{y}\rangle\geq b_{2},|\tilde{\theta}_{i}|\leq\frac{1}{2},i=1,\cdots,n\right\},

(12)

where
b_{1}=g-(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}y_{i}
and
b_{2}=g_{\lambda}(\hat{\theta})-(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}y_{i}
.
To get an easily calculated result of
\underset{\theta}{\max}|X_{.j}^{T}\theta|
, we relax
\mathcal{\Theta}_{2}
as

\displaystyle\Theta=\left\{\tilde{\theta}\Big|\langle\tilde{\theta},\textbf{{y}}\rangle\leq b_{1},\langle\tilde{\theta},\textbf{{y}}\rangle\geq b_{2},\|\tilde{\theta}\|_{2}\leq\rho\right\},

where
\rho=\frac{\sqrt{n}}{2}
and
\left\{\tilde{\theta}\Big|||\tilde{\theta}||_{2}\leq\rho\right\}
is a circumscribed sphere of
\left\{\tilde{\theta}\Big||\tilde{\theta}_{i}|\leq\frac{1}{2},i=1,\cdots,n\right\}
.
∎

Remark III.2
.

In Lemma 3.2, we estimate the dual solution by employing the circumscribed sphere relaxation of the dual box constraints. Therefore, we name it as the dual circumscribed sphere technique.

From the proof of Lemma 3.2, we get that

\displaystyle X_{\cdot j}^{T}\theta^{*}(\lambda)

\displaystyle\leq\underset{\theta\in\Theta_{1}}{\max}{X_{\cdot j}^{T}\theta}=\underset{\theta\in\Theta_{2}}{\max}{X_{\cdot j}^{T}\theta}+(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}X_{ij}

\displaystyle\leq P^{+}_{j}(\lambda):=\underset{\theta\in\Theta}{\max}{X_{\cdot j}^{T}\theta}+(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}X_{ij}

and

\displaystyle-X_{\cdot j}^{T}\theta^{*}(\lambda)

\displaystyle\leq\underset{\theta\in\Theta_{1}}{\max}{-X_{\cdot j}^{T}\theta}=\underset{\theta\in\Theta_{2}}{\max}{-X_{\cdot j}^{T}\theta}+(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}X_{ij}

\displaystyle\leq P^{-}_{j}(\lambda):=\underset{\theta\in\Theta}{\max}{-X_{\cdot j}^{T}\theta}+(\tau-\frac{1}{2})\sum\limits_{i=1}^{n}X_{ij}.

Combining these results, we obtain that

|X_{\cdot j}^{T}\theta^{*}(\lambda)|\leq\max\{P^{+}_{j}(\lambda),P^{-}_{j}(\lambda)\}.

V
Conclusion

In this paper, we introduce the dual circumscribed sphere technique to estimate the dual solution. Based on this technique, we build up a safe feature screening rule for the
\ell_{1}
-norm quantile regression, which has a closed-form formula of given data and can be computed with low cost. In the numerical experiments, we adopt the proximal ADMM to solve the
\ell_{1}
-norm quantile regression and illustrate the efficiency of our screening rule, which shows that the screening rule performs well in eliminating inactive features and saving up to 23 times of computational time in some cases. Actually, our screening rule can be embedded into any algorithm or solver for solving this model.
