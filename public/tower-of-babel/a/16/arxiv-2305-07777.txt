Evaluating a double integral using Euler’s method and Richardson extrapolation
J. S. C. Prentice

Abstract
We transform a double integral into a second-order initial value problem, which we solve using Euler’s method and Richardson extrapolation. For an example we consider, we achieve accuracy close to machine precision ( ∼ 10 − 15 ) . \left(\sim 10^{-15}\right). We also use the algorithm to determine the error curve for a Simpson cubature rule.



1
Introduction

Many techniques for evaluating multiple integrals have been developed (see,
for example,
[
1
]
-
[
25
]
). In this paper, we add to
this pool of knowledge: we transform a double integral into a pure
quadrature second-order initial value problem, which we solve using Euler’s
method and Richardson extrapolation. We necessarily assume that the integral
has been “preprocessed” (so that
singularities, discontinuities, infinite limits and so on have been dealt
with).

2
Relevant Concepts

Let
f\left(x,t\right)
be a real-valued function, i.e.
f:\mathbb{R}^{2}\rightarrow\mathbb{R},
that is Riemann integrable in both variables. We will assume that
f
is
suitably smooth so that all relevant derivatives in our analysis exist.

Define

C\left(x\right)\equiv\int\limits_{x_{0}}^{x}\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}f\left(x,t\right)dtdx

(1)

as the
double integral
of interest, noting that the limits of the
inner integral may be functions of
x.

Let
M
denote the exact numerical value of some mathematical object, such
as an integral. Let
N\left(h\right)
denote a numerical approximation to
M
that is dependent on an adjustable parameter
h.
Assume that

N\left(h\right)=M+K_{1}\left(x\right)h+K_{2}\left(x\right)h^{2}+K_{3}\left(x\right)h^{3}+K_{4}\left(x\right)h^{4}+\ldots

(2)

In other words, the approximation error in
N\left(h\right)
is a power
series in
h
.
Richardson extrapolation
is a process by which
values of
N\left(h\right),
for differing values of
h,
can be combined
linearly to yield approximations that are of higher order than the original
approximation
N\left(h\right).
Details of this procedure, relevant to
the current paper, are provided in the Appendix.

The well-known
Euler’s method
is a first-order Runge-Kutta method
for numerically solving an initial value problem, and it has an
approximation error of the form in (
2
).

3
Theory

Differentiating (
1
) wrt
x
gives

\displaystyle C^{\prime}\left(x\right)

\displaystyle=\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}f\left(x,t\right)dt

\displaystyle C^{\prime\prime}\left(x\right)

\displaystyle=f\left(x,t_{1}\left(x\right)\right)t_{1}^{\prime}\left(x\right)-f\left(x,t_{0}\left(x\right)\right)t_{0}^{\prime}\left(x\right)+\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}\frac{\partial f\left(x,t\right)}{\partial x}dt

via the Leibniz rule.

Hence, we have

\displaystyle C^{\prime}

\displaystyle=Z

\displaystyle Z^{\prime}

\displaystyle=f\left(x,t_{1}\left(x\right)\right)t_{1}^{\prime}\left(x\right)-f\left(x,t_{0}\left(x\right)\right)t_{0}^{\prime}\left(x\right)+\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}\frac{\partial f\left(x,t\right)}{\partial x}dt\equiv g\left(x\right)

(3)

with initial values

\displaystyle C\left(x_{0}\right)

\displaystyle=

\displaystyle\int\limits_{x_{0}}^{x_{0}}\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}f\left(x,t\right)dtdx=0

\displaystyle Z\left(x_{0}\right)

\displaystyle=

\displaystyle C^{\prime}\left(x_{0}\right)=\int\limits_{t_{0}\left(x_{0}\right)}^{t_{1}\left(x_{0}\right)}f\left(x_{0},t\right)dt.

Of course, this is a second-order system, compactly expressed as

\left[\begin{array}[]{c}C^{\prime}\\
Z^{\prime}\end{array}\right]=\left[\begin{array}[]{c}Z\\
g\left(x\right)\end{array}\right].

(4)

Euler’s Method applied to this system has the form

\left[\begin{array}[]{c}C_{i+1}\\
Z_{i+1}\end{array}\right]=\left[\begin{array}[]{c}C_{i}\\
Z_{i}\end{array}\right]+h\left[\begin{array}[]{c}Z_{i}\\
g\left(x_{i}\right)\end{array}\right]

where
h
is a
stepsize
- the spacing between the nodes
\left\{x_{0},x_{1},x_{2},\ldots,x_{i},\ldots,x\right\}.
We treat the upper
limit
x
as the final node in the set. Solving this system numerically
yields the values
C\left(x_{i}\right)
and, of course,
C\left(x\right).

C\left(x\right)=\int\limits_{1}^{5}\int\limits_{x/5}^{x^{2}+1}\sin\left(xt\right)dtdx

Z^{\prime}=2x\sin\left(x^{3}+x\right)-\frac{\sin\left(\frac{x^{2}}{5}\right)}{5}+\int\limits_{x/5}^{x^{2}+1}t\cos tdt.

(6)

The one-dimensional integral in (

The initial values are

\displaystyle C\left(1\right)

\displaystyle=0

4.1
Error control

It is possible to choose the stepsize
h
so as to achieve a desired level
of accuracy in the computation of
C\left(x\right).
Terminology and
notation used in this section is described in the Appendix, and the reader
is thereto referred.

With a moderately small value of
h
(we used
h=0.01
in our example), we
use Euler’s method to obtain solutions of (
4
), at the
nodes
\left\{x_{0}=1,x_{1},x_{2},\ldots,\right.

\left.x_{i},\ldots,x=5\right\},
for the various stepsizes required to construct
M_{4}\left(x,h\right)
and
M_{5}\left(x,h\right)
via Richardson extrapolation. We
then perform the computations

\displaystyle M_{4}\left(x_{i},h\right)-M_{5}\left(x_{i},h\right)

\displaystyle=\widetilde{K}_{4}\left(x_{i}\right)h^{4}-O\left(h^{5}\right)

\displaystyle\approx\widetilde{K}_{4}\left(x_{i}\right)h^{4}

\displaystyle\Rightarrow\widetilde{K}_{4}\left(x_{i}\right)

\displaystyle=\frac{M_{4}\left(x_{i},h\right)-M_{5}\left(x_{i},h\right)}{h^{4}}

at each of the nodes
\left\{x_{0}=1,x_{1},x_{2},\ldots,x_{i},\ldots,x=5\right\}
. Hence, we have the error coefficient
\widetilde{K}_{4}
at
each node. We note that, due to the linear combination necessary to
construct
M_{4}\left(x,h\right),

\widetilde{K}_{4}
is not necessarily
equal to
K_{4}.
In fact, we have
K_{4}=64\widetilde{K}_{4}.

The sequence of calculations below then allows a new stepsize to be found,
consistent with a user-defined tolerance
\varepsilon.

\displaystyle h^{\ast}

\displaystyle=\left(\frac{\varepsilon}{\max\limits_{x_{i}}\left|\widetilde{K}_{4}\left(x_{i}\right)\right|}\right)^{\frac{1}{4}}

\displaystyle n

\displaystyle=\left\lceil\frac{x-x_{0}}{h^{\ast}}\right\rceil

\displaystyle h

\displaystyle=\frac{x-x_{0}}{n}.

The Euler/Richardson algorithm is then repeated using this new stepsize,
ultimately leading to a new
M_{4}\left(x_{i},h\right)
and, in
particular,
M_{4}\left(5,h\right)\approx C\left(5\right).

5
Possible Applications

Apart from the obvious task of determining
C\left(x\right),
we can also
use this algorithm to find the error term for a given cubature rule
Q\left(x\right).
If we include
Q\left(x\right)
in (
1
), we have

\int\limits_{x_{0}}^{x}\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}f\left(x,t\right)dtdx=Q\left(x\right)+C\left(x\right)

which yields the system

\displaystyle C^{\prime}

\displaystyle=Z

\displaystyle Z^{\prime}

\displaystyle=f\left(x,t_{1}\left(x\right)\right)t_{1}^{\prime}\left(x\right)-f\left(x,t_{0}\left(x\right)\right)t_{0}^{\prime}\left(x\right)

\displaystyle+\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}\frac{\partial f\left(x,t\right)}{\partial x}dt-Q^{\prime\prime}\left(x\right)

\displaystyle\equiv g\left(x\right),

with initial values

\displaystyle C\left(x_{0}\right)

\displaystyle=\int\limits_{x_{0}}^{x_{0}}\int\limits_{t_{0}\left(x\right)}^{t_{1}\left(x\right)}f\left(x,t\right)dtdx-Q\left(x_{0}\right)=-Q\left(x_{0}\right)

\displaystyle Z\left(x_{0}\right)

\displaystyle=C^{\prime}\left(x_{0}\right)=\int\limits_{t_{0}\left(x_{0}\right)}^{t_{1}\left(x_{0}\right)}f\left(x_{0},t\right)dt-Q^{\prime}\left(x_{0}\right).

In this case,
C\left(x\right)
now plays the role of an
error term
or a
correction term
(earlier, we effectively had
Q\left(x\right)=0).

For example, applying Simpson’s Rule to our example yields the cubature
expression
Q\left(x\right)
shown in the Appendix. Then, applying our
algorithm with
h=4\times 10^{-3},
we find the curves
Q\left(x\right)

and
C\left(x\right)
shown in Figure 4. Comparing
Q\left(x\right)
to
the curve in Figure 1, we see that the cubature rule is very inaccurate.
However, when the correction term
C\left(x\right)
is added to
Q\left(x\right),
the result differs from the true value by
\sim 2\times 10^{-6}

(for
M_{4})
and
\sim 5\times 10^{-9}
(for
M_{5})
at
x=5,
and these
errors can, of course, be made even smaller by using a smaller stepsize.

6
Conclusion

We have described a technique by which the task of determining a double
integral can be presented as the task of solving a second-order initial
value problem. We use Euler’s method for this purpose, combined with
Richardson extrapolation to yield very accurate results. Indeed, we have
achieved accuracy close to machine precision for the numerical example
considered here. Moreover, our algorithm lends itself to error control - the
stepsize
h
needed for a desired accuracy can be estimated. Additionally,
we have shown how the algorithm can be adapted to yield the error curve for
a cubature rule, if such a rule is imposed on the problem.

Future work could address the matter of relative error control,
higher-dimensional cubature and the possibility of developing custom
Runge-Kutta methods of high order that are able to incorporate the integral
term that appears in (
3
). If the interval of integration is
relatively large, it may be wise to divide said interval into subintervals
and to apply the algorithm on each subinterval, adding the results in an
appropriate manner. Whether or not this is necessary or advantageous needs
to investigated. The general case where the limits in the outer integral are
arbitrary functions of
x
should also be considered (we make some comments
in this regard in the Appendix).

Lastly, we note that the physical time taken on our platform
[
27
]

to compute
C\left(x\right)
- for
\sim 6100
nodes - was roughly
30
s.
To compute the same curve using the symbolic
int(f,a,x)
function in
MatLab took as long as an hour. Future research might study this aspect of
efficiency in more detail.
