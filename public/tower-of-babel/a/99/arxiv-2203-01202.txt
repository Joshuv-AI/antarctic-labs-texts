Remarks on the Large data global solutions of 3 ​ D 3D RVP system and 3 ​ D 3D RVM system
Xuecheng Wang

Abstract
. We show that the simplified 3 ​ D 3D relativistic Vlasov-Maxwell (sRVM) system, in which there is no magnetic field, poses a global solution for a class of arbitrarily large cylindrically symmetric initial data. In particular, a vanishing order condition imposed on the initial data for the relativistic Vlasov-Poisson system (RVP) in [ 16 ] is not imposed for the sRVM system.



1.
Introduction

1.1.
Motivation

The
3D
relativistic Vlasov-Maxwell system is one of the fundamental models in the collisionless plasma physics. It reads as follows,

(1.1)

(\textup{RVM})\qquad\left\{\begin{array}[]{c}\partial_{t}f+\hat{v}\cdot\nabla_{x}f+(E+\hat{v}\times B)\cdot\nabla_{v}f=0,\\
\nabla\cdot E=4\pi\displaystyle{\int_{\mathbb{R}^{3}}f(t,x,v)dv},\qquad\nabla\cdot B=0,\\
\partial_{t}E=\nabla\times B-4\pi\displaystyle{\int_{\mathbb{R}^{3}}f(t,x,v)\hat{v}dv},\quad\partial_{t}B=-\nabla\times E,\\
f(0,x,v)=f_{0}(x,v),\quad E(0,x)=E_{0}(x),\quad B(0,x)=B_{0}(x),\end{array}\right.

where
f:\mathbb{R}_{t}\times\mathbb{R}_{x}^{3}\times\mathbb{R}_{v}^{3}\longrightarrow\mathbb{R}_{+}
denotes the distribution function of particles,
E,B:\mathbb{R}_{t}\times\mathbb{R}_{x}^{3}\longrightarrow\mathbb{R}^{3}
denote the electromagnetic field,
\hat{v}:=v/\sqrt{1+|v|^{2}}
.

In particular, if there is no magnetic field, then the electric field is curl free. Hence, we know that
E=\nabla\phi
, where
\phi:\mathbb{R}_{t}\times\mathbb{R}_{x}^{3}\longrightarrow\mathbb{R}
. As a result, the RVM system is reduced to the following simplified RVM (sRVM) system

(1.2)

(\textup{sRVM})\quad\left\{\begin{array}[]{c}\partial_{t}f+\hat{v}\cdot\nabla_{x}f+E\cdot\nabla_{v}f=0,\quad E=\nabla\phi\\
\Delta\phi=4\pi\displaystyle{\int_{\mathbb{R}^{3}}f(t,x,v)dv},\qquad\partial_{t}\nabla_{x}\phi=-4\pi\displaystyle{\int_{\mathbb{R}^{3}}f(t,x,v)\hat{v}dv},\quad f(0,x,v)=f_{0}(x,v).\end{array}\right.

The following conservation law holds for the above system,

(1.3)

\mathcal{H}(t):=\int_{\mathbb{R}^{3}}\int_{\mathbb{R}^{3}}\sqrt{1+|v|^{2}}f(t,x,v)dxdv+\int_{\mathbb{R}^{3}}|\nabla_{x}\phi(t,x)|^{2}dx=\mathcal{H}(0).

We remark that, due to the divergence free condition of the magnetic field, for any smooth localized radial initial data, the solution of the RVM system (
1.1
) must have zero magnetic field.

As comparison, the following
3D
relativistic Vlasov-Poisson system (RVP) for the plasma physics case is also widely studied in the literature.

(1.4)

(\textup{RVP})\quad\left\{\begin{array}[]{c}\partial_{t}f+\hat{v}\cdot\nabla_{x}f+E\cdot\nabla_{v}f=0,\quad E=\nabla\phi\\
\Delta\phi=\rho(t),\quad\rho(t):=\displaystyle{\int_{\mathbb{R}^{3}}f(t,x,v)dv},\quad f(0,x,v)=f_{0}(x,v).\\
\end{array}\right.

Note that the RVP is a determined system while sRVM system is over-determined in general. However, for the radial case, these two systems are equivalent.

The properties of the solution of the RVP system are shared with the solution of the sRVM system, however not the other way around. For example, the solution of sRVM system (
1.2
) enjoys the following property over time,

\int_{\mathbb{R}^{3}}\hat{v}\times\nabla_{x}f(t,x,v)dv=0,

which is not necessarily true for the solution of the RVP system in general. But, indeed, it’s true for the radial case.

In
[
16
]
, we show the global existence of
3D
RVP system (
1.4
) for a class of arbitrarily large initial data with cylindrical symmetry and an extra vanishing order condition on the planar momentum. More precisely, the following condition is imposed on the initial data,

\textup{(a vanishing order condition for RVP)}\qquad\int_{\mathbb{R}^{3}}\int_{\mathbb{R}^{3}}\frac{1}{|\not{x}\times\not{v}|^{13}}f_{0}(x,v)dxdv<+\infty.

In
[
16
]
, we exploit the benefit of the above condition via the conservation law of planar momentum of the
3D
RVP system for the cylindrical symmetry. The the conservation law of planar momentum is available is mainly because of the cylindrical symmetry assumption and the gradient structure of the electric field. However, the gradient structure of the electric field is no longer available for the RVM system (
1.1
). We don’t expect such conservation law for the RVM system.

One of the main goals of this paper is to show that, thanks to the extra equation in sRVM system (
1.2
), the difficulty of removing the vanishing order condition for the RVP system is absent in the sRVM system as well as in the RVM system, see
[
17
]
. In this paper, we will not use the conservation law of the planar momentum of any kind to show large data global existence of the sRVM system (
1.2
). Instead, we exploit the hyperbolic nature of the sRVM system.

We also reveal some properties shared commonly by the RVP system and the sRVM system, e.g., the estimate (
3.23
) in Lemma
3.1
. We hope that it can shine some light on the further study of the large data problem of the RVP system (
1.4
).

Moreover, as a toy model for the RVM system (
1.1
), the framework of proving global existence used in this paper is same as the framework used in a more complicated study of the RVM system
[
17
]
. For pedagogical purpose, we also hope that this paper also serves as an introduction for more complicated and more technical full study of the RVM system in
[
17
]
.

1.2.
Main result of this paper

The main result of this paper is stated as follows.

Theorem 1.1
.

Assume that the initial data
f_{0}(x,v)\in H^{s}(\mathbb{R}_{x}^{3}\times\mathbb{R}_{v}^{3})
,
s\in\mathbb{Z}_{+},s\geq 6
is cylindrical symmetric in the sense that the following equality holds for any
x,v\in\mathbb{R}^{3}
,

(1.5)

f_{0}(x_{1},x_{2},x_{3},v_{1},v_{2},v_{3})=f_{0}(|\not{x}|,0,x_{3},|\not{v}|,0,v_{3}),\quad\not{x}:=(x_{1},x_{2}),\quad\not{v}:=(v_{1},v_{2}).

Moreover, we assume that the initial data decays polynomially as
(x,v)\longrightarrow\infty
in the following sense,

(1.6)

\sum_{\alpha\in\mathbb{Z}_{+}^{6},|\alpha|\leq s}\|(1+|x|+|v|)^{N_{0}}\nabla_{x,v}^{\alpha}f_{0}(x,v)\|_{L^{2}_{x,v}}<+\infty,\quad N_{0}:=10^{8},

then the simplified relativistic Vlasov-Maxwell system
(
1.2
)
admits a global solution
(f(t,\cdot,\cdot))\in H^{s}(\mathbb{R}_{x}^{3}\times\mathbb{R}_{v}^{3})
.

A few remarks are in order.

Remark 1.1
.

Although, as stated in (
1.5
), the initial data is cylindrical symmetric with respect to the
x_{3}
-axis, by changing coordinate system, our main theorem also holds for initial data with cylindrical symmetry with respect to any line that goes through the origin.

Remark 1.2
.

The plausible goal of optimizing the size of
N_{0},s
is not pursued here.

2.
Preliminary

2.1.
The set-up

We use the classic moment method, which is propagating a high order moment of the distribution function over time, to control directly the electric field over time, see Lemma
2.3
. We define

(2.1)

M_{n}(t):=\int_{\mathbb{R}^{3}}\int_{\mathbb{R}^{3}}(1+|v|)^{n}f(t,x,v)dvdx,\quad\tilde{M}_{n}(t):=(1+t)^{n^{2}}+\sup_{s\in[0,t]}M_{n}(s),\quad n:=N_{0}/10=10^{7}.

Therefore
\tilde{M}_{n}(t)
is an increasing function with respect to time.

Let
T\in\mathbb{R}_{+}
be the maximal time of existence. For any fixed
t\in[0,T]
, we let
M_{t}\in\mathbb{Z}_{+}
to be the least integer such that
2^{M_{t}}\geq(\tilde{M}_{n}(t))^{1/(n-1)}
. Moreover, it would be sufficient to only consider the case that
M_{t}\gg 1
otherwise the momentum
\tilde{M}_{n}(t)
is naturally bounded by an absolute constant by definition.

From (
1.2
), the backward characteristics associated with the sRVM system read as follow,

(2.2)

\left\{\begin{array}[]{l}\displaystyle{\frac{d}{ds}X(x,v,s,t)=\hat{V}(x,v,s,t)},\quad\displaystyle{\frac{d}{ds}V(x,v,s,t)=E(s,X(x,v,s,t))}\\
\\
X(x,v,t,t)=x,\quad V(x,v,t,t)=v.\\
\end{array}\right.

Due to the transport nature of the Vlasov equation, see (
1.2
), for any
s,t\in[0,T)
, we have

(2.3)

f(t,x,v)=f(s,X(x,v,s,t),V(x,v,s,t)).

For any
t\in[0,T)
, we define
t
-majority set of particles, which initially localize around zero, at time
s\in[0,T)
as follows,

(2.4)

R_{t}(s):=\{(X(x,v,s,0),V(x,v,s,0)):|V(x,v,0,0)|+|X(x,v,0,0)|\leq 2^{M_{t}/2}\}.

Moreover, we define

(2.5)

\alpha_{t}(s,x,v):=\sup_{\tau\in[0,s]}\inf\{k:k\in\mathbb{R}_{+},|\not{V}(x,v,\tau,0)|\leq 2^{kM_{t}}\},\quad\alpha_{t}(s):=\sup_{(x,v)\in R_{t}(0)}\alpha_{t}(s,x,v),\\
\beta_{t}(s,x,v):=\sup_{\tau\in[0,s]}\inf\{k:k\in\mathbb{R}_{+},|V(x,v,\tau,0)|\leq 2^{kM_{t}}\},\quad\beta_{t}(s):=\sup_{(x,v)\in R_{t}(0)}\beta_{t}(s,x,v),\\
\epsilon:=100/n=10^{-5},\quad\alpha_{t}:=\alpha_{t}(t),\quad\tilde{\alpha}_{t}=\min\{\alpha_{t},1+\epsilon\},\quad\beta_{t}:=\beta_{t}(t),\quad\tilde{\beta}_{t}=\min\{\beta_{t},1+\epsilon\}.

From the above definition, we know that

(2.6)

\forall t\in[0,T),s\in[0,t],\quad R_{s}(0)\subset R_{t}(0),\quad\alpha_{s}M_{s}\leq\alpha_{t}(s)M_{t}\leq\alpha_{t}M_{t},\quad\beta_{s}M_{s}\leq\beta_{t}(s)M_{t}\leq\beta_{t}M_{t}.

Note that

\forall s\in[0,t],x,v\in\mathbb{R}^{3},\quad X(X(x,v,0,s),V(x,v,0,s),s,0)=x,\quad V(X(x,v,0,s),V(x,v,0,s),s,0)=v.

Therefore, from the above definition, for any fixed
s\in[0,t],x\in\mathbb{R}^{3},v\in\mathbb{R}^{3}
, s.t., either
|\not{v}|\geq 2^{(\alpha_{s}+\epsilon)M_{s}}
or
|v|\geq 2^{(\beta_{s}+\epsilon)M_{s}}
, we have

(2.7)

(X(x,v,0,s),V(x,v,0,s))\notin R_{s}(0).

Thanks to the rapid polynomial decay rate of the initial data, see (
1.6
), to control the high moments
\tilde{M}_{n}(t)
, it would be sufficient to control the majority set over time. More precisely, from the assumption on the initial data in (
1.6
), the following estimate holds for any
s\in[0,t],x,v\in\mathbb{R}^{3}
, s.t., either
|\not{v}|\geq 2^{(\alpha_{s}+\epsilon)M_{s}}
or
|v|\geq 2^{(\beta_{s}+\epsilon)M_{s}}
,

(2.8)

\big|f(s,x,v)\big|=\big|f_{0}(X(x,v,0,s),V(x,v,0,s))\big|\lesssim 2^{-4nM_{s}}.

To exploit the benefit of the hyperbolic natural of the sRVM system, we will use the following Kirchhoff’s formula.

Lemma 2.1

(Kirchhoff’s formula)
.

For any
t\in\mathbb{R},x\in\mathbb{R}^{3}
, the following equality holds,

(2.9)

|\nabla|^{-1}\sin(t|\nabla|)h(x)=\frac{1}{4\pi}t\int_{\mathbb{S}^{2}}h(x+t\theta)d\theta,

(2.10)

|\nabla|^{-1}\cos(t|\nabla|)h(x)=\frac{1}{4\pi}\int_{\mathbb{S}^{2}}|\nabla|^{-1}h(x+t\theta)d\theta+\frac{1}{4\pi}\int_{\mathbb{S}^{2}}t\theta\cdot\frac{\nabla}{|\nabla|}h(x+t\theta)d\theta.

Proof.

Note that

(2.11)

\int_{\mathbb{R}^{3}}e^{-ix\cdot\xi}\int_{\mathbb{S}^{2}}h(x+t\theta)d\theta dx=\int_{\mathbb{S}^{2}}e^{it\xi\cdot\theta}\hat{h}(\xi)d\theta=2\pi\hat{h}(\xi)\int_{0}^{\pi}e^{it|\xi|\cos(\phi)}\sin(\phi)d\phi=\frac{4\pi\sin(t|\xi|)}{t|\xi|}\hat{h}(\xi).

Hence finishing the proof of the desired formula (
2.9
). Our desired equality (
2.10
) holds after taking derivative with respect to “
t
” for the equality (
2.9
).
∎
