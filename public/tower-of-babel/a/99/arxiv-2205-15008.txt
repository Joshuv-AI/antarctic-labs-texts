Efficient Transformed Gaussian Processes for Non-Stationary Dependent Multi-class Classification
Juan Maroñas, Daniel Hernández-Lobato

Abstract
This work introduces the Efficient Transformed Gaussian Process (, a new way of creating C C stochastic processes characterized by: 1) the C C processes are non-stationary , 2) the C C processes are dependent by construction without needing a mixing matrix, 3) training and making predictions is very efficient since the number of Gaussian Processes ( operations (e.g. inverting the inducing point’s covariance matrix) do not depend on the number of processes. This makes the articularly suited for multi-class problems with a very large number of classes, which are the problems studied in this work. s exploit the recently proposed Transformed Gaussian Process (, a stochastic process specified by transforming a Gaussian Process using an invertible transformation. However, unlike s, s are constructed by transforming a single sample from a sing C C invertible transformations. We derive an efficient sparse variational inference algorithm for the proposed model and demonstrate its utility in 5 classification tasks which include low/medium/large datasets and a different number of classes, ranging from just a few to hundreds. Our results show that s, in general, outperform state-of-the-art methods for multi-class classification based on s, and have a lower computational cost (around one order of magnitude smaller).

in Fig. \ref{fig:arch_nn}. In principle, we could use a \lx@acro@@@def{\smaller NN}{\smaller NN}{p}{{\smaller NN}}{{p}}er flow parameter,
implemented efficiently using batched operations \cite[citep]{[\@@bibref{Number}{Blas_library}{}{}]}. However,
by using a single \lx@acro@@@def{\smaller NN}{\smaller NN}{w}{{\smaller NN}}{{w}}hose output layer coincides with the number of parameters
per flow times the number of classes, we achieve a more efficient parameterization.
For example, if we are modeling Imagenet ($C=1000$) with a linear flow
($|\theta|=2$), then we would use an output layer of $2000$ neurons. Beyond
being more efficient, this could also serve as a possible regularizer
in the same fashion as sharing parameters regularizes \lx@acro@@@def{\smaller DNN}{\smaller DNN}{}{{\smaller DNN}}{{}}s, something
commonly used in computer vision applications through a back-bone convolutional model.

\par\lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{c}{{\smaller ETGP}}{{c}}reates $C$ dependent processes since $\mathbf{f}_{0}$ is shared.
We have characterized the dependencies of these $C$ processes for a linear flow in
Prop. \ref{prop1}. The flows, however, need not be linear and can be arbitrarily complicated.
Because $\mathbb{G}_{\theta_{K}}^{c}$ is input-dependent the $C$ processes are also non-stationary.
\par Expectations w.r.t. the \lx@acro@@@def{\smaller NN}{\smaller NN}{}{{\smaller NN}}{{}}'s parameters can be computed using batched matrix multiplications. Expectations w.r.t. $q(\mathbf{f}_{0})$ in Eq. \ref{elbo} and Eq. \ref{pos_predictive} can be computed with $1$-d quadrature. By contrast, the \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}} method from Sec. \ref{sec:background_mgp} cannot
use quadrature methods.
Moreover, the number of \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} operations is constant with $C$. To get $q(\mathbf{f}^{c})$ in \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s Sec. \ref{sec:background_mgp} one needs a cubic operation to invert $K^{c}_{\nu}(\mathbf{z},\mathbf{z})$ and $M^{2}$ operation to compute the variational parameters per class and datapoint, giving a complexity of $\mathcal{O}(CM^{3}+CNM^{2})$. This can be alleviated by
sharing $K_{\nu}$ and $\mathbf{Z}$ across \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s, resulting in
$\mathcal{O}(M^{3}+CNM^{2})$, at the cost of limiting expressiveness, as we'll show. \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{c}{{\smaller ETGP}}{{c}}ost is always $\mathcal{O}(M^{3}+NM^{2})$ (without considering
the \lx@acro@@@def{\smaller NN}{\smaller NN}{'}{{\smaller NN}}{{'}}{}s computations, which for the architecture presented is often much faster and can be done in parallel to \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} operations).
\par\par\@@numbered@section{section}{toc}{Related Work}
\par On the non-stationary side, the traditional approach is to use non-stationary covariance functions such as the Neural
Network \cite[citep]{[\@@bibref{Number}{NNetKernelWill}{}{}]} or the Arcosine
\cite[citep]{[\@@bibref{Number}{Arcoskernel}{}{}]}. Our experiments, however, show
that \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{p}{{\smaller ETGP}}{{p}}rovides superior results in the multi-class setting when
compared to a method using these kernels. One can also make stationary
kernels non-stationary by making the parameters of the kernel depend
on the input \cite[citep]{[\@@bibref{Number}{NScovheinonen16}{}{}]}. However, the work in \cite[citep]{[\@@bibref{Number}{NScovheinonen16}{}{}]} is
limited to small datasets since it does not consider sparse \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s and
it relies on Hamilton Monte Carlo for approximate inference, which is
computationally expensive. Nevertheless, a sparse approach would require a \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} per kernel hyperparameter which can lead to a big number of \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s for high $d$. Another approach to obtain non-stationary processes
considers stochastic processes mixing using hierarchical models \cite[citep]{[\@@bibref{Number}{KangruiNSNS}{}{}]} or by placing \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s over the mixing matrix entries, achieving input-dependent length scales and
amplitudes \cite[citep]{[\@@bibref{Number}{GPRNwilson}{}{}]}. These works either don't scale for high $C$ \cite[citep]{[\@@bibref{Number}{GPRNwilson}{}{}]} or require domain knowledge to avoid misspecification \cite[citep]{[\@@bibref{Number}{KangruiNSNS}{}{}]}.
\par Non-stationarity can also be obtained by warping the input
space using a non-linear transformation before introducing the data into the
kernel \cite[citep]{[\@@bibref{Number}{sampson1992nonparametric,Schmidt00bayesianinference,manifold_gp_calandra:2016,deep_kernel_wilson:2016}{}{}]}.
These methods, however, either run the risk of over-fitting the observed data, as
a consequence of not regularizing the parameters of the non-linear transformation nor
using a fully Bayesian approach, or either do not scale to large datasets.
\par One can also use more sophisticated processes such as the
\lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} Product Model \cite[citep]{[\@@bibref{Number}{GPPM}{}{}]}, \lx@acro@@@def{\smaller DGP}{\smaller DGP}{}{{\smaller DGP}}{{}}s \cite[citep]{[\@@bibref{Number}{DGP_seminal}{}{}]} or \lx@acro@@@def{\smaller TGP}{\smaller TGP}{}{{\smaller TGP}}{{}}s
\cite[citep]{[\@@bibref{Number}{TGP_maronas}{}{}]} to achieve non-stationarity. The \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} Product Model, however, does not
scale to large datasets. \lx@acro@@@def{\smaller DGP}{\smaller DGP}{}{{\smaller DGP}}{{}}s have been shown to give similar results to those
of \lx@acro@@@def{\smaller TGP}{\smaller TGP}{}{{\smaller TGP}}{{}}s. However, \lx@acro@@@def{\smaller TGP}{\smaller TGP}{}{{\smaller TGP}}{{}}s have a lower computational cost than \lx@acro@@@def{\smaller DGP}{\smaller DGP}{}{{\smaller DGP}}{{}}s and slightly higher than \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s.
Therefore, the proposed method, \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{,}{{\smaller ETGP}}{{,}} is expected to be faster than \lx@acro@@@def{\smaller TGP}{\smaller TGP}{}{{\smaller TGP}}{{}}s and also faster than
\lx@acro@@@def{\smaller DGP}{\smaller DGP}{}{{\smaller DGP}}{{}}s, in consequence.
\par On the dependence point of view, several approaches have been considered, which
range from using process convolutions \cite[citep]{[\@@bibref{Number}{DependentGP}{}{}]} to mix latent
\lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s via a mixing matrix \cite[citep]{[\@@bibref{Number}{LMCReview}{}{}]} whose entries can be parameterized
by a \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} \cite[citep]{[\@@bibref{Number}{GPRNwilson}{}{}]}. More recently, \cite[citep]{[\@@bibref{Number}{JankowiakMOGP}{}{}]} extends
Multi-output \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s \cite[citep]{[\@@bibref{Number}{LMCReview}{}{}]}, Gaussian Process Regression Networks
\cite[citep]{[\@@bibref{Number}{GPRNwilson}{}{}]} and \lx@acro@@@def{\smaller DGP}{\smaller DGP}{\cite[citep]{[\@@bibref{Number}{}{}{}]}}{{\smaller DGP}}{{\cite[citep]{[\@@bibref{Number}{}{}{}}{}{}]}}{DGP_seminal} by using \lx@acro@@@def{\smaller NN}{\smaller NN}{}{{\smaller NN}}{{}}s to replace
different building blocks of these methods. Since the computational
cost of considering several \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s for inference is high
(not necessarily for multi-class learning),
several methods have tried to alleviate this cost by, \emph{e.g.}, using sparse methods
\cite[citep]{[\@@bibref{Number}{SparseConvolvedGP}{}{}]} or more recently by assuming that the data
lives around a linear subspace and then exploit a low-rank structure of
the covariance matrix \cite[citep]{[\@@bibref{Number}{ScalableMOGPBruinsma}{}{}]}. All these works, however,
use several \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s for modeling the data, unlike the proposed method \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{,}{{\smaller ETGP}}{{,}}
and are hence expected to be more expensive.

\par\par\par\@@numbered@section{subsection}{toc}{Fewer inducing points act as a regularizer}
\par In \cite[citep]{[\@@bibref{Number}{TGP_maronas}{}{}]} it is showed that \lx@acro@@@def{\smaller TGP}{\smaller TGP}{}{{\smaller TGP}}{{}}s could match
\lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s performance in regression problems using $20$ times less inducing

also as a regularizer, since the \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}} posterior is expected to parameterize smoother
functions in that case. With this goal, we report results for \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{u}{{\smaller ETGP}}{{u}}sing $50$ and $100$ inducing
points, see Fig. \ref{fig:less_inducings}. We observed that
\lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{g}{{\smaller ETGP}}{{g}}ets regularized when using fewer inducing
points. In {vowel} it improves results, and matches \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s performance

\par\@@numbered@section{section}{toc}{Conclusions and future work}
\par We have introduced the Efficient Transformed Gaussian Process (\lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{)}{{\smaller ETGP}}{{)}}, as a way of
creating $C$ dependent non-stationary stochastic processes in an efficient way.
For this, a single initial \lx@acro@@@def{\smaller GP}{\smaller GP}{i}{{\smaller GP}}{{i}}s transformed $C$ times. This has the benefit
of reducing the computational cost while providing enough model flexibility to
learn complex tasks. We have provided an efficient training algorithm for \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{b}{{\smaller ETGP}}{{b}}ased
on variational inference. This method has been evaluated in the context of multi-class
classification. Our results show that \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{}{{\smaller ETGP}}{{}} is competitive or even better than
typical sparse \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s, at a lower computational cost. A limitation of \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{}{{\smaller ETGP}}{{}} is,
however, that it leads to a model that is more difficult to interpret than \lx@acro@@@def{\smaller SVGP}{\smaller SVGP}{}{{\smaller SVGP}}{{}}s
as a consequence of the non-linear transformations, although some flows allow controlling the moments of the induced distributions \cite[citep]{[\@@bibref{Number}{compositionally_warped_gp_rios:2019}{}{}]}.
Future work can focus
on extending \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{t}{{\smaller ETGP}}{{t}}o multi-task and multi-label problems, where a large
number of processes is also needed, and its use in a deep kernel learning
framework \cite[citep]{[\@@bibref{Number}{deep_kernel_wilson:2016}{}{}]}. Also, an analysis of how the dependencies are modeled by sharing the copula of the base \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}, including how additional dependencies can be gained by mixing \lx@acro@@@def{\smaller ETGP}{\smaller ETGP}{}{{\smaller ETGP}}{{}}s with a mixing matrix. The use of concrete dropout and using \lx@acro@@@def{\smaller GP}{\smaller GP}{}{{\smaller GP}}{{}}s instead of \lx@acro@@@def{\smaller NN}{\smaller NN}{}{{\smaller NN}}{{}}s to parameterize the flows are alternatives to improve different aspects of the Bayesian nature of the flow such as computational performance, well-specified Bayesian priors and epistemic uncertainty.
