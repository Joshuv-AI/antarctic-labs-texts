Meromorphic functions on annuli sharing finite sets with truncated multiplicity
Si Duc Quang

Abstract
. The purpose of this paper has twofold. The first is to establish a second main theorem for meromorphic functions on annuli and meromorphic function targets (may not be small functions) with truncated counting functions (truncation level 1) and with a detailed estimate for the error term. The second is to show that if the polynomial P S ( w ) = ( w − a 1 ) ⋯ ( w − a q ) P_{S}(w)=(w-a_{1})\cdots(w-a_{q}) is a uniqueness polynomial for admissible meromorphic functions on an annulus 𝔸 ⁡ ( R 0 ) {\mathbb{A}}(R_{0}) such that P S ′ ​ ( w ) P^{\prime}_{S}(w) has exactly k k distinct zeros and q > ( 5 ​ k + 7 ) ​ ℓ 2 ​ ℓ − 175 q>\frac{(5k+7)\ell}{2\ell-175} , then the set S = { a 1 , … , a q } S=\{a_{1},\ldots,a_{q}\} is a finite range set with truncation level ℓ \ell for admissible meromorphic functions on 𝔸 ⁡ ( R 0 ) {\mathbb{A}}(R_{0}) . This result extends the previous result on the finite range set (with truncation level ℓ = ∞ \ell=\infty ) for holomorphic functions on ℂ {\mathbb{C}} of H. Fujimoto.

1.
Introduction

A nonconstant monic polynomial
P(w)
is called a uniqueness polynomial for meromorphic functions (or holomorphic functions) if, for any nonconstant
meromorphic functions (or holomorphic functions)
f
and
g
on
{\mathbb{C}}
, the equation
P(f)=cP(g)
implies
f=g
, where
c
is a nonzero constant which possibly depends on
f
and
g
.
A finite subset
S
of
{\mathbb{C}}
is said to be a unique range set for meromorphic functions (resp. holomorphic functions) if
f^{*}(S)=g^{*}(S)
implies
f=g
for arbitrary nonconstant meromorphic functions (resp. holomorphic functions)
f
and
g
on
{\mathbb{C}}
, where
f^{*}(S)
and
g^{*}(S)
denote the pull-back divisors of
S
. For
S=\{a_{1},\ldots,a_{q}\}
, we consider the polynomial

(1.1)

\displaystyle P_{S}(w)=(w-a_{1})\cdots(w-a_{q}).

Hence, if
S
is a unique range set for meromorphic functions (resp. holomorphic functions) then
P_{S}(w)
is a uniqueness polynomial for meromorphic functions (resp. holomorphic functions).

In
[
1
]
, Fujimoto extended the notion of the unique range set to the following.

Definition A.

A finite subset
S
of
{\mathbb{C}}
is called a finite range set for holomorphic functions if, for any given nonconstant holomorphic function
g
, there exist only finitely many nonconstant holomorphic functions
f
such that
f^{*}(S)=g^{*}(S)
.

With the above definitions, Fujimoto proved a sufficient condition for a set to be a finite range set for holomorphic functions on
{\mathbb{C}}
as follows.

Theorem B.

Take a finite set
S=\{a_{1},\ldots,a_{q}\}
and assume that, for the polynomial
P_{S}(\omega)
defined by (
1.1
),
P^{\prime}_{S}(w)
has exactly
k
distinct zeros. If
P_{S}(w)
is a uniqueness polynomial for holomorphic functions and
q>k+2
, then
S
is a finite range set for holomorphic functions. More precisely, for an arbitrarily given nonconstant holomorphic function
g
, there exist at most
\frac{2q-2}{q-k-2}
holomorphic functions
f
such that
f^{*}(S)=g^{*}(S)
.

Our purpose in this paper is to extend the result of Fujimoto to the case where the meromorphic functions (not only holomorphic) are defined only on annuli and the condition
f^{*}(S)=g^{*}(S)
is replaced by a more general condition that
f
and
g
share the finite set
S
with multiplicity truncated by a certain level. In order to state our result, we give the following definition.

For
0<R_{0}\leq+\infty
, we set an annulus
\mathbb{A}(R_{0})=\{z\in{\mathbb{C}};\frac{1}{R_{0}}<|z|<R_{0}\}
.

Definition 1.2
.

Let
S=\{a_{1},\ldots,a_{q}\}
be a set of distinct values in
{\mathbb{C}}
and
\ell
be a positive integer (may be
\ell=+\infty
). Two admissible meromorphic functions
f
and
g
on
{\mathbb{A}}(R_{0})
are said to share
S
with multiplicity truncated to level
\ell
if

\sum_{i=1}^{q}\min\{\ell,\nu_{f-a_{i}}\}=\sum_{i=1}^{q}\min\{\ell,\nu_{g-a_{i}}\}.

The set
S
is said to be a finite range set with the truncation level
\ell
for admissible meromorphic functions on
{\mathbb{A}}(R_{0})
if for an arbitrarily given admissible meromorphic function
g
on
{\mathbb{A}}(R_{0})
, there exist finitely many admissible meromorphic functions
f
on
{\mathbb{A}}(R_{0})
only such that
f
and
g
share
S
with multiplicity truncated to level
\ell
.

Here, a meromorphic function
f
on
{\mathbb{A}}(R_{0})
is said to be admissible if it satisfies

{\mathrel{\mathop{{\mathrm{limsup}}}\limits_{{r\longrightarrow+\infty}}}}\dfrac{T_{0}(r,f)}{\log r}=+\infty\text{ in the case }R_{0}=+\infty

or

{\mathrel{\mathop{{\mathrm{limsup}}}\limits_{{r\longrightarrow R_{0}^{-}}}}}\dfrac{T_{0}(r,f)}{-\log(R_{0}-r)}=+\infty\text{ in the case }1<R_{0}<+\infty,

where
T_{0}(r,f)
denotes the characteristic function of
f
, which is defined in Section 2.
Hence, the condition that
f
and
g
share
S
with multiplicity truncated to level
\ell=+\infty
is equivalent to the condition
f^{*}(S)=g^{*}(S)
in the sense of divisors. The set
S
is said to be a finite range set for admissible meromorphic functions on
{\mathbb{A}}(R_{0})
if it is a finite range set with the truncation level
+\infty
for admissible meromorphic functions on
{\mathbb{A}}(R_{0})
.

Our main result is stated as follows.

Theorem 1.3
.

Take a finite set
S=\{a_{1},\ldots,a_{q}\}
of
q
distinct values in
{\mathbb{C}}
and assume that, for the polynomial
P_{S}(\omega)
defined by (
1.1
),
P^{\prime}_{S}(w)
has exactly
k
distinct zeros. Let
\ell
be a positive integer (may be
\ell=+\infty
). If
P_{S}(w)
is a uniqueness polynomial for admissible meromorphic functions on an annulus
{\mathbb{A}}(R_{0})
and
q>\frac{(5k+7)\ell}{2\ell-175}
, then
S
is a finite range set with truncation
\ell
for admissible meromorphic functions on
{\mathbb{A}}(R_{0})
. More precisely, for an arbitrarily given admissible meromorphic function
g
on
{\mathbb{A}}(R_{0})
, there exist at most four admissible meromorphic functions
f
on
{\mathbb{A}}(R_{0})
such that
f
and
g
share the set
S
with multiplicity truncated to level
\ell
.

Here, we would like emphasize that the proof of Fujimoto for Theorem B is based on the sharp second main theorem for meromorphic functions and small functions on
{\mathbb{C}}
with counting functions truncated to level
1
of Yamanoi
[
6
, Theorem 1]
. By the assumption of Theorem B, Fujimoto assumed that
P_{S}(f_{i})=e^{\varphi_{i}}P_{S}(g)
with an holomorphic function
\varphi_{i}
for each holomorphic function
f_{i}
such that
f_{i}^{*}(S)=g^{*}(S)
and
\varphi^{\prime}_{i}
is a small function, and then he applied the second main theorem of Yamanoi. However, in Theorem
1.3
, the such holomorphic function
\varphi_{i}
does not exist. Therefore we have to establish a new second main theorem for meromorphic functions with meromorphic function targets (may not be small) on annuli with a more detailed error term estimate. Namely, we will prove the following second main theorem.

Theorem 1.4
.

Let
g
be a nonconstant meromorphic function on
{\mathbb{A}}(R_{0})
. Let
a_{1},\dots,a_{q}
be
q\ (q\geq 5)
distinct meromorphic functions (may be equal to
\infty
). We have

\frac{2q}{5}T_{0}(r,g)\leq\sum_{i=1}^{q}\overline{N}_{0}(r,\nu^{0}_{g-a_{i}})+35\sum_{i=1}^{q}T_{0}(r,a_{i})+S(r)\ (1\leq r<R_{0}),

where
S(r)=S_{g}(r)+\sum_{i=1}^{q}S_{a_{i}}(r)
(here we set
T_{0}(r,a_{i})=0
if
a_{i}\equiv\infty
).

Here,
\overline{N}_{0}(r,\nu)
denotes the counting function without multiplicity of the divisor
\nu
and the quantity
S_{f}(r)
is the small term with respect to the meromorphic function
f
. These notions are defined in Section 2.

We note that, the weak version of this theorem for the case of small functions
a_{i}\ (1\leq i\leq 5)
is initially stated in
[
5
]
without proving (by repeating the method in
[
7
]
). Then the proof in this paper will also provide a detailed proof for that weak version, although the proof is based on the method of the proofs of Lemma 3.1 and Lemma 3.2 in
[
7
]
.

Finally, we remark that if
\ell=+\infty
then the assumption of Theorem
1.3
is fulfilled with
q>\frac{5k+7}{2}
. Unfortunately, this number is bigger than the number
k+2
in Theorem B of Fujimoto. Therefore, “
how to find the optimal number
k
in our situation
” is still an open interesting question.

2.
Some definitions and results from Nevanlinna theory on annuli

In this section, we will recall some basic notions of Nevanlinna theory for meromorphic functions on annuli from
[
3
]
(see also
[
2
]
).

For a divisor
\nu
on
{\mathbb{A}}(R_{0})
, which we may regard as a function on
{\mathbb{A}}(R_{0})
with values in
\mathbb{Z}
whose support is a discrete subset of
{\mathbb{A}}(R_{0}),
and for a positive integer
M
(may be
M=+\infty
), we define the counting function of
\nu
as follows

\displaystyle n_{0}^{[M]}(t)

\displaystyle=\begin{cases}\sum\limits_{1\leq|z|\leq t}\min\{M,\nu(z)\}&\text{ if }1\leq t<R_{0}\\
\sum\limits_{t\leq|z|<1}\min\{M,\nu(z)\}&\text{ if }\dfrac{1}{R_{0}}<t<1\end{cases}

\displaystyle\text{ and }N_{0}^{[M]}(r,\nu)

\displaystyle=\int\limits_{\frac{1}{r}}^{1}\dfrac{n_{0}^{[M]}(t)}{t}dt+\int\limits_{1}^{r}\dfrac{n_{0}^{[M]}(t)}{t}dt\quad(1<r<\infty).

For brevity we set
N_{0}(r,\nu)=N_{0}^{[+\infty]}(r,\nu)
and
\overline{N}_{0}(r,\nu)=N_{0}^{[1]}(r,\nu)
.

For a meromorphic function
\varphi
, we define

•

\nu^{0}_{\varphi}
(resp.
\nu^{\infty}_{\varphi}
) the divisor of zeros (resp. divisor of poles) of
\varphi
,

•

\nu_{\varphi}=\nu^{0}_{\varphi}-\nu^{\infty}_{\varphi},

•

\nu^{0}_{\varphi,\geq k}=\max\{k,\nu^{0}_{\varphi}\}
.

Note that, by Jensen’s formula we have

N_{0}(r,\nu^{0}_{\varphi})-N_{0}(r,\nu^{\infty}_{\varphi})=\sum_{t=1/r,r}\dfrac{1}{2\pi}\int\limits_{0}^{2\pi}\log|\varphi(te^{i\theta})|d\theta-\dfrac{1}{\pi}\int\limits_{0}^{2\pi}\log|\varphi(e^{i\theta})|d\theta.

Let
f
be a nonconstant meromorphic function on
{\mathbb{A}}(R)
. The proximity function of
f
is defined by

m_{0}(r,f)=\sum_{t=1/r,r}\dfrac{1}{2\pi}\int\limits_{0}^{2\pi}\log^{+}|f(te^{i\theta})|d\theta-\dfrac{1}{\pi}\int\limits_{0}^{2\pi}\log^{+}|f(e^{i\theta})|d\theta

and the characteristic function of
f
is defined by

T_{0}(r,f)=m_{0}(r,f)+N_{0}(r,\nu^{\infty}_{f}).

Now, we write
f=\frac{f_{0}}{f_{1}}
where
f_{0},f_{1}
are two holomorphic functions without common zero. It is well-known that

\displaystyle T_{0}(r,f)=\sum_{t=1/r,r}\dfrac{1}{2\pi}\int\limits_{0}^{2\pi}\log\|f(te^{i\theta})\|d\theta+O(1),

where
\|f\|=\sqrt{|f_{0}|^{2}+|f_{1}|^{2}}
and
O(1)
is a bounded term depending on the choice of
f_{0},f_{1}
.

Throughout this paper, we denote by
S_{f}(r)
the quantities satisfying:

\bullet
in the case
R_{0}=+\infty
,

S_{f}(r)=O(\log(rT_{0}(r,f)))

for all
r\in(1,+\infty)
outside an exceptional set
\Delta_{R}
with
\int_{\Delta_{R}}r^{\lambda-1}dr<+\infty
for some
\lambda>0
,

\bullet
in the case
R_{0}<+\infty
,

S_{f}(r)=O\left(\log\biggl(\dfrac{T_{0}(r,f)}{R_{0}-r}\biggl)\right)\text{ as }r\longrightarrow R_{0}

for all
r\in(1,R_{0})
outside an exceptional set
\Delta^{\prime}_{R}
with
\int_{\Delta^{\prime}_{R}}\frac{dr}{(R_{0}-r)^{\lambda+1}}<+\infty
for some
\lambda>0
.

Thus, for an admissible meromorphic function
f
on
{\mathbb{A}}(R_{0})
, we have
S_{f}(r)=o(T_{0}(r,f))
as
r\longrightarrow R_{0}
for all
r\in(1,R_{0})
outside the set
\Delta_{R}
or the set
\Delta^{\prime}_{R}
mentioned above, respectively (cf.
[
2
]
).

A meromorphic function
a
on
{\mathbb{A}}(R_{0})
is said to be small with respect to
f
if

T_{0}(r,a)=S_{f}(r).

Lemma 2.1

(Lemma on logarithmic derivatives
[
2
,
3
]
)
.

Let
f
be a nonzero meromorphic function on
{\mathbb{A}}(R_{0})
. Then for each
k\in\mathbb{N}
we have

m_{0}\left(r,\dfrac{f^{(k)}}{f}\right)=S_{f}(r)\ (1\leq r<R_{0}).

Theorem 2.2

(Second main theorem
[
2
]
)
.

Let
f
be a nonconstant meromorphic function on
{\mathbb{A}}(R_{0})
. Let
a_{1},\dots,a_{q}
be
q
distinct values in
{\mathbb{C}}\cup\{\infty\}
. We have

(q-2)T_{0}(r,f)\leq\sum_{i=1}^{q}\overline{N}_{0}(r,\nu^{0}_{f-a_{i}})+S_{f}(r)\ (1\leq r<R_{0}).

3.
Uniqueness theorem for meromorphic functions sharing finite sets

Before proving Theorem
1.3
, we first prove Theorem
1.4
. In order to prove Theorem
1.4
, we need the following lemmas.

Lemma 3.1
.

Let
f_{1},f_{2}
be two meromorphic functions on
{\mathbb{A}}(R_{0})
,
a_{1},a_{2},a_{3}
be three distinct meromorphic functions on
{\mathbb{A}}(R_{0})
(being not equal to
\infty
) such that
f_{2}=(f_{1}-a_{1})/(f_{1}-a_{2}).
Then we have:

\displaystyle\mathrm{(a)}\

\displaystyle T_{0}(r,f_{2})\geq T_{0}(r,f_{1})-\sum_{i=1}^{2}T_{0}(r,a_{i})+O(1),

\displaystyle\mathrm{(b)}\

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f_{2}})+\overline{N}_{0}(r,\nu^{0}_{f_{2}-1})+\overline{N}_{0}(r,\nu^{\infty}_{f_{2}})

\displaystyle\leq\overline{N}_{0}(r,\nu^{\infty}_{f_{1}})+\sum_{i=1}^{2}\left(\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+2T_{0}(r,a_{i})\right)+O(1).

Moreover, if we set
b=\dfrac{a_{3}-a_{1}}{a_{3}-a_{2}}
then

(c)\ \overline{N}_{0}(r,\nu^{0}_{f_{2}-b})\leq\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{3}})+T_{0}(r,a_{1})+2T_{0}(r,a_{2})+T_{0}(r,a_{3})+O(1).

Proof.

We write
f_{i}=\frac{f_{i0}}{f_{i1}}
, where
f_{i0}
and
f_{i1}
are holomorphic functions defined on
{\mathbb{A}}(R_{0})
without common zeros, for
i=1,2
. Similarly, we write
a_{i}=\frac{a_{i0}}{a_{i1}}
, where
a_{i0}
and
a_{i1}
are holomorphic functions defined on
{\mathbb{A}}(R_{0})
without common zeros, for
i=1,2,3
. We have

\displaystyle f_{1}=\frac{a_{1}-a_{2}f_{2}}{1-f_{2}},\text{i.e., }\frac{f_{10}}{f_{11}}=\frac{f_{21}a_{10}a_{21}-f_{20}a_{11}a_{20}}{f_{21}a_{11}a_{21}-f_{20}a_{11}a_{21}}.

Then, there is a holomorphic function
h
and a positive constant
C
such that

\displaystyle hf_{10}=f_{21}a_{10}a_{21}-f_{20}a_{11}a_{20},

\displaystyle hf_{11}=f_{21}a_{11}a_{21}-f_{20}a_{11}a_{21}

and

\displaystyle|h|\cdot\|f_{1}\|\leq C\|f_{2}\|\cdot\|a_{1}\|\cdot\|a_{2}\|.

This implies that

T_{0}(r,f_{1})+N_{0}(r,h)\leq T_{0}(r,f_{2})+T_{0}(r,a_{1})+T_{0}(r,a_{2})+O(1).

Therefore,

T_{0}(r,f_{2})\geq T_{0}(r,f_{1})-T_{0}(r,a_{1})-T_{0}(r,a_{2})+O(1)

and we get the inequality (a).

From the assumption
f_{2}=\frac{f_{1}-a_{1}}{f_{1}-a_{2}}
, we easily have

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f_{2}})

\displaystyle+\overline{N}_{0}(r,\nu^{0}_{f_{2}-1})+\overline{N}_{0}(r,\nu^{\infty}_{f_{2}})

\displaystyle\leq\overline{N}_{0}(r,\nu^{\infty}_{f_{1}})+\sum_{i=1}^{2}\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+(\overline{N}_{0}(r,\nu^{0}_{a_{1}-a_{2}})+\overline{N}_{0}(r,\nu^{\infty}_{a_{1}})+\overline{N}_{0}(r,\nu^{\infty}_{a_{2}}))

\displaystyle\leq\overline{N}_{0}(r,\nu^{\infty}_{f_{1}})+\sum_{i=1}^{2}\left(\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+2T_{0}(r,a_{i})\right)+O(1).

Then we have the inequality (b).

Similarly, we have

\dfrac{1}{f_{2}-b}=\dfrac{(a_{3}-a_{2})}{(a_{1}-a_{2})}\cdot\left(1+\frac{a_{3}-a_{2}}{f_{1}-a_{3}}\right).

This implies that

\min\{1,\nu^{0}_{f_{2}-b}\}\leq\min\{1,\nu^{\infty}_{a_{3}-a_{2}}+\nu^{0}_{a_{1}-a_{2}}+\nu^{0}_{f_{1}-a_{3}}\}.

It yields that

\overline{N}_{0}(r,\nu^{0}_{f_{2}-b})\leq\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{3}})+T_{0}(r,a_{1})+2T_{0}(r,a_{2})+T_{0}(r,a_{3}),

and we get the inequality (c). This completes the proof of the lemma.
∎

Lemma 3.2
.

Let
f_{1},f_{2}
be two meromorphic functions on
{\mathbb{A}}(R_{0})
and let
a_{1},a_{2},a_{3},a_{4}
be four distinct meromorphic functions on
{\mathbb{A}}(R_{0})
such that

f_{2}=\frac{f_{1}-a_{1}}{f_{1}-a_{2}}\cdot\frac{a_{3}-a_{2}}{a_{3}-a_{1}}.

Then we have:

\displaystyle\mathrm{(a)}\

\displaystyle T_{0}(r,f_{2})\geq T_{0}(r,f_{1})-\sum_{i=1}^{3}T_{0}(r,a_{i})+O(1),

\displaystyle\mathrm{(b)}\

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f_{2}})+\overline{N}_{0}(r,\nu^{0}_{f_{2}-1})+\overline{N}_{0}(r,\nu^{\infty}_{f_{2}})

\displaystyle\hskip 30.0pt\leq\sum_{i=1}^{3}\left(\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+3T_{0}(r,a_{i})\right)+O(1).

Moreover, if we set
b=\dfrac{a_{4}-a_{1}}{a_{4}-a_{2}}\cdot\dfrac{a_{3}-a_{2}}{a_{3}-a_{1}}
then

\mathrm{(c)}\ \overline{N}_{0}(r,\nu^{0}_{f_{2}-b})\leq\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{4}})+2T_{0}(r,a_{1})+3T_{0}(r,a_{2})+2T_{0}(r,a_{3})+T_{0}(r,a_{4}).

Proof.

We write
f_{i}=\frac{f_{i0}}{f_{i1}}
and
a_{i}=\frac{a_{i0}}{a_{i1}}\ (1\leq i\leq 4)
similarly as in the proof of Lemma
3.1
.
By a simple computation, we have

\displaystyle f_{1}=\frac{a_{1}(a_{3}-a_{2})-a_{2}(a_{3}-a_{1})f_{2}}{(a_{3}-a_{2})-(a_{3}-a_{1})f_{2}},

i.e.,

\displaystyle\frac{f_{10}}{f_{11}}=\frac{f_{21}a_{10}(a_{21}a_{30}-a_{20}a_{31})-f_{20}a_{20}(a_{11}a_{30}-a_{10}a_{31})}{f_{21}a_{11}(a_{21}a_{30}-a_{20}a_{31})-f_{20}a_{21}(a_{11}a_{30}-a_{10}a_{31})}.

Then, there is a holomorphic function
h
and a positive constant
C
such that

\displaystyle hf_{10}=f_{21}a_{10}(a_{21}a_{30}-a_{20}a_{31})-f_{20}a_{20}(a_{11}a_{30}-a_{10}a_{31}),

\displaystyle hf_{11}=f_{21}a_{11}(a_{21}a_{30}-a_{20}a_{31})-f_{20}a_{21}(a_{11}a_{30}-a_{10}a_{31})

and

\displaystyle|h|\cdot\|f_{1}\|\leq C\|f_{2}\|\cdot\|a_{1}\|\cdot\|a_{2}\|\cdot\|a_{3}\|.

This implies that

T_{0}(r,f_{1})+N_{0}(r,h)\leq T_{0}(r,f_{2})+\sum_{i=1}^{3}T_{0}(r,a_{i})+O(1).

Therefore,

T_{0}(r,f_{2})\geq T_{0}(r,f_{1})-\sum_{i=1}^{3}T_{0}(r,a_{i})+O(1),

and we get the inequality (a).

It is also easy to see that

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f_{2}})

\displaystyle+\overline{N}_{0}(r,\nu^{0}_{f_{2}-1})+\overline{N}_{0}(r,\nu^{\infty}_{f_{2}})

\displaystyle\leq\sum_{i=1}^{3}\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+\sum_{1\leq i<j\leq 3}\overline{N}_{0}(r,\nu^{0}_{a_{i}-a_{j}})+\sum_{i=1}^{3}\overline{N}_{0}(r,\nu^{\infty}_{a_{i}})

\displaystyle\leq\sum_{i=1}^{3}\left(\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{i}})+3T_{0}(r,a_{i})\right)+O(1).

Then we have the inequality (b).

On the other hand, we have

\dfrac{1}{f_{2}-b}=\dfrac{(a_{3}-a_{1})(a_{4}-a_{2})}{(a_{3}-a_{2})(a_{1}-a_{2})}\cdot\left(1+\frac{a_{4}-a_{2}}{f_{1}-a_{4}}\right).

This implies that

\min\{1,\nu^{0}_{f_{2}-b}\}\leq\min\{1,\nu^{\infty}_{a_{3}-a_{1}}+\nu^{\infty}_{a_{4}-a_{2}}+\nu^{0}_{a_{3}-a_{2}}+\nu^{0}_{a_{1}-a_{2}}+\nu^{0}_{f_{1}-a_{4}}\}.

It yields that

\overline{N}_{0}(r,\nu^{0}_{f_{2}-b})\leq\overline{N}_{0}(r,\nu^{0}_{f_{1}-a_{4}})+2T_{0}(r,a_{1})+3T_{0}(r,a_{2})+2T_{0}(r,a_{3})+T_{0}(r,a_{4}).

This completes the proof of the lemma.
∎

The proof of Theorem
1.4
is a straightforward deduction from the next lemma.

Lemma 3.3
.

Let
g
be a nonconstant meromorphic function on
{\mathbb{A}}(R_{0})
. Let
a_{1},\dots,a_{5}
be five distinct meromorphic functions (may be equal to
\infty
). We have

2T_{0}(r,g)\leq\sum_{i=1}^{5}\overline{N}_{0}(r,\nu^{0}_{g-a_{i}})+35\sum_{i=1}^{5}T_{0}(r,a_{i})+S(r)\ (1\leq r<R_{0}),

where
S(r)=S_{g}(r)+\sum_{i=1}^{5}S_{a_{i}}(r)
.

Then, in order to prove Theorem
1.4
, it is sufficient to prove Lemma
3.3
.

Proof.

We split the proof of the lemma into two parts.

Part A.
We first consider the case where
a_{i}\not\equiv\infty
for all
i=1,\ldots,5
. We set

f=\frac{g-a_{2}}{g-a_{1}}\cdot\frac{a_{3}-a_{1}}{a_{3}-a_{2}},b_{1}=\frac{a_{4}-a_{2}}{a_{4}-a_{1}}\cdot\frac{a_{3}-a_{1}}{a_{3}-a_{2}},b_{2}=\frac{a_{5}-a_{2}}{a_{5}-a_{1}}\cdot\frac{a_{3}-a_{1}}{a_{3}-a_{2}},b_{3}=0\text{ and }b_{4}=1.

By Lemma
3.2
, we have

(3.4)

\displaystyle T_{0}(r,g)

\displaystyle\leq T_{0}(r,f)+\sum_{i=1}^{3}T_{0}(r,a_{i})+O(1),

(3.5)

\displaystyle T_{0}(r,b_{1})

\displaystyle\leq\sum_{i=1}^{4}T_{0}(r,a_{i})+O(1),

(3.6)

\displaystyle T_{0}(r,b_{2})

\displaystyle\leq\sum_{i=1}^{3}T_{0}(r,a_{i})+T_{0}(r,a_{5})+O(1)

and

(3.7)

\displaystyle\begin{split}\overline{N}_{0}(r,\nu^{\infty}_{f})+\sum_{i=1}^{4}\overline{N}_{0}(r,\nu^{0}_{f-b_{i}})&\leq\sum_{i=1}^{5}\overline{N}_{0}(r,\nu^{0}_{g-a_{i}})+7T_{0}(r,a_{1})+9T_{0}(r,a_{2})\\
&+7T_{0}(r,a_{3})+T_{0}(r,a_{4})+T_{0}(r,a_{5})+O(1).\end{split}

We now prove the following claim.

Claim
3.8
.

2T_{0}(r,f)\leq\overline{N}_{0}(r,\nu^{\infty}_{f})+\sum_{i=1}^{4}\overline{N}_{0}(r,\nu^{0}_{f-b_{i}})+18\sum_{i=1,2}T_{0}(r,b_{i})+S(r).

Indeed, if
b_{1}
or
b_{2}
is constant then the claim directly follows from Theorem
2.2
.
Therefore, we may assume that both
b_{1}
and
b_{2}
are not constant. We define

(3.9)

F=\begin{vmatrix}ff^{\prime}&f^{\prime}&f^{2}-f\\
b_{1}b_{1}^{\prime}&b_{1}^{\prime}&b_{1}^{2}-b_{1}\\
b_{2}b_{2}^{\prime}&b_{2}^{\prime}&b_{2}^{2}-b_{2}\end{vmatrix}.

Consider the following two cases.

Case 1:
F(z)\equiv 0
. From (
3.9
) we get

(3.10)

\displaystyle\biggl(\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}\biggl)\biggl(\dfrac{f^{\prime}}{f-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}\biggl)\equiv\biggl(\dfrac{b_{1}^{\prime}}{b_{1}-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}\biggl)\biggl(\dfrac{f^{\prime}}{f}-\dfrac{b_{2}^{\prime}}{b_{2}}\biggl).

We distinguish the following four subcases.

Subcase 1:

\dfrac{b_{1}^{\prime}}{b_{1}}\equiv\dfrac{b_{2}^{\prime}}{b_{2}}.
We have
\dfrac{b_{1}^{\prime}}{b_{1}-1}\not\equiv\dfrac{b_{2}^{\prime}}{b_{2}-1}
, since otherwise
b_{1}
and
b_{2}
are constants. Therefore, from (
3.10
), we have
\dfrac{f^{\prime}}{f}\equiv\dfrac{b_{2}^{\prime}}{b_{2}}
, and hence
f=cb_{2}
with a constant
c
. This implies that
T_{0}(r,f)=T_{0}(r,b_{2})
and the claim is proved in this subcase.

Subcase 2:

\dfrac{b_{1}^{\prime}}{b_{1}-1}\equiv\dfrac{b_{2}^{\prime}}{b_{2}-1}.
By the same arguments as in Subcase 1, we get again the inequality of the claim in this subcase.

Subcase 3:

\dfrac{b_{1}^{\prime}}{b_{1}}\not\equiv\dfrac{b_{2}^{\prime}}{b_{2}},\dfrac{b_{1}^{\prime}}{b_{1}-1}\not\equiv\dfrac{b_{2}^{\prime}}{b_{2}-1},\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}\equiv\dfrac{b_{1}^{\prime}}{b_{1}-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}.
The identity (
3.10
) implies that

\dfrac{f^{\prime}}{f-1}-\dfrac{f^{\prime}}{f}\equiv\dfrac{b_{2}^{\prime}}{b_{2}-1}-\dfrac{b_{2}^{\prime}}{b_{2}}.

Then, we have

\dfrac{f-1}{f}\equiv c\cdot\dfrac{b_{2}-1}{b_{2}},

where
c
is a constant. Therefore
f=\frac{b_{2}}{(c-1)b_{2}-c}
, and hence
T_{0}(r,f)=T_{0}(r,b_{2})
. We get again the inequality of the claim in this subcase.

Subcase 4:

\dfrac{b_{1}^{\prime}}{b_{1}}\not\equiv\dfrac{b_{2}^{\prime}}{b_{2}},\dfrac{b_{1}^{\prime}}{b_{1}-1}\not\equiv\dfrac{b_{2}^{\prime}}{b_{2}-1},\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}\not\equiv\dfrac{b_{1}^{\prime}}{b_{1}-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}.
The identity (
3.10
) may be rewritten as

(3.11)

\displaystyle\biggl(\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}\biggl)\dfrac{f^{\prime}}{f-1}-\biggl(\dfrac{b_{1}^{\prime}}{b_{1}-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}\biggl)\dfrac{f^{\prime}}{f}\equiv\dfrac{b_{1}^{\prime}b_{2}^{\prime}}{b_{1}(b_{2}-1)}-\dfrac{b_{2}^{\prime}b_{1}^{\prime}}{b_{2}(b_{1}-1)}.

From (
3.11
), we see that each zero of
(f-1)
must be a zero or an
1
-point or a pole of
b_{j}\ (j=1,2)
or a zero of
\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}
. Therefore,

(3.12)

\displaystyle\min\{1,\nu^{0}_{f-1}\}\leq\sum_{i=1,2}\sum_{a=0,1,\infty}\min\{1,\nu^{0}_{b_{i}-a}\}+\min\left\{1,\nu^{0}_{\frac{b_{1}^{\prime}}{b_{1}}-\frac{b_{2}^{\prime}}{b_{2}}}\right\}.

Similarly, we have

(3.13)

\displaystyle\min\{1,\nu^{0}_{f}\}\leq\sum_{i=1,2}\sum_{a=0,1,\infty}\min\{1,\nu^{0}_{b_{i}-a}\}+\min\left\{1,\nu^{0}_{\frac{b_{1}^{\prime}}{b_{1}-1}-\frac{b_{2}^{\prime}}{b_{2}-1}}\right\}.

From (
3.11
), we also see that each pole of
f
must be a zero or an
1-
point or a pole of
b_{j}\ (j=1,2)
or a zero of
\biggl(\dfrac{b_{1}^{\prime}}{b_{1}}-\dfrac{b_{2}^{\prime}}{b_{2}}\biggl)-\biggl(\dfrac{b_{1}^{\prime}}{b_{1}-1}-\dfrac{b_{2}^{\prime}}{b_{2}-1}\biggl)
. Therefore, by the similar arguments, we have

(3.14)

\displaystyle\min\{1,\nu^{\infty}_{f}\}\leq\sum_{i=1,2}\sum_{a=0,1,\infty}\min\{1,\nu^{0}_{b_{i}-a}\}+\min\left\{1,\nu^{0}_{\bigl(\frac{b_{1}^{\prime}}{b_{1}}-\frac{b_{2}^{\prime}}{b_{2}}\bigl)-\bigl(\frac{b_{1}^{\prime}}{b_{1}-1}-\frac{b_{2}^{\prime}}{b_{2}-1}\bigl)}\right\}.

Combining (
3.12
), (
3.13
) and (
3.14
), we have

(3.15)

\displaystyle\begin{split}\sum_{a=0,1,\infty}\min\{1,\nu^{0}_{f-a}\}&\leq\sum_{i=1,2}\sum_{a=0,1,\infty}\min\{1,\nu^{0}_{b_{i}-a}\}+\min\bigl\{1,\nu^{0}_{\frac{b_{1}^{\prime}}{b_{1}}-\frac{b_{2}^{\prime}}{b_{2}}}\bigl\}\\
&+\min\bigl\{1,\nu^{0}_{\frac{b_{1}^{\prime}}{b_{1}-1}-\frac{b_{2}^{\prime}}{b_{2}-1}}\bigl\}+\min\bigl\{1,\nu^{0}_{\bigl(\frac{b_{1}^{\prime}}{b_{1}}-\frac{b_{2}^{\prime}}{b_{2}}\bigl)-\bigl(\frac{b_{1}^{\prime}}{b_{1}-1}-\frac{b_{2}^{\prime}}{b_{2}-1}\bigl)}\bigl\}.\end{split}

By Theorem
2.2
, we get

\displaystyle T_{0}(r,f)

\displaystyle\leq\overline{N}_{0}(r,\nu^{0}_{f})+\overline{N}_{0}(r,\nu^{0}_{f-1})+\overline{N}_{0}(r,\nu^{\infty}_{f})+S(r)

\displaystyle\leq 2\sum_{i=1}^{2}\left(T_{0}\left(r,\frac{b_{i}^{\prime}}{b_{i}}\right)+T_{0}\left(r,\frac{b_{i}^{\prime}}{b_{i}-1}\right)\right)+S(r)

\displaystyle\leq 2\sum_{i=1}^{2}\left(N_{0}\left(r,\nu^{\infty}_{\frac{b_{i}^{\prime}}{b_{i}}}\right)+N_{0}\left(r,\nu^{\infty}_{\frac{b_{i}^{\prime}}{b_{i}-1}}\right)\right)+S(r)

\displaystyle\leq 8T_{0}(r,b_{1})+8T_{0}(r,b_{2}).

Then, we have the desired inequality of the claim in this subcase.

Case 2:

F(z)\not\equiv 0
. For
t=r
or

, we set

\displaystyle\delta(z)

\displaystyle=\min\{1,|b_{1}(z)|,|b_{2}(z)|,|b_{1}(z)-1|,|b_{2}(z)-1|,|b_{1}(z)-b_{2}(z)|\},

\displaystyle\theta_{j}(t)

\displaystyle=\{\theta:|f(te^{i\theta})-b_{j}(te^{i\theta})|\leq\delta(te^{i\theta})\},(j=1,2),

\displaystyle\theta_{j}(t)

\displaystyle=\{\theta:|f(te^{i\theta})-b_{j}|\leq\delta(te^{i\theta})\},(j=3,4).

It is clear that the sets

(3.16)

\displaystyle\begin{split}\sum_{t=1/r,r}\dfrac{1}{2\pi}\int\limits_{0}^{2\pi}\log\dfrac{1}{\delta(te^{i\theta})}d\theta&\leq m_{0}\left(r,\dfrac{1}{b_{1}}\right)+m_{0}\left(r,\dfrac{1}{b_{2}}\right)+m_{0}\left(r,\dfrac{1}{b_{1}-1}\right)\\
&+m_{0}\left(r,\dfrac{1}{b_{2}-1}\right)+m_{0}\left(r,\dfrac{1}{b_{1}-b_{2}}\right)\\
&\leq T(r)+S(r)+O(1),\end{split}

We also see that

\displaystyle ff^{\prime}

\displaystyle=(f-b_{1})(f^{\prime}-b_{1}^{\prime})+b_{1}^{\prime}(f-b_{1})+b_{1}(f^{\prime}-b_{1}^{\prime})+b_{1}b_{1}^{\prime},

\displaystyle f^{\prime}

\displaystyle=(f^{\prime}-b_{1}^{\prime})+b_{1}^{\prime},

\displaystyle f^{2}-f

Substituting these functions (on the right hand side) into (
3.9
), by the properties of the Wronskian, we have

(3.17)

where

\displaystyle\varphi

\displaystyle=(f-b_{1})(f^{\prime}-b_{1}^{\prime})+b_{1}^{\prime}(f-b_{1})+b_{1}(f^{\prime}-b_{1}^{\prime}),

\displaystyle\psi

\displaystyle=(f-b_{1})^{2}+(2b_{1}-1)(f-b_{1}).

From (
3.17
) we see that each zero with multiplicity
p

(p>1)
of

which is neither a pole of
b_{1}
nor a pole of

with multiplicity at least

. Similarly, each zero with multiplicity
p

(p>1)

. Moreover, from (

p

(p>1)

F

(3.18)

\displaystyle\sum_{i=1}^{4}(N(r,\nu^{0}_{f-b_{i}})-\overline{N}_{0}(r,\nu^{0}_{f-b_{i}}))\leq N(r,\nu^{0}_{F}).

(3.19)

\displaystyle\begin{split}&\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}\left|\dfrac{F}{f-b_{1}}\right|d\theta\leq\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log\left(1+\left|\dfrac{F}{f-b_{1}}\right|\right)d\theta\\
&\leq\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log\left\{(1+|b_{1}^{\prime}|)(1+|b_{1}|)\left(1+\left|\frac{f^{\prime}-b_{1}^{\prime}}{f-b_{1}}\right|\right)\right\}d\theta\\
&\hskip 30.0pt+\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log\left\{(1+|b_{1}|)(1+|b_{1}^{\prime}|)\right\}d\theta\\
&\hskip 30.0pt+\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log\left\{(1+|b_{2}|)(1+|b_{2}^{\prime}|)\right\}d\theta+O(1)\\
&\leq m_{0}\left(r,\dfrac{f^{\prime}-b_{1}^{\prime}}{f-b_{1}}\right)+2m_{0}\left(r,\frac{b_{1}^{\prime}}{b_{1}}\right)+m_{0}\left(r,\frac{b_{2}^{\prime}}{b_{2}}\right)\\
&\hskip 30.0pt+4\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}|b_{1}|d\theta+2\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}|b_{2}|d\theta+O(1)\\
&\leq 4\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}|b_{1}|d\theta+2\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}|b_{2}|d\theta+S(r).\end{split}

Here, the second inequality comes from the fact that

(3.20)

\displaystyle\log^{+}|\det(x_{ij};1\leq i,j\leq 3)|\leq\sum_{i=1}^{3}\log^{+}\max\{|x_{ij}|;1\leq j\leq 3\}+O(1)

for every
(3\times 3)

Therefore, from (
3.16

(3.21)

\displaystyle\begin{split}&m_{0}\left(r,\dfrac{1}{f-b_{1}}\right)\leq\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{1}(t)}\log^{+}\left|\dfrac{1}{f-b_{1}}\right|d\theta+\dfrac{1}{2\pi}\int\limits_{0}^{2\pi}\log\dfrac{1}{\delta(re^{i\theta})}d\theta\\

(3.22)

\displaystyle\begin{split}m_{0}\left(r,\dfrac{1}{f-b_{2}}\right)&\leq\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{2}(t)}\biggl(\log^{+}\dfrac{1}{|F|}d\theta+2\log^{+}|b_{1}|+4\log^{+}|b_{2}|\biggl)d\theta\\
&+T(r)+S(r).\end{split}

On the other hand, for each

Similarly as above, for

(3.23)

\displaystyle\begin{split}m_{0}\left(r,\dfrac{1}{f-b_{j}}\right)&\leq\sum_{t=1/r,r}\frac{1}{2\pi}\int\limits_{\theta_{j}(t)}\biggl(\log^{+}\dfrac{1}{|F|}d\theta+2\log^{+}|b_{1}|+2\log^{+}|b_{2}|\biggl)d\theta\\
&+T(r)+S(r).\end{split}

Combining (

\displaystyle 4T_{0}(r,f)

\displaystyle\leq N_{0}(r,\nu^{0}_{f})+N_{0}(r,\nu^{0}_{f-1})+N_{0}(r,\nu^{0}_{f-b_{1}})+N_{0}(r,\nu^{0}_{f-b_{2}})-N(r,\nu^{0}_{F})

\displaystyle 2T_{0}(r,f)\leq

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f})+\overline{N}_{0}(r,\nu^{0}_{f-1})+\overline{N}_{0}(r,\nu^{\infty}_{f})+\overline{N}_{0}(r,\nu^{0}_{f-b_{1}})

\displaystyle+\overline{N}_{0}(r,\nu^{0}_{f-b_{2}})+18T_{0}(r,b_{1})+18T_{0}(r,b_{2})+S(r).

Proof of Theorem

on

g
share the set
S
with multiplicity truncated to level
\ell
, where
g=f_{1}
. We note that

P_{S}(w)=(w-a_{1})\cdots(w-a_{q}).

We set
\Psi_{i}:=P_{S}(f_{i})/P_{S}(g)\ (1\leq i\leq 5).

Claim
3.32
.

One has
T_{0}(r,f_{j})=O(T_{0}(r,g))+S_{f_{j}}(r)
and
T_{0}(r,g)=O(T_{0}(r,f_{j}))+S_{g}(r)
, in particular
S_{f_{j}}(r)=S_{g}(r)
for every
1\leq j\leq 5
.

Indeed, by Theorem
2.2
we have

\displaystyle(q-2)T_{0}(r,g)

\displaystyle\leq\sum_{i=1}^{q}\overline{N}_{0}(r,\nu^{0}_{g-a_{i}})+S_{g}(r)

\displaystyle=\sum_{j=1}^{q}\overline{N}_{0}(r,\nu^{0}_{f_{j}-a_{i}})+S_{g}(r)

\displaystyle\leq qT_{0}(r,f_{j})+S_{g}(r).

Then,
T_{0}(r,g)=O(T_{0}(r,f_{j}))+S_{g}(r)
. Similarly
T_{0}(r,f_{j})=O(T_{0}(r,g))+S_{f_{j}}(r)
and hence
S_{f_{j}}(r)=S_{g}(r)\ (1\leq j\leq 5)
.

We set
\varphi_{j}=P^{\prime}_{S}(f_{j})f_{j}^{\prime}/P_{S}(f_{j})
and
\varphi=\varphi_{1}
. By the definition of
\Psi_{j}
, we have

\varphi=\alpha_{j}+\varphi_{j},\text{ where }\alpha_{j}=\frac{\Psi_{j}^{\prime}}{\Psi_{j}}\ (1\leq j\leq 5).

By the lemma on logarithmic derivative, we have

m_{0}(r,\varphi_{j})=S_{P_{S}(f_{j})}(r)=S_{g}(r)\ \forall 1\leq j\leq 5\ (\text{note that }T_{0}(r,P_{S}(f_{j}))=qT_{0}(r,f_{j})).

Since each pole of
\varphi_{j}
is a simple pole and must be either zero or pole of
P_{S}(f_{j})
, we have

N_{0}(r,\nu^{\infty}_{\varphi_{j}})=\overline{N}_{0}(r,\nu^{0}_{P_{S}(f_{j})})+\overline{N}_{0}(r,\nu^{\infty}_{P_{S}(f_{j})})\leq 2qT_{0}(r,f_{j}).

It yields that

T_{0}(r,\varphi_{j})=m_{0}(r,\varphi_{j})+N_{0}(r,\nu^{\infty}_{\varphi_{j}})\leq 2qT_{0}(r,f_{j})+S_{g}(r).

In particular
T_{0}(r,\varphi_{j})=O(T_{0}(r,g))
. Moreover, by Theorem
2.2
we have

\displaystyle N_{0}(r,\nu^{\infty}_{\varphi})

\displaystyle\geq\overline{N}_{0}(r,\nu^{0}_{P_{S}(g)})+\overline{N}_{0}(r,\nu^{\infty}_{P_{S}(g)})

\displaystyle=\overline{N}_{0}(r,\nu^{0}_{P_{S}(f_{j})})+\overline{N}_{0}(r,\nu^{\infty}_{P_{S}(f_{j})})

\displaystyle=\sum_{i=1}^{q}\overline{N}_{0}(r,\nu^{0}_{f_{j}-a_{i}})+q\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})

\displaystyle\geq(q-1)(T_{0}(r,f_{j})+\overline{N}_{0}(r,\nu^{\infty}_{f_{j}}))+S_{f_{j}}(r).

This implies that

(3.33)

\displaystyle(q-1)T_{0}(r,f_{j})\leq T_{0}(r,\varphi)-(q-1)\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})+S_{g}(r).

Also, we note that

\displaystyle T_{0}(r,\alpha_{j})

\displaystyle=m_{0}(r,\alpha_{j})+N_{0}(r,\nu^{\infty}_{\alpha_{j}})

\displaystyle\leq m(r,\varphi)+m(r,\varphi_{j})+\overline{N}_{0}(r,\nu^{0}_{\Psi_{j}})+\overline{N}_{0}(r,\nu^{\infty}_{\Psi_{j}})+O(1)

\displaystyle=\overline{N}_{0}(r,\nu^{0}_{P_{S}(g)/P_{S}(f_{j})})+\overline{N}_{0}(r,\nu^{\infty}_{P_{S}(g)/P_{S}(f_{j})})+S_{g}(r)

\displaystyle\leq\sum_{i=1}^{q}\overline{N}_{0}(r,\nu^{0}_{f_{j}-a_{i},\geq\ell})+S_{g}(r)\leq\frac{q}{\ell}T_{0}(r,f_{j})+S_{g}(r).

This also yields that
T_{0}(r,\alpha_{j})=O(T_{0}(r,g))
.

We now show that
\alpha_{1},\ldots,\alpha_{5}
are mutually distinct. Indeed, suppose contrarily that
\alpha_{i}=\alpha_{j}
for some
i\neq j
. Then, there exists a nonzero constant
c_{0}
with
\Psi_{i}=c_{0}\Psi_{j}
and hence
c_{0}P_{S}(f_{i})=P_{S}(f_{j}).
This contradicts the assumption that
P_{S}(w)
is a uniqueness polynomial for admissible meromorphic functions on
{\mathbb{A}}(R_{0})
and
f_{i}\neq f_{j}
.

Applying Theorem
1.4
to the function
\varphi
and functions
\alpha_{1},\ldots,\alpha_{5}
, we obtain

2T_{0}(r,\varphi)\leq\sum_{j=1}^{5}\overline{N}_{0}(r,\nu^{0}_{\varphi-\alpha_{j}})+35\sum_{j=1}^{5}T_{0}(r,\alpha_{j})+S_{g}(r).

On the other hand, we have

\overline{N}_{0}(r,\nu^{0}_{\varphi-\alpha_{j}})=\overline{N}_{0}(r,\nu^{0}_{\varphi_{j}})\leq\overline{N}_{0}(r,\nu^{0}_{f_{j}^{\prime}})+\sum_{t=1}^{k}\overline{N}_{0}(r,\nu^{0}_{f_{j}-e_{t}}),

where
e_{1},\ldots,e_{k}
are all of distinct zeros of
P^{\prime}_{S}(w)
. Since
\overline{N}_{0}(r,\nu^{0}_{f_{j}-e_{t}})\leq T_{0}(r,f_{j})+O(1)
and

\displaystyle\overline{N}_{0}(r,\nu^{0}_{f_{j}^{\prime}})\leq

\displaystyle T_{0}(r,f_{j}^{\prime})+O(1)=m_{0}(r,f_{j}^{\prime})+N_{0}(r,\nu^{\infty}_{f_{j}^{\prime}})+O(1)

\displaystyle\leq

\displaystyle m_{0}(r,f_{j})+m_{0}\left(r,\frac{f_{j}^{\prime}}{f_{j}}\right)+N_{0}(r,\nu^{\infty}_{f_{j}})+\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})+O(1)

\displaystyle\leq

\displaystyle T_{0}(r,f_{j})+\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})+S_{g}(r),

we have

(3.34)

\displaystyle\sum_{j=1}^{5}\overline{N}_{0}(r,\nu^{0}_{\varphi-\alpha_{j}})\leq(k+1)\sum_{j=1}^{5}T_{0}(r,f_{j})+\sum_{j=1}^{5}\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})+S_{g}(r).

Then, combining (
3.33
) and (
3.34
) we have

\displaystyle 2(q-1)T_{0}(r,f_{i})

\displaystyle\leq 2T(r,\varphi)-2(q-1)\overline{N}_{0}(r,\nu^{\infty}_{f_{i}})+S_{g}(r)

\displaystyle\leq\left(k+1+\frac{35q}{\ell}\right)\sum_{j=1}^{5}T_{0}(r,f_{j})+\sum_{j=1}^{5}\overline{N}_{0}(r,\nu^{\infty}_{f_{j}})

\displaystyle\ \ \ -2(q-1)\overline{N}_{0}(r,\nu^{\infty}_{f_{i}})+S_{g}(r)\ \forall i=1,\ldots,5.

Summing up this inequality over all
i=1,\ldots,5
, we easily obtain

2(q-1)\sum_{i=1}^{5}T_{0}(r,f_{i})\leq 5\left(k+1+\frac{35q}{\ell}\right)\sum_{j=1}^{5}T_{0}(r,f_{j})+S_{g}(r).

Letting
r\rightarrow R_{0}
(outside the exceptional set), we get

2(q-1)\leq 5\left(k+1+\frac{35q}{\ell}\right),\text{ i.e., }q\leq\frac{(5k+7)\ell}{2\ell-175}.

This contradiction completes the proof of the theorem.
∎
