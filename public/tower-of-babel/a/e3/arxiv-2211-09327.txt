Unique identification and domination of edges in a graph: The vertex-edge dominant edge metric dimension
Hafiz Muhammad Ikhlaq

Abstract
Dominating sets and resolving sets have important applications in control theory and computer science. In this paper, we introduce an edge-analog of the classical dominant metric dimension of graphs. By combining the concepts of a vertex-edge dominating set and an edge resolving set, we introduce the notion of a vertex-edge dominant edge resolving set of a graph. We call the minimum cardinality of such a set in a graph Γ \Gamma , the vertex-edge dominant edge metric dimension γ e ​ m ​ d ​ ( Γ ) \gamma_{emd}(\Gamma) of Γ \Gamma . The new parameter γ e ​ m ​ d \gamma_{emd} is calculated for some common families such as paths, cycles, complete bipartite graphs, wheel and fan graphs. We also calculate γ e ​ m ​ d \gamma_{emd} for some Cartesian products of path with path and path with cycle. Importantly, some general results and bounds are presented for this new parameter. We also conduct a comparative analysis of γ e ​ m ​ d \gamma_{emd} with the dominant metric dimension of graphs. Comparison shows that these two parameters are not comparable, in general. Upon considering the class of bipartite graphs, we show that γ e ​ m ​ d ​ ( T n ) \gamma_{emd}(T_{n}) of a tree T n T_{n} is always less than or equal to its dominant metric dimension. However, we show that for non-tree bipartite graphs, the parameter is not comparable just like general graphs. Based on the results in this paper, we propose some open problems at the end.

5
Some general results and bounds

In this section, we provide some results for general graphs. First, we define some necessary terminologies.
For a graph
\Gamma
, two vertices
x,y\in V(\Gamma)
are said to be true twins (resp. false twins) if
N[x]=N[y]
(resp.
N(x)=N(y)
).
In a similar fashion, a vertex
x\in V(\Gamma)
is called true twin (resp. false twin) in
\Gamma
, if there exists a vertex
y\neq x

such that
x,~y
are true twins (resp. false twins).

Lemma 2

Let
\Gamma
be a connected graph. Then there exists a minimum vertex-edge dominating set for
\Gamma
which
does not have any pair of false twin vertices.

Proof:
Let
T
be a minimum vertex-edge dominating set for
\Gamma
with minimum number of false twin pairs of vertices
and
u,v
be any arbitrary false twin pair in
T
. Since
u
and
v
dominate the same edges in
\Gamma
, by
definition of vertex-edge domination,
T\setminus\{u\}
and
T\setminus\{v\}
are vertex-edge dominating
sets in
\Gamma
. This implies that there exists a minimum vertex-edge dominating set for
\Gamma
which does
not have any pair of false twin vertices. This shows the lemma.

Theorem 13

For every connected graph
\Gamma
of order
n
, we have
\beta_{e}(\Gamma)\leq n-\gamma_{ve}(\Gamma)
. In particular,
if
T
is a minimum vertex-edge dominating set for
\Gamma
with no false twin pair of vertices, then

V(\Gamma)\setminus T
is an edge resolving set for
\Gamma
.

Proof:
By Lemma 1,
\Gamma
has a minimum vertex-edge dominating set
S
with no pair of false twin vertices. Suppose,
on the contrary, that
V(\Gamma)\setminus T
is not an edge resolving set for
\Gamma
. By definition of edge
metric dimension, there exist edges
e
and
f
such that
r(e|V(\Gamma)\setminus T)=r(f|V(\Gamma)\setminus T)

if edge
e
is incident to vertex
u
and edge
f
is incident to vertex
v
, then

r(u|V(\Gamma)\setminus T)=r(v|V(\Gamma)\setminus T)
. This implies that all neighboring vertices of

u
and
v
in
V(\Gamma)\setminus T
are the same. So, vertices
u
and
v
have no neighbor
in the set
T
. On the other hand, we can remove one of the vertices
u
and
v
from the set
T
and get a dominating
set with order of
\mid T\mid-1
. Hence,
u
and
v
are false twin vertices, which is a contradiction. Thus,
V(G)\setminus T

is a resolving set for
\Gamma
. Accordingly,
\beta_{e}(\Gamma)\leq n-\gamma_{ve}(\Gamma)
.

Lemma 3

Let
\Gamma
be a connected graph. If
\Gamma
has no vertex-edge dominant edge resolving set with cardinality
l
, then
K\subseteq V(\Gamma)
with
|K|<l
is not a vertex-edge dominant edge resolving set.

Proof:

Let
\Gamma
be a connected graph. Assume that
\Gamma
has no vertex-edge dominant edge resolving set with cardinality
l
and suppose that there exist a vertex-edge dominant edge resolving set
X\subseteq V(\Gamma)
with
|X|<l
. So, that for every
e_{i},e_{j}\in E(\Gamma)
, we have
r(e_{i}|X)\neq r(e_{j}|X)
and every edge
e\in E(\Gamma)
, is dominated by any vertex of set
X
. Moreover, there exist a set
Y
and
Y\subseteq V(\Gamma)\setminus X
such that
|X\cup Y|=l
. The set
X\cup Y
is an edge resolving set for
\Gamma
as
X
is an edge resolving set for
\Gamma
and
X\cup Y
is vertex-edge dominant set for
\Gamma
as
X
is vertex-edge dominant set for
\Gamma
. So, that the set
X\cup Y
is vertex-edge dominant edge resolving set for
\Gamma
, which is contradiction and the proof is complete.

The following proposition bounds the vertex-edge domination number of a connected graph
\Gamma
.

Proposition 12

Let
\Gamma
be a connected graph of order
n
and size
m
. Then

\max\{\gamma_{ve}(\Gamma),\beta_{e}(\Gamma)\}\leq\gamma_{emd}(\Gamma)\leq\gamma_{ve}(\Gamma)+\beta_{e}(\Gamma).

Proof:

Assume that the set
T\subseteq V(\Gamma)
is
vertex-edge dominating set and the set
A\subseteq V(\Gamma)
is an edge resolving set of a graph
\Gamma
.
If
T\cup A=T
or
T\cup A=A
then
\gamma_{emd}(\Gamma)=\max\{\gamma_{ve}(\Gamma),\beta_{e}(\Gamma)\}
.
If
T\cap A\neq\phi
and
T\subset T\cup A
or
A\subset T\cup A
, then
\gamma_{emd}(\Gamma)>\max\{\gamma_{ve}(\Gamma),\beta_{e}(\Gamma)\}
.
Since, the vertex-edge dominant edge metric dimension of
\Gamma
is greater than its vertex-edge
domination number and its edge metric dimension, we obtain that
\gamma_{emd}(\Gamma)\geq\max\{\gamma_{ve}(\Gamma),\beta_{e}(\Gamma)\}
. If
the vertex-edge dominating set and the edge resolving set of
\Gamma
do not intersect, i.e.
T\cap A=\phi
, then

\gamma_{emd}(\Gamma)\leq\gamma_{ve}(\Gamma)+\beta_{e}(\Gamma)
. This completes the proof.

Next theorem presents sharp upper and lower bounds on the
\gamma_{emd}(\Gamma)
of
\Gamma
in terms of its order.

Theorem 14

Let
\Gamma
be a graph of order
n
. Then, the vertex-edge dominant edge metric dimension of
\Gamma
satisfies

\Big\lfloor\frac{n+2}{4}\Big\rfloor\leq\gamma_{emd}(\Gamma)\leq n-1.

Let
\Gamma
be a graph of order

and size
m
. Assume
\Delta(\Gamma)
is the maximum degree of
\Gamma
and
\Gamma
satisfies

\Delta(\Gamma)=2

\Gamma
is either path

or cycle

\gamma_{ve}(P_{n})=\big\lfloor\frac{n+2}{4}\big\rfloor
.
This implies that, we obtain
\gamma_{emd}(P_{n})=\big\lfloor\frac{n+2}{4}\big\rfloor
. Moreover, we know that
\beta_{e}(C_{n})=2
and

\gamma_{ve}(C_{n})=\big\lfloor\frac{n+3}{4}\big\rfloor

\gamma_{emd}(C_{n})=\big\lfloor\frac{n+3}{4}\big\rfloor

\Gamma
is

.

is

\beta_{e}(\Gamma)=n-2

by Proposition

but
\gamma_{ve}(\Gamma)=1
because
\mathrm{diam}(\Gamma)\leq 2

Next, we show some result on the vertex-edge dominant edge metric dimension of trees.

\gamma_{emd}(T_{n})
of
T_{n}
is

\gamma_{emd}(T_{n})=n-1
or
\gamma_{emd}(T_{n})=n-2
. Thus, if the maximum degree of tree
T_{n}
satisfies

2<\Delta(T_{n})<n-1
, then, this implies that the vertex-edge dominant edge metric dimension of

T_{n}
satisfies
\Big\lceil\frac{m}{4}\Big\rceil\leq\gamma_{emd}(T_{n})\leq n-1.
This shows the theorem.

5.1
The Corona Product of two graphs

Let
\Gamma
and
\Omega
be two graphs of order
p
and
q
, respectively. The corona product graph
\Gamma\odot\Omega

is defined as the graph obtained from
\Gamma
and
\Omega
, by taking one copy of
\Gamma
and
p
copies of
\Omega
and
joining by an edge the
i^{th}
-vertex of
\Gamma
with every vertex from the
i^{th}
-copy of
\Omega
. Given a vertex

u\in V(\Gamma)
, the copy of
\Omega
whose vertices are adjacent to
u
is denoted by
\Omega_{u}
.

Proposition 14

Let
\Gamma
and
\Omega
be two connected graphs and
|V(\Omega)|\geq 2
. Then,

\gamma_{ve}(\Gamma\odot\Omega)=|V(\Gamma)|
.

Proof:

Let the graph
\Gamma\odot\Omega
is corona product of two graphs
\Gamma
and
\Omega
and
|V(\Omega)|\geq 2
. If the vertex
x_{i}\in V(\Gamma\odot\Omega)
, then all edges incident to
N(x_{i})
are dominated by the vertex
x_{i}
. The subset
V(\Omega_{x_{i}})\subset N(x_{i})
is the vertex set of
i^{th}
-copy of
\Omega
and
U=\{y\in V(\Gamma):x_{i}y\in E(\Gamma)\}\subset N(x_{i})
. The set
N(x_{i})=V(\Omega_{x_{i}})\cup U
shows that the edges of
i^{th}
-copy of
\Omega
are dominated by the vertex
x_{i}
. So, that the set
T=V(\Gamma)
will dominate all edges of
\Gamma\odot\Omega
and it is clear that
\gamma_{ve}(\Gamma\odot\Omega)\leq|V(\Gamma)|
.
The set
T=V(\Gamma)=\{x_{1},x_{2},\ldots,x_{p}\}
is the minimum vertex-edge dominant set for
\Gamma\odot\Omega
. If the vertex
x_{i}\not\in T
, then all edges of
i^{th}
-copy of
\Omega
are not dominated by any vertex of
T
, it is clear that
\gamma_{ve}(\Gamma\odot\Omega)\geq|V(\Gamma)|
. This implies that
\gamma_{ve}(\Gamma\odot\Omega)=|V(\Gamma)|
.

Theorem 18

Let
\Gamma
and
\Omega
be two connected graphs and
|V(\Omega)|\geq 2
. Then,

\gamma_{emd}(\Gamma\odot\Omega)=\beta_{e}(\Gamma\odot\Omega)
.

Proof:

Note that the graph
\Gamma\odot\Omega
is corona product of two graphs
\Gamma
with order
p
and
\Omega
with order
q
, where
|V(\Omega)|\geq 2
and the vertex set of
\Gamma\odot\Omega
is defined as
V(\Gamma\odot\Omega)=\{x_{i}|1\leq i\leq p\}\cup\{y_{i}^{j}|1\leq i\leq p,1\leq j\leq q\}
. By Theorem
3
(resp. Proposition
14
), we have that
\beta_{e}(\Gamma\odot\Omega)=|V(\Gamma)|\cdot(|V(\Omega)|-1)
(resp.
\gamma_{ve}(\Gamma\odot\Omega)=|V(\Gamma)|
). The set
W=\{x_{i}|1\leq i\leq p\}\cup\{y_{i}^{j}|1\leq i\leq p,1\leq j\leq q-1\}
is an edge resolving set for
\Gamma\odot\Omega
and
T=\{x_{i}|1\leq i\leq p\}\subset W
is vertex-edge dominant set for
\Gamma\odot\Omega
by Proposition
14
. Since,
|W|=|V(\Gamma)|\cdot(|V(\Omega)|-1)
and the set
W
is vertex-edge dominant edge resolving set for
\Gamma\odot\Omega
. We obtain the desired result.

5.2
The Join of two graphs

Noted that the
\Gamma
and
\Omega
are two graphs, the join graph
\Gamma\vee\Omega
is obtained from
\Gamma
and
\Omega
by adding an edge between every vertex of
\Gamma
and every vertex of
\Omega
. It is clearly observed that the join graph
\Gamma\vee\Omega
is always a connected independently of the connectivity of the graphs
\Gamma
and
\Omega
.

Proposition 15

Let
\Gamma
and
\Omega
be two connected graphs. Then,

\gamma_{ve}(\Gamma\vee\Omega)=1~or~2
.

Proof:

Let the graph
\Gamma\vee\Omega
is join of two connected graphs
\Gamma
and
\Omega
. The vertex set and edge set of
\Gamma\vee\Omega
are
V(\Gamma\vee\Omega)=V(\Gamma)\cup V(\Omega)
and
E(\Gamma\vee\Omega)=E(\Gamma)\cup E(\Omega)\cup\{xu|x\in V(\Gamma),u\in V(\Omega)\}
, respectively. If the vertex
x\in V(\Gamma\vee\Omega)
, then all edges incident to
N(x)
are dominated by the vertex
x
.

Case 1:
Assume That
\Gamma\cong K_{n}
or
\Omega\cong K_{n}
.

For
\Gamma\vee\Omega
, the vertex
x\in V(\Gamma)
will dominate all edges of
\Gamma\vee\Omega
as
N(x)=V(\Gamma)\cup V(\Omega)
. This implies that the singleton set
T=\{x:x\in V(\Gamma)\}
is vertex-edge dominating set for
\Gamma\vee\Omega
where
\Gamma\cong K_{n}
. Therefore, we obtain
\gamma_{ve}(\Gamma\vee\Omega)=1
.

For
\Gamma\vee\Omega
, the vertex
u\in V(\Omega)
will dominate all edges of
\Gamma\vee\Omega
as
N(u)=V(\Gamma)\cup V(\Omega)
. This implies that the singleton set
T=\{u:u\in V(\Omega)\}
is vertex-edge dominating set for
\Gamma\vee\Omega
where
\Gamma\cong K_{n}
. Therefore, we obtain
\gamma_{ve}(\Gamma\vee\Omega)=1
.

Case 2:
Assume That
\Gamma,\Omega\not\cong K_{n}
.

The set
T=\{x,u:x\in V(\Gamma),u\in V(\Omega)\}
provides the minimum vertex-edge dominant set of
\Gamma\vee\Omega
. It is clear that the
\gamma_{ve}(\Gamma\vee\Omega)\leq 2
. The vertex
x\in V(\Gamma)
will dominate all edges incident to

T_{1}=\{x\}
(resp.
T_{2}=\{u\}

\Gamma
(resp.
\Omega

T_{1}
(resp.
T_{2}
), it is clear that
\gamma_{ve}(\Gamma\vee\Omega)\geq 2
. This implies that
\gamma_{ve}(\Gamma\vee\Omega)=2
. This completes the proof.

7
Concluding remarks and further open problems

This paper introduces a new parameter related to vertex-edge domination and distances in a graph.
The vertex-edge dominant edge metric dimension
\gamma_{emd}(\Gamma)
, in fact, combines the theory of vertex-edge domination and
edge resolvability of graphs. The parameter
\gamma_{emd}(\Gamma)
has been calculated for classical families such as paths, cycles, complete graphs,
complete bipartite graphs, wheel graphs and fan graphs. Some general results and bounds are provided. The most
significant contribution is that the vertex-edge dominant edge metric dimension
\gamma_{emd}(\Gamma)
is not comparable,
in general, with its vertex-version counterpart i.e. the dominant metric dimension
\gamma_{md}(\Gamma)
. In fact, for a
graph
\Gamma
, all three cases i.e.
\gamma_{md}(\Gamma)>\gamma_{emd}(\Gamma)
,
\gamma_{md}(\Gamma)<\gamma_{emd}(\Gamma)
, or
\gamma_{md}(\Gamma)=\gamma_{emd}(\Gamma)

can occur.
Upon considering the class of bipartite graphs, we show that

\gamma_{emd}(T_{n})
of a tree
T_{n}
is always less than or equal to its dominant metric dimension.
However, we show that for non-tree bipartite graphs, the parameter is not comparable just like general graphs.

Based on the results in this paper, we would like to propose the following open questions which arise naturally.

Problem 1

Characterize graphs
\Gamma
satisfying one of the following three cases:

(i)

\gamma_{md}(\Gamma)>\gamma_{emd}(\Gamma)
,

(ii)

\gamma_{md}(\Gamma)=\gamma_{emd}(\Gamma)
,

(iii)

\gamma_{md}(\Gamma)<\gamma_{emd}(\Gamma)
.

Theorem
20
shows that trees are comparable with respect to their vertex-edge dominant edge
metric dimension. However, it motivates the following problem.

Problem 2

Let
T_{n}
be a tree on
n\geq 2
vertices. Characterize all trees
T_{n}
with
\gamma_{md}(T_{n})=\gamma_{emd}(T_{n})
.

Although, the dominant metric dimension and the vertex-edge dominant edge metric dimension are not comparable,
in general, there might exist a relationship between these parameters for special classes of graph such trees,
unicyclic or bipartite graphs etc.

Problem 3

Is there any relationship between the dominant metric dimension
\gamma_{md}(\Gamma)
and
ve-
dominant edge metric
dimension
\gamma_{emd}(\Gamma)
for special classes of graph,
unicyclic or bipartite graphs etc.?

Problem 4

Let
\Gamma
be a graph with order
n
and size
m
. Let
\delta(\Gamma)
(resp.
\Delta(\Gamma)
) be the minimum degree (resp. maximum
degree) of
\Gamma
. Derive upper/lower bounds for
\gamma_{emd}(\Gamma)
in terms of
n,m,\delta(\Gamma)
or
\Delta(\Gamma)
?
