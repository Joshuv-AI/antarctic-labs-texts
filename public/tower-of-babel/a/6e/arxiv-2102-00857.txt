Abstract

A Banach space X X has property ( K ) (K) , whenever every weak* null sequence in the dual space admits a convex block subsequence ( f n ) n = 1 ∞ (f_{n})_{n=1}^{\infty} so that ⟨ f n , x n ⟩ → 0 \langle f_{n},x_{n}\rangle\to 0 as n → ∞ n\to\infty for every weakly null sequence ( x n ) n = 1 ∞ (x_{n})_{n=1}^{\infty} in X X ; X X has property ( μ s ) (\mu^{s}) if every weak ∗ null sequence in X ∗ X^{*} admits a subsequence so that all of its subsequences are Cesàro convergent to 0 0 with respect to the Mackey topology. , reciprocal Dunford–Pettis property

Mazur’s lemma (see,

,
[

in a Banach space

so that

for every

, where we set

; we denote by

the collection of all convex block subsequences of
(x_{n})_{n=1}^{\infty}
.) Kalton and Pełczyński
[

proved that if a Banach space

contains an isomorphic copy of

, then for every
\sigma
-finite measure

onto

is uncomplemented in its second dual. Consequently,

is not isomorphic to a Banach lattice; the original argument relied on the Lindenstrauss Lifting Principle. Having read a preliminary version of
[

]
, Kwapień introduced property
(K)
to provide an alternative proof of
[
KP
, Propositon 2.2]
which did not appeal to the Lindenstrauss Lifting Principle (Kwapień’s idea was incorporated in
[
KP
]
, where it was presented with his permission). Property

is central to our considerations:

Definition 1.1

A Banach space
X
has

(K)
, whenever every weak* null sequence in
X^{*}
admits a convex block subsequence
(f_{n})_{n=1}^{\infty}
so that
\lim\limits_{n\rightarrow\infty}\langle f_{n},x_{n}\rangle=0
for every weakly null sequence
(x_{n})_{n=1}^{\infty}

Put equivalently, Definition

stipulates that the sequence
(f_{n})_{n=1}^{\infty}
converges to
0
with respect to the Mackey topology

[

Property

may be thought of as a counterpart of Mazur’s lemma with respect to the weak* topology. It was shown in
[

that the space

fails to have this property.
Schur spaces

is a

converges weakly.)

Figiel, Johnson, and Pełczyński

[

It was proved in
[

Property

(b)

(c)

In Section

A bounded subset
A
of a Banach space
X
is a
Banach–Saks set
if each sequence in
A
has a Cesàro convergent subsequence. A Banach space

is said to have the

if its closed unit ball

is a Banach–Saks set. Banach and Saks proved in
[

that the spaces

and

(

later showed that uniformly convex spaces have the Banach–Saks property (hence so do superreflexive spaces). Any space with the Banach–Saks property is reflexive
[

]
, but there are reflexive spaces without the Banach–Saks property
[

]

[

]
says that any Banach–Saks set is relatively weakly compact
[

]

It follows from the Erdős–Magidor Theorem (Theorem

) that a Banach space

has the Banach–Saks property if and only if every bounded sequence in

admits a subsequence such that all of its subsequences are Cesàro convergent.
Property

, introduced by Rodríguez
[

, is a statement refining the Banach–Saks property for weak* null sequences in the dual space.

Definition 1.2
.

A Banach space
X
has

, whenever every weak
∗
null sequence in
X^{*}
admits a subsequence so that all of its subsequences are Cesàro convergent to
0
with respect to
\mu(X^{*},X)
.

Clearly, if
X^{*}
has the Banach–Saks property, then

has property
(\mu^{s})
. The converse is true for reflexive spaces
[

, Proposition 2.2]
. Moreover, it was pointed out
[

that property

is strictly stronger than property (

The goal of Section

is to quantify the following implications (
[

]

has the Banach–Saks property
\Rightarrow

has property
(\mu^{s})

\Rightarrow

X
has property
(K)
.

(
\star\star\star
)

To quantify property

, we first introduce a quantity

by means of

that we then prove characterises property

2.1.
Weak compactness

Let us invoke the following characterisation of weak compactness due to Ülger
[

]
.

Lemma 2.1

A bounded subset

of a Banach space

(x_{n})_{n=1}^{\infty}
in

(z_{n})_{n=1}^{\infty}

Diestel, Ruess, and Schachermayer
[

]
improved Lemma

Lemma 2.2
.

For a bounded subset

of

(1)

A
is relatively weakly compact.

(2)

For every sequence
(x_{n})_{n=1}^{\infty}
in

(z_{n})_{n=1}^{\infty}
such that

.

(3)

For every sequence
(x_{n})_{n=1}^{\infty}
in

, there is a weakly convergent sequence
(z_{n})_{n=1}^{\infty}
such that
z_{n}\in\operatorname{conv}(x_{i}\colon i\geqslant n)
.

Let

, we set

•

\textrm{d}(A,B)=\inf\{\|a-b\|\colon a\in A,b\in B\},

•

\textrm{d}(A,B)

is the (non-symmetrised) Hausdorff distance from

. When

\textrm{wk}_{X}(A)=\widehat{\textrm{d}}\big(\overline{A}^{\sigma(X^{**},X^{*})},X\big);

\operatorname{wck}_{X}(A)=\sup\{\textrm{d}(\textrm{clust}_{X^{**}}((x_{n})_{n=1}^{\infty}),X)\colon(x_{n})_{n=1}^{\infty}

,

where

•

\upgamma_{X}(A)=\sup\{|\lim\limits_{n}\lim\limits_{m}\langle f_{m},x_{n}\rangle-\lim\limits_{m}\lim\limits_{n}\langle f_{m},x_{n}\rangle|\colon(x_{n})_{n=1}^{\infty}

2.2.
Mackey topology

Let
X
be a Banach space. The Mackey topology,
\mu(X^{*},X)
, is the strongest locally convex topology on
X^{*}
which is compatible with the dual pairing
\langle X^{*},X\rangle
. In particular,
\overline{C}^{w^{*}}=\overline{C}^{\mu(X^{*},X)}
for every convex subset
C
of
X^{*}
. If the dual unit ball endowed with the relative Mackey topology,
(B_{X^{*}},\mu(X^{*},X))
, is metrisable, then
X
has property
(K)
. Schlüchtermann and Wheeler
[
SW
]
term Banach spaces
X
for which
(B_{X^{*}},\mu(X^{*},X))
is metrisable as
strongly weakly compactly generated
(SWCG) spaces. As proved in
[
SW
]
, a Banach space
X
is SWCG if and only if there exists a weakly compact subset
K
of
X
so that for every weakly compact subset
L
of
X
and
\varepsilon>0
, there is a positive integer
n
with
L\subseteq nK+\varepsilon B_{X}
. Moreover, reflexive spaces, separable Schur spaces, the space of operators of trace-class on a separable Hilbert space, and
L_{1}(\mu)
for a
\sigma
-finite measure
\mu
are SWCG.

2.3.
Banach–Saks sets

Let
(x_{n})_{n=1}^{\infty}
be a bounded sequence in a Banach space. We set

\operatorname{ca}((x_{n})_{n=1}^{\infty})=\inf_{n\in\mathbb{N}}\sup_{k,l\geqslant n}\|x_{k}-x_{l}\|.

Clearly
(x_{n})_{n=1}^{\infty}
is norm-Cauchy if and only if
\operatorname{ca}((x_{n})_{n=1}^{\infty})=0
.
Following
[
BKS
]
, we define

\textrm{cca}\big((x_{n})_{n=1}^{\infty}\big)=\operatorname{ca}\big((\frac{1}{n}\sum_{i=1}^{n}x_{i})_{n=1}^{\infty}\big).

Clearly,
\textrm{cca}((x_{n})_{n=1}^{\infty})=0
if and only if
(x_{n})_{n=1}^{\infty}
is Cesàro convergent.

A subset
A
of a Banach space is
Banach–Saks
, whenever every sequence in
A
has a Cesàro convergent subsequence.

We shall require the well-known
0
-
1
law by Erdős–Magidor
[
EM
]
.

Theorem 2.3
.

(Erdős–Magidor)
Every bounded sequence in a Banach space has a subsequence such that either all its further subsequences are Cesàro convergent, or none of them.

For a bounded set
A
in a Banach space
X
, Krulišová (neé Bendová), Kalenda, and Spurný
[
BKS
]
introduced the following quantity

\operatorname{bs}(A)=\sup_{(x_{n})_{n=1}^{\infty}\subseteq A}\inf_{(y_{n})_{n=1}^{\infty}\in\textrm{ss}((x_{n})_{n=1}^{\infty})}\textrm{cca}((y_{n})_{n=1}^{\infty})

measuring how far is
A
from being a Banach–Saks set. More precisely, they proved that
A
is a Banach–Saks set if and only if
\operatorname{bs}(A)=0
.

Let
(f_{n})_{n=1}^{\infty}

\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty})=\sup_{K\in\mathcal{F}_{X}}\inf_{n\in\mathbb{N}}\sup_{k,l\geqslant n}\sup_{x\in K}|\langle f_{k}-f_{l},x\rangle|,

\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty})=0
if and only if
(f_{n})_{n=1}^{\infty}
is

\mu(X^{*},X)
-convergent as the Mackey topology

[

is complete). We set

\alpha((f_{n})_{n=1}^{\infty})=\sup_{K\in\mathcal{F}_{X}}\limsup_{n\to\infty}\sup_{x\in K}|\langle f_{n},x\rangle|,

then
\alpha((f_{n})_{n=1}^{\infty})=0
if and only if
(f_{n})_{n=1}^{\infty}
is

\beta((f_{n})_{n=1}^{\infty})=\sup_{(x_{n})_{n=1}^{\infty}\subseteq B_{X}\atop\textrm{weakly null}}\limsup_{n\to\infty}|\langle f_{n},x_{n}\rangle|.

The following result is a quantitative version of
[

.

Lemma 3.1
.

Let
(f_{n})_{n=1}^{\infty}
be a weak
∗
null sequence in
X^{*}
. Then

\beta((f_{n})_{n=1}^{\infty})\leqslant\alpha((f_{n})_{n=1}^{\infty})\leqslant 2\beta((f_{n})_{n=1}^{\infty}).

Proof.

The former inequality is trivial. It remains to prove the latter one.

Let
0<c<\alpha\big((f_{n})_{n=1}^{\infty}\big)
. Then there exist a weakly compact subset
K\subseteq B_{X}
, a subsequence
(f_{k_{n}})_{n=1}^{\infty}
of
(f_{n})_{n=1}^{\infty}
, and a sequence
(x_{n})_{n=1}^{\infty}
in
K
so that
|\langle f_{k_{n}},x_{n}\rangle|>c
for all
n
. Since
K
is weakly compact, by the Eberlein–Šmulian theorem,
(x_{n})_{n=1}^{\infty}
admits a subsequence
(x_{n_{m}})_{m=1}^{\infty}
that converges weakly to some
x\in K
. We define a sequence
(z_{n})_{n=1}^{\infty}
in
X
by

z_{k_{n_{m}}}=\frac{1}{2}(x_{n_{m}}-x)\quad(m=1,2,\ldots)

and
z_{n}=0
for
n\notin\{k_{n_{m}}\}_{m=1}^{\infty}
. Then
(z_{n})_{n=1}^{\infty}
is weakly null in
B_{X}
. For each
m
, we get

|\langle f_{k_{n_{m}}},z_{k_{n_{m}}}\rangle|=\frac{1}{2}|\langle f_{k_{n_{m}}},x_{n_{m}}\rangle-\langle f_{k_{n_{m}}},x\rangle|\geqslant\frac{1}{2}(c-|\langle f_{k_{n_{m}}},x\rangle|).

Since
(f_{n})_{n=1}^{\infty}
is
\sigma(X^{*},X)
-null, we get

\limsup_{n\to\infty}|\langle f_{n},z_{n}\rangle|\geqslant\limsup_{m\to\infty}|\langle f_{k_{n_{m}}},z_{k_{n_{m}}}\rangle|\geqslant\frac{c}{2}.

Since
c
is arbitrary, we arrive at
\beta((f_{n})_{n=1}^{\infty})\geqslant\frac{1}{2}\alpha((f_{n})_{n=1}^{\infty}).
∎

Lemma 3.2
.

Let
(f_{n})_{n=1}^{\infty}
be a bounded sequence in
X^{*}
and
f\in X^{*}
. Then

\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty})\leqslant 2\alpha((f_{n}-f)_{n=1}^{\infty}).

Proof.

Let
c>\alpha((f_{n}-f)_{n=1}^{\infty})
be arbitrary. Let
K\in\mathcal{F}_{X}
. Then there exists a positive integer
n
so that
\sup\limits_{x\in K}|\langle f_{k}-f,x\rangle|<c
for all
k\geqslant n
. Hence, for
k,l\geqslant n
, we get

\sup\limits_{x\in K}|\langle f_{k}-f_{l},x\rangle|=\sup\limits_{x\in K}|\langle(f_{k}-f)-(f_{l}-f),x\rangle|\leqslant 2c.

This implies that
\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty})\leqslant 2c
. As
c
was arbitrary, the proof is complete.
∎

Lemma 3.3
.

Suppose that
(f_{n})_{n=1}^{\infty}
converges to

\alpha((f_{n}-f)_{n=1}^{\infty})\leqslant\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty}).

Let
c>\operatorname{ca}_{\rho^{*}}((f_{n})_{n=1}^{\infty})

n

\sup\limits_{x\in K}|\langle f_{k}-f_{l},x\rangle|<c

|\langle f_{k}-f_{l},x\rangle|<c

Letting

|\langle f_{k}-f,x\rangle|\leqslant c

\sup\limits_{x\in K}|\langle f_{k}-f,x\rangle|\leqslant c

4.
Quantifying the Grothendieck property and reflexivity

The following result is a slight improvement on Lemma
2.2
. For the sake of completeness, we include the proof here.

Lemma 4.1
.

For a bounded subset
A
of
X
the following are equivalent:

(1)

A
is relatively weakly compact.

(2)

Every sequence in
A
admits a convex block subsequence that is norm convergent.

(3)

Every sequence in
A
admits a convex block subsequence that is weakly convergent.

Proof.

(1)\Rightarrow(2)
. Given a sequence
(x_{n})_{n=1}^{\infty}
in
A
. Then
(x_{n})_{n=1}^{\infty}
admits a subsequence
(y_{n})_{n=1}^{\infty}
that is weakly convergent. By Mazur’s lemma,
(y_{n})_{n=1}^{\infty}
admits a convex block subsequence
(z_{n})_{n=1}^{\infty}
that is norm convergent. It follows from Lemma
3.7
that
(z_{n})_{n=1}^{\infty}
is a convex block subsequence of
(x_{n})_{n=1}^{\infty}
.

(2)\Rightarrow(3)
is trivial. It remains to prove
(3)\Rightarrow(1)
.

Let
K=\overline{\operatorname{conv}}(A)
. Given any
f\in X^{*}
. We let
c=\sup\limits_{x\in K}\langle f,x\rangle=\sup\limits_{x\in A}\langle f,x\rangle
.
Choose a sequence
(x_{n})_{n=1}^{\infty}
in
A
so that
\langle f,x_{n}\rangle\rightarrow c
. By the assumption, there exists a sequence
(z_{n})_{n=1}^{\infty}\in\operatorname{cbs}((x_{n})_{n=1}^{\infty})
so that
(z_{n})_{n=1}^{\infty}
converges weakly to some
x\in K
. It is easy to see that
\langle f,z_{n}\rangle\rightarrow c
. Hence
c=\langle f,x\rangle.
It follows from James’ characterisation of weak compactness via norm-attaining functionals that
K
is weakly compact and so
A
is relatively weakly compact.∎

Proposition 4.2
.

A Banach space
X
has the Grothendieck property if and only if every weak
∗
null sequence in
X^{*}
admits a convex block subsequence that is norm null.

Proof.

The necessity follows from Mazur’s lemma. It remains to prove the sufficiency.

Given a weak
∗
null sequence
(f_{n})_{n=1}^{\infty}
in
X^{*}
and any subsequence
(h_{n})_{n=1}^{\infty}
of
(f_{n})_{n=1}^{\infty}
. By the hypothesis,
(h_{n})_{n=1}^{\infty}
admits a convex block subsequence
(g_{n})_{n=1}^{\infty}
that is norm null. By Lemma
4.1
, the sequence
(f_{n})_{n=1}^{\infty}
is relatively weakly compact and hence is weakly null. Thus

has the Grothendieck property.∎

Definition 4.3
.

Let
X
be a Banach space. We set

G(X)=\sup_{(f_{n})_{n=1}^{\infty}\subseteq B_{X^{*}}\atop\operatorname{weak}^{*}\textrm{null}}\inf_{(g_{n})_{n=1}^{\infty}\in\operatorname{cbs}((f_{n})_{n=1}^{\infty})}\limsup_{n\to\infty}\|g_{n}\|.

The above-defined quantity measures, in a certain sense, how far is a given Banach space from being a Grothendieck space. This quantification of the Grothendieck property is very different from the one proposed by Krulišová (
[

]
) who introduced the so-called

parametrised by

. Every

-Grothendieck space is Grothendieck but not every Grothendieck space is

(
[

).

\|y^{**}-y\|=\|i^{**}_{Y}y^{**}-y\|\geqslant\textrm{d}(\textrm{clust}_{X^{**}}((x_{n})_{n=1}^{\infty}),X).

Finally, by Case 1, we get

c\leqslant\operatorname{wck}_{Y}(B_{Y})\leqslant R(Y)\leqslant R(X).

As
c
was arbitrary, the proof is complete.∎

Example 4.9
.

(1)

Let

. Then

. In particular,
R(\ell_{1})=R(C[0,1])=2

(2)

(3)

1\leqslant R(c_{0})\leqslant\frac{4}{3}

Proof.

(
1
). Let
\varepsilon>0
. By James’ distortion theorem, there is a sequence
(x_{n})_{n=1}^{\infty}
in
B_{X}

\|\sum\limits_{i=1}^{n}a_{i}x_{i}\|\geqslant(1-\varepsilon)\sum\limits_{i=1}^{n}|a_{i}|

a_{1},a_{2},\ldots,a_{n}.

For each
(z_{n})_{n=1}^{\infty}\in\operatorname{cbs}((x_{n})_{n=1}^{\infty})

z_{n}=\sum_{i=k_{n-1}+1}^{k_{n}}\lambda_{i}x_{i}
. Then, for
n<m
, we get

\|z_{n}-z_{m}\|=\|\sum\limits_{i=k_{n-1}+1}^{k_{n}}\lambda_{i}x_{i}-\sum\limits_{i=k_{m-1}+1}^{k_{m}}\lambda_{i}x_{i}\|\geqslant 2(1-\varepsilon).

This implies that

. As
\varepsilon
was arbitrary, we proved (
1
).

(
2
). For each
n

x_{n}(i)=\left\{\begin{array}[]{r@{\quad}l}1,&i\leqslant n\\
-1,&i>n\end{array}\right.

Given
(z_{n})_{n=1}^{\infty}\in\operatorname{cbs}((x_{n})_{n=1}^{\infty})

z_{n}=\sum\limits_{i=k_{n-1}+1}^{k_{n}}\lambda_{i}x_{i}

\sum\limits_{i=k_{n-1}+1}^{k_{n}}\lambda_{i}x_{i}(k_{m-1}+1)=-1,\quad\sum\limits_{i=k_{m-1}+1}^{k_{m}}\lambda_{i}x_{i}(k_{m-1}+1)=1.

This implies that
\|z_{n}-z_{m}\|=2
and so
\operatorname{ca}((z_{n})_{n=1}^{\infty})=2
. Thus, we obtain

.

(
3
). The inequality
R(c_{0})\geqslant 1
follows from Theorem
4.8
since for every non-reflexive space

\operatorname{wck}_{X}(B_{X})=1
, which follows for example from
[
GHP

and
[

, Proposition 2.2]
. The inequality
R(c_{0})\leqslant 4/3
was pointed out by W. B. Johnson; we present it here with his permission.

Suppose that
(x_{n})_{n=1}^{\infty}
is a sequence in
B_{c_{0}}
. By passing to a subsequence, we may assume that
(x_{n})_{n=1}^{\infty}
converges coordinate-wise to some
x\in B_{\ell_{\infty}}
. By passing to further subsequence and making a small perturbation we may assume that there are
k_{1}<k_{2}<\ldots
so that
x_{n}
is supported on
\{1,2,\ldots,k_{n}\}
and
x_{n+1}(i)=x(i),i=1,2,\ldots,k_{n}
. We define
z_{n}=\frac{2}{3}x_{2n}+\frac{1}{3}x_{2n+1}
(

We

|z_{n}(i)-z_{m}(i)|=\left\{\begin{array}[]{r@{\quad\quad}l}|\frac{2}{3}x_{2n}(i)+\frac{1}{3}x(i)-\frac{2}{3}x_{2m}(i)-\frac{1}{3}x(i)|\leqslant\frac{4}{3},&i\leqslant k_{2n}\\

Consequently,

We require an elementary lemma whose proof is straightforward.

Lemma 4.10
.

Suppose that

is a weak
∗
null sequence in

An immediate consequence of Lemma

is the following quantification of implications (

Theorem 4.11
.

Let

In order to quantify (

Lemma 4.12
.

Let
X
be a Banach space containing no subspaces isomorphic to
\ell_{1}
. Suppose that
f_{n}\stackrel{{\scriptstyle\operatorname{weak}^{*}}}{{\longrightarrow}}0
in
X^{*}

\limsup\limits_{n\to\infty}\|f_{n}\|\leqslant 2\beta\big((f_{n})_{n=1}^{\infty}\big).

Let

. By passing to a subsequence, we may assume that
\|f_{n}\|>c

. Choose
x_{n}\in B_{X}
with
\langle f_{n},x_{n}\rangle>c
(
n\in\mathbb{N}

(x_{n})_{n=1}^{\infty}
is weakly Cauchy.
Let
\varepsilon>0

(k_{n})_{n=1}^{\infty}

\langle f_{k_{n}},x_{k_{n}}-x_{2n-1}\rangle>c-\varepsilon

y_{n}=\frac{1}{2}(x_{k_{n}}-x_{2n-1})

(z_{n})_{n=1}^{\infty}

\beta\big((f_{n})_{n=1}^{\infty}\big)\geqslant\limsup\limits_{n\to\infty}|\langle f_{n},z_{n}\rangle|\geqslant\limsup\limits_{n\to\infty}|\langle f_{k_{n}},z_{k_{n}}\rangle|\geqslant\frac{c-\varepsilon}{2}.

Theorem 4.13
.

Let

K_{1}(X)\leqslant G(X)\leqslant R(X^{*})\leqslant 8K_{2}(X).

Proof.

By Theorem
4.11

0<c<R(X^{*})
. Then there exists a sequence
(f_{n})_{n=1}^{\infty}
in
B_{X^{*}}
so that

\operatorname{ca}\big((g_{n})_{n=1}^{\infty}\big)>c\qquad\Big((g_{n})_{n=1}^{\infty}\in\operatorname{cbs}\big((f_{n})_{n=1}^{\infty}\big)\Big).

Since
X
contains no isomorphic copy of
\ell_{1}
, it follows from
[

, Proposition 3.11]
(
cf
.
[

is
weak
∗
convex block compact

B_{X^{*}}
admits a weak

3.7

f_{n}\stackrel{{\scriptstyle\operatorname{weak}^{*}}}{{\longrightarrow}}f

. Hence, we get

\operatorname{ca}((g_{n})_{n=1}^{\infty})>c\qquad\Big((g_{n})_{n=1}^{\infty}\in\operatorname{cbs}\big((f_{n}-f)_{n=1}^{\infty}\big)\Big).

5.
Quantifying property (
\mu^{s}
)

For a bounded sequence
(f_{n})_{n=1}^{\infty}
in
X^{*}
, we define

c\alpha\big((f_{n})_{n=1}^{\infty}\big)=\alpha\big((\frac{1}{n}\sum_{i=1}^{n}f_{i})_{n=1}^{\infty}\big).

Then
c\alpha((f_{n})_{n=1}^{\infty})=0
if and only if
(f_{n})_{n=1}^{\infty}
is Cesàro convergent to
0
with respect to
\mu(X^{*},X)
. A direct argument shows that
c\alpha((f_{n})_{n=1}^{\infty})=c\alpha((f_{n})_{n\geqslant N+1})
for every positive integer
N
.

Definition 5.1
.

Let
X
be a Banach space. We set

\mu^{s}(X)=\sup_{(f_{n})_{n=1}^{\infty}\subseteq B_{X^{*}}\atop\operatorname{weak}^{*}\textrm{null}}\inf_{(g_{n})_{n=1}^{\infty}\in\textrm{ss}((f_{n})_{n=1}^{\infty})}\sup_{(h_{n})_{n=1}^{\infty}\in\textrm{ss}((g_{n})_{n=1}^{\infty})}c\alpha\big((h_{n})_{n=1}^{\infty}\big).

Theorem 5.2
.

A Banach space
X
has property
(\mu^{s})
if and only if
\mu^{s}(X)=0
.

Proof.

The sufficient part is trivial. We only prove the necessary part.

Given a weak
∗
null sequence
(f_{n})_{n=1}^{\infty}
in
B_{X^{*}}
, by induction, for each
k
we may find a sequence
((g_{n})^{(k)})_{n=1}^{\infty}
in
X^{*}
such that

•

((g_{n})^{(1)})_{n=1}^{\infty}\in\textrm{ss}((f_{n})_{n=1}^{\infty}),

•

((g_{n})^{(k+1)})_{n}\in\textrm{ss}(((g_{n})^{(k)})_{n}),

•

c\alpha\big((g_{n})_{n=1}^{\infty}\big)<\frac{1}{k}\quad\big((g_{n})_{n=1}^{\infty}\in\textrm{ss}(((g_{n})^{(k)})_{n})\big).

Let
g_{n}=(g_{n})^{(n)}

(n=1,2,\ldots)
. Then
(g_{n})_{n=1}^{\infty}
is a subsequence of
(f_{n})_{n=1}^{\infty}
. Take any subsequence
(h_{n})_{n=1}^{\infty}
of

(g_{n})_{n=1}^{\infty}
. By construction, for each
k
, there exists
N_{k}\in\mathbb{N}
so that
(h_{n})_{n\geqslant N_{k}+1}\in\textrm{ss}(((g_{n})^{(k)})_{n}).

Consequently,

c\alpha\big((h_{n})_{n=1}^{\infty}\big)=c\alpha((h_{n})_{n\geqslant N_{k}+1})<\frac{1}{k}.

As
k
was arbitrary,
c\alpha\big((h_{n})_{n=1}^{\infty}\big)=0
. Thus the sequence
(h_{n})_{n=1}^{\infty}
is Cesàro convergent to
0
with respect to
\mu(X^{*},X)
, which completes the proof. ∎

Definition 5.3
.

For a Banach space
X
, we set

\operatorname{bs}(X)=\sup_{(x_{n})_{n=1}^{\infty}\subseteq B_{X}}\inf_{(y_{n})_{n=1}^{\infty}\in\textrm{ss}((x_{n})_{n=1}^{\infty})}\sup_{(z_{n})_{n=1}^{\infty}\in\textrm{ss}((y_{n})_{n=1}^{\infty})}\textrm{cca}((z_{n})_{n=1}^{\infty}).

Clearly,
\operatorname{bs}(B_{X})\leqslant\operatorname{bs}(X)
. Combining Theorem
2.3
with
[
BKS
, Corollary 4.3]
, we see that
\operatorname{bs}(X)=0
if and only if
X
has the Banach–Saks property.

Theorem 5.4
.

Let
X
be a Banach space. Then

\frac{1}{3}K_{1}(X)\leqslant\mu^{s}(X)\leqslant\operatorname{bs}(X^{*}).

Proof.

The latter inequality follows from Lemma
3.3
, so it remains to prove only the former one.

Let
0<c<K_{1}(X)
and let
\varepsilon>0
. Then there exist a weak
∗
null sequence
(f_{n})_{n=1}^{\infty}
in
B_{X^{*}}
and a subsequence
(g_{n})_{n=1}^{\infty}
of
(f_{n})_{n=1}^{\infty}
such that

•

\alpha\big((h_{n})_{n=1}^{\infty}\big)>c\quad\big((h_{n})_{n=1}^{\infty}\in\operatorname{cbs}((f_{n})_{n=1}^{\infty})\big),

•

c\alpha((g_{n})_{n=1}^{\infty})<\mu^{s}(X)+\varepsilon.

It follows from Lemma
3.7
that

\displaystyle c

\displaystyle<\alpha\big((\frac{1}{2^{n-1}}\sum_{i=2^{n-1}+1}^{2^{n}}g_{i})_{n=1}^{\infty}\big)

\displaystyle\leqslant 2\alpha\big((\frac{1}{2^{n}}\sum_{i=1}^{2^{n}}g_{i})_{n=1}^{\infty}\big)+\alpha\big((\frac{1}{2^{n-1}}\sum_{i=1}^{2^{n-1}}g_{i})_{n=1}^{\infty}\big)

\displaystyle\leqslant 3\alpha\big((\frac{1}{n}\sum_{i=1}^{n}g_{i})_{n=1}^{\infty}\big)

\displaystyle\leqslant 3\mu^{s}(X)+3\varepsilon.

As
c
and
\varepsilon
are arbitrary, we arrive at
K_{1}(X)\leqslant 3\mu^{s}(X)
, which completes the proof. ∎

Theorem 5.5
.

Let
X

\mu^{s}(X)\leqslant\operatorname{bs}(X^{*})\leqslant 4\mu^{s}(X).

Proof.

The former inequality follows from Lemma
3.3
, so we need to prove the latter one.

Let
0<c<\operatorname{bs}(X^{*})
. Then there exists a sequence
(f_{n})_{n=1}^{\infty}
in
B_{X^{*}}

\sup_{(h_{n})_{n=1}^{\infty}\in\textrm{ss}((g_{n})_{n=1}^{\infty})}\textrm{cca}((h_{n})_{n=1}^{\infty})>c\quad\big((g_{n})_{n=1}^{\infty}\in\textrm{ss}((f_{n})_{n=1}^{\infty})\big).

(5.1)

Due to reflexivity, we may assume that
f_{n}\stackrel{{\scriptstyle\operatorname{weak}^{*}}}{{\longrightarrow}}f

Given any
