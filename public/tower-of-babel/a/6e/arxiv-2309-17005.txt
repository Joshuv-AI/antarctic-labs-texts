Abstract
bayesian_pyhf is a Python package that allows for the parallel Bayesian and frequentist evaluation of multi-channel binned statistical models. The Python library pyhf is used to build such models according to the HistFactory framework and already includes many frequentist inference methodologies. The pyhf -built models are then used as data-generating model for Bayesian inference and evaluated with the Python library PyMC . Based on Monte Carlo Chain Methods, PyMC allows for Bayesian modelling and together with the arviz library offers a wide range of Bayesian analysis tools.

2.2
Bayes’ Theorem

Bayesian inference is governed by Bayes’ theorem
ConjPriorsBerkeley
:

\displaystyle p(\eta,\chi|x,a)=\frac{p(x,a|\eta,\chi)p(\eta,\chi)}{p(x,a)}.

(2)

It describes the updating of a prior probability distribution
p(\eta,\chi)
to a posterior distribution
p(\eta,\chi|x)
by multiplication with a data-generating model
p(x|\eta,\chi)
.
\eta,\chi
are parameters of interest (POI) and constraint parameters respectively and
x,a
observations and auxiliary measurements and evidence
p(x,a)
. While a closed form solution of Eq. (
2

PyMC
) as only a tractable joint likelihood
p(x,a|\eta,\chi)p(\eta,\chi)
is required.

2.4
Prior Constraints from Auxiliary Measurements and Ur-Priors

In order to get a sampling representation of the posterior using MCMC methods the prior distribution and the
HistFactory
models are needed, i.e following Eq. (
2
):

\displaystyle p(\eta,\chi|x,a)\approx p(x,a|\eta,\chi)p(\eta,\chi).

(3)

While
p(x,a|\eta,\chi)
can be build using
pyhf
, the prior beliefs of the value of the parameters still have to be quantified. It would be possible to treat
\eta
and
\chi
equally, i.e. to determine some ur-prior
p(\eta,\chi)
by hand and update with
x
and
a
in parallel. Ur-priors describe the belief about the parameter value before taking the observations into account.

The approach followed in this work however relies on a different treatment of the constraint priors
p(\chi)
. It is based on separating the auxiliary observations
a
from the main inference step and using it instead in an initial inference step. In this step, Bayes’ theorem is used to update ur-priors
p_{\text{ur}}(\chi)
with the auxiliary measurements
a
, thus incorporating the information gained from the auxiliary measurements
a
, see Eq. (
4
).

\displaystyle p(\chi|a)\approx p(a|\chi)p_{\text{ur}}(\chi)

(4)

The posteriors
p(\chi|a)
from Eq. (
4
) can then be used as prior belief in the main inference step.

This approach is useful, as the number of constraint measurements can get arbitrarily high which would imply high computational cost when updating
p(\eta)
and
p(\chi)
together. Splitting the auxiliary update of the constraint parameters into this initial step solves this issue based on the concept of conjugate priors. This concept dictates that for given sets of distributions for the priors and the data-generating model, the posterior distribution is of the same distribution family as the prior and can be given in closed form — the priors and posteriors are then conjugate. Due to the limited possibilities for the auxiliary measurements (which can be either Gaussian or Poisson distributed), this concept is viable for the constraint parameters with corresponding Gaussian and Gamma distributed ur-priors, see Table

\alpha_{\text{ur}},\beta_{\text{ur}}\rightarrow 0\quad&\longrightarrow\quad\alpha^{\prime},\beta^{\prime}\rightarrow a.\end{split}

(5)

As the impact of the auxiliary measurements can now be implemented in closed form, no sampling is needed for the implementation of the knowledge gained from the auxiliary measurements

Hamiltonian Monte Carlo Sampling

pyhf

pyhf

pyhf_joss
;
jax2018github

. Therefore, the Hamiltonian Monte Carlo (HMC) step method provided by

. For this work, it is sufficient to point out that HMC relies on the derivatives of the model — and while this comes with a computational cost, the quality of the drawn samples should be higher compared to other step methods, such as Metropolis-Hastings

The quality of MCMC chains can be measured using the autocorrelation length, i.e. the correlation between subsequent samples. Independent samples are necessary to fully express the parameter space. In order to reduce the autocorrelation length, thinning can be applied. In thinned chains, only every
n
th sample is kept in the final chains
hoyer2017xarray
. Fig.
1
visualises how the Metropolis-Hastings chains have to be thinned twice as much (

n=6

3
for the model used). Accordingly, in order to produce sampling chains of the same magnitude, the computational cost of the gradient calculation can seen as substituting the cost for drawing twice as many samples for Metropolis-Hastings steps.
