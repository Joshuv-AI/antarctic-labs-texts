On the design of autonomous agents from multiple data sources
Émiland Garrabé, Giovanni Russo

Abstract
This paper is concerned with the problem of designing agents able to dynamically select information from multiple data sources in order to tackle tasks that involve tracking a target behavior while optimizing a reward. We formulate this problem as a data-driven optimal control problem with integer decision variables and give an explicit expression for its solution. The solution determines how (and when) the data from the sources should be used by the agent. We also formalize a notion of agent’s regret and, by relaxing the problem, give a regret upper bound. Simulations complement the results.



I
INTRODUCTION

The problem of designing agents able to tackle tasks by using data coming from multiple sources is attracting much research attention. Learning algorithms with multiple simulators in the loop
[
1
]

[

Contributions

we consider the problem of designing agents able to dynamically choose between multiple sources in order to fulfill tasks that involve tracking a target behavior while optimizing a reward function. We formulate this problem as a data-driven, integer, optimal control problem. For this problem: (i) we formalize the problem as a data-driven control problem. This leads to an optimal control formulation with integer decision variables; (ii) by relaxing the problem, we find an explicit expression for its optimal solution. The solution determines, at each time step, which source should be picked by the agent; (iii) finally, we formalize a notion of regret w.r.t. an oracle and give a regret upper bound. The oracle is obtained by relaxing the original control problem. This leads to an infinite-dimensional convex problem that we also solve explicitly. Our results are complemented via simulations.

While the results of this paper are inspired by the ones presented in
[
4
]

[

[
4

[
4

and, as a result, our regret analysis cannot obtained with the results from
[
4

II
The set-up

The agent seeks to craft its behavior by gathering data from a number of sources in order to fulfill a task that involves tracking a target/desired behavior while, at the same time, maximizing a reward function. In what follows,
\mathbf{x}_{k}\in\mathcal{X}
is the state at time step

\begin{split}p_{0:N}&=p_{0:0}\prod_{k=1}^{N}p_{k|k-1}=:p_{0:0}p_{1:N|0},\end{split}

(1)

which is termed as
target behavior
. As noted in
[
4
]
, the agent behavior can be designed by designing the joint pdf/pmf
\pi(\mathbf{x}_{0},\ldots,\mathbf{x}_{N})
. By letting
\pi_{k|k-1}:=\pi_{k}(\mathbf{x}_{k}|\mathbf{x}_{k-1})
we have:

\begin{split}\pi_{0:N}&=\pi_{0:0}\prod_{k=1}^{N}\pi_{k|k-1}=:\pi_{0:0}\pi_{1:N|0}.\end{split}

(2)

That is, the
agent behavior

\pi_{0:N}
can be designed by shaping the
\pi_{k|k-1}
’s. We let
r_{k}:\mathcal{X}\rightarrow\mathbb{R}
be the reward obtained by the agent for being in state
\mathbf{x}_{k}
at time
k
. Hence, the expected reward for the agent that follows the behavior in (
2
) is
\mathbb{E}_{\pi_{k-1:k-1}}\left[\tilde{r}_{k}(\mathbf{X}_{k-1})\right]:=\mathbb{E}_{\pi_{k-1:k-1}}\left[\mathbb{E}_{\pi_{k|k-1}}\left[r_{k}(\mathbf{X}_{k})\right]\right]=\mathbb{E}_{\pi_{k:k}}\left[r_{k}(\mathbf{X}_{k})\right]
. We let
\mathcal{S}:={1:S}
be the set of sources that the agent can use and
\left\{\pi_{k|k-1}^{(i)}\right\}_{1:N}
be the sequence of pdfs/pmfs (i.e. the behavior) provided by the
i
-th source. While the sources do not know the target behavior/reward of the agent, we make the following assumption, which, as discussed in
[
4
]
, is not restrictive in practice:

Assumption 1

\mathcal{D}_{\text{KL}}(\pi_{k|k-1}^{(i)}||p_{k|k-1})<+\infty
,
\forall k
,
\forall i\in\mathcal{S}
.

Remark 1

situations where the
\pi_{k|k-1}^{(i)}
’s are available to the agent naturally arise in a number of applications. For example, within the multi-fidelity RL framework, the sources might be simulators available to the agent and each
\pi_{k|k-1}^{(i)}
might be given by the output of the
i
-th simulator.

Remark 2

in what follows, we use
p_{1:n|0}
and
\pi_{1:n|0}
for
p(\mathbf{x}_{1},\ldots,\mathbf{x}_{n}|\mathbf{x}_{0})
and
\pi(\mathbf{x}_{1},\ldots,\mathbf{x}_{n}|\mathbf{x}_{0})
to make equations more compact.

III
The control problem and a link with the CCP

Let
\alpha_{k}^{(i)}
,
i\in\mathcal{S}
, be a weight and
\boldsymbol{\alpha}_{k}
be the stack of the
\alpha_{k}^{(i)}
’s. Then, the problem of designing agents able to dynamically choose between different sources in order to track their own target behavior while optimizing the agent-specific reward can be recast via the following

Problem 1

find the sequence
{\left\{\boldsymbol{\alpha}_{k}^{\ast}\right\}_{1:N}}
solving

\displaystyle\underset{\left\{\boldsymbol{\alpha}_{k}\right\}_{1:N}}{\text{min}}

\displaystyle\mathcal{D}_{\text{KL}}\left(\pi_{1:N|0}||p_{1:N|0}\right)-\sum_{k=1}^{N}\mathbb{E}_{\pi_{k-1:k-1}}\left[\tilde{r}_{k}(\mathbf{X}_{k-1})\right]

(3)

\displaystyle s.t.

\displaystyle\pi_{k|k-1}=\sum_{i\in\mathcal{S}}\alpha_{k}^{(i)}\pi_{k|k-1}^{(i)},\ \ \ \forall k

\displaystyle\sum_{i\in\mathcal{S}}\alpha_{k}^{(i)}=1,\ \ \alpha_{k}^{(i)}\in\{0,1\},\ \ \forall k.

In Problem
1
the constraints formalize the fact that, at each
k
, the agent picks the behavior from one source. The first term in the cost quantifies the discrepancy between the agent behavior and the target: hence, minimizing this term amounts to tracking the target behavior. Instead, minimizing the second term in the cost implies maximizing the agent’s expected reward.

Remark 3

Problem
1
captures situations where an agent needs to pick between (rather than combine) multiple sources. These situations arise in a number of applications, such as multi-fidelity RL where the agents needs to make its decision based on the output of different simulators.

Definition 1

\left\{{\pi}^{\ast}_{k|k-1}\right\}_{1:N}
is an optimal solution of Problem
1
if
{\pi}^{\ast}_{k|k-1}:=\sum_{i\in\mathcal{S}}{\alpha_{k}^{(i)}}^{\ast}\pi_{k|k-1}^{(i)}
, with the weights being an optimal solution of (
3
).

We now state the CCP from
[
4
]
in terms of Problem
1

Problem 2

the CCP is the relaxation of Problem
1
obtained by replacing,
\forall k
,
\alpha_{k}^{(i)}\in\{0,1\}
with
\alpha_{k}^{(i)}\geq 0
.

In what follows, we also make use of the following definition

Definition 2

\left\{\tilde{\pi}_{k|k-1}\right\}_{1:N}
is an approximate solution of the CCP if
\tilde{\pi}_{k|k-1}:=\sum_{i\in\mathcal{S}}{\tilde{\alpha}_{k}^{(i)}}\pi_{k|k-1}^{(i)}

Lemma 1

consider the CCP. Then
\left\{\tilde{\pi}_{k|k-1}\right\}_{1:N}

\displaystyle\mathbf{a}_{k}^{T}(\mathbf{x}_{k-1})\boldsymbol{\alpha}_{k}

(4)

\displaystyle s.t.

\displaystyle\sum_{i\in\mathcal{S}}\alpha_{k}^{(i)}=1,\ \alpha_{k}^{(i)}\geq 0,

is an approximate solution of the CCP. In (

(5)

We define the regret of an agent that follows

Definition 3

In the above definition,

\displaystyle\underset{\left\{\pi_{k|k-1}\right\}_{1:N}}{\text{min}}

\displaystyle\mathcal{D}_{\text{KL}}\left(\pi_{1:N|0}||p_{1:N|0}\right)-\sum_{k=1}^{N}\mathbb{E}_{\pi_{k-1:k-1}}\left[\tilde{r}_{k}(\mathbf{X}_{k-1})\right]

(11)

\displaystyle s.t.

\displaystyle\pi_{k|k-1}\in\mathcal{D},\ \ \forall k.

Problem
3
is an infinite-dimensional relaxation of Problem
1

Definition 4

\bar{\pi}_{0:N}:=\pi_{0:0}\prod_{k=1}^{N}\bar{\pi}_{k|k-1}=\pi_{0:0}\bar{\pi}_{1:N|0}

VII
Conclusions

We considered the problem of designing agents that are able to dynamically choose between different data sources in order to tackle tracking tasks. We formulated the problem as a data-driven control problem and this led to study an integer optimal control problem. After finding the optimal solution, which determines how the use of the different sources should be orchestrated by the agent, we formalized a notion of regret. Then, by solving a relaxation of the control problem, we gave a regret upper bound. The results were complemented via simulations on a connected cars scenario.

\displaystyle-\mathbb{E}_{\pi_{N-1:N-1}}\left[\ln\mathbb{E}_{p_{N|N-1}}\left[\exp(\bar{\rho}_{N}(\mathbf{X}_{N}))\right]\right].

Moreover:

\displaystyle-\mathbb{E}_{\pi_{N-1:N-1}}\left[\ln\mathbb{E}_{p_{N|N-1}}\left[\exp(\bar{\rho}_{N}(\mathbf{X}_{N}))\right]\right]

\displaystyle=-\mathbb{E}_{\pi_{N-1:N-1}}\left[\hat{\rho}_{N-1}(\mathbf{X}_{N-1})\right]

\displaystyle=-\mathbb{E}_{\pi_{N-2:N-1}}\left[\hat{\rho}_{N-1}(\mathbf{X}_{N-1})\right]

\displaystyle=\int\int\pi_{N-1|N-2}\left(\mathbf{x}_{N-1}|\mathbf{x}_{N-2}\right)\pi_{N-2:N-2}(\mathbf{x}_{N-2})\hat{\rho}_{N-1}(\mathbf{x}_{N-1})d\mathbf{x}_{N-1}d\mathbf{x}_{N-2}

\displaystyle=-\mathbb{E}_{\pi_{N-2:N-2}}\left[\mathbb{E}_{\pi_{N-1|N-2}}\left[\hat{\rho}_{N-1}(\mathbf{X}_{N-1})\right]\right],

and

\displaystyle\mathbb{E}_{\pi_{1:N-2|0}}\left[\mathcal{D}_{\text{KL}}\left(\pi_{N-1|N-2}||p_{N-1|N-2}\right)\right]

\displaystyle=\mathbb{E}_{\pi_{N-2:N-2}}\left[\mathcal{D}_{\text{KL}}\left(\pi_{N-1|N-2}||p_{N-1|N-2}\right)\right].

Hence:

\displaystyle-\mathbb{E}_{\pi_{N-2:N-2}}\left[\tilde{r}_{N-1}(\mathbf{X}_{N-2})\right]+\mathbb{E}_{\pi_{1:N-2|0}}\left[\mathcal{D}_{\text{KL}}\left(\pi_{N-1|N-2}||p_{N-1|N-2}\right)\right]-\mathbb{E}_{\pi_{N-1:N-1}}\left[\ln\mathbb{E}_{p_{N|N-1}}\left[\exp(\bar{\rho}_{N}(\mathbf{X}_{N}))\right]\right]

\displaystyle=\mathbb{E}_{\pi_{N-2:N-2}}\left[\mathcal{D}_{\text{KL}}\left(\pi_{N-1|N-2}||p_{N-1|N-2}\right)-\mathbb{E}_{\pi_{N-1|N-2}}\left[{r}_{N-1}(\mathbf{X}_{N-1})+\hat{\rho}_{N-1}(\mathbf{X}_{N-1})\right]\right]

Again, this means that the problem can be split as the sum of:

\displaystyle\underset{\left\{\pi_{k|k-1}\right\}_{1:N-2}}{\text{min}}

\displaystyle\mathcal{J}_{N-1}\left\{\pi_{1:N-2|0},p_{1:N-2|0}\right\}

\displaystyle s.t.

\displaystyle\pi_{k|k-1}\in\mathcal{D},\ \ k\in 1:N-2,

and

\displaystyle\underset{\pi_{N-1|N-2}}{\text{min}}

\displaystyle\mathbb{E}_{\pi_{N-2:N-2}}\left[\mathcal{C}_{N-1}\left\{\pi_{N-1|N-2}\right\}\right]

(23)

\displaystyle s.t.

\displaystyle\pi_{N-1|N-2}\in\mathcal{D},

with

\displaystyle\mathcal{C}_{N-1}\left\{\pi_{N-1|N-2}\right\}:=\int\pi_{N-1|N-2}(\ln\frac{\pi_{N-1|N-2}}{p_{N-1|N-2}}-\bar{\rho}_{N-1}(\mathbf{x}_{N-1}))d\mathbf{x}_{N-1}

and

\displaystyle\bar{\rho}_{N-1}(\mathbf{x}_{N-1})={r}_{N-1}(\mathbf{x}_{N-1})+\hat{\rho}_{N-1}(\mathbf{x}_{N-1}).

The minimum for (
23
) is
\mathbb{E}_{\pi_{N-2:N-2}}\left[\bar{c}_{N-1}(\mathbf{X}_{N-2}))\right]
, with
\bar{c}_{N-1}(\mathbf{x}_{N-2})
being the cost obtained by solving:

\displaystyle\underset{\pi_{N-1|N-2}}{\text{min}}

\displaystyle\mathcal{C}_{N-1}\left\{\pi_{N-1|N-2}\right\}

\displaystyle s.t.

\displaystyle\pi_{N|N-2}\in\mathcal{D}.

That is, once the problem at time
N
is solved, the optimization problem up to
N-1
can be still split as the sum of two sub-problems with the one at
k=N-1
being independent on the sub-problem up to
k=N-2
. The sub-problem at
k=N-1
has the same structure as (
22
). Hence, by defining
\bar{\rho}_{N-1}(\mathbf{x}_{N-1})={r}_{N-1}(\mathbf{x}_{N-1})+\hat{\rho}_{N-1}(\mathbf{x}_{N-1})
, we have that its solution is

\bar{\pi}_{N-1|N-2}=\frac{p_{N-1|N-2}\exp\left(\bar{\rho}_{N-1}(\mathbf{x}_{N-1})\right)}{\int p_{N-1|N-2}\exp\left(\bar{\rho}_{N-1}(\mathbf{x}_{N-1})\right)d\mathbf{x}_{N-1}}.

This gives (
12
) - (
13
) at
k=N-1
. The optimal cost for the sub-problem at
k=N-1
is

-\mathbb{E}_{\pi_{N-2:N-2}}\left[\ln\mathbb{E}_{p_{N-1|N-2}}\left[\exp(\bar{\rho}_{N-1}(\mathbf{X}_{N-1}))\right]\right].

We can then conclude the proof by noticing the following. By iterating the above arguments we find that, at each of the remaining time steps in
1:N-2
, Problem
3
can always be split as the sum of two sub-problems, where the last one can be solved by finding the minimum of:

\displaystyle\underset{\pi_{k|k-1}}{\text{min}}

\displaystyle\mathcal{D}_{\text{KL}}\left(\pi_{k|k-1}||p_{k|k-1}\right)-\mathbb{E}_{\pi_{k|k-1}}\left[\bar{\rho}_{k}(\mathbf{X}_{k-1})\right]

(24)

\displaystyle s.t.

\displaystyle\pi_{k|k-1}\in\mathcal{D},

and
\bar{\rho}_{k}(\mathbf{x}_{k})={r}_{k}(\mathbf{x}_{k})+\hat{\rho}_{k}(\mathbf{x}_{k})
with
\hat{\rho}_{k}(\mathbf{x}_{k}):=\ln\mathbb{E}_{p_{k+1|k}}\left[\exp(\bar{\rho}_{k+1}(\mathbf{X}_{k+1}))\right]
. Hence, the solution of (
24
) is

\bar{\pi}_{k|k-1}=\frac{p_{k|k-1}\exp\left(\bar{\rho}_{k}(\mathbf{x}_{k})\right)}{\int p_{k|k-1}\exp\left(\bar{\rho}_{k}(\mathbf{x}_{k})\right)d\mathbf{x}_{k}},

and from this we can draw the desired conclusion. ∎
