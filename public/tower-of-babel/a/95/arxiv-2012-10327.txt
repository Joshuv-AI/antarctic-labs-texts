Solving a new type of quadratic optimization problem having a joint numerical range constraint
Huu-Quang Nguyen, Ruey-Lin Sheu, Yong Xia

Abstract
We propose a new formulation about quadratic optimization problems. The objective function F ⁡ ( f ⁡ ( x ) , g ⁡ ( x ) ) F(f(x),g(x)) is given as composition of a quadratic function F ⁡ ( z ) F(z) with two n n -variate quadratic functions z 1 = f ⁡ ( x ) z_{1}=f(x) and z 2 = g ⁡ ( x ) . z_{2}=g(x). In addition, it incorporates with a set of linear inequality constraints in z = ( z 1 , z 2 ) T , z=(z_{1},z_{2})^{T}, while having an implicit constraint that z z belongs to the joint numerical range of ( f , g ) . (f,g). The formulation is very general in the sense that it covers quadratic programming with a single quadratic constraint of all types, including the inequality-type, the equality-type, and the interval-type. Even more, the composition of “quadratic with quadratics” as well as the joint numerical range constraint all together allow us to formulate existing unsolved (or not solved efficiently) problems into the new model. In this paper, we solve the quadratic hypersurfaces intersection problem (QSIC) proposed by P o ´ \acute{{\rm o}} lik and Terlaky; and the problem (AQP) to minimize the absolute value of a quadratic function over a quadratic constraint proposed by Ye and Zhang. We show that, when F ⁡ ( z ) F(z) and the joint numerical range constraint are both convex, the optimal value of the convex optimization problem can be obtained by solving an SDP followed from a new development of the 𝒮 \mathcal{S} -procedure. The optimal solution can be approximated by conducting a bisection method on [ 0 , 2 ​ π ] . [0,2\pi]. On the other hand, if the joint numerical range of f ⁡ ( x ) f(x) and g ⁡ ( x ) g(x) is non-convex, the respective quadratic matrices of f ⁡ ( x ) f(x) and g ⁡ ( x ) g(x) must be linearly dependent. The linear dependence property enables us to solve (QSIC) and (AQP) accordingly by elementary analysis.

4.1
Problem (QSIC)

The problem (QSIC) defined in (
(v)
) can be recast in the following form:

\displaystyle{\rm(QSIC)}\hskip 8.5359pt\inf\limits_{x\in\mathbb{R}^{n}}(x^{T}Px+p^{T}x+p_{0})^{2}+(x^{T}Qx+q^{T}x+q_{0})^{2}.

It is to determine whether or not the two hypersurfaces,
f(x)=x^{T}Px+p^{T}x+p_{0}=0
and

g(x)=x^{T}Qx+q^{T}x+q_{0}=0
, intersect. If
v{\rm(QSIC)}=0,
or
v{\rm(QSIC)}<\rho
for some user-defined small
\rho>0
to accommodate possible noises arising from the problem data, the two hypersurfaces are thought to intersect with each other.
Otherwise,
v{\rm(QSIC)}
gives some sort of measurement as to how far the two hypersurfaces deviate from each other. For this purpose, the optimal value
v{\rm(QSIC)}
suffices to decide the intersection problem. However, problem (QSIC) belongs to the special case that
F(z)=z_{1}^{2}+z_{2}^{2}
and
a=b=c=0.
By Theorem
3.3
, we are able to find an approximate solution
\bar{x}
which is either a common root of the two quadratic equations
f(x)=g(x)=0;
or can be viewed as a point whose total distance to the two hypersurfaces
f(x)=0
and
g(x)=0
is the least.

We solve
{\rm(QSIC)}
by two cases.

Case 1
: If
\{P,Q\}
are linearly independent, by Theorem
2.2
and by taking

F(z)=z_{1}^{2}+z_{2}^{2}
,
a=b=c=0,

we see that (QSIC) is a (Po4) satisfying conditions (
17
)-(
18
). In this case, the optimal value
v(\rm{QSIC})

can be computed by the following (SDP):

\displaystyle\gamma^{*}

\displaystyle=\underset{\gamma,\,\alpha,\,\beta\in\mathbb{R}}{\sup}\left\{\begin{array}[]{cc}\gamma&|~M\succeq 0\end{array}\right\},

where
M
is

\begin{pmatrix}\begin{array}[]{ccc}1&&0\\
0&&1\end{array}&[0]&\begin{array}[]{cc}\frac{-\alpha}{2}\\
\frac{-\beta}{2}\end{array}\\
[0]^{T}&\alpha P+\beta Q&\alpha p+\beta q\\
\begin{array}[]{cc}\frac{-\alpha}{2}&\quad\quad\frac{-\beta}{2}\end{array}&\quad\alpha p^{T}+\beta q^{T}&\quad\alpha p_{0}+\beta q_{0}-\gamma\end{pmatrix}.

The optimal solution of (QSIC), if attainable, can be computed approximately via Algorithm
1
, Algorithm
2
and Theorem
3.3
.

Case 2
: If
\{P,Q\}
are linearly dependent, say
Q=t^{*}P.
If
P=Q=0,
then (QSIC) is an unconstrained convex quadratic optimization problem, which can be solved directly. Hence, let us assume that
P\not=0.
Then, we multiply the first equation in (
(v)
) by
t^{*}
and subtract it from the second equation to obtain

\displaystyle\begin{cases}\begin{array}[]{lll}x^{T}Px+p^{T}x+p_{0}-z_{1}=0,\\
(q^{T}-t^{*}p^{T})x+(q_{0}-t^{*}p_{0})+t^{*}z_{1}-z_{2}=0.\end{array}\end{cases}

(50)

Define
y^{T}=[x^{T},~{z^{T}}]
;
h^{T}=[q^{T}-t^{*}p^{T},t^{*},-1]
;
h_{0}=q_{0}-t^{*}p_{0}
;
and

\bar{A}=\begin{pmatrix}\begin{array}[]{ll}[0]_{n\times n}&[0]_{n\times 2}\\[0.0pt]
{}_{2\times n}&I_{2\times 2}\end{array}\end{pmatrix},~\bar{P}=\begin{pmatrix}\begin{array}[]{ll}P&[0]_{n\times 2}\\[0.0pt]

Then,

becomes

\displaystyle\inf_{y\in\mathbb{R}^{n+2}}

\displaystyle{\rm s.t.}

\displaystyle y^{T}\bar{P}y+\bar{p}^{T}y+p_{0}=0,~h^{T}y+h_{0}=0,

where

By the null space representation, the solution set for the hyperplane

can be written as

for some

where

and
V\in\mathbb{R}^{(n+2)\times(n+1)}
is the matrix basis of
\mathcal{N}(h)
.
It implies that
{\rm(QSIC)}
is reduced to the following (QP1EQC) problem:

\displaystyle\inf\limits_{z\in\mathbb{R}^{n+1}}

\displaystyle~(y_{0}+Vz)^{T}\bar{A}(y_{0}+Vz)\hskip 42.67912pt

(51)

\displaystyle{\rm s.t.}

\displaystyle~(y_{0}+Vz)^{T}\bar{P}(y_{0}+Vz)+\bar{p}^{T}(y_{0}+Vz)+p_{0}=0,

which can be solved by applying the S-lemma with equality. See
XWS
.

5
Conclusion and Discussion

In this paper, we propose a new type of quadratic optimization problems involving a joint numerical range constraint. There are many natural applications arising from such a formulation. Some applications like the double well potential problem (DWP)
FGLSX
;
XSFX
were already solved independently, while others like (QSIC) and (AQP) can now be resolved through our new approach. Interestingly, due to the composition of “quadratic with quadratics,” the objective function
F(f(x),g(x))
is indeed a polynomial of degree 4. We hope that our method can be later extended to solve optimization problems involving quartic polynomials.

Notice that, in Theorem
2.1
, we can replace
\{f,g\}
by
k
quadratic functions
\{f_{1},\cdots,f_{k}\}
. The theoretical results in this paper are still valid (the implementation can be more complicate though), provided the following conditions are satisfied:

\displaystyle\{(f_{1}(x),\cdots,f_{k}(x))|~x\in\mathbb{R}^{n}\}\text{~is convex},

\displaystyle\Theta_{k\times k}\succeq 0,

where
\Theta_{k\times k}
defines a quadratic function
f(z)=z^{T}\Theta_{k\times k}z+\eta^{T}z
of
k
variables. It suggests that the convexity of the joint numerical range of
\{f_{1},\cdots,f_{k}\}
is the central feature for many optimization problems and should be studied carefully in the future.
