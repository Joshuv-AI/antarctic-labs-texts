Conforming finite element DIVDIV complexes and the application for the linearized Einstein-Bianchi system Thanks:
Jun Hu, YiZhou Liang, Rui Ma

Abstract
This paper presents the first family of conforming finite element div ⁡ div \ddiv\ddiv complexes on tetrahedral grids in three dimensions. In these complexes, finite element spaces of H ⁡ ( div ⁡ div , Ω , 𝕊 ) H(\ddiv\ddiv,\Omega;\mathbb{S}) are from a current preprint [Chen and Huang, arXiv: 2007.12399, 2020] while finite element spaces of both H ⁡ ( sym ⁡ curl , Ω , 𝕋 ) H(\sym\ccurl,\Omega;\mathbb{T}) and H 1 ​ ( Ω , ℝ 3 ) H^{1}(\Omega;\mathbb{R}^{3}) are newly constructed here. It is proved that these finite element complexes are exact. As a result, they can be used to discretize the linearized Einstein-Bianchi system within the dual formulation.

Introduction

The linearized Einstein-Bianchi system from
[
16
]
reads

\displaystyle\dot{\boldsymbol{E}}+\ccurl\boldsymbol{B}=0,\ddiv\boldsymbol{E}=0,

\displaystyle\dot{\boldsymbol{B}}-\ccurl\boldsymbol{E}=0,\ddiv\boldsymbol{B}=0

with symmetric and traceless tensor fields
\boldsymbol{E}
and
\boldsymbol{B}
, respectively. By introducing a new variable
\sigma(t)=\int_{0}^{t}\ddiv\ddiv\boldsymbol{E}\,ds
, the linearized Einstein-Bianchi system can be realized as a Hodge wave equation

\displaystyle\begin{cases}\dot{\sigma}=\ddiv\ddiv\boldsymbol{E},\\
\dot{\boldsymbol{E}}=-\nabla\nabla\sigma-\sym\ccurl\boldsymbol{B},\\
\dot{\boldsymbol{B}}=\ccurl\boldsymbol{E}.\end{cases}

(1)

Given initial conditions
\sigma(0),\boldsymbol{E}(0)
and
\boldsymbol{B}(0)
, and with appropriate boundary conditions, (
1
) is well posed (see
[
16
]
).
The weak formulation of (
1
) in
[
16
]
introduces some Lagrange multiplies to reduce the constraint of the symmetry of the electric field
\boldsymbol{E}
and high derivatives of
\sigma
. In
[
11
]
, the first family of conforming finite element spaces of
H(\ccurl,\Omega;\mathbb{S})
on a bounded polyhedral domain
\Omega\subset\mathbb{R}^{3}
is constructed as well as those finite element spaces associated with the following Gradgrad complex from
[
2
,
15
]

P_{1}(\Omega)\xrightarrow{\subset}H^{2}(\Omega)\xrightarrow{\nabla\nabla}H(\ccurl,\Omega;\mathbb{S})\xrightarrow{\ccurl}H(\ddiv,\Omega;\mathbb{T})\xrightarrow{\ddiv}L^{2}(\Omega;\mathbb{R}^{3})\rightarrow 0,

(2)

where the space
H(\ccurl,\Omega;\mathbb{S})
consists of square-integrable tensors with square-integrable curl, taking values in the space of
\mathbb{S}
of symmetric matrices, and the space
H(\ddiv,\Omega;\mathbb{T})
consists of square-integrable tensors with square-integrable divergence, taking value in the space
\mathbb{T}
of traceless matrices.
The finite element Gradgrad complexes are utilized in
[
11
]
to discretize (
1
) with a weak formulation such that
\boldsymbol{E}
is sought in
C^{0}([0,T],H(\ccurl,\Omega;\mathbb{S}))
with the strongly symmetric constraint,

is in
C^{0}([0,T],H^{2}(\Omega))
and the magnetic tensor field
\boldsymbol{B}
is in
C^{1}([0,T],L^{2}(\Omega;\mathbb{T}))
. The polynomial degree of the lowest order case for the pair
(\sigma,\boldsymbol{E},\boldsymbol{B})
is
P_{9}(K)-P_{7}(K;\mathbb{S})-P_{6}(K;\mathbb{T})
on each tetrahedron
K
. In
[
4
]
, conforming and nonconforming virtual element Gradgrad complexes are constructed on tetrahedral grids.

This paper considers the discretization of (

(3)

2
Preliminaries

This section prepares some operators for vectors and tensors. More related results can be found in
[
6
]
. Let
\boldsymbol{I}
denote the
3\times 3
identity matrix.
Given a matrix
\boldsymbol{A}\in\mathbb{R}^{3\times 3}
, define

\displaystyle\sym\boldsymbol{A}=\frac{1}{2}(\boldsymbol{A}+\boldsymbol{A}^{T}),\;\ddev\boldsymbol{A}=\boldsymbol{A}-\frac{1}{3}{\rm tr}(\boldsymbol{A})\boldsymbol{I}.

For a vector
\boldsymbol{v}=(v_{1},v_{2},v_{3})^{T}
, define a skew-symmetric matrix as follows

\displaystyle{\rm mspn\ }\boldsymbol{v}=\begin{pmatrix}0&-v_{3}&v_{2}\\
v_{3}&0&-v_{1}\\
-v_{2}&v_{1}&0\end{pmatrix}.

For a matrix function
\boldsymbol{A}
,
the
\ccurl
and
\ddiv
operators apply row-wise to produce a matrix function
\ccurl\boldsymbol{A}
and a vector function
\ddiv\boldsymbol{A}
, respectively.
For a vector function
\boldsymbol{v}=(v_{1},v_{2},v_{3})^{T}
, the gradient
\nabla
applies row-wise to produce a matrix function

\displaystyle\nabla\boldsymbol{v}=\begin{pmatrix}\partial_{x}v_{1}&\partial_{y}v_{1}&\partial_{z}v_{1}\\
\partial_{x}v_{2}&\partial_{y}v_{2}&\partial_{z}v_{2}\\
\partial_{x}v_{3}&\partial_{y}v_{3}&\partial_{z}v_{3}\end{pmatrix}.

Define the symmetric gradient by

\displaystyle\epsilon(\boldsymbol{v})=\sym(\nabla\boldsymbol{v}).

Given a plane
f
with the unit normal vector
\boldsymbol{n}
, for a vector
\boldsymbol{v}\in\mathbb{R}^{3}
, the following orthogonal decomposition holds

\displaystyle\boldsymbol{v}=\Pi_{n}\boldsymbol{v}+\Pi_{f}\boldsymbol{v}\mathrel{\mathop{\mathchar 58\relax}}=(\boldsymbol{v}\cdot\boldsymbol{n})\boldsymbol{n}+(\boldsymbol{n}\times\boldsymbol{v})\times\boldsymbol{n}.

Define the tangential derivatives and the surface curl operator for a scalar function
q
as

\displaystyle\nabla_{f}q=\Pi_{f}\nabla q=(\boldsymbol{n}\times\nabla q)\times\boldsymbol{n},\quad\ccurl_{f}q=\boldsymbol{n}\times\nabla q.

Define the surface rot operator for a vector function
\boldsymbol{v}
as

\displaystyle\rrot_{f}\boldsymbol{v}=(\boldsymbol{n}\times\nabla)\cdot\boldsymbol{v}=\boldsymbol{n}\cdot(\ccurl\boldsymbol{v})

and the surface divergence
\ddiv_{f}
as

\displaystyle\ddiv_{f}\boldsymbol{v}=\ddiv_{f}(\Pi_{f}\boldsymbol{v})=(\boldsymbol{n}\times\nabla)\cdot(\boldsymbol{n}\times\boldsymbol{v})=\rrot_{f}(\boldsymbol{n}\times\boldsymbol{v}).

The surface gradient
\nabla_{f}\boldsymbol{v}
applies row-wise to produce a matrix function
\nabla_{f}\boldsymbol{v}
.
Define the surface symmetric gradient
\epsilon_{f}
by

\displaystyle\epsilon_{f}(\boldsymbol{v})=\sym(\nabla_{f}(\Pi_{f}\boldsymbol{v})).

In particular, for
\boldsymbol{n}=(0,0,1)^{T}
,
f
is the
x-y
plane. Then, these operators
\nabla_{f},\rrot_{f},

\ccurl_{f},\ddiv_{f},\epsilon_{f}
are standard differential operators in two dimensions.

Given a matrix function
\boldsymbol{A}
,
\boldsymbol{n}\times\boldsymbol{A}
acts row-wise while
\boldsymbol{A}\times\boldsymbol{n}
acts column-wise. The operators
\Pi_{f}
,
\rrot_{f}\boldsymbol{A}
and
\ddiv_{f}\boldsymbol{A}
act row-wise. Define the symmetric projection

\displaystyle\Pi_{f,{\rm sym}}\boldsymbol{A}=\sym(\Pi_{f}\boldsymbol{A}).

Given a vector function
\boldsymbol{v}
and a matrix function
\boldsymbol{A}
, the vector products commute with differentiation as follows

\displaystyle(\nabla\boldsymbol{v})^{T}\boldsymbol{n}=\nabla(\boldsymbol{v}\cdot\boldsymbol{n}),

\displaystyle\nabla\boldsymbol{v}\times\boldsymbol{n}=\nabla(\boldsymbol{v}\times\boldsymbol{n}),

\displaystyle(\ccurl\boldsymbol{A})^{T}\boldsymbol{n}=\ccurl(\boldsymbol{A}^{T}\boldsymbol{n}).
