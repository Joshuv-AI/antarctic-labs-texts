On the Satisfiability of Local First-Order Logics with Data
Benedikt Bollig, Arnaud Sangnier ORCID:0000-0002-6731-0340, Olivier Stietel

Abstract
. We study first-order logic over unordered structures whose elements carry a finite number of data values from an infinite domain. Data values can be compared wrt. equality. As the satisfiability problem for this logic is undecidable in general, we introduce a family of local fragments. They restrict quantification to the neighbourhood of a given reference point that is bounded by some radius. Our first main result establishes decidability of the satisfiability problem for the local radius-1 fragment in presence of one “diagonal relation”. On the other hand, extending the radius leads to undecidability. In a second part, we provide the precise decidability and complexity landscape of the satisfiability problem for the existential fragments of local logic, which are parameterized by the number of data values carried by each element and the radius of the considered neighbourhoods. Altogether, we draw a landscape of formalisms that are suitable for the specification of systems with data and open up new avenues for future research.

Introduction

Data logics have been introduced to reason about structures whose elements are labeled with a value from an infinite alphabet
[
Seg06
]
. The idea is to extend classic mathematical structures by a mapping that associates with every element of the universe a value from an infinite domain. When comparing data values only for equality, this view is equivalent to extending the underlying signature by a binary relation symbol whose interpretation is restricted to an equivalence relation. Among potential applications are XML reasoning or the specification of concurrent systems and distributed algorithms. Expressive decidable fragments include notably two-variable logics over data words and data trees
[
BDM+11
,
BMSS09
]
. The decidability frontier is fragile, though. Extensions to two data values, for example, quickly lead to an undecidable satisfiability problem. From a modeling point of view, those extensions still play an important role.
When specifying the
input-output behavior
of distributed algorithms
[
Fok13
,
Lyn96
]
, processes get an input value and produce an output value, which requires two data values per process. In leader election or renaming algorithms, for instance, a process gets its unique identifier as input, and it should eventually output the identifier of a common leader (leader election) or a unique identifier from a restricted name space (renaming).

In this paper, we consider a natural extension of first-order logic over unordered structures whose elements carry two or more data values from an infinite domain. There are two major differences between most existing formalisms and our language. While previous data logics are usually interpreted over words or trees, we consider unordered structures (or multisets). When each element of such a structure represents a process, we therefore do not assume a particular processes architecture, but rather consider clouds of computing units.
Moreover, decidable data logics are usually limited to one value per element, which would not be sufficient to model an input-output relation. Hence, our models are algebraic structures consisting of a universe and functions assigning to each element a tuple of integers. We remark that, for many distributed algorithms, the precise data values are not relevant, but whether or not they are the same is.
Like
[
BDM+11
,
BMSS09
]
, we thus add binary relations that allow us to test if two data values are identical and, for example, whether all output values were already present in the collection of input values (as required for leader election).

The first fundamental question that arises is whether a given specification is consistent. This leads us to the satisfiability problem. While the general logic considered here turns out to be undecidable already in several restricted settings, we show that interesting fragments preserve decidability. The fragments we consider are
local
logics in the sense that data values can only be compared within the neighborhood of a (quantified) reference element of the universe. In other words, comparisons of data values are restricted to elements whose distance to some reference point is bounded by a given radius.

We first consider a fragment over structures with two data values where the first value at the reference point can be compared with any second value in the neighborhood in terms of what we call the
diagonal relation
. In particular, we do not allow the symmetrical relation. However, we do not restrict comparisons of first values with each other in a neighborhood, nor do we restrict comparisons of second values with each other. Note that adding only one diagonal relation still constitutes an extension of the (decidable) two-variable first-order logic with two equivalence relations
[
KMPT12
,
Kie05
,
KT09
]
: equivalence classes consist of those elements with the same first value, respectively, second value. In fact, our main technical contribution is a reduction to this two-variable logic. The reduction requires a careful relabelling of the underlying structures so as to be able to express the diagonal relation in terms of the two equivalence relations. In addition, the reduction takes care of the fact that our logic does not restrict the number of variables. We can actually count elements up to some threshold and express, for instance, that at most five processes crash (in the context of distributed algorithms). This is a priori not possible in two-variable logic. We also show that this local fragment has an undecidable satisfiability problem for any radius strictly greater than 1.

In a second part, we study orthogonal local fragments where global quantification is restricted to being existential (while quantification inside a local property is still unrestricted). We obtain decidability for (i) radius 1 and an arbitrary number of data values, and for (ii) radius 2 and two data values. In all cases, we provide tight complexity upper and lower bounds. These results mark the exact decidability frontier of the existential fragments: satisfiability is undecidable as soon as we consider radius 3 in presence of two data values, or radius 2 together with three data values.

2.1.
Data Structures

We define here the class of models we are interested in. It consists of sets of nodes containing data values with the assumption that each node is labeled by a set of predicates and carries the same number of values. We consider hence
\Sigma
a finite set of unary relation symbols (sometimes
called unary predicates) and an integer
\mathit{Da}\geq 0
. A
\mathit{Da}
-data structure
over
\Sigma
is a tuple

\mathfrak{A}=(A,(P_{\sigma})_{\sigma\in\Sigma},f_{1},\ldots,f_{\mathit{Da}})

(in the following, we simply write
(A,(P_{\sigma}),f_{1},\ldots,f_{\mathit{Da}})
)
where
A
is a nonempty finite set,

P_{\sigma}\subseteq A
for all
\sigma\in\Sigma
, and

f_{i}
s are mappings
A\to\N
.
Intuitively
A
represents the set of nodes and
f_{i}(a)
is the
i
-th data value carried by
a
for each node
a\in A
.
For
X\subseteq A
, we let
\mathit{Val}_{\mathfrak{A}}(X)=\{f_{i}(a)\mid a\in X,i\in\{1,\ldots,\mathit{Da}\}\}
.
The set of all
\mathit{Da}
-data structures over
\Sigma

is denoted by
\textup{Data}[{\mathit{Da}},{\Sigma}]
.

While this representation is often very convenient to deal with
data values, a more standard way of
representing mathematical structures is in terms of binary
relations.
For every
(i,j)\in\{1,\ldots,\mathit{Da}\}\times\{1,\ldots,\mathit{Da}\}
, the mappings

f_{1},\ldots,f_{\mathit{Da}}
determine a binary relation

{{{}_{i}{\sim^{\mathfrak{A}}_{j}}}}\subseteq A\times A

as follows:

a\mathrel{{}_{i}{\sim^{\mathfrak{A}}_{j}}}b
iff
f_{i}(a)=f_{j}(b)
.
We may omit the superscript
\mathfrak{A}
if it is clear from the context
and if
\mathit{Da}=1
, as there will be only one relation, we way may write
\sim
for
{{}_{1}{\sim_{1}}}
.

2.2.
First-Order Logic

Let
\mathit{Da}\geq 0
be an integer,
\Gamma\subseteq\{\mathrel{{}_{i}{\sim}{{}_{j}}}\mid i,j\in\{1,\ldots,\mathit{Da}\}\}
a set of binary relation symbols, which
determines the binary relation symbols at our disposal, and

a
countably infinite set of variables. The set
\textup{dFO}[{\mathit{Da}},{\Sigma,\Gamma}]
of first-order formulas interpreted over
\mathit{Da}
-data structures
over

\varphi::={\sigma}(x)\mid x\mathrel{{\sim}{}}y\mid x=y\mid\varphi\vee\varphi\mid\neg\varphi\mid\exists x.\varphi

where

and

range over
\mathcal{V}
,
\sigma
ranges over
\Sigma
,
and
\sim\in\Gamma
.
We use standard abbreviations such as

We write

\varphi
are among

x_{1},\ldots,x_{k}
. We call
\varphi

if it does not
contain free variables. Moreover, we use
\Gamma_{\mathit{Da}}
to represent the
set of binary relation symbols
\{\mathrel{{}_{i}{\sim}{{}_{j}}}\mid i,j\in\{1,\ldots,\mathit{Da}\}\}

For
\mathfrak{A}=(A,(P_{\sigma}),f_{1},\ldots,f_{\mathit{Da}})\in\textup{Data}[{\mathit{Da}},{\Sigma}]
and a formula
\varphi\in\textup{dFO}[{\mathit{Da}},{\Sigma,\Gamma}]
,
the satisfaction relation
\mathfrak{A}\models_{I}\varphi
is defined wrt. an interpretation function
I:\mathcal{V}\to A
. The
purpose of
I
is to assign an interpretation to every (free)
variable of
\varphi
so that
\varphi
can be assigned a truth value.
For
x\in\mathcal{V}
and
a\in A
, the interpretation function
{I[x/a]}

maps
x
to
a
and coincides
with
I
on all other variables.
We then define:

\mathfrak{A}\models_{I}{\sigma}(x)
if
I(x)\in P_{\sigma}

\mathfrak{A}\models_{I}\varphi_{1}\vee\varphi_{2}
if
\mathfrak{A}\models_{I}\varphi_{1}
or
\mathfrak{A}\models_{I}\varphi_{2}

\mathfrak{A}\models_{I}x\mathrel{{}_{i}{\sim}{{}_{j}}}y
if
I(x)\mathrel{{}_{i}{\sim^{\mathfrak{A}}_{j}}}I(y)

\mathfrak{A}\models_{I}\neg\varphi
if
\mathfrak{A}\not\models_{I}\varphi

\mathfrak{A}\models_{I}x=y
if
I(x)=I(y)

\mathfrak{A}\models_{I}\exists x.\varphi
if there is
a\in A
s.t.
\mathfrak{A}\models_{{I[x/a]}}\varphi

Finally, for a data structure
\mathfrak{A}=(A,(P_{\sigma}),f_{1},\ldots,f_{\mathit{Da}})
, a formula
\varphi(x_{1},\ldots,x_{k})
and
a_{1},\ldots,a_{k}\in A
,
we write
\mathfrak{A}\models\varphi(a_{1},\ldots a_{k})
if there exists an interpretation function
I
such that
\mathfrak{A}\models_{I[x_{1}/a_{1}]\ldots[x_{k}/a_{k}]}\varphi
. In particular, for a sentence
\varphi
, we write
\mathfrak{A}\models\varphi
if there exists an interpretation function
I
such that
\mathfrak{A}\models_{I}\varphi
.

\textsc{DataSat}(\textup{dFO},1,\{{{}_{1}{\sim_{1}}}\})

2.4.2.
A Normal Form

When
\Gamma=\emptyset
,
satisfiability of monadic first-order logic is decidable
[
BGG97b
, Corollary 6.2.2]

and the logic actually has a useful normal form.
Let
\varphi(x_{1},\ldots,x_{n},y)\in\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
(note
that since the set of binary relation symbols is empty, the number
\mathit{Da}
of
data values does not matter here) and
k\geq 1

be a natural number. We use
\exists^{\geq k}y.\varphi(x_{1},\ldots,x_{n},y)
as an abbreviation for

\exists y_{1}\ldots\exists y_{k}.\bigwedge_{1\leq i<j\leq k}\neg{(y_{i}=y_{j})}\wedge\bigwedge_{1\leq i\leq k}\varphi(x_{1},\linebreak\ldots,x_{n},y_{i})
.
Thus,
\exists^{\geq k}y.\varphi
says that there are at least
k

distinct elements
y
that verify
\varphi
.
We call a formula of the form
\exists^{\geq k}y.\varphi
a
threshold formula
.
We also use

\exists^{=k}y.\varphi
as an abbreviation for

\exists^{\geq k}y.\varphi\wedge\neg\exists^{\geq k+1}y.\varphi
.

When
\Gamma=\emptyset
, the out-degree of every element is
0
so that,
over this particular signature, we deal with structures of bounded
degree.
The following lemma will turn out to be useful. It is due to Hanf’s locality theorem
[
Han65
,
Lib04
]

for structures of bounded degree (cf.
[
BK12
, Theorem 2.4]
).

Lemma
\thethm
.

Every formula from
\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
with one free variable
x

is effectively equivalent to a Boolean combination of
formulas of the form
\sigma(x)
with
\sigma\in\Sigma
and
threshold formulas of the form

\exists^{\geq k}y.\varphi_{U}(y)
where
U\subseteq\Sigma
and

\varphi_{U}(y)=\bigwedge_{\sigma\in U}\sigma(y)\wedge\bigwedge_{\sigma\in\Sigma\setminus U}\neg\sigma(y)
.

2.4.3.
Extended Two-Variable First-Order Logic

One way to skirt the undecidability result of Theorem

2.2
is to restrict the number of allowed variables
in the formulas. We denote by
\textup{dFO}^{2}[{\mathit{Da}},{\Sigma,\Gamma}]
the
two-variable fragment of
\textup{dFO}[{\mathit{Da}},{\Sigma,\Gamma}]
, i.e. the
set of formulas in
\textup{dFO}[{\mathit{Da}},{\Sigma,\Gamma}]
which use only two variables (usually
x
and
y
). In a two-variable
formula, however, each of the two variables can be used arbitrarily
often. The satisfiability problem of two-variable logic over arbitrary finite
structures with two equivalence relations is decidable
[
KT09
, Theorem 15]
.
By a straightforward reduction to this problem, we obtain :

{thmC}

[
[
KT09
]
]
The problem
\textsc{DataSat}(\textup{dFO}^{2},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
is decidable.

Actually, this result can be generalized to
extended

two-variable first-order logic. A formula belongs to
\textup{ext-dFO}^{2}[{\mathit{Da}},{\Sigma,\Gamma}]
if it is of the form

\varphi\et\psi
where
\varphi\in\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
and

\psi\in\textup{dFO}^{2}[{\mathit{Da}},{\Sigma,\Gamma}]
. To obtain the next
result, the idea consists in first translating the formula

\varphi\in\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
to a two-variable formula thanks to new unary predicates.

Proposition
\thethm
.

The problem
\textsc{DataSat}(\textup{ext-dFO}^{2},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
is decidable.

Proof.

We first show that one can reduce the first-order part with
\Gamma=\emptyset

to a two-variable formula. Let
\varphi
be a sentence in

\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
. We show we can effectively construct
\varphi^{\prime}\in\textup{dFO}^{2}[{\mathit{Da}},{\Sigma^{\prime},\emptyset}]
with
\Sigma\subseteq\Sigma^{\prime}
such that
\varphi
is satisfiable iff
\varphi^{\prime}
is satisfiable.
Furthermore, if a structure
\mathfrak{A}
satisfies
\varphi
, then we can add an interpretation of the predicates in
\Sigma^{\prime}\setminus\Sigma
to
\mathfrak{A}
to get a model for
\varphi^{\prime}
.
Conversely, if a structure
\mathfrak{A}^{\prime}
satisfies
\varphi^{\prime}
, then
forgetting the interpretation of the predicates in

\Sigma^{\prime}\setminus\Sigma
in
\mathfrak{A}^{\prime}
give us a model for
\varphi
.

We apply Lemma
2.4.2
to
\varphi
and then obtain
\varphi^{\prime\prime}
.
As there is no free variable in
\varphi
, the formula
\varphi^{\prime\prime}
is a boolean combination of formulas of the form
\exists^{\geq k}y.\varphi_{U}(y)
where
U\subseteq\Sigma
.
Let
M
be the maximal such
k
(if there is no threshold formula,
\varphi^{\prime\prime}
is either
\mathit{true}
or
\mathit{false}
).
We define a set of unary predicates
\Lambda_{M}=\{\eta_{i}\mid 1\leq i\leq M\}

and let
\Sigma^{\prime}=\Sigma\cup\Lambda_{M}
. Intuitively the unary
predicates in
\Lambda_{M}
will be used to count up to
M
the
elements labeled by the same predicates in
\Sigma
associating each element of the
domain with a unique numerical index.
The following formulas will specify the meaning of the elements of
\Lambda_{M}
. First, let
\varphi_{same}(x,y)=\bigwedge_{\sigma\in\Sigma}\sigma(x)\leftrightarrow\sigma(y)
. With this, we define:

\begin{array}[]{rcl}\varphi_{\eta}^{1}&:=&\displaystyle\forall x.\bigvee_{i\in[1,M]}\big(\eta_{i}(x)\wedge\bigwedge_{j\in[1,M]\setminus\{i\}}\neg\eta_{j}(x)\big)\\
&&\\
\varphi_{\eta}^{2}&:=&\displaystyle\forall x.\bigwedge_{i\in[1,M-1]}\big(\eta_{i}(x)\rightarrow\neg\exists y.(x\neq y\wedge\varphi_{same}(x,y)\wedge\eta_{i}(y))\big)\\
&&\\
\varphi_{\eta}^{3}&:=&\displaystyle\forall x.\bigwedge_{i\in[2,M]}\big(\eta_{i}(x)\rightarrow(\exists y.\varphi_{same}(x,y)\wedge\eta_{i-1}(y))\big)\\
\end{array}

We then denote
\varphi_{\eta}:=\varphi_{\eta}^{1}\et\varphi_{\eta}^{2}\et\varphi_{\eta}^{3}\in\textup{dFO}^{2}[{\mathit{Da}},{\Sigma^{\prime},\emptyset}]
. We provide an
informal explanation of the previous formulas:

•

the formula
\varphi_{\eta}^{1}
ensures that each element is labeled by
a single label from
\Lambda_{M}
;

•

the formula
\varphi_{\eta}^{2}
ensures that there are no two elements
labeled by the same predicates in
\Sigma
which are labeled
by the same element
\eta_{i}
with
i\leq M-1
;

•

the formula
\varphi_{\eta}^{3}
ensures that if an element is labeled
with
\eta_{i}
with
i\geq 2
then there must exist
another element with the same labels in
\Sigma
labeled by
\eta_{i-1}
.

Then, for a model
\mathfrak{A}\in\textup{Data}[{\mathit{Da}},{\Sigma^{\prime}}]
of
\varphi_{\eta}
with carrier set
A
, an element
a\in A
, and an integer
1\leq i\leq M
, we have that
a\in P_{\eta_{i}}
iff
|\{b\in A\mid
for all
\sigma\in\Sigma
,
a\in P_{\sigma}
iff
b\in P_{\sigma}\}|\geq i
.
Then in
\varphi^{\prime\prime}
, we replace all threshold formulas
\exists^{\geq k}y.\varphi_{U}(y)
with
\exists y.\varphi_{U}(y)\et\eta_{k}(y)
in
order to obtain
\varphi^{\prime\prime\prime}\in\textup{dFO}^{2}[{\mathit{Da}},{\Sigma^{\prime},\emptyset}]
.
Finally we take
\varphi^{\prime}
as
\varphi^{\prime\prime\prime}\et\varphi_{\eta}
.

We can now proceed with the proof of the Proposition. Let
\varphi\et\psi
be a sentence such that
\varphi\in\textup{dFO}[{\mathit{Da}},{\Sigma,\emptyset}]
and
\psi\in\textup{dFO}^{2}[{\mathit{Da}},{\Sigma,\Gamma}]
.
We determine
\Sigma^{\prime}\supseteq\Sigma
and
\varphi^{\prime}
in
\textup{dFO}^{2}[{\mathit{Da}},{\Sigma,\Gamma}]
according to what we said above. Then, by Theorem
2.4.3
, it only remains to show that
\varphi\et\psi
is satisfiable iff
\varphi^{\prime}\et\psi
is satisfiable.

Suppose there is
\mathfrak{A}\in\textup{Data}[{\mathit{Da}},{\Sigma}]
such that
\mathfrak{A}\models\varphi\et\psi
. According to what we said, we can add propositions from

\Sigma^{\prime}\setminus\Sigma
to
\mathfrak{A}
to get a data structure
\mathfrak{A}^{\prime}
such that
\mathfrak{A}^{\prime}\models\varphi^{\prime}
.
As
\psi

\Sigma^{\prime}\setminus\Sigma

\mathfrak{A}^{\prime}\models\varphi^{\prime}\et\psi

Conversely, let
\mathfrak{A}^{\prime}\in\textup{Data}[{\mathit{Da}},{\Sigma^{\prime}}]
such that
\mathfrak{A}^{\prime}\models\varphi^{\prime}\et\psi
.
Then, “forgetting”

\mathfrak{A}^{\prime}

\Sigma^{\prime}\setminus\Sigma

\mathfrak{A}
such that
\mathfrak{A}\models\varphi
.
As we still have
\mathfrak{A}\models\psi

\mathfrak{A}\models\varphi\et\psi
.

3.
Dealing with Two Data Values

3.1.
Decidability with Radius One and One Diagonal Relation

We will show in this section that, when considering structures with two data values,
\textsc{DataSat}(1\textup{-Loc-dFO},2,\linebreak\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}},{{}_{1}{\sim_{2}}}\})

•

\mathfrak{A}=(A,(P_{\sigma}),f_{1},f_{2})\in\textup{Data}[{2},{\Sigma\cup\Gamma\cup\{\mathsf{eq}\}\cup\mathtt{C}_{M}}]
and an interpretation function

such that,
for all

and
{{}_{i}{\sim_{j}}}\in\Gamma
, we have

iff

.
Then,

\mathfrak{A}|_{I(x)}^{1}\models_{I}\hat{\psi}^{\prime\prime}(x)~\Longleftrightarrow~\mathfrak{A}|_{I(x)}^{1}\models_{I}\chi^{\prime}(x)\,.

Moreover, for
U\subseteq\Sigma
, a nonempty set
R\subseteq\Gamma
, and
k\in\N
, we have

\mathfrak{A}|_{I(x)}^{1}\models_{I}\Lbag U,R,k\Rbag(x)~\Longleftrightarrow~\mathfrak{A}\models_{I}\Lbag U,R,k\Rbag(x)\,.

We deduce that,
for all well-typed
\mathfrak{A}\in\textup{Data}[{2},{\Sigma\cup\Gamma\cup\{\mathsf{eq}\}\cup\mathtt{C}_{M}}]
and
interpretation functions
I
,

\mathfrak{A}\models_{I}\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\psi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{1}~\Longleftrightarrow~\mathfrak{A}\models_{I}\chi^{\prime}(x)\,.

We can apply this translation to all the terms
\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\psi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{1}
present in the formula
\varphi\in 1\textup{-Loc-dFO}[2,\Sigma,\linebreak\Gamma]
to obtain a formula
\chi\in\textup{dFO}[{2},{\Sigma\cup\{\mathsf{eq}\}\cup\mathtt{C}_{M},\emptyset}]
. From what we have seen if
\chi
has a well-typed model then
\varphi
is satisfiable (note to obtain a data structure in
\textup{Data}[{2},{\Sigma}]
from a well-typed model in
\textup{Data}[{2},{\Sigma\cup\Gamma\cup\{\mathsf{eq}\}\cup\mathtt{C}_{M}}]
, we simply forget the unary predicates not in
\Sigma
). Furthermore from a data structure in
\textup{Data}[{2},{\Sigma}]
, we can easily build a well-typed model in
\textup{Data}[{2},{\Sigma\cup\Gamma\cup\{\mathsf{eq}\}\cup\mathtt{C}_{M}}]
(by respecting the typing rules) and this is allows to conclude that if
\varphi
is satisfiable then
\chi
has a well-typed model.
∎

Step 2: Well-Diagonalized Structures

In
\mathtt{C}_{M}
, we still have the diagonal
relation
(1,2)\in\Gamma
.
Our goal is to get rid of it
so that we only deal with the diagonal-free set

\Gamma_{df}=\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}
. The idea is again to
extend a given structure
\mathfrak{A}
, but now we add new elements,
one for each value
n\in\mathit{Val}_{\mathfrak{A}}(A)
, which we tag with a unary symbol

\mathsf{ed}
and whose two data values are
n
. Diagonal equality
will be ensured through making a detour via these ‘diagonal’ elements
(hence the name
\mathsf{ed}
).

Formally, when we start from some
\mathfrak{A}=(A,(P_{\sigma}),f_{1},f_{2})\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq}\}}]
,
the data structure
\mathfrak{A}+\mathsf{ed}\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\}}]

is defined as
(A^{\prime},(P^{\prime}_{\sigma}),f_{1}^{\prime},f_{2}^{\prime})
where

A^{\prime}=A\uplus\mathit{Val}_{\mathfrak{A}}(A)
,
f_{i}^{\prime}(a)=f_{i}(a)
for all
a\in A
and
i\in\{1,2\}
,

f_{1}^{\prime}(a)=f_{2}^{\prime}(a)=a
for all
a\in\mathit{Val}_{\mathfrak{A}}(A)
,

P^{\prime}_{\sigma}=P_{\sigma}
for all
\sigma\in\Theta\setminus\{\mathsf{eq}\}
,

P^{\prime}_{\mathsf{ed}}=\mathit{Val}_{\mathfrak{A}}(A)
, and

P^{\prime}_{\mathsf{eq}}=P_{\mathsf{eq}}\cup\mathit{Val}_{\mathfrak{A}}(A)
.

We will need a way to ensure that the considered data structures are well-diagonalized. To this end, we introduce the following
sentence from
\textup{dFO}^{2}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\},\Gamma_{df}}]
:

\begin{array}[]{lcl}\xi_{\mathsf{ed}}^{\Theta}:=&&\bigwedge_{i\in\{1,2\}}\forall x.\exists y.(\mathsf{ed}(y)\wedge x\mathrel{{}_{i}{\sim}{{}_{i}}}y)\wedge\bigl(\forall x.\forall y.(\mathsf{ed}(x)\wedge\mathsf{ed}(y)\wedge x\mathrel{{}_{i}{\sim}{{}_{i}}}y)\rightarrow x=y\bigr)\\[3.01385pt]
&\wedge&\forall x.\mathsf{eq}(x)\leftrightarrow\exists y.(\mathsf{ed}(y)\wedge x\mathrel{{}_{1}{\sim}{{}_{1}}}y\wedge x\mathrel{{}_{2}{\sim}{{}_{2}}}y)\\[3.01385pt]
&\wedge&\forall x.\mathsf{ed}(x)\rightarrow\bigwedge_{\sigma\in\Theta}\neg\sigma(x)\end{array}

Informally, this formula ensures the following properties:

•

for each element, and each of its value, there exists an
element labeled by
\mathsf{ed}
having the same value at the same
position;

•

there is no two distinct elements labeled by
\mathsf{ed}
and
having an equal value at the same position;

•

for all elements labeled by
\mathsf{eq}
, there exists an element
labeled by
\mathsf{ed}
having the two same values at the same positions;

•

the elements labeled by
\mathsf{ed}
are not labeled by any other
labels from
\Theta
.

Every structure that is well-diagonalized satisfies
\xi_{\mathsf{ed}}^{\Theta}
.
The converse is not true in general. In particular, a model of
\xi_{\mathsf{ed}}^{\Theta}
is not necessarily eq-respecting.
However, if a structure satisfies a formula
\varphi\in\textup{dFO}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\},\Gamma_{df}}]
, then it is
possible to perform a permutation on the first (or the second) values
of its elements while preserving
\varphi
. This allows us to get:

Lemma
\thethm
.

Let
\mathfrak{B}\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\}}]
and
\varphi\in\textup{dFO}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\},\Gamma_{df}}]
. If
\mathfrak{B}\models\varphi\wedge\xi_{\mathsf{ed}}^{\Theta}
, then there exists an eq-respecting
\mathfrak{A}\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq}\}}]
such that
\mathfrak{A}+\mathsf{ed}\models\varphi
.

Proof.

Let
\mathfrak{B}=(A,(P_{\sigma}),f_{1},f_{2})
in
\textup{Data}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\}}]
such that
\mathfrak{B}\models\varphi\wedge\xi_{\mathsf{ed}}
. We define the sets
I=\{n\in\N\mid\exists b\in P_{\mathsf{ed}}.f_{1}(b)=n\}
and
O=\{n\in\N\mid\exists b\in P_{\mathsf{ed}}.f_{2}(b)=n\}
. Since

\mathfrak{B}\models\bigwedge_{i\in\{1,2\}}\bigl[\big(\forall x.\exists y.\mathsf{ed}(y)\wedge x\mathrel{{}_{i}{\sim}{{}_{i}}}y\big)\wedge\big(\forall x.\forall y.(\mathsf{ed}(x)\wedge\mathsf{ed}(y)\wedge x\mathrel{{}_{i}{\sim}{{}_{i}}}y)\rightarrow x=y\big)\bigr]\,,

we deduce that
|I|=|O|
and furthermore the mapping
\pi:I\mapsto O
defined by
\pi(n)=m
iff there exists
b\in P_{\mathsf{ed}}

such that
f_{1}(b)=n
and
f_{2}(b)=m
is a well-defined
bijection. It is well defined because there is a single element
b

in
P_{\mathsf{ed}}
such that
f_{1}(b)=n
and it is a bijection because
for all
m\in O
, there is a single
b\in P_{\mathsf{ed}}
such that

f_{2}(b)=m
. We can consequently extend
\pi
to be a
permutation from
\N
to
\N
. We then take the model
\mathfrak{A}^{\prime}=(A,(P_{\sigma}),\pi\circ f_{1},f_{2})
. Since
\varphi\wedge\xi_{\mathsf{ed}}\in\textup{dFO}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\},\Gamma_{df}}]
with
\Gamma_{df}=\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}

and since
\mathfrak{B}\models\varphi\wedge\xi_{\mathsf{ed}}
, we deduce that
\mathfrak{A}^{\prime}\models\varphi\wedge\xi_{\mathsf{ed}}

because performing a permutation on the first data values of the
elements of
\mathfrak{B}
does not affect the satisfaction of
\varphi\wedge\xi_{\mathsf{ed}}
(this
is a consequence of the fact that there is no comparison between the
first values and the second values of the elements). The
satisfaction of
\xi_{\mathsf{ed}}
by
\mathfrak{A}^{\prime}
allows us to deduce that
\mathfrak{A}^{\prime}
is
well-diagonalized. We can in fact safely remove from
\mathfrak{A}^{\prime}
the elements
of
P_{\mathsf{ed}}
to obtain a structure
\mathfrak{A}\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq}\}}]
which is eq-respecting ( this is due to the fact that
\mathfrak{A}^{\prime}\models\forall x.\mathsf{eq}(x)\leftrightarrow\exists y.(\mathsf{ed}(y)\wedge x\mathrel{{}_{1}{\sim}{{}_{1}}}y\wedge x\mathrel{{}_{2}{\sim}{{}_{2}}}y)\wedge\forall x.\mathsf{ed}(x)\rightarrow\bigwedge_{\sigma\in\Theta\setminus\{\mathsf{eq}\}}\neg\sigma(x)
) and
such that
\mathfrak{A}^{\prime}=\mathfrak{A}+\mathsf{ed}
.
∎

Step 3: Getting Rid Of the Diagonal Relation

We will now exploit
well-diagonalized data structures to reason about environments
relative to
\Gamma
in terms of environments relative to
\Gamma_{df}
.
Recall that
\Theta
ranges over finite sets such that
\Sigma\subseteq\Theta
.

Lemma
\thethm
.

Let
\mathfrak{A}=(A,,(P_{\sigma}),f_{1},f_{2})\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq}\}}]

be eq-respecting and
\mathfrak{B}=\mathfrak{A}+\mathsf{ed}
. Moreover, let
a\in A
,
U\subseteq\Sigma
, and
R\subseteq\Gamma
be a nonempty set. We have

\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=

\begin{cases}\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\Gamma_{df})\setminus P_{\mathsf{ed}}&\text{if }a\in P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\Gamma$}(1)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\Gamma_{df})&\text{if }a\notin P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\Gamma_{df}$}(2)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\{{{}_{1}{\sim_{1}}}\})\cap(P_{\mathsf{eq}}\setminus P_{\mathsf{ed}})&\text{if }a\notin P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\{{{}_{1}{\sim_{1}}},{{}_{1}{\sim_{2}}}\}$}(3)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\{{{}_{2}{\sim_{2}}}\})&\text{if }a\in P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\{{{}_{2}{\sim_{2}}},{{}_{1}{\sim_{2}}}\}$}(4)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\{{{}_{2}{\sim_{2}}}\})\setminus P_{\mathsf{ed}}&\text{if }a\notin P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\{{{}_{2}{\sim_{2}}}\}$}(5)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\{{{}_{1}{\sim_{1}}}\})\setminus P_{\mathsf{eq}}&\text{if }\hskip 53.50014pt\makebox[102.22168pt][l]{$R=\{{{}_{1}{\sim_{1}}}\}$}(6)\\
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(d,U,\{{{}_{2}{\sim_{2}}}\})&\text{if }a\notin P_{\mathsf{eq}}\text{ and }\makebox[102.22168pt][l]{$R=\{{{}_{1}{\sim_{2}}}\}$}(7)\\[-2.15277pt]
\quad\text{for the unique }d\in P_{\mathsf{ed}}\text{ such that }d\mathrel{{}_{1}{\sim^{\mathfrak{B}}_{1}}}a\\
\emptyset&\text{otherwise }\hskip 119.0001pt(8)\end{cases}

Example
\thethm
.

Before to provide the formal proof, let us go through the different cases of Lemma
3.1
using Figure
4
(a),

(1)

Let

and

. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{1},a_{2},a_{3}\}
.
We also have that

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\Gamma_{df})=\{a_{1},a_{2},a_{3},b_{1}\}
: These are the elements
that coincide with
a

exactly
on the first and the on the second data value when we dismiss the diagonal relation.
Of course, as we consider
\mathfrak{B}
, this includes
b_{1}
, which we have to exclude.
Thus,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\Gamma_{df})\setminus P_{\mathsf{ed}}
.

(2)

Let
a=a_{7}
and
R=\Gamma_{df}
. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\Gamma_{df})=\{a_{7}\}
. Since
a\not\in P_{\mathsf{eq}}
, it actually does not matter whether we include the diagonal relation or not.

(3)

Let
a=a_{7}
and
R=\{{{}_{1}{\sim_{1}}},{{}_{1}{\sim_{2}}}\}
. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{1},a_{2},a_{3}\}
.
So how do we get this set in
\mathfrak{B}
without referring to the diagonal relation?
The idea is to use only
{{}_{1}{\sim_{1}}}\in\Gamma_{df}
and to ensure data equality by restricting to elements in
P_{\mathsf{eq}}
(again excluding
P_{\mathsf{ed}}
).
Indeed, we have
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\{{{}_{1}{\sim_{1}}}\})\cap(P_{\mathsf{eq}}\setminus P_{\mathsf{ed}})=\{a_{1},a_{2},a_{3},b_{1}\}\cap(\{a_{1},a_{2},a_{3},b_{1}\}\setminus\{b_{1}\})=\{a_{1},a_{2},a_{3}\}
.

(4)

Let
a=a_{1}
and
R=\{{{}_{2}{\sim_{2}}},{{}_{1}{\sim_{2}}}\}
. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{4},a_{5}\}
.
So we are looking for elements that have
1
as the second data value and a first data value different from 1,
and this set is exactly
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\{{{}_{2}{\sim_{2}}}\})
.

(5)

Let
a=a_{5}
and
R=\{{{}_{2}{\sim_{2}}}\}
. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{1},a_{2},a_{3},a_{4}\}
,
which is the set of elements that have 1 as the second data value and a first data value different from 2.
Thus, this is exactly
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\{{{}_{2}{\sim_{2}}}\})\setminus P_{\mathsf{ed}}
(i.e., after discarding
b_{1}\in P_{\mathsf{ed}}
).

(6)

Let
a=a_{4}
and
R=\{{{}_{1}{\sim_{1}}}\}
. We have
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{8}\}
.
Looking at
\mathfrak{B}
and discarding the diagonal relation would also include
b_{3}
and any element with data-value
pair
(3,3)
. Discarding
P_{\mathsf{eq}}
, we obtain

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,\emptyset,\{{{}_{1}{\sim_{1}}}\})\setminus P_{\mathsf{eq}}=\{a_{8},b_{3}\}\setminus\{b_{3}\}=\{a_{8}\}
.

(7)

Let
a=a_{7}
and
R=\{{{}_{1}{\sim_{2}}}\}
. Then,
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,\emptyset,R)=\{a_{4},a_{5}\}
,
which is the set of elements whose second data value is 1 and whose first data value is different from 1.
The idea is now to change the reference point. Take the unique
d\in P_{\mathsf{ed}}
such that

d\mathrel{{}_{1}{\sim^{\mathfrak{B}}_{1}}}a
. Thus,
d=b_{1}
. The set

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(b_{1},\emptyset,\{{{}_{2}{\sim_{2}}}\})
gives us exactly the elements that
have 1 as the second data value and a first value different from 1, as desired.

Proof.

Let
\mathfrak{A}=(A,(P_{\sigma}),f_{1},f_{2})\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq}\}}]

be eq-respecting and
\mathfrak{B}=\mathfrak{A}+\mathsf{ed}
. We consider
a\in A
,
U\subseteq\Sigma
, and
R\subseteq\Gamma
be a nonempty set.
Note that by definition of
\mathtt{Env}
, we have

\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R)\setminus P_{\mathsf{ed}}
and when
R\neq\{{{}_{1}{\sim_{2}}}\}
, we have

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,R\setminus\{(1,2)\})=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R\cup\{{{}_{1}{\sim_{2}}}\})\cup\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R\setminus\{{{}_{1}{\sim_{2}}}\})
. We will use these two equalities in the rest of
the proof.
We now perform a case analysis on
R
.

(1)

Assume
R=\Gamma=\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}},{{}_{1}{\sim_{2}}}\}
. First we suppose
that
a\notin P_{\mathsf{eq}}
. Since
\mathfrak{A}
is eq-respecting it implies that

f_{1}(a)\neq f_{2}(a)
. Now assume there exists
b\in\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)
, this means
that
a\mathrel{{}_{1}{\sim^{\mathfrak{A}}_{1}}}b
and
a\mathrel{{}_{2}{\sim^{\mathfrak{A}}_{2}}}b

and
a\mathrel{{}_{1}{\sim^{\mathfrak{A}}_{2}}}b
. Hence we have

f_{2}(a)=f_{2}(b)
and
f_{1}(a)=f_{2}(b)
, which is
a contradiction. Consequently

\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\emptyset
. We
now suppose that
a\in P_{\mathsf{eq}}
. In that case, since
\mathfrak{A}
is eq-respecting, we have

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R\setminus\{{{}_{1}{\sim_{2}}}\})=\emptyset
. In fact if

a\mathrel{{}_{2}{\sim^{\mathfrak{A}}_{2}}}b
for some
b
then

a\mathrel{{}_{1}{\sim^{\mathfrak{A}}_{2}}}b
as
a\in P_{\mathsf{eq}}
. Hence we have
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R)\setminus P_{\mathsf{ed}}=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\Gamma_{df})\setminus P_{\mathsf{ed}}
.

(2)

Assume
R=\Gamma_{df}=\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}
. By a similar
reasoning as the previous case, if
a\in P_{\mathsf{eq}}
, we have
necessarily
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\emptyset
. Now suppose
a\notin P_{\mathsf{eq}}
. Thanks to this
hypothesis, we know that

P_{\mathsf{ed}}\cap\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\Gamma_{df})=\emptyset
and that
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}},\linebreak(1,2)\})=\emptyset
. Hence we obtain directly
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,\Gamma_{df})=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\Gamma_{df})
.

(3)

Assume
R=\{{{}_{1}{\sim_{1}}},{{}_{1}{\sim_{2}}}\}
. Again it is obvious that if

a\in P_{\mathsf{eq}}
, we have
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\emptyset
. We suppose that
a\notin P_{\mathsf{eq}}
. Note that we have that

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R)\subseteq P_{\mathsf{eq}}
and
\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,\{{{}_{1}{\sim_{1}}}\})\cap P_{\mathsf{eq}}=\emptyset
. Since

.

, we have
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\emptyset
. We now suppose that

. In that case, we have

\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma}(a,U,R)\cap P_{\mathsf{ed}}=\emptyset

\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\mathtt{Env}_{\mathfrak{B},\Sigma,\Gamma_{df}}(a,U,\{{{}_{2}{\sim_{2}}}\})
.

(5)

Assume

a\in P_{\mathsf{eq}}
, we have
\mathtt{Env}_{\mathfrak{A},\Sigma,\Gamma}(a,U,R)=\emptyset

(7)

Step 4: Counting in Two-Variable Logic

The next step is to express these constraints using two-variable formulas.
Counting in two-variable logic is established using further unary predicates.
These additional predicates allow us to define a partitioning of the universe of
a structure into so-called
intersections
.
Suppose
\mathfrak{A}=(A,(P_{\sigma}),f_{1},f_{2})\in\textup{Data}[{2},{\Theta\cup\{\mathsf{eq},\mathsf{ed}\}}]

.
A set is called an

in

if it is the intersection of some

A

Let

The logic
FO
over tri-binary structures
is the same as
FO
over bi-binary structures with the addition of the binary symbol
\mathsf{W}
.

\varphi^{\prime}_{\mathit{complete}}
be the following FO formula over tri-binary structure:

\displaystyle\varphi^{\prime}_{\mathit{complete}}=

\displaystyle\phantom{\wedge}\forall x.\forall y.\forall y^{\prime}.(\mathsf{H}xy\et\mathsf{V}yy^{\prime}\donc\mathsf{W}xy^{\prime})~~\et~~\forall x.\forall x.\forall^{\prime}y^{\prime}.(\mathsf{W}xy^{\prime}\et\mathsf{V}xx^{\prime}\donc\mathsf{H}x^{\prime}y^{\prime})\,.

data structures are grid-like and that an embedding of a domino system

our logical formulas to neighborhood of radius 3 (cf formula

(c,k)\in\mathit{B}_{1}^{\mathfrak{A}}(a_{p})

It implies that

.
Thanks to Lemma

.1,

So
\mathfrak{A}|_{a_{p}}^{2}\not\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
.

(4)

Assume that

•

and
f^{p}_{k}(c)=f_{k}(c)
. If

. Similarly assume that

and
k=j

If there exists

for some

. Then we have

. Consequently, we have
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
iff

[\![-]\!]

Lemma
\thethm
.

We have
\mathfrak{A}\models\varphi_{qf}(\vec{a})
iff
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![\varphi_{qf}]\!](\vec{a})
.

Proof.

Since
[\![\varphi_{qf}]\!](x_{1},\ldots,x_{n})
belongs to the quantifier free fragment of
2\textup{-Loc-dFO}[2,\Sigma,\Gamma_{2}]
, the only place where quantifiers can be used are in the local modalities
\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\psi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x_{p}}^{2}
. As a matter of fact, because of the inductive definition of
[\![\varphi]\!]
and that only the formulas
\exists x.\varphi
and
y\mathrel{{}_{j}{\sim}{{}_{k}}}z
change, we only have to prove that
\mathfrak{A}|_{a_{p}}^{2}\models\exists x.\varphi
iff
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![\exists x.\varphi]\!]_{x_{p}}
and that given
b,c\in A
, we have
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
iff
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![y\mathrel{{}_{j}{\sim}{{}_{k}}}z]\!]_{x_{p}}(b,c)
.

To show that
\mathfrak{A}|_{a_{p}}^{2}\models\exists x.\varphi
iff

[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![\exists x.\varphi]\!]_{x_{p}}
, we recall that
\mathfrak{A}|_{a_{p}}^{2}=(A^{\prime},(P^{\prime}_{\sigma}),f_{1}^{\prime},\ldots,f_{n}^{\prime})
with
A^{\prime}=\{b\in A\mid(b,i)\in\mathit{B}_{r}^{\mathfrak{A}}(a)
for some

i\in\{1,2\}\}
. Hence when we quantify existentially in
[\![\mathfrak{A}]\!]_{\vec{a}}
, we should only consider the element belonging to
A^{\prime}
. Thanks to Lemma
4.1
.1, we know that if
b\in A^{\prime}
then
(b,1)
and
(b,2)
belong to
\mathit{B}_{2}^{\mathfrak{A}}(a_{p})
. Consequently the formula
\varphi_{\mathit{B}_{2}(a_{p})}(x)
allows to focus on elements in
A^{\prime}
.

We now prove that given
b,c\in A
, we have
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
iff
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![y\mathrel{{}_{j}{\sim}{{}_{k}}}z]\!]_{x_{p}}(b,c)
and we first suppose that
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
and assume
\mathfrak{A}|_{a_{p}}^{2}=(A^{\prime},(P^{\prime}_{\sigma}),f_{1}^{\prime},\ldots,f_{n}^{\prime})
.
Using Lemma
4.1
, it implies that
b,c\in A^{\prime}
and
(b,j)
and
(c,k)
belong to same set between
\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
and
\mathit{B}_{2}^{\mathfrak{A}}(a_{p})\setminus\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
. We proceed by a case analysis.

•

If
(b,j),(c,k)\in\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
then by lemma
4.1
.2 we have that
[\![\mathfrak{A}]\!]_{\vec{a}}\models\varphi_{j,k,a_{p}}^{r=1}(b,c)
and thus
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![y\mathrel{{}_{j}{\sim}{{}_{k}}}z]\!]_{x_{p}}(b,c)
.

•

If
(b,j),(c,k)\in\mathit{B}_{2}^{\mathfrak{A}}(a_{p})\setminus\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
then by lemma
4.1
.4 we have that
[\![\mathfrak{A}]\!]_{\vec{a}}\models\varphi_{j,k,a_{p}}^{r=2}(b,c)
and thus
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![y\mathrel{{}_{j}{\sim}{{}_{k}}}z]\!]_{x_{p}}(b,c)
.

We now suppose that
[\![\mathfrak{A}]\!]_{\vec{a}}\models[\![y\mathrel{{}_{j}{\sim}{{}_{k}}}z]\!]_{x_{p}}(b,c)
.
It means that
[\![\mathfrak{A}]\!]_{\vec{a}}
satisfies
\varphi_{j,k,a_{p}}^{r=1}(b,c)
or
\varphi_{j,k,a_{p}}^{r=2}(b,c)
.
If
[\![\mathfrak{A}]\!]_{\vec{a}}\models\varphi_{j,k,a_{p}}^{r=1}(b,c)
, it implies that
(b,j)
and
(c,k)
are in
\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
, and we can then apply lemma
4.1
.2 to deduce that
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
.
If
[\![\mathfrak{A}]\!]_{\vec{a}}\models\varphi_{j,k,a_{p}}^{r=2}(b,c)
, it implies that
(b,j)
and
(c,k)
are in
\mathit{B}_{2}^{\mathfrak{A}}(a_{p})\setminus\mathit{B}_{1}^{\mathfrak{A}}(a_{p})
, and we can then apply lemma
4.1
.4 to deduce that
\mathfrak{A}|_{a_{p}}^{2}\models b\mathrel{{}_{j}{\sim}{{}_{k}}}c
. ∎

To provide a reduction from
\textsc{DataSat}(\exists\textup{-}{2}\textup{-Loc-dFO},2,\Gamma_{2})
to

\textsc{DataSat}(\textup{dFO},1,\Gamma_{1})
, having the formula
[\![\varphi_{qf}]\!](x_{1},\ldots,x_{n})

is not enough because to use the result of the previous
lemma, we need to ensure that there exists a model
\mathfrak{B}
and a tuple
of elements
(a_{1},\ldots,a_{n})
such that
\mathfrak{B}\models\ [\![\varphi_{qf}]\!](a_{1},\ldots,a_{n})
and as well that there exists

\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{B}=[\![\mathfrak{A}]\!]_{\vec{a}}
. We explain now how we
can ensure this last point.

Now, we want to characterize the structures of the form
[\![\mathfrak{A}]\!]_{\vec{a}}
.
Given a structure
\mathfrak{B}=(A,(P_{\sigma})_{\sigma\in\Sigma^{\prime}},f)\in\textup{Data}[{1},{\Sigma^{\prime}}]
and

\vec{a}\in A
, we say that
(\mathfrak{B},\vec{a})
is
well formed

iff there exists a structure
\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{B}=[\![\mathfrak{A}]\!]_{\vec{a}}
. Hence
(\mathfrak{B},\vec{a})
is
well formed
iff there
exist two functions
f_{1},f_{2}:A\to\N
such that
[\![\mathfrak{A}]\!]_{\vec{a}}=[\![(A,(P_{\sigma})_{\sigma\in\Sigma},f_{1},f_{2})]\!]_{\vec{a}}
.
We state three properties on
(\mathfrak{B},\vec{a})
, and we will show that they characterize being well formed.

(1)

(Transitivity) For all
b,c\in A
,
p,q\in\{1,\ldots,n\}
,

i,j,k,\ell\in\{1,2\}
if
b\in P_{a_{p}[{i},{j}]}
,
c\in P_{a_{p}[{i},{\ell}]}
and
b\in P_{a_{q}[{k},{j}]}
then
c\in P_{a_{q}[{k},{\ell}]}
.

(2)

(Reflexivity) For all
p
and
i
, we have
a_{p}\in P_{a_{p}[{i},{i}]}

(3)

(Uniqueness) For all
b\in A
, if
b\in\bigcap_{j=1,2}\bigcup_{p=1,\ldots,n}^{i=1,2}P_{a_{p}[{i},{j}]}
or
b\notin\bigcup_{j=1,2}\bigcup_{p=1,\ldots,n}^{i=1,2}P_{a_{p}[{i},{j}]}
then for any
c\in B
such that
f(c)=f(b)
we have
c=b
.

Each property can be expressed by a first order logic formula, which
we respectively name
\varphi_{\mathit{tran}}
,
\varphi_{\mathit{refl}}
and
\varphi_{\mathit{uniq}}
and we
denote by
\varphi_{\mathit{wf}}
their conjunction:

\hskip-3.0pt\begin{array}[]{ll}\varphi_{\mathit{tran}}&\!=\forall y\forall z.\Et_{p,q=1}^{n}\Et_{i,j,k,\ell=1}^{2}\Big(\!a_{p}[{i},{j}](y)\et a_{p}[{i},{\ell}](z)\et a_{q}[{k},{j}](y)\donc a_{q}[{k},{\ell}](z)\!\Big)\\
\varphi_{\mathit{refl}}(x_{1},\ldots,x_{n})&\!=\Et_{p=1}^{n}\Et_{i=1}^{2}a_{p}[{i},{i}](x_{p})\\
\varphi_{\mathit{uniq}}&\!=\forall y.\Big(\Et_{j=1}^{2}\Ou^{n}_{p=1}\Ou_{i=1}^{2}a_{p}[{i},{j}](y)\ou\Et_{j=1}^{2}\Et^{n}_{p=1}\Et^{2}_{i=1}\neg a_{p}[{i},{j}](y)\Big)\donc\\
&\qquad\qquad(\forall z.y\sim z\donc y=z)\\
\varphi_{\mathit{wf}}(x_{1},\ldots,x_{n})&\!=\varphi_{\mathit{tran}}\et\varphi_{\mathit{refl}}(x_{1},\ldots,x_{n})\et\varphi_{\mathit{uniq}}\end{array}

The next lemma expresses that the formula
\varphi_{\mathit{wf}}
allows to
characterise precisely the
1
-data structures in
\textup{Data}[{1},{\Sigma^{\prime}}]

which are well-formed.

Lemma
\thethm
.

Let
\mathfrak{B}\in\textup{Data}[{1},{\Sigma^{\prime}}]
and
a_{1},\ldots,a_{n}
elements of

\mathfrak{B}
, then

is well formed iff
\mathfrak{B}\models\varphi_{\mathit{wf}}(\vec{a})

Proof.

First, if
(\mathfrak{B},\vec{a})
is well formed, then there there exists

\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{B}=[\![\mathfrak{A}]\!]_{\vec{a}}
and by
construction we have
[\![\mathfrak{A}]\!]_{\vec{a}}\models\varphi_{\mathit{wf}}(\vec{a})
. We now suppose
that
\mathfrak{B}=(A,(P_{\sigma})_{\sigma\in\Sigma^{\prime}},f)
and
\mathfrak{B}\models\varphi_{\mathit{wf}}(\vec{a})
. In order to define the functions
f_{1},f_{2}:A\to\N
, we need
to introduce some objects.

We first define a function
g:\{1,\ldots,n\}\times\{1,2\}\to\N\setminus\mathit{Im}(f)
(where

\mathit{Im}(f)
is the image of
f
in
\mathfrak{B}
) which

•

for all

and

, we
have

a_{p}\in P_{a_{p}[{i},{3-i}]}
iff
g(p,1)=g(p,2)
;

•

for all
p,q\in\{1,\ldots,n\}
and
i,j\in\{1,2\}
,
we have
a_{q}\in P_{a_{p}[{i},{j}]}
iff
g(p,i)=g(q,j)
.

We use this function to fix the two data values carried by the
elements in
\{a_{1},\ldots,a_{m}\}
. We now explain why this function is
well founded, it is due to the fact
that
\mathfrak{B}\models\varphi_{\mathit{tran}}\et\varphi_{\mathit{refl}}(a_{1},\ldots,a_{n})
. In fact, since

\mathfrak{B}\models\varphi_{\mathit{refl}}(a_{1},\ldots,a_{n})
, we have for all
p\in\{1,\ldots,n\}
and
i\in\{1,2\}
,
a_{p}\in P_{a_{p}[{i},{i}]}
. Furthermore if
a_{p}\in P_{a_{p}[{i},{j}]}
then
a_{p}\in P_{a_{p}[{j},{i}]}
thanks to the formula
\varphi_{\mathit{tran}}
; indeed since we
have
a_{p}\in P_{a_{p}[{i},{j}]}
and
a_{p}\in P_{a_{p}[{i},{i}]}

and
a_{p}\in P_{a_{p}[{j},{j}]}
, we obtain
a_{p}\in P_{a_{p}[{j},{i}]}
. Next, we also have that if
a_{q}\in P_{a_{p}[{i},{j}]}
then
a_{p}\in P_{a_{q}[{j},{i}]}
again thanks to
\varphi_{\mathit{tran}}
; indeed since we
have
a_{q}\in P_{a_{p}[{i},{j}]}
and
a_{p}\in P_{a_{p}[{i},{i}]}

and
a_{q}\in P_{a_{q}[{j},{j}]}
, we obtain
a_{p}\in P_{a_{q}[{j},{i}]}
.

We also need a natural
d_{\mathit{out}}
belonging to
\N\setminus(\mathit{Im}(g)\cup\mathit{Im}(f))
. For
j\in\{1,2\}
, we define
f_{j}
as follows for all
b\in A
:

f_{j}(b)=\left\{\begin{array}[]{ll}g(p,i)&\text{if for some }p,i\text{ we have }b\in P_{a_{p}[{i},{j}]}\\
f(b)&\text{if for all $p,i$ we have $b\notin P_{a_{p}[{i},{j}]}$ and for some $p,i$ we have $b\in P_{a_{p}[{i},{3-j}]}$}\\
d_{\mathit{out}}&\text{if for all $p,i,j^{\prime}$, we have }b\notin P_{a_{p}[{i},{j^{\prime}}]}\end{array}\right.

Here again, we can show that since
\mathfrak{B}\models\varphi_{\mathit{tran}}\et\varphi_{\mathit{refl}}(a_{1},\ldots,a_{n})
, the functions
f_{1}
and
f_{2}
are well
founded. Indeed, assume that
b\in P_{a_{p}[{i},{j}]}\cap P_{a_{q}[{k},{j}]}
, then we have necessarily that

. For this we need to show that
a_{p}\in a_{q}[{k},{i}]
and we use again the formula
\varphi_{\mathit{tran}}
. This can be
obtained because we have
b\in P_{a_{p}[{i},{j}]}
and

a_{p}\in P_{a_{p}[{i},{i}]}
and
b\in P_{a_{q}[{k},{j}]}
.

We then define
\mathfrak{A}
as the
2
-data-structures

(A,(P_{\sigma})_{\sigma\in\Sigma},f_{1},f_{2})
. It remains to
prove that
\mathfrak{B}=[\![\mathfrak{A}]\!]_{\vec{a}}
.

First, note that for all
b\in A
,
p\in\{1,\ldots,n\}
and

i,j\in\{1,2\}
, we have
b\in P_{a_{p}[{i},{j}]}
iff

a_{p}\mathrel{{}_{i}{\sim^{\mathfrak{A}}_{j}}}b
. Indeed, we have
b\in P_{a_{p}[{i},{j}]}
,
we have that

and since
a_{p}\in P_{a_{p}[{i},{j}]}
we
have as well that

, as a consequence

a_{p}\mathrel{{}_{i}{\sim^{\mathfrak{A}}_{j}}}b
. In the other direction, if

a_{p}\mathrel{{}_{i}{\sim^{\mathfrak{A}}_{j}}}b
, it means that
f_{j}(b)=f_{i}(a_{p})=g(p,i)

and thus
b\in P_{a_{p}[{i},{j}]}
. Now to have
\mathfrak{B}=[\![\mathfrak{A}]\!]_{\vec{a}}
, one has
only to be careful in the choice of function

4.3.
Undecidability results

We show here
\textsc{DataSat}(\exists\textup{-}{3}\textup{-Loc-dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
and
\textsc{DataSat}(\exists\textup{-}{2}\textup{-Loc-dFO},3,\Gamma_{3})

are undecidable. To obtain this we provide reductions from

\textsc{DataSat}(\textup{dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
and we use the fact that any
2-data structure can be interpreted as a radius-3-ball of a 2-data structure or
respectively as a radius-2-ball of a 3-data structure.

4.3.1.
Radius 3 and two data values

In order to reduce
\textsc{DataSat}(\textup{dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
to the problem

\textsc{DataSat}(\exists\textup{-}{3}\textup{-Loc-dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
, we show that
we can transform any
2
-data structure
\mathfrak{A}
into another
2-data structure
\mathfrak{A}_{\mathsf{ge}}
such that
\mathfrak{A}_{\mathsf{ge}}
corresponds to the
radius-3-ball of any element of
\mathfrak{A}_{\mathsf{ge}}
and this transformation has
some kind of inverse. To obtain
\mathfrak{A}_{\mathsf{ge}}
from
\mathfrak{A}
, we add some
elements and in order to not take them into account for the
satisfaction of the formula, we label them with a fresh unary predicate

\mathsf{ge}
. Furthermore, given a formula
\varphi\in\textup{dFO}[{2},{\Sigma,\Gamma_{2}}]
, we transform it into a formula
T(\varphi)
in

\exists\textup{-}{3}\textup{-Loc-dFO}[{2},{\Sigma^{\prime},\Gamma_{2}}]
such that
\mathfrak{A}
satisfies
\varphi
iff
\mathfrak{A}_{\mathsf{ge}}

satisfies
T(\varphi)
. What follows is the formalization of this reasoning.

Let
\mathfrak{A}=(A,(P_{\sigma})_{\sigma},f_{1},f_{2})
be a
2
-data
structure in
\textup{Data}[{2},{\Sigma}]
and
\mathsf{ge}
be a fresh unary
predicate not in
\Sigma
. From
\mathfrak{A}
we build the following
2
-data structure

\mathfrak{A}_{\mathsf{ge}}=(A^{\prime},(P_{\sigma}^{\prime})_{\sigma},f_{1}^{\prime},f_{2}^{\prime})\in\textup{Data}[{2},{\Sigma\cup\{\mathsf{ge}\}}]

such that:

•

A^{\prime}=A\uplus\mathit{Val}_{\mathfrak{A}}(A)\times\mathit{Val}_{\mathfrak{A}}(A)
,

•

for
i\in\{1,2\}
and
a\in A
,
f_{i}^{\prime}(a)=f_{i}(a)
and for
(d_{1},d_{2})\in\mathit{Val}_{\mathfrak{A}}(A)\times\mathit{Val}_{\mathfrak{A}}(A)
,
f_{i}((d_{1},d_{2}))=d_{i}
,

•

for
\sigma\in\Sigma
,
P_{\sigma}^{\prime}=P_{\sigma}
,

•

P_{\mathsf{ge}}=\mathit{Val}_{\mathfrak{A}}(A)\times\mathit{Val}_{\mathfrak{A}}(A)
.

Hence to build
\mathfrak{A}_{\mathsf{ge}}
from
\mathfrak{A}
we have added to the elements of

\mathfrak{A}
all pairs of data presented in
\mathfrak{A}
and in order to recognize
these new elements in the structure we use the new unary predicate

\mathsf{ge}
. We add these extra elements to ensure that all the elements of
the structure are located in the
radius-3-ball of any element of
\mathfrak{A}_{\mathsf{ge}}
.
We have then the following property.

Lemma
\thethm
.

\mathfrak{A}_{\mathsf{ge}}|_{a}^{3}=\mathfrak{A}_{\mathsf{ge}}
for all
a\in A^{\prime}
.

Proof.

Let
b\in A^{\prime}
and
i,j\in\{1,2\}
. We show that

\mathit{d}^{\mathfrak{A}_{\mathsf{ge}}}((a,i),(b,j))\leq 3
. i.e. that there is a path of length at most 3 from
(a,i)
to
(b,j)
in the data graph
\mathcal{G}(\mathfrak{A}_{\mathsf{ge}})
.
By construction of
\mathfrak{A}_{\mathsf{ge}}
, there is an element
c\in A^{\prime}
such that
f_{1}(c)=f_{i}(a)
and
f_{2}(c)=f_{j}(b)
.
So we have the path
(a,i),(c,1),(c,2),(b,j)
of length at most 3 from
(a,i)
to
(b,j)
in
\mathcal{G}(\mathfrak{A}_{\mathsf{ge}})
.
∎

Conversely, to
\mathfrak{A}=(A,(P_{\sigma})_{\sigma},f_{1},f_{2})\in\textup{Data}[{2},{\Sigma\cup\{\mathsf{ge}\}}]
, we associate
\mathfrak{A}_{\setminus\mathsf{ge}}=(A^{\prime},(P_{\sigma}^{\prime})_{\sigma},\linebreak f_{1}^{\prime},f_{2}^{\prime})\in\textup{Data}[{2},{\Sigma}]
where:

•

A^{\prime}=A\setminus P_{\mathsf{ge}}
,

•

for

and

,

•

for
\sigma\in\Sigma
,
P_{\sigma}^{\prime}=P_{\sigma}^{\prime}\setminus P_{\mathsf{ge}}
.

Finally we inductively translate any formula

\varphi\in\textup{dFO}[{2},{\Sigma,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}}]

by making it quantify over elements not labeled with

,

and

Lemma
\thethm
.

Let
\varphi

\textup{dFO}[{2},{\Sigma}]

\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
and
\mathfrak{B}\in\textup{Data}[{2},{\Sigma\cup\{\mathsf{ge}\}}]

•

\mathfrak{A}\models\varphi

•

\mathfrak{B}_{\setminus\mathsf{ge}}\models\varphi
iff
\mathfrak{B}\models T(\varphi)

Proof.

As for any
\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]

, it is sufficient to prove the second point.
We reason by induction on
\varphi
.
Let
\mathfrak{A}=(A,(P_{\sigma})_{\sigma},f_{1},f_{2})\in\textup{Data}[{2},{\Sigma\cup\{\mathsf{ge}\}}]
and let
\mathfrak{A}_{\setminus\mathsf{ge}}=(A^{\prime},(P_{\sigma}^{\prime})_{\sigma},f_{1}^{\prime},f_{2}^{\prime})\in\textup{Data}[{2},{\Sigma}]

The inductive hypothesis is that for any formula
\varphi\in\textup{dFO}[{2},{\Sigma}]
(closed or not) and any context interpretation function

we have
\mathfrak{A}_{\setminus\mathsf{ge}}\models_{I}\varphi\text{ iff }\mathfrak{A}\models_{I}T(\varphi)
.
Note that the inductive hypothesis is well founded in the sense that the interpretation
I
always maps variables to elements of the structures.

We prove two cases: when
\varphi
is a unary predicate and when

\varphi
starts by an existential quantification, the other cases
being similar. First, assume that
\varphi=\sigma(x)
where
\sigma\in\Sigma

\mathfrak{A}_{\setminus\mathsf{ge}}\models_{I}\sigma(x)

.
As

Second assume
\varphi=\exists x.\varphi^{\prime}

.
Thus, there is a

.
As

\mathfrak{A}\models_{I[x/a]}\neg\mathsf{ge}(x)

\mathfrak{A}\models_{I}\exists x.\neg\mathsf{ge}(x)\et T(\varphi^{\prime})

Conversely, suppose that
\mathfrak{A}\models_{I}T(\exists x.\varphi^{\prime})
.
It means that there is a
a\in A
such that
\mathfrak{A}\models_{I[x/a]}\neg\mathsf{ge}(x)\et T(\varphi^{\prime})
.
So we have that

, which means that
{I[x/a]}
takes values in

\mathfrak{A}_{\setminus\mathsf{ge}}\models_{I[x/a]}\varphi^{\prime}
.
So we have
\mathfrak{A}_{\setminus\mathsf{ge}}\models_{I}\exists x.\varphi^{\prime}
.
∎

From Theorem
2.2
, we know that

\textsc{DataSat}(\textup{dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
is undecidable. From a closed formula

\varphi\in\textup{dFO}[{2},{\Sigma,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}}]
, we build the formula
\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{T(\varphi)}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{3}
which belongs to
\exists\textup{-}{3}\textup{-Loc-dFO}[{2},{\Sigma\cup\{\mathsf{ge}\},\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}}]

\varphi
is satisfiable, it means that there exists
\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{A}\models\varphi
. By Lemma

4.3.1
,
\mathfrak{A}_{\mathsf{ge}}\models T(\varphi)
. Let

be an element
of
\mathfrak{A}
, then thanks to Lemma
4.3.1
, we have
\mathfrak{A}_{\mathsf{ge}}|_{a}^{3}\models T(\varphi)
.
Finally by definition of our logic,
\mathfrak{A}_{\mathsf{ge}}\models\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{T(\varphi)}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{3}
.
So
\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{T(\varphi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{3}
is satisfiable. Now assume
that
\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{T(\varphi)}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{3}

\thethm

4.3.2.
Radius 2 and three data values

We give a reduction from
\textsc{DataSat}(\textup{dFO},2,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\})
to

\textsc{DataSat}(\exists\textup{-}{2}\textup{-Loc-dFO},3,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}},{{}_{3}{\sim_{3}}}\})
. The idea is similar to the one used in the
proof of Lemma
4.1
to show that

\textsc{DataSat}(\exists\textup{-}{2}\textup{-Loc-dFO},2,\Gamma_{2})
is
N2EXP
-hard by reducing
the problem
\textsc{DataSat}(\textup{dFO},1,\Gamma_{1})
. The intuition is that
when we add the same extra value to each node, then all the elements
of the structure are in the ball of radius
2
of any element. Indeed we have the following lemma.

Lemma
\thethm
.

Let
\varphi
be
a formula in
\textup{dFO}[{2},{\Sigma,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}}]
. There exists
\mathfrak{A}\in\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{A}\models\varphi

if and only if there exists
\mathfrak{B}\in\textup{Data}[{3},{\Sigma}]
such that

\mathfrak{B}\models\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\varphi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{2}
.

Proof.

Assume that there exists
\mathfrak{A}=(A,(P_{\sigma})_{\sigma\in\Sigma},f_{1},f_{2})
in
\textup{Data}[{2},{\Sigma}]
such that
\mathfrak{A}\models\varphi
.Consider the
3
-data structure
\mathfrak{B}=(A,(P_{\sigma})_{\sigma\in\Sigma},f_{1},f_{2},f_{3})
such that
f_{3}(a)=0
for all
a\in A
. Let
a\in A
. It is clear that we have
\mathfrak{B}|_{a}^{2}=\mathfrak{B}

and that
\mathfrak{B}|_{a}^{2}\models\varphi
(because
\mathfrak{A}\models\varphi
and
\varphi
never mentions the third values of the elements
since it is a formula in
\textup{dFO}[{2},{\Sigma,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}}\}}]
). Consequently
\mathfrak{B}\models\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\varphi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{2}
.

Assume now that there exists
\mathfrak{B}=(A,(P_{\sigma}),f_{1},f_{2},f_{3})
in
\textup{Data}[{3},{\Sigma}]
such that
\mathfrak{B}\models\exists x.\mathopen{\hbox{${\langle}$}\kern-1.94444pt\hbox{${\langle}$}}{\varphi}\mathclose{\hbox{${\rangle}$}\kern-1.94444pt\hbox{${\rangle}$}}_{x}^{2}
. Hence there exists
a\in A
such that

\mathfrak{B}|_{a}^{2}\models\varphi
, but then by forgetting the third
value in
\mathfrak{B}|_{a}^{2}
we obtain a model in
\textup{Data}[{3},{\Sigma}]

which satisfies
\varphi
.
∎

2.2
, we obtain the following result.

Theorem
\thethm
.

The problem
\textsc{DataSat}(\exists\textup{-}{2}\textup{-Loc-dFO},3,\{{{}_{1}{\sim_{1}}},{{}_{2}{\sim_{2}}},{{}_{3}{\sim_{3}}}\})
is undecidable.

Summary of the results for the satisfiability problem

In this work, we have tried to pursue an exhaustive study in order to
determine when the satisfiability of the local first order logic with
data is decidable. The results we have obtained are provided in Table

1
. We observe that even if we consider the existential
fragment, as soon as the view of the elements has a radius bigger
than
3
, the satisfiability problem is undecidable. This table
allows us as well to see what are the missing elements in order to
fully characterize the decidability status of this satisfiability
problem. In particular, we do not know whether the decidability result
of Theorem
3.1
still holds when considering two
diagonal relations, but our proof technique does not seem to directly
apply. It would be as well very interesting to establish the relative
expressive power of these logics and to compare them with some other
well-known fragments as for instance the guarded fragment. Finally,
another research direction would be to see how our logic could be used
to verify distributed algorithms with data (each element in our model
representing a process).
