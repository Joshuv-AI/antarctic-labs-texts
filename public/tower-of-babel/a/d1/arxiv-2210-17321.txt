Dominator Coloring and CD Coloring in Almost Cluster Graphs A preliminary version of this paper appeared in th 18th Algorithms and Data Structures Symposium (WADS 2023).
Aritra Banik, Prahlad Narasimhan Kasthurirangan, Venkatesh Raman

Abstract
In this paper, we study two popular variants of Graph Coloring – Dominator Coloring and Class Domination Coloring . In both problems, we are given a graph G G and a ℓ ∈ ℕ \ell\in\mathbb{N} as input and the goal is to properly color the vertices with at most ℓ \ell colors with specific constraints. In Dominator Coloring , we require for each v ∈ V ⁡ ( G ) v\in V(G) , a color c c such that v v dominates all vertices colored c c . In Class Domination Coloring , we require for each color c c , a v ∈ V ⁡ ( G ) v\in V(G) which dominates all vertices colored c c . These problems, defined due to their applications in social and genetic networks, have been studied extensively in the last 15 years. While it is known that both problems are fixed-parameter tractable ( FPT ) when parameterized by ( t , ℓ ) (t,\ell) where t t is the treewidth of G G , we consider strictly structural parameterizations which naturally arise out of the problems’ applications. We prove that Dominator Coloring is FPT when parameterized by the size of a graph’s cluster vertex deletion (CVD) set and that Class Domination Coloring is FPT parameterized by CVD set size plus the number of remaining cliques. En route, we design simpler and faster FPT algorithms when the problems are parameterized by the size of a graph’s twin cover , a special CVD set. When the parameter is the size of a graph’s clique modulator , we design a randomized single-exponential time algorithm for the problems. These algorithms use an inclusion-exclusion based polynomial sieving technique and add to the growing number of applications using this powerful algebraic technique.

Introduction

Graphs motivated by applications in bio-informatics, social networks, and machine learning regularly define edges between data points based on some notion of similarity. As a consequence, we are often interested in how “close” a given graph is to a (special type of)

Parameterized Complexity and Algorithms.

The goal of parameterized complexity is to find ways of solving
NP
-hard problems more efficiently than brute force: here the aim is to restrict the combinatorial explosion to a parameter that is hopefully much smaller than the input size. Formally, a
parameterization
of a problem is assigning a positive integer parameter
k
to each input instance and we say that a parameterized problem is
fixed-parameter tractable
(
FPT
) if there is an algorithm that solves the problem in time
f(k)\cdot|I|^{O(1)}
, where
|I|
is the size of the input and
f
is an arbitrary computable function that depends only on the parameter
k
. We use
\mathcal{O}^{*}(f(k))
to denote the running time of such an algorithm. Such an algorithm is called an
FPT
algorithm and such a running time is called
FPT
running time. There is also an accompanying theory of parameterized intractability using which one can identify parameterized problems that are unlikely to admit
FPT
algorithms. These are essentially proved by showing that the problem is
W
-hard. We refer the interested readers to books such as
[
16
,
24
]
for an introduction to the theory of parameterized algorithms.

Proof.

5.2

We say that a clique

Consider an isolated clique

Observation 5.13

. A partial CD coloring is a mapping

{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
if it agrees with
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
on

. An extension
\textstyle\chi
of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
is disjoint if no vertex outside

is colored using a

We will prove the following theorem, which establishes that an optimal disjoint extension of a partial CD coloring can be found quickly.

Theorem 5.17

Let
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
be a partial CD coloring of
G
where
M\subseteq S
. Then, given an
\ell\in\mathbb{N}
, we can decide in
\mathcal{O}^{*}(2^{\mathcal{O}(k\log{k})})
-time if there exists a disjoint extension
\textstyle\chi
of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|\leq\ell
.

For each
Q_{i}\in\mathcal{Q}
, let
b_{i}
denote the number of vertices in
Q_{i}
that are uncolored by
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
. Let
\mathbf{b}=(b_{1},b_{2}\dots b_{q})^{T}
and let
\{v_{1},v_{2}\dots v_{k}\}
be an arbitrary ordering of
M
. Consider the matrix
A\in M(q,k)
with
A(i,j)=1
if
v_{j}\in N_{G}[Q_{i}]
and is 0 otherwise (similar to an adjacency matrix). Let
\mathbf{1}_{k}
denote the vector in
\mathbb{R}^{k}
containing only 1s. Consider the following Integer Linear Program (ILP):

\text{Minimize }\{\mathbf{1}_{k}\cdot\mathbf{x}\mid A\mathbf{x}\geq\mathbf{b},\ \mathbf{x}\in\mathbb{Z}^{k},\ \mathbf{x}\geq 0\}

We refer the interested reader to Chapter 6 of
[
16
]
for a discussion on the use of ILPs in the world of parameterized algorithms. We describe the intuition behind designing this ILP. The
i
th
component of
\mathbf{x}
, denoted by
x_{i}
, represents the number of color classes outside
\textup{Im}({{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}})
that
v_{i}\in M
is required to dominate. Consider an arbitrary disjoint extension
\textstyle\chi
of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
. By
5.13
, every
c\in\textup{Im}({\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}})\setminus\textup{Im}({{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}})
is dominated by some vertex in
M
. Since no two vertices in a clique can get the same color, for each
Q_{i}\in\mathcal{Q}
the total sum of colors that the vertices in
N_{G}[Q_{i}]\cap M
dominate must be at least
b_{i}
(the number of uncolored vertices in
Q_{i}
). This is exactly the
i
th
constraint in the linear program. We now formalize this notion below.

Note that the above program is feasible since
n\cdot\mathbf{1}
is a feasible solution. Let
\ell^{*}
denote the optimal value of the above program and
\ell^{\prime}=|{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}|
.

Lemma 5.18

There exists a disjoint extension
\textstyle\chi
of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|\leq\ell
if, and only if,
\ell^{*}\leq\ell-\ell^{\prime}
.

Proof.

Consider a disjoint extension
\textstyle\chi
of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|\leq\ell
. By
5.13
, every
c\in\textup{Im}({\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}})\setminus\textup{Im}({{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}})
is dominated by some vertex in
M
. Make this choice arbitrarily and let
v_{c}
denote this vertex. Let
x_{j}
denote the number of colors that
v_{j}
was chosen to dominate – i.e.,
x_{j}=|\{c\mid v_{c}=v_{j}\}|
. Since vertices in a clique must get different colors, for each clique
Q_{i}\in\mathcal{Q}
,
\sum_{j\mid v_{j}\in N_{G}[Q_{i}]\cap M}x_{j}\geq b_{i}
. Therefore,
A\mathbf{x}\geq\mathbf{b}
. Moreover, as
\mathbf{x}
satisfies the non-negativity and the integral constraints,
\mathbf{x}
is a feasible solution of ILP. Now,

\mathbf{1}_{k}\cdot\mathbf{x}=\sum_{i=1}^{k}x_{i}=|\textup{Im}({\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}})\setminus\textup{Im}({{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}})|=|\textup{Im}({\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}})|-|\textup{Im}({{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}})|\leq\ell-\ell^{\prime}

Thus,
\ell^{*}\leq\mathbf{1}_{k}\cdot\mathbf{x}\leq\ell-\ell^{\prime}
.

Now, assume that
\ell^{*}\leq\ell-\ell^{\prime}
. Let
\mathbf{x}
be a feasible solution of the ILP such that
\mathbf{1}_{k}\cdot\mathbf{x}\leq\ell-\ell^{\prime}
. For
1\leq j\leq k
, let
C_{j}=\{c^{1}_{j},c^{2}_{j}\dots c^{x_{j}}_{j}\}
be a set of colors. Color the uncolored vertices of
Q_{i}\in\mathcal{Q}
by an arbitrary set of
b_{i}
-many colors from
\cup_{j\mid v_{j}\in N_{G}[Q_{i}]\cap M}C_{j}
. Note that this is indeed possible –
\sum_{j\mid v_{j}\in N_{G}[Q_{i}]\cap M}x_{j}\geq b_{i}
by the
i
th
constraint of the ILP. Let this coloring be
\textstyle\chi
.
\textstyle\chi
is clearly a proper coloring of
G
. Moreover, a color in
C_{j}
is dominated by
v_{j}
in
\textstyle\chi
. Thus,
\textstyle\chi
is a disjoint extension of
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}
. Finally,

|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|\leq|{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}|+\sum^{k}_{j=1}|C_{j}|\leq\ell^{\prime}+(\ell-\ell^{\prime})\leq\ell

This completes the proof of this lemma.
∎

Since our ILP has
k
variables, it can be solved in
\mathcal{O}^{*}(2^{\mathcal{O}(k\log{k})})
-time
[
16
]
. Thus,
Theorem

5.17
follows as a corollary of
5.18
.

Consider
\Gamma
, a collection of partial CD colorings, with the following properties:

For all
{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}^{S}}\in\Gamma

(ii)

. We define the well known
Hitting Set
problem below.

Hitting Set

Input:
A set of elements
U
and
\mathcal{F}\subseteq\mathscr{P}(U)
; an integer
\kappa

Question:
Does there exist a hitting set
S\subseteq U
of
\mathcal{F}
with
|S|\leq\kappa
?

We let
(U,\mathcal{F},\kappa)
denote an instance of
Hitting Set
and assume that
|U|=n
. We will construct an instance
(G,\ell)
of
DomCol
from an instance
(U,\mathcal{F},\kappa)
of
Hitting Set
which has the following property:
(U,\mathcal{F},\kappa)
is a
yes
instance if, and only if,
(G,\ell)
is a
yes
instance where
\ell=n+2
.

For each
F\in\mathcal{F}
, we have a vertex
m_{F}\in V(G)
and for each
u\in U
, we have a corresponding vertex
v_{u}\in V(G)
. Moreover, in
V(G)
, we have a set
Q_{2}
of
(n-\kappa)
-many vertices and two special vertices
m_{1}
and
m_{2}
. We now define the edges of
G
. All the vertices of
Q_{1}=\{v_{u}\mid u\in U\}
are connected to each other as are all vertices in
Q_{2}
. The vertices
m_{1}
and
m_{2}
are adjacent to all vertices in
Q_{1}\cup Q_{2}
and to each other. For an
F\in\mathcal{F}
,
N_{G}(m_{F})=\{v_{u}\in Q_{1}\mid u\in F\}
. Let
M_{\mathcal{F}}=\{m_{F}\mid F\in\mathcal{F}\}
. Refer to
Figure

3
for a pictorial representation of
G
.

Note that
M=M_{\mathcal{F}}\cup\{m_{1},m_{2}\}
is a cluster vertex deletion set of
G
and
G-M
consists of the two cliques
Q_{1}
and
Q_{2}
. Let
\ell=n+2
and
k=|M|=|\mathcal{F}|+2
. First, note that
G
cannot be colored with fewer than
(n+2)
-many colors since
Q_{1}\cup\{w_{1},w_{2}\}
is a clique of size
n+2
. The main result of this section is the following.

Theorem 7.5

(U,\mathcal{F},\kappa)
is a
yes
instance of
Hitting Set
if, and only if,
(G,\ell)
is a
yes
instance of
DomCol
.

It is known, due to
[
18
]
, that
Hitting Set
does not admit a polynomial kernel unless
\textup{{NP}}\subseteq\textup{{coNP}/poly}
. Moreover this also implies, under the Set Cover Conjecture
[
15
]
, that
DomCol
does not admit any
\mathcal{O}^{*}({(2-\epsilon)}^{k})
-time algorithm where
k
is the size of a CVD set. Therefore,
Theorems

7.4
and
7.3
follow from
Theorem

7.5
. We prove this theorem in two steps: first we show that
(U,\mathcal{F},\kappa)
is a
yes
instance of
Hitting Set
if, and only if, there exists a dominator coloring
\textstyle\chi
of
G
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
such that all vertices in
M\setminus\{m_{2}\}
get the same color and then show that there exists a dominator coloring with this property of optimal size. We prove these two results as the final two lemmas of the paper below.

(G,\ell)
from
(U,\mathcal{F},\kappa)
.

Lemma 7.6

(U,\mathcal{F},\kappa)
is a
yes
instance of
Hitting Set
if, and only if, there exists a dominator coloring
\textstyle\chi
of
G
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
such that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{F})
for all
m_{F}\in M_{\mathcal{F}}
.

Proof.

Assume that
(U,\mathcal{F},\kappa)
is a
yes
instance of
Hitting Set
. Then, there exists a set
S\subseteq U
with
|S|\leq\kappa
which hits every set of
\mathcal{F}
. We define a coloring
\textstyle\chi
of
G
as follows. Color each vertex in
Q_{1}\cup\{m_{1},m_{2}\}
a different color and let
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{F})={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})
for all
m_{F}\in M_{\mathcal{F}}
. Let
Q^{S}_{1}=\{v_{u}\in Q_{1}\mid u\in S\}
. Then,
|Q^{S}_{1}|=|S|\leq\kappa
and hence
|Q_{1}\setminus Q^{S}_{1}|\geq n-\kappa
. Color the
(n-\kappa)
-many vertices in
Q_{2}
using the colors of in
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(Q_{1}\setminus Q^{S}_{1})
.

Note that
\textstyle\chi
is indeed a proper coloring of
G
– for if
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(u)={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(v)
for some
u
and
v
, then either
u,v\in M\setminus\{m_{2}\}
or (without loss in generality)
u\in Q_{1}
and
v\in Q_{2}
. In either case,
(u,v)\notin E(G)
. Moreover, vertices in
Q_{1}\cup Q_{2}\cup\{m_{1},m_{2}\}
dominate the color class
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{2})
. Consider a vertex
m_{F}\in M_{\mathcal{F}}
. Since there exists a
s\in S\cap F
,
x_{F}
is adjacent to
v_{s}\in Q_{1}
. Since
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(v_{s})
is not used to color any other vertex in the graph,
m_{F}
dominates this color class. Since
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
and
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{F})
for all
m_{F}\in M_{\mathcal{F}}
, we have the forward direction of this proof.

Now, let
\textstyle\chi
be a dominator coloring of
G
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
where
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{F})
for all
m_{F}\in M_{\mathcal{F}}
. Since
Q_{1}\cup\{m_{1},m_{2}\}
is a clique of
G
,
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(Q_{1}\cup\{m_{1},m_{2}\})|=n+2
. Moreover, the
(n-\kappa)
-many vertices in
Q_{2}
cannot be colored with either
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})
or
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{2})
as
N_{G}[m_{1}]=N_{G}[m_{2}]\supseteq Q_{2}
. Thus,
\textstyle\chi
must use
(n-\kappa)
-many colors of
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(Q_{1})
to color the vertices of
Q_{2}
.

Moreover as every vertex in
M_{\mathcal{F}}
is colored with
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})
, they must dominate a color class that is only used in
Q_{1}
. By the final sentence of the previous paragraph, there are at most
\kappa
-many such vertices in
Q_{1}
. Let
Q^{S}_{1}
denote this set of vertices and
S=\{u\in U\mid v_{u}\in Q^{S}_{1}\}
. Each vertex in
M_{\mathcal{F}}
must be adjacent to at least one vertex in
Q^{1}_{S}
. By construction of
G
this implies that
S\cap F\neq\emptyset
for all
F\in\mathcal{F}
. Since
|S|\leq\kappa
,
(U,\mathcal{F},\kappa)
is a
yes
instance of
Hitting Set
.
∎

Lemma 7.7

(G,\ell)
is a
yes
instance of
DomCol
if, and only if, there exists a dominator coloring
\textstyle\chi
of
G
with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
such that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})={\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{F})
for all
m_{F}\in M_{\mathcal{F}}
.

Proof.

Assume that
(G,\ell)
is a
yes
instance of
DomCol
. Then, there exists a dominator coloring
\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}
of
G
with
|\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}|=n+2
. By construction of
G
, a vertex
m_{F}\in M_{\mathcal{F}}
must either dominate the color class
\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}(m_{F})
or
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(v_{u})
for some
v_{u}\in Q_{1}
. Note that, in either case, exactly one vertex is colored with the color
m_{F}
dominates. Let
\delta(m_{F})
denote that vertex. Let
M_{a}=\{m_{F}\in M_{\mathcal{F}}\mid\delta(m_{F})=m_{F}\}
. We construct a coloring
\textstyle\chi
of
G
from
\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}
as follows: color every vertex in
M_{\mathcal{F}}

\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}(m_{1})
, for each
m_{F}\in M_{a}
color an arbitrary vertex in

with
\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}(m_{F})
(if

, then

.

Note that the only color that is used multiple times by

but not by
\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}
is
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{1})=\overline{{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}}(m_{1})

is an independent set,

is a proper coloring of

. Moreover, note that every vertex in

dominates
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{2})
as

is the only vertex colored with
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(m_{2})

. As every vertex

has a

which gets a unique color in

is a dominator coloring of

with
|{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}|=n+2
such that

for all

. Since the other side of the claim is trivial, this completes the proof of this lemma.

Conclusion and Future Work

In this paper, we introduced the study of structural parameterizations of
DomCol
and
CD Coloring
. There were three parameters of interest: clique modulator size, twin cover size, and CVD set size. We designed randomized algorithms, based on an inclusion-exclusion based polynomial sieving method, running in
\mathcal{O}^{*}(c^{k})
-time (for
c=16
for
DomCol
and
c=2
for
CD Coloring
), where
k
was the clique modulator size. For twin cover size, we had
\mathcal{O}^{*}(2^{\mathcal{O}(k\log{k})})
-time algorithms for both problems. These algorithms hinged on solving
Pre-Coloring Extension
-type problems quickly for dominator colorings and CD colorings. Finally, for the smallest parameter, CVD set size, we described an involved a double exponential-time branching algorithm for
DomCol
. For
CD Coloring
, our (much simpler) algorithm also depended on the number of cliques in the cluster graph obtained by deleting a CVD set. We list a few interesting open questions below:

(i)

We have shown that under ETH, we cannot do better than a
\mathcal{O}^{*}(2^{k})
-time algorithm for our two problems when
k
is the clique modulator size. While we have achieved this bound for
CD Coloring
, our algorithm for
DomCol
is (possibly) suboptimal. Crucially, the current bottleneck in our algorithm’s running time is the exact
\tilde{\mathcal{O}}(4^{n})
-time algorithm for
DomCol
we designed in
Section

3
. If this can be bettered to
\tilde{\mathcal{O}}(2^{n})
(which, we believe, is possible), our algorithm will run in
\mathcal{O}^{*}(4^{k})
-time.

(ii)

Does a faster
FPT
algorithm for
DomCol
parameterized by CVD set size exist? We have shown that
CD Coloring
, parameterized by CVD set size and the number of cliques which remain, is
FPT
. Is there a branching algorithm, similar to the one in
Section

6.1
for
DomCol
, which is
FPT
with respect to
only
CVD set size? Is
CD Coloring
, instead,
W
-hard with respect to this parameter?

(iii)

While we have shown strong positive results in this work, most lower bounds we designed are (possibly) loose. The constructions we use in
Section

7
all use a few (at most two) cliques – we believe that more involved constructions can give much tighter bounds, especially for parameterization with CVD set size.
