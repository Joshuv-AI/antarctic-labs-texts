Connection between near the D s + ​ D s − D_{s}^{+}D_{s}^{-} threshold enhancement in B + → D s + ​ D s − ​ K + B^{+}\to D_{s}^{+}D_{s}^{-}K^{+} and conventional charmonium χ c ​ 0 ​ ( 2 ​ P ) \chi_{c0}(2P)
Dan Guo 1,3, Jun-Zhang Wang 2,1, Dian-Yong Chen 4,5, Xiang Liu 1,3,5

Abstract
Focusing on recent measurement of B + → D s + ​ D s − ​ K + B^{+}\to D_{s}^{+}D_{s}^{-}K^{+} process given by the LHCb Collaboration, we propose that this newly observed near the D s + ​ D s − D_{s}^{+}D_{s}^{-} threshold enhancement can be due to the contribution of the χ c ​ 0 ​ ( 2 ​ P ) \chi_{c0}(2P) , which is a P P -wave charmonium below the D s + ​ D s − D_{s}^{+}D_{s}^{-} threshold. By performing a combined fit to the measured D s + ​ D s − D_{s}^{+}D_{s}^{-} , D s + ​ K + D_{s}^{+}K^{+} , and D s − ​ K + D_{s}^{-}K^{+} invariant mass spectra, introducing the χ c ​ 0 ​ ( 2 ​ P ) \chi_{c0}(2P) can well reproduce the near threshold enhancement in the D s + ​ D s − D_{s}^{+}D_{s}^{-} invariant mass spectrum. When depicting the whole D s + ​ D s − D_{s}^{+}D_{s}^{-} invariant mass spectrum, the contributions from higher charmonium ψ ⁡ ( 4230 ) \psi(4230) and charmoniumlike state X 0 ​ ( 4140 ) X_{0}(4140) are obvious. In addition, a charmed meson D ∗ ​ ( 3 3 ​ S 1 ) D^{*}(3^{3}S_{1}) with mass around 3015 MeV is found to be important to depict the D s − ​ K + D_{s}^{-}K^{+} invariant mass spectrum well. Especially, the importance of node effect of the spatial wave function of the χ c ​ 0 ​ ( 2 ​ P ) \chi_{c0}(2P) is revealed, by which the anomaly of the ratio Γ ⁡ ( X → D + ​ D − ) / Γ ⁡ ( X → D s + ​ D s − ) \Gamma(X\to D^{+}D^{-})/\Gamma(X\to D_{s}^{+}D_{s}^{-}) indicated by LHCb can be explained well. Finally, our scenario of the newly observed enhancement structure resulted from the χ c ​ 0 ​ ( 2 ​ P ) \chi_{c0}(2P) is enforced.
