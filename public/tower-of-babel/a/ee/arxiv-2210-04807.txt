Efficient NTK using Dimensionality Reduction
Nir Ailon, Supratim Shit

Abstract
Recently, neural tangent kernel (NTK) has been used to explain the dynamics of learning parameters of neural networks, at the large width limit. Quantitative analyses of NTK give rise to network widths that are often impractical and incur high costs in time and energy in both training and deployment. Using a matrix factorization technique, we show how to obtain similar guarantees to those obtained by a prior analysis while reducing training and inference resource costs. The importance of our result further increases when the input points’ data dimension is in the same order as the number of input points. More generally, our work suggests how to analyze large width networks in which dense linear layers are replaced with a low complexity factorization, thus reducing the heavy dependence on the large width.

Introduction

Deep learning techniques have overwhelmed the world of machine learning in the last decade. Among them, one of the popular techniques is the deep neural network. Usually, in practice, these networks are overparameterized, and they proved to be extremely successful in various applications like image recognition
[
11
,
2

[

[

etc. Due to the non-convexity of the cost function and the complex dynamics of the training process, it is incredibly challenging to explain the reason for their success.

In a recent breakthrough, Jacot et. al.,
[
17
]
discovered that
the dynamics of learning the network parameters at the infinite width limit regime tend to be that of a kernelized linear regression setting, with
respect to a feature map known as the
Neural Tangent Kernel

Du et. al.,
[

improved the original analysis by providing a sharper non-asymptotic bound for finite network width.
Further, using the NTK idea, Arora et. al.,
[
18
]
showed why the training error goes to zero even when adding adversarial noise to the input data. They also showed why these overparameterized networks have benign overfitting behaviour. These results follow when the network width is very high,
O(\mbox{poly}(n))
, where
n
is the number of input points. Unfortunately, in a regime where input points are in
\mathbb{R}^{O(n)}
dimensional space, the number of trainable parameters is infeasible. Therefore, training such a network would incur high time and energy costs. We refer the reader to
[
23
]
to understand the adverse societal and environmental effects of such costs.

In another line of work, matrix factorization has been proven to be a useful tool in reducing costs of both training and deploying deep networks, e.g.
[
28
,
31
,
20
]
. In this work, we provide a connection between matrix factorization ideas and NTK analysis, suggesting that the resources required to obtain NTK guarantees may not necessarily be as high as reported in previous work.

Following the work of
[
16
,
18
]
, we study a network containing a linear transformation of the input, followed by a RELU activation function,
followed by a scalar valued linear function, and follow the dynamic of this network with respect to an MSE loss function.
The NTK matrix given rise to by this network is well understood following the work of
[
16
,
18
]
. Here we replace the first
linear layer with a factorization thereof, and show that by carefully choosing the factorization parameters we can approximately preserve
the NTK structure and hence the network dynamics.

The factorization we choose, following ideas from
[
31
]
is a random
dimensionality reduction matrix (Johnson-Lindenstrauss) followed by
a trainable matrix which increases the dimension. The first matrix is constant, and does not change after the (random initialization).
Using well known properties of JL matrices, we show how the dynamics of the factorized network, which is much cheaper to execute,
mimic those of the original matrix.

. The first layer has

\mathbf{W}\in\mathbb{R}^{m\times d}
. We use the ReLU function as the activation function in the first layer. The second (latent) layer is denoted by
\mathbf{v}\in\mathbb{R}^{m}
. The norm of every input points to the network is assumed to be
1
. Given
n

\{\mathbf{X}_{i},\mathbf{y}_{i}\}_{i=1}^{n}
. We represent the set
\{\mathbf{X}_{i}\}
by a matrix
\mathbf{X}\in\mathbb{R}^{n\times d}
and
\{\mathbf{y}_{i}\}
by an
n
-dimensional vector
\mathbf{y}\in\mathbb{R}^{n}
. Based on some network parameters
\mathbf{W}
, and
\mathbf{v}
for every
\mathbf{X}_{i}
we get
\mathbf{u}_{i}
as follows,

{}\mathbf{u}_{i}=\frac{1}{\sqrt{m}}\sum_{r\leq m}\mathbf{v}_{r}\cdot\sigma(\mathbf{W}_{r}\mathbf{X}_{i}^{T}).

(1)

We represent the set
\{\mathbf{u}_{i}\}
by an
n
-dimensional vector
\mathbf{u}
. We learn
\mathbf{W}
and

such that it minimizes

.

In this paper we use the properties of the Johnson-Lindenstrauss transformation, which has been stated below for completeness.

Definition 3.1

(Johnson-Lindenstrauss
[
1
]
)
.

Let
\mathbf{M}\in\mathbb{R}^{n\times d}
represents
n
points in
\mathbb{R}^{d}
,
\delta\in(0,1)
. Let
\mathbf{S}
be a
d\times k
random matrix such that
k=O(\log(n/\delta))
. For each
i\in[d]
and
j\in[k]

\mathbf{S}_{i,j}\sim\mathcal{N}(0,1/\sqrt{d})
. Then for every pair of

we have
|\mathbf{M}_{i}\mathbf{M}_{j}^{T}-\mathbf{M}_{i}\mathbf{S}\mathbf{S}^{T}\mathbf{M}_{j}^{T}|\leq\|\mathbf{M}_{i}\|\cdot\|\mathbf{M}_{j}\|

.

The matrix
\mathbf{S}

3.1
Neural Tangent Kernel

Recent work by Du et. al.
[
16
]
showed that in an overparameterized (number of neurons
\Omega(n^{6})
) neural network, the dynamics of the gradient descent for a small learning rate
O(\lambda_{0}n^{-2})
behaves like a linear model.
The linear model is captured by a kernel matrix called the neural tangent kernel (NTK). Given
\mathbf{X}
the NTK matrix
\mathbf{H}^{\infty}\in\mathbb{R}^{n\times n}
is a gram matrix with the
(i,j)^{th}
term defined as follows,

\mathbf{H}_{i,j}^{\infty}=\mathbb{E}_{\mathbf{w}\sim\mathcal{N}(\mathbf{0},\mathbf{I}_{m})}\left[\mathbf{X}_{i}\mathbf{X}_{j}^{T}\mathbbm{1}\{\mathbf{w}\mathbf{X}_{i}^{T}\geq 0,\mathbf{w}\mathbf{X}_{j}^{T}\geq 0\}\right].

The main result in the paper reads as follows:

Theorem 3.1
.

Assume
\lambda_{0}=\lambda_{\min}(\mathbf{H}^{\infty})>0
. For
\delta\in(0,1)
, number of neurons
m=\Omega(\frac{n^{6}}{\lambda_{0}^{4}\delta^{2}})
, set
\mathbf{W}_{r}\sim\mathcal{N}(\mathbf{0},\mathbf{I})
for every
r\in[m]
and we set
\eta=O(\frac{\lambda_{0}}{n^{2}})
then during the gradient descent, we have the following with probability at least
1-\delta
at every
t=0,1,\ldots
,

\|\mathbf{u}(t)-\mathbf{y}\|^{2}\leq\left(1-\frac{\eta\lambda_{0}}{2}\right)^{t}\|\mathbf{u}(0)-\mathbf{y}\|^{2}

(2)

Now, assuming that we fix the second layer parameter, in order to ensure that
\|\mathbf{u}(t)-\mathbf{y}\|^{2}\leq\varepsilon\|\mathbf{u}(0)-\mathbf{y}\|^{2}
for some small
\varepsilon\in(0,1)
, the gradient descent has to run for
t=\Omega(\frac{\log(\varepsilon)}{\log(1-(\lambda_{0}/n)^{2})})
steps. The time taken to update
\mathbf{W}(t+1)
from
\mathbf{W}(t)
is
\Omega(nmd)
, i.e.,
\Omega\left(\frac{n^{7}d}{\lambda_{0}^{4}\delta^{2}}\right)
. Now, in the regime where
d=\Theta(n)
, it will take
\Omega\left(\frac{n^{8}\log(\varepsilon)}{\lambda_{0}^{4}\delta^{2}\log(1-(\lambda_{0}/n)^{2})}\right)
running time to achieve the above training loss. Notice the dependence on
m
(number of neurons) and the dimension of the input vectors.

In this paper, we apply dimensionality reduction techniques to reduce the effective number of neurons
m
and the dimension of input points
d
and thereby improving the overall running time. We present our results in two parts. First, we show how to reduce the dimension of the input points and how it affects the training process. Next, we show how to reduce the number of effective neurons in the latent layer.

4
Reducing Input Dimension

Let
\mathbf{X}\in\mathbb{R}^{n\times d}
be a set of
n
input points in
\mathbb{R}^{d}
. Recall that we assume each point is normalized to a unit vector. We apply a Johnson-Lindenstrauss
[
1
]
transformation
\mathbf{C}
on the input
\mathbf{X}
before feeding it into the network. Every index of
\mathbf{C}
is an i.i.d. sample of
\mathcal{N}(0,1/\sqrt{\ell})
, where
\ell=O(\log(n/\delta))
for some
\delta\in(0,1)
. This transformation is drawn once before training, and not updated in the training process. We use a low rank weight matrix
\mathbf{W}
which is defined as
\mathbf{W}=\mathbf{B}\mathbf{C}
, where
\mathbf{B}\in\mathbb{R}^{m\times\ell}
and
\mathbf{C}
is the
\ell\times d
JL transformation matrix. Now, based on the above low rank weight matrix
\mathbf{W}
for every input
\mathbf{X}_{i}
and network outputs
\mathbf{u}_{i}
as follows,

\mathbf{u}_{i}=\frac{1}{\sqrt{m}}\sum_{r\leq m}\mathbf{v}_{r}\cdot\sigma(\mathbf{B}_{r}\mathbf{C}\mathbf{X}_{i}^{T}).

Notice, how
\mathbf{B}
and
\mathbf{C}
replace
\mathbf{W}
in equation (
1
) in a plug and play fashion. Now we discuss the effect of this on the training phase.
Fixing,
\mathbf{C}
(the dimension reduction layer) and
\mathbf{v}
the goal is to learn
\mathbf{B}
that minimizes,

\min_{\mathbf{B}}\frac{1}{2}\sum_{i\leq n}\left(\mathbf{y}_{i}-\mathbf{u}_{i}\right)^{2}.

(3)

The above cost is a function of
\mathbf{B}
and it can be represented in vector form as
\Phi(\mathbf{B})=\frac{1}{2}\|\mathbf{y}-\mathbf{u}\|^{2}
.
The matrix
\mathbf{C}
is first initialized as mentioned above.
The parameter
\mathbf{v}
is also drawn as a random vector sampled from
\{-1,+1\}^{m}
. Both
\mathbf{C}
and
\mathbf{v}
are fixed and do not vary during training.

We now randomly initialize the trainable parameters
\mathbf{B}(0)
at time
0
, where every entry is an i.i.d. sample from
\mathcal{N}(0,1)
. Now with a fixed
\mathbf{C}
and
\mathbf{v}
, we learn
\mathbf{B}
using gradient descent on the above loss function equation (
3
) based on a small learning rate
\eta
. Every row of
\mathbf{B}_{r}
,
\forall r\in[m]
are updated as follows,

\displaystyle\mathbf{B}_{r}(t+1)

\displaystyle=

\displaystyle\mathbf{B}_{r}(t)-\eta\frac{\partial\Phi(\mathbf{B}(t))}{\partial\mathbf{B}_{r}(t)}

\displaystyle=

\displaystyle\mathbf{B}_{r}(t)-\frac{\eta}{\sqrt{m}}\sum_{j\leq n}(\mathbf{y}_{j}-\mathbf{u}_{j}(t))\mathbf{v}_{r}\mathbf{X}_{j}\mathbf{C}^{T}\mathbbm{1}\{\mathbf{B}_{r}(t)\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}

The NTK matrix
\mathbf{H}^{\infty}\in\mathbb{R}^{n\times n}
is now defined as follows:

\mathbf{H}_{i,j}^{\infty}=\mathbb{E}_{\mathbf{b}}\left[\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T}\mathbbm{1}\{\mathbf{b}\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{b}\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}\right]

(4)

Here
\mathbf{b}
is a random vector from
\mathcal{N}(\mathbf{0},\mathbf{I})
. The above term is the expected dot product between two vectors which corresponds to the change in the output for the inputs
\mathbf{X}_{i}
and
\mathbf{X}_{j}
with respect to
\mathbf{b}
, i.e.,
\langle\frac{\partial\mathbf{u}_{i}}{\partial\mathbf{b}},\frac{\partial\mathbf{u}_{j}}{\partial\mathbf{b}}\rangle
(for details on this derivation, refer to
[
18
]
).

Now for a random initialization
\mathbf{B}(0)
, fixed
\mathbf{C}
and
\mathbf{v}
we define
\mathbf{H}(0)\in\mathbb{R}^{n\times n}
such that
\forall i,j\in[n]
,

{}\mathbf{H}_{i,j}(0)=\frac{1}{m}\sum_{r\leq m}\left[\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T}\mathbbm{1}\{\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}\right]

(5)

Lemma 4.1
.

For
\mathbf{H}^{\infty}
and
\mathbf{H}(0)
as defined above, with at least
1-\delta
probability,

\|\mathbf{H}^{\infty}-\mathbf{H}(0)\|\leq O\left(\frac{n^{2}\log(n/\delta)}{m}\right)

Proof.

Every single term in the difference matrix
\mathbf{H}_{i,j}^{\infty}-\mathbf{H}_{i,j}(0)
is

\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{i}\left(\mathbb{E}[\mathbbm{1}\{\mathbf{b}\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{b}\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}]-\frac{1}{m}\sum_{r\leq m}\mathbbm{1}\{\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}\right)

Here the randomness is over
\mathbf{b}\in\mathbb{R}^{\ell}
, which takes
m
i.i.d random samples from
\mathcal{N}(\mathbf{0},\mathbf{I}_{\ell})
. For all
r\in[m]
the random variable
\mathbbm{1}\{\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}\in[0,1]
. Now since the above term is the difference between the expectation of a random variable and the empirical average of
m
i.i.d samples of the random variable, so by Hoeffding’s inequality we get the following with at least
1-\delta^{\prime}
probability,

|\mathbf{H}_{i,j}^{\infty}-\mathbf{H}_{i,j}(0)|\leq|\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T}|\frac{\log(2/\delta^{\prime})}{2m}.

Next, for a random
\mathbf{C}\in\mathbb{R}^{\ell\times d}
such that each entry of
\mathbf{C}
is an i.i.d. sample from
\mathcal{N}(0,1/\sqrt{\ell})
where
\ell=O(\frac{\log(n/\delta)}{\varepsilon^{2}})
, for all
i,j\in[n]
we have
\mathbb{P}(|\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T}-\mathbf{X}_{i}\mathbf{X}_{j}^{T}|\geq\varepsilon)<\delta/(2n^{2})
. Now for
\varepsilon=O(1)
, setting
\delta^{\prime}=\delta/(2n^{2})
and taking a union bound over all pairs of
(i,j)\in[n]
we get the following with at least
1-\delta
,

\displaystyle\|\mathbf{H}^{\infty}-\mathbf{H}(0)\|\leq\sum_{i,j}|\mathbf{H}_{i,j}^{\infty}-\mathbf{H}_{i,j}(0)|\leq O\left(n^{2}\frac{\log(2n^{2}/\delta)}{2m}\right)

∎

Now with the following lemma, we show that
\mathbf{H}(0)
does not change too much during the training period.

Lemma 4.2
.

If
\mathbf{B}_{1},\ldots,\mathbf{B}_{m}
are random vectors whose entries are iid sample from
\mathcal{N}(0,1)
then with probability
1-\delta
, the following holds.

For any set of vectors
\mathbf{B}_{1}(0),\ldots,\mathbf{B}_{m}(0)
if
\|\mathbf{B}_{r}\mathbf{C}-\mathbf{B}_{r}(0)\mathbf{C}\|\leq O\left(\frac{\delta\lambda_{0}}{n^{2}}\right)\stackrel{{\scriptstyle\Delta}}{{=}}R
, then with
\mathbf{B}
the matrix
\mathbf{H}\in\mathbb{R}^{n\times n}
whose
(i,j)^{th}
entries are defined as (
5
)
satisfies
\|\mathbf{H}-\mathbf{H}(0)\|\leq\frac{\lambda_{0}}{4}
and
\lambda_{\min}(\mathbf{H})\geq\frac{\lambda_{0}}{4}
.

Proof.

For a fixed
\mathbf{C}
and a random
\mathbf{B}_{r}
we define a random vector
\mathbf{W}_{r}=\mathbf{B}_{r}\mathbf{C}
. Similarly we also define
\mathbf{W}_{r}(0)=\mathbf{B}_{r}(0)\mathbf{C}
. Now consider the following event for every input
\mathbf{X}_{i}\in\mathbf{X}
and neuron
r\in[m]
,

\mathcal{E}_{r,i}=\{\exists\mathbf{B}_{r}:\|\mathbf{W}_{r}-\mathbf{W}_{r}(0)\|\leq R,\mathbbm{1}\{\mathbf{W}_{r}(0)\mathbf{X}_{i}^{T}\geq 0\}\neq\mathbbm{1}\{\mathbf{W}_{r}\mathbf{X}_{i}^{T}\geq 0\}\}.

The above event happens if and only if
|\mathbf{W}_{r}(0)\mathbf{X}_{i}^{T}|\leq R
. Now notice that for a fixed
\mathbf{C}
and a randomly initialized
\mathbf{B}_{r}(0)
we have
z\sim\mathcal{N}(0,1)
where
z=\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{i}^{T}
. So
\mathbb{P}(\mathcal{E}_{r,i})=\mathbb{P}(|z|\leq R)\leq\int_{-R}^{R}\frac{1}{\sqrt{2\pi}}\exp(-x^{2})dx\leq\frac{\sqrt{2}R}{\sqrt{\pi}}
. Now we bound deviation of every entry
(i,j)\in[n]\times[n]
as follows,

\displaystyle\mathbb{E}[|\mathbf{H}_{i,j}-\mathbf{H}_{i,j}(0)|]

\displaystyle=

\displaystyle\mathbb{E}\bigg[O\left(\frac{1}{m}\right)\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T}\sum_{r\leq m}(\mathbbm{1}\{\mathbf{B}_{r}\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{B}_{r}\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\}

\displaystyle-

\displaystyle\mathbbm{1}\{\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{i}^{T}\geq 0,\mathbf{B}_{r}(0)\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\})\bigg]

\displaystyle\leq

\displaystyle O\left(\frac{1}{m}\right)\sum_{r\leq m}\mathbb{E}[\mathbbm{1}\{\mathcal{E}_{r,i}\}\cup\mathbbm{1}\{\mathcal{E}_{r,j}\}]\leq O\left(\frac{2\sqrt{2}R}{\sqrt{\pi}}\right)\leq O(R)

So,
\mathbb{E}[\sum_{i,j}|\mathbf{H}_{i,j}-\mathbf{H}_{i,j}(0)|]\leq O(n^{2}R)
and by Markov inequality we have
\sum_{i,j}|\mathbf{H}_{i,j}-\mathbf{H}_{i,j}(0)|\leq O\left(\frac{n^{2}R}{\delta}\right)
with at least
1-\delta
probability. Therefore with at least
1-\delta
probability
\|\mathbf{H}-\mathbf{H}(0)\|\leq O\left(\frac{n^{2}R}{\delta}\right)
. Finally,

\lambda_{\min}(\mathbf{H})\geq\lambda_{\min}(\mathbf{H}(0))-O\left(\frac{n^{2}R}{\delta}\right)\geq\frac{\lambda_{0}}{2}

∎

Now we state our main theorem of this section describing the required network width and the learning rate to get to the desired training loss.

Theorem 4.1
.

Assume
\lambda_{0}=\lambda_{\min}(\mathbf{H}^{\infty})>0
. Fix
\delta\in(0,1)
, and take the number of neurons in the latent layer
m
to be
\Omega\left(\frac{n^{6}}{\lambda_{0}^{4}\delta^{2}}\right)
.

\mathbf{B}(0)
is a random matrix whose entries are i.i.d. sample from
\mathcal{N}(0,1)
and we let the learning rate
\eta
be
O\left(\frac{\lambda_{0}}{n^{2}}\right)
then during the gradient descent we have the following with probability at least
1-\delta
for
t=0,1,\ldots
,

\|\mathbf{u}(t)-\mathbf{y}\|^{2}\leq\left(1-\frac{\eta\lambda_{0}}{2}\right)^{t}\|\mathbf{u}(0)-\mathbf{y}\|^{2}

(6)

Proof.

We prove it by induction. The induction hypothesis is the following,

\|\mathbf{u}(t)-\mathbf{y}\|^{2}\leq\left(1-\frac{\eta\lambda_{0}}{2}\right)^{t}\|\mathbf{u}(0)-\mathbf{y}\|^{2}

(7)

The following corollary follows from the hypothesis.

Corollary 4.1
.

If the above hypothesis is true then we have the following for all
r\in[m]
.

\|\mathbf{W}_{r}(t+1)-\mathbf{W}_{r}(0)\|\leq\frac{4\sqrt{n}\|\mathbf{u}(0)-\mathbf{y}\|}{\sqrt{m}\lambda_{0}}\stackrel{{\scriptstyle\Delta}}{{=}}R^{\prime}

(8)

Proof.

\displaystyle\|\mathbf{W}_{r}(t+1)-\mathbf{W}_{r}(0)\|

\displaystyle\leq

\displaystyle\sum_{t^{\prime}\leq t}\left\|-\eta\frac{\partial\Phi(\mathbf{B}(t^{\prime}))}{\partial\mathbf{B}_{r}(t^{\prime})}\mathbf{C}\right\|

(9)

\displaystyle=

\displaystyle\eta\sum_{t^{\prime}\leq t}\left\|\sum_{j\leq n}\frac{(\mathbf{y}_{j}-\mathbf{u}_{j}(t^{\prime}))\mathbf{v}_{r}\mathbf{X}_{j}\mathbf{C}^{T}\mathbf{C}(\mathbbm{1}\{\mathbf{B}_{r}(t^{\prime})\mathbf{C}\mathbf{X}_{j}^{T}\geq 0\})}{\sqrt{m}}\right\|

\displaystyle\leq

\displaystyle\eta\sum_{t^{\prime}\leq t}\left\|\sum_{j\leq n}\frac{(\mathbf{y}_{j}-\mathbf{u}_{j}(t^{\prime}))\mathbf{X}_{j}^{T}\mathbf{C}^{T}\mathbf{C}}{\sqrt{m}}\right\|

\displaystyle\leq

\displaystyle\frac{\eta}{\sqrt{m}}\sum_{t^{\prime}\leq t}\left(\sum_{j\leq n}|\mathbf{y}_{j}-\mathbf{u}_{j}(t^{\prime})|\right)\max_{j}\|\mathbf{X}_{j}\mathbf{C}^{T}\mathbf{C}\|

(10)

\displaystyle\leq

\displaystyle O\left(\frac{\eta}{\sqrt{m}}\right)\sum_{t^{\prime}\leq t}\left(\sum_{j\leq n}|\mathbf{y}_{j}-\mathbf{u}_{j}(t^{\prime})|\right)

(11)

\displaystyle\leq

\displaystyle O\left(\frac{\eta}{\sqrt{m}}\right)\sum_{t^{\prime}\leq t}\sqrt{n}\|\mathbf{y}-\mathbf{u}(t^{\prime})\|

(12)

\displaystyle\leq

\displaystyle O\left(\frac{\eta\sqrt{n}}{\sqrt{m}}\right)\sum_{t^{\prime}\leq t}\left(1-\frac{\eta\lambda_{0}}{2}\right)^{t^{\prime}/2}\|\mathbf{u}(0)-\mathbf{y}\|

5
Reducing Effective Network Width

The matrix
\mathbf{W}
represents the first layer parameters.
We represent this weight matrix
\mathbf{W}
as the product

\mathbf{A}\mathbf{B}\mathbf{C}

\mathbf{A}\in\mathbb{R}^{m\times k}

\mathbf{B}\in\mathbb{R}^{k\times\ell}

\mathbf{C}\in\mathbb{R}^{\ell\times d}

In other words, we add a dimension reduction gadget as input to the latent layer. It is important to note that the number of neurons in the first layer remains the same. However, due to the low rank structure of the weight matrix
\mathbf{W}
, not all neurons are independent of others. Hence effectively, in the training phase, not every neuron needs to be learned. Now we study the effect of this addition on the NTK bound.

Now we discuss how this affects the training phase. First we randomly and independently initialize
\mathbf{A}\in\mathbb{R}^{m\times k}
such that all its entries are iid sampled from
\mathcal{N}(0,1/\sqrt{k})
for some
k<m
. We also initialize
\mathbf{C}
as mentioned in the previous section. Next, recall that
\mathbf{v}
is initialized as a random vector sampled from
\{-1,+1\}^{m}

\mathbf{B}
using gradient descent on the loss function
\Phi(\mathbf{B})=\frac{1}{2}\|\mathbf{y}-\mathbf{u}\|^{2}
based on a small learning rate
\eta
by keeping rest of the network parameters fixed. The matrix
\mathbf{B}
is updated as follows,

\displaystyle\mathbf{B}(t+1)

\displaystyle=

\displaystyle\mathbf{B}(t)-\eta\frac{\partial\Phi(\mathbf{B}(t))}{\partial\mathbf{B}(t)}

\displaystyle=

\displaystyle\mathbf{B}(t)-\frac{\eta}{\sqrt{m}}\sum_{j\leq n}(\mathbf{y}_{j}-\mathbf{u}_{j}(t))\mathbf{A}^{T}\mathbf{Z}_{j}(t)\mathbf{X}_{j}\mathbf{C}^{T}\ .

Here
\mathbf{Z}_{j}(t)\in\{-1,0,1\}^{m}

\mathbf{v}_{r}\cdot\mathbbm{1}\{\mathbf{A}_{r}\mathbf{B}(t)\mathbf{C}\mathbf{X}_{j}^{T}>0\}

\mathbf{X}

\mathbf{H}^{\infty}\in\mathbb{R}^{n\times n}

\mathbf{H}_{i,j}^{\infty}=\mathbb{E}_{\mathbf{B}}\left[\frac{1}{m}(\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T})(\mathbf{Z}_{i}\mathbf{A}\mathbf{A}^{T}\mathbf{Z}_{j}^{T})\right]\ .

\mathbf{B}(0)

{}\mathbf{H}_{i,j}(0)=\frac{1}{m}(\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T})(\mathbf{Z}_{i}(0)\mathbf{A}\mathbf{A}^{T}\mathbf{Z}_{j}^{T}(0))\ .

Lemma 5.1
.

If

Proof.

For a fixed
\mathbf{A},\mathbf{C}

\mathbf{W}_{r}(0)

\displaystyle\mathbb{E}[|\mathbf{H}_{i,j}-\mathbf{H}_{i,j}(0)|]

\displaystyle\mathbb{E}\left[\frac{1}{m}\left|(\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T})(\mathbf{Z}_{i}\mathbf{A}\mathbf{A}^{T}\mathbf{Z}_{j}^{T}-\mathbf{Z}_{i}(0)\mathbf{A}\mathbf{A}^{T}\mathbf{Z}_{j}^{T}(0))\right|\right]

\displaystyle\|\mathbf{u}(t+1)-\mathbf{u}(t)\|^{2}

\displaystyle\eta^{2}\sum_{i\leq n}\left(\frac{\partial\mathbf{u}_{i}(t)}{dt}\right)^{2}

\displaystyle\leq

\displaystyle\eta^{2}\sum_{i\leq n}\left(\sum_{j\leq n}\frac{1}{m}(\mathbf{y}_{j}-\mathbf{u}_{j}(t))(\mathbf{X}_{i}\mathbf{C}^{T}\mathbf{C}\mathbf{X}_{j}^{T})(\mathbf{Z}_{i}(t)\mathbf{A}\mathbf{A}^{T}\mathbf{Z}_{j}^{T}(t))\right)^{2}

Running Time:

The previous theorem essentially implies that in an overparameterized network with network width of
O\left(\frac{n^{6}}{\lambda_{0}^{4}\delta^{7}}\right)
one can find global minimum by gradient descent with a learning rate
\eta=O\left(\frac{\lambda_{0}\delta^{4}}{n^{2}}\right)
. However, notice that due to our dimensionality reduction, our network can achieve it much faster even for network width of
O(n^{6})
. In each iteration we update a
k\times\ell
dimensional matrix matrix
\mathbf{B}
. For all
i\in[n]
we do a matrix vector product,
\mathbf{Z}_{i}(t)\mathbf{A}
and
\mathbf{X}_{i}\mathbf{C}^{T}
which takes
O(mk+\ell d)=O(mk)
. Now instead of using
\mathbf{A}
as naive dimensionality reduction matrix (i.e., Johnson–Lindenstrauss), if replace it with Fast Johnson–Lindenstrauss transformation
[
3
]
, then our running time improves to
O(m\log(k))=O\left(n^{6}\log\left(\frac{n}{\lambda_{0}\delta}\right)\right)
. As in each iteration of the gradient descent process uses all the
n
inputs, hence updating
\mathbf{B}(t)
takes
O(nm\log(k))=O\left(n^{7}\log\left(\frac{n}{\lambda_{0}\delta}\right)\right)
. Now for
t\geq\frac{\log(\varepsilon)}{\log(1-\eta\lambda_{0})}
our learnt parameter ensures,

\|\mathbf{y}-\mathbf{u}(t+1)\|^{2}\leq\varepsilon\cdot\|\mathbf{y}-\mathbf{u}(0)\|^{2}.

So the total running time to achieve this is
O\left(\frac{n^{7}\log\left(\frac{n}{\lambda_{0}\delta}\right)\log(\varepsilon)}{\log(1-\eta\lambda_{0})}\right)
. Notice that with existing technique the running time would be
O(nmdt)
which is
O\left(\frac{n^{7}d\log(\varepsilon)}{\lambda_{0}^{4}\delta^{2}\log(1-(\lambda_{0}/n)^{2})}\right)
.

6
Conclusion

In this work we presented a simple yet powerful way to reduce the required number of unknown parameters in an overparameterized network.
Our result uses a dimentionality reduction approach for input points as well as for the vector fed into the neurons of the latent layer. We get a significant improvement in the running time while retaining the original theoretical NTK based guarantees. In particular, when
d=O(n)
our network achieves a similar training loss with a faster running time by factor
O(n)
compared to other related results.
