1.1.
Preliminaries and definitions

Let us next give some important definitions that will be used throughout the paper.

First, recall that given any open set
\Omega\subset\mathbb{R}^{N}
, the regional fractional Laplacian in
\Omega
is defined by (
1.2
), and its associated bilinear form is given by

D_{\Omega}(u,v)=\frac{c_{N,s}}{2}\int_{\Omega}\int_{\Omega}\frac{(u(x)-u(y))(v(x)-v(y))}{|x-y|^{N+2s}}\,dxdy

The natural notion of weak solution is the following.

Definition 1.5
.

We say that
u
is a (weak) solution of

(1.5)

(-\Delta)^{s}_{{\Omega}}u=f\quad\textrm{ in\hskip 10.22217pt$\Omega\cap B_{1}$}

with zero

on
\partial\Omega\cap B_{1}
if

and

D_{\Omega}(u,\varphi)=\int_{\Omega}f\varphi\,dx\qquad\textrm{$\forall\varphi\in C^{\infty}_{c}(B_{1})$.}

On the other hand, when
s>\frac{1}{2}
, we say that
u
is a (weak) solution of (
1.5
) with zero
Dirichlet boundary condition
on
\partial\Omega\cap B_{1}
if
u\in H^{s}_{0}(\Omega)
and

D_{\Omega}(u,\varphi)=\int_{\Omega}f\varphi\,dx\qquad\textrm{$\forall\varphi\in C^{\infty}_{c}(B_{1}\cap\Omega)$.}

By approximation, we can of course take any
\varphi\in H^{s}_{0}(\Omega\cap B_{1})
.

We notice that being a weak solution is equivalent to being a minimizer of the functional (

), for both the Neumann and the Dirichlet case.

Combining the previous expressions, we find that at

\begin{split}(-\Delta)^{s}(x_{+})^{\beta}&=\frac{2s}{\pi}\Gamma(2s)\sin(\pi s)\,\frac{2\pi\Gamma(-2s)}{\Gamma(-\beta)\Gamma(1-2s+\beta)}\frac{\cos(\pi s)\sin(\pi(\beta-s))}{\sin(\pi\beta)\sin(\pi(\beta-2s))}\\
&=\frac{\Gamma(\beta+1)}{\Gamma(\beta-2s+1)}\frac{\sin(\pi(\beta-s))}{\sin(\pi(\beta-2s))},\end{split}

where we used again the properties of the

Thus, by homogeneity, (

Once we have the result for

, by noticing that we can take derivatives in (

).
∎

G^{n}_{R}(x):=\frac{1}{r_{n}^{\beta}\theta_{n}}f_{n}(r_{n}x)+c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{(\chi_{R}(x)-\chi_{R}(y))v_{n}(y)}{|\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|^{N+2s}}J_{n}(y)\,dy-\frac{\ell}{r_{n}^{\alpha}\theta_{n}}{\mathcal{L}}_{\psi_{n}}[A_{r_{n},w_{n}}\cdot y^{\prime}](r_{n}x),

where
J_{n}(y):=Jac_{\widetilde{\psi}_{n}}(y)1_{B^{+}_{\frac{1}{r_{n}}}}(y).

Since
\psi_{n}
is a global diffeomorphism, by (
6.15
) and increasing
c_{0}
if necessary, we obtain

(5.22)

c_{0}|x-y|\geq|\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|\geq c_{0}^{-1}|x-y|,\qquad|D\widetilde{\psi}_{n}(x)|\leq c_{0}\qquad\textrm{ for all $x,y\in\mathbb{R}^{N}$. }

Define, for
x\in B_{R/2}
,

\displaystyle F_{R}^{n}(x)

\displaystyle:=c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{(\chi_{R}(x)-\chi_{R}(y))v_{n}(y)}{|\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|^{N+2s}}J_{n}(y)\,dy

\displaystyle=c_{N,s}\int_{\mathbb{R}^{N}_{+}\cap\{|y|\geq R\}}\frac{(1-\chi_{R}(y))v_{n}(y)}{|\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|^{N+2s}}J_{n}(y)\,dy.

Since
\widetilde{\psi}_{n}(0)=0
, by the mean value theorem, we have
F_{R}^{n}(x)=F_{R}^{n}(0)+{\mathcal{R}}_{R}^{n}(x)
, where

{\mathcal{R}}_{R}^{n}(x):=-(N+2s)c_{N,s}\int_{0}^{1}\int_{\mathbb{R}^{N}_{+}}\frac{(\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y))\cdot\widetilde{\psi}_{n}(x)}{|\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|}\frac{(1-\chi_{R}(y))v_{n}(y)}{|t\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|^{N+2s+1}}J_{n}(y)\,dy\,dt.

Note that by (
5.22
),
|t\widetilde{\psi}_{n}(x)-\widetilde{\psi}_{n}(y)|\geq\frac{c_{0}}{2}|y|
whenever
|y|\geq R
and
|x|\leq\frac{R}{2c_{0}^{2}}
.
Therefore,
by (
5.20
) and (
5.22
), there exists
C,n_{0}>0
such that

(5.23)

|\nabla{\mathcal{R}}_{R}^{n}(x)|\leq{C}R^{\alpha-1}\qquad\textrm{ for all $R>1$, $|x|\leq\frac{R}{2c_{0}^{2}}$ and $n\geq n_{0}$}

and by construction we have
{\mathcal{R}}_{R}^{n}(0)=0
.
We can thus write

(5.24)

G^{n}_{R}(x)=H^{n}_{R}(x)+c^{n}_{R}+{\mathcal{R}}^{n}_{R}(x),

with

H^{n}_{R}(x)=\frac{1}{r_{n}^{\beta}\theta_{n}}\left\{f_{n}(r_{n}x)-f_{n}(0)+{\mathcal{L}}_{\psi_{n}}[A_{r_{n},w_{n}}\cdot y^{\prime}](r_{n}x)-{\mathcal{L}}_{\psi_{n}}[A_{r_{n},w_{n}}\cdot y^{\prime}](0)\right\}

and

c^{n}_{R}=\frac{1}{r_{n}^{\beta}\theta_{n}}\left\{f_{n}(0)+{\mathcal{L}}_{\psi_{n}}[A_{r_{n},w_{n}}\cdot y^{\prime}](0)\right\}+F_{R}^{n}(0).

Recalling that
\|f_{n}\|_{C^{\alpha}(\mathbb{R}^{N}_{+})}\leq 1
, we then get from (
5.14
) and Lemma
5.1
that

(5.25)

|H^{n}_{R}(x)|\leq\frac{r_{n}^{\alpha}C}{r_{n}^{\beta}\theta_{n}}+\ell\frac{r_{n}^{\alpha-\varrho}}{r_{n}^{\beta}\theta_{n}}\leq\frac{C(R)}{\theta_{n}}\qquad\textrm{ for all $x\in B_{R/2}$.}

Let us now show that
c_{R}^{n}
is bounded. For this, we pick
\phi\in C^{\infty}_{c}(B_{\frac{1}{2c_{0}^{2}}}^{+})
with
\int_{\mathbb{R}^{N}}\phi\,dx=1
.
Then multiply (
5.21
) by
\phi
and integrate over
\mathbb{R}^{N}_{+}
to get

(5.26)

\displaystyle|c^{n}_{R}|\leq\int_{\mathbb{R}^{N}_{+}}|\chi_{R}(x)v_{n}(x)||{\mathcal{L}}_{\widetilde{\psi}_{n}}\phi(x)|\,dx+\int_{\mathbb{R}^{N}_{+}}|H_{R}^{n}(x)\phi(x)|dx+\int_{\mathbb{R}^{N}_{+}}|{\mathcal{R}}^{n}_{R}(x)\phi(x)|dx\leq C(R).

In view of this, (
5.21
), (
5.24
), (
5.25
) and (
5.23
), we can apply Lemma
5.2
, to deduce that

(v_{n})_{n}
is bounded in
C^{s+\delta}_{loc}(\overline{\mathbb{R}^{N}_{+}})
, for some
\delta>0
, and converges to some
v\in C^{s+\delta}_{loc}(\overline{\mathbb{R}^{N}_{+}})\subset H^{s}_{loc}(\overline{\mathbb{R}^{N}_{+}})
.
In addition passing to the limit in (
5.16
), (
5.20
) and (
5.19
), we get

(5.27)

|v(x)|\leq C(1+|x|^{2s+\alpha}),

(5.28)

\|v\|_{L^{\infty}(B_{1}^{+})}\geq\frac{1}{4},\qquad v(0)=0,\qquad\int_{B_{1}^{+}}v(y)y_{i}\,dx=0,\textrm{ for $i=1,\dots,N-1$. }

Passing to the limit in (
5.21
), (
5.23
) and using (
5.26
), we get, for all
\phi\in C^{\infty}_{c}(B_{\frac{Rc_{0}^{2}}{2}})
,

c_{N,s}\int_{\mathbb{R}^{2N}_{+}}\frac{((\eta_{R}v)(x)-(\eta_{R}v)(y))(\phi(x)-\phi(y))}{|Bx-By|^{N+2s}}\textrm{det}(B)^{2}dydx=\int_{\mathbb{R}^{N}_{+}}(c_{R}^{\infty}+{\mathcal{R}}^{\infty}_{R}(x))\phi(x)\,dx,

where
B=\lim_{n\to\infty}D\widetilde{\psi}_{n}(0)=\lim_{n\to\infty}D\psi_{n}(0)
and

(5.29)

c^{\infty}_{R}\in\mathbb{R},\qquad{\mathcal{R}}_{R}^{\infty}(0)=0,\qquad|\nabla{\mathcal{R}}_{R}^{\infty}(x)|\leq{C}R^{\alpha-1}\qquad\textrm{ for all $R\geq 2$ and $x\in B_{\frac{R}{2c_{0}^{2}}}$.}

Recall from the construction of
\psi_{n}
that
B=\textrm{diag}(1,\dots,1,\lambda)
is a diagonal matrix, for some
\lambda\not=0
. Hence by scaling and (
6.39
), we can assume that

(-\Delta)^{s}_{{\mathbb{R}^{N}_{+}}}v\stackrel{{\scriptstyle\alpha}}{{=}}0\qquad\textrm{ in $\mathbb{R}^{N}_{+}$}.

Applying Theorem
3.4
and using (
6.37
), we deduce that
v(x)=b+a\cdot x^{\prime}
.
This is in contradiction with (
5.28
).
∎

As a consequence, we have :

Corollary 5.4
.

Let
s\in(0,1)
and
\alpha_{s}\in(0,1-s)
be given by Lemma
2.6
. Let
\alpha\in(0,\alpha_{s})
,
\psi
be as above, with
\|\psi\|_{C^{\max(1,2s+\alpha)}(\mathbb{R}^{N})}\leq c_{0}
. Let
f\in C^{\alpha}(\mathbb{R}^{N}_{+})
and
w\in H^{s}(B_{2}^{+})\cap L^{\infty}(\mathbb{R}^{N}_{+})
such that

\mathcal{D}_{\psi}(w,\varphi)=\int_{\mathbb{R}^{N}_{+}}f\varphi\,dx\qquad\textrm{ for all $\varphi\in C^{\infty}_{c}(B_{2})$}.

Then, there exists
C=C(N,s,c_{0},\alpha)
such that for all
z\in B_{1/2}^{\prime}
there exists a vector
e=e_{z}\in\mathbb{R}^{N-1}=:\partial\mathbb{R}^{N}_{+}
, with
|e|\leq C
and

(5.30)

\sup_{r>0}r^{-2s-\alpha}\|w-w(z)-e\cdot(y^{\prime}-z)\|_{L^{\infty}(B_{r}^{+}(z))}\leq C\left(\|w\|_{L^{\infty}(\mathbb{R}^{N}_{+})}+\|f\|_{C^{\alpha}(\mathbb{R}^{N}_{+})}\right).

In particular, if
2s+\alpha>1
then
\partial_{y_{N}}w=0
on
B_{1/2}^{\prime}
.

Proof.

Thanks to Lemma
5.2
, the function
v_{z}(x)=\chi_{2}(x)(w(x+z)-w(z))
satisfies the hypothesis of Proposition
5.3
. We can thus prove (
5.30
) with
z=0
. We assume for simplicity that
\|w\|_{L^{\infty}(\mathbb{R}^{N}_{+})}+\|f\|_{C^{\alpha}(\mathbb{R}^{N}_{+})}\leq 1.

If
2s+\alpha_{s}<1
, then the result clearly holds with
e=0
. We start with (
5.30
) and we distinguish the two cases
2s>1
and
2s<1
. We start with the case
2s>1
, where Lemma
5.2
, yields
|w(y)|\leq C|y|
, so that (
6.25
) holds with
\varrho=0
.
By (
5.11
) and an (algebraic) iteration argument (see e.g.
[
18
,
5
]
), we can find
e\in\mathbb{R}^{N-1}
such that

(5.31)

\|w-e\cdot y^{\prime}\|_{L^{\infty}(B_{r}^{+})}\leq Cr^{2s+\alpha},\qquad|e|\leq C.

We finally consider the case
2s<1
. Here, (
5.11
) implies that
|w(y)|\leq C|y|^{2s+\alpha^{\prime}}
as soon as
2s+\alpha^{\prime}<1
(i.e.
\alpha^{\prime}<1-2s<\alpha
). As a consequence
w
satisfies (
6.25
) with
\varrho=1-2s-\alpha^{\prime}
. Therefore choosing
\alpha^{\prime}
close to
1-2s
so that
2s+\alpha-\varrho>1
, we get from (
5.11
) and an iteration argument, as above, that

(5.32)

\|w-e\cdot y^{\prime}\|_{L^{\infty}(B_{r}^{+})}\leq Cr^{2s+\alpha-\varrho},\qquad|e|\leq C,

which again implies that
|w(y)|\leq C|y|
. Hence
w
satisfies (
5.33
) with
\varrho=0
which, once again by an iteration argument, yields (
5.32
) with
\varrho=0
.

If
2s=1
then Lemma
5.2
implies that
|w(y)|\leq C|y|^{1-\varrho}
, for all
\varrho\in(0,1)
so that (
6.25
) holds with
\varrho\in(0,\alpha_{\frac{1}{2}})
. We thus get, from (
5.11
) and an iteration argument, as above, a vector
e\in\mathbb{R}^{N-1}
such that

(5.33)

\|w-e\cdot y^{\prime}\|_{L^{\infty}(B_{r}^{+})}\leq Cr^{1+\alpha_{\frac{1}{2}}-\varrho},\qquad|e|\leq C.

This gives
|w(y)|\leq C|y|
, so that
w
satisfies (
6.25
) with
\varrho=0
. Hence as above, we get (
5.33
) with
\varrho=0
.
∎

We will also need the following interior Schauder estimate.

Lemma 5.5
.

Let
\Omega
be an open set containing
B_{2}
and
\alpha\in(0,1)
. Let
f\in C^{\alpha}(B_{2})
and
v\in H^{s}(\Omega)
be a solution to

(-\Delta)^{s}_{\Omega}v=f\qquad\text{in $B_{2}$}

satisfying
C_{0}:=\int_{\Omega}\frac{|v(y)|dy}{1+|y|^{N+2s+1}}<\infty
.
Then, provided
2s+\alpha\not\in\mathbb{N}
,

\|v\|_{C^{2s+\alpha}(B_{1})}\leq C(N,s,\alpha)(C_{0}+\|v\|_{L^{2}(B_{2})}+\|f-f(0)\|_{C^{\alpha}(B_{2})}).

Proof.

We have

(-\Delta)^{s}_{\Omega}(\chi_{{2}}v)=f+g_{v}\qquad\text{in $B_{1}$, }

where for
x\in B_{1}

g_{v}(x)=c_{N,s}\int_{\Omega}(1-\chi_{{2}}(y))|x-y|^{-N-2s}v(y)\,dy.

Letting
\widetilde{v}=\chi_{{2}}v\in H^{s}(\mathbb{R}^{N})
, we get

(-\Delta)^{s}_{\mathbb{R}^{N}}\widetilde{v}+\widetilde{v}V=f+g_{v}=c_{0}+(f-f(0))+(g_{v}-g_{v}(0))\qquad\text{in $B_{1/2}$, }

where
c_{0}=f(0)+g_{v}(0)
,
V(x)=c_{N,s}\int_{\mathbb{R}^{N}\setminus\Omega}|x-y|^{-N-2s}\,dy
.
Clearly
\|V\|_{C^{3}(B_{1})}\leq C(N,s)
. Moreover
\|g_{v}-g_{v}(0)\|_{C^{1}(B_{1/2})}\leq C(N,s)C_{0}
. Now as in Remark
3.2
(ii)
, we can estimate

\displaystyle|c_{0}|

\displaystyle\leq C(N,s)\left(C_{0}+\|\widetilde{v}V\|_{L^{1}(B_{1/4})}+\|g_{v}-g_{v}(0)\|_{L^{1}(B_{1/4})}+\|f-f(0)\|_{L^{1}(B_{1/4})}\right)

\displaystyle\leq C(N,s)\left(C_{0}+\|v\|_{L^{2}(B_{2})}+\|f-f(0)\|_{L^{\infty}(B_{2})}\right).

By the interior regularity estimates in
[
11
]
, we have that

\|\widetilde{v}\|_{C^{2s-\varepsilon}(B_{1/4})}\leq C(N,s,\varepsilon)(C_{0}+\|v\|_{L^{2}(B_{2})}+\|f-f(0)\|_{L^{\infty}(B_{2})}).

We can now apply the interior Schauder estimate in
[
18
]
and a standard bootstrap (only necessary for
2s<1
because
\alpha<1
) argument to get the desired estimate.
∎

We can now prove the following.

Theorem 5.6
.

Let
s\in(0,1)
and
\alpha_{s}\in(0,1-s)
be given by Lemma
2.6
, which satisfies
2s+\alpha_{s}>1
.
Let
\Omega\subset\mathbb{R}^{N}
be a
C^{\max(1,2s+\alpha)}
domain, with
0\in\partial\Omega
, and let
f\in C^{\alpha}(\overline{\Omega}\cap B_{1})
, with
\alpha<\alpha_{s}
and with
\alpha+2s\neq 1
.
Let
u\in H^{s}(\Omega)
be such that

D_{\Omega}(u,\varphi)=\int_{\Omega}f\varphi\,dx\qquad\textrm{$\forall\varphi\in C^{\infty}_{c}(B_{1})$.}

Then,

(5.34)

\|u\|_{C^{2s+\alpha}(\overline{\Omega}\cap B_{1/2})}\leq C\left(\|u\|_{L^{2}(\Omega)}+\|f\|_{C^{\alpha}(\overline{\Omega}\cap B_{1})}\right).

with
C
depending only on
N
,
s
,
\alpha
, and
\Omega
.

Moreover, if
2s+\alpha>1
then
\partial_{\nu}u=0
on
\partial\Omega\cap B_{1}
, where
\nu
is the exterior normal of
\partial\Omega
.

Proof.

We assume for simplicity that
\|u\|_{L^{2}(\Omega)}+\|f\|_{C^{\alpha}(\overline{\Omega})}\leq 1
and that
\Omega
satisfies (
5.1
) and (
5.2
).

By Corollary
5.4
and the change of variable
w(y)=u(\psi(y))
we have that, for all
\zeta\in\partial\Omega\cap B_{1/2}
, there exists
e=e_{\zeta}\in\mathbb{R}^{N-1}=:\partial\mathbb{R}^{N}_{+}
with
|e_{\zeta}|\leq C
and such that

(5.35)

\|u-u(\zeta)-\ell_{\alpha}e\cdot(\psi^{-1}(\cdot)-\zeta)\|_{L^{\infty}(B_{r}(\zeta)\cap\Omega)}\leq Cr^{2s+\alpha}.

In addition, using also (
5.2
), we have
\partial_{\nu}u=0
on
\partial\Omega\cap B_{1/2}
as soon as
2s+\alpha>1
.

Let
x_{0}\in\Omega\cap B_{1}
and
\zeta\in\partial\Omega
be such that
\textrm{dist}(x_{0},\partial\Omega)=|x_{0}-\zeta|
. Put
\rho:=\frac{|x_{0}-\zeta|}{4}
and
\overline{x}=\frac{x_{0}-\zeta}{2}\in\Omega
then
B_{2\rho}(\overline{x})\subset\Omega
. We next, define

v_{\rho}(y)=(u(\overline{x}+\rho y)-u(\zeta))-\ell_{\alpha}e\cdot(\psi^{-1}(\rho y+\overline{x})-\zeta),\qquad f_{\rho}(y)=\rho^{2s}f(\overline{x}+\rho y)

and
\Omega_{\rho}=\frac{1}{\rho}(\Omega-\overline{x})
.
Then

(5.36)

(-\Delta)^{s}_{\Omega_{\rho}}v_{\rho}=f_{\rho}+F_{\rho}=:G_{\rho}\qquad\textrm{ in $B_{2}\subset\Omega_{\rho}$},

where
F_{\rho}(y):=\ell_{\alpha}\rho^{2s}[(-\Delta)^{s}_{\Omega}(e\cdot\psi^{-1})](\overline{x}+\rho y))
.
Since
f\in C^{\alpha}(\Omega)
, using Lemma
4.1
, we then get
[G_{\rho}]_{C^{\alpha}(B_{1})}\leq C\rho^{2s+\alpha}
. By (
5.35
), we have that
\|v_{\rho}\|_{L^{\infty}(B_{1})}\leq C\rho^{2s+\alpha}
and

(5.37)

\|v_{\rho}(\cdot/\rho)\|_{L^{\infty}(B_{R\rho}\cap(\Omega-\overline{x}))}\leq\|v_{\rho}(\cdot/\rho)\|_{L^{\infty}(B_{R\rho+2\rho}\cap(\Omega-\zeta))}\leq C(R\rho)^{2s+\alpha}\qquad\textrm{ for all $R\geq 1$. }

Now applying Lemma
5.5
to (
5.36
), we obtain

\|v_{\rho}\|_{C^{2s+\alpha}(B_{1/4})}\leq C(N,s,\alpha)\left(\int_{\Omega_{\rho}\setminus B_{1}}\frac{|v_{\rho}(y)|dy}{|y|^{N+2s+1}}+\|v_{\rho}\|_{L^{\infty}(B_{1})}+\|G_{\rho}-G_{\rho}(0)\|_{C^{\alpha}(B_{1})}\right).

Thanks to (
5.37
) and a change of variable we get

\displaystyle\int_{\Omega_{\rho}\setminus B_{1}}\frac{|v_{\rho}(y)|dy}{|y|^{N+2s+1}}=\rho^{2s+1}\int_{(\Omega-\overline{x})\setminus B_{\rho}}\frac{|v_{\rho}(x/\rho)|dx}{|x|^{N+2s+1}}

\displaystyle\leq\sum_{i=0}^{\infty}(2^{i}\rho)^{-N-2s-1}\rho^{2s+1}\int_{(\Omega-\overline{x})\{|y|<2^{i+1}\rho\}}{|v_{\rho}(x/\rho)|,dx}

\displaystyle\leq C\sum_{i=0}^{\infty}(2^{i}\rho)^{-N-2s-1}\rho^{2s+1}(2^{i+1}\rho)^{N+2s+\alpha}\leq C\rho^{2s+\alpha}.

We conclude that
\|v_{\rho}\|_{C^{2s+\alpha}(B_{1/4})}\leq C\rho^{2s+\alpha}.

Therefore scaling and translating back, we get for
2s+\alpha<1
that

(5.38)

[u]_{C^{2s+\alpha}(B_{\rho}(\overline{x}))}\leq C

and thus
[u]_{C^{2s+\alpha}(B_{1/2}\cap\Omega)}\leq C
because
\overline{x}
is arbitrary.

If now
2s+\alpha>1
, we obtain

[\nabla u-\nabla{e}\cdot(\psi^{-1}(\cdot)-\zeta)]_{C^{2s+\alpha-1}(B_{\rho}(\overline{x}))}\leq C.

Hence, since
[\nabla{e}\cdot(\psi^{-1}(\cdot)-\zeta)]_{C^{2s+\alpha-1}(B_{\rho}(\overline{x}))}\leq C
, we get

[\nabla u]_{C^{2s+\alpha-1}(B_{\rho}(\overline{x}))}\leq C.

This implies

[\nabla u]_{C^{2s+\alpha-1}(B_{1/2}\cap\overline{\Omega})}\leq C.

∎

.

The result follows from Theorem

.

6.
Regional Dirichlet problem

In this section, we consider
\phi\in C^{2,\beta}(\mathbb{R}^{N-1})
satisfying
\|\phi\|_{C^{2,\beta}(\mathbb{R}^{N-1})}\leq\frac{1}{4}
and
\phi(0)=|\nabla\phi(0)|=0
.
We define
\Phi(x^{\prime},x_{N})=(x^{\prime},x_{N}+\phi(x^{\prime}))
.
We start with the following result.

Lemma 6.1
.

Let
\eta\in C^{2s-1}_{c}(\mathbb{R})
with
\eta=0
on
\mathbb{R}_{-}
and
\ell(x^{\prime}):=a\cdot x^{\prime}+b
. Let
f(x)=\eta(x_{N})\ell(x^{\prime})
. Then, for all
x\in\mathbb{R}^{N}_{+}
,

\displaystyle c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{f(x)-f(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy=\ell(x^{\prime})T_{1}(x^{\prime})(-\Delta)^{s}_{\mathbb{R}_{+}}\eta(x_{N})+\ell(x^{\prime})T_{3}(x^{\prime})(-\Delta)^{s}_{\mathbb{R}_{+}}(x_{N}\eta)

\displaystyle-T_{2}(x^{\prime})\cdot a\int_{\mathbb{R}}\frac{(t-x_{N})(\eta(t)-\eta(x_{N}))}{|x_{N}-t|^{1+2s}}\,dt-T_{3}(x^{\prime})\ell(x^{\prime})\left(\eta(-\Delta)^{s}_{\mathbb{R}_{+}}x_{N}+x_{N}(-\Delta)^{s}_{\mathbb{R}_{+}}\eta\right)+h(x),

where
\|h\|_{C^{\min(\alpha,\beta)}(\overline{B_{1}^{+}})}\leq C\|\eta\|_{C^{2s-1}(\mathbb{R})}
for all
\alpha<2s-1
,
T_{1}(0)=1
,
T_{2}(0)=0
and

\|T_{j}\|_{C^{1,\beta}(B_{1}^{\prime})}\leq C(N,s,\beta)
, for
j=1,2
. Moreover,
\|T_{3}\|_{C^{\beta}(B_{1}^{\prime})}\leq C(N,s,\beta)
and

(6.1)

T_{3}(0)=-D^{2}\phi(0)[e_{i},e_{i}]=-\Delta\phi(0).

Proof.

We have

\displaystyle\int_{\mathbb{R}^{N}_{+}}\frac{f(x)-f(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy=\int_{\mathbb{R}^{N-1}}\int_{-x_{N}}^{\infty}\frac{f(x)-f(x+z)}{|\Phi(x)-\Phi(x+z)|^{N+2s}}\,dz

\displaystyle=\int_{\mathbb{R}^{N-1}}\int_{-x_{N}}^{\infty}\frac{f(x)-f(x+z)}{|D\Phi(x^{\prime})z|^{N+2s}}\,dz+\int_{\mathbb{R}^{N-1}}\int_{-x_{N}}^{\infty}\frac{f(x)-f(x+z))}{|z|^{N+2s}}B(x^{\prime},|z^{\prime}|,z^{\prime}/|z^{\prime}|,z/|z|)\,dz,

where

B(x^{\prime},r,\theta^{\prime},\theta)=\frac{1}{|\int_{0}^{1}D\Phi(x^{\prime}+tr\theta^{\prime})\theta dt|^{N+2s}}-\frac{1}{|D\Phi(x^{\prime})\theta|^{N+2s}}.

Recall that for all
y\in\mathbb{R}^{N}

D\Phi(x+r\theta^{\prime})y=y+\left(\nabla\phi(x^{\prime}+r\theta^{\prime})\cdot y^{\prime}\right)e_{N}.

We can thus write

(6.2)

B(x^{\prime},r,\theta^{\prime},\theta)=r\mu_{1}(x^{\prime},\theta^{\prime},\theta)+r\mathcal{O}(x^{\prime},r,\theta^{\prime},\theta),

where

\displaystyle\mu_{1}(x^{\prime},\theta^{\prime},\theta)=\partial_{r}B(x^{\prime},0,\theta^{\prime},\theta)

\displaystyle=-(N+2s)\frac{D^{2}\Phi(x^{\prime})[\theta^{\prime},\theta-(\theta\cdot e_{N})e_{N}]\cdot D\Phi(x^{\prime})\theta}{|D\Phi(x^{\prime})\theta|^{N+2s+2}},

and

\mathcal{O}(x^{\prime},r,\theta^{\prime},\theta)=\partial_{r}B(x^{\prime},r,\theta^{\prime},\theta)-\partial_{r}B(x^{\prime},0,\theta^{\prime},\theta).

We then have

\mu_{1},\mathcal{O}\in C^{\beta}_{x}(B_{2})
,
\mu_{1}(x^{\prime},-\theta^{\prime},-\theta)=-\mu_{1}(x^{\prime},\theta^{\prime},\theta)
,
|\mathcal{O}(x^{\prime},r,\theta^{\prime},\theta)|\leq C\min(1,r^{\beta})
and

(6.3)

|\mathcal{O}(x^{\prime},r,\theta^{\prime},\theta)|\leq C\min(1,r^{\beta}),\qquad|\mathcal{O}(x^{\prime},r,\theta^{\prime},\theta)-\mathcal{O}(\overline{x}^{\prime},r,\theta^{\prime},\theta)|\leq C\min(|x^{\prime}-\overline{x}^{\prime}|,r^{\beta}).

We thus get from (
6.2
),

\displaystyle c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{f(x)-f(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy=c_{N,s}\int_{\mathbb{R}^{N-1}}\int_{-x_{N}}^{\infty}\frac{f(x)-f(x+z)}{|D\Phi(x^{\prime})z|^{N+2s}}\,dz

\|v_{n}\|_{L^{\infty}(B_{M}^{+})}\leq CM^{2s+\beta}\qquad\textrm{ for all $M\geq 1$}.

Letting
\widetilde{\Phi}_{n}(x)=\frac{1}{r_{n}}\Phi(r_{n}x)
, we thus get

(6.29)

\mathcal{B}_{\widetilde{\Phi}_{n}}(\chi_{R}v_{n},\varphi)=\int_{\mathbb{R}^{N}_{+}}G^{n}_{R}\varphi\,dx\qquad\textrm{ for all $\varphi\in C^{\infty}_{c}(B_{\frac{1}{r_{n}}}^{+})$},

where

G^{n}_{R}(x):=\frac{1}{r_{n}^{\beta}\theta_{n}(r_{n})}f_{n}(r_{n}x)+c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{(\chi_{R}(x)-\chi_{R}(y))v_{n}(y)}{|\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|^{N+2s}}\,dy-\frac{1}{r_{n}^{\beta}\theta_{n}(r_{n})}({\mathcal{L}}_{\Phi_{n}}P_{n})(r_{n}x),

P_{n}(x)=\overline{\eta}(x_{N})\left(a_{r_{n},w_{n}}\cdot x^{\prime}+b_{r_{n},{w_{n}}}(1-T_{3}^{n}(0)x_{N})\right)x_{N}^{2s-1}

and
({\mathcal{L}}_{\Phi_{n}}P_{n})(x)=c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{P_{n}(x)-P_{n}(y)}{|\Phi_{n}(x)-\Phi_{n}(y)|^{N+2s}}\,dy
.
By Lemma
6.2
,

(6.30)

({\mathcal{L}}_{\Phi_{n}}P_{n})(r_{n}x)=g_{1,n}(r_{n}x)\log(r_{n}x_{N})+g_{2,n}(r_{n}x)

and thus using (
6.25
) we see that

\displaystyle\frac{1}{r_{n}^{\beta}\theta_{n}(r_{n})}|({\mathcal{L}}_{\Phi_{n}}P_{n})(r_{n}x)-(g_{2,n}(r_{n}x)-g_{2,n}(0))|

\displaystyle\leq\frac{Cr_{n}^{\beta}|x|^{\beta}}{r_{n}^{\alpha}\theta_{n}(r_{n})}\left(1+|\log x_{N}|+|\log r_{n}|\right)(r_{n}^{-\varrho}+1)

(6.31)

\displaystyle\leq\frac{C|x|^{\beta}}{\theta_{n}(r_{n})}\left(1+|\log x_{N}|\right).

Since
|\nabla\phi_{n}|\leq\frac{1}{4}
and
\widetilde{\Phi}_{n}(x)=x+(0,r_{n}^{-1}\phi_{n}(r_{n}x))
, we obtain

(6.32)

\displaystyle 2|x-y|\geq|\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|\geq\frac{1}{2}|x-y|,\qquad|D\widetilde{\Phi}_{n}(x)|\leq 2\qquad\textrm{ for all $x,y\in\mathbb{R}^{N}$. }

Define, for
x\in B_{R/2}
,

\displaystyle F_{R}^{n}(x)

\displaystyle:=c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{(\chi_{R}(x)-\chi_{R}(y))v_{n}(y)}{|\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|^{N+2s}}\,dy

\displaystyle=c_{N,s}\int_{\mathbb{R}^{N}_{+}\cap\{|y|\geq R\}}\frac{(1-\chi_{R}(y))v_{n}(y)}{|\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|^{N+2s}}\,dy.

By the mean value theorem and the fact that
\widetilde{\Phi}_{n}(0)=0
, we have
F_{R}^{n}(x)=F_{R}^{n}(0)+{\mathcal{R}}_{R}^{n}(x)
, where

{\mathcal{R}}_{R}^{n}(x):=-(N+2s)c_{N,s}\int_{0}^{1}\int_{\mathbb{R}^{N}_{+}}\frac{(\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y))\cdot\widetilde{\Phi}_{n}(x)}{|\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|}\frac{(1-\chi_{R}(y))v_{n}(y)}{|t\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|^{N+2s+1}}\,dy\,dt.

Note that by (
6.32
),
|t\widetilde{\Phi}_{n}(x)-\widetilde{\Phi}_{n}(y)|\geq\frac{1}{4}|y|
whenever
|y|\geq R
and
|x|\leq\frac{R}{4}
.
Therefore,
by (
5.20
) and (
6.32
), there exists
C>0
such that

(6.33)

|\nabla{\mathcal{R}}_{R}^{n}(x)|\leq{C}R^{\beta-1}\qquad\textrm{ for all $R>1$, $|x|\leq\frac{R}{4}$ and $n\geq 2$}

and by construction we have
{\mathcal{R}}_{R}^{n}(0)=0
.
We can thus write

(6.34)

G^{n}_{R}(x)=H^{n}_{R}(x)+c^{n}_{R}+{\mathcal{R}}^{n}_{R}(x),

with (recalling (
6.30
))

H^{n}_{R}(x)=\frac{1}{r_{n}^{\alpha}\theta_{n}(r_{n})}\left\{f_{n}(r_{n}x)-f_{n}(0)-({\mathcal{L}}_{\Phi_{n}}P_{n})(r_{n}x)+(g_{2,n}(r_{n}x)-g_{2,n}(0))\right\}

and

c^{n}_{R}=\frac{1}{r_{n}^{\alpha}\theta_{n}(r_{n})}\left(f_{n}(0)-g_{2,n}(0)\right)+F_{R}^{n}(0).

Recalling that
\|f_{n}\|_{C^{\alpha}(\mathbb{R}^{N}_{+})}\leq 1
, we then get from (
6.1
) that

|H^{n}_{R}(x)|\leq\frac{C(R)}{\theta_{n}(r_{n})}(1+|\log x_{N}|)\qquad\textrm{ for all $x\in B_{R/2}^{+}$,}

so that

(6.35)

\|H^{n}_{R}\|_{L^{p}(B_{R/2})}\leq\frac{C(R)}{\theta_{n}(r_{n})}\qquad\textrm{ for all $p>1$.}

Let us now show that
(c_{R}^{n})_{n\in\mathbb{N}}
is bounded. For this, we pick
\phi\in C^{\infty}_{c}(B_{1/4}^{+})
with
\int_{\mathbb{R}^{N}}\phi\,dx=1
and let
R\geq 2
.
Then multiply (
6.29
) by
\phi
and integrate over
\mathbb{R}^{N}_{+}
to get

(6.36)

\displaystyle|c^{n}_{R}|\leq\int_{\mathbb{R}^{N}}|\chi_{R}(x)v_{n}(x)||{\mathcal{L}}_{\widetilde{\Phi}_{n}}\phi(x)|\,dx+\int_{B_{R/2}}|H^{n}_{R}(x)\phi(x)|dx+\int_{B_{R/2}}|{\mathcal{R}}^{n}_{R}(x)\phi(x)|dx\leq C(R).

In view of this, (
6.29
), (
6.34
), (
6.35
) and (
6.33
), we can apply Lemma
6.3
, to deduce that

v_{n}
is bounded in
C^{2s-1}_{loc}(\overline{\mathbb{R}^{N}_{+}})\cap H^{s}_{loc}(\overline{\mathbb{R}^{N}_{+}})
and converges to some
v\in C^{2s-1}_{loc}(\overline{\mathbb{R}^{N}_{+}})\cap H^{s}_{loc}(\overline{\mathbb{R}^{N}_{+}})
. Moreover
v_{n}/x_{N}^{2s-1}
converges to
v/x_{N}^{2s-1}
in
C^{1-\varepsilon}_{loc}(\overline{\mathbb{R}^{N}_{+}})
, for all
\varepsilon\in(0,1)
.
In addition passing to the limit in (
6.23
), (
6.28
) and (
6.24
), we get

(6.37)

|v(x)|\leq C|x|^{2s+\beta}\qquad\textrm{ for all $x\in\mathbb{R}^{N}$,}

(6.38)

\|v/x^{2s-1}_{N}\|_{L^{\infty}(B_{1}^{+})}\geq\frac{1}{2},\qquad\int_{B_{1}^{+}}\frac{v}{x_{N}^{2s-1}}(1-T_{3}^{\infty}(0)x_{N})\,dx=\int_{B_{1}^{+}}\frac{v}{x_{N}^{2s-1}}x_{i}\,dx=0,

for
i=1,\dots,N-1
, where
T_{3}^{\infty}(0)
is the limit
T_{3}^{n}(0)
as
n\to\infty
and satisfies
|T_{3}^{\infty}(0)|\leq 1/4
.
Passing to the limit in (
6.29
), (
6.33
) and using (
6.36
), we get, for all
\phi\in C^{\infty}_{c}(B_{\frac{R}{4}})
,

\int_{\mathbb{R}^{2N}_{+}}\frac{((\eta_{R}v)(x)-(\eta_{R}v)(y))(\varphi(x)-\varphi(y))}{|x-y|^{N+2s}}dydx=\int_{\mathbb{R}^{N}_{+}}(c_{R}^{\infty}+{\mathcal{R}}^{\infty}_{R}(x))\varphi(x)\,dx

and

(6.39)

c^{\infty}_{R}\in\mathbb{R},\qquad{\mathcal{R}}_{R}^{\infty}(0)=0,\qquad|\nabla{\mathcal{R}}_{R}^{\infty}(x)|\leq{C}R^{\beta-1}\qquad\textrm{ for all $R\geq 2$ and $x\in B_{\frac{R}{2}}$.}

Consequently, since
\beta<\alpha_{s}<1
,

(-\Delta)^{s}_{{\mathbb{R}^{N}_{+}}}v\stackrel{{\scriptstyle\beta}}{{=}}0\qquad\textrm{ in $\mathbb{R}^{N}_{+}$}.

Applying Theorem
3.4
and using (
6.37
), we deduce that
\frac{v}{x_{N}^{2s-1}}(x)=b+a\cdot x^{\prime}
. This is in contradiction with (
6.38
).
∎

Corollary 6.5
.

Under the assumptions of Proposition
6.4
, there exist
a\in\mathbb{R}^{N-1}
and
b\in\mathbb{R}
with
|a|+|b|\leq C
such that letting
\psi=\frac{w}{x_{N}^{2s-1}},
we get

(6.40)

\left\|\psi-\left((a\cdot x^{\prime}+b)-bT_{3}(0)x_{N}\right)\right\|_{L^{\infty}(B_{r}^{+})}\leq Cr^{1+\alpha}\qquad\textrm{ for all $r>0$.}

Moreover
a=\nabla_{x^{\prime}}\psi(0)
,
b=\psi(0)
and
\partial_{x_{N}}\psi(0)=-bT_{3}(0)
.

Proof.

Let
Q_{r}(x)=a_{r,w}\cdot x^{\prime}+b_{r,{w}}(1-T_{3}(0)x_{N}).

Let
0<\rho_{2}\leq\rho_{1}/4\leq 1/4
. Pick
k\in\mathbb{N}
and
\sigma\in[1/4,1/2]
such that
\rho_{2}=\sigma^{k}\rho_{1}
. Then provided
r\in(0,1)
, by (
6.26
) and (
6.14
) we get

\displaystyle\rho_{1}|a_{\rho_{2},w}-a_{\rho_{1},w}|+|b_{\rho_{2},w}-b_{\rho_{1},w}|

\displaystyle\leq\sum_{i=0}^{k-1}\sigma^{i+1}\rho_{1}|a_{\sigma^{i+1}\rho_{1},w}-a_{\sigma^{i}\rho_{1},w}|+\sum_{i=0}^{k-1}|b_{\sigma^{i+1}\rho_{1},w}-b_{\sigma^{i}\rho_{1},w}|

\displaystyle\leq C\frac{1}{|B_{\sigma^{i+1}\rho_{1}}|^{\frac{1}{2}}}\|Q_{\sigma^{i+1}\rho_{1}}-Q_{\sigma^{i}\rho_{1}}\|_{L^{2}(B_{\sigma^{i+1}\rho_{1}})}

\displaystyle\leq C\sum_{i=0}^{k-1}\left(\|\psi-Q_{\sigma^{i}\rho_{1}}\|_{L^{\infty}\left(B_{\sigma^{i}\rho_{1}}\right)}+\|\psi-Q_{\sigma^{i+1}\rho_{1}}\|_{L^{\infty}\left(B_{\sigma^{i+1}\rho_{1}}\right)}\right)

\displaystyle\leq C\sum_{i=0}^{k-1}\left((\sigma^{i}\rho_{1})^{1+\alpha}+(\sigma^{i+1}\rho_{1})^{1+\alpha}\right)\leq C\rho_{1}^{1+\alpha}.

This implies that the limits
a:=\lim_{r\to 0}a_{r,w}
and
b:=\lim_{r\to 0}b_{r,w}
exist. Moreover, letting
\rho_{2}\to 0
and
\rho_{1}=1/2
in the above estimate, we get
|a|+|b|\leq C
. Hence (
6.40
) follows.

It is by now easy to see from (
6.40
), that
b=\psi(0)
and
\nabla\psi(0)=(a,-bT_{3}(0))
.
∎

Corollary 6.6
.

Under the hypothesis of Proposition
6.4
, there exists a constant
C
depending only on
N,s,\alpha
and
\beta
such that
for all
{\xi\in B_{1}^{+}\cap\mathbb{R}e_{N}}
,

[w/x_{N}^{2s-1}]_{C^{1+\alpha}({B_{\xi_{N}/2}(\xi)})}\leq C.

Proof.

Let
\xi:=(0,2\rho)\in B_{1}^{+}
with
\rho<1/2
. We define

P(x)=\overline{\eta}(x_{N})(x_{N})^{2s-1}_{+}(a\cdot x^{\prime}+b)-bT_{3}(0)\overline{\eta}(x_{N})(x_{N})^{2s}_{+},

where
b
and
a
are given by Corollary
6.5
and
T_{3}(0)
is given by Lemma
6.2
. Put

v_{\xi}(y)=w(\xi+\rho y)-P(\xi+\rho y)
,
f_{\xi}(y)=\rho^{2s}f(\xi+\rho y)
. We have

(6.41)

\mathcal{L}_{\Phi_{\rho}}v_{\xi}=f_{\xi}(x)+\rho^{2s}(\mathcal{L}_{\Phi}P)(\xi+\rho x)\qquad\textrm{ for all $\varphi\in C^{\infty}_{c}(B_{1}^{+})$,}

where
\Phi_{\rho}(x)=\rho^{-1}\Phi(\rho x+\xi)=(x^{\prime},x_{N}+\rho^{-1}\phi(\rho x^{\prime}))
and

\mathcal{L}_{\Phi_{\rho}}v(x)=c_{N,s}\int_{\{y_{N}>-2\}}\frac{v(x)-v(y)}{|\Phi_{\rho}(x)-\Phi_{\rho}(y)|^{N+2s}}\,dy.

By Lemma
6.2
, we have

\displaystyle F(x):=(\mathcal{L}_{\Phi}P)(\xi+\rho x)

\displaystyle=g_{1}(\xi+\rho x)\log(2\rho+\rho x_{N})+g_{2}(\xi+\rho x)

from which it follows that

\|F\|_{C^{\beta}([0,1))}\leq C\rho^{\beta}|\log\rho|\leq C\rho^{\alpha}
. Note that
|u_{\xi}(x)|\leq C(1+|x|^{2s+\alpha})
and thus since
\Phi_{\rho}\in C^{2}(\mathbb{R}^{N};\mathbb{R}^{N})
is a global (volume preserving) diffeomorphism, by a change of variable and (
6.41
), we obtain

(-\Delta)^{s}_{\Omega_{\rho}}v_{\xi}\circ\Phi_{\rho}^{-1}{=}G_{\xi}\circ\Phi_{\rho}^{-1}\qquad\textrm{ in $\Omega_{\rho}$,}

where
G_{\xi}(x):=f_{\xi}(x)+\rho^{2s}F(\xi+\rho x)
and
\Omega_{\rho}=\Phi_{\rho}^{-1}(\{y_{N}>-2\})
. We note that

[G_{\xi}]_{C^{\alpha}(B_{1/2})}\leq\rho^{2s+\alpha}
,
\|v_{\xi}\circ\Phi_{\rho}^{-1}\|_{L^{\infty}(B_{1/2})}\leq\rho^{2s+\alpha}
and
B_{1}\subset\Omega_{\rho}
. We then apply Lemma
5.5
to deduce that

\displaystyle\|v_{\xi}\circ\Phi_{\rho}^{-1}\|_{C^{2s+\alpha}(B_{1/4})}

\displaystyle\leq C\left(\int_{\Omega_{\rho}\setminus B_{1/8}}|y|^{-N-2s-1}|v_{\xi}\circ\Phi_{\rho}^{-1}(y)|dy+\rho^{2s+\alpha}\right)

\displaystyle\leq C\left(\int_{\mathbb{R}^{N}_{+}\setminus B_{1/16}}|x|^{-N-2s-1}|v_{\xi}(x)|dx+\rho^{2s+\alpha}\right)

\displaystyle\leq C\left(\sum_{i=0}^{\infty}\int_{2^{i-3}>|x|>2^{i-4}}|x|^{-N-2s-1}|v_{\xi}(x)|dx+\rho^{2s+\alpha}\right)

\displaystyle\leq C\left(\sum_{i=0}^{\infty}(2^{i}\rho)^{-N-2s-1}\rho^{2s+1}\int_{2^{i-3}\rho>|z|>2^{i-4}\rho}v_{\xi}(z/\rho)|dz+\rho^{2s+\alpha}\right)

\displaystyle\leq C\left(\sum_{i=0}^{\infty}(2^{i}\rho)^{-N-2s-1}\rho^{2s+1}\int_{2^{i}\rho>|x|}|w(x)-P(x)|dx+\rho^{2s+\alpha}\right)

\displaystyle\leq C\left(\sum_{i=0}^{\infty}2^{i{(\alpha-1)}}\rho^{2s+\alpha}+\rho^{2s+\alpha}\right)\leq C\rho^{2s+\alpha},

where we used (
6.40
) which yields
|w(x)-P(x)|\leq C|x|^{2s+\alpha}
. We conclude that

\|v_{\xi}\|_{C^{2s+\alpha}(B_{1/4})}\leq C\rho^{2s+\alpha}.

Scaling and translating back, we then get

\|w-P\|_{L^{\infty}(B_{\rho/4}(\xi))}\leq C\rho^{2s+\alpha},\qquad[\nabla w-\nabla P]_{C^{\alpha}(B_{\rho/4}(\xi))}\leq C\rho^{2s-1}.

Combining the above estimates with

\|1/x_{N}^{2s-1}\|_{L^{\infty}(B_{\rho/4}(\xi))}\leq C\rho^{1-2s},\qquad[\nabla(1/x_{N}^{2s-1})]_{C^{\alpha}(B_{\rho/4}(\xi))}\leq C\rho^{-2s-\alpha}

we finally get

[\nabla(w/x^{2s-1})-\nabla(P/x^{2s-1})]_{C^{\alpha}(B_{\rho/4}(\xi))}\leq C.

Since
[\nabla(P/x^{2s-1})]_{C^{\alpha}(B_{\rho/4}(\xi))}=0
, this yields

[\nabla(w/x^{2s-1})]_{C^{\alpha}(B_{\rho/4}(\xi))}\leq C.

and the proof is complete.
∎

We now prove the following.

Theorem 6.7
.

Given
s\in(\frac{1}{2},1)
, let
\alpha_{s}\in(0,1-s)
be given by Lemma
2.6
.
Let
\Omega\subset\mathbb{R}^{N}
be a
C^{2,\beta}
domain, with
0\in\partial\Omega
, and
f\in C^{\alpha}(\overline{\Omega}\cap B_{1})
with
\alpha<\min\{\alpha_{s},2s-1,\beta\}
and
\alpha+2s\neq 1
.
Let
u\in H^{s}_{0}(\Omega)
be such that

D_{\Omega}(u,\varphi)=\int_{\Omega}f\varphi\,dx\qquad\textrm{$\forall\varphi\in C^{\infty}_{c}(B_{1}\cap\Omega)$,}

and let
\delta=\textrm{dist}(x,\partial\Omega)
.
Then,

(6.42)

\|u/\delta^{2s-1}\|_{C^{1+\alpha}(B_{\rho/2}\cap\overline{\Omega})}\leq C\left(\|u\|_{L^{2}(\Omega)}+\|f\|_{C^{\alpha}(\overline{\Omega})}\right),

with
C,\rho>0
depending only on
N
,
s
,
\alpha
, and
\Omega
.

Moreover, letting
\psi=u/\delta^{2s-1}
, we have

(6.43)

\partial_{\nu}\psi(\sigma)=-(N-1)H_{\partial\Omega}(\sigma)\psi(\sigma)\qquad\textrm{ for all $\sigma\in\partial\Omega\cap B_{1}$,}

where
H_{\partial\Omega}
is the mean curvature of
\partial\Omega
.

Proof.

We assume for simplicity that
\|u\|_{L^{2}(\Omega)}+\|f\|_{C^{\alpha}(\overline{\Omega})}\leq 1.
Hence by Lemma
6.3
, we get
\|u/\delta^{2s-1}\|_{L^{\infty}(\Omega\cap B_{1/2})}+\|u\|_{C^{2s-1}(\overline{\Omega}\cap B_{1/2})}\leq C
.

Up to a scaling and a rotation, we may assume that
B_{1/4}\cap\partial\Omega
is contained in the graph
\{x_{N}=\gamma(x^{\prime})\}
with
\gamma\in{C^{2,\beta}(B_{1/4}^{\prime})}
.
For
q\in\partial\Omega
, let
\nu(q)
denote the unit exterior normal vector of
\Omega
at
q
and denote
T_{q}\partial\Omega=\nu(q)^{\perp}
the tangent plane of
\partial\Omega
at
q
.

By the local inversion theorem, there exist
r_{0}\in(0,1/4]
depending only on
N
,
\beta
and
\|\gamma\|_{{C^{2,\beta}(B_{1}^{\prime})}}
such that for any
q\in B_{r_{0}}\cap\partial\Omega
, there exist an orthonormal basis
(E_{1}(q)\dots,E_{N-1}(q))
of
T_{q}\partial\Omega
and
\widetilde{\phi}\in C^{2,\beta}(B_{r_{0}}^{\prime})
such that

x^{\prime}\mapsto q+\sum_{i=1}^{N-1}x_{i}E_{i}(q)-\widetilde{\phi}(x^{\prime})\nu(q):B_{r_{0}}^{\prime}\to\partial\Omega

with
\|\widetilde{\phi}\|_{C^{2,\beta}(B_{r_{0}}^{\prime})}\leq C(N,\beta,\gamma,r_{0})
. It is clear that
\widetilde{\phi}(0)=|\nabla\widetilde{\phi}(0)|=0
.
We let
\eta\in C^{\infty}_{c}(B_{r_{0}}^{\prime})
with
\eta\equiv 1
on
B_{r_{0}/2}^{\prime}
and put
\phi=\eta\widetilde{\phi}
.
For all
q\in B_{r_{0}}\cap\partial\Omega
, we define

(6.44)

\Phi:\mathbb{R}^{N}\to\mathbb{R}^{N},\qquad\Phi(x^{\prime},x_{N})=q+\sum_{i=1}^{N-1}x_{i}E_{i}(q)-\left(x_{N}+\phi(x^{\prime})\right)\nu(q).

Next, decreasing
r_{0}
if necessary,
\Phi
is a global
C^{2,\beta}
diffeomorphism and clearly
\textrm{Det}D\Phi(x)=1
for all
x\in\mathbb{R}^{N}
. We may assume that the (signed) distance function
d\in C^{2,\beta}(\{d<r_{0}/2\})
.
We also recall that the mean curvature of
\partial\Omega
at
q
is given by

(6.45)

H_{\partial\Omega}(q):=\frac{1}{N-1}\Delta\phi(0).

We define
Q_{\delta}:=B_{\delta}^{\prime}\times(0,\delta)
and
\mathcal{Q}_{\delta}:=\Phi(Q_{\delta})\subset\Omega
.
For any
x_{0}\in\mathcal{Q}_{r_{0}/9}
, let
q\in\partial\Omega\cap B_{r_{0}}
such that
|x_{0}-q|=d(x_{0})
.
Letting
v={\chi_{r_{0}/4}}u
, we have

\displaystyle(-\Delta)^{s}_{\Omega}v=f+c_{N,s}\int_{\Omega}\frac{(1-\chi_{{r_{0}/4}}(y))u(y)}{|x-y|^{N+2s}}\,dy=:f_{1}.

Clearly
\|f_{1}\|_{C^{\alpha}(\mathcal{Q}_{r_{0}/8})}\leq C
for all
\alpha\in(0,\min(2s-1,\beta))
.
Now we get

\displaystyle(-\Delta)^{s}_{\mathcal{Q}_{r_{0}/2}}v=f_{1}-(-\Delta)^{s}_{\Omega\setminus\mathcal{Q}_{r_{0}/2}}v=:f_{2},

and obviously
\|f_{2}\|_{C^{\alpha}(\mathcal{Q}_{r_{0}/8})}\leq C
because
\|v\|_{C^{2s-1}(\mathcal{Q}_{r_{0}/8})}\leq C
. We define
w(x)=v(\Phi(x))
and
g_{2}(x)=f_{2}(\Phi(x))
. Then by a change of variable, we get

\displaystyle c_{N,s}\int_{Q_{r_{0}/2}}\frac{w(x)-w(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy=g_{2}(x).

Hence
w\in H^{s}(\mathbb{R}^{N}_{+})
satisfies
\|w/x^{2s-1}_{N}\|_{L^{\infty}(\mathbb{R}^{N}_{+})}+\|w\|_{C^{2s-1}(\mathbb{R}^{N}_{+})}\leq C

(6.46)

\displaystyle c_{N,s}\int_{\mathbb{R}^{N}_{+}}\frac{w(x)-w(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy=g_{3}(x),

with
g_{3}(x)=g_{2}(x)-c_{N,s}\int_{\mathbb{R}^{N}_{+}\setminus Q_{r_{0}/2}}\frac{w(x)-w(y)}{|\Phi(x)-\Phi(y)|^{N+2s}}\,dy.

\|g_{3}\|_{C^{\alpha}(Q_{r_{0}/8})}\leq C.

x_{0}=q-|x_{0}-q|\nu(q)=\Phi(0,|x_{0}-q|).

We can thus apply Corollary
6.6
to the equation (
6.46

(6.47)

[w/x_{N}^{2s-1}]_{C^{1+\alpha}(B_{r/2}(\xi))}=[u\circ\Phi/x_{N}^{2s-1}]_{C^{1+\alpha}({B_{r/2}(\xi)})}\leq C,\quad\textrm{ with $\xi=\Phi^{-1}(x_{0})\in Q_{\frac{r_{0}}{9}}\cap\mathbb{R}e_{N}$.}

where
r=\xi_{N}/2=|x_{0}-q|/2
.
In addition, Corollary
6.40
, (
6.1
) and (
6.45
) yield

(6.48)

\partial_{x_{N}}[w/x_{N}^{2s-1}](0)=-T_{3}(0)[w/x_{N}^{2s-1}](0)=(N-1)H_{\partial\Omega}(q)[w/x_{N}^{2s-1}](0).

In view of (
6.44
) and (
6.47
), by changing variables, we thus obtained

[u/\delta^{2s-1}]_{C^{1+\alpha}({B_{r/8}(x_{0})})}\leq C,

where we used that

and that

in
\Omega
.
This implies that
[u/\delta^{2s-1}]_{C^{1+\alpha}(\mathcal{Q}_{r_{0}/9})}\leq C

) follows.

Finally using (

\partial_{\nu}[u/\delta^{2s-1}](q)=-(N-1)H_{\partial\Omega}(q)[u/\delta^{2s-1}](q)
