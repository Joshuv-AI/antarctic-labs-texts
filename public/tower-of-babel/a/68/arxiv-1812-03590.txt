Abstract
. We show that, for a certain large class of power-bounded o o -minimal ℒ T \mathcal{L}_{T} -theories T T whose field of exponents is infinite-dimensional as a ℚ \mathds{Q} -vector space, any definable set in a T T -convex valued field ( ℛ , 𝔒 ) (\mathcal{R},\mathfrak{O}) is in a precise sense the limit of a family of ℒ T \mathcal{L}_{T} -definable sets indexed over the residue field. Alternatively, in the mainstream model-theoretic language, this says that if ( ℛ ′ , 𝔒 ′ ) (\mathcal{R}^{\prime},\mathfrak{O}^{\prime}) is an elementary substructure of ( ℛ , 𝔒 ) (\mathcal{R},\mathfrak{O}) and if the residue field of 𝔒 \mathfrak{O} contains an element that is infinitesimal relative to the residue field of 𝔒 ′ \mathfrak{O}^{\prime} then any set A ⊆ ( ℛ ′ ) m A\subseteq(\mathcal{R}^{\prime})^{m} definable in ( ℛ ′ , 𝔒 ′ ) (\mathcal{R}^{\prime},\mathfrak{O}^{\prime}) is the trace of a set definable in ℛ \mathcal{R} .

Consider the set

We try another construction. Surely it is possible that

be an

-definable interval containing

On second thought, in the first construction above, what if the intervals

If we wish to declare that some

-definable semialgebraic sets

For

In conclusion, for any semialgebraic set

\mathcal{R}

With this terminology, Theorem

Theorem 1.3

Every set definable in

A definable disc

is a closed

Remark 2.5
.

Since the

-minimal theory

Definition 2.6
