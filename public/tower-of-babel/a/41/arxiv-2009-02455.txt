User-Guided Domain Adaptation for Rapid Annotation from User Interactions: A Study on Pathological Liver Segmentation
Ashwin Raju, Zhanghexuan Ji, Chi Tung Cheng, Jinzheng Cai, Junzhou Huang, Jing Xiao, Le Lu, ChienHung Liao, Adam P. Harrison

Abstract
Mask-based annotation of medical images, especially for 3 3 D data, is a bottleneck in developing reliable machine learning models. Using minimal-labor user interactions to guide the annotation is promising, but challenges remain on best harmonizing the mask prediction with the user interactions. To address this, we propose the user-guided domain adaptation framework, which uses prediction-based adversarial domain adaptation to model the combined distribution of user interactions and mask predictions. The user interactions are then used as anchors to guide and align the mask prediction. Importantly, user-guided domain adaptation can both learn from unlabelled data and also model the high-level semantic meaning behind different user interactions. We test user-guided domain adaptation on annotating pathological livers using a clinically comprehensive dataset of 927 927 patient studies. Using only extreme-point user interactions, we achieve a mean (worst-case) performance of 96.1 % 96.1\% ( 94.9 % 94.9\% ), compared to 93.0 % 93.0\% ( 87.0 % 87.0\% ) for deep extreme points. Furthermore, we also show user-guided domain adaptation can retain this state-of-the-art performance even when only seeing a fraction of available user interactions, demonstrating an ability for robust and reliable user interaction-guided segmentation with extremely minimal labor demands.



1
Introduction

Reliable computer-assisted segmentation of anatomical structures from medical images can allow for quantitative biomarkers for disease diagnosis, prognosis, and progression. Given the extreme labor to fully annotate data, especially for 3D volumes, a considerable body of work focuses on weakly-supervised segmentation solutions
[
24
]
. Solutions that can leverage user interactions,
e.g.
, extreme-points, scribbles, and boundary marks, are an important such category.

The main challenge is effectively leveraging user interactions to constrain or guide the mask generation. Classic approaches, like the random walker algorithm
[
5
]
, do so via propagating seed regions using intensity similarities. Later approaches add additional constraints,
e.g.
, based on presegmentations
[
6
]
or learned probabilities
[
7
]
. With the advent of deep-learning, harmonizing mask predictions with the user interactions continues to be a challenge. Deep extreme points
[
17
]
, which requires the user to click on the extreme boundary points of an object, is a popular and effective approach. But deep extreme points only adds the extreme point annotations as an additional channel when training the segmentor, meaning the predicted mask may not agree with the user interactions. Later work uses expectation-maximization strategies that alternate between network training and then regularization via random walker
[
22
]
or dense conditional random fields
[
20
,
27
,
2
]
. However, over and above their computational demands, the intensity-based random walker or conditional random field regularization may not capture high-level semantics and any guidance on the mask predictions still remains highly indirect. DeepIGeoS
[
28
]
offers an alternative that uses a deep-conditional random field optimizer to propagate scribbles. However, DeepIGeos would only allow boundary annotations or extreme points to be treated as simple seed regions, neglecting their rich semantic meaning.

To address these issues, we propose user-guided domain adaptation. Our new method uses prediction-based adversarial domain adaptation
[
26
]
to guide mask predictions by the user interactions. user-guided domain adaptation’s advantage is that it is equipped to model the high-level meaning behind different types of user interactions and how they should impact the ultimate mask prediction. Importantly, the user interactions are used as anchors when adapting the mask. Another advantage is that, like prediction-based adversarial domain adaptation, user-guided domain adaptation can learn from and exploit completely unlabelled data, in addition to those accompanied by user interactions. Without loss of generality, we focus on using deep extreme points-style extreme point user interactions because of their intuitiveness and effectiveness
[
19
,
22
]
. But other types,
e.g.
, boundary corrections, are equally possible in addition to, or instead of, extreme points. The only constraint is that we assume a fully-supervised dataset is available in order to model the interplay between mask and user interactions. But such data can originate from sources other than the target dataset,
e.g.
, from public data. To the best of our knowledge, we are the first to use domain adaptation as a mechanism to drive user interaction-based segmentation.

We test user-guided domain adaptation on an extremely challenging pathological liver segmentation dataset collected directly from the picture archiving and communication system of Chang Gung Memorial hospital. This dataset comprises
927
patient studies, all with hepatocellular carcinoma, intrahepatic cholangiocellular carcinoma, metastasized, or benign lesions and is
one of the most challenging datasets to date for pathological liver segmentation
. Liver volumetry analysis is a crucial pre-requisite prior to many hepatic procedures, such as liver transplantation
[
18
,
25
]
or resection
[
15
,
14
]
. Despite success with fully-automated solutions, modern deep solutions
[
29
,
12
,
11
]
are often trained only on public datasets,
e.g.
, LiTS
[
1
]
, which only represents hepatocellular carcinoma and metastasized lesions and does not fully represent patient/co-morbidity distributions. Thus, they may not generalize to all datasets, such as ours. Using
only extreme-point user interactions
, we achieve state-of-the-art mean (worst-case) Dice-Sørensen coefficient scores of
96.1\%
(
94.5\%
) on our dataset, compared to
93.0\%
(
79.0\%
) and
93.1\%
(
87.0\%
) for a strong a fully-supervised baseline and DEXTR
[
17
]
, respectively. We also show that user-guided domain adaptation can improve over prediction-based adversarial domain adaptation
[
26
]
by
1.3\%
Dice-Sørensen coefficient and that user-guided domain adaptation can even perform robustly when only shown incomplete sets of user interactions. Finally, we demonstrate predicted masks align extraordinarily well with user interactions, allowing the user to interact with confidence and with minimal frustration.

2
Methods

We aim to produce reliable mask predictions on a target dataset or deployment scenario, given only minimal user interactions. More formally, we assume we are given a dataset composed of both user interaction-labelled and completely unlabelled volumes,
\mathcal{D}_{t}=\{X_{i},E_{i}\}_{i=1}^{N_{w}}\bigcup\{X_{i}\}_{i=1}^{N_{u}}
, with
X_{i}
and
{E}_{i}
denoting the images and extreme points user interactions, respectively. In addition, we also assume a fully-supervised source dataset with masks is also available,
\mathcal{D}_{s}=\{\mathcal{X}_{i},Y_{i}\}_{i=1}^{N_{s}}
. As long as the masks and extreme points describe the same anatomical structure,
\mathcal{D}_{s}
may originate from entirely different sources,
e.g.
, public data. The goal is to use only the extreme point user interactions to robustly annotate
\mathcal{D}_{t}
. Fig.
1
outlines our workflow, which uses user-guided domain adaptation (UGDA) to efficiently and effectively exploit the extreme-point user interactions.

Figure 1:
Overview.
user-guided domain adaptation chains together (1) an initial FCN that predicts the object’s extreme points, and (2) a second FCN that accepts the first’s predictions to predict a mask. For source data,
\mathcal{D}_{s}
, where the mask label is present, we compute fully-supervised loss on both the extreme-point and mask predictions. For target data,
\mathcal{D}_{t}
, we compute a fully-supervised loss when user interactions are available. For all
\mathcal{D}_{t}
volumes, whether user interaction-labelled or completely unlabelled, we use PADA to guide the mask predictions based on the extreme-point anchors.

2.1
Supervised Workflow

The backbone of user-guided domain adaptation is two 3D fully-convolutional networks chained together, where the first fully-convolutional network predicts extreme-points while the second predicts a full mask. Working backward, the second fully-convolutional network acts very similarly to DEXTR
[
17
]
, where the latter predicts a mask given an input image along with the extreme-point user interactions:

\displaystyle\hat{Y}=s(X,E)\mathrm{,}

(1)

where we have used
s(.)
to represent the segmentation fully-convolutional network. Each of the
6
extreme points are represented by a 3D Gaussian heat map centered on the user clicks and rendered into an additional input channel,
E_{i}
. We find the method is not sensitive to the size of the Gaussian heat maps, and we use a kernel with
5
-pixel standard deviation. However, unlike DEXTR, we do not assume all training volumes come with extreme-points, as only some target volumes in
\mathcal{D}_{t}
may have user interactions.

To loosen these restrictions, we use the first fully-convolutional network to predict extreme-point heatmaps for each volume. Following heatmap regression conventions
[
30
]
, the extreme-point fully-convolutional network,
h(.)
, outputs
6
3D Gaussian heatmaps, each corresponding to one extreme point. These are then summed together into one channel prior to being inputted into our segmentation fully-convolutional network:

\displaystyle\hat{Y}

\displaystyle=s(X,\hat{E})\mathrm{,}

(2)

\displaystyle\hat{E}

\displaystyle=h(X)\mathrm{,}

(3)

where for convenience we have skipped showing the summation of
6
heatmaps into one channel. By relying on predictions, this allows our system to operate even with unlabelled data. Ground-truth extreme-points can be generated from any user interactions performed on
\mathcal{D}_{t}
. Extreme-points for
\mathcal{D}_{s}
can be deterministically generated from the full masks, simulating the user interactions.

In terms of loss, if we use
\mathcal{D}_{e}
to denote any input volume associated with extreme-point user interactions, whether from
\mathcal{D}_{s}
or
\mathcal{D}_{t}
, then a supervised loss can be formulated:

\displaystyle\mathcal{L}_{sup}

\displaystyle=\mathcal{L}_{seg}+\mathcal{L}_{ext}\mathrm{,}

(4)

\displaystyle\mathcal{L}_{ext}

\displaystyle=\dfrac{1}{N_{e}}\sum_{X,E\in\mathcal{D}_{e}}\ell_{ext}\left(h(X),E\right)\mathrm{,}

(5)

\displaystyle\mathcal{L}_{seg}

\displaystyle=\dfrac{1}{N_{s}}\sum_{X,Y\in\mathcal{D}_{s}}\ell_{seg}\left(s(X,h(X)),Y\right)\mathrm{,}

(6)

where
N_{e}
denotes the cardinality of
\mathcal{D}_{e}
. Following heat-map regression practices
[
30
]
, we implement
\ell_{ext}
using mean-squared error. For
\ell_{seg}
we use a summation of cross entropy and Dice-Sørensen coefficient losses, which has experienced success in segmentation tasks
[
11
]
. While we focus on extreme points for this work, other types of user interactions, such as boundary corrections, can be readily incorporated in this framework.

2.2
User-Guided Domain Adaptation

Similar to DEXTR
[
17
]
, (
6
) indirectly guides mask predictions by using extreme-point heat maps as an additional input channel for the segmentor. Additionally, for user interaction-labelled volumes in
\mathcal{D}_{t}
, the supervised loss in (
5
) encourages the extreme-point predictions to actually match the user interactions. However, the mask prediction may contradict the user interactions because there is no penalty for disagreement between the two. Thus, an additional mechanism is needed to align the mask with user interactions. We opt for an adversarial domain adaption approach to penalize discordant mask predictions. While image translation-based adversarial domain adaptation methods show excellent results
[
10
,
13
]
, these are unsuited to our task because we are concerned with adapting the
prediction-space
to produce a mask well-aligned with the user interactions. Thus, we use prediction-based adversarial domain adaptation (PADA)
[
26
]
.

More specifically, we use a discriminator,
d(.)
, to learn the distribution and interplay between masks and extreme-points. Treating samples from
\mathcal{D}_{s}
as the “correct” distribution, the discriminator loss can be expressed as

\displaystyle\mathcal{L}_{d}=\dfrac{1}{N_{s}}\sum_{\mathcal{D}_{s}}\ell_{bce}(d(\{\hat{Y},\hat{E}\},\mathbf{1}))+\dfrac{1}{N_{t}}\sum_{\mathcal{D}_{t}}\ell_{bce}(d(\{\hat{Y},\hat{E}\},\mathbf{0}))\mathrm{,}

(7)

where
\ell_{bce}
denotes the cross-entropy loss. Importantly, to model their combined distribution, the discriminator accepts both the user interaction and mask predictions. Following standard adversarial training, here gradients only flow through the discriminator. user-guided domain adaptation then attempts to fool the discriminator by predicting extreme-point/mask pairs for
\mathcal{D}_{t}
that match
\mathcal{D}_{s}
’s distribution. More formally, an adversarial loss is set up for volumes in
\mathcal{D}_{t}
:

\displaystyle\mathcal{L}_{adv}=\dfrac{1}{N_{t}}\sum_{\mathcal{D}_{t}}\ell_{bce}(d(\{\hat{Y},\hat{E}\},\mathbf{1}))\mathrm{.}

(8)

Note that compared to (
7
), the “label” for
\mathcal{D}_{t}
has been switched from
\mathbf{0}
to
\mathbf{1}
. Like standard prediction-based adversarial domain adaptation setups, gradients do not flow through the discriminator weights in (
8
). Importantly,
gradients also do not flow through the extreme-point predictions when the user interactions are present
. Consequently, when user interactions are available, extreme-point predictions are only influenced by the supervised loss in (
5
) to match the user interactions. While there is no strict guarantee, our results demonstrate almost perfect matching. Thus, the extreme-point predictions act as anchors, while the adversarial loss in (
8
) guides the mask predictions to properly align with the user interactions. This alignment is more than simply making mask predictions agree with the user interactions, as by modelling their interplay, prediction-based adversarial domain adaptation also guides mask regions far away from user interactions. Finally, the use of prediction-based adversarial domain adaptation provides another important benefit, as completely unlabelled volumes in
\mathcal{D}_{t}
can seamlessly contribute to the learning process in (
7
) and (
8
). In fact, user-guided domain adaptation can be seen as integrating domain adaptation learning processes
[
26
]
in addition to DEXTR-style guidance
[
17
]
from user interactions. Thus, the overall training objective for user-guided domain adaptation is to minimize the following total loss:

\displaystyle\mathcal{L}=\mathcal{L}_{sup}+\lambda_{adv}\mathcal{L}_{adv}\mathrm{,}

(9)

where we have purposely kept loss weighting to only the adversarial component to reduce hyper-parameter tuning.

Dataset description.
We test user-guided domain adaptation on segmenting pathological livers, using a target dataset of
927
venous-phase computed tomography studies from the picture archiving and communication system of Chang Gung Memorial hospital. The only selection criterion was of patients with biospied or resecuted liver lesions, with computed tomography scans taken within one month before the procedure. Patients directly reflect clinical distributions and represent intrahepatic cholangiocellular carcinoma, hepatocellular carcinoma, benign or metastasized lesions, along with co-occuring maladies, such as liver fibrosis, splenomegaly, or embolized lesions. This serves as
\mathcal{D}_{t}
. From these, we selected
47
and
100
studies as validation and test sets, respectively, and delineated the patient livers. These
147
computed tomographies are called
evaluation volumes
. We annotated the remainder using only extreme point user interactions. For
\mathcal{D}_{s}
we collected
235
fully-labelled venous-phase computed tomography studies from public datasets
[
1
,
4
,
9
,
3
]
, which, unlike
\mathcal{D}_{t}
, comprises both healthy and pathological livers and only represents hepatocellular carcinoma and metastasized tumors. Corresponding extreme-point “user interactions” were generated from the full masks following
[
17
]
. For internal validation, we also split
\mathcal{D}_{s}
into
70\%
,
20\%
, and
10\%
for training, testing and validation, respectively.

Implementation Details.
For user-guided domain adaptation’s two fully-convolutional network architectures, we use a
3
D version of the deeply-supervised progressive holistically nested network
[
8
]
, which provides an efficient and decoder-free pipeline. As backbone, we use a
3
D generalization of VGG-16
[
23
]
. We first train a fully-supervised baseline on
\mathcal{D}_{s}
using (
4
), then we finetune after convergence using (
9
). This dual-PHNN baseline is very strong on our public data, achieving a Dice-Sørensen coefficient score of
96.9\%
on the
\mathcal{D}_{s}
test set. For discriminator, we use a
3
D version of a popular architecture
[
16
]
using atrous convolution, which has proved a useful discriminator for liver masks
[
21
]
. We do not use the multi-level discriminator variant proposed by Tsai
et al.

[
26
]
, as its added complexity does not seem to result in noticeable improvements for liver-based prediction-based adversarial domain adaptation
[
21
]
. Specific details on the choice of hyper parameters are listed in the supplementary material.

Evaluation protocols.
We evaluate user-guided domain adaptation on how well it can annotate
\mathcal{D}_{t}
using only extreme-point user interactions. To do this, we include the evaluation volumes and their extreme point user interactions within the training procedure,
but hide their masks
. For evaluation, we measure Dice-Sørensen coefficient scores and also the mask-extreme-point agreement. The latter measures the average distance between all six of a predicted

mask’s
extreme-points vs. the ground-truth extreme points. This directly measures how well the model can produce a mask prediction that actually matches the extreme-point user interactions.

Comparisons.
We test against the user-interactive DEXTR
[
17
]
using the same progressive holistically nested network backbone. DEXTR can only be trained on
\mathcal{D}_{s}
because it requires fully-labelled training data, but during inference it sees
\mathcal{D}_{t}
’s extreme-point user interactions. The DEXTR authors claim their approach can generalize well to new data. We also test against two mask-based prediction-based adversarial domain adaptation
[
26
]
variants. The first variant, called “mask-based prediction-based adversarial domain adaptation (no user interactions)”, matches published practices
[
26
]
and just uses a single network (progressive holistically nested network in our case) to directly predict masks, using a discriminator to penalize ill-behaving mask predictions on unlabeled data. It does not incorporate user interactions. The second variant, simply called “mask-based prediction-based adversarial domain adaptation (w user interactions)”, is almost identical to user-guided domain adaptation, meaning the mask and extreme-point predictions are still trained with the supervised losses of (
6
) and (
5
), respectively, but the discriminator in (
7
) and (
8
) only models mask predictions without seeing the extreme-point predictions. Comparing this variant to user-guided domain adaptation reveals the impact of using extreme-points as anchors to guide the domain adaptation of the masks.

Finally, we also compare against user-guided domain adaptation variants trained with only a fraction of the user interactions available in
\mathcal{D}_{t}
, with the remainder being left unlabelled. This reveals how well user-guided domain adaptation can operate in scenarios when only a fraction of target volumes have user interaction-labels. When doing so, we remove the same percentage of user interaction-labels from both non-evaluation and evaluation volumes.

4
Conclusion

We presented user-guided domain adaptation (UGDA), an effective approach to use user interactions to rapidly annotate 3D medical volumes.
We tested user-guided domain adaptation on arguably the most challenging and comprehensive pathological liver segmentation dataset to date, demonstrating that by only using extreme-point user interactions we can achieve Dice-Sørensen coefficient scores of
96.1\%
, outperforming both deep extreme points
[
17
]
and conventional mask-based prediction-based adversarial domain adaptation
[
26
]
. Future work includes testing on other anatomical structures, incorporating additional types of user interactions, and adapting user-guided domain adaptation for real-time interaction.
