On Reward-Penalty-Selection Games
N. Gräf, T. Heller, S.O. Krumke

Abstract
The Reward-Penalty-Selection Problem (RPSP) can be seen as a combination of the Set Cover Problem (SCP) and the Hitting Set Problem (HSP). Given a set of elements, a set of reward sets, and a set of penalty sets, one tries to find a subset of elements such that as many reward sets as possible are covered, i.e. all elements are contained in the subset, and at the same time as few penalty sets as possible are hit, i.e. the intersection of the subset with the penalty set is non-empty. In this paper we define a cooperative game based on the RPSP where the elements of the RPSP are the players. We prove structural results and show that RPS games are convex, superadditive and totally balanced. Furthermore, the Shapley value can be computed in polynomial time. In addition to that, we provide a characterization of the core elements as a feasible flow in a network graph depending on the instance of the underlying RPSP. By using this characterization, a core element can be computed efficiently.



1
Introduction

For a company that specializes in the further processing of raw materials into various end products, two strategic questions are of particular interest. Firstly, which products should be produced and secondly, which materials should be purchased for them. In this case, different materials can be purchased together, whereby the full price is incurred as soon as only one of the materials from a package is required. On the other hand, end products can only be produced if all the materials required for them are available - only in this case can a profit be made.

This problem can be formalized as the
reward-penalty-selection problem
(RPSP) which was recently introduced in
[
6
]
. It can be viewed as a combination of two classical, well-known combinatorial problems, the set cover problem and the hitting set problem (cf.
[
4
]
). The ground set of elements
N
is given by the set of materials. The set of reward sets
A\coloneqq\{A_{i}|A_{i}\subseteq N\}
with corresponding rewards
a_{i}\in\mathbb{N}
and a set of penalty sets
B\coloneqq\{B_{i}|B_{i}\subseteq N\}
with corresponding penalties
b_{i}\in\mathbb{N}
are given by the end products and raw material packages with their respective price. We say that a set is
covered
if all elements of said set are chosen and that a set is
hit
if at least one element is chosen. Now we aim to find a subset of elements
S
such that the profit function

\displaystyle\sum_{i:A_{i}\subseteq S}a_{i}-\sum_{j:B_{j}\cap S\neq\emptyset}b_{j}

(1)

is maximized. In the example given above, this corresponds to selecting a subset of the raw materials such that the net profit defined by the profit obtained by selling the final products minus the cost for the necessary raw material packages is maximized. For an analysis on the complexity of the RPSP and its variants, as well as algorithmic approaches, we refer to
[
6
,
7
]
.

The question how “fair prices” for the materials could look like can be tackled by considering the problem from the viewpoint of game theory, which is the central point of this paper.
For this, we view each material as a player in a cooperative game with characteristic function as in (
1
). This leads us to
reward-penalty-selection games
(RPS games) which we define formally later.

Cooperative games are often used to find “fair” solutions (cf.
[
9
]
) for settings where multiple players cooperate to obtain a profit together. In general, a cooperative game consists of a group of players and a
characteristic function
, which maps every subset of players to its obtainable profit. A
solution
to such a cooperative game is given by a
payment vector
that stores the profit for each player. Properties, that are widely considered as fair, are the following ones. We say that a payment vector fulfills
efficiency
(EFF), if the obtained profit of the group of all players is fully distributed. If all entries in the vector are greater or equal to the profit the corresponding player can obtain by itself,
individual rationality
(IR) is satisfied.
Coalitional rationality
(CR) is fulfilled if the same holds for all subsets of the players, i.e. the sum of the payments to players is greater or equal to the obtained profit by this subset of players. The
core
consists of all those payment vectors that fulfill (EFF), (IR) and (CR) (cf.
[
9
]
). For the rest of the paper, we focus on core vectors, such as the
Shapley value
(cf.
[
10
]
), but we note that there exists other payment vectors that are considered as fair, for instance the
egalitarian allocation
(cf.
[
3
,
8
]
). One of the main results of this paper is a characterization of the core vectors via flows in an associated network.

The remainder of the paper is structured as follows. In Section
2
we give a definition of an RPS game. We also provide basic results regarding the properties of such games. In Section
3
we prove a characterization of the core elements of an RPS game as a network flow in a suitable network graph. We then conclude with a short outlook.

2
The Reward-Penalty-Selection Game

We start with a formal definition of
reward-penalty-selection (RPS) games
:

Definition 2.1

(Reward-Penalty-Selection Games)
.

Let
N\coloneqq\{1,\dots,n\}
be the set of players. Further, let
\mathcal{A}\coloneqq\{A_{1},\dots,A_{k}\}\subseteq 2^{N}
be the set of non-empty reward sets with rewards
a_{1},\dots,a_{k}\in\mathbb{N}
and
\mathcal{B}\coloneqq\{B_{1},\dots,B_{l}\}\subseteq 2^{N}
be the set of non-empty penalty sets with penalties
b_{1},\dots,b_{l}\in\mathbb{N}
. The game
(N,v)
with characteristic function
v\colon 2^{N}\rightarrow\mathbb{Z}
defined by

\displaystyle v(S)\coloneqq\sum_{i:A_{i}\subseteq S}a_{i}-\sum_{j:B_{j}\cap S\neq\emptyset}b_{j}

is called
reward-penalty-selection game (RPS game)
.

Theorem 2.2

(Convexity of RPS games)
.

Every RPS game
(N,v)
is convex, i.e. the characteristic function satisfies
v(S)+v(T)\leq v(S\cup T)+v(S\cap T)
for arbitrary subsets
S,T\subseteq N
of players.

Proof.

Note that it is sufficient to check the cases of a single reward or a single penalty set since the sum of convex games is again convex. Let
(N,v)
be an RPS game consisting of one non-empty reward set
A\subseteq N
with reward
a
. Further, let
S,T\subseteq N
be arbitrary sets of players.

If
v(S\cup T)=0
, then
A
is not contained in
S\cup T
and therefore not either in
S
and
T
. This implies that

\displaystyle v(S\cup T)=0=v(S)+v(T)-v(S\cap T),

thus, convexity is fulfilled.

If
v(S\cup T)=a
, we have to distinguish between two cases. Either
A\subseteq S\cap T
, which implies

\displaystyle v(S\cup T)=a=a+(a-a)=v(S)+v(T)-v(S\cap T),

or
A\not\subseteq S\cap T
. In this case,
A
cannot be contained in both
S
and
T
and therefore

\displaystyle v(S\cup T)=a=a-0\geq v(S)+v(T)-v(S\cap T).

The case of an RPS game with a single penalty set can be shown in the same way.
∎

Furthermore, by a similar argument as in the proof of convexity, we obtain the following corollary.

Corollary 2.3
.

RPS games are superadditive, i.e. the characteristic function satisfies
v(T\cup S)\geq v(S)+v(T)
for all
S,T\subseteq N
with
S\cap T=\emptyset
.∎

The main purpose of such a cooperative game is to find a fair profit distribution of the total profit among all players. For this, we define the
payment vector
as the vector
p\in\mathbb{R}^{N}
whose
i
th entry
p_{i}
is the payment for player
i
. We define the payment to a coalition
S\subseteq N
as the sum over the payments to the single players, i.e.
p(S)\coloneqq\sum_{i\in S}p_{i}
. Given such a payment vector, we now formally define desired properties as introduced above. A payment vector
p
fulfills
efficiency
(EFF), if
\sum_{i\in N}p_{i}=v(N)
holds. Furthermore, if
p_{i}\geq v(\{i\})
for all
i\in N
, we say
p
fulfills
individual rationality
(IR). The extension of (IR) to coalitions is called
coalitional rationality
(CR). We say a payment vector fulfills (CR) if each coalition is guaranteed at least the value the players could obtain by themselves, i.e.
\sum_{i\in S}p_{i}\geq v(S)
.

Now, the
core
is a well known solution to such cooperative games and defined as the set of payments, which fulfills (EFF), (IR) and (CR). Using the convexity of RPS games, it follows that an element in the core can be computed in polynomial time (cf.
[
9
]
). Thus, it follows immediately:

Corollary 2.4
.

RPS games are balanced (cf.
[
11
]
), i.e. the core of an RPS game is never empty. A core element can be computed in polynomial time.
∎

The following two lemmas present structural insights into RPS games.

Lemma 2.5
.

RPS games are totally balanced.

Proof.

Each subgame of an RPS game is itself an RPS game. Thus, since each RPS game is balanced, so are its subgames and therefore RPS games are totally balanced.
∎

Lemma 2.6
.

Suppose we are given an RPS game where all reward and penalty sets consist of exactly one player. Then the core consists of a singleton.

Proof.

Suppose
|A_{i}|=|B_{j}|=1
for all
i
,
j
. Further, let
p
be a core vector. Hence,
p
has to satisfy
p_{k}\geq v(\{k\})=\sum_{i:\{k\}=A_{i}}a_{i}-\sum_{j:\{k\}=B_{j}}b_{j}
. Since a core vector also has to fulfill
p(N)=v(N)
, we get

\displaystyle\sum_{k\in N}\left(\sum_{i:\{k\}=A_{i}}a_{i}-\sum_{j:\{k\}=B_{j}}b_{j}\right)

\displaystyle\leq\sum_{k\in N}p_{k}

\displaystyle=p(N)

\displaystyle=v(N)

\displaystyle=\sum_{k\in N}\left(\sum_{i:\{k\}=A_{i}}a_{i}-\sum_{j:\{k\}=B_{j}}b_{j}\right).

Thus,
p(N)=\sum_{k\in N}\left(\sum_{i:\{k\}=A_{i}}a_{i}-\sum_{j:\{k\}=B_{j}}b_{j}\right)
is the only core vector.
∎

A famous core payment is the
Shapley value
(cf.
[
10
]
). Formally, for a cooperative game
(N,v)
the Shapley value of a player
k
is defined as

\displaystyle\phi_{v}(k)\coloneqq\sum_{S\subseteq N\backslash\{k\}}\frac{|S|!(n-|S|-1)!}{n!}(v(S\cup\{k\})-v(S)).

This can be interpreted as the average marginal profit the player
k
adds to an existing coalition
S
when joining the coalition over all possible permutations. The next theorem states that the Shapley value can be computed efficiently for RPS games.

Theorem 2.7
.

Given an RPS game, the Shapley value
\phi_{v}
for a player
k
is given by

\displaystyle\phi_{v}(k)\coloneqq\sum_{i\in N}\frac{a_{i}}{|A_{i}|}-\sum_{j\in N}\frac{b_{j}}{|B_{j}|}

(2)

for
k=1,\dots,n
and, thus, can be computed efficiently.

Proof.

For each reward set
A_{i}\in\mathcal{A}
a player
k
adds value
a_{i}
to the coalition value if and only if all other players of
A_{i}
are already contained in the coalition, i.e. in
\frac{1}{|A_{i}|}
of all cases. Hence, on average each player in
A_{i}
contributes
\frac{a_{i}}{|A_{i}|}
to the value of the coalition. On the other side, for each penalty set
B_{j}\in\mathcal{B}
, a player
k
incurs cost
b_{j}
if and only if she enters the coalition first. Again, on average, each player in
B_{j}
incurs cost
\frac{b_{j}}{|B_{j}|}
to the coalition. By summing up over all reward and penalty sets we obtain (
2
).

In order to compute the Shapley value of a player, the contribution of each player is initialized with zero. Now we iterate over all reward and penalty sets and update the contribution of each player according to (
2
).
∎

We now investigate the relation of RPS games to the set of convex games.

Lemma 2.8
.

The following statements are true:

(i)

Every convex cooperative game with three players can be modeled as an RPS game.

(ii)

The set of all convex cooperative games is a strict superset of the set of RPS games, meaning that there exist convex cooperative games with four players that cannot be modeled as an RPS game.

Proof.

(i)

Let
(N,v)
be a convex cooperative game with player set
N=\{1,2,3\}
. W.l.o.g. we can assume that the value of a singleton is always zero since we can add singleton reward and penalty sets while keeping convexity. Let
d\coloneqq\min\{v(\{1,2\}),v(\{1,3\}),v(\{2,3\})\}
be the minimal value of a coalition consisting of two players. By convexity,
d
is non-negative. If
d
is greater than
0
, we add a penalty set
B=\{1,2,3\}
with penalty
b=d
. In order to obtain the amount given by the characteristic function
v
, we add reward sets

\displaystyle A_{1}=\{1\}

\displaystyle\text{ with }a_{1}=d

\displaystyle A_{2}=\{2\}

\displaystyle\text{ with }a_{2}=d

\displaystyle A_{3}=\{3\}

\displaystyle\text{ with }a_{3}=d

\displaystyle A_{4}=\{1,2\}

\displaystyle\text{ with }a_{4}=v(\{1,2\})-d

\displaystyle A_{5}=\{2,3\}

\displaystyle\text{ with }a_{5}=v(\{2,3\})-d

\displaystyle A_{6}=\{1,3\}

\displaystyle\text{ with }a_{6}=v(\{1,3\})-d

Note that all rewards are non-negative by the definition of
d
. Finally, we add
A_{7}=\{1,2,3\}\text{ with }a_{7}=v(\{1,2,3\})-\sum_{i=1}^{6}a_{i}-b
. With this, an arbitrary game consisting of three players can be modeled as an RPS game.

(ii)

Let
(N,v)
be the convex cooperative game with player set
N=\{1,2,3,4\}
and characteristic function

\displaystyle v(S)=\begin{cases}0,\qquad\quad\text{ if }|S|\leq 2,\\
1,\qquad\quad\text{ if }|S|=3,\\
2,\qquad\quad\text{ if }S=N.\\
\end{cases}

Suppose
(N,v)
can be modeled by an RPS game. Let
i,j\in N
be two different players. It holds that
v(\{i,j\})=0=v(i)+v(j)
. Since
v(\{i,j\})\geq v(i)+v(j)
is always true due to convexity, there cannot be a penalty set containing both
i
and
j
, because otherwise for the coalition the penalty incurs once while the penalty incurs for both singletons
\{i\},\{j\}
.

Adding more sets, the gap only increases which does not help in order to obtain
v(\{i,j\})=v(i)+v(j)
. Hence, no penalty set of size two or larger can be used to model the game. As every two player coalition receives value zero, reward sets of size exactly two cannot exist in said game at the same time. In order to generate a profit of one for all three-player coalitions, we have to add a reward set of value one for each of those coalitions. But then, since there are four such coalitions, the RPS game must grant a profit of at least four to the grand coalition — a contradiction.

∎

Characterization of Core Elements

In this section we give a characterization of core elements of an instance of an RPS game. In order to do this, we define a profit sharing graph and prove that any feasible flow in this graph of a certain flow value induces a core vector and vice versa. As a byproduct of this characterization we obtain an alternative proof to the polynomial time computability of a core element stated in Corollary
2.4
. We assume that the reader is familiar with the basics of network flows
[
2
]
.

Our approach of a characterization of core elements as feasible flows is based on results of Ackermann et al. (cf.
[
1

). First, we define the

(Profit Sharing Graph for RPS Games)

(N,v)

N=\{1,2,\dots,n\}

\displaystyle\{(A,i):i\in A,A\in\mathcal{A}\}\cup\{(i,B):i\in B,B\in\mathcal{B}\}\cup\{(\overline{s},\overline{t})\}.

We set the edge capacities to be given by the function

\displaystyle c(e)\coloneqq\begin{cases}a_{i},&\text{for $e=(s,A_{i})$ and $A_{i}\in\mathcal{A}$}\\

\sum_{j=1}^{l}b_{j},&\text{for $e=(s,\overline{s})$}\\
\sum_{i=1}^{k}a_{i},&\text{for $e=(\overline{t},t)$}\\
\infty,&\text{otherwise.}\end{cases}

Now, let
(N,v)

to a player

\displaystyle p_{i}\coloneqq f(i,\overline{t})-f(\overline{s},i).

The next theorem shows the connection between a feasible flow in the profit sharing graph and a core vector.

Theorem 3.2

(Core Elements)
.

Any feasible flow with value
H
in the profit sharing graph of an RPS game defines a payment vector that fulfills the properties of efficiency (EFF), coalitional rationality (CR) and individual rationality (IR).

Proof.

We prove the claim by showing that a payment vector
p
defined by a feasible flow
f
with value
H
fulfills the above conditions, where the payment of a player
i
is is defined by (
3
). Recall that a feasible flow fully exhausts all finite capacities of the profit sharing graph.

(i)

Efficiency: For efficiency we need to show
p(N)=v(N)
. By definition we have

\displaystyle p(N)

\displaystyle=\sum_{i\in N}p_{i}=\sum_{i\in N}f(i,\overline{t})-f(\overline{s},i).

By using flow conservation at each of the player nodes
i
this is equal to

\displaystyle\sum_{i\in N}\left(f(\mathcal{A},i)-f(i,\mathcal{B})\right)

\displaystyle=\sum_{i:A_{i}\in\mathcal{A}}a_{i}-\sum_{j:B_{j}\in\mathcal{B}}b_{j}=v(N).

(ii)

Coalitional Rationality: Let
S\subseteq N
be a subset of players. We want to show that the profit distributed to this subgroup
S
is greater or equal to the value of
S
, i.e.
p(S)\geq v(S)
. By definition we have

\displaystyle p(S)

\displaystyle=\sum_{i\in S}p_{i}=\sum_{i\in S}\left(f(i,\overline{t})-f(\overline{s},i)\right)

By using flow conservation this is equal to

\displaystyle\sum_{A\in\mathcal{A}}\sum_{i\in S}f(A,i)-\sum_{B\in\mathcal{B}}\sum_{i\in S}f(i,B)

\displaystyle=\sum_{i:A_{i}\cap S\neq\emptyset}f(A_{i},S)-\sum_{j:B_{j}\cap S\neq\emptyset}f(S,B_{j})

\displaystyle\geq\sum_{i:A_{i}\subseteq S}f(A_{i},S)-\sum_{j:B_{j}\cap S\neq\emptyset}f(S,B_{j})

\displaystyle=\sum_{i:A_{i}\subseteq S}a_{i}-\sum_{j:B_{j}\cap S\neq\emptyset}b_{j}

\displaystyle=v(S),

since every feasible flow with value
H
fully exhausts all finite capacities.

(iii)

Individual Rationality: Follows by the same argumentation as for (CR).

Thus, all four properties are fulfilled.
∎

Conversely, the next theorem shows that given a core vector, one finds a corresponding feasible flow.

Theorem 3.3

(Core Elements II)
.

Let
p
be a core allocation of an RPS game
(N,v)
. Then, there exists a feasible flow
f
with value
H
in the corresponding profit sharing graph that induces the allocation
p
.

Proof.

Let
G=(V,E)
be the corresponding profit sharing graph of
(N,v)
. We modify
G
by changing the infinite capacities to finite ones. Define
c_{p}
as follows:

\displaystyle c_{p}(\overline{s},i)

\displaystyle=\begin{cases}p_{i}&\text{if $p_{i}\geq 0$}\\
0&\text{otherwise,}\end{cases}

\displaystyle c_{p}(i,\overline{t})

\displaystyle=\begin{cases}-p_{i}&\text{if $p_{i}<0$}\\
0&\text{otherwise}\end{cases}

and

\displaystyle c_{p}(\overline{s},\overline{t})

\displaystyle=\sum_{B_{j}\in\mathcal{B}}b_{j}-\sum_{i\in N}c(\overline{s},i).

We now define finite capacities
\operatorname{cap}\colon E\rightarrow\mathbb{Z}
by

\displaystyle\operatorname{cap}(e)\coloneqq\begin{cases}c(e),&\text{if $c(e)<\infty$}\\
c_{p}(e),&\text{if $c(e)=\infty$.}\end{cases}

With these finite capacities, the payment from or to a player
i
made by
p
is representable in the flow network since
c_{p}(\overline{s},i)+c_{p}(i,\overline{t})=|p_{i}|
and
c_{p}(\overline{s},i)-c_{p}(i,\overline{t})=p_{i}
always hold true.

By the Max-Flow Min-Cut Theorem (cf.
[

), the capacity of a minimum

is equal to the value of a feasible
s
-

. Therefore we show in the following that the capacity of a minimum cut is at least
H
. Thus, let
X\subseteq V
be an
s
-

-cut in
G
, i.e.
s\in X
and

. Since
X^{\prime}=\{s\}
is a cut with finite capacity, we know that all edges connecting

have finite capacity. That means for an arbitrary player

. With this, we get

\displaystyle\mathcal{A}\cap X=\{\,A:A\cap X\neq\emptyset,A\in\mathcal{A}\,\}=\{\,A:A\cap N\cap X\neq\emptyset,A\in\mathcal{A}\,\}

and

\displaystyle\mathcal{A}\backslash X=\{\,A:A\cap X=\emptyset,A\in\mathcal{A}\,\}=\{\,A:A\cap N\cap X=\emptyset,A\in\mathcal{A}\,\}.

There are four possibilities depending on whether
\overline{s}\in X
or
\overline{t}\in X
.

(i)

Assume
\overline{s},\overline{t}\notin X
. Then, we get

\displaystyle\sum_{i\in N\cap X}\left(c_{p}(\overline{s},i)+c_{p}(i,\overline{t})\right)

\displaystyle=\sum_{i\in N\cap X}|p_{i}|

\displaystyle\geq\sum_{i\in N\cap X}p_{i}=p(N\cap X).

By coalitional rationality, this is greater or equal to
v(N\cap X)
. Thus,

\displaystyle v(N\cap X)

\displaystyle=\sum_{i:A_{i}\subseteq N\cap X}a_{i}-\sum_{j:B_{j}\cap N\cap X\neq\emptyset}b_{j}

\displaystyle=\sum_{i:A_{i}\cap N\cap X}a_{i}-\sum_{j:B_{j}\cap N\cap X\neq\emptyset}b_{j}

\displaystyle=\sum_{i:A_{i}\in\mathcal{A}\cap X}a_{i}-\sum_{j:B_{j}\in\mathcal{B}\cap X\neq\emptyset}b_{j}

With the above calculation, we get as the capacity of the cut
X

\displaystyle\operatorname{cap}(X)

\displaystyle=c(s,\overline{s})+\sum_{i:A_{i}\in\mathcal{A}\backslash X}c(s,A_{i})+\sum_{j:B_{j}\in\mathcal{B}\cap X}c(B_{j},t)

\displaystyle\qquad\qquad\qquad+\sum_{i\in N\cap X}\left(c_{p}(\overline{s},i)+c_{p}(i,\overline{t})\right)

\displaystyle\geq\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}

\displaystyle\qquad\qquad\qquad+\left(\sum_{i:A_{i}\in\mathcal{A}\cap X}a_{i}-\sum_{j:B_{j}\in\mathcal{B}\cap X\neq\emptyset}b_{j}\right)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{1\leq i\leq|\mathcal{A}|}a_{i}=H.

(ii)

Assume
\overline{s},\overline{t}\in X
. Then

\displaystyle\sum_{i\in N\backslash X}\left(c_{p}(\overline{s},i)+c_{p}(i,\overline{t})\right)

\displaystyle=\sum_{i\in N\backslash X}|p_{i}|

\displaystyle\geq\sum_{i\in N\backslash X}-p_{i}

\displaystyle=-p(N\backslash X)

\displaystyle=-p(N)+p(N\cap X)

\displaystyle\geq-v(N)+v(N\cap X)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}-\sum_{1\leq i\leq|\mathcal{A}|}a_{i}+\sum_{i:A_{i}\cap N\cap X}a_{i}

\displaystyle\qquad\qquad\qquad-\sum_{j:B_{j}\cap N\cap X\neq\emptyset}b_{j}

\displaystyle=\sum_{j:B_{j}\cap N\cap X=\emptyset}b_{j}-\sum_{i:A_{i}\cap(N\backslash X)\neq\emptyset}a_{i}

\displaystyle\sum_{j:B_{j}\in\mathcal{B}\backslash X}b_{j}-\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}.

With this, we get

\displaystyle\operatorname{cap}(X)

\displaystyle=c(\overline{t},t)+\sum_{i:A_{i}\in\mathcal{A}\backslash X}c(s,A_{i})+\sum_{j:B_{j}\in\mathcal{B}\cap X}c(B_{j},t)

\displaystyle\qquad\qquad\qquad+\sum_{i\in N\backslash X}\left(c_{p}(\overline{s},k)+c_{p}(i,\overline{t})\right)

\displaystyle=\sum_{1\leq i\leq|\mathcal{A}|}a_{i}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}+\sum_{i\in N\cap X}\left(c_{p}(\overline{s},i)+c_{p}(i,\overline{t})\right)

\displaystyle\geq\sum_{1\leq i\leq|\mathcal{A}|}a_{i}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}+\left(\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}-\sum_{i:A_{i}\in\mathcal{A}\cap X}a_{i}\right)

\displaystyle=\sum_{1\leq i\leq|\mathcal{A}|}a_{i}+\sum_{1\leq j\leq|\mathcal{B}|}b_{j}=H.

(iii)

Assume
\overline{s}\in X
and
\overline{t}\notin X
. Thus, the following holds by similar calculations as above.

\displaystyle\operatorname{cap}(X)

\displaystyle=c(\overline{s},\overline{t})+\sum_{i:A_{i}\in\mathcal{A}\backslash X}c(s,A_{i})+\sum_{j:B_{j}\in\mathcal{B}\cap X}c(B_{j},t)

\displaystyle\qquad\qquad\qquad+\sum_{i\in N\cap X}c_{p}(i,\overline{t})+\sum_{i\in N\backslash X}c_{p}(\overline{s},i)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}-\sum_{i\in N}c_{p}(\overline{s},i)+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}

\displaystyle\qquad\qquad\qquad+\sum_{i\in N\cap X}c_{p}(i,\overline{t})+\sum_{i\in N\backslash X}c_{p}(\overline{s},i)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}+\sum_{i\in N\cap X}c_{p}(i,\overline{t})

\displaystyle\qquad\qquad\qquad-\sum_{i\in N\cap X}c_{p}(\overline{s},i)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}+\sum_{i\in N\cap X}p_{i}

\displaystyle\geq\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{i:A_{i}\in\mathcal{A}\backslash X}a_{i}+\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}

\displaystyle\qquad\qquad\qquad+\left(\sum_{i:A_{i}\in\mathcal{A}\cap X}a_{i}-\sum_{j:B_{j}\in\mathcal{B}\cap X}b_{j}\right)

\displaystyle=\sum_{1\leq j\leq|\mathcal{B}|}b_{j}+\sum_{1\leq i\leq|\mathcal{A}|}=H.

(iv)

Assume
\overline{s}\notin X
and
\overline{t}\in X
. In this case, the only outgoing edges with finite capacities are
(s,\overline{s})
and
(\overline{t},t)
, and thus we get

\displaystyle\operatorname{cap}(X)\geq c(s,\overline{s})+c(\overline{t},t)=\sum_{1\leq i\leq|\mathcal{A}|}a_{i}+\sum_{1\leq j\leq|\mathcal{B}|}b_{j}=H.

Thus, a minimum
s
-
t
-cut of
G
has at least capacity
H
. Since there exists a cut with capacity
H
, this bound is tight. We still need to show that the finite capacities on outgoing edges from
\overline{s}
and ingoing edges to
\overline{t}
are fully exhausted. Suppose not, then there exists at least one edge which is not fully exhausted. We prove this by case distinction. Suppose an edge
(\overline{s},i)
from
\overline{s}
to a player node
i
has flow value
f_{i}
strict less than
p_{i}
. Then, the capacity on outgoing edges from
s
and
\overline{s}
is given by
\sum_{A_{i}\in\mathcal{A}}a_{i}+\sum_{B_{j}\in\mathcal{B}}b_{j}-\sum_{i\in N}p_{i}
. Since we assumed at least one edge capacity is not fully exhausted, we obtain
\sum_{i\in N}p_{i}<\sum_{A_{i}\in\mathcal{A}}a_{i}+\sum_{B_{j}\in\mathcal{B}}b_{j}
, which is a contradiction to
p
being a core vector. Thus, in this case all the edges are fully exhausted.

The case for ingoing edges to
\overline{t}
follows analogously. In total, this shows that a feasible flow
f
exists that induces the given payment
p
.
∎

With the equivalence between a core vector and a feasible flow in the profit sharing graph, the problem of finding a such a core vector can now be done in polynomial time using any polynomial time maximum flow algorithm (cf.
[
2
]
for an overview of flow algorithms). We summarize this in the next theorem.

Theorem 3.4
.

A core element for an RPS game can be computed in polynomial time.
\Box

4
Conclusion and Outlook

In this paper we introduced a novel class of combinatorial cooperative games, namely the
reward-penalty-selection games
(RPS games) which are based on the
reward-penalty-selection problem
(RPSP). We showed that an RPS game is convex and, thus, its core is always non-empty. Furthermore, we showed that RPS games are a proper subgroup of convex games. RPS games allow a polynomial computation of the Shapley value. Focusing more on solution vectors of RPS games, we gave a characterization of core elements as feasible flows in a network graph. Thus, a core element can be computed not only in polynomial time but also efficiently.

Future research is directed to find flow representations of other payment vectors that fulfill certain fairness properties. For instance, the egalitarian allocation (cf.
[
3
,
8
]
) has the property to distribute the obtained profit in a “most equal” way among the players as well as being contained in the core given a convex game. This could be transformed to finding a feasible flow of a certain value with the additional property that the flow values on edges do not differ “too much”. This problem of finding an
almost equal flow
was introduced in
[
5
]
. However, at the current stage it is not clear whether such a one-to-one correspondence between almost equal flows and egalitarian allocations actually holds.

Altogether, due to their generality, we think that RPS games are a widely viable modeling technique for profit sharing for several underlying application settings.
