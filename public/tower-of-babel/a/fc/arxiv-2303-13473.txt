Very Basic Set theory
Doeko H. Homan

Abstract
. The naive conception of set is described as ”Any predicate has an extension”. Then Russell’s paradox is used to prove the inconsistency of naive set theory. Russell’s paradox reads ”No set can contain all and only those sets which do not contain themselves”. We call a set which contains itself an ‘individual’. In this article we show Russell’s paradox is logically equivalent to ‘for every set s s , an individual is contained in s s or a set that is not an individual is not contained in s s ’. Very basic set theory is a set theory with individuals that has its philosophical foundation in Ludwig Wittgenstein’s Tractatus Logico-Philosophicus.

1.
What is an individual?

In set theory
s\in s
is possible thus individuals are possible. But a set
that contains itself, an individual, is problematic (Boolos [1971] p.217,
pp.219-220)

”perhaps the mind ought to boggle at the idea of something’s
containing

itself.”

”It is important to realize how odd the idea of something’s containing itself
is.”

”Here are some things. Now we bind them up into a whole.
Now

set.”

However, ‘binding up some things’ or ‘containing something’ is not the
definition of a set. A set does not ‘contain’ something, the constituents of a
set exist.

Georg Cantor defined a set as (Boolos [1971] p.215)

•

”a ‘many, which can be thought of as one, i.e. a totality of definite

elements that can be combined into a whole by a law’.”

Thus a set is something which can be thought of as one, therefore a set is a
‘mental picture’ in your mind. That is in line with (Wittgenstein [1999] p.39)
proposition

•

”2.1 We make to ourselves pictures of facts.”

Therefore we prefer to write ‘constituent of a set’, not ‘contained in a
set’.

Set theory is a language that follows rules of logic to communicate the mental
picture of a set with the physical world. Then someone reading, seeing or
listening that language forms a mental picture of a set. That picture agrees or
disagrees with the picture in your mind. (Wittgenstein [1999] p.43) proposition

•

”2.222 In the agreement or disagreement of its sense with reality, its
truth

or falsity consists.”

An individual is what is called in (Wittgenstein [1999]) ”a simple sign”
(propositions

3.2, 3.201, 3.202, 3.26). In the Introduction (p.12) Bertrand Russell
explains

”If an atomic fact is analyzed as fully as possible (theoretical, not
practical

possibility is meant) the constituents finally reached may be
called simples

or objects.”

”(…) the naming of simples is shown to be what is logically first in
logic.”

Therefore in
Very basic set theory
the naming of individuals is logically
first.

2.
What is a set?

At an early age you develop the mental picture of ‘what is a set’. You belong
to a family or a clan, to the inhabitants of a village or a particular region.
Then experience shows there are things that constitute a set. The members of a
set are the constituents of that set. Therefore
Very basic set theory

describes

:

a world of individuals,

:

with a definite membership relation between sets,

:

the basic properties of a set are the constituents of that set and the
sets that set is a member of,

:

the only constituent of an individual is that individual itself.

Experience shows a set ‘is equal to’ or ‘is not equal to’ another set. Sets
with different constituents are different sets, and different sets have
different constituents.

Set theory follows rules of logic. Logic treats every possibility thus logic
treats the definiteness of the membership relation. In the next section we
prove the building up of logical formulas preserves definiteness.

4.
Russell’s paradox

We prove Russell’s paradox, that is formula
\neg\exists s\forall u(u\in s\leftrightarrow u\notin u)

”No set can contain all and only those sets which do not contain themselves”.

Assume exists set
s
such that for every set

(u\in s\leftrightarrow u\notin u)
.

The formula applies to every
u

s
therefore

exists

such that
(s\in s\leftrightarrow s\notin s)

Formula
(s\in s\leftrightarrow s\notin s)

(s\in s\vee s\in s)\wedge(s\notin s\vee s\notin s)

(s\in s\wedge s\notin s)

Formula

Therefore set

Formula
\exists s\forall u(u\in s\leftrightarrow u\notin u)

\neg\exists s\forall u(u\in s\leftrightarrow u\notin u)
.

\Box

Then Russell’s paradox

\forall s\exists u(u\in s\leftrightarrow u\in u)

\forall s\exists u((u\in s\wedge u\in u)\vee(u\notin s\wedge u\notin u))

Therefore the logic of definiteness proves that

Axiom ‘pairs’

Any pair of sets constitute a set. We postulate ‘pairs’.

•

\forall s\forall t\exists v\forall u(u\in v\leftrightarrow(u=s\vee u=t))

Set

8.

The naming of individuals is logically first. Thus every set has a constituent,

\forall s\exists v(v\in s\wedge\forall u((u\in s\wedge u\in v)\rightarrow u\in u))

Therefore any sequence of sets

\forall s\forall t(s\neq t\rightarrow(s\notin t\vee t\notin s))

Axiom ‘union’

The members of the members of a set constitute a set. We postulate ‘union’.

10.
Natural numbers

In the Introduction (Wittgenstein [1999] p.21) Bertrand Russell writes

”No logic can be considered adequate until it has been shown to be capable of

The logic in Very basic set theory is capable to deal with transfinite
numbers.

Conclusion

Very basic set theory is a set theory that has its philosophical
foundation in Ludwig Wittgenstein’s Tractatus Logico-Philosophicus. It is a set
theory with individuals, the logic is capable to deal with transfinite numbers
and the naming of individuals is logically first. But individuals are not
needed for mathematical purposes therefore individuals are banished from
‘mainstream set theory’.

There are more differences with mainstream set theory. For example, the axiom
‘powerset’ is as usual but Cantor’s Theorem does not hold.

•

(powerset)
\forall s\exists v\forall u(u\in v\leftrightarrow u\subseteq s)
.

Set
v
is denoted by
{\mathcal{P}}s
. Then
{\mathcal{P}}\{s\}=\{\{s\}\}

thus the ‘number of members’ of
\{s\}

is equal to the ‘number of members’ of

.

Cantor’s Theorem (Zermelo [1908] p.276) reads

for every set

s

of

members’ of
{\mathcal{P}}s
.

Thus Cantor’s Theorem does not hold.

\Box
