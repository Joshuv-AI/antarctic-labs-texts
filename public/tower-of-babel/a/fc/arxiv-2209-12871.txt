Variationally Mimetic Operator Networks
Dhruv Patel, Deep Ray, Michael R A Abdelmalik, Thomas J R Hughes, Assad A Oberai

Abstract
In recent years operator networks have emerged as promising deep learning tools for approximating the solution to partial differential equations (PDEs). These networks map input functions that describe material properties, forcing functions and boundary data to the solution of a PDE. This work describes a new architecture for operator networks that mimics the form of the numerical solution obtained from an approximate variational or weak formulation of the problem. The application of these ideas to a generic elliptic PDE leads to a variationally mimetic operator network ( VarMiON ). Like the conventional Deep Operator Network (DeepONet) the VarMiON is also composed of a sub-network that constructs the basis functions for the output and another that constructs the coefficients for these basis functions. However, in contrast to the DeepONet, the architecture of these sub-networks in the VarMiON is precisely determined. An analysis of the error in the VarMiON solution reveals that it contains contributions from the error in the training data, the training error, the quadrature error in sampling input and output functions, and a “covering error” that measures the distance between the test input functions and the nearest functions in the training dataset. It also depends on the stability constants for the exact solution operator and its VarMiON approximation. The application of the VarMiON to a canonical elliptic PDE and a nonlinear PDE reveals that for approximately the same number of network parameters, on average the VarMiON incurs smaller errors than a standard DeepONet and a recently proposed multiple-input operator network (MIONet). Further, its performance is more robust to variations in input functions, the techniques used to sample the input and output functions, the techniques used to construct the basis functions, and the number of input functions. Moreover, it consistently outperforms baseline methods at various dataset sizes. Keywords: variational formulation, deep neural operator, deep operator network, error analysis.

Introduction

Over the last decade there has been significant interest in the use of Deep Learning (DL) based methods for solving problems that emerge from physical principles. This includes the so-called Physics-Informed Neural Networks (PINNs) that were introduced in the 1990s
[
19
]
(though not under that name) and then further developed more recently
[
32
]
. There have been several interesting extensions of PINNs
and theoretical investigations into their approximations properties, a selective list of which includes
[
38
,
18
,
26
,
36
,
9
,
29
,
30
,
33
,
10
,
8
]
. However, one shortcoming of these techniques is that the fully trained network represents the solution of a single instance of the problem. If a slightly different problem is to be solved, for example, by altering the forcing function for a given partial differential equation (PDE), the network has to be retrained, which can be an arduous task.

Operator Networks address this challenge directly. Rather than focusing on a single instance of the solution to a given system, they approximate the operator that maps the input functions to the solution. For example, for a physical problem governed by a system of PDEs (which is the focus of this work), the input would consist of functions that specify the initial conditions, the boundary conditions, the forcing terms and the material properties, while the output function would be the solution of the system of PDEs. The benefit of the operator point of view is obvious. Once the network is trained it can be used to solve multiple instances of a problem corresponding to different input functions. This makes it an ideal surrogate model for many-query tasks like uncertainty quantification and optimization that require solutions corresponding to multiple instances of input functions.

Broadly speaking, two distinct types of Operator Networks have been proposed and implemented.
One of the first operator network architecture was first introduced in
[
7
]
along with universal approximation guarantees. This result was then adapted to deep neural networks in
[
25
]
and the resulting model was called a DeepONet. In a DeepONet, the overall network is split into a branch and a trunk sub-network, and the solution is represented as a dot product between their outputs. The branch network accepts as input, samples of the input functions at discrete points and maps these to a latent vector of a fixed dimension. On the other hand, the trunk network maps the spatial coordinates of the problem to a latent vector of the same fixed dimension. The solution is obtained by performing a dot-product between these vectors. Given this, the trunk network can be viewed as a network that constructs a basis for representing the solution, and the branch network can be viewed as a network that constructs the coefficients for the basis functions.

There has been significant recent work on extending and improving DeepONets. This includes reducing the amount of labeled data (the number of spatial points where the solution is required) needed to train the network
[
35
]
by adding terms to the loss function that are driven by the residual of the original system of equations. For physical problems that are derived from variational principles, the same benefit can also be achieved by encoding the variational principle into the loss function
[
12
]
. For example, if the governing equations are obtained from the minimization of the total potential energy, then the potential energy of the system can be added to the overall loss function for the network. Other interesting work on DeepONets includes their extension to approximating stochastic operators
[
37
]
, to operators associated with multiphysics problems
[
27
,
5
]
, to operators with multiple inputs and outputs
[
14
,
34
]
, and to instances where the sensor points, which are the points where the input functions are queried, are allowed to vary from one sample to another
[
31
]
.

There has also been significant work on analyzing the approximation properties of DeepONets. This includes the original universal approximation result for a shallow network
[
7
]
, a variant using radial basis functions (RBFs)
[
6
]
and the recent extension to deep networks
[
20
]
. In the same work
[
20
]
, the authors have also established error bounds for DeepONets used to approximate a broad class of operators. These bounds quantify the rate of growth in the network parameters as a function of the desired error in its solution. For a broad class of operators it is shown that this rate is exponential, however for specific operators driven by solutions to PDEs it is much milder.

Distinct from DeepONets is the work on Neural Operators
[
17
]
, which includes Graph Neural Operators, Fourier Neural Operators and their variants
[
21
]
. Neural Operators can be thought of as direct extensions of typical deep neural networks to infinite dimensional functions. Like a typical neural network, they are composed of multiple layers, where each layer performs a linear and a nonlinear operation. However, in contrast to a typical deep neural network, the operations are performed on functions rather than vectors. The non-linear operation is performed using standard activation functions that are applied point-wise, while the linear operation is performed by local (affine) and non-local operators. Different choices of implementing the non-local operators lead to different types of Neural Operators. These include Fourier Neural Operators
[
21
]
, Multipole Neural Operators
[
23
]
and Graph Neural Operators
[
22
]
. A physics-informed variant of Neural Operators which combined both data and PDE constraints was proposed in
[
24
]
. Recently, analytical estimates that quantify the performance of Fourier Neural Operators
[
16
]
have been developed. These include a universal approximation theorem and growth rates in complexity as a function of desired error when these networks are used to solve canonical problems like the steady-state heat conduction equation and the incompressible Navier Stokes equations.

In this manuscript we ask the question whether operator networks can be informed by the weak, or variational, formulations that are used to approximate solutions to PDEs. These formulations have traditionally been used to develop finite element methods, spectral methods, and projection-based reduced order models. Specifically, we consider the solution of an elliptic PDE and a nonlinear advection-diffusion-reaction PDE with spatially varying coefficients, forcing functions, and Neumann boundary data. The application of a standard method, like the Galerkin method, to this problem leads to a numerical solution with a very specific structure. Motivated by this structure, we propose a Variationally Mimetic Operator Network (
VarMiON
). Thereafter, we demonstrate that this network has several special features. These include:

1.

A computationally efficient network structure. For canonical linear and nonlinear problems we demonstrate that for roughly the same number of network parameters, the variationally mimetic network produces solutions that are significantly more accurate than the solutions produced by a generic DeepONet or MIONet
[
14
]
. This improved performance holds for a network (a) with multiple input functions, (b) input sensors that are distributed randomly, or distributed in a spatially uniform grid, and (c) for a trunk network comprised of basis functions that employ ReLU activations, or those constructed from a span of radial basis functions. We also demonstrate that the accuracy of the
VarMiON
is more robust. That is, when considering solutions corresponding to a distribution of input functions, the distribution of error has lower variance than a conventional DeepONet. Moreover, the VarMiON consistently outperforms both the DeepONet and the MIONet at varying cardinality of training set demonstrating its usefulness in low-data regimes.

2.

Motivated by the error analysis for methods like the finite element method, we derive an
a-priori
error estimate for the solutions of the
VarMiON
. This analysis reveals that the overall network error can be reduced by (a) training it with more accurate solutions, (b) training it with a large data set, (c) by designing branch networks that are stable with respect to perturbations in their input, and (b) by using larger number points for sampling the input and output functions. Further, the variationally-mimetic structure of the network enables a precise definition of the constants that appear in the error estimate. These constants are obtained from the discrete operators (matrices) that appear in the network, which can be easily evaluated for a trained network.

3.

The development of a workflow that couples an efficient numerical solver for a given class of problems and a
VarMiON
that is trained using solutions produced by the solver. The solver is used to train the
VarMiON
, and to guide the design of the higher level structure of the network, such as selecting the nature of branches (linear/non-linear), determining the format of the branch output (matrix or vector), specifying how branches interact with each other (via matrix-vector product, dot product, or Hadamard product), and interpreting each constituent of the network (such as the trunk network serving as a surrogate for the basis functions of the numerical solver). Further, the error analysis for the
VarMiON
includes the error in the solver.

The format of the remainder of this paper is as follows. In Section
2
, we introduce the model linear PDE and present its variational discretization. This motivates the architecture of the variationally mimetic operator network for canonical linear problems which is introduced in Section
3
. In the following section (Section
4
) we present an analysis of the generalization error of the network. Thereafter, in Section
5
, we present the extension of the
VarMiON
to nonlinear PDEs. In Section
6
we present numerical results that demonstrate the benefit of the variationally mimetic architecture for both linear and non-linear problems. In particular, we demonstrate that for approximately the same number of network parameters, the
VarMiON
produces more accurate solutions as compared to a conventional DeepONet and MIONet. It can also be used to introduce “optimal” basis functions, which further improve its performance. We end with conclusions in Section
7
.

2
PDE model and discretization

Let
\Omega\in\mathbb{R}^{d}
be an open, bounded domain with piecewise smooth boundary
\Gamma
. The boundary is further split into the Dirichlet boundary
\Gamma_{g}
and natural boundary
\Gamma_{\eta}
, with
\Gamma=\Gamma_{g}\cup\Gamma_{\eta}
. Define the space
H^{1}_{g}=\{u\in H^{1}(\Omega)\ :\ u\big|_{\Gamma_{g}}=0\}
. We consider the following scalar elliptic boundary value problem

\displaystyle\mathcal{L}(u({\bm{x}});\theta({\bm{x}}))

\displaystyle=f({\bm{x}}),\quad

\displaystyle\forall\ {\bm{x}}\in\Omega,

(2.1)

\displaystyle\mathcal{B}(u({\bm{x}});\theta({\bm{x}}))

\displaystyle=\eta({\bm{x}}),\quad

\displaystyle\forall\ {\bm{x}}\in\Gamma_{\eta},

\displaystyle u({\bm{x}})

\displaystyle=0,\quad

\displaystyle\forall\ {\bm{x}}\in\Gamma_{g},

where
\mathcal{L}
is assumed to be a second-order elliptic operator,
\mathcal{B}
is the natural boundary operator,
f\in\mathcal{F}\subset L^{2}(\Omega)
is the source term,
\eta\in\mathcal{N}\subset L^{2}(\Gamma_{\eta})
is the flux data, and
\theta\in\mathcal{T}\subset L^{\infty}(\Omega)
is some spatially varying material parameter, such as thermal conductivity or permeability.

The variational formulation of (
2.1
) is given by: find
u\in H^{1}_{g}
such that
\forall\ w\in H^{1}_{g}

a(w,u;\theta)=(w,f)+(w,\eta)_{\Gamma_{\eta}},

(2.2)

where
(.,.)
and
(.,.)_{\Gamma_{\eta}}
are respectively the
L^{2}(\Omega)
and
L^{2}(\Gamma_{\eta})
inner-products, while
a(.,.;\theta)
is the associated bilinear form. We assume that we are working with operators
\mathcal{L}
possessing requisite properties, such as uniform ellipticity and continuity, to ensure that (
2.2
) is well-posed.
We refer interested users to
[
11
,
4
]
for additional details.

Consider the solution operator

{\mathcal{S}}:\mathcal{X}=\mathcal{F}\times\mathcal{T}\times\mathcal{N}\longrightarrow\mathcal{V}\subset H^{1}_{g},\quad{\mathcal{S}}(f,\theta,\eta)=u(.;f,\theta,\eta)

(2.3)

which maps the data
(f,\theta,\eta)
to the unique solution
u(,;f,\theta,\eta)
of (
2.2
). Our goal is to approximate the operator
{\mathcal{S}}
using a
VarMiON
.

For everything that follows, we assume that
\Omega
,
\Gamma_{\eta}
and
\Gamma_{g}
are fixed for a given PDE model, while the various quantities appearing in (
2.1
) are dimensionless.

2.1
Numerical solution

Training the
VarMiON
requires solutions of (
2.2
) for varying
(f,\theta,\eta)\in\mathcal{X}
. In the absence of analytical expressions, (
2.2
) can be approximately solved using a suitable numerical solver. We consider the class of solvers that approximate
\mathcal{V}
by the space
\mathcal{V}^{h}
spanned by a set of continuous basis functions
\{\phi_{i}({\bm{x}})\}_{i=1}^{q}
. For instance, we could use a FEM or POD basis approximating the solutions of (
2.2
)
[
13
,
2
]
. Then any function
v^{h}\in\mathcal{V}^{h}
can be be expressed as a linear combination of the finite basis

v^{h}({\bm{x}})=v_{i}\phi_{i}({\bm{x}})={\bm{V}}^{\top}{\bm{\Phi}}({\bm{x}}),\quad{\bm{V}}=(v_{1},\cdots,v_{q})^{\top},\quad{\bm{\Phi}}({\bm{x}})=(\phi_{1}({\bm{x}}),\cdots,\phi_{q}({\bm{x}}))^{\top}.

We also define the restricted space
\mathcal{V}^{h}\big|_{\Gamma_{\eta}}=\{v\big|_{\Gamma_{\eta}}:v\in\mathcal{V}^{h}\}
for the boundary data.
Consider the projector

\mathcal{P}:\mathcal{X}\rightarrow\mathcal{X}^{h}:=\mathcal{F}^{h}\times\mathcal{T}^{h}\times\mathcal{N}^{h}\subset\mathcal{V}^{h}\times\mathcal{V}^{h}\times\mathcal{V}^{h}\big|_{\Gamma_{\eta}},\qquad\mathcal{P}(f,\theta,\eta)=(f^{h},\theta^{h},\eta^{h})

(2.4)

where the given PDE data is approximated (projected) as

f^{h}({\bm{x}})={\bm{F}}^{\top}{\bm{\Phi}}({\bm{x}}),\quad\theta^{h}({\bm{x}})={{\bm{\Theta}}}^{\top}{\bm{\Phi}}({\bm{x}}),\quad\eta^{h}({\bm{x}})={\bm{N}}^{\top}{\bm{\Phi}}({\bm{x}})\big|_{\Gamma_{\eta}}.

(2.5)

The coefficients
{\bm{F}},{{\bm{\Theta}}},{\bm{N}}
will depend on the choice of the basis functions (also see Remark
2.1
). If the approximate solution in
\mathcal{V}^{h}
is represented as
u^{h}({\bm{x}})={\bm{U}}^{\top}{\bm{\Phi}}({\bm{x}})
, then using (
2.5
) in (
2.2
) gives us the discrete weak formulation (see
[
13
]
, for example)

{\bm{K}}(\theta^{h}){\bm{U}}={\bm{M}}{\bm{F}}+{\widetilde{\bm{M}}}{\bm{N}}

(2.6)

where the matrices are given by

K_{ij}(\theta^{h})=a(\phi_{i},\phi_{j};\theta^{h}),\quad M_{ij}=(\phi_{i},\phi_{j}),\quad\widetilde{M}_{ij}=(\phi_{i},\phi_{j})_{\Gamma_{\eta}}\quad 1\leq i,j\leq q.

(2.7)

Note that the matrix
{\bm{M}}
will be invertible by virtue of its positive-definiteness. In order to recover the solution coefficients
{\bm{U}}
from (
2.6
), we make the following assumption.

Assumption 2.1
.

The basis
\{\phi_{i}({\bm{x}})\}_{i=1}^{q}
is chosen such that the matrix
{\bm{K}}(\theta^{h})
is invertible for all
\theta^{h}\in\mathcal{T}^{h}
. Note that this is equivalent to requiring the spectrum of
{\bm{K}}(\theta^{h})
to be bounded away from 0.

We can now define the discrete solution operator

{\mathcal{S}}^{h}:\mathcal{V}^{h}\times\mathcal{V}^{h}\times\mathcal{V}^{h}\big|_{\Gamma_{\eta}}\rightarrow\mathcal{V}^{h},\quad{\mathcal{S}}^{h}(f^{h},\theta^{h},\eta^{h}):=u^{h}(.;f^{h},\theta^{h},\eta^{h})=({\bm{B}}(f^{h},\theta^{h})+{\widetilde{\bm{B}}}(\eta^{h},\theta^{h}))^{\top}{\bm{\Phi}}

(2.8)

where

{\bm{B}}(f^{h},\theta^{h})={\bm{K}}^{-1}(\theta^{h}){\bm{M}}{\bm{F}},\quad{\widetilde{\bm{B}}}(\eta^{h},\theta^{h})={\bm{K}}^{-1}(\theta^{h}){\widetilde{\bm{M}}}{\bm{N}}.

(2.9)

Remark 2.1
.

Given
(f,\theta,\eta)\in\mathcal{X}
, the coefficients in (
2.5
) can be evaluated as
{\bm{F}}={\bm{M}}^{-1}{\overline{{\bm{F}}}}
and
{{\bm{\Theta}}}={\bm{M}}^{-1}{\overline{{{\bm{\Theta}}}}}
, where
{\overline{F}}_{i}=(f,\phi_{i})
and
{\overline{\Theta}}_{i}=(\theta,\phi_{i})
for
1\leq i\leq q
. Let us assume that
q^{\prime}\leq q
basis functions do not vanish (almost everywhere) on
\Gamma_{\eta}
, which we enumerate as
\{\phi_{R(j)}\}_{j=1}^{q^{\prime}}
with
R(j)
being the global index. Then the
q^{\prime}\times q^{\prime}
matrix
\mathring{{\bm{M}}}
given by
\mathring{M}_{ij}=(\phi_{R(i)},\phi_{R(j)})_{\Gamma_{\eta}}
will be a maximal invertible sub-matrix of
{\widetilde{\bm{M}}}
. This is used to uniquely define the coefficients of
\eta^{h}({\bm{x}})
as

\mathring{{\bm{N}}}=\mathring{{\bm{M}}}^{-1}{\overline{{\bm{N}}}},\quad{\overline{H}}_{j}=(\eta,\phi_{R(j)})_{\Gamma_{\eta}}\ \forall\ 1\leq j\leq q^{\prime},\quad H_{i}=\begin{cases}\mathring{H}_{j}&\quad\text{if }i=R(j)\text{ for some }1\leq j\leq q^{\prime}\\
0&\quad\text{otherwise}\end{cases}.

Note that Remark
2.1
implies that the projector
\mathcal{P}:\mathcal{X}\rightarrow\mathcal{X}^{h}
is a linear operator.

3
Variationally mimetic operator network

The
VarMiON
architecture is motivated by the discrete weak variational form (
2.6
). The PDE data
(f,\theta,\eta)\in\mathcal{X}
is fed into the
VarMiON
, with
f
and
\theta
sampled at the sensor nodes
\{{\widehat{\bm{x}}}_{i}\}_{i=1}^{k}
while
\eta
is sampled at the boundary sensor nodes
\{{\widehat{\bm{x}}}_{i}^{b}\}_{i=1}^{k^{\prime}}
on
\Gamma_{h}
. We define the input vectors

{\widehat{\bm{F}}}=(f({\widehat{\bm{x}}}_{1}),\cdots,f({\widehat{\bm{x}}}_{k}))^{\top},\quad{\widehat{\bm{\Theta}}}=(\theta({\widehat{\bm{x}}}_{1}),\cdots,\theta({\widehat{\bm{x}}}_{k}))^{\top},\quad{\widehat{\bm{N}}}=(\eta({\widehat{\bm{x}}}^{b}_{1}),\cdots,\eta({\widehat{\bm{x}}}^{b}_{k^{\prime}}))^{\top},

(3.1)

given by the data sensing operator
{\widehat{\mathcal{P}}}
as

{\widehat{\mathcal{P}}}:\mathcal{X}\rightarrow\mathbb{R}^{k}\times\mathbb{R}^{k}\times\mathbb{R}^{k^{\prime}},\qquad{\widehat{\mathcal{P}}}(f,\theta,\eta)=({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}},{\widehat{\bm{N}}}).

(3.2)

VarMiON
architecture.

We consider the
VarMiON
shown in Figure
1
, which comprises:

•

a
non-linear branch
taking the input
{\widehat{\bm{\Theta}}}\in\mathbb{R}^{k}
, which is transformed into a matrix output
{\bm{D}}({\widehat{\bm{\Theta}}})\in\mathbb{R}^{p\times p}
. Here
p
is the latent dimension of the
VarMiON
.

•

a
linear branch
taking the input
{\widehat{\bm{F}}}\in\mathbb{R}^{k}
and transforming it as
{\bm{A}}{\widehat{\bm{F}}}
, where
{\bm{A}}\in\mathbb{R}^{p\times k}
is a learnable matrix. The output of this branch is acted upon by the matrix
{\bm{D}}
to give
{\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}})={\bm{D}}({\widehat{\bm{\Theta}}}){\bm{A}}{\widehat{\bm{F}}}\in\mathbb{R}^{p}
.

•

a
linear branch
taking the input
{\widehat{\bm{N}}}\in\mathbb{R}^{k^{\prime}}
and transforming it as
{\widetilde{\bm{A}}}{\widehat{\bm{N}}}
, where
{\widetilde{\bm{A}}}\in\mathbb{R}^{p\times k^{\prime}}
is a learnable matrix. The output of this branch is acted upon by the matrix
{\bm{D}}
to give
{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}})={\bm{D}}({\widehat{\bm{\Theta}}}){\widetilde{\bm{A}}}{\widehat{\bm{N}}}\in\mathbb{R}^{p}
.

•

a
non-linear trunk
taking the input
{\bm{x}}\in\mathbb{R}^{d}
, which gives the output
{\bm{\tau}}({\bm{x}})=(\tau_{1}({\bm{x}}),\cdots,\tau_{p}({\bm{x}}))^{\top}
, where each
\tau_{i}:\mathbb{R}^{d}\rightarrow\mathbb{R}
is a trainable network.

Let
\mathcal{V}^{\tau}
be the space spanned by the trained trunk functions
\tau
. Then the final

operator is given by

\widehat{{\mathcal{S}}}:\mathbb{R}^{k}\times\mathbb{R}^{k}\times\mathbb{R}^{k^{\prime}}\rightarrow\mathcal{V}^{\tau},\qquad\widehat{{\mathcal{S}}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}},{\widehat{\bm{N}}})=\widehat{u}(.;{\widehat{\bm{F}}},{\widehat{\bm{\Theta}}},{\widehat{\bm{N}}})=\left({\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}})+{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}})\right)^{\top}{\bm{\tau}}.

(3.3)

Notice the similarity between (
2.8
) and (

). In particular,
{\bm{B}}
(respectively

) have the same structure as
{\bm{\beta}}
(respectively

). We further demonstrate in Section

The discrete operator
{\mathcal{S}}^{h}
is used to generate samples to train the
VarMiON
. This is done in the following manner:

1.

For
1\leq j\leq J
, consider distinct samples
(f_{j},\theta_{j},\eta_{j})\in\mathcal{X}
.

2.

Use the projector (

) to obtain the discrete approximations
(f^{h}_{j},\theta^{h}_{j},\eta^{h}_{j})\in\mathcal{X}^{h}
.

3.

Find the discrete numerical solution
u^{h}_{j}={\mathcal{S}}^{h}(f^{h}_{j},\theta^{h}_{j},\eta^{h}_{j})
.

4.

Use (
3.2
) to generate the
VarMiON
input vectors
({\widehat{\bm{F}}}_{j},{\widehat{\bm{\Theta}}}_{j},{\widehat{\bm{N}}}_{j})={\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})
.

5.

Select a set of output nodes
\{{\bm{x}}_{l}\}_{l=1}^{L}
. For each
1\leq j\leq J
, sample the numerical solution at these nodes as
u^{h}_{jl}=u^{h}_{j}({\bm{x}}_{l})
.

6.

Finally, collect all the inputs and output labels to form the training set containing
JL
samples

\mathbb{S}=\{({\widehat{\bm{F}}}_{j},{\widehat{\bm{\Theta}}}_{j},{\widehat{\bm{N}}}_{j},{\bm{x}}_{l},u_{jl}^{h}):1\leq j\leq J,\ 1\leq l\leq L\},

(3.4)

where
({\widehat{\bm{F}}}_{j},{\widehat{\bm{\Theta}}}_{j},{\widehat{\bm{N}}}_{j})
is the input to the branch subnets,

is the trunk input, and

is the target output.

Remark 3.1
.

To allow a point-wise evaluation of the input and output to the
VarMiON
, we need to assume
\mathcal{F}\subset C(\Omega)
,
\mathcal{N}\subset C(\Gamma_{\eta})
,
\mathcal{T}\subset C({\overline{\Omega}})
and
\mathcal{V}\subset C({\overline{\Omega}})
.

We also need to define a suitable loss/objective function which needs to be optimized to train the
VarMiON
. First, let
\{w_{l}\}_{l=1}^{L}
be the weights corresponding to the output nodes
\{{\bm{x}}_{l}\}_{l=1}^{L}\in\Omega
used to describe the following quadrature for the square of function
g:\Omega\rightarrow\mathbb{R}

\left|\sum_{l=1}^{L}w_{l}g^{2}({\bm{x}}_{l})-\int_{\Omega}g^{2}({\bm{x}})\text{d}{\bm{x}}\right|\leq\frac{{\mathcal{C}}_{Q}(g)}{L^{\gamma}},

(3.5)

where the

may depend on the derivatives of

. The rate of convergence

will depend on the quadrature rule used. Let

be the (vector of) trainable parameters of the

, which we make explicit by representing the

\Pi({\bm{\psi}})=\frac{1}{J}\sum_{j=1}^{J}\Pi_{j}({\bm{\psi}}),\qquad\Pi_{j}({\bm{\psi}})=\sum_{l=1}^{L}w_{l}\left(u^{h}_{jl}-{\widehat{\mathcal{S}}}_{\bm{\psi}}({\widehat{\bm{F}}}_{j},{\widehat{\bm{\Theta}}}_{j},{\widehat{\bm{N}}}_{j})[{\bm{x}}_{l}]\right)^{2}.

(3.6)

Note that
\Pi_{j}({\bm{\psi}})\approx\|{\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}_{\bm{\psi}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})\|^{2}_{L^{2}(\Omega)}
by virtue of (

Then training the

corresponds to solving the following optimization problem

{\bm{\psi}}^{*}=\underset{{\bm{\psi}}}{\arg\min}\Pi({\bm{\psi}}).

(3.7)

In practice, (

) is typically solved using iterative algorithms such as stochastic gradient descent or Adam
[
15
]
. Further, in the numerical results presented in Section

, we choose the output sensor nodes as random Monte Carlo nodes in the domain, with the corresponding quadrature weights set as
w_{l}=1/L
.

4
Error analysis

Our objective is to train a
VarMiON
such that the true solution operator
{\mathcal{S}}
is well-approximated by
{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}:\mathcal{X}\rightarrow\mathcal{V}^{\tau}
. We denote the corresponding error for any
(f,\theta,\eta)\in\mathcal{X}
as

\displaystyle{\mathcal{E}}(f,\theta,\eta)

\displaystyle:=

\displaystyle\|{\mathcal{S}}(f,\theta,\eta)-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f,\theta,\eta)\|_{L^{2}(\Omega)}.

(4.1)

which we also call the
generalization error
. Additionally, we define the error between
{\mathcal{S}}
and
{\mathcal{S}}^{h}
, i.e., the numerical approximation error, as

\displaystyle{\mathcal{E}}_{h}(f,\theta,\eta)

\displaystyle:=

\displaystyle\|{\mathcal{S}}(f,\theta,\eta)-{\mathcal{S}}^{h}\circ\mathcal{P}(f,\theta,\eta)\|_{L^{2}(\Omega)},

(4.2)

and that between
{\mathcal{S}}^{h}
and the
{\widehat{\mathcal{S}}}
as

\displaystyle{{\widehat{\mathcal{E}}}}(f,\theta,\eta)

\displaystyle:=

\displaystyle\|{\mathcal{S}}^{h}\circ\mathcal{P}(f,\theta,\eta)-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f,\eta,\theta)\|_{L^{2}(\Omega)}

(4.3)

\displaystyle=

\displaystyle\|{\mathcal{S}}^{h}(f^{h},\theta^{h},\eta^{h})-{\widehat{\mathcal{S}}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}},{\widehat{\bm{N}}})\|_{L^{2}(\Omega)}.

Further, for any
(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})\in\mathcal{X}
, we define the corresponding perturbation in the solution given by
{\mathcal{S}}
as

\displaystyle{\mathcal{E}}_{\text{stab}}[(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})]

\displaystyle:=

\displaystyle\|{\mathcal{S}}(f,\theta,\eta)-{\mathcal{S}}(f^{\prime},\theta^{\prime},\eta^{\prime})\|_{L^{2}(\Omega)},

(4.4)

and the
VarMiON
operator
{\widehat{\mathcal{S}}}
as

\displaystyle{{\widehat{\mathcal{E}}}}_{\text{stab}}[(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})]

\displaystyle:=

\displaystyle\|{\widehat{\mathcal{S}}}\circ\mathcal{P}(f,\theta,\eta)-{\widehat{\mathcal{S}}}\circ\mathcal{P}(f^{\prime},\theta^{\prime},\eta^{\prime})\|_{L^{2}(\Omega)},

(4.5)

Then, for any training sample index
1\leq j\leq J
, we obtain the estimate

\displaystyle{\mathcal{E}}(f,\theta,\eta)

\displaystyle=

\displaystyle\|{\mathcal{S}}(f,\theta,\eta)-{\mathcal{S}}(f_{j},\theta_{j},\eta_{j})+{\mathcal{S}}(f_{j},\theta_{j},\eta_{j})-{\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})

(4.6)

\displaystyle\ \ +{\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})+{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f,\theta,\eta)\|_{L^{2}(\Omega)}

\displaystyle\leq

\displaystyle\|{\mathcal{S}}(f,\theta,\eta)-{\mathcal{S}}(f_{j},\theta_{j},\eta_{j})\|_{L^{2}(\Omega)}+\|{\mathcal{S}}(f_{j},\theta_{j},\eta_{j})-{\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})\|_{L^{2}(\Omega)}

\displaystyle+\|{\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})\|_{L^{2}(\Omega)}+\|{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}\circ{\widehat{\mathcal{P}}}(f,\theta,\eta)\|_{L^{2}(\Omega)}

\displaystyle=

\displaystyle{\mathcal{E}}_{\text{stab}}[(f,\theta,\eta),(f_{j},\theta_{j},\eta_{j})]+{\mathcal{E}}_{h}(f_{j},\theta_{j},\eta_{j})+{{\widehat{\mathcal{E}}}}(f_{j},\theta_{j},\eta_{j})

\displaystyle+{{\widehat{\mathcal{E}}}}_{\text{stab}}[(f_{j},\theta_{j},\eta_{j}),(f,\theta,\eta)].

Thus, we need to find suitable bounds to each of the four terms on the right of the above expression, to bound the generalization error. These estimates are investigated in the following sections.

4.1
Stability of
{\mathcal{S}}

The term (
4.4
) captures how much the output of
{\mathcal{S}}
varies as the PDE-data is perturbed. Thus, bounding this term requires the solution operator of the PDE to be stable. This leads us to the following assumption.

Assumption 4.1
.

The solution operator
{\mathcal{S}}
is stable with respect to the PDE data. In other words, for any
(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})\in\mathcal{X}

\displaystyle{\mathcal{E}}_{\text{stab}}[(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})]\leq

\displaystyle{\mathcal{C}}_{\text{stab}}\left(\|f-f^{\prime}\|_{L^{2}(\Omega)}+\|\theta-\theta^{\prime}\|_{L^{2}(\Omega)}+\|\eta-\eta^{\prime}\|_{L^{2}(\Gamma_{\eta})}\right),

(4.7)

where
{\mathcal{C}}_{\text{stab}}
depends may depend on
\Omega
,
\Gamma_{\eta}
and
\Gamma_{g}
.

A stability estimate of the type (
4.7
) is guaranteed if the underlying PDE model is well-defined, and have been explored for elliptic PDEs in
[
3
,
28
]
.

4.2
Numerical approximation error

The term (
4.2
) characterizes the error introduced while generating the training set using the numerical solver to the PDE. This motivates the use of high-order solvers in the data generation process. For the purposes of our discussions, we make the following assumption about the numerical error.

Assumption 4.2
.

Given the projection function (
2.4
), there exists an
\epsilon_{h}>0
such that the following error bound holds

{\mathcal{E}}_{h}(f,\theta,\eta)<{\mathcal{C}}_{h}(f,\theta,\eta)\epsilon_{h}\quad\forall\ (f,\theta,\eta)\in\mathcal{X}

(4.8)

where
{\mathcal{C}}_{h}
may depend on the given PDE data.

Moving forward, we assume that the PDE data is bounded which is also typical for the data used to train neural networks.

Assumption 4.3
.

Assume that the PDE data space
\mathcal{X}
is compact. We also assume that the data is point-wise bounded. In other words, there exist constants
C_{\mathcal{F}},C_{\mathcal{T}},C_{\mathcal{N}}<\infty
such that

\displaystyle\|f\|_{L^{\infty}(\Omega)}\leq C_{\mathcal{F}}\ \forall\ f\in\mathcal{F},\quad\|\theta\|_{L^{\infty}(\Omega)}\leq C_{\mathcal{T}}\ \forall\ \theta\in\mathcal{T},\quad\|\eta\|_{L^{\infty}(\Gamma_{\eta})}\leq C_{\mathcal{N}}\ \forall\ \eta\in\mathcal{N}.

(4.9)

We make a few remarks here:

1.

Estimates of the form (
4.8
) are typically available depending on the underlying numerical solver used to obtain
u^{h}
. For instance, if a Galerkin finite element method with degree
r
basis functions is used to solve (
2.1
), then under sufficient regularity of the solution we get
\epsilon_{h}\sim h^{r+1}
where
h
represents the size of the elements.

2.

We have assumed
{\mathcal{C}}_{h}
to be as general as possible by allowing it to depend on the triplet
(f,\theta,\eta)
. However, if the underlying method is of Galerkin-type, then by Galerkin orthogonality,
{\mathcal{C}}_{h}
will not depend on
f
and
\eta
, i.e.,
{\mathcal{C}}_{h}={\mathcal{C}}_{h}(\theta)
.

3.

In addition to the bounds assumed in Assumption
4.3
, we may require
\theta>0
to ensure the well-definedness of the underlying PDE, for instance the steady-state heat conduction problem considered in Section
6
.

4.

With the assumption of compactness of
\mathcal{X}
, we can define the following finite-valued constants

{\mathcal{C}}_{h,\mathbb{S}}=\max_{1\leq j\leq J}{\mathcal{C}}_{h}(f_{j},\theta_{j},\eta_{j}),\quad{\mathcal{C}}_{h,\mathcal{X}}=\sup_{\mathcal{X}}{\mathcal{C}}_{h}(f,\theta,\eta),

(4.10)

with
{\mathcal{C}}_{h,\mathbb{S}}\leq{\mathcal{C}}_{h,\mathcal{X}}
.

4.3
Training error

We now wish to find a bound for (
4.3
) when evaluated on the training set. We demonstrate that this is closely associated with the final training error (which need not be zero) after solving the optimization problem (
3.7
).

We begin by introducing the notion of when the
VarMiON
is said to be well-trained.

Definition 4.1

(
\epsilon_{t}
-trained)
.

Let a
VarMiON
with operator
{\widehat{\mathcal{S}}}
be trained on a dataset
\mathbb{S}
generated by the set
\{f_{j},\theta_{j},\eta_{j}\}_{j=1}^{J}
and defined by (
3.4
). Let
\{{\bm{x}}_{l}\}_{l=1}^{L}
and
\{w_{l}\}_{l=1}^{L}
be the quadrature nodes and weights asociated with the (
3.5
). Then the
VarMiON
is said to be
\epsilon_{t}
-trained for some
\epsilon_{t}>0
if the following estimate holds for the trained network

\Pi_{j}({\bm{\psi}}^{*})<\epsilon_{t}\quad\forall\ 1\leq j\leq J

(4.11)

where
\Pi(\phi^{*})_{j}
is defined according to (
3.6
).

Note that the satisfaction of the estimate (
4.11
) can be monitored in practice while training the
VarMiON
. The following result is a consequence of Definition
4.1
, the proof of which follows trivially from (
3.6
), (
3.5
) and the relation
\sqrt{(a+b)}\leq(\sqrt{a}+\sqrt{b})
for
a,b\geq 0
.

Lemma 4.1
.

Let us define the (point-wise) error in approximating the numerical solution using the
VarMiON
{\widehat{\mathcal{S}}}
for the
j-th
training sample as

e_{j}={\mathcal{S}}^{h}\circ\mathcal{P}(f_{j},\theta_{j},\eta_{j})-{\widehat{\mathcal{S}}}_{\bm{\psi}}\circ{\widehat{\mathcal{P}}}(f_{j},\theta_{j},\eta_{j}).

If
{\widehat{\mathcal{S}}}
is
\epsilon_{t}
-trained, then the training error
\Pi({\bm{\psi}}^{*})<\epsilon_{t}
and

{{\widehat{\mathcal{E}}}}(f_{j},\theta_{j},\eta_{j})\leq\sqrt{\Pi_{j}({\bm{\psi}}^{*})}+\frac{\sqrt{{\mathcal{C}}_{Qj}}}{L^{\gamma/2}}\leq\sqrt{\epsilon_{t}}+\frac{\sqrt{{\mathcal{C}}_{Q,\mathbb{S}}}}{L^{\gamma/2}}

(4.12)

where
{\mathcal{C}}_{Qj}={\mathcal{C}}_{Q}(e_{j})
is defined as in (
3.5
) and
{\mathcal{C}}_{Q,\mathbb{S}}=\max\limits_{1\leq j\leq J}{\mathcal{C}}_{Qj}
.

4.4
Stability of
{\widehat{\mathcal{S}}}

Controlling the term (
4.5
) requires an estimate of the stability of
VarMiON
operator
{\widehat{\mathcal{S}}}
. First, the assumption
4.3
leads to the following bounds for all
(f,\theta,\eta)\in\mathcal{X}

\displaystyle\|{\widehat{\bm{F}}}\|_{2}\leq\sqrt{k}{\mathcal{C}}_{\mathcal{F}},\quad\|{\widehat{\bm{\Theta}}}\|_{2}\leq\sqrt{k}{\mathcal{C}}_{\mathcal{T}},\quad\|{\widehat{\bm{N}}}\|_{2}\leq\sqrt{k^{\prime}}{\mathcal{C}}_{\mathcal{N}}.

(4.13)

Next, to ensure the
VarMiON
output is bounded, we make the following assumption.

Assumption 4.4
.

The various sub-components of the
VarMiON
are bounded. In other words, there exist positive constants
{\mathcal{C}}_{\bm{A}},{\mathcal{C}}_{\widetilde{\bm{A}}},{\mathcal{C}}_{\tau},<\infty
such that

\|{\bm{A}}\|_{2}\leq{\mathcal{C}}_{\bm{A}},\quad\|{\widetilde{\bm{A}}}\|_{2}\leq{\mathcal{C}}_{\widetilde{\bm{A}}},\quad\|{\bm{\tau}}\|_{L^{2}(\Omega)}\leq{\mathcal{C}}_{\tau},

(4.14)

where it is understood that the
L^{2}
norm of a vector-valued function is given by

\|{\bm{\tau}}\|_{L^{2}(\Omega)}=\left(\sum_{i=1}^{p}\|\tau_{i}\|^{2}_{L^{2}(\Omega)}\right)^{1/2}.

The bounds in the above assumption are typically ensured by the fact the the input data to the
VarMiON
is bounded, and the use of regularization techniques to control the magnitude of the trainable parameters of the
VarMiON
.

We also rely on the following simple result to obtain several estimates moving forward.

Lemma 4.2
.

Let
\bm{f}\in L^{2}(\Omega;\mathbb{R}^{n})
,
\bm{v}\in\mathbb{R}^{n}
and define
\ell=\bm{v}^{\top}\bm{f}
. Then,
\ell\in L^{2}(\Omega)
and

\|\ell\|_{L^{2}(\Omega)}\leq\|\bm{v}\|_{2}\|\bm{f}\|_{L^{2}(\Omega)}.

Proof.

The result can obtained by a simple application of Cauchy-Schwarz

\displaystyle\|\ell\|^{2}_{L^{2}(\Omega)}=\int_{\Omega}\left(\bm{v}^{\top}\bm{f}({\bm{x}})\right)^{2}\text{d}{\bm{x}}=\int_{\Omega}\left(\sum_{i=1}^{n}v_{i}f_{i}({\bm{x}})\right)^{2}\text{d}{\bm{x}}

\displaystyle\leq

\displaystyle\int_{\Omega}\left(\sum_{i=1}^{n}v_{i}^{2}\right)\left(\sum_{i=1}^{n}f_{i}^{2}({\bm{x}})\right)\text{d}{\bm{x}}

\displaystyle=

\displaystyle\|\bm{v}\|^{2}_{2}\sum_{i=1}^{n}\|f_{i}\|^{2}_{L^{2}(\Omega)}=\|\bm{v}\|^{2}_{2}\|\bm{f}\|^{2}_{L^{2}(\Omega)}.

∎

We can now prove the following stability estimate for the
VarMiON
.

Theorem 4.1
.

Assume the data is bounded in accordance to Assumption
4.3
. Define the set
\widehat{\mathcal{T}}=\{{\widehat{\bm{\Theta}}}:{\widehat{\bm{\Theta}}}=\{\theta({\widehat{\bm{x}}}_{i})\}_{i=1}^{k}\ \forall\ \theta\in\mathcal{T}\}\subset\mathbb{R}^{k}
, where
\{{\widehat{\bm{x}}}_{i}\}_{i=1}^{k}
are the
VarMiON
sensor nodes for
\theta
. Assume the non-linear branch
{\bm{D}}:\widehat{\mathcal{T}}\rightarrow\mathbb{R}^{p\times p}
of the trained
VarMiON
{\widehat{\mathcal{S}}}
is Lipschitz

\|{\bm{D}}(\widehat{{{\bm{\Theta}}}})-{\bm{D}}(\widehat{{{\bm{\Theta}}}}^{\prime})\|_{2}\leq L_{D}\|\widehat{{{\bm{\Theta}}}}-\widehat{{{\bm{\Theta}}}}^{\prime}\|_{2}\quad\forall\ {\widehat{\bm{\Theta}}},{\widehat{\bm{\Theta}}}^{\prime}\in\widehat{\mathcal{T}},

(4.15)

with Lipschitz constant
L_{D}
. Let
\|{\bm{D}}({\widehat{\bm{\Theta}}}_{0})\|_{2}
be bounded for some
{\widehat{\bm{\Theta}}}_{0}\in\widehat{\mathcal{T}}
. We also assume that the trained
VarMiON
is bounded in the sense of Assumption
4.4
.
Then for any
(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})\in\mathcal{X}
, the following stability estimate holds

\displaystyle{{\widehat{\mathcal{E}}}}_{\text{stab}}[(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})]\leq

\displaystyle\widehat{{\mathcal{C}}}_{\text{stab}}\left(\|{\widehat{\bm{F}}}-{\widehat{\bm{F}}}^{\prime}\|_{2}+\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}+\|{\widehat{\bm{N}}}-{\widehat{\bm{N}}}^{\prime}\|_{2}\right),

(4.16)

where
\widehat{{\mathcal{C}}}_{\text{stab}}
depends on the bounds in (
4.9
) and (
4.14
), the number of sensor nodes, and
L_{D}
.

Proof.

For any
(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})\in\mathcal{X}
, we have using (
3.3
)and (
4.5
)

\displaystyle{{\widehat{\mathcal{E}}}}_{\text{stab}}[(f,\theta,\eta),(f^{\prime},\theta^{\prime},\eta^{\prime})]

\displaystyle=

\displaystyle\|{\widehat{\mathcal{S}}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}},{\widehat{\bm{N}}})-{\widehat{\mathcal{S}}}({\widehat{\bm{F}}}^{\prime},{\widehat{\bm{\Theta}}}^{\prime},{\widehat{\bm{N}}}^{\prime})\|_{L^{2}(\Omega)}

(4.17)

\displaystyle\leq

\displaystyle\underbrace{\|\big({\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}})-{\bm{\beta}}({\widehat{\bm{F}}}^{\prime},{\widehat{\bm{\Theta}}}^{\prime})\big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}}_{{\mathcal{E}}_{{\bm{\beta}}}}

\displaystyle+\underbrace{\|\big({\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}})-{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}}^{\prime},{\widehat{\bm{\Theta}}}^{\prime})\big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}}_{{\mathcal{E}}_{{\widetilde{\bm{\beta}}}}}.

We can use the Lipschitz assumption on
{\bm{D}}
and (
4.13
) to prove that
{\bm{D}}
is bounded on
\widehat{\mathcal{T}}
. To see this, we consider
{\widehat{\bm{\Theta}}}_{0}\in\widehat{\mathcal{T}}
defined in the theorem statement to get

\displaystyle\|{\bm{D}}({\widehat{\bm{\Theta}}})\|_{2}-\|{\bm{D}}({\widehat{\bm{\Theta}}}_{0})\|_{2}

\displaystyle\leq\|{\bm{D}}({\widehat{\bm{\Theta}}})-{\bm{D}}({\widehat{\bm{\Theta}}}_{0})\|_{2}\leq L_{D}\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}_{0}\|_{2}\quad\forall\ {\widehat{\bm{\Theta}}}\in\widehat{\mathcal{T}},

\displaystyle\implies\|{\bm{D}}({\widehat{\bm{\Theta}}})\|_{2}

\displaystyle\leq\underbrace{\|{\bm{D}}({\widehat{\bm{\Theta}}}_{0})\|_{2}+2L_{D}\sqrt{k}{\mathcal{C}}_{\mathcal{T}}^{2}}_{{\mathcal{C}}_{D}}\quad\forall\ {\widehat{\bm{\Theta}}}\in\widehat{\mathcal{T}}.

(4.18)

Next, using (
4.13
), (
4.15
), (
4.4
), (
4.14
) and Lemma
4.2
, we get the estimate

\displaystyle{\mathcal{E}}_{{\bm{\beta}}}

\displaystyle=

\displaystyle\|\big({\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}})-{\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}}^{\prime})+{\bm{\beta}}({\widehat{\bm{F}}},{\widehat{\bm{\Theta}}}^{\prime})-{\bm{\beta}}({\widehat{\bm{F}}}^{\prime},{\widehat{\bm{\Theta}}}^{\prime})\big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}

(4.19)

\displaystyle=

\displaystyle\|\Big({\bm{D}}({\widehat{\bm{\Theta}}})-{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime})\big){\bm{A}}{\widehat{\bm{F}}}+{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime}){\bm{A}}\big({\widehat{\bm{F}}}-{\widehat{\bm{F}}}^{\prime}\big)\Big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}

\displaystyle\leq

\displaystyle\|{\bm{A}}\|_{2}\|{\bm{\tau}}\|_{L^{2}(\Omega)}\left(L_{D}\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}\|{\widehat{\bm{F}}}\|_{2}+\|{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime})\|_{2}\|{\widehat{\bm{F}}}-{\widehat{\bm{F}}}^{\prime}\|_{2}\right)

\displaystyle\leq

\displaystyle\|{\bm{A}}\|_{2}\|{\bm{\tau}}\|_{L^{2}(\Omega)}\left(L_{D}\sqrt{k}{\mathcal{C}}_{\mathcal{F}}\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}+{\mathcal{C}}_{D}\|{\widehat{\bm{F}}}-{\widehat{\bm{F}}}^{\prime}\|_{2}\right)

\displaystyle\leq

\displaystyle{\widehat{{\mathcal{C}}}}_{1}\left(\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}+\|{\widehat{\bm{F}}}-{\widehat{\bm{F}}}^{\prime}\|_{2}\right),

where

{\widehat{{\mathcal{C}}}}_{1}={\mathcal{C}}_{\bm{A}}{\mathcal{C}}_{\tau}\max\{L_{D}\sqrt{k}{\mathcal{C}}_{\mathcal{F}},{\mathcal{C}}_{D}\}.

Similarly

\displaystyle{\mathcal{E}}_{{\widetilde{\bm{\beta}}}}

\displaystyle=

\displaystyle\|\big({\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}})-{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}}^{\prime})+{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}},{\widehat{\bm{\Theta}}}^{\prime})-{\widetilde{\bm{\beta}}}({\widehat{\bm{N}}}^{\prime},{\widehat{\bm{\Theta}}}^{\prime})\big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}

(4.20)

\displaystyle=

\displaystyle\|\Big({\bm{D}}({\widehat{\bm{\Theta}}})-{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime})\big){\widetilde{\bm{A}}}{\widehat{\bm{N}}}+{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime}){\widetilde{\bm{A}}}\big({\widehat{\bm{N}}}-{\widehat{\bm{N}}}^{\prime}\big)\Big)^{\top}{\bm{\tau}}\|_{L^{2}(\Omega)}

\displaystyle\leq

\displaystyle\|{\widetilde{\bm{A}}}\|_{2}\|{\bm{\tau}}\|_{L^{2}(\Omega)}\left(L_{D}\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}\|{\widehat{\bm{N}}}\|_{2}+\|{\bm{D}}({\widehat{\bm{\Theta}}}^{\prime})\|_{2}\|{\widehat{\bm{N}}}-{\widehat{\bm{N}}}^{\prime}\|_{2}\right)

\displaystyle\leq

\displaystyle\|{\widetilde{\bm{A}}}\|_{2}\|{\bm{\tau}}\|_{L^{2}(\Omega)}\left(L_{D}\sqrt{k^{\prime}}C_{\mathcal{N}}\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}+{\mathcal{C}}_{D}\|{\widehat{\bm{N}}}-{\widehat{\bm{N}}}^{\prime}\|_{2}\right)

\displaystyle\leq

\displaystyle{\widehat{{\mathcal{C}}}}_{2}\left(\|{\widehat{\bm{\Theta}}}-{\widehat{\bm{\Theta}}}^{\prime}\|_{2}+\|{\widehat{\bm{N}}}-{\widehat{\bm{N}}}^{\prime}\|_{2}\right),

where

{\widehat{{\mathcal{C}}}}_{2}={\mathcal{C}}_{\widetilde{\bm{A}}}{\mathcal{C}}_{\tau}\max\{L_{D}\sqrt{k^{\prime}}{\mathcal{C}}_{\mathcal{N}},{\mathcal{C}}_{D}\}.

Combining (
4.17
), (
4.19
) and (
4.20
), and setting
{\widehat{{\mathcal{C}}}}_{stab}=2\max\{{\widehat{{\mathcal{C}}}}_{1},{\widehat{{\mathcal{C}}}}_{2}\}
proves the result.
∎

Remark 4.1
.

In
[
3
]
, it was shown for the homogeneous Dirichlet problem that if
\nabla u\in L^{r}(\Omega)
for some
r\geq 2
, then the solution operator (measured in
H^{1}_{0}(\Omega)
) is stable with respect to perturbations in
\theta
measured in
L^{s}
for
s=2r/(r-2)
. An analogue of such a result for the general elliptic mixed-boundary value problem considered in the present manuscript might change the norms for measuring
\theta
in (
4.7
), as well as the discrete norms in (
4.15
). This norm consistency might be useful in ensuring that the Lipschitz constant
L_{D}
is stable to variations in the latent dimension
p
. These concepts will be explored in future work.

4.5
Covering estimates and quadrature errors

In addition to the data being bounded, we also require the training set to sufficiently cover the entire data space. As a consequence of compactness of
\mathcal{X}
in Assumption
4.3
, given any
\epsilon_{s}>0
, we can find a positive integer
J:=J(\epsilon_{s})
such that
\mathcal{X}
possesses a
\epsilon_{s}
-net with
J
elements. In particular, there exists a set
W:=\{(f_{j},\theta_{j},\eta_{j})\}_{j=1}^{J}\subset\mathcal{X}
such that for any
(f,\theta,\eta)\in\mathcal{X}

\|f-f_{j}\|_{L^{2}(\Omega)}<\epsilon_{s},\quad\|\theta-\theta_{j}\|_{L^{2}(\Omega)}<\epsilon_{s},\quad\|\eta-\eta_{j}\|_{L^{2}(\Gamma_{\eta})}<\epsilon_{s}\quad\text{for some }1\leq j\leq J.

(4.21)

We make the following assumption about the training dataset.

Assumption 4.5
.

Assuming
\mathcal{X}
to be compact and given
\epsilon_{s}>0
, let
W\subset\mathcal{X}
be with
J
elements such that (
4.21
) holds. We assume that the training set
\mathbb{S}
is generated using such an
\epsilon_{s}
-net
W
.

Next, we need suitable conditions on the sensor nodes to allow us to bound the norm of the input vectors of the
VarMiON
with the corresponding
L^{2}
norms.

Assumption 4.6
.

The sensor nodes
\{{\widehat{\bm{x}}}_{i}\}_{i=1}^{k}
and
\{{\widehat{\bm{x}}}^{b}_{i}\}_{i=1}^{k^{\prime}}
are chosen to be suitable quadrature nodes to approximate the square integrals of
g:\Omega\rightarrow\mathbb{R}
and
g_{b}:\Gamma_{\eta}\rightarrow\mathbb{R}
as

\left|\sum_{i=1}^{k}{\widehat{w}}_{i}g^{2}({\widehat{\bm{x}}}_{i})-\int_{\Omega}g^{2}({\bm{x}})\text{d}{\bm{x}}\right|\leq\frac{{\widehat{{\mathcal{C}}}}_{Q}(g)}{k^{\alpha}},\quad\left|\sum_{i=1}^{k^{\prime}}{\widehat{w}}^{b}_{i}g_{b}^{2}({\widehat{\bm{x}}}^{b}_{i})-\int_{\Gamma_{\eta}}g_{b}^{2}({\bm{x}})\text{d}{\bm{x}}\right|\leq\frac{{\widehat{{\mathcal{C}}}}_{b,Q}(g_{b})}{{(k^{\prime})}^{\alpha^{\prime}}},

(4.22)

where
\{{\widehat{w}}_{i}\}_{i=1}^{k}
and
\{{\widehat{w}}^{b}_{i}\}_{i=1}^{k^{\prime}}
are the quadrature weights. Further, the weights are assumed to be positive.

As a consequence of Assumption
4.6
the following estimates hold:

Lemma 4.3
.

Let
g:\Omega\rightarrow\mathbb{R}
,
g_{b}:\Gamma_{\eta}\rightarrow\mathbb{R}
, and the sensors be chosen according to Assumption
4.6
. Define the vector
{\widehat{\bm{G}}}=(g({\widehat{\bm{x}}}_{1}),\cdots g({\widehat{\bm{x}}}_{k}))^{\top}\in\mathbb{R}^{k}
,
{\widehat{\bm{G}_{b}}}=(g_{b}({\widehat{\bm{x}}}^{b}_{1}),\cdots g_{b}({\widehat{\bm{x}}}^{b}_{k^{\prime}}))^{\top}\in\mathbb{R}^{k^{\prime}}
, and the diagonal matrices
{\widehat{{\bm{W}}}}_{\frac{1}{2}}=\text{diag}(\sqrt{{\widehat{w}}_{1}},\cdots\sqrt{{\widehat{w}}_{k}})\in\mathbb{R}^{k\times k}
,
{\widehat{{\bm{W}}}}^{b}_{\frac{1}{2}}=\text{diag}(\sqrt{{\widehat{w}}^{b}_{1}},\cdots\sqrt{{\widehat{w}}^{b}_{k^{\prime}}})\in\mathbb{R}^{k^{\prime}\times k^{\prime}}
. Then

\|{\widehat{\bm{G}}}\|_{2}\leq\|{\widehat{{\bm{W}}}}^{-1}_{\frac{1}{2}}\|_{2}\left(\|g\|_{L^{2}(\Omega)}+\frac{\sqrt{{\widehat{{\mathcal{C}}}}_{Q}(g)}}{k^{\alpha/2}}\right),\quad\|{\widehat{\bm{G}}}_{b}\|_{2}\leq\|({\widehat{{\bm{W}}}}^{b}_{\frac{1}{2}})^{-1}\|_{2}\left(\|g_{b}\|_{L^{2}(\Gamma_{\eta})}+\frac{\sqrt{{\widehat{{\mathcal{C}}}}_{b,Q}(g_{b})}}{(k^{\prime})^{\alpha^{\prime}/2}}\right),

(4.23)

where
{\widehat{{\mathcal{C}}}}_{Q},{\widehat{{\mathcal{C}}}}_{b,Q},\alpha,\alpha^{\prime}
are as defined in Assumption
4.6
.

Proof.

Let us first focus on the square integral of
g
. Note that

\displaystyle\sum_{i=1}^{k}{\widehat{w}}_{i}g^{2}({\widehat{\bm{x}}}_{i})=\sum_{i=1}^{k}\left(\sqrt{{\widehat{w}}_{i}}g({\widehat{\bm{x}}}_{i})\right)^{2}=\|{\widehat{{\bm{W}}}}_{\frac{1}{2}}{\widehat{\bm{G}}}\|_{2}^{2}.

Then, using (

We make some remarks here:

•

The expression (

•

The quadrature errors can be reduced by either increasing the number of sensor and output nodes, or by using the nodes (and weights) corresponding to a higher-order quadrature.

•

We cannot in general hope for the

•

We have assumed that

5
Extension to nonlinear problems

In this section we describe the extension of the
VarMiON
to nonlinear partial differential equations. To fix ideas, we consider a time-independent nonlinear advection-diffusion-reaction equation with inhomogeneous source term and Dirichlet and Neumann boundary conditions. The problem is given by,

\displaystyle-\nabla\cdot(\theta\nabla u)+\bm{a}\cdot\nabla u+\rho u-f

\displaystyle=

\displaystyle 0,\mbox{ in }\Omega,

(5.1)

\displaystyle u

\displaystyle=

\displaystyle g,\mbox{ on }\Gamma_{g},

(5.2)

\displaystyle-\theta\nabla u\cdot\bm{n}

\displaystyle=

\displaystyle\eta,\mbox{ on }\Gamma_{\eta}.

(5.3)

Here
\theta,\bm{a}
, and
\rho
are the diffusion, advection and reaction coefficients and are allowed to be functions of
u
and the spatial coordinates. Further
f
is the forcing function,

\eta
is the prescribed Neumann data and
g
is the prescribed Dirichlet data. Note that
\overline{\Gamma_{\eta}\bigcup\Gamma_{g}}=\partial\Omega
.

The weak formulation of this PDE is given by: find
u\in\mathcal{V}\equiv H^{1}(\Omega)
, such that
\forall w\in\mathcal{V}
,

\displaystyle a(w,u)

\displaystyle=

\displaystyle(w,f)+(w,\eta)_{\Gamma_{\eta}}+(-\theta\nabla w\cdot\bm{n}+\beta w,g)_{\Gamma_{g}}.

(5.4)

Here
a(\cdot,\cdot)
is linear in its first argument and nonlinear in the second, and is defined as

\displaystyle a(w,u)\equiv(\nabla w,\theta\nabla u)+(w,\bm{a}\cdot\nabla{u}+\rho u)-(w,\theta\nabla u\cdot\bm{n})_{\Gamma_{g}}+(-\theta\nabla w\cdot\bm{n}+\beta w,u)_{\Gamma_{g}}.

(5.5)

Further,
\beta
is a numerical parameter. It is easily shown that the formulation above is consistent, and when the weighting function and trial solution spaces are approximated by their finite dimensional counterpart, it leads to a finite element solution that converges to the exact solution
[
1
]
. This formulation is often referred to as the weak imposition of Dirichlet boundary conditions.

Next, as in Section
2.1
, we approximate the space
\mathcal{V}
with its finite dimensional counterpart
\mathcal{V}^{h}
, which is spanned by a set of continuous basis functions
\{\phi_{i}({\bm{x}})\}_{i=1}^{q}
. Further expanding the weighting functions, the approximate solution and the approximate PDE data
(

) using this basis, and substituting this in (
5.4
), we arrive at,

\bm{r}(\bm{U})=\bm{M}\bm{F}+\widetilde{\bm{M}}\bm{N}+\breve{\bm{M}}\bm{G}.

(5.6)

Here
\bm{U},\bm{F},\bm{N}
and
\bm{G}\in\mathbb{R}^{q}
are the coefficients in the expansion of

and
g^{h}
, respectively. Further,
\bm{r}:\mathbb{R}^{q}\to\mathbb{R}^{q}
is given by,

\displaystyle r_{i}(\bm{U})\equiv a(\phi_{,}U_{j}\phi_{j}),\qquad 1\leq i,j\leq q.

(5.7)

The matrices
\bm{M}
and
\widetilde{\bm{M}}
are as defined in (
2.7
), and the matrix
\breve{\bm{M}}
is given by

\displaystyle\breve{M}_{ij}\equiv(-\theta\nabla\phi_{i}\cdot\bm{n}+\beta\phi_{i},\phi_{j})_{\Gamma_{g}},\qquad 1\leq i,j\leq q.

(5.8)

Note that due to dependence of
\theta
on

,

is a function of
\bm{U}
; however, for simplicity we ignore this dependence.

Assuming that ((

)) is solvable for

, we may write

u^{h}({\bm{x}})=(\bm{R}^{-1}(\bm{M}\bm{F}+\widetilde{\bm{M}}\bm{N}+\breve{\bm{M}}\bm{G}))^{T}{\bm{\Phi}},

(5.9)

where

solves for

in (

)
This suggests the form of the

shown in Figure

are evaluated at sensor nodes to construct the input vectors

Numerical results

In this section we compare the performance of the
VarMiON
with a vanilla DeepONet which consists of a branch and a trunk network. We note that the vanilla DeepONet only works with a single input function and so for the benchmark comparison we simply concatenate all the values of the input functions (
\theta
,
f
,
\eta
, etc) through a common fully-connected branch network. In contrast, as shown in Figure
1
, the architecture of the
VarMiON
is more nuanced. The precise architectures of the networks are shown in the Appendix. When comparing the performance of these networks we ensure that the number of network parameters in each is approximately the same (see Table
1
and
3
for precise values). We also ensure that the architecture of the network used for constructing the basis functions (often referred to as the trunk network) is identical.

We first consider the steady-state heat conduction problem as the prototypical linear elliptic PDE model. We demonstrate that the conclusions drawn from the numerical examples are broadly applicable by considering different sampling strategies for the input functions (spatially random and uniform sampling), different methods for generating basis functions (ReLU networks and radial basis functions (RBFs)), and operators with varying number of input functions (two in Section
6.1.1
and three in Section
6.1.2
). In each case, we observe that the
VarMiON
yields more accurate results than the vanilla DeepONet.

For the experiments using an RBF trunk, in Section
6.1.3
we also compare the results with those obtained using a MIONet architecture which was proposed in
[
14
]
to suitably handle multiple input functions. In a MIONet architecture, a separate branch is constructed for each input function. Hadamard products are performed between the outputs of each branch sub-network, which results in a final branch output vector of size equal to the latent dimension. The MIONet output is obtained by taking a dot product of this vector with the trunk output. Specific architectures of the MIONet are detailed in the Appendix. In numerous science and engineering applications, the amount of available training data is constrained. Given this, we also evaluate the performance of the networks as a function of the size of the training data set in Section
6.1.3
.

We end by designing a variationally mimetic architecture for the nonlinear regularized Eikonal equation with a varying source function in Section
6.2
. Here, we compare the performance of the vanilla DeepONet with both the VarMiON and the constrained VarMiON-c architectures as discussed in Section
5
.

Regularized eikonal equation

We consider the regularized eikonal equation which is useful in modeling wave propagation. It is given by

\displaystyle-0.01\Delta u({\bm{x}})+|\nabla u(x)|

\displaystyle=f({\bm{x}}),\quad

\displaystyle\forall\ {\bm{x}}\in\Omega,

(6.3)

\displaystyle u({\bm{x}})

\displaystyle=0,\quad

\displaystyle\forall\ {\bm{x}}\in\partial\Omega,

where
u({\bm{x}})
is interpreted as the minimal time required to travel from
{\bm{x}}
to the domain boundary
\partial\Omega

1/f
represents the speed of travel through the medium. Note that the eikonal equation (
6.3

\theta\equiv 0.01

\rho=0.0

\bm{a}=\nabla u(x)/|\nabla u(x)|

\Gamma_{g}=\partial\Omega

\{\phi_{i}({\bm{x}})\}_{i=1}^{q}

u^{h}({\bm{x}})=(\bm{R}^{-1}({\bm{M}}{\bm{F}}))^{\top}{\bm{\Phi}}.

(6.4)

We are interested in approximation the solution operator that maps
f
to
u

The domain
\Omega
is chosen as a unit square, while the source function
f

(0.1,2.0)

To train the operator networks,

Motivated by the performance of the operators with the linear PDE model in the previous section, and the solution features of the eikonal problem, we continue to use an RBF trunk. All networks use a latent dimension
p=100
but have different branch architectures. We recall the key properties of the weak form discussed in Section
5
which we are interested in mimicking:

•

The sampled input function needs to be compressed by a linear transform to a vector of dimension that equals the latent dimension
p
. Since the present problem has a single input function, i.e., the
sum
block shown in Figure
2

p=100
, irrespective of the input dimension (1024 in this case). One can argue that this leads to an architecture that is an instance of a DeepONet. However, in standard practice, one would construct the branch of a DeepONet to i) include a bias in every hidden layer, and ii) gradually decay the width of the hidden layers with increasing depth. This is what distinguishes a vanilla DeepONet from the proposed VarMiON architecture.

•

We want to preserve the homogeneous nature of the solution operator. This is achieved be considering the constrained VarMiON-c architecture (see Figure
2
(b)), but which also satisfies the above property of compressing the branch input vector to a
p
dimensional vector.

We consider a number of architectures for the eikonal problem, a summary of whose performance is given in Table
3

We also consider DeepONet architectures with a branch that compresses the input vector of size 1024 more gradually. Keeping the number of trainable parameters similar to the VarMiONs affords us a DeepONet branch with a single hidden layer of width 130. The error with this operator network is more than twice of the VarMiON networks. Increasing the hidden layer width to be 200 pulls down the mean error but at the cost of having more trainable parameters. We also look at the extreme case where the DeepONet branch has as many layers as the VarMiONs but with a gradually tapering down architecture, i.e., we consider four hidden layers with widths 512, 256, 128 and 100. With this DeepONet architecture, the error is brought down to the range of the VarMiONs. However, the number of parameters is five times that of the VarMiONs, which leads to larger training and evaluation times. These results indicate that using a branch whose first hidden layer compresses the input to a vector of size of the latent dimension leads to the optimal results, while also controlling the size of the network. 7
Conclusions

In this manuscript we have proposed a novel architecture for an operator network that maps input functions for agiven PDE, including forcing functions, boundary data and material property functions, to its solution. This architecture mimics the form of the numerical solution obtained by approximating the corresponding variational formulation of the PDE. For this reason we refer to this operator as the variationally mimetic operator network, or
VarMiON
. Like the conventional Deep Operator Network (DeepONet), the
VarMiON
can also be decomposed into branch and trunk networks, where the latter constructs the basis functions for representing the output, and the former generates the coefficients for this expansion. However, in contrast to a conventional DeepONet, the
VarMiON
prescribes a precise architecture for the branch network. In the linear PDE case considered in this manuscript, this involves linear branches for the forcing function and Neumann data vectors and a nonlinear branch for the material property vector that leads to a matrix of small dimension (say,
100\times 100
). The output of the branch network is obtained by summing the vectors of the linear branches and then computing the product of the material property matrix with the resulting vector. For the nonlinear PDE problem, variational formulation leads to distinct architecture, where the sum of the output of the linear branches (corresponding to forcing function and Neumann data) is fed to a nonlinear network. Furthermore, an extension of this architecture is also proposed (called VarMiON-c), in which the homogeneity constraint of the underlying solution operator is encoded in the architecture.

An analysis of the error in the solution generated by this network reveals several important contributions. These include, the training error, error in the solutions used to train the network, quadrature error in sampling the input and output functions during training, and the distance between the test input functions and the “closest” functions in the training dataset. This last component is multiplied by the sum of the stability constants for the true and the
VarMiON
operators. This clear delineation of errors provides the user with a systematic approach to thinking about the performance of
VarMiON
. Further, the special structure of the
VarMiON
allows the identification of the precise operators responsible for these properties.

The application of the
VarMiON
to a canonical linear elliptic PDE and generic nonlinear PDE reveals several interesting results. First, for approximately the same number of network parameters, on average the
VarMiON
incurs smaller error than a vanilla DeepONet and MIONet. Second, across large instances of test functions the distribution of this error for the
VarMiON
is much tighter, thereby indicating that it is more robust to variations in input data. Third, we recognize that this performance is robust to techniques used to sampling the input functions (random or regular), to different basis functions (ReLU or radial basis functions) and to the number of inputs functions (two or three). Finally, VarMiON performs consistently better than baseline methods at various sizes of training datasets.

There are several directions for future work that emerge from this work. These include the application of the
VarMiON
as a surrogate model for problems in optimization and uncertainty quantification.
In the solution to these problems many solutions of the forward problem are required, and the
VarMiON
can be used to compute these quickly and accurately.
Extending the VarMiON architecture to solve other challenging nonlinear PDE models, and developing the associated theoretical framework to estimate the approximation error would be a fruitful endeavor. While we believe that the philosophy of mimicking the weak form will carry over, the precise architecture of the VarMiON may greatly differ depending on the weak formulation of the PDE model.
In a similar vein, the ideas developed in this manuscript may be extended to time-dependent and hyperbolic PDEs, where the
VarMiON
architecture could be applied to solve a series of linear problems. These, and related ideas, will be explored in future work.
