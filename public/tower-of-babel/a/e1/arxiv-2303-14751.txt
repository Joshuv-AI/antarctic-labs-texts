Matrix-Scaled Consensus over Undirected Networks
Minh Hoang Trinh, Hoang Huy Vu, Nhat-Minh Le-Phan, Quyen Ngoc Nguyen

Abstract
In this paper, we propose matrix-scaled consensus algorithms for linear dynamical agents interacting over an undirected network. Under the proposed algorithms, the state vectors of all agents to asymptotically agree up to some matrix scaling weights. First, the algebraic properties of the matrix-scaled Laplacian and the geometry of the matrix-scaled consensus space are studied. Second, we examine matrix-scaled consensus algorithms for networks of single-integrators with or without constant parametric uncertainties. Nonlinear and finite-time matrix-scaled consensus algorithms are also proposed. Third, observer-based matrix-scaled consensus algorithms for homogeneous or heterogeneous linear-time invariant agents are designed. The convergence of the proposed algorithms is asserted by rigorous mathematical analysis and supported by numerical simulations.

Introduction

Collective behaviors displayed in nature such as bird flocking, fish schooling, synchronous fireflies, have inspired a lot of research works. Though simple, the consensus algorithm has been widely used for modeling and studying such striking phenomena
[
1
]
. It is interesting that a lot of multiagent systems such as autonomous vehicle formations, electrical system, sensor networks, or social networks can be coordinated by appropriately applying consensus algorithms and its modifications

Consider a network in which the interactions between subsystems, or agents, is modeled by a graph. In the consensus algorithm, each agent updates its state based on the sum of the relative states with its nearby agents. If the interaction graph is connected, the agents’ states asymptotically converge to a common point in the space, and the system is said to asymptotically achieve a consensus
[
1
]

A (scalar) scaled consensus model was proposed in
[
4
]
, in which each agent has a nonzero scalar scaling gain and updates its state variable based on the sum of differences in the scaled states. Under the scaled consensus model, the scaled states of all agents agree to the same virtual consensus value, and the state variable of each agent converges to a value differing from the virtual consensus value by an inverse of the scaling gain. Thus, if each agent is characterized by a
d
-dimensional state vector, the state vectors of the agents asymptotically converges to a straight line through the origin under the scalar scaled consensus algorithm
[
4
]
. The scaled consensus system can describe a cooperative network, where agents have different levels of consensus on a single topic. Further studies of the scalar scaled consensus algorithm with consideration to switching or signed graphs
[
5
,
6
]
, time delays
[
7
,
8
]
, disturbance rejection
[
9
]
, or different agents’ models can be found in the literature
[

,
11
]
.

Matrix-scaled consensus (MSC), a multi-dimensional generalization of the scaled consensus model in
[
4
]
, has been recently proposed in
[
12
]
. Under the MSC algorithm, each agent is associated with a positive/negative definite scaling matrix, and the matrix-scaled states of all agents eventually agree to a virtual consensus point. The state vector of each agent asymptotically converges to a point, which can be obtained from the virtual consensus point by a linear transformation determined by the inverse of its scaling matrix. Thus, clustering behaviors usually happen due to the homogeneity of the scaling matrices.
Several studies, e.g., MSC algorithms with state constraints
[
13
]
, resilient protocols
[
14
]
, some uncertain dynamics
[
15

16
]
, or for double-integrator without velocity measurements
[

have been recently proposed.

In this paper, we firstly characterize the geometry of the matrix-scaled consensus space and the algebraic properties of the matrix scaled Laplacian. Second, we study matrix-scaled consensus algorithm for a network of single integrators interacting over an undirected network. Besides revisiting the basic algorithm in
[
12
]
, we also consider nonlinear MSC algorithms and providing a corresponding Lyapunov-based analysis. Third, we study the MSC algorithm for a system of single integrators with parametric uncertainties. An adaptive scheme is developed, which guarantees the system to eventually achieve matrix-scaled consensus. If in addition, a persistently exciting condition is satisfied, the estimate variables eventually converge to the precise parameters. Fourth, we consider a network of homogeneous linear agents and propose an observer-based matrix-scaled consensus algorithm. It is shown that the agents asymptotically achieve matrix-scaled consensus with regard to a trajectory of a virtual agent. If we specify the agents to be linear oscillators in 2D, and the scaling matrices to be a composition of rotation and expansion/compression matrices, the asymptotic biases in phase and magnitude of each agent’s trajectory with a common oscillator can be determined by the scaling matrices. Finally, as practical networks often consists of agents with different sizes and capacities, we propose a matrix-scaled consensus algorithm for a network of heterogeneous linear agents. The proposed algorithm combines the corresponding MSC algorithm for homogeneous linear agents with a disturbance observer which compensates the differences between each agent’s model and a pre-specified one. The main challenges and differences in the analysis of our proposed algorithms with regard to the existing consensus algorithms for general linear agents in the literature, e.g.,

As a generalization of the scaled consensus algorithm, the MSC algorithm can replace scaled consensus in any application that scaled consensus are being used. First, the algorithm can be used as a biased resource allocation algorithm. Second, in
[
12
]
, the MSC was interpreted as a multi-dimensional model opinion dynamics
[

In this paper, we further demonstrate how to design the MSC space for generating a desired shape, thus, extent the applicability of the MSC algorithm to formation control

Matrix-scaled consensus algorithms for single-integrator agents

IV-A

Matrix-scaled consensus of single-integrators

We firstly consider the ideal case, where agents are modeled by single integrators. The matrix-scaled consensus algorithm is proposed for each agent
i=1,\ldots,n
as follows

\displaystyle\dot{\mathbf{x}}_{i}

\displaystyle=\mathbf{u}_{i}=-\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}\mathbf{x}_{i}-\mathbf{S}_{j}\mathbf{x}_{j}).

(9)

The
n
-agent system can be expressed in the matrix form as follows:

\displaystyle\dot{\mathbf{x}}=-(\text{sign}(\mathbf{S})\mathbf{L}\otimes\mathbf{I}_{d})\mathbf{S}\mathbf{x}=-\bm{\Omega}\mathbf{x}.

(10)

The asymptotic behavior of the system (
9

[
12
]
.

Theorem IV.1

[
12
]
Under the MSC algorithm (
9
),
\mathbf{x}(t)
exponentially converges to
\mathbf{S}^{-1}(\mathbf{1}_{n}\otimes\mathbf{x}_{0})\in\mathcal{C}_{S}
, where
\mathbf{x}_{0}:=\mathbf{P}(\mathbf{1}_{n}^{\top}\text{sign}(\mathbf{S})\otimes\mathbf{I}_{d})\mathbf{x}(t)=\mathbf{P}\sum_{i=1}^{n}\text{sign}(\mathbf{S}_{i})\mathbf{x}_{i}(0)
is a virtual consensus point.

Remark IV.1

Note that the proof that
\lim_{t\to+\infty}\mathbf{x}(t)=\mathbf{S}\mathbf{x}_{{0}}
can also be shown by considering the Lyapunov candidate function
V=\mathbf{x}^{\top}\mathbf{S}^{\top}\bar{\mathbf{L}}\mathbf{S}\mathbf{x}
.

Remark IV.2

In the MSC algorithm (
9
), each agent needs
d^{2}
multiplications and
d(d-1)
additions to obtain
\mathbf{S}_{i}\mathbf{x}_{i}
. Then,
|\mathcal{N}_{i}|d
additions and
d
multiplications are additionally required to determine the input
\mathbf{u}_{i}
. In sparse network (each vertex does not have a lot of neighbors), the complexity of the MSC algorithm for each agent is
\mathcal{O}(d^{2})
(polynomial complexity), and for the whole system is
\mathcal{O}(nd^{2})
. Note that the MSC algorithm (
9

scalable
with regard to network size, i.e., the complexity of the algorithm does not increases for each agent as the size of the network grows.

The next theorem expands the class of interaction functions which can be used in a MSC algorithm.

Theorem IV.2

Let

Consider the following nonlinear MSC algorithm

\displaystyle{\mathbf{u}}_{i}=-\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}\mathbf{f}(\mathbf{S}_{i}\mathbf{x}_{i}-\mathbf{S}_{j}\mathbf{x}_{j}),~i=1,\ldots,n.

(11)

Proof:

The matrix-scaled consensus system with generalized interaction (
11

(12)

For stability analysis, let

\displaystyle=-\mathbf{f}(\bar{\mathbf{H}}\mathbf{S}\mathbf{x})^{\top}\bar{\mathbf{W}}\bar{\mathbf{H}}|\mathbf{S}|\bar{\mathbf{H}}^{\top}\bar{\mathbf{W}}\mathbf{f}(\bar{\mathbf{H}}\mathbf{S}\mathbf{x})

\displaystyle=(\mathbf{1}_{n}^{\top}\text{sign}(\mathbf{S}))\otimes\mathbf{I}_{d})(\mathbf{I}_{n}\otimes\mathbf{A}-c\bm{\Omega})\mathbf{V}\mathbf{y}=\mathbf{A}\mathbf{y}_{[1:d]},

\displaystyle\dot{\mathbf{y}}_{[d+1:dn]}

\displaystyle=\underbrace{\left(\mathbf{Z}_{[d+1:dn]}^{\top}(\mathbf{I}_{n}\otimes\mathbf{A})\mathbf{V}_{[d+1:dn]}-c\bm{\Omega}^{\prime}\right)}_{:=\bm{\Omega}_{c}}\mathbf{y}_{[d+1:dn]}.

We have the following theorem on the system (
20
):

Theorem V.1

Let
\mathbf{Q}=\mathbf{Q}^{\top}>0
be the unique solution of the Lyapunov equation
\mathbf{Q}{\bm{\Omega}^{\prime}}+(\bm{\Omega}^{\prime})^{\top}\mathbf{Q}=\mathbf{I}_{d(n-1)}
and
c>2\|\mathbf{A}\|\lambda_{\max}(\mathbf{Q})
. Then,
\mathbf{x}(t)\to\mathcal{C}_{S}
, as
t\to+\infty
.

Proof:

We have
\|\mathbf{Z}_{[d+1:dn]}^{\top}(\mathbf{I}_{n}\otimes\mathbf{A})\mathbf{V}_{[d+1:dn]}\|\leq\|\mathbf{V}^{-1}(\mathbf{I}_{n}\otimes\mathbf{A})\mathbf{V}\|=\|\mathbf{I}_{n}\otimes\mathbf{A}\|=\|\mathbf{A}\|
. Based on Lemma
V.1
, the matrix
\bm{\Omega}_{c}
is Hurwitz. It follows that
\mathbf{y}_{[d+1:dn]}
globally exponentially converges to
\mathbf{0}_{d(n-1)}
. The solution of Eqn. (
20
) is

\displaystyle\mathbf{x}(t)=\mathbf{V}\mathbf{y}(t)

\displaystyle=\mathbf{V}\text{blkdiag}(\text{exp}(\mathbf{A}t),\text{exp}(\bm{\Omega}_{c}t))\mathbf{y}(0)

\displaystyle=\mathbf{S}^{-1}(\mathbf{1}_{n}\otimes\mathbf{P})\text{exp}(\mathbf{A}t)(\mathbf{1}_{n}^{\top}\text{sign}(\mathbf{S})\otimes\mathbf{I}_{d})\mathbf{x}(0)+\bm{\xi}(t),

where
\bm{\xi}(t)=\mathbf{V}_{[d+1:dn]}\text{exp}(\bm{\Omega}_{c}t)\mathbf{Z}_{[d+1:dn]}^{\top}\mathbf{x}(0)\to\mathbf{0}_{dn}
exponentially fast. Thus,

\lim_{t\to+\infty}(\mathbf{x}_{i}(t)-\mathbf{S}_{i}^{-1}\mathbf{P}\text{exp}(\mathbf{A}t)\mathbf{P}^{-1}\mathbf{x}_{{0}})=\mathbf{0}_{d},~\forall i=1,\ldots,n,

or
\mathbf{x}(t)\to\mathcal{C}_{S}
, as
t\to+\infty
.
∎

c_{i}(t)
with

n
-agent system

\displaystyle\dot{\mathbf{x}}

\displaystyle=(\mathbf{I}_{n}\otimes\mathbf{A}-\bar{\mathbf{C}}\bm{\Omega})\mathbf{x},

(21a)

\displaystyle\dot{c}_{i}

\displaystyle=\kappa_{i}\bm{\chi}_{i}^{\top}|\mathbf{S}_{i}|\bm{\chi}_{i},\,c_{i}(0)>0,~\forall i=1,\ldots,n,

(21b)

\displaystyle\bm{\chi}_{i}

\displaystyle=\text{exp}(-\mathbf{A}(t-t_{0}))\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}\mathbf{x}_{i}-\mathbf{S}_{j}\mathbf{x}_{j}),

(21c)

\mathbf{S}_{i}
commutes with
\mathbf{A}

Theorem V.2

Suppose that the matrices
\mathbf{S}_{i},~i=1,\ldots,n,
commutes with
\mathbf{A}
, then under the adaptive MSC algorithm (

\mathbf{x}(t)\to\mathcal{C}_{S}

Simplified heterogeneous linear agents with unknown system matrix and full control input

In this subsection, we design an adaptive matrix-scaled consensus law for a network of heterogeneous linear dynamics with full control input

\dot{\mathbf{x}}_{i}=\mathbf{A}_{i}\mathbf{x}_{i}+\mathbf{u}_{i},\,i=1,\ldots,n,

(22)

where
\mathbf{A}_{i}\in\mathbb{R}^{d\times d}
is unknown to each agent
i
. Let
\mathbf{A}_{i}=\mathbf{A}+(\mathbf{A}_{i}-\mathbf{A})=\mathbf{A}+\bar{\mathbf{A}}_{i}
, where
\mathbf{A}
is a pre-selected matrix such that
\mathbf{W}_{d+1:dn}^{\top}\otimes\mathbf{A}\mathbf{V}_{[d+1:dn]}-c\bm{\Omega}^{\prime}
is Hurwitz.

Let the
k
-th row of the matrix
\bar{\mathbf{A}}_{i}
be denoted by
\bar{\mathbf{A}}_{ik}
, we have the representation
[
24
]
:

\bar{\mathbf{A}}_{i}\mathbf{x}_{i}=\begin{bmatrix}\bar{\mathbf{A}}_{i1}^{\top}\mathbf{x}_{i}\\
\vdots\\
\bar{\mathbf{A}}_{in}^{\top}\mathbf{x}_{i}\end{bmatrix}=\begin{bmatrix}\mathbf{x}_{i}^{\top}\bar{\mathbf{A}}_{i1}\\
\vdots\\
\mathbf{x}_{i}^{\top}\bar{\mathbf{A}}_{id}\end{bmatrix}=(\mathbf{I}_{d}\otimes\mathbf{x}_{i}^{\top})\text{vec}(\bar{\mathbf{A}}_{i}).

By setting
\bm{\phi}_{i}:=\mathbf{I}_{d}\otimes\mathbf{x}_{i}^{\top}\in\mathbb{R}^{d\times d^{2}}
and
\bm{\theta}_{i}:=\text{vec}(\bar{\mathbf{A}}_{i})
, the linear time-invariant model (
22
) is transformed into the single-integrator with uncertain parameters (
1
).

The system achieves MSC if the uncertainty is being compensated faster than the evolution of
\|\mathbf{x}\|
(exponential rate). The following MSC algorithm is proposed

\displaystyle\dot{\mathbf{z}}_{i}

\displaystyle=\mathbf{A}\mathbf{x}_{i}-c\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}\mathbf{x}_{i}-\mathbf{S}_{j}\mathbf{x}_{j}),

(23a)

\displaystyle\mathbf{u}_{i}

\displaystyle=-c\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}\mathbf{x}_{i}-\mathbf{S}_{j}\mathbf{x}_{j})+\beta_{1}\text{sgn}(\mathbf{e}_{i})+\beta_{2}\text{diag}(\text{sgn}(\mathbf{e}_{i}))(\mathbf{I}_{d}\otimes|\mathbf{x}_{i}|^{\top})\mathbf{1}_{d^{2}},

(23b)

where
|\mathbf{x}_{i}|:=[|x_{i1}|,\ldots,|x_{id}|]^{\top}
,
\mathbf{e}_{i}={\mathbf{z}}_{i}-\mathbf{x}_{i},

\beta_{1},\beta_{2}>0
are control gains, and sgn
(\cdot)
denotes the signum function. The following theorem will be proved.

Theorem V.3

Let
\mathcal{G}
be connected and
\beta_{2}\geq\max_{i=1,\ldots,n}\|\text{vec}(\mathbf{\bar{A}}_{i})\|_{\infty}
. Under the algorithm (
23
),
\mathbf{x}(t)\to\mathcal{C}_{S}
as
t\to+\infty
.

Proof:

We have

\displaystyle\dot{\mathbf{e}}_{i}

\displaystyle=\bar{\mathbf{A}}_{i}\mathbf{x}_{i}-\beta_{1}\text{sgn}(\mathbf{e}_{i})-\beta_{2}\text{sgn}(\mathbf{e}_{i})(|\mathbf{x}_{i}|^{\top}\otimes\mathbf{I}_{d})\mathbf{1}_{d^{2}}

\displaystyle=-\beta_{1}\text{sgn}(\mathbf{e}_{i})+\bm{\phi}_{i}(t)\bm{\theta}_{i}-\beta_{2}\text{diag}(\text{sgn}(\mathbf{e}_{i}))(\mathbf{I}_{d}\otimes|\mathbf{x}_{i}|^{\top})\mathbf{1}_{d^{2}}

As the right-hand side of the above equation is discontinuous, the solution of
\mathbf{e}_{i}
is understood in Filippov sense. Using the Lyapunov function
V=\frac{1}{2}\|\mathbf{e}_{i}\|^{2}
, we have

\displaystyle\dot{V}

\displaystyle\in^{\text{a.e.}}\tilde{V}=\bigcap_{\bm{\nu}\in\partial V}\bm{\nu}^{\top}K[\dot{\mathbf{e}}_{i}]

\displaystyle=\mathbf{e}_{i}^{\top}\Big(-\beta_{1}\text{sgn}(\mathbf{e}_{i})+\bm{\phi}_{i}(t)\bm{\theta}_{i}-\beta_{2}\text{diag}(\text{sgn}(\mathbf{e}_{i}))(|\mathbf{x}_{i}|^{\top}\otimes\mathbf{I}_{d})\mathbf{1}_{d^{2}}\Big)

\displaystyle\leq-\beta\|\mathbf{e}_{i}\|_{1}-\beta_{2}\sum_{k=1}^{d}|\mathbf{e}_{ik}|\|\mathbf{x}_{i}\|_{1}+\sum_{k=1}^{d}|\mathbf{e}_{ik}|\|\mathbf{x}_{i}\|_{1}\|\bm{\theta}_{i}\|_{\infty}

\displaystyle\leq-\beta\|\mathbf{e}_{i}\|_{1}

\displaystyle\leq-\epsilon V^{1/2},

(24)

for
\epsilon=\beta\sqrt{2}
, and this implies that
V(t)\to 0
in finite time
[
38
]
. Therefore, there exists
T>0
such that
\mathbf{e}_{i}=\mathbf{0}_{d}
or
\mathbf{x}_{i}=\mathbf{z}_{i}
for
t\geq T
. For
t\geq T
,
\mathbf{x}_{i}
can be considered to be governed by the simplified homogeneous linear agent (
20
). Thus,
\mathbf{x}\to\mathcal{C}_{S}
as
t\to+\infty
.
∎

Homogeneous general linear agents

In this subsection, we consider the
n
-agent system with identical general linear model (
2
). The following observer-based matrix-scaled consensus algorithm is proposed

\displaystyle\dot{\hat{\mathbf{x}}}_{i}=\mathbf{A}\hat{\mathbf{x}}_{i}+\mathbf{B}\mathbf{u}_{i}+\mathbf{H}(\mathbf{C}{\hat{\mathbf{x}}}_{i}-\mathbf{y}_{i}),

(25a)

\displaystyle\dot{\bm{\eta}}_{i}=\mathbf{A}{\bm{\eta}}_{i}+\mathbf{B}\mathbf{u}_{i}+\mathbf{H}(\mathbf{C}{\hat{\mathbf{x}}}_{i}-\mathbf{y}_{i})+c\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}(\hat{\mathbf{x}}_{i}-\bm{\eta}_{i}){-}\mathbf{S}_{j}(\hat{\mathbf{x}}_{j}-\bm{\eta}_{j})),

(25b)

\displaystyle\mathbf{u}_{i}=\mathbf{K}\bm{\eta}_{i},\,i=1,\ldots,n,

(25c)

where the matrices
\mathbf{H}
and
\mathbf{K}
are designed so that
\mathbf{A}+\mathbf{H}\mathbf{C}
and
\mathbf{A}+\mathbf{B}\mathbf{K}
are Hurwitz, and
c>0
is a coupling gain.

In the proposed algorithm, (
25a
) is a Luenberger observer which estimates the state
\mathbf{x}
. The MSC algorithm is conducted via the auxiliary state variables
{\bm{\zeta}}_{i}=\hat{\mathbf{x}}_{i}-\bm{\eta}_{i}
. It is worth noting that
c\text{sign}(\mathbf{S}_{i})(\mathbf{S}_{i}(\hat{\mathbf{x}}_{i}-\bm{\eta}_{i}){-}\mathbf{S}_{j}(\hat{\mathbf{x}}_{j}-\bm{\eta}_{j}))=c\text{sign}(\mathbf{S}_{i})(\mathbf{S}_{i}\bm{\zeta}_{i}-\mathbf{S}_{j}\bm{\zeta}_{j})
acts as a proportional control input to make
\bm{\zeta}_{i}
converge to
\mathcal{C}_{S}
. When the coupling gain
c
is sufficiently large, it becomes a high-gain controller and the matrix-scaled variables
\mathbf{S}_{i}\bm{\zeta}_{i}(t)
are forced to a solution of the system
{\dot{\bar{\bm{\zeta}}}=\mathbf{P}\mathbf{A}\mathbf{P}^{-1}{\bar{\bm{\zeta}}}}
. Finally, by forcing
\mathbf{\bm{\eta}}
converge to
\mathbf{0}_{dn}
under the control law (
25c
),
\mathbf{x}\to\mathcal{C}_{S}
as
t\to+\infty
.

For stability analysis, from Eqn. (
25
), we can write

\displaystyle\dot{\tilde{\mathbf{x}}}_{i}

\displaystyle=(\mathbf{A}+\mathbf{H}\mathbf{C}){\tilde{\mathbf{x}}}_{i},

(26a)

\displaystyle\dot{\bm{\zeta}}_{i}

\displaystyle=\mathbf{A}{\bm{\zeta}}_{i}-c\text{sign}(\mathbf{S}_{i})\sum_{j\in\mathcal{N}_{i}}{w_{ij}}(\mathbf{S}_{i}\bm{\zeta}_{i}-\mathbf{S}_{j}\bm{\zeta}_{j}),

(26b)

where
i=1,\ldots,n,
and
\tilde{\mathbf{x}}_{i}=\hat{\mathbf{x}}_{i}-\mathbf{x}_{i}
. Denoting
\bm{{\tilde{\mathbf{x}}}}=\text{vec}({\tilde{\mathbf{x}}}_{1},\ldots,{\tilde{\mathbf{x}}}_{n})
,
{\bm{\zeta}}=\text{vec}({\bm{\zeta}}_{1},\ldots,{\bm{\zeta}}_{n})
, and
{\bm{\eta}}=\text{vec}({\bm{\eta}}_{1},\ldots,{\bm{\eta}}_{n})
, we will prove a theorem regarding the following system

\displaystyle\dot{\tilde{\mathbf{x}}}

\displaystyle=\mathbf{I}_{n}\otimes(\mathbf{A}+\mathbf{H}\mathbf{C})\tilde{\mathbf{x}},

(27a)

\displaystyle\dot{\bm{\zeta}}

\displaystyle=(\mathbf{I}_{n}\otimes\mathbf{A}-c\bm{\Omega}){\bm{\zeta}},

(27b)

\displaystyle\dot{\bm{\eta}}

\displaystyle=(\mathbf{I}_{n}\otimes(\mathbf{A}+\mathbf{B}\mathbf{K})){\bm{\eta}}+c(\mathbf{I}_{n}\otimes(\mathbf{H}\mathbf{C}))\tilde{\mathbf{x}}+\bm{\Omega}{\bm{\zeta}}.

(27c)

Theorem V.4

Let
\mathbf{H},\mathbf{K}
be designed so that
\mathbf{A}+\mathbf{H}\mathbf{C}
and
\mathbf{A}+\mathbf{B}\mathbf{K}
are Hurwitz, and the control gain
c
is chosen so that
\bm{\Theta}_{c}=\mathbf{Z}_{[d+1:dn]}^{\top}(\mathbf{I}_{n}\otimes\mathbf{A})\mathbf{V}_{[d+1:dn]}-c\bm{\Omega}^{\prime}
is Hurwitz. Under the algorithm (
25
),
\mathbf{x}(t)\to\mathcal{C}_{S}
as
t\to+\infty
. More specifically,
\mathbf{S}_{i}\mathbf{x}_{i}(t),~i=1,\ldots,n,
asymptotically converge to a common solution of
{\dot{\bar{\bm{\zeta}}}=\mathbf{P}\mathbf{A}\mathbf{P}^{-1}{\bar{\bm{\zeta}}}}
.

Proof:

(i) Because
\mathbf{A}+\mathbf{H}\mathbf{C}
is Hurwitz,
{\tilde{\mathbf{x}}}
converges to
\mathbf{0}_{dn}
exponentially fast.

(ii) It follows from Thm.
V.1
that
\bm{\zeta}(t)
exponentially converges to
\mathcal{C}_{S}
. More specifically,

\lim_{t\to+\infty}(\bm{\zeta}_{i}(t)-\mathbf{S}_{i}^{-1}\mathbf{P}\text{exp}(\mathbf{A}t)\mathbf{P}^{-1}\bm{\zeta}_{{0}})=\mathbf{0}_{d},~\forall i=1,\ldots,n,

where

\bm{\zeta}_{{0}}=(\mathbf{1}_{n}^{\top}\text{sign}(\mathbf{S})\otimes\mathbf{P})\bm{\zeta}(0)=\mathbf{P}\sum_{i=1}^{n}\text{sign}(\mathbf{S}_{i})\bm{\zeta}_{i}(0).

(iii) Consider equation (
27c
) with
\tilde{\mathbf{x}}=\mathbf{0}_{dn}
and
\bm{\zeta}\in\mathcal{C}_{S}
, we have the unforced system

\dot{\bm{\eta}}=(\mathbf{I}_{n}\otimes(\mathbf{A}+\mathbf{B}\mathbf{K}))\bm{\eta}.

Because
\mathbf{A}+\mathbf{B}\mathbf{K}
is Hurwitz, the unforced system is globally exponentially stable, and (
27c
) is input-to-state stable
[
35
]
. As the external input
(\mathbf{I}_{n}\otimes(\mathbf{H}\mathbf{C}))\tilde{\mathbf{x}}+\bm{\Omega}{\bm{\zeta}}
converges to
\mathbf{0}_{dn}
exponentially fast according to (i) and (ii),
{\bm{\eta}}\to\mathbf{0}_{dn}
exponentially fast.

(iv) Finally, as
\bm{\zeta}=\hat{\mathbf{x}}-\bm{\eta}=\mathbf{x}-\tilde{\mathbf{x}}-\bm{\eta}
,

\lim_{t\to+\infty}\bm{\eta}(t)=\lim_{t\to+\infty}\tilde{\mathbf{x}}(t)=\mathbf{0}_{dn},

it follows that

\lim_{t\to+\infty}(\mathbf{x}_{i}(t)-\mathbf{S}_{i}^{-1}\mathbf{P}\text{exp}(\mathbf{A}t)\mathbf{P}^{-1}\bm{\zeta}_{{0}})=\mathbf{0}_{d},

for all
i=1,\ldots,n.

Thus, we conclude that
\mathbf{x}(t)\to\mathcal{C}_{S}
, as
t\to+\infty
, and the convergence rate is exponential.

Remark V.1

We have introduced a novel approach to dealing with heterogeneous dynamics by fast compensating the heterogeneity using the help of a sliding-mode control input. By this way, the MSC algorithm can be designed as for identical linear systems after some finite time and an exact MSC can be exponentially achieved. It is hard to perfectly realize the proposed algorithm (
28
) because of the signum function. Also, using a nonsmooth algorithm may reduce the durability of each agent, especially when the gap between pre-selected and the agent’s matrices,
\|\mathbf{A}_{i}-\mathbf{A}\|
, are significant. As far as we know, the approach has not been proposed in the literature.

VII
Conclusions

In this paper, several matrix-scaled consensus algorithms were designed for single-integrators and linear time-invariant agents interacting over an undirected network. The asymptotic behaviors of the proposed algorithms associate with the algebraic properties of the matrix-scaled Laplacian. The main challenges in the stability analysis comes from the asymmetry and multi-dimensionality of the matrix-scaled Laplacian. The matrix-scaled consensus space has been characterized in detail in case
d=2
, which allows these algorithms to be applicable in formation control. Simulation results have also been extensively provided to demonstrate the algorithm. For a simulation of the MSC algorithm over a large-scale network, we refer readers to
[
39
]
.

As the study of the matrix-scaled consensus algorithm in this paper only focused on undirected graphs, our further work will focus on studying the matrix-scaled consensus algorithm with directed or signed graphs.

Appendix B
Proof of Lemma
V.1

Let
\bm{\Omega}_{c}=-c\bm{\Omega}^{\prime}+\bm{\Delta}_{\Omega}
, and consider the dynamical system

\displaystyle\dot{\mathbf{x}}=\bm{\Omega}_{c}\mathbf{x}=(-c\bm{\Omega}^{\prime}+\bm{\Delta}_{\Omega})\mathbf{x}.

Consider the Lyapunov function
V=\mathbf{x}^{\top}\mathbf{Q}\mathbf{x}
, we have,
\dot{V}=\mathbf{x}^{\top}(\mathbf{Q}\bm{\Omega}_{c}+\bm{\Omega}_{c}^{\top}\mathbf{Q})\mathbf{x}=-c\|\mathbf{x}\|^{2}+2\mathbf{x}^{\top}\mathbf{Q}\bm{\Delta}_{\Omega}\mathbf{x}\leq-(c-2\|\mathbf{Q}\|\|\bm{\Delta}_{\Omega}\|)\|\mathbf{x}\|^{2}\leq-(c-2{\delta}_{\Omega}\lambda_{\max}(\mathbf{Q}))\lambda_{\min}^{-1}(\mathbf{Q})V.

Thus,
\mathbf{x}(t)
is globally exponentially stable. Equivalently, the matrix
\bm{\Omega}_{c}
is Hurwitz.
\blacksquare
