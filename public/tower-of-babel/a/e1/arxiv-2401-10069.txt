Pre-orders and filtrations

Let
C

\leq
on
C

\left(C,\leq\right)

The following claims are easy to prove and also are not hard to find in internet:

Lemma 2.1
.

1.

There is an equivalence relation on
C

c_{1}\sim c_{2}
iff
c_{1}\leq c_{2}
and
c_{2}\leq c_{1}.
Let
\pi:C\longrightarrow C/\sim
be the canonical induced suprajective function, and let us denote
\pi(c)=\overline{c}.
Then
C/\sim
has a canonical partial order given by
\overline{c_{1}}\leq\overline{c_{2}}
iff
c_{1}\leq c_{2}.
(See section 2.1 of
[
4
]
)

2.

By the order-extension principle,
[
7
]
, there is a total order (a linearization)
\preceq
on
C/\sim
that extends
\leq.

With respect to Lemma
2.1
let
\left(C,\leq\right)
denote the pre-ordered set,
\left(C/\sim,\leq\right)
the partially ordered set and
\left(C/\sim,\preceq\right)
the totally ordered set.

Lemma 2.2
.

Consider the setting of Lemma
2.1
and previous notation.

1.

If
c_{1}\leq c_{2}
then
\overline{c_{1}}\leq\overline{c_{2}}
and
\overline{c_{1}}\preceq\overline{c_{2}}.

2.

By the proof ot the order-extension principle, if
\overline{c_{1}}
is not related to
\overline{c_{2}}
in the partially ordered set, then there is at least one total order that extends
\leq
such that
\overline{c_{1}}\preceq\overline{c_{2}},
and at least one total order that extends
\leq
such that
\overline{c_{2}}\preceq\overline{c_{1}}.

Definition 2.5
.

A b-homological system
\left(\Delta;\Omega,\leq\right),
consists of the following:

HS1: A pre-ordered set
\left(\Omega,\leq\right).

HS2: The set
\Delta=\left\{\Delta_{\omega}\right\}_{\omega\in\Omega},
where
\Delta_{\omega}
is a finitely generated
R-
module with local ring of endomorphisms for any
\omega\in\Omega.

Also
\omega\neq\omega^{\prime}
implies
\Delta_{\omega}\ncong\Delta_{\omega^{\prime}}.

HS3: If
{\rm Hom}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)\neq 0
then
\omega\leq\omega^{\prime}.

HS4: If
{\rm Ext}^{1}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)\neq 0
then
\omega\leq\omega^{\prime}
and it is
not true that
\omega^{\prime}\leq\omega.

Remark 2.6
.

Let
\pi:\Omega\longrightarrow\Omega/\sim
be the canonical suprajective function,
\left(\Omega/\sim,\leq\right)
the induced partially ordered set and
\left(\Omega/\sim,\preceq\right)
a totally ordered set where
\preceq
extends
\leq,
as in Lemma
2.1
.

By Lemma
2.2
and axiom HS4 if
\overline{\omega^{\prime}}\preceq\overline{\omega}
then
{\rm Ext}^{1}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)=0,
and by same lemma and axiom HS3 if
\overline{\omega^{\prime}}\prec\overline{\omega}
(i.e.
\overline{\omega^{\prime}}\preceq\overline{\omega}
and
\overline{\omega^{\prime}}\neq\overline{\omega}
) then
{\rm Hom}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)=0.

Moreover, by Lemma
2.2
in the definition of b-homological system we can substitute HS3 and HS4 for the following axioms:

HS3’: For any total order
\preceq
that extends
\leq,
if
{\rm Hom}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)\neq 0
then
\overline{\omega}\preceq\overline{\omega^{\prime}}.

HS4’: For any total order
\preceq
that extends
\leq,
if
{\rm Ext}^{1}_{\Lambda}\left(\Delta_{\omega},\Delta_{\omega^{\prime}}\right)\neq 0
then
\overline{\omega}\prec\overline{\omega^{\prime}}.

Definition 2.7
.

Given the set
\Delta=\left\{\Delta_{\omega}\right\}_{\omega\in\Omega},

The modules in

A

Remark 2.8
.

It is immediate that
\widetilde{\cal{F}}\left(\Delta\right)
is closed under
isomorphisms, extensions, and contains any zero object.

Applying the Correspondence Theorem for modules it is easy to verify that for a
\widetilde{\Delta}-

\widetilde{\Delta}-

Corollary 2.20
.

\widetilde{\cal{F}}\left(\Delta\right)
is closed under direct summands.

Proof:
Let
M\in\widetilde{\cal{F}}\left(\Delta\right)
and
M=L\oplus N.

Consider the ordered
\widetilde{\Delta}-
filtration of
M
with the notation of Proposition
2.17
.

By Lemma
2.16
we have the identity
W_{a}={\rm tr}_{W_{a}}\left(M\right),
and by additivity of the trace,
{\rm tr}_{W_{a}}\left(M\right)={\rm tr}_{W_{a}}\left(L\right)\oplus{\rm tr}_{W_{a}}\left(N\right).

By Lemma
2.19
we get that
{\rm tr}_{W_{a}}\left(L\right)=L_{a}\subseteq L
and
{\rm tr}_{W_{a}}\left(N\right)=N_{a}\subseteq N
are in
\widetilde{\cal{F}}\left(\Delta\right).

By same Lemma
\ell_{\omega}\left(W_{a}\right)=\ell_{\omega}\left(L_{a}\right)+\ell_{\omega}\left(N_{a}\right)
for each
\omega.

We can repeat this argument for the quotients
M/W_{a}\cong\left(L/L_{a}\right)\oplus\left(N/N_{a}\right)
in order to get larger
submodules of
L
and
N
that are in
\widehat{\cal{F}}\left(\Delta\right).

Repeating the procedure we obtain ordered
\widetilde{\Delta}-
filtrations of
L
and

N,
so they both belong to
\widetilde{\cal{F}}\left(\Delta\right).

\hfill\square
