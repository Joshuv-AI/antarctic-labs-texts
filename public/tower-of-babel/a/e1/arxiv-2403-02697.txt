Noise misleads rotation invariant algorithms on sparse targets
Manfred K. Warmuth, Ehsan Amid, Manfred K. Warmuth, Wojciech Kotłowski, Matt Jones, Ehsan Amid

Abstract
It is well known that the class of rotation invariant algorithms are suboptimal even for learning sparse linear problems when the number of examples is below the “dimension” of the problem. This class includes any gradient descent trained neural net with a fully-connected input layer (initialized with a rotationally symmetric distribution). The simplest sparse problem is learning a single feature out of d d features. In that case the classification error or regression loss grows with 1 − k / d 1-\nicefrac{{k}}{{d}} where k k is the number of examples seen. These lower bounds become vacuous when the number of examples k k reaches the dimension d d . Nevertheless we show that when noise is added to this sparse linear problem, rotation invariant algorithms are still suboptimal after seeing d d or more examples. We prove this via a lower bound for the Bayes optimal algorithm on a rotationally symmetrized problem. We then prove much lower upper bounds on the same problem for simple non-rotation invariant algorithms. Finally we analyze the gradient flow trajectories of many standard optimization algorithms in some simple cases and show how they veer toward or away from the sparse targets. We believe that our trajectory categorization will be useful in designing algorithms that can exploit sparse targets and our method for proving lower bounds will be crucial for analyzing other families of algorithms that admit different classes of invariances.

An

(1)

In other words, the prediction

\bm{U}

If the algorithm is randomized, based on an internal random variable

Our lower bounds in sections

In particular,

The reason is that such a network can be written as

1.2
Lower bounds for rotation invariant algorithms

Our method for proving lower bounds builds on the following observation: Given any rotation invariant algorithm and any learning problem, the algorithm will achieve the same loss on all rotated versions of that problem. We can therefore consider a Bayesian setting where the problem is sampled uniformly from all rotated versions, and the optimal solution provides a lower bound on the loss of the algorithm. Intuitively, being rotation invariant forces an algorithm to be agnostic over all possible rotations of the problem, and hedging its bets in this way prevents it from excelling at any specific problem instance. In Section
1.3
we apply this reasoning to linear regression to show that a rotation invariant algorithm cannot efficiently learn sparse solutions, because it must be equally efficient at finding any other solution (including rotated, non-sparse ones).

Formally, let the learning problem be defined by
(a) an input distribution
p_{\textrm{in}}(\tilde{\bm{X}})
with the input matrix
\underset{n+1,d}{\tilde{\bm{X}}}=[\bm{X},\bm{x}_{\rm{te}}^{\top}]
consisting of the training matrix
\bm{X}
and the test example
\bm{x}_{\rm{te}}

(b) an observation model
q(\tilde{\bm{y}}|\tilde{\bm{X}})
which gives the joint conditional distribution over
n
training outcomes and a test outcome,
\underset{n+1}{\tilde{\bm{y}}}=[\bm{y},y_{\rm{te}}]
, and
(c) a loss function
\mathcal{L}(\widehat{y},y)
.
We assume the input distribution is rotationally symmetric, meaning
p_{\textrm{in}}(\tilde{\bm{X}})=p_{\textrm{in}}(\tilde{\bm{X}}\bm{U}^{\top})
for any orthogonal
\bm{U}
.
The task of any algorithm will be to produce predictions
\widehat{y}(\bm{x}_{\rm{te}}|\bm{X},\bm{y})
to minimize the loss on the test outcomes,
\mathcal{L}(\widehat{y},y_{\rm{te}})
.
Note that this setup allows arbitrary conditional dependencies among observations (not just iid problems), including dependencies between the training and the test sets.

For any orthogonal
\underset{d,d}{\bm{U}}
, define the rotated observation model as

\;q_{\bm{U}}(\tilde{\bm{y}}|\tilde{\bm{X}})=q(\tilde{\bm{y}}|\tilde{\bm{X}}\bm{U}^{\top})
.
Now define a new learning problem by first sampling
\bm{U}

uniformly (under the Haar measure
p_{\textrm{H}}
) and then generating observations according to
q_{\bm{U}}
. This is equivalent to a symmetrized observation model
\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q}
that is a mixture over all
q_{\bm{U}}
:

\displaystyle\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q}(\tilde{\bm{y}}|\tilde{\bm{X}})=\int q_{\bm{U}}(\tilde{\bm{y}}|\tilde{\bm{X}}){\textrm{d}}p_{\textrm{H}}(\bm{U})

The Bayes optimal prediction can be expressed by computing a posterior over
\bm{U}
and integrating expected loss over this posterior:

\displaystyle\widehat{y}^{\star}(\bm{x}_{\rm{te}}|\bm{X},\bm{y})=\arg\min_{\widehat{y}}\int\mathbb{E}_{y_{\rm{te}}\sim q_{\bm{U}}(\cdot|\tilde{\bm{X}},\bm{y})}[\mathcal{L}(\widehat{y},y_{\rm{te}})]p(\bm{U}|\tilde{\bm{X}},\bm{y}){\textrm{d}}\bm{U}.

Thus
\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q}
is difficult, especially for large
d
, because equal prior probability must be given to all possible rotations. We define the optimal expected loss on this problem as

\displaystyle L_{\mathcal{B}}(\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q})=\mathbb{E}_{\tilde{\bm{X}}\sim p_{\textrm{in}},\tilde{\bm{y}}\sim\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q}(\cdot|\tilde{\bm{X}})}[\mathcal{L}(\widehat{y}^{\star}(\bm{x}_{\rm{te}}|\bm{X},\bm{y}),y_{\rm{te}})].

Our first result is that the performance of any rotation
invariant algorithm on the original problem, defined by

q
, is lower bounded by
L_{\mathcal{B}}(\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q})
.

Theorem 1
.

Given a rotationally symmetric
p_{\textrm{in}}(\tilde{\bm{X}})
, an observation model
q(\tilde{\bm{y}}|\tilde{\bm{X}})
, a loss function
\mathcal{L}
, and a rotationally invariant learning algorithm
\widehat{y}_{n}(\cdot|\bm{X},\bm{y})
, define the expected loss

\displaystyle L_{\widehat{y}}(q)=\mathbb{E}_{\tilde{\bm{X}}\sim p_{\textrm{in}},\tilde{\bm{y}}\sim q(\cdot|\tilde{\bm{X}}),Z}[\mathcal{L}(\widehat{y}(\bm{x}_{\rm{te}}|\bm{X},\bm{y}),y_{\rm{te}})],

This loss is bounded by
L_{\widehat{y}}(q)\geq L_{\mathcal{B}}(\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q})
.

The proof in Appendix
A
shows any rotationally invariant algorithm will satisfy
L_{\widehat{y}}(q_{\bm{U}})=L_{\widehat{y}}(q)
for all
\bm{U}
. This implies
L_{\widehat{y}}(q)=L_{\widehat{y}}(\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q})\leq L_{\mathcal{B}}(\overset{\mathrel{\mathsmaller{\mathsmaller{\circ}}}}{q})
.

As we show in this paper, a consequence of Theorem
1
is that rotational invariance prevents efficient learning of problems characterized by properties that are not rotationally invariant, such as sparsity. Algorithms with inductive biases for such properties are necessarily not rotation invariant and can give dramatically better performance.
Although we have stated the theorem in terms of rotational
invariance, it is easily extended to other transformation
groups
\mathcal{T}
on the input (by replacing
\bm{U}
with
elements of
\mathcal{T}
and requiring

to be symmetric under

For example, natural gradient descent (NGD) is often touted for being invariant to arbitrary smooth reparameterization

In particular, since spindly and fully connected networks are related by smooth reparameterization,

Kerekes et al., 2021

Thus the lower bounds we prove apply to NGD

\displaystyle\EE_{k,\xi_{\rm{te}}}[\mathcal{L}(\widehat{y},y_{\rm{te}})]

3
Gradient flow trajectories

In our setting of overconstrained optimization without explicit regularization, all algorithms operate on the same loss landscape but follow different paths to the minimum.
To understand these differences, we derive exact expressions for the weight trajectories for the continuous time (gradient flow) versions of several representative algorithms.
We then use these results to analyze the algorithms’ ability to learn sparse targets without overfitting to noise.

3.1
Preconditioning, mirror descent, reparameterization, and Riemannian descent

Gradient descent (GD) on a given loss function can be generalized in several ways, including preconditioned GD, mirror descent (MD), GD on reparameterized variables, and Riemannian GD. We show how they are all interchangeable in the continuous-time case.

Preconditioned GD premultiplies the gradient with a matrix
\bm{P}
that can depend on the current weights or the training history. Explicit preconditioning methods include adaptive learning rate algorithms such as Adagrad
(
Duchi et al., 2011b
)
, natural gradient descent which preconditions with the inverse Fisher information matrix
(
Amari, 1998
)
, and variational Bayesian methods that precondition with the prior or posterior covariance
(
Lambert et al., 2022
;
Chang et al., 2023
)
.

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}=-\bm{P}\nabla_{w}L

(5)

Reparameterizing refers to defining some injective function
\widehat{\bm{w}}=g(\bm{w})
and performing GD on the new variable:

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\widehat{\bm{w}}}}}=-\nabla_{\widehat{\bm{w}}}L

(6)

MD
(
Nemirovsky and Yudin, 1983
)
involves an invertible mirror map
\widetilde{\bm{w}}=f(\bm{w})
where
f
is the gradient of a convex function, with the update

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\widetilde{\bm{w}}}}}=-\nabla_{\bm{w}}L

(7)

Riemannian GD generalizes to parameter spaces with non-Euclidean geometry (specifically, differentiable manifolds)
(
Bonnabel, 2013
)
. In Riemannian geometry the update
{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}
lies in the tangent space
T_{\bm{w}}
(a direction of motion based at
\bm{w}
) whereas the gradient
\nabla_{\bm{w}}L
lies in the cotangent space
T_{\bm{w}}^{*}
(the dual of
T_{\bm{w}}
).
Unlike in Euclidean geometry,
T_{\bm{w}}
and
T_{\bm{w}}^{*}
cannot be identified and instead mapping between them requires a metric
\bm{\Gamma}_{\bm{w}}:T_{\bm{w}}\to T_{\bm{w}}^{*}
or equivalently
\bm{\Gamma}_{\bm{w}}:T_{\bm{w}}\times T_{\bm{w}}\to\mathbb{R}
.
This leads to an update that is the direction of steepest descent with respect to the geometry:

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}=-\bm{\Gamma}_{\bm{w}}^{-1}\nabla_{\bm{w}}L

(8)

Theorem 5
.

The continuous-time versions of reparameterized GD, MD, and Riemannian GD are all equivalent to preconditioned GD under the relation

\bm{P}=\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\left(\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\right)^{\top}=\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}=\bm{\Gamma}_{\bm{w}}^{-1}

(9)

Appendix
H
gives the proof and then uses this result (a) to derive a close connection between EGU and the spindly network and (b) to show how EGU implicitly operates on a non-Euclidean geometry
(Figure
3
) that tends to hold it in sparse regions of parameter space.
Rotationally invariant algorithms cannot do this because their implicit geometry must be rotationally symmetric.

We derive analytic trajectories for the simple linear regression problem from Sections

and

\displaystyle w_{i}(t)

4
Noise experiments on Fashion MNIST

The assumption of rotationally symmetric input distribution is too strong for real datasets. Therefore it is important to complement our theoretical results with experimental demonstration that standard rotationally invariant algorithms cannot exploit asymmetries in real data. Here we report experiments on the Fashion MNIST
(
Xiao et al., 2017
)
dataset.
One could trivially cheat this task by hard-coding a lookup table of the test set,
and this can even be done with a rotation invariant algorithm:
If
\bm{X}^{\top}\bm{X}
is the (known, asymmetric) covariance of the original training set,
then when presented with rotated training data

\bm{Z}=\bm{X}\bm{U}^{\top}
, the algorithm infers the unknown
\bm{U}
to
high precision by solving
\bm{Z}^{\top}\bm{Z}=\bm{U}\bm{X}^{\top}\bm{X}\bm{U}^{\top}
.
It then un-rotates
\bm{z}_{\rm te}
and uses the lookup table.
Such a bespoke algorithm is of course not of interest; the question is whether standard
rotation invariant algorithms based on gradient descent can do anything similar, or whether they are limited by their rotation invariance just as they are in the idealized symmetric-input setting.

We use a
multilayer feedforward network with two hidden layers of
size 256 each. We consider two cases for the input layer
weights: 1) fully-connected (each 1st layer hidden node is
connected to all inputs) and 2) “spindly” (each 1st layer hidden node
is connected to all inputs via the network of Figure

1
).
In the noise-free case, both variants of the network
achieve the same top one accuracy of
85\%
(although
the spindly version takes longer to train).
Next, we double the number of features of
the examples by augmenting each example with uniformly sampled noise pixels in the range
[-1,1]
.
With noisy augmentation, the spindly network still achieves
85\%
test accuracy
while the fully-connected network gets only to
71\%

(after a much longer training phase).
In addition, the learned weights by
the two networks are significantly different: The
fully-connected network assigns almost the same magnitude
of weights to the noisy features as to the image features,
while the spindly network allocates much larger weights to the image features.
This illustrates that rotation invariant algorithms have a harder time ignoring
the noisy features.

Finally, to further compare the different sensitivity to the
informativeness of features, we augment each example on top of the noise
with its one-hot representation of the 10 target class labels.
This splits the features into three categories
in terms of their informativeness: 1) highly informative label features, 2) less informative image features, and 3) noise features with no (structured) information. The spindly network achieves
100\%
test accuracy while the fully-connected network gets to
98\%
. We observe that the spindly network assigns much larger weights (in magnitude) to the label features while almost ignoring the rest. This phenomenon is less prominent in the fully-connected network. We defer all the details to Appendix
K
.

5
Open problems

The “full versions” of many common optimization
algorithms
(
Abdulkadirov et al., 2023
)
such as
AdaGrad, Fisher, Adam, RMS Prop are all rotation invariant.
However in practice diagonalized versions of these updates
are used. In a major step forward we were able to solve the
differential equations for all these algorithms
when
\bm{\Sigma}=\lambda\bm{I}
(the arbitrary
\bm{\Sigma}
cases are
challenging open problems).
This lets us analyze the inductive biases of all these
algorithms on linear neurons based on their gradient flow trajectories.
For example, the diagonalized AdaGrad is biased away from sparsity.
So using sparsity as a yard stick, we show
that already for linear neurons, dramatic differences
can occur compared to the optimal algorithms.
The question is whether these differences remain
when running the same algorithms on neural nets with any number of hidden layers.

Appendix B
Proof of lower bound Theorem
2

Before we give the proof observe that one can equivalently think of the
m
stacked copies of
\bm{H}
as just a single copy of
\bm{H}
with the variance of label noise reduced by a factor of
m
. Indeed,
if
\bm{y}_{i}
represents the label vector of size
d
associated with the
i
-th copy of
\bm{H}
, then the training loss for any weight vector
\widehat{\bm{w}}
is effectively

\|\bm{y}-\bm{X}\widehat{\bm{w}}\|^{2}=\sum_{i=1}^{m}\|\bm{y}_{i}-\bm{H}\widehat{\bm{w}}\|^{2}=m\|\bar{\bm{y}}-\bm{H}\widehat{\bm{w}}\|^{2}+\sum_{i=1}^{m}\|\bm{y}_{i}-\bar{\bm{y}}\|^{2},

where
\bar{\bm{y}}=m^{-1}\sum_{i}\bm{y}_{i}\sim\mathrm{N}(\bm{H}\bm{e}_{1},\sigma^{2}/m\bm{I}_{d})
and the last term on the right-hand side does not depend on
\widehat{\bm{w}}
.
Therefore, by varying
m
, we effectively alter the level of noise the algorithms encounter.
We also note that our model is equivalent to the Gaussian Sequence Model (see, for example,
Rigollet and Hütter (2023)
),
given by
\bm{y}=\bm{\theta}+\bm{\xi}
(with
\bm{\theta}=\bm{X}\bm{e}_{1}
and
\bm{\xi}\sim\mathcal{N}(\bm{0},\sigma^{2}/m\bm{I}_{d})
), a commonly used model for analyzing nonparametric and high dimensional statistical problems.

Proof.

We consider the rotated observational model described in the main text, which can be defined as follows. Let
\bm{w}\in\mathbb{R}^{d}

be a weight vector drawn uniformly from a unit sphere

\mathcal{S}^{d-1}=\{\bm{w}\in\mathbb{R}^{d}\colon\|\bm{w}\|=1\}
.
The algorithm is given data set
(\bm{X},\bm{y})
with
\bm{X}=[\bm{H};\ldots;\bm{H}]
being

m
copies of
\bm{H}=\sqrt{d}\bm{V}
, and
\bm{y}=\bm{H}\bm{w}+\bm{\xi}
, where
\bm{\xi}\sim N(\bm{0},\sigma^{2}\bm{I}_{dm})
is a vector of Gaussian i.i.d. noise variables, each having zero
mean and variance
\sigma^{2}
. Given
\bm{y}
, the algorithm is supposed to produce a vector of predictions

\widehat{\bm{y}}\in\mathbb{R}^{d}
and is evaluated by means of the squared error,

e(\widehat{\bm{y}}|\bm{w})=\frac{1}{d}\|\widehat{\bm{y}}-\bm{H}\bm{w}\|^{2}
.
We first note that without loss of generality, the algorithm produces a weight vector

\widehat{\bm{w}}
, based on which the predictions are generated,
\widehat{\bm{y}}=\bm{H}\widehat{\bm{w}}
; this is due
to the fact that
\bm{H}
is invertible (as multiplicity of an orthogonal matrix), so
for every
\widehat{\bm{y}}
, one can have a corresponding weight vector
\widehat{\bm{w}}=\bm{H}^{-1}\widehat{\bm{y}}
.
Thus, using (
3
) the error can be equivalently written as

e(\widehat{\bm{w}}|\bm{w})=\|\widehat{\bm{w}}-\bm{w}\|^{2}.

It is well-known (see, e.g.,
Berger (1985)
) that the expected squared error,

\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}|\bm{w})\right]
(with expectation with
respect to the prior and the label noise) is minimized by the
posterior mean

\widehat{\bm{w}}^{\star}=\EE_{\bm{w}|\bm{y}}[\bm{w}]
, that is the mean value of
\bm{w}
with respect to the posterior distribution

q(\bm{w}|\bm{X},\bm{y})
. Even though the posterior mean does not have a nice analytic form, we can still lower bound
its expected squared error using a technique borrowed from
(
Marchand, 1993
;
Dicker, 2016
)
. Let

\widehat{\bm{w}}_{RR}
be the ridge regression estimator:

\widehat{\bm{w}}_{RR}=(\bm{X}^{\top}\bm{X}+\sigma^{2}d\bm{I})^{-1}\bm{X}^{\top}\bm{y},

which is the posterior mean itself (and thus optimal)
when the prior over
\bm{w}
is Gaussian with zero mean and covariance
\frac{1}{d}\bm{I}
(the covariance is multiplied by factor
d^{-1}
to have
\EE[\|\bm{w}\|^{2}]=\EE[\bm{w}\bm{w}^{\top}]=\tr(\frac{1}{d}\bm{I})=1
as in the unit sphere prior case). Even though the Gaussian prior differs from the uniform prior over a unit sphere, it turns out that the RR predictor has error only slightly larger than that of the optimal Bayes predictor

\widehat{\bm{w}}^{\star}
:

Lemma 6
.

\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}_{RR}|\bm{w})\right]\leq\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}^{\star}|\bm{w})\right]+\frac{1}{d}\frac{\sigma^{2}}{\sigma^{2}+m}.

Proof.

Dicker (2016)
considered a Bayesian setting similar to ours, with
\sigma^{2}=1
and

\bm{w}
distributed uniformly over
\tau\mathcal{S}^{d-1}=\{\bm{w}\colon\|\bm{w}\|=\tau\}
.
To account for this setting, we note that in our setup,

\sigma^{-1}\bm{y}=\bm{X}^{\top}(\sigma^{-1}\bm{w})~+\underbrace{\sigma^{-1}\bm{\xi}}_{\sim N(\bm{0},\bm{I}_{dm})},

so that we can set
\tau=\sigma^{-1}
and assume unit variance of the noise. Their ‘oracle ridge estimator’ is thus
\widehat{\bm{w}}_{RR}
. Furthermore, since
\|\widehat{\bm{w}}-\bm{w}\|^{2}=\sigma^{2}\|\sigma^{-1}\widehat{\bm{w}}-\sigma^{-1}\bm{w}\|^{2}
, we need to multiply their bound by
\sigma^{2}
. We use their Theorem 2 (adapted to the modifications stated above):

Theorem 7
.

(Theorem 2 by
Dicker (2016)
, Theorem 3.1 by
Marchand (1993)
)
Let
n=md
and let
s_{1}\geq\ldots\geq s_{d}
denote the eigenvalues of
n^{-1}\bm{X}^{\top}\bm{X}
.
Then

\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}_{RR}|\bm{w})\right]\leq\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}^{\star}|\bm{w})\right]+\frac{\sigma^{2}}{d}\frac{s_{1}}{s_{d}}\mathrm{tr}\left\{(\bm{X}^{\top}\bm{X}+d\sigma^{2}\bm{I}_{n})^{-1}\right\}.

Since
\bm{X}^{\top}\bm{X}=n\bm{I}
, we have
s_{1}=s_{d}=1
and

(\bm{X}^{\top}\bm{X}+\bm{I}_{n})^{-1}=(n+d\sigma^{2})^{-1}\bm{I}_{n}
, and thus,

\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}_{RR}|\bm{w})\right]\leq\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}^{\star}|\bm{w})\right]+\frac{\sigma^{2}}{n+d\sigma^{2}}=\EE_{\bm{w},\bm{\xi}}\left[e(\widehat{\bm{w}}^{\star}|\bm{w})\right]+\frac{1}{d}\frac{\sigma^{2}}{m+\sigma^{2}}.

∎

Now, we compute the expected error of
\widehat{\bm{w}}_{RR}
. Since
\bm{X}^{\top}\bm{X}=md\bm{I}
, we get

\widehat{\bm{w}}_{RR}=\frac{1}{md+\sigma^{2}d}\bm{X}^{\top}\bm{y}=\frac{1}{md+\sigma^{2}d}\bm{X}^{\top}(\bm{X}\bm{w}+\bm{\xi})=\frac{md\bm{w}+\bm{X}^{\top}\bm{\xi}}{md+\sigma^{2}d},

and thus

\displaystyle e(\widehat{\bm{w}}_{RR}|\bm{w})

\displaystyle=\|\widehat{\bm{w}}_{RR}-\bm{w}\|^{2}=\left|\frac{\bm{X}^{\top}\bm{\xi}-\sigma^{2}d\bm{w}}{md+\sigma^{2}d}\right\|^{2}

\displaystyle=\frac{\|\bm{X}^{\top}\bm{\xi}\|^{2}}{(md+\sigma^{2}d)^{2}}-\frac{md\bm{w}{}^{\top}\bm{X}^{\top}\bm{\xi}}{(md+\sigma^{2}d)^{2}}+\frac{\sigma^{4}d^{2}\|\bm{w}\|^{2}}{(md+\sigma^{2}d)^{2}}.

We take the expectation over
\bm{w}
, under which the middle term in the last line
vanishes (as
\EE[\bm{w}]=\bm{0}
over a unit sphere) and use
\|\bm{w}\|=1
to get

\EE_{\bm{w}}[e(\widehat{\bm{w}}_{RR}|\bm{w})]=\frac{\|\bm{X}^{\top}\bm{\xi}\|^{2}}{(md+\sigma^{2}d)^{2}}+\frac{\sigma^{4}d^{2}}{(md+\sigma^{2}d)^{2}}.

We further take an expectation over
\bm{\xi}
and use

\EE[\|\bm{X}^{\top}\bm{\xi}\|^{2}]=\EE[\tr(\bm{X}^{\top}\bm{\xi}\bm{\xi}^{\top}\bm{X})]=\tr(\bm{X}^{\top}\EE[\bm{\xi}\bm{\xi}^{\top}]\bm{X})=\tr(\bm{X}^{\top}\bm{X})=md\tr(\bm{I})=md^{2},

to get:

\EE_{\bm{w},\bm{\xi}}[e(\widehat{\bm{w}}_{RR}|\bm{w})]=\frac{md^{2}}{(md+\sigma^{2}d)^{2}}+\frac{\sigma^{4}d^{2}}{(md+\sigma^{2}d)^{2}}.=\frac{\sigma^{2}d(md+\sigma^{2}d)}{(md+\sigma^{2}d)^{2}}=\frac{\sigma^{2}}{m+\sigma^{2}}.

Using this together with Lemma
6
gives the lower bound on the Bayes optimal
predictor in the rotated observational model.

\EE_{\bm{w},\bm{\xi}}[e(\widehat{\bm{w}}^{\star}|\bm{w})]\geq\frac{d-1}{d}\frac{\sigma^{2}}{\sigma^{2}+m}.

We now use the fact that
that
\bm{H}=\sqrt{d}\bm{V}

with orthogonal matrix
\bm{V}
of size
d\times d
, drawn uniformly at random (with respect to Haar measure), so that our input distribution is rotation symmetric. This means that we can apply Theorem 1 and conclude that any rotation invariant algorithm has the expected error
at least
\frac{d-1}{d}\frac{\sigma^{2}}{\sigma^{2}+m}
on the original problem,
that is for
\bm{w}=\bm{e}_{1}
.
∎

Note that the proof would significantly simplify if we
assumed from the start that the target weight vector

\bm{w}
is generated from a Gaussian distribution

N(\bm{0},\frac{1}{d}\bm{I}_{d})
rather than from a unit
sphere
\mathcal{S}^{d-1}
(both priors give unit squared
norm of
\bm{w}
on expectation), as the Bayes
predictor would be exactly the RR predictor, giving even a
better lower bound of
\frac{\sigma^{2}}{\sigma^{2}+m}
,
without the need to apply results from

Marchand (1993)
;
Dicker (2016)
. This would, however, result in a
random norm of the sparse target vector. In our proof we opted for a bound with a fixed, unit norm of
\bm{w}
.

Appendix C
Lower bound for i.i.d. sampling

Instead of observing copies of the same matrix
\bm{H}
, one can instead consider a standard linear model framework, where individual inputs

\bm{x}
are drawn i.i.d. from some input distribution
p_{\mathrm{in}}(\bm{x})
. The associated labels are given by
y=\bm{x}_{i}^{\top}\bm{e}_{1}+\xi
, where
\xi\sim\mathcal{N}(0,\sigma^{2})
.
The algorithm observes
n
such i.i.d. samples
(\bm{X},\bm{y})
and produces a weight vector
\widehat{\bm{w}}
, which is then evaluated by the squared error
\|\widehat{\bm{w}}-\bm{e}_{1}\|^{2}
. Assume
p_{\mathrm{in}}(\bm{x})
is rotationally symmetric with covariance
\EE[\bm{x}\bm{x}^{\top}]=\bm{I}_{d}
(so that the expected input size matches that from our previous setup); for instance, we could have
\bm{x}\sim\mathcal{N}(\bm{0},\bm{I}_{d})
. Employing our Bayesian argument from section
1.2
,
one can establish a similar lower bound for any rotation-invariant algorithm.
Note that for large
d
, the bound is essentially the same
as that of Theorem
2
.
The proof makes use of information-theoretic arguments by
Gerchinovitz et al. (2020)
.

Theorem 8
.

Let the rows of
\bm{X}
be drawn i.i.d. from rotationally symmetric
p_{\mathrm{in}}
with covariance
\bm{I}_{d}
, and the labels given by
\bm{y}=\bm{X}\bm{e}_{1}+\bm{\xi}
,

\bm{\xi}\sim\mathcal{N}(\bm{0},\sigma^{2}\bm{I}_{n})
. Assume
d\geq 12
.
Then, the expected error (with a random choice of the sample) of any rotation-invariant learning algorithm is at least

\EE[e(\widehat{\bm{w}})]\geq\left(\frac{\sigma^{2}}{e(\sigma^{2}+m/2)}\right)^{d/(d-1)}.

Proof.

We consider a Bayesian setup, in which the target weight vector is drawn
uniformly from a unit sphere,

\bm{w}\sim\mathcal{S}^{d-1}
,
with
\mathcal{S}^{d-1}=\{\bm{w}\in\mathbb{R}^{d}\colon\|\bm{w}\|=1\}
.
We will show a lower bound on the error of
any
predictor
\widehat{\bm{w}}
,

\EE_{\bm{w},\bm{\xi}}\left[\|\widehat{\bm{w}}-\bm{w}\|^{2}\right]
,
by exploiting the fact
that it is not less than the error of the Bayes optimal predictor
\widehat{\bm{w}}^{\star}
(the posterior mean), followed
by a lower bound on the error of
\widehat{\bm{w}}^{\star}
:

\EE_{\bm{w},\bm{\xi}}\left[\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}\right]\geq\left(\frac{\sigma^{2}}{e(\sigma^{2}+m/2)}\right)^{d/(d-1)}.

(14)

Using the rotational symmetry of the input distribution
p_{\mathrm{in}}
, and giving the same arguments as in the proof of Theorem
2
(or Section
1.2
), this will imply
the same lower bound (
14
) for any rotation-invariant algorithm with a sparse target vector

\bm{w}=\bm{e}_{1}
.

Unfortunately, for prior uniform over a sphere,
\widehat{\bm{w}}^{\star}
does not have a closed form. We will, however, use a continuous version of Fano’s inequality
(
Gerchinovitz et al., 2020
)
to lower bound its Bayes risk.

From now on, we condition our analysis on
\bm{X}
drawn i.i.d. from the input distribution.
We lower-bound the Bayes risk using Markov’s inequality: for any
\epsilon>0
,

\EE[\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}]\geq\epsilon P(\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}\geq\epsilon)=\epsilon\left(1-P(\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}<\epsilon)\right).

(15)

where the expectation and the probability is with respect to random
\bm{y},\bm{w}
(conditioned on
\bm{X}
). Let
P_{\bm{w}}=\mathcal{N}(\bm{X}\bm{w},\sigma^{2}\bm{I}_{n})
be the distribution of
\bm{y}
given
\bm{w}
(and
\bm{X}
). Given
\bm{w}
, define event

\mathcal{A}_{\bm{w}}=\{\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}<\epsilon\}
. We can
write

P\left(\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}<\epsilon\right)=\EE_{\bm{w}}\left[P_{\bm{w}}(\mathcal{A}_{\bm{w}})\right]

Using techniques from
Gerchinovitz et al. (2020)
,
we have for any distribution
Q
over
\bm{y}
,

\EE_{\bm{w}}\left[P_{\bm{w}}(\mathcal{A}_{\bm{w}})\right]\leq\EE_{\bm{w}}\left[Q(\mathcal{A}_{\bm{w}})\right]+\sqrt{\left(\EE_{\bm{w}}\left[Q(\mathcal{A}_{\bm{w}})\right]\right)\left(\EE_{\bm{w}}\left[\chi^{2}(P_{\bm{w}},Q)\right]\right)}

(16)

where
\chi^{2}(P,Q)=\EE_{Q}\left[\left(\frac{\mathrm{d}P}{\mathrm{d}Q}\right)^{2}\right]
is the
\chi^{2}
-divergence between
P
and
Q
.
We now choose
Q=\mathcal{N}(\bm{0},\bm{\Sigma})

with
\bm{\Sigma}=\sigma^{2}\bm{I}_{n}+\frac{1}{d}\bm{X}\bm{X}^{\top}
.
It follow from the Gaussian integration that

\chi^{2}(P_{\bm{w}},Q)=\sqrt{\det\left(\sigma^{-2}\bm{\Sigma}^{2}(2\bm{\Sigma}-\sigma^{2}\bm{I}_{n})^{-1}\right)}e^{\bm{w}^{\top}\bm{X}^{\top}\left(2\bm{\Sigma}-\sigma^{2}\bm{I}_{n}\right)^{-1}\bm{X}\bm{w}}-1.

First note that

\sigma^{-2}\bm{\Sigma}^{2}(2\bm{\Sigma}-\sigma^{2}\bm{I}_{n})^{-1}=\left(\bm{I}_{n}+\frac{1}{d\sigma^{2}}\bm{X}\bm{X}^{\top}\right)^{2}\left(\bm{I}_{n}+\frac{2}{d\sigma^{2}}\bm{X}\bm{X}^{\top}\right)^{-1}\preceq\bm{I}_{n}+\frac{1}{2d\sigma^{2}}\bm{X}\bm{X}^{\top}.

Indeed, by taking any eigenvalue
\lambda_{i}
of
\frac{1}{2d\sigma^{2}}\bm{X}\bm{X}^{\top}
,

\frac{(1+\lambda_{i})^{2}}{1+2\lambda_{i}}\leq 1+\frac{\lambda_{i}^{2}}{1+2\lambda_{i}}\leq 1+\frac{\lambda_{i}}{2}.

Moreover, from the property of the determinant, that

\det(\bm{I}_{m}+\bm{A}\bm{B})=\det(\bm{I}_{n}+\bm{B}\bm{A})
for
\bm{A}
of size
m\times n
and
\bm{B}
of size
n\times m
, we get

\det\left(\bm{I}_{n}+\frac{1}{2d\sigma^{2}}\bm{X}\bm{X}^{\top}\right)=\det\left(\bm{I}_{m}+\frac{1}{2d\sigma^{2}}\bm{X}^{\top}\bm{X}\right).

Finally, note that

\bm{X}^{\top}(2\bm{\Sigma}-\sigma^{2}\bm{I}_{n})^{-1}\bm{X}=\bm{X}^{\top}\left(\sigma^{2}\bm{I}_{n}+\frac{2}{d}\bm{X}\bm{X}^{\top}\right)^{-1}\bm{X}\preceq\frac{d}{2}\bm{X}^{\top}(\bm{X}\bm{X}^{\top})^{\dagger}\bm{X}=\frac{d}{2}\bm{I}_{d},

so that

e^{\bm{w}^{\top}\bm{X}^{\top}\left(2\bm{\Sigma}-\sigma^{2}\bm{I}_{n}\right)^{-1}\bm{X}\bm{w}}\leq e^{\frac{d}{2}\|\bm{w}\|^{2}}=e^{\frac{d}{2}}.

Thus, we get:

\chi^{2}(P_{\bm{w}},Q)\leq\sqrt{\det\left(\bm{I}_{m}+\frac{1}{2d\sigma^{2}}\bm{X}^{\top}\bm{X}\right)}e^{\frac{d}{2}}

For any positive-definite
d\times d
matrix
\bm{A}
with eigenvalues
a_{1},\ldots,a_{d}
,
we have
\ln\det\bm{A}=\sum_{i}\ln a_{i}
. Using the concavity of negative logarithm,
we can bound:

\ln\det\bm{A}=d\frac{1}{d}\sum_{i}\ln(a_{i})\leq d\ln\left(\frac{1}{d}\sum_{i}a_{i}\right)=d\ln\tr(\bm{A}/d),

which gives
\det\bm{A}\leq\tr(\bm{A}/d)^{d}
and thus

\chi^{2}(P_{\bm{w}},Q)\leq\left(e\tr\left(\frac{1}{d}\bm{I}_{m}+\frac{1}{2d^{2}\sigma^{2}}\bm{X}^{\top}\bm{X}\right)\right)^{\frac{d}{2}}.

Since this expression does not depend on
\bm{w}
, taking expectation on both sides (with respect to
\bm{w}
) gives the same bound on
\EE_{\bm{w}}\left[\chi^{2}(P_{\bm{w}},Q)\right]
.

We will now upper-bound
\EE_{\bm{w}}[Q(\mathcal{A}_{\bm{w}})]
.
Let

\bm{1}\{C\}
denote the Iverson bracket which is
1
if
C
holds and
0
otherwise.
Using the fact that
\widehat{\bm{w}}^{\star}=\widehat{\bm{w}}^{\star}(\bm{y})
depends on
\bm{y}
(and
\bm{X}
), but
not on
\bm{w}
, and that
\bm{y}\sim Q
is independent of
\bm{w}
, we have

\displaystyle\EE_{\bm{w}}[Q(\mathcal{A}_{\bm{w}})]

\displaystyle=\EE_{\bm{w}}[Q(\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}<\epsilon)]=\EE_{\bm{w}\sim\mathcal{S}^{d-1},\bm{y}\sim Q}\left[\bm{1}\left\{\|\widehat{\bm{w}}^{\star}(\bm{y})-\bm{w}\|^{2}<\epsilon\right\}\right]

\displaystyle=\EE_{\bm{y}\sim Q}\left[\EE_{\bm{w}\sim\mathcal{S}^{d-1}}\left[\bm{1}\left\{\|\widehat{\bm{w}}^{\star}(\bm{y})-\bm{w}\|^{2}<\epsilon\right\}\right]\right]

\displaystyle\leq\EE_{\bm{y}\sim Q}\left[\max_{\widehat{\bm{w}}}\EE_{\bm{w}\sim\mathcal{S}^{d-1}}\left[\bm{1}\left\{\|\widehat{\bm{w}}-\bm{w}\|^{2}<\epsilon\right\}\right]\right]=\max_{\widehat{\bm{w}}}\EE_{\bm{w}}\left[\bm{1}\left\{\|\widehat{\bm{w}}-\bm{w}\|^{2}<\epsilon\right\}\right],

where in the last equality we used the fact that the term inside the expectation over
\bm{y}

does not depend on
\bm{y}
. Let us now fix
\widehat{\bm{w}}
and we will bound

\EE_{\bm{w}}\left[\bm{1}\left\{\|\widehat{\bm{w}}-\bm{w}\|^{2}<\epsilon\right\}\right]

Since the distribution
of
\bm{w}
is rotation-invariant (uniform over a sphere), without loss of generality take

\widehat{\bm{w}}=c\bm{e}_{1}
with
c>0
(
c=0
would give
0
for any
\epsilon<1
). We have

\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}=(c-w_{1})^{2}+\sum_{j=2}^{d}w_{j}^{2}=(c-w_{1})^{2}+1-w_{1}^{2}=1+c^{2}-2cw_{1},

and thus

\EE_{\bm{w}}\left[\bm{1}\left\{\|\widehat{\bm{w}}-\bm{w}\|^{2}<\epsilon\right\}\right]=\EE_{\bm{w}}\left[\bm{1}\left\{1+c^{2}-2cw_{1}<\epsilon\right\}\right]=P\left(w_{1}>\frac{1+c^{2}-\epsilon}{2c}\right).

Since the probability is nonincreasing in
\frac{1+c^{2}-\epsilon}{2c}
we take
c

which minimizes this quantity to get an upper bound. By inspecting the derivative

\min_{c}\frac{1+c^{2}-\epsilon}{2c}=\frac{1}{2}\min_{c}c+\frac{1-\epsilon}{c}~\stackrel{{\scriptstyle c=\sqrt{1-\epsilon}}}{{=}}~\sqrt{1-\epsilon},

we have

\EE_{\bm{w}}\left[\bm{1}\left\{\|\widehat{\bm{w}}-\bm{w}\|^{2}<\epsilon\right\}\right]=P\left(w_{1}>\sqrt{1-\epsilon}\right)=\frac{1}{2}P\left(w_{1}^{2}>1-\epsilon\right),

where we used the fact that distribution of
w_{1}
is symmetric around zero.
To determine the distribution of
w_{1}^{2}
we use the fact that drawing
\bm{w}
uniformly
over a unit sphere amounts to drawing
\bm{u}\sim\mathcal{N}(\bm{0},\bm{I}_{d})
and setting

\bm{w}=\frac{\bm{u}}{\|\bm{u}\|}
. Thus,
w_{1}^{2}=\frac{x}{x+y}
, where

x\sim\chi^{2}(1)=\mathrm{Gamma}(\alpha=1/2,\beta=1/2)
and

y\sim\chi^{2}(d-1)=\mathrm{Gamma}(\alpha=(d-1)/2,\beta=1/2)
and
x,y
independent,
Thus,

w_{1}^{2}
is distributed according to beta distribution
B(\alpha=1/2,\beta=(d-1)/2)
.
This gives

\displaystyle P\left(w_{1}^{2}>1-\epsilon\right)

\displaystyle=\frac{\Gamma(d/2)}{\Gamma(1/2)\Gamma((d-1)/2)}\int_{1-\epsilon}^{1}x^{-1/2}(1-x)^{-(d-1)/2}\mathrm{d}x

\displaystyle\leq\frac{\Gamma(d/2)}{\Gamma(1/2)\Gamma((d-1)/2)}(1-\epsilon)^{-1/2}\int_{1-\epsilon}^{1}(1-x)^{(d-1)/2-1}\mathrm{d}x

\displaystyle=\frac{\Gamma(d/2)}{\Gamma(1/2)\Gamma((d-1)/2)}\frac{2(1-\epsilon)^{-1/2}\epsilon^{(d-1)/2}}{d-1}

Assuming
\epsilon<1/2
, we have
2(1-\epsilon)^{-1/2}\leq 2\sqrt{2}
. We also use
Gautschi’s inequality which states that for any
x>0
and any
s\in(0,1)
,

\frac{\Gamma(x+1)}{\Gamma(x+s)}\leq(x+1)^{1-s}
. Taking

x=\frac{d}{2}-1
and
s=\frac{1}{2}
, we can bound

\frac{\Gamma(d/2)}{\Gamma((d-1)/2)}\leq\sqrt{d/2}\leq\sqrt{d-1}
, where we used
d\geq 2
. This, together
with
\Gamma(1/2)=\sqrt{\pi}
allows us to bound

P\left(w_{1}^{2}>1-\epsilon\right)\leq\frac{2\sqrt{2}\epsilon^{(d-1)/2}}{\sqrt{\pi}\sqrt{d-1}}.

Thus,
\EE_{\bm{w}}[Q(\mathcal{A}_{\bm{w}})]
can be bounded by

\EE_{\bm{w}}[Q(\mathcal{A}_{\bm{w}})]=\frac{1}{2}P\left(w_{1}^{2}>1-\epsilon\right)\leq\frac{\sqrt{2}\epsilon^{(d-1)/2}}{\sqrt{\pi}\sqrt{d-1}}

Plugging all bounds to (
16
)
gives:

\EE_{\bm{w}}\left[P_{\bm{w}}(\mathcal{A}_{\bm{w}})\right]\leq\frac{\sqrt{2}\epsilon^{(d-1)/2}}{\sqrt{\pi(d-1)}}+\sqrt{\sqrt{2}\frac{\epsilon^{(d-1)/2}}{\sqrt{(\pi(d-1)}}\left(e\tr\left(\frac{1}{d}\bm{I}_{m}+\frac{1}{2d^{2}\sigma^{2}}\bm{X}^{\top}\bm{X}\right)\right)^{\frac{d}{2}}}.

Now, take

\epsilon^{-1}=\left(e\tr\left(\frac{1}{d}\bm{I}_{m}+\frac{1}{2d^{2}\sigma^{2}}\bm{X}^{\top}\bm{X}\right)\right)^{d/(d-1)}.

Note that
\epsilon\leq 1/e
.
This gives

\EE_{\bm{w}}\left[P_{\bm{w}}(\mathcal{A}_{\bm{w}})\right]\leq\frac{\sqrt{2}e^{-(d-1)/2}}{\sqrt{\pi(d-1)}}+\sqrt{\frac{\sqrt{2}}{\sqrt{\pi(d-1)}}}\leq\frac{1}{2},

whenever
d\geq 12
. We thus have shown

P\left(\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}\leq\epsilon\right)\leq\frac{1}{2},

which, using (
15
), gives:

\EE_{\bm{w},\bm{y}|\bm{X}}[\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}]\geq\frac{\epsilon}{2}.

To get a bound with respect to a random choice of
\bm{X}
, note that
function
x\mapsto x^{-d/(d-1)}
is convex, and thus:

\displaystyle\EE[\|\widehat{\bm{w}}^{\star}-\bm{w}\|^{2}]

\displaystyle\geq\frac{1}{2}\EE[\epsilon]\geq\frac{1}{2}\left(e\tr\left(\frac{1}{d}\bm{I}_{m}+\frac{1}{2d^{2}\sigma^{2}}\EE[\bm{X}^{\top}\bm{X}]\right)\right)^{d/(d-1)}

\displaystyle=\left(e\left(1+\frac{n\tau^{2}}{2d\sigma^{2}}\right)\right)^{-d/(d-1)}=\left(\frac{\sigma^{2}}{e(\sigma^{2}+n\tau^{2}/(2d))}\right)^{d/(d-1)}

∎

Appendix D
Upper bound for EG
±
: Proof of Theorem
3

Here we prove that the
batch version of EG
±
achieves small error already after one trial, when the learning rate is set to a sufficiently large value.

The (batch) EG
±
algorithm keeps track of two vectors,
\bm{v}^{+}_{t}
and
\bm{v}^{-}_{t}
, and its prediction vector is given by
\bm{w}_{t}=\bm{v}^{+}_{t}-\bm{v}^{-}_{t}
.
It starts with a set of weights
\bm{v}_{1}^{+}=\bm{v}_{1}^{-}=\frac{1}{2d}\bm{1}
, and updates according to

\bm{v}^{+}_{t+1}\propto\bm{v}^{+}_{t}\odot e^{-\eta\nabla L(\bm{w}_{t})},\qquad\bm{v}^{-}_{t+1}\propto\bm{v}^{-}_{t}\odot e^{\eta\nabla L(\bm{w}_{t})},

where
\odot
is component-wise multiplication, and the normalization ensures that

\|\bm{v}^{+}_{t+1}\|_{1}+\|\bm{v}^{-}_{t+1}\|_{1}=1
, while
L(\bm{w})
is the average total loss on the training
sample:

L(\bm{w})=\frac{1}{dm}\|\bm{X}\bm{w}-\bm{y}_{t}\|^{2}.

We compute the expression for the gradient:

\displaystyle\nabla L(\bm{w})

\displaystyle=\frac{2}{dm}\sum_{t=1}^{m}\sqrt{d}\bm{V}^{\top}(\sqrt{d}\bm{V}\bm{w}-\bm{y}_{t})=\frac{2}{dm}\sum_{t=1}^{m}\sqrt{d}\bm{V}^{\top}(\sqrt{d}\bm{V}(\bm{w}-\bm{e}_{1})-\bm{\xi}_{t})

\displaystyle=\frac{2}{dm}\sum_{t=1}^{m}\left(d(\bm{w}-\bm{e}_{1})+\sqrt{d}\bm{V}^{\top}\bm{\xi}_{t}\right)=2(\bm{w}-\bm{e}_{1})-\frac{2}{\sqrt{d}}\bm{V}^{\top}\bar{\bm{\xi}},

where

\bar{\bm{\xi}}=\frac{1}{m}\sum_{t=1}^{m}\bm{\xi}_{t}~\sim~N\left(\bm{0},\frac{\sigma^{2}}{m}\bm{I}\right),

and the reduction of variance is due to averaging i.i.d. noise variables. Furthermore,
we rewrite

\nabla L(\bm{w})=2(\bm{w}-\bm{e}_{1}-\bm{\zeta}),

(17)

where the noise vector
\bm{\zeta}=\frac{1}{\sqrt{d}}\bm{V}^{\top}\bar{\bm{\xi}}
has distribution

\bm{\zeta}~\sim~N\left(\bm{0},\frac{\sigma^{2}}{md}\bm{V}^{\top}\bm{V}\right)~=~N\left(\bm{0},\frac{\sigma^{2}}{md}\bm{I}\right).

We also bound the error of the algorithm from above:

e(\bm{w}_{t})=\|\bm{w}_{t}-\bm{e}_{1}\|^{2}=\|\bm{w}_{t}\|^{2}-2\bm{w}_{t}^{\top}\bm{e}_{1}+\|\bm{e}_{1}\|^{2}\leq 2-2\bm{w}_{t}^{\top}\bm{e}_{1}=2(1-w_{t,1})=2(1-v_{t,1}^{+}+v_{t,1}^{-}).

So it suffices to upper-bound
1-v_{t,1}^{+}
and
v_{t,1}^{-}
.

Consider the weights of the batch EG
±
algorithm after just a
single
trial,
that is

v^{+}_{t+1,i}=\prod_{q=1}^{t}(1-2\eta(w_{q,i}-\zeta_{i}))^{2}v^{+}_{1,i}\leq(1+2\eta\zeta_{i})^{2t}v^{+}_{1,i}=(1+2\eta\zeta_{i})^{2t}\frac{1}{2d},

and similarly lower-bound
v^{-}_{t+1,i}
as

v^{-}_{t+1,i}=\prod_{q=1}^{t}(1+2\eta(w_{q,i}-\zeta_{i}))^{2}v^{-}_{1,i}\geq(1-2\eta\zeta_{i})^{2t}v^{+}_{1,i}=(1-2\eta\zeta_{i})^{2t}\frac{1}{2d}.

We have

(1+2\eta\zeta_{i})^{2t}=e^{2t\ln(1+2\eta\zeta_{i})}\leq e^{4t\eta\zeta_{i}},

where we used
\ln(1+x)\leq x
. Moreover, by Bernoulli’s inequality,

(1-2\eta\zeta_{i})^{2t}\geq 1-4t\eta\zeta_{i}.

This gives:

w_{t+1,i}=v^{+}_{t+1,i}-v^{-}_{t+1,i}=\frac{1}{2d}\left((1+2\eta\zeta_{i})^{2t}-(1-2\eta\zeta_{i})^{2t}\right)\leq\frac{1}{2d}(e^{4t\eta\zeta_{i}}-1+4t\eta\zeta_{i}).

Now, note that

4t\eta\zeta_{i}\leq\frac{T}{2}\gamma\leq\frac{4\sqrt{d}}{2\sqrt{8d}}\leq\frac{1}{\sqrt{2}},

Using the convexity of
e^{x}
, we have for
x\in[0,a]
that

e^{x}=e^{\left(1-\frac{x}{a}\right)\cdot 0+\frac{x}{a}\cdot a}\leq\left(1-\frac{x}{a}\right)e^{0}+\frac{x}{a}e^{a}=1+x\frac{e^{a}-1}{a}.

Taking
x=4t\eta\zeta_{i}
and
a=\frac{1}{\sqrt{2}}
, we have

e^{4t\eta\zeta_{i}}\leq 1+4t\eta\zeta_{i}\sqrt{2}(e^{1/\sqrt{2}}-1)\leq 1+6t\eta\zeta_{i}.

This allows us to bound

w_{t+1,i}\leq\frac{1}{2d}(e^{4t\eta\zeta_{i}}-1+4t\eta\zeta_{i})\leq\frac{1}{2d}10t\eta\zeta_{i}\leq\frac{5T\eta\zeta_{i}}{d}=\frac{5}{2\sqrt{d}}\zeta_{i}\leq\frac{5}{6}\zeta_{i}\leq\zeta_{i},

(34)

where we used
d\geq 9
. This finishes the inductive proof that
0\leq w_{t,i}\leq\zeta_{i}

for all
t=1,\ldots,T+1
. However, applying (
34
) to
t=T
gives

so that using (
31
)

w^{2}_{T+1,i}\leq\frac{25}{4d}\zeta^{2}_{i}\leq\frac{25}{4d}\gamma^{2}=\frac{25\sigma^{2}\ln\frac{2d}{\delta}}{4md^{2}}.

Thus, the total error from ‘zero-signal’ coordinates is

\sum_{i=2}^{d}w_{T+1,i}^{2}\leq\frac{25\sigma^{2}\ln\frac{2d}{\delta}}{4md}.

(35)

Analysis for the ‘signal’ coordinate.

For

v^{\pm}_{t+1,1}=(1\mp 2\eta(w_{t,i}-1-\zeta_{1}))^{2}v^{\pm}_{t,1}.

.
This is clearly true for

\displaystyle=v_{t+1,1}^{+}-v_{t+1,1}^{-}

\displaystyle w_{t+1,1}

\displaystyle\leq(1-2\eta(w_{t,1}-1-\zeta_{1}))^{2}w_{t,1}+8\eta(1+\zeta_{1}-w_{t,1})\frac{1}{18}

\displaystyle=(1-2\eta(w_{t,1}-1-\zeta_{1}))^{2}w_{t,1}+\frac{4}{9}\eta(1+\zeta_{1}-w_{t,1}).

(37)

We now maximize

) with respect

.
To this end, define function

\displaystyle=\frac{Q_{t}-4\eta(r-w_{t,1})}{1+4\eta(r-w_{t,1})}=\frac{Q_{t}-4\eta w_{t,1}Q_{t}}{1+4\eta(r-w_{t,1})}=Q_{t}\frac{1-4\eta w_{t,1}}{1+4\eta(r-w_{t,1})}.

\frac{1-4\eta w_{t,1}}{1+4\eta(r-w_{t,1})}=1-\frac{4\eta r}{1+4\eta(r-w_{t,1})}\leq 1-\frac{4\eta r}{1+4\eta r}=\frac{1}{1+4\eta r},

r-w_{T+1,1}\leq 2.24de^{-1/3(T-1)}=2.24e^{1/3}e^{-4/3\sqrt{d}+\ln d}\leq 4e^{-4/3\sqrt{d}+\ln d}

To bound

Appendix G
Upper bound for the priming method

The priming method operates as follows
(
Warmuth and Amid, 2023
)
:
First, it computes the least squares estimator

\widehat{\bm{w}}_{LS}=(\bm{X}^{\top}\bm{X})\bm{X}^{\top}\bm{y}
. Then, it scales
each column of
\bm{X}
(each feature)
by the corresponding coordinate of
\widehat{\bm{w}}_{LS}
, resulting in a new matrix

\widetilde{\bm{X}}=\bm{X}\mathrm{diag}(\widehat{\bm{w}}_{LS})
. Next, it calculates the Ridge Regression solution
\widetilde{\bm{w}}_{RR}

using the new inputs
\widetilde{\bm{X}}
and an appropriate regularization constant
\lambda
. The final priming predictor
\widehat{\bm{w}}^{\prime}
is obtained by by multiplying it
by the coordinates of
\widehat{\bm{w}}_{LS}
, that is
\widehat{\bm{w}}^{\prime}=\mathrm{diag}(\widehat{\bm{w}}_{LS})\widetilde{\bm{X}}
.
In the proof we rewrite the priming predictor
\widehat{\bm{w}}^{\prime}
as a regularized least-squares
solution, with the square regularizer based on a matrix
\lambda\mathrm{diag}(\widehat{\bm{w}}_{LS})^{-2}
. Note that the regularization strength is
amplified along directions where the coordinates of
\widehat{\bm{w}}_{LS}
are small in magnitude, effectively biasing the algorithm towards sparse solutions.
The proof carefully bounding the expected error of such a predictor.

Theorem 10
.

Consider the priming method equipped with
\lambda=\sigma^{2}\sqrt{d}
.
The expected error can be bounded by:

e(\widehat{\bm{w}}^{\prime})\leq\frac{17\sigma^{2}}{md}+\frac{32\sigma^{4}}{m^{2}d}+\frac{4\sigma e^{-md/(8\sigma^{2})}}{\sqrt{2\pi md}}.

Note that this upper bound
is by a factor of

O(\log d)

better
(assuming
\sigma^{2}=O(1)
)
than the upper bound for Approximated EGU
±
(and thus
by a factor of
O(d)
better than the error of any rotation invariant algorithm).
However we don’t know whether such an improved upper bound
is also possible for Approximated EGU
±
.

Proof.

We start with rewriting the priming method into a form which is easier to analyze.
Let
\widehat{\bm{w}}_{LS}=(\bm{X}^{\top}\bm{X})\bm{X}^{\top}\bm{y}
be the least-squares solution, which induces
a diagonal weight matrix
\bm{W}=\mathrm{diag}(\widehat{\bm{w}}_{LS}
. The new (rescaled) input matrix
is then given by
\widetilde{\bm{X}}=\bm{X}\bm{W}
. The ridge regression solution
on the new inputs with regularization constant
\lambda
is then

\widetilde{\bm{w}}=(\widetilde{\bm{X}}^{\top}\widetilde{\bm{X}}+\lambda\bm{I}_{d})^{-1}\widetilde{\bm{X}}^{\top}\bm{y}
. Finally the output of the algorithm is
\widehat{\bm{w}}^{\prime}=\bm{W}\widetilde{\bm{w}}
. We thus have

\displaystyle\widehat{\bm{w}}^{\prime}

\displaystyle=\bm{W}(\widetilde{\bm{X}}^{\top}\widetilde{\bm{X}}+\lambda\bm{I}_{d})^{-1}\widetilde{\bm{X}}^{\top}\bm{y}

\displaystyle=\bm{W}(\bm{W}\bm{X}^{\top}\bm{X}\bm{W}+\lambda\bm{I}_{d})^{-1}\bm{W}\bm{X}\bm{y}

\displaystyle=\left(\bm{W}^{-1}(\bm{W}\bm{X}^{\top}\bm{X}\bm{W}+\lambda\bm{I}_{d})\bm{W}^{-1}\right)^{-1}\bm{X}\bm{y}

\displaystyle=\left(\bm{X}^{\top}\bm{X}+\lambda\bm{W}^{-2}\right)^{-1}\bm{X}\bm{y}

(in any of the elements of
\widehat{\bm{w}}_{LS}
is zero, take the limit of the expression above).
Thus,
\widehat{\bm{w}}^{\prime}
is a regularized least-square solution with
the quadratic regularization matrix
\lambda\bm{W}^{-2}
:

\widehat{\bm{w}}^{\prime}=\argmin_{\widehat{\bm{w}}}\left\{\frac{1}{2}\|\bm{y}-\bm{X}\widehat{\bm{w}}\|^{2}+\frac{\lambda}{2}\widehat{\bm{w}}^{\top}\bm{W}^{-2}\widehat{\bm{w}}\right\}.

Note that the regularization strength is
amplified along directions where the coordinates of
\widehat{\bm{w}}_{LS}
are small in
magnitude, effectively biasing the algorithm towards sparse solutions.

We now specialize the priming predictor to our setup. We have

\bm{X}^{\top}\bm{X}=n\bm{I}_{d},\quad\text{and}\quad\bm{X}^{\top}\bm{y}=\bm{X}^{\top}\bm{X}\bm{e}_{1}+\bm{X}^{\top}\bm{\xi}=n\bm{e}_{1}+\sqrt{n}\bm{\zeta},

where
\underset{d}{\bm{\zeta}}=n^{-1/2}\bm{X}^{\top}\bm{\xi}
.
Being a linear function of
\bm{\xi}
,
\bm{\zeta}
has a normal distribution
with parameters that can be obtained from:

\EE[\bm{\zeta}]=n^{-1/2}\bm{X}^{\top}\EE[\bm{\xi}]=\bm{0},\qquad\EE[\bm{\zeta}\bm{\zeta}^{\top}]=n^{-1}\bm{X}^{\top}\EE[\bm{\xi}\bm{\xi}]\bm{X}=n^{-1}\sigma^{2}\bm{X}^{\top}\bm{X}=\sigma^{2}\bm{I}_{d},

that is
\bm{\zeta}\sim\mathcal{N}(\bm{0},\sigma^{2}\bm{I}_{d})
.
This gives us the expression for
\widehat{\bm{w}}_{LS}
:

\widehat{\bm{w}}_{LS}=(\bm{X}^{\top}\bm{X})\bm{X}^{\top}\bm{y}=n^{-1}(n\bm{e}_{1}+\sqrt{n}\bm{\zeta})=\bm{e}_{1}+n^{-1/2}\bm{\zeta},

as well as for
\widehat{\bm{w}}^{\prime}
:

\widehat{\bm{w}}^{\prime}=\left(\bm{X}^{\top}\bm{X}+\lambda\bm{W}^{-2}\right)^{-1}\bm{X}\bm{y}=(n\bm{I}_{d}+\lambda\bm{W}^{-2})^{-1}(n\bm{e}_{1}+\sqrt{n}\bm{\zeta})

We will analyze
\widehat{\bm{w}}^{\prime}
separately for each coordinate
i=1,\ldots,d
. To simplify the notation, let
w_{i}
be the
i
-th coordinate of
\widehat{\bm{w}}^{\prime}
, and let
v_{i}
be the
i
-th coordinate of
\widehat{\bm{w}}_{LS}
. The error of
\widehat{\bm{w}}^{\prime}
is given by:

e(\widehat{\bm{w}}^{\prime})=\|\widehat{\bm{w}}^{\prime}-\bm{e}_{1}\|^{2}=(w_{1}-1)^{2}+\sum_{i=2}^{d}w_{i}^{2}.

As
\bm{W}=\mathrm{diag}(\widehat{\bm{w}}_{LS})
is
diagonal, we have for any
i>1

w_{i}=\frac{\sqrt{n}\zeta_{i}}{n+\lambda v_{i}^{-2}}=\frac{\sqrt{n}v_{i}^{2}\zeta_{i}}{nv_{i}^{2}+\lambda}=\frac{1}{\sqrt{n}}\frac{\zeta_{i}^{3}}{\zeta_{i}^{2}+\lambda},

where we used
v_{i}=n^{-1/2}\zeta_{i}
for
i>1
. Thus the error on the
i
-th coordinate is

w_{i}^{2}=\frac{1}{n}\frac{\zeta_{i}^{6}}{(\zeta_{i}^{2}+\lambda)^{2}}\leq\frac{1}{n}\frac{\zeta_{i}^{6}}{\lambda^{2}}.

Taking expectation over
\zeta_{i}\sim\mathcal{N}(0,\sigma^{2})
and using

\EE[\zeta_{i}^{6}]=15\sigma^{6}
,

\EE[w_{i}^{2}]\leq\frac{15\sigma^{6}}{n\lambda^{2}}.

We now switch to coordinate
i=1
. We have
v_{1}=1+n^{-1/2}\zeta_{1}=n^{-1}(n+\sqrt{n}\zeta_{1})

so that

w_{1}=\frac{n+\sqrt{n}\zeta_{1}}{n+\lambda v_{1}^{2}}=\frac{v_{1}^{2}(n+\sqrt{n}\zeta_{1})}{v_{1}^{2}n+\lambda}=\frac{n^{-2}(n+\sqrt{n}\zeta_{1})^{3}}{n^{-1}(n+\sqrt{n}\zeta_{1})^{2}+\lambda}=\frac{(n+\sqrt{n}\zeta_{1})^{3}}{n(n+\sqrt{n}\zeta_{1})^{2}+n^{2}\lambda}.

The error on the first coordinate is thus

\displaystyle(w_{1}-1)^{2}

\displaystyle=\left(\frac{(n+\sqrt{n}\zeta_{1})^{3}-n(n+\sqrt{n}\zeta_{1})^{2}-n^{2}\lambda}{n(n+\sqrt{n}\zeta_{1})^{2}+n^{2}\lambda}\right)^{2}

\displaystyle=\left(\frac{\sqrt{n}\zeta_{1}(n+\sqrt{n}\zeta_{1})^{2}-n^{2}\lambda}{n(n+\sqrt{n}\zeta_{1})^{2}+n^{2}\lambda}\right)^{2}.

Using
(a+b)\leq 2a^{2}+2b^{2}
in the numerator and
(a+b)\geq a^{2}+b^{2}
for
a,b\geq 0

in the denominator, we bound

\displaystyle(w_{1}-1)^{2}

\displaystyle\leq 2\frac{n\zeta_{1}^{2}(n+\sqrt{n}\zeta_{1})^{4}+n^{4}\lambda^{2}}{(n(n+\sqrt{n}\zeta_{1})^{2}+n^{2}\lambda)^{2}}\leq\frac{2n\zeta_{1}^{2}(n+\sqrt{n}\zeta_{1})^{4}}{n^{2}(n+\sqrt{n}\zeta_{1})^{4}}+\frac{2n^{4}\lambda^{2}}{n^{2}(n+\sqrt{n}\zeta_{1})^{4}+n^{4}\lambda^{2}}

\displaystyle=\frac{2\zeta_{1}^{2}}{n}+\frac{2\lambda^{2}}{(\sqrt{n}+\zeta_{1})^{4}+\lambda^{2}}

We now take expectation with respect
\zeta_{1}
and get:

\EE[(w_{1}-1)^{2}]=\frac{2\sigma^{2}}{n}+\EE\left[2\lambda^{2}((\sqrt{n}+\zeta_{1})^{4}+\lambda^{2})^{-1}\right].

The second term requires more work. Using

f(\zeta_{1})=2\lambda^{2}((\sqrt{n}+\zeta_{1})^{4}+\lambda^{2})^{-1}
:

\displaystyle\EE[f(\zeta_{1})]

\displaystyle=\EE[f(\zeta_{1})|\zeta_{1}\leq c]\,P(\zeta_{1}\leq c)+\EE[f(\zeta_{1})|\zeta_{1}\geq c]\,P(\zeta_{1}\geq c))

\displaystyle\leq P(\zeta_{1}\leq c)\max_{\zeta_{1}\leq c}\{f(\zeta_{1})\}+\max_{\zeta_{1}\geq c}\{f(\zeta_{1})\}.

We take
c=-\sqrt{n}/4
and use a bound
P(Z<-t)\leq\frac{\exp\{-t^{2}/2\}}{\sqrt{2\pi}t}

to get

P(\zeta_{1}\leq-\sqrt{n}/4)=P(Z\leq-\sqrt{n}/(4\sigma))\leq\frac{2\sigma e^{-n/(32\sigma^{2})}}{\sqrt{2\pi n}}.

Moreover,

\max_{\zeta_{1}\leq c}\{f(\zeta_{1})\}\stackrel{{\scriptstyle\zeta_{1}=-\sqrt{n}}}{{=}}=2,\qquad\max_{\zeta_{1}\geq c}\{f(\zeta_{1})\}\stackrel{{\scriptstyle\zeta_{1}=c}}{{=}}=\frac{2\lambda^{2}}{\left(\frac{3}{4}\right)^{4}n^{2}+\lambda^{2}}\leq\frac{2\lambda^{2}}{\left(\frac{3}{4}\right)^{4}n^{2}}\leq\frac{7\lambda^{2}}{n^{4}}

Thus,

\EE[(w_{1}-1)^{2}]\leq\frac{2\sigma^{2}}{n}+\frac{7\lambda^{2}}{n^{2}}+\frac{4\sigma e^{-n/(32\sigma^{2})}}{\sqrt{2\pi n}}.

Taking it all together, we have

\EE[\|\widehat{\bm{w}}^{\prime}-\bm{e}_{1}\|^{2}]\leq(d-1)\frac{15\sigma^{6}}{n\lambda^{2}}+\frac{2\sigma^{2}}{n}+\frac{7\lambda^{2}}{n^{2}}+\frac{4\sigma e^{-n/(32\sigma^{2})}}{\sqrt{2\pi n}}.

Without optimizing too much, we simply take

\lambda^{2}=\sqrt{dn}\sigma^{3}=d\sqrt{m}\sigma^{3}
and get

\displaystyle\EE[e(\widehat{\bm{w}}^{\prime})]

\displaystyle=\EE[\|\widehat{\bm{w}}^{\prime}-\bm{e}_{1}\|^{2}]\leq\frac{2\sigma^{2}}{n}+\frac{22\sigma^{3}\sqrt{d}}{n^{3/2}}+\frac{4\sigma e^{-n/(32\sigma^{2})}}{\sqrt{2\pi n}}

\displaystyle=\frac{2\sigma^{2}}{md}+\frac{22\sigma^{4}}{m^{3/2}d}+\frac{4\sigma e^{-md/(32\sigma^{2})}}{\sqrt{2\pi md}}.

∎

Appendix H
Theorem
5
and EGU equivalences

Proof.

(
Theorem
5
)

For reparameterization we have

\displaystyle{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}

\displaystyle=\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\widehat{\bm{w}}}}}

\displaystyle=-\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\nabla_{\widehat{\bm{w}}}L

\displaystyle=-\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\left(\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\right)^{\top}\nabla_{\bm{w}}L

so the preconditioner is
\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\left(\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\right)^{\top}
.

For MD we have

\displaystyle{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}

\displaystyle=\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\widetilde{\bm{w}}}}}

\displaystyle=-\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}\nabla_{\bm{w}}L

so the preconditioner is
\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}
.

For Riemannian GD the update

\displaystyle{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{\bm{w}}}}

\displaystyle=-\bm{\Gamma}_{\bm{w}}\nabla_{\bm{w}}L

immediately implies the preconditioner is
\bm{\Gamma}_{\bm{w}}^{-1}
.
∎

We now analyze the implications of the theorem for EGU.
EGU is defined by the mirror map (applied componentwise):

f(\bm{w})=\log\bm{w}

This implies

\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}={\rm Diag}(\bm{w})

(39)

Now consider the reparameterization (applied componentwise):

\widehat{\bm{w}}=2\sqrt{\bm{w}}

This implies

\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}=\tfrac{1}{2}{\rm Diag}(\widehat{\bm{w}})

and therefore

\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\left(\frac{\partial\bm{w}}{\partial\widehat{\bm{w}}}\right)^{\top}=\frac{\partial\bm{w}}{\partial\widetilde{\bm{w}}}

as in Theorem
5
. This means continuous-time EGU is equivalent to gradient flow on the spindly network when the two weights are set to be equal, i.e.
w_{i}=u_{i}^{2}
instead of
w_{i}=u_{i}v_{i}
(note that if
\bm{u}
and
\bm{v}
are initialized equally then they will remain equal)
(
Warmuth et al., 2021
)
.

Using (
39
), Theorem
5
also implies EGU is equivalent to Riemannian GD with metric

\bm{\Gamma}_{\bm{w}}={\rm Diag}(\bm{w})^{-1}

(40)

Trajectory derivations

We analyze several algorithms on the regression problem of Sections

The mean loss over the training set is

L(\bm{w})=\frac{1}{md}\|\bm{X}\bm{w}-\bm{y}\|^{2}

Using
\bm{X}^{\top}\bm{X}=md\bm{I}
, the gradient is

\displaystyle\nabla_{\bm{w}}L

\displaystyle=2(\bm{w}-\bm{w}^{\rm LS})

\displaystyle\bm{w}^{\rm LS}

\displaystyle=\frac{1}{md}\bm{X}^{\top}\bm{y}

where
\bm{w}^{\rm LS}
is the linear least-squares solution to which all considered algorithms converge.

The continuous EGU update can be written as

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{w}}}_{i}=-w_{i}\nabla_{w_{i}}L=2w_{i}(w^{\rm LS}_{i}-w_{i})

The trajectory in (
10

w_{i}(0)
satisfied by setting

c_{i}=\tanh^{-1}\left(\frac{2w_{i}(0)}{w^{\rm LS}_{i}}-1\right)

The continuous EGU
\pm

(
Amid and Warmuth, 2020

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{w}}}_{i}=-\sqrt{w_{i}^{2}+1}\,\nabla_{w_{i}}L=2\sqrt{w_{i}^{2}+1}\,(w^{\rm LS}_{i}-w_{i})

The trajectory in (

w_{i}(0)

\displaystyle\tau_{i}

\displaystyle=\sinh^{-1}\left(\frac{1+w^{\rm LS}_{i}w_{i}(0)}{w_{i}(0)-w^{\rm LS}_{i}}\right)+2t\xi\sqrt{(w^{\rm LS}_{i})^{2}+1}

\displaystyle G_{i}

Incremental priming and Burg MD
:
We also consider an incremental version of priming where the learned weights are continuously transferred into the priming vector rather than only once at the end of a pre-training phase.
Specifically, we begin with the predictive model

\widehat{y}_{t}(\bm{x})=(\bm{x}\odot\bm{p}_{t})^{\top}\bm{w}_{t}

where
\bm{p}_{t}
is the priming vector,
\bm{w}_{t}
is the weight vector, and
t
indexes iterations of the learning algorithm. The idea is to maintain
\bm{w}_{t}=\bm{1}
, transferring each update of
\bm{w}
immediately into
\bm{p}
. Specifically, at each time step we make a provisional GD update

\displaystyle\widetilde{\bm{w}}_{t+1}

\displaystyle=\bm{w}_{t}-\eta\nabla_{\bm{w}_{t}}L(\widehat{\bm{y}}_{t}(\bm{X}),\bm{y})

\displaystyle=1+\eta{\rm Diag}(\bm{p}_{t})\bm{X}^{\top}(\bm{y}-\bm{X}\bm{p}_{t})

where the second line uses the inductive assumption
\bm{w}_{t}=\bm{1}
. This assumption holds because we immediately transfer the provisional update into
\bm{p}
:

\displaystyle\bm{p}_{t+1}

\displaystyle=\bm{p}_{t}\odot\widetilde{\bm{w}}_{t+1}

\displaystyle\bm{w}_{t+1}

\displaystyle=\bm{1}

This transfer leaves predictions at step
t+1
unchanged because

(\bm{x}\odot\bm{p}_{t})^{\top}\widetilde{\bm{w}}_{t+1}=(\bm{x}\odot\bm{p}_{t+1})^{\top}\bm{w}_{t+1}
for all
\bm{x}
,
but it leads the learning on step
t+1
to contribute immediately to priming on future steps.

We now simplify the model by dropping the inconsequential
\bm{w}
and directly computing the update for
\bm{p}
:

\displaystyle\widehat{y}_{t}(\bm{x})

\displaystyle=\bm{x}^{\top}\bm{p}_{t}

\displaystyle\bm{p}_{t+1}

\displaystyle=\bm{p}_{t}\odot(1+\eta{\rm Diag}(\bm{p}_{t})\bm{X}^{\top}(\bm{y}-\bm{X}\bm{p}_{t}))

\displaystyle=\bm{p}_{t}-\eta{\rm Diag}(\bm{p}_{t})^{2}\,\nabla_{\bm{p}_{t}}L(\widehat{\bm{y}}_{t}(\bm{X}),\bm{y})

Treating
\bm{p}
as the weight vector, we have a
preconditioned GD algorithm which, by
Theorem
5
, is equivalent in the
continuous-time case to MD with mirror map
f(\bm{p})=-\bm{p}^{-1}
(componentwise). This corresponds to Burg MD

(
Jain et al., 2007
;
Amid and Warmuth, 2020
)
.
(In the discrete time case, incremental priming corresponds
to the “dual update” of Burg MD
(
Warmuth and Jagota, 1998
)
,
\bm{p}_{t+1}=\bm{p}_{t}-\eta\nabla_{f(\bm{p}_{t})}L
instead of
f(\bm{p}_{t+1})=f(\bm{p}_{t})-\eta\nabla_{\bm{p}_{t}}L
.)

Changing notation from
\bm{p}
back to
\bm{w}
, we can write the update as

{\stackrel{{\scriptstyle\scriptscriptstyle\mathbin{\vbox{\hbox{\scalebox{0.42}{$\bullet$}}}}}}{{w}}}_{i}=-w_{i}^{2}\nabla_{w_{i}}L=2w_{i}^{2}(w^{\rm LS}_{i}-w_{i})

This has the solution

\displaystyle w_{i}(t)

\displaystyle=\frac{w^{\rm LS}_{i}}{W\left(\exp\left(-2\left(w^{\rm LS}_{i}\right)^{2}(t-b_{i})\right)\right)+1}

\displaystyle b_{i}

\displaystyle=\frac{1}{2\left(w_{i}^{{\rm LS}}\right)^{2}}\log W^{-1}\left(\frac{w_{i}^{{\rm LS}}}{w_{i}\left(0\right)}-1\right)

where
W
is Lambert’s W function as above. The solution can be verified by substituting it back into the PDE.

Appendix J
Anisotropic covariance

Theorem
2
and the analytic trajectory solutions in Section
3.2
assume spherical input covariance, meaning
\bm{X}^{\top}\bm{X}

is proportional to the identity. When it is not, rotationally invariant
algorithms can produce trajectories that curve toward sparse solutions
under certain circumstances (Figure
4
a). Nevertheless, Theorem 1 implies a rotationally
invariant algorithm cannot perform better on sparse over non-sparse
problems with a rotationally symmetric input distribution, i.e. when averaged over all rotations of
\bm{X}^{\top}\bm{X}
.

For a rotationally invariant algorithm on a linear problem, rotating
the problem rotates the entire weight trajectory:
X\to XU^{\top}

implies
w(t)\to Uw(t)
. This allows us to understand the algorithm’s
behavior with a fixed sparse target
v
and rotated input
XU^{\top}

by examining its behavior with a rotated target
Uv
and fixed input

X
. We illustrate this in Figure
4
for a 2-dimensional
problem with
X=H\,{\rm Diag}\left(2,1\right)
so that
X^{\top}X

has condition number 4. On the left, the first principal component of
\bm{X}^{\top}\bm{X}
is aligned with the sparse target. GD and EGU
\pm
both produce trajectories that bend
toward the target, but for different reasons: GD’s sparsity
bias depends on
\bm{X}
while EGU
\pm
’s does not. This is seen in the right figure where the input is rotated. Rotation invariance
of GD implies its trajectories also rotate, so that it no longer learns efficiently. Thus GD has no sparsity advantage
when averaging over all rotated inputs. In contrast, EGU
\pm
shows
a sparsity bias in all cases. Because it is not rotationally invariant,
rotating the problem does not rotate its trajectories (they are altered but to a much lesser degree).

[Unbalanced covariance]

Figure 4:

GD produces curved trajectories (blue) when the covariance
\bm{X}^{\top}\bm{X}
is nonspherical.
This can speed learning then the first principal component is aligned with the target as in (a).
However, GD and other rotationally invariant algorithms cannot produce a systematic bias toward sparsity. When the input distribution is rotated as in (b), the trajectories rotate as well such that they no longer learn the sparse target efficiently.
