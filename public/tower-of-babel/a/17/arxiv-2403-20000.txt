Computational Complexity of the Recoverable Robust Shortest Path Problem with Discrete Recourse
Marcel Jackiewicz, Adam Kasperski, Paweł Zieliński

Abstract
In this paper the recoverable robust shortest path problem is investigated. Discrete budgeted interval uncertainty representation is used to model uncertain second-stage arc costs. The known complexity results for this problem are strengthened. It is shown that it is Σ 3 p \Sigma_{3}^{p} -hard for the arc exclusion and the arc symmetric difference neighborhoods. Furthermore, it is also proven that the inner adversarial problem for these neighborhoods is Π 2 p \Pi_{2}^{p} -hard.



Keywords
: robust optimization, interval data, recovery, shortest path.

1
Preliminaries

Let
G=(V,A)
be a directed graph with nonnegative arc costs
C_{e}\geq 0
,
e\in A
. Two nodes
s,t\in V
are distinguished as a source and a destination node, respectively. We will use
\Phi
to denote the set of all simple
s-t
paths in
G
. In a shortest path problem we seek a simple
s-t
path in
G
, minimizing the total cost. This classic network optimization problem can be solved in polynomial time by using one of several known algorithms (see, e.g.
[
1
]
). In this paper, we consider a recoverable version of the problem, in which an
s-t
path
X\in\Phi
, called a first-stage path, can be modified to some extent in the second stage by applying a limited recovery action. This action consists in choosing a second-stage path
Y
in some prescribed neighborhood
\Phi(X,k)
of
X
, where
k\geq 0
is a fixed recovery parameter. We will consider the following three types of neighborhoods, called arc inclusion, arc exclusion, and arc symmetric difference neighborhoods, respectively:

\displaystyle\Phi^{\mathrm{incl}}(X,k)

\displaystyle=\{Y\in\Phi\,:\,|Y\setminus X|\leq k\},

(1)

\displaystyle\Phi^{\mathrm{excl}}(X,k)

\displaystyle=\{Y\in\Phi\,:\,|X\setminus Y|\leq k\},

(2)

\displaystyle\Phi^{\mathrm{sym}}(X,k)

\displaystyle=\{Y\in\Phi\,:\,|(Y\setminus X)\cup(X\setminus Y)|\leq k\}

(3)

The cost of the first-stage path
X
is
\sum_{e\in X}C_{e}
. The second-stage arc costs are uncertain while the path
X
is chosen. Let
\hat{c}_{e}
be a nominal second-stage cost of arc
e\in A
and
\Delta_{e}
be a maximum deviation of the second-stage cost of
e
from
\hat{c}_{e}
. Hence,
c_{e}\in[\hat{c}_{e},\hat{c}_{e}+\Delta_{e}]
for each
e\in A
.
In the following, we will assume that each realization of the second-stage arc costs
(c_{e})_{e\in A}
, called scenario, belongs to the following uncertainty set
[
3
]
:

\displaystyle\mathcal{U}(\Gamma)

\displaystyle=\{\boldsymbol{c}=(c_{e})_{e\in A}\,:\,c_{e}\in[\hat{c}_{e},\hat{c}_{e}+\Delta_{e}],e\in A\,:\,|c_{e}>\hat{c}_{e}|\leq\Gamma\}.

(4)

\mathcal{U}(\Gamma)
is called a discrete budgeted uncertainty set and the parameter
\Gamma\in\{0,\dots,|A|\}
is called a discrete budget. It denotes the maximum number of the second-stage arc costs that can differ from their nominal values.
We consider the following recoverable robust shortest path problem with discrete recourse
[
4
,
9
]
:

\textsc{Rec Rob SP}:\;\min_{X\in\Phi}\left(\sum_{e\in X}C_{e}+\max_{\boldsymbol{c}\in\mathcal{U}(\Gamma)}\min_{Y\in\Phi(X,k)}\sum_{e\in Y}c_{e}\right).

(5)

Given a first stage path
X\in\Phi
, we will consider the following adversarial problem:

\textsc{Adv SP}:\;\max_{\boldsymbol{c}\in\mathcal{U}(\Gamma)}\min_{Y\in\Phi(X,k)}\sum_{e\in Y}c_{e}.

(6)

Given additionally a second-stage cost scenario
(c_{e})_{e\in A}
we will consider the following incremental problem:

\textsc{Inc SP}:\;\min_{Y\in\Phi(X,k)}\sum_{e\in Y}c_{e}.

(7)

The
Rob Rec SP
problem was first investigated in
[
4
]
, where it was shown to be strongly NP-hard for the arc inclusion neighborhood. It was shown in
[
5
]
that
Inc SP
for the arc exclusion neighborhood is strongly NP-hard and the same hardness result was established in
[
9
]
for the arc symmetric difference neighborhood. Interestingly, the
Inc SP
problem for the arc inclusion neighborhood can be solved in polynomial time
[
5
]
. The
Adv SP
problem is strongly NP-hard for all considered neighborhoods, which results from a reduction from the most vital arcs problem
[
2
]
(see also
[
9
]
). Because
Adv SP
is a special case of
Rec Rob SP
(we fix
C_{e}=0
for
e\in X
and
C_{e}
to some large number if
e\notin X
), the same hardness result holds for
Rec Rob SP
.

New results

In this paper we strengthen the negative complexity results for
Rec Rob SP
. Namely, we show that the problem is
\Sigma_{3}^{p}
-hard for the arc exclusion and the arc symmetric difference neighborhoods. We also prove that the adversarial problem for these neighborhoods is
\Pi_{2}^{p}
-hard.
