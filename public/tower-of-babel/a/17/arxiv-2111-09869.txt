The exceptional set for integers of the form [ p 1 c ] + [ p 2 c ] [p_{1}^{c}]+[p_{2}^{c}]
Roger Baker

Abstract
. Let 1 < c < 24 / 19 1<c<24/19 . We show that the number of integers n ≤ N n\leq N that cannot be written as [ p 1 c ] + [ p 2 c ] [p_{1}^{c}]+[p_{2}^{c}] ( p 1 p_{1} , p 2 p_{2} primes) is O ⁡ ( N 1 − σ + ε ) O(N^{1-\sigma+\varepsilon}) . Here σ \sigma is a positive function of c c (given explicitly) and ε \varepsilon is an arbitrary positive number.
