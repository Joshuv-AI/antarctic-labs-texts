Theoretical study on the contributions of ω \omega meson to the X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − X(3872)\to J/\psi\pi^{+}\pi^{-} and J / ψ ​ π + ​ π − ​ π 0 J/\psi\pi^{+}\pi^{-}\pi^{0} decays
Hao-Nan Wang, Qian Wang, Ju-Jun Xie

Abstract
With the newly measurements of X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − X(3872)\to J/\psi\pi^{+}\pi^{-} from LHCb Collaboration, in addition to the dominant contribution from the ρ 0 \rho^{0} meson, we perform a theoretical study on the contribution of ω \omega meson in the X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − X(3872)\to J/\psi\pi^{+}\pi^{-} and X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − ​ π 0 X(3872)\to J/\psi\pi^{+}\pi^{-}\pi^{0} processes. It is found that the recent experimental measurements on the π + ​ π − \pi^{+}\pi^{-} invariant mass distributions can be well reproduced, and the ratio of the couplings between X ⁡ ( 3872 ) → J / ψ ​ ρ 0 X(3872)\to J/\psi\rho^{0} and X ⁡ ( 3872 ) → J / ψ ​ ω X(3872)\to J/\psi\omega is also evaluated. Within the parameters extracted from the π + ​ π − \pi^{+}\pi^{-} invariant mass distributions of the X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − X(3872)\to J/\psi\pi^{+}\pi^{-} process, the branching fractions of the X ⁡ ( 3872 ) → J / ψ ​ ω X(3872)\to J/\psi\omega channel relative to that of the X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − ​ π 0 X(3872)\to J/\psi\pi^{+}\pi^{-}\pi^{0} channel and the π + ​ π − ​ π 0 \pi^{+}\pi^{-}\pi^{0} invariant mass distributions of the X ⁡ ( 3872 ) → J / ψ ​ π + ​ π − ​ π 0 X(3872)\to J/\psi\pi^{+}\pi^{-}\pi^{0} decay are calculated, which gives a hint for the further high-statistic experiment.

Introduction

In 2003, the

II
formalism

The effective Lagrangian method is an useful tool in describing the various processes around the resonance region. The model used in the present work can give a reasonable description of the experimental data for the
X(3872)\to J/\psi\pi^{+}\pi^{-}
decay, and our calculation offers some important clues for the mechanisms of the decays of
X(3872)\to J/\psi\pi^{+}\pi^{-}
and
J/\psi\pi^{+}\pi^{-}\pi^{0}
. In this section, we introduce the theoretical formalism and ingredients to study the
X(3872)\to J/\psi\pi^{+}\pi^{-}
and
X(3872)\to J/\psi\pi^{+}\pi^{-}\pi^{0}
decays by using the effective Lagrangian method.

IV
Summary

In summary, we have performed a theoretical calculation for the processes of
X(3872)\to J/\psi\pi^{+}\pi^{-}
and
J/\psi\pi^{+}\pi^{-}\pi^{0}
. For the
X(3872)\to J/\psi\pi^{+}\pi^{-}
decay, in addition to the dominant contribution from the
\rho^{0}
meson, the contribution of the intermediate
\omega
meson with an effective
\omega\pi\pi
coupling is also considered in our framework. It is found that the recent LHCb experimental measurements on the
\pi^{+}\pi^{-}
invariant mass distributions
LHCb:2022bly
can be well reproduced. Meanwhile, the ratio of the couplings between
X(3872)\to J/\psi\rho^{0}
and
X(3872)\to J/\psi\omega
is determined, which is consistent with the previous analysis in Refs.
Hanhart:2011tn
;
LHCb:2022bly
.

Furthermore, with the model parameters determined from the
\pi^{+}\pi^{-}
invariant mass distribution of the
X(3872)\to J/\psi\pi^{+}\pi^{-}
decay, the
X(3872)\to J/\psi\pi^{+}\pi^{-}\pi^{0}
branching fraction and the corresponding
\pi^{+}\pi^{-}\pi^{0}
invariant mass distributions are extracted, which are also in agreement with the available experimental data with large errors. This kind of results could be tested by the future precise measurements.
