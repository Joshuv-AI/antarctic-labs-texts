Codes for the Z-channel
Nikita Polyanskii, and Yihan Zhang

Abstract
This paper is a collection of results on combinatorial properties of codes for the Z-channel . A Z-channel with error fraction τ \tau takes as input a length- n n binary codeword and injects in an adversarial manner up to n ​ τ n\tau asymmetric errors, i.e., errors that only zero out bits but do not flip 0 0 ’s to 1 1 ’s. It is known that the largest ( L − 1 ) (L-1) -list-decodable code for the Z-channel with error fraction τ \tau has exponential size (in n n ) if τ \tau is less than a critical value that we call the ( L − 1 ) (L-1) -list-decoding Plotkin point and has constant size if τ \tau is larger than the threshold. The ( L − 1 ) (L-1) -list-decoding Plotkin point is known to be L − 1 L − 1 − L − L L − 1 L^{-\frac{1}{L-1}}-L^{-\frac{L}{L-1}} , which equals 1 / 4 1/4 for unique-decoding with L − 1 = 1 L-1=1 . In this paper, we derive various results for the size of the largest codes above and below the list-decoding Plotkin point. In particular, we show that the largest ( L − 1 ) (L-1) -list-decodable code ε \varepsilon -above the Plotkin point, for any given sufficiently small positive constant ε > 0 \varepsilon>0 , has size Θ L ( ε − 3 / 2 ) \Theta_{L}(\varepsilon^{-3/2}) for any L − 1 ≥ 1 L-1\geq 1 . We also devise upper and lower bounds on the exponential size of codes below the list-decoding Plotkin point.

In coding theory, the Z-channel is used to model some asymmetric data storage and transmission systems. In this binary-input binary-output channel, the symbol
0

II
Overview of our results and techniques

This paper is a collection of results on combinatorial properties of codes for the Z-channel with adversarial errors.
The most technically challenging part of our results has to do with obtaining the order-optimal size of codes that correct a fraction of asymmetric errors
\varepsilon
-above
the Plotkin point.
We start with the unique-decoding case and show in Sec.
V
that the optimal size of codes which correct
1/4+\varepsilon
fraction of asymmetric errors is exactly
\Theta(\varepsilon^{-3/2})
.
This follows from an upper bound (Theorem
4
in Sec.
V-A
) and a matching construction (Theorem
5
in Sec.
V-B
).
We then generalize these results to list-decoding for any list size at least one.
We show in Sec.
VI-C
-
VI-G
that the same bound
\Theta_{L}(\varepsilon^{-3/2})
is also optimal for list-decodable codes which correct
\tau_{L}+\varepsilon
fraction of asymmetric errors, where
\tau_{L}
is the list-decoding Plotkin point.
See Sec.
VI-A
and
VI-B
for definitions and properties of the list-decoding radius and list-decoding Plotkin point.

We briefly explain below the ideas behind our results on codes that correct a fraction of errors beyond the Plotkin bound.

1.

(Upper bound for (approximate) constant-weight codes.) For
constant-weight
codes (i.e., a code in which all codewords have the same Hamming weight; see
[
GS80
]
), it follows from a standard double-counting argument that the size of any code
\varepsilon
-above the Plotkin point (i.e.,
1/4
) is at most
O_{L}(\varepsilon^{-1})
.
For unique-decoding, this is known by
[
Plo60
]
;
for list-decoding, this follows from
[
LLP22
]
(see Theorem
6
in Sec.
VI-C
).
Furthermore, these results can be extended to
approximate constant-weight
codes (i.e., a code in which all codewords have
approximately
the same Hamming weight).
This can be done by either repeating the double-counting argument with additional care of the deviation in weights or carefully augmenting the codewords in such a way that the augmented codewords all have the same weight.
See Theorem
8
and
9
in Sec.
VI-E
for details.

2.

(Upper bound for general codes.) For
general
codes in which codewords can have any weight between
0
and
n
, given the above results, it is tempting to partition
\{0,1\}^{n}
into
\varepsilon^{-1}
slices each of weight between
nw
and
n(w+\varepsilon)
for some
w\in[0,1]
.
The subcode in each slice is therefore approximate constant-weight and has size at most
O_{L}(\varepsilon^{-1})
.
In total, we get an upper bound
O_{L}(\varepsilon^{-2})
on the size of the whole code.
However, this bound turns out to be suboptimal!
We improve it by partitioning the space in a more delicate way.
The width of the slice is wider for weights far from the critical (relative) weight
w_{\max}=L^{-\frac{1}{L-1}}
and is thinner for (relative) weights close to
w_{\max}
.
4
4

4

For the convenience of discussion, we refer “weight” to the Hamming weight (i.e., number of nonzero coordinates) or the relative Hamming weight (i.e., fraction of nonzero coordinates).
Without further clarification, the meaning shall be clear from the context.

In particular, we choose the width to be
\varepsilon^{1/2}
on average for
w\in[0,w_{\max}-\Omega_{L}(\varepsilon^{1/2})]\cup[w_{\max}+\Omega_{L}(\varepsilon^{1/2}),1]
and we choose it to be
\varepsilon
for
w\in[w_{\max}-O_{L}(\varepsilon^{1/2}),w_{\max}+O_{L}(\varepsilon^{1/2})]
, while keeping the subcode in each slice having size
O_{L}(\varepsilon^{-1})
.
In total, there are at most
O_{L}(1/\varepsilon^{1/2})=O_{L}(\varepsilon^{-1/2})
slices for small and large weights (i.e., weights far from
w_{\max}
) and at most
O_{L}(\varepsilon^{1/2}/\varepsilon)=O_{L}(\varepsilon^{-1/2})
slices for moderate weights (i.e., weights close to
w_{\max}
).
This gives an improved upper bound
O_{L}(\varepsilon^{-1/2}\varepsilon^{-1})=O_{L}(\varepsilon^{-3/2})
on the size of the whole code.
The rigorous analyses for
L=2
and
L>2
are presented in the proofs of Theorem
4
in Sec.
V-A
and Theorem
10
in Sec.
VI-F
, respectively.

3.

(Construction of constant-weight codes.) In Sec.
VI-D
, we analyze a code formed by rows of a matrix whose columns are all possible constant-weight words. In Theorem
7
, such a code is shown to be
\varepsilon
-above the list-decoding Plotkin point and have order-optimal size
\Omega_{L}(\varepsilon^{-1})
. This code generalizes a construction proposed in
[
ABP18
]
in the context of list-decodable codes for symmetric errors and has a similar flavour as weak-flip codes discussed in
[
LMC18
]
.

4.

(Construction of general codes.) We note that purely random codes that correct a fraction of errors larger than the Plotkin bound do not have large size. However, we show how to use randomness in order to build a code
\varepsilon
-above the Plotkin point of size
\Omega_{L}(\varepsilon^{-3/2})
. The non-uniform partition used in the proof of the converse bound suggests a matching construction.
We reuse the constant-weight construction in Theorem
7
in a consistent way with the non-uniform partition. Specifically, we first build
\Theta_{L}(\varepsilon^{-1/2})
constant-weight codes such that the
i
th code has size
\Theta_{L}(\varepsilon^{-1})
and contains codewords with relative weight
w_{\max}-i\varepsilon

\Theta_{L}(\varepsilon^{-1/2})
independent random permutations on the set of coordinates within each code and consider the union of all these codes. For
L=2
, we carefully analyze the unique-decoding radius of the resulting construction in the proof of Theorem
5
in Sec.
V-B
. For
L>2
, we investigate the list-decoding radius of our construction in the proof of Theorem
12

In Sec.
VII-A
and
VII-B

below
the list-decoding Plotkin point and obtain upper and lower bounds on the list-decoding capacity.
The upper bound in Theorem
15

[
Bas65

17

The question of obtaining the exact list-decoding capacity for arbitrary list sizes is difficult and our upper and lower bounds do not match.
However, we manage to derive the list-decoding capacity for asymptotically large list sizes in Theorem
20

VII-C

Sec.

This is a direct consequence of the seminal channel coding theorem by Shannon

We end the paper with open questions in Sec.

Preliminaries

We use the standard Bachmann–Landau notation.
For a set
\mathcal{S}
and an integer
0\leq t\leq|\mathcal{S}|
,
\binom{\mathcal{S}}{t}\coloneqq\{\mathcal{S}^{\prime}\subset\mathcal{S}:|\mathcal{S}^{\prime}|=t\}
.
The set
\{i,i+1,\ldots,j\}
for some integers
i
and
j
with
i\leq j
will be denoted as
[i,j]
. The set
[1,j]
is shortly denoted as
[j]
. By slight abuse of notation, we write
[w_{1},w_{2}]
to also denote the closed interval of real numbers between
w_{1}
and
w_{2}
. A vector of length
n
is denoted by bold lowercase letters, such as
\boldsymbol{x}
,
and the
i
th entry of the vector
\boldsymbol{x}
is referred to as
x_{i}
. The all-zero vector, whose length will be clear from the context, is written as
\boldsymbol{0}
. Define the asymmetric function
\Delta(\boldsymbol{x},\boldsymbol{y})
to be the number of positions
i\in[n]
such that
x_{i}=1
and
y_{i}=0
. The Hamming distance between
\boldsymbol{x},\boldsymbol{y}\in\{0,1\}^{n}
is then
d_{\mathrm{H}}(\boldsymbol{x},\boldsymbol{y}):=\Delta(\boldsymbol{x},\boldsymbol{y})+\Delta(\boldsymbol{y},\boldsymbol{x})
. The (Hamming) weight of
\boldsymbol{x}\in\{0,1\}^{n}
is
\textrm{wt}(\boldsymbol{x}):=d_{\mathrm{H}}(\boldsymbol{x},\boldsymbol{0})
; the relative weight is
\textrm{wt}(\boldsymbol{x})/n
.
The
Z-distance
between
\boldsymbol{x},\boldsymbol{y}\in\{0,1\}^{n}
is defined as
d_{\mathrm{Z}}(\boldsymbol{x},\boldsymbol{y})\coloneqq\max(\Delta(\boldsymbol{x},\boldsymbol{y}),\Delta(\boldsymbol{y},\boldsymbol{x}))
.
Note that the Hamming distance and the Z-distance are related by the following identity:
d_{\mathrm{Z}}(\boldsymbol{x},\boldsymbol{y})=\frac{1}{2}(d_{\mathrm{H}}(\boldsymbol{x},\boldsymbol{y})+|\textrm{wt}(\boldsymbol{x})-\textrm{wt}(\boldsymbol{y})|)
.
By this relation, we see that
d_{\mathrm{Z}}(\cdot,\cdot)
is indeed a distance, and it equals
d_{\mathrm{H}}(\cdot,\cdot)/2
if the Hamming weights of
\boldsymbol{x}
and
\boldsymbol{y}
are the same.
Define the

and the

centered at
\boldsymbol{x}\in\{0,1\}^{n}
with radius

\displaystyle B^{\text{Z}}_{t}(\boldsymbol{x})

\displaystyle\coloneqq\{\boldsymbol{y}\in\{0,1\}^{n}:\ \Delta(\boldsymbol{y},\boldsymbol{x})=0,\ \Delta(\boldsymbol{x},\boldsymbol{y})\leq t\},

\displaystyle B^{\text{H}}_{t}(\boldsymbol{x})

\displaystyle\coloneqq\{\boldsymbol{y}\in\{0,1\}^{n}:\ d_{\mathrm{H}}(\boldsymbol{x},\boldsymbol{y})\leq t\}.

Similarly, define the

and the

centered at
\boldsymbol{x}\in\{0,1\}^{n}
with radius

\displaystyle S^{\mathrm{Z}}_{t}(\boldsymbol{x})

\displaystyle\coloneqq\{\boldsymbol{y}\in\{0,1\}^{n}:\ \Delta(\boldsymbol{y},\boldsymbol{x})=0,\ \Delta(\boldsymbol{x},\boldsymbol{y})=t\},

\displaystyle S^{\mathrm{H}}_{t}(\boldsymbol{x})

\displaystyle\coloneqq\{\boldsymbol{y}\in\{0,1\}^{n}:\ d_{\mathrm{H}}(\boldsymbol{x},\boldsymbol{y})=t\}.

A (binary block)

\mathcal{C}\subseteq\{0,1\}^{n}

The

Remark 1

With a slight abuse of terminology, we will interchangeably use weight/distance/radius to refer to

Without further specification, the exact meaning should be clear from the context.

Definition 1

(Uniquely-decodable code)
.

We say that a code
\mathcal{C}\subseteq\{0,1\}^{n}

\boldsymbol{x}\in\{0,1\}^{n}

(

Note that a code
\mathcal{C}

; see, e.g.,
[

]

A code

t

.

-constant-weight and correct
t
symmetric errors. If the inequality
w^{2}-(w-t)n>0
is fulfilled, then the size of
\mathcal{C}
is bounded above as follows

|\mathcal{C}|\leq\frac{tn}{w^{2}-(w-t)n}.

We introduce below the concept of list-decodable codes.

Definition 2

(List-decodable code)
.

Let
L
be a positive integer at least
2
.
A code
\mathcal{C}\subseteq\{0,1\}^{n}
is said to be
(L-1)
-list-decodable with list-decoding radius
\tau
if for any
\boldsymbol{x}\in\{0,1\}^{n}
the respective Z-ball (H-ball) centered at
\boldsymbol{x}
with radius
t:=\lceil\tau n\rceil
contains at most
L-1
codewords from
\mathcal{C}
, i.e., it holds that
|B^{\text{Z}}_{t}(\boldsymbol{x})\cap\mathcal{C}|\leq L-1
(
|B^{\text{H}}_{t}(\boldsymbol{x})\cap\mathcal{C}|\leq L-1
).

At last, we need the binary entropy function defined as
H(x)\coloneqq-x\log x-(1-x)\log(1-x)
for any
x\in[0,1]
.

V
Uniquely-decodable codes above the Plotkin point

In this section, we obtain upper and lower bounds on the size of an optimal code capable of correcting a fraction
\tau=\frac{1}{4}+\varepsilon
of asymmetric errors. For simplicity of arguments, we naturally assume in this section that if an
n

\tau=\frac{1}{4}+\varepsilon
of errors, then
\tau n=n/4+\varepsilon n
is an integer and, consequently,
\varepsilon n\geq 1/4
.

V-A

Upper bound

In the following statement, we derive an upper bound on the size of a code capable of correcting a large fraction of asymmetric errors. The idea of the proof is to partition a code into
O(\varepsilon^{-1/2})
subcodes with approximate constant-weight. By lengthening codewords within each subcode, we obtain constant-weight codes correcting a large fraction of symmetric errors and show that their size can be bounded by
O(\varepsilon^{-1})
.

Theorem 4
.

Let
\mathcal{C}\subseteq\{0,1\}^{n}
be a code correcting a fraction
\tau=\frac{1}{4}+\varepsilon
of asymmetric errors for some real number
\varepsilon\leq 1/12
, where
\tau n
is an integer. Then the size of the code can be bounded as follows

|\mathcal{C}|\leq\frac{1+3\sqrt{\varepsilon}+4\varepsilon}{\varepsilon^{3/2}}+14.

(In fact, we proved the upper bound

During the finalization of the current manuscript, the first author updated the other manuscript

V-B

Construction

In the following statement, we prove that there exists a code of size
\Omega(\varepsilon^{-3/2})
and length
\exp(\Theta(\varepsilon^{-3/2}))
capable of correcting a fraction
1/4+\varepsilon
of asymmetric errors. We use the intuition from the proof of Theorem
4
. First, we build
O(\varepsilon^{-1/2})
codes such that the
j
th code is a uniquely-decodable code containing codewords with the relative weight
\frac{1}{2}-j\varepsilon
. We borrow an idea for such code with

from
[

]
, where the authors constructed list-decodable codes for symmetric errors. By performing simple repetition, we construct longer codes of the same size while the error-correction capability of all those codes remains unchanged. Applying a random permutation on the set of coordinates within each code, we guarantee that two codewords from different codes have a large asymmetric distance with overwhelming probability.

Theorem 5
.

There exists a code of length
\exp(O(\varepsilon^{-3/2}))
, capable of correcting a fraction
\tau=\frac{1}{4}+\varepsilon
of asymmetric errors. Furthermore, its size is at least
\frac{3\sqrt{3}}{128}\varepsilon^{-3/2}(1+o(1))
as
\varepsilon\to 0
.

Proof.

Consider the positive integer
m:=\lfloor 3/(32\varepsilon)\rfloor
and define the real number
c:=2^{-3/2}
. For every
j\in\{-\lfloor c\sqrt{m}\rfloor,\ldots,\lfloor c\sqrt{m}\rfloor\}
, denote
n_{j}:=\binom{2m}{m-j}
. Consider a binary matrix
A_{j}
of size
2m\times n_{j}
, whose columns are all possible binary vectors of length
2m
and weight
m-j
. For two distinct rows
\boldsymbol{x}
and
\boldsymbol{y}
of matrix

, we compute the number of positions in which the rows are different.
We have

\Delta(\boldsymbol{x},\boldsymbol{y})=\Delta(\boldsymbol{y},\boldsymbol{x})=\binom{2m-2}{m-j-1}.

This means that a code, whose codewords are rows of
A_{j}
, corrects a fraction
\tau_{j}
of asymmetric errors, where

\tau_{j}:=\frac{\binom{2m-2}{m-j-1}-1}{\binom{2m}{m-j}}=\frac{(m-j)(m+j)}{2m(2m-1)}-\frac{1}{\binom{2m}{m-j}}=\frac{1}{4}+\frac{m/2-j^{2}}{4m^{2}-2m}-\frac{1}{\binom{2m}{m-j}}.

Let us show that for small enough
\varepsilon
, it holds that

. We have

\displaystyle\frac{m/2-j^{2}}{4m^{2}-2m}-\frac{1}{\binom{2m}{m-j}}

\displaystyle\geq\frac{m/2-c^{2}m}{4m^{2}-2m}-\frac{1}{\binom{2m}{m-\lfloor c\sqrt{m}\rfloor}}

\displaystyle=\frac{3}{32m-16}-\frac{1}{\binom{2m}{m-\lfloor c\sqrt{m}\rfloor}}

\displaystyle=\frac{3}{32m}+\frac{3}{2m(32m-16)}-\frac{1}{\binom{2m}{m-\lfloor c\sqrt{m}\rfloor}}

\displaystyle\geq\varepsilon.

To show the last inequality, we used that
m=\lfloor 3/(32\varepsilon)\rfloor
,
c=2^{-3/2}
and the fact that for sufficiently large
m
(small
\varepsilon
), it holds

\frac{3}{64m^{2}}>\frac{1}{\binom{2m}{m-\lfloor c\sqrt{m}\rfloor}}.

For a positive integer
z
, consider a matrix
A_{j}^{(z)}
of size
2m\times zn_{j}
which is composed of
z

A_{j}
. We write copies of

to the right, i.e.,
A_{j}^{(z)}=(A_{j},A_{j},\ldots,A_{j})
. By
\tilde{A}_{j}^{(z)}

by applying a random permutation of its columns. This permutation is taken uniformly at random from the set of all permutations. Note that a code whose codewords are rows of
\tilde{A}_{j}^{(z)}
corrects the same fraction of errors as the original code obtained from
A_{j}
. Define integers

z_{j}:=\prod_{\begin{subarray}{c}i=-\lfloor c\sqrt{m}\rfloor,\\
i\neq j\end{subarray}}^{\lfloor c\sqrt{m}\rfloor}\binom{2m}{m-i},\quad N:=\prod_{\begin{subarray}{c}i=-\lfloor c\sqrt{m}\rfloor\end{subarray}}^{\lfloor c\sqrt{m}\rfloor}\binom{2m}{m-i},\quad M:=2m(2\lfloor c\sqrt{m}\rfloor+1).

Consider a random matrix
A
of size
M\times N
containing
\tilde{A}_{j}^{(z_{j})}
as a submatrix for all

. We assume that matrices
\tilde{A}_{j}^{(z_{j})}
are written one below the other using the ascending order of parameter
j
. For
\varepsilon\to 0
, we estimate the number of rows
M
and the number of columns

M=\frac{3\sqrt{3}}{128\varepsilon\sqrt{\varepsilon}}(1+o(1)),\quad N=\exp(\Theta(\varepsilon^{-3/2})).

Define the random code
\mathcal{C}
of length
N
and size
M
to be the set of rows in
A
. Let us show that for two distinct rows
\tilde{\boldsymbol{x}}
and
\tilde{\boldsymbol{y}}
in
A
, the value

is large enough with overwhelming probability. The latter ensures that the code

can correct the required fraction of asymmetric errors. More formally, let
\tilde{\boldsymbol{x}}
and

be rows from

\Pr\{\Delta(\tilde{\boldsymbol{x}},\tilde{\boldsymbol{y}})=t\}=\begin{cases}\frac{\binom{\textrm{wt}(\tilde{\boldsymbol{x}})}{t}\binom{N-\textrm{wt}(\tilde{\boldsymbol{x}})}{\textrm{wt}(\tilde{\boldsymbol{y}})-\textrm{wt}(\tilde{\boldsymbol{x}})+t}}{\binom{N}{\textrm{wt}(\tilde{\boldsymbol{y}})}},\quad&\text{for }t\in\left\{\textrm{wt}(\tilde{\boldsymbol{x}})-\textrm{wt}(\tilde{\boldsymbol{y}}),\ldots,\min\left(\textrm{wt}(\tilde{\boldsymbol{x}}),N-\textrm{wt}(\tilde{\boldsymbol{y}})\right)\right\},\\
0,\quad&\text{otherwise.}\end{cases}

We estimate the probability of the event that
\Delta(\tilde{\boldsymbol{x}},\tilde{\boldsymbol{y}})

is small as follows

\Pr\left\{\Delta(\tilde{\boldsymbol{x}},\tilde{\boldsymbol{y}})\leq N\left(\frac{1}{4}+\varepsilon\right)\right\}\leq N\max\limits_{t\in[0,\lfloor N(\frac{1}{4}+\varepsilon)\rfloor]}\Pr\left\{\Delta(\tilde{\boldsymbol{x}},\tilde{\boldsymbol{y}})=t\right\}.

(4)

Let an integer
t
be equal to
\alpha N
for some real number

For arbitrary integers

\sqrt{\frac{u}{8v(u-v)}}2^{uH(v/u)}\leq\binom{u}{v}\leq 2^{uH(v/u)}.

\displaystyle g_{i,j}(\alpha,\varepsilon)

\displaystyle\leq\frac{m-j}{2m}H\left(\frac{2\alpha m}{m-j}\right)+\frac{m+j}{2m}H\left(\frac{j-i+2\alpha m}{m+j}\right)-H\left(\frac{m-i}{2m}\right)-\frac{\log\left(\frac{m^{2}}{2(m-i)(m+i)N}\right)}{2N}

is positive for

, we get that

\sup_{\frac{i-j}{2m}<\alpha\leq\frac{1}{4}+\varepsilon}g_{i,j}(\alpha,\varepsilon)\leq r_{i,j}(1/4+\varepsilon,\varepsilon)+\delta(\varepsilon).

(5)

Observe that we have the partial sum of the Taylor series with the remainder in Lagrange’s form

\displaystyle=\log\left(1+\frac{mi-4\varepsilon m^{2}-jm-ji}{(m/2+2\varepsilon m)(m/2+j-i+2\varepsilon m)}\right)

\displaystyle=4\log e\frac{m(i-j)-4\varepsilon m^{2}-ji}{m^{2}}(1+o(1)).

\displaystyle=-\left(\alpha_{i,j}-\frac{1}{4}-\varepsilon\right)\left(\frac{m(i-j)-4\varepsilon m^{2}-ji}{m^{2}}(4\log e-2\log e)\right)(1+o(1))

VI
List-decodable codes above the Plotkin point

VI-A

List-decoding radius

Fix
L\in\mathbb{Z}_{\geq 2}
.
For an
L
-list
\mathcal{L}\coloneqq\{\boldsymbol{x}_{1},\cdots,\boldsymbol{x}_{L}\}\in\binom{\{0,1\}^{n}}{L}
of distinct vectors, define its
Chebyshev radius
with respect to Z-distance as the smallest
t
such that all sequences in
\mathcal{L}
are contained in a Z-ball of radius
t
:

\displaystyle\mathrm{rad}(\mathcal{L})

\displaystyle\coloneqq\min\{t\in\{0,1,\ldots,n\}:\exists\boldsymbol{y}\in\{0,1\}^{n},\,\mathcal{L}\subset B_{t}^{\mathrm{Z}}(\boldsymbol{y})\}.

(7)

In other words,
\mathrm{rad}(\mathcal{L})
is the smallest number of asymmetric errors that are sufficient to change all sequences in
\mathcal{L}
to a same sequence
\boldsymbol{y}
.
Let
\mathcal{C}\subseteq\{0,1\}^{n}
be an arbitrary code for the Z-channel.
The
(L-1)
-list-decoding radius

\tau_{L}(\mathcal{C})
of
\mathcal{C}
is defined as

\displaystyle\tau_{L}(\mathcal{C})

\displaystyle\coloneqq\min_{\mathcal{L}\in\binom{\mathcal{C}}{L}}\mathrm{rad}(\mathcal{L}).

It is easy to see that the minimum in the definition of
\mathrm{rad}(\mathcal{L})

Remark 5
.

Readers who are familiar with the literature may have noticed that unlike results for symmetric errors
[
Bli86
,
ABP18
]
, to prove Theorem

The benefit of the Ramsey reduction is that the Chebyshev radius of the subcode turns out to be (approximately) the same as another stronger notion of radius called “average radius”.
The average radius is analytically much easier to deal with since unlike the Chebyshev radius, it does not involve a minimax expression.
However, the drawback is that the size of the subcode is much smaller than the original one.
The optimal size of codes correcting a fraction of symmetric errors above the Plotkin bound remains open.

The reason why in Theorem
8
we did not need Ramsey reduction while still managed to obtain the optimal bound on the code sizes is as follows.
For asymmetric errors, the Chebyshev radius of (approximate) constant-weight codes admits an explicit expression since the Chebyshev center (i.e., the minimizer
\boldsymbol{y}
in Eqn. (
7
)) can be easily identified with Eqn. (
8
).
Note, however, that in the symmetric case there is no simple formula for the Chebyshev center.

\displaystyle\geq w_{\max}-w_{\max}^{L}+w_{\max}^{L}\left(1-\frac{LD_{L}}{iw_{\max}}+\frac{LD_{L}^{2}}{2i^{2}w_{\max}^{2}}\right)+C_{L}\varepsilon

\displaystyle\geq w_{\max}-\frac{D_{L}}{i+1}-\frac{D_{L}}{i(i+1)}+\frac{D_{L}^{2}}{2w_{\max}i^{2}}+C_{L}\varepsilon.

Note that for

Define the subcode

that includes all codewords of

with the Hamming weight within the range
[0,n(w_{\max}-D_{L}\varepsilon^{1/2})]

Large weight

\displaystyle x_{i+1}

\displaystyle\geq w_{\max}-w_{\max}^{L}+\left(w_{\max}+\frac{E_{L}}{\varepsilon^{-1/2}+1-i}\right)^{L}+C_{L}\varepsilon

\displaystyle=w_{\max}-w_{\max}^{L}+w_{\max}^{L}\left(1+\frac{2E_{L}}{w_{\max}(\varepsilon^{-1/2}+1-i)}+\frac{E_{L}^{2}}{w_{\max}^{2}(\varepsilon^{-1/2}+1-i)^{2}}\right)^{L/2}+C_{L}\varepsilon

\displaystyle\geq w_{\max}+\frac{E_{L}}{\varepsilon^{-1/2}+1-i}+\frac{E_{L}^{2}}{2w_{\max}(\varepsilon^{-1/2}+1-i)^{2}}+C_{L}\varepsilon

\displaystyle=w_{\max}+\frac{E_{L}}{\varepsilon^{-1/2}-i}+\frac{E_{L}}{(\varepsilon^{-1/2}+1-i)(\varepsilon^{-1/2}-i)}+\frac{E_{L}^{2}}{2w_{\max}(\varepsilon^{-1/2}+1-i)^{2}}+C_{L}\varepsilon.

Observe that the sum of the last three terms is non-negative for

Define the subcode
\mathcal{C}^{\prime\prime}\subseteq\mathcal{C}
that includes all codewords of
\mathcal{C}
with the Hamming weight within the range
[n(w_{\max}+D_{L}\varepsilon^{1/2}),n]

is
O_{L}(\varepsilon^{-3/2})
.

Moderate weight
|w_{1}-w_{\max}|=O_{L}(\sqrt{\varepsilon})
:
By Corollary

subcodes such that each of them has size
O_{L}(\varepsilon^{-1})
.

Summing up the above discussion, we conclude that the size of

can be bounded as

as

.
∎

\displaystyle\Pr\left\{\tilde{W}\geq\gamma+\prod_{i=1}^{L}w_{i}\right\}

\displaystyle\leq

\displaystyle\frac{\Pr\left\{\overline{W}\geq\gamma+\prod_{i=1}^{L}w_{i}\right\}}{\Pr\left\{A_{1}\cap\ldots\cap A_{L}\right\}}

\displaystyle 1-\Pr\left\{A_{1}\cap\ldots\cap A_{L}\right\}+\Pr\left\{\mathsf{Bin}(N,w^{\prime})\geq N\left(\gamma+\prod_{i=1}^{L}w_{i}\right)\right\},

\displaystyle\Pr\{\exists\boldsymbol{x}\in S^{\mathrm{H}}_{nw}(\boldsymbol{0}),\;\forall\boldsymbol{u}\in\mathcal{D},\;T_{\boldsymbol{u},\boldsymbol{x}}\neq P_{U,X}\}

\displaystyle\leq\sum_{\boldsymbol{x}\in S^{\mathrm{H}}_{nw}(\boldsymbol{0})}\prod_{\boldsymbol{u}\in\mathcal{D}}(1-\Pr\{T_{\boldsymbol{u},\boldsymbol{x}}=P_{U,X}\})

\displaystyle=\sum_{\boldsymbol{x}\in S^{\mathrm{H}}_{nw}(\boldsymbol{0})}\prod_{\boldsymbol{u}\in\mathcal{D}}\left(1-\frac{\binom{n(1-w)}{n(v-a)}\binom{nw}{na}}{\binom{n}{nv}}\right)

\displaystyle=\binom{n}{nw}\left(1-2^{n(1-w)H\left(\frac{v-a}{1-w}\right)+nwH\left(\frac{a}{w}\right)-nH(v)+o(n)}\right)^{M}

\displaystyle\leq 2^{nH(w)}\left(1-2^{nI(w,v,a)+o(n)}\right)^{2^{nI(w,v,a)}2^{n\varepsilon}}

\displaystyle\xrightarrow{n\to\infty}2^{nH(w)}e^{-2^{n\varepsilon}}

(20)

\displaystyle=e^{-2^{n\varepsilon}+O_{L}(n)}.

In Eqn. (
20
), we used the fact
\lim\limits_{n\to\infty}(1-1/n)^{n}=1/e
.
Therefore, with probability at least
1-e^{-2^{\Omega(n)}}
,
\mathcal{D}
is a covering of
S^{\mathrm{H}}_{nw}(\boldsymbol{0})
with respect to
P_{U,X}
.
This finishes the proof of the lemma.
∎

We are now ready to prove the upper bound which reads as follows.

Theorem 15
.

Fix
0<w<1
.
Let
\mathcal{C}
be a
w
-constant-weight list-decodable code for the Z-channel of length
n
with list-decoding radius
\tau
.
Then for
n\to\infty

\displaystyle R(\mathcal{C})

\displaystyle\leq\min_{\begin{subarray}{c}0\leq v\leq 1,\;\max(0,w+v-1)\leq a\leq\min(w,v)\\
(1-v)\left[\frac{w-a}{1-v}-\left(\frac{w-a}{1-v}\right)^{L}\right]+v\left[\frac{a}{v}-\left(\frac{a}{v}\right)^{L}\right]\leq\tau\end{subarray}}I(w,v,a)+o(1),

where
I(w,v,a)
was defined in Lemma
14
.

Proof.

By Lemma
14
, for any list-decodable code
\mathcal{C}
with constant-weight
nw
, one can find a weight-
nv
covering
\mathcal{D}
with respect to a joint distribution
P_{U,X}
as specified in Lemma
14
, where the parameters
v
and
a
are to be optimized later and
\mathcal{D}
satisfies the properties given by the lemma.

For each
\boldsymbol{u}\in S^{\mathrm{H}}_{nv}(\boldsymbol{0})
, define the following
jointly typical set

A(\boldsymbol{u},P_{U,X})
with respect to the joint distribution
P_{U,X}
:

\displaystyle A(\boldsymbol{u},P_{U,X})

\displaystyle\coloneqq\left\{\boldsymbol{x}\in S^{\mathrm{H}}_{nw}(\boldsymbol{0}):T_{\boldsymbol{u},\boldsymbol{x}}=P_{U,X}\right\}.

(21)

By the covering property of
\mathcal{D}
, we have

\displaystyle S^{\mathrm{H}}_{nw}(\boldsymbol{0})

\displaystyle=\bigcup_{\boldsymbol{u}\in\mathcal{D}}A(\boldsymbol{u},P_{U,X})

\displaystyle\implies

\displaystyle S^{\mathrm{H}}_{nw}(\boldsymbol{0})\cap\mathcal{C}

\displaystyle=\left(\bigcup_{\boldsymbol{u}\in\mathcal{D}}A(\boldsymbol{u},P_{U,X})\right)\cap\mathcal{C}

\displaystyle\implies

\displaystyle\mathcal{C}

\displaystyle=\bigcup_{\boldsymbol{u}\in\mathcal{D}}(A(\boldsymbol{u},P_{U,X})\cap\mathcal{C})

\displaystyle\implies

\displaystyle|\mathcal{C}|

\displaystyle\leq\sum_{\boldsymbol{u}\in\mathcal{D}}|A(\boldsymbol{u},P_{U,X})\cap\mathcal{C}|.

For each
\boldsymbol{u}\in\mathcal{D}
, define
\mathcal{C}_{\boldsymbol{u}}\coloneqq A(\boldsymbol{u},P_{U,X})\cap\mathcal{C}
.
By Markov’s inequality, there must be a
\boldsymbol{u}^{*}\in\mathcal{D}
such that
|\mathcal{C}_{\boldsymbol{u}^{*}}|\geq|\mathcal{C}|/|\mathcal{D}|
.
We further define the punctured subcodes of
\mathcal{C}_{\boldsymbol{u}^{*}}
with respect to
\boldsymbol{u}^{*}
.
For
u\in\{0,1\}
, let

\mathcal{C}_{\boldsymbol{u}^{*},u}\coloneqq\{(x_{i})_{i\in[n],u^{*}_{i}=u}:\boldsymbol{x}\in\mathcal{C}\}
be the subcode obtained by restricting codewords in
\mathcal{C}
to the coordinates
i
’s where
u^{*}_{i}=u
.
Note that
\mathcal{C}_{\boldsymbol{u}^{*},1}\in\{0,1\}^{nv}
and
\mathcal{C}_{\boldsymbol{u}^{*},0}\in\{0,1\}^{n(1-v)}
.

The punctured subcodes
\mathcal{C}_{\boldsymbol{u}^{*},0}
and
\mathcal{C}_{\boldsymbol{u}^{*},1}
enjoy the following property.
For
u\in\{0,1\}
, all codewords in
\mathcal{C}_{\boldsymbol{u}^{*},u}
have the same type
P_{X|U=u}
.
That is, every codeword in
\mathcal{C}_{\boldsymbol{u}^{*},0}
has weight
w-a
and every codeword in
\mathcal{C}_{\boldsymbol{u}^{*},1}
has weight
a
.
Clearly,

|\mathcal{C}_{\boldsymbol{u}^{*}}|\leq|\mathcal{C}_{\boldsymbol{u}^{*},0}|\cdot|\mathcal{C}_{\boldsymbol{u}^{*},1}|
.

Suppose that there are
n\tau_{0}
errors in the locations
i
’s such that
u^{*}_{i}=0
and there are
n\tau_{1}
errors in the locations
j
’s such that
u^{*}_{j}=1
.
The parameters
\tau_{0}
and
\tau_{1}
satisfy
\tau_{0}+\tau_{1}\leq\tau
.
As long as the following two conditions are satisfied,

\displaystyle\frac{\tau_{0}}{1-v}

\displaystyle>\frac{w-a}{1-v}-\left(\frac{w-a}{1-v}\right)^{L},\quad\frac{\tau_{1}}{v}>\frac{a}{v}-\left(\frac{a}{v}\right)^{L},

both
|\mathcal{C}_{\boldsymbol{u}^{*},0}|
and
|\mathcal{C}_{\boldsymbol{u}^{*},1}|
are at most a constant (independent of
n
) by Theorem
6
.
Specifically, if

\displaystyle\frac{\tau_{0}}{1-v}=\frac{w-a}{1-v}-\left(\frac{w-a}{1-v}\right)^{L}+\varepsilon,\quad\frac{\tau_{1}}{v}=\frac{a}{v}-\left(\frac{a}{v}\right)^{L}+\varepsilon,

then

\displaystyle|\mathcal{C}_{\boldsymbol{u}^{*},0}|

\displaystyle\leq\frac{C_{0}}{\varepsilon}+O_{L}(1),\quad|\mathcal{C}_{\boldsymbol{u}^{*},1}|\leq\frac{C_{1}}{\varepsilon}+O_{L}(1),

where

\displaystyle C_{0}

\displaystyle\coloneqq\left[\frac{w-a}{1-v}-\left(\frac{w-a}{1-v}\right)^{L}\right]\binom{L}{2},\quad C_{1}\coloneqq\left[\frac{a}{v}-\left(\frac{a}{v}\right)^{L}\right]\binom{L}{2}.

Therefore

\displaystyle|\mathcal{C}|

\displaystyle\leq|\mathcal{C}_{\boldsymbol{u}^{*}}|\cdot|\mathcal{D}|\leq|\mathcal{C}_{\boldsymbol{u}^{*},0}|\cdot|\mathcal{C}_{\boldsymbol{u}^{*},1}|\cdot|\mathcal{D}|\leq\left(\frac{C_{0}}{\varepsilon}+O_{L}(1)\right)\cdot\left(\frac{C_{1}}{\varepsilon}+O_{L}(1)\right)\cdot 2^{n(I(w,v,a)+\varepsilon)},

and

R(\mathcal{C})\leq I(w,v,a)+\varepsilon+o(1)
.
Taking
\varepsilon\to 0
finishes the proof.
∎

Though not used in the proof of Theorem
15
, the upper bound on the size of a covering given in Lemma
14
is actually tight (on the exponential scale).
Such a converse follows from a simple sphere-covering-type argument as below.

Lemma 16
.

Let
I(w,v,a)
and
P_{U,X}
be as defined in Lemma
14
.
Then any covering
\mathcal{D}\subset S_{nv}^{\mathrm{H}}(\boldsymbol{0})
of
S_{nw}^{\mathrm{H}}(\boldsymbol{0})
satisfying the property in Lemma
14
has size at least
2^{nI(w,v,a)-o(n)}
.

Proof.

For any
\boldsymbol{u}\in S_{nv}^{\mathrm{H}}(\boldsymbol{0})
, we first compute the size of
A(\boldsymbol{u},P_{U,X})
defined in Eqn. (
21
).

\displaystyle|A(\boldsymbol{u},P_{U,X})|

\displaystyle=\binom{n(1-v)}{n(w-a)}\binom{nv}{na}\leq 2^{n\left[(1-v)H\left(\frac{w-a}{1-v}\right)+vH\left(\frac{a}{v}\right)\right]}.

Now, by the covering property of
\mathcal{D}
, we have

\displaystyle S_{nw}^{\mathrm{H}}(\boldsymbol{0})

\displaystyle=\bigcup_{\boldsymbol{u}\in\mathcal{D}}A(\boldsymbol{u},P_{U,X})

\displaystyle\implies

\displaystyle|S_{nw}^{\mathrm{H}}(\boldsymbol{0})|

\displaystyle\leq\sum_{\boldsymbol{u}\in\mathcal{D}}|A(\boldsymbol{u},P_{U,X})|

\displaystyle\implies

\displaystyle 2^{nH(w)-o(n)}

\displaystyle\leq|\mathcal{D}|2^{n\left[(1-v)H\left(\frac{w-a}{1-v}\right)+vH\left(\frac{a}{v}\right)\right]}

\displaystyle\implies

\displaystyle|\mathcal{D}|

\displaystyle\geq 2^{n\left[H(w)-(1-v)H\left(\frac{w-a}{1-v}\right)-vH\left(\frac{a}{v}\right)\right]-o(n)}=2^{nI(w,v,a)-o(n)}.\qed

VII-B

Lower bound on
(L-1)
-list-decoding capacity

In this section, our goal is to construct an
(L-1)
-list-decodable code
\mathcal{C}\subset\{0,1\}^{n}
for a Z-channel with noise level
\tau
.
We would like to obtain a lower bound on the rate
R(\mathcal{C})
that can be achieved by such a
\mathcal{C}
.

Before deriving the bound, we first introduce a set of distributions that will play an important role in the proceeding analysis.
For any
w\in[0,1]
and
\tau\in[0,w]
, define the following set of distributions:

\displaystyle\mathcal{K}(w,\tau)

\displaystyle\coloneqq\left\{P_{X_{1},\cdots,X_{L}}\in\mathcal{P}(\{0,1\}^{L}):\begin{array}[]{l}\forall i\in[L],\;P_{X_{i}}(1)=w\\
w-P_{X_{1},\cdots,X_{L}}(1,\cdots,1)\leq\tau\end{array}\right\}.

In words,
\mathcal{K}(w,\tau)
is the collection of distributions
P_{X_{1},\cdots,X_{L}}
on length-
L
binary strings satisfying:

(i)
each of its marginal
P_{X_{i}}
(for
1\leq i\leq L
) is
\mathsf{Ber}(w)
;

(ii)
the probability mass
P_{X_{1},\cdots,X_{L}}(1,\cdots,1)
on the all-one string is at least
w-\tau
.

We now describe our construction and analyze it.
Our approach follows the standard random coding with expurgation technique.
We sample a codebook
\mathcal{C}\in\{0,1\}^{M\times n}
each entry of which is i.i.d. according to
\mathsf{Ber}(w)
.

First, we claim that in expectation a
1/\mathrm{poly}(n)
fraction of the codewords have weight exactly
nw
.
To see this, note that for any
\boldsymbol{x}\in\mathcal{C}
,

\displaystyle\Pr\{\textrm{wt}(\boldsymbol{x})=nw\}

\displaystyle=\binom{n}{nw}w^{nw}(1-w)^{n(1-w)}

\displaystyle=\frac{\sqrt{2\pi n}(n/e)^{n}}{\sqrt{2\pi nw}(nw/e)^{nw}\sqrt{2\pi(1-w)}(n(1-w)/e)^{n(1-w)}}(1-O_{L}(n^{-1}))w^{nw}(1-w)^{n(1-w)}

\displaystyle=\frac{1}{\sqrt{2\pi nw(1-w)}}(1-O_{L}(n^{-1})),

where the second step is by Stirling’s approximation
n!=\sqrt{2\pi n}(n/e)^{n}(1+O_{L}(n^{-1}))
.
Therefore,

\displaystyle\mathbf{E}|\{\boldsymbol{x}\in\mathcal{C}:\textrm{wt}(\boldsymbol{x})=nw\}|

\displaystyle=\frac{M}{\sqrt{2\pi nw(1-w)}}(1-O_{L}(n^{-1})).

Second, we compute the expected number of
bad

L
-lists, i.e., those
L
-lists whose list-decoding radius is at most
n\tau
.
For any list
\mathcal{L}\in\binom{\mathcal{C}}{L}
of codewords all of weight
nw
, it is clear that
\mathrm{rad}(\mathcal{L})\leq n\tau
(where
\mathrm{rad}(\mathcal{L})
was defined in Eqn. (
9
)) if and only if the joint type
T_{\mathcal{L}}
of
\mathcal{L}
is in
\mathcal{K}(w,\tau)
.
By Sanov’s theorem (Theorem
13
),

\displaystyle-\frac{1}{n}\log\Pr\{\mathrm{rad}(\mathcal{L})\leq n\tau\}

\displaystyle=-\frac{1}{n}\log\Pr\{T_{\mathcal{L}}\in\mathcal{K}(w,\tau)\}

\displaystyle\xrightarrow{n\to\infty}\min_{P_{X_{1},\cdots,X_{L}}\in\mathcal{K}(w,\tau)}D\left(P_{X_{1},\cdots,X_{L}}\middle\|\mathsf{Ber}^{\otimes L}(w)\right)\eqqcolon E(w,\tau).

Therefore, for sufficiently large
n
, we have

\displaystyle\mathbf{E}\left|\left\{\mathcal{L}\in\binom{\mathcal{C}}{L}:\mathrm{rad}(\mathcal{L})\leq n\tau\right\}\right|

\displaystyle=\binom{M}{L}2^{-nE(w,\tau)(1-o(1))}.

Finally, we expurgate all codewords whose weights are not exactly
nw
; we also expurgate one codeword from each of the
bad

L
-lists
\mathcal{L}
, i.e., those
\mathcal{L}
such that
\mathrm{rad}(\mathcal{L})\leq n\tau
.
If

\displaystyle\binom{M}{L}2^{-nE(w,\tau)(1-o(1))}

\displaystyle\leq\frac{M}{2\sqrt{2\pi nw(1-w)}}(1-O_{L}(n^{-1}))

\displaystyle\impliedby

\displaystyle M^{L}2^{-nE(w,\tau)(1-o(1))}

\displaystyle\leq\frac{M}{2\sqrt{2\pi nw(1-w)}}(1-O_{L}(n^{-1}))

\displaystyle\impliedby

\displaystyle RL-E(w,\tau)(1-o(1))

\displaystyle\leq R(1-o(1))

\displaystyle\impliedby

\displaystyle R

\displaystyle\leq\frac{E(w,\tau)}{L-1}(1-o(1)),

then after expurgation, we are left with at least
\frac{M}{2\sqrt{2\pi nw(1-w)}}(1-O(n^{-1}))
codewords which form an
(L-1)
-list-decodable code
\mathcal{C}^{\prime}\subset\mathcal{C}
.
Note that the rate
R(\mathcal{C}^{\prime})
is asymptotically equal to
R(\mathcal{C})
.

Therefore, we have proved the following theorem.

Theorem 17
.

There exist
w
-constant-weight
(L-1)
-list-decodable codes for the Z-channel with list-decoding radius
\tau<\tau_{L}(w)
of rate at least

\displaystyle\frac{1}{L-1}\min_{P_{X_{1},\cdots,X_{L}}\in\mathcal{K}(w,\tau)}D\left(P_{X_{1},\cdots,X_{L}}\middle\|\mathsf{Ber}^{\otimes L}(w)\right),

where
\mathcal{K}(w,\tau)
was defined in Eqn.
VII-B
.

VII-C

List-decoding capacity

Obtaining the exact
(L-1)
-list-decoding capacity for the Z-channel is a difficult question and we are only able to derive nonmatching upper and lower bounds in Sec.
VII-A
and
VII-B
respectively.
Nevertheless, we can compute the list-decoding capacity
C_{L-1}(w,\tau)
when
L
is sufficiently large.
Specifically, we determine the limit
\lim\limits_{L\to\infty}C_{L-1}(w,\tau)
using the following two lemmas.
The proofs below follow the outline that one uses to prove the standard list-decoding capacity theorem for symmetric errors.

Define

\displaystyle C_{\mathrm{LD}}(w,\tau)

\displaystyle\coloneqq-(1-w+\tau)\log(1-w+\tau)+\tau\log\tau-w\log w.

(25)

Note that for any fixed
w
,
C_{\mathrm{LD}}(w,\tau)
is convex and decreasing in
\tau
.
It attains its maximum value
H(w)
at
\tau=0
and attains its minimum value
0
at
\tau=w
.
Furthermore,
C_{\mathrm{LD}}(w,\tau)
is concave in
w
and attains its maximum value at
w=\frac{1+\tau}{2}
for any fixed
\tau
.
The corresponding maximum value is
C_{\mathrm{LD}}(\tau)\coloneqq-(1+\tau)\log\frac{1+\tau}{2}+\tau\log\tau
which is in turn convex and decreasing with maximum value
1
at
\tau=0
and minimum value
0
at
\tau=1
.

Lemma 18

(Upper bound)
.

For any
\delta\in(0,1)
, any
w
-constant-weight code of rate
C_{\mathrm{LD}}(w,\tau)+\delta
for the Z-channel with error fraction
\tau
is not
(L-1)
-list-decodable for any
L<2^{n\delta+o(n)}
.

Proof.

Let
\mathcal{C}
be any
w
-constant-weight code of rate
C_{\mathrm{LD}}(w,\tau)+\delta
.
To show non-list-decodability, we need to exhibit a
bad
center
\boldsymbol{y}
such that the Z-ball around
\boldsymbol{y}
of radius
n\tau
contains at least
2^{n\delta+o(n)}
codewords from
\mathcal{C}
.
Indeed, we will show that a random
\boldsymbol{y}
has such a property.
Specifically, let
\boldsymbol{y}
be uniformly distributed among all vectors of weight
n(w-p)
.
We compute the expected number of codewords in
B^{\mathrm{Z}}_{n\tau}(\boldsymbol{y})
.

\displaystyle\mathbf{E}|B^{\mathrm{Z}}_{n\tau}(\boldsymbol{y})\cap\mathcal{C}|

\displaystyle=\sum_{\boldsymbol{x}\in\mathcal{C}}\Pr\{B^{\mathrm{Z}}_{n\tau}(\boldsymbol{y})\ni\boldsymbol{x}\}

\displaystyle=\sum_{\boldsymbol{x}\in\mathcal{C}}\Pr\{\mathrm{supp}(\boldsymbol{y})\subseteq\mathrm{supp}(\boldsymbol{x})\}

\displaystyle=\sum_{\boldsymbol{x}\in\mathcal{C}}\frac{\binom{nw}{n(w-p)}}{\binom{n}{n(w-p)}}

\displaystyle=2^{nC_{\mathrm{LD}}(w,\tau)+n\delta}2^{n\left(wH\left(\frac{w-p}{w}\right)-H(w-p)\right)+o(n)}

\displaystyle=2^{n\delta+o(n)}.

This finishes the proof.
∎

Lemma 19

(Construction)
.

For any
\delta\in(0,1)
and any
L>1/\delta
, there exist
(L-1)
-list-decodable codes for the Z-channel with error fraction
\tau
of rate
C_{\mathrm{LD}}(w,\tau)-\delta
.

Proof.

First note that if
\tau\geq w
, the capacity is trivially zero under any constant list size since the channel can zero out all bits in any codeword and the list size has to be as large as the code size.
In the proof we therefore assume
\tau<w
.

Let
\mathcal{C}\subset\{0,1\}^{n}
be a collection of
M\coloneqq 2^{nR}
(where
R=C_{\mathrm{LD}}(w,\tau)-\delta
) random vectors
\boldsymbol{x}_{1},\cdots,\boldsymbol{x}_{M}
each of which is i.i.d. chosen from the set of all weight-
nw
binary vectors.
If a codeword
\boldsymbol{x}\in\mathcal{C}
is input to the channel, the weight of the output vector
\boldsymbol{y}\in\{0,1\}^{n}
is in the range
[n(w-\tau),nw]
.
A vector
\boldsymbol{y}\in\{0,1\}^{n}
of weight in
[n(w-\tau),nw]
can result from
\boldsymbol{x}\in\mathcal{C}
through the channel if and only if
\mathrm{supp}(\boldsymbol{y})\subset\mathrm{supp}(\boldsymbol{x})
.
We compute the probability that this happens to a random codeword
\boldsymbol{x}\in\mathcal{C}
.
For any fixed
\boldsymbol{y}\in\{0,1\}^{n}
of weight
nu
where
u\in[w-\tau,w]
, we have

\displaystyle\Pr\{\mathrm{supp}(\boldsymbol{y})\subseteq\mathrm{supp}(\boldsymbol{x})\}

\displaystyle=\frac{\binom{n(1-u)}{n(w-u)}}{\binom{n}{nw}}\leq 2^{n(1-u)H\left(\frac{w-u}{1-u}\right)-nH(w)+o(n)}.

Therefore, the probability that such a random code
\mathcal{C}
is not
(L-1)
-list-decodable is:

\displaystyle\Pr\{\mathcal{C}\text{ is not $(L-1)$-list-decodable}\}

\displaystyle\leq\Pr\left\{\exists\{i_{1},\cdots,i_{L}\}\in\binom{[M]}{L},\;\exists\boldsymbol{y}\in\{0,1\}^{n},\;\mathrm{s.t.}\;\textrm{wt}(\boldsymbol{y})\in[n(w-\tau),nw];\;\forall j\in[L],\;\mathrm{supp}(\boldsymbol{y})\subseteq\mathrm{supp}(\boldsymbol{x}_{i_{j}})\right\}

\displaystyle\leq\binom{M}{L}2^{n}\max_{w-\tau\leq u\leq w}\left(2^{n(1-u)H\left(\frac{w-u}{1-u}\right)-nH(w)+o(n)}\right)^{L}

\displaystyle\leq\max_{w-\tau\leq u\leq w}2^{nRL+n+nL\left[(1-u)H\left(\frac{w-u}{1-u}\right)-H(w)+o(1)\right]}

\displaystyle\leq 2^{n\left[RL+1+L\left((1-w+\tau)H\left(\frac{\tau}{1-w+\tau}\right)-H(w)+o(1)\right)\right]}.

(26)

The last inequality follows since the function
f_{w}(u)\coloneqq(1-u)H\left(\frac{w-u}{1-u}\right)
has the following property.
For any fixed
w
,
f_{w}(u)
is concave and decreasing in
u\in[0,w]
, and therefore in the domain
u\in[w-\tau,w]
it attains its maximum at
u=w-\tau
.

By elementary algebraic manipulation, we have

\displaystyle(1-w+\tau)H\left(\frac{\tau}{1-w+\tau}\right)-H(w)=-C_{\mathrm{LD}}(w,\tau).

Recall
R=C_{\mathrm{LD}}(w,\tau)-\delta
.
Then the exponent (normalized by
n^{-1}
) of the RHS of the inequality (
26
) equals

\displaystyle(C_{\mathrm{LD}}(w,\tau)-\delta)L+1-C_{\mathrm{LD}}(w,\tau)L+o(1)=-\delta L+1+o(1),

which is negative if
L>1/\delta+o(1)
.
That is, the probability that
\mathcal{C}
is
(L-1)
-list-decodable is at least
1-2^{-\Omega(n)}
for any
L>1/\delta+o(1)
.
∎

Lemma
18
and
19
imply the following characterization.

Theorem 20

(List-decoding capacity)
.

The
(L-1)
-list-decoding capacity of the Z-channel with error fraction
\tau
under input constraint
w
is given by
\lim\limits_{L\to\infty}C_{L-1}(w,\tau)=C_{\mathrm{LD}}(w,\tau)
as defined in Eqn. (
25
).

VIII
Capacity of stochastic Z-channels

In all other sections of this paper, we considered Z-channels with
adversarial
errors.
In this section, we derive the capacity of
stochastic
Z-channels from Shannon’s seminal channel coding theorem.

To this end, we first state Shannon’s theorem for general discrete memoryless channels (DMCs).
Let
\mathcal{X}
and
\mathcal{Y}
be two finite sets denoting the input and output alphabets of the channel.
A DMC is a stochastic matrix
W_{Y|X}
that maps a distribution over
\mathcal{X}
to a distribution over
\mathcal{Y}
.
When the channel is used
n
times with an input sequence
\boldsymbol{x}\in\mathcal{X}^{n}
, the output sequence
\boldsymbol{y}\in\mathcal{Y}^{n}
follows a product law:

\displaystyle\Pr\{\boldsymbol{y}=(b_{1},\cdots,b_{n})|\boldsymbol{x}=(a_{1},\cdots,a_{n})\}

\displaystyle=\prod_{i=1}^{n}W_{Y|X}(b_{i}|a_{i}),

for any
(a_{1},\cdots,a_{n})\in\mathcal{X}^{n}
and
(b_{1},\cdots,b_{n})\in\mathcal{Y}^{n}
.

For a code
\mathcal{C}=\{\boldsymbol{x}_{1},\cdots,\boldsymbol{x}_{M}\}\subset\mathcal{X}^{n}
, its
rate
is defined as
R(\mathcal{C})\coloneqq\frac{1}{n}\log M
.
The
average (over messages) probability of error
of
\mathcal{C}
when used over a DMC
W_{Y|X}
with a decoder
\mathrm{Dec}\colon\mathcal{Y}^{n}\to[M]
is defined as

\displaystyle P_{\mathrm{e},\mathrm{avg}}(\mathcal{C})

\displaystyle\coloneqq\frac{1}{M}\sum_{i=1}^{M}\sum_{y\in\mathcal{Y}^{n}}\prod_{j=1}^{n}W_{Y|X}(y_{j}|x_{i,j})\mathds{1}\{\mathrm{Dec}(y)\neq i\}.

The
capacity
of the channel is then defined as

\displaystyle C(W_{Y|X})

\displaystyle\coloneqq\limsup_{\varepsilon\downarrow 0}\limsup_{n\uparrow\infty}\max_{\begin{subarray}{c}\mathcal{C}_{n}\subset\mathcal{X}^{n}\\
P_{\mathrm{e},\mathrm{avg}}(\mathcal{C}_{n})\leq\varepsilon\end{subarray}}R(\mathcal{C}_{n}),

i.e., the largest rate for which there exists a sequence of codes with vanishing error probability.

The DMC is said to be equipped with input constraints
\mathcal{Q}\subset\mathcal{P}(\mathcal{X})
if the type
T_{\boldsymbol{x}}
of any input sequence
\boldsymbol{x}\in\mathcal{C}
is required to belong to
\mathcal{Q}
.
The capacity of
W_{Y|X}
with input constraints
\mathcal{Q}
can be similarly defined.

Theorem 21

(Channel coding theorem
[
Sha48
]
)
.

The capacity
C(W_{Y|X})
of a DMC
W_{Y|X}\in\mathcal{P}(\mathcal{Y}|\mathcal{X})
with input constraints
\mathcal{Q}
is given by

\displaystyle C(W_{Y|X})

\displaystyle=\max_{P_{X}\in\mathcal{Q}}I(X;Y),

(27)

where the mutual information is evaluated with respect to the joint law
P_{X}W_{Y|X}
.

A discrete memoryless Z-channel is defined as follows.
Both the input and output alphabets are binary:
\mathcal{X}=\mathcal{Y}=\{0,1\}
.
The channel transition law is parameterized by the zeroing-out probability
\tau
, i.e.,

W^{\mathrm{Z}}_{Y|X}(0|0)=1,W^{\mathrm{Z}}_{Y|X}(0|1)=\tau
.
The input constraint is such that all input sequences should have Hamming weight at most
nw
for some
w\in[0,1]
.
It is easy to evaluate Eqn. (
27
) which yields

C(W^{\mathrm{Z}}_{Y|X})=C(w,\tau)=H(w(1-\tau))-wH(\tau)
.

We note that for any fixed
w\in[0,1]
,
C(w,\tau)
is convex and decreasing in
\tau
.
It attains its maximum value
H(w)
at
\tau=0
and attains its minimum value
0
at
\tau=1
.

We also note that
C(w,\tau)
is concave in
w
for any fixed
\tau
.
The maximizing
w
is given by

\displaystyle w_{\max}

\displaystyle\coloneqq\left(1-\tau+\tau^{-\frac{\tau}{1-\tau}}\right)^{-1},

and the corresponding capacity is given by
C(\tau)\coloneqq H(w_{\max}(1-\tau))-w_{\max}H(\tau)
.
Equivalent expressions have also been presented in
[
TABB08
]
:

\displaystyle w_{\max}

\displaystyle=\left(\left(1+2^{\frac{H(\tau)}{1-\tau}}\right)(1-\tau)\right)^{-1},\quad C(\tau)=\log\left(1+\tau^{\frac{\tau}{1-\tau}}-\tau^{\frac{1}{1-\tau}}\right).

Note that
C(\tau)
is convex and decreasing with maximum value
1
at
\tau=0
and minimum value
0
at
\tau=1
.

For symmetric errors and erasures, it happens that the capacities of binary symmetric channels and binary erasure channels coincide with the respective list-decoding capacities (under adversarial errors).
Comparing the expressions of
C(w,\tau)
and
C_{\mathrm{LD}}(w,\tau)
, we see that this is no longer true for Z-channels.

IX
Open problems

1.

For codes correcting symmetric errors, the Elias–Bassalygo bound can be improved using Delsarte’s linear program
[
MRRW77
]
.
We do not know how to derive a linear programming-type bound for Z-channels.
As far as we know, the linear programming framework, in its most general form, assumes that the ambient space that the code lives in (which is
\{0,1\}^{n}
for general codes and
S_{nw}^{\mathrm{H}}(\boldsymbol{0})
for
w
-constant-weight codes) can be defined as an
association scheme
.
We do not see how to do so under the Z-metric
d_{\mathrm{Z}}(\cdot,\cdot)
since the volume of the intersection of two Z-spheres is not invariant under shifts.

2.

The largest code size is exponential in
n
if the fraction of asymmetric errors the list-decodable code can correct is less than the Plotkin point
\tau_{L}
and we gave bounds on the exponent in Sec.
VII-A
and
VII-B
; whereas it is
\Theta_{L}(\varepsilon^{-3/2})
if the fraction of errors is
\varepsilon
-above
\tau_{L}
.
There is one missing case which we did not solve, that is, what is the largest code size with error fraction being
exactly

\tau_{L}
?
We conjecture that in this case the answer is
\Theta_{L}(n^{3/2})
.
Note that the answer to the same question for symmetric errors is
2n
proved by a geometric argument.
