1.
Introduction

Birkhoff’s ergodic theorem is one of the most important and beautiful result of the probability
theory. The study of ergodic theorems started in 1931 by von Neumann and Birkhoff, having its origins
in statistical mechanics. Recall the definition of the measure-preserving transformation (see
[
6
]
).

Definition 1.1
.

Let
(X,\mathcal{B},\mu)
be a probability space. A mapping
T:X\to X
is said to be a measure-preserving transformation if for any measurable set
E\in\mathcal{B}
the set
T^{-1}(E)
is also measurable and
\mu(E)=\mu(T^{-1}(E))
. The combination
(X,\mathcal{B},\mu,T)
is called a measure-preserving system.

Theorem A

(Birkhoff)
.

If
(X,\mathcal{B},\mu,T)
is a measure-preserving system, then for any function
f\in L^{1}(X)
the averages

(1.1)

\frac{1}{n}\sum_{j=0}^{n-1}f(T^{j}x)

converge almost everywhere to a
T
-invariant function
\bar{f}
as
n\to\infty
.

There are different proofs and various generalizations of this classical theorem. Some of those clearly demonstrate strong link between the Lebesgue differentiation theory on
\mathbb{R}^{n}
and pointwise convergence of different type of ergodic averages. The following multiple version of Birkhoff’s theorem, proved by Zygmund
[
10
]
and Dunford
[
5
]
independently, is an example of such a resemblance. Let
\Phi:\mathbb{R}^{+}\to\mathbb{R}^{+}
be non-decreasing function and
(X,\mathcal{B},\mu)
be a probability space. Denote by
L_{\Phi}(X)
the class of
\mathcal{B}
-measurable functions
f
on
X
with
\Phi(|f|)\in L^{1}(\mathbb{T})
. The class
L_{\Phi}(X)
corresponding to a function

(1.2)

\Phi(t)=t\left(1+\max\{0,\log^{n}t\}\right),\quad n\geq 1,

will be denoted by
L\log^{n}L(X)
. Clearly this class of function is strongly included in
L^{1}(X)
.

Theorem B

(Dunford-Zygmund)
.

Let
U_{1},\ldots,U_{n}
be measure-preserving one-to-one transformations of a probability space
(X,\mathcal{B},\mu)
. Then for any function
f\in L\log^{n-1}L(X)
the averages

(1.3)

\frac{1}{s_{1}\cdots s_{n}}\sum_{j_{1}=0}^{s_{1}-1}\cdots\sum_{j_{n}=0}^{s_{n}-1}f\left(U_{1}^{j_{1}}\cdots U_{n}^{j_{n}}x\right)

converge a.e. as
\min_{j}s_{j}\to\infty
.

This result has been generalized for general contraction operators on
L^{1}
, considering those instead of the operators
f\to f\circ U_{k}
generated by the measure-preserving transformations
U_{k}
(Dunford-Schwartz
[
4
]
, Fava
[
7
]
). Hagelstein and Stokolos in
[
8
]
proved the sharpness of the class of functions
L\log^{n-1}L(X)
in the context of Theorem
B
. Namely,

Theorem C

(Hagelstein-Stokolos)
.

Let a collection of invertible commuting measure-preserving transformations
\mathfrak{U}=\{U_{k}:\,k=1,2,\ldots,n\}
be non-periodic, that is for any non-trivial collection of integers
p_{k}\in\mathbb{Z}
,
k=1,2,\ldots,n
we have

(1.4)

\mu\{U_{1}^{p_{1}}\circ\ldots\circ U_{n}^{p_{n}}(x)=x\}=0.

If
\Phi(t)=o(t\log^{n-1}t)
as
t\to\infty
, then there exists a function
f\in L_{\Phi}(X)
such that averages (
1.3
) unboundedly diverge a.e..

Definition 1.2
.

A set of invertible commuting measure-preserving (ICMP) transformations
\mathfrak{U}=\{U_{k}:\,k=1,2,\ldots,n\}
is said to be
dependent
if there is a non-trivial collection of integers
p_{k}\in\mathbb{Z}
,
k=1,2,\ldots,n
, such that

(1.5)

(U_{1}^{p_{1}}\circ\ldots\circ U_{n}^{p_{n}})(x)=x

almost everywhere on
X
. If there is no such a collection of integers
p_{k}
, then we say
\mathfrak{U}
is
independent
.
The
rank of
\mathfrak{U}
denoted by
{\rm rank\,}(\mathfrak{U})
will be called the largest integer
r
for which there is an independent subset of cardinality
r
in
\mathfrak{U}
.

Remark 1.1
.

Note that according to our definition, the independence of
\mathfrak{U}
requires the failure of (
1.5
) on a set of positive measure for any non-trivial collection of integers
\{p_{k}\}
, while the condition of non-periodicity in Theorem
C
is a stronger version of independence, since in this case the failure of (
1.5
) is required almost everywhere.

The main result of the present paper provides a generalization of Theorem
B
. Namely, it says that in fact a.e. convergence of averages (
1.3
) holds in a larger class of functions
L\log^{d-1}L\supset L\log^{n-1}L
, where
d={\rm rank\,}(\mathfrak{U})\leq n
. First we prove the following weak type maximal inequality, where
{\rm Log}_{n}t
denotes the function in (
1.2
), i.e.

(1.6)

{\rm Log}_{n}(t)=t\left(1+\max\{0,\log^{n}t\}\right).

Theorem 1.1
.

Let
\mathfrak{U}=\{U_{k}:\,k=1,2,\ldots,n\}
be a set of ICMP transformations of rank
d
.
Then, for any function
f\in L\log^{d-1}L(X)
and
\lambda>0
, we have

(1.7)

\displaystyle\mu\Biggl\{x\in X:\,\sup_{s_{j}\geq 0}\frac{1}{s_{1}\ldots s_{n}}\sum_{k_{1}=0}^{s_{1}-1}\cdots\sum_{k_{n}=0}^{s_{n}-1}

\displaystyle\left|f\left((U_{1}^{k_{1}}\circ\cdots\circ U_{n}^{k_{n}})(x)\right)\right|>\lambda\Biggr\}

(1.8)

\displaystyle\leq

\displaystyle C(\mathfrak{U})\int_{X}{\rm Log}_{d-1}\left(\frac{|f|}{\lambda}\right),

where
C(\mathfrak{U})
is a constant depending only on
\mathfrak{U}
.

As a corollary of (
1.8
) we obtain the following.

Theorem 1.2
.

Let
\mathfrak{U}=\{U_{k}:\,k=1,2,\ldots,n\}
be a set of ICMP transformations of rank
d
.
Then, for any function
f\in L\log^{d-1}L(X)
the averages (
1.3
) converge almost everywhere as
\min s_{k}\to\infty
.

Remark 1.2
.

We will see in the last section that the class
L\log^{d-1}L(X)
of the functions in Theorem
1.2
is optimal. More precisely, if the corresponding independent subset of cardinality
d={\rm rank\,}(\mathfrak{U})
in
\mathfrak{U}
is “strongly independent” (i.e. non-periodic), then under the condition
\Phi(t)=o(t\log^{d-1}t)
there exists a function
f\in L_{\Phi}(X)
with a.e. diverging averages (
1.3
).

The inequality (
1.8
) will be deduced from a maximal inequality on
\mathbb{R}^{n}
. Let
A:\mathbb{R}^{n}\to\mathbb{R}^{d}
be a linear operator given by the matrix

(1.9)

A=\{a_{kj}:\,1\leq j\leq n,\,1\leq k\leq d\}

of size
d\times n
(
d
-rows and
n
-columns). We consider the maximal function

(1.10)

M_{A}f(\textbf{x})=\sup_{R}\frac{1}{|R|}\int_{R}|f(\textbf{x}+A\cdot\textbf{t})|d\textbf{t},\quad\textbf{x}\in\mathbb{R}^{d},

where
\sup
is taken over all
n
-dimensional symmetric intervals

(1.11)

R=\left\{\textbf{t}=(t_{1},\ldots,t_{n})\in\mathbb{R}^{n}:\,t_{j}\in[-r_{j},r_{j}],\,j=1,2,\ldots,n\right\}\subset\mathbb{R}^{n}.

Denote by
{\rm rank\,}A
the rank of the matrix
A
.

Theorem 1.3
.

Let
A
be the matrix (
1.9
) and
r={\rm rank\,}A
. Then for any function
f\in L(\log^{+}L)^{r-1}(\mathbb{R}^{d})
it holds the bound

(1.12)

|\{\textbf{x}\in\mathbb{R}^{d}:\,M_{A}f(\textbf{x})>\lambda)\}|\leq C(A)\int_{\mathbb{R}^{d}}{\rm Log}_{r-1}\left(\frac{|f|}{\lambda}\right),

where
C(A)
is a constant, depending only the matrix
A
.

Remark 1.3
.

Observe that if
n=d=r
and
A
is the identity matrix of size
n
, then (
1.10
) gives the well-known strong maximal function on
\mathbb{R}^{n}
, correspondingly, (
1.12
) becomes the weak type inequality due to M. de Guzman
[
2
]
(see also
[
3
]
).
Moreover, inequality (
1.12
) holds even if
A
is a general invertible matrix and it follows from Guzman’s inequality of
[
2
]
, simply using the equivalence of rectangular and parallelepiped differentiation bases on
\mathbb{R}^{n}
. Our proof of the full version of inequality (
1.12
) is a reduction of the general case to the case of invertible
A
.

Remark 1.4
.

Note that papers
[
5
]
and
[
10
]
suggest different proofs of Theorem
B
. The proof of
[
5
]
is straightforward and the convergence of averages (
1.3
) was established only for the functions in
L^{p}
,
1<p<\infty
, while Zygmund
[
10
]
provides an inequality, which is the analogue of a similar inequality for the strong maximal function, originally proved in
[
9
]
. The latter is the weaker version of Guzman’s inequality of
[
2
]
.

We will use the following equivalent form of the maximal function (

M_{\mathfrak{U}}f(\textbf{x})=\sup_{r_{k}>0}\frac{1}{2^{n}r_{1}\cdots r_{n}}\int_{-r_{1}}^{r_{1}}\cdots\int_{-r_{n}}^{r_{n}}|f(\textbf{x}+t_{1}\textbf{u}_{1}+\cdots+t_{n}\textbf{u}_{n})|dt_{1}\cdots dt_{n},

where the vector set
\mathfrak{U}=\{\textbf{u}_{k},\,k=1,2,\ldots,n\}
is formed by the columns of the matrix (

). So the rank of vectors

coincides with the rank of the matrix

Once again note that that if the collection of vectors are independent, i.e. the matrix
A
is invertible, then inequality (
1.12
) is known, and we are going to reduce the general case to the case of invertible
A
. We need several lemmas, concerning parallelepipeds in

and associated measures.

For a vector
\textbf{x}=(x_{1},\ldots,x_{d})\in\mathbb{R}^{d}
we denote

we denote by
{\rm span}(\mathfrak{V})
the linear space generated by
\mathfrak{V}
(sometimes this Euclidean space will be denoted by
\mathbb{R}_{\mathfrak{U}}

The notation
|E|
will stand for the Lebesgue measure of a set

in an Euclidean space.

Definition 2.1
.

Let
\mathfrak{U}=\{\textbf{u}_{k}:\,k=1,2,\ldots,n\}\subset\mathbb{R}^{d}
be a set of unit vectors. Call parallelepiped in
\mathbb{R}^{d}
a set of the form

(2.2)

R=\left\{\textbf{x}\in\mathbb{R}^{d}:\,\textbf{x}=t_{1}\textbf{u}_{1}+\ldots+t_{n}\textbf{u}_{n},\,t_{j}\in[-r_{j},r_{j}]\right\}.

The family of all parallelepipeds (
2.2
) generated by a fixed set of vectors
\mathfrak{U}
will be denoted by
\mathcal{P}_{\mathfrak{U}}
.

Note that parallepipeds can have different representations (
2.2
). Clearly the arithmetic sum of two parallelepipeds
R
,
Q

R+Q=\{\textbf{x}+\textbf{t}:\,\textbf{x}\in R,\,t\in Q\}

is again a parallelepiped. For two parallelepipeds
R
and
Q
we write
Q\prec R
if there is a parallelepiped
R^{\prime}
such that
Q=R+R^{\prime}
.

Lemma 2.1
.

If
\mathfrak{U}=\{\textbf{u}_{k}:\,k=1,2,\ldots,n\}
is a basis set of vectors in
\mathbb{R}^{n}
and
R\in\mathcal{P}_{\mathfrak{U}}
has a representation (
2.2
), then

(2.3)

\{\textbf{x}\in\mathbb{R}^{n}:\,|\textbf{x}|\leq 1\}\subset\frac{C(\mathfrak{U})}{\min_{j}r_{j}}\cdot R,

where
C(\mathfrak{U})
is a constant, depending only on the set of vectors
\mathfrak{U}
.

Proof.

For any
j=1,2,\ldots,n
we consider hyperplanes
\Gamma_{j}^{+}
and
\Gamma_{j}^{-}
in
\mathbb{R}^{n}
defined

\displaystyle\Gamma_{j}^{\pm}=\{\textbf{x}=t_{1}\textbf{u}_{1}+\ldots+t_{n}\textbf{u}_{n}:\,t_{j}=\pm r_{j},\,t_{i}\in\mathbb{R},\,i\neq j\}

and let
S_{j}
be the closed strip domain lying between the hyperplanes
\Gamma_{j}^{\pm}
. We have
R=\cap_{j}S_{j}
. Denote by
h_{j}
the distance of the hyperplanes
\Gamma_{j}^{+}
and
\Gamma_{j}^{-}
from the origin. It is clear that

(2.4)

\{\textbf{x}\in\mathbb{R}^{n}:\,|\textbf{x}|\leq\min_{j}h_{j}\}\subset R.

One can also check that
c_{j}=h_{j}/r_{j}
are constants, depending only on
\mathfrak{U}
. Denote
C(\mathfrak{U})=(\min_{j}c_{j})^{-1}
. From (
2.4
) we obtain

\{\textbf{x}\in\mathbb{R}^{n}:\,|\textbf{x}|\leq 1\}\subset\frac{1}{\min_{j}h_{j}}\cdot R\subset\frac{C(\mathfrak{U})}{\min_{j}r_{j}}\cdot R

and so (
2.3
).
∎

\displaystyle{\rm rank\,}(\mathfrak{V})={\rm rank\,}(\mathfrak{U}),

(2.6)

\displaystyle R\subset C(\mathfrak{U})\cdot Q,

Suppose that

is the parallelepiped (

r_{1}\geq r_{2}\geq\ldots\geq r_{n}.

Denote

One can easily check that the vectors of

(2.9)

\displaystyle 0=k_{0}<k_{1}<\ldots<k_{s}=n,

\displaystyle\mathfrak{V}=\bigcup_{i\geq 0}\mathfrak{U}_{2i+1},\quad\mathfrak{U}_{2j}\subset{\rm span}\left(\bigcup_{i=1}^{j}\mathfrak{U}_{2i-1}\right).

3.
A discrete maximal inequality

We will need a discrete version of inequality (
1.12
). Let
\phi:\mathbb{Z}^{d}\to\mathbb{R}
be a
d
-dimensional sequence and let
A=\{a_{kj}:\,1\leq j\leq n,\,1\leq k\leq d\}
be an integer matrix. Consider the maximal operator

(3.1)

\displaystyle\mathcal{D}_{A}\phi(\textbf{n})

\displaystyle=\sup_{s_{j}\in\mathbb{N}}\frac{1}{s_{1}\ldots s_{n}}\sum_{k_{1}=0}^{s_{1}-1}\ldots\sum_{k_{n}=0}^{s_{n}-1}\phi(\textbf{n}+A\cdot\textbf{k})

(3.2)

\displaystyle=\sup_{s_{j}\in\mathbb{N}}\frac{1}{s_{1}\ldots s_{n}}\sum_{\textbf{k}=0}^{\textbf{s}-1}\phi(\textbf{n}+A\cdot\textbf{k}),\quad\textbf{n}\in\mathbb{N}^{d}.

From Theorem
1.3
we easily obtain the following.

Corollary 3.1
.

For any integer matrix
A
of
{\rm rank\,}(A)=r
it holds the bound

(3.3)

\#\{\textbf{n}\in\mathbb{Z}^{d}:\,\mathcal{D}_{A}\phi(\textbf{n})>\lambda\}\leq C(A)\sum_{\textbf{n}\in\mathbb{Z}^{d}}{\rm Log}_{r-1}\left(\frac{|\phi(\textbf{n})|}{\lambda}\right).

Proof.

Given multiple sequence
\phi(\textbf{m})
consider the function

(3.4)

f(\textbf{x})=\sum_{\varepsilon_{j}=0,1,-1}\phi(m_{1}+\varepsilon_{1},\ldots,m_{n}+\varepsilon_{n}),\text{ if }[\textbf{x}]=\textbf{m},\quad\textbf{m}\in\mathbb{Z}_{d},

on
\mathbb{R}^{d}
, where
[\textbf{x}]=([x_{1}],\ldots,[x_{d}])
denotes the coordinate wise integer part of the vector
\textbf{x}=(x_{1},\ldots,x_{d})
. Clearly there is a constant
\delta=\delta(A)<1
such that

(3.5)

A\left(\Delta\right)\subset(-1,1)^{d},\text{ where }\Delta=[0,\delta)^{n},

Using (
3.4
), (
3.5
), one can check that

(3.6)

\phi(\textbf{n}+A\cdot\textbf{k})\leq f(\textbf{x}+A\cdot\textbf{t})\text{ if }\textbf{t}\in\textbf{k}+\Delta,\,[\textbf{x}]=\textbf{n}.

Thus we obtain

(3.7)

\displaystyle\sum_{\textbf{k}=0}^{\textbf{s}-1}\phi(\textbf{n}+A\cdot\textbf{k})

\displaystyle\leq\sum_{\textbf{k}=0}^{\textbf{s}-1}\frac{1}{|\Delta|}\int_{\textbf{k}+\Delta}|f(\textbf{x}+A\cdot\textbf{t})|d\textbf{t}

(3.8)

\displaystyle\leq\frac{1}{|\Delta|}\int_{R}|f(\textbf{x}+A\cdot\textbf{t})|d\textbf{t},

for any
x
with
[\textbf{x}]=\textbf{n}
, where

(3.9)

R=\{\textbf{t}\in\mathbb{R}^{n}:\,t_{j}\in[-1,s_{j}],\,j=1,\ldots,n\}.

This implies

(3.10)

\mathcal{D}_{A}\phi(\textbf{n})\leq C(A)M_{A}f(\textbf{x})\text{ if }[\textbf{x}]=\textbf{n}\in\mathbb{Z}^{d}

and so

(3.11)

\displaystyle\#\{\textbf{n}\in\mathbb{Z}_{+}^{d}:\,\mathcal{D}_{A}\phi(\textbf{n})>\lambda\}

\displaystyle\leq|\{\textbf{x}\in\mathbb{R}^{d}:\,M_{A}f(\textbf{x})>\lambda/C(A)\}|

(3.12)

\displaystyle\leq C(A)\int_{\mathbb{R}^{d}}{\rm Log}_{r-1}\left(\frac{|f|}{\lambda}\right)

(3.13)

\displaystyle\leq C(A)\sum_{\textbf{n}\in\mathbb{Z}^{d}}{\rm Log}_{r-1}\left(\frac{|\phi(\textbf{n})|}{\lambda}\right).

This completes the proof.
∎
