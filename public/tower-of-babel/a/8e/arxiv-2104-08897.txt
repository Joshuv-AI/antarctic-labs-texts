X=(B_{1},z_{1},B_{2},...,B_{i-1}),\,\,a=z_{i-1},\,\,Y=B_{i}.

So we get the inequality

\frac{\langle B_{1},z_{1},B_{2},...,B_{i-1},z_{i-1},B_{i}\rangle}{(z_{i-1}+2)\langle B_{1},z_{1},B_{2},...,B_{i-1}\rangle}\leq\langle B_{i}\rangle\leq\frac{\langle B_{1},z_{1},B_{2},...,B_{i-1},z_{i-1},B_{i}\rangle}{z_{i-1}\langle B_{1},z_{1},B_{2},...,B_{i-1}\rangle}.

(21)

From (

\langle B_{1},z_{1},B_{2},...,B_{i-1}\rangle=2^{\sigma_{A_{i-1}}-1},\,\,\,\langle B_{1},z_{1},B_{2},...,B_{i-1},z_{i-1},B_{i}\rangle=2^{\sigma_{A_{i}}-1}.

By (

Recall that by (

Last four formulas enable us to write (

2^{\sigma_{A_{i-1}}+S_{A_{i}}-3}\leq\frac{2^{\tau_{i-1}+A_{i}}}{2^{s_{i-1}+2}+1}\leq\langle B_{i}\rangle\leq\frac{2^{\tau_{i-1}+A_{i}}}{2^{s_{i-1}+1}-1}\leq 2^{\sigma_{A_{i-1}}+S_{A_{i}}}.

Note that both upper and lower bounds do not depend on
s_{i-1}

From (

S_{B_{k+1}}\leq\langle B_{k+1}\rangle\leq 2^{\sigma_{A_{k}}+S_{A_{k+1}}}.

Now we can apply bound (
20
) on

) on

g_{k}\geq 2^{s_{k}}-2^{\sigma_{A_{k}}-1}>2^{(\kappa_{2}-1)S_{A_{k+1}}+\sigma_{A_{k}}+2}-2^{\sigma_{A_{k}}-1}.
