Zhongdi Cen, Jian Huang
∗

Abstract




An efficient numerical method for a time-fractional
diffusion equation

Abstract:

A reaction-diffusion problem with a Caputo time derivative is
considered. An integral discretization scheme on a graded mesh
along with a decomposition of the exact solution is proposed. The
truncation error estimate of the discretization scheme is derived
by using the remainder formula of the linear interpolation and
some inequality estimate techniques. It is proved that the scheme
is second-order convergent by applying a difference analogue of
Gronwall’s inequality, which exhibits an enhancement in the
convergence rate compared with the
L1
schemes. Numerical
experiments are presented to support the theoretical result.

Keywords:
Fractional differential equation; Caputo
derivative; singularity; graded mesh

AMS subject classifications:
65M06, 65M12, 65M15

1
Introduction

This article is prompted by recent
publications
[
3
,
10
,
11
]
where the authors consider
the following initial-boundary value problem

\displaystyle D_{t}^{\alpha}u(x,t)+Lu(x,t)=f(x,t),\ \ \ \ \ \ \ \ \ (x,t)\in Q:=(0,l)\times(0,T],

(1.1)

\displaystyle u(x,0)=\phi(x),\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \,\,\,\ \ \ \ \ \ \ x\in[0,l],

(1.2)

\displaystyle u(0,t)=u(l,t)=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ t\in(0,T].

(1.3)

Here
D_{t}^{\alpha}
denotes a Caputo fractional derivative with

0<\alpha<1
,

\displaystyle Lu(x,t):=-p\frac{\partial^{2}u}{\partial x^{2}}(x,t)+c(x)u(x,t),

p
is a positive constant,
c\in C[0,l]
with
c\geq 0
,
f\in C\left(\bar{Q}\right)
and
\phi\in C[0,l]
. It is proved
in
[
3
,
10
]
that under reasonable hypotheses on its
data, problem (1.1)-(1.3) has a unique solution
u
which
typically exhibits a weak singularity at
t=0
.

In
[
10
]
a finite difference scheme is proposed, which is
a combination of the standard
L1
approximation for

D_{t}^{\alpha}u
on a graded temporal mesh and the central
difference approximation for
Lu
on a uniform spatial mesh. It
is proved that the scheme converges with order

O\left(M^{-2}+N^{-\min\left\{2-\alpha,r\alpha\right\}}\right)
,
where
M
and
N
are the spatial and temporal discretization
parameters and
r\geq 1
is the mesh grading. In
[
3
,
11
]

a fitted difference scheme and a preprocessed
L1
scheme are used
to yield an enhanced convergence rate

O\left(M^{-2}+N^{-\min\left\{2-\alpha,2r\alpha\right\}}\right)
,
respectively.

In the present paper we construct and analyze an integral
discretization scheme on a graded mesh along with a decomposition
of the exact solution of problem (1.1)-(1.3). The truncation error
estimate of the discretization scheme is derived by using the
remainder formula of the linear interpolation and some inequality
estimate techniques. It is shown that the convergence order of our
scheme is
O\left(M^{-2}+N^{-2}\right)
by applying a difference
analogue of Gronwall’s inequality, which improves the convergence
orders given in
[
3
,
10
,
11
]
. Numerical experiments are
provided to validate the theoretical result.

Notation.
Throughout the paper,
C
will denote a generic
positive constant that is independent of the mesh. Note that
C

can take different values in different places. We always use the
(pointwise) maximum norm
\left\|\cdot\right\|_{\bar{\Omega}}
,
where
\bar{\Omega}
is a closed and bounded set.

2
The continuous problem

As in
[
3

, it is assumed that
\phi\in C^{4}[0,l]
,
0=\phi(0)=\phi^{\prime\prime}(0)=\phi(l)=\phi^{\prime\prime}(l)=f(0,t)=f(l,t)

for
0\leq t\leq T
,
c\in C^{2}[0,l]
and
f,f_{x},f_{xx}\in C\left(\bar{Q}\right)
, and it is shown that the exact solution

u
of problem (1.1)-(1.3) can be decomposed as

\displaystyle u(x,t)=z(x)t^{\alpha}+\phi(x)+v(x,t),\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \left(x,t\right)\in\bar{Q},

(2.1)

where

\displaystyle z(x)=\frac{1}{\Gamma\left(\alpha+1\right)}\left(f(x,0)+p\phi^{\prime\prime}(x)-c(x)\phi(x)\right),

(2.2)

and
v(x,t)
is the solution of the following initial-boundary
value problem

\displaystyle\left(D_{t}^{\alpha}+L\right)v(x,t)=f(x,t)+g(x,t),\ \ \ \ \ \ \ \ \ \ \ \ \left(x,t\right)\in Q,\ \ \ \

(2.3)

\displaystyle v(x,0)=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ x\in[0,l],

(2.4)

\displaystyle v(0,t)=v(l,t)=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \,\ \ t\in(0,T],

(2.5)

where

\displaystyle g(x,t)=-f(x,0)+pz^{\prime\prime}(x)t^{\alpha}-c(x)z(x)t^{\alpha}.

It is proved
in
[
3
, Theorem 1]
, under extra regularity assumptions

f_{ttt}\left(\cdot,t\right)\in D\left(L^{1/2}\right)
and

\left\|f_{tt}\left(\cdot,t\right)\right\|_{L^{1/2}}+t^{\tilde{\rho}}\left\|f_{ttt}\left(\cdot,t\right)\right\|_{L^{1/2}}\leq C_{1}
for all
t\in(0,T]
, where
0<\rho<1
and
C_{1}
is a
constant independent of
t
, that
v(x,t)
satisfies

\displaystyle\left|\frac{\partial^{k+\ell}v}{\partial x^{k}\partial t^{\ell}}\right|\leq C\left(1+t^{2\alpha-\ell}\right),\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ 0\leq k+\ell\leq 4,\ \ \ 0\leq\ell\leq 2

(2.6)

for all
\left(x,t\right)\in[0,l]\times(0,T]
and some constant

C
. The similar bounds have been given in
[
10
, Theorem
2.1]
, but with
2\alpha
replaced by
\alpha
. From these
bounds we know that
v
is smoother than
u

It is shown in
[
2
, Lemma 6.2]
that the problem
(2.3)-(2.5) can be written as the following equivalent
integral-differential equation with a weakly singular kernel

\displaystyle v(x,t)=v(x,0)+\frac{1}{\Gamma(\alpha)}\int_{0}^{t}\left(t-s\right)^{\alpha-1}\left[f(x,s)-Lv(x,s)\right]{\rm d}s+G(x,t),\ \ \ \ (x,t)\in Q,\ \ \ \ \ \

(2.7)

\displaystyle v(x,0)=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \,\ \ \ \ \ \ \ \ \ \ x\in[0,l],

(2.8)

\displaystyle v(0,t)=v(l,t)=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ t\in(0,T],

(2.9)

where

\displaystyle G(x,t)=-\frac{t^{\alpha}}{\Gamma(\alpha+1)}f(x,0)+\frac{t^{2\alpha}}{\Gamma(\alpha)}\left(pz^{\prime\prime}(x)-c(x)z(x)\right)B(\alpha+1,\alpha).

In the following we will
discrete this integral-differential equation instead of the
differential equation (1.1)-(1.3).

3
Discretization

In this section we describe a numerical scheme for the
integral-differential equation (2.7)-(2.9). The numerical scheme
is based on a quadrature rule for the integral term and a central
difference method for the temporal discretization.

Based on the properties of the exact solution
v(x,t)
we
construct a graded mesh
\Omega^{M,N}:=\Omega^{M}\times\Omega^{N}
, where
\Omega^{M}=\left\{x_{i}=ih\left|0\leq i\leq M,h=i/M\right.\right\}
and
\Omega^{N}=\left\{t_{j}\left|0\leq j\leq N,\triangle t_{j}=t_{j}-t_{j-1}\right.\right\}
with

\displaystyle t_{j}=\left\{\begin{array}[]{ll}T\left(\frac{1}{N}\right)^{2/\alpha},&j=1,\\
T\left(\frac{1}{N}\right)^{2/\alpha}+T\left(\frac{1}{N}\right)^{3/(2\alpha)},&j=2,\\
T\left(\frac{1}{N}\right)^{2/\alpha}+T\left(\frac{1}{N}\right)^{3/(2\alpha)}+T\left[1-\left(\frac{1}{N}\right)^{2/\alpha}-\left(\frac{1}{N}\right)^{3/(2\alpha)}\right]\left(\frac{j-2}{N-2}\right)^{1/\alpha},&3\leq j\leq N.\end{array}\right.

On this mesh our discrete scheme is second-order convergent.
Furthermore, this mesh avoids too many mesh points concentrating
around
t=0
compared with the standard graded mesh

t_{j}=T\left(\frac{j}{N}\right)^{2/\alpha}
for
0\leq j\leq N

as that in
[
9
,
6
,
7
,
10
]
, which improves the
accuracy.

An approximation to the integral can be obtained by the following
quadrature formula

\displaystyle\int_{0}^{t_{j}}\left(t_{j}-s\right)^{\alpha-1}\left[f(x,s)-Lv\left(x,s\right)\right]{\rm d}s

\displaystyle\approx\sum_{k=1}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{k}-s}{\triangle t_{k}}\left(f(x,t_{k-1})-Lv(x,t_{k-1})\right)+\frac{s-t_{k-1}}{\triangle t_{k}}\left(f(x,t_{k})-Lv(x,t_{k})\right)\right]{\rm d}s.

Then, we have the following discretization scheme for problem
(2.7)-(2.9):

\displaystyle\left\{\begin{array}[]{ll}V^{0}_{i}=0,\\
\left\{\begin{array}[]{ll}\displaystyle{V^{j}_{i}=V^{0}_{i}+\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j}\left\{\triangle t_{k}\left(t_{j}-t_{k-1}\right)^{\alpha}-\frac{1}{\alpha+1}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}\right.\right.}\\
\displaystyle{\left.\left.-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}\frac{f^{k-1}_{i}-L^{M}V^{k-1}_{i}}{\triangle t_{k}}+\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j}\left\{-\triangle t_{k}\left(t_{j}-t_{k}\right)^{\alpha}\right.}\\
\displaystyle{\left.+\frac{1}{\alpha+1}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}\frac{f^{k}_{i}-L^{M}V^{k}_{i}}{\triangle t_{k}}}+G_{i}^{j},\ \ \ \ \ \ \ \ \ 1\leq i<M,\\
V^{j}_{0}=V^{j}_{M}=0,\end{array}\right.\\
{\rm for}\ \ j=1,2,\cdots,N,\end{array}\right.

where
V_{i}^{j}
is the discrete approximation to the exact
solution
v
of (2.7)-(2.9) at the mesh point
(x_{i},t_{j})
and
the discrete operator
L^{M}
is defined as

\displaystyle L^{M}V_{i}^{j}\equiv-p\frac{V_{i+1}^{j}-2V_{i}^{j}+V_{i-1}^{j}}{h^{2}}+c_{i}V_{i}^{j}.

(3.13)

4
Convergence analysis

Let
w^{j}_{i}=V^{j}_{i}-v(x_{i},t_{j})
, where
V_{i}^{j}
is the
solution of problem (3.2) and
v(x_{i},t_{j})
is the solution of
problem (2.7)-(2.9) at the mesh point
\left(x_{i},t_{j}\right)

Then, the error
w_{i}^{j}
satisfies the following equation

\displaystyle w_{i}^{j}+\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j}\left\{\left(t_{j}-t_{k-1}\right)^{\alpha}-\frac{1}{\left(\alpha+1\right)\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}L^{M}w^{k-1}_{i}

\displaystyle+\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j}\left\{-\left(t_{j}-t_{k}\right)^{\alpha}+\frac{1}{\left(\alpha+1\right)\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}L^{M}w^{k}_{i}

\displaystyle=R^{j}_{i},\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ 1\leq i<M,\ 1\leq j\leq N,

(4.1)

\displaystyle w^{0}_{i}=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \,\ 1\leq i<M,

(4.2)

\displaystyle w_{0}^{j}=w_{M}^{j}=0,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ 1\leq j\leq N,

(4.3)

where

\displaystyle R^{j}_{i}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha)}\sum_{k=1}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{k}-s}{\triangle t_{k}}f(x_{i},t_{k-1})+\frac{s-t_{k-1}}{\triangle t_{k}}f(x_{i},t_{k})-f(x_{i},s)\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=1}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}Lv(x_{i},s){\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=1}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\frac{t_{k}-s}{\triangle t_{k}}\left[Lv(x_{i},t_{k-1})-L^{M}v(x_{i},t_{k-1})\right]{\rm d}s

Lemma 4.3

Case I

\displaystyle\left|R^{1}_{i}\right|

\displaystyle\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{1}-s\right)^{\alpha-1}\left|\frac{t_{1}-s}{\triangle t_{1}}f(x_{i},0)+\frac{s}{\triangle t_{1}}f(x_{i},t_{1})-f(x_{i},s)\right|{\rm d}s

(4.11)

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{1}-s\right)^{\alpha-1}\left|Lv(x_{i},s)\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{1}-s\right)^{\alpha-1}\left[\frac{t_{1}-s}{\triangle t_{1}}\left|Lv(x_{i},0)\right|+\frac{s}{\triangle t_{1}}\left|Lv(x_{i},t_{1})\right|\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{1}-s\right)^{\alpha-1}\frac{t_{1}-s}{\triangle t_{1}}\left|Lv(x_{i},0)-L^{M}v(x_{i},0)\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{1}-s\right)^{\alpha-1}\frac{s}{\triangle t_{1}}\left|Lv(x_{i},t_{1})-L^{M}v(x_{i},t_{1})\right|{\rm d}s

\displaystyle\leq

\displaystyle C\left(t_{1}^{\alpha}+t_{1}^{\alpha}M^{-2}\right)\leq CN^{-2},

where we have used the assumptions for
f
, (2.6), (3.1) and a
Taylor expansion for
v(x,\cdot)
about
x_{i}
. From this we
conclude that the lemma holds true for Case I.

Case II
:
1<j\leq N
.

We decompose the truncation error into two components as follows

\displaystyle R^{j}_{i}=R^{j,1}_{i}+R^{j,2}_{i},

(4.12)

where

\displaystyle R^{j,1}_{i}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{1}-s}{\triangle t_{1}}f(x_{i},0)+\frac{s}{\triangle t_{1}}f(x_{i},t_{1})-f(x_{i},s)\right]{\rm d}s

(4.13)

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}Lv(x_{i},s){\rm d}s

\displaystyle-\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{1}-s}{\triangle t_{1}}Lv(x_{i},0)+\frac{s}{\triangle t_{1}}Lv(x_{i},t_{1})\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\frac{t_{1}-s}{\triangle t_{1}}\left[Lv(x_{i},0)-L^{M}v(x_{i},0)\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\frac{s}{\triangle t_{1}}\left[Lv(x_{i},t_{1})-L^{M}v(x_{i},t_{1})\right]{\rm d}s,

and

\displaystyle R^{j,2}_{i}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{k}-s}{\triangle t_{k}}f(x_{i},t_{k-1})+\frac{s-t_{k-1}}{\triangle t_{k}}f(x_{i},t_{k})-f(x_{i},s)\right]{\rm d}s

(4.14)

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}Lv(x_{i},s){\rm d}s

\displaystyle-\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left[\frac{t_{k}-s}{\triangle t_{k}}Lv(x_{i},t_{k-1})+\frac{s-t_{k-1}}{\triangle t_{k}}Lv(x_{i},t_{k})\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\frac{t_{k}-s}{\triangle t_{k}}\left[Lv(x_{i},t_{k-1})-L^{M}v(x_{i},t_{k-1})\right]{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\frac{s-t_{k-1}}{\triangle t_{k}}\left[Lv(x_{i},t_{k})-L^{M}v(x_{i},t_{k})\right]{\rm d}s.

Similarly to Case I, from (4.13) we have

\displaystyle\left|R^{j,1}_{i}\right|

\displaystyle\leq

\displaystyle\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\left|\frac{t_{1}-s}{\triangle t_{1}}f(x_{i},0)+\frac{s}{\triangle t_{1}}f(x_{i},t_{1})-f(x_{i},s)\right|{\rm d}s

(4.15)

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\left|Lv(x_{i},s)\right|{\rm d}s

\displaystyle-\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\left|\frac{t_{1}-s}{\triangle t_{1}}Lv(x_{i},0)+\frac{s}{\triangle t_{1}}Lv(x_{i},t_{1})\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\frac{t_{1}-s}{\triangle t_{1}}\left|Lv(x_{i},0)-L^{M}v(x_{i},0)\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\int_{0}^{t_{1}}\left(t_{j}-s\right)^{\alpha-1}\frac{s}{\triangle t_{1}}\left|Lv(x_{i},t_{1})-L^{M}v(x_{i},t_{1})\right|{\rm d}s

\displaystyle\leq

\displaystyle C\left[t_{j}^{\alpha}-\left(t_{j}-t_{1}\right)^{\alpha}\right]\left[\left(\triangle t_{1}\right)^{2}+1+M^{-2}\right]

\displaystyle\leq

\displaystyle Ct_{1}\left(t_{j}-t_{1}\right)^{\alpha-1}\leq Ct_{1}^{\alpha}\leq CN^{-2},

where we also have used the assumptions for
f
, (2.6), (3.1), the
remainder formula of the linear interpolation for
f(\cdot,t)
and
a Taylor expansion for
v(x,\cdot)
about
x_{i}
. From (4.14) we
have

\displaystyle\left|R^{j,2}_{i}\right|

\displaystyle\leq

\displaystyle\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left|\frac{t_{k}-s}{\triangle t_{k}}f(x_{i},t_{k-1})+\frac{s-t_{k-1}}{\triangle t_{k}}f(x_{i},t_{k})-f(x_{i},s)\right|{\rm d}s

(4.16)

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left|Lv(x_{i},s)-\frac{t_{k}-s}{\triangle t_{k}}Lv(x_{i},t_{k-1})-\frac{s-t_{k-1}}{\triangle t_{k}}Lv(x_{i},t_{k})\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\frac{t_{k}-s}{\triangle t_{k}}\left|Lv(x_{i},t_{k-1})-L^{M}v(x_{i},t_{k-1})\right|{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\frac{s-t_{k-1}}{\triangle t_{k}}\left|Lv(x_{i},t_{k})-L^{M}v(x_{i},t_{k})\right|{\rm d}s

\displaystyle\leq

\displaystyle\frac{1}{\Gamma(\alpha)}\sum_{k=2}^{j}\left|\frac{\partial^{2}f}{\partial t^{2}}(x_{i},\xi_{k})\right|\left(\triangle t_{k}\right)^{2}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}{\rm d}s

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=4}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}\left|Lv(x_{i},s)-\frac{t_{k}-s}{\triangle t_{k}}Lv(x_{i},t_{k-1})-\frac{s-t_{k-1}}{\triangle t_{k}}Lv(x_{i},t_{k})\right|{\rm d}s

\displaystyle+CN^{-2}+CM^{-2}\sum_{k=2}^{j}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}{\rm d}s

\displaystyle\leq

\displaystyle C\sum_{k=2}^{j}\left[\left(t_{j}-t_{k-1}\right)^{\alpha}-\left(t_{j}-t_{k}\right)^{\alpha}\right]\left[\left(\triangle t_{k}\right)^{2}+M^{-2}\right]+CN^{-2}

\displaystyle+\frac{1}{\Gamma(\alpha)}\sum_{k=4}^{j}\left|L\frac{\partial^{2}v}{\partial t^{2}}(x,\eta_{k})\right|\left(\triangle t_{k}\right)^{2}\int_{t_{k-1}}^{t_{k}}\left(t_{j}-s\right)^{\alpha-1}{\rm d}s

\displaystyle\leq

\displaystyle C\left(M^{-2}+N^{-2}\right)\left(t_{j}-t_{1}\right)^{\alpha}+CN^{-2}+C\sum_{k=4}^{j}\left[\left(t_{j}-t_{k-1}\right)^{\alpha}-\left(t_{j}-t_{k}\right)^{\alpha}\right]\left(\triangle t_{k}\right)^{2}t_{k-1}^{2\alpha-2}

\displaystyle\leq

\displaystyle C\left(M^{-2}+N^{-2}\right),

where we have used the remainder formula of the linear
interpolation for
v(\cdot,t)
and
f(\cdot,t)
with
\xi_{k},\eta_{k}\in(t_{k-1},t_{k})
, the bounds on
v(x,t)
and its
derivatives given by (2.6), the assumptions for
f(x,t)
, Lemmas
4.2 and 4.3. Therefore, from (4.12), (4.15) and (4.16) we conclude
that the lemma also holds true for Case II.

Next we give the error estimates for the discretization scheme.

Theorem 4.5
Let
v(x,t)
be the solution of problem
(2.7)-(2.9) and
V
be the solution of problem (3.2). Then, under
some regularity conditions on the data, we have the following
error estimate

\displaystyle\left\|V-v\right\|_{\Omega^{M,N}}\leq C\left(M^{-2}+N^{-2}\right),

(4.17)

where
C
is a positive constant independent of
M
and
N
.

Proof.
From (4.1) we have

\displaystyle w^{j}_{i}

\displaystyle=

\displaystyle\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)^{-1}R^{j}_{i}-\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j}\left\{\left(t_{j}-t_{k-1}\right)^{\alpha}\right.

(4.18)

\displaystyle\left.-\frac{1}{(\alpha+1)\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)^{-1}L^{M}w^{k-1}_{i}

\displaystyle-\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j-1}\left\{-\left(t_{j}-t_{k}\right)^{\alpha}+\frac{1}{(\alpha+1)\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right\}

\displaystyle\cdot\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)^{-1}L^{M}w^{k}_{i}.

It is easy to see that the operator
\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)
satisfies a
discrete maximum principle, and consequently

\displaystyle\left\|\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)^{-1}\right\|_{\Omega^{M}}\leq 1,\ \ \ \ \ \ \ \ \ \ \ \ 1\leq j\leq N.

(4.19)

Furthermore, applying the result proved in Palencia
[
8
]
we
have

\displaystyle\left\|\left(I+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}L^{M}\right)^{-1}L^{M}\right\|_{\Omega^{M}}\leq d_{j},\ \ \ \ \ \ \ \ \ \ \ \ \ 1\leq j\leq N,

(4.20)

since
\left(1+\frac{\left(\triangle t_{j}\right)^{\alpha}}{\Gamma(\alpha+2)}y\right)^{-1}y
is a
rational A-acceptable function, where
d_{j}
is a positive
constant. The analogous problems have been discussed
in
[
1
,
5
]
.

Therefore, from (4.18)-(4.20) we can
obtain

\displaystyle\left\|w^{j}\right\|_{\Omega^{M}}\leq z_{j}+d_{j}\sum_{k=1}^{j-1}q_{k}\left\|w^{k}\right\|_{\Omega^{M}},

(4.21)

where

\displaystyle z_{k}

\displaystyle=

\displaystyle\left\|R^{k}\right\|_{\Omega^{M}},

\displaystyle q_{k}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha+2)}\left\{\frac{1}{\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right.

\displaystyle\left.-\frac{1}{\triangle t_{k+1}}\left[\left(t_{j}-t_{k}\right)^{\alpha+1}-\left(t_{j}-t_{k+1}\right)^{\alpha+1}\right]\right\},\ \ \ \ \ \ \ 1\leq k\leq j.

Then applying the discrete analogue of Gronwall’s
inequality
[
13
, Theorem 3]
, we have

\displaystyle\left\|w^{j}\right\|_{\Omega^{M}}\leq z_{j}+d_{j}\prod_{m=1}^{j-1}\left(1+d_{m}q_{m}\right)\cdot\sum_{k=1}^{j-1}\left[z_{k}q_{k}\prod_{m=1}^{k}\left(1+d_{m}q_{m}\right)^{-1}\right]

(4.22)

for
1\leq j\leq N
. Lemma 4.4 implies

\displaystyle 0<z_{k}\leq C\left(M^{-2}+N^{-2}\right),\ \ \ \ \ \ \ \ \ \ \ \ \ 1\leq k\leq j.

(4.23)

Furthermore, we have

\displaystyle\sum_{k=1}^{j-1}q_{k}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha+2)}\sum_{k=1}^{j-1}\left\{\frac{1}{\triangle t_{k}}\left[\left(t_{j}-t_{k-1}\right)^{\alpha+1}-\left(t_{j}-t_{k}\right)^{\alpha+1}\right]\right.

(4.24)

\displaystyle\left.-\frac{1}{\triangle t_{k+1}}\left[\left(t_{j}-t_{k}\right)^{\alpha+1}-\left(t_{j}-t_{k+1}\right)^{\alpha+1}\right]\right\}

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha+1)}\sum_{k=1}^{j-1}\left[\left(t_{j}-\mu_{k}\right)^{\alpha}-\left(t_{j}-\mu_{k+1}\right)^{\alpha}\right]

\displaystyle=

\displaystyle\frac{1}{\Gamma(\alpha+1)}\left[\left(t_{j}-\mu_{1}\right)^{\alpha}-\left(t_{j}-\mu_{j}\right)^{\alpha}\right],

where we have used the mean value theorem with
\mu_{k}\in(t_{k-1},t_{k})
. Thus we have

\displaystyle\sum_{k=1}^{j-1}\left[z_{k}q_{k}\prod_{m=1}^{k}\left(1+d_{m}q_{m}\right)^{-1}\right]\leq CN^{-2}\sum_{k=1}^{j-1}q_{k}

\displaystyle=C\left(M^{-2}+N^{-2}\right)\left[\left(t_{j}-\mu_{1}\right)^{\alpha}-\left(t_{j}-\mu_{j}\right)^{\alpha}\right]

\displaystyle\leq C\left(M^{-2}+N^{-2}\right),

(4.25)

and

\displaystyle\prod_{m=1}^{j-1}\left(1+d_{m}q_{m}\right)\leq\exp\left(\sum_{m=1}^{j-1}d_{m}q_{m}\right)\leq\exp\left(C\left[\left(t_{j}-\mu_{1}\right)^{\alpha}-\left(t_{j}-\mu_{j}\right)^{\alpha}\right]\right)\leq C,

(4.26)

where we have used (4.23)-(4.24) and the inequality

\left(1+y\right)\leq e^{y}
for
y\geq-1
. Hence, combining
(4.25)-(4.26) with (4.22) we can obtain

\displaystyle\left\|w^{j}\right\|_{\Omega^{M}}\leq C\left(M^{-2}+N^{-2}\right),\ \ \ \ \ \ \ \ \ \ \ \ \ \ 1\leq j\leq N.

From this we complete the proof.

Then, our approximation
U_{i}^{j}
of
u(x_{i},t_{j})
can be
obtained from (2.1)

\displaystyle U_{i}^{j}=z(x_{i})t_{j}^{\alpha}+\phi(x_{i})+V_{i}^{j},\ \ \ \ \ \ \ \ 0\leq i\leq M,\ 0\leq j\leq N.

(4.27)

Therefore, from (4.27) and Theorem 4.5 we have

\displaystyle\left\|U-u\right\|_{\Omega^{M,N}}\leq C\left(M^{-2}+N^{-2}\right),

(4.28)

which improves the convergence orders given
in
[
3
,
10
,
11
]
. There are two reasons for an
enhancement in the convergence rate. The first one is that the
fractional differential equation is transformed into an equivalent
integral-differential equation which reduces the singularity of
the integrand function. The other reason is that the decomposition
of the exact solution is used and the remainder term
v
is
smoother than
u
.
