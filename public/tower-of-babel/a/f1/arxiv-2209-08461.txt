Random Fourier Features for Asymmetric kernels
Mingzhen He, Fan He, Fanghui Liu, Xiaolin Huang

Abstract
The random Fourier features (RFFs) method is a powerful and popular technique in kernel approximation for scalability of kernel methods. The theoretical foundation of RFFs is based on the Bochner theorem ( Bochner, 2005 ) that relates symmetric, positive definite (PD) functions to probability measures. This condition naturally excludes asymmetric functions with a wide range applications in practice, e.g., directed graphs, conditional probability, and asymmetric kernels. Nevertheless, understanding asymmetric functions (kernels) and its scalability via RFFs is unclear both theoretically and empirically. In this paper, we introduce a complex measure with the real and imaginary parts corresponding to four finite positive measures, which expands the application scope of the Bochner theorem. By doing so, this framework allows for handling classical symmetric, PD kernels via one positive measure; symmetric, non-positive definite kernels via signed measures; and asymmetric kernels via complex measures, thereby unifying them into a general framework by RFFs, named AsK-RFFs. Such approximation scheme via complex measures enjoys theoretical guarantees in the perspective of the uniform convergence. In algorithmic implementation, to speed up the kernel approximation process, which is expensive due to the calculation of total mass, we employ a subset-based fast estimation method that optimizes total masses on a sub-training set, which enjoys computational efficiency in high dimensions. Our AsK-RFFs method is empirically validated on several typical large-scale datasets and achieves promising kernel approximation performance, which demonstrate the effectiveness of AsK-RFFs.

Introduction

Kernel methods
(
Schölkopf and Smola, 2002
;
Suykens et al., 2002
;
Vapnik, 2013
)
play a significant role in statistical machine learning in almost all the topics, e.g., classification
(
Soman et al., 2009
)
, regression
(
Drucker et al., 1997
)
, clustering
(
Girolami, 2002
)
, and dimension reduction
(
Schölkopf et al., 1997
)
.
One significant limitation is the lack of scalability due to the fact that kernel methods are working on the kernel matrices which have the size
N\times N
with
N
being the number of samples.
Kernel approximation
(
Williams and Seeger, 2001
;
Drineas et al., 2005
;
Liu et al., 2021b
)
is able to address this issue by approximating the original kernel matrix or kernel function.
One typical technique tool is

Random Fourier features
(RFFs) that introduces low dimensional randomized feature mappings for approximating the original kernel function
(
Rahimi and Recht, 2007
;
Rahimi and Recht, 2008
)
. The theoretical foundation of RFFs is established by the Bochner’s theorem in harmonic analysis
(
Bochner, 2005
;
Rahimi and Recht, 2007
)
. The Bochner’s theorem claims that a continuous, symmetric, shift-invariant and positive definite (PD) function can be approximated by a finite non-negative measure.
Besides, RFFs can be regarded as a two-layer neural network with only training the second layer, which naturally bridges kernel methods and neural networks in deep learning theory
(
Mehrkanoon and Suykens, 2018
;
Belkin et al., 2019
;
Malach et al., 2020
)
; refer to one recent survey
(
Liu et al., 2021b
)
.

The target of RFFs is to establish an explicit feature mapping via the sampled random features and then approximate the original kernel function via inner product. There is a strict pre-condition on RFFs that the sampling measure is well-defined only when the kernel is stationary, PD, and symmetric.
Extension of RFFs to other kernels, e.g., polynomial kernels
(
Pennington et al., 2015
)
, non-positive definite kernel, e.g., the neural tangent kernel of two-layer ReLU networks with unit spherical constraints
(
Liu et al., 2021a
)
is important and has been discussed. However, study on RFFs for asymmetric kernels is missing in the machine learning community.

In practice, asymmetric similarities/dissimilarities are commonly used.
Here we take several typical examples to illustrate this.
1) In directed graphs, the adjacency matrices that record (weighted)
connections between two samples can efficiently represent asymmetric similarities.
The relationship between a central and a local node can be asymmetric. For example, in federated learning, the central update is aggregated by updates of all local nodes.
In this case, neural tangent kernel-based federated learning is asymmetric
(
Huang et al., 2021
)
.
2) the conditional probability is another popular scene we may meet asymmetric similarities due to
{\rm P}(A|B)\neq{\rm P}(B|A)
in general, where
A
and
B
are two events in an event space. Some applications for conditional probabilities could be found in the works of
Hinton and Roweis, 2002
;
Tang et al., 2015a
;
Tang et al., 2015b
.
3) Asymmetric kernels, as a tool more flexible than PD kernels, are promising to connect to deep models. As an encouraging attempt,
Wright and Gonzalez, 2021
successfully characterize the dot-product attention by asymmetric kernels and provides a theoretical understanding of transformer models
(
Vaswani et al., 2017
)
.

In theory, the function space associated with asymmetric kernels is often built on reproducing kernel Banach spaces (RKBS)
(
Zhang et al., 2009
;
Song et al., 2013
;
Fasshauer et al., 2015
;
Bartolucci et al., 2021
;
Lin et al., 2022
)
instead of the classical reproducing kernel Hilbert spaces (RKHS).
For the primal feature analysis,
Suykens, 2016
;
Suykens, 2017
introduce a variational principle for understanding the singular value decomposition from the perspective of asymmetric kernels associated with different feature mappings. These theories are helpful for understanding asymmetric kernels but are not suitable to handle the
approximation problem.

Extension of standard RFFs to asymmetric kernels is unanswered and non-trivial both theoretically and algorithmically.
To be specific, theoretically, the original probability measure for PD kernels
(
Rahimi and Recht, 2007
)
and signed measure for indefinite but symmetric kernels
(
Huang et al., 2017
;
Liu et al., 2021a
)
cannot be used as
the sampling measure for asymmetric kernels, which is the main obstacle of RFFs for asymmetric kernels.
Algorithmically, the point evaluation at the origin is not sufficient to represent the corresponding total masses of measures, which differs from that in the Bochner’s theorem. In this scene, calculation of total masses often involves a
d
dimensional numerical integral, which is time-consuming in high dimensions.

In this paper, we propose a unified kernel approximation framework for asymmetric kernels by RFFs, called
AsK-RFFs
, which fills the gap of asymmetric kernels from theory to practice. Ask-RFFs design a complex measure on the sample space for a real, absolutely integrable, and shift-invariant kernel, without any requirement on symmetry. In theory, we provide the uniform convergence bound of the proposed AsK-RFFs, which is not only for asymmetric kernels but is also applicable to PD and indefinite kernels. In the algorithm, we partition a complex measure into four finite positive measures and then approximate asymmetric kernels by using the Monte Carlo sampling method to sample a series of random Fourier features.
One crucial and skillful point is to efficiently calculate total masses via a subset-based strategy.
By doing so, Ask-RFFs enjoys nice theoretical guarantees and promising approximation performance in several large-scale benchmark datasets.

In the rest of this paper, Section
2
briefly introduces preliminaries about RFF and measures. Then, we give the formulation of AsK-RFFs with its uniform convergence bound in Section
3
. We give three typical asymmetric kernels and investigate an estimation algorithm for total masses in Section
4
. Section
5
shows the experimental results of the proposed AsK-RFFs on several large datasets. Finally, a brief conclusion is drawn in Section
6
.

2
Preliminaries

In this section, we briefly sketch several basic properties of random Fourier features and complex measures which are needful in the approximation for asymmetric kernels. Let
\mathcal{X}=\{\boldsymbol{x_{k}}\}_{k=1}^{N}\subset\mathbb{R}^{d}
be the sample set.
Denote
\mathsf{i}=\sqrt{-1}
.

Theorem 1

(Bochner’s theorem
(
Bochner, 2005
)
)
.

Let
k:\mathbb{R}^{d}\times\mathbb{R}^{d}\rightarrow\mathbb{R}
be a continuous, symmetric, and shift-invariant function, i.e.,
k(\boldsymbol{x},\boldsymbol{y})=k(\boldsymbol{x}-\boldsymbol{y})
and
k(\boldsymbol{0})=1
. Then
k
is a positive definite function if and only if it is the Fourier transform of a finite non-negative Borel measure
\mu
.

k(\boldsymbol{x}-\boldsymbol{y})=\int_{\mathbb{R}^{d}}e^{\mathsf{i}\boldsymbol{\omega}^{\top}(\boldsymbol{x}-\boldsymbol{y})}\mu(\mathrm{d}\boldsymbol{\omega})=\mathbb{E}_{\boldsymbol{\omega}\sim\mu}\left[e^{\mathsf{i}\boldsymbol{\omega}^{\top}(\boldsymbol{x}-\boldsymbol{y})}\right]\,.

A positive definite kernel can be constructed by a finite non-negative Borel measure. According to Theorem
1
, one can approximate a positive definite (symmetric) kernel
k(\boldsymbol{x}-\boldsymbol{y})=\mathbb{E}_{\boldsymbol{\omega}\sim\mu}\left[e^{i\boldsymbol{\omega}^{\top}(\boldsymbol{x}-\boldsymbol{y})}\right]
by the Monte Carlo sampling method to sample a series of random Fourier features
\{\boldsymbol{\omega_{k}}\}_{k=1}^{M}
from the normalized measure
\mu
which can be regarded as a probability measure by taking
k(\bm 0)=1

(
Rahimi and Recht, 2007
)
.
However, for asymmetric kernels, their Fourier transform can not be associated with a probability measure, which does not allows for designing the random features sampling strategy in our problem.
To address this, we need study the conjugate property and complex measure that are required for analysis of non-positive definite kernels.

Theorem 2

(Conjugate property
(
Pinsky, 2008
)
)
.

Given a real absolutely integrable function
k(\boldsymbol{\Delta})
and its Fourier transform
\mu(\boldsymbol{\omega})
where
\boldsymbol{\Delta},\boldsymbol{\omega}\in\mathbb{R}^{d}
, then one has the reality condition
\mu(-\boldsymbol{\omega})=\overline{\mu(\boldsymbol{\omega})}
.

Denote
\mu:=\mu_{R}+\mathsf{i}\mu_{I}
, then it is obvious that
\mu_{R}
is even and
\mu_{I}
is odd with respect to
\boldsymbol{\omega}
, i.e.,
\mu_{R}(\boldsymbol{\omega})=\mu_{R}(-\boldsymbol{\omega})
and
\mu_{I}(\boldsymbol{\omega})=-\mu_{I}(-\boldsymbol{\omega})
.
In the following, we introduce complex measures which will help to build the asymmetric kernel approximation. Actually, a finite positive measure and a finite signed measure have been used in approaching PD
kernels
(
Rahimi and Recht, 2007
)
and indefinite kernels
(
Liu et al., 2021a
)
, respectively.

Definition 1

(Complex measures
(
Cohn, 2013
)
)
.

Let
\Omega
be a sample set,
\mathcal{M}
be a
\sigma
-algebra of subsets on
\Omega
and
(\Omega,\mathcal{M})
be a measurable space. A complex measure on
(\Omega,\mathcal{M})
is a complex-valued function
\mu:\mathcal{M}\rightarrow\mathbb{C}
that satisfies
\mu(\varnothing)=0
and countable additivity.

A complex measure
\mu
on a measurable space
(\Omega,\mathcal{M})
can be formulated as
\mu=\mu_{R}+\mathsf{i}\mu_{I}
, where
\mu_{R}
and
\mu_{I}
are two finite signed measures on
(\Omega,\mathcal{M})
.

Theorem 3

(Jordan decomposition
(
Athreya and Lahiri, 2006
)
)
.

Every signed measure is the difference of two positive measures
\zeta=\zeta^{+}-\zeta^{-}
, at least one of which is finite.

The Jordan decomposition theory implies that a complex measure
\mu
consists of four finite positive measures
\mu_{R}^{+}
,
\mu_{R}^{-}
,
\mu_{I}^{+}
and
\mu_{I}^{-}
on a measurable space
(\Omega,\mathcal{M})
as the following,

\mu=\mu_{R}^{+}-\mu_{R}^{-}+\mathsf{i}\mu_{I}^{+}-\mathsf{i}\mu_{I}^{-}\,.

(1)

Notice that the decomposition of a complex measure is not unique.

3
Methods

In this section, we propose a novel framework for
approximating asymmetric kernels by random Fourier features (AsK-RFFs). We will first introduce the random features and then establish a uniform convergence on the approximation ability. The algorithms including the sampling method and the total mass estimation are given in the next section.

Given a real and absolutely integrable kernel function
k:\mathbb{R}^{d}\times\mathbb{R}^{d}\rightarrow\mathbb{R}
,
k(\boldsymbol{x},\boldsymbol{y})=k(\boldsymbol{x}-\boldsymbol{y})=k(\boldsymbol{\Delta})
(maybe not symmetric),
\boldsymbol{x},\boldsymbol{y}\in\mathcal{X}\subset\mathbb{R}^{d}
and its Fourier transform as a complex measure
\mu(\boldsymbol{\omega})=\mu_{R}(\boldsymbol{\omega})+\mathsf{i}\mu_{I}(\boldsymbol{\omega})
where
\boldsymbol{\omega}\in\mathbb{R}^{d}
, we can define four positive measures as the following,

\left\{\begin{aligned} {}&\mu_{R}^{+}=\max\{\mu_{R},0\},~\mu_{R}^{-}=\max\{-\mu_{R},0\}\\
&\mu_{I}^{+}=\max\{\mu_{I},0\},~\mu_{I}^{-}=\max\{-\mu_{I},0\}\,.\\
\end{aligned}\right.

(2)

According to Theorem
2
, the imaginary part
\mu_{I}
is odd, and then the following equation holds,

\mu_{I}^{+}(-\boldsymbol{\omega})=\max\{\mu_{I}(-\boldsymbol{\omega}),0\}=\max\{-\mu_{I}(\boldsymbol{\omega}),0\}=\mu_{I}^{-}(\boldsymbol{\omega})\,.

(3)

Definition 2
.

(Total masses of positive measures)
Suppose
\zeta
is a finite positive measure on a measurable space
(\Omega,\mathcal{M})
, the total mass of
\zeta
, denoted
\|\zeta\|
, is defined by
\|\zeta\|=\int_{\boldsymbol{\omega}\in\Omega}\zeta(\mathrm{d}\boldsymbol{\omega})=\zeta(\Omega)<\infty
.

Remark 1
.

Specifically, a (normalized) measure
\tilde{\zeta}=\zeta/\|\zeta\|
is a probability measure i.e.,
\tilde{\zeta}(\Omega)=1
. Then a mathematical triple
(\Omega,\mathcal{M},\tilde{\zeta})
is the corresponding probability space. It helps us to “sample” from a finite positive measure
\zeta
,
\int_{\Omega}fd\zeta=\int_{\Omega}f\|\zeta\|d\tilde{\zeta}=\mathbb{E}_{\tilde{\zeta}}[f\|\zeta\|]
.

According to the Jordan decomposition, a complex measure is made up of four finite positive measures, as shown in (
1
). In this paper, the total mass of a complex measure is defined as follows,

Definition 3
.

(Total masses of complex measures)
Suppose a complex measure
\mu
on a measurable space
(\Omega,\mathcal{M})
can be written in the form of (
1
) i.e.,
\mu=\mu_{R}^{+}-\mu_{R}^{-}+\mathsf{i}\mu_{I}^{+}-\mathsf{i}\mu_{I}^{-}
.
The total mass of
\mu
, denoted
\|\mu\|
, is defined by

\|\mu\|=\|\mu_{R}^{+}\|+\|\mu_{R}^{-}\|+\|\mu_{I}^{+}\|+\|\mu_{I}^{-}\|\,.

(4)

Then, we begin to introduce the approximation process of the proposed AsK-RFFs. Firstly, a real, absolutely integrable, shift-invariant kernel function
k
can be represented by the following proposition.

Proposition 4

(Representation of kernels by complex measures)
.

A real, absolutely integrable, shift-invariant kernel function
k
can be represented by its Fourier transform
\mu
with
\|\mu\|<\infty
which can be regarded as a complex measure on a measurable space
(\Omega,\mathcal{M})
, where
\mu_{R}^{+},\mu_{R}^{-},\mu_{I}^{+},\mu_{I}^{-}
are defined by (
2
),

\displaystyle k(\boldsymbol{\Delta})

\displaystyle=\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{+}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{-}(\mathrm{d}\boldsymbol{\omega})

\displaystyle-\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})+\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})\,.

Proof
.

An inverse Fourier transform between a kernel function and the complex measure
can be formulated as follows,

\displaystyle k(\boldsymbol{\Delta})

\displaystyle=\int_{\mathbb{R}^{d}}e^{\mathsf{i}\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}}\mu(\mathrm{d}\boldsymbol{\omega})=\int_{\mathbb{R}^{d}}e^{\mathsf{i}\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}}\mu_{R}(\mathrm{d}\boldsymbol{\omega})+\mathsf{i}\int_{\mathbb{R}^{d}}e^{\mathsf{i}\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}}\mu_{I}(\mathrm{d}\boldsymbol{\omega})

(5)

\displaystyle=\int_{\mathbb{R}^{d}}\left[\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})+\mathsf{i}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\right]\mu_{R}(\mathrm{d}\boldsymbol{\omega})+\int_{\mathbb{R}^{d}}\left[\mathsf{i}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})-\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\right]\mu_{I}(\mathrm{d}\boldsymbol{\omega})

\displaystyle=\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}(\mathrm{d}\boldsymbol{\omega})+\mathsf{i}\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}(\mathrm{d}\boldsymbol{\omega})

\displaystyle+\mathsf{i}\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}(\mathrm{d}\boldsymbol{\omega})

\displaystyle=\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}(\mathrm{d}\boldsymbol{\omega})

\displaystyle=\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{+}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{-}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})

\displaystyle+\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})\,.

The fourth equation holds because
k
is a real kernel thus the imaginary part of the representation can be ignored.

According to (
5
), there are two constraints on
\mu
for being the complex measure of a kernel.

Corollary 5

(Constraints of complex measures)
.

Suppose
\mu=\mu_{R}^{+}-\mu_{R}^{-}+\mathsf{i}\mu_{I}^{+}-\mathsf{i}\mu_{I}^{-}
is a Fourier transform of a real kernel function
k
and the total mass
\|\mu\|
is finite, then

\left\{\begin{aligned} {}&\|\mu_{R}^{+}\|-\|\mu_{R}^{-}\|=k(\boldsymbol{0})\\
&\|\mu_{I}^{+}\|-\|\mu_{I}^{-}\|=0.\,\\
\end{aligned}\right.

(6)

Proof
.

Substituting
\boldsymbol{\Delta}=\boldsymbol{0}
into (
5
), one can obtain that

\displaystyle k(\boldsymbol{0})

\displaystyle=\int_{\mathbb{R}^{d}}e^{\mathsf{i}\boldsymbol{\omega}^{\top}\boldsymbol{0}}\mu(\mathrm{d}\boldsymbol{\omega})=\int_{\mathbb{R}^{d}}\mu_{R}(\mathrm{d}\boldsymbol{\omega})+\mathsf{i}\int_{\mathbb{R}^{d}}\mu_{I}(\mathrm{d}\boldsymbol{\omega})

\displaystyle=\int_{\mathbb{R}^{d}}\mu_{R}^{+}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\mu_{R}^{-}(\mathrm{d}\boldsymbol{\omega})+\mathsf{i}\int_{\mathbb{R}^{d}}\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})-\mathsf{i}\int_{\mathbb{R}^{d}}\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})

\displaystyle=\|\mu_{R}^{+}\|-\|\mu_{R}^{-}\|+\mathsf{i}\left(\|\mu_{I}^{+}\|-\|\mu_{I}^{-}\|\right).\,

k
is a real kernel thus
k(\bm 0)
is of course real. In other words, the imaginary part is zero, and thus (
6
) should hold.

Remark 2
.

Corollary
5
provides two rules for a complex measure
\mu
to be a Fourier transform of a real kernel function
k
. According to Definition
3
, the total mass of the measure
\mu
can also be defined by
\|\mu\|=\|\mu_{R}^{+}\|+\|\mu_{R}^{-}\|+2\|\mu_{I}^{+}\|
.

According to (
3
), i.e.,
\mu_{I}^{+}(-\boldsymbol{\omega})=\mu_{I}^{-}(\boldsymbol{\omega})
, we know that
(\mu_{I}^{+}+\mu_{I}^{-})(\boldsymbol{\omega})
is an even function with respect to
\boldsymbol{\omega}
, i.e.,
(\mu_{I}^{+}+\mu_{I}^{-})(-\boldsymbol{\omega})=\mu_{I}^{+}(-\boldsymbol{\omega})+\mu_{I}^{-}(-\boldsymbol{\omega})=\mu_{I}^{-}(\boldsymbol{\omega})+\mu_{I}^{+}(\boldsymbol{\omega})=(\mu_{I}^{+}+\mu_{I}^{-})(\boldsymbol{\omega})
.
Then,
\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\cdot\big[\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})+\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})\big]
is an odd function with respect to
\boldsymbol{\omega}
. Thus we have
\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\big[\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})+\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})\big]=0
,
which indicates that

\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})=-\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{-}(\mathrm{d}\boldsymbol{\omega})\,.

The contributions of the positive imaginary measure
\mu_{I}^{+}
and the negative imaginary measure
\mu_{I}^{-}
are equivalent. Secondly, we can speed up the approximation process since only one of
\mu_{I}^{+}
and
\mu_{I}^{-}
need to be sampled.

\displaystyle k(\boldsymbol{\Delta})

\displaystyle=\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{+}(\mathrm{d}\boldsymbol{\omega})-\int_{\mathbb{R}^{d}}\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{R}^{-}(\mathrm{d}\boldsymbol{\omega})-2\int_{\mathbb{R}^{d}}\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\mu_{I}^{+}(\mathrm{d}\boldsymbol{\omega})

(7)

\displaystyle=\mathbb{E}_{\boldsymbol{\omega}\sim\tilde{\mu}_{R}^{+}}\left[\|\mu_{R}^{+}\|\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta})\right]-\mathbb{E}_{\boldsymbol{\zeta}\sim\tilde{\mu}_{R}^{-}}\left[\|\mu_{R}^{-}\|\cos(\boldsymbol{\zeta}^{\top}\boldsymbol{\Delta})\right]

\displaystyle-2\mathbb{E}_{\boldsymbol{\nu}\sim\tilde{\mu}_{I}^{+}}\left[\|\mu_{I}^{+}\|\sin(\boldsymbol{\nu}^{\top}\boldsymbol{\Delta})\right]

\displaystyle:=k_{R}^{+}(\boldsymbol{\Delta})-k_{R}^{+}(\boldsymbol{\Delta})-k_{I}(\boldsymbol{\Delta})

\displaystyle\approx\|\mu_{R}^{+}\|\phi(\boldsymbol{\omega},\boldsymbol{x})^{\top}\phi(\boldsymbol{\omega},\boldsymbol{y})-\|\mu_{R}^{-}\|\phi(\boldsymbol{\zeta},\boldsymbol{x})^{\top}\phi(\boldsymbol{\zeta},\boldsymbol{y})-2\|\mu_{I}^{+}\|\phi(\boldsymbol{\nu},\boldsymbol{x})^{\top}\psi(\boldsymbol{\nu},\boldsymbol{y})

\displaystyle:=s(\boldsymbol{\Delta})\,,

where
k_{R}^{+}
and
k_{R}^{+}
are two symmetric PD functions,
k_{I}
is a skew-symmetric function,
\tilde{\mu}_{R}^{+},\tilde{\mu}_{R}^{-},\tilde{\mu}_{I}^{+}
are three normalized measures corresponding to
\mu_{R}^{+}
,
\mu_{R}^{-}
and
\mu_{I}^{+}
, respectively. The feature mapping
\phi(\boldsymbol{\omega},\boldsymbol{x}),\psi(\boldsymbol{\omega},\boldsymbol{y})
,
\{\boldsymbol{\omega}_{k}\}_{k=1}^{M}\sim\tilde{\mu}
can be sampled by the Monte Carlo sampling method, where
M
is the sampling number. Specifically,

\left\{\begin{aligned} {}&\phi(\boldsymbol{\omega},\boldsymbol{x})=\frac{1}{\sqrt{M}}\left[\cos({\boldsymbol{\omega}}_{1}^{\top}\boldsymbol{x}),\cdots,\cos({\boldsymbol{\omega}}_{M}^{\top}\boldsymbol{x}),\sin({\boldsymbol{\omega}}_{1}^{\top}\boldsymbol{x}),\cdots,\sin({\boldsymbol{\omega}}_{M}^{\top}\boldsymbol{x})\right]^{\top}\\
&\psi(\boldsymbol{\omega},\boldsymbol{y})=\frac{1}{\sqrt{M}}\left[-\sin({\boldsymbol{\omega}}_{1}^{\top}\boldsymbol{y}),\cdots,-\sin({\boldsymbol{\omega}}_{M}^{\top}\boldsymbol{y}),\cos({\boldsymbol{\omega}}_{1}^{\top}\boldsymbol{y}),\cdots,\cos({\boldsymbol{\omega}}_{M}^{\top}\boldsymbol{y})\right]^{\top}\,.\\
\end{aligned}\right.

(8)

As a general framework, Ask-RFFs also covers symmetric kernels, including PD and indefinite ones. In that case,
the complex measures reduce to real signed measures, i.e.,
\mu_{I}=0
.
Then the proposed AsK-RFF is equivalent to that in
Liu et al., 2021a
, where the kernels to be approximated are symmetric. When the positive definiteness is imposed, the complex measure further degenerates to a finite real and positive measure.
In this sense,
the Bochner’s theorem
(
Bochner, 2005
)
can be regarded as a special case of the AsK-RFFs.

As a kernel approximation method,
the approximation error with respect to the feature dimension is the most concerned. We give and prove the following uniform convergence for Ask-RFFs.

Proposition 6

(Uniform convergence of RFFs for asymmetric kernels)
.

Let k be a real and continuous kernel function,
k(\boldsymbol{x},\boldsymbol{y})=k(\boldsymbol{\Delta})
and
\mu=\mu_{R}^{+}-\mu_{R}^{-}+i(\mu_{I}^{+}-\mu_{I}^{-})
be its Fourier transform with
\|\mu\|=\|\mu_{R}^{+}\|+\|\mu_{R}^{-}\|+2\|\mu_{I}^{+}\|<\infty
, defined on a compact subset
\mathcal{X}\subset\mathbb{R}^{d}
with diameter
l
. Let the approximation function
s(\boldsymbol{x},\boldsymbol{y})=s(\boldsymbol{\Delta})
be as in (
7
) and
\sigma_{\mu}^{2}:=\mathbb{E}_{\omega\sim\tilde{\mu}_{R}^{+}}\|\omega\|^{2}+\mathbb{E}_{\zeta\sim\tilde{\mu}_{R}^{-}}\|\zeta\|^{2}+2\mathbb{E}_{\nu\sim\tilde{\mu}_{I}^{+}}\|\nu\|^{2}
. Let
\alpha_{\mu}^{2}=\left(\|\mu_{R}^{+}\|^{2}+\|\mu_{R}^{-}\|^{2}+2\|\mu_{I}^{+}\|^{2}\right)\cdot\sigma_{\mu}^{2}
and
\beta_{d}=\left((\frac{d}{2})^{\frac{-d}{d+2}}+(\frac{d}{2})^{\frac{2}{d+2}}\right)\cdot 2^{\frac{6d+2}{d+2}}
.
Then, for any
\epsilon>0
,
then
\|s-k\|_{\infty}
is at most
\epsilon
with probability at least
1-\delta
as long as

\displaystyle{}M\geq\frac{4(d+2)\|\mu\|^{2}}{\epsilon^{2}}\left(\log\frac{\beta_{d}}{\delta}+\frac{2d}{d+2}\log\frac{\alpha_{\mu}l}{\epsilon}\right)\,.

The proof sketch follows
Rahimi and Recht, 2007
;
Sutherland and Schneider, 2015
but differs in the considered complex measure. The details
can be found in Appendix
7
. The one sentence conclusion is: Pointwise error of Ask-RFF is no more than
\epsilon
almost surely if the number of random Fourier features
M=\mathcal{O}\left(d\|\mu\|^{2}\epsilon^{-2}\log\frac{\alpha_{\mu}l}{\epsilon}\right)
.

4
Computational Aspects

The overall process of Ask-RFFs is summarized in Algorithm
1
, which allows for approximating asymmetric kernels by random Fourier features.
The measures
\mu
,
\mu_{R}^{+}
,
\mu_{R}^{-}
, and
\mu_{I}^{+}
and their total masses are kernel-dependent, which can be calculated in advance. By this means, the proposed method has the same complexity as RFFs with PD and indefinite kernels
(
Rahimi and Recht, 2007
;
Liu et al., 2021a
)
:
\mathcal{O}\left(NM^{2}\right)
time cost and
\mathcal{O}\left(NM\right)
memory.

Algorithm 1

AsK-RFFs via complex measures.

1:

A kernel function
k(\boldsymbol{x},\boldsymbol{y})=k(\boldsymbol{u})
with
\boldsymbol{u}:=\boldsymbol{x}-\boldsymbol{y}
and #random features
M
.

2:

The random Fourier features
\phi,\psi:\mathbb{R}^{d}\times\mathbb{R}^{d}\rightarrow\mathbb{R}^{2M}
.

3:

Obtain a complex measure
\mu=\mu_{R}+\mathsf{i}\mu_{I}
of the kernel
k

4:

Let
\mu_{R}=\mu_{R}^{+}-\mu_{R}^{-}

with four finite positive measures

Beyond the general algorithm, there are some tricky but important details for AsK-RFFs. To better demonstrate the computational details, we first list three practical asymmetric kernels. In the first kernel, the asymmetric part comes from shift and for the last two, the functions are the product of a symmetric part and an asymmetric part.

•

Shift-Gaussian kernels
are generalized from Gaussian kernels by shifting

\boldsymbol{r}
in the time domain. The resulted kernel function and its Fourier transform are given as follows,

\displaystyle k_{1}(\boldsymbol{\Delta})

\displaystyle=\exp(-\frac{\|\boldsymbol{\Delta}+\boldsymbol{r}\|^{2}}{2\sigma^{2}})

(9)

\displaystyle\mu_{1}(\boldsymbol{\omega})

\displaystyle=\big(\frac{\sigma}{\sqrt{2\pi}}\big)^{d}\exp(-\frac{\sigma^{2}\|\boldsymbol{\omega}\|^{2}}{2})\exp(\mathsf{i}\cdot\boldsymbol{r}^{\top}\boldsymbol{\omega})\,,

where
\sigma
is the kernel bandwidth as in Gaussian kernels.

•

Sinh-Gaussian kernels
are generalized from Gaussian kernels with an asymmetric skew part
\sinh(x)=(e^{x}-e^{-x})/2
. The resulted kernel function and its Fourier transform are given as follows,

\displaystyle k_{2}(\boldsymbol{\Delta})

\displaystyle=\exp(-\frac{\|\boldsymbol{\Delta}\|^{2}}{2\sigma^{2}})\cdot(1+\sinh{(\boldsymbol{\beta}^{\top}\boldsymbol{\Delta})})

(10)

\displaystyle\mu_{2}(\boldsymbol{\omega})

\displaystyle=\big(\frac{\sigma}{\sqrt{2\pi}}\big)^{d}\exp(-\frac{\sigma^{2}\|\boldsymbol{\omega}\|^{2}}{2})\big[1-\mathsf{i}\cdot\exp(\frac{\sigma^{2}\|\boldsymbol{\beta}\|^{2}}{2})\sin(\sigma^{2}\boldsymbol{\beta}^{\top}\boldsymbol{\omega})\big]\,.

•

Cosh-Gaussian kernels
are generalized from Gaussian kernels with an asymmetric part, i.e.,
\exp(x)
. The resulted kernel function and its Fourier transform are given as follows,

\displaystyle k_{3}(\boldsymbol{\Delta})

\displaystyle=\exp(-\frac{\|\boldsymbol{\Delta}\|^{2}}{2\sigma^{2}})\cdot\exp(\boldsymbol{\beta}^{\top}\boldsymbol{\Delta})

(11)

\displaystyle\mu_{3}(\boldsymbol{\omega})

\displaystyle=\big(\frac{\sigma}{\sqrt{2\pi}}\big)^{d}\exp(-\frac{\sigma^{2}\|\boldsymbol{\omega}\|^{2}}{2})\exp(\frac{\sigma^{2}\|\boldsymbol{\beta}\|^{2}}{2})\exp(-\mathsf{i}\cdot\sigma^{2}\boldsymbol{\beta}^{\top}\boldsymbol{\omega})\,.

With the specific kernels, we can better illustrate the process of estimating
AsK-RFFs based on the total masses in (
7
),
which can be computed in advance as they only depend on the kernel function type.
Notice that the four positive measures forms a complex measure, see (
2
), defined by the non-smooth operator.
That means, no analytical integral is allowed and thus we in turn focus on numerical integration for the estimation of total masses.

Conducting numerical integration for total masses estimation involves computationally extensive in high dimensions (i.e.,
d
is large). To accelerate the estimation, we approximate the total masses on a subset of training data
\mathcal{X}_{s}
and formulate this estimation task as a least squares regression problem under the constraints (
6
).
To be specific: denote the number of sub-training samples as
N_{s}=|\mathcal{X}_{s}|
and
\boldsymbol{K}\in\mathbb{R}^{N_{s}\times N_{s}}
be a sub-Gram matrix. Let
\boldsymbol{\omega}
,
\boldsymbol{\zeta}
and
\boldsymbol{\nu}
be as in (
7
), denote
\xi_{1}:=\|\mu_{R}^{+}\|
,
\xi_{2}:=\|\mu_{R}^{-}\|
and
\xi_{3}:=\|\mu_{I}^{+}\|
. We focus on the following optimization problem

\begin{split}&\min_{\xi_{1},\xi_{2},\xi_{3}}\,\,\|\boldsymbol{K}-\xi_{1}\cdot\phi\left(\boldsymbol{\omega},\mathcal{X}_{s}\right)\phi\left(\boldsymbol{\omega},\mathcal{X}_{s}\right)^{\top}+\xi_{2}\cdot\phi\left(\boldsymbol{\zeta},\mathcal{X}_{s}\right)\phi\left(\boldsymbol{\zeta},\mathcal{X}_{s}\right)^{\top}\\
&\qquad\qquad-2\xi_{3}\cdot\phi\left(\boldsymbol{\nu},\mathcal{X}_{s}\right)\psi\left(\boldsymbol{\nu},\mathcal{X}_{s}\right)^{\top}\|_{F}^{2}\\
&\rm{s.t.}\quad\begin{array}[]{lc}\xi_{1}-\xi_{2}=k(\boldsymbol{0}),~\xi_{1},\xi_{2},\xi_{3}\geq 0,\\
\end{array}\end{split}

(12)

where

\left\{\begin{aligned} {}&\phi(\boldsymbol{\omega},\mathcal{X}_{s}):=\left[\phi(\boldsymbol{\omega},\boldsymbol{x_{1}}),\cdots,\phi(\boldsymbol{\omega},\boldsymbol{x_{N_{s}}})\right]^{\!\top}\\
&\psi(\boldsymbol{\nu},\mathcal{X}_{s}):=\left[\psi(\boldsymbol{\nu},\boldsymbol{x_{1}}),\cdots,\psi(\boldsymbol{\nu},\boldsymbol{x_{N_{s}}})\right]^{\!\top}\,.\\
\end{aligned}\right.

The optimization problem converts the original
d
dimensional integral problem to a least square problem with
N_{s}
samples, and thus the computational complexity is
\mathcal{O}(N_{s}^{3})
, determined by
N_{s}
.
We remark that, the total masses do not need to be known before sampling
\boldsymbol{\omega},\boldsymbol{\zeta},\boldsymbol{\nu}
, since a modified acceptance-rejection algorithm that samples random variables (r.v.)
\boldsymbol{\omega}
from a finite positive measure
f/\|f\|
works as follows:

1.

Given a proposal distribution
g/\|g\|
satisfying
\sup_{\boldsymbol{\omega}}\frac{f(\boldsymbol{\omega})}{g(\boldsymbol{\omega})}\leq c
where
c
is a constant.

2.

Sample a r.v.
\boldsymbol{\zeta}
distributed as
g/\|g\|
.

3.

Sample a r.v.
U
distributed as a uniform distribution
\mathcal{U}[0,1]
.

4.

If
U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}
then set
\boldsymbol{\omega}=\boldsymbol{\zeta}
; otherwise go back to the step 2.

The proof that the acceptance-rejection algorithm works is deferred to Appendix
8
. The total mass of
g
can be calculated analytically if
g
is a good measure such as the Gaussian distribution. As shown in the above steps,
\|f\|
is not required to be necessarily known before the acceptance-rejection sampling. Thus, we can sample the frequency components before estimating total masses. The AsK-RFFs method with the estimation total masses process is shown in Algorithm

6
Conclusion

In this paper, we investigated a unified kernel approximation framework by RFFs which can uniformly approximate asymmetric kernels. A spectral representation of asymmetric kernels via complex measure was presented by the proposed AsK-RFFs method which could be applied to both asymmetric and symmetric kernels including positive definite and indefinite kernels.
In this framework, we could design kernels by altering their complex measures from a statistics perspective. Besides, we proposed a subset-based fast estimation method for total masses on a sub-training set to speed up our approximation process. The effecietnveness of AsK-RFFs was evaluated in experimental results on several large classification datasets.
Another intererting avenue for asymmetric kernel approximation is the Nyström-type method
(
Williams and Seeger, 2001
;
Drineas et al., 2005
)
. The Nyström-type approximation process that uses low-rank matrices to approximate the asymmetric kernel matrix is worthy of further research.

Proof of Proposition
6

The proof strategy closely follows which of
(
Rahimi and Recht, 2007
;
Sutherland and Schneider, 2015
)
. Suppose
k(\boldsymbol{\Delta})
is twice differentiable. Denote
f(\boldsymbol{\Delta}):=s(\boldsymbol{\Delta})-k(\boldsymbol{\Delta})
. Let
\mathcal{X_{\boldsymbol{\Delta}}}=\{\boldsymbol{x}-\boldsymbol{y}|\boldsymbol{x},\boldsymbol{y}\in\mathcal{X}\}
which is compact with diameter
l
. An
\epsilon
-net can be found that covers
\mathcal{X_{\boldsymbol{\Delta}}}
with at most
T=(\frac{4l}{r})^{d}
balls of radius
r

(
Cucker and Smale, 2002
)
. Let
\{\boldsymbol{\Delta_{k}}\}_{k=1}^{T}
be centers and
L_{f}
be the Lipschitz constant of
f
. There is a fact that
|f(\boldsymbol{\Delta})|<\epsilon
for all
\boldsymbol{\Delta}\in\mathcal{X_{\boldsymbol{\Delta}}}
if
|f(\boldsymbol{\Delta_{k}})|<\frac{\epsilon}{2}
and
L_{f}<\frac{\epsilon}{2r}
for all
k
.

Since
f
is differentiable, we denote
L_{f}=\triangledown f(\boldsymbol{\Delta}^{\star})
where
\boldsymbol{\Delta}^{\star}=\arg\max_{\boldsymbol{\Delta}\in\mathcal{X_{\boldsymbol{\Delta}}}}\|\triangledown f(\boldsymbol{\Delta})\|
. We have

\displaystyle\mathbb{E}[L_{f}^{2}]

\displaystyle=\mathbb{E}\|\triangledown f(\boldsymbol{\Delta}^{\star})\|^{2}

\displaystyle\leq\mathbb{E}\|\triangledown s(\boldsymbol{\Delta}^{\star})\|^{2}-\mathbb{E}\|\triangledown k(\boldsymbol{\Delta}^{\star})\|^{2}

\displaystyle\leq\mathbb{E}\|\triangledown s(\boldsymbol{\Delta}^{\star})\|^{2}

\displaystyle=\mathbb{E}\big\|\frac{1}{M}\triangledown\sum_{l=1}^{M}\|\mu_{R}^{+}\|\cos(\boldsymbol{\omega}_{l}^{\top}\boldsymbol{\Delta}^{\star})-\|\mu_{R}^{-}\|\cos(\boldsymbol{\zeta}_{l}^{\top}\boldsymbol{\Delta}^{\star})-2\|\mu_{I}^{+}\|\sin(\boldsymbol{\nu}_{l}^{\top}\boldsymbol{\Delta}^{\star})\big\|^{2}

\displaystyle=\mathbb{E}\big\|\triangledown\big[\|\mu_{R}^{+}\|\cos(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}^{\star})-\|\mu_{R}^{-}\|\cos(\boldsymbol{\zeta}^{\top}\boldsymbol{\Delta}^{\star})-2\|\mu_{I}^{+}\|\sin(\boldsymbol{\nu}^{\top}\boldsymbol{\Delta}^{\star})\big]\big\|^{2}

\displaystyle=\mathbb{E}\left\|\|\mu_{R}^{+}\|\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}^{\star})\boldsymbol{\omega}-\|\mu_{R}^{-}\|\sin(\boldsymbol{\zeta}^{\top}\boldsymbol{\Delta}^{\star})\boldsymbol{\zeta}+2\|\mu_{I}^{+}\|\cos(\boldsymbol{\nu}^{\top}\boldsymbol{\Delta}^{\star})\boldsymbol{\nu}\right\|^{2}

\displaystyle\leq\mathbb{E}\big[|\sin(\boldsymbol{\omega}^{\top}\boldsymbol{\Delta}^{\star})|\cdot\|\mu_{R}^{+}\|\|\boldsymbol{\omega}\|+|\sin(\boldsymbol{\zeta}^{\top}\boldsymbol{\Delta}^{\star})|\cdot\|\mu_{R}^{-}\|\|\boldsymbol{\zeta}\|

\displaystyle+2|\cos(\boldsymbol{\nu}^{\top}\boldsymbol{\Delta}^{\star})|\cdot\|\mu_{I}^{+}\|\|\boldsymbol{\nu}\|\big]^{2}

\displaystyle\leq\mathbb{E}\big[\|\mu_{R}^{+}\|\cdot\|\boldsymbol{\omega}\|+\|\mu_{R}^{-}\|\cdot\|\boldsymbol{\zeta}\|+2\|\mu_{I}^{+}\|\cdot\|\boldsymbol{\nu}\|\big]^{2}

\displaystyle\leq\mathbb{E}\left[\left(\|\mu_{R}^{+}\|^{2}+\|\mu_{R}^{-}\|^{2}+(\sqrt{2}\|\mu_{I}^{+}\|)^{2}\right)\cdot\left(\|\boldsymbol{\omega}\|^{2}+\|\boldsymbol{\zeta}\|^{2}+(\sqrt{2}\|\boldsymbol{\nu}\|)^{2}\right)\right]

\displaystyle=\left(\|\mu_{R}^{+}\|^{2}+\|\mu_{R}^{-}\|^{2}+2\|\mu_{I}^{+}\|^{2}\right)\cdot\mathbb{E}\left(\|\boldsymbol{\omega}\|^{2}+\|\boldsymbol{\zeta}\|^{2}+2\|\boldsymbol{\nu}\|^{2}\right):=\alpha_{\mu}^{2}\,.

The first and second inequalities are derived in a similar fashion with
(
Sutherland and Schneider, 2015
)
. The third inequality is from the triangle inequality
\|a+b+c\|\leq\|a\|+\|b\|+\|c\|
with
a,b,c
being vectors. The fourth inequality holds because the sine and cosine functions are bounded by
\pm 1
. The fifth inequality is from the Cauchy–Schwarz inequality
(\sum_{i=1}^{n}u_{i}v_{i})^{2}\leq(\sum_{i=1}^{n}u_{i}^{2})(\sum_{i=1}^{n}v_{i}^{2})
with
u_{i},v_{i}
being real numbers.

According to the Markov’s inequality, we obtain a probability bound for the Lipschitz constant,

{\rm Pr}\left(L_{f}\geq\frac{\epsilon}{2r}\right)={\rm Pr}\left(L_{f}^{2}\geq(\frac{\epsilon}{2r})^{2}\right)\leq\alpha_{\mu}^{2}\left(\frac{2r}{\epsilon}\right)^{2}\,.

(13)

Given a fixed
\boldsymbol{\Delta}
,
s(\boldsymbol{\Delta})
is bounded by
\pm\left(\|\mu_{R}^{+}\|+\|\mu_{R}^{-}\|+2\|\mu_{I}^{+}\|\right)
with the expectation
k(\boldsymbol{\Delta})
. Applying the Hoeffding’s
inequality and a union bound to anchors in the
\epsilon
-net, we have

{\rm Pr}\left(\cup_{k=1}^{T}|f(\boldsymbol{\Delta_{k}})|\geq\frac{\epsilon}{2}\right)\leq T{\rm Pr}\left(|f(\boldsymbol{\Delta_{k}}\right)|\geq\frac{\epsilon}{2})\leq 2T\exp\left(-\frac{M\epsilon^{2}}{8\|\mu\|^{2}}\right)\,.

(14)

Combining bounds (
13
) and (
14
), we obtain a bound in terms of
r
,

{\rm Pr}\left(\sup_{\boldsymbol{\Delta}\in\mathcal{X_{\boldsymbol{\Delta}}}}|f(\boldsymbol{\Delta})|\leq\epsilon\right)\geq 1-\kappa_{1}r^{-d}-\kappa_{2}r^{2},

where
\kappa_{1}=2(4l)^{d}\exp\left(-\frac{M\epsilon^{2}}{8\|\mu\|^{2}}\right)
,
\kappa_{2}=4\alpha_{\mu}^{2}\epsilon^{-2}
. We choose
r
such that
d\kappa_{1}r^{-d-1}-2\kappa_{2}r=0
i.e.,
r=\left(\frac{d\kappa_{1}}{2\kappa_{2}}\right)^{\frac{1}{d+2}}
, as did in
(
Sutherland and Schneider, 2015

. Then we have a bound

\displaystyle{}{\rm Pr}\left(\sup_{\boldsymbol{\Delta}\in\mathcal{X_{\boldsymbol{\Delta}}}}|f(\boldsymbol{\Delta})|>\epsilon\right)

\displaystyle\leq\left((\frac{d}{2})^{\frac{-d}{d+2}}+(\frac{d}{2})^{\frac{2}{d+2}}\right)\cdot 2^{\frac{6d+2}{d+2}}\left(\frac{\alpha_{\mu}l}{\epsilon}\right)^{\frac{2d}{d+2}}\exp\left(\frac{-M\epsilon^{2}}{4(d+2)\|\mu\|^{2}}\right)

\displaystyle=\beta_{d}\left(\frac{\alpha_{\mu}l}{\epsilon}\right)^{\frac{2d}{d+2}}\exp\left(\frac{-\epsilon^{2}M}{4(d+2)\|\mu\|^{2}}\right)\,.

Thus, we can control the pointwise error no more than
\epsilon
with probability at least
1-\delta
as long as
M\geq 4(d+2)\|\mu\|^{2}\epsilon^{-2}\left(\log\frac{\beta_{d}}{\delta}+\frac{2d}{d+2}\log\frac{\alpha_{\mu}l}{\epsilon}\right)
.
Sutherland and Schneider, 2015
provide the maximum value
\beta_{64}=66
and asymptotic values
\lim_{d\rightarrow\infty}\beta_{d}=64
and the exponent of the second factor can be loosened to 2 if

.

Proof of the Acceptance-Rejection sampling algorithm works

Denote
F(\boldsymbol{t}):=f(\boldsymbol{\zeta}\leq\boldsymbol{t})
and
G(\boldsymbol{t}):=g(\boldsymbol{\zeta}\leq\boldsymbol{t})
. Denote two events
A=\{\boldsymbol{\zeta}\leq\boldsymbol{t}\}
and
B=\{U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}\}
. Then,
F/\|f\|
and
G/\|g\|
are two probability measures. Suppose a r.v.
\boldsymbol{\zeta}
is sampled from a distribution
G/\|g\|
and a r.v.
U
is sampled from a uniform distribution
\mathcal{U}[0,1]
.

We need to prove

{\rm Pr}(A|B)=F/\|f\|
.
To this end, we utilize the Bayes’ theorem, i.e.,
{\rm Pr}(A|B)={\rm Pr}(B|A)\cdot{\rm Pr}(A)/{\rm Pr}(B)
.

Firstly,
\boldsymbol{\zeta}
follows the distribution
G/\|g\|
, then
{\rm Pr}(A)={\rm Pr}(\boldsymbol{\zeta}\leq\boldsymbol{t})=G(\boldsymbol{t})/\|g\|
.
Secondly, the probability
{\rm Pr}(B)
is given as follows,

\displaystyle{\rm Pr}(B)

\displaystyle=\int_{\mathbb{R}^{d}}{\rm Pr}\left(U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}|\boldsymbol{\zeta}=\boldsymbol{t})\right)\cdot{\rm Pr}(\boldsymbol{\zeta}=\boldsymbol{t})\mathrm{d}\boldsymbol{t}

\displaystyle=\int_{\mathbb{R}^{d}}\frac{f(\boldsymbol{t})}{cg(\boldsymbol{t})}\cdot\frac{g(\boldsymbol{t})}{\|g\|}\mathrm{d}\boldsymbol{t}

\displaystyle=\frac{\|f\|}{c\|g\|}.\,

Thirdly, the probability
{\rm Pr}(B|A)
can be derived by,

\displaystyle{\rm Pr}(B|A)

\displaystyle={\rm Pr}\left(U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}|\boldsymbol{\zeta}\leq\boldsymbol{t}\right)

\displaystyle=\frac{{\rm Pr}\left(U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})},\boldsymbol{\zeta}\leq\boldsymbol{t}\right)}{{\rm Pr}(\boldsymbol{\zeta}\leq\boldsymbol{t})}

\displaystyle=\frac{\|g\|}{G(\boldsymbol{t})}\int_{[-\infty]^{d}}^{\boldsymbol{t}}{\rm Pr}\left(U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}|\boldsymbol{\zeta}=\boldsymbol{w}\leq\boldsymbol{t}\right)\cdot\frac{g(\boldsymbol{w})}{\|g\|}\mathrm{d}\boldsymbol{w}

\displaystyle=\frac{\|g\|}{G(\boldsymbol{t})}\int_{[-\infty]^{d}}^{\boldsymbol{t}}\frac{f(\boldsymbol{w})}{cg(\boldsymbol{w})}\frac{g(\boldsymbol{w})}{\|g\|}\mathrm{d}\boldsymbol{w}

\displaystyle=\frac{F(t)}{cG(t)}.\,

Then, the probability
{\rm Pr}\left(\boldsymbol{\zeta}\leq\boldsymbol{t}|U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}\right)={\rm Pr}(A|B)
can be calculated by the following equation.

\displaystyle{\rm Pr}\left(\boldsymbol{\zeta}\leq\boldsymbol{t}|U\leq\frac{f(\boldsymbol{\zeta})}{cg(\boldsymbol{\zeta})}\right)

\displaystyle={\rm Pr}(A|B)

\displaystyle=\frac{{\rm Pr}(B|A)\cdot{\rm Pr}(A)}{{\rm Pr}(B)}

\displaystyle=\frac{F(t)}{cG(t)}\cdot\frac{G(\boldsymbol{t})}{\|g\|}\cdot\frac{c\|g\|}{\|f\|}

\displaystyle=\frac{F(t)}{\|f\|}\,,

which concludes the proof.
