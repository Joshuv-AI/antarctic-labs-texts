Jacob’s ladders, crossbreeding, secondary crossbreeding and synergetic phenomena generated by Riemann’s zeta-function and some elementary functions on disconnected sets of the critical line
Jan Moser

Abstract
. In this paper we obtain new complete hybrid formula for corresponding class of ζ \zeta -factorization formulas. We demonstrate that this formula is the synergetic one. Namely, this one describes the cooperation between some class of elementary functions and Riemann’s zeta-function on a class of disconnected sets on the critical line. Some comparizon between this pure mathematical phenomenon and the Belousov-Zhabotinski chemical reaction is added. DEDICATED TO 110th ANNIVERSARY OF HARDY’S PURE MATHEMATICS

1.1.

In sciences (physics, chemistry,biology, …) there are known various effects called as synergetic (cooperative) phenomena, (see
[
1

(a)

the system contain big number of objects (atoms, molecules or more complicated formations),

(b)

the cooperative phenomenon is such one in which the constituents of the system cannot be regarded as acting independently from each other,

(c)

cooperative phenomena result from interactions between constituents.

An wonderful example of such a phenomenon is given by the classical Belousov-Zhabotinski periodic chemical reaction (see
[
1
]

\mbox{red}(excess\ of\ Ce^{3+})\longleftrightarrow\mbox{blue}(excess\ of\ Ce^{4+})

oscillations of the chemical system on two disconnected parts of a test-tube (see
[
1
]
, p. 27, Fig. 1.19).

2.
Jacob’s ladders and the basic disconnected set (the first set of notions)

2.1.

Let us remind that the Jacob’s ladder

\varphi_{1}(t)=\frac{1}{2}\varphi(t)

was introduced in
[
2
]
(see also
[
3
]
), where the function
\varphi(t)
is arbitrary solution of the nonlinear integral equation (also introduced in
[
2
]
)

\int_{0}^{\mu[x(T)]}Z^{2}(t)e^{-\frac{2}{x(T)}t}{\rm d}t=\int_{0}^{T}Z^{2}(t){\rm d}t,

where, of course,

\begin{split}&Z(t)=e^{i\vartheta(t)}\zeta\left(\frac{1}{2}+it\right),\\
&\vartheta(t)=-\frac{t}{2}\ln\pi+\mbox{Im}\ln\Gamma\left(\frac{1}{4}+i\frac{t}{2}\right),\end{split}

where each admissible function
\mu(y)
generates a solution

y=\varphi(T;\mu)=\varphi(T);\ \mu(y)>7y\ln y.

We call the function
\varphi_{1}(T)
the Jacob’s ladder as an analogue of the Jacob’s dream in Chumash, Bereishis, 28:12.

Remark 4
.

By making use of the Jacob’s ladders we have shown (see
[
2
]
) that the classical Hardy-Littlewood integral (1918)

\int_{0}^{T}\left|\zeta\left(\frac{1}{2}+it\right)\right|^{2}{\rm d}t

has - in addition to previously known Hardy-Littlewood expression (and other similar) possessing an unbounded error term at
T\to\infty
- the following infinite set of almost exact representations

\begin{split}&\int_{0}^{T}\left|\zeta\left(\frac{1}{2}+it\right)\right|^{2}{\rm d}t=\varphi_{1}(T)\ln\{\varphi_{1}(T)\}+\\
&+(c-\ln 2\pi)\varphi_{1}(T)+c_{0}+\mathcal{O}\left(\frac{\ln T}{T}\right),\ T\to\infty,\end{split}

where
c
is the Euler’s constant and
c_{0}
is the constant from the Titschmarsh-Kober-Atkinson formula.

2.2.

Next, we have obtained (see
[
2
]
, (6.2)) the following formula

(2.1)

T-\varphi_{1}(T)\sim(1-c)\pi(T);\ \pi(T)\sim\frac{T}{\ln T},\ T\to\infty,

where
\pi(T)
is the prime-counting function.

Remark 5
.

Consequently, the Jacob’s ladder
\varphi_{1}(T)
can be viewed by our formula (
2.1
) as an asymptotic complementary function to the function

(1-c)\pi(T)

in the following sense

\varphi_{1}(T)+(1-c)\pi(T)\sim T,\ T\to\infty.

Since Jacob’s ladder is exactly increasing function, we have defined the reversely iterated sequence

\{\overset{k}{T}\}_{k=1}^{k_{0}},\ k_{0}\in\mathbb{N}:\ \varphi_{1}(\overset{k}{T}):=\overset{k-1}{T},\ \overset{0}{T}=T>T_{0}>0;\ \overset{k}{T}=\varphi_{1}^{-k}(T),

where
T_{0}
is a sufficiently big, (we fix
k_{0}
). Next, we have proved (see
[
4
]
, (2.5)-(2.7), (5.1)-(5.13)) the following properties: if

(2.2)

U=o\left(\frac{T}{\ln T}\right),\ T\to\infty

then

(2.3)

\begin{split}&\varphi_{1}\{[\overset{k}{T},\overset{k}{\wideparen{T+U}}]\}=[\overset{k-1}{T},\overset{k-1}{\wideparen{T+U}}],\\
&[\overset{0}{T},\overset{0}{\wideparen{T+U}}]=[T,T+U],\end{split}

(2.4)

|[\overset{k}{T},\overset{k}{\wideparen{T+U}}]|=\overset{k}{\wideparen{T+U}}-\overset{k}{T}=o\left(\frac{T}{\ln T}\right),

(2.5)

|[\overset{k-1}{\wideparen{T+U}},\overset{k}{T}]|=\overset{k}{T}-\overset{k-1}{\wideparen{T+U}}\sim(1-c)\pi(T),

(2.6)

\begin{split}&[T,T+U]\prec[\overset{1}{T},\overset{1}{\wideparen{T+U}}]\prec\dots\prec[\overset{k}{T},\overset{k}{\wideparen{T+U}}],\\
&k=1,\dots,k_{0}.\end{split}

From (
2.2
)-(
2.6
) we obtain the following basic property of Jacob’s ladder.

Property
.

For every segment

[T,T+U],\ U=o\left(\frac{T}{\ln T}\right),\ T\to\infty

there is the following class of disconnected sets

(2.7)

\Delta(T,U,k)=\bigcup_{r=0}^{k}[\overset{r}{T},\overset{r}{\wideparen{T+U}}],\ 1\leq k\leq k_{0}

generated by the Jacob’s ladder
\varphi_{1}(T)
.

Remark 6
.

Disconnected set (
2.7
) has the following properties:

(a)

lengths of its components are (see (
2.4
))

(2.8)

|[\overset{r}{T},\overset{r}{\wideparen{T+U}}]|\sim o\left(\frac{T}{\ln T}\right),\ \ T\to\infty,

(b)

lengths of its adjacent segments are (see (
2.5
))

(2.9)

|[\overset{r-1}{\wideparen{T+U}},\overset{r}{T}]|\sim(1-c)\frac{T}{\ln T},\ T\to\infty.

Remark 7
.

The asymptotic behavior of the components of the disconnected set (
2.7
) is as follows: if
T\to\infty
then these components recede unboundedly each from other and all together are receding to infinity. Hence, at
T\to\infty
the set of components of (
2.7
) behaves as one dimensional Friedman-Hubble expanding universe.
