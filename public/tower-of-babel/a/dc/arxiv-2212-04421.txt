Implications of subconvexity bounds for the moments of ζ ⁡ ( s ) \zeta(s)
Kevin Smith

Abstract
. It is well-known that upper bounds for moments of the Riemann zeta function ζ ⁡ ( s ) \zeta(s) have implications for subconvexity bounds. In this paper we explore some implications in the opposite direction using functional analysis in the right-half of the critical strip. The main results characterise potential transitions in the behaviour of the moments.

Since Montgomery’s work
[
17
]

\zeta(s)

[

by analogy with the unitary case, and by Conrey and Ghosh

(1.1)

\displaystyle M_{k}(1/2,T)\sim a_{k}g_{k}T(\log T)^{k^{2}}

where

(1.2)

\displaystyle a_{k}=\prod_{p\textrm{ prime}}\left(1-\frac{1}{p}\right)^{(k-1)^{2}}\sum_{n=0}^{\infty}{k-1\choose n}^{2}p^{-n}\hskip 11.38092pt\textrm{and }\hskip 11.38092ptg_{k}=\frac{G^{2}(k+1)}{G(2k+1)}

, while the constant factor

arises from the influence of the primes. More recently, building on work of Soundararajan
[

[

\displaystyle M_{k}(1/2,T)\ll_{k}T(\log T)^{k^{2}}\hskip 28.45274pt(k>0).

Lower bounds for

of the correct order of magnitude for all

and Ingham

The difficulties involved in computing

Denoting by

\displaystyle\lim_{T\rightarrow\infty}\frac{M_{k}(\sigma,T)}{T}=\sum_{n=1}^{\infty}\frac{d^{2}_{k}(n)}{n^{2\sigma}}\hskip 28.45274pt(1/2\leq\sigma_{k}<\sigma<1)

5.4.

Let

and
\nu\in\mathbb{R}
be fixed. Since the set
\{e_{\lambda}\}_{\lambda\in\mathbb{R}}
is a complete orthonormal set in
B^{2}
, for every
\epsilon>0
there is an integer
M(u,\epsilon)
and a sequence of real numbers
\lambda_{1},\cdots,\lambda_{M}
such that

(5.11)

\displaystyle\left\|\overline{u}-\sum_{m\leq M}\left\langle\overline{u},e_{\lambda_{m}-\nu}\right\rangle e_{\lambda_{m}-\nu}\right\|<\epsilon\hskip 28.45274pt(M>M(u,\epsilon)).

If
|u|=1
, then it is immediate from (
5.11
) that

(5.12)

\displaystyle\left\|e_{\nu}-\sum_{m\leq M}\left\langle e_{\nu},ue_{\lambda_{m}}\right\rangle ue_{\lambda_{m}}\right\|<\epsilon\hskip 28.45274pt(M>M(u,\epsilon)).

For each
\lambda\in\mathbb{R}
we write
u_{\lambda}=ue_{\lambda}

\{u_{\lambda}\}_{\lambda\in\mathbb{R}}

B^{2}
. Now suppose that the set
\{u_{\lambda}\}_{\lambda\in\mathbb{R}}

B^{2}

, which contradicts (
5.12

\{u_{\lambda}\}_{\lambda\in\mathbb{R}}

. Since a dense orthonormal set in a Hilbert space is complete, it follows that the set
\{u_{\lambda}\}_{\lambda\in\mathbb{R}}

B^{2}

\displaystyle\sum_{\lambda\in\mathbb{R}}|\langle\overline{u}f,e_{\lambda}\rangle|^{2}=\sum_{\lambda\in\mathbb{R}}|\langle f,u_{\lambda}\rangle|^{2}=\|f\|^{2}\hskip 28.45274pt(f\in B^{2}).
