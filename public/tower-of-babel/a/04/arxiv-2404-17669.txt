Approximation Algorithms for ℓ p \ell_{p} -Shortest Path and ℓ p \ell_{p} -Group Steiner Tree
Yury Makarychev, Max Ovsiankin, Erasmo Tani

Abstract
We present polylogarithmic approximation algorithms for variants of the Shortest Path, Group Steiner Tree, and Group ATSP problems with vector costs. In these problems, each edge e e has a vector cost c e ∈ ℝ ≥ 0 ℓ c_{e}\in\mathbb{R}_{\geq 0}^{\ell} . For a feasible solution – a path, subtree, or tour (respectively) – we find the total vector cost of all the edges in the solution and then compute the ℓ p \ell_{p} -norm of the obtained cost vector (we assume that p ≥ 1 p\geq 1 is an integer). Our algorithms for series-parallel graphs run in polynomial time and those for arbitrary graphs run in quasi-polynomial time. To obtain our results, we introduce and use new flow-based Sum-of-Squares relaxations. We also obtain a number of hardness results.

Introduction

In this work, we study robust versions of network design problems. In the
\ell_{p}
-Shortest Path problem, we are given
p\geq 1
, a graph
G=(V,E)
with vector-valued edge costs
c_{e}\in\mathbb{R}_{\geq 0}^{\ell}
, and two vertices
s
and
t
; the goal is to find a path
P
from
s
to
t
in
G
that minimizes the following cost:

\cost_{\ell_{p}}(P)=\left\|\sum_{e\in P}c_{e}\right\|_{p}

This problem is a natural generalization of the classical shortest path problem, but surprisingly has not received much attention till recently.
The problem has been studied for
p=\infty
under the name Robust Shortest Path.
Aissi, Bazgan and Vanderpooten
[
ABV07
]
used dynamic programming to obtain a fully polynomial-time approximation scheme for the case when the number of coordinates
\ell
is a constant and
p=\infty
(this result generalizes to other
p
). Kasperski and Zieliński
[
KZ09
]
proved that
\ell_{\infty}
-Shortest Path is hard to approximate within
\log^{1-\varepsilon}\ell
for all
\varepsilon>0
unless
\mathrm{NP}\subseteq\mathrm{DTIME}(n^{\operatorname{polylog}n})
.
More recently, the same authors
[
KZ18
]
gave an
O(\sqrt{n\log\ell/\log\log\ell})
-approximation to the problem by rounding a flow-based linear programming relaxation and proved that their LP has the integrality gap of
\Omega(\sqrt{n})
. In a recent breakthrough, Li, Xu, and Zhang
[
LXZ24
]
gave an
O(\log n\log\ell)
-approximation algorithm for
\ell_{\infty}
-Shortest Path with running time quasi-polynomial in the size of the input instance. In particular, their algorithm is the first polylogarithmic approximation known to date. They also show that the same approximation guarantees can be obtained in polynomial time for graphs of bounded treewidth, and they give a polynomial time
O(d\log\ell)
approximation algorithm for series-parallel graphs, where
d
is the depth (order) of the series-parallel decomposition of the input graph. No results were known for any other exponents
p\in(1,\infty)
. However, it is trivial to get an
\ell^{1-1/p}
-approximation by solving standard shortest path with edge costs
\|c_{e}\|_{1}
.

Introducing vector-valued costs to the graph’s edges allows this model to capture a number of different applications. First, it allows us to describe a situation in which different parties, each corresponding to a different coordinate of the cost vectors, incur different cost when an edge is added to the solution.
In this interpretation, as
p\to\infty
, the problem will increasingly favor paths in which every party simultaneously incurs small cost. Alternatively, each coordinate of the cost vectors may represent the cost incurred in terms of a different resource. This model would then allow one to balance minimizing the total amount of resources spent and ensuring that no single resource is depleted. Furthermore, one can think of this problem as providing an avenue for modeling robustness of a solution in the presence of uncertainty. Each coordinate would then represent the cost incurred by adding an edge in a distinct possible scenario, and the value of the
\ell_{p}
-Shortest Path problem would amount to a trade-off between average and worst-case cost among all scenarios. Finally, this problem generalizes congestion minimization in directed graphs (a fact that we prove in
Section

8.2
).

Our results for the
\ell_{p}
-Shortest Path problem

In this paper, we introduce a natural flow-based sum-of-squares (SoS) relaxation for
\ell_{p}
-Shortest Path (
Section

3
) and present approximation algorithms for all integer
p\geq 1
.

First, we give an
O(pd^{1-1/p})
-approximation algorithm for the problem running in
n^{O(p)}
time for series-parallel graphs of depth/order
d
(
Section

5
). We do this by considering a natural rounding algorithm for the SoS relaxation.
We prove the following theorem:

Theorem 1.1
.

There exists an approximation algorithm for the
\ell_{p}
-Shortest Path problem in series-parallel graphs that, given a series-parallel graph
G
of order/depth
d
and parameters
p\in\mathbb{Z}_{\geq 1}
and
\varepsilon\in(0,1)
, finds a

(1+\varepsilon){\cal{B}}_{d}(p)^{1/p}=O(pd^{1-1/p})
approximation in time
m^{O(p)}/\varepsilon^{O(1)}
(which is polynomial time when
p
and
\varepsilon
are fixed). Here,
{\cal{B}}_{d}(p)
is the
p
-th
d
-dimensional Bell number.

We provide a review of Bell numbers in the preliminaries.

For graphs of small series-parallel order/depth
d\leq\log^{*}p
, the approximation factor is
{\cal{B}}_{d}^{1/p}\leq O(p/\log^{(d)}p)
.
Remarkably, in a complementary analysis given in
Section

8.3
, we show that the approximation factor
{\cal{B}}_{d}(p)^{1/p}
is tight for our rounding scheme.
In all algorithms, we assume that
\ell
is at most polynomial in

(if not, the running times will also depend on
\ell
).

Then, we give a
O(p\log^{1-1/d}n)
-approximation for arbitrary graphs (

6
), obtaining the following theorem:

Theorem 1.2
.

There exists an approximation algorithm for the
\ell_{p}
-Shortest Path problem in arbitrary graphs that, given a graph
G
and parameters
p\in\mathbb{Z}_{\geq 1}
and
c\in(0,1/2)
, finds a
cp\log^{1-1/p}n
approximation in time
m^{ce^{O(1/c)}\log n}=m^{O_{c}(\log n)}
.

Note that when
p=\log\ell
, this result yields an
O(c\log n\log\ell)
approximation. This is very similar to the approximation guarantee of
O(\log n\log k)
by Li, Xu, and Zhang, except that in our algorithm
c
can be an arbitrarily small constant.

Remark 1.3
.

As previously discussed, an
\ell^{1-1/p}
-approximation is trivial to achieve in polynomial time by solving standard shortest path with edge costs
\|c_{e}\|_{1}
. On the other hand, for each fixed
\ell^{\prime}
there is a polynomial-time approximation scheme (PTAS) for
\ell_{p}
-Shortest Path in
\ell^{\prime}
dimensions that runs in time
n^{O(\ell^{\prime})}
. We now explain how to combine these two results. Fix
\delta\in(1/\ell,1/2)
. Divide the coordinates of the cost vectors
c_{e}\in\mathbb{R}^{\ell}
into
\ell^{\prime}=\lceil 1/\delta\rceil
groups, each of size at most
k=\lceil\delta\ell\rceil

and then add up the coordinates in each group. For each cost vector
c_{e}\in\mathbb{R}^{\ell}
, we obtain a new vector
c_{e}^{\prime}\in\mathbb{R}^{\ell^{\prime}}
. Costs
c^{\prime}_{e}
approximate costs
c_{e}
within a factor of
k^{1-1/p}
in the following sense: for every path
P
,

\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{p}\leq\Bigl\|\sum_{e\in P}c_{e}^{\prime}\Bigr\|_{p}\leq k^{1-1/p}\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{p}.

(1.1)

Using the PTAS, we solve the problem with costs
c^{\prime}_{e}
and by (
1.1
) get a
(1+\varepsilon)k^{1-1/p}
approximation to the original problem.
We conclude that there exists an approximation algorithm that finds an
O((\delta\ell)^{1-1/p})
approximation in time
n^{O(1/\delta)}
(for every
\delta\in(1/\ell,1/2)
).

In the course of analyzing our algorithms, we prove a new majorization inequality for pseudo-expectations (see
Section

4
) generalizing pseudo-expectation Lyapunov’s and Hölder inequality (for the latter see
[
BKS14
, arXiv version]
). We believe this result to be of independent interest.

Hardness results

We also complement the analysis above with several hardness results for
\ell_{p}
-Shortest Path. First, in
Section

8.2
, we give a reduction showing that the problem of congestion minimization can be reduced to the
\ell_{\infty}
-Shortest Path problem. This simultaneously speaks to the broad applicability of
\ell_{p}
-Shortest Path and implies hardness for the
\ell_{\infty}
-version of the problem, following a result of Chuzhoy and Khanna
[
CK06
]
.

Theorem 1.4
.

The
\ell_{\infty}
-Shortest Path problem is hard to approximate within an
\Omega(\log n/\log\log n)
-factor unless
\mathrm{NP}\subseteq\mathrm{ZPTIME}(n^{\log\log n})
.

This theorem slightly strengthens the
\Omega(\log^{1-\varepsilon}\ell)
-hardness of approximation result by
Kasperski and Zieliński
[
KZ09
]
.
Finally, in
Section

8.1
, we show that allowing the entries of the cost vectors to be negative makes the problem substantially harder. We do this by giving a reduction from the Closest Vector problem in lattices to this (potentially negative costs) version of the
\ell_{p}
-Shortest Path problem.
Below,
\Omega_{p}
hides a constant depending on
p
.

Theorem 1.5
.

For every
p\in[1,\infty]
, it is
\mathrm{NP}
-Hard to approximate the
\ell_{p}
-Shortest Path problem allowing negative edge costs within a factor of
n^{\Omega_{p}(1/\log\log n)}
.

Remark 1.6
.

The requirement that all the coordinates of cost vectors
c_{e}
are non-negative can be slightly relaxed when
p=2
. For our algorithms to work, it is sufficient that all pairwise inner products of cost vectors are non-negative. That is, instead of requiring that the Gram matrix of cost vectors is completely positive, we can only require that it is doubly non-negative.

From shortest path to network design

In network design problems, one is
given a graph
G=(V,E)
with non-negative edge costs
c_{e}\geq 0
, and wishes to find a subgraph
F=(V_{F},E_{F})
that minimizes the total cost
\sum_{e\in E_{F}}c_{e}
subject to some connectivity constraints.
By varying the set of allowed subgraphs
F
, this paradigm encapsulates many central and well-studied network design problems, including the Survivable Network Design, Steiner Forest, Steiner Tree, and Minimum Spanning Tree.
In this paper we explore two network design problems, Group Steiner Tree and Asymetric Traveling Salesperson (ATSP). We first recall the Group Steiner Tree problem.

Problem 1.7

(Group Steiner Tree)
.

Given a weighted undirected graph
G=(V,E,c)
, as well as
k
subsets
R_{1},\dots,R_{k}
of
V
, find a minimum-cost subtree
T
of
G
containing at least one vertex from each
R_{i}
.

We then introduce an analogous group variant of ATSP:

Problem 1.8

(Group ATSP)
.

Given a weighted directed graph
G=(V,E,c)
and a collection of subsets
R_{1},\dots,R_{k}
of
V
, find a minimum-cost tour that visits at least one vertex in each
R_{i}
.

As in the case of Shortest Path, it is natural to ask whether we can approximately solve
\ell_{p}
versions of other network design problems efficiently. Prior work has been done in this area. Hamacher and Ruhe
[
HR94
]
studied
\ell_{\infty}
-Minimum Spanning Tree, and proved that it is NP-complete. Following that, the complexity of the problem has been nearly completely settled: Chekuri, Vondrák, and Zenklusen
[
CVZ10
]
presented an
O(\log\ell/\log\log\ell)
-approximation algorithm, while Kasperski and Zielinski
[
KZ11
]
(also see
[
KZ16
]
, Table 1) proved an
\Omega(\log^{1-\varepsilon}\ell)
-hardness of approximation for every
\varepsilon>0
, unless all problems in NP can be solved in quasi-polynomial time. Laddha, Singh and Vempala
[
LSV22
]
studied the
\ell_{\infty}
-version of a subclass of network design problems which encompasses the Generalized Steiner Network problem, and gave a polynomial-time
\ell
-approximation algorithm for it.

Our results for
\ell_{p}
-Group Steiner Tree and

We consider the
\ell_{p}
-version of the Group Steiner Tree and the Group ATSP problems.

.

There exists an approximation algorithm for

\ell_{p}
-Group Steiner Tree problem in undirected graphs that given a graph
G
, groups
R_{i}
, and parameters
p\in\mathbb{Z}_{\geq 1}
and

Multi-objective combinatorial optimization for shortest path and network design

The work in this paper is closely related to multi-objective combinatorial optimization (MOCO). This area studies combinatorial optimization problems in the presence of multiple competing objective functions. Much of the literature on MOCO is concerned with finding all or some Pareto efficient solutions, that is, solutions that are not dominated in every objective by any other solution, a problem which is often intractable due to the exponential number of these points. In particular, there is prior MOCO work on both shortest path
[
Han80
,
Mar84
,
BDH17
]
and network design problems
[
RMRRH93
]
. We refer the reader to the paper of Ruzika and Hamacher
[
RH09
]
for a survey on multi-objective spanning tree problems, and the book of Ehrgott
[
Ehr05
]
for an overview of multi-criteria optimization area as a whole.

1.2
Technical Overview

Let us first discuss the
\ell_{p}
-Shortest Path problem. The most basic variant of this problem is when
G
is a series-parallel graph (see Section
2
for definitions) and
p=2
. The first idea is to write an LP flow relaxation with a convex objective: minimize
\|\sum_{e\in E}c_{e}x_{e}\|^{2}
subject to the constraint that
(x_{e})_{e\in E}
define a unit flow from
s
to
t
. However, this LP has an integrality gap of
\sqrt{\ell}
. To deal with this problem, Li, Xu, and Zhang
[
LXZ24
]
introduced a new constraint for
\ell_{\infty}
-Shortest Path: the constraint loosely speaking says that the LP cost of every subgraph/block
B
in the series-parallel decomposition of
G
is at most
\mathsf{OPT}
times the probability (according to the LP) that the path visits
B
. Unfortunately, this new constraint does not help when
p=2
.

Instead, we consider a sum-of-squares (SoS) strengthening of this LP.
2
2

2

It is sufficient to use a vector-flow SDP with one vector variable per edge in order to approximate the
\ell_{2}
-cost in series-parallel graphs. However, we need higher degree SoS relaxations when
p>2
and in general graphs.
The SoS relaxation gives valuations not only to individual edges but also to tuples of edges. Using the standard notation of pseudo-expectations (see Section
2
), the SoS relaxation for
p=2
gives
\operatorname{\widetilde{\mathbb{E}}}[x_{e}]
for every edge
e
and
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}]
for every pair of edges
e_{1}
and
e_{2}
. The former could be interpreted as the probability that
e\in P
and the latter as the probability as both
e_{1},e_{2}\in P
according to the relaxation.
To the best of our knowledge, this is the first flow-based SoS or SDP relaxation studied in the literature.

Our algorithm is very straightforward. We start at
u_{0}=s
, then choose one of the edges outgoing from
u_{1}
with probability of choosing
e
being equal to
\operatorname{\widetilde{\mathbb{E}}}[x_{e}]
. We get to a vertex
u_{1}
and then again sample one of the edges leaving
u_{1}
with probability of choosing
e
proportional to
\operatorname{\widetilde{\mathbb{E}}}[x_{e}]
. We repeat this step over and over until we reach
t
. It is clear that the algorithm finds an
s
-
t
path
P
.

Now we need to upper bound the cost of
P
. We do that recursively using the series-parallel decomposition of
G
.
3
3

3

Interestingly, neither the relaxation nor the algorithm uses the series-parallel decomposition of
G
.
Assume that
G
is composed of subgraphs/blocks
B_{1},\dots,B_{t}

and our algorithm achieves an
\alpha
approximation for the squared
\ell_{2}
-cost in each of them. For simplicity, assume that
t=2
for now. There are two cases:
G
is a (i) parallel and (ii) series composition of
B_{1}
and
B_{2}
. Consider the first case.
The SoS relaxation ensures that
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}]=0
for all
e_{1}\in B_{1}
and
e_{2}\in B_{2}
; this means that the SoS solution is simply a convex combination of solutions for
B_{1}
and
B_{2}
with some weights
p_{1}
and
p_{2}
.
Also, with probability
p_{1}
, the first edge of
P
will be in
B_{1}
and then the entire path will be in
B_{1}
; similarly, with probability
p_{2}
, the entire path will be in
B_{2}
. Thus running the algorithm reduces to randomly choosing a block
B_{i}
with probability
p_{i}
and then running the algorithm in
B_{i}
. Since the algorithm gets an
\alpha
approximation in each
B_{i}
, it also gets an
\alpha
approximation in the entire graph. Interestingly, this step would already fail if we used the basic LP relaxation; however, a Sherali–Adams or configuration LP would work in
this
case.

The second case – when
G
is a series composition of
B_{1}
and
B_{2}
is more challenging and requires the power of an SDP relaxation. Let
P_{i}=P\cap B_{i}
. Write the squared objective as follows:

\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{2}^{2}=\underbrace{\Bigl\|\sum_{e\in P_{1}}c_{e}\Bigr\|_{2}^{2}+\Bigl\|\sum_{e\in P_{2}}c_{e}\Bigr\|_{2}^{2}}_{\leq\alpha\mathsf{OPT}^{2}\text{ (in expectation)}}+2\sum_{\begin{subarray}{c}e_{1}\in P_{1}\\
e_{2}\in P_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle.

(1.2)

The first two terms are squared
\ell_{2}
-costs of paths
P_{1}
and
P_{2}
. As we assumed, they are at most
\alpha
times their SoS costs, and thus their sum is at most
\alpha\mathsf{OPT}^{2}
(in expectation). We now analyze the third term. It is not hard to see that our algorithm samples edges in
P_{1}
and
P_{2}
independently (because the last vertex of
P_{1}
and the first vertex of
P_{2}
are fixed). Therefore,

\mathbb{E}\Bigl[\sum_{\begin{subarray}{c}e_{1}\in P_{1}\\
e_{2}\in P_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle\Bigr]=\sum_{\begin{subarray}{c}e_{1}\in B_{1}\\
e_{2}\in B_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle\cdot\Pr\left(e_{1},e_{2}\in P\right)=\sum_{\begin{subarray}{c}e_{1}\in B_{1}\\
e_{2}\in B_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle\cdot\Pr\left(e_{1}\in P\right)\cdot\Pr\left(e_{2}\in P\right).

(1.3)

It would be natural to upper bound this expression by the corresponding expression in the SoS objective (appropriately scaled):

\sum_{\begin{subarray}{c}e_{1}\in B_{1}\\
e_{2}\in B_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle\cdot\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}].

However, this is not possible, since it may happen that

\Pr\left(e_{1}\in P\right)\cdot\Pr\left(e_{2}\in P\right)>0
but
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}]=0
. Instead, observing that for every edge
e
,
\Pr\left(e\in P\right)=\operatorname{\widetilde{\mathbb{E}}}[x_{e}]
, we rewrite and upper bound (
1.3
):

\displaystyle\sum_{\begin{subarray}{c}e_{1}\in B_{1}\\
e_{2}\in B_{2}\end{subarray}}\langle c_{e_{1}},c_{e_{2}}\rangle\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}]\operatorname{\widetilde{\mathbb{E}}}[x_{e_{2}}]

\displaystyle\leq\sum_{e_{1},e_{2}\in E}\langle c_{e_{1}},c_{e_{2}}\rangle\cdot\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}]\cdot\operatorname{\widetilde{\mathbb{E}}}[x_{e_{2}}]

\displaystyle=\Bigl\|\operatorname{\widetilde{\mathbb{E}}}\Bigl[\sum_{e\in E}c_{e}x_{e}\Bigr]\Bigr\|_{2}^{2}\leq\operatorname{\widetilde{\mathbb{E}}}\Bigl[\Bigl\|\sum_{e\in E}c_{e}x_{e}\Bigr\|^{2}\Bigr]\leq\mathsf{OPT}^{2}.

Here, we first expanded the summation, then used the pseudo-expectation Lyapunov’s inequality
\|\operatorname{\widetilde{\mathbb{E}}}[f]\|_{2}^{2}\leq\operatorname{\widetilde{\mathbb{E}}}[\|f\|_{2}^{2}]
(see Fact
2.9
), and finally observed that the last pseudo-expectation is the SoS objective for
G
.
We conclude that the expected squared cost of
P
is at most
(\alpha+2)\mathsf{OPT}
.
Applying this argument recursively, we get an
O(d)
-approximation for the squared cost and an
O(\sqrt{d})
-approximation for the cost itself in series-parallel graphs of order/depth
d
.

When
p>2
and blocks in the series-parallel composition of
G
are formed by
t>2
lower-order blocks, the proof becomes more technical. In particular, we need to use a new majorization inequality for pseudo-expectation, which we present in Section
4
.

The SoS relaxation for arbitrary graphs is the same as that for series-parallel graphs (except that its degree is higher). However, the rounding algorithm is quite different. Very informally, the algorithm in its simplest form resembles Savitch’s algorithm for
s
-
t
connectivity in
O(\log^{2}n)
space
[
Sav70
]
(see also
[
CP05
]
): (i) we sample the middle edge
e=(u,v)
of the path using probabilities provided by
\operatorname{\widetilde{\mathbb{E}}}[\cdot]
, (ii) condition
\operatorname{\widetilde{\mathbb{E}}}[\cdot]
on
e
being the middle edge, (iii) then recursively find paths
P_{1}
from
s
to
u
and (independently)
P_{2}
from
v
to
t
, using the
conditional
pseudo-expectation. To upper bound the cost, as in the analysis of the algorithm for series-parallel graphs, we first use (
1.2
) , then bound the third term using a variant of (
1.3
), and finally use the majorization inequality for pseudo-expectations.

To solve Group ATSP, we loosely speaking add SoS constraints that require that the tour
P
visits every group (for technical reasons, we need to require that
P
visits each group exactly once). Then we run the rounding algorithm for
\ell_{p}
-Shortest Path in arbitrary graphs. It is not guaranteed that
P
indeed visits every group; however, using the machinery we developed for bounding the cost of
P
, we show that
P
visits every group with probability at least
\Omega(1/\log n)
. By sampling sufficiently many tours and concatenating them, we obtain the desired solution with high probability. The Group Steiner Tree problem easily reduces to Group ATSP.

(2.1)

2.3
Sum-of-Squares Relaxations

We recall some basics about the sum-of-squares relaxations. Sum-of-squares relaxations can be thought of in terms of moment matrices, pseudo-distributions, and pseudo-expectations. As is common, we will use the pseudo-expectation framework in this paper. We refer the reader to
[
FKP19
]
for a detailed description of the sum-of-squares framework.

Consider a set of variables
x_{i}
where
i
belongs to some set of indices
{\cal{I}}
. We denote the entire collection of all variables
(x_{i})_{i\in{\cal{I}}}
by
\mathbf{x}
. Consider the set of multivariate polynomials
\mathbb{R}_{\leq d}[\mathbf{x}]\stackrel{{\scriptstyle\mathrm{\scriptscriptstyle def}}}{{=}}\mathbb{R}_{\leq d}[\{x_{i}:i\in{\cal{I}}\}]
in variables
x_{i}
of degree at most
d
. We say that
f\in\mathbb{R}_{\leq d}[\mathbf{x}]
is a sum of squares (SoS) if
f=\sum_{i=1}^{m}f_{i}^{2}
for some polynomials
f_{1},\dots,f_{m}
. Note that the product of SoS polynomials is a SoS, and so is any linear combination of SoS polynomials with positive coefficients.

In this paper, we consider SoS relaxations for the Boolean hypercube; that is, all variables
x_{i}
take values
0
and
1
in the intended solution. Therefore, we work with the quotient ring
\mathbb{R}_{\leq d}/\langle x_{i}^{2}-x_{i}\rangle_{i}
, where
\langle x_{i}^{2}-x_{i}\rangle_{i}
is the ideal generated by polynomials
x_{i}^{2}-x_{i}
. In other words, we identify monomials
x_{i_{1}}^{a_{1}},\dots,x_{i_{t}}^{a_{t}}
and
x_{i_{1}},\dots,x_{i_{t}}
for all
i_{1},\dots,i_{t}
and
a_{1},\dots,a_{t}\geq 1
such that
\sum_{i=1}^{t}a_{i}\leq d
. In particular, we will write
f=g
if
f-g\in\langle x_{i}^{2}-x_{i}\rangle_{i}
.

Definition 2.6
.

A linear map
\operatorname{\widetilde{\mathbb{E}}}:\mathbb{R}_{\leq d}[\mathbf{x}]/\langle x_{i}^{2}-x_{i}\rangle_{i}\to\mathbb{R}
is a pseudo-expectation of degree
d
if it satisfies the following properties.

•

\operatorname{\widetilde{\mathbb{E}}}[1]=1
,

•

\operatorname{\widetilde{\mathbb{E}}}[f^{2}]\geq 0
for every polynomial
f
of degree at most
d/2
,

We say that a pseudo-expectation
\operatorname{\widetilde{\mathbb{E}}}
satisfies an equality constraint
f=0
if
\operatorname{\widetilde{\mathbb{E}}}[fg]=0
whenever
\deg fg\leq d
.

Given an objective function
f
and sets of equality and inequality constraints, we can find a pseudo-expectation
\operatorname{\widetilde{\mathbb{E}}}
that maximizes
\operatorname{\widetilde{\mathbb{E}}}[f]
and satisfies all the constraints in time polynomial in
N^{O(d)}
, where
N
is the number variables, as long as it satisfies certain regularity conditions
[
RW17
]
. When we prove any statements about pseudo-expectations
\operatorname{\widetilde{\mathbb{E}}}[f]
below, we will
always
implicitly assume that
d\geq\Omega(\deg f)
so that all the inequalities appearing in the proofs have degree at most
d
.

Definition 2.7
.

Let
\operatorname{\widetilde{\mathbb{E}}}
be a pseudo-expectation of degree
d
.
Assume that
g
is a sum of squares and
\operatorname{\widetilde{\mathbb{E}}}[g]>0
. Then the conditional pseudo-expectation
\operatorname{\widetilde{\mathbb{E}}}[\cdot\,|\,g]
operator is defined as follows:
\operatorname{\widetilde{\mathbb{E}}}[f\,|\,g]\stackrel{{\scriptstyle\mathrm{\scriptscriptstyle def}}}{{=}}\operatorname{\widetilde{\mathbb{E}}}[fg]/\operatorname{\widetilde{\mathbb{E}}}[g]
.

Fact 2.8
.

A conditional pseudo-expectation
\operatorname{\widetilde{\mathbb{E}}}[\cdot\,|\,g]
is a pseudo-expectation of degree
d^{\prime}=d-\deg g
. If
\operatorname{\widetilde{\mathbb{E}}}
satisfies an equality or inequality constraint of degree at most
d^{\prime}
, then so does
\operatorname{\widetilde{\mathbb{E}}}
.

We will use Lyapunov’s inequality for pseudo-expectations (which is also referred to as Jensen’s inequality in the literature).

Claim 2.9
.

Let
g
be a sum of squares and f be any polynomial. Assume that
\deg f^{2}g\leq d
. Then,

\operatorname{\widetilde{\mathbb{E}}}[fg]^{2}\leq\operatorname{\widetilde{\mathbb{E}}}[f^{2}g]\operatorname{\widetilde{\mathbb{E}}}[g].

(2.2)

If
\operatorname{\widetilde{\mathbb{E}}}[g]>0
, the inequality can be restated as

\operatorname{\widetilde{\mathbb{E}}}[f\,|\,g]^{2}\leq\operatorname{\widetilde{\mathbb{E}}}[f^{2}\,|\,g].

(2.3)

Claim 2.10
.

Let
f_{1},\dots,f_{t}
be SoS polynomials. Then,
\operatorname{\widetilde{\mathbb{E}}}[\left(\sum_{i=1}^{t}f_{i}\right)^{p}]\geq\sum_{i=1}^{t}\operatorname{\widetilde{\mathbb{E}}}[f_{i}^{p}]
.

Proof.

We expand
\left(\sum_{i=1}^{t}f_{i}\right)^{p}
as
\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=p\end{subarray}}\binom{p}{\alpha}f_{1}^{\alpha_{1}}\cdots f_{t}^{\alpha_{t}}
. All terms in the expansion are SoS polynomials and thus have non-negative pseudo-expectations. The claim follows from the observation that all terms
f_{i}^{p}
are present in the expansion.
∎

Sum of Squares Relaxation for
\ell_{p}
-Shortest Path

In this section, we first present our SoS relaxation for
\ell_{p}
-Shortest Path in directed acyclic graphs (DAGs). In
Section

5
, we will present a rounding algorithm for series-parallel graphs and then, in
Section

6
, for layered graphs. The latter result will also yield an algorithm for arbitrary graphs. We will also describe a few basic properties that feasible solutions for this relaxation satisfy.

Relaxation

We use a degree
2p
SoS relaxation with variables
\mathbf{x}=\left(x_{e}\right)_{e\in E}
for
\ell_{p}
-Shortest Path in series-parallel graphs.

min

\displaystyle\operatorname{\widetilde{\mathbb{E}}}\Bigl[\sum_{i=1}^{\ell}\Bigl(\sum_{e}c_{e}(i)x_{e}\Bigr)^{p}\Bigr]

subject to

\displaystyle(x_{e})_{e\in E}\text{ is a unit flow from }s\text{ to }t

The flow constraint says that
\sum_{e\in\delta^{+}(u)}x_{e}-\sum_{e\in\delta^{-}(u)}x_{e}=0
for all
u
other than
s
and
t
(flow conservation) and
\sum_{e\in\delta^{+}(s)}x_{e}-1=0
(
x_{e}
sends 1 unit of flow from
s
to
t
).
It is clear that this is a relaxation for the
\ell_{p}
-Shortest Path problem:
\operatorname{\widetilde{\mathbb{E}}}[\sum_{i=1}^{\ell}(\sum_{e}c_{e}(i)x_{e})^{p}\Bigr]\leq\mathsf{OPT}^{p}
, where
\mathsf{OPT}
is the
\ell_{p}
-cost of the optimal
s
-
t
path.

Basic properties of the SoS relaxation

We say that two edges
e_{1}
and
e_{2}
are
compatible
if both of them belong to some
s
-
t
path; otherwise, we say that
e_{1}
and
e_{2}
are
incompatible
. In a series-parallel graph edges
e_{1}
and
e_{2}
are incompatible if and only if there exist two parallel blocks
B_{1}
and
B_{2}
such that
e_{1}
lies in
B_{1}
and
e_{2}
lies in
B_{2}
.
For any set of vertices
A
, let
\mathbf{x}^{+}_{A}=\sum_{e\in\delta^{+}(A)}x_{e}
and
\mathbf{x}^{-}_{A}=\sum_{e\in\delta^{-}(A)}x_{e}
.

Claim 3.1
.

Assume that
G
is a DAG and
\operatorname{\widetilde{\mathbb{E}}}
is a feasible pseudo-expectation for the relaxation. Let
h
be a multivariate polynomial. Then

1.

If
A\subseteq V
contains neither of the terminals, then
\operatorname{\widetilde{\mathbb{E}}}[(\mathbf{x}^{+}_{A}-\mathbf{x}^{-}_{A})h]=0
. If
A
contains
s
but not
t
,
\operatorname{\widetilde{\mathbb{E}}}[(\mathbf{x}^{+}_{A}-\mathbf{x}^{-}_{A})h]=\operatorname{\widetilde{\mathbb{E}}}[h]
.

2.

If
e_{1}
and
e_{2}
are not compatible, then
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}h]=0
.

3.

Assume further that
G
is a series-parallel graph. Let
(L,R)
be an
s_{B}
-
t_{B}
cut in a block
B
. Let
f_{LR}=\sum_{e\in\delta(L,R)}x_{e}
.
Then

\operatorname{\widetilde{\mathbb{E}}}\Bigl[f_{LR}h\Bigr]=\operatorname{\widetilde{\mathbb{E}}}\Bigl[\bigl(\sum_{e\in\delta^{+}(s_{B})\cap B}x_{e}\bigr)h\Bigr].

In particular,
\operatorname{\widetilde{\mathbb{E}}}[f_{LR}h]
does not depend on the cut
(L,R)
in
B
.

Proof.

1. The SoS relaxation satisfies the flow conservation constraints and the constraint that the amount of flow being routed equals
1
. Therefore, it satisfies any linear combination of them. In particular, it satisfies degree-1 polynomial equations
\mathbf{x}^{+}_{A}-\mathbf{x}^{-}_{A}=0
when
s,t\notin A
and
\mathbf{x}^{+}_{A}-\mathbf{x}^{-}_{A}=1
when
s\in A
but
t\notin A
. The first item follows.

2.
It is sufficient to prove the statement for all monomials (the claim then follows by the linearity of
\operatorname{\widetilde{\mathbb{E}}}
). Thus, we will assume that
h
is a monomial.
Recall that an
s
-
t
cut is monotone if it cuts exactly one edge on every
s
-
t
path. Since
e_{1}
and
e_{2}
are incompatible, there is a monotone
s
-
t
cut
(A,\bar{A})
that cuts both of them. We apply item 1 to polynomial
x_{e_{1}}h
and get

\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}h]=\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}\mathbf{x}^{+}_{A}h]=\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}(x_{e_{1}}+x_{e_{2}}+\dots)h]
. Here,
\dots
is a sum of some
x_{e}
(the coefficient of each of them is 1). Note that
x_{e}h
is a monomial, thus
x_{e}h=(x_{e}h)^{2}
and therefore
\operatorname{\widetilde{\mathbb{E}}}[x_{e}h]\geq 0
. We conclude that

\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}h]\geq\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}(x_{e_{1}}+x_{e_{2}})h]=\operatorname{\widetilde{\mathbb{E}}}[(x_{e_{1}}+x_{e_{1}}x_{e_{2}})h]

and simplifying, we get
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}h]\leq 0
.
Since
x_{e_{1}}x_{e_{2}}h
is a monomial,
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}h]\geq 0
, and thus
\operatorname{\widetilde{\mathbb{E}}}[x_{e_{1}}x_{e_{2}}h]=0
.

3. Item 3 follows immediately from item 1.
∎

Majorization Inequalities for Pseudo-expectations

In this section, we will prove a majorization inequality for pseudo-expectations. This inequality generalizes already known pseudo-expectation Lyapunov’s (see Claim
2.9
) and Hölder’s (see
[
BKS14
]
) inequalities.

Definition 4.1
.

Consider two integer sequences
a_{1}\geq a_{2}\geq\ldots\geq a_{k}\geq 0

and
b_{1}\geq\ldots\geq b_{k}\geq 0
.
We say
a
majorizes
b
and write
a\succeq b
, if
\sum_{i=1}^{k}a_{i}=\sum_{i=1}^{k}b_{i}
and for all
1\leq i\leq k
we have

a_{1}+\ldots+a_{i}\geq b_{1}+\ldots+b_{i}.

Sequence majorization is a powerful tool for proving inequalities; it appears in widely used Muirhead’s
[
Mui02
]
and Karamata’s
[
Kar32
]
majorization inequalities. We now present a majorization inequality for pseudo-expectations. An analogous inequality for true expectations easily follows both from Karamata’s and from Muirhead’s majorization inequality.

Lemma 4.2
.

Consider a degree
d
pseudo-expectation
\operatorname{\widetilde{\mathbb{E}}}
. Let
a\succeq b
and
f
be an SoS polynomial of degree
\deg(f^{a_{1}})\leq d
. Then

\prod_{i=1}^{k}\operatorname{\widetilde{\mathbb{E}}}[f^{a_{i}}]\geq\prod_{i=1}^{k}\operatorname{\widetilde{\mathbb{E}}}[f^{b_{i}}].

(4.1)

Proof.

First, observe that this inequality for sequences
(r+1,r-1)\succeq(r,r)
follows from Lyapunov’s inequality for pseudo-expectations (Claim
2.9
). Indeed, let
g=f^{r-1}
. Then, Lyapunov’s inequality states that

\operatorname{\widetilde{\mathbb{E}}}[f^{r}]^{2}=\operatorname{\widetilde{\mathbb{E}}}[fg]^{2}\leq\operatorname{\widetilde{\mathbb{E}}}[f^{2}g]\operatorname{\widetilde{\mathbb{E}}}[g]=\operatorname{\widetilde{\mathbb{E}}}[f^{r+1}]\operatorname{\widetilde{\mathbb{E}}}[f^{r-1}],

(4.2)

as required.
Now we use this inequality to show the desired inequality (
4.1
) for a more general case
(p+1,q-1)\succeq(p,q)
.

Claim 4.3
.

Let
p\geq q\geq 1
be integers.
Then

\operatorname{\widetilde{\mathbb{E}}}[f^{p+1}]\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\geq\operatorname{\widetilde{\mathbb{E}}}[f^{p}]\operatorname{\widetilde{\mathbb{E}}}[f^{q}].

Proof.

We just proved the inequality when
p=q
. So we will assume below that
p>q
. Since
f
is an SoS polynomial,
\operatorname{\widetilde{\mathbb{E}}}[f^{r}]\geq 0
for all integers
0\leq r\leq p
.
Let us assume first that the inequality is strict for all
r
:
\operatorname{\widetilde{\mathbb{E}}}[f^{r}]>0
. Then, by dividing and multiplying
\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]
by
\prod_{r=q}^{p-1}\operatorname{\widetilde{\mathbb{E}}}[f^{r}]
, we obtain the following identity.

\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]=\frac{\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]}{\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]}

Now we upper bound the numerator of this fraction by iteratively applying (
4.2
).

\displaystyle\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\Bigr)\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]

\displaystyle\leq\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\Bigr)\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]

\displaystyle\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\Bigr)\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]

\displaystyle\leq\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+2}]\Bigr)\cdots\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]

\displaystyle\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{p}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]\Bigr)

\displaystyle\leq\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{q+1}]\cdots\Bigl(\operatorname{\widetilde{\mathbb{E}}}[f^{p-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p+1}]\Bigr)

We conclude that

\operatorname{\widetilde{\mathbb{E}}}[f^{q}]\operatorname{\widetilde{\mathbb{E}}}[f^{p}]\leq\operatorname{\widetilde{\mathbb{E}}}[f^{q-1}]\operatorname{\widetilde{\mathbb{E}}}[f^{p+1}],

as desired.
If
\operatorname{\widetilde{\mathbb{E}}}[f^{r}]=0
for some
r
, we apply the inequality to
\hat{f}=f+\varepsilon
(where
\varepsilon>0
). Now
\operatorname{\widetilde{\mathbb{E}}}[{\bar{f}}^{r}]\geq\varepsilon^{r}>0
, since

is a SoS polynomial. Therefore,

\operatorname{\widetilde{\mathbb{E}}}[\hat{f}^{q}]\operatorname{\widetilde{\mathbb{E}}}[\hat{f}^{p}]\leq\operatorname{\widetilde{\mathbb{E}}}[\hat{f}^{q-1}]\operatorname{\widetilde{\mathbb{E}}}[\hat{f}^{p+1}]
.
Letting

, we obtain the desired inequality in the limit.
∎

Consider an integer sequence

Lemma 5.1

Claim 5.2
.

Let

be a block inside

(possibly

). Assume

\mathbb{E}_{B}\left[\cost(P_{B^{\prime}})^{r}\right]=\frac{\mathbb{E}\left[\cost(P_{B^{\prime}})^{r}\right]}{p_{B}}

\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B^{\prime}}^{r}]=\frac{\operatorname{\widetilde{\mathbb{E}}}[f_{B^{\prime}}^{r}]}{p_{B}}
when

Proof.

We have

\displaystyle\mathbb{E}\left[\cost(P_{B^{\prime}})^{r}\right]

\displaystyle=\mathbb{E}\left[\cost(P_{B^{\prime}})^{r}\,|\,P_{B}\neq\varnothing\right]\cdot\Pr\left(P_{B}\neq\varnothing\right)+\mathbb{E}\left[\cost(P_{B^{\prime}})^{r}\,|\,P_{B}=\varnothing\right]\cdot\Pr\left(P_{B}=\varnothing\right)

\displaystyle=\mathbb{E}_{B}\left[\cost(P_{B^{\prime}})^{r}\right]\cdot p_{B}+0\cdot(1-p_{B})=p_{B}\cdot\mathbb{E}_{B}\left[\cost(P_{B^{\prime}})^{r}\right],

as required. To prove the second identity, consider a monomial

in the expansion of

. We now prove that
\operatorname{\widetilde{\mathbb{E}}}[gh_{B}]=\operatorname{\widetilde{\mathbb{E}}}[g]
and thus
\operatorname{\widetilde{\mathbb{E}}}_{B}[g]\stackrel{{\scriptstyle\mathrm{\scriptscriptstyle def}}}{{=}}\operatorname{\widetilde{\mathbb{E}}}[gh_{B}]/p_{B}=\operatorname{\widetilde{\mathbb{E}}}[g]/p_{B}
.
Note that only

with

appear in

, and
\deg g=r\geq 1
. Choose an arbitrary

in

, say

and let

be such that

. Let

be a monotone

, item 3,

\operatorname{\widetilde{\mathbb{E}}}[gh_{B}]=\operatorname{\widetilde{\mathbb{E}}}\Bigl[g\sum_{e^{\prime}\in\delta(L,R)}x_{e^{\prime}}\Bigr]=\operatorname{\widetilde{\mathbb{E}}}\Bigl[g^{\prime}\sum_{e^{\prime}\in\delta(L,R)}x_{e}x_{e^{\prime}}\Bigr].

Lemma 5.3
.

Let
\operatorname{\widetilde{\mathbb{E}}}
be a feasible solution for the SoS relaxation of
\ell_{p}
-Shortest Path. Let
B
be a block of order
\mathcal{h}=\sheight(B)
with
p_{B}>0
. Then for every
r\leq p
, we have

\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]\leq{\cal{B}}_{\mathcal{h}}(r)\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B}^{r}].

Here,
{\cal{B}}_{\mathcal{h}}(r)
is an
\mathcal{h}
-dimensional Bell number (see Section
2.2
for details).

Proof.

We will prove the upper bound on
\mathbb{E}\left[\cost(P_{B})^{r}\right]
by induction on
r
and on the series-parallel decomposition of
B
.
If
r=0
or
\mathcal{h}=0
, the claim trivially holds.
We consider two cases: when a block
B
is a parallel composition and when it is a series composition of lower-level blocks. We start with the former, much simpler case when
B
is a parallel composition of blocks
B_{1},\dots,B_{t}
sharing the same source
s_{B}
and sink
t_{B}
. If
P
visits
B
, then it visits exactly one of the blocks
B_{1},\dots,B_{t}
. Therefore,

\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]=\sum_{i=1}^{t}\mathbb{E}_{B_{i}}\left[\cost(P_{B_{i}})^{r}\right]\Pr\left(P\text{ visits }B_{i}|P\text{ visits }B\right)=\sum_{i=1}^{t}\frac{p_{B_{i}}}{p_{B}}\mathbb{E}_{B_{i}}\left[\cost(P_{B_{i}})^{r}\right].

(5.1)

Note that
f_{B}=\sum_{i=1}^{t}f_{B_{i}}
. Applying Claim
2.10
and then Claim
5.2
twice, we get

\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B}^{r}]\geq\sum_{i=1}^{t}\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B_{i}}^{r}]=\sum_{i=1}^{t}\frac{1}{p_{B}}\operatorname{\widetilde{\mathbb{E}}}[f_{B_{i}}^{r}]=\sum_{i=1}^{t}\frac{p_{B_{i}}}{p_{B}}\operatorname{\widetilde{\mathbb{E}}}_{B_{i}}[f_{B_{i}}^{r}].

(5.2)

In fact the inequality above is an equality by Claim
3.1
, part 2, but we do not need that here.
Comparing (
5.1
) and (
5.2
) term-by-term, and using the induction hypothesis, we get

\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]\leq{\cal{B}}_{\mathcal{h}}(r)\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B}^{r}].

This concludes the analysis of this case.
Now we assume that
B
is a series composition of blocks
B_{1},\dots,B_{t}
.
In this case, if
P
visits
B
then it visits all
B_{i}
; if it visits
B_{i}
, it visits
B
and all other
B_{j}
. Thus,
p_{B}=p_{B_{1}}=\dots=p_{B_{t}}
. Also,
P_{B}
is the concatenation of
P_{B_{1}},\dots,P_{B_{t}}
.
Using the multinomial theorem, we get

\displaystyle\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]

\displaystyle=\mathbb{E}_{B}\left[\left(\sum_{i=1}^{t}\cost(P_{B_{i}})\right)^{r}\right]=\mathbb{E}_{B}\left[\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}\cost(P_{B_{i}})^{\alpha_{i}}\right]

(5.3)

\displaystyle=\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\mathbb{E}_{B}\left[\prod_{i=1}^{t}\cost(P\cap B_{i})^{\alpha_{i}}\right].

Observe that if
P
enters
B
, it necessarily visits
s_{B_{1}},\dots,s_{B_{t}}
and thus paths
P_{B_{1}},\ldots,P_{B_{t}}
are mutually independent. We then have

\displaystyle\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]

\displaystyle=\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}\mathbb{E}_{B}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right].

By Claim
5.2
,

\mathbb{E}_{B}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]=\mathbb{E}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]/p_{B}=\mathbb{E}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]/p_{B_{i}}=\mathbb{E}_{B_{i}}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]

and

\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B_{i}}^{\alpha_{i}}]=\operatorname{\widetilde{\mathbb{E}}}[f_{B_{i}}^{\alpha_{i}}]/p_{B}=\operatorname{\widetilde{\mathbb{E}}}[f_{B_{i}}^{\alpha_{i}}]/p_{B_{i}}=\operatorname{\widetilde{\mathbb{E}}}_{B_{i}}[f_{B_{i}}^{\alpha_{i}}]
.
Using that
\sheight(B_{i})\leq h-1
and applying the induction hypothesis, we get

\displaystyle\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]

\displaystyle=\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}\mathbb{E}_{B}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]=\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}\mathbb{E}_{B_{i}}\left[\cost(P_{B_{i}})^{\alpha_{i}}\right]

\displaystyle\leq\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}{\cal{B}}_{\mathcal{h}-1}(\alpha_{i})\cdot\operatorname{\widetilde{\mathbb{E}}}_{B_{i}}f_{B_{i}}^{\alpha_{i}}=\sum_{\begin{subarray}{c}\alpha_{1},\ldots,\alpha_{t}\geq 0\\
\alpha_{1}+\cdots+\alpha_{t}=r\end{subarray}}\binom{r}{\alpha}\prod_{i=1}^{t}{\cal{B}}_{\mathcal{h}-1}(\alpha_{i})\cdot\operatorname{\widetilde{\mathbb{E}}}_{B}f_{B_{i}}^{\alpha_{i}}.

Now, every
\alpha
in the summation defines an unlabeled partition
\lambda
of
n
:
\lambda
is obtained by sorting all non-zero entries
\alpha_{i}
of
\alpha
. Let us denote this
\alpha\to\sigma
. For example,
\alpha=(4,1,0,2,4,0,2,2)\to\lambda=(4,4,2,2,2,1)
. Thus, to go over all
\alpha
, it is sufficient to go over all

\lambda\operatorname{\vdash}r
and then all
\alpha
such that
\alpha\to\lambda
. To do the latter, we go over all choices of distinct indices
j_{1},\dots,j_{|\lambda|}
and define
\alpha
as follows:
\alpha_{j_{i}}=\lambda_{i}
for
i\in[|\lambda|]
and
\alpha_{j}=0
for all other
j
. However, if
\lambda_{i}=\lambda_{i^{\prime}}
, then indices
j_{1},\dots,j_{|\lambda|}
and those with
j_{i}
and
j_{i^{\prime}}
swapped define the same
\alpha
. It is easy to see that the above procedure defines every
\alpha
exactly
\prod_{j=1}^{r}\cnt(j,\lambda)
times. In the example above with
\lambda=(4,4,2,2,2,1)
, this procedure defines every
\alpha
exactly
2!\cdot 3!
times. Finally note that
\binom{r}{\alpha}=\binom{r}{\lambda}
.
Keeping this discussion in mind, we rewrite the upper bound on
\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]
as follows.

\displaystyle\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]

\displaystyle\leq\sum_{\lambda\operatorname{\vdash}r,~|\lambda|\leq t}\binom{r}{\lambda}\frac{\sum_{\begin{subarray}{c}j_{1},\ldots,j_{|\lambda|}\in[t]\\
\text{distinct}\end{subarray}}\prod_{i=1}^{|\lambda|}{\cal{B}}_{\mathcal{h}-1}(\lambda_{i})\cdot\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B_{j_{i}}}^{\lambda_{i}}]}{\prod_{j=1}^{r}\cnt(j,\lambda)}

\displaystyle\leq\sum_{\lambda\operatorname{\vdash}r,~|\lambda|\leq t}\binom{r}{\lambda}\cdot\frac{\prod_{i=1}^{|\lambda|}{\cal{B}}_{\mathcal{h}-1}(\lambda_{i})}{\prod_{j=1}^{r}\cnt(j,\lambda)}\sum_{j_{1},\ldots,j_{|\lambda|}\in[t]}\prod_{i=1}^{|\lambda|}\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B_{j_{i}}}^{\lambda_{i}}].

Note that we removed the requirement that all
j_{i}
are distinct in the last inequality (this is valid, since all terms are non-negative). Now we use Claim
2.10
and then the majorization inequality (see Lemma
4.2
) to upper bound each term in the inner sum.

\sum_{j_{1},\ldots,j_{|\lambda|}\in[t]}\prod_{i=1}^{|\lambda|}\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B_{j_{i}}}^{\lambda_{i}}]=\prod_{i=1}^{|\lambda|}\sum_{j\in[t]}\operatorname{\widetilde{\mathbb{E}}}_{B}\Bigl[f_{B_{j}}^{\lambda_{i}}\Bigr]=\prod_{i=1}^{|\lambda|}\operatorname{\widetilde{\mathbb{E}}}_{B}\Bigl[\sum_{j\in[t]}f_{B_{j}}^{\lambda_{i}}\Bigr]\leq\prod_{i=1}^{|\lambda|}\operatorname{\widetilde{\mathbb{E}}}_{B}[f_{B}^{\lambda_{i}}]\leq\operatorname{\widetilde{\mathbb{E}}}[f_{B}^{r}].

Using the recurrence relation for multidimensional Bell numbers from Lemma
2.2
, we conclude that

\mathbb{E}_{B}\left[\cost(P_{B})^{r}\right]\leq\sum_{\lambda\operatorname{\vdash}r}\frac{\binom{r}{\lambda}\prod_{i=1}^{|\lambda|}{\cal{B}}_{\mathcal{h}-1}(\lambda_{i})}{\prod_{j=1}^{r}\cnt(j,\lambda)}\operatorname{\widetilde{\mathbb{E}}}[f_{B}^{r}]={\cal{B}}_{\mathcal{h}}(r)\operatorname{\widetilde{\mathbb{E}}}[f_{B}^{r}].

∎

Theorem 5.4
.

Algorithm
1
gives an
(1+\varepsilon){\cal{A}}_{d}(p)\stackrel{{\scriptstyle\mathrm{\scriptscriptstyle def}}}{{=}}(1+\varepsilon){\cal{B}}_{d}(p)^{1/p}
approximation for the problem in series-parallel graphs of order
d
in time polynomial in
n^{O(p)}
and
1/\varepsilon
.

Proof.

We apply Lemma
5.3
with
a_{e}=c_{e}(i)
to every coordinate
i\in[\ell]
and add up the obtained upper bounds on
\mathbb{E}\left[\bigl(\sum_{e\in P}c_{e}(i)\bigr)^{p}\right]
. We get that

\mathbb{E}\left[\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{p}^{p}\right]\leq{\cal{B}}_{\mathcal{h}}(p)\operatorname{\widetilde{\mathbb{E}}}\Bigl[\sum_{i=1}^{\ell}\Bigl(\sum_{e}c_{e}(i)x_{e}\Bigr)^{p}\Bigr]\leq{\cal{B}}_{\mathcal{h}}(p)\cdot\mathsf{OPT}^{p}.

By Markov’s inequality,
\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{p}^{p}\leq(1+\varepsilon){\cal{B}}_{\mathcal{h}}(p)\cdot\mathsf{OPT}^{p}
with probability at least
\varepsilon/(1+\varepsilon)
. By running the algorithm
1/\varepsilon
times, we find a solution of cost at most
\Bigl\|\sum_{e\in P}c_{e}\Bigr\|_{p}\leq(1+\varepsilon)^{1/p}{\cal{B}}_{\mathcal{h}}(p)^{1/p}\cdot\mathsf{OPT}\leq(1+\varepsilon){\cal{A}}_{\mathcal{h}}(p)\cdot\mathsf{OPT}
with constant probability. (As is standard, we can run this procedure many times and make the failure probability exponentially small.)
∎

Algorithms for
\ell_{p}
-Shortest Path in Arbitrary Graphs

In this section, we describe an approximation algorithm for
\ell_{p}
-Shortest Path in arbitrary graphs.

We note that there is a block-box reduction from problem in arbitrary graphs to that in series-parallel graphs, which is implicitly used by Li, Xu, and Zhang
[
LXZ24
]
in their algorithm for
\ell_{\infty}
-Shortest Path (Robust
s
-
t
Path). This reduction outputs a series-parallel graph with
O(n^{\log n})
vertices, where
n
is the number of vertices in the original graph. By using this reduction, we immediately get an
O(p\log^{1-1/p}n)
-approximation algorithm for general graphs with running time
n^{O(p\log n)}
. We describe how to get an approximation algorithm for general graphs with an improved running time and slightly improved approximation factor; namely we describe how to get a
O(cp\log^{1-1/p}n)
-approximation in time
m^{O(ce^{1/c}\log n)}
for every
c\in(0,1/2)
.
We assume below that
\ell
is at most polynomial in
n
; thus, we may assume
r\leq{\lceil{\log_{2}\ell}\rceil}=O(\log n)
(since all norms
\|\cdot\|_{r}
with
r\geq\log_{2}\ell
are equivalent within a factor of 2).

Layered graphs and reduction from general graphs to layered graphs.

We say that a DAG
G=(V,E)
is an
s
-
t
layered graph with
\Delta
edge layers if

V
is the disjoint union of vertex layers
V_{0},V_{1},\dots,V_{\Delta}
,
E
is the disjoint union of layers
E_{1},\dots,E_{\Delta}
, and each edge in
E_{i}
goes from
V_{i-1}
to
V_{i}
.
Further, we require that
V_{0}=\{s\}
and
V_{\Delta}=\{t\}
.

We transform an arbitrary graph
G
with terminals
s
and
t
into a layered graph
\hat{G}=(V_{\hat{G}},E_{\hat{G}})
with
\Delta=n-1
edge layers. We create vertex layers
V_{0},V_{1},\dots,V_{\Delta}
:
V_{0}=\{s\}
,
V_{\Delta}=\{t\}
, each
V_{i}
is a disjoint copy of
V_{G}
. We connect
\hat{u}\in V_{i}
with
\hat{v}\in V_{i+1}
if there is an edge
(u,v)\in E_{G}
between the corresponding vertices in
G
. The vector cost of

8.1

In this section, we argue that the assumption that all edge costs are entry-wise non-negative is indeed necessary to obtain a good approximation result. We prove that the version of the
\ell_{p}
-Shortest Path problem in which weight vectors can have negative coordinates is as hard as the
\ell_{p}
closest vector problem in lattices.

We now recall the basic definitions required for this argument. For a more detailed overview of the background, we refer the reader to the book of Micciancio and Goldwasser
[
MG02
]
. A lattice is the set of all integer linear combinations of a collection
\mathcal{L}=\{\mathbf{v}_{1},\dots,\mathbf{v}_{d}\}
of linearly independent vectors in
\mathbb{R}^{n}
. The set
\mathcal{L}
is referred to as the
lattice basis
and is often represented as a matrix

B=\begin{pmatrix}|&&|\\
\mathbf{v}_{1}&\cdots&\mathbf{v}_{d}\\
|&&|\end{pmatrix}.

The closest vector problem is then defined as follows.

Definition 8.1

(
\ell_{p}
-Closest Vector Problem)
.

The
\ell_{p}
-closest vector problem (
\ell_{p}
-CVP) is defined as follows: given a lattice basis
B\in\mathbb{Z}^{n\times d}
and a target vector
\mathbf{t}\in\mathbb{Z}^{n}
, find a vector
\mathbf{x}\in\mathbb{Z}^{d}
minimizing
\left\|B\mathbf{x}-\mathbf{t}\right\|_{p}
.

This problem has a long history and several hardness results have been proved about it. We will use hardness results by Dinur, Kindler, and Safra
[
DKS03
]
(for
p<\infty
) and Dinur
[
Din02
]
(for
p=\infty

Theorem 8.2

(Paraphrasing
[
DKS03
]
and Dinur
[
Din02
]
)
.

For every

\ell_{p}
-CVP to within a factor of

Now we show that all hardness of approximation results for

There is a polynomial-time approximation-preserving reduction from the
