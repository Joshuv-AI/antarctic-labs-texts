A constraint-based approach to function interpolation, with application to performance estimation for weakly convex optimization.
Anne Rubbens, Julien M. Hendrickx

Abstract
We consider the problem of obtaining interpolation constraints for function classes, i.e., necessary and sufficient constraints that a set of points, function values and (sub)gradients must satisfy to ensure the existence of a global function of the class considered, consistent with this set. The derivation of such constraints is crucial, e.g., in the performance analysis of optimization methods, since obtaining a priori tight performance guarantees requires using a tight description of function classes of interest. We propose an approach that allows setting aside all analytic properties of the function class to work only at an algebraic level, and to obtain counterexamples when a condition characterizing a function class cannot serve as an interpolation constraint. As an illustration, we provide interpolation constraints for the class of weakly convex functions with bounded subgradients, and rely on these constraints to outperform state-of-the-art bounds on the performance of the subgradient method on this class.

Introduction

Consider the problem of obtaining exact discrete definitions of function classes
\mathcal{F}
, whose need arises in any situation where one manipulates or has access to a finite set

\mathcal{F}

That is,

defined everywhere, in the sense that
f(x_{i})=f_{i}
,
g_{i}\in\partial f(x_{i})

For instance, consider the problem of conducting a worst-case performance analysis of an optimization method. In this context, one derives bounds on the evolution of some performance measure, holding for any initial point satisfying some initial condition and for any element of a given function class
\mathcal{F}
, e.g.,
\mathcal{F}_{0,L}
the class of smooth convex functions, which can for example be defined as functions

\displaystyle\begin{cases}&f(x)\geq f(y)+\langle\nabla f(y),x-y\rangle\\
&\|\nabla f(x)-\nabla f(y)\|\leq L\|x-y\|\end{cases}\quad\forall x,y\in\mathbb{R}^{d}.

(1)

Obtaining bounds as tight as possible is essential to understand bottlenecks of the method analyzed as well as tune their parameters by optimizing the bound derived.

To obtain such bounds, one typically manipulates the quantities involved in the method, that is the iterates of the method, their function values and subgradients, as well as the optimum and its function value, by combining inequalities involving these quantities and translating the knowledge that (i) they are given by the method’s definition and (ii) they are evaluations of a smooth convex function,
see, e.g.,
[

This requires translating the global characterization of
\mathcal{F}

1

\mathcal{F}_{0,L}

\mathcal{F}
, i.e., conditions satisfied by any finite
\mathcal{F}
-interpolable dataset.

A natural way to obtain such a characterization is to discretize global characterizations as (
1

\mathcal{F}_{0,L}
, (

\displaystyle f(x)\geq f(y)+\langle\nabla f(y),x-y\rangle+\frac{1}{2L}\|\nabla f(x)-\nabla f(y)\|^{2}\ \forall x,y\in\mathbb{R}^{d}\text{ \cite[cite]{\@@bibref{Authors Phrase1YearPhrase2}{nesterov2018lectures}{\@@citephrase{(}}{\@@citephrase{)}}}},

(2)

their discretizations are not necessarily equivalent, see, e.g.,

\mathcal{F}

This is the case, e.g., for (

Any analysis relying on these weaker characterizations leads to a priori overconservative bounds, since these are valid for a larger set of admissible values than those actually corresponding to some

To obtain tight bounds, one must rely on the strongest constraints possible, denoted by
interpolation constraints
,
that is discretized definitions whose satisfaction by a dataset is not only necessary, but also sufficient to ensure its
\mathcal{F}
-interpolability.
For instance, the discretized version of (
2
) is an interpolation constraint for
\mathcal{F}_{0,L}
, see, e.g.
(
59

.
Hence, manipulating a set of iterates satisfying this constraint is strictly equivalent to manipulating a function
f\in\mathcal{F}_{0,L}
evaluated at the iterates.

Obtaining an exact bound on the performance of a method on given function class
\mathcal{F}
does not only require describing the set of iterates via interpolation constraints, but also optimally combining these constraints and the method’s definition.
While obtaining the optimal combination by hand is in general challenging, it can be computed automatically for a large number of methods, performance measures and function classes via the Performance Estimation Problem (PEP) framework
[
27
,
57

. This framework formulates the search of a worst-case function as an optimization problem over the set
S
of iterates and optimum, under the constraint that
S

\mathcal{F}
-interpolable, see Appendix

1.1
Contributions

Proposing interpolation constraints for a given function class, and proving their validity, are, to the best of our knowledge, open problems. In this work, we develop tools to address these challenges and illustrate their application on several examples:

•

Constraint-based approach.
Rather than guessing, from a specific function class, candidate interpolation constraints for this class, we suggest a reverse approach. We start from a class of constraints and identify those that (i) define meaningful function classes
\mathcal{F}
when imposed everywhere, and (ii) are interpolation constraints for
\mathcal{F}
(Section
2
).

•

Algebraic assessment of interpolability.
To assert interpolability of given constraints, we introduce the notion of
pointwise extensibility
, which captures whether a constraint allows consistent extension to any additional point. We prove this condition is equivalent to interpolability under reasonable regularity assumptions (Section
3
).

•

Systematic analysis of a class of constraints.
Starting from the class of constraints that can be written as a single inequality, linear in function values and scalar products of points and subgradients, we show that the only interpolation constraints of the class, that describe meaningful functions, are the ones describing smooth
weakly/strongly convex functions, as in
(
59
, Theorem 4)
, and the one describing quadratic functions
f=\frac{\mu}{2}\|x\|^{2}
(Section
6
)

•

Automated testing of a constraint’s interpolability.
Relying on pointwise extensibility, we develop a numerical heuristic to generate counterexamples to the interpolability of given constraints. We obtain such counterexamples on several classical characterizations of function classes (Section
4
).

•

Tight description of a class of weakly convex functions.
Taking a step back from the constraint-based approach, but as to further illustrate pointwise extensibility, we provide interpolation constraints for
weakly convex
functions, i.e., convex up to the addition of a quadratic term, with bounded subgradients. This allows improving on existing PEP-based bounds on this class
[
18
]
, that relied on non-tight constraints (Section
5
).

2
Constraint-based approach to interpolation

This paper considers function classes
\mathcal{F}
characterized via
pairwise
algebraic constraints
p
, that involve evaluations of a function
f
and its (sub)gradient, see, e.g., (
1
) and (
2
).

Formally, given any
\mathcal{X}\subseteq\mathbb{R}^{d}
, let

F:\mathcal{X}\rightrightarrows\mathbb{R}\times\mathbb{R}^{d}:x\rightrightarrows(f(x),g(x)),

denote a set-valued mapping, where
f(x)
is single-valued and
g(x)
, possibly multi-valued, is intended to represent a subgradient of
f
at
x
, but is an a priori unrelated quantity. We consider constraints

\displaystyle p:(\mathbb{R}^{d}\times\mathbb{R}\times\mathbb{R}^{d})^{2}\to\mathbb{R}^{\ell},\quad\ell\in\mathbb{N},

and say that
p
is satisfied at a pair
(x_{1},x_{2})\in\mathcal{X}
if
p((x_{1},F_{x_{1}}),(x_{2},F_{x_{2}}))\geq 0\quad\text{for all }F_{x_{i}}\in F(x_{i}),\ i=1,2,
where the inequality is to be taken elementwise for
\ell\geq 2
.

The proposed constraint-based approach stems from the observation that any pairwise constraint defines a function class over
\mathcal{X}\subseteq\mathbb{R}^{d}
, simply by requiring the constraint to hold at all pairs of points in
\mathcal{X}
.

Definition 1
.

Given a pairwise constraint
p
and
\mathcal{X}\subseteq\mathbb{R}^{d}
, a function class defined by
p
on
\mathcal{X}
consists of all mappings
F
satisfying
p
on
\mathcal{X}
.

\displaystyle\mathcal{F}_{p}(\mathcal{X}):=\big\{F:\mathcal{X}\rightrightarrows\mathbb{R}\times\mathbb{R}^{d}\ \big|\

\displaystyle p((x_{1},F_{x_{1}}),(x_{2},F_{x_{2}}))\geq 0,

\displaystyle\forall x_{1},x_{2}\in\mathcal{X},\ \forall F_{x_{i}}\in F(x_{i})\big\}.

Further, we say
F\in\mathcal{F}_{p}(\mathbb{R}^{d})
is
maximal
if there exists no proper extension of
F
in
\mathcal{F}_{p}(\mathbb{R}^{d})
. We denote by
\mathcal{F}^{m}_{p}(\mathbb{R}^{d})
the class of maximal functions in
\mathcal{F}_{p}(\mathbb{R}^{d})
. This class typically encompasses functions satisfying
p

for all subgradients
in their subdifferential, rather than possibly for a single one.

Definition 2
.

Let
p
a pairwise constraint. We let

\displaystyle\mathcal{F}^{m}_{p}(\mathbb{R}^{d}):=\{F:\mathbb{R}^{d}\rightrightarrows\mathbb{R}\times\mathbb{R}^{d}\big|\

\displaystyle F\in\mathcal{F}_{p}(\mathbb{R}^{d}),

(4)

\displaystyle\not\exists\bar{F}\in\mathcal{F}_{p}(\mathbb{R}^{d})\text{ s.t. }\text{Graph }(F)\subset\text{Graph }(\bar{F})\}.

Our goal, starting from classes of pairwise constraints, is to only keep those that (i) imply a subdifferential relationship between

and
g

Differentially consistent constraints

Notice that at this stage, given
F:\mathcal{X}\rightrightarrows\mathbb{R}\times\mathbb{R}^{d}:x\rightrightarrows(f(x),g(x))
, with
F\in\mathcal{F}_{p}(\mathcal{X})
,
f(x)
and
g(x)
are related only via the algebraic relation imposed by

. We are interested in
differentially consistent
constraints, i.e., constraints which, when satisfied everywhere, imply
g(x)\in\partial f(x)
.

Definition 3

(Differentially consistent constraint)
.

A pairwise constraint
p
is
differentially consistent
if, given
\{(x_{i},f_{i},g_{i}),(x_{j},f_{j},g_{j})\}\in(\mathbb{R}^{d}\times\mathbb{R}\times\mathbb{R}^{d})^{2}
, the condition

p((x_{i},f_{i},g_{i}),(x_{j},f_{j},g_{j}))\geq 0,

implies

f_{j}\geq f_{i}+\langle g_{i},x_{j}-x_{i}\rangle+\omega(\|x_{i}-x_{j}\|).

(5)

(Convex functions)

The pairwise constraint

\displaystyle p((x_{i},f_{i},g_{i}),(x_{j},f_{j},g_{j}))=f_{j}-f_{i}-\langle g_{i},x_{j}-x_{i}\rangle,

(6)

is differentially consistent since its satisfaction implies
f_{j}\geq f_{i}+\langle g_{i},x_{j}-x_{i}\rangle
, hence (

Example 2

The trivial pairwise constraint

on

, e.g., by

, which do not satisfy

Interpolation constraints

Trivially, for any constraint
p

\mathcal{X}_{1}\subseteq\mathcal{X}_{2}
, a mapping
F_{2}\in\mathcal{F}_{p}(\mathcal{X}_{2})
can always be restricted to a mapping
F_{1}\in\mathcal{F}_{p}(\mathcal{X}_{1})
. However, the converse does not hold in general. In particular, a mapping satisfying

Definition 4

(Interpolation constraint)
.

We say a pairwise constraint

is an

for

, if

\forall\text{ finite }\mathcal{X}\subset\mathbb{R}^{d},\ \forall F\in\mathcal{F}_{p}(\mathcal{X}),\quad\exists\bar{F}\in\mathcal{F}^{m}_{p}(\mathbb{R}^{d})\text{ such that }F(x)=\bar{F}(x)\ \forall x\in\mathcal{X}.

The approach to interpolation of Definition

differs from what is classically done in, e.g.,
[

]
. Instead of defining
p
from a function class
\mathcal{F}
, as a necessary and sufficient condition to impose on any finite set

to ensure its

-interpolability, we directly focus on

Nevertheless, these are for almost all practical purposes equivalent notions, see Appendix

.

Compact notation for a pairwise constraint

Let

3
Pointwise extensible constraints

Definition
4
allows for an algebraic approach to establish interpolability, based on idea of extending
a mapping satisfying a constraint
p
on a finite set to just one (arbitrary) point, in the spirit of what is done in, e.g.,
[
2
,
34
]
with respect to potentially infinite sets.

Definition 5

(Pointwise extensible constraint)
.

We say a pairwise constraint
p
is pointwise extensible if

\forall\text{ finite }\mathcal{X}\subset\mathbb{R}^{d},\forall z\in\mathbb{R}^{d},\ \forall F\in\mathcal{F}_{p}(\mathcal{X}),\ \exists\bar{F}\in\mathcal{F}_{p}(\mathcal{X}\ \cup\ z)\text{ s.t. }F(x)=\bar{F}(x)\ \forall x\in\mathcal{X}.

Example 3

(Convex functions)

Let
p
be defined as in (
6
). For some
N\in\mathbb{N}
, consider
S=\{(x_{i},f_{i},g_{i})\}_{i\in[N]}
, where

satisfies

. Given any

, let

\displaystyle i_{\star}=\underset{i\in[N]}{\text{argmax }}f_{i}+\langle g_{i},x-x_{i}\rangle,\quad f=f_{i_{\star}}+\langle g_{i_{\star}},x-x_{i_{\star}}\rangle\text{ and }g=g_{i_{\star}}.

By definition of

f\geq f_{i}+\langle f_{i},x-x_{i}\rangle\ \forall i\in[N].

In addition, since

\displaystyle f_{j}\geq f_{i_{\star}}+\langle g_{i_{\star}},x_{j}-x_{i_{\star}}\rangle=f+\langle g,x_{j}-x\rangle\ \forall j\in[N].

Hence, these

Under some regularity assumptions, we show equivalence between pointwise extensible and interpolation constraints. By definition, the first implication holds.

Proposition 1

Let
p
be a pairwise constraint. If
p
is an interpolation constraint for
\mathcal{F}^{m}_{p}(\mathbb{R}^{d})
, then
p
is pointwise extensible.

Proposition
1
allows deriving counterexamples to the interpolability of a constraint

, see Section
4

The converse holds under additional technical conditions. Indeed, pointwise extensibility allows iteratively extending any
F\in\mathcal{F}_{p}(\mathcal{X})
to the rationals, i.e., to
\bar{F}\in\mathcal{F}_{p}(\mathbb{Q}^{d})
. Then, one can extend
\bar{F}
to
\mathbb{R}^{d}
, taking its limit on
\mathbb{Q}^{d}
, provided (i) such a limit exists, and (ii)
p
is continuous, hence still satisfied at the limit. We formalize these requirements by introducing the notion of a regularly extensible constraint, before providing sufficient conditions ensuring regular extensibility of a constraint
p
.

Definition 6

(
Regularly extensible constraint
)
.

Let
p
be a pairwise constraint. We say
p
is

if

1.

p
is continuous.

2.

Given a finite set
\mathcal{X}\subset\mathbb{R}^{d}
, and

,

\exists\bar{F}\in\mathcal{F}_{p}(\mathbb{Q}^{d}\cup\mathcal{X}):\ F(x)=\bar{F}(x),\ x\in\mathcal{X},

(x_{k})_{k=1,2,\ldots}\subset\mathbb{Q}^{d}
, there exists a convergent subsequence in

Lemma 1

Let
p
be a continuous, differentially consistent, pointwise extensible, pairwise constraint. If any of the following conditions holds:

Remark 2
.

While we restrict ourselves here to function classes defined by pairwise constraints involving evaluations of a single function and its subgradient, all concepts presented in this section can be straightforwardly extended to broader settings. We now demonstrate how pointwise extensibility can be used to automatically compute counterexamples to the interpolability of given constraints, and to verify the interpolability of specific ones. We then illustrate the constraint-based approach introduced in Section

Remark 3

The bounds on the performance of optimization methods on the function classes presented in Table

6
Exhaustive analysis of a class of constraints

Motivated by the difficulty to obtain equivalent characterizations of given a function class, and by the observation that function classes considered as interesting in optimization do not always have a simple tight description, see Section
5

2
on a simple class of constraints. We consider constraints consisting of a single inequality, linear in function values and scalar product of points and subgradients,
and such that
p^{xx}=0
, i.e., any single data point satisfies
p
.
Hence, we analyze constraints

\displaystyle p^{ij}\geq 0\Leftrightarrow f_{i}

\displaystyle\geq f_{j}+B\|g_{i}\|^{2}+C\|g_{j}\|^{2}+D\langle g_{j},g_{i}\rangle+E\|x_{i}\|^{2}+F\|x_{j}\|^{2}

\displaystyle+G\langle x_{i},x_{j}\rangle+H\langle g_{i},x_{i}\rangle+I\langle g_{i},x_{j}\rangle+J\langle g_{j},x_{i}\rangle+K\langle g_{j},x_{j}\rangle,

(29)

where
D=-(B+C)
,
G=-(E+F)
and
K=-(H+I+J)
. Indeed, such constraints fit the PEP framework, and tightly describe several first-order function classes, for given parameters. For instance,
\forall-\infty<\mu<L<+\infty
,

\displaystyle p^{ij}\geq 0\Leftrightarrow f_{i}\geq f_{j}+\frac{\langle Lg_{j}-\mu g_{i},x_{i}-x_{j}\rangle}{L-\mu}+\frac{\|g_{i}-g_{j}\|^{2}}{2(L-\mu)}+\frac{\mu L\|x_{i}-x_{j}\|^{2}}{2(L-\mu)},

(30)

\mu
-strongly convex

-smooth functions
(

.

We show that the only differentially consistent interpolation constraints of the form (

), and
a constraint describing the class of quadratic functions

for some

,

Remark 8

The second function class is in itself trivial, since it can be exactly characterized by equalities

7
Conclusion

We considered the questions of proposing candidate interpolation constraints and of assessing the interpolability of these candidates, and proposed tools to gain insight into both questions. First, we proposed a constraint-centered approach to interpolation, starting from meaningful interpolation constraints to the class they define when imposed everywhere. This allows highlighting function classes based on the fact that they possess a simple tight description rather than on their analytical properties. First-order methods can then be tightly analyzed/designed for these function classes. Second, we introduced pointwise extensibility, which allows verifying the interpolability of a constraint algebraically.

Relying on these tools, we exhaustively analyzed a class of potential constraints and obtained interpolation constraints for a class of quadratic functions. Then, relying on pointwise extensibility, we provided interpolation constraints for weakly convex functions satisfying a continuity condition, and tightly numerically analyzed the performance of the subgradient method on this class. Finally, we provided a heuristic numerical approach to assess non-interpolability of constraints, and exploited it to show that several commonly used descriptions were, in fact, not interpolation constraints.

Regarding interpolation constraints, several questions remain open. For instance, it is not known how to combine interpolation constraints defining different properties to tightly define function classes combining those properties, as in the case of smooth convex functions. In general, there is no principled way to design interpolation constraints for a function class
\mathcal{F}
. Then, no interpolation constraint involving high-order quantities is presently available. Finally, it is not known what constraints to impose on a data set to ensure interpolation of the set by a function of interest defined on a given subset of
\mathbb{R}^{d}
strictly different from
\mathbb{R}^{d}
, since classical interpolation constraints are not valid in this case. In future research, we would like to extend our framework to answer some of these questions.

Appendix A
Instance of a PEP program

The PEP framework, introduced in
[
27
]
, computes tight worst-case bounds on the performance of a method on a function class
\mathcal{F}
by formulating the search of a worst-case function as an optimization problem over
f\in\mathcal{F}
. For instance, to analyze the gradient descent after
N
iterations on smooth convex functions, when the initial condition is chosen to be
\|x_{1}-x_{\star}\|^{2}\leq R^{2}
and the performance measure is chosen to be

, where
x_{\star}
is a minimizer of
f
, the idea is to solve

\displaystyle\underset{f\in\mathcal{F}_{0,L}}{\max\ }f(x_{N})-f(x_{\star})

(35)

\displaystyle\text{Definition of the method:}

\displaystyle\text{ s.t. }x_{i+1}=x_{i}-\alpha\nabla f(x_{i}),\quad i\in[N-1]

\displaystyle\text{Initial condition:}

\displaystyle\|x_{0}-x_{\star}\|^{2}\leq R^{2}

\displaystyle\text{Optimality:}

\displaystyle\nabla f(x_{\star})=0.

Without loss of generality,
x_{\star}
and
f(x_{\star})
can be set to
0
. This infinite-dimensional problem is made tractable by optimizing over the finite set
S=\{(x_{i},f_{i},g_{i})\}_{i\in[N]\cup_{\star}}
of iterates and optimum, under the constraint that
S
is
\mathcal{F}
-interpolable. In the same spirit as in traditional performance analysis, the abstract concept
f\in\mathcal{F}
is thus translated into a set of algebraic constraints imposed on
S
, and Problem (
35
) becomes

\displaystyle\underset{S=\{(x_{i},f_{i},g_{i})\}_{i\in[N]\cup_{\star}}}{\max\ }f_{N}-f_{\star}

(36)

\displaystyle\text{Definition of the method:}

\displaystyle\text{ s.t. }x_{i+1}=x_{i}-\alpha g_{i},\quad i\in[N-1]

\displaystyle S\text{ is }\mathcal{F}_{0,L}\text{-interpolable: }

\displaystyle f_{i}\geq f_{j}+\langle g_{j},x_{i}-x_{j}\rangle+\frac{1}{2L}\|g_{i}-g_{j}\|^{2},\ i,j\in[N]\cup_{\star}

\displaystyle\text{Initial condition:}

\displaystyle\|x_{1}-x_{\star}\|^{2}\leq R^{2}

\displaystyle\text{Optimality:}

\displaystyle g_{\star}=0.

Whenever interpolation constraints for
\mathcal{F}
are known and imposed, the resulting PEP-based bound is tight and the set
S
of iterates corresponds to an actual worst-case instance. In fact, the dual variables associated to each constraint are the coefficients associated to the optimal combination of these constraints, in general challenging to obtain by hand. Otherwise, when only imposing necessary conditions on
S
, Problem (
36
) is a relaxation of Problem (
35
), and the bound achieved could be conservative since
S
might not be consistent with some
f\in\mathcal{F}
. For instance,
letting
N=2
, solving Problem (
36
) and thus imposing the interpolation constraint (
2
) allows concluding
f(2)-f_{\star}\leq\frac{1}{6}
, while solving a relaxation of (
36
) by imposing (
1
) on
S
leads to a bound of
\frac{1}{4}
. This implies that the solution obtained in this setting belongs to the admission region allowed by (
1
) and not by (
2
). In addition, (
36
) can be turned into a semi-definite program whenever all quantities involved are linear in function values and scalar products of points and subgradients, see, e.g.,
[
59
]
for details.
