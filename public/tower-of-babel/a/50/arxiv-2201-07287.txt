Polar Coded Merkle Tree: Improved Detection of Data Availability Attacks in Blockchain Systems
Debarnab Mitra, Lev Tauz, and Lara Dolecek

Abstract
Light nodes in blockchain systems are known to be vulnerable to data availability (DA) attacks where they accept an invalid block with unavailable portions. Previous works have used LDPC and 2-D Reed Solomon (2D-RS) codes with Merkle Trees to mitigate DA attacks. While these codes have demonstrated improved performance across a variety of metrics such as DA detection probability, they are difficult to apply to blockchains with large blocks due to generally intractable code guarantees for large codelengths (LDPC), large decoding complexity (2D-RS), or large coding fraud proof sizes (2D-RS). We address these issues by proposing the novel Polar Coded Merkle Tree (PCMT) which is a Merkle Tree built from the encoding graphs of polar codes and a specialized polar code construction called Sampling-Efficient Freezing (SEF). We demonstrate that the PCMT with SEF polar codes performs well in detecting DA attacks for large block sizes.

The first paper to address DA attacks via coding used 2D Reed-Solomon (RS) codes to encode each block

To improve upon 2D-RS codes, authors in

proposed the

where each layer is encoded using a Low-Density Parity-Check (LDPC) code. LDPC codes reduce the IC proof size compared to 2D-RS codes due to their sparse parity check equations. LDPC codes also allow the use of a low complexity peeling decoder

Application of coding has to be carefully considered depending on the size of the transaction blocks in blockchains which can range from a few MBs (small block size), e.g., Bitcoin

In regard to the CMT, previous work in

(we refer to a CMT built using LDPC codes as an LCMT). Although polar codes have dense parity check matrices
[
34

, they have sparse encoding graphs, which result in a small IC proof size in the PCMT. We provide a specialized polar code construction called
Sampling-Efficient Freezing (SEF) Algorithm
that i) provides a low probability of failure to detect DA attacks; ii) allows flexibility in designing polar codes of any lengths.
We demonstrate that SEF Polar codes have an efficiently computable
guarantee on the probability of failure which simplifies system design at large block sizes. We then demonstrate that for large block sizes, a PCMT built using SEF Polar codes result in a lower probability of failure compared to LDPC codes designed by the PEG algorithm.

Set the data symbols of the base layer

form the data symbols
\text{{data}}[j-1]
from the coded symbols
\text{{CodeSym}}[j]

\text{{data}}[j-1]=\text{{formParent}}(\text{{CodeSym}}[j])

The

()

coded symbols of
\text{{CodeSym}}[j]

Each coded symbol

(
\tau

(

The CMT is decoded using a hash-aware decoder which decodes the tree from the root to the base layer. Each layer is decoded using a procedure

The IC proof is verified by first verifying that each symbol

(

(
{\tau}_{e}

12

A polar code can be decoded using a peeling decoder on the code FG. A stopping set is a set of VNs such that every CN connected to this set is connected to at least two VNs in the set. Similar to

III-A

DA attacks on PCMT

Consider layer
L_{j}
,
j\in[l]
, of the PCMT. For a given information index set
\mathcal{A}_{j}
, let
\Psi^{\mathcal{A}_{j}}
denote the set of all stopping sets in the FG
\mathcal{G}_{N_{j}}
that
do not have any VNs corresponding to
\text{{frozen}}[j]
.
The hash-aware peeling decoder fails to decode
L_{j}
if coded symbols corresponding to a stopping set in
\Psi^{\mathcal{A}_{j}}
are erased. Since all the coded symbols except the rightmost column of
\mathcal{G}_{N_{j}}
are dropped, the peeling decoder will fail if the adversary hides the leaf set of a stopping set in
\Psi^{\mathcal{A}_{j}}
.

To prevent a DA attack, light nodes randomly sample symbols from the PCMT base layer, i.e.,
\text{{CodeSym}}[l]
. Randomly sampling the base layer ensures that the non-dropped symbols of intermediate layer
L_{j}
,
j\in[l-1]
, i.e.,
\text{{CodeSym}}[j]
, are also randomly sampled via the Merkle proofs of the base layer samples similar to an LCMT in
[
9
]
.
For subsequent analysis, we assume (WLOG) that the adversary conducts a DA attack on the base layer of the PCMT.
To find the adversary strategy that leads to the largest probability of failure when the light nodes use random sampling, we use the following important property of stopping sets in polar FGs that was proved in
[
37
]
:

\min_{\psi\in\Psi^{\mathcal{A}_{l}}}|\text{{Leaf-Set}}(\psi)|=\min_{i\in\mathcal{A}_{l}}f^{N_{l}}_{i}.

(3)

Eqn. (
3
) implies that, when light nodes use random sampling, the best strategy for the adversary (to maximize the probability of failure) is to hide the smallest leaf set amongst all stopping trees with non frozen root. Thus,
\alpha_{\min}=\underset{i\in\mathcal{A}_{l}}{\min}f^{N_{l}}_{i}
.

IV
Sampling-Efficient Freezing Algorithm

For the best adversary strategy,
\alpha_{\min}=\min_{i\in\mathcal{A}_{l}}f^{N_{l}}_{i}
.
Based
on this result,
a naïve frozen set selection method would be to select the indices of
RN_{l}
VNs from the leftmost column of the FG
\mathcal{G}_{l}
with the smallest stopping tree leaf set sizes
f^{N_{l}}_{i}
. Note that for this naïve frozen set selection, the polar code becomes equivalent to a Reed-Muller (RM) Code
[
38
]
. We call the naïve frozen set selection as
Naïve-RM (NRM)
algorithm for which it
can be easily shown that
\alpha_{\min}^{NRM}=\min\left(\mathbf{T}_{N_{l}};(1-R)N_{l}\right)

(which is the
(1-R)N_{l}
-th smallest value of
\mathbf{T}_{N_{l}}

symbols again consists of
d-1
symbols and the Merkle proofs of the
d

L_{j}
,
j\in[l-1]
in a PCMT consists of
q_{j}=q(\lceil\log N_{j}\rceil+1)
hashes. Thus, for a failed parity check equation with
d
symbols, the size of the IC proof in a PCMT is

\displaystyle\frac{(d-1)b}{k}

\displaystyle+\sum_{j=1}^{l-1}dy(q_{j}-1)

\displaystyle=\frac{(d-1)b}{k}+\sum_{j=1}^{l-1}dy((q(\lceil\log N_{j}\rceil+1))-1)

\displaystyle=\frac{(d-1)b}{k}+dy(q-1)(l-1)+dyq\sum_{j=1}^{l-1}\lceil\log N_{j}\rceil.

For a PCMT, the maximum CN degree for a CN in the FG of the polar code is

\frac{(d_{p}-1)b}{k}+d_{p}y(q-1)(l-1)+d_{p}yq\sum_{j=1}^{l-1}\lceil\log N_{j}\rceil

Appendix D
Systematic encoding of Polar codes

Systematic encoding of an
(\widehat{N},\widehat{K})
polar codes can be performed using the method described in
[
36
]
. It operates on the FG
\mathcal{G}_{\widehat{N}}
of the code. Let
\widehat{\mathcal{A}}\subset[\widehat{N}]
and
\widehat{\mathcal{F}}=[\widehat{N}]\setminus\widehat{\mathcal{A}}
be the index sets corresponding to the data and frozen symbols of the
(\widehat{N},\widehat{K})
polar code, respectively, where
|\widehat{\mathcal{A}}|=\widehat{K}
. Also, let
\widehat{N}=2^{n}
. The systematic encoding is performed on the FG
\mathcal{G}_{\widehat{N}}
by i) placing the
\widehat{K}
data symbols at the VNs
\{v_{(n+1)i}|i\in\widehat{\mathcal{A}}\}
(in the rightmost column) and setting the VNs at
\{v_{1i}|i\in\widehat{\mathcal{F}}\}
(in leftmost column) to zero symbols; ii) determining the rest of the VNs using the check constraints of the FG
\mathcal{G}_{\widehat{N}}
in a two stage reverse and forward encoding on the FG
[
36
]
. The coded symbols are the VNs
v_{(n+1)i},i\in[\widehat{N}],
and are by design systematic.
Systematic encoding can also be performed using a peeling decoder as the encoder as described next.

In
[
35
]
, author proposed to perform systematic encoding of polar codes by using a successive cancellation decoder on the code FG as the encoder. Inspired by this idea, we show that systematic encoding of the polar codes can also be performed using a peeling decoder as the encoder. The encoder, which we call a peeling encoder for polar codes (PEPC), works as follows.
Consider the data and frozen index sets
\widehat{\mathcal{A}}\subset[\widehat{N}]
and
\widehat{\mathcal{F}}=[\widehat{N}]\setminus\widehat{\mathcal{A}}
of the polar code with FG
\mathcal{G}_{\widehat{N}}
. Place the data symbols at the VNs
\{v_{(n+1)i}|i\in\widehat{\mathcal{A}}\}
(in the rightmost column) and set the VNs at
\{v_{1i}|i\in\widehat{\mathcal{F}}\}
(in leftmost column) to zero symbols. Use a peeling decoder to find the remaining VNs of the FG. The coded symbols
c_{i}=v_{(n+1)i},i\in[\widehat{N}],
are by design systematic. We have the following lemma corresponding to a PEPC.

Lemma 3
.

Systematic encoding of polar codes using a PEPC always results in a valid codeword. In other words, the peeling decoder never encounters a decoding failure when used for encoding.

We prove Lemma
3
by proving the following important property of stopping sets in the FG of polar codes produced by the SEF algorithm.
Note that the property holds true for regular polar FG
\mathcal{G}_{\widehat{N}}
where
\widehat{N}
is a power of 2. Additionally, the property also holds true for the FG
\mathcal{G}_{N}
obtained by removing VNs from the last few rows of FG of the form
\mathcal{G}_{\widehat{N}}
, where
\widehat{N}
is a power of 2. Thus, let
n=\lceil\log N\rceil
. The proof provides insights on important properties of stopping sets in the FG of polar codes. To our best knowledge, we have not seen the following result before in literature and, hence, it may be of independent interest.

Lemma 4
.

Consider a polar FG
\mathcal{G}_{N}
produced by the SEF algorithm (this encompasses polar factor graphs
\mathcal{G}_{\widehat{N}}
, where
\widehat{N}
is a power of 2). Every stopping set of
\mathcal{G}_{N}
has a full row of VNs i.e., it has all VNs in the set
\{v_{ki}\;|\;k\in[\;\lceil\log N\rceil+1\;]\}
for some
i\in[N]
.

Proof.

Let
\psi
be a stopping set of
\mathcal{G}_{N}
. Let
\mathcal{G}^{\psi}_{N}
be the induced subgraph of
\mathcal{G}_{N}
corresponding to the set of VNs
\psi
. Observe that the FG
\mathcal{G}_{N}
has two types of edges (see Fig.
1
for an example): horizontal edges and slanted edges (which involves a connection between a degree 3 VN and a degree 3 CN). We consider two cases: i)
\mathcal{G}^{\psi}_{N}
does not have any slanted edges;
ii)
\mathcal{G}^{\psi}_{N}
has at least one slanted edge.

For case i), it is easy to see that the stopping set
\psi
must include a full row of VNs. For case ii), note that it implies
\mathcal{G}^{\psi}_{N}
has at least one slanted edge. This implies that
\psi
has at least one VN of degree 3. In this situation, define the set

\Delta_{\psi}=\{(i,k)\;|\;i\in[N],\;k\in[n],v_{ki}\in\psi,\text{degree of }v_{ki}=3\}
. Let
i_{\max}=\max(\{i|(i,k)\in\Delta_{\psi}\text{ for some }k,k\in[n]\})
.

\Delta_{\psi}
contains the indices of all the degree 3 VNs of
\psi
and
i_{\max}
denotes the largest row index such that
\psi
has a degree 3 VN from that row. Note that
\Delta_{\psi}
is non empty because we are considering case ii). Now, we claim that
\psi
has all the VNs in the row
i_{\max}
, i.e.,
\psi
contains all the VNs in
\{v_{ki_{\max}}\;|\;k\in[n+1]\}
. To see why this is true, let
\accentset{\rule{2.45836pt}{0.6pt}}{k}
,
\accentset{\rule{2.45836pt}{0.6pt}}{k}\in[n]
, be such that
(i_{\max},\accentset{\rule{2.45836pt}{0.6pt}}{k})\in\Delta_{\psi}
. This means that
v_{\accentset{\rule{2.45836pt}{0.6pt}}{k}i_{\max}}\in\psi
. Now by the definition of a stopping set, the CNs to the right and left of
v_{\accentset{\rule{2.45836pt}{0.6pt}}{k}i_{\max}}
must belong to the induced subgraph graph of the stopping set. In other words,
c_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}-1)i_{\max}}\in\mathcal{G}^{\psi}_{N}
and
c_{\accentset{\rule{2.45836pt}{0.6pt}}{k}i_{\max}}\in\mathcal{G}^{\psi}_{N}
(unless
v_{\accentset{\rule{2.45836pt}{0.6pt}}{k}i_{\max}}
is the rightmost or the left most VN in which case we will have only one CN neighbour). Now, to satisfy the stopping set property, for both these CNs, their corresponding VNs to their left and right in the same row
i_{\max}
must belong to the stopping set
\psi
(i.e.,
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}-1)i_{\max}}\in\psi
,
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}+1)i_{\max}}\in\psi
). If not, then to satisfy the stopping set property, the CN must be connected to a VN
v_{ki}\in\psi
by a slanted edge. Note that a slanted edge connects a CN to a degree 3 VN in lower row. In other words, a slanted edge connects a CN from row
i_{\max}
to a degree 3 VN in a row with index greater than
i_{\max}
. This condition violates the definition of
i_{\max}
. Thus,
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}-1)i_{\max}}\in\psi
and
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}+1)i_{\max}}\in\psi
.
Now, considering
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}-1)i_{\max}}
and
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}+1)i_{\max}}
as the starting VN (similar to
v_{\accentset{\rule{2.45836pt}{0.6pt}}{k}i_{\max}}
), we can apply the above logic to show that
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}-2)i_{\max}}\in\psi
and
v_{(\accentset{\rule{2.45836pt}{0.6pt}}{k}+2)i_{\max}}\in\psi
. Repeatedly applying the same argument, we can show that all the VNs in
\{v_{ki_{\max}}\;|\;k\in[n+1]\}
belong to
\psi
, where
n=\lceil\log N\rceil
.

∎

According to the above lemma, every stopping set has at least one full row of VNs, i.e., it has VNs from all columns along a single row. We use this property to prove Lemma
3
.

Proof of Lemma
3
:

Let
\mathcal{V}
be the set of all VNs in the polar FG
\mathcal{G}_{N}
. Also, let
\mathcal{\overline{V}}_{e}=\{v_{(n+1)i}\;|\;i\in\mathcal{A}\}\cup\{v_{1i}\;|\;i\in\mathcal{F}\}
and
\mathcal{V}_{e}=\mathcal{V}\setminus\mathcal{\overline{V}}_{e}
. VNs in
\mathcal{V}_{e}
are uninitialized or initially erased by the PEPC and are determined using a peeling decoder (for the purposes of encoding).
Thus, the PEPC can fail if
\mathcal{V}_{e}
contains a stopping set of
\mathcal{G}_{N}
. However, since
\mathcal{A}\cup\mathcal{F}=[N]
(i.e., they form a partition of all the row indices), for all
i\in[N]
either
v_{(n+1)i}\in\mathcal{\overline{V}}_{e}
or
v_{1i}\in\mathcal{\overline{V}}_{e}
. Thus, for all
i\in[N]
,
v_{(n+1)i}
and
v_{1i}
both cannot simultaneously belong to
\mathcal{V}_{e}
. Hence,
\mathcal{V}_{e}
cannot contain a full row of VNs. Using Lemma
4
, we conclude that
\mathcal{V}_{e}
cannot contain a stopping set. Thus, the PEPC will always be successful and will result in a valid codeword.
