Random Access Based on Maximum Average Distance Code for Massive MTC in Cellular IoT Networks
Carlos A. Astudillo, , Ekram Hossain, , and Nelson L. S. da Fonseca

Abstract
Code-expanded Random Access (CeRA) is a promising technique for supporting mMTC in cellular IoT networks. However, its potentiality is limited by code ambiguity, which results from the inference of a larger number of codewords than those actually transmitted. In this letter, we propose a RA ( RA ) scheme to alleviate this problem by allowing devices to select the preambles to be transmitted considering a q -ary code with MAD . Moreover, a CeRA decoding approach based on hypergraphs is proposed and an analytical model is derived. Numerical results show that the proposed scheme significantly increases the probability of successful channel access as well as resource utilization.

II
Maximum Average Distance Codes and their Application to Code-Expanded RA

This section introduces the OptCeRA scheme to tackle the
code ambiguity problem
. OptCeRA optimizes the code used to perform consecutive preamble transmissions.
For some fixed value of
\mathchar 29038
, when the number of available codewords is reduced, redundancy is introduced, imposing constraints to the transmitted messages (codewords) in a way that just a fraction of all possible received messages (all combinations of the received preambles at each subframe) are valid codewords.
By reducing the similarity between the codewords in the code, the number of inferred valid codewords can be reduced as well. This reduction can be formulated as the maximization of the average Hamming distance between the codewords in a code.

In contrast to the existing CeRA schemes, in which the codeword is formed by a sequence of preambles selected randomly from the
\mathchar 29025
allowed preambles, in the OptCeRA scheme, the codeword is first randomly selected from a code
\mathcal{\mathchar 28995}
with maximum average Hamming distance (a
MAD
code), considering all the
\mathchar 29041
available preambles, i.e.
\mathcal{\mathchar 28995}\mathchar 12818\mathcal{\mathchar 28993}_{\mathchar 29041}^{\mathchar 29038}
, where
\mathcal{\mathchar 28993}_{\mathchar 29041}
is a finite set of
\mathchar 29041
symbols (a
\mathchar 29041
-ary alphabet). Then, a preamble is transmitted at the
i
th subframe according to the
i
th coordinate of the chosen codeword.
Using the OptCeRA approach, the CeRA scheme in
[
3
]
becomes equivalent to randomly selecting a codeword from a code
\mathcal{\mathchar 28995}\mathchar 12349\mathcal{\mathchar 28993}_{\mathchar 29025}^{\mathchar 29038}
.

Since a
\mathchar 29041
-ary code of a given size and length with the
MAD

MAD
code problem, characterize these codes, and show their construction.
Moreover, we present a hypergraph representation of codes for CeRA which facilitates their storage, analysis, and processing. Finally, we introduce a simple method based on the proposed hypergraph representation to perform decoding in CeRA.

VI
Conclusion

This letter has addressed the
code ambiguity problem
in code-expanded
RA
for
mMTC
by allowing devices to select codewords from a novel code with maximum average distance.
The proposed scheme reduces the number of valid codewords that can be inferred, and greatly increases the
RA

The proposed maximum average distance code is likely to find other innovative applications.
