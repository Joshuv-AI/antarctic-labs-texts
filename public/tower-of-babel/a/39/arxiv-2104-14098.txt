A Normal Form Characterization for Efficient Boolean Skolem Function Synthesis
Preey Shah, Aman Bansal, S. Akshay and Supratik Chakraborty

Abstract
Boolean Skolem function synthesis concerns synthesizing outputs as Boolean functions of inputs such that a relational specification between inputs and outputs is satisfied. This problem, also known as Boolean functional synthesis, has several applications, including design of safe controllers for autonomous systems, certified QBF solving, cryptanalysis etc. Recently, complexity theoretic hardness results have been shown for the problem, although several algorithms proposed in the literature are known to work well in practice. This dichotomy between theoretical hardness and practical efficacy has motivated research on normal forms of specification representation that guarantee efficient synthesis, thus partially explaining the efficacy of some of these algorithms. In this paper we go one step further and ask if there exists a normal form representation of the specification that precisely characterizes “efficient” synthesis. We present a normal form called SAUNF that answers this question affirmatively. Specifically, a specification is polynomial time synthesizable iff it can be compiled to SAUNF in polynomial time. Additionally, a specification admits a polynomial-sized functional solution iff there exists a semantically equivalent polynomial-sized SAUNF representation. SAUNF is exponentially more succinct than well-established normal forms like BDDs and DNNFs, used in the context of AI problems, and strictly subsumes other more recently proposed forms like SynNNF. It enjoys compositional properties that are similar to those of DNNF. Thus, SAUNF provides the right trade-off in knowledge representation for Boolean functional synthesis.



I
Introduction

The history of Skolem functions can be traced all the way back to the 1920’s when Thoralf Skolem provided a simplified proof of the celebrated Löwenheim Skolem theorem in first order logic. A key step in the proof showed that any first order logic formula can be converted into Skolem normal form, that has no existential quantifiers, while preserving satisfiability. This process, called Skolemization, involves replacing existentially quantified variables by terms constructed out of new function symbols, called Skolem functions. Skolemization has been an immensely influential technique in logic, and is now used routinely in many applications, viz. automated theorem proving. While it suffices for some applications to merely know that desired Skolem functions exist, others require us to efficiently synthesize such Skolem functions.

Algorithmic synthesis of Skolem functions has been studied extensively in the Boolean setting. Given disjoint sequences of Boolean variables
\mathbf{{I}}=(i_{1},\ldots i_{n})
and
\mathbf{{X}}=(x_{1},\ldots x_{m})
, representing inputs and outputs respectively of a system,
and given a Boolean formula
\varphi(\mathbf{{X}},\mathbf{{I}})
specifying a desired relation between the system inputs and outputs, the
Boolean Skolem function synthesis
(
\mathsf{BFnS}
) problem asks us to synthesize a sequence of formulas
\mathbf{\Psi}(\mathbf{{I}})=(\psi_{1}(\mathbf{{I}}),\ldots,\psi_{m}(\mathbf{{I}}))
that can be substituted for
\mathbf{{X}}
to satisfy the specification, i.e.,
\forall\mathbf{{I}}\,\big(\varphi(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}}\big)\Leftrightarrow\exists\mathbf{{X}}\ \varphi(\mathbf{{X}},\mathbf{{I}})\big)
. The formulas in
\mathbf{\Psi}
indeed represent Boolean Skolem functions for
\mathbf{{X}}
in
\exists\mathbf{{X}}\varphi(\mathbf{{X}},\mathbf{{I}})

Further, and somewhat surprisingly, each tool seems to work well on a different set of benchmarks, often incomparable across tools.
What is common among the approaches, however, is that it is difficult to predict reliably the set of benchmarks, i.e., the class of formulas, on which a particular algorithm will be efficient (other than simple cases or heuristic guesses).
On a related note, a theoretical study undertaken in

This leads to a curious dichotomy of theoretical worst-case hardness vs practical (sometimes unreasonable) efficiency.
To resolve this dichotomy, researchers have searched for structure in the input specification that can result in provably efficient synthesis.
It turns out that the representation used for input specification and Skolem functions indeed has a bearing on the complexity of synthesis.
For example, if the specification is given as a

Significantly, it is not the case that every class of specifications that admit efficient Skolem function synthesis can be efficiently compiled to

III
Problem Statement

Earlier work
[
12
]
has established (conditional) time and space lower bounds for
\mathsf{BFnS}
; therefore it is unlikely that efficient algorithms exist for solving this problem in general. Yet, several recent works
[
12
,
7
,
5
,
23
,
13
,
24
]
have shown that
\mathsf{BFnS}
indeed admits practically efficient solutions for several non-trivial benchmarks. This motivates us to ask the following question, where we are interested in Boolean circuit representations of relational specifications and Skolem functions.

Does there exist a class, say
\mathcal{C}^{\star}
, of circuits such that the following hold?

P0:

For every circuit
G
, there is a semantically equivalent circuit
G^{\star}\in\mathcal{C}^{\star}
, i.e.
\llbracket\varphi_{G}\rrbracket=\llbracket\varphi_{G^{\star}}\rrbracket
. In other words,
\mathcal{C}^{\star}
is not semantically constraining.

P1:

\mathsf{BFnS}
is solvable in polynomial-time for the class
\mathcal{C}^{\star}
.

P2:

For every class
\mathcal{C}
of circuits,

P2a:

\mathsf{BFnS}
is solvable in polynomial-time for the class
\mathcal{C}
iff circuits in
\mathcal{C}
can be compiled to semantically equivalent ones in
\mathcal{C}^{\star}
in polynomial-time.

P2b:

Relational specifications represented by circuits in
\mathcal{C}
admit polynomial-sized Skolem function vectors iff circuits in
\mathcal{C}
admit polynomial-sized semantically equivalent circuits in
\mathcal{C}^{\star}
.

We answer the above question positively in this paper, effectively providing a circuit normal form characterization of efficient Boolean Skolem function synthesis. In light of our characterization, the hardness results of
[
12
]
translate to the hardness of computing
G^{\star}\in\mathcal{C}^{\star}
such that
\llbracket\varphi_{G^{\star}}\rrbracket=\llbracket\varphi_{G}\rrbracket
.

Definition 2
.

Let

We say that

\land

\land

.

Finally, we use the above definitions to introduce a new normal form for circuits that precisely characterizes efficient Boolean Skolem Function Synthesis. We show in subsequent sections that this normal form defines a class
\mathcal{C}^{\star}
of circuits that satisfies properties P0, P1 and P2 described in Section

.

Definition 3
.

Let
G
be a circuit with leaves labeled by
\mathsf{lits}(\mathbf{{I}})
and
\mathsf{lits}(\mathbf{{X}})
. Let
S=(S_{1},S_{2},..S_{k})
be a non-empty sequence of subsets of leaves of
G
. We say that
G
is in
Subset And-Unrealizable Normal Form (
\mathsf{SAUNF}
, for short)
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and
S
if the following hold:

1.

S_{j}\cap S_{l}=\emptyset
for all distinct
j,l\in\{1,\ldots k\}
.

2.

For each
j\in\{1,\ldots k\}
, all leaves in
S_{j}
are labeled by the same literal over
\mathbf{{X}}
.

3.

S_{1}
is
\land
-unrealizable in
G
.

4.

For each
j\in\{2\ldots k\}
,
S_{j}
is
\land
-unrealizable in
G\mid_{S_{1}:\top,S_{2}:\top\ldots S_{j-1}:\top}
.

5.

\llbracket\varphi_{G\mid_{S_{1}:\top,S_{2}:\top\ldots S_{k}:\top}}\rrbracket
is semantically independent of
\mathbf{{X}}
, i.e. its value doesn’t depend on the assignment of
\mathbf{{X}}
.

A few points about Definition
3
are worth noting.

•

A circuit
G
may be in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and
S
, but not in
\mathsf{SAUNF}
w.r.t. a different
\mathsf{set}({\mathbf{{X}}^{\prime}})
and/or
S^{\prime}
.

•

Conditions
3
,
4
and
5
are semantic in nature. Normal forms with such semantic conditions are not new. For example, the widely used disjoint decomposable negation normal form (
\mathsf{dDNNF}
) uses a semantic condition in its definition (see
[
16
]
).

•

S_{1}\cup\cdots S_{k}
may not include all leaves of
G
, nor even all leaves labeled by a literal over
\mathbf{{X}}
.

•

While the use of
\top
as labels for leaves in
S_{1},S_{2},\ldots
in conditions 4 and 5 may seem arbitrary for now, we will soon see the significance of this in the synthesis of Boolean Skolem functions.

.

Consider the circuit

and

. Let

be a sequence of (singleton) subsets of leaves. As seen above,

. It can similarly be verified that

,

and

.

V
Relation with other normal forms

Several normal forms for Boolean circuits studied in the literature, viz.
\mathsf{ROBDD}

[
14
]
,
\mathsf{FDD}

[
17
]
,
\mathsf{DNNF}

[
19
]
,
\mathsf{dDNNF}

[
16
]
,
\mathsf{wDNNF}

[
12
]
,
\mathsf{SynNNF}

[
15
]
, admit efficient Boolean Skolem function synthesis, and satisfy properties P0 and P1 in our problem statement (see Section
III
).
However,
none of these are known to satisfy property P2 in our problem statement, thereby failing to provide a characterization of efficient Boolean Skolem function synthesis
.
In contrast, as we show in this paper, the class of
\mathsf{SAUNF}
circuits satisfies all the properties mentioned in our problem statement.

Among the various alternative normal forms, we discuss
\mathsf{SynNNF}

[
15
]
first.
We say that a circuit normal form (or class of circuits)
\mathcal{N}_{1}
is exponentially more succinct than another normal form
\mathcal{N}_{2}
if
(i) for every circuit
G_{2}\in\mathcal{N}_{2}
, there exists a circuit
G_{1}\in\mathcal{N}_{1}
such that
|G_{1}|\leq|G_{2}|
and
\llbracket\varphi_{G_{1}}\rrbracket~=~\llbracket\varphi_{G_{2}}\rrbracket
, and (ii) there is a circuit
G_{1}\in\mathcal{N}_{1}
such that every circuit
G_{2}\in\mathcal{N}_{2}
with
\llbracket\varphi_{G_{1}}\rrbracket~=~\llbracket\varphi_{G_{2}}\rrbracket
has
|G_{2}|\in 2^{\mathcal{O}\big({|G_{1}|}\big)}
.
The notion of super-polynomial succinctness is similarly defined.
The authors of
[
15
]
showed a conditional succinctness result for
\mathsf{SynNNF}
, namely
\mathsf{SynNNF}
is super-polynomially more succinct than
\mathsf{DNNF}

[
19
]
and
\mathsf{dDNNF}

[
16
]
, unless some long-standing complexity theoretic conjectures are falsified.
We show the following stronger result for
\mathsf{SAUNF}
.

Lemma 1
.

\mathsf{SAUNF}
is unconditionally exponentially more succinct than
\mathsf{DNNF}
and
\mathsf{dDNNF}
.

Proof.

We use a result from
[
25
]
to prove the lemma. In Proposition 11 of
[
25
]
, a family of Boolean functions
\{JS_{r}\mid r\geq 2\}
is defined. The formula
JS_{r}
, defined on
\mathcal{O}\big({r^{2}}\big)
variables, asserts that for every triple
(v_{j},v_{k},v_{l})
of variables in a carefully constructed set
A_{r}
of triples, at least one of
v_{j},v_{k}
or
v_{l}
must be
\mathsf{false}
. It is shown in
[
25
]
that
|A_{r}|\in\mathcal{O}\big({r^{2}}\big)
. Therefore, a
\mathsf{CNF}
formula representing
JS_{r}
has
\mathcal{O}\big({r^{2}}\big)
clauses, with each clause having three negated variables as literals. Since no non-negated variables appear as literals in the formula, a circuit representation of the
\mathsf{CNF}
formula cannot have any literal-consistent subset of leaves that is
\land
-realizable. This implies that
JS_{r}
can be represented in
\mathsf{SAUNF}
in size
\mathcal{O}\big({r^{2}}\big)
. It is also shown in
[
25
]
that any
\mathsf{DNNF}
(and hence also
\mathsf{dDNNF}
) representation of
JS_{r}
requires size
2^{\Omega\big(r^{2}\big)}
. Therefore,
\mathsf{SAUNF}
is unconditionally exponentially more succinct compared to
\mathsf{DNNF}
and
\mathsf{dDNNF}
.
∎

Next, we show that
\mathsf{SynNNF}
is, in fact, a special case of
\mathsf{SAUNF}
. Towards this end, we recall the definition of
\mathsf{SynNNF}
from
[
15
]
, re-cast in our terminology.

Definition 4
.

A circuit
G
with leaves labeled by
\mathsf{lits}(\mathbf{{I}})
and
\mathsf{lits}(\mathbf{{X}})
is in
\mathsf{SynNNF}
w.r.t.
\mathbf{{X}}
iff the following hold:

•

x_{1}
is
\land
-unrealizable in
G
.

•

For
2\leq i\leq|\mathbf{{X}}|
,
x_{i}
is
\land
-unrealizable in
G\mid_{x_{1}=\top,\neg{x_{1}}=\top,\ldots x_{i-1}=\top,\neg x_{i-1}=\top}
.

The following lemma shows that
\mathsf{SAUNF}
strictly subsumes
\mathsf{SynNNF}
.

Lemma 2
.

Every circuit
G
that is in
\mathsf{SynNNF}
w.r.t.
\mathbf{{X}}
is also a
\mathsf{SAUNF}
circuit
w.r.t
\mathsf{set}({\mathbf{{X}}})
and a sequence
S
of
2\cdot|\mathbf{{X}}|

\land
-unrealizable subsets of leaves. However, there exist
\mathsf{SAUNF}
circuits that are not in
\mathsf{SynNNF}
.

Proof.

Suppose a circuit
G
is in
\mathsf{SynNNF}
w.r.t.
\mathbf{{X}}
, and let
|\mathbf{{X}}|=r
. We define a sequence of
2r
literal-consistent subsets of leaves of
G
as follows. For each
j\in\{1,\ldots r\}
, we define
S_{2j-1}
to be the set of
x_{j}
-leaves of
G
, and
S_{2j}
to be the set
\neg x_{j}
-leaves of
G
. It can now be seen from Definition
4
and Definition
3
that
G
is in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and the sequence
S=(S_{1},\ldots S_{2n})
of subsets of literal-consistent leaves. This proves the first part of the lemma.

To show the second part, we must demonstrate a circuit that is in
\mathsf{SAUNF}
but not in
\mathsf{SynNNF}
for any permutation of the sequence of system outputs
\mathbf{{X}}
. We claim that the circuit
G
in Figure
1
, already shown to be in
\mathsf{SAUNF}
, suffices for this purpose.
This is because Definition
4
entails that for
G
to be in
\mathsf{SynNNF}
, at least one literal over
\mathbf{{X}}
must be
\land
-unrealizable in
G
. However, none of
x_{1},\neg x_{1},x_{2},\neg x_{2}
are
\land
-unrealizable in the circuit
G
in Figure
1
. Specifically,
\llbracket\varphi_{G\mid_{x_{1}=w,\neg x_{1}=w^{\prime}}}\rrbracket_{\sigma}=\llbracket w\wedge w^{\prime}\rrbracket
when
\sigma(i)=\sigma(x_{2})=\bot
, and
\llbracket\varphi_{G\mid_{x_{2}=w,\neg x_{2}=w^{\prime}}}\rrbracket_{\sigma^{\prime}}=\llbracket w\wedge w^{\prime}\rrbracket
when
\sigma^{\prime}(i)=\sigma^{\prime}(x_{1})=\top
. Therefore, the circuit in Figure
1
is not in
\mathsf{SynNNF}
w.r.t. any
permutation of
\mathbf{{X}}
.
∎

It has been shown in
[
15
]
that every
\mathsf{DNNF}
,
\mathsf{dDNNF}
and
\mathsf{wDNNF}
circuit is also in
\mathsf{SynNNF}
, and
\mathsf{SynNNF}
is super-polynomially more succinct than
\mathsf{wDNNF}
unless
{\mathsf{P}}={\mathsf{NP}}
. Furthermore, every
\mathsf{ROBDD}
and
\mathsf{FDD}
can be converted to a
\mathsf{DNNF}
(hence
\mathsf{SynNNF}
) circuit with at most linear blowup in size, although
\mathsf{SynNNF}
can be exponentially more succinct than
\mathsf{ROBDD}
or
\mathsf{FDD}

[
19
,
15
]
. By virtue of Lemma
2
, we now have the following result.

Corollary 1
.

All subsumption and (conditional) succinctness results for
\mathsf{SynNNF}
circuits hold for
\mathsf{SAUNF}
circuits as well.

Since every Boolean specification can be represented as a
\mathsf{SynNNF}
circuit
[
15
]
, it also follows from Lemma
2
that property P0 in our problem statement (see Section
III
) holds for the class of
\mathsf{SAUNF}
circuits.

VI
Efficient synthesis of Skolem functions from
\mathsf{SAUNF}
specifications

We now show how a Skolem function vector can be efficiently computed if the relational specification is given as a
\mathsf{SAUNF}
circuit. Informally, the process involves transforming a given
\mathsf{SAUNF}
circuit
G
with leaves labeled by
\mathsf{lits}(\mathbf{{I}})
and
\mathsf{lits}(\mathbf{{X}})
to a semantically different but related circuit
H
with leaves labeled by
\mathsf{lits}(\mathbf{{I}})
,
\mathsf{lits}(\mathbf{{X}})
and
\mathsf{lits}(\mathbf{{X}}^{\prime})
, where
\mathbf{{X}}^{\prime}
is a sequence of fresh system outputs, also called
auxiliary outputs
. The transformation is done in a way such that a Skolem function vector for
(\mathbf{{X}},\mathbf{{X}}^{\prime})
in
H
can be found efficiently, and a projection of this Skolem function vector on the first
|\mathbf{{X}}|
components directly yields a Skolem function vector for
\mathbf{{X}}
in
G
. To formalize this notion, we begin with a few definitions.

Definition 5
.

[Equisynthesizable Under Projection] Let
G
be a circuit representing a relational specification over system inputs
\mathbf{{I}}
and systems outputs
\mathbf{{X}}
. Let
H
be another circuit representing a relational specification over
\mathbf{{I}}
and
(\mathbf{{X}},\mathbf{{X}}^{\prime})
, where
\mathbf{{X}}^{\prime}
is a fresh sequence of system outputs or auxiliary outputs. We say that
G
is equisynthesizable to
H
under projection, denoted
G\leftrightsquigarrow H
, iff the following hold

•

\forall\mathbf{{I}}\forall\mathbf{{X}}\,\big(\varphi_{G}(\mathbf{{X}},\mathbf{{I}})~\Rightarrow~\exists\mathbf{{X}}^{\prime}\,\varphi_{H}(\mathbf{{X}},\mathbf{{X}}^{\prime},\mathbf{{I}})\big)

•

\forall\mathbf{{I}}\forall\mathbf{{X}}\forall\mathbf{{X}}^{\prime}\big(\varphi_{H}(\mathbf{{X}},\mathbf{{X}}^{\prime},\mathbf{{I}})~\Rightarrow~\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)

It follows from Definition
5
that
\leftrightsquigarrow
defines a transitive relation on circuits representing relational specifications. The following lemma is an easy consequence of Definition
5
.

Lemma 3
.

If
G\leftrightsquigarrow H
holds and
\big(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{\Psi}^{\prime}(\mathbf{{I}})\big)

is a Skolem function vector for
(\mathbf{{X}},\mathbf{{X}}^{\prime})
in
\varphi_{H}(\mathbf{{X}},\mathbf{{X}}^{\prime},\mathbf{{I}})
, then
\mathbf{\Psi}(\mathbf{{I}})
is a Skolem
function vector for
\mathbf{{X}}
in
\varphi_{G}(\mathbf{{X}},\mathbf{{I}})
.

Proof.

Since
\forall\mathbf{{I}}\,\big(\varphi_{G}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}})\Rightarrow\exists\mathbf{{X}}\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)
holds trivially, we only show below
that
\forall\mathbf{{I}}\,\big(\exists\mathbf{{X}}\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}})\big)
.

From Definition
5
and from the definition of Skolem functions, we have

\forall\mathbf{{I}}\,\big(\exists\mathbf{{X}}\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\Rightarrow

\exists\mathbf{{X}}\exists\mathbf{{X}}^{\prime}\varphi_{H}(\mathbf{{X}},\mathbf{{X}}^{\prime},\mathbf{{I}})\Rightarrow

\varphi_{H}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{\Psi}^{\prime}(\mathbf{{I}}),\mathbf{{I}})\Rightarrow

\varphi_{G}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}})
.
∎

VI-A

Role of auxiliary outputs

We now investigate how auxiliary outputs can be introduced in a principled manner, so that they help in generating Skolem functions. We start with a circuit
G
with leaves labeled by
\mathsf{lits}(\mathbf{{I}})
and
\mathsf{lits}(\mathbf{{X}})
. Let
G_{1}
and
G_{2}
be two sub-circuits of
G
such that
G_{1}
is not a sub-circuit of
G_{2}
and vice versa. For a fresh auxiliary variable
p\not\in\mathsf{set}({\mathbf{{X}}})\cup\mathsf{set}({\mathbf{{I}}})
and for
j\in\{1,2\}
, define a circuit transformation
\tau_{j}^{p}
that replaces the sub-circuit
G_{j}
in
G
with the circuit representing
\varphi_{G_{j}}\wedge p
. The definition of the circuit transformation
\tau_{j}^{\neg p}
is similar.

Lemma 4
.

If
\varphi_{G_{1}}\wedge\varphi_{G_{2}}
is unsatisfiable, then
G\leftrightsquigarrow\tau_{1}^{p}(\tau_{2}^{\neg{p}}(G))
.

Proof.

Let
H
denote the circuit
\tau_{1}^{p}(\tau_{2}^{\neg{p}}(G))
, and let
H_{1}
and
H_{2}
denote the newly introduced sub-circuits representing
p\wedge\varphi_{G_{1}}
and
\neg p\wedge\varphi_{G_{2}}
respectively in
H
. We show below that the conditions for
G\leftrightsquigarrow H
(see Definition
5
) are satisfied.

Let
\sigma:\mathsf{set}({\mathbf{{X}}})\cup\mathsf{set}({\mathbf{{I}}})\rightarrow\{\bot,\top\}
be an assignment for which
\llbracket\varphi_{G}\rrbracket
evaluates to
\top
. We have four cases to analyze depending on what
\llbracket\varphi_{{G_{1}}}\rrbracket
and
\llbracket\varphi_{{G_{2}}}\rrbracket
evaluate to under
\sigma
.

•

\llbracket\varphi_{{G_{1}}}\rrbracket=\bot=\llbracket\varphi_{{G_{2}}}\rrbracket
: Then for any assignment to
p
,
\llbracket\varphi_{{H_{1}}}\rrbracket
and
\llbracket\varphi_{{H_{2}}}\rrbracket
also evaluate to
\bot
, and hence
\llbracket\varphi_{{H}}\rrbracket
evaluates to the same value, viz.
\top
, as
\llbracket\varphi_{{G}}\rrbracket
.

•

If
\llbracket\varphi_{{G_{1}}}\rrbracket=\top,\llbracket\varphi_{{G_{2}}}\rrbracket=\bot
, then with
p
assigned
\top
,
\llbracket\varphi_{{H_{1}}}\rrbracket=\top
and
\llbracket\varphi_{{H_{2}}}\rrbracket=\bot
, and hence
\llbracket\varphi_{{H}}\rrbracket
evaluates to the same value, viz.
\top
, as
\llbracket\varphi_{{G}}\rrbracket
.

•

By a similar argument, if
\llbracket\varphi_{{G_{1}}}\rrbracket=\bot,\llbracket\varphi_{{G_{2}}}\rrbracket=\top
, assigning
p
to
\bot

causes
\llbracket\varphi_{{H}}\rrbracket
to evaluate to
\top
.

•

The case of
\llbracket\varphi_{{G_{1}}}\rrbracket=\llbracket\varphi_{{G_{2}}}\rrbracket=\top
doesn’t arise since
\varphi_{G_{1}}\wedge\varphi_{G_{2}}
is unsatisfiable.

This shows that
\forall\mathbf{{I}}\forall\mathbf{{X}}\,\big(\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\exists p\,\varphi_{H}(\mathbf{{X}},p,\mathbf{{I}})\big)
.

Consider any assignment
\sigma^{\prime}:\mathsf{set}({\mathbf{{X}}})\cup\{p\}\cup\mathsf{set}({\mathbf{{I}}})\rightarrow\{\bot,\top\}
that renders
\llbracket\varphi_{{H}}\rrbracket=\top
.
Let
\sigma:\mathsf{set}({\mathbf{{X}}})\cup\mathsf{set}({\mathbf{{I}}})\rightarrow\{\bot,\top\}
be the projection of
\sigma^{\prime}
on
\mathsf{set}({\mathbf{{X}}})\cup\mathsf{set}({\mathbf{{I}}})
. Note that
\sigma^{\prime}
necessarily assigns one of
p
or
\neg p
to
\bot
, while still rendering
\llbracket\varphi_{{H}}\rrbracket=\top
. Therefore, since all internal gates in
H
(i.e.
\land
and
\lor
gates) are monotone,
\sigma
must render
\llbracket\varphi_{{H\mid_{p=\top,\neg p=\top}}}\rrbracket=\top
as well. However,
\llbracket\varphi_{{H\mid_{p=\top,\neg p=\top}}}\rrbracket=\llbracket\varphi_{{G}}\rrbracket
by definition. Hence,
\sigma
satisfies
\llbracket\varphi_{{G}}\rrbracket(\mathbf{{X}},\mathbf{{I}})
. This shows that
\forall\mathbf{{I}}\forall\mathbf{{X}}\forall p\,\big(\varphi_{H}(\mathbf{{X}},p,\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)
.
∎

The argument in the above proof can be easily generalized to prove the following.

Lemma 5
.

Let
\mathcal{G}_{1}=\{G_{1,1},\ldots G_{1,s}\}
and
\mathcal{G}_{2}=\{G_{2,1},\ldots G_{2,t}\}
be two sets of
sub-circuits of
G
such that (a) there are no distinct
G_{k,i}
and

Theorem 3

Let

in

We first show that

. This involves showing two implications.

•

\varphi_{H}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{{X}},\mathbf{{I}}):

\varphi_{G^{\prime}}(\mathbf{{I}})\Leftrightarrow\varphi_{G}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}})

\Rightarrow\forall\mathbf{{X}}\,(\varphi_{F}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{{X}},\mathbf{{I}}))

\varphi_{G}(\mathbf{\Psi}(\mathbf{{I}}),\mathbf{{I}})\Rightarrow\forall\mathbf{{X}}\,\big(\varphi_{F}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)

\varphi_{H}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\big(\varphi_{F}(\mathbf{{X}},\mathbf{{I}})\lor\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)

\varphi_{H}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\big(\varphi_{G^{\prime}}(\mathbf{{I}})\land\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\big)
. Hence
\varphi_{H}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{G}(\mathbf{{X}},\mathbf{{I}})

\varphi_{G}(\mathbf{{X}},\mathbf{{I}})\Rightarrow\varphi_{H}(\mathbf{{X}},\mathbf{{I}})

VII
Operations on
\mathsf{SAUNF}

In this section, we discuss the application of basic operations like conjunction, disjunction and existential quantification of variables on formulas represented by
\mathsf{SAUNF}
circuits, and also examine the complexity of checking if a given circuit is in
\mathsf{SAUNF}
. Throughout the section, we assume that all specifications (circuits) are over system inputs
\mathsf{set}({\mathbf{{I}}})
and system outputs
\mathsf{set}({\mathbf{{X}}})
unless otherwise specified. To reduce notational clutter, given circuits

and

Lemma 6

Suppose

\mathsf{SAUNF}

and a sequence

\mathsf{SAUNF}

\mathsf{set}({\mathbf{{X}}})
and
(S^{G},S^{H})

Proof.

The proof follows from the claim that

is a sequence of subsets of leaves of

that satisfies the conditions of Definition
3
. To see why this is so, note that by Definition
2
, when considering a subset, say

-labeled leaves in

-labeled leaves of

-unrealizable in

is
\land
-unrealizable in

are satisfied by the circuit

. To see why condition 5 is also satisfied, observe that since

(resp.

\mathsf{SAUNF}

\mathsf{set}({\mathbf{{X}}})
and

(resp.
S^{H}

represents the disjunction of two formulas, each of which is semantically independent of

Significantly, Lemma

and

Similarly, combining two
\mathsf{SynNNF}

than in
\mathsf{ROBDD}

Next, we observe that existential quantification of

Follows from Theorem

Next, we move to the more difficult case of conjunction.

Suppose

\mathsf{set}({\mathbf{{X}}})

Proof.

If there is no literal

\land_{i=1}^{n}(x_{i}^{\prime}\Leftrightarrow\neg{x_{i}})

Proof.

It is easy to see that for the sequence

are satisfied. Moreover
\varphi_{G^{+}\mid_{S_{1}:\top,S_{2}:\top,\ldots S_{2n}:\top}}\Leftrightarrow\top

It is easy to see that
\varphi_{G^{-}}\land\varphi_{G^{+}}
is equisatisfiable to
\varphi_{G}
. Now, consider an arbitrary instance of the Boolean satisfiability (SAT) problem, i.e., given a Boolean circuit
G
over
\mathbf{{X}}=(x_{1},\ldots x_{m})

\varphi_{G}
is satisfiable. We interpret
\varphi_{G}
as a relational specification over system outputs
\mathbf{{X}}
, with the system inputs
\mathbf{{I}}
being absent.

By definition,
|G^{-}|
and
|G^{+}|
are in
\mathcal{O}\big({|G|}\big)

\mathsf{set}({\mathbf{{X}}})\cup\mathsf{set}({\mathbf{{X}}^{\prime}})
and an appropriate sequence of subsets of leaves. Suppose there exists a polynomial-time algorithm

that takes two
\mathsf{SAUNF}
circuits as inputs and produces a
\mathsf{SAUNF}

circuit semantically equivalent to the conjunction of the formulas represented by the

to obtain a circuit
\widehat{G}
that is semantically equivalent to
\llbracket\varphi_{G^{-}}\wedge\varphi_{G^{+}}\rrbracket
. Clearly,
|\widehat{G}|

|G^{-}|
and

, and therefore polynomial in
|G|
.
Since every
\mathsf{SAUNF}

), we can compute a Skolem function for every output of

. In other words, we can determine if

is equisatisfiable to
\varphi_{G}
, this effectively solves the Boolean satisfiability problem in polynomial time. Therefore, algorithm

cannot run in polynomial time unless
\mathsf{P}=\mathsf{NP}
.

Suppose for every two
\mathsf{SAUNF}
circuits, there exists a polynomial sized
\mathsf{SAUNF}
circuit that is semantically equivalent to the conjunction of the formulas represented by the two circuits. Let
\widetilde{G}
be the circuit obtained in this manner for

By Theorem

, Skolem functions synthesized from

must have size polynomial in

\mathsf{NP}\subseteq\mathsf{P}/\mathsf{Poly}
. By Karp-Lipton Theorem, however, we know that this implies that the polynomial hierarchy collapses to the second level, i.e.
\Pi_{2}^{P}=\Sigma_{2}^{P}
.
∎

Finally, we ask how difficult it is to check if a given circuit

is in
\mathsf{SAUNF}
.

Theorem 5
.

1.

Given
G
and a sequence
S
of literal-consistent disjoint subsets of leaves, checking if
G
is in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and
S
is
\mathsf{co}\mathsf{NP}
-complete.

2.

Given
G
, checking if
G
is in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and some (unspecified) sequence of subsets of leaves is
\mathsf{co}\mathsf{NP}
-hard and in
\Sigma_{2}^{P}
.

Proof.

First, we show that identifying whether a given circuit is in
\mathsf{SAUNF}
for a given sequence of subsets of leaves is in coNP. This is equivalent to asking whether the complement problem, i.e. if the given circuit is
not
in
\mathsf{SAUNF}
for the given sequence of subsets of leaves, is in
\mathsf{NP}
. We will define a non-deterministic polynomial-time Turing machine
M
that solves this complement problem. The machine
M
first checks whether the input circuit (say
G
) is in NNF. This can be done by checking if each internal node of
G
is labeled either
\land
or
\lor
, and if all negations (if any) are on the labels of leaves. Clearly, this check can be done in time polynomial in the size of
G
. If the circuit is found to be not in NNF, the machine
M
accepts, since
G
cannot be in
\mathsf{SAUNF}
in this case. Otherwise (i.e. if
G
is in NNF), the machine
M
non-deterministically chooses a subset
S_{i}
of literal-consistent leaves in the given sequence
S
and executes the following operations.

Suppose the literal labeling leaves in the subset
S_{i}
is
\ell_{i}
. The machine
M
does the following: (a) it constructs
G^{\dagger}=G\mid_{S_{1}:\top\ldots S_{i-1}:\top}
, (b) sets all leaves of
G^{\dagger}
that are not in
S_{i}
but are labeled
\ell_{i}
to
\bot
, (c) replaces all remaining labels
\ell
(resp.
\neg\ell
) on leaves by
w
(resp.
w^{\prime}
), (d) guesses an assignment
\sigma
to all variables other than
w
and
w^{\prime}
labeling leaves in the resulting circuit, and (e) checks if the resulting circuit represents the Boolean function
w\land w^{\prime}
for the assignment
\sigma
. Note that after step (d), the resulting circuit represents a function of only
w
and
w^{\prime}
. Hence the check in step (e) can be performed by setting
(w,w^{\prime})
to each of
(\top,\top),(\top,\bot),(\bot,\top)
and
(\bot,\bot)
and checking if the resulting circuit evaluates to
\top
,
\bot
,
\bot
and
\bot
respectively. Clearly, all the steps above can be done in time polynomial in
|G|
. If after step (e), the resulting circuit is found to represent
w\land w^{\prime}
, then machine
M
accepts. In this case,
G
is not in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and the given sequence
S
of subsets of leaves. Conversely, if the circuit is not in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and the given sequence
S
, then there is a subset
S_{i}
of leaves in
S
that is
\land
-realizable in
G
for the assignment described above. Hence the problem of identifying whether a circuit is
not
in
\mathsf{SAUNF}
for a given sequence of subsets of leaves is in
\mathsf{NP}
. Thus, the problem of identifying whether
G
is in
\mathsf{SAUNF}
for a given sequence of subsets of leaves is in
\mathsf{co}\mathsf{NP}
.

Next, we show that the problem is co-NP hard. We reduce the problem of checking if a propositional formula represented by a
\mathsf{CNF}
circuit
G
is unsatisfiable to identifying whether an appropriately constructed circuit is in
\mathsf{SAUNF}
for a specific sequence of subsets of literal-consistent leaves. For this, we consider the specification
G\land x\land\neg{x}
, where
x
is the sole output of the specification, and the inputs are the variables labeling leaves of
G
. Since there is only one output variable, there are only two (equivalent) orderings of subsets of leaves labeled by output literals. It is easy to see that
x
(equivalently,
\neg x
) is
\land
-realizable if and only if
G
is satisfiable. Hence, identifying whether a problem is in
\mathsf{SAUNF}
for a given sequence of subsets of leaves is coNP-hard.

To prove the second part of the theorem, we show that checking whether a given
G
is in
\mathsf{SAUNF}
w.r.t. some (unspecified) sequence of subsets of output literal-consistent leaves can be solved by a non-deterministic polynomial-time Turing machine

with access to an
\mathsf{NP}
oracle, i.e. the problem is in
{\mathsf{NP}}^{\mathsf{NP}}
. Given a specification
G
with system inputs
\mathbf{{I}}
and system outputs
{\mathbf{{X}}}
the machine
M
does the following:

(i)

It guesses a sequence
S
of disjoint subsets of literal-consistent leaves.

(ii)

It then reduces the problem of deciding whether
G
is not in
\mathsf{SAUNF}
w.r.t
\mathsf{set}({\mathbf{{X}}})
and the sequence
S
to checking the satisfiability of an appropriately constructed propositional formula
\varphi
. This reduction is similar to what we discussed above in the proof of part (1).

(iii)

Finally, it feeds
\varphi
to the
\mathsf{NP}
oracle and accepts if and only if the
\mathsf{NP}
oracle rejects.

Therefore,
M
accepts if and only if there is a sequence
S
of subsets of output literal-consistent leaves for which
G
is in
\mathsf{SAUNF}
w.r.t.
\mathsf{set}({\mathbf{{X}}})
and
S
. Hence, we have proved that our problem is contained in
\mathsf{NP}^{\mathsf{NP}}
, or equivalently in
\Sigma_{2}^{P}
. The proof that the problem is
\mathsf{co}\mathsf{NP}
-hard uses arguments similar to the earlier
\mathsf{co}\mathsf{NP}
hardness proof.
∎

Some interesting applications

In Section
I
, we described the
n
-bit
factorization problem
– a problem of immense interest in cryptanalysis.
We now show some interesting partial results using
\mathsf{SAUNF}
circuits. We start with a relational specification
R
over inputs
\mathbf{{I}}
and outputs
(\mathbf{{X}},\mathbf{{Y}})
defined by
(\mathbf{{X}}\times_{[n]}\mathbf{{Y}}=\mathbf{{I}})
where
\times_{[n]}
denotes
n
-bit unsigned integer multiplication. This specification evaluates to
\mathsf{true}
iff the given product relation holds, where
\mathbf{{X}},\mathbf{{Y}}
are
n
-bit output vectors and
\mathbf{{I}}
is a
2n
bit input vector. For
1\leq l\leq j\leq 2n
, we define a parametrized specification
R[l,j]
over
\mathbf{{X}}
,
\mathbf{{Y}}
and
\mathbf{{I}}
that evaluates to
\mathsf{true}
if and only if the bits from position
l
to
j
of
\mathbf{{X}}\times_{[n]}\mathbf{{Y}}
match the corresponding bits of
\mathbf{{I}}
.

Let
\mathbf{1}
denote an
n
-bit representation of the integer
1
. If
R[1,2n]\wedge(\mathbf{{X}}\neq{\bf 1})\wedge(\mathbf{{Y}}\neq{\bf 1})
can be represented as a polynomial (in
n
) sized
\mathsf{SAUNF}
circuit, our results show that Skolem functions of size polynomial in
n
can be obtained for
n
-bit factorization with non-trivial (i.e.
\neq 1
) factors. This would have serious ramifications for cryptanalysis. While we are not close to achieving such a result, our initial studies show some interesting results in trying to represent
R[l,j]
in
\mathsf{SAUNF}
. Note that it is already known from
[
17
]
that representing
R[n,n]
requires exponentially large
\mathsf{ROBDD}
s, and sub-exponential representations using
\mathsf{DNNF}
,
\mathsf{dDNNF}
,
\mathsf{wDNNF}
or
\mathsf{SynNNF}
are not known. With
\mathsf{SAUNF}
circuits however, we obtain a significant improvement.

Theorem 6
.

For\ l\leq j\leq 2n,j-l<n,R[l,j]
is representable by a polynomial (in

) sized

Proof.

By Theorem

, a polynomial-sized

Therefore, we focus on obtaining a polynomial-sized Skolem function vector for

We use the notation
\mathbf{{X}}_{l}
to denote the

\mathbf{{X}}_{l,j}
to denote the bit-slice of
\mathbf{{X}}
from

to

Using similar notations for
\mathbf{{Y}}
and
\mathbf{{I}}
, we consider two cases:

•

(resp

as system inputs and

Theorem 7
.

\mathbf{{X}}=\mathbf{{I}}/\mathbf{{Y}}

For notational convenience, we use

to denote both sequences of Boolean variables, and also the unsigned integers represented by the corresponding bit-vectors. We use

We give below a polynomial-sized Skolem function vector for division, which can be used to obtain a
\mathsf{SAUNF}

Suppose we have inputs
\mathbf{{I}}
and
\mathbf{{Y}}

\mathbf{{X}}^{1},\mathbf{{X}}^{2}
such that

(\mathbf{{X}}^{1}-\mathbf{{X}}^{2})\times\mathbf{{Y}}\equiv~0\ mod\ 2^{n}

\mathbf{{Y}}
is odd and therefore co-prime to

; hence
(\mathbf{{X}}^{1}-\mathbf{{X}}^{2})\equiv~0\ mod\ 2^{n}
. Since,
\mathbf{{X}}^{1},\mathbf{{X}}^{2}<2^{n}

\mathbf{{X}}^{1}=\mathbf{{X}}^{2}
. Therefore, the generated

from the Skolem function vector is correct if there exists a solution that matches the least significant
n
bits of
\mathbf{{I}}
. Using the notation defined above, denote
\mathbf{{X}}_{l}
to be the
l^{th}
least significant bit of
\mathbf{{X}}

\mathbf{{X}}_{l,j}
to denote the bit vector from
\mathbf{{X}}_{l}

\mathbf{{X}}_{j}
(both included). Now, since the inputs

\mathbf{{Y}}

Now note that

Note that while we have used a specific Skolem function vector above, once the

X
Conclusion

In this paper, we presented a normal form for Boolean relational specifications that characterizes efficient Skolem function synthesis. This is a significantly stronger characterization than those used in earlier works.
\mathsf{SAUNF}
is exponentially more succinct than
\mathsf{DNNF}
,
\mathsf{dDNNF}
while enjoying similar composability properties. It also strictly subsumes the recently proposed
\mathsf{SynNNF}
. As future work, we plan to improve the compilation algorithm and apply it to challenging benchmarks. It would also be interesting to see if similar characterizations or normal forms exist and are efficiently computable for Skolem functions for first order logic
[
26
]
, i.e., beyond the propositional case that we treated in this work.
