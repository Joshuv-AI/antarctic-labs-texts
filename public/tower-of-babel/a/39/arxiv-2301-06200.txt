Efficiently Computing Sparse Fourier Transforms of q q -ary Functions
Yigit Efe Erginbas ∗ , Justin Singh Kang ∗ , Amirali Aghazadeh, Kannan Ramchandran

Abstract
Fourier transformations of pseudo-Boolean functions are popular tools for analyzing functions of binary sequences. Real-world functions often have structures that manifest in a sparse Fourier transform, and previous works have shown that under the assumption of sparsity the transform can be computed efficiently. But what if we want to compute the Fourier transform of functions defined over a q q -ary alphabet? These types of functions arise naturally in many areas including biology. A typical workaround is to encode the q q -ary sequence in binary, however, this approach is computationally inefficient and fundamentally incompatible with the existing sparse Fourier transform techniques. Herein, we develop a sparse Fourier transform algorithm specifically for q q -ary functions of length n n sequences, dubbed q q -SFT, which provably computes an S S -sparse transform with vanishing error as q n → ∞ q^{n}\rightarrow\infty in O ⁡ ( S ​ n ) O(Sn) function evaluations and O ⁡ ( S ​ n 2 ​ log ⁡ q ) O(Sn^{2}\log q) computations, where S = q n ​ δ S=q^{n\delta} for some δ < 1 \delta<1 . Under certain assumptions, we show that for fixed q q , a robust version of q q -SFT has a sample complexity of O ⁡ ( S ​ n 2 ) O(Sn^{2}) and a computational complexity of O ⁡ ( S ​ n 3 ) O(Sn^{3}) with the same asymptotic guarantees. We present numerical simulations on synthetic and real-world RNA data, demonstrating the scalability of q q -SFT to massively high dimensional q q -ary functions.

Our approach to design a solution specific to

The potential wide range of applications for efficient

In

In

16

t
th order.
A combinatorial approach to computing sparse Fourier transforms can be found in
[
17
]
.

There are other works that consider sparse Fourier transforms in other settings. Of note,
[
18
,
19
]
both offer practical approaches for computing the sparse DFT of a signal. Furthermore, since the Fourier transform is a linear operation, computing the sparse Fourier transform may also be viewed as a linear inverse problem, and the existing approaches to

[

]
and

[

are also relevant. In particular, LASSO
[

]

We also note that decoding cyclic Reed-Solomon codes

Problem Statement

This work addresses the problem of computing the
S

\textrm{Oracle}:\mathbf{m}\longrightarrow f[\mathbf{m}]+v,\;\;v\sim\mathcal{CN}(0,\sigma^{2}),

(3)

Sample Complexity
denotes the number of oracle queries. The following assumptions are used to establish our theoretical guarantees.

Assumption 1
.

Let

1.

Each element in the support set

\mathbb{Z}_{q}^{n}

2.

The sparsity
S=|\mathcal{S}|=O(N^{\delta})

Assumption 2
.

1.

Each coefficient

2.

The signal-to-noise ratio (SNR) is defined as

\mathrm{SNR}=\frac{\|f\|^{2}}{N\sigma^{2}}=\frac{\|F\|^{2}}{\sigma^{2}}=\frac{S\rho^{2}}{\sigma^{2}}

III-A

Subsampling and Aliasing

We construct
C
subsampling groups, each characterized by a subsampling matrix
\boldsymbol{\mathbf{M}}_{c}\in\mathbb{Z}_{q}^{n\times b}
defining a linear space and a set of
P
offsets
\boldsymbol{\mathbf{d}}_{c,p}\in\mathbb{Z}_{q}^{n}
for
p\in[P]
for a total of
PB
oracle queries with
B:=q^{b}
. For each
c,p
we compute:

U_{c,p}[\boldsymbol{\mathbf{j}}]=\frac{1}{B}\sum_{\boldsymbol{\ell}\in\mathbb{Z}_{q}^{b}}f[\boldsymbol{\mathbf{M}}_{c}\boldsymbol{\ell}+\boldsymbol{\mathbf{d}}_{c,p}]\omega^{-\langle\boldsymbol{\mathbf{j}},\boldsymbol{\ell}\rangle},

(5)

for all
\boldsymbol{\mathbf{j}}\in\mathbb{Z}_{q}^{b}
.
In Appendix
-B
, we show that

U_{c,p}[\boldsymbol{\mathbf{j}}]=\sum_{\boldsymbol{\mathbf{k}}\;:\;\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}}F[\boldsymbol{\mathbf{k}}]\omega^{\langle\boldsymbol{\mathbf{d}}_{c,p},\boldsymbol{\mathbf{k}}\rangle},

(6)

and thus the coefficients
U_{c,p}[\boldsymbol{\mathbf{j}}]
are aliased versions of the coefficients
F[\boldsymbol{\mathbf{k}}]
.
It can be observed that the aliasing pattern is invariant with respect to the offsets
\boldsymbol{\mathbf{d}}_{c,p}
used in subsampling. Therefore, we can group the observations according to their aliasing pattern to write
\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]=[\dots,U_{c,p}[\boldsymbol{\mathbf{j}}],\dots]^{\textrm{T}}

by stacking the
\boldsymbol{\mathbf{j}}
th coefficient associated with all the offsets. Then the aliasing pattern for the coefficients can be written as

\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]=\sum_{\boldsymbol{\mathbf{k}}\;:\;\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}}F[\boldsymbol{\mathbf{k}}]\omega^{\boldsymbol{\mathbf{D}}_{c}\boldsymbol{\mathbf{k}}},

(7)

where
\omega^{(\cdot)}
is the element-wise exponentiation operator.

III-B

Bin Detection

Each observation vector
\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]
in (
7
) is a linear combination of the unknown coefficients. The goal of bin detection is to identify which
\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]
correspond to singleton bins, and for what value
\boldsymbol{\mathbf{k}}
that singleton corresponds to. To do so, define

1.

\mathrm{Type}\left({\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]}\right)=\mathcal{H}_{Z}
denotes a
zero-ton
, for which there does not exist
F[\boldsymbol{\mathbf{k}}]\neq 0
such that
\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}
.

2.

\mathrm{Type}\left({\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]}\right)=\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}])
denotes a
singleton
with only one
\boldsymbol{\mathbf{k}}
with
F[\boldsymbol{\mathbf{k}}]\neq 0
such that
\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}
.

3.

\mathrm{Type}\left({\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]}\right)=\mathcal{H}_{M}
denotes a
multi-ton
for which there exists more than one
F[\boldsymbol{\mathbf{k}}]\neq 0
such that
\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}
.

We use the following rule to compute the bin type:

\mathrm{Type}\left({\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]}\right)=\begin{cases}\mathcal{H}_{Z},&\hskip-2.0pt\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]=\boldsymbol{\mathbf{0}}\\
\mathcal{H}_{M},&\hskip-2.0pt\exists p\in[P]:\left\lvert{\frac{U_{c,p}[\boldsymbol{\mathbf{j}}]}{U_{c,1}[\boldsymbol{\mathbf{j}}]}}\right\rvert\neq 1\\
\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},X[\boldsymbol{\mathbf{k}}]),&\hskip-2.0pt\text{else.}\end{cases}

(8)

When
\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]
is a singleton, we must determine the values
(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}])
.
Note that each singleton bin satisfies
U_{c,p}[\boldsymbol{\mathbf{j}}]=F[\boldsymbol{\mathbf{k}}]\omega^{\langle\boldsymbol{\mathbf{d}}_{c,p},\boldsymbol{\mathbf{k}}\rangle}
and hence we need to get rid of
F[\boldsymbol{\mathbf{k}}]
to identify
\boldsymbol{\mathbf{k}}
. To achieve this, in addition to the offset matrix
\boldsymbol{\mathbf{D}}_{c}
, we choose a fixed delay
\boldsymbol{\mathbf{d}}_{c,0}=\boldsymbol{\mathbf{0}}
such that
U_{c,0}[\boldsymbol{\mathbf{j}}]=F[\boldsymbol{\mathbf{k}}]
. Using these observations, we can write the following set of linear equations in
\boldsymbol{\mathbf{k}}
:

\begin{bmatrix}\text{arg}_{q}[U_{c,1}[\boldsymbol{\mathbf{j}}]/U_{c,0}[\boldsymbol{\mathbf{j}}]]\\
\vdots\\
\text{arg}_{q}[U_{c,P}[\boldsymbol{\mathbf{j}}]/U_{c,0}[\boldsymbol{\mathbf{j}}]]\\
\end{bmatrix}=\boldsymbol{\mathbf{D}}_{c}\boldsymbol{\mathbf{k}}.

(9)

where
\text{arg}_{q}:\mathbb{C}\to\mathbb{Z}_{q}
is the
q
-quantization of the argument of a complex number defined as

\text{arg}_{q}(z):=\left\lfloor\frac{q}{2\pi}\text{arg}(ze^{j\pi/q})\right\rfloor.

(10)

If we choose
\boldsymbol{\mathbf{D}}_{c}=\boldsymbol{\mathbf{I}}_{n}
, then
\boldsymbol{\mathbf{k}}
can be obtained directly from (
9
) and the value of the coefficient can be obtained as
F[\boldsymbol{\mathbf{k}}]=U_{c,0}[\boldsymbol{\mathbf{j}}]
. If we have additional information about
\mathbf{k}
, we can further reduce the number of rows in
\boldsymbol{\mathbf{D}}_{c}
required to recover
\boldsymbol{\mathbf{k}}
. In particular, if
f
has degree no greater than
t
, i.e.,
\left\lVert{\boldsymbol{\mathbf{k}}}\right\rVert_{0}>t\implies F[\boldsymbol{\mathbf{k}}]=0
, we can prove the following result.

Proposition 1
.

For any prime
q
and
\boldsymbol{\mathbf{k}}\in\mathbb{Z}_{q}^{n}
such that
\left\lVert{\boldsymbol{\mathbf{k}}}\right\rVert_{0}\leq t
there exists a
\boldsymbol{\mathbf{D}}_{c}\in\mathbb{Z}_{q}^{P\times n}
with
P=2t\left\lceil\log_{q}(n)\right\rceil
such that
\boldsymbol{\mathbf{k}}
can be exactly recovered from
\boldsymbol{\mathbf{D}}_{c}\boldsymbol{\mathbf{k}}

As a final note, we point out that Proposition

Peeling Decoder

Once we have determined the bin detection procedure, the final step is the use of a peeling decoder. Algorithm
1
describes the procedure in detail. It is analogous to decoding a code over a bipartite graph, where the variable nodes are the non-zero
F[\boldsymbol{\mathbf{k}}]
and the check nodes are
U_{c}[\boldsymbol{\mathbf{j}}]
, respectively. There is an edge between
\boldsymbol{\mathbf{U}}_{c}[\boldsymbol{\mathbf{j}}]
and
F[\boldsymbol{\mathbf{k}}]
only if
\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}
. After sub-sampling, the singletons are identified, and their values are subtracted from the
\boldsymbol{\mathbf{U}}_{c}
values that they are connected to. This can be thought of as “peeling" an edge of the bipartite graph. With the careful choice of parameters, we can prove the following performance guarantee.

The key to robustness is changing the bin detection scheme of Section

. Denoting
\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}=\omega^{\boldsymbol{\mathbf{D}}\boldsymbol{\mathbf{k}}}
,
let
\boldsymbol{\mathbf{S}}=[\dotsc,\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}},\dotsc]

\boldsymbol{\mathbf{D}}

\boldsymbol{\mathbf{U}}

\boldsymbol{\mathbf{U}}=\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\alpha}}+\boldsymbol{\mathbf{W}}

IV-A

Near-linear Time Robust Bin Detection

The near-linear (in
N

1.

Zero-ton verification:
We first rule out zero-tons. We declare
\mathrm{Type}\left({\boldsymbol{\mathbf{U}}}\right)=\mathcal{H}_{Z}
if

\frac{1}{P}\|\boldsymbol{\mathbf{U}}\|^{2}\leq(1+\gamma)\nu^{2}.

2.

Single-ton search:
The next step is to estimate

assuming that bin

is a singleton. We compute the Maximum Likelihood Estimate (MLE) of
\boldsymbol{\mathbf{k}}
, which involves a search over the

N/B=q^{n-b}

that satisfy
\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}

For each location

\widehat{\alpha}[\boldsymbol{\mathbf{k}}]=\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\textrm{T}}\boldsymbol{\mathbf{U}}/P

\widehat{\boldsymbol{\mathbf{k}}}=\argmin_{\boldsymbol{\mathbf{k}}\;:\;\boldsymbol{\mathbf{M}}_{c}^{\textrm{T}}\boldsymbol{\mathbf{k}}=\boldsymbol{\mathbf{j}}}\|\boldsymbol{\mathbf{U}}-\widehat{\alpha}[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}\|^{2}.

(11)

Given that

This manuscript presents a fast and sample efficient algorithm to computing

\mathrm{Pr}(\mathcal{E})\leq O(1/S)
, the probability of failure of peeling decoder can be written as

\displaystyle\mathbb{P}_{F}

\displaystyle=\mathrm{Pr}\left(\widehat{F}\neq F|\mathcal{E}^{\mathrm{c}}\right)\mathrm{Pr}(\mathcal{E}^{\mathrm{c}})+\mathrm{Pr}\left(\widehat{F}\neq F|\mathcal{E}\right)\mathrm{Pr}(\mathcal{E})

\displaystyle\leq\mathrm{Pr}\left(\widehat{F}\neq F|\mathcal{E}^{\mathrm{c}}\right)+\mathrm{Pr}(\mathcal{E})

\displaystyle=O(1/S)

where the first term in the last inequality is obtained from Theorem
1
for the peeling decoder with an oracle such that the event
\mathcal{E}^{\mathrm{c}}
holds.

Then, we define
\mathcal{E}_{b}
as the the error event where a bin
\boldsymbol{\mathbf{j}}
is decoded wrongly and then, using a union bound over different bins and different iterations, the probability of the algorithm making a mistake in bin identification satisfies

\mathrm{Pr}(\mathcal{E})\leq\text{(\# of iterations)}\times\text{(\# of bins)}\times\mathrm{Pr}(\mathcal{E}_{b})

The number of bins is
\eta S
and the number of iterations is at most
CS
(at least one edge is peeled off at each iteration in the worst case). Hence,
\mathrm{Pr}(\mathcal{E})\leq\eta CS^{2}\mathrm{Pr}(\mathcal{E}_{b})
. In order to satisfy
\mathrm{Pr}(\mathcal{E})\leq O(1/S)
, we need to show that
\mathrm{Pr}(\mathcal{E}_{b})\leq O(1/S^{3})
.

In the following, we prove that
\mathrm{Pr}(\mathcal{E}_{b})\leq O(1/S^{3})
holds using the observation model. In the following analysis, we consider separate cases where the bin in consideration is fixed as a zero-ton, singleton or multi-ton.

Proposition 3
.

The error probability
\mathrm{Pr}(\mathcal{E}_{b})
for an arbitrary bin can be upper bounded as
\mathrm{Pr}(\mathcal{E}_{b})\leq O(1/S^{3})
.

Proof.

The error probability
\mathrm{Pr}(\mathcal{E}_{b})
for an arbitrary bin can be upper bounded as

\displaystyle\mathrm{Pr}(\mathcal{E}_{b})\leq

\displaystyle\sum_{\mathcal{F}\in\{\mathcal{H}_{Z},\mathcal{H}_{M}\}}\mathrm{Pr}(\mathcal{F}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle+

\displaystyle\sum_{\mathcal{F}\in\{\mathcal{H}_{Z},\mathcal{H}_{M}\}}\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{F})

\displaystyle+

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

where the events refer to:

1.

\{\mathcal{F}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}])\}
: missed verification in which the singleton verification fails when the ground truth is in fact a singleton.

2.

\{\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{F}\}
: false verification in which the singleton verification is passed when the ground truth is not a singleton.

3.

\{\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}])\}
: crossed verification in which a singleton with a wrong index-value pair passes the singleton verification when the ground truth is another singleton pair.

Since all the error probabilities decay exponentially with respect to
P_{1}
, it is clear that if
P_{1}
is chosen as
P_{1}=O(n)=O(\log N)
, the probability can be bounded as
\mathrm{Pr}(\mathcal{E}_{b})\leq O(1/N^{3})
. Then, the result follows by noting
S\leq N
.

Note that the number of samples required is
O(PB)=O(PS)
. For near-linear time bin detection, the total number of computations is dominated by the singleton search which requires
O(SNn)=O(Snq^{n})
. On the other hand, for sublinear time bin detection, the total number of computations is dominated by the subsampling, which requires
O(PB\log B)=O(PS\log S)=O(PS\log N)
because
S=O(N^{\delta})
. As a result, this gives a total complexity of
O(PSn)=O(Sn^{3})
.
∎

Proposition 4

(False Verification Rate)
.

For
0<\gamma<\frac{\eta}{2}\mathrm{SNR}
, the false verification rate for each bin hypothesis satisfies:

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{Z})

\displaystyle\leq e^{-\frac{P_{1}}{2}(\sqrt{1+2\gamma}-1)^{2}},

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{M})

\displaystyle\leq e^{-\frac{P_{1}\gamma^{2}}{2(1+4\gamma)}}+4N^{2}e^{-\epsilon\left(1-\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)^{2}P_{1}},

where
P_{1}
is the number of the random offsets in the near-linear time and sublinear time robust bin detection algorithms.

Proof.

The probability of detecting a zero-ton as a singleton can be upper bounded by the probability of a zero-ton failing the zero-ton verification. Thus,

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{Z})

\displaystyle\leq\mathrm{Pr}\left(\frac{1}{P_{1}}\|\boldsymbol{\mathbf{W}}\|^{2}\geq(1+\gamma)\nu^{2}\right)

\displaystyle\leq e^{-\frac{P_{1}}{2}(\sqrt{1+2\gamma}-1)^{2}}

by noting that
\boldsymbol{\mathbf{W}}\sim\mathcal{CN}(0,\nu^{2}\boldsymbol{\mathbf{I}})
and applying Lemma
2
.

On the other hand, given some multi-ton observation
\boldsymbol{\mathbf{U}}=\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\alpha}}+\boldsymbol{\mathbf{W}}
, the probability of detecting it as a singleton with index-value pair
(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])
can be written as

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{Z})=\mathrm{Pr}\left(\frac{1}{P_{1}}\left\|\boldsymbol{\mathbf{g}}+\boldsymbol{\mathbf{v}}\right\|^{2}\leq(1+\gamma)\nu^{2}\right),

where
\boldsymbol{\mathbf{g}}:=\boldsymbol{\mathbf{S}}(\boldsymbol{\mathbf{\alpha}}-\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\boldsymbol{\mathbf{e}}_{\widehat{\boldsymbol{\mathbf{k}}}})
and
\boldsymbol{\mathbf{v}}:=\boldsymbol{\mathbf{W}}
. Then, we can upper bound this probability by

\displaystyle\mathrm{Pr}\left(\frac{1}{P_{1}}\left\|\boldsymbol{\mathbf{g}}+\boldsymbol{\mathbf{v}}\right\|^{2}\leq(1+\gamma)\nu^{2}\middle|\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\geq 2\gamma\nu^{2}\right)

\displaystyle+\mathrm{Pr}\left(\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\leq 2\gamma\nu^{2}\right).

Using Lemma
2
, the first term is upper bounded by
\exp\{-(P_{1}\gamma^{2})/(2(1+4\gamma))\}
. To analyze the second term, we let
\boldsymbol{\mathbf{\beta}}=\boldsymbol{\mathbf{\alpha}}-\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\boldsymbol{\mathbf{e}}_{\widehat{\boldsymbol{\mathbf{k}}}}
and write
\boldsymbol{\mathbf{g}}=\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}
. Denoting its support as
\mathcal{L}:=\mathrm{supp}(\boldsymbol{\mathbf{\beta}})
, we can further write
\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}=\boldsymbol{\mathbf{S}}_{\mathcal{L}}\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}
where
\boldsymbol{\mathbf{S}}_{\mathcal{L}}
is the sub-matrix
of
\boldsymbol{\mathbf{S}}
consisting of the columns in
\mathcal{L}
and
\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}
is the sub-vector consisting of the elements in
\mathcal{L}
. Then, we consider two scenarios:

•

The multi-ton size is a constant, i.e.,
|\mathcal{L}|=L=O(1)
. In this case, we have

\lambda_{\mathrm{min}}(\boldsymbol{\mathbf{S}}_{\mathcal{L}}^{\mathrm{H}}\boldsymbol{\mathbf{S}}_{\mathcal{L}})\|\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}\|^{2}\leq\|\boldsymbol{\mathbf{S}}_{\mathcal{L}}\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}\|^{2}

Using
\|\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}\|^{2}\geq L\rho^{2}
, the probability can be bounded as

\mathrm{Pr}\left(\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\leq 2\gamma\nu^{2}\right)\leq\mathrm{Pr}\left(\lambda_{\mathrm{min}}\left(\frac{1}{P_{1}}\boldsymbol{\mathbf{S}}_{\mathcal{L}}^{\mathrm{H}}\boldsymbol{\mathbf{S}}_{\mathcal{L}}\right)\leq\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)

Then, according to the Gershgorin Circle Theorem,

\lambda_{\mathrm{min}}\left(\frac{1}{P_{1}}\boldsymbol{\mathbf{S}}_{\mathcal{L}}^{\mathrm{H}}\boldsymbol{\mathbf{S}}_{\mathcal{L}}\right)\geq 1-L\mu,

where
\mu
is the mutual coherence of
\boldsymbol{\mathbf{S}}
defined in Lemma
3
. Using the bound for
\mu
and letting
\mu_{0}=\frac{1}{L}\left(1-\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)
,

\displaystyle\mathrm{Pr}\left(\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\leq 2\gamma\nu^{2}\right)\leq 4N^{2}e^{-\frac{1}{8L^{2}}\left(1-\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)^{2}P_{1}}

which holds as long as
\gamma<L\rho^{2}/2\nu^{2}=\frac{L\eta}{2}\mathrm{SNR}
.

•

The multi-ton size grows asymptotically with respect to S, i.e.,
|\mathcal{L}|=L=\omega(1)
. As a result, the vector of random variables
\boldsymbol{\mathbf{g}}=\boldsymbol{\mathbf{S}}_{\mathcal{L}}\boldsymbol{\mathbf{\beta}}_{\mathcal{L}}
becomes asymptotically Gaussian due to the central limit theorem with zero mean and a covariance

\mathbb{E}[\boldsymbol{\mathbf{g}}\boldsymbol{\mathbf{g}}^{\mathrm{H}}]=L\rho^{2}\boldsymbol{\mathbf{I}}

Therefore, by Lemma
2
, we have

\displaystyle\mathrm{Pr}\left(\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\leq 2\gamma\nu^{2}\right)\leq e^{-\frac{P_{1}}{2}\left(1-\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)}

which holds as long as
\gamma<L\rho^{2}/2\nu^{2}=\frac{L\eta}{2}\mathrm{SNR}
.

By combining the results from both cases, there exists some absolute constant
\epsilon>0
such that

\displaystyle\mathrm{Pr}\left(\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P_{1}}\leq 2\gamma\nu^{2}\right)\leq 4N^{2}e^{-\epsilon\left(1-\frac{2\gamma\nu^{2}}{L\rho^{2}}\right)^{2}P_{1}}

as long as
\gamma<\rho^{2}/2\nu^{2}=\frac{\eta}{2}\mathrm{SNR}
.
∎

Proposition 5

(Missed Verification Rate)
.

For
0<\gamma<\frac{\eta}{2}\mathrm{SNR}
, the missed verification rate for each bin hypothesis satisfies

\displaystyle\mathrm{Pr}(\mathcal{H}_{Z}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))\leq e^{-\frac{P_{1}}{2}\frac{(\rho^{2}/\nu^{2}-\gamma)^{2}}{1+2\rho^{2}/\nu^{2}}}

\displaystyle\mathrm{Pr}(\mathcal{H}_{M}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle\quad\leq e^{-\frac{P_{1}}{2}(\sqrt{1+2\gamma}-1)^{2}}+2e^{-\frac{\rho^{2}\sin^{2}(\pi/\kappa)}{2\nu^{2}}P_{1}}

\displaystyle\quad+\begin{cases}4Ne^{-\frac{P_{1}}{2}\left(\sqrt{2\gamma+1}-1\right)^{2}}\\
\quad+4N^{2}e^{-\frac{P_{1}}{8}\left(1-\sqrt{16(1+\gamma)\nu^{2}/\rho^{2}}\right)^{2}},&\text{NLT}\\
4ne^{-\frac{1}{2q}\epsilon^{2}P_{1}},&\text{SLT}\end{cases}

where
P_{1}
is the number of the random offsets in the near-linear time and sublinear time robust bin detection algorithms.

Proof.

The probability of detecting a singleton as a zero-ton can be upper bounded by the probability of a singleton passing the zero-ton verification. Hence, by noting that
\boldsymbol{\mathbf{W}}\sim\mathcal{CN}(0,\nu^{2}\boldsymbol{\mathbf{I}})
and applying Lemma
2
,

\displaystyle\mathrm{Pr}

\displaystyle(\mathcal{H}_{Z}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle\leq\mathrm{Pr}\left(\frac{1}{P_{1}}\|F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}+\boldsymbol{\mathbf{W}}\|^{2}\leq(1+\gamma)\nu^{2}\right)

\displaystyle\leq e^{-\frac{P_{1}}{2}\frac{(\rho^{2}/\nu^{2}-\gamma)^{2}}{1+2\rho^{2}/\nu^{2}}}.

which holds as long as
\gamma<\rho^{2}/\nu^{2}=\eta\mathrm{SNR}
.

On the other hand, the probability of detecting a singleton as a multi-ton can be written as the probability of failing the singleton verification step for some index-value pair
(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])
. Denoting the error event by

\mathcal{E}_{V}=\left\{\frac{1}{P}\left\|\boldsymbol{\mathbf{U}}-\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\boldsymbol{\mathbf{s}}_{\widehat{k}}\right\|^{2}\geq(1+\gamma)\nu^{2}\right\},

we can write,

\displaystyle\mathrm{Pr}(\mathcal{H}_{M}\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle=\mathrm{Pr}(\mathcal{E}_{V})

\displaystyle\leq\mathrm{Pr}(\mathcal{E}_{V}|\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]=F[\boldsymbol{\mathbf{k}}]\wedge\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})

\displaystyle+\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}]\vee\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}}).

Here, the first term is bounded as

\displaystyle\mathrm{Pr}(\mathcal{E}_{V}|\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]=F[\boldsymbol{\mathbf{k}}]\wedge\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})

\displaystyle\leq\mathrm{Pr}\hbox{$\left(\vbox to0.0pt{}\right.$}\frac{1}{P_{1}}\|\boldsymbol{\mathbf{W}}\|^{2}\geq(1+\gamma)\nu^{2}\hbox{$\left)\vbox to0.0pt{}\right.$}

\displaystyle\leq e^{-\frac{P_{1}}{2}(\sqrt{1+2\gamma}-1)^{2}}.

The second term is bounded as

\displaystyle\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]

\displaystyle\neq F[\boldsymbol{\mathbf{k}}]\vee\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})

\displaystyle\leq\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}])+\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})

\displaystyle=\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}]|\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})

\displaystyle\qquad+\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}]|\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})

\displaystyle\qquad+\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})

\displaystyle\leq\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}]|\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})+2\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})

The first term is the error probability of a
\kappa
-point PSK signal with constellation points
\{\rho,\rho\phi,\rho\phi^{2},\dots,\rho\phi^{\kappa-1}\}
, and can be bounded as

\mathrm{Pr}(\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\neq F[\boldsymbol{\mathbf{k}}]|\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})\leq 2e^{-\frac{\rho^{2}\sin^{2}(\pi/\kappa)}{2\nu^{2}}P_{1}}

Since the second term
\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})
is the error probability of the singleton search, we use Lemmas
4
and
5
.
∎

Proposition 6

(Crossed Verification Rate)
.

For
0<\gamma<\frac{\eta}{2}\mathrm{SNR}
, the crossed verification rate for each bin hypothesis satisfies

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle\qquad\leq 4N^{2}e^{-\frac{1}{32}\left(1-\frac{2\gamma\nu^{2}}{2\rho^{2}}\right)^{2}P_{1}}+e^{-\frac{P_{1}\gamma^{2}}{2(1+4\gamma)}}

where
P_{1}
is the number of the random offsets in the near-linear time and sublinear time robust bin detection algorithms.

Proof.

This error event can only occur if a singleton with index-value pair
(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}])
passes the singleton verification step for some index-value pair
(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])
such that
\boldsymbol{\mathbf{k}}\neq\widehat{\boldsymbol{\mathbf{k}}}
. Hence,

\displaystyle\mathrm{Pr}(\mathcal{H}_{S}(\widehat{\boldsymbol{\mathbf{k}}},\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}])\leftarrow\mathcal{H}_{S}(\boldsymbol{\mathbf{k}},F[\boldsymbol{\mathbf{k}}]))

\displaystyle\leq\mathrm{Pr}\left(\frac{1}{P_{1}}\|F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\widehat{F}[\widehat{\boldsymbol{\mathbf{k}}}]\boldsymbol{\mathbf{s}}_{\widehat{\boldsymbol{\mathbf{k}}}}+\boldsymbol{\mathbf{W}}\|^{2}\leq(1+\gamma)\nu^{2}\right)

\displaystyle=\mathrm{Pr}\left(\frac{1}{P_{1}}\|\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}+\boldsymbol{\mathbf{W}}\|^{2}\leq(1+\gamma)\nu^{2}\right)

\displaystyle=\mathrm{Pr}\left(\frac{1}{P_{1}}\|\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}+\boldsymbol{\mathbf{W}}\|^{2}\leq(1+\gamma)\nu^{2}\middle|\|\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}\|^{2}\geq 2\gamma\nu^{2}\right)

\displaystyle\qquad+\mathrm{Pr}\left(\|\boldsymbol{\mathbf{S}}\boldsymbol{\mathbf{\beta}}\|^{2}\leq 2\gamma\nu^{2}\right)

where
\boldsymbol{\mathbf{\beta}}
is a
2
-sparse vector with non-zero entries from
\{\rho,\rho\phi,\rho\phi^{2},\dots,\rho\phi^{\kappa-1}\}
. Using Lemma
2
, the first term is upper-bounded by
e^{-\frac{P_{1}\gamma^{2}}{2(1+4\gamma)}}
. By Lemma
3
, the second term is upper bounded by
4N^{2}e^{-\frac{1}{32}\left(1-\frac{2\gamma\nu^{2}}{2\rho^{2}}\right)^{2}P_{1}}
.
∎

Lemma 2

(Non-central Tail Bounds)
.

Given
\boldsymbol{\mathbf{g}}\in\mathbb{C}^{P}
and a complex Gaussian vector
\boldsymbol{\mathbf{v}}\sim\mathcal{CN}(0,\nu^{2}\boldsymbol{\mathbf{I}})
, the following tail bounds hold:

\displaystyle\mathrm{Pr}\left(\frac{1}{P}\|\boldsymbol{\mathbf{g}}+\boldsymbol{\mathbf{v}}\|^{2}\geq\tau_{1}\right)

\displaystyle\leq e^{-\frac{P}{2}(\sqrt{2\tau_{1}/\nu^{2}-1}-\sqrt{1+2\theta_{0}})^{2}}

\displaystyle\mathrm{Pr}\left(\frac{1}{P}\|\boldsymbol{\mathbf{g}}+\boldsymbol{\mathbf{v}}\|^{2}\leq\tau_{2}\right)

\displaystyle\leq e^{-\frac{P}{2}\frac{\left(1+\theta_{0}-\tau_{2}/\nu^{2}\right)^{2}}{1+2\theta_{0}}}

for any
\tau_{1}
and
\tau_{2}
that satisfy

\tau_{1}\geq\nu^{2}(1+\theta_{0})\geq\tau_{2},

where
\theta_{0}
is the normalized non-centrality parameter given by

\theta_{0}:=\frac{\|\boldsymbol{\mathbf{g}}\|^{2}}{P\nu^{2}}.

Proof.

We apply Lemma 11 in
[
11
]
to
\widetilde{\boldsymbol{\mathbf{g}}}=[\mathrm{Re}[\boldsymbol{\mathbf{g}}],\mathrm{Im}[\boldsymbol{\mathbf{g}}]]^{\mathrm{T}}\in\mathbb{R}^{2P}
and
\widetilde{\boldsymbol{\mathbf{v}}}=[\mathrm{Re}[\boldsymbol{\mathbf{v}}],\mathrm{Im}[\boldsymbol{\mathbf{v}}]]^{\mathrm{T}}\sim\mathcal{N}(0,\frac{\nu^{2}}{2}\boldsymbol{\mathbf{I}})
.
∎

Lemma 3
.

Denote the mutual coherence of
\boldsymbol{\mathbf{S}}
by

\mu:=\max_{\boldsymbol{\mathbf{k}}\neq\boldsymbol{\mathbf{m}}}\frac{1}{P_{1}}|\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{H}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}|.

Then, we have
\mathrm{Pr}(\mu\geq\mu_{0})\leq 4N^{2}e^{-\frac{\mu_{0}^{2}}{8}P_{1}}
for any
\mu_{0}>0
.

Proof.

The columns of
\boldsymbol{\mathbf{S}}
are given as
\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}=\omega^{\boldsymbol{\mathbf{D}}\boldsymbol{\mathbf{k}}}
. Let us denote the
p
-th entry of
\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}
by
\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}[p]=\omega^{\langle\boldsymbol{\mathbf{d}}_{p},\boldsymbol{\mathbf{k}}\rangle}
for
p\in[P_{1}]
. Therefore, each multiplication can be written as
\boldsymbol{\mathbf{y}}[p]:=\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}[p]^{\mathrm{H}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}[p]=\omega^{\langle\boldsymbol{\mathbf{d}}_{p},\boldsymbol{\mathbf{m}}\ominus_{q}\boldsymbol{\mathbf{k}}\rangle}
. Since
\boldsymbol{\mathbf{m}}\ominus_{q}\boldsymbol{\mathbf{k}}\neq\boldsymbol{\mathbf{0}}
for all
\boldsymbol{\mathbf{k}}\neq\boldsymbol{\mathbf{m}}
, each
\boldsymbol{\mathbf{y}}[p]
term is uniformly distributed over the set
\{\rho,\rho\omega,\rho\omega^{2},\dots,\rho\omega^{q-1}\}
. Then, due to independence in choosing offsets
\boldsymbol{\mathbf{d}}_{p}
, we can apply a Hoeffding bound to obtain

\displaystyle\mathrm{Pr}\left(\frac{|\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{H}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}|}{P_{1}}\geq\mu_{0}\right)

\displaystyle=\mathrm{Pr}(|\boldsymbol{\mathbf{y}}|\geq P_{1}\mu_{0})

\displaystyle\leq 2\mathrm{Pr}(\mathrm{Re}|\boldsymbol{\mathbf{y}}|\geq P_{1}\mu_{0}/\sqrt{2})

\displaystyle\leq 4e^{-\frac{\mu_{0}^{2}}{8}P_{1}}.

By applying a union bound over all
(\boldsymbol{\mathbf{k}},\boldsymbol{\mathbf{m}})
pairs, we obtain the result.
∎

Lemma 4
.

The singleton search error probability of the near-linear time robust bin detection is upper bounded as

\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}\neq\boldsymbol{\mathbf{k}})\leq 4Ne^{-\frac{P}{2}\left(\sqrt{2\epsilon+1}-1\right)^{2}}+4N^{2}e^{-\frac{P}{8}\left(1-\sqrt{\frac{16(1+\epsilon)\nu^{2}}{\rho^{2}}}\right)^{2}}

for some constant
\epsilon>0
.

Proof.

The error occurs if the residual energy for some
\boldsymbol{\mathbf{m}}\neq\boldsymbol{\mathbf{k}}
is lower than the residual energy for true singleton index
\boldsymbol{\mathbf{k}}
. Let
\mathcal{H}
denote the event
\{\mu<1-\sqrt{16(1+\epsilon)\nu^{2}/\rho^{2}}\}
where
\mu
is the mutual coherence of
\boldsymbol{\mathbf{S}}
and
\gamma
is a constant. Furthermore, let
\mathrm{Pr}_{\mathcal{H}}
denote probabilities conditioned on
\mathcal{H}
. Then, for any given
\boldsymbol{\mathbf{m}}\neq\boldsymbol{\mathbf{k}}
,

\displaystyle\mathrm{Pr}_{\mathcal{H}}(\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{m}})

\displaystyle\qquad\leq\mathrm{Pr}_{\mathcal{H}}\hbox{$\left(\vbox to0.0pt{}\right.$}\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\boldsymbol{\mathbf{U}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-\boldsymbol{\mathbf{U}}\right\|\leq\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{T}}\boldsymbol{\mathbf{U}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\boldsymbol{\mathbf{U}}\right\|\hbox{$\left)\vbox to0.0pt{}\right.$}

\displaystyle\quad=\mathrm{Pr}_{\mathcal{H}}\hbox{$\left(\vbox to0.0pt{}\right.$}\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\left(F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}+\boldsymbol{\mathbf{W}}\right)\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\boldsymbol{\mathbf{W}}\right\|

\displaystyle\quad\qquad\qquad\leq\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{T}}\left(F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}+\boldsymbol{\mathbf{W}}\right)\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-F[\boldsymbol{\mathbf{k}}]\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\boldsymbol{\mathbf{W}}\right\|\hbox{$\left)\vbox to0.0pt{}\right.$}

\displaystyle\quad=\mathrm{Pr}_{\mathcal{H}}\hbox{$\left(\vbox to0.0pt{}\right.$}\left\|F[\boldsymbol{\mathbf{k}}]\left(\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}\right)+\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\boldsymbol{\mathbf{W}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-\boldsymbol{\mathbf{W}}\right\|

\displaystyle\quad\qquad\qquad\leq\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{T}}\boldsymbol{\mathbf{W}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\boldsymbol{\mathbf{W}}\right\|\hbox{$\left)\vbox to0.0pt{}\right.$}.

Then,

\displaystyle\mathrm{Pr}_{\mathcal{H}}(\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{m}})

\displaystyle\qquad\leq\mathrm{Pr}_{\mathcal{H}}\hbox{$\left(\vbox to0.0pt{}\right.$}\rho\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}\right\|-\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}^{\mathrm{T}}\boldsymbol{\mathbf{W}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{m}}}-\boldsymbol{\mathbf{W}}\right\|

\displaystyle\qquad\qquad\qquad\leq\left\|\frac{1}{P}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}^{\mathrm{T}}\boldsymbol{\mathbf{W}}\boldsymbol{\mathbf{s}}_{\boldsymbol{\mathbf{k}}}-\boldsymbol{\mathbf{W}}\right\|\hbox{$\left)\vbox to0.0pt{}\right.$}

\displaystyle\qquad\leq 4\mathrm{Pr}_{\mathcal{H}}\hbox{$\left(\vbox to0.0pt{}\right.$}\frac{1}{P}\left\|\boldsymbol{\mathbf{W}}\right\|^{2}\geq(1+\epsilon)\nu^{2}\hbox{$\left)\vbox to0.0pt{}\right.$}

\displaystyle\qquad\leq 4e^{-\frac{P}{2}\left(\sqrt{2\epsilon+1}-1\right)^{2}}.

Next, by a union bound over all
\boldsymbol{\mathbf{m}}\in\mathbb{Z}_{q}^{n}
, we have

\mathrm{Pr}_{\mathcal{H}}(\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}})\leq 4Ne^{-\frac{P}{2}\left(\sqrt{2\epsilon+1}-1\right)^{2}}.

Lastly, we can write

\displaystyle\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}

\displaystyle=\boldsymbol{\mathbf{k}})\leq\mathrm{Pr}(\widehat{\boldsymbol{\mathbf{k}}}=\boldsymbol{\mathbf{k}}|\mathcal{H})+\mathrm{Pr}(\mathcal{H}^{\mathrm{c}})

\displaystyle\leq 4Ne^{-\frac{P}{2}\left(\sqrt{2\epsilon+1}-1\right)^{2}}+4N^{2}e^{-\frac{P}{8}\left(1-\sqrt{\frac{16(1+\epsilon)\nu^{2}}{\rho^{2}}}\right)^{2}}.

∎

Lemma 5
.

Proof.
