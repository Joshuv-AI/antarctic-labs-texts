Some aspects on the computational implementation of diverse terms arising in mixed virtual element formulations
Filánder A. Sequeira, Helen Guillén-Oviedo

Abstract
In the present paper we describe the computational implementation of some integral terms that arise from mixed virtual element methods (mixed-VEM) in two-dimensional pseudostress-velocity formulations. The implementation presented here consider any polynomial degree k ≥ 0 k\geq 0 in a natural way by building several local matrices of small size through the matrix multiplication and the Kronecker product. In particular, we apply the foregoing mentioned matrices to the Navier-Stokes equations with Dirichlet boundary conditions, whose mixed-VEM formulation was originally proposed and analyzed in a recent work using virtual element subspaces for H ⁡ ( div ) H(\text{\rm div}) and H 1 H^{1} , simultaneously. In addition, an algorithm is proposed for the assembly of the associated global linear system for the Newton’s iteration. Finally, we present a numerical example in order to illustrate the performance of the mixed-VEM scheme and confirming the expected theoretical convergence rates.



Key words:
mixed virtual element method, high-order approximations,
computational implementation, Navier-Stokes problem, pseudostress-velocity
formulation, augmented formulation

Introduction

The virtual element method (VEM) was introduced in
[
3
]
for the
Poisson equation, which is one of the high-order discretization schemes for
the approximation of solutions to partial differential equations, that can be
seen as a generalization of the standard finite element method. In other words,
the method extends the classical finite element technique to general polygonal
and polyhedral meshes. Moreover, according to
[
8
]
, additional
advantages of VEM schemes, when compared with finite volume methods, mimetic
finite difference method, and related techniques, are given by its solid mathematical
ground, the simplicity of the respective computational coding, and the quality
of the numerical results provided. On the other hand, regarding to purely mixed
virtual element techniques, that is based on dual-mixed variational formulations,
the method was initially developed in
[
11
]
, and more recently
extended in
[
4
]
,
[
5
]
,
[
14
]
,

[
15
]
, and
[
27
]
. In particular, edge and face VEM spaces in
2D and 3D, which together with the nodal and volume spaces constitute a discrete
complex, were developed in
[
4
]
, whereas
[
5
]

generalizes the results of
[
4
]
to the case of variable coefficients.
In turn,
[
14
]
and
[
27
]
provide the first analysis of
a virtual element method for a mixed variational formulation of the Stokes and
Navier-Stokes problems, respectively, in which the pseudostress and the velocity
are the only unknowns, whereas the pressure is computed via a postprocessing formula.
Additionally, the analysis presented in
[
27
]
allows to study problems
of the same nature as Navier-Stokes, such as the Boussinesq problem, where a mixed
method of virtual elements was introduced and analyzed in
[
26
]
.
For several other contributions on VEM and mixed-VEM we refer for instance to

[

]
,

]
,

]
,

]

implementation of mixed-VEM schemes. For this reason, the main goal of this paper is to
describe a computational approach for mixed-VEM methods in order to obtain high-order
approximations, without imposing a certain programming language. More precisely, the
reason for this contribution is that there is a few literature that explains how to program
the subspaces of virtual elements accurately (particularly the mixed ones). Up to the authors
knowledge, some works such as

2
The virtual element subspaces

In this section we recall two local element subspaces, usually used in the
design of virtual element schemes. More precisely, we introduce the spaces
\text{\rm H}_{k}^{K}

(see (
2.3
)) and
V_{k}^{K}
(see (
2.20
)) for
H(\text{\rm div})
-conforming
and
H^{1}
-conforming elements, respectively. In order to do that, we let
\{\mathcal{T}_{h}\}_{h>0}

be a family of decompositions of
\Omega
in polygonal elements, where
h
denotes the
largest of its diameters. For theoretical purposes, it is assumed that
\mathcal{T}_{h}
satisfies
some conditions described at the beginning of
[
27
, Section 3.1]
.

In what follows, we consider
K
an arbitrary element of
\mathcal{T}_{h}
, which it is important
to realize that the decomposition
\mathcal{T}_{h}
needs a quite more sophisticated computational
structure than those used in classical finite element methods. Indeed, we recall here
that
\mathcal{T}_{h}
can contain elements with several shapes that affect important aspects,
such as: the number of edges and the calculation of its diameter. In particular,
any structure that is implemented for mesh management, from a connectivity
point of view, must be able to indicate:

•

the number of nodes (points)

•

the number of edges

•

the number of elements

•

the number of boundary edges

•

for any element:

–

the number of nodes of the element

–

the global index (identifier) of a node of the element

–

the local indexes of the nodes in a specific edge

–

the global indexes of the nodes in a specific edge

–

the global index of an edge of the element

•

for any edge:

–

the global index of a node of the edge

–

the global index of the edge

–

the global index of the neighbor element shared by the edge

–

the global indexes of the elements that contain the edge

–

the orientation in a specific elements that contain the edge

–

an identifier that establishes if the edge is in the boundary

Here, the orientation of an edge corresponds to a boolean identifier that indicates
the ordering (independent of the element that contains it) of its extreme nodes.
In addition, in the case of geometric aspects, for all
K\in\mathcal{T}_{h}
, it
must be able to calculate:

•

the number of vertices, or equivalently, the number of edges

•

the coordinates of a specific vertex

•

the coordinates of the barycenter of
K

•

the area of
K

•

the diameter of
K

•

the midpoints, normal vectors and lengths of each of its edges

2.1
\text{\rm H}(\text{\rm div};K)
-conforming subspace, associated bilinear form and projection

Let
e
be an edge of
\mathcal{T}_{h}
with midpoint
x_{e}
and length
h_{e}
. Thus, given
an integer
\ell\geq 0
, we consider the following set of
k+1
normalized
monomials on
e
:

\mathcal{B}_{\ell}(e)\ :=\ \left\{\left(\frac{x-x_{e}}{h_{e}}\right)^{j}\right\}_{0\,\leq\,j\,\leq\,\ell}\,,

(2.1)

which constitutes a basis of
\textrm{P}_{\ell}(e)
. Similarly, given an element
K\in\mathcal{T}_{h}
with barycenter

\text{\rm x}_{K}
and diameter
h_{K}
, we define the following set of
\frac{1}{2}(\ell+1)(\ell+2)

normalized monomials on
K
:

\mathcal{B}_{\ell}(K)\ :=\ \left\{\left(\frac{\text{\rm x}-\text{\rm x}_{K}}{h_{K}}\right)^{\text{\boldmath$\alpha$}}\right\}_{0\,\leq\,|\text{\boldmath$\alpha$}|\,\leq\,\ell}\,,

(2.2)

which is a basis of
\textrm{P}_{\ell}(K)
. It is important to remark that in (
2.2
)
we use the multi-index notation, where given
\text{\rm x}:=(x_{1},x_{2})^{\text{\tt t}}\in\text{\rm R}^{2}

and
\text{\boldmath$\alpha$}:=(\alpha_{1},\alpha_{2})^{\text{\tt t}}
, with non-negative integers
\alpha_{1}
,

\alpha_{2}
, we let
\text{\rm x}^{\text{\boldmath$\alpha$}}:=x_{1}^{\alpha_{1}}x_{2}^{\alpha_{2}}
and

|\text{\boldmath$\alpha$}|:=\alpha_{1}+\alpha_{2}
.

Next, we introduce the auxiliary local virtual element space of order

(see, e.g.,

5

\begin{array}[]{l}\text{\rm H}_{k}^{K}\ :=\ \Big\{\tau:=(\tau_{1},\tau_{2})^{\text{\tt t}}\in\text{\rm H}(\text{\rm div};K)\cap\text{\rm H}(\text{\rm rot};K)\,:\quad\tau\cdot\text{\boldmath$n$}|_{e}\in\textrm{P}_{k}(e)\\[4.30554pt]
\phantom{\text{\rm H}_{k}^{K}\ :=\ \Big\{}\forall\mbox{ edge }e\in\partial K\,,\quad\text{\rm div}(\tau)\in\textrm{P}_{k}(K)\,,\;\text{ and }\;\text{\rm rot}(\tau)\in\textrm{P}_{k-1}(K)\Big\}\,,\end{array}

(2.3)

where
\text{\rm rot}(\tau):=\frac{\partial\tau_{2}}{\partial{x_{1}}}-\frac{\partial\tau_{1}}{\partial{x_{2}}}

and
\textrm{P}_{{-}1}(K):=\{0\}
.
Moreover, the local degrees of freedom for

\displaystyle\begin{array}[]{rcl}m_{q,\text{\boldmath$n$}}^{H}(\tau)&:=&\displaystyle\int_{e}\text{\boldmath$\tau$}\cdot\text{\boldmath$n$}\,q\qquad\;\;\forall\ q\in\mathcal{B}_{k}(e)\,,\quad\forall\ \mbox{edge}\ e\in\partial K\,,\\[12.91663pt]

\frac{1}{2}k(k+1)

2.1

\text{\rm H}_{k}^{K}

\displaystyle n_{k}^{H}\ =\ n_{k}^{H}(K)

\displaystyle:=

\displaystyle(k+1)\,d_{K}\ +\ \left\{\frac{(k+1)(k+2)}{2}-1\right\}\ +\ \frac{k(k+1)}{2}

(2.8)

\displaystyle=

\displaystyle(k+1)(d_{K}+k+1)-1\,,

where

corresponds to the number of edges in

it was proved in

that, for every

in
\text{\rm H}_{k}^{K}

On the other hand, we employ the space
\text{\rm H}_{k}^{K}
to define a tensor virtual element

\mathbb{H}_{k}^{K}

\mathbb{H}_{k}^{K}\ =\ \Big\{\text{\boldmath$\tau$}\in\mathbb{H}(\textrm{\bf div};K)\,:\quad(\tau_{i1},\,\tau_{i2})^{\text{\tt t}}\in\text{\rm H}_{k}^{K}\quad\forall\ i\in\{1,2\}\Big\}\,.

(2.9)

In other words,
\mathbb{H}_{k}^{K}
is a subspace of
\mathbb{H}(\textrm{\bf div};K)
, where each row of

\text{\boldmath$\tau$}\in\mathbb{H}_{k}^{K}
belongs to
\text{\rm H}_{k}^{K}
. According to this, it is natural
to consider for each
\text{\boldmath$\tau$}\in\mathbb{H}_{k}^{K}
, the following
2n_{k}^{H}

of freedom:

\displaystyle\begin{array}[]{rcl}\text{\boldmath$m$}_{\text{\rm q},\text{\boldmath$n$}}^{H}(\text{\boldmath$\tau$})&:=&\displaystyle\int_{e}\text{\boldmath$\tau$}\text{\boldmath$n$}\cdot\text{\rm q}\qquad\;\;\forall\ \text{\rm q}\in\text{\boldmath$\mathcal{B}$}_{k}(e)\,,\quad\forall\ \mbox{edge}\ e\in\partial K\,,\\[12.91663pt]

\text{\boldmath$m$}_{\text{\boldmath$\rho$},\textrm{\bf rot}}^{H}(\text{\boldmath$\tau$})&:=&\displaystyle\int_{K}\text{\boldmath$\tau$}:\text{\boldmath$\rho$}\qquad\quad\forall\ \text{\boldmath$\rho$}\in\mathcal{G}_{k}^{\perp}(K)\,,\end{array}

where

\displaystyle\text{\boldmath$\mathcal{B}$}_{\ell}(e)

\displaystyle:=

\displaystyle\big\{(q,0)^{\text{\tt t}}\,:\,q\in\mathcal{B}_{\ell}(e)\big\}\,\cup\,\big\{(0,q)^{\text{\tt t}}\,:\,q\in\mathcal{B}_{\ell}(e)\big\}\,,

\displaystyle\text{\boldmath$\mathcal{B}$}_{\ell}(K)

\displaystyle:=

\displaystyle\big\{(q,0)^{\text{\tt t}}\,:\,q\in\mathcal{B}_{\ell}(K)\big\}\,\cup\,\big\{(0,q)^{\text{\tt t}}\,:\,q\in\mathcal{B}_{\ell}(K)\big\}\,,

and

\text{\boldmath$\mathcal{G}$}_{k}^{\perp}(K)\ :=\ \left\{\left(\begin{array}[]{c}\text{\rm q}\\[0.86108pt]
\text{\rm 0}\end{array}\right)\,:\,\text{\rm q}\in\mathcal{G}_{k}^{\perp}(K)\right\}\,\cup\,\left\{\left(\begin{array}[]{c}\text{\rm 0}\\[-2.15277pt]
\text{\rm q}\end{array}\right)\,:\,\text{\rm q}\in\mathcal{G}_{k}^{\perp}(K)\right\}\,.

Furthermore, according to the degrees of freedom defined in (
2.1
)
and (
2.1
), it is possible to define a bilinear form

\mathcal{S}_{H}^{K}:\mathbb{H}_{k}^{K}\times\mathbb{H}_{k}^{K}\to\text{\rm R}
based on these.
Indeed, let
K\in\mathcal{T}_{h}
and consider the union of all local degrees of freedom
(cf. (
2.1
)) of a given
\tau\in\text{\rm H}^{1}(K)
, in a set

\{m_{i,K}^{H}(\tau)\}_{i=1}^{n_{k}^{H}}
. Then, as usual, let
\{\Psi^{K}_{j}\}_{j=1}^{n_{k}^{H}}

be the canonical basis of
\text{\rm H}_{k}^{K}
. That is, given
i=1,2,\ldots,n_{k}^{H}
,

\Psi^{K}_{i}
is the unique element in
\text{\rm H}_{k}^{K}
such that:

m_{j,K}^{H}(\Psi^{K}_{i})\ =\ \delta_{ij}\qquad\forall\ j=1,2,\ldots,n_{k}^{H}\,,

(2.14)

where, in particular, there holds:

\tau\ =\ \sum_{j=1}^{n_{k}^{H}}m_{j,K}^{H}(\tau)\,\Psi^{K}_{j}\qquad\forall\,\tau\in\text{\rm H}^{K}_{k}\,.

Now, let
s_{H}^{K}:\text{\rm H}_{k}^{K}\times\text{\rm H}_{k}^{K}\rightarrow\text{\rm R}
be
the bilinear form associated with the identity matrix in
\text{\rm R}^{n_{k}^{H}\times n_{k}^{H}}
,
respect to the basis
\{\Psi^{K}_{j}\}_{j=1}^{n_{k}^{H}}
of
\text{\rm H}_{k}^{K}
. More precisely, we
have:

s_{H}^{K}(\zeta,\tau)\ :=\ \sum_{i=1}^{n_{k}^{H}}m_{i,K}^{H}(\zeta)\,m_{i,K}^{H}(\tau)\qquad\forall\,\zeta,\,\tau\in\text{\rm H}_{k}^{K}\,.

Then, we define
\mathcal{S}_{H}^{K}:\mathbb{H}_{k}^{K}\times\mathbb{H}_{k}^{K}\rightarrow\text{\rm R}
as the bilinear
form associated with the degrees of freedom of
\mathbb{H}_{k}^{K}
as follows:

\mathcal{S}_{H}^{K}(\text{\boldmath$\zeta$},\,\text{\boldmath$\tau$})\ :=\ \sum_{i=1}^{2}s_{H}^{K}\big((\zeta_{i1},\zeta_{i2})^{\text{\tt t}}\,,(\tau_{i1},\tau_{i2})^{\text{\tt t}}\big)\,,

(2.15)

for all
\text{\boldmath$\zeta$}:=(\zeta_{ij}),\,\text{\boldmath$\tau$}:=(\tau_{ij})\in\mathbb{H}_{k}^{K}
.

In addition, let
P_{k}^{K}:L^{2}(K)\rightarrow\textrm{P}_{k}(K)
be corresponding orthogonal
projection, such that, for
v\in L^{2}(K)
, it is characterized by:

P_{k}^{K}(v)\in\textrm{P}_{k}(K){\qquad\hbox{and}\qquad}\int_{K}P_{k}^{K}(v)\,q\ =\ \int_{K}v\,q\qquad\forall\,q\in\textrm{P}_{k}(K)\,.

(2.16)

In turn, let
\mathcal{P}_{k}^{K}:\text{\rm L}^{2}(K)\rightarrow\text{\rm P}_{k}(K)
its corresponding vectorial version,
such that, for
\text{\rm v}\in\text{\rm L}^{2}(K)
there hold:

\mathcal{P}_{k}^{K}(\text{\rm v})\in\text{\rm P}_{k}(K){\qquad\hbox{and}\qquad}\int_{K}\mathcal{P}_{k}^{K}(\text{\rm v})\cdot\text{\rm q}\ =\ \int_{K}\text{\rm v}\cdot\text{\rm q}\qquad\forall\,\text{\rm q}\in\text{\rm P}_{k}(K)\,,

(2.17)

where, notice that
\mathcal{P}_{k}^{K}(\text{\rm v})=\big(P_{k}^{K}(v_{1}),P_{k}^{K}(v_{2})\big)^{\text{\tt t}}

for all
\text{\rm v}:=(v_{1},v_{2})^{\text{\tt t}}\in\text{\rm L}^{2}(K)
.

Next, for the following sections, it is important to mention that, according
to
[
5
, Section 3.2]
, the degrees of freedom given in
(
2.1
) allow us the explicit calculation of
\mathcal{P}_{k}^{K}(\tau)
for every

\tau\in\text{\rm H}_{k}^{K}
. That is, it is possible to determine the
\text{\rm L}^{2}(K)
-orthogonal projector
for elements in the virtual space. Indeed, it is sufficient to verify that the

2.17
) can be calculated in these cases.
To do that, notice from the definitions of

and

(cf. (
2.1
)), that it is possible to determine the value of

using the identity:

\int_{K}\text{\rm div}(\tau)\,q\ =\ -\int_{K}\tau\cdot\nabla q\ +\ \int_{\partial K}\tau\cdot\text{\boldmath$n$}\,q\qquad\forall\,q\in\textrm{P}_{k}(K)\,.

(2.18)

Moreover, given
\text{\rm q}\in\text{\rm P}_{k}(K)
, it is well known that there exist unique

\text{\rm q}^{\perp}\in(\nabla\textrm{P}_{k+1}(K))^{\perp}\cap\text{\rm P}_{k}(K)
and
\widetilde{q}\in\textrm{P}_{k+1}(K)
,
such that:
\text{\rm q}=\text{\rm q}^{\perp}+\nabla\widetilde{q}
.
In this sense, it follows that:

\int_{K}\tau\cdot\text{\rm q}\ =\ \int_{K}\tau\cdot\text{\rm q}^{\perp}\,+\,\int_{K}\tau\cdot\nabla\widetilde{q}\ =\ \int_{K}\tau\cdot\text{\rm q}^{\perp}\,-\,\int_{K}\widetilde{q}\,\text{\rm div}(\tau)\,+\,\int_{\partial K}\tau\cdot\text{\boldmath$n$}\,\widetilde{q}\,,

(2.19)

which, in accordance with (
2.18
) and the definition of
m_{\text{\rm q},\text{\rm rot}}^{H}(\tau)

(see (
2.1
)), allow the required calculation.

Finally, we also consider the
\mathbb{L}^{2}(K)
-orthogonal projection
\text{\boldmath$\mathcal{P}$}_{k}^{K}:\mathbb{L}^{2}(K)\rightarrow\mathbb{P}_{k}(K)
.
In other words,
\text{\boldmath$\mathcal{P}$}_{k}^{K}
is the operator
\mathcal{P}_{k}^{K}
(cf. (
2.17
)) acting
on each row of a tensor of
\mathbb{L}^{2}(K)
, which according to the foregoing discussion
it quite simple to see that
\text{\boldmath$\mathcal{P}$}_{k}^{K}(\text{\boldmath$\tau$})
can be explicitly calculated for each

\text{\boldmath$\tau$}\in\mathbb{H}_{k}^{K}
.

-conforming subspace, associated bilinear form and projection

We follow the previous section by defining the following local virtual

(see, e.g.,

\quad=\ \displaystyle\sum_{e\in\partial K}\frac{h_{K}}{\alpha+\beta+2}\int_{e}\left(\frac{x-x_{K}}{h_{K}}\right)^{\alpha}\left(\frac{y-y_{K}}{h_{K}}\right)^{\beta}\bigg[\left(\frac{x-x_{K}}{h_{K}}\right)n_{1}^{e}\,+\,\left(\frac{y-y_{K}}{h_{K}}\right)n_{2}^{e}\bigg]\,,\end{array}

where

3.4
The
L^{2}(K)
-orthogonal projection for elements of
V_{k}^{K}

Similarly to the previous section, we now aim to introduce the matrices
associated with the projection
P_{k}^{K}:L^{2}(K)\to\textrm{P}_{k}(K)
for elements of
the canonical basis of
V_{k}^{K}
, and the projection
\text{\boldmath$\mathcal{P}$}_{k}^{K}:\mathbb{L}^{2}(K)\to\mathbb{P}_{k}(K)

for the gradient of elements of the canonical basis of
\text{\rm V}_{k}^{K}
. Indeed,
we begin by considering the matrix of coefficients of the elements of

\{\psi^{K}_{i}\}_{i=1}^{n_{k}^{V}}
under the operator
P_{k}^{K}
, which employing
(
2.29
) is given by:

\displaystyle\text{\rm P}_{V}

\displaystyle:=

\displaystyle\left[\int_{K}\varphi_{i}^{K}\,\varphi_{j}^{K}\right]^{-1}\left[\int_{K}\varphi_{i}^{K}\,\psi^{K}_{j}\right]

\displaystyle=

\displaystyle\text{\rm M}_{\text{mass},K}^{-1}\,\left[\begin{array}[]{c}\left[\begin{array}[]{c:c}\text{\rm 0}_{m_{0}\times((k+1)d_{K})}\hfil\lx@intercol\vrule\lx@add@cssclass&\;\text{\rm I}_{m_{0}}\end{array}\right]\\
\\[-8.61108pt]
\hline\cr\\[-8.61108pt]
\widetilde{\text{\rm U}}\,\text{\rm R}^{K}\end{array}\right]\in\text{\rm R}^{m\times n_{k}^{V}}\,,

where the matrix
\widetilde{\text{\rm U}}\in\text{\rm R}^{(m-m_{0})\times m_{1}}
is the submatrix
of
\text{\rm M}_{\text{mass},K}^{(k+1)}
, whose index range is
[m_{0}+1,m]\times[1,m_{1}]
. Now, we follow (
2.28
)
and let
\mathcal{D}\text{\rm P}_{V}\in\text{\rm R}^{(4m)\times(2n_{k}^{V})}
be the matrix of coefficients of the elements of

\{\nabla\vec{\text{\boldmath$\psi$}}^{K}_{i}\}_{i=1}^{2n_{k}^{V}}
under the operator
\text{\boldmath$\mathcal{P}$}_{k}^{K}
. Hence, we deduce that:

\displaystyle\mathcal{D}\text{\rm P}_{V}\!\!\!

\displaystyle:=

\displaystyle\left[\int_{K}\Phi_{i}^{K}:\Phi_{j}^{K}\right]^{-1}\left[\int_{K}\Phi_{i}^{K}:\nabla\vec{\text{\boldmath$\psi$}}^{K}_{j}\right]

\displaystyle=

\displaystyle\textrm{kron}\left(\text{\rm I}_{4},\,\text{\rm M}_{\text{mass},K}^{-1}\right)\textrm{kron}\left(\text{\rm I}_{2},\,\left[\int_{K}\text{\boldmath$\varphi$}_{i}^{K}\cdot\nabla\psi^{K}_{j}\right]\right)

\displaystyle=

\displaystyle\textrm{kron}\left(\text{\rm I}_{4},\,\text{\rm M}_{\text{mass},K}^{-1}\right)\textrm{kron}\left(\text{\rm I}_{2},\,{-}\left[\int_{K}\text{\rm div}(\text{\boldmath$\varphi$}_{i}^{K})\,P_{k}^{K}(\psi^{K}_{j})\right]\,+\,\left[\int_{\partial K}(\text{\boldmath$\varphi$}_{i}^{K}\cdot\text{\boldmath$n$})\,\psi^{K}_{j}\right]\right)

\displaystyle=

\displaystyle\textrm{kron}\left(\text{\rm I}_{4},\,\text{\rm M}_{\text{mass},K}^{-1}\right)\textrm{kron}\left(\text{\rm I}_{2},\,{-}\left[\int_{K}\text{\rm div}(\text{\boldmath$\varphi$}_{i}^{K})\,\varphi_{j}^{K}\right]\text{\rm P}_{V}\,+\!\sum_{e\in\partial K}\textrm{kron}\left(\text{\boldmath$n$}^{e},\,\left[\int_{e}\varphi_{i}^{K}\,\mathcal{L}_{j}^{e}\right]\!\text{\rm C}_{L}^{e}\right)\right)\!,

where
\text{\boldmath$n$}^{e}:=(n_{1}^{e},n_{2}^{e})^{\text{\tt t}}
is the unit outward normal at
e
.
In addition, we introduce the following matrices:

\text{\rm P}_{\text{div}}\ :=\ \left[\int_{K}\text{\rm div}(\text{\boldmath$\varphi$}_{i}^{K})\,\varphi_{j}^{K}\right]\ =\ \left[\begin{array}[]{c}\text{\rm 0}_{1\times m}\\[-8.61108pt]
\\
\hline\cr\\[-8.61108pt]
\text{\rm D}_{x}\\[-8.61108pt]
\\
\hline\cr\\[-8.61108pt]
\text{\rm 0}_{1\times m}\\[-8.61108pt]
\\
\hline\cr\\[-8.61108pt]
\text{\rm D}_{y}\end{array}\right]\in\text{\rm R}^{(2m)\times m}\,,

and

\text{\rm P}_{L}^{e}\ :=\ \left[\int_{e}\varphi_{i}^{K}\,\mathcal{L}_{j}^{e}\right]\ =\ \left[h_{e}\int_{0}^{1}\varphi_{i}^{K}((1-t)\,\text{\rm v}_{1}+t\,\text{\rm v}_{2})\,\widehat{\mathcal{L}}_{j}(t)\,\text{d}t\right]\in\text{\rm R}^{m\times(k+2)}\,,

where

is the submatrix of
\text{\rm M}_{0,K}
with
index range
[1,m-1]\times[1,m]
, whereas
\text{\rm D}_{y}\in\text{\rm R}^{(m-1)\times m}

is the submatrix of
\text{\rm M}_{0,K}
with index range

Moreover, once again,
\text{\rm v}_{1}
and
\text{\rm v}_{2}
are the oriented vertices
of
e
. Then, according to the previous analysis, we conclude that

\mathcal{D}\text{\rm P}_{V}\ =\ \textrm{kron}\left(\text{\rm I}_{4},\,\text{\rm M}_{\text{mass},K}^{-1}\right)\textrm{kron}\left(\text{\rm I}_{2},\,{-}\text{\rm P}_{\text{div}}\,\text{\rm P}_{V}\,+\,\sum_{e\in\partial K}\textrm{kron}\left(\text{\boldmath$n$}^{e},\,\text{\rm P}_{L}^{e}\,\text{\rm C}_{L}^{e}\right)\right)\in\text{\rm R}^{(4m)\times(2n_{k}^{V})}\,.

5
A particular example: the Navier-Stokes problem

In this section we show how to use the previously defined discrete operators in
a particular formulation. More precisely, we present some specific aspects
on the computational implementation of a mixed virtual element method
for the two-dimensional pseudostress-velocity formulation of the Navier-Stokes
equations with Dirichlet boundary conditions. Indeed, the formulation used
below was originally proposed and analyzed in
[
27
]
. Here we
recall the continuous and discrete formulations, and propose an algorithm
for the assembly of the associated global linear system for the Newton’s
iteration. Finally, a numerical example illustrating the performance
of the mixed-VEM scheme and confirming these theoretical rates is presented.

5.1
The continuous problem

We begin, recalling from
[
27
, Section 2]
, the boundary value problem
of interest. Indeed, letting
\Omega\subset\text{\rm R}^{2}
be a bounded polygonal domain with
boundary
\Gamma
, we consider the stationary Navier-Stokes equations with nonhomogeneous
Dirichlet boundary conditions. More precisely, given a volume force
\text{\rm f}\in\text{\rm L}^{2}(\Omega)

and a Dirichlet datum
\text{\rm g}\in\text{\rm H}^{1/2}(\Gamma)
, we seek a vector field (the velocity)

u
and a scalar field (the pressure)
p
of a fluid on
\Omega
, such that

\displaystyle\begin{array}[]{c}-\mu\Delta\text{\rm u}\,+\,(\nabla\text{\rm u})\,\text{\rm u}\,+\,\nabla p\ =\ \text{\rm f}\quad{\rm in}\quad\Omega\,,\qquad\text{\rm div}(\text{\rm u})\ =\ 0\quad{\rm in}\quad\Omega\,,\\[4.30554pt]
\text{\rm u}\ =\ \text{\rm g}\quad{\rm on}\quad\Gamma\,,{\qquad\hbox{and}\qquad}\displaystyle\int_{\Omega}p\ =\ 0\,,\end{array}

where
\mu>0
is the viscosity constant. In addition, it is important to recall
here that the incompressibility condition given by the second equation of
(
5.1
), establishes that the datum
g
satisfies the compatibility
condition
\int_{\Gamma}\text{\rm g}\cdot\text{\boldmath$n$}=0
, where
n
stands for the unit outward
normal at
\Gamma
.

On the other hand, defining the constant
c:=-\frac{1}{2|\Omega|}\|\text{\rm u}\|_{0,\Omega}^{2}

and
\text{\rm I}_{2}
the identity matrix of
\text{\rm R}^{2\times 2}
, we introduce the pseudostress tensor
(see
[
18
,
19
,
23
]
)

\text{\boldmath$\sigma$}\ :=\ \mu\nabla\text{\rm u}\,-\,\text{\rm u}\otimes\text{\rm u}\,-\,(p+c)\,\text{\rm I}_{2}\quad{\rm in}\quad\Omega\,,

(5.4)

which allows us to arrive at the equivalent system: Find the pseudostress
\sigma
and the velocity

u
such that

\begin{array}[]{c}\text{\boldmath$\sigma$}^{\text{\tt d}}\ =\ \mu\nabla\text{\rm u}\,-\,(\text{\rm u}\otimes\text{\rm u})^{\text{\tt d}}\quad{\rm in}\quad\Omega\,,\qquad-\textrm{\bf div}(\text{\boldmath$\sigma$})\ =\ \text{\rm f}\quad{\rm in}\quad\Omega\,,\\[4.30554pt]
\text{\rm u}\ =\ \text{\rm g}\quad{\rm on}\quad\Gamma\,,{\qquad\hbox{and}\qquad}\displaystyle\int_{\Omega}\text{\rm tr}(\text{\boldmath$\sigma$})\ =\ 0\,,\end{array}

(5.5)

where the pseudostress variable has eliminated the pressure from the original model
(
5.1
), which can be recover through the postprocessing formula:

p\ =\ -\frac{1}{2}\,\big\{\text{\rm tr}(\text{\boldmath$\sigma$})\,+\,\text{\rm tr}(\text{\rm u}\otimes\text{\rm u})\big\}\,-\,c\quad{\rm in}\quad\Omega\,,

which is obtained from (
5.4
) and the incompressibility condition.

Next, we let
\mathbb{H}_{0}(\textrm{\bf div};\Omega):=\left\{\text{\boldmath$\tau$}\in\mathbb{H}(\textrm{\bf div};\Omega)\,:\,\int_{\Omega}\text{\rm tr}(\text{\boldmath$\tau$})=0\right\}
,
and recall from
[
27
, Section 2]
the following redundant terms:

\begin{array}[]{rcll}\displaystyle\kappa_{1}\int_{\Omega}\textrm{\bf div}(\text{\boldmath$\sigma$})\cdot\textrm{\bf div}(\text{\boldmath$\tau$})&=&\displaystyle-\kappa_{1}\int_{\Omega}\text{\rm f}\cdot\textrm{\bf div}(\text{\boldmath$\tau$})&\forall\ \text{\boldmath$\tau$}\in\mathbb{H}_{0}(\textrm{\bf div};\Omega)\,,\\[8.61108pt]
\displaystyle\kappa_{2}\int_{\Omega}\Big\{\mu\nabla\text{\rm u}-\text{\boldmath$\sigma$}^{\text{\tt d}}-(\text{\rm u}\otimes\text{\rm u})^{\text{\tt d}}\Big\}:\nabla\text{\rm v}&=&0&\forall\ \text{\rm v}\in\text{\rm H}^{1}(\Omega)\,,\\[8.61108pt]
\displaystyle\kappa_{3}\int_{\Gamma}\text{\rm u}\cdot\text{\rm v}&=&\displaystyle\kappa_{3}\int_{\Gamma}\text{\rm g}\cdot\text{\rm v}&\forall\ \text{\rm v}\in\text{\rm H}^{1}(\Omega)\,,\end{array}

where, according to
[
27
, Theorem 2.1]
, the parameters
\kappa_{1},\kappa_{2},\kappa_{3}

must satisfy that
\kappa_{1},\kappa_{3}>0
and
0<\kappa_{2}<2\mu
. Then, we consider the
continuous formulation of (
5.5
) introduced in
[
27
, Section 2]
,
whose well-posedness has been established in
[
27
, Theorem 2.1]
. More precisely, we
seek
\vec{\text{\boldmath$\sigma$}}:=(\text{\boldmath$\sigma$},\text{\rm u})\in\mathbbm{X}:=\mathbb{H}_{0}(\textrm{\bf div};\Omega)\times\text{\rm H}^{1}(\Omega)
such that

a(\vec{\text{\boldmath$\sigma$}},\vec{\text{\boldmath$\tau$}})\ +\ b(\text{\rm u};\vec{\text{\boldmath$\sigma$}},\vec{\text{\boldmath$\tau$}})\ =\ F(\vec{\text{\boldmath$\tau$}})\qquad\forall\ \vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}\,,

(5.6)

where
a:\mathbbm{X}\times\mathbbm{X}\to\text{\rm R}
is the bilinear form

\begin{array}[]{rcl}a(\vec{\text{\boldmath$\zeta$}},\vec{\text{\boldmath$\tau$}})&:=&\displaystyle\int_{\Omega}\text{\boldmath$\zeta$}^{\text{\tt d}}:\text{\boldmath$\tau$}^{\text{\tt d}}\,+\,\kappa_{1}\int_{\Omega}\textrm{\bf div}(\text{\boldmath$\zeta$})\cdot\textrm{\bf div}(\text{\boldmath$\tau$})\,+\,\kappa_{2}\mu\int_{\Omega}\nabla\text{\rm w}:\nabla\text{\rm v}\,+\,\kappa_{3}\int_{\Gamma}\text{\rm w}\cdot\text{\rm v}\\[8.61108pt]
&&\displaystyle-\ \mu\int_{\Omega}\text{\rm v}\cdot\textrm{\bf div}(\text{\boldmath$\zeta$})\,+\,\mu\int_{\Omega}\text{\rm w}\cdot\textrm{\bf div}(\text{\boldmath$\tau$})\,-\,\kappa_{2}\int_{\Omega}\text{\boldmath$\zeta$}^{\text{\tt d}}:\nabla\text{\rm v}\end{array}

for all
\vec{\text{\boldmath$\zeta$}}:=(\text{\boldmath$\zeta$},\text{\rm w})
,
\vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}
,

F:\mathbbm{X}\to\text{\rm R}
is the linear functional

F(\vec{\text{\boldmath$\tau$}})\ :=\ \mu\langle{\text{\boldmath$\tau$}\text{\boldmath$n$},\text{\rm g}}\rangle_{\Gamma}\,-\,\kappa_{1}\int_{\Omega}\text{\rm f}\cdot\textrm{\bf div}(\text{\boldmath$\tau$})\,+\,\mu\int_{\Omega}\text{\rm f}\cdot\text{\rm v}\,+\,\kappa_{3}\int_{\Gamma}\text{\rm g}\cdot\text{\rm v}\,,

for all
\vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}
, and given
\text{\rm z}\in\text{\rm H}^{1}(\Omega)
,

b(\text{\rm z};\,\cdot\,,\,\cdot\,):\mathbbm{X}\times\mathbbm{X}\to\text{\rm R}
is the bilinear form

b(\text{\rm z};\vec{\text{\boldmath$\zeta$}},\vec{\text{\boldmath$\tau$}})\ :=\ \int_{\Omega}(\text{\rm w}\otimes\text{\rm z})^{\text{\tt d}}:\big\{\text{\boldmath$\tau$}-\kappa_{2}\nabla\text{\rm v}\big\}\,,

for all
\vec{\text{\boldmath$\zeta$}}:=(\text{\boldmath$\zeta$},\text{\rm w})
,
\vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}
.

5.2

Now, given an integer
k\geq 0
, we consider the virtual element subspace

\mathbbm{X}_{h}
of
\mathbbm{X}:=\mathbb{H}_{0}(\textrm{\bf div};\Omega)\times\text{\rm H}^{1}(\Omega)

given by

\mathbbm{X}_{h}\ :=\ \Big\{(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}\,:\quad\text{\boldmath$\tau$}|_{K}\in\mathbb{H}_{k}^{K}\;\text{ and }\;\text{\rm v}|_{K}\in\text{\rm V}_{k}^{K}\quad\forall\ K\in\mathcal{T}_{h}\Big\}\,,

(5.7)

where, for each

, the virtual subspaces
\mathbb{H}_{k}^{K}
and
\text{\rm V}_{k}^{K}

are defined in (
2.9
) and (
2.24
), respectively.
In turn, we now aim to define the nonlinear mixed virtual element scheme
associated with (
5.6
) and introduced in
[
27
, Section 5]
.
That is, we seek
\vec{\text{\boldmath$\sigma$}}_{h}:=(\text{\boldmath$\sigma$}_{h},\text{\rm u}_{h})\in\mathbbm{X}_{h}
such that

\displaystyle:=

\displaystyle+\ \kappa_{1}\int_{K}\textrm{\bf div}(\text{\boldmath$\zeta$})\cdot\textrm{\bf div}(\text{\boldmath$\tau$})\ +\ \mu\int_{K}\text{\rm w}\cdot\textrm{\bf div}(\text{\boldmath$\tau$})\ -\ \mu\int_{K}\text{\rm v}\cdot\textrm{\bf div}(\text{\boldmath$\zeta$})

\displaystyle-\ \kappa_{2}\int_{K}\big[\text{\boldmath$\mathcal{P}$}_{k}^{K}(\text{\boldmath$\zeta$})\big]^{\text{\tt d}}:\text{\boldmath$\mathcal{P}$}_{k}^{K}(\nabla\text{\rm v})\ +\ \kappa_{2}\mu\int_{K}\nabla\mathcal{R}_{k}^{K}(\text{\rm w}):\nabla\mathcal{R}_{k}^{K}(\text{\rm v})

\displaystyle+\ \mathcal{S}_{V}^{K}\big(\text{\rm w}-\mathcal{R}_{k}^{K}(\text{\rm w}),\text{\rm v}-\mathcal{R}_{k}^{K}(\text{\rm v})\big)\ +\ \kappa_{3}\int_{\partial K\cap\Gamma}\text{\rm w}\cdot\text{\rm v}\Bigg\}

for all
\vec{\text{\boldmath$\zeta$}}:=(\text{\boldmath$\zeta$},\text{\rm w})

\vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}_{h}

for all
\vec{\text{\boldmath$\tau$}}:=(\text{\boldmath$\tau$},\text{\rm v})\in\mathbbm{X}_{h}
, and given

such
that

for all

Once Newton’s iteration is over, we can use the discrete operators described

\text{\boldmath$\beta$}^{K}\\

,
\text{\rm u}_{h}^{(s)}
and

\text{\boldmath$\sigma$}^{(s)}_{h}\big|_{K}\ =\ \sum_{i=1}^{2n_{k}^{H}}\alpha_{i}^{K}\,\vec{\text{\boldmath$\Psi$}}^{K}_{i}{\qquad\hbox{and}\qquad}\text{\rm u}^{(s)}_{h}\big|_{K}\ =\ \sum_{i=1}^{2n_{k}^{V}}\beta_{i}^{K}\,\vec{\text{\boldmath$\psi$}}^{K}_{i}\,,

\text{\boldmath$\alpha$}^{K}=(\alpha_{1}^{K},\ldots,\alpha_{2n_{k}^{H}}^{K})^{\text{\tt t}}

We begin by recalling from (

stands for the total number of
degrees of freedom (unknowns) of (

errors are defined by
