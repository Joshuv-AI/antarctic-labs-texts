Non-jumping Turán densities of hypergraphs
Zilong Yan, Yuejian Peng

Abstract
A real number α ∈ [ 0 , 1 ) \alpha\in[0,1) is a jump for an integer r ≥ 2 r\geq 2 if there exists c > 0 c>0 such that no number in ( α , α + c ) (\alpha,\alpha+c) can be the Turán density of a family of r r -uniform graphs. A classical result of Erdős and Stone [ 7 ] implies that that every number in [ 0 , 1 ) [0,1) is a jump for r = 2 r=2 . Erdős [ 5 ] also showed that every number in [ 0 , r ! / r r ) [0,r!/r^{r}) is a jump for r ≥ 3 r\geq 3 and asked whether every number in [ 0 , 1 ) [0,1) is a jump for r ≥ 3 r\geq 3 . Frankl and Rödl [ 8 ] gave a negative answer by showing a sequence of non-jumps for every r ≥ 3 r\geq 3 . After this, Erdős modified the question to be whether r ! r r \frac{r!}{r^{r}} is a jump for r ≥ 3 r\geq 3 ? What’s the smallest non-jump? Frankl, Peng, Rödl and Talbot [ 9 ] showed that 5 ​ r ! 2 ​ r r {5r!\over 2r^{r}} is a non-jump for r ≥ 3 r\geq 3 . Baber and Talbot [ 1 ] showed that every α ∈ [ 0.2299 , 0.2316 ) ∪ [ 0.2871 , 8 27 ) \alpha\in[0.2299,0.2316)\cup[0.2871,\frac{8}{27}) is a jump for r = 3 r=3 . Pikhurko [ 14 ] showed that the set of all possible Turán densities of r r -uniform graphs has cardinality of the continuum for r ≥ 3 r\geq 3 . However, whether r ! r r \frac{r!}{r^{r}} is a jump for r ≥ 3 r\geq 3 remains open, and 5 ​ r ! 2 ​ r r \frac{5r!}{2r^{r}} has remained the known smallest non-jump for r ≥ 3 r\geq 3 . In this paper, we give a smaller non-jump by showing that 54 ​ r ! 25 ​ r r {54r!\over 25r^{r}} is a non-jump for r ≥ 3 r\geq 3 . Furthermore, we give infinitely many irrational non-jumps for every r ≥ 3 r\geq 3 . Keywords : Jumping number, Turán density, hypergraph

For a finite set

If

\Pi_{fin}^{r}=\{\pi(\mathcal{F}):\mathcal{F}{\rm\ is\ a\ finite\ family\ of\ }r{\rm-uniform\ graphs},\}

and

\Pi_{t}^{r}=\{\pi(\mathcal{F}):\mathcal{F}{\rm\ is\ a\ family\ of\ }r{\rm-uniform\ graphs\ and}\ |\mathcal{F}|\leq t\}.

Clearly,

Finding good estimation for Turán densities in hypergraphs (
r\geq 3
) is believed to be one of the most challenging problems in extremal combinatorics. The following concept concerns the accumulation points of the set

Definition 1.1

A real number

2.1
Karush-Kuhn-Tucker Conditions

Let us consider the optimisation problem:

subject to

(3.1)

where

for all

whose

. We say that KKT conditions hold at

if there exist

such that

1.

\nabla{f(x^{*})}=\sum_{i=1}^{m}\lambda_{i}\nabla{g_{i}(x^{*})},

2.

\lambda_{i}\geq 0
for
i=1,\dots,m,

3.

\lambda_{i}g_{i}(x^{*})=0
for
i=1,\dots,m.

We call the constraints linear if

are all affine functions.

Theorem 2.1

(
[
3
]
,
[

]
)
If the constraints of (3.1) are linear, then any optimal solution to (3.1) must satisfy the KKT conditions.
