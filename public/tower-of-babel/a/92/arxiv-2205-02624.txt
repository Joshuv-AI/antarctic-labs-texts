Correspondence Theory for Generalized Modal Algebras
Zhiguang Zhao

Abstract
In the present paper, we give a systematic study of the correspondence theory of generalized modal algebras and generalized modal spaces, in the spirit of [ 3 , 6 ] . The special feature of the present paper is that in the proof of the (right-handed) topological Ackermann lemma, the admissible valuations are not the clopen valuations anymore, but values in the set 𝒟 𝒦 ​ ( X ) \mathcal{D}_{\mathcal{K}}(X) which are only closed and satisfy additional properties, not necessarily open. This situation is significantly different from existing settings using Stone/Priestley-like dualities, where all admissible valuations are clopen valuations. Keywords: generalized modal algebra, generalized modal space, duality theory, correspondence theory

2.3
Topological Duality between Generalized Boolean Algebras and Generalized Stone Spaces

If

is a basis for a topology

Let

and
(Ul(\mathcal{D}_{\mathcal{K}}(X)),\mathcal{K}_{\mathcal{D}_{\mathcal{K}}(X)})

The First-order Correspondence Language and the Standard Translation

In the first-order correspondence language, we have a binary predicate symbol
R
corresponding to the binary relation in the generalized modal space, a set of unary predicate symbols
P
corresponding to each propositional variable
p

Definition 9
.

The standard translation of the expanded language is defined as follows:

ST_{x}(p):=Px

ST_{x}(\varphi\land\psi):=ST_{x}(\varphi)\land ST_{x}(\psi)

ST_{x}(\bot):=\bot

ST_{x}(\varphi\lor\psi):=ST_{x}(\varphi)\lor ST_{x}(\psi)

ST_{x}(\top):=\top

ST_{x}(\varphi\to\psi):=ST_{x}(\varphi)\to ST_{x}(\psi)

ST_{x}(\mathbf{i}):=x=i

ST_{x}(\Box\varphi):=\forall y(Rxy\to ST_{y}(\varphi))

ST_{x}(\mathbf{m}):=x\neq m

ST_{x}(\Diamondblack\varphi):=\exists y(Ryx\land ST_{y}(\varphi))

ST(\varphi\leq\psi):=\forall x(ST_{x}(\varphi)\to ST_{x}(\psi))

ST(\varphi_{1}\leq\psi_{1}\ \&\ \ldots\ \&\ \varphi_{n}\leq\psi_{n}\ \Rightarrow\ \varphi\leq\psi):=ST(\varphi_{1}\leq\psi_{1})\land\ldots\land ST(\varphi_{n}\leq\psi_{n})\to ST(\varphi\leq\psi)

5
Inductive Inequalities for Generalized Modal Algebras

In this section, we define inductive inequalities for generalized modal algebras and generalized modal spaces.

We first define positive formulas with propositional variables in
A\subseteq\mathsf{Prop}
as follows:

\mathsf{POS}_{A}::=p\mid\top\mid\Box\mathsf{POS}\mid\mathsf{POS}\land\mathsf{POS}\mid\mathsf{POS}\lor\mathsf{POS}

where
p\in A\subseteq\mathsf{Prop}
.

Then we define the dependence order on propositional variables as any irreflexive and transitive binary relation
<_{\Omega}
on them. Then we define the PIA formulas with main variable
p
as follows:

\mathsf{PIA}_{p}::=p\mid\top\mid\Box\mathsf{PIA}_{p}\mid\mathsf{POS}_{A_{p}}\to\mathsf{PIA}_{p}

where
A_{p}=\{q\in\mathsf{Prop}\mid q<_{\Omega}p\}
in
\mathsf{PIA}_{p}
. Then we define the inductive antecedent as follows:

\mathsf{Ant}::=\mathsf{PIA}_{p}\mid\mathsf{Ant}\land\mathsf{Ant}\mid\mathsf{Ant}\lor\mathsf{Ant}

where
p\in\mathsf{Prop}
. Then we define the inductive succedent as follows:

\mathsf{Suc}::=p\mid\top\mid\mathsf{PIA}_{q}\to\mathsf{Suc}\mid\Box\mathsf{Suc}\mid\mathsf{Suc}\land\mathsf{Suc}\mid\mathsf{Suc}\lor\mathsf{Suc}

where
p,q\in\mathsf{Prop}
.

Finally, an
\Omega
-inductive inequality
is an inequality of the form
\mathsf{Ant}\leq\mathsf{Suc}
where each propositional variable in the inequality both occur positively and negatively
2
2

2

We say that an occurrence of a propositional variable
p
in a formula
\varphi
is
positive
, if it is in the scope of an even number of the left-handside of implications, and
negative
if it is in the scope of an odd number of the left-handside of implications. For example, in
(p\to q)\to r
,
p
is positive because it is in the scope of 2 of the left-handside of implications, and
r
is also positive (in the scope of 0), and
q
is negative (in the scope of 1).
. An inductive inequality is an
\Omega
-inductive inequality for some
\Omega
.

6
Algorithm

In the present section, we define the algorithm
\mathsf{ALBA}
which compute the first-order correspondence of the input inequality in the style of
[
9
]
. The algorithm
\mathsf{ALBA}
proceeds in three stages. Firstly,
\mathsf{ALBA}
receives an inequality
\mathsf{Ant}\leq\mathsf{Suc}
as input.

1.

Preprocessing and First approximation
:

(a)

We apply the following distribution rules exhaustively:

•

In
\mathsf{Ant}
, rewrite every subformula of the former form into the latter form:

–

\alpha\land(\beta\lor\gamma)
,
(\alpha\land\beta)\lor(\alpha\land\gamma)

–

(\beta\lor\gamma)\land\alpha
,
(\beta\land\alpha)\lor(\gamma\land\alpha)

•

In
\mathsf{Suc}
, rewrite every subformula of the former form into the latter form:

–

\alpha\to\beta\land\gamma
,
(\alpha\to\beta)\land(\alpha\to\gamma)

–

\Box(\alpha\land\beta)
,
\Box\alpha\land\Box\beta

–

\alpha\lor(\beta\land\gamma)
,
(\alpha\lor\beta)\land(\alpha\lor\gamma)

–

(\beta\land\gamma)\lor\alpha
,
(\beta\lor\alpha)\land(\gamma\lor\alpha)

(b)

Apply the splitting rules:

\alpha\leq\beta\ \ \ \alpha\leq\gamma\alpha\leq\beta\land\gamma\qquad\alpha\leq\gamma\ \ \ \beta\leq\gamma\alpha\lor\beta\leq\gamma

Now for each obtained inequality
\varphi_{i}\leq\psi_{i}
, We apply the following first-approximation rule:

\mathbf{i}_{0}\leq\varphi_{i}\ \&\ \psi_{i}\leq\mathbf{m}_{0}\Rightarrow\ \mathbf{i}_{0}\leq\mathbf{m}_{0}\varphi_{i}\leq\psi_{i}

Now we focus on each set of the antecedent inequalities
\{\mathbf{i}_{0}\leq\varphi_{i},\psi_{i}\leq\mathbf{m}_{0}\}
, which we call a
system
.

2.

The reduction-elimination cycle
:

In this stage, for each
\{\mathbf{i}_{0}\leq\varphi_{i},\psi_{i}\leq\mathbf{m}_{0}\}
, we apply the following rules to eliminate all the propositional variables:

(a)

Splitting rules:

\alpha\leq\beta\ \ \ \alpha\leq\gamma\alpha\leq\beta\land\gamma\qquad\alpha\leq\gamma\ \ \ \beta\leq\gamma\alpha\lor\beta\leq\gamma

(b)

Residuation rules:

\alpha\leq\Box\beta

\Diamondblack\alpha\leq\beta

\alpha\leq\beta\to\gamma

\alpha\land\beta\leq\gamma

(c)

Approximation rules:

\alpha\leq\mathbf{n}\ \ \ \Box\mathbf{n}\leq\mathbf{m}\Box\alpha\leq\mathbf{m}\qquad\mathbf{j}\leq\alpha\ \ \ \ \ \ \ \beta\leq\mathbf{n}\ \ \ \ \ \ \ \mathbf{j}\rightarrow\mathbf{n}\leq\mathbf{m}\alpha\rightarrow\beta\leq\mathbf{m}

The nominals and conominals introduced by the approximation rules must not occur in the system before applying the rule.

(d)

Deleting rule: delete inequalities of the form
\alpha\leq\top
.

(e)

The right-handed Ackermann rule.
3
3

3

Here we only have the right-handed Ackermann rule, because we could only guarantee the right-handed topological Ackermann lemma, due to the fact that admissible valuations are not clopen anymore, but only closed.
This rule eliminates propositional variables and is the core of the algorithm, the other rules are aimed at reaching a shape in which the rule can be applied. Notice that an important feature of this rule is that it is executed on the whole set of inequalities, and not on a single inequality.

The system

\left\{\begin{array}[]{ll}\theta_{1}\leq p\\
\vdots\\
\theta_{n}\leq p\\
\eta_{1}\leq\iota_{1}\\
\vdots\\
\eta_{m}\leq\iota_{m}\\
\end{array}\right.

is replaced by

\left\{\begin{array}[]{ll}\eta_{1}((\theta_{1}\lor\ldots\lor\theta_{n})/p)\leq\iota_{1}((\theta_{1}\lor\ldots\lor\theta_{n})/p)\\
\vdots\\
\eta_{m}((\theta_{1}\lor\ldots\lor\theta_{n})/p)\leq\iota_{m}((\theta_{1}\lor\ldots\lor\theta_{n})/p)\\
\end{array}\right.

where:

i.

p
does not occur in
\theta_{1},\ldots,\theta_{n}
;

ii.

Each
\eta_{i}
is positive, and each
\iota_{i}
negative in
p
, for
1\leq i\leq m
.

3.

Output
: If in the previous stage, for some systems, the algorithm gets stuck, i.e. some propositional variables cannot be eliminated, then the algorithm halts and output “failure”. Otherwise, each initial system after the first approximation has been reduced to a set of pure inequalities Reduce
(\mathbf{i}_{0}\leq\varphi_{i},\psi_{i}\leq\mathbf{m}_{0})

. Then we can use the conjunction of the standard translations of the quasi-inequalities to obtain the first-order correspondence (notice that in the standard translation of each quasi-inequality, we need to universally quantify over all the individual variables).
