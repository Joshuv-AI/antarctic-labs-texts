Abstract
We propose a method to obtain the optimal weight function of 9 paths in (3+1)D space-time whose length is less than or equal to 2 × ( 6 + 2 ) 2\times(6+2) lattice units. The factor 2 comes from inclusion of opposite direction path or time reversed paths. There are 2 × 2 2\times 2 time shifts, which we assume that they can be regarded as stochastic Markov processes. We prepare the input 9D vector 𝐗 {\bf X} and a 9 × 9 9\times 9 matrix 𝐖 {\bf W} and a bias vector 𝐛 {\bf b} , and consider affine transformations 𝐙 ( h ) = 𝐗 ( i ​ n ) ​ 𝐖 ( h ) ​ T + 𝐛 ( h ) {\bf Z}^{(h)}={\bf X}^{(in)}{\bf W}^{(h)T}+{\bf b}^{(h)} and 𝐀 ( h ) = σ ⁡ ( 𝐙 ( h ) ) {\bf A}^{(h)}=\sigma({\bf Z}^{(h)}) from an input layer to a hidden layer, the hidden layer to another hidden layer and from the hidden layer to an output layer, using the transformation 𝐙 ( x ) = 𝐀 ( h ) ​ 𝐖 ( o ​ u ​ t ) ​ T + 𝐛 ( x ) {\bf Z}^{(x)}={\bf A}^{(h)}{\bf W}^{(out)T}+{\bf b}^{(x)} and 𝐀 ( x ) = σ ⁡ ( 𝐙 ( x ) ) {\bf A}^{(x)}=\sigma({\bf Z}^{(x)}) . By choosing the matrix 𝐖 {\bf W} a diagonal matrix, and introducing the information of action of the 9 paths, a simple Monte Carlo simulation yields actions on a 2D plane spanned by e 1 , e 2 e_{1},e_{2} for a fixed u 2 = j 2 ​ e 2 u_{2}=j_{2}e_{2} as a function of u 1 = j 1 ​ e 1 u_{1}=j_{1}e_{1} . The action at high momentum region has small fluctuations, but at small momentum region, has large fluctuation. Generalizing 𝐖 \bf W including mixing of paths, we search the optimal weight function using the Machine Learning (ML) techniques. 4.1
Elman Recurrent Neural Network method

When there are two vectors
{\bf x}^{(t)}
and
{\bf h}^{(t-1)}
as the input, the optimal bias vector
{\bf b}_{h}
is hard to define.
In the Elman Recurrent Neural Network (ERNN)
[
30
]
, the bias vector for
{\bf x}
denoted as
{\bf b}_{x}
, and that for
{\bf h}
denoted as
{\bf b}_{h}
are calculated using
\frac{\partial L}{\partial{\bf W}_{xh}}
and using
\frac{\partial L}{\partial{\bf W}_{hh}}
, respectively. In ERNN, there is no back propagation, adopted in the NN of
[
28
]
.

Choosing the expected value
a_{k}^{(x)},a_{k}^{(h)}
as the means of the 18 samples of
{\bf W}^{(x)}{\bf x}
and
{\bf W}^{(h)}{\bf h}
, respectively,
the loss function is

L=\sum_{k}(y_{x}-a_{k}^{(x)})^{2}+\sum_{k}(y_{h}-a_{k}^{(h)})^{2}

(22)

\displaystyle\frac{\partial L}{\partial a_{k}^{(x)}}=-2(a_{k}^{(x)}-y_{x}),\quad\frac{\partial L}{\partial a_{k}^{(h)}}=-2(a_{k}^{(h)}-y_{h})

\displaystyle\frac{\partial a_{k}^{(x)}}{\partial W_{k,k}^{(x)}}=\frac{\partial}{\partial W_{k,k}^{(x)}}(a_{k}^{(h)}W_{k,k}^{(x)}+b_{k}^{(x)})=a_{k}^{(h)},\quad\frac{\partial a_{k}^{(h)}}{\partial W_{k,k}^{(h)}}=0

We ignore variation of
{\bf W}_{hh}^{(t)}
and choose
{\bf b}_{h}^{(t)}=0
.
For the activation we adopt the logistic sigmoid function. The weight function
{\bf W}^{(x)}
is modified as

W_{k,k}^{(x)}:=W_{k,k}^{(x)}-\eta\langle\frac{\partial L}{\partial W_{k,k}^{(x)}}\rangle,

(24)

where
\frac{\partial L}{\partial W_{k,k}^{(x)}}=-2(a_{k}^{(x)}-y_{x})a_{k}^{(h)}
,
and
\langle\frac{\partial L}{\partial W}\rangle
is an average over 18 samples of
\frac{\partial L}{\partial W}
in the training process and 8 samples in the validation process. The learning rate parameter
\eta
is chosen to be 0.01.

With the new

{\bf z}_{h}
and

is a null matrix

(26)

4.2
Long-Short Term Memory layer method

In recent RNN, long-short term memory (LSTM) layer are used in order to avoid vanishing gradient problem
[
28
,
29
]
.
Although we do not adopt the method in the present work, we explain the method.

One introduces the forget gate
{\bf f}_{t}
, inputgate
{\bf i}_{t}
and thecandidate value
\tilde{\bf C}_{t}

\displaystyle{\bf f}_{t}=\sigma({\bf W}_{xf}{\bf x}^{(t)}+{\bf W}_{hf}^{(t)}{\bf h}^{(t-1)}+{\bf b}_{f})

\displaystyle{\bf i}_{t}=\sigma({\bf W}_{xi}{\bf x}^{(t)}+{\bf W}_{hi}^{(t)}{\bf h}^{(t-1)}+{\bf b}_{i})

\displaystyle\tilde{\bf C}_{t}=\tanh({\bf W}_{xc}{\bf x}^{(t)}+{\bf W}_{hc}^{(t)}{\bf h}^{(t-1)}+{\bf b}_{c})

(32)

In our case,
{\bf W}_{xf}={\bf W}_{xi}={\bf W}_{xc},{\bf W}_{hf}^{(t)}={\bf W}_{hi}^{(t)}={\bf W}_{hc}^{(t)}
are random matrices,
{\bf x}^{(t)}
and
{\bf h}^{(t)}
are 9D vectors.

The cell state at time
t
is defined as

{\bf C}^{(t)}=({\bf C}^{(t-1)}\odot{\bf f}_{t})\oplus({\bf i}_{t}\odot\tilde{\bf C}_{t}),

(33)

and the output gate at
t=5,8,9,13,16,17
are

{\bf o}^{(t)}=\sigma({\bf W}_{xo}{\bf x}^{(t)}+{\bf W}_{ho}^{(t)}{\bf h}^{(t-1)}+{\bf b}_{o}).

(34)

The outputs at other epochs are

{\bf o}^{(t)}=\sigma({\bf W}_{xo}{\bf x}^{(t)}+{\bf b}_{o}).

(35)

The hidden unit at
t
is

{\bf h}^{(t)}={\bf o}^{(t)}\odot\tanh({\bf C}^{(t)}).

(36)

\odot
denotes the element wise multiplication which is known as Hudmard product
[
46
]
.
The loss function of
{\bf x}^{t}
is the difference between the input
{\bf h}^{(t)}
and the output
\hat{\bf o}^{(t)}\cdot\tanh({\bf C}^{(t)})
.

The loss function of
{\bf h}^{(t)}
is evaluated by using softmax function.

S_{i}=\frac{e^{y_{i}}}{\sum_{k}e^{y_{k}}},\quad\ell=-\log S_{m}

(37)

The derivative of
S_{i}
with respect to
y_{j}
is

\frac{\partial S_{i}}{\partial y_{j}}=\left\{\begin{array}[]{cc}S_{i}(1-S_{j})&j=i\\
-S_{i}S_{j}&j\neq i\end{array}\right.

(38)

Derivative of
\tanh(s)
with respect to
s
is

\frac{\partial\tanh(s)}{\partial s}=1-\tanh^{2}(s).

(39)

The iteration stop condition is
({\bf W}_{ho}{\bf h}^{(t)}-{\bf W}_{xo}{\bf x}^{(t)})^{2}<\epsilon
, where
\epsilon
is a positive small real number.

The bias vectors
{\bf b}_{f},{\bf b}_{i}
are chosen to be 0,

is

5
Conclusion and outlook

We showed that the weight function of paths defined by the fixed point action can be optimized by the Elman RNN method. The optimal weight functioon of the C-type fixed point actions which contain hysteresis effect can be simulated by using the biquaternion basis. We observed stablility of the action on the output layer produced from the hidden layers. Thee are other RNN methods which are left for the future study.
