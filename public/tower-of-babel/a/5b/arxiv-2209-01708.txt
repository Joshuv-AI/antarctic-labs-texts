A note on time functions associated with effectively hyperbolic double characteristics
Tatsuo Nishitani

Abstract
Geometrical aspects of effectively hyperbolic singular points over t = 0 t=0 are discussed assuming that the characteristic roots are real only on the one side t ≥ 0 t\geq 0 . In particular, the difference from the case that the characteristic roots are real in both sides t ≥ 0 t\geq 0 and t < 0 t<0 is concerned.

\psi(z)\geq 0
hence we have

(2.11)

a(t,x,\xi)\geq\big(t-\phi(z)\big)^{2},\quad\phi(z)\geq 0.

Thus from (
2.10
) and (
2.11
) we conclude

a(t,x,\xi)\geq c\,\min{\{t^{2},(t-\phi(z))^{2}\}}|\xi|^{2}.

Next estimate the Poisson bracket
\{\phi,a\}
. Recall that
\{\phi,\{\phi,a\}\}(0,0,e_{d})=\{\phi_{p},\{\phi_{p},\psi_{p}\}\}(0,0,e_{d})=0
by (
2.3
) since
\phi(z)=\phi_{p}(z+(0,e_{d}))
. Then for any
\epsilon_{1}>0
one can find a neighborhood
U
of
(0,e_{d})
such that

\big|H_{\phi}^{2}\,a\big|=\big|\{\phi,\{\phi,a\}\}\big|\leq\epsilon_{1},\quad(x,\xi)\in U

uniformly in
t\geq 0
. Since
a\geq 0
for
t\geq 0
thanks to the Glaeser’s inequality we see that

\big|H_{\phi}a\big|^{2}=\big|\{\phi,a\}\big|^{2}\leq 2\,\epsilon_{1}\,a,\quad t\geq 0

which finishes the proof for the case (
2.2
).

Turn to the case (
2.4
). Denote
x_{a}=(x_{1},\ldots,x_{p-1})
,
x_{b}=(x_{p+1},\ldots,x_{d})
and
\xi_{a}=(\xi_{1},\ldots,\xi_{p})
,
\xi_{b}=(\xi_{p+1},\ldots,\xi_{d})
. As above we extend
q_{j}
,
r_{j}
so that such extended ones, containing
\delta>0
, are defined for all
(x_{a},\xi_{a})\in{\mathbb{R}}^{p-1}\times{\mathbb{R}}^{p}
. Considering
a/{r_{p}}
we may assume
{r_{p}}=1
as before.
Consider

\displaystyle Q(w,t,z,x_{p},\varepsilon)=(y_{1}+1)^{2}{q_{1}}(t,x_{p}-\varepsilon y_{a},x_{p},\varepsilon\eta_{a},z+(0,e_{d}))

\displaystyle+\sum_{j=1}^{p-1}(y_{j}-y_{j+1})^{2}{q_{j}}(t,x_{p}-\varepsilon y_{a},x_{p},\varepsilon\eta_{a},z+(0,e_{d}))

\displaystyle+\sum_{j=1}^{p}\eta_{j}^{2}\,{r_{j}}(t,x_{p}-\varepsilon y_{a},x_{p},\varepsilon\eta_{a},z+(0,e_{d}))

where
y_{p}=0
,
w=(y_{a},\eta_{a})\in{\mathbb{R}}^{2p-1}
,
(x_{b},\xi_{b})=z+(0,e_{d})
and
x_{p}-\varepsilon y_{a}=(x_{p},\ldots,x_{p})-\varepsilon y_{a}
as before. Note that if we choose
\varepsilon=t-x_{p}
then

\displaystyle a(t,x_{p}-\varepsilon y,x_{p},\varepsilon\eta,z+(0,e_{d}))=\varepsilon^{2}Q(w,t,z,x_{p},\varepsilon)+g(x_{p},z),\;\;\varepsilon=t-x_{p}

where
g(x_{p},z)=g_{p}(x_{p},x_{b},\xi_{b})
. Denoting
\theta=(t,z,x_{p},\varepsilon)
and noting

Q(w,0)=(y_{1}+1)^{2}{\bar{q}}_{1}+\sum_{j=1}^{p-1}(y_{j}-y_{j+1})^{2}{\bar{q}}_{j}+\sum_{j=1}^{p}\eta_{j}{\bar{r}}_{j}

one can repeat a similar argument as above to conclude that

\min_{w\in{\mathbb{R}}^{2p-1}}Q(w,\theta)=m(\theta)=Q({\bar{w}}(\theta),\theta)

where
{\bar{w}}(\theta)
is smooth near
\theta=0
.
Choosing
\varepsilon=t-x_{p}
we have

(2.12)

\begin{split}a(t,x_{p}-\varepsilon y_{a},x_{p},\varepsilon\eta_{a},z+(0,e_{d}))\\
=(t-x_{p})^{2}Q(w,t,z,x_{p},t-x_{p})+g(x_{p},z)\\
\geq m(t,z,x_{p},t-x_{p})(t-x_{p})^{2}+g(x_{p},z)\\
=m_{1}(t,x_{p},z)(t-x_{p})^{2}+g(x_{p},z)\end{split}

where we have set
m_{1}(t,x_{p},z)=m(t,z,x_{p},t-x_{p})
. When
x_{p}<0
, repeating the same arguments as above one can find
c_{1}>0

(2.13)

a(t,x,\xi)\geq c_{1}t^{2}+t|x_{p}|(2c_{1}-C|x_{p}|)\geq c_{1}t^{2},\quad x_{p}<0

in a neighborhood of
(0,e_{d})
. Assume
x_{p}\geq 0
. Thanks to Proposition
2.1
one has
\sum_{i=1}^{p}1/{\bar{r}}_{i}>1
then one can find
\epsilon_{i}>0
such that
\sum_{i=1}^{p}\epsilon_{i}^{2}\,{\bar{r}}_{i}=\rho<1
with
\sum_{i=1}^{p}\epsilon_{i}=1
.
Define

\phi(x)=\sum_{i=1}^{p}\epsilon_{i}x_{i}.

Since
x_{i-1}-x_{i}=0
,
i=1,\ldots,p
implies
t-\phi(x)=x_{0}-x_{0}=0
hence
t-\phi(x)
is a linear combination of
x_{i-1}-x_{i}
so that

t-\phi(x)=\sum_{i=1}^{p}\alpha_{i}(x_{i-1}-x_{i}),\quad\alpha_{i}\in{\mathbb{R}}.

Therefore it is clear that there is
C>0
such that

(t-\phi(x))^{2}\leq C\sum_{i=1}^{p}(x_{i-1}-x_{i})^{2}{q_{i}}.

Since
g(x_{p},z)\geq 0
for
x_{p}\geq 0
which follows from (
2.12
) taking
x_{p}=t\geq 0
we have
a(t,x,\xi)\geq\sum_{i=1}^{p}(x_{i-1}-x_{i})^{2}{q_{i}}
which implies that there is
c^{\prime}>0
such that

(2.14)

a(t,x,\xi)\geq c^{\prime}\,(t-\phi(x))^{2},\quad x_{p}\geq 0.

Thus from (
2.13
) and (
2.14
) we have

a(t,x,\xi)\geq c\,\min{\{t^{2},(t-\phi(x))^{2}\}}|\xi|^{2}.

It is clear that for any
\epsilon>0
one can find a neighborhood
U
of
(0,e_{d})
such that

\displaystyle\big|H_{\phi}^{2}a\big|\leq 2\sum_{i=1}^{p}\epsilon_{i}^{2}\,{\bar{r}}_{i}+\epsilon=2\rho+\epsilon,\quad(x,\xi)\in U

uniformly in small
t\geq 0
because
H_{\phi}^{2}a(0,0,e_{d})=2\sum_{i=1}^{p}\epsilon_{i}^{2}\,{\bar{r}}_{i}
.
Since
a\geq 0
for
t\geq 0
it follows from the Glaeser’s inequality that

\big|H_{\phi}a\big|^{2}=\big|\{\phi,a\}\big|^{2}\leq 2(2\rho+\epsilon)a,\quad(x,\xi)\in U

for small
t\geq 0
where one can assume
2\rho+\epsilon<2
for
\rho<1
. Thus we have completed the proof for the case (
2.4
).
