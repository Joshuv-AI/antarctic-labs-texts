Primality proving using elliptic curves with complex multiplication by imaginary quadratic fields of class number three
Hiroshi Onuki

Abstract
. In 2015, Abatzoglou, Silverberg, Sutherland, and Wong presented a framework for primality proving algorithms for special sequences of integers using an elliptic curve with complex multiplication. They applied their framework to obtain algorithms for elliptic curves with complex multiplication by imaginary quadratic field of class numbers one and two, but, they were not able to obtain primality proving algorithms in cases of higher class number. In this paper, we present a method to apply their framework to imaginary quadratic fields of class number three. In particular, our method provides a more efficient primality proving algorithm for special sequences of integers than the existing algorithms by using an imaginary quadratic field of class number three in which 2 splits. As an application, we give two special sequences of integers derived from ℚ ⁡ ( − 23 ) \mathbb{Q}(\sqrt{-23}) and ℚ ⁡ ( − 31 ) \mathbb{Q}(\sqrt{-31}) , which are all the imaginary quadratic fields of class number three in which 2 splits. Finally, we give a computational result for the primality of these sequences.

1.
Introduction

Research on algorithms to determine the primality of a given integer has
received a lot of interest from computational mathematics and its application to cryptography.
There are efficient algorithms for compositeness test, which return the input is composite or undetermined.
For example,
the Miller-Rabin test
[
6
, Algorithm 3.5.1]
has computational complexity
\tilde{O}((\log n)^{2})
with input
n
.
However, primality proving algorithms, which determine the primality of the input, are less efficient.
The best algorithm currently known is the Agrawal-Kayal-Saxena algorithm
[
4
]
improved by
Lenstra and Pomerance
[
9
]

and has computational complexity
\tilde{O}((\log n)^{6})
with input
n
.

On the other hand,
more efficient algorithms are known
for an integer
n
such that a partial factorization of either

n+1
or
n-1
is known (see §4.1 and 4.2 of
[
6
]
).
For example,
the Lucas-Lehmer test for Mersenne numbers
[
6
, Theorem 4.2.6]

and the Pepin test for Fermat numbers
[
6
, Theorem 4.1.2]

are such algorithms.
The computational complexities of these algorithms are
\tilde{O}((\log n)^{2})

the same as for the Miller-Rabin test.
These classical algorithms (we call these the
n\pm 1
algorithms
)
use the structure of the multiplicative group of the residue ring modulo
n
.

In 2005, Gross
[
8
]
constructed a primality proving algorithm for
Mersenne numbers by using an elliptic curve with complex multiplication (CM)
by
\mathbb{Q}(\sqrt{-1})
.
Its computational complexity is also
\tilde{O}((\log n)^{2})
with input
n
.
Similar results for other sequences of integers are obtained
by Denomme and Savin
[
7
]
for Fermat numbers and integers of the
forms
3^{2^{l}}-3^{2^{l-1}}+1
and
2^{2^{l}}-2^{2^{l-1}}+1
,
and by Tsumura
[
17
]
for integers of the form
2^{p}\pm 2^{(p+1)/2}+1
.
Denomme and Savin used elliptic curves with CM by
\mathbb{Q}(\sqrt{-1})
and
\mathbb{Q}(\sqrt{-3})
,
and Tsumura used an elliptic curve with CM by
\mathbb{Q}(\sqrt{-1})
.
However, an integer
N
to which these algorithms can be applied has
the property that
N+1
or
N-1
is smooth, i.e.,
the
n\pm 1
algorithms can also be applied to such
N
.

Based on these studies,
Abatzoglou, Silverberg, Sutherland and Wong
[
2
]

proposed a primality proving algorithm for sequences of integers
to which the
n\pm 1
algorithms cannot be applied
(see also
[
19
]
).
Their algorithm has the same computational complexity as the above algorithms.
The same authors
[
3
]
presented
a framework for primality proving algorithms using elliptic curves with CM.
If one applies their framework to elliptic curves with CM by
an imaginary quadratic field in which
2
splits,
i.e.,
2
splits into two distinct prime ideals,
then one can obtain a primality proving algorithm for sequences of integers
to which the
n\pm 1
algorithms cannot be applied.
As an application of their framework,
they gave a primality proving algorithm for sequences of integers
using
\mathbb{Q}(\sqrt{-7})
and
\mathbb{Q}(\sqrt{-15})
, which are
all the imaginary quadratic fields of class number one or two
in which
2
splits.
A primality proving algorithm using
\mathbb{Q}(\sqrt{-2})

based on the same framework
was also proposed by
[
1
,
3
]
.
However, the
n\pm 1
algorithm can be applied to
the sequence of integers to which the algorithm using
\mathbb{Q}(\sqrt{-2})
can be applied
since
2
is ramified in
\mathbb{Q}(\sqrt{-2})
.
The algorithm using
\mathbb{Q}(\sqrt{-15})
is the first algorithm of this type using an imaginary quadratic field of class number two
(the previous algorithms use those of class number one).
They left as an open problem
the construction of a similar primality proving algorithm using an imaginary quadratic field of class number greater than two
(see Remark 4.12 in
[
3
]
).
The main obstacle to use an imaginary quadratic field of class number greater
than two is as follows.
Let
K
be an imaginary quadratic field
and
H
the Hilbert class field of
K
.
The framework of Abatzoglou et al. uses a sequence
\{\mathfrak{p}_{k}\}_{k}
of ideals of
\mathcal{O}_{H}

such that
\mathrm{N}_{H/K}(\mathfrak{p}_{k})
is principal
and a generator
\pi_{k}
of
\mathrm{N}_{H/K}(\mathfrak{p}_{k})
satisfying that

\pi_{k}-1
is “highly factored,”
i.e.,
\pi_{k}-1
is divisible by a smooth
\alpha\in\mathcal{O}_{K}

and
\mathrm{N}_{K/\mathbb{Q}}(\alpha)
is approximately greater than
\sqrt{\mathrm{N}_{K/\mathbb{Q}}(\pi_{k})}
,
and they did not know how to
systematically
find such ideals.

In this paper, we solve this problem in the case that the class number is three.
Our method is based on the framework of Abatzoglou et al. and
can be applied to any imaginary quadratic field of class number three
in which
2
splits.
As in the framework of Abatzoglou et al.,
we can obtain a primality proving algorithm for a special sequence of integers
to which the
n\pm 1
algorithms cannot be applied.

Let
K
be an imaginary quadratic field of class number three
and
H
the Hilbert class field of
K
.
The key idea of this work is using a primitive element
\xi
of
H/K

such that
\mathrm{Tr}_{H/K}(\xi)=0
.
In this case, the minimal polynomial of
\xi
over
K
is
of the form

x^{3}+c_{1}x+c_{0}
for
c_{0},c_{1}\in\mathcal{O}_{K}
.
We define a sequence
\{\mathfrak{p}_{k}\}_{k}
of ideals of
\mathcal{O}_{H}
as

\mathfrak{p}_{k}=(1-\alpha^{k}\xi)\mathcal{O}_{H}
for a smooth
\alpha\in\mathcal{O}_{K}
.
Then
\mathrm{N}_{H/K}(\mathfrak{p}_{k})
is principal and generated by

\pi_{k}=1+c_{1}\alpha^{2k}+c_{0}\alpha^{3k}

and
\pi_{k}-1=\alpha^{2k}(c_{1}+c_{0}\alpha^{k})
is highly factored.

As an application,
we present two sequences of integers and primality proving algorithms for them.
These algorithms use
\mathbb{Q}(\sqrt{-23})
and
\mathbb{Q}(\sqrt{-31})
, respectively,
which are all the imaginary quadratic fields of class number three
in which
2
splits
(see sequence A006203 in
[
16
]
).

The organization of this paper is as follows.
In §
2
, we give the notation that we use in this paper.
We recall the framework of
[
3
]
in §
3
.
Our main contribution is given in §
4
.
In particular, we present our idea to solve the open problem in §
4.1
.
Then, in §
4.2
, we give the setting of our primality proving.
We deal with some technical issues to construct our algorithm in §
4.3
.
Our concrete algorithm is given in §
4.4
.
Finally, in §
5
, we show the computational result of our primality proving algorithm.

2.
Notation

Let
L
be a number field.
We denote the ring of integers of
L
by
\mathcal{O}_{L}
.
The norm and the trace of a finite extension
M/L
are denoted by
\mathrm{N}_{M/L}
and
\mathrm{Tr}_{M/L}
, respectively.
For a place
v
of
L
,
we denote the completion of
L
at
v
by
L_{v}
.
For a finite place
\mathfrak{p}
of
L
and
a\in L_{\mathfrak{p}}
,
we denote the
\mathfrak{p}
-adic valuation of
a
by
\mbox{ord}_{\mathfrak{p}}(a)
.
For
a,b\in L_{v}^{\times}
, the
quadratic Hilbert symbol

\left(\frac{\cdot,\cdot}{v}\right)
at
v
is defined by

\left(\frac{a,b}{v}\right)=\left\{\begin{array}[]{ll}1,&\mbox{if }ax^{2}+by^{2}=z^{2}\mbox{ has a solution }(x,y,z)\in L_{v}^{3}\backslash(0,0,0),\\
-1,&\mbox{otherwise}.\end{array}\right.

For a finite place
\mathfrak{p}
of
L
not dividing
2
,
we define the
quadratic residue symbol modulo
\mathfrak{p}
as

\left(\frac{a}{\mathfrak{p}}\right)=\left\{\begin{array}[]{cl}\left(\frac{\pi,a}{\mathfrak{p}}\right),&\mbox{if }\mbox{ord}_{\mathfrak{p}}(a)\mbox{ is even},\\
0,&\mbox{otherwise},\end{array}\right.

where
a\in L_{\mathfrak{p}}^{\times}
and
\pi
is a prime element of
L_{\mathfrak{p}}
.
Note that this definition does not depend on the choice of
\pi
.
If
\mathrm{ord}_{\mathfrak{p}}(a)=0
then
\left(\frac{a}{\mathfrak{p}}\right)=1
if and only if
a
is square modulo
\mathfrak{p}
.
For an element
a
of an imaginary quadratic field,

\bar{a}
denotes the complex conjugate of
a
.

In this paper, we consider only elliptic curves defined by a short Weierstrass form,
i.e., curves defined by a projective equation

Y^{2}Z=X^{3}+AXZ^{2}+BZ^{3}
,
where
A
and
B
are the coefficients of the curve.
For simplicity, we also use the affine model
y^{2}=x^{3}+Ax+B
of the same curve.
For an elliptic curve
E
,
we denote its neutral element by
O_{E}
,
its
j
-invariant by
j(E)
,
its discriminant by
\mathrm{disc}(E)
,
and its endomorphism ring by
\mathrm{End}(E)
.
Note that
O_{E}
is the unique point whose
Z
-coordinate is zero.
Let
\mathcal{O}
be an order of an imaginary quadratic field and

E
an elliptic curve over a number field.
When
\mathrm{End}(E)
is isomorphic to
\mathcal{O}
,
we say
E
is
an
elliptic curve with complex multiplication (CM) by
\mathcal{O}
.
In this case, the normalized isomorphism

\mathcal{O}\to\mathrm{End}(E)
is denoted by
[\cdot]

(see
[
14
, Proposition II.1.1]
for the definition).

3.
Framework for primality proving

In this section,
we give an overview of the framework provided in
[
3
]
.
First, we recall terminology from
[
3
]
.

Definition 3.1
.

Let
E
be an elliptic curve over a number field
M

and
J
an ideal of
\mathcal{O}_{M}
prime to
\mathrm{disc}(E)
.
We say that
P\in E(M)
is
strongly nonzero modulo
J

if one can express
P=(X:Y:Z)\in\mathbb{P}^{2}(\mathcal{O}_{M})

such that
Z\mathcal{O}_{M}+J=\mathcal{O}_{M}
.

Let
K
be an imaginary quadratic field,

E
an elliptic curve defined over a number field
M
containing
K

with CM by
\mathcal{O}_{K}
.
We fix a point
P
in
E(M)
.
Let
\gamma,\alpha_{1},\dots,\alpha_{s}
be nonzero elements of
\mathcal{O}_{K}

and assume that we know the prime ideal factorization of
(\prod_{i=1}^{s}\alpha_{i})\mathcal{O}_{K}
.
For
k=(k_{1},\dots,k_{s})\in\mathbb{N}^{s}
,
we define

\Lambda_{k}=\gamma\alpha_{1}^{k_{1}}\cdots\alpha_{s}^{k_{s}},\quad\pi_{k}=1+\Lambda_{k},\quad F_{k}=\mathrm{N}_{K/\mathbb{Q}}(\pi_{k}),

and
L_{k}
as the positive generator of an ideal
(\Lambda_{k}/\gamma)\mathcal{O}_{K}\cap\mathbb{Z}
of
\mathbb{Z}
.
Let
\mathfrak{p}_{k}
be an ideal of
\mathcal{O}_{M}
such that

\mathrm{N}_{M/K}(\mathfrak{p}_{k})=\pi_{k}\mathcal{O}_{K}
.
When
\mathfrak{p}_{k}
is a prime ideal,
we denote the reductions modulo
\mathfrak{p}_{k}
of
E
and
P

by
\tilde{E}
and
\tilde{P}
.
Further, we adopt the assumption described in §3.1 of
[
3
]
.
In particular, we assume that
k
is chosen so that the following holds.

Assumption 3.2
.

Whenever
\mathfrak{p}_{k}
is a prime ideal, the following hold:

(i)

The Frobenius endomorphism of
\tilde{E}
is
[\pi_{k}]
,

(ii)

\tilde{P}\not\in[\lambda]\tilde{E}(\mathcal{O}_{M}/\mathfrak{p}_{k})

for every prime ideal
\lambda
of
\mathcal{O}_{K}
containing

\prod_{i=1}^{s}\alpha_{i}
.

In this setting,
Abatzoglou et al. showed
the following primality theorem.

Theorem 3.3

(Theorem 3.6 of
[
3
]
)
.

With the notation as above, assume Assumption
3.2
.
Suppose that
\prod_{i=1}^{s}\alpha_{i}
is not divisible in
\mathcal{O}_{K}

by any rational prime that splits in
K
,
and that
F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(\gamma\prod_{\lambda}\lambda)^{2}

where
\lambda
runs over the prime ideals of
\mathcal{O}_{K}

that divide
\prod_{i=1}^{s}\alpha_{i}
and are ramified in
K/\mathbb{Q}
.
Then the following are equivalent:

(a)

\mathfrak{p}_{k}
is a prime ideal,

(b)

[L_{k}\gamma]P\equiv O_{E}\pmod{\mathfrak{p}_{k}}
,
and
\left[\frac{L_{k}}{p}\gamma\right]P

is strongly nonzero modulo
\mathfrak{p}_{k}

for every prime divisor
p
of
\mathrm{N}_{K/\mathbb{Q}}(\alpha_{1}\cdots\alpha_{s})
.

This theorem states that the primality of
\mathfrak{p}_{k}
can be
detected by the arithmetic of
P
modulo
\mathfrak{p}_{k}
.
The condition
F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(\gamma\prod\lambda)^{2}
means that
the unknown part of the factorization of
\pi_{k}-1
is less than
about half of the size of
\pi_{k}
.
This and condition (ii) in Assumption
3.2
ensure that

P\bmod{\mathfrak{p}_{k}}
has a sufficiently large order to prove the primality of
\mathfrak{p}_{k}
.
Although
\gamma
does not depend on
k
in
[
3
]
,
the proof does not use this fact.
Therefore, Theorem
3.3
remains true even if
\gamma
depends on
k
.

Abatzoglou et al. obtained an algorithm for determining the primality of
\mathfrak{p}_{k}
from this theorem.
To make the above theorem a concrete primality proving algorithm,
we must choose a setting that satisfies Assumption
3.2
.

As in
[
3
]
,
for condition (i),
we can use Theorem 5.3 of
[
12
]
.
Suppose that
E
is defined by
y^{2}=x^{3}+Ax+B
and the discriminant of
K
is odd.
Then the theorem says that
the Frobenius map of
\tilde{E}
is

(3.1)

\left(\frac{6B\bm{\gamma}_{3}(E)}{\mathfrak{p}_{k}}\right)\epsilon_{k}[\pi_{k}],

where
\bm{\gamma}_{3}(E)\in H
is the value of a Weber function at a complex number corresponding to
E

(see §2 in
[
12
]
for the definition),
and
\epsilon_{k}
is
\pm 1
depending on
\pi_{k}^{3}\bmod{4}

(see Proposition 6.2 in
[
12
]
).

For condition (ii),
Abatzoglou et al. showed the following theorem.

Theorem 3.4

(Theorem 4.4 of
[
3
]
)
.

Let
\lambda
be a prime ideal of
\mathcal{O}_{K}
such that

\mathfrak{p}_{k}
does not divide
\mathrm{N}_{K/\mathbb{Q}}(\lambda)
,
and
\varphi:E\to E^{\prime}
an isogeny with kernel
E[\bar{\lambda}]
.
Let
P\in E(M)
,
F=M(E^{\prime}[\lambda])
, and
L=F(\widehat{\varphi}^{-1}(P))
,
where
\widehat{\varphi}
is the dual isogeny of
\varphi
.
If
\mathfrak{p}_{k}
is a prime ideal then
the following are equivalent:

(a)

\tilde{P}\not\in[\lambda]\tilde{E}(\mathcal{O}_{M}/\mathfrak{p}_{k})
,

(b)

\mathfrak{p}_{k}
splits completely in
F
and

\mathfrak{p}_{k}
does not split completely in
L
.

To determine the condition on
k
satisfying (b) of this theorem,
they restrict their attention to the case
M=F

and this field is the Hilbert class field of
K
.
This restriction makes
\lambda
an ideal above
2

except in the case
K=\mathbb{Q}(\sqrt{-3})
.
For a detailed discussion, see §4 in
[
3
]
.

In order to construct a primality proving algorithm
for numbers to which
the
n\pm 1
algorithms cannot be applied,
we need to restrict
K
to a field in which
2
splits.
Otherwise,

F_{k}-1
is highly factored.
The imaginary quadratic fields in which
2
splits of class number one or two are
\mathbb{Q}(\sqrt{-7})
and
\mathbb{Q}(\sqrt{-15})
.
A primality proving algorithm for
\mathbb{Q}(\sqrt{-7})
was given by
[
2
]

and one for
\mathbb{Q}(\sqrt{-15})
by
[
3
]
.

4.
Primality Proof for class number three

In this section,
we give a method to construct a primality proving algorithm for imaginary quadratic fields of class number three in which
2
splits.
In particular, we give a systematic method for constructing
\mathfrak{p}_{k}
such that

\pi_{k}-1
is highly factored.

4.1.
Construction of
\mathfrak{p}_{k}

Let
K
be an imaginary quadratic field and
H
the Hilbert class field of
K
.
As in the previous section,
we let
\mathfrak{p}_{k}
be an ideal of
\mathcal{O}_{H}
,

\pi_{k}
a generator of
\mathrm{N}_{H/K}(\mathfrak{p}_{k})
,
and
F_{k}=\mathrm{N}_{K/\mathbb{Q}}(\pi_{k})
for
k\in\mathbb{N}
.
In this setting, “
\pi_{k}-1
is highly factored” means that

\pi_{k}-1
is of the form
A\gamma

satisfying
A
is divisible only by a prime ideal of
\mathcal{O}_{K}
above
2
,
and
F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(\gamma)^{2}
.
The latter condition comes from Theorem
3.3
.

First, we consider a more general setting.
Let
h
be the class number of
K

and
\xi\in\mathcal{O}_{H}
a primitive element of
H/K
,
i.e.,
H=K(\xi)
.
We can write the minimal polynomial
f(x)
of
\xi
over
K
as

(4.1)

f(x)=x^{h}+c_{m}x^{m}+\cdots+c_{0},\quad c_{0},\dots,c_{m}\in\mathcal{O}_{K}\mbox{ and }m<h.

Let
\alpha
be an element in
\mathcal{O}_{K}

such that
\alpha
is divisible only by a prime ideal of

\mathcal{O}_{K}
above
2
.
We define
\mathfrak{p}_{k}
as an ideal generated by
1-\alpha^{k}\xi
.
Then we have

\displaystyle\pi_{k}

\displaystyle=\mathrm{N}_{H/K}(1-\alpha^{k}\xi)=\alpha^{kh}\mathrm{N}_{H/\mathbb{Q}}(\alpha^{-k}-\xi)=\alpha^{kh}f(\alpha^{-k})

\displaystyle=1+c_{m}\alpha^{(h-m)k}+c_{m-1}\alpha^{(h-(m-1))k}+\cdots+c_{0}\alpha^{hk}

\displaystyle=1+\alpha^{(h-m)k}(c_{m}+c_{m-1}\alpha+\cdots+c_{0}\alpha^{mk}).

In this case,
if
m<h/2

then the norm condition in Theorem
3.3
holds.
More precisely, we have the following lemma.

Lemma 4.1
.

We use the above notation and assume
m<h/2
.
Let
\gamma_{k}=c_{m}+c_{m-1}\alpha+\cdots+c_{0}\alpha^{mk}
.
Then
we have
F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(\gamma_{k})^{2}
for sufficiently large
k
.

Proof.

It suffices to show that

\displaystyle\lim_{k\to\infty}\mathrm{N}_{K/\mathbb{Q}}(\gamma_{k})^{2}/F_{k}=0
.
Since
\alpha
is divisible by a prime ideal above
2
,
we have
\mathrm{N}_{K/\mathbb{Q}}(\alpha)\geq 2
.
Therefore,
the limit of a complex number

\pi_{k}/\alpha^{hk}=c_{0}+c_{1}\alpha^{-k}+\dots+c_{m}\alpha^{-mk}+\alpha^{-hk}

as
k
approaches infinity equals
c_{0}
.
On the other hand,
the condition
m<h/2
shows
\displaystyle\lim_{k\to\infty}\gamma_{k}/\alpha^{hk/2}=0
.
Taking the norms of these limits shows that

\lim_{k\to\infty}F_{k}/\mathrm{N}_{K/\mathbb{Q}}(\alpha)^{hk}=c_{0}^{2}\mbox{ and }\lim_{k\to\infty}\mathrm{N}_{K/\mathbb{Q}}(\gamma_{k})^{2}/\mathrm{N}_{K/\mathbb{Q}}(\alpha)^{hk}=0.

Since
c_{0}\neq 0
,
we have

\displaystyle\lim_{k\to\infty}\mathrm{N}_{K/\mathbb{Q}}(\gamma_{k})^{2}/F_{k}=0
.
∎

As we stated in §
3
,
the framework also works in the case
\gamma
depends on
k
.
Therefore, if we find
\xi
with
m<h/2

then we can apply the primality proving in
[
3
]
.
For general class numbers, we do not know how to find such
\xi
.
However, in the case that the class number of
K
is three,
we can always find such
\xi
by taking a trace-zero element.

Remark 4.2
.

We can construct a primality proving algorithm for
a generator of the form
1-\beta\alpha^{k}\xi
of
\mathfrak{p}_{k}
with cofactor
\beta\in\mathcal{O}_{K}

in the same way as described in the following sections.
In this paper, we describe the case
\beta=1
to simplify the notation.

4.2.
Settings

We use the notation in the previous subsection.
Suppose that the class number of
K
is three and that
2
splits in
K
.
We choose a primitive element
\xi
of
H/K
so that the trace of
\xi
is zero,
i.e., the minimal polynomial of
\xi
over
K
is
x^{3}+c_{1}x+c_{0}
.
Let
\lambda
be a prime ideal of
\mathcal{O}_{K}
above
2
,
and
\alpha
a generator of
\lambda^{3}
.
For
k\in\mathbb{N}
, we define
p_{k}=1-\alpha^{k}\xi
and
\mathfrak{p}_{k}
is the ideal of
\mathcal{O}_{H}
generated by
p_{k}
.
In summary, our setting is

\displaystyle\mathfrak{p}_{k}

\displaystyle=p_{k}\mathcal{O}_{H}=(1-\alpha^{k}\xi)\mathcal{O}_{H},

\displaystyle\pi_{k}

\displaystyle=\mathrm{N}_{H/K}(p_{k})=1+c_{1}\alpha^{2k}+c_{0}\alpha^{3k},

\displaystyle F_{k}

\displaystyle=\mathrm{N}_{K/\mathbb{Q}}(\pi_{k}).

Our goal is to construct a primality proving algorithm for
F_{k}
by using an elliptic curve with CM by
\mathcal{O}_{K}
.
For this, we choose
\xi
so that
F_{k}
is a prime number
if
\mathfrak{p}_{k}
is a prime ideal
since the primality of
\mathfrak{p}_{k}
can be determined by Theorem
3.3
.
The following lemma gives such a condition on
\xi
.

Lemma 4.3
.

Let
t
be the trace of
\alpha
.
Suppose that

1+c_{1}+c_{0}

and
1+c_{1}+c_{0}t

are not congruent to
1
modulo
\bar{\lambda}^{3}
.
Then
\mathfrak{p}_{k}
is a prime ideal
if and only if
F_{k}
is a prime number.

Proof.

First, we show that if
\mathfrak{p}_{k}
is a prime ideal
then
\pi_{k}\mathcal{O}_{K}
is a prime ideal.
Let
\kappa
be a prime ideal dividing
\pi_{k}\mathcal{O}_{K}
in
K
.
Because the minimal polynomial
x^{3}+c_{1}x+c_{0}
of
\xi
has a root
\alpha^{-k}
modulo
\pi_{k}\mathcal{O}_{K}
,
there exists a prime ideal above
\kappa
in
H
whose inertia degree over
\kappa
is one.
From this and the fact that
H
is the Hilbert class field of
K
,
it follows that
\kappa
splits completely in
H
.
Therefore, if
\mathfrak{p}_{k}
is prime then the inertia degree of
\mathfrak{p}_{k}
over
K
is one.
This means that
\pi_{k}
, the norm of
\mathfrak{p}_{k}
over
K
, is prime in
K
.

Next, we show that if
\pi_{k}\mathcal{O}_{K}
is a prime ideal
then
F_{k}
is a prime number.
Suppose that
\pi_{k}\mathcal{O}_{K}
is a prime ideal.
We assume that
F_{k}
is not prime.
Then
F_{k}
is the square of a rational prime.
Therefore, we have
F_{k}\equiv 1\pmod{8}
or
F_{k}=2^{2}
.
The latter case occurs only when
2
is inert in
K
,
so
\alpha
is divisible by
2
.
In this case,
F_{k}
must be odd. This contradicts the fact that
F_{k}=2^{2}
.
Therefore, we conclude that
F_{k}\equiv 1\pmod{8}
.
Since
\overline{\pi_{k}}\equiv 1\pmod{\bar{\lambda}^{3}}
,
we have
F_{k}\equiv\pi_{k}\pmod{\bar{\lambda}^{3}}
.
This implies that
\pi_{k}\equiv 1\pmod{\bar{\lambda}^{3}}
.
On the other hand,
we have

\pi_{k}\equiv 1+c_{1}t^{2k}+c_{0}t^{3k}\pmod{\bar{\lambda}^{3}}

since
\alpha\equiv t\pmod{\bar{\lambda}^{3}}
.
Since
t
is odd and
\bar{\lambda}^{3}
divides
8
,
it follows that
\pi_{k}
is congruent to

1+c_{1}+c_{0}

or

1+c_{1}+c_{0}t

modulo
\bar{\lambda}^{3}

depending on whether
k
is even or odd.
This contradicts our assumption. Therefore,
F_{k}
must be prime.

The other direction is obvious.
∎

From now on, we restrict our attention to
\xi
satisfying the assumption in Lemma
4.3
.
We can find such
\xi
for any imaginary quadratic field of class number three
in which
2
splits.
There are exactly two such quadratic fields,
\mathbb{Q}(\sqrt{-23})
and
\mathbb{Q}(\sqrt{-31})
.
We can take
\xi
as a root of
x^{3}-x-1
for
\mathbb{Q}(\sqrt{-23})

and a root of
x^{3}+x+1
for
\mathbb{Q}(\sqrt{-31})
.

The remaining tasks are to find an elliptic curve and a point on it
and to determine the condition on
k
satisfying Assumption
3.2
.

4.3.
Determining the condition on
k

We can use the method in
[
2
,
3
]
to determine the condition on
k
,
but the authors described methods for searching conditions on
k
separately for each form of
F_{k}
.
Here, we give a slightly more unified method and explicit algorithms for this.

Let
E
be an elliptic curve with CM by
\mathcal{O}_{K}

defined by
y^{2}=x^{3}+Ax+B
with
A,B\in\mathcal{O}_{H}
.
We can suppose that
B
is square in
\mathcal{O}_{H}
since

y^{2}=x^{3}+Au^{2}x+Bu^{3}
is isomorphic to
E
for any
u\in H^{\times}
.
We suppose that
B
is square
and let
\beta
be a square root of
B
.
Then
(0,\beta)
is a point in
E(H)
.
We let
P=(0,\beta)
.
As in §
3
,
when
\mathfrak{p}_{k}
is a prime ideal, we denote the reductions
modulo
\mathfrak{p}_{k}
of
E
and
P
by
\tilde{E}
and
\tilde{P}
.

The purpose of this subsection is to give a method to compute sets
T_{0}
,
T_{1}
, and
T_{2}

satisfying the following conditions:

\displaystyle T_{0}=\{k\in\mathbb{N}\mid\mathfrak{p}_{k}\mbox{ does not divide }\mathrm{disc}(E)\},

\displaystyle k\in T_{1}\mbox{ and }\mathfrak{p}_{k}\mbox{ is a prime ideal }\Rightarrow\mbox{(i) of Assumption \ref{assump:frob_inv} holds},

\displaystyle k\in T_{2}\mbox{ and }\mathfrak{p}_{k}\mbox{ is a prime ideal }\Rightarrow\mbox{(ii) of Assumption \ref{assump:frob_inv} holds}.

We can apply Theorem
3.3
to
k\in T_{0}\cap T_{1}\cap T_{2}
and
obtain a primality proving algorithm.
In the following, we show that these sets are determined by
the condition on
k
modulo some integer.
Determining
T_{0}
is trivial, so we focus on
T_{1}
and
T_{2}
in the following.
First,
we show that quadratic residue symbols modulo
\mathfrak{p}_{k}
are determined by
k
modulo some integers.
Next,
we show that we can define
T_{1}
and
T_{2}
as
sets of integers satisfying conditions on quadratic residue symbols.
Finally, we give explicit algorithms to determine
T_{1}
and
T_{2}

4.3.1.
Computing quadratic residue symbols

To determine quadratic residue symbols modulo
\mathfrak{p}_{k}
,
we use the following theorem.

Theorem 4.4
.

Fix
a\in H^{\times}
.
For a prime ideal
\mathfrak{l}
of
\mathcal{O}_{H}
,
we denote the order of
(\mathcal{O}_{H}/\mathfrak{l})^{\times}
by
N_{\mathfrak{l}}
.
Then the quadratic residue symbol
\left(\frac{a}{\mathfrak{p}_{k}}\right)
is determined by

k
modulo the least common multiple of
2
and
N_{\mathfrak{l}}

for the prime ideals
\mathfrak{l}
of
\mathcal{O}_{H}
dividing
a
and not dividing
2
.

To prove this theorem, we need the following lemmas.

Lemma 4.5
.

Let
L
be a number field in which
2
is not ramified,
and
\mathfrak{l}
a prime ideal of
\mathcal{O}_{L}
above
2
.
We fix an element
a
in
L^{\times}
.
Then, for
b\in\mathcal{O}_{L}
not divisible by
\mathfrak{l}
,
the quadratic Hilbert symbol
\left(\frac{a,b}{\mathfrak{l}}\right)

is determined by
b
modulo
\mathfrak{l}^{3}
.

Proof.

We may assume that
\mbox{ord}_{\mathfrak{l}}(a)=0\mbox{ or }1
.
Let
\mathcal{O}_{\mathfrak{l}}
be the valuation ring of
L_{\mathfrak{l}}
.
It suffices to show that
\left(\frac{a,b}{\mathfrak{l}}\right)=1

if and only if

ax^{2}+by^{2}\equiv z^{2}\pmod{\mathfrak{l}^{3}}
has a solution
(x,y,z)
in
\mathcal{O}_{\mathfrak{l}}^{3}

such that at least one of
x,y,z
is in
\mathcal{O}_{\mathfrak{l}}^{\times}
.

It is obvious that the former implies the latter.
Suppose that the latter holds.
Let
(x_{0},y_{0},z_{0})
be a solution of the equation in the latter.
If
\mbox{ord}_{\mathfrak{l}}(y_{0})
and
\mbox{ord}_{\mathfrak{l}}(z_{0})
are positive
then
\mbox{ord}_{\mathfrak{l}}(x_{0})
is also positive
since
\mbox{ord}_{\mathfrak{l}}(a)\leq 1
.
Therefore,
y_{0}
or
z_{0}
is in
\mathcal{O}_{\mathfrak{l}}^{\times}
.
Assume that
y_{0}\in\mathcal{O}_{\mathfrak{l}}^{\times}
.
We define a polynomial
f(y)=y^{2}+b^{-1}ax_{0}^{2}-b^{-1}z_{0}^{2}
.
Then
\mbox{ord}_{\mathfrak{l}}(f(y_{0}))\geq 3
and
\mbox{ord}_{\mathfrak{l}}(f^{\prime}(y_{0}))=\mbox{ord}_{\mathfrak{l}}(2)=1
.
Therefore,
we can apply Hensel’s lemma
[
5
, Proposition 4.1.37]
to
f(y)

and obtain a root
y_{1}\in\mathcal{O}_{\mathfrak{l}}^{\times}
of
f(y)
.
This means
\left(\frac{a,b}{\mathfrak{l}}\right)=1
.
The case
z_{0}\in\mathcal{O}_{\mathfrak{l}}^{\times}
can be proven
by defining
f
as
f(z)=z^{2}-ax_{0}^{2}-by_{0}^{2}
.
∎

Lemma 4.6
.

Fix a prime ideal
\mathfrak{l}
of
\mathcal{O}_{H}
above
2
and
a\in H^{\times}
.
The quadratic Hilbert symbol
\left(\frac{a,p_{k}}{\mathfrak{l}}\right)
is determined by
k\bmod{2}
.

Proof.

Recall that
p_{k}=1-\alpha^{k}\xi
, where
\alpha
is a generator
of
\lambda^{3}

and that
\lambda
is a prime ideal of
\mathcal{O}_{K}
above
2
.

From Lemma
4.5
,
the quadratic Hilbert symbol in this lemma
is determined by
p_{k}\bmod{\mathfrak{l}^{3}}
.
If
\mathfrak{l}
divides
\lambda
then
p_{k}\equiv 1\pmod{\mathfrak{l}^{3}}
for any
k
.
Otherwise,
\mathfrak{l}
divides
\bar{\lambda}
,
so
\alpha\equiv\mathrm{Tr}_{K/\mathbb{Q}}(\alpha)\pmod{\mathfrak{l}^{3}}
.
Since
\mathrm{Tr}_{K/\mathbb{Q}}(\alpha)
is an odd integer,

\alpha^{k}\bmod{\mathfrak{l}^{3}}
is determined by
k\bmod{2}
.
∎

Proof of Theorem
4.4
.

By the product formula of Hilbert symbols
[
10
, Theorem (8.1)]
,
we have

(4.2)

\left(\frac{a}{\mathfrak{p}_{k}}\right)=\prod_{\mathfrak{l}\mid 2}\left(\frac{a,p_{k}}{\mathfrak{l}}\right)\prod_{\mathfrak{l}\mid a\mathcal{O}_{H}\mbox{ and }\mathfrak{l}\nmid 2}\left(\frac{p_{k}}{\mathfrak{l}}\right)^{\mbox{ord}_{l}(a)}

for
a\in H^{\times}
, where
\mathfrak{l}
runs over the prime ideals of
H
different from
\mathfrak{p}_{k}
.
From Lemma
4.6
,
the first product of the right-hand side of (
4.2
)
is determined by
k\bmod{2}
.
Since a residue symbol modulo
\mathfrak{l}
is determined by
k\bmod{N_{\mathfrak{l}}}
,
the second product of the right-hand side of (
4.2
)
is determined by
k
modulo the least common multiple of
N_{\mathfrak{l}}

for the prime ideals
\mathfrak{l}
of
\mathcal{O}_{H}
dividing
a
and not dividing
2
.
This completes the proof.
∎

We denote
the right-hand side of (
4.2
)
by
s_{k}(a)
.
Note that
s_{k}(a)
is defined even if
\mathfrak{p}_{k}
is not a prime ideal
and equal to
\left(\frac{a}{\mathfrak{p}_{k}}\right)
if
\mathfrak{p}_{k}
is a prime ideal.

4.3.2.
Determining
T_{1}

As mentioned in §
3
,
we can use Theorem 5.3 of
[
11
]
for determining
T_{1}
.
Since
B
is square in
\mathcal{O}_{H}
,
if
\mathfrak{p}_{k}
is a prime ideal and

\left(\frac{6\bm{\gamma}_{3}(E)}{\mathfrak{p}_{k}}\right)\epsilon_{k}=1

then (i) in Assumption
3.2
holds.
Therefore, we can define

(4.3)

T_{1}\coloneqq\{k\in\mathbb{N}\mid s_{k}(6\bm{\gamma}_{3}(E))\epsilon_{k}=1\}.

In the following,
we show how to compute
\epsilon_{k}
and
\bm{\gamma}_{3}(E)
.

First, we show that
\epsilon_{k}
is determined by
k\bmod{2}
.
Let
D
be the discriminant of
\mathcal{O}_{K}
.
We fix a square root of
D
in
K
and denote it by
\sqrt{D}
.
Proposition 6.2 of
[
11
]
says that, in our case,

(4.4)

\displaystyle\epsilon_{k}=\begin{cases}1&\mbox{ if }\pi_{k}^{3}\equiv 1\mbox{ or }-\sqrt{D}\pmod{4},\\
-1&\mbox{ otherwise}.\end{cases}

Since 2 splits in
K
,
we have
(\mathcal{O}_{K}/4\mathcal{O}_{K})^{\times}\cong(\mathbb{Z}/4\mathbb{Z})^{\times}\oplus(\mathbb{Z}/4\mathbb{Z})^{\times}
.
Therefore,
\pi_{k}\bmod{4}
is determined by
k\bmod{2}
,
so
\epsilon_{k}
is also determined by
k\bmod{2}
.

Next, we show how to compute
\bm{\gamma}_{3}(E)
.
We have
\bm{\gamma}_{3}(E)\in H
(Lemma 3.4 of
[
11
]
) and

(4.5)

\bm{\gamma}_{3}(E)^{2}=j(E)-1728.

This equation determines
\bm{\gamma}_{3}(E)
up to sign.
The sign can be determined as follows.
Let
p
be a rational prime
congruent to
3
modulo
4
,
splitting in
\mathcal{O}_{K}
,
and not dividing the discriminant of
E
.
Let
\pi
be a prime of
\mathcal{O}_{K}
above
p

and let
\mathfrak{p}
be a a prime ideal of
\mathcal{O}_{H}
above
\pi
.
We denote the reduction of
E
modulo
\mathfrak{p}
by
\bar{E}
.
Theorem 5.3 of
[
11
]
says that
the Frobenius endomorphism of
\bar{E}
is

\left(\frac{6\bm{\gamma}_{3}(E)}{\mathfrak{p}}\right)\epsilon(\pi)[\pi]
,
where
\epsilon(\pi)
is defined in the same way as in (
4.4
).
Since
p\equiv 3\pmod{4}
and
p
splits in
\mathcal{O}_{K}
,
we have
\left(\frac{-1}{\mathfrak{p}}\right)=-1
.
Therefore, we can determine the sign of
\bm{\gamma}_{3}(E)
by checking whether

(4.6)

\left(\frac{6\bm{\gamma}_{3}(E)}{\mathfrak{p}}\right)\epsilon(\pi)[\pi]Q=Q

for
Q\in\bar{E}(\mathcal{O}_{H}/\mathfrak{p})
such that
[2]Q\neq O_{\bar{E}}
.
More precisely, the sign of
\bm{\gamma}_{3}(E)
can be determined as follows.

(1)

Compute a square root
t
of
j(E)-1728
.

(2)

Determine
\epsilon(\pi)
by (
4.4
).

(3)

Take
Q\in\bar{E}(\mathcal{O}_{H}/\mathfrak{p})
such that
[2]Q\neq O_{\bar{E}}
.

(4)

If
\left[\left(\frac{6t}{\mathfrak{p}}\right)\epsilon(\pi)\mathfrak{p}\right]Q=Q

then
\bm{\gamma}_{3}(E)=t
, otherwise
\bm{\gamma}_{3}(E)=-t
.

We can take
p=59
in the case

and
p=47
in the case

.

4.3.3.
Determining
T_{2}

We use Theorem
3.4

to determine
T_{2}
.
In particular, we show the following theorem.

Theorem 4.7
.

There exists a polynomial
f
with coefficients in
\mathcal{O}_{H}
of degree
2

such that
when
\mathfrak{p}_{k}
is a prime ideal, the following are equivalent:

(a)

\tilde{P}\not\in[\lambda]\tilde{E}(\mathcal{O}_{H}/\mathfrak{p}_{k})
,

(b)

f\bmod\mathfrak{p}_{k}
has a multiple root
or does not have a root in
\mathcal{O}_{H}/\mathfrak{p}_{k}
.

Proof.

Let
\varphi
be an isogeny from
E
with kernel
E[\bar{\lambda}]

and
E^{\prime}:y^{2}=x^{3}+A^{\prime}x+B^{\prime}
its codomain.
The theory of complex multiplication shows that

E^{\prime}
has also CM by
\mathcal{O}_{K}
.
Therefore, we can assume that
A^{\prime}
and
B^{\prime}
are in
\mathcal{O}_{H}
.

From Lemma 4.6 of
[
3
]
,
we have
E^{\prime}[\lambda]\subset E^{\prime}(H)
.
Therefore, the field
F
in Theorem
3.4
is equal to
H
in our case.
Consequently,
when
\mathfrak{p}_{k}
is a prime ideal,
(a) holds if and only if

\mathfrak{p}_{k}
does not split completely in
H(\widehat{\varphi}^{-1}(P))
.

Let
x_{0}
be the
x
-coordinate of the generator of
E^{\prime}[\lambda]
.
Since
\lambda
divides
2
, we have
x_{0}
is a root of
x^{3}+A^{\prime}x+B^{\prime}
.
Therefore, we have
x_{0}\in\mathcal{O}_{H}
.

By Vélu’s formula
[
18
]
,
the image of an affine point
(x,y)\in E^{\prime}
under
\widehat{\varphi}
is given by

(4.7)

\widehat{\varphi}(x,y)=\left(\frac{f(x)}{x-x_{0}},\frac{g(x)}{(x-x_{0})^{2}}y\right),

where and
f,g
are univariate polynomials over
H
of degree
2
.
From the explicit form of Vélu’s formula,
we can show that the coefficients of
f
and
g
are in
\mathbb{Z}[A^{\prime},B^{\prime},x_{0}]
.
Therefore, the coefficients of
f
and
g
are in
\mathcal{O}_{H}
.

Let
H_{f}
be the splitting field of
f
over
H
.
Then
H_{f}
is a subfield of
H(\widehat{\varphi}^{-1}(P))
.
Note that the degrees of these fields over
H
are at most
2

and that
H_{f}\subseteq H(\widehat{\varphi}^{-1}(P))
.
Therefore, we have
H_{f}=H(\widehat{\varphi}^{-1}(P))
if
H_{f}\neq H
.

Assume that
H_{f}=H
.
Let
Q
be a point in
\widehat{\varphi}^{-1}(P)
.
The
x
-coordinate of
Q
is a root of
f
, so it is in
H
.
Then
Q^{\sigma}=\pm Q
for any
\sigma
in the Galois group of
H(\widehat{\varphi}^{-1}(P))/H
.
If there exists
\sigma
such that
Q^{\sigma}=-Q

then we have
-P=\widehat{\varphi}(-Q)=\widehat{\varphi}(Q^{\sigma})=(\widehat{\varphi}(Q))^{\sigma}=P^{\sigma}=P
.
This means that
P\in E[2]
.
This contradicts
P=(0,\beta)
with
\beta\neq 0
.
Note that
B\neq 0
since
E
does not have CM by the Gauss integer ring.
Therefore, we have
Q\in E^{\prime}(H)
.
This means that
H(\widehat{\varphi}^{-1}(P))=H
.

Therefore, we have
H_{f}=H(\widehat{\varphi}^{-1}(P))
in any case.
This means that when
\mathfrak{p}_{k}
is a prime ideal,
it follows that
\mathfrak{p}_{k}
does not split completely in
H(\widehat{\varphi}^{-1}(P))

if and only if (b) holds.
∎

Let
f
be the same as in the proof of Theorem
4.7

and denote the discriminant of
f
by
\mathrm{disc}(f)
.
Then we can define

(4.8)

T_{2}\coloneqq\{k\in\mathbb{N}\mid s_{k}(\mathrm{disc}(f))\neq 1\}.

Remark 4.8
.

For computing the isogeny
\varphi
with kernel
E[\bar{\lambda}]
,
we need to compute the action of
\bar{\lambda}
on
E
.
It suffices for this to obtain
[\tau]
as a rational map,
where
\tau
is an element of
\mathcal{O}_{K}
such that
\mathcal{O}_{K}=\mathbb{Z}+\mathbb{Z}\tau
.
In our case, the norm of
\tau
is small (
6
or
8
in the case
K=\mathbb{Q}(\sqrt{-23})
or
\mathbb{Q}(\sqrt{-31})
, respectively).
Therefore, the rational map of
[\tau]
consists of polynomials of degree at most
8
.
We can find the rational map of
[\tau]
by computing all the cyclic isogenies from
E
of degree
\mathrm{N}_{K/\mathbb{Q}}(\tau)
by Vélu’s formula.
There are exactly two such isogenies from
E
to
E
, which correspond to
[\tau]
and
[\bar{\tau}]
.
We can determine the desired
[\tau]
by computing these invariant differentials.

4.3.4.
Algorithm

The remaining task for determining
T_{1}
and
T_{2}
explicitly
is to determine the condition on
k
to satisfy
s_{k}(a)\in S

for given
a\in\mathcal{O}_{H}
and
S\subset\{-1,0,1\}
.
Theorem
4.4
shows that
there exist a positive integer
M
and a subset
\mathcal{T}_{a,S}
of
\mathbb{Z}/M\mathbb{Z}

such that

s_{k}(a)\in S

if and only if

k\bmod{M}\in\mathcal{T}_{a,S}
.

We can determine
M
and a subset
\mathcal{T}_{a,S}
by the following algorithm.

Algorithm 4.9
.

For
a\in\mathcal{O}_{H}
and
S\subset\{-1,0,1\}
,
return
a positive integer
M
and a subset
\mathcal{T}_{a,S}
of
\mathbb{Z}/M\mathbb{Z}

such that

s_{k}(a)\in S

if and only if

k\bmod{M}\in\mathcal{T}_{a,S}
.

1.

Set
N
be the least common multiple of
2
and

N_{\mathfrak{l}}
for the prime ideals
\mathfrak{l}
of
\mathcal{O}_{H}

dividing
a
and not dividing
2
.

2.

Set
\mathcal{T}=\emptyset
.

3.

For
k\in\{1,\dots,N\}
, if
s_{k}(a)\in S
then append
k
to
\mathcal{T}
.

4.

Set
M=\min\{t\in\mathbb{N}\mid t\mbox{ divides }N\mbox{ and }k\in T\Rightarrow k+t\in T\mbox{ for all }k\in\{1,\dots,N-t\}\}
.

5.

Return
M
and
\{k\in\mathcal{T}\mid k\leq M\}
.

For
T_{1}
, we use Algorithm
4.9
with input
6\bm{\gamma}_{3}(E)
and
\{1\}

replacing

s_{k}(a)\in S
in Step
3
with
s_{k}(a)\epsilon_{k}
.
For
T_{2}
, the input is
\mathrm{disc}(f)
and
\{-1,0\}
.

4.4.
Primality proving

Now, we describe our primality proving algorithm.
In our algorithm,
we need to compute a square root of
D
modulo
F_{k}
.
For this, we use Algorithm 2.3.8 in
[
6
]
.
This algorithm terminates in deterministic polynomial time in
k
in our case since
F_{k}\not\equiv 1\pmod{8}
.
We note that this algorithm
can be defined even if
F_{k}
is not prime.
In this case, the output is not necessarily a square of
D
modulo
F_{k}
.
Therefore, if the output is not a square of
D
modulo
F_{k}

then we can determine that
F_{k}
is not prime.

Let
C_{k}
be the odd part of
\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})
.
We assume that
2^{6k+1}
does not divide
\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})
.
Then we can construct a primality proving
by replacing
\gamma
in Theorem
3.3
with
C_{k}
.
In particular,
we obtain the following primality proving algorithm.

Algorithm 4.10
.

For
k\in T_{0}\cap T_{1}\cap T_{2}
such that
F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})^{2}

and
2^{6k+1}
does not divide
\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha)
,
this algorithm returns whether
F_{k}
is prime.

1.

Compute
r
by Algorithm 2.3.8 in
[
6
]
with input
F_{k}
and
D
.

2.

If
r^{2}\not\equiv D\pmod{F_{k}}
then return
False
.

3.

Let
a
be an integer modulo
F_{k}
by replacing
\sqrt{D}
in
\alpha
with
r
.

4.

Let
t
be
a^{-k}\bmod{F_{k}}
.

5.

Compute
t^{3}+c_{1}t+c_{0}\bmod{F_{k}}
,
where
\sqrt{D}
in
c_{0}
and
c_{1}
is replaced with
r
.
If it is not congruent to zero then replace
r
with
-r
and go to Step
3
,

6.

Define an elliptic curve
E^{\prime}
over
\mathbb{Z}/F_{k}\mathbb{Z}
and its point
P^{\prime}

by replacing
\sqrt{D}
with
r
and
\xi
with
t
in
E
and
P
.

7.

Compute
Q=[2^{6k-1}C_{k}]P^{\prime}
.

8.

If
Q
is not strongly nonzero modulo
F_{k}
then return
False
.

9.

Return whether
[2]Q\equiv O_{E^{\prime}}\pmod{F_{k}}
.

This algorithm is analogous to Algorithm 6.3 in
[
3
]
,
which is a primality proving algorithm for an integer sequence obtained from
\mathbb{Q}(\sqrt{-15})
.
As in Algorithm 6.3 in
[
3
]
,
the complexity of this algorithm is
O(k^{2}\log k\log\log k)
.
We show the correctness of Algorithm
4.10
.
The proof is similar to that of Theorem
3.3
by
[
3
]
.
For the proof,
we recall a lemma from
[
3
]
.

Lemma 4.11

(Lemma 2.5 of
[
3
]
)
.

IF
C,F\in\mathbb{R},C\geq 1
, and
F>16C^{2}
,
then
C(F^{1/4}+1)^{2}<(\sqrt{F}-1)^{2}
.

Theorem 4.12
.

Algorithm
4.10
returns
True

if and only if
F_{k}
is prime.

Proof.

Assume that
F_{k}
is prime.
Then
\mathfrak{p}_{k}
is a prime ideal
and we can define the reduction
\tilde{E}
and
\tilde{P}
.
From Lemma
4.3
,
we have
\mathbb{Z}/F_{k}\mathbb{Z}\cong\mathcal{O}_{H}/\mathfrak{p}_{k}
.
Therefore, there exists a square root of
D
modulo
F_{k}

and the condition in Step 2 holds.
In Step 5,
r
and
t
satisfy that

r\equiv\sqrt{D}\mbox{ and }t\equiv\xi\pmod{\mathfrak{p}_{k}}.

Therefore,
through the isomorphism
\mathcal{O}_{H}/\mathfrak{p}_{k}\cong\mathbb{Z}/F_{k}\mathbb{Z}
,
we can identify
E^{\prime}
with
\tilde{E}
and
P^{\prime}
with
\tilde{P}
.

Since the Frobenius endomorphism on
\tilde{E}

is
[\pi_{k}]
,
we have

\displaystyle\tilde{E}(\mathcal{O}_{H}/\mathfrak{p}_{k})

\displaystyle\cong\mathcal{O}_{K}/(\pi_{k}-1)\mathcal{O}_{K}

\displaystyle=\mathcal{O}_{K}/(\alpha^{2k}(c_{1}+c_{0}\alpha^{k}))\mathcal{O}_{K}

\displaystyle\cong\mathbb{Z}/2^{6k}\mathbb{Z}\oplus\mathcal{O}_{K}/(c_{1}+c_{0}\alpha^{k})\mathcal{O}_{K}.

From this and the assumption that
2^{6k+1}
does not divide
\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})
,
we have

[2^{6k}C_{k}]\tilde{P}=O_{\tilde{E}}
.
In addition,
[2^{6k-1}C_{k}]\tilde{P}\neq O_{\tilde{E}}

since
\tilde{P}\notin[2]\tilde{E}(\mathcal{O}_{H}/\mathfrak{p}_{K})
.
This means that the condition in Step 8 does not hold
and that the congruence in Step 9 holds.

Conversely, we assume that Algorithm
4.10
returns
True
.
This means that,
for any prime factor
p
of
F_{k}
,
there exists a point
in
E^{\prime}\bmod{p}
of order at least
2^{6k}
.

Assume that
F_{k}
is not prime.
Let
p
be the smallest prime factor of
F_{k}
.
Then
\sqrt{F_{k}}\geq p
.
By the Hasse’s theorem
[
15
, Theorem V.1.1]
,
the order of
(E^{\prime}\bmod{p})(\mathbb{Z}/p\mathbb{Z})
is at most
(\sqrt{p}+1)^{2}
.
Therefore, we have

\displaystyle(F_{k}^{1/4}+1)^{2}

\displaystyle\geq(\sqrt{p}+1)^{2}\geq 2^{6k}=\mathrm{N}_{K/\mathbb{Q}}\left(\frac{\pi_{k}-1}{c_{1}+c_{0}\alpha^{k}}\right)

\displaystyle=\frac{(\pi_{k}-1)(\overline{\pi_{k}}-1)}{\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})}=\frac{F_{k}-\mathrm{Tr}_{K/\mathbb{Q}}(\pi_{k})+1}{\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})}

\displaystyle\geq\frac{F_{k}-2\sqrt{F_{k}}+1}{\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})}=\frac{(\sqrt{F_{k}}-1)^{2}}{\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})}.

The final inequality comes from the fact that

\mathrm{Tr}_{K/\mathbb{Q}}(\beta)^{2}\leq 4\mathrm{N}_{K/\mathbb{Q}}(\beta)
for any
\beta\in K
.
From the above inequality, we have

\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})(F_{k}^{1/4}+1)^{2}\geq(\sqrt{F_{k}}-1)^{2}.

This contradicts Lemma
4.11
with
C=\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})

and
F=F_{k}
.
Therefore,
F_{k}
must be prime.
∎

5.
Examples

As mentioned above,
our algorithm can be applied to the following two cases.

(1)

K=\mathbb{Q}(\sqrt{-23})
and
\xi
is a root of
x^{3}-x-1
,

(2)

K=\mathbb{Q}(\sqrt{-31})
and
\xi
is a root of
x^{3}+x+1
.

In these cases, the sequences
\{F_{k}\}
determined the primality are

(1)

F_{k}=\mathrm{N}_{\mathbb{Q}(\sqrt{-23})/\mathbb{Q}}\left(1-\left(\frac{3+\sqrt{-23}}{2}\right)^{2k}-\left(\frac{3+\sqrt{-23}}{2}\right)^{3k}\right)
,

(2)

F_{k}=\mathrm{N}_{\mathbb{Q}(\sqrt{-31})/\mathbb{Q}}\left(1+\left(\frac{1+\sqrt{-31}}{2}\right)^{2k}+\left(\frac{1+\sqrt{-31}}{2}\right)^{3k}\right)
.

In these cases,
the conditions on
k
in Algorithm
4.10

hold for
k\geq 2
.
In particular,
we have the following lemmas.

Lemma 5.1
.

Let
k\geq 2
be an integer
and
F_{k}
one of the two integers defined above.
We define

•

c_{0}=c_{1}=-1
and
\alpha=\frac{3+\sqrt{-23}}{2}

if
F_{k}
is the sequence defined by (1),

•

c_{0}=c_{1}=1
and
\alpha=\frac{1+\sqrt{-31}}{2}

if
F_{k}
is the sequence defined by (2).

Then we have

(5.1)

F_{k}>16\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})^{2}.

Proof.

Let
K
be
\mathbb{Q}(\sqrt{-23})
in the case (1) or
\mathbb{Q}(\sqrt{-31})
in the case (2).
Note that we have
F_{k}=\mathrm{N}_{K/\mathbb{Q}}(1+c_{1}\alpha^{2k}+c_{0}\alpha^{3k})
in the both cases.

For any
\beta\in K
, we have

\mathrm{Tr}_{K/\mathbb{Q}}(\beta)^{2}\leq 4\mathrm{N}_{K/\mathbb{Q}}(\beta)
.
Since

c_{0},c_{1}\in\{\pm 1\}
and
\mathrm{N}_{K/\mathbb{Q}}(\alpha)=8
, we have

\displaystyle F_{k}

\displaystyle=8^{3k}+8^{2k}+1+c_{1}\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{2k})+c_{0}\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{3k})+c_{0}c_{1}8^{2k}\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{k})

\displaystyle\geq 8^{3k}+8^{2k}+1-4(8^{k}+8^{1.5k}+8^{2.5k})

\displaystyle>8^{3k}-8\cdot 8^{2.5k}.

On the other hand,

\displaystyle\mathrm{N}_{K/\mathbb{Q}}(c_{1}+c_{0}\alpha^{k})=\mathrm{N}_{K/\mathbb{Q}}(1+\alpha^{k})=8^{k}+1+\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{k})<2\cdot 8^{k}.

Therefore, (
5.1
) holds if

8^{3k}-8\cdot 8^{2.5k}>16(2\cdot 8^{k})^{2}
.
If
k\geq 5
then
this inequality holds since
8^{3k}>72\cdot 8^{2.5k}
.
Computing explicitly both sides in (
5.1
) for
k=2,3,4
,
we obtain our assertion.
∎

Lemma 5.2
.

Let
K
be an imaginary quadratic field,

k
be a positive integer,
c_{0},c_{1}\in\{\pm 1\}
.
Let
\alpha\in\mathcal{O}_{K}
such that
\mathrm{N}_{K/\mathbb{Q}}(\alpha)=8
.
Then
2^{6k}
does not divide
N_{K/\mathbb{Q}}(c_{0}+c_{1}\alpha^{k})
.

Proof.

It suffices to show
N_{K/\mathbb{Q}}(c_{0}+c_{1}\alpha^{k})<2^{6k}
.
As in the proof of Lemma
5.1
,
we have
\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{k})\leq 2\sqrt{\mathrm{N}_{K/\mathbb{Q}}(\alpha^{k})}=2\cdot 2^{1.5k}
.
Therefore,

N_{K/\mathbb{Q}}(c_{0}+c_{1}\alpha^{k})=1+2^{3k}\pm\mathrm{Tr}_{K/\mathbb{Q}}(\alpha^{k})\leq(1+2^{1.5k})^{2}<(2\cdot 2^{1.5k})^{2}<2^{6k}.

∎
