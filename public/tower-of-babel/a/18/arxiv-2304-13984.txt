An FPTAS for Budgeted Laminar Matroid Independent Set
Ilan Doron-Arad, Ariel Kulik, Hadas Shachnai

Abstract
We study the budgeted laminar matroid independent set problem. The input is a ground set, where each element has a cost and a non-negative profit, along with a laminar matroid over the elements and a budget. The goal is to select a maximum profit independent set of the matroid whose total cost is bounded by the budget. Several well known special cases, where we have, e.g., no matroid constraint (the classic knapsack problem) or a uniform matroid constraint (knapsack with a cardinality constraint), admit a fully polynomial-time approximation scheme (FPTAS) . In contrast, the budgeted matroid independent set (BMI) problem with a general matroid has an efficient polynomial-time approximation scheme (EPTAS) but does not admit an FPTAS. This implies an EPTAS for our problem, which is the best known result prior to this work. We present an FPTAS for budgeted laminar matroid independent set, improving the previous EPTAS for this matroid family and generalizing the FPTAS known for knapsack with a cardinality constraint and multiple-choice knapsack. Our scheme is based on a simple dynamic program which utilizes the tree-like structure of laminar matroids.

3
A Pseudo-polynomial Time Algorithm

In this section we give a pseudo-polynomial time algorithm for BLM. Let
I=(S,{\mathcal{F}},k,c,p,B)
be a BLM instance, and define
P_{I}=\{0,1,\ldots,|S|\cdot\max_{e\in S}p(e)\}
. Observe that for any solution
T\subseteq S
it holds that
p(T)\in P_{I}
. Also, there may be
t\in P_{I}
such that
t\neq p(T)
for any
T\subseteq S
. Our algorithm computes the following table.

Definition 3.1
.

For any
BLM
instance
I=(S,{\mathcal{F}},k,c,p,B)
, define the
DP
table of
I
as the function
\textnormal{{DP}}_{I}:\{0,....|S|\}\times P_{I}\to\mathbb{N}\cup\infty
such that for all
q\in\{0,1,\ldots,|S|\}
and
t\in P_{I}
,

\textnormal{{DP}}_{I}(q,t)=\min_{Q\in{\mathcal{I}}_{{\mathcal{F}},k}\textnormal{ s.t. }|Q|=q,~p(Q)=t}c(Q).

For any
q\in\{0,1,\ldots,|S|\}
and
t\in P_{I}
, the entry
\textsf{DP}_{I}(q,t)
gives the minimum cost of an independent set in
{\mathcal{I}}_{{\mathcal{F}},k}
of exactly
q
elements and profit equal to
t
; if there is no such independent set then
\textsf{DP}_{I}(q,t)=\infty
. Also,
\textsf{DP}_{I}(q,t)=\infty
if
q
or
t
do not belong to the domain of
\textsf{DP}_{I}
(e.g.,
q=|S|+1
).

We formulate a dynamic program which computes the table
\textsf{DP}_{I}
. Informally, the table
\textsf{DP}_{I}
is constructed by taking a maximal set
X\in{\mathcal{F}}\setminus\{S\}
in the laminar family (recall that a maximal set is not a subset of any other set in
{\mathcal{F}}\setminus\{S\}
). Our algorithm computes the sub-tables
\textsf{DP}_{I\cap X}
and
\textsf{DP}_{I\setminus X}
recursively. An important observation is that the instances
I\cap X
and
I\setminus X
are disjoint;
thus, the table
\textsf{DP}_{I}
can be computed from
DP_{I\cap X}
and
DP_{I\setminus X}
using a convolution.
Specifically, to compute an entry
\textsf{DP}_{I}(q,t)
for
q\in\{0,1,\ldots,|S|\}
and
t\in P_{I}
, we find the minimum solution induced by partitioning the values
q
and
t
between the complementary sub-instances
I\cap X
and
I\setminus X
. This is formalized by the next lemma.

Lemma 3.2
.

Let
I=(S,{\mathcal{F}},k,c,p,B)
be a
BLM
instance, and
X\in{\mathcal{F}}\setminus\{S\}
a maximal set. Then, for all
q\in\{0,1,\ldots,|S|\}
and
t\in P_{I}
,

\textnormal{{DP}}_{I}(q,t)=\begin{cases}\min_{\begin{subarray}{c}q_{1},q_{2},t_{1},t_{2}\in\mathbb{N}\textnormal{ s.t. }\\
q_{1}+q_{2}=q,~t_{1}+t_{2}=t\end{subarray}}\left\{\textnormal{{DP}}_{I\cap X}(q_{1},t_{1})+\textnormal{{DP}}_{I\setminus X}(q_{2},t_{2})\right\}~~&\textnormal{if}\ q\leq k(S)\\
\infty~~&\textnormal{otherwise}\end{cases}

Proof.

Let
q\in\{0,1,\ldots,|S|\}
and
t\in P_{I}
. For simplicity, let

M=\min_{\begin{subarray}{c}q_{1},q_{2},t_{1},t_{2}\in\mathbb{N}\textnormal{ s.t. }\\
q_{1}+q_{2}=q,~t_{1}+t_{2}=t\end{subarray}}\left\{\textnormal{{DP}}_{I\cap X}(q_{1},t_{1})+\textnormal{{DP}}_{I\setminus X}(q_{2},t_{2})\right\}.

We first consider the case where
\textnormal{{DP}}_{I}(q,t)
and
M
differ from
\infty
. We use the following auxiliary claims.

Claim 3.3
.

If
\textnormal{{DP}}_{I}(q,t)\neq\infty
then
M\leq\textnormal{{DP}}_{I}(q,t)
.

Proof.

As
\textnormal{{DP}}_{I}(q,t)\neq\infty
there is
Q^{*}\in{\mathcal{I}}_{{\mathcal{F}},k}
such that

Q^{*}=\argmin_{Q\in{\mathcal{I}}_{{\mathcal{F}},k}\textnormal{ s.t. }|Q|=q,~p(Q)=t}c(Q).

(1)

Let
q^{*}_{1}=|Q^{*}\cap X|,q^{*}_{2}=|Q^{*}\setminus X|,t^{*}_{1}=p(Q^{*}\cap X)
, and
t^{*}_{2}=p(Q^{*}\setminus X)
. By (
1
), and since
S=X\uplus(S\setminus X)
, it holds that

|Q^{*}|=|Q^{*}\cap X|+|Q^{*}\setminus X|=q^{*}_{1}+q^{*}_{2}=q

and

p(Q^{*})=p(Q^{*}\cap X)+p(Q^{*}\setminus X)=t^{*}_{1}+t^{*}_{2}=t.

Moreover, by Observation
2.2
, since
Q^{*}\in{\mathcal{I}}_{{\mathcal{F}},k}
, it holds that
Q^{*}\cap X\in{\mathcal{I}}(I\cap X)
and
Q^{*}\setminus X\in{\mathcal{I}}(I\setminus X)
. Thus,

\displaystyle\textnormal{{DP}}_{I}(q,t)=c(Q^{*})=c(Q^{*}\cap X)+c(Q^{*}\setminus X)\geq\textnormal{{DP}}_{I\cap X}(q^{*}_{1},t^{*}_{1})+\textnormal{{DP}}_{I\setminus X}(q^{*}_{2},t^{*}_{2})\geq M.

The first inequality holds since
\textnormal{{DP}}_{I\cap X}(q^{*}_{1},t^{*}_{1})
is the minimum cost of
Q\in{\mathcal{I}}(I\cap X)
such that
|Q|=q^{*}_{1}
and
p(Q)=t^{*}_{1}
; since
Q^{*}\cap X
satisfies these conditions (by Observation
2.2
), we conclude that
c(Q^{*}\cap X)\geq\textnormal{{DP}}_{I\cap X}(q^{*}_{1},t^{*}_{1})
. Similar arguments show that
c(Q^{*}\setminus X)\geq\textnormal{{DP}}_{I\setminus X}(q^{*}_{2},t^{*}_{2})
. The second inequality holds since

is the minimum value of
\textnormal{{DP}}_{I\cap X}(q_{1},t_{1})+\textnormal{{DP}}_{I\setminus X}(q_{2},t_{2})

q^{*}_{1},q^{*}_{2},t^{*}_{1},t^{*}_{2}\in\mathbb{N}
and
q^{*}_{1}+q^{*}_{2}=q,t^{*}_{1}+t^{*}_{2}=t

\square

Claim 3.4
.

If
M\neq\infty

q\leq k(S)

\textnormal{{DP}}_{I}(q,t)\leq M
.

Proof.

Let
q^{\prime}_{1},q^{\prime}_{2},t^{\prime}_{1},t^{\prime}_{2}\in\mathbb{N},q^{\prime}_{1}+q^{\prime}_{2}=q,t^{\prime}_{1}+t^{\prime}_{2}=t

\textnormal{{DP}}_{I\cap X}(q^{\prime}_{1},t^{\prime}_{1})+\textnormal{{DP}}_{I\setminus X}(q^{\prime}_{2},t^{\prime}_{2})=M.

Since
M\neq\infty
, there exist

Q^{\prime}_{1}=\argmin_{Q\in{\mathcal{I}}(I\cap X)\textnormal{ s.t. }|Q|=q^{\prime}_{1},~p(Q)=t^{\prime}_{1}}c(Q),~~~~~~~~~~~~~~~~~Q^{\prime}_{2}=\argmin_{Q\in{\mathcal{I}}(I\setminus X)\textnormal{ s.t. }|Q|=q^{\prime}_{2},~p(Q)=t^{\prime}_{2}}c(Q).

(2)

By (
2
),

\displaystyle M={}

\displaystyle\textnormal{{DP}}_{I\cap X}(q^{\prime}_{1},t^{\prime}_{1})+\textnormal{{DP}}_{I\setminus X}(q^{\prime}_{2},t^{\prime}_{2})

\displaystyle={}

\displaystyle c(Q^{\prime}_{1})+c(Q^{\prime}_{2})

\displaystyle={}

\displaystyle c(Q^{\prime}_{1}\uplus Q^{\prime}_{2})

\displaystyle\geq{}

\displaystyle\min_{Q\in{\mathcal{I}}_{{\mathcal{F}},k}\textnormal{ s.t. }|Q|=q,~p(Q)=t}c(Q)

\displaystyle={}

\displaystyle\textsf{DP}_{I}(q,t).

and

, by Observation
2.2

Q^{\prime}_{1}\uplus Q^{\prime}_{2}\in{\mathcal{I}}_{{\mathcal{F}},k}
; also,

, and

\square

In this section we use the dynamic program in Section

\left\lfloor\frac{p(e)}{\alpha}\right\rfloor

\bar{I}
,
for which the table
\textsf{DP}_{I}
can be computed efficiently.
Then, by iterating over all possible values in
\textsf{DP}_{I}

\bar{I}

optimal solution for

, where the solution itself is computed using standard backtracking. The pseudocode of the algorithm is given in Algorithm

5
Discussion

In this paper we showed that the budgeted laminar matroid independent set (BLM) problem admits an FPTAS, thus improving upon the existing EPTAS for this matroid family, and generalizing the FPTAS for the special cases of cardinality constrained knapsack and multiple-choice knapsack. Our FPTAS is based on a natural dynamic program which utilizes the tree-like structure of laminar matroids. It seems that
with slight modifications our scheme yields an FPTAS for the more general problem of
budgeted
k
-laminar matroid independent set, where
k\in\mathbb{N}
is fixed.

An intriguing open question is whether BMI admits an FPTAS on other families of matroids, such as graphic matroids, transversal matroids, or linear matroids.

We note that the running time of our scheme is

It would be interesting to design an FPTAS for BLM that matches the running time of
