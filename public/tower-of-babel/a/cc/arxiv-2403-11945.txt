Kernel Modelling of Fading Memory Systems
Yongkang Huo, Thomas Chaffey, Rodolphe Sepulchre

Abstract
The paper is a follow-up of the recently introduced kernel-based framework to identify nonlinear input-output systems regularized by desirable input-output incremental properties. Assuming that the system has fading memory, we propose to learn the functional that maps the past input to the present output rather than the operator mapping input trajectories to output trajectories. While retaining the benefits of the previously proposed framework, this modification simplifies the selection of the kernel, enforces causality, and enables temporal simulation.

The recent article

The method identifies an input-output operator, but the kernel representation of the operator lacks a state-space realization and simulation forwards in time is expensive as it involves computing an entire future trajectory at each time step.

This technical note addresses those issues by exploiting the property of

[

]
of Boyd and Chua, who defined fading memory as an elementary continuity property for such operators. The standard approach in the literature of fading memory systems has been to represent fading memory operators with state-space models. Here we bypass such state-space representations and consider instead a direct kernel-based representation of the fading memory functional.
In comparison to
[
22
]

Our main result is to show that this modified framework retains the benefits of the methodology in
[
22
]
, namely that the learning task can be regularized with desirable input-output incremental properties such as a small Lipschitz constant or incremental passivity.

For

The

A

show that each TI causal operator

We call this functional the

Each time-invariant and causal operator

Define

Since

is continuous

Let

An operator

III
Kernel modeling of fading memory systems

III-A

Fading memory

Fading memory is an important stability property which expresses that the influence of the past input on the current output fades away over time. A LTI system with fading memory property has a convolution representation. Fading memory was originally introduced to system approximation by
[
1
]
, where it was shown that Volterra series are universal approximators of systems with fading memory. The concept later received attention in the context of robust control
[
23
,
24
]
. Recently,
[
25
]
introduced the
reservoir kernel
as a universal approximant for the Volterra series expansion of a fading memory operator.

Instead of the original fading memory definition in
[
1
]
, we adopt and extend the fading
memory norm definition of
[
26
]
and the concept of fading memory normed spaces of
[
2
]
. We use this definition to define the input signal space as a Hilbert space with a fading memory norm, which enables in turn a kernel representation of the memory functional.

Let
w:(-\infty,0]\to(0,1]
be a weight,
such that
\lim_{t\to-\infty}w(t)=0
and
w
has finite
L_{p}
norm for all
1\leq p\leq\infty
. We define the
(w,p)
fading memory norm of a past signal
u
as

\|u\|_{w,p}:=\|u\,w\|_{p},

and the corresponding
(w,p)
fading memory normed space as

{\cal W}_{w,p}\coloneqq\{u:(-\infty,0]\to\mathbb{R}^{m}\;|\;\|u\|_{w,p}<\infty\}.

Note that,
{\cal U}_{\text{past}}
is a subspace of
{\cal W}_{w,p}
.

In this paper, except Section
III-E
, we restrict our attention to the case
p=2
and denote the norm by
\|u\|_{{\cal U}_{\text{past}}}:=\|u\|_{w,2}
. In this case, we also have an inner product, denoted by
\left\langle u,v\right\rangle_{{\cal U}_{\text{past}}}=\left\langle u,v\right\rangle_{w}:=\langle uw,vw\rangle
, where
\langle u,v\rangle
is the regular
L_{2}
inner product. Fading memory is then defined as the continuity with respect to a fading memory norm.

Definition 1
.

Consider an operator
G:{\cal U}\to{\cal Y}
. We say that
G
has
(w,p)

fading memory
if and only if its
functional
F:{\cal U}_{\text{past}}\to\mathbb{R}^{n}
is continuous with respect to the
(w,p)
fading memory norm: for all
\varepsilon>0
, there exists
\delta>0
such that, for
all
u,v\in{\cal U}_{\text{past}}
,

\displaystyle\|u-v\|_{w,p}<\delta

\displaystyle\Rightarrow

\displaystyle|Fu-Fv|<\varepsilon.

III-B

Problem statement

We address the problem of modeling the fading memory functional
F
of a fading memory system given a set of input output data. This is made precise in Objective 1.

Objective 1
.

Given
\left\{(u_{c,i},y_{c,i})\in{\cal U}\times{\cal Y}\right\}_{i=1}^{l}
find
\hat{F}
that satisfies Definition
1
, such that:

\sum_{t=\infty}^{-\infty}\sum_{i=1}^{l}|\hat{F}PU_{t}u_{c,i}-y_{c,i}(t)|^{2}

is minimized.

Let
u_{i,t}=PU_{t}u_{c,i}
and
y_{i,t}=PU_{t}y_{c,i}
. Since in practice, we will not have data with infinite length but instead have data with finite length and finite time samples (e.g.
t\in\mathcal{T},\text{card}(\mathcal{T})=N
), we can drop the subscribe
t
by defining:

\{(u_{j},\,y_{j}(0))\}\;:=\;\bigl\{\,\bigl(u_{i,t},\,y_{i,t}(0)\bigr):\;i=1,\ldots,l,\;t\in\mathcal{T}\bigr\}.

Then we can rewrite our objective to be:

Objective 2
.

Given
\left\{(u_{j},y_{j}(0))\in{\cal U}_{\text{past}}\times\mathbb{R}^{n}\right\}_{i=1}^{l\times N}
, find
\hat{F}
that satisfies Definition
1
, such that:

\sum_{j=1}^{l\times N}|\hat{F}u_{j}-y_{j}(0)|^{2}

is minimized.

Most importantly, we wish to impose the incremental small gain property to the approximated system. The extension to other incremental input-output properties is considered in Section
III-E
.

III-C

Kernel representation of fading memory functionals

The theory of approximation in Reproducing Kernel Hilbert Spaces is well-established for continuous functions in real vector spaces

[
27
]
, and has been extended to arbitrary separable Hilbert spaces in
[
28
]
. We combine these results with the vector-valued kernels defined in
[
29
]
to approximate any continuous vector-valued functional on a compact subset of a separable Hilbert space. Firstly, we define the RKHS of continuous functionals
\{F:{\cal U}_{\text{past}}\to\mathbb{R}^{n}\}
, with the
inner product
\langle\cdot,\cdot\rangle_{{\cal H}}
.

Definition 2

(RKHS)
.

A mapping
k:{\cal U}_{\text{past}}\times{\cal U}_{\text{past}}\to{\cal B}(\mathbb{R}^{n})
, where
{\cal B}(\mathbb{R}^{n})
means bounded linear operator in
\mathbb{R}^{n}
, is called a reproducing kernel of
{\cal H}
if :

1.

k(\cdot,u)\alpha:{\cal U}_{\text{past}}\to\mathbb{R}^{n}
is a member of
\cal H
for all
u\in{\cal U}_{\text{past}}
and
\alpha\in\mathbb{R}^{n}

2.

The reproducing property holds: for all
u\in{\cal U}_{\text{past}}
,
\alpha\in\mathbb{R}^{n}
, and
F\in{\cal H}
:

\langle\alpha,Fu\rangle=\langle F,k(\cdot,u)\alpha\rangle_{{\cal H}}

A
universal kernel
is one that can approximate all fading memory functionals on a compact subset
S\in{\cal U}_{\text{past}}
.

Definition 3

(Universal kernel
[
30
]
)
.

Let
C^{0}(S,\mathbb{R}^{n})
be the set of all continuous functionals mapping
S
to
\mathbb{R}^{n}
. Then if
{\cal H}
is dense in
C^{0}(S,\mathbb{R}^{n})
, the corresponding kernel
k
is called a
universal
kernel
of
C^{0}(S,\mathbb{R}^{n})
.

For every continuous functional
F
on
S
, there exists a sequence of finite linear combinations of
the form

\sum_{i=1}^{m}\alpha_{i}\,k(x_{i},\cdot)\quad(m\in\mathbb{N},\;\alpha_{i}\in\mathbb{R}^{n},\;x_{i}\in S)

that converges uniformly to
F
: for every
\varepsilon>0
, there exists
M
such that, for all
m\geq M
, there exists
\{(\alpha_{i},x_{i})\}
, such that for all
y\in\cal S

\left|\sum_{i=1}^{m}\alpha_{i}\,k(x_{i},y)-F(y)\right|<\varepsilon.

This fact follows from
the Moore–Aronszajn theorem and the definition of universal kernels
[
27
,
28
,
30
]
.

The following theorem of
[
28
]
shows how to find such a kernel for
C^{0}(S,\mathbb{R}^{n})
.

Theorem 3

(
[
28
, Thm. 2.2]
)
.

Let
S
be a compact subset of a separable Hilbert space with inner product
\langle\cdot,\cdot\rangle_{{\cal U}_{\text{past}}}
. Let
\sigma(\cdot):\mathbb{R}\to\mathbb{R}
be a function that can be expressed by its Taylor series

\sigma(t)=\sum_{n=0}^{\infty}c_{n}t^{n}.

If
c_{n}>0
for all
n
then the kernel
k:{\cal U}_{\text{past}}\times{\cal U}_{\text{past}}\to\mathbb{R}

k(u,v)=\sigma(\langle u,v\rangle_{{\cal U}_{\text{past}}})

is a universal kernel of
C^{0}(S,\mathbb{R})
.

Any universal kernel in
C^{0}(S,\mathbb{R})
induces a corresponding universal kernel in
C^{0}(S,\mathbb{R}^{n})
.

Theorem 4
.

For any universal kernel
k
in
C^{0}(S,\mathbb{R})

k_{e}(u,v)=k(u,v)I

is a universal kernel in
C^{0}(S,\mathbb{R}^{n})
, where
I
is the
n\times n
identity matrix.

Proof.

Let
F\in C^{0}(S,\mathbb{R}^{n})
with components
F=(F_{1},\dots,F_{n})^{\top}
. For each
j\in\{1,\dots,n\}
and any
\varepsilon>0
, universality of
k
implies that there exist an integer
l_{j}
, centers
A_{j}:=\{u_{j,i}\}_{i=1}^{l_{j}}\subset S
, and coefficients
\{\alpha_{j,i}\}_{i=1}^{l_{j}}\subset\mathbb{R}
such that

\sup_{u\in S}\Biggl|F_{j}(u)-\sum_{i=1}^{l_{j}}\alpha_{j,i}\,k(u_{j,i},u)\Biggr|<\frac{\varepsilon}{\sqrt{n}}.

Define
\alpha_{j}(u_{i})=\alpha_{j,i},\forall u_{i}\in A_{j}
and let

A:=\bigcup_{j=1}^{n}A_{j},

and enumerate
\{u_{m}\}_{m=1}^{M}:=A
, where
M=\text{Card}(A)
. For each
j
, define

\hat{F}_{j}(u)=\sum_{m=1}^{M}\tilde{\alpha}_{j}(u_{m})\,k(u_{m},u),

where
\tilde{\alpha}_{j}(u_{m})=\alpha_{j}(u_{m})
if
u_{m}\in A_{j}
and zero otherwise.
Let
\hat{F}(u):=(\hat{F}_{1}(u),\dots,\hat{F}_{n}(u))^{\top}=\sum_{m=1}^{M}(\tilde{\alpha}_{1}(u_{m}),\dots,\tilde{\alpha}_{n}(u_{m}))^{\top}\,k(u_{m},u)
. Then

|F(u)-\hat{F}(u)|_{2}\leq\sqrt{n}\max_{1\leq j\leq n}\sup_{u\in{\cal S}}|F_{j}(u)-\hat{F}_{j}(u)|<\varepsilon.

Since
\hat{F}
is a finite linear combination of the kernel sections
k_{e}(u_{m},\cdot)=k(u_{m},\cdot)I
, it belongs to the RKHS of
k_{e}
. As
\varepsilon>0
was arbitrary and
M
is finite, the RKHS of
k_{e}
is dense in
C^{0}(S,\mathbb{R}^{n})
.
∎

A particular example of a universal kernel of
C^{0}(S,\mathbb{R}^{n})
is the Gaussian-type
Radial Basis Function (RBF) kernel with
\sigma\neq 0
:

k_{e}(u,v)=I\operatorname{exp}\left(-\frac{\|u-v\|_{{\cal U}_{\text{past}}}^{2}}{2\sigma^{2}}\right).

Using these results, if the input set
S
is a compact subset of
{\cal U}_{\text{past}}
, we can use kernel methods to approximate any functional in
C^{0}(S,\mathbb{R}^{n})
with a universal kernel. In Appendix
V
, we show that the set of bounded and rate limited signals with a finite upper bound
C_{2}
and Lipschitz constant
C_{1}
:

S_{b}:\{u\in{\cal U}_{\text{past}}|~|u(t_{1})-u(t_{2})|<C_{1}|t_{1}-t_{2}|,~\sup_{t}|u(t)|<C_{2}\}

for some
0<C_{1},C_{2}<\infty
and all
t_{1},t_{2}\leq 0
, is a compact subset of
{\cal U}_{\text{past}}
with a fading memory norm. The same set of signals was adopted in the original work of Boyd and Chua.

III-D

Kernel regularized learning of memory functional

Kernel methods are popular in machine learning for their ability to
regularize
the data fit of the approximation.

Given a finite data set of past inputs and current outputs, together with a fading memory kernel, the representer theorem provides an optimal approximant with the fading memory property.

Theorem 5

(Representer Theorem
[
27
, Thm. 8.7]
)
.

Given
l
past inputs and current outputs
(u_{i},y_{i}(0))\in S_{b}\times\mathbb{R}^{n}
, let
\mathcal{H}
be an RKHS of functionals from
S_{b}
to
\mathbb{R}^{n}
. Then the regularized least-square problem

\min_{\hat{F}\in{\cal H}}\sum_{i=0}^{l}|\hat{F}u_{i}-y_{i}(0)|^{2}+\gamma\|\hat{F}\|^{2}_{\mathcal{H}}.

has a unique solution given by

\hat{F}u=\sum_{i=0}^{l}\alpha_{i}k(u_{i},u),\quad\hat{\alpha}=(K+\gamma I)^{-1}Y,

where
\hat{\alpha}
is a matrix with each row is
\alpha_{i}
,
K_{i,j}=k(u_{i},u_{j})
and
Y
is a matrix with each row is
y_{i}(0)
.

The regularized least squares problem minimizes the sum of an empirical loss and the norm of the functional. Minimizing the empirical loss provides a good data fit whereas minimizing the functional norm gives better generality and robustness to noise in the data. The regularization parameter
\gamma
controls the trade-off between data fit and regularization.

With regularization on the fading memory functional, we can also impose the incremental small gain property on the learned system. In this part, we will first show the relationship between the Lipschitz constant of the functional and the incremental gain of the system and hence prove that by regularizing the Lipschitz constant of the approximated functional, we can ensure that the approximated system has incremental small gain.

First, we define
Lipschitz Kernels
.

Definition 4
.

A kernel
k(u,v)
is said to have
Lipschitz constant
r
if

|k(u,u)-2k(u,v)+k(v,v)|\leq r^{2}\|u-v\|_{{\cal U}_{\text{past}}}^{2},

(1)

for some
r>0
.
It is said to be an non-expansive kernel in
[
22
]
when
0<r\leq 1
.

In addition, if a kernel has Lipschitz constant
r
, then

|\hat{F}u-\hat{F}v|\leq r\|\hat{F}\|_{\mathcal{H}}\|u-v\|_{{\cal U}_{\text{past}}}.

This is a direct application of
[
22
]
[Lemma 1].
Van Waarde and Sepulchre
[
22
]
[Prop. 2] provide several examples of kernels which satisfy property (
1
). In particular, the Gaussian-type RBF-kernel is a universal kernel with Lipschitz constant
r=\frac{1}{\sigma^{2}}
. We now give a condition on the Lipschitz constant of the functional which guarantees an incremental small gain operator.

Theorem 6

(Incremental small gain regularization)
.

Let
{\cal U}_{\text{past}}
be equipped with the norm
\left\|\cdot\right\|_{{\cal U}_{\text{past}}}^{2}=\left\|\cdot\right\|_{w,2}^{2}
. Assume that the weight function
w
satisfies
c\coloneqq\left(\int_{-\infty}^{0}w(t)^{2}dt\right)^{\frac{1}{2}}
.
Suppose
G:{\cal U}\to{\cal Y}
, and its memory functional
F:{\cal U}_{\text{past}}\to\mathbb{R}^{m}
is Lipschitz continuous with respect to the norm
\left\|\cdot\right\|_{{\cal U}_{\text{past}}}
with Lipschitz constant
\beta
. Then
G
has incremental small gain if
\beta^{2}<\frac{1}{c^{2}}
.

Proof.

For
u_{c},v_{c}\in\{u_{c}\in{\cal U}\;|\;\left\|u_{c}\right\|_{2}<\infty\}
, let
u(t,\cdot)
and
v(t,\cdot)
denote the truncated
u_{c}
and
v_{c}
at time
t
such that

u(t,\tau)=\begin{cases}u_{c}(t+\tau)&\tau\leq 0\\
0&\tau>0.\end{cases}

It follows that
Pu_{t},Pv_{t}\in{\cal U}_{\text{past}}
. We then have

\displaystyle\|Gu_{c}-Gv_{c}\|_{2}^{2}

\displaystyle=

\displaystyle\int_{-\infty}^{\infty}|Gu_{c}(t)-Gv_{c}(t)|^{2}dt

\displaystyle=

\displaystyle\int_{-\infty}^{\infty}|FPu(t,\cdot)-FPv(t,\cdot)|^{2}dt

\displaystyle\leq

\displaystyle\int_{-\infty}^{\infty}\beta^{2}\|Pu(t,\cdot)-Pv(t,\cdot)\|_{{\cal U}_{\text{past}}}^{2}dt

=\int_{-\infty}^{\infty}\beta^{2}\int_{-\infty}^{0}|u_{c}(t+\tau)-v_{c}(t+\tau)|^{2}w(\tau)^{2}d\tau dt.

Let
w^{\prime}(\tau)=w(\tau)
for
\tau\leq 0
and
w^{\prime}(\tau)=0
for
\tau>0
. Then

\|Gu_{c}-Gv_{c}\|_{2}^{2}=\int_{-\infty}^{\infty}\beta^{2}\int_{-\infty}^{\infty}|u_{c}(\tau)-v_{c}(\tau)|^{2}w^{\prime}(t+\tau)^{2}d\tau dt

Since
w^{\prime}
is a square integrable function, by Fubini’s theorem,

\|Gu_{c}-Gv_{c}\|_{2}^{2}=\int_{-\infty}^{\infty}\beta^{2}|u_{c}(\tau)-v_{c}(\tau)|^{2}\int_{-\infty}^{\infty}w^{\prime}(t+\tau)^{2}dtd\tau.

Note that
\int_{-\infty}^{\infty}w^{\prime}(t+\tau)^{2}dt=c^{2}
, so we have

\|Gu_{c}-Gv_{c}\|_{2}^{2}=c^{2}\int_{-\infty}^{\infty}\beta^{2}|u_{c}(\tau)-v_{c}(\tau)|^{2}d\tau=\beta^{2}c^{2}\|u_{c}-v_{c}\|_{2}^{2}.

If
\beta^{2}<\frac{1}{c^{2}}
, it follows that the operator
G
has incremental small gain.
∎

To impose incremental small gain on the approximated system, as described in Theorem
6
, it suffices to choose a sufficiently large value for
\gamma
. Obviously, there exists a trade-off between the size of the bias
\gamma
and the incremental gain of the approximated system: enforcing a smaller gain requires a larger bias. We can also use this constraint to impose other IQC properties via the scattering transform, for more detail we refer the reader to
[
22
]
.

III-E

Regularized learning with IQCs constraints

A system
G
is said to be
incrementally passive
, if its input space
{\cal X}
and output space
{\cal Y}
are the same Hilbert space and
\langle Gx_{1}-Gx_{2},x_{1}-x_{2}\rangle\geq 0
for all
x_{1},x_{2}\in{\cal X}

Theorem 7

(Scattering transform between incremental small gain system and incrementally passive system)
.

If a system
E
is incremental small gain and its input space
{\cal X}
and output space
{\cal Y}
are the same Hilbert space, then
G:=(I-E)(I+E)^{-1}
is incrementally passive. If a system
G
is incrementally passive, then
G:=(G-I)(G+I)^{-1}
has incremental small gain.

Similarly to
[
22
]
, we can convert the small gain constraint to other IQCs via a scattering transform. For more detail, we refer the interested reader to
[
22
]
[Thm. 4]. Due to space limitations, in this paper, we will focus on the illustration of incremental passivity.

]

To impose incremental passivity, we can utilize the scattering transform to convert the input/output data of system
G

.
Let
\{u_{i},y_{i}\}^{N}_{i}

III-F

Comparison with previous frameworks

Most previous models
[
1
,
3
,
32
,
2
]
that approximate fading memory systems rely on the same conceptual construction: compactness of the set of past signals
S_{b}
guarantees uniform convergence of the approximation by the classical Stone-Weierstrass theorem. The methods of approximation then follow these steps:

1.

Project data points from compact set
S_{b}
to
\mathbb{R}^{N}
, where
N
is chosen large enough to define a bijective continuous map
\phi:S_{b}\to\mathbb{R}^{N}
.

2.

Approximate the function from the projected data in
\mathbb{R}^{N}
to the outputs in
\mathbb{R}^{n}
using a universal approximator, such as a polynomial, sigmoid gate, or kernel. This produces a function
\hat{f}:\mathbb{R}^{N}\to\mathbb{R}^{N}
.

3.

Obtain the approximated functional
\hat{F}=\hat{f}\circ\phi
.

All the methods above suffer from the same limitation: the bijection between the infinite dimensional set of signals and the finite-dimensional state-space is defined theoretically but not algorithmically. Secondly, all the methods suffer the limitation of nonlinear state-space models to capture incremental input-output properties. This limitation has been a key motivation for the present work, see
[
33
]
for further details.

A key novelty in the present paper is to bypass the problem of
finding a bijection from the data set to state-space
\phi:S_{b}\to\mathbb{R}^{N}
. Furthermore, as previously discussed and will be continually discussed in the rest of the paper, the kernel framework provides a versatile approximation methodology to encode input-output properties in the model structure.

V
Conclusion

In this paper, we proposed a kernel-based framework for modeling and identification of nonlinear fading memory systems. The proposed framework departs from the state-space representations that have dominated the literature on fading memory systems. In contrast, we use a kernel to model the memory functional. Kernel approximations are well suited for regularized learning and to encode a prior knowledge about input-output properties. We showed how regularization can be used to impose IQC properties. Future work will explore how to enforce arbitrary incremental integral quadratic constraints by using regularization techniques and/or special kernels.

sectionCompactness with respect to the fading memory norm

[
1
]
observed that the set of bounded and rate-limited input signals with a finite upper bound is compact with respect to a fading memory norm. In this section, we develop this result for arbitrary fading memory normed spaces.

The following lemma generalizes
[
2
, Corollary 2.7]
to
L_{2}
norms in continuous time.

Lemma 1
.

S_{b}
is a compact subset with respect to
\|\cdot\|_{w,2}
.

Proof.

To show this, we need to show that every sequence in
S_{b}
has a convergent sub-sequence in the sense of
\|\cdot\|_{w,2}
.
[
1
, Lem. 1]
shows that every sequence in
S_{b}
has a sub-sequence which converges in the infinity norm
\|\cdot\|_{w,\infty}
when the output dimension
m=1
. This can be extend to
m>1
by combining the converging sub-sequence in each coordinate to construct a sub-sequence that converge in all coordinates. We now show that such a sub-sequence converges in the
2
-norm as well.
Consider a sequence
u_{n}\in S_{b}
, and let
u_{n_{k}}
be a converging sub-sequence:
\exists u_{0}\in S_{b}

\|u_{n_{k}}-u_{0}\|_{w,\infty}\to 0,k\to\infty.

By Hölder’s inequality,

\|1(u_{n_{k}}-u_{0})^{2}\|_{w,1}\leq\|1\|_{w,q/(q-2)}\|(u_{n_{k}}-u_{0})^{2}\|_{w,q/2}

for any
2<q<\infty
. Since we defined
w
to have finite
L^{q}
norm for all
1\leq q\leq\infty
, we can let
C=\sup_{q}{\|1\|_{w,q/(q-2)}}
. Rearranging, we get,

\|u_{n_{k}}-u_{0}\|_{w,2}\leq C^{\frac{1}{2}}\|u_{n_{k}}-u_{0}\|_{w,q}

\|u_{n_{k}}-u_{0}\|_{w,2}\leq\lim_{q\to\infty}C^{\frac{1}{2}}\|u_{n_{k}}-u_{0}\|_{w,q}=C^{\frac{1}{2}}\|u_{n_{k}}-u_{0}\|_{w,\infty}.

Hence,
S_{b}
is a compact subset with respect to
\|\cdot\|_{w,2}
.∎
