The q-Binomial Coefficient for Negative Arguments and Some q-Binomial Summation Identities
M.J. Kronenburg

Abstract
Using a property of the q-shifted factorial, an identity for q-binomial coefficients is proved, which is used to derive the formulas for the q-binomial coefficient for negative arguments. The result is in agreement with an earlier paper about the normal binomial coefficient for negative arguments. Some new q-binomial summation identities are derived, and the formulas for negative arguments transform some of these summation identities into each other. One q-binomial summation identity is transformed into a new q-binomial summation identity.

Definitions and Basic Identities

Let the following definition of the q-binomial coefficient,
also called the Gaussian polynomial, be given.

\genfrac{(}{)}{0.0pt}{}{m+p}{m}_{\textstyle q}=\prod_{j=1}^{m}\frac{1-q^{p+j}}{1-q^{j}}

(1.1)

Let the q-shifted factorial, also called the q-Pochhammer symbol, be given by
[
7
]
:

(a;q)_{k}=\prod_{j=0}^{k-1}(1-aq^{j})

(1.2)

Then the q-binomial coefficient for integer
k\geq 0
is:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=\prod_{j=1}^{k}\frac{1-q^{n-k+j}}{1-q^{j}}=\frac{(q^{n-k+1};q)_{k}}{(q;q)_{k}}

(1.3)

Let
\Gamma_{q}(x)
be the q-gamma function
[
2
]
.

For complex
x
,
y
:

\genfrac{(}{)}{0.0pt}{}{x}{y}_{\textstyle q}=\frac{\Gamma_{q}(x+1)}{\Gamma_{q}(y+1)\Gamma_{q}(x-y+1)}

(1.4)

From this follows the symmetry identity:

For complex
x
,
y
:

\genfrac{(}{)}{0.0pt}{}{x}{y}_{\textstyle q}=\genfrac{(}{)}{0.0pt}{}{x}{x-y}_{\textstyle q}

(1.5)

The functional equation of the
\Gamma_{q}(x)
function is
[
2
]
:

\Gamma_{q}(x+1)=\frac{1-q^{x}}{1-q}\Gamma_{q}(x)

(1.6)

Combination of (
1.4
) and (
1.6
) gives the absorption identity:

For complex
x
,
y
:

\genfrac{(}{)}{0.0pt}{}{x}{y}_{\textstyle q}=\frac{1-q^{x}}{1-q^{y}}\genfrac{(}{)}{0.0pt}{}{x-1}{y-1}_{\textstyle q}

(1.7)

From definition (
1.3
) follows:

For integer
n\geq 0
and integer
k
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=0\textrm{~if~}k>n

(1.8)

From this and (
1.5
) follows:

For integer
n\geq 0
and integer
k
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=0\textrm{~if~}k<0

(1.9)

2
The q-Binomial Coefficient for Negative Arguments

For deriving the q-binomial coefficient for negative arguments,
the following theorem
[
4
,
7
]
is needed.

Theorem 2.1
.

For integer
k\geq 0
:

(a;q)_{k}=(-a)^{k}q^{k(k-1)/2}(\frac{q^{1-k}}{a};q)_{k}

(2.1)

Proof.

From:

k(k-1)/2=\sum_{j=0}^{k-1}j=\sum_{j=0}^{k-1}(k-j-1)

(2.2)

follows:

q^{k(k-1)/2}=\prod_{j=0}^{k-1}q^{j}=\prod_{j=0}^{k-1}q^{k-j-1}

(2.3)

This is used in:

(-a)^{k}q^{k(k-1)/2}\prod_{j=0}^{k-1}(1-\frac{q^{1-k}}{a}q^{j})=q^{k(k-1)/2}\prod_{j=0}^{k-1}(q^{1-k+j}-a)=\prod_{j=0}^{k-1}(1-aq^{k-j-1})=\prod_{j=0}^{k-1}(1-aq^{j})

(2.4)

∎

Theorem 2.2
.

For integer
k\geq 0
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=(-1)^{k}q^{nk-k(k-1)/2}\genfrac{(}{)}{0.0pt}{}{-n+k-1}{k}_{\textstyle q}

(2.5)

Proof.

Using (
1.3
) and the previous theorem and
-n=(-n+k-1)-k+1
:

\begin{split}&\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=\frac{(q^{n-k+1};q)_{k}}{(q;q)_{k}}=(-1)^{k}q^{k(n-k+1)+k(k-1)/2}\frac{(q^{-n};q)_{k}}{(q;q)_{k}}\\
&=(-1)^{k}q^{nk-k(k-1)/2}\genfrac{(}{)}{0.0pt}{}{-n+k-1}{k}_{\textstyle q}\\
\end{split}

(2.6)

∎

Theorem 2.3
.

For integer
k\leq n
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=(-1)^{n-k}q^{(n-k)(n+k+1)/2}\genfrac{(}{)}{0.0pt}{}{-k-1}{n-k}_{\textstyle q}

(2.7)

Proof.

In the previous theorem replacing
k
with
n-k
, which makes it valid when
n-k\geq 0

which is when
k\leq n
, and then applying (
1.5
) to the left side:

\genfrac{(}{)}{0.0pt}{}{n}{n-k}_{\textstyle q}=\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}

(2.8)

and using
n(n-k)-(n-k)(n-k-1)/2=(n-k)(n+k+1)/2

gives this theorem.
∎

These two transformations can be used to transform one q-binomial
summation identity into another,
and can be used to express the q-binomial coefficient
for negative integer
n
and integer
k

into the q-binomial coefficient for nonnegative integer
n
and
k
.

Theorem 2.4
.

For negative integer
n
and integer
k
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=\begin{cases}\displaystyle(-1)^{k}q^{nk-k(k-1)/2}\genfrac{(}{)}{0.0pt}{}{-n+k-1}{k}_{\textstyle q}&\text{if $k\geq 0$}\\
\displaystyle(-1)^{n-k}q^{(n-k)(n+k+1)/2}\genfrac{(}{)}{0.0pt}{}{-k-1}{n-k}_{\textstyle q}&\text{if $k\leq n$}\\
0&\text{otherwise}\\
\end{cases}

(2.9)

Proof.

The first two cases are identical to theorems
2.2
and
2.3
.

For the third case, from (
1.7
) follows for integer
n
,
k
:

\genfrac{(}{)}{0.0pt}{}{n-1}{k-1}_{\textstyle q}=\frac{1-q^{k}}{1-q^{n}}\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}

(2.10)

When
k=0
the right side is zero,
so when
n<0
and
k=0
this identity produces zeros for
n<k<0
,
which is the third case.
This identity does not produce zeros for all
k<0

because when
n>0
a point will be reached where
n=0
and this expression becomes

(1-q^{k})0/0
which is undefined.
∎

The normal binomial coefficients are the q-binomial coefficients with
q=1
,
in which case this theorem reduces to theorem 2.1 in
[
5
]
.

For
n=-1
this theorem results in:

\genfrac{(}{)}{0.0pt}{}{-1}{k}_{\textstyle q}=\begin{cases}(-1)^{k}q^{-k(k+1)/2}&\textrm{\rm~if~}k\geq 0\\
(-1)^{k+1}q^{-k(k+1)/2}&\textrm{\rm~if~}k\leq-1\\
\end{cases}

(2.11)

which is in agreement with example 1.4 in
[
3
]
.

As an example of the second case of this theorem:

\genfrac{(}{)}{0.0pt}{}{-3}{-5}_{\textstyle q}=q^{-7}\genfrac{(}{)}{0.0pt}{}{4}{2}_{\textstyle q}=q^{-7}(1+q^{2})(1+q+q^{2})

(2.12)

which is in agreement with example 1.2 in
[
3
]
.

The q-binomial coefficient polynomial is palindromic,
which means that
a_{j}=a_{k(n-k)-j}
,
from which follows that it is self-reciprocal,
where
j
is replaced by
k(n-k)-j
:

\begin{split}&\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}=\sum_{j=0}^{k(n-k)}a_{j}q^{j}=\sum_{j=0}^{k(n-k)}a_{k(n-k)-j}q^{j}=\sum_{j=0}^{k(n-k)}a_{j}q^{k(n-k)-j}\\
&=q^{k(n-k)}\sum_{j=0}^{k(n-k)}a_{j}q^{-j}=q^{k(n-k)}\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q^{-1}}\\
\end{split}

(2.13)

The theorems above leave all q-binomial coefficients
self-reciprocal.

For theorem
2.2
:

q^{k(n-k)}\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q^{-1}}=(-1)^{k}q^{nk-k(k-1)/2}q^{-k(n+1)}\genfrac{(}{)}{0.0pt}{}{-n+k-1}{k}_{\textstyle q^{-1}}

(2.14)

and because
-k(n-k)+nk-k(k-1)/2-k(n+1)=-(nk-k(k-1)/2)
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q^{-1}}=(-1)^{k}q^{-(nk-k(k-1)/2)}\genfrac{(}{)}{0.0pt}{}{-n+k-1}{k}_{\textstyle q^{-1}}

(2.15)

For theorem
2.3
:

q^{k(n-k)}\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q^{-1}}=(-1)^{n-k}q^{(n-k)(n+k+1)/2}q^{-(n-k)(n+1)}\genfrac{(}{)}{0.0pt}{}{-k-1}{n-k}_{\textstyle q^{-1}}

(2.16)

and because
-k(n-k)+(n-k)(n+k+1)/2-(n-k)(n+1)=-(n-k)(n+k+1)/2
:

\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q^{-1}}=(-1)^{n-k}q^{-(n-k)(n+k+1)/2}\genfrac{(}{)}{0.0pt}{}{-k-1}{n-k}_{\textstyle q^{-1}}

(2.17)

3
Some q-Binomial Summation Identities

Some q-binomial summation identities are derived and it is shown
how q-binomial coefficients with negative arguments transform
one summation identity into another.
The following identities are the q-binomial theorem and the q-binomial
theorem for negative powers
[
10
]
:

\prod_{k=0}^{n-1}(1+xq^{k})=\sum_{k=0}^{n}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{n}{k}_{\textstyle q}x^{k}

(3.1)

\frac{1}{\prod_{k=0}^{n-1}(1-xq^{k})}=\sum_{k=0}^{\infty}\genfrac{(}{)}{0.0pt}{}{n+k-1}{n-1}_{\textstyle q}x^{k}

(3.2)

The following is an obvious product rule:

\prod_{k=0}^{a-1}(1+xq^{k})\prod_{k=0}^{b-1}(1+xq^{a+k})=\prod_{k=0}^{a+b-1}(1+xq^{k})

(3.3)

With these three identities some q-binomial summation identities are derived,
using that the coefficients of a product of two polynomials are the convolutions
of the coefficients of the two polynomials.

Theorem 3.1
.

The q-analog of the Chu-Vandermonde identity
[
1
]
:

\sum_{k=0}^{n}q^{(a-k)(n-k)}\genfrac{(}{)}{0.0pt}{}{a}{k}_{\textstyle q}\genfrac{(}{)}{0.0pt}{}{b}{n-k}_{\textstyle q}=\genfrac{(}{)}{0.0pt}{}{a+b}{n}_{\textstyle q}

(3.4)

Proof.

Using (
3.1
) with (
3.3
):

(\sum_{k=0}^{a}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{a}{k}_{\textstyle q}x^{k})(\sum_{k=0}^{b}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{b}{k}_{\textstyle q}q^{ak}x^{k})=\sum_{k=0}^{a+b}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{a+b}{k}_{\textstyle q}x^{k}

(3.5)

The coefficients of both sides must be equal:

\sum_{k=0}^{n}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{a}{k}_{\textstyle q}q^{\textstyle\binom{n-k}{2}}\genfrac{(}{)}{0.0pt}{}{b}{n-k}_{\textstyle q}q^{a(n-k)}=q^{\textstyle\binom{n}{2}}\genfrac{(}{)}{0.0pt}{}{a+b}{n}_{\textstyle q}

(3.6)

Because:

\binom{k}{2}+\binom{n-k}{2}+a(n-k)-\binom{n}{2}=(a-k)(n-k)

(3.7)

the theorem is proved.
By replacing
k
with
n-k
and interchanging
a
and
b
, the power of
q
in the summand
can be replaced by
q^{(b-n+k)k}
.
∎

Theorem 3.2
.

\sum_{k=0}^{n}q^{(b+1)k}\genfrac{(}{)}{0.0pt}{}{a+k}{a}_{\textstyle q}\genfrac{(}{)}{0.0pt}{}{b+n-k}{b}_{\textstyle q}=\genfrac{(}{)}{0.0pt}{}{n+a+b+1}{n}_{\textstyle q}

(3.8)

Proof.

Using the reciprocal of (
3.3
) with
-x

\frac{1}{\prod_{k=0}^{a-1}(1-xq^{k})}\frac{1}{\prod_{k=0}^{b-1}(1-xq^{a+k})}=\frac{1}{\prod_{k=0}^{a+b-1}(1-xq^{k})}

(3.9)

which with (
3.2

(\sum_{k=0}^{\infty}\genfrac{(}{)}{0.0pt}{}{a+k-1}{a-1}_{\textstyle q}x^{k})(\sum_{k=0}^{\infty}\genfrac{(}{)}{0.0pt}{}{b+k-1}{b-1}_{\textstyle q}q^{ak}x^{k})=\sum_{k=0}^{\infty}\genfrac{(}{)}{0.0pt}{}{a+b+k-1}{a+b-1}_{\textstyle q}x^{k}

(3.10)

The coefficients of both sides must be equal:

\sum_{k=0}^{n}\genfrac{(}{)}{0.0pt}{}{a+k-1}{a-1}_{\textstyle q}\genfrac{(}{)}{0.0pt}{}{b+n-k-1}{b-1}_{\textstyle q}q^{a(n-k)}=\genfrac{(}{)}{0.0pt}{}{a+b+n-1}{a+b-1}_{\textstyle q}=\genfrac{(}{)}{0.0pt}{}{n+a+b-1}{n}_{\textstyle q}

(3.11)

Replacing
a
by
a+1
and
b
by
b+1
, and then replacing
k
by
n-k
and interchanging

a
and
b
gives the theorem.
By replacing
k
with
n-k
and interchanging
a
and
b
, the power of
q
in the summand
can be replaced by

\sum_{k=0}^{n}(-1)^{k}q^{\textstyle\binom{k}{2}}\genfrac{(}{)}{0.0pt}{}{a}{k}_{\textstyle q}\genfrac{(}{)}{0.0pt}{}{b+n-k}{b}_{\textstyle q}=\begin{cases}\displaystyle q^{an}\genfrac{(}{)}{0.0pt}{}{n-a+b}{n}_{\textstyle q}&\textrm{\rm~if~}a\leq b\\
