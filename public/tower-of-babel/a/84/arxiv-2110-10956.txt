Data splitting improves statistical performance in overparameterized regimes
Nicole Mücke, Enrico Reiss, Jonas Rungenhagen, Markus Klein

Abstract
While large training datasets generally offer improvement in model performance, the training process becomes computationally expensive and time consuming. Distributed learning is a common strategy to reduce the overall training time by exploiting multiple computing devices. Recently, it has been observed in the single machine setting that overparameterization is essential for benign overfitting in ridgeless regression in Hilbert spaces. We show that in this regime, data splitting has a regularizing effect, hence improving statistical performance and computational complexity at the same time. We further provide a unified framework that allows to analyze both the finite and infinite dimensional setting. We numerically demonstrate the effect of different model parameters.

2
Setup

In this section we provide the mathematical framework for our analysis. More specifically, we
introduce distributed ridgeless regression and state the main assumptions on our model.

2.1
Linear Regression

We consider a linear regression model over a real separable Hilbert space
{\mathcal{H}}
in random design. More precisely,
we are given a random covariate vector
x\in{\mathcal{H}}
and a random output
y\in\mathbb{R}
following the model

y=\mathopen{}\mathclose{{\left\langle\beta^{*},x}}\right\rangle+\epsilon\;,

(2.1)

where
\epsilon\in\mathbb{R}
is a noise variable. The true regression parameter
\beta^{*}\in{\mathcal{H}}
minimizes the least squares test risk, i.e.

{\mathcal{R}}(\beta^{*})=\min_{\beta\in{\mathcal{H}}}{\mathcal{R}}(\beta)\;,\qquad{\mathcal{R}}(\beta):=\mathbb{E}[(y-\mathopen{}\mathclose{{\left\langle\beta,x}}\right\rangle)^{2}]\;,

where the expectation is taken with respect to the joint distribution of the pair
(x,y)\in{\mathcal{H}}\times\mathbb{R}
.
This framework covers many common supervised learning tasks, e.g. learning in reproducing kernel Hilbert spaces
[
RV15
]
.

For our analysis we need to impose some distributional assumptions. To this end, we
recall that a positive definite operator
\Gamma\in{\mathcal{L}}({\mathcal{H}})
is
trace class
(and hence compact), if

\mathop{\rm Tr}\limits(\Gamma)=\sum_{j\in\mathbb{N}}\lambda_{j}(\Gamma)<\infty\;,

see e.g.
[
Ree12
]
.

Definition 2.1

(Hilbert space valued subgaussian random variable)
.

Let
z
be a random variable in
{\mathcal{H}}
and let
\Gamma:{\mathcal{H}}\to{\mathcal{H}}
be a bounded, linear and self-adjoint positive definite trace class operator.
Given some
\sigma>0
we say that
z
is
(\sigma^{2},\Gamma)
-subgaussian if for all
v\in{\mathcal{H}}
one has

\mathbb{E}\mathopen{}\mathclose{{\left[e^{\mathopen{}\mathclose{{\left\langle v,z-\mathbb{E}[z]}}\right\rangle}}}\right]\leq e^{\frac{\sigma^{2}}{2}\mathopen{}\mathclose{{\left\langle\Gamma v,v}}\right\rangle}\;.

Note that (taking
{\mathcal{H}}=\mathbb{R}
) this definition includes the special case of real valued variables. On
{\mathcal{H}}
, we define the
covariance operator

\Sigma

by
\Sigma u:=\mathbb{E}[\mathopen{}\mathclose{{\left\langle u,x}}\right\rangle x]
, where
\mathbb{E}
denotes expectation w.r.t. the marginal distribution. We assume

Assumption 2.2
.

1.

\mathbb{E}[x]=0
and
\mathbb{E}[||x||^{2}]<\infty
.

2.

x
is
(\sigma_{x}^{2},\Sigma)
-subgaussian and has independent components.

3.

The covariance
\Sigma
possesses an orthonormal basis of eigenvectors
v_{j}
with eigenvalues
\lambda_{1}\geq\lambda_{2}\geq...
(counted according to multiplicity).

4.

Conditionally on
x
, the noise
\varepsilon
in equation (
2.1
) is centered and
(\tau^{2},id)
-subgaussian, where
id
denotes the identity on
\mathbb{R}
.

Note that 1. and 3. imply that
\Sigma
is trace class (and also positive and self-adjoint). Indeed, this easily follows from

\mathbb{E}[||x||^{2}]=\sum_{j\in\mathbb{N}}\mathopen{}\mathclose{{\left\langle v_{j},\Sigma v_{j}}}\right\rangle=\sum_{j\in\mathbb{N}}\lambda_{j}<\infty\;.

To derive an estimator
\hat{\beta}\in{\mathcal{H}}
for
\beta^{*}
we are given an i.i.d. dataset

D:=\{(x_{1},y_{1}),...,(x_{n},y_{n})\}\subset{\mathcal{H}}\times\mathbb{R}\;,

following the above model (
2.1
), with i.i.d. noise

{\mathbf{\varepsilon}}=(\varepsilon_{1},...,\varepsilon_{n})\in\mathbb{R}^{n}
.
The corresponding random vector of outputs is denoted as
{\mathbf{Y}}=(y_{1},\ldots,y_{n})^{T}\in\mathbb{R}^{n}

and we arrange the data
x_{j}\in{\mathcal{H}}
into a
data matrix

{\mathbf{X}}\in{\mathcal{L}}({\mathcal{H}},\mathbb{R}^{n})
by setting
({\mathbf{X}}v)_{j}=\langle x_{j},v\rangle
for
v\in{\mathcal{H}},1\leq j\leq n
. If
{\mathcal{H}}=\mathbb{R}^{d}
, then
{\mathbf{X}}
is a
n\times d
matrix
(with row vectors
x_{j}
).

2.2
Distributed Ridgeless Regression

In the distributed setting, our data are evenly divided into
M
local disjoint subsets

D=D_{1}\cup...\cup D_{M}

of size
|D_{m}|=\frac{n}{M}
, for
m=1,...,M
. To each local dataset we associate
a
local design matrix

{\mathbf{X}}_{m}\in{\mathcal{L}}({\mathcal{H}},\mathbb{R}^{\frac{n}{M}})
with local output vector

{\mathbf{Y}}_{m}\in\mathbb{R}^{\frac{n}{M}}
and a local noise vector
{\mathbf{\varepsilon}}_{m}\in\mathbb{R}^{\frac{n}{M}}
.

In addition to the above distributional assumptions we require:

Assumption 2.3
.

Let
m\in[M]
.
Almost surely, the projection of the local data
{\mathbf{X}}_{m}
on the space orthogonal to any eigenvector of
\Sigma

spans a space of dimension
\frac{n}{M}
.

More precisely, recall that the data matrix
{\mathbf{X}}_{m}
is built up from
n/M

row vectors

x_{k}\in{\mathcal{H}}
.
The above assumption means that those row vectors almost surely are
in
general position
: Only with zero probability the orthogonal projections of those vectors are linearly dependent
in each hyperplane
H_{j}:=\{x\in{\mathcal{H}};\langle x,v_{j}\rangle=0\}
orthogonal to the
eigenvector
v_{j}
of
\Sigma
. In particular, data vectors
x_{j}
are collinear to some
v_{j}
with zero probability.

Note that Assumptions
2.2
and
2.3
are satisfied if
x,y
are jointly gaussian with zero mean and rank
(\Sigma)>n/M
.

We define the
local minimum norm estimator

\hat{\beta}_{m}
as the solution to the
optimization problem

\displaystyle\min_{\beta\in{\mathcal{H}}}

\displaystyle\;\;||\beta||^{2}\quad\mbox{ such that }

\displaystyle||{\mathbf{X}}_{m}\beta-{\mathbf{Y}}_{m}||^{2}

\displaystyle=\min_{\tilde{\beta}\in{\mathcal{H}}}||{\mathbf{X}}_{m}\tilde{\beta}-{\mathbf{Y}}_{m}||^{2}\;.

It is well known that
\hat{\beta}_{m}
has a closed form expression (see
[
EHN96
]
) given by

\hat{\beta}_{m}={\mathbf{X}}_{m}^{T}({\mathbf{X}}_{m}{\mathbf{X}}_{m}^{T})^{\dagger}{\mathbf{Y}}_{m}\;,

(2.2)

where
({\mathbf{X}}_{m}{\mathbf{X}}_{m}^{T})^{\dagger}
denotes the pseudoinverse of the bounded linear operator
{\mathbf{X}}_{m}{\mathbf{X}}_{m}^{T}
.

In the case that dim
({\mathcal{H}})=d<\frac{n}{M}
and
{\mathbf{X}}_{m}
has rank
d
, there is a unique solution to the normal equations.
However, under Assumption
2.3
we find many local interpolating solutions
\beta\in{\mathcal{H}}
to the normal equations
with
{\mathbf{X}}_{m}\beta={\mathbf{Y}}_{m}
.

The final estimator is defined as the uniform average

\bar{\beta}_{M}=\frac{1}{M}\sum_{j=1}^{M}\beta_{m}\;.

(2.3)

We aim at finding optimal bounds for the excess risk

{\mathcal{R}}(\bar{\beta}_{M})-{\mathcal{R}}(\beta^{*})=||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M}-\beta^{*})||^{2}\;,

in high probability, as a function of the number of local nodes
M
and under various model assumptions.

3
Main Results

In this section we state our main results. We first derive a general upper bound and consider
the infinite and finite dimensional settings in more detail. We complete our presentation
with matching lower bounds.

3.1
A General Error Bound

Before stating our error bounds we briefly describe the underlying error decomposition in bias and variance.
For an estimator
\hat{\beta}\in{\mathcal{H}}
let us define the
bias
by

\widehat{{\rm Bias}}(\hat{\beta}):=||\Sigma^{1/2}(\mathbb{E}_{\epsilon}[\hat{\beta}]-\beta^{*})||^{2}

and the
variance
as

\widehat{{\rm Var}}(\hat{\beta}):=\mathbb{E}_{\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{1/2}(\hat{\beta}-\mathbb{E}_{\epsilon}[\hat{\beta}])||^{2}}}\right]\;,

where
\mathbb{E}_{\varepsilon}[\cdot]
denotes the conditional expectation given the input data.
We then have the following preliminary bound for the excess risk whose full proof is given in Appendix
A
.

Lemma 3.1
.

Let
\bar{\beta}_{M}
be defined by (
2.3
) and denote by

\hat{\Sigma}_{m}=\frac{M}{n}X_{m}^{T}X_{m}

the local empirical covariance operator.
The excess risk can be bounded almost surely by

\mathbb{E}_{\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M}-\beta^{*})||^{2}}}\right]=\widehat{{\rm Bias}}(\bar{\beta}_{M})+\widehat{{\rm Var}}(\bar{\beta}_{M})\;,

where

\widehat{{\rm Bias}}(\bar{\beta}_{M})\leq\frac{1}{M}\sum_{m=1}^{M}\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left\langle\beta^{*},(\Sigma-\hat{\Sigma}_{m})\beta^{*}}}\right\rangle}}\right|\;,

\widehat{{\rm Var}}(\bar{\beta}_{M})\leq\frac{8\tau^{2}}{M^{2}}\sum_{m=1}^{M}\mathop{\rm Tr}\limits\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left(X_{m}^{\dagger}}}\right)^{T}\Sigma X_{m}^{\dagger}}}\right]\;.

We are interested in finding conditions such that bias and variance (and thus the excess risk) converge to zero with high probability. To this end,
we also take the hardness of the learning problem into account. This can be quantified via a classical a-priori
assumption on the minimizer
\beta^{*}
.

Assumption 3.2

(General random-effects model)
.

Let
\Theta\in{\mathcal{L}}({\mathcal{H}})
be compact.
Let
\beta^{*}
be randomly sampled (independently of
\varepsilon
) with mean
\mathbb{E}_{\beta^{*}}[\beta^{*}]=0
and covariance
\mathbb{E}_{\beta^{*}}[\beta^{*}(\beta^{*})^{T}]=\Theta
.

This assumption is a slight generalization of the classical concept of a
source condition
in inverse problems
[
MP03
]
and learning in
(reproducing kernel) Hilbert spaces
[
BPR07
,
BM18
,
LRRC20
]
; see also
[
RMR20
]
,
[
SD20
]

for the context of (distributed) high dimensional ridge(less) regression. We give some specific examples in Assumptions
3.12
,
3.6
below.

For bounding the variance we follow the approach in
[
CL20
]
,
[
BLLT20
]
and choose an index
k\in\mathbb{N}

and split the spectrum of
\Sigma
accordingly.
For a suitable choice of
k
(called
effective dimension
)
it will be crucial to control
two notions of the
effective ranks
, see e.g.
[
KL17
,
BLLT20
]

Definition 3.3

(Effective Ranks)
.

For
k\geq 0
with
\lambda_{k+1}>0
we define

r_{k}(\Sigma):=\frac{\sum_{j>k}\lambda_{j}(\Sigma)}{\lambda_{k+1}(\Sigma)}\;,\quad R_{k}(\Sigma)=\frac{\mathopen{}\mathclose{{\left(\sum_{j>k}\lambda_{j}(\Sigma)}}\right)^{2}}{\sum_{j>k}\lambda_{j}^{2}(\Sigma)}\;.

Definition 3.4

(Effective Dimension)
.

Let
a>1
and
M\in[n]
. Define the
effective dimension
as

k^{*}=k^{*}_{\frac{n}{M}}:=\min\mathopen{}\mathclose{{\left\{k\geq 0\;:\;r_{k}(\Sigma)\geq a\frac{n}{M}}}\right\}\;,

where the minimum of the empty set is defined as
\infty
.

Our main result gives an upper bound for the bias and variance in terms of the source condition, effective ranks and effective dimension.

Theorem 3.5
.

Suppose Assumptions
2.2
,
2.3
and
3.2
are satisfied and let
\delta\in(0,1]
.
There exists a universal constant
c_{1}>0

such that for all
\frac{n}{M}\geq\frac{1}{c_{1}}\log(2/\delta)
,
with probability at least
1-\delta

\mathbb{E}_{\beta^{*}}[\widehat{{\rm Bias}}(\bar{\beta}_{M})]\leq\frac{4\sigma_{x}}{c_{1}}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{2M}{\delta}}}\right)\mathop{\rm Tr}\limits[\Sigma\Theta]\sqrt{\frac{M}{n}}\;.

Additionally, there exist
c_{2}>1
such that, if

k_{\frac{n}{M}}^{*}\leq\frac{n}{c_{2}M}\;,

with probability at least
1-7Me^{-\frac{n}{c_{2}M}}

\widehat{{\rm Var}}(\bar{\beta}_{M})\leq 8c_{2}\tau^{2}\mathopen{}\mathclose{{\left(\frac{k_{\frac{n}{M}}^{*}}{n}+\frac{n}{M^{2}}\;\frac{1}{R_{k_{\frac{n}{M}}^{*}}(\Sigma)}}}\right)\;.

(3.1)

Theorem
3.5
reveals that the excess risk of the averaged local interpolants converges to zero if

\mathop{\rm Tr}\limits[\Sigma\Theta]\sqrt{\frac{M_{n}}{n}}\to 0\;,\;\;\frac{k_{\frac{n}{M_{n}}}^{*}}{n}\to 0\;,

\frac{n}{M_{n}^{2}}\;\frac{1}{R_{k_{\frac{n}{M_{n}}}^{*}}(\Sigma)}\to 0\;,

for
M_{n}\leq n
. This imposes restrictions on the decay of the eigenvalues of
\Sigma
. Moreover, the convergence of the bias
depends on the prior assumption on
\beta^{*}
.

In the following two subsections we discuss the infinite dimensional and finite dimensional cases in more detail.

3.2
Infinite Dimension

We refine the excess risk bound under more specific assumptions on
\beta^{*}
and the spectral decay of the covariance.

Source Condition.
The a-priori assumption on
\beta^{*}
from Assumption
3.2
can be expressed via an
increasing
source function

\Phi:\mathbb{R}_{+}\to\mathbb{R}_{+}
by setting
\Theta=\Phi(\Sigma)
,
describing how coefficients of
\beta^{*}
vary along the eigenvectors of
\Sigma
, see e.g.
[
RMR20
]
.
Recall that the bias in Theorem
3.5
depends on

\mathop{\rm Tr}\limits[\Sigma\Theta]=\mathop{\rm Tr}\limits[\Sigma\Phi(\Sigma)]=\sum_{j=1}^{\infty}\lambda_{j}\Phi(\lambda_{j})\;.

Thus, the bias is finite if the map
x\mapsto x\Phi(x)
is non-decreasing while the sequence of eigenvalues
(\lambda_{j})_{j\in\mathbb{N}}
is decreasing.

Assumption 3.6

(Source Condition)
.

Assume that
\Phi(x)=x^{\alpha}
, for
\alpha\geq 0
.

This particular choice of source function goes under the name
Hölder-type source condition
and is a standard assumption
in inverse problems
[
MP03
]
and nonparametric regression
[
BPR07
,
BM18
,
LRRC20
]
.
Indeed, it has a direct characterization in terms of
smoothness
, where a larger exponent
\alpha
corresponds to a smoother regression function.
In this regard, this assumption also quantifies the
easiness
of the learning problem: Larger values of
\alpha
indicate an easier problem, as
smoother functions are easier to recover.

Eigenvalue Decay.

Finally, to control the variance in Theorem
3.5
we impose a specific spectral assumption for
the covariance:

Assumption 3.7
.

Assume that
\lambda_{j}(\Sigma)=j^{-(1+\varepsilon_{n})}
for some positive sequence

(\varepsilon_{n})_{n\in\mathbb{N}}
with
M_{n}\lesssim\varepsilon_{n}n
.

Polynomially decaying eigenvalues are a common assumption in ridgeless regression. Indeed, it is shown for the single machine setting
in
[
BLLT20
]
that under this assumption, the excess risk of the least-norm interpolant converges to zero and
benign overfitting
occurs.

Our main result in this section is a refined upper bound for the excess risk under the two additional assumptions made above.
The proof is given in Appendix
A.2
.

Proposition 3.8
.

In addition to all assumptions of Theorem
3.5
, suppose that Assumptions
3.7
,
3.6
hold.
Set

C_{\alpha,n}=\frac{1}{\alpha}\mathbb{1}\{\alpha>0\}+\frac{1}{\varepsilon_{n}}\mathbb{1}\{\alpha=0\}

and assume that
\frac{n}{M}\geq\frac{1}{c^{2}_{1}}\log(2/\delta)
.
With probability at least
1-\delta-7Me^{-\frac{n}{c_{2}M}}
we have

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M}-\beta^{*})||^{2}}}\right]

\displaystyle\leq c_{3}\sigma_{x}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{2M}{\delta}}}\right)C_{\alpha,n}\sqrt{\frac{M}{n}}+c_{4}\tau^{2}\frac{\varepsilon_{n}}{M}\;,

for some
c_{3}>0
,
c_{4}>0
.

The above result offers the following insights:

1.

The dependence of our error approximations on the
number of machines reveals an interesting accuracy-complexity trade-off. Indeed,
data splitting has a regularizing effect, where the number of local nodes
M
acts as an explicit regularization parameter:
The bias term is increasing as
\sqrt{M}

while the variance is decreasing as
1/M
.

2.
The source condition controls the bias: The smoother the solution, i.e. the larger
\alpha>0
, the smaller the bias.
Notably, we observe a
phase transition
to the case where
\alpha=0
(low smoothness, harder problem). The bias is multiplied by a factor
1/\varepsilon_{n}
for a
sequence
\varepsilon_{n}\to 0
and hence grows with
n
while for
\alpha>0
the factor is
1/\alpha
that is constant in
n
and decreasing with
\alpha
.

3.
Eigenvalue decay, reflected in the sequence
(\varepsilon_{n})_{n}
controls the variance: Ideally, we want
\varepsilon_{n}\to 0
to
achieve fast decay of the variance. However, even increasing
(\varepsilon_{n})_{n}
is possible as long as we ensure that
\varepsilon_{n}/M_{n}\to 0
.

Balancing both terms allows to establish learning rates for different smoothness regimes (see Appendix
A.2
):

Corollary 3.9

(Learning rate high smoothness)
.

Suppose all assumptions of Proposition
3.8
are satisfied and let
\alpha>0
.
For

\frac{1}{\sqrt{n}}\lesssim\varepsilon_{n}\lesssim n\;,

(3.2)

the value

M_{n}=C_{\tau,\sigma_{x}}\mathopen{}\mathclose{{\left(\alpha\varepsilon_{n}\sqrt{n}}}\right)^{2/3}

with
C_{\tau,\sigma_{x}}=\mathopen{}\mathclose{{\left(\frac{c_{4}\tau^{2}}{c_{3}\sigma_{x}}}}\right)^{2/3}

trades-off bias and variance and
with the same probability as above, we have

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M_{n}}-\beta^{*})||^{2}}}\right]

\displaystyle\leq\frac{C^{\prime}_{\tau,\sigma_{x}}}{\alpha^{2/3}}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{4M_{n}}{\delta}}}\right)\mathopen{}\mathclose{{\left(\frac{\varepsilon_{n}}{n}}}\right)^{1/3}\;,

(3.3)

for some
C^{\prime}_{\tau,\sigma_{x}}>0
.

Corollary 3.10

(Learning rate low smoothness)
.

Suppose all assumptions of Proposition
3.8
are satisfied and let
\alpha=0
.
For

\frac{1}{\sqrt{n}}\lesssim\varepsilon^{2}_{n}\lesssim n\;,

(3.4)

the value

M_{n}=C_{\tau,\sigma_{x}}\mathopen{}\mathclose{{\left(\varepsilon^{2}_{n}\sqrt{n}}}\right)^{2/3}

with
C_{\tau,\sigma_{x}}=\mathopen{}\mathclose{{\left(\frac{c_{4}\tau^{2}}{c_{3}\sigma_{x}}}}\right)^{2/3}

trades-off bias and variance and
with the same probability as above, we have

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M_{n}}-\beta^{*})||^{2}}}\right]

Finite Dimension

In this section we investigate the finite dimensional setting in more detail

To highlight the effects of all characteristics effecting model

Assumption 3.11

Let

Furthermore,

[

[

Assumption 3.12

(Random-effects model)

Define the

The coordinates of
\beta^{*}

\frac{{\rm SNR}}{d}

\Theta=\frac{{\rm SNR}}{d}\;Id_{d}

The next result presents an upper bound for the excess risk under both assumptions.
The proof is provided in Appendix

.

Proposition 3.13
.

In addition to all assumptions of Theorem

a\frac{n}{M}<\mathopen{}\mathclose{{\left(1-\rho_{2}}}\right)F+\rho_{2}d\;.

If

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M}-\beta^{*})||^{2}}}\right]

\displaystyle\leq c\sigma_{x}\frac{{\rm SNR}}{d}\;F\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{2M}{\delta}}}\right)\sqrt{\frac{M}{n}}+\tilde{c}\tau^{2}C_{\rho_{2}}\;\frac{n}{M^{2}}\;\frac{1}{F}\;,

We comment on two additional assumptions required: First, (

Second, the assumption

\rho_{2,n}
of weak features is small enough and consequently they do not contribute much, while

The above result shows how the various model parameters determine statistical accuracy:

1.
As above, we observe that data splitting has a regularizing effect:
The bias term is increasing as
\sqrt{M}

while averaging significantly reduces the variance by

.

2.
The signal-to-noise ratio

and the ratio

of the number of strong features to the dimension control the bias:
The bias is small, if both quantities are small.

3.
The variance is controlled by the number
F
of strong features. The more strong features, the faster the variance decreases.

Thus, the excess risk is characterized by the interplay of all these parameters.
Minimizing the rhs in (

allows to trade-off these different contributions.

Remarks about efficiency

In addition to the non-asymptotic bounds on bias and variance we are interested in the possible gain in efficiency of data splitting compared
to the single machine setting. To this end, let us introduce the ratio of the excess risks for the single machine estimator
\bar{\beta}_{1}

and the distributed estimator
\bar{\beta}_{M}

Definition 4.1
.

We define the

by

\displaystyle{\rm\widehat{Eff}}(M)

\displaystyle=\frac{\mathbb{E}_{\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{1/2}(\bar{\beta}_{1}-\beta^{*})||^{2}}}\right]}{\mathbb{E}_{\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{1/2}(\bar{\beta}_{M}-\beta^{*})||^{2}}}\right]}\;.

4.1
Quadratic increase in efficiency in finite dimension

We consider the setting of Section
3.3
. To bound the relative prediction efficiency in this case recall that from
Proposition
3.13
and Corollary
3.18
we have in the single machine setting a lower and upper bound for
the excess risk
4

4

We omit logarithmic terms.
: With probability at least

\displaystyle\frac{n}{F}\lesssim\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{1}-\beta^{*})||^{2}}}\right]\lesssim\max\mathopen{}\mathclose{{\left\{\frac{F}{d\sqrt{n}},\frac{n}{F}}}\right\}\;.

Note that

if

5
Discussion

Comparison to averaged ordinary least squares (AOLS).
To understand the regularizing effect of the number of data-splits we compare
our approach to AOLS, i.e. (
2.2
), (
2.3
) in the

underparameterized
regime. This has been studied in e.g.
[
RN16
]
.
Since OLS is
unbiased
, AOLS is unbiased, too, and the risk behaves
fundamentally different as a function of
M
. In particular, there is no trade-off between bias and variance.
The performance in this setting for fixed
d
as
n\to\infty
is comparable to the single machine setting. However,
in the high dimensional limit
d/n\to\gamma\in(0,1)
, data splitting incurs a loss in accuracy that increases linearly with
M
and
we trade accuracy for speed. Notably, in the overparameterized
regime, we observe an additional bias and hence an
increase
in efficiency until the optimum
M_{n}
is achieved (see Fig.
1
),
see Section
4
for a more extended discussion.

Comparison to distributed Ridge Regression (DRR).

The learning properties of the distributed ridgeless estimator also changes with additional regularization as for (kernel) ridge regression. This setting
is extensively investigated in kernel learning e.g.
[
ZDW15
]
,
[
LGZ17
]
,
[
MB18
]
.
In this setup, the averaged estimator suffers
no loss
in accuracy, i.e. no increase in efficiency, if appropriately regularized,
provided the number of machines grows sufficiently slowly with the sample size.

The work
[
SD20
]
investigates DRR in the high dimensional limit and finds that the efficiency is generally high when the signal strength is low.
Note that we observe a similar phenomenon in Corollary
3.14
through the signal-to-noise-ratio
{\rm SNR}
.
A low
{\rm SNR}
increases the optimal number
M_{n}
.
Moreover, the authors show that even in the limit of many machines, DRR does not lose
all efficiency. We show in (
3.3
) that in the infinite worker limit, the risk converges to zero if
d_{n}
increases.

\displaystyle=\mathopen{}\mathclose{{\left|\frac{B^{2}}{n}\mathopen{}\mathclose{{\left(\sum_{j=1}^{n}\frac{\mathopen{}\mathclose{{\left\langle\beta,x_{j}}}\right\rangle^{2}}{B^{2}}-1}}\right)}}\right|\;.

(A.1)

We next show that for any
j=1,...,n
, the real valued variables
z_{j}:=\frac{\mathopen{}\mathclose{{\left\langle\beta,x_{j}}}\right\rangle}{B}
are
(\sigma_{x}^{2},id)
-subgaussian.
Indeed, by Assumption
2.2
and Definition
2.1
we find for all
\alpha\in\mathbb{R}

\displaystyle\mathbb{E}\mathopen{}\mathclose{{\left[e^{\alpha z_{j}}}}\right]

\displaystyle=\mathbb{E}\mathopen{}\mathclose{{\left[e^{\mathopen{}\mathclose{{\left\langle\frac{\alpha}{B}\beta,x_{j}}}\right\rangle}}}\right]

\displaystyle\leq e^{\frac{\sigma_{x}^{2}}{2}\mathopen{}\mathclose{{\left\langle\Sigma\frac{\alpha}{B}\beta,\frac{\alpha}{B}\beta}}\right\rangle}

\displaystyle=e^{\frac{\sigma_{x}^{2}}{2}\alpha^{2}}\;.

(A.2)

For bounding (
A.1
) with high probability we use the fact that for any
j=1,...,n
the random variable
z_{j}^{2}-1
is
16\sigma_{x}^{2}
-subexponential.
Indeed, this follows from (
A.1
) and results in
[
Ver18
, Section 2]
that are condensed in
[
BLLT20
, Lemma S.4]
.
Next, Bernstein’s inequality for the independent and mean zero subexponential variables
z_{1},...,z_{n}
in
[
Ver18
, Theorem 2.8.2]

shows that there exists a universal constant
c>0
such that for all
t\geq 0
, with probability at least

1-2\exp\mathopen{}\mathclose{{\left(-c^{2}\min\mathopen{}\mathclose{{\left\{\frac{t^{2}}{16\sigma_{x}^{2}n},\frac{t}{4\sigma_{x}}}}\right\}}}\right)

we have

\mathopen{}\mathclose{{\left|\frac{B^{2}}{n}\mathopen{}\mathclose{{\left(\sum_{j=1}^{n}\frac{\mathopen{}\mathclose{{\left\langle\beta,x_{j}}}\right\rangle^{2}}{B^{2}}-1}}\right)}}\right|\leq\frac{B^{2}}{n}\;t\;.

Assuming that
t\leq 4\sigma_{x}n
we find that

\min\mathopen{}\mathclose{{\left\{\frac{t^{2}}{16\sigma_{x}^{2}n},\frac{t}{4\sigma_{x}}}}\right\}=\frac{t^{2}}{16\sigma_{x}^{2}n}\;.

Setting now
\delta=2e^{-\frac{c^{2}}{16\sigma_{x}^{2}}\frac{t^{2}}{n}}
we finally get

\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left\langle\beta,(\Sigma-\hat{\Sigma})\beta}}\right\rangle}}\right|\leq\frac{4\sigma_{x}}{c}\frac{||\Sigma^{\frac{1}{2}}\beta||^{2}}{\sqrt{n}}\log^{\frac{1}{2}}(2/\delta)\;.

with probability at least
1-\delta
, for all
\delta\geq 2e^{-c^{2}n}
.
∎

The next result establishes a bound for the single machine variance. This is a first step for bounding the variance from Lemma
3.1
in the distributed setting.

Proposition A.3
.

Let
n\in\mathbb{N}
and suppose Assumption
2.2
is satisfied.
Define

\widehat{C}:=({\mathbf{X}}{\mathbf{X}}^{T})^{-1}{\mathbf{X}}\Sigma{\mathbf{X}}^{T}({\mathbf{X}}{\mathbf{X}}^{T})^{-1}\;.

There exists a universal constant
c>1
and a
0\leq k_{n}^{*}\leq\frac{n}{c}

such that with probability at least
1-7e^{-\frac{n}{c}}
it holds

\mathop{\rm Tr}\limits[\widehat{C}]\leq c\mathopen{}\mathclose{{\left(\frac{k_{n}^{*}}{n}+n\;\frac{\sum_{j>k_{n}^{*}}\lambda_{j}^{2}}{\mathopen{}\mathclose{{\left(\sum_{j>k_{n}^{*}}\lambda_{j}}}\right)^{2}}}}\right)\;,

where
(\lambda_{j})_{j\in\mathbb{N}}
are the eigenvalues of
\Sigma
, arranged in decreasing order.

Proof of Proposition
A.3
.

The proof follows from
[
BLLT20
, Lemma 6]
and
[
BLLT20
, Lemma 11]
.
∎

Combining now the above results allows to prove Lemma
3.1
.

Proof of Lemma
3.1
.

We first derive a bound for the bias. Linearity of the expectation and (
2.1
) yields

\mathbb{E}_{\varepsilon}[\bar{\beta}_{M}]=\frac{1}{M}\sum_{m=1}^{M}X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}\mathbb{E}_{\varepsilon}[Y_{m}]=\frac{1}{M}\sum_{m=1}^{M}X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}X_{m}\beta^{*}\;,

(A.3)

since, conditionally on the inputs
{\mathbf{X}}
, the noise is centered. Hence

\displaystyle\beta^{*}-\mathbb{E}_{\epsilon}[\bar{\beta}_{M}]

\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\tilde{\Pi}_{m}\beta^{*}\;,

where we denote by

\tilde{\Pi}_{m}:=Id-{\mathbf{X}}_{m}^{T}({\mathbf{X}}_{m}{\mathbf{X}}_{m}^{T})^{\dagger}{\mathbf{X}}_{m}

the orthogonal projection onto the nullspace of
{\mathbf{X}}_{m}
.
Convexity and Lemma
A.1
allow to deduce

\displaystyle\widehat{{\rm Bias}}(\bar{\beta}_{M})

\displaystyle=||\Sigma^{1/2}(\mathbb{E}_{\epsilon}[\bar{\beta}_{M}]-\beta^{*})||^{2}

\displaystyle\leq\frac{1}{M}\sum_{m=1}^{M}||\Sigma^{1/2}\tilde{\Pi}_{m}\beta^{*}||^{2}

\displaystyle\leq\frac{1}{M}\sum_{m=1}^{M}\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left\langle\beta^{*},(\Sigma-\hat{\Sigma}_{m})\beta^{*}}}\right\rangle}}\right|\;.

Next, we derive a bound for the variance.
By definition of the variance, (
2.2
) and (
A.3
) we find

\displaystyle\widehat{{\rm Var}}(\bar{\beta}_{M})

\displaystyle=\mathbb{E}_{\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{1/2}(\bar{\beta}_{M}-\mathbb{E}_{\epsilon}[\bar{\beta}_{M}])||_{2}^{2}}}\right]

\displaystyle=\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}\hat{\beta}^{(m)}-X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}X_{m}\beta^{*}\Big)||^{2}\Big]

\displaystyle=\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}(Y_{m}-X_{m}\beta^{*})\Big)||^{2}\Big]

\displaystyle=\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}\varepsilon_{m}\Big)||^{2}\Big]

\displaystyle=\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}X_{m}^{\dagger}\varepsilon_{m}\Big)||^{2}\Big]\;.

In the last step we use
X_{m}^{T}(X_{m}X_{m}^{T})^{\dagger}=X_{m}^{\dagger}
.
Recall that for any
\beta\in{\mathcal{H}}
we may write
||\beta||^{2}=\mathop{\rm Tr}\limits[\beta\otimes\beta]
. Hence,

\displaystyle||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}X_{m}^{\dagger}\varepsilon_{m}\Big)||^{2}

\displaystyle\mathop{\rm Tr}\limits\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left(\frac{1}{M}\sum_{m=1}^{M}\Sigma^{1/2}X_{m}^{\dagger}\varepsilon_{m}}}\right)\otimes\mathopen{}\mathclose{{\left(\frac{1}{M}\sum_{m^{\prime}=1}^{M}\Sigma^{1/2}X_{m^{\prime}}^{\dagger}\varepsilon_{m^{\prime}}}}\right)}}\right]

\displaystyle=\frac{1}{M^{2}}\sum_{m,m^{\prime}=1}^{M}\mathop{\rm Tr}\limits\mathopen{}\mathclose{{\left[\Sigma^{1/2}X_{m}^{\dagger}\varepsilon_{m}\otimes\varepsilon_{m^{\prime}}(X_{m^{\prime}}^{\dagger})^{T}\Sigma^{1/2}}}\right]\;.

By linearity of the trace and independence, taking the expectation gives
\mathbb{E}_{\varepsilon}[\varepsilon_{m}\otimes\varepsilon_{m^{\prime}}]=0
for any
m\not=m^{\prime}
and the sum reduces to

\displaystyle\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}\Big(\frac{1}{M}\sum_{m=1}^{M}X_{m}^{\dagger}\varepsilon_{m}\Big)||^{2}\Big]

\displaystyle=\frac{1}{M^{2}}\sum_{m=1}^{M}\mathbb{E}_{\varepsilon}\Big[\mathop{\rm Tr}\limits\Big[\Sigma^{1/2}X_{m}^{\dagger}\varepsilon_{m}\otimes\varepsilon_{m}(X_{m}^{\dagger})^{T}\Sigma^{1/2}\Big]\Big]

\displaystyle=\frac{1}{M^{2}}\sum_{m=1}^{M}\mathbb{E}_{\varepsilon}\Big[||\Sigma^{1/2}X_{m}^{\dagger}\varepsilon_{m}||^{2}\Big]

\displaystyle=\frac{1}{M^{2}}\sum_{m=1}^{M}\mathbb{E}_{\varepsilon}\Big[\mathopen{}\mathclose{{\left\langle\varepsilon_{m},C_{m}\varepsilon_{m}}}\right\rangle\Big]\;,

(A.4)

where we set

C_{m}:=\mathopen{}\mathclose{{\left(X_{m}^{\dagger}}}\right)^{T}\Sigma X_{m}^{\dagger}\;.

To proceed, we apply a conditional subgaussian version of the Hanson-Wright inequality taken from
[
PG19
, Lemma 35]
. This gives almost surely
conditional on the data
X_{m}
, for all
t\geq 0
, with probability at least
1-e^{-t}
(w.r.t. the noise)

\displaystyle\mathopen{}\mathclose{{\left\langle\varepsilon_{m},C_{m}\varepsilon_{m}}}\right\rangle

\displaystyle\leq\tau^{2}\mathop{\rm Tr}\limits[C_{m}]+2\tau^{2}t||C_{m}||+2\tau^{2}\sqrt{t^{2}||C_{m}||^{2}+t\mathop{\rm Tr}\limits[C_{m}^{2}]}

\displaystyle\leq 4\tau^{2}\mathop{\rm Tr}\limits[C_{m}]\;(t+1)\;,

where we use that
||C_{m}||\leq\mathop{\rm Tr}\limits[C_{m}]
and
\mathop{\rm Tr}\limits[C_{m}^{2}]\leq||C_{m}||\mathop{\rm Tr}\limits[C_{m}]\leq\mathop{\rm Tr}\limits[C_{m}]^{2}
.
From
[
BM18
, Lemma C.1]
we obtain after integration
for the conditional expectation

\mathbb{E}_{\varepsilon}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle\varepsilon_{m},C_{m}\varepsilon_{m}}}\right\rangle}}\right]\leq 8\tau^{2}\mathop{\rm Tr}\limits[C_{m}]\;.

Inserting the last bound into (
A.1
) finally gives almost surely

\widehat{{\rm Var}}(\bar{\beta}_{M})\leq\frac{8\tau^{2}}{M^{2}}\sum_{m=1}^{M}\mathop{\rm Tr}\limits[C_{m}]\;.

∎

Finally, we give the proof of our main result, a general upper bound for distributed ridgeless regression.

Proof of Theorem
3.5
.

We start with bounding the bias term.

Bounding the Bias.
Recall that by Lemma
3.1
we have almost surely

\widehat{{\rm Bias}}(\bar{\beta}_{M})\leq\frac{1}{M}\sum_{m=1}^{M}\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left\langle\beta^{*},(\Sigma-\hat{\Sigma}_{m})\beta^{*}}}\right\rangle}}\right|\;.

Proposition
A.2
gives for all
\delta\geq 2e^{-c^{2}\frac{n}{M}}
, with probability at least
1-\delta

\mathopen{}\mathclose{{\left|\mathopen{}\mathclose{{\left\langle\beta^{*},(\Sigma-\hat{\Sigma}_{m})\beta^{*}}}\right\rangle}}\right|\leq\frac{4\sigma_{x}}{c}\;\log^{\frac{1}{2}}(2/\delta)\;||\Sigma^{\frac{1}{2}}\beta^{*}||^{2}\sqrt{\frac{M}{n}}\;,

for some universal constant
c>0
. Performing now a union bound and invoking Assumption
3.2
finally gives with probability
at least
1-\delta

\mathbb{E}_{\beta^{*}}[\widehat{{\rm Bias}}(\bar{\beta}_{M})]\leq\frac{4\sigma_{x}}{c}\;\log^{\frac{1}{2}}(2M/\delta)\;\mathop{\rm Tr}\limits[\Sigma\Theta]\sqrt{\frac{M}{n}}\;,

where we use that

\mathbb{E}_{\beta^{*}}[||\Sigma^{\frac{1}{2}}\beta^{*}||^{2}]=\mathop{\rm Tr}\limits\mathopen{}\mathclose{{\left[\mathbb{E}_{\beta^{*}}[\Sigma\beta^{*}\otimes\beta^{*}]}}\right]=\mathop{\rm Tr}\limits[\Sigma\Theta]\;.

Bounding the Variance.
Applying Lemma
3.1
once more we have almost surely

\widehat{{\rm Var}}(\bar{\beta}_{M})\leq\frac{8\tau^{2}}{M^{2}}\sum_{m=1}^{M}\mathop{\rm Tr}\limits[C_{m}]\;.

With Lemma
A.3
together with a union bound we get with probability at least
1-7Me^{-\frac{n}{c_{2}M}}

\displaystyle\widehat{{\rm Var}}(\bar{\beta}_{M})

\displaystyle\leq\frac{8c_{2}\tau^{2}}{M^{2}}\sum_{m=1}^{M}\mathopen{}\mathclose{{\left(\frac{M}{n}k_{n/M}^{*}+\frac{n}{M}\;\frac{\sum_{j>k_{n/M}^{*}}\lambda_{j}^{2}}{\mathopen{}\mathclose{{\left(\sum_{j>k_{n/M}^{*}}\lambda_{j}}}\right)^{2}}}}\right)

\displaystyle=8c_{2}\tau^{2}\mathopen{}\mathclose{{\left(\frac{k_{n/M}^{*}}{n}+\frac{n}{M^{2}}\;\frac{\sum_{j>k_{n/M}^{*}}\lambda_{j}^{2}}{\mathopen{}\mathclose{{\left(\sum_{j>k_{n/M}^{*}}\lambda_{j}}}\right)^{2}}}}\right)\;,

for some constant
c_{2}>1
and
0\leq k_{n/M}^{*}\leq\frac{n}{c_{2}M}
.
∎

,
3.7
. We start with a preliminary Lemma that is needed to estimate the variance.

Lemma A.4
.

Suppose all assumptions of Theorem
3.5
are satisfied. Assume that
\lambda_{j}(\Sigma)=j^{-(1+\varepsilon_{n})}
for a positive sequence
(\varepsilon_{n})_{n\in\mathbb{N}}
.
We have

1.

\frac{k_{\frac{n}{M}}^{*}}{n}\leq a\;\frac{\varepsilon_{n}}{M}
.

2.

For any

sufficiently large,

\frac{n}{M^{2}}\;\frac{1}{R_{k_{\frac{n}{M}}^{*}}(\Sigma)}\leq\frac{6}{a}\;\frac{\varepsilon_{n}}{M}

, then
k^{*}_{\frac{n}{M}}\gtrsim 1
.

Proof of Lemma
A.4
.

1.

We follow the lines of
[

]

With Lemma 14 in

\displaystyle r_{k}(\Sigma)

By Definition

, the effective dimension

is the smallest number satisfying

k^{*}_{\frac{n}{M}}\leq a\varepsilon_{n}\frac{n}{M}

2.

A short calculation shows that

Following the arguments in the proof of Theorem 31 in
[
BLLT20
]
we find also in the distributed setting

k^{*}_{\frac{n}{M}}\geq\frac{a\varepsilon}{3}\frac{n}{M}
for sufficiently large

R_{k^{*}_{\frac{n}{M}}}(\Sigma)\geq\frac{a\varepsilon_{n}}{6}\frac{n}{M}\;.

∎

The second preliminary Lemma will help to bound the bias.

Lemma A.5
.

Suppose Assumption
3.7
is satisfied.
Let
\alpha\geq 0
. Then

\mathop{\rm Tr}\limits[\Sigma^{1+\alpha}]\;=\;\sum_{j=1}^{\infty}\mathopen{}\mathclose{{\left(\frac{1}{j}}}\right)^{(1+\alpha)(1+\varepsilon_{n})}\;\leq\;\frac{1}{\alpha+\varepsilon_{n}(1+\alpha)}\;\leq\;\mathopen{}\mathclose{{\left\{{\begin{array}[]{cc}\alpha=0&:\;\frac{1}{\varepsilon_{n}}\\
\alpha>0&:\;\frac{1}{\alpha}\\
\end{array}}}}\right.\;.

Proof of Lemma
A.5
.

Let
\beta=(1+\alpha)(1+\varepsilon_{n})
.
The infinite sum can easily be bounded by an integral

\displaystyle\sum_{j=1}^{\infty}\mathopen{}\mathclose{{\left(\frac{1}{j}}}\right)^{\beta}

\displaystyle\leq\int_{1}^{\infty}t^{-\beta}dt=\frac{1}{\beta-1}\;,

see e.g. Lemma 14 in
[
MNR19
]
.
∎

Combining now Lemma
A.4
and Lemma
A.5

Proof of Proposition
3.8
.

For bounding the bias we apply Lemma

\mathop{\rm Tr}\limits[\Sigma\Theta]=\mathop{\rm Tr}\limits[\Sigma^{1+\alpha}]=\sum_{j\in\mathbb{N}}\lambda^{1+\alpha}_{j}(\Sigma)\leq\frac{1}{\alpha}\mathbb{1}\{\alpha>0\}+\frac{1}{\varepsilon_{n}}\mathbb{1}\{\alpha=0\}=:C_{\alpha,n}\;.

Combining this with Lemma
A.4
, Lemma
3.1
and Theorem
3.5
leads to

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M}-\beta^{*})||^{2}}}\right]

\displaystyle\leq\frac{4\sigma_{x}}{c_{1}}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{2M}{\delta}}}\right)\mathop{\rm Tr}\limits[\Sigma^{1+\alpha}]\sqrt{\frac{M}{n}}+8c_{2}\tau^{2}\mathopen{}\mathclose{{\left(a\;\frac{\varepsilon_{n}}{M}+\frac{6}{a}\;\frac{\varepsilon_{n}}{M}}}\right)

\displaystyle\leq\frac{4\sigma_{x}}{c_{1}}C_{\alpha,n}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{2M}{\delta}}}\right)\sqrt{\frac{M}{n}}+8c_{2}c_{a}\tau^{2}\frac{\varepsilon_{n}}{M}\;,

holding with probability at least
1-\delta-7Me^{-\frac{n}{c_{2}M}}
, for any
\delta\geq 2e^{-c_{1}^{2}\frac{n}{M}}
.
Here, we set
c_{a}=\max\{a,6/a\}
.
The result follows with
c_{3}=4/c_{1}
and
c_{4}=8c_{2}c_{a}
.
∎

Proof of Corollary
3.9
and Corollary
3.10
.

We determine the maximum number of local nodes by balancing bias and variance. To this end, firstly note that

1\leq\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{4M_{n}}{\delta}}}\right)
.
Setting now

A:=c_{3}\sigma_{x}\frac{C_{\alpha,n}}{\sqrt{n}}\;,\quad B:=c_{4}\tau^{2}\varepsilon_{n}\;,

we find that

A\sqrt{M}=\frac{B}{M}\quad\Longleftrightarrow\quad M=\mathopen{}\mathclose{{\left(\frac{B}{A}}}\right)^{2/3}\;.

Hence, the value

M_{n}:=C_{\tau,\sigma_{x}}\mathopen{}\mathclose{{\left(\frac{\varepsilon_{n}\sqrt{n}}{C_{\alpha,n}}}}\right)^{2/3}\;,\quad C_{\tau,\sigma_{x}}=\mathopen{}\mathclose{{\left(\frac{c_{4}\tau^{2}}{c_{3}\sigma_{x}}}}\right)^{2/3}

trades off bias and variance and the excess risk is bounded as

\displaystyle\mathbb{E}_{\beta^{*},\epsilon}\mathopen{}\mathclose{{\left[||\Sigma^{\frac{1}{2}}(\bar{\beta}_{M_{n}}-\beta^{*})||^{2}}}\right]

\displaystyle\leq 2c_{4}\tau^{2}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{4M_{n}}{\delta}}}\right)\frac{\varepsilon_{n}}{M_{n}}

\displaystyle=C^{\prime}_{\tau,\sigma_{x}}\log^{\frac{1}{2}}\mathopen{}\mathclose{{\left(\frac{4M_{n}}{\delta}}}\right)\mathopen{}\mathclose{{\left(\frac{C^{2}_{\alpha,n}\varepsilon_{n}}{n}}}\right)^{1/3}\;,

where

.
∎

A.3
Proofs of Section
3.3

In this section we provide the proofs for our results in finite dimension with
dim({\mathcal{H}})=d<\infty
from Section
3.3
.
We start with two preliminary Lemmata.

Lemma A.6
.

Suppose Assumption
3.12
holds. Then

\mathop{\rm Tr}\limits[\Sigma\Theta]\leq\frac{2\cdot{\rm SNR}}{d}\;F\;.

Proof of Lemma
A.6
.

By Assumption
3.12
with
\Theta=\frac{{\rm SNR}}{d}\;Id_{d}
and since
d\rho_{2}\leq F
we easily obtain

\displaystyle\mathop{\rm Tr}\limits[\Sigma\Theta]

\displaystyle=\frac{{\rm SNR}}{d}\;\mathop{\rm Tr}\limits[\Sigma]

\displaystyle=\frac{{\rm SNR}}{d}\;\mathopen{}\mathclose{{\left(\sum_{j=1}^{F}\rho_{1}+\sum_{j=F+1}^{d}\rho_{2}}}\right)

\displaystyle=\frac{{\rm SNR}}{d}\;\mathopen{}\mathclose{{\left(F\rho_{1}+(d-F)\rho_{2}}}\right)

\displaystyle=\frac{{\rm SNR}}{d}\;\mathopen{}\mathclose{{\left((\rho_{1}-\rho_{2})F+d\rho_{2}}}\right)

\displaystyle\leq\frac{{\rm SNR}}{d}\;(\rho_{1}-\rho_{2}+1)F

\displaystyle\leq\frac{2{\rm SNR}}{d}\;F\;.

In the last step we use that
\rho_{1}=1
and
-\rho_{2}\leq 0
.
∎

Lemma A.7
.

Suppose Assumptions of Theorem
3.5
are satisfied. If additionally Assumption
3.11
holds, then
with probability at least
1-7Me^{-\frac{n}{c_{2}M}}

\displaystyle\widehat{{\rm Var}}(\bar{\beta}_{M})

\displaystyle\leq 16c_{2}\tau^{2}\;\frac{1}{(\rho_{1}-\rho_{2})^{2}}\;\frac{n}{M^{2}}\;\frac{1}{F}\;.

Proof of Lemma
A.7
.

We bound the first term
\frac{k_{\frac{n}{M}}^{*}}{n}
in the variance. To this end, let
k<F
and consider

\displaystyle r_{k}(\Sigma)

\displaystyle=\frac{1}{\lambda_{k+1}}\sum_{j>k}\lambda_{j}(\Sigma)

\displaystyle=\frac{1}{\lambda_{k+1}}\mathopen{}\mathclose{{\left(\sum_{j=k+1}^{F}\lambda_{j}(\Sigma)+\sum_{j=F+1}^{d}\lambda_{j}(\Sigma)}}\right)

\displaystyle=\frac{1}{\rho_{1}}\mathopen{}\mathclose{{\left(\rho_{1}(F-k)+\rho_{2}(d-F)}}\right)

\displaystyle=\frac{1}{\rho_{1}}\mathopen{}\mathclose{{\left((\rho_{1}-\rho_{2})F+\rho_{2}d-\rho_{1}k}}\right)

\displaystyle=\mathopen{}\mathclose{{\left(1-\frac{\rho_{2}}{\rho_{1}}}}\right)F+\frac{\rho_{2}}{\rho_{1}}d-k\;.

(A.5)

Thus,

r_{k}(\Sigma)\geq a\frac{n}{M}\quad\Longleftrightarrow\quad k\leq\mathopen{}\mathclose{{\left(1-\frac{\rho_{2}}{\rho_{1}}}}\right)F+\frac{\rho_{2}}{\rho_{1}}d-a\frac{n}{M}\;.

The right hand side is non-negative if we require

a\frac{n}{M}<\mathopen{}\mathclose{{\left(1-\frac{\rho_{2}}{\rho_{1}}}}\right)F+\frac{\rho_{2}}{\rho_{1}}d\;.

(A.6)

By the definition
3.4
of the effective dimension and from (
A.3
) we obtain

\displaystyle k^{*}_{\frac{n}{M}}

\displaystyle=\min\mathopen{}\mathclose{{\left\{k\geq 0\;:\;r_{k}(\Sigma)\geq a\frac{n}{M}}}\right\}

\displaystyle=\min\mathopen{}\mathclose{{\left\{k\geq 0\;:\;k\leq\mathopen{}\mathclose{{\left(1-\frac{\rho_{2}}{\rho_{1}}}}\right)F+\frac{\rho_{2}}{\rho_{1}}d-a\frac{n}{M}}}\right\}

\displaystyle=0\;,

(A.7)

provided (

) is satisfied.

\frac{1}{R_{k^{*}}(\Sigma)}=\frac{1}{R_{0}(\Sigma)}=\frac{\sum_{j=1}^{d}\lambda_{j}^{2}(\Sigma)}{\mathopen{}\mathclose{{\left(\sum_{j=1}^{d}\lambda_{j}(\Sigma)}}\right)^{2}}\;.

By Assumption
3.11
and for
\rho_{2}^{2}d\leq F
we may write

\displaystyle\sum_{j=1}^{d}\lambda_{j}^{2}(\Sigma)

\displaystyle=\sum_{j=1}^{F}\lambda_{j}^{2}(\Sigma)+\sum_{j=F+1}^{d}\lambda_{j}^{2}(\Sigma)

\displaystyle=\theta^{4}\mathopen{}\mathclose{{\left(\rho_{1}^{2}F+\rho_{2}^{2}(d-F)}}\right)

\displaystyle=\theta^{4}\mathopen{}\mathclose{{\left((\rho_{1}^{2}-\rho_{2}^{2})F+\rho_{2}^{2}d}}\right)

(A.8)

\displaystyle\leq\theta^{4}\mathopen{}\mathclose{{\left(1+\rho_{1}^{2}-\rho_{2}^{2}}}\right)F

\displaystyle\leq\theta^{4}\mathopen{}\mathclose{{\left(1+\rho_{1}^{2}}}\right)F\;.

Moreover, since
\rho_{1}>\rho_{2}>0
we obtain

\displaystyle\sum_{j=1}^{d}\lambda_{j}(\Sigma)

\displaystyle=\sum_{j=1}^{F}\lambda_{j}(\Sigma)+\sum_{j=F+1}^{d}\lambda_{j}(\Sigma)

\displaystyle=\theta^{2}\mathopen{}\mathclose{{\left((\rho_{1}-\rho_{2})F+\rho_{2}d}}\right)

(A.9)

\displaystyle\geq\theta^{2}(\rho_{1}-\rho_{2})F\;.

Hence,

\frac{n}{M^{2}}\;\frac{1}{R_{k_{\frac{n}{M}}^{*}}(\Sigma)}\leq\frac{n}{M^{2}}\;\frac{\theta^{4}\mathopen{}\mathclose{{\left(1+\rho_{1}^{2}}}\right)F}{\theta^{4}(\rho_{1}-\rho_{2})^{2}F^{2}}=\frac{1+\rho_{1}^{2}}{(\rho_{1}-\rho_{2})^{2}}\;\frac{n}{M^{2}}\;\frac{1}{F}\;.

(A.10)

Combining now (
A.3
) and (
A.10
) finally gives with probability at least
1-7Me^{-\frac{n}{c_{2}M}}

d=\frac{n}{M}
with height at least
\tilde{\tau}^{2}\frac{d}{M}
, see Fig. fig:3.

We consider functions of the form
f_{\beta}:{\mathcal{H}}\to\mathbb{R}
,
\beta\in{\mathcal{H}}
, with
f_{\beta}(x):=\mathopen{}\mathclose{{\left\langle\beta,x}}\right\rangle

and define for any estimator
\hat{\beta}\in{\mathcal{H}}
the quantity

\tilde{\mathcal{E}}:=\mathbb{E}[(f_{\hat{\beta}}(x)-\mathbb{E}_{Y|X}[f_{\hat{\beta}}(x)])^{2}]\;.

One easily verifies that

\tilde{\mathcal{E}}\leq\mathbb{E}[{\mathcal{R}}(\hat{\beta})]-{\mathcal{R}}(\beta^{*})\;.

(B.4)

Thus, finding a lower bound for
\tilde{\mathcal{E}}
leads to a lower bound for the excess risk.

Proof of Theorem
B.6
.

Define the centered output variables
\tilde{Y}_{m}:=Y_{m}-\mathbb{E}_{Y_{m}|X}[Y_{m}]
,
m=1,...,M
and
set

Cov(Y_{m},X_{m}):=\mathbb{E}_{Y_{m}|X_{m}}[\tilde{Y}_{m}\otimes\tilde{Y}_{m}]\;.

We then write

\displaystyle\tilde{\mathcal{E}}(X)

\displaystyle:=\mathbb{E}_{Y,x|X}[(f_{\bar{\beta}_{0}}(x)-\mathbb{E}_{Y|X}[f_{\bar{\beta}_{0}}(x)])^{2}]

\displaystyle=\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left(\mathopen{}\mathclose{{\left\langle x,\frac{1}{M}\sum_{m=1}^{M}X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle}}\right)^{2}}}\right]

\displaystyle=\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left(\frac{1}{M}\sum_{m=1}^{M}\mathopen{}\mathclose{{\left\langle x,X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle}}\right)^{2}}}\right]

\displaystyle=\frac{1}{M^{2}}\sum_{m=1}^{M}\sum_{m^{\prime}=1}^{M}\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle x,X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle\mathopen{}\mathclose{{\left\langle x,X_{m^{\prime}}^{\dagger}\tilde{Y}_{m^{\prime}}}}\right\rangle}}\right]\;.

Note that by definition of
\tilde{Y}_{m}
and linearity we have

\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle x,X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle}}\right]=0\;.

Thus, by independence and Assumption
B.5
we find

\displaystyle\tilde{\mathcal{E}}(X)

\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle x,X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle^{2}}}\right]

\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}_{Y,x|X}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle x,X_{m}^{\dagger}\tilde{Y}_{m}}}\right\rangle^{2}}}\right]

\displaystyle=\frac{1}{M}\sum_{m=1}^{M}\mathbb{E}_{x}\mathopen{}\mathclose{{\left[\mathopen{}\mathclose{{\left\langle(X_{m}^{\dagger})^{T}x,Cov(Y_{m},X_{m})(X_{m}^{\dagger})^{T}x}}\right\rangle}}\right]

\displaystyle\geq\frac{\tilde{\tau}^{2}}{M}\sum_{m=1}^{M}\mathbb{E}_{x}\mathopen{}\mathclose{{\left[||(X_{m}^{\dagger})^{T}x||^{2}}}\right]

\displaystyle=\frac{\tau^{2}}{M}\sum_{m=1}^{M}Tr\mathopen{}\mathclose{{\left[(X_{m}^{\dagger})^{T}\mathbb{E}_{x}\mathopen{}\mathclose{{\left[x\otimes x}}\right]X_{m}^{\dagger}}}\right]

\displaystyle=\frac{\tau^{2}}{M}\sum_{m=1}^{M}Tr\mathopen{}\mathclose{{\left[(X_{m}^{\dagger})^{T}\Sigma X_{m}^{\dagger}}}\right]\;.

(B.5)

We proceed by introducing the whitened data matrices

W_{m}:=X_{m}\Sigma^{-1/2}\;.

We then
distinguish the two cases:

(I)
d\geq b=\frac{n}{M}
:
Following the arguments in
[
Hol20
]
(Proof of Theorem 3) shows that

\mathbb{E}_{X}\mathopen{}\mathclose{{\left[Tr\mathopen{}\mathclose{{\left[(X_{m}^{\dagger})^{T}\Sigma X_{m}^{\dagger}}}\right]}}\right]\geq\mathbb{E}_{X}\mathopen{}\mathclose{{\left[Tr\mathopen{}\mathclose{{\left[(W_{m}W_{m}^{T})^{-1}}}\right]}}\right]\geq\frac{b}{d+1-b}\;.

Combining this with (
B.2
) gives by independence

\displaystyle\tilde{\mathcal{E}}

\displaystyle=\mathbb{E}_{X}[\tilde{\mathcal{E}}(X)]

\displaystyle\geq\frac{\tilde{\tau}^{2}}{M}\frac{b}{d+1-b}

\displaystyle=\frac{\tilde{\tau}^{2}}{M}\frac{b}{d+1-b}\;.

The result follows from (
B.4
).

(II)
d\leq b=\frac{n}{M}
:
A short calculation shows that

Tr\mathopen{}\mathclose{{\left[(X_{m}^{\dagger})^{T}\Sigma X_{m}^{\dagger}}}\right]=Tr\mathopen{}\mathclose{{\left[(W_{m}^{T}W_{m})^{-1}}}\right]\;.

Following again
[
Hol20
]
(Proof of Theorem 3) we readily obtain

\mathbb{E}_{X}\mathopen{}\mathclose{{\left[Tr\mathopen{}\mathclose{{\left[(X_{m}^{\dagger})^{T}\Sigma X_{m}^{\dagger}}}\right]}}\right]=\mathbb{E}_{X}\mathopen{}\mathclose{{\left[Tr\mathopen{}\mathclose{{\left[(W_{m}^{T}W_{m})^{-1}}}\right]}}\right]\geq\frac{d}{b+1-d}\;.

We conclude as above to obtain the result.
∎
