Sample Efficient Model Evaluation
Emine Yilmaz, Peter Hayes, Raza Habib, Jordan Burgess, David Barber

Abstract
Labelling data is a major practical bottleneck in training and testing classifiers. Given a collection of unlabelled data points, we address how to select which subset to label to best estimate test metrics such as accuracy, F 1 F_{1} score or micro/macro F 1 F_{1} . We consider two sampling based approaches, namely the well-known Importance Sampling and we introduce a novel application of Poisson Sampling. For both approaches we derive the minimal error sampling distributions and how to approximate and use them to form estimators and confidence intervals. We show that Poisson Sampling outperforms Importance Sampling both theoretically and experimentally.



1
Offline Model Evaluation

How to select
training
examples from an unlabelled pool to minimise labelling effort is well studied (see for example
[
1
]
). However, the complementary problem of selecting which testpoints to label to estimate
test
performance is less well studied. Having a good estimate of test performance is vital to gain confidence in the predictive performance of a model. We focus in this initial work on the ‘offline’ setting in which we assume that a single set of data points will be selected to be labelled. The ‘online’ setting in which labelled testpoints can inform the future selection of testpoints to label is left for a separate study.

We assume that we have a trained probabilistic binary classifier
p(c^{p}_{n}|x_{n})
, where
x_{n}
is an input and
c^{p}_{n}\in\left\{{0,1}\right\}
is the predicted class, with
c^{p}_{n}=1
being the positive’ class and
c^{p}_{n}=0
being the ‘negative’ class. From this trained classifier we assume that a class label is produced deterministically. For example, one may use thresholding to set
c^{p}_{n}=1
if
p(c^{p}_{n}=1|x_{n})>\theta
for some user specified
\theta
. Given a set of test inputs
\mathcal{X}=\left\{{x_{1},\ldots,x_{N}}\right\}
we would like to estimate various measures of performance such as accuracy,
F_{1}
score, etc. However, we do not a priori know the true class labels
c^{t}_{n}
and assume that it is very costly (in time/effort) to obtain these true class labels. We therefore know the test set inputs and wish to estimate the test performance using as little test labelling effort as possible. Assuming for the moment that we have access to all true test labels,
c^{t}_{n}\in\left\{{0,1}\right\}
, we first consider test metrics of the form

\mathbb{F}\equiv\frac{\sum_{n=1}^{N}f(c^{p}_{n},c^{t}_{n})}{\sum_{n=1}^{N}g(c^{p}_{n},c^{t}_{n})}

(1)

For example, for the accuracy metric we have
f(c^{p},c^{t})=\mathbb{I}\left[{c^{p}=c^{t}}\right]
,
g(c^{p},c^{t})=1
.
Here
\mathbb{I}\left[{x=y}\right]
is the indicator function, being 1 when
x=y
and 0 otherwise. Similarly, for the
\mathbb{F}_{\alpha}
metric
0\leq\alpha\leq 1

\mathbb{F}_{\alpha}\equiv\frac{\sum_{n=1}^{N}\mathbb{I}\left[{c^{t}_{n}=1}\right]\mathbb{I}\left[{c^{p}_{n}=1}\right]}{\alpha\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=1}\right]+(1-\alpha)\sum_{n=1}^{N}\mathbb{I}\left[{c^{t}_{n}=1}\right]}

(2)

where

\displaystyle f(c^{p},c^{t})

\displaystyle=\mathbb{I}\left[{c^{t}=1}\right]\mathbb{I}\left[{c^{p}=1}\right],\hskip 7.11317ptg(c^{p},c^{t})=\alpha\mathbb{I}\left[{c^{p}=1}\right]+(1-\alpha)\mathbb{I}\left[{c^{t}=1}\right].

(3)

The
F_{1}
metric is given by
\mathbb{F}_{\frac{1}{2}}
; recall (
\mathbb{F}_{0}
) and precision (
\mathbb{F}_{1}
) along with other metrics are also easily defined. Where there is no ambiguity, we write
f_{n}
in place of
f(c^{p}_{n},c^{t}_{n})
, and similarly for
g_{n}
.

The above metrics require us to know the true value of the test label
c^{t}_{n}
. However, in our scenario we wish to get a good estimate of the test metric, without having to label all test points. A simple approach is to uniformly sample a subset of test points
x_{n}
, label them and calculate the performance. However, this is sub-optimal, particularly in the case of high class imbalance which occurs frequently in practice. Consider for example the ability to correctly classify an offensive tweet for content moderation. Only a small percentage of the dataset (say less than 7%) may contain offensive tweets
1
1

1

See for example
www.kaggle.com/vkrahul/twitter-hate-speech
.
We therefore wish to actively select datapoints to label such that we obtain an accurate metric (for example, by concentrating on tweets which are likely to be offensive).

We consider two sampling-based approaches to estimating test metrics – Importance Sampling and Poisson Sampling. Full derivations are in the appendix, including the more general approach in app(
D
) that can be used to estimate for example the macro
F_{1}
score in multi-label classification. The theory behind the approaches is similar and we begin with the better known Importance Sampling. We note that an ideal estimator would have the property that as all
N
test labels are known, the metric will be correctly evaluated with no uncertainty (for a deterministic true classifier
p(c^{t}_{n}|x_{n})
).

It is important to bear in mind the two stages in which we need estimates of the metric. The pre-sampling stage estimates the metric to approximate the optimal sampler. The post-sampling stage uses the drawn samples to form an estimate of the performance.
We also note that the metric used to form the samples may not be the same as the metric used for the evaluation. This is because we will typically only wish to use a single criterion to determine which test points should be labelled – however, we may wish to estimate a variety of performance metrics using those samples. For example, we may decide which datapoints to label on the basis of getting the best estimate of
F_{1}
score, but also use those samples to estimate
F_{1}
, recall, precision, etc.

2
Importance Sampling

We first extend the work of
[
2
]
to a more general class of test metrics. Importance Sampling (IS) can be used to estimate test performance by independently sampling (with replacement) indices
m_{1},\ldots,m_{M}
,
m_{i}\in\left\{{1,\ldots,N}\right\}
from the test dataset using the importance distribution
q_{n}
,
n\in\left\{{1,\ldots,N}\right\}
. We then form the estimator using

\hat{\mathbb{F}}=\frac{\hat{x}}{\hat{y}}

(4)

where
\hat{x}
and
\hat{y}
are obtained from
M
sampled datapoints:

\hat{x}=\frac{1}{MN}\sum_{i=1}^{M}\frac{f_{m_{i}}}{q_{m_{i}}},\hskip 28.45274pt\hat{y}=\frac{1}{MN}\sum_{i=1}^{M}\frac{g_{m_{i}}}{q_{m_{i}}}.

(5)

Both
\hat{x}
and
\hat{y}
are sums of independently distributed random variables. For large
M
(and any value of
N
),
(\hat{x},\hat{y})
will therefore be approximately jointly Gaussian distributed (per the Central Limit Theorem,
[
3
]
). It is straightforward to show (app(
A
)) the Gaussian
p(\hat{x},\hat{y})
has mean

\mu_{x}\equiv\mathbb{E}\left[{\hat{x}}\right]=\frac{1}{N}\sum_{n=1}^{N}\left\langle{f_{n}}\right\rangle,\hskip 28.45274pt\mu_{y}\equiv\mathbb{E}\left[{\hat{y}}\right]=\frac{1}{N}\sum_{n=1}^{N}\left\langle{g_{n}}\right\rangle.

(6)

Here
\left\langle{\cdot}\right\rangle
is the expectation with respect to the true label distribution
p(c^{t}_{n}|x_{n})
. The corresponding covariance elements are given by

\Sigma_{xy}=\frac{1}{M}\left({\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{\left\langle{f_{n}g_{n}}\right\rangle}{q_{n}}-\mu_{x}\mu_{y}}\right),

(7)

and similarly for
\Sigma_{xx},\Sigma_{yy}
. Since
q_{n}
is typically
O(1/N)
, the mean elements are
O(1)
whilst the covariance elements scale as
O(1/M)
meaning that for large
M
fluctuations from the mean will typically be small. Writing
\hat{x}
and
\hat{y}
in terms of a mean-fluctuation decomposition, and expanding for a small fluctuation
\Delta
,

\hat{\mathbb{F}}=\frac{\hat{x}}{\hat{y}}=\frac{\mu_{x}+\Delta_{x}}{\mu_{y}+\Delta_{y}}=\frac{1}{\mu_{y}}\frac{\mu_{x}+\Delta_{x}}{1+\frac{\Delta_{y}}{\mu_{y}}}\approx\frac{1}{\mu_{y}}\left({\mu_{x}+\Delta_{x}}\right)\left({1-\frac{\Delta_{y}}{\mu_{y}}}\right),

(8)

hence

\mathbb{E}\left[{\hat{\mathbb{F}}}\right]=\frac{\mu_{x}}{\mu_{y}}\left({1-\frac{\Sigma_{xy}}{\mu_{x}\mu_{y}}}\right)+O(1/M^{2}).

(9)

The expected metric therefore tends to

{\mathbb{F}^{\prime}}\equiv\frac{\mu_{x}}{\mu_{y}}=\frac{\sum_{n=1}^{N}\left\langle{f_{n}}\right\rangle}{\sum_{n=1}^{N}\left\langle{g_{n}}\right\rangle}

(10)

as the number of IS samples
M\rightarrow\infty
. This is the exact expected value of the metric calculated on the test set. The estimator
{\hat{\mathbb{F}}}
is therefore a consistent estimator of
\mathbb{F}^{\prime}
, with bias
O(1/M)
.

2.1
Optimal Sampling Distribution

The squared error between the finite
M
estimator
{\hat{\mathbb{F}}}
and infinite
M
limit
{\mathbb{F}^{\prime}}

is (to leading order in
1/M
- see app(
A.1
) for more details)

\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-{\mathbb{F}^{\prime}}}\right)^{2}}\right]=\frac{1}{MN^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\frac{h_{n}^{2}}{q_{n}},

(11)

where
h_{n}^{2}\equiv\left\langle{\left({f_{n}-{\mathbb{F}^{\prime}}g_{n}}\right)^{2}}\right\rangle
is given by

h_{n}^{2}=p(c_{n}^{t}=1|x_{n})\left({f(c^{p}_{n},c^{t}_{n}=1)-{\mathbb{F}^{\prime}}g(c^{p}_{n},c^{t}_{n}=1)}\right)^{2}\\
+p(c^{t}_{n}=0|x_{n})\left({f(c^{p}_{n},c^{t}_{n}=0)-{\mathbb{F}^{\prime}}g(c^{p}_{n},c^{t}_{n}=0)}\right)^{2}.

(12)

The minimal error estimator is then given by
q_{n}\propto|h_{n}|
(see app(
A.2
)).
To calculate the optimal sampler, we therefore need to know the true class distribution
p(c^{t}_{n}=1|x_{n})
. In related works (eg
[
4
,
2
]
) the assumption
p(c^{t}_{n}=1|x_{n})=p(c^{p}_{n}=1|x_{n})
is made. However, this places great faith in the model and we found this can lead to overconfidence, particularly in models with very high or very low probabilities. To address this we replace the unknown
p(c^{t}_{n}|x_{n})
with an estimate

p_{a}(c^{t}_{n}=1|x_{n})=\lambda p(c^{p}_{n}=1|x_{n})+(1-\lambda)0.5

(13)

for some user chosen
0\leq\lambda\leq 1
. In our experiments we found that
\lambda=0.9
works well in practice.
2
2

2

Any choice of
\lambda
gives in a consistent estimator, but a good choice of
\lambda
can result in better convergence.

We also use this to form a pre-sampling approximation to
{\mathbb{F}^{\prime}}
by computing the expectation with respect to
p_{a}(c^{t}_{n}|x_{n})
. We denote this

\mathbb{F}^{\prime}_{a}\equiv\frac{\sum_{n=1}^{N}\mathbb{E}_{{a}}\left[{f_{n}}\right]}{\sum_{n=1}^{N}\mathbb{E}_{{a}}\left[{g_{n}}\right]}.

(14)

which is used in place of
\mathbb{F}^{\prime}
to evaluate eq(
12
). This enables us to fully define
h_{n}
and the optimal Importance Sampler
q_{n}\propto|h_{n}|
.

Given the samples, and the sampling distribution
q
from which they were drawn, we estimate the metric using eq(

) for the given choice of test metric to form a post-sample estimate
{\hat{\mathbb{F}}}

\frac{1}{N}\sum_{n=1}^{N}\frac{h_{n}^{2}}{q_{n}}\approx\frac{1}{MN}\sum_{i=1}^{M}\frac{h_{m_{i}}^{2}}{q_{m_{i}}^{2}},

(15)

in which the

3
3

3

(16)

(17)

3
Poisson Sampling

Importance Sampling has some clear drawbacks: For a deterministic true classifier, once a datapoint has been sampled we know its true label. The IS estimator only becomes exact in the limit of infinite number of samples
M
(and all datapoints are guaranteed to be touched). More seriously, in IS the requirement
q_{n}>0
,
\sum_{n}q_{n}=1
means that no datapoint can have
q_{n}=1
. Hence, even for datapoints which would cause large errors if not included, they cannot be selected with certainty. On the other hand, Poisson Sampling (see eg
[
5
,
6
]
) has the property that as the number of samples tends to the number of datapoints, the approximation becomes exact. As we will show, it also has the ability to select with certainty datapoints that should be labelled.

We again consider the problem of approximating
\mathbb{F}=\sum_{n=1}^{N}f_{n}/\sum_{n=1}^{N}g_{n}
. The Poisson Sampler can be used to form an estimator

{\hat{\mathbb{F}}}=\frac{\hat{x}}{\hat{y}},\hskip 28.45274pt\hat{x}=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}f_{n},\hskip 7.11317pt\hat{y}=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}g_{n}.

(18)

Here the binary indicators
{s_{n}\in\left\{{0,1}\right\}}
are independently drawn from a set of Bernoulli distributions
p(s_{n}=1)=b_{n}
,
b_{n}\in\left[{0,1}\right]
. We also refer to this as Bernoulli Sampling
4
4

4

In the survey sampling literature, “Bernoulli Sampling” refers to Poisson Sampling in which the Bernoulli probabilities of including each sample are all equal. Here we will use the term Bernoulli Sampling interchangeably with Poisson Sampling (with different inclusion probabilities).
.

The
s_{n}
select which test datapoints need to be labelled since

\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}f_{n}=\frac{1}{N}\sum_{n:s_{n}=1}\frac{f_{n}}{b_{n}}.

(19)

Setting all
b_{n}=1
(which means that all test points would be drawn with probability 1), we have
{\hat{\mathbb{F}}}=\sum_{n=1}^{N}f_{n}/\sum_{n=1}^{N}g_{n}
which, for a deterministic true classifier, is equal to the exact value
\mathbb{F}^{\prime}
of the metric on the test data. Hence, as all
b_{n}\rightarrow 1
, the estimator is consistent.

Since
\hat{x}
and
\hat{y}
are sums of independently generated random variables, for large
N
,
p(\hat{x},\hat{y})
will be approximately Gaussian distributed
[
3
]
with mean

\mu_{x}=\frac{1}{N}\sum_{n}\frac{\mathbb{E}\left[{s_{n}f_{n}}\right]}{b_{n}}=\frac{1}{N}\sum_{n}\left\langle{f_{n}}\right\rangle,\hskip 28.45274pt\mu_{y}=\frac{1}{N}\sum_{n}\left\langle{g_{n}}\right\rangle,

(20)

where
\mathbb{E}\left[{s_{n}f_{n}}\right]=\mathbb{E}\left[{s_{n}}\right]\left\langle{f_{n}}\right\rangle=b_{n}\left\langle{f_{n}}\right\rangle
. Here we used the fact that for a 0/1 binary variable
\mathbb{E}\left[{s_{n}}\right]=p(s_{n}=1|b_{n})=b_{n}
. The covariance elements are also straightforward to calculate:

\Sigma_{xy}=\frac{1}{N^{2}}\sum_{n=1}^{N}\left({\frac{\left\langle{f_{n}g_{n}}\right\rangle}{b_{n}}-\left\langle{f_{n}}\right\rangle\left\langle{g_{n}}\right\rangle}\right)

(21)

and similarly for
\Sigma_{xx},\Sigma_{yy}
. Since the covariance elements are
O(1/N)
compared to the
O(1)
mean elements, fluctuations
\Delta
from the mean are typically small and we can write

\hat{\mathbb{F}}=\frac{\hat{x}}{\hat{y}}=\frac{\mu_{x}+\Delta_{x}}{\mu_{y}+\Delta_{y}}=\frac{1}{\mu_{y}}\frac{\mu_{x}+\Delta_{x}}{1+\frac{\Delta_{y}}{\mu_{y}}}\approx\frac{1}{\mu_{y}}\left({\mu_{x}+\Delta_{x}}\right)\left({1-\frac{\Delta_{y}}{\mu_{y}}}\right),

(22)

hence

\mathbb{E}\left[{\hat{\mathbb{F}}}\right]=\frac{\mu_{x}}{\mu_{y}}\left({1-\frac{\Sigma_{xy}}{\mu_{x}\mu_{y}}}\right)+O(1/N^{2})=\frac{\mu_{x}}{\mu_{y}}+O(1/N).

(23)

In the deterministic true classifier setting, the bias of this estimator is therefore approximately

\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}{f_{n}g_{n}}\left({\frac{1}{b_{n}}-1}\right),

(24)

which scales as
O((1/b-1)/N)
for typical values
b
of
b_{n}
. The expected error of the estimator in approximating the metric is (to leading order in
1/N
), see app(
B
)

\displaystyle\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]

\displaystyle\approx\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\left({\frac{1}{b_{n}}\left\langle{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\right\rangle-\left({\left\langle{f_{n}}\right\rangle-\mathbb{F}^{\prime}\left\langle{g_{n}}\right\rangle}\right)^{2}}\right).

(25)

In the deterministic true classifier setting, this reduces to

\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]\approx\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\left({\frac{1}{b_{n}}-1}\right).

(26)

3.1
Optimal Sampling Distribution

The
b
-dependence of the error in eq(
25
) is given by
\sum_{n}h_{n}^{2}/b_{n}
where
h_{n}^{2}=\left\langle{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\right\rangle
;
h_{n}
can be estimated taking the expectation with respect to an approximation
p_{a}(c^{t}_{n}|x_{n})
, leading to the same definition eq(
12
).
Clearly, we can minimise the error to zero by setting all
b_{n}=1
. However, that means that we would simply sample all test points. We therefore add the constraint
\sum_{n=1}^{N}b_{n}=M
so that the expected number of test points that will be sampled is
M
;
the variance of the number of sampled points is
M-\sum_{n=1}^{N}b_{n}^{2}
. The objective
\sum_{n}h_{n}^{2}/b_{n}
is convex on the feasible set
0\leq b_{n}\leq 1
,
\sum_{n=1}^{N}b_{n}=M
and an efficient
O(N)
algorithm to find the global minimum is given in app(
B.1
), similar to a water-filling algorithm, see for example
[
7
]
.

3.2
Post-sampling Performance Approximation

We estimate the error by sampling, using

\displaystyle\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]

\displaystyle\approx\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}\left({\frac{1}{b_{n}}\left\langle{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\right\rangle-\left({\left\langle{f_{n}}\right\rangle-\mathbb{F}^{\prime}\left\langle{g_{n}}\right\rangle}\right)^{2}}\right).

(27)

For a deterministic true classifier the above becomes

\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]\approx\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}h_{n}^{2},

(28)

where
h_{n}^{2}=\left({\frac{1}{b_{n}}-1}\right)\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}
. As for IS, to avoid issues when there are no true positives, we add a small value
\epsilon
to each
h^{2}_{n}
.
We approximate the denominator using

N\mu_{y}\approx\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}g_{n}.

(29)

The full procedure is given in algorithm(
2
). In contrast to IS, there are some key differences:

•

In BS, for a deterministic true classifier
p(c^{t}_{n}|x_{n})
and
M=N
samples, we will evaluate
f_{n}
,
g_{n}
exactly at each point, resulting in calculating the exact metric. In contrast, in IS, as
{M\rightarrow\infty}
the estimator becomes exact (for any testset size
N
).

•

In BS datapoints can be included with probability 1. In fig(
4
) we show the probability of datapoint inclusion
b_{n}
for the Bernoulli approach and the IS inclusion probabilities (the probability that a datapoint
n
will be included in any of the
M
importance samples)
\pi_{n}=1-(1-q_{n})^{M}
.

•

The BS weights start to saturate to 1 when

where
h^{*}
is the maximum of the deviations
h_{1},\ldots,h_{N}
and
\bar{h}
is their average, see app(
C
).

•

In BS we do not know exactly how many datapoints will be sampled, since this is stochastic. In IS we know the number of samples drawn
M
, but the number of unique samples is stochastic.

An important question is whether the asymptotic performance of BS is superior (in expectation) to IS. In app(
C
) we consider the error estimates and show that BS indeed has a lower expected error than IS. This theoretical result is borne out by our experiments, sec(

(s(x),c^{t})
to learn this relationship is not stated and, in cases of severe class imbalance, selecting these uniformly at random is likely to be suboptimal.
Another approach is to use stratified sampling
[
9
]
in which the testset is split into a number of defined strata (for example based on the probability
p(c^{p}=1|x_{n})
). In
[
9
]

. In our case, the metrics of interest
\sum_{n}{f_{n}}/\sum_{n}{g_{n}}
are not of the form to which
[
9
]
can be applied. Implementing stratified sampling using a perturbation approximation of the ratio
\sum_{n}f_{n}/\sum_{n}g_{n}
would make for an interesting but separate study to ours.

Stratified sampling and importance sampling techniques have also been applied to information retrieval metrics such as average precision and normalised discounted cumulative gain
[
10
,
11
,
12
]
. However, these works focused on deriving unbiased estimations of evaluation metrics
given
a sampling distribution, as opposed to identifying the minimum error sampling distribution.

In
[
13
]
the authors recognise that in
[
2
]
the optimal Importance distribution depends on unknown quantities (such as an estimate of the true
F
measure). They update ‘online’ the estimate of the
F
metric as samples are obtained and subsequently update the sampling distribution. This results in an iterative approach to continually updating the sampler.

6
Summary

We addressed the important challenge of approximating the test performance for common metrics used in single and multi-label classification problems. This work addressed the ‘offline’ scenario in which test points are selected
without
the new labels being able to inform future points to label.
We introduced Bernoulli Sampling and compared it to the more standard Importance Sampling to estimate these performance measures.

Our conclusion is that whilst Optimal Importance Sampling and Bernoulli Sampling perform the same in the limit of very small fractions of labelled data, Bernoulli Sampling inevitably outperforms Importance Sampling as the amount of labelled data increases.

Bernoulli Sampling has better accuracy and a lower variance in the examples we considered and we believe it is generally superior for estimating test performance since potentially problematic test points can be included in the sample with certainty. Bernoulli Sampling (Poisson Sampling) is straightforward to implement and, given its superiority over Importance Sampling, we see it as a drop-in replacement for Importance Sampling for performance estimation.

Appendix A
Importance Sampling

We begin with a standard derivation of Importance Sampling being an unbiased estimator, here for the denominator term
\hat{x}
in a estimator:

{\hat{\mathbb{F}}}=\frac{\hat{x}}{\hat{y}}

(30)

Both
\hat{x}
and
\hat{y}
are sums of independently distributed random variables. For large
M
(and any value of
N
),
(\hat{x},\hat{y})
will therefore be approximately jointly Gaussian distributed (Central Limit Theorem).
Taking the expectation with respect to the Importance distribution, the Gaussian
p(\hat{x},\hat{y})
has mean

\mu_{x}\equiv\mathbb{E}\left[{\hat{x}}\right]=\frac{1}{MN}\sum_{i=1}^{M}\mathbb{E}\left[{\frac{f_{m_{i}}}{q_{m_{i}}}}\right]=\frac{1}{MN}\sum_{i=1}^{M}\sum_{n=1}^{N}q_{n}\frac{\left\langle{f_{n}}\right\rangle}{q_{n}}=\frac{1}{N}\sum_{n=1}^{N}\left\langle{f_{n}}\right\rangle

(31)

Here
\left\langle{\cdot}\right\rangle
is expectation with respect to the true label distribution
p(c^{t}_{n}|x_{n})
.
Similarly,

\mu_{y}\equiv\mathbb{E}\left[{\hat{y}}\right]=\frac{1}{N}\sum_{n=1}^{N}\left\langle{g_{n}}\right\rangle

(32)

Covariance elements of the Gaussian
p(\hat{x},\hat{y})
can be computed using

\displaystyle N^{2}M^{2}\mathbb{E}\left[{\hat{x}\hat{y}}\right]

\displaystyle=\mathbb{E}\left[{\sum_{i,j}\frac{f_{m_{i}}g_{m_{j}}}{q_{m_{i}}q_{m_{j}}}}\right]=\mathbb{E}\left[{\sum_{i}\frac{f_{m_{i}}g_{m_{i}}}{q_{m_{i}}^{2}}}\right]+\mathbb{E}\left[{\sum_{i\neq j}\frac{f_{m_{i}}g_{m_{j}}}{q_{m_{i}}q_{m_{j}}}}\right]

(33)

\displaystyle=M\sum_{n=1}^{N}\frac{\left\langle{f_{n}g_{n}}\right\rangle}{q_{n}}+(M^{2}-M)\sum_{n=1}^{N}\left\langle{f_{n}}\right\rangle\sum_{n=1}^{N}\left\langle{g_{n}}\right\rangle

(34)

so that the covariance between
\hat{x},\hat{y}
is

\Sigma_{xy}=\frac{1}{M}\left({\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{\left\langle{f_{n}g_{n}}\right\rangle}{q_{n}}-\mu_{x}\mu_{y}}\right)

(35)

Similarly,

\Sigma_{xx}=\frac{1}{M}\left({\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{\left\langle{f_{n}f_{n}}\right\rangle}{q_{n}}-\mu_{x}\mu_{x}}\right)

(36)

\Sigma_{yy}=\frac{1}{M}\left({\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{\left\langle{g_{n}g_{n}}\right\rangle}{q_{n}}-\mu_{y}\mu_{y}}\right)

(37)

Since
q_{n}
is typically
O(1/N)
, the mean elements are
O(1)
whilst the covariance elements scale as
O(1/M)
meaning that for large
M
fluctuations from the mean will typically be small. Writing
\hat{x}
and
\hat{y}
in terms of a mean-fluctuation decomposition, and expanding for a small fluctuation
\Delta
,

\hat{\mathbb{F}}=\frac{\hat{x}}{\hat{y}}=\frac{\mu_{x}+\Delta_{x}}{\mu_{y}+\Delta_{y}}=\frac{1}{\mu_{y}}\frac{\mu_{x}+\Delta_{x}}{1+\frac{\Delta_{y}}{\mu_{y}}}\approx\frac{1}{\mu_{y}}\left({\mu_{x}+\Delta_{x}}\right)\left({1-\frac{\Delta_{y}}{\mu_{y}}}\right)

(38)

Hence

\mathbb{E}\left[{\hat{\mathbb{F}}}\right]=\frac{\mu_{x}}{\mu_{y}}\left({1-\frac{\Sigma_{xy}}{\mu_{x}\mu_{y}}}\right)+O(1/M^{2})

(39)

The expected metric therefore tends to

{\mathbb{F}^{\prime}}\equiv\frac{\mu_{x}}{\mu_{y}}=\frac{\sum_{n=1}^{N}\left\langle{f_{n}}\right\rangle}{\sum_{n=1}^{N}\left\langle{g_{n}}\right\rangle}

(40)

as the number of IS samples
M\rightarrow\infty
. This is the exact expected value of the metric calculated on the test set and holds for any
N
. We wish to find an estimator that accurately matches this ideal value
\mathbb{F}^{\prime}
. From eq(
39
) we see that
{\hat{\mathbb{F}}}
is a consistent, but biased (with bias
O(1/M)
) estimator of
\mathbb{F}^{\prime}
.

As
N\rightarrow\infty
, the means
\mu_{x}
,
\mu_{y}
tend to (from the law of large numbers)

\mu_{x}\rightarrow\mathbb{E}\left[{f(c^{p},c^{t})}\right],\hskip 7.11317pt\mu_{y}\rightarrow\mathbb{E}\left[{g(c^{p},c^{t})}\right],

(41)

where the expectation is with respect to the joint
p(c^{p},c^{t},x)=p_{d}(c^{p}|x)p(c^{t}|x)p(x)
for decision distribution
10
10

10

Here
p_{d}(c^{p}|x)
represents the decision probability as a function of the model
p(c^{p}|x)
. For example, if we use the model
p(c^{p}|x)
to form a deterministic classifier by thesholding, then
p_{d}(c^{p}=1|x)=\mathbb{I}\left[{p(c^{p}|x)>\theta}\right]
for some user defined threshold
\theta\in\left[{0,1}\right]
.

p_{d}(c^{p}|x)
. Hence, as both
M
and
N
become large, the estimator
{\hat{\mathbb{F}}}
converges to the true test metric (evaluated on infintely many test points
N
)

{\hat{\mathbb{F}}}\rightarrow\frac{\mathbb{E}\left[{f(c^{p},c^{t})}\right]}{\mathbb{E}\left[{g(c^{p},c^{t})}\right]}\equiv{\mathbb{F}^{*}}

(42)

{\hat{\mathbb{F}}}
is therefore also a consistent (but biased) estimator of
{\mathbb{F}^{*}}
. We note that estimating the infinite testset size (
N{}\rightarrow{}\infty
) performance
{\mathbb{F}^{*}}
is not our aim. Rather, our aim is to estimate the performance
{\mathbb{F}^{\prime}}
on the given, finite
N
dataset. In our scenario, if we could evaluate the test performance on all
N
datapoints, we would be able to compute the exact metric (for a deterministic classifier
p(c^{t}_{n}|x_{n})
).

The squared error between the finite

{\hat{\mathbb{F}}}

(47)

Hence, to leading order in

\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-{\mathbb{F}^{\prime}}}\right)^{2}}\right]=\frac{1}{M\mu_{y}^{2}}\left({\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{\left\langle{\left({f_{n}-{\mathbb{F}^{\prime}}g_{n}}\right)^{2}}\right\rangle}{q_{n}}-\left({\mu_{x}-{\mathbb{F}^{\prime}}\mu_{y}}\right)^{2}}\right)

Since
\mathbb{F}^{\prime}=\mu_{x}/\mu_{y}
, we note that the term

\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-{\mathbb{F}^{\prime}}}\right)^{2}}\right]=\frac{1}{MN^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\frac{h_{n}^{2}}{q_{n}}

(49)

where

\displaystyle h_{n}^{2}

\displaystyle=\left\langle{\left({f_{n}-{\mathbb{F}^{\prime}}g_{n}}\right)^{2}}\right\rangle

(50)

\displaystyle=p(c_{n}^{t}=1|x_{n})\left({f(c^{p}_{n},c^{t}_{n}=1)-{\mathbb{F}^{\prime}}g(c^{p}_{n},c^{t}_{n}=1)}\right)^{2}

\displaystyle\hskip 99.58464pt+p(c^{t}_{n}=0|x_{n})\left({f(c^{p}_{n},c^{t}_{n}=0)-{\mathbb{F}^{\prime}}g(c^{p}_{n},c^{t}_{n}=0)}\right)^{2}

(51)

A.2
Optimal Sampling Distribution

The sampling distribution that minimises the variance can be calculated using the Lagrangian

\sum_{n=1}^{N}\frac{h_{n}^{2}}{q_{n}}-\lambda\left({\sum_{n=1}^{N}q_{n}-1}\right).

(52)

Differentiating with respect to
q_{n}
and equating to zero gives the optimal choice as

q_{n}=\frac{|h_{n}|}{\sum_{n=1}^{N}|h_{n}|}.

(53)

Clearly, it isn’t possible to construct this optimal estimator in practice, since this would require us to know the true metric
F
. Hence, in practice, we use

q_{n}=\frac{\tilde{h}_{n}}{\sum_{n=1}^{N}\tilde{h}_{n}}

(54)

for some approximation
\tilde{h}_{n}
of
h_{n}
.

Appendix B
Bernoulli Sampling

We again consider the problem of approximating

\frac{\sum_{n=1}^{N}f_{n}}{\sum_{n=1}^{N}g_{n}}

(55)

The Bernoulli Sampler
[
6
]
which can be used to form an estimator

{\hat{\mathbb{F}}}=\frac{\hat{x}}{\hat{y}}

(56)

where

\hat{x}=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}f_{n},\hskip 28.45274pt\hat{y}=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}g_{n}

(57)

Since
\hat{x}
and
\hat{y}
are sums of independently generated random variables, for large
N
,
p(\hat{x},\hat{y})
will be approximately Gaussian distributed with mean

\mu_{x}=\frac{1}{N}\sum_{n}\frac{\mathbb{E}\left[{s_{n}f_{n}}\right]}{b_{n}}=\frac{1}{N}\sum_{n}\left\langle{f_{n}}\right\rangle,\hskip 28.45274pt\mu_{y}=\frac{1}{N}\sum_{n}\left\langle{g_{n}}\right\rangle,

(58)

where
\mathbb{E}\left[{s_{n}f_{n}}\right]=\mathbb{E}\left[{s_{n}}\right]\left\langle{f_{n}}\right\rangle=b_{n}\left\langle{f_{n}}\right\rangle
. Here we used the fact that for a 0/1 binary variable
\mathbb{E}\left[{s_{n}}\right]=p(s_{n}=1|b_{n})=b_{n}
; as for IS,
\left\langle{\cdot}\right\rangle
denotes expectation with to a stochastic true classifier. The covariance elements are also straightforward to calculate:

\displaystyle\Sigma_{xy}

\displaystyle=\frac{1}{N^{2}}\sum_{n=1}^{N}\left({\frac{\left\langle{f_{n}g_{n}}\right\rangle}{b_{n}}-\left\langle{f_{n}}\right\rangle\left\langle{g_{n}}\right\rangle}\right),

(59)

\displaystyle\Sigma_{yy}

\displaystyle=\frac{1}{N^{2}}\sum_{n=1}^{N}\left({\frac{\left\langle{g_{n}g_{n}}\right\rangle}{b_{n}}-\left\langle{g_{n}}\right\rangle\left\langle{g_{n}}\right\rangle}\right),

(60)

\displaystyle\Sigma_{xx}

\displaystyle=\frac{1}{N^{2}}\sum_{n=1}^{N}\left({\frac{\left\langle{f_{n}f_{n}}\right\rangle}{b_{n}}-\left\langle{f_{n}}\right\rangle\left\langle{f_{n}}\right\rangle}\right)

(61)

Since the covariance elements are

compared to the

\hat{\mathbb{F}}=\frac{\hat{x}}{\hat{y}}=\frac{\mu_{x}+\Delta_{x}}{\mu_{y}+\Delta_{y}}=\frac{1}{\mu_{y}}\frac{\mu_{x}+\Delta_{x}}{1+\frac{\Delta_{y}}{\mu_{y}}}\approx\frac{1}{\mu_{y}}\left({\mu_{x}+\Delta_{x}}\right)\left({1-\frac{\Delta_{y}}{\mu_{y}}}\right)

(62)

Hence

\mathbb{E}\left[{\hat{\mathbb{F}}}\right]=\frac{\mu_{x}}{\mu_{y}}\left({1-\frac{\Sigma_{xy}}{\mu_{x}\mu_{y}}}\right)+O(1/N^{2})=\frac{\mu_{x}}{\mu_{y}}+O(1/N)

(63)

In the deterministic true classifier setting, the bias of this estimator is therefore approximately

\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}{f_{n}g_{n}}\left({\frac{1}{b_{n}}-1}\right)

(64)

As
N\rightarrow\infty
, the means
\mu_{x}
,
\mu_{y}
tend to (from the law of large numbers)

\mu_{x}\rightarrow\mathbb{E}\left[{f(c^{p},c^{t})}\right],\hskip 7.11317pt\mu_{y}\rightarrow\mathbb{E}\left[{g(c^{p},c^{t})}\right],

(65)

where the expectation is with respect to the joint
p(c^{p},c^{t},x)=p_{d}(c^{p}|x)p(c^{t}|x)p(x)
. Hence, as
N
becomes large, the estimator
{\hat{\mathbb{F}}}
converges to the value

{\hat{\mathbb{F}}}\rightarrow\frac{\mathbb{E}\left[{f(c^{p},c^{t})}\right]}{\mathbb{E}\left[{g(c^{p},c^{t})}\right]}\equiv{\mathbb{F}^{*}}

(66)

As for IS, the BS estimator
{\hat{\mathbb{F}}}
is therefore a consistent (but biased) estimator of
{\mathbb{F}^{*}}
.

The expected squared error of the estimator in approximating the metric on the given dataset is then (to leading order in
1/N
)

\displaystyle\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]

\displaystyle\approx\frac{1}{\mu_{y}^{2}}\mathbb{E}\left[{\left({\Delta_{x}-\mathbb{F}\Delta_{y}}\right)^{2}}\right]=\frac{1}{\mu_{y}^{2}}\left({\Sigma_{xx}-2\mathbb{F}^{\prime}\Sigma_{xy}+\mathbb{F}^{\prime 2}\Sigma_{yy}}\right)

(67)

\displaystyle=\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\left({\frac{1}{b_{n}}\left\langle{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\right\rangle-\left({\left\langle{f_{n}}\right\rangle-\mathbb{F}^{\prime}\left\langle{g_{n}}\right\rangle}\right)^{2}}\right)

(68)

In the above

is the true value of the metric on the given finite

(69)

B.1
Optimal sampling probabilities

The objective is to minimise the function

\sum_{n=1}^{N}\frac{h_{n}^{2}}{b_{n}}

(70)

subject to the constraints
\sum_{n}b_{n}=M
and
0<b_{n}\leq 1
. We note first that the constraints are convex and that the function is convex in the feasible set. Therefore the objective function has a unique minimum value.

Minimising the variance while keeping the expected number of samples fixed to
M
requires solving the Lagrangian

\sum_{n=1}^{N}\frac{h_{n}^{2}}{b_{n}}+\lambda\left({M-\sum_{n}b_{n}}\right).

(71)

Since we have the requirement
0\leq b_{n}\leq 1
we parameterise

b_{n}=e^{-\gamma_{n}^{2}}.

(72)

Taking the derivative of the Lagrangian wrt
\gamma_{n}
gives

\gamma_{n}\left({h_{n}^{2}/b_{n}-\lambda b_{n}}\right)=0,

(73)

so that either
\gamma_{n}=0
(
b_{n}=1
) or,

\frac{h_{n}^{2}}{b_{n}}=\lambda b_{n}\Rightarrow b_{n}=\frac{h_{n}}{\sqrt{\lambda}}

(74)

Defining binary indicators
i_{n}\in\left\{{0,1}\right\}
we can write these two possibilities as

b_{n}=i_{n}+\kappa(i)(1-i_{n})h_{n}

(75)

for some the function
\kappa(i)
. Since
\sum_{n}b_{n}=M
we have

M=\sum_{n}i_{n}+\kappa(i)\sum_{n}\left({1-i_{n}}\right)h_{n}

(76)

so that

\kappa(i)\equiv\frac{M-\sum_{n}i_{n}}{\sum_{n}\left({1-i_{n}}\right)h_{n}}

(77)

Plugging this back into the objective, we have

E(i)\equiv\sum_{n}\frac{h_{n}^{2}}{b_{n}}=\sum_{n}h_{n}^{2}\left({i_{n}+(1-i_{n})\frac{1}{\kappa(i)h_{n}}}\right)=\sum_{n}i_{n}h_{n}^{2}+\frac{1}{M-\sum_{n}i_{n}}\left({\sum_{n}(1-i_{n})h_{n}}\right)^{2}.

(78)

Since the highest contributions to the error arise from the largest values of
h_{n}
, the values of
b_{n}
must be ordered according to decreasing values of
h_{n}
. That is, the largest values of
b_{n}
are associated with the largest values of
h_{n}
. We note also that the objective is convex on the feasible set
0\leq b_{n}\leq 1
. This means that the first valid solution we find is guaranteed to equal the global minimal value. A simple
O(N)
algorithm to find the global minimum is given in algorithm(
3
).

Appendix C
Importance Sampling versus Bernoulli Sampling

From eq(
49
) the expected squared error for IS is, using the optimal IS distribution eq(
53
)

E_{IS}\equiv\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-{\mathbb{F}^{\prime}}}\right)^{2}}\right]_{IS}=\frac{1}{M_{IS}N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\frac{h_{n}^{2}}{q_{n}}=\frac{1}{M_{IS}\mu_{y}^{2}}\left({\frac{1}{N}\sum_{n=1}^{N}h_{n}}\right)^{2}

(79)

For BS we do not have a simple expression for the optimal setting of the sampling parameters
b_{n}
. However, when
M_{BS}
is small compared to
N
, the
b_{n}
typically do not saturate to 1 and that therefore, from eq(
74
),
b_{n}\propto h_{n}
. Using the constraint
\sum_{n=1}^{N}b_{n}=M_{BS}
, provided that all
b_{n}<1
, we have
b_{n}=M_{BS}h_{n}/\sum_{n}h_{n}
. The expected squared error, from eq(
25
) in the deterministic true-classifier case is then

E_{BS}\equiv\mathbb{E}\left[{\left({{\hat{\mathbb{F}}}-\mathbb{F}^{\prime}}\right)^{2}}\right]_{BS}=\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}\left({\frac{1}{b_{n}}-1}\right)h_{n}^{2}=\frac{1}{M_{BS}\mu_{y}^{2}}\left({\frac{1}{N}\sum_{n=1}^{N}h_{n}}\right)^{2}-\frac{1}{N^{2}\mu_{y}^{2}}\sum_{n=1}^{N}h_{n}^{2}

(80)

meaning that the expected BS error is less than the expected IS error if the same number of samples
M_{IS}=M_{BS}
is used.

However, this question is made more complex by the fact that, in a deterministic true classifier setting, repeated use of the same sample does not add to the labelling cost. In IS, due to resampling, the inclusion probability in
M
samples is

\pi_{n}=1-(1-q_{n})^{M}

(81)

so that the expected number of unique samples in
M
drawn samples is,

\sum_{n}\pi_{n}=N-\sum_{n}(1-q_{n})^{M}

(82)

We therefore suggest the sample equivalence

M_{BS}=N-\sum_{n}(1-q_{n})^{M_{IS}}

(83)

Using the simple bound

\frac{1}{N}\sum_{n}h_{n}^{2}\geq\left({\frac{1}{N}\sum_{n}h_{n}}\right)^{2}

(84)

we can write

E_{BS}\leq\left({\frac{1}{M_{BS}}-\frac{1}{N}}\right)M_{IS}E_{IS}

(85)

For small
M_{IS}
and large
N
(so that each
q_{n}
is small), from eq(
83
)

M_{BS}\approx N-\sum_{n}(1-M_{IS}q_{n})=N-N+M_{IS}=M_{IS}

(86)

so that (for small
M_{IS}/N
)

E_{BS}\leq\left({1-\frac{M_{IS}}{N}}\right)E_{IS}

(87)

In the limit of small
M_{IS}
,
E_{BS}\approx E_{IS}
(as borne out by our experiments). However, as
M_{IS}
increases BS starts to significantly outperform IS. This shows that there is no reason to prefer IS over BS since BS will have at least as good performance as IS (even though they have equivalent performance in the very low sample limit).

The difference between IS and BS will become more significant when the BS weights start to saturate to 1. This happens when (from algorithm(
3
))

h^{*}\geq\frac{N}{M_{BS}}\bar{h}

(88)

where
h^{*}
is the maximum of the deviations
h_{1},\ldots,h_{N}
and
\bar{h}
is the average of the deviations.

Appendix D
Multi-Labels

In the multi-labelling scenario, an input
x_{n}
can have multiple labels
c_{n}\in\left\{{1,\ldots,C}\right\}
; for example, a sentence might be classed as "upbeat", "humorous" and "about cats". A standard way to address this is to consider a set of binary classifiers, each predicting the presence/absence of each of the
C
attributes – sometimes called the binary relevance approach
[
17
]
. For simplicity, we assume the
C
binary classifiers are independent, conditioned on the input
x_{n}
.

Writing
c^{p}_{n}=\left({v_{1},\ldots,v_{C}}\right)
where each
v_{k}\in\left\{{0,1}\right\}
the model prediction is then given by

p(c^{p}_{n}|x_{n})=\prod_{k=1}^{C}p(v_{k}=1|x_{n})

(89)

where
p(v_{k}=1|x_{n})
is a user provided binary classifier for each class.

D.1
Micro
F_{1}

For this setting, a common metric is the Micro-
F_{1}
score defined as

\mathbb{F}^{\mu}_{\alpha}\equiv\frac{\sum_{n=1}^{N}\sum_{i=1}^{C}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}=i}\right]}{\sum_{n=1}^{N}\sum_{i=1}^{C}\left({\alpha\mathbb{I}\left[{c^{p}_{n}=i}\right]+(1-\alpha)\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right)}

(90)

where
c^{p}_{n}=i
means
v^{p}_{n,i}=1
and
c^{p}_{n}\neq i
means
v^{p}_{n,i}=0
.

This is of the general form
\sum_{n}f_{n}/\sum_{n}g_{n}
where

f_{n}=\sum_{i=1}^{C}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}=i}\right],\hskip 7.11317ptg_{n}=\sum_{i=1}^{C}\left({\alpha\mathbb{I}\left[{c^{p}_{n}=i}\right]+(1-\alpha)\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right)

(91)

We may then use the same strategy as in eq(
13
) to form an approximation to the true classifier using

p_{a}(c^{t}_{n}|x_{n})=\prod_{k=1}^{C}p_{a}(v_{k}=1|x_{n})

(92)

where

p_{a}(v_{k}=1|x_{n})=\lambda p(v_{k}=1|x_{n})+(1-\lambda)0.5

(93)

The previous Optimal IS and Optimal BS theory still holds in this setting and to calculate the optimal sampling distributions we need to calculate the expected squared deviation

h_{n}^{2}=\left\langle{\left({f_{n}-\mathbb{F}^{\prime}g_{n}}\right)^{2}}\right\rangle

(94)

where the quantities are approximated by taking expectation with respect to
p_{a}(c^{t}_{n}|x_{n})
. This is a straightforward calculation, see app(
D.2
). This can then be used to define the Optimal Importance and Bernoulli Samplers, as before. We estimate the error in the resulting estimator of
\mathbb{F}^{\mu}_{\alpha}
by using the same approach as for IS and BS.

D.2
Micro
F_{1}
Deviation

Writing
h_{n}(v)=\sum_{k=1}^{C}h(v_{nk})
, where
h(v_{nk})=f(v^{p}_{nk},v^{t}_{nk})-\mathbb{F}^{\prime}g(v^{p}_{nk},v^{t}_{nk})

a straightforward calculation gives the expectation
h_{n}^{2}\equiv\left\langle{h_{n}(v)^{2}}\right\rangle

as

\displaystyle h_{n}^{2}

\displaystyle=\sum_{k}p_{a}(v_{k}=0|x_{n})h^{2}(v^{p}_{nk},v^{t}_{k}=0)+p_{a}(v_{k}=1|x_{n})h^{2}(v^{p}_{nk},v^{t}_{k}=1)

(95)

\displaystyle-\sum_{k}\left({p_{a}(v_{k}=0|x_{n})h(v^{p}_{nk},v^{t}_{k}=0)+p_{a}(v_{k}=1|x_{n})h(v^{p}_{nk},v^{t}_{k}=1)}\right)^{2}

(96)

\displaystyle+\left({\sum_{k}p_{a}(v_{k}=0|x_{n})h(v^{p}_{nk},v^{t}_{k}=0)+p_{a}(v_{k}=1|x_{n})h(v^{p}_{nk},v^{t}_{k}=1)}\right)^{2}

(97)

D.3
Macro
F_{1}

We first compute the true positive, false positive and false negative rates for each class:

\displaystyle TP_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}=i}\right]

(98)

\displaystyle FP_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}\neq i}\right]

(99)

\displaystyle FN_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}\neq i,c^{t}_{n}=i}\right]

(100)

Then the macro Precision and Recall are defined as

P=\frac{1}{C}\sum_{i=1}^{C}\frac{TP_{i}}{TP_{i}+FP_{i}},\hskip 7.11317ptR=\frac{1}{C}\sum_{i=1}^{C}\frac{TP_{i}}{TP_{i}+FN_{i}},

(101)

and we finally define the the Macro
F_{1}
score as

\mathbb{F}=\frac{2PR}{P+R}

(102)

This cannot be written in the form
\sum_{n}f_{n}/\sum_{n}g_{n}
and our previous theory cannot be directly applied. For notational simplicity, we define

\bar{a}_{i}\equiv TP_{i},\hskip 7.11317pt\bar{b}_{i}\equiv FP_{i},\hskip 7.11317pt\bar{c}_{i}\equiv FN_{i}

(103)

and define a BS sampling approximation for each quantity as

\displaystyle a_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}=i}\right]

(104)

\displaystyle b_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}\mathbb{I}\left[{c^{p}_{n}=i,c^{t}_{n}\neq i}\right]

(105)

\displaystyle c_{i}

\displaystyle=\frac{1}{N}\sum_{n=1}^{N}\frac{s_{n}}{b_{n}}\mathbb{I}\left[{c^{p}_{n}\neq i,c^{t}_{n}=i}\right]

(106)

We can make use of the fact that these estimators are sums of independent random variables and as such as jointly Gaussian distributed.
Then the macro
F_{1}
is a function of these variables:

\frac{C}{2}\mathbb{F}(a,b,c)=\frac{\sum_{i}a_{i}/(a_{i}+b_{i})\sum_{i}a_{i}/(a_{i}+c_{i})}{\sum_{i}a_{i}/(a_{i}+b_{i})+\sum_{i}a_{i}/(a_{i}+c_{i})}

(107)

By the Central Limit Theorem,
a,b,c
will concentrate around their average values for large
N
and we can write (see app(
D.4

\mathbb{F}(a,b,c)\approx\frac{1}{N^{2}}\sum_{n=1}^{N}\frac{h_{n}^{2}}{b_{n}}

(108)

where

h_{n}^{2}\equiv\sum_{i=1}^{C}\mathbb{I}\left[{c^{p}_{n}=i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left({\partial_{a_{i}}\mathbb{F}}\right)^{2}+\mathbb{I}\left[{c^{p}_{n}=i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}\neq i}\right]}\right\rangle\left({\partial_{b_{i}}\mathbb{F}}\right)^{2}\\
+\mathbb{I}\left[{c^{p}_{n}\neq i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left({\partial_{c_{i}}\mathbb{F}}\right)^{2}

(109)

We evaluate the derivative of
\mathbb{F}
at
a=\mathbb{E}_{{p_{a}}}\left[{a}\right]
,
b=\mathbb{E}_{{p_{a}}}\left[{b}\right]
,
c=\mathbb{E}_{{p_{a}}}\left[{c}\right]
where the expectation is with respect to
p_{a}
, eq(
92
). This then enables us to compute an approximation to
h_{n}^{2}
which we use to define the Optimal BS, using algorithm(
2
) as usual.

Then the macro

\frac{C}{2}\mathbb{F}(a,b,c)=\frac{\sum_{i}a_{i}/(a_{i}+b_{i})\sum_{i}a_{i}/(a_{i}+c_{i})}{\sum_{i}a_{i}/(a_{i}+b_{i})+\sum_{i}a_{i}/(a_{i}+c_{i})}

a,b,c
will concentrate around their average values for large

\mathbb{F}(a,b,c)\approx\mathbb{F}(\bar{a},\bar{b},\bar{c})+\Delta_{a}^{\textsf{T}}\partial_{a}\mathbb{F}+\Delta_{b}^{\textsf{T}}\partial_{b}\mathbb{F}+\Delta_{c}^{\textsf{T}}\partial_{c}\mathbb{F}

+2\left({\partial_{a_{i}}\mathbb{F}\partial_{b_{i}}\mathbb{F}}\right)\mathbb{E}\left[{\Delta a_{i}\Delta b_{i}}\right]+2\left({\partial_{a_{i}}\mathbb{F}\partial_{c_{i}}\mathbb{F}}\right)\mathbb{E}\left[{\Delta a_{i}\Delta c_{i}}\right]+2\left({\partial_{b_{i}}\mathbb{F}\partial_{c_{i}}\mathbb{F}}\right)\mathbb{E}\left[{\Delta b_{i}\Delta c_{i}}\right]

(112)

\mathbb{E}\left[{\Delta a_{i}^{2}}\right]=\frac{1}{N^{2}}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left({\frac{1}{b_{n}}-1}\right)

(113)

\mathbb{E}\left[{\Delta b_{i}^{2}}\right]=\frac{1}{N^{2}}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}\neq i}\right]}\right\rangle\left({\frac{1}{b_{n}}-1}\right)

(114)

\mathbb{E}\left[{\Delta c_{i}^{2}}\right]=\frac{1}{N^{2}}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}\neq i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left({\frac{1}{b_{n}}-1}\right)

(115)

\mathbb{E}\left[{\Delta a_{i}\Delta b_{i}}\right]=-\frac{1}{N^{2}}\sum_{n=1}^{N}\mathbb{I}\left[{c^{p}_{n}=i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left\langle{\mathbb{I}\left[{c^{t}_{n}\neq i}\right]}\right\rangle

(116)

\mathbb{E}\left[{\Delta a_{i}\Delta c_{i}}\right]=\mathbb{E}\left[{\Delta b_{i}c_{i}}\right]=0

(117)

\sum_{n=1}^{N}\frac{h_{n}^{2}}{b_{n}}

+\mathbb{I}\left[{c^{p}_{n}\neq i}\right]\left\langle{\mathbb{I}\left[{c^{t}_{n}=i}\right]}\right\rangle\left({\partial_{c_{i}}\mathbb{F}}\right)^{2}

Appendix E
Online Bernoulli Sampling

Unlike Importance Sampling, in which a data index
n
can be selected one at a time, by construction in Bernoulli Sampling a
collection
of indices
\mathcal{N}=\left\{{n:s_{n}=1}\right\}
are sampled. However, it is still possible to form an online Bernoulli process in which at each sampling round, a subset of indices are drawn, based on previously drawn indices. For example, consider a simple metric of the form
\sum_{n=1}^{N}f_{n}
. In the first round of Bernoulli Sampling, we have weights
b^{1}=b^{1}_{1},\ldots,b^{1}_{N}
and samples
s^{1}_{1},\ldots,s^{1}_{N}
and thus indices
\mathcal{N}_{1}
that correspond to
s^{1}_{n}=1
from this Bernoulli distribution. We would then like to use these sampled values to inform the second stage of Bernoulli sampling. We write the first round estimator as

{\hat{\mathbb{F}}}_{1}=\sum_{n=1}^{N}\frac{s^{1}_{n}}{b^{1}_{n}}f_{n}=\sum_{n\in\mathcal{N}_{1}}\frac{f_{n}}{b^{1}_{n}}

(120)

In the second round, we do not wish to redraw the set
\mathcal{N}_{1}
and the weights
b^{2}
will therefore depend on the previously drawn indices
\mathcal{N}_{1}
. We can then form a new estimator

{\hat{\mathbb{F}}}_{2}=\sum_{n=1}^{N}\frac{s^{2}_{n}}{b^{2}_{n}}f_{n}

(121)

Since
{\hat{\mathbb{F}}}_{2}
does not contain the previously sampled indices, it cannot be an unbiased estimator of
\mathbb{F}
. A simple way to compensate for this (analogous to the PURE estimator
[
15
]
for IS) is to write

{\hat{\mathbb{F}}}_{1:2}=\frac{1}{2}{\hat{\mathbb{F}}}_{1}+\frac{1}{2}\left({\sum_{n\in\mathcal{N}_{1}}f_{n}+{\hat{\mathbb{F}}}_{2}}\right)

(122)

Taking the expectation with respect to the two rounds
p(s^{2}|s^{1})p(s^{1})
we have

\displaystyle\mathbb{E}_{{s}}\left[{{\hat{\mathbb{F}}}_{1:2}}\right]

\displaystyle=\frac{1}{2}\mathbb{E}_{{s_{1}}}\left[{{\hat{\mathbb{F}}}_{1}}\right]+\frac{1}{2}\mathbb{E}_{{s_{1}}}\left[{{\sum_{n\in\mathcal{N}_{1}}f_{n}+\mathbb{E}_{{s_{2}|s_{1}}}\left[{{\hat{\mathbb{F}}}_{2}}\right]}}\right]

(123)

\displaystyle=\frac{1}{2}\mathbb{E}_{{s_{1}}}\left[{{\hat{\mathbb{F}}}_{1}}\right]+\frac{1}{2}\mathbb{E}_{{s_{1}}}\left[{{\sum_{n\in\mathcal{N}_{1}}f_{n}+\sum_{n\in\mathcal{N}\setminus\mathcal{N}_{1}}f_{n}}}\right]

(124)

\displaystyle=\frac{1}{2}\mathbb{F}+\frac{1}{2}\mathbb{E}_{{s_{1}}}\left[{\mathbb{F}}\right]

(125)

\displaystyle=\mathbb{F}

(126)

More generally, for the
r^{th}
round of Bernoulli Sampling (designed so that it cannot select any of the previously selected datapoints) we write an estimator for the sum over the remaining non-sampled indices as

{\hat{\mathbb{F}}}_{r}=\sum_{n=1}^{N}\frac{s_{n}}{b_{n}^{r}}f_{n}

(127)

Then writing
\mathcal{N}_{1:R-1}
for all indices that have been sampled in the previous
R-1
rounds, we can form an unbiased estimator of
\mathbb{F}
using

{\hat{\mathbb{F}}}_{1:R}=\frac{1}{R}\sum_{r=1}^{R}\left({\sum_{n\in\mathcal{N}_{1:r-1}}f_{n}+{\hat{\mathbb{F}}}_{r}}\right),\hskip 28.45274pt\mathcal{N}_{0}=\emptyset

(128)

We note that the choice of distribution
p(s^{r}|s^{1:r-1})
can depend on an updated online estimate of the metric, and the estimator
{\hat{\mathbb{F}}}_{1:R}
remains unbiased. However, the theoretical and empirical properties of such an online Bernoulli Sampler and its implementation in the estimation of general metrics
\sum_{n}f_{n}/\sum_{n}g_{n}
is left for future study.
