More on Projected Type Iteration Method and Linear Complementarity Problem
Bharat Kumar, Deepmala, A.K. Das

Abstract
In this article, we establish a class of new projected type iteration methods based on matrix spitting for solving the linear complementarity problem. Also, we provide a sufficient condition for the convergence analysis when the system matrix is an H + H_{+} -matrix. We show the efficiency of the proposed method by using two numerical examples for different parameters.

Main results

For a given vector

Theorem 3.1

Let

\displaystyle\zeta_{+}=(\mathcal{M}+2I+D_{\mathcal{A}})^{-1}[(\mathcal{N}+I+D_{\mathcal{A}})\zeta_{+}+|(\mathcal{A}-I)\zeta_{+}+\sigma|-\sigma]

(2)

Proof.

We have
\lambda=\zeta_{+}\geq 0
and
\mathcal{A}\lambda+\sigma\geq 0

2.1

\begin{split}(\mathcal{A}\zeta_{+}+\sigma+\zeta_{+})&=|\mathcal{A}\zeta_{+}+\sigma-\zeta_{+}|\\
(I+\mathcal{A})\zeta_{+}&=|(\mathcal{A}-I)\zeta_{+}+\sigma|-\sigma\\
(\mathcal{M}+2I+D_{\mathcal{A}})\zeta_{+}&=(\mathcal{N}+I+D_{\mathcal{A}})\zeta_{+}+|(\mathcal{A}-I)\zeta_{+}+\sigma|-\sigma,\\
\end{split}

the above equation can be rewritten as,

\zeta_{+}=(\mathcal{M}+2I+D_{\mathcal{A}})^{-1}[(\mathcal{N}+I+D_{\mathcal{A}})\zeta_{+}+|(\mathcal{A}-I)\zeta_{+}+\sigma|-\sigma]

(3)

6
Conclusion

In this article, we introduce a class of new projected-type iteration methods based on matrix splitting for solving the linear complementarity problem LCP
(\sigma,\mathcal{A})
. During the iteration process, the large and sparse structure of
\mathcal{A}
is maintained by these iterative forms. Moreover, the sufficient conditions for convergence for
H_{+}
matrix or
P
-matrix are presented. Finally, two numerical examples are provided to demonstrate the effectiveness of the proposed methods.
