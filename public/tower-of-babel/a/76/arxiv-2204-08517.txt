Norm Preserving Extensions of Holomorphic Functions Defined on Varieties in ℂ n \mathbb{C}^{n}
Jim Agler, Łukasz Kosiński, John E. M c Carthy

Abstract
If V V is an analytic set in a pseudoconvex domain Ω \Omega , we show there is always a pseudoconvex domain G ⊆ Ω G\subseteq\Omega that contains V V and has the property that every bounded holomorphic function on V V extends to a bounded holomorphic function on G G with the same norm. We find such a G G for some particular analytic sets. When Ω \Omega is an operhedron we show there is a norm on holomorphic functions on V V that can always be preserved by extensions to Ω \Omega .



1
Motivation

Let
\Omega\subset\mathbb{C}^{n}
be a domain of holomorphy and
V
be a subset. We study when
a bounded, holomorphic function on
V
extends to a bounded holomorphic function with the same norm defined on the whole domain
\Omega
. If
V
is a discrete set, this is an interpolation problem.
In this note we are interested in the case when
V
is a fatter set. It is then natural to assume it has an analytic structure.

The first significant result in this direction was obtained in
[
3
]
, where the simplest non-trivial case
\Omega=\mathbb{D}^{2}
was studied. It was shown using operator theory that if
V\subset\mathbb{D}^{2}
is algebraic, then it must be a retract to have the isometric extension property. The function theory argument of P. Thomas
[
44
]
inspired further research: it turns out that a similar result holds for the
n
-dimensional Euclidean ball and more generally for strictly convex domains and strongly linearly convex domains in
\mathbb{C}^{2}

[
31
]
. In all these cases
V
was shown to be a retract. Some methods developed there remained true for strongly convex and linearly convex domains in
\mathbb{C}^{n}
with arbitrary
n>1
. In particular, it was shown that
V
was always totally geodesic with respect to the Kobayashi metric on
G
— consequently, it had no singularities.

The aim of this paper is to show a result in the opposite direction. Using a totally different approach, we prove that if
V
is an analytic set in a pseudoconvex domain
\Omega
, there is always a pseudoconvex domain
G\subseteq\Omega
that contains
V
and has the property that every bounded holomorphic function on
V
extends to a bounded holomorphic function on
G
with the same norm. We find such a
G
for some analytic sets. These particular examples show that the situation when
G
is a convex domain while
V
has singularities (that are either cusps or obtained as intersections of two curves) can occur. This is intriguing as the crucial role in the strategy of proving extension results has been so far played by the Lempert theory of invariant functions on convex domains.

2
Introduction

If
\Omega
is a domain of holomorphy in
\mathbb{C}^{n}
, then an
analytic set in
\Omega
is a relatively closed set
V
in
\Omega
such that for each point
\lambda\in V
there exist a neighborhood
U
of
\lambda
(
U
is open in
\mathbb{C}^{n}
) and holomorphic functions
f_{1},f_{2},\ldots,f_{m}
on
U
such that

V\cap U=\{\mu\in U\,|\,f_{i}(\mu)=0\text{ for }i=1,2,\ldots,m\}.

We say that a function
f:V\to\mathbb{C}
is
holomorphic on
V
if for each
\lambda\in V
there exist an open set
U\subseteq\mathbb{C}^{n}
containing
\lambda
and a holomorphic function
F
defined on
U
such that
F(\mu)=f(\mu)
for all
\mu\in V\cap U
.

The following fact is one of Henri Cartan’s numerous profound contributions to several complex variables.

Theorem 2.1
.

(Cartan Extension Theorem)
If
\Omega
is a domain of holomorphy,
V
is an analytic set in
\Omega
,
and
f
is a holomorphic function defined on
V,
then there exists a holomorphic function
F
defined on
\Omega
such that

f=F\,|\,V.

This theorem, a consequence of Cartan’s deep work in the theory of analytic sheaves, was originally presented in
[
15
]
. Accessible proofs can be found in the classic texts
[
19
]
and
[
27
]
(Theorem 7.4.8) and also in the more modern text
[
42
]
(Corollary 11.5.2).

This prompts the following definition.

Definition 2.2
.

We say that a pair
(\Omega,V)
is a
Cartan pair
if
\Omega
is a domain of holomorphy in
\mathbb{C}^{n}
for some
n
and
V
is an analytic set in
\Omega
.

In this paper we shall be interested in cases where one can obtain bounds in Cartan’s theorem.
If
(\Omega,V)
is a Cartan pair, say that
(\Omega,V)
has the
bounded extension property
if every bounded holomorphic function on
V
has a bounded extension to
\Omega
. In the case when
\Omega=\mathbb{D}^{n}
, the polydisc, geometric conditions which imply that
(\Omega,V)
has the bounded extension property have been investigated by Herbert Alexander
[
9
]
, Walter Rudin
[
39
]
(Theorem 7.5.1), Edgar Lee Stout
[
40
]
, Guennadi Henkin and Pierre Polyakov
[
26
]
, and Greg Knese
[
30
]
. One lesson to be gleaned from these papers is that the bounded extension property is quite sensitive to the interaction of the boundary of
V
and
\mathbb{T}^{n}
, the distinguished boundary of
\mathbb{D}^{n}
. For example, in
[
9
]
it is shown that a certain class of varieties in
\mathbb{D}^{n}
introduced by Rudin have the bounded extension property if and only if
\partial V\cap\mathbb{T}^{d}=\varnothing
and in
[
30
]
it is shown that if
V
is an algebraic distinguished variety in
\mathbb{D}^{2}
(i.e.,
V
is an algebraic set in
\mathbb{C}^{2}
and
\partial(V\cap\mathbb{D}^{2})\subseteq\mathbb{T}^{2}
) with no singularities on
\mathbb{T}^{2}
, then
(\mathbb{D}^{2},V\cap\mathbb{D}^{2})
has the bounded extension property. Other work on the bounded extension property,
when
\Omega
is assumed to be strictly pseudoconvex (but its boundary is not assumed to be smooth) and
V
is assumed to have the form
V=D\cap\Omega
, where
D
is a relatively closed complex submanifold of a neighborhood of
\Omega^{-}
, can be found in
[
25
]
and
[
1
]
.

A stronger notion was studied in
[
3
]
, namely when an extension can always be found with the same norm. This will be the focus of the current paper.

Definition 2.3
.

If
(\Omega,V)
is a Cartan pair, then we say that
(\Omega,V)
has the
norm preserving extension property
(or simply,
(\Omega,V)
is an
np pair
) if for every bounded holomorphic function
f
on
V
there exists a holomorphic function
F
on
\Omega
such that
F(\mu)=f(\mu)
for all
\mu\in V
and

\sup_{\mu\in\Omega}|F(\mu)|=\sup_{\mu\in V}|f(\mu)|.

We organize our results in this paper around the following three fundamental problems associated with the study of np pairs.

Problem A.
Given a domain of holomorphy
\Omega
, find all analytic sets
V
in
\Omega
such that
(\Omega,V)
is an np pair.

Problem B.
Given a Cartan pair
(\Omega,V)
, find all domains of holomorphy
G
such that
(G,V)
is an np pair.

Problem C.
Given a Cartan pair
(\Omega,V)
, how can one concretely construct a domain of holomorphy
G
such that
(G,V)
is an np pair?

Results

3.1
Problem A

It is obvious that if
V
is a holomorphic retract of
\Omega
(which means there is a holomorphic

which equals the identity on

) then

is a norm preserving homomorphism that gives extensions.
On the bidisk this turns out to be the only way that a reasonably nice set can have the norm-preserving extension property.
We say that

\Omega

\overline{V}
is polynomially convex and
\overline{V}\cap\Omega=V
.

Theorem 3.1
.

(Theorem 1.20 from
[
3
]
) Let
V
be a nonempty relatively polynomially convex subset of
\mathbb{D}^{2}
. Every polynomial has a norm preserving extension to
\mathbb{D}^{2}
if and only if
V
is a holomorphic retract of
\mathbb{D}^{2}
.

Non-trivial retracts of

are of the form
\{(z,\phi(z)):z\in\mathbb{D}\}

or
\{(\phi(z),z):z\in\mathbb{D}\}
for some holomorphic

[
20
]
,
so in particular if

is a relatively polynomially convex subset of
\mathbb{D}^{2}

and

is norm preserving, then

is a manifold.

Both these results hold more generally. In
[
31
]
, it was shown that if
(\Omega,V)
is an np pair and

is relatively polynomially convex, then

must be a retract if any of the following hold:

•

\Omega
is a ball in any dimension;

•

\Omega
is strictly convex in
\mathbb{C}^{2}
;

•

\Omega
is strongly linearly convex in
\mathbb{C}^{2}
with

boundary.

It was also proved that

must at least be a complex submanifold if either

\Omega
is the tridisk
[
32
]
or is strongly linearly convex with

It came as a surprise, then, when the first author, together with Z. Lykova and

is the symmetrized bidisk and

an algebraic subset
[
8
]
; see also
[
14
]
. It was shown that some special

only not retracts, but are not even submanifolds. This result spurred the current investigation.

3.4
Noncommutative np extensions

In Section
10
we study np extensions in the free setting, and
prove in Theorems
10.14
and
10.18
that in some generality,
norm preserving extensions always exist, but the norm that is preserved is not
the supremum of
|f|
evaluated on points in
\mathbb{C}^{d}
, but rather the supremum of
\|f\|
evaluated
on
d
-tuples of matrices.

This allows us to prove a version of Cartan’s Theorem
2.1
.
We restrict
\Omega
to be an operhedron (a slight generalization of a poynomial polyhedron in
\mathbb{C}^{n}
) and

V
to be an algebraic subset, but we gain norm estimates: we show we can always extend a function

on
V
to a function

on
\Omega
with the

, where again the norms are
given by taking the supremum of
\|f(x)\|
(resp.
\|F(y)\|
) where

ranges over
certain

-tuples of matrices associated with

, and
y
ranges over
n
-tuples associated with
\Omega
.
See Theorem
10.19

Although the proof of Theorem
10.19
uses non-commutative function theory, the statement
is just a theorem about extending holomorphic functions from analytic sets to domains in
\mathbb{C}^{n}

4
Existence of Norm Preserving Pairs

Rudin
[
39
]
was the first to exploit the following theorem, essentially a consequence of the Michael Selection Theorem
[
33
]
, to study extensions of holomorphic functions defined on subvarieties on polydiscs.

Theorem 4.1
.

If
X
and
Y
are Frechet spaces and
L:X\to Y
is a continuous linear surjection, then there exists a continuous function
S:Y\to X
satisfying
L(S(y))=y
for all
y\in Y
.

Proof.

The theorem is a special case of the far more general Michael Selection Theorem
[
33
]
. Alternately, for a brief, direct proof consult the proof of Theorem 7.2.3 in
[
39
]
.
∎

If
\Omega
is a domain we let
{\rm Hol}(\Omega)
denote the collection of holomorphic functions on
\Omega
, let
{\rm Hol}^{\infty}(\Omega)
denote the collection of bounded holomorphic functions on
\Omega
, and let
\mathscr{S}(\Omega)
denote the Schur class of
\Omega
, i.e., the subset of
{\rm Hol}^{\infty}(\Omega)
defined by

\mathscr{S}(\Omega)=\{\phi\in{\rm Hol}(\Omega)\,|\,\sup_{\lambda\in\Omega}|\phi(\lambda)|\leq 1\}.

We let
\mathscr{H}(\Omega)
denote the Herglotz class of
\Omega
, namely

\mathscr{H}(\Omega)=\{\phi\in{\rm Hol}(\Omega)\,|\,\forall\lambda\in\Omega,\ \Re\phi(\lambda)\geq 0\}.

In similar fashion, if
(\Omega,V)
is a Cartan pair, then we let
{\rm Hol}(V)
denote the collection of holomorphic functions on
V
, let
{\rm Hol}^{\infty}(V)
denote the collection of bounded holomorphic functions on
V
, and let
\mathscr{S}(V)
and
\mathscr{H}(V)
denote the Schur and Herglotz classes of
V
, i.e., those subsets of
{\rm Hol}(V)
defined by

\displaystyle\mathscr{S}(V)

\displaystyle\ =\

\displaystyle\{\phi\in{\rm Hol}(V)\,|\,\sup_{\lambda\in V}|\phi(\lambda)|\leq 1\}

\displaystyle\mathscr{H}(V)

\displaystyle=

\displaystyle\{\phi\in{\rm Hol}(\Omega)\,|\,\forall\lambda\in V,\ \Re\phi(\lambda)\geq 0\}.

It is well known and elementary that
{\rm Hol}(\Omega)
is a Frechet space when equipped with the topology of uniform convergence on compact subsets of
\Omega
. That
{\rm Hol}(V)
is a Frechet space as well, when so equipped, is a very deep result implicit in the original seminars of Cartan
[
15
]
(see Theorem 7.4.9
[
27
]
). As consequence, we are able to apply Theorem
4.1
to prove the following highly useful technical result.

Lemma 4.2
.

If
(\Omega,V)
is a Cartan pair, then their exists a continuous function
S:{\rm Hol}(V)\to{\rm Hol}(\Omega)
such that
S(f)|V=f
for all
f\in{\rm Hol}(V)

Proof.

By the Cartan Extension Theorem (Theorem 7.4.8 in
[
27
]
), the map
L
defined by
L(F)=F|V
is a continuous linear surjection from
{\rm Hol}(\Omega)
onto
{\rm Hol}(V)
. Therefore, as
{\rm Hol}(\Omega)
and
{\rm Hol}(V)
are Frechet spaces, the desired continuous function
S
exists by Theorem
4.1
.
∎

Another useful lemma is the following. Recall that a TVS is said to be a Montel space if it is barrelled and the Heine-Borel Theorem is true, i.e., a set is compact if and only if it is closed and bounded.

Lemma 4.3
.

If
(\Omega,V)
is a Cartan pair, then
{\rm Hol}(V)
is a Montel space.

Proof.

By
[
42
, Thm. 2.4.2]
,
{\rm Hol}(\Omega)
is a Montel space. By Cartan’s theorem,
{\rm Hol}(V)
is the quotient of
{\rm Hol}(\Omega)
by the
closed subspace of functions vanishing on
V
, and so is a separated quotient.
By
[
42
, Prop. 11.1.1]
a
separated quotient of a Montel space is Montel.
∎

For a final lemma we have the following result.

Lemma 4.4
.

Let
(\Omega,V)
be a Cartan pair, and assume
V
is connected. Fix a point
\lambda_{0}\in V
, and let

\mathscr{S}_{\lambda_{0}}(V)=\{f\in\mathscr{S}(V)\,|\,f(\lambda_{0})=0\}.

Then
(\Omega,V)
is norm preserving if and only if each
f\in\mathscr{S}_{\lambda_{0}}(V)
has an extension to an element
F\in\mathscr{S}(\Omega)
.

Proof.

Let
f\in\mathscr{S}(V)
. If
|f(\lambda_{0})|=1
, then by the Maximum Principle (
[
19
]
Theorem 16, Chapter III)
f
is constant on
V
and trivially has a norm preserving extension to
\Omega
. Otherwise,
|f(\lambda_{0})|<1
and there exists a Möbius transformation
m
of
\mathbb{D}
such that
(m\circ f)(\lambda_{0})=0
. As
h=m\circ f\in\mathscr{S}(V)
, the assumption of the lemma implies that there exists
H\in\mathscr{S}(\Omega)
such that
H|V=h
. But then if we define
F=m^{-1}\circ H
,
F\in\mathscr{S}(\Omega)
and
F|V=f
.
∎

Theorem 4.5
.

If
(\Omega,V)
is a Cartan pair, then there exists
G\subseteq\Omega
such that
(G,V)
is a norm preserving Cartan pair if and only if
V
is connected.

Proof.

If
V
is not connected, there is a non-trivial characteristic function in
{\rm Hol}^{\infty}(V)
.
By the maximum principle, any extension of this to a pseudoconvex domain
G
must have a larger
norm.

Conversely, assume
V
is connected.
Fix
\lambda_{0}\in V
and let
S
be as in Lemma
4.2
. For each
f\in\mathscr{S}_{\lambda_{0}}(V)
define
\Omega_{f}
in
\Omega
by

\Omega_{f}=\{\lambda\in\Omega\,|\,|S(f)(\lambda)|<1\}

and let
G
be the connected component of

\Big(\bigcap_{f\in\mathscr{S}_{\lambda_{0}}(V)}\Omega_{f}\Big)^{\circ}.

containing
V
.

We first observe that, as every connected component of each
\Omega_{f}
is a domain of holomorphy

[
28
, Prop. 4.1.7]
, it follows that
G
is a domain of holomorphy
[
38
, Cor. II.3.19]
.
Hence,
(G,V)
will be a Cartan pair if

V\subseteq G
. Assume to the contrary that
\mu\in V\setminus G
. Then for each positive integer
n
, there exist
\mu_{n}\in B(\mu,1/n)\cap\Omega
and
f_{n}\in\mathscr{S}_{\lambda_{0}}(V)
with
|S(f_{n})(\mu_{n})|\geq 1
. As Lemma
4.3
implies that
\mathscr{S}_{\lambda_{0}}(V)
is a compact subset of
{\rm Hol}(V)
, there exists a subsequence
\{f_{n_{k}}\}
and
f\in\mathscr{S}_{\lambda_{0}}(V)
such that
f_{n_{k}}\to f
in
{\rm Hol}(V)
as
k\to\infty
. It follows by the continuity of
S
, that
|f(\mu)|\geq 1
. But as
f\in\mathscr{S}_{\lambda_{0}}
, this contradicts the Maximum Principle.

Now observe that by construction,

f\in\mathscr{S}_{\lambda_{0}}(V)\implies\sup_{\lambda\in G}|Sf(\lambda)|\leq 1.

Hence, if
f\in\mathscr{S}_{\lambda_{0}}(V)
and

\sup_{\lambda\in V}|f(\lambda)|=\rho\not=0,

then, as
\rho^{-1}f\in\mathscr{S}_{\lambda_{0}}(V)
,

\sup_{\lambda\in G}|S(\rho^{-1}f)(\lambda)|\leq 1,

which implies that
\rho S(\rho^{-1}f)
is a norm preserving extension of
f
to
G
. Consequently, Lemma
4.4
implies that
(G,V)
is norm preserving.
∎

Remark 4.6
.

Some authors, such as Hörmander
[
27
]
, do not require that a domain of holomorphy be connected; in this case the connectivity of
V
can then also be dropped.
Indeed, we just need to find disjoint pseudoconvex subdomains of
\Omega
each of which contains at most one
component of
V
. To do this, let
\{V_{j}:j=1,\dots\}
be an enumeration of the at most countably many components of
V
. Let
f
be the function that is
0
on
V_{1}
and
1
on
each other
V_{j}
.
Since
(\Omega,V)
is a Cartan pair, there is a holomorphic
F
on
\Omega
extending
f
.
Let
\Omega_{1}=\{\lambda\in\Omega:|F(\lambda)|<1/2\}
. Let
D=\{\lambda\in\Omega:|F(\lambda)-1|<1/2\}
.
Apply Theorem
4.5
to
(\Omega_{1},V_{1})
to get a norm preserving pair
(G_{1},V_{1})

with
G_{1}\subseteq\Omega_{1}
. Now replace
(\Omega,V)
with
(D,\cup_{j\geq 2}V_{j})
and continue by induction.

Problems B and C for Two Crossed Discs

and

\tau_{2}z&\mbox{if }\lambda=(0,z)\in D_{2}\end{array}\right.

and

h_{\tau}(\lambda)=\left\{\begin{array}[]{ll}\frac{1+\tau_{1}z}{1-\tau_{1}z}&\mbox{if }\lambda=(z,0)\in D_{1}\\
\\
\frac{1+\tau_{2}z}{1-\tau_{2}z}&\mbox{if }\lambda=(0,z)\in D_{2}.\end{array}\right.

Since the map

C:z\mapsto\frac{1+z}{1-z}

is a conformal map from the unit disk onto the right-half plane, it is immediate
that one can extend the function
f
from
\mathscr{S}(T)
to
\mathscr{S}(G)
if and only if
one can extend
C\circ f
from
\mathscr{H}(T)
to
\mathscr{H}(G)
.

Lemma 5.3
.

If
(G,T)
is a Cartan pair, then
(G,T)
is norm preserving if and only if for each
\tau\in\mathbb{T}^{2}
, there exists
B_{\tau}\in\mathscr{S}(G)
such that
B_{\tau}|T=b_{\tau}
.

Proof.

First note that necessity is obvious. To show sufficiency assume that for each
\tau\in\mathbb{T}^{2}
, there exists
B_{\tau}\in\mathscr{S}(G)
such that
B_{\tau}|T=b_{\tau}
, or equivalently
that

\forall_{\tau\in\mathbb{T}^{2}}\ \ \exists_{H_{\tau}\in\mathscr{H}(G)}\ \ H_{\tau}|T=h_{\tau}.

To prove that
(G,T)
is a norm preserving pair, by Lemma
4.4
it suffices to show that if
h\in\mathscr{H}_{(0,0)}(T)
then there exists
H\in\mathscr{H}(G)
such that
H|T=h
.

Assume that
h\in\mathscr{H}_{(0,0)}(T)
. By Lemma
5.1
, there exist
h_{1},h_{2}\in\mathscr{H}_{0}(\mathbb{D})
such that

h(\lambda)=\left\{\begin{array}[]{ll}h_{1}(z)&\mbox{if }\lambda=(z,0)\in D_{1}\\
\\
h_{2}(z)&\mbox{if }\lambda=(0,z)\in D_{2}.\end{array}\right.

By the Herglotz Representation Theorem, there exist probability measures
\mu_{1},\mu_{2}
on
\mathbb{T}
such that

h_{1}(z)=\int\frac{1+\tau z}{1-\tau z}\ d\mu_{1}(\tau)\qquad\text{ and }\qquad h_{2}(z)=\int\frac{1+\tau z}{1-\tau z}\ d\mu_{2}(\tau).

Let
\mu=\mu_{1}\times\mu_{2}
(so that
\mu
is a probability measure on
\mathbb{T}^{2}
).
First, suppose that the map
\tau\mapsto H_{\tau}
is measurable.
Then we define
H
by the formula

H(\lambda)=\int_{\tau\in\mathbb{T}^{2}}H_{\tau}(\lambda)\ d\mu(\tau);

Clearly, as
\mu
is a probability measure and
H_{\tau}\in\mathscr{H}(G)
for all
\tau\in\mathbb{T}^{2}
,
H\in\mathscr{H}(G)
.
If
\lambda=(z,0)\in D_{1}
,

\displaystyle H(\lambda)

\displaystyle=\int_{\tau\in\mathbb{T}^{2}}H_{\tau}(\lambda)\ d\mu(\tau)

\displaystyle=\int_{\tau\in\mathbb{T}^{2}}h_{\tau}(\lambda)\ d\mu(\tau)

\displaystyle=\int_{\tau_{2}\in\mathbb{T}}\Big(\int_{\tau_{1}\in\mathbb{T}}\frac{1+\tau_{1}z}{1-\tau_{1}z}\ d\mu_{1}(\tau_{1})\Big)\ d\mu_{2}(\tau_{2})

\displaystyle=h_{1}(z)

\displaystyle=h(\lambda).

Likewise, if
\lambda=(0,z)\in D_{2}
,
H(\lambda)=h(\lambda)
.
Consequently,
H\in\mathscr{H}(G)
and
H|T=h
, as was to be proved.

Now, let us drop the measurability hypothesis; we shall use an approximation argument to get round
the difficulty.
Let
K_{n}
be a compact exhaustion of
G
. It thus follows
(use e.g. a Montel type argument) that there is a constant
\delta_{n}>0
so that

\|B_{\tau}\|_{K_{n}}\ \leq\ 1-\frac{1}{\delta_{n}}\quad\forall\ \tau\in\mathbb{T}^{2}.

Let

M_{n}\ :=\ \sup\{\|\lambda\|_{\infty}:\lambda\in K_{n}\}\ <\infty.

Choose a finite set of points
F_{n}
in
\mathbb{T}^{2}
so that every point in

\mathbb{T}^{2}
is less than
\delta_{n}/M_{n}
away from some point of
F_{n}
in the
\ell^{1}
norm. Let

\alpha:\mathbb{T}^{2}\to F_{n}
be a Borel map such that
\|\alpha(\tau)-\tau\|_{\ell^{1}}<\delta_{n}/M_{n}
for all
\tau
.
Write

B_{\tau}(\lambda)\ =\ \lambda_{1}\tau_{1}+\lambda_{2}\tau_{2}+\lambda_{1}\lambda_{2}\Gamma_{\tau}(\lambda).

Define

B^{(n)}_{\tau}(\lambda)\ =\ \lambda_{1}\tau_{1}+\lambda_{2}\tau_{2}+\lambda_{1}\lambda_{2}\Gamma_{\alpha(\tau)}(\lambda).

Then the map
\tau\mapsto B^{(n)}_{\tau}
is Borel, and as

|B^{(n)}_{\tau}(\lambda)-B_{\alpha(\tau)}(\lambda)|\ \leq\ M_{n}\|\tau-\alpha(\tau)\|_{\ell^{1}}\|\lambda\|_{\ell^{\infty}},

we have that
|B^{(n)}_{\tau}|<1
on
K_{n}
.
So if we define

H^{(n)}_{\tau}=C\circ B^{(n)}_{\tau}
,
then
H^{(n)}_{\tau}
is a holomorphic map from
K_{n}
to the right-half plane.
Let

H^{(n)}(\lambda)=\int_{\tau\in\mathbb{T}^{2}}H^{(n)}_{\tau}(\lambda)\ d\mu(\tau).

The sequence
H^{(n)}
will have a subsequence that converges uniformly on
compact subsets of
G
to some function
H
in
\mathscr{H}(G)
; this will be our
desired extension of
h
.
∎

For
v
a unit vector in
\mathbb{C}^{2}
and
G
a neighborhood of the origin in
\mathbb{C}^{2}
let

R_{v}=\sup\ \{r\,|\,\forall_{z\in\mathbb{C}}\ \ |z|<r\implies zv\in G\}.

Lemma 5.4
.

Assume that
G
a neighborhood of the origin in
\mathbb{C}^{2}
and
v
is a unit vector in
\mathbb{C}^{2}
. If
(G,T)
is np, then
R_{v}\leq\frac{1}{|v_{1}|+|v_{2}|}
.

Proof.

By Lemma
5.3
, for each
\tau\in\mathbb{T}
, there exists
B_{\tau}\in\mathscr{S}(G)
such that
B_{\tau}|T=b_{\tau}
. Evidently, we have that

\frac{\partial B_{\tau}}{\partial\lambda_{1}}(0,0)=\tau_{1}\qquad\text{ and }\qquad\frac{\partial B_{\tau}}{\partial\lambda_{2}}(0,0)=\tau_{2}.

Hence, by the chain rule, if we define an analytic function
f
on
\mathbb{D}
by the formula

f^{\prime}(0)=(\tau_{1}v_{1}+\tau_{2}v_{2})R_{v}.

Hence, by Schwarz’s Lemma,

|\tau_{1}v_{1}+\tau_{2}v_{2}|R_{v}\leq 1.

As
\tau\in\mathbb{T}^{2}
is arbitrary, the result follows.
∎

Theorem 5.6

6
Linear isometric extension operators

In
[
39
, Sec. 7.5]
Rudin asks if
(\Omega,V)
is a Cartan pair with the
bounded extension property,
is there a bounded linear extension operator? In this section we show that the answer is no in the case of norm preserving extensions.

We shall say that a Cartan pair
(\Omega,V)
has the
linear norm preserving extension property

if there is a linear isometry
E:{\rm Hol}^{\infty}(V)\to{\rm Hol}^{\infty}(\Omega)
such that
(Ef)(\lambda)=f(\lambda)

for every
\lambda
in
V
.

We show in Theorem
6.1
that
(\Delta,T)
does not have the linear norm preserving extension property.
There are Cartan pairs
(G,T)
that do have the linear norm preserving
extension property.

Let

m_{a}(z)\ =\ \frac{a-z}{1-\bar{a}z}

be the Möbius map swapping
a
and
0
.
Whenever
f_{1},f_{2}
are in
{\rm Hol}(\mathbb{D})
and

f_{1}(0)=f_{2}(0)
, let

\Psi_{f_{1},f_{2}}
be the function in
{\rm Hol}(T)
given by the right-hand side of (
5.2
).

Theorem 6.1
.

The pair
(\Delta,T)
does not have the linear
norm preserving extension property.

Proof.

Suppose there were an isometric linear extension operator
E
.
Let the extensions of
\Psi_{z,0}
and
\Psi_{0,z}
be given by

\displaystyle E(\Psi_{z,0})(\lambda)

\displaystyle\ =\

\displaystyle\lambda_{1}+\lambda_{1}\lambda_{2}f_{1}(\lambda)

\displaystyle E(\Psi_{0,z})(\lambda)

\displaystyle\ =\

\displaystyle\lambda_{2}+\lambda_{1}\lambda_{2}g_{1}(\lambda)

where
f_{1},g_{1}
are holomorphic functions on
\Delta
.
For unimodular
\tau_{1}
and
\tau_{2}
we get, by linearity of
E
, that

E\circ\Psi_{\tau_{1}z,\tau_{2}z}:\lambda\mapsto\tau_{1}\lambda_{1}+\tau_{2}\lambda_{2}+\lambda_{1}\lambda_{2}(\tau_{1}f_{1}(\lambda)+\tau_{2}g_{1}(\lambda))

maps
\Delta
into the unit disc. For
t\in[0,1]

\psi_{t}:\zeta\mapsto E(\Psi_{\tau_{1}z_{1},\tau_{2}z_{2}})(\bar{\tau}_{1}t\zeta,\bar{\tau}_{2}(1-t)\zeta)

is thus a well defined holomorphic
selfmap of the unit disc such that
\psi_{t}(0)=0
and
\psi^{\prime}_{t}(0)=1
. Therefore,
\psi_{t}(\zeta)=\zeta
for every
\zeta\in\mathbb{D}
and
t\in[0,1]
.
So
\tau_{1}f_{1}+\tau_{2}g_{1}\equiv 0
on the
three real dimensional set
\{(\bar{\tau}_{1}t\zeta,\bar{\tau}_{2}(1-t)\zeta):\ \zeta\in\mathbb{D},\ t\in[0,1]\}.
Consequently
\tau_{1}f_{1}+\tau_{2}g_{1}=0
, and as this is true for all choices of

\tau
, we get
f_{1}=g_{1}=0
.
By the maximum principle,
E(1)=1
, so
E
is the identity on all affine polynomials.

Now let us consider
\Psi_{m_{a}(z),m_{a}(\omega z)}
, where
\omega\in\mathbb{T}
, and
a\in\mathbb{D}\setminus\{0\}
.
Observe that

E(\Psi_{m_{a}(z),m_{a}(\omega z)})(\lambda)=a-(1-|a|^{2})(\lambda_{1}+\omega\lambda_{2})+\lambda_{1}\lambda_{2}h(\lambda),

for some
h\in{\rm Hol}(\Delta)
.

It follows from the Schwarz lemma that the function

\zeta\mapsto E(\Psi_{m_{a}(z),m_{a}(\omega z)})(\zeta/2,\bar{\omega}\zeta/2)

is equal to the Möbius function
m_{a}(\zeta)
.
It follows that the mappings
E(\Psi_{m_{a}(z),m_{a}(\omega z)})(\lambda)
and
m_{a}(\lambda_{1}+\omega\lambda_{2})
coincide on
\lambda_{1}=0
,
\lambda_{2}=0
and
\lambda_{2}=\bar{\omega}\lambda_{1}
; in particular

E(\Psi_{m_{a}(z),m_{a}(\omega z)})(\lambda)=m_{a}(\lambda_{1}+\omega\lambda_{2})+\lambda_{1}\lambda_{2}(\bar{\omega}\lambda_{1}-\lambda_{2})F_{\omega}(\lambda_{1},\lambda_{2}).

(6.2)

To get a contradiction we shall compute
E(\Psi_{m_{a}(z),m_{a}(\omega z)})
using a Taylor expansion of
m_{a}
. Let
f_{n},g_{n}
be functions in
{\rm Hol}(\Delta)
such that

\displaystyle E(\Psi_{z^{n},0})(\lambda)

\displaystyle\ =

\displaystyle\lambda_{1}^{n}+\lambda_{1}\lambda_{2}f_{n}(z)

\displaystyle E(\Psi_{0,z^{n}})(\lambda)

\displaystyle=

\displaystyle\lambda_{2}^{n}+\lambda_{1}\lambda_{2}g_{n}(\lambda).

Write
m_{a}(z)=\sum_{n}a_{n}z^{n}
, where
a_{0}=a
and
a_{n}=-(1-|a|^{2})\bar{a}^{n-1}
for
n\geq 1
.
Then

\displaystyle E(\Psi_{m_{a}(z),m_{a}(\omega z)})(\lambda)

\displaystyle\ =\

\displaystyle E(\Psi_{m_{a},0})(\lambda)+E(\Psi_{0,m_{a}(\omega z)})(\lambda)-a

\displaystyle=

\displaystyle a-(1-|a|^{2})(\lambda_{1}+\omega\lambda_{2})+\sum_{n\geq 2}a_{n}(\lambda_{1}^{n}+\omega^{n}\lambda_{2}^{n})+

\displaystyle\quad\lambda_{1}\lambda_{2}\sum_{n\geq 2}a_{n}(f_{n}(\lambda)+\omega^{n}g_{n}(\lambda))

\displaystyle=

\displaystyle m_{a}(\lambda_{1}+\omega\lambda_{2})+2\omega\bar{a}(1-|a|^{2})\lambda_{1}\lambda_{2}+

\displaystyle\quad\lambda_{1}\lambda_{2}\sum_{n\geq 2}a_{n}f_{n}(\lambda)+\lambda_{1}\lambda_{2}\sum_{n\geq 2}\omega^{n}a_{n}g_{n}(\lambda)+O(||\lambda||^{3}).

Comparing the last equation with (
6.2
), we see that the coefficients of
\lambda_{1}\lambda_{2}

must agree, which yields

0\ =\ 2\omega\bar{a}(1-|a|^{2})+\sum_{n\geq 2}a_{n}(f_{n}(0)+\omega^{n}g_{n}(0)).

(6.3)

As (
6.3
) holds for all
\omega\in\mathbb{T}
, we get
a=0
, a contradiction.
∎

By Theorem
5.5

(\Delta,T)
does have the norm preserving extension
property. One can also write down a simple formula to see this.
If
f
is given by (
5.2
) and has norm one and is not constant, let
a=f(0)
.
Then the function

F(\lambda_{1},\lambda_{2})\ =\ m_{a}\left(m_{a}(f(\lambda_{1},0)+m_{a}(f(0,\lambda_{2})\right)

is a norm-preserving extension of

.

The singularity in

does not prevent the existence of np pairs

Theorem 6.4
.

There is a domain of holomorphy

containing
T
so that

Proof.

Define a linear extension operator

Define
G

[
38

,
G
is a domain of holomorphy, provided it is non-empty. So we need to prove that

.
Define

H\ =\ \{\frac{|\lambda_{2}|}{1-|\lambda_{2}|}<\frac{1}{2}\frac{1-|\lambda_{1}|}{1+|\lambda_{1}|}\}\cup\{\frac{|\lambda_{1}|}{1-|\lambda_{1}|}<\frac{1}{2}\frac{1-|\lambda_{2}|}{1+|\lambda_{2}|}\}.

7
The Representation of Even Schur Functions on the Bidisc

For use in Section
8
, we derive a model and a representation
for even Schur functions on the bidisc.

A
decomposed Hilbert space

is a Hilbert space
\mathcal{M}
together with two orthogonal subspaces

\mathcal{M}_{1}
and
\mathcal{M}_{2}
satisfying
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
.
By
[
2
]
, a function
\phi:\mathbb{D}^{2}\to\mathbb{C}
is in
\mathscr{S}(\mathbb{D}^{2})
if
and only if there exist a separable decomposed Hilbert space
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
,
and a
function
v:\mathbb{D}^{2}\to\mathcal{M}
such that

1-\overline{\phi(\mu)}\phi(\lambda)=\langle(1-\mu^{*}\lambda)v_{\lambda},v_{\mu}\rangle.

(7.1)

In (
7.1
) we write
v_{\lambda}
for
v(\lambda)
, and the operator
\lambda:\mathcal{M}\to\mathcal{M}

is defined by

\lambda\ =\ \lambda_{1}I_{\mathcal{M}_{1}}\oplus\lambda_{2}I_{\mathcal{M}_{2}}.

(7.2)

We call (
7.1
) a
model
for
\phi
.

We say
\phi\in{\rm Hol}(\mathbb{D}^{2})
is
even
if

\forall_{\lambda\in\mathbb{D}^{2}}\ \ \phi(-\lambda)=\phi(\lambda).

We let
{\rm Hol}_{\,\rm even}\ (\mathbb{D}^{2})
denote the even holomorphic functions on
\mathbb{D}^{2}
,
and
\mathscr{S}_{e}(\mathbb{D}^{2})
the ones in Schur class.

Proposition 7.3
.

Let
\phi:\mathbb{D}^{2}\to\mathbb{C}
. Then
\phi
is in
\mathscr{S}_{e}(\mathbb{D}^{2})
if and only if there exist a separable decomposed Hilbert space
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
, a unitary operator
U
acting on
\mathcal{M}
, and
an even
function
u:\mathbb{D}^{2}\to\mathcal{M},\lambda\mapsto u_{\lambda},
such that

1-\overline{\phi(\mu)}\phi(\lambda)=\langle(1-(\mu U\mu)^{*}(\lambda U\lambda))u_{\lambda},u_{\mu}\rangle.

(7.4)

Proof.

Note that
if (
7.4
) holds, then it
defines
\phi

(up to a unimodular constant), and it is clear that
\phi
is even and bounded by
1
in modulus.
So to see it is in
\mathscr{S}(\mathbb{D}^{2})
, we must show it is holomorphic.
This follows from the argument in the proof of
[
7
, Proposition 4.26]
, which shows
that
\lambda\mapsto u_{\lambda}
is holomorphic.

Conversely, suppose that
\phi
is an even function in
\mathscr{S}(\mathbb{D}^{2})
. Then there is some
model so that (
7.1
) holds. Define

\displaystyle v_{e}(\lambda)

\displaystyle\ =\

\displaystyle\frac{1}{2}(v(\lambda)+v(-\lambda))

\displaystyle v_{o}(\lambda)

\displaystyle=

\displaystyle\frac{1}{2}(v(\lambda)-v(-\lambda))

A lurking isometry argument (see
[
7
, Sec. 2.4]
) shows that there is a partial isometry
W:\mathbb{C}\oplus\mathcal{M}\oplus\mathcal{M}\to\mathbb{C}\oplus\mathcal{M}\oplus\mathcal{M}

satisfying

W:\begin{pmatrix}1\\
\lambda v_{o}(\lambda)\\
\lambda v_{e}(\lambda)\end{pmatrix}\ \mapsto\ \begin{pmatrix}\phi(\lambda)\\
v_{e}(\lambda)\\
v_{o}(\lambda)\end{pmatrix}

(7.5)

Expanding both sides of (
7.5
) in powers of
\lambda
, we see that
W
has to map the odd part to the odd part, so

W\begin{pmatrix}0\\
0\\
\lambda v_{e}(\lambda))\end{pmatrix}=\begin{pmatrix}0\\
0\\
v_{o}(\lambda)\end{pmatrix}.

(7.6)

Thus we see that
U(\lambda v_{e}(\lambda))=v_{o}(\lambda),
for some partial isometry
U:\mathcal{M}\to\mathcal{M}
.
By adding a separable infinite dimensional Hilbert space to
\mathcal{M}
if necessary, one can additionally assume that the
partial isometry
U
is a unitary.

Define
u_{\lambda}=v_{e}(\lambda)
. Substituting this into (
7.5
) and using (
7.6
), we get

W:\begin{pmatrix}1\\
\lambda U\lambda u_{\lambda}\\
\lambda u_{\lambda}\end{pmatrix}\ \mapsto\ \begin{pmatrix}\phi(\lambda)\\
u_{\lambda}\\
U\lambda u_{\lambda}\end{pmatrix}

(7.7)

Again we expand (
7.7
) into odd and even parts, and get

W:\begin{pmatrix}1\\
\lambda U\lambda u_{\lambda}\\
0\end{pmatrix}\ \mapsto\ \begin{pmatrix}\phi(\lambda)\\
u_{\lambda}\\
0\end{pmatrix}

(7.8)

Since
W
is a partial isometry, we get that for any
\lambda,\mu
in
\mathbb{D}^{2}
we have

\Big\langle\begin{pmatrix}1\\
\lambda U\lambda u_{\lambda}\\
0\end{pmatrix},\begin{pmatrix}1\\
\mu U\mu u_{\mu}\\
0\end{pmatrix}\Big\rangle_{\mathbb{C}\oplus\mathcal{M}\oplus\mathcal{M}}\ =\ \Big\langle\begin{pmatrix}\phi(\lambda)\\
u_{\lambda}\\
0\end{pmatrix},\begin{pmatrix}\phi(\mu)\\
u_{\mu}\\
0\end{pmatrix}\Big\rangle_{\mathbb{C}\oplus\mathcal{M}\oplus\mathcal{M}},

which rearranges into (
7.4
).
∎

Let
\mathcal{M}
be a Hilbert space. We define
\rm ball\,[\mathcal{B}(\mathcal{M})]
by

\rm ball\,[\mathcal{B}(\mathcal{M})]=\{X\in\mathcal{B}(\mathcal{M})\,|\,\|X\|<1\}.

We let
\mathscr{R}(\mathcal{M})
denote the set of 4-tuples
\xi=(a,\beta,\gamma,D)
such that
a\in\mathbb{C}
,
\beta\in\mathcal{M}
,
\gamma\in\mathcal{M}
,
D\in\mathcal{B}(\mathcal{M})
, and the block operator
L_{\xi}\in\mathcal{B}(\mathbb{C}\oplus\mathcal{M})
defined by

L_{\xi}=\begin{bmatrix}a&1\otimes\beta\\
\gamma\otimes 1&D\end{bmatrix}

(7.9)

is unitary.
If
\xi\in\mathscr{R}(\mathcal{M})
, then we may define a function
F_{\xi}
on
\rm ball\,[\mathcal{B}(\mathcal{M})]
by the formula

F_{\xi}(X)=a+\langle X(1-DX)^{-1}\gamma,\beta\rangle_{\mathcal{M}},\qquad X\in\rm ball\,[\mathcal{B}(\mathcal{M})]

(7.10)

Proposition 7.11
.

\phi\in\mathscr{S}_{e}(\mathbb{D}^{2})
if and only if there exists a separable decomposed Hilbert space

\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
, a unitary
U\in\mathcal{B}(\mathcal{M})
, and
\xi\in\mathscr{R}(\mathcal{M})
such that

\forall_{\lambda\in\mathbb{D}^{2}}\ \ \phi(\lambda)=F_{\xi}(\lambda U\lambda).

Proof.

This follows from Proposition
7.3
,
where we write
U
as
L_{\xi}
in (
7.9
), and then use (
7.8
) to solve for

\phi
.
∎

Propositions
7.3
and
7.11
easily generalize to Schur functions
\phi
that
satisfy
\phi(\omega\lambda)=\phi(\lambda)
, where
\omega
is a primitive
n^{\rm th}
root of unity.
One just replaces
\lambda U\lambda
by
\lambda(U\lambda)^{n-1}
.

8
The Representation of Schur Functions on
{\mathcal{V}}

We define a variety in
\mathbb{D}^{3}
by

{\mathcal{V}}=\{z\in\mathbb{D}^{3}\,|\,z_{3}^{2}=z_{1}z_{2}\}

(8.1)

and let
\pi:\mathbb{D}^{2}\to{\mathcal{V}}
denote the surjective map defined by

\pi(\lambda)=(\lambda_{1}^{2},\lambda_{2}^{2},\lambda_{1}\lambda_{2}).

The map
\pi
is a two-to-one branched cover of
\mathbb{D}^{2}
over
{\mathcal{V}}
.
The key observation is that

\Phi\in\mathscr{S}({\mathcal{V}})\iff\Phi\circ\pi\in\mathscr{S}_{e}(\mathbb{D}^{2}).

(8.2)

For a separable decomposed Hilbert space
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
and a unitary operator
U\in\mathcal{B}(\mathcal{M})
we may decompose
U
,

U=\begin{bmatrix}A&B\\
C&D\end{bmatrix},

where
A:\mathcal{M}_{1}\to\mathcal{M}_{1}
,
B:\mathcal{M}_{2}\to\mathcal{M}_{1}
,
C:\mathcal{M}_{1}\to\mathcal{M}_{2}
, and
D:\mathcal{M}_{2}\to\mathcal{M}_{2}
. Furthermore, for each
z\in\mathbb{C}^{3}
, we may define an operator
z_{U}
by the formula

z_{U}=\begin{bmatrix}Az_{1}&Bz_{3}\\
Cz_{3}&Dz_{2}\end{bmatrix},\qquad z\in\mathbb{C}^{3}.

We then have that if we view
\lambda
as an operator on
\mathcal{M}
(as in (
7.2
)) and
z=\pi(\lambda)
, then

\lambda U\lambda=\begin{bmatrix}A\lambda_{1}^{2}&B\lambda_{1}\lambda_{2}\\
C\lambda_{1}\lambda_{2}&D\lambda_{2}^{2}\end{bmatrix}=\begin{bmatrix}Az_{1}&Bz_{3}\\
Cz_{3}&Dz_{2}\end{bmatrix}=z_{U}

Consequently, using Propositions
7.3
and
7.11
we obtain the following description of the Schur class of
{\mathcal{V}}
.

Proposition 8.3
.

\Phi\in\mathscr{S}({\mathcal{V}})
if and only if there exists a decomposed Hilbert space
\mathcal{M}
, a unitary
U\in\mathcal{B}(\mathcal{M})
, and
\xi\in\mathscr{R}(\mathcal{M})
such that

\forall_{\lambda\in\mathbb{D}^{2}}\ \ \Phi(\lambda)=F_{\xi}(z_{U}).

Let
\mathscr{U}
denote the collection of ordered pairs
(\mathcal{M},U)
such that
\mathcal{M}
is a separable decomposed Hilbert space and
U
is a unitary operator acting on
\mathcal{M}
and define
{\mathcal{G}}\subseteq\mathbb{C}^{3}
by ordaining that
z\in{\mathcal{G}}
precisely when

\|z_{U}\|<1

for all separable decomposed Hilbert spaces
\mathcal{M}
and all unitary
U
acting on
\mathcal{M}
. Thus,

z\in{\mathcal{G}}\iff\forall_{(\mathcal{M},U)\in\mathscr{U}}\ \ \|z_{U}\|<1.

(8.4)

It is clear from the definition that
{\mathcal{G}}
is convex, and it
follows from
Lemma
9.21

that
{\mathcal{G}}
is open.

Proposition 8.5
.

If
\Phi\in\mathscr{S}({\mathcal{V}})
, then there exists
\Phi^{\sim}\in\mathscr{S}({\mathcal{G}})
such that
\Phi=\Phi^{\sim}|{\mathcal{V}}
.

Proof.

Since
\Phi\in\mathscr{S}({\mathcal{V}})
it has a realization as in Proposition
8.5
.
Define
\Phi^{\sim}
by
\Phi^{\sim}(z)=F_{\xi}(z_{U}).

It is immediate from (
7.10
) that this defines an analytic function;
to show it is in the Schur class requires a calculation. See eg
[
7
, Sec. 3.9]
.

∎

9
The Envelope

In this section we compute
{\mathcal{G}}
defined by (
8.4
). For
z\in\mathbb{C}^{3}
, define
\|z\|_{\mathscr{U}}
by

\|z\|_{\mathscr{U}}=\sup_{(\mathcal{M},U)\in\mathscr{U}}\|z_{U}\|.

Lemma 9.1
.

If
z\in\mathbb{C}^{3}
, then

z\in{\mathcal{G}}\iff\|z\|_{\mathscr{U}}<1.

Proof.

The lemma will follow if it can be shown that when
z\in\mathbb{C}^{3}
, there exists
(\mathcal{M}^{\sim},U^{\sim})\in\mathscr{U}
such that

\|z_{U^{\sim}}\|=\sup_{(\mathcal{M},U)\in\mathscr{U}}\|z_{U}\|.

(9.2)

Choose a sequence
\{(\mathcal{M}^{(n)},U^{(n)})\}
in
\mathscr{U}
such that

\|z_{U^{(n)}}\|\to\sup_{(\mathcal{M},U)\in\mathscr{U}}\|z_{U}\|\ \ \text{ as }\ \ n\to\infty.

Let

\mathcal{M}^{\sim}=\bigoplus_{n}\mathcal{M}^{(n)}\qquad\text{ and }\qquad U^{\sim}=\bigoplus_{n}U^{(n)}.

if we decompose
\mathcal{M}^{\sim}
,

\mathcal{M}^{\sim}=\Big(\bigoplus_{n}(\mathcal{M}_{1}^{(n)}\oplus 0)\Big)\ \oplus\ \Big(\bigoplus_{n}(0\oplus\mathcal{M}_{2}^{(n)})\Big),

then
(\mathcal{M}^{\sim},U^{\sim})\in\mathscr{U}
, and as

z_{U^{\sim}}\ \cong\ \ \bigoplus_{n}z_{U^{(n)}},

(
9.2
) holds.
∎

We let
\mathscr{C}
denote the collection of ordered pairs
(\mathcal{M},T)
where
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
is a decomposed Hilbert space and
T
is a contraction acting on
\mathcal{M}
. If
(\mathcal{M},T)\in\mathscr{C}
, we may decompose
T
,

T=\begin{bmatrix}A&B\\
C&D\end{bmatrix}

(9.3)

and then for
z\in\mathbb{C}^{3}
define
z_{T}\in\mathcal{B}(\mathcal{M})
by

z_{T}=\begin{bmatrix}Az_{1}&Bz_{3}\\
Cz_{3}&Dz_{2}\end{bmatrix}

We let
\mathscr{C}_{2}
denote the collection of ordered pairs
(\mathcal{M},T)\in\mathscr{C}
satisfying
\dim\mathcal{M}_{1}=\dim\mathcal{M}_{2}=2
.

Lemma 9.4
.

If
z\in\mathbb{C}^{3}
, then

\|z\|_{\mathscr{U}}\geq\sup_{(\mathcal{M},T)\in\mathscr{C}_{2}}\|z_{T}\|.

Proof.

Fix
(\mathcal{M},T)\in\mathscr{C}_{2}
and assume that
T
is represented as in (
9.3
) with respect to the decomposition
\mathcal{M}=\mathcal{M}_{1}\oplus\mathcal{M}_{2}
. By the Sz.-Nagy Dilation Theorem
[
41
]
there exists a decomposed Hilbert space

\mathcal{H}=\mathcal{H}_{0}\oplus\mathcal{M}_{1}\oplus\mathcal{M}_{2}\oplus\mathcal{H}_{1}

on which the block operator
U
defined on
\mathcal{H}
by

U=\begin{bmatrix}X_{11}&X_{12}&X_{13}&X_{14}\\
0&A&B&X_{24}\\
0&C&D&X_{34}\\
0&0&0&X_{44}\end{bmatrix}

is unitary.
If we decompose
\mathcal{H}
as

\mathcal{H}=(\mathcal{H}_{0}\oplus\mathcal{M}_{1})\oplus(\mathcal{M}_{2}\oplus\mathcal{H}_{1}),

then

z_{U}=\begin{bmatrix}X_{11}z_{1}&X_{12}z_{1}&X_{13}z_{3}&X_{14}z_{3}\\
0&Az_{1}&Bz_{3}&X_{24}z_{3}\\
0&Cz_{3}&Dz_{2}&X_{34}z_{2}\\
0&0&0&X_{44}z_{3}\end{bmatrix}

and we see that

\|z_{T}\|=\|\begin{bmatrix}Az_{1}&Bz_{3}\\
Cz_{3}&Dz_{2}\end{bmatrix}\|\leq\|z_{U}\|\leq\|z\|_{\mathscr{U}}.

As
(\mathcal{M},T)
is an arbitrary element of
\mathscr{C}_{2}
, this proves the lemma.
∎

Lemma 9.5
.

If
z\in\mathbb{C}^{3}
, then

\|z\|_{\mathscr{U}}\leq\sup_{(\mathcal{M},T)\in\mathscr{C}_{2}}\|z_{T}\|.

Proof.

Fix
z\in\mathbb{C}^{3}
and
\epsilon>0
. Choose
(\mathcal{M},U)\in\mathscr{U}
such that

\|z\|_{\mathscr{U}}-\epsilon/2<\|z_{U}\|

(9.6)

and choose
\gamma\in\mathcal{M}
such that
\|\gamma\|=1
and

\|z_{U}\|-\epsilon/2<\|z_{U}\gamma\|.

(9.7)

If we let
P_{1}
and
P_{2}
denote the orthogonal projections of
\mathcal{M}
onto
\mathcal{M}_{1}
and
\mathcal{M}_{2}
, respectively, and define

\mathcal{N}_{1}=\spn\{P_{1}\gamma,P_{1}z_{U}\gamma\}\ \ \text{ and }\ \ \mathcal{N}_{2}=\spn\{P_{2}\gamma,P_{2}z_{U}\gamma\},

then
\mathcal{N}_{1}\perp\mathcal{N}_{2}
, i.e.,
\mathcal{N}=\mathcal{N}_{1}+\mathcal{N}_{2}
is a decomposed Hilbert space. Furthermore, if we define
T\in\mathcal{B}(\mathcal{N})
by letting
T=P_{\mathcal{N}}U|\mathcal{N}
, then
(\mathcal{N},T)\in\mathscr{C}
,
\gamma\in\mathcal{N}
, and

z_{T}\gamma=z_{U}\gamma.

Hence, using (
9.6
) and (
9.7
) it follows that

\|z\|_{\mathscr{U}}-\epsilon<\|z_{T}\gamma\|\leq\|z_{T}\|.

(9.8)

Now, it might be the case that either
\dim\mathcal{N}_{1}
or
\dim\mathcal{N}_{2}
is strictly less than 2, i.e.,
(\mathcal{N},T)\not\in\mathscr{C}_{2}
. However, we may choose Hilbert spaces
\lambda_{1}
and
\lambda_{2}
such that
\dim(\lambda_{1}\oplus\mathcal{N}_{1})=2
and
\dim(\mathcal{N}_{2}\oplus\lambda_{2})=2
and then define
(\mathcal{N}^{\sim},T^{\sim})\in\mathscr{C}_{2}
in the following way. Let

\mathcal{N}^{\sim}=(\lambda_{1}\oplus\mathcal{N}_{1})\oplus(\mathcal{N}_{2}\oplus\lambda_{2}),

and define
T^{\sim}
by choosing contractions
L_{1}\in\mathcal{B}(\lambda_{1})
and
L_{2}\in\mathcal{B}(\lambda_{2})
and letting

T^{\sim}\big((x\oplus u)\oplus(v\oplus y)\big)=L_{1}x\oplus(T(u\oplus v))\oplus L_{2}y,\qquad x\in\lambda_{1},y\in\lambda_{2},u\in\mathcal{N}_{1},v\in\mathcal{N}_{2}.

Here, we have identified the two spaces

(\lambda_{1}\oplus\mathcal{N}_{1})\oplus(\mathcal{N}_{2}\oplus\lambda_{2})\ \ \text{ and }\ \ \lambda_{1}\oplus(\mathcal{N}_{1}\oplus\mathcal{N}_{2})\oplus\lambda_{2}.

With this definition it follows that

z_{T^{\sim}}\cong(z_{1}L_{1})\oplus z_{T}\oplus z_{2}L_{2}.

Therefore,

\|z_{T}\|\leq\|z_{T^{\sim}}\|,

which implies via (
9.8
) that

\|z\|_{\mathscr{U}}-\epsilon<\|z_{T^{\sim}}\|.

(9.9)

Summarizing, we have shown that if
\epsilon>0
, then there exists
(\mathcal{N}^{\sim},T^{\sim})\in\mathscr{C}_{2}
such that (
9.9
) holds. This proves the lemma.
∎

Finally we show that to check if
z\in{\mathcal{G}}
, you just need to check that
\|z_{U}\|<1
for every unitary on
a decomposed Hilbert space of dimension
2+2
.
We let
\mathscr{U}_{2}
denote the collection of ordered pairs
(\mathcal{M},U)\in\mathscr{U}
satisfying
\dim\mathcal{M}_{1}=\dim\mathcal{M}_{2}=2
.

Proposition 9.10
.

If
z\in\mathbb{C}^{3}
, then

\|z\|_{\mathscr{U}}=\sup_{(\mathcal{M},U)\in\mathscr{U}_{2}}\|z_{U}\|.

Proof.

Fix a 2 dimensional Hilbert space
\mathcal{N}
, let
\mathcal{M}=\mathcal{N}\oplus\mathcal{N}
, and let
\rm ball\,\mathcal{B}(\mathcal{M})
denote the closed unit ball of
\mathcal{B}(\mathcal{M})
. By Lemmas
9.4
and
9.5

\|z\|_{\mathscr{U}}=\sup_{T\in\rm ball\,\mathcal{B}(\mathcal{M})}\|z_{T}\|.

But the map
T\mapsto\|z_{T}\|
is convex and therefore attains its maximum at an extreme point of
\rm ball\,\mathcal{B}(\mathcal{M})
. As the extreme points of
\rm ball\,\mathcal{B}(\mathcal{M})
are the unitaries, it follows that there exists
(\mathcal{M},U)\in\mathscr{U}_{2}
such that
\|z_{U}\|=\|z\|_{\mathscr{U}}
.
∎

Now we shall derive an inequality that defines
{\mathcal{G}}
.

Lemma 9.11
.

\begin{bmatrix}A&B\\
C&D\end{bmatrix}

is a block unitary acting on
\mathbb{C}^{2}\oplus\mathbb{C}^{2}
if and only if
there exist 3 unitary
2\times 2
matrices
u,v,w
such that

\begin{bmatrix}A&B\\
C&D\end{bmatrix}=\begin{bmatrix}u&0\\
0&v\end{bmatrix}\begin{bmatrix}a&b\\
c&d\end{bmatrix}\begin{bmatrix}1&0\\
0&w\end{bmatrix}

(9.12)

where

\begin{bmatrix}a&b\\
c&d\end{bmatrix}\text{ is a block unitary acting on }\mathbb{C}^{2}\oplus\mathbb{C}^{2}

(9.13)

and

a,b,c\geq 0.

(9.14)

Proof.

Using polar decomposition there exist unitary
u,v
and
a,c\geq 0
such that

A=ua\ \text{ and }\ C=vc.

Again using polar decomposition, there exists a unitary
w
and
b\geq 0
such that

B=ubw.

If we set
d=v^{*}Dw^{*}
, then (
9.12
) holds by direct computation, and, as the product of unitaries is unitary, (
9.13
) holds as well.
The converse is immediate.
∎

Lemma 9.15
.

(
9.13
) and (
9.14
) hold if and only if there exists a unitary
2\times 2
matrix
u
and scalars
r\leq s
in
[0,1]
such that

\begin{bmatrix}u^{*}&0\\
0&u^{*}\end{bmatrix}\begin{bmatrix}a&b\\
c&d\end{bmatrix}\begin{bmatrix}u&0\\
0&u\end{bmatrix}=\begin{bmatrix}r&0&\sqrt{1-r^{2}}&0\\
0&s&0&\sqrt{1-s^{2}}\\
\sqrt{1-r^{2}}&0&x_{11}&x_{12}\\
0&\sqrt{1-s^{2}}&x_{21}&x_{22}\end{bmatrix}

(9.16)

where

\begin{bmatrix}x_{11}&x_{12}\\
x_{21}&x_{22}\end{bmatrix}=\left\{\begin{array}[]{ll}\begin{bmatrix}-r&0\\
0&-s\end{bmatrix}&\mbox{if }s<1,\\
\\
\begin{bmatrix}-r&0\\
0&\tau\end{bmatrix},\text{ where }|\tau|=1,&\mbox{if }r<s=1,\\
\\
V,\text{ where $V$ is unitary, }&\mbox{if }r=s=1.\end{array}\right.

(9.17)

Proof.

By the spectral theorem there exists a unitary
2\times 2
matrix
u
and scalars
r\leq s
in
[0,1]
such that

u^{*}au=\begin{bmatrix}r&0\\
0&s\end{bmatrix}

As (
9.13
) holds we have that

\begin{bmatrix}a&c\\
b&d^{*}\end{bmatrix}\begin{bmatrix}a&b\\
c&d\end{bmatrix}=\begin{bmatrix}1&0\\
0&1\end{bmatrix}=\begin{bmatrix}a&b\\
c&d\end{bmatrix}\begin{bmatrix}a&c\\
b&d^{*}\end{bmatrix}

(9.18)

In particular,
a^{2}+c^{2}=1
. Hence, as
c\geq 0
,
c=\sqrt{1-a^{2}}
. But then

u^{*}cu=u^{*}(\sqrt{1-a^{2}})u=\sqrt{1-(u^{*}au)^{2}}=\begin{bmatrix}\sqrt{1-r^{2}}&0\\
0&\sqrt{1-s^{2}}.\end{bmatrix}

Likewise, as
a^{2}+b^{2}=1
and
b\geq 0
,

u^{*}bu=\begin{bmatrix}\sqrt{1-r^{2}}&0\\
0&\sqrt{1-s^{2}}.\end{bmatrix}

There remains to show that
d
has the form described in the statement of the lemma. This follows by simple calculations using the relations

b^{2}+d^{*}d=1=c^{2}+dd^{*},\ \ ab+cd=0,\ \ \text{ and }\ \ ca+db=0.

∎

Combining Proposition
9.10
with Lemmas
9.11
and
9.15
yields the following lemma.

Lemma 9.19
.

The point
z\in\mathbb{D}^{3}
is in
{\mathcal{G}}

if and only if

\sup_{r\in[0,1]}\big\|z_{r}\big\|<1

(9.20)

where

z_{r}=\begin{bmatrix}rz_{1}&\sqrt{1-r^{2}}z_{3}\\
\sqrt{1-r^{2}}z_{3}&-rz_{2}\end{bmatrix}.

Proof.

For
U=\begin{bmatrix}A&B\\
C&D\end{bmatrix}
, we have by Lemma
9.15
that

z_{U}
is unitarily equivalent to
z_{r}\oplus z_{s}
when
s<1
,
so (
9.20
) is necessary. It is easy to check the cases when
s=1
to see that
the condition is also sufficient.
∎

Lemma 9.21
.

The point

z\in\mathbb{D}^{3}
is in
{\mathcal{G}}
if and only if

|z_{1}z_{2}-z_{3}^{2}|<(1-|z_{3}|^{2})+\sqrt{1-|z_{1}|^{2}}\sqrt{1-|z_{2}|^{2}}.

(9.22)

Proof.

We need to find those
z
such that spectral radius of
z_{r}z_{r}^{*}
is less then one for every
r\in[0,1].

Letting
t=r^{2}
, we get that the trace
\tau
of the matrix
z_{r}z_{r}^{*}
is

\tau=t|z_{1}|^{2}+t|z_{2}|^{2}+2(1-t)|z_{3}|^{2}

(this must be in the interval
(0,2)
)
and the determinant
d
is

d=|tz_{1}z_{2}+(1-t)z_{3}^{2}|^{2}.

For the spectral radius to be less than one, we need to have
\tau+\sqrt{\tau^{2}-4d}<2
. Since
\tau<2
, this
is equivalent to
\tau<1+d
. So we want

t|z_{1}|^{2}+t|z_{2}|^{2}+2(1-t)|z_{3}|^{2}<1+t^{2}|z_{1}z_{2}|^{2}+(1-t)^{2}|z_{3}|^{4}+2t(1-t)\Re z_{1}z_{2}\bar{z}_{3}^{2}.

Simple calculations show that this inequality is equivalent to

t^{2}|z_{1}z_{2}-z_{3}^{2}|^{2}-t\left(|z_{1}z_{2}-z_{3}^{2}|^{2}+(1-|z_{3}|^{2})^{2}-(1-|z_{1}|^{2})(1-|z_{2}|)^{2}\right)+(1-|z_{3}|^{2})^{2}>0.

(9.23)

We want (
9.23
) to be satisfied for every
t\in(0,1)
. Let

A=|z_{1}z_{2}-z_{3}^{2}|
,
B=(1-|z_{3}|^{2})
and
C=\sqrt{1-|z_{1}|^{2}}\sqrt{1-|z_{2}|^{2}}
,
and
a:=A^{2}
,
b:=B^{2}
,
c:=C^{2}
,
a\geq 0
,
b,c>0
.
Note that

at^{2}-(a+b-c)t+b>0\ \forall\ t\in[0,1]

(9.24)

if either
a+b-c\leq 0
or
(a+b-c)/2a\geq 1
or
(a+b-c)^{2}<4ab
.
(The inequality is automatically satisfied when
t=0
or
1
.)

The first equality means that
a\leq c-b
. The second one that
a\leq b-c
(so both together mean that
a\leq|b-c|
). The third one can be transformed to

(a-b-c)^{2}<4bc,

that is
|A^{2}-B^{2}-C^{2}|<2BC
, which means that
|B-C|<A<B+C
.

Summing up, either
A^{2}\leq|B^{2}-C^{2}|
or
|B-C|<A<B+C
. Since
|B-C|^{2}\leq|B^{2}-C^{2}|
we get that
(
9.24
) holds if and only if
A<B+C
, that is
(
9.22
).
∎

Putting all these results together, we get the following theorem.

Theorem 9.25
.

Let
{\mathcal{V}}
and
{\mathcal{G}}
be defined by

\displaystyle{\mathcal{V}}

\displaystyle\ =\

\displaystyle\{z\in\mathbb{D}^{3}\,|\,z_{3}^{2}=z_{1}z_{2}\}

\displaystyle{\mathcal{G}}

\displaystyle\ =\

\displaystyle\{z\in\mathbb{D}^{3}\,|\,|z_{1}z_{2}-z_{3}^{2}|<(1-|z_{3}|^{2})+\sqrt{1-|z_{1}|^{2}}\sqrt{1-|z_{2}|^{2}}\}.

Then
{\mathcal{G}}
is convex, and

({\mathcal{G}},{\mathcal{V}})
is an np pair.

Now we shall show that
{\mathcal{G}}
is the largest balanced set for which
(G,{\mathcal{V}})
is np.
We exploit the fact that even though
{\mathcal{V}}
is two-dimensional, it effectively has a 3-dimensional
tangent space at
0
.

Lemma 9.26
.

Assume that
(G,{\mathcal{V}})
is a Cartan pair.
Let

The Noncommutative Analysis Setting

10.1
Overview

Joe Taylor introduced noncommutative analysis in his seminal work
[
43
]
on functional calculus for noncommuting elements of a Banach algebra. Landmarks in the development of the theory are Dan Voiculescu’s works
[
45
,
46
]
in the context of developing the theory of free probability, Bill Helton’s result
[
21
]
proving that positive free polynomials are sums of squares, the advance of Helton and McCullough
[
24
]
as a step in Helton’s fruitful program to develop a descriptive theory of the domains on which LMI and semi-definite programming apply, and the recent monograph by Kaliuzhnyi-Verbovetzkii and Vinnikov

[
29
]
that gives a panoramic view of the field to date, and establishes
a beautiful “Taylor-Taylor” formula for nc-functions.

There is much other notable work as well. As a sampling, there are articles of Popescu
[
34
,
35
,
36
,
37
]
which extend various results from classical function theory to functions of d-tuples of bounded operators; the magnum opus
[
13
]
of Ball,Groenewald and Malakorn, which extends realization formulas for functions of commuting operators to functions of non-commuting operators; Alpay and Kalyuzhnyi-Verbovetzkii
[
10
]
which studies realization formulas for noncommutative rational functions that are J-inner; and
[
22
,
23
]
where Helton, Klep and
McCullough study mappings of noncommutative domains.

In this section, which is largely expository in nature, we shall present some of the techniques developed
in the papers
[
5
]
,
[
4
]
, and
[
6
]
to prove the existence of free holomorphic extensions of both holomorphic functions defined on varieties in
\mathbb{C}^{d}
and free holomorphic functions defined on free varieties in
\mathcal{M}^{d}
, the “
d
dimensional noncommutative universe”. As an application one obtains a classical Cartan theorem with sharp bounds,
with norms that are defined using matrices.

10.2
Free Holomorphic Functions

There are many types of analysis that can be carried out on functions in noncommuting variables. Here, we shall focus on
free analysis
, by which we mean the study of
free holomorphic functions
.
Let
\mathbb{P}_{d}
denote the free algebra on
d
generators and let
\mathcal{M}_{n}
denote the space of
n\times n
matrices with complex entries. Let
\mathcal{M}_{n}^{d}
denote the space of
d
-tuples of
n\times n
matrices and define
\mathcal{M}^{[d]}
, the
d
-dimensional nc universe
, by

\mathcal{M}^{[d]}=\bigcup_{n=1}^{\infty}\mathcal{M}_{n}^{d}.

We may equip
\mathcal{M}^{[d]}
with the
coproduct topology
wherein one ordains that a set
D
in
\mathcal{M}^{[d]}
is open if and only if
D\cap\mathcal{M}_{n}^{d}
is open in
\mathcal{M}_{n}^{d}
for each integer
n\geq 1
.

If
\delta\in\mathbb{P}_{d}
and
x\in\mathcal{M}^{[d]}
then we may form
\delta(x)
in the natural way. More generally, if
\delta=[\delta_{ij}]\in\mathbb{P}_{d}^{\,I\times J}
, the collection of
I\times J
matrices with entries in
\mathbb{P}_{d}
and
x\in\mathcal{M}^{[d]}
, we may form

\delta(x)=[\delta_{ij}(x)].

We say that a subset of
\mathcal{M}^{[d]}
is
basic
if it has the form

B_{\delta}=\{x\in\mathcal{M}^{[d]}\,|\,\|\delta(x)\|<1\}

for some matrix
\delta
with entries in
\mathbb{P}_{d}
. Noting that

B_{\delta_{1}}\cap B_{\delta_{2}}=B_{\delta_{1}\oplus\delta_{2}},

it follows that the collection of basic sets forms a basis for a topology on
\mathcal{M}^{[d]}
, which we refer to as the
free topology
. We say that a subset of
\mathcal{M}^{[d]}
is a
domain
if it is open in the free topology.

If
D\subseteq\mathcal{M}^{[d]}
is a free domain, and
f:D\to\mathcal{M}^{[1]}
is a function, we say that
f
is a
free holomorphic function
if
f
can be locally uniformly approximated by free polynomials, i.e., for each
\lambda\in D
there exists a basic set
B_{\delta}
such that

\lambda\in B_{\delta}\subseteq D

and

\forall_{\epsilon>0}\ \exists_{\pi\in\mathbb{P}_{d}}\ \forall_{x\in B_{\delta}}\ \ \|f(x)-\pi(x)\|<\epsilon.

If
D
is a free domain and
E\subseteq D
, we shall refer to
(D,E)
as a
free pair
. If
(D,E)
is a free pair, then a function
f:E\to\mathcal{M}^{[1]}
is said to be
free holomorphic on
E
if for each point
\lambda\in E
there exist a basic set
B_{\delta}
and a free holomorphic function
F
on
B_{\delta}
such that

\lambda\in B_{\delta}\subseteq D\qquad\text{ and }\qquad F|E=f.

Finally, we say that a free pair
(D,E)
is
norm preserving
if for each bounded free holomorphic function
f
on
E
, there exists a free holomorphic function
F
on
D
that extends
f
and such that

\sup_{x\in D}\|F(x)\|=\sup_{x\in E}\|f(x)\|.

10.3
Pick Pairs

If
S\subseteq\mathbb{P}_{d}
, we define
V(S)
in
\mathcal{M}^{[d]}
by

V(S)=\{x\in\mathcal{M}^{[d]}\,|\,\forall_{\delta\in S}\ \ \delta(x)=0\}

and if
A\subseteq\mathcal{M}^{[d]}
we say that
A
is a
free variety in
\mathcal{M}^{[d]}
if
A=V(S)
for some
S\subseteq\mathbb{P}_{d}
. If
D
is a free domain and
A
is a variety in
\mathcal{M}^{[d]}
, we say that
V=A\cap D
is a
variety in
D
.
For a point
x\in\mathcal{M}^{[d]}
we define an ideal
I_{x}
in
\mathbb{P}_{d}
by

I_{x}=\{\delta\in\mathbb{P}_{d}\,|\,\delta(x)=0\}

and define a variety in
\mathcal{M}^{[d]}
by

V_{x}=V(I_{x}).

Notice that if
A
is a variety in
\mathcal{M}^{[d]}
and

, then
V_{x}\subseteq A
.

Definition 10.1
.

A
Pick pair
is an ordered pair
(D,E)
such that
D
is a basic set in
\mathcal{M}^{[d]}
and
E
is a subset of
D
satisfying the following two properties.

E\text{ is closed with respect to direct sums.}

(10.2)

x\in E\implies V_{x}\cap D\subseteq E.

(10.3)

Example 10.4
.

If
D
is a basic set in
\mathcal{M}^{[d]}
and
V
is a variety in
D
, then
(D,V)
is a Pick pair.

Proof.

Let
V=A\cap D
where
A
is a variety in
\mathcal{M}^{[d]}
. As
D
and
A
are closed with respect to direct sums,
V
is closed with respect to direct sums, i.e., (
10.2
) holds. Furthermore, since
V_{x}\subseteq A
whenever
x\in A
,

V_{x}\cap D\subseteq A\cap D=V
whenever
x\in A
, i.e., (
10.3
) holds.
∎

Definition 10.5
.

If
(D,E)
is a Pick pair, then
Pick data on
E
is a function
f:E\to\mathcal{M}^{[1]}
satisfying the following properties:

\forall_{x\in E}\ \ f(x)\in\mathbb{P}_{d}(x).,

(10.6)

and
f
preserves direct sums, i.e.,

\forall_{m}\ \ \ x_{1},\ldots,x_{m}\in E\implies f(\oplus_{i=1}^{m}x_{i})=\oplus_{i=1}^{m}f(x_{i}).

(10.7)

Definition 10.8
.

If
(D,E)
is a Pick pair, we say that
(D,E)
is
norm preserving
if whenever
f
is bounded Pick data on
E
, there exists a free holomorphic function
F
on
D
that extends
f
and such that

\sup_{x\in D}\|F(x)\|=\sup_{x\in E}\|f(x)\|.

(10.9)

It turns out that Pick pairs are always norm preserving.

Theorem 10.10
.

(
[
6
]
, Theorem 1.5) If
(D,E)
is a Pick pair, then
(D,E)
is norm preserving.

Proof.

Assume that
(D,E)
is a Pick pair and
f
is bounded Pick data on
E
. We wish to show that there exists a bounded free holomorphic function
F
on
D
that extends
f
and such that (
10.9
) holds. Fix a sequence
\{\lambda_{j}\}_{j=1}^{\infty}
in
E
that is dense in
E
in the coproduct topology and for each
n\geq 1
let

\Lambda_{n}=\oplus_{j=1}^{n}\lambda_{j}

By
(
10.2
)

\Lambda_{n}\in E
. Hence, (
10.6
) implies that there exists
\pi_{n}\in\mathbb{P}_{d}
such that

{}f(\Lambda_{n})=\pi_{n}(\Lambda_{n}).

(10.11)

Now, fix
x\in V_{\Lambda_{n}}
. As
\Lambda_{n}\in E
, (
10.3
) implies that
x\in E
. Hence, by (
10.2
),
\Lambda_{n}\oplus x\in E
. But then, (
10.6
) implies that there exists

such that

or equivalently, via (

f(\Lambda_{n})=\rho(\Lambda_{n})\qquad\text{ and }\qquad f(x)=\rho(x).

The first equation above together with (

Summarizing, in the previous paragraph we showed that if

Consequently, by Theorem 1.3 in

on

The desired function

[

]
.
∎

10.4
p
Norms

In order to relate the free setting to the classical theory of functions in several complex variables of particular value is the algebraic set
\mathcal{M}^{[d]}_{\rm com}
defined in
\mathcal{M}^{[d]}
by

\mathcal{M}^{[d]}_{\rm com}=V(S)

where

S=\{x_{i}x_{j}-x_{j}x_{i}\,|\,i,j=1,\ldots,d\}.

We let
{\rm P}_{d}
denote the algebra of polynomials in
d
variables.
Naturally,
{\rm P}_{d}
can be identified with the quotient
\mathbb{P}_{d}/I
where
I
is the ideal generated by the set
S
above. Accordingly, each
p\in{\rm P}_{d}
corresponds to a coset
\delta+I
and conversely to each coset
\delta+I
corresponds an element of
{\rm P}_{d}
. When
p
and
\delta
are so related we write
p=[\delta]
.

For
p
an
I\times J
matrix with entries in
{\rm P}_{d}
we define a set
G_{p}
in
\mathbb{C}^{d}
by the formula

G_{p}=\{\lambda\in\mathbb{C}^{d}\,|\,\|p(\lambda)\|<1\},

For example, if

p(\lambda)=\begin{bmatrix}\lambda_{1}&&&\\
&\lambda_{2}&&\\
&&\ddots&\\
&&&\lambda_{d}\end{bmatrix},

then
G_{p}
equals the polydisc
\mathbb{D}^{d}
, if

p(\lambda)=\begin{bmatrix}\lambda_{1}\\
\lambda_{2}\\
\ddots\\
\lambda_{d}\end{bmatrix},

then
G_{p}
is the unit ball in
\mathbb{C}^{d}
centered at the origin, and if

p(\lambda)=\begin{bmatrix}p_{1}(\lambda)&&&\\
&p_{2}(\lambda)&&\\
&&\ddots&\\
&&&p_{n}(\lambda)\end{bmatrix}

where
p_{1},\ldots,p_{n}
are polynomials in
d
variables,
then
G_{p}
is the general polynomial polyhedron in
\mathbb{C}^{d}
. We say a domain
D
in
\mathbb{C}^{d}
is an
operhedron
if
D=G_{p}
for some matrix
p
with entries in
{\rm P}_{d}
. (So an operhedron
is a polynomial polyhedron if and only if it can be written as
G_{p}
where
p
is a diagonal matrix.)

Basic sets in
\mathcal{M}^{[d]}
and operhedrons in
\mathbb{C}^{d}
are related in a natural way described in the following lemma.

Lemma 10.12
.

If
\delta
is an
I\times J
matrix of free polynomials and
p=[\delta]
, then

([\lambda_{1}],\ldots,[\lambda_{d}])\in B_{\delta}\cap\mathcal{M}^{[d]}_{1}\qquad\iff\qquad(\lambda_{1},\ldots,\lambda_{d})\in G_{p}.

Proof.

Notice first that

([\lambda_{1}],\ldots,[\lambda_{d}])\in\mathcal{M}^{[d]}_{1}\qquad\iff\qquad(\lambda_{1},\ldots,\lambda_{d})\in\mathbb{C}^{d}.

Also, as
p=[\delta]
,

\forall_{\lambda\in\mathbb{C}^{d}}\ \ \delta([\lambda_{1}],\ldots,[\lambda_{d}])=p(\lambda_{1},\ldots,\lambda_{d}).

Therefore,

\displaystyle([\lambda_{1}],\ldots,[\lambda_{d}])\in B_{\delta}\cap\mathcal{M}^{[d]}_{1}

\displaystyle\iff\|\delta([\lambda_{1}],\ldots,[\lambda_{d}])\|<1

\displaystyle\iff\|p(\lambda_{1},\ldots,\lambda_{d})\|<1

\displaystyle\iff(\lambda_{1},\ldots,\lambda_{d})\in G_{p}.

∎

For
G_{p}
an operhedron, we define

\mathcal{F}_{p}=\{x\in\mathcal{M}^{[d]}_{\rm com}\ \,|\,\ \|p(x)\|<1\},

and for
f\in{\rm Hol}(G_{p})
, define
\|f\|_{p}
by

\|f\|_{p}=\sup_{x\in\mathcal{F}_{p}}\|f(x)\|.

(10.13)

By
f(x)
on the right-hand side of (
10.13
) we mean we use functional calculus to
evaluate the holomorphic function
f
on the
d
-tuple
x
whose spectrum lies in the domain of
f
.

We let
{\rm Hol}^{\infty}_{p}
denote the Banach algebra

{\rm Hol}^{\infty}_{p}=\{f\in{\rm Hol}(G_{p})\,|\,\|f\|_{p}<\infty\}.

The idea of studying function theory on polydiscs using p-norms dates back to
[
2
]
. The idea was first considered for general p-operhedrons by Ambrozie and Timotin in the beautiful paper
[
11
]
. In
[
12
]
Ball and Bolotnikov considerably extended the work in
[
11
]
introducing many powerful new tools.

A fundamental connection between p-norms and free analysis is revealed by the following result of two of the authors..

Theorem 10.14
.

(
[
4
]
, Theorem 8.5)
Assume that
\delta
is an
I\times J
matrix of free polynomials and let
p=[\delta]
. If
f\in{\rm Hol}^{\infty}_{p}
, then there exists a free holomorphic function
F
on

such that

\forall_{\lambda\in G_{p}}\ \ F([\lambda_{1}],\ldots,[\lambda_{d}])=[f(\lambda_{1},\ldots,\lambda_{d})]\ \qquad\text{ and }\qquad\sup_{x\in B_{\delta}}\|F(x)\|=\|f\|_{p}.

Conversely, if
F
is a bounded free holomorphic function on
B_{\delta}
and

is defined by

[f(\lambda_{1},\ldots,\lambda_{d})]=F([\lambda_{1}],\ldots,[\lambda_{d}]),\qquad\lambda\in G_{\delta},

and

\|f\|_{p}\leq\sup_{x\in B_{\delta}}\|F(x)\|.

The proof of Theorem
10.14
in
[
4
]
required a great deal of heavy lifting. Here, we present a simple proof using the fact that Pick pairs are norm preserving.

Proof.

Let
(D,E)=(B_{\delta},B_{\delta}\cap\mathcal{M}^{[d]}_{\rm com})
. Then
D
is a basic set,
E
is a subset of

, and as both

and
\mathcal{M}^{[d]}_{\rm com}
are closed with respect to direct sums, so also

is closed with respect to direct sums, i.e., (

) holds. Also, since
\mathcal{M}^{[d]}_{\rm com}
is an algebraic set in
\mathcal{M}^{[d]}

whenever

is a Pick pair.

Now fix

and

whenever

,

As

To prove the converse, note that since

, we get that

The inequality

Lemma 10.15
.

Let

.

.

Proof.

Let

.
Suppose

. Let

be a unit vector in

Choose an orthonormal basis in

). Write

We shall say that

y=(y_{1},y_{2})

of commuting matrices whose spectrum is in
\mathbb{D}^{2}
,
and
\mathcal{F}_{p,V}
is the subset for which both
y_{1}
and
y_{2}
have norm less than
1
and in addition satisfy
y_{1}^{2}=y_{2}^{2}
.
This is slightly larger than just the diagonalizable pairs of strict contractions; for example it contains the pair

\begin{bmatrix}c&d&0&0\\
0&c&0&0\\
0&0&c&d\\
0&0&0&c\end{bmatrix}\text{ and }\begin{bmatrix}-c&-d&0&0\\

0&0&c&d\\

whenever

But
\mathcal{F}_{p,V}

\begin{bmatrix}c&d\\
0&c\end{bmatrix}\text{ and }\begin{bmatrix}-c&d\\

and

.

A very similar proof to the one for Theorem
10.14
yields the following.

Theorem 10.18
.

Assume that
\delta
is an
I\times J
matrix of free polynomials and let
p=[\delta]
. Let
A
be an algebraic set
2
2

2

i.e.
A
is the common set of 0’s of a collection of polynomials in
{\rm P}_{d}

in
\mathbb{C}^{d}
and let

.
If
f\in{\rm Hol}^{\infty}_{p,V}
, then there exists a free holomorphic function
F
on
B_{\delta}
such that

\forall_{\lambda\in V}\ \ F([\lambda_{1}],\ldots,[\lambda_{d}])=[f(\lambda_{1},\ldots,\lambda_{d})]\ \qquad\text{ and }\qquad\sup_{x\in B_{\delta}}\|F(x)\|=\|f\|_{p,V}.

Conversely, if
F
is a bounded free holomorphic function on
B_{\delta}
and
f\in{\rm Hol}(V)
is defined by

[f(\lambda_{1},\ldots,\lambda_{d})]=F([\lambda_{1}],\ldots,[\lambda_{d}]),\qquad\lambda\in V,

then
f\in{\rm Hol}^{\infty}_{p,V}
and

\|f\|_{p}\leq\sup_{x\in B_{\delta}}\|F(x)\|.

Proof.

Let
(D,E)=(B_{\delta},\mathcal{F}_{p,V})
. Then (
10.2
) holds, and since

A
is an algebraic set, so does (
10.3
). Therefore,
(D,E)
is a Pick pair.

Now fix
f\in{\rm Hol}^{\infty}_{p,V}
and
y\in E
.
We may define a function
g:E\to\mathcal{M}^{[1]}
by formula (
10.16
).
Notice that this is well-defined. If at some
x_{i}
with spectrum
\{\lambda\}
we choose two

which agree with

in

V
, then

.

10.6
A Sharp Commutative Cartan Extension Theorem

We can now use the non-commutative result Theorem
10.18
to
prove a commutative extension theorem with sharp bounds for algebraic sets in operhedrons.

Theorem 10.19
.

Let
p\in{\rm P}_{d}^{\,I\times J}
and assume that
V
is an
algebraic set
in
G_{p}
.
If
f\in{\rm Hol}^{\infty}_{p,V}
, then there exists an extension
F\in{\rm Hol}^{\infty}_{p}
such that

F|V=f\qquad\text{}\qquad\|F\|_{p}=\|f\|_{p,V}.

(10.20)

Moreover, the norm estimate in (
10.20
) cannot be improved.
If
F\in{\rm Hol}^{\infty}_{p}
, then
F|V\in{\rm Hol}^{\infty}_{p,V}
and
\|F|V\|_{p,V}\leq\|F\|_{p}
.

Proof.

Let
f\in{\rm Hol}^{\infty}_{p,V}
. Choose
\delta
in
\mathbb{P}_{d}^{\,I\times J}
so that

p=[\delta]
. By Theorem
10.18
there exists a free holomorphic function

\Phi
on
B_{\delta}
with norm equal to
\|f\|_{p,V}
that extends
f
.
Define
F=\Phi|_{G_{p}}
. Then

\|F\|_{p}\ \leq\ \|\Phi\|_{B_{\delta}}\ =\ \|f\|_{p,V}.

(10.21)

But if
F|V=f
, we must have

\|F\|_{p}\ \geq\ \|f\|_{p,V},

since we are taking the supremum over a larger set.
Therefore we must have equality in (
10.21
).
∎
