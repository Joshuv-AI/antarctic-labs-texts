Blow-up of solutions to relaxed compressible Navier-Stokes equations in divergence form
Johannes Bärlin

Abstract




1
Compressible Navier-Stokes equations with relaxation in divergence form

We consider a hyperbolic system of balance laws with relaxation given by

(1.1)

\displaystyle\left\{\begin{aligned} \rho_{t}+(\rho u)_{x}&=0\\
(\rho u)_{t}+(\rho u^{2}+p(\rho))_{x}&=S_{x}\\
\tau((\rho S)_{t}+(\rho uS)_{x})-u_{x}&=-S\end{aligned}\right.

where
\tau>0
and the pressure
p
satisfies the constitutive relation

(1.2)

\displaystyle p(\rho)=\rho^{\gamma}

for
\gamma>1
. System (
1.1
) is to be solved on
[0,T)\times\mathbb{R}
for some
T\in(0,\infty]
with
(\rho,u,S)
taking values in the state space
(0,\infty)\times\mathbb{R}\times\mathbb{R}
. It is equivalent to

(1.3)

\displaystyle\rho_{t}+(\rho u)_{x}

\displaystyle=0

(1.4)

\displaystyle\rho u_{t}+\rho uu_{x}+p(\rho)_{x}

\displaystyle=S_{x}

(1.5)

\displaystyle\tau\rho(S_{t}+uS_{x})-u_{x}

\displaystyle=-S.

System (
1.1
) is a delayed version of the Navier-Stokes equations with a Maxwell-type law as a relaxation equation. A divergence-form variant of systems recently considered by Hu et al.
[
HW19
,
HRW22
]
, it is a prototypical version of a model proposed by Ruggeri
[
Rug83
]
as discussed by Freistühler in
[
Fre22
]
. In the latter the question is raised whether, like the systems considered in
[
HW19
,
HRW22
]
, also divergence-form relaxation systems such as (
1.1
) possess a dichotomy in the sense that for small perturbations of a homogeneous reference state the Cauchy problem for (
1.1
) has unique global solutions which time-asymptotically decay to the reference state, while for (some) large data there is a blow-up of solutions, i.e. physically reasonable solutions can only exist on a finite time interval. This note serves to confirm the second part of the mentioned dichotomy.

In proving the claimed blow-up we closely follow the procedure given by Hu, Racke and Wang
[
HRW22
]
. In fact we show that system (
1.1
) has all the necessary features in order to apply the identical steps as in
[
HRW22
]
from a certain point on. Our system is some what similar to the one considered in
[
HW19
]
, and in this note one may find many analogies to
[
HW19
]
including a dissipative-entropy equation and a finite speed of propagation result for the system (
1.1
).

The general strategy has its origins in two remarkable papers of T. Sideris. In
[
Sid84
]
he establishes a finite speed of propagation result for symmetric hyperbolic conservation laws which he uses in
[
Sid85
]
to show the “formation of singularities in three-dimensional compressible fluids“. The blow-up occurs for a certain averaged quantity involving
\rho u
. The strategy in
[
Sid85
]
is by now well-established and for instance used in
[
HW19
]
and
[
HRW22
]
.

The system (
1.1
) belongs to a general class of quasi-linear equations considered by Godunov
[
God61
]
and Boillat
[
Boi74
]
. Equations in this Godunov-Boillat class have the property of possessing a dissipative entropy equation. In this note we will use, and shortly derive, the follwing mathematical entropy equation

(1.6)

\displaystyle 0=

\displaystyle\left[\frac{p(\rho)-p(\overline{\rho})-\gamma(\rho-\overline{\rho})}{\gamma-1}+\frac{\tau\rho S^{2}}{2}+\frac{\rho u^{2}}{2}\right]_{t}

\displaystyle+\left[\frac{\gamma}{\gamma-1}up(\rho)+\frac{\gamma}{\gamma-1}\rho u+\frac{\rho u^{3}}{2}+\frac{\tau\rho uS^{2}}{2}-uS\right]_{x}

\displaystyle+S^{2}

where
\overline{\rho}>0
is some reference density. Assume we are given a solution
(\rho,u,S)\in C^{1}(\Omega)
on some open subset
\Omega\subset(0,\infty)\times\mathbb{R})
. To obtain (
1.6
) multiply (
1.3
) by
p^{\prime}(\rho)
to get

\displaystyle 0=p(\rho)_{t}+\gamma u_{x}p(\rho)+up(\rho)_{x}=p(\rho)_{t}+[\gamma up(\rho)]_{x}+(1-\gamma)up(\rho)_{x}.

In this way we find

(1.7)

\displaystyle up(\rho)_{x}=\left[\frac{1}{\gamma-1}p(\rho)\right]_{t}+\left[\frac{\gamma}{\gamma-1}up(\rho)\right]_{x}.

From (
1.3
) and (
1.4
) we deduce

(1.8)

\displaystyle-up(\rho)_{x}+uS_{x}=\rho uu_{t}+\rho u^{2}u_{x}+\frac{u^{2}}{2}(\rho_{t}+(\rho u)_{x})=\left[\frac{\rho u^{2}}{2}\right]_{t}+\left[\frac{\rho u^{3}}{2}\right]_{x}

and similarly from (
1.5
)

(1.9)

\displaystyle-S^{2}+u_{x}S=\tau(\rho S_{t}S+\rho uS_{x}S)=\left[\frac{\tau\rho S^{2}}{2}\right]_{t}+\left[\frac{\tau\rho uS^{2}}{2}\right]_{x}.

Combining (
1.7
)-(
1.9
) gives the entropy dissipation equality (
1.6
) where we have added an affine linear expression in the time-derivative term and compensated for this appropriately in the space-derivative term.

2
Blow-up of solutions for some large data

We begin with two properties of the Cauchy problem for system (
1.3
)-(
1.5
). On the one hand we have existence of physically reasonable solutions of said Cauchy problem on a maximal time interval for suitable inital values since (
1.3
)-(
1.5
) may be written as a first-order symmetrizable hyperbolic system of quasi-linear differential equations. On the other hand there is a finite speed of propagation result in the spirit of
[
Sid84
]
.

Lemma 2.1
.

Let
\overline{\rho}>0
. Let
(\rho_{0},u_{0},S_{0}):\mathbb{R}\rightarrow\mathbb{R}^{3}
satisfy
(\rho_{0}-\overline{\rho},u_{0},S_{0})\in H^{2}(\mathbb{R})
and
\rho_{0}(x)>0
for all
x\in\mathbb{R}
. Then there exists a maximal
T\in(0,\infty]
such that there is a unique solution
(\rho,u,S)
of (
1.3
)-(
1.5
) satisfying

\displaystyle(\rho-\overline{\rho},u,S)\in C^{0}([0,T),H^{2}(\mathbb{R}))\cap C^{1}([0,T),H^{1}(\mathbb{R})),

and

\displaystyle(\rho(0),u(0),S(0))=(\rho_{0},u_{0},S_{0}),

and for all
(t,x)\in[0,T)\times\mathbb{R}

\displaystyle\rho(t,x)>0.

Proof.

See Chapter 2 in
[
Maj84
]
.
∎

Lemma 2.2
.

Let
T,R>0
and
\overline{\rho}>0
. Set

(2.1)

\displaystyle\sigma:=\sqrt{p^{\prime}(\overline{\rho})+\frac{1}{\tau\overline{\rho}^{2}}}>0.

Suppose
(\rho,u,S)\in C^{1}([0,T)\times\mathbb{R})
solves (
1.3
)-(
1.5
) and satisfies

•

(\rho,u,S)\in C^{1}_{b}([0,t]\times\mathbb{R})
for all
t\in[0,T)
;

•

\textnormal{supp}\,(\rho(0,\cdot)-\overline{\rho},u(0),S(0))\subset(-R,R)
.

Then for all
t\in[0,T)
and
x\in D_{t}:=\{x\in\mathbb{R}:\;|x|\geq R+\sigma t\}
it holds

(2.2)

\displaystyle(\rho(t,x)-\overline{\rho},u(t,x),S(t,x))=(0,0,0).

Proof.

Write
U=(\rho,u,S)
and define

\displaystyle A_{0}(U)=\begin{pmatrix}1&0&0\\
0&\rho&0\\
0&0&\tau\rho\end{pmatrix},\;A_{1}(U)=\begin{pmatrix}u&\rho&0\\
p^{\prime}(\rho)&u&-1\\
0&-1&\tau\rho u\end{pmatrix},\;B=\begin{pmatrix}0&0&0\\
0&0&0\\
0&0&1\end{pmatrix}.

Set
\overline{U}:=(\overline{\rho},0,0)
and consider for
V:=U-\overline{U}
the system

\displaystyle V_{t}+A_{0}(\overline{U})^{-1}A_{1}(\overline{U})V_{x}+A_{0}(\overline{U})^{-1}BV=G(\overline{U},U,U_{t},U_{x})

with

\displaystyle G(\overline{U},U,U_{t},U_{x})=A_{0}(\overline{U})^{-1}[(A_{0}(\overline{U})-A_{0}(U))U_{t}+(A_{1}(\overline{U})-A_{1}(U))U_{x}].

The eigenvalues of
A_{0}(\overline{U})^{-1}A_{1}(\overline{U})
are

\displaystyle\lambda_{1}(\overline{U},\tau)=-\sqrt{p^{\prime}(\overline{\rho})+\tfrac{1}{\tau\overline{\rho}^{2}}},\;\lambda_{2}(\overline{U},\tau)=0,\;\lambda_{3}(\overline{U},\tau)=\sqrt{p^{\prime}(\overline{\rho})+\tfrac{1}{\tau\overline{\rho}^{2}}}.

Set
\sigma:=\lambda_{3}
and proceed like in
[
HW19
]
which follows the idea of
[
Sid84
]
to show the claim of the lemma.
∎

The data for which solutions of (
1.3
)-(
1.5
) experience a blow-up is constructed from the function in the following lemma taken from
[
HR14
]
(see
[
HRW22
]
, too):

Lemma 2.3
.

Let
L>0
and
M>2
. Then the function

\displaystyle u_{L,M}(x):=\left\{\begin{aligned} 0,&&x\in(-\infty,-M]\\
\tfrac{L}{2}\cos(\pi(x+M))-\tfrac{L}{2},&&x\in(-M,-M+1]\\
-L,&&x\in(-M+1,-1]\\
L\cos(\pi(x+M)),&&x\in(-1,1]\\
L,&&x\in(1,M-1]\\
\tfrac{L}{2}\cos(\pi(x+M))+\tfrac{L}{2},&&x\in(M-1,M]\\
0,&&x\in(M,\infty)\end{aligned}\right.

is an element of
H^{2}(\mathbb{R})\cap C^{1}(\mathbb{R})
with

(2.3)

\displaystyle||u_{L,M}||_{L^{2}}^{2}\leq 2L^{2}M.

Now we state and prove the theorem on blow-up of solutions to (
1.3
)-(
1.5
) for some large data.

Theorem 2.4
.

Let
R>0,\overline{\rho}=1
and let
(\rho_{0},S_{0})\in C^{1}(\mathbb{R})
. Suppose
\rho_{0}(x)>0
for all
x\in\mathbb{R}
and
\textnormal{supp}\;(\rho_{0}-1,S_{0})\subset(-R,R)
. Assume

(2.4)

\displaystyle\int_{\mathbb{R}}\rho_{0}(x)-1dx\geq 0.

and set
\sigma:=\sqrt{\gamma+\tau^{-1}}
. Choose
\tilde{\sigma},L\ >0
such that

(2.5)

\displaystyle\tilde{\sigma}^{2}=\max\{\sigma^{2},(8\max\rho_{0})^{-1}\}

and

(2.6)

\displaystyle\frac{L}{2}\min\rho_{0}>\max\{\sqrt{8\max\rho_{0}},16\tilde{\sigma}\max\rho_{0}\}.

Define

(2.7)

\displaystyle H_{0}:=\int_{\mathbb{R}}\frac{p(\rho_{0}(x))-1-\gamma(\rho_{0}(x)-1)}{\gamma-1}+\frac{\tau\rho_{0}(x)S^{2}_{0}(x)}{2}dx

and choose
M\geq\max\{4,R\}
such that

(2.8)

\displaystyle H_{0}+\max\rho_{0}L^{2}M\leq 2\tilde{\sigma}M^{2}\max\rho_{0}.

Let
(\rho,u,S)
be the solution of (
1.3
)-(
1.5
) with initial data
(\rho_{0},u_{L,M},S_{0})
and maximal time of existence
T>0
as given by Lemma
2.1
. Then
T
is finite and the critical averaged quantity initially satisfies

(2.9)

\displaystyle\int_{\mathbb{R}}x\cdot\rho_{0}(x)u_{0}(x)dx>\max\{16\tilde{\sigma}M^{2}\max\rho_{0},M^{2}\sqrt{8\max\rho_{0}}\}.

Remark 2.5
.

Before we enter the proof let us comment on where the above choices of constants enter in the proof. The relations (
2.5
) and (
2.6
) are needed to establish two a-priori estimates which appear in the deduction of the central Riccati-type differential inequality. Then again (
2.6
) together with (
2.8
) serves to find that the quantity on the right of (
2.9
) plays the role of a critical treshold for the Riccati-type inequality thereby allowing the conclusion of a finite maximal time of existence of the considered solution of (
1.3
)-(
1.5
).

Proof.

The proof is very close to section 3 of
[
HRW22
]
, also with respect to notation. In fact after establishing the Riccati-type estimate the claim follows like in
[
HRW22
]
. The general strategy follows
[
Sid85
]
. First define for
t\in[0,T)
the averaged quantities

(2.10)

\displaystyle m(t):=\int_{\mathbb{R}}\rho(t,x)-1dx

and

(2.11)

\displaystyle F(t):=\int_{\mathbb{R}}x\cdot\rho(t,x)u(t,x)dx.

m
and
F
are well-defined and continuous functions because of the compact supports of
u(t,\cdot)
and
\rho(t,\cdot)-1
by Lemma
2.2
.

By conservation of density (
1.3
), the compact support of
\rho(t,\cdot)-1
and by (
2.4
) we have for
t\in[0,T)

(2.12)

\displaystyle m(t)=m(0)\geq 0.

Setting

\displaystyle B_{t}:=\{x\in\mathbb{R}:\;|x|<M+\tilde{\sigma}t\}\subset D_{t}^{c}

and using Jensen’s inequality (see p.846 [WH18]) implies

(2.13)

\displaystyle\int_{B_{t}}p(\rho(t,x))dx\geq\int_{B_{t}}p(\overline{\rho})dx.

By Lemma
2.2
, partial integration and (
1.3
) and (
1.4
) we have

\displaystyle F^{\prime}(t)=\int_{\mathbb{R}}(\rho u^{2})(t,x)dx+\int_{\mathbb{R}}p(\rho(t,x))-p(\overline{\rho})dx-\int_{\mathbb{R}}S(t,x).

Apply estimate (
2.13
) and Young’s inequality to conclude

(2.14)

\displaystyle F^{\prime}(t)\geq\int_{\mathbb{R}}(\rho u^{2})(t,x)dx-\frac{1}{2}\int_{\mathbb{R}}S^{2}(t,x)dx-(M+\tilde{\sigma}t).

Hölder’s inequality and (
2.12
) yield

(2.15)

\displaystyle F^{2}(t)

\displaystyle\leq\int_{B_{t}}x^{2}\rho(t,x)dx\int_{B_{t}}(\rho u^{2})(t,x)dx

\displaystyle\leq 2(M+\tilde{\sigma}t)^{3}\max\rho_{0}\int_{B_{t}}(\rho u^{2})(t,x)dx.

Let

\displaystyle c_{2}

\displaystyle:=\frac{\tilde{\sigma}}{M},

\displaystyle c_{3}

\displaystyle:=\frac{1}{2\max\rho_{0}M^{3}},

\displaystyle c_{1}

\displaystyle:=\frac{2c_{2}}{c_{3}},

and assume for all
t\in[0,T)
the a-priori estimates

(2.16)

\displaystyle F(t)\geq c_{1}>0

and

(2.17)

\displaystyle M+\tilde{\sigma}t=M(1+c_{2}t)\leq\frac{c_{3}}{2(1+c_{2}t)^{3}}F^{2}(t).

Combining the estimate (
2.14
) for
F^{\prime}
with the estimate (
2.15
) for
F^{2}
and using the a-priori estimates (
2.16
) and (
2.17
) one finds the Riccati-type inequality

(2.18)

\displaystyle\frac{F^{\prime}(t)}{F^{2}(t)}\geq\frac{c_{3}}{2(1+c_{2}t)^{3}}-\frac{1}{2c_{1}}\int_{\mathbb{R}}S^{2}(t,x)dx.

One uses the entropy equality (
1.6
) to treat the
S^{2}
-term above:

(2.19)

\displaystyle\int_{\mathbb{R}}S^{2}(t,x)dx

\displaystyle\leq\int_{\mathbb{R}}\frac{p(\rho_{0})-1-\gamma(\rho_{0}-1)}{\gamma-1}+\frac{\rho_{0}u_{L,M}^{2}}{2}+\frac{\tau\rho_{0}S^{2}}{2}dx

\displaystyle\leq H_{0}+\frac{\max\rho_{0}}{2}||u_{L,M}||_{L^{2}}^{2}.

Remark 2.6
.

By Taylor’s Theorem one has for
\rho>0

\displaystyle p(\rho)=1+\gamma(\rho-1)+\frac{p^{\prime\prime}}{2}(\xi)(\rho-1)^{2}

for some
\xi>0
. Note
p^{\prime\prime}(\rho)>0
for
\rho>0
. These facts were used for the estimate in (
2.19
) (see also p.829
[
HW19
]
).

Now we are in the exact same situation as in
[
HRW22
]
section 3, and all further steps repeat theirs. Collecting the constants once more in

\displaystyle c_{4}:=\frac{H_{0}}{2c_{1}^{2}}\;\textnormal{and}\;c_{5}:=\frac{\max\rho_{0}}{4c_{1}^{2}}

and noting

\displaystyle c_{4}+c_{5}||u_{L,M}||_{L^{2}}^{2}\leq\frac{c_{3}^{2}}{8c_{2}^{2}}(H_{0}+\max\rho_{0}L^{2}M)\leq\frac{c_{3}}{8c_{2}}

by (
2.3
), the definition of
c_{1}
and (
2.8
) we finally find by integrating (
2.18
) that for all
t\in[0,T)

(2.20)

\displaystyle F(0)^{-1}

\displaystyle\geq F(0)^{-1}-F(t)^{-1}

\displaystyle\geq-\frac{c_{3}}{4c_{2}(1+c_{2}t)^{2}}+\frac{c_{3}}{4c_{2}}-c_{4}-c_{5}||u_{L_{M}}||_{L^{2}}^{2}

\displaystyle\geq-\frac{c_{3}}{4c_{2}(1+c_{2}t)^{2}}+\frac{c_{3}}{8c_{2}}.

But by definition of
u_{L,M}
(note its symmetry
u_{L,M}(x)=-u_{L,M}(-x)
),
M\geq 4
and by (
2.6
) it holds

(2.21)

\displaystyle F(0)>\frac{L}{2}\min\rho_{0}M^{2}\geq 16\frac{\tilde{\sigma}}{M}\max\rho_{0}M^{3}=\frac{8c_{2}}{c_{3}}

which implies
T<\infty
since otherwise there exists a
t>0
such that (
2.20
) violates (
2.21
).

It remains to verify the a-priori estimates. We have

\displaystyle F(0)\geq 2c_{1}

by (
2.21
). If for some
T^{\ast}\in(0,T]
we have
F\geq c_{1}
on
[0,T^{\ast})
then we get from (
2.20
)

\displaystyle F(t)\geq\frac{4c_{2}(1+c_{2}t)^{2}}{c_{3}}\geq 2c_{1}.

for all
t\in[0,T^{\ast})
. Since
F
is continuous these two facts imply
F\geq c_{1}
on
[0,T)
(see p.10
[
HR14
]
).

We show

(2.22)

\displaystyle M+\tilde{\sigma}t=M(1+c_{2}t)\leq\frac{c_{3}}{4(1+c_{2}t)^{3}}F^{2}(t)

which implies (
2.17
). Proceeding in a similar fashion like before we have

\displaystyle F^{2}(0)\geq\frac{L^{2}M^{4}\min\rho_{0}^{2}}{2}\geq 4M^{4}\max\rho_{0}=\frac{4M}{c_{3}}=2\frac{2M}{c_{3}}

by (
2.21
) and (
2.6
). Hence the estimate (
2.22
) holds for
t=0
. Again if for some
T^{\ast}\in(0,T]
the estimate (
2.17
) holds for all
t\in[0,T^{\ast})
then by the Riccati-type inequality (
2.20
) and assumption (
2.5
) we find

\displaystyle F^{2}(t)\geq\frac{16c_{2}^{2}}{c_{3}^{2}}(1+c_{2}t)^{4}\geq\frac{4M}{c_{3}}(1+c_{2}t)^{4}

closing the a-priori estimate (
2.17
) by a continuity argument.
∎
