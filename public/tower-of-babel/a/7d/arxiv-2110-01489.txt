Object generators, sets, and a foundation for mathematics
Frank Quinn

Abstract




1.
Abstract

Beginning with two primitives, four axioms, and weak non-binary logic, we develop what seems to be a complete foundation for mainstream deductive mathematics. In more detail, the primitives are “object generators”, essentially the “object” primitive of category theory; and morphisms of these, essentially functions. The main assumption is the axiom of choice. The logic does not include a global equality operator, quantification, or excluded middle. Sets are defined inside this context, and most of the standard properties of sets are proved rather than assumed as axioms.

The main technical result is that, in this context there is an implementation of the Zermillo-Fraenkel-Choice axioms, except that our use of “function” as a primitive instead of “membership” avoids the traditional need for first-order logic. We abbreviate the axioms with this omission as ZFC-1. This model is maximal in the sense that any other model of ZFC+/-1 is (uniquely) a transitive submodel of this one. Finally, we formulate the “coherent limit axiom”. It is an immediate consequence of the use of “function” as a primitive that this holds in the maximal model. It is a simple consequence of maximality that this characterizes the maximal model among all ZFC-1 models.

There are a number of qualitative implications. In the mainstream, the coherent limit axiom is regarded as self-evident and used extensively. Therefore, mainstream deductive work implicitly takes place in the set theory described here. This is even true of elementary calculus. One implication is that much of the axiomatic set theory of the last century is irrelevant to mainstream mathematics. Forcing and independence results, for example, do not give information about the maximal model. The existence of a maximal model suggests that “large cardinal” hypotheses may be problematic.
In more positive directions, questions such as the Continuum Hypothesis are well-posed for the maximal model. Showing that the maximal model satisfies “Martin’s Maximum”, the “diamond” hypothesis, or the like, would connect with extensive known material. Similarly, much of what is known about singular strong-limit cardinals is model-independent; can this be sharpened or simplified in the maximal model?

2.
Introduction

2.1.
Some ideas

The larger context uses “assertion” logic, for example “
a

is

A “binary function” is a function that takes values in the two-element collection
\{\textsf{yes},\textsf{no}\}

then

is supposed to define a binary function with support

\{0,1\}
, can be used, but we reserve ‘true’ and ‘false’ for other purposes.

A
logical domain
is a collection of elements (an object generator)

with a binary pairing

such that applying it to

returns ‘
yes

a
can be asserted to be the same as
b
. Logical domains are the appropriate setting for binary logic.
The

of a logical domain, denoted
\textsf{P}[A]
, is the collection of all binary functions on
A
. We say that a logical domain
supports quantification
if
\textsf{P}[A]
is again a logical domain. Finally, a
set
(‘relaxed’ set if distinctions are needed) is a logical domain that supports quantification.

The main technical result connects this set theory with the axiomatic theories developed in the last hundred years. Most of these, the Zermillo-Fraenkel-Choice (ZFC) axioms in particular, are organized around the membership pairing ‘
\in
’. To avoid contradictions, this pairing is required to be well-founded. The main result is that relaxed set theory contains a universal well-founded pairing, universal in the sense that every well-founded pairing is (uniquely) isomorphic to a transitive subobject. In particular this contains copies of all models of the ZFC axioms. The universal pairing satisfies the ZFC-1 axioms, where “-1” stands for “ignore first-order logic restrctions”. This makes sense here because functions are taken as primitives. The set theory associated to this universal object is relaxed set theory.

The main qualitative result is that, of all models of the ZFC axioms, only the maximal one is consistent with mainstream mathematical practice. For this we give a number of formulations of the “Coherent Limit axiom”. These are routinely assumed in mainstream practice and, more to the point, no effort is made to deal with possible failures. But it is easy to see that this axiom holds only in the maximal theory.
[
Quinn2
]
gives historical background and qualitative discussion of the role of foundations.

We remark that the Coherent Limit axiom answers a question of Gödel, though not in the way he anticipated. He felt that the existence of different models for the ZFC axioms indicated a “missing axiom” that, when added to ZFC, would uniquely specify a particularly capable set theory. The expectation seemed to be that this would give a new tool to use within the ZFC context. The Coherent Limit axiom does indeed uniquely specify a particularly capable theory, but one with a simpler description that avoids ZFC.

3.
Primitives

There are three types of irreducible ingredients: primitive objects, primitive logic, and primitive hypotheses. We particularly focus on the logic, since it is weaker than the binary logic used in mainstream mathematics and embedded in our language.

3.1.
Primitive objects

Standard practice in mathematics is to define new things in terms of old, and use the definition to infer properties from properties of the old things. The old things are typically defined in terms of yet more basic things. But to get started there must be objects that are not fully defined. Features and usage of primitive objects must be specified directly, since they cannot be inferred from a definition. A key concern is that different users reliably interpret these descriptions in the same way. Given this, logical consistency of the theory is an experimental conclusion, based on extensive downstream development that has not revealed contradictions. This is discussed in more detail in a later paper.

3.2.
Assertion logic

Logic provides methods of reasoning with primitive objects and hypotheses.
Traditional set theory uses
binary
(yes/no valued) logic. The core logic here is weaker in that it is based on assertions. We describe primitive logical terms, and provide examples to illustrate useage.

Assertions

An
assertion
is a statement that is asserted to be correct. For example, if we introduce the symbol
a
by saying “
a{\in\in}B
”, then at a later time we could assert
a\,!{\in\in}B
because this is known to be correct.

We clarify the difference between this and binary logic, particularly because binary logic is deeply embedded in both our natural language and our mathematical thinking. If we say “A is B”, for instance, it is usually implicit that there is a binary function that returns ‘yes’ if it is true, and ‘no’ if not. In particular we can formally negate to get “A is not B” simply by interchanging ‘yes’ and ‘no’. We can also use ‘if-then-else’ logical constructs. The term ‘asserted’ is used in part to avoid this interpretation. The formal negation of “A is asserted to be B” is “A is
not asserted
to be B”, which has no logical force.

To differentiate between logics, assertions are usually indicated by ‘!’ and statements implemented by binary functions are indicated by ‘?’. Writing
A{\,?\!\!=\,}B

A{\;!\!\!=\,}B
is an assertion that may not be implemented by a binary function.

Basic assertions relevant to set and generator theory include:

(1)

is an output of the generator

(2)

(3)

(4)

(5)

(6)

We also use the common notation

True and false

As with binary logic, assertions can be true or false. By default they are assumed to be true, so “

Note that identification of the false input depends heavily on

Conclusions of contradiction arguments are usually expressed as negative assertions. For example we understand “

3.3.
Primitive hypotheses

Primitive

are assertions that we believe are consistent, but cannot justify by reasoning with other primitives. Instead we regard these as experimental hypotheses. As such they are all well-supported; see the Discussion.

Hypotheses

Two:

There is a generator

Choice:

Suppose

Infinity:

The natural numbers support quantification.

Quantification:

If a logical domain supports quantification then so does its powerset.

Discussion:

About Two
: The force of this hypothesis is that, unlike general generators, we can tell the objects apart. This axiom is needed for ‘binary functions’ to make sense.

The names ‘yes’, ‘no’ are chosen to make it easy to remember operations (‘and’, ‘or’, etc.). As above, one might prefer ‘1’ and ‘0’ for indexing or connections to algebra and analysis, but we avoid ‘true’ and ‘false’.

About Choice
: The term “choice” comes from the idea that if a morphism is onto, then we can “choose” an element in each preimage to get a morphism
s
. Note that in general there is no binary-function way to determine if a morphism is onto, or if the composition is the identity. These must be

The axiom of choice in traditional settings has strong consequences that have been extensively tested for more than a century. No contradictions have been found, and it is now generally accepted. The above form extends the well-established version to contexts without quantification. This extension has implicitly been used in category theory, again without difficulty.

About Infinity
: Using primitive objects and hypotheses other than Infinity, we can construct the natural numbers
\mathbb{N}
as a logical domain. However we cannot show that it supports quantification. The Infinity hypothesis asserts that it does. This is essentially the same as the ZFC axiom, and is well established.

About Quantification
The appendix §

4.
Logical domains, and quantification

We provide definitions and basic properties of logical domains and quantification.

is empty. Since each

is a set, there is a binary function that implements “is the restriction to
f^{-1}[b]
empty?”. The outputs of these define a binary function on
B
, and the function on
A
is empty if and only if this function is always ‘yes’. Or equivalently, if the negation is empty. But since
B
is a set there is a binary function on
\textsf{P}[B]
that detects this. Putting these together gives an empty-detecting function on
\textsf{P}[A]
. ∎

Comment: in the literature the domains
f^{-1}[b]
are sometimes thought of as “a family of sets, indexed by the set
B
”. In these terms the Proposition asserts that the union of such a family is a set.

5.
Well-orders

We briefly recall the properties of well orders, and show that there is a universal almost well-ordered domain. This is sometimes called “the ordinal numbers”.

5.1.
Definitions

Suppose
A
is an object generator.

(1)

A
linear order
on
A
is a binary pairing
(\#1\leq\#2)\colon A\times A\to\textsf{y/n}
that is
transitive (
a\leq b
and
b\leq c
implies
a\leq c
);
any two elements are related: (
(a\leq b)\textsf{\,or\,}(b\leq a)
);
and elements related both ways are the same: (
(a\leq b)\textsf{ and\,}(b\leq a)\Leftrightarrow(a{\;!\!\!=\,}b)
).

(2)

(A,\leq)
is a
well-order
if it is a linear order,
A
is a set, and if
A\supset B
is transitive then
either
B=A
or
B=(\#<b)
for some
b\in A
.

(3)

(A,\leq)
is an
almost
well-order if subdomains of the form
(\#<x
) are well-ordered.

Notes

(1)

Note the last condition in (1) asserts that
(a{\,?\!\!=\,}b):=(a\leq b)\textsf{ and\,}(b\leq a)
is an equality pairing, making
A
a logical domain.

(2)

In (2) recall that a sub
domain

B\subset A
is said to be
transitive
if
(b\in B)\textsf{ and\,}(a\leq b)\Longrightarrow a\in B
.

(3)

In (2), note that quantification is needed for “
B=A
” to be implemented by a binary function.

(4)

This definition of ‘well-order’ differs from the usual one (cf. Jech
[
Jech
]
definition 2.3), but it is equivalent and better for the development here.

(5)

As usual, well-orders are
hereditary
in the sense that
if
(A,\leq)
is well-ordered, and
B\subset A
is a binary subdomain, then
the induced order on
B
is a well-order. Similarly for almost well-orders.

(6)

We will see in §
5.3
that an
almost
well-order fails to be a well-order if and only if the domain is not a set. It will turn out that there is only one of these, up to order-isomorphism.

Well-ordered equivalence classes

This is a variation on ‘Domains of equivalence classes’ in §
4.1
. We will use this construction in the definition of the universal almost well-order.

A
linear pre-order
consists of an object generator
{\in\in}A
and a binary pairing
\textsf{leq}[\#1,\#2]
defined on pairs of outputs. The pairing satisfies:

(1)

(transitive)
\textsf{leq}[a,b]\textsf{ and\,}\textsf{leq}[b,c]\Rightarrow\textsf{leq}[a,c]
;

(2)

(reflexive)
\textsf{leq}[a,a]
; and

(3)

(pre-linear) for all
a,b{\in\in}A
, either
\textsf{leq}[a,b]
or
\textsf{leq}[b,a]
(or both).

Given this structure, define
\textsf{eqv}[a,b]:=(\textsf{leq}[a,b]\textsf{ and\,}\textsf{leq}[b,a])
. The quotient
A/\textsf{eqv}
is a logical domain, and
leq
induces a linear order in the ordinary sense on elements (ie. on equivalence classes of objects).
The additional conditions used to define well-orders in this context are the same as those on the element level.

5.2.
Recursion

Our version is slightly different from the standard one (cf.
[
Jech
]
, Theorem 2.15) in part because we do not find the standard one to be completely clear. In §
8
we see that being too casual about recursion can conflict with the ZFC axioms. There is a version for well-founded pairings in §
7.2
.

First we need a notation for restrictions. Suppose
f\colon A\to B
is a partially-defined function and
D\subset A
is a set. Then
f\upharpoonright D
is the restriction to
\textsf{dom}[f]\cap D
.

Now, suppose
(A,\leq)
is an almost well-order,
B
is a domain, and
R
is a partially-defined function

R\colon\textsf{tfn}[A,B]\times A\to B.

Here ‘
tfn
’ denotes functions with transitive domains, i.e. domains of the form
(\#<a)
for some
a\in A
. We refer to such an
R
as a
recursion condition
.

A (partially-defined) function
f\colon A\to B
is said to be
R
-
recursive
if:

(1)

\textsf{dom}[f]
is transitive; and

(2)

for every
c\in\textsf{dom}[f]
,
f[c]=R[f\upharpoonright(\#<c),c\,]
.

Note that this is hereditary in the sense that if
D\subset\textsf{dom}[f]
is transitive then the restriction
f\upharpoonright D
is also recursive.

Proposition
.

(Recursion) If
(A,\leq),B,R
are as above, then there is a unique maximal
R
-recursive function
r\colon A\to B
.

“Maximal” refers to domains:
r
is maximal if there is no recursive function with larger domain. We describe a criterion for maximality below. Note that the domain of
r
may be all of
A
even if it is not a set; the recursion condition applies to restrictions to subdomains of the form
(\#<a)
, and according to the definition of ‘almost’ these are all sets.

The proof is essentially the same as the classical one; we sketch it to illustrate the slightly non-standard definitions. First, if
f,g
are recursive and have the same domain, then they are equal. Suppose not and let
a
be the least element on which they differ. Minimality of
a
implies the restrictions to
(\#<a)
are equal. but then

f[a]=R[f\upharpoonright(\#<a)]=R[g\upharpoonright(\#<a)]=g[a],

a contradiction.

The maximal
r
has domain the union
\cup(\textsf{dom}[f]\mid f\text{ is }R-\text{recursive})
. If
x
is in this union then
x\in\textsf{dom}[f]
for some recursive
f
. Define
r[x]:=f[x]
. Uniqueness implies this is well-defined, and is recursive.∎

Note a recursive
r
is maximal if either
\textsf{dom}[r]=A
or, if
\textsf{dom}[r]\neq A
and
a
is the least element not in
\textsf{dom}[r]
, then
(r,a)
is not in the domain of
R
.

As an aside, a recursion condition can be thought of as a sort of “vector field” on functions with transitive domain, and recursion gives a “flow” following this vector field. Specifically, a function
F
is a ‘recursive extension’ of a function
f
if
F\upharpoonright\textsf{dom}[f]=f
, and for each
c\in\textsf{dom}[F]-\textsf{dom}[f]
,
F[c]=R[F\upharpoonright(\#<c),c\,]
. The recursive extensions of
f
trace out the flow line beginning at
f
. The proof above shows there is a unique maximal such flow line. The traditional result concerns the flow line beginning with the empty function.

Order isomorphisms

The first application of recursion is a key result in traditional set theory. It is extended to well-founded pairings in §
7.2
.

Proposition
.

Suppose
(A,\leq),(B,\leq)
are almost well-orders. Then there is a unique maximal order-isomorphism, from a transitive subdomain of
A
to a transitive subdoman of
B
. Maximality is characterized by either full domain or full image.

This results from the recursion condition
R[f,a]:=\min[B-f[(\#<a)]]
. ∎

5.3.
Universal almost well-order

In this section the domain
\mathbb{W}
is defined, and shown to be universal for almost well-orders.
\mathbb{W}
corresponds to the “ordinal numbers” of classical set theory, cf. Jech
[
Jech
]
, §2.

Definition

\mathbb{W}
is the quotient of an equivalence relation on a generator
\mathbb{W}\mathbb{O}
.

(1)

the object generator is defined by:
(A,\leq){\in\in}\mathbb{W}\mathbb{O}
means “
(A,\leq)
is a well-order”;

(2)

\textsf{leq}[(A,\leq),(B,\leq)]:=(\textsf{dom}[r]{\,?\!\!=\,}A)
, where
r\colon A\to B
denotes the maximal partially-defined order-isomorphism described just above.

We expand on (2). We think of
\textsf{dom}[r]
as a binary function on
A
. Since
A
is a set the comparison of binary functions
\textsf{dom}[r]{\,?\!\!=\,}A
is a binary function of
\textsf{dom}[r]
.
Finally, since
r
is uniquely determined by
A,B
and their well-orders,
\textsf{dom}[r]{\,?\!\!=\,}A
is a binary function of
A,B
.

(\mathbb{W}\mathbb{O},\textsf{leq})
is a linear pre-order. Let
(\mathbb{W},\leq)
denote the quotient domain with its induced linear order. The elements of the domain
\mathbb{W}
are order-isomorphism classes, and we denote the class represented by
(A,\leq)
by
\boldsymbol{\langle}A,\leq\boldsymbol{\rangle}
(angle brackets).

Canonical embeddings

Recall that if
(A,\leq)
is almost well-ordered and
x\in A
then
(\#<x)\subset A
, with the induced order, is well-ordered. It therefore determines an equivalence class
\boldsymbol{\langle}(\#<x),\leq\boldsymbol{\rangle}\in\mathbb{W}
. This defines the
canonical embedding

\omega\colon A\to\mathbb{W}
. Explicitly,
\omega[x]=\boldsymbol{\langle}(\#<x),\leq\boldsymbol{\rangle}
.

Theorem
.

( Universality of
\mathbb{W}
)

(1)

(\mathbb{W},\leq)
is almost well-ordered, but not well-ordered because it does not support quantification;

(2)

If
(A,\leq)
is almost well-ordered then the canonical embedding
\omega\colon A\to{W}
defined above is an order-isomorphism to a transitive subdomain, and
\omega
is uniquely determined by this property;

(3)

If
A
is a set then the image of
\omega
is
(\#<\boldsymbol{\langle}A,\leq\boldsymbol{\rangle})
; if
A
is not a set then the image is all of
\mathbb{W}
.

In (3) we caution that there is no binary function on subdomains of
\mathbb{W}
that detects whether or not they are sets.

Proof of the theorem

First, the properties of maximal order-isomorpisms described in §
5.2
imply that
(\mathbb{W},\leq)
is a linear pre-order.
We next see that it is almost well-ordered. If
a\in\mathbb{W}
then
a
is an equivalence class of well-ordered domains
\boldsymbol{\langle}A,\leq\boldsymbol{\rangle}
. As explained in “canonical embeddings”, there is an order-preserving bijection, from
(A,\leq)
to the subdomain

(\#<\boldsymbol{\langle}A,\leq\boldsymbol{\rangle})\subset\mathbb{W}.

Since
A
is well-ordered, so is the indicated subdomain of
\mathbb{W}
. But this is the definition of “almost” well-order.

This proves all but the second halves of (1) and (3). We take these up next.

Quantification fails in
\mathbb{W}

To begin, we make explicit that quantification is the issue.

First, an almost well-order is a well-order if and only if the domain supports quantification.
One direction is clear: a well-order is a set by definition. For the converse suppose
(A,\leq)
is an almost well-order,
A
is a set, and suppose
h
is a transitive binary subdomain of
A
. Since
A
is a set,
\textsf{not}[h]{{\,?\!\!=\,}}\emptyset
is a binary function that returns either
yes
, in which case
h=A
, or
no
, in which case
\exists x\mid h[x]=\textsf{no}
. Transitive implies that
h[y]=\textsf{no}
for
y\leq x
, so
h
has domain contained in
(\#<x)
. But
(\#<x)
is well-ordered, so either
h{\,?\!\!=\,}(\#<x)
or there is
x>z
so that
h{\,?\!\!=\,}(\#<z)
. In either case
h
has the form required to show
A
is well-ordered.

Next we use a form of the Burali-Forti paradox to show that
(\mathbb{W},\leq)
cannot be a well-order. If it were, then by definition of
\mathbb{W}
there would be
x\in\mathbb{W}
and an isomorphism
\omega\colon\mathbb{W}\simeq(\#<x)
. But then,
\omega^{2}
gives an isomorphism of
\mathbb{W}
with
(\#<\omega[x])
. Since
\omega[x]<x
, this contradicts the fact that isomorphism classes of well-orders correspond
uniquely
to elements of
\mathbb{W}
. Thus
(\mathbb{W},\leq)
cannot be a well-order, and therefore does not support quantification.

The final part of the theorem is to see that if
A
is an almost well-order and not a set then the canonical embedding is an isomorphism to
\mathbb{W}
. Suppose there is
x
not in the image. The image is transitive, so must be contained in
(\#<x)
. But this is well-ordered, so a transitive subdomain of it must be a set. This contradicts the hypothesis that
A
is not a set. We conclude that there cannot be any such
x
, and therefore
\omega
is onto. It follows that it is an order-isomorphism.

This completes the proof of the theorem.∎

5.4.
Existence of well-orders

We review a crucial classical consequence of the axiom of choice, and get some information about
\mathbb{W}
.

Proposition
.

Suppose
A
is a logical domain.

(1)

If
A
is a set then it has a well-order.

(2)

if
A
is known to not be a set then there is an injection
\mathbb{W}\to A
.

(3)

There is no binary fuction on domains that detects which of these alternatives holds.

Proof: As above,
\textsf{sP}[A]
denotes the binary functions on
A
whose supports are sets, and
(\textsf{sP}[A]\textsf{ and\,}(\#\neq A))
the ones whose support is not all of
A
. Comment on the logic: if
A
is a set then
\textsf{sP}[A]=\textsf{P}[A]
is a logical domain and
\#\neq A
is a binary function on it. If
A
is
not
a set then
\textsf{P}[A]
is not a logical domain. But
(\#\neq A)
is still a binary function because it is always ‘yes’.

Define a
choice function
for
A
to be
ch\colon(\#\in\textsf{sP}[A]\mid\#\neq A)\to A
, satisfying
h[ch[h]]=\textsf{no}
(ie.
ch[h]
is in the complement of
h
). The axiom of Choice implies that any
A
has a choice function, as follows:
Define
c\colon(\textsf{sP}[A]\textsf{ and\,}(\#\neq A))\times A\to\textsf{y/n}
by
c[h,a]:=\textsf{not}[h[a]]
. The projection of (the support of)
c
to
\textsf{sP}[A]
is known to be onto, due to the “not all of
A
” condition. According to Choice, there is a section of this, and sections are exactly choice functions.

We now set up for recursion. Fix a choice function and
define a condition
R\colon\textsf{tfn}[\mathbb{W},A]\times A\to A
, where ‘
\textsf{tfn}[\mathbb{W},\#]
’ denotes partially-defined functions with transitive domain, by:

R[f,a]:=ch[\textsf{im}[f\upharpoonright(\#<a)]]).

In words,
f[a]
is the chosen element in the complement of the image of the restriction
f\upharpoonright(\#<a)
.

This is clearly a recursion condition. We conclude that the partially-defined functions
r\colon\mathbb{W}\to A
satisfying:

(1)

\textsf{dom}[r]\subset\mathbb{W}
is transitive;

(2)

f[a]=R[r\upharpoonright(\#<a),a]
holds for all
a\in\textsf{dom}[r]
.

form a linearly-ordered domain with a maximal element, and
r
is maximal if and only if either
\textsf{im}[r]=A
or
\textsf{dom}[r]=\mathbb{W}
.

If
\textsf{dom}[r]=\mathbb{W}
then
r
gives an injective function
\mathbb{W}\to A
. We will see, just below, that this implies
A
cannot be a set. If
\textsf{dom}[r]\neq\mathbb{W}
then
r
gives a bijection from a transitive proper subdomain of
\mathbb{W}
to
A
. But a transitive proper subdomain has a well-order, so
A
has one also.
∎

5.5.
Binary subdomains

Proposition
.

Subdomains of sets or of
\mathbb{W}
are binary

The hereditary aspect of this property shows that the set case is implied by the
\mathbb{W}
case, but we include it in the statement for clarity.

Proof:
Abbreviate “all subdomains of
A
are binary” to “
A
is all-binary”. The first observation is that this property is hereditary in the sense that if
X\subset B\subset A
and
B
is binary in
A
, then
X
is binary in
B

\iff
it is binary in
A
. In particular if
f\colon A\to\textsf{y/n}
detects
X
in
A
then the restriction
f\upharpoonright B
detects
X
in
B
.

The next step is to contradict the existence of
a\in\mathbb{W}
such that
(\#<a)
contains a non-binary domain. The observation above implies “
(\#<b)
is all-binary” is a transitive property, so if there is a non-binary
a
then there is a least one. Denote it by
a
. We rule out possibilities.

(1)
a
cannot be finite. The hypothesis of Two implies the two-element domain
y/n
is all-binary, and finite domains follow from this.

(2)
a
must be a limit. If not then
a-1
is defined, and since
a
is infinite there is a bijection
(\#<a)\simeq(\#\leq a-1)
. By minimality,
(\#<a-1)
is all-binary. But “all-binary” is a bijection invariant, so
a
is also all-binary, which contradicts the hypothesis about
a
.

(3) If
a
is the limit of all-binary elements then it is all-binary. Suppose
X\subset(\#<a)
. If
b<a
then
X\cap(\#<b)
is binary in
\#<b
. Let
f_{b}\colon(\#<b)\to\textsf{y/n}
be a binary function that detects it. The observation about restrictions at the beginning of the proof implies that if
y<c<b<a
then
f_{b}[y]=f_{c}[y]
. Now define
f\colon(\#<a)\to\textsf{y/n}
by:
f[y]=f_{b}[y]
for any
b
with
y<b<a
. Since
a
is a limit there always is such
b
, so
f
is well-defined, and detects
X
. This implies

a
is all-binary, which contradicts the supposition that there is
a\in\mathbb{W}
that is not all-binary.

(4) According to the above, for every
a\in\mathbb{W}
,
(\#<a)
is all-binary. But
\mathbb{W}
is the limit of these, so the argument in (3) implies
\mathbb{W}
is also all-binary.∎

5.6.
Identifying
\mathbb{W}

A subdomain
D\subset\mathbb{W}
is said to be
cofinal
if it is unbounded. Explicitly, for every
a\in\mathbb{W}
there is
b\in D
such that
b\geq a
. See Jech
[
Jech
]
§3.6.
Note that
\textsf{P}[\mathbb{W}]
is the disjoint union of bounded and cofinal functions, but there is no binary function on
\textsf{P}[\mathbb{W}]
that identifies the two pieces.

Proposition
.

If
A
is a logical domain and
f\colon A\to\mathbb{W}
is a function whose point inverses are sets, then the following are asserted to be equivalent:

(1)

A
is not a set (does not support quantification);

(2)

the image of
f
is cofinal in
\mathbb{W}
; and

(3)

there is a bijection
D\simeq\mathbb{W}
.

Note these equivalences are assertions: if one is known then the others are known, but there is no binary function that detects them.

Proof: Since the point inverses are sets they have well-orders. Choice enables us to choose a well-order
(f^{-1}[a],\leq_{a})
, for every
a
. Now define an order on
A
by:

(x\leq y):=(f[x]>f[y])\textsf{\,or\,}(f[x]=f[y]\textsf{ and\,}(x\leq_{f[x]}y)).

This is easily seen to be an almost well-order, and
f
is nondecreasing.
The classifying function for this well-order is an order-preserving injection with transitive image,
\omega\colon A\to\mathbb{W}
. The Union lemma implies
A
is not a set if and only if the image of
\omega
is
\mathbb{W}
. This gives the implications in the Proposition, except for: if
\textsf{im}[f]\subset\mathbb{W}
is cofinal then it is not a set.

If
D\subset\mathbb{W}
is cofinal then
h[a]:=\min[\#\in D\textsf{ and\,}\#\geq a]
defines a function
\mathbb{W}\to D
. The point-inverses are bounded, and therefore sets. The domain of
h
is not a set so the Union lemma implies
D
is not a set. ∎

6.
Cardinals

Cardinals in set theories have been studied for well over a century. Here we turn this around by developing cardinality for relaxed sets, and then using it to study set theories.

6.1.
Definitions

An element
a\in\mathbb{W}
is a
cardinal element
if
b<a
implies that there is
no
injective function
(\#<a)\to(\#<b)
. A
cardinal well-order
is one whose equivalence class is a cardinal element. Note that
a
is a cardinal element if and only if
(\#<a)
with its induced order is a cardinal well-order.

For this definition to be legitimate in the logic used here we need:

Lemma
.

There is a binary function
?\textsf{inj}\colon\mathbb{W}\times\mathbb{W}\to\textsf{y/n}
such that
?\textsf{inj}[a,b]=\textsf{yes}
if and only if there is an injection
(\#<a)\to(\#<b)
.

Fix
b\in\mathbb{W}
and define a subdomain of
\mathbb{W}
by

\{y\in\mathbb{W}\mid\text{ there is an injective function }(\#<y)\to(\#<b)\}.

If
y\geq z
then the inclusion
(\#<z)\to(\#<y)
is an injective function. It follows that the subdomain is transitive, and given by either the binary function ‘
yes
’ (ie. all of
\mathbb{W}
) or
(\#<c)
for some
c
. ∎

Definition of
\textsf{card}[A]

Suppose
A
is a set. Choose a well-order
(A,\geq)
, then
\textsf{card}[A]
is defined to the the smallest element in
?\textsf{inj}[(A,\geq),\#]
.

Note
(A,\geq)\in?\textsf{inj}[(A,\geq),\#]
, so the latter is nonempty, and a nonempty logical subdomain of
\mathbb{W}
has a least element. Minimality implies that
\textsf{card}[A]
is a cardinal element of
\mathbb{W}
. It also implies that
\textsf{card}[A]
is well-defined (ie. doesn’t depend on the choice of well-order on
A
).

6.2.
Bijections, logicality, and Cantor’s theorem

Lemma
.

Suppose
A
is a set, and
(B,\geq)
is a representative of the equivalence class
\textsf{card}[A]
. Then there is a bijection
A\simeq B
.

Proof: Choose a well-order on
A
. By minimality,
(A,\geq)\geq(B,\geq)
, so there is an inclusion

B\to A
. By definition of
\textsf{card}[A]
, there is an injection
A\to B
. But the Cantor-Bernstein theorem
4.2
then asserts that there is a bijection
A\simeq B
.∎

Corollary
.

There is an injection
A\to B
if and only if
\textsf{card}[A]\leq\textsf{card}[B]
, and a bijection
A\simeq B
if and only if
\textsf{card}[A]=\textsf{card}[B]
.

Cantor’s theorem

Theorem
.

(Cantor) If
A
is a nonempty set then
\textsf{card}[\textsf{P}[A]]>\textsf{card}[A]
.

Proof: The conclusion is equvalent to: there is no surjective function
A\to\textsf{P}[A]
. Suppose
p\colon A\to\textsf{P}[A]
is a function. Define a binary function
h\colon A\to\textsf{y/n}
by
h[a]:=\textsf{not}[(p[a])[a]]
. Then
h
is not in the image of
p
, so
p
is not surjective.∎

6.3.
Hessenberg’s theorem

In the classical development this is a key fact about cardinality of sets. Here it is a key ingredient in showing ‘relaxed sets’ have the properties expected of sets. We go through the proof to check the use of quantification, and because the traditional proof is somewhat muddled by the identification of sets and elements.

The canonical order

Suppose
(A,\leq)
, is a linear order and
A\supset B
. The
canonical
order on
A\times B
is a partially-symmetrized version of lexicographic order, as follows:

First define the maximum function
{\textsf{max}}\colon A\times B\to A
by
(a,b)\mapsto\textsf{max}[a,b]
.
This induces a pre-linear order on
A\times B
, namely

(a_{1},b_{1})\prec(a_{2},b_{2}):=\textsf{max}[a_{1},b_{1}]<\textsf{max}[a_{2},b_{2}].

The canonical order refines this to a linear order as follows: Fix
c\in A
, then the elements of
A\times B
with max equal to
c
have the form
(\#<c,c)
or
(c,\#\leq c)
. Each of these is given the order induced from
A
, and pairs of the first form are defined to be smaller than pairs of the second form. The canonical order is denoted by
\leq_{can}
. Note that if
c\notin B
then there are no elements of the first form in
A\times B
.

More explicitly,
(a_{1},b_{1})<_{can}(a_{2},b_{2})
means:

\displaystyle(\textsf{max}[a_{1},b_{1}]<\textsf{max}[a_{2},b_{2}])

\displaystyle\textsf{\,or\,}

\displaystyle((\textsf{max}[a_{1},b_{1}]=\textsf{max}[a_{2},b_{2}])

\displaystyle\textsf{ and\,}\bigl((a_{1}<a_{2})\textsf{\,or\,}(a_{2}=a_{1}\textsf{ and\,}b_{1}<b_{2})\bigr).

The following is straightforward:

Lemma
.

If
A,B
are almost well-ordered, then
the canonical order on
A\times B
is an almost well-order.

The classifying function therefore gives an order-preserving injection

\omega\colon(A\times B,\leq_{can})\to(\mathbb{W},\leq)

with transitive image. The main result is a variation on a century-old theorem of Hessenberg (see
[
Jech
]
, Th. 3.5) describing some of these images.

Theorem
.

If
c\in\mathbb{W}
is an infinite cardinal and
d\leq c
is nonzero then

\omega[(\#<c)\times(\#<d),\leq_{can}]=(\#<c)

The maximal case
c=d
is the most useful: it implies that for infinite
A
,
\textsf{card}[A\times A]=\textsf{card}[A]
.

To begin the proof, note the image in
\mathbb{W}
is transitive so is of the form
(\#<w)
for some
w
.
We want to show that
w=c
.

The first step is to note that, since
d>0
,
(\#<c)\times(\#<d)
contains
(\#<c)\times(0)
as an ordered subset.
\omega
is order-preserving on this so the transitive closure contains
\#<c
, and this implies
c\leq w
.

Next we work out the consequences of strict inequality in this last: suppose
c<w
. Since the image is transitive, there is
(x,y)\in(\#<c)\times(\#<d)
with
\omega[x,y]=c
. It follows that there is a bijection from
((\#1,\#2)\leq_{can}(x,y))
to
(\#<c)
, so these have cardinality
c
. Denote the maximum of
(x,y)
by
m
, then
((\#1,\#2)<_{can}(x,y))
is contained in
(\#<m)\times(\#<m)
, which is bijective to
(\#<\textsf{card}[m])\times(\#<\textsf{card}[m])
. But
\textsf{card}[m]\leq m
so
\textsf{card}[m]<c
. Putting these together we see that if
c<w
then there is an infinite cardinal
n:=\textsf{card}[m]
with
n<c
and
\omega[(\#<n)\times(\#<n)]]\geq c
.

If the Proposition is false there is a least infinite cardinal for which it fails; use this as
c
. The above shows that failure at
c
implies there is an infinite cardinal
n<c
so that
\textsf{card}[(\#<n)\times(\#<n)]\geq c
. But this means the Proposition fails at
n
, contradicting the minimality of
c
. Therefore the theorem must be true.∎

Products and unions

For traditional set theories this has been known for well over a century:

Proposition
.

Suppose
A,B
are sets, and at least one is infinite. Then

(1)

\textsf{card}[A\times B]=\max[\textsf{card}[A],\textsf{card}[B]]
, and

(2)

if
A,B\subseteq D
then
\textsf{card}[A\cup B]=\max[\textsf{card}[A],\textsf{card}[B]]
.

Proof: suppose
\textsf{card}[A]\geq\textsf{card}[B]
, so
\max[\textsf{card}[A],\textsf{card}[B]]=\textsf{card}[A]
. Then

\textsf{card}[A]\leq\textsf{card}[A\times B]\leq\textsf{card}[A\times A]=\textsf{card}[A]

The last step being the Proposition above. This gives (1).

For (2),
\textsf{card}[A]\leq\textsf{card}[A\cup B]\leq\textsf{card}[A\times B]=\textsf{card}[A]
, by (1). ∎

6.4.
The Beth function

Only one cardinal function is needed here.

‘Beth’ (
\beth
) is the second character in the Hebrew alphabet, and is used to denote the “iterated powerset function”.
\beth
is briefly mentioned in
[
Jech
]
§5, p. 55. This, and the associated rank function, play major roles in the construction of §

.

Proposition
.

There is a unique function
\beth\colon\mathbb{W}\to\mathbb{W}
satisfying:

(1)

if
a=0
then
\beth[a]=\textsf{card}[N]
;

(2)

if
a>0
is not a limit and
\beth[a-1]
is defined, then
\beth[a]=\textsf{card}[\textsf{P}[\beth[a-1]]]
; and

(3)

if
a\in\mathbb{W}
is a limit then
\beth[a]=\sup[\beth[\#<a]]
.

‘
\sup
’ in (3) is the ‘supremum’, which is a convenient shorthand for the minimum of elements greater or equal all elements in the set:

\sup[A]:=\min[\#\mid\forall a\in A,a\leq\#].

In the special case
A
is transitive, if
A
has no maximal element then
\sup[A]=\lim[A]
. If
b\in A
is maximal then
\sup[A]=b
.

It is straightforward to formulate a recursive condition on partially defined functions so that conditions (1)–(4) correspond to fully recursive. Existence of a maximal such function therefore follows from recursion. ∎

Limits and strong limits

Recall that
a\in{\mathbb{W}}
is a
limit
if
(\#<a)
does not have a maximal element. It is a
strong limit
if
b<a
implies
\textsf{card}[\textsf{P}[\#<b]]<a
.

Proposition
.

(1)

b\leq\beth[b]
;

(2)

a\in\mathbb{W}
is a strong limit if and only if
a=\beth[b]
for either
b=0
or
b
a limit;

(3)

if
b
is a limit then the image
\beth[\#<b]
is cofinal in
(\#<\beth[b])
.

Proof: (1) is standard, and easily proved by considering the least element that fails.

For (2), first note that
\beth
is non-decreasing, so
(\beth^{-1}[\#]<a)
is transitive and therefore of the form
(\#<b)
. Since
b\notin(\beth^{-1}[\#<a])
,
\beth[b]\geq a
.

Now we suppose
a
is a strong limit and show
b
is a limit. If not then
(\#<b)
has a maximal element,
b-1
.
\beth[b-1]<a
, so by definition of strong limit
\textsf{card}[\textsf{P}[\#<\beth[b-1]]]<a
. The left side of this is the definition of
\beth[b]
, so this shows
\beth[b]<a
. This contradicts the conclusion
\beth[b]\geq a
just above. We conclude
(\#<b)
does not have a maximal element, so
b
is a limit.
To complete the implication we show
\beth[b]=a
.
\beth[\#<b]
is bounded by
a
, so
\sup[\beth[\#<b]]
is defined and is
\leq a
. But, since
b
is a limit, this is also the definition of
\beth[b]
. Thus
\beth[b]\leq a
. Combining with the inequality above gives
\beth[b]=a
, as required.

For the other direction of ‘if and only if’, suppose
b
is a limit. We want to show that
a=\beth[b]:=\sup[\beth[\#<b]]
is a strong limit. Suppose
x<a
. Then there is
y<b
with
x\leq\beth[y]
. Thus
\textsf{card}[\textsf{P}[\#<x]]\leq\textsf{card}[\textsf{P}[\#<\beth[y]]]
. Next, since
b
is a limit,
y+1<b
. But the definition of
\beth
gives
\textsf{card}[\textsf{P}[\#<\beth[y]]]=\beth[y+1]
. Since
\beth[y+1]<\sup[\beth[\#<b]]=a
, we get
\textsf{card}[\textsf{P}[\#<x]]<a
. This verifies the definition of strong limit.

The cofinality conclusion follows from the definition of ‘
\sup
’. ∎

A corollary of (3) in the Proposition is that the cofinalities are the same:
cf[\beth[b]]=cf[b]
. Therefore the strong limit
\beth[b]
is regular if and only if if
b=\beth[b]
, and
b
is regular.

Beth rank

Rank plays a central role in the construction in the next Section. This rank follows the
\beth
function closely, and is a bit different from the rank function defined in
[
Jech
]
§6.2: it starts with
\textsf{rank}=0\Leftrightarrow
‘finite’, rather than
\textsf{rank}=0\Leftrightarrow
‘empty’, and otherwise differs by
+1
.

The (Beth)
rank
is the function
\mathbb{W}\to\mathbb{W}
given by

\textsf{rank}[x]:=\min[(\#\mid x<\beth[\#])].

Note that if
a
is a limit then there are no elements of rank
a
. The reason is that
\beth[a]=\sup[\beth[\#<a]]
, so if
x<\beth[a]
then there is some
b<a
with
x<\beth[b]
. Thus
\textsf{rank}[x]\leq b<a
, and in particular
\textsf{rank}[x]\neq a

These hidden values come into play in ranks of binary functions, defined next.
If
h\colon\mathbb{W}\to\textsf{y/n}
has bounded (
\Leftrightarrow
set) support then define

\textsf{rank}[h]:=\sup[\textsf{rank}[(\#\mid h[\#])]].

Examples and special cases

If
h[\#]=(\#=a)
, the function that detects
a
, then the ranks of
a
and
h
are the same. More generally,
h[a]\Rightarrow(\textsf{rank}[a]\leq\textsf{rank}[h])
.

If
h
is cofinal in

then
\textsf{rank}[h]=\textsf{rank}[g]
.

Finally, consider the binary function
(\#<a)
.
\textsf{rank}[\#<a]=\textsf{rank}[a]

unless

for some
b
, in which case
\textsf{rank}[\#<a]=b
and
\textsf{rank}[a]=b+1
.

7.
The universal well-founded pairing

This section provides an interface between the present theory and traditional axiomatic set theory.
The result is roughly that the universal well-founded pairing is a ZFC set theory, and a domain is a relaxed set if and only if there is a bijection with a set in this ZFC theory.

7.1.
Main result

Definitions

Most of these are standard, but included for precision.
Suppose
(A,\epsilon)
is a binary pairing, and
A\supset B
is a subdomain.

(1)

As with well-orders, ‘
\epsilon
-transitive’ means if
b\in B
and
\epsilon[a,b]=\textsf{yes}
then
a\in B
.

(2)

An element
c\in A-B
is
minimal
if
\epsilon[a,c]\Longrightarrow a\in B
.

(3)

A pairing
(A,\epsilon)
is
well-founded
if

A
is a set, and if
B\subset A
is transitive with
A-B
nonempty then there is a minimal element in
A-B
.

(4)

For the “almost” version we need the
transitive closure
of
B\subset A
. This is the smallest transitive subdomain containing
\epsilon[b,\#]
for all
b\in B
. More explicitly, it consists of
a
such that there is a finite sequence
c_{0},c_{1},\dots,c_{n}
,
n\geq 1
, with
c_{0}\in B
,
c_{n}=a
, and
\epsilon[c_{i+1},c_{i}]=\textsf{yes}
. We denote this by
\textsf{tcl}[B]
.

(5)

Now we define a pairing
(A,\epsilon)
to be
almost
well-founded if the restriction to the transitive closure of any point,
(\textsf{tcl}[a],\epsilon)
, is well-founded.

Theorem
.

Some of the terms are defined below

Existence:

There is a pairing
\;\epsilon\colon\mathbb{W}\times\mathbb{W}\to\textsf{y/n}
so that the adjoint of the opposite gives a bijection
\epsilon^{opadj}\colon\mathbb{W}\to\textsf{bP}[\mathbb{W}]
, such that

(1):

the restriction
\mathbb{N}\to\textsf{bP}[\mathbb{N}]
is the canonical order-preserving isomorphism; and

(2):

if
x\notin N
then
\textsf{rank}[\epsilon^{opadj}[x]]=\textsf{rank}[x]-1
.

Universality:

Suppose
(A,\alpha)
is an almost well-founded pairing, and the adjoint of the opposite
\alpha^{opadj}\colon A\to\textsf{P}[A]
is injective. Then there is a unique injective function
\omega\colon A\to\mathbb{W}
with
\epsilon
-transitive image, giving a morphism of pairings from
\alpha
to the restriction of
\epsilon
to
\textsf{im}[\omega]
.

Set theory:

(\mathbb{W},\epsilon)
satisfies the ZFC-1 axioms, where “-1” indicates removing the first-order logic restrictions in the Separation and Replacement axioms.

Clarifications: the adjoint of the opposite is the function
a\mapsto\epsilon[\#,a]
.
\mathbb{N}
is the natural numbers. The opposite adjoint of ‘
\epsilon
’ takes elements of rank 1 to the cofinal functions on
\mathbb{N}
. Technically, all functions on
\mathbb{N}
have rank 0, but the bounded ones are accounted for by Existence (1).
In Existence (2), recall that ranks of elements cannot be limits, so
\textsf{rank}[x]-1
is defined.

It is not used here, but two such pairings ‘
\epsilon
’ differ by a bijection
\mathbb{W}\to\mathbb{W}
that is the identity on
N
and preserves the rank function.

The universality property is a version of Mostowski collapsing (
[
Jech
]
, §6.15). The injective-adjoint condition is traditionally called “extensional”, and corresponds to the set-theory axiom that sets are determined by their elements.

Proof of Existence

We will show that for every
a
there is a bijection, from elements of rank
a+1
to binary functions of rank
a
. The rest of the proof is short: According to the axiom of choice we can make a simultaneous choice of bijections for all
a
. These fit together to give a bijection
\mathbb{W}\to\textsf{bP}[\mathbb{W}]
. This is the opposite adjoint of a pairing with properties (1) and (2).

Now we activate this sketch by showing that there are bijections as claimed.
Suppose
a\in\mathbb{W}
. There is a bijection from elements of rank
a+1
to functions of rank
a
if these collections have the same cardinality.

The elements of rank
a+1
are
(\beth[a]\leq\#<\beth[a+1])
. This is the complement of
(\#<\beth[a])
in

(\#<\beth[a+1])
. Since
\beth[a+1]=\textsf{card}[\textsf{P}[\#<\beth[a]]]
, we are removing a set of smaller cardinality.
According to §
6.3
, this does not change cardinality. The cardinality of the collection of elements is therefore
\textsf{card}[\textsf{P}[\#<\beth[a]]]
.

There are two cases for functions. Suppose
a
is not a limit. Then functions of rank
a
are the complement of
\textsf{P}[\#<\beth[a-1]]
in
\textsf{P}[\#<\beth[a]]
. Again the smaller subdomain has smaller cardinality, so removing it does not change cardinality. Cardinality of the functions is therefore
\textsf{card}[\textsf{P}[\#<\beth[a]]]
, same as the elements.

Now suppose
a
is a limit. The functions on
\#<\beth[a]
of rank
a
are the cofinal ones. These are the complement of the bounded functions:
\textsf{cfP}[\#<\beth[a]]=\textsf{P}[\#<\beth[a]]-\textsf{bP}[\#<\beth[a]]
. We want to show that removing the bounded functions does not change the cardinality. For this it is sufficient to show that the cardinality of the cofinal functions is at least as large as that of the bounded ones. This is so because there is an injection
\textsf{bP}[\#<\beth[a]]\to\textsf{cfP}[\#<\beth[a]]
defined by
h\mapsto\textsf{not}[h]
. The conclusion is that the cardinality of the functions is
\textsf{card}[\textsf{P}[\#<\beth[a]]]
, again same as the elements.

This completes the existence part of the Theorem.

7.2.
Well-founded recursion, and universality

See Jech,
[
Jech
]
p. 66.

Suppose
(A,\lambda)
is an almost well-founded pairing.
As in §
5.2
, a
recursion condition
is a partially-defined function
R\colon\textsf{tfn}[A,B]\times A\to B
, where ‘
tfn
’ denotes partially-defined functions with
\lambda
-transitive domains.

Again as in §
5.2
, a partially-defined function
f\colon A\to B
is
R
-
recursive
if:

(1)

\textsf{dom}[f]
is
\lambda
-transitive; and

(2)

for every
c\in\textsf{dom}[f]
,
f[c]=R[(f\upharpoonright(\textsf{tcl}[c]-c),c]
.

Then, exactly as in §
5.2
, there is a unique maximal
R
-recursive partially-defined function
A\to B
. ∎

For the proof of universality of
\epsilon
, we suppose
(A,\lambda)
is an almost well-founded pairing and define a recursion condition
R\colon\textsf{tfn}[A,\mathbb{W}]\times A\to\mathbb{W}
by:

(1)

(f,a)\in\textsf{dom}[R]
if the image of
f
is transitive and
(\lambda[\#,a])\subset\textsf{dom}[f]
;

(2)

In this case
R[f,a]:=(\epsilon^{opadj})^{-1}[(\lambda[f^{-1}[\#],a])]
.

Comment

We unwind (2). Given
(f,a)
, define a binary function on
\mathbb{W}
by
\#\mapsto\lambda[f^{-1}[\#],a]
. When this is used in the proof,
f
is injective and the inverse function can be taken literally. To avoid building injectivity into the definition we define
\lambda[a,C]
, where
C
is a subdomain of
A
(here
f^{-1}[\#]
), by:

\lambda[a,C]:=(\exists c\in C\mid\lambda[a,c]=\textsf{yes}).

The above definition then makes sense if the
f^{-1}[\#]
are subsets rather than just points. In any case it is easy to see that this binary function is bounded.

Recall that the opposite adjoint
\epsilon^{opadj}\colon\mathbb{W}\to\textsf{bP}[\mathbb{W}]
is a bijection. Therefore there is
b\in\mathbb{W}
so that
\epsilon\!\![\#,b]=\lambda[f^{-1}[\#],a]
.
R[f,a]
is defined to be this element
b
.

Note that undoing adjoints gives
\lambda[\#,a]=\epsilon\!\![f[\#],R[f,a]]
. If
f[a]=R[f,a]
then this becomes
\lambda[\#,a]=\,\epsilon\!\![f[\#],f[a]]
, which is part of the condition that
f
is a morphism of pairings. Note also that
\epsilon\!\![\#,R[f,a]]\subset\textsf{im}[f\upharpoonright(\textsf{tcl}[a]-a)]
, so the image is still transitive after extending
f
by
f[a]=R[f,a]
.

We return to the proof. By recursion, there is a unique maximal
R
-recursive function
f\colon A\to\mathbb{W}
.
The maximality criterion for recursion implies the maximal has domain
A
. As noted above, the recursion condition implies that
f
is a morphism of pairings
(A,\lambda)\to(\mathbb{W},\in)
.

In general, morphisms of pairings need not be injective. However it is straightforward to see that if the opposite adjoint
\lambda^{opadj}\colon A\to\textsf{P}[A]
is injective then
f
is injective. This completes the proof of the uniqueness part of the theorem.

7.3.
Reformulation of the ZFC axioms

A traditional set theory is a Universe
U
of potential elements and a binary pairing ‘
\epsilon
’.
We use the prefix form: define
\epsilon\colon U\times U\to\textsf{y/n}
by
\epsilon[a,b]:=a\,\epsilon\,b
.

A
set
in the theory is a binary function on
U
of the form
\#\mapsto\epsilon[\#,a]
, for some
a\in U
.

Axioms

Given all this, we translate the
ZFC axioms described in
[
Jech
]
Ch. 1:

(1)

(Well-founded, or Regular)
\epsilon
is almost well-founded.

(2)

(Extentionality)
\epsilon[\#,a]=\epsilon[\#,b]
implies
a=b
(see note 3);

(3)

(Union)
!\exists\,(\cup a)]\in U
such that
\#,\epsilon[\cup a]=(\epsilon*\epsilon)[\#,a]
.
\epsilon*\epsilon
is the composition of pairings, defined by
(\epsilon*\epsilon)[\#,a]:=(\exists b\mid\epsilon[\#,b]\textsf{ and\,}\epsilon[b,a])
.

(4)

(Powerset)
!\exists\,\textsf{P}[a]\in U
such that
\epsilon[b,\textsf{P}[a]]=(\epsilon[\#,b]\subset\epsilon[\#,a])
;

(5)

(Infinity) There is
a
with
\epsilon[\#,a]
infinite;

(6)

(Choice) There is a partially-defined function
ch\colon U\to U
with domain
(a\in U\mid\epsilon[\#,a]\neq U)
satisfying
\epsilon[ch[a],a]=\textsf{no}
(see note 4);

(7)

(Separation) If
P
is a binary function on
U
given by a first-order formula in the set operations, then the intersection of a set with
P
is also a set (see note 5);

(8)

(Replacement) Suppose
A
is a set and
f\colon A\to U
is a ZFC function (see note 5). Then the image of
f
is a set.

Notes

(1)

‘Well-founded’ is usually put near the end of axiom lists. The universality theorem indicates that it is a key ingredient, so we put it first.

(2)

External
quantification requires that there be a binary function, defined on
all possible
functions
A\to\textsf{y/n}
, that detects the empty function. The
Internal
quantification of ZFC requires only that
\emptyset
be detectable among functions of the form
\epsilon[\#,b]
. There may be many fewer of these so, in principle, there might be theories with sets that support internal quantification but not external. This seems unlikely, but if it happens then we discard such sets.

(3)

The domain
U
may not support quantification, so we may not be able to identify functions
\epsilon[\#,a]
among all possible binary functions on
U
. But we can identify them

within
functions of the form
\epsilon[\#,x]
as follows.
\epsilon[a,\#]=\epsilon[b,\#]
means:
(\forall x\in\epsilon[a,\#])(\epsilon[b,x]=\textsf{yes})
, and similarly
(\forall x\in\epsilon[b,\#])(\epsilon[a,x]=\textsf{yes})
.

(4)

In this formulation the choice function provides an element
not
in the given set, rather than (as more usual) one in the set. This is the form used to show
U
has an almost well-order, which implies any other form of Choice one might want. Note that if
U
does not support quantification then “
\epsilon[\#,a]\neq U
” does not make good sense. In this case omit this condition: it is redundant anyway because
\epsilon[\#,a]
is assumed to be a set, and therefore cannot be all of
U
.

(5)

The objective of the Separation and Replacement axioms is to ensure there are enough sets to transact the business of set theory. Sets correspond to binary functions, but these are not primitives in ZFC so one cannot just say “binary function”. Instead one stays within the system by only using binary functions obtained by first-order formulas in the data at hand.

Verifying the axioms

We verify that
(\mathbb{W},\in)
satisfies the translated axioms.

(1)

‘Well-founded’ follows from the fact that the pairing reduces rank, and rank takes values in an almost well-ordered domain.

(2)

The domains
\in\![\#,a]
are relaxed sets because they are bounded in
\mathbb{W}
.

(3)

‘Extension’ is equivalent to injectivity of the adjoint of
\in
, and this is a design requirement in the construction.

(4)

‘Infinity’ is a primitive axiom in the system used here.

(5)

Similarly, ‘Choice’ is a primitive axiom.

(6)

For Separation, note that in the universal theory the intersection of a set with
any
binary function is again a set, so this is certainly true of the ones coming from first-order logic.

(7)

We interpret ‘Replacement’ in a strong way, namely that
any
function
\mathbb{W}\to\mathbb{W}

should take bounded binary functions to bounded binary functions. This is included in §
5.6
.

This completes the verification of the axioms, and the proof of the Theorem.∎

8.
The Coherent Limit Axiom

We begin with the primary formulation and the proof that this characterizes relaxed set theory. This is followed by comments and commonly-used reformulations. The general theme is that if the set theory being used is not the maximal one then additional arguments are needed to see things stay in the subtheory. These arguments are missing from mainstream work, so mainstream methodology is not consistent with a smaller-than-maximal set theory. Historical background and further discussion of “foundations” is given in
[
Quinn2
]

To clarify the statements we denote the universal theory of the previous section by
\Omega
, and let
\Lambda\subset\Omega

\pm 1

Axiom

Suppose

is a well-ordered
\Lambda

for each

\Lambda

then the restriction

.

Then
the formula
F[a]:=f_{c}[a]
for any
c>a
defines a
\Lambda
function
A\to\{0,1\}
.

The ZFC axioms show that if the collection of functions
\{f_{a}\mid a\in A\}
is a
\Lambda
subset of
\textsf{P}_{\Lambda}[A]
, then
F
is a
\Lambda
function. The hypotheses of the axiom do not imply this.

Proposition
.

\Lambda
is (a truncation of)
\Omega
if and only if it satisfies the Coherent Limit axiom.

A “truncation” is the collection of sets with cardinality less than
k
, where
k
is a regular strong-limit cardinal. As is well known, this is also a ZFC set theory.

Proof

If
\Lambda
is a truncation of
\Omega
then the axiom is a very special case of the union lemma.

For the converse, “not a truncation” means there is a
\Lambda
-set
A
that contains an non-
\Lambda
-set. Equivalently, there is an
\Omega
function
F\colon A\to\{0,1\}
that is not a
\Lambda
function.

Next,
A
is well-ordered, and we may assume that it is minimal in the sense that if
a\in A
then every
\Omega
function
(\#<a)\to\{0,1\}
is a
\Lambda
function. If not, then replace
A
by
(\#<b)
where
b
is the minimal element so that
(\#<b)
has this property. In this case the non-
\Lambda
function
F
satisfies the hypotheses of the axiom, but not the conclusion. ∎

8.1.
Comments, and equivalent formulations

(1)

The common version has range an arbitrary set
B
rather than just
\{0,1\}
: if
f_{a}\colon(\#<a)\to B
is a family of functions satisfying the coherence condition, then
F[a]:=f_{c}[a]
for any
c>a
defines a function. This is equivalent to the
\{0,1\}
version, so is generally true only in
\Omega
.

(2)

Recursion uses this principle, so if
\Lambda\neq\Omega
then additional argument seems to be needed to show functions defined by recursion are in
\Lambda
. The development in

[
Jech
]
p. 22 has a casual reference to the Replacement axiom that does not seem to be sufficient for this, so as it stands it seems to be incomplete.
A complete argument should at least use the implicit assumption that the recursion condition is a
\Lambda
function.

(3)

If the
f_{a}
are interpreted as sets, then the limit
F
is the union. The union lemma gives the general form: if
A,B
are sets and
\{S_{b}\subset A\}

are subsets indexed by
b\in B
, then
\cup_{b\in B}S_{b}
is an
\Omega
set. To know the union is in
\Lambda
we would need to know that the collection
\{S_{b}\mid b\in F\}
is a
\Lambda
subset of
\textsf{P}_{\Lambda}[A]
. Again ignoring this implicitly puts the outcomes in
\Omega
.

There is a formulation in terms of convergence in
\textsf{P}[A]
. We focus on the natural numbers
A=\mathbb{N}
to
clarify consequences for elementary mathematics. A real number in the unit interval has a base-2 decimal expansion that is a function from positive natural numbers to
\{0,1\}
. Explicitly, if
n\mapsto c_{n}
then the real number is
\sum_{n=1}^{\infty}c_{n}2^{n}
, where the summation notation stands for the limit of the monotone increasing sequence of partial sums. Now note this depends on the set theory:
\Lambda
reals corresponds to
\Lambda
functions
\mathbb{N}^{>0}\to\{0,1\}
. Some ZFC theories have reals strictly smaller than those of
\Omega
, and in these there are
\Omega
functions
\mathbb{N}^{>0}\to\{0,1\}
that are not
\Lambda
functions. The partial sums of the series give a monotone increasing sequence in the
\Lambda
reals that has no limit point. In abstract set theory this is not considered a problem: if the sequence is not a
\Lambda
sequence, then
\Lambda
has no obligation to provide a limit. The downside is that to get limit points in
\Lambda
we would need to verify that the sequences, partial sums, etc. that naturally occur are in
\Lambda
.

Theories with smaller real number systems are not consistent with standard developments of elementary calculus. For instance, for a power series
x\mapsto\sum_{0}^{\infty}a_{n}x^{n}
to define a
\Lambda
function it has to take
\Lambda
reals to
\Lambda
reals. Is it sufficient for the coefficients to be a
\Lambda
sequence? Is the integral of a
\Lambda
function again a
\Lambda
function? Which ordinary differential equations have solutions in the
\Lambda
reals? None of these issues are addressed by standard methodology, so standard treatments implicitly take place in the maximal theory and are not consistent with ZFC alone.

9.
Appendix: relaxed sets without Quantification

Of the primitive hypotheses in §
3
, Two and InfinIty are clearly necessary, and Choice has been extremely well-tested.
The justification for the Quantification Hypothesis (QH) is less clear, and earlier versions of this paper did not include it. In this appendix we describe the changes needed to avoid QH. It turns out the set theory is essentially the same as with QH, and gives no hint QH is in any way problematic. QH streamlines the development and simplifies statements of results, so it is included in the main body of the paper.

9.1.
Outcomes

First, some notation. We say that a logical domain is
Q^{1}
if it supports quantification, §4.3. A domain
A
is
Q^{n}
for
n>1
if it is
Q^{1}
and
\textsf{P}[A]
is
Q^{n-1}
.
Sets
are
Q^{\infty}
domains. The Quantification hypothesis is that
Q^{1}\Rightarrow Q^{\infty}
, so in this case the intermediate notations are unnessary. If not[QH] then there are
Q^{1}
domains that are not
Q^{\infty}
.

If QH fails there is a maximal strong-limit cardinal we denote by
q_{\infty}
.
Q^{\infty}
domains are those with cardinality less than this, and there are finite-quantification domains with larger cardinality. This is a version of von Neumann’s “Axiom of size”. With QH there is no useful analog: a domain must be
Q^{1}
for cardinality to be defined, so if cardinality is defined and QH holds then the domain is already a set.

As in §
5.3
,
\mathbb{W}
denotes the order-equivalence classes of well-ordered
Q^{1}
domains. Let
Q^{j}\subset\mathbb{W}
denote the transitive subdomains that are
Q^{j}
, for
j\geq 1
. Comparing with the definition above we see
Q^{\infty}
=
(\#<q_{\infty})
.

The main construction in §
7
still applies to give a pairing on
Q^{\infty}
that is universal for well-founded pairings on sets. As in the QH case this pairing satisfies the ZFC-1 axioms
except
for the Union axiom. The Union lemma in §
4.4
only gives
Q^{1}
. QH promotes this to
Q^{\infty}
, but not[QH] does not.

The Union axiom is equivalent to regularity of the maximal strong-limit cardinal. Success with the Union axiom in traditional set theory supports adding this as a hypothesis, but we see no reason not to assume QH and get Union for free.

9.2.
Details

The development follows the version above closely, so we describe only the differences.

Hypotheses

Primitive hypotheses assumed here are those of §3.3
except
for the Quantification hypothesis. The Infinity hypothesis must be strengthened to: the natural numbers support infinite-order quantification. If QH holds then this follows from the assumption that it supports first-order quantification, but without QH this must be made explicit.

The
Q^{1}
theory

With one minor exception, all the statements up to §6.4 (The Beth function) hold with “set” replaced by “
Q^{1}

Q^{1}

The minor exception is the statement of Cantor’s theorem in §6.2. The statement is

Q^{2}

A

then there is no surjection

The powerset function ‘Beth’

\beth[a]
is defined recursively by: at non-limit points

If not[QH] then there is a limit element

The maximal domain of

The construction in §7 uses Beth and its associated rank function, and standard facts about cardinality. In not[QH] the same argument gives a universal well-founded pairing
\epsilon\colon Q^{\infty}\times Q^{\infty}\to\textsf{y/n}
with all the same properties except, as noted above, the Union axiom.
