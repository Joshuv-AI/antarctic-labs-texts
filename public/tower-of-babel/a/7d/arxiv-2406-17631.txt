Abstract
A spannning subgraph F F of G G is a { K 2 , C n } \{K_{2},C_{n}\} -factor if each component of F F is either K 2 K_{2} or C n C_{n} . A graph G G is called a ( { K 2 , C n } , n ) (\{K_{2},C_{n}\},n) -factor critical avoidable graph if G − X − e G-X-e has a { K 2 , C n } \{K_{2},C_{n}\} -factor for any S ⊆ V ⁡ ( G ) S\subseteq V(G) with | X | = n |X|=n and e ∈ E ⁡ ( G − X ) e\in E(G-X) . In this paper, we first obtain a sufficient condition with regard to isolated toughness of a graph G G such that G G is { K 2 , C n } \{K_{2},C_{n}\} -factor critical avoidable.
