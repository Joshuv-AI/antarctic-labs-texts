Optimal online Learning using potential functions
Yoav Freund

Abstract
We study regret-minimizing online algorithms based on potential functions. First, we show that any algorithm with a regret bound that holds for any ϵ \epsilon is equivalent to a potential minimizing algorithm and vice versa. Second we should a min-max learning algorithm for known horizon. We show a regret bound that is close to optimal when the horizon is not known. Finally we give an algorithm with second order bounds that characterize easy sequences.

For

1.

The learner chooses a weight function

The

.

4.

The learner incurs an

\ell^{i}=\sum_{j=1}^{N}P(i,j)l_{j}^{i}

The goal of the learner (in the percentile version of the game) is to

Definition 1

Let

A distribution over regrets

\forall R\in\mathbb{R}\;\;{\bf P}_{\rho\sim{\bf\Psi}}\left[\rho\geq R\right]\leq G(R)

A potential function is an increasing function

\phi:\mathbb{R}\to\mathbb{R}

potential functions control the regret by upper bounding the average

{\bf E}_{R\sim{\bf\Psi}}\left[\phi(R)\right]

Definition 2

(Average potential bound (APB))

A distribution over he reals

\Phi\doteq{\bf E}_{R\sim{\bf\Psi}}\left[\phi(R)\right]\leq 1

Potential functions have long been used to design and analyze online
learning algorithms. However, the choice of the potential function has
been somewhat ad hoc. Here we show a strong one to one relationship
between SBR functions and potential functions:

Theorem 1
.

A distribution
{\bf\Psi}
is simultaneously bounded by
B
if and only
if it satisfies the average potential bound with
\phi(R)=B(R)^{-1}

The proof of the theorem is in Appendix

Theorem
1
justifies our focus on

We start with the bounded horizon case. Fixing a potential function at
the end of the game
\phi(T,R)

\Phi(T)=\Phi(T-1)=\cdots=\Phi(0)

This allows us to analyze the game one iteration at a time and

The strategies yielded by the analysis guarantee bounds on the final

, while the learner’s strategy

\Phi(T)\leq\Phi^{\downarrow}
. Unfortunately, these bounds

\Phi^{\uparrow}<\Phi^{\downarrow}
. In other words our

there exist min/max strategies for the integer time game is open.

To find min/max strategies we expand the game. We call the expanded

. The expansion involves giving the
more options to the adversary, but not to the learner. As a result,
any upper bound

that holds for a learner strategy in

The added option for the adversary is to declare, at the beginning of
each iteration, the range of values of the instantanous losses. In the
integer time game this range is set to

We fix the potential at the end of the game
\boldsymbol{\phi}_{\mathcal{T}}\in{\cal P}^{4}

The discrete time game presents the adversary with a dilemma. On the
one hand, The adversary has to declare, on each iteration, an upper bound on the

[-s_{i},s_{i}]

The situation is

We introduce a variant of the game called the

to alleviate this dilemma. In this came the adversary does not
announce the step size and the learner behaves as if
the step size is infinitesimally small. In this case time is advanced according

a regret bound that depends on the cumulative variance and is smaller
for easy, low variance sequences.

We derive a potential function and a corresponding learning algorithm

Divisibility:

There might be other (pure) strategies for the

To close this gap we extend the integer time game into a new game we

We make two additional alterations to the integer time game in order to
keep the game fair. An unfair game is one where one side always wins.
We list the alterations and then justify them.

1.

\mathcal{T}=\sum_{i=0}^{T}s_{i}^{2}

|\ell(i)|\leq s_{i}^{2}

Brownian motion

There seems to be a paradox: the adversary prefers to set
s_{i}>0
as
small as possible. On the other hand, there is no minimal strictly
positive number, so whatever the adversary chooses has to be
suboptimal. In other words, time is not continuous, it increases in
discrete steps. As that is the case, why is brownian motion still
the correct way to compute the potential?

One can use the following argument: the learner knows the range

[-s_{i},+s_{i}]
for the next instantanous losses before it has to choose
the weights he places on the actions. On the other hand, it does not
know the range of the following losses, but he knows that the
adversary always prefers small ranges. The safe thing for the learner
to do is to assume that the following steps will be infinitesmaly
small, i.e. that the future losses form a brownian process

It is well known that the limit of random walks where
s\to 0
and

\Delta t=s^{2}
is the the Brownian or Wiener process
(see
[
15
]
).

An alternative characterization of Brownian Process is

{\bf P}\left[X_{t+\Delta t}=x_{1}|X_{t}=x_{0}\right]=e^{-\frac{(x_{1}-x_{0})^{2}}{2\Delta t}}

The backwards recursion that
defines the value function is the celebrated Backwards Kolmogorov
Equation with no drift and unit variance

\frac{\partial}{\partial t}\phi(t,R)+\frac{1}{2}\frac{\partial^{2}}{\partial R^{2}}\phi(t,R)=0

(51)

Given a final value function with a strictly positive fourth
derivative we can use Equation (

value function for all

9
Anytime potential functions

The results up to this point hold for any potential function in

{\cal P}^{4}
. Given a final potential function
\boldsymbol{\phi}_{\mathcal{T}}\in{\cal P}^{4}
we
can compute the potential for any

and any

using the equation

\phi(t,R)={\cal N}(R_{0},\mathcal{T}-t)\odot\boldsymbol{\phi}_{\mathcal{T}}

(57)

By using uses the
R
-derivative of this potential function to define
the weights the learner guarantees that the final average score is at
most
\phi(0,0)
.

A major limition of this result is that the horizon
\mathcal{T}
is set in
advance. It is desirable that the potential is defined without
knowledge of the horizon. In what follows we show that Hedge and
NormalHedge can both be used in such “anytime” algorithms.

Our solution is based on the observation that a potential function satisfies Eqn (
57
) if and only if it satisfies
the Kolmogorov backwards PDE (
51
):

\frac{\partial}{\partial t}\phi(t,R)+\frac{1}{2}\frac{\partial^{2}}{\partial r^{2}}\phi(t,R)=0

(58)

The potential
\boldsymbol{\phi}_{\mathcal{T}}\in{\cal P}^{4}
defines a boundary condition of the PDE.

We derive our anytime algorithm by finding solutions to the Kolmogorov
PDE that are not restricted in time, and that have a fixed parametric form.
In other words, the evolution of the potential with time is defined by changing the parameter values, without changing the form.

We consider two solutions to the PDE, the exponential potential and
the NormalHedge potential. We give the form of the potential function
that satisfies Kolmogorov Equation
51
, and derive
the regret bound corresponding to it.

The exponential potential function
which corresponds to exponential
weights algorithm corresponds to the following equation

\phi_{\mbox{\tiny exp}}(R,t)=e^{\sqrt{2}\eta R-\eta^{2}t}

Where
\eta>0
is the learning rate parameter.

Given
\epsilon
we choose
\eta=\sqrt{\frac{\ln(1/\epsilon)}{t}}

we get the regret bound that holds for any
t>0

R_{\epsilon}\leq\sqrt{2t\ln\frac{1}{\epsilon}}

(59)

Note that the algorithm depends on the choice of
\epsilon
, in other
words, the bound does
not
hold for all values of
\epsilon
at
the same time.

The NormalHedge value
is

\phi_{\mbox{\tiny NH}}(R,t)=\begin{cases}\frac{1}{\sqrt{t+1}}\exp\left(\frac{R^{2}}{2(t+1)}\right)&\mbox{if }R\geq 0\\
\frac{1}{\sqrt{t+1}}&\mbox{if }R<0\end{cases}

(60)

The function
\phi_{\mbox{NH}}(R,t)
,
restricted to
R\geq 0
is in
{\cal P}^{4}
and is a constant for
R\leq 0
.

The regret bound we get is:

R_{\epsilon}\leq\sqrt{(t+1)\left(2\ln\frac{1}{2\epsilon}+\ln(t+1)\right)}
