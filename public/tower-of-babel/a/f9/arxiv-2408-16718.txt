Introduction

The nonlinear reaction-diffusion equation is the governing equation for many very important nonlinear models that are used to describe various processes in biology, ecology, physics, chemistry, and so on, readers can refer to
[
6
,
12
,
24
,
43
,
49
]
and references therein. For instance in tumor growth, the reaction-diffusion equation with degenerate diffusion in
[
6
,
43
]
simulates that the cell proliferation is governed by the contact inhibition of bio-mechanical form, and the cell division stops as the cell density reaches the critical threshold. In this article, we consider the Cauchy problem of the porous medium type reaction-diffusion equation, written as

\begin{cases}\partial_{t}\rho=\Delta\rho^{m}+\rho g(\rho),\quad&(x,t)\in\mathbb{R}^{n}\times\mathbb{R}_{+},\ n\geq 2,\\
\rho(x,0)=\rho_{0}(x)\geq 0,&x\in\mathbb{R}^{n},\end{cases}

(1.1)

where
\rho\geq 0
denotes the density,
m>1
(slow diffusion) stands for the diffusion exponent, and
g
is a given monotonic decreasing function with the density critical threshold
\rho_{M}>0
satisfying
g(\rho_{M})=0
. The another important variable for the porous medium type equation
\eqref{de}_{1}
is the pressure
P
defined by

P:=\frac{m}{m-1}\rho^{m-1},\quad P(x,0):=P_{0}(x)=\frac{m}{m-1}\rho_{0}^{m-1}\ (\text{initial pressure}).

(1.2)

For convenience, we set

G(P):=g(\rho)\text{ with }G(P_{M})=0,

(1.3)

where
P_{M}
is the corresponding pressure critical threshold given by

P_{M}:=\frac{m}{m-1}(\rho_{M})^{m-1}.

(1.4)

By a direct computation, the equation of the pressure
P
is expressed as

\partial_{t}P=(m-1)P\big(\Delta P+G(P)\big)+\nabla P\cdot\nabla P,\quad(x,t)\in\mathbb{R}^{n}\times\mathbb{R}_{+}.

(1.5)

If the initial density
\rho_{0}\geq 0
is compactly supported, the weak solution
\rho\geq 0
to the Cauchy problem (
1.1
) remains compactly supported for all the time
t>0
; cf.
[
43
]
. Naturally, an interesting and important problem is to study the regularity of free (support) boundary
\partial\{(x,t):\rho(x,t)>0\}
for the Cauchy problem (
1.1
). Indeed, we formally derive from
\eqref{de}_{1}
that

\partial_{t}\rho=\nabla\rho\cdot\nabla P=|\nabla\rho||\nabla P|\quad\text{on }\partial\{(x,t):\ \rho(x,t)>0\},

and the motion of the free boundary
\partial\{(x,t):\ \rho(x,t)>0\}
is determined by Darcy’s law, i.e.,

V(x,t)=\frac{\partial_{t}\rho}{|\nabla\rho|}=|\nabla P(x,t)|\quad\text{on }\partial\{(x,t):\rho(x,t)>0\},

(1.6)

where
V(x,t)
is the outer normal velocity on the free boundary, which was verified in
[
30
]
by the method of optimal transport.

Gavrilut and Morosanuin
[
25
]
established the global well-posedness of the porous medium type reaction-diffusion equation
\eqref{de}_{1}
with the Cauchy-Neumann boundary conditions, and the uniqueness was obtained in
[

through the comparison principle. In addition, for the porous medium type reaction-diffusion equation

We give the definitions of weak solutions for the Cauchy problem (
1.1

Definition 1.1

(Weak solution)
.

Let
\rho_{0}\in L^{1}(\mathbb{R}^{n})
with
0\leq\rho_{0}(x)\leq\rho_{H}
(
\rho_{H}\geq\rho_{M}
). We call that the non-negative function
\rho:\mathbb{R}^{n}\times(0,\infty)\to[0,\infty)
is a weak sub-solution (resp. sup-solution) to the Cauchy problem (
1.1
) for the porous medium type reaction-diffusion equation if it holds for any
T>0
and any non-negative test function
\varphi\in C_{c}^{\infty}(\mathbb{R}^{n}\times(0,T))
that

\begin{cases}\rho\in C([0,T];L^{1}(\mathbb{R}^{n})),\quad\rho^{m}\in L^{2}([0,T];\dot{H}^{1}(\mathbb{R}^{n}))\quad\text{and }\ \ g(\rho)\in L^{\infty}_{loc}(\mathbb{R}^{n}\times[0,T]),&\\
\int_{0}^{T}\hskip-4.0pt\int_{\mathbb{R}^{n}}\rho\partial_{t}\varphi dxdt\geq(\text{resp. }\leq)-\int_{0}^{T}\hskip-4.0pt\int_{\mathbb{R}^{n}}\rho^{m}\Delta\varphi dxdt-\int_{0}^{T}\hskip-4.0pt\int_{\mathbb{R}^{n}}\rho g(\rho)\varphi dxdt.&\\
\end{cases}

(1.10)

Moreover, if (
1.10
) holds, we claim that the corresponding pressure
P=\frac{m}{m-1}\rho^{m-1}
is a weak sub-solution (resp. sup-solution) to the Cauchy problem of the pressure equation (
1.5
). We call
\rho
a weak solution to the Cauchy problem (
1.1
) if and only if
\rho
is both a weak sup-solution and a weak sub-solution to the Cauchy problem (
1.1
).

In the rest of this paper, we use the definition of ball, denoted precisely by

B_{R}(x_{0}):=\{x\in\mathbb{R}^{n}:\ |x-x_{0}|\leq R\},\quad B_{R}:=\{x\in\mathbb{R}^{n}:\ |x|\leq R\}\text{ for }x_{0}\in\mathbb{R}^{n}\text{ and }R>0.

\Omega_{0}:=\{x:\ P_{0}(x)>0\}\text{ is a bounded domain with Lipschitz's boundary},

3
Large time behaviors

This section is devoted to studying the large time behaviors of the non-negative weak solution to the Cauchy problem (
1.1
). Different from the case of the PME (
1.7
), the absence of scaling invariance means the missing of self-similar solution, and the presence of the nonlinear Lotka-Volterra source term
\rho g(\rho)
means that there exist two constant equilibrium states
0,\rho_{M}
.

Large time behaviors.

The compound effect of both the degenerate diffusion and the logistic growth effect is the main characteristic of the porous medium type reaction-diffusion equation (
1.1
). We aim to prove that the solution
\rho
tends to its critical threshold
\rho_{M}
in time. To this end, we construct a new type weak sub-solution to the porous medium type reaction-diffusion equation (
1.1
), which locally tends to the critical threshold as the time goes to infinity. For the reason of technique, we need to assume that there exists a constant
d_{G}>0
for
m>1
such that

d_{G}:=\inf\limits_{\rho\in[0,\rho_{M}]}-g^{\prime}(\rho)\frac{\rho^{2-m}}{m-1}=\inf\limits_{P\in[0,P_{M}]}[-G^{\prime}(P)]>0,

(3.1)

where both
G(P):=P_{M}-P
from the tumor growth model
[
43
]
and
g(\rho)=1-\rho
from the Fisher-KPP equation with
m\geq 2

[
22
]
satisfy (
3.1
). To construct the sub-solution, we need to introduce the initial value problem for the Lotka-Volterra system
[
37
, Section 12]
as follows

\begin{cases}\dot{\alpha}(t)=(m-1)d_{G}\alpha(t)\big(P_{M}-\alpha(t)-\frac{2n}{d_{G}}\beta(t)\big),\quad t>0,&\\
\dot{\beta}(t)=(m-1)d_{G}\beta(t)\big(P_{M}-\alpha(t)-\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t)\big),&\\
\alpha(0):=\alpha_{0}>0,\quad\beta(0):=\beta_{0}>0.&\\
\end{cases}

(3.2)

(Large time asymptotic)

Assume that

) of the Lotka-Volterra system

(3.3)

Then, there exists a constant
C>0
depending on

such that the optimal time decay rates of

hold as

C^{-1}(1+t)^{-1}\leq P_{M}-\alpha(t),\beta(t)\leq C(1+t)^{-1},\quad t>0.

Furthermore,
(\alpha(t)-\beta(t)|x|^{2})_{+}
is a weak sub-solution to the Cauchy problem for the pressure equation (

satisfying (

Lemma 3.1

(Lotka-Volterra system)
.

Let
(\alpha(t),\beta(t))
be the strong solution to the initial value problem of the Lotka-Volterra system (

)

\begin{cases}\alpha_{0}<\alpha(t)<P_{M},\quad 0<\beta(t)<\beta_{0},&\\
P_{M}-\frac{2n}{d_{G}}\beta(t)>\alpha(t)>P_{M}-\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t),\quad t>0,&\\
\alpha(t)\to P_{M},\quad\beta(t)\to 0,\quad\text{as }t\to\infty.&\end{cases}

(3.4)

Moreover, the optimal time decay rates are obtained as follows:

C^{-1}(t+1)^{-1}\leq P_{M}-\alpha(t),\beta(t)\leq C(t+1)^{-1},\quad t>0,

for some constant
C>0
depending on
P_{M},\alpha_{0},\beta_{0},m,d_{G}
.

Proof.

By the standard phase-plane analysis of the Lotka-Volterra system, (
3.4
) evidently holds.

By direct computations, it holds for
\eqref{dy}_{2}
that

\displaystyle\dot{\beta}(t)

\displaystyle=(m-1)d_{G}\beta(t)(P_{M}-\alpha(t)-\frac{2n}{d_{G}}\beta(t))-(m-1)d_{G}\beta^{2}(t)

\displaystyle\leq(m-1)d_{G}\beta(t)(P_{M}-\alpha(t)-\frac{2n}{d_{G}}\beta(t)).

Let
f_{1}(t):=\alpha(t)+\frac{2n}{d_{G}}\beta(t)
with
f_{1}(0)=f_{1,0}:=\alpha_{0}+\frac{2n}{d_{G}}\beta_{0}<P_{M}
, it holds after
\eqref{dy}_{1}+\frac{2n}{d_{G}}\times\eqref{dy22}
that

\dot{f}_{1}(t)\leq(m-1)d_{G}f_{1}(t)(P_{M}-f_{1}(t)).

(3.6)

Then, we obtain

\dot{f}_{1}(t)(\frac{1}{f_{1}(t)}+\frac{1}{P_{M}-f_{1}(t)})\leq P_{M}d_{G}(m-1).

It follows from the derivative of compound function that

\frac{d}{dt}\{\log\frac{f_{1}(t)}{P_{M}-f_{1}(t)}\}\leq P_{M}d_{G}(m-1).

We integrate the above equation on
[0,t]
for any
t>0
and get

\log\frac{f_{1}(t)}{P_{M}-f_{1}(t)}\leq\log\frac{f_{1,0}}{P_{M}-f_{1,0}}+P_{M}d_{G}(m-1)t.

It holds by taking the inverse operator
\log^{-1}=e^{*}
action on the above inequality that

\frac{f_{1}(t)}{P_{M}-f_{1}(t)}\leq\frac{f_{1,0}}{P_{M}-f_{1,0}}e^{d_{G}P_{M}(m-1)t}.

Hence, we obtain

\alpha(t)+\frac{2n}{d_{G}}\beta(t)=f_{1}(t)\leq\frac{P_{M}f_{1,0}}{(P_{M}-f_{1,0})e^{-P_{M}d_{G}(m-1)t}+f_{1,0}}.

(3.7)

Similarly, it follows from
\eqref{dy}_{1}
that

\displaystyle\dot{\alpha}(t)

\displaystyle=d_{G}(m-1)\alpha(t)(P_{M}-\alpha(t)-\frac{2n(m-1)+4}{(m-1)d_{G}}\beta(t))+\frac{4}{d_{G}(m-1)}\beta^{2}(t)

(3.8)

\displaystyle\geq d_{G}(m-1)\alpha(t)(P_{M}-\alpha(t)-\frac{2n(m-1)+4}{(m-1)d_{G}}\beta(t)).

Define

with

\eqref{dy11}+\frac{2n(m-1)+4}{d_{G}(m-1)}\times\eqref{dy}_{2}
that

\dot{f}_{2}(t)\geq d_{G}(m-1)f_{2}(t)(P_{M}-f_{2}(t)).

Similar to (
3.6
), we solve directly the above inequality equation and get

\alpha(t)+\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t)=f_{2}(t)\geq\frac{P_{M}f_{2,0}}{(f_{2,0}-P_{M})e^{-P_{M}d_{G}(m-1)t}+f_{2,0}}.

(3.9)

Since

\displaystyle\frac{d}{dt}\big\{\frac{\alpha(t)}{\beta(t)}\big\}=\frac{\dot{\alpha}(t)}{\beta(t)}-\frac{\alpha(t)\dot{\beta}(t)}{\beta^{2}(t)}

(3.10)

\displaystyle=

\displaystyle\frac{(m-1)d_{G}\alpha(t)}{\beta(t)}[(P_{M}-\alpha(t)-\frac{2n}{d_{G}}\beta(t)\big)-(P_{M}-\alpha(t)-\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t))]

\displaystyle=

\displaystyle\frac{(m-1)d_{G}\alpha(t)}{\beta(t)}\frac{4\beta(t)}{d_{G}(m-1)}

\displaystyle=

\displaystyle 4\alpha(t)>0

and
\alpha_{0}\leq\alpha(t)\leq P_{M}
hold, we integrate (
3.10
) on
[0,t]
for any
t>0
and obtain

\alpha_{0}t+\frac{\alpha_{0}}{\beta_{0}}\leq\frac{\alpha(t)}{\beta(t)}\leq P_{M}t+\frac{\alpha_{0}}{\beta_{0}},\quad t>0.

Hence, the time decay rate of
\beta(t)
is obtained as

\frac{\alpha_{0}}{P_{M}t+\frac{\alpha_{0}}{\beta_{0}}}\leq\beta(t)\leq\frac{P_{M}}{\alpha_{0}t+\frac{\alpha_{0}}{\beta_{0}}},\quad t>0.

(3.11)

Inserting (
3.11
) into (
3.7
), we get

\displaystyle P_{M}-\alpha(t)\geq

\displaystyle P_{M}-\frac{P_{M}f_{1,0}}{(P_{M}-f_{1,0})e^{-P_{M}d_{G}(m-1)t}+f_{1,0}}+\frac{2n}{d_{G}}\beta(t)

(3.12)

\displaystyle\geq

\displaystyle\frac{P_{M}(P_{M}-f_{1,0})e^{-P_{M}d_{G}(m-1)t}}{(P_{M}-f_{1,0})e^{-P_{M}d_{G}(m-1)t}+f_{1,0}}+\frac{2n}{d_{G}}\frac{\alpha_{0}}{P_{M}t+\frac{\alpha_{0}}{\beta_{0}}}.

Similarly, we take (
3.11
) into (
3.9
) and attain

\displaystyle P_{M}-\alpha(t)

\displaystyle\leq P_{M}-\frac{P_{M}e^{-P_{M}d_{G}(m-1)t}}{(f_{2,0}-P_{M})e^{-P_{M}d_{G}(m-1)t}+f_{2,0}}+\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t)

(3.13)

\displaystyle\leq\frac{P_{M}(f_{2,0}-P_{M})e^{-P_{M}d_{G}(m-1)t}}{(f_{2,0}-P_{M})e^{-P_{M}d_{G}(m-1)t}+f_{2,0}}+\frac{2n(m-1)+4}{d_{G}(m-1)}\frac{P_{M}}{\alpha_{0}t+\frac{\alpha_{0}}{\beta_{0}}}.

Combining(

), there exists a constant

depending on

Lemma 3.2

(Sub-solution)
.

Let
Q(x,t):=\big(\alpha(t)-\beta(t)|x|^{2}\big)_{+}
with
\big(\alpha(t),\beta(t)\big)
being the strong solution to the initial value problem (

Proof.

For any given

such that

By direct calculations in the positive parts of

\partial_{t}Q(x,t)=\dot{\alpha}(t)-\dot{\beta}(t)|x|^{2},

\displaystyle-(m-1)Q\Delta Q=

\displaystyle-(m-1)(\alpha(t)-\beta(t)|x|^{2})(-2n\beta(t))

\displaystyle=

\displaystyle(m-1)2n\alpha(t)\beta(t)-(m-1)2n\beta^{2}(t)|x|^{2},

-|\nabla Q|^{2}=-|2\beta(t)x|^{2}=-4\beta^{2}(t)|x|^{2},

It concludes by combining the above results that

\displaystyle\partial_{t}Q-(m-1)Q\Delta Q-|\nabla Q|^{2}-(m-1)QG(Q)

\displaystyle\leq

\displaystyle\big[\dot{\alpha}(t)-(m-1)d_{G}\alpha(t)(P_{M}-\alpha(t)-\frac{2n}{d_{G}}\beta(t))\big]

\displaystyle-|x|^{2}\big[\dot{\beta}(t)-(m-1)d_{G}\beta(t)(P_{M}-\alpha(t)-\frac{2n(m-1)+4}{d_{G}(m-1)}\beta(t))\big]

\displaystyle=

\displaystyle 0-0|x|^{2}

\displaystyle=

\displaystyle 0\quad\text{in }\{(x,t)\in\mathbb{R}^{n}\times\mathbb{R}_{+}:\ Q(x,t)>0\},

and the proof is completed.

Lemma 4.1

(Aronson-Bénilan estimate)

(4.1)

Proof.

Let
\Delta\times\eqref{pe}+G^{\prime}(P)\times\eqref{pe}
and set

\displaystyle\partial_{t}\omega=

\displaystyle(m-1)P\Delta\omega+2m\nabla P\cdot\nabla\omega+(m-1)\omega^{2}-(G(P)-PG^{\prime}(P))(m-1)\omega

(4.2)

\displaystyle-G^{\prime}(P)|\nabla P|^{2}+2\nabla^{2}P:\nabla^{2}P

\displaystyle(m-1)P\Delta\omega+2m\nabla P\cdot\nabla\omega+(m-1)\omega^{2}-(G(P)-PG^{\prime}(P))(m-1)\omega.

Set

) by
sign(|\omega|_{-})

\displaystyle\partial_{t}|\omega|_{-}\leq

\displaystyle(m-1)P\Delta|\omega|_{-}+2m\nabla P\cdot\nabla|\omega|_{-}-(m-1)|\omega|_{-}^{2}

(4.3)

\displaystyle-(G(P)-PG^{\prime}(P))(m-1)|\omega|_{-}

\displaystyle\leq

\displaystyle(m-1)P\Delta|\omega|_{-}+2m\nabla P\cdot\nabla|\omega|_{-}-(m-1)|\omega|_{-}^{2}.

Since

with

(.74)

Consequently, we obtain

\varphi(t)\geq e^{-\varepsilon t}\varphi(0)\geq e^{-\varepsilon\lambda}\nu\quad\text{for}\ t\in[0,\lambda].

(.75)

Next, we construct a differential inequality equation to obtain a upper bound for the growth of
\varphi
over time.

As in
[
8
,
9
]
, we introduce the Green’s function in a ball
B_{1}
so that
G_{1}
solves

\Delta G_{1}=\alpha_{n}\textbf{1}_{B_{1}}-\gamma_{n}\delta(x)\quad\text{and}\quad G_{1}=|\nabla G_{1}|=0,\quad\text{on }\partial B_{1},

where
\gamma_{n}
is a positive constant depending only on
n
,
\textbf{1}_{A}
is the characteristic function of a given set
A
,
\delta(x)
is the Dirac measure and
\alpha_{n}=n(n-2)
. According to the Green’s function on
B_{1}
,
G_{1}
as in
[
9
]
is defined as

G_{1}(x)=\begin{cases}|x|^{2-n}-1+\frac{n-2}{2}(|x|^{2}-1),&n\geq 3,\\
\log\frac{1}{|x|}-\frac{1}{2}(1-|x|^{2}),&n=2.\\
\end{cases}

Then, for
0<t<1
, we have

\displaystyle\int_{B_{1}}G_{1}\tilde{\rho}dx\geq

\displaystyle\int_{0}^{t}\int_{B_{1}}G_{1}(x)\tilde{\rho}_{s}(x,s)dxds

\displaystyle=

\displaystyle\int_{0}^{t}\int_{B_{1}}G_{1}(x)\Delta\tilde{\rho}^{m}dxds+\sigma\int_{0}^{t}\int_{B_{1}}G_{1}(x)\tilde{\rho}G(\frac{R^{2}}{\sigma}\tilde{P})dxds

\displaystyle\geq

\displaystyle\int_{0}^{t}\int_{B_{1}}G_{1}(x)\Delta\tilde{\rho}^{m}dxds+\sigma G(P_{H})\int_{0}^{t}\int_{B_{1}}G_{1}(x)\tilde{\rho}dxds

\displaystyle=

\displaystyle-\gamma_{n}\int_{0}^{t}\tilde{\rho}^{m}(0,s)ds+\alpha_{n}\int_{0}^{t}\int_{B_{1}}\tilde{\rho}^{m}(x,s)dxds+\sigma G(P_{H})\int_{0}^{t}\int_{B_{1}}G_{1}(x)\tilde{\rho}dxds,

where
G(P)\geq G(P_{H})
on
[0,P_{H}]
defined in (
3.1
) is used.
Hence, it follows

\displaystyle\int_{B_{1}}

\displaystyle G_{1}(x)\tilde{\rho}(x,t)dx-\sigma G(P_{H})\int_{0}^{t}\int_{B_{1}}G_{1}(x)\tilde{\rho}dxds

\displaystyle\geq-\gamma_{n}\int_{0}^{t}\tilde{\rho}^{m}(0,s)ds+\alpha_{n}\int_{0}^{t}\int_{B_{1}}\tilde{\rho}^{m}(x,s)dxds.

Let us recall the definition of
\varphi(t)
as

\varphi(t)=\int_{B_{1}}\tilde{\rho}^{m}(x,t)dx.

Parallel to
[
9
, Lemma 2.3]
with the dimension
n\geq 2
and the diffusion exponent
m>1
, we have

\int_{B_{1}}G_{1}(x)\tilde{\rho}(x,t)dx\leq\tilde{C}_{1}\varepsilon^{\delta}+\tilde{C}_{2}(\varphi(t))^{\frac{1}{m}},

then it holds by Young’s inequality that

\int_{0}^{t}\varphi(s)ds\leq C_{1}\int_{0}^{t}\tilde{\rho}^{m}(0,s)ds+C_{2}[\varepsilon^{\delta}+\varepsilon\lambda(\varepsilon^{\delta}+1)]+C_{3}(\varphi(t))^{\frac{1}{m}},

(.76)

where
\tilde{C}_{1}
,
\tilde{C}_{2}
,
C_{1}
,
C_{2}
,
C_{3}
and
\delta
are positive constants depending only on
m,n
.

Now, assume that (
5.1
) is not satisfied, that is

\tilde{\rho}^{m}(0,\lambda)\leq c.

It follows from (
.74
) that

\tilde{\rho}^{m}(0,t)\leq e^{\varepsilon\lambda}c\quad\text{for}\ 0\leq t\leq\lambda.

Set

\tilde{C}:=\frac{(C_{1}\lambda ce^{\varepsilon\lambda}+C_{2}[\varepsilon^{\delta}+\varepsilon\lambda(\epsilon^{\delta}+1)])e^{\varepsilon\lambda/m}}{\nu^{1/m}},

by means of (
.75
) and (
.76
), we conclude

\int_{0}^{t}\varphi(s)ds\leq\frac{1}{B}(\varphi(t))^{1/m}\quad\text{with }\frac{1}{B}=C_{3}+\tilde{C}.

Let

\Psi(t):=\int_{0}^{t}\varphi(s)ds,

we have

\Psi^{\prime}(t)\geq(B\Psi(t))^{m}.

(.77)

From (
.75
), it follows

\Psi(t)\geq At,\ A=\nu e^{-\varepsilon\lambda}.

We can construct a sub-function
\chi(t)
of
\Psi(t)
by solving the following ODE:

\chi^{\prime}(t)=(B\chi(t))^{m},\ t>t_{0},\ \chi(t_{0})=At_{0},

(.78)

it holds by the comparison principle that

\Psi(t)\geq\chi(t),\ t_{0}\leq t\leq\lambda.

(.79)

By directly solving ODE (
.78
), we obtain

(m-1)\chi^{m-1}(t)=\frac{1}{C-B^{m}t}

where
C
is a constant determined by

\frac{1}{C-B^{m}t_{0}}=(m-1)A^{m-1}t_{0}^{m-1}.

Since

\chi(t)\to\infty,\ as\ t\to\frac{C}{B^{m}},

but (
.79
) implies

\Psi(t)\to\infty,\ as\ t\to\frac{C}{B^{m}}

under the assumption
\lambda\geq\frac{C}{B^{m}}
, which is contradicted with the bound of
\Psi
. Thus, (
5.1
) must be valid provided

\lambda\geq\frac{C}{B^{m}}=\frac{e^{\varepsilon\lambda(m-1)}}{(m-1)\nu^{m-1}t_{0}^{m-1}B^{m}}+t_{0}

(.80)

where the definitions of
A,C
were used.

In addition, choosing
t_{0}=\frac{\lambda}{2}
, we verify by the definition of
B,c
that (
.80
) satisfies

\lambda^{m}\nu^{m-1}\geq\frac{2^{m}e^{m-1}}{m-1}(\frac{(C_{1}\lambda ce^{\varepsilon\lambda}+C_{2}[\varepsilon^{\delta}+\varepsilon\lambda(\varepsilon^{\delta}+1)])e^{\varepsilon\lambda/m}}{\nu^{1/m}}+C_{3})^{m}.

Therefore, (
5.2
) guarantees that (
.80
) holds. The proof is completed.
