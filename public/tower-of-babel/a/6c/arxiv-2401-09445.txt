Quadratic neural networks for solving inverse problems
Leon Frischauf leon.frischauf@univie.ac.at, Otmar Scherzer otmar.scherzer@univie.ac.at, Cong Shi cong.shi@univie.ac.at

Abstract
In this paper we investigate the solution of inverse problems with neural network ansatz functions with generalized decision functions. The relevant observation for this work is that such functions can approximate typical test cases, such as the Shepp-Logan phantom, better, than standard neural networks. Moreover, we show that the convergence analysis of numerical methods for solving inverse problems with shallow generalized neural network functions leads to more intuitive convergence conditions, than for deep affine linear neural networks.

1. Introduction

We consider an
inverse problem
, which consists in solving an operator equation

F({\bf x})={\bf y}_{0},

(1.1)

where
F:{\bf X}\rightarrow{\bf Y}
denotes an operator, mapping between function spaces
({\bf X},\left\|\cdot\right\|)

and
({\bf Y},\left\|\cdot\right\|)
.
For the numerical solution of
Equation 1.1
an appropriate set of ansatz-functions
{\bf P}
has to be selected, on which an approximate solution of
Equation 1.1
is calculated, for instance a function
{\bf p}\in{\bf P}\subseteq{\bf X}
, which solves

F({\bf p})={\bf y},

(1.2)

where
{\bf y}
is an approximation of
{\bf y}_{0}
.
The history on the topic of approximating the solution of
Equation 1.1
by discretization and regularization is long: For linear inverse problems this has been investigated for instance in
[
23
]
. Much later on neural network ansatz functions have been used for solving
Equation 1.1
; see for instance
[
24
]
. In this paper we investigate solving
Equation 1.2
when
{\bf P}
is a set of neural network functions with
generalized
decision functions. In order to spot the difference to classical neural network functions we recall the definition of them first:

Definition 1.1
(Affine linear neural network functions).

Let
m\geq n\in\mathbb{N}
.
Line vectors in
\mathbb{R}^{m}
and
\mathbb{R}^{n}
are denoted by

{\bf w}=(w^{(1)},w^{(2)},\ldots,w^{(m)})^{T}\text{ and }{\vec{x}}=(x_{1},x_{2},\ldots,x_{n})^{T},\text{ respectively.}

•

A
shallow
affine linear neural networks (
ALNN
) is a function (here
m=n
)

{\vec{x}}\in\mathbb{R}^{n}\to{\bf p}({\vec{x}}):=\Psi[{\vec{p}}]({\vec{x}}):=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\vec{x}}+\theta_{j}\right),

(1.3)

with
\alpha_{j},\theta_{j}\in\mathbb{R}
,
{\bf w}_{j}\in\mathbb{R}^{n}
;
\sigma
is an activation function, such as the sigmoid, ReLU
k
or Softmax function.
Moreover,

{\vec{p}}=[\alpha_{1},\ldots,\alpha_{N};{\bf w}_{1},\ldots,{\bf w}_{N};\theta_{1},\ldots,\theta_{N}]\in\mathbb{R}^{n_{*}}\text{ with }n_{*}=(n+2)N

(1.4)

denotes the according parametrization of
{\bf p}
.
In this context the set of
ALNN
s is given by

{\bf P}:=\left\{{\bf p}\text{ of the form \autoref{eq:classical_approximation}}:{\vec{p}}\in\mathbb{R}^{n_{*}}\right\}.

•

More recently
deep
affine linear neural network functions (
DNN
s) have become popular: An
(L+2)
-layer network looks as follows:

\displaystyle{\vec{x}}\in\mathbb{R}^{n}\to

\displaystyle\bf{\displaystyle p}({\vec{x}}):=

(1.5)

\displaystyle\Psi[{\vec{p}}]({\vec{x}}):=\sum_{j_{L}=1}^{N_{L}}\alpha_{j_{L},L}\sigma_{L}\left(p_{j_{L},L}\left(\sum_{j_{L-1}=1}^{N_{L-1}}\ldots\left(\sum_{j_{1}=1}^{N}\alpha_{j_{1},1}\sigma_{1}\left(p_{j_{1},1}({\vec{x}})\right)\right)\right)\right).

where

p_{j,l}({\vec{x}})={\bf w}_{j,l}^{T}{\vec{x}}+\theta_{j,l}\text{ with }\alpha_{j,l},\theta_{j,l}\in\mathbb{R}\text{ and }{\bf w}_{j,l}\in\mathbb{R}^{n}\text{ for all }l=1,\ldots,L.

Here
s\in\mathbb{R}\to\sigma_{k}(s)
,
k=1,\ldots,L
, denote activation functions. Moreover, we denote the parametrizing vector by

{\vec{p}}=[\alpha_{1,1},\ldots,\alpha_{N_{L},L};{\bf w}_{1,1},\ldots,{\bf w}_{N_{L},L};\theta_{1,1},\ldots,\theta_{N_{L},L}]\in\mathbb{R}^{n_{*}}.

(1.6)

A shallow linear neural network can also be called a
3-layer network
. The notation 3-layer network is consistent with the literature because input-and output are counted on top. Therefore,
a general
(L+2)
-layer network has only
L

internal

We demonstrate exemplary below (see

[

). Moreover, it is well-known in regularization theory that the quality of approximation of the solution of

is depending on the approximation qualities of the set

:
Approximation of functions with shallow affine linear neural networks is a classical topic of machine learning and

), convolutional neural networks (CNN) (see for example

In this paper we follow up on this topic and analyze neural network functions with decision functions, which are higher order polynomials, as specified now:

Definition 1.2
(Shallow generalized neural network function).

Let
n,m,N\in\mathbb{N}
. Moreover, let

{\bf{f}}_{j}:\mathbb{R}^{n}\to\mathbb{R}^{m},\quad j=1,\ldots,N

be vector-valued functions. Neural network functions associated to
\left\{{\bf{f}}_{j}:j=1,\ldots,N\right\}
are defined by

{\vec{x}}\to{\bf p}({\vec{x}})=\Psi[{\vec{p}}]({\vec{x}}):=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\bf{f}}_{j}({\vec{x}})+\theta_{j}\right)\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R}\text{ and }{\bf w}_{j}\in\mathbb{R}^{m}.

(1.7)

Again we denote the parametrization vector, containing all coefficients, with
{\vec{p}}
and the set of all such functions with
{\bf P}
.
We call

\mathcal{D}:=\left\{{\vec{x}}\to{\bf w}^{T}{\bf{f}}_{j}({\vec{x}})+\theta:{\bf w}\in\mathbb{R}^{m},\theta\in\mathbb{R},j=1,\ldots,N\right\}

(1.8)

the set of
decision functions
associated to
Equation 1.7
.
The composition of
\sigma
with a decision function is called
neuron
.

We discuss approximation properties of generalized neural networks (see
Section 2
),
in particular neural network functions with decision functions, which are at most
quadratic polynomials
in
{\vec{x}}
. This idea is not completely new: In
[
33
]
neural networks with
parabolic
decision functions have been applied in a number of applications. In
[
10
]
, the authors proposed neural networks with radial decision functions, and proved an universal approximation result for ReLU-activated
deep quadratic networks
.

Outline of this paper

The motivation for this paper is to solve
Equation 1.2
on a set of neural network functions
{\bf P}

with iterative algorithms, such as for instance a Gauss-Newton method. Good approximation
properties of functions of interest (such as the Shepp-Logan phantom) is provided with quadratic

decision functions
, which have been suggested already in
[
21
]
.
We concentrate on shallow neural networks because the resulting analysis of iterative methods for solving inverse problems is intuitive (see
Section 3.2
). We apply different approximation theorems (such as for instance the universal approximation theorem of
[
5
]
) to cover all situations from
Section 2
, below. Moreover, by constructing wavelet frames based on quadratic decision functions, we give an explicit convergence rate for shallow radial network approximations; see
Section 4
, with main result
Section 4
. In
Appendix A
the important conditions of the
approximation to the identity
(AtI) from
[
7

used for proving the convergence rates in

are verified.

2. Examples of networks with generalized decision functions

The versatility of the network defined in
Equation 1.7
is due to the flexibility of the functions
{\bf{f}}_{j}
,
j=1,\ldots,N
to chose.

We give a few examples.

Definition 2.1
(Neural networks with generalized decision functions).

We split them into three categories:

General quadratic neural networks
(GQNN)
: Let

m=n+1,\quad{\bf{f}}_{j}({\vec{x}})=\begin{pmatrix}f_{j}^{(1)}({\vec{x}})\\
\vdots\\
f_{j}^{(n)}({\vec{x}})\\
f_{j}^{(n+1)}({\vec{x}})\end{pmatrix}=\begin{pmatrix}x_{1}\\
\vdots\\
x_{n}\\
{\vec{x}}^{T}A_{j}{\vec{x}}\end{pmatrix}\text{ for all }j=1,\ldots,N.

That is,
{\bf{f}}_{j}
is a graph of a quadratic function.
Then
Equation 1.7
reads as follows:

\displaystyle{\vec{x}}\to{\bf p}({\vec{x}})=\Psi[{\vec{p}}]({\vec{x}})

\displaystyle:=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\vec{x}}+{\vec{x}}^{T}A_{j}{\vec{x}}+\theta_{j}\right)

(2.1)

\displaystyle\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R},{\bf w}_{j}\in\mathbb{R}^{n},A_{j}\in\mathbb{R}^{n\times n}.

{\vec{p}}
denotes the parametrization of
{\bf p}
:

\displaystyle{\vec{p}}=[\alpha_{1}\ldots,\alpha_{N};{\bf w}_{1},\ldots,{\bf w}_{N};A_{1},\ldots,A_{N};\theta_{1},\ldots,\theta_{N}]\in\mathbb{R}^{n_{*}}\text{ with }n_{*}=(n^{2}+n+2)N.

(2.2)

Note that in
Equation 2.1
all parameters of the entries of the matrices
A_{j}
are parameters.

Constrained quadratic neural networks
(CQNN)
: These are networks, where the entries of the matrices
A_{j}
,
j=1,\ldots,N
are constrained:

(i)

Let

{\bf{f}}({\vec{x}})={\bf{f}}_{j}({\vec{x}})=\begin{pmatrix}f_{j}^{(1)}({\vec{x}})\\
\vdots\\
f_{j}^{(n)}({\vec{x}})\\
f_{j}^{(n+1)}({\vec{x}})\end{pmatrix}=\begin{pmatrix}x_{1}\\
\vdots\\
x_{n}\\
0\end{pmatrix}\text{ for all }j=1,\ldots,N.

That is
A_{j}=0
for all
j=1,\ldots,N
. This set of
CQNN
s corresponds with the
ALNN
s defined in
Equation 1.3
.

(ii)

Let
A_{j}\in\mathbb{R}^{n\times n}
,
j=1,\ldots,N
be chosen and fixed. We denote by
MCNN
the family of functions

\displaystyle{\vec{x}}\to{\bf p}({\vec{x}})=\Psi[{\vec{p}}]({\vec{x}})

\displaystyle:=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\vec{x}}+\xi_{j}{\vec{x}}^{T}A_{j}{\vec{x}}+\theta_{j}\right)

(2.3)

\displaystyle\text{ with }\alpha_{j},\theta_{j},\xi_{j}\in\mathbb{R},{\bf w}_{j}\in\mathbb{R}^{n},A_{j}\in\mathbb{R}^{n\times n},

which is parametrized by the vector

\displaystyle{\vec{p}}=[\alpha_{1}\ldots,\alpha_{N};{\bf w}_{1},\ldots,{\bf w}_{N};\xi_{1},\ldots,\xi_{N};\theta_{1},\ldots,\theta_{N}]\in\mathbb{R}^{n_{*}}\text{ with }n_{*}=(n+3)N.

(2.4)

In particular, choosing
A_{j}=\mathcal{I}
we get:

\displaystyle{\vec{x}}\to{\bf p}({\vec{x}})=\Psi[{\vec{p}}]({\vec{x}})

\displaystyle:=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\vec{x}}+\xi_{j}\left\|{\vec{x}}\right\|^{2}+\theta_{j}\right)

(2.5)

\displaystyle\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R},{\bf w}_{j}\in\mathbb{R}^{n},\xi_{j}\in\mathbb{R}.

Radial quadratic neural networks
(RQNN)s
:
For
\xi_{j}\neq 0
the argument in
Equation 2.5
rewrites to

\displaystyle\nu_{j}({\vec{x}}):=\xi_{j}\left\|{\vec{x}}\right\|^{2}+\hat{{\bf w}}_{j}^{T}{\vec{x}}+\theta_{j}=\xi_{j}\left\|{\vec{x}}-{\vec{y}}\right\|^{2}+\kappa_{j}

(2.6)

with

{\vec{y}}_{j}=-\frac{1}{2\xi_{j}}\hat{{\bf w}}_{j}^{T}\text{ and }\kappa_{j}=\theta_{j}-\frac{\left\|\hat{{\bf w}}_{j}\right\|^{2}}{4\xi_{j}}.

(2.7)

We call the set of functions from
Equation 2.5
, which satisfy

\xi_{j}\geq 0\text{ and }\kappa_{j}\leq 0\text{ for all }j=1,\ldots,N,

(2.8)

RQNN
s, radial neural network functions, because the level sets of
\nu_{j}
are circles. These are
radial basis functions

(see for instance
[
3
]
for a general overview).

Sign based quadratic
(SBQNN)
and cubic neural networks
(CUNN)
: Let
m=n
.

(i)

(SBQNN)
: Let

f^{(i)}({\vec{x}})=\text{sgn}(x_{i})x_{i}^{2}\text{ for }i=1,\ldots,n,

(2.9)

or alternatively

f^{(i)}({\vec{x}})=\left\|{\vec{x}}\right\|^{2}\text{sgn}(x_{i})\text{ for }i=1,\ldots,n.

In the first case, and in the second case similarly, we obtain the family of functions

\Psi[{\vec{p}}]({\vec{x}}):=\sum_{j=1}^{N}\alpha_{j}\sigma\left(\sum_{i=1}^{n}w_{j}^{(i)}\text{sgn}(x_{i})x_{i}^{2}+\theta_{j}\right)\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R}\text{ and }{\bf w}_{j}\in\mathbb{R}^{n}.

(2.10)

We call these functions
signed squared neural networks
. Note, here
{\vec{p}}\in\mathbb{R}^{n_{*}}
with
n_{*}=(n+2)N
.

(ii)

(CUNN)
: Let

f^{(i)}({\vec{x}})=x_{i}^{3}\text{ for }i=1,\ldots,n.

(2.11)

We obtain the family of functions

\Psi[{\vec{p}}]({\vec{x}}):=\sum_{j=1}^{N}\alpha_{j}\sigma\left(\sum_{i=1}^{n}w_{j}^{(i)}x_{i}^{3}+\theta_{j}\right)\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R}\text{ and }{\bf w}_{j}\in\mathbb{R}^{n}.

(2.12)

We call these functions
cubic neural networks
. Again

with
n_{*}=(n+2)N
.

.

(i)

Definition 2.2

A function

Let

(2.13)

Theorem 2.5
(Generalized universal approximation theorem).

Let
\sigma:\mathbb{R}\to\mathbb{R}
be a continuous discriminatory function and assume that
{\bf{f}}_{j}:[0,1]^{n}\to\mathbb{R}^{m}
,
j=1,\ldots,N
are injective (this in particular means that
n\leq m
) and continuous, respectively. We denote
{\bf{f}}=({\bf{f}}_{1},\ldots,{\bf{f}}_{N})
.

Then for every
g\in C([0,1]^{n})
and every
\epsilon>0
there exists some function

\Psi^{\bf{f}}({\vec{x}}):=\sum_{j=1}^{N}\alpha_{j}\sigma\left({\bf w}_{j}^{T}{\bf{f}}_{j}({\vec{x}})+\theta_{j}\right)\text{ with }\alpha_{j},\theta_{j}\in\mathbb{R}\text{ and }{\bf w}_{j}\in\mathbb{R}^{m}

satisfying

\left|\Psi^{\bf{f}}({\vec{x}})-g({\vec{x}})\right|<\epsilon\text{ for all }{\vec{x}}\in[0,1]^{n}.

Proof
.

We begin the proof by noting that since
{\vec{x}}\to{\bf{f}}_{j}({\vec{x}})
is injective, the inverse function on the range of
{\bf{f}}_{j}
is well-defined, and we write
{\bf{f}}_{j}^{-1}:{\bf{f}}_{j}([0,1]^{n})\subseteq\mathbb{R}^{m}\to[0,1]^{n}\subseteq\mathbb{R}^{n}
.
The proof that
{\bf{f}}_{j}^{-1}
is continuous relies on the fact that the domain
[0,1]^{n}
of
{\bf{f}}_{j}
is compact, see for instance
[
9
, Chapter XI, Theorem 2.1]
. Then applying the Tietze–Urysohn–Brouwer extension theorem (see
[
16
]
) to the continuous function
g\circ{\bf{f}}_{j}^{-1}:{\bf{f}}_{j}([0,1]^{n})\to\mathbb{R}
, we see that this function can be extended continuously to
\mathbb{R}^{m}
. This extension will be denoted by
g^{*}:\mathbb{R}^{m}\to\mathbb{R}
.

We apply
Section 2
to conclude that there exist
\alpha_{j},\theta_{j}\in\mathbb{R}
and
{\bf w}_{j}\in\mathbb{R}^{m}
,
j=1,\ldots,N
such that

\Psi^{*}({\bf{z}}):=\sum_{j=1}^{N}\alpha_{j}\sigma({\bf w}_{j}^{T}{\bf{z}}+\theta_{j})\text{ for all }{\bf{z}}\in\mathbb{R}^{m},

which satisfies

\left|\Psi^{*}({\bf{z}})-g^{*}({\bf{z}})\right|<\epsilon\text{ for all }{\bf{z}}\in[0,1]^{m}.

(2.14)

Then, because
{\bf{f}}_{j}
maps into
\mathbb{R}^{m}
we conclude, in particular, that

\displaystyle\Psi^{*}({\bf{f}}_{j}({\vec{x}}))

\displaystyle=\sum_{j=1}^{N}\alpha_{j}\sigma({\bf w}_{j}^{T}{\bf{f}}_{j}({\vec{x}})+\theta_{j})

and

\displaystyle\left|\Psi^{*}({\bf{f}}_{j}({\vec{x}}))-g({\vec{x}})\right|=\left|\Psi^{*}({\bf{f}}_{j}({\vec{x}}))-g^{*}({\bf{f}}_{j}({\vec{x}}))\right|<\epsilon.

Therefore
\Psi^{\bf{f}}(\cdot):=\Psi^{*}({\bf{f}}_{j}(\cdot))
satisfy the claimed assertions.

\square

It is obvious that the full variability in
{\bf w}
is the key to bring our proof and the universal approximation theorem in context. That is, if

,
\theta_{j}

\mathbb{R}^{n}
,
\mathbb{R}
, respectively.

in

3. Motivation

3.1. Motivation 1: The Shepp-Logan phantom

Almost all tomographic algorithms are tested with the Shepp-Logan phantom (see
[
30
]
).
It is obvious that it can be exactly represented with a
GQNN
with 10 coefficients, while we conjecture that it can neither be exactly represented with an
ALNN
or a
DNN
with a finite number of coefficients. This observation extends immediately to all function that contains “localized” features.
In this sense sparse approximations with linear neural networks would be more costly in practice.

3.2. Motivation 2: The Gauss-Newton iteration

Let us assume that
F:{\bf X}\to{\bf Y}
is a linear operator. We consider the solution
\bf p
of
Equation 1.2
to be an element of an
ALNN
or
DNN
, as defined in
Section 1
. Therefore
\bf p
can be parameterized by a vector
{\vec{p}}
as in
Equation 1.4
(for shallow linear neural networks) or
Equation 1.6
(for deep neural networks). For
GQNN
s the adequate parametrization can be read out from
Section 2
.
In other words, we can write every searched for function
\bf p
via an operator
\Psi
which maps a parameter
{\vec{p}}\in\mathbb{R}^{n_{*}}
to a function in
{\bf X}
, i.e.,

{\vec{x}}\to{\bf p}({\vec{x}})=\Psi[{\vec{p}}]({\vec{x}}).

Therefore, we aim for solving the
nonlinear
operator equation

\mathcal{N}({\vec{p}}):=F\circ\Psi[{\vec{p}}]={\bf y}.

(3.1)

For
ALNN
s we have proven in
[
28
]
that the Gauss-Newton method (see
Equation 3.7
, below) is locally, quadratically convergent under conditions, which guarantee that during the iteration the gradients of
\Psi
does not degenerate, i.e., that
{\bf P}
is a finite-dimensional manifold. Let us now calculate derivatives of the radial neural network operators
\Psi
(see
Equation 2.5
), which are the basis to prove that also the Gauss-Newton with
RQNN
s is convergent:

Example 3.1
.

Let
\sigma:\mathbb{R}\to\mathbb{R}
be continuous activation function, where all derivatives up to order
2
are uniformly bounded, i.e., in formulas

\sigma\in C^{2}(\mathbb{R};\mathbb{R})\cap\mathcal{B}^{2}(\mathbb{R};\mathbb{R}),

(3.2)

such as the sigmoid function.
Then, the derivatives of a radial neural network (
RQNN
)
\Psi
as in
Equation 2.5

with respect to the coefficients of
{\vec{p}}
in
Equation 2.2
are given by the following formulas, where
\nu_{s}
is defined in
Equation 2.6
:

•

Derivative with respect to
\alpha_{s}
,
s=1,\ldots,N
:

\displaystyle\frac{\partial\Psi}{\partial\alpha_{s}}[{\vec{p}}]({\vec{x}})

\displaystyle=\sigma(\nu_{s})\text{ for }s=1,\ldots,N.

(3.3)

•

Derivative with respect to
w_{s}^{(t)}
where
s=1,\ldots,N
,
t=1,\ldots,n
:

\displaystyle\frac{\partial\Psi}{\partial w_{s}^{(t)}}[{\vec{p}}]({\vec{x}})

Example 3.4

\displaystyle=\sum_{j_{2}=1}^{N_{2}}\alpha_{j_{2},2}\sigma^{\prime}\left(w_{j_{2},2}\rho(w_{1,1})+\theta_{j_{2},2}\right)w_{j_{2},2}\rho^{\prime}(w_{1,1})

In other word, the potential manifold of quadratic neural networks is extremely complex.

The conclusion of this section is that the analysis of iterative regularization methods, like a Gauss-Newton method, gets significantly more complicated if deep neural networks are used as ansatz functions. In contrast using neural network with higher order nodes (such as radial) results in transparent moment conditions. So the research question discussed in the following is whether shallow higher order neural networks have similar approximation properties than deep neural network functions, which would reveal clear benefits of such for analyzing iterative methods for solving ill–posed problems.

\displaystyle\leq

\displaystyle\frac{\left|S^{C}_{k}({\vec{x}},{\vec{y}})-S^{C}_{k}({\vec{x}}^{\prime},{\vec{y}})-S^{C}_{k}({\vec{x}},{\vec{y}}^{\prime})+S^{C}_{k}({\vec{x}}^{\prime},{\vec{y}}^{\prime})\right|}{\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|}

\displaystyle\leq

\displaystyle 2^{-k/n}2^{3}C_{n}C_{\sigma}\left((1-3^{-n}2)2^{-k}+3^{-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)^{-1-3/n}

\displaystyle 2^{-k/n}2^{3}(3^{-n})^{-1-3/n}C_{n}C_{\sigma}\left(\frac{1-3^{-n}2}{3^{-n}}2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)^{-1-3/n}

\displaystyle 2^{-k/n}2^{3}3^{n+3}C_{n}C_{\sigma}\left(2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)^{-1-3/n}.

Therefore
item (iii)
is satisfied with

,

Remark 4
.

Our results in section 4 are proved using “similar” methods as in
[
29
]
, but can not be used directly. Because the main ingredient of the proof is the construction of
localizing
functions as wavelets. This task requires two layers of affine linear decision functions to accomplish, since the linear combinations of functions of the form
{\vec{x}}\to\varphi({\vec{x}}):=C_{n}\sigma(\vec{w}^{T}{\vec{x}}+\theta)
are not localized; they
cannot
satisfy
item (iii)
in
Appendix A
, as they are not integrable on
\mathbb{R}^{n}
. In comparison, some quadratic decision functions - such as those used in Section 4 - naturally gives localized functions, and therefore can work as wavelets on their own.

We mention that there exists a zoo of approximation rates results for neural network functions (see for instance
[
32
,
31
]
, where best-approximation results in dependence of the space-dimension
n
have been proven). We have based our analysis on convergence rates results of
[
29
]
and
[
7
]
. This choice is motivated by the fact that the AtI property from
[
7
]
is universal, and allows a natural extension of their results to quadratic neural network functions. The motivation here is not to give the optimal convergence rates result for quadratic neural networks, but to verify that convergence rates results are possible. We believe that AtI is a very flexible and elegant tool.

5. Conclusion

In this paper we studied generalized neural networks functions for solving inverse problems.
We proved a universal approximation theorem and we have proven convergence rates of radial neural networks,
which are the same order as the classical affine linear neural network functions, but with vastly reduced numbers of elements
(in particular it spares one layer). The paper presents a proof of concept and thus we restrict attention only to radial neural networks although generalizations to higher order neural networks (such as cubic) is quite straightforward.

We also make the remark about the convergence of the actual training process of a neural network, i.e. optimization of the parameters of each decision function. This is usually done by gradient descent or Gauss-Newton-type methods. From the analysis in
[
28
]
the convergence conditions of Newton’s method become very complicated for
DNN
s, but are transparent for
quadratic neural networks, which is fact a matter of the complicated chain rule, when differentiating
DNN
s with respect to the parameters. For such an analysis there is a clear preference to go higher with the degree of polynomials than increasing the number of layers.

Appendix A
Approximation to the identity (AtI)

Definition A.1
(Approximation to the identity
[
7
]
).

A sequence of
symmetric kernel functions

(S_{k}:\mathbb{R}^{n}\times\mathbb{R}^{n}\to\mathbb{R})_{k\in\mathbb{Z}}
is said to be an
approximation to the identity (AtI)
if there exist a quintuple
(\epsilon,\zeta,C,C_{\rho},C_{A})
of positive numbers satisfying the additional constraints

0<\epsilon\leq\frac{1}{n},0<\zeta\leq\frac{1}{n}\text{ and }C_{A}<1

(A.1)

the following three conditions are satisfied for all
k\in\mathbb{Z}
:

(i)

\left|S_{k}({\vec{x}},{\vec{y}})\right|\leq C\frac{2^{-k\epsilon}}{\left(2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)^{1+\epsilon}}
for all
{\vec{x}},{\vec{y}}\in\mathbb{R}^{n}
;

(ii)

\left|S_{k}({\vec{x}},{\vec{y}})-S_{k}({\vec{x}}^{\prime},{\vec{y}})\right|\leq C\left(\frac{C_{\rho}\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n}}{2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}}\right)^{\zeta}\frac{2^{-k\epsilon}}{\left(2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)^{1+\epsilon}}

for all triples
({\vec{x}},{\vec{x}}^{\prime},{\vec{y}})\in\mathbb{R}^{n}\times\mathbb{R}^{n}\times\mathbb{R}^{n}
which satisfy

C_{\rho}\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n}\leq C_{A}\left(2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right);

(A.2)

(iii)

\int_{\mathbb{R}^{n}}S_{k}({\vec{x}},{\vec{y}})d{\vec{y}}=1
for all
{\vec{x}}\in\mathbb{R}^{n}
.

Moreover, we say that the AtI satisfies the
double Lipschitz condition
if there exist a triple
(\tilde{C},\tilde{C}_{A},\zeta)
of positive constants satisfying

\tilde{C}_{A}<\frac{1}{2},

(A.3)

such that for all
k\in\mathbb{Z}

\displaystyle\left|S_{k}({\vec{x}},{\vec{y}})-S_{k}({\vec{x}}^{\prime},{\vec{y}})-S_{k}({\vec{x}},{\vec{y}}^{\prime})+S_{k}({\vec{x}}^{\prime},{\vec{y}}^{\prime})\right|

(A.4)

\displaystyle\leq

\displaystyle\tilde{C}\left(\frac{C_{\rho}\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n}}{2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}}\right)^{\zeta}\left(\frac{C_{\rho}\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|^{n}}{2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}}\right)^{\zeta}\frac{2^{-k\epsilon}}{(2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n})^{1+\epsilon}}

for all quadruples
({\vec{x}},{\vec{x}}^{\prime},{\vec{y}},{\vec{y}}^{\prime})\in\mathbb{R}^{n}\times\mathbb{R}^{n}\times\mathbb{R}^{n}\times\mathbb{R}^{n}
which satisfy

C_{\rho}\max\left\{\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n},\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|^{n}\right\}\leq\tilde{C}_{A}\left(2^{-k}+C_{\rho}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right).

(A.5)

The conditions
item (ii)
and
Equation A.5
are essential for our analysis. We characterize now geometric properties of these constrained sets:

Lemma A.2
.

Let
C_{\rho}=1
,
C_{A}=2^{-n}
and
\tilde{C}_{A}=3^{-n}
.

•

Then set of triples
({\vec{x}},{\vec{x}}^{\prime},{\vec{y}})
which satisfy
Equation A.2
and for which
\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\geq 2^{-k}
and all
t\in[0,1]
satisfy

\left\|{\vec{x}}+t({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}\right\|^{n}\geq 2^{-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-2^{-n}2^{-k}.

(A.6)

•

The set of quadrupels
({\vec{x}},{\vec{x}}^{\prime},{\vec{y}},{\vec{y}}^{\prime})
which satisfy
Equation A.5
and for which
\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\geq 2^{-k}
satisfy

\left\|{\vec{x}}+t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}-t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|^{n}\geq 3^{-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-3^{-n}2^{1-k}

(A.7)

for all
t_{\vec{x}},t_{\vec{y}}\in[0,1]
.

Proof
.

•

With the concrete choice of parameters
C_{A}
,
C_{\rho}

Equation A.2
reads as follows

\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n}\leq 2^{-n}\left(2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right).

(A.8)

Since we assume that
\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\geq 2^{-k}
it follows from
Equation A.8
that

\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|\leq 2^{-1}\left\|{\vec{x}}-{\vec{y}}\right\|.

In particular
\left\|{\vec{x}}-{\vec{y}}\right\|-\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|\geq 0
.

We apply Jensen’s inequality, which states that for
a,b\geq 0

a^{n}+b^{n}\geq 2^{1-n}(a+b)^{n}.

(A.9)

We use
a=\left\|{\vec{x}}+t({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}\right\|
and
b=\left\|t({\vec{x}}^{\prime}-{\vec{x}})\right\|
, which then (along with the triangle inequality) gives

\left\|{\vec{x}}+t({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}\right\|^{n}+\left\|t({\vec{x}}^{\prime}-{\vec{x}})\right\|^{n}\geq 2^{1-n}\left(\left\|{\vec{x}}-{\vec{y}}\right\|\right)^{n}.

In other words, it follows from
Equation A.8
that

\displaystyle\left\|{\vec{x}}+t({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}\right\|^{n}

\displaystyle\geq 2^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-t^{n}\left\|{\vec{x}}^{\prime}-{\vec{x}}\right\|^{n}

\displaystyle\geq 2^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-\left\|{\vec{x}}^{\prime}-{\vec{x}}\right\|^{n}

\displaystyle\geq 2^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-2^{-n}\left(2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)

\displaystyle=2^{-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-2^{-n}2^{-k}.

•

With the concrete choice of parameters
\tilde{C}_{A}
,
C_{\rho}

Equation A.5
reads as follows

\max\left\{\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|^{n},\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|^{n}\right\}\leq 3^{-n}\left(2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right).

(A.10)

Since we assume that
\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\geq 2^{-k}
it follows from
Equation A.10
that

\max\left\{\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|,\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|\right\}\leq 3^{-1}\left\|{\vec{x}}-{\vec{y}}\right\|.

This in particular shows that

\left\|{\vec{x}}-{\vec{y}}\right\|-\left\|{\vec{x}}-{\vec{x}}^{\prime}\right\|-\left\|{\vec{y}}-{\vec{y}}^{\prime}\right\|\geq 0.

We apply Jensen’s inequality, which states that for
a,b,c\geq 0

a^{n}+b^{n}+c^{n}\geq 3^{1-n}(a+b+c)^{n}.

(A.11)

We use
a=\left\|{\vec{x}}+t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}-t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|
,
b=\left\|t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})\right\|
and
c=\left\|t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|
, which then (along with the triangle inequality) gives

\left\|{\vec{x}}+t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}-t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|^{n}+\left\|t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})\right\|^{n}+\left\|t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|^{n}\geq 3^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}.

In other words, it follows from
Equation A.10
that

\displaystyle\left\|{\vec{x}}+t_{\vec{x}}({\vec{x}}^{\prime}-{\vec{x}})-{\vec{y}}-t_{\vec{y}}({\vec{y}}^{\prime}-{\vec{y}})\right\|^{n}

\displaystyle\geq 3^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-t_{\vec{x}}^{n}\left\|{\vec{x}}^{\prime}-{\vec{x}}\right\|^{n}-t_{\vec{y}}^{n}\left\|{\vec{y}}^{\prime}-{\vec{y}}\right\|^{n}

\displaystyle\geq 3^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-\left\|{\vec{x}}^{\prime}-{\vec{x}}\right\|^{n}-\left\|{\vec{y}}^{\prime}-{\vec{y}}\right\|^{n}

\displaystyle\geq 3^{1-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-3^{-n}2\left(2^{-k}+\left\|{\vec{x}}-{\vec{y}}\right\|^{n}\right)

\displaystyle=3^{-n}\left\|{\vec{x}}-{\vec{y}}\right\|^{n}-3^{-n}2^{1-k}.

\square
