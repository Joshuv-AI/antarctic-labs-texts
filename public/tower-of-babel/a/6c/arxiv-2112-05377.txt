Optimal Quaternary ( r , δ ) (r,\delta) -Locally Repairable Codes Achieving the Singleton-type Bound
Kenneth W. Shum, Jie Hao

Abstract
Locally repairable codes enables fast repair of node failure in a distributed storage system. The code symbols in a codeword are stored in different storage nodes, such that a disk failure can be recovered by accessing a small fraction of the storage nodes. The number of storage nodes that are contacted during the repair of a failed node is a parameter called locality. We consider locally repairable codes that can be locally recovered in the presence of multiple node failures. The punctured code obtained by removing the code symbols in the complement of a repair group is called a local code. We aim at designing a code such that all local codes have a prescribed minimum distance, so that any node failure can be repaired locally, provided that the total number of node failures is less than the tolerance parameter. We consider linear locally repairable codes defined over a finite field of size four. This alphabet has characteristic 2, and hence is amenable to practical implementation. We classify all quaternary locally repairable codes that attain the Singleton-type upper bound for minimum distance. For each combination of achievable code parameters, an explicit code construction is given.



Keywords:
Locally repairable codes, maximal distance separable codes, Singleton-like bound, codes with small defect, subspace codes.

I
Introduction

The advent of locally repairable codes is motivated by their application in distributed storage systems. A data file is first divided into chunks of
k
data symbols. Each chunk is encoded separately by an
[n,k]
linear code. The
n
encoded symbols are distributed and stored in
n
different storage nodes. In this paper we will use the terms “storage node” and “disk” interchangeably. If a disk failure occurs, we replace the failed node by a new one, and recover the lost data with the help of the surviving storage nodes. A basic recovery method is to contact
k
other storage nodes, decode the original data file, and then re-encode the lost data. This recovery method incurs excessive network traffic as whole data file is downloaded, but in fact only a small portion of the data file is required.

The network traffic generated during the course of repairing a failed node is termed
repair bandwidth
in
[
1
]
. The authors in
[
1
]
suggest that the new node can contact and download data from all surviving nodes, and each of the other surviving nodes send minimum amount of coded data to the new node, so as to minimize the repair bandwidth. An information-theoretic lower bound on the resulting repair bandwidth is derived, and is shown to be much smaller than the size of the original data file. This type of encoding schemes that minimize repair bandwidth is called
regenerating codes
.

Another approach is to minimize the number of contacted nodes during the repair process. In this repair model, all coded symbols in the contacted node are sent to the new node. The number of contacted nodes is a code parameter called
locality
, which is commonly denoted by the letter
r
. A code symbol is said to have locality
r
if it is a deterministic function of
r
other code symbols. A code with this kind of local property is called a
locally repairable code
, or
locally recoverable code
(LRC). There are two categories of LRCs. In the first category, we only require that there is a set of
k
information symbols such that each of them has locality
r
; the parity-check symbols need not be locally recoverable. A code with this property is said to be a code with
information locality
. A fundamental bound on the LRC with information locality is derived in
[
2
]
. An implementation of this idea in Hadoop file system is investigated in
[
3
]
. In the second category of LRCs, all coded symbols are required to have locality
r
. A code with this type of local property is said to have
all-symbol locality
. Obviously, the latter imposes a more stringent requirement on the code design in compare to the former, and the bound in
[
2
]
is also valid for LRCs with all-symbol locality. In this paper, we will consider LRCs with all-symbol locality. There are many results in the literature about LRCs. We refer the readers to
[
4
,
5
,
6
,
7
,
8
,
9
,
10
]
for a partial list.

In
[
11
]
, the repair model mentioned in the previous paragraph is extended to enable local repair under multiple node failures.
The authors in
[
11
]
give an upper bound on the minimum distance that extends the classical Singleton bound to codes with local properties. A refinement of this bound is recently derived in
[
12
]
. There are a number of constructions of optimal code in this multiple-failure setting. In the literature, we can find constructions using cyclic or constacyclic codes
[
13
,
14
,
15
,
16
]
, generalized RS codes
[
17
]
, and Steiner system
[
18
]
, and finite geometry
[
19
]
, etc. Another source of code constructions is algebraic geometry. Constructions of LRC using algebraic curves and algebraic surfaces are studied in
[
20
,
21
,
22
]
. In this paper, we will focus on optimal linear codes that attain the Singleton-like bound in the multiple-failure setting.

Code design for practical distributed storage systems is limited by computational complexity. The speed of encoding and decoding algorithms is affected by the choice of alphabet. Many existing code constructions of LRC, including those that are based on Reed-Solomon codes and cyclic codes, require the field size to be larger than the code length. For example, families of LRCs whose lengths grow super-linearly as a function of the alphabet size are constructed in
[
23
,
24
]
. We take a slightly different perspective and enumerate the code parameters of all optimal LRCs over a fixed finite field. For field size two and three, binary and ternary locally repairable codes attaining the Singleton-like bound are already characterized in
[
25

27

GF(4)

An explicit code construction is given to each combination of available code parameters. Some of the construction is presented using a parity-check matrix which has the structure of
generalized tensor product
(GTP).
Code constructions using GTP was proposed by Imai and Fujiya in

[

, and
matrix-product code

[

. We remark that the GTP construction is for LRC with disjoint repair groups. In this paper we do not assume that the repair groups are disjoint. Indeed, some of the optimal codes belong to the families of simplex codes and ovoid codes, and they have overlapping repair groups

II
Preliminaries on Optimal Locally Repairable Codes

II-A

Definition of Locally Repairable Codes

We give a formal definition of linear locally repairable codes over a general finite field
GF(q)
, where
q
is a prime power. A linear code
\mathcal{C}
over
GF(q)
with length
n
, dimension
k
and minimum distance
d
is called an
[n,k,d]_{q}
code, or
[n,k,d]
code if the alphabet size
q
is understood from the context. The dimension and minimum distance of
\mathcal{C}
are denoted by
\dim(\mathcal{C})
and
d_{\mathrm{min}}(\mathcal{C})
, respectively.
We label the
n
components of a codeword in
\mathcal{C}
by
[n]:=\{1,2,\ldots,n\}
. Given a subset
\mathcal{X}
of
[n]
, we let
\mathcal{C}_{\mathcal{X}}
denote the
punctured subcode

\mathcal{C}_{\mathcal{X}}:=\{(u_{j})_{j\in\mathcal{X}}\in GF(q)^{|\mathcal{X}|}:\,(u_{1},\ldots,u_{n})\in\mathcal{C}\},

which is also called the
restriction
of
\mathcal{C}
at
\mathcal{X}
. We will assume that
\mathcal{C}_{\mathcal{S}}\neq\{\mathbf{0}\}
for any subset
\mathcal{S}
of
\{1,2,\ldots,n\}
, i.e., no component is identically zero.

For
r\geq 1
and
\delta\geq 2
, we say that
\mathcal{C}
has
locality

r
with
tolerance

\delta
if
\mathcal{C}
there is a collection
\mathscr{R}
of subsets of
[n]
such that

(a)
[n]=\bigcup_{\mathcal{R}\in\mathscr{R}}\mathcal{R}
,

(b)
|\mathcal{R}|\leq r+\delta-1
for all
\mathcal{R}\in\mathscr{R}
,

(c) the minimum distance of
\mathcal{C}_{\mathcal{R}}
is at least
\delta
for all
\mathcal{R}\in\mathscr{R}
.

Each
\mathcal{R}\in\mathscr{R}
is called a
repair group
, and the punctured subcode
\mathcal{C}_{\mathcal{R}}
is called a
local code
. By a slight abuse of notation, we will also call the code symbols indexed by some
\mathcal{R}\in\mathscr{R}
a repair group. Condition (c) forces the size of a repair group to be at least
\delta
. Conditions (b) and (c) guarantee that a code symbol in a repair group
\mathcal{R}
can be recovered by accessing any
|\mathcal{R}|-(\delta-1)\leq r
other code symbols in the repair group
\mathcal{R}
. Since the repair groups cover all the coded symbols by assumption (a), we can recover any
\delta
erasures locally. A code
\mathcal{C}
that satisfies the above requirements is denoted by
(r,\delta)
-LRC. We note that an
(r,\delta)
-LRC is also an
(r^{\prime},\delta^{\prime})
-LRC for all
r^{\prime}\geq r
and
2\leq\delta^{\prime}\leq\delta
.

For
r\geq 1
and
\delta\geq 2
, the minimal distance of an
(r,\delta)
-LRC with length
n
and dimension
k
satisfies a Singleton-type bound
[
11
]
,

d\leq n-k+1-\Big(\Big\lceil\frac{k}{r}\Big\rceil-1\Big)(\delta-1).

(1)

An
(r,\delta)
-LRC achieving this bound with equality is called
Singleton-optimal
, or
optimal
for short.

When
k\leq r
, the bound in (
1
) reduces to the classical Singleton bound, and an optimal LRC attaining (
1
) is an MDS code. We will assume
r<k
in the rest of this paper.

We recall how to define locality in terms of the
dual code

\mathcal{C}^{\perp}:=\{\mathbf{u}\in GF(q)^{n}:\,\mathbf{u}\cdot\mathbf{v}=0\text{ for all }\mathbf{v}\in\mathcal{C}\}.

We denote the
support
of a linear code
\mathcal{D}
of length
n
by

\supp(\mathcal{D}):=\{i\in[n]:\,\text{there exists }\mathbf{u}\in\mathcal{D}\text{ s.t. }u_{i}\neq 0\}.

A linear code
\mathcal{C}
has locality
r
with tolerance
\delta
if and only if we can find a collection
\mathscr{D}
of subcodes in
\mathcal{C}^{\perp}
such that

(a’)
[n]=\bigcup_{\mathcal{D}\in\mathscr{D}}\supp(\mathcal{D})
,

(b’)
|\supp(\mathcal{D})|\leq r+\delta-1
for all
\mathcal{D}\in\mathscr{D}
,

(c’) For any
\mathcal{D}\in\mathscr{D}
and for any subset
\mathcal{X}
of
\supp(\mathcal{D})
of size less than or equal to
\delta-1
, the dimension of
(\mathcal{D})_{\mathcal{X}}
is equal to
|\mathcal{X}|
.

Because we assume that no code symbol is identically zero, a subcode
\mathcal{D}
of
\mathcal{C}^{\perp}
satisfying Condition (c’) must have support size larger than or equal to
\delta
. Condition (c’) ensures that
\mathcal{D}
has dimension at least
\delta-1
.
It is not difficult to verify that the support of a subcode
\mathcal{D}
that satisfies Conditions (b’) and (c’) is a repair group of
\mathcal{C}
.
A generator matrix of a subcode
\mathcal{D}\subset\mathcal{C}^{\perp}
satisfying Conditions (b’) and (c’) is called a
local parity-check matrix
.

We remark that any
\mathcal{D}
in
\mathscr{D}
is a subcode of
\mathcal{C}^{\perp}
with length
n
, and the punctured code
(\mathcal{D})_{\supp(\mathcal{D})}
has length at most
r+\delta-1
.

, respectively. The two repair groups cover all the code symbols and overlap at the 5th component. This parity-check matrix defines an optimal

II-B

Chain of Subcodes and Residue Codes

Definition.
Let
\mathscr{D}
denote the collection of all subcodes of
\mathcal{C}^{\perp}
that satisfies Conditions (b’) and (c’). A sequence of subcodes
\mathcal{D}_{1}
,
\mathcal{D}_{2},\ldots,\mathcal{D}_{m}
in
\mathscr{D}
is said to form a
chain
if

\dim(\mathcal{D}_{1}\oplus\mathcal{D}_{2}\oplus\cdots\oplus\mathcal{D}_{i})-\dim(\mathcal{D}_{1}\oplus\mathcal{D}_{2}\oplus\cdots\oplus\mathcal{D}_{i-1})\geq\delta-1

for
i=2,3,\ldots,m
. The number of subcodes in a chain is called the
length
of the chain. A chain
\mathcal{D}_{1}
,
\mathcal{D}_{2},\ldots,\mathcal{D}_{M}
is said to be
maximal
if

\dim(\mathcal{D}_{1}\oplus\cdots\oplus\mathcal{D}_{M}\oplus\mathcal{D}^{\prime})-\dim(\mathcal{D}_{1}\oplus\cdots\oplus\mathcal{D}_{M})<\delta-1

for any
\mathcal{D}^{\prime}\in\mathscr{D}
. (The notation
\mathcal{D}\oplus\mathcal{D}^{\prime}
stands for the sum space of subspaces
\mathcal{D}
and
\mathcal{D}^{\prime}
.)

A lower bound on the length of a maximal chain is derived in
[
25
,
27
]
.

Proposition 1
.

Given an
(r,\delta)
-LRC
\mathcal{C}
with dimension
k
, a maximal chain of subcodes in
\mathcal{C}^{\perp}
contains at least
\lceil k/r\rceil
subcodes.

The next definition assumes that
\mathcal{C}
is an optimal LRC satisfying the Singleton-like bound (
1
) with equality.

Definition.
Suppose
\mathcal{C}
is a Singleton-optimal
(r,\delta)
-LRC. Let
\mathcal{D}_{1},\ldots,\mathcal{D}_{m}
be a chain with size
m=\lfloor(k-1)/r\rfloor
(such a chain exists by Prop.
1
). The shortened code of
\mathcal{C}
consisting of codewords that are zero in the support of
\mathcal{D}_{1}\oplus\cdots\oplus\mathcal{D}_{m}
is called a
residue code
of
\mathcal{C}
.

The following result is proved in
[
27
, Theorem 1]
.

Proposition 2
.

Suppose
\mathcal{C}
is a Singleton-optimal
(r,\delta)
-LRC with dimension
k
.

(i)

A residue code is an MDS code with minimum distance
n-k-\lfloor(k-1)/r\rfloor(\delta-1)+1
and co-dimension
n-k-\lfloor(k-1)/r\rfloor(\delta-1)
.

(ii)

Any subcode in
\mathcal{C}^{\perp}
that satisfies Conditions (b’) and (c’), i.e., a subcode in
\mathcal{C}^{\perp}
that corresponds to a repair group of
\mathcal{C}
, has dimension
\delta-1
.

(iii)

The restriction of
\mathcal{C}
to any repair group is an MDS code with minimum distance exactly
\delta-1
.

Part (iii) in the above proposition is proved in
[
38
, Theorem 2.2]
under an additional condition that
r|k
. This result actually holds holds without the condition
r|k
. For the sake of completeness, we give the proofs of Prop.
1
and Prop.
2
in Appendix
A
.

We note that there are more than one residue codes; two different chains can give rise to two residue codes with different supports. Two residue codes may have different support length. For example, in Example
II-A
, the residue code of the LRC is a
[4,2,3]
codes over
GF(4)
defined by the parity-check matrix

\begin{bmatrix}1&1&1&1\\
1&\alpha&\alpha^{2}&0\end{bmatrix}.

In Example
II-A
, the residue code is a
[12,1,12]
repetition code.

The next proposition investigates the possible dimension of a residue code.

Proposition 3
.

Suppose
\mathcal{C}
is an optimal
(r,\delta)
-LRC with dimension
k
. We pick a maximal chain of subcodes
\mathcal{D}_{1},\ldots,\mathcal{D}_{M}
in
\mathcal{C}^{\perp}
and construct the associated residue code. The dimension
k^{\prime}
of the residue codes satisfies

k^{\prime}\geq k-\big\lfloor\frac{k-1}{r}\big\rfloor r.

(2)

Moreover, if equality holds, the supports of the first
\lfloor(k-1)/r\rfloor
subcodes in a chain are mutually disjoint.

Proof.

Suppose that the residue code of is an
[n^{\prime},k^{\prime}]
code. From Prop.
2
, we know that the co-dimension equals

n^{\prime}-k^{\prime}=d-1=n-k-\big\lfloor\frac{k-1}{r}\big\rfloor(\delta-1).

After some re-arrangements, this becomes

n-n^{\prime}=k+\big\lfloor\frac{k-1}{r}\big\rfloor(\delta-1)-k^{\prime}.

Since
n-n^{\prime}
is the size of the union of the repair groups associated with the first
\lfloor(k-1)/r\rfloor
subcodes in the chain, we obtain

k+\big\lfloor\frac{k-1}{r}\big\rfloor(\delta-1)-k^{\prime}\leq\big\lfloor\frac{k-1}{r}\big\rfloor(r+\delta-1)

(3)

which is equivalent to the inequality in the proposition.

If equality holds in (
3
) holds, then the support of
\mathcal{D}_{1},\ldots,\mathcal{D}_{\lfloor(k-1)/r\rfloor}
must be mutually disjoint.
∎

Prop.
1
suggests that we can write down a parity-check matrix of an
(r,\delta)
-LRC in a specific form. Given an
(r,\delta)
-LRC
\mathcal{C}
, we first pick a maximal chain of subcodes in
\mathcal{C}^{\perp}
. We form a parity-check matrix by stacking the local parity-check matrices associated to the subcodes in the maximal chain. If the number of rows in this matrix is strictly less than
n-k
, we append additional rows to this matrix to form a parity-check matrix of
\mathcal{C}
. The structure of the resulting parity-check matrix is summarized as follows.

Corollary 4
.

For any Singleton-optimal
(r,\delta)
-LRC with length
n
and dimension
k
, there is a parity-check matrix with the following structure:

•

The rows are divided into an upper part and a lower part;

•

the rows in the upper part of the matrix are partitioned into groups, with each group corresponding to a repair group;

•

there are at least
\lceil k/r\rceil
groups, and each of these group occupies exactly
\delta-1
rows;

•

any
\delta-1
columns chosen within the support of a repair group are linearly independent;

•

the lower part of the matrix, which may or may not be empty, corresponds to global parity-check equations of the code.

An example of parity-check matrix that is in the form described by the above corollary can be found in Fig.
1
. In the matrix in Fig.
1

Proposition 8
.

Let
\mathcal{C}
be an optimal
q
-ary
k
-dimensional
(r,\delta)
-LRC with minimum distance
d_{\mathrm{min}}(\mathcal{C})
strictly larger than
q
. Then

(i)

a residue code of
\mathcal{C}
has dimension 1, and is equivalent to a repetition code;

(ii)

r|(k-1)
;

(iii)

each repair group
\mathcal{R}
in
\mathcal{C}
has size
r+\delta-1
;

(iv)

furthermore, if
k>2r
, then the code length
n
is divisible by
r+\delta-1
, and the code symbols can be partitioned into disjoint repair groups of size
r+\delta-1
.

Proof.

(i) Under the hypothesis that
\mathcal{C}
has minimum distance larger than
q
, the residue code is an MDS code with minimum distance larger than
q
. Part (i) then follows from Theorem
5
.

(ii) The property
r|(k-1)
is a direct consequence of Theorem
6
.

(iii) Let
\mathscr{D}
be the set of all subcodes in
\mathcal{C}^{\perp}
that satisfy Conditions (b’) and (c’).
Suppose
\mathcal{R}_{0}
is a repair group with size strictly less than
r+\delta-1
, and
\mathcal{D}_{0}
be the subcode in
\mathcal{C}^{\perp}
associated with
\mathcal{R}_{0}
. We form a chain as follows. We initialize by letting
\mathcal{D}_{0}
be the first subcode in the chain, and iteratively append a subcode to it if the resulting list satisfies the definition of chain. We stop when the chain is maximal. By Prop.
1
, we have at least
\lceil k/r\rceil
subcodes in the chain. By part (ii), we know that
\lceil k/r\rceil-1=(k-1)/r
is a positive integer. Since one of the subcode in the chain has support strictly less than
r+\delta-1
, the support of
\mathcal{D}_{1}\oplus\cdots\oplus\mathcal{D}_{(k-1)/r}
is upper bounded by

|\supp(\mathcal{D}_{1}\oplus\cdots\oplus\mathcal{D}_{(k-1)/r})|\leq\frac{k-1}{r}(r+\delta-1)-1

(27)

From Prop.
2
we know that the co-dimension of the residue code is
n-k-\frac{k-1}{r}(\delta-1)
. Hence, the dimension of the residue code is lower bounded by

\displaystyle[n-(\frac{k-1}{r}(r+\delta-1)-1)]-[n-k-\frac{k-1}{r}(\delta-1)]\geq 2.

We can now apply Theorem
5
and get a contradiction that
d_{\mathrm{min}}(\mathcal{C})\leq q
.

(iv) Suppose
k>2r
. Under this assumption, any maximal chain has at least three subcodes. If there are two overlapping repair groups, we can set up a chain with these two overlapping subcodes as the first two subcodes. The support size of the first
(k-1)/r
subcodes in this chain is upper bounded by (
27
). We can repeat the same argument in part (iii) and show that the residue code has dimension at least 2. By Theorem
5
, we get a contradiction
d_{\mathrm{min}}(\mathcal{C})\leq q
. This shows that any two subcodes in
\mathscr{D}
has mutually disjoint supports. Since all repair groups has the same size, namely
r+\delta-1
, the code length must be divisible by
r+\delta-1
.
∎

IX

Concluding Remarks

In this paper we classify quaternary
(r,\delta)
LRC with
\delta>2
. With three exceptions, all possible combinations of code parameters are found, and for each combination of code parameters we provide an explicit code construction.
The result of the classification is shown in Table.
I
. The codes can be divided into two groups. The first group has locality
r=1
. The code length and minimum distance can get arbitrarily large in this group. In the second group, the locality parameter
r
is larger than or equal to 2, and the minimum distance is bounded between 3 and 12. For minimum distance
d=3
or
d=4
, we have a sequence of optimal LRCs for each combination of
(r,\delta)
. For minimum distance
d>4
, we have infinitely many optimal LRCs of increasing lengths only when
r=3
,
\delta\in\{3,4\}
and
k>r+1
. In the remaining combinations of
r
and
\delta
, there are either no or finitely many LRCs that are Singleton-optimal.

The first unsettled case in the classification is
(3,3)
-LRC with
\ell=\sigma+2
, where
\ell
is the number of repair groups and
\sigma=\lfloor k/r\rfloor-1
. The largest possible minimum distance is 10 by the Singleton-type bound. Nevertheless, due to the special weight distribution of the quaternary
[5,3]
MDS code, we conjecture that minimum distance 10 is not achievable. The second open case is
(2,3)
-LRC with
\ell=\sigma+3
repair groups and minimum distance 12. We give a construction for 5 repair groups, but it is now known whether longer code exists. The last unsettled case is
(r,\delta)=(3,4)
and
d=12
. We prove that the repair groups are disjoint and the there are at most 21 repair groups. We can construct a
(3,4)
-LRC with 17 repair groups and minimum distance 12. Whether we can extend it to 18 to 21 repair groups is an open question.
