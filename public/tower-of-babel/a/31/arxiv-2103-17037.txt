Existential Refinement on the search of integer solutions for the Diophantine equation x 3 + y 3 + z 3 = n x^{3}+y^{3}+z^{3}=n

Abstract
We propose a new algorithm, call S.A.M to determinate the existence of the solutions for the equation x 3 + y 3 + z 3 = n x^{3}+y^{3}+z^{3}\,=\,n for a fixed value n > 0 n\,>\,0 unknown.

\displaystyle\forall\hskip 5.69046ptZ_{\phi a}\odot Z_{\phi b}\equiv v_{a}\odot\hskip 2.84544ptv_{b}~(mod~9)

Proof:

If:

\displaystyle\begin{matrix}\vskip 5.69046ptv_{a},Z_{\phi a}\in\phi^{a}\rightarrow v_{a}\equiv Z_{\phi a}~(mod\hskip 2.84544pt9)\\
\vskip 5.69046ptv_{b},Z_{\phi b}\in\phi^{b}\rightarrow v_{b}\equiv Z_{\phi b}~(mod\hskip 2.84544pt\hskip 2.84544pt9)\\
v_{c},Z_{\phi c}\in\phi^{c}\rightarrow v_{c}\equiv Z_{\phi c}~(mod\hskip 2.84544pt9)\end{matrix}

Then by definition:

\displaystyle\begin{matrix}(\phi\odot\phi)^{a+b=}=\left\{x\in\mathbb{Z}\mid x\equiv Z_{\phi a}+Z_{\phi b}=Z_{\phi c}~(mod\hskip 2.84544pt9)\right\}\end{matrix}

From where:

\displaystyle\begin{matrix}\vskip 5.69046ptx-(Z_{\phi a}+Z_{\phi b}=Z_{\phi c})=9t,\hskip 5.69046ptfor\hskip 2.84544ptt\in\mathbb{Z}\\
\vskip 5.69046ptx=9t+(Z_{\phi a}+Z_{\phi b}=Z_{\phi c})\\
\vskip 5.69046ptx=9t+[(v_{a}-9q)+(v_{b}-9r)=(v_{c}-9s)]\hskip 5.69046ptfor\hskip 5.69046ptq,r,s\in\mathbb{Z}\\
\vskip 5.69046ptx=9t+[(v_{a}+v_{b})-9(q+r)=v_{c}-9s]\\
\vskip 5.69046ptx=9t+[(v_{a}+v_{b})-9(q+r)+9s=v_{c}]\\
\vskip 5.69046ptx=9t+[9(-q-r+s)+(v_{a}+v_{b})=v_{c}]\\
\vskip 5.69046ptx=9(-q-r+s+t)+(v_{a}+v_{b})=v_{c}\\
\rightarrow x\equiv v_{a}+v_{b}=v_{c}\hskip 5.69046pt(mod\hskip 2.84544pt9)\therefore x\in(\phi\odot\phi)^{a+b=c}.\hskip 5.69046pt\square\end{matrix}

We can understand by the results of the S.A.M. algorithm the following:

•

There exists a finite set of combinations for each outcome class.

•

There is a pattern in the proportion of how the outcome classes appear.

This shows that there are classes of results with a higher degree of difficulty, while the rest appear more frequently and all this is related to the number of combinations.

To calculate these combinations we use what we have learned from the matrix and together with the algorithm manage to obtain a considerable amount of combinations, to optimize the process and have the results fixed, discarding the combinations that are commutative between them and only keep those that are different from each other.

In this way it is easier to identify which classes of
k
will appear more frequently, since they are those that present a greater number of combinations.
