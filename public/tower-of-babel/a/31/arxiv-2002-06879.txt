Tight Quantum Lower Bound for Approximate Counting with Quantum States
Aleksandrs Belovs, Ansis Rosmanis

Abstract
We prove tight lower bounds for the following variant of the counting problem considered by Aaronson et al. [ 1 ] . The task is to distinguish whether an input set x ⊆ [ n ] x\subseteq[n] has size either k k or k ′ = ( 1 + ε ) ​ k k^{\prime}=(1+\varepsilon)k . We assume the algorithm has access to • the membership oracle, which, for each i ∈ [ n ] i\in[n] , can answer whether i ∈ x i\in x , or not; and • the uniform superposition | ψ x ⟩ = ∑ i ∈ x | i ⟩ / | x | \mathopen{}\mathclose{{\left|\psi_{x}}}\right>=\sum_{i\in x}\mathopen{}\mathclose{{\left|i}}\right>/\sqrt{|x|} over the elements of x x . Moreover, we consider three different ways how the algorithm can access this state: – the algorithm can have copies of the state | ψ x ⟩ \mathopen{}\mathclose{{\left|\psi_{x}}}\right> ; – the algorithm can execute the reflecting oracle which reflects about the state | ψ x ⟩ \mathopen{}\mathclose{{\left|\psi_{x}}}\right> ; – the algorithm can execute the state-generating oracle (or its inverse) which performs the transformation | 0 ⟩ ↦ | ψ x ⟩ \mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|\psi_{x}}}\right> . Without the second type of resources (the ones related to | ψ x ⟩ \mathopen{}\mathclose{{\left|\psi_{x}}}\right> ), the problem is well-understood, see Brassard et al. [ 15 ] . The study of the problem with the second type of resources was recently initiated by Aaronson et al. [ 1 ] . We completely resolve the problem for all values of 1 / k ≤ ε ≤ 1 1/k\leq\varepsilon\leq 1 , giving tight trade-offs between all types of resources available to the algorithm. We also demonstrate that our lower bounds are tight. Thus, we close the main open problems from [ 1 ] . The lower bounds are proven using variants of the adversary bound from [ 9 ] and employing representation theory of the symmetric group applied to the S n S_{n} -modules ℂ ( [ n ] k ) \mathbb{C}^{\binom{[n]}{k}} and ℂ ( [ n ] k ) ⊗ ℂ \mathbb{C}^{\binom{[n]}{k}}\otimes\mathbb{C} .

Introduction

1.1
Motivation

The theory of quantum query algorithms deals extensively with the standard input oracle, which is the canonical quantum counterpart of the usual deterministic input oracle.
Other kinds of input oracles have received much less attention, especially from the lower bound point of view.
We find this unfortunate, since these questions are not only interesting theoretically, but also come up in practice.

There are two main techniques for proving quantum query lower bounds: the polynomial method and the adversary method.
The polynomial method was developed by Beals, Buhrman, Cleve, Mosca, and de Wolf
[
7

The adversary bound was first formulated by Ambainis

Afterwards, a significant strengthening was obtained by Høyer, Lee, and Špalek
[

1.4
Techniques

A substantial difference between our paper and
[
1
]
is in the techniques used. Aaronson
et al.
use the method of Laurent polynomials, whereas we use the adversary method combined with representation theory of the symmetric group.

The method of Laurent polynomials is a generalisation of the aforementioned polynomial method.
In Laurent polynomials, negative powers of the variables are allowed.
The positive degree bounds the number of executions of the membership oracle (like in the original version), executions of the reflecting oracle, and the number of copies, whereas the negative degree bounds the latter two.

As mentioned previously, we use the general version of the adversary bound from
[
9
]
.
Moreover, we use the version of the bound that allows for several input oracles that can be queried independently.
The adversary method with several input oracles was already used by Kimmel, Lin, and Lin in
[
22
]
, but we use a different approach.

Let us return to the proof of Theorem
1.1
.
Using the above machinery, we formulate the lower bound as an optimisation problem.
Since the problem is symmetric, we can use representation theory of the symmetric group.
This gives a simplified optimization problem, which yields the required lower bound in a relatively simple way.
This simplification step can be applied to other symmetric problems that use access to the state (
1.1
).
Also, we give a different approach to representation theory of the symmetric group compared to previous papers like
[
28
]
.
It is based on the use of group algebra to identify isotypical subspaces within a module.

Our technique has a number of advantages compared to the Laurent polynomials.
The Laurent-polynomial method depends crucially on the state being a uniform superposition over some set, the size of the set being an important parameter.
While Laurent polynomials can handle a restricted number of possible input resources,
adversary method, in principle, can be applied to any state-generating, reflecting, or any other type of input oracle.
Laurent polynomials also cannot distinguish between copies of the state and invocations of the reflecting oracle, whereas we are able to count all input resources independently.

1.6
Discussion and Future Work

With Lemmata
4.2
–
4.5
at our disposal, the proof of our lower bound is relatively concise and direct.
We believe that similar estimates can be helpful for other problems involving oracles that prepare uniform superpositions over some unstructured set.
Our approach to representation theory of the symmetric group follow a clear pattern, and can be used to analyse other related modules.

Let us mention one open problem here.
In the
k
-fold search problem, the input
x
is a set of size
k
, and the task is to output
x
.
We are interested in trade-offs between different resources, as defined in this paper,
and the success probability
.
This problem is solved for the membership oracle by Klauck, Špalek, and de Wolf
[
23
]
using the polynomial method, and by Ambainis
[
3
]
using a variant of the adversary method.
A recent paper
[
5
]
is a preliminary step in that direction.

One complication is that our techniques are not well-suited for problems with small success probability.
We are using a variant of the so-called
additive
adversary, which is not capable of proving better-than-linear dependence on the success probability
[
31
]
.
Therefore, one might require generalisation of the techniques in
[
9
]
to allow small success probability and reformulation of the techniques of the current paper to fit that generalisation.
Let us note that the ideas from the aforementioned proof by Ambainis
[
3
]
were later generalised by Špalek into a
multiplicative
version of the adversary bound
[
31
]
, suited for small success probabilities.
It is not clear at the moment how to merge the ideas of Špalek with our techniques.

Finally, the version of the adversary bound for several input oracles used in this paper inspired formulation of quantum Las Vegas query complexity in
[
13
,
11
]
.

Assume that in the settings of state conversion, Definition

It is possible to come up with various ways of providing access to these oracles simultaneously.

This is the model we assume in Appendix
A
for the algorithms that match the lower bounds of Theorem
1.1
.

Since we are interested in proving lower bounds, we allow as flexible a model as possible, which later was formalised as quantum Las Vegas query complexity in
[
13
]
.
This model incorporates the scenarios as above via standard technique of postponed measurements.
Additionally, it is easy to reconcile with Definition
2.2
, as we formally combine all the input oracles into one.
The only thing that changes is the way how we count the number of queries.

We model our algorithm as a usual single-oracle quantum query algorithm as in Definition
2.2
with access to the combined input oracle
O_{x}
on
\mathcal{M}=\mathcal{M}^{(1)}\oplus\cdots\oplus\mathcal{M}^{(r)}
given by

O_{x}=O^{(1)}_{x}\oplus O^{(2)}_{x}\cdots\oplus O^{(r)}_{x}.

We will not restrict the number of queries to this combined oracle per se.
Instead of that, we will account for the query complexity of each of the individual input oracles post factum.

Let
\psi_{t,x}
be the state of the algorithm on input
x
just before the
t
-th application of the combined input oracle.
As in Definition
2.2
, assume that on the
t
-th query, the oracle is executed as

I^{\prime}\oplus(I\otimes O_{x})=I^{\prime}\oplus\bigl(I\otimes O^{(1)}_{x}\bigr)\oplus\bigl(I\otimes O^{(2)}_{x}\bigr)\cdots\oplus\bigl(I\otimes O^{(r)}_{x}\bigr).

Decompose the state
\psi_{t,x}
in the same way:

\psi_{t,x}=\psi^{(0)}_{t,x}\oplus\psi^{(1)}_{t,x}\oplus\psi^{(2)}_{t,x}\oplus\cdots\oplus\psi^{(r)}_{t,x}

so that
\psi^{(i)}_{t,x}
is processed by
I\otimes O^{(i)}_{x}
, and
\psi^{(0)}_{t,x}
remains intact.
In the case when the inverse oracle
I^{\prime}\oplus(I\otimes O_{x}^{-1})
is applied, we define
\psi^{(i)}_{t,x}
similarly.

Now we
define
the query complexity of the oracle
O^{(i)}
on input
x
as

L^{(i)}_{x}=\sum_{t}\mathopen{}\mathclose{{\left\lVert\psi_{t,x}^{(i)}}}\right\rVert^{2}.

(2.3)

Thus, query complexity can vary for different inputs
x
.
The total query complexity of the
i
-th input oracle is defined as the maximum of
L^{(i)}_{x}
over all
x\in D
.

2.3
Definitions of the Input Oracles

In this section, we define the input oracles available to the algorithm.
We use the same notation
O=(O_{x})
to denote any input oracle, as it will be clear from the context which one is meant in each case.
For state-generating and membership oracles, we first give a more general definition, and then a more restricted version, which is without loss of generality.

•

First, we define the
state-generating input oracle
.
In this case, for each
x\in D
, the algorithm is given a black-box access to a unitary
O_{x}
performing the transformation
\mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|\psi_{x}}}\right>
in
\mathcal{M}=\mathbb{C}^{n}
, where
\mathopen{}\mathclose{{\left|0}}\right>
is some fixed state in
\mathcal{M}
.
The algorithm should work for any unitary
O_{x}
performing this transformation
4
4

4

To formally encapsulate this into the formalism of Definition
2.2
, we can assume the labels are of the form
(x,O)
, where
x\in D
is the original label, and
O
is some legitimate input oracle for
x
.

.

Alternatively, one may assume that
\mathcal{M}
is
n+1
-dimensional:
\mathcal{M}=\mathbb{C}^{\{0\}\cup[n]}
, and the state
\mathopen{}\mathclose{{\left|0}}\right>
is orthogonal to all
\psi_{x}
.
The transformation
O_{x}
is the reflection about the orthogonal complement of
(\mathopen{}\mathclose{{\left|0}}\right>-\mathopen{}\mathclose{{\left|\psi_{x}}}\right>)/\sqrt{2}
:

O_{x}=I-\bigl(\mathopen{}\mathclose{{\left|0}}\right>-\mathopen{}\mathclose{{\left|\psi_{x}}}\right>\bigr)\bigl(\mathopen{}\mathclose{{\left|0}}\right>-\mathopen{}\mathclose{{\left|\psi_{x}}}\right>\bigr)^{*}.

(2.4)

This is a special case of the above transformation, and it can be implemented using two invocations of
any
input oracle mapping
\mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|\psi_{x}}}\right>
: one inverse and one direct.

•

Second, we define the
reflecting input oracle
.
In this case, the black-box unitary
O_{x}
is the reflection about the state
\psi_{x}
:
O_{x}=2\psi_{x}\psi_{x}^{*}-I
in
\mathcal{M}=\mathbb{C}^{n}
.

•

Third, we use the
standard (membership) input oracle
.
In this case, we treat
D
as a subset of the set
\{0,1\}^{n}
of bit-strings of length
n
and
\mathcal{M}=\mathbb{C}^{n}\otimes\mathbb{C}^{2}
.
For
x\in D
, the corresponding input oracle performs the transformation
O_{x}\colon\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|x_{i}}}\right>
.
The algorithm should work for any unitary
O_{x}
performing this transformation.
This can be seen as a direct sum of state-generating oracles performing transformations
\mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|x_{i}}}\right>
over all
i\in[n]
.

Alternatively, one may assume that
O_{x}
performs the transformation

O_{x}\colon\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|b}}\right>\mapsto\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|b\oplus x_{i}}}\right>,

(2.5)

where
i\in[n]
,
b\in\{0,1\}
and
\oplus
is the XOR operation.
This is the usually assumed special case of the above transformation
[
16
]
.
And, again, it can be implemented using two invocations of any input oracle mapping
O_{x}\colon\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|0}}\right>\mapsto\mathopen{}\mathclose{{\left|i}}\right>\mathopen{}\mathclose{{\left|x_{i}}}\right>
.

It is easy to see that, for any given state, the state-generating input oracle is at least as strong as both the reflecting oracle and a copy of the state.
Indeed, it is possible to implement the reflecting oracle using the state-generating oracle twice; and, using it once, it is possible to get a copy of the state.
Other than that, the above resources are incomparable.

3
General Adversary Method

The aim of this section is to describe the techniques used in the proof of the lower bound.
We extend on the general adversary method from
[
9
]
, and we adopt a lower-bound-related perspective.

3.1
Formulation for Multiple Input Oracles

We need few pieces of notation.
First, for an input oracle
O=(O_{x})_{x\in D}
, we define a family of matrices
representing
the input oracle, where
x,y
range over
D
:

\Delta_{x,y}=O_{x}-O_{y}.

(3.1)

For pairs
\xi_{x}\mapsto\tau_{x}
of states, where
x
ranges over
D
, we define a
D\times D
-matrix
E
given by

E[\![x,y]\!]=\mathopen{}\mathclose{{\left\langle\xi_{x},\xi_{y}}}\right\rangle-\mathopen{}\mathclose{{\left\langle\tau_{x},\tau_{y}}}\right\rangle,

(3.2)

which
represents
state conversion
\xi_{x}\mapsto\tau_{x}
.
We often treat
E
as a family of
1\times 1
-matrices indexed by
x,y\in D
.

Assume
(A_{x,y})_{x,y\in D}
is a family of matrices all of the same size.
Let
\Gamma
be an
X\times Y
matrix with
X,Y\subseteq D
.
We define
\Gamma\circ A
as the
X\times Y
block matrix, where the block corresponding to
x\in X
and
y\in Y
is given by
\Gamma[\![x,y]\!]A_{x,y}
.
This is a generalisation of the usual Hadamard product.

Now we define a variant of the adversary bound for multiple input oracles, which follows the same ideas as in the proof of negative-weighted adversary
[
19
,
9
]
.

Theorem 3.1

(State Conversion, Multiple Input Oracles)
.

Consider the state-conversion problem
\xi_{x}\mapsto\tau_{x}
with input oracles
O^{(1)},O^{(2)},\dots,O^{(r)}
.
Let
\Delta^{(1)},\Delta^{(2)},\dots,\Delta^{(r)}
be defined like in (
3.1
) for these oracles, and
E
be as in (
3.2
).
Then, for any
D\times D
-matrix
\Gamma
and every algorithm performing the state conversion exactly, we have

\sum_{i=1}^{r}\bigl\lVert\Gamma\circ\Delta^{(i)}\bigr\rVert\max_{x\in D}L_{x}^{(i)}\geq\|\Gamma\circ E\|,

where
L_{x}^{(i)}
are as in (
2.3
).

We prove this theorem in Appendix
C
.
The following easy corollary is useful.

Corollary 3.2
.

Consider the state-conversion problem
\xi_{x}\mapsto\tau_{x}
with
r=O(1)
input oracles
O^{(1)},O^{(2)},\dots,O^{(r)}
.
Let
E
be as in (
3.2
), and
\Delta^{(1)},\Delta^{(2)},\dots,\Delta^{(r)}
be as in (
3.1
).

Then, for any
D\times D
-matrix
\Gamma
, and every algorithm performing the state conversion exactly, there exists
i
such that the query complexity of
O^{(i)}
is

\max_{x\in D}L^{(i)}_{x}=\Omega\mathopen{}\mathclose{{\left(\frac{\|\Gamma\circ E\|}{\|\Gamma\circ\Delta^{(i)}\|}}}\right).

(3.3)

For one input oracle, and if
E
corresponds to function evaluation, this becomes the usual adversary bound by Høyer
et al.

[
19
]
.
Intuitively, our formulation says that if we want to prove a lower bound against a collection of oracles, it suffices to find an adversary matrix
\Gamma
which is a solution to all single-oracle versions of the bounds simultaneously.

3.2
Alternative Input and Output Conditions

Corollary
3.2
is rather cumbersome to apply in its original form due to various
\tau_{x}
vectors allowed in Definition
2.3
because of permitted error
\delta
, and the necessity to deal with complicated matrices
\Delta_{x,y}
.
Luckily, it is possible to simplify the bound using equivalent ways to represent input and output conditions.

We start with the output condition for approximate function evaluation with initial states.
We assume notation of Definition
2.3
.
In particular,
\delta
is the error parameter of the algorithm, and we also let
X=f^{-1}(1)
and
Y=f^{-1}(0)
.
In this context, we will switch from
D\times D
-matrices to
X\times Y
-matrices.
Let
\Xi
be the
X\times Y
-matrix defined by
\Xi[\![x,y]\!]=\mathopen{}\mathclose{{\left\langle\xi_{x},\xi_{y}}}\right\rangle
.
The following result
[
24
]
effectively reduces the approximate case to the exact case.
See Appendix
B
for a proof.

Lemma 3.3
.

In the above notation, assume that
\Gamma
is an
X\times Y
-matrix that satisfies

\|\Gamma\|=1\qquad\text{and}\qquad\|\Gamma\circ\Xi\|\geq 3\sqrt{\delta}.

(3.4)

Then, for every state conversion problem
\xi_{x}\mapsto\tau_{x}
that corresponds to evaluation of the function
f
with initial states
\xi_{x}
and permitted error
\delta
, we get

\|\Gamma\circ E\|\geq\sqrt{\delta},

(3.5)

where
E
is defined in (
3.2
).

Now let us move to the input conditions.
The key idea is the following definition.

Definition 3.4

(
\gamma_{2}
-equivalence)
.

Let
\Delta=(\Delta_{x,y})
and
\Delta^{\prime}=(\Delta^{\prime}_{x,y})
be two families of matrices both indexed by
x,y\in D
.
If, for every
D\times D
-matrix
\Gamma
, we have

\frac{\|\Gamma\circ\Delta\|}{\|\Gamma\circ\Delta^{\prime}\|}=\Theta(1),

then we say that
\Delta
and
\Delta^{\prime}
are
\gamma_{2}
-equivalent
.
If
\Delta^{\prime}
is
\gamma_{2}
-equivalent to the family
\Delta
defined in (
3.1
), then we say that
\Delta^{\prime}

represents
the input oracle
O=(O_{x})
.

We will often have that
\Delta^{\prime}=A^{(1)}\oplus\cdots\oplus A^{(\ell)}
meaning that
\Delta^{\prime}_{x,y}=A^{(1)}_{x,y}\oplus\cdots\oplus A^{(\ell)}_{x,y}
for all
x,y\in D
.
In this case, we will say that the input oracle is represented by a tuple
A^{(1)},\dots,A^{(\ell)}
.
The following identity can be used in this case:

\bigl\lVert\Gamma\circ(A^{(1)}\oplus\cdots\oplus A^{(\ell)})\bigr\rVert=\max_{i\in[\ell]}\bigl\lVert\Gamma\circ A^{(i)}\bigr\rVert.

The idea is that we replace
\Delta^{(i)}
in the denominator of (
3.3
) with any
\gamma_{2}
-equivalent
\Delta^{\prime(i)}
, which changes the bound by at most a constant factor.
Thus, we can find a representation that is easier to work with.
This is what we will do in the remaining part of this section for the input oracles defined in Section
2.3
.
The results are from previous papers, and their proofs are given in Appendix
B
for completeness.

For the reflecting oracle, defined by
O_{x}=2\psi_{x}\psi_{x}^{*}-I
, we will use the standard definition (
3.1
) removing the constant factor 2.
Thus, the following family represents the reflecting oracle:

\Delta^{\psi\psi^{*}}_{x,y}:=\psi_{x}\psi_{x}^{*}-\psi_{y}\psi_{y}^{*}.

(3.6)

We use mnemonic
\psi\psi^{*}
, which reminds of the definition.

The state-generating oracle is represented
[
10
]
by the family
\Delta^{\psi}\oplus\Delta^{\psi^{*}}
, where

\Delta^{\psi}_{x,y}:=\psi_{x}-\psi_{y}\qquad\text{and}\qquad\Delta^{\psi^{*}}_{x,y}:=\psi_{x}^{*}-\psi_{y}^{*}.

(3.7)

Finally, the following family represents
[
9
]
the membership oracle:

\Delta^{\mathrm{membership}}_{x,y}:=\bigoplus\nolimits_{i\in[n]}1_{x_{i}\neq y_{i}}.

(3.8)

Here
\bigoplus
stands for the direct sum of
1\times 1
matrices, hence,
\Delta^{\mathrm{membership}}_{x,y}
is a diagonal
n\times n
matrix.
The usual way to write
\Delta^{\mathrm{membership}}
is as
\Delta_{1}\oplus\cdots\oplus\Delta_{n}
, where

\Delta_{i}[\![x,y]\!]:=1_{x_{i}\neq y_{i}}.

(3.9)

Again, we treat these
D\times D
-matrices as families of
1\times 1
-matrices.

3.3
Application to Approximate Counting

Let us apply the above results for the special case of approximate counting of Theorem
1.1
.
In this case, the set
D
of labels is

, where

consists of all the
n
-bit strings of Hamming weight

consists of all the
n
-bit strings of Hamming weight

Define an

where

The Gram matrix of the initial states,

Proposition 3.5
.

Assume we can find an

\Gamma
such that

•

\|\Gamma\|=1
;

•

with
\Psi

);

•

);

Then, there exists a constant

such that every quantum algorithm, given

times;

•

or execute the state-generating oracle

•

Proof of Proposition
3.5
.

Let a constant

be such that

Assume the error parameter of the algorithm is

We may achieve this by repeating the algorithm

By Remark

The proposition follows from Corollary

using the representations of the input oracles from Section

∎

4
Lower Bound

In this section, we prove the lower bound for approximate counting, Theorem

.
First, in Section

4.1
Main Lemmata

In this section, we give the general form of the adversary matrix
\Gamma
and give estimates on the norm of the matrix when various
\Delta

Using a variant of the automorphism principle as in

\Gamma

5.1
Representation theory

In this section, we introduce basic notions from representation theory of finite groups. For more background, the reader may refer to
[
17
,
30
]
.

Let
G
be a finite group.
The
group algebra

\mathbb{C}G
consists of formal linear combinations of the form
\sum_{g\in G}\alpha_{g}g
with
\alpha_{g}\in\mathbb{C}
.
It is clearly a linear space, but it is also an algebra because we can extend the multiplication law of
G
to all
\mathbb{C}G
by linearity.
A
left module
over
\mathbb{C}G
is a vector space
\mathcal{M}
with a left multiplication operation by the elements of
\mathbb{C}G
satisfying the usual associativity and distributivity axioms and such that
ev=v
for
e
the identity in
G
and every
v\in\mathcal{M}
.
Such modules are also known as representations of
G
.
We will use the term
G
-module
, which is a standard
[
29
,
21
]
misnomer, since what is actually meant is a
\mathbb{C}G
-module. We can treat elements of
\mathbb{C}G
as linear operators acting on
\mathcal{M}
.
Due to linearity, it suffices to specify these operators for
g\in G
.

We assume the module
\mathcal{M}
is equipped with a
G
-invariant
inner product, that is,
\mathopen{}\mathclose{{\left\langle gv,gu}}\right\rangle=\mathopen{}\mathclose{{\left\langle u,v}}\right\rangle
for all
u,v\in\mathcal{M}
and
g\in G
.
Thus, the linear operators corresponding to
g\in G
are unitary.
If
\mathcal{V}
and
\mathcal{W}
are two
G
-modules, then the direct sum
\mathcal{V}\oplus\mathcal{W}
and the tensor product
\mathcal{V}\otimes\mathcal{W}
are also
G
-modules defined by
g(v,w)=(gv,gw)
and
g(v\otimes w)=(gv)\otimes(gw)
for all
v\in\mathcal{V}
,
w\in\mathcal{W}
, and
g\in G
.

A
G
-morphism
(or just morphism, if
G
is clear from the context) between two
G
-modules
\mathcal{V}
and
\mathcal{W}
is a linear operator
\theta\colon\mathcal{V}\to\mathcal{W}
that commutes with all
\alpha\in\mathbb{C}G
:
\theta\alpha=\alpha\theta
. By linearity, it suffices to check commutativity with all
\alpha\in G
. Let us denote by
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{W})
the linear space of
G
-morphisms from
\mathcal{V}
to
\mathcal{W}
.

An important special case of a
G
-module is
\mathbb{C}^{X}
, where
X
is a finite set with a
group action of
G
on it.
A group action is a map
(g,x)\mapsto g(x)
from
G\times X
onto
X
satisfying
g(h(x))=(gh)(x)
for all
g,h\in G
and
x\in X
.
By linearity, this gives a
G
-module.
The linear operators on
\mathbb{C}^{X}
corresponding to
g\in G
are given by permutation matrices. Hence, the standard inner product in
\mathbb{C}^{X}
is
G
-invariant.
We have the following easy characterisation of morphisms in this case:

Proposition 5.1
.

Assume
X
and
Y
are two sets with group action of
G
defined on them.
A linear operator
A\colon\mathbb{C}^{Y}\to\mathbb{C}^{X}
is a
G
-morphism if and only if
A[\![x,y]\!]=A[\![g(x),g(y)]\!]
for all
x\in X
,
y\in Y
, and
g\in G
.

A
G
-module is called
irreducible
(or irrep) if it does not contain a non-trivial
G
-submodule.
Schur’s Lemma is an essential result in representation theory, stated as follows.

Lemma 5.2

(Schur’s Lemma)
.

Assume
\theta\colon\mathcal{V}\to\mathcal{W}
is a morphism between two irreducible
G
-modules
\mathcal{V}
and
\mathcal{W}
.
If
\mathcal{V}
and
\mathcal{W}
are non-isomorphic, then
\theta=0
.
Otherwise,
\theta
is uniquely determined up to a scalar multiplier.

In other words, the second part of the above lemma states that
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{V})\cong\mathbb{C}
for irreducible
\mathcal{V}
.
Let us note that while the first part holds for any base field, for the second part it is essential that the base field
\mathbb{C}
is algebraically closed.

Schur’s Lemma has a large number of consequences.
First, on an irrep
\mathcal{V}
, there is only one, up to a scalar multiplier,
G
-invariant inner product.
Hence, any isomorphism between two irreducible
G
-modules is an isometry times a scalar.
Second, if
\mathcal{M}
is a
G
-module, and
\mathcal{V}
and
\mathcal{W}
are two its non-isomorphic irreducible submodules, then
\mathcal{V}
and
\mathcal{W}
are orthogonal as subspaces.

Let
\mathcal{V}
be an irrep.
A submodule of
\mathcal{M}
isomorphic to
\mathcal{V}
is called a
copy
of
\mathcal{V}
in
\mathcal{M}
.
The dimension of
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})
is known as the
multiplicity
of
\mathcal{V}
in
\mathcal{M}
.
It is equal to the number of pairwise orthogonal copies of
\mathcal{V}
that can be embedded in
\mathcal{M}
.

Next, let
\mathop{\mathrm{Iso}}\nolimits_{G}(\mathcal{V},\mathcal{M})
denote the span of all the copies of
\mathcal{V}
in
\mathcal{M}
, which is known as the
isotypical subspace
.
The mapping
\theta\otimes v\mapsto\theta(v)
defines an isomorphism between
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})\otimes\mathcal{V}
and
\mathop{\mathrm{Iso}}\nolimits_{G}(\mathcal{V},\mathcal{M})
as linear spaces.
The whole module
\mathcal{M}
can be expressed as
\mathcal{M}=\bigoplus_{\mathcal{V}}\mathop{\mathrm{Iso}}\nolimits_{G}(\mathcal{V},\mathcal{M})
as
\mathcal{V}
ranges over the irreps of
G
.
This is called the isotypical decomposition of
\mathcal{M}
.
The terms in the isotypical decomposition are pairwise orthogonal.

We use the following palpable way to represent
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})
.
Fix some reference non-zero vector
v_{\mathcal{V}}\in\mathcal{V}
, and define the
slice
of
v_{\mathcal{V}}
in a module
\mathcal{M}
, denoted
\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{M})
, as the set of all
\theta(v_{\mathcal{V}})
as
\theta
ranges over
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})
.
The space
\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})
is isomorphic to
\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{M})
, the isomorphism being
\theta\mapsto\theta(v_{\mathcal{V}})
.
Combining the two above isomorphisms, we get that
\mathop{\mathrm{Iso}}\nolimits_{G}(\mathcal{V},\mathcal{M})
is isomorphic to
\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{M})\otimes\mathcal{V}
.
This allows us to write down the following isotypical decomposition of a morphism
\theta\colon\mathcal{M}\to\mathcal{N}
between two
G
-modules
\mathcal{M}
and
\mathcal{N}
:

\theta=\bigoplus_{\mathcal{V}}\theta_{\mathcal{V}}\otimes I_{\mathcal{V}}.

(5.1)

Here
\mathcal{V}
ranges over all irreps of
G
,
a linear operator
\theta_{\mathcal{V}}\colon\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{M})\to\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{N})
is the restriction of
\theta
to
\mathop{\mathrm{Slice}}\nolimits_{G}(v_{\mathcal{V}},\mathcal{M})
for a fixed non-zero
v_{\mathcal{V}}\in\mathcal{V}
, and
I_{\mathcal{V}}
is the identity on
\mathcal{V}
.
In particular, (
5.1
) implies

\|\theta\|=\max_{\mathcal{V}}\|\theta_{\mathcal{V}}\|.

(5.2)

We will use group algebra extensively in our proofs.
Its elements are important as they give linear operators that are preserved under isomorphisms.
In particular, if
\alpha\in\mathbb{C}G
is a group element, and
\alpha_{\mathcal{M}}
is the corresponding linear operator in a
G
-module
\mathcal{M}
, we have the following decomposition complementing (
5.1
):

\alpha_{\mathcal{M}}=\bigoplus_{\mathcal{V}}I_{\mathop{\mathrm{Hom}}\nolimits_{G}(\mathcal{V},\mathcal{M})}\otimes\alpha_{\mathcal{V}},

(5.3)

where again
\mathcal{V}
ranges over all irreps of
G
.
An important use-case is provided by an
\alpha
that is zero on all irreps but one (call it
\mathcal{V}
) and is a 1-dimensional projector on
\mathcal{V}
.
In this case, by (
5.3
),
\alpha
projects onto the slice of
v
in every
G
-module
\mathcal{M}
, where
v
is a non-zero vector in
\alpha(\mathcal{V})
.

5.2
Symmetric group

In this section, we consider a special case of the symmetric group.
If
A
is a finite set,
S_{A}
denotes the
symmetric group
on
A
, that is, the group with the permutations of
A
as elements, and composition as the group operation.
We will write
S_{n}
instead of
S_{[n]}
.
If
A\subseteq B
, then we consider
S_{A}
as a subgroup of
S_{B}
, where each permutation
\pi\in S_{A}
is extended to
B\setminus A
by identity.
We also use the following elements of the group algebra
\mathbb{C}S_{A}
:

\mathcal{S}_{A}^{+}=\sum_{\pi\in S_{A}}\pi\qquad\text{and}\qquad\mathcal{S}_{A}^{-}=\sum_{\rho\in S_{A}}(\sgn\rho)\rho,

where
\sgn\rho
stands for the sign of
\rho
.
Both of them are scalar multiples of orthogonal projectors.

Representation theory of
S_{n}
is closely related to
partitions of integers
.
A
partition

\lambda
of an integer
n
is a non-increasing sequence
(\lambda_{1},\dots,\lambda_{\ell})
of positive integers satisfying
\lambda_{1}+\dots+\lambda_{\ell}=n
.
For each partition
\lambda
of
n
, one assigns an irreducible
S_{n}
-module
\mathcal{S}^{\lambda}
, called the
Specht module
. All these modules are pairwise non-isomorphic, and give a complete list of all the irreps of
S_{n}
.

A partition
\lambda=(\lambda_{1},\dots,\lambda_{\ell})
of
n
is often represented in the form of a
Young diagram
that consists, from top to bottom, of rows of
\lambda_{1},\lambda_{2},\dots,\lambda_{\ell}
boxes aligned by the left side.
We often identify
\lambda
with the corresponding diagram.
A
Young tableau
of shape
\lambda
is a Young diagram of
\lambda
with each box containing an element from
[n]
, each element used exactly once.
As an example, the following is a Young tableau of shape
(4,3,1)
:

For a Young tableau
t
, define its
row permutations

R_{t}
and its
column permutations

C_{t}
as the permutations in
S_{n}
that permute the elements within each row or column of
t
, respectively.
In our example above,
R_{t}=S_{\{1,5,6,4\}}\times S_{\{2,3,8\}}
and
C_{t}=S_{\{2,4,7\}}\times S_{\{3,6\}}\times S_{\{5,8\}}
.
This gives rise to the following two elements of the group algebra
\mathbb{C}S_{n}
:

\mathcal{R}^{+}_{t}=\sum_{\pi\in R_{t}}\pi=\prod_{\text{$R$ is a row of $t$}}\mathcal{S}^{+}_{R},\qquad\text{and}\qquad\mathcal{C}^{-}_{t}=\sum_{\rho\in C_{t}}(\sgn\rho)\rho=\prod_{\text{$C$ is a column of $t$}}\mathcal{S}^{-}_{C}.

The following is one of the key results in representation theory of the symmetric group.
In fact, this is the only result from this theory we rely on in our forthcoming proofs.

Theorem 5.3

(
[
21
, Chapter 3]
,
[
17
, §28]
)
.

Let
t
be a Young tableau of shape
\lambda
.
The element
\mathcal{C}^{-}_{t}\mathcal{R}^{+}_{t}
of the group algebra annihilates (is identical zero on) every Specht module
\mathcal{S}^{\mu}
with
\mu\neq\lambda
.
On
\mathcal{S}^{\lambda}
, it is a 1-dimensional projector times a scalar.

This result is important as
\mathcal{C}^{-}_{t}\mathcal{R}^{+}_{t}
is the projector onto
\mathop{\mathrm{Slice}}\nolimits_{S_{n}}(v,\mathcal{M})
in every
S_{n}
-module
\mathcal{M}
, where
v
lies in the image of
\mathcal{C}^{-}_{t}\mathcal{R}^{+}_{t}
in
\mathcal{S}^{\lambda}
.
Note that while both
\mathcal{C}^{-}_{t}
and
\mathcal{R}^{+}_{t}
are non-normalized orthogonal projectors, they generally do not commute, hence,
\mathcal{C}^{-}_{t}\mathcal{R}^{+}_{t}
is not Hermitian, and is
not
an
orthogonal
projector.

5.3
The Module
\mathbb{C}^{\binom{[n]}{k}}

For the remaining part of this paper, we assume the value of
n
is fixed, so our notation will often implicitly depend on
n
.

For positive integers
n\geq 2k
, the set
\binom{[n]}{k}
of all subsets of
[n]
of size
k
admits group action of
S_{n}
on it.
Namely,
x\in\binom{[n]}{k}
is mapped by
\pi\in S_{n}
to
\pi(x)=\mathopen{}\mathclose{{\left\{\pi(i)\mid i\in x}}\right\}
.
Let
\mathbb{C}^{\binom{[n]}{k}}
be the corresponding
S_{n}
-module.
We will write the elements of
\mathbb{C}^{\binom{[n]}{k}}
as formal linear combinations of subsets similar as we write group algebra elements.
This module has close connection to the Johnson association scheme
[
6
]
, and both spaces
\mathbb{C}^{X}
and
\mathbb{C}^{Y}
in Section
4
are of this form.

In this section, we will use Theorem
5.3
to analyse its structure.
Although the results are well-known, this serves as a warm-up for the next sections.
We will need the following piece of notation.
For two disjoint sets
A,B\subseteq[n]
, let
A\mathbin{\vtop{\halign{#\cr$\sqcup$\cr$\times$\crcr}}}B
denote their disjoint union.
We extend this notation to formal linear combinations of sets in a straightforward way.
For instance,

\Bigl(\{1\}-\{2\}\Bigr)\mathbin{\vtop{\halign{#\cr$\sqcup$\cr$\times$\crcr}}}\Bigl(\{3,5\}-\{4,5\}\Bigr)=\{1,3,5\}-\{1,4,5\}-\{2,3,5\}+\{2,4,5\}.

This notation is similar to tensor products with the distinction that the sets are unordered and the promise that the multipliers are disjoint.
The symbol
\mathbin{\vtop{\halign{#\cr$\sqcup$\cr$\times$\crcr}}}
is a combination of the symbols for the disjoint union
\sqcup
and the product
\times
.

Take any 3 distinct elements
a,b,c\in[n]
and
T\in{\binom{[n]}{k}}
.
Either
\bigl\lvert\{a,b,c\}\cap T\bigr\rvert\geq 2
, or
\bigl\lvert\{a,b,c\}\cap([n]\setminus T)\bigr\rvert\geq 2
.
In either case,
\mathcal{S}^{-}_{\{a,b,c\}}T=0
, hence,
\mathcal{S}^{-}_{\{a,b,c\}}
annihilates the whole
\mathbb{C}^{\binom{[n]}{k}}
.
By Theorem
5.3
,
\mathbb{C}^{\binom{[n]}{k}}
does not contain a copy of any
S^{\lambda}
for
\lambda
with more than two rows.

A.1
Algorithmic Preliminaries

Before we proceed, we need some well-known results both from the theory of randomized and quantum algorithms.
They all are only needed for Section
A.2
, and are not used anywhere else in the paper.
We assume the reader is familiar with basic probability theory.

Theorem A.1

(Chebyshev’s Inequality)
.

Let
X
is a probability distribution with variance
\sigma^{2}
.
It is possible to get an estimate of the mean
\mathbb{E}[X]
with additive precision
O(\sigma)
using 1 sample from
X
.

Recall that in the above theorem, as elsewhere, we assume here that the algorithm can err with probability up to
1/3
.
A distribution that is concentrated on values 0 and 1 is called Bernoulli distribution.
For that, we have an important corollary:

Theorem A.2
.

Let
X
be a Bernoulli distribution with unknown mean
p
.
Then,
O(1/(p\varepsilon^{2}))
samples from
X
are enough to estimate
p
with multiplicative precision
\varepsilon
.

Theorem A.3

(Coupon collector)
.

Assume we are sampling uniformly at random elements out of a set
S
of size
s
.
The expected number of samples needed to obtain
t
distinct elements of
S
is

•

O(t)
, if
t\leq s/2
;

•

O(s\log s)
, if
t=s
.

For the quantum part, we will need the following version of the quantum amplitude amplification and estimation, which follows the original design of
[
14
]
.

Theorem A.4
.

Let
\phi\in\mathcal{H}
be some state known to the algorithm.
It has a decomposition of the form
\phi=\alpha\mathopen{}\mathclose{{\left|\phi_{0}}}\right>+\beta\mathopen{}\mathclose{{\left|\phi_{1}}}\right>
for some orthogonal and normalised
\phi_{0},\phi_{1}\in\mathcal{H}
and non-negative reals
\alpha
and
\beta
with
\beta<1/\sqrt{2}
.
The decomposition is unknown to the algorithm, but it has black-box access to a unitary
R
satisfying
R\phi_{0}=\phi_{0}
and
R\phi_{1}=-\phi_{1}
.
Under these assumptions, the following two procedures are available:

•

(Amplitude Estimation) It is possible to get an estimate of
\beta
with multiplicative precision
\varepsilon
using
O(1/(\varepsilon\beta))
executions of
R
.

•

(Amplitude Amplification)
With probability
\Omega(1)
, it is possible to get a state
\phi^{\prime}_{1}
such that
|\mathopen{}\mathclose{{\left\langle\phi_{1},\phi^{\prime}_{1}}}\right\rangle|=\Omega(1)
using
O(1/\beta)
executions of
R
.

We will call
\phi_{1}
the
marked part
of the state
\phi
, and
\beta
the

.

Remark A.5
.

Amplitude amplification works by applying the operator
SR
to
\phi

S
is reflection about
\phi
.
This has two consequences:

•

The state of the algorithm is guaranteed to stay in the span of
\phi_{0}
and
\phi_{1}
.

•

In the extreme case
\beta=0
, the algorithm stays in the state
\phi=\phi_{0}
.

Corollary A.6
.

We can use Theorem
A.4
in one of the following three ways.
In all of them,
\phi_{1}=\psi_{x}=\frac{1}{\sqrt{|x|}}\sum_{i\in x}\mathopen{}\mathclose{{\left|i}}\right>
is the state from (

(a)

(From the outside, Grover’s search

]
and quantum counting
[

]

.

(b’)

For (a), we have

The membership oracle implements

In this section, we prove that Theorem

Proposition A.7
.

It is possible to solve the approximate counting problem using
O(k\log k)
classical samples from

Proof.

The algorithm is similar to the classical coupon collector problem.
Sample the elements out of

Output that
|x|=k
if the number of distinct elements observed is at most

. The algorithm has 1-sided error.

For the analysis, we apply Theorem
A.3
with

.
∎

Proposition A.8

(
[
1
]
)
.

It is possible to solve the approximate counting problem using
O\Bigl(\frac{\sqrt{k}}{\varepsilon}\Bigr)

.

Proof.

The idea of the algorithm is to sample from
x
and count the number of pairs of equal samples.
Assume we have
\ell

.
For

Z_{ij}=1_{s_{i}=s_{j}}

The expectation and the variance satisfy
\mathbb{E}[Z_{ij}]=1/|x|

The events

are not independent, but they are

\mathbb{E}\biggl[\sum_{i,j}Z_{ij}\biggr]=\frac{\ell(\ell-1)}{2|x|}\qquad\text{and}\qquad\Var\biggl[\sum_{i,j}Z_{ij}\biggr]=O\biggl(\frac{\ell^{2}}{k}\biggr).

By Chebyshev’s inequality, we can distinguish whether
|x|=k

\frac{\ell(\ell-1)}{2k}-\frac{\ell(\ell-1)}{2k^{\prime}}=\Omega\biggl(\frac{\ell}{\sqrt{k}}\biggr).

Since

\frac{\ell(\ell-1)}{2k}-\frac{\ell(\ell-1)}{2k^{\prime}}=\Omega\biggl(\frac{\ell^{2}}{k}\varepsilon\biggr),

this happens when
\ell\geq C\sqrt{k}/\varepsilon
for a sufficiently large constant

.
∎

The approximate counting problem with the usual membership oracle is a prime example of the power of the original formulation of the adversary method due to Ambainis
[

]

For completeness, we briefly restate the formulation of the bound and its application to approximate counting.

Theorem D.1
.

Let

and

•

x\sim y

•

and

\ell

x\sim y
and

;

•

for each

\ell^{\prime}
different

\Omega\mathopen{}\mathclose{{\left(\sqrt{\frac{mm^{\prime}}{\ell\ell^{\prime}}}}}\right)

Theorem D.2
.

Consider the same counting problem as in Theorem
1.1
, but assume that the algorithm only has access to the standard membership oracle.
Then, in order to solve the problem, the algorithm has to use

\Omega\mathopen{}\mathclose{{\left(\frac{1}{\varepsilon}\sqrt{\frac{n}{k}}}}\right)

Proof.

Let
X
contain all the sets of size

contain all the sets of size

Define the relation
\sim

Then, it is easy to check that

Hence,

\sqrt{\frac{mm^{\prime}}{\ell\ell^{\prime}}}=\sqrt{\frac{(n-k)}{\varepsilon k}\frac{(1+\varepsilon)k}{\varepsilon k}}=\Omega\mathopen{}\mathclose{{\left(\frac{1}{\varepsilon}\sqrt{\frac{n}{k}}}}\right).\qed

This is a particularly short and nice combinatorial proof, and the question arises whether it is possible to adapt a variant of this technique for a more general Theorem

We argue that it is most likely impossible, in the sense that the most natural yet quite general adaptation provably fails.
