Gang Lü, Sheng-Tao Li, Yu-Ting Wang

Abstract
In the perturbative QCD (PQCD) approach we study the direct C ​ P CP violation in B c + → D ( s ) + ​ ρ 0 ​ ( ω ) → D ( s ) + ​ π + ​ π − B^{+}_{c}\rightarrow D_{(s)}^{+}\rho^{0}(\omega)\rightarrow D_{(s)}^{+}\pi^{+}\pi^{-} via the ρ − ω \rho-\omega mixing mechanism. We find that the C ​ P CP violation can be enhanced by ρ − ω \rho-\omega mixing when the invariant masses of the π + ​ π − \pi^{+}\pi^{-} pairs are in the vicinity of the ω \omega resonance. For the decay process B c + → D + ​ ρ 0 ​ ( ω ) → D + ​ π + ​ π − B^{+}_{c}\rightarrow D^{+}\rho^{0}(\omega)\rightarrow D^{+}\pi^{+}\pi^{-} , the maximum C ​ P CP violation can reach 7.5 %.
