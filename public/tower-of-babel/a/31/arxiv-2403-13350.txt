Construction of Minimal Binary Linear Codes of dimension n + 3 n+3
Wajid M. Shaikh, Rupali S. Jain, B. Surendranath Reddy, Bhagyashri S. Patil

Abstract
In this paper, we will give the generic construction of a binary linear code of dimension n + 3 n+3 and derive the necessary and sufficient conditions for the constructed code to be minimal. Using generic construction, a new family of minimal binary linear code will be constructed from a special class of Boolean functions violating the Ashikhmin-Barg condition. We also obtain the weight distribution of the constructed minimal binary linear code.



Keywords
Linear code, minimal code, weight distribution, Ashikhmin-Barg condition.

94B05, 94C10, 94A60

Introduction

Linear codes serve as a cornerstone of modern communication systems, providing robust error control mechanisms essential for reliable data transmission in various applications ranging from telecommunications to digital broadcasting. Minimal linear codes is a special class of linear codes widely used in secret sharing, data storage, and information processing systems in modern technology
[
10
]
[
14
]
. So, the construction of minimal linear codes is one of the thrust area for many researchers in coding theory.

Minimal codes are characterized by the property that none of the codeword is covered by some other linearly independent codeword. There are two approaches to studying minimal linear codes one is the algebraic method and another is geometric method. The algebraic method is based on the Hamming weights of the codeword. In 1998, Ashikhmin and Barg
[
1
]
gave a sufficient condition for linear code to be minimal, which is stated below.

Lemma 1.1
.

[
1
]
[Ashikhmin-Barg]
Let
p
be a prime. Then a linear code
\mathscr{C}
over
\mathbb{F}_{p}
is minimal if

\frac{{wt}_{min}}{{wt}_{max}}>\frac{p-1}{p}

where,
{wt}_{min}
and
{wt}_{max}
denote the minimum and maximum non-zero Hamming weights for
\mathscr{C}
, respectively.

From the above lemma, many minimal linear codes constructed but constructing minimal linear codes violating Ashikhmin-Barg condition is an interesting research topic. In the year 2018, Chang and Hyun
[
2
]
constructed an infinite family of minimal binary linear codes, which are not satisfying Ashikhmin-Barg condition with the help of mathematical objects called simplicial complexes and generic construction

\mathscr{C}_{f}=\{(\alpha f({\bf x})+{\bf w}\cdot{\bf x})_{\bf x\in\mathbb{F}_{p}^{n*}}\ |\ \alpha\in\mathbb{F}_{p},\ {\bf w}\in\mathbb{F}_{p}^{n}\}

(1.1)

The necessary and sufficient condition for binary linear code to be minimal was given by Ding, Heng, and Zhou
[
3
]
in 2018, and using special Boolean functions, they constructed three classes of minimal binary linear codes. Heng et al.
[
4
]
discovered a necessary and sufficient condition for linear codes over finite fields to be minimum. This is a generalised version of result Ding, C., Heng, Z., & Zhou, Z.
[

. Also, several researchers constructed minimal linear code from different kinds of functions (see

,

Till date, several minimum linear codes have been constructed that do not meet the Ashikhmin-Barg condition, but the dimension of these codes is either
n
or
n+1
, which reduces the information rate of a code. Recently, Liu and Liao
[

In this paper, we extend the results of

A Boolean function

Lemma 2.3
.

[

Let

\widehat{f}({\bf w})=\begin{cases}2^{n}-2\tilde{f}({\bf 0}),&\text{ if }{\bf w}={\bf 0}\\
-2\tilde{f}({\bf w}),&\text{ if },{\bf w}\neq{\bf 0}\end{cases}

[

Let

if and only if

\text{wt}({\bf x}+{\bf y})=\text{wt}({\bf x})-\text{wt}({\bf y})

\mathscr{C}_{f,g,h}=\{c_{f,g,h}({\bf w})=(\alpha f({\bf x})+\beta g({\bf x})+\gamma h({\bf x})+{\bf w}\cdot{\bf x})_{{\bf x}\in\mathbb{F}_{2}^{n*}}\ |\ \alpha,\beta,\gamma\in\mathbb{F}_{2},\ {\bf w}\in\mathbb{F}_{2}^{n}\}

Theorem 3.1
.

Let

\displaystyle\bigcup_{\phi\in\mathcal{F}}\left\{\frac{2^{n}-\widehat{\phi}({\bf w})}{2}|\ {\bf w}\in\mathbb{F}_{2}^{n}\right\}\bigcup\{2^{n-1}\ |\ {\bf w}\in\mathbb{F}_{2}^{n}\}\bigcup\{0\}
.

Clearly, the length of the code
\mathscr{C}_{f,g,h}
is

. Let

. Then, we prove that

\displaystyle\sum_{i=1}^{n}\delta_{i}c_{f,g,h}({\bf u_{i}})+\delta_{n+1}c_{f}({\bf 0})+\delta_{n+2}c_{g}({\bf 0})+\delta_{n+3}c_{h}({\bf 0})

\displaystyle={\bf 0}

\displaystyle\sum_{i=1}^{n}\delta_{i}(f({\bf x})+g({\bf x})+h({\bf x})+{\bf u_{i}}\cdot{\bf x})_{{\bf x}\in\mathbb{F}_{2}^{n}}+\delta_{n+1}(f({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}

\displaystyle+\delta_{n+2}(g({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}+\delta_{n+3}(h({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}

\displaystyle={\bf 0}

\displaystyle\sum_{i=1}^{n}\delta_{i}({\bf u_{i}}\cdot{\bf x})_{{\bf x}\in\mathbb{F}_{2}^{n}}+(\delta_{1}+\delta_{2}+\cdots+\delta_{n}+\delta_{n+1})(f({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}+

\displaystyle(\delta_{1}+\delta_{2}+\cdots+\delta_{n}+\delta_{n+2})(g({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}+(\delta_{1}+\delta_{2}+\cdots+\delta_{n}+\delta_{n+3})(h({\bf x}))_{{\bf x}\in\mathbb{F}_{2}^{n}}

\displaystyle={\bf 0}

\displaystyle\sum_{i=1}^{n}\delta_{i}({\bf u_{i}}\cdot{\bf x})_{{\bf x}\in\mathbb{F}_{2}^{n}}+\alpha_{1}f({\bf x})+\alpha_{2}g({\bf x})+\alpha_{3}h({\bf x})

\displaystyle=0

If

From this, we get

is linearly independent. From the dimension of

containing

Now we will give the weight enumeration for the case

\displaystyle\widehat{f+g+h}({\bf w})

\displaystyle=\sum_{{\bf x}\in\mathbb{F}_{2}^{n}}(-1)^{f({\bf x})+g({\bf x})+h({\bf x})+{\bf w}\cdot{\bf x}}

\displaystyle\text{wt}({\bf w})

All other cases follow in the same manner, which is similar to Theorem 3.1 in

Theorem 3.2
.

Let
\mathscr{C}_{f,g,h}
be a binary code defined in (

For any
\phi_{1},\phi_{2}\in\mathcal{F}

\widehat{\phi_{1}}({\bf x}+{\bf y})+\widehat{\phi_{2}}({\bf x})-\widehat{\phi_{1}+\phi_{2}}({\bf y})\neq 2^{n}
