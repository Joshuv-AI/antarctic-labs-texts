On Vaughan’s approximation in restricted sets of arithmetic progressions
Claus Bauer

Abstract
We investigate the approximation to the number of primes in arithmetic progressions given by Vaughan ( [ 7 ] ). Instead of averaging the expected error term over all residue classes to modules in a given range, here we only consider subsets of arithmetic progressions that satisfy additional congruence conditions and provide asymptotic approximations.



1
Introduction

The distribution of primes in arithmetic progressions is a long standing topic in analytic number theory. Defining

\displaystyle\vartheta(x,q,b)=\sum\limits_{p\leq x\atop p\equiv b(mod\,d)}\log\,p,

the approximation
\vartheta(x,q,b)\sim\frac{x}{\phi(q)}
is known to be true for small
q
and
(a,q)=1.
For larger
q,

in
[
1
]
,
[
4
]
, and
[
5
]
the quantity

\displaystyle\sum\limits_{d\leq Q}\sum\limits_{b=1\atop(b,d)=1}^{d}E^{2}(x,d,b),

(1.1)

\displaystyle E(x,d,b)=\vartheta(x,d,b)-\frac{x}{\phi(d)},

has been investigated for
Q\leq x.

The most accurate asymptotic expression for (
1.1
) was given in
[
3
]
as follows:

For
Q<x,
any
A>0,
and a constant C,

\displaystyle\sum\limits_{d\leq Q}\sum\limits_{b=1\atop(b,d)=1}^{d}E^{2}(x,d,b)=Qx\log\,Q+CQx+O\left(Q^{3/2}x^{1/2}+x^{2}(\log\,x)^{-A}\right).

(1.2)

In
[
7
]
, it was shown that for large
q
the approximation
\frac{x}{\phi(q)}
used in (
1.1
) is not best possible. Setting

\displaystyle F_{R}(n)=\sum\limits_{r\leq R}\frac{\mu(r)}{\phi(r)}\sum\limits_{b=1\atop(b,r)=1}^{r}e\left(\frac{bn}{r}\right),\qquad\Delta(n)=\Lambda(n)-F_{R}(n),

\displaystyle\rho(x,d,b)=\sum\limits_{n\leq x\atop n\equiv b(mod\,d)}F_{R}(n),

the following approximation
was shown in
[
7
]
:

Theorem 1.1

For any positive integer
A
and

R=L^{A},
there is

\displaystyle\sum\limits_{d\leq Q}\sum\limits_{b=1}^{d}\left(\vartheta(x,d,b)-\rho(x,d,b)\right)^{2}=Qx\log(x/R)-c_{0}Qx+O\left(QxR^{-1/2}+x^{2}(\log\,x)^{2}R^{-1}\right),

(1.3)

where

c_{0}=1+\gamma+\sum\limits_{p\geq 2}\frac{\log\,p}{p(p-1)}.

For
x/R<Q,
the main term in (
1.3
) is smaller than the main term in (
1.2
).

We notice that in Theorem
1.1
the average is taken over all reduced residue classes
b
mod
d.
It is of interest to understand if one can get a better asymptotic when limiting the summation to reduced rest classes only. Theorem
1.2
shows that this is indeed the case.

Theorem 1.2

For a real number
x,
a real number
R
satisfying

R=L^{G}
for some
G>10
and
Q=x(\log\,x)^{-B}
for some
B>0,
there is

\displaystyle\sum\limits_{d\leq Q}\sum\limits_{b=1\atop(b,d)=1}^{d}\left(\vartheta(x,d,b)-\rho(x,d,b)\right)^{2}

\displaystyle xQ\left(\log\,\left(x/R^{\left(2-\zeta^{-1}(2)\right)}\right)\right)+xQ\left(-c_{1}+1-\prod\limits_{p\geq 2}\left(1-\frac{1}{p(p-1)}\right)+\prod\limits_{p\geq 2}\left(1-\frac{1}{p^{2}}\right)c_{2}\right)

\displaystyle+

\displaystyle O\left(\frac{xQ}{R^{1/2}}+\frac{x^{2}(\log\,x)^{2}}{R}\right),

where

\displaystyle c_{1}

\displaystyle=

\displaystyle 1+2\gamma+2\sum\limits_{p\geq 2}\frac{\log\,p}{p(p-1)},

\displaystyle c_{2}

\displaystyle=

\displaystyle\gamma+\sum\limits_{p\geq 2}\frac{\log\,p}{p(p-1)}.

Comparing Theorems
1.1
and
1.2

b

(r,b)>1

1.2

[

is considered. As in our case, it is shown that the non-reduced rest-classes make a non-negligible contribution.

\displaystyle+

\displaystyle O\left(x\,exp\left(-cL^{1/2}\right)+\frac{x\tau(v)}{vR^{1/2}}+\frac{x}{\phi(v)R^{1/2}}+R^{2}\log\,R+\tau(v)R+\frac{x(\log\,v+\tau(v))}{v}\sum\limits_{r|v\atop r>R}1\right),
