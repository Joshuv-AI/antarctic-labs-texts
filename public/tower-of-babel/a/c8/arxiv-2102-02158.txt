1.
Introduction

Let
f
be a transcendental entire function and denote by
f^{n}
,
n\in{\mathbb{N}}
, the
n
-th iterate of
f
. The results in this paper address a question in complex dynamics concerning the
escaping set
of a transcendental entire function
f
, defined as

I(f)=\{z:f^{n}(z)\to\infty\;\text{ as }n\to\infty\},

namely, whether all the components of
I(f)
are unbounded. This question is known as
Eremenko’s conjecture

[
3
]
and despite much work it remains open.

For any transcendental entire function
f
, the
maximum modulus
and
minimum modulus
of
f
are defined as follows, for
r\geq 0
:

M(r)=M(r,f)=\max_{|z|=r}|f(z)|\quad\text{and}\quad m(r)=m(r,f)=\min_{|z|=r}|f(z)|,

respectively. There is a huge literature about the relationship between
m(r)
and
M(r)
for various types of transcendental entire functions. Clearly
m(r)<M(r)
for all
r>0
and the function
M(r)
is strictly increasing and unbounded. On the other hand, the function
m(r)
is alternately increasing and decreasing between adjacent values of
r
for which
m(r)=0
and eventually decreases to 0 in the case that
f
has only finitely many zeros. For certain functions, however,
m(r)
is comparable in size to
M(r)
for an unbounded set of values of
r
.

We let
M^{n}(r)
and
m^{n}(r)
be defined by iterating the real functions
M(r)
and
m(r)
respectively. For any transcendental entire function
f
we have

(1.1)

M^{n}(r)\to\infty\;\text{ as }n\to\infty,

for
r\geq R=R(f)
say, but for the iterated minimum modulus the property:

(1.2)

\text{there exists }r>0\text{ such that }m^{n}(r)\to\infty\text{ as }n\to\infty,

may or may not hold, depending on the function
f
.

It has been known for some time that the sequence
M^{n}(r)
is of importance in relation to work on Eremenko’s conjecture, since it plays a key role in the definition of a subset of
I(f)
called the
fast escaping set
, all of whose components are unbounded; see, for example,
[
12
]
. More recently, it has been observed that property (
1.2
), when it is true, can also play an important role in relation to this conjecture; see
[
9
]
,
[
10
]
and
[
8
]
. For example, in
[
8
]
we obtained the following result, which gives a family of transcendental entire functions for which Eremenko’s conjecture holds in a particularly strong way.

Theorem 1.1
.

Let
f
be a real transcendental entire function of finite order with only real zeros for which there exists
r>0
such that
m^{n}(r)\to\infty
as
n\to\infty.
Then
I(f)
is connected and hence Eremenko’s conjecture holds for
f
.

Remark
In
[
8
, Theorem 1.1]
we showed moreover that, for such functions
f
, the set
I(f)
has the structure of an (infinite) spider’s web.

Recall that the
order

\rho(f)
and the
lower order

\lambda(f)
of a transcendental entire function
f
are

\rho(f)=\limsup_{r\to\infty}\frac{\log\log M(r)}{\log r}\quad\text{and}\quad\lambda(f)=\liminf_{r\to\infty}\frac{\log\log M(r)}{\log r},

respectively, and
f
is said to be
real
if
f(\bar{z})=\overline{f(z)},\;\;\text{for }z\in{\mathbb{C}}.

In view of Theorem
1.1
, it is natural to ask which transcendental entire functions satisfy property (
1.2
); in particular, which amongst those that satisfy the hypotheses of this theorem. In
[
8
]
we proved several results in relation to this question, including the following.

(a)

For a real transcendental entire function
f
of finite order with only real zeros:

(i)

if
0\leq\rho(f)<1/2
, then property (
1.2
) holds;

(ii)

if
\rho(f)>2
, then property (
1.2
) does not hold.

(b)

For any
\rho\in[1/2,2]
there are examples of real transcendental entire functions with only real zeros of order
\rho
for which property (
1.2
) holds and also examples of such functions for which (
1.2
) does not hold.

Actually, property (
1.2
) holds for
all
entire functions of order less than
1/2
; see
[
10
, Theorem 1.1]
. This follows from the cos
\pi\rho
theorem which shows that for functions of order less than
1/2
there is a close relation between the minimum modulus and maximum modulus for many values of
r
; see
[
5
, Theorem 6.13]
.

For functions of order
1/2
, minimal type, weaker results on the size of the minimum modulus are known; in particular, Wiman showed that, for such functions,
m(r)
is unbounded on
(0,\infty)
; see
[
5
, Theorem 6.4]
. In view of Wiman’s result, one might hope that property (
1.2
) holds for real entire functions with only real zeros of order 1/2, minimal type, that is, when

(1.3)

\limsup_{r\to\infty}\frac{\log\log M(r)}{\log r}=\frac{1}{2}\quad\text{and}\quad\lim_{r\to\infty}\frac{\log M(r)}{r^{1/2}}=0.

In this paper, we show that (
1.2
) does indeed hold for many families of such functions, but does not hold for all.
Our main positive result is the following which, roughly speaking, shows that (
1.2
) holds whenever
(\log M(r))/r^{1/2}
tends to 0 (as
r\to\infty)
in a sufficiently regular manner.

Theorem 1.2
.

Let
f
be a transcendental entire function of order at most 1/2, minimal type, and suppose that there exists
r_{0}>0
such that, for
r>r_{0}
,

(1.4)

\frac{\log M(r)}{r^{1/2}}\leq\frac{1}{4}\frac{\log M(s)}{s^{1/2}},

for some
s\in(0,r)
which satisfies
M(s)\geq r^{2}
. Then there exists
r>0
such that
m^{n}(r)\to\infty
as
n\to\infty.

Remarks
1. The second hypothesis of Theorem
1.2
implies the first hypothesis, that
f
has order at most 1/2, minimal type, though this is not quite obvious.

2. Theorem
1.2
implies the result stated earlier that, if
\rho(f)<1/2
, then property (
1.2
) holds. Indeed, if
\rho(f)<1/2
and we put

\delta:=1/2-\rho(f)\in(0,1/2],

then (
1.4
) holds with
s=r^{\delta}
for
r
sufficiently large, since this choice of
s
gives
r^{1/2}/s^{1/2}=r^{\rho(f)+\delta/2}
and
M(r^{\delta})\geq r^{2}
for
r
sufficiently large.

In Section 2, we give a number of conditions on the maximum modulus and on the zeros of
f
which imply the hypotheses of Theorem
1.2
and are convenient for applications.

In the second half of the paper we use a recent generalisation of a method of Kjellberg
[
13
]
to construct examples of functions of order
1/2
, minimal type, for which property (
1.2
) does not hold. First, we show that no matter how
slowly

\log M(r)
grows, consistent with
f
having order 1/2, minimal type, we cannot deduce that property (
1.2
) holds.

Example 1.3
.

Let
\delta:(0,\infty)\to(0,\tfrac{1}{2})
be a decreasing function such that

\delta(r)\to 0\;\text{ as }r\to\infty.

Then there exists a real transcendental entire function
f
of order
1/2
, minimal type, with only real zeros, and
r_{0}>0
such that

(1.5)

\log M(r,f)\leq r^{1/2-\delta(r)},\;\;\text{for }r\geq r_{0},

for which property (
1.2
) does not hold.

Next we show that making the additional assumption of positive lower order, or even of lower order
1/2
, is insufficient to ensure that property (
1.2
) holds.

Example 1.4
.

There exists a real transcendental entire function
f
of order
1/2
, minimal type, and of lower order
1/2
, with only real zeros such that property (
1.2
) does not hold.

Finally, we remark that consideration of the iterates of the minimum modulus first arose in connection with the conjecture of Baker that entire functions of order
1/2
, minimal type, have no unbounded Fatou components; see
[
7
]
for the most recent progress on this conjecture.

The structure of the paper is as follows. In Section
2
we prove our positive results, including Theorem
1.2
, and in Section
3
we recall some results from
[
13
]
needed for the proofs of Examples
1.3
and
1.4
, which are given in Section
4
.

2.
Proof of Theorem
1.2
and some special cases

In this section we prove Theorem
1.2
, our positive result about property (
1.2
), and give some special cases of it which we use to obtain examples of functions that satisfy the hypotheses of Theorem
1.2
.

The proof of Theorem
1.2
depends on the following lemma of Beurling
[
2
, page 95]
. For any subharmonic function
u
we write

B(r,u)=\max_{|z|=r}u(z),\;\text{where }r>0.

Lemma 2.1
.

If
u
is subharmonic in
{\mathbb{C}}
,
0<r_{1}<r_{2}
, and

E(r_{1},r_{2})=\{r\in[r_{1},r_{2}]:\inf_{|z|=r}u(z)\leq 0\},

then

(2.1)

B(r_{2},u)>\frac{1}{2}\exp\left(\frac{1}{2}\int_{E(r_{1},r_{2})}\frac{1}{t}\,dt\right)B(r_{1},u).

In particular, if
E(r_{1},r_{2})=[r_{1},r_{2}]
, then

B(r_{2},u)\geq\frac{1}{2}\left(\frac{r_{2}}{r_{1}}\right)^{1/2}B(r_{1},u).

In order to work with property (
1.2
), the function

\widetilde{m}(r):=\max\{m(s):0\leq s\leq r\},\;\;\text{for }r\in[0,\infty),

was introduced in
[
10
]
and it was shown that property (
1.2
) is true if and only if

(2.2)

\text{there exists }R>0\text{ such that }\widetilde{m}(r)>r,\text{ for }r\geq R.

We use this equivalent property to prove Theorem
1.2
.

Proof of Theorem
1.2
.

Suppose the hypotheses of Theorem
1.2
hold. If property (
1.2
) does not hold, then by (
2.2
) there exist arbitrarily large
r>r_{0}
such that
\widetilde{m}(r)\leq r
; that is, for arbitrarily large
r
we have

(2.3)

m(t)\leq r,\;\;\text{for }0<t\leq r.

For such an
r
, there exists by hypothesis
s<r
such that
\log M(s)\geq 2\log r
and (
1.4
) holds. However, we deduce from (
2.3
) by applying Lemma
2.1
to
u(z)=\log(|f(z)|/r)
that

\log M(r)>\log\frac{M(r)}{r}>\frac{1}{2}\left(\frac{r}{s}\right)^{1/2}\log\frac{M(s)}{r}\geq\frac{1}{4}\left(\frac{r}{s}\right)^{1/2}\log M(s),

which contradicts condition (
1.4
).
∎

For applications of Theorem
1.2
, it is often useful to express condition (
1.4
) in terms of the functions
\varepsilon(r),r>0,
and
k(r),r>0,
defined as follows:

\log M(r)=r^{1/2-\varepsilon(r)}\quad\text{and}\quad k(r)=\varepsilon(r)\log r;

equivalent forms of condition (
1.4
) are then

(2.4)

s^{\varepsilon(s)}\leq\frac{1}{4}r^{\varepsilon(r)}\quad\text{and}\quad k(r)\geq k(s)+\log 4,

for
r>r_{0}
, where
M(s)\geq r^{2}
as before.

Note that if
f
has order at most 1/2, minimal type, then for all sufficiently large values of
r
we have
0<\varepsilon(r)<1/2
and hence
0<k(r)=\varepsilon(r)\log r<\frac{1}{2}\log r
.

It is also useful to note that if
f
has order 1/2 then:

(a)

f
has lower order 1/2 if and only if
\varepsilon(r)\to 0
as
r\to\infty
,

(b)

f
is of minimal type if and only if
k(r)\to\infty
as
r\to\infty
.

We now give two special cases of Theorem
1.2
which are convenient for applications. Theorem
2.2
, part (a), shows that property (
1.2
) holds whenever the function
f
has positive lower order and
\varepsilon(r)=k(r)/\log r
does not tend to 0 too quickly. Example
1.3
shows that positive lower order alone is not sufficient here.

Theorem 2.2
.

Let
f
be a transcendental entire function of order 1/2, minimal type, and let
\varepsilon(r),r>0,
and
k(r),r>0,
be defined as above. Then there exists
r>0
such that
m^{n}(r)\to\infty
as
n\to\infty
if either of the following statements holds:

(a)

there exist
\delta\in(0,1/2)
,
C>1
and
r_{1}>0
such that

(2.5)

\delta\log r\geq k(r)\geq C\frac{\delta}{1/2-\delta}\log\log r,\;\;\text{for }r>r_{1};

(b)

\varepsilon(r)\to 0
as
r\to\infty
and there exist
C,d>1
and
r_{2}>0
such that

(2.6)

k(r)\geq Ck((\log r)^{2d}),\;\;\text{for }r>r_{2}.

Proof.

By Theorem
1.2
, it is sufficient to show that, for all sufficiently large
r
, condition (
1.4
) holds for some
s\in(0,r)
with
M(s)\geq r^{2}
.

(a) The inequality
k(r)\leq\delta\log r
can be written as
\varepsilon(r)\leq\delta
, that is,

\log M(r)\geq r^{1/2-\delta},

so the condition
M(s)\geq r^{2}
is satisfied by taking
s=(2\log r)^{1/(1/2-\delta)}
. With this choice of
s
the required condition (
1.4
), or equivalently (
2.4
), can be written as

(2.7)

k(r)\geq k((2\log r)^{1/(1/2-\delta)})+\log 4,\;\;\text{for }r>r_{0}.

The hypothesis
k(r)\leq\delta\log r
for
r>r_{1}
implies that

\displaystyle k((2\log r)^{1/(1/2-\delta)})

\displaystyle\leq\delta\log\left((2\log r)^{1/(1/2-\delta)}\right)

\displaystyle=\frac{\delta}{1/2-\delta}(\log 2+\log\log r),\;\;\text{for }(2\log r)^{1/(1/2-\delta)}>r_{1},

so a condition of the form

k(r)\geq\frac{\delta}{1/2-\delta}(\log 2+\log\log r)+\log 4,\;\;\text{for }r>r_{1},

is sufficient to imply that (
2.7
) and hence (
1.4
) hold for some
r_{0}\geq r_{1}
. This proves part (a).

(b) We first choose
\delta>0
such that
1/(1/2-\delta)<2d
. The hypothesis that
\varepsilon(r)\to 0
as
r\to\infty
implies that there exists
r(C,d)>0
such that
\varepsilon(r)\leq\delta/C
for
r>r(C,d)
, so

\log M(r)\geq r^{1/2-\delta/C},\;\;\text{for }r>r(C,d).

Therefore, the condition
M(s)\geq r^{2}
is satisfied, for sufficiently large
r
, by taking
s=(\log r)^{1/(1/2-\delta)}
, since
C>1
.
With this choice of
s
the required condition (
1.4
), or equivalently (
2.4
), can be written as

k(r)\geq k((\log r)^{1/(1/2-\delta)})+\log 4,\;\;\text{for }r>r_{0},

so a condition of the form

k(r)\geq Ck((\log r)^{1/(1/2-\delta)}),\;\;\text{for }r>r_{2},

is sufficient to imply that (
1.4
) holds for some
r_{0}\geq\max\{r_{2},r(C,d)\}
. This proves part (b).
∎

Theorem
2.2
can be used to give many examples of transcendental entire functions of order 1/2, minimal type, for which property (
1.2
) holds, including ones for which we can deduce that
I(f)
is connected by using Theorem
1.1
. We give here some examples of this type, derived from Theorem
2.2
, part (b), in which the functions have a very regular distribution of zeros.

For any transcendental entire function
f
we define
n(r)=n(r,f)
to be the number of zeros of
f
in
\{z:|z|\leq r\}
, counted according to multiplicity.

Theorem 2.3
.

Let
\varepsilon(r)
satisfy the hypotheses of Theorem
2.2
, part (b) and in addition suppose that
\varepsilon(r)
is decreasing and
k(r)=\varepsilon(r)\log r
is increasing.

Let
f
be a transcendental entire function of the form

f(z)=\prod_{n\in{\mathbb{N}}}\left(1-\frac{z}{a_{n}}\right),\quad 0<|a_{1}|<|a_{2}|<\cdots,

where

n(r,f)\sim r^{1/2-\varepsilon(r)}\;\text{ as }r\to\infty.

Then

(a)

there exist constants
1<A<B
and
R>0
such that

Ar^{1/2-\varepsilon(r)}\leq\log M(r,f)\leq Br^{1/2-\varepsilon(r)},\;\;\text{for }r>R,

(b)

there exists
r>0
such that
m^{n}(r)\to\infty
as
n\to\infty
.

Remark
A family of functions that satisfy the hypotheses of Theorem
2.2
, part (b), and Theorem
2.3
is given by

k(r)=\alpha(\log^{n}r)^{\beta},\quad\alpha,\beta>0,n\geq 2,

where
\log^{n}
denotes the
n
-th iterated logarithm.

For the proof of Theorem
2.3
, we require a result about the relationship between
M(r)=M(r,f)
and the following quantities:

N(r)=\int_{0}^{r}\frac{n(t)}{t}\,dt\quad\text{and}\quad Q(r)=r\int_{r}^{\infty}\frac{n(t)}{t^{2}}\,dt.

We use the following estimates; see
[
11
, Lemma 3.3]
, for example.

Lemma 2.4
.

Let
f
be a transcendental entire function of order less than
1
with
f(0)=1
. Then, for
r>0
,

N(r)\leq\log M(r)\leq N(r)+Q(r).

Proof of Theorem
2.3
.

Since
n(r)\sim r^{1/2-\varepsilon(r)}
as
r\to\infty
, where
\varepsilon(r)
is positive and decreasing to 0, and
k(r)=\varepsilon(r)\log r
is increasing, we have

N(r)=\int_{0}^{r}\frac{1+o(1)}{t^{1/2+\varepsilon(t)}}\,dt\geq\frac{(1+o(1))}{r^{\varepsilon(r)}}\int_{0}^{r}\frac{dt}{t^{1/2}}=2r^{1/2-\varepsilon(r)}(1+o(1))

and

Q(r)=r\int_{r}^{\infty}\frac{1+o(1)}{t^{3/2+\varepsilon(t)}}\,dt\leq(1+o(1))r^{1-\varepsilon(r)}\int_{r}^{\infty}\frac{dt}{t^{3/2}}=2r^{1/2-\varepsilon(r)}(1+o(1)),

so

Q(r)\leq N(r)(1+o(1))\;\text{ as }r\to\infty.

Since
\varepsilon(r)
is decreasing, we have

N(r)=\int_{0}^{r}\frac{(1+o(1))}{t^{1/2+\varepsilon(t)}}\,dt\leq(1+o(1))\int_{0}^{r}\frac{dt}{t^{1/2+\varepsilon(r)}}=\frac{1+o(1)}{1/2-\varepsilon(r)}r^{1/2-\varepsilon(r)},

so

N(r)+Q(r)\leq 4r^{1/2-\varepsilon(r)}(1+o(1))\;\text{ as }r\to\infty.

Part (a) follows by Lemma
2.4
and the above inequalities for
N(r)
and
Q(r)
.

It follows from part (a) that

\log M(r,f)=r^{1/2-\hat{\varepsilon}(r)},\quad\text{where}\quad\hat{\varepsilon}(r)=\varepsilon(r)+O(1)/\log r\;\text{ as }r\to\infty,

so
\hat{\varepsilon}(r)\to 0
as
r\to\infty
and
\hat{k}(r)=\hat{\varepsilon}(r)\log r
satisfies

\hat{k}(r)=k(r)+O(1)\;\text{ as }r\to\infty.

Since
k(r)
satisfies (
2.6
), so in particular
k(r)\to\infty
as
r\to\infty
, it follows that
\hat{k}(r)
also satisfies (
2.6
). Hence
f
satisfies the hypotheses of Theorem
2.2
, part (b), so the proof is complete.
∎

3.
Constructing entire functions of small order

Our method of proving Examples
1.4
and
1.3
uses a recent generalisation
[
13
]
of Kjellberg’s method
[
6
, Chapter 2]
for constructing transcendental entire functions of order less than
1/2
by approximating certain continuous subharmonic functions by functions of the form
\log|f|
where
f
is a transcendental entire function. In this section we summarise the results from
[
13
]
which are needed to construct our examples.

Kjellberg’s method is a two stage process:

1.

a continuous subharmonic function
u
with the required properties is obtained by using a positive harmonic function defined in the complement of a particular sequence of radial slits, on which
u
vanishes;

2.

the Riesz measure of
u
is discretised to produce an entire function
f
such that
\log|f|
is close to
u
away from the zeros of
f
.

The paper
[
13
]
gives a generalisation of Kjellberg’s method which allows the slits to be chosen more flexibly than in
[
6
]
.

We now recall some of the key definitions and terminology needed to state the results from
[
13
]
.

Definition 3.1
.

A subharmonic function
u
is in the class
{\mathcal{K}}
if
u
is continuous in
{\mathbb{C}}
and positive harmonic in
D={\mathbb{C}}\setminus E
, where
E\subset(-\infty,0]
is a closed set on which
u
vanishes. We assume that each point of
E
is regular for the Dirichlet problem in
D
.

Remark
For each closed subset of the negative real axis, there is exactly one corresponding function
u\in{\mathcal{K}}
up to positive scalar multiples, by a result of Benedicks
[
1
, Theorem 4]
.

Recall that for a set
S\subset{\mathbb{R}}^{+}
and
r>1
, we define the
upper logarithmic density
of
S
,

\overline{\Lambda}(S)=\limsup_{r\to\infty}\frac{1}{\log r}\int_{S\cap(1,r)}\frac{dt}{t},

and the
lower logarithmic density
of
S
,

\underline{\Lambda}(S)=\liminf_{r\to\infty}\frac{1}{\log r}\int_{S\cap(1,r)}\frac{dt}{t}.

When
\overline{\Lambda}(S)=\underline{\Lambda}(S)
we speak of the
logarithmic density
of
S
, denoted by
\Lambda(S)
.

Recall next that, for a continuous subharmonic function
u
in
{\mathbb{C}}
,

A(r)=A(r,u)=\min_{|z|=r}u(z)\quad\text{and}\quad B(r)=B(r,u)=\max_{|z|=r}u(z),

and the
order
and
lower order
of
u
are

\rho(u)=\limsup_{r\to\infty}\frac{\log B(r)}{\log r}\quad\text{and}\quad\lambda(u)=\liminf_{r\to\infty}\frac{\log B(r)}{\log r},

respectively. For all
u\in{\mathcal{K}}
we have
0\leq\lambda(u)\leq\rho(u)\leq 1/2
.

The following result gives some basic properties of all functions in the class
{\mathcal{K}}
; see
[
13
, Theorem 1.2]
.

Theorem 3.2
.

Let
u\in{\mathcal{K}}
, with
E
the corresponding closed subset of the negative real axis. Then
u
has the following properties.

(a)

Monotonicity properties:
for all
r>0
,

u(re^{i\theta})\;\;\text{is decreasing as a function of }\theta,\text{ for }0\leq\theta\leq\pi,

so, in particular,
B(r,u)=u(r)
and
A(r,u)=u(-r)
for all
r>0
. Also,

\frac{u(r)}{r^{1/2}}=\frac{B(r,u)}{r^{1/2}}\;\;\text{is decreasing for }r>0,

so, in particular,
\rho(u)\leq 1/2
.

(b)

Bounds for order and lower order:

\rho(u)\geq\tfrac{1}{2}\overline{\Lambda}(E^{*})\quad{\text{a}nd}\quad\lambda(u)\geq\tfrac{1}{2}\underline{\Lambda}(E^{*}),

where
E^{*}=\{x:-x\in E\}
.

The next result, again taken from
[
13
, Theorem 1.5]
, concerns the behaviour of certain functions in the class
{\mathcal{K}}
.

Theorem 3.3
.

Let
u\in{\mathcal{K}}
, with
E
the corresponding closed subset of the negative real axis. If

E^{c}\supset\bigcup_{n\geq 0}(-d_{n},-c_{n}),

where
0\leq c_{0}<d_{0}<c_{1}<d_{1}<\cdots,
and
\limsup_{n\to\infty}d_{n}/c_{n}>1
, then

\frac{u(r)}{r^{1/2}}\to 0\;\;\text{as }r\to\infty.

The final result we need from
[
13
, Theorem 1.6]
describes the approximation used in the second stage of Kjellberg’s process, showing how we can approximate a function
u\in{\mathcal{K}}
by
\log|f|
, where
f
is entire. This generalises the result given by Kjellberg for a particular type of set
E
; see
[
6
, Chapter 4]
.

Theorem 3.4
.

Suppose that
u\in{\mathcal{K}}
and

E=\bigcup_{n\geq 0}[-b_{n},-a_{n}],

where
0\leq a_{0}<b_{0}<a_{1}<b_{1}<\cdots,
and
a_{n}\to\infty
as
n\to\infty
. Put

D_{1}={\mathbb{C}}\setminus\{z:\text{{\rm dist}}(z,E)\leq 1\}.

Then there exists an entire function
f
with only negative zeros, all lying in the set
E
, such that

(3.1)

\log|f(z)|-u(z)=O\left(\log|z|\right)\;\;\text{as }z\to\infty,\;\;\text{for }z\in D_{1}.

Moreover, if we also have

(3.2)

b_{n}/a_{n}\geq d>1,\;\;\text{for }n\geq 0,

then there exists
R=R(u)>0
such that

(3.3)

\log|f(z)|\leq u(z)+4\log|z|,\;\;\text{for }|z|\geq R.

Theorem
3.4
will enable us to approximate subharmonic functions
u\in{\mathcal{K}}
by functions of the form
\log|f|
, where
f
is a transcendental entire function of the same order, lower order and type class as
u
.

4.
Proofs of Examples
1.3
and
1.4

We prove Examples
1.3
and
1.4
by using Theorems
3.2
,
3.3
and
3.4
to construct entire functions that approximate suitable subharmonic functions. In each case we show that property (
1.2
) is false by arranging that the minimum modulus of the entire function is relatively small on intervals that are relatively long, consistent with the required growth of the maximum modulus.

We begin by proving the following result, needed in the construction of Example
1.3
. The proof is rather long as the set
E
has to be chosen carefully so that the function
u\in{\mathcal{K}}
does not grow too quickly on the positive real axis and takes large values on the negative real axis only relatively rarely.

Lemma 4.1
.

Let
\delta:(0,\infty)\mapsto(0,1/4)
be a decreasing function such that

\delta(r)\to 0\;\text{ as }r\to\infty,

and let
a_{n}
and
b_{n}
,
n\geq 0
, be chosen to satisfy

(4.1)

a_{n+1}\geq b_{n}^{10},\;\;\text{for }n\geq 0,

(4.2)

\delta(\tfrac{1}{2}a_{n+1})\leq\frac{\log b_{n}}{40b_{n}},\;\;\text{for }n\geq 0,

and

(4.3)

\log b_{n+1}=\frac{b_{n}}{\log b_{n}}\log a_{n+1},\;\;\text{for }n\geq 0.

Then the unique subharmonic function
u\in{\mathcal{K}}
corresponding to the set
E=\bigcup_{n\geq 0}[-b_{n},-a_{n}]
, with
u(1)=1
, satisfies

\rho(u)=1/2\quad\text{and }\quad u(r)/r^{1/2}\to 0\;\text{ as }r\to\infty,

and also

(a)

there exists
r_{0}>0
such that

(4.4)

u(r)\leq r^{1/2-\delta(r)},\;\;\text{for }r\geq r_{0};

(b)

we have
u(-r)=0
, for
r\in[a_{n},b_{n}]
,
n\geq 0
, and, for
n
sufficiently large,

(4.5)

u(-r)<\log b_{n+1},\;\;\text{for }b_{n}\leq r\leq a_{n+1}.

Proof.

Let
u\in{\mathcal{K}}
be the unique subharmonic function with
u(1)=1
corresponding to the set
E=\bigcup_{n\geq 0}[-b_{n},-a_{n}]
, where
a_{n}
and
b_{n}
satisfy (
4.1
), (
4.2
) and (
4.3
). The property (
4.3
) implies that
\overline{\Lambda}(E^{*})=1
, so
u
has order 1/2 by Theorem
3.2
, part (b).

Also, by (
4.1
) and Theorem
3.3
, we have

\frac{u(r)}{r^{1/2}}\to 0\;\text{ as }r\to\infty.

In the proof, we often use the following property of
u
, from Theorem
3.2
, part (a):

(4.6)

\frac{u(r)}{r^{1/2}}=\frac{B(r,u)}{r^{1/2}}\;\;\text{is decreasing as }r\to\infty.

We also need further properties of
u(r)
and of the average

I(r)=\frac{1}{2\pi}\int_{0}^{2\pi}u(re^{i\theta})\,d\theta,\quad r>0,

namely that

(4.7)

u(r)\text{ and }I(r)\text{ are positive increasing convex functions of }\log r,

and

(4.8)

I(r)=A_{n}\log r+B_{n},\;\;\text{for }r\in[b_{n},a_{n+1}],\;n\geq 0,

for some constants
A_{n}>0
and
B_{n}
,
n\geq 0
; see
[
4
, Section 2.7]
. Also,

(4.9)

u(-r)<I(r)<u(r),\;\;\text{for }r>0,

by Theorem
3.2
, part (a), and

(4.10)

u(r)\leq 3I(2r),\;\;\text{for }r\geq 0,

by using the Poisson integral of
u
to majorise
u
in
\{z:|z|\leq 2r\}
; see
[
4
, Theorem 2.5]
for example.

Taken together, these properties will give us good control over the behaviour of
u(r)
and
u(-r)
in terms of the sequences
(a_{n})
and
(b_{n})
.

We write

u(r)=r^{1/2-\varepsilon(r)},\;\;r>0,

where
0\leq\varepsilon(r)<1/2
, for
r>1
, by (
4.6
). In order to verify (
4.4
), we need to show that
\varepsilon(r)\geq\delta(r)
for
r
sufficiently large.

To do this, we obtain bounds on the coefficients
A_{n}
and
B_{n}
,
n\geq 0
, in (
4.8
). First, we obtain an upper bound for
A_{n}
. By (
4.6
), (
4.8
) and (
4.9
),

\frac{A_{n}\log(b_{n}^{2})+B_{n}}{b_{n}}=\frac{I(b_{n}^{2})}{b_{n}}<\frac{u(b_{n}^{2})}{b_{n}}\leq\frac{u(b_{n})}{b_{n}^{1/2}},\;\;\text{for }n\geq 0,

so

(4.11)

A_{n}\log b_{n}+(A_{n}\log b_{n}+B_{n})<u(b_{n})b_{n}^{1/2}\leq b_{n},\;\;\text{for }n\geq 0,

by (
4.6
) again. Since
A_{n}\log b_{n}+B_{n}=I(b_{n})>0
, we deduce from (
4.11
) that

(4.12)

A_{n}<\frac{b_{n}}{\log b_{n}},\;\;\text{for }n\geq 0.

Next we claim that
B_{n}<0
for
n
sufficiently large. We do this by using the fact that
\phi(t)=I(e^{t})
is a positive increasing convex function with the property that
\phi(t)/t\to\infty
as
t\to\infty
. This last property holds because
\phi
is convex and

\limsup_{t\to\infty}\frac{\log\phi(t)}{t}=\limsup_{r\to\infty}\frac{\log I(r)}{\log r}=\limsup_{r\to\infty}\frac{\log u(r)}{\log r}=1/2,

in view of (
4.10
) and the fact that
u
has order
1/2
.

Now, by (
4.8
),

\frac{\phi(t)}{t}=A_{n}+\frac{B_{n}}{t},\;\text{ for }\log b_{n}\leq t\leq\log a_{n+1},

and, by the convexity of
\phi
, we have

A_{n}\geq\frac{\phi(\log b_{n})-\phi(1)}{\log b_{n}-1}>\frac{\phi(\log b_{n})}{\log b_{n}}=A_{n}+\frac{B_{n}}{\log b_{n}},

for
n
sufficiently large. Hence there exists a positive integer
N_{1}
such that

(4.13)

B_{n}<0,\;\text{ for }n\geq N_{1},

as claimed.

The estimate (
4.12
) implies that there exists
N_{2}\geq N_{1}
such that

A_{n}<\frac{b_{n}}{\log b_{n}}\leq\frac{r^{1/5}}{\log r^{1/5}}<\frac{r^{1/4}}{3\log 2r}\,,\;\;\text{for }r\geq b_{n}^{5},n\geq N_{2}.

Therefore, we deduce from (
4.10
), (
4.13
) and (
4.8
) that

\frac{1}{r^{\varepsilon(r)}}=\frac{u(r)}{r^{1/2}}\leq\frac{3I(2r)}{r^{1/2}}<\frac{3A_{n}\log 2r}{r^{1/2}}<\frac{1}{r^{1/4}},\;\;\text{for }b_{n}^{5}\leq r\leq\tfrac{1}{2}a_{n+1},n\geq N_{2}.

Hence

(4.14)

\varepsilon(r)>\frac{1}{4}\geq\delta(r),\;\;\text{for }b_{n}^{5}\leq r\leq\tfrac{1}{2}a_{n+1},n\geq N_{2}.

To complete the proof of (
4.4
), we show that
\varepsilon(r)\geq\delta(r)
for
r\in[\frac{1}{2}a_{n},b_{n}^{5}]
and
n\geq N_{2}+1
by using the fact that

\frac{u(r)}{r^{1/2}}\leq\frac{u(\tfrac{1}{2}a_{n})}{(\tfrac{1}{2}a_{n})^{1/2}},\;\;\text{for }r\geq\tfrac{1}{2}a_{n},n\geq 0,

by (
4.6
) once again, that is,

\varepsilon(r)\geq\frac{\varepsilon(\tfrac{1}{2}a_{n})\log\tfrac{1}{2}a_{n}}{\log r},\;\;\text{for }r\geq\tfrac{1}{2}a_{n},n\geq 0.

Therefore, for
r\in[\frac{1}{2}a_{n},b_{n}^{5}]
and
n\geq N_{2}+1
, we have, by (
4.14
), (
4.3
) and (
4.2
),

(4.15)

\displaystyle\varepsilon(r)

\displaystyle\geq\frac{\varepsilon(\tfrac{1}{2}a_{n})\log\tfrac{1}{2}a_{n}}{\log r}>\frac{\log\tfrac{1}{2}a_{n}}{4\log r}

\displaystyle\geq\frac{\log a_{n}^{1/2}}{20\log b_{n}}=\frac{\log b_{n-1}}{40b_{n-1}}

\displaystyle\geq\delta(\tfrac{1}{2}a_{n})\geq\delta(r),

since
\delta
is a decreasing function. Combining (
4.14
) and (
4.15
), we obtain (
4.4
).

Finally, (
4.5
) follows immediately from the fact that, for
r\in[a_{n},b_{n}]
, we have
u(-r)=0
and for
r\in[b_{n},a_{n+1}]
,
n\geq N_{1}
, we have

\displaystyle u(-r)<I(r)

\displaystyle=A_{n}\log r+B_{n}

\displaystyle\leq A_{n}\log a_{n+1}

\displaystyle\leq\frac{b_{n}}{\log b_{n}}\log a_{n+1}

\displaystyle=\log b_{n+1},

by (
4.9
), (
4.13
), (
4.12
) and (
4.3
).
∎

We now give the proof of Example
1.3
. Here we use again the fact, mentioned in Section
2
, that property (
1.2
) holds if and only if

(4.16)

\text{there exists }R>0\text{ such that }\widetilde{m}(r)>r,\text{ for }r\geq R,

where

\widetilde{m}(r):=\max\{m(s):0\leq s\leq r\},\;\;\text{for }r\in[0,\infty).

Proof of Example
1.3
.

Without loss of generality we can assume that
\delta(r):(0,\infty)\to(0,1/4)
is a decreasing function such that
\delta(r)\to 0
as
r\to\infty
.

Let
u
be the subharmonic function constructed in Lemma
4.1
and let
D={\mathbb{C}}\setminus E={\mathbb{C}}\setminus\bigcup_{n\geq 0}[-b_{n},-a_{n}]
. We apply Theorem
3.4
to the function
u
to obtain an entire function
f_{1}
with zeros in the set
E
such that

(4.17)

\log|f_{1}(z)|-u(z)=O(\log|z|)\;\text{ as }z\to\infty,\;z\in D_{1},

where
D_{1}=D\setminus\{z:{\rm dist}(z,\partial D)\leq 1\}
, and also such that

(4.18)

\log|f_{1}(z)|\leq u(z)+4\log|z|,\;\;\text{for }|z|\geq R,

for some
R=R(u)>0
.

In view of the symmetry of
u
in the real axis, we can assume that
\arg f_{1}(x)=0
for
x>0
.

We deduce from (
4.17
) and (
4.18
) that
f_{1}
has order
1/2
minimal type, since
u
has these properties. In particular we can represent
f_{1}
as an infinite product of the form

(4.19)

f_{1}(z)=c\prod_{n=0}^{\infty}\left(1+\frac{z}{t_{n}}\right),\;\;\text{where }c>0\text{ and }t_{n}\in E,\;n\geq 0.

We also deduce from (
4.18
) that there exist
r_{0}>0
such that

(4.20)

m(r,f_{1})\leq\exp(u(-r)+4\log r),\;\;\text{for }r\geq r_{0},

and hence, since
u
vanishes on the set
E
,

(4.21)

m(r,f_{1})\leq r^{4},\;\;\text{for }r\geq r_{0},\;-r\in E.

Now we consider the function
f
defined by

(4.22)

f(z)=c\prod_{n=5}^{\infty}\left(1+\frac{z}{t_{n}}\right),

and prove that
f
satisfies (
1.5
). For some constant
K>0
, we have, by (
4.18
) and (
4.4
),

\displaystyle M(r,f)

\displaystyle\leq M(r,f_{1})\frac{K}{r^{5}}

\displaystyle\leq\exp(u(r)+4\log r)\frac{K}{r^{5}}

\displaystyle\leq\exp(u(r))

\displaystyle\leq\exp\left(r^{1/2-\delta(r)}\right),

provided that
r
is sufficiently large.

Finally, we show that property (
2.2
) does not hold for this function
f
. For
r\in[a_{n+1},b_{n+1}]
, we have

m(r,f)\leq m(r,f_{1})\frac{K}{r^{5}}<1\leq b_{n+1},

provided that
n
is sufficiently large, by (
4.22
) and (
4.21
). Next, for
r\in[b_{n},a_{n+1}]
, we have, by (
4.18
) and (
4.5
),

\displaystyle m(r,f)

\displaystyle\leq m(r,f_{1})\frac{K}{r^{5}}

\displaystyle\leq\exp\left(u(-r)+4\log r\right)\frac{K}{r^{5}}

\displaystyle\leq\exp(u(-r))\leq b_{n+1},

provided that
n
is sufficiently large.

Therefore, for
n
sufficiently large,

\widetilde{m}(b_{n+1},f)=\max\{m(r):0\leq r\leq b_{n+1}\}\leq b_{n+1},

so property (
4.16
) does not hold. Hence, for the function
f
, there is no value of
r
such that
m^{n}(r)\to\infty
as
n\to\infty
.

This completes the proof of Example
1.3
.
∎

Proof of Example
1.4
.

Here we follow a similar procedure to the previous proof, starting this time with a subharmonic function
u\in{\mathcal{K}}
, where
E=\bigcup_{n\geq 0}[-b_{n},-a_{n}]
, such that
u(1)=1
,
b_{n}/a_{n}\nearrow\infty
as
n\to\infty
and
a_{n+1}=2b_{n}
for
n\geq 0
.

By Theorems
3.2
and
3.3
, the function
u
has order 1/2 minimal type and lower order 1/2, so the entire functions
f_{1}
and
f
resulting from applying Theorem
3.4
(as in the previous proof) also have these properties, by (
4.17
) and (
4.18
).

Finally, to show that property (
4.16
) fails, we need to choose the sequences
(a_{n})
and
(b_{n})
iteratively so that

(4.23)

u(-r)<\log b_{n+1},\;\;\text{for }b_{n}\leq r\leq a_{n+1},n\geq 0,

also holds, in order that

m(r,f)\leq\exp(u(-r))\leq b_{n+1},\;\;\text{for }b_{n}\leq r\leq a_{n+1},n\geq 0.

Arranging for (
4.23
) to hold is clearly possible since

\max\{u(-r):b_{n}\leq r\leq a_{n+1}\}\leq\max\{u(r):b_{n}\leq r\leq a_{n+1}\}\leq a^{1/2}_{n+1},

by Theorem
3.2
, part (a).
∎
