1.
Introduction

The weighted Euclidean distance between two vectors is a Euclidean distance where the contribution of each dimension is scaled by a given weight representing the relevance of the dimension.
Specifically, given a vector
x\in\mathbb{R}^{d}
and a weight vector
w\in\mathbb{R}^{d}
(with
w_{i}\geq 0
for all
i\in\{1,\ldots d\}
), the
weighted norm
of
x
with weights
w
is defined as
\left\lVert x\right\rVert_{w}=\sqrt{\sum_{i=1}^{d}w_{i}^{2}x_{i}^{2}}
. The
weighted Euclidean distance
between two vectors
x,y
is then defined as
\left\lVert x-y\right\rVert_{w}
.

When weights are known and fixed, the weighted Euclidean norm/distance can be trivially reduced to the unweighted case by suitably scaling vector coordinates: each vector
x
is replaced with
x^{\prime}=w\odot x
, where
\odot
represents the element-wise multiplication; we easily get
\left\lVert x^{\prime}\right\rVert_{2}=\left\lVert x\right\rVert_{w}
.
It then follows that several computational problems defined on the unweighted Euclidean space (e.g., dimensionality reduction, near neighbor search) can be easily adapted to the weighted case by scaling the input vectors.
However, this is not the case when the weight vector might change or is initially unknown.
This is for instance the case of relevance feedback in information retrieval: this is an iterative retrieval process where the feedback
information from an user on a initial set of results is incorporated into subsequent database searches; the feedback is encoded in suitable weights of a weighted distance (e.g.,
\ell_{2}
or
\ell_{1}

(
AHCG 00
)
) used in subsequent similarity search queries.

The goal of this paper is to investigate the impact of a dynamically weighted distance in dimensionality reduction techniques.
Dimensionality reduction methods map high- dimensional vectors into a space with lower dimensionality, while keeping some information on the original vectors; the low-dimension vectors reduce communication and storage costs and mitigate the curse of dimensionality in the running time.
A well-known result on dimensionality reduction is provided by the
Johnson–Lindenstrauss (JL) lemma

(
JL 84
)
: given a set
S
of
n
vectors in
\mathbb{R}^{d}
, there exists a linear map
g(\cdot)
that approximately maintains pairwise squared Euclidean distances; that is, for any
x,y\in S
, we have that
|\left\lVert x-y\right\rVert_{2}^{2}-\left\lVert g(x)-g(y)\right\rVert_{2}^{2}|\leq\varepsilon\left\lVert x-y\right\rVert_{2}^{2}
.
The JL lemma holds even with weighted Euclidean distance if weights are known beforehand.
Consider one of the several linear maps
g(x)
satisfying the JL lemma, for instance
g(x)=Ax
where
A
is the Achlioptas’ matrix
(
Ach 03
)
(i.e., each element is a random value in
\{-1,1\}
):
if all input vectors in
S
are scaled according to the given weights
w
, the map
g(x^{\prime})
gives
|\left\lVert x-y\right\rVert_{w}^{2}-\left\lVert g(x^{\prime})-g(y^{\prime})\right\rVert_{2}^{2}|\leq\varepsilon\left\lVert x-y\right\rVert_{w}^{2}
, where
x^{\prime}
is the scaled version of the input vector
x\in S
.
However, this does not hold if weights are known only after the dimensionality reduction step: clearly, one can scale the original vectors once weights are provided, and then reapply the dimensionality reduction method; however, this doesn’t clearly work if only access to the compressed vectors is provided (e.g., for space issues).

Dimensionality reduction under Euclidean distance with dynamic weights can be formalized by the following problem: 1) each vector
x\in S
is mapped into a smaller vector with a function
g(\cdot)
, obliviously of weights; 2) when weights
w
are provided, a function
\rho(g(x),w)
is applied to a compressed vector
g(x)
to obtain an unbiased estimate of
\left\lVert x\right\rVert_{w}^{2}
.
To solve the problem we have to provide function
g(x)
to map vectors into the smaller space, and function
\rho(g(x),w)
to recover the weighted norm.
To the best of our knowledge, no previous works have addressed this problem.

1.1.
Our results

In this paper, we provide the first solution to dimensionality reduction with dynamic weights.
We map vectors in
S
into a low dimensional
complex
vector space with a
linear
map
g(x):\mathbb{R}^{d}\rightarrow\mathbb{C}^{k}
, for a suitable value
k>0
; the map is done before the weights are revealed and it is hence independent of weights.
More specifically, we let
g(x)=Ax/\sqrt{k}
where matrix
A
is a complex
k\times d
random matrix, where each entry is an independently and identically distributed random variable over
\{+1,-1,+i,-i\}
, where
i
is the imaginary unit (i.e.,
i^{2}=-1
).
Once the weight vector
w
is known, we apply a suitable transformation to the low-dimensional vectors in
S^{\prime}=\{g(x):x\in S\}
that allows to estimate the squared weighted Euclidean norms and the pairwise distances for any pair of vectors in
S
.
Let
h(g(x),w)=g(x)\odot\sqrt{k}g(w)
, and
\rho(g(x),w)=\textnormal{Re}\left(\displaystyle h(g(x),w)\cdot h(g(x),w)\right)
, where
\odot
is the element-wise multiplication,
\cdot
is the inner product, and
\textnormal{Re}\left(\displaystyle\cdot\right)
is the real part; note that computing
\rho(\cdot,\cdot)
does not require access to the original vector
x
.
We claim that the expected value of
\rho(g(x),w)
is
\left\lVert x\right\rVert_{w}^{2}
.

Given a vector
x
and weight vector
w
, we define the
distortion
as
\Delta(x,w)=\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{2}/\left\lVert x\right\rVert_{w}
, which measures the perturbation of the norm of
x
with respect to the given weights.
By the Cauchy-Schwarz inequality we have
\Delta(x,w)\geq 1
, and when all dimensions of
w
have the same value, we get the minimum distortion
\Delta(x,w)=1
.
Let
\Delta
be a given parameter named
distortion threshold
.
Then, the following theorem, which is the main result of our paper, states that when the given weights create a distortion
\Delta(x,w)
lower than the given threshold
\Delta
,
\rho(g(x),w)
provides an
\varepsilon
approximation as in the JL lemma; otherwise, we get a bounded additive error.

Theorem 1.1.

Let
\varepsilon,\delta>0
. Let
c
be a suitable universal constant. Let also

k=c\max\left\{\frac{\Delta^{4}\ln(24/\delta)}{\varepsilon^{2}},\ \frac{\Delta^{2}\ln(24/\delta)^{2}}{\varepsilon}\right\}.

Then, for any given
x,w\in\mathbb{R}^{d}
we have, with probability at least
1-\delta
,

\left\lVert x\right\rVert_{w}^{2}-\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}<\rho(x,w)<\left\lVert x\right\rVert_{w}^{2}+\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}.

In particular, if
\Delta\geq\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{2}/\left\lVert x\right\rVert_{w}
, we get, with probability at least
1-\delta
,

(1-\varepsilon)\left\lVert x\right\rVert_{w}^{2}<\rho(x,w)<(1+\varepsilon)\left\lVert x\right\rVert_{w}^{2}.

Note that function
\rho(g(x),w)
is not a norm in
\mathbb{C}^{k}
: the function can indeed return a negative value; however its expected behavior is as the weighted squared Euclidean distance.

To better understand the results, consider the following example.
A similarity search query returns a compressed set
S^{\prime}
of vectors within Euclidean distance
R
from a given query
q
.
We want to narrow down the set
S^{\prime}
by keeping those vectors within distance
r\leq R
under a selected subset of
\ell<<d
coordinates: that is,
w
is
\ell
-sparse
(
KW 16
)
and consists of
\ell
entries set to 1, and
d-\ell
entries to 0.
Then the above theorem states that our construction allows to select vectors with a
(1+\varepsilon)r
error if
k=\Omega\left((R/r)^{4}(\ell/\varepsilon)^{2}\log n\right)
.
This example also highlights a limitation of our approach: as
\ell
approaches
\sqrt{d}
(or the distortion thresholds reaches
d^{1/4}
), we get that the dimension
k
should be superlinear in
d
: clearly, storing the entire datasets provide better bounds and we leave as an open question to improve guarantees in this case.

We observe that the linearity of
g(\cdot)
, allows us to estimate pairwise weighted Euclidean distances in
S
using the compressed vectors, as

\rho(g(x)-g(y))=\rho(g(x-y))
is a unbiased estimator of
\left\lVert x-y\right\rVert_{w}^{2}
.
Note that the dimensionality reduction function
g^{\prime}(x)=B(x\odot x)
, where
B
is a random matrix with entries in
\{-1,1\}
, allows to estimate the weighted norm: indeed,
\rho^{\prime}(g^{\prime}(x),w)=g^{\prime}(x)\odot g^{\prime}(w)
is an unbiased estimator of
\left\lVert x\right\rVert_{w}^{2}
. However,
g^{\prime}(\cdot)
is not linear and cannot be used for estimating pairwise weighted distances in
S
.

The analysis of the aforementioned result leverages on the decomposition of the complex dimensionality reduction into several Rademacher chaos random variables.
To do so, we develop a novel upper bound the tail probabilities for sums of independent Rademacher chaoses, which can be of independent interest.
Specifically, let be
S
be a Rademacher chaos of order
\gamma^{\prime}
, and let
S_{i}
denote
k
independent Rademacher chaoses with the same distribution of
S
.
We then have the following concentration result that builds on a concentration result for sums of independent sub-Weibull random variables
(
KC 22
)
.

Theorem 1.2.

Let
S
and
\{S_{i}\}_{i=1,\dots,k}
be
k+1
independent and identically distributed Rademacher chaoses of order
\gamma^{\prime}
. Let
W(S)
be the Euclidean norm of the coefficients in
S
.
Then
\forall\gamma\geq 3
such that
\gamma^{\prime}\leq\gamma
, there exist constants
c_{1}(\gamma),c_{2}(\gamma)
depending only on
\gamma
such that

\textnormal{Pr}\left[\displaystyle\left|\sum_{i=1}^{k}S_{i}\right|>W(S)\left(c_{1}(\gamma)\sqrt{k}\sqrt{t}+c_{2}(\gamma)t^{\nicefrac{{\gamma}}{{2}}}\right)\right]\leq 2e^{-t}.

Moreover, we show that the proposed approach with complex numbers can also be used in the streaming settings to estimate
\left\lVert x\right\rVert_{w}^{2}
when both
x
and
w
are provided in the stream in arbitrary order.
We recall that, in the streaming model of computation, data are generated continuously, and they have to be processed on-the-fly while maintaining in memory only a small (i.e. sublinear) portion of the data.
We construct an AMS-like sketch
\rho_{\rm s}
that, by leveraging on random complex values in
\{+1,-1,+i,-i\}
, allows us to estimate
\left\lVert x\right\rVert_{w}^{2}
.
The sketch is not linear and cannot be used for computing pairwise weighted distances;
however, it requires 8-independent hash functions, and not full independence as in the previous result.
The following theorem formalizes this result.

Theorem 1.3.

There exists a sketch
\rho_{\rm s}(x,w)
that uses
{O}\left(\varepsilon^{-2}\Delta^{4}\log(1/\delta)\right)
space such that,
for any
x,w\in\mathbb{R}^{d}
and for any
\varepsilon,\delta>0
, we have that, with probability at least
1-\delta
,

\left\lVert x\right\rVert^{2}_{w}-\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}<\rho_{\rm s}(x,w)<\left\lVert x\right\rVert^{2}_{w}+\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}.

In particular, if
\Delta\geq\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}/\left\lVert x\right\rVert^{2}_{w}
, we get, with probability at least
1-\delta
,

(1-\varepsilon)\left\lVert x\right\rVert^{2}_{w}<\rho_{\rm s}(x,w)<(1+\varepsilon)\left\lVert x\right\rVert^{2}_{w}.

In Section

Preliminaries

2.1.
Basic concepts

Given a value
p>0
, the
p
-norm
of a vector
x\in\mathbb{R}^{d}
is defined as
\left\lVert x\right\rVert_{p}=\left(\sum_{i=1}^{d}|x|^{p}_{i}\right)^{1/p}
.
Given a
weight vector

w
in
\mathbb{R}_{+}^{d}
, the
weighted
p
-norm
of
x
is
\left\lVert x\right\rVert_{w,p}=\left(\sum_{i=1}^{d}w_{i}^{p}|x|^{p}_{i}\right)^{1/p}
.
When
p=2
, we get the Euclidean norm and we simply denote the weighted norms of
x
as
\left\lVert x\right\rVert_{w}
.

We define a quantity that will be used later in the paper.
Let
x,w\in\mathbb{R}^{d}
;
we define the
distortion
of
x
and
w
as
\Delta(x,w)=\frac{\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{2}}{\left\lVert x\right\rVert_{w}}
.
Note that the distortion of
x
and
w
is invariant to scaling for both the arguments, i.e.
\Delta(ax,w)=\Delta(x,w)
and
\Delta(x,aw)=\Delta(x,w)
for any
a>0
.
Moreover, for the Cauchy-Schwarz inequality (see
2.1
below), we have that
\Delta(x,w)\geq 1
.

We state some commonly known inequalities that will be used in the subsequent sections.

Lemma 2.0 (Cauchy-Schwarz ineq.).

For any
x,y\in\mathbb{R}^{d}
,

\left(\sum_{i=1}^{d}x_{i}y_{i}\right)^{2}\leq\left(\sum_{i=1}^{d}x_{i}^{2}\right)\left(\sum_{i=1}^{d}y_{i}^{2}\right)=\left\lVert x\right\rVert^{2}_{2}\left\lVert y\right\rVert^{2}_{2}.

Lemma 2.0 (Monotonicity of
p
-norm).

For any
x\in\mathbb{R}^{d}
and any
0<p<q<+\infty
, we have

\left\lVert x\right\rVert_{q}\leq\left\lVert x\right\rVert_{p}.

Proof.

If
x=0
the claim holds trivially. Else, let
y_{i}=|x_{i}|/\left\lVert x\right\rVert_{q}\leq 1
.
Then we have

\begin{split}\left\lVert x\right\rVert_{p}^{p}&=\sum_{i=1}^{d}|x_{i}|^{p}=\sum_{i=1}^{d}|y_{i}|^{p}\left\lVert x\right\rVert_{q}^{p}\\
&\geq\sum_{i=1}^{d}|y_{i}|^{q}\left\lVert x\right\rVert_{q}^{p}=\left\lVert x\right\rVert_{q}^{p}\sum_{i=1}^{d}|x_{i}|^{q}/\left\lVert x\right\rVert_{q}^{q}=\left\lVert x\right\rVert_{q}^{p}\end{split}

∎

Lemma 2.0.

For any
p,q\geq 1
and any
x,y\in\mathbb{R}^{d}
, we have

\sum_{i=1}^{d}|x_{i}|^{p}|y_{i}|^{q}\leq\left\lVert x\right\rVert_{2}^{p}\left\lVert y\right\rVert_{2}^{q}.

Proof.

By applying Lemmas
2.1
and
2.2
, we get:

\begin{split}\sum_{i=1}^{d}x_{i}^{p}y_{i}^{q}&\leq\left(\sum_{i=1}^{d}|x_{i}|^{2p}\right)^{1/2}\left(\sum_{i=1}^{d}|y_{i}|^{2q}\right)^{1/2}\\
&\leq\left\lVert x\right\rVert_{2p}^{p}\left\lVert y\right\rVert_{2q}^{q}\leq\left\lVert x\right\rVert_{2}^{p}\left\lVert y\right\rVert_{2}^{q}.\end{split}

∎

2.2.
Johnson-Lindenstrauss (JL) lemma

Let
X=\{x_{1},\ldots x_{n}\}
be a set of
n
vectors in
d>0
dimensions.
For any
\varepsilon>0
, the Johnson-Lindenstrauss lemma
(
JL 84
)
claims that, if
k=\Omega\left(\varepsilon^{-2}\log n\right)
, there exists a linear function
g:\mathbb{R}^{d}\rightarrow\mathbb{R}^{k}
that maintains pairwise distances up to a multiplicative error
\varepsilon
. That is, for any
x,y\in X
,
we have

(1-\varepsilon)\left\lVert x-y\right\rVert^{2}_{2}\leq\left\lVert g(x)-g(y)\right\rVert^{2}_{2}\leq(1+\varepsilon)\left\lVert x-y\right\rVert^{2}_{2}.

Equivalently, the JL lemma claims the existence of a linear map that approximately maintains Euclidean norms.
The JL lemma has been proved to provide tight bounds
(
LN 16
;
LN 17
)
, and has been used for several applications, including differential privacy
(
BBDS 12
)
and clustering
(
MMR 19
)
.
There are several constructions for
g(\cdot)
, for instance, those by Achlioptas
(
Ach 03
)
. Let
g(x)=Ax
for a suitable
k\cdot d
matrix; if
k={\Theta}\left(\varepsilon^{-2}\log n\right)
and each entry of
A
is an independent and even distributed Rademacher random variable
\{-1,1\}
, then
A
satisfies the JL lemma with high probability.
The property holds even if an entry of
A
is 0 with probability 2/3 and in
\{-1,1\}
otherwise.

2.3.
Rademacher chaos

We introduce here some results on Rademacher chaos.
Let
I_{\gamma,n}\subseteq\{1,\ldots n\}^{\gamma}
, and let

I^{\prime}_{\gamma,n}=\{(i_{1},\ldots,i_{\gamma}):i_{j}\in\{1,\ldots n\},i_{j}\neq i_{k}\text{ if }j\neq k\}
be a set of ordered sequences of
\gamma
distinct values from
\{1,\dots,n\}
; when
n
is clear from the context, we drop the subscript
n
.

Let
X_{1},\ldots X_{n}
be
n
independent Rademacher random variables.
Then, a
Rademacher chaos

S
of order
\gamma
is defined as:

S=\sum_{(i_{1},\ldots i_{\gamma})\in I^{\prime}_{\gamma,n}}a_{(i_{1},\ldots i_{\gamma})}X_{i_{1}}\ldots X_{i_{\gamma}}.

The
q
-norm
of the random variable
S
is defined as

\left\lVert S\right\rVert_{q}=\mathbb{E}\left[\displaystyle|S|^{q}\right]^{\nicefrac{{1}}{{q}}}.

We define a function
W
on the set of all Rademacher chaoses as

W(S)=\sqrt{\sum_{i\in I^{\prime}_{\gamma,n}}a_{(i_{1},\dots,i_{\gamma})}^{2}}.

Bonami’s hypercontractive inequality
(
BJ 04
)
provides a bound for
\left\lVert S\right\rVert_{q}
when the sum is taken over sequences
(i_{1},\dots,i_{\gamma})
such that
i_{1}<i_{2}<\dots<i_{\gamma}
, possibly after a renaming of the indexes.

Theorem 2.4 (
(
BJ 04
)
).

Let
S
be a Rademacher chaos of the form

S=\sum_{1\leq i_{1}<\dots<i_{\gamma}\leq n}a_{(i_{1},\ldots i_{\gamma})}X_{i_{1}}\ldots X_{i_{\gamma}}.

Then,
\left\lVert S\right\rVert_{q}\leq(q-1)^{\gamma/2}\left\lVert S\right\rVert_{2}=(q-1)^{\gamma/2}W(S)
.

Note that in general, for Rademacher chaoses with sums over
I^{\prime}_{\gamma,n}
, Bonami’s hypercontractive inequality does not hold.
In Section
3.1
we show how to generalize the result to arbitrary Rademacher chaoses.

2.4.
Orlicz norms and sub-Weibull random variables

We introduce some results on the concentration of sums of independent heavy-tailed distributions.
We recall the definition of Orlicz norms for random variables
(
KC 22
)
.

Definition 2.0.

Let
g:[0,\infty)\rightarrow[0,\infty)
be a non-decreasing function with
g(0)=0
. The
g-Orlicz norm
of a real-valued random variable
X
is

\left\lVert X\right\rVert_{g}:=\inf\left\{\eta>0:\ \mathbb{E}\left[\displaystyle g(|X|/\eta)\right]\leq 1\right\}.

Note that, if
g
is not convex, the function
\left\lVert\cdot\right\rVert_{g}
on the space of real-valued random variables is not a norm. This property though is not needed in the following derivations.

Two well-known spacial cases of
g
are
\psi_{2}=\exp(x^{2})-1
and
\psi_{1}=\exp(x)-1
. When a random variable has finite
\psi_{2}
-Orlicz norm it is called sub-Gaussian and when it has finite
\psi_{1}
-Orlicz norm it is called sub-exponential.
The following definition
(
KC 22
)
generalizes such random variables.

Definition 2.0.

A random variable
X
is said to be sub-Weibull of order
\alpha>0
if

\left\lVert X\right\rVert_{\psi_{\alpha}}<\infty
with
\psi_{\alpha}(x)=\exp(x^{\alpha})-1.

3.
Concentration of sums of Rademacher chaoses

In this section, we provide the forst concentration results for sums of independent Rademacher chaoses.

3.1.
Tail bounds and Orlicz norms of arbitrary Rademacher chaoses

We generalize the bound given by Bonami’s inequality for arbitrary Rademacher chaoses.
Let
G_{\gamma}
be the set of permutations over
\gamma
elements, i.e.
G_{\gamma}=Sym(\{1,\dots,\gamma\})
.
Then,
\forall\sigma\in G_{\gamma}
, let
I^{\sigma}_{\gamma,n}=\{(i_{1},\ldots,i_{\gamma}):i_{j}\in\{1,\ldots n\},i_{\sigma(j)}<i_{\sigma(k)}\text{ if }j<k\}
.
Then we can express

\begin{split}S&=\sum_{(i_{1},\ldots i_{\gamma})\in I^{\prime}_{\gamma,n}}a_{(i_{1},\ldots i_{\gamma})}X_{i_{1}}\ldots X_{i_{\gamma}}=\\
&=\sum_{\sigma\in G_{\gamma}}\sum_{i\in I^{\sigma}_{\gamma,n}}a_{(i_{1},\ldots i_{\gamma})}X_{i_{1}}\ldots X_{i_{\gamma}}=\sum_{\sigma\in G_{\gamma}}S^{\sigma}\end{split}

Intuitively, we can decompose the chaos
S
into a collection of chaoses
S^{\sigma}
: in each
S^{\sigma}
, tuples can be sorted using permutation
\sigma
and then the Bonami’s inequality can be applied.
Indeed, Bonami’s hypercontractive inequality
(
BJ 04
)
implies that,
\forall\sigma\ \forall q\geq 2
,

\left\lVert S^{\sigma}\right\rVert_{q}\leq(q-1)^{\gamma/2}\left\lVert S^{\sigma}\right\rVert_{2}=(q-1)^{\gamma/2}\left(\sum_{(i_{1},\ldots i_{\gamma})\in I^{\sigma}_{\gamma,n}}a^{2}_{(i_{1},\ldots i_{\gamma})}\right)^{\nicefrac{{1}}{{2}}}.

Lemma 3.0.

Let
S=\sum_{\sigma\in G_{\gamma}}S^{\sigma}
be a Rademacher chaos of order
\gamma\geq 2
. Then,

\left\lVert S\right\rVert_{q}\leq(q-1)^{\gamma/2}\sqrt{\gamma!}W(S)

Proof.

Let
\overline{S}^{\sigma}=W(S^{\sigma})^{2}=\left\lVert S^{\sigma}\right\rVert_{2}^{2}\ \forall\sigma
and
\overline{S}=W(S)^{2}=\sum_{\sigma\in G_{\gamma}}\overline{S}^{\sigma}

We have that:

\displaystyle 0

\displaystyle\leq\sum_{\sigma\in G_{\gamma}}\sum_{\rho\in G_{\gamma}}\left(\sqrt{\overline{S}^{\sigma}}-\sqrt{\overline{S}^{\rho}}\right)^{2}=

\displaystyle=\sum_{\sigma\in G_{\gamma}}\sum_{\rho\in G_{\gamma}}\left(\overline{S}^{\sigma}+\overline{S}^{\rho}-2\sqrt{\overline{S}^{\sigma}\overline{S}^{\rho}}\right)=

\displaystyle=2\gamma!\sum_{\sigma\in G_{\gamma}}\overline{S}^{\sigma}-2\sum_{\sigma\in G_{\gamma}}\sum_{\rho\in G_{\gamma}}\sqrt{\overline{S}^{\sigma}\overline{S}^{\rho}}\leq

\displaystyle\leq 2\gamma!\sum_{\sigma\in G_{\gamma}}\overline{S}^{\sigma}-2\left(\sum_{\sigma\in G_{\gamma}}\sqrt{\overline{S}^{\sigma}}\right)^{2}

This implies that
\sqrt{\gamma!\overline{S}}\geq\sum_{\sigma\in G_{\gamma}}\sqrt{\overline{S}^{\sigma}}
and thus
\sqrt{\gamma!}W(S)\geq\sum_{\sigma\in G_{\gamma}}\left\lVert S^{\sigma}\right\rVert_{2}
.
Then we can use the triangular inequality and Bonami’s hypercontractive inequalities to prove the lemma:

\begin{split}\left\lVert S\right\rVert_{q}&=\left\lVert\sum_{\sigma\in G_{\gamma}}S^{\sigma}\right\rVert_{q}\leq\sum_{\sigma\in G_{\gamma}}\left\lVert S^{\sigma}\right\rVert_{q}\leq(q-1)^{\gamma/2}\sum_{\sigma\in G_{\gamma}}\left\lVert S^{\sigma}\right\rVert_{2}\\
&\leq(q-1)^{\gamma/2}\sqrt{\gamma!}W(S)\end{split}

∎

Lemma 3.0.

Let
S
be a Rademacher chaos of order
\gamma\geq 2
. Then for any
\gamma^{\prime}\geq\gamma
and

\textnormal{Pr}\left[\displaystyle|S|>t\right]\leq e^{2}\exp\left(-(e\sqrt{\gamma!}W(S))^{-\nicefrac{{2}}{{\gamma^{\prime}}}}t^{\nicefrac{{2}}{{\gamma^{\prime}}}}\right).

Proof.

When

e^{2}\exp\left(-(e\sqrt{\gamma!}W(S))^{-\nicefrac{{2}}{{\gamma^{\prime}}}}t^{\nicefrac{{2}}{{\gamma^{\prime}}}}\right)\geq 1

Assume now that

.
We apply Markov’s inequality and lemma

, obtaining

\begin{split}\textnormal{Pr}\left[\displaystyle|S|>t\right]&\leq\mathbb{E}\left[\displaystyle|S|^{q}\right]t^{-q}=\left\lVert S\right\rVert_{q}^{q}t^{-q}\leq\left(\frac{q^{\nicefrac{{\gamma}}{{2}}}\sqrt{\gamma!}W(S)}{t}\right)^{q}\\
&\leq\left(\frac{q^{\nicefrac{{\gamma^{\prime}}}{{2}}}\sqrt{\gamma!}W(S)}{t}\right)^{q},\quad\forall q\geq 2.\end{split}

Then, by setting

from which the Lemma follows.
∎

Lemma 3.0.

Let
S
be a Rademacher chaos of order
\gamma\geq 2
. Let
\alpha\leq 2/\gamma
and
\psi_{\alpha}=\exp(x^{\alpha})-1
.
Then

\left\lVert S\right\rVert_{\psi_{\alpha}}\leq e(e^{2}+1)^{\nicefrac{{1}}{{\alpha}}}\sqrt{\gamma!}W(S).

Proof.

From the definition of Orlicz norm we have
\left\lVert S\right\rVert_{\psi_{\alpha}}=\inf\left\{\eta>0:\ \mathbb{E}\left[\displaystyle\psi_{\alpha}(|S|/\eta)\right]\leq 1\right\}.

Then, applying Lemma
3.2
with
\gamma^{\prime}=2/\alpha\geq\gamma

\begin{split}\mathbb{E}\left[\displaystyle\psi(|S|/\eta)\right]&=\int_{0}^{\infty}\textnormal{Pr}\left[\displaystyle\psi(|S|/\eta)>x\right]dx\\
&=\int_{0}^{\infty}\textnormal{Pr}\left[\displaystyle|S|>\eta(\ln(x+1)^{\nicefrac{{1}}{{\alpha}}})\right]dx\\
&\leq e^{2}\int_{0}^{\infty}\exp\left(-\left(\frac{1}{e\sqrt{\gamma!}W(S)}\right)^{\alpha}\eta^{\alpha}\ln(x+1)\right)dx\\
&=e^{2}\int_{0}^{\infty}(x+1)^{-\left(\frac{\eta}{e\sqrt{\gamma!}W(S)}\right)^{\alpha}}dx\\
&=\frac{e^{2}}{\left(\frac{\eta}{e\sqrt{\gamma!}W(S)}\right)^{\alpha}-1}.\end{split}

Then, if

Therefore,
\left\lVert S\right\rVert_{\psi_{\alpha}}\leq e(e^{2}+1)^{\nicefrac{{1}}{{\alpha}}}\sqrt{\gamma!}W(S)
.
∎

In this section we analyze the properties of the dimensionality reduction onto the complex vector space described in the introduction.
We recall that

Results in expectation

&\hskip 9.24994pt+8w_{j_{1}}^{3}x_{j_{1}}w_{j_{2}}x_{j_{2}}x_{j_{3}}^{2}+8w_{j_{1}}x_{j_{1}}^{3}w_{j_{2}}^{2}w_{j_{3}}x_{j_{3}}+2w_{j_{1}}^{2}x_{j_{1}}^{2}w_{j_{2}}x_{j_{2}}x_{j_{3}}w_{j_{3}}\\
&\leq 36\left\lVert w\right\rVert_{2}^{4}\left\lVert x\right\rVert_{2}^{4}.\end{split}

The final inequality follows since each term of the summation can upper bounded by the product of three sums to which we can apply Lemma
2.3
. For instance,

\small\begin{split}\sum_{(j_{1},j_{2},j_{3})\in I^{\prime}_{3,d}}&8w_{j_{1}}^{3}x_{j_{1}}w_{j_{2}}x_{j_{2}}x_{j_{3}}^{2}\leq 8\sum_{(j_{1},j_{2},j_{3})\in I_{3,d}}|w_{j_{1}}^{3}x_{j_{1}}w_{j_{2}}x_{j_{2}}x_{j_{3}}^{2}|\\
&\leq 8\left(\sum_{j_{1}\in I_{1,d}}|w_{j_{1}}|^{3}|x_{j_{1}}|\right)\left(\sum_{j_{2}\in I_{1,d}}|w_{j_{2}}||x_{j_{2}}|\right)\left(\sum_{j_{3}\in I_{1,d}}|x_{j_{3}}|^{2}\right)\\
&\leq\left\lVert w\right\rVert_{2}^{3}\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{2}\left\lVert x\right\rVert_{2}\left\lVert x\right\rVert_{2}^{2}.\end{split}

We can then apply Theorem
1.2
with
\gamma=4
, from which follows that

\begin{split}&\textnormal{Pr}\left[\displaystyle|H_{2,1}|>6\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq\textnormal{Pr}\left[\displaystyle|H_{2,1}|>W(H_{2,1,i})F(t)\right]\\
&\quad\leq 2e^{-t}.\end{split}

Since a similar bound holds for
H_{2,2}
, and since

, an union bound gives

\begin{split}&\textnormal{Pr}\left[\displaystyle|H_{2}|>6\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\\
&\quad=\textnormal{Pr}\left[\displaystyle|H_{2,1}+H_{2,2}|>12\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\\
&\quad\leq 2\textnormal{Pr}\left[\displaystyle|H_{2,1}|>6\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq 4e^{-t}\end{split}

∎

Lemma 4.0.

We have that
\textnormal{Pr}\left[\displaystyle|H_{3}|>2\sqrt{2}\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq 2e^{-t}
.

Proof.

By setting
\tau_{j_{1},j_{2}}=w_{j_{1}}^{2}x_{j_{1}}x_{j_{2}}+x_{j_{1}}^{2}w_{j_{1}}w_{j_{2}}
, we rewrite
H_{3}
as

\begin{split}H_{3}&=2\sum_{i=1}^{k}\sum_{(j_{1},j_{2})\in I^{\prime}_{2,d}}\textnormal{Re}\left(\displaystyle A_{i,j_{1}}^{3}A_{i,j_{2}}\right)\tau_{j_{1},j_{2}}\\

\end{split}

where

Let

\hat{\tau}_{j_{1},j_{2}}=\begin{cases}\tau_{j_{1},j_{2}}&\text{if }j_{1}\leq d,j_{2}\leq d\\

Then, we can rewrite
H_{3}

\begin{split}W(H_{3,i})^{2}&=2\sum_{(j_{1},j_{2})\in I^{\prime}_{2,d}}\left(w_{j_{1}}^{2}x_{j_{1}}x_{j_{2}}+x_{j_{1}}^{2}w_{j_{1}}w_{j_{2}}\right)^{2}\\

&\leq 8\left\lVert w\right\rVert_{2}^{4}\left\lVert x\right\rVert_{2}^{4},\end{split}

Since

is a sum of independent Rademacher chaoses of order
2\leq 4
, from Theorem
1.2

\begin{split}&\textnormal{Pr}\left[\displaystyle|H_{3}|>2\sqrt{2}\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq\textnormal{Pr}\left[\displaystyle|H_{3}|>W(H_{3,i})F(t)\right]\\
&\quad\leq 2e^{-t},\end{split}

and the claim follows.
∎

Lemma 4.0.

We have that
\textnormal{Pr}\left[\displaystyle|H_{4}|>3\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq 2e^{-t}

Proof.

\begin{split}W&(H_{4,i})^{2}=\sum_{(j_{1},j_{2})\in I^{\prime}_{2,d}}\left(w_{j_{1}}^{2}x_{j_{2}}^{2}+2w_{j_{1}}x_{j_{1}}w_{j_{2}}x_{j_{2}}\right)^{2}\\

\begin{split}&\textnormal{Pr}\left[\displaystyle|H_{4}|>3\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq\textnormal{Pr}\left[\displaystyle|H_{4}|>W(H_{4,i})F(t)\right]\\

∎

Lastly, we bound

Lemma 4.0.

We have that
\textnormal{Pr}\left[\displaystyle|H_{1}|>2\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq 16e^{-t}

Lemma 4.0.

We have that
\textnormal{Pr}\left[\displaystyle|H|>24\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]\leq 24e^{-t}
.

Proof.

\small\begin{split}&\textnormal{Pr}\left[\displaystyle|H|>24\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}F(t)\right]=\textnormal{Pr}\left[\displaystyle|H|>24u\right]\leq\\
&\leq\textnormal{Pr}\left[\displaystyle|H_{1}|>6u\right]+\textnormal{Pr}\left[\displaystyle|H_{2}|>6u\right]+\textnormal{Pr}\left[\displaystyle|H_{3}|>6u\right]+\textnormal{Pr}\left[\displaystyle|H_{4}|>6u\right]\\
&\leq\textnormal{Pr}\left[\displaystyle|H_{1}|>2u\right]+\textnormal{Pr}\left[\displaystyle|H_{2}|>6u\right]+\textnormal{Pr}\left[\displaystyle|H_{3}|>2\sqrt{2}u\right]+\textnormal{Pr}\left[\displaystyle|H_{4}|>3u\right]\\

∎

Lemma 4.0.

For any given
x,w\in\mathbb{R}^{d}
,

\small\begin{split}&\textnormal{Pr}\left[\displaystyle|\rho(g(x),w)-\left\lVert x\right\rVert_{w}^{2}|>t\right]\ \leq\\
&\hskip 9.24994pt\leq\begin{cases}24\exp\left(-k\frac{1}{\left(c_{1}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}\right)^{2}}t^{2}\right)&\text{if }t<c_{1}^{\nicefrac{{4}}{{3}}}c_{2}^{-\nicefrac{{1}}{{3}}}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}k^{-\nicefrac{{1}}{{3}}}\\
24\exp\left(-\sqrt{k}\frac{1}{\sqrt{c_{2}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}}}\sqrt{t}\right)&\text{otherwise}\end{cases}\end{split}

Proof.

We have

k\rho(g(x),w)-\ k\left\lVert x\right\rVert_{w}^{2}=H_{1}+H_{2}+H_{3}+H_{4}=H,

which in turn implies that

\textnormal{Pr}\left[\displaystyle|\rho(g(x),w)-\left\lVert x\right\rVert_{w}^{2}|>t\right]=\textnormal{Pr}\left[\displaystyle|H|>kt\right]=\textnormal{Pr}\left[\displaystyle|H|>u\right].

From Lemma
4.6
, we have that

\textnormal{Pr}\left[\displaystyle|H|>24\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}\left(c_{1}\sqrt{k}\sqrt{v}+c_{2}v^{2}\right)\right]\leq 24e^{-v}.

Then, for
v<(c_{1}/c_{2})^{\nicefrac{{2}}{{3}}}k^{\nicefrac{{1}}{{3}}}
, we have that
2c_{1}\sqrt{k}\sqrt{v}\geq c_{1}\sqrt{k}\sqrt{v}+c_{2}v^{2}
and therefore
\textnormal{Pr}\left[\displaystyle|H|>48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}c_{1}\sqrt{k}\sqrt{v}\right]\leq 24e^{-v}
.
Similarly, for
v\geq(c_{1}/c_{2})^{\nicefrac{{2}}{{3}}}k^{\nicefrac{{1}}{{3}}}
, we have that
\textnormal{Pr}\left[\displaystyle|H|>48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}c_{2}v^{2}\right]\leq 24e^{-v}
.

Then, setting
u=48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}c_{1}\sqrt{k}\sqrt{v}
for the first bound and
u=48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}c_{2}v^{2}
for the second one yields

\small\begin{split}&\textnormal{Pr}\left[\displaystyle|H|>u\right]\ \leq\\
&\hskip 9.24994pt\leq\begin{cases}24\exp\left(-\frac{1}{\left(c_{1}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}\right)^{2}}\frac{u^{2}}{k}\right)&\text{if }u<c_{1}^{\nicefrac{{4}}{{3}}}c_{2}^{-\nicefrac{{1}}{{3}}}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}k^{\nicefrac{{2}}{{3}}}\\
24\exp\left(-\frac{1}{\sqrt{c_{2}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}}}\sqrt{u}\right)&\text{otherwise}.\end{cases}\end{split}

Finally, making the substitution
u=kt
, we obtain the claim.
∎

Since matrix
A
should have a size that does not depend on a specific input vector, we state the main theorem as a function of a parameter
\Delta
which represents the maximum tolerated distortion: if the actual distortion
\Delta(x,w)
is not larger than
\Delta
, we get a multiplicative error
\varepsilon
; otherwise, we get an additive error
\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}
.
We now then prove our main result, Theorem
1.1
, which we restate for completeness.

Theorem
1.1
0.

Let
\varepsilon,\delta>0
. Let
c
be a suitable universal constant. Let also

k=c\max\left\{\frac{\Delta^{4}\ln(24/\delta)}{\varepsilon^{2}},\ \frac{\Delta^{2}\ln(24/\delta)^{2}}{\varepsilon}\right\}.

Then, for any given
x,w\in\mathbb{R}^{d}
we have, with probability at least
1-\delta
,

\left\lVert x\right\rVert_{w}^{2}-\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}<\rho(g(x),w)<\left\lVert x\right\rVert_{w}^{2}+\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}.

In particular, if
\Delta\geq\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{2}/\left\lVert x\right\rVert_{w}
, we get, with probability at least
1-\delta
,

(1-\varepsilon)\left\lVert x\right\rVert_{w}^{2}<\rho(g(x),w)<(1+\varepsilon)\left\lVert x\right\rVert_{w}^{2}.

Proof.

Let
\varepsilon\ln(24/\delta)\Delta^{-2}<c_{1}^{2}c_{2}^{-1}48
. Then let
k=c_{1}^{2}48^{2}\Delta^{4}\varepsilon^{-2}\ln(24/\delta)
.
In this case,

t:=\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}\ <c_{1}^{\nicefrac{{4}}{{3}}}c_{2}^{-\nicefrac{{1}}{{3}}}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}k^{-\nicefrac{{1}}{{3}}},

and we are in the Gaussian tail case of the bound described by Lemma
4.7
.
Then we have

\small\begin{split}&\textnormal{Pr}\left[\displaystyle|\rho(g(x),w)-\left\lVert x\right\rVert_{w}^{2}|>t\right]\leq 24\exp\left(-k\frac{\left(\varepsilon\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}\Delta^{-2}\right)^{2}}{\left(c_{1}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}\right)^{2}}\right)\\
&\hskip 18.49988pt\hskip 18.49988pt=24\exp\left(c_{1}^{2}48^{2}\Delta^{4}\varepsilon^{-2}\ln(\frac{24}{\delta})\frac{\varepsilon^{2}}{c_{1}^{2}48^{2}\Delta^{4}}\right)=\delta.\end{split}

Let instead
\varepsilon\ln(24/\delta)\Delta^{-2}\geq c_{1}^{2}c_{2}^{-1}48
. Then let
k=c_{2}48\frac{\Delta^{2}\ln(24/\delta)^{2}}{\varepsilon}
.
In this case,

t:=\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}\ \geq c_{1}^{\nicefrac{{4}}{{3}}}c_{2}^{-\nicefrac{{1}}{{3}}}48\left\lVert w\right\rVert_{2}^{2}\left\lVert x\right\rVert_{2}^{2}k^{-\nicefrac{{1}}{{3}}},

and we are in the long tail part of the bound described by Lemma
4.7
.
Then,
\textnormal{Pr}\left[\displaystyle|\rho(g(x),w)-\left\lVert x\right\rVert_{w}^{2}|>t\right]\leq\delta
.
Taking
k=\max\left\{c_{1}^{2}48^{2},c_{2}48\right\}\cdot\max\left\{\frac{\Delta^{4}\ln(24/\delta)}{\varepsilon^{2}},\frac{\Delta^{2}\ln(24/\delta)^{2}}{\varepsilon}\right\}\geq\max\left\{c_{1}^{2}48^{2}\frac{\Delta^{4}\ln(24/\delta)}{\varepsilon^{2}},\ c_{2}48\frac{\Delta^{2}\ln(24/\delta)^{2}}{\varepsilon}\right\}
completes the proof.
∎

Finally, we restate the above theorem to prove that the proposed reduction maintains pairwise distances in a set
S
of
n
vectors and for a set of weights
W
with a bounded relative error.
We remark that
\rho(g(x-y),w)
can be computed from the reduced vector

\begin{split}\rho(g(x-y),w)&=\rho(g(x)-g(y),w)\\

Corollary 4.0.

Let
S=(x_{1},\dots,x_{n})
,
x_{i}\in\mathbb{R}^{d}
be a dataset of
n

be the set of the weights of interest, with

Finally, we carried out some proof-of-concept experiments, which are reported in the Appendix, to
validate our theoretical contributions.
The experiments indeed show that the weighted squared norms estimates are centered around the true weighted squared norms, and that the concentration around the mean increases with

. Moreover, they show that the estimation quality degrades as the distortion

5.
Streaming estimation of weighted norms

In the streaming model of computation, data is generated continuously and has to be processed on-the-fly while maintaining in memory only a sublinear portion of it.
We focus on the following problem. A vector
x=(x_{1},\dots,x_{d})^{\intercal}\in\mathbb{R}^{d}
is provided to the machine via a stream one dimension at a time (e.g. at timestep 1
x_{1}
is provided, at timestep 2
x_{2}
, and so on) and the goal is to compute
\left\lVert x\right\rVert^{2}_{w}
while using
o(d)
memory. If
w
is provided in the stream simultaneously to
x
then it is easy to compute the weighted norm just by updating the estimate as
\left\lVert x\right\rVert^{2}_{w}\leftarrow\left\lVert x\right\rVert^{2}_{w}+x^{2}_{i}w^{2}_{i}
for each timestep
i
.
We now detail a streaming algorithm for computing weighted norms when the weight vector is provided separately, or for when one wants to compute the norm for a vector
x
with respect to multiple weights
w
.
Our algorithm is inspired by the AMS sketch
(
AMS 96
)
and exploits the same ideas that we developed in the previous sections.

We maintain an array of
r\times m
counters
C[i,j]
, as well as
r\times m
independent hash functions
h_{ij}:\mathbb{N}^{+}\longrightarrow\{1,-1,i,-i\}
that map timesteps to
\pm 1
and
\pm i
. These hash functions shall each produce 8-independent uniform random variables over
\{1,-1,i,-i\}
, which can be achieved using k-independent hashing
(
WC 81
)
using a degree-7 polynomial, whose coefficients can be stored with
{O}\left(1\right)
memory.
Note that the linear transformation described in Section
4
required storing in memory the entire matrix
A
, which takes
{O}\left(kd\right)
bits.
Upon the arrival of a value
x_{t}
at timestep
t
we update, for each
i
and
j
, the counter as
C_{x}[i,j]+=x_{t}h_{ij}(t)
. At the end of the stream, the array
C_{x}
is the compressed representation of
x
.
We do the same for the weight
w
using the same family of hash functions, and we obtain the array
C_{w}
.
Let
\hat{x}^{(ij)}=C_{x}[i,j]^{2}C_{w}[i,j]^{2}
. We then define
\hat{x}^{(i)}=\frac{1}{m}\sum_{j=1}^{m}\hat{x}^{(ij)}
and
\tilde{x}^{(i)}=\textnormal{Re}\left(\displaystyle\hat{x}^{(i)}\right)
. Finally, our estimate for the squared weighted norm is
\rho_{\rm s}(x,w)
, defined as the median of the
r
values of the
\tilde{x}^{(i)}
’s.
While in the dimensionality reduction technique described in Section
4
, exponential tail bounds are obtained by the average of
{O}\left(\varepsilon^{-2}\log(1/\delta)\right)
independent estimates, the weaker k-independence, which is necessary to avoid using
{O}\left(kd\right)
memory to store the matrix
A
, is not enough to get exponential tail bounds just by averaging. We show that by first averaging and then taking the median is enough to get the desired exponential tail bounds.
First of all, we establish the expected value of the
\tilde{x}^{(i)}
’s.

Lemma 5.0.

We have that
\mathbb{E}\left[\displaystyle\tilde{x}^{(i)}\right]=\left\lVert x\right\rVert^{2}_{w}
, for
i=1,\dots,r
.

Proof.

By definition of
\hat{x}^{(ij)}
, we get

\begin{split}\mathbb{E}\left[\displaystyle\hat{x}^{(ij)}\right]&=\mathbb{E}\left[\displaystyle\left(\sum_{t=1}^{d}x_{t}h_{ij}(t)\right)^{2}\left(\sum_{t=1}^{d}w_{t}h_{ij}(t)\right)^{2}\right]\\
&=\sum_{t_{1},t_{2},t_{3},t_{4}}x_{t_{1}}x_{t_{2}}w_{t_{3}}w_{t_{4}}\mathbb{E}\left[\displaystyle h_{ij}(t_{1})h_{ij}(t_{2})h_{ij}(t_{3})h_{ij}(t_{4})\right]\end{split}

Since the
h_{ij}(t)
’s are 4-independent, we have
\mathbb{E}\left[\displaystyle\hat{x}^{(ij)}\right]=\sum_{t=1}^{d}x_{t}^{2}w_{t}^{2}
.
Then, taking the average of the
\hat{x}^{(ij)}
’s and the real part preserves the expected value.
∎

The following lemma bounds the variance of
\hat{x}^{(i)}
by using the 8-independence of the random variables.

Lemma 5.0.

We have that
\textnormal{Var}\left[\hat{x}^{(i)}\right]\leq\frac{34}{m}\left\lVert x\right\rVert^{4}\left\lVert w\right\rVert^{4}
.

Proof.

Recall that the variance of a complex-valued random variable is a real number defined as
\textnormal{Var}\left[Z\right]=\mathbb{E}\left[\displaystyle|Z-\mathbb{E}\left[\displaystyle Z\right]|^{2}\right]=\mathbb{E}\left[\displaystyle|Z|^{2}\right]-|\mathbb{E}\left[\displaystyle Z\right]|^{2}=\mathbb{E}\left[\displaystyle|Z^{2}|\right]-|\mathbb{E}\left[\displaystyle Z\right]|^{2}
.

We have that

\begin{split}\mathbb{E}\left[\displaystyle\hat{x}^{(ij)\ 2}\right]&=\mathbb{E}\left[\displaystyle\left(\sum_{t=1}^{d}x_{t}h(t)\right)^{4}\left(\sum_{t=1}^{d}w_{t}h(t)\right)^{4}\right]\\
&=\sum_{t_{1},\dots,t_{8}}x_{t_{1}}\dots w_{t_{8}}\mathbb{E}\left[\displaystyle h(t_{1})\dots h(t_{8})\right].\end{split}

By 8-independence of the hash function, and recalling that
\mathbb{E}\left[\displaystyle h(t)\right]=\mathbb{E}\left[\displaystyle h(t)^{2}\right]=\mathbb{E}\left[\displaystyle h(t)^{3}\right]=0
, while
\mathbb{E}\left[\displaystyle h(t)^{4}\right]=1
, we have that the only terms of the above sum that are not 0 are the terms with 8 equal indexes and the ones with 2 distinct quadruplets of equal indices. In the former case, for each index
t\in\{1,\dots,d\}
, we have a single contribution to the sum. In the latter case, for each pair of distinct indexes, we have five possible configurations.
The configuration
x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}
appears
\left(\frac{4!}{2!2!}\right)^{2}=36
times,
the configurations
x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}
and
x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}}
appear
\left(\frac{4!}{3!1!}\right)^{2}=16
times each and the configurations
x^{4}_{t_{1}}w^{4}_{t_{2}}
and
x^{4}_{t_{2}}w^{4}_{t_{1}}
appear
\left(\frac{4!}{4!0!}\right)^{2}=1
time each.

We then get

\begin{split}\mathbb{E}\left[\displaystyle\hat{x}^{(ij)\ 2}\right]=&\sum_{t=1}^{d}x_{t}^{4}w_{t}^{4}+36\sum_{1\leq t_{1}<t_{2}\leq d}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}\\
&+16\sum_{1\leq t_{1}<t_{2}\leq d}(x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}+x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}})\\
&+\sum_{1\leq t_{1}<t_{2}\leq d}(x^{4}_{t_{1}}w^{4}_{t_{2}}+x^{4}_{t_{2}}w^{4}_{t_{1}}).\end{split}

Then, we have

\small\begin{split}\textnormal{Var}[&\hat{x}^{(ij)}]=\mathbb{E}\left[\displaystyle\hat{x}^{(ij)\ 2}\right]-\mathbb{E}\left[\displaystyle\hat{x}^{(ij)}\right]^{2}=\\
&=\sum_{t=1}^{d}x_{t}^{4}w_{t}^{4}+36\sum_{1\leq t_{1}<t_{2}\leq d}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}\\
&+16\sum_{1\leq t_{1}<t_{2}\leq d}(x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}+x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}})\\
&+\sum_{1\leq t_{1}<t_{2}\leq d}(x^{4}_{t_{1}}w^{4}_{t_{2}}+x^{4}_{t_{2}}w^{4}_{t_{1}})-\left(\sum_{t=1}^{d}x_{t}^{2}w_{t}^{2}\right)^{2}=\\
&=\sum_{t=1}^{d}x_{t}^{4}w_{t}^{4}+36\sum_{t_{1}<t_{2}}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}\\
&+16\sum_{t_{1}<t_{2}}(x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}+x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}})\\
&+\sum_{t_{1}<t_{2}}(x^{4}_{t_{1}}w^{4}_{t_{2}}+x^{4}_{t_{2}}w^{4}_{t_{1}})-\sum_{t=1}^{d}x_{t}^{4}w_{t}^{4}-2\sum_{t_{1}<t_{2}}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}=\\
&=34\sum_{t_{1}<t_{2}}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}+16\sum_{t_{1}<t_{2}}(x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}+x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}})\\
&+\sum_{t_{1}<t_{2}}(x^{4}_{t_{1}}w^{4}_{t_{2}}+x^{4}_{t_{2}}w^{4}_{t_{1}}).\end{split}

We bound each of the three terms individually, using a combination of Lemma
2.1
and Lemma
2.2
:

\small\begin{split}2\sum_{1\leq t_{1}<t_{2}\leq d}x^{2}_{t_{1}}w^{2}_{t_{1}}x^{2}_{t_{2}}w^{2}_{t_{2}}&\leq\left(\sum_{t}x^{2}_{t}w^{2}_{t}\right)^{2}\leq\left(\sum_{t}x_{t}^{4}\right)\left(\sum_{t}w^{4}_{t}\right)\\
&=\left\lVert x\right\rVert_{4}^{4}\left\lVert w\right\rVert_{4}^{4}\leq\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}\end{split}

\small\begin{split}\sum_{1\leq t_{1}<t_{2}\leq d}&(x^{3}_{t_{1}}w_{t_{1}}x_{t_{2}}w^{3}_{t_{2}}+x_{t_{1}}w^{3}_{t_{1}}x^{3}_{t_{2}}w_{t_{2}})\leq\left(\sum_{t}x^{3}_{t}w_{t}\right)\left(\sum_{t}x_{t}w^{3}_{t}\right)\\
&\leq\left(\sum_{t}x_{t}^{6}\right)^{1/2}\left(\sum_{t}w^{2}_{t}\right)^{1/2}\left(\sum_{t}x_{t}\right)^{1/2}\left(\sum_{t}w^{6}_{t}\right)^{1/2}\\
&=\left\lVert x\right\rVert_{6}^{3}\left\lVert w\right\rVert_{2}\left\lVert x\right\rVert_{2}\left\lVert w\right\rVert_{6}^{3}\leq\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}\end{split}

\small\begin{split}\sum_{1\leq t_{1}<t_{2}\leq d}(x^{4}_{t_{1}}w^{4}_{t_{2}}+x^{4}_{t_{2}}w^{4}_{t_{1}})&\leq\left(\sum_{t}x_{t}^{4}\right)\left(\sum_{t}w^{4}_{t}\right)=\left\lVert x\right\rVert_{4}^{4}\left\lVert w\right\rVert_{4}^{4}\\
&\leq\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}.\end{split}

Then we have that

\textnormal{Var}[\hat{x}^{(ij)}]\leq 17\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}+16\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}+\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}.

Since the
\hat{x}^{(ij)}
,
j=1,\dots,m
are all independent, we have that

\textnormal{Var}[\hat{x}^{(i)}]=\frac{1}{m^{2}}\sum_{j=1}^{m}\textnormal{Var}[\hat{x}^{(ij)}]\leq\frac{34}{m}\left\lVert x\right\rVert^{4}_{w}.

∎

Using the two lemmas above we can prove Theorem
1.3
, which we restate for completeness.

Theorem
1.3
0.

There exists a sketch
\rho_{\rm s}(x,w)
that uses
{O}\left(\varepsilon^{-2}\Delta^{4}\log(1/\delta)\right)
space such that,
for any
x,w\in\mathbb{R}^{d}
and for any
\varepsilon,\delta>0
, we have that

\left\lVert x\right\rVert^{2}_{w}-\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}<\rho_{\rm s}(x,w)<\left\lVert x\right\rVert^{2}_{w}+\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}

with probability at least
1-\delta
. In particular, if
\Delta\geq\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}/\left\lVert x\right\rVert^{2}_{w}
, we get:

(1-\varepsilon)\left\lVert x\right\rVert^{2}_{w}<\rho_{\rm s}(x,w)<(1+\varepsilon)\left\lVert x\right\rVert^{2}_{w}

with probability at least
1-\delta
.

Proof.

Let
\rho_{\rm s}(x,w)
be the sketch described above, choosing
m>\frac{136}{\varepsilon^{2}}\Delta^{4}
and
r>12\ln(1/\delta)
. The space complexity holds trivially. We now show the concentration result.

We first show that Chebychev’s inequality holds for complex random variables. Indeed, let
Z
be a complex random variable and
\textnormal{Var}[Z]
its variance. Let also
U=|Z-\mathbb{E}\left[\displaystyle Z\right]|^{2}
. Then
U
is a real-valued random variable. Then we have

\textnormal{Pr}\left[\displaystyle|Z-\mathbb{E}\left[\displaystyle Z\right]|>a\right]=\textnormal{Pr}\left[\displaystyle U>a^{2}\right]\leq\frac{\mathbb{E}\left[\displaystyle U\right]}{a^{2}}=\frac{\textnormal{Var}[Z]}{a^{2}}.

By Chebychev’s inequality, we then have that

\begin{split}&\textnormal{Pr}\left[\displaystyle\left|\hat{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right|>\varepsilon\frac{\left\lVert x\right\rVert_{2}^{2}\left\lVert w\right\rVert_{2}^{2}}{\Delta^{2}}\right]\leq\frac{\textnormal{Var}[\hat{x}^{(i)}]}{\varepsilon^{2}\frac{\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}}{\Delta^{4}}}\leq\\
&\qquad\qquad\leq\frac{\frac{34}{m}\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}\Delta^{4}}{\varepsilon^{2}\left\lVert x\right\rVert_{2}^{4}\left\lVert w\right\rVert_{2}^{4}}\leq\frac{34}{\varepsilon^{2}m}\Delta^{4}\leq\frac{1}{4}.\end{split}

Recalling that

\begin{split}\left|\hat{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right|^{2}&=\left(\textnormal{Re}\left(\displaystyle\hat{x}^{(i)}\right)-\left\lVert x\right\rVert_{w}^{2}\right)^{2}+\textnormal{Im}\left(\displaystyle\hat{x}^{(i)}\right)^{2}\\
&\!\!\!=\left(\tilde{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right)^{2}+\textnormal{Im}\left(\displaystyle\hat{x}^{(i)}\right)^{2}\geq\left(\tilde{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right)^{2},\end{split}

we have that

\textnormal{Pr}\left[\displaystyle\left|\tilde{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right|>\varepsilon\left\lVert x\right\rVert_{w}^{2}\right]\leq\frac{1}{4}.

For each
i=1,\dots,r
, let then
X_{i}
be
1
if the event
\left|\tilde{x}^{(i)}-\left\lVert x\right\rVert_{w}^{2}\right|\leq\varepsilon\left\lVert x\right\rVert_{w}^{2}
happens and
0
otherwise.
By letting
\rho_{\rm s}(x,w)
be the median of the
\tilde{x}^{(i)}
’s, we have that if
\sum_{i=1}^{r}X_{i}>r/2
, then the event
\left|\rho_{\rm s}(x,x)-\left\lVert x\right\rVert_{w}^{2}\right|\leq\varepsilon\left\lVert x\right\rVert_{w}^{2}
is true.
We can bound such a probability using Chernoff’s bound:

\begin{split}\textnormal{Pr}\left[\displaystyle\sum_{i=1}^{r}X_{i}>r/2\right]&=\textnormal{Pr}\left[\displaystyle\sum_{i=1}^{r}X_{i}>2\cdot\mathbb{E}\left[\displaystyle\sum_{i=1}^{r}X_{i}\right]\right]\\
&\leq\exp\left(-\frac{r}{12}\right)<\delta.\end{split}

∎

We remark that the dimensionality reduction described in this section uses only
{O}\left(\varepsilon^{-2}\log(1/\delta)\right)
memory.
On the other hand, this transformation is not linear in
x
, and hence it would not maintain pairwise distances between vectors, while the one described in Section
4
is.

6.
Conclusion

In this paper we provided the first dimensionality reduction techniques that are able to cope with dynamically-weighted Euclidean distances.
First, we introduced a JL-type linear transformation that maps vectors to a lower-dimensional complex vector space. The estimated weighted norms obtained from the compressed vectors are an
\varepsilon
-approximation for the true weighted norms with high probability.
Moreover, the AMS-like sketch provides an alternative dimensionality reduction approach that allows for a significantly lower memory footprint, at the cost of giving up linearity.
As mentioned in the introduction, a limitation of our approach is that a large distortion threshold
\Delta
incurs a dimensionality expansion (i.e.,
k>d
): we conjecture that better bounds can be achieved by keeping the linear map
g(\cdot)
but redefining the
\rho(\cdot,\cdot)
function, possibly by relaxing the linear dependency on the weight vector.
Another interesting open question is to provide a fast method for dimensionality reductions in the complex vector space similar to the Fast JL transform
(
AC 09
)
.
Finally, we believe that our constructions can be of interest for privacy preserving similarity search: suppose that an user wants to search similar vectors using its own weights; the low dimension vectors represent a noisy variant of the original vectors that can be shared with this user, but without revealing the original vectors.
