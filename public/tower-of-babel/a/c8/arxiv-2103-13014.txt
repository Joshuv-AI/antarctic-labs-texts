Enhanced Robust Adaptive Beamforming Designs for General-Rank Signal Model via an Induced Norm of Matrix Errors
Yongwei Huang, Senior Member, IEEE, and Sergiy A. Vorobyov Fellow, IEEE

Abstract
The robust adaptive beamforming (RAB) problem for general-rank signal model with an uncertainty set defined through a matrix induced norm is considered. The worst-case signal-to-interference-plus-noise ratio (SINR) maximization RAB problem is formulated by decomposing the presumed covariance of the desired signal into a product between a matrix and its Hermitian, and putting an error term into the matrix and its Hermitian. In the literature, the norm of the matrix errors often is the Frobenius norm in the maximization problem. Herein, the closed-form optimal value for a minimization problem of the least-squares residual over the matrix errors with an induced l p , q l_{p,q} -norm constraint is first derived. Then, the worst-case SINR maximization problem is reformulated into the maximization of the difference between an l 2 l_{2} -norm function and a l q l_{q} -norm function, subject to a convex quadratic constraint. It is shown that for any q q in the set of rational numbers greater than or equal to one, the maximization problem can be approximated by a sequence of second-order cone programming (SOCP) problems, with the ascent optimal values. The resultant beamvector for some q q in the set, corresponding to the maximal actual array output SINR, is treated as the best candidate such that the RAB design is improved the most. In addition, a generalized RAB problem of maximizing the difference between an l p l_{p} -norm function and an l q l_{q} -norm function subject to the convex quadratic constraint is studied, and the actual array output SINR is further enhanced by properly selecting p p and q q . Simulation examples are presented to demonstrate the improved performance of the robust beamformers for certain matrix induced l p , q l_{p,q} -norms, in terms of the actual array output SINR and the CPU-time for the sequential SOCP approximation algorithm.



I
Introduction

Robust adaptive beamforming (RAB) consists of applying an optimized weight vector (beamvector) to dramatically reduce the sensitivity to any sort of parameter uncertainties and to significantly improve the array output performance. Particularly, the parameters’ uncertainty in a RAB design problem can be caused, e.g., by any imperfect knowledge about the source, propagation and sensor array. The array output performance metrics include the output signal-to-interference-plus-noise ratio (SINR) of the beamformer and others
[
1
,
2
,
3
]
.

There are many papers on RAB proposed for the scenario of a general-rank signal model (see
[
3
,
4
]
and reference therein), since the desired signal source often can be incoherently scattered (rather than to be a point source corresponding to a rank-one signal model). Often, a RAB design for general-rank signal model addresses a worst-case SINR maximization problem (see, e.g.,
[
5
, problem (46)]
), where the desired signal covariance matrix is not known precisely as well as the sample estimate of the data covariance matrix is inaccurate.
In
[
5
]
, a closed-form solution for the worst-case SINR maximization problem has been proposed; however the positive semidefinite (PSD) assumption on the actual covariance for the desired signal was missing. We have reformulated the maximization problem into a quadratic matrix inequality (QMI) problem via a strong duality of linear conic programming in
[
4
]
, incorporating the PSD assumption, and the global optimality conditions for the QMI problem are established.

On the other hand, the authors of
[
6
]
presented an alternative worst-case SINR maximization problem formulation by introducing a matrix decomposition (e.g., spectral type) of the presumed covariance of the desired signal and putting an error term into both the matrix and its Hermitian obtained from the decomposition. It turned out that the RAB problem is a nonconvex quadratic programming problem, and an approximation algorithm for the quadratic problem has been proposed via solving a semidefinite programming (SDP) problem in each iterative step.
In
[
7
]
, a method using a bisection search to solve the RAB problem formulated
in
[
6
]
was proposed. In each step of the bisection search, an SDP feasibility problem is solved. In
[
8
,
9
]
,
the aforementioned RAB problem was viewed as a difference-of-convex (DC) functions optimization problem, and an approximate algorithm has been established, where an SDP problem must be solved in each iterative step. In addition, the authors proved the conditions under which the output by the algorithm is indeed globally optimal. In
[
10
]
, the RAB problem has been approximated by a sequence of second-order cone programming (SOCP) problems, and an algorithm that exhibited faster run time than the previously proposed SDP based approximation algorithm has been developed.

In this paper, we study the RAB problem, in a form of the worst-case SINR maximization (see, e.g.,
[
9
]
), with the uncertainty set defined via a matrix induced norm of the errors. Then, we can identify a matrix induced
l_{p,q}
-norm such that the RAB problem has a solution improving the actual beamformer output SINR the most. Remark that in contrast to the Frobenius norm of the matrix errors, the introduction of the matrix induced
l_{p,q}
-norm of the errors paves a
new way to enhance the array performance
. Specifically, we first derive the closed-form optimal value of a minimization problem of the least-squares residual, where the induced
l_{p,q}
-norm of the matrix errors is bounded by a constant. The optimal value obtained extends the result in
[
11
]
. Then the optimal value is applied to the worst-case SINR maximization problem with an induced
l_{2,q}
-norm of the matrix errors, and then the RAB problem is recast into a maximization problem with the objective being the difference between an
l_{2}
-norm function and an
l_{q}
-norm function, subject to a convex quadratic constraint. The maximization problem can be approximated by a sequence of SOCP problems with nondecreasing optimal values, since the epigraph of an
l_{q}
-norm function is second-order cone (SOC) representable for any rational number
q
greater than or equal to one and extended also with the infinity. By comparing the actual array output SINRs computed by the optimal beamvectors for the RAB problems with different values of
q
, we can select the optimal beamvector with a certain matrix induced
l_{2,q}
-norm as a candidate, which gives the maximal actual array output SINR. Then this candidate is the optimal solution. In addition, we consider a generalized RAB problem with an induced
l_{p,q}
-norm of the matrix errors, and the problem again can be solved approximately by a sequential SOCP approximation algorithm for
p\geq 1
and rational number
q\geq 1
. Finally, the optimal beamvector corresponding to a matrix induced
l_{p,q}
-norm, which gives the best real array output SINR, is found.

The paper is organized as follows. In Section II, we introduce the signal model and our problem formulation of the RAB problem for general-rank models.
In Section III, we propose the sequential SOCP approximation algorithm for the RAB optimization problem with a rational number
q
greater than or equal to one. In Section IV, we study generalized RAB problems involving the induced
l_{p,q}
-norm of the matrix errors. Section V includes illustrative numerical examples aiming to show how to select the best matrix induced norm, and Section V draws some concluding remarks.

II
Signal Model and Problem Formulation

The array observation vector is given by

\mbox{\boldmath{$y$}}(t)=\mbox{\boldmath{$s$}}(t)+\mbox{\boldmath$i$}(t)+\mbox{\boldmath{$n$}}(t)\in{\mathbb{C}^{N}}

(1)

where
\mbox{\boldmath{$s$}}(t)
,
\mbox{\boldmath$i$}(t)
, and
\mbox{\boldmath{$n$}}(t)
are the statistically
independent components of the desired signal, interference, and array
noise, respectively, and
N
is the number
of antenna elements of the array. The array output signal can be
written as

x(t)=\mbox{\boldmath{$w$}}^{H}\mbox{\boldmath{$y$}}(t)

(2)

where
\mbox{\boldmath{$w$}}\in{\mathbb{C}^{N}}
is the vector of beamformer (termed also beamvector). The beamformer output SINR is obtained by

\mbox{SINR}=\frac{\mbox{\boldmath{$w$}}^{H}\mbox{\boldmath{$R$}}_{\rm s}\mbox{\boldmath{$w$}}}{\mbox{\boldmath{$w$}}^{H}\mbox{\boldmath{$R$}}_{\rm i+n}\mbox{\boldmath{$w$}}}

(3)

where the desired signal covariance matrix is
\mbox{\boldmath{$R$}}_{\rm s}={\bf\sf E}[\mbox{\boldmath{$s$}}(t)\mbox{\boldmath{$s$}}^{H}(t)]
and the interference-plus-noise covariance matrix is
\mbox{\boldmath{$R$}}_{\rm i+n}={\bf\sf E}[(\mbox{\boldmath$i$}(t)+\mbox{\boldmath{$n$}}(t))(\mbox{\boldmath$i$}(t)+\mbox{\boldmath{$n$}}(t))^{H}]
. Note that the SINR (
3
) is unchanged when the beamvector
w
is replaced with
re^{j\theta}\mbox{\boldmath{$w$}}
, where
re^{j\theta}
is any nonzero complex number. Here, matrix
\mbox{\boldmath{$R$}}_{\rm s}
is of general rank, i.e.,
\mbox{\rm Rank}\,(\mbox{\boldmath{$R$}}_{\rm s})\in\{1,\ldots,N\}
. The rank-one
\mbox{\boldmath{$R$}}_{\rm s}
corresponds to the case of a point source or a scattered source in a far field from the array (see
[
1
,
3
,
5
,
6
]
).

An optimal beamforming problem of maximizing the SINR can be expressed as:

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}\neq\mbox{\boldmath{$0$}}}{\sf{maximize}}&\begin{array}[c]{c}\frac{\mbox{\boldmath{$w$}}^{H}\mbox{\boldmath{$R$}}_{\rm s}\mbox{\boldmath{$w$}}}{\mbox{\boldmath{$w$}}^{H}\mbox{\boldmath{$R$}}_{\rm i+n}\mbox{\boldmath{$w$}}},\end{array}\end{array}

(4)

If
\mbox{\boldmath{$R$}}_{\rm s}
and
\mbox{\boldmath{$R$}}_{\rm i+n}
are known perfectly in some way, the optimal value of (
4
) is the maximal eigenvalue
\lambda_{\max}(\mbox{\boldmath{$R$}}^{-1/2}_{\rm i+n}\mbox{\boldmath{$R$}}_{\rm s}\mbox{\boldmath{$R$}}^{-1/2}_{\rm i+n})
and the optimal solution is an eigenvector corresponding to this maximal eigenvalue.

However, in practical scenarios, matrix

\mbox{\boldmath{$R$}}_{\rm i+n}
is not available. As a compromise, the sample covariance matrix for
\mbox{\boldmath{$R$}}={\bf\sf E}[\mbox{\boldmath{$y$}}(t)\mbox{\boldmath{$y$}}^{H}(t)]
:

\hat{\mbox{\boldmath{$R$}}}=\frac{1}{T}\sum_{t=1}^{T}\mbox{\boldmath{$y$}}(t)\mbox{\boldmath{$y$}}^{H}(t)

(5)

is used to replace
\mbox{\boldmath{$R$}}_{\rm i+n}
in the optimal beamforming design problem (
4
). In (
5
),
T
stands for the
number of training snapshots. Of course, there could be substantial difference between
\mbox{\boldmath{$R$}}_{\rm i+n}
and
\hat{\mbox{\boldmath{$R$}}}
. On the other hand, the desired signal covariance matrix
\mbox{\boldmath{$R$}}_{s}
usually is only imperfectly known; in other words, there is always a certain mismatch between
the presumed signal covariance matrix
\hat{\mbox{\boldmath{$R$}}}_{\rm s}
and the actual signal covariance matrix
\mbox{\boldmath{$R$}}_{\rm s}
.

If
\hat{\mbox{\boldmath{$R$}}}_{\rm s}
and
\hat{\mbox{\boldmath{$R$}}}
are used in (
4
) to compute a beamvector, then the so obtained beamvector often leads to poor performance of the array (in terms of, e.g., the real array output SINR), which means that the beamvector could be useless. Therefore, in order to improve the array performance, RAB techniques have been studied in the last two decades, and there is a number of papers on this subject (see
[
2
,
3
,
4
]
and references therein).

Among all existing robust adaptive beamforming problem formulations, the following problem maximizing the worst-case SINR (cf.
[
12
]
) is of great interest:

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}\neq\mbox{\boldmath{$0$}}}{\sf{maximize}}&\underset{\mbox{\boldmath{$\Delta$}}_{1}\in{\cal B}_{1},\mbox{\boldmath{$\Delta$}}_{2}\in{\cal B}_{2}}{\sf{minimize}}\begin{array}[c]{c}\displaystyle\frac{\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}_{s}+\mbox{\boldmath{$\Delta$}}_{2})\mbox{\boldmath{$w$}}}{\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}+\mbox{\boldmath{$\Delta$}}_{1})\mbox{\boldmath{$w$}}}\end{array}\end{array}

(6)

where the uncertainty sets
{\cal B}_{1}
and
{\cal B}_{2}
are given
by

{\cal B}_{1}=\{\mbox{\boldmath{$\Delta$}}_{1}\in\mathbb{C}^{N\times N}~|~\|\mbox{\boldmath{$\Delta$}}_{1}\|_{F}\leq\gamma,\,\hat{\mbox{\boldmath{$R$}}}+\mbox{\boldmath{$\Delta$}}_{1}\succeq\mbox{\boldmath{$0$}}\},

(7)

and

{\cal B}_{2}=\{\mbox{\boldmath{$\Delta$}}_{2}\in\mathbb{C}^{L\times L}~|~\|\mbox{\boldmath{$\Delta$}}_{2}\|_{F}\leq\epsilon,\,\hat{\mbox{\boldmath{$R$}}}_{\rm s}+\mbox{\boldmath{$\Delta$}}_{2}\succeq\mbox{\boldmath{$0$}}\},

(8)

respectively. Here
L
is the number of sources.

Since
\mbox{\boldmath{$\Delta$}}_{1}
and
\mbox{\boldmath{$\Delta$}}_{2}
are separable in the objective function of (
6
), it is not hard to show that (
6
) is equivalent to the following problem:

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{maximize}}&\underset{\mbox{\boldmath{$\Delta$}}_{2}\in{\cal B}_{2}}{\sf{min}}\begin{array}[c]{c}\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}_{\rm s}+\mbox{\boldmath{$\Delta$}}_{2})\mbox{\boldmath{$w$}}\end{array}\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}+\gamma\mbox{\boldmath{$I$}})\mbox{\boldmath{$w$}}\leq 1,\end{array}

(9)

in the sense that if
\mbox{\boldmath{$w$}}^{\star}
solves (
9
), then it is optimal for (
6
) too. It is known that (
9
) can be reformulated into the following QMI problem (see, e.g.,
[
4
]
):

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}},\mbox{\boldmath{$Y$}}}{\sf{maximize}}&\mbox{\rm tr}\,(\hat{\mbox{\boldmath{$R$}}}_{\rm s}\mbox{\boldmath{$Y$}})-\epsilon\|\mbox{\boldmath{$Y$}}\|_{F}\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}\left(\hat{\mbox{\boldmath{$R$}}}+\gamma\mbox{\boldmath{$I$}}\right)\mbox{\boldmath{$w$}}\leq 1,\\
&\mbox{\boldmath{$w$}}\mbox{\boldmath{$w$}}^{H}-\mbox{\boldmath{$Y$}}\succeq\mbox{\boldmath{$0$}}.\end{array}

(10)

However, how to efficiently obtain a globally optimal solution for (
10
) remains to be a research topic in general despite there is an approximation algorithm and the global optimality conditions established in
[
4
]
.

In many existing works (see, e.g.,
[
6
,
7
,
8
,
9
,
10
]
), by incorporating the PSD constraint
\hat{\mbox{\boldmath{$R$}}}_{\rm s}+\mbox{\boldmath{$\Delta$}}_{2}\succeq\mbox{\boldmath{$0$}}
in
{\cal B}_{2}
, the objective
\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}_{\rm s}+\mbox{\boldmath{$\Delta$}}_{2})\mbox{\boldmath{$w$}}
of (
9
) is replaced by

\mbox{\boldmath{$w$}}^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})\mbox{\boldmath{$w$}},

(11)

where
\hat{\mbox{\boldmath{$R$}}}_{s}=\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}
,
\mbox{\boldmath{$Q$}}\in\mathbb{C}^{M\times N}
,
N\geq M=\mbox{\rm Rank}\,(\mbox{\boldmath{$R$}}_{s})
, and the norm of the distortion
\mbox{\boldmath{$\Delta$}}_{3}
is simply bounded
by
\eta
:

{\cal B}_{3}=\{\mbox{\boldmath{$\Delta$}}_{3}\in\mathbb{C}^{M\times N}~|~\|\mbox{\boldmath{$\Delta$}}_{3}\|_{F}\leq\eta\}.

(12)

With the new objective (
11
), problem (
9
) is reformulated into

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{maximize}}&\underset{\mbox{\boldmath{$\Delta$}}_{3}\in{\cal B}_{3}}{\sf{min}}\begin{array}[c]{c}\mbox{\boldmath{$w$}}^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})\mbox{\boldmath{$w$}}\end{array}\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}+\gamma\mbox{\boldmath{$I$}})\mbox{\boldmath{$w$}}\leq 1.\end{array}

(13)

It can be shown that RAB problem (
13
) is equivalent to (see, e.g.,
[
10
]
):

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{maximize}}&\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|-\eta\|\mbox{\boldmath{$w$}}\|\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1,\end{array}

(14)

due to the fact that

\displaystyle\min_{\mbox{\boldmath{$\Delta$}}_{3}\in{\cal B}_{3}}\mbox{\boldmath{$w$}}^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})^{H}(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})\mbox{\boldmath{$w$}}

(15)

\displaystyle~~~~~~~~~~=\left(\max\{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|-\eta\|\mbox{\boldmath{$w$}}\|,0\}\right)^{2}

(16)

(see, e.g.,
[
11
]
) and the optimal value of (
14
) is nonnegative. In
[
10
]
, problem (
14
) is solved by solving its equivalent problem

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{minimize}}&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\\
\sf{subject\;to}&\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|-\eta\|\mbox{\boldmath{$w$}}\|\geq 1,\end{array}

(17)

through designing a sequence of SOCP approximation problems with descent optimal values. It turns out by extensive simulations that the sequential SOCP approximation algorithm is faster than the other existing sequential SDP approximation algorithm for (
17
) in
[
8
,
9
]
, while both solutions by the two methods are globally optimal.

In robust optimization, one of the major questions is how to define a meaningful uncertainty set (see
[
13
, page 15]
). Therefore, there is a new possible dimension to improve the real array output performance by defining a proper error set
{\cal B}_{3}
. Herein, we try to define
{\cal B}_{3}
using different matrix induced norms (instead of using only Frobenius norm), and find the choice of a matrix induced norm such that a solution for (
13

III
Solutions for the RAB Problem with a Matrix Induced Norm of the Errors

In this section, we design an approch for solving RAB problem (
13
) when
{\cal B}_{3}
is defined by a certain arbitrary matrix induced norm.

III-A

The Closed-Form Optimal Value for a Minimization Problem of the Least-Squares Residual

The matrix induced norm
\|\mbox{\boldmath{$\Delta$}}\|_{p,q}
can be expressed as

\begin{array}[c]{rcl}\|\mbox{\boldmath{$\Delta$}}\|_{p,q}=&\underset{\mbox{\boldmath{$v$}}}{\sf{maximize}}&\|\mbox{\boldmath{$\Delta$}}\mbox{\boldmath{$v$}}\|_{p}\\
&\sf{subject\;to}&\|\mbox{\boldmath{$v$}}\|_{q}=1,\end{array}

(18)

where
\mbox{\boldmath{$\Delta$}}\in\mathbb{C}^{M\times N}
and
\mbox{\boldmath{$v$}}\in\mathbb{C}^{N}
(see, e.g.,
[
14
]
). For example,
\|\mbox{\boldmath{$\Delta$}}\|_{2,2}
is equivalent to the spectral norm
\|\mbox{\boldmath{$\Delta$}}\|_{2}
.

Suppose that

{\cal U}_{p,q}=\{\mbox{\boldmath{$\Delta$}}~|~\|\mbox{\boldmath{$\Delta$}}\|_{p,q}\leq\eta\},

(19)

with
p\geq 1
and
q\geq 1
.
Therefore, it is not hard to verify that

{\cal U}_{p,q}=\{\mbox{\boldmath{$\Delta$}}~|~\|\mbox{\boldmath{$\Delta$}}\mbox{\boldmath{$v$}}\|_{p}\leq\eta\|\mbox{\boldmath{$v$}}\|_{q},\,\forall\mbox{\boldmath{$v$}}\}.

(20)

Let us consider the minimization problem of the least-squares residual as follows.

\underset{\mbox{\boldmath{$\Delta$}}\in{\cal U}_{p,q}}{\sf{minimize}}~\|(\mbox{\boldmath{$A$}}+\mbox{\boldmath{$\Delta$}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p},

(21)

where
\mbox{\boldmath{$A$}}\in\mathbb{C}^{M\times N}
,
\mbox{\boldmath{$x$}}\in\mathbb{C}^{N}
and
\mbox{\boldmath{$b$}}\in\mathbb{C}^{M}
are parameters.
It is known (see, e.g.,
[
11
]
) that

\underset{\|\mbox{\boldmath{$\Delta$}}\|_{F}\leq\eta}{\sf{minimize}}~\|(\mbox{\boldmath{$A$}}+\mbox{\boldmath{$\Delta$}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|=\max\{\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|-\eta\|x\|,0\}.

(22)

Here, we extend the previous result in (
22
) by calculating the closed-form optimal value for (
21
).

Proposition III.1

It holds that

\underset{\mbox{\boldmath{$\Delta$}}\in{\cal U}_{p,q}}{\sf{minimize}}~\|(\mbox{\boldmath{$A$}}+\mbox{\boldmath{$\Delta$}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}=\max\{\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q},0\},

(23)

where
{\cal U}_{p,q}
is defined as in (
19
).

Proof:
Note that if
\mbox{\boldmath{$x$}}=\mbox{\boldmath{$0$}}
, then clearly (
23
) is true. Suppose that
\mbox{\boldmath{$x$}}\neq\mbox{\boldmath{$0$}}
. It follows that

\displaystyle\|(\mbox{\boldmath{$A$}}+\mbox{\boldmath{$\Delta$}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}

\displaystyle\geq

\displaystyle\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\|\mbox{\boldmath{$\Delta$}}\mbox{\boldmath{$x$}}\|_{p}

(24)

\displaystyle\geq

\displaystyle\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q},

where the second inequality is due to (
20
). First, we show (
23
) under the condition that

\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q}\geq 0,

(25)

and then we prove it under the condition that

\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q}<0.

(26)

Suppose that
\hat{\mbox{\boldmath{$y$}}}
is an optimal solution for the following problem

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$y$}}}{\sf{maximize}}&|\mbox{\boldmath{$y$}}^{H}\mbox{\boldmath{$x$}}|\\
\sf{subject\;to}&\|\mbox{\boldmath{$y$}}\|_{p^{\prime}}=1,\end{array}

(27)

where
p^{\prime}\geq 1
fulfills
1/p^{\prime}+1/q=1
. Therefore, we have
|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$x$}}|=\|\mbox{\boldmath{$x$}}\|_{q}
(due to the H
{\rm\ddot{o}}
lder inequality for complex vectors (see, e.g.,
[
15
, page 346]
).

Assume that condition (
25
) is satisfied. Then, we claim that
\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}>0
(otherwise, it follows from (
25
) that
\mbox{\boldmath{$x$}}=\mbox{\boldmath{$0$}}
, which contradicts the assumption that
\mbox{\boldmath{$x$}}\neq\mbox{\boldmath{$0$}}
).

Define a rank-one matrix

\hat{\mbox{\boldmath{$\Delta$}}}=-\eta e^{-j\arg(\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$x$}})}\frac{(\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}})\hat{\mbox{\boldmath{$y$}}}^{H}}{\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}}.

(28)

It can be easily verified that

\displaystyle\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\|(\mbox{\boldmath{$A$}}+\hat{\mbox{\boldmath{$\Delta$}}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}

(29)

\displaystyle=

\displaystyle\left\|\frac{\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}}{\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}}(\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$x$}}|)\right\|_{p}

\displaystyle=

\displaystyle\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q},

and that for any
\mbox{\boldmath{$z$}}\in\mathbb{C}^{N}
, we have

\displaystyle\|\hat{\mbox{\boldmath{$\Delta$}}}\mbox{\boldmath{$z$}}\|_{p}

\displaystyle=

\displaystyle\left\|\frac{\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}}{\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}}\right\|_{p}|\eta\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$z$}}|

(30)

\displaystyle=

\displaystyle\eta|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$z$}}|\leq\eta\|\hat{\mbox{\boldmath{$y$}}}\|_{p^{\prime}}\|\mbox{\boldmath{$z$}}\|_{q}

\displaystyle=

\displaystyle\eta\|\mbox{\boldmath{$z$}}\|_{q}.

Therefore,
\hat{\mbox{\boldmath{$\Delta$}}}
is such that both inequalities in (
24
) are satisfied as equality, and
\hat{\mbox{\boldmath{$\Delta$}}}\in{\cal U}_{p,q}
(which implies that the optimal value for the minimization problem in (
23
) is
\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q}
).

Now, we consider the other condition that
\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}-\eta\|\mbox{\boldmath{$x$}}\|_{q}<0
(i.e., (
26
)). Set

\hat{\mbox{\boldmath{$\Delta$}}}=-e^{-j\arg(\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$x$}})}\frac{(\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}})\hat{\mbox{\boldmath{$y$}}}^{H}}{\|\mbox{\boldmath{$x$}}\|_{q}}.

(31)

It is easy to see that the objective function of the minimization problem in (
23
) at
\hat{\mbox{\boldmath{$\Delta$}}}
is

\displaystyle\|(\mbox{\boldmath{$A$}}+\hat{\mbox{\boldmath{$\Delta$}}})\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}\|_{p}

\displaystyle=

\displaystyle\left\|\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}-\frac{\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}}{\|\mbox{\boldmath{$x$}}\|_{q}}|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$x$}}|\right\|_{p}

(32)

\displaystyle=

\displaystyle 0,

(33)

and that for any
\mbox{\boldmath{$z$}}\in\mathbb{C}^{N}
,

\|\hat{\mbox{\boldmath{$\Delta$}}}\mbox{\boldmath{$z$}}\|_{p}=\left\|\frac{\mbox{\boldmath{$A$}}\mbox{\boldmath{$x$}}-\mbox{\boldmath{$b$}}}{\|\mbox{\boldmath{$x$}}\|_{q}}\right\|_{p}|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$z$}}|<\eta|\hat{\mbox{\boldmath{$y$}}}^{H}\mbox{\boldmath{$z$}}|\leq\eta\|\mbox{\boldmath{$z$}}\|_{q},

(34)

where the first inequality holds thanks to (
26
). Therefore,
\hat{\mbox{\boldmath{$\Delta$}}}
has the property that the objective function of the minimization problem in (
23
) is equal to zero at
\hat{\mbox{\boldmath{$\Delta$}}}
, and
\hat{\mbox{\boldmath{$\Delta$}}}\in{\cal U}_{p,q}
(which means that the optimal value for the minimization problem in (
23
) is zero since the objective is a norm and zero is attainable).

Thereby, combining (
29
), (
30
), (
33
) and (
34
) yields (
23
), and thus, the proof is complete.

III-B

Solutions for the RAB Problem with a Matrix Induced Norm of the Errors

Let us now turn our focus on solving robust adaptive beamforming problem (
13
).

Suppose that the error set
{\cal B}_{3}
in (
12
) is redefined as

{\cal B}_{3}=\{\mbox{\boldmath{$\Delta$}}\in\mathbb{C}^{M\times N}~|~\|\mbox{\boldmath{$\Delta$}}\|_{2,q}\leq\eta_{q}\},

(37)

where
q\geq 1
. Note that the matrix induced
l_{2,q}
-norm is considered here because the numerator of the objective in (
13

\|(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})\mbox{\boldmath{$w$}}\|^{2}

It follows from Proposition
III.1
that the inner minimization problem of (

\left(\max\{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|-\eta_{q}\|\mbox{\boldmath{$w$}}\|_{q},0\}\right)^{2}.

(38)

Therefore, problem (
13
) is tantamount to the following problem

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{maximize}}&\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|-\eta_{q}\|\mbox{\boldmath{$w$}}\|_{q}\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1,\end{array}

(39)

since the optimal value of it is always nonnegative.

Essentially, problem (
39
) is a DC optimization problem (the objective is a difference of two convex functions), and hence it appears hard to solve. The SDP approximation method proposed in
[
8
,
9
]
is not applicable to solve it since
q
may not be equal to two as it is necessary for
[
8
,
9
]
. However, using the fact that the epigraph of the function
\|\mbox{\boldmath{$w$}}\|_{q}
can be represented as SOC for a rational number
q\geq 1
(see, e.g.,
[
17
]
), a sequential SOCP approximation approach can be applied to solve problem (
39
).

Specifically, in order to solve problem (
39
), let us rewrite it into

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}},\,t}{\sf{maximize}}&t\\
\sf{subject\;to}&\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|\geq t+\eta_{q}\|\mbox{\boldmath{$w$}}\|_{q}\\
&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1.\end{array}

(40)

Let
\mbox{\boldmath{$w$}}_{0}
be an initial point. It can be observed that

\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|\geq\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|},

(41)

and, thus, if

\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|}\geq t+\eta_{q}\|\mbox{\boldmath{$w$}}\|_{q},

(42)

then the first constraint of (
40
) is satisfied. Thereby, the following problem is a restriction of (
40
)

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}},\,t}{\sf{maximize}}&t\\
\sf{subject\;to}&\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|}\geq t+\eta_{q}\|\mbox{\boldmath{$w$}}\|_{q}\\
&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1,\end{array}

(43)

for any given
\mbox{\boldmath{$w$}}_{0}
such that
\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|\neq 0
.

It can be easily seen that the first constraint in (
43
) (i.e., (
42
)) can be represented as

\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|}\geq t+\eta_{q}s,\quad s\geq\|\mbox{\boldmath{$w$}}\|_{q}.

(44)

The first constraint in (
44
) is linear and the second one can be represented as a SOC constraint for any rational number
q\geq 1
.

In fact, when

with auxiliary variables

(46)

Example 1:

\sqrt{z_{n}^{2}+\left(\frac{\xi_{n}-s}{2}\right)^{2}}\leq\frac{\xi_{n}+s}{2},\quad n=1,\ldots,N,

IV
Solutions for Generalized Robust Adaptive Beamforming Problems

In this section, we extend robust beamforming problem (
13
) to

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}}}{\sf{maximize}}&\underset{\mbox{\boldmath{$\Delta$}}_{3}\in{\cal B}_{3}}{\sf{min}}\begin{array}[c]{c}\|(\mbox{\boldmath{$Q$}}+\mbox{\boldmath{$\Delta$}}_{3})\mbox{\boldmath{$w$}}\|_{p}\end{array}\\
\sf{subject\;to}&\mbox{\boldmath{$w$}}^{H}(\hat{\mbox{\boldmath{$R$}}}+\gamma\mbox{\boldmath{$I$}})\mbox{\boldmath{$w$}}\leq 1,\end{array}

(55)

where the distortion set is redefined as

{\cal B}_{3}=\{\mbox{\boldmath{$\Delta$}}\in\mathbb{C}^{M\times N}~|~\|\mbox{\boldmath{$\Delta$}}\|_{p,q}\leq\eta_{p,q}\},

(56)

and
p\geq 1
and
q\geq 1
. Clearly, the problem is equivalent to problem (
13
) when
p=q=2
.

Therefore, it follows from Proposition
III.1
that the inner minimization problem in (
55
) has the optimal value

\max\{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|_{p}-\eta_{p,q}\|\mbox{\boldmath{$w$}}\|_{q},0\}.

Hence, problem (
55
) can be reformulated into

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}},\,t}{\sf{maximize}}&t\\
\sf{subject\;to}&\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|_{p}\geq t+\eta_{p,q}\|\mbox{\boldmath{$w$}}\|_{q}\\
&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1.\end{array}

(57)

In (
57
), integers
p\geq 1
and
q\geq 1
are two freedom degrees to improve the performance of the resultant beamformer.

By the H
{\rm\ddot{o}}
lder inequality, we obtain that for a fixed vector
\mbox{\boldmath{$w$}}_{0}
,

\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|_{p}\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|_{q^{\prime}}\geq|\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}|\geq\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}),

(58)

where
q^{\prime}
satisfies
1/p+1/q^{\prime}=1
(i.e.,
q^{\prime}=p/(p-1)
). In other words,

\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}\|_{p}\geq\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|_{q^{\prime}}}.

(59)

Similar to problem (
43
), we claim that the following beamforming problem

\begin{array}[c]{cl}\underset{\mbox{\boldmath{$w$}},\,t}{\sf{maximize}}&t\\
\sf{subject\;to}&\frac{\Re(\mbox{\boldmath{$w$}}_{0}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|_{q^{\prime}}}\geq t+\eta_{p,q}\|\mbox{\boldmath{$w$}}\|_{q}\\
&\mbox{\boldmath{$w$}}^{H}\hat{\mbox{\boldmath{$R$}}}\mbox{\boldmath{$w$}}+\gamma\|\mbox{\boldmath{$w$}}\|^{2}\leq 1,\end{array}

(60)

for any given
\mbox{\boldmath{$w$}}_{0}
such that
\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{0}\|_{q^{\prime}}\neq 0
, is a restriction problem for problem (
57
). Clearly, (
60
) is an SOCP when
q\geq 1
is a rational number, and then (
57
) can be solved as a sequential SOCP approximation, as stated in Algorithm
1
with problem (
43
) in step 3 replaced by (
60
), where
\mbox{\boldmath{$w$}}_{0}
is substituted with
\mbox{\boldmath{$w$}}_{k}
.

The following proposition is in order.

Proposition IV.1

Suppose that
\{(\mbox{\boldmath{$w$}}_{k},t_{k})\}
is a sequence obtained from the sequential SOCP approximation algorithm, and suppose that
\{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|/\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}\}
is nondecreasing. Then,
\{t_{k}\}
is a nondecreasing sequence.

Proof:
Assume that at the
k
-th step, we solve (
60
) with
\mbox{\boldmath{$w$}}_{0}
changed to
\mbox{\boldmath{$w$}}_{k}
, getting an optimal solution
(\mbox{\boldmath{$w$}}_{k+1},t_{k+1})
. Therefore, we have

\frac{\Re(\mbox{\boldmath{$w$}}_{k}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}}\geq t_{k+1}+\eta_{p,q}\|\mbox{\boldmath{$w$}}_{k+1}\|_{q},

(61)

and
\mbox{\boldmath{$w$}}_{k+1}
satisfying the second constraint of (
60
).
Due to the assumption that
\{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|/\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}\}
is nondecreasing, the following inequality holds:

\frac{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|_{q^{\prime}}}\geq\frac{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}},

(62)

which implies that

\frac{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|^{2}}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|_{q^{\prime}}}\geq\frac{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}}\geq\frac{\Re(\mbox{\boldmath{$w$}}_{k}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k}\|_{q^{\prime}}},

(63)

This, together with (
61
), means that

\frac{\Re(\mbox{\boldmath{$w$}}_{k+1}^{H}\mbox{\boldmath{$Q$}}^{H}\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1})}{\|\mbox{\boldmath{$Q$}}\mbox{\boldmath{$w$}}_{k+1}\|_{q^{\prime}}}\geq t_{k+1}+\eta_{p,q}\|\mbox{\boldmath{$w$}}_{k+1}\|_{q}.

(64)

Thereby,
(\mbox{\boldmath{$w$}}_{k+1},t_{k+1})
is feasible for (
60
) with
\mbox{\boldmath{$w$}}_{0}
changed to
\mbox{\boldmath{$w$}}_{k+1}
, and hence the optimal value
t_{k+2}
is not less than
t_{k+1}
, namely,
t_{k+2}\geq t_{k+1}
. The proof is complete.

It then follows from (

&r+\eta_{p_{1},q_{1}}s\leq 1\\
&\|\mbox{\boldmath{$P$}}\mbox{\boldmath{$w$}}\|_{p_{1}}\leq r,\,\|\mbox{\boldmath{$w$}}\|_{q_{1}}\leq s.\end{array}

(70)

VI
Conclusion

We have considered the RAB problem for general-rank signal model, which has been formulated into a worst-case SINR maximization problem with an uncertainty set defined through a matrix induced norm. We have derived the closed-form optimal value of the minimization problem of the least-squares residual over the matrix errors with an induced norm constraint. Applying the closed-form result, the worst-case SINR maximization problem has been reexpressed as the problem maximizing the difference of a two-norm function and a
l_{q}
-norm function subject to a convex quadratic constraint. By observing that the epigraph of the
l_{q}
-norm function with a rational number
q>1
is SOC-representable, the maximization problem has been solved by a sequential SOCP approximation algorithm. The obtained solutions (beamvectors) corresponding to different values of
q
are then used compute the actual beamformer output SINRs, and the number
\bar{q}
that leads to the maximal beamformer output SINR is selected. In other words, the uncertainty set with matrix induced
l_{2,\bar{q}}
-norm has been treated as the best choice such that the optimal beamvector for the worst-case SINR maximization problem with the uncertainty set improves the array output performance the most. Apart from that, the matrix induced
l_{p,q}
-norm of the errors has been considered in the worst-case SINR maximization problem, and it has been shown that the problem can be approximated by a sequence of SOCPs. The rational number pair
(\bar{p},\bar{q})
which yields the highest array output SINR is chosen. Throughout our simulation examples we have demonstrated how to select the best (in terms of the actual array output SINRs and the CPU-time of the algorithm) uncertainty set defined via a matrix induced norm.
