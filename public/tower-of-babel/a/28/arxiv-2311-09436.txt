A characterization of piecewise ℱ \mathcal{F} -syndetic sets
Conner Griffin

Abstract
Some filter relative notions of size, ( ℱ , 𝒢 ) \left(\mathcal{F},\mathcal{G}\right) -syndeticity and piecewise ℱ \mathcal{F} -syndeticity, were defined and applied with clarity and focus by Shuungula, Zelenyuk and Zelenyuk Shuungula et al. 2009 . These notions are generalizations of the well studied notions of syndeticity and piecewise syndeticity. Since then, there has been an effort to develop the theory around the algebraic structure of the Stone-Čech compactification so that it encompasses these new generalizations. We prove one direction of a characterization of piecewise ℱ \mathcal{F} -syndetic sets. This completes the characterization, as the other direction was proved by Christopherson and Johnson ( Christopherson and Johnson 2021 , Theorem 4.4) .

Notions of size in a semigroup

We will use the following notation throughout this paper.

1.

We take

2.

For a set

\mathcal{P}_{f}\left(S\right):=\{A\subseteq S:\ \varnothing\neq A,\ \left|A\right|<\infty\}.

There are several different notions of size in a semigroup that have applications in combinatorial number theory.

Definition 1.1

(Syndetic, thick, piecewise syndetic)
.

Let
S
be a semigroup.

1.

A set
A\subseteq S
is
syndetic
if and only if there exists some
H\in\mathcal{P}_{f}\left(S\right)
such that
S=\bigcup_{h\in H}h^{-1}A.

2.

A set
A\subseteq S
is
thick
if and only if for all
H\in\mathcal{P}_{f}\left(S\right)
we have
\bigcap_{h\in H}h^{-1}A\neq\varnothing.

3.

A set
A\subseteq S
is
piecewise syndetic
if and only if there is some
H\in\mathcal{P}_{f}\left(S\right)
such that

\left\{x^{-1}\left(\bigcup_{h\in H}h^{-1}A\right):\quad x\in S\right\}

has the finite intersection property.

In the semigroup
\left(\mathbb{N},+\right)
, syndetic sets are the sets with bounded gaps and thick sets are the sets with arbitrarily long sequences of consecutive natural numbers. In this case – and in the case of the generalization to arbitrary semigroups – remark
1.2
should be clear.

Remark 1.2
.

Let
S
be a semigroup and let
A\subseteq S
.

1.

A
is thick if and only if
A^{c}
is not syndetic.

2.

A
is syndetic if and only if
A^{c}
is not thick.

3.

For any syndetic set
A
and any thick set
B
,
A\cap B\neq\varnothing.

The following characterization of piecewise syndetic is important.

Theorem 1.3
.

A set is piecewise syndetic if and only if it is the intersection of a syndetic set and a thick set.

We will prove one direction of this after introducing the Stone-Čech compactification of a semigroup. We will present a new proof which uses the relationship between piecewise syndetic sets and minimal idempotent ultrafilters.

The following theorem shows the connection between piecewise syndeticity and combinatorial number theory. It can be used to prove Van der Waerden’s theorem. Indeed, if
\bigcup_{i=1}^{k}C_{i}=\mathbb{N}
is a finite partition of the natural numbers then there is an
1\leq i\leq k
such that
C_{i}
is piecewise syndetic.

Theorem 1.4
.

Let
A
be a piecewise syndetic set in
\mathbb{N}
and let
\ell\in\mathbb{N}.
There exist
a,d\in\mathbb{N}
such that
\{a,a+d,a+2d,\dots,a+\ell d\}\subseteq A.

For a proof of this theorem see
(
Hindman and Strauss 2012
, Theorem 14.1)
. The first algebraic proof of Theorem
1.4
along these lines is due to Furstenberg and Katznelson.
Furstenberg and Katznelson 1989
These proofs are independent of Van der Waerden’s Theorem.

This gives a combinatorial property of piecewise syndetic sets, but it does not characterize them. That is, there are sets which contain arbitrarily long arithmetic progressions which are not piecewise syndetic.

Example 1.5
.

The set
\cup_{n=1}^{\infty}\{n!,n!+n,n!+2n,\dots,n!+n^{2}\}
is not piecewise syndetic.

The Stone-Čech compactification of a semigroup

There are several set theoretic notions that we need in order to define the Stone-Čech compactification.

Definition 2.1

(Filter, prime, ultrafilter)
.

Let
S

\mathcal{F}\subseteq\mathcal{P}\left(S\right).

•

We call
\mathcal{F}

filter on

1.

\varnothing\not\in\mathcal{F}

2.

(Upward closed) if

then
B\in\mathcal{F}.

3.

(Downward directed) if
A\in\mathcal{F}
and
B\in\mathcal{F}
then
A\cap B\in\mathcal{F}.

•

We call
\mathcal{F}

prime
if it has the following property:

4.

if
A\cup B\in\mathcal{F}
then
A\in\mathcal{F}
or
B\in\mathcal{F}.

•

We call
\mathcal{F}
an
ultrafilter on

if and only if
\mathcal{F}
is a prime filter.

There are many equivalent ways of defining ultrafilters. Alternatively,
\mathcal{F}
is an ultrafilter if and only if it is a filter which is not properly contained in any other filter. In lattice and order therory it is common to refer to the 4th property above as
prime
. It may also be called partition regularity. We use the following specific case of primality often: for any ultrafilter,
p,
on a set

and for any set

or

(The Stone-Čech compactification)

Let

be a discrete topological space. Then the Stone-Čech compactification of

\beta S:=\{p:\ p\ \textrm{is an ultrafilter on}\ S\}

Definition 2.3

(Principal ultrafilters)

For any

associated with

It is a typical abuse of notation to identify

Let

Let

From the two preceding theorems, we immediately have the following corollary.

Let

Definition 2.8

(Filter closure)

Let

The ultrafilters which are not principal are called

Algebraic characterizations of filter relative notions of size

In
Christopherson and Johnson 2021
, Christopherson and Johnson use the following useful term which we adopt.

Definition 3.1

(Mesh)
.

Let
S
be a nonempty set and let
\mathcal{F}\subseteq\mathcal{P}\left(S\right).
The
mesh of
\mathcal{F}
is
\mathcal{F}^{*}=\{A\subseteq S:\ A^{c}\notin\mathcal{F}\}.

When
\mathcal{F}
is a filter there is an equivalent definition:
\mathcal{F}^{*}=\{A\subseteq S:\ B\cap A\neq\varnothing\ \textrm{for all}\ B\in\mathcal{F}\}.
Again, when
\mathcal{F}
is a filter, it is useful to think of
\mathcal{F}^{*}
as the collection of all sets which may extend
\mathcal{F}
in the sense that for any
A\in\mathcal{F}^{*}
,
\{A\}\cup\mathcal{F}
has the finite intersection property and hence must be contained in an ultrafilter. As a consequence of this perspective, one can see that if
\mathcal{F}
and
\mathcal{G}
are filters with
\mathcal{F}\subseteq\mathcal{G}
then
\mathcal{G}^{*}\subseteq\mathcal{F}^{*}.

In
Shuungula et al. 2009
, Shuungula, Zelenyuk and Zelenyuk characterized the closure of the minimal ideal of an aribitrary subsemigroup of
\beta S.
Crucial to this paper are the filter relative notions of size,
\left(\mathcal{F},\mathcal{G}\right)
-syndeticity and piecewise
\mathcal{F}
-syndeticity. The notion of
\left(\mathcal{F},\mathcal{G}\right)
-thick comes from
Christopherson and Johnson 2021
.

Definition 3.2

(Relatively syndetic, thick, piecwise syndetic)
.

Let
S
be a semigroup,

and
\mathcal{F}
,
\mathcal{G}
be filters on
S.

•

We call
A

\left(\mathcal{F},\mathcal{G}\right)

\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)
to represent the collection of all
\left(\mathcal{F},\mathcal{G}\right)
-syndetic sets.

•

We call
A

\left(\mathcal{F},\mathcal{G}\right)

Proof.

If
\mathcal{F}
is an ultrafilter then both
\left(1\right)
and
\left(2\right)
are clear because in this case
\overline{\mathcal{F}}=\{\mathcal{F}\}
.

For
\left(1\right)
, it is clear that
\mathcal{F}\subseteq\bigcap_{p\in\overline{\mathcal{F}}}p.
For the reverse inclusion we will go by contradiction. Suppose that there is an
A\in\left(\bigcap_{p\in\overline{\mathcal{F}}}p\right)\setminus\mathcal{F}.
It cannot be that
A
is a superset of any set in
\mathcal{F}
as
A
would then be in
\mathcal{F}
. Therefore,
B\setminus A\neq\varnothing
for all
B\in\mathcal{F}.
But this means that
A^{c}\cap B\neq\varnothing
for all
B\in\mathcal{F}.
By the preceding line we may conclude that there is an ultrafilter,
p,
in
\overline{\mathcal{F}}
which contains
A^{c}.
Since
A
is an element of every ultrafilter in
\overline{\mathcal{F}},
we have
A
and
A^{c}
in
p.
Contradiction.

For
\left(2\right),
if
A\in p\in\overline{\mathcal{F}}
then
A\cap B\neq\varnothing
for all
B\in\mathcal{F}.
Therefore,
A\in\mathcal{F}^{*}.
So
\bigcup_{p\in\overline{\mathcal{F}}}p\subseteq\mathcal{F}^{*}.
Conversely, if
A\in\mathcal{F}^{*}
then
\mathcal{F}\cup\{A\}
has the finite intersection property and hence must be contained in an ultrafilter.
∎

We first build on the characterizations in Theorem

to achieve computationally useful characterizations of
\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right),

\operatorname{Thick}\left(\mathcal{F},\mathcal{G}\right)
and

In order to do this, we first note that we may extend the filter product to collections of sets that are simply upward closed. Christopherson and Johnson refer to such sets as
\emph{stacks}.
If
\mathcal{F}
and
\mathcal{G}
are stacks then we define the product as we have been:

\mathcal{F}\cdot\mathcal{G}:=\{A:\ \{x:\ x^{-1}A\in\mathcal{G}\}\in\mathcal{F}\}.

When we do this,
\mathcal{F}\cdot\mathcal{G}
is a stack and the operation is associative. The mesh of a filter is a stack. For
\mathcal{A}
, an arbitrary collection of filters on a set
S
,
\bigcap_{\mathcal{F}\in\mathcal{A}}\mathcal{F}
is a filter and
\bigcup_{\mathcal{F}\in\mathcal{A}}\mathcal{F}
is a stack.

Theorem 4.1
.

Let
S
be a semigroup and
\mathcal{A}\subseteq\beta S
. Then
\forall q\in\beta S

\bigcap_{p\in\mathcal{A}}\left(p\cdot q\right)=\left(\bigcap_{p\in\mathcal{A}}p\right)\cdot q\quad\textrm{and}\quad\bigcup_{p\in\mathcal{A}}\left(p\cdot q\right)=\left(\bigcup_{p\in\mathcal{A}}p\right)\cdot q.

Proof.

Let
q\in\beta S.

\displaystyle\forall p\in\mathcal{A},\quad A\in p\cdot q\quad

\displaystyle\iff\quad\forall p\in\mathcal{A},\quad\{x:\ x^{-1}A\in q\}\in p

\displaystyle\iff\quad\{x:\ x^{-1}A\in q\}\in\bigcap_{p\in\mathcal{A}}p

\displaystyle\iff\quad A\in\left(\bigcap_{p\in\mathcal{A}}p\right)\cdot q.

Likewise,

\displaystyle\exists p\in\mathcal{A},\quad A\in p\cdot q\quad

\displaystyle\iff\quad\exists p\in\mathcal{A},\quad\{x:\ x^{-1}A\in q\}\in p

\displaystyle\iff\quad\{x:\ x^{-1}A\in q\}\in\bigcup_{p\in\mathcal{A}}p

\displaystyle\iff\quad A\in\left(\bigcup_{p\in\mathcal{A}}p\right)\cdot q.

∎

It is the case that, for a filter
\mathcal{F}
and ultrafilter
p
, if
p\subseteq\mathcal{F}^{*}
then
p\in\overline{\mathcal{F}}.
Indeed, since
p\subseteq\mathcal{F}^{*}
,
p\cup\mathcal{F}
has the finite intersection property. Hence, there is an ultrafilter,
q
, with
p\cup\mathcal{F}\subseteq q.
Then
q\in\overline{\mathcal{F}}
and
q=p.
We adapt this proof to the following useful lemma.

Lemma 4.2
.

Let
\mathcal{F}
be a filter on a semigroup
S
and let
r,p\in\beta S.
If
r\subseteq\mathcal{F}^{*}\cdot p
, then
r\in\overline{\mathcal{F}}\cdot p
.

Proof.

Suppose
r\subseteq\mathcal{F}^{*}\cdot p.
Then for every finite
H\subseteq r
,

\bigcap_{A\in H}A^{\prime}\left(p\right)=\left(\bigcap_{A\in H}A\right)^{\prime}\left(p\right)\in\mathcal{F}^{*},

because
\bigcap_{A\in H}A\in r.
Hence,
\mathcal{F}\cup\{A^{\prime}\left(p\right):\ A\in r\}
has the finite intersection property. There is a
q\in\beta S
such that
\mathcal{F}\cup\{A^{\prime}\left(p\right):\ A\in r\}\subseteq q.
Thus
q\in\overline{\mathcal{F}}
and
r\subseteq q\cdot p.
Being ultrafilters,
r=q\cdot p.

∎

The following result is useful. Recall that for any two filters
\mathcal{F}
and
\mathcal{G}
, it may not be that
\overline{\mathcal{F}\cdot\mathcal{G}}=\overline{\mathcal{F}}\cdot\overline{\mathcal{G}}
.

Theorem 4.3
.

Let
\mathcal{F}
be a filter on a semigroup
S.
Then
\overline{\mathcal{F}}\cdot q=\overline{\mathcal{F}\cdot q}
and
\mathcal{F}^{*}\cdot q=\left(\mathcal{F}\cdot q\right)^{*}
for any
q\in\beta S
.

Proof.

We first prove the later result.

\displaystyle A\in\left(\mathcal{F}\cdot q\right)^{*}\quad

\displaystyle\iff\quad A^{c}\notin\mathcal{F}\cdot q=\bigcap_{p\in\overline{\mathcal{F}}}p\cdot q

\displaystyle\iff\quad\left(\exists p\in\overline{\mathcal{F}}\right)\ \left(A^{c}\notin p\cdot q\right)

\displaystyle\iff\quad\left(\exists p\in\overline{\mathcal{F}}\right)\ \left(A\in p\cdot q\right)

\displaystyle\iff\quad A\in\bigcup_{p\in\overline{\mathcal{F}}}p\cdot q=\mathcal{F}^{*}\cdot q.

For the former result, if
r\in\overline{\mathcal{F}}\cdot q
then there is a
p\in\overline{\mathcal{F}}
such that
r=p\cdot q.
Of course
p\cdot q\supseteq\mathcal{F}\cdot q
which means that
p\cdot q\in\overline{\mathcal{F}\cdot q}.
So,
\overline{\mathcal{F}}\cdot q\subseteq\overline{\mathcal{F}\cdot q}.

Let
r\in\overline{\mathcal{F}\cdot q}.
Then
r\subseteq\left(\mathcal{F}\cdot q\right)^{*}=\mathcal{F}^{*}\cdot q.
By Lemma
4.2
,
r\in\overline{\mathcal{F}}\cdot q.

∎

Theorem 4.4
.

Let
\mathcal{F},\mathcal{G}
be filters on a semigroup S. Then

\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)=\bigcap_{q\in\overline{\mathcal{G}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right)

and

\operatorname{Thick}\left(\mathcal{F},\mathcal{G}\right)=\bigcup_{q\in\overline{\mathcal{G}}}\bigcap_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right).

Proof.

\displaystyle A\in\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)\quad\iff

\displaystyle\quad\left(\forall V\in\mathcal{F}\right)\ \left(\exists H_{V}\in\mathcal{P}_{f}\left(V\right)\right)\ \left(\bigcup_{h\in H_{V}}h^{-1}A\in\mathcal{G}\right)

\displaystyle\iff

\displaystyle\quad\neg\left[\left(\exists V\in\mathcal{F}\right)\ \left(\forall H\in\mathcal{P}_{f}\left(V\right)\right)\ \left(\bigcup_{h\in H}h^{-1}A\notin\mathcal{G}\right)\right]

\displaystyle\iff

\displaystyle\quad\neg\left[\left(\exists V\in\mathcal{F}\right)\ \left(\forall H\in\mathcal{P}_{f}\left(V\right)\right)\ \left(\bigcap_{h\in H}h^{-1}A^{c}\in\mathcal{G}^{*}\right)\right]

\displaystyle\iff

\displaystyle\quad\neg\big[\left(\exists V\in\mathcal{F}\right)\ \left(\forall H\in\mathcal{P}_{f}\left(V\right)\right)\ (\mathcal{G}\cup\{x^{-1}A^{c}:x\in V\}

\displaystyle\quad\phantom{\neg\big[}\textrm{has the f.i.p.})\big]

\displaystyle\iff

\displaystyle\quad\neg\left[\left(\exists q\in\overline{\mathcal{G}}\right)\ \left(\exists V\in\mathcal{F}\right)\ \left(\forall x\in V\right)\ \left(x^{-1}A^{c}\in q\right)\right]

\displaystyle\iff

\displaystyle\quad\neg\left[\left(\exists q\in\overline{\mathcal{G}}\right)\ \left(A^{c}\in\mathcal{F}\cdot q\right)\right]

\displaystyle\iff

\displaystyle\quad\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(A^{c}\notin\mathcal{F}\cdot q\right)

\displaystyle\iff

\displaystyle\quad\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(A\in\left(\mathcal{F}\cdot q\right)^{*}\right)

\displaystyle\iff

\displaystyle\quad\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(A\in\mathcal{F}^{*}\cdot q\right)

\displaystyle\overset{\ref{elim}}{\iff}

\displaystyle\quad\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(A\in\left(\bigcup_{p\in\overline{\mathcal{F}}}p\right)\cdot q\right)

\displaystyle\overset{\ref{firstposition}}{\iff}

\displaystyle\quad\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(A\in\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right)\right)

\displaystyle\iff

\displaystyle\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(\exists p\in\overline{\mathcal{F}}\right)\ \left(A\in p\cdot q\right)

Thus

\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)=\bigcap_{q\in\overline{\mathcal{G}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right).

One can apply Theorem
3.3
to get

\operatorname{Thick}\left(\mathcal{F},\mathcal{G}\right)=\bigcup_{q\in\overline{\mathcal{G}}}\bigcap_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right).

Indeed,

\displaystyle\operatorname{Thick}\left(\mathcal{F},\mathcal{G}\right)

\displaystyle=\left(\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)\right)^{*}

\displaystyle=\{A\subseteq S:\ A^{c}\not\in\operatorname{Syn}\left(\mathcal{F},\mathcal{G}\right)\}

\displaystyle=\{A\subseteq S:\ \neg\left[\left(\forall q\in\overline{\mathcal{G}}\right)\ \left(\exists p\in\overline{\mathcal{F}}\right)\ \left(A^{c}\in p\cdot q\right)\right]\}

\displaystyle=\{A\subseteq S:\ \left(\exists q\in\overline{\mathcal{G}}\right)\ \left(\forall p\in\overline{\mathcal{F}}\right)\ \left(A^{c}\not\in p\cdot q\right)\}

\displaystyle=\{A\subseteq S:\ \left(\exists q\in\overline{\mathcal{G}}\right)\ \left(\forall p\in\overline{\mathcal{F}}\right)\ \left(A\in p\cdot q\right)\}

\displaystyle=\bigcup_{q\in\overline{\mathcal{G}}}\bigcap_{p\in\overline{\mathcal{F}}}\left(p\cdot q\right)

∎

Theorem 4.5
.

Let
\mathcal{F}
be a filter on a semigroup
S
and let
A\subseteq S.
The following are equivalent:

1.

A
is piecewise
\mathcal{F}
-syndetic;

2.

A\in\bigcup_{r\in\overline{\mathcal{F}}}\operatorname{Syn}\left(\mathcal{F},\operatorname{Thick}\left(\mathcal{F},r\right)\right)
;

3.

A\in\bigcup_{r\in\overline{\mathcal{F}}}\bigcap_{q\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot r\right)
.

Proof.

We will show
(1)\iff(2)\iff(3)
. Note that,
\operatorname{Thick}\left(\mathcal{F},r\right)=\bigcup_{r\in\overline{r}}\left(\mathcal{F}\cdot r\right).
However,
\overline{r}=\{r\}
meaning that

\operatorname{Thick}\left(\mathcal{F},r\right)=\mathcal{F}\cdot r.

We first show that
\left(1\right)\Longrightarrow\left(2\right)
. Suppose
A
is piecewise
\mathcal{F}
-syndetic. We need to be careful with the quantifiers in the definition of piecewise
\mathcal{F}
-syndetic. Since
A
is piecewise
\mathcal{F}
-syndetic,
\left(\exists H\in\bigtimes_{V\in\mathcal{F}}\mathcal{P}_{f}\left(V\right)\right)\ \left(\exists W\in\bigtimes_{V\in\mathcal{F}}\mathcal{F}\right)

(\{x^{-1}\bigcup_{h\in H_{V}}\left(h^{-1}A\right)\cap V:\ V\in\mathcal{F},\ x\in W_{V}\}
has the finite intersection property).

Equivalently,

\left(\exists H\in\bigtimes_{V\in\mathcal{F}}\mathcal{P}_{f}\left(V\right)\right)\ \left(\exists W\in\bigtimes_{V\in\mathcal{F}}\mathcal{F}\right)\ \left(\exists r\in\overline{\mathcal{F}}\right)

\left(\{x^{-1}\bigcup_{h\in H_{V}}\left(h^{-1}A\right):\ V\in\mathcal{F},\ x\in W_{V}\}\subseteq r\right).

It is important to note that the ultrafilter,
r,
is not at all dependent on the
V\in\mathcal{F}.

For all
V\in\mathcal{F}
,
W_{V}\subseteq\{x:\ x^{-1}\bigcup_{h\in H_{V}}\left(h^{-1}A\right)\in r\}
. Since
W_{V}\in\mathcal{F},
we may conclude that

\{x:\ x^{-1}\bigcup_{h\in H_{V}}\left(h^{-1}A\right)\in r\}\in\mathcal{F}.

We then have,
\left(\forall V\in\mathcal{F}\right)\ \left(\bigcup_{h\in H_{V}}\left(h^{-1}A\right)\in\mathcal{F}\cdot r\right).
By definition,
A\in\operatorname{Syn}\left(\mathcal{F},\mathcal{F}\cdot r\right).

We now show that
\left(2\right)\Longrightarrow\left(1\right)
. Suppose there is an
r\in\overline{\mathcal{F}}
such that
A\in\operatorname{Syn}\left(\mathcal{F},\mathcal{F}\cdot r\right).
Then for all
V\in\mathcal{F}
there exists an
H_{V}\in\mathcal{P}_{f}\left(V\right)
such that
\bigcup_{h\in H_{V}}h^{-1}A\in\mathcal{F}\cdot r.
Let
W_{V}=\{x:x^{-1}\bigcup_{h\in H_{V}}h^{-1}A\in r\}.
Notice that
W_{V}\in\mathcal{F}
. So then
\{x^{-1}\bigcup_{h\in H_{V}}h^{-1}A\cap V:\ V\in\mathcal{F},\ x\in W_{V}\}
has the finite intersection property. Hence,
A
is piecewise
\mathcal{F}
-syndetic.

Finally, we prove that
(2)\iff(3)
, which follows from Theorem
\ref{compcon}.

\displaystyle\operatorname{Syn}\left(\mathcal{F},\operatorname{Thick}\left(\mathcal{F},r\right)\right)

\displaystyle=\operatorname{Syn}\left(\mathcal{F},\mathcal{F}\cdot r\right)

\displaystyle=\bigcap_{s\in\overline{\mathcal{F}\cdot r}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot s\right)

\displaystyle=\bigcap_{s\in\overline{\mathcal{F}}\cdot r}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot s\right)

\displaystyle=\bigcap_{q\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot r\right).

∎

If we add the assumption that
\overline{\mathcal{F}}
is a semigroup, then we get the following result.

Lemma 4.6
.

Let
\mathcal{F}
be a filter on a semigroup
S
such that
\overline{\mathcal{F}}
is a subsemigroup of
\beta S
. Then,

\bigcup_{r\in\overline{\mathcal{F}}}\bigcap_{q\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot r\right)=\bigcup_{e\in E\left(K\left(\overline{\mathcal{F}}\right)\right)}\bigcap_{p\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot e\right).

Proof.

First note that, since
E\left(K\left(\overline{\mathcal{F}}\right)\right)\subseteq\overline{\mathcal{F}},
we have

\bigcup_{e\in E\left(K\left(\overline{\mathcal{F}}\right)\right)}\bigcap_{p\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot e\right)\subseteq\bigcup_{r\in\overline{\mathcal{F}}}\bigcap_{q\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot r\right).

For the converse, consider that
\overline{\mathcal{F}}\cdot r
is a left ideal of
\overline{\mathcal{F}}
and hence contains a minimal left ideal,
L.
Since
L
is minimal, there exists a minimal idempotent of
\overline{\mathcal{F}},e_{r},
such that
L=\overline{\mathcal{F}}\cdot e_{r}.
Since
\overline{\mathcal{F}}\cdot e_{r}\subseteq\overline{\mathcal{F}}\cdot r
,
\left(\forall u\in\overline{\mathcal{F}}\right)

\left(\exists q_{u}\in\overline{\mathcal{F}}\right)

\left(u\cdot e_{r}=q_{u}\cdot r\right).
We are assuming that
\left(\exists r\in\overline{\mathcal{F}}\right)

\left(\forall q\in\overline{\mathcal{F}}\right)

\left(A\in\mathcal{F}^{*}\cdot q\cdot r\right)
and thus
\left(\forall u\in\overline{\mathcal{F}}\right)

\left(A\in\mathcal{F}^{*}\cdot q_{u}\cdot r=\mathcal{F}^{*}\cdot u\cdot e_{r}\right)
. Hence,

A\in\bigcup_{e\in E\left(K\left(\overline{\mathcal{F}}\right)\right)}\bigcap_{q\in\overline{\mathcal{F}}}\left(\mathcal{F}^{*}\cdot q\cdot e\right)=\bigcup_{e\in E\left(K\left(\overline{\mathcal{F}}\right)\right)}\bigcap_{q\in\overline{\mathcal{F}}}\bigcup_{p\in\overline{\mathcal{F}}}\left(p\cdot q\cdot e\right).

∎

Let

A\cup A^{\prime}\left(e\right)\ \textrm{is}\ \mathcal{F}\textrm{-syndetic}.

It is the case, that
\forall p\in\beta S,

A\in p\cdot e

A^{\prime}\left(e\right)\in p\cdot e.
Indeed,
A\in p\cdot e=p\cdot e\cdot e

\forall p\in\beta S,

A\in p\cdot e

\left(A^{\prime}\left(e\right)\right)^{c}\in p\cdot e.

\forall p\in\beta S

A\cup\left(A^{c}\right)^{\prime}\left(e\right)

\mathcal{F}
-thick.

Finally,

\displaystyle\left(A\cup\left(A^{c}\right)^{\prime}\left(e\right)\right)\cap\left(A\cup A^{\prime}\left(e\right)\right)=

\displaystyle\left(A\cup\left(A^{\prime}\left(e\right)\right)^{c}\right)\cap\left(A\cup A^{\prime}\left(e\right)\right)

\displaystyle A\cup\varnothing=A.
