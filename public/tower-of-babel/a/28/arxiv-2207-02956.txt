Expressiveness and Decidability of Temporal Logics for Asynchronous Hyperproperties
Laura Bozzelli, Adriano Peron, César Sánchez

Abstract
Hyperproperties are properties of systems that relate different executions traces, with many applications from security to symmetry, consistency models of concurrency, etc. In recent years, different linear-time logics for specifying asynchronous hyperproperties have been investigated. Though model checking of these logics is undecidable, useful decidable fragments have been identified with applications e.g. for asynchronous security analysis. In this paper, we address expressiveness and decidability issues of temporal logics for asynchronous hyperproperties. We compare the expressiveness of these logics together with the extension S1S[E] of S1S with the equal-level predicate by obtaining an almost complete expressiveness picture. We also study the expressive power of these logics when interpreted on singleton sets of traces. We show that for two asynchronous extensions of HyperLTL , checking the existence of a singleton model is already undecidable, and for one of them, namely Context HyperLTL ( HyperLTL C ), we establish a characterization of the singleton models in terms of the extension of standard FO[ < < ] over traces with addition. This last result generalizes the well-known equivalence between FO[ < < ] and LTL . Finally, we identify new boundaries on the decidability of model checking HyperLTL C .

Hyperproperties.

Asynchronous extensions of Hyper logics.
Many
application domains require asynchronous properties that relate traces
at distinct time points which can be arbitrarily far from each
other.
For example, asynchronous specifications are needed to reason about a
multithreaded environment in which threads are not scheduled in
lockstep, and traces associated with distinct threads progress at
different speed.
Asynchronous hyperproperties are also useful in information-flow
security where an observer is not time-sensitive, so the observer
cannot distinguish consecutive time points along an execution having
the same observation.
This again requires asynchronously matching sequences of observations
along distinct execution traces.
A first systematic study of asynchronous hyperproperties is done

HyperLTL

A context

Given a context

\Pi+_{C}i

Let

contains the variables occurring in

The satisfaction relation

(we omit the semantics of the Boolean connectives):

\begin{array}[]{ll}(\Pi,C)\models p[x]&\Leftrightarrow\Pi(x)=(\pi,i)\text{ and }p\in\pi(i)\\
(\Pi,C)\models\textsf{X}\psi&\Leftrightarrow(\Pi+_{C}1,C)\models\psi\\

We write

We compare now the expressiveness of the asynchronous extensions of

HyperLTL
against
S1S[E]

[
7
]

S1S[E]
is a monadic second-order logic with equality over the
signature
\{<,E\}\cup\{P_{a}\mid a\in\textsf{AP}\}
which syntactically
extends the monadic second-order logic of one successor
S1S
with
the equal-level binary predicate

While

is interpreted over traces,

A set
\mathcal{L}
of traces induces the relational structure with domain

\mathcal{L}\times{\mathbb{N}}
(i.e., the set of pointed traces associated with

•

the binary predicate

•

\mathcal{L}\times{\mathbb{N}}

((\pi_{1},i),(\pi_{2},i))

Hence,

allows to compare distinct timestamps along the same trace,

We recall the syntax and semantics of parity

For a set

{\mathbb{B}}^{+}(X)
denotes the set
of
positive
Boolean formulas over

X

using
\vee
and
\wedge
(we also allow the formulas
true
and

false
). A subset
Y
of
X

satisfies

\theta\in{\mathbb{B}}^{+}(X)
iff the truth assignment that assigns
true

to the elements in
Y
and
false
to the elements of
X\setminus Y
satisfies
\theta
.

Labeled trees.
A tree
T
is a prefix closed subset of
{\mathbb{N}}^{*}
. Elements of
T
are called nodes and
\varepsilon
(the empty word) is the root of
T
. For
x\in T
, the set of children of
x
in
T
is the set of
nodes of the form
x\cdot n
for some
n\in{\mathbb{N}}
. A path of
T
is a maximal sequence
\pi
of nodes such that
\pi(0)=\varepsilon
and
\pi(i)
is a child in
T
of
\pi(i-1)
for all
0<i<|\pi|
. For an alphabet
\Sigma
, a
\Sigma
-labeled tree is a pair
\langle T,\textit{Lab}\rangle
consisting of a tree
and a labelling
\textit{Lab}:T\mapsto\Sigma
assigning to each node in
T
a symbol in
\Sigma
.

Syntax and Semantics of parity
AAWA
.
Here, we consider a equivalent and slight variant of the automata in
[
18
]
. Let
n\geq 1
. A parity
AAWA
with
n
tapes (parity
n
AAWA
for short) over a finite alphabet
\Sigma
is a tuple
\mathcal{A}=\langle\Sigma,Q,Q_{0},\rho,\Omega\rangle
, where

Q
is a finite set of (control) states,
Q_{0}\subseteq Q
is a set of initial states,

\rho:Q\times\Sigma^{n}\rightarrow{\mathbb{B}}^{+}(Q\times[1,n])
is the transition function, and
\Omega:Q\mapsto{\mathbb{N}}
is a parity acceptance condition assigning to each state a natural number (
color
).
If
\rho(q,\sigma)
only consists of disjunctions for all
q\in Q
and
\sigma\in\Sigma^{n}
, we call an

AAWA
a Nondeterministic Asynchronous Word Automaton (
NAWA
for short).

Let
n\geq 1
and
\mathcal{A}=\langle\Sigma,Q,Q_{0},\rho,\Omega\rangle
be a parity
AAWA
with
n
tapes (parity
n
AAWA
). A run of
\mathcal{A}
over an
n
-tuple
\overrightarrow{w}=(w_{1},\ldots,w_{n})
of infinite words over
\Sigma
is a
(Q\times{\mathbb{N}}^{n})
-labeled tree

r=\langle T_{r},\textit{Lab}_{r}\rangle
, where each node of
T_{r}
labelled by
(q,\wp)
with
\wp=(i_{1},\ldots,i_{n})
describes a copy of the automaton that is in state
q
and reads the
(i_{h}+1)^{th}
symbol of the input word

h\in[1,n]

(initially, the automaton is in state

reading the first position of each input word), and for each
\tau\in T_{r}
with
\textit{Lab}_{r}(\tau)=(q,\wp)
and
\wp=(i_{1},\ldots,i_{n})
, there
is a (possibly empty) set

\{(q_{1},d_{1}),\ldots,(q_{k},d_{k})\}\subseteq Q\times[1,n]

k\geq 0
satisfying

.
The run

is accepting if for each infinite path
\nu
of

color of the states in
Q
that occur infinitely often along
\nu
is even.
An
n
-tuple
\overrightarrow{w}
of infinite words over
\Sigma
is accepted by

\mathcal{A}
if there exists
an accepting run of
\mathcal{A}
over
\overrightarrow{w}
.

We also consider Büchi
n
AAWA
and generalized Büchi
n
AAWA
. In a Büchi
n
AAWA
, the acceptance condition is given by a set
F
of accepting states (encodable as a parity condition with two colors): in this case, a run is accepting if each infinite
path visits infinitely often some accepting state in
F
. In a generalized Büchi
n
AAWA
, the acceptance condition is given by a family
{\mathcal{F}}
of sets of accepting states (Büchi components): a run is accepting if every infinite path visits a state in every set

infinitely
often. By standard arguments (see e.g.
[

), a generalized Büchi

can be translated into an equivalent Büchi

n
AAWA
with quadratic blowup by exploiting a counter modulo the number of Büchi components.

Without loss

is the set of atomic propositions occurring in the

\theta

\psi

\theta

An

\psi

•

for each

\neg\theta\notin A

•

for each
\theta_{1}\wedge\theta_{2}\in{\textit{cl}}(\psi)

for each

is interpreted as the set of pairs of pointed traces in
\mathcal{L}\times{\mathbb{N}}
of the form
((\pi_{1},i),(\pi_{2},i))
. Hence, the predicate
<
allows to compare distinct timestamps along the same trace, while
the equal-level predicate allows to compare distinct traces at the same timestamp.
The semantics of
S1S[E]
is formally defined as follows. A
first-order valuation over
\mathcal{L}
is a pointed-trace assignment
\Pi
over
V_{1}
and
\mathcal{L}
, and
a
second-order valuation over
\mathcal{L}
is a mapping
{\mathcal{V}}
assigning to each second-order variable in
V_{2}
a set of pointed traces in
\mathcal{L}\times{\mathbb{N}}
.
Given a
S1S[E]
formula
\varphi
, the satisfaction relation

\Pi,{\mathcal{V}}\models_{\mathcal{L}}\varphi
is inductively defined as follows (we omit the semantics for the Boolean connectives which is standard):

\begin{array}[]{ll}\Pi,{\mathcal{V}}\models_{\mathcal{L}}P_{a}(x)&\Leftrightarrow\Pi(x)=(\pi,i)\text{ and }a\in\pi(i)\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}x\in X&\Leftrightarrow\Pi(x)\in{\mathcal{V}}(X)\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}x<y&\Leftrightarrow\Pi(x)=(\pi_{1},i_{1}),\,\Pi(y)=(\pi_{2},i_{2}),\,\pi_{1}=\pi_{2},\,\text{ and }i_{1}<i_{2}\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}x=y&\Leftrightarrow\Pi(x)=\Pi(y)\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}E(x,y)&\Leftrightarrow\Pi(x)=(\pi_{1},i_{1}),\,\Pi(y)=(\pi_{2},i_{2}),\text{ and }i_{1}=i_{2}\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}\exists x.\varphi&\Leftrightarrow\Pi[x\mapsto(\pi,i)]\models_{\mathcal{L}}\varphi\text{ for some }(\pi,i)\in\mathcal{L}\times N\\
\Pi,{\mathcal{V}}\models_{\mathcal{L}}\exists X.\varphi&\Leftrightarrow{\mathcal{V}}[X\mapsto A]\models_{\mathcal{L}}\varphi\text{ for some }A\subseteq\mathcal{L}\times N\end{array}

where
{\mathcal{V}}[X\mapsto A](X)=A
and
{\mathcal{V}}[X\mapsto A](Y)={\mathcal{V}}(Y)
for
Y\neq X
.
Note that if
\varphi
is a sentence, then the satisfaction relation
\Pi,{\mathcal{V}}\models_{\mathcal{L}}\varphi
is independent of
\Pi
and
{\mathcal{V}}
.
We say that
\mathcal{L}
is a model of
\varphi
, written

\mathcal{L}\models\varphi
if
\Pi,{\mathcal{V}}\models_{\mathcal{L}}\varphi
for some first-order valuation
\Pi
and second-order valuation
{\mathcal{V}}
over
\mathcal{L}
.

10.2
Proof of Lemma
17

In this section, we provide a proof of Lemma
17
(see Appendix
10.1
for the definition of the syntax and semantics of
S1S[E]
and
S1S
).

Lemma 4.34
.

Let
k\geq 1
and
\varphi
be a
S1S[E]

sentence over
AP
. Then, one can construct a
S1S
sentence
\varphi^{\prime}

over
\textsf{AP}\times[1,k]
whose set of models is the
k
-language of

\varphi
.

Proof.

Fix
k\geq 1
. Let
\psi
be a
S1S[E]
formula over
AP
with first-order variables
V_{1}=\{x_{1},\ldots,x_{n}\}
and second-order variables

V_{2}=\{X_{1},\ldots,X_{m}\}
for some
n\geq 1
and
m\geq 0
. For each first-order variable
x_{i}
, we introduce

k
fresh first-order variables
y_{i,1},\ldots,y_{i,k}
. Moreover,
for each second-order variable
X_{j}
, we introduce
k
fresh second-order variables

Y_{j,1},\ldots,Y_{j,k}
. Let
V^{\prime}_{1}=\{y_{1,1},\ldots,y_{1,k},\ldots,y_{n,1},\ldots,y_{n,k}\}

and
V^{\prime}_{2}=\{Y_{1,1},\ldots,Y_{1,k},\ldots,Y_{m,1},\ldots,Y_{m,k}\}
.
Let
\mathcal{L}=\{\pi_{1},\ldots,\pi_{k}\}
be a set of traces (over
AP
) of cardinality
k
.
Intuitively, for a first-order variable
x_{i}
mapped to a pointed trace
(\pi_{\ell},h)
, we use the
variable
y_{i,\ell}
in
S1S
for keeping track of the position
h
associated to the trace
\pi_{\ell}
in
\mathcal{L}
.
Moreover, for a set
A\subseteq\mathcal{L}\times{\mathbb{N}}
mapped to variable
X_{i}
, we use the second-order variables
Y_{i,1},\ldots,Y_{i,k}
for partitioning the set of timestamps in
A
in accordance to the first component of the pointed traces in
A
(recall that the second-order variables in
S1S
are mapped to sets of positions of the given trace).

Let
g:V_{1}\mapsto[1,k]
be a choice function associating to each first-order variable
x_{i}
an index
\ell\in[1,k]
. We associate to the
S1S[E]
formula
\psi
and the choice function
g
an
S1S
formula
f(\psi,g)
over
\textsf{AP}\times[1,k]
,
V^{\prime}_{1}
, and
V^{\prime}_{2}
.
The mapping
f(\psi,g)
is inductively defined as follows:

•

f
is homomorphic for the Boolean connectives.

•

f(P_{a}(x_{i}),g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,P_{(a,g(x_{i}))}(y_{i,g(x_{i})})

•

f(x_{i}\in X_{j},g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,y_{i,g(x_{i})}\in Y_{j,g(x_{i})}

•

f(x_{i}<x_{j},g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,\left\{\begin{array}[]{ll}\neg\top&\text{ if }g(x_{i})\neq g(x_{j})\\
y_{i,g(x_{i})}<y_{j,g(x_{j})}&\text{ otherwise}\end{array}\right.

•

f(x_{i}=x_{j},g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,\left\{\begin{array}[]{ll}\neg\top&\text{ if }g(x_{i})\neq g(x_{j})\\
y_{i,g(x_{i})}=y_{j,g(x_{j})}&\text{ otherwise}\end{array}\right.

•

f(E(x_{i},x_{j}),g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,y_{i,g(x_{i})}=y_{j,g(x_{j})}

•

f(\exists x_{i}.\,\psi,g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,\displaystyle{\bigvee_{\ell\in[1,k]}}\exists y_{i,\ell}.\,f(\psi,g[x_{i}\mapsto\ell])

•

f(\exists X_{i}.\,\psi,g)\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,\exists Y_{i,1}.\ldots\exists Y_{i,k}.f(\psi,g)

where
g[x_{i}\mapsto\ell](x_{j})=\ell
if
j=i
,
g[x_{i}\mapsto\ell](x_{j})=g(x_{j})
otherwise. Fix a well-formed trace
\nu
over
\textsf{AP}\times[1,k]
and let
\mathcal{L}(\nu)
be the set of traces over
AP
having cardinality
k
associated with
\nu
. Then,
\mathcal{L}(\nu)
can be written in the form
\mathcal{L}(\nu)=\{\pi_{1},\ldots,\pi_{k}\}
where
for each
\ell\in[1,k]
and
i\geq 0
,
\pi_{\ell}(i)=\{p\in\textsf{AP}\mid(p,\ell)\in\nu(i)\}
.
Let
g:V_{1}\mapsto[1,k]
be a choice function,
{\mathcal{V}}_{1}
be a first-order
S1S
-valuation over
V^{\prime}_{1}
(i.e., a function associating a position
i\geq 0
to each variable in
V^{\prime}_{1}
), and
{\mathcal{V}}_{2}
be a second-order
S1S
-valuation over
V^{\prime}_{2}
for
S1S

(i.e., a function associating a subset of
{\mathbb{N}}
to each variable in
V^{\prime}_{2}
).
We denote by
\Pi({\mathcal{V}}_{1},g)
and
{\mathcal{V}}({\mathcal{V}}_{2})
the first-order
S1S[E]
-valuation and the second-order
S1S[E]
-valuation over
V_{1}
and
V_{2}
, respectively, for the set of traces
\mathcal{L}(\nu)
, defined as follows:

•

for each
x_{i}\in V_{1}
, let
g(x_{i})=\ell
: then
\Pi({\mathcal{V}}_{1},g)(x_{i})\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,(\pi_{\ell},{\mathcal{V}}_{1}(y_{i,\ell}))
;

•

for each
X_{i}\in V_{2}
,
{\mathcal{V}}({\mathcal{V}}_{2})(X_{i})\,\stackrel{{\scriptstyle\text{{def}}}}{{=}}\,\displaystyle{\bigcup_{1\leq\ell\leq k}\{\pi_{\ell}\}\times{\mathcal{V}}_{2}(Y_{i,\ell})}
.

We first show the following.

Claim.

{\mathcal{V}}_{1},{\mathcal{V}}_{2}\models_{\nu}f(\psi,g)
if and only if
\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\psi
.

Proof of the claim:
by induction on the structure of
\psi
. The case of Boolean connectives directly follows from the induction hypothesis. For the other cases, we proceed as follows:

•

\psi=P_{a}(x_{i})
for some
a\in\textsf{AP}
and
i\in[1,n]
. Let
g(x_{i})=\ell
and
{\mathcal{V}}_{1}(y_{i,\ell})=h
. By construction,

f(\psi,g)=P_{(a,\ell)}(y_{i,\ell})
and
\Pi({\mathcal{V}}_{1},g)(x_{i})=(\pi_{\ell},h)
. Moreover,

a\in\pi_{\ell}(h)
iff
(a,\ell)\in\nu(h)
. Hence, the result follows.

•

\psi=x_{i}\in X_{j}
for some
i\in[1,n]
and
j\in[1,m]
. Let
g(x_{i})=\ell
,
{\mathcal{V}}_{1}(y_{i,\ell})=h
, and
{\mathcal{V}}_{2}(Y_{j,\ell})=A\subseteq{\mathbb{N}}
. By construction,

f(\psi,g)=y_{i,\ell}\in Y_{j,\ell}
,
\Pi({\mathcal{V}}_{1},g)(x_{i})=(\pi_{\ell},h)
, and
{\mathcal{V}}({\mathcal{V}}_{2})(X_{j})\cap(\{\pi_{\ell}\}\times{\mathbb{N}})=\{\pi_{\ell}\}\times A
. Hence,
\Pi({\mathcal{V}}_{1},g)(x_{i})\in{\mathcal{V}}({\mathcal{V}}_{2})(X_{j})
iff
{\mathcal{V}}_{1}(y_{i,\ell})\in{\mathcal{V}}_{2}(Y_{j,\ell})
, and the result holds in this case as well.

•

\psi=x_{i}<x_{j}
for some
i,j\in[1,n]
. Let
g(x_{i})=\ell
,
g(x_{j})=\ell^{\prime}
,
{\mathcal{V}}_{1}(y_{i,\ell})=h
, and
{\mathcal{V}}_{1}(y_{j,\ell^{\prime}})=h^{\prime}
. By construction,

\Pi({\mathcal{V}}_{1},g)(x_{i})=(\pi_{\ell},h)
and
\Pi({\mathcal{V}}_{1},g)(x_{j})=(\pi_{\ell^{\prime}},h^{\prime})
. Moreover,
either

\ell\neq\ell^{\prime}
and
f(\psi,g)=\neg\top
,
or

\ell=\ell^{\prime}
and
f(\psi,g)=y_{i,\ell}<y_{j,\ell}
. Thus, since
\pi_{\ell}\neq\pi_{\ell^{\prime}}
if
\ell\neq\ell^{\prime}
, the result easily follows.

•

\psi=x_{i}=x_{j}
for some
i,j\in[1,n]
. This case is similar to the previous one.

•

\psi=E(x_{i},x_{j})
for some
i,j\in[1,n]
. Let
g(x_{i})=\ell
,
g(x_{j})=\ell^{\prime}
,
{\mathcal{V}}_{1}(y_{i,\ell})=h
, and
{\mathcal{V}}_{1}(y_{j,\ell^{\prime}})=h^{\prime}
. By construction,

\Pi({\mathcal{V}}_{1},g)(x_{i})=(\pi_{\ell},h)
,
\Pi({\mathcal{V}}_{1},g)(x_{j})=(\pi_{\ell^{\prime}},h^{\prime})
, and
f(\psi,g)=y_{i,\ell}=y_{j,\ell^{\prime}}
.
Hence, (i)
{\mathcal{V}}_{1},{\mathcal{V}}_{2}\models_{\nu}f(\psi,g)
iff
h=h^{\prime}
and (ii)
\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\psi
iff
h=h^{\prime}
, and the result follows.

•

\psi=\exists x_{i}.\,\theta
for some
i\in[1,n]
. First, assume that
{\mathcal{V}}_{1},{\mathcal{V}}_{2}\models_{\nu}f(\exists x_{i}.\,\theta,g)
.
By construction, there exists
\ell\in[1,k]
such that
{\mathcal{V}}_{1},{\mathcal{V}}_{2}\models_{\nu}\exists y_{i,\ell}.\,f(\theta,g[x_{i}\mapsto\ell])
. Hence, for some
h\in{\mathbb{N}}
,
{\mathcal{V}}_{1}[y_{i,\ell}\mapsto h],{\mathcal{V}}_{2}\models_{\nu}f(\theta,g[x_{i}\mapsto\ell])
.
Let
{\mathcal{V}}^{\prime}_{1}={\mathcal{V}}_{1}[y_{i,\ell}\mapsto h]
and
g^{\prime}=g[x_{i}\mapsto\ell]
. By the induction hypothesis, we have that

\Pi({\mathcal{V}}^{\prime}_{1},g^{\prime}),{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\theta
. Since
\Pi({\mathcal{V}}^{\prime}_{1},g^{\prime})=\Pi({\mathcal{V}}_{1},g)[x_{i}\mapsto(\pi_{\ell},h)]
, we obtain that

\Pi({\mathcal{V}}_{1},g)[x_{i}\mapsto(\pi_{\ell},h)],{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\theta
. Hence,
\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\exists x_{i}.\,\theta
. The converse implication is similar.

•

\psi=\exists X_{i}.\,\theta
for some
i\in[1,m]
. First, assume that
{\mathcal{V}}_{1},{\mathcal{V}}_{2}\models_{\nu}f(\exists X_{i}.\,\theta,g)
.
By construction, for each
\ell\in[1,k]
, there exists a set
A_{\ell}\subseteq{\mathbb{N}}
such that
{\mathcal{V}}_{1},{\mathcal{V}}_{2}[Y_{i,1}\mapsto A_{1},\ldots,Y_{i,k}\mapsto A_{k}]\models_{\nu}f(\theta,g)
.
Let
{\mathcal{V}}^{\prime}_{2}={\mathcal{V}}_{2}[Y_{i,1}\mapsto A_{1},\ldots,Y_{i,k}\mapsto A_{k}]
. By the induction hypothesis, we have that

\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}^{\prime}_{2})\models_{\mathcal{L}(\nu)}\theta
. Let
A=\displaystyle{\bigcup_{\ell\in[1,k]}}\{\pi_{\ell}\}\times A_{i}
. Since
{\mathcal{V}}({\mathcal{V}}^{\prime}_{2})={\mathcal{V}}({\mathcal{V}}_{2})[X_{i}\mapsto A]
, we obtain that

\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}_{2})[X_{i}\mapsto A]\models_{\mathcal{L}(\nu)}\theta
. Hence,
\Pi({\mathcal{V}}_{1},g),{\mathcal{V}}({\mathcal{V}}_{2})\models_{\mathcal{L}(\nu)}\exists X_{i}.\,\theta
. The converse implication is similar.

This concludes the proof of the claim.∎

Fix an arbitrary choice function
g_{0}:V_{1}\mapsto[1,k]
. For a
S1S[E]
sentence
\varphi
over
AP
,
V_{1},
and
V_{2}
, let
\varphi^{\prime}
be the
S1S
sentence over
\textsf{AP}\times[1,k]

given by

\varphi^{\prime}:=f(\varphi,g_{0})\wedge\displaystyle{\bigwedge_{\ell,\ell^{\prime}\in[1,k]:\,\ell\neq\ell}\exists z_{0}.\,\bigvee_{a\in\textsf{AP}}}(P_{(a,\ell)}(z_{0})\leftrightarrow\neg P_{(a,\ell^{\prime})}(z_{0}))

Note that the second conjunct captures the well-formed traces over
\textsf{AP}\times[1,k]
. By the previous claim, it follows that
the
k
-language of
\varphi
is the set of traces (over
\textsf{AP}\times[1,k]
) satisfying
\varphi^{\prime}
.
This concludes the proof of Lemma
17
.
∎
