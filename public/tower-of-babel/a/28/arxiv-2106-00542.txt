Introduction

Let
\eta=\{\eta(t);t\in[0,1]\}
be a mean zero continuous Gaussian process with covariance
U=\{U(s,t),s,t\in[0,1]\},
with
U(0,0)>0
. Let
\{\eta_{i};i=1,\ldots,k\}
be independent copies of
\eta
and set,

Y_{k}(t)=\sum_{i=1}^{k}\eta^{2}_{i}(t),\qquad t\in[0,1].

(1.1)

The stochastic process
Y_{k}=\{Y_{k}(t),t\in[0,1]\}
is referred to as a chi–square process of order
k
with kernel
U
.

Theorem 1.1

Let
\phi(t)
be a positive function on
[0,\delta]
for some
\delta>0
.
If

\limsup_{t\to 0}\frac{\eta(t)-\eta(0)}{\phi(t)}=1\qquad a.s.,

(1.2)

then for all integers
k\geq 1
,

\limsup_{t\to 0}\frac{Y_{k}(t)-Y_{k}(0)}{\phi(t)}=2Y^{1/2}_{k}(0)\qquad a.s.

(1.3)

When
k=1
this is particularly simple. Since
\eta
is symmetric it follows from (
1.2
) that,

\liminf_{t\to 0}\frac{\eta(t)-\eta(0)}{\phi(t)}=-1\qquad a.s.

(1.4)

Therefore, writing
Y_{1}(t)-Y_{1}(0)=(\eta(t)-\eta(0))(\eta(t)+\eta(0))
and using the continuity of
\eta
, we see that

\limsup_{t\to 0}\frac{Y_{1}(t)-Y_{1}(0)}{\phi(t)}=2\left(\eta(0)\vee-\eta(0)\right)\qquad a.s.,

(1.5)

which is (
1.3
).

A result similar to Theorem
1.1

for the limiting behavior of chi–square sequences at infinity is given in
[
2
, Lemma 6.5]
.

Set

\sigma^{2}(u,v)=E(\eta(u)-\eta(v))^{2}\quad\text{and}\quad\widetilde{\sigma}^{2}(x)=\sup_{|u-v|\leq x}\sigma^{2}(u,v).

(1.6)

Theorem 1.2

Assume that
\inf_{t\in[0,1]}U(t,t)>0
and,

\lim_{x\to 0}\widetilde{\sigma}^{2}(x)\log 1/x=0.

(1.7)

Let
\varphi(t)
be a positive function on
[0,1]
. Then if

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\eta(u)-\eta(v)}{\varphi(|u-v|)}=1\qquad a.s.,

(1.8)

for all intervals
\Delta\subset[0,1]
,
it follows that for all intervals
\Delta\subset[0,1]
and all integers
k\geq 1
,

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{Y_{k}(u)-Y_{k}(v)}{\varphi(|u-v|)}=2\sup_{u\in\Delta}Y_{k}^{1/2}(u),\hskip 14.45377pta.s.

(1.9)

When
\eta
is a continuous Gaussian process with stationary increments,
\sigma^{2}(u,v)
in (
1.6
) can be written as

\sigma^{2}(u-v,0)
. In this case if
\widetilde{\sigma}^{2}(x)
is asymptotic to an increasing function at 0,
then (
1.8
) implies (
1.7
). We discuss this further in Remark
2.1
.

An extensive treatment of Gaussian processes satisfying (
1.2
) and (
1.8
)
is given in
[
1
, Chapter 7]
.

Proof of Theorem
1.1

Let
\eta_{i}(t)
,
i=1,\ldots,k
, be independent copies of
\eta(t)
.
We write,

\displaystyle\eta_{i}^{2}(t)-\eta_{i}^{2}(0)

\displaystyle=

\displaystyle(\eta_{i}(t)-\eta_{i}(0))(\eta_{i}(t)+\eta_{i}(0))

(2.1)

\displaystyle=

\displaystyle(\eta_{i}(t)-\eta_{i}(0))(2\eta_{i}(0)+(\eta_{i}(t)-\eta_{i}(0)))

\displaystyle=

\displaystyle 2(\eta_{i}(t)-\eta_{i}(0))\eta_{i}(0)+(\eta_{i}(t)-\eta_{i}(0))^{2}.

By (
1.2
)

\displaystyle\limsup_{t\to 0}\frac{\sum_{i=1}^{k}(\eta_{i}(t)-\eta_{i}(0))^{2}}{\phi(t)}

(2.2)

\displaystyle\qquad\leq\sum_{i=1}^{k}\limsup_{t\to 0}\frac{|\eta_{i}(t)-\eta_{i}(0)|}{\phi(t)}\lim_{t\to 0}|\eta_{i}(t)-\eta_{i}(0)|=0.

Consequently, using (
1.1
) we see that,

\limsup_{t\to 0}\frac{Y_{k}(t)-Y_{k}(0)}{\phi(t)}=\limsup_{t\to 0}\frac{2\sum_{i=1}^{k}(\eta_{i}(t)-\eta_{i}(0))\eta_{i}(0)}{\phi(t)}.

(2.3)

Write,

\displaystyle(\eta_{i}(t)-\eta_{i}(0))\eta_{i}(0)

(2.4)

\displaystyle\qquad=\left(\eta_{i}(t)-\frac{U(0,t)}{U(0,0)}\eta_{i}(0)\right)\eta_{i}(0)-\left(\frac{U(0,0)-U(0,t)}{U(0,0)}\right)\eta^{2}_{i}(0).

We show below that

\limsup_{t\to 0}\frac{|U(0,0)-U(0,t)|}{U(0,0)\phi(t)}=0.

(2.5)

Consequently,

\limsup_{t\to 0}\frac{Y_{k}(t)-Y_{k}(0)}{\phi(t)}=\limsup_{t\to 0}\frac{2\sum_{i=1}^{k}\left(\eta_{i}(t)-\frac{U(0,t)}{U(0,0)}\eta_{i}(0)\right)\eta_{i}(0)}{\phi(t)}.

(2.6)

Let
\{\xi_{i}(t),t\in[0,1]\}
,
i=1,\ldots,k
, be independent copies of a mean zero Gaussian process
\{\xi(t),t\in[0,1]\}
, and set
\vec{\xi}(t)=(\xi_{1}(t),\ldots,\xi_{k}(t))
. Let
\vec{v}\in R^{k}
with
\|\vec{v}\|_{2}=1
. Computing the covariances we see that,

\{(\vec{v}\cdot\vec{\xi}(t)),t\in[0,1]\}\stackrel{{\scriptstyle law}}{{=}}\{\xi(t),t\in[0,1]\}.

(2.7)

(This relationship is used by P. Revesz in
[
3
, Theorem 18.1]
to obtain LILs for Brownian motion in
R^{k}
.)

Therefore, since

\left(\eta_{i}(t)-(U(0,t)/U(0,0))\eta_{i}(0)\right)
and
\eta_{i}(0)
are independent for
i=1,\ldots,k
, we see that,

\displaystyle\Big\{\left(\vec{\eta}(t)-\frac{U(0,t)}{U(0,0)}\vec{\eta}(0)\right)\cdot\frac{\vec{\eta}(0)}{\|\vec{\eta}(0)\|_{2}},t\in[0,1]\Big\}

(2.8)

\displaystyle\qquad\stackrel{{\scriptstyle law}}{{=}}\Big\{\left(\eta(t)-\frac{U(0,t)}{U(0,0)}\eta(0)\right),t\in[0,1]\Big\},

where
\vec{\eta}(t)=(\eta_{1}(t),\ldots,\eta_{k}(t))
.
Consequently, (
2.6
) implies that

\limsup_{t\to 0}\frac{Y_{k}(t)-Y_{k}(0)}{\phi(t)\|\vec{\eta}(0)\|_{2}}\stackrel{{\scriptstyle law}}{{=}}\limsup_{t\to 0}\frac{2\left(\eta(t)-\frac{U(0,t)}{U(0,0)}\eta(0)\right)}{\phi(t)}.

(2.9)

Using (
2.4
) again and (
2.5
) we see that this implies that,

\limsup_{t\to 0}\frac{Y_{k}(t)-Y_{k}(0)}{\phi(t)\|\vec{\eta}(0)\|_{2}}\stackrel{{\scriptstyle law}}{{=}}\limsup_{t\to 0}\frac{2(\eta(t)-\eta(0))}{\phi(t)}=2,

(2.10)

where the last equality uses (
1.2
). Since,

\|\vec{\eta}(0)\|_{2}=\left(\sum_{i=1}^{k}\eta^{2}_{i}(0)\right)^{1/2}=Y_{k}^{1/2}(0),

(2.11)

we obtain (
1.3
).

To obtain (
2.5
) we first note that it follows from (
1.2
) that,

\phi(t)=(E(\eta(t)-\eta(0))^{2})^{1/2}h(t),

(2.12)

for some function
h
such that
\lim_{t\downarrow 0}h(t)=\infty
. To see this, suppose that it is false. Then there exists a sequence
\{t_{k}\}
, with
\lim_{k\to\infty}t_{k}=0
, such that
\sup_{k}h(t_{k})\leq M
. Therefore, if (
1.2
) holds, we would have,

\sup_{k}\frac{\eta(t_{k})-\eta(0)}{(E(\eta(t_{k})-\eta(0))^{2})^{1/2}}\leq M\qquad a.s.

(2.13)

This is not possible because
\{{\eta(t_{k})-\eta(0)}/{(E(\eta(t_{k})-\eta(0))^{2})^{1/2}}\}

is a sequence of standard normal random variables.

Since,

U(0,0)-U(0,t)=E\left(\left(\eta(t)-\eta(0)\right)\eta(0)\right)\leq E\left(\left(\eta(t)-\eta(0)\right)^{2}\right)^{1/2}U^{1/2}(0,0),

(2.14)

we have,

\frac{U(0,0)-U(0,t)}{\phi(t)}\leq\frac{U^{1/2}(0,0)}{h(t)}.

(2.15)

Using the fact that
\lim_{t\downarrow 0}h(t)=\infty
we get (
2.5
).

Proof of Theorem

To show,

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{Y_{k}(u)-Y_{k}(v)}{\varphi(|u-v|)}\geq 2\sup_{t\in\Delta}Y_{k}^{1/2}(t),\hskip 14.45377pta.s.

(2.16)

it suffices to show that for any

,

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{Y_{k}(u)-Y_{k}(v)}{\varphi(|u-v|)}\geq 2Y_{k}^{1/2}(d),\hskip 14.45377pta.s.

(2.17)

This is because, (
2.17

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{Y_{k}(u)-Y_{k}(v)}{\varphi(|u-v|)}\geq 2\sup_{d\in\Delta^{\prime}}Y_{k}^{1/2}(d),\hskip 14.45377pta.s.

(2.18)

which implies (
2.16
).

Let
u,v,d\in\Delta
. We write,

\displaystyle\eta_{i}^{2}(u)-\eta_{i}^{2}(v)

\displaystyle=

\displaystyle(\eta_{i}(u)-\eta_{i}(v))(\eta_{i}(u)+\eta_{i}(v))

(2.19)

\displaystyle=

\displaystyle(\eta_{i}(u)-\eta_{i}(v))(2\eta_{i}(d)+(\eta_{i}(u)-\eta_{i}(d))+(\eta_{i}(v)-\eta_{i}(d))).

It follows from (
1.8
) that,

\displaystyle\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}(\eta_{i}(u)-\eta_{i}(v))(\eta_{i}(u)-\eta_{i}(d))}{\varphi(|u-v|)}

(2.20)

\displaystyle\qquad\leq\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}|\eta_{i}(u)-\eta_{i}(v)|\sup_{u\in\Delta}|\eta_{i}(u)-\eta_{i}(d)|}{\varphi(|u-v|)}

\displaystyle\qquad\leq\sum_{i=1}^{k}\sup_{u\in\Delta}|\eta_{i}(u)-\eta_{i}(d)|:=\Delta^{*}.

Therefore, using (
2.16
)–(
2.20
) and (
2.11
) with 0 replaced by

we see that,

\displaystyle\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{Y_{k}(u)-Y_{k}(v)}{\varphi(|u-v|)Y^{1/2}_{k}(d)}

(2.21)

\displaystyle\qquad\geq\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{2\sum_{i=1}^{k}(\eta_{i}(u)-\eta_{i}(v))\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}-\frac{2\Delta^{*}}{\|\vec{\eta}(d)\|_{2}}.

To simplify the notation we take
V(u,v)={U(u,v)}/{U(d,d)}
.
Write

\eta_{i}(u)-\eta_{i}(v)=V(v,d)\eta_{i}(u)-V(u,d)\eta_{i}(v)+G_{i}(u,v),

(2.22)

where,

G_{i}(u,v)=(1-V(v,d))\eta_{i}(u)-(1-V(u,d))\eta_{i}(v).

(2.23)

In this notation,

\displaystyle\frac{\sum_{i=1}^{k}(\eta_{i}(u)-\eta_{i}(v))\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}-\frac{\sum_{i=1}^{k}G_{i}(u,v)\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}

\displaystyle\qquad=\frac{\sum_{i=1}^{k}\left(V(v,d)\eta_{i}(u)-V(u,d)\eta_{i}(v)\right)\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}.

(2.24)

Note that for all
u,v\in[0,1],

E\left((V(v,d)\eta_{i}(u)-V(u,d)\eta_{i}(v))\eta_{i}(d)\right)=0.

This shows that
\eta_{i}(d)
is independent of
\{V(v,d)\eta_{i}(u)-V(u,d)\eta_{i}(v);u,v\in[0,1]\}
. Therefore by (
2.7
),

\displaystyle\Big\{\sum_{i=1}^{k}(V(v,d)\eta_{i}(u)-V(u,d)\eta_{i}(v))\frac{\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}};\quad u,v\in[0,1]\Big\}

(2.25)

\displaystyle\qquad\stackrel{{\scriptstyle law}}{{=}}\Big\{V(v,d)\eta(u)-V(u,d)\eta(v);\quad u,v\in[0,1]\Big\}.

It follows that,

\displaystyle\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}(\eta_{i}(u)-\eta_{i}(v))\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}

(2.26)

\displaystyle\qquad\qquad+\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}|G_{i}(u,v)||\eta_{i}(d)|}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}

\displaystyle\qquad\stackrel{{\scriptstyle law}}{{\geq}}\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{V(v,d)\eta(u)-V(u,d)\eta(v)}{\varphi(|u-v|)}.

Using (
2.22
) we can write,

\displaystyle\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{V(v,d)\eta(u)-V(u,d)\eta(v)}{\varphi(|u-v|)}

\displaystyle\qquad\geq\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{(\eta(u)-\eta(v))}{\varphi(|u-v|)}-\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{|G(u,v)|}{\varphi(|u-v|)}

\displaystyle\qquad=1-\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{|G(u,v)|}{\varphi(|u-v|)},

where

G(u,v)=(1-V(v,d))\eta(u)-(1-V(u,d))\eta(v)

(2.28)

and we use (

It follows from (

\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}(\eta_{i}(u)-\eta_{i}(v))\eta_{i}(d)}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}\geq 1-{\cal H},

where,

{\cal H}=\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{\sum_{i=1}^{k}|G_{i}(u,v)||\eta_{i}(d)|}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}+\lim_{h\to 0}\sup_{\stackrel{{\scriptstyle|u-v|\leq h}}{{u,v\in\Delta}}}\frac{|G(u,v)|}{\varphi(|u-v|)}

\frac{\sum_{i=1}^{k}|G_{i}(u,v)||\eta_{i}(d)|}{\|\vec{\eta}(d)\|_{2}\,\varphi(|u-v|)}\leq\frac{\sum_{i=1}^{k}|G_{i}(u,v)|}{\varphi(|u-v|)}.

(2.30)

where for notational convenience we have set

.

Lemma 2.1

|G(u,v)|\leq\frac{\sigma(d,v)}{U^{1/2}(d,d)}|\eta(u)-\eta(v)|+\frac{\sigma(u,v)}{U^{1/2}(d,d)}|\eta(v)|.

(2.41)

Proof:

We write,

G(u,v)=(1-V(v,d))(\eta(u)-\eta(v))+(V(u,d)-V(v,d))\eta(v).

Note that,

\displaystyle|(V(u,d)-V(v,d))|

\displaystyle=

\displaystyle\frac{|\left(E(\eta(u)-\eta(v))\eta(d)\right)|}{U(d,d)}

\displaystyle\leq

\displaystyle\frac{\left(E(\eta(u)-\eta(v))^{2}E\eta^{2}(d)\right)^{1/2}}{U(d,d)}

\displaystyle\leq

\displaystyle\frac{\sigma(u,v)}{U^{1/2}(d,d)},

and,

\displaystyle(1-V(v,d))

\displaystyle=

\displaystyle\frac{\left(E(\eta(d)-\eta(v))\eta(d)\right)}{U(d,d)}

\displaystyle\leq

\displaystyle\frac{\left(E(\eta(d)-\eta(v))^{2}E\eta^{2}(d)\right)^{1/2}}{U(d,d)}

\displaystyle\leq

Lemma 2.2

P\left(\sum_{i=1}^{k}\sup_{u\in\Delta}|\eta_{i}(u)-\eta_{i}(d)|\geq k((1+2C)\widetilde{\sigma}^{2}(|\Delta|)\log 1/|\Delta|)^{1/2}\right)\leq 2k|\Delta|^{C}.

(2.42)

Proof:

Let

a
be the median of
\sup_{u\in\Delta}(\eta_{1}(u)-\eta_{1}(d))
. It follows from
[
1
, Lemma 5.4.3]
that,

P\left(\sup_{u\in\Delta}|\eta_{1}(u)-\eta_{1}(d)|\geq\mathbf{a}+\widetilde{\sigma}(|\Delta|)t\right)\leq 2e^{-t^{2}/2}.

(2.43)

Since by
[
1
, (7.113)]
,

\mathbf{a}=o(\widetilde{\sigma}^{2}(|\Delta|)\log 1/|\Delta|)^{1/2},

(2.44)

we see that

P\left(\sup_{u\in\Delta}|\eta_{1}(u)-\eta_{1}(d)|\geq((1+2C)\widetilde{\sigma}^{2}(|\Delta|)\log 1/|\Delta|)^{1/2}\right)\leq 2|\Delta|^{C},

(2.45)

which gives (
2.42
).

Remark 2.1

When
\eta
has stationary increments,
\sigma^{2}(u,v)
in (
1.6
) can be written as

\sigma^{2}(u-v)
. For
x\in[0,\delta]
define,

\overline{\sigma}^{2}(x)=\mu\left(s:\sigma^{2}(x)\leq x\right),

where
\mu
is Lebesgue measure. Clearly,
\overline{\sigma}^{2}(x)
is an increasing function. It is called the increasing rearrangement of
\sigma^{2}(x)
. (See
[
1
, Section 6,4]
for more details.) We show in
[
1
, (6.138)]

that when
\eta
is continuous a.s.,

\lim_{x\to 0}\overline{\sigma}^{2}(x)\log(1/x)=0.

This shows that
if
\widetilde{\sigma}^{2}(x)
is asymptotic to an increasing function at 0, then (
1.8
), which implies that
\eta
is continuous a.s., implies (
1.7
).
