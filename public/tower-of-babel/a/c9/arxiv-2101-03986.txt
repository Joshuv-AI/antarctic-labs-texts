Abstract
. A deformed Donaldson–Thomas connection for a manifold with a Spin ⁡ ( 7 ) {\rm Spin}(7) -structure, which we call a Spin ⁡ ( 7 ) {\rm Spin}(7) -dDT connection, is a Hermitian connection on a Hermitian line bundle L L over a manifold with a Spin ⁡ ( 7 ) {\rm Spin}(7) -structure defined by fully nonlinear PDEs. It was first introduced by Lee and Leung as a mirror object of a Cayley cycle obtained by the real Fourier–Mukai transform and its alternative definition was suggested in our other paper. As the name indicates, a Spin ⁡ ( 7 ) {\rm Spin}(7) -dDT connection can also be considered as an analogue of a Donaldson–Thomas connection ( Spin ⁡ ( 7 ) {\rm Spin}(7) -instanton). In this paper, using our definition, we show that the moduli space ℳ Spin ⁡ ( 7 ) \mathcal{M}_{{\rm Spin}(7)} of Spin ⁡ ( 7 ) {\rm Spin}(7) -dDT connections has similar properties to these objects. That is, we show the following for an open subset ℳ Spin ⁡ ( 7 ) ′ ⊂ ℳ Spin ⁡ ( 7 ) \mathcal{M}^{\prime}_{{\rm Spin}(7)}\subset\mathcal{M}_{{\rm Spin}(7)} . (1) Deformations of elements of ℳ Spin ⁡ ( 7 ) ′ \mathcal{M}^{\prime}_{{\rm Spin}(7)} are controlled by a subcomplex of the canonical complex defined by Reyes Carrión by introducing a new Spin ⁡ ( 7 ) {\rm Spin}(7) -structure from the initial Spin ⁡ ( 7 ) {\rm Spin}(7) -structure and a Spin ⁡ ( 7 ) {\rm Spin}(7) -dDT connection. (2) The expected dimension of ℳ Spin ⁡ ( 7 ) ′ \mathcal{M}^{\prime}_{{\rm Spin}(7)} is finite. It is b 1 b^{1} , the first Betti number of the base manifold, if the initial Spin ⁡ ( 7 ) {\rm Spin}(7) -structure is torsion-free. (3) Under some mild assumptions, ℳ Spin ⁡ ( 7 ) ′ \mathcal{M}^{\prime}_{{\rm Spin}(7)} is smooth if we perturb the initial Spin ⁡ ( 7 ) {\rm Spin}(7) -structure generically. (4) The space ℳ Spin ⁡ ( 7 ) ′ \mathcal{M}^{\prime}_{{\rm Spin}(7)} admits a canonical orientation if all deformations are unobstructed.

Ideas used in the proof

The moduli space
{\mathcal{M}}^{\prime}_{{\text{\rm Spin}(7)}}
is defined
as a zero set of the so-called deformation map
{\mathcal{F}}_{\text{\rm Spin}(7)}
.
We introduce a new
{\text{\rm Spin}(7)}
-structure from the initial
{\text{\rm Spin}(7)}
-structure and a
{\text{\rm Spin}(7)}
-dDT connection
and describe the linearization of
{\mathcal{F}}_{\text{\rm Spin}(7)}
in a “nice way”.
Using this, we show that each deformation is controlled by a subcomplex of the canonical complex
introduced by Reyes Carrión
[
15
]
.
The idea is similar to that of
[
8
]
, but we need more sophisticated calculations in the
{\text{\rm Spin}(7)}
case.
We derive some formulas for
{\text{\rm Spin}(7)}
-geometry in Section
2
and Appendix
A
,
which do not seem to appear in the literature.
These formulas themselves would be interesting and useful for the study of
{\text{\rm Spin}(7)}
-geometry.

Orienting the moduli space is considered to be important to define enumerative invariants.
It is because we must count “with signs” to define enumerative invariants
and we need a canonical orientation of the moduli space to determine the signs.
The point in our case is that our new
{\text{\rm Spin}(7)}
-structures are connected in the space of
{\text{\rm Spin}(7)}
-structures to the initial
{\text{\rm Spin}(7)}
-structure
by construction.
Investigating this fact in more detail, we see that a family of Fredholm operators describing infinitesimal deformations is
homotopic to the trivial family in the space of Fredholm operators.
Then, the homotopy property of vector bundles implies that the determinant line bundle is trivial, and hence,
the moduli space is orientable.
