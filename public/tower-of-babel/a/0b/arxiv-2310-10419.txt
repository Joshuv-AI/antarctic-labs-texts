Inverse problem of correlation functions in holography and bulk reconstruction
Run-Qiu Yang

Abstract
This paper shows that the exterior of a planar/spherically/hyperbolically symmetric asymptotically anti-de Sitter static black brane/hole can be reconstructed from its boundary frequency 2-point correlation functions of arbitrary two probe scalar operators by solving a Gel’fand-Levitan-Marchenko integral equation. A method about how to solve this integral equation is also presented. Since the frequency correlation function is easily handled in experiments and theories, this paper not only proposes an explicit method to “directly measure” the corresponding holographic spacetime for a material that has holographic dual but also provides a powerful approach to experimentally check if a system has holographic dual.



1
Introduction

The mathematical expression of a physical law is usually a set of equations determined by the parameters and its solutions stand for the results which can be compared with observations. Deriving the “computed result” for a given set of parameters is called “solving the direct problem”. Conversely, obtaining the set of the parameters
from a given set of results is called “solving the inverse problem”. The “solving inverse problem” plays essential roles both in theoretical studies and in practice of applied holography
Maldacena:1997re
;
Gubser:1998bc
;
Witten:1998qj
;
Witten:1998zw
;
Zaanen2015
;
Baggioli:2019rrs
. In theoretical viewpoint, bulk reconstruction is the central question in understanding the emerging spacetime in holography and answers how the gravitational degrees of freedom emerge from field theory. In the viewpoint of application, it will help us to build holographic spacetime and theory more efficiently by directly from the observable data when we try to use holographic duality to deal with strongly coupling materials.

A few advances have been pushed forward towards this issue. When conformal dimension
\Delta
is much larger than spacetime dimensional
d
, boundary 2-point correlation functions can be expressed in terms of geodesics
Balasubramanian:1999zv
and so have been used to reconstruct the bulk geometry
Hubeny:2012ry
. However, the requirement
\Delta\gg d
restricts its application in practice since materials in general will not satisfy this requirement. There is also a method called “bulk-cone singularities”, which uses the relationship between singular correlators and bulk null geodesics to recover some special spherically symmetric static bulk geometries
Bilson:2008ab
;
Hammersley:2006cp
.
In most situations, the materials we are concerned about have planar structures. For those boundary systems, this method cannot be applied since the bulk null geodesics of planar symmetric static anti-de Sitter (AdS) black brane will no longer return to boundary again if they start from the boundary. What’s more, locating all singularities of correlator in boundary spacetime coordinates is also a huge challenge for measurements. Another well-known method of reconstruction is called “entanglement wedge reconstruction”, which uses the boundary entanglement spectrum to reconstruct bulk geometry and local observables
Dong:2016eik
;
Espindola:2018ozt
;
Penington:2019npb
. Such a reconstruction is given via proving its “existence” rather than explicitly giving the method of reconstruction. There are also some other approaches based on holographic entanglement entropy
Ryu:2006bv
;
Nishioka:2009un
;
Jokela:2020auu
, Wilson loop
Maldacena:1998im
;
Rey:1998ik
, tensor network
Swingle:2009bg
;
Pastawski:2015qua
or complexity
Susskind:2014rva
;
Susskind:2014jwa
;
Brown:2015bva
, e.g. see Refs.
Hashimoto:2020mrx
;
Hashimoto:2021umd
;
Xu:2023eof
;
Bilson:2010ff
;
Caputa:2017urj
;
Milsted:2018san
. In these approaches, some boundary quantities are conjectured to dual to some bulk geometric quantities and so give the chance to recover the bulk metric. It needs to be noted that except for a few of special systems (a recent such example for glue Yang-Mills theory has been discussed in Ref.
Jokela:2023yun
), it is still a challenge to experimentally measure the entanglement entropy or Wilson loop of general materials. The complexity currently is a “theoretical quantity” and the way to measure it is unclear. Taking all these into account, one may ask: is there a universal and explicit method to reconstruct the bulk geometry by experimentally measurable quantities of the dual materials?

This paper will give a positive answer. It will propose a new method about bulk reconstruction for a static asymptotically AdS black brane/hole by solving the inverse problem of 2-point correlation functions. This supplies a possibility to “directly measure” the corresponding holographic spacetime. The purpose of following parts is to present a proof of following theorem,

Theorem 1

For a stable planar symmetric static asymptotically AdS black brane, the bulk geometry can be reconstructed from the boundary frequency 2-point correlation functions of arbitrary two probe scalar operators that are dual to Klein-Gordon fields in the bulk.

It will also give explicit steps about how to reconstruct the bulk metric by using BTZ black hole as a concrete example. Here it uses the Klein-Gorden field to explain the main idea of this reconstruction. At the end of this paper, it will show that this requirement can be relaxed.

2
Overview on correlation function in holography

Before we present our proof on above theorem and the method of reconstructing bulk metric, let us first briefly review the “solving direct problem” of holographic 2-point correlation functions. We focus on the planar symmetric asymptotically AdS black brane, of which the metric will have following form

\textmd{d}s^{2}=\frac{1}{z(\rho)^{2}}[h(\rho)(-\textmd{d}t^{2}+\textmd{d}\rho^{2})+\textmd{d}\vec{x}^{2}_{d-1}],~~\rho\in\mathbb{R}^{+}\,.

(1)

The functions
h(\rho)
and
z(\rho)
will satisfy following boundary conditions

z(0)=0,~~z^{\prime}(0)=h(0)=1\,

(2)

and

z(\infty)=z_{h},~~h(\infty)=0\,.

(3)

The horizon then locates at
\rho\rightarrow\infty
and the AdS boundary locates at
\rho=0
.

When we consider the correlation function of scalar operator in holography, we consider a real probe scalar field
\Psi
which is described by Klein-Gorden equation
\nabla^{2}\Psi+m^{2}\Psi=0
in the bulk. Here
m^{2}
is the mass-square of the scalar field and is relative to the conformal dimension
\Delta
of boundary scalar operator
\mathcal{O}
such that
\Delta=d/2+\sqrt{d^{2}/4+m^{2}}
. In general, the asymptotical expansion of the scalar field near the AdS boundary has two independent branches,

\Psi=\Phi^{(+)}_{\Delta}\rho^{\Delta}(1+\cdots)+\Phi^{(-)}_{\Delta}\rho^{d-\Delta}(1+\cdots)\,.

(4)

Here we choose that so called “standard quantization”, which treats
\Phi^{(-)}_{\Delta}
as the source term of boundary theory and
\Phi^{(+)}_{\Delta}\sim\langle\mathcal{O}\rangle
as the value of expectation for boundary scalar operator. In some cases, we may have an alternative quantization by choosing
\Phi^{(+)}_{\Delta}
as the source, for which the conformal dimension of dual operator is
d-\Delta
. In the following discussion, we shall focus on the “standard quantization”. The generalization to alternative quantization is parallel. The Weyl anomaly coming from gravity is zero
Henningson:1998ey
;
deHaro:2000vlm
due the flatness of boundary. The Weyl anomaly of the matter sector will appear for some fine-tuned values of mass-square, so we will do not consider it here.

To compute the frequency 2-point correlation function of dual boundary scalar operator, we consider the bulk scalar field of a form
\Psi=z^{(d-1)/2}\phi(\rho)\textmd{e}^{-i\omega t}
on the fixed background (
1
). The Klein-Gordon equation then reads

-\frac{\textmd{d}^{2}\phi}{\textmd{d}\rho^{2}}+\left(V_{\Delta}+\frac{4m^{2}+d^{2}-1}{4\rho^{2}}\right)\phi=\omega^{2}\phi\,.

(5)

Here

\begin{split}V_{\Delta}&=-\frac{(d-1)z^{\prime\prime}}{2z}+\frac{(d^{2}-1)}{4}\left(\frac{z^{\prime 2}}{z^{2}}-\frac{1}{\rho^{2}}\right)+m^{2}\left(\frac{h}{z^{2}}-\frac{1}{\rho^{2}}\right)\,.\end{split}

(6)

Eq. (
5
) has four kinds of solutions
\{\psi_{\omega}(\rho),\psi_{\omega}(\rho)^{*},\varphi^{(+)}_{\omega}(\rho),\varphi^{(-)}_{\omega}(\rho)\}
. The
\{\psi_{\omega}(\rho),\psi_{\omega}(\rho)^{*}\}
are defined by following boundary conditions

\lim_{\rho\rightarrow\infty}\textmd{e}^{-i\omega\rho}\psi_{\omega}(\rho)=\lim_{\rho\rightarrow\infty}\textmd{e}^{i\omega\rho}\psi_{\omega}(\rho)^{*}=1\,.

(7)

The solutions
\{\varphi^{(\pm)}\}
are defined by following boundary conditions when
\rho\rightarrow 0^{+}

\varphi^{(\pm)}_{\omega}(\rho)=\rho^{1/2\pm v}[1+\mathcal{O}(\omega^{2}\rho^{2})]\,.

(8)

Here
v=\sqrt{d^{2}/4+m^{2}}=\Delta-d/2
. Due to the fact that Eq. (
5
) is 2nd order linear differential equation with real-valued coefficients, any one of above 4 types of solutions can be expressed in terms of linear combination of any other two. In the case that we consider the retarded Green function of holography, we impose the ingoing wave boundary condition
\Phi\propto\textmd{e}^{-i\omega(t-\rho)}
near the horizon. This leads to
\phi(\rho)\propto\psi_{\omega}(\rho)
. We then have

\psi_{\omega}(\rho)=\Phi^{(-)}_{\Delta}(\omega)\varphi_{\omega}^{(-)}(\rho)+\Phi^{(+)}_{\Delta}(\omega)\varphi_{\omega}^{(+)}(\rho)\,.

(9)

The frequency 2-point correlation function
\mathcal{G}(\omega)
is defined as
1
1

1

Here we omit an irrelevant factor that is determined by scaling dimension.

\mathcal{G}_{\Delta}(\omega)=\Phi^{(+)}_{\Delta}(\omega)/\Phi^{(-)}_{\Delta}(\omega)\,.

(10)

In the “solving direct problem” of correlation functions, what we have known is the metric functions
\{z(\rho),h(\rho)\}
and the purpose is to find the correlation function
\mathcal{G}_{\Delta}(\omega)
for a give conformal dimension
\Delta
.

For the purpose of proving Theorem
1
and following notations in Refs.
Chadan1989
;
Kravchenko2020
;
Kravchenko2021
, let us introduce a function
F_{\Delta}(\omega)
such that

F_{\Delta}(\omega)=\lim_{\rho\rightarrow 0^{+}}\frac{\sqrt{2\pi}(-\omega\rho)^{v-1/2}}{2^{v}\Gamma(v)}\textmd{e}^{i\pi(v-1/2)/2}\psi_{\omega}(\rho)\,.

(11)

This function plays an important role in reconstruction of potential
V_{\Delta}
, which is not determined by correlation function. However, this paper proves following lemma to relate it to correlation function,

Lemma 1

The modulus of
F_{\Delta}(\omega)
is completely determined by the correlation function

|F_{\Delta}(\omega)|^{2}=\frac{\pi|\omega/2|^{2v}v}{\Gamma(v+1)^{2}\Im[\mathcal{G}_{\Delta}(\omega)]}\,.

(12)

See appendix
A
for a proof.

3
“Solving the inverse problem” and bulk reconstruction

The “solving the inverse problem” of correlation functions then is to recover the metric functions
\{z(\rho),h(\rho)\}
from the correlation
\mathcal{G}_{\Delta}(\omega)
. Though our reconstruction will be performed in real-valued frequency, let us make a short discussion on mathematical property of analytical continuation in complex frequency.

The function
\psi_{\omega}(\rho)
is not square-integrable for a general
\omega\in\mathbb{C}
. However, there may be some special complex frequencies
\omega_{k}
such that
\Phi^{(-)}(\omega_{k})=0
. Such modes are called “quasi-normal modes (QNMs)”. The QNMs are related to the stability of the holographic system. Particularly, if there is a QNM
\omega_{k}
such that
\Im(\omega_{k})>0
, then the system will be unstable under perturbations since the scalar field
\Psi=z^{(d-1)/2}\phi(\rho)\textmd{e}^{-i\omega_{k}t}\propto\textmd{e}^{\Im(\omega_{k})t}
will grow exponentially. Instead, the system will be stable if no QNM has positive imaginary part. For those unstable QNMs we have following lemma

Lemma 2

If
\omega_{k}\in\mathbb{C}
is an unstable QNM, then
\psi_{\omega_{k}}
is square-integrable in the interval
(0,\infty)
. If
\psi_{\omega_{k}}
is square-integrable in the interval
(0,\infty)
, then
\omega_{k}
is a QNM and
\omega_{k}^{2}<0
.

A proof will be found in appendix
A
.

From this lemma we see that the system is stable if and only if there is no square-integrable solution for Eq. (
5
). In practice, the correlation function is measured according to linear response of the system to external perturbations. Then the system should be stable against the small perturbations otherwise the correlation function can not be obtained experimentally. Thus, it is natural to assume that Eq. (
5
)
has no square-integrable solution
. Under such an assumption, we will have following mathematical results to reconstruct effective potential (see the chapters 1-3 of Ref.
Chadan1989
for more details and explanations on its mathematical aspects)

V_{\Delta}(\rho)=2\frac{\textmd{d}}{\textmd{d}\rho}K_{\Delta}(\rho,\rho)\,.

(13)

The transmutation kernel
K_{\Delta}(\rho,\sigma)
is determined by the Gel’fand-Levitan-Marchenko integral equation

K_{\Delta}(\rho,\sigma)+\Omega_{\Delta}(\rho,\sigma)+\int_{0}^{\rho}K_{\Delta}(\rho,y)\Omega_{\Delta}(y,\sigma)\textmd{d}y=0

(14)

and function
\Omega_{\Delta}(\rho,\sigma)
is given by function
F_{\Delta}(\omega)
according to

\Omega_{\Delta}(\rho,\sigma)=\int_{0}^{\infty}\hat{J}_{v}(\omega\rho)\hat{J}_{v}(\omega\sigma)\left(\frac{1}{|F_{\Delta}(\omega)|^{2}}-1\right)\textmd{d}\omega\,.

(15)

Here
\hat{J}_{v}(x)=\sqrt{x}J_{v}(x)
and
J_{v}(x)
is the
v
-th order Bessel function of the first kind. When the system is not stable, i.e. correlation function has poles at upper complex plane, we still have similar results but the function
\Omega_{\Delta}(\rho,\sigma)
will be more complicated, see Refs.
Chadan1989
;
Kravchenko2020
;
Kravchenko2021
. According to Lemma
1
, the effective potential can be recovered from the correlation function.

Take
\mathcal{G}_{\Delta_{1}}(\omega)
and
\mathcal{G}_{\Delta_{2}}(\omega)
to be correlation functions of arbitrary two different real scalar operators. After we reconstruct their corresponding effective potentials
V_{\Delta_{1}}
and
V_{\Delta_{2}}
, the function
z(\rho)
will be determined by

\begin{split}\frac{m_{2}^{2}V_{\Delta_{1}}-m_{1}^{2}V_{\Delta_{2}}}{m_{2}^{2}-m_{1}^{2}}&=\frac{(d^{2}-1)}{4}\left(\frac{z^{\prime 2}}{z^{2}}-\frac{1}{\rho^{2}}\right)-\frac{(d-1)z^{\prime\prime}}{2z}\,.\end{split}

(16)

The function
h(\rho)
then is given by

h=\frac{V_{\Delta_{1}}-V_{\Delta_{2}}}{m_{1}^{2}-m_{2}^{2}}z^{2}+\frac{z^{2}}{\rho^{2}}\,.

(17)

Naively, one may think that we can solve Eq. (
16
) by using initial condition (
2
), i.e.
\{z(0)=0,z^{\prime}(0)=1\}
. However, such a Cauchy problem is ill-defined due to that the Eq. (
16
) is singular at
z=0
. From the physical viewpoint, this is because that the solution of above system is not unique but can be different up to a scaling transformation. Instead of solving Eq. (
16
) as a Cauchy problem, we solve this problem as a boundary-value-problem by requiring

\lim_{\rho\rightarrow 0^{+}}z/\rho=1,~~\text{and}~z(\infty)=z_{h}\,.

(18)

The first boundary condition insures metric is asymptotically AdS when
\rho\rightarrow 0^{+}
. Without losing generality, we can set “inverse horizon radius”
z_{h}=1
by using the scaling transformation. This setup fixes the scaling symmetry. The boundary-value-problem now is well defined and so we finished the proof of Theorem
1
.

4
Example of BTZ black hole

Let us consider the BTZ black hole as an example and exhibit how to recover the metric from its 2-point correlation functions. By setting the inverse horizon
z_{h}=1
, the BTZ black hole is given by
z(\rho)=\tanh\rho
and
h(\rho)=1/\cosh^{2}\rho
. The boundary 2-point correlation function is give by

\mathcal{G}_{\Delta}(\omega)=\frac{\Gamma(-v)\Gamma(\frac{1-i\omega+v}{2})^{2}}{\Gamma(v)\Gamma(\frac{1-i\omega-v}{2})^{2}}\,.

(19)

The correlation function has pole when
\omega_{k}=-i(1+v+2k)
with
k\in\mathbb{N}^{+}
. Thus there is no QNMs at upper complex plane and so no unstable QNM.

In following we will applied the “Fourier-Jacobi series representation” to solve Eq. (
14
). Since it may not be familiar to the potential readers of this paper, we here first briefly explain this method. For more mathematical aspects, one can refer to Refs.
Kravchenko2020
;
Kravchenko2021
and references therein.

Step 1
) We write the kernel into following series expansion

K_{\Delta}(\rho,\sigma)=\sum_{n=0}^{\infty}\frac{\beta_{n}(\rho)}{\rho^{v+3/2}}\sigma^{v+1/2}P_{n}^{(v,0)}(1-2\sigma^{2}/\rho^{2})\,,

(20)

where
P_{n}^{(\alpha,\beta)}
stands for the Jacobi polynomial. Introduce a matrix
A_{ln}
and an vector
B_{n}
such that

A_{ln}(\rho)=\int_{0}^{\infty}\frac{J_{v+1+2l}(\omega\rho)J_{v+1+2n}(\omega\rho)}{\omega\rho}\left(\frac{1}{|F_{\Delta}(\omega)|^{2}}-1\right)\textmd{d}\omega

(21)

and

B_{n}(\rho)=-\int_{0}^{\infty}J_{v}(\omega\rho)J_{v+1+2n}(\omega\rho)\left(\frac{1}{|F_{\Delta}(\omega)|^{2}}-1\right)\textmd{d}\omega\,.

(22)

Then Eq. (
14
) becomes a discrete form

\frac{\beta_{l}(\rho)}{2(2l+v+1)\rho}+\sum_{n=0}^{M}A_{ln}(\rho)\beta_{n}(\rho)=B_{l}(\rho)\,.

(23)

Here
l=0,1,2\cdots,M
with
M\rightarrow\infty
. To perform numerical computation, we can truncate system into a finite system by setting a finite
M
.

Step 2
) Discrete the coordinate
\rho
to be
\rho_{k}=k\delta\rho
. For every
\rho_{k}
, compute
B_{m}(\rho_{k})
and
A_{mn}(\rho_{k})
according to the formulas (
21
) and (
22
). One then solves the truncated system (
23
) to find
\beta_{0}(\rho_{k})
for every
\rho_{k}
.

Step 3
) Use the finite differential methods to obtain the
\beta^{\prime}_{0}(\rho_{k})
and
\beta^{\prime\prime}_{0}(\rho_{k})
based on the values of
\beta_{0}(\rho_{k})
. The effective potential at the
k
-th grid can be recovered according to

V_{\Delta}(\rho_{k})=\frac{\rho\beta_{0}^{\prime\prime}(\rho_{k})+(2v+1)\beta^{\prime}_{0}(\rho_{k})}{\rho_{k}[\beta_{0}(\rho_{k})+2(v+1)]}\,.

(24)

Step 4
) Repeat the steps (1)-(3) to obtain effective potentials
\{V_{\Delta_{1}},V_{\Delta_{2}}\}
for two different scaling dimension and then solve the differential equation (
16
) to obtain function
z(\rho_{k})
.

Step 5
) Take the solution
z(\rho_{k})
into Eq. (
17
) to obtain the function
h(\rho_{k})
.

Though here we discuss the BTZ black hole, above 5 steps are valid for general planar symmetric static asymptotically AdS spacetime.

In Fig.
1
we show the reconstructed metric components and their exact values. Here we choose the scaling dimensions of dual boundary theory to be
\Delta=5/3
and
\Delta=3/2
and only use 5 truncated equations (i.e. setting
M=4
). We see that the reconstructed method gives excellent results.

5
Summary and discussion

To summary, this paper considers the bulk reconstruction of metric from the viewpoint the “solving inverse problem” of correlation functions. It shows that a planar symmetric static asymptotically anti-de Sitter black brane can be reconstructed from 2-point correlation functions of two different probe scalar operators. By using BTZ black hole as a concrete example, we give a step-by-step method to recover the metric. Though the Theorem
1
and above discussion focused on real scalar field and planar symmetric case, the generalizations to other kinds of operators and spherical/hyperbolic symmetric case are straightforward.

The requirement that bulk field satisfies the Klein-Gorden equation can be relaxed. Consider a general Lagrangian of scalar field
L=-\frac{1}{2}[g^{\mu\nu}\partial_{\mu}\Psi\partial_{\nu}\Psi+m^{2}\Psi^{2}+W(\{X_{i}\},R_{\mu\nu\sigma\tau},g_{\mu\nu},\Psi)]
. Here the potential
W
of scalar field may depend on curvature tensor
R_{\mu\nu\sigma\tau}
, bulk metric
g_{\mu\nu}
and some others bulk matters fields
\{X_{i}\}
. To have a well-defined linear-response theory,
W
is required to satisfy
\partial W/\partial\Psi|_{\Psi=0}=0
. In this case, the linear-response theory in holography is given by tuning on an infinitesimal scalar source and Eq. (
5
) becomes

-\frac{\textmd{d}^{2}\phi}{\textmd{d}\rho^{2}}+\left(V_{\Delta}+\frac{4m^{2}+d^{2}-1}{4\rho^{2}}+\tilde{V}\right)\phi=\omega^{2}\phi\,.

(25)

with

\tilde{V}=\frac{h}{z^{2}}\left.\frac{\partial^{2}W}{\partial\Psi^{2}}\right|_{\Psi=0}\,.

(26)

In such a case, we can use three such operators of different
m^{2}
to reconstruct the metric components and potential
\tilde{V}
. Though the Theorem
1
and above discussion focused on real scalar field and planar symmetric case, the generalizations to other kinds of operators and spherical/hyperbolic symmetric case are straightforward.

From the above discussions, one can realize that the boundary 2-point correlation functions of fields that only couple with gravity are not independent. In addition, the entanglement entropy of large-
c
limit in holography is completely determined by bulk metric
Ryu:2006bv
;
Nishioka:2009un
, so it can also be determined by the boundary 2-point correlation functions. These seem to uncover that there may be a deep underlying unknown structure hidden in the holography, which is worth of being understood further. On the other hand, one can use different operators to probe the material. To have a holographic dual for this material, the metrics reconstructed from these different correlation functions must be the same. The result in this paper then not only proposes an explicit method to build a holographic spacetime for a material that has holographic dual but also provides a powerful approach to check if a material has holographic dual.

In fact, the correlation functions belong to the scattering matrix of bulk theory. For the case of less symmetries, it is unclear about how to recover the bulk geometry from its scattering matrix. However, the results of Refs.
Barreto
;
Joshi2000
;
doi:10.1142/e040
;
Hora2015
show that the Euclidean asymptotically AdS manifold and its metric, up to invariants, are determined by the scattering matrix at all energies. This implies, at least the general static asymptotically AdS black brane/hole (only in this case Wick rotation to Euclidean signature is unambiguous) is determined by its boundary correlation functions

Appendix A
Proof on Lemmas 1 and 2

Proof of Lemma 1

Apart from Eq. (
9
), we can also expand solutions
\varphi_{\omega}^{(\pm)}(\rho)
in terms of the combinations of
\{\psi_{\omega}(\rho),\psi_{\omega}(\rho)^{*}\}

\varphi_{\omega}^{(+)}(\rho)=\frac{i}{2\omega}\left[C_{\Delta}^{(+)}(\omega)\psi_{\omega}(\rho)^{*}-C_{\Delta}^{(+)*}(\omega)\psi_{\omega}(\rho)\right]\,

(27)

and

\varphi_{\omega}^{(-)}(\rho)=\frac{1}{2\omega}\left[C_{\Delta}^{(-)}(\omega)\psi_{\omega}(\rho)^{*}+C_{\Delta}^{(-)*}(\omega)\psi_{\omega}(\rho)\right]\,.

(28)

From boundary conditions (
7
) we can find

\psi_{\omega}(\rho)^{*}=\psi_{-\omega}(\rho)\,.

(29)

for
\omega\in\mathbb{R}
. From the fact that Eq. (
5
) is invariant under transformation
\omega\rightarrow-\omega
, we will see that

\varphi^{(\pm)}_{\omega}(\rho)=\varphi^{(\pm)}_{-\omega}(\rho)=\varphi^{(\pm)}_{\omega}(\rho)^{*}\,

(30)

for
\omega\in\mathbb{R}
.

We can solve the
\psi_{\omega}
from Eqs. (
27
) and (
28
). Take Eq. (
9
) into account and we then find

\begin{split}\Phi^{(+)}_{\Delta}&=\frac{-2i\omega C_{\Delta}^{(-)*}}{C_{\Delta}^{(-)}C_{\Delta}^{(+)*}+C_{\Delta}^{(-)*}C_{\Delta}^{(+)}}\\
\Phi^{(-)}_{\Delta}&=\frac{2\omega C_{\Delta}^{(+)*}}{C_{\Delta}^{(-)}C_{\Delta}^{(+)*}+C_{\Delta}^{(-)*}C_{\Delta}^{(+)}}\,.\end{split}

(31)

The correlation function
\mathcal{G}(\omega)
then is given by

\mathcal{G}_{\Delta}(\omega)=\frac{\Phi^{(+)}_{\Delta}(\omega)}{\Phi^{(-)}_{\Delta}(\omega)}=-i\frac{C_{\Delta}^{(-)}(\omega)^{*}}{C_{\Delta}^{(+)}(\omega)^{*}}\,.

(32)

Let us define Wronskian determinate
W[f,g]=fg^{\prime}-f^{\prime}g
. For any two solutions of Eq. (
5
), their Wronskian is constant. We now compute
W[\psi_{\omega},\psi_{-\omega}]
at the infinity and
W[\varphi^{(+)}_{\omega},\varphi^{(-)}_{\omega}]
at AdS boundary. The results then read

W[\psi_{\omega},\psi_{-\omega}]=-2i\omega,~~W[\varphi^{(+)}_{\omega},\varphi^{(-)}_{\omega}]=-2v\,.

(33)

The function
C_{\Delta}^{(\pm)}(\omega)
can also be determined according to Wronskian determinate

C_{\Delta}^{(+)}(\omega)=W[\psi_{\omega},\varphi_{\omega}^{(+)}],~~C_{\Delta}^{(-)}(\omega)=iW[\psi_{\omega},\varphi_{\omega}^{(-)}]\,.

(34)

These can be verified by using Eqs. (
27
), (
27
) and (
33
). Using the asymptotically behavior Eq. (
8
) and computing Eq. (
34
) near
\rho=0
, we can find

C_{\Delta}^{(+)}(\omega)=2v\lim_{\rho\rightarrow 0^{+}}\rho^{v-1/2}\psi_{\omega}(\rho)

(35)

if
v>0.

We note from Eqs. (
27
) and (
28
) that

\begin{split}W[\varphi^{(+)}_{\omega},\varphi^{(-)}_{\omega}]&=\frac{i}{4\omega^{2}}W[\psi_{-\omega},\psi_{\omega}]\left(C_{\Delta}^{(-)}(\omega)C_{\Delta}^{(+)}(\omega)^{*}+C_{\Delta}^{(-)}(\omega)^{*}C_{\Delta}^{(+)}(\omega)\right)\,.\end{split}

(36)

Thus, we obtain

C_{\Delta}^{(-)}(\omega)C_{\Delta}^{(+)}(\omega)^{*}+C_{\Delta}^{(-)}(\omega)^{*}C_{\Delta}^{(+)}(\omega)=4v\omega\,.

(37)

On the other hand, Eq. (
32
) shows

C_{\Delta}^{(-)}(\omega)=i\mathcal{G}(\omega)^{*}C_{\Delta}^{(+)}(\omega)\,.

(38)

Take it into Eq. (
37
) and we will find

|C_{\Delta}^{(+)}(\omega)|^{2}=2v\omega/\Im[\mathcal{G}_{\Delta}(\omega)]\,.

(39)

The function
F_{\Delta}(\omega)
is defined as

F_{\Delta}(\omega)=\lim_{\rho\rightarrow 0^{+}}\frac{\sqrt{2\pi}(-\omega\rho)^{v-1/2}}{2^{v}\Gamma(v)}\textmd{e}^{i\pi(v-1/2)/2}\psi_{\omega}(\rho)\,.

(40)

Then we see that the function
