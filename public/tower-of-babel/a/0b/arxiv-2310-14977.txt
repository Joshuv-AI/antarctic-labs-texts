Abstract
Traditionally in the turnstile model of data streams, there is a state vector x = ( x 1 , x 2 , … , x n ) x=(x_{1},x_{2},\ldots,x_{n}) which is updated through a stream of pairs ( i , k ) (i,k) where i ∈ [ n ] i\in[n] and k ∈ ℤ k\in\mathbb{Z} . Upon receiving ( i , k ) (i,k) , x i ← x i + k x_{i}\leftarrow x_{i}+k . A distinct count algorithm in the turnstile model takes one pass of the stream and then estimates ‖ x ‖ 0 = | { i ∈ [ n ] ∣ x i ≠ 0 } | \|x\|_{0}=|\{i\in[n]\mid x_{i}\neq 0\}| (aka L 0 L_{0} , the Hamming norm). In this paper, we define a finite-field version of the turnstile model. Let F F be any finite field. Then in the F F -turnstile model, for each i ∈ [ n ] i\in[n] , x i ∈ F x_{i}\in F ; for each update ( i , k ) (i,k) , k ∈ F k\in F . The update x i ← x i + k x_{i}\leftarrow x_{i}+k is then computed in the field F F . A distinct count algorithm in the F F -turnstile model takes one pass of the stream and estimates ‖ x ‖ 0 ; F = | { i ∈ [ n ] ∣ x i ≠ 0 F } | \|x\|_{0;F}=|\{i\in[n]\mid x_{i}\neq 0_{F}\}| . We present a simple distinct count algorithm, called F F - PCSA , in the F F -turnstile model for any finite field F F . The new F F - PCSA algorithm takes m ​ log ⁡ ( n ) ​ log ​ ( | F | ) m\log(n)\log(|F|) bits of memory and estimates ‖ x ‖ 0 ; F \|x\|_{0;F} with O ⁡ ( 1 m ) O(\frac{1}{\sqrt{m}}) relative error where the hidden constant depends on the order of the field. F F - PCSA is straightforward to implement and has several applications in the real world with different choices of F F . Most notably, • 𝔽 2 \mathbb{F}_{2} - PCSA can be used to estimate the number of non-zero elements in a boolean system where every element has a boolean state which can be toggled during a stream of updates; • 𝔽 2 k \mathbb{F}_{2^{k}} - PCSA can be used to estimate the number of non-zero elements in a k k -boolean system where every element has a vector of k k boolean attributes which can be individually toggled during a stream of updates; • 𝔽 p \mathbb{F}_{p} - PCSA can be used to implement simple and efficient L 0 L_{0} -estimation algorithms in the (original) turnstile model, making the probabilistic counting with deletions conceptually no harder than the probabilistic counting without deletions. With different schemes to select p p , one gets different upper bounds. To get a ( 1 ± ϵ ) (1\pm\epsilon) -estimation of L 0 L_{0} with 1/3 error probability, one needs – O ⁡ ( ϵ − 2 ​ log ⁡ n ⋅ ( log ⁡ ϵ − 1 + log ⁡ log ⁡ ‖ x ‖ ∞ ) ) O(\epsilon^{-2}\log n\cdot(\log\epsilon^{-1}+\log\log\|x\|_{\infty})) bits, matching the state of the art L 0 L_{0} -estimation algorithm by Kane, Nelson and Woodruff [ 9 ] ; – O ⁡ ( ϵ − 2 ​ log ⁡ n ⋅ log ⁡ ‖ x ‖ ∞ ) O(\epsilon^{-2}\log n\cdot\log\|x\|_{\infty}) bits, which is useful when the maximum frequency is small; – O ⁡ ( ϵ − 2 ​ log ⁡ n ⋅ max ⁡ ( log ⁡ ‖ x ‖ 1 ‖ x ‖ 0 , log ⁡ ϵ − 1 ) ) O(\epsilon^{-2}\log n\cdot\max(\log\frac{\|x\|_{1}}{\|x\|_{0}},\log\epsilon^{-1})) bits, which is useful when the average non-zero frequency is low. The upper bounds above can be further sharpened by ignoring the top O ⁡ ( ϵ ) O(\epsilon) -fraction of elements with non-zero frequencies.

Introduction

Distinct-Count
is the problem of approximately counting the number of distinct elements in a stream. In 1983, Flajolet and Martin
[
8
]
proposed the first streaming Distinct-Count algorithm, Probabilistic Counting with Stochastic Averaging (
PCSA
). Although being the first streaming Distinct-Count algorithm in history, the
PCSA
sketch already possesses two fundamental characteristics that are desirable when counting distinct elements.

•

“Zero knowledge”. The distribution of
PCSA
’s memory state depends only on the cardinality of the stream.

•

“Scale invariance”. The behavior of the sketch is multiplicatively periodic in the cardinality.

However,
PCSA
only works in the
incremental
setting, in which only insertions are allowed.

Definition 1

(incremental setting)
.

Let
U=\{1,2,\ldots,n\}
be the universe (e.g. the set of IPv4 addresses).
The state vector
x=(x_{1},x_{2},\ldots,x_{n})\in\mathbb{N}^{n}
is initialized as all zeros and gets updated by a stream of pairs in the form of
(v,k)

v\in U
and
k\in\mathbb{N}

•

Upon receiving
(v,k)

x_{v}\leftarrow x_{v}+k

A streaming Distinct-Count algorithm in the incremental setting takes one pass of the stream and estimates
\|x\|_{0}=|\{v\in U:x_{v}\neq 0\}|
(aka cardinality,
F_{0}
), i.e., the number of elements that have non-zero frequency.

The key insight.

The application of a streaming model is intimately related to the

The algebraic structure of finite fields brings us the following properties.

Lemma 1
.

Let
F
be a finite field. Then the uniform distribution over

is well-defined.

Let

\displaystyle aR_{1}\sim R_{1}

(1)

\displaystyle\sum_{i=1}^{k}R_{i}\sim R_{1}.

(2)

Proof.

The uniform distribution over a finite field

Since

\displaystyle\mathbb{P}(aR_{1}=b)=\mathbb{P}(R_{1}=ba^{-1})=\frac{1}{|F|}.

Thus (

\displaystyle\mathbb{P}(R_{1}+R_{2}=b)

\displaystyle=\sum_{c\in F}\frac{1}{|F|}\mathbb{P}(R_{1}+c=b)

since every element

\displaystyle=\sum_{c\in F}\frac{1}{|F|}\mathbb{P}(R_{1}=b-c)=\sum_{c\in F}\frac{1}{|F|^{2}}=\frac{1}{|F|},

∎

2.1
Simplification Assumptions

Assumption 1

(random oracle)
.

There is a random oracle that provides ideal hash functions
h
and
g
.

Assumption 2

(poissonization)
.

Since we only care about the cases where
\|x\|_{0}
is in the middle range (see the Middle Range Assumption in Section
1.3
), we may assume the following.

•

Since every element is hashed to only one table entry (through the hash function
h(\cdot)
), there are negligible negative correlations between table entries. For example, if there is only one non-zero element, then a non-zero entry necessarily implies that all other entries are zeros. However, this correlation vanishes when
\|x\|_{0}\gg 1
and thus we will assume all the entries in FIELDMAP are
strictly
independent. I.e. when a new element comes in, instead of being hashed to only one entry, now every entry
(i,j)
has an independent chance of
\frac{1}{m}2^{-j}
to be hashed to.

•

The probability that one hits the
(i,j)
entry is
\frac{1}{m}2^{-j}
which goes to
1-e^{-\frac{1}{m}2^{-j}}
as
j
becomes large. Since
\|x\|_{0}\gg 1
and the highest index is likely to be large, we will assume the probability of hitting the
(i,j)
entry is
exactly

1-e^{-\frac{1}{m}2^{-j}}
.

•

Since
\|x\|_{0}
is assumed to be in the middle range, we assume that the columns are indexed by
integers
, extending infinitely to both ends. E.g. the probability of hitting the
(i,-3)
entry is now assumed to be
1-e^{-\frac{2^{3}}{m}}
.

Remark 6
.

This assumption is called “poissonization” since it essentially assumes that elements are inserted
continuously
into the sketch with rate 1, which is why the entries are independent and the
(i,j)
entry has a hitting probability
1-e^{-\frac{1}{m}2^{-j}}
. Poissonization doesn’t affect the statistics of high-positioned entries when
\|x\|_{0}
becomes mildly large, which can be shown by a standard coupling method.

There is another difficulty during the analysis of such estimators: The behavior of the estimator has constant fluctuations which do
not
vanish even when
m
goes to infinity. See, for example, the analysis of
PCSA

[
8
]
and
HyperLogLog

[
7
]
where every statement has a periodic error term. See Figure 1 of
[
11
]
for a visualization of the fluctuation. As proposed in
[
11
]
, these fluctuations can be eliminated elegantly by
randomly offsetting
the subsketches.

Assumption 3

(random offsetting)
.

We assume that for each
i\in[m]
, there is a random offset
\Theta_{i}
uniformly drawn from
[0,1)
for the
i
th subsketch. Then the
i
th subsketch randomly ignores a
2^{-\Theta_{i}}
-fraction of the elements in the universe. Thus now the probability of hitting the
(i,j)
entry is
1-e^{-m^{-1}2^{-j-\Theta_{i}}}
.

Remark 7
.

A
PCSA
-style sketch is inherently multiplicatively periodic in
2
and therefore one will get the same relative behaviour for
\|x\|_{0}=2^{k}
with different
k\in\mathbb{N}
. However, the sketch will have different behaviours for e.g.
\|x\|_{0}=2^{k}
and
\|x\|_{0}=2^{k+0.5}
. The random offsetting assumption adds noise to this process, thus making the sketch now has an “averaged” behaviour for any
\|x\|_{0}\in\mathbb{R}^{+}
. Note that this random offsetting trick is
necessary to be actually implemented
if the required error is comparable to the fluctuation magnitudes (usually small, e.g.
<10^{-6}
for
PCSA

[
8
]
).

With all the assumptions above, we reconstruct the
F
-
PCSA
sketch (Definition
6
) in the following subsection.

Theorem 1

(characterization of
F
-
PCSA
’s state)
.

Fix a stream state

\theta\in[0,1)
. Let the memory state be
S=(S_{i})_{i\in\mathbb{Z}}
.
3
3

3

We capitalize the memory state
s
when we emphasize it as a
random vector
for a fixed stream state
x
.
Then

•

S_{i}
s are mutually independent.

•

\mathbb{P}(S_{i}\neq 0)=(1-e^{-\|x\|_{0}m^{-1}e^{-i-\theta}})(1-|F|^{-1})
, for
i\in\mathbb{Z}
.

Proof.

By construction, the memory state
S
and the stream state
x
are linearly related:

\displaystyle S_{i}=\sum_{v\in U}x_{v}H_{v,i}G_{v,i}.

(3)

Consequently,
S_{i}
s are independent due to the independence of entries of
H
and
G
.

Recall that
G_{v,i}
s are i.i.d. uniform random variables over
F
. By Lemma
1
, we have

\displaystyle S_{i}

\displaystyle=\sum_{v\in U}x_{v}H_{v,i}G_{v,i}=\sum_{v\in U:x_{v}H_{v,i}\neq 0}x_{v}H_{v,i}G_{v,i}

\displaystyle\sim\mathbbm{1}\left[\exists v,x_{v}H_{v,i}\neq 0\right]R_{i},

where
R_{i}
is uniformly random over
F
. Thus we know

\displaystyle\mathbb{P}(S_{i}\neq 0)

\displaystyle=\mathbb{P}(\exists v,x_{v}H_{v,i}\neq 0)\mathbb{P}(R_{i}\neq 0)

\displaystyle=(1-\mathbb{P}(\forall v,x_{v}H_{v,i}=0))(1-|F|^{-1})

\displaystyle=(1-\prod_{v\in U}\mathbb{P}(x_{v}H_{v,i}=0))(1-|F|^{-1})

(4)

Recall that
H_{v,i}
is a binary random variable with probability
e^{-2^{-i/m-\theta}}
of being 0. Since
F
is a field,
x_{v}H_{v,i}=0
if and only if
(H_{v,i}=0\lor x_{v}=0)
. Thus

\displaystyle\mathbb{P}(x_{v}H_{v,i}=0)=\begin{cases}1,&x_{v}=0\\
e^{-m^{-1}2^{-i-\theta}},&x_{v}\neq 0\end{cases},

and then by (
4
),

\displaystyle\mathbb{P}(S_{i}\neq 0)

\displaystyle=(1-e^{-\|x\|_{0}m^{-1}2^{-i-\theta}})(1-|F|^{-1}).

Definition 8

Let

\displaystyle\mathbb{P}(B\leq i|\Theta=\theta)=\prod_{j=i+1}^{\infty}\mathbb{P}(S_{j}=0)=\prod_{j=i+1}^{\infty}\left(1-(1-e^{-\|x\|_{0}m^{-1}2^{-j-\theta}})(1-|F|^{-1})\right)

3.1
A Matching Upper Bound with Kane, Nelson and Woodruff’s
L_{0}
-Estimation Algorithm

We will prove that it is possible to achieve the same space complexity of

-
L_{0}
(
[
9
]
) with
\mathbb{F}_{p}
-
PCSA
using a similar
p
-selection trick. Instead of bounding the probabilities of all the “bad events” as in
[
9
]
, for
\mathbb{F}_{p}
-
PCSA
we only need to estimate the difference between
\|x\|_{0}
and
\|x\|_{0;\mathbb{F}_{p}}
, where
\|x\|_{0}
is the quantity we
want
to estimate and
\|x\|_{0;\mathbb{F}_{p}}
is the quantity we
can
estimate accurately by
\mathbb{F}_{p}
-

.

Theorem 3
.

Let
\epsilon>0
be the desired error. Let
P
be a random prime uniformly drawn from the set
S
of the smallest
\frac{10\log\|x\|_{\infty}}{\epsilon}
primes. Then for any
x\in\mathbb{Z}^{n}

\displaystyle\|x\|_{0}\geq\|x\|_{0;\mathbb{F}_{P}},\quad\text{and}\quad\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}>\epsilon\|x\|_{0})\leq\frac{1}{10}.

Proof.

Since for any
a\in\mathbb{Z}
,
a=0
implies
a=0\mod P
, we have
\|x\|_{0}\geq\|x\|_{0;\mathbb{F}_{P}}
.

Imagine every element is placing balls in a set of bins indexed by
S
. Each element
v\in U
will place a ball in the bin indexed by
p\in S
if
p\mid x_{v}
. By randomly picking a prime
P
from the set
S
,
\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}
is equal to the number of element
v
with
P\mid x_{v}
, which is equal to the number of balls in the bin indexed by
P
.
Note that for every element
v\in U
,
x_{v}
has at most
\log\|x\|_{\infty}
distinct prime factors. Thus the number of balls is at most
\|x\|_{0}\log\|x\|_{\infty}
. As a result, the number of bins with at least
\epsilon\|x_{0}\|
balls is at most
\log\|x\|_{\infty}/\epsilon
(otherwise we run out of balls). We conclude that

\displaystyle\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}>\epsilon\|x\|_{0})

\displaystyle\leq\frac{\text{number of bins with at least $\epsilon\|x\|_{0}$ balls}}{\text{number of bins}}

\displaystyle\leq\frac{\log\|x\|_{\infty}/\epsilon}{{10\log\|x\|_{\infty}}/{\epsilon}}=1/10.

∎

Remark 9
.

In

-

, a random prime is picked in the range
[O(\frac{\log\|x\|_{\infty}}{\epsilon}),O((\frac{\log\|x\|_{\infty}}{\epsilon})^{3})]
. In contrast, we only need to pick a random prime in the range
[2,\tilde{O}(\frac{\log\|x\|_{\infty}}{\epsilon})]
for

To store a prime in Theorem
3
, one needs

,

-

gets the same space complexity

with

-
L_{0}
, to give a
(1\pm\epsilon)
-estimation of
L_{0}
with a constant error probability, but with a much smaller hidden constant.

3.2.1

Let

bits of memory.

3.2.2
O(\epsilon^{-2}\log n\cdot\max(\log(\frac{\|x\|_{1}}{\|x\|_{0}}),\log(\epsilon^{-1})))

Observe the following.

Theorem 4
.

Let
\epsilon>0
be the desired error.
Let
S=\{p_{1},p_{2},\ldots,p_{K}\}
be a set of
K
distinct primes such that
\min S\geq\|x\|_{1}/\|x\|_{0}
and
K\geq 10/\epsilon
. Let
P
be a random prime uniformly drawn from S. Then for any
x\in\mathbb{Z}^{n}
,

\displaystyle\|x\|_{0}\geq\|x\|_{0;\mathbb{F}_{P}},\quad\text{and}\quad\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}>\epsilon\|x\|_{0})\leq\frac{1}{10}.

Proof.

We only need to prove the second inequality.
Let
y_{k}=|\{v:p_{k}|x_{v},x_{v}\neq 0\}|
, i.e. the number of non-zero
x_{v}
s that have prime factor
p_{k}
. Without loss of generality, assume
x_{1},x_{2},\ldots,x_{\tau}
are positive and
x_{\tau+1},\ldots,x_{n}
are zeros. Then by the AM-GM inequality,

\displaystyle\frac{\sum_{i=1}^{\tau}x_{i}}{\tau}\geq\left(\prod_{i=1}^{\tau}x_{i}\right)^{\tau^{-1}}\geq\left(\prod_{i=1}^{K}p_{i}^{y_{i}}\right)^{\tau^{-1}}\geq p_{*}^{\tau^{-1}\sum_{i=1}^{K}y_{i}},

where
p_{*}=\min S
. Thus we have
\sum_{i=1}^{K}y_{i}\leq\tau\frac{\log(\|x\|_{1}/\tau)}{\log p_{*}}
.
Note that

\displaystyle\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}\geq\epsilon\|x\|_{0})

\displaystyle=\sum_{i=1}^{K}\frac{1}{K}\mathbbm{1}\left[y_{k}\geq\epsilon\|x\|_{0}\right]

where we use
\mathbbm{1}\left[y_{k}\geq\epsilon\|x\|_{0}\right]\leq\frac{y_{k}}{\epsilon\|x\|_{0}}
,

\displaystyle\leq\sum_{i=1}^{K}\frac{1}{K\epsilon\|x\|_{0}}y_{k}=\frac{1}{K\epsilon\|x\|_{0}}\sum_{i=1}^{K}y_{k}.

since
\sum_{i=1}^{K}y_{i}\leq\tau\frac{\log(\|x\|_{1}/\tau)}{\log p_{*}}

\displaystyle\leq\tau\frac{\log(\|x\|_{1}/\tau)}{\log p_{*}}\frac{1}{K\epsilon\|x\|_{0}}

by definition,
\tau=\|x\|_{0}

\displaystyle=\frac{\log(\|x\|_{1}/\|x\|_{0})}{\log p_{*}}\frac{1}{K\epsilon}

By assumption,
p_{*}=\min S\geq\|x\|_{1}/\|x\|_{0}
and
K\geq 10/\epsilon
. We conclude that
\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}\geq\epsilon\|x\|_{0})\leq 1/10
.
∎

To store a prime in Theorem
4
, one needs
\log(\tilde{O}(\max(\|x\|_{1}/\|x\|_{0},\epsilon^{-1})))
bits of space. Therefore, by choosing a random
p
with the scheme in Theorem
4
,
\mathbb{F}_{p}
-
PCSA
gets a new space complexity
O(\epsilon^{-2}\log n\cdot\max(\log(\frac{\|x\|_{1}}{\|x\|_{0}}),\log(\epsilon^{-1})))
to give a
(1\pm\epsilon)
-estimation of
L_{0}
with a constant error probability.

Note that
\|x\|_{1}/\|x\|_{0}
is precisely the
average non-zero frequency
. Thus this scheme is particularly space-saving in a system where the maximum frequency is unbounded but the average frequency is small.

Remark 10
.

Similar upper bounds can be proved in the same way with
\frac{\|x\|_{1}}{\|x\|_{0}}
replaced by
(\frac{\sum_{i=1}^{\tau}x_{i}^{\gamma}}{\|x\|_{0}})^{\gamma^{-1}}
for any
\gamma\in(0,1)
by realizing that
\frac{\sum_{i=1}^{\tau}x_{i}^{\gamma}}{\tau}\geq\left(\prod_{i=1}^{\tau}x_{i}\right)^{\gamma\tau^{-1}}
.

3.3
O(\epsilon)
-Mass Discount

Theorem 5
.

Given a state vector
x\in\mathbb{Z}^{n}
, without loss of generality, we assume

|x_{1}|\geq|x_{2}|\geq\ldots\geq|x_{\tau}|>0=|x_{\tau+1}|=\ldots=|x_{n}|,

where
\tau=\|x\|_{0}
. We define the
(\epsilon/2)
-mass discounted vector
x^{(\epsilon/2)}
as follows.

\displaystyle x^{(\epsilon/2)}_{i}

\displaystyle=0,\quad i\leq\epsilon\tau/2

\displaystyle x^{(\epsilon/2)}_{i}

\displaystyle=x_{i},\quad i>\epsilon\tau/2.

Suppose
P
is a random prime chosen by some scheme such that

\displaystyle\mathbb{P}(\|x^{(\epsilon/2)}\|_{0}-\|x^{(\epsilon/2)}\|_{0;\mathbb{F}_{P}}>\frac{\epsilon}{2}\|x^{(\epsilon/2)}\|_{0})

\displaystyle\leq\frac{1}{10},

then

\displaystyle\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}>\epsilon\|x\|_{0})

\displaystyle\leq\frac{1}{10}.

Proof.

By construction we have
\|x\|_{0}-\|x^{(\epsilon/2)}\|_{0}=\frac{\epsilon}{2}\|x\|_{0}
. Thus we have

\displaystyle\mathbb{P}(\|x\|_{0}-\|x\|_{0;\mathbb{F}_{P}}>\epsilon\|x\|_{0})

\displaystyle=\mathbb{P}(\|x^{(\epsilon/2)}\|-\|x\|_{0;\mathbb{F}_{P}}>\frac{\epsilon}{2}\|x\|_{0})

where we always have
\|x\|_{0;\mathbb{F}_{P}}\geq\|x^{(\epsilon/2)}\|_{0;\mathbb{F}_{P}}
and
\|x\|_{0}\geq\|x^{(\epsilon/2)}\|_{0}
, so

\displaystyle\leq\mathbb{P}(\|x^{(\epsilon/2)}\|-\|x^{(\epsilon/2)}\|_{0;\mathbb{F}_{P}}>\frac{\epsilon}{2}\|x^{(\epsilon/2)}\|_{0})\leq 1/10.

∎

This theorem formally proves that we may replace
x
by
x^{(\epsilon/2)}
in the upper bounds we derived earlier in this section.

Appendix A
Asymptotic Analysis

Lemma 4
.

Let
X_{r}
be a random variable with density
\nu(z,r)
and
r\in[1/2,1]
. Then
X_{r}
is sub-exponential. Specifically,

\displaystyle\mathbb{E}2^{|X_{r}|/6}<4.

Proof.

Note that

\displaystyle\mathbb{E}2^{|X_{r}|/6}=\int_{-\infty}^{0}2^{-z/6}\nu(z,r)\,dz+\int_{0}^{\infty}2^{z/6}\nu(z,r)\,dz.

We estimate the two parts separately. Note that
\nu(z,r)\leq(1-e^{-2^{-z}})
since
r\leq 1
.
We first estimate

\displaystyle\int_{0}^{\infty}2^{z/6}\nu(z,r)\,dz

\displaystyle\leq\int_{0}^{\infty}2^{z/6}(1-e^{-2^{-z}})\,dz<2

Note that since
r\in[1/2,1]
,
\nu(z,r)\leq\prod_{j=1}^{\infty}(1-(1-e^{-2^{-z-j}})/2)
. Then we estimate

\displaystyle\int_{-\infty}^{0}2^{-z/6}\nu(z,r)\,dz\leq\int_{-\infty}^{0}2^{-z/6}\prod_{j=1}^{\infty}(1-(1-e^{-2^{-z-j}})/2)\,dz<2

We conclude that

\displaystyle\mathbb{E}2^{|X_{r}|/6}<2+2=4,

(8)

from which we know
X_{r}
is sub-exponential.
∎

Lemma 5
.

Let
X_{r}
be a random variable with density
\nu(z,r)
and
r\in[1/2,1]
. Then

\displaystyle\log\mathbb{E}e^{tX_{r}}

\displaystyle=t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{V}X_{r}+O(t^{3}),\quad t\to 0

Proof.

Note that by the definition of the exponential function,

\displaystyle\mathbb{E}e^{tX_{r}}=\sum_{k=0}^{\infty}\frac{t^{k}}{k!}\mathbb{E}X_{r}^{k}=1+t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2}+\sum_{k=3}^{\infty}\frac{t^{k}}{k!}\mathbb{E}X_{r}^{k}.

We want to prove
\mathbb{E}e^{tX_{r}}=1+t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2}+O(t^{3})
as
t\to 0
. Then we need to bound the moments
\mathbb{E}|X_{r}|^{k}
.
Since
X_{r}
is sub-exponential (Lemma
4
), we can bound the moments in a standard way.
For
k\geq 1
,

\displaystyle\mathbb{E}|X_{r}|^{k}

\displaystyle=\mathbb{E}(2^{|X_{r}|/6}\cdot 2^{-|X_{r}|/6}|X_{r}|^{k})=\int 2^{z/6}\cdot(2^{-z/6}z^{k})\,d\mu_{|X_{k}|}

(9)

\displaystyle\leq\int 2^{z/6}\cdot\sup_{s\geq 0}(2^{-s/6}s^{k})\,d\mu_{|X_{k}|}=\mathbb{E}2^{|X_{r}|/6}\sup_{s\geq 0}(2^{-s/6}s^{k}),

(10)

where
\sup_{s\geq 0}(2^{-s/6}s^{k})=e^{-k}(6k/\log 2)^{k}
. Thus by Lemma
4
and (
10
)

\displaystyle\mathbb{E}|X_{r}|^{k}\leq 4e^{-k}(6k/\log 2)^{k}<4\cdot 3.2^{k}\cdot k^{k},

(11)

Thus we have

\displaystyle|\mathbb{E}e^{tX_{r}}-(1+t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2})|

\displaystyle=\left|\sum_{k=3}^{\infty}\frac{t^{k}}{k!}\mathbb{E}X_{r}^{k}\right|\leq\sum_{k=3}^{\infty}\frac{t^{k}}{k!}\mathbb{E}|X_{r}|^{k}

\displaystyle\leq\sum_{k=3}^{\infty}\frac{t^{k}}{k!}4\cdot 3.2^{k}\cdot k^{k}

By Stirling’s formula, we know for
k\in\mathbb{N}
,

\displaystyle k!>\sqrt{2\pi k}(k/e)^{k}>e^{-k}k^{k}.

Thus

\displaystyle|\mathbb{E}e^{tX_{r}}-(1+t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2})|

\displaystyle\leq 4\sum_{k=3}^{\infty}t^{k}(3.2e)^{k}\leq 8t^{3}(3.2e)^{3},

as soon as
3.2et<1/2
.
Thus we have

\displaystyle\mathbb{E}e^{tX_{r}}

\displaystyle=1+t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2}+O(t^{3}),\quad t\to 0.

Note that
\log(1+x)=x-\frac{1}{2}x^{2}+O(x^{3})
as
x\to 0
. Since
X_{r}
is sub-exponential (Lemma
4
), both
|\mathbb{E}X_{r}|
and
\mathbb{E}X^{2}_{r}
are finite. Thus

\displaystyle\log\mathbb{E}e^{tX_{r}}

\displaystyle=t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{E}X_{r}^{2}-\frac{1}{2}t^{2}(\mathbb{E}X_{r})^{2}+O(t^{3})

\displaystyle=t\mathbb{E}X_{r}+\frac{t^{2}}{2}\mathbb{V}X_{r}+O(t^{3}),\quad t\to 0,

since
\mathbb{V}X_{r}=\mathbb{E}X_{r}^{2}-(\mathbb{E}X_{r})^{2}
.
∎

Theorem 6
.

Define
X_{r}
to be a random variable with density
\nu(z,r)
(see Definition
8
). Then for
r\in[1/2,1]
,

\displaystyle\phi(1/m,r)^{-m}

\displaystyle=2^{-\mathbb{E}X_{r}}+O(m^{-1})

\displaystyle\frac{\phi(2/m,r)^{m}}{\phi(1/m,r)^{2m}}

\displaystyle=1+(\log^{2}2)m^{-1}\mathbb{V}X_{r}+O(m^{-2}),\quad m\to\infty.

Furthermore, for any
r\in[1/2,1]
,
(\log^{2}2)\mathbb{V}X_{r}<79
.
We define
\psi_{\mathbb{E}}(|F|)=\mathbb{E}X_{1-|F|^{-1}}
and
\psi_{\mathbb{V}}(|F|)=\mathbb{V}X_{1-|F|^{-1}}
.

Proof.

By construction, we have
\phi(t,r)=\int_{-\infty}^{\infty}2^{tz}\nu(z,r)\,dz=\mathbb{E}2^{tX_{r}}
. Then we have

\displaystyle\log(\phi(1/m,r))

\displaystyle=\log\mathbb{E}2^{X_{r}/m}=\log\mathbb{E}e^{(\log 2)X_{r}/m}

by Lemma
5
, as
m\to\infty
,

\displaystyle=((\log 2)/m)\mathbb{E}X_{r}+\frac{((\log 2)/m)^{2}}{2}\mathbb{V}X_{r}+O(m^{-3}).

Thus we have

\displaystyle\log(\phi(1/m,r)^{-m})

\displaystyle=(-m)\log(\phi(1/m,r))

\displaystyle=(-m)\left(((\log 2)/m)\mathbb{E}X_{r}+\frac{(\log(2)/m)^{2}}{2}\mathbb{V}X_{r}+O(m^{-3})\right)

\displaystyle=-(\log 2)\mathbb{E}X_{r}+O(m^{-1}).

\displaystyle\log\left(\frac{\phi(2/m,r)^{m}}{\phi(1/m,r)^{2m}}\right)

\displaystyle=m\log(\phi(2/m,r))-2m\log(\phi(1/m,r))

\displaystyle=m\left((2(\log 2)/m)\mathbb{E}X_{r}+\frac{(2\log(2)/m)^{2}}{2}\mathbb{V}X_{r}+O(m^{-3})\right)

\displaystyle-2m\left(((\log 2)/m)\mathbb{E}X_{r}+\frac{(\log(2)/m)^{2}}{2}\mathbb{V}X_{r}+O(m^{-3})\right)

\displaystyle=(\log^{2}2)m^{-1}\mathbb{V}X_{r}+O(m^{-2}).

Note that
e^{x}=1+x+O(x^{2})
as
x\to 0
. Thus

\displaystyle\phi(1/m,r)^{-m}

\displaystyle=e^{-(\log 2)\mathbb{E}X_{r}+O(m^{-1})}=e^{-(\log 2)\mathbb{E}X_{r}}(1+O(m^{-1}))=2^{-\mathbb{E}X_{r}}+O(m^{-1}).

\displaystyle\frac{\phi(2/m,r)^{m}}{\phi(1/m,r)^{2m}}

\displaystyle=e^{(\log^{2}2)m^{-1}\mathbb{V}X_{r}+O(m^{-2})}=1+(\log^{2}2)m^{-1}\mathbb{V}X_{r}+O(m^{-2}).

Finally, to bound
\mathbb{V}X_{r}
, note that

\displaystyle\mathbb{V}X_{r}

\displaystyle=\mathbb{E}X_{r}^{2}-(\mathbb{E}X_{r})^{2}\leq\mathbb{E}X_{r}^{2}

by the moment bound (
11
)

\displaystyle\mathbb{E}X_{r}^{2}

\displaystyle\leq 4\cdot 3.2^{2}\cdot 2^{2}<164.

We conclude that
(\log^{2}2)\mathbb{V}X_{r}<79
.
∎
