Generation Function For One-loop Tensor Reduction
Bo Feng

Abstract
For loop integrals, the reduction is the standard method. Having an efficient way to find reduction coefficients is an important topic in scattering amplitudes. In this paper, we present the generation functions of reduction coefficients for general one-loop integrals with arbitrary tensor rank in numerator.

\displaystyle e^{2tx-t^{2}}=\sum_{n=0}^{\infty}H_{n}(x){t^{n}\over n!}~\,.~~~~

\displaystyle\psi_{1}(t)=\sum_{n=0}^{\infty}t^{n}(2\ell\cdot R)^{n}={1\over 1-t(2\ell\cdot R)}~\,,~~~~~~~\psi_{2}(t)=\sum_{n=0}^{\infty}{(2\ell\cdot R)^{n}t^{n}\over n!}=e^{t(2\ell\cdot R)}~\,.~~~~

analytically.

\displaystyle+{(6DK^{2}(K^{2}(D-2)+DM_{0}^{2})-2(D+2)(3D-2)K^{2}M_{1}^{2}+D(D+2)\widetilde{f}^{2})t^{3}\over 6(D-1)(K^{2})^{2}}p^{3}+..~~~

where we have defined

Here we have presented the general recursive algorithm. In the Appendix B, we will show that these recursion relations can be

3.3
The analytic solution

In previous subsection, we have present the solution using the series expansion. In this subsection, we will solve the two differential equations (

Let us start from (

\displaystyle=

\displaystyle K^{2}r-p^{2},~~~~~y=p~\,,~~~

The differential equation (

Now we consider the equation (

Thus using (

\displaystyle\left({4xK^{2}}\partial_{x}^{2}+2(D-1)K^{2}\partial_{x}+{t^{2}(f^{2}-4K^{2}M_{0}^{2})\over K^{2}}\right)c=\left(-t\xi_{K}\partial_{y}+{4t^{2}\xi_{R}K^{2}-t^{2}\xi_{K}f\over K^{2}}\right)h_{T}\,.~~~

Putting (

\displaystyle\left({4xK^{2}}\partial_{x}^{2}+2(D-1)K^{2}\partial_{x}+{t^{2}(f^{2}-4K^{2}M_{0}^{2})\over K^{2}}\right)G(x)

\displaystyle=

\displaystyle K^{2}e^{-{tf\over K^{2}}y}\left(-t\xi_{K}\partial_{y}+{4t^{2}\xi_{R}K^{2}-t^{2}\xi_{K}f\over K^{2}}\right)h_{T}(x,y)

Equation (

Having laid out the frame, we can use it to solve various generation functions.

which satisfies the differential equation (

\displaystyle=

\displaystyle K^{2}e^{-{tf\over K^{2}}y}t\left(\partial_{y}+{tf\over K^{2}}\right)h_{T}(x,y)

\displaystyle te^{-{tf\over K^{2}}y}\left\{-tf\left(\partial_{y}+{tf\over K^{2}}\right)h_{T}(x,y)+K^{2}\left(\partial^{2}_{y}+{tf\over K^{2}}\partial_{y}\right)h_{T}(x,y)\right.

one can check that (

\displaystyle\int_{0}^{y}dwe^{-{tf\over K^{2}}w}h_{T}(x,w)=\sum_{n=0}^{\infty}{(t^{2}M_{0}^{2})^{n}\over n!\left({D\over 2}\right)_{n}}\int_{0}^{y}dwe^{-{tf\over K^{2}}w}\left({x+w^{2}\over K^{2}}\right)^{n}~\,.~~

\displaystyle R({\alpha})\equiv\int_{0}^{T}due^{{\alpha}u}={1\over{\alpha}}e^{{\alpha}u}|_{0}^{T}={e^{{\alpha}T}-1\over{\alpha}}~\,,~~~

thus

\displaystyle\int_{0}^{T}due^{{\alpha}u}u^{n}={(-)^{n}n!\over{\alpha}^{n+1}}\left(e^{{\alpha}T}\lfloor e^{-{\alpha}T}\rfloor_{{\alpha}^{n}}-1\right)

\displaystyle=

\displaystyle{(-)^{n}n!\over{\alpha}^{n+1}}\left(e^{{\alpha}T}\left(e^{-{\alpha}T}-\sum_{i=n+1}^{\infty}{(-{\alpha}T)^{i}\over i!}\right)-1\right)={-(-)^{n}n!\over{\alpha}^{n+1}}e^{{\alpha}T}\sum_{i=n+1}^{\infty}{(-{\alpha}T)^{i}\over i!}~\,,~~~

\displaystyle\int_{0}^{T}due^{{\alpha}u}({\beta}+\gamma u^{2})^{N}=\sum_{i=0}^{N}{N!\over i!(N-i)!}{\beta}^{N-i}\gamma^{i}\int_{0}^{T}due^{{\alpha}u}u^{2i}

\displaystyle=

\displaystyle\sum_{i=0}^{N}{N!\over i!(N-i)!}{\beta}^{N-i}\gamma^{i}{-(2i)!\over{\alpha}^{2i+1}}e^{{\alpha}T}\sum_{j=2i+1}^{\infty}{(-{\alpha}T)^{j}\over j!}~\,.~~~

) we can evaluate (

\displaystyle\int_{0}^{y}dwe^{-{tf\over K^{2}}w}h_{T}(x,w)=ye^{-{tf\over K^{2}}y}\sum_{n=0}^{\infty}\sum_{j=0}^{\infty}\sum_{i=0}^{n}{\left({t^{2}M_{0}^{2}\over K^{2}}\right)^{n}\over\left({D\over 2}\right)_{n}}{(2i)!x^{n-i}y^{2i}\over i!(n-i)!}{\left({tfy\over K^{2}}\right)^{j}\over(j+2i+1)!}~\,.~~

\displaystyle G(x)

\displaystyle=

\displaystyle c_{2\to 1;\widehat{1}}(t,r,p,K^{2};M_{0},M_{1})

\displaystyle=

\displaystyle{1\over K^{2}}e^{{tf\over K^{2}}y}\sum_{n=0}^{\infty}\sum_{i=0}^{n-1}{\left({D-1\over 2}\right)_{i}\over n!\left({D-1\over 2}\right)_{n}\left({D\over 2}\right)_{i}}{f(M_{0}^{2})^{i}(t^{2}x)^{n}(4K^{2}M_{0}^{2}-f^{2})^{n-i-1}\over 4^{n-i}(K^{2})^{2n-i-1}}

This result can be checked with the one given in (

4
The general frame

Having the detail computations in the bubble, in this section we will set up the general frame to
find generation functions for general one-loop integrals with
(n+1)
propagators. The system has

n
external momenta
K_{i},i=1,...,n
and
(n+1)
masses

M_{j}^{2},j=0,1,...,n
. Using the auxiliary vector
R
we have
(n+1)

auxiliary scalar products (ASP)

r=R\cdot R
,
p_{i}=K_{i}\cdot R,i=1,...,n
. From the experience in the bubble, we know that these ASP’s are not good variables to solve differential equations produced by
\partial_{R}\cdot\partial_{R}
and
K_{i}\cdot\partial_{R},i=1,...,n
. Thus we will discuss how to find these good variables in the first subsection. Then we discuss the differential equations in these new variables in the second subsection and finally their solutions in the third subsection.

4.1
Finding good variables

We will denote the good variables by
x
and
y_{i},i=1,...,n
. To simplify the differential equations, we need to impose following conditions

\displaystyle(K_{i}\cdot\partial_{R})x=0,~~~~(K_{i}\cdot\partial_{R})y_{j}\sim\delta_{ij},~~~~~\forall i,j=1,...,n~\,.~~

(68)

To see there is indeed a solution for (
68
), let us define the Gram matrix
G
and the row vector
P^{T}
as

\displaystyle G_{ij}=K_{i}\cdot K_{j},~~~~(P^{T})_{i}=K_{i}\cdot R\,.~~~

(69)

Putting
y_{j}=\sum_{t}{\beta}_{jt}p_{t}
to (
68
), it is easy to see that the condition becomes

\displaystyle K_{i}\cdot\partial_{R}y_{j}=\sum_{t}{\beta}_{jt}(K_{t}\cdot K_{i})\sim\delta_{ij}\,,~~~

(70)

thus the matrix
{\beta}
can be solved as

\displaystyle{\beta}=|G|G^{-1}~\,,~~

(71)

where
|G|
is the Gram determinant. For
x
, let us assume

\displaystyle x=|G|r+P^{T}AP,~~~~A^{T}=A~\,.~~

(72)

Since

\displaystyle K_{i}\cdot\partial_{R}x

\displaystyle=

\displaystyle|G|2p_{i}+2(P^{T})_{R\to K_{i}}AP~\,,~~

(73)

where
P_{R\to K_{i}}
means to replace vector
R
by the vector
K_{i}
, when collecting all
i
together,
the right hand side of (
73
) is just
(2|G|I+2GA)P
, thus we have the solution

\displaystyle A=-|G|G^{-1}\,.~~~

(74)

Putting everything together, we finally have

\displaystyle x

\displaystyle=

\displaystyle|G|(r-P^{T}G^{-1}P),~~~~~~~Y=|G|G^{-1}P~\,,~~

(75)

where the mass dimensions of various quantities are

\displaystyle[|G|]=2n,~~~[(G^{-1})_{ij}]=-2,~~~[A_{ij}]=2(n-1),~~~[x]=2(n+1),~~~[y_{i}]=2n~\,.~~

(76)

From (
75
) we can solve

\displaystyle P={1\over|G|}GY,~~~~r={|G|x+Y^{T}GY\over|G|^{2}}\,.~~~

(77)

4.2
The differential equations

Having found the good variables, we express differential operators
\partial_{R}\cdot\partial_{R}
and
K_{i}\cdot\partial_{R},i=1,...,n
using them.
The first step is to use (
75
) to write

\displaystyle{\partial\over\partial R^{\mu}}

\displaystyle=

\displaystyle\left(2|G|R_{\mu}-2|G|{\cal K}^{T}_{\mu}G^{-1}P\right)\partial_{x}+|G|{\cal K}^{T}_{\mu}G^{-1}\partial_{Y}~\,,~~

(78)

where we have defined
{\cal K}^{T}=(K_{1},...,K_{n})
and
\partial_{Y}^{T}=(\partial_{y_{1}},...,\partial_{y_{n}})
. Thus we find

\displaystyle{\cal K}\cdot{\partial\over\partial R^{\mu}}=|G|\partial_{Y},~~~~~~\partial_{R}\cdot\partial_{R}=2|G|(D-n)\partial_{x}+4|G|x\partial^{2}_{x}+|G|^{2}\partial_{Y}^{T}G^{-1}\partial_{Y}~\,.~~

(79)

The differential equations for
c_{T}
, where
T
denotes different
types of generation functions, have following pattern

\displaystyle K_{i}\cdot\partial_{R}c_{T}

\displaystyle=

\displaystyle{\alpha}_{i}c_{T}+H_{T;i},~~i=1,2,...,n~\,,

(80)

\displaystyle\partial_{R}\cdot\partial_{R}c_{T}

\displaystyle=

\displaystyle{\alpha}_{R}c_{T}+H_{T;R}~\,,~~

(81)

where
{\alpha}_{R},{\alpha}_{i}
are constant (which are independent of
T
) and
H_{T;R},H_{T;i}
are known functions coming from lower topologies. Using the result (
79
) and (
80
), we find

\displaystyle|G|^{2}\partial_{Y}^{T}G^{-1}\partial_{Y}c_{T}={\alpha}^{T}_{\cal K}G^{-1}{\alpha}_{\cal K}c_{T}+H^{T}_{T;\cal K}G^{-1}{\alpha}_{\cal K}+|G|\partial_{Y}^{T}G^{-1}H_{T;\cal K}~\,,~~

(82)

where
{\alpha}^{T}_{\cal K}=({\alpha}_{1},...,{\alpha}_{n})
and
H^{T}_{T;\cal K}=(H_{T;1},...,H_{T;n})
. Thus
the differential equations (
80
) can be written as

\displaystyle\left(\partial_{y_{i}}-{{\alpha}_{i}\over|G|}\right)c_{T}

\displaystyle=

\displaystyle{1\over|G|}H_{T;i}~~i=1,2,...,n~\,,

(83)

while (
81
) becomes

\displaystyle\left(4|G|x\partial^{2}_{x}+2|G|(D-n)\partial_{x}+\widetilde{{\alpha}}_{R}\right)c_{T}

\displaystyle=

\displaystyle{\cal H}_{T;R}~~~

(84)

with

\displaystyle\widetilde{{\alpha}}_{R}={\alpha}^{T}_{\cal K}G^{-1}{\alpha}_{\cal K}-{\alpha}_{R},~~~~~~{\cal H}_{T;R}=-H^{T}_{T;\cal K}G^{-1}{\alpha}_{\cal K}-|G|\partial_{Y}^{T}G^{-1}H_{T;\cal K}+H_{T;R}~\,.~~

(85)

Having given the differential equations (
83
) and (
84
), there is an important point to be mentioned. For (
83
) and (
84
) to have solution, functions
H
are not arbitrary, but must satisfy the
integrability conditions
, which are

\displaystyle\left(\partial_{y_{j}}-{{\alpha}_{j}\over|G|}\right)H_{T;i}=\left(\partial_{y_{i}}-{{\alpha}_{i}\over|G|}\right)H_{T;j},~~~\forall i,j=1,2,...,n~\,,~~

(86)

and

\displaystyle\left(4|G|x\partial^{2}_{x}+2|G|(D-n)\partial_{x}+\widetilde{{\alpha}}_{R}\right){1\over|G|}H_{T;i}=\left(\partial_{y_{i}}-{{\alpha}_{i}\over|G|}\right){\cal H}_{T;R},~~~\forall i=1,2,...,n~\,.~~

(87)

Differential equations (
83
) and (
84
) are the type of (
148
) and (
161
) respectively in the Appendix A, for which the solution has been presented. In next subsection, we will solve them analytically.

In this part, we will present the necessary steps of solving above differential equations (

\displaystyle+e^{-{{\alpha}_{1}\over|G|}y_{1}}{1\over|G|}H_{T;2}(x,y_{1},y_{2},...,y_{n})\,.~~~

\displaystyle-e^{{{\alpha}_{2}\over|G|}y_{2}}{1\over|G|}\int_{0}^{y_{1}}dw_{1}e^{-{{\alpha}_{1}\over|G|}w_{1}}\left(e^{-{{\alpha}_{2}\over|G|}y_{2}}H_{T;1}(x,w_{1},y_{2},...,y_{n})-H_{T;1}(x,w_{1},y_{2}=0,...,y_{n})\right)\,.~~~

Putting (

\displaystyle c_{T}(x,y)

\displaystyle=

\displaystyle e^{{{\alpha}_{1}\over|G|}y_{1}}e^{{{\alpha}_{2}\over|G|}y_{2}}F_{T}(x,y_{3},...,y_{n})

(91)

\displaystyle+e^{{{\alpha}_{2}\over|G|}y_{2}}{1\over|G|}\int_{0}^{y_{2}}dw_{2}e^{-{{\alpha}_{2}\over|G|}w_{2}}H_{T;2}(x,y_{1},w_{2},...,y_{n})

\displaystyle+e^{{{\alpha}_{1}\over|G|}y_{1}}e^{{{\alpha}_{2}\over|G|}y_{2}}{1\over|G|}\int_{0}^{y_{1}}dw_{1}e^{-{{\alpha}_{1}\over|G|}w_{1}}H_{T;1}(x,w_{1},y_{2}=0,...,y_{n})~\,.~~

and then find

\displaystyle c_{T}(x,y)=e^{{{\alpha}_{1}\over|G|}y_{1}}e^{{{\alpha}_{2}\over|G|}y_{2}}e^{{{\alpha}_{3}\over|G|}y_{3}}F_{T}(x,y_{4},...,y_{n})

\displaystyle+e^{{{\alpha}_{1}\over|G|}y_{1}}e^{{{\alpha}_{2}\over|G|}y_{2}}e^{{{\alpha}_{3}\over|G|}y_{3}}{1\over|G|}\int_{0}^{y_{1}}dw_{1}e^{-{{\alpha}_{1}\over|G|}w_{1}}H_{T;1}(x,w_{1},y_{2}=0,y_{3}=0,...,y_{n})~\,.~~

By checking (

) and (

\displaystyle c_{T}(x,y_{1},...,y_{n})=e^{\sum_{i=1}^{n}{\alpha}_{i}y_{i}\over|G|}F(x)+{\cal H}_{T;K}~~~~~~

(93)

with

\displaystyle{\cal H}_{T;K}={1\over|G|}\widetilde{\sum}_{i=n}^{1}e^{\widetilde{\sum}_{j=n}^{i}{\alpha}_{j}y_{j}\over|G|}\int_{0}^{y_{i}}dw_{i}e^{-{\alpha}_{i}w_{i}\over|G|}H_{T;i}(x,y_{1},...,y_{i-1},w_{i},0,...,0)~\,,~~~~~

where for simplicity we have defined the sum

.

As shown in the paper, differential equations for generation functions can be reduced to two typical types.

The first order differential equation:
The first typical differential equation is following first order differential equation

\displaystyle\boxed{\left(A{d\over dx}+B\right)F(x)=H(x)}~\,,~~~

(148)

are independent of
x

is the known function of

\displaystyle\left(A{d\over dx}+B\right)F_{0}(x)=0,~~~~~\Longrightarrow~~~F_{0}(x)=e^{-{B\over A}x}\,.~~~~

Then we write

F_{1}(x)

\displaystyle A{d\over dx}F_{1}(x)=F_{0}^{-1}H(x)~\,,~~~

(150)

\displaystyle F_{1}(x)=F_{1}(x=0)+\int_{0}^{x}dt{1\over A}e^{{B\over A}t}H(t)~\,.~~~

Knowing the special solution of
F(x)
in (

\displaystyle\boxed{F(x)=F_{0}(x)F_{1}(x)+\widetilde{{\alpha}}F_{0}(x)=e^{-{B\over A}x}\left({\alpha}+\int_{0}^{x}dw{1\over A}e^{{B\over A}w}H(w)\right)}~\,,~~~
