A New Algebraic Structure That Extends Fields And Allows For A True Division By Zero
Brendan Santangelo

Abstract




Abstract

To allow for Division By Zero, we develop a new algebraic structure containing addition and multiplication called an S-Extension of a Field. This unique structure extends a Field so that the equation
0\cdot s=x
has exactly one solution for every non-zero Field element
x
. Furthermore, a different solution is obtained for each choice of
x
, making this solution unique to that particular equation. However, the equation
0\cdot s=0
has two or more solutions, with no preference towards any one particular solution. This allows us to use the usual definition of division as the solution to the equation
0\cdot s=x
to evaluate
x
divided by
0
. And if
x\not=0
, every
{x\over 0}
is a unique element that is also unique to that particular
x
while
{0\over 0}
remains indeterminate. This creates a manner of Division By Zero which significantly differs from other attempts at Division By Zero.

Introduction

According to our understanding of mathematics, no general formula for evaluating Division By Zero exists. This is not due to a lack of trying. In the year 628 AD, a mathematician named Brahmagupta attempted to define Division By Zero by writing that a number divided by zero equals a fraction with zero as the denominator and zero divided by zero equals zero. However this definition either makes no sense or leads to a contradiction
[
1
]
.

In modern times, a few attempts at developing Division By Zero have also been made. These attempts include the following: an attempt by introducing fractions so that
{z\over 0}={0\over 0}=0
for every Complex Number
[
2
]
, an attempt by creating an element
{0\over 0}
to use with the Projective Real Number Line
[
3
]
and an attempt by creating elements
\pm\infty
,
\Phi
such that
{x\over 0}=+\infty
for all positive Real Numbers,
{x\over 0}=-\infty
for all negative Real Numbers and
{0\over 0}=\Phi

[
4
]
.

One thing each of these attempts has in common is that they all involve defining or evaluating
{0\over 0}
as something fixed. This of course goes against our understanding that
{0\over 0}
is indeterminate. Another common theme is that
{x\over 0}
is never distinct or unique to that particular
x
. In each attempt, most distinct numbers
x
evaluate to the same
{x\over 0}
. Furthermore, a couple of these attempts involve
{x\over 0}
being some form of
\infty
. This method is often controversial however as
\infty
is not considered a number. And finally, for most of these attempts,
{x\over 0}
is not a unique solution to the equation
0\cdot s=x
.

This raises a few questions. First, is it possible to develop an algebraic structure so that whenever
x\not=0
, every
{x\over 0}
can be evaluated and have a distinct value unique to that particular
x
? Can this new structure maintain
{0\over 0}
as indeterminate? Can we do all of this without requiring
{x\over 0}
to be some form of
\infty
? And most importantly, can this
{x\over 0}
satisfy our usual definition of division and be a true division operation? As we will see, the answer to all of these questions is yes.

By using axioms which very much resemble the Field axioms, along with an equivalence relation, we will construct a unique algebraic structure called an S-Extension of a Field. In this structure, the equation
0\cdot s=x
will have exactly one solution for every non-zero Field element
x
which is unique to that particular
x
while the equation
0\cdot s=0
will have two or more solutions. If we then define
x
divided by
0
as the solution to
0\cdot s=x
, we see that every
{x\over 0}
is unique and evaluates to an element unique to that particular
x
while
{0\over 0}
remains indeterminate. Furthermore, we do this without requiring any
{x\over 0}
to be
\infty
in any form. And we use the usual definition of division to evaluate
{x\over 0}
, making this operation a true division operation.

Procedure

As stated, we wish to develop an algebraic structure we call an S-Extension of a Field. To build this structure however, we must begin from scratch. We start by developing a small collection of algebraic properties similar to the Field Axioms using an algebraic structure we call an S-Structure. This collection of algebraic properties can then be used as axioms to define an algebraic structure we call an Ascended Ring. And by including inverse elements with Ascended Rings, we can create an algebraic structure we call an Ascended Field. We will see that these names are quite fitting as we will prove that an Ascended Ring is an Extension of a Ring and an Ascended Field is an Extension of a Field. By an Extension of a Ring and an Extension of a Field, we mean that an Ascended Ring contains in it a structure which forms a Ring and an Ascended Field contains in it a structure which forms a Field. We will see that in both Ascended Rings and Ascended Fields, solutions to the equation
0\cdot s=x
exist, but are not yet unique.

From there, we introduce an equivalence relation to Ascended Rings to create an algebraic structure we call the S-Quotient Space of an Ascended Ring. We do the same thing for Ascended Fields, creating the S-Quotient Space of an Ascended Field. For every Field element
x
, we will see that this equivalence relation collapses every possible solution to the equation
0\cdot s=x
into one solution. Furthermore, this solution will be unique to that particular
x
.

We can then create the S-Extension of a Field by combining a Field contained in an Ascended Field with the S-Quotient Space of that Ascended Field. Since this structure contains a Field, we can setup the equation
0\cdot s=x
for every element
x
in the Field. And since it contains an S-Quotient Space of an Ascended Field, there exists exactly one solution to this equation which is unique to that particular
x
for every
x
which is non-zero. This then allows us to evaluate Division By Zero using the usual definition of division as being the inverse operation of multiplication while keeping
0
divided by
0
indeterminate.

S-Structures And Basic Types Of S-Structures

We start by defining an algebraic structure called an S-Structure, which contains at least one element that when multiplied by zero is non-zero. We define S-Structures in the most general way possible, using the fewest assumptions needed. We then substitute different algebraic properties in and out to see what the S-Structure looks like with these swapped in properties. For each property we swap in, we will prove at least one proposition about that particular S-Structure. Over time, we will build up a collection of algebraic properties and a collection of propositions using these properties.

S-Structures

We define an
S-Structure

({{S}},+,\cdot)

{S}

({S},+)

0

({S},\cdot)

and there exists

0\cdot s\not=0
or
s\cdot 0\not=0
(or both).

We consider the operation
+

\cdot

({{S}},+,\cdot)

Commutative S-Structures

We say an S-Structure
({{S}},+,\cdot)
is
Commutative
if
({{S}},\cdot)
is Commutative. Therefore
({{S}},+,\cdot)
is Commutative if
s\cdot t=t\cdot s
for all
s,t\in{S}
. Now Non-Commutative S-Structures do exist. For example, the S-Structure
({S},+,\cdot)=({R}^{2},+,\cdot)
where
s+t=(x+u,y+v)
and
s\cdot t=(xu+v,yv)
from above is a Non-Commutative S-Structure as
0\cdot s=(y,0)\not=0
if
y\not=0
and
s\cdot 0=(0,0)
. Therefore
0\cdot s\not=s\cdot 0
. Now we can avoid a lot of complications in the future by having multiplicative commutativity. For this reason, we will only consider Commutative S-Structures from here on out.

Let
({{S}},+,\cdot)
be a Commutative S-Structure, then for every
\alpha\in{S}
, we define the set

{{S}}_{\alpha}=\{s\in{{S}}\,|\,0\cdot s=s\cdot 0=\alpha\}.

We call any element

a
Scalar
. We also define the set
\Lambda\subseteq{{S}}
, called the
Index of
({{S}},+,\cdot)

\Lambda=\{\alpha\in{{S}}\,|\,{{S}}_{\alpha}\not=\emptyset\}.

The following proposition will illustrate why calling
\Lambda
the Index of
({S},+,\cdot)

Proposition 1.3

Let
({{S}},+,\cdot)
be a Commutative S-Structure, then
\{{{S}}_{\alpha}\}_{\alpha\in\Lambda}
is a partition on
{{S}}
.

Proof:
We will first show that
{S}=\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
and then show that each
{{S}}_{\alpha}
is disjoint from one another. Now
\bigcup_{\alpha\in\Lambda}{S}_{\alpha}\not=\emptyset
as each
{S}_{\alpha}
where
\alpha\in\Lambda
contains at least one element. Let
s_{1}\in\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
, then
s_{1}\in{S}_{\alpha}
for some
\alpha\in\Lambda
. Now
{{S}}_{\alpha}\subseteq{{S}}
, implying
s_{1}\in{{S}}
. This means that
\bigcup_{\alpha\in\Lambda}{S}_{\alpha}\subseteq{{S}}
. And if
s_{2}\in{S}
, since
({{S}},\cdot)
is closed, we know that
0\cdot s_{2}=\alpha
for some
\alpha\in{S}
. This means that
s_{2}\in{S}_{\alpha}
and since
{{S}}_{\alpha}\not=\emptyset
, we see that
\alpha\in\Lambda
. Therefore

, which means that
{S}\subseteq\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
. This proves that
{S}=\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
.

Now let
\alpha_{1},\alpha_{2}\in{{S}}
. If
{\alpha_{1}}={\alpha_{2}}
, then
{S}_{\alpha_{1}}\cap{S}_{\alpha_{2}}={S}_{\alpha_{1}}\cap{S}_{\alpha_{1}}={S}_{\alpha_{1}}
. If
{\alpha_{1}}\not={\alpha_{2}}

{S}_{\alpha_{1}}\cap{S}_{\alpha_{2}}=\{s\in{{S}}\,|\,(0\cdot s)={\alpha_{1}}
and
(0\cdot s)={\alpha_{2}}\}=\{s\in{{S}}\,|\,(0\cdot s)={\alpha_{1}}={\alpha_{2}}\}=\emptyset

is disjoint from one another. Therefore

is a partition on

.

Wheel Distributive S-Structures

We know that an S-Structure cannot be Distributive. To make up for this, we will define another property similar to Distribution which can be used to take it’s place. Let
({{S}},+,\cdot)
be a Commutative S-Structure. We say
({{S}},+,\cdot)
is
Wheel Distributive
if for every
s,t,r\in{{S}}
,

s\cdot(t+r)+(s\cdot 0)=(s\cdot t)+(s\cdot r).

Equivalently, we could say
({{S}},+,\cdot)
is
Wheel Distributive
if for every
s,t,r\in{{S}}
,

s\cdot(t+r)=(s\cdot t)+(s\cdot r)-(s\cdot 0).

We can prove a few algebraic properties using this type of distribution.

Proposition 1.4

Let
({{S}},+,\cdot)
be a Wheel Distributive Commutative S-Structure, then we have the following:

1) If
s,t\in{S}
, then
-(s\cdot t)=(-s)\cdot t-(0\cdot t)-(0\cdot t)
.

2) If
s,t\in{S}
, then
(-s)\cdot(-t)=(s\cdot t)-[(0\cdot s)+(0\cdot s)+(0\cdot t)+(0\cdot t)]
.

3) If
s,t\in{S}
and
x\in{S}_{0}
, then
x\cdot(s+t)=(x\cdot s)+(x\cdot t)
.

Proof:
Let
s,t\in{S}
, then we see that

\begin{array}[]{rcl}0&=&s+(-s)\cr t\cdot 0&=&t\cdot(s+(-s))\cr t\cdot 0&=&(t\cdot s)+(t\cdot(-s))-(t\cdot 0)\cr-(t\cdot s)&=&t\cdot(-s)-(t\cdot 0)-(t\cdot 0)\cr-(s\cdot t)&=&(-s)\cdot t-(0\cdot t)-(0\cdot t).\cr\end{array}

We also see that

\begin{array}[]{rcl}t+(-t)&=&0\cr(-s)\cdot(t+(-t))&=&(-s)\cdot 0\cr((-s)\cdot t)+((-s)\cdot(-t))-((-s)\cdot 0)&=&(-s)\cdot 0\cr((-s)\cdot t)+((-s)\cdot(-t))&=&(-s)\cdot 0+(-s)\cdot 0\cr-(s\cdot t)+(0\cdot t)+(0\cdot t)+((-s)\cdot(-t))&=&-(s\cdot 0)+(0\cdot 0)+(0\cdot 0)-(s\cdot 0)+(0\cdot 0)+(0\cdot 0)\cr-(s\cdot t)+(0\cdot t)+(0\cdot t)+((-s)\cdot(-t))&=&-(s\cdot 0)+0+0-(s\cdot 0)+0+0\cr-(s\cdot t)+(0\cdot t)+(0\cdot t)+((-s)\cdot(-t))&=&-(s\cdot 0)-(s\cdot 0)\cr(-s)\cdot(-t)&=&(s\cdot t)-(s\cdot 0)-(s\cdot 0)-(0\cdot t)-(0\cdot t)\cr(-s)\cdot(-t)&=&(s\cdot t)-[(0\cdot s)+(0\cdot s)+(0\cdot t)+(0\cdot t)].\end{array}

Finally, let
x\in{S}_{0}
. This means that
x\cdot 0=0
, implying

x\cdot(s+t)=(x\cdot s)+(x\cdot t)-(x\cdot 0)=(x\cdot s)+(x\cdot t)-0=(x\cdot s)+(x\cdot t).

Therefore if
x\in{S}_{0}
and
s,t\in{S}
, then
x\cdot(s+t)=(x\cdot s)+(x\cdot t)
.

\exists s\in{S}_{1}
, implying
s\cdot(0\cdot 0)=s\cdot 0=1
. However
(s\cdot 0)\cdot 0=1\cdot 0=0
and since
1\not=0
, we see that
s\cdot(0\cdot 0)\not=(s\cdot 0)\cdot 0
. This means that
({{S}},\cdot)
is not Associative. And as it turns out, we will be dealing with structures that satisfy this exact criteria. This means that we must define another property similar to Associativity that can be used to take it’s place, just as we did for Distribution.

Let
({S},+,\cdot)
be a Commutative S-Structure where
\exists 1\in\Lambda
such that
0\not=1
. We say
({S},+,\cdot)
is
S-Associative
, short for
Santangelo Associative
, if
\forall m,n\in{{S}}_{0}
and
\forall s\in{{S}}
, we have

m\cdot(n\cdot s)=(m\cdot n)\cdot s-([(m-1)\cdot(n-1)]\cdot(0\cdot s)).

This gives us a very good replacement for Associativity. The following proposition will show us why this is so.

Proposition 1.6

Let
({{S}},+,\cdot)
be a Commutative S-Structure where
\exists 1\in\Lambda
such that
0\not=1
. Also, let
({{S}},+,\cdot)
be an S-Associative S-Structure, then we have the following:

1) If
m,n\in{{S}}_{0}
and
s\in{{S}}
, then
m\cdot(n\cdot s)=n\cdot(m\cdot s)
.

2) If
x\in{{S}}_{0}
and
s\in{{S}}_{\alpha}
, then
x\cdot s\in{{S}}_{x\cdot\alpha}
.

3)
({S}_{0},\cdot)
is Closed.

Proof:
Let
m,n\in{{S}}_{0}
and
s\in{{S}}
, then we see that

m\cdot(n\cdot s)=(m\cdot n)\cdot s-([(m-1)\cdot(n-1)]\cdot(0\cdot s))=(n\cdot m)\cdot s-([(n-1)\cdot(m-1)]\cdot(0\cdot s))=n\cdot(m\cdot s).

Therefore
m\cdot(n\cdot s)=n\cdot(m\cdot s)
. Now let
s\in{{S}}_{\alpha}
and
x\in{{S}}_{0}
, then
0\cdot s=\alpha
implying
x\cdot(0\cdot s)=x\cdot\alpha
. However, we know that
x\cdot(0\cdot s)=0\cdot(x\cdot s)
. This means that
0\cdot(x\cdot s)=x\cdot\alpha
and so
x\cdot s\in{{S}}_{x\cdot\alpha}
. Finally, if
x,y\in{S}_{0}
, then
0\cdot(x\cdot y)=x\cdot(0\cdot y)=x\cdot 0=0
implying
0\cdot(x\cdot y)=0
. Therefore
x\cdot y\in{S}_{0}
, proving that
({S}_{0},\cdot)
is Closed.
\mathchar 1027\relax

S-Structures With Unity

Let
({{S}},+,\cdot)
be a Commutative S-Structure. We say
({{S}},+,\cdot)

has Unity
if
\exists e\in{S}
called the
Unity of
({{S}},+,\cdot)
, or
Identity of
({{S}},\cdot)
, where
\forall s\in{{S}}
we have

e\cdot s=s\cdot e=s.

Proposition 1.7

Let
({{S}},+,\cdot)
be a Commutative S-Structure with Unity, then
e\in{S}_{0}
,
e
is unique and
e\not=0
provided there exists at least one element
x\in{S}_{0}
where
x\not=0
.

Proof:
Since
e
is the Unity of
({{S}},+,\cdot)
, we know that
0\cdot e=0
implying
e\in{{S}}_{0}
. Now assume
e,e_{1}\in{{S}}
are Unities of
({{S}},+,\cdot)
, then
\forall s,t\in{{S}}
, we have
e\cdot s=s
and
e_{1}\cdot t=t
. If we let
s=e_{1}
, then
e\cdot e_{1}=e_{1}
and if
t=e
, then
e_{1}\cdot e=e\cdot e_{1}=e
. Therefore
e\cdot e_{1}=e_{1}=e
, making
e
unique. Finally, assume that
e=0
and let
x\in{{S}}_{0}
where
x\not=0
. We know
0\cdot x=0
and so
e\cdot x=0\cdot x=0
. However we know that
e\cdot x=x
implying
x=0
. This contradicts
x\not=0
, proving that
e\not=0
.
\mathchar 1027\relax

S-Structures With Scalar Inverses

Let
({{S}},+,\cdot)
be a Commutative S-Structure with Unity
e
. We say
({{S}},+,\cdot)

has Scalar Inverses
if
\forall x\in{{S}}_{0}
where
x\not=0
, there exists a multiplicative inverse
x^{-1}\in{{S}}_{0}
such that

x\cdot x^{-1}=x^{-1}\cdot x=e.

Proposition 1.8

Let
({{S}},+,\cdot)
be a Commutative S-Structure with Unity and Scalar Inverses, then provided there exists at least one element
x\in{S}_{0}
where
x\not=0
, we know
e^{-1}
exists and
e^{-1}=e
.

Proof:
Since
\exists x\in{S}_{0}
where
x\not=0
, we know that
e\in{{S}}_{0}
where
e\not=0
. Therefore
e^{-1}\in{{S}}_{0}
exists such that
e\cdot e^{-1}=e
. However
e\cdot e^{-1}=e^{-1}
, implying
e^{-1}=e
.
\mathchar 1027\relax

Complete Regular S-Structures

Let
({{S}},+,\cdot)
be a Commutative S-Structure. We say that
({{S}},+,\cdot)
is
Regular
if
\forall s\in{{S}}
,
0\cdot s\in{{S}}_{0}
. And we say that
({{S}},+,\cdot)
is
Complete
if
\forall\alpha\in{{S}}_{0}
,
\exists s\in{{S}}
such that
0\cdot s=\alpha
.

Proposition 1.9

Let
({S},+,\cdot)
be a Commutative S-Structure, then
({S},+,\cdot)
is Regular if and only if
\Lambda\subseteq{S}_{0}
. Furthermore,
({S},+,\cdot)
is Complete if and only if
{S}_{0}\subseteq\Lambda
.

Proof:
Let
({S},+,\cdot)
be Regular and let
\alpha\in\Lambda
, then
{S}_{\alpha}\not=\emptyset
. Let
s\in{S}_{\alpha}
, then
0\cdot s=\alpha\in{S}_{0}
implying that
\Lambda\subseteq{S}_{0}
. Now let
\Lambda\subseteq{S}_{0}
and let
s\in{S}
. Since
{S}=\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
is a partition, we know that
s\in\bigcup_{\alpha\in\Lambda}{S}_{\alpha}
and that
\exists\alpha\in\Lambda
such that
s\in{S}_{\alpha}
. This means that
0\cdot s=\alpha\in\Lambda\subseteq{S}_{0}
, implying
0\cdot s\in{S}_{0}
. And so
({S},+,\cdot)
is Regular, proving that
({S},+,\cdot)
is Regular if and only if
\Lambda\subseteq{{S}}_{0}
.

Let
({S},+,\cdot)
be Complete and let
\alpha\in{S}_{0}
, then
\exists s\in{S}
such that
0\cdot s=\alpha
. This means that
s\in{S}_{\alpha}
implying
{S}_{\alpha}\not=\emptyset
. Therefore
\alpha\in\Lambda
, proving that
{S}_{0}\subseteq\Lambda
. Now let
{S}_{0}\subseteq\Lambda
where
\alpha\in{S}_{0}
, then
\alpha\in\Lambda
implying that
{S}_{\alpha}\not=\emptyset
. Therefore
\exists s\in{S}_{\alpha}
such that
0\cdot s=\alpha
. And so
({S},+,\cdot)
is Complete, proving that
({{S}},+,\cdot)
is Complete if and only if
{S}_{0}\subseteq\Lambda
.
\mathchar 1027\relax

Let
({S},+,\cdot)
be a Commutative S-Structure. We say that

is

if it is both Regular and Complete.

Corollary 1.3

Let

be a Commutative S-Structure, then

.

2
Ascended Rings, Ascended Fields And S-Quotient Spaces

We are now familiar with some basic types of Commutative S-Structures and the collection of algebraic properties that are used to create these S-Structures. In this section, we will use these properties as axioms to build an algebraic structure called an Ascended Ring. And if we include Scalar Inverses with these axioms, we can create a special Ascended Ring called an Ascended Field. We will see that an Ascended Ring is an Extension of a Ring and an Ascended Field is an Extension of a Field.

We will also see that for both Ascended Rings and Ascended Fields, the equation
0\cdot s=x
will have a solution if and only if
x\in{S}_{0}
. But we’ll see that for every
x\in{S}_{0}
, there are more than one solution to the equation
0\cdot s=x
. On top of that, both Ascended Rings and Ascended Fields themselves are not necessarily unique structures as we can find at least two different Ascended Rings or two different Ascended Fields for the same set. These are problems as we wish to create a unique structure with a unique solution to the equation
0\cdot s=x
.

In response, we will create an algebraic structure called an S-Quotient Space by taking either an Ascended Ring or an Ascended Field and defining an equivalence relation on that structure. This will condense all of the elements in each set
{S}_{\alpha}
into an equivalence class
[\alpha]
. We can then prove that the S-Quotient Space of one Ascended Ring is equal to the S-Quotient Space of another Ascended Ring provided that both Ascended Rings extend the same Ring. We can also do this for Ascended Fields. This will take care of the uniqueness of the structure as a whole. We will discuss the effects of this equivalence relation on the equation
0\cdot s=x
in the next section.

Ascended Rings

Let
({S},+,\cdot)
be an algebraic structure where
{S}
is a set with well defined addition and multiplication operations. We define
({S},+,\cdot)
as an
Ascended Ring
if
({S},+,\cdot)
satisfies the following
Ascended Ring Axioms
:

1)
({S},+)
is a Commutative Group with Identity
0
and Inverses
-s
.

2)
({S},\cdot)
is Closed.

3)
({S},+,\cdot)
has Unity
1
.

4)
1\in\Lambda
where
0\not=1
.

5)
0\in{{S}}_{0}
.

6)
({S},+,\cdot)
is Commutative.

7)
({S},+,\cdot)
is Wheel Distributive.

8)
({S},+,\cdot)
is S-Associative.

So if
({S},+,\cdot)
is an Ascended Ring, we know that
({S},+)
is a Commutative Group and that
({{S}},\cdot)
is Closed. And since there exists
1\in\Lambda
such that
0\not=1
, we know that
\exists s_{1}\in{{S}}_{1}
such that
0\cdot s_{1}=1\not=0
. We also know that
0\cdot 0=0
and that
({S},+,\cdot)
is Commutative. Therefore
({{S}},+,\cdot)
is a Commutative S-Structure.

Furthermore, since
({S},+,\cdot)
has Unity
1
, we know that
1\in{S}_{0}
. And since
0\in{S}_{0}
where
0\not=1
, we can conclude that in every Ascended Ring,
{S}_{0}
contains at least two elements:
0
and
1
. We can also show that every Ascended Ring
({S},+,\cdot)
is Complete Regular.

Theorem 2.1

Let
({{S}},+,\cdot)
be an Ascended Ring, then
\Lambda={{S}}_{0}
making
({S},+,\cdot)
Complete Regular.

Proof:
If
n\in{S}_{0}
, since
1\in\Lambda
, we know that
\exists s_{1}\in{S}_{1}
. Furthermore, we know that
n\cdot s_{1}\in{S}_{n\cdot 1}
. However
n\cdot 1=n
, implying that
n\cdot s_{1}\in{S}_{n}
. This means that
{S}_{n}\not=\emptyset
and so
n\in\Lambda
, implying
{S}_{0}\subseteq\Lambda
. Now if
n\in\Lambda
, we know that
\exists s\in{S}_{n}
such that
0\cdot s=n
. And since
1
is the Unity of
{S}_{0}
, we know that
1\cdot 0=0
. But since
({S},+,\cdot)
is Wheel Distributive, this means that
(-1)\cdot 0=-(1\cdot 0)=-0=0
, implying
(-1)\cdot 0=0
. And so

\begin{array}[]{rcl}n&=&0\cdot s\cr&=&0\cdot(1\cdot s)\cr&=&(0\cdot 1)\cdot s-((0-1)\cdot(1-1))\cdot(0\cdot s)\cr&=&0\cdot s-((-1)\cdot 0)\cdot(0\cdot s)\cr&=&0\cdot s-0\cdot(0\cdot s)\cr&=&n-0\cdot n.\cr\end{array}

Therefore
n=n-0\cdot n
and since
({S},+)
is a Commutative Group, this means that
0\cdot n=0
. And so
n\in{S}_{0}
, implying
\Lambda\subseteq{S}_{0}
. This means that
\Lambda={S}_{0}
and proves that
({S},+,\cdot)
is Complete Regular.
\mathchar 1027\relax

Since
({S},+,\cdot)
is Complete Regular, we know that
0\cdot s\in{S}_{0}
for every
s\in{S}
. This means that the equation
0\cdot s=x
only has a solution if
x\in{S}_{0}
. And again, since
({S},+,\cdot)
is Complete Regular, we know that if
x\in{S}_{0}
, then there exists
s\in{S}
such that
0\cdot s=x
. This means that for every
x\in{S}_{0}
, the equation
0\cdot s=x
has a solution. Therefore
0\cdot s=x
has a solution if and only if
x\in{S}_{0}
.

However, we know that
{S}_{0}
has at least two elements:
0
and
1
. And since
({S},+,\cdot)
is Wheel Distributive, we know that for every
x\in{S}_{0}
, the set
{S}_{x}=\{s_{x}+a\,|\,a\in{S}_{0}\}
for some fixed
s_{x}\in{S}_{x}
. Hence every set
{S}_{x}
contains at least two elements,
s_{x}
and
s_{x}+1
. So while the equation
0\cdot s=x
has a solution if and only if
x\in{S}_{0}
, there are no unique solutions to this equation for any
x\in{S}_{0}
.

Now every Ascended Ring is actually an Extension of a Commutative Ring. To see this, we will show that
({S}_{0},+,\cdot)
forms a Commutative Ring. And since
({S}_{0},+,\cdot)
is contained within
({S},+,\cdot)
, this means that
({S},+,\cdot)
is an Extension of the Commutative Ring
({S}_{0},+,\cdot)
. More interesting though is that
({S}_{\alpha},+,\cdot)
forms a Ring if and only if
\alpha=0
.

Proposition 2.1

Let
({{S}},+,\cdot)
be an Ascended Ring and let
\alpha\in{S}_{0}
, then we have the following:

1)
({S}_{0},+,\cdot)
forms a Commutative Ring.

2)
({{S}}_{\alpha},+,\cdot)
forms a Ring iff
\alpha=0
.

Proof:
Since
({S},+,\cdot)
is Wheel Distributive, we know that
({S}_{0},+,\cdot)
is Distributive and that
({S}_{0},+)
forms a Commutative Group. Furthermore, since
({S},+,\cdot)
is S-Associative, we know that
({S}_{0},\cdot)
is Closed. Since
({S},+,\cdot)
is Commutative, we also know that
({{S}}_{0},\cdot)
is Commutative. And since
1
is the Unity of
({S},+,\cdot)
, we know that
1\in{S}_{0}
. Finally, if
m,n,p\in{S}_{0}
, then
(m-1),(n-1)\in{S}_{0}
. This means that
(m-1)\cdot(n-1)\in{S}_{0}
, implying that
[(m-1)\cdot(n-1)]\cdot 0=0
. And so

\begin{array}[]{rcl}m\cdot(n\cdot p)&=&(m\cdot n)\cdot p-([(m-1)\cdot(n-1)]\cdot(0\cdot p))\cr&=&(m\cdot n)\cdot p-([(m-1)\cdot(n-1)]\cdot(0))=(m\cdot n)\cdot p-0=(m\cdot n)\cdot p.\cr\end{array}

This means that
m\cdot(n\cdot p)=(m\cdot n)\cdot p
, proving that
({S}_{0},\cdot)
is Associative. Therefore
({S}_{0},+,\cdot)
forms a Commutative Ring. This also means that if
\alpha=0
, then
({{S}}_{\alpha},+,\cdot)
forms a Ring.

We must now show that if
({{S}}_{\alpha},+,\cdot)
is a Ring, then
\alpha=0
. To do this, we will prove the contrapositive: Let
\alpha\not=0
, then we wish to show that
({{S}}_{\alpha},+,\cdot)
is not a Ring. Since
\alpha\in{S}_{0}
and
{S}_{0}=\Lambda
, we know that
\alpha\in\Lambda
, implying that
{S}_{\alpha}\not=\emptyset
. So if
s_{\alpha},t_{\alpha},r_{\alpha}\in{S}_{\alpha}
, then
s_{\alpha}\cdot 0=\alpha\not=0
and

s_{\alpha}\cdot(t_{\alpha}+r_{\alpha})=(s_{\alpha}\cdot t_{\alpha})+(s_{\alpha}\cdot r_{\alpha})-(s_{\alpha}\cdot 0)=(s_{\alpha}\cdot t_{\alpha})+(s_{\alpha}\cdot r_{\alpha})-\alpha\not=(s_{\alpha}\cdot t_{\alpha})+(s_{\alpha}\cdot r_{\alpha}).

This means that if
\alpha\not=0
, then
s_{\alpha}\cdot(t_{\alpha}+r_{\alpha})\not=(s_{\alpha}\cdot t_{\alpha})+(s_{\alpha}+r_{\alpha})
implying that
({S}_{\alpha},+,\cdot)
is not Distributive. Therefore if
\alpha\not=0
, then
({S}_{\alpha},+,\cdot)
is not a Ring. And so
({{S}}_{\alpha},+,\cdot)
forms a Ring iff
\alpha=0
.
\mathchar 1027\relax

We will now look at two examples of Ascended Rings.

Example 1

Let
(R,+,\cdot)
be a Commutative Ring (such as
({Z},+,\cdot)
, the Ring of Integers) and let
{S}=R\times R
with elements
s,t\in{S}
. We then make the following definitions for addition and multiplication:

\begin{array}[]{rrcll}s+t&=&(x,y)+(u,v)&=&(x+u\,,\,y+v).\cr s\cdot t&=&(x,y)\cdot(u,v)&=&(xu+y+v-xv-yu,\,xv+yu).\cr\end{array}

We can show that this forms an Ascended Ring.

Example 2

Let
(R,+,\cdot)
be a Commutative Ring (such as
({Z},+,\cdot)
, the Ring of Integers) and let
{S}=R\times R
with elements
s,t\in{S}
. We then make the following definitions for addition and multiplication:

\begin{array}[]{rrcll}s+t&=&(x,y)+(u,v)&=&(x+u\,,\,y+v).\cr s\cdot t&=&(x,y)\cdot(u,v)&=&(xu+y+v-xv-yu,\,yv+xv+yu).\cr\end{array}

We can show that this forms an Ascended Ring. Furthermore, this Ascended Ring is different from the Ascended Ring in Example 1, proving that at least two different Ascended Rings exist for the same set. Therefore Ascended Rings are not necessarily unique algebraic structures.

Ascended Fields

Let
({S},+,\cdot)
be an algebraic structure where
{S}
is a set with well defined addition and multiplication operations. We define
({S},+,\cdot)
as an
Ascended Field
if
({S},+,\cdot)
is an Ascended Ring with Scalar Inverses.

Since an Ascended Field is also an Ascended Ring, any statements that are true for Ascended Rings are also true for Ascended Fields. Furthermore, the following proposition which we looked at for Ascended Rings can be extended to accommodate the case of Ascended Fields.

Proposition 2.2

Let
({S},+,\cdot)
be an Ascended Field and let
\alpha\in{S}_{0}
, then we have the following:

1)
({S}_{0},+,\cdot)
forms a Field.

2)
({S}_{\alpha},+,\cdot)
forms a Field iff
\alpha=0
.

Proof:
Since
({S},+,\cdot)
is an Ascended Field, we know that
({S},+,\cdot)
is an Ascended Ring. This means that
({S}_{0},+,\cdot)
is a Ring and since we know
({S},+,\cdot)
has Scalar Inverses, this means that
({S}_{0},+,\cdot)
has inverses
x^{-1}
for every
x\in{S}_{0}
such that
x\not=0
. Therefore
({S}_{0},+,\cdot)
is a Field. Furthermore, since
({S}_{\alpha},+,\cdot)
is a Ring if and only if
\alpha=0
and
({S}_{\alpha},+,\cdot)
must be a Ring to be a Field, we can conclude that if
\alpha\not=0
, then
({S}_{\alpha},+,\cdot)
is not a Field. Therefore
({S}_{\alpha},+,\cdot)
is a Field if and only if
\alpha=0
.
\mathchar 1027\relax

However, there are some things that we can prove about Ascended Fields that we were not able to prove about Ascended Rings.

Proposition 2.3

Let
({S},+,\cdot)
be an Ascended Field containing the Field
({S}_{0},+,\cdot)
. If
x,y\in{S}_{0}
where
y\not=0
, then we have the following:

1)
y^{-1}\in{S}_{0}
is a unique element.

2) If
y\cdot q=x
, then
q=y^{-1}\cdot x
is the unique solution.

Proof:
Let
y\in{S}_{0}
where
y\not=0
and assume there exists
x^{\prime}\in{S}
such that
y\cdot x^{\prime}=1
, then
0\cdot(y\cdot x^{\prime})=0\cdot 1=0
. This means that
0=0\cdot(y\cdot x^{\prime})=y\cdot(0\cdot x^{\prime})
. And since
({S},+,\cdot)
is Complete Regular, we know that
0\cdot x^{\prime}=a\in{S}_{0}
implying
y\cdot a=0
. Furthermore, since
({S}_{0},+,\cdot)
is a Field where
y\not=0
, this means that
a=0
. Therefore
a=0\cdot x^{\prime}=0
, implying that
x^{\prime}\in{S}_{0}
. Now
y\cdot x^{\prime}=1
where
y\in{S}_{0}
is non-zero, implying
y^{-1}\in{S}_{0}
exists. Therefore
y^{-1}\cdot(y\cdot x^{\prime})=y^{-1}\cdot 1=y^{-1}
. And since
y,y^{-1},x^{\prime}\in{S}_{0}
, we know that
y^{-1}=y^{-1}\cdot(y\cdot x^{\prime})=(y^{-1}\cdot y)\cdot x^{\prime}=1\cdot x^{\prime}=x^{\prime}
. So we can conclude that
x^{\prime}=y^{-1}
, making
y^{-1}\in{S}_{0}
a unique element.

And if
x\in{S}_{0}
such that
y\cdot q=x
for some
q\in{S}
, then
y^{-1}\cdot(y\cdot q)=y^{-1}\cdot x
. So by S-Associativity, we know that
(y^{-1}\cdot y)\cdot q-{((y-1)\cdot(y^{-1}-1))\cdot(0\cdot q)}=y^{-1}\cdot x
. And since
y^{-1}\cdot y=1
and
1\cdot q=q
, this means that
q-{((y-1)\cdot(y^{-1}-1))\cdot(0\cdot q)}=y^{-1}\cdot x
or
q=(y^{-1}\cdot x)+{((y-1)\cdot(y^{-1}-1))\cdot(0\cdot q)}
. But since
({S},+,\cdot)
is an Ascended Ring, we know that it’s Complete Regular. This means that
0\cdot q=a\in{S}_{0}
, implying
q=(y^{-1}\cdot x)+{((y-1)\cdot(y^{-1}-1))\cdot a}
. And since
({S}_{0},+,\cdot)
is a Field where
a,x,y,y^{-1},-1\in{S}_{0}
, we know that
q=(y^{-1}\cdot x)+{((y-1)\cdot(y^{-1}-1))\cdot a}\in{S}_{0}
. Hence
q\in{S}_{0}
, which implies that
0\cdot q=a=0
. This means that
q=(y^{-1}\cdot x)+{((y-1)\cdot(y^{-1}-1))\cdot 0}=y^{-1}\cdot x
implying
q=y^{-1}\cdot x
. And since
y^{-1}
is a unique element, we know that
q=y^{-1}\cdot x
is a unique solution.
\mathchar 1027\relax

We will now look at two examples of Ascended Fields.

Example 3

Let
(F,+,\cdot)
be a Field (such as
{R}
, the Real Number Field) and let
{S}=F\times F
with elements
s,t\in{S}
. We then make the following definitions for addition and multiplication:

\begin{array}[]{rrcll}s+t&=&(x,y)+(u,v)&=&(x+u\,,\,y+v).\cr s\cdot t&=&(x,y)\cdot(u,v)&=&(xu+y+v-xv-yu,\,xv+yu).\cr\end{array}

Just like Example 1, we can prove that this structure forms an Ascended Ring. Furthermore, we can see that
({S}_{0},+,\cdot)=({R}\times\{0\},+,\cdot)
and that each element
(x,0)\in{S}_{0}
where
x\not=0
has an inverse element
(x^{-1},0)\in{S}_{0}
. Therefore
({S},+,\cdot)
is an Ascended Field.

Example 4

Let
(F,+,\cdot)
be a Field (such as
{R}
, the Real Number Field) and let
{S}=F\times F
with elements
s,t\in{S}
. We then make the following definitions for addition and multiplication:

\begin{array}[]{rrcll}s+t&=&(x,y)+(u,v)&=&(x+u\,,\,y+v).\cr s\cdot t&=&(x,y)\cdot(u,v)&=&(xu+y+v-xv-yu,\,yv+xv+yu).\cr\end{array}

Just like Example 2, we can prove that this structure forms an Ascended Ring. Furthermore, we can see that
({S}_{0},+,\cdot)=({R}\times\{0\},+,\cdot)
and that each element
(x,0)\in{S}_{0}
where
x\not=0
has an inverse element
(x^{-1},0)\in{S}_{0}
. Therefore
({S},+,\cdot)
is an Ascended Field. And again, this Ascended Field is different from the Ascended Field in Example 3, proving that at least two different Ascended Fields exist for the same set. Therefore Ascended Fields are not necessarily unique algebraic structures.

Introducing Ascended Rings and Ascended Fields is a great way to start exploring Division By Zero. However, these structures still have problems with this operation as Ascended Rings lack unique solutions to the equation
0\cdot s=x
for every
x\in{S}_{0}
. And since an Ascended Field is also Complete Regular, we know this is true for Ascended Fields as well. Therefore, the equation
0\cdot s=x
does not have a unique solution for any
x\in{S}_{0}
in both Ascended Rings and Ascended Fields. On top of that, Ascended Rings and Ascended Fields are not necessarily unique as one can construct at least two Ascended Rings or two Ascended Fields for the same set. So while these structures are a great starting point, these issues must be addressed and figured out in order to allow for Division By Zero using the standard definition for division.

S-Quotient Spaces

Let
({{S}},+,\cdot)
be an Ascended Ring with elements
s,t\in{S}
and define the relation
\equiv
on
({S},+,\cdot)
as

s\equiv t\,\,\,\,{\rm if\,and\,only\,if}\,\,\,\,0\cdot s=0\cdot t.

We can easily see that
s\equiv s
and that
s\equiv t
iff
t\equiv s
. Furthermore, we can see that if
s\equiv t
and
t\equiv r
, then
0\cdot s=0\cdot t=0\cdot r
, implying
s\equiv r
. Therefore
\equiv
is an Equivalence Relation. And since
({S},+,\cdot)
is Complete Regular, for every
x\in{S}_{0}
, there exists
t_{x}\in{S}_{x}
such that
0\cdot t_{x}=x
. So we can express the Equivalence Class containing
t_{x}
as
[x]
where

[x]=\{s\in{S}\,|\,s\equiv t_{x}\}=\{s\in{S}\,|\,0\cdot s=0\cdot t_{x}=x\}=\{s\in{S}\,|\,0\cdot s=x\}={S}_{x}\not=\emptyset.

This means that for every
x\in{S}_{0}
, the Equivalence Class
[x]={S}_{x}\not=\emptyset
. And since
\{{S}_{\alpha}\}_{\alpha\in\Lambda}
forms a partition on
{S}
where
\Lambda={S}_{0}
, we know that
\{{S}_{x}\}_{x\in{S}_{0}}=\{[x]\}_{x\in{S}_{0}}
also forms a partition on
{S}
. But this implies that the Quotient Set, which we will label
[{S}_{0}]
, looks like

[{S}_{0}]=\{[x]\}_{x\in{S}_{0}}=\{[x]\,|\,x\in{S}_{0}\}.

Therefore
\equiv
is an Equivalence Relation with the Quotient Set
[{S}_{0}]=\{[x]\,|\,x\in{S}_{0}\}
containing the Equivalence Classes
[x]
. Furthermore, we see that
[x]\in[{S}_{0}]
if and only if
x\in{S}_{0}
.

We can then setup the function
\phi:{S}_{0}\to[{S}_{0}]
where
\phi(x)=[x]
. If
\phi(x)=\phi(y)
, then
[x]=[y]
which means that
{S}_{x}={S}_{y}
. And since each
{S}_{\alpha}
is disjoint, this means that
x=y
, making
\phi
injective. Now let
s\in[{S}_{0}]
, then
s=[x]
where
x\in{S}_{0}
. By the definition of
\phi
, we see that
\phi(x)=[x]=s
. So if
s\in[{S}_{0}]
, then
\exists x\in{S}_{0}
such that
\phi(x)=s
, making
\phi
surjective as well. This proves that
\phi
is a bijection between
{S}_{0}
and
[{S}_{0}]
.

Now for any
([{S}_{0}],+,\cdot)
from an Ascended Ring
({S},+,\cdot)
containing the Ring
({S}_{0},+,\cdot)
under the Equivalence Relation
\equiv
, we can evaluate the addition operation as follows: Let
[x],[y]\in[{S}_{0}]
. By fixing an element in
{S}_{x}
, call it
q_{0}(x)
, and fixing an element in
{S}_{y}
, call it
q_{0}(y)
, we can uniquely describe every element
s_{x}\in{S}_{x}
as
s_{x}=q_{0}(x)+a
for some
a\in{S}_{0}
and every element
t_{y}\in{S}_{y}
as
t_{y}=q_{0}(y)+b
for some
b\in{S}_{0}
. This allows us to write
[x]={S}_{x}=\{q_{0}(x)+a\,|\,a\in{S}_{0}\}
and
[y]={S}_{y}=\{q_{0}(y)+b\,|\,b\in{S}_{0}\}
. This means that

\begin{array}[]{rcl}[x]+[y]&=&\{s+t\,|\,s\in[x],\,t\in[y]\}\cr&=&\{s+t\,|\,s\in{S}_{x},\,t\in{S}_{y}\}\cr&=&\{(q_{0}(x)+a)+(q_{0}(y)+b)\,|\,a,b\in{S}_{0}\}\cr&=&\{q_{0}(x)+q_{0}(y)+(a+b)\,|\,a,b\in{S}_{0}\}.\end{array}

And since
q_{0}(x)\in{S}_{x}
and
q_{0}(y)\in{S}_{y}
,
q_{0}(x)+q_{0}(y)\in{S}_{x+y}
. Furthermore, since
q_{0}(x)
and
q_{0}(y)
are both fixed elements and addition is closed,
q_{0}(x)+q_{0}(y)=q_{0}(x+y)\in{S}_{x+y}
is also a fixed element. And so

\begin{array}[]{rcl}[x]+[y]&=&\{q_{0}(x)+q_{0}(y)+(a+b)\,|\,a,b\in{S}_{0}\}\cr&=&\{q_{0}(x+y)+c\,|\,c\in{S}_{0}\}\cr&=&{S}_{x+y}\cr&=&[x+y].\cr\end{array}

Therefore
[x]+[y]=[x+y]
for every
[x],[y]\in[{S}_{0}]
. This means that
\phi:{S}_{0}\to[{S}_{0}]
where
\phi(x)=x
satisfies
\phi(x)+\phi(y)=\phi(x+y)
, making
([{S}_{0}],+)
isomorphic to
({S}_{0},+)
. And since
({S}_{0},+)
forms a Commutative Group with identity
0
and additive inverses
-x
for every
x\in{S}_{0}
, we see that
([{S}_{0}],+)
forms a Commutative Group with identity
[0]
and additive inverses
-[x]=[-x]
for every
[x]\in[{S}_{0}]
. Furthermore, we see that the additive inverse
-[x]\in[{S}_{0}]
exists and is unique for every
[x]\in[{S}_{0}]
.

We can then define subtraction in
([{S}_{0}],+,\cdot)
as
[x]-[y]=[x]+[-y]
, which we see is well defined for every
[x],[y]\in[{S}_{0}]
. Given this subtraction operation, if
s,t\in[{S}_{0}]
where
s=[x]
and
t=[y]
, we say that
s=t
if and only if
t-s=[0]
. Now of course
s=s
as
[x]-[x]=[0]
for every
[x]\in[{S}_{0}]
. Furthermore, if
s=t
, then
t-s=[y]-[x]=[0]
implying
[0]=-[0]=-([y]-[x])=[x]-[y]=s-t
. This means that
s-t=[0]
, proving that
t=s
. And finally, if
r\in[{S}_{0}]
such that
s=t
and
t=r
, then we see that
s=r
as
[0]=[0]+[0]=(t-s)+(r-t)=r-s+t-t=r-s
, implying
r-s=[0]
. Therefore we have an Equivalence Relation on
([{S}_{0}],+,\cdot)
which we can use to define what it means for two elements
s,t\in[{S}_{0}]
to be equal or not. It’s then easy to show that
[x]=[y]
in
([{S}_{0}],+,\cdot)
if and only if
x=y
in
({S}_{0},+,\cdot)
.

Now evaluating the multiplication operation in
([{S}_{0}],+,\cdot)
is a little more difficult than evaluating the addition operation. The following proposition will illustrate why this is so.

Proposition 2.4

Let
([{S}_{0}],+,\cdot)
be created using an Ascended Ring
({S},+,\cdot)
under the Equivalence Relation
\equiv
. If
[x],[y]\in[{S}_{0}]
where
[x]
and
[y]
are not both
[0]
, then
[x]\cdot[y]\not=[\alpha]
for any
[\alpha]\in[{S}_{0}]
.

Proof:
To begin, fix elements
q_{0}(x)\in{S}_{x}
and
q_{0}(y)\in{S}_{y}
. We then see that
[x]=\{q_{0}(x)+a\,|\,a\in{S}_{0}\}
and that
[y]=\{q_{0}(y)+b\,|\,b\in{S}_{0}\}
, implying

[x]\cdot[y]=\{s\cdot t\,|\,s\in[x],\,t\in[y]\}=\{s\cdot t\,|\,s\in{S}_{x},\,t\in{S}_{y}\}=\{(q_{0}(x)+a)\cdot(q_{0}(y)+b)\,|\,a,b\in{S}_{0}\}.

Since
({S},+,\cdot)
is an Ascended Ring, this means that

\begin{array}[]{rcl}[x]\cdot[y]&=&\{(q_{0}(x)+a)\cdot(q_{0}(y)+b)\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(x)+a)\cdot q_{0}(y)+(q_{0}(x)+a)\cdot b-0\cdot(q_{0}(x)+a)\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(x)\cdot q_{0}(y))+(a\cdot q_{0}(y))-(0\cdot q_{0}(y))+(b\cdot q_{0}(x))+(a\cdot b)-x\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(x)\cdot q_{0}(y))+(a\cdot q_{0}(y))+(b\cdot q_{0}(x))+(a\cdot b)-x-y\,|\,a,b\in{S}_{0}\}.\end{array}

And since
q_{0}(y)\in{S}_{y}
,
q_{0}(x)\in{S}_{x}
and
a,b\in{S}_{0}
, we know that
a\cdot q_{0}(y)\in{S}_{a\cdot y}
and that
b\cdot q_{0}(x)\in{S}_{b\cdot x}
. Furthermore, since
q_{0}(x)
and
q_{0}(y)
are both fixed elements and multiplication is closed, we know that
a\cdot q_{0}(y)=q_{0}(a\cdot y)\in{S}_{a\cdot y}
is a fixed element and that
b\cdot q_{0}(x)=q_{0}(b\cdot x)\in{S}_{b\cdot x}
is a fixed element. But this means that
q_{0}(a\cdot y)+q_{0}(b\cdot x)=q_{0}((a\cdot y)+(b\cdot x))
is a fixed element in
{S}_{(a\cdot y)+(b\cdot x)}
. And so

\begin{array}[]{rcl}[x]\cdot[y]&=&\{(q_{0}(x)\cdot q_{0}(y))+(a\cdot q_{0}(y))+(b\cdot q_{0}(x))+(a\cdot b)-x-y\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(x)\cdot q_{0}(y))+q_{0}((a\cdot y)+(b\cdot x))+(a\cdot b)-x-y\,|\,a,b\in{S}_{0}\}.\end{array}

Now, by fixing an element
q_{0}(\alpha)\in{S}_{\alpha}
, we can write
[\alpha]={S}_{\alpha}=\{q_{0}(\alpha)+c\,|\,c\in{S}_{0}\}
. So if we assume that
[x]\cdot[y]=[\alpha]
for some
[\alpha]\in[{S}_{0}]
, then

\{(q_{0}(x)\cdot q_{0}(y))+q_{0}((a\cdot y)+(b\cdot x))+(a\cdot b)-x-y\,|\,a,b\in{S}_{0}\}=\{q_{0}(\alpha)+c\,|\,c\in{S}_{0}\}.

But this means that for every
a,b\in{S}_{0}
, there exists
c\in{S}_{0}
such that

(q_{0}(x)\cdot q_{0}(y))+q_{0}((a\cdot y)+(b\cdot x))+(a\cdot b)-x-y=q_{0}(\alpha)+c.

This can be written as
q_{0}(x)\cdot q_{0}(y)=q_{0}(\alpha)-q_{0}((a\cdot y)+(b\cdot x))-(a\cdot b)+x+y+c
.

However
a,b\in{S}_{0}
can take on different values. And since we know
[x]
and
[y]
are not both
[0]
, either
x\not=0
,
y\not=0
or both. Without loss of generality, we can let
x\not=0
. If
a=b=0
, we see that
q_{0}(x)\cdot q_{0}(y)=q_{0}(\alpha)-q_{0}(0)+x+y+c_{0}
. However if
a=0
and
b=1
, then we see that
q_{0}(x)\cdot q_{0}(y)=q_{0}(\alpha)-q_{0}(x)+x+y+c_{1}
. But we know that multiplication in an Ascended Ring is well defined, which means that
q_{0}(x)\cdot q_{0}(y)
must be unique. Hence

q_{0}(\alpha)-q_{0}(0)+x+y+c_{0}=q_{0}(\alpha)-q_{0}(x)+x+y+c_{1}.

Therefore
q_{0}(x)=q_{0}(0)+c_{1}-c_{0}
. And since
q_{0}(0),c_{0},c_{1}\in{S}_{0}
, we know that
q_{0}(0)+c_{1}-c_{0}\in{S}_{0}
. However
q_{0}(x)=q_{0}(0)+c_{1}-c_{0}
where
q_{0}(x)\in{S}_{x}
. So by multiplying both sides by
0
, we see that
x=0
. This gives us a contradiction as we know
x\not=0
. Therefore
[x]\cdot[y]\not=[\alpha]
for any
[\alpha]\in[{S}_{0}]
.
\mathchar 1027\relax

This means that for most
[x],[y]\in[{S}_{0}]
, we see that
[x]\cdot[y]\not\in[{S}_{0}]
. So even though
([{S}_{0}],+)
is isomorphic to
({S},+)
, we will see that
([{S}_{0}],+,\cdot)
is not isomorphic to
({S}_{0},+,\cdot)
.

Proposition 2.5

Let
([{S}_{0}],+,\cdot)
be created using an Ascended Ring
({S},+,\cdot)
containing the Ring
({S}_{0},+,\cdot)
under the Equivalence Relation
\equiv
, then
([{S}_{0}],+,\cdot)\not\cong({S}_{0},+,\cdot)
.

Proof:
If we assume that
([{S}_{0}],+,\cdot)\cong({S}_{0},+,\cdot)
, then there exists an isomorphism
\phi:{S}_{0}\to[{S}_{0}]
. This makes
\phi(x)=[f(x)]
where
f:{S}_{0}\to{S}_{0}
is an automorphism. So for every
z_{1},z_{2}\in{S}_{0}
, there exist
x,y\in{S}_{0}
such that
z_{1}=f(x)
and
z_{2}=f(y)
. This means that for every
[z_{1}],[z_{2}]\in[{S}_{0}]
, there exist
x,y\in{S}_{0}
such that
\phi(x)=[f(x)]=[z_{1}]
and
\phi(y)=[f(y)]=[z_{2}]
. Therefore, for all
[z_{1}],[z_{2}]\in[{S}_{0}]
,

[z_{1}]\cdot[z_{2}]=\phi(x)\cdot\phi(y)=\phi(x\cdot y)=[f(x\cdot y)]=[f(x)\cdot f(y)]=[z_{1}\cdot z_{2}].

This means that
[z_{1}]\cdot[z_{2}]=[z_{1}\cdot z_{2}]
for every
[z_{1}],[z_{2}]\in[{S}_{0}]
. However, this is a contradiction because we know
[z_{1}]\cdot[z_{2}]\not\in[{S}_{0}]
for most
[z_{1}],[z_{2}]\in[{S}_{0}]
. So we can conclude that
([{S}_{0}],+,\cdot)\not\cong({S}_{0},+,\cdot)
.
\mathchar 1027\relax

Now we know that
[x]\cdot[y]=\{(q_{0}(x)\cdot q_{0}(y))+q_{0}((a\cdot y)+(b\cdot x))+(a\cdot b)-x-y\,|\,a,b\in{S}_{0}\}
. If
[x]=[y]=[0]
, then we see that

\begin{array}[]{rcl}[0]\cdot[0]&=&\{(q_{0}(0)\cdot q_{0}(0))+q_{0}((a\cdot 0)+(b\cdot 0))+(a\cdot b)-0-0\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(0)\cdot q_{0}(0))+q_{0}((0)+(0))+(a\cdot b)\,|\,a,b\in{S}_{0}\}\cr&=&\{(q_{0}(0)\cdot q_{0}(0))+q_{0}(0)+(a\cdot b)\,|\,a,b\in{S}_{0}\}.\cr\end{array}

Now
q_{0}(0)\in{S}_{0}
is some fixed element in
{S}_{0}
. And we know that both
({S}_{0},+)
and
({S}_{0},\cdot)
are closed. This means that
(q_{0}(0)\cdot q_{0}(0))+q_{0}(0)=q_{1}(0)
where
q_{1}(0)\in{S}_{0}
is also some fixed element in
{S}_{0}
. And so

\begin{array}[]{rcl}[0]\cdot[0]&=&\{(q_{0}(0)\cdot q_{0}(0))+q_{0}(0)+(a\cdot b)\,|\,a,b\in{S}_{0}\}\cr&=&\{q_{1}(0)+(a\cdot b)\,|\,a,b\in{S}_{0}\}\cr&=&\{q_{1}(0)+c\,|\,c\in{S}_{0}\}.\cr\end{array}

Therefore
[0]\cdot[0]=\{q_{1}(0)+c\,|\,c\in{S}_{0}\}={S}_{0}=[0]
, and so
[0]\cdot[0]=[0]
. But if either
[x]\not=[0]
or
[y]\not=[0]
(or both), then we know that
[x]\cdot[y]\not=[\alpha]
for any
[\alpha]\in[{S}_{0}]
. This means that multiplication in
([{S}_{0}],+,\cdot)
is not closed.

This provides motivation to introduce
\infty_{0}
, a new element such that for every
([{S}_{0}]\cup\{\infty_{0}\},+,\cdot)
, if the elements
[x],[y]\in[{S}_{0}]
, then

[x]\cdot[y]=\left\{\begin{array}[]{cl}{\rm[}0{\rm]}&\quad[x]=[0],\,[y]=[0]\\
\infty_{0}&\quad{\rm else}.\\
\end{array}\right.

While the element
\infty_{0}
shares its symbol with
\infty
, it is not at all associated with this concept. We define
\infty_{0}
as the product
[x]\cdot[y]
for any
[x],[y]\in[{S}_{0}]
where at least one of
[x]
or
[y]
does not equal
[0]
. This makes
\infty_{0}
an actual element. Furthermore, this element will not be used at all when evaluating Division By Zero.

But since we lack a formal definition for
\infty_{0}
, we must define the arithmetic operations associated with
\infty_{0}
rather than derive them. So we define
\infty_{0}+\infty_{0}=\infty_{0}
and
\infty_{0}\cdot\infty_{0}=\infty_{0}
as they make the most logical choices. And if
[a]\in[{S}_{0}]
, then we define
\infty_{0}+[a]=\infty_{0}
and
[a]\cdot\infty_{0}=\infty_{0}
.

Therefore, by combining
[{S}_{0}]
with
\infty_{0}
to create
([{S}_{0}]\cup\{\infty_{0}\},+,\cdot)
, we get an algebraic structure with addition and multiplication operations that are both defined and closed. We define the structure
([{S}_{0}]\cup\{\infty_{0}\},+,\cdot)
as the
S-Quotient Space of
({S},+,\cdot)
, short for
Santangelo Quotient Space
. And since we are using Ascended Rings which have Commutativity, the operations in S-Quotient Spaces also have Commutativity.

Now for any given set, we know that multiple Ascended Rings containing that set exist. But every Ascended Ring contains the structure
({S}_{0},+,\cdot)
, which we know forms a Commutative Ring. And as we will see, if
({S}_{0},+,\cdot)
is the same Ring for any two Ascended Rings, equal or not, then we automatically know that their corresponding S-Quotient Spaces are also the same.

Theorem 2.2

Let
({S}_{1},+_{1},\cdot_{1})
and
({S}_{2},+_{2},\cdot_{2})
be Ascended Rings containing the Rings
({S}_{0}^{1},+_{1},\cdot_{1})
and
({S}_{0}^{2},+_{2},\cdot_{2})
, respectively. If
({S}_{0}^{1},+_{1},\cdot_{1})=({S}_{0}^{2},+_{2},\cdot_{2})
, then

([{S}_{0}^{1}]\cup\{\infty_{0}^{1}\},+_{1},\cdot_{1})=([{S}_{0}^{2}]\cup\{\infty_{0}^{2}\},+_{2},\cdot_{2}).

Proof:
Now
[{S}_{0}^{1}]=\{[x]\,|\,x\in{S}_{0}^{1}\}
and
[{S}_{0}^{2}]=\{[x]\,|\,x\in{S}_{0}^{2}\}
. And since
({S}_{0}^{1},+_{1},\cdot_{1})=({S}_{0}^{2},+_{2},\cdot_{2})
, we know that
{S}_{0}^{1}={S}_{0}^{2}
. Therefore
[{S}_{0}^{1}]=\{[x]\,|\,x\in{S}_{0}^{1}\}=\{[x]\,|\,x\in{S}_{0}^{2}\}=[{S}_{0}^{2}]
, implying
[{S}_{0}^{1}]=[{S}_{0}^{2}]
. But by definition, we know that
\infty_{0}^{1}=[x]\cdot[y]
where
[x],[y]\in[{S}_{0}^{1}]
such that
[x],[y]
are not both
[0]\in[{S}_{0}^{1}]
and that
\infty_{0}^{2}=[x]\cdot[y]
where
[x],[y]\in[{S}_{0}^{2}]
such that
[x],[y]
are not both
[0]\in[{S}_{0}^{2}]
. And since
[{S}_{0}^{1}]=[{S}_{0}^{2}]
, we see that
\infty_{0}^{1}=[x]\cdot[y]=\infty_{0}^{2}
, implying
\infty_{0}^{1}=\infty_{0}^{2}
. Therefore
[{S}_{0}^{1}]\cup\{\infty_{0}^{1}\}=[{S}_{0}^{2}]\cup\{\infty_{0}^{2}\}
.

If we let
[x],[y]\in[{S}_{0}^{1}]=[{S}_{0}^{2}]
, since we know that
({S}_{0}^{1},+_{1},\cdot_{1})=({S}_{0}^{2},+_{2},\cdot_{2})
, we can see that
[x]+_{1}[y]=[x+_{1}y]=[x+_{2}y]=[x]+_{2}[y]
. Furthermore, if
[x],[y]
are not both
[0]
, then
[x]\cdot_{1}[y]=\infty_{0}^{1}=\infty_{0}^{2}=[x]\cdot_{2}[y]
. Similarly, since
\infty_{0}^{1}=\infty_{0}^{2}
, we see that
[x]+_{1}\infty_{0}^{1}=[x]+_{2}\infty_{0}^{2}
and that
\infty_{0}^{1}+_{1}\infty_{0}^{1}=\infty_{0}^{2}+_{2}\infty_{0}^{2}
. At the same time
[x]\cdot_{1}\infty_{0}^{1}=[x]\cdot_{2}\infty_{0}^{2}
and
\infty_{0}^{1}\cdot_{1}\infty_{0}^{1}=\infty_{0}^{2}\cdot_{2}\infty_{0}^{2}
. Finally, we see that
[0]\cdot_{1}[0]=[0]=[0]\cdot_{2}[0]
and that
\infty_{0}^{1}-\infty_{0}^{1}=[0]=\infty_{0}^{2}-\infty_{0}^{2}
. So we can conclude that
([{S}_{0}^{1}]\cup\{\infty_{0}^{1}\},+_{1},\cdot_{1})=([{S}_{0}^{2}]\cup\{\infty_{0}^{2}\},+_{2},\cdot_{2})
.
\mathchar 1027\relax

Therefore two Ascended Rings only have to share the same
({S}_{0},+,\cdot)
for their S-Quotient Spaces to be the same. For example, the Ascended Rings in Example 1 and Example 2 both have the same
({S}_{0},+,\cdot)=({Z}\times\{0\},+,\cdot)
. So according to the theorem above, they both have the same S-Quotient Spaces, even though the two Ascended Rings are not the same.

This can also be generalized to two Ascended Rings
({S}_{1},+_{1},\cdot_{1})
and
({S}_{2},+_{2},\cdot_{2})
containing the Rings
({S}_{0}^{1},+_{1},\cdot_{1})
and
({S}_{0}^{2},+_{2},\cdot_{2})
which are isomorphic instead of equal.

Theorem 2.3

Let
({S}_{1},+_{1},\cdot_{1})
and
({S}_{2},+_{2},\cdot_{2})
be Ascended Rings containing the Rings
({S}_{0}^{1},+_{1},\cdot_{1})
and
({S}_{0}^{2},+_{2},\cdot_{2})

S-Extensions And Division By Zero

In the previous section, we defined the equivalence relation
\equiv
on an Ascended Ring or an Ascended Field in order to create the unique structure called an S-Quotient Space. This took every element in the set
{S}_{x}
and condensed them into an equivalence class
[x]
. And since S-Quotient Spaces satisfy a uniqueness property, this addressed the issue of uniqueness as a whole that Ascended Rings and Ascended Fields were unable to. But we know that every possible solution to the equation

must come from the set
{S}_{x}
. So by condensing every element in
{S}_{x}
into one unique element, we are able to condense every possible solution to the equation

into one unique solution,
s=[x]
. Therefore, by introducing
\equiv
, we address the issue regarding the uniqueness of solutions to the equations
0\cdot s=x
as well.

However, the elements
0,x\in{S}_{0}
are scalars, meaning that
0,x\notin[{S}_{0}]
for any
x\in{S}_{0}
as
[{S}_{0}]
only contains sets. So while the unique solution to the equation

exists for all
x\in{S}_{0}
, the equations themselves do not exist as the scalars used in these equations do not exist in
([{S}_{0}]\cup\{\infty_{0}\},+,\cdot)
. To fix this dilemma, we will take a Field
({S}_{0},+,\cdot)
which is contained in an Ascended Field
({S},+,\cdot)
and combine it with
([{S}_{0}]\cup\{\infty_{0}\},+,\cdot)

. This will create a hybrid structure consisting of
{S}_{0}
and
[{S}_{0}]
, along with
\infty_{0}
, called an S-Extension of
({S}_{0},+,\cdot)
.

We will see that this is a unique structure which contains the equation
0\cdot s=x
for every
x\in{S}_{0}
, along with it’s unique solution from
[{S}_{0}]
. And if
x\not=0
, then each equation

will have
s=[x]
as the unique solution. Furthermore, since each

is unique to that particular

, since this structure contains both
{S}_{0}
and
[{S}_{0}]
, the equation

will still have multiple solutions as every element in
{S}_{0}
is a solution to this equation. With this, we can finally introduce Division By Zero using the usual definition for division.

Final Remarks

We have laid out the blueprints to theoretically evaluate Division By Zero by defining a new algebraic structure called an S-Extension of a Field. But now that the blueprints have been drawn up, further investigation must be conducted in order to prove or disprove the existence of these structures. If we should find such a structure to exist however, the possible applications of these ideas are far-reaching. These applications include using elements in
[{R}]
to evaluate factorials for negative integers and also to evaluate certain infinite sums which previously equaled
