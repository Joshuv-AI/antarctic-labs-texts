Abstract
We consider distributed stochastic optimization problems that are solved with master/workers computation architecture. Statistical arguments allow to exploit statistical similarity and approximate this problem by a finite-sum problem, for which we propose an inexact accelerated cubic-regularized Newton’s method that achieves lower communication complexity bound for this setting and improves upon existing upper bound. We further exploit this algorithm to obtain convergence rate bounds for the original stochastic optimization problem and compare our bounds with the existing bounds in several regimes when the goal is to minimize the number of communication rounds and increase the parallelization by increasing the number of workers.

Introduction

Distributed optimization lies on the interface between control and optimization with the goal being to find a minimum of some global objective by a network of agents, each of which has access to a local part of the objective and can interact with only neighbouring agents.
Many algorithms for this setting under different assumptions were proposed as early as in 1970s

An important recent application is training large-scale machine learning models, which in the language of optimization requires to solve distributed stochastic optimization problems.

This paper focuses on distributed stochastic optimization problems using master/workers architectures. These computational architectures are common, e.g., in the context of federated learning

Finite-Sum Approximation for Stochastic Optimization Problem

In this section, we state the main assumptions about stochastic optimization problem (
1
), discuss its finite-sum approximation obtained via the SAA approach, as well as introduce and motivate the concept of statistical similarity for finite-sum optimization problems.

We consider stochastic minimization problem

\min_{x\in\mathbb{R}^{d}}\boldsymbol{F}(x):=\mathbb{E}_{\xi}{f(x,\xi)},

(19)

where
\xi
is a random variable,
f(x,\xi)
is convex function w.r.t.
x\in\mathbb{R}^{d}
for all
\xi

is

-Lipschitz continuous, i.e.,

\|f(x,\xi)-\ f(y,\xi)\|\leq L_{0}\|x-y\|~\forall x,y\in\mathbb{R}^{d}

and has

\|\nabla^{2}f(x,\xi)-\nabla^{2}f(y,\xi)\|\leq L\|x-y\|~\forall x,y\in\mathbb{R}^{d}.

Note that the first of these assumptions implies that

is

-Lipschitz continuous.
We will also consider the case when

is
\mu
-strongly convex for all

as functions of

.

II-A

Finite-sum approximation

To solve problem
(
19
)
we apply the SAA approach, i.e. sample

from an unknown distribution of

\min_{x\in\mathbb{R}^{d}}F(x):=\frac{1}{m}\sum_{k=1}^{m}f_{k}(x)+\frac{\mu}{2}\|x-x_{0}\|^{2}.

(20)

We use

to denote the solutions of problems
(
19
)
and
(
20
)
respectively. We assume that

and

lie inside the Euclidean ball with center at

and radius

Corollary 1.2 from

claims that under the assumption of

-Lipschitz continuity of

\boldsymbol{F}(x_{F}^{*})-\boldsymbol{F}(x^{*})\leq O\left({\frac{L_{0}R}{\sqrt{N}}}\log\left(N/\delta\right)\right).

Using

\boldsymbol{F}(x)-\boldsymbol{F}(x_{F}^{*})\leq L_{0}\|x-x_{F}^{*}\|,\;\forall x.

Combining the above two inequalities and plugging

, where

is an output of some optimization algorithm after
T

\boldsymbol{F}(x^{T})-\boldsymbol{F}(x^{*})\leq L_{0}\|x^{T}-x_{F}^{*}\|+O\left({\frac{L_{0}R}{\sqrt{N}}}\log\left(N/\delta\right)\right).

(21)

Thus, if we find a good approximation

to the solution

of the finite-sum problem (

).

If we additionally assume that

is

-strongly convex for all
\xi
, there is no need in additional regularization and the original stochastic problem
(
19
)
can be approximated by

\min\limits_{x}\frac{1}{m}\sum_{k=1}^{m}f_{k}(x).

In that case the bound
(
21
)
can be improved
[
18
]
to:

\mathbb{E}\boldsymbol{F}(x^{T})-\boldsymbol{F}(x^{*})\leq L_{0}\|x^{T}-x_{F}^{*}\|+O\left({\frac{L_{0}^{2}}{\mu N}}\right).

(22)

II-B

Statistical similarity

Since problem (

Under assumption that the observations

are iid, the following bound holds

III
Achieving the lower bound for finite-sum optimization under statistical similarity

Motivated by the connection between the finite sum problem (
20
) and the original stochastic optimization problem (

) stated in the previous section, we propose in this section a distributed minimization algorithm with master/workers architecture for general finite-sum problems, in particular,
problem (

[

]
specialized for our setting of master/workers architecture. Moreover, our algorithm achieves communication complexity bound that is better than the one in
[

To that end we consider a network with
m

\min_{x\in\mathbb{R}^{d}}F(x):=\frac{1}{m}\sum_{k=1}^{m}f_{k}(x),

(24)

where each worker node

Note that this problem statement covers problem (

\mu

Motivated by subsection

Assumption 1

(statistical similarity)
Each local function

\|\nabla^{2}F(x)-\nabla^{2}f_{k}(x)\|\leq\beta,

(25)

for all

In particular, for problem (

To solve problem (

First, we describe Distributed Accelerated Cubic Regularized Newton’s Method for minimizing convex functions (Algorithm

We choose one of the agents (w.l.o.g. the agent with number 1) to be the central node (server), and all the others are

Each one of these nodes stores the part

, computes the Hessian of its local loss

\displaystyle\widetilde{{F}}_{M}(x,z)=F\left(z\right)+\left\langle\nabla F\left(z\right),x-z\right\rangle

(26)

\displaystyle+\frac{1}{2}\left\langle(\nabla^{2}{f_{1}}(z)+{3\beta}I)\left(x-z\right),x-z\right\rangle+\frac{M}{6}\left\|x-z\right\|^{3},

(27)

1
