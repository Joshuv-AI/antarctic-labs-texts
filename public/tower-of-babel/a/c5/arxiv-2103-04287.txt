Reduction Free Normalization for a proof-irrelevant type of propositions
Thierry Coquand

Abstract
. We show normalization for a type theory with a hierarchy of universes and a proof irrelevant type of propositions, close to the type system used in the proof assistant Lean. The proof uses the technique of Artin glueing between the term model and a suitable preseaf model. This can also be seen as a proof relevant version of Tait’s computability argument.

Introduction

We show normalization and decidability of conversion
for dependent type theory
with a cumulative sequence of universes
{\mathsf{U}}_{0},{\mathsf{U}}_{1}\dots

with
\eta
-conversion
and
where the type
\mathsf{U_{0}}
is an impredicative
universe of proof-irrelevant propositions.
One interest of such a system is that it is very close to the
type system used by the proof assistant Lean
[
Car19
]
.

Such a system with a hierarchy of universes, with the lowest level
impredicative, was introduced in
[
Coq86
]
. It was conjectured there
that this system is stronger than Zermelo set theory (without even introducing
primitive data types). This conjecture was solved by A. Miquel in
[
Miq04
]
,
by encoding a non well-founded version of set theory where a set is interpreted
as a pointed graph up to bissimulation.
The notion of proof-irrelevant propositions goes back to de Bruijn
[
dB95
]
.

Our proof is a direct adaptation of the normalization argument
presented in
[
Coq19
]
. We recall three features of this approach

(1)

we never need to consider a
reduction
relation,

(2)

we only define a reducibility
predicate
, and this
reducibility predicate is
proof-relevant
1
1

1

A key point
is to define reducibility as a
structure
and not only
as a
property
. It is only for the lowest impredicative universe

\mathsf{U_{0}}
that reducibility is a property.
,

(3)

the reducibility predicate is not defined by an inductive-recursive
relation.

This approach has been much refined in
[
Ste22
,
Gra22
]
.
One goal of this note is to illustrate further the flexibility of this “reduction free” approach,
by combining it with an idea already used in
[
ACP09
]
for dealing with proof irrelevance.
To each type
A
in a context
\Gamma
,
we associate a set of syntactical expressions

\mathsf{Term}(\Gamma,A)
and a set
\mathsf{Elem}(\Gamma,A)

have a quotient map
\mathsf{Term}(\Gamma,A)\rightarrow\mathsf{Elem}(\Gamma,A)
and the main result

The metatheory used in the present note is the impredicative intuitionistic set theory

, introduced by P. Aczel
[

(Essentially the same argument works in a predicative version CZFu

As in the previous work

We first define a general operation which associates to any model

We apply then this general construction to the initial model

1.
What is a model of type theory

1.1.
Definition

We present a formal system, which at the same time can be thought of describing the
syntax of basic dependent type theory, with
explicit substitutions
and
a
name-free
(de Bruijn index) presentation, and defining what is a model

A model of type theory consists of one set

of

\Gamma

in the context
\Gamma

\Gamma

\mathsf{Con}
and

\mathsf{Type}(\Gamma)
then this determines a set

\mathsf{Elem}(\Gamma,A)
of elements of type
A
in the context
\Gamma
.

This describes the
sort
of type theory. We describe now the
operations

and the equations they have to satisfy. For any context
\Gamma

\mathsf{id}:\Gamma\rightarrow\Gamma
.
We also have a composition operator
\sigma\delta:\Theta\rightarrow\Gamma
if

\delta:\Theta\rightarrow\Delta
and
\sigma:\Delta\rightarrow\Gamma
.
The equations are

\sigma~\mathsf{id}=\mathsf{id}~\sigma=\sigma~~~~~~~~(\theta\sigma)\delta=\theta(\sigma\delta)

We have a terminal context

\Gamma

():\Gamma\rightarrow 1

\sigma=()
if
\sigma:\Gamma\rightarrow 1

If
A

and
\sigma:\Delta\rightarrow\Gamma

in
\mathsf{Type}(\Delta)
.
Furthermore, we have

A~\mathsf{id}=A~~~~~~(A\sigma)\delta=A(\sigma\delta)

If

\mathsf{Elem}(\Gamma,A)
and
\sigma:\Delta\rightarrow\Gamma

we should have

in
\mathsf{Elem}(\Delta,A\sigma)
.
Furthermore

a~\mathsf{id}=a~~~~~~(a\sigma)\delta=a(\sigma\delta)

We have a
context extension operation

\mathsf{Type}(\Gamma)
we have
a new context
\Gamma.A
. There is a projection

\mathsf{p}:\Gamma.A\rightarrow\Gamma

\mathsf{q}
in
\mathsf{Elem}(\Gamma.A,A\mathsf{p})

\sigma:\Delta\rightarrow\Gamma
and

A
in
\mathsf{Type}(\Gamma)
and
a

\mathsf{Elem}(\Delta,A\sigma)

we have

(\sigma,a):\Delta\rightarrow\Gamma.A

We should have

\mathsf{p}(\sigma,a)=\sigma~~~~~~~~~\mathsf{q}(\sigma,a)=a~~~~~~~~~(\sigma,a)\delta=(\sigma\delta,a\delta)~~~~~~~~~~(\mathsf{p},\mathsf{q})=\mathsf{id}

If

in

Thus if

If furthermore

If

The extension operation can then be defined as

Thus instead of the extension operation, we could have chosen the operations

We suppose furthermore one operation

\mathsf{Type}(\Gamma)

We should have

We have an abstraction operation

\mathsf{Elem}(\Gamma.A,B)

and an application operation

in

These operations should satisfy the equations

{(\lambda b)}~{a}=b[a],~~~~~~c=\lambda(c\mathsf{p}~\mathsf{q}),~~~~~(\lambda b)\sigma=\lambda(b\sigma^{+}),~~~~({c}~{a})\sigma={c\sigma}~{(a\sigma)}

We assume each set

to be stratified in

.

Each subset

M. Hofmann

2.3.
Artin Glueing

We define now a pseudomorphism
[
KHS19
]
between the model
M

\hat{{\mathcal{C}}}
. The normalisation model
M^{*}
will be a refinement of the glued

[
KHS19
]

To each context
\Gamma
in

|\Gamma|
of
\hat{{\mathcal{C}}}
by taking

|\Gamma|(X)
to be the set
{\langle X\rangle}\rightarrow\Gamma
, with restriction

for

Each element

|A|:|\Gamma|\rightarrow\mathsf{Type}_{n}
, by
\rho\mapsto A{\rho}

Similarly, each element

\mathsf{Elem}(\Gamma,A)

For any

\mathsf{Type}_{n}(\Gamma)
in

\mathsf{mk}:\Pi_{\rho:|\Gamma|}|A|\rho\rightarrow|\Gamma.A|

and projections
\mathsf{fst}:|\Gamma.A|\rightarrow|\Gamma|

\mathsf{snd}:\Pi_{\nu:|\Gamma.A|}|A|(\mathsf{fst}~\nu)

\mathsf{fst}~(\mathsf{mk}~\rho~u)=\rho~~~~~~\mathsf{snd}~(\mathsf{mk}~\rho~u)=u~~~~~~~\nu=\mathsf{mk}~(\mathsf{fst}~\nu)~(\mathsf{snd}~\nu)

This defines a pseudomorphism between the model

Given

\mathsf{Type}_{n}(\Gamma.A)
