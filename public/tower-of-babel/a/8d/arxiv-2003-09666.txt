Double Lowering Operators on Polynomials
Paul TERWILLIGER

Abstract
Recently Sarah Bockting-Conrad introduced the double lowering operator ψ \psi for a tridiagonal pair. Motivated by ψ \psi we consider the following problem about polynomials. Let 𝔽 \mathbb{F} denote an algebraically closed field. Let x x denote an indeterminate, and let 𝔽 ⁡ [ x ] \mathbb{F}[x] denote the algebra consisting of the polynomials in x x that have all coefficients in 𝔽 \mathbb{F} . Let N N denote a positive integer or ∞ \infty . Let { a i } i = 0 N − 1 \{a_{i}\}_{i=0}^{N-1} , { b i } i = 0 N − 1 \{b_{i}\}_{i=0}^{N-1} denote scalars in 𝔽 \mathbb{F} such that ∑ h = 0 i − 1 a h ≠ ∑ h = 0 i − 1 b h \sum_{h=0}^{i-1}a_{h}\not=\sum_{h=0}^{i-1}b_{h} for 1 ≤ i ≤ N 1\leq i\leq N . For 0 ≤ i ≤ N 0\leq i\leq N define polynomials τ i , η i ∈ 𝔽 ⁡ [ x ] \tau_{i},\eta_{i}\in\mathbb{F}[x] by τ i = ∏ h = 0 i − 1 ( x − a h ) \tau_{i}=\prod_{h=0}^{i-1}(x-a_{h}) and η i = ∏ h = 0 i − 1 ( x − b h ) \eta_{i}=\prod_{h=0}^{i-1}(x-b_{h}) . Let V V denote the subspace of 𝔽 ⁡ [ x ] \mathbb{F}[x] spanned by { x i } i = 0 N \{x^{i}\}_{i=0}^{N} . An element ψ ∈ End ⁡ ( V ) \psi\in\operatorname{End}(V) is called double lowering whenever ψ ​ τ i ∈ 𝔽 ​ τ i − 1 \psi\tau_{i}\in\mathbb{F}\tau_{i-1} and ψ ​ η i ∈ 𝔽 ​ η i − 1 \psi\eta_{i}\in\mathbb{F}\eta_{i-1} for 0 ≤ i ≤ N 0\leq i\leq N , where τ − 1 = 0 \tau_{-1}=0 and η − 1 = 0 \eta_{-1}=0 . We give necessary and sufficient conditions on { a i } i = 0 N − 1 \{a_{i}\}_{i=0}^{N-1} , { b i } i = 0 N − 1 \{b_{i}\}_{i=0}^{N-1} for there to exist a nonzero double lowering map. There are four families of solutions, which we describe in detail.

Let
V
denote a vector space with finite positive dimension.
A tridiagonal pair on
V

is an ordered pair of linear maps

A\colon V\to V

and
A^{*}\colon V\to V
that satisfy the following conditions:

(i)

each of
A
,
A^{*}
is diagonalizable;

(ii)

\{V_{i}\}_{i=0}^{d}
of the eigenspaces
of

such that

\displaystyle A^{*}V_{i}\subseteq V_{i-1}+V_{i}+V_{i+1},\qquad 0\leq i\leq d,

where
V_{-1}=0
and
V_{d+1}=0
;

(iii)

there exists an ordering
\{V^{*}_{i}\}_{i=0}^{\delta}

of the eigenspaces of
A^{*}
such that

\displaystyle AV^{*}_{i}\subseteq V^{*}_{i-1}+V^{*}_{i}+V^{*}_{i+1},\qquad 0\leq i\leq\delta,

where
V^{*}_{-1}=0
and
V^{*}_{\delta+1}=0
;

(iv)

there does not exist a subspace
W\subseteq V

such that

AW\subseteq W
and

A^{*}W\subseteq W
and

and

W\not=V

\displaystyle U^{\Downarrow}_{0}+U^{\Downarrow}_{1}+\cdots+U^{\Downarrow}_{i}=V^{*}_{0}+V^{*}_{1}+\cdots+V^{*}_{i},

\displaystyle U^{\Downarrow}_{i}+U^{\Downarrow}_{i+1}+\cdots+U^{\Downarrow}_{d}=V_{0}+V_{1}+\cdots+V_{d-i}

[

\displaystyle(A-\theta_{i}I)U_{i}\subseteq U_{i+1},\qquad

\displaystyle(A^{*}-\theta^{*}_{i}I)U_{i}\subseteq U_{i-1},
