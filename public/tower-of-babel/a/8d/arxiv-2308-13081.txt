Formal specification terminology for demographic agent-based models of fixed-step single-clocked simulations
Atiyah Elsheikh

Abstract
This document presents adequate formal terminology for the mathematical specification of a subset of Agent Based Models (ABMs) in the field of Demography. The simulation of the targeted ABMs follows a fixed-step single-clocked pattern. The proposed terminology further improves the model understanding and can act as a stand-alone protocol for the specification and optionally the documentation of a significant set of (demographic) ABMs. Nevertheless, it is imaginable the this terminology can serve as an inspiring basis for further improvement to the largely-informal widely-used model documentation and communication O.D.D. protocol [ Grimm and et al., 2020 , Amouroux et al., 2010 ] to reduce many sources of ambiguity which hinder model replications by other modelers. A published demographic model documentation, largely simplified version of the Lone Parent Model [ Gostoli and Silverman, 2020 ] is separately published in [ Elsheikh, 2023c ] as illustration for the formal terminology presented here. The model was implemented in the Julia language [ Elsheikh, 2023b ] based on the Agents.jl julia package [ Datseris et al., 2022 ] .

3
Temporal operators

This section introduces further operators, inspired by the field of temporal logic.
These operators provide powerful capabilities for algorithmic specification of complex phrases with temporal elements in a compact manner.
The demonstrated temporal operators are included in the set of composite features
\bigcup\mathcal{F}
.

3.1
just operator

A special operator is

just(P_{f})\equiv P_{just(f)}\subseteq P_{f}~,~f\in\bigcup\mathcal{F}

standing for a featured sub-population established by an event that has just occurred (in the current simulation iteration).
For instance,

just(P_{married})\equiv P_{just(married)}^{t+\Delta t}~~~\text{ where }~~~\Delta t:\text{ a simulation fixed step size }

stands for those individuals who just got married in the current simulation iteration but they were not married in the previous iteration, i.e.

P_{just(married)}^{t+\Delta t}~=~P_{married}^{t+\Delta t}~-~P_{married}^{t}

Formally,

P_{just(f)}^{t+\Delta t}=P_{f}^{t+\Delta t}~-~P_{f}^{t}

(21)

The just operator provides powerful capabilities for concise specification when combined with the negation operator.
For example,

P_{just(\neg married)}^{t+\Delta t}

stands for those who ”just” got divorced or widowed.

3.2
pre operator

Another distinguishable operator is

pre(P_{f})\equiv P_{pre(f)}~,~f\in\bigcup\mathcal{F}

standing for a featured
f-
sub-population in the ”previous” iteration.
So for instance,

P_{pre(married)}^{t+\Delta t}

stands for those individuals who were married (and not necessarily just got married) in the previous simulation iteration

pre(P_{married}^{t+\Delta t})~\equiv~P_{pre(married)}^{t+\Delta t}~\equiv~P_{married}^{t}

Formally,

P_{pre(f)}^{t+\Delta t}=P_{f}^{t}

(22)

Temporal operators can also be applied to individuals and their attributes. For instance

pre(location(p\in P^{t}))=Glasgow

stands for the location of a person in the previous iteration (which does not need to be either similar or different in the current iteration).

This operator may look unnecessary excessive, however the demographic model specification
[
Elsheikh, 2023c
]
of the package implemented in
[
Elsheikh, 2023b
]
makes use of the
pre
operator several times. For instance, a model assumption related to a divorce event is informally and formally described as follows:

Any male who just got divorced moves to an empty house within the same town:

\displaystyle m\in

\displaystyle M_{just(isDivorced}^{t})\implies

\displaystyle pre(location(m))\neq location(m)~\text{ and }~livesAlone(m)~\text{ and }~

\displaystyle town(m)=pre(town(m))

(23)

4
post operator

The operator
post
is similar to the
pre
operator, but it is rather concerned with the ”post” iteration.
Without loss of information, the formal description is analgous to the
pre
operator.
The following is an example from the accompained demonstrated model for formulating a model assumption making use of the
post
operator:

Once a new house is built (e.g. to host an adult moving out of his parent’s house), it never gets demolished and remains always inhabitable

\text{ if }h\in H(t)~\implies h\in post(H(t))\text{ where }t_{0}\leq t<t_{final}

(24)

5
General form

5.1
General definitions

This article is concerned with proposing a terminology for the mathematical specification of demographic ABMs based on a single-clocked fixed-step simulation formally defined via the tuple

<\alpha_{sim},\mathcal{F},\mathcal{M},\mathcal{M}^{t_{0}},\mathcal{E},\mathcal{A},\mathcal{A}^{t_{0}}>

(25)

where

•

\alpha_{sim}=(\Delta t,t_{0},t_{final},\alpha_{meta})^{T}
:
simulation parameters including a fixed step size and final time-step after which the simulation process ends

–

\alpha_{meta}
:
Implementation-dependent simulation parameters, e.g. simulation seed for random number generation

•

\mathcal{F}
: a finite set of elementary population features, cf. Section
5.2

•

\mathcal{M}
: a mathematical model representation corresponding to (demographic) ABM, cf. Section
5.3

•

\mathcal{M}^{t_{0}}
: a mathematical model that evaluates the initial model state at time
t_{0}
, cf. Section
5.4

•

\mathcal{E}
: a finite set of events that takes place in the population. They transient the states of the (featured sub-)population(s), cf. Section
5.5

Establishing a mathematical model that corresponds to reality till the tiniest details is impossible. Therefore, a set of (typically non-realistic) assumptions has to be included in order to simplify the model specification process:

•

\mathcal{A}
: a set of model assumptions that should not be violated during the simulation course between
t_{0}
and
t_{final}
, cf. Section
5.6

•

\mathcal{A}^{t_{0}}
: a set of initial model assumptions that should not violate the initial model state
\mathcal{M}^{t_{0}}
, cf. Section
5.7

Population features
~\mathcal{F}~

\mathcal{F}=\{f_{1},f_{2},f_{3},...f_{k}\}
describes a finite set of elementary features each distinguishes a featured sub-population

as defined in Equations

5.5
Events
\mathcal{E}

\mathcal{E}=\{e_{1},e_{2},e_{3},...,e_{n}\}
is a finite set of events, each of which transients a particular featured sub-population
P_{f^{*}}(t)
is evaluated by the sub-model:

f_{1}^{*}(\mathcal{M}^{t})\equiv\mathcal{M}_{f_{1}^{*}}(P_{f_{1}^{*}},S,\alpha,D,t)\text{ with }f_{1}^{*}\in\bigcup\mathcal{F}

(35)

to another modified sub-population predicted by

f_{2}^{*}(M^{t+\Delta t})\equiv\mathcal{M}_{f_{2}^{*}}(P_{f_{2}^{*}},S,\alpha,D,t+\Delta t)

(36)

Formally,

e(\mathcal{M}_{f_{1}^{*}}^{t})=\mathcal{M}_{f_{2}^{*}}^{t+\Delta t}~~~\text{ for some }\{f_{1}^{*},f_{2}^{*}\}\in\bigcup\mathcal{F}~~\text{ where }e\in\mathcal{E}

(37)

The application of all events transients the model to the next state:

\prod_{i=1}^{n}e_{i}(\mathcal{M}^{t})=\mathcal{M}^{t+\Delta t}

(38)

As an example, the model specification provided in
[
Elsheikh, 2023a
]
specifies the set of events as

\mathcal{E}=\{ageing,birth,death,divorce,marriage\}

The death event specification transforms a given population of alive individuals to the same population with some individuals possibly dead:

\displaystyle death\left(P_{isAlive}^{t}\right)~=~P_{isAlive-age=0}^{t+\Delta t}~\bigcup~P_{just(\neg isAlive)}^{t+\Delta t}

(39)

The first phrase in the right hand side stands for the alive population except neonates and the second stands for those who just became dead.

5.6

\mathcal{A}(\mathcal{M}^{[t_{0},t_{final}]})

is a finite set of assumptions each represented as a Boolean condition

a_{i}(\mathcal{M}^{t})=a_{i}(\mathcal{M}(P(t),S(t),\alpha,D(t),t))=b\in\{true,false\}

a_{i}\vdash\mathcal{M}^{t}~~~,~~~\forall i\in\{1,2,\dots,s\}

A particular assumption

if at any simulation time point

t\in[t_{0},t_{final}]_{\Delta t}\implies a_{j}(M^{t})=false

a_{j}\nvdash\mathcal{M}^{[t_{0},t_{final}]_{\Delta t}}~~~,~~~\text{ where }j\in\{1,2,\dots,s\}

(42)

That is, the violation of an assumption may also depend on the simulation parameter resolution, i.e.
\Delta t
.
Typically, an assumption would be usually rather concerned with a featured sub-population, i.e.

a_{i}(\mathcal{M}^{t}_{f^{*}})=a_{i}(\mathcal{M}(P_{f^{*}}(t),S(t),\alpha,D(t),t))=b\in\{true,false\}~,~f^{*}\in\bigcup\mathcal{F}
