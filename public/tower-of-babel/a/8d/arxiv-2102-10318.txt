A new technique for solving Sobolev type fractional multi-order evolution equations
Nazim I. Mahmudov, Arzu Ahmadova, Ismail T. Huseynov

Abstract
A strong inspiration for studying Sobolev type fractional evolution equations comes from the fact that have been verified to be useful tools in the modeling of many physical processes. We introduce a novel technique for solving Sobolev type fractional evolution equations with multi-orders in a Banach space. We propose a new Mittag-Leffler type function which is generated by linear bounded operators and investigate their properties which are productive for checking the candidate solutions for multi-term fractional differential equations. Furthermore, we propose an exact analytical representation of solutions for multi-dimensional fractional-order dynamical systems with nonpermutable and permutable matrices.

In this section, we consider the Cauchy problem for fractional evolution equation of Sobolev type in a Banach spaces.
Firstly, we introduce the following hypotheses on the linear operators

,
B_{0}
and

:

(H_{1})
:

is a closed operator;

(H_{2})

is a bounded operator;

(H_{3})

(H_{4})

It is important to stress out that

Obviously, the substitution

This signifies that a mild solution of the Cauchy problem for Sobolev type multi-term fractional evolution equation (

0<\beta\leq 1
, respectively. To do this, we need to assume exponential boundedness for one of the given fractional differentiation operators and a forced term with the aid of following Theorem
3.1
.

Theorem 3.1
.

Assume (
3.1
) has a unique continuous solution
x(t)
, if
g(t)
is continuous & exponentially bounded and
\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)
for
0<\beta\leq 1
is exponentially bounded on
\left[0,\infty\right)
, then
x(t)
and its Caputo derivative
\left(\prescript{C}{}{D}^{\alpha}_{0^{+}}x\right)(t)
is exponentially bounded for
1<\alpha\leq 2
on
\left[0,\infty\right)
and, thus, their Laplace transforms exist.

Proof.

Since
g(t)
and
\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)
for
0<\beta\leq 1
is exponentially bounded, there exists positive constants
L,P,\delta
and sufficient large
T
such that
\|g(t)\|\leq L\exp(\delta t)
and
\|\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)\|\leq P\exp(\delta t)
for any
t\geq T
.
It is clear that the system (
3.1
) is equivalent to the following Volterra fractional integral equation of second-kind:

\displaystyle x(t)

\displaystyle=\left(1-\frac{At^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\right)\eta+t\hat{\eta}+\frac{A}{\Gamma(\alpha-\beta)}\int\limits_{0}^{t}(t-r)^{\alpha-\beta-1}x(r)dr

\displaystyle+\frac{1}{\Gamma(\alpha)}\int\limits_{0}^{t}(t-r)^{\alpha-1}[Bx(r)+g(r)]dr.

(3.2)

This means that every solution of (
3
) is also a solution of (
3.1
) and vice versa. For
t\geq T
, (
3
) can be expressed as

\displaystyle x(t)

\displaystyle=\left(1-\frac{At^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\right)\eta+t\hat{\eta}+\frac{A}{\Gamma(\alpha-\beta)}\int\limits_{0}^{T}(t-r)^{\alpha-\beta-1}x(r)dr

\displaystyle+\frac{1}{\Gamma(\alpha)}\int\limits_{0}^{T}(t-r)^{\alpha-1}[Bx(r)+g(r)]dr+\frac{A}{\Gamma(\alpha-\beta)}\int\limits_{T}^{t}(t-r)^{\alpha-\beta-1}x(r)dr

\displaystyle+\frac{1}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}[Bx(r)+g(r)]dr.

In view of hypotheses of Theorem
3.1
, the solution
x(t),(x(0)=\eta,\quad x^{\prime}(0)=\hat{\eta})
is unique and continuous on
\left[0,\infty\right)
, then
Ax(t)
and
Bx(t)+g(t)
are bounded on
[0,T]
, namely:

\exists M>0\quad\text{s.t.}\quad\|Ax(t)\|\leq M,\quad\forall t\in[0,T],

and

\exists N>0\quad\text{s.t.}\quad\|Bx(t)+g(t)\|\leq N,\quad\forall t\in[0,T].

We have

\displaystyle\|x(t)\|

\displaystyle\leq\left(1+\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\right)\|\eta\|+t\|\hat{\eta}\|+\frac{M}{\Gamma(\alpha-\beta)}\int\limits_{0}^{T}(t-r)^{\alpha-\beta-1}dr

\displaystyle+\frac{N}{\Gamma(\alpha)}\int\limits_{0}^{T}(t-r)^{\alpha-1}dr+\frac{\|A\|}{\Gamma(\alpha-\beta)}\int\limits_{T}^{t}(t-r)^{\alpha-\beta-1}\|x(r)\|dr

\displaystyle+\frac{\|B\|}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\|x(r)\|dr+\frac{1}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\|g(r)\|dr.

Multiplying last inequality by
\exp(-\delta t)
and note that

\exp(-\delta t)\leq\exp(-\delta r),\quad r\in[T,t]\quad\text{and}\quad\exp(-\delta t)\leq\exp(-\delta T),\quad\|g(t)\|\leq L\exp(\delta t),\quad t\geq T.

Using the aforementioned inequalities, we attain

\displaystyle\|x(t)\|\exp(-\delta t)\leq\|\eta\|\exp(-\delta t)+\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\|\eta\|\exp(-\delta t)

\displaystyle+t\|\eta\|\exp(-\delta t)+\frac{M\exp(-\delta t)}{\Gamma(\alpha-\beta)}\int\limits_{0}^{T}(t-r)^{\alpha-\beta-1}dr

\displaystyle+\frac{N\exp(-\delta t)}{\Gamma(\alpha)}\int\limits_{0}^{T}(t-r)^{\alpha-1}dr+\frac{\|A\|\exp(-\delta t)}{\Gamma(\alpha-\beta)}\int\limits_{T}^{t}(t-r)^{\alpha-\beta-1}\|x(r)\|dr

\displaystyle+\frac{\|B\|\exp(-\delta t)}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\|x(r)\|dr+\frac{\exp(-\delta t)}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\|g(r)\|dr

\displaystyle\leq\|\eta\|\exp(-\delta T)+\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\|\eta\|\exp(-\delta T)+t\|\eta\|\exp(-\delta T)

\displaystyle+\frac{M\exp(-\theta T)}{\Gamma(\alpha-\beta+1)}(t^{\alpha-\beta}-(t-T)^{\alpha-\beta})+\frac{N\exp(-\delta T)}{\Gamma(\alpha+1)}(t^{\alpha}-(t-T)^{\alpha})

\displaystyle+\frac{\|A\|}{\Gamma(\alpha-\beta)}\int\limits_{T}^{t}(t-r)^{\alpha-\beta-1}\|x(r)\|\exp(-\delta r)dr

\displaystyle+\frac{\|B\|}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\|x(r)\|\exp(-\delta r)dr

\displaystyle+\frac{L}{\Gamma(\alpha)}\int\limits_{T}^{t}(t-r)^{\alpha-1}\exp(\delta(r-t))dr

\displaystyle\leq\|\eta\|\exp(-\delta T)+\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\|\eta\|\exp(-\delta T)

\displaystyle+t\|\eta\|\exp(-\delta T)+\frac{M\exp(-\delta T)}{\Gamma(\alpha-\beta+1)}T^{\alpha-\beta}+\frac{N\exp(-\delta T)}{\Gamma(\alpha+1)}T^{\alpha}

\displaystyle+\int\limits_{0}^{t}\left(\frac{\|A\|(t-r)^{\alpha-\beta-1}}{\Gamma(\alpha-\beta)}+\frac{\|B\|(t-r)^{\alpha-1}}{\Gamma(\alpha)}\right)\|x(r)\|\exp(-\delta r)dr

\displaystyle+\frac{L}{\Gamma(\alpha)}\int\limits_{0}^{t}(t-r)^{\alpha-1}\exp(-\delta(t-r))dr

\displaystyle\leq\|\eta\|\exp(-\delta T)+\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\|\eta\|\exp(-\delta T)

\displaystyle+t\|\eta\|\exp(-\delta T)+\frac{M\exp(-\delta T)}{\Gamma(\alpha-\beta+1)}T^{\alpha-\beta}+\frac{N\exp(-\delta T)}{\Gamma(\alpha+1)}T^{\alpha}

\displaystyle+\left(\frac{\|A\|t^{\alpha-\beta-1}}{\Gamma(\alpha-\beta)}+\frac{\|B\|t^{\alpha-1}}{\Gamma(\alpha)}\right)\int\limits_{0}^{t}\|x(r)\|\exp(-\delta r)dr+\frac{L}{\delta^{\alpha}},\quad t\geq T.

Denote

\begin{cases}a(t)=\frac{\|A\|t^{\alpha-\beta}}{\Gamma(\alpha-\beta+1)}\|\eta\|\exp(-\delta T)+t\|\eta\|\exp(-\delta T)+\|\eta\|\exp(-\delta T)\\
\hskip 18.49411pt+\frac{M\exp(-\delta T)}{\Gamma(\alpha-\beta+1)}T^{\alpha-\beta}+\frac{N\exp(-\delta T)}{\Gamma(\alpha+1)}T^{\alpha}+\frac{L}{\delta^{\alpha}},\\
b(t)=\frac{\|A\|t^{\alpha-\beta-1}}{\Gamma(\alpha-\beta)}+\frac{\|B\|t^{\alpha-1}}{\Gamma(\alpha)},\\

Thus, we attain

v(t)\leq a(t)+b(t)\int\limits_{0}^{t}v(s)ds,\quad t\geq T.

(3.3)

According to the Gronwall’s inequality (
2.9
), we have

v(t)\leq a(t)\exp(tb(t))\leq\exp(a(t)+tb(t)).

(3.4)

Then, it yields from (

) that

\displaystyle\|x(t)\|\leq\exp(a(t)+tb(t)+\delta t),\quad t\geq T.

Since
g(t)
and
\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)
for
\beta\in(0,1]
are exponentially bounded on
[0,\infty)
, from equation (
3.1
), we acquire

\displaystyle\|\left(\prescript{C}{}{D}^{\alpha}_{0^{+}}x\right)(t)\|

\displaystyle\leq\|A\|\|\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)\|+\|B\|\|x(t)\|+\|g(t)\|

\displaystyle\leq\|A\|P\exp(\delta t)+\|B\|\exp(a(t)+tb(t)+\delta t)+L\exp(\delta t)

\displaystyle\leq\left(\|A\|P+\|B\|+L\right)\exp(a(t)+tb(t)+\delta t),\quad t\geq T.

In other words,
\left(\prescript{C}{}{D}^{\alpha}_{0^{+}}x\right)(t)
is also exponentially bounded, the Laplace integral transforms of
x(t)
and its Caputo derivatives
\left(\prescript{C}{}{D}^{\alpha}_{0^{+}}x\right)(t)
,
\left(\prescript{C}{}{D}^{\beta}_{0^{+}}x\right)(t)
exist for
\alpha\in(1,2]
and
\beta\in(0,1]
, respectively. The proof is complete.
∎

Theorem 3.3

A linear operator

(3.7)

(ii)

(i)

) for

) for

Theorem 4.1
.

Let

\displaystyle\mathscr{L}^{-1}\Bigl\{\frac{s^{\gamma}B^{m}}{(s^{\alpha}I-As^{\beta})^{m+1}}\Bigr\}(t)

\displaystyle=t^{m\alpha+\alpha+\gamma-1}\sum_{k=0}^{\infty}\binom{k+m}{m}\frac{A^{k}B^{m}t^{k(\alpha-\beta)}}{\Gamma(k(\alpha-\beta)+m\alpha+\alpha-\gamma)}

\displaystyle=t^{m\alpha+\alpha-\gamma-1}E^{m+1}_{\alpha-\beta,m\alpha+\alpha-\gamma}(At^{\alpha-\beta})B^{m}.

Proof.

By using the Taylor series representation of
\frac{1}{(1-t)^{m+1}},m\in\mathbb{N}_{0}
of the form

\frac{1}{(1-t)^{m+1}}=\sum_{k=0}^{\infty}\binom{k+m}{m}t^{k},\quad|t|<1,

we achieve that

\displaystyle\frac{s^{\gamma}B^{m}}{(s^{\alpha}I-As^{\beta})^{m+1}}=\frac{s^{\gamma}B^{m}}{(s^{\alpha}I)^{m+1}}\frac{1}{(1-\frac{A}{s^{\alpha-\beta}})^{m+1}}

\displaystyle=\frac{s^{\gamma}B^{m}}{s^{(m+1)\alpha}}\sum_{k=0}^{\infty}\binom{k+m}{m}\Big(\frac{A}{s^{\alpha-\beta}}\Big)^{k}

\displaystyle=\sum_{k=0}^{\infty}\binom{k+m}{m}\frac{A^{k}B^{m}}{s^{(m+1)\alpha+k(\alpha-\beta)-\gamma}}.

By using the inverse Laplace integral formula for the above function, we get the desired result:

\displaystyle\mathscr{L}^{-1}\Bigl\{\frac{s^{\gamma}B^{m}}{(s^{\alpha}I-As^{\beta})^{m+1}}\Bigr\}(t)

\displaystyle=\sum_{k=0}^{\infty}A^{k}B^{m}\binom{k+m}{m}\mathscr{L}^{-1}\Bigr\{\frac{1}{s^{k(\alpha-\beta)+(m+1)\alpha-\gamma}}\Bigr\}(t)

\displaystyle=\sum_{k=0}^{\infty}A^{k}B^{m}\binom{k+m}{m}\frac{t^{k(\alpha-\beta)+m\alpha+\alpha-\gamma-1}}{\Gamma(k(\alpha-\beta)+m\alpha+\alpha-\gamma)}

\displaystyle=t^{m\alpha+\alpha-\gamma-1}E^{m+1}_{\alpha-\beta,m\alpha+\alpha-\gamma}(At^{\alpha-\beta})B^{m}.

We have required an extra condition on

Discussion and future work

In this research work, first, we convert Sobolev type fractional evolution equation with multi-orders (
1.1
) to multi-term fractional evolution equation with linear bounded operators (
3.1
). Secondly, we give the sufficient conditions to guarantee the rationality of solving multi-term fractional differential equations with linear bounded operators by the Laplace transform method. Then we solve linear inhomogeneous fractional evolution equation with nonpermutable & permutable linear bounded operators
A,B\in\mathscr{B}(Y)
by making use of Laplace integral transform.
Next we propose exact analytical representation of a mild solution of (
3.1
) and (
1.1
), respectively with the help of newly defined Mittag-Leffler type function which is generated by linear bounded operators by removing the strong condition which is an exponential boundedness of a forced term and one of fractional orders with the help of analytical methods, namely: verification by substitution and fractional analogue of variation of constants formula.

The main contributions of this paper are as follows:

•

we introduce a new Mittag-Leffler type function which is generated by linear bounded operators
A,B\in\mathscr{B}(Y)
via a double infinity series ;

•

we derive new properties of Mittag-Leffler type function which are useful tool for checking the candidate solutions of multi-term fractional differential equations;

•

we propose the property of
Q_{k,m}^{A,B}
with nonpermutable linear operators
A,B\in\mathscr{B}(Y)
which is a generalization of well-known Pascal’s rule binomial coefficients.

•

we acquire the analytical representation of a mild solution for linear Sobolev type fractional multi-term evolution equations with nonpermutable and permutable linear operators;

•

we derive the exact analytical representation of multi-dimensional fractional differential equations with two independent orders and nonpermutable & permutable matrices.

The possible directions for future work in which to extend the results of this paper is looking at Sobolev type fractional functional evolution equations with multi-orders (
5.1
).
Furthermore, one can expect the results of this paper to hold for a class of problems such as Sobolev type functional evolution system governed by

Ey(\tau)=E\phi(t),\quad-\tau\leq t\leq 0.\end{cases}

It would be interesting to see how the theorems
proved above can be extended to these cases. Another direction in which we would like to investigate stability and approximate controllability results for Sobolev type multi-term fractional differential equations (
1.1
) and (

).
