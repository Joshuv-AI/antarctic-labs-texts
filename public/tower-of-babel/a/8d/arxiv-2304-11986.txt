On sparse solution of tensor complementarity problem
R. Deb, A. K. Das

Abstract
In this article we consider the sparse solutions of the tensor complementarity problem (TCP) which are the solutions of the smallest cardinality. We establish a connection between the least element of the feasible solution set of TCP and sparse solution for Z Z -tensor. We propose a p p norm regularized minimization model when p ∈ ( 0 , 1 ) p\in(0,1) and show that it can approximate sparse solution applying the regularization of parameter. Keywords: Tensor complementarity problem, sparse solution, l p l_{p} regularized minimization, Z Z -tensor. AMS subject classifications: 15A69, 90C33.

Main results

Here we explore the properties of sparse solution of TCP
(q,\mathcal{A}).

theorem 3.1
:

Let the solution set of TCP
(q,\mathcal{A})
be nonempty. Then
\exists
a sparse solution of the TCP
(q,\mathcal{A}).

Proof.

If SOL
(q,\mathcal{A})\neq\phi,
then the feasible region of (
2.2
) is nonempty. The objective value of the problem (
2.2
) has a finite number of choices among
0,\;1,\;...,\;n.
So, (
2.2
) is always solvable, and any solution
u^{*}\in\arg\min_{\bar{u}\in\mbox{SOL}(q,\mathcal{A})}\|\bar{u}\|_{0}
is a sparse solution of the TCP
(q,\mathcal{A}).

∎

remark 3.1

It is obvious that the sparse solution of TCP

(q,\mathcal{A})
is unique. For instance, if

Under the supposition of the

Theorem

and the sparse solution of the TCP involving

theorem 3.2

Let a

If FEA

Proof.

From Theorem

:

For any fixed

Proof.

Let for any fixed

(3.10)

In this article, for
