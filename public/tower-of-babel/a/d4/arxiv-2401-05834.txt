Modeling Online Paging in Multi-Core Systems
Mathieu Mari, Anish Mukherjee, Runtian Ren, Piotr Sankowski

Abstract
Web requests are growing exponentially since the 90s due to the rapid development of the Internet. This process was further accelerated by the introduction of cloud services. It has been observed statistically that memory or web requests generally follow power-law distribution (Breslau et al., INFOCOM’99). That is, the i th i^{\text{th}} most popular web page is requested with a probability proportional to 1 / i α 1/i^{\alpha} ( α > 0 \alpha>0 is a constant). Furthermore, this study, which was performed more than 20 years ago, indicated Zipf-like behavior, i.e., that α ≤ 1 \alpha\leq 1 . Such laws are useful for designing caching algorithms in general and configuring proxy caches, and therefore it is important to understand how universal they are. We revisit these stochastic models in the case of cache requests in the context of modern cloud systems. Surprisingly, the memory access traces coming from petabyte-size systems not only show that α \alpha can be bigger than one but also illustrate a shifted power-law distribution — called Pareto type II or Lomax. These previously not reported phenomenon calls for statistical explanation. Our first contribution is a new statistical multi-core power-law model indicating that double-power law can be attributed to the presence of multiple cores running many virtual machines in parallel on such systems. We verify experimentally the applicability of this model using the Kolmogorov-Smirnov test (K-S test). The second contribution of this paper is a theoretical analysis indicating why LRU and LFU-based algorithms perform well in practice on data satisfying power-law or multi-core assumptions. We provide an explanation by studying the online paging problem in the stochastic input model, i.e., the input is a random sequence with each request independently drawn from a page set according to a distribution π \pi . To study the performance of LRU and Perfect LFU (PLFU, an ideal version of LFU), we use ratio-of-expectations ( RoE {\rm RoE} ), by comparing the expected cost of LRU or PLFU with the expected cost of the optimal offline solution OPT, both dealing with a random sequence of requests with sequence length large enough. We derive formulas (as a function of the page probabilities in π \pi ) to upper bound their ratio-of-expectations, which help in establishing RoE ⁡ ( LRU ) = O ⁡ ( 1 ) {\rm RoE}({\rm LRU})=O(1) and RoE ⁡ ( PLFU ) = O ⁡ ( 1 ) {\rm RoE}({\rm PLFU})=O(1) given the random sequence following power-law and multi-core power-law distributions.

Introduction

Nowadays, the public search online for news and information, anytime and anywhere.
Thanks to the rapid development of the Internet, billions of users have registered on Google, Facebook, Twitter, YouTube, etc, and thousands of requests from these users are sent to the cloud servers every second.
Optimizing the average response time for user requests, as a consequence, becomes a core issue for running the business of the platform.
For this purpose, caching plays a central role — a “good” caching replacement policy is essential for improving the efficiency of cloud servers.

The paging problem.

We now formally define the paging problem as follows. Consider a two-level memory system: a small fast memory (the cache) that can store
k
pages and a large but slow memory (e.g., HDD) that can potentially hold infinitely many pages. A sequence of page requests needs to be processed in such a memory system: each request specifies a page and such a page has to be inside the cache for its processing. When a request arrives, if the requested page is already in the cache, then no cost is incurred; otherwise, a
page fault
occurs, i.e., one page in the cache must be evicted to make room for the requested page and some cost is incurred. A paging algorithm decides which page to evict when facing a page fault and the paging problem seeks an optimal algorithm to minimize the total cost incurred while processing a sequence of requests.

Stochastic input model.

We study the online paging problem in the stochastic input model, where each request (in the random sequence) is independently drawn from a set of pages
\mathcal{M}
according to a distribution
\pi:\mathcal{M}\to(0,1)
.
To evaluate the performance of an online paging algorithm
{\rm ALG}
we use
ratio-of-expectation
(
{\rm RoE}
), by comparing the expected cost of
{\rm ALG}
with the expected cost of the offline optimal solution
{\rm OPT}
.
To elaborate, we need the following definitions and notations.

Given any sequence of requests
\sigma
, for any paging algorithm
{\rm ALG}
, let
{\rm ALG}(\sigma)
denote the cost of
{\rm ALG}
.
In the case that
\sigma
is a length-
n
random sequence with each request generated according to
\pi
, let
\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]
denote the expected cost of
{\rm ALG}
to deal with this sequence
\sigma
.
2
2

2

If
{\rm ALG}
is a randomized algorithm (which flips a coin to maintain the cache configuration), let
r
denote the random coins used, and the expected cost of
{\rm ALG}
becomes
\mathbb{E}_{\sigma}^{n}\big[\mathbb{E}_{r}[{\rm ALG}(\sigma,r)]\big]
.

W.l.o.g., we assume that the
i^{\text{th}}
request in the given sequence arrives at time
i
.
In the online situation, an online paging algorithm needs to process request
t
at time
t
, before the arrival of the next request.
The ratio-of-expectation of a paging algorithm
{\rm ALG}
is defined as

{\rm RoE}({\rm ALG})=\overline{\displaystyle\lim_{n\to\infty}}\frac{\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]}{\mathbb{E}_{\sigma}^{n}[{\rm OPT}(\sigma)]}.

Here,
{\rm OPT}(\sigma)
denotes the cost of the offline optimal solution
{\rm OPT}
for
\sigma
.
We remark that the ratio-of-expectation criteria have been widely used to evaluate the performance of an online algorithm for Steiner forest

in the stochastic input model. We thus believe that it is also suited for evaluating the performance of online paging algorithms.

Least-Frequently-Used.

Now we elaborate on the LFU method by introducing two versions of LFU-based paging algorithms:
Perfect LFU
and
In-Cache LFU
.

-

Perfect LFU (PLFU) counts the page frequency over all the pages and maintains the size-
k
cache with
k
most frequent pages. At a page fault, the
k^{\text{th}}
most popular page is evicted to make room for the incoming requested page; right after processing the request, the
k^{\text{th}}
most popular page is added back inside the cache immediately – a cost of 2 is thus incurred for each page fault.

-

In-Cache LFU only counts the pages inside the cache at any moment. At a page fault, the page with the least frequency is evicted to make room for the incoming requested page.

Note that an online paging algorithm is called
lazy
if it only evicts one page to make room for the incoming requested page at a page fault.
Many classic paging algorithms belong to this class and have been verified to perform well, since requests typically follow
locality of reference
in practice, i.e., once a page is requested, it is likely that this page will be soon requested again during the following requests.
By definition, In-Cache LFU is lazy and PLFU is not lazy.
However, PLFU can be reduced to In-Cache LFU without paying an extra cost.
3
3

3

The reduction from PLFU to In-Cache LFU is trivial by not adding back the
k^{\text{th}}
most frequent page back inside the cache right after PLFU dealing with a page fault.
To explain why no extra cost is incurred through this reduction, given any sequence of requests, consider when requesting a
j^{\text{th}}
most frequent page (
j>k
): by applying PLFU, a cost of 2 is incurred for processing this page
j
; however, by applying In-Cache LFU, at most a cost of 1 is incurred to process this request and also at most a cost of 1 is incurred for the next time when one of the
k
most frequent pages is requested.

Another salient feature of PLFU is that, up to a factor of 2, PLFU is the optimal online paging algorithm in the stochastic input model.
This is because, PLFU produces a
cost rate
(per request) of
2\sum_{j>k}p_{j}
and no online paging algorithm can produce a cost rate less than
\sum_{j>k}p_{j}
due to the cache size constraint (
p_{j}
is the probability of the
j^{\text{th}}
most frequent page in
\pi
; for a detailed proof, see Proposition
5
).

Least-Recently-Used and marking algorithms.

Now we elaborate LRU as an online paging algorithm belonging to a class called
marking
, which processes the sequence of requests in
phases
defined as follows.

-

At the beginning of each phase, all the pages inside the cache (if exists) are unmarked; the first phase starts from the first request in the given sequence.

-

When a page is requested (in a phase), it is marked immediately.

-

At a page fault, an unmarked page in the cache is evicted to make room for the requested page; in the case that all
k
pages in the cache are marked, then the current phase terminates, all the pages become unmarked, and the next phase starts.

By definition, LRU is a marking algorithm: at a page fault in any phase, LRU evicts the unmarked page which is least recently requested.

One famous marking algorithm is called
Flush-When-Full
(FWF), which evicts all the
k
pages from the cache when a phase terminates.
Although FWF is not realistic, studying its competitiveness provides an in-depth understanding of the class of marking algorithms.
Besides, one another
randomized
marking algorithm is called
Marker
(Fiat et al.
[
23
]
), which works as follows: at a page fault in any given phase, among all the unmarked pages, one of them is evicted uniformly at random.
Thanks to the random eviction at page fault, Marker achieves an O(
\log k
) competitive ratio, while LRU and FWF are
k
-competitive.

Here we remark that the classic paging algorithm
First-In-First-Out
(FIFO), which evicts the page which arrives earliest (among the
k
pages inside the cache), is not a marking algorithm by the above definition.

Related works.

Extensive papers have studied the online paging problem and here we only introduce the core results from the theoretical perspective.

In the offline setting (i.e., the sequence of requests is known before processing), the optimal algorithm
{\rm OPT}
(known as Belady’s rule) works as follows: at a page fault, the page to be requested farthest away in the future is evicted from the cache, to make room for the currently requested page
[
12
]
. However, paging is an inherent
online
problem: each request has to be processed immediately at its arrival, without knowing the requests arriving in the future. Note that Belady’s rule cannot be used in the online setting and as a result, many heuristic online paging algorithms have been proposed, for instance, LRU, FIFO, FWF, Marker, etc.

In the online adversarial model (i.e., each request can be arbitrarily decided by an online adversary), LRU achieves a competitive ratio of
k
and no deterministic online algorithm can achieve a competitive ratio less than
k

[
45
,
34
]
.
Torng
[
47
]
showed that any deterministic marking algorithm is
\Theta(k)
-competitive.
Later, Fiat et al.
[
23
]
proposed a randomized marking algorithm called
Marker
and showed that it achieves a competitive ratio of
2H_{k}=O(\log k)
(
H_{k}
denotes the
k^{\text{th}}
Harmonic number).
Besides, they also show that no online algorithm can achieve a competitive ratio better than
\Theta(\log k)
.

In fact, although LRU is
k
-competitive, it actually performs well in practice (usually with a performance ratio of no more than 2) and hence is referred to as the golden rule.
To provide an explanation for such a phenomenon, some works investigated the characterization of the online adversary such that
{\rm LRU}
achieves a good performance ratio
[
41

8

Some previous works have studied online paging problems in the stochastic input model
[
25

22
,
36
,
50

, for the purpose of explaining why LRU works well in practice.
Franaszek and Wagner
[
25
]
studied the performance of a class of algorithms called
H_{1}
(including classic algorithms like LRU, FIFO, etc) by comparing the cost rate of
{\rm ALG}
(denoted by
Q_{{\rm ALG}}
in their work) with
Q_{0}=\sum_{j>k}p_{i}
.
They showed that
\frac{Q_{{\rm ALG}}}{Q_{0}}=\Omega(\log k)
for any algorithm
{\rm ALG}\in H_{1}
and particularly for LRU,

\frac{Q_{{\rm LRU}}}{Q_{0}}\leq 1+\frac{k\cdot\sum_{j\leq k}p_{i}}{1+(k-1)\cdot\sum_{j>k}p_{i}}.

However, no result in their work compares
Q_{{\rm LRU}}
or

Q_{{\rm OPT}}
(the cost rate of the offline optimal solution).
Koutsoupias and Papadimitriou
[

analyzed
{\rm LRU}

\varepsilon

They showed that among all deterministic online paging algorithms,
{\rm LRU}
achieves the optimal competitive ratio against the diffuse adversary.
Following
[

[

He established accurate formulas (as a function of
k

\varepsilon

[

]

[

We note, however, that for skewed distributions, i.e., power-law, we have typically

In such case

\Theta(\log k)

Laoutaris
[
37

studied the performance of LRU when the input follows power-law distribution and derived an analytic formula on LRU’s hit ratio, yet without comparing the hit ratios of LRU and PLFU or OPT.
Although some previous works have considered the online paging problem in the stochastic input model, nonetheless, several questions still remain open:

-

What is the performance ratio of LFU and LRU compared with the offline optimal solution OPT? Is there any formula (as a function of the page probabilities in the given distribution
\pi
) to upper bound their performance ratios?

-

Is there any result to prove that LFU and LRU achieve a “good” performance ratio (say
O(1)
) when the input follows some practical distribution like power-law?

In this paper, our results provide an affirmative answer to these questions.

Some previous work has studied multi-core paging problem
[

López-Ortiz and Salinger

In recent years, another line of works given by Agrawal et al.

In this paper, we considered the multi-core paging problem in the stochastic input model and showed that both LRU and PLFU achieves O(1) ratio-of-expectations when the sequence follow power-law distribution.

Experimental results

In this section, we report the experiments on traces provided by Huawei coming from their petabyte size systems.
Dorado systems typically have 64-256 PB of SSD storage and 16-64 TB of smart cache.
The traces record correspond to different usage scenarios in which hundreds (
\geq 500
) virtual machines are used.
The user requests (in each trace file) are served in a multi-core environment.
That is, at any time,
\kappa
different virtual machines are working concurrently and independently (thus generating
\kappa
intermixed sequence of requests) but they are sharing the same cache pool of size
k
.
When a particular page
i
is requested (in any sequence served by any core) but not inside the cache pool, one page from the cache has to be evicted to make room for page
i
.
Typically, the number of cores
\kappa
is smaller than the cache size
k
.

In order to be consistent with previous results (e.g.
[
15
]
), we need to propose a model that reconstructs Zipf-like distributions when
\kappa=1
. Thus we assume that in the considered multi-core environment, the requests in each of
\kappa
sequences follow a power-law distribution
\pi
with parameter
\alpha
.
This implies that the probability
\tilde{p}_{i}
that a page
i
is requested (in at least one of the
\kappa
sequences) at any time is equal to

\tilde{p}_{i}=C\cdot(1-(1-p_{i})^{\kappa})\text{\ with\ }p_{i}=\frac{1}{L(\alpha,m)}\cdot\frac{1}{i^{\alpha}},

where
C
is a normalization constant.

Since the heavy-tailed distribution of cascade size had been experimentally observed, there have been many attempts to fit models to the data.
Unfortunately, many of them have not used adequate metrics to properly measure the fit of the distribution.
The rudimentary characterization of power-law distribution is that large events do happen quite often (contrary to exponential distribution).
To apply those characteristics, it is tempting to propose a metric that would somehow punish errors on the tail of the distribution.
Another naive idea is to assume that power-law distribution is linear on a log-log plot and use linear regression, e.g., as it seems to be the case in
[
15
]
.
Unfortunately, as claimed in
[
19
]
, both of those methods have serious problems with variation, and virtually any distribution can be accepted by those metrics.
The proper method of analyzing power-law distributed data should involve a goodness-of-fit test
[
19
]
.
The most commonly used is the Kolmogorov-Smirnov test (K-S test),

\sup_{x}|X(x)-Y(x)|

which computes the maximum difference between CDFs of real and predicted data distribution (
X(x)
is CDF of predicted data and
Y(x)
CDF of real data).
Applying this metric allows us to avoid serious errors.
For example, Bild et al.
[
13
]
showed using outlined methods that the lifetime of tweets does not follow power-law distribution but in fact, it is type-II discrete Weibull distribution.
The application of such conservative metrics can dispel any doubts about which model fits better to the data.

According to our experiments, the page distribution fits the above model closely.

\tilde{p}_{i}

3
Theoretical results

In this section, we study the online paging problem in the stochastic input model (where each request is drawn independently from a page set
\mathcal{M}
according to a distribution
\pi
).
We focus on deriving upper bounds on the ratio-of-expectations (RoE) of PLFU and LRU, using functions of the page probabilities of
\pi
.
We derive two formulas to upper bound
{\rm RoE}({\rm PLFU})
and
{\rm RoE}({\rm LRU})
.
Specifically, given the distribution
\pi
, by sorting all the page probabilities in the decreasing order, i.e.,
p_{1}\geq p_{2}\geq\dots\geq p_{m}
(recalling that
m
and
k
denote the number of pages and the cache size, respectively) and denoting by

p[x:y]:=\sum_{i=x}^{y}p_{i}\text{ for }1\leq x<y\leq m,

we obtain the following results.

Theorem 1
.

{\rm RoE}({\rm LRU})\leq\frac{16}{\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}}.

Theorem 2
.

{\rm RoE}({\rm PLFU})\leq\frac{32}{\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}}.

Remark that we can assume
m\geq 2k
with no loss: in the case
m<2k
, this can be achieved by adding dummy pages with zero probability to appear.

Later we show that these two results are particularly useful to prove that
{\rm RoE}({\rm PLFU})
and
{\rm RoE}({\rm LRU})
only depend on the power-law parameter
\alpha
under power-law or multi-core power-law assumption.

Furthermore, we derive two additional formulas to upper bound
{\rm RoE}({\rm PLFU})
as follows.

Theorem 3
.

{\rm RoE}({\rm PLFU})\leq 2\cdot\sum_{i=2}^{k+1}\frac{p_{k+1}}{p[i:k+1]}
.

Theorem 4
.

{\rm RoE}({\rm PLFU})\leq\frac{8}{p[k+1:m]}-4
.

Remark that depending on the given distribution
\pi
, each of the three upper bounds on
{\rm RoE}({\rm PLFU})
can be better than the other two.

Technical Overview.

We briefly introduce our techniques as follows.
To upper bound
{\rm RoE}({\rm ALG})
for an online paging algorithm
{\rm ALG}
(not only PLFU or LRU), a typical method is to first decompose any given sequence
\sigma
into
phases
, such that it is easier to both lower bound the cost of
{\rm OPT}
and also upper bound the cost of
{\rm ALG}
in each phase.
In previous works, the phases are defined recursively for the class of marking algorithms: each phase
i
starts by seeing the first page and terminates right before seeing
k+1
different pages.
By defining a page being
clean
in phase
i
if it is requested within phase
i
but not requested in previous phase
i-1
,
{\rm OPT}
has to pay a cost at least the number of clean pages of phase
i
during the two consecutive phases
i-1
and
i
.
This method of dividing
\sigma
into phases has been used to derive the competitive ratio of the classic online paging algorithms (e.g. LRU
[
45
]
and Marker
[
23
]
) in the adversarial model.

To prove Theorem
1
, we use the above original definition of phases used to analyse marking algorithms.
We prove that the expected number of clean pages in each phase (except for the last one) is at least

\min\left\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\right\}\cdot\frac{k}{8}.

Due to the fact that any
marking
algorithm
{\rm ALG}
(including LRU, Marker, etc, later defined in Section
3.1
) produces a cost of at most
k
in any phase, we immediately have this upper bound for LRU. Thanks to the fact that PLFU has a cost rate
2\cdot p[k+1:m]
and no online algorithm can produce a cost rate less than
p[k+1:m]
, we have
{\rm RoE}({\rm PLFU})\leq 2\cdot{\rm RoE}({\rm ALG})
for any online paging algorithm
{\rm ALG}
.
As a consequence, we have Theorem
2
.

To derive the two additional upper bound on
{\rm RoE}({\rm PLFU})
, we follow a similar strategy to derive
{\rm RoE}({\rm ALG})
, but using a different notion of phases, as well as being careful when taking the expectation over all possible sequences.
More specifically, to prove Theorem
3
, we define phases recursively as follows.
We denote the pages with indices
1,\dots,k
as
big
pages and the pages with indices
k+1,\dots,m
as
small
pages.
The current phase terminates when all the big pages have been requested (during that phase), and the next phase starts.
In this way,
{\rm OPT}
has to pay at least the number of small pages seen in this phase.
Using this new definition of phases, we obtain
{\rm RoE}({\rm PLFU})\leq 2\cdot\sum_{i=2}^{k+1}\frac{p_{k+1}}{p[i:k+1]}
. As a corollary, this upper bound is capped by
O(\log k)
for any distribution
\pi
, i.e., PLFU achieves a ratio-of-expectations of O(
\log k
) in the stochastic input model.
See Appendix
A
for detailed proof of Theorem
3
.

Next, to prove Theorem
4
, we use the
cost rate
of a paging algorithm
{\rm ALG}
, i.e., the expected cost of
{\rm ALG}

per request
,

{\rm cr}({\rm ALG})=\displaystyle\overline{\lim_{n\to\infty}}\frac{\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]}{n}.

Notice that
{\rm cr}({\rm ALG})\leq c
and
{\rm cr}({\rm OPT})\geq c^{\prime}
(
c,c^{\prime}>0
) implies that
{\rm RoE}({\rm ALG})\leq c/c^{\prime}
.
Since
{\rm cr}({\rm PLFU})=2\cdot p[k+1:m]
, we only need to prove that

{\rm cr}({\rm OPT})\geq\frac{p[k+1:m]^{2}}{4-2\cdot p[k+1:m]}.

To obtain this bound, we again use a different definition of phases (see Appendix
B
for detailed proof).

3.1
Proof of Theorem
1
and
2

In this section, we focus on proving Theorem
1
:

{\rm RoE}({\rm LRU})\leq\frac{16}{\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}}.

However, before we prove this theorem, we first explain why Theorem
2
follows immediately from the fact that
{\rm RoE}({\rm PLFU})\leq 2\cdot{\rm RoE}({\rm ALG})
for any paging algorithm
{\rm ALG}
.

Proposition 5
.

Given any online paging algorithm
{\rm ALG}
,

{\rm RoE}({\rm PLFU})\leq 2\cdot{\rm RoE}({\rm ALG}).

Proof.

By definition of ratio-of-expectations, we only need to prove

\frac{\mathbb{E}_{\sigma}^{n}[{\rm PLFU}(\sigma)]}{2n}\leq\frac{\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]}{n}

for any
n
.
On one hand,

\frac{\mathbb{E}_{\sigma}^{n}[{\rm PLFU}(\sigma)]}{2n}=p[k+1:m].

On the other hand, given any online paging algorithm
{\rm ALG}
(deterministic or randomized), before processing any request
r
, let
Q
denote the pages inside the cache (
|Q|\leq k
), then the probability to face a page fault at request
r
is at least
1-\sum_{i\in Q}p_{i}\geq p[k+1:m],
which implies

\frac{\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]}{n}\geq\frac{n\cdot p[k+1:m]}{n}=p[k+1:m].

In this way, we have this proposition.
∎

Now we prove Theorem
1
, which heavily depends on the fact that LRU belongs to a class of paging algorithms called marking.
Recall from Section
1
that the marking algorithms have the following properties.

-

A marking algorithm processes the sequence of requests in phases. At the beginning of each phase, all the pages inside the cache (if existed) are unmarked; the first phase starts from the first request in the given sequence.

-

When a page is requested (in a phase), it is marked immediately. At a page fault, an unmarked page in the cache is evicted to make room for the requested page; if all the
k
pages in the cache are marked, then the current phase terminates, all the pages become unmarked and the next phase starts.

-

Given any two consecutive phases
\phi^{\prime}
,
\phi
, if a page is requested in phase
\phi
but not requested in phase
\phi^{\prime}
, then this page is called a clean page of phase
\phi
.

For any complete phase
\phi
, let
P(\phi)
denote the
k
pages requested in this phase and let
s(\phi)
denote the number of clean pages in phase
\phi
, i.e.,

s(\phi):=|P(\phi)-P(\phi^{\prime})|.

We immediately obtain the following property on
{\rm OPT}
for any given sequence of requests.

Proposition 6
.

Given any two consecutive phases
\phi^{\prime}
,
\phi
, any paging algorithm (including
{\rm OPT}
) produces a cost of at least
s(\phi)
during these two phases.

Proof.

Notice that exactly
k+s(\phi)
different pages have been requested during the phases
\phi^{\prime}
and
\phi
.
Since the cache can contain at most
k
different pages, for any paging algorithm, irrespective of the full cache configuration before the start of phase
\phi^{\prime}
, it must have faced at least
k+s(\phi)-k=s(\phi)
evictions during the phases
\phi^{\prime}
and
\phi
, and hence has to pay a cost at least
s(\phi)
during the phases
\phi^{\prime}
and
\phi
.
∎

Given any marking algorithm
{\rm ALG}
, let
\mathbb{E}_{\phi}[{\rm ALG}(\phi)]
denote the expected cost of
{\rm ALG}
produced in a complete phase
\phi
and let
\mathbb{E}_{\phi}[s(\phi)]
denote the expected number of clean pages in a complete phase
\phi
.
To upper bound
{\rm RoE}({\rm ALG})
, we only need to upper bound
\frac{\mathbb{E}_{\phi}[{\rm ALG}(\phi)]}{\mathbb{E}_{\phi}[s(\phi)]}
.
Denoting by
\sigma\sim\ell
-CP if
\sigma
is a random sequence that consists of
\ell
complete phases,

\displaystyle{\rm RoE}({\rm ALG})

\displaystyle=

\displaystyle\overline{\displaystyle\lim_{n\to\infty}}\frac{\mathbb{E}_{\sigma}^{n}[{\rm ALG}(\sigma)]}{\mathbb{E}_{\sigma}^{n}[{\rm OPT}(\sigma)]}=\overline{\displaystyle\lim_{\ell\to\infty}}\frac{\mathbb{E}_{\sigma}^{\ell\text{-}{\rm CP}}[{\rm ALG}(\sigma)]}{\mathbb{E}_{\sigma}^{\ell\text{-}{\rm CP}}[{\rm OPT}(\sigma)]}

(1)

\displaystyle\leq

\displaystyle 2\cdot\overline{\displaystyle\lim_{\ell\to\infty}}\frac{\mathbb{E}_{\sigma}^{\ell\text{-}{\rm CP}}[\sum_{\phi}^{\ell}{\rm ALG}(\phi)]}{\mathbb{E}_{\sigma}^{\ell\text{-}{\rm CP}}[\sum_{\phi}^{\ell}s(\phi)]}=2\cdot\frac{\mathbb{E}_{\phi}[{\rm ALG}(\phi)]}{\mathbb{E}_{\phi}[s(\phi)]}.

By definition, we observe the following property.

Proposition 7
.

Given any marking algorithm
{\rm ALG}
, we have
\mathbb{E}_{\phi}[{\rm ALG}(\phi)]\leq k
.

Proof.

Once a page is marked in a phase, it stays in the cache until the end of the current phase. In particular, requesting a marked page does not result in a page fault. Since the cache size is
k
, a marking algorithm has a cost of at most
k
during any phase.
∎

As a result, to prove Theorem
1
, we only need to prove the following lemma.

Lemma 8
.

\mathbb{E}_{\phi}[s(\phi)]\geq\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}\cdot\frac{k}{8}.

Proof.

We (again) remark here that w.l.o.g. we can assume that
m\geq 2k
by adding dummy pages with zero probability to be requested.

To prove the lemma, we show that, given any
k
distinct pages
Q\subseteq\mathcal{M}
requested in the previous phase
\phi^{\prime}
, i.e.,
P(\phi^{\prime})=Q
,

\displaystyle\mathbb{E}_{\phi}[s(\phi)\,|\,P(\phi^{\prime})=Q]\geq\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}\cdot\frac{k}{8}.

We first partition
P(\phi^{\prime})
into two sets
P_{1}(\phi^{\prime})
and
P_{2}(\phi^{\prime})
as follows:

P_{1}(\phi^{\prime})=P(\phi^{\prime})\cap\Big\{1,\dots,\frac{k}{2}\Big\},

P_{2}(\phi^{\prime})=P(\phi^{\prime})\cap\Big\{\frac{k}{2}+1,\dots,m\Big\}.

Besides, define

Q_{1}(\phi^{\prime})=\Big\{1,\dots,\frac{k}{2}\Big\}-P_{1}(\phi^{\prime}).

By definition,
|P_{1}(\phi^{\prime})|\leq\frac{k}{2}
and
|P_{2}(\phi^{\prime})|\geq\frac{k}{2}
.

Note that
k
different pages are drawn from
\{1,\dots,m\}
in phase
\phi
according to
\pi
without replacement.
We can relax the constraint that the first requested page in phase
\phi
must be a clean page (recall that a clean page is in
P(\phi)
but not in
P(\phi^{\prime})
) and this relaxation can only make
\mathbb{E}_{\phi}[s(\phi)\,|\,P(\phi^{\prime})]
smaller.
As a result, at least
k-|P_{1}(\phi^{\prime})|\geq\frac{k}{2}
pages are drawn from
Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}
in phase
\phi
according to
\pi
without replacement.
For each page
i
drawn from
Q_{1}(\phi^{\prime})
in phase
\phi
, by definition,
i\notin P(\phi^{\prime})
and hence it is a clean page;
for each page
i
drawn from
\{\frac{k}{2}+1,\dots,m\}
in phase
\phi
, if
i\notin P_{2}(\phi^{\prime})
, it is also a clean page.

Given any
k
pages set
P(\phi)
, we have

\displaystyle s(\phi)=|P(\phi)-P(\phi^{\prime})|\geq|P(\phi)\cap\big(Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}\big)-P(\phi^{\prime})|.

To lower bound
\mathbb{E}_{\phi}[s(\phi)\,|\,P(\phi^{\prime})]
, we thus need to lower bound the expected number of clean pages amongst the pages drawn from
Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}
in phase
\phi
.

We first consider the case
|Q_{1}(\phi^{\prime})|\geq\frac{k}{4}
(i.e., less than
\frac{k}{4}
pages from
\{1,\dots,\frac{k}{2}\}
are drawn in the previous phase
\phi^{\prime}
).
When collecting the
j^{\text{th}}
(
j\leq\frac{k}{8}
) distinct page from
Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}
in phase
\phi
(with
j-1
different pages
R
already drawn from
Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}
), the probability to collect a (clean) page among
Q_{1}(\phi^{\prime})
is

\displaystyle\frac{\sum_{i\in Q_{1}(\phi^{\prime})\cup\{\frac{k}{2},\dots,m\}-R}p_{i}}{\sum_{i\in Q_{1}(\phi^{\prime})-R}p_{i}+\sum_{i=\frac{k}{2}+1}^{m}p_{i}}\geq\frac{p[\frac{k}{2}-(j-1):\frac{k}{2}]+p[\frac{k}{2}+k:m]}{p[\frac{k}{2}-(j-1):\frac{k}{2}]+p[\frac{k}{2}+1:m]}\geq\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]}.

(the first inequality is due to the fact that
\sum_{i\in R}p_{i}\leq\sum_{i=1}^{j-1}p_{i}
and
\frac{a-c}{b-c}\leq\frac{a}{b}
for
0<c<a<b
).
Therefore, the expected clean pages number among the pages drawn from
Q_{1}(\phi^{\prime})\cup\{\frac{k}{2}+1,\dots,m\}
in phase
\phi
, is at least

\sum_{j=1}^{\frac{k}{8}}\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]}=\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]}\cdot\frac{k}{8}.

Now we consider the case
|Q_{1}(\phi^{\prime})|<\frac{k}{4}
(i.e., more than
\frac{k}{4}
pages from
\{1,\dots,\frac{k}{2}\}
are drawn in the previous phase
\phi^{\prime}
).
In other words, less than
k-\frac{k}{4}=\frac{3k}{4}
pages are drawn among
\{\frac{k}{2}+1,\dots,m\}
in the previous phase
\phi^{\prime}
.
As a result, when collecting the
j^{\text{th}}
(
j\leq\frac{k}{8}
) distinct page from
\{\frac{k}{2},\dots,m\}
in phase
\phi
(with
j-1
different pages
R
already drawn from
\{\frac{k}{2},\dots,m\}
), the probability to collect a clean page is at least

\displaystyle\frac{\sum_{i\in\{\frac{k}{2}+1,\dots,m\}-P_{2}(\phi^{\prime})-R}p_{i}}{\sum_{i=\frac{k}{2}+1}^{m}p_{i}}\geq\frac{p[\frac{k}{2}+\frac{3k}{4}+\frac{k}{8}:m]}{p[\frac{k}{2}:m]}=\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}.

In this way, the expected number of clean pages among the pages drawn from
\{\frac{k}{2}+1,\dots,m\}
in phase
\phi
, is at least

\sum_{j=1}^{\frac{k}{8}}\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}=\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\cdot\frac{k}{8}.

In summary,
\mathbb{E}_{\phi}[s(\phi)\,|\,P(\phi^{\prime})]
is thus at least

\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}\cdot\frac{k}{8},

which concludes the lemma.
∎

4
The power-law case

Recall that the web requests from an app or a website generally follow power-law distribution
[
15
]
.
Since it is popular to apply LRU or LFU (or hybrid in both of them) to maintain the cache and this type of caching replacement policies perform well in practice, our goal is to provide a theoretical explanation of this observation.
Thanks to Theorem
1
and
2
, we show that
{\rm RoE}({\rm LRU})=O(1)
and
{\rm RoE}({\rm PLFU})=O(1)
when the random sequence follows a power-law distribution and the number of all pages is at least twice the cache size (i.e.,
m\geq 2k
).
4
4

4

It indeed makes sense to assume
m\geq 2k
since the web page number is way larger than the cache size in practice.

Definition of power-law distribution.

Given a power-law distribution
\pi
, by sorting all the
m
pages in the decreasing order of their probabilities, we have

p_{i}=\frac{1}{L(\alpha,m)}\cdot\frac{1}{i^{\alpha}}

for each
i\in\{1,2,\dots,m\}
.
Here,

L(\alpha,m):=\sum_{i=1}^{m}\frac{1}{i^{\alpha}}=\begin{cases}O(1)&\textit{ when }\alpha>1;\\
\Theta(\log m)&\textit{ when }\alpha=1;\\
\Theta(m^{1-\alpha})&\textit{ when }\alpha\in(0,1).\end{cases}

LRU and PLFU achieves O(1) ratio-of-expectations in the power-law case.

Thanks to Theorem
1
and
2
, we only need to show that

\min\Big\{\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]},\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\Big\}:=Formula

can be lower bounded by a function only depending on
\alpha
(seen as a constant) but not
m
or
k
.
Indeed this is true.
Note that given
m\geq 2k
,

\frac{p[\frac{3k}{8}:\frac{k}{2}]+p[\frac{3k}{2}:m]}{p[\frac{3k}{8}:m]}\geq 1-\frac{p[\frac{k}{2}:\frac{3k}{2}]}{p[\frac{3k}{8}:2k]}.

When
\alpha>1
, we have

1-\frac{p[\frac{k}{2}:\frac{3k}{2}]}{p[\frac{3k}{8}:2k]}\geq 1-\frac{2^{\alpha-1}-(\frac{2}{3})^{\alpha-1}}{(\frac{8}{3})^{\alpha-1}-(\frac{1}{2})^{\alpha-1}}\text{ and }\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\geq\frac{p[\frac{12k}{8}:2k]}{p[\frac{k}{2}:2k]}\geq\frac{(\frac{4}{3})^{\alpha-1}-1}{4^{\alpha-1}-1},

which implies

Formula\geq\min\bigg\{1-\frac{2^{\alpha-1}-(\frac{2}{3})^{\alpha-1}}{(\frac{8}{3})^{\alpha-1}-(\frac{1}{2})^{\alpha-1}},\frac{(\frac{4}{3})^{\alpha-1}-1}{4^{\alpha-1}-1}\bigg\}.

When
\alpha=1
, we have

1-\frac{p[\frac{k}{2}:\frac{3k}{2}]}{p[\frac{3k}{8}:2k]}\geq 1-\frac{\log 3}{\log\frac{16}{3}}\text{ and }\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\geq 1-\frac{p[\frac{k}{2}:\frac{11k}{8}]}{p[\frac{k}{2}:2k]}\geq 2-\frac{\log 11}{\log 4},

which implies
Formula\geq 2-\frac{\log 11}{\log 4}>1-\frac{\log 3}{\log 4}
.

When
\alpha\in(0,1)
, we have

1-\frac{p[\frac{k}{2}:\frac{3k}{2}]}{p[\frac{3k}{8}:2k]}\geq 1-\frac{3^{1-\alpha}-1}{4^{1-\alpha}-1}\text{ and }\frac{p[\frac{11k}{8}:m]}{p[\frac{k}{2}:m]}\geq 1-\frac{p[\frac{k}{2}:\frac{11k}{8}]}{p[\frac{k}{2}:2k]}>1-\frac{3^{1-\alpha}-1}{4^{1-\alpha}-1},

which implies
Formula\geq 1-\frac{3^{1-\alpha}-1}{4^{1-\alpha}-1}
.

5
The multi-core power-law case

Now we show that LRU and PLFU achieve constant ratio-of-expectations (i.e., only depending on the power-law parameter
\alpha
) in the multi-core power-law case, where the probability
\tilde{p}_{i}
that a page
i
is requested (in at least one of the
\kappa
sequences) at any time is equal to

\tilde{p}_{i}=C\cdot(1-(1-p_{i})^{\kappa})\text{\ with\ }p_{i}=\frac{1}{L(\alpha,m)}\cdot\frac{1}{i^{\alpha}},

where
C
is a normalization constant.

On one hand, recall that the cost produced by any core in a complete phase is no more than
k
(see Proposition
7
). On the other hand, according to Lemma
8
, the expected number of clean pages in a complete phase is at least

\min\Big\{\frac{\tilde{p}[\frac{3k}{8}:\frac{k}{2}]+\tilde{p}[\frac{3k}{2}:m]}{\tilde{p}[\frac{3k}{8}:m]},\frac{\tilde{p}[\frac{11k}{8}:m]}{\tilde{p}[\frac{k}{2}:m]}\Big\}\cdot\frac{k}{8}.

Again,

6
Concluding remarks

In this paper, we study the online paging problem in the stochastic input model. First, we observe that in modern cloud systems Pareto type II distributions are present, whereas previously only Pareto type I distributions were reported. We provide an model explaining this behaviour which we call multi-core power-law. In our opinion, this indicates that stochastic data for testing caching strategies shall include this more general model. Second, we provide theoretical explanation for the good performance of LRU and LFU-based online paging algorithms for data following power-law and multi-core power-law distribution. Up to our knowledge this is the first known throughout proof of this fact for these types of stochastic distributions.

We conclude our work by discussing some lower bounds on the ratio-of-expectations for stochastic online paging and some future directions.

O(\log k)

In the arbitrary input model, the randomized online algorithm

In other words,

In the stochastic input model, does there exist an online paging algorithm achieving ratio-of-expectation better than

?
Unfortunately,

remains the best performance ratio for an online paging algorithm: when the number of all pages is

{\rm ALG}
achieves

To explain this, we again divide any given random sequence into phases recursively using the method when defining the class of marking algorithms.
In this way, each phase terminates right before seeing
k+1
pages, i.e., all pages.
Note that the offline optimal solution
{\rm OPT}
only produces a cost of 1 at the beginning of each phase.
However, in the stochastic online situation, any paging algorithm produces a cost rate of
\frac{1}{k+1}
to deal with each request.
On the other hand, similar as for the Coupon Collector’s problem, the expected length of a complete phase is exactly

1+\frac{1}{1-\frac{1}{k+1}}+\frac{1}{1-\frac{2}{k+1}}+\dots+(\frac{1}{1-\frac{k}{k+1}}-1)=(k+1)\cdot H_{k}.

This is because the probability to collect the

new page in a complete phase is equal to

(since
i-1
pages are already at hand), and according to geometrical distribution property, the expected length to collect the
i

\frac{1}{1-\frac{i-1}{k+1}}

Since each phase terminates right before seeing all the
k+1

k+1

As a result, the expected cost of any algorithm
{\rm ALG}
in a complete phase is
\frac{1}{k+1}\cdot(k+1)\cdot H_{k}=H_{k}
, which establishes
{\rm RoE}({\rm ALG})=H_{k}=O(\log k)
.

{\rm LRU}

To prove

k+1

k+1

Given the (random) sequence, let

Let

By phase definition, all the pages need to be requested within

\phi_{2}

i

\phi_{1}\phi_{2}

Since there are in total
k+1

Such a page is referred to as the

{\rm LRU}
faces a page fault whenever the missing page is requested.
Besides, during
[t_{0},t_{k-1}]

{\rm LRU}

resides in the cache - this is because, such a small page is placed in the cache at time

and for every page fault arising during

Note that, for any

By linearity of expectation, the total number of page faults during the time interval

is equal to

\sum_{i=1}^{k-1}\frac{1}{k+1-i}=\sum_{i=1}^{k-1}\frac{1}{i}=H_{k-1}=\Omega(\log k).

Future directions.

One future direction is to study a more complicated but practical stochastic model following power-law distribution, for example, the Markov paging model
[
35
]
(where the probability to request a page depends on the previously requested page).
Another future direction is to consider a prefetching problem with stochastic input (especially when the requests follow power-law distribution).
That is, right after dealing with each request and before the arrival of the next request, it is allowed to swap
p\leq k
pages inside the cache with no cost incurred — this is indeed witnessed nowadays in the multi-cores caching system, one core processing the requests and the other core working on prefetching (according to the recommendations learned from the history data). Designing a “good” prefetching algorithm is challenging both from theoretical and practical point of view.
