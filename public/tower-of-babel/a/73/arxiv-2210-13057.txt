Certifying Induced Subgraphs in Large Graphs
Ulrich Meyer, Hung Tran, Konstantinos Tsakalidis

Abstract
We introduce I/O-optimal certifying algorithms for bipartite graphs, as well as for the classes of split, threshold, bipartite chain, and trivially perfect graphs. When the input graph is a class member, the certifying algorithm returns a certificate that characterizes this class. Otherwise, it returns a forbidden induced subgraph as a certificate for non-membership. On a graph with n n vertices and m m edges, our algorithms take optimal O ​ ( sort ​ ( n + m ) ) O({\textsc{sort}(n+m)}) I/Os in the worst case or with high probability for bipartite chain graphs, and the certificates are returned in optimal I/Os. We give implementations for split and threshold graphs and provide an experimental evaluation.

Certifying bipartiteness in internal memory takes time linear in the number of edges by any traversal of the graph.
However, all known external memory breadth-first search

Time-Forward Processing

Time-forward processing

[
12
]

These dependencies are typically modeled by a directed acyclic graph

where every vertex
v_{i}\in V
models the computation of
z_{i}
and an edge
(v_{i},v_{j})\in E

Computing a solution then requires the algorithm to traverse

according to some topological order

of the vertices

The TFP technique achieves this in the following way: after

has been calculated, the algorithm inserts a message
\langle v_{j},z_{i}\rangle
into a minimum priority-queue data structure for every successor
(v_{i},v_{j})\in E
where the items are sorted by the recipients according to

By construction,

receives all required values

of its predecessors

as messages in the data structure.
Since these predecessors already removed their messages from the data structure, items addressed to
v_{j}
are currently the smallest elements in the data structures and thus can be dequeued with a delete-minimum operation. By using suitable external memory priority-queues
[
3
]
, TFP incurs
O({\textsc{sort}(k)})
I/Os, where
k
is the number of messages sent.

Bipartite chain graphs are bipartite graphs where one part of the bipartition has an nno

We follow the linear time internal memory approach of

We have implemented our external memory certifying algorithms for split and threshold graphs in

STXXL offers external memory versions of fundamental algorithmic building blocks like scanning, sorting and several data structures.
Our benchmarks are built with

For

In

-instances.
It is clear that the performance of both external memory algorithms is not impacted by the main memory barrier while the running time of their internal memory counterparts already increases when at least half the main memory is used.

Figure 1

5
Conclusions

We have presented the first I/O-efficient certifying recognition algorithms for split, threshold, trivially perfect, bipartite and bipartite chain graphs.
Our algorithms require
O({\textsc{sort}(n+m)})
I/Os matching common lower bounds for many algorithms in external memory.
It would be interesting to further extend the scope of certifying algorithms to more graph classes for the external memory regime.
