Abstract
Let G G be a graph and C C a finite set of colours. A vertex colouring f : V ⁡ ( G ) → C f:V(G)\to C is complete if for any pair of distinct colours c 1 , c 2 ∈ C c_{1},c_{2}\in C one can find an edge { v 1 , v 2 } ∈ E ⁡ ( G ) \{v_{1},v_{2}\}\in E(G) such that f ⁡ ( v i ) = c i f(v_{i})=c_{i} , i = 1 , 2 i=1,2 . The achromatic number of G G is defined to be the maximum number achr ⁡ ( G ) \mathrm{achr}(G) of colours in a proper complete vertex colouring of G G . In the paper achr ⁡ ( K 6 ​ □ ​ K q ) \mathrm{achr}(K_{6}\square K_{q}) is determined for any integer q q such that either 8 ≤ q ≤ 40 8\leq q\leq 40 or q ≥ 42 q\geq 42 is even.
