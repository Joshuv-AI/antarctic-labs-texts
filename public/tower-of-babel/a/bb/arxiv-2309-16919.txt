Study of two-body doubly charmful baryonic B B decays with S ​ U ​ ( 3 ) SU(3) flavor symmetry
Yu-Kuo Hsiao

Abstract
Within the framework of S ​ U ​ ( 3 ) SU(3) flavor symmetry, we investigate two-body doubly charmful baryonic B → 𝐁 c ​ 𝐁 ¯ c ′ B\to{\bf B}_{c}\bar{\bf B}^{\prime}_{c} decays, where 𝐁 c ​ 𝐁 ¯ c ′ {\bf B}_{c}\bar{\bf B}^{\prime}_{c} represents the anti-triplet charmed dibaryon. We determine the S ​ U ​ ( 3 ) f SU(3)_{f} amplitudes and calculate ℬ ⁡ ( B − → Ξ c 0 ​ Ξ ¯ c − ) = ( 3.4 − 0.9 + 1.0 ) × 10 − 5 {\cal B}(B^{-}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{-})=(3.4^{+1.0}_{-0.9})\times 10^{-5} and ℬ ⁡ ( B ¯ s 0 → Λ c + ​ Ξ ¯ c − ) = ( 3.9 − 1.0 + 1.2 ) × 10 − 5 {\cal B}(\bar{B}^{0}_{s}\to\Lambda_{c}^{+}\bar{\Xi}_{c}^{-})=(3.9^{+1.2}_{-1.0})\times 10^{-5} induced by the single W W -emission configuration. We find that the W W -exchange amplitude, previously neglected in studies, needs to be taken into account. It can cause a destructive interfering effect with the W W -emission amplitude, alleviating the significant discrepancy between the theoretical estimation and experimental data for ℬ ⁡ ( B ¯ 0 → Λ c + ​ Λ ¯ c − ) {\cal B}(\bar{B}^{0}\to\Lambda_{c}^{+}\bar{\Lambda}_{c}^{-}) . To test other interfering decay channels, we calculate ℬ ⁡ ( B ¯ s 0 → Ξ c 0 ​ ( + ) ​ Ξ ¯ c 0 ​ ( + ) ) = ( 3.0 − 1.1 + 1.4 ) × 10 − 4 {\cal B}(\bar{B}^{0}_{s}\to\Xi_{c}^{0(+)}\bar{\Xi}_{c}^{0(+)})=(3.0^{+1.4}_{-1.1})\times 10^{-4} and ℬ ⁡ ( B ¯ 0 → Ξ c 0 ​ Ξ ¯ c 0 ) = ( 1.5 − 0.6 + 0.7 ) × 10 − 5 {\cal B}(\bar{B}^{0}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0})=(1.5^{+0.7}_{-0.6})\times 10^{-5} . We estimate non-zero branching fractions for the pure W W -exchange decay channels, specifically ℬ ⁡ ( B ¯ s 0 → Λ c + ​ Λ ¯ c − ) = ( 8.1 − 1.5 + 1.7 ) × 10 − 5 {\cal B}(\bar{B}^{0}_{s}\to\Lambda_{c}^{+}\bar{\Lambda}_{c}^{-})=(8.1^{+1.7}_{-1.5})\times 10^{-5} and ℬ ⁡ ( B ¯ 0 → Ξ c + ​ Ξ ¯ c − ) = ( 3.0 ± 0.6 ) × 10 − 6 {\cal B}(\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Xi}_{c}^{-})=(3.0\pm 0.6)\times 10^{-6} . Additionally, we predict ℬ ⁡ ( B c + → Ξ c + ​ Ξ ¯ c 0 ) = ( 2.8 − 0.7 + 0.9 ) × 10 − 4 {\cal B}(B^{+}_{c}\to\Xi_{c}^{+}\bar{\Xi}_{c}^{0})=(2.8^{+0.9}_{-0.7})\times 10^{-4} and ℬ ⁡ ( B c + → Λ c + ​ Ξ ¯ c 0 ) = ( 1.6 − 0.4 + 0.5 ) × 10 − 5 {\cal B}(B^{+}_{c}\to\Lambda_{c}^{+}\bar{\Xi}_{c}^{0})=(1.6^{+0.5}_{-0.4})\times 10^{-5} , which are accessible to experimental facilities such as LHCb.

IV
Discussion and Conclusions

The
SU(3)_{f}
approach enables us to explore all possible
B\to{\bf B}_{c}\bar{\bf B}^{\prime}_{c}
decays,
as summarized in Table
1
. Furthermore, it helps in deriving constraints on
SU(3)_{f}
relations,
facilitating the decomposition of amplitudes into
e
and
c^{\prime}
terms.
These terms parameterize the
W_{\rm ex}
and
W_{\rm em}
topologies
depicted in Fig.
1
a and Fig.
1
b(c), respectively.

In
b\to c\bar{c}s
induced decays, the
SU(3)_{f}
symmetry unequivocally establishes that
both
\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Lambda}_{c}^{-}
and
B^{-}\to\Xi_{c}^{0}\bar{\Lambda}_{c}^{-}

solely proceed through the
W_{\rm em}
topology, supporting
earlier considerations
[
17
,
16
]
.
The nearly identical branching fractions, as shown in Eq. (
1
),
also provide consistent evidence.
In our latest findings, we unveil additional insights. For
\bar{B}^{0}_{s}\to\Xi_{c}^{0(+)}\bar{\Xi}_{c}^{0(-)}
,
the interference of the
W_{\rm ex}
amplitude with the
W_{\rm em}
amplitude
adds a new contribution to the decay process.
Furthermore,
\bar{B}^{0}_{s}\to\Lambda_{c}^{+}\bar{\Lambda}_{c}^{-}

represents a pure
W_{\rm ex}
decay,
offering a clear and distinct case for experiments to clarify
if the
W_{\rm ex}
contribution can be neglected.

The
b\to c\bar{c}d
induced decays with
|V_{cd}/V_{cs}|\simeq 0.05
are more suppressed.
Unlike
{\cal M}(\bar{B}^{0}_{s}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0})={\cal M}(\bar{B}^{0}_{s}\to\Xi_{c}^{+}\bar{\Xi}_{c}^{-})
,

\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Xi}_{c}^{-}
as a pure
W_{\rm ex}
decay
does not share an isospin relation with
\bar{B}^{0}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0}
,
which is against our naive expectation. Instead, the equality relation arises from

{\cal M}(\bar{B}^{0}\to\Lambda_{c}^{+}\bar{\Lambda}_{c}^{-})={\cal M}(\bar{B}^{0}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0})
.
Moreover, an interesting triangle relation exists:

\displaystyle{\cal M}(\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Xi}_{c}^{-})+{\cal M}(B^{-}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{-})={\cal M}(\bar{B}^{0}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0})\,.

(13)

If the
W_{\rm{ex}}
contribution is negligible,
the relation is simplified to
{\cal M}(B^{-}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{-})\simeq{\cal M}(\bar{B}^{0}\to\Xi_{c}^{0}\bar{\Xi}_{c}^{0})
, resulting in nearly equal branching fractions.

It can be challenging to compute the
W_{\rm ex}
and
W_{\rm em}
amplitudes.
For example, the factorization approach derives the
W_{\rm ex}
amplitude as

{\cal M}_{\rm wex}\propto f_{B}q^{\mu}\langle{\bf B}_{c}\bar{\bf B}^{\prime}_{c}|\bar{c}\gamma_{\mu}(1-\gamma_{5})c|0\rangle

1

the similar deviation for
{\cal M}(B\to{\bf B}_{c}\bar{\bf B})
in Ref.
[
13
]
.
,
where
f_{B}
is the B meson decay constant,
q^{\mu}
the momentum transfer, and
the matrix elements present the vacuum (0) to
{\bf B}_{c}\bar{\bf B}^{\prime}_{c}
production.
As information on the
0\to{\bf B}_{c}\bar{\bf B}^{\prime}_{c}
production is lacking,
a model calculation is currently unavailable. For a calculation on
{\cal M}_{\rm wem}
,
one proposes a meson propagator to provide an additional quark pair,
resulting in the branching fractions to be a few times
10^{-3}

for
\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Lambda}_{c}^{-}
and
B^{-}\to\Xi_{c}^{0}\bar{\Lambda}_{c}^{-}

[
17

Additionally, a theoretical attempt incorporating final state interactions yields

{\cal B}\simeq{\cal O}(10^{-3})

[

.
It appears that the above approaches may overestimate the
W_{\rm em}

Without relying on the aforementioned model calculations,
we determine
e
and
c^{\prime}
using the experimental data based on the
SU(3)_{f}
symmetry,
as described in Eq. (
12

By employing
|c^{\prime}|=(1.29\pm 0.18)~{\rm GeV}^{3}
, we successfully replicate

{\cal B}(\bar{B}^{0}\to\Xi_{c}^{+}\bar{\Lambda}_{c}^{-})=(7.2^{+2.1}_{-1.9})\times 10^{-4}
and

{\cal B}(B^{-}\to\Xi_{c}^{0}\bar{\Lambda}_{c}^{-})=(7.8^{+2.3}_{-2.0})\times 10^{-4}
