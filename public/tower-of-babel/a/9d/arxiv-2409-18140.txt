Globally conservative weak solutions for a class of two-component nonlinear dispersive wave equations beyond wave breaking
Yonghui Zhou, Xiaowan Li

Abstract
In this paper, we prove that the existence of globally conservative weak solutions for a class of two-component nonlinear dispersive wave equations beyond wave breaking. We first introduce a new set of independent and dependent variables in connection with smooth solutions, and transform the system into an equivalent semi-linear system. We then establish the global existence of solutions for the semi-linear system via the standard theory of ordinary differential equations. Finally, by the inverse transformation method, we prove the existence of the globally conservative weak solution for the original system.

Preliminary

dispersive wave equations

For smooth solutions, differentiating (

Multiplying (

Define

Then (

Integrating (

) with respect to

and

, we get

E(t)=\int_{\mathbb{R}}(u^{2}(t,x)+u_{x}^{2}(t,x)+\rho^{2})dx=E(0).

Since

\displaystyle\|P\|_{L^{2}}\leq

\displaystyle\frac{1}{2}\left\|e^{-|x|}\right\|_{L^{1}}\|g(u)\|_{L^{2}}+\frac{1}{2}\left\|e^{-|x|}\right\|_{L^{2}}\left\|\frac{f^{\prime\prime}(u)}{2}u_{x}^{2}+\frac{\rho^{2}}{2}\right\|_{L^{1}}

\displaystyle\leq

\displaystyle C\left(\|g(u)\|_{L^{2}}+\|u\|_{1}^{2}+\|\rho\|_{L^{2}}\right)

\displaystyle\leq

\displaystyle CE(0).

Similarly, we can obtain

(2.11)

\frac{dx(t)}{dt}=f^{\prime}(u(t,x)).

4
Global solutions of the semi-linear system

In this section, we will prove the global existence of solutions for the semi-linear system. Let initial data
(u_{0}(x),\rho_{0}(x))=(\bar{u},\bar{\rho})\in H^{1}\times\left(L^{2}\cap L^{\infty}\right)
be given. We can transfer problem (
2.1
)-(
2.2
) into the following semi-linear system

\displaystyle\begin{cases}u_{T}=-P_{x},\\
\rho_{T}=-\left(\frac{1}{2}+\frac{f^{\prime\prime}(u)}{2}\right)\rho\tan\frac{w}{2},\\
w_{T}=2\left(g(u)-P+\frac{\rho^{2}}{2}\right)\cos^{2}\frac{w}{2}-f^{\prime\prime}(u)\sin^{2}\frac{w}{2},\\
v_{T}=\left(g(u)-P+\frac{f^{\prime\prime}(u)}{2}+\frac{\rho^{2}}{2}\right)v\sin w\end{cases}

(4.1)

subject to the initial data

\displaystyle\begin{cases}u(0,Z)=\bar{u}(\bar{x}(Z)),\\
\rho(0,Z)=\bar{\rho}(\bar{x}(Z)),\\
w(0,Z)=2\arctan\bar{u}_{x}(\bar{x}(Z)),\\

(4.2)

where
P
and

are given by (

)–(
3.12

It is easy to verify that system (

with the norm

\|(u,\rho,w,v)\|_{X}=\|u\|_{1}+\|\rho\|_{L^{2}}+\|\rho\|_{L^{\infty}}+\|w\|_{L^{2}}+\|w\|_{L^{\infty}}+\|v\|_{L^{\infty}}.

In what follows, we first prove the local existence of solutions for the Cauchy problem (

.

Let
(\bar{u},\bar{\rho})\in H^{1}\times\left(L^{2}\cap L^{\infty}\right)

)–(

Proof.

To establish the local well-posedness, it suffices to prove the operator determined by the
right-hand side of (

to

\displaystyle\Big\{-P_{x},\ -\left(\frac{1}{2}+\frac{f^{\prime\prime}(u)}{2}\right)\rho\tan\frac{w}{2},\ 2\left(g(u)-P+\frac{\rho^{2}}{2}\right)\cos^{2}\frac{w}{2}-f^{\prime\prime}(u)\sin^{2}\frac{w}{2},\

\displaystyle\Omega=\Big\{(u,\rho,w,v):\|u\|_{1}\leq\alpha,\|\rho\|_{L^{2}}\leq\beta,\|w\|_{L^{2}}\leq\theta,\|w\|_{L^{\infty}}\leq\pi,v(x)\in[v^{-},v^{+}]

It is clear that the maps

(T,Z)\rightarrow(t,x(T,Z))

is a surjective function in
\mathbb{R}^{2}
. Indeed, by (
4.3
) and (
5.1
), we get

\bar{x}(Z)-\sqrt{E(0)}T\leq x(T,Z)\leq\bar{x}(Z)+\sqrt{E(0)}T.

Then from (
3.3
), we deduce that

\lim_{Z\rightarrow\pm\infty}x(T,Z)=\pm\infty.

Therefore, the image of continuous map
(T,Z)\rightarrow(t,x(T,Z))
covers the entire half-plane
\mathbb{R}^{+}\times\mathbb{R}
.

Step 2.
We claim that

x_{Z}=v\cos^{2}\frac{w}{2}\ \ \text{for}\ \ T\geq 0,\ \ \text{a.e.}\ \ Z\in\mathbb{R}.

(5.6)

In fact, from (
4.1
) and (
4.24
), we get

\displaystyle\left(v\cos^{2}\frac{w}{2}\right)_{T}=

\displaystyle-w_{T}\sin\frac{w}{2}\cos\frac{w}{2}+v_{T}\cos^{2}\frac{w}{2}

\displaystyle=

\displaystyle-v\sin\frac{w}{2}\cos\frac{w}{2}\left(2(g(u)-P(Z))\cos^{2}\frac{w}{2}-f^{\prime\prime}(u)\sin^{2}\frac{w}{2}\right)

\displaystyle+v\sin w\cos^{2}\frac{w}{2}\left(g(u)-P(Z)+\frac{f^{\prime\prime}(u)}{2}\right)

\displaystyle=

\displaystyle\frac{f^{\prime\prime}(u)}{2}v\sin w

\displaystyle=

\displaystyle\left(f^{\prime}(u)\right)_{Z}.

(5.7)

On the other hand, (
5.2
) implies

\frac{\partial x_{Z}}{\partial T}=\left(f^{\prime}(u)\right)_{Z}.

(5.8)

Since the function
x\rightarrow 2\arctan\bar{u}_{x}(x)
is measure, the identity (
5.6
) holds for almost every
Z\in\mathbb{R}
and
T=0
. By the above computations, it remains true for all times
T\geq 0
. Furthermore, the function
x(T,Z)
is non-decreasing on
Z
when
T
is fixed.

Step 3.
Our goal is to show that
u(t,x)=u(T,x(T,Z))
is well defined. In fact,
if
x(T,Z_{1})=x(T,Z_{2})
for
Z_{1}<Z_{2}
, then we have

x(T,Z)=x(T,Z_{1})\ \text{for}\ Z\in[Z_{1},Z_{2}],

where we use the non-decreasing property of
x(T,Z)
on
Z
. From (
5.6
), we get

\cos\frac{w(T,Z)}{2}=0\ \text{for}\ Z\in[Z_{1},Z_{2}].

Therefore,

u(T,Z_{2})-u(T,Z_{1})=\int_{Z_{1}}^{Z_{2}}\frac{v}{2}\sin wds=0.

This proves
u(t,x)\rightarrow u(T,x(T,Z))
is well defined for all
t\geq 0
and
x\in\mathbb{R}
.

Step 4.
We discuss the regularity of
(u(t,\cdot),\rho(t,\cdot))

\displaystyle=

\displaystyle=

\displaystyle E(0).

(5.9)

By Lemma
