EPTAS for the Dual of Splittable Bin Packing with Cardinality Constraint Thanks: Supported in part by ISF - Israeli Science Foundation grant number 308/18.
G. Jaykrishnan, Asaf Levin

Abstract
The problem considered is the splittable bin packing with cardinality constraint. It is a variant of the bin packing problem where items are allowed to be split into parts but the number of parts in each bin is at most a given upper bound. Two versions of the splittable bin packing with cardinality constraint have been studied in the literature. Among these variants we consider the dual one where the objective is to minimize the maximum bin size while packing (may be fractional) the items to a given set of bins. We exhibit an EPTAS for the dual problem when the cardinality upper bound is part of the input. This result answers an open question raised by Epstein, Levin, and van Stee [ 16 ] .



1
Introduction

The splittable bin packing with cardinality constraint problem was suggested as a compromise between memory allocation and parallelism. In that setting, the problem allows memory sharing while limiting the number of ports i.e., the processors that can access the shared memory.
In this problem we have a set of items
T
. Each item
t
is associated with its
size

S_{t}\geq 0
. The item sizes are not bounded (from above).

A
fractional packing
of items to bins is a packing wherein the items are allowed to be split into parts (without any restriction on the sizes or the number of parts) and the parts can be packed to any bin without restriction except for the bins size. An optimal solution to bin packing, when fractional packing is allowed, can be obtained in polynomial time as follows. Pack items sequentially (in an arbitrary order) to bins and split items when the total size of parts in the current bin is about to exceed the bin size. In this optimal solution there is at most one partially filled bin. Enforcing constraints can make the problem hard. There are many constraints considered in literature. Limiting the number of parts generated from an item, limiting the part sizes, and item conflicts are some constraints considered in the literature. We consider the
cardinality constraint
which defines an upper bound
k
on the number of parts of different items in each bin. Enforcing this constraint makes the problem NP-hard. Two versions of the splittable bin packing with cardinality constraint have been studied in the literature.

The primal problem, denoted as
\mathsf{PSBP}
, is defined as follows. Given a bin size
\mathcal{Z}>0
, a feasible solution is a packing of all items to bins (fractional packing is allowed) such that the total size of parts of items in each bin is at most
\mathcal{Z}
and the number of parts of different items in each bin is at most
k
. The goal function is to minimize the total number of used bins.

The dual problem, named the
Dual Splittable Bin Packing with cardinality constraint
is denoted as
\mathsf{DSBP}
. It is defined as follows. Given a set of bins
\mathcal{B}
, a feasible solution is a packing of all items (fractional packing is allowed) to the bins in
\mathcal{B}
such that the number of parts of different items in each bin is at most
k
. The goal function is to minimize the maximum bin size. Observe that in this
\mathsf{DSBP}
the input consists of the set of items
T
, each of which associated with a size, the set of bins
\mathcal{B}
, and the value of
k
.

In order to present the known results for these problems, we recall the definitions of approximation schemes both in the absolute sense and in the asymptotic sense. Our problems are minimization problems so the objective function is referred to as cost. For an algorithm
\mathcal{A}
, we denote its cost by
\mathcal{A}
as well. The cost of an optimal algorithm is denoted by
\mathsf{OPT}
. We define the
asymptotic approximation ratio
of an algorithm
\mathcal{A}
as the infimum
\mathcal{R}\geq 1
such that for any input,
\mathcal{A}\leq\mathcal{R}\cdot\mathsf{OPT}+c
, where
c
is independent of the input. If we enforce
c=0
,
\mathcal{R}
is called the
absolute approximation ratio
. An
asymptotic polynomial time approximation scheme
is a family of approximation algorithms such that for every
\varepsilon\geq 0
, the family contains a polynomial time algorithm with an asymptotic approximation ratio of
1+\varepsilon
. We abbreviate asymptotic polynomial time approximation scheme by APTAS (also called an asymptotic PTAS). An
asymptotic fully polynomial time approximation scheme
(AFPTAS) is an APTAS whose time complexity is polynomial not only in the input size but also in
1/\varepsilon
. If the scheme satisfies the definition above with
c=0
, stronger results are obtained, namely, polynomial time approximation schemes and fully polynomial time approximation schemes, which are abbreviated as PTASs and FPTASs, respectively. An
efficient polynomial time approximation scheme
(EPTAS) is a PTAS whose time complexity is upper bounded by the form
f(1/\varepsilon)\cdot poly(n)
where
f
is some computable (not necessarily polynomial) function and
poly(n)
is a polynomial of the length of the (binary) encoding of the input. The notion of EPTAS is a modern one, motivated in the fixed parameterized tractable (FPT) community (see e.g.
[
8
]
).

Literature review.

\mathsf{PSBP}
was first considered in
[
10
]
with
k=2
. They show that the problem is NP-hard in the strong sense and also gave a
3/2
approximation algorithm for this case.
[
17
]
further generalized the primal problem for fixed values of
k\geq 3
. The authors show that the problem is NP-hard for every fixed value of
k
and provide a
(7/5+\varepsilon)
-approximation algorithm for
k=2
and for any
\varepsilon\geq 0
. In
[
16
]
special cases of the primal problem are solved in polynomial time (polynomial in both
|T|
and the binary encoding length of the input). For the general case when the problem becomes NP-hard, they present an EPTAS. Furthermore, the problem is strongly NP-hard so this is the best achievable scheme since an FPTAS would imply P=NP. Next, we note that the existence of an AFPTAS for the primal problem would also imply P=NP. The case when the problem becomes NP-hard is when the cost of the optimal solution is very large. In such cases the asymptotic approximation ratio and the absolute approximation ratio becomes the same up to an additive
\varepsilon
in the value of approximation ratio. Therefore, an AFPTAS would result in an FPTAS which is impossible unless P=NP. Thus, an AFPTAS is not achievable for the primal problem.

Most relevant to our work,
[
16
]
also presents a PTAS for
\mathsf{DSBP}
with constant values of
k
. The authors leave the existence of an EPTAS for the dual problem as an open problem. The assumption that
k
is a constant means that in their scheme the time complexity is exponential in
k
. Our result is an EPTAS for
\mathsf{DSBP}
that need not assume that
k
is a constant. Namely, we both generalize the cases for which there exist an approximation scheme for
\mathsf{DSBP}
, and improve the time complexity of the scheme for the cases in which there was a previous PTAS.

Notation.

Given a positive integer
N

[N]=\{1,2,\ldots,N\}
be the set of natural numbers up to

\mathbb{R}_{+}

Paper outline.

For the remainder of the paper we are dealing with
\mathsf{DSBP}
. Recall that the number of bins determined in the input is denoted by
|\mathcal{B}|
. This problem can be interpreted as fractional scheduling on parallel identical machines with the goal of minimizing the makespan but the problem is non-trivial as we have an upper bound of
k
on the number of parts of different jobs that can be placed on a machine.

Our scheme starts by imposing a structure on the input (Section
2
). We use a guessing step, to guess approximated information on the optimal solution. For each value of the guess, we perform the following. We identify a near optimal solution with a particular structure we detail in Section
3
. This structure is exploited to generate partial information on the solution. This partial information is used in a formulation of a mixed integer linear program (MILP) (see Section
4
) directing our algorithm. The next step of the scheme is to obtain an optimal solution of the MILP. The best solution among all the optimal solutions to all possible values of the guess is converted to a feasible packing for
\mathsf{DSBP}
whose cost is approximately the cost of the corresponding optimal solution to the MILP (Section
5
).

2
Structuring the input

Our scheme starts by guessing the optimal maximum bin size and assume that this bin size is
1
, then we perform a rounding step, and then we classify the items into small and large. All these steps can be considered as part of structuring the input and these are the steps we consider in this section. Later, we provide the remaining steps of the algorithm.

2.1
Guessing the optimal bin size

The optimal bin size is in the interval
\in[W/|\mathcal{B}|,W]
. We guess the approximated upper bound on bin size as an integer power of
1+\varepsilon
. We guess a value
g
that is an integer power of
1+\varepsilon
and that the maximum bin size of an optimal solution to the problem is in the interval
(g/(1+\varepsilon),g]
. We conclude the following lemma.

Lemma 1
.

The number of possible values for the guess is at most
\log_{(1+\varepsilon)}|\mathcal{B}|+2
.

If the guess is
g
, we scale down the item sizes of all items in the original instance by dividing the sizes of all items by
g
and initialize the approximated upper bound on the size of bins to
1
. This scaled down instance is denoted by
I
.

2.2
Rounding step

We next convert the scaled down instance
I
into a new instance
I^{\prime}
for which the following two properties hold.

1.

The maximum size of an item in
I^{\prime}
is at most
1/\varepsilon^{2}
.

2.

For every item whose size in
I^{\prime}
is at least
\varepsilon
, the size of the item is an integer multiple of
\varepsilon^{2}
.

Property
1
is obtained by splitting items of size strictly greater than
1/\varepsilon^{2}
. Every item
x
of size
X
strictly greater than
1/\varepsilon^{2}
, is replaced with
\lfloor\varepsilon^{2}X\rfloor
items of size
1/\varepsilon^{2}
and one additional item of size
X-\lfloor\varepsilon^{2}X\rfloor\cdot(1/\varepsilon^{2})
. Property
2
is achieved by rounding up sizes of items at least
\varepsilon
to integer multiples of
\varepsilon^{2}
. We denote by
I^{\prime}
the instance obtained after the preceding transformations.

Lemma 2
.

A packing of
I
can be converted to a packing of
I^{\prime}
by increasing the size of bin by at most
3\varepsilon
. A packing of
I^{\prime}
can be converted to a packing of
I
in polynomial time without increasing the size of bins.

Proof.

Consider a packing of instance
I
. Modify each item
x
of size
X>1/\varepsilon^{2}
as follows. First increase the size of parts of
x
in each bin by a multiplicative factor of
1+\varepsilon
, adding empty space as necessary. Arbitrarily order the bins in which parts of
x
are packed and denote the ordered list of those bins by
B_{x}
. Let
S_{b},\forall b\in B_{x}
be the total size of parts of
x
in bins up to
b
. For each
i=1,2,\ldots,\lfloor\varepsilon^{2}X\rfloor
identify the bin
b_{i}\in B_{x}
such that
S_{b_{i}-1}<i/\varepsilon^{2}
and
S_{b_{i}}\geq i/\varepsilon^{2}
. Cut the part of
x
in bin
b_{i}
into two parts of size
i/\varepsilon^{2}-S_{b_{i}-1}
and
S_{b_{i}}-i/\varepsilon^{2}
, thus increasing the number of parts in
b_{i}
. Notice that the empty space added in bins
b_{(i-1)},\ldots,b_{i}-1
is
\varepsilon\cdot 1/\varepsilon^{2}=1/\varepsilon
. Move the first part of
x
in
b_{i}
to the bins between
b_{(i-1)}
and
b_{i}-1
arbitrarily. There is enough empty space available to do this since the size of the part is at most
1<1/\varepsilon
. The increase in the size of a bin
b
after performing the above conversion to all items of size strictly larger than
1/\varepsilon^{2}
is at most
\varepsilon\mathsf{S}_{b}\leq\varepsilon
, where
\mathsf{S}_{b}
is the total size of parts of items larger than
1/\varepsilon^{2}
packed into bin
b
in the packing of
I
. Let this intermediate instance, after the above conversion, be
\underline{I}
.

Next, perform the following conversion for each item
y
of
\underline{I}
of size
Y\geq\varepsilon
. Let
B_{y}
be the set of the bins in which parts of
y
are packed. Increase the size of all parts of
y
by a multiplicative factor of
1+\varepsilon
, adding empty space as necessary. Then, we add a part of
y
of size
Y^{\prime}
such that
Y^{\prime}=\varepsilon^{2}\lceil Y/\varepsilon^{2}\rceil-Y<\varepsilon^{2}
. This part is added arbitrarily to the bins in
B_{y}
by increasing the sizes of the parts of
y
in the bins accordingly. The number of parts of items in each bin is not increased. This is a feasible packing since the empty space created is of size at least
\varepsilon^{2}
using
Y\geq\varepsilon
. This increases the space of a bin
b
by at most
\varepsilon(1+\varepsilon)\leq 2\varepsilon
. This gives the required packing of instance
I^{\prime}
.

For the other direction consider a packing of instance
I^{\prime}
. Decrease the size of items of size strictly greater than
\varepsilon^{2}
to the original size as in
\underline{I}
in an arbitrary way. This does not increase the maximum size of a bin or the number of parts in each bin. Now we have a packing of instance
\underline{I}
. Any packing of instance
\underline{I}
is a packing of instance
I
since the items of
I
can be split arbitrarily and this does not increase the number of parts in each bin with respect to the packing of
\underline{I}
. Thus, we get a packing of
I
without increasing the maximum bin size.
∎

After the above rounding we have that the approximated upper bound on the bin sizes is denoted as
\mathcal{G}^{\prime}
and we initialize its value to be
\mathcal{G}^{\prime}=1+3\varepsilon
. Based on the guessing step, we are guaranteed there exists a feasible solution to the instance
I^{\prime}
whose maximum bin size is at most
\mathcal{G}^{\prime}
.

2.3
Classification of items

The items are classified into two categories. An item is called
small
if the size of the item is strictly smaller than
\varepsilon
, else it is
large
. The size of a large item is in the interval
[\varepsilon,1/\varepsilon^{2}]
and is an integer multiple of
\varepsilon^{2}
(as a result of the rounding step). Let
\mathsf{L}
denote the set of distinct sizes of large items in

. We have,
|\mathsf{L}|\leq 1/\varepsilon^{4}-1/\varepsilon+1\leq 1/\varepsilon^{4}
and the upper bound is a constant when

is fixed. Let
\mathcal{L}
denote the set of all large items,
\mathcal{L}_{\ell}
the set of large items of size
\ell\in\mathsf{L}
, and
\mathcal{S}
the set of small items.

Nice packing

We next show that every feasible packing can be converted to another packing where items of size at least

\displaystyle=1,\ i=1,2,\ldots,n,

(LP(g))

.

[

If

has a feasible solution

where the size of bin

In our scenario, the second part of the lemma will imply that the number of parts of items in each bin is not increased in

Lemma 4
.

Every feasible packing can be converted to another feasible packing with maximum bin size at most
1+4\varepsilon
where every part of every large item has a size that is an integer multiple of

.

Proof.

Consider a feasible packing
P

in which items are split arbitrarily. We use Lemma

in

be

for all

We split the large items as follows. For each

is replaced by

items of size
\varepsilon^{2}
. Items thus created are called

and the set of all auxiliary items in

be

. Notice that

is a packing of

by replacing the large item by the corresponding auxiliary items it generates, even though it may be infeasible for
\mathsf{DSBP}
for

(as the number of parts in a bin may increase). The packing of small items in each bin is left as in

. We modify the packing of the auxiliary items generated to get the structure we need. Thus, the effective space available for auxiliary items in a bin
j
is now
G_{j}=Z_{j}-S_{j}
where
S_{j}
is the total size of parts of small items in

.

Next, we generate
x

i\in\mathcal{I}
and

as follows. If a portion of size

of

is assigned to bin

. We modify the item sizes in preparation to apply Lemma

in bin

is denoted by

, and otherwise

. The

with

. Using Lemma

we convert

to an integral packing of auxiliary items, denoted by
\textbf{x}^{\prime\prime}
. The total size of auxiliary items in bin

with respect to

is at most

. Considering the preexisting small items in bin

is at most
G_{j}+\varepsilon^{2}+S_{j}=Z_{j}+\varepsilon^{2}\leq\mathcal{G}^{\prime}+\varepsilon^{2}\leq(1+3\varepsilon)+\varepsilon=1+4\varepsilon
.

Next, we modify the
\textbf{x}^{\prime\prime}
values for auxiliary items in

to
\textbf{x}^{\prime}
for only large items of

. The
{x}^{\prime}_{ij}

∎

A packing that satisfies Lemma

4
MILP

Patterns and configurations define partial information on the solution and are used in the MILP. The MILP finds the patterns by which the large items are split. The MILP also finds the configurations according to which the parts generated from large items (based on the patterns) are packed in bins. In addition to these tasks, the MILP also provides a fractional packing of small items to the configurations. The optimal solution to the MILP is found in polynomial time using
[
30
,
24
]
since the number of integer variables is a constant. The MILP solution can be transformed to a feasible packing with a similar cost as we demonstrate in the proof of Theorem
2
.

4.1
Pattern

A pattern is a vector of length
\mathcal{G}^{\prime}/\varepsilon^{2}+1
and each large item is assigned to a pattern which represents how the item is split. The components of a pattern
p
are as follows.

•

The first component (denoted by
\alpha_{p}\in\mathbb{Z}_{+}
) stores the size of the large item as an integer multiple of
\varepsilon^{2}
to which this pattern is assigned. That is,
\alpha_{p}\varepsilon^{2}
is the size of the large item to which
p
is assigned.

•

The next
r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]
components (denoted by
\beta_{pr}\in\mathbb{Z}_{+}
) determine how many parts of size
r\varepsilon^{2}
(for all
r
) are cut from a large item assigned pattern
p
.

We say that a pattern
p
is a
feasible pattern
if

\displaystyle\alpha_{p}=\sum_{r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]}\beta_{pr}r.

(1)

Let
\mathcal{P}
be the set of feasible patterns.

Lemma 5
.

The number of feasible patterns is at most
\left(1/\varepsilon^{4}+1\right)^{(2/\varepsilon^{2})}
.

Proof.

The
\alpha_{p}
value of a feasible pattern is well-defined given the
\beta_{pr}
for all
r
. Each of the
\beta_{pr}
components can have at most
\left(1/\varepsilon^{4}+1\right)
values (by (
1
)) since
\alpha_{p}\leq 1/\varepsilon^{4}
. The claim follow from
\mathcal{G}^{\prime}/\varepsilon^{2}<2/\varepsilon^{2}-1
since
1/\varepsilon\geq 10
.
∎

4.2
Configuration

Every bin is assigned a configuration and this configuration represents the packing of the bin. The components of a configuration
c
are as follows.

•

The first component (denoted by
\gamma_{c}\in\mathbb{Z}_{+}
) represents the total size of parts of small items assigned to a bin (assigned this configuration) rounded down to an integer multiple of
\varepsilon^{2}
such that the size of the small items in such a bin is in the interval
[\gamma_{c}\varepsilon^{2},(\gamma_{c}+1)\varepsilon^{2})
.

•

The next
r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]
components (denoted by
\delta_{cr}\in\mathbb{Z}_{+}
) store the number of different parts of a particular size (as an integer multiple of
\varepsilon^{2}
) cut from large items packed to a bin assigned this configuration. For each
r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]
,
\delta_{cr}
states the number of different parts of size
r\varepsilon^{2}
(cut from large items) packed to a bin assigned configuration
c
.

4.2.1
Creating a partial packing

To create a

\mathcal{G}^{\prime}
. Let
\mathcal{C}
be the set of all feasible configurations.

Lemma 6
.

The number of feasible configurations is at most
(2/\varepsilon^{2})^{(2/\varepsilon^{2})}
.

Proof.

The possible values for the first component of the configuration is at most

. Each of the next

4.3
The families of decision variables

Assignment variables for small items to configurations.

We have an assignment variable
x_{ic}
for small item
i
and configuration
c
. If small item
i
is assigned completely to bins with configuration
c
, then
x_{ic}=1
. There are at most
n\cdot|\mathcal{C}|
such variables. These variables are allowed to be fractional.

Configuration counters.

There is a configuration counter for every feasible configuration. For a configuration
c\in\mathcal{C}
, the variable
y_{c}
denotes the number of bins to which configuration
c
is assigned. There are at most
|\mathcal{C}|
variables and these variables are forced to be integral.

Pattern counter.

There is a pattern counter for every feasible pattern. For a pattern
p\in\mathcal{P}
, the variable
z_{p}
denotes the number of large items to which pattern
p
is assigned. There are
|\mathcal{P}|
such variables and these variables are forced to be integral.

Parts counter.

For every distinct size of parts, as an integer multiple of
\varepsilon^{2}
, we have a counter. For
r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]
,
v_{r}
states the number of different parts (cut from large items) of size
r\varepsilon^{2}
available for packing. These variables are allowed to be fractional.

4.4
The constraints

Next, we present the constraints of the MILP with their intuitive meaning. This intuition is not used to prove our claims but it is presented to ease the reading of the constraints.

Each bin should be assigned a configuration and since one configuration can be assigned to multiple bins, we have

\displaystyle\sum_{c\in\mathcal{C}}y_{c}=|\mathcal{B}|.

(2)

Each small item
i
should be packed completely. Since such a small item can be split between configurations, we have

\displaystyle\sum_{c\in\mathcal{C}}x_{ic}=1,\ \forall i\in\mathcal{S}.

(3)

All the parts that are generated from large items should be packed.

\displaystyle v_{r}

\displaystyle=\sum_{p\in\mathcal{P}}\beta_{pr}z_{p},\ \forall r\in[\mathcal{G}^{\prime}/\varepsilon^{2}].

(4)

\displaystyle v_{r}

\displaystyle=\sum_{c\in\mathcal{C}}\delta_{cr}y_{c},\ \forall r\in[\mathcal{G}^{\prime}/\varepsilon^{2}].

(5)

The former constraint calculates the number of parts of each size generated from large items based on the patterns. Observe that by this constraint and the fact that
z
values are forced to be integral, we conclude that in every feasible solution the
v
values are also integers. The constraint (
5
) chooses the configurations such that there are enough positions to pack these parts.

Each large item should be assigned a pattern and since some large items can be assigned to a common pattern, we have

\displaystyle\sum_{p\in\mathcal{P}:\alpha_{p}=\ell/\varepsilon^{2}}z_{p}=|\mathcal{L}_{\ell}|,\ \forall\ell\in\mathsf{L}.

(6)

Each configuration should satisfy the cardinality constraint since each configuration represents a bin. The total number of parts of large items that can be assigned to a configuration is determined by the configuration and the number of copies of this configuration. Thus, the average number of parts of small items that can be assigned to one copy of a configuration is at most the difference between
k
and the total number of parts of large items allowed by the configuration. We get,

\displaystyle\sum_{i\in\mathcal{S}}x_{ic}\leq y_{c}\left(k-\sum_{r\in[\mathcal{G}^{\prime}/\varepsilon^{2}]}\delta_{cr}\right),\ \forall c\in\mathcal{C}.

(7)

The total size of parts of small items assigned to a configuration should be at most the size allowed by each configuration. Since the total size of parts of small items allowed was rounded down in each configuration, we increase the space for each copy of the configuration by
\varepsilon^{2}
. That is,

\displaystyle\sum_{i\in\mathcal{S}}x_{ic}S_{i}\leq y_{c}(\gamma_{c}+1)\varepsilon^{2},\ \forall c\in\mathcal{C}.

(8)

Lastly, we have the non-negativity of all variables and integrality constraints of some of the variables.

\displaystyle v_{r}

\displaystyle\in\mathbb{R}_{+},\ \forall r\in[\mathcal{G}^{\prime}/\varepsilon^{2}].

(9)

\displaystyle x_{ic}

\displaystyle\in\mathbb{R}_{+},\ \forall c\in\mathcal{C},\forall i\in\mathcal{S}.

(10)

\displaystyle y_{c}

\displaystyle\in\mathbb{Z}_{+},\ \forall c\in\mathcal{C}.

(11)

\displaystyle z_{p}

\displaystyle\in\mathbb{Z}_{+},\ \forall p\in\mathcal{P}.

(12)

This concludes the presentation of the MILP. Next, we turn our attention to the analysis of this MILP.

Theorem 1
.

If there exists a feasible nice packing of the instance
I^{\prime}
with maximum bin size
\mathcal{G}^{\prime}

Proof.

Consider a nice packing

and

corresponding to component

Next, we generate the patterns. For each large item

corresponding to

is
\alpha\varepsilon^{2}

corresponding to

corresponding to component

is set to the number of copies of

in

.

\mathcal{P}^{\prime}

Converting the MILP solution into the output of the scheme

In order to present our rounding method of taking a solution to the MILP and returning a feasible solution to

, we need a method to handle the assignment of the small items. We will apply a method established in
[
9
]
originally for the cardinality constraint scheduling problem. Specifically the analysis of a procedure referred to as Best-Fit. Next, we state the lemma analyzing the Best-Fit solution for packing the small items satisfying cardinality constraint
[
9

. We apply this lemma in the proof of the following theorem.

Lemma 7
.

If there is a feasible fractional solution to the following feasibility linear program in the variables
x

\displaystyle\sum_{i\in\mathcal{S}}S_{i}x_{ib}\leq t_{b}

\displaystyle,\ b\in\mathcal{B}

\displaystyle\sum_{i\in\mathcal{S}}x_{ib}\leq c_{b}

\displaystyle,\ b\in\mathcal{B}

\displaystyle\sum_{b\in\mathcal{B}}x_{ib}=1

\displaystyle,\ i\in\mathcal{S}

\displaystyle 0\leq x_{ib}\leq 1

\displaystyle,\ i\in\mathcal{S},\ \ b\in\mathcal{B}

then an integer solution satisfying:

\displaystyle\sum_{i\in\mathcal{S}}S_{i}x_{ib}\leq t_{b}+S_{\max}

\displaystyle,\ b\in\mathcal{B}

\displaystyle\sum_{i\in\mathcal{S}}x_{ib}\leq c_{b}

\displaystyle,\ b\in\mathcal{B}

\displaystyle\sum_{b\in\mathcal{B}}x_{ib}=1

\displaystyle,\ i\in\mathcal{S}

\displaystyle 0\leq x_{ib}\leq 1

\displaystyle,\ i\in\mathcal{S},\ \ b\in\mathcal{B}

could be obtained in
O(n\log n)
time, where

.

Theorem 2
.

If there exists a solution to the MILP for the rounded instance

with the given guessed value

of cost at most

Let the MILP solution be

,
\mathcal{C}
the set of feasible configurations, and

the set of feasible patterns. We convert the MILP solution to a feasible packing.

For every

Now we have information on how many parts of each size from large items we need to assign to each bin and a fractional assignment of small items to configurations. This information is used in the following way. Assign
\delta_{cr}
different parts of size

to each bin assigned configuration

and

is the configuration assigned to bin
