Analytic functions with conic domains associated with certain generalized q q -integral operator 0 0 footnotetext: 2010 AMS Mathematics Subject Classification: 30C45, 30C50, 30C80 Key words and phrases: Quantum calculus, q q -derivative operator, q q -difference operator, q q -gamma function, q q -integral operator, conic domain, k k -uniformly starlike functions of order gamma, coefficient estimate.
Om Ahuja, Asena Çetinkaya, Naveen Kumar Jain

Abstract
In this paper, we define a new subclass of k k -uniformly starlike functions of order γ , ( 0 ≤ γ < 1 ) \gamma,\ (0\leq\gamma<1) by using certain generalized q q -integral operator. We explore geometric interpretation of the functions in this class by connecting it with conic domains. We also investigate q q -sufficient coefficient condition, q q -Fekete-Szegö inequalities, q q -Bieberbach-De Branges type coefficient estimates and radius problem for functions in this class. We conclude this paper by introducing an analogous subclass of k k -uniformly convex functions of order γ \gamma by using the generalized q q -integral operator. We omit the results for this new class because they can be directly translated from the corresponding results of our main class.

Let

Quantum calculus (or
q
-calculus) is a theory of calculus where smoothness is not required. A systematic study of
q
-differentation and
q
-integration was initiated by Jackson
[
12
,
13
]
. The
q
-derivative (or
q
-difference) operator of a function
f
, defined on a subset of
{\mathbb{C}}
, is defined by

(D_{q}f)(z)=\begin{cases}\frac{f(z)-f(qz)}{(1-q)z},&\mbox{if }z\neq 0\\
f^{\prime}(0),&\mbox{if }z=0,\end{cases}

where
q\in(0,1)
. Note that
\lim_{q\rightarrow 1^{-}}(D_{q}f)(z)=f^{\prime}(z)
if
f
is differentiable at
z
. Under the hypothesis of the definition of
q
-derivative, we have the following rules:

D_{q}(af(z)\pm bg(z))=aD_{q}f(z)\pm bD_{q}g(z)\ (a,b\in{\mathbb{C}}),

D_{q}(f(z).g(z))=f(qz)D_{q}g(z)+g(z)D_{q}f(z).

(1.2)

It easily follows that if a function
f
is given by (
1.1
), then

(D_{q}f)(z)=\sum_{n=1}^{\infty}[n]_{q}a_{n}z^{n-1},\hskip 10.00002pt\hskip 10.00002ptD_{q}(zD_{q}f(z))=\sum_{n=1}^{\infty}[n]_{q}^{2}a_{n}z^{n-1},

where

[n]_{q}=\frac{1-q^{n}}{1-q}

is called
q
-number or
q
-bracket of
n
. Clearly,
\lim_{q\rightarrow 1^{-}}[n]_{q}=n
. In
[
13
]
, Jackson defined
q
-integral of a function

as follows:

\int_{0}^{x}f(t)d_{q}t=x(1-q)\sum_{{n=0}}^{\infty}q^{n}f(xq^{n}),

provided the series converges. It is known that
q
-gamma function is given by

\Gamma_{q}(x+1)=[x]_{q}\Gamma_{q}(x),\hskip 10.00002pt\Gamma_{q}(x+1)=[x]_{q}!,

(1.3)

where
q
-factorial
[x]_{q}!
is given by

[x]_{q}!=\begin{cases}[x]_{q}[x-1]_{q}\dots[2]_{q}[1]_{q},&\text{if $x\geq 1$}\\
1,&\text{if $x=0$}.\end{cases}

Note that in the limiting case when
q\rightarrow 1^{-}
,
\Gamma_{q}(x)\rightarrow\Gamma(x)
; see
[
11
]
.

The
q
-beta function has the

[

B_{q}(t,s)=\int_{0}^{1}x^{t-1}(1-qx)_{q}^{s-1}d_{q}x,\ \ (0<q<1;t,s>0).

(1.4)

Jackson

B_{q}(t,s)=\frac{\Gamma_{q}(t)\Gamma_{q}(s)}{\Gamma_{q}(t+s)},

tends to

as

Also, the Gauss

-binomial coefficients are given by

\binom{n}{k}_{q}:=\frac{[n]_{q}!}{[k]_{q}![n-k]!}.

(1.6)

For more details, one may refer to

(1.16)

Main Results

We first obtain
q
-sufficient coefficient condition for the functions belonging to the class
k
-
\mathcal{JUST}(q;\alpha,\beta,\gamma)

Theorem 2.1
.

If a function
f
defined by (
1.1
) satisfies the inequality

\sum_{n=2}^{\infty}\big([n]_{q}(k+1)-(k+\gamma)\big)\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|\leq 1-\gamma,

(2.1)

then

belongs to
k
-
\mathcal{JUST}(q;\alpha,\beta,\gamma)
. The result is sharp.

Proof.

To show that
f\in k
-
\mathcal{JUST}(q;\alpha,\beta,\gamma)
, it suffices to prove that

k\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|-\RE\bigg(\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg)\leq 1-\gamma.

We note that

\displaystyle\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|

\displaystyle=\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))-\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}\bigg|

\displaystyle=\bigg|\frac{\sum_{n=2}^{\infty}([n]_{q}-1)\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}a_{n}z^{n}}{z+\sum_{n=2}^{\infty}\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}a_{n}z^{n}}\bigg|

\displaystyle\leq\frac{\sum_{n=1}^{\infty}\big([n]_{q}-1\big)\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|}{1-\sum_{n=1}^{\infty}\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|}.

(2.2)

In view of (
2.1
), it follows that

1-\sum_{n=1}^{\infty}\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|>0.

Using (
2
), we have

\displaystyle k\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|-\RE\bigg(\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg)

\displaystyle\ \ \leq k\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|+\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|

\displaystyle\ \ \leq(k+1)\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))-\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}\bigg|

\displaystyle\ \ \leq(k+1)\bigg\{\frac{\sum_{n=2}^{\infty}\big([n]_{q}-1\big)\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|}{1-\sum_{n=1}^{\infty}\frac{\Gamma_{q}(\beta+n)}{\Gamma_{q}(\alpha+\beta+n)}\frac{\Gamma_{q}(\alpha+\beta+1)}{\Gamma_{q}(\beta+1)}|a_{n}|}\bigg\}

\displaystyle\ \ \leq 1-\gamma

which proves (
2.1
).

For sharpness, consider the function
f_{n}:\mathbb{D}\rightarrow\mathbb{C}
defined by

f_{n}(z)=z-\frac{(1-\gamma)\Gamma_{q}(\alpha+\beta+n)}{\big([n]_{q}(k+1)-(k+\gamma)\big)\Gamma_{q}(\beta+n)}\frac{\Gamma_{q}(\beta+1)}{\Gamma_{q}(\alpha+\beta+1)}z^{n}.

Since

\RE\bigg(\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}\bigg)=\RE\left(\frac{[n]_{q}(k+1)-(k+\gamma)-(1-\gamma)[n]_{q}z^{n-1}}{[n]_{q}(k+1)-(k+\gamma)-(1-\gamma)z^{n-1}}\right)>\frac{k+\gamma}{k+1}

and

\displaystyle k\bigg|\frac{zD_{q}(\mathcal{\chi}^{\alpha}_{\beta,q}f(z))}{\mathcal{\chi}^{\alpha}_{\beta,q}f(z)}-1\bigg|

\displaystyle=k\left|\frac{(1-\gamma)(1-[n]_{q})z^{n-1}}{[n]_{q}(k+1)-(k+\gamma)-(1-\gamma)z^{n-1}}\right|

\displaystyle<\frac{k(1-\gamma)}{k+1},

it follows that
f_{n}\in k
-
\mathcal{JUST}(q;\alpha,\beta,\gamma)
. Also, it is easy to shows that the equality holds in (
2.1
) for the function

. Thus the result is sharp.
