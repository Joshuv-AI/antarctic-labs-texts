On the Erdős-Tuza-Valtr Conjecture
Jineon Baek

Abstract
. The Erdős-Szekeres conjecture states that any set of more than 2 n − 2 2^{n-2} points in the plane with no three on a line contains the vertices of a convex n n -gon. Erdős, Tuza, and Valtr strengthened the conjecture by stating that any set of more than ∑ i = n − b a − 2 ( n − 2 i ) \sum_{i=n-b}^{a-2}\binom{n-2}{i} points in a plane either contains the vertices of a convex n n -gon, a a points lying on a concave downward curve, or b b points lying on a concave upward curve. They also showed that the generalization is actually equivalent to the Erdős-Szekeres conjecture. We prove the first new case of the Erdős-Tuza-Valtr conjecture since the original 1935 paper of Erdős and Szekeres. Namely, we show that any set of ( n − 1 2 ) + 2 \binom{n-1}{2}+2 points in the plane with no three points on a line and no two points sharing the same x x -coordinate either contains 4 points lying on a concave downward curve or the vertices of a convex n n -gon.

Definition 2.1
.

In this paper, a

is a finite set

•

A linear ordering
<

•

For any subset of

In standard terms, a configuration is a bi-coloring of a finite, complete 3-uniform hypergraph with a prescribed linear ordering of vertices.

Given a finite set of points in general position, we can make a configuration by ordering the points in their increasing

Let’s say that a configuration is

The notion of caps and cups in plane are generalized to arbitrary configurations which may not be realizable.

Denote any set of vertices

Define the set

We assumed without loss of generality that

(

)

Let

(3)

x_{i}<x
and the edge

is labeled 1, so
x_{i}C
is an

-cup in

(4)

\alpha(x_{i})=1
and

First we show
x<q_{S}
, the first item of (
\ast\ast
). Assume otherwise that
x\geq q_{S}
. Then the case

If the edge

is labeled 1, then

is an
(n-1)
-cup so it also contradicts our assumption.
So

(n-1)
-cup
D
by definition,
Dx
is an
n
-cup which contradicts that
S
is
n
-cup free.
This concludes the proof of
x<q_{S}
by contradiction.

As

is the minimum value of

, we also get
x\not\in R_{n-1}(S)
and
i=\beta(x)\leq n-2
(the second item of (
\ast\ast
)).
Therefore,
x_{i}\in\Delta
and as

that also contains

,

x_{i}<x

Consequently, the
(n-1)
-cup

(the third item of (

)).

If

is

-cup free.

.
Next, we show that
\alpha(x)=2
.

\ast\ast
)).

\ast\ast
).

is

-cup free.
Assume otherwise that

contains an

-cup

from some point

in
