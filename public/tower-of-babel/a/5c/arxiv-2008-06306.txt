Existence Theorem


Abstract
In this paper, we initially derive the equivalent fractional integral equation to Ψ \Psi -Hilfer hybrid fractional differential equations and through it, we prove the existence of a solution in the weighted space. The primary objective of the paper is to obtain estimates on Ψ \Psi -Hilfer derivative and utilize it to derive the hybrid fractional differential inequalities involving Ψ \Psi -Hilfer derivative. With the assistance of these fractional differential inequalities, we determine the existence of extremal solutions, comparison theorems and uniqueness of the solution.

Let
[a,b]

(0<a<b<\infty)
be a finite interval and
\Psi\in C^{1}([a,b],\mathbb{R})
be an increasing function such that
\Psi^{\prime}(t)\neq 0
,
\forall~t\in[a,b]
. We consider the weighted space

C_{1-\xi;\,\Psi}\left[a,b\right]=\left\{h:\left(a,b\right]\rightarrow\mathbb{R}~\big|~\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h\left(t\right)\in C\left[a,b\right]\right\},\text{ }0<\xi\leq 1,

endowed with the norm

\left\|h\right\|_{C_{1-\xi;\Psi}\left[a,b\right]}=\underset{t\in\left[a,b\right]}{\max}\left|\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h\left(t\right)\right|.

(2.1)

The weighted space
C_{1-\xi\,;\Psi}(\left[a,b\right],\,\mbox{\Bbb R})
is a partially ordered Banach space with the norm
\left\|\cdot\right\|_{C_{1-\xi;\Psi}\left[a,b\right]}
and the partial ordering relation
\preceq
defined by

h_{1}\preceq h_{2}~\text{if and only if}~\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{1}\left(t\right)\leq\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{2}\left(t\right),~t\in\left[a,b\right],

where
h_{1},h_{2}\in C_{1-\xi\,;\Psi}(\left[a,b\right],\,\mbox{\Bbb R})
.
Note that

(i)

h_{1}\prec h_{2}~\text{if and only if}~\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{1}\left(t\right)<\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{2}\left(t\right),~t\in\left[a,b\right];

(ii)

h_{1}=h_{2}~\text{if and only if}~\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{1}\left(t\right)=\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{2}\left(t\right),~t\in\left[a,b\right];

(iii)

h_{1}\succ h_{2}~\text{if and only if}~\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{1}\left(t\right)>\left(\Psi\left(t\right)-\Psi\left(a\right)\right)^{1-\xi}h_{2}\left(t\right),~t\in\left[a,b\right].

3
Existence of solution

Lemma 3.1

A function
y\in C_{1-\xi;\,\Psi}(J,\,\mbox{\Bbb R})
is the solution of the Cauchy problem for hybrid FDEs (
1.1
)-(
1.2
) if and only if it is solution of the following hybrid fractional IE

\displaystyle y(t)

\displaystyle=f(t,y(t))\left\{\frac{y_{0}}{f(0,y(0))}\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}+\mathcal{I}_{0^{+}}^{\mu\,;\,\Psi}g(t,y(t))\right\},~t\in(0,T].

(3.1)

Proof:

Let
y\in C_{1-\xi;\,\Psi}(J,\,\mbox{\Bbb R})
be the solution of the Cauchy problem for hybrid FDEs (
1.1
)-(
1.2
). Operating
\Psi
-RL fractional integral
\mathcal{I}_{0^{+}}^{\mu\,;\,\Psi}
on the both sides of the equation (
1.1
) and using Lemma
2.2
(i), we obtain

\frac{y(t)}{f(t,y(t))}-\frac{\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}}{\Gamma(\xi)}\left[\mathcal{I}_{0^{+}}^{1-\xi\,;\Psi}\frac{y(t)}{f(t,y(t))}\right]_{t=0}=\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t)),\,t\in(0,T].

The above equation can be written as

y(t)=f(t,y(t))\left\{\frac{C}{\Gamma(\xi)}\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}+\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t))\right\},~t\in(0,T],

(3.2)

where

C=\left[\mathcal{I}_{0^{+}}^{1-\xi\,;\Psi}\frac{y(t)}{f(t,y(t))}\right]_{t=0}.

Next, we evaluate the value of
C
using initial condition. Multiplying
\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}
on both sides of the equation (
3.2
), we get

\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}y(t)=\frac{C\,}{\Gamma(\xi)}f(t,y(t))+\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}f(t,y(t))\,\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t)),~t\in J.

Putting
t=0
in the above equation and using the initial condition (
1.2
), we obtain

C=\frac{y_{0}\,\Gamma(\xi)}{f(0,y(0))}.

Putting value of
C
in the equation (
3.2
), we get

y(t)=f(t,y(t))\left[\frac{y_{0}\,}{f(0,y(0))}\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}+\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t))\right],~t\in(0,T],

which is required equivalent hybrid fractional IE to the hybrid FDEs (
1.1
)-(
1.2
).

Conversely, let
y\in C_{1-\xi;\,\Psi}(J,\,\mbox{\Bbb R})
is a solution of the hybrid IE (
3.1
).
Then it can be written as

\frac{y(t)}{f(t,y(t))}=\frac{y_{0}\,}{f(0,y(0))}\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}+\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t)),~t\in(0,T].

(3.3)

Operating the
\Psi
-Hilfer derivative
{}^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}
on both sides of the equation (
3.3
) and using the Lemma
2.1
(iii) and Lemma
2.2
(ii), we obtain

{}^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}\left[\frac{y(t)}{f(t,y(t))}\right]

\displaystyle=\frac{y_{0}\,}{f(0,y(0))}\,^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}+\,^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t))

\displaystyle=g(t,y(t)).

It remains to verify the initial condition (
1.2
). From the equation (
3.3
), we have

\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\frac{y(t)}{f(t,y(t))}=\frac{y_{0}}{f(0,y(0))}+\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\mathcal{I}_{0^{+}}^{\mu\,;\Psi}g(t,y(t)).

At

\left[\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\,y(t)\right]_{t=0}=y_{0},

which gives the initial condition (

\left|g(t,y)\right|\leq h(t),\,~a.e.\,\,t\in J~\text{and}~\,y\in\mbox{\Bbb R}.

Theorem 3.2

Assume that the hypotheses
(H1)-(H2)
hold. Then the hybrid FDEs (
1.1
)-(
1.2
) has a solution
y\in C_{1-\xi;\,\Psi}(J,\,\mbox{\Bbb R})
provided

L\left\{\left|\frac{y_{0}\,}{f(0,y(0))}\right|+\frac{\left\|h\right\|_{\infty}\left(\Psi\left(T\right)-\Psi\left(0\right)\right)^{\mu}}{\Gamma(\mu+1)}\right\}<1.

(3.4)

Proof:

Let
X:=\left(C_{1-\xi;\,\Psi}(J,\,\mbox{\Bbb R}),\,\left\|\cdot\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}\right)
. Then
X
is a Banach algebra with the product of vectors defined by
(xy)(t)=x(t)y(t),\,t\in J
. Define,

S=\{x\in X:\left\|x\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}\leq R\},

where

R=K\left\{\left|\frac{y_{0}\,}{f(0,y(0))}\right|+\frac{\left\|h\right\|_{\infty}\left(\Psi\left(T\right)-\Psi\left(0\right)\right)^{\mu+1-\xi}}{\Gamma(\mu+1)}\right\}

and
K
is bound on
f
.
Clearly,
S
is closed, convex and bounded subset of
X
.
Define two operators
A:X\rightarrow X
and
B:S\rightarrow X
by

\displaystyle Ay(t)

\displaystyle=f(t,y(t)),\,t\in J,

\displaystyle By(t)

\displaystyle=\frac{y_{0}\,\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{\xi-1}}{f(0,y(0))}+\frac{1}{\Gamma\left(\mu\right)}\int_{0}^{t}\Psi^{\prime}(s)(\Psi(t)-\Psi(s))^{\mu-1}g(s,y(s))\,ds,\,t\in(0,T].

Then, the hybrid IE (
3.1
) is transformed into the following operator equation

y=AyBy,\,y\in X.

We prove that the operators
A
and
B
satisfies all the conditions of Lemma
2.3
. The proof is given in the following steps:

Step 1:

A:X\rightarrow X
is Lipschitz operator.

Using the hypothesis (H1)(ii), we obtain

\displaystyle\left|\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\left(Ax(t)-Ay(t)\right)\right|

\displaystyle=\left|\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\left(f(t,x(t))-f(t,y(t))\right)\right|

\displaystyle\leq L\left|\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\left(x(t)-y(t)\right)\right|

\displaystyle\leq L\left\|x-y\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}.

This gives,

\left\|Ax-Ay\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}\leq L\left\|x-y\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}.

(3.5)

Step 2:

B:S\rightarrow X
is completely continuous.

(i)
B:S\rightarrow X
is continuous.

Let
y_{n}\rightarrow y
in
S
. Then,

\displaystyle\left\|By_{n}-By\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}

\displaystyle=\underset{t\in J}{\max}\left|\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}\left(By_{n}(t)-By(t)\right)\right|

\displaystyle\leq\underset{t\in J}{\max}\frac{\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}}{\Gamma\left(\mu\right)}\int_{0}^{t}\Psi^{\prime}(s)(\Psi(t)-\Psi(s))^{\mu-1}\left|g(s,y_{n}(s))-g(s,y(s))\right|\,ds.

By continuity of
g
and Lebesgue dominated convergence theorem, from the above inequality, we have

\left\|By_{n}-By\right\|_{C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)}\rightarrow 0~\text{ as}~n\rightarrow\infty.

This proves
B:S\rightarrow X
is continuous.

(ii)
B(S)=\left\{By:y\in S\right\}
is uniformly bounded.

Using hypothesis (H2), for any
y\in S
and
t\in J

Using the inequality (
8.1
), we get

{}^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}m(t)

\displaystyle=\,^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}\left[\frac{u_{1}(t)}{f(t,u_{1}(t))}\right]-\,^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}\left[\frac{u_{2}(t)}{f(t,u_{2}(t))}\right]

\displaystyle=g(t,u_{1}(t))-g(t,u_{2}(t))

\displaystyle\leq G\left(t,\frac{u_{1}(t)}{f(t,u_{1}(t))}-\frac{u_{2}(t)}{f(t,u_{2}(t))}\right)

\displaystyle=G(t,m(t)).

Further,

\displaystyle\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}m(t)|_{t=0}

\displaystyle=\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}u_{1}(t)|_{t=0}-\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}u_{2}(t)|_{t=0}=0.

Therefore,

\displaystyle\begin{cases}&{}^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}m(t)\leq G(t,m(t)),t\in(0,\,T],\\
&\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}m(t)|_{t=0}=0.\end{cases}

(8.3)

By assumption the identically zero function is the maximal solution of

\displaystyle\begin{cases}&{}^{H}\mathcal{D}^{\mu,\,\nu\,;\,\Psi}_{0^{+}}m(t)=G(t,m(t)),~t\in(0,\,T],\\
&\left(\Psi\left(t\right)-\Psi\left(0\right)\right)^{1-\xi}m(t)|_{t=0}=0.\end{cases}

(8.4)

Applying Theorem
7.1
to the problems (
8.3
) and (
8.4
) with
f(t,\,x)=1
,
g=G
and
y_{0}=0
, we obtain

m\preceq 0~\text{in}~C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)

(8.5)

The equation (
8.5
) contradicts to the equation (
8.2
). Thus, we must have
u_{1}=u_{2}
in
C_{1-\xi;\,\Psi}\left(J,\,\mbox{\Bbb R}\right)
.
