1.
Introduction and statement of results

A

In particular, Ramanujan proved that

\begin{split}p(5n+4)&\equiv 0\pmod{5},\\
p(7n+5)&\equiv 0\pmod{7},\\
p(11n+6)&\equiv 0\pmod{11}.\end{split}

Partitions also play a significant role in representation theory (for example, see
[
10
]
). Indeed, partitions of size
n
are used
to define
Young tableaux
, and their combinatorial properties encode the representation theory of the symmetric group
S_{n}
.
Moreover, the
t
-
core partitions
of size
n
play an important role in number theory (for example, see
[
6
,
7
,
12
]
) and the modular representation theory of

(for example, see

[

For positive integers

The case where

-D<0

In particular, if

Furthermore, for primes

c_{4}\left(\frac{Np^{2k}-5}{8}\right)=c_{4}\left(\frac{N-5}{8}\right)\cdot\left(1+\frac{p^{k+1}-p}{p-1}-\frac{p^{k}-1}{p-1}\cdot\left(\frac{-N}{p}\right)\right),

Further relationships between integer partitions and class numbers are expected to be extremely rare.
In this note we find one more instance where

To this end, we let

{\text{\rm sc}}_{t}(n)
denote number of the

To formulate these results, for a positive odd integer

-D_{n}:=\begin{cases}-28n-56\ \ \ \ \ &{\text{\rm if}}\ n\equiv 1\pmod{4},\\

Theorem 1
.

If

is a positive odd integer, then we have

\operatorname{sc}_{7}(n)=\begin{cases}\frac{1}{4}H(-D_{n})\ \ \ \ \ \ \ &{\text{\rm if}}\ n\equiv 1\pmod{4}\\
\frac{1}{2}H(-D_{n})\ \ \ \ \ &{\text{\rm if}}\ n\equiv 3\pmod{8}\\
0\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ &{\text{\rm if}}\ n\equiv 7\pmod{8}.\end{cases}

Corollary 2

If

is a non-negative odd integer for which

\operatorname{sc}_{7}(n)=\begin{cases}-\frac{1}{4D_{n}}\sum_{m=1}^{D_{n}}\left(\frac{-D_{n}}{m}\right)m\ \ \ \ \ \ &{\text{\rm if}}\ n\equiv 1\pmod{4},\\

If

Hurwitz class numbers enjoy a host of multiplicative properties which can be formulated in terms of the Möbius function

Corollary 3

If

is a positive odd integer, and

\operatorname{sc}_{7}((n+2)f^{2}-2)=\operatorname{sc}_{7}(n)\sum_{1\leq d\mid f}\mu(d)\left(\frac{-D_{n}}{d}\right)\sigma_{1}(f/d).

Remark

The cases where

is a prime power coincide with (

.
