Improved Algorithms for Low Rank Approximation from Sparsity
David P. Woodruff, Taisuke Yasuda

Abstract
We overcome two major bottlenecks in the study of low rank approximation by assuming the low rank factors themselves are sparse. Specifically, (1) for low rank approximation with spectral norm error, we show how to improve the best known 𝗇𝗇𝗓 ⁡ ( 𝐀 ) ​ k / ε \nnz(\mathbf{A})k/\sqrt{\varepsilon} running time to 𝗇𝗇𝗓 ⁡ ( 𝐀 ) / ε \nnz(\mathbf{A})/\sqrt{\varepsilon} running time plus low order terms depending on the sparsity of the low rank factors, and (2) for streaming algorithms for Frobenius norm error, we show how to bypass the known Ω ⁡ ( n ​ k / ε ) \Omega(nk/\varepsilon) memory lower bound and obtain an s ​ k ​ ( log ⁡ n ) / poly ⁡ ( ε ) sk(\log n)/\poly(\varepsilon) memory bound, where s s is the number of non-zeros of each low rank factor. Although this algorithm runs in exponential time, as it must under standard complexity-theoretic assumptions, we also present polynomial time algorithms using poly ⁡ ( s , k , log ⁡ n , ε − 1 ) \poly(s,k,\log n,\varepsilon^{-1}) memory that output rank k k approximations supported on an O ⁡ ( s ​ k / ε ) × O ⁡ ( s ​ k / ε ) O(sk/\varepsilon)\times O(sk/\varepsilon) submatrix. Both the prior 𝗇𝗇𝗓 ⁡ ( 𝐀 ) ​ k / ε \nnz(\mathbf{A})k/\sqrt{\varepsilon} running time and the n ​ k / ε nk/\varepsilon memory for these problems were long-standing barriers; our results give a natural way of overcoming them assuming sparsity of the low rank factors.



1
Introduction

In modern computational problems, one often encounters large scale and high dimensional datasets that are too large and complex to be understood as is. A common approach to dealing with this complexity is to find
low rank approximations
to these datasets. That is, given a matrix
\mathbf{A}\in\mathbb{R}^{n\times d}
and a target rank
k
, one seeks a rank
k
matrix
\mathbf{B}\in\mathbb{R}^{n\times d}
such that
\mathbf{A}
is well-approximated by
\mathbf{B}
. This is advantageous, as a rank
k
matrix can be written as
\mathbf{B}=\mathbf{U}\cdot\mathbf{V}^{\top}
for an
n\times k
matrix
\mathbf{U}
and a
d\times k
matrix
\mathbf{V}
, which only takes
(n+d)k
parameters to describe rather than
nd
. Oftentimes, the task of finding this
\mathbf{B}
is accomplished by computing a rank
k
matrix
\mathbf{B}
that approximately minimizes the reconstruction error
\left\lVert\mathbf{A}-\mathbf{B}\right\rVert
, where
\left\lVert\cdot\right\rVert
is some norm, e.g., the Frobenius norm or the spectral norm.

In practice, the coordinates often have physical interpretations, and in such cases, it is desirable to be able to interpret the low rank approximation found. However,
\mathbf{B}
as obtained above, now described with
(n+d)k
parameters, is often still too large to interpret easily. Thus, one could further ask for the low rank approximation factor
\mathbf{B}
to be sparse as well. One way to formalize this is to require that
\mathbf{B}
can be written as the sum of
k
rank
1
matrices, each of which is supported on an
s\times s
submatrix for some sparsity parameter
s
. We refer to such a
\mathbf{B}
as being an
s\times s
-sparse rank
k
matrix
.

Definition 1.1

(
s\times s
-sparse rank
k
matrix)
.

For a sparsity parameter
s\in\mathbb{N}
and rank parameter
k\leq n
, an
n\times d
matrix
\mathbf{B}
is
s\times s
sparse rank
k
if it can be written as

\mathbf{B}=\sum_{i=1}^{k}\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}

where
\tau_{i}\in\mathbb{R}
and
\mathbf{x}_{i}\in\mathbb{R}^{n}
and
\mathbf{y}_{i}\in\mathbb{R}^{d}
are
s
-sparse unit vectors for each
i\in[k]
. When the ambient dimensions
n
and
d
are clear from context, we write
\mathcal{S}_{s,k}\subseteq\mathbb{R}^{n\times d}
for the set of
s\times s
-sparse rank
k
matrices.

The above notion of sparse low rank matrices can be either used as an
assumption
or a
constraint
. We study both variants of the low rank approximation problem, and in both cases, we obtain improved algorithms over prior low rank approximation algorithms in certain settings.

In the first setting, one
assumes
that the optimal rank
k
approximation takes the form of a sparse low rank matrix. This scenario is a phenomenon known as
localization
of eigenvectors, and occurs frequently in many applications
[
HBCY21
,
ZYC+20
]
, for example in quantum many-body problems
[
LVTW09
,
NH15
]
and network analysis
[
PSC18
]
. In this case, the optimal solution to the low rank approximation problem can be computed by an SVD, which has efficient approximation algorithms
[
CW13
,
MM15
,
ZL16
]
. However, one may further ask the question of whether we can do better than the best known algorithms for approximate SVD under this additional sparsity assumption on the singular vectors. This question was studied in the work of
[
HBCY21
]
and a followup work of
[
ZYC+20
]
, which studied algorithms for computing eigenvectors in symmetric matrices with localized eigenvectors. In
[
HBCY21
]
, the authors study an algorithm for finding a small submatrix containing the supports of the leading eigenvectors by greedily adding rows and columns without formal guarantees, and
[
ZYC+20
]
seek to improve this approach using reinforcement learning techniques.

In the second setting, we instead deal with an arbitrary input matrix
\mathbf{A}
, but still seek a sparse low rank matrix to approximate
\mathbf{A}
. Thus, we
constrain
our low rank approximation to be sparse, and optimize over this smaller space instead. It turns out that this constraint makes the problem significantly harder in time complexity (as we show later), which is a phenomenon that is well-documented in the context of the related sparse PCA problem (see Section
1.4
for a discussion). Nonetheless, we show that this formulation of the problem is in fact
easier
than the unconstrained low rank approximation problem in the context of streaming algorithms.

1.1
Randomized Block Krylov Methods for Sparse Singular Vectors

Our first contribution gives new algorithms for the spectral low rank approximation problem, when we are promised that the top
k
singular components are
s
-sparse. Let
\mathbf{A}\in\mathbb{R}^{n\times d}
be a rank
r
matrix whose top
k
left and right singular vectors are
s
-sparse. The best previous known general case algorithm of
[
MM15
]
(see Theorem
1.11
), based on block Krylov methods, runs in time dominated by roughly

\frac{\nnz(\mathbf{A})k}{\sqrt{\varepsilon}}.

We improve this bound to roughly

\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}.

Theorem 1.2

(Spectral low rank approximation for sparse singular vectors)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
be a rank
r
matrix whose top
k
left and right singular vectors are supported on
s
coordinates. Then, there is an algorithm which outputs
\hat{\mathbf{A}}
such that

\left\lVert\mathbf{A}-\hat{\mathbf{A}}\right\rVert_{2}^{2}\leq(1+\varepsilon)\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{2}^{2}

in time

O\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}+\frac{n}{\varepsilon}\right\rparen\log\frac{srk\log n}{\varepsilon}+\poly\left\lparen s,k,\frac{1}{\varepsilon},\log n\right\rparen.

Remark 1.3
.

By a simple modification of our analyses, the condition for
s
-sparse singular vectors can be replaced by an approximate sparsity condition, such that for the
j
th singular component, there is a set of
s
coordinates which captures a

1-\frac{\varepsilon}{k\sqrt{r}}\frac{\sigma_{k+1}}{\sigma_{j}}

fraction of the
\ell_{2}
mass of the left singular vector, and similarly for the right singular vector.

We note that this robustness condition is a strong assumption, and we believe that an important direction for future work is to find algorithms that handle more relaxed assumptions on the approximate sparsity of the singular vectors.

Our algorithm proceeds in two steps: (1) we first identify small subsets of coordinates
S\subset[n]
and
T\subset[d]
that contain all large coordinates of the sparse left and right singular vectors (2) we proceed with standard low rank approximation algorithms on the subset of coordinates. The idea is that finding top singular vectors in the smaller submatrix is sufficient to find the top singular vectors in the original matrix, since all of our original singular vectors roughly retain their singular values in the submatrix, while the other singular components can only decrease. The observation for this general approach has already been made in
[
HBCY21
,
ZYC+20
]
. However, to implement this idea efficiently, several additional new ideas are needed, and our algorithm carefully combines power method, Chebyshev polynomials, and binary search to obtain the result of Theorem
1.2
.

1.1.1
Overview of Techniques

Our first idea is that with a budget of
\nnz(\mathbf{A})/\sqrt{\varepsilon}
running time, we can run naïve power method for
1/\sqrt{\varepsilon}
iterations initialized with a single random Gaussian vector
\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{d})
to compute
(\mathbf{A}\mathbf{A}^{\top})^{1/\sqrt{\varepsilon}}\mathbf{A}\mathbf{g}
. Using the SVD
\mathbf{A}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\top}
of
\mathbf{A}
, we may write this as
\mathbf{U}\boldsymbol{\Sigma}^{O(1/\sqrt{\varepsilon})}\mathbf{V}^{\top}\mathbf{g}
. Then by the rotational invariance of the Gaussian, this random vector is distributed as a random linear combination of the left singular vectors of
\mathbf{A}
, where the
i
th left singular vector is scaled by roughly
\sigma_{i}^{1/\sqrt{\varepsilon}}
. Then if
i\in[k]
is such that
\sigma_{i}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
, then
\sigma_{i}^{1/\sqrt{\varepsilon}}
is a constant factor larger than
\sigma_{k+1}^{1/\sqrt{\varepsilon}}
, so the
s
entries corresponding to the
i
th left singular vector stand out in
(\mathbf{A}\mathbf{A}^{\top})^{1/\sqrt{\varepsilon}}\mathbf{A}\mathbf{g}
. Thus, selecting the top
sk
entries with largest absolute value in
(\mathbf{A}\mathbf{A}^{\top})^{1/\sqrt{\varepsilon}}\mathbf{A}\mathbf{g}
retrieves a superset of the support of the left singular vectors with singular value
\sigma_{i}
for which
\sigma_{i}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
. We can repeat on the right side as well to obtain the support of the large right singular vectors.

The above approach is enough to find the large singular components with singular value at least
(1+\sqrt{\varepsilon})\sigma_{k+1}
, but we must find singular values all the way down to
(1+\varepsilon)\sigma_{k+1}
for a
(1+\varepsilon)
relative error approximation. To do this, we use the approach of
[
MM15
]
of using Chebyshev polynomials, which, given a location parameter
\alpha
, gives us a degree
1/\sqrt{\varepsilon}
polynomial
p
for which
p(x)
, for all
x\geq(1+\varepsilon)\alpha
, is a constant times greater than any
p(x)
for
x\leq\alpha
(see Lemma
3.9
for the mathematical statement). If we knew the location
\alpha=\sigma_{k+1}
, then we could compute
p(\mathbf{A})\mathbf{g}
in
\nnz(\mathbf{A})/\sqrt{\varepsilon}
time and use the same approach as before to find the support of all singular components
i
for which
\sigma_{i}\geq(1+\varepsilon)\sigma_{k+1}
. The challenge, of course, is that we do not know
\sigma_{k+1}
.

We first show how to find the value of
\sigma_{k+1}
up to a
(1+\sqrt{\varepsilon})
factor. To this end, we first show that if
\sigma_{i}
for
i\in[k]
is large, i.e.
\sigma_{i}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
, then we can find
\sigma_{i}
up to a
(1+\varepsilon)
factor using the set of
sk
large coordinates on the left and right located before, using the power method. However, note that we do not know for which
i
this is true. That is, if we let
\hat{\mathbf{A}}
be the
sk\times sk
submatrix supported on the large coordinates identified using the power method, we expect the large singular values of
\hat{\mathbf{A}}
to be good estimates of the large singular values of
\mathbf{A}
, but we do not know which of them are large enough to actually be good estimates.

To address this, let
i\in[k]
, and first note that
\sigma_{i}(\hat{\mathbf{A}})
is always a lower bound on
\sigma_{i}(\mathbf{A})
by the Cauchy interlacing theorem. Furthermore, suppose that
\hat{\mathbf{B}}
is a rank
i-1
approximation to
\hat{\mathbf{A}}
. Then,
\left\lVert\mathbf{A}-\hat{\mathbf{B}}\right\rVert_{2}
serves as an upper bound for
\sigma_{i}(\mathbf{A})
, as

\sigma_{i}(\mathbf{A})=\min_{\text{rank $i-1$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{2}\leq\left\lVert\mathbf{A}-\hat{\mathbf{B}}\right\rVert_{2}.

We show that for
i\in[k]
such that
\sigma_{i}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
, these are good lower and upper bounds on the singular value
\sigma_{i}(\mathbf{A})
, i.e., they are within
(1+\varepsilon)
factors of each other. Furthermore, they can both be computed in time roughly

\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}+\poly(s,k,\varepsilon^{-1}).

Thus, we have an extremely efficient way to certify our estimates to the singular values
\sigma_{i}(\mathbf{A})
, if they are large enough. We then consider the following binary search strategy over the singular values: if the upper and lower bounds are within
(1+\varepsilon)
factors of each other, then we keep searching lower, and otherwise, we search higher. If the
\sigma_{i_{*}}(\mathbf{A})
found is such that
\sigma_{i_{*}}(\mathbf{A})\geq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
, then the top
i_{*}
singular components are found in the initial power method step accurately enough so that
\left\lVert\mathbf{A}-\hat{\mathbf{B}}\right\rVert_{2}
is close to
\sigma_{i_{*}+1}(\mathbf{A})\leq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
, where
\hat{\mathbf{B}}
is a rank
i_{*}
approximation
\hat{\mathbf{B}}
of
\hat{\mathbf{A}}
. Otherwise,
\sigma_{i_{*}}(\mathbf{A})
itself is within a
(1+\sqrt{\varepsilon})
factor of
\sigma_{k+1}(\mathbf{A})
.

Now that we are within a
(1+\sqrt{\varepsilon})
factor of
\sigma_{k+1}(\mathbf{A})
, we just need
1/\sqrt{\varepsilon}
guesses in powers of
(1+\varepsilon)
in order to guess
\sigma_{k+1}(\mathbf{A})
up to a factor of
(1+\varepsilon)
. We can in fact afford to guess all of these locations
\alpha
, compute the corresponding Chebyshev polynomial
p
, compute
p(\mathbf{A})\mathbf{g}
from precomputed Krylov iterates, select the top
sk
entries, and then add the entries to the support that we consider.

With the support superset in hand, we finish the algorithm by performing an approximate SVD on this submatrix. Our full discussion can be found in Section
3
.

1.2
Streaming Frobenius Low Rank Approximation with Sparse Factors

We now discuss our results on the Frobenius norm sparse low rank approximation problem. For the Frobenius norm, a variant of the sparse low rank approximation problem has previously been studied in
[
ZZS02
,
ZZS04
]
, who slightly relax the sparsity requirement compared to our formulation.

We consider the
streaming setting
, in which our input matrix
\mathbf{A}
arrives as one pass over entrywise additive updates
\mathbf{A}_{i,j}\leftarrow\mathbf{A}_{i,j}+\Delta
for
\Delta\in\mathbb{R}
. The goal is to design algorithms which use low space. A standard approach is to consider
sketching algorithms
, in which we choose a random
m\times(nd)
matrix
\mathbf{S}
and maintain
\mathbf{S}(\vc(\mathbf{A}))
, where
\vc(\mathbf{A})
is the flattening of the
n\times d
matrix
\mathbf{A}
into an
nd
-dimensional vector, and then postprocess
\mathbf{S}(\vc(\mathbf{A}))
for the final result. This yields an algorithm of space roughly
\tilde{O}(m)
, up to bit complexity factors. We refer to each row of
\mathbf{S}
as a
measurement
. In fact, it is known that, with some restrictions, any turnstile streaming algorithm can be implemented as a linear sketch with roughly the same amount of memory
[
LNW14
,
AHLW16
,
KP20
]
, so in some sense, the number of measurements required for a sketching algorithm in a turnstile stream captures the space complexity of the streaming problem.

For the standard Frobenius norm low rank approximation problem, it is known since the work of
[
CW09
,
BWZ16
]
that
\tilde{\Theta}(nk/\varepsilon)
measurements are necessary and sufficient to output a rank
k
approximation of an
n\times d
matrix
\mathbf{A}
with a relative error Frobenius norm guarantee.

Theorem 1.4

(
[
CW09
,
BWZ16
]
)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. Then, any randomized sketching algorithm which outputs a rank
k
matrix
\mathbf{B}
such that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq(1+\varepsilon)\min_{\text{rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}

with probability at least
2/3
requires
\Theta((n+d)k/\varepsilon)
measurements, and this lower bound is tight up to constant factors.

1.2.1
Upper Bounds

We overcome the above negative result by showing that we can find an
s\times s
-sparse rank
k
matrix
\mathbf{B}
such that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq(1+\varepsilon)\min_{\mathbf{C}\in\mathcal{S}_{s,k}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}

in only
O(sk(\log n)/\varepsilon^{2})
measurements, which for constant
\varepsilon
replaces the dependence on the ambient dimension
n
by a dependence of
s
on the desired sparsity. Our algorithm achieving this space bound iterates over a net and runs in exponential time, which is necessary as we show in Section
4.2
. We additionally present polynomial time algorithms with some relaxations by allowing the output to be
s^{\prime}\times s^{\prime}
-sparse rank
k
, for
s^{\prime}=O(sk/\varepsilon)
, one with a
relative error guarantee
introduced above, as well as an improved algorithm with the weaker
additive error guarantee
, i.e.,

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq\min_{\mathbf{C}\in\mathcal{S}_{s,k}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

\mathbf{B}

In order to improve upon the measurement bound of this simple algorithm, we change our approximate SVD routine from a black box offline SVD algorithm to the
\ell_{2}
sampling based approach of
[
FKV04
,
DKM06
]
, which first performs an adaptive sampling routine in order to reduce the dimension before performing an SVD. Although this has a weaker additive error guarantee, we show that by carefully combining this approach with heavy hitter algorithms, we can remove a factor of
s
in the measurement bound.

1.2.2
Lower Bounds

Our upper bounds are complemented by relatively straightforward reductions from known lower bounds for related problems. Perhaps the most obvious is the lower bound for the usual Frobenius norm low rank approximation problem (Theorem
1.4
), which already gives an
\Omega(sk/\varepsilon)
lower bound.

Corollary 1.5
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
be such that there exists a unique
\mathbf{B}\in\mathcal{S}_{s,k}
that minimizes
\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}
over
\mathbf{B}\in\mathcal{S}_{s,k}
that is supported on an
s\times s
submatrix and has orthogonal factors. Then, any randomized sketching algorithm which outputs a matrix
\mathbf{B}\in\mathcal{S}_{s,k}
such that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq(1+\varepsilon)\min_{\text{rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}

with probability at least
2/3
requires
\Omega(sk/\varepsilon)
measurements.

Importantly, this lower bound holds even when there is a unique optimal solution that is promised to lie on an
s\times s
submatrix, and the sparse low rank factors are orthogonal. Note that none of these properties is guaranteed for the general problem. In fact, given the promise that an optimal solution exists on an
s\times s
submatrix, our additive error polynomial time algorithm improves to a measurement bound of
sk\cdot\poly(\log n,\varepsilon^{-1})
, which has a tight dependence on
s
and
k
.

Despite this natural lower bound, tighter lower bounds can be obtained from reductions from work in the sparse recovery literature when the optimal solution need not be supported on an
s\times s
submatrix. In the sparse recovery problem, one is given a hidden vector
\mathbf{x}\in\mathbb{R}^{n}
, and the goal is to output an
s
-sparse vector
\hat{\mathbf{x}}
such that

\left\lVert\mathbf{x}-\hat{\mathbf{x}}\right\rVert_{2}^{2}\leq(1+\varepsilon)\min_{\text{$s$-sparse $\mathbf{x}^{\prime}$}}\left\lVert\mathbf{x}-\mathbf{x}^{\prime}\right\rVert_{2}^{2},

given linear measurements of the vector. The following lower bounds are known for this problem:

Theorem 1.6

(
[
PW11

.

Let
\mathbf{x}\in\mathbb{R}^{n}
. Then, any randomized sketching algorithm which outputs an

such that

\left\lVert\mathbf{x}-\hat{\mathbf{x}}\right\rVert_{2}^{2}\leq(1+\varepsilon)\min_{\text{$s$-sparse $\mathbf{x}^{\prime}$}}\left\lVert\mathbf{x}-\mathbf{x}^{\prime}\right\rVert_{2}^{2}

with probability at least
2/3
requires
\Omega(s(\log(n/s))/\varepsilon)
measurements. Furthermore, if the algorithm guarantees that
\hat{\mathbf{x}}
is
s
-sparse, then
\Omega(s/\varepsilon^{2})
measurements are required.

Note that an
sk
-sparse vector can be written as the sum of
k
many
s
-sparse vectors. This simple observation immediately gives the following:

Corollary 1.7
.

\mathbf{A}\in\mathbb{R}^{n\times d}

1.3
Gaussian Noise Spectral Sparse Low Rank Approximation

As a final contribution, we study the sketching complexity of sparse low rank approximation in the common setting where the input matrix
\mathbf{A}\in\mathbb{R}^{n\times n}
is the sum of a low rank signal and additive Gaussian noise. That is,

\mathbf{A}=\lambda\mathbf{X}+\mathbf{G}

where
\mathbf{G}_{i,j}\sim\mathcal{N}(0,1)
,
\left\lVert\mathbf{X}\right\rVert_{2}=1
, and
\lambda
is roughly
O(\sqrt{n})
. This “low rank signal plus Gaussian noise” setting is ubiquitous in both theory and in practice, in areas such as matrix denoising (see, e.g.,
[
SN13
,
CST13
]

Sparse PCA.

The closely related problem of sparse PCA also seeks sparse low rank approximations and has been studied intensely in a variety of settings. In this problem, one seeks only a sparse right factor, that is, an
s
-sparse unit vector
\mathbf{x}
that maximizes the quantity
\mathbf{x}^{\top}\mathbf{A}^{\top}\mathbf{A}\mathbf{x}
. We refer to
[
NmJ15
,
ZX18
]
for surveys on various formulations, algorithms, and hardness results on sparse PCA. Note the distinction between this problem and our problem, which seeks to minimize the reconstruction error with both sparse left and right factors. From the perspective of computational complexity, it is known that sparse PCA is NP-hard even to approximate
[
MWA06
,
Mag17
]
, with improved inapproximability results under other complexity theoretic assumptions
[
CPR16
]
. Sparse PCA has also recently been studied from an average-case complexity perspective under the natural input distribution of the form “signal plus noise”, see e.g.,
[
BB19
]
.

2.1
\varepsilon
-Nets

We will need the notion of
\varepsilon
-nets for our analyses. See, e.g., Section 4.2 of
[
Ver18
]
for a standard reference.

Definition 2.1

(
\varepsilon
-net)
.

For a set
K
, a subset
\mathcal{N}\subseteq K
is an
\varepsilon
-net
of
K
if for every
\mathbf{x}\in K
there exists an
\hat{\mathbf{x}}
such that

\left\lVert\mathbf{x}-\hat{\mathbf{x}}\right\rVert_{2}\leq\varepsilon.

For
K=\mathbb{S}^{d-1}
the unit sphere in
d
dimensions, there exist small
\varepsilon
-nets.

Lemma 2.2

(Corollary 4.2.13,
[
Ver15
]
)
.

Let
\varepsilon\in(0,1)
. There exists an
\varepsilon
-net
\mathcal{N}
of
\mathbb{S}^{d-1}
of size at most

\left\lvert\mathcal{N}\right\rvert\leq\left\lparen\frac{3}{\varepsilon}\right\rparen^{d}.

Using this, we can construct an
\varepsilon
-net for
\mathcal{S}_{s,k}\cap\mathbb{S}^{n\times d-1}
, where
\mathbb{S}^{n\times d-1}
denotes the set of all
n\times d
matrices with Frobenius norm
1
, provided that the coefficients
\tau_{i}
in Definition
1.1
are bounded by
\poly(n)
.

Corollary 2.3

(
\varepsilon
-net for
\mathcal{S}_{s,k}
)
.

Let
\varepsilon\in(0,1)
. There exists an
\varepsilon
-net
\mathcal{N}
of
\mathcal{S}_{s,k}^{\mathrm{bounded}}\cap\mathbb{S}^{n\times d-1}
of size at most

\left\lvert\mathcal{N}\right\rvert\leq\poly(nk/\varepsilon)^{sk},

where
\mathcal{S}_{s,k}^{\mathrm{bounded}}
is the set of
s\times s
-sparse rank
k
matrices with
\tau_{i}
bounded by
\poly(n)
.

Proof.

We first construct an
\varepsilon
-net
\mathcal{N}
over rank
1

s\times s
sparse matrices in the Frobenius norm and bound its size. Consider an
(\varepsilon/2)
-net for
\mathbb{S}^{s-1}
, of size at most
(6/\varepsilon)^{s}
(see Lemma
2.2
). Then for any rank
1

s\times s
sparse matrix
\sigma\mathbf{u}\mathbf{v}^{\top}
, we may find vectors
\mathbf{u}^{\prime}
and
\mathbf{v}^{\prime}
in the net such that

\displaystyle\left\lVert\mathbf{u}\mathbf{v}^{\top}-\mathbf{u}^{\prime}(\mathbf{v}^{\prime})^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{u}\mathbf{v}^{\top}-\mathbf{u}^{\prime}\mathbf{v}^{\top}\right\rVert_{F}+\left\lVert\mathbf{u}^{\prime}\mathbf{v}^{\top}-\mathbf{u}^{\prime}(\mathbf{v}^{\prime})^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{u}-\mathbf{u}^{\prime}\right\rVert_{2}\left\lVert\mathbf{v}\right\rVert_{2}+\left\lVert\mathbf{u}^{\prime}\right\rVert_{2}\left\lVert\mathbf{v}-\mathbf{v}^{\prime}\right\rVert_{2}

\displaystyle\leq\varepsilon.

Then we choose a sparsity pattern for this submatrix, which requires a net of total size at most

\binom{n}{s}^{2}\left\lparen\frac{6}{\varepsilon}\right\rparen^{2s}\leq\left\lparen\frac{6en}{\varepsilon s}\right\rparen^{2s}

Now suppose
\mathbf{X}\in\mathcal{S}_{s,k}
with

\mathbf{X}=\sum_{i=1}^{k}\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}.

We now approximate each component up to
\varepsilon/k
Frobenius norm error. Because
\tau_{i}\leq\poly(n)
, for each
i\in[k]
, we can find a
\tau_{i}^{\prime}
among at most
\poly(n)k/\varepsilon
candidates such that

\left\lvert\tau_{i}-\tau_{i}^{\prime}\right\rvert\leq\frac{\varepsilon}{2k}.

Furthermore, we find
\mathbf{x}_{i}^{\prime}
and
\mathbf{y}_{i}^{\prime}
in an
\varepsilon/\poly(n)k
-net for
s\times s
-sparse rank
1
matrices such that

\left\lVert\mathbf{x}_{i}^{\prime}\mathbf{y}_{i}^{\prime\top}-\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}\leq\frac{\varepsilon}{\poly(n)k}.

Then,

\displaystyle\left\lVert\tau_{i}^{\prime}\mathbf{x}_{i}^{\prime}\mathbf{y}_{i}^{\prime\top}-\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\tau_{i}^{\prime}\mathbf{x}_{i}^{\prime}\mathbf{y}_{i}^{\prime\top}-\tau_{i}^{\prime}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}+\left\lVert\tau_{i}^{\prime}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}-\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}

\displaystyle\leq\left\lvert\tau_{i}\right\rvert\left\lVert\mathbf{x}_{i}^{\prime}\mathbf{y}_{i}^{\prime\top}-\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}+\left\lvert\tau_{i}-\tau_{i}^{\prime}\right\rvert\left\lVert\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}

\displaystyle\leq\frac{\varepsilon}{2k}+\frac{\varepsilon}{2k}

\displaystyle\leq\frac{\varepsilon}{k}.

Then summing over the
k
components, we find an
\mathbf{X}^{\prime}\in\mathcal{S}_{s,k}
for

\mathbf{X}^{\prime}=\sum_{i=1}^{k}\tau_{i}^{\prime}\mathbf{x}_{i}^{\prime}\mathbf{y}_{i}^{\prime\top}

that is at most a distance of
\varepsilon
to
\mathbf{X}
, by the triangle inequality. The total net size is

\left[\frac{\poly(n)k}{\varepsilon}\left\lparen\frac{\poly(n)k}{\varepsilon s}\right\rparen^{2s}\right]^{k}=\poly(nk/\varepsilon)^{sk}.

2.2
CountSketch

[
CCF04
]

We collect some results on
CountSketch

[
CCF04
]
, a versatile primitive for the design of sketching algorithms.

Definition 2.4

(
CountSketch

[
CCF04
]
)
.

A
CountSketch
matrix is a distribution over
r\times n
matrices
\mathbf{S}
where samples are drawn as follows. Let
h:[n]\to[r]
and
\sigma:[n]\to\{\pm 1\}
be random hash functions. Then,

(\mathbf{S})_{i,j}=\begin{cases}\sigma_{j}&\text{if $i=h(j)$}\\
0&\text{otherwise}\end{cases}.

Equivalently,

\mathbf{S}=\mathbf{H}\mathbf{D}

where
\mathbf{D}
is an
n\times n
diagonal matrix with
\sigma(j)
in the
j
th diagonal position for
j\in[n]
, and
\mathbf{H}
is an
r\times n
matrix where the
j
th column is the random standard basis vector
\mathbf{e}_{h(j)}
for
j\in[n]
.

That is,
\mathbf{S}
acts on a vector by multiplying each coordinate by a random sign and hashing it to one of
r
buckets.

2.2.1
Tail Error Guarantee

The first guarantee achieved by
CountSketch
, introduced by
[
CCF04
]
, is the
tail error guarantee
.

Lemma 2.5

(Tail error guarantee
[
CCF04
]
)
.

Let
\mathbf{x}\in\mathbb{R}^{n}
. Let
B\in\mathbb{N}
and
\delta\in(0,1)
. Consider
r=O\left\lparen\log\frac{1}{\delta}\right\rparen
independent copies of
O(B)\times n

CountSketch
matrices
\mathbf{S}^{(1)},\mathbf{S}^{(2)},\dots,\mathbf{S}^{(r)}
. Then, given

\mathbf{S}^{(1)}\mathbf{x},\mathbf{S}^{(2)}\mathbf{x},\dots,\mathbf{S}^{(r)}\mathbf{x},

for each
i\in[n]
, one can recover an estimate
\hat{\mathbf{x}}_{i}
such that

\Pr\left\{\left\lvert\hat{\mathbf{x}}_{i}-\mathbf{x}_{i}\right\rvert^{2}\leq\frac{1}{B}\left\lVert\mathbf{x}_{\overline{[B]}}\right\rVert_{2}^{2}\right\}\geq 1-\delta,

where
\mathbf{x}_{\overline{[B]}}
denotes the vector obtained by zeroing out the
B
coordinates of
\mathbf{x}
with largest absolute value.

2.2.2
Row-wise Approximation

The tail error guarantee generalizes to the following guarantee for estimating the rows of a matrix
[
MRWZ20
, Lemma 2.2]
:

Lemma 2.6

(Row-wise approximation
[
MRWZ20
]
)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
,
\varepsilon>0
, and
\delta\in(0,1)
. Consider
r=O(\log(\frac{1}{\delta}))
independent copies of
O(\frac{1}{\varepsilon})\times n

CountSketch
matrices
\mathbf{S}^{(1)},\mathbf{S}^{(2)},\dots,\mathbf{S}^{(r)}
. Then, given

\mathbf{S}^{(1)}\mathbf{A},\mathbf{S}^{(2)}\mathbf{A},\dots,\mathbf{S}^{(r)}\mathbf{A},

one can obtain an estimate
\hat{\mathbf{A}}\in\mathbb{R}^{n\times d}
such that for each
i\in[n]
,

\Pr\left\{\left\lVert\mathbf{e}_{i}^{\top}\hat{\mathbf{A}}-\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}\leq\varepsilon\left\lVert\mathbf{A}_{\overline{[1/\varepsilon]},*}\right\rVert_{F}^{2}\right\}\geq 1-\delta,

where
\mathbf{A}_{\overline{[1/\varepsilon]},*}
denotes the matrix with the top
1/\varepsilon
rows with largest
\ell_{2}
norm zeroed out.

As a corollary, we obtain the following lemma for approximating row norms with an additive-multiplicative error guarantee.

Corollary 2.7

(Row norm approximation)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
,
\varepsilon>0
,
\alpha>0
, and
\delta\in(0,1)
. Consider
r=O(\log(\frac{1}{\delta}))
independent copies of
O(\frac{1}{\varepsilon})\times n

CountSketch
matrices
\mathbf{S}^{(1)},\mathbf{S}^{(2)},\dots,\mathbf{S}^{(r)}
and an
O(\frac{1}{\alpha^{2}}(\log\frac{n}{\delta}))\times d
i.i.d. Gaussian matrix
\mathbf{G}
. Then, given

\mathbf{S}^{(1)}\mathbf{A}\mathbf{G}^{\top},\mathbf{S}^{(2)}\mathbf{A}\mathbf{G}^{\top},\dots,\mathbf{S}^{(r)}\mathbf{A}\mathbf{G}^{\top},

one can obtain an estimate
\widehat{\mathbf{A}\mathbf{G}^{\top}}\in\mathbb{R}^{n\times d}
such that for each
i\in[n]
,

\left\lvert\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}\right\rVert_{2}-\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}\right\rvert\leq\alpha\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}+\sqrt{(1+\alpha)\varepsilon}\left\lVert\mathbf{A}_{\overline{[1/\varepsilon]},*}\right\rVert_{F}

where
\mathbf{A}_{\overline{[1/\varepsilon]},*}
denotes the matrix with the top
1/\varepsilon
rows with largest
\ell_{2}
norm zeroed out.

Proof.

Lemma
2.7
provides us with an estimate
\widehat{\mathbf{A}\mathbf{G}^{\top}}
such that

\Pr\left\{\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}-\mathbf{e}_{i}^{\top}\mathbf{A}\mathbf{G}^{\top}\right\rVert_{2}^{2}\leq\varepsilon\left\lVert(\mathbf{A}\mathbf{G}^{\top})_{\overline{[1/\varepsilon]},*}\right\rVert_{F}^{2}\right\}\geq 1-\frac{\delta}{2}.

Note that
\mathbf{G}
is a Johnson-Lindenstrauss transform (see, e.g.,
[
DG03
]
) so that

\Pr\left\{\forall i\in[n],\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\mathbf{G}^{\top}\right\rVert_{2}^{2}=(1\pm\alpha)\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}\right\}\geq 1-\frac{\delta}{2}.

By a union bound, both of these happen with probability at least
1-\delta
. We now condition on this event.

We first bound
\left\lVert(\mathbf{A}\mathbf{G}^{\top})_{\overline{[1/\varepsilon]},*}\right\rVert_{F}^{2}
. This quantity is at most the Frobenius norm of
\mathbf{A}\mathbf{G}^{\top}
after deleting
any
set of
1/\varepsilon
rows. By letting these
1/\varepsilon
rows be the
1/\varepsilon
heaviest rows of
\mathbf{A}
, say
S\subseteq[n]
, we have the bound

\left\lVert(\mathbf{A}\mathbf{G}^{\top})_{\overline{[1/\varepsilon]},*}\right\rVert_{F}^{2}\leq\sum_{i\in[n]\setminus S}\left\lVert\mathbf{e}_{i}\mathbf{A}\mathbf{G}^{\top}\right\rVert_{2}^{2}\leq\sum_{i\in[n]\setminus S}(1+\alpha)\left\lVert\mathbf{e}_{i}\mathbf{A}\right\rVert_{2}^{2}=(1+\alpha)\left\lVert\mathbf{A}_{\overline{[1/\varepsilon]},*}\right\rVert_{F}^{2}.

Note then that

\displaystyle\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}\right\rVert_{2}

\displaystyle=\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\mathbf{G}^{\top}\right\rVert_{2}\pm\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}-\mathbf{e}_{i}^{\top}\mathbf{A}\mathbf{G}^{\top}\right\rVert_{2}

\displaystyle=(1\pm\alpha)\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}\pm\sqrt{\varepsilon}\left\lVert(\mathbf{A}\mathbf{G}^{\top})_{\overline{[1/\varepsilon]},*}\right\rVert_{F}

\displaystyle=(1\pm\alpha)\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}\pm\sqrt{(1+\alpha)\varepsilon}\left\lVert\mathbf{A}_{\overline{[1/\varepsilon]},*}\right\rVert_{F}.\qed

3.1
Approximating Singular Components

To carry out our plan as described in the introduction (Section
1.1.1
), we first calculate the magnitude of coordinates that we need to capture in order to achieve a relative error spectral approximation. We follow
[

]
and make use of the fact that additive Frobenius norm low rank approximation implies additive spectral norm low rank approximation, originally due to
[
Gu15
]
.

Lemma 3.1

(Theorem 3.4 of
[
Gu15
]
)
.

For any
\mathbf{A}\in\mathbb{R}^{n\times d}
, let
\mathbf{B}\in\mathbb{R}^{n\times d}
be any rank
k
matrix satisfying
\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq\lVert\mathbf{A}-\mathbf{A}_{k}\rVert_{F}^{2}+\eta
. Then,

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}^{2}\leq\lVert\mathbf{A}-\mathbf{A}_{k}\rVert_{2}^{2}+\eta.

By the above result, it suffices to find a rank
k
matrix
\mathbf{B}
such that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq\lVert\mathbf{A}-\mathbf{A}_{k}\rVert_{F}^{2}+\varepsilon\sigma_{k+1}^{2}.

Using this, we show that it suffices to find all coordinates of the top left singular vectors
\mathbf{U}\mathbf{e}_{j}
such that

\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\mathbf{e}_{j}\rvert\geq\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}},

and similarly, all coordinates of the top right singular vectors
\mathbf{V}\mathbf{e}_{j}
such that

\lvert\mathbf{e}_{i}^{\top}\mathbf{V}\mathbf{e}_{j}\rvert\geq\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}}.

Lemma 3.2
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
have rank
r
with singular value decomposition
\mathbf{A}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\top}
, and let
\varepsilon\in(0,1/2)
. Let
S\subset[n]
and
T\subset[d]
be a set of coordinates such that

\displaystyle S

\displaystyle\supset\bigcup_{j\in[r]}\left\{i\in[n]:\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\mathbf{e}_{j}\rvert\geq\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}}\right\}

\displaystyle T

\displaystyle\supset\bigcup_{j\in[r]}\left\{i\in[d]:\lvert\mathbf{e}_{i}^{\top}\mathbf{V}\mathbf{e}_{j}\rvert\geq\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}}\right\}

Let
\mathbf{B}
be a rank
k
matrix such that

\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{B}\right\rVert_{F}^{2}\leq\min_{\text{rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{C}\right\rVert_{F}^{2}+\eta.

Then,

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+8\varepsilon\sigma_{k+1}^{2}+\eta.

Proof.

Note first that

\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}=\sum_{t=k+1}^{r}\sigma_{t}^{2}(\mathbf{A})\leq\sum_{t=k+1}^{r}\sigma_{k+1}^{2}(\mathbf{A})\leq\sigma_{k+1}^{2}(\mathbf{A})r.

Then,

\displaystyle\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle\stackrel{{\scriptstyle(1)}}{{\leq}}\left\lVert\mathbf{A}-\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{A}_{k}\right\rVert_{F}^{2}+\eta

\displaystyle\stackrel{{\scriptstyle(2)}}{{=}}\left\lVert\mathbf{A}-\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

\displaystyle\stackrel{{\scriptstyle(3)}}{{=}}\left\lVert\mathbf{A}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

\displaystyle\stackrel{{\scriptstyle(4)}}{{\leq}}\left\lparen\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}+\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}\right\rparen^{2}+\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

\displaystyle=\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+2\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}+2\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+2\sigma_{k+1}\sqrt{r}\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}+2\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

In the above, the inequality (1) is due to the approximate optimality of
\mathbf{B}
, the identities (2) and (3) are by the Pythagorean theorem, and inequality (4) is the triangle inequality. Finally, we calculate that

\displaystyle\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\right\rVert_{F}+\left\lVert\mathbf{P}_{S}\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}

\displaystyle=\left\lVert\sum_{j=1}^{k}\sigma_{j}\mathbf{P}_{\overline{S}}\mathbf{U}\mathbf{e}_{j}(\mathbf{V}\mathbf{e}_{j})^{\top}\right\rVert_{F}+\left\lVert\sum_{j=1}^{k}\sigma_{j}\mathbf{P}_{S}\mathbf{U}\mathbf{e}_{j}(\mathbf{V}\mathbf{e}_{j})^{\top}\mathbf{P}_{\overline{T}}\right\rVert_{F}

\displaystyle\leq\sum_{j=1}^{k}\sigma_{j}\left\lVert\mathbf{P}_{\overline{S}}\mathbf{U}\mathbf{e}_{j}\right\rVert_{2}\left\lVert\mathbf{V}\mathbf{e}_{j}\right\rVert_{2}+\sigma_{j}\left\lVert\mathbf{P}_{S}\mathbf{U}\mathbf{e}_{j}\right\rVert_{2}\left\lVert\mathbf{P}_{\overline{T}}\mathbf{V}\mathbf{e}_{j}\right\rVert_{2}

\displaystyle\leq\sum_{j=1}^{k}2\sigma_{j}\left\lparen\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}}\right\rparen\sqrt{s}

\displaystyle=\frac{2\varepsilon}{\sqrt{r}}\sigma_{k+1}

so the previous bound is

\displaystyle\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+4\sigma_{k+1}\sqrt{r}\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}+2\left\lVert\mathbf{A}_{k}-\mathbf{P}_{S}\mathbf{A}_{k}\mathbf{P}_{T}\right\rVert_{F}^{2}+\eta

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+4\varepsilon\sigma_{k+1}^{2}+\frac{8\varepsilon^{2}}{r}\sigma_{k+1}^{2}+\eta

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+8\varepsilon\sigma_{k+1}^{2}+\eta.\qed

3.2
Finding the Support of Singular Vectors with Large Singular Value

We next show how to find all large coordinates of singular vectors whose singular values
\sigma_{j}
are at least a
(1+\sqrt{\varepsilon})
factor larger than
\sigma_{k+1}
. By the results of the previous section, we seek to find all of the large coordinates of the top sparse singular vectors, which have absolute value at least

\tau_{j}\coloneqq\frac{\varepsilon}{k\sqrt{sr}}\frac{\sigma_{k+1}}{\sigma_{j}}

for the
j
th singular vector.

Our identification of the large coordinates of the top sparse singular vectors starts from the standard analysis of the power method (see also, e.g., the overview of
[
MM15
]
). If we run power method starting from a random Gaussian vector
\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{d})
, that is, we compute
(\mathbf{A}\mathbf{A}^{\top})^{q}\mathbf{A}\mathbf{g}
for some
q\in\mathbb{N}
, then we retrieve a random Gaussian linear combination of the left singular vectors
\mathbf{U}\mathbf{e}_{j}
, each scaled by
\sigma_{j}^{2q+1}
. This is a simple consequence of the rotational invariance of the Gaussian:

Lemma 3.3
.

Let
\mathbf{g}^{\prime}\sim\mathcal{N}(0,\mathbf{I}_{d})
and let
q\in\mathbb{N}
. Let
\mathbf{A}\in\mathbb{R}^{n\times d}
be a rank
r
matrix and let
\mathbf{A}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^{\top}
be its singular value decomposition. Then,
(\mathbf{A}\mathbf{A}^{\top})^{q}\mathbf{A}\mathbf{g}^{\prime}
has the same distribution as

\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}=\sum_{j=1}^{r}\mathbf{g}_{j}\sigma_{j}^{2q+1}\mathbf{U}\mathbf{e}_{j}

for
\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{r})
.

Note then that for
\sigma_{j}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
, the
j
th singular vector is scaled more than the
(k+1)
-st singular vector by a factor of at least
(\sigma_{j}/\sigma_{k+1})^{2q+1}
. For
q
roughly order
1/\sqrt{\varepsilon}
, this separates all large coordinates of the
j
th singular vector from the coordinates of the
(k+1)
-st singular vector.

Lemma 3.4
.

For

q=O\left\lparen\frac{1}{\sqrt{\varepsilon}}\log\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen,

the
sk
coordinates of
(\mathbf{A}\mathbf{A}^{\top})^{q}\mathbf{A}\mathbf{g}
with largest absolute value are guaranteed to contain all entries
i\in[n]
for which there exists a
j\in[k]
with
\sigma_{j}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
and

\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\mathbf{e}_{j}\right\rvert\geq\tau_{j}.

Proof.

For

q=O\left\lparen\frac{1}{\sqrt{\varepsilon}}\log\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen,

the blow up factor
(\sigma_{j}/\sigma_{k+1})^{2q+1}
is at least

\left\lparen\frac{\sigma_{j}}{\sigma_{k+1}}\right\rparen^{2q+1}\geq(1+\sqrt{\varepsilon})^{2q}\frac{\sigma_{j}}{\sigma_{k+1}}=\Theta\left\lparen\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen\frac{\sigma_{j}}{\sigma_{k+1}}=\Theta\left\lparen\frac{sk\sqrt{\log n}}{\tau_{j}}\right\rparen

for the
j
th singular component. The time required to compute this vector
(\mathbf{A}\mathbf{A}^{\top})^{q}\mathbf{A}\mathbf{g}
is

O\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}\log\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen=O\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}\log\frac{srk\log n}{\varepsilon}\right\rparen

Now note that for each
i\in[n]
, we have that

\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}\sim\mathcal{N}\left\lparen 0,\left\lVert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\right\rVert_{2}^{2}\right\rparen.

Since the maximum absolute value among
n
Gaussians is
O(\sqrt{\log n})
with constant probability, we have

\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}\right\rvert\leq O(\sqrt{\log n})\left\lVert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\right\rVert_{2}.

Furthermore, if we consider all
i
in the support of the top
k
singular vectors, which is at most
sk
coordinates, then the minimum absolute value among the
sk
Gaussians is

\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}\right\rvert\geq\Omega\left\lparen\frac{1}{sk}\right\rparen\left\lVert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\right\rVert_{2}.

Now consider a coordinate
i\in[n]
such that

\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\mathbf{e}_{j}\right\rvert\geq\tau_{j}

for some
j\in[k]
such that
\sigma_{j}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
. Then by the previous results,

\displaystyle\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}\right\rvert

\displaystyle\geq\Omega\left\lparen\frac{1}{sk}\right\rparen\left\lVert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\right\rVert_{2}

\displaystyle\geq\Omega\left\lparen\frac{1}{sk}\right\rparen\sigma_{j}^{2q+1}\tau_{j}

\displaystyle=\Omega\left\lparen\frac{1}{sk}\right\rparen\sigma_{k+1}^{2q+1}\left\lparen\frac{\sigma_{j}}{\sigma_{k+1}}\right\rparen^{2q+1}\tau_{j}

\displaystyle\geq\Omega\left\lparen\frac{1}{sk}\right\rparen\sigma_{k+1}^{2q+1}\Theta\left\lparen\frac{sk\sqrt{\log n}}{\tau_{j}}\right\rparen\tau_{j}

\displaystyle=\Omega\left\lparen\sigma_{k+1}^{2q+1}\sqrt{\log n}\right\rparen.

On the other hand, for any
i\in[n]
that is outside of the at most
sk
coordinates of the support of the top
k
singular vectors, then

\left\lvert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\mathbf{g}\right\rvert\leq O(\sqrt{\log n})\left\lVert\mathbf{e}_{i}^{\top}\mathbf{U}\boldsymbol{\Sigma}^{2q+1}\right\rVert_{2}\leq O(\sigma_{k+1}^{2q+1}\sqrt{\log n}).

We thus conclude as desired.
∎

In other words, we can identify a set of
sk
coordinates that contains all large entries of left singular vectors
j
for which
\sigma_{j}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
. Repeating for the right singular vectors, we may identify the sets
S
and
T
as required by Lemma
3.2
.

3.3
Approximating Large Singular Values

Our next task is to compute the singular values of
\mathbf{A}
with
\sigma_{j}(\mathbf{A})\geq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
, up to
(1+\varepsilon)
factors. We first show that approximating the singular values of
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
directly approximates the singular values of
\mathbf{A}
, when the singular values are sufficiently large.

Lemma 3.5
.

Let
m
be the number of singular values of
\mathbf{A}
such that
\sigma_{j}(\mathbf{A})\geq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
. Let
S\subset[n]
and
T\subset[d]
be sets satisfying the hypotheses of Lemma
3.2
. Then for each
l\in[m]
,

(1-8\varepsilon)\sigma_{l}^{2}(\mathbf{A})\leq\sigma_{l}^{2}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})\leq\sigma_{l}^{2}(\mathbf{A}).

Proof.

Recall the Cauchy interlacing theorem:

Theorem 3.6

(Cauchy interlacing theorem)
.

Let
\mathbf{M}
be a symmetric matrix and let
\mathbf{N}
be a principal submatrix of size
l\times l
. Then for all
j\in[l]
,

\lambda_{j}(\mathbf{M})\geq\lambda_{j}(\mathbf{N})\geq\lambda_{n-l+j}(\mathbf{M}).

Then applying the interlacing theorem to
\mathbf{M}=\mathbf{A}\mathbf{A}^{\top}
and
\mathbf{N}=\mathbf{P}_{S}\mathbf{A}\mathbf{A}^{\top}\mathbf{P}_{S}^{\top}
, we find that the singular values of
\mathbf{P}_{S}\mathbf{A}
uniformly bound the top
sk
singular values of
\mathbf{A}
from below, and similarly, the singular values of
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
uniformly bound the singular values of
\mathbf{P}_{S}\mathbf{A}
from below. We thus have that

\sigma_{j}(\mathbf{A})\geq\sigma_{j}(\mathbf{P}_{S}\mathbf{A})\geq\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})

for all
j\in[sk]
. Furthermore, we know by Lemma
3.2
that for each
l\in[m]
,

\left\lVert\mathbf{A}-\mathbf{A}_{l}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{l}\right\rVert_{F}^{2}+8\varepsilon\sigma_{l+1}(\mathbf{A})^{2}

(1)

where
(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}
is the best rank
l
approximation
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
. Now note that

\left\lVert\mathbf{A}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}-\mathbf{A}_{l}\right\rVert_{F}^{2}=\left\lVert\mathbf{A}_{l}\right\rVert_{F}^{2}

and

\displaystyle\left\langle\mathbf{A}-(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l},(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rangle

\displaystyle=\left\langle\mathbf{A}-\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T},(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rangle

\displaystyle\hskip 50.00008pt+\left\langle\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l},(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rangle=0

so

\left\lVert\mathbf{A}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}-(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rVert_{F}^{2}=\left\lVert(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rVert_{F}^{2}

by the Pythagorean theorem. Then subtracting the inequalities of Equation
1
from
\left\lVert\mathbf{A}\right\rVert_{F}^{2}
, we have that

\left\lVert\mathbf{A}_{l}\right\rVert_{F}^{2}-8\varepsilon\sigma_{l+1}(\mathbf{A})^{2}\leq\left\lVert(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}_{l}\right\rVert_{F}^{2}.

Then,

\displaystyle\sigma_{l}^{2}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})

\displaystyle=\left\lVert(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l}\right\rVert_{F}^{2}-\left\lVert(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})_{l-1}\right\rVert_{F}^{2}

\displaystyle\geq\left\lVert\mathbf{A}_{l}\right\rVert_{F}^{2}-8\varepsilon\sigma_{l+1}(\mathbf{A})^{2}-\left\lVert\mathbf{A}_{l-1}\right\rVert_{F}^{2}

\displaystyle=\sigma_{l}^{2}(\mathbf{A})-8\varepsilon\sigma_{l+1}(\mathbf{A})^{2}

\displaystyle\geq(1-8\varepsilon)\sigma_{l}^{2}(\mathbf{A})

as desired.
∎

We may use the existing results of
[
MM15
]
to find
(1+\varepsilon)
factor approximations to the top
k
singular values of
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
in time

O\left\lparen\frac{\nnz(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})k}{\sqrt{\varepsilon}}\log(sk)\right\rparen=O\left\lparen\frac{s^{2}k^{3}}{\sqrt{\varepsilon}}\log(sk)\right\rparen.

However, note that given estimates for the singular values of
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
, we do not know which ones are within a
(1+\varepsilon)
factor of the singular values of
\mathbf{A}
, since we do not know the number
m
of singular values
j
with
\sigma_{j}(\mathbf{A})\geq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
. However, by the Cauchy interlacing theorem, the singular values of
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
are always a lower bound on the singular values of
\mathbf{A}
, so it suffices to compute an upper bound for the singular values of
\mathbf{A}
that are at most a
(1+\varepsilon)
factor larger than the lower bound. We obtain such an upper bound on the singular values of
\mathbf{A}
by approximating
\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}
for a rank
l
matrix
\mathbf{B}
. Indeed, if
\mathbf{B}
is rank
l
, then

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}^{2}\geq\min_{\text{rank $l$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}=\sigma_{l+1}(\mathbf{A})^{2}.

This idea is executed in the following lemma.

Lemma 3.7
.

Let
S\subset[n]
and
T\subset[d]
be sets of size
sk
each that satisfy the hypotheses of Lemma
3.2
. Given such
S
and
T
and an index
j\in[k]
, there is a randomized algorithm that runs in time

O\left\lparen\frac{\nnz(\mathbf{A})+s^{2}k^{3}}{\sqrt{\varepsilon}}\log(sk)\right\rparen

and outputs numbers
U
and
L
such that

L\leq\sigma_{j}^{2}(\mathbf{A})\leq U

with probability at least
0.99
. Furthermore, if
j\in[m]
, where
m
is the number of singular values
j
with
\sigma_{j}\geq(1+\sqrt{\varepsilon})\sigma_{k+1}
, we have that

\frac{U}{L}\leq\frac{1+10\varepsilon}{1-9\varepsilon}\leq 1+20\varepsilon.

Proof.

We first show how to obtain the lower bound
L
. By the Cauchy interlacing theorem (as in Lemma
3.5
), we have that

\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})\leq\sigma_{j}(\mathbf{A}).

Then by the randomized block Krylov algorithm of
[
MM15
]
(see Theorem
1.11
), we may find an estimate
L
to
\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})
such that

(1-\varepsilon)\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})\leq L\leq\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})

in time

O\left\lparen\frac{\nnz(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})k}{\sqrt{\varepsilon}}\log(sk)\right\rparen=O\left\lparen\frac{s^{2}k^{3}}{\sqrt{\varepsilon}}\log(sk)\right\rparen.

Furthermore, if
j\in[m]
, then by Lemma
3.5
,

L\geq(1-\varepsilon)\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})\geq(1-\varepsilon)(1-8\varepsilon)\sigma_{j}(\mathbf{A})\geq(1-9\varepsilon)\sigma_{j}(\mathbf{A}).

For the upper bound, we use the rank
j
approximation
\mathbf{B}
obtained by running the randomized block Krylov algorithm of
[
MM15
]
on
\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}
. Note that

\sigma_{j}(\mathbf{A})=\min_{\text{rank $j$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{2}\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}

for any rank
j-1
matrix
\mathbf{B}
. By the results of
[
MM15
]
, we may compute an estimate
U
such that

(1+\varepsilon)\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}\geq U\geq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}

in time

O\left\lparen\frac{\nnz(\mathbf{A}-\mathbf{B})}{\sqrt{\varepsilon}}\right\rparen=O\left\lparen\frac{\nnz(\mathbf{A})+s^{2}k^{2}}{\sqrt{\varepsilon}}\right\rparen.

Furthermore, for
j\in[m]
, if we find a rank
j-1
matrix
\mathbf{B}
such that

\displaystyle\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle\leq\min_{\text{rank $j-1$ $\mathbf{C}$}}\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{C}\right\rVert_{F}^{2}+\varepsilon\sigma_{j}(\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T})^{2}

\displaystyle\leq\min_{\text{rank $j-1$ $\mathbf{C}$}}\left\lVert\mathbf{P}_{S}\mathbf{A}\mathbf{P}_{T}-\mathbf{C}\right\rVert_{F}^{2}+\varepsilon\sigma_{j}(\mathbf{A})^{2},

which we can by the results of
[
MM15
]
as before, then by Lemma
3.2
,

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{j-1}\right\rVert_{F}^{2}+9\varepsilon\sigma_{j}^{2}(\mathbf{A}).

By Lemma
3.1
, this implies that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{j-1}\right\rVert_{2}^{2}+9\varepsilon\sigma_{j}^{2}(\mathbf{A})=(1+9\varepsilon)\sigma_{j}^{2}(\mathbf{A}).\qed

We now show how to use the above result to efficiently find a
(1+\sqrt{\varepsilon})
factor approximation to
\sigma_{k+1}(\mathbf{A})
using binary search.

Lemma 3.8
.

There is a randomized algorithm that runs in time

O\left\lparen\frac{\nnz(\mathbf{A})+s^{2}k^{3}}{\sqrt{\varepsilon}}\log(sk)(\log k)\right\rparen

that finds a
(1+\sqrt{\varepsilon})
factor approximation to
\sigma_{k+1}(\mathbf{A})
.

Proof.

If
\sigma_{k}(\mathbf{A})\geq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
, then deflating off the top
k
components already gives a
(1+\varepsilon)
factor approximation to
\sigma_{k+1}(\mathbf{A})
. Otherwise, we proceed with binary search as follows.

Suppose we consider
j\in[k]
. If the upper and lower bounds for
\sigma_{j}(\mathbf{A})
in Lemma
3.7
are within a
(1+O(\varepsilon))
factor, then we know that
\sigma_{k+1}(\mathbf{A})
is smaller than this, up to a
(1\pm O(\varepsilon))
factor. On the other hand, if the upper and lower bounds for
\sigma_{j}(\mathbf{A})
are further than a
(1+O(\varepsilon))
factor, then
\sigma_{j}(\mathbf{A})\leq(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
, since otherwise the upper and lower bounds for
\sigma_{j}(\mathbf{A})
would have matched up to a
(1\pm O(\varepsilon))
factor by the second guarantee of Lemma
3.7
. Thus, we may use binary search over the at most
k
singular values in at most
O(\log k)
calls to the algorithm of Lemma
3.7
.
∎

3.4
Approximating Small Singular Values

With a
(1+\sqrt{\varepsilon})
factor approximation to
\sigma_{k+1}(\mathbf{A})
in hand, we now zoom into the singular values between
\sigma_{k+1}(\mathbf{A})
and
(1+\sqrt{\varepsilon})\sigma_{k+1}(\mathbf{A})
. We consider partitioning this
(1+\sqrt{\varepsilon})
factor window into
O(1/\sqrt{\varepsilon})
buckets that increase in powers of
(1+\varepsilon)
, that is

L,L(1+\varepsilon),L(1+\varepsilon)^{2},L(1+\varepsilon)^{3},\dots,L(1+\varepsilon)^{O(1/\sqrt{\varepsilon})}=(1+\sqrt{\varepsilon})L

where
L
is a lower bound on
\sigma_{k+1}(\mathbf{A})
, up to a
(1+\sqrt{\varepsilon})
factor. Our idea now is to simply enumerate over these
O(1/\sqrt{\varepsilon})
guesses to a
(1\pm\varepsilon)
-approximation of
\sigma_{k+1}(\mathbf{A})
, and then choose the best result.

With only a
(1+\varepsilon)
factor gap in the singular values, using power method as before will require roughly (ignoring log factors)
1/\varepsilon
iterations, which takes time roughly
\nnz(\mathbf{A})/\varepsilon
to separate out the singular components, which is above our target budget. However, using Chebyshev polynomials, it is known that a
(1+\varepsilon)
factor gap in the singular values can be separated with only roughly
1/\sqrt{\varepsilon}
iterations
[
MM15
]
which takes time only
\nnz(\mathbf{A})/\sqrt{\varepsilon}
. The main lemma for this technique is the following:

Lemma 3.9

(Lemma 5,
[
MM15
]
)
.

Given a specified value
\alpha>0
, gap
\gamma\in(0,1]
, and
q\geq 1
, there exists a degree
q
polynomial
p(x)
such that:

1.

p((1+\gamma)\alpha)=(1+\gamma)\alpha

2.

p(x)\geq x
for all
x\geq(1+\gamma)\alpha

3.

\lvert p(x)\rvert\leq\frac{\alpha}{2^{q\sqrt{\gamma}-1}}
for all
x\in[0,\alpha]

Furthermore, when q is odd, the polynomial only contains odd powered monomials.

In words, the above lemma states that there is a polynomial that “jumps” by a factor of
2^{q\sqrt{\gamma}-1}
in a window of size
(1+\gamma)
at a specified location
\alpha
. The difference between this lemma and our power method analysis from before is that we must specify the location of our “jump”,
\alpha
, in order to use the above polynomial in the Krylov method, whereas in the power method, the polynomial
p(x)=x^{q}
had the “jump” property at any location
\alpha
. Thus, in order to use the above lemma, we must
first
specify our jump location
\alpha
, and then proceed with our previous techniques.

Our procedure is thus as follows. We first compute Krylov iterates
(\mathbf{A}\mathbf{A}^{\top})^{i}\mathbf{A}\mathbf{g}
for
i\in[q]
, where
\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{d})
and

q=O\left\lparen\frac{1}{\sqrt{\varepsilon}}\log\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen.

We then proceed with our enumeration procedure. We guess a bucket
\alpha=L(1+\varepsilon)^{t}
for some
t\in[O(1/\sqrt{\varepsilon})]
, and then consider the degree
q
polynomial
p_{\alpha}(x)
that jumps by a
2^{q\sqrt{\varepsilon}-1}
factor at
\alpha
by Lemma
3.9
. Then, we may compute the vector
\mathbf{U}p_{\alpha}(\boldsymbol{\Sigma})\mathbf{V}^{\top}\mathbf{g}
as a linear combination of the Krylov iterates

(\mathbf{A}\mathbf{A}^{\top})^{i}\mathbf{A}\mathbf{g}=\mathbf{U}\boldsymbol{\Sigma}^{2i+1}\mathbf{V}^{\top}\mathbf{g}

where the coefficients of the linear combination are the coefficients of the polynomial
p_{\alpha}
. Next, we take the top
sk
entries of
\mathbf{U}p_{\alpha}(\boldsymbol{\Sigma})\mathbf{V}^{\top}\mathbf{g}
as sets
S_{\alpha}
and
T_{\alpha}
, combine them with the
sk
entries
S
and
T
obtained earlier by the power method, and then take our new subset of entries to be

\displaystyle S^{\prime}\coloneqq S\cup\bigcup_{\alpha}S_{\alpha}

\displaystyle T^{\prime}\coloneqq T\cup\bigcup_{\alpha}T_{\alpha}

Finally we compute a rank
k
matrix
\mathbf{B}
such that

\left\lVert\mathbf{P}_{S^{\prime}}\mathbf{A}\mathbf{P}_{T^{\prime}}-\mathbf{B}\right\rVert_{F}^{2}\leq\min_{\text{rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{P}_{S^{\prime}}\mathbf{A}\mathbf{P}_{T^{\prime}}-\mathbf{C}\right\rVert_{F}^{2}+\varepsilon\sigma_{k+1}^{2}(\mathbf{P}_{S^{\prime}}\mathbf{A}\mathbf{P}_{T^{\prime}})

using the results of
[
MM15
]
.

Note that if the
\alpha
we choose satisfies
\alpha\in[\sigma_{k+1}(\mathbf{A}),(1+\varepsilon)\sigma_{k+1}(\mathbf{A})]
, then all singular values
j
that are at least a
(1+\varepsilon)
factor larger than
\alpha
and at most
\Theta(1)\sigma_{k+1}(\mathbf{A})
are scaled by at least a factor of

2^{q\sqrt{\varepsilon}-1}=\Theta\left\lparen\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen=\Theta\left\lparen\frac{sk^{2}\sqrt{sr\log n}}{\varepsilon}\right\rparen\frac{\sigma_{j}}{\sigma_{k+1}}=\Theta\left\lparen\frac{sk\sqrt{\log n}}{\tau_{j}}\right\rparen,

which means we may recover all coordinates of the
j
th singular vectors that are at least
\tau_{j}
for these singular values, as done in the analyses in Section
3.2
. Thus, we have that

\displaystyle\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{l}\right\rVert_{2}^{2}+8\varepsilon\sigma_{l+1}^{2}(\mathbf{A})+\varepsilon\sigma_{l+1}^{2}(\mathbf{P}_{S^{\prime}}\mathbf{A}\mathbf{P}_{T^{\prime}})

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{l}\right\rVert_{2}^{2}+9\varepsilon\sigma_{l+1}^{2}(\mathbf{A})

\displaystyle=(1+9\varepsilon)\sigma_{l+1}^{2}(\mathbf{A})

\displaystyle\leq(1+9\varepsilon)(1+\varepsilon)\sigma_{k+1}^{2}(\mathbf{A})

\displaystyle\leq(1+11\varepsilon)\sigma_{k+1}^{2}(\mathbf{A})

by Lemma
3.2
, where
l\in[k]
is such that
\sigma_{k+1}^{2}(\mathbf{A})\leq\sigma_{l+1}^{2}(\mathbf{A})\leq(1+\varepsilon)\sigma_{k+1}^{2}(\mathbf{A})
.

The initial computation of the Krylov iterates takes time

O(\nnz(\mathbf{A})q)=O\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}\log\frac{srk\log n}{\varepsilon}\right\rparen

and a single guess of
\alpha
takes time

O\left\lparen nq\right\rparen=O\left\lparen\frac{n}{\sqrt{\varepsilon}}\log\frac{srk\log n}{\varepsilon}\right\rparen

which we repeat
O(1/\sqrt{\varepsilon})
times, so the total running time in this section is

O\left\lparen\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}+\frac{n}{\varepsilon}\right\rparen\log\frac{srk\log n}{\varepsilon}\right\rparen.

We then additionally run an approximate SVD using Theorem
1.11
on the
O(sk/\sqrt{\varepsilon})\times O(sk/\sqrt{\varepsilon})
matrix, which adds an
s^{2}k^{3}(\log(sk))/\varepsilon^{3/2}
term, for a running time of

O\left\lparen\left\lparen\frac{\nnz(\mathbf{A})}{\sqrt{\varepsilon}}+\frac{n}{\varepsilon}\right\rparen\log\frac{srk\log n}{\varepsilon}+\frac{s^{2}k^{3}}{\varepsilon^{3/2}}\log(sk)\right\rparen.

This dominates the running times of the previous steps and thus is the running time of our entire algorithm.

4
Frobenius Sparse Low Rank Approximation

We now switch to discussing sparse low rank approximation with no assumptions on the input matrix, in the Frobenius norm, in the streaming setting.

4.1
Algorithms

4.1.1
Exponential Time Algorithms for Sparse Output

Our first result is a naïve exponential time algorithm which iterates over an
\varepsilon
-net to find a good
s\times s
sparse rank
k
approximation, taking time roughly
\exp(O(sk\log n))
and only
O(sk(\log n)/\varepsilon^{2})
sketching dimensions. In order to make our net argument, we will assume for this section that the
\tau_{i}
in Definition
1.1
are bounded by
\tau_{i}\leq\poly(n)
, to support Corollary
2.3
. The exponential dependence on
s
and
k
is necessary, as we show later in Section
4.2
. The sketch is just a Gaussian matrix, and the analysis of the algorithm follows from Gordon’s theorem, which is a dimensionality reduction result which shows the preservation of norms of sets under random projections, when the target dimension scales with the
Gaussian width
of the set.

Definition 4.1

(Gaussian width)
.

The
Gaussian width
of a subset
S\subset\mathbb{R}^{n}
is defined as

w(S)\coloneqq\E_{\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{n})}\left[\sup_{\mathbf{x}\in S}\left\langle\mathbf{g},\mathbf{x}\right\rangle\right].

Gordon’s theorem essentially states that a random projection to approximately

\frac{1}{\varepsilon^{2}}\left\lparen w(S)^{2}+\log\frac{1}{\delta}\right\rparen

dimensions suffices to preserve the norms of all points in
S
, with probability at least
1-\delta
.

Theorem 4.2

(Gordon’s Theorem (Theorem 9.11,
[
BSS20
]
))
.

Let
\mathbf{G}\sim\mathcal{N}(0,1)^{m\times d}
and let
S\subseteq\mathbb{S}^{d-1}
be a closed subset of the
d
-dimensional unit sphere. Let

a_{m}\coloneqq\E_{\mathbf{g}\sim\mathcal{N}(0,\mathbf{I}_{m})}\lVert\mathbf{g}\rVert_{2}=\Theta(\sqrt{m}).

Then for
\varepsilon>\sqrt{w(S)^{2}/a_{m}^{2}}
,

\Pr\left\{(1-\varepsilon)\lVert\mathbf{x}\rVert_{2}\leq\frac{1}{a_{m}}\lVert\mathbf{G}\mathbf{x}\rVert_{2}\leq(1+\varepsilon)\lVert\mathbf{x}\rVert_{2},\forall\mathbf{x}\in S\right\}\geq 1-2\exp\left\lparen-\left\lparen\varepsilon-\frac{w(S)}{a_{m}}\right\rparen^{2}m\right\rparen.

The use of Gordon’s theorem for low rank matrix recovery is standard, see e.g.
[
Ver15
]
. We show that this technique can be used for sparse low rank matrix approximation as well, by setting the failure rate
\delta
to
\binom{n}{s}^{-2}
and then iterating over all
s\times s
submatrices of
\mathbf{A}
.

Theorem 4.3
.

There is a randomized sketching algorithm which solves the Frobenius sparse low rank approximation with

O\left\lparen\frac{sk}{\varepsilon^{2}}\log\frac{n}{s}\right\rparen

measurements and takes time

(\poly(n)k/\varepsilon)^{sk}

to output a
\mathbf{D}\in\mathcal{S}_{s,k}
such that

\lVert\mathbf{A}-\mathbf{D}\rVert_{F}^{2}\leq(1+\varepsilon)\min_{\mathbf{C}\in\mathcal{S}_{s,k}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}.

Proof.

Note that we may write the objective as

\min_{\text{$s\times s$ sparse rank $k$ $\mathbf{C}$}}\lVert\mathbf{A}-\mathbf{C}\rVert_{F}^{2}=\min_{S,T\in\binom{[n]}{s}\times\binom{[n]}{s}}\min_{\text{rank $k$ $\mathbf{C}$}}\lVert\mathbf{A}|_{S\times T}-\mathbf{C}\rVert_{F}^{2}

where
\mathbf{A}|_{S\times T}
denotes the restriction of
\mathbf{A}
to the submatrix indexed by coordinates
S\times T
.

By
[
Ver15
, Proposition 10.4]
, the Gaussian mean width of the set

D=\left\{\mathbf{X}\in\mathbb{R}^{s\times s}:\lVert\mathbf{X}\rVert_{F}^{2}=1,\rank(\mathbf{X})\leq k\right\}

is at most

w(D)\leq 4\sqrt{sk}.

We now fix
S,T\in\binom{[n]}{s}\times\binom{[n]}{s}
. Then by the translational invariance of Gaussian width
[
Ver15
, Proposition 3.5]
as well as the fact that padding zeros does not change the Gaussian width, we also have that
w(D^{\prime})\leq 4\sqrt{sk}
for the set

D^{\prime}=\left\{\mathbf{A}-\mathbf{X}\in\mathbb{R}^{n\times d}:\lVert\mathbf{X}\rVert_{F}^{2}=1,\rank(\mathbf{X})\leq k,\text{$\mathbf{X}$ supported on $S\times T$}\right\}.

Now let

m=\Omega\left\lparen\frac{1}{\varepsilon^{2}}\left\lparen w(D^{\prime})+\log\binom{n}{s}\right\rparen\right\rparen=\Omega\left\lparen\frac{sk}{\varepsilon^{2}}\log\frac{n}{s}\right\rparen.

Then by Gordon’s theorem (Theorem
4.2
), an
m\times s^{2}
Gaussian matrix
G\sim\mathcal{N}(0,1)^{m\times s^{2}}
will satisfy

\left\lVert\frac{1}{a_{m}}\mathbf{G}\vc(\mathbf{A}-\mathbf{X})\right\rVert_{2}^{2}=(1\pm\varepsilon)\lVert\mathbf{A}-\mathbf{X}\rVert_{F}^{2}

for all
\mathbf{X}
of rank at most
k
supported on
S\times T
, with probability at least
1-\binom{n}{s}^{-2}/200
. Thus, solving the problem

\min_{\mathbf{X}\in D}\left\lVert\frac{1}{a_{m}}\mathbf{G}\vc(\mathbf{A}-\mathbf{X})\right\rVert_{2}^{2}

provides a
(1+\varepsilon)
multiplicative error solution for

\min_{\mathbf{X}\in D}\lVert\mathbf{A}-\mathbf{X}\rVert_{F}^{2}

with probability at least
1-\binom{n}{s}^{-2}/200
. By a union bound, this holds for all
S,T\in\binom{[n]}{s}\times\binom{[n]}{s}
with probability at least
1-1/200
.

To solve the approximate minimization problem supported on
S\times T
, we simply iterate over an
\varepsilon
-net using Corollary
2.3
, which has size at most

(\poly(n)k/\varepsilon)^{sk}.\qed

4.1.2
Polynomial Time Bicriteria Algorithm with Relative Error

Although the above algorithm runs in exponential time, by our results in Section
4.2
, we cannot hope for polynomial time algorithms for the sparse low rank approximation problem. In order to find polynomial time algorithms, we relax our requirement of outputting an
s\times s
-sparse rank
k
matrix and instead allow for larger matrices.

As a warm-up to our more technically involved additive error bicriteria algorithm of Section
4.1.3
and Theorem
4.8
achieving roughly
\tilde{O}(sk^{2})
measurements, we prove a relative error algorithm achieving roughly
\tilde{O}(s^{2}k^{2})
measurements. More specifically, we show the following:

Theorem 4.4
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. There is a randomized sketching algorithm which makes

O\left\lparen\frac{s^{2}k^{2}}{\varepsilon^{4}}\log(nd)+\frac{sk}{\varepsilon}\log^{2}(nd)\right\rparen

measurements to
\mathbf{A}
and outputs a rank
k
matrix
\mathbf{D}
which is supported on an
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix such that

\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}\leq(1+\varepsilon)\min_{\mathbf{B}\in\mathcal{S}_{s,k}}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

in polynomial time.

Throughout this section, let
\mathbf{B}
denote any
s\times s
sparse rank
k
matrix. For our relative error polynomial time algorithm, our first observation is that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\geq\left\lVert\mathbf{A}_{\overline{[s^{2}k]}}\right\rVert_{F}^{2}

where
\mathbf{A}_{\overline{[s^{2}k]}}
is the matrix obtained by zeroing out the
s^{2}k
largest entries in absolute value from
\mathbf{A}
. We can similarly note that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}\geq\left\lVert\mathbf{A}_{\overline{[sk]},*}\right\rVert_{F}^{2}

where
\mathbf{A}_{\overline{[sk]},*}
denotes the matrix obtained by zeroing out the
sk
heaviest rows of
\mathbf{A}
, since
\mathbf{B}
is supported on at most
sk
rows. These tail guarantees are compatible with guarantees achievable efficiently in a stream using
CountSketch
(see Section
2.2
).

Our next observation is to note that a relative error solution is supported on the intersection of the rows and columns of
\mathbf{A}
with squared norm at least
\tau
, for

\tau=\frac{\varepsilon}{sk}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}^{2}\leq\frac{\varepsilon}{sk}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2},

since we miss at most
sk
rows of the optimal solution, and each of these will have squared norm at most
\tau
. This is formalized in the following lemma.

Lemma 4.5
.

Consider an
s\times s
-sparse rank
k
matrix

\mathbf{B}=\sum_{i=1}^{k}\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}

that minimizes
\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}
. Let
\tau>0
be a threshold parameter. Then, there exists a rank
k
matrix
\mathbf{D}
supported on the rows and columns of
\mathbf{A}
with norm at least
\tau
such that

\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+sk\tau.

Proof.

Let
W
be the support of an
sk\times sk
submatrix that contains
\mathbf{B}
, let
X\subseteq W
be the part of
W
contained in columns of
\mathbf{A}
with norm at most
\tau
, and let
W\setminus X
be the part of
W
contained in columns of
\mathbf{A}
with norm at least
\tau
(see Figure
1
).

\mathbf{B}
X
W\setminus X

:
The supports
W,X,W\setminus X
to be used in the proof.

Let
\mathbf{A}\mid_{W}
denote the matrix
\mathbf{A}
restricted to
W
, and similarly define
\mathbf{A}\mid_{X}
and
\mathbf{A}\mid_{W\setminus X}
. Then, by repeatedly using the Pythagorean theorem, we have that

\displaystyle\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-\mathbf{A}\mid_{W}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}\mid_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-\mathbf{A}\mid_{W\setminus X}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{X}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}\mid_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-\mathbf{A}\mid_{W\setminus X}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{X}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}\mid_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}

\displaystyle\hskip 30.00005pt+\left\lVert\mathbf{A}\mid_{W\setminus X}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{W\setminus X}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{X}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}\mid_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}

\displaystyle\hskip 30.00005pt-\left\lVert\mathbf{A}\mid_{W\setminus X}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}.

Note that if we restrict
(\mathbf{A}\mid_{W})_{k}
to
W\setminus X
, then this is a rank

and thus

\left\lVert\mathbf{A}\mid_{W\setminus X}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}\mid_{W\setminus X}-((\mathbf{A}\mid_{W})_{k})\mid_{W\setminus X}\right\rVert_{F}^{2}=\left\lVert(\mathbf{A}_{W}-(\mathbf{A}\mid_{W})_{k})\mid_{W\setminus X}\right\rVert_{F}^{2}.

Furthermore, we can remove the restriction to
W\setminus X
so that the above is bounded above by
\left\lVert\mathbf{A}_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}
, so

\left\lVert\mathbf{A}\mid_{W}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{W\setminus X}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}\geq 0.

We thus have that

\displaystyle\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}\geq\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}-\left\lVert\mathbf{A}\mid_{X}\right\rVert_{F}^{2}.

Rearranging and noting that

\left\lVert\mathbf{A}_{X}\right\rVert_{F}^{2}\leq sk\cdot\tau,

we have that

\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W})_{k}\right\rVert_{F}^{2}+sk\tau.

Finally, since
\mathbf{B}
is a rank
k
matrix supported on
W
, we have that

\left\lVert\mathbf{A}-(\mathbf{A}\mid_{W\setminus X})_{k}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+sk\tau.\qed

We set the parameter
\tau
in the above lemma to
\tau=\frac{\varepsilon}{sk}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}^{2}
, so that there exists a rank

solution
\mathbf{D}
such that

\displaystyle\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+sk\cdot\frac{\varepsilon}{sk}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle=(1+\varepsilon)\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

We can efficiently find such rows and columns using Lemma
2.7
:

Lemma 4.6
.

With

O\left\lparen\frac{sk}{\varepsilon}\log^{2}(nd)\right\rparen

measurements, one can find a set
S\subseteq[n]
of rows of size
O(sk/\varepsilon)
containing all
i\in[n]
such that

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}\geq\frac{\varepsilon}{sk}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}^{2}.

Proof.

We use Lemma
2.7
with
\varepsilon
in the lemma set to
\frac{\varepsilon}{100sk}
and
\alpha
set to
1/4
. Suppose row
i\in[n]
has norm at least

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}\geq\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}.

This requires only

O\left\lparen\frac{sk}{\varepsilon}\log^{2}(nd)\right\rparen

measurements to identify. Then,

\displaystyle\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}\right\rVert_{2}

\displaystyle\geq\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}-\frac{1}{4}\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}-\sqrt{\frac{5}{4}}\sqrt{\frac{\varepsilon}{100sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}

\displaystyle\geq\frac{5}{8}\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}.

On the other hand, if
\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}\right\rVert_{2}\geq\frac{5}{8}\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}
, then

\displaystyle\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}

\displaystyle\geq\frac{5}{8}\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}-\frac{1}{4}\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}-\sqrt{\frac{5}{4}}\sqrt{\frac{\varepsilon}{100sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}

\displaystyle\implies\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}

\displaystyle\geq\frac{2}{5}\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}.

Thus, by selecting all rows with

\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{A}\mathbf{G}^{\top}}\right\rVert_{2}\geq\frac{5}{8}\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F},

we select all rows with

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}\geq\sqrt{\frac{\varepsilon}{sk}}\left\lVert\mathbf{A}_{\overline{[sk/\varepsilon]},*}\right\rVert_{F}.

Furthermore, there are at most
\frac{25}{4}\frac{sk}{\varepsilon}
such rows belonging to
\mathbf{A}_{\overline{[sk/\varepsilon]},*}
and thus we select at most

\frac{25}{4}\frac{sk}{\varepsilon}+\frac{sk}{\varepsilon}=O\left\lparen\frac{sk}{\varepsilon}\right\rparen

rows of
\mathbf{A}
.
∎

Finally, we let
q=O(s^{2}k^{2}/\varepsilon^{4})
and let
r=\log(nd)
. We then treat
\mathbf{A}
as an
nd
-dimensional vector and use the tail error guarantee of
CountSketch
(Lemma
2.5
) in order to reconstruct a matrix
\hat{\mathbf{A}}
such that

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{\infty}^{2}\leq\frac{1}{q}\left\lVert\mathbf{A}_{\overline{[q]}}\right\rVert_{F}^{2}\leq\frac{\varepsilon^{4}}{s^{2}k^{2}}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}.

When restricted to the
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix
S\times T
of the heavy rows and columns identified before, we have that

\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}^{2}\leq O\left\lparen\frac{sk}{\varepsilon}\right\rparen^{2}\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{\infty}^{2}\leq\varepsilon^{2}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}.

This requires only

O\left\lparen\frac{s^{2}k^{2}}{\varepsilon^{4}}\log(nd)\right\rparen

measurements. We can then show that the optimal low rank approximation to
\hat{\mathbf{A}}\mid_{S\times T}
will give us a relative error sparse low rank approximation to
\mathbf{A}
.

Lemma 4.7
.

Let
S\subseteq[n]
and
T\subseteq[n]
be supersets of the rows and columns of
\mathbf{A}
that have squared norm at least

\tau=\frac{\varepsilon}{sk}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

and let
\hat{\mathbf{A}}
be a matrix such that

\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}^{2}\leq\varepsilon^{2}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

where for a matrix
\mathbf{M}
,
\mathbf{M}_{S\times T}
denotes the restriction of
\mathbf{M}
to the submatrix indexed by rows
S
and columns
T
. Then,

\left\lVert\mathbf{A}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}^{2}\leq(1+O(\varepsilon))\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}.

Proof.

We have that

\displaystyle\left\lVert\mathbf{A}\mid_{S\times T}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}

\displaystyle\leq\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}+\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}

\displaystyle\leq\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}+\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}+2\left\lVert\hat{\mathbf{A}}\mid_{S\times T}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}+2\varepsilon\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}

so by squaring both sides, we get

\displaystyle\left\lVert\mathbf{A}\mid_{S\times T}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}^{2}

\displaystyle\leq\left\lparen\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}+2\varepsilon\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}\right\rparen^{2}

\displaystyle=\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}^{2}+4\varepsilon\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}+4\varepsilon^{2}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}^{2}+4\varepsilon(1+\varepsilon)\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}+4\varepsilon^{2}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}^{2}+(4\varepsilon(1+\varepsilon)+4\varepsilon^{2})\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}\mid_{S\times T}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}^{2}+(4\varepsilon(1+\varepsilon)+4\varepsilon^{2})\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}.

Adding
\left\lVert\mathbf{A}-\mathbf{A}\mid_{S\times T}\right\rVert_{F}^{2}
on both sides and applying the Pythagorean theorem, we obtain

\left\lVert\mathbf{A}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-(\mathbf{A}\mid_{S\times T})_{k}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}.

Since
(\mathbf{A}\mid_{S\times T})_{k}
is the optimal matrix supported on the rows and column at least
\tau
, we have by Lemma
4.5
that

\displaystyle\left\lVert\mathbf{A}-(\hat{\mathbf{A}}\mid_{S\times T})_{k}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

\displaystyle=(1+O(\varepsilon))\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}

as desired.
∎

4.1.3
Polynomial Time Bicriteria Algorithm with Additive Error

The previous polynomial time relative error algorithm has a quadratic dependence on both
s
and
k
, whereas a linear dependence is possible if we allow for exponential time algorithms. A natural question is whether these can be improved to linear or not. The quadratic dependencies can be attributed to the tail error guarantee we seek from every entry on our
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix that contains an approximately optimal solution, which was used to compute an SVD. If we change our approximate SVD approach to be based on sampling rows of this submatrix, then we would require a tail error guarantee on fewer entries, and thus should lead to better upper bounds. This leads to the idea of implementing the
[
FKV04
]

\ell_{2}
sampling
approach to approximate SVD in this setting. This approximate SVD subroutine gives additive error guarantees rather than the stronger relative error guarantees in the previous section. However, with this relaxation, we are able to improve the quadratic dependence on
s
to linear. In this section, we prove the following theorem:

Theorem 4.8
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. There is a randomized sketching algorithm which makes

O\left\lparen\frac{sk^{2}}{\varepsilon^{6}}\log^{2}n\right\rparen

measurements to
\mathbf{A}
and outputs a rank
k
matrix
\mathbf{D}
supported on an
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix such that

\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}\leq\min_{\mathbf{B}\in\mathcal{S}_{s,k}}\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}

in polynomial time.

Remark 4.9
.

If we optimize over only rank
k
matrices that are supported on an
s\times s
submatrix rather than sums of
k

s\times s
matrices, then by making small adjustments to our argument, we can show that we use only

O\left\lparen\frac{sk}{\varepsilon^{6}}\log^{2}n\right\rparen=sk\poly(\log n,\varepsilon^{-1})

measurements, i.e., linear in both
s
and
k
, which is the correct dependence on
s
and
k
.

Our algorithm roughly proceeds in the same way as the previous one: by identifying
O(sk/\varepsilon)
heavy rows and columns that contain an additive error rank
k
approximation to
\mathbf{A}
, and then performing an approximate SVD on this
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix. The difference is that the approximate SVD will be replaced by the
[
FKV04
]
routine which samples rows proportional to their
\ell_{2}
norms.

Note that näively, the
[
FKV04
]
algorithm is implemented in two passes over a stream
[
DKM06
]
: one pass to compute the
\ell_{2}
norms of the rows, and one pass to obtain the sample of the rows. We now show the intuition for conducting this sampling in one pass. The work of
[
MRWZ20
]
recently implemented
subspace sampling
, a seemingly even more sequential sampling scheme, in one pass over a stream, and includes
\ell_{2}
sampling as a special case. We show an alternate one pass implementation for
\ell_{2}
sampling.

Our idea is to switch the
\ell_{2}
norm computation step and then sampling step. That is, we first obtain a sample of rows each sampled with probability
p
, and then later restrict to the rows of the sample with
\ell_{2}
norm
\Theta(p\left\lVert\mathbf{A}\right\rVert_{F}^{2})
. By running this procedure in parallel for geometrically decreasing values of
p
, say
p=1,1/2,1/4,\dots,1/n
, we obtain an
[
FKV04
]
sample. The advantage of this approach is that by sampling first, we need to approximate fewer values of the matrix, which improves our upper bounds.

Approximate
\ell_{2}
Sampling of Rows.

By setting

\tau=\frac{\varepsilon}{sk}\left\lVert\mathbf{A}\right\rVert_{F}^{2}

in Lemma
4.5
, we see that an additive error solution is supported in the
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix at the intersection of the rows and columns with
\ell_{2}
norm at least
\tau
. Let these rows and columns be indexed by
S\subseteq[n]
and
T\subseteq[d]
, respectively. Then, Lemma
2.7
allows us to find the subset of coordinates
S
and
T
. Next, we discuss how to approximately find a rank
k
projection
\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}
that is supported on these coordinates
S
and
T
. Our strategy is to obtain approximations to the rows of
\mathbf{A}
that are sampled proportionally to their

norm, formalized in the following definition.

Definition 4.10

(
\ell_{2}
sampling
[
FKV04
]
)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. Then,
P
is a
c

\ell_{2}

P_{i}\geq\min\left\{c\frac{\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}}{\left\lVert\mathbf{A}\right\rVert_{F}^{2}},1\right\}

i\in[n]
.

It is known that a
\Theta(k/\varepsilon^{2})
-approximate
\ell_{2}
sample of the rows of
\mathbf{A}
yields additive low rank approximations, which we seek
[
DKM06

Theorem 4.11

(
LinearTimeSVD

[
DKM06
]
)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. Then, there is an algorithm that samples rows from a
\Theta(k/\varepsilon^{2})
-approximate
\ell_{2}
distribution and outputs a matrix
\mathbf{Z}\in\mathbb{R}^{d\times k}
with orthogonal columns such that

\left\lVert\mathbf{A}-\mathbf{A}\mathbf{Z}\mathbf{Z}^{\top}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Before we proceed with the sampling result, we show several lemmas that allow us to reduce the task of obtaining an additive rank
k

\mathbf{A}
to obtaining an additive rank
k
approximation to a surrogate matrix
\hat{\mathbf{A}}
that is close to
\mathbf{A}
in Frobenius norm.

Our first lemma shows that if
\hat{\mathbf{A}}
is close to
\mathbf{A}
in Frobenius norm and
\hat{\mathbf{A}}\hat{\mathbf{V}}\mathbf{V}^{\top}
is a good rank

is also a good rank

\mathbf{A}

Lemma 4.12
.

Let
\hat{\mathbf{V}}\mathbf{V}^{\top}
be a rank
k
projection and let
\hat{\mathbf{A}}
be such that

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}^{2}\leq\delta.

Then,

\left\lVert\mathbf{A}-\mathbf{A}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}+\delta+2\sqrt{\delta}\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}.

Proof.

\displaystyle\left\lVert\mathbf{A}-\mathbf{A}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}

\displaystyle\leq\left\lparen\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}+\left\lVert\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}-\mathbf{A}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}\right\rparen^{2}

\displaystyle=\left\lparen\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}+\left\lVert(\hat{\mathbf{A}}-\mathbf{A})\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}\right\rparen^{2}

\displaystyle\leq\left\lparen\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}+\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}\right\rparen^{2}

\displaystyle=\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}+\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}^{2}+2\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}+\delta+2\sqrt{\delta}\left\lVert\mathbf{A}-\hat{\mathbf{A}}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}

∎

Our second lemma shows that if
\hat{\mathbf{A}}
and
\mathbf{A}
are close in Frobenius norm, then a good additive error low rank approximation of
\hat{\mathbf{A}}
is a good additive error low rank approximation of
\mathbf{A}
.

Lemma 4.13
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
and let
\hat{\mathbf{A}}
be such that

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}^{2}\leq\delta.

Let
\mathbf{D}
be a rank
k
matrix such that

\left\lVert\hat{\mathbf{A}}-\mathbf{D}\right\rVert_{F}^{2}\leq\left\lVert\hat{\mathbf{A}}-\hat{\mathbf{A}}_{k}\right\rVert_{F}^{2}+\eta.

Then,

\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+2\sqrt{\delta}\left\lVert\mathbf{A}\right\rVert_{F}+2\delta+\eta+2\sqrt{\delta\left\lparen 2\delta+2\left\lVert\mathbf{A}\right\rVert_{F}^{2}+\eta\right\rparen}.

Proof.

We first estimate

\displaystyle\left\lVert\hat{\mathbf{A}}-\mathbf{A}_{k}\right\rVert_{F}^{2}

\displaystyle\leq\left\lparen\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}

by triangle inequality

\displaystyle\leq\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}

Then, we can bound

\displaystyle\left\lVert\mathbf{A}-\mathbf{D}\right\rVert_{F}^{2}

\displaystyle\leq\left\lparen\left\lVert\mathbf{A}-\hat{\mathbf{A}}\right\rVert_{F}+\left\lVert\hat{\mathbf{A}}-\mathbf{D}\right\rVert_{F}\right\rparen^{2}

\displaystyle\leq\left\lparen\left\lVert\mathbf{A}-\hat{\mathbf{A}}\right\rVert_{F}+\sqrt{\left\lVert\hat{\mathbf{A}}-\mathbf{A}_{k}\right\rVert_{F}^{2}+\eta}\right\rparen^{2}

\displaystyle\leq\left\lparen\sqrt{\delta}+\sqrt{\left\lVert\hat{\mathbf{A}}-\mathbf{A}_{k}\right\rVert_{F}^{2}+\eta}\right\rparen^{2}

\displaystyle\leq\left\lparen\sqrt{\delta}+\sqrt{\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}+\eta}\right\rparen^{2}

\displaystyle=\delta+\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}+\eta+2\sqrt{\delta\left\lparen\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}+\eta\right\rparen}

\displaystyle\leq\delta+\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}+\eta+2\sqrt{\delta\left\lparen 2\delta+2\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+\eta\right\rparen}

\displaystyle\leq\delta+\left\lparen\sqrt{\delta}+\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}\right\rparen^{2}+\eta+2\sqrt{\delta\left\lparen 2\delta+2\left\lVert\mathbf{A}\right\rVert_{F}^{2}+\eta\right\rparen}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{A}_{k}\right\rVert_{F}^{2}+2\sqrt{\delta}\left\lVert\mathbf{A}\right\rVert_{F}+2\delta+\eta+2\sqrt{\delta\left\lparen 2\delta+2\left\lVert\mathbf{A}\right\rVert_{F}^{2}+\eta\right\rparen}.\qed

Finally, we show that an
\ell_{2}
norm approximation of the rows of
\mathbf{A}
implies a Frobenius norm approximation of
\mathbf{A}
.

Lemma 4.14
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
and let
\hat{\mathbf{A}}
be such that for every

,

\left\lVert\mathbf{e}_{i}^{\top}\hat{\mathbf{A}}-\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}\leq\varepsilon\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{F}^{2}.

Then

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}^{2}\leq\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}

Proof.

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{F}^{2}=\sum_{i=1}^{n}\left\lVert\mathbf{e}_{i}^{\top}\hat{\mathbf{A}}-\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{2}^{2}\leq\sum_{i=1}^{n}\varepsilon\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\right\rVert_{F}^{2}\leq\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}\qed

Outputting a Good Sparse Projection.

By setting
\tau
in Lemma
4.5
to
(\varepsilon/sk)\left\lVert\mathbf{A}\right\rVert_{F}^{2}
, we may identify an
O(sk/\varepsilon)\times O(sk/\varepsilon)
submatrix that contains a good additive error

-sparse rank

low rank approximation to
\mathbf{A}
using

O\left\lparen\frac{sk}{\varepsilon}\log n\right\rparen

S
and

be the indices of the

heavy rows and columns, and let
\mathbf{A}_{S\times T}
denote the

and

[

,

Note that if
\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}<\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}

\displaystyle\left\lVert\mathbf{A}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{A}-\mathbf{A}_{S\times T}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{A}_{S\times T}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}

If we conduct the

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}_{S\times T}\right\rVert_{2}^{2}\geq\Omega\left\lparen\frac{\varepsilon^{2}}{k}\right\rparen\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

Suppose that we view
\mathbf{A}
as a vector and attempt to reconstruct

using

\left\lVert\hat{\mathbf{A}}-\mathbf{A}\right\rVert_{\infty}^{2}\leq\frac{\varepsilon^{6}}{sk^{2}}\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

For row

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}_{S\times T}\right\rVert_{2}^{2}\geq\Omega\left\lparen\alpha\frac{\varepsilon^{2}}{k}\right\rparen\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}\geq\Omega\left\lparen\alpha\frac{\varepsilon^{3}}{k}\right\rparen\left\lVert\mathbf{A}\right\rVert_{F}^{2},

\E\left\lVert\mathbf{P}_{W}\mathbf{A}\right\rVert_{F}^{2}=\alpha\left\lVert\mathbf{A}\right\rVert_{F}^{2}
, and at most

\left\lVert\mathbf{P}_{W}\mathbf{A}\right\rVert_{F}^{2}\leq O\left\lparen\alpha\log\frac{n}{\varepsilon}\right\rparen\left\lVert\mathbf{A}\right\rVert_{F}^{2}

with probability at least
1-O(1/\log(n/\varepsilon))
. Then again treating this subsampled matrix as a vector, we may reconstruct this submatrix using
CountSketch
with
O(sk^{2}\log(n/\varepsilon)/\varepsilon^{6})
buckets to recover an approximation
\widehat{\mathbf{P}_{W}\mathbf{A}}
such that

\left\lVert\widehat{\mathbf{P}_{W}\mathbf{A}}-\mathbf{P}_{W}\mathbf{A}\right\rVert_{\infty}^{2}\leq\frac{\varepsilon^{6}}{sk^{2}\log(n/\varepsilon)}\left\lVert\mathbf{P}_{W}\mathbf{A}\right\rVert_{F}^{2}=O(\alpha)\frac{\varepsilon^{6}}{sk^{2}}\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Then for this row
i
, if sampled, the error over the
O(sk/\varepsilon)
coordinates of the row is at most

\left\lVert\mathbf{e}_{i}^{\top}\widehat{\mathbf{P}_{W}\mathbf{A}_{S\times T}}-\mathbf{e}_{i}^{\top}\mathbf{P}_{W}\mathbf{A}_{S\times T}\right\rVert_{2}^{2}\leq O\left\lparen\frac{sk}{\varepsilon}\right\rparen\cdot O(\alpha)\frac{\varepsilon^{6}}{sk^{2}}\left\lVert\mathbf{A}\right\rVert_{F}^{2}\leq O\left\lparen\alpha\frac{\varepsilon^{5}}{k}\right\rparen\leq\varepsilon^{2}\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}_{S\times T}\right\rVert_{2}^{2}

with probability at least
1-O(1/\log(n/\varepsilon))
. By a union bound over all
O(\log(n/\varepsilon))
sampling levels for
\alpha=1,1/2,1/4,1/8,\dots,\varepsilon^{2}/n^{2}
, this is true for all of these sampling levels with constant probability.

Thus, we may obtain a
\Theta(k/\varepsilon^{2})
-approximate
\ell_{2}
sample of some matrix
\hat{\mathbf{A}}_{S\times T}
that satisfies

\left\lVert\mathbf{e}_{i}^{\top}\hat{\mathbf{A}}_{S\times T}-\mathbf{e}_{i}^{\top}\mathbf{A}_{S\times T}\right\rVert_{2}^{2}\leq\varepsilon^{2}\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}_{S\times T}\right\rVert_{2}^{2},

where by Lemma
4.14
,
\left\lVert\hat{\mathbf{A}}_{S\times T}-\mathbf{A}_{S\times T}\right\rVert_{F}^{2}\leq\varepsilon^{2}\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}
. Now let
\hat{\mathbf{C}}_{S\times T}
be the rows sampled from
\hat{\mathbf{A}}_{S\times T}
and let
\hat{\mathbf{V}}
be the
\Theta(sk/\varepsilon)\times k
matrix of the top
k
right singular vectors of
\hat{\mathbf{C}}_{S\times T}
. Then by
[
DKM06
, Theorem 2]
, we have that

\left\lVert\hat{\mathbf{A}}_{S\times T}-\hat{\mathbf{A}}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}\leq\left\lVert\hat{\mathbf{A}}_{S\times T}-(\hat{\mathbf{A}}_{S\times T})_{k}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

Then by Lemma
4.13
,

\displaystyle\left\lVert\mathbf{A}_{S\times T}-\hat{\mathbf{A}}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}_{S\times T}-(\mathbf{A}_{S\times T})_{k}\right\rVert_{F}^{2}+(3\varepsilon+\varepsilon^{2}+\varepsilon\sqrt{2+\varepsilon+2\varepsilon^{2}})\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}_{S\times T}-(\mathbf{A}_{S\times T})_{k}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

and thus by Lemma
4.12
,

\left\lVert\mathbf{A}_{S\times T}-\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}_{S\times T}-(\mathbf{A}_{S\times T})_{k}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

as well.

We now add back the squared Frobenius mass of the entries outside of the
S\times T
submatrix, i.e.,
\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\mathbf{S}_{T}\right\rVert_{F}^{2}
. Adding
\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\mathbf{S}_{T}\right\rVert_{F}^{2}
on both sides, we have that

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\mathbf{S}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}_{S\times T}-\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}=\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}

and

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\mathbf{S}_{T}\right\rVert_{F}^{2}+\left\lVert\mathbf{A}_{S\times T}-(\mathbf{A}_{S\times T})_{k}\right\rVert_{F}^{2}=\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}(\mathbf{A}_{S\times T})_{k}\mathbf{S}_{T}\right\rVert_{F}^{2}

which shows that

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}(\mathbf{A}_{S\times T})_{k}\mathbf{S}_{T}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}.

Note then that

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}(\mathbf{A}_{S\times T})_{k}\mathbf{S}_{T}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}-\hat{\mathbf{B}}\right\rVert_{F}^{2}

where
\hat{\mathbf{B}}
keeps only the columns of an optimal
s\times s
-sparse rank
k

\mathbf{B}
with
\ell_{2}
norm at least
(\varepsilon^{2}/sk)\left\lVert\mathbf{A}\right\rVert_{F}^{2}
, and

\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}\leq\left\lVert\mathbf{A}\right\rVert_{F}^{2},

so by combining the above bounds,

\displaystyle\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}(\mathbf{A}_{S\times T})_{k}\mathbf{S}_{T}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}_{S\times T}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}(\mathbf{A}_{S\times T})_{k}\mathbf{S}_{T}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}\right\rVert_{F}^{2}

\displaystyle\leq\left\lVert\mathbf{A}-\hat{\mathbf{B}}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}\right\rVert_{F}^{2}

\displaystyle\leq\min_{\text{$s\times s$-sparse rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

By rescaling
\varepsilon
by a constant factor, we conclude that

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}\leq\min_{\text{$s\times s$-sparse rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}^{2}

as desired.

Outputting a Good Factorization.

Given the above result, we have coordinate projections down to a submatrix supported on
S\times T
, with
S
and
T
each of size
O(sk/\varepsilon)
, and a rank
k
right projection for this submatrix. Our final task is to obtain an actual
O(sk/\varepsilon)\times O(sk/\varepsilon)
matrix, rather than just a right factor.

Recall the current form of our sparse low rank approximation:

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{A}_{S\times T}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}=\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{S}_{S}\mathbf{A}\mathbf{P}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}^{2}.

Note that here, we have
S,T
, and
\hat{\mathbf{V}}
, but we don’t have all of the entries of
\mathbf{A}_{S\times T}
. We first use approximate matrix product (Lemma
2.8
) to approximate
\mathbf{A}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}
by
\mathbf{A}\mathbf{R}^{\top}\mathbf{R}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}
, where
\mathbf{R}
is an
O(k/\varepsilon^{2})\times n

CountSketch
matrix. By applying Lemma
2.8
with
\varepsilon
in the lemma set to
\varepsilon/\sqrt{k}
, we have that

\left\lVert\mathbf{A}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}-\mathbf{A}\mathbf{R}^{\top}\mathbf{R}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}\leq\frac{\varepsilon^{2}}{k}\left\lVert\mathbf{A}\right\rVert_{F}^{2}\left\lVert\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}=\frac{\varepsilon^{2}}{k}\cdot\left\lVert\mathbf{A}\right\rVert_{F}^{2}\cdot k=\varepsilon^{2}\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Next, suppose that
\mathbf{T}^{(1)},\mathbf{T}^{(2)},\dots,\mathbf{T}^{(r)}
are
(sk/\varepsilon^{3})\times n

CountSketch
matrices for
r=O(\log(nsk/\varepsilon))
. Then, by applying row-wise approximation (Lemma
2.6
) with
\varepsilon
in the lemma set to
\varepsilon^{3}/sk
and
d
to
O(sk/\varepsilon)
, if we maintain
\mathbf{T}^{(j)}\mathbf{A}\mathbf{R}^{\top}
for
j\in[r]
, from which we can compute

\mathbf{T}^{(j)}\mathbf{A}\mathbf{R}^{\top}\mathbf{R}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top},

for every
i\in[n]
, we can compute an approximate row
\mathbf{w}^{(i)}
such that

\left\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\mathbf{R}^{\top}\mathbf{R}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}-\mathbf{w}^{(i)}\right\rVert_{2}^{2}\leq\frac{\varepsilon^{3}}{sk}\left\lVert\mathbf{A}\mathbf{R}^{\top}\mathbf{R}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}.

Note that

\displaystyle\left\lVert\mathbf{A}\mathbf{S}_{T}^{\top}\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}+\left\lVert\mathbf{A}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}-\mathbf{A}\mathbf{S}_{T}^{\top}\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}\right\rVert_{F}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}

\displaystyle=(1+\varepsilon)\left\lVert\mathbf{A}\right\rVert_{F}

so

\frac{\varepsilon^{3}}{sk}\left\lVert\mathbf{A}\mathbf{S}_{T}^{\top}\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\right\rVert_{F}^{2}\leq O\left\lparen\frac{\varepsilon^{3}}{sk}\right\rparen\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Thus, summing over the
O(sk/\varepsilon)
rows in
S
, and letting
\mathbf{W}
be the matrix corresponding to the approximate rows
\mathbf{w}^{(i)}
for
i\in S
,

\left\lVert\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}-\mathbf{W}\right\rVert_{F}^{2}\leq O\left\lparen\frac{sk}{\varepsilon}\right\rparen\frac{\varepsilon^{3}}{sk}\left\lVert\mathbf{A}\right\rVert_{F}^{2}=\varepsilon^{2}\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Then by a couple of applications of the triangle inequality,

\displaystyle\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{W}\mathbf{S}_{T}^{\top}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\mathbf{R}^{\top}\mathbf{R}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}+\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}

\displaystyle\leq\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\hat{\mathbf{V}}\hat{\mathbf{V}}^{\top}\mathbf{S}_{T}\right\rVert_{F}+2\varepsilon\left\lVert\mathbf{A}\right\rVert_{F}

so

\left\lVert\mathbf{A}-\mathbf{S}_{S}^{\top}\mathbf{W}\mathbf{S}_{T}\right\rVert_{F}^{2}\leq\min_{\text{$s\times s$-sparse rank $k$ $\mathbf{C}$}}\left\lVert\mathbf{A}-\mathbf{C}\right\rVert_{F}^{2}+O(\varepsilon)\left\lVert\mathbf{A}\right\rVert_{F}^{2}

as desired.

To implement the above, we must maintain
\mathbf{T}^{(j)}\mathbf{A}\mathbf{R}^{\top}
for
j\in[r]
, which requires

O\left\lparen\frac{sk}{\varepsilon^{3}}\right\rparen\cdot O\left\lparen\frac{k}{\varepsilon^{2}}\right\rparen\cdot\log\frac{nsk}{\varepsilon}=O\left\lparen\frac{sk^{2}}{\varepsilon^{5}}\log\frac{nsk}{\varepsilon}\right\rparen

which is within our measurement budget.

4.2
Computational Complexity

In this section, we show that under a randomized version of the Exponential Time Hypothesis, the
(1+\varepsilon)
-approximate Frobenius sparse low rank approximation problem has no algorithm running in time

f(s)\left\lparen\frac{1}{\sqrt{\varepsilon}}\right\rparen^{o(\sqrt{s})}.

Related works have shown NP-completeness and computational hardness results for related low rank approximation variants, including sparse PCA
[
MWA06
,
Mag17
,
CPR16
]
, low rank approximation with weights or missing data
[
GG11
,
RSW16
]
and
\ell_{p}
low rank approximation for
p\in(1,2)

[
BBB+19
]
. The NP-completeness result of
[
GG11
]
employs a reduction from the maximum-edge biclique problem to show hardness for the rank
1
weighted low rank approximation problem, which is similar to our reduction from the
s
-biclique problem to show exponential running time in
s
under a randomized variant of the Exponential Time Hypothesis. Related hardness results were shown by
[
RSW16
, Theorem 1.4]
, also by a reduction to the maximum biclique problem.

4.2.1
Dependence on
s
and
\varepsilon

We first note that the sparse low rank approximation problem is NP-complete for
\varepsilon=1/n^{2}
. This is obtained through a reduction from the
s
-
Biclique
problem, which asks whether a given bipartite graph contains an
s
-biclique
K_{s,s}
or not:

Lemma 4.15
.

Let
G=(L,R,E)
be a bipartite graph with
\lvert L\rvert=\lvert R\rvert=n
, and let
\mathbf{A}_{G}
denote the
n\times n
biadjacency matrix for
G
, that is,
(\mathbf{A}_{G})_{i,j}
is
1
if vertex
i\in L
and
j\in R
are adjacent and
0
otherwise. Then for
\varepsilon=1/n^{2}
, it is NP-hard to compute the cost
\lVert\mathbf{A}-\mathbf{A}^{*}\rVert_{F}^{2}
of the optimal solution
\mathbf{A}^{*}
for the
s\times s
-sparse low rank approximation problem within a
(1+\varepsilon)
factor.

Proof.

If
G
contains a
K_{s,s}
, then
\mathbf{A}_{G}
contains an
s\times s
all ones matrix, so the optimal cost is
\lVert\mathbf{A}-\mathbf{A}^{*}\rVert_{F}^{2}=\lVert\mathbf{A}\rVert_{F}^{2}-s^{2}
. On the other hand, if
G
contains no
K_{s,s}
, then every
s\times s
submatrix of
\mathbf{A}_{G}
must have at most
s^{2}-1
ones. Thus, the optimal cost is at least
\lVert\mathbf{A}-\mathbf{A}^{*}\rVert_{F}^{2}\geq\lVert\mathbf{A}\rVert_{F}^{2}-s^{2}+1
. In any case, we have that
\lVert\mathbf{A}-\mathbf{A}^{*}\rVert_{F}^{2}\leq\lVert\mathbf{A}\rVert_{F}^{2}\leq n^{2}
so the costs in these two cases are separated by at least a
1+\varepsilon
factor for
\varepsilon=1/n^{2}
.
∎

This is similar to the reduction of sparse PCA to the
s
-
Clique
problem
[
Mag17
]
. The NP-completeness of
s
-biclique
K_{s,s}
is stated without proof in
[
GJ79
]
and proven in e.g.,
[
ADL+94
]
.

In fact, it is also known that
s
-
Biclique
does not admit fixed parameter tractable (FPT) algorithms, assuming a randomized version of the Exponential Time Hypothesis.

Theorem 4.16

(Corollary 1.8,
[
Lin18
]
)
.

Under the randomized ETH, there is no
f(s)\cdot n^{o(\sqrt{s})}
-time algorithm to decide whether a given graph contains a subgraph isomorphic to
K_{s,s}
.

Then by a similar reduction as before, under the randomized ETH, the
(1+n^{-2})
-approximate
s\times s
-sparse low rank approximation problem admits no
f(s)\cdot n^{o(\sqrt{s})}
-time algorithm as well. Stated in terms of the accuracy parameter
\varepsilon
and
s
, we have the following:

Corollary 4.17
.

Under the randomized ETH, there is no
f(s)\cdot(1/\sqrt{\varepsilon})^{o(\sqrt{s})}
-time algorithm to compute a
(1+\varepsilon)
-approximate
s\times s
-sparse low rank approximation.

Remark 4.18
.

Recently, the running time lower bound for the
s
-
Biclique
problem has been shown to admit no algorithms running in time
f(s)n^{o(s)}
under a variant of the Planted Clique conjecture, termed the
Strongish Planted Clique Hypothesis

[
MRS21
]
. Then using this, one concludes that there is no algorithm running in time
f(s)(1/\sqrt{\varepsilon})^{o(s)}
for the
(1+\varepsilon)
-approximate Frobenius sparse low rank approximation problem as well, under the Strongish Planted Clique Conjecture.

5
Gaussian Noise Spectral Sparse Low Rank Approximation

We finally consider the setting where we are given a matrix

\mathbf{A}=\lambda\mathbf{X}+\mathbf{G}

for
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
,
\lambda=O(\sqrt{n})
, and
\mathbf{X}\in\mathcal{O}_{s,k}
has operator norm
1
. Note that we consider disjoint
s\times s
-sparse rank
k
matrices
\mathcal{O}_{s,k}
rather than
\mathcal{S}_{s,k}
in order to obtain tight bounds for this problem. Furthermore, throughout this section, we will assume that the coefficients
\tau_{i}
in the Definition
1.1
are bounded by
\tau_{i}\leq\poly(n)
, for convenience for certain net arguments.

In this setting, we consider both the problem of detection of the low rank signal
\mathbf{X}
as well as the estimation of the low rank signal.

5.1
Lemmas for Analysis

We first introduce simple lemmas which will be useful for our analysis. The first argues that orthogonal sparse components can only add Frobenius mass to each other.

Lemma 5.1
.

Let
\mathbf{u}_{1},\mathbf{v}_{1}
and
\mathbf{u}_{2},\mathbf{v}_{2}
be two
s
-sparse left and right singular vector pairs. Then, the Frobenius norm of the restriction of
\mathbf{u}_{1}\mathbf{v}_{1}^{\top}+\mathbf{u}_{2}\mathbf{v}_{2}^{\top}
to the
s\times s
support of
\mathbf{u}_{1}\mathbf{v}_{1}^{\top}
is at least
\lVert\mathbf{u}_{1}\mathbf{v}_{1}^{\top}\rVert_{F}
.

Proof.

Let
S_{\mathbf{u}}
be intersection of the supports of
\mathbf{u}_{1}
and
\mathbf{u}_{2}
. Note then that
\left\langle\mathbf{u}_{1}|_{S_{u}},\mathbf{u}_{2}|_{S_{u}}\right\rangle=\left\langle\mathbf{u}_{1},\mathbf{u}_{2}\right\rangle=0
. Similarly,
\left\langle\mathbf{v}_{1}|_{S_{\mathbf{v}}},\mathbf{v}_{2}|_{S_{\mathbf{v}}}\right\rangle=0
where
S_{\mathbf{v}}
is the intersection of the supports of
\mathbf{v}_{1}
and
\mathbf{v}_{2}
. Then by the Pythagorean theorem, the Frobenius norm of the sum
\mathbf{u}_{1}\mathbf{v}_{1}^{\top}+\mathbf{u}_{2}\mathbf{v}_{2}^{\top}
restricted to
S_{\mathbf{u}}\times S_{\mathbf{v}}
is

\displaystyle\left\lVert\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top}+\mathbf{u}_{2}|_{S_{\mathbf{u}}}\mathbf{v}_{2}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}+\left\lVert\mathbf{u}_{2}|_{S_{\mathbf{u}}}\mathbf{v}_{2}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}+2\left\langle\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top},\mathbf{u}_{2}|_{S_{\mathbf{u}}}\mathbf{v}_{2}|_{S_{\mathbf{v}}}^{\top}\right\rangle

\displaystyle=\left\lVert\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}+\left\lVert\mathbf{u}_{2}|_{S_{\mathbf{u}}}\mathbf{v}_{2}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}+2\left\langle\mathbf{u}_{1}|_{S_{\mathbf{u}}},\mathbf{u}_{2}|_{S_{\mathbf{u}}}\right\rangle\left\langle\mathbf{v}_{1}|_{S_{\mathbf{v}}},\mathbf{v}_{2}|_{S_{\mathbf{v}}}\right\rangle

\displaystyle=\left\lVert\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}+\left\lVert\mathbf{u}_{2}|_{S_{\mathbf{u}}}\mathbf{v}_{2}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}\geq\left\lVert\mathbf{u}_{1}|_{S_{\mathbf{u}}}\mathbf{v}_{1}|_{S_{\mathbf{v}}}^{\top}\right\rVert_{F}^{2}

By adding in the rest of the entries of
\mathbf{u}_{1}\mathbf{v}_{1}^{\top}
outside of
S_{\mathbf{u}}\times S_{\mathbf{v}}
, we conclude as desired.
∎

Our second lemma shows that any unit vector is essentially an
s
-sparse vector with entries of squared value roughly
1/s
, for some
s
.

Lemma 5.2
.

Let
\mathbf{v}\in\mathbb{R}^{m}
. Then, there exists an
s\in[m]
such that there are at least
s/2
entries of
\mathbf{A}
with squared value at least
\left\lVert\mathbf{v}\right\rVert_{2}^{2}(s(1+\log_{2}m))^{-1}
.

Proof.

By scaling, assume WLOG that
\left\lVert\mathbf{v}\right\rVert_{2}^{2}=1
. If
\mathbf{v}
has an entry with squared value at least
(1+\log_{2}m)^{-1}
, then we are already done with
s=1
. Thus, let
\lvert\mathbf{v}_{i}\rvert<(1+\log_{2}m)^{-1}
for all
i\in[m]
.

Suppose for contradiction that for every
\ell\in[\log_{2}m]
, there are fewer than
2^{\ell}/2
entries of
\mathbf{v}
with absolute value at least
(2^{\ell}\log_{2}m)^{-1}
. We then partition the entries of
\mathbf{A}
into the multiset
S_{0}
of entries with squared value at most
1/m(1+\log_{2}m)
and the multisets
S_{\ell}
with squared value in

\left[\frac{1}{2^{\ell}(1+\log_{2}m)},\frac{2}{2^{\ell}(1+\log_{2}m)}\right)

for each
\ell\in[\log_{2}m]
. Note then that

\displaystyle\lVert\mathbf{v}\rVert_{2}^{2}

\displaystyle<\lvert S_{0}\rvert\cdot\frac{1}{m(1+\log_{2}m)}+\sum_{\ell=1}^{\log_{2}m}\lvert S_{\ell}\rvert\cdot\frac{2}{2^{\ell}(1+\log_{2}m)}

\displaystyle\leq\frac{m}{m(1+\log_{2}m)}+\sum_{\ell=1}^{\log_{2}m}\frac{2^{\ell}}{2}\frac{2}{2^{\ell}(1+\log_{2}m)}

\displaystyle\leq\frac{1}{1+\log_{2}m}+\sum_{\ell=1}^{\log_{2}m}\frac{1}{1+\log_{2}m}

\displaystyle=\frac{1+\log_{2}m}{1+\log_{2}m}=1,

a contradiction.
∎

5.2
Detection

We first consider the problem of detection.

5.2.1
Lower Bounds

As previously noted,
[
LNW19
]
give sketching lower bounds for the detection problem when
\mathbf{X}
is a random
n\times n
rank
1
matrix. We first adapt this lower bound to the setting where
\mathbf{X}\in\mathcal{O}_{s,k}
. For our sparse low rank signal lower bound, we draw our low rank signal matrix as a random sparse vector.

Definition 5.3

(Random sparse vector)
.

We define the distribution
\nu_{s,n}
which samples a vector
\mathbf{u}\in\mathbb{R}^{n}
by sampling a subset
S\subseteq[n]
of
\lvert S\rvert=s
random coordinates, drawing the values for
\mathbf{u}
on the coordinates of
S
as
\mathbf{u}|_{S}\sim\mathcal{N}(0,\mathbf{I}_{s})
, and
0
s everywhere else.

Now consider the problem of distinguishing between two distributions where
\mathcal{D}_{1}=\mathcal{N}(0,1)^{n\times n}
is an
n\times n
matrix with independent standard Gaussian entries, and
\mathcal{D}_{2}
is the distribution drawn as
\sum_{j=1}^{k}\mathbf{w}_{j}\mathbf{u}^{j}(\mathbf{v}^{j})^{\top}
where
\mathbf{u}^{j}\sim\nu_{n,s_{1}}
and
\mathbf{v}^{j}\sim\nu_{d,s_{2}}
, are all drawn independently (recall Definition
5.3
). We take
m
linear measurements and denote the corresponding measurements as
\mathbf{L}^{1},\mathbf{L}^{2},\dots,\mathbf{L}^{m}
. We WLOG assume that
\left\lVert\mathbf{L}^{i}\right\rVert_{F}^{2}=1
and
\tr(\mathbf{L}^{i}(\mathbf{L}^{j})^{\top})=0
for
i\neq j
. Let
\mathcal{L}_{1}
and
\mathcal{L}_{2}
denote the distribution
of the
m
dimensional linear sketches of
\mathcal{D}_{1}
and
\mathcal{D}_{2}
, respectively.

Useful Computations.

We will need the following simple lemma.

Lemma 5.4
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
. Then,

\E_{S\sim\binom{[n]}{s}}\lVert\mathbf{S}_{S}\mathbf{A}\rVert_{F}^{2}=\sum_{S\in\binom{[n]}{s}}\frac{1}{\binom{n}{s}}\sum_{i\in S}\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\rVert_{2}^{2}=\sum_{i\in[n]}\frac{\binom{n-1}{s-1}}{\binom{n}{s}}\lVert\mathbf{e}_{i}^{\top}\mathbf{A}\rVert_{2}^{2}=\frac{s}{n}\lVert\mathbf{A}\rVert_{F}^{2}

We also need the following computation for later use. This slightly modifies
[
LNW19
, Lemma 3.1]
.

Lemma 5.5
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
with
\left\lVert\mathbf{A}\right\rVert_{F}<1
. Let
\mathbf{u}^{\prime}\sim\nu_{s_{1},n}
and
\mathbf{v}^{\prime}\sim\nu_{s_{2},d}
be drawn independently. Then,

\E_{\mathbf{u}^{\prime},\mathbf{v}^{\prime}}\exp(\mathbf{u}^{\prime\top}\mathbf{A}\mathbf{v}^{\prime})\leq 1+\frac{s_{1}s_{2}}{nd}\left\lVert\mathbf{A}\right\rVert_{F}^{2}.

Proof.

It is shown in the proof of
[
LNW19
, Lemma 3.1]
that for a matrix
\mathbf{M}\in\mathbb{R}^{s_{1}\times s_{2}}
and independent Gaussians
\mathbf{x}\sim\mathcal{N}(0,\mathbf{I}_{s_{1}})
and
\mathbf{y}\sim\mathcal{N}(0,\mathbf{I}_{s_{2}})
that

\E_{\mathbf{x},\mathbf{y}}\exp(\mathbf{x}^{\top}\mathbf{M}\mathbf{y}^{\top})=\prod_{i}\frac{1}{\sqrt{1-\sigma_{i}^{2}(\mathbf{M})}}.

Applying this identity, we obtain

\displaystyle\E_{\begin{subarray}{c}\mathbf{u}^{\prime}\sim\nu_{s_{1},n}\\
\mathbf{v}^{\prime}\sim\nu_{s_{2},d}\end{subarray}}\exp\left\lparen\mathbf{u}^{\prime\top}\mathbf{A}\mathbf{v}^{\prime}\right\rparen

\displaystyle=\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}\E_{\mathbf{x}\sim\mathcal{N}(0,\mathbf{I}_{s_{1}}),\mathbf{y}\sim\mathcal{N}(0,\mathbf{I}_{s_{2}})}\exp\left\lparen\mathbf{x}^{\top}(\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top})\mathbf{y}\right\rparen

\displaystyle=\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}\prod_{i}\frac{1}{\sqrt{1-\sigma_{i}^{2}(\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top})}}

We then continue to bound as

\displaystyle\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}\prod_{i}\frac{1}{\sqrt{1-\sigma_{i}^{2}(\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top})}}

\displaystyle\leq\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}\frac{1}{\sqrt{1-\sum_{i}\sigma_{i}^{2}(\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top})}}

\displaystyle=\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}\frac{1}{\sqrt{1-\lVert\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\rVert_{F}^{2}}}

\displaystyle\leq\E_{S\sim\binom{[n]}{s_{1}},T\sim\binom{[d]}{s_{2}}}1+\lVert\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\rVert_{F}^{2}

1/\sqrt{1-t}\leq 1+t
on
[0,1/2]

\displaystyle=1+\E_{S\sim\binom{[n]}{s_{1}}}\E_{T\sim\binom{[d]}{s_{2}}}\lVert\mathbf{S}_{S}\mathbf{A}\mathbf{S}_{T}^{\top}\rVert_{F}^{2}

\displaystyle=1+\frac{s_{1}s_{2}}{nd}\lVert\mathbf{A}\rVert_{F}^{2}

Lemma
5.4

which is the desired conclusion.
∎

Main Lower Bound.

Lemma 5.6
.

We consider sketching dimension
m
with normalization vector
\mathbf{w}\in\mathbb{R}^{k}
. Let
s_{1}
and
s_{2}
be sparsity parameters and let
n,d
be the dimensions of the Gaussian matrix. Further suppose

m\frac{s_{1}s_{2}}{nd}\lVert\mathbf{w}\rVert_{2}^{4}\leq c

for a small enough constant
c
. Then,

\lVert\mathcal{L}_{1}-\mathcal{L}_{2}\rVert_{\mathsf{TV}}\leq\frac{1}{10}.

Proof.

Note that
\mathcal{L}_{1}=\mathcal{N}(0,\mathbf{I}_{m})
and
\mathcal{L}_{2}=\mathcal{N}(0,\mathbf{I}_{m})*\mu
where
\mu
is the distribution of

\begin{pmatrix}\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{1}\mathbf{v}^{j}\\
\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{2}\mathbf{v}^{j}\\
\vdots\\
\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{m}\mathbf{v}^{j}\\
\end{pmatrix}\in\mathbb{R}^{m}

Define

\xi\coloneqq\sum_{i=1}^{m}\left\lparen\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\right\rparen^{2}

Note that for a single
j\in[k]
,
\E(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}=0
so

\displaystyle\E\xi

\displaystyle=\sum_{i=1}^{m}\E\left\lparen\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\right\rparen^{2}

\displaystyle=\sum_{i=1}^{m}\sum_{j=1}^{k}\E\left\lparen\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\right\rparen^{2}

\displaystyle=\sum_{i=1}^{m}\sum_{j=1}^{k}\mathbf{w}_{j}^{2}\sum_{a=1}^{n}\sum_{b=1}^{d}(\mathbf{L}^{i})_{a,b}^{2}\E(\mathbf{u}^{j})_{a}^{2}\E(\mathbf{v}^{j})_{b}^{2}

\displaystyle=\frac{ms_{1}s_{2}}{nd}\lVert\mathbf{w}\rVert_{2}^{2}

We now define the event

\mathcal{E}\coloneqq\left\{\lVert\mathbf{w}\rVert_{2}^{2}\xi<1/2\right\}.

The expected value of
\lVert\mathbf{w}\rVert_{2}^{2}\xi
is

\frac{ms_{1}s_{2}}{nd}\lVert\mathbf{w}\rVert_{2}^{4}\leq c

so by Markov’s inequality,
\Pr(\mathcal{E})\geq 1-2c
. Restrict
\mu
to this event and let
\tilde{\mu}
denote the resulting distribution. Let
\tilde{\mathcal{L}_{2}}=\mathcal{N}(0,\mathbf{I}_{m})*\tilde{\mu}
. Then using Propositions 2.1 and 2.2 of
[
LNW19
]
,

\displaystyle\left\lVert\mathcal{L}_{1}-\mathcal{L}_{2}\right\rVert_{\mathsf{TV}}

\displaystyle\leq\left\lVert\mathcal{L}_{1}-\tilde{\mathcal{L}_{2}}\right\rVert_{\mathsf{TV}}+\left\lVert\tilde{\mathcal{L}_{2}}-\mathcal{L}_{2}\right\rVert_{\mathsf{TV}}

\displaystyle\leq\sqrt{\E_{\mathbf{z}_{1},\mathbf{z}_{2}\sim\tilde{\mu}}\exp(\left\langle\mathbf{z}_{1},\mathbf{z}_{2}\right\rangle)-1}+\left\lVert\tilde{\mu}-\mu\right\rVert_{\mathsf{TV}}

\displaystyle\leq\sqrt{\frac{1}{\Pr(\mathcal{E})}\E_{\mathbf{z}_{1}\sim\tilde{\mu},\mathbf{z}_{2}\sim\mu}\exp(\left\langle\mathbf{z}_{1},\mathbf{z}_{2}\right\rangle)-1}+\Pr(\mathcal{E}^{c}).

Then,

\displaystyle\E_{\mathbf{z}_{1}\sim\tilde{\mu},\mathbf{z}_{2}\sim\mu}\exp(\left\langle\mathbf{z}_{1},\mathbf{z}_{2}\right\rangle)

\displaystyle=\E\exp\left\lparen\sum_{i=1}^{m}\sum_{j=1}^{k}\sum_{j^{\prime}=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}(\mathbf{u}^{j^{\prime}})^{\top}\mathbf{L}^{i}\mathbf{v}^{j^{\prime}}\right\rparen

\displaystyle=\E\exp\left\lparen\sum_{j^{\prime}=1}^{k}(\mathbf{u}^{j^{\prime}})^{\top}\left[\sum_{i=1}^{m}\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}\mathbf{L}^{i}\right]\mathbf{v}^{j^{\prime}}\right\rparen

\displaystyle=\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{r},\mathbf{v}^{1},\dots,\mathbf{v}^{r}\mid\mathcal{E}}\prod_{j^{\prime}=1}^{k}\E_{\begin{subarray}{c}\mathbf{u}^{j^{\prime}}\sim\nu_{k,m}\\
\mathbf{v}^{j^{\prime}}\sim\nu_{k,n}\end{subarray}}\exp\left\lparen(\mathbf{u}^{j^{\prime}})^{\top}\mathbf{Q}^{j^{\prime}}\mathbf{v}^{j^{\prime}}\right\rparen

where
\mathbf{Q}^{j^{\prime}}
is an
n\times d
matrix defined by

\mathbf{Q}^{j^{\prime}}\coloneqq\sum_{i=1}^{m}\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}\mathbf{L}^{i}

We have that

\displaystyle\lVert\mathbf{Q}^{j^{\prime}}\rVert_{F}^{2}

\displaystyle=\left\lVert\sum_{i=1}^{m}\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}\mathbf{L}^{i}\right\rVert_{F}^{2}

\displaystyle=\sum_{i=1}^{m}\left\lVert\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}\mathbf{L}^{i}\right\rVert_{F}^{2}

since the
\mathbf{L}^{i}
are orthogonal

\displaystyle=\sum_{i=1}^{m}\left\lparen\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\cdot\mathbf{w}_{j^{\prime}}\right\rparen^{2}\left\lVert\mathbf{L}^{i}\right\rVert_{F}^{2}

\displaystyle=\mathbf{w}_{j^{\prime}}^{2}\sum_{i=1}^{m}\left\lparen\sum_{j=1}^{k}\mathbf{w}_{j}(\mathbf{u}^{j})^{\top}\mathbf{L}^{i}\mathbf{v}^{j}\right\rparen^{2}

\displaystyle=\mathbf{w}_{j^{\prime}}^{2}\xi<1

since we have conditioned on
\mathcal{E}
. Thus,

\displaystyle\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{k},\mathbf{v}^{1},\dots,\mathbf{v}^{k}\mid\mathcal{E}}\prod_{j^{\prime}=1}^{k}\E_{\mathbf{u}^{j^{\prime}},\mathbf{v}^{j^{\prime}}}\exp\left\lparen(\mathbf{u}^{j^{\prime}})^{\top}\mathbf{Q}^{j^{\prime}}\mathbf{v}^{j^{\prime}}\right\rparen

\displaystyle\leq\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{k},\mathbf{v}^{1},\dots,\mathbf{v}^{k}\mid\mathcal{E}}\prod_{j^{\prime}=1}^{k}\left\lparen 1+\frac{s_{1}s_{2}}{nd}\mathbf{w}_{j^{\prime}}^{2}\xi\right\rparen

\displaystyle\leq\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{k},\mathbf{v}^{1},\dots,\mathbf{v}^{k}\mid\mathcal{E}}\exp\left\lparen\sum_{j^{\prime}=1}^{k}\frac{s_{1}s_{2}}{nd}\mathbf{w}_{j^{\prime}}^{2}\xi\right\rparen

\displaystyle=\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{k},\mathbf{v}^{1},\dots,\mathbf{v}^{k}\mid\mathcal{E}}\exp\left\lparen\frac{s_{1}s_{2}}{nd}\lVert\mathbf{w}\rVert_{2}^{2}\xi\right\rparen

\displaystyle\leq\E_{\mathbf{u}^{1},\dots,\mathbf{u}^{k},\mathbf{v}^{1},\dots,\mathbf{v}^{k}\mid\mathcal{E}}1+2\frac{s_{1}s_{2}}{nd}\lVert\mathbf{w}\rVert_{2}^{2}\xi

\displaystyle\leq 1+2c

Thus,

\lVert\mathcal{L}_{1}-\mathcal{L}_{2}\rVert_{\mathsf{TV}}\leq\sqrt{\frac{2c}{1-2c}}+2c\leq\frac{1}{10}

when
c
is small enough.
∎

Corollary 5.7
.

Let
k=1
,
d=n
, and

w=\frac{\sqrt{n}}{\sqrt{s_{1}s_{2}}}.

Then, a randomized sketching algorithm distinguishing between
\mathcal{D}_{1}
and
\mathcal{D}_{2}
must make at least
m=\Omega(s_{1}s_{2})
measurements.

Proof.

By Lemma
5.6
, we must have that

m\frac{s_{1}s_{2}}{n^{2}}w^{4}=m\frac{1}{s_{1}s_{2}}\geq c

for a constant
c
. Thus,
m\geq cs_{1}s_{2}=\Omega(s_{1}s_{2})
, as desired.
∎

Now note that if we set
s_{1}=s
and
s_{2}=sk
in the above theorem, this yields a disjoint
s\times s
-sparse rank
k
matrix. To detect this matrix, our theorem states that
\Omega(s^{2}k)
measurements are required.

Corollary 5.8
.

Any randomized sketching algorithm distinguishing between
\mathbf{A}=\mathbf{G}
and
\mathbf{A}=\lambda\mathbf{X}+\mathbf{G}
for
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
,
\lambda=\sqrt{n}
, and
\mathbf{X}\in\mathcal{O}_{s,k}
with
\left\lVert\mathbf{X}\right\rVert_{2}=1
requires
\Omega(s^{2}k)
measurements.

Despite this natural lower bound, there is in fact a better lower bound when
s^{2}k
is small. Consider the task of distinguishing between
\mathbf{A}=\mathbf{G}
and
\mathbf{A}=\mathbf{G}+\sqrt{n}\mathbf{e}_{i}\mathbf{e}_{j}^{\top}
for two randomly chosen coordinates
i\sim[n]
and
j\sim[n]
. This is the hard instance in
[
ANPW13
]
for estimating the
p=4
norm of an
n^{2}
dimensional vector in the context of frequency moment estimation. For this problem, they show that

\Omega((n^{2})^{1-2/p}\log(n^{2}))=\Omega(n\log n)

measurements are required. Putting these together, the lower bound we obtain is

\Omega(n\log n+s^{2}k).

5.2.2
Upper Bounds

We have two upper bounds, each matching the two terms, the
n\log n
and the
s^{2}k
, in the lower bound.

Small
s
Regime:
s\leq\sqrt{n/k\log n}
.

We first show that when

s^{2}k\log(s^{2}k)\leq n

or equivalently when
s\leq\sqrt{n/k\log n}
, that is, when the first term in the lower bound is roughly tight, then an algorithm based on
4
-norm estimation achieves a bound of
n\cdot\poly\log(n)
measurements. In this setting, we essentially need none of the structure provided by the fact that
\mathbf{X}\in\mathcal{O}_{s,k}
. In fact, all we use is that
\left\lVert\mathbf{X}\right\rVert_{F}^{2}\geq 1
and that
\mathbf{X}
is supported on
s^{2}k
coordinates.

For intuition, let
b\leq n
and suppose that
\mathbf{X}
is supported on
b
entries with each nonzero entry equal to
1/\sqrt{b}
, so the corresponding entry in
\mathbf{A}
is
\sqrt{n/b}
. Now consider a random sample
S
of
n^{2}/b^{2}
elements of
\mathbf{A}
, whose
4
-norm we compute in roughly
\sqrt{n^{2}/b^{2}}=n/b
measurements. If
S
contains no entries of
\mathbf{X}
, then
\lVert S\rVert_{4}^{4}=\Theta(n^{2}/b^{2})
, while if
S
does contain an entry of
\mathbf{X}
, then
4
-norm is a constant times larger, so we can distinguish between the two cases. If we now repeat this
b
times, for a total of
b\cdot(n/b)=n
measurements, then we sample a total of
b\cdot(n^{2}/b^{2})=n^{2}/b
elements, so one of these trials will find one of the
b
elements of
\mathbf{X}
.

As described earlier, when
s\leq\sqrt{n/k\log n}
, then we may make use of
4
-norm estimation algorithms to detect the presence of the signal.

Theorem 5.10
.

Let
\mathbf{X}\in\mathcal{S}_{s,k}
. Then Algorithm
1
makes
O(n(\log^{3}(sk))(\log n))
sketching measurements and distinguishes between the cases of
\mathbf{A}=\mathbf{G}+\sqrt{n}\mathbf{X}
and
\mathbf{A}=\mathbf{G}
with constant probability, where
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
.

Proof.

We show in general that when
\mathbf{X}
has Frobenius norm
\left\lVert\mathbf{X}\right\rVert_{F}^{2}\geq r
for some
r
and is supported on
b
entries, then the sketching complexity is

O\left\lparen\frac{n}{r}(\log^{3}b)(\log\log b)(\log n)\right\rparen.

The result then follows since

\left\lVert\mathbf{X}\right\rVert_{F}^{2}\geq\left\lVert\mathbf{X}\right\rVert_{2}^{2}=1

and
\mathbf{X}
is supported on
s^{2}k
entries. In this case, we assume the parameter regime

\frac{nr}{b\log b}\geq c

for some sufficiently large constant
c
.

By applying Lemma
5.2
to
\mathbf{X}
viewed as a vector in
b
dimensions, there exists some
s^{\prime}\in[b]
such that there are at least
s^{\prime}/2
entries of
\mathbf{X}
with squared value at least

\alpha\coloneqq r(s^{\prime}(1+\log_{2}b))^{-1}.

This translates to an entry of squared value at least
n\alpha
in
\mathbf{A}
after scaling
\mathbf{X}
by
\sqrt{n}
. Now consider a random sample of
m=O(n^{2}\alpha^{2})
entries of
\mathbf{A}
. Note that
m\geq 1
by assumption on our parameter regime. The
4
-norm of this sample can be approximated up to constant factors with probability at least
1-O(1/b)
with
O(\sqrt{m}(\log b)(\log n))
measurements by Theorem
5.9
.

If this sample contains only Gaussian entries, then the
4
-norm has an expectation of
O(m^{1/4})

[
PVZ17
, Proposition 2.4]
and concentrates to this expectation up to a
(1+\varepsilon)
factor with probability at least
1-\exp(-\Omega(\varepsilon\sqrt{m}))

[
PVZ17
, Theorem 1.1]
. On the other hand, if this sample contains an entry of squared size
n\alpha
, then this single entry increases the
4
-norm of the sample by a constant factor, so this distinguishes between the two cases. The probability that this random sample contains one of these entries of squared size
n\alpha
is

p=O\left\lparen\frac{ms^{\prime}}{n^{2}}\right\rparen=O(\alpha^{2}s^{\prime})=O\left\lparen\frac{r^{2}}{s^{\prime}\log^{2}b}\right\rparen.

Thus, with
O(\log(1/\delta)/p)
repetitions for
\delta=1/\log_{2}b
, the probability that we find none of the
s^{\prime}
large entries is at most

(1-p)^{\log(1/\delta)/p}\leq\exp\left\lparen-p\frac{\log\frac{1}{\delta}}{p}\right\rparen=\delta

we find one of the
s^{\prime}
entries of squared size at least
n\alpha
with constant probability.

The total number of sketching measurements assuming that we know
s^{\prime}
was

\displaystyle O\left\lparen\sqrt{m}(\log b)(\log n)\cdot\frac{\log\frac{1}{\delta}}{p}\right\rparen

\displaystyle=O\left\lparen n\alpha(\log b)(\log n)\cdot\frac{\log\frac{1}{\delta}}{\alpha^{2}s^{\prime}}\right\rparen

\displaystyle=O\left\lparen\frac{n}{r}(\log^{2}b)(\log n)\log\frac{1}{\delta}\right\rparen

By guessing
s^{\prime}
up to constant factors by
s^{\prime}=1,2,4,\dots,b
in
\log_{2}b
guesses, our final sketching complexity is

O\left\lparen\frac{n}{r}(\log^{3}b)(\log\log b)(\log n)\right\rparen.\qed

Thus, in the regime where
s\leq\sqrt{n/k\log n}
, the detection problem can roughly be viewed as a simpler case of the
4
-norm estimation problem, since both the algorithms and lower bounds are captured by
4
-norm estimation.

Large
s
Regime:
s\geq\sqrt{n/k\log n}
.

When
s\geq\sqrt{n/k\log n}
, the
4
-norm estimation approach cannot work, and our approach shifts to sampling a submatrix and iterating over a net to identify the signal. We illustrate the basic idea of the algorithm on the hard instance of the lower bound in Corollary
5.8
, where the signal matrix is
\mathbf{X}
is essentially
\mathbf{u}\mathbf{v}^{\top}
for
\mathbf{u}\sim\mathcal{N}(0,\mathbf{I}_{s})
and
\mathbf{u}\sim\mathcal{N}(0,\mathbf{I}_{sk})
, normalized appropriately, so that the signal matrix added to the Gaussian noise has operator norm
\sqrt{n}
. To detect this signal, suppose we sample an
sk\times s
submatrix. Then, in expectation, we sample a

\frac{s^{2}k}{n}\times\frac{s^{2}k}{n}

submatrix
\mathbf{X}^{\prime}
of
\mathbf{X}
. We then iterate over a net
\mathcal{N}
for
(s^{2}k/n)\times(s^{2}k/n)
-sparse rank
1
matrices, which has log size roughly
\tilde{O}(s^{2}k/n)
, to try to find a net vector that aligns with
\mathbf{X}^{\prime}
. If we find such a net vector, then the inner product between the net vector and
\mathbf{X}^{\prime}
will be

\left\lVert\mathbf{X}^{\prime}\right\rVert_{F}=\sqrt{\frac{s^{2}k}{n}\cdot\frac{s^{2}k}{n}\cdot\frac{n}{s^{2}k}}=\sqrt{\frac{s^{2}k}{n}}.

On the other hand, note that the inner product between the net vector and the Gaussian noise will just be a standard Gaussian, since the net vector has Frobenius norm
1
. Now for any
\delta\in(0,1)
, the Gaussian will be at most
\sqrt{\log\frac{1}{\delta}}
with probability at least
1-\delta
, so with
\delta=1/\Theta(\left\lvert\mathcal{N}\right\rvert)
, we can union bound over the net to see that the Gaussian noise is at most

\sqrt{\log\frac{1}{\delta}}=\tilde{O}\left\lparen\sqrt{\frac{s^{2}k}{n}}\right\rparen.

We thus see that by adjusting constants and log factors appropriately, we can distinguish between the Gaussian noise and the signal and thus solve the detection problem.

In general, this approach will work to give a sketching upper bound of
\tilde{O}(s^{2}k)
dimensions, if we can find an
a\times b
submatrix with operator norm at least
\tilde{\Omega}(1)
for
ab\leq\tilde{O}(s^{2}k)
. However, we are unable to show that such a submatrix exists for every
\mathbf{X}\in\mathcal{O}_{s,k}
. Instead, we obtain a looser bound of

\tilde{O}(s^{2}k^{4/3})

measurements by showing two algorithms that roughly follow the above approach, one for when the Frobenius norm of
\mathbf{X}
is large and one for when the Frobenius norm of
\mathbf{X}
is small:

Lemma 5.11

Let

Proof.

Write

\mathbf{X}=\sum_{i=1}^{k}\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}.

Note then that

\left\lVert\mathbf{X}\right\rVert_{F}^{2}=\sum_{i=1}^{k}\left\lVert\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}^{\top}\right\rVert_{F}^{2}=\sum_{i=1}^{k}\tau_{i}^{2}.

Then there is some

.

We now apply Lemma

\mathbf{x}_{i}
and
\mathbf{y}_{i}

has at least
s_{1}/2

of

have squared size at least
(s_{1}(1+\log_{2}s))^{-1}
, and similarly,
\mathbf{y}_{i}
has at least
s_{2}/2

S_{2}\subseteq[n]

\mathbf{y}_{i}

(s_{2}(1+\log_{2}s))^{-1}
. We refer to these entries as the

.

Handling Sparse Components.

Suppose that

Then, there is a submatrix supported on
s_{1}s_{2}

\frac{n\tau_{i}^{2}}{s_{1}s_{2}(1+\log_{2}s)^{2}}\geq\frac{nr}{ks_{1}s_{2}(1+\log_{2}s)^{2}}\geq 1,

which has a sparsity of
b=s_{1}s_{2}
and Frobenius norm

such that

\frac{nr}{b\log b}\geq c

so we can detect this submatrix by using the
4
-norm estimation procedure of Theorem

. We thus assume that

s_{1}s_{2}>\Omega\left\lparen\frac{nr}{k(1+\log_{2}s)^{2}\log n}\right\rparen=\tilde{\Omega}\left\lparen\frac{nr}{k}\right\rparen.

(2)

Handling Dense Components.

When
s_{1}s_{2}=\tilde{\Omega}(nr/k)
as in Equation (
2
), then our algorithm is to sample a submatrix. Suppose for the moment that we know
s_{1}
and
s_{2}
, and we will remove this assumption later. We then sample a random

submatrix
\mathbf{A}^{\prime}
of
\mathbf{A}

t_{1}\coloneqq\Theta(n_{1}s_{1}/n)

t_{2}\coloneqq\Theta(n_{2}s_{2}/n)

\tau_{i}\mathbf{x}_{i}\mathbf{y}_{i}

\Theta\left\lparen\frac{n_{1}s_{1}}{n}\right\rparen=\Theta\left\lparen\frac{n_{2}s_{2}}{n}\right\rparen\geq\log\log s.

\mathbf{X}
, supported on the flat entries
S_{1}\times S_{2}

\mathbf{X}^{\prime}
. We now consider an
\varepsilon
-net
\mathcal{N}

On the other hand, if

Lemma 5.12
.

Let
\mathbf{X}\in\mathcal{O}_{s,k}
be an
n\times n
matrix with Frobenius norm at most

\left\lVert\mathbf{X}\right\rVert_{F}^{2}\leq r.

Then, we can distinguish
\mathbf{G}+\sqrt{n}\mathbf{X}
and
\mathbf{G}
for
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
with

O(s^{2}kr\log^{6}(sk)\log^{2}n).

measurements.

Proof.

The proof proceeds in two stages. We first prove the existence of a small rank
1
approximation to
\mathbf{X}
, and then iterate over a net to find it.

Existence of a Sparse Rank 1 Approximation.

Let
\mathbf{u}
and
\mathbf{v}
be the top left and right singular vectors of
\mathbf{X}
. Write the vectors
\mathbf{u}
and
\mathbf{v}
in level sets by

\mathbf{u}=\sum_{i=1}^{O(\log(sk))}\mathbf{u}_{i},\qquad\mathbf{v}=\sum_{i=1}^{O(\log(sk))}\mathbf{v}_{i}.

Then,

1=\left\lvert\mathbf{u}^{\top}\mathbf{X}\mathbf{v}\right\rvert\leq\sum_{i=1}^{O(\log n)}\sum_{j=1}^{O(\log n)}\left\lvert\mathbf{u}_{i}^{\top}\mathbf{X}\mathbf{v}_{j}\right\rvert

and thus by averaging, there exist
i,j
such that

\frac{1}{\Theta(\log^{2}(sk))}\leq\left\lvert\mathbf{u}_{i}^{\top}\mathbf{X}\mathbf{v}_{j}\right\rvert

where
\mathbf{u}_{i}
is
s_{1}
-sparse and
\mathbf{v}_{j}
is
s_{2}
-sparse. Let
\mathbf{X}\mid_{\mathbf{u},\mathbf{v}}
denote the restriction of
\mathbf{X}
to the supports of
\mathbf{u}
and
\mathbf{v}
. Then,

\left\lvert\mathbf{u}_{i}^{\top}\mathbf{X}\mathbf{v}_{j}\right\rvert\leq\frac{\left\lVert\mathbf{X}\mid_{\mathbf{u},\mathbf{v}}\right\rVert_{1}}{\sqrt{ab}}\leq\frac{\sqrt{\nnz(\mathbf{X}\mid_{\mathbf{u},\mathbf{v}})}\left\lVert\mathbf{X}\mid_{\mathbf{u},\mathbf{v}}\right\rVert_{2}}{\sqrt{ab}}\leq\frac{\sqrt{s^{2}k}\sqrt{r}}{\sqrt{ab}}.

Combining the previous bounds,

s_{1}s_{2}\leq\Theta(s^{2}kr\log^{2}(sk)).

Net Argument.

By the previous argument, there exist vectors
\mathbf{u}
and
\mathbf{v}
of norm at most
1
that are
s_{1}
-sparse and
s_{2}
-sparse for
s_{1},s_{2}\in[sk]
, respectively, such that

\left\lvert\left\langle\mathbf{u}\mathbf{v}^{\top},\mathbf{X}\right\rangle\right\rvert=\left\lvert\mathbf{u}^{\top}\mathbf{X}\mathbf{v}\right\rvert\geq\frac{1}{\Theta(\log^{2}(sk))}

and

s_{1}s_{2}\leq\Theta(s^{2}kr\log^{2}(sk)).

We then proceed as in the subsampling and net iteration step of Lemma
5.11
. Since the calculations are essentially the same, we only quickly outline the proof. We first assume we know
s_{1}
and
s_{2}
and we sample a
n_{1}\times n_{2}
submatrix. This samples a
t_{1}\times t_{2}
submatrix of
\mathbf{X}\mid_{\mathbf{u},\mathbf{v}}
where

t_{1}=\Theta\left\lparen\frac{n_{1}s_{1}}{n}\right\rparen,\qquad t_{2}=\Theta\left\lparen\frac{n_{2}s_{2}}{n}\right\rparen.

We then iterate over a net
\mathcal{N}
over
t_{1}\times t_{2}
rank
1
matrices of log size at most

\log\left\lvert\mathcal{N}\right\rvert\leq(t_{1}+t_{2})\log n=\frac{n_{1}s_{2}+n_{2}s_{2}}{n}\log n.

Let
\mathbf{B}\in\mathcal{N}
. If there is no signal, then

\left\langle\mathbf{B},\mathbf{A}\right\rangle\sim\mathcal{N}(0,\left\lVert\mathbf{B}\right\rVert_{F}^{2})=\mathcal{N}(0,1)

while if there is a signal, then for some
\mathbf{B}\in\mathcal{N}
,

\left\langle\mathbf{B},\mathbf{A}\right\rangle\sim\mathcal{N}(\left\langle\sqrt{n}\mathbf{X}\mid_{\mathbf{u},\mathbf{v}},\mathbf{B}\right\rangle,\left\lVert\mathbf{B}\right\rVert_{F}^{2})=\mathcal{N}(\left\langle\sqrt{n}\mathbf{X}\mid_{\mathbf{u},\mathbf{v}},\mathbf{B}\right\rangle,1)

where

\left\langle\sqrt{n}\mathbf{X}\mid_{\mathbf{u},\mathbf{v}},\mathbf{B}\right\rangle=\Theta\left\lparen\sqrt{t_{1}t_{2}\frac{n}{s_{1}s_{2}\log^{2}(sk)}}\right\rparen=\Theta\left\lparen\sqrt{\frac{n_{1}n_{2}}{n\log^{2}(sk)}}\right\rparen.

This is larger than the noise from the Gaussian over
\mathcal{N}
as long as

\sqrt{\log\left\lvert\mathcal{N}\right\rvert}=\sqrt{\frac{n_{1}s_{2}+n_{2}s_{2}}{n}\log n}=O\left\lparen\sqrt{\frac{n_{1}n_{2}}{n\log^{2}(sk)}}\right\rparen

which happens for

n_{1}=O(s_{2}\log^{2}(sk)\log n),\qquad n_{2}=O(s_{1}\log^{2}(sk)\log n).

Thus, the required number of samples in this case is

O(s_{1}s_{2}\log^{4}(sk)\log^{2}n)=O(s^{2}kr\log^{4}(sk)\log^{2}n)

Iterating over
\log^{2}(sk)
choices of
s_{1}
and
s_{2}
, the total number of measurements is

O(s^{2}kr\log^{6}(sk)\log^{2}n).\qed

.

\mathbf{X}\in\mathcal{O}_{s,k}

\mathbf{G}+\sqrt{n}\mathbf{X}
and
\mathbf{G}
for
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}

If

Estimation

We now consider the estimation problem, in which, given a matrix

\mathbf{X}^{\prime}\in\mathcal{S}_{s,k}

\mathbf{X}=\lVert\mathbf{X}-\mathbf{X}^{\prime}\rVert_{2}\leq\varepsilon.

For this problem, for constant

5.3.1
Gaussian Noise Estimation Upper Bound

We will need an analogue of the approximate matrix product lemma (Lemma
2.8
) for matrices with i.i.d. Gaussian entries from
[
Sar06
, Lemma 6]
.

Lemma 5.14

(Gaussian approximate matrix product
[
Sar06
]
)
.

Let
\mathbf{A}\in\mathbb{R}^{n\times d}
,
\mathbf{B}\in\mathbb{R}^{m\times d}
, and
\varepsilon>0
. Consider an
r\times d
matrix
\mathbf{S}
of all i.i.d. Gaussian entries for
r=\Omega(\varepsilon^{-2}(\log(n+m))(\log\frac{1}{\delta}))
. Then,

\Pr\left\{\left\lVert\mathbf{A}\mathbf{S}^{\top}\mathbf{S}\mathbf{B}^{\top}-\mathbf{A}\mathbf{B}^{\top}\right\rVert_{F}^{2}\leq\varepsilon^{2}\left\lVert\mathbf{A}\right\rVert_{F}^{2}\left\lVert\mathbf{B}\right\rVert_{F}^{2}\right\}\geq 1-\delta.

Given this lemma, our algorithm is simply to approximately maximize the inner product between
\mathbf{A}
and net vectors given by Corollary
2.3
.

Theorem 5.15
.

Let
\varepsilon,s,n
be such that

\sqrt{2s\log\frac{3en}{\varepsilon s}}\leq\varepsilon^{2}\sqrt{n}.

Let
\mathbf{H}
be an
m\times n^{2}
Gaussian matrix for

m=O\left\lparen\frac{ns}{\varepsilon^{4}}\log\frac{n}{\varepsilon s}\right\rparen.

Consider
\mathbf{A}=\mathbf{G}+\sqrt{n}\mathbf{X}
for a
s\times s
sparse rank
1
matrix
\mathbf{X}
with operator norm
1
and
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
. Then, there is an algorithm which, given
m
Gaussian measurements of
\mathbf{A}
, outputs an
s\times s
sparse rank
1
matrix
\mathbf{X}^{\prime}
such that

\left\lVert\mathbf{X}-\mathbf{X}^{\prime}\right\rVert_{2}\leq\varepsilon.

Proof.

We iterate over an
\varepsilon
-net
\mathcal{N}
for
\mathcal{S}_{s,k}
of size at most
(\poly(n)k/\varepsilon)^{sk}
, which exists by Corollary
2.3
. Our approach is to select the best candidate in the net by finding the
\mathbf{X}^{\prime}\in N
that approximately maximizes the inner product with
\mathbf{X}
. Indeed, if we find a
\mathbf{X}^{\prime}
such that

\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle\geq 1-\varepsilon^{2}/2

then

\displaystyle\left\lVert\mathbf{X}-\mathbf{X}^{\prime}\right\rVert_{2}^{2}

\displaystyle\leq\left\lVert\mathbf{X}-\mathbf{X}^{\prime}\right\rVert_{F}^{2}

\displaystyle=\left\lVert\mathbf{X}\right\rVert_{F}^{2}+\left\lVert\mathbf{X}^{\prime}\right\rVert_{F}^{2}-2\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle

\displaystyle=2-2\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle\leq\varepsilon^{2}.

To do this, we make use of the
approximate matrix product
lemma, Lemma
5.14
. Then with the failure rate set to
\delta=1/10\lvert\mathcal{N}\rvert
and the accuracy parameter
\varepsilon
in the lemma set to
\varepsilon^{2}/\sqrt{n}
, we use

m=\Theta\left\lparen\frac{nsk}{\varepsilon^{4}}\log\frac{nk}{\varepsilon}\right\rparen

measurements to guarantee that for an
m\times n^{2}
i.i.d. Gaussian matrix
\mathbf{S}
and a net vector
\mathbf{X}^{\prime}\in\mathcal{N}

\Pr\left\{\left\lvert\left\langle\mathbf{A},\mathbf{X}^{\prime}\right\rangle-\left\langle\mathbf{S}\vc(\mathbf{A}),\mathbf{S}\vc(\mathbf{X}^{\prime})\right\rangle\right\rvert\leq\frac{\varepsilon^{2}}{\sqrt{n}}\left\lVert\mathbf{A}\right\rVert_{F}\left\lVert\mathbf{X}^{\prime}\right\rVert_{F}\right\}\geq 1-\frac{1}{10\left\lvert\mathcal{N}\right\rvert}.

Note that

\frac{\varepsilon^{2}}{\sqrt{n}}\left\lVert\mathbf{A}\right\rVert_{F}\left\lVert\mathbf{X}^{\prime}\right\rVert_{F}=\frac{\varepsilon^{2}}{\sqrt{n}}\cdot n\cdot 1=\varepsilon^{2}\sqrt{n}.

Furthermore,

\left\langle\mathbf{A},\mathbf{X}^{\prime}\right\rangle=\left\langle\mathbf{G}+\sqrt{n}\mathbf{X},\mathbf{X}^{\prime}\right\rangle\sim\mathcal{N}(\left\langle\sqrt{n}\mathbf{X},\mathbf{X}^{\prime}\right\rangle,\left\lVert\mathbf{X}^{\prime}\right\rVert_{F}^{2})=\mathcal{N}(\sqrt{n}\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle,1),

and a standard Gaussian is at most
O(\sqrt{\log(1/\delta)})
with probability at least

, we have by a union bound over the net that, with constant probability,

\displaystyle\left\langle\mathbf{S}\vc(\mathbf{A}),\mathbf{S}\vc(\mathbf{X}^{\prime})\right\rangle

\displaystyle=\left\langle\mathbf{A},\mathbf{X}^{\prime}\right\rangle\pm\varepsilon^{2}\sqrt{n}

\displaystyle=\sqrt{n}\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle\pm\left\lparen O(sk)\log\frac{nk}{\varepsilon}+\varepsilon^{2}\sqrt{n}\right\rparen

\displaystyle=\sqrt{n}\left\lparen\left\langle\mathbf{X},\mathbf{X}^{\prime}\right\rangle\pm 2\varepsilon^{2}\right\rparen

for all
\mathbf{X}^{\prime}\in\mathcal{N}
. Thus by rescaling

\mathbf{X}
and
\mathbf{X}^{\prime}

\mathbf{X}^{\prime}
such that

\left\lVert\mathbf{X}-\mathbf{X}^{\prime}\right\rVert_{2}\leq\varepsilon.\qed

5.3.2
Gaussian Noise Estimation Lower Bound

Theorem 5.16
.

Suppose that
\mathbf{S}
is a random
m\times(nd)
matrix such that, given
\mathbf{S}(\vc(\mathbf{A}))
for
\mathbf{A}=\sqrt{n}\mathbf{X}+\frac{1}{100}\mathbf{G}
for
s\times s
-sparse rank
k
matrix
\mathbf{X}
with
\left\lVert\mathbf{X}\right\rVert_{2}=1
and
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
, there is an algorithm which outputs an
s\times s
-sparse rank
k
matrix
\mathbf{B}
such that

\left\lVert\mathbf{A}-\mathbf{B}\right\rVert_{2}\leq\frac{1}{10}\left\lVert\mathbf{G}\right\rVert_{2}.

Then,
m=\Omega(nsk\log(n/sk))
.

Proof.

We follow the sparse recovery lower bound technique of
[
PW11
]
using the information capacity of a Gaussian channel. The techniques are essentially the same, so we only briefly outline their argument and the modifications that are necessary.

Consider a family
\mathcal{F}
of
sk
-sparse supports such that:

•

\lvert S\triangle S^{\prime}\rvert\geq sk
for
S\neq S^{\prime}\in\mathcal{F}

•

\Pr_{S\in\mathcal{F}}[i\in S]=sk/n
for all
i\in[n]

•

\log\lvert\mathcal{F}\rvert=\Omega(sk\log(n/sk))

which can be taken to be a random linear code in
[n/sk]^{sk}
with relative distance
1/2
.

We then define a communication game as follows. Alice first chooses a random
S\sim\mathcal{F}
. Then to construct a random rank
1
matrix
\mathbf{X}
, she chooses a random row
i\in[n]
and chooses a random sign vector supported on the support
S
on the
i
th row, and normalizes by
\sqrt{n/sk}
so that the resulting matrix
\mathbf{X}
has operator norm
\sqrt{n}
. She then sets
\mathbf{y}=\mathbf{S}(\vc(\mathbf{X}+\frac{1}{100}\mathbf{G}))
for
\mathbf{G}\sim\mathcal{N}(0,1)^{n\times n}
and sends
\mathbf{y}
to Bob. Bob performs the Gaussian noise estimation algorithm on
\mathbf{y}
to retrieve some
s\times s
sparse rank
k
matrix
\mathbf{B}
, rounds to a matrix
\mathbf{X}^{\prime}
in the set of possible matrices
\mathbf{X}
, and returns the support
S^{\prime}=\supp(\mathbf{X}^{\prime})
.

We WLOG assume that
\mathbf{S}
has orthonormal rows. Note that for any fixed matrix
\mathbf{V}
with Frobenius norm
1
,

\mathbf{E}_{\mathbf{X}}\left\langle\mathbf{X},\mathbf{V}\right\rangle^{2}=\frac{n}{sk}\mathbf{E}_{S\sim\mathcal{F}}\mathbf{E}_{i\sim[n]}\left[\sum_{j\in S}(\mathbf{e}_{i}^{\top}\mathbf{V}\mathbf{e}_{j})^{2}\right]=\frac{n}{sk}\frac{sk}{n^{2}}=\frac{1}{n}

while
\E\left\langle\mathbf{G},\mathbf{V}\right\rangle^{2}=\E_{x\sim\mathcal{N}(0,1)}x^{2}=1
. Thus, for
i\in[m]
, if
