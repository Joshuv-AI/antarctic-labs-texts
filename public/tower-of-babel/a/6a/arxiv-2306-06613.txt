Parameter-free version of Adaptive Gradient Methods for Strongly-Convex Functions
Deepak Gouda, Hassan Naveed, Salil KamathGeorgia Institute of TechnologyAtlanta, USA {deepakgouda, hnaveed3, skamath36}@gatech.edu

Abstract
The optimal learning rate for adaptive gradient methods applied to λ \lambda -strongly convex functions relies on the parameters λ \lambda and learning rate η \eta . In this paper, we adapt a universal algorithm along the lines of Metagrad, to get rid of this dependence on λ \lambda and η \eta . The main idea is to concurrently run multiple experts and combine their predictions to a “master" algorithm. This master enjoys O ⁡ ( d ​ log ⁡ T ) O(d\log T) regret bounds.

1
Introduction

Online convex optimization (OCO) is a widely recognized approach for representing sequential decision-making processes. The OCO algorithm operates in the following manner:

•

the learner selects an action
\mathbf{x}_{t}

•

an adversary chooses a loss function
f_{t}(\cdot)

•

the learner incurs a loss
f_{t}(\mathbf{x}_{t})

•

the learner updates its action based on this loss

The aim is to minimize regret, which is defined as the disparity between the cumulative loss suffered by the learner and that of the optimal action in retrospect
[
1
]
. This is defined as:

Regret=\sum_{t=1}^{T}f_{t}(\mathbf{x}_{t})-\min_{\mathbf{x}\in D}\sum_{t=1}^{T}f_{t}(\mathbf{x})

Several work has been done on this under various loss function settings. Among the most frequent are convex functions, exponentially concave functions and strongly convex functions. These leverage the slope of the function to alter the gradient update step in order to obtain sublinear regret bounds. OGD on convex functions achieves
O(\sqrt{T})
regret with step size decreasing by
1/\sqrt{T}

[
2
]
, and a
O(\log(T))
regret bound on strongly convex functions with a step-size of order
1/T

[
3
]
. Similarly, for exponentially concave functions, the ONS algorithm achieves a regret bound of
O(\log(T))
as well
[
3
]
.

Our proposed algorithm combines a variant of the meta algorithm described in
[
4
]
using strongly convex experts from a version of Adagrad described in
[
5
]
.

2
Related Work

Recent work on adaptive gradients set a parameter specific learning rate to help with sparse gradients, i.e, settings where we only have a few non-zero features. A popular method was Adagrad, which decays the learning rate faster for parameters with larger gradients
[
5
]
. This way, we have a larger step size for weights that have smaller magnitude. It still has a regret bound of the order
{O}(\sqrt{T})
similar to work by
[
1
]
, but this data dependent bound demonstrates better performance in practice.

The Adagrad algorithm without modification did not guarantee a
{O}(\log(T))
bound in strongly convex functions. This extension to the strongly convex case was made by
[
6
]
by one major change. First, they decayed the step size on the parameters using the sum of squared gradients, rather than taking an L2 norm of them. They also had a decay rate for the constant added by Adagrad numerical stability, but this did not result in any better bounds or performance.

At another front, there has been a push to create universal algorithms that can perform well for most function types. As previously mentioned, the type of alogrithm and learning rate strictly divided the type of functions into three main categories: convex, exp-concave, and strongly convex. It would be preferable to have algorithms that work for not only these three cases at once, but also everything in between. This influenced work on an algorithm called
MetaGrad
by
[
7
]
, which works for functions that satisfy the so called Bernstien condition. It consists of one master algorithm which spawns several experts. Each of these slaves has its own learning rate and employs a surrogate loss function which closely mimics the Online Newton Step (ONS). The master alogrithm combines the predictions from each of these slaves and passes down its gradients to them after incurring a loss. This approach only requires gradient information and achieves
O(\sqrt{T\log T\log T})
regret on convex and
O(d\log T)
on exponentially concave functions.

However, the
O(d\log T)
regret Metagrad implies on strongly convex functions has an
O(d)
gap from the optimal
O(\log T)
regret possible. This inspired work on
Maler
by
[
4
]
. The main idea was to run multiple learning algorithms for each of the three function classes in parallel. The master algorithm continued to track the best one on the fly. This spawned three times the number of experts as Metagrad, but enjoyed optimal regret bound on all three function classes. We borrow inspirations the learning algorithm employed by Maler on the strongly convex case and extend it to handle sparse gradients.

Setup

3.1
Notation

We denote
C\subseteq\mathbb{R}^{d}
to be our convex decision set. We let
\mathbf{x}_{t}\in C
be the learner’s decision at time step
t
. We denote our loss function at time step
t
to be
f_{t}(\cdot):C\rightarrow\mathbb{R}
. We let
\mathbf{g}_{t}
be the gradient of
f_{t}(\mathbf{x}_{t})
. We use
\lVert\cdot\rVert
to denote the 2-norm, and
\langle\cdot,\cdot\rangle
to denote the Euclidean inner product. We use boldface letters to denote vectors.

3.2
Assumptions and Definitions

We include two main assumptions akin to those from previous studies
[
4
]
.

Assumption 1:
The gradients of all loss functions
f_{1}(\cdot)\dots f_{T}(\cdot)
are bounded i.e.
\forall t\in[T],\forall\mathbf{x}\in C

\lVert\nabla f_{t}(\mathbf{x})\rVert\leq G
for some
G\in\mathbb{R}
.

Assumption 2:
The diameter of the decision set
C
is bounded i.e.
\forall\mathbf{x}_{1},\mathbf{x}_{2}\in C
,
\lVert\mathbf{x}_{1}-\mathbf{x}_{2}\rVert\leq D
for some
D\in\mathbb{R}
.

Definition 1: Strong Convexity
A function
f:C\rightarrow\mathbb{R}
is
\lambda
-strongly convex if
\forall\mathbf{x}_{1},\mathbf{x}_{2}\in C
,

f(\mathbf{x}_{1})\geq f(\mathbf{x}_{2})+\langle\nabla f(\mathbf{x}_{2}),\mathbf{x}_{1}-\mathbf{x}_{2}\rangle+\frac{\lambda}{2}\lVert\mathbf{x}_{1}-\mathbf{x}_{2}\rVert^{2}

Assumption 3:
All loss functions
f_{1}(\cdot)\dots f_{T}(\cdot)
are
\lambda
-strongly convex.

Definition 2: A-weighted norm

Let
A\in\mathbb{R}^{d\times d}
and let
\mathbf{x}\in\mathbb{R}^{d}
. We define the
A
-weighted norm to be the matrix norm
\lVert\mathbf{x}\rVert_{A}^{2}=\mathbf{x}^{\top}A\mathbf{x}=\sum_{i,j=1}^{d}A_{ij}\mathbf{x}_{i}\mathbf{x}_{j}

[
6
]
.

Definition 3: Weighted Projection

We define a weighted projection function onto the convex set
C
with respect to the
A
-weighted norm to be

\Pi_{C}^{A}(\mathbf{x}_{1})=\arg\min_{\mathbf{x}\in C}\lVert\mathbf{x}_{1}-\mathbf{x}\rVert^{2}_{A}

4
Algorithm

The algorithm draws inspiration from the strongly convex experts in Maler. It similarly follows a two hierarchical structure. At the lower level, we have a set of experts, each with their own learning rates
\eta
. Because we are only dealing with the strongly convex case, all of them use the same learning algorithm (Algorithm 2). At the higher level, we have a meta algorithm which tracks the best one using a tilted exponential weighted average
[
7
]
.

Input:

Grid of learning rates
\eta_{1},\eta_{2},\dots,\eta_{k}
and weights
\pi_{1}^{\eta_{1}},\pi_{1}^{\eta_{2}},\dots,\pi_{1}^{\eta_{k}}

Get prediction
\mathbf{x}_{t}^{\eta}
from Algorithm 2

Play
\mathbf{x}_{t}=\frac{\sum_{\eta}\pi_{t}^{\eta}\eta\mathbf{x}_{t}^{\eta}}{\sum_{\eta}\pi_{t}^{\eta}\eta}

Observe gradient
\mathbf{g}_{t}
and send
\mathbf{x}_{t},\mathbf{g}_{t}
to all experts

For all
\eta
, update weights according to

\pi_{t+1}^{\eta}=\frac{\pi_{t}^{\eta}\exp{\left(-s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)}}{\sum_{\eta}\pi_{t}^{\eta}\exp{\left(-s_{t}^{\eta}(\mathbf{x}_{t}^{\eta}\right))}}

Algorithm 1

Meta Algorithm

We define the surrogate loss function to be

s_{t}^{\eta}(\mathbf{x})=-\eta(\mathbf{x}_{t}-\mathbf{x})^{\top}\mathbf{g}_{t}+\eta^{2}G^{2}\lVert\mathbf{x}_{t}-\mathbf{x}\rVert^{2}

(1)

Note, by taking the second derivative of the surrogate loss function, we see that it is
\eta^{2}G^{2}
strongly convex.

Input:

\mathbf{v}_{0}=\mathbf{0}\in\mathbb{R}^{d}
,
\eta\in\mathbb{R}
,
\mathbf{x}_{1}^{\eta}=0
,
\delta>0

for

t=1\dots T

do

Send
\mathbf{x}_{t}^{\eta}
to Algorithm 1

Receive
\mathbf{x}_{t},\mathbf{g}_{t}
from Algorithm 1

\nabla s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})=\eta\mathbf{g}_{t}+2\eta^{2}G^{2}(\mathbf{x}_{t}^{\eta}-\mathbf{x}_{t})

\mathbf{v}_{t}=\mathbf{v}_{t-1}+\nabla s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\odot\nabla s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})

A_{t}=\text{diag}(\mathbf{v}_{t})+\delta I

\mathbf{x}_{t+1}^{\eta}=\Pi_{C}^{A_{t}}\left(\mathbf{x}_{t}^{\eta}-\alpha A^{-1}_{t}\nabla s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)
, where
\alpha=\frac{1}{4\eta^{2}}

end for

Algorithm 2

SC-Adagrad expert algorithm

Experts:
Each expert uses an adaptive algorithm with an update rule derived from the Adagrad for strongly convex function
[
6
]
. However, in contrast to the original Adagrad, this adaptation is on the gradients of the surrogate losses, rather than the
\mathbf{g}_{t}
incurred by a single learner. We maintain
\lceil\frac{1}{2}\log_{2}T\rceil
experts. For
i=0,1,2,...\frac{1}{2}\log_{2}T
, each expert is configured with:

\eta_{i}=\frac{2^{-i}}{5GD}

and

\pi_{1}^{\eta_{i}}=\frac{c}{3(i+1)(i+2)}

These values for
\eta
,
\pi
and
\alpha
were carefully chosen to satisfy certain criteria which will help in proving regret bounds.

\displaystyle R_{T}^{Meta}=\sum_{t=1}^{T}s_{t}(\mathbf{x}_{t})-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})

5.3
Expert Regret

The regret of the expert algorithm is defined as the difference of the surrogate losses of the expert and the surrogate losses of the best decision in hindsight. It is given by:

\displaystyle R_{T}^{Expert}=\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}^{*})

(5.3.1)

Let us denote
\nabla s_{t}=\nabla s_{t}^{\eta}(\mathbf{x}^{\eta})

\displaystyle||\mathbf{x}_{t+1}^{\eta}-\mathbf{x}^{*}||_{A_{t}}

\displaystyle=||\mathbf{x}_{t}^{\eta}-\mathbf{x}^{*}||^{2}_{A_{t}}+\alpha^{2}||A_{t}^{-1}\nabla s_{t}||^{2}_{A_{t}}-2\alpha(\mathbf{x}_{t}^{\eta}-\mathbf{x}^{*})^{\top}A_{t}(A_{t}^{-1}\nabla s_{t})

5.4
Total Regret

The total regret is given by

\displaystyle R_{T}

\displaystyle=\sum_{t=1}^{T}f_{t}(\mathbf{x}_{t})-f_{t}(\mathbf{x}^{*})

\displaystyle\leq\sum_{t=1}^{T}\mathbf{g}_{t}^{\top}(\mathbf{x}_{t}-\mathbf{x}^{*})-\frac{\mu}{2}||\mathbf{x}_{t}-\mathbf{x}^{*}||^{2}

(from the definition of surrogate loss function)

\displaystyle\leq\sum_{t=1}^{T}\frac{s_{t}^{\eta}(\mathbf{x}_{t})-s_{t}^{\eta}(\mathbf{x}^{*})}{\eta}+\eta\sum_{t=1}^{T}G^{2}||\mathbf{x}_{t}-\mathbf{x}^{*}||-\frac{\mu}{2}\sum_{t=1}^{T}||\mathbf{x}_{t}-\mathbf{x}^{*}||^{2}

Remark :
In
[
6
]
the authors claim that

\displaystyle\sum_{i=1}^{d}\log\Bigg(\frac{||\nabla s_{1:T,i}||^{2}+\delta_{T,i}}{\delta_{1,i}}\Bigg)=O(\log T)

And hence, the overall regret is
O(\log T)
for strongly-convex functions. Even with the monotonic-decay factor, the term

\displaystyle\frac{||\nabla s_{1:T,i}||^{2}}{\delta_{1,i}}\leq\frac{TG^{2}}{\delta_{1,i}}

Hence, the regret term is bound by
O(d\log(T))
rather than
O(\log(T))
. This result hasn’t been explained in the paper which seems like a weakness on the results. Hence, we take state the final regret bound as
O(d\log(T))
.

By taking a Metagrad like approach to Adagrad, we can have created a parameter free version of Strongly Convex Adagrad. This enjoys
O(d\log T)
regret bound in strongly convex functions. If every expert employs SAdam

, the regret bound can be improved to
O(logT)
instead. This work can be extended to make parameter free versions of other algorithms such as RMSProp or Adam.

Appendix A
Proof of Meta Regret

This proof follows closely from the proof of the meta regret bound in
[
4
]
. We define a potential function

\displaystyle\Phi(T)=\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)

We have

\displaystyle\Phi(T+1)-\Phi(T)

\displaystyle=\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\exp\left(-s_{T+1}^{\eta}\left(\mathbf{x}_{T+1}^{\eta}\right)-1\right)

\displaystyle\leq\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\eta(\mathbf{x}_{T+1}-\mathbf{x}_{T+1}^{\eta})^{\top}\mathbf{g}_{t}

\displaystyle=(\mathbf{a}_{T}\mathbf{x}_{T+1}-\mathbf{b}_{T})^{\top}\mathbf{g}_{t}

where

\displaystyle\mathbf{a}_{T}

\displaystyle=\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\eta

\displaystyle\mathbf{b}_{T}

\displaystyle=\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\eta\mathbf{x}_{T+1}^{\eta}

By definition,

\displaystyle\mathbf{x}_{T+1}

\displaystyle=\frac{\sum_{\eta}\pi_{T+1}^{\eta}\eta\mathbf{x}_{T+1}^{\eta}}{\sum_{\eta}\pi_{T+1}^{\eta}\eta}

\displaystyle=\frac{\sum_{\eta}\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T+1}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\eta\mathbf{x}_{T}^{\eta}}{\sum_{\eta}\pi_{1}^{\eta}\exp(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta}))\eta}

\displaystyle=\frac{\mathbf{b}_{T}}{\mathbf{a}_{T}}

This implies that
\Phi(T+1)-\Phi(T)\leq 0
and
1=\Phi(0)\geq\Phi(1)\geq\dots\Phi(T)\geq 0
. Then for any
\eta

\displaystyle\ln\left(\pi_{1}^{\eta}\exp\left(-\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\right)\right)

\displaystyle\leq 0

\displaystyle\implies\ln\left(\frac{1}{\pi_{1}^{\eta}}\right)+\sum_{t=1}^{T}s_{t}^{\eta}(\mathbf{x}_{t}^{\eta})\geq 0

By definition,
\pi_{1}^{\eta_{i}}=\frac{c}{3(i+1)(i+2)}
, where
c=1+\frac{1}{1+k}
,
i\in\{0,\dots,k\}
and
k=\left\lceil\frac{1}{2}\log_{2}(T)\right\rceil
. Therefore,

\displaystyle\ln\left(\frac{1}{\pi_{1}^{\eta}}\right)

\displaystyle=\ln\left(\frac{3(i+1)(i+2)}{c}\right)

\displaystyle\leq\ln\left(3(1+k)(2+k)\right)

\displaystyle\leq\ln\left(\left(\sqrt{3}\left(3+\frac{1}{2}\log_{2}(T)\right)\right)^{2}\right)

\displaystyle=2\ln\left(\sqrt{3}\left(3+\frac{1}{2}\log_{2}(T)\right)\right)
