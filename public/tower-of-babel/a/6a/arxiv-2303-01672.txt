Self-supervised Learning for Gastrointestinal Pathologies Endoscopy Image Classification with Triplet Loss
1 st Tai NGUYEN-D-P

Abstract
Recently, the amount of GI tract datasets is introduced more and more by gathering from contests and challenges. The most common task needs to solve that is to classify images from the GI tract into various classes. However, the contributions of the existing approaches exhibit lots of limitations. In this paper, we aim to develop a computer-aided diagnosis system to classify the pathological findings in endoscopy images, the system can classify some common pathologies including polyps, esophagitis, and ulcerative – colitis. To evaluate the proposed work, we use the public dataset which is Hyper–Kvasir instead of gathering the data. The key idea of our system is to develop self-supervised learning based on the Barlow Twins framework with a downstream task which is an endoscopy image classification integrated with triplet loss and focal loss functions. The self-supervision framework and focal loss function are used to overcome class-imbalanced data, while the triplet loss function is to tackle the domain-specific properties in endoscopy images which are inter/intra-class problems. An extensive experimental study on the pathological finding images in the Hyper–Kvasir dataset has shown that our proposed system is in general better than the compared methods, whereas using a simple neural network model. This means the proposed system can be used efficiently and capable of accurately for the classification of pathology images in the GI tract.

Background

To comprehensively understand the proposed work, we present the principles of deep learning theories which are needed for our system.

III-A
1
Convolutional Neural Network

A convolutional neural network usually takes a tensor that has 3 dimensions as an input, it represents a natural image with
H\times W\times 3
corresponding to
H\times W
resolution and 3 channels (red, green, blue). The image then sequentially goes through a series of processing, each of which is usually called a layer. There are 3 common layers including the convolution layer, the pooling layer, and the fully-connected layer. Assuming that the problem at hand is image classification, and the mission of the neural network is to categorize the input image by
C
given classes. Typically, we expect that the predictive output is presented as a probability mass function, so we can set the processing at the last layer as a softmax transfer function. In the case of classification problems, the cross-entropy loss is often used as the loss function. The cross-entropy loss measures the distance between the ground truth
y
and the prediction
\hat{y}
as the format of vectors
C
-dimension:

z=-\sum_{i=1}^{C}y_{i}\times log(\hat{y}_{i})

(1)

III-A
2
Focal loss

Loss functions are mathematical equations that calculate how far the predictions deviate (output) from the actual values (ground truth). The model produces a higher loss value when it is making a significant error, whereas a lower loss value implies that the predictions are rather accurate. As described in the Equation (
1
), the classification model usually uses the cross-entropy as the category loss function to learn the discrimination. Class-imbalance problem inherits bias during the learning process. The majority class samples dominate the loss function and gradient descent, which leads to the weights updating in the direction of the model becoming more easier in predicting the majority class while putting less emphasis on the minority classes. In this respect, the Balanced Cross-Entropy loss can tackle this problem, which adds a weighting factor (
\alpha
in Equation (
2
)) to each class,
\alpha
is in the range of
[0,1]
. Additionally,
\alpha
could be the inverse class frequency or a hyper-parameter that is determined by cross-validation.

L_{BCE}=-\sum_{i=1}^{i=n}\alpha_{i}\times log_{b}(\hat{y}_{i})

(2)

The loss contribution of well-classified (easy) samples overwhelms the contribution of misclassified (hard) samples and dominates the gradient. Although the Balanced Cross-Entropy loss function can overcome the issue of class-imbalance data, it cannot distinguish between hard and easy examples. In 2017, the Facebook AI research team proposed a new way to compute the category loss which is called Focal loss
[
5
]
. In general, Focal loss is similar to cross-entropy loss, and a modulating factor
-(1-p_{t})^{\gamma}
is added:

FL(p_{t})=-(1-p_{t})^{\gamma}\times log(p_{t})

(3)

in which:

•

p_{t}
: is the probability distribution,
p_{t}\in[0,1]
.

•

\gamma
: is the focusing parameter. With a larger focusing parameter, the loss is very small even at confidence levels that used to produce some amount of loss.

III-A
3
Triplet loss

Based on the advancements in deep learning that have made it possible to learn a similarity measure for a set of images using a deep metric learning network. The main idea of a metric learning network is to map visually similar images onto nearby locations in an embedding manifold, whereas visually dissimilar images are far away from each other. In short, the objective of metric learning is to generate relative distance between inputs. In training a metric learning network, the deep features are learned to produce well-discriminative features with compact intra-product variance and well-separated inter-product differences, which are key to having better visual search engines. During the training phase, the metric learning networks are trained similarly to the conventional deep learning networks but with a different loss function that explicitly pushes similar images together in latent space and pulls dissimilar images far away from each other. Triplet loss
[
6
]
is by far the most popular and widely used loss function for metric learning. The idea of Triplet loss is to take in a triplet of deep features consisting of anchor, positive, and negative. The anchor and positive have similar product labels, whereas the negative has dissimilar product labels and tunes the network so that the distance between the anchor and positive is less than the distance between the anchor and negative by at least a distance margin:

L=max(d(a,p)-d(a,n)+m,0)

(4)

where
a
,
p
, and
n
are the feature representation of the anchor, positive, and negative samples respectively;
d()
is the distance function to measure the difference of two vectors;
m
is a fixed value to indicate the margin of the minimum value of the distance between
d(a,p)
and
d(a,n)
.

III-A
4
Barlow Twins

The objective of the self-supervised learning pretext task is to learn a good representation of the input so that it can subsequently be used for supervised tasks. Typically, computer vision pipelines that employ self-supervised learning involve performing two tasks, a pretext task, and a real (downstream) task:

1.

The real (downstream) task can be anything like a classification or detection task, with insufficient annotated data samples.

2.

The pretext task is the self-supervised learning task solved to learn visual representations, to use the learned representations or model weights obtained in the process, for the downstream task.

Self-supervised visual representation learning methods usually exhibit the inherent problem that is the collapse, where the network learns the representations are not ideal and cannot be used for this task of similarity learning. In other words, the model cannot learn the discriminative features in the downstream task. The proposed Barlow Twins
[
4
]
is an objective function that naturally avoids such collapse by measuring the cross-correlation matrix between the outputs of two identical networks fed with distorted versions of a sample, and making it as close to the identity matrix as possible. This causes the representation vectors of distorted versions of a sample to be similar while minimizing the redundancy between the components of these vectors. The workflow of the Barlow Twins framework follows these steps:

1.

Producing two distorted views for all images of a batch
X
sampled from a dataset. The distorted views are obtained via a distribution of data augmentations
T
.

2.

Two batches of distorted views
Y^{A}
and
Y^{B}
are then fed to a function
f
, typically a deep network with trainable parameters
\theta
, producing batches of embeddings
Z^{A}
and
Z^{B}
respectively.

3.

To simplify notations,
Z^{A}
and
Z^{B}
are assumed to be mean-centered along the batch dimension, such that each unit has to mean output 0 over the batch.

4.

An innovative loss function
L_{BT}
:

L_{BT}\triangleq\sum_{i}(1-C_{ii})^{2}+\lambda\sum_{i}\sum_{j\neq i}C_{ij}^{2}

(5)

where
\lambda
is a positive constant trading of the importance of the first and second terms of the loss, and
C
is the cross-correlation matrix computed between the outputs of the two identical networks along the batch dimension:

C_{ij}\triangleq\frac{\sum_{b}z^{A}_{b,i}z^{B}_{b,j}}{\sqrt{\sum_{b}(z^{A}_{b,i})^{2}}\sqrt{\sum_{b}(z^{B}_{b,j})^{2}}}

(6)

where
b
indexes batch samples and
i
,
j
index the vector dimension of the network’s outputs.

Proposed SsLTF system

Figure 4
:
A schematic illustration of the training process of the proposed SsLTF.

The proposed SsLTF tries to overcome the class-imbalanced dataset problem and enhance the discriminative power of the deeply learned features. Training the SsLTF involves two basic tasks of a self-supervised learning framework in the field of computer vision including:

III-C
1
Pretext task

The pretext task is to train the neural network which is inspired by the Barlow Twins
[
4
]
framework, which is shown at the top part in Figure
4
. The inputs are pathology-finding images without labeled information. The input image has the size of
224\times 224\times 3
corresponding to the image resolution is
224\times 224
and RGB color channel. The image then is augmented by two different ways to pass into the neural network. To train the
Encoder
, we used the feature extraction (backbone) of the ResNet-50 model. The feature representations are produced by the
Encoder
which are the tensors with a size of
[1,2048]
. Then, the feature representations are passed into the
Projector
to generate the deep feature embeddings. The
Projector
is constructed by 2 fully-connected layers to translate these features to another embedding space. The size of feature embedding vectors depends on the output size of the last fully-connected layer, where we fixed a value of 2048.

Although there are two
Encoder
modules and two
Projector
modules in Figure
4
, they are only one
Encoder
and one
Projector
because
Encoder
modules have the same architecture and are shared weights, the similar happens with the
Projector
modules. The output of the neural network is the empirical cross-correlation between the feature embeddings of the same input image. The training strategy is to minimize the difference between the output and an identity matrix as shown in Equation (
5
). The loss value is used to update the parameters in both
Encoder
and
Projector
by a
Weight Optimizer
module.

III-C
2
Downstream task

The downstream task is to fine-tune the network from the Pretext task for the classification problem, which is shown at the bottom part in Figure
4
. At this point, a triplet loss function is combined with a Focal loss function to produce the total loss. During the training, there are mainly several processes in the classification task consisting of:

•

The input is the image with the pathology label annotation which has the size of
224\times 224\times 3
corresponding to the image resolution is
224\times 224
and RGB color channel.

•

Produced the
Feature Representations
by passing the input into the feature extraction (backbone) ResNet-50 which was shared weights from the Pretext task. Since using the same architecture as in the Pretext task, the
Feature Representations
have the size of
[1,2048]
.

•

Selected the triplet mining mode is
Online
, where a
Triplet Validation
module is to verify the right triplet from available triplets in the training batch.

•

Another branch of the
Feature Representations
is passed into the multi-layer perceptron (MLP) head which consists of 3 hidden layers to learn the feature discrimination. The output of the MLP head is a tensor with a size of
[1,6]
corresponding to 6 pathology classes. Commonly, this tensor is transformed to a probability distribution format by a
Softmax
function.

•

Probability Distribution
is compared with
Ground truth
label to produce a category loss value (
L_{category}
). Instead of using the cross-entropy loss function, we need a special loss function to overcome the imbalanced classes problem, where the Focal loss
[
5
]
is chosen.

•

After validation, the
Triplet features
are satisfactory and used to produce the triplet loss value (
L_{triplet}
) following the Equation (
4
).

•

Total Loss
is a weight-sum of loss values from triplet loss (
L_{triplet}
) and Focal loss (
L_{category}
), where
\alpha
is a value to indicate how much the triplet loss value impacts the total loss. During the training phase, we fixed the value of
\alpha=2
.

L_{total}=L_{category}+\alpha\times L_{triplet}

IV-A

Experimental settings

The Pretext and Downstream tasks were trained separately, once we had pre-trained the ResNet-50 model with a pretext task, we moved on to the Downstream task. There were mainly two experiments on the Downstream task that consists of using the pre-trained weights from the Pretext task and the ImageNet. The pre-trained weights were loaded and stored in the neural network model ResNet-50 before running the training process. Furthermore, we conducted re-producing the study of Borgli et al.
[
3
]
to verify their results and to make a fair comparison regarding the same context of the number of classes. The workflow of experiments followed this:

1.

Training and evaluation of the Pretext task.

2.

Training and evaluation of the Downstream task using the pre-trained weights from the ImageNet dataset.

3.

Training and evaluation of the Downstream task using the pre-trained weights from the Pretext task.

4.

Re-producing the compared method of Borgli
[
3
]
in the context of 6 pathology classes.

The NVIDIA TESLA P100 GPU and CUDA 11.0 with 16GB memory were used for the training acceleration during the training phases. The limitation of GPU memory led to we only can use “tiny” neural networks such as ResNet-50. Stochastic gradient descent (SGD) is chosen for optimization with momentum = 0.9, weight_decay = 0.0001. The initialized learning rate was set to 0.001 and was dropped by 0.2 after every 10 epochs. All training steps used a batch size of 96 samples. We applied the
Early Stopping
features that enable the training to be automatically stopped when a performance metric has stopped improving or is insignificant. It means the
Early Stopping
was can reduce the training time, where the neural network reached the global minimum and starts over-fitting. The process of setting the hyper-parameters was the same in all experiments.

V
Conclusion

In this paper, we introduced a new automatic classification system of endoscopy images based on deep learning techniques. Different from the existing studies, our system focused on classifying the various pathology findings of 3 common diseases including
polyps, esophagitis
and
ulcerative-colitis
. The proposed system is called SsLTF which consists of two stages: (1) The Pretext task was based on Barlow Twins self-supervised learning; (2) The Downstream task was an image classification pipeline. The goal Pretext task was to produce better feature representations, which was useful to overcome the class imbalance problem in the Downstream task. During the training phase, the classification pipeline in the Downstream task was customized to deal with two problems. First, Triplet loss was used to deal with the inherent challenge which was the inter/intra-class problem in the endoscopy images. Second, taking the advances of Focal loss to reduce the impact of the majority classes to the total loss in the context of the class-imbalance problem.
The results of SsLTF verified that the proposed system was capable of accurately classifying GI diseases. The Downstream task (classification pipeline) achieved higher performance than that of more powerful convolutional neural network approaches. Despite our approach’s simplicity, the produced F1-score of the SsLTF was competitive with recent related work based on the Hyper-Kvasir dataset. This means the proposed work can be used efficiently for the classification of pathology findings in the GI tract.
