Abstract
For a given linear code 𝒞 {\mathcal{C}} of length n n over GF ⁡ ( q ) {\mathrm{GF}}(q) and a nonzero vector 𝐮 {\mathbf{u}} in GF ​ ( q ) n {\mathrm{GF}}(q)^{n} , Sun, Ding and Chen defined an extended linear code 𝒞 ¯ ​ ( 𝐮 ) \overline{{\mathcal{C}}}({\mathbf{u}}) of 𝒞 {\mathcal{C}} , which is a generalisation of the classical extended code 𝒞 ¯ ​ ( − 𝟏 ) \overline{{\mathcal{C}}}(-{\mathbf{1}}) of 𝒞 {\mathcal{C}} and called the second kind of an extended code of 𝒞 {\mathcal{C}} (see arXiv:2307.04076 and arXiv:2307.08053). They developed some general theory of the extended codes 𝒞 ¯ ​ ( 𝐮 ) \overline{{\mathcal{C}}}({\mathbf{u}}) and studied the extended codes 𝒞 ¯ ​ ( 𝐮 ) \overline{{\mathcal{C}}}({\mathbf{u}}) of several families of linear codes, including cyclic codes, projective two-weight codes, nonbinary Hamming codes, and a family of reversible MDS cyclic codes. The objective of this paper is to investigate the extended codes 𝒞 ¯ ​ ( 𝐮 ) \overline{{\mathcal{C}}}({\mathbf{u}}) of MDS codes 𝒞 {\mathcal{C}} over finite fields. The main result of this paper is that the extended code 𝒞 ¯ ​ ( 𝐮 ) \overline{{\mathcal{C}}}({\mathbf{u}}) of an MDS [ n , k ] [n,k] code 𝒞 {\mathcal{C}} remains MDS if and only if the covering radius ρ ⁡ ( 𝒞 ⊥ ) = k \rho(\mathcal{C}^{\bot})=k and the vector 𝐮 {\mathbf{u}} is a deep hole of the dual code 𝒞 ⟂ {\mathcal{C}}^{\perp} . I
Introduction

Let
n
be a positive integer and
q
be a power of a prime.
An
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
is a
k
-dimensional subspace of
{\mathrm{GF}}(q)^{n}
with minimum
Hamming distance
d
. The minimum distance
d
of
a linear code
\mathcal{C}
is upper bounded by
d\leq n-k+1
, which is called the
Singleton bound
.
If
d=n-k+1
, then
\mathcal{C}
is called a
maximum distance separable
(MDS) code. Namely, an MDS code has the greatest error correcting capability
when its length and dimension are fixed. MDS codes have wide applications in communication systems, cryptography ad data storage systems. There are many known constructions for MDS codes, including
the
generalized Reed-Solomon
(GRS) codes and extended GRS codes
[
5
]
,
and those from arcs in projective geometry
[
4
]
, circulant matrices
[
6
]
, and Hankel matrices
[
7
]
.

In coding theory, there are several methods to construct new linear codes with interesting parameters and properties from old ones. Among them are the shortening, puncturing, augmenting and extending techniques. There are different ways to extend an
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
into an
[n+1,k,d^{\prime}]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
. Two of them are outlined below.

For a given
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
, the first extending method goes as follows.
Select a
k\times n
generator matrix
G
of
{\mathcal{C}}
and a
k\times 1
vector
{\mathbf{g}}
in
{\mathrm{GF}}(q)^{k}
.
Then construct a
k\times(n+1)
matrix

\displaystyle\widetilde{G}(G,{\mathbf{g}})=(G|{\mathbf{g}}).

(1)

Let
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
be the linear code with generator matrix
\widetilde{G}(G,{\mathbf{g}})
. By definition,
the extended code
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
has parameters
[n+1,k,\tilde{d}]
, where
\tilde{d}=d
or

\tilde{d}=d+1
. It is easy to notice the following:

•

The exact value of
\tilde{d}
depends on both
G
and
{\mathbf{g}}
.

•

The weight distribution of the extended code
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
depends on both
G
and
{\mathbf{g}}
.

•

Two extended codes
\widetilde{{\mathcal{C}}}(G_{1},{\mathbf{g}})
and
\widetilde{{\mathcal{C}}}(G_{2},{\mathbf{g}})
may not be equivalent
for a fixed nonzero vector
{\mathbf{g}}
, where
G_{1}
and
G_{2}
are two
k\times n
generator matrices of
{\mathcal{C}}
.

There are a huge number of choices of a generator matrix
G
of
{\mathcal{C}}
and
q^{k}-1
choices of a nonzero vector
{\mathbf{g}}
.
Hence, by this extending technique a given
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
could be extended
into a huge number of codes
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
. Seroussi and Roth
[
8
]
proved that a GRS code can be extended by this extending technique while preserving the MDS property if and only if the resulting extended code is a GRS code or extended GRS code.
This extending technique is not well studied in the
literature and has been applied only to MDS codes and a few other types of linear
codes. The extended GRS codes and Roth-Lempel codes are such extended codes. To distinguish these
extended codes
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
from other types of extended codes of
{\mathcal{C}}
, we call those codes
the
first kind of extended codes
.

For a given
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
, the second extending method goes as follows
[
11
]
.
Let
{\bf u}=(u_{1},u_{2},\ldots,u_{n})\in{\mathrm{GF}}(q)^{n}
be any nonzero vector. Define an
[n+1,k,\overline{d}]
code
\overline{\mathcal{C}}({\bf u})
over
{\mathrm{GF}}(q)
by

\overline{\mathcal{C}}({\bf u})=\bigg\{(c_{1},\ldots,c_{n},c_{n+1}):(c_{1},\ldots,c_{n})\in\mathcal{C},c_{n+1}=\sum_{i=1}^{n}u_{i}c_{i}\bigg\},

(2)

where
\overline{d}=d
or
\overline{d}=d+1
. All extended codes
\overline{\mathcal{C}}(a{\bf 1})
with
a\neq 0
are called the standardly extended codes and all the other extended codes
\overline{\mathcal{C}}({\bf u})
with
{\bf u}\neq a{\bf 1}
for all
a\in{\mathrm{GF}}(q)^{*}
are called nonstandardly extended codes.
It is easy to observe the following:

•

If
{\bf u}\in\mathcal{C}^{\bot}
(i.e., the dual of
{\mathcal{C}}
), then
c_{n+1}=0
for all codewords

{\mathbf{c}}=(c_{1},\ldots,c_{n+1})
of
\overline{{\mathcal{C}}}({\mathbf{u}})
.
In this case,
\overline{\mathcal{C}}({\bf u})
is not interesting and is said to be trivial.

•

The extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
depends on
{\mathbf{u}}
but does not require a selected generator matrix of
{\mathcal{C}}
.

•

\overline{{\mathcal{C}}}({\mathbf{u}}_{1})
and
\overline{{\mathcal{C}}}({\mathbf{u}}_{2})
may have different minimum distances or different weight distributions.

The classical extended codes
\overline{{\mathcal{C}}}(-{\mathbf{1}})
of a number of types of linear codes were studied in the literature. Recently, nonstandardly extended codes
\overline{{\mathcal{C}}}({\mathbf{u}})
of linear codes were investigated in
[
11
]
. To distinguish the extended codes
\overline{{\mathcal{C}}}({\mathbf{u}})
of
{\mathcal{C}}
from those extended codes

\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
, we called these
\overline{{\mathcal{C}}}({\mathbf{u}})
the
second kind of extended codes

of
{\mathcal{C}}
.

For a given
[n,k,d]
linear code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
, the two kinds of extended codes
\overline{{\mathcal{C}}}({\mathbf{u}})

and
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
are different but related in the following senses.
We have the following remarks.

•

For each
\overline{{\mathcal{C}}}({\mathbf{u}})
, there is a vector
{\mathbf{g}}
such that
\overline{{\mathcal{C}}}({\mathbf{u}})=\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})

for each generator matrix
G
.

•

For a given
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
, where
G
is a
k\times n
generator matrix of
{\mathcal{C}}
, there are
q^{n-k}

vectors
{\mathbf{u}}
in
{\mathrm{GF}}(q)^{n}
such that
\overline{{\mathcal{C}}}({\mathbf{u}})=\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
, as
{\mathrm{Rank}}(G)={\mathrm{Rank}}(G|{\mathbf{g}})=k\leq n
. These
{\mathbf{u}}
are the solutions to the system of equations
G{\mathbf{u}}^{T}={\mathbf{g}}
.

Hence, both extending techniques yield the same set of
[n+1,k]
linear codes when they are applied to an

[n,k]
linear code
{\mathcal{C}}
.

The first kind of extended codes of only a few families of MDS and other types of codes were studied in the literature.
Relatively speaking, the second kind of extended codes of more families of linear codes were investigated in the
literature (see, e.g.,
[
10
,
11
]
). By definition, it looks harder to determine the minimum distance of an extended
code
\widetilde{{\mathcal{C}}}(G,{\mathbf{g}})
than the minimum distance of an extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
in general.

This paper is motivated by the following open problem:

Open Problem 1
.

Is there a vector
{\mathbf{u}}\in{\mathrm{GF}}(q)^{n}
such that the extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
remains MDS for a given MDS code
{\mathcal{C}}
of length
n
over
{\mathrm{GF}}(q)
? What are such vectors
{\mathbf{u}}\in{\mathrm{GF}}(q)^{n}
if they exist?

In this paper, we will investigate the second kind of extended codes
\overline{{\mathcal{C}}}({\mathbf{u}})
of MDS codes
{\mathcal{C}}
regarding Open Problem
1
. The rest of the paper is arranged as follows. In Section
II
, we will recall some required concepts and results on the extended codes and (extended) GRS codes over finite fields. In Section
III
, we will establish a relation between the extended codes
\overline{{\mathcal{C}}}({\mathbf{u}})
of MDS codes and deep holes of the dual codes
{\mathcal{C}}^{\perp}
, which is the main result of this paper. As applications of this main result, we will investigate the second kind of extended codes of the GRS codes and extended GRS codes and also give partial answers to the open problem above for these special families of MDS codes in Sections
IV
and
V

As another application of the main result, we will determine the covering radii of several families of MDS codes in Section

Recall the definition of the extended code

in (

.

II-B

The GRS codes and extended GRS codes

In this section, we recall the GRS codes and the extended GRS codes as well as their basic properties.

Definition 1
.

For a positive integer
k
, let

{\mathrm{GF}}(q)[x]_{k}=\{f(x)\in{\mathrm{GF}}(q)[x]|\mbox{ deg}(f(x))\leq k-1\},

which is a
{\mathrm{GF}}(q)
-linear space of dimension
k
. Take
{\bf a}=(\alpha_{1},\alpha_{2},\ldots,\alpha_{n})\in{\mathrm{GF}}(q)^{n}
, where
\alpha_{1},\ldots,\alpha_{n}
are pairwise distinct,
{\bf v}=(v_{1},v_{2},\ldots,v_{n})\in({\mathrm{GF}}(q)^{*})^{n}
,
and
k\leq n\leq q
. The
generalized Reed-Solomon code

(GRS code for short) is defined by

\mathcal{C}_{k}({\bf a},{\bf v})=\{(v_{1}f(\alpha_{1}),v_{2}f(\alpha_{2}),\ldots,v_{n}f(\alpha_{n}))|\ f(x)\in{\mathrm{GF}}(q)[x]_{k}\}.

It is well known that

\mathcal{C}_{k}({\bf a},{\bf v})
is an
[n,k,n-k+1]
MDS code over
{\mathrm{GF}}(q)
. When
v_{i}=1
for all
1\leq i\leq n,
the code
\mathcal{C}_{k}({\bf a},{\bf 1})
is called a
Reed-Solomon code
.
It is easily seen that
\mathcal{C}_{k}({\bf a},{\bf v})
has generator matrix

G_{k}=\left(\begin{array}[]{cccc}v_{1}\alpha_{1}^{0}&v_{2}\alpha_{2}^{0}&\ldots&v_{n}\alpha^{0}_{n}\\
v_{1}\alpha_{1}^{1}&v_{2}\alpha_{2}^{1}&\ldots&v_{n}\alpha^{1}_{n}\\
\vdots&\vdots&\ddots&\vdots\\
v_{1}\alpha_{1}^{k-1}&v_{2}\alpha_{2}^{k-1}&\ldots&v_{n}\alpha^{k-1}_{n}\end{array}\right)

(3)

and parity check matrix

H_{n-k}=\left(\begin{array}[]{cccc}w_{1}\alpha_{1}^{0}&w_{2}\alpha_{2}^{0}&\ldots&w_{n}\alpha^{0}_{n}\\
w_{1}\alpha_{1}^{1}&w_{2}\alpha_{2}^{1}&\ldots&w_{n}\alpha^{1}_{n}\\
\vdots&\vdots&\ddots&\vdots\\
w_{1}\alpha_{1}^{n-k-1}&w_{2}\alpha_{2}^{n-k-1}&\ldots&w_{n}\alpha^{n-k-1}_{n}\end{array}\right),

(4)

where these
w_{i}
are given in the next lemma.

Lemma 2
.

[
2
]

\mathcal{C}_{k}^{\bot}({\bf a},{\bf v})=\mathcal{C}_{n-k}({\bf a},{\bf w})
, where
{\bf w}=(w_{1},w_{2},\ldots,w_{n})
and for
i=1,2,\ldots,n
,

{w_{i}}=\frac{1}{v_{i}\prod_{1\leq j\leq n,j\neq i}(\alpha_{i}-\alpha_{j})}.

(5)

Lemma
2
tells us that the dual code of
\mathcal{C}_{k}^{\bot}({\bf a},{\bf v})
is also a GRS code with parameters
[n,n-k,k+1]
.

Definition 2
.

By including the point at infinity
\infty=(0,0,\ldots,0,1)\in{\mathrm{GF}}(q)^{k}
, the
extended GRS code
(EGRS code for short) is defined as follows:

\mathcal{C}_{k}({\bf a},{\bf v},\infty)=\{(v_{1}f(\alpha_{1}),v_{2}f(\alpha_{2}),\ldots,v_{n}f(\alpha_{n}),f_{k-1})|\mbox{ for all }f(x)\in{\mathrm{GF}}(q)[x]_{k}\},

where
f_{k-1}
is the coefficient of
x^{k-1}
in
f(x)
.

It is well known that
\mathcal{C}_{k}({\bf a},{\bf v},\infty)
is an
[n+1,k,n-k+2]
MDS code over
{\mathrm{GF}}(q)
. Furthermore,

\mathcal{C}_{k}({\bf a},{\bf v},\infty)
has generator matrix
G_{k,\infty}
and parity check matrix
H_{n+1-k,\infty}
, where

G_{k,\infty}:=(G_{k}|\infty^{T})=\left(\begin{array}[]{ccccc}v_{1}\alpha_{1}^{0}&v_{2}\alpha_{2}^{0}&\ldots&v_{n}\alpha_{n}^{0}&0\\
v_{1}\alpha_{1}^{1}&v_{2}\alpha_{2}^{1}&\ldots&v_{n}\alpha^{1}_{n}&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
v_{1}\alpha_{1}^{k-2}&v_{2}\alpha_{2}^{k-2}&\ldots&v_{n}\alpha_{n}^{k-2}&0\\
v_{1}\alpha_{1}^{k-1}&v_{2}\alpha_{2}^{k-1}&\ldots&v_{n}\alpha_{n}^{k-1}&1\end{array}\right)

(6)

and

H_{n+1-k,\infty}:=\left(\begin{array}[]{ccccc}w_{1}\alpha_{1}^{0}&w_{2}\alpha_{2}^{0}&\ldots&w_{n}\alpha^{0}_{n}&0\\
w_{1}\alpha_{1}^{1}&w_{2}\alpha_{2}^{1}&\ldots&w_{n}\alpha^{1}_{n}&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
w_{1}\alpha_{1}^{n-k-1}&w_{2}\alpha_{2}^{n-k-1}&\ldots&w_{n}\alpha^{n-k-1}_{n}&0\\
w_{1}\alpha_{1}^{n-k}&w_{2}\alpha_{2}^{n-k}&\ldots&w_{n}\alpha^{n-k}_{n}&-1\end{array}\right),

(7)

where
G_{k}
was defined in (
3
).
Using our earlier notation, we have

\mathcal{C}_{k}({\bf a},{\bf v},\infty)=\widetilde{\mathcal{C}_{k}({\bf a},{\bf v})}(G_{k},\infty^{T}).

Hence,
\mathcal{C}_{k}({\bf a},{\bf v},\infty)
is a first kind of extended code of
\mathcal{C}_{k}({\bf a},{\bf v})
.
The following result is well known.

Lemma 3
.

[
9
, Lemma 2.1]

\mathcal{C}_{k}^{\bot}({\bf a},{\bf v},\infty)=\mathcal{C}_{n+1-k}({\bf a},{\bf w},\infty)
, where
{\bf w}=(w_{1},w_{2},\ldots,w_{n})
and
{w_{i}}
was given in (

.

By Lemma

III
The extended codes and deep holes of MDS codes

In this section, we will establish the relationship between extended codes and deep holes of MDS codes.
Before doing this, we need to recall the definition of deep holes of a linear code.

The
covering radius
of a code
\mathcal{C}
, denoted by
\rho(\mathcal{C})
, is the maximum distance from any vector in
{\mathrm{GF}}(q)^{n}
to the nearest codeword in
{\mathcal{C}}
. A
deep hole
is a vector achieving the covering radius. Before presenting our main result, we need to recall the following well-known characterisation of covering radius of a linear code in terms of a generator matrix.

Lemma 4
.

[
12
, Lemma II.7]
Let
G
denote a generator matrix of an
[n,k]
MDS code
\mathcal{C}
. Then the covering radius
\rho(\mathcal{C})=n-k
if and only if there exists a vector
{\bf x}\in{\mathrm{GF}}(q)^{n}
such that the
(k+1)\times n
matrix
\bigg(\frac{G}{{\bf x}}\bigg)
generates an
[n,k+1]
MDS code.

The determination of deep holes for a given linear code is a hard problem in general. Below we provide a general characterization of deep holes of MDS codes with parity check matrices. The following lemma is a generalisation of
[
13
, Proposition 2]
, which was stated only for the Reed-Solomon codes.

Lemma 5
.

(1)
[
12
, Lemma II. 2]
Let
\mathcal{C}
be an
[n,k]
linear code with parity check matrix
H
. The vector
{\bf u}
is a deep hole of
\mathcal{C}
if and only if the vector
H{\bf u}^{T}
can not be written as a linear combination of any
(\rho(\mathcal{C})-1)
columns of
H
.

(2) Suppose
G
is a generator matrix of an
[n,k]
MDS code
\mathcal{C}
over
{\mathrm{GF}}(q)
with covering radius
\rho=n-k
. Then
{\mathbf{u}}\in{\mathrm{GF}}(q)^{n}
is a deep hole of
\mathcal{C}
if and only if

G^{\prime}=\bigg(\frac{G}{{\mathbf{u}}}\bigg)

generates an MDS code.

Proof.

(2). (
\Longrightarrow
). Suppose that
{\mathbf{u}}
is a deep hole of
\mathcal{C}
, we need to show that
G^{\prime}
is a generator matrix for another MDS code. Equivalently, we need to show that any
k+1
columns of
G^{\prime}
are linearly independent.

Assume there exist
k+1
columns of
G^{\prime}
which are linearly dependent. Without loss of generality, assume that the first
k+1
columns of
G^{\prime}
are linearly dependent. Consider the submatrix consisting of the intersection of the first
k+1
rows and
k+1
columns of
G^{\prime}
. Hence there exist
a_{1},\ldots,a_{k}\in{\mathrm{GF}}(q)
, not all zero, such that

(u_{1},\ldots,{u}_{k+1})=a_{1}{\bf r}_{1,k+1}+\cdots+a_{k}{\bf r}_{k,k+1},

where
{\mathbf{u}}=(u_{1},\ldots,u_{n})
and
{\bf r}_{i,k+1}
is the vector consisting of the first
k+1
elements of
i
-th row of
G
for
1\leq i\leq k
. Let
{\mathbf{g}}=a_{1}{\bf r}_{1}+\cdots+a_{k}{\bf r}_{k}\in\mathcal{C}
, where
{\bf r}_{i}
is the
i
-th row of
G
for
1\leq i\leq k
. We have

d({\mathbf{u}},{\mathbf{g}})\leq n-(k+1)<\rho,

which is a contradiction with the assumption that
{\mathbf{u}}
is a deep hole of
\mathcal{C}
.

(
\Longleftarrow
). Now suppose
G^{\prime}
is a generator matrix for an MDS code, i.e., any
k+1
columns of
G^{\prime}
are linearly independent. We need to show that
d({\mathbf{u}},\mathcal{C})=n-k
.

Assume that
d({\mathbf{u}},\mathcal{C})<n-k
. Equivalently, there exist
a_{1},\ldots,a_{k}\in{\mathrm{GF}}(q)
such that
{\mathbf{u}}
and
{\mathbf{g}}=a_{1}{\bf r}_{1}+\cdots+a_{k}{\bf r}_{k}\in\mathcal{C}
have more than
k
common coordinates, where
{\bf r}_{i}
is the
i
-th row of
G
for
1\leq i\leq k
. Without loss of generality, assume that the first
k+1
coordinates of
{\mathbf{u}}
and
{\mathbf{g}}
are the same. Consider the submatrix consisting of the first
k+1
columns. Since the rank of the matrix is less than
k+1
, thus the first
k+1
columns of
G^{\prime}
are linearly dependent, which contradicts the assumption.
This completes the proof.
∎

We are now ready to present our main result, which gives an answer to Open Problem
1

Theorem 6
.

Let
\mathcal{C}
be an
[n,k]
MDS code over
{\mathrm{GF}}(q)
. Then for any
{\bf u}\in{\mathrm{GF}}(q)^{n}
, the extended code
\overline{\mathcal{C}}({\bf u})

\rho(\mathcal{C}^{\bot})=k

{\bf u}
is a deep hole of the dual code
\mathcal{C}^{\bot}

Proof.

Suppose that the code
\mathcal{C}
has generator and parity check matrices
G
and
H
, respectively.
By Lemma
1
, the generator and parity check matrices for the code
\overline{\mathcal{C}}({\bf u})

(G~G{\bf u}^{T})
and

\left(\begin{array}[]{cccc}H&{\bf 0}^{T}\\
{\bf u}&-1\end{array}\right).

Then the code
\overline{\mathcal{C}}({\bf u})

1.

The submatrix consisting of the vector
(0,\ldots,0,-1)^{T}
and any
n-k
columns from
\bigg(\frac{H}{\bf u}\bigg)
is nonsingular.

2.

The submatrix consisting of any
n+1-k
columns from
\bigg(\frac{H}{\bf u}\bigg)
is nonsingular.

(
\Longrightarrow
). Assume that
\overline{\mathcal{C}}({\bf u})
is MDS with parameters
[n+1,k,n+2-k]
.
Since
\mathcal{C}
is an
[n,k,n-k+1]
MDS code, the condition 1) holds.
Let
\mathcal{D}
be the code generated by
\bigg(\frac{H}{\bf u}\bigg)
. From 2), the dual code of
\mathcal{D}
has parameters
[n,k-1,n-k+2]
and hence
\mathcal{D}
is also MDS with parameters
[n,n+1-k,k]
.
From Lemma
4
,
\rho(\mathcal{C}^{\bot})=n-(n-k)=k
. From Lemma
5
,
{\bf u}
is a deep hole of

(

Given a vector
{\bf f}=(f_{1},f_{2},\ldots,f_{n})\in{\mathrm{GF}}(q)^{n}

f(x)=\sum_{i=1}^{n}f_{i}\prod_{j=1,j\neq i}^{n}\frac{x-\alpha_{j}}{\alpha_{i}-\alpha_{j}}\in{\mathrm{GF}}(q)[x],

{\bf a}=(\alpha_{1},\alpha_{2},\ldots,\alpha_{n})\in{\mathrm{GF}}({q})^{n}

The Lagrange interpolating polynomial is the unique polynomial in
{\mathrm{GF}}(q)[x]

n

with

{\bf f}=(f(\alpha_{1}),f(\alpha_{2}),\ldots,f(\alpha_{n}))

We say that two functions

and

are equivalent over
{\mathrm{GF}}(q)
if and only if there exist

such that

[

, then the result holds because each induced submatrix is Vandermonde and
\alpha_{i}
are distinct. Then we consider the other case, without loss of generality we need to compute the determinant of the matrix:

B=\left(\begin{array}[]{ccccc}1&1&\ldots&1&0\\
\alpha_{1}&\alpha_{2}&\ldots&\alpha_{n+1-k}&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n-k-1}&\alpha_{2}^{n-k-1}&\ldots&\alpha^{n-k-1}_{n+1-k}&0\\
\alpha_{1}^{n-k}&\alpha_{2}^{n-k}&\ldots&\alpha^{n-k}_{n+1-k}&-1\\
\alpha_{1}^{n+1-k}&\alpha_{2}^{n+1-k}&\ldots&\alpha^{n+1-k}_{n+1-k}&\delta\\
\end{array}\right).

Let
A_{i}
be the coefficient of
x^{i}
in the polynomial
\mbox{det}(B(x))
, where

B(x)=\left(\begin{array}[]{ccccc}1&1&\ldots&1&1\\
\alpha_{1}&\alpha_{2}&\ldots&\alpha_{n+1-k}&x\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n+1-k}&\alpha_{2}^{n+1-k}&\ldots&\alpha^{n+1-k}_{n+1-k}&x^{n+1-k}\\
\end{array}\right).

Then
\mbox{det}(B)=\delta A_{n+1-k}-A_{n-k}
. Note that

\sum_{i=0}^{n+1-k}A_{i}x^{i}=\prod_{1\leq i<j\leq n+1-k}(\alpha_{j}-\alpha_{i})\prod_{i=1}^{n+1-k}(x-\alpha_{i}).

Thus
A_{n+1-k}\neq 0
,
A_{n-k}=-A_{n+1-k}\sum_{i=1}^{n+1-k}\alpha_{i}
and
\mbox{det}(B)\neq 0
if and only if
\sum_{i=1}^{n+1-k}\alpha_{i}\neq-\delta.

(2) When
{{\mathbf{g}}}=(f_{\pi}(\alpha_{1}),\ldots,f_{\pi}(\alpha_{n}),\delta)
, it suffices to prove that the submatrix consisting of any
(n+2-k)
columns of the following matrix is nonsingular:

\bigg(\frac{H_{n+1-k,\infty}}{{\mathbf{g}}}\bigg)=\left(\begin{array}[]{ccccc}w_{1}\alpha_{1}^{0}&w_{2}\alpha_{2}^{0}&\ldots&w_{n}\alpha^{0}_{n}&0\\
w_{1}\alpha_{1}^{1}&w_{2}\alpha_{2}^{1}&\ldots&w_{n}\alpha^{1}_{n}&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
w_{1}\alpha_{1}^{n-k-1}&w_{2}\alpha_{2}^{n-k-1}&\ldots&w_{n}\alpha^{n-k-1}_{n}&0\\
w_{1}\alpha_{1}^{n-k}&w_{2}\alpha_{2}^{n-k}&\ldots&w_{n}\alpha^{n-k}_{n}&-1\\
\frac{w_{1}}{\alpha_{1}-\pi}&\frac{w_{1}}{\alpha_{1}-\pi}&\ldots&\frac{w_{n}}{\alpha_{n}-\pi}&\delta\\
\end{array}\right).

(14)

If those columns from (
14
) do not containing the vector
(0,\ldots,0,-1,\delta)^{T}
, then the result holds because each induced submatrix is Vandermonde and
\alpha_{i}
are distinct. Then we consider the other case, without loss of generality we need to compute the determinant of the matrix:

B=\left(\begin{array}[]{ccccc}\frac{1}{\alpha_{1}-\pi}&\frac{1}{\alpha_{2}-\pi}&\ldots&\frac{1}{\alpha_{n+1-k}-\pi}&\delta\\
1&1&\ldots&1&0\\
\alpha_{1}&\alpha_{2}&\ldots&\alpha_{n+1-k}&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n-k-1}&\alpha_{2}^{n-k-1}&\ldots&\alpha^{n-k-1}_{n+1-k}&0\\
\alpha_{1}^{n-k}&\alpha_{2}^{n-k}&\ldots&\alpha^{n-k}_{n+1-k}&-1\\
\end{array}\right).

Then

\prod_{i=1}^{n+1-k}\frac{1}{\alpha_{i}-\pi}\mbox{det}(B)=\left|\begin{array}[]{ccccc}1&1&\ldots&1&\delta\\
\alpha_{1}&\alpha_{2}&\ldots&\alpha_{n+1-k}&\pi\delta\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n-k}&\alpha_{2}^{n-k}&\ldots&\alpha^{n-k}_{n+1-k}&\pi^{n-k}\delta\\
\alpha_{1}^{n+1-k}&\alpha_{2}^{n+1-k}&\ldots&\alpha^{n+1-k}_{n+1-k}&\pi^{n+1-k}\delta-1\\
\end{array}\right|.

Let
\prod_{i=1}^{n+1-k}\frac{1}{\alpha_{i}-\pi}\mbox{det}(B)=\delta\mbox{det}(B_{1})+\mbox{det}(B_{2})
, where

B_{1}=\left(\begin{array}[]{ccccc}1&\ldots&1&1\\
\alpha_{1}&\ldots&\alpha_{n+1-k}&\pi\\
\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n-k}&\ldots&\alpha^{n-k}_{n+1-k}&\pi^{n-k}\\
\alpha_{1}^{n+1-k}&\ldots&\alpha^{n+1-k}_{n+1-k}&\pi^{n+1-k}\\
\end{array}\right)\mbox{ and }B_{2}=\left(\begin{array}[]{ccccc}1&\ldots&1&0\\
\alpha_{1}&\ldots&\alpha_{n+1-k}&0\\
\vdots&\ddots&\vdots&\vdots\\
\alpha_{1}^{n-k}&\ldots&\alpha^{n-k}_{n+1-k}&0\\
\alpha_{1}^{n+1-k}&\ldots&\alpha^{n+1-k}_{n+1-k}&-1\\
\end{array}\right).

Note that

\mbox{det}(B_{1})=\prod_{1\leq i<j\leq n+1-k}(\alpha_{j}-\alpha_{i})\prod_{i=1}^{n+1-k}(\pi-\alpha_{i})

and

\mbox{det}(B_{2})=-\prod_{1\leq i<j\leq n+1-k}(\alpha_{j}-\alpha_{i}).

Therefore
\mbox{det}(B)\neq 0
if and only if
\delta\cdot\prod_{i=1}^{n+1-k}(\pi-\alpha_{i})\neq 1
.
This completes the proof.

As an application of Theorem

VI-A

Covering radii of projective Reed-Solomon codes

In this subsection, we will determine the covering radii of some projective Reed-Solomon codes.
Determining the covering radius of a given linear code over a finite field is generally a challenging task. The covering radius is a basic geometric parameter of a code and has been widely investigated for distinguished families of error-correcting codes, including Reed-Solomon codes and Reed-Muller codes, see
[
1
]
. For an
[n,k]
MDS code
{\mathcal{C}}
, it is known that the covering radius
\rho({\mathcal{C}})
is either
n-k
or
n-k-1

[
1
]
.
In
[
12
]
it is mentioned that the covering radius of a
q
-ary
[n,k]
Reed-Solomon code with length
n<q+1
is known to be
n-k
.

In the case
n=q+1
, these
q
-ary
[n,k]
Reed-Solomon codes are referred to as
projective Reed-Solomon codes
, denoted as
\mbox{PRS}(k)
. Now let’s consider the projective Reed-Solomon codes. By Lemma
3
, we have
\mbox{PRS}(k)^{\bot}=\mbox{PRS}(q+1-k)
as in this case
w_{i}=-1
in (
5
) for all
i
. This result is derived from the fact that
\prod_{1\leq j\leq n,j\neq i}(\alpha_{i}-\alpha_{j})=-1
, which is precisely the derivative of the polynomial
x^{q}-x
at the element
\alpha_{i}
. It was informed in
[
12
]
that for
k\in\{1,q,q+1\}
the covering radius of
\mbox{PRS}(k)
is
q-k+1
. In the case of
k=q-1
, the covering radius of
\mbox{PRS}(k)
is
1
. However, for
2\leq k\leq q-2
, the covering radius of
\mbox{PRS}(k)
is currently open and conjectured as follows.

Conjecture 2
.

[
12
, Conjecture I.2 ]
For
2\leq k\leq q-2
, the covering radius of
\mbox{PRS}(k)
is:

\displaystyle\begin{cases}q-k+1\mbox{~ if }q\mbox{ is even and }k\in\{2,q-2\},\\
q-k\mbox{ ~~~~~~otherwise}.\\
\end{cases}

The above conjecture is true if
k\geq\left\lfloor\frac{q-1}{2}\right\rfloor
from the work of Seroussi and Roth
[
8
]
. The following theorem gives a partial answer to Conjecture
2
.

Theorem 17
.

(1) When
k\in\{2,q-2\}
, then the covering radius of
\mbox{PRS}(k)
is equal to
q-k+1
if and only if
q
is even.

(2) When
3\leq k\leq q-3
, if the covering radius
\rho(\mbox{PRS}(k))=q-k
, then the set
{\mathrm{GF}}(q)
is not a
(q,k,\delta)
-set in
{\mathrm{GF}}(q)
for any
\delta\in{\mathrm{GF}}(q)
, namely for each
\delta\in{\mathrm{GF}}(q)
, there exist
k
distinct elements of
{\mathrm{GF}}(q)
whose sum is exactly
\delta
.

Proof.

(1) If
k=2
, then
{\mathrm{GF}}(q)
is a
(q,2,0)
-set in
{\mathrm{GF}}(q)
if and only if
q
is even. Theorem
14
tells us that
\rho(\mbox{PRS}(3)^{\bot})=\rho(\mbox{PRS}(q-2))=3=(q+1)-(q-2)
.
If
k=q-2
, then
{\mathrm{GF}}(q)
is a
(q,q-2,0)
-set in
{\mathrm{GF}}(q)
if and only if
q
is even due to the identity
\sum_{x\in{\mathrm{GF}}(q)}x=0
. By Theorem
14
,
\rho(\mbox{PRS}(q-1)^{\bot})=\rho(\mbox{PRS}(2))=q-1=(q+1)-2
.

(2) Suppose that
\rho(\mbox{PRS}(k))=q-k
. By Theorem
6
,
\overline{\text{PRS}(q+1-k)}(\mathbf{u})
is not an MDS code.
By Lemma
12
, the set
{\mathrm{GF}}(q)
is not a
(q,q-k,\delta)
-set in
{\mathrm{GF}}(q)
for any
\delta\in{\mathrm{GF}}(q)
. So
{\mathrm{GF}}(q)
is also not a
(q,k,-\delta)
-set. The result follows from the fact that the argument holds for any arbitrary choice of
\delta
in
\text{GF}(q)
.
This completes the proof.∎

From
[
8
]
, Conjecture
2
holds for
k\geq\left\lfloor\frac{q-1}{2}\right\rfloor
. Namely
\rho(\mbox{PRS}(k))=q-k
when
\left\lfloor\frac{q-1}{2}\right\rfloor\leq k<q-2

Corollary 18

When
\left\lfloor\frac{q-1}{2}\right\rfloor\leq k<q-2

k
distinct elements of
{\mathrm{GF}}(q)

VII
Summary and concluding remarks

The main contributions of this paper are summarized as follows.

•

For an MDS
[n,k]
code
{\mathcal{C}}
, we proved that its extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
for a vector
{\mathbf{u}}

is still MDS if and only if
\rho(\mathcal{C}^{\bot})=k
and and
{\mathbf{u}}
is a deep hole of the dual code
{\mathcal{C}}^{\perp}
(see Theorem
6
).
This is the main result of this paper.

•

With the help of known results on deep holes of the GRS codes, we determined all vectors
{\mathbf{u}}
such that
the extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
of the GRS code
{\mathcal{C}}
is still MDS in some cases (see Corollary
11
).

•

With the help of known results on deep holes of the GRS codes, we determined some vectors
{\mathbf{u}}
such that the extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
of the EGRS code
{\mathcal{C}}
is still MDS in some cases (see Theorem
16
).

•

We determined the covering radius of
\mathcal{C}_{k}({\bf a},{\bf 1},\infty)^{\perp}
under certain conditions (see Theorem
14
).

•

We proved that the covering radius of
\mbox{PRS}(k)
is equal to
q-k+1
when
q
is even and
k\in\{2,q-2\}
(see Theorem
17
).
This provides a partial answer to Conjecture
2
.

•

We settled the covering radii of two families of MDS cyclic codes (see Theorems
21
and
23
).

It was proved in
[
11
]
that every linear code
{\mathcal{C}}^{\prime}
of length
n+1
with minimum distance
at least 2 is permutation-equivalent to an extended code
\overline{{\mathcal{C}}}({\mathbf{u}})
for some vector
{\mathbf{u}}
and some
linear code
{\mathcal{C}}
of length
n
over the same finite field. This shows the importance of the extending techniques in
coding theory. However, the determination of the minimum distance of
\overline{{\mathcal{C}}}({\mathbf{u}})
is very hard in most cases,
even if the weight distribution of
{\mathcal{C}}
is known. For example, the minimum distance of
\overline{{\mathcal{C}}}({\mathbf{u}})
is
either 3 or 4 when
{\mathcal{C}}
is a Hamming code over
{\mathrm{GF}}(q)
for
q>2
. But it is open for which
{\mathbf{u}}
’s the minimum
distance of the extended nonbinary Hamming code is exactly 4
[
11
]
. This hardness may explain why there are very limited results on extended linear codes in the literature.

Given an MDS
[n,k]
code
{\mathcal{C}}
over
{\mathrm{GF}}(q)
and a vector
{\mathbf{u}}\in{\mathrm{GF}}(q)^{n}
,
\overline{{\mathcal{C}}}({\mathbf{u}})
is an MDS code if and only
\rho(\mathcal{C}^{\bot})=k
and
{\mathbf{u}}
is a deep hole of
{\mathcal{C}}^{\perp}
according to Theorem
6
. However, determining the deep holes of MDS codes is a very hard problem. Hence, Open Problem 1 for MDS codes is very hard in general. For instance, it is open if
\overline{{\mathcal{C}}}(-{\mathbf{1}})
is MDS for many MDS codes
{\mathcal{C}}
in a family of MDS codes
[
10
]
.
Determining the covering radii of MDS codes is also a hard problem in general.
It would be good if the conjectures presented in this paper could be proved or disproved.
