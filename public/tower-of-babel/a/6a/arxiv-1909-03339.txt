On the complexity of counting feedback arc sets
Kévin Perrot

Abstract
In this note we study the computational complexity of feedback arc set counting problems in directed graphs, highlighting some subtle yet common properties of counting classes. Counting the number of feedback arc sets of cardinality k k and the total number of feedback arc sets are # ​ 𝖯 {\mathsf{\#P}} -complete problems, while counting the number of minimum feedback arc sets is only proven to be # ​ 𝖯 {\mathsf{\#P}} -hard. Indeed, this latter problem is # ⋅ 𝖮𝗉𝗍𝖯 ⁡ [ log ⁡ 𝗇 ] {\mathsf{\#\!\cdot\!OptP[\log n]}} -complete, hence if it belongs to # ​ 𝖯 {\mathsf{\#P}} then 𝖯 = 𝖭𝖯 {\mathsf{P}}={\mathsf{NP}} .

Complexity of counting feedback vertex sets

There is a straightforward polynomial parsimonious reduction
from counting feedback arc sets
to counting feedback vertex sets in a digraph.
A
feedback vertex set
(FVS) of a digraph

is a subset
of vertices intersecting every cycle of

The reduction, as noted in
