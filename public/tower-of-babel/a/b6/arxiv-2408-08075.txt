Independent Policy Mirror Descent for Markov Potential Games: Scaling to Large Number of Players
Pragnya Alatur *, Anas Barakat *, Niao He

Abstract
Markov Potential Games (MPGs) form an important sub-class of Markov games, which are a common framework to model multi-agent reinforcement learning problems. In particular, MPGs include as a special case the identical-interest setting where all the agents share the same reward function. Scaling the performance of Nash equilibrium learning algorithms to a large number of agents is crucial for multi-agent systems. To address this important challenge, we focus on the independent learning setting where agents can only have access to their local information to update their own policy. In prior work on MPGs, the iteration complexity for obtaining ε \varepsilon -Nash regret scales linearly with the number of agents N N . In this work, we investigate the iteration complexity of an independent policy mirror descent (PMD) algorithm for MPGs. We show that PMD with KL regularization, also known as natural policy gradient, enjoys a better N \sqrt{N} dependence on the number of agents, improving over PMD with Euclidean regularization and prior work. Furthermore, the iteration complexity is also independent of the sizes of the agents’ action spaces.

Introduced by the seminal work of

A major challenge in MARL is to deal with the so-called curse of multi-agents in which the size of the joint action space scales exponentially with the number of agents.
Given the ever-growing scale of real-world multi-agent systems such as transportation networks, social networks and autonomous vehicles, scalability of MARL algorithms to these large-scale systems involving a large number of agents poses a fundamental challenge.

Preliminaries

Markov Game.
We consider a discounted infinite time horizon Markov Game
\Gamma=\left\langle\mathcal{N},\mathcal{S},(\mathcal{A}_{i})_{i\in\mathcal{N}},P,(r_{i})_{i\in\mathcal{N}},\rho,\gamma\right\rangle

[
18
]
where:

•

\mathcal{N}\triangleq\{1,\cdots,N\}
with
N\geq 2
is the set of players
3
3

3

We use agent and player interchangeably throughout this work.
,

•

\mathcal{S}
is a finite set of states
4
4

4

Extension to infinite countable or even continuous state space is possible under additional technical assumptions such as boundedness of the reward and potential functions.
,

•

\mathcal{A}_{i}
is a finite set of actions for each
i\in\mathcal{N}
. We denote by
\mathcal{A}\triangleq\times_{i\in\mathcal{N}}\mathcal{A}_{i}
the set of joint actions,

•

P:\mathcal{S}\times\mathcal{A}\to\Delta(\mathcal{S})
is the Markov transition kernel, where we use throughout this paper the notation
\Delta(\mathcal{S})
for the set of probability distributions over the set
\mathcal{S}
,

•

r_{i}:\mathcal{S}\times\mathcal{A}\to{{\mathbb{R}}}
is the reward function of agent
i\in\mathcal{N}
,

•

\rho\in\Delta(\mathcal{S})
is an initial distribution over states,

•

\gamma\in(0,1)
is a discount factor .

Policies.
For each
i\in\mathcal{N}
, denote by
\pi_{i}:\mathcal{S}\to\Delta(\mathcal{A}_{i})
the policy of agent
i
and
\Pi^{i}
the set of all possible Markov stationary policies for agent
i\in\mathcal{N}\,.
We denote by
\pi=(\pi_{i})_{i\in\mathcal{N}}
the joint policy.
We use the notation
\Pi\triangleq\Large{\times}_{i\in\mathcal{N}}\Pi^{i}
for the set of joint Markov stationary policies.

In a Markov game, the agents’ interaction with the environment unfolds as follows: At each time step
t\geq 0
, the agents observe a shared state
s_{t}\in\mathcal{S}
and choose a joint action
a_{t}=(a_{t,i})_{i\in\mathcal{N}}
according to their joint policy
\pi^{(t)}
, i.e. for every
i\in\mathcal{N},a_{t,i}
is sampled according to
\pi_{i}^{(t)}(\cdot|s_{t})
. Each agent
i\in\mathcal{N}
receives a reward
r_{i}(s_{t},a_{t})
. Then the game proceeds by transitioning to a state
s_{t+1}
drawn from the distribution
P(s_{t},a_{t})\,.

Occupancy measures and distribution mismatch coefficients.

For any joint policy
\pi\in\Pi,
we define the state occupancy measure
d_{\rho}^{\pi}
for every state
s\in\mathcal{S}
by
d_{\rho}^{\pi}(s)=(1-\gamma)\sum_{t=0}^{\infty}\gamma^{t}\mathbb{P}_{\rho,\pi}(s_{t}=s)\,.
Similarly to prior work
[
5
]
, we introduce distribution mismatch coefficients to quantify the difficulty for learning agents to explore in a Markov game. In particular, we define for any distribution
\rho\in\Delta(\mathcal{S})
and any policy
\pi\in\Pi
, the distribution mismatch coefficient
\kappa_{\rho}\triangleq\sup_{\pi\in\Pi}\|\frac{d_{\rho}^{\pi}}{\rho}\|_{\infty}
as well as its minimax version
\tilde{\kappa}_{\rho}\triangleq\inf_{\nu\in\Delta(\mathcal{S})}\sup_{\pi\in\Pi}\|\frac{d_{\rho}^{\pi}}{\nu}\|_{\infty}\,,
where the division is to be understood componentwise in both cases. Notice that
\tilde{\kappa}_{\rho}\leq\min(\kappa_{\rho},|\mathcal{S}|)\,.

Value functions.

For each joint policy
\pi\in\Pi,
and each
i\in\mathcal{N}
, define the state-action value function
Q_{i}^{\pi}:\mathcal{S}\times\mathcal{A}\rightarrow{{\mathbb{R}}}
for each
s\in\mathcal{S},a\in\mathcal{A}
by

Q_{i}^{\pi}(s,a)\triangleq\mathbb{E}_{\pi}\left[\sum_{t=0}^{\infty}\gamma^{t}r_{i}(s_{t},a_{t})|s_{0}=s,a_{0}=a\right]\,.

We also define the value function
V_{i}^{\pi}:\mathcal{S}\to{{\mathbb{R}}}
for each
s\in\mathcal{S}
by
V_{i}^{\pi}(s)\triangleq\sum_{a\in\mathcal{A}}\pi(a|s)Q_{i}^{\pi}(s,a)\,.

For any initial state distribution
\rho
and any policy
\pi\in\Pi
, we use the notation
V_{i}^{\pi}(\rho)\triangleq\mathbb{E}_{s\sim\rho}[V_{i}^{\pi}(s)]\,.

Nash equilibria.

For any
\varepsilon\geq 0
, a joint policy
\pi=(\pi_{i})_{i\in\mathcal{N}}\in\Pi
is an
\varepsilon
-approximate Nash equilibrium for the game
\Gamma
if for every
i\in\mathcal{N}
and every
\pi_{i}^{\prime}\in\Pi^{i}
,

V_{i}^{\pi_{i},\pi_{-i}}(\rho)\geq V_{i}^{\pi_{i}^{\prime},\pi_{-i}}(\rho)-\varepsilon
.
When
\varepsilon=0
, such a policy
\pi
from which no agent has an incentive to deviate unilaterally, is called a Nash equilibrium policy.

Markov Potential Game.
A Markov game
\Gamma
is a Markov Potential Game (MPG) if there exists a function
\phi:\mathcal{S}\times\mathcal{A}\to{{\mathbb{R}}}
s.t. for any
i\in\mathcal{N}
, and any policies
(\pi_{i}^{\prime},\pi_{-i}),\pi\in\Pi
,

V_{i}^{\pi^{\prime}_{i},\pi_{-i}}(\rho)-V_{i}^{\pi_{i},\pi_{-i}}(\rho)=\Phi^{\pi^{\prime}_{i},\pi_{-i}}(\rho)-\Phi^{\pi_{i},\pi_{-i}}(\rho),

(1)

where
\Phi^{\pi}(\rho)\triangleq\mathbb{E}_{s_{0}\sim\rho,\pi}\left[\sum_{t=0}^{\infty}\gamma^{t}\phi(s_{t},a_{t})\right]
is the so-called
total potential function
induced by the function
\phi\,.

We denote by
\phi_{\max}\triangleq\max_{s\in\mathcal{S},a\in\mathcal{A}}|\phi(s,a)|\,.

The identical-interest case is an important particular case of this definition. In this case in which all the reward functions are identical, it can be easily seen that the total potential function is the value function of any of the players.
Beyond this important case, conditions to obtain MPGs with non-identical rewards were identified in
[
15
,
11
,
24
]
.

Remark III.1
.

The definition of MPGs we consider coincides with the definitions used in
[
24
,
23
]
.
Compared to other works
[
11
,
5
]
, our definition requires the total potential function to have a cumulative discounted sum form with a function
\phi
. Such a sum structure naturally connects MPGs to their historical parent, the (stateless) potential game. Notice that this definition also captures the identical-interest setting in the same way.
We will also comment later on about the consequences of this definition in our results.

IV
Independent Policy Mirror Descent

Inspired by a line of works
[
10
,
21
,
22
]
for the single-agent setting, we extend the Policy Mirror Descent (PMD) algorithm to the multi-agent setting for MPGs.
Then we discuss two instantiations of PMD with Euclidean and KL regularizations respectively.

We start by defining a central quantity for independent learning in MPGs:
The averaged Q-value
\bar{Q}_{i}^{\pi}:\mathcal{S}\times\mathcal{A}_{i}\to{{\mathbb{R}}}
for any agent
i\in\mathcal{N}
and policy
\pi\in\Pi
defined as follows:

\bar{Q}_{i}^{\pi}(s,a_{i})\triangleq{{\mathbb{E}}}_{a_{-i}\sim\pi_{-i}(\cdot|s)}[Q_{i}^{\pi}(s,a_{i},a_{-i})],\forall s\in\mathcal{S},a_{i}\in\mathcal{A}_{i}\,.

For each agent
i\in\mathcal{N}
and each state
s\in\mathcal{S}
, starting from an initial policy
\pi_{i}^{(1)}\in\Delta(\mathcal{A}_{i})^{\mathcal{S}}
, independent PMD for MPGs unfolds iteratively as follows:

\pi_{i,s}^{(t+1)}\in\underset{\pi_{i,s}\in\Delta(\mathcal{A}_{i})}{\mathrm{argmax}}\left\{\langle\bar{Q}_{i,s}^{\pi^{(t)}},\pi_{i,s}\rangle-\frac{1}{\eta}D_{\psi}(\pi_{i,s},\pi_{i,s}^{(t)})\right\}\,,

(PMD)

where we use the shorthand notations
\pi_{i,s}^{(t)}=\pi_{i}^{(t)}(\cdot|s)
and
\pi_{i,s}=\pi_{i}(\cdot|s)
, where
\eta

is a positive step size,
\bar{Q}_{i,s}^{\pi^{(t)}}\in\mathbb{R}^{|\mathcal{A}_{i}|}
is a vector containing average state-action values for
\pi^{(t)}
at state
s
, and
D_{\psi}
is the Bregman divergence induced by a mirror map
\psi:\dom\psi\to{{\mathbb{R}}}
such that
\Delta(\mathcal{A}_{i})\subset\dom\psi\,,
i.e. for any
p,q\in\Delta(\mathcal{A}_{i}),

D_{\psi}(p,q)=\psi(p)-\psi(q)-\langle\nabla\psi(q),p-q\rangle\,,

where we suppose throughout this paper that the function
\psi
is of Legendre type, i.e. strictly convex and essentially smooth in the relative interior of
\dom\psi
(see
[
17
]
, section 26). We emphasize that the updates are performed
simultaneously
by all the agents.

Remark IV.1
.

A standard mirror descent algorithm as in the optimization literature would feature the gradients
\nabla V_{i}^{\pi}(\rho)
of the value functions in the inner product in the (PMD) update rule above. Recall that the policy gradients are given by
\frac{\partial V_{i}^{\pi}(\rho)}{\partial\pi_{i}(a_{i}|s)}=\frac{1}{1-\gamma}d_{\rho}^{\pi}(s)\bar{Q}_{i}^{\pi}(s,a_{i})
for every
s\in\mathcal{S},a_{i}\in\mathcal{A}_{i}\,
(e.g. see
[
21
]
).
Similarly to the PMD algorithm in the single-agent setting, (PMD) corresponds to a standard mirror descent algorithm enhanced with adaptive preconditioning with a dynamically weighted divergence: Each state Bregman divergence is weighted by the discounted visitation measure
d_{\rho}^{\pi}(s)
. We refer the reader to section 4, p.15-16 in
[
21
]
for a more precise exposition of this observation in the single-agent setting.

The mirror map choice generates a large class of PMD algorithms.
In this work, we focus on two concrete algorithms corresponding to the choice of two prominent mirror maps:

1.

Projected
Q
-ascent.
When the mirror map
\psi
is the squared
\ell_{2}
-norm, the corresponding Bregman divergence is the squared Euclidean distance and the resulting algorithm is playerwise projected
Q
-ascent:

\pi_{i,s}^{(t+1)}=\text{Proj}_{\Delta(\mathcal{A}_{i})}(\pi_{i,s}^{(t)}+\eta\bar{Q}_{i,s}^{\pi^{(t)}})\,,

(2)

for every
i\in\mathcal{N},s\in\mathcal{S}
and
\text{Proj}_{\Delta(\mathcal{A}_{i})}
is the projection operator on the simplex
\Delta(\mathcal{A}_{i})\,.

2.

Natural Policy Gradient.
When the mirror map
\psi
is the negative entropy, the Bregman divergence
D_{\psi}
is the Kullback-Leibler (KL) divergence and (PMD) boils down to independent Natural Policy Gradient which updates for every
i\in\mathcal{N},(s,a_{i})\in\mathcal{S}\times\mathcal{A}_{i}
as follows,

\pi_{i}^{(t+1)}(a_{i}|s)=\frac{\pi_{i}^{(t)}(a_{i}|s)\exp(\eta\bar{Q}_{i}^{\pi^{(t)}}(s,a_{i}))}{Z_{t}^{i,s}}\,,

(3)

where
Z_{t}^{i,s}\triangleq\sum_{a_{i}\in\mathcal{A}_{i}}\pi_{i}^{(t)}(a_{i}|s)\exp(\eta\,\bar{Q}_{i}^{\pi^{(t)}}(s,a_{i}))\,,
and the initial joint policy
\pi^{(0)}
is chosen in the interior of
\Delta(\mathcal{A})^{|\mathcal{S}|}.

Algorithm (
3
) is also referred to as a multiplicative weights update algorithm. We remark that the averaged Q-function in (
3
) (including in
Z_{t}^{i,s}
) can be replaced by the averaged advantage function
\bar{A}_{i}^{\pi^{(t)}}
defined for every
s\in\mathcal{S},i\in\mathcal{N},a_{i}\in\mathcal{A}_{i}
by

\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})\triangleq\bar{Q}_{i}^{\pi^{(t)}}(s,a_{i})-V_{i}^{\pi^{(t)}}(s)\,.

(4)

Information setting.
Throughout this work, we assume that each agent
i\in\mathcal{N}
has access to their average Q-value function
\bar{Q}_{i}^{\pi^{(t)}}
at each iteration
t
of the algorithm.
Beyond this oracle-based feedback setting, the averaged Q-value functions can also be estimated independently. Indeed, each agent can resort to payoff-based methods to estimate their own average Q-value function relying uniquely on their received rewards and without observing the policies or the actions of the other agents.
The extension of our guarantees to this stochastic setting requires further investigation, especially when using the KL regularization. We leave it for future work.

V
Nash Regret Analysis

In this section, we provide Nash regret guarantees for the PMD algorithm we introduced in the previous section when implemented either with Euclidean (
2
) or KL (
3
) regularization, with a focus on the dependence on the number of players.
Following prior work (see e.g.
[
5
,
23
]
), to make our analysis precise, we first define the notion of Nash regret for every time horizon
T\geq 1
as follows:

\text{Nash-regret(T)}\triangleq\frac{1}{T}\sum_{t=1}^{T}\max_{i\in\mathcal{N}}\max_{\pi^{\prime}_{i}\in\Pi^{i}}V_{i}^{\pi^{\prime}_{i},\pi^{(t)}_{-i}}(\rho)-V_{i}^{\pi^{(t)}}(\rho)\,,

where
\pi^{(t)}=(\pi_{i}^{(t)},\pi_{-i}^{(t)})
is the joint policy of the
N
players at time step
t\in\{1,\cdots,T\}
and
\rho
is the initial distribution over the state space
\mathcal{S}
. It follows from this definition that
\text{Nash-regret(T)}\geq 0
for every
T\geq 1\,.
Furthermore, when
\text{Nash-regret(T)}\leq\varepsilon
for some accuracy
\varepsilon>0
, there exists
t^{*}\in\{1,\cdots,T\}
such that
\pi^{(t^{*})}
is an
\varepsilon
-Nash equilibrium.
At each time step
t
and for every player
i\in\mathcal{N}
, the joint policy
\pi^{(t)}
is compared to the policy where player
i
unilaterally deviates to its best response to policy
\pi_{-i}^{(t)}
. The difference in value functions quantifies player
i
’s Nash gap. The Nash regret computes the average over the worst player’s Nash gap induced by the joint policy
\pi^{(t)}
over the time horizon
T\,.
The complete proofs of the results in this section are deferred to the appendix.

V-A

Analysis of PMD with Euclidean Regularization

We make the following standard assumption ensuring that all the states are visited.

Assumption V.1
.

For every joint policy
\pi\in\Pi
and every state
s\in\mathcal{S},d_{\rho}^{\pi}(s)>0\,.

Since
d_{\rho}^{\pi}(s)\geq(1-\gamma)\rho(s)
for every
\pi\in\Pi,s\in\mathcal{S}\,,
Assumption
V.1
is automatically satisfied when the initial distribution
\rho
has full support.

The key step of our analysis consists in quantifying the potential function improvement between two consecutive time steps of Algorithm (
2
). Since agents are updating their policy simultaneously, the challenge is to establish a joint policy improvement. The following lemma characterizes this improvement.

Proposition V.2

(Potential Improvement - Euclidean PMD)
.

Under Assumption
V.1
, for any
\mu\in\Delta(\mathcal{S}),t\geq 1,
we have

\displaystyle\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)\geq\left(\frac{1}{2\eta(1-\gamma)}-\frac{\phi_{\max}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{2}}\right)\cdot

\displaystyle\sum_{s\in\mathcal{S}}d_{\mu}^{\pi^{(t+1)}}(s)\sum_{i=1}^{N}\|\pi_{i,s}^{(t+1)}-\pi_{i,s}^{(t)}\|^{2}\,.

Proof sketch (of Proposition
V.2
).

The first step consists in using the performance difference lemma (
Lemma

IX.4
) to relate the potential function change to the policy change:

\displaystyle\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)

\displaystyle=\sum_{s\in\mathcal{S},a\in\mathcal{A}}\frac{d_{\mu}^{\pi^{(t+1)}}(s)}{1-\gamma}(\pi^{(t+1)}(a|s)-\pi^{(t)}(a|s))Q_{\phi}^{\pi^{(t)}}(s,a)\,,

where
Q_{\phi}^{\pi^{(t)}}
is the
Q
-function induced by the reward function
\phi
and the policy
\pi^{(t)}\,.
The second step consists in connecting the joint policy change to the individual policy deviation to use the update rule of the algorithm. For this, we recall that the joint policies are product policies across agents and use the following decomposition:

\displaystyle\pi^{(t+1)}(a|s)-\pi^{(t)}(a|s)

\displaystyle=\sum_{i=1}^{N}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))\,\tilde{\pi}_{-i}^{(t)}(a_{-i}|s)\,,

where
\tilde{\pi}_{-i}^{(t)}(a_{-i}|s)\triangleq\prod_{j=1}^{i-1}\pi_{j}^{(t+1)}(a_{j}|s)\prod_{j=i+1}^{N}\pi_{j}^{(t)}(a_{j}|s)
with the convention
\prod_{j=1}^{0}z_{j}=1
and
\prod_{j=N+1}^{N}z_{j}=1
for any sequence of nonnegative reals
(z_{j})\,.
The rest of the proof follows from plugging this decomposition into the first expression of the potential change above, using the update rule of the algorithm to obtain a potential improvement and control the remaining error terms.

The complete proof can be found in Appendix
VIII
.

Connecting the above policy improvement to the Nash regret (see proof in Appendix
VIII
), we obtain the following Nash regret guarantee.

Theorem V.3

(PMD with Euclidean Regularization)
.

Let Assumption
V.1
hold.
Set
\eta=\frac{1-\gamma}{4\phi_{\max}\sum_{i=1}^{N}|\mathcal{A}_{i}|}
. Then the individual policies
(\pi_{i}^{t})_{i\in\mathcal{N},t\in\{1,\cdots,T\}}
obtained from running PMD with Euclidean regularization (
2
) and constant step size
\eta
for
T\geq 1
iterations satisfy the following,

\text{Nash-regret(T)}\leq 12\sqrt{\frac{2\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{4}T}}\,.

(5)

Hence, the number of iterations to achieve
\varepsilon
-Nash regret is:

T\geq\frac{288\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{4}\varepsilon^{2}}\,.

Comparison to Prior Work.
We provide a few comments regarding Theorem
V.3
in the light of the existing literature:

•

Our result improves over the convergence rates provided in
[
5
]
in terms of the distribution mismatch coefficient
\tilde{\kappa}_{\rho}
which can scale with the state space size
|\mathcal{S}|
in the worst case, reducing the dependence from
\tilde{\kappa}_{\rho}^{4}
to
\tilde{\kappa}_{\rho}
(see Table

Moreover, this rate matches the
\mathcal{O}\left(\frac{\tilde{\kappa}_{\rho}N\underset{i\in\mathcal{N}}{\max}|\mathcal{A}_{i}|}{(1-\gamma)^{4}\varepsilon^{2}}\right)
regret bound provided for the specific identical interest case in
[
5
]
(Theorem 2) where
\phi_{\max}=1
since their rewards are bounded in
[0,1]
. This closes the gap between the purely identical interest case and the more general MPG setting. However, this result leverages the fact that the potential function is an expected discounted cumulative sum of ‘state-wise’ potential functions. While the result in
[
5
]
applies to a more general definition of MPGs which does not require the cumulative sum form of the total potential function, we improve over this result with this additional structure. Our result for the Euclidean setting mainly serves as a comparison point for our upcoming result for PMD under KL regularization.

•

Overall, we follow a proof strategy similar to
[
5
,
23
]
.
However, we highlight that compared to
[
5
]
, we rely on a different decomposition of the policy improvement.
The refined decomposition we use was considered in a similar way in
[
3
]
in the context of stateless potential games when analyzing an independent natural gradient method with entropy regularization and in
[
23
]
when analyzing softmax gradient play. In the present work, we address the case of MPGs beyond the particular case of (stateless) potential games and we do not consider any
additional
entropy regularization. Importantly, our goal is to learn Nash equilibria for an unregularized game and our iteration complexity is of the order
\mathcal{O}(\varepsilon^{-2})

\mathcal{O}(\varepsilon^{-4})

.

Notice that the iteration complexity in Theorem

V-B

Analysis of PMD with KL Regularization

It has been shown in
[
6
]
that the iterates of independent Natural Policy Gradient with softmax policy parametrization converge to fixed point policies of the multiplicative weights algorithm (namely (
3
)).
This asymptotic result required an assumption on these fixed points. Before stating this assumption which we will also make to guarantee convergence, we recall that the fixed points of (
3
) are the policies
\pi\in\Pi
satisfying either
\pi_{i}(a_{i}|s)=0
or
\bar{A}_{i}^{\pi}(s,a_{i})=0
for every
s\in\mathcal{S},i\in\mathcal{N},a_{i}\in\mathcal{A}_{i}
as can be readily seen in (

).

Assumption V.4
.

The fixed points of (
3
) are isolated.

Notice that Assumption
V.4
has been made in several prior works
[
6
,
23
,
20
]
.

Similarly to the previous section, we start by quantifying the potential improvement for our algorithm.

Proposition V.5

(Potential Improvement - KL PMD)
.

Under Assumption
V.1
, for any
\mu\in\Delta(\mathcal{S}),t\geq 1,
we have

\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)\geq\left(\frac{1}{\eta}-\frac{\phi_{\max}\sqrt{N}}{(1-\gamma)^{2}}\right)\cdot\\
\sum_{s\in\mathcal{S}}d_{\mu}^{\pi^{(t+1)}}(s)\text{KL}(\pi^{(t+1)}_{s}||\,\pi^{(t)}_{s})+\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{\pi^{(t+1)}}(s)\sum_{i=1}^{N}\log Z_{t}^{i,s}.

Moreover, if
\eta\leq\frac{(1-\gamma)^{2}}{\phi_{\max}\sqrt{N}}
, then

\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)\geq\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{\pi^{(t+1)}}(s)\sum_{i=1}^{N}\log Z_{t}^{i,s}\,.

(6)

Note that the potential improvement bound now features a dependence on
\sqrt{N}
instead of
N
in comparison to Proposition
V.2
. Crucially, this improvement allows to take larger step sizes for PMD with KL regularization which leads to our improved iteration complexity.
Using Proposition
V.5
, we connect the right-hand side of (
6
) to the Nash regret using Lemma 21 in
[
23
]
which is adapted and reported in Lemma
IX.3
in the appendix.
We obtain the following main result whose complete proof is deferred to Appendix

.

Theorem V.6

(PMD with KL Regularization)
.

Let Assumptions
V.1
and
V.4
hold.
Set
\eta=\frac{1-\gamma}{2\phi_{\max}\sqrt{N}}\,.
Then the individual policies
(\pi_{i}^{t})_{i\in\mathcal{N},t\in\{1,\cdots,T\}}
obtained from running Algorithm (
3
) for
T\geq 1
iterations with constant step size
\eta
satisfy the following regret guarantee,

\text{Nash-regret}(T)\leq\sqrt{\frac{12\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sqrt{N}}{(1-\gamma)^{4}c\,T}}\,,

(7)

where
c\triangleq\underset{i\in\mathcal{N}}{\min}\underset{t\in{{\mathbb{N}}}}{\inf}\,\underset{s\in\mathcal{S}}{\min}\underset{a_{i}^{*}\in\underset{a_{i}\in\mathcal{A}_{i}}{\argmax}\bar{Q}^{\pi^{(t)}}_{i}(s,a_{i})}{\sum}\,\pi_{i}^{(t)}(a_{i}^{*}|s)>0\,.

The number of iterations to achieve
\varepsilon
-Nash regret is:

T\geq\frac{12\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sqrt{N}}{(1-\gamma)^{4}c\,\varepsilon^{2}}\,.

Some comments are in order about Theorem
V.6
:

•

First and foremost, observe the improved
\sqrt{N}
dependence on the number players in the theorem instead of
N
in Theorem
V.3
which uses Euclidean regularization.

•

It is also worth noting that there is no dependence on the size of the action space anymore. Furthermore, the dependence on the state space size is only indirect via the minimax distribution mismatch coefficient
\tilde{\kappa}_{\rho}
. This offers the possibility of further extension of the result to the continuous state space setting.

•

The positivity of the constant
c
has been previously shown in
[
23
]
using Assumption
V.4
.
Relaxing this assumption and removing the dependence on the constant
c
(which can be very small) is an interesting question left for future work.

•

The proof of this result uses similar arguments to the proof of Theorem 5 in
[
23
]
. Our improved result stems from a tighter policy improvement lemma than Lemma 20 in
[
23
]
. More precisely, we control an error term differently using similar techniques to the proofs in
[
3
]
which is concerned with stateless (i.e. static) potential games enhanced with entropy regularization. However, notice here that (a) we consider MPGs which have stateless potential games as a particular case and (b) we are interested in natural policy gradient (PMD with KL regularization) without the additional entropic regularization considered in
[
3
]
.

•

In contrast to the single-agent setting where a unified analysis of PMD for different mirror maps has been developed
[
21
]
, our analysis is tailored to the choice of the mirror map. Whether a unified analysis can be performed remains an open question.

VI
Conclusion and Future Work

In this work, we introduced an independent PMD algorithm for MPGs which subsumes as particular cases the projected Q-ascent and the celebrated Natural Policy Gradient algorithms, corresponding to PMD with Euclidean and entropic mirror maps respectively. We provided Nash regret guarantees for both algorithms showing an improved dependence on the number of agents when using Natural Policy Gradient. Notably, the Nash regret guarantee for the latter algorithm is independent of the size of the action space in contrast with the iteration complexity for PMD with Euclidean regularization.

There are several interesting directions for future research:

•

Relaxing the assumption of isolated stationary policies is an interesting question for future work. Regularization might offer a way to get rid of this assumption as well as the constant
c
as pursued in
[
23
]
. Achieving this while also obtaining our improved dependence on the number of players is an interesting open question.

•

Obtaining guarantees on the last-iterate of the algorithm instead of our average Nash regret result is an interesting question to address to ensure that implementing the last-iterate policies indeed leads to Nash equilibria.

•

Extending the result to the stochastic setting where average Q-functions are estimated from the immediate rewards observed by the agents, i.e. designing payoff-based methods is a fruitful avenue for future work. While the extension for the Euclidean case is straightforward, obtaining the result for the Natural Policy Gradient seems more delicate as it is not immediate to show that the constant
c
is indeed positive in the stochastic setting.

•

While our focus in this paper was on improving the dependence on the number of agents, scaling the algorithm to large state spaces is also an important challenge. Extending our results in this direction using function approximation merits further investigation. Some results were recently discussed along these lines for PMD with Euclidean regularization
[
5
]
.

Let
\mu

\Phi^{\pi}(\mu)\triangleq\mathbb{E}_{\mu,\pi}\left[\sum_{t=0}^{\infty}\gamma^{t}\phi(s_{t},a_{t})\right]\,.

Proposition VIII.1
.

For any initial distribution

\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)\geq\left(\frac{1}{2\eta(1-\gamma)}-\frac{2\phi_{\max}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{3}}\right)\sum_{s\in\mathcal{S}}d_{\mu}^{\pi^{(t+1)}}(s)\sum_{i=1}^{N}\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|^{2}\,.

Proof.

Using the performance difference lemma (

\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S},a\in\mathcal{A}}d_{\mu}^{\pi^{(t+1)}}(s)(\pi^{(t+1)}(a|s)-\pi^{(t)}(a|s))Q_{\phi}^{\pi^{(t)}}(s,a)\,.

Remark VIII.2
.

Notice here that our first step consists in using the performance difference lemma between the

i

\pi^{(t+1)}(a|s)-\pi^{(t)}(a|s)=\sum_{i=1}^{N}\left(\prod_{j=1}^{i}\pi_{j}^{(t+1)}(a_{j}|s)\prod_{j=i+1}^{N}\pi_{j}^{(t)}(a_{j}|s)-\prod_{j=1}^{i-1}\pi_{j}^{(t+1)}(a_{j}|s)\prod_{j=i}^{N}\pi_{j}^{(t)}(a_{j}|s)\right)\,,

\displaystyle\tilde{\pi}_{-i}^{(t)}(a_{-i}|s)

\displaystyle\triangleq\prod_{j=1}^{i-1}\pi_{j}^{(t+1)}(a_{j}|s)\prod_{j=i+1}^{N}\pi_{j}^{(t)}(a_{j}|s)\,,

(12)

\displaystyle\tilde{Q}_{\phi,i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\triangleq\sum_{a_{-i}\in\mathcal{A}_{-i}}\tilde{\pi}_{-i}^{(t)}(a_{-i}|s)\,Q_{\phi}^{\pi^{(t)}}(s,a)\,,

(13)

\displaystyle\bar{Q}_{\phi,i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\triangleq\sum_{a_{-i}\in\mathcal{A}_{-i}}\pi_{-i}^{(t)}(a_{-i}|s)\,Q_{\phi}^{\pi^{(t)}}(s,a)\,.

\displaystyle\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)

\displaystyle=\underbrace{\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))\bar{Q}_{i}^{(t)}(s,a_{i})}_{\text{Term A}}

Term A.

\displaystyle\stackrel{{\scriptstyle(b)}}{{\leq}}\frac{3}{\eta(1-\gamma)}\sum_{t=1}^{T}\sum_{s\in\mathcal{S}}d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|

\displaystyle=\frac{3}{\eta(1-\gamma)}\sum_{t=1}^{T}\sum_{s\in\mathcal{S}}\sqrt{\frac{d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}{d_{\nu}^{\pi^{(t+1)}}(s)}}\sqrt{d_{\nu}^{\pi^{(t+1)}}(s)}\sqrt{d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|

\displaystyle\stackrel{{\scriptstyle(c)}}{{\leq}}\frac{3\sqrt{\sup_{\pi\in\Pi}\left\|\frac{d_{\rho}^{\pi}}{\nu}\right\|_{\infty}}}{\eta(1-\gamma)^{3/2}}\sqrt{\sum_{t=1}^{T}\sum_{s\in\mathcal{S}}d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}\sqrt{\sum_{t=1}^{T}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\sum_{j=1}^{N}\|\pi_{j}^{(t+1)}(\cdot|s)-\pi_{j}^{(t)}(\cdot|s)\|^{2}}

\displaystyle\stackrel{{\scriptstyle(d)}}{{\leq}}\frac{3\sqrt{\sup_{\pi\in\Pi}\left\|\frac{d_{\rho}^{\pi}}{\nu}\right\|_{\infty}T}}{\eta(1-\gamma)^{3/2}}\sqrt{4\eta(1-\gamma)(\Phi^{\pi^{(T+1)}}(\nu)-\Phi^{\pi^{(1)}}(\nu))}

\displaystyle\stackrel{{\scriptstyle(e)}}{{\leq}}6\sqrt{\frac{2\sup_{\pi\in\Pi}\left\|\frac{d_{\rho}^{\pi}}{\nu}\right\|_{\infty}\phi_{\max}T}{\eta(1-\gamma)^{3}}}

\displaystyle\stackrel{{\scriptstyle(f)}}{{\leq}}6\sqrt{\frac{2\tilde{\kappa}_{\rho}\phi_{\max}T}{\eta(1-\gamma)^{3}}}\,,

(26)

where
(a)
follows from the multi-agent performance difference lemma,
(b)
uses Lemma
VIII.3
,
(c)
holds for any distribution
\nu
with full support on the state space
\mathcal{S}
, uses the inequality
d_{\nu}^{\pi^{(t+1)}}(s)\geq(1-\gamma)\nu(s)
together with the Cauchy-Schwarz inequality and upperbounds the
i
-th term by the sum over the
N
players,
(d)
uses Lemma
VIII.1
,
(e)
follows from the boundedness of the potential function
\phi
and finally
(f)
stems from the definition of the constant
\tilde{\kappa}_{\rho}\,.

Finally, setting
\eta=\frac{1-\gamma}{4(\phi_{\max}-\phi_{\min})\sum_{i=1}^{N}|\mathcal{A}_{i}|}
, we obtain:

\text{Nash-regret(T)}\leq 12\sqrt{\frac{2\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{4}T}}\,.

(27)

Hence, the iteration complexity to achieve
\varepsilon
-Nash regret is up to numerical constants:

\mathcal{O}\left(\frac{\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sum_{i=1}^{N}|\mathcal{A}_{i}|}{(1-\gamma)^{4}\varepsilon^{2}}\right)\,.

Remark VIII.4
.

Notice that

\tilde{\kappa}_{\rho}\leq\min(\kappa_{\rho},|\mathcal{S}|)\,,

(28)

where
\kappa_{\rho}\triangleq\sup_{\pi\in\Pi}\left\|\frac{d_{\rho}^{\pi}}{\rho}\right\|_{\infty}\,.

Observe for this that setting
\nu
to be the uniform distribution over the state space
\mathcal{S}
gives
\tilde{\kappa}_{\rho}\leq\sup_{\pi\in\Pi}\left\|\frac{d_{\rho}^{\pi}}{\nu}\right\|_{\infty}\leq|\mathcal{S}|
whereas
\nu=\rho
yields
\tilde{\kappa}_{\rho}\leq\kappa_{\rho}\,.

For any initial distribution

(30)

where we recall that
Z_{t}^{i,s}=\sum_{a_{i}\in\mathcal{A}_{i}}\pi_{i}^{(t)}(a_{i}|s)\exp\left(\frac{\eta\bar{A}_{i}^{(t)}(s,a_{i})}{1-\gamma}\right)
for every

Moreover, if

Proof.

We first introduce a few additional notations for every

and

\displaystyle V_{\phi}^{\pi^{(t)}}(s)

\displaystyle\triangleq\mathbb{E}_{\mu,\pi}\left[\sum_{t=0}^{\infty}\gamma^{t}\phi(s_{t},a_{t})|s_{0}=s\right]\,,

(32)

\displaystyle A_{\phi}^{\pi^{(t)}}(s,a)

\displaystyle\triangleq Q_{\phi}^{\pi^{(t)}}(s,a)-V_{\phi}^{\pi^{(t)}}(s)\,,

(33)

\displaystyle\tilde{A}_{\phi,i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\triangleq\sum_{a_{-i}\in\mathcal{A}_{-i}}\tilde{\pi}_{-i}^{(t)}(a_{-i}|s)\,A_{\phi}^{\pi^{(t)}}(s,a)\,,

(34)

\displaystyle\bar{A}_{\phi,i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\triangleq\sum_{a_{-i}\in\mathcal{A}_{-i}}\pi_{-i}^{(t)}(a_{-i}|s)\,A_{\phi}^{\pi^{(t)}}(s,a)\,.

(35)

We will also use again the shorthand notation

Similarly to the proof of Lemma

(and Lemma 20 in

\displaystyle\Phi^{\pi^{(t+1)}}(\mu)-\Phi^{\pi^{(t)}}(\mu)

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))\tilde{A}_{\phi,i}^{(t)}(s,a_{i})

\displaystyle=\underbrace{\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))\bar{A}_{i}^{(t)}(s,a_{i})}_{\text{Term A}}

\displaystyle+\underbrace{\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))(\tilde{A}_{\phi,i}^{(t)}(s,a_{i})-\bar{A}_{i}^{(t)}(s,a_{i}))}_{\text{Term B}}\,,

We now control each one of the terms separately in what follows.

1.

Term A.

For this term, our treatment is the same as in
[
23
]
. We provide a proof here for completeness and we also add a crucial precision in the proof that seemed to be used in
[
23
]
as a claim. This is the fact that
\bar{A}_{i}^{\pi}(s,a_{i})=\bar{A}_{\phi,i}^{\pi}(s,a_{i})
for every
\pi\in\Pi,s\in\mathcal{S},i\in\mathcal{N},a_{i}\in\mathcal{A}_{i}
, i.e. the averaged advantage function
\bar{A}_{i}^{\pi}
coincides with the averaged advantage function induced by the potential function
\bar{A}_{\phi,i}^{\pi}
(see (
33

) for a definition).
This result is a consequence of the equality between the partial derivatives of the individual value functions and the partial derivative of the potential function w.r.t. the individual policies entries, as implied by the definition of MPGs (see (
19
) and (
20
)). Before proceeding, we provide a brief proof of this fact that will be useful later on. Since
\bar{Q}_{i}^{\pi}(s,a_{i})=\bar{Q}_{\phi}^{\pi}(s,a_{i})
(see (
18

V_{\phi}^{\pi}(s)=\sum_{a_{i}^{\prime}\in\mathcal{A}_{i}}\pi_{i}(a_{i}^{\prime}|s)\bar{Q}_{\phi}^{\pi}(s,a_{i}^{\prime})
, we also have the desired equality
\bar{A}_{i}^{\pi}(s,a_{i})=\bar{A}_{\phi,i}^{\pi}(s,a_{i})
using the definition of the averaged advantage function.

It follows from our update rule (
29
) that:

\bar{A}_{i}^{(t)}(s,a_{i})=\frac{1-\gamma}{\eta}\left(\log\left(\frac{\pi_{i}^{(t+1)}(a_{i}|s)}{\pi_{i}^{(t)}(a_{i}|s)}\right)+\log Z_{t}^{i,s}\right)\,.

(37)

Plugging (
37
) into the Term A immediately implies that

Term A

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}(\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s))\bar{A}_{i}^{(t)}(s,a_{i})

\displaystyle\stackrel{{\scriptstyle(a)}}{{=}}\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}\pi_{i}^{(t+1)}(a_{i}|s)\bar{A}_{i}^{(t)}(s,a_{i})

\displaystyle=\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}\pi_{i}^{(t+1)}(a_{i}|s)\left(\log\left(\frac{\pi_{i}^{(t+1)}(a_{i}|s)}{\pi_{i}^{(t)}(a_{i}|s)}\right)+\log Z_{t}^{i,s}\right)

\displaystyle=\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\text{KL}(\pi_{i}^{(t+1)}(\cdot|s)\,||\,\pi_{i}^{(t)}(\cdot|s))+\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\log Z_{t}^{i,s}

\displaystyle=\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\text{KL}(\pi^{(t+1)}(\cdot|s)\,||\,\pi^{(t)}(\cdot|s))+\frac{1}{\eta}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\log Z_{t}^{i,s}\,,

(38)

where
(a)
follows from observing that
\sum_{a_{i}\in\mathcal{A}_{i}}\pi_{i}^{(t)}(a_{i}|s)\bar{A}_{i}^{(t)}(s,a_{i})=0
and the last identity follows from the additivity of the KL divergence for product distributions.

2.

Term B.
Our improvement w.r.t. Theorem 5 in
[
23
]
comes from the way we control this term. The following derivations are similar to parts of the proofs in
[
3
]
, namely Appendix A and the end of Appendix B.1. Recall though that the work
[
3
]
which inspired our analysis only deals with (stateless) potential games and considers a different natural policy gradient algorithm enhanced with entropy regularization.
First of all, we have that

\displaystyle|\tilde{A}_{\phi,i}^{(t)}(s,a_{i})-\bar{A}_{i}^{(t)}(s,a_{i})|

\displaystyle\stackrel{{\scriptstyle(a)}}{{=}}|\tilde{A}_{\phi,i}^{(t)}(s,a_{i})-\bar{A}_{\phi,i}^{(t)}(s,a_{i})|

\displaystyle\stackrel{{\scriptstyle(b)}}{{=}}\left|{{\mathbb{E}}}_{a_{-i}\sim\tilde{\pi}_{-i}^{(t)}}[A_{\phi}^{(t)}(s,a_{i},a_{-i})]-{{\mathbb{E}}}_{a_{-i}\sim\pi_{-i}^{(t)}}[A_{\phi}^{(t)}(s,a_{i},a_{-i})]\right|

\displaystyle\stackrel{{\scriptstyle(c)}}{{=}}\left|{{\mathbb{E}}}_{a_{-i}\sim\tilde{\pi}_{-i}^{(t)}}[Q_{\phi}^{(t)}(s,a_{i},a_{-i})]-{{\mathbb{E}}}_{a_{-i}\sim\pi_{-i}^{(t)}}[Q_{\phi}^{(t)}(s,a_{i},a_{-i})]\right|

\displaystyle\stackrel{{\scriptstyle(d)}}{{\leq}}\|Q_{\phi}^{(t)}(s,a_{i},\cdot)\|_{\infty}\,\text{d}_{\text{TV}}(\tilde{\pi}_{-i}^{(t)}(\cdot|s),\pi_{-i}^{(t)}(\cdot|s))

\displaystyle\stackrel{{\scriptstyle(e)}}{{\leq}}\frac{\phi_{\max}}{1-\gamma}\text{d}_{\text{TV}}(\tilde{\pi}_{-i}^{(t)}(\cdot|s),\pi_{-i}^{(t)}(\cdot|s))\,,

(39)

where
\text{d}_{\text{TV}}(\cdot,\cdot)
is the total variation distance,
(a)
uses the identity
\bar{A}_{i}^{(t)}(s,a_{i})=\bar{A}_{\phi,i}^{(t)}(s,a_{i})
,
(b)
stems from the definitions (
34
) and (
35
),
(c)
is a consequence of the definition of the advantage function,
(d)
follows from the standard inequality
\left|\int_{\Omega}fd\mu-\int_{\Omega}fd\nu\right|\leq\|f\|_{\infty}\text{d}_{\text{TV}}(\mu,\nu)
for any bounded measurable function
f:\Omega\to\mathbb{R}
and any probability measures
\mu
and
\nu
and finally
(e)
stems from observing that
\|Q_{\phi}^{(t)}(s,a_{i},\cdot)\|_{\infty}\leq\phi_{\max}/(1-\gamma)\,.

Plugging the above inequality into Term B, we obtain

\displaystyle|\text{Term B}|

\displaystyle\leq\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\sum_{a_{i}\in\mathcal{A}_{i}}|\pi_{i}^{(t+1)}(a_{i}|s)-\pi_{i}^{(t)}(a_{i}|s)|\cdot|\tilde{A}_{\phi,i}^{(t)}(s,a_{i})-\bar{A}_{i}^{(t)}(s,a_{i})|

\displaystyle\leq\frac{\phi_{\max}}{(1-\gamma)^{2}}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\sum_{i=1}^{N}\text{d}_{\text{TV}}(\tilde{\pi}_{-i}^{(t)}(\cdot|s),\pi_{-i}^{(t)}(\cdot|s))\cdot\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|_{1}\,.

(40)

Then we observe that

\displaystyle\sum_{i=1}^{N}\text{d}_{\text{TV}}(\tilde{\pi}_{-i}^{(t)}(\cdot|s),\pi_{-i}^{(t)}(\cdot|s))\cdot\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|_{1}

\displaystyle\stackrel{{\scriptstyle(a)}}{{\leq}}\sum_{i=1}^{N}\left(\frac{1}{2\sqrt{N}}\text{d}_{\text{TV}}(\tilde{\pi}_{-i}^{(t)}(\cdot|s),\pi_{-i}^{(t)}(\cdot|s))^{2}+\frac{\sqrt{N}}{2}\|\pi_{i}^{(t+1)}(\cdot|s)-\pi_{i}^{(t)}(\cdot|s)\|_{1}^{2}\right)

\displaystyle\stackrel{{\scriptstyle(b)}}{{\leq}}\sum_{i=1}^{N}\left(\frac{1}{2\sqrt{N}}\text{KL}(\tilde{\pi}_{-i}^{(t)}(\cdot|s)||\pi_{-i}^{(t)}(\cdot|s))+\frac{\sqrt{N}}{2}\text{KL}(\pi_{i}^{(t+1)}(\cdot|s)||\pi_{i}^{(t)}(\cdot|s))\right)

\displaystyle\stackrel{{\scriptstyle(c)}}{{\leq}}\sum_{i=1}^{N}\left(\frac{1}{2\sqrt{N}}\text{KL}(\pi^{(t+1)}(\cdot|s)||\pi^{(t)}(\cdot|s))+\frac{\sqrt{N}}{2}\text{KL}(\pi_{i}^{(t+1)}(\cdot|s)||\pi_{i}^{(t)}(\cdot|s))\right)

\displaystyle=\frac{\sqrt{N}}{2}\text{KL}(\pi^{(t+1)}(\cdot|s)||\pi^{(t)}(\cdot|s))+\frac{\sqrt{N}}{2}\sum_{i=1}^{N}\text{KL}(\pi_{i}^{(t+1)}(\cdot|s)||\pi_{i}^{(t)}(\cdot|s))

\displaystyle\stackrel{{\scriptstyle(d)}}{{=}}\sqrt{N}\,\text{KL}(\pi^{(t+1)}(\cdot|s)||\pi^{(t)}(\cdot|s))\,,

where
(a)
stems from Young’s inequality (
xy\leq\frac{x^{2}}{2\sqrt{N}}+\frac{\sqrt{N}y^{2}}{2}
for any
x,y\in\mathbb{R}
),
(b)
is a consequence of Pinsker’s inequality,
(c)
follows from observing that

\text{KL}(\tilde{\pi}_{-i}^{(t)}(\cdot|s)||\pi_{-i}^{(t)}(\cdot|s))=\sum_{j<i}\text{KL}(\pi_{j}^{(t+1)}(\cdot|s)||\pi_{j}^{(t)}(\cdot|s))\leq\sum_{j=1}^{N}\text{KL}(\pi_{j}^{(t+1)}(\cdot|s)||\pi_{j}^{(t)}(\cdot|s))\,,

where we used the definition of
\tilde{\pi}_{-i}^{(t)}
in (
12
).
Then,
(d)
uses the additivity of the KL divergence for product distributions.
Overall, plugging (

|\text{Term B}|\leq\frac{\phi_{\max}\sqrt{N}}{(1-\gamma)^{2}}\sum_{s\in\mathcal{S}}d_{\mu}^{(t+1)}(s)\text{KL}(\pi^{(t+1)}(\cdot|s)||\pi^{(t)}(\cdot|s))\,.

(42)

38
) and (

) yields the desired inequality (
30

∎

\displaystyle\text{Nash-gap}_{i}(\pi)

\displaystyle\triangleq\underset{\pi_{i}^{\prime}\in\Pi^{i}}{\max}V_{i}^{\pi_{i}^{\prime},\pi_{-i}}(\rho)-V_{i}^{\pi_{i},\pi_{-i}}(\rho)\,,\forall i\in\mathcal{N}\,,

(43)

\displaystyle\triangleq\underset{i\in\mathcal{N}}{\max}\,\text{Nash-gap}_{i}(\pi)\,.

Lemma IX.3
.

If
\eta\leq(1-\gamma)^{2}
, then for any initial distribution
\nu\in\Delta(\mathcal{S}),

\text{Nash-gap}(\pi^{(t)})^{2}\leq\frac{3\tilde{\kappa}_{\rho}}{c\eta^{2}(1-\gamma)}\sum_{i=1}^{N}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\log Z_{t}^{i,s}\,,

(45)

where we recall that
c\triangleq\underset{i\in\mathcal{N}}{\min}\underset{t\in{{\mathbb{N}}}}{\inf}\,\underset{s\in\mathcal{S}}{\min}\underset{a_{i}^{*}\in\underset{a_{i}\in\mathcal{A}_{i}}{\argmax}\bar{Q}^{\pi^{(t)}}_{i}(s,a_{i})}{\sum}\,\pi_{i}^{(t)}(a_{i}^{*}|s)>0\,.

Proof.

We start by upper-bounding the Nash gap of every policy
\pi^{(t)}
for every iteration
t
. As a first step, we use the performance difference lemma for policy
\pi^{(t)}
, for any
i\in\mathcal{N}
and any policy
\pi_{i}^{\prime}\in\Pi^{i}
to write:

\displaystyle V_{i}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(\rho)-V_{i}^{\pi^{(t)}}(\rho)

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S},a_{i}\in\mathcal{A}_{i}}d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)\pi_{i}^{\prime}(a_{i}|s)\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\leq\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sqrt{\frac{d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}{d_{\nu}^{\pi^{(t+1)}}(s)}}\sqrt{d_{\nu}^{\pi^{(t+1)}}(s)}\sqrt{d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\leq\frac{\sqrt{\tilde{\kappa}_{\rho}}}{(1-\gamma)^{3/2}}\sum_{s\in\mathcal{S}}\sqrt{d_{\nu}^{\pi^{(t+1)}}(s)}\sqrt{d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)}\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})

\displaystyle\leq\frac{(1-\gamma)\sqrt{\tilde{\kappa}_{\rho}}}{\eta(1-\gamma)^{3/2}}\left(\sum_{s\in\mathcal{S}}d_{\rho}^{\pi_{i}^{\prime},\pi_{-i}^{(t)}}(s)\right)^{1/2}\left(\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\left(\frac{\eta\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})}{1-\gamma}\right)^{2}\right)^{1/2}

\displaystyle\leq\frac{\sqrt{\tilde{\kappa}_{\rho}}}{\eta\sqrt{1-\gamma}}\left(\sum_{i=1}^{N}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\left(\frac{\eta\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})}{1-\gamma}\right)^{2}\right)^{1/2}\,.

(46)

Hence, we have shown so far that

\text{Nash-gap}(\pi^{(t)})^{2}\leq\frac{\tilde{\kappa}_{\rho}}{\eta^{2}(1-\gamma)}\sum_{i=1}^{N}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\left(\frac{\eta\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})}{1-\gamma}\right)^{2}\,.

(47)

To conclude the proof, we now use an inequality that appeared in the proof of Lemma 21 in
[
23
]
in p. 26 (in the arxiv version), namely the second to last inequality in the proof:

\sum_{i=1}^{N}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\left(\frac{\eta\underset{a_{i}\in\mathcal{A}_{i}}{\max}\bar{A}_{i}^{\pi^{(t)}}(s,a_{i})}{1-\gamma}\right)^{2}\leq\frac{3}{c}\sum_{i=1}^{N}\sum_{s\in\mathcal{S}}d_{\nu}^{\pi^{(t+1)}}(s)\log Z_{t}^{i,s}\,.

(48)

Combining (
47
) and (
48
) leads to the desired inequality of Lemma
IX.3
.
∎

The last part of the proof follows the same lines as
[
23
]
(see p. 29 therein).
Combining Lemma
IX.2
with Lemma

, we obtain:

\text{Nash-gap}(\pi^{(t)})^{2}\leq\frac{3\tilde{\kappa}_{\rho}}{c\eta(1-\gamma)}(\Phi^{\pi^{(t+1)}}(\nu)-\Phi^{\pi^{(t)}}(\nu))\,.

(49)

As a consequence, we have

\frac{1}{T}\sum_{t=1}^{T}\text{NE-gap}(\pi^{(t)})^{2}\leq\frac{3\tilde{\kappa}_{\rho}}{c\eta(1-\gamma)T}(\Phi^{\pi^{(T+1)}}(\nu)-\Phi^{\pi^{(1)}}(\nu))\leq\frac{6\tilde{\kappa}_{\rho}\phi_{\max}}{(1-\gamma)^{2}c\eta T}

\text{Nash-regret}(T)\leq\left(\frac{1}{T}\sum_{t=1}^{T}\text{NE-gap}(\pi^{(t)})^{2}\right)^{1/2}\leq\sqrt{\frac{12\phi_{\max}^{2}\tilde{\kappa}_{\rho}\sqrt{N}}{(1-\gamma)^{4}cT}}\,.

(51)

The following lemma is standard and well-known in the literature (see e.g.

Lemma IX.4

(Performance Difference Lemma)
.

Consider a Markov Decision Process
(\mathcal{S},\mathcal{A},P,r,\gamma,\mu)
.
Then for any policies
\pi,\pi^{\prime}\in\Pi,

V^{\pi^{\prime}}(\mu)-V^{\pi}(\mu)=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sum_{a\in\mathcal{A}}d_{\mu}^{\pi^{\prime}}(s)(\pi^{\prime}(a|s)-\pi(a|s))Q^{\pi}(s,a)\,,

where for every policy
\pi\in\Pi,V^{\pi}(\mu)
and
Q^{\pi}:\mathcal{S}\times\mathcal{A}\to{{\mathbb{R}}}
are the state-value function with initial distribution
\mu
and state-action value function of policy
\pi
respectively.

Lemma IX.5

(Multi-Agent Performance Difference Lemma (Single-Agent Deviation))
.

Consider a Markov game
\Gamma=\left\langle\mathcal{N},\mathcal{S},(\mathcal{A}_{i})_{i\in\mathcal{N}},P,(r_{i})_{i\in\mathcal{N}},\gamma\right\rangle
with initial state distribution
\mu\in\Delta(\mathcal{S})
. Then, for any agent
i\in\mathcal{N}
, any two policies
\pi^{\prime}_{i},\pi_{i}\in\Pi^{i}
and any joint policy
\pi_{-i}\in\Pi^{-i}
of the other agents, we have:

\displaystyle V_{i}^{\pi^{\prime}_{i},\pi_{-i}}(\mu)-V_{i}^{\pi_{i},\pi_{-i}}(\mu)

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sum_{a_{i}\in\mathcal{A}_{i}}d_{\mu}^{\pi^{\prime}_{i},\pi_{-i}}(s)(\pi^{\prime}_{i}(a_{i}|s)-\pi_{i}(a_{i}|s))\bar{Q}_{i}^{\pi_{i},\pi_{-i}}(s,a_{i})\,,

where we use the same notations as in section
III
.

Proof.

We provide a proof for completeness. Using
Lemma

IX.4
, we have for every
i\in\mathcal{N},\pi^{\prime}_{i},\pi_{i}\in\Pi^{i},\pi_{-i}\in\Pi^{-i},

\displaystyle V_{i}^{\pi^{\prime}_{i},\pi_{-i}}(\mu)-V_{i}^{\pi_{i},\pi_{-i}}(\mu)

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sum_{a=(a_{i},a_{-i})\in\mathcal{A}}d_{\mu}^{\pi_{i}^{\prime},\pi_{-i}}(s)\left(\pi_{i}^{\prime}(a_{i}|s)\pi_{-i}(a_{-i}|s)-\pi_{i}(a_{i}|s)\pi_{-i}(a_{-i}|s)\right)Q_{i}^{\pi}(s,a)

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sum_{a_{i}\in\mathcal{A}_{i}}d_{\mu}^{\pi_{i}^{\prime},\pi_{-i}}(s)\left(\pi^{\prime}_{i}(a_{i}|s)-\pi_{i}(a_{i}|s)\right)\underbrace{\sum_{a_{-i}\in\mathcal{A}_{-i}}\pi_{-i}(a_{-i}|s)Q_{i}^{\pi}(s,(a_{i},a_{-i}))}_{=\bar{Q}^{\pi}_{i}(s,a_{i})}

\displaystyle=\frac{1}{1-\gamma}\sum_{s\in\mathcal{S}}\sum_{a_{i}\in\mathcal{A}_{i}}d_{\mu}^{\pi^{\prime}_{i},\pi_{-i}}(s)(\pi^{\prime}_{i}(a_{i}|s)-\pi_{i}(a_{i}|s))\bar{Q}_{i}^{\pi}(s,a_{i}).

∎
