Projective Hilbert modules and sequential approximations
Lawrence G. Brown, Huaxin Lin

Abstract
We show that, when A A is a separable C ∗ C^{*} -algebra, every countably generated Hilbert A A -module is projective (with bounded module maps as morphisms). We also study the approximate extensions of bounded module maps. In the case that A A is a σ \sigma -unital simple C ∗ C^{*} -algebra with strict comparison and every strictly positive lower semicontinuous affine function on quasitraces can be realized as the rank of an element in Cuntz semigroup, we show that the Cuntz semigroup is the same as unitarily equivalent class of countably generated Hilbert A A -modules if and only if A A has stable rank one.

Introduction

We study Hilbert module over a
C^{*}
-algebra
A.

A Hilbert
A
-module
H
is said to be projective (with bounded module maps as morphisms)
if, for any
Hilbert
A
-modules
H_{1}
and
H_{2},
any bounded module map

\varphi:H\to H_{1}
and any surjective bounded module map
s:H_{2}\to H_{1},
there is always
a bounded module map
\psi:H\to H_{2}
such that
\varphi=s\circ\psi.

It is easy to see that, when
A
is a unital
C^{*}
-algebra, a direct sum
A^{(n)}
of
n
copies of
A
is
a projective Hilbert
A
-module.
However, it is not known that this holds for non-unital
C^{*}
-algebras.
One observes that, for a non-unital
C^{*}
-algebra
A,
it itself is
not algebraically finitely generated as an
A
-module.
The characterization of projective Hilbert modules over a

C^{*}
-algebra
A
seems to remain elusive for decades. Evidence, on the other hand, suggests that most countably
generated Hilbert modules are projective. In this paper, we will confirm that, for any separable
C^{*}
-algebra
A,

every countably generated Hilbert
A
-module is projective.

It is attempting to classify countably generated Hilbert
A
-modules.
It was shown in
[
11
]
that, when
A
has stable rank one, unitary equivalence classes of Hilbert

A
-modules are determined by the Cuntz semigroup of
A.
One might prefer a more quantified description
of Hilbert
A
-modules using some version of dimension functions. Indeed,
in the case that
A
is a separable simple

C^{*}
-algebra  such that its purely non-compact elements in the Cuntz semigroup are determined by
strictly positive lower semicontinuous affine functions on its
quasitraces, then one wishes to use the same functions to described those Hilbert
A
-modules
which are not algebraically finitely generated. We show that in this case,
Cuntz equivalence classes are the same as unitary equivalence classes of countably generated Hilbert

A
-modules if and only if
A
has tracial approximate oscillation zero, or equivalently, in this case,

A
has stable rank one. This is a partial converse of the theorem in
[
11
]
mentioned above.

Injective Hilbert
A
-modules were studied in
[
33
]
. If
A
is not an
AW^{*}
-algebra,
then
A
itself is not an injective Hilbert
A
-module (with bounded module maps as morphisms) (see
Theorem 3.14 of
[
33
]
).
Even if we only consider bounded module maps with adjoints, there are only very few injective Hilbert
modules.
It was shown in
[
33
]
that a countably generated Hilbert
A
-module is *-injective if only if it is orthogonal complementary.
Let
H
be a countably generated Hilbert
A
-module. Suppose that
H_{0}\subset H_{1}
are
Hilbert
A
-modules and
\varphi:H_{0}\to H
is a bounded module map.
As we mentioned

\varphi
may not be extended to a bounded module map
from
H_{1}
to
H.

However, we show that one may find a sequence of bounded module maps

\varphi_{n}:H_{1}\to H
with
\|\varphi_{n}\|\leq\|\varphi\|
such that

\lim_{n\to\infty}\|\varphi_{n}(x)-\varphi(x)\|=0
for all
x\in H_{0}
(note that
H_{0}
is not assumed to
be separable).
This result may be stated as every countably generated Hilbert module
over a
\sigma
-unital
C^{*}
-algebra
A
is “sequentially approximately injective”.
With the same spirit, we show that every countably generated Hilbert module
over a
\sigma
-unital
C^{*}
-algebra  is “sequentially approximately projective”.

The paper is organized as follows:
Section 2 collects some easy facts about projective Hilbert modules and algebraically finitely generated
Hilbert modules over a
C^{*}
-algebra.
Section 3 discusses some basic results about countably generated Hilbert A-modules.
In Section 4, we show that, under the assumption that
A
is a
\sigma
-unital simple

C^{*}
-algebra  with strict comparison and the canonical (dimension function) map
\Gamma
from
Cuntz semigroup to lower semi-continuous affine functions on quasitraces

{\widetilde{QT}}(A)
is surjective, countably generated (but not algebraically generated) Hilbert
A
-modules
can be classified by these lower semi-continuous affine functions if and only if
A
has stable rank one.
This is a partial converse of a theorem in
[
11
]
. We also show that, assume that

A
is a
\sigma
-unital simple
C^{*}
-algebra  with finite radius of comparison, then a countably generated Hilbert

A
-module with infinite quasitrace is unitarily equivalent to
l^{2}(A).

In section 5, we show that every countably generated Hilbert module over a separable
C^{*}
-algebra
A
is always
projective. Section 6 shows that every Hilbert
A
-module is “approximately injective,” and
every countably generated Hilbert module over a
\sigma
-unital
C^{*}
-algebra
A
is “approximately projective”.

Easy facts about projective Hilbert modules

Definition 2.1
.

Let
A
be a
C^{*}
-algebra. For an integer

denote by

the
(right) Hilbert
A
-module of orthogonal direct sum of
n

If

then

\langle x,y\rangle=\sum_{i=1}^{n}a_{n}^{*}b_{n}.

Denote by
H_{A},
or

the standard countably generated Hilbert

A
-module

H_{A}=\{\{a_{n}\}:\sum_{n=1}^{k}a_{n}^{*}a_{n}\,\,\,{\rm converges\,\,\,in\,\,\,norm\,\,as}\,\,k\to\infty\},

where the inner product is defined by

\langle\{a_{n}\},\{b_{n}\}\rangle=\sum_{n=1}^{\infty}a_{n}^{*}b_{n}.

Let
H
be a Hilbert
A
-module. denote by
H^{\sharp}
the set of
all bounded
A
-module maps from
H
to
A.

For each
y\in H,
define
\hat{y}(x)=\langle y,x\rangle
for all
x\in H.
Then

\hat{y}\in H^{\sharp}.
We say
H
is self-dual, if every
f\in H^{\sharp}
has the form

\hat{y}
for some
y\in H.

If
H_{1},H_{2}
are
Hilbert
A
-modules, denote by
B(H_{1},H_{2})
the space of all
bounded module maps from
H_{1}
to
H_{2}.
If
T\in B(H_{1},H_{2}),

denote by
T^{*}:H_{2}\to H_{1}^{\sharp}
the bounded module maps
defined by

T^{*}(y)(x)=\langle y,Tx\rangle\,\,\,\text{for\,\,\,all}\,\,\,x\in H_{1}\,\,\,{\rm and}\,\,\,y\in H_{2}.

If
T^{*}\in B(H_{2},H_{1}),
one says that
T
has an adjoint
T^{*}.
Denote by

L(H_{1},H_{2})
the set of all bounded
A
-module maps in
B(H_{1},H_{2})
with adjoints. Let
H
be a Hilbert
A
-module. In what
follows, denote
B(H)=B(H,H)
and
L(H)=L(H,H).

B(H)
is a
Banach algebra and
L(H)
is a
C^{*}
-algebra.

For
x,y\in H,
define
\theta_{x,y}\in L(H)
by

\theta_{x,y}(z)=x\langle y,z\rangle
for all
z\in H.

Denote by
F(H)
the linear span of those module maps with the form

\theta_{x,y},
where
x,y\in H.
Denote by
K(H)
the
closure of
F(H).

K(H)
is a
C^{*}
-algebra. It follows from a result of
Kasparov (
[
26
]
) that
L(H)=M(K(H)),
the multiplier algebra of

K(H),
and, by
[
31
]
,
B(H)=LM(K(H)),
the left multiplier
algebra of
K(H).

Suppose that
H_{1}
and
H_{2}
are Hilbert
A
-submodules of a Hilbert
A
-module
H.

Then
K(H_{i})
is a hereditary
C^{*}
-subalgebra  of
K(H),

i=1,2,
(see Lemma 2.13
[
33
]
).
Denote by
K(H_{1},H_{2})

the subspace of
K(H)
consists of module maps
of the form
STL,
where
S\in K(H_{2}),

T\in B(H)
and
L\in K(H_{1}),
where

K(H_{2})
and
K(H_{1})
are viewed as hereditary
C^{*}
-subalgebras of
K(H).

Note that
K(H_{1},H_{2})
is
the closure of the linear span of those
module maps with the form
\theta_{x,y},
where
x\in H_{2}
and
y\in H_{1}.

It is convenient to have an example that
H\not=H^{\sharp}.

Let
A
be a
C^{*}
-algebra  with a sequence
\{d_{n}\}
of mutually orthogonal positive elements
with
\|d_{n}\|=1.

Define
f(\{a_{n}\})=\sum_{n=1}^{\infty}d_{n}a_{n}
for all
\{a_{n}\}\in H_{A}.

Then

is a bounded module map but

f\not\in H.

Two Hilbert
A
-modules are said to be unitarily equivalent, or isomorphic, if there
is an invertible map
U\in B(H_{1},H_{2})
such that

\langle U(x_{1}),U(x_{2})\rangle=\langle x_{1},x_{2}\rangle\,\,\,\text{for\,\,\,all}\,\,\,x_{1},x_{2}\in H_{1}.

(see
[
41
]
for further basic information).

Definition 2.3
.

Let
H
be a Hilbert
A
-module and
{\cal F}\subset H
be a subset.
We say that

is generated by

(as a Hilbert

We say

if every element

Note that we write

Definition 2.4
.

Let
A
be a
C^{*}
-algebra  and
H
be a Hilbert
A
-module.
We say that
H
is
*
-projective, if, for any Hilbert
A
-modules
H_{1}
and
H_{2},
any
module map
\varphi\in L(H,H_{2})
and any surjective module map

s\in L(H_{1},H_{2}),
there exists a module map
\psi\in L(H,H_{1})

\displaystyle s\circ\psi=\varphi.

(e 2.1)

Note here we assume that
s,\varphi
and

Theorem 2.5
.

Let
A
be a
C^{*}
-algebra.

(1)
Suppose that
H
and
H_{1}
are Hilbert
A
-modules and

s\in L(H_{1},H)
is surjective.
Then there is

\psi_{1}\in L(H,H_{1})
such that

\displaystyle s\circ\psi_{1}={\rm id}_{H}.

(e 2.2)

Moreover,
\psi_{1}(H)
is an orthogonal summand of
H_{1}
and

\psi_{1}(H)
is unitarily equivalent to
H.

(2)
Every Hilbert
A
-module is
*
-projective.

Proof.

For (1), let

s
be as described. We note that
s
has a closed range. Define
T:H_{1}\oplus H\to H_{1}\oplus H
by
T(h_{1}\oplus h)=0\oplus s(h_{1})
for

h_{1}\in H_{1}
and
h\in H.
Then
T\in L(H_{1}\oplus H)=M(K(H_{1}\oplus H))
(see Theorem 1.5 of
[
31
]
). It follows from Lemma 2.4 of
[
33
]
that

\displaystyle H_{1}\oplus H={\rm ker}T\oplus|T|(H_{1}\oplus H).

(e 2.3)

Let
T=V|T|
be the polar decomposition in
(K(H_{1}\oplus H))^{**}.

Note that the proof of Lemma 2.4 of
[
33
]
shows that
0
is an
isolated point of
|T|
or
|T|
is invertible. So the same holds for
(T^{*}T),
and
hence the same holds for

(TT^{*}).
Let
S=(TT^{*})^{-1},
where the inverse is taken in
the hereditary
C^{*}
-subalgebra
L(H)\subset L(H_{1}\oplus H).
Since
s
is
surjective,

\displaystyle|TT^{*}|(H)=H.

(e 2.4)

Note that
T^{*}=|T|V^{*},

V|T|V^{*}=|TT^{*}|^{1/2}
and
V^{*}|TT^{*}|^{1/2}=T^{*}.

Hence

\displaystyle L_{1}:=V^{*}(TT^{*})^{-1/2}=V^{*}(TT^{*})^{1/2}S=T^{*}S\in L(H_{1}\oplus H).

(e 2.5)

This also implies that
L_{1}(H)=V^{*}((TT^{*})^{-1/2}(H))=V^{*}(H)
is closed.
Moreover,
V^{*}
gives a unitary equivalence of
H
and
L_{1}(H).

One then checks that

\displaystyle TL_{1}=V|T|V^{*}(TT^{*})^{-1/2}=P,

(e 2.6)

where
P
is the range projection of
(TT^{*})^{1/2}
which gives the
identity map on
H.
Since both
T
and
L_{1}
are in
L(H_{1}\oplus H),

so is
P.

One then defines
\psi_{1}=L_{1}P|_{H}:H\to H_{1}.
Thus
s\circ\psi_{1}={\rm id}_{H}.

Next we note that
H\subset{\rm ker}T
and
|T|(H_{1}\oplus H)=|T|(H_{1})\subset H_{1}.

It follows that
{\rm ker}T=H_{0}\oplus H.
By
(
e 2.3
) again,
H_{1}\oplus H=H_{0}\oplus H\oplus|T|(H_{1}).

It follows that

|T|(H)
is an orthogonal summand of
H_{1}.

On the other hand, since
\psi_{1}(H)=L_{1}(H)=V^{*}(H),

\psi_{1}(H)

is closed. But we also have
\psi_{1}(H)=T^{*}S(H)=T^{*}T(H_{1})=|T|(H_{1}).

As we have shown that
L_{1}(H)
is unitarily equivalent to
H,
this proves the “Moreover” part of (1).

To show that every Hilbert
A
-module
H
is
*
-projective,
let
H_{1}
and
H_{2}
be Hilbert
A
-modules,
\varphi:H\to H_{1}
and
s:H_{2}\to H_{1}

be bounded module maps with adjoints, where
s
is surjective.
We now apply the statement of (1).

Note that (1) holds for any Hilbert
A
-module, in particular,
it holds for
H_{1}
(in place of
H
).
Since
s
is surjective, we obtain

\psi_{1}\in L(H_{1},H_{2})
such that

\displaystyle s\circ\psi_{1}={\rm id}_{H_{1}}.

(e 2.7)

Define
\psi=\psi_{1}\circ\varphi:H\to H_{2}.
Then

Let

From

,

{\tilde{A}}

be Hilbert

\begin{array}[]{ccccc}H&\leftarrow_{j}&H\oplus H^{\prime}&\leftarrow_{\iota}H\\

Proposition 2.11

(L. Robert)
.

be a
C^{*}
-algebra  and

be an algebraically finitely generated Hilbert

-module.

Proof.

Write

(where
{{\xi_{i}}}\in H
).
Put

We view both

and

as Hilbert
\tilde{A}
-modules.
Write

where

Define a module map

by

1\leq i\leq n.

Then

\displaystyle s(h)=\sum_{i=1}^{n}\xi_{i}\langle e_{i},h\rangle\,\,\,{\rm for\,\,\,all}\,\,\,h\in H_{1}.

(e 2.13)

In other words

In particular,

Since

is algebraically generated by

to obtain the bounded module map

(with notation in the proof of

By Theorem
2.5
,
\psi_{1}(H)
is an orthogonal summand of

Let

be a bounded module map
which implements the unitary equivalence. Note that

Let

be the projection
of

Lemma 2.12

(cf. Proposition 1.4.5 of
[
42
]
)
.

Let
A
be a
C^{*}
-algebra  and

H
a Hilbert
A
-module and

Then, for any

there exists

with

such
that

Proof.

We first consider Hilbert
\tilde{A}

\overline{x\tilde{A}}.

Put
a=\langle x,x\rangle,

a_{n}=(1/n+a)^{-{\alpha}}
and
x_{n}=x\cdot(1/n+a)^{-{\alpha}},

n\in\mathbb{N}.

We will show that
\{x_{n}\}
is a Cauchy sequence.

Put
{\beta}_{n,m}=(1/n+a)^{-{\alpha}}-(1/m+a)^{-{\alpha}},

n,m\in\mathbb{N}.

Then

\|x{\beta}_{n,m}\|=\|({\beta}_{n,m}\langle x,x\rangle{\beta}_{n,m})^{1/2}\|=\|a^{1/2}{\beta}_{n,m}\|.

converges to

in norm.
we conclude that

as

for some

Moreover,

(converge in norm).

Since
x_{n}a^{\alpha}=xa_{n}a^{\alpha},
we obtain that

It follows that

Choose

Then
(1/n+a)^{-{\alpha}^{\prime}}a^{{\alpha}^{\prime}-{\alpha}}\in A.

Since

∎

Definition 4.7
.

Let
A

C^{*}

in this paper. It should be mentioned

Lemma 4.8
.

Let
A
be a
\sigma
-untal algebraically simple
C^{*}
-algebra  with
QT(A)\not=\emptyset,

strict comparison and surjective
\Gamma.

For any

there is
b\in(A\otimes{\cal K})_{+},
such
that
\Gamma([a])=\Gamma([b])
in
{\rm Cu}(A)
such that

\Omega^{T}(b)=0.

Proof.

Recall that
we assume that
QT(A)\not=\emptyset.

Let
g\in{\rm LAff}_{+}(\overline{QT(A)}^{w})
be such that
\widehat{[a]}=g.

There is a sequence of increasing
g_{n}\in\operatorname{Aff}_{+}(QTA)
such that

g_{n}\nearrow g
(pointwisely).

Put
f_{1}=g_{1}-(1/4)g_{1}\in{\rm Aff}_{+}(\overline{QT(A)}^{w})
and
{\alpha}_{1}=1/4.
Then
g_{2}(\tau)>f_{1}(\tau)

for all
\tau\in\overline{QT(A)}^{w}.
Choose

(1-{\alpha}_{2})g_{2}(\tau)>f_{1}(\tau)

Put

Suppose that

Then
g_{n+1}(\tau)>(1-{\alpha}_{n})g_{n}(\tau)

Define

and
h_{n}=f_{n}-f_{n-1}
for

Then

\Gamma
is surjective, there are

such that

Define

In other words,
\Gamma([a])=\Gamma([b]).

For each

\widehat{[a_{n}]}

\overline{QT(A)}^{w},

(by Lemma 4.5 of
[
20
]

\displaystyle d_{\tau}(a_{n})-\tau(e_{n,m})<1/2^{n+m}\,\,\,{\rm for\,\,\,all}\,\,\,\tau\in\overline{QT(A)}^{w},\,\,\,{\rm and}\,\,\,\omega(e_{n,m})<1/2^{n+m}.

(e 4.50)

Since

if

we have that

By (2) of Proposition 4.4 of
[

(e 4.51)

Hence

Theorem 4.9
.

Lemma 5.1
.

Let
A
be a
C^{*}
-algebra  and
H
be Hilbert
A
-modules.
Suppose that

is a bounded module map

is a Hilbert

Proof.

Let
H_{1}=T(H)
and
F(H)
be the linear span of bounded module maps of the form

\theta_{x,y}
for
x,y\in H.

Note that
Lb(x)=Tb(x)

and
x\in H.

Let

Since
T:H\to H_{1}
is surjective, there is
x\in H

T(x)=\xi.
Then
T\circ\theta_{x,\zeta}=\theta_{\xi,\zeta}.

This implies that
LF(H)=F(H_{1}).

Let

be as a Hilbert submodule of
H.
Then
K(H_{0})\subset K(H)

C^{*}
-subalgebra  of
K(H)
(see Lemma 2.13 of
[

be the

and

for all

We identify

with
(1-p)H
(
\subset H^{\sim}
). Let
\tilde{T}:(1-p)H\to H_{1}
be
the bounded module map induced by
T
which has a bounded inverse
\tilde{T}^{-1}

as
T
is surjective. Note that
\tilde{T}^{-1}(T(z))=(1-p)z
for all
z\in H.

To show that
T(K(H))=K(H_{1}),
fix

Let

be such that

Then, for any

We claim that

for some

Note that, for any

\displaystyle\|(1-p)F_{n}(x)-(1-p)F_{m}(x)\|=\|\tilde{T}^{-1}(LF_{n}(x)-LF_{m}(x))\|\leq\|\tilde{T}^{-1}\|\|S_{n}-S_{m}\|\|x\|.

It then follows that, for any

\displaystyle Lb=L(1-p)b=\lim_{n\to\infty}L(1-p)F_{n}=\lim_{n\to\infty}S_{n}=S.

This shows that

Corollary 6.5
.

Let
A
be a
C^{*}
-algebra  and
H_{0}\subset H
be Hilbert
A
-modules.
Suppose that there is a bounded module map
\varphi:H_{0}\to A.
Then,
for any
\epsilon>0
and any finite subset
{\cal F}\subset H_{0},
there exists a
bounded module map
\psi:H\to A
such that

\displaystyle\|\varphi(x)-\psi(x)\|<\epsilon\,\,\,\text{for\,\,\,all}\,\,\,x\in{\cal F}\,\,\,\text{and}\,\,\,\|\psi\|\leq\|\varphi\|.

(e 6.98)

If, in addition,
H_{0}
is countably generated Hilbert
A
-module, then there exists
a sequence of bounded module maps
\psi_{n}:H\to A
such that

\displaystyle\lim_{n\to\infty}\|\psi_{n}(x)-\varphi(x)\|=0\,\,\,\text{for\,\,\,all}\,\,\,x\in H\,\,\,\text{and}\,\,\,\|\psi_{n}\|\leq\|\varphi\|\,\,\,\text{for\,\,\,all}\,\,\,n\in\mathbb{N}.

(e 6.99)

Remark 6.6
.

In the light of Theorem
6.4
,
one may think that every
Hilbert
A
-module is “approximately injective”.
Next, let us turn to “approximate projectivity”.

Lemma 6.7
.

Let
A
be a
\sigma
-unital
C^{*}
-algebra  and
H=A^{(k)}
(for some
k\in\mathbb{N}
).
Suppose that
H_{1},H_{2}
are Hilbert
A
-modules,
\varphi:H\to H_{1}
is a bounded
module map and
s:H_{2}\to H_{1}
is a surjective bounded module map.
Then there exists a sequence of bounded module maps

\psi_{n}:H\to H_{2}
and an increasing sequence
of Hilbert
A
-submodules
X_{n}\subset H

such that
\overline{\cup_{n=1}^{\infty}X_{n}}=H,

\displaystyle{s\circ\psi_{m}}|_{H_{n}}=\varphi|_{H_{n}}\,\,\,\,\,\text{for\,\,\,all}\,\,\,m\geq n.

(e 6.100)

Moreover there exists a sequence of module maps
T_{n}:H\to X_{n}

such that
\|T_{n}\|\leq 1
and

\displaystyle\lim_{n\to\infty}\|T_{n}(h)-h\|=0,\,T_{2n+j}|_{H_{n}}={\rm id}_{H_{n}},\,\,n,j\in\mathbb{N},

(e 6.101)

\displaystyle\,\,\,{\rm and}\,\,\,s\circ\varphi_{n}(h)=\varphi(T_{n}(h))\,\,\,\text{for\,\,\,all}\,\,\,h\in H.

(e 6.102)

In particular,

\displaystyle\lim_{n\to\infty}\|s\circ\psi_{n}(x)-\varphi(x)\|=0\,\,\,\text{for\,\,\,all}\,\,\,x\in H.

(e 6.103)

Proof.

Fix a strictly positive element
e\in A.

Write
A^{(n)}=\overline{e_{1}A}\oplus\overline{e_{2}A}\oplus\cdots\oplus\overline{e_{n}A},

where
e_{i}=e^{1/2}
(
1\leq i\leq n
).
Let
f_{1/n}\in C([0,\infty))
be defined in (4) of
4.4
,
n\in\mathbb{N}.

For each
n\in\mathbb{N},
define
X_{n}=\bigoplus_{i=1}^{k}\overline{f_{1/n}(e_{i})A}.

Note that
X_{n}\subset X_{n+1},

n\in\mathbb{N},
and
\overline{\cup_{n=1}^{\infty}X_{n}}=A^{(k)}=H.

Let
x_{n,i}=\varphi(f_{1/2n}(e_{i})),

1\leq i\leq k,
and
n\in\mathbb{N}.

Choose
y_{m,i}\in H_{2}

such that
s(y_{m.i})=x_{m,i},

1\leq i\leq m
and
m\in\mathbb{N}.

Define
\psi_{n}:H\to H_{2}
by

\displaystyle\psi_{n}(h)=\sum_{i=1}^{k}y_{n,i}\langle f_{1/2n}(e_{i}),h\rangle\,\,\,{\rm for\,\,\,all}\,\,\,h\in H.

(e 6.104)

It follows that
\psi_{n}\in K(H,H_{2}).

If
h=\bigoplus_{i=1}^{k}f_{1/n}(e)a_{i},
where

then

\displaystyle\psi_{n}(h)=\sum_{i=1}^{k}y_{n,i}f_{1/n}(e)a_{i}.

(e 6.105)

Hence,
for

where
a_{i}\in A
(
1\leq i\leq k
), and for any
j\geq 0,

\displaystyle s(\psi_{n+j}(\sum_{i=1}^{k}f_{1/n}(e_{i})a_{i}))

\displaystyle=

\displaystyle s(\sum_{i=1}^{k}y_{n+j,i}f_{1/n}(e)a_{i})

(e 6.106)

\displaystyle=

\displaystyle\sum_{i=1}^{k}\varphi(f_{1/2(n+j)}(e_{i}))f_{1/n}(e)a_{i}

(e 6.107)

\displaystyle=

\displaystyle\sum_{i=1}^{k}\varphi(f_{1/2(n+j)}(e_{i})f_{1/n}(e))a_{i}

(e 6.108)

\displaystyle=

\displaystyle\sum_{i=1}^{k}\varphi(f_{1/n}(e_{i}))a_{i}=\varphi(\sum_{i=1}^{k}f_{1/n}(e_{i})a_{i}).

\displaystyle=

\displaystyle\bigoplus_{i=1}^{k}f_{1/n}(e)a_{i}.

(e 6.112)

(e 6.118)

H=H_{A}=l^{2}(A).

So now we assume that
H=l^{2}(A).

Put
Y_{n}=A^{(n)},

n\in\mathbb{N}.
We view
Y_{n}\subset Y_{n+1}
as
an increasing sequence of Hilbert
A
-submodules of
H=l^{2}(A)

and the closure of the union is
H.

By applying Lemma
6.7
, we obtain, for each
n\in\mathbb{N},

an increasing sequence of Hilbert
A
-submodules
X_{n,j}\subset X_{n,j+1}

such that
\overline{\cup_{j=1}^{\infty}X_{n,j}}=Y_{n},
and
there exists a sequence of bounded module maps

\psi_{n,j}:Y_{n}\to H_{2}
and module maps
T_{n,j}:Y_{n}\to X_{n,j}
with
\|T_{n,j}\|\leq 1
such that

\displaystyle{s\circ\psi_{n,j+i}}|_{X_{n,j}}=\varphi|_{X_{n,j}},\,\,\,j,i\in\mathbb{N},

(e 6.121)

\displaystyle T_{n,2j+i}|_{X_{n,j}}={\rm id}|_{X_{n,j}},\,\,\,j,i\in\mathbb{N},\,\,\,{\rm and}\,\,\,

(e 6.122)

\displaystyle\lim_{j\to\infty}\|T_{n,j}(h)-h\|=0\,\,\,{\rm for\,\,\,all}\,\,\,h\in Y_{n}\,\,\,{\rm and}\,\,\,

(e 6.123)

\displaystyle s\circ\psi_{n,j}(h)=\varphi(T_{n,j}(h))\,\,\,{\rm for\,\,\,all}\,\,\,h\in Y_{n}\,\,\,{\rm and}\,\,\,j\in\mathbb{N}.

(e 6.124)

Note that
Y_{n}=A^{(n)}\subset A^{(n+1)}=Y_{n+1},

n\in\mathbb{N},
therefore we may arrange so that

\displaystyle X_{n,j}\subset X_{n+1,j}\,\,\,{\rm for\,\,\,all}\,\,\,j\in\mathbb{N}\,\,\,{\rm and}\,\,\,n\in\mathbb{N}.

(e 6.125)

Define
P_{n}:H\to Y_{n}
by
P_{n}(\bigoplus_{n=1}^{\infty}a_{n})=\bigoplus_{i=1}^{n}a_{i},

where
\sum_{n=1}^{\infty}a_{n}^{*}a_{n}
converges, i.e,
\bigoplus_{n=1}^{\infty}a_{n}\in l^{2}(A)=H.

Then
P_{n}
is a projection from
H=H_{A}
onto
A^{(n)}.

Now define

\displaystyle\psi_{n}=\psi_{n,2n}\circ P_{n}:H\to H_{2},\,\,\,n\in\mathbb{N}.

(e 6.126)

We will verify that
\psi_{n}
meets the requirements.

Fix
h=\bigoplus_{n=1}^{\infty}a_{n}\in l^{2}(A)=H.

There is
n_{0}\in\mathbb{N}
such that, for all
n\geq m\geq n_{0},

\displaystyle\|P_{m}(h)-h\|<\epsilon/6(\|\varphi\|+1)\,\,\,{\rm and}\,\,\,\|P_{n}(h)-P_{m}(h)\|<\epsilon/6(\|\varphi\|+1).

(e 6.127)

For
P_{n_{0}}(h)\in A^{(n_{0})},
there is
n_{1}\in\mathbb{N}
such
that, for all
n\geq n_{1}

\displaystyle\|T_{n_{0},n}(P_{n_{0}}(h))-P_{n_{0}}(h)\|<\epsilon/6(\|\varphi\|+1).

(e 6.128)

Since
T_{n_{0},n}(P_{n_{0}}(h))\in X_{n_{0},n}\subset X_{n,n}
(see (
e 6.125
)),
by (
e 6.122
),

\displaystyle T_{n,2n}(T_{n_{0},n}(P_{n_{0}}(h)))=T_{n_{0},n}(P_{n_{0}}(h)).

(e 6.129)

Hence, if
n\geq n_{1}+n_{0},
by (
e 6.129
) and by (
e 6.128
),

\displaystyle\hskip-101.17755pt\|T_{n,2n}(P_{n_{0}}(h))-P_{n_{0}}(h)\|=\|T_{n,2n}(P_{n_{0}}(h))-T_{n,2n}(T_{n_{0},n}(P_{n_{0}}(h)))\|

(e 6.131)

\displaystyle\hskip 72.26999pt+\|T_{n,2n}((T_{n_{0},n}(P_{n_{0}}(h))))-P_{n_{0}}(h)\|

\displaystyle\leq

\displaystyle\|T_{n,2n}\|\|P_{n_{0}}(h)-T_{n_{0},n}(P_{n_{0}}(h))\|+\|T_{n_{0},n}(P_{n_{0}}(h))-P_{n_{0}}(h)\|

(e 6.132)

\displaystyle<

\displaystyle\epsilon/6(\|\varphi\|+1)+\epsilon/6(\|\varphi\|+1)

(e 6.133)

\displaystyle=

\displaystyle\epsilon/3(\|\varphi\|+1).

(e 6.134)

We also estimate that, if
n\geq n_{1}+n_{0},
by both parts of (
e 6.127
) and the inequalities right above,

\displaystyle\|T_{n,2n}(P_{n}(h))-h\|

\displaystyle\leq

\displaystyle\|T_{n,2n}(P_{n}(h))-P_{n_{0}}(h)\|+\|P_{n_{0}}(h)-h\|

(e 6.135)

\displaystyle<

\displaystyle\|T_{n,2n}(P_{n}(h)-P_{n_{0}}(h))\|+\|T_{n,2n}(P_{n_{0}}(h))-P_{n_{0}}(h)\|+\epsilon/6(\|\varphi\|+1)

\displaystyle<

\displaystyle\|T_{n,2n}\|(\epsilon/3(\|\varphi\|+1))+\epsilon/3(\|\varphi\|+1))+\epsilon/3(\|\varphi\|+1)

\displaystyle=

\displaystyle\epsilon/(\|\varphi\|+1).

We then have, by (
e 6.126
),
(
e 6.124
) and (
e 6.135
),

\displaystyle\|s\circ\psi_{n}(h)-\varphi(h)\|

\displaystyle\leq

\displaystyle\|s\circ\psi_{n,2n}(P_{n}^{2}(h))-\varphi(T_{n,2n}(P_{n}(h)))\|+\|\varphi(T_{n,2n}(P_{n}(h)))-\varphi(h)\|

\displaystyle<0+\epsilon.

Next we consider the general case that
H
is an arbitrary countably generated Hilbert

A
-module. By Kasparov’s absorbing theorem (
[
26
]
), there is
a Hilbert module isomorphism
U:H\oplus l^{2}(A)\to l^{2}(A).

Define
j:H\to H\oplus l^{2}(A)
to be the obvious embedding and
p:H\oplus l^{2}(A)\to H

the projection. Thus
p\circ j={\rm id}_{H}.

Define
\Phi=\varphi\circ p\circ U^{-1}:l^{2}(A)\to H_{1}.

Then
we have the following commutative diagram:

\begin{array}[]{ccccc}l^{2}(A)&\\
&&\\
{}_{U}\updownarrow^{U^{-1}}&\searrow^{\Phi}\\
&&\\
H\oplus l^{2}(A)&\stackrel{{\scriptstyle\varphi\circ p}}{{\longrightarrow}}&H_{1}.\end{array}

In particular,
\Phi\circ U(x)=\varphi(x)
for all
x\in H.

By what have been proved above, there exists a sequence of module maps
\Psi_{n}:l^{2}(A)\to H_{2}

such that

\displaystyle\lim_{n\to\infty}\|s\circ\Psi_{n}(z)-\Phi(z)\|=0\,\,\,{\rm for\,\,\,all}\,\,\,z\in l^{2}(A).

(e 6.136)

Define
\psi_{n}:H\to H_{2}
by
\psi_{n}(x)=\Psi_{n}\circ U(x)

for all
x\in H.
It follows that

\displaystyle,\lim_{n\to\infty}\|s\circ\psi_{n}(x)-\varphi(x)\|=\lim_{n\to\infty}\|s\circ\Psi_{n}(U(x))-\Phi(U(x))\|=0.

(e 6.137)

∎

Remark 6.9
.

Note that, in Lemma
6.7
,
for any
\epsilon>0,
we may choose
\|y_{n}\|\leq\|\tilde{s}^{-1}\circ\varphi\|+\epsilon.

So we may estimate that
\|\psi_{n}\|\leq\sqrt{k}(\|\tilde{s}^{-1}\circ\varphi\|+\epsilon),

which unfortunately depends on
k.
Therefore we do not have an estimate on the norm
of
\psi_{n}
in Theorem
6.8
. This is also the reason that the proof seems a little more involved than
expected (as we need a complicated statement in Lemma
6.7
). If
\{\|\psi_{n}\|\}
were, at least, uniformly bounded, then the proof would be much shorter.

However, under the assumption that
A
has real rank zero, in the next statement,
we then have a better estimate on the norm
on
\psi_{n}.

Theorem 6.10
.

Let
A
be a
\sigma
-unital
C^{*}
-algebra  of real rank zero and
H
a countably generated Hilbert
A
-module.
Suppose that
\varphi:H\to H_{1}
is a bounded module map
and
s:H_{2}\to H_{1}
is a surjective bounded module map.
Then there exists a sequence of module maps
\psi_{n}:H\to H_{2}
such that

\displaystyle\|\psi_{n}\|\leq\|{\tilde{s}}^{-1}\circ\varphi\|\,\,\,\text{and}\,\,\,\lim_{n\to\infty}\|s\circ\psi_{n}(x)-\varphi(x)\|=0\,\,\,\text{for\,\,\,all}\,\,\,x\in H.

(e 6.138)

Proof.

Since
H
is countably generated,
by Corollary 1.5 of
[
39
]
(see
(Lemma
3.2
, for convenience),
K(H)
is a
\sigma
-unital hereditary
C^{*}
-subalgebra  of
A\otimes{\cal K}

(see also Lemma 2.13 of
[
33
]
). Let
\{P_{m}\}
be an approximate identity for
K(H)
consisting of projections.
Put
H_{0,m}=P_{m}(H).
Then
K(H_{0,m})=P_{m}K(H)P_{m}
is unital.
It follows from Proposition
2.7
that
H_{0,m}
is algebraically finitely generated,
say, by
\{\xi_{m,i}:1\leq i\leq d(m)\},
where
\|\xi_{m,i}\|=1.

It is important to note that
H_{0,m}\subset H_{0,m^{\prime}}
if
m<m^{\prime}.

Fix
m\in\mathbb{N}.
Let
H_{1,m}
be the Hilbert
A
-submodule of
H_{1}

generated by
\{x_{m,i}=\varphi(\xi_{m,i}):1\leq i\leq d(m)\}.

Since
H_{0,m}\subset H_{0,m^{\prime}},

H_{1,m}\subset H_{1,m^{\prime}},

if
m<m^{\prime}.

Then
K(H_{1,m})
is a
\sigma
-unital hereditary
C^{*}
-subalgebra  of
A\otimes{\cal K}
(see Lemma
3.2
),
m\in\mathbb{N}.
Since

A
has real rank zero, so is
K(H_{1,m}),

m\in\mathbb{N}.

Let
\{p_{m,k}\}_{k=1}^{\infty}
be an approximate identity for
K(H_{1,m}).

Let
H_{1,m,k}=p_{m,k}(H_{1,m}),

k,m\in\mathbb{N}.

Since
H_{1,m}\subset H_{1,m^{\prime}},
if
m\leq m^{\prime},

K(H_{1,m})\subset K(H_{1,m^{\prime}})
(see Lemma 2.13 of
[
33
]
).
So we may assume that

\displaystyle\|p_{m+1,k}p_{m,k}-p_{m,k}\|<{1\over{2^{k+m+1}(\|\varphi\|+1)}},\,\,k,m\in\mathbb{N}.

(e 6.139)

Note that
K(H_{1,m,k})=p_{m,k}K(H_{1,m})p_{m,k}
which is unital.
It follows from Proposition
3.2
that
H_{1,m,k}
is algebraically finitely generated, say,
by

z_{m,k,1},z_{m,k,2},...,z_{m,k,r(m,k)}
as
A
-module.
Choose
y_{m,k,j}\in H_{2}
such that
s(y_{m,k,j})=z_{m,k,j},

1\leq j\leq r(m,k),

k,m\in\mathbb{N}.

Let
H_{2,m,k}
be the Hilbert
A
-submodule of
H_{2}
generated by
\{y_{m,k,j}:1\leq k=j\leq r(m,k)\}

as Hilbert
A
-module.

Then, since
H_{1,m,k}
is algebraically generated by
z_{m,k,1},z_{m,k,2},...,z_{m,k,r(i,k)}
as
A
-module,

s(H_{2,m,k})=H_{1,m,k}.
In other words,
s|_{H_{2,m,k}}
is surjective (onto
H_{1,m,k}
).

Fix an integer
m\in\mathbb{N}.
Define
\varphi_{m,k}:H\to H_{1,m,k}
by

\displaystyle\varphi_{m,k}(x)=p_{m,k}\circ\varphi(P_{m}(x))

(e 6.140)

for all
x\in H.
Note that
\|\varphi_{m,k}\|\leq\|\varphi\|,

m,k\in\mathbb{N}.

Now
H_{2,m,k}
is countably generated,
it follows from Theorem
5.3
that there is a module
map
\psi_{m,k}:H\to H_{2,m,k}
such that

\displaystyle s\circ\psi_{m,k}=\varphi_{m,k}\,\,\,{\rm for\,\,\,all}\,\,\,k,m\in\mathbb{N},\,\,\,{\rm and}\,\,\,

(e 6.141)

\displaystyle\|\psi_{m,k}\|\leq\|\tilde{s}^{-1}\circ\varphi_{m,k}\|\leq\|\tilde{s}^{-1}\circ\varphi\|.

(e 6.142)

Define
\psi_{n}=\psi_{n,n},

n\in\mathbb{N}.
Then
\|\psi_{n}\|\leq\|\tilde{s}^{-1}\circ\varphi\|

for all
n\in\mathbb{N}.

We will check that

\displaystyle\lim_{n\to\infty}\|s\circ\psi_{n}(x)-\varphi(x)\|=0\,\,\,{\rm for\,\,\,all}\,\,\,x\in H.

(e 6.143)

To check this, let
\epsilon>0
and
x\in H
with
\|x\|\leq 1.
Let
M=(\|s\|+1)(\|\tilde{s}^{-1}\circ\varphi\|+1).

By Lemma
3.1
, there is
n_{0}\in\mathbb{N}
such that

\displaystyle\|x-P_{m}(x)\|<\epsilon/8M\,\,\,{\rm and}\,\,\,\|P_{m}(x)-P_{m^{\prime}}(x)\|<\epsilon/8M\,\,\,{\rm for\,\,\,all}\,\,\,m^{\prime},m\geq n_{0}.

(e 6.144)

There is also
k_{0}\in\mathbb{N}
with
1/k_{0}<\epsilon/4
such that, for any

\displaystyle\|p_{n_{0},k}(\varphi(P_{n_{0}}(x)))-\varphi(P_{n_{0}}(x))\|<\epsilon/4.

(e 6.145)

If

and for all

we have, if

) and (

),

\displaystyle p_{k,k}(\varphi(P_{n_{0}}(x)))

\displaystyle\approx_{\epsilon/4}

\displaystyle p_{k,k}p_{n_{0},k_{0}}(\varphi(P_{n_{0}}(x)))

(e 6.146)

\displaystyle\approx_{1/2^{k_{0}}}

\displaystyle p_{n_{0},k_{0}}(P_{n_{0}}(x))\approx_{\epsilon/4}P_{n_{0}}(x).

(e 6.147)

Then (recall that
H_{0,n_{0}}\subset H_{0,n},

n_{0}<n
), by (
e 6.144
), (
e 6.140
), (
e 6.141
)
and (
e 6.146
), when

\displaystyle\|s\circ\psi_{n}(x)-\varphi(x)\|

\displaystyle\leq

\displaystyle\|s\circ\psi_{n}(x)-s\circ\psi_{n,n}(P_{n_{0}}(x))\|+\|s\circ\psi_{n,n}(P_{n_{0}}(x))-\varphi(x)\|

(e 6.149)

\displaystyle<

\displaystyle\|s\circ\psi_{n}\|\|x-P_{n_{0}}(x)\|+\|s\circ\psi_{n,n}(P_{n_{0}}(x))-\varphi(P_{n_{0}}(x))\|+

\displaystyle\hskip 21.68121pt+\|\varphi(P_{n_{0}}(x))-\varphi(x)\|

\displaystyle<

\displaystyle\epsilon/8+\|s\circ\psi_{n,n}(P_{n_{0}}(x))-\varphi_{n,n}(P_{n_{0}}(x))\|

\displaystyle\hskip 21.68121pt+\|p_{n,n}(\varphi(P_{n_{0}}(x)))-\varphi(P_{n_{0}}(x))\|+\epsilon/4

\displaystyle<

\displaystyle\epsilon/8+0+(1/2^{k_{0}}+\epsilon/2)+\epsilon/8<\epsilon.
