Wigner functions for angle and orbital angular momentum: Operators and dynamics
H. A. Kastrup

Abstract
Recently a paper on the contruction of consistent Wigner functions for cylindrical phase spaces 𝕊 1 × ℝ \mathbb{S}^{1}\times\mathbb{R} , i.e. for the canonical pair angle and orbital angular momentum, was presented, main properties of those functions derived, discussed and their usefulness illustrated by examples. The present paper is a continuation which compares properties of the new Wigner functions for cylindrical phase spaces with those of the well-known Wigner functions on planar ones in more detail. Furthermore, the mutual (Weyl) correspondence between HIlbert space operators and their phase space functions is discussed. The ⋆ \star product formalism is shown to be completely implementable. In addition basic dynamical laws for Wigner and Moyal functions are derived as generalized Liouville and energy equations. They are very similar to those of the planar case, but also show characteristic differences.

Another remark concerns the

On the other hand,

Wigner functions proper

II.1.1
Expectation values of operators and

operator–related phase-space functions

The basic postulate for the concept of Wigner functions - here for the planar case - is to express the expectation value
\langle A\rangle_{\phi}
of an
operator
A
with respect to a state
\phi
in a Hilbert space with scalar product

(\phi_{2},\phi_{1})_{\mathbb{R}}=\int_{-\infty}^{\infty}dx\,\phi_{2}^{\ast}(x)\phi_{1}(x)

(13)

as an integral over phase space with density
W_{\phi}(q,p)
:

\langle A\rangle_{\phi}=(\phi,A\phi)_{\mathbb{R}}=\int_{\mathbb{R}^{2}}dq\,dp\,\tilde{A}(q,p)\,W_{\phi}(q,p),

(14)

where, in Dirac’s notation,

\tilde{A}(q,p)=\int_{-\infty}^{\infty}d\xi e^{-ip\xi/\hbar}\langle q+\xi/2|A|q-\xi/2\rangle

(15)

is the phase space function associated with the Hilbert space operator
A
.

The expression (
15

\tilde{A}(q,p)
may be rewritten in a way which resembles the
corresponding cylindrical one very closely:
Introducing the operator
Leaf 1968a
;
Leaf 1968b
;
de Groot and Suttorp 1972

\Delta(q,p)=\int_{-\infty}^{\infty}d\xi e^{-ip\xi/\hbar}|q-\xi/2\rangle\langle q+\xi/2|,

(16)

the function
\tilde{A}(q,p)
can be written as

\tilde{A}(q,p)=\tr[A\cdot\Delta(q,p)],

(17)

where

\tr(B)=\int_{-\infty}^{\infty}dx\,\langle x|B|x\rangle.

(18)

Expectation values of operators with respect to a density operator
\rho
will be treated below
when traces of operators and their products are discussed.

If
A
is an operator in a Hilbert space with scalar product (
1
) then -
according to Ref.
Kastrup 2016
- its expectation value with respect to a wave function

II.1.2
Marginal distributions and transition probabilities

As the Wigner functions (
8
) and (
7
) can be negative on certain subsets
of their respective phase spaces, they are no proper probability distributions. That
W_{\phi}(q,p)

may be negative can be seen from the relation

W_{\phi}(q=0,p=0)=\frac{1}{2\pi\hbar}\int_{-\infty}^{\infty}d\xi\,\phi^{\ast}(-\xi/2)\phi(\xi/2).

(40)

So, if
\phi(x)
is an odd function, the right hand side of the last equation is negative.
This is, e.g., so for the odd
n
eigenfunctions of the harmonic oscillator
Schleich 2001
;
Agarwal 2013

Similar arguments apply to the Wigner function (
7

6
)
that the Wigner function
V_{mm}(\theta,p)
of the basic function
e_{m}(\varphi)
is the sinc function which has negative
regions
Kastrup 2016

Contrary to the Wigner functions themselves the marginal distributions

\int_{-\infty}^{\infty}dpW_{\phi}(q,p)=|\phi(q)|^{2},~\int_{-\infty}^{\infty}dqW_{\phi}(q,p)=|\hat{\phi}(q)|^{2},

(41)

where
\hat{\phi}(p)
is the Fourier transform of
\phi(q)
,

\hat{\phi}(p)=\frac{1}{2\pi\hbar}\int_{\mathbb{R}}dq\,\phi(q)\,e^{-iqp/\hbar},

(42)

are the usual non-negative quantum mechanical ones. (Definition (
42
) follows the convention of Ref.
Hillery et al. 1984
).
This is considered to be an essential requirement for the properties of Wigner functions
Hillery et al. 1984
.

The situation is slightly more complicated for the Wigner function
V_{\psi}(\theta,p)
. Here we have

\displaystyle\int_{-\infty}^{\infty}d\bar{p}\,V_{\psi}(\theta,p)

\displaystyle=\frac{1}{2\pi}|\psi(\theta)|^{2},

(43)

\displaystyle\int_{-\pi}^{\pi}d\theta\,V_{\psi}(\theta,p)=\sum_{n\in\mathbb{Z}}|c_{n}|^{2}

\displaystyle\sinc\pi(p/\hbar-n)\equiv\omega_{\psi}(p)\,,

(44)

\displaystyle\int_{-\infty}^{\infty}d\bar{p}\,\omega_{\psi}(p)\,\sinc\pi(p/\hbar

\displaystyle-m)=|c_{m}|^{2},~m\in\mathbb{Z}.

(45)

The last equation, which yields the quantum mechanical marginal probabilities
|c_{m}|^{2}
for the quantized angular momentum,
follows from the previous one as a consequence of the orthonormality relations

\int_{-\infty}^{\infty}d\bar{p}\,\sinc\pi(m-\bar{p})\,\sinc\pi(n-\bar{p})=\delta_{mn}.

(46)

More details, especially about the interpolating role of the sinc functions, can be found in Ref.
Kastrup 2016
.

If the Wigner functions

and

(47)

which implies

\int_{\mathbb{R}^{2}}dq\,dp\,W_{\phi}^{2}(q,p)=\frac{1}{2\pi\hbar}.

(48)

An analogue relation hold for the cylindrical case

:

(49)

and therefore

\int_{-\infty}^{\infty}d\bar{p}\int_{-\pi}^{\pi}d\theta\,V_{\psi}^{2}(\theta,p)=\frac{1}{2\pi}.

II.1.3
Traces of operators

It is possible to discuss the trace of the product of two Hilbert space operators in terms of the functions (

) or (
20
)

If

\tr(A\cdot B)=\frac{1}{2\pi\hbar}\int_{\mathbb{R}^{2}}dq\,dp\,\tilde{A}(q,p)\,\tilde{B}(q,p).

This relation can be obtained by using the expressions (

If
A
is a density operator
\rho

we get from the last equation

\langle O\rangle_{\rho}=\tr(\rho\cdot O)=\frac{1}{2\pi\hbar}\int_{\mathbb{R}^{2}}dq\,dp\,\tilde{\rho}(q,p)\,\tilde{O}(q,p),

with, according to Eq. (

\tilde{\rho}(q,p)=\int_{-\infty}^{\infty}d\xi e^{-ip\xi/\hbar}\langle q+\xi/2|\rho|q-\xi/2\rangle.

Inserting for

II.1.4
Recovering the wave function

If the Wigner functions
W_{\phi}(q,p)
or
V_{\psi}(\theta,p)
of wave functions
\phi(x)
or
\psi(\varphi)

are given, then the wave functions may be retrieved up to an over all constant phase

Multiplying the Wigner function (
8

and integrating over

yields a delta funcction

\phi^{\ast}(q-\xi_{1}/2)\phi(q+\xi_{1}/2)=\int_{-\infty}^{\infty}d(p/\hbar)\,e^{ip\xi_{1}/\hbar}W_{\phi}(q,p).

(60)

Finally, putting first
q=\xi_{1}/2
and afterwards renaming
\xi_{1}
by

\phi^{\ast}(0)\,\phi(q)=\int_{-\infty}^{\infty}d(p/\hbar)\,e^{ipq/\hbar}W_{\phi}(q/2,p).

(61)

Here
\phi^{\ast}(0)

normalization of
\phi(q)
and the constant phase of which has no physical significance.

Exactly the same reasoning leads in the cylindrical case to the result

\psi^{\ast}(0)\,\psi(\theta)=2\pi\int_{-\infty}^{\infty}d\bar{p}\,e^{ip\theta/\hbar}V_{\psi}(\theta/2,p).

IV
Dynamical and energy equations

Quantum mechanics provides - among others - two basic elements for the description of atomic systems:

First, it gives a description of their time evolution, i.e. their dynamics, either - in the Schrödinger picture - in terms of
a Schrödinger equation for the wave function of the system, or - in the Heisenberg picture - in terms of equations of motion for
operators (“observables”) which characterize the system.

Second, it allows - in principle - for the calculation of eigenvalues and eigenstates of observables, especially the energy,
which are important for a quantitative description of the system. In addition, in the realm of continuous (higher) energies
it provides the basis for the description of, e.g., stationary scattering processes for a given energy.

In this second case, which concerns the stationary structure of physical systems, the time-independent Schrödinger equation
is an important tool.

Similarly one can ask, how the time evolution of a system, from a given initial state, is described by its associated Wigner function and: are there
appropriate structure equations corresponding to the eigenvalue etc. equations of the conventional time-independent quantum mechanics.

The question of time evolution was already answered by Wigner in his very first paper on the subject for planar phase spaces
Wigner 1932

in terms of a generalized Liouville equation. The problem was later discussed extensively by Moyal
Moyal 1949
. For the further development of this subject
see the reviews
Takabayasi 1954
;
Hillery et al. 1984
;
Lee 1995
;
Schleich 2001
;
Dragoman 2002
.

The discussion of time-independent structure or energy “eigenvalue” equations for Wigner functions has its origin in applications to statistical
mechanics systems, the topic of
Wigner’s seminal paper
Wigner 1932
: For a quantum canonical ensemble in equilibrium the quantum mechanical time evolution operator

U(t)=e^{-itH/\hbar}

(109)

is replaced by

\Omega(\beta)=e^{-\beta H},~\beta=\frac{1}{k_{B}T},

(110)

where
H
is the associated Hamilton operator.
The operator
\Omega
provides the density operator

\rho(\beta)=\Omega(\beta)/Z(\beta),~~Z(\beta)=\tr(\Omega)

(111)

of the system and obeys the Bloch equation
Bloch 1932

\partial_{\beta}\Omega=-H\cdot\Omega=-\Omega\cdot H.

(112)

Wigner functions related to
\Omega
have been discussed in Refs.
Oppenheim and Ross 1957
;
İmre et al. 1967
. A brief summary is contained in Ref.
Hillery et al. 1984
.

Comparing Eqs. (
109
) and (

-t/\hbar\longleftrightarrow i\beta.

(113)

In modern approaches
Haag 1996
;
Bordemann et al. 1999
;
Thirring 2002
this relation is treated under the topic “KMS condition” which deals with the analytic continuation between the
two regions in the complex

\displaystyle H_{0}

In the following we abbreviate:

\displaystyle i\hbar\partial_{t}V_{\psi_{2}\psi_{1}}(\theta,p;t)=-\frac{2\,i\varepsilon\,p}{\hbar}\partial_{\theta}V_{\psi_{2}\psi_{1}}(\theta,p;t)-

(135)

\displaystyle-\frac{2\varepsilon}{(2\pi)^{2}}\partial_{\theta}b_{\psi_{2}\psi_{1}}(\theta,p,\vartheta=\pm\pi;t),

\displaystyle b_{\psi_{2}\psi_{1}}(\theta,p,\vartheta=\pm\pi;t)

\displaystyle=\frac{1}{(2\pi)^{2}}[e^{-ip\vartheta/\hbar}\psi_{2}^{\ast}(\theta-\vartheta/2;t)\,\psi_{1}(\theta+\vartheta/2;t)]^{\vartheta=\pi}_{\vartheta=-\pi}.

is the difference of the values of the integrand of

For

for which the boundary term turns out to be

\displaystyle b_{\psi}(\theta,p,\vartheta=\pm\pi;t)=\frac{2i}{(2\pi)^{2}}\sin\pi[(m+n)/2-p]\times

\displaystyle\times\{\cos(m-n)\theta+\cos\pi[(m-n)/2]\}

Differentiating with respect to

, but not in general. It vanishes also

We next turn to the contribution of the potential

to the right hand side of Eq. (

) (recall Eq. (

\displaystyle\frac{1}{2\pi}\int_{-\pi}^{\pi}\frac{d\vartheta}{2\pi}e^{-ip\vartheta/\hbar}[-U(\theta-\vartheta/2)\psi_{2}^{\ast}]\psi_{1}+\psi_{2}^{\ast}[U(\theta+\vartheta/2)\psi_{1}].

\displaystyle=\frac{1}{2\pi}\int_{-\pi}^{\pi}\frac{d\vartheta}{2\pi}e^{-ip\vartheta/\hbar}[U(\theta+\vartheta/2)-U(\theta-\vartheta/2)]\psi_{2}^{\ast}\psi_{1}

A real periodic potential,

\displaystyle U_{k}(\theta+\vartheta/2)-U_{k}(\theta-\vartheta/2)

(144)

with

Adding the term (

\displaystyle\partial_{t}V_{\psi_{2}\psi_{1}}(\theta,p;t)=-\frac{2\varepsilon\,p}{\hbar^{2}}\partial_{\theta}V_{\psi_{2}\psi_{1}}(\theta,p;t)+

(146)

\displaystyle+\frac{2}{ik\hbar}[\partial_{k}U(\theta)]\sin[(k/2)i\hbar\partial_{p}]V_{\psi_{2}\psi_{1}}(\theta,p)

\displaystyle-\frac{2\varepsilon}{\hbar i}\partial_{\theta}b_{\psi_{2}\psi_{1}}(\theta,p,\vartheta=\pm\pi;t)

Some remarks on the result:

The generalized Liouville equation (
147

\psi_{2}(\varphi)=\psi_{1}(\varphi)
, i.e. for the Wigner function proper

:

\displaystyle\{\partial_{t}+\frac{p}{mr_{0}^{2}}\partial_{\theta}-\partial_{\theta}U_{k}(\theta)\,\partial_{p}\}V_{\psi}(\theta,p;t)=

(148)

\displaystyle=\{\partial_{\theta}U_{k}(\theta)\sum_{n=1}^{\infty}\frac{(k\hbar/2)^{2n}}{k(2n+1)!}\partial_{p}^{2n+1}\}V_{\psi}(\theta,p;t)+

\displaystyle+\frac{\hbar}{mr_{0}^{2}i}\partial_{\theta}b_{\psi}(\theta,p,\vartheta=\pm\pi;t),

If

IV.3
An energy equation for the Wigner-Moyal function

We have seen in the last subsection that a time dependence (
150
) for the wave functions
\psi_{1,2}(\theta;t)
in the principal dynamical equation (
147
)
leads to a stationary equation (
152
) in the limit
\psi_{2}\to\psi_{1}=\psi
which does not contain an energy parameter
E
anymore.
One can change that by two related arguments:

If one replaces
\psi_{2}^{\ast}(\theta;t)
by
\psi_{2}^{\ast}(\theta;-t)
then
E_{2}
in Eq. (
151
) changes sign. However, this operation is not the established
Wigner time inversion which involves a simultaneous complex conjugation of the wave function. Therefore,
\psi_{2}^{\ast}(\theta;-t)
is equivalent to
\psi_{2}(\theta;t)
.
Thus, if one replaces
\psi_{2}^{\ast}(\theta;t)
merely by its complex conjugate, then
E_{2}
in Eq. (
151
) changes sign, too. So, either of these procedures
can make the
difference
E_{1}-E_{2}
in Eq. (
151
) into the sum
E_{1}+E_{2}
.

Another related argument makes use of the exchange (
113
): if one replaces
it/\hbar
in the Schrödinger equation by
\beta
then one achieves the same goal,
namely an equation for
E_{1}+E_{2}
.

The discussion to obtain such an energy type equation for Wigner functions was – implicitly – started by Baker
Baker, Jr. 1958
, explicitly discussed by
Fairlie
Fairlie 1964
and then persued by others
Kundt 1967
;
Fairlie and Manogue 1991
;
Curtright et al. 1998
;
Schleich 2001
.

We will now derive the corresponding equation for the cylindrical phase space:

If we have the stationary Schrödinger equations

H\psi_{j}=E_{j}\psi_{j},~j=1,2\,,

(154)

with

as in Eqs. (
130
) and (

\displaystyle(E_{1}+E_{2})V_{\psi_{2}\psi_{1}}(\theta,p)=

(155)

\displaystyle=\frac{1}{2\pi}\int_{-\pi}^{\pi}\frac{d\vartheta}{2\pi}e^{-ip\vartheta/\hbar}[(H\psi_{2}^{\ast})\psi_{1}+\psi_{2}^{\ast}(H\psi_{1})].

Like in the case of Eq. (
133

134
) in order to transform the
H_{0}
part under the last integral by partial
integration and obtain:

\displaystyle\{\frac{2\varepsilon}{\hbar^{2}}p^{2}-\frac{\varepsilon}{2}\partial^{2}_{\theta}\}\,V_{\psi_{2}\psi_{1}}(\theta,p)-

(156)

\displaystyle-2i\frac{\varepsilon\,mr_{0}^{2}}{\hbar}[e^{-ip\vartheta/\hbar}\{\frac{p}{mr_{0}^{2}}\,\rho_{21}(\theta;\vartheta)+j_{21}(\theta;\vartheta)\}]^{\vartheta=\pi}_{\vartheta=-\pi},

IV.4
PDEs for Wigner functions

In the last two subsections we have derived PDEs for the Wigner function
V_{\psi}(\theta,p;t)
or
V_{\rho}(\theta,p;t)
, Eq. (
148
) for the
time evolution and Eqs. (
152
) and (
167
) for stationary systems. The question comes up immediately, whether these equation can replace
- at least in principle - the Schrödinger wave or Heisenberg operator equations, like path integrals in quantum mechanics or the Hamilton-Jacobi
equation in mechanics.

The time evolution of the Wigner function in the planar case is considered to be equivalent to that of the Schrödinger equation
Case 2008
, mainly because both
are of first order in the time derivative and, therefore, have equivalent initial value problems. As the corresponding Eq. (
148
) has the additional
boundary terms (
137
) this problem has to be analysed anew for the cylindrical case.

As to the stationary Eqs. (
152
) and (
167
) the question arises whether they can replace the stationary Schrödinger equation, especially an
eigenvalue equation. Such an eigenfunction has to obey the normalization conditions (
12
) and (
50
) and should have the
properties (
69
) -
(
72
) for
\psi_{2}=\psi_{1}=\psi
. All this has yet to be analysed. In the planar case the corresponding eigenvalue problem has been positively solved
for the harmonic oscillator
Fairlie 1964
;
Schleich 2001
. But, of course, one has to get far beyond the harmonic oscillator in order to establish a generally attractive
and convincing framework. There is much work ahead!

Eqs. (
148
), (
152
) and (
167
) have a structure which invites to attempt semi-classical approximations and classical limits:
The left hand sides are ”classsical”,
i.e. they do not contain any
\hbar
, whereas the right hand sides contain a (formal) power series in
\hbar
which appears to be useful for approximations.
This was already
one of the main motives of Wigner in 1932
Wigner 1932
. Many investigations followed. See, e.g., the Refs.
Voros 1976
;
Berry 1977
;
Hillery et al. 1984
;
Osborn and Molzahn 1995
;
Werner
;
Landsman 1998
;
Schleich 2001
.
However, one has to beware
of essential singularities in
\hbar

Voros 1977
;
Heller 1976
;
Heller 1977
;
Heller and Tomsovic 1993
which can spoil naive polynomial approximations!
