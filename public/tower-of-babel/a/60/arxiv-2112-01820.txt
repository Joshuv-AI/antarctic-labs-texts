Three-chromatic geometric hypergraphs
Gábor Damásdi, Dömötör Pálvölgyi

Abstract
We prove that for any planar convex body C C there is a positive integer m m with the property that any finite point set P P in the plane can be three-colored such that there is no translate of C C containing at least m m points of P P , all of the same color. As a part of the proof, we show a strengthening of the Erdős-Sands-Sauer-Woodrow conjecture. Surprisingly, the proof also relies on the two dimensional case of the Illumination conjecture.

In this section we show that given a point set

and a convex set

and calculate a three-coloring of

efficiently if

is given in a natural way, for example, if

is a disk.
Our algorithm is randomized and its running time is a polynomial of the number of points,

.

•

First, we need to fix three points on the boundary,
\tau_{1},\tau_{2},\tau_{3}\subset\partial C
such that Lemma

\tau_{i}=\gamma(t_{i})

for some

and

for each

.
Note that we do not need to fix a complete parametrization

of

or

and

if we assume
\tau_{i}^{\scalebox{0.6}{$--$}}=\gamma(t_{i}-\varepsilon)
and

.
If

has a smooth boundary, like a disk, we can pick

If the boundary of

contains vertex-type sharp turns, the complexity of finding these turns depends on how

is given, but for any reasonable input method, this should be straight-forward.
After that, one can follow closely the steps of the proof of the Illumination conjecture in the plane to get an algorithm, but apparently, this has not yet been studied in detail.

•

To pick

, the side length of the squares of the grid, we can fix some arbitrary points
\tau_{i}^{\scalebox{0.6}{$-$}}
between

It is sufficient to pick

so that

, is less than

–

Set

, which is an absolute constant given by Theorem

.
We need to construct the complete multidigraph given by the tri-partition cones determined by

To obtain the subsets

5
Open questions

It is a natural question whether there is a universal

that works for all convex bodies in Theorem
1
, like in Theorem

.
This would follow if we could choose

While the

To ensure that properties (A) and (B) are satisfied would require further study of the Illumination conjecture.

Our bound for

∎
