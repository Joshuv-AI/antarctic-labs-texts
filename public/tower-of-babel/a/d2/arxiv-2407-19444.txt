An inverse of Furstenberg’s correspondence principle and applications to nice recurrence
Alexander Fish and Sean Skinner

Abstract
. We prove an inverse of Furstenberg’s correspondence principle stating that for all measure preserving systems ( X , μ , T ) (X,\mu,T) and A ⊂ X A\subset X measurable there exists a set E ⊂ ℕ E\subset\mathbb{N} such that μ ⁡ ( ⋂ i = 1 k T − n i ​ A ) = lim N → ∞ | ( ⋂ i = 1 k ( E − n i ) ) ∩ { 0 , … , N − 1 } | N \mu\left(\bigcap_{i=1}^{k}T^{-n_{i}}A\right)=\lim_{N\to\infty}\frac{\left|\left(\bigcap_{i=1}^{k}(E-n_{i})\right)\cap\{0,\dots,N-1\}\right|}{N} for all k , n 1 , … , n k ∈ ℕ k,n_{1},\dots,n_{k}\in\mathbb{N} . As a corollary we show that a set R ⊂ ℕ R\subset\mathbb{N} is a set of nice recurrence if and only if it is nicely intersective. Together, the inverse of Furstenberg’s correspondence principle and it’s corollary partially answer two questions of Moreira.

Poincaré’s famous recurrence theorem says that for any measure preserving system
(X,\mu,T)
and any

\mu(A\cap T^{-r^{2}}A)>0.

This phenomenon motivates the notion of a set of recurrence as introduced by Furstenberg.

Definition 1.1

(Sets of recurrence)
.

A set
R\subset\mathbb{N}
is called a set of recurrence if for any measure preserving system
(X,\mu,T)
and any set
A\subset X
with
\mu(A)>0
there exists some non-zero
r\in R
for which

\mu(A\cap T^{-r}A)>0.

Thus Poincaré’s theorem states that the positive integers are a set of recurrence and the content of equation (

E\subset\mathbb{N}
has positive upper density,

\overline{d}_{(\{0,\dots,N-1\})}(E):=\limsup_{N\to\infty}\frac{|E\cap\{0,1,\dots,N-1\}|}{N}>0,

then there must exist some non-zero integer

(2)

E\cap(E-r^{2})\neq\emptyset,

or in other words,
E
must contain two elements that differ by a perfect square. The above also holds when
(\{0,\dots,N-1\})
is replaced by any other Følner sequence in
\mathbb{N}

Definition 1.2

(Følner sequences)
.

A sequence
(F_{N})
of finite subsets of
\mathbb{N}
is a Følner sequence if for any
t\in\mathbb{N}
we have that

\frac{|F_{N}\Delta(F_{N}+t)|}{|F_{N}|}\to 0\text{ as }N\to\infty.

For a Følner sequence
(F_{N})
and a set
E\subset\mathbb{N}
we define the upper density of
E
with respect to
(F_{N})
to be

\overline{d}_{(F_{N})}(E):=\limsup_{N\to\infty}\frac{|E\cap F_{N}|}{|F_{N}|}.

When the limit supremum is actually a limit we drop the overline and call
d_{(F_{N})}(E)
the density of
E
with respect to
(F_{N})
.

Definition 1.3

(Intersective Sets)
.

Let
(F_{N})
be a Følner sequence in
\mathbb{N}
and let
R\subset\mathbb{N}
.
R
is
(F_{N})
-intersective if for every
E\subset\mathbb{N}
with
\overline{d}_{(F_{N})}(E)>0
there exists some non-zero
r\in R
with

E\cap(E-r)\neq\emptyset.

Even though one can easily verify that different Følner sequences can define genuinely different upper densities

(\{N^{2}+1,\dots,N^{2}+N\})

, it turns out that the corresponding notions of intersectivity are all equivalent, and in fact we have the following characterisation which is implicit in

Theorem 1.1

(Characterisation of sets of recurrence)
.

Let
R\subset\mathbb{N}
. Then
R
is a set of recurrence if and only if it is
(F_{N})
-intersective for some Følner sequence
(F_{N})
.

Thus, the results referred to in equations (
1
) and (
2

The only if direction of Theorem
1.1
follows immediately from
Furstenberg’s now ubiquitous correspondence principle.

Theorem 1.2

(Furstenberg’s Correspondence Principle
[
9
]
)
.

Given any
E\subset\mathbb{N}
and any Følner sequence
(F_{N})
there exists a measure preserving system
(X,\mu,T)
, a set
A\subset X
with
\mu(A)=\overline{d}_{(F_{N})}(E)
, and a subsequence
(N_{i})
such that

\mu(A\cap T^{-n_{1}}A\cap\dots\cap T^{-n_{k}}A)=d_{(F_{N_{i}})}(E\cap(E-n_{1})\cap\dots\cap(E-n_{k}))

for all
k,n_{1},\dots,n_{k}\in\mathbb{N}
.

In 1986 Bergelson introduced a different notion of recurrence and intersectivity as part of his proof of a density version of Schur’s theorem
[
2
]
.

Definition 1.4

(Nice Recurrence)
.

A set
R\subset\mathbb{N}
is called a set of nice recurrence (c.f.
[
2
]
) if for any measure preserving system
(X,\mu,T)
, any
A\subset X
, and any
\varepsilon>0
there exists some non-zero
r\in R
such that

\mu(A\cap T^{-r}A)>\mu(A)^{2}-\varepsilon.

Note that for any strong mixing system
\mu(A\cap T^{-n}A)\to\mu(A)^{2}
as
n\to\infty
and so the lower bound in Definition
1.4
is in this sense optimal. Nearly all known examples of sets of recurrence (including the squares) are also sets of nice recurrence, however in
[
6
]
Forrest constructed a set of recurrence which is not a set of nice recurrence.

Definition 1.5

(Nicely Intersective Sets)
.

Let
(F_{N})
be a Følner sequence in
\mathbb{N}
and let
R\subset\mathbb{N}
. We call
R
a
(F_{N})
-nicely intersective set (also referred to as a set of
nice combinatorial recurrence
in
[
2
]
for the case
(F_{N})=(\{1,\dots,N\})
) if for any set
E\subset\mathbb{N}
and any
\varepsilon>0
there exists some non-zero
r\in R
such that

\overline{d}_{(F_{N})}(E\cap(E-r))>\overline{d}_{(F_{N})}(E)^{2}-\varepsilon.

It is natural to ask whether a characterisation similar to Theorem
1.1
holds for sets of nice recurrence. Indeed Theorem
1.2
immediately implies that for any Følner sequence
(F_{N})
, any set of nice recurrence
R
is
(F_{N})
-nicely intersective. A question of Moreira in
[
11
]
asks if the converse is also true.

Question 1
.

Is it true that a set
R\subset\mathbb{N}
is a set of nice recurrence if and only if it is
(F_{N})
-nicely intersective for some Følner sequence
(F_{N})
?

We provide a partial answer to this question.

Theorem 1.3
.

A set
R\subset\mathbb{N}
is a set of nice recurrence if and only if it is
(\{0,\dots,N-1\})
-nicely intersective.

In particular, by Theorem
1.2
we have that any
(\{0,\dots,N-1\})
-nicely intersective set is also
(F_{N})
-nicely intersective set for all Følner sequences
(F_{N})
.
Moreira also observed that an affirmative answer to Question
1
would follow from an affirmative answer to the following question.

Question 2
.

Let
(X,\mu,T)
be a measure preserving system and let
A\subset X
. Is it true that for any Følner sequence
(F_{N})
there is some set
E\subset\mathbb{N}
such that for every
n\in\mathbb{N}
we have that

\mu(A\cap T^{-n}A)=\overline{d}_{(F_{N})}(E\cap(E-n)).

Indeed our proof of Theorem
1.3
follows from the following partial answer to Question
2
.

Theorem 1.4
.

Given any measure preserving system
(X,\mu,T)
and any set
A\subset X
there exists some
E\subset\mathbb{N}
such that

\mu\left(\bigcap_{i=1}^{k}T^{-n_{i}}A\right)=\lim_{N\to\infty}\frac{\left|\left(\bigcap_{i=1}^{k}(E-n_{i})\right)\cap\{0,\dots,N-1\}\right|}{N}

for any
k,n_{1},\dots,n_{k}\in\mathbb{N}
.

In a slightly different direction, it is also known that sets of recurrence admit an equivalent uniform characterisation.

Theorem 1.5

(Uniformity of recurrence
[
6
]
)
.

Let
R\subset\mathbb{N}
be a set of recurrence. Then for any
\delta>0
there exists some positive integer
N_{0}=N_{0}(R,\delta)
and
\varepsilon=\varepsilon(R,\delta)
such that for any measure preserving system
(X,\mu,T)
and any
A\subset X
with
\mu(A)\geq\delta

with

\mu(A\cap T^{-r}A)\geq\varepsilon.

An analogous result also holds for sets of nice recurrence.

Theorem 1.6

(Uniformity of nice recurrence)

Let
R\subset\mathbb{N}
be a set of nice recurrence. Then for any
\delta,\varepsilon>0
there exists some positive integer
N_{0}=N_{0}(R,\delta,\varepsilon)
such that for any measure preserving system
(X,\mu,T)
and any
A\subset X
with
\mu(A)\geq\delta
there exists some
r\in R\cap\{1,\dots,N_{0}\}
with

\mu(A\cap T^{-r}A)>\delta^{2}-\varepsilon.

Proof of theorem
1.3

For convenience let us denote
(G_{N}):=(\{0,\dots,N-1\})
.
To prove the ’if’ direction of Theorem
1.3
suppose that
R\subset\mathbb{N}
is a
(G_{N})
-nicely intersective set and let
(X,\mu,T)
be a measure preserving system with
A\subset X
. By Theorem
1.4
there exists some
E\subset\mathbb{N}
with

d_{(G_{N})}(E\cap(E-t))=\mu(A\cap T^{-t})\quad\text{for all }t\in\mathbb{N}.

In particular
d_{(G_{N})}(E)=\mu(A)
and since
R
is a
(G_{N})
-nicely intersective set then for every
\varepsilon>0
there exists some non-zero
r\in R
with

\mu(A)^{2}-\varepsilon=d_{(G_{N})}(E)^{2}-\varepsilon<d_{(G_{N})}(E\cap(E-r))=\mu(A\cap T^{-r}A)

as required.

On the other hand is
R\subset\mathbb{N}
is a set of nice recurrence and
E\subset\mathbb{N}
, then for any Følner sequence
(F_{N})
Theorem
1.2
ensures the existence of a measure preserving system
(X,\mu,T)
and a set
A\subset X
with
\mu(A)=\overline{d}_{(F_{N})}(E)
and

\mu(A\cap T^{-t}A)\leq\overline{d}_{(F_{N})}(E\cap(E-t))\quad\text{for any }t\in\mathbb{N}.

Since
R
is a set of nice recurrence then for every
\varepsilon>0
there exists some non-zero
r\in R
with

\overline{d}_{(F_{N})}(E)^{2}-\varepsilon=\mu(A)^{2}-\varepsilon<\mu(A\cap T^{-r}A)\leq\overline{d}_{(F_{N})}(E\cap(E-r))

as required.

3.
Proof of the inverse correspondence principle

In what follows the space
\{0,1\}^{\mathbb{N}}
of binary valued sequences indexed by
\mathbb{N}
will always be equipped with the product topology (where
\{0,1\}
is discrete), the Borel
\sigma
-algebra and the right shift
\sigma:\{0,1\}^{\mathbb{N}}\to\{0,1\}^{\mathbb{N}}
defined by

(\sigma\omega)_{n}=\omega_{n+1}\text{ for any }\omega\in\{0,1\}^{\mathbb{N}}\text{ and any }n\in\mathbb{N}.

For any
r,n_{1},\dots,n_{r}\in\mathbb{N}
and
i_{1},\dots,i_{r}\in\{0,1\}
we denote by

[\omega_{n_{1}}=i_{1},\dots,\omega_{n_{r}}=i_{r}]

the set of all sequences
\omega\in\{0,1\}^{\mathbb{N}}
with
\omega_{n_{j}}=i_{j}
for each
j=1,\dots,r
. Such a set is called a cylinder.
Recall that the collection of cylinders forms a generating algebra for the Borel
\sigma
-algebra on
\{0,1\}^{\mathbb{N}}
. Denote by
\mathcal{M}
the compact space of all Borel probability measures on
\{0,1\}^{\mathbb{N}}
equipped with the topology of weak-* convergence, which in this setting means that a sequence of measures
\nu_{n}\in\mathcal{M}
converges to some
\nu\in\mathcal{M}
if and only if

\nu_{n}(C)\to\nu(C)\quad\text{for all cylinders }C.

Denote by
\mathcal{M}_{\sigma}
the set of all
\sigma
-invariant measures in
\mathcal{M}
.
We begin with the well known observation that
(\{0,1\}^{\mathbb{N}},\sigma)
is universal for all measure preserving systems
(X,\mu,T)
with a distinguished set
A\subset X
in the following sense.

Lemma 3.1

(
[
14
]
[Example 2.2.6])
.

Let
(X,\mu,T)
be a measure preserving system. Given any
A\subset X
there exists some
\nu\in\mathcal{M}_{\sigma}
such that for any
r,n_{1},\dots,n_{r}\in\mathbb{N}
and
i_{1},\dots,i_{r}\in\{0,1\}
,

\nu([\omega_{n_{1}}=i_{1},\dots,\omega_{n_{r}}=i_{r}])=\mu(T^{-n_{1}}A^{i_{1}}\cap\dots\cap T^{-n_{r}}A^{i_{r}}),

where
A^{1}:=A
and
A^{0}:=A^{c}
.

Proof.

Define a map
\phi:X\to\{0,1\}^{\mathbb{N}}
by

\phi(x)_{n}:=1_{A}(T^{n}x)\text{ for any }n\in\mathbb{N}.

The map
\phi
is measurable and so we can define
\nu
to be the pushforward of
\mu
under
\phi
, i.e.
\nu(B):=\mu(\phi^{-1}(B))
for any
B\subset\{0,1\}^{\mathbb{N}}
measurable. For any cylinder
[\omega_{n_{1}}=i_{1},\dots,\omega_{n_{r}}=i_{r}]
we have that

\displaystyle\phi^{-1}([\omega_{n_{1}}=i_{1},\dots,\omega_{n_{r}}=i_{r}])

\displaystyle=\{x\in X\,|\,T^{n_{j}}x\in A^{i_{j}}\text{ for each }j=1,\dots,r\}

\displaystyle=T^{-n_{1}}A^{i_{1}}\cap\dots\cap T^{-n_{r}}A^{i_{r}}

and so the result follows.
∎

Definition 3.1
.

Let
(F_{N})
be a Følner sequence.
A point
x\in\{0,1\}^{\mathbb{N}}
is called
(F_{N})
-generic for a measure
\nu\in\mathcal{M}_{\sigma}
if

\delta_{F_{N}}(x):=\frac{1}{|F_{N}|}\sum_{i\in F_{N}}\delta_{\sigma^{i}(x)}\to\nu\quad\text{as }N\to\infty,

where
\delta_{\sigma^{i}(x)}
is the Dirac mass at
\sigma^{i}(x)
.

Theorem
1.4
now follows from Lemma
3.1
combined with the following classical result of Sigmund.

Proposition 3.1

(
[
13
]
[Theorem 4])
.

Every
\nu\in\mathcal{M}_{\sigma}
admits a
(\{0,\dots,N-1\})
-generic point.

In fact Sigmund proved that any measure on a compact metric space invariant under a continuous map satisfying a property known as specification (of which the shift space
(\{0,1\}^{\mathbb{N}},\sigma)
is an example) admits a
(\{0,\dots,N-1\})
-generic point. For the sake of completeness we include a proof of Proposition
3.1
in Section
5
.

Proof of Theorem
1.4
.

Let
(X,\mu,T)
be a measure preserving system and let
A\subset X
. By Lemma
3.1
there exists some
\nu\in\mathcal{M}_{\sigma}
with

\mu\left(\bigcap_{i=1}^{k}T^{-n_{i}}A\right)=\nu([\omega_{n_{1}}=1,\dots,\omega_{n_{k}}=1])

for all
k,n_{1},\dots,n_{k}\in\mathbb{N}
. Proposition
3.1
ensures there exists a point
x\in\{0,1\}^{\mathbb{N}}
for which

\frac{1}{N}\sum_{i=0}^{N-1}\delta_{\sigma^{i}(x)}([\omega_{n_{1}}=1,\dots,\omega_{n_{k}}=1])\to\nu([\omega_{n_{1}}=1,\dots,\omega_{n_{k}}=1])

as
N\to\infty
for all
k,n_{1},\dots,n_{k}\in\mathbb{N}
. Identifying
x
with the indicator function
1_{E}
for some set
E\subset\mathbb{N}
allows us to re-write

\frac{1}{N}\sum_{i=0}^{N-1}\delta_{\sigma^{i}(x)}([\omega_{n_{1}}=1,\dots,\omega_{n_{k}}=1])=\frac{\left|\left(\bigcap_{i=1}^{k}(E-n_{i})\right)\cap\{0,\dots,N-1\}\right|}{N}

for any
k,n_{1},\dots,n_{k}\in\mathbb{N}
and so the result follows.
∎

5.
Existence of
(\{0,\dots,N-1\})
-generic points for shift invariant measures

Let
\mathcal{M}_{\sigma}^{e}\subset\mathcal{M}_{\sigma}
be the set of all ergodic
\sigma
-invariant measures. We define the domain of a cylinder
[\omega_{n_{1}}=i_{1},\dots,\omega_{n_{k}}=i_{k}]
to be the set

\mathrm{dom}([\omega_{n_{1}}=i_{1},\dots,\omega_{n_{k}}=i_{k}]):=\{n_{1},\dots,n_{k}\},

and denote by
\mathcal{C}_{N}
to be the collection of all cylinders
C
with
\mathrm{dom}(C)\subset\{0,1,\dots,N-1\}
.

Lemma 5.1
.

Let
\nu\in\mathcal{M}_{\sigma}
. For every
k\in\mathbb{N}
and every
\varepsilon>0
there exists a point
x\in\{0,1\}^{\mathbb{N}}
and some positive integer
R_{0}=R(k,\varepsilon,\nu)
such that for all
R\geq R_{0}
any
y\in\{0,1\}^{\mathbb{N}}
starting with the word
x_{0}x_{1}\dots x_{R-1}
we have that

(3)

\left|\frac{1}{R}\sum_{i=0}^{R-1}\delta_{\sigma^{i}(y)}(C)-\nu(C)\right|<\varepsilon\quad\text{for all }C\in\mathcal{C}_{k}.

Proof.

Let
\nu\in\mathcal{M}_{\sigma}
,
k\in\mathbb{N}
and
\varepsilon>0
be given. The Krein-Milman theorem implies that

\overline{\mathrm{conv}(\mathcal{M}_{\sigma}^{e})}=\mathcal{M}_{\sigma}

where
\mathrm{conv}(\mathcal{M}_{\sigma}^{e})
is the set of all finite convex combinations of ergodic
\sigma
-invariant measures. By finiteness of
\mathcal{C}_{k}
it follows that we can find some convex weights
\alpha_{1},\dots,\alpha_{r}\in[0,1]
and measures
\nu_{1},\dots,\nu_{r}\in\mathcal{M}_{\sigma}^{e}
such that

(4)

\left|\nu(C)-\sum_{i=1}^{r}\alpha_{i}\nu_{i}(C)\right|<\frac{\varepsilon}{5}\quad\text{for all }C\in\mathcal{C}_{k}.

For each
i=1,\dots,r
use the pointwise ergodic theorem to find a
\nu_{i}
-generic point
x^{i}\in\{0,1\}^{\mathbb{N}}
, i.e. a point for which the measure

\delta_{n}(x^{i}):=\frac{1}{n}\sum_{j=0}^{n-1}\delta_{\sigma^{j}(x^{i})}\quad\text{has that}\quad\delta_{n}(x^{i})\to\nu_{i}\text{ as }n\to\infty.

Finiteness of
\mathcal{C}_{k}
then ensures that for each
i=1,\dots,r
there exists some
\tilde{n}_{i}\in\mathbb{N}
such that

(5)

\left|\nu_{i}(C)-\delta_{n}(x^{i})(C)\right|<\frac{\varepsilon}{5}\quad\text{for all }C\in\mathcal{C}_{k}\text{ and }n\geq\tilde{n}_{i}.

Now pick some
n_{1},\dots,n_{r}
satisfying

(6)

n_{i}\geq\tilde{n}_{i}\quad\text{and}\quad\left|\frac{n_{i}}{\sum_{j=1}^{r}n_{j}}-\alpha_{i}\right|<\frac{\varepsilon}{5r}\quad\text{for each }i=1,\dots,r,

and such that

(7)

\frac{rk}{\sum_{j=1}^{r}n_{j}}<\frac{\varepsilon}{5}.

For a point
z\in\{0,1\}^{\mathbb{N}}
, denote by
z|_{n}:=z_{0}z_{1}\dots z_{n-1}
the word formed by the first
n
symbols of
z
and let
x\in\{0,1\}^{\mathbb{N}}
be the point obtained by repeating the finite string

x^{1}|_{n_{1}}\bullet x^{2}|_{n_{2}}\bullet\dots\bullet x^{r}|_{n_{r}}

where
\bullet
denotes concatenation. Thus
x
is a periodic point with period
p:=\sum_{j=1}^{r}n_{j}
.
Notice that for any
C\in\mathcal{C}_{k}
,

\displaystyle\delta_{p}(x)(C)

\displaystyle=\frac{1}{p}\sum_{i=1}^{r}\left[n_{i}\delta_{n_{i}}(x^{i})(C)+e_{i}\right]

\displaystyle=\sum_{i=1}^{r}\frac{n_{i}}{p}\delta_{n_{i}}(x^{i})(C)+\frac{1}{p}\sum_{i=1}^{r}e_{i}.

where each
e_{i}
is an error term resulting from the
i^{\text{th}}
concatenation boundary. Since each
C\in\mathcal{C}_{k}
has
\mathrm{dom}(C)\subset\{0,1,\dots,k-1\}
then each
|e_{i}|\leq k
, and so by equation (
7
) we have that

(8)

\left|\delta_{p}(x)(C)-\sum_{i=1}^{r}\frac{n_{i}}{p}\delta_{n_{i}}(x^{i})(C)\right|<\frac{\varepsilon}{5}\quad\text{for all }C\in\mathcal{C}_{k}.

Since each
n_{i}\geq\tilde{n}_{i}
then we may combine our estimates from equations (
4
), (
5
), (
6
) and (
8
) to conclude that

(9)

\left|\delta_{p}(x)(C)-\nu(C)\right|<\frac{4\varepsilon}{5}\quad\text{for all }C\in\mathcal{C}_{k}.

Since
x
is periodic with period
p
then
\delta_{p}(x)=\delta_{qp}(x)
for any positive integer
q
. Picking
R_{0}=pq
for
q
sufficiently large in terms of
p,\varepsilon
and
k
will then ensure that for any
R\geq R_{0}
and any point
y\in\{0,1\}^{\mathbb{N}}
starting with the word
x_{0}x_{1}\dots x_{R-1}
will have that

\left|\delta_{R}(y)(C)-\delta_{p}(x)(C)\right|<\frac{\varepsilon}{5}\quad\text{for all }C\in\mathcal{C}_{k},

which combined with equation (
9
) completes the proof.
∎

Notice that the proof of Lemma
5.1
in particular implies periodic measures, i.e. those giving equal mass to each point in finite
\sigma
-orbit of a periodic point, are dense in
\mathcal{M}_{\sigma}
. The proof of Proposition
3.1
proceeds by concatenating larger and larger pieces of these periodic points in the correct proportion.

Proof of Proposition
3.1
.

Let
\nu\in\mathcal{M}_{\sigma}
and use Lemma
5.1
to obtain for each
k\in\mathbb{N}
a point
x^{k}\in\{0,1\}^{\mathbb{N}}
and a positive integer
R_{k}
such that for every
R\geq R_{k}
and every
y\in\{0,1\}^{\mathbb{N}}
with
y|_{R}=x^{k}|_{R}
we have that

(10)

\left|\delta_{R}(y)(C)-\nu(C)\right|<\frac{1}{k}\quad\text{for all }C\in\mathcal{C}_{k}.

Now let
L_{1}:=R_{1}
and for
j\geq 2
inductively pick some integer
L_{j}
such that

(11)

\displaystyle L_{j}\geq R_{j},

(12)

\displaystyle\frac{R_{j+1}}{L_{j}}<\frac{1}{j},\text{ and}

(13)

\displaystyle\frac{L_{j}}{L_{1}+L_{2}+\dots+L_{j}}>1-\frac{1}{j}.

We claim that the point

y:=x^{1}|_{L_{1}}\bullet x^{2}|_{L_{2}}\bullet x^{3}|_{L_{3}}\dots

has that
\delta_{N}(y)\to\nu
as
N\to\infty
. Indeed for any
N
let
k=k(N)
be such that

L_{1}+\dots+L_{k}\leq N<L_{1}+\dots+L_{k+1}

and write
N=L_{1}+\dots+L_{k}+L
. Notice that we can then split
\delta_{N}(y)
into three terms which we will refer to as first, middle and last for the remainder of the proof. The three terms are

\delta_{N}(y)=\frac{1}{N}\sum_{i=1}^{k-1}L_{i}\delta_{L_{i}}(y^{i})+\frac{L_{k}}{N}\delta_{L_{k}}(y^{k})+\frac{L}{N}\delta_{L}(y^{k+1})

where
y^{i}\in\{0,1\}^{\mathbb{N}}
has
y^{i}|_{L_{i}}=x^{i}|_{L_{i}}
for each
i=1,\dots,k
and
y^{k+1}|L=x^{k+1}|_{L}
. Equation (
13
) always ensures that the first term is
\mathcal{O}(1/k)
. If
L<R_{k+1}
then equations (
12
) and (
13
) ensure both that the last term is
\mathcal{O}(1/k)
and that
L_{k}/N=1+\mathcal{O}(1/k)
. This observation combined with equations (
11
) and (
10
) ensure that for every cylinder
C\in\mathcal{C}_{k}
the middle term has that

\displaystyle\frac{L_{k}}{N}\delta_{L_{k}}(y^{k})(C)

\displaystyle=\left(1+\mathcal{O}(1/k)\right)\left(\nu(C)+\mathcal{O}(1/k)\right)

\displaystyle=\nu(C)+\mathcal{O}(1/k).

If instead
L\geq R_{k+1}
then the last term may not be negligible but instead equation (
10
) applies to both the middle and the final term to see that for every cylinder
C\in\mathcal{C}_{k}
we have that

\displaystyle\frac{L_{k}}{N}\delta_{L_{k}}(y^{k})(C)+\frac{L}{N}\delta_{L}(y^{k+1})(C)

\displaystyle=\frac{L_{k}+L}{N}\left(\nu(C)+\mathcal{O}(1/k)\right)

\displaystyle=\left(1+\mathcal{O}(1/k)\right)\nu(C)+\mathcal{O}(1/k)

where in the last line we use equation (
13
). In any case then we have that

\delta_{N}(y)(C)=\nu(C)+\mathcal{O}(1/k)\quad\text{for all }C\in\mathcal{C}_{k}.

Since
k=k(N)\to\infty
as
N\to\infty
then for any fixed cylinder
C
this implies that

\delta_{N}(y)(C)\to\nu(C)\quad\text{as}\quad N\to\infty

as required.
∎

6.
Further questions

As stated our inverse correspondence principle only applies to the Følner sequence
(F_{N})=(\{0,1,\dots,N-1\})
, and so Questions
1
and
2
both remain open in their full generality. Although the construction in the proof of Proposition
3.1
is flexible enough to also cover the cases when
(F_{N})
is an increasing sequence of nested intervals or when
(F_{N})
is a sequence of disjoint intervals, the general case when
(F_{N})
is an arbitrary Følner sequence remains unclear. Indeed we do not even know how to handle the case when

F_{N}=\{1,\dots,n_{N}\}+t_{N}

for some increasing sequence
(n_{N})
and some shifts
t_{N}\in\mathbb{N}
.

In a slightly different direction, if in Definition
1.1
we replace the words "for any measure preserving system" with "for any
ergodic
measure preserving system", then we obtain the a-priori weaker definition of a set of
ergodic recurrence
. In the exact same way one can modify Definition
1.4
to obtain the definition of a set of
ergodic nice recurrence
. It is known that being a set of ergodic recurrence is in fact equivalent to being a set of recurrence, indeed one proof follows from Theorem
1.5
and an appeal to the ergodic decomposition. Whether or not the same equivalence holds for nice recurrence is another question of Moreira
[
11
]
.

Question 3
.

Does there exist a set of ergodic nice recurrence which is not a set of nice recurrence?

Contrastingly to all other similarities between sets of recurrence and sets of nice recurrence, both proved and conjectured, we expect that the answer to Question
3
is yes because in the setting of multiple recurrence the analogous version of Question
3
is known to have an affirmative answer. Indeed the authors of
[
4
]
showed that if
(X,\mu,T)
is an ergodic measure preserving system and
A\subset X
has positive measure, then for any
\varepsilon>0
the set

R_{3}(A,\varepsilon):=\{n\in\mathbb{N}\,:\,\mu(A\cap T^{-n}A\cap T^{-2n})>\mu(A)^{3}-\varepsilon\}

is syndetic and in particular non-empty, however they also constructed an example of a non-ergodic system
(X,\mu,T)
with a positive measure set
A\subset X
for which
R_{3}(A,\varepsilon)
is empty. In the setting of single recurrence however, Question
3
remains open.
