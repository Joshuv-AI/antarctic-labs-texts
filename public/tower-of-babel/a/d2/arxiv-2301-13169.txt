Improved machine learning algorithm for predicting ground state properties
Laura Lewis, Hsin-Yuan Huang, Viet T. Tran, Sebastian Lehner, Richard Kueng, John Preskill

Abstract
Finding the ground state of a quantum many-body system is a fundamental problem in quantum physics. In this work, we give a classical machine learning (ML) algorithm for predicting ground state properties with an inductive bias encoding geometric locality. The proposed ML model can efficiently predict ground state properties of an n n -qubit gapped local Hamiltonian after learning from only 𝒪 ⁡ ( log ⁡ ( n ) ) \mathcal{O}(\log(n)) data about other Hamiltonians in the same quantum phase of matter. This improves substantially upon previous results that require 𝒪 ⁡ ( n c ) \mathcal{O}(n^{c}) data for a large constant c c . Furthermore, the training and prediction time of the proposed ML model scale as 𝒪 ⁡ ( n ​ log ⁡ n ) \mathcal{O}(n\log n) in the number of qubits n n . Numerical experiments on physical systems with up to 45 45 qubits confirm the favorable scaling in predicting ground state properties using a small training dataset.

II
ML algorithm and rigorous guarantee

The central component of the improved ML algorithm is the geometric inductive bias built into our feature mapping
x\in[-1,1]^{m}\mapsto\phi(x)\in\mathbb{R}^{m_{\phi}}
.
To describe the ML algorithm, we first need to present some definitions relating to this geometric structure.

II.1
Definitions

We consider
n
qubits arranged at locations, or sites, in a
d
-dimensional space, e.g., a spin chain (
d=1
), a square lattice (
d=2
), or a cubic lattice (
d=3
).
This geometry is characterized by the distance
d_{\mathrm{qubit}}(i,i^{\prime})
between any two qubits
i
and
i^{\prime}
.
Using the distance
d_{\mathrm{qubit}}
between qubits, we can define the geometry of local observables.
Given any two observables
O_{A},O_{B}
on the
n
-qubit system,
we define the distance
d_{\mathrm{obs}}(O_{A},O_{B})
between the two observables as the minimum distance between the qubits that
O_{A}
and
O_{B}
act on.
We also say an observable is geometrically local if it acts nontrivially only on nearby qubits under the distance metric
d_{\mathrm{qubit}}
.
We then define
S^{\mathrm{(geo)}}
as the set of all geometrically local Pauli observables, i.e., geometrically local observables that belong to the set
\{I,X,Y,Z\}^{\otimes n}
.
The size of
S^{\mathrm{(geo)}}
is
\mathcal{O}(n)
, linear in the total number of qubits.

With these basic definitions in place, we now define a few more geometric objects.
The first object is the set of coordinates in the
m
-dimensional vector
x
that are close to a geometrically local Pauli observable
P
. This is formally given by,

I_{P}\triangleq\left\{c\in\{1,\dots,m\}:d_{\mathrm{obs}}(h_{j(c)},P)\leq\delta_{1}\right\},

(II.1)

where
h_{j(c)}
is the few-body interaction term in the
n
-qubit Hamiltonian
H(x)
that is parameterized by the variable
x_{c}\in[-1,1]
, and
\delta_{1}
is an efficiently computable hyperparameter that is determined later.
Note that, by definition, each variable
x_{c}
parameterizes one of the interaction terms
h_{j(c)}
.
Intuitively,
I_{P}
is the set of coordinates that have the strongest influence on the function
\Tr(P \rho(x))
.

The second geometric object is a discrete lattice over the space
[-1,1]^{m}
associated to each subset
I_{P}
of coordinates.
For any geometrically local Pauli observable
P\in S^{\mathrm{(geo)}}
, we define
X_{P}
to contain all vectors
x
that take on value
0
for coordinates outside
I_{P}
and take on a set of discrete values for coordinates inside
I_{P}
. Formally, this is given by

X_{P}\triangleq\left.\begin{cases}x\in[-1,1]^{m}:\text{if }c\notin I_{P},\,\,x_{c}=0\\
\hskip 62.0pt\text{if }c\in I_{P},\,\,x_{c}\in\left\{0,\pm\delta_{2},\pm 2\delta_{2},\dots,\pm 1\right\}\end{cases}\right\},

(II.2)

where
\delta_{2}
is an efficiently computable hyperparameter to be determined later.
The definition of
X_{P}
is meant to enumerate all sufficiently different vectors for coordinates in the subset
I_{P}\subseteq\{1,\ldots,m\}
.

Now given a geometrically local Pauli observable
P
and a vector
x
in the discrete lattice
X_{P}\subseteq[-1,1]^{m}
, the third object is a set
T_{x,P}
of vectors in
[-1,1]^{m}
that are close to
x
for coordinates in
I_{P}
. This is formally defined as,

T_{x,P}\triangleq\left\{x^{\prime}\in[-1,1]^{m}:-\frac{\delta_{2}}{2}<x_{c}-x_{c}^{\prime}\leq\frac{\delta_{2}}{2},\forall c\in I_{P}\right\}.

(II.3)

The set
T_{x,P}
is defined as a thickened affine subspace close to the vector
x
for coordinates in
I_{P}
.
If a vector
x^{\prime}
is in
T_{x,P}
, then
x^{\prime}
is close to
x
for all coordinates in
I_{P}
, but
x^{\prime}
may be far away from
x
for coordinates outside of
I_{P}
.

II.2
Feature mapping and ML model

We can now define the feature map
\phi
taking an
m
-dimensional vector
x
to an
m_{\phi}
-dimensional vector
\phi(x)
using the thickened affine subspaces
T_{x^{\prime},P}
for every geometrically local Pauli observable
P\in S^{\mathrm{(geo)}}
and every vector
x^{\prime}
in the discrete lattice
X_{P}
.
The dimension of the vector
\phi(x)
is given by
m_{\phi}=\sum_{P\in S^{\mathrm{(geo)}}}|X_{P}|
.
Each coordinate of the vector
\phi(x)
is indexed by
x^{\prime}\in X_{P}
and
P\in S^{\mathrm{(geo)}}
with

\phi(x)_{x^{\prime},P}\triangleq\mathds{1}\left[x\in T_{x^{\prime},P}\right],

(II.4)

which is the indicator function checking if
x
belongs to the thickened affine subspace.
Recall that this means each coordinate of the
m_{\phi}
-dimensional vector
\phi(x)
checks if
x
is close to a point
x^{\prime}
on a discrete lattice
X_{P}
for the subset
I_{P}
of coordinates close to a geometrically local Pauli observable
P
.

The classical ML model we consider is an
\ell_{1}
-regularized regression (LASSO) over the
\phi(x)
space.
More precisely, given an efficiently computable hyperparameter
B>0
, the classical ML model finds an
m_{\phi}
-dimensional vector
\mathbf{w}^{*}
from the following optimization problem,

\min_{\begin{subarray}{c}\mathbf{w}\in\mathbb{R}^{m_{\phi}}\\
\norm{\mathbf{w}}_{1}\leq B\end{subarray}}\,\frac{1}{N}\sum_{\ell=1}^{N}\left|\mathbf{w}\cdot\phi(x_{\ell})-y_{\ell}\right|^{2},

(II.5)

where
\{(x_{\ell},y_{\ell})\}_{\ell=1}^{N}
is the training data.
Here,
x_{\ell}\in[-1,1]^{m}
is an
m
-dimensional vector that parameterizes a Hamiltonian
H(x)
and
y_{\ell}
approximates
\Tr(O\rho(x_\ell))
.
The learned function is given by
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x)
.
The optimization does not have to be solved exactly.
We only need to find a
\mathbf{w}^{*}
whose function value is
\mathcal{O}(\epsilon)
larger than the minimum function value.
There is an extensive literature

;
daubechies2004iterative
;
combettes2005signal
;
cesa2011efficient
;
friedman2010regularization
;
hazan2012linear
;
chen2021quantum
improving the computational time for the above optimization problem.
The best known classical algorithm

has a computational time scaling linearly in
m_{\phi}/\epsilon^{2}
up to a log factor, while the best known quantum algorithm

has a computational time scaling linearly in
\sqrt{m_{\phi}}/\epsilon^{2}
up to a log factor.

(Sample and computational complexity)

Given

,
\tfrac{1}{e}>\epsilon>0

\mathop{{\mathbb{E}}}\displaylimits_{x\sim\mathcal{D}}\left|h^{*}(x)-\Tr(O \rho(x))\right|^{2}\leq\epsilon

The training and prediction time of the classical ML model are bounded by

The output

(II.8)

III
Proof ideas

We describe the key ideas behind the proof of Theorem
1
.
The proof is separated into three parts.
The first part in Appendix
A
describes the existence of a simple functional form that approximates the ground state property
\Tr(O \rho(x))
.
The second part in Appendix
B
gives a new bound for the
\ell_{1}
-norm of the Pauli coefficients of the observable
O
when written in the Pauli basis.
The third part in Appendix
C
combines the first two parts, using standard tools from learning theory to establish the sample complexity corresponding to the prediction error bound given in Theorem
1
.
In the following, we discuss these three parts in detail.

III.1
Simple form for ground state property

Using the spectral flow formalism
bachmann2012automorphic
;
hastings2005quasiadiabatic
;
osborne2007simulating
, we first show that the ground state property can be approximated by a sum of local functions.
First, we write
O
in the Pauli basis as
O=\sum_{P\in\{I,X,Y,Z\}^{\otimes n}}\alpha_{P}P
.
Then, we show that for every geometrically local Pauli observable
P
, we can construct a function
f_{P}(x)
that depends only on coordinates in the subset
I_{P}
of coordinates that parameterizes interaction terms
h_{j}
near the Pauli observable
P
.
The function
f_{P}(x)
is given by

f_{P}(x)=\alpha_{P}\Tr(P \rho(\chi_P(x))),

(III.1)

where
\chi_{P}(x)\in[-1,1]^{m}
is defined as
\chi_{P}(x)_{c}=x_{c}
for coordinate
c\in I_{P}
and
\chi_{P}(x)_{c}=0
for coordinates
c\not\in I_{P}
.
The sum of these local functions
f_{P}
can be used to approximate the ground state property,

\Tr(O \rho(x))\approx\sum_{P\in S^{\mathrm{(geo)}}}f_{P}(x).

(III.2)

The approximation only incurs an
\mathcal{O}(\epsilon)
error if we consider
\delta_{1}=\Theta(\log^{2}(1/\epsilon))
in the definition of
I_{P}
.
The key point is that correlations decay exponentially with distance in the ground state of a gapped local Hamiltonian; therefore, the properties of the ground state in a localized region are not sensitive to the details of the Hamiltonian at points far from that localized region.
Furthermore, the local function
f_{P}
is smooth.
The smoothness property allows us to approximate each local function
f_{P}
by a simple discretization,

f_{P}(x)\approx\sum_{x^{\prime}\in X_{P}}f_{P}(x^{\prime})\mathds{1}\left[x\in T_{x^{\prime},P}\right].

(III.3)

One could also use other approximations for this step, such as Fourier approximation or polynomial approximation.
For simplicity, we consider a discretization-based approximation with
\delta_{2}=\Theta(1/\epsilon)

in the definition of
T_{x^{\prime},P}
to incur at most an
\mathcal{O}(\epsilon)
error.
The point is that, for a sufficiently smooth function
f_{P}(x)
that depends only on coordinates in
I_{P}
and a sufficiently fine lattice over the coordinates in
I_{P}
, replacing
x
by the nearest lattice point (based only on coordinates in
I_{P}
) causes only a small error.
Using the definition of the feature map
\phi(x)
in Eq. (
II.4
), we have

\Tr(O \rho(x))\approx\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}f_{P}(x^{\prime})\phi(x)_{x^{\prime},P}=\mathbf{w}^{\prime}\cdot\phi(x),

(III.4)

where
\mathbf{w}^{\prime}
is an
m_{\phi}
-dimensional vector indexed by
x^{\prime}\in X_{P}
and
P\in S^{\mathrm{geo}}
given by
\mathbf{w}_{x^{\prime},P}^{\prime}=f_{P}(x^{\prime})
.
The approximation is accurate if we consider
\delta_{1}=\Theta(\log^{2}(1/\epsilon))
and
\delta_{2}=\Theta(1/\epsilon)
.
Thus, we can see that the ML algorithm with the proposed feature mapping indeed has the capacity to approximately represent the target function
\Tr(O \rho(x))
.
As a result, we have the following lemma.

Lemma 1

(Training error bound)
.

The function given by
\mathbf{w}^{\prime}\cdot\phi(x)
achieves a small training error:

\frac{1}{N}\sum_{\ell=1}^{N}\left|\mathbf{w}^{\prime}\cdot\phi(x_{\ell})-y_{\ell}\right|^{2}\leq 0.53\epsilon.

(III.5)

This lemma follows from the two facts that
\mathbf{w}^{\prime}\cdot\phi(x)\approx\Tr(O \rho(x))
and
\Tr(O \rho(x_\ell))\approx y_{\ell}
.

III.2
Norm inequality for observables

The efficiency of an
\ell_{1}
-regularized regression depends greatly on the
\ell_{1}
norm of the vector
\mathbf{w}^{\prime}
.
Moreover, the
\ell_{1}
-norm of
\mathbf{w}^{\prime}
is closely related to the observable
O=\sum_{j}O_{j}
given as a sum of geometrically local observables with
\norm{O}_{\infty}\leq 1
.
In particular, again writing
O
in the Pauli basis as
O=\sum_{Q\in\{I,X,Y,Z\}^{\otimes n}}\alpha_{Q}Q
, the
\ell_{1}
-norm
\norm{\mathbf{w}'}_{1}
is closely related to

\sum_{Q}\left|\alpha_{Q}\right|,

which we refer to as the Pauli
1
-norm of the observable
O
.
While it is well known that

\sum_{Q}\left|\alpha_{Q}\right|^{2}=\Tr(O^2)/2^{n}\leq\norm{O}_{\infty}^{2},

(III.6)

there do not seem to be many known results characterizing
\sum_{Q}\left|\alpha_{Q}\right|
.
To understand the Pauli
1
-norm,
we prove the following theorem.

Theorem 2

(Pauli
1
-norm bound)
.

Let
O=\sum_{Q\in\{I,X,Y,Z\}^{\otimes n}}\alpha_{Q}Q
be an observable that can be written as a sum of geometrically local observables. We have,

\sum_{Q}|\alpha_{Q}|\leq C\norm{O}_{\infty},

(III.7)

for some constant
C
.

A series of related norm inequalities are also established in
huang2022learning
.
However, the techniques used in this work differ significantly from those in
huang2022learning
.

III.3
Prediction error bound for the ML algorithm

Using the construction of the local function
f_{P}(x_{c},c\in I_{P})
given in Eq. (
III.1
) and the vector
\mathbf{w}^{\prime}
defined in Eq. (
III.4

\norm{\mathbf{w}'}_{1}\leq\max_{P\in S^{\mathrm{(geo)}}}\left|X_{P}\right|\left(\sum_{Q}\left|\alpha_{Q}\right|\right)\leq\left(1+\frac{2}{\delta_{2}}\right)^{\mathrm{poly}(\delta_{1})}\left(\sum_{Q}\left|\alpha_{Q}\right|\right).

The norm inequality in Theorem

\norm{\mathbf{w}'}_{1}\leq C\norm{O}_{\infty}\left(1+\frac{2}{\delta_{2}}\right)^{\mathrm{poly}(\delta_{1})}\leq 2^{\mathrm{poly}\log(1 / \epsilon)},

because
\norm{O}_{\infty}\leq 1
and
\delta_{1}=\Theta(\log^{2}(1/\epsilon)),\delta_{2}=\Theta(1/\epsilon)
.
This shows that there exists a vector

that has a bounded

-norm and achieves a small training error.

Using the norm bound on

.
Using standard learning theory

;
mohri2018foundations

\mathop{{\mathbb{E}}}\displaylimits_{x\sim\mathcal{D}}\left|h^{*}(x)-\Tr(O \rho(x))\right|^{2}\leq\frac{1}{N}\sum_{\ell=1}^{N}\left|\mathbf{w}^{*}\cdot\phi(x_{\ell})-y_{\ell}\right|^{2}+\mathcal{O}\left(B\sqrt{\frac{\log(m_{\phi} / \delta)}{N}}\right)

(III.10)

with probability at least

The first term is the training error for

for

from Lemma

Thus, the first term is bounded by

The second term is determined by

Hence, with a training data size of

V
Outlook

The classical ML algorithm and the advantage over non-ML algorithms as proven in
huang2021provably
illustrate the potential of using ML algorithms to solve challenging quantum many-body problems.
However, the classical ML model given in
huang2021provably
requires a large amount of training data.
Although the need for a large dataset is a common trait in contemporary ML algorithms
brown2020language
;
deng2009imagenet
;
saharia2022photorealistic
,
one would have to perform an equally large number of physical experiments to obtain such data.
This makes the advantage of ML over non-ML algorithms challenging to realize in practice.
The sample complexity
N=\mathcal{O}(\log n)
of the ML algorithm proposed here illustrates that this advantage could potentially be realized after training with data from a small number of physical experiments.
The existence of a theoretically backed ML algorithm with a
\log(n)
sample complexity raises the hope of designing good ML algorithms to address practical problems in quantum physics, chemistry, and materials science by learning from the relatively small amount of data that we can gather from real-world experiments.

Despite the progress in this work, many questions remain to be answered.
Recently, powerful machine learning models such as graph neural networks have been used to empirically demonstrate a favorable sample complexity when leveraging the local structure of Hamiltonians in the 2D random Heisenberg model
wang2022predicting
;
tran2022shadows
.
Is it possible to obtain rigorous theoretical guarantees for the sample complexity of neural-network-based ML algorithms for predicting ground state properties?
An alternative direction is to notice that the current results have an exponential scaling in the inverse of the spectral gap. Is the exponential scaling a fundamental nature of this problem? Or do there exist more efficient ML models that can efficiently predict ground state properties for gapless Hamiltonians?

We have focused on the task of predicting local observables in the ground state, but many other physical properties are also of high interest.
Can ML models predict low-energy excited state properties? Could we achieve a sample complexity of
N=\mathcal{O}(\log n)
for predicting any observable
O
?
Another important question is whether there is a provable quantum advantage in predicting ground state properties.
Could we design quantum ML algorithms that can predict ground state properties by learning from far fewer experiments than any classical ML algorithm? Perhaps this could be shown by combining ideas from adiabatic quantum computation
farhi2000quantum
;
mizel2007simple
;
childs2001robustness
;
aharonov2008adiabatic
;
barends2016digitized
;
albash2018adiabatic
;
du2010nmr
;
wan2020fast
and recent techniques for proving quantum advantages in learning from experiments
aharonov2021quantum
;
chen2022exponential
;
huang2022foundations
;
huang2021information
;
huang2022quantum
.
It remains to be seen if quantum computers could provide an unconditional super-polynomial advantage over classical computers in predicting ground state properties.

.

Consider a class of local Hamiltonians
\{H(x):x\in[-1,1]^{m}\}
satisfying assumptions
1
-
3
, and an observable
O=\alpha_{P}P
, where
P
acts on at most
\mathcal{O}(1)
qubits. Suppose that some
x,x^{\prime}\in[-1,1]^{m}
only differ in one coordinate, say the coordinate
c^{*}
such that
c^{*}\notin I_{P}
and only one
h_{j}
depends on
x_{c^{*}}
. Let
\hat{u}
be a unit vector in the direction that moves from
x
to
x^{\prime}
along the
c^{*}
th coordinate. Then, there exist constants
c_{1},c_{2}
such that

\displaystyle\begin{split}&|\alpha_{P}|\left|\hat{u}\cdot\nabla_{x}\Tr(P\rho(x))\right|\\
&\leq|\alpha_{P}|\left(c_{1}e^{-\frac{a_{\mathrm{lr}}\Delta(j,P)}{2}}+c_{2}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right).\end{split}

(A.16)

Proof.

For the direction
\hat{u}
, we can write the directional derivative of
\rho(x)
in two ways. First, we have the standard definition:

\frac{\partial\rho}{\partial\hat{u}}(x)=\hat{u}\cdot\nabla_{x}\rho(x).

(A.17)

Then, from spectral flow, we also have Eq. (
A.1
).
When evaluated on an observable
O=\alpha_{P}P
, this establishes the following correspondence:

\alpha_{P}(\hat{u}\cdot\nabla_{x}\Tr(P \rho(x)))=i\alpha_{P}\Tr(P[D_{\hat{u}}(x),\rho(x)])=i\alpha_{P}\Tr([P, D_{\hat{u}}(x)]\rho(x)).

(A.18)

Expanding
D_{\hat{u}}(x)
according to Eq. (
A.2
) and applying the triangle inequality to

H(x)=\sum_{j=1}^{L}h_{j}(\vec{x}_{j}),

(A.19)

we have

|\alpha_{P}||\Tr([P, D_{\hat{u}}(x)]\rho(x))|\leq|\alpha_{P}|\int_{-\infty}^{+\infty}W_{\gamma}(t)\sum_{j=1}^{L}\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt.

(A.20)

Here, since
x_{c^{*}}
only affects
h_{j}
for one
j
and
\hat{u}
is in the direction where only the coordinate
c^{*}
changes, then

\frac{\partial h_{j^{\prime}}}{\partial\hat{u}}=0

(A.21)

for all
j^{\prime}\neq j
. Thus, we are left with

|\alpha_{P}||\Tr([P, D_{\hat{u}}(x)]\rho(x))|\leq|\alpha_{P}|\int_{-\infty}^{+\infty}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt.

(A.22)

We bound this integral using Lieb-Robinson bounds and the inequality on
W_{\gamma}(t)
that

\sup_{t}|W_{\gamma}(t)|=1/2.

(A.23)

We first need to split the integral into cases.
This is because Lieb-Robinson bounds only apply outside of the lightcone, i.e., when
\Delta(j,P)>v_{\mathrm{lr}}|t|
.
Then, when
\Delta(j,P)\leq v_{\mathrm{lr}}|t|
, we can instead use the commutator norm bound
\norm{[A, B]}_{\infty}\leq 2\norm{A}_{\infty}\norm{B}_{\infty}
.
Thus, we define
t^{*}=\Delta(j,P)/(2v_{\mathrm{lr}})
and split up the integration into two parts:
t\in[-t^{*},t^{*}]
and
t\notin[-t^{*},t^{*}]
so that we have

\displaystyle\begin{split}|\alpha_{P}||\Tr([P, D_{\hat{u}}(x)]\rho(x))|&\leq|\alpha_{P}|\int_{-t^{*}}^{t^{*}}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt\\
&+|\alpha_{P}|\int_{t^{*}}^{+\infty}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt\\
&+|\alpha_{P}|\int_{-\infty}^{-t^{*}}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt.\end{split}

(A.24)

Notice that the first integral corresponds to the case when we are outside of the lightcone, i.e.,
\Delta(j,P)>2v_{\mathrm{lr}}|t|
while the other two integrals correspond to the case when we are inside of the light cone.

First, we bound the first integral using the Lieb-Robinson bound.
Applying Eq. (
A.6
) to the commutator norm, we have

\displaystyle\norm{\left[P, e^{itH(x)}\frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}

\displaystyle\leq c_{\mathrm{lr}}\norm{P}_{\infty}\norm{\frac{\partial h_j}{\partial\hat{u}}}_{\infty}|\mathsf{dom}(h_{j})|e^{-a_{\mathrm{lr}}(\Delta(j,P)-v_{\mathrm{lr}}|t|)}

(A.25a)

\displaystyle\leq c_{\mathrm{lr}}c_{h}e^{-a_{\mathrm{lr}}(\Delta(j,P)-v_{\mathrm{lr}}|t|)},

(A.25b)

where in the last inequality, we are using assumption
2
that
\norm{\partial h_j/\partial\hat{u}}_{\infty}\leq 1
and
|\mathsf{dom}(h_{j})|\leq c_{h}
for a constant
c_{h}
.
Plugging this into the integral, we have

\displaystyle|\alpha_{P}|\int_{-t^{*}}^{t^{*}}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}}e^{-itH(x)}\right]}_{\infty}\,dt

\displaystyle\leq|\alpha_{P}|c_{\mathrm{lr}}c_{h}e^{-a_{\mathrm{lr}}\Delta(j,P)}\int_{-t^{*}}^{t^{*}}|W_{\gamma}(t)|e^{a_{\mathrm{lr}}v_{\mathrm{lr}}|t|}\,dt

(A.26a)

\displaystyle\leq\frac{1}{2}|\alpha_{P}|c_{\mathrm{lr}}c_{h}e^{-a_{\mathrm{lr}}\Delta(j,P)}\int_{-t^{*}}^{t^{*}}e^{a_{\mathrm{lr}}v_{\mathrm{lr}}|t|}\,dt

(A.26b)

\displaystyle=|\alpha_{P}|c_{\mathrm{lr}}c_{h}e^{-a_{\mathrm{lr}}\Delta(j,P)}\int_{0}^{t^{*}}e^{a_{\mathrm{lr}}v_{\mathrm{lr}}t}\,dt

(A.26c)

\displaystyle=|\alpha_{P}|\frac{c_{\mathrm{lr}}c_{h}e^{-a_{\mathrm{lr}}\Delta(j,P)}}{a_{\mathrm{lr}}v_{\mathrm{lr}}}\left(e^{a_{\mathrm{lr}}v_{\mathrm{lr}}t^{*}}-1\right)

(A.26d)

\displaystyle=|\alpha_{P}|\frac{c_{\mathrm{lr}}c_{h}}{a_{\mathrm{lr}}v_{\mathrm{lr}}}e^{-a_{\mathrm{lr}}\Delta(j,P)}\left(e^{a_{\mathrm{lr}}\Delta(j,P)/2}-1\right)

(A.26e)

\displaystyle=|\alpha_{P}|\frac{c_{\mathrm{lr}}c_{h}}{a_{\mathrm{lr}}v_{\mathrm{lr}}}\left(e^{-a_{\mathrm{lr}}\Delta(j,P)/2}-e^{-a_{\mathrm{lr}}\Delta(j,P)}\right)

(A.26f)

\displaystyle\leq|\alpha_{P}|\frac{c_{\mathrm{lr}}c_{h}}{a_{\mathrm{lr}}v_{\mathrm{lr}}}e^{-a_{\mathrm{lr}}\Delta(j,P)/2},

(A.26g)

where in the second line, we used the fact that
\sup_{t}|W_{\gamma}(t)|=1/2
, and in the fifth line, we substituted back in
t^{*}=\Delta(j,P)/(2v_{\mathrm{lr}})
.

We can also bound the other integrals using the commutator norm bound

\norm{[A, B]}_{\infty}\leq 2\norm{A}_{\infty}\norm{B}_{\infty}

(A.27)

to obtain:

\displaystyle|\alpha_{P}|\int_{t^{*}}^{+\infty}W_{\gamma}(t)\norm{\left[P, e^{itH(x)} \frac{\partial h_j}{\partial\hat{u}} e^{-itH(x)}\right]}_{\infty}\,dt

\displaystyle\leq 2|\alpha_{P}|\int_{t^{*}}^{+\infty}|W_{\gamma}(t)|\norm{P}_{\infty}\norm{\frac{\partial h_j}{\partial\hat{u}}}_{\infty}\,dt

(A.28a)

\displaystyle\leq 2|\alpha_{P}|\int_{t^{*}}^{\infty}|W_{\gamma}(t)|\,dt,

(A.28b)

where in the second line, we used assumption
2
that
\norm{\partial h_j/\partial\hat{u}}_{\infty}\leq 1
.
To bound the resulting integral, we use the definition of
W_{\gamma}(t)
in Eq. (
A.3
).
Note that by our definition of
t^{*}
,
\gamma t^{*}>\theta
, so we only need to consider this case in the upper bound on
W_{\gamma}(t)
.
This is because we chose

\delta_{1}=\max\left(C_{\mathrm{max}}\log^{2}(1/\epsilon),C_{4},C_{5},\frac{\max(5900,\alpha,7(d+11),\theta)}{b}\right),

(A.29)

and here we consider
\Delta(j,P)>\delta_{1}
. Thus, we have

\gamma t^{*}=\frac{\gamma\Delta(j,P)}{2v_{\mathrm{lr}}}>\frac{\gamma\delta_{1}}{2v_{\mathrm{lr}}}\geq\max(5900,\alpha,7(d+11),\theta)\geq\theta.

(A.30)

Hence, we can bound the integral:

\int_{t^{*}}^{+\infty}|W_{\gamma}(t)|\,dt\leq 35e^{2}\int_{t^{*}}^{+\infty}(\gamma t)^{4}e^{-\frac{2}{7}\frac{\gamma t}{\log^{2}(\gamma t)}}\,dt=35e^{2}\gamma^{-1}\int_{x=\gamma t^{*}}^{+\infty}x^{4}e^{-\frac{2}{7}\frac{x}{\log^{2}(x)}}\,dx.

(A.31)

In the inequality, we used the definition of
W_{\gamma}(t)
and in the equality, we used the substitution
x=\gamma t
.
We can bound this integral using Lemma
9
. Set
a=2/7
and
k=4
.
We have chosen
t^{*}
and
\delta_{1}
such that all of the assumptions of Lemma
9
are satisfied.
In particular, from Eq. (
A.30
), we see that
t=\gamma t^{*}>\max(5900,\alpha,7(d+11),\theta)\geq 5900
.
Furthermore, we have
at/\log^{2}(t)>2k+2
, because if
t\geq 5900
, then it is clear that
at/\log^{2}(t)>10
.
Now, applying Lemma
9
, we have

\int_{t^{*}}^{+\infty}|W_{\gamma}(t)|\,dt\leq\frac{245}{2}e^{2}\gamma^{-1}\left(\frac{1}{1-\frac{35\log^{2}(\gamma t^{*})}{\gamma t^{*}}}\right)(\gamma t^{*})^{10}e^{-\frac{2}{7}\frac{\gamma t^{*}}{\log^{2}(\gamma t^{*})}}.

(A.32)

The last integral can be bounded in exactly the same way.
Plugging these bounds into Eq. (
A.24
), we have

\displaystyle|\alpha_{P}||\Tr([P, D_{\hat{u}}(x)]\rho(x))|

(A.33a)

\displaystyle\leq|\alpha_{P}|\left(\frac{c_{\mathrm{lr}}c_{h}}{a_{\mathrm{lr}}v_{\mathrm{lr}}}e^{-a_{\mathrm{lr}}\Delta(j,P)/2}+4\left(\frac{245}{2}e^{2}\gamma^{-1}\left(\frac{1}{1-\frac{35\log^{2}(\gamma t^{*})}{\gamma t^{*}}}\right)(\gamma t^{*})^{10}e^{-\frac{2}{7}\frac{\gamma t^{*}}{\log^{2}(\gamma t^{*})}}\right)\right)

(A.33b)

\displaystyle=|\alpha_{P}|\left(c_{1}e^{-a_{\mathrm{lr}}\Delta(j,P)/2}+c_{2}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right),

(A.33c)

where in the second line, we defined constants

c_{1}=\frac{c_{\mathrm{lr}}c_{h}}{a_{\mathrm{lr}}v_{\mathrm{lr}}},\;\;\;c_{2}=\frac{245e^{2}b^{9}}{v_{\mathrm{lr}}}.

(A.34)

Thus, we have proven that if we only change one coordinate outside of
I_{P}
, then the directional derivative changing this coordinate is small. This is exactly the claim of the lemma.
∎

An immediate consequence of this is that we can integrate the directional derivative to obtain a bound on the distance between
\Tr(P\rho(x))
and
\Tr(P\rho(x'))
.

Lemma 4

(Change one coordinate; distance)
.

Consider a class of local Hamiltonians
\{H(x):x\in[-1,1]^{m}\}
satisfying assumptions
1
-
3
, and an observable
O=\alpha_{P}P
, where
P
acts on at most
\mathcal{O}(1)
qubits. Suppose that some
x,x^{\prime}\in[-1,1]^{m}
only differ in one coordinate, say the coordinate
c^{*}
such that
c^{*}\notin I_{P}
and only one
h_{j}
depends on
x_{c^{*}}
. Let
\hat{u}
be a unit vector in the direction that moves from
x
to
x^{\prime}
along the
c^{*}
th coordinate. Then, there exist constants
c_{1}^{\prime},c_{2}^{\prime}
such that

\displaystyle\begin{split}&|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|\\
&\leq|\alpha_{P}|\left(c_{1}^{\prime}e^{-\frac{a_{\mathrm{lr}}\Delta(j,P)}{2}}+c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right).\end{split}

(A.35)

Proof.

By Lemma
3
, we have a bound on the directional derivative of
\alpha_{P}\Tr(P\rho(x))
in the direction of
\hat{u}
.
In this lemma, we want a bound on the distance

|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|=|\alpha_{P}||\Tr(P\rho(x_1,\dots, x_{c^*},\dots, x_m))-\Tr(P\rho(x_1,\dots, x_{c^*}',\dots, x_m))|.

(A.36)

To this end, we can obtain the distance by integrating the directional derivative:

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

(A.37a)

\displaystyle=|\alpha_{P}|\left|\int_{x_{c^{*}}}^{x_{c^{*}}^{\prime}}\frac{\partial\Tr(P\rho(x_1,\dots, t, \dots, x_m))}{\partial\hat{u}}\,dt\right|

(A.37b)

\displaystyle\leq|\alpha_{P}|\int_{x_{c^{*}}}^{x_{c^{*}}^{\prime}}\left|\frac{\partial\Tr(P\rho(x_1,\dots, t, \dots, x_m))}{\partial\hat{u}}\right|\,dt

(A.37c)

\displaystyle=|\alpha_{P}|\int_{x_{c^{*}}}^{x_{c^{*}}^{\prime}}|\Tr([P, D_{\hat{u}}(x_1,\dots, t, \dots, x_m)]\rho(x_1,\dots,t,\dots,x_m))|\,dt,

(A.37d)

where in the last line, we used the correspondence from Eq. (
A.18
).
Now, the integrand is exactly what we bounded in Lemma
3
, so we have

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

(A.38a)

\displaystyle\leq|\alpha_{P}|\int_{x_{c^{*}}}^{x_{c^{*}}^{\prime}}\left(c_{1}e^{-a_{\mathrm{lr}}\Delta(j,P)/2}+c_{2}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right)\,dt

(A.38b)

\displaystyle\leq 2|\alpha_{P}|\left(c_{1}e^{-a_{\mathrm{lr}}\Delta(j,P)/2}+c_{2}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\delta_{1})}\right)\right),

(A.38c)

where in the last line, we can bound this integral because
x_{c^{*}},x_{c^{*}}^{\prime}\in[-1,1]
, so their difference is at most
2
.
Taking
c_{1}^{\prime}=2c_{1}
and
c_{2}^{\prime}=2c_{2}
, we arrive at the claim.
∎

With these two results, we can prove Lemma
2
.

Proof of Lemma
2
.

It remains to show that if we change multiple coordinates outside of
I_{P}
, the difference
|\Tr(P\rho(x))-\Tr(P\rho(x'))|
is still bounded.
Then, taking
f_{P}(x)
to be
\alpha_{P}\Tr(P\rho(\chi_P(x)))
with
\chi_{P}(x)\in[-1,1]^{m}
equal to
x_{c}
for coordinates
c\in I_{P}
and
0
for coordinates outside of
I_{P}
gives the desired result.
Thus, we want to bound

|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|=|\alpha_{P}||\Tr(P\rho(x_1,\dots, x_m))-\Tr(P\rho(x_1',\dots,x_m'))|,

(A.39)

where
x_{c^{\prime}}^{\prime}=x_{c^{\prime}}
if and only if
c^{\prime}\in I_{P}
. We can bound this using the triangle inequality

\displaystyle\begin{split}|\alpha_{P}||\Tr(P \rho(x))-\Tr(P \rho(x'))|&\leq|\alpha_{P}||\Tr(P \rho(x_1,x_2,\dots, x_m))-\Tr(P\rho(x_1',x_2,\dots, x_m))|\\
&+|\alpha_{P}||\Tr(P \rho(x_1',x_2,\dots, x_m))-\Tr(P\rho(x_1',x_2',\dots, x_m))|\\
&+\cdots\\
&+|\alpha_{P}||\Tr(P \rho(x_1',\dots, x_{m-1}', x_m))-\Tr(P \rho(x_1',\dots, x_m'))|\end{split}

(A.40)

Here, recall that we are only changing coordinates outside of
I_{P}
, i.e.,
x_{c}
such that
h_{j}
depends on
x_{c}
and
\Delta(j,P)>\delta_{1}
for
\delta_{1}
in Definition
1
.
Moreover, by assumption
2
, each local term
h_{j}
depends on at most a constant number
q
of parameters.
Then, we can upper bound this sum by

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

\displaystyle\leq q|\alpha_{P}|\sum_{j:\Delta(j,P)>\delta_{1}}|\Tr(P\rho(y_{k^*}))-\Tr(P\rho(y_{k^*}'))|,

(A.41a)

where
k^{*}
is defined as

k^{*}\triangleq\argmax_{1\leq k\leq m}|\Tr(P \rho(y_k))-\Tr(P\rho(y_k'))|,

(A.42)

and
y_{k},y_{k}^{\prime}\in[-1,1]^{m}
denote parameter vectors that only differ in the
k
th coordinate.
Each of these terms in the summand can be bounded using Lemma
4
:

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

(A.43a)

\displaystyle\leq q|\alpha_{P}|\sum_{j:\Delta(j,P)>\delta_{1}}\left(c_{1}^{\prime}e^{-\frac{a_{\mathrm{lr}}\Delta(j,P)}{2}}+c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right)

(A.43b)

\displaystyle\begin{split}&\leq q|\alpha_{P}|\sum_{r=0}^{\infty}\sum_{j:\Delta(j,P)\in[\delta_{1}+r,\delta_{1}+r+1]}\left(c_{1}^{\prime}e^{-\frac{a_{\mathrm{lr}}\Delta(j,P)}{2}}\right.\\
&\hskip 100.0pt\left.+c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b\Delta(j,P))}{b\Delta(j,P)}}\right)\Delta(j,P)^{10}\exp\left(-\frac{2}{7}\frac{b\Delta(j,P)}{\log^{2}(b\Delta(j,P))}\right)\right).\end{split}

(A.43c)

Now, we want to upper bound this inner sum over
j
such that
\Delta(j,P)\in[\delta_{1}+r,\delta_{1}+r+1]
.
Using Eq. (
A.5
), we see that there are at most
|\mathsf{dom}(P)|(b_{d}+c_{d}(\delta_{1}+r+1)^{d})
interaction terms
h_{j}
such that
\Delta(j,P)\in[\delta_{1}+r,\delta_{1}+r+1]
.
Moreover, because
P
acts on only a constant number of sites (by assumption), then

|\mathsf{dom}(P)|(b_{d}+c_{d}(\delta_{1}+r+1)^{d})\leq c_{P}(b_{d}+c_{d}(\delta_{1}+r+1)^{d}),

(A.44)

for some constant
c_{P}
. Using this as well as upper bounding the sum over
r
by an integral, we have

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

(A.45a)

\displaystyle\leq qc_{P}|\alpha_{P}|\int_{r=0}^{+\infty}(b_{d}+c_{d}(\delta_{1}+r+1)^{d})

(A.45b)

\displaystyle\cdot\left(c_{1}^{\prime}e^{-\frac{a_{\mathrm{lr}}(\delta_{1}+r)}{2}}+c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b(\delta_{1}+r+1))}{b(\delta_{1}+r)}}\right)(\delta_{1}+r+1)^{10}\exp\left(-\frac{2}{7}\frac{b(\delta_{1}+r)}{\log^{2}(b(\delta_{1}+r+1))}\right)\right)\,dr.

(A.45c)

It remains to integrate this to obtain our desired bound. Distributing, we can split this integral into four terms. We bound each of these individually.

First, we have

\int_{r=0}^{+\infty}b_{d}c_{1}^{\prime}e^{-a_{\mathrm{lr}}(\delta_{1}+r)/2}\,dr=c_{1}^{\prime}b_{d}e^{-a_{\mathrm{lr}}\delta_{1}/2}\int_{r=0}^{+\infty}e^{-a_{{\mathrm{lr}}}r/2}\,dr=\frac{2c_{1}^{\prime}b_{d}}{a_{\mathrm{lr}}}e^{-a_{\mathrm{lr}}\delta_{1}/2}.

(A.46)

We also have

\displaystyle\int_{r=0}^{+\infty}c_{d}c_{1}^{\prime}(\delta_{1}+r+1)^{d}e^{-a_{\mathrm{lr}}(\delta_{1}+r)/2}\,dr

\displaystyle=c_{1}^{\prime}c_{d}e^{-a_{\mathrm{lr}}\delta_{1}/2}\int_{r=0}^{+\infty}(\delta_{1}+r+1)^{d}e^{-a_{\mathrm{lr}}r/2}\,dr

(A.47a)

\displaystyle=c_{1}^{\prime}c_{d}e^{-a_{\mathrm{lr}}\delta_{1}/2}\sum_{k=0}^{d}\frac{d!\,2^{d-k+1}}{k!\,a_{\mathrm{lr}}^{d-k+1}}(\delta_{1}+1)^{k},

(A.47b)

where in the last equality we used integration by parts.
For the other two integrals, we use Lemma
11
to obtain

\int_{r=0}^{+\infty}b_{d}c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b(\delta_{1}+r+1))}{b(\delta_{1}+r)}}\right)(\delta_{1}+r+1)^{10}\exp\left(-\frac{2}{7}\frac{b(\delta_{1}+r)}{\log^{2}(b(\delta_{1}+r+1))}\right)\,dr\leq c\epsilon,

(A.48)

for some constant
c
. Similarly, for the last integral, by Lemma
12
, we have

\int_{r=0}^{+\infty}c_{d}c_{2}^{\prime}\left(\frac{1}{1-\frac{35\log^{2}(b(\delta_{1}+r+1))}{b(\delta_{1}+r)}}\right)(\delta_{1}+r+1)^{d+10}\exp\left(-\frac{2}{7}\frac{b(\delta_{1}+r)}{\log^{2}(b(\delta_{1}+r+1))}\right)\,dr\leq c^{\prime}\epsilon,

(A.49)

for some constant
c^{\prime}
. Putting everything together, we have

\displaystyle|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|

(A.50a)

\displaystyle\leq qc_{P}|\alpha_{P}|\left(\frac{2c_{1}^{\prime}b_{d}}{a_{\mathrm{lr}}}e^{-a_{\mathrm{lr}}\delta_{1}/2}+c_{1}^{\prime}c_{d}e^{-a_{\mathrm{lr}}\delta_{1}/2}\sum_{k=0}^{d}\frac{d!2^{d-k+1}}{k!a_{\mathrm{lr}}^{d-k+1}}(\delta_{1}+1)^{k}+c\epsilon+c^{\prime}\epsilon\right).

(A.50b)

Combining constants and simplifying, we have

|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|\leq|\alpha_{P}|\left(e^{-a_{\mathrm{lr}}\delta_{1}/2}\sum_{k=0}^{d}c_{k}^{\prime\prime}\delta_{1}^{k}+c^{\prime\prime}\epsilon\right).

(A.51)

To obtain the final bound, we can use our choice of
\delta_{1}
to write this bound in terms of
\epsilon
:

e^{-a_{\mathrm{lr}}\delta_{1}/2}\sum_{k=0}^{d}c_{k}^{\prime\prime}\delta_{1}^{k}=\sum_{k=0}^{d}c_{k}^{\prime\prime}e^{-a_{\mathrm{lr}}\delta_{1}/2+k\log\delta_{1}}\leq\left(\sum_{k=0}^{d}c_{k}^{\prime\prime}\right)\epsilon,

(A.52)

where the last inequality follows from our choice of
\delta_{1}
in Definition
1
and
C_{1}
in Lemma
6
. Thus, we have

|\alpha_{P}||\Tr(P\rho(x))-\Tr(P\rho(x'))|\leq C|\alpha_{P}|\epsilon,

(A.53)

where we take

C=\sum_{k=0}^{d}c_{k}^{\prime\prime}+c^{\prime\prime}.

(A.54)

To complete the proof, recall that
f_{P}(x)=\alpha_{P}\Tr(P \rho(\chi_P(x)))
, where
\chi_{P}
is defined in Eq. (
A.13
).
The function
f_{P}
only depends on parameters in
I_{P}
by definition.
By the previous analysis, since
\chi_{P}(x)
and
x
only differs in the coordinates outside of the set
I_{P}
, the function
f_{P}(x)
should be close to
\alpha_{P}\Tr(P \rho(\chi_P(x)))
in absolute value as required.
Moreover,
\Tr(P\rho(x))
is smooth by Lemma 4 in
[
29
]
in that

\norm{\nabla_x \Tr(P\rho(x))}_{2}^{2}\leq C^{\prime}\norm{P}_{\infty}^{2}=C^{\prime}

(A.55)

for some constant
C^{\prime}>0
. Then, because
f_{P}
is defined as
\alpha_{P}\Tr(P \rho(\chi_P(x)))
, we have

\norm{\nabla_x f_P(x)}_{2}^{2}\leq|\alpha_{P}|^{2}C^{\prime},

(A.56)

so
f_{P}
is smooth as claimed.
∎

A.2
Simplification using discretization

Now, we want to show that the sum of smooth local functions
f(x)=\sum_{P\in S^{\mathrm{(geo)}}}f_{P}(x)
from Corollary
2
can be approximated by simple functions, i.e., linear combinations of indicator functions.
In order to do so, we discretize our parameter space and map each
x\in[-1,1]^{m}
to some
x^{\prime}
with discrete values.
Our simple function is then
f
evaluated on this discretized
x^{\prime}
.
To state this more precisely, we first require some definitions.
An illustrative example of how each set is defined is given in Figure
4
.

Definition 3

(Discretization)
.

Let
\epsilon>0
. Let

\delta_{2}\triangleq\frac{1}{\left\lceil\frac{\sqrt{C^{\prime}|I_{P}|}}{\epsilon}\right\rceil},

(A.57)

where
I_{P}
is defined in Definition
2
and
C^{\prime}
is as in Lemma
2
. Define the discretized parameter space as

X_{P}\triangleq\left.\begin{cases}x\in[-1,1]^{m}:\text{if }c\notin I_{P},x_{c}=0\\
\hskip 62.0pt\text{if }c\in I_{P},x_{c}\in\left\{0,\pm\delta_{2},\pm 2\delta_{2},\dots,\pm 1\right\}\end{cases}\right\}.

(A.58)

Moreover, for each
x\in X_{P}
, define the thickened affine subspace close to the vector
x
for coordinates in
I_{P}
as

T_{x,P}\triangleq\left\{x^{\prime}\in[-1,1]^{m}:-\frac{\delta_{2}}{2}<x_{c}-x_{c}^{\prime}\leq\frac{\delta_{2}}{2},\forall c\in I_{P}\right\}.

(A.59)

Figure 4:
Example of Definition
3
. Illustration of the set
T_{x^{\prime},P}
(light blue shading) for specific
x^{\prime}\in X_{P}
(blue circle), fixing
\delta_{2}=1/2
for simplicity.
(a)

Example for
m=1
.

I_{P}
is fixed to
\{1\}
so that
X_{P}=\{0,\pm 1/2,\pm 1\}
according to Def.
3
.
T_{x^{\prime},P}
is depicted for the chosen
x^{\prime}=1/2
.
(b)

Example for
m=2
.

I_{P}
is fixed to
\{2\}
, and
T_{x^{\prime},P}
is depicted for the chosen
x^{\prime}=(0,-1/2)
.

With these definitions, the simple function that approximates
f
is defined by

g(x)\triangleq\sum_{P\in S^{\mathrm{(geo)}}}\left[\,\sum_{x^{\prime}\in X_{P}}f_{P}(x^{\prime})\mathds{1}[x\in T_{x^{\prime},P}]\,\right]\triangleq\sum_{P\in S^{\mathrm{(geo)}}}g_{P}(x).

(A.60)

In what follows, we prove that
g
indeed approximates
f
well. As in Appendix
A.1
, we first consider the simpler case where our observable
O=\alpha_{P}P
is a single Pauli term, which easily generalizes to the general case via triangle inequality.

Lemma 5

(Approximation using simple functions; simple case)
.

Let
\epsilon>0
. Given this
\epsilon
in Definition
3
,

|g_{P}(x)-f_{P}(x)|<\epsilon|\alpha_{P}|

(A.61)

for any
x
, where
f_{P}
is as in Lemma
2
and
g_{P}
is defined in Eq. (
A.60
).

Corollary 3

(Approximation using simple functions; general case)
.

Let
\epsilon>0
. Given this
\epsilon
in Definition
3
, then

|g(x)-f(x)|<\epsilon\left(\sum_{P\in S^{\mathrm{(geo)}}}|\alpha_{P}|\right)

(A.62)

for any
x
, where
f
is as in Corollary
2
and
g
is defined in Eq. (
A.60
).

Proof of Lemma
5
.

Consider some input
x\in[-1,1]^{m}
.
First, we want to argue that
x\in T_{x^{\prime},P}
for exactly one
x^{\prime}\in X_{P}
.
Consider some variable
x_{c}\in[-1,1]
of
x
for
c\in I_{P}
.
It suffices to show that there exists
x_{c}^{\prime}\in\{0,\pm\delta_{2},\pm 2\delta_{2},\dots,\pm 1\}
such that
-\delta_{2}/2<x_{c}^{\prime}-x_{c}\leq\delta_{2}/2
.
This is clear because
\delta_{2}
is defined as a fraction of the form
1/n
for an integer
n
.
Moreover, there is at most one
x_{c}^{\prime}
such that this is true because each possible discrete value of
x_{c}^{\prime}
is separated by intervals of size
\delta_{2}
while
x_{c}
is within
\delta_{2}/2
of
x_{c}^{\prime}
, so there cannot be overlap for different values of
x_{c}^{\prime}
.
Also, since
x_{c}
is in a half-open interval of
x_{c}^{\prime}
, this prevents points on the boundary (i.e., exactly
\delta_{2}/2
away from
x_{c}^{\prime}
) from being associated with two
x_{c}^{\prime}
.
Finally, this half-open interval does not prevent the boundary case of
x_{c}=-1
from being associated with an
x_{c}^{\prime}
because
-1
is always a possible discrete value for
x_{c}^{\prime}
.
This occurs again because of our choice of
\delta_{2}
as a fraction of the form
1/n
for an integer
n
. Thus,
x\in T_{x^{\prime},P}
for exactly one
x^{\prime}\in X_{P}
.

With this, our goal is to show that

|g_{P}(x)-f_{P}(x)|=|f_{P}(x^{\prime})-f_{P}(x)|<\epsilon|\alpha_{P}|.

(A.63)

There are two parts to proving this. By definition of
T_{x^{\prime},P}
in Definition
3
, this means that
x^{\prime}
and
x
are close for coordinates in
I_{P}
. However, for coordinates not in
I_{P}
,
x^{\prime}
and
x
can be far away. Nevertheless, from our results in Lemma
2
, we know that
f_{P}
does not change much when its input only differs for coordinates not in
I_{P}
. Thus, we can use this to obtain our bound.

To make this more clear, we introduce the notation

f_{P}(x)=f_{P}(x_{\mathrm{in}};x_{\mathrm{out}}),

(A.64)

where
x_{\mathrm{in}}
denotes the variables
x_{c}\in[-1,1]
such that
c\in I_{P}
and
x_{\mathrm{out}}
denotes the variables
x_{c}\in[-1,1]
such that
c\notin I_{P}
.
With this, we can use the triangle inequality to treat the two cases separately:

\displaystyle|f_{P}(x^{\prime})-f_{P}(x)|

\displaystyle=|f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}}^{\prime})-f_{P}(x_{\mathrm{in}};x_{\mathrm{out}})|

(A.65a)

\displaystyle\begin{split}&\leq|f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}}^{\prime})-f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}})|\\
&+|f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}})-f_{P}(x_{\mathrm{in}};x_{\mathrm{out}})|.\end{split}

(A.65b)

Here, in the first term, only the coordinates not in
I_{P}
change while in the second term, only coordinates in
I_{P}
change.
To bound the first term, we can use Lemma
2
with
\epsilon
set to
\epsilon/(2C)
, where
C
is the constant defined in Lemma
2
, to obtain

|f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}}^{\prime})-f_{P}(x_{\mathrm{in}}^{\prime};x_{\mathrm{out}})|\leq|\alpha_{P}|\frac{\epsilon}{2}.

(A.66)

For the second term in Eq. (
A.65
), we bound this using the fact that
x^{\prime}
and
x
are separated by at most
\delta_{2}
for coordinates in
I_{P}
and the smoothness condition on
f_{P}
from Lemma
2
.
The key step here is that we can write this difference as the integral of the directional derivative of
f_{P}
along the direction from
x_{\mathrm{in}}
to
x^{\prime}_{\mathrm{in}}
given by a line. In particular, we can parameterize this line by
x_{\mathrm{in}}(t)=x_{\mathrm{in}}+(x_{\mathrm{in}}^{\prime}-x_{\mathrm{in}})t
. Notice that at
t=0
, this is equal to
x_{\mathrm{in}}
while at
t=1
, this is equal to
x_{\mathrm{in}}^{\prime}
. Thus, suppressing the
x_{\mathrm{out}}
parameters in our notation, we have

\displaystyle|f_{P}(x_{\mathrm{in}}^{\prime})-f_{P}(x_{\mathrm{in}})|

\displaystyle=\left|\int_{0}^{1}\frac{\partial f_{P}(x_{\mathrm{in}}(t))}{\partial t}\,dt\right|

(A.67a)

\displaystyle\leq\int_{0}^{1}\left|\frac{\partial f_{P}(x_{\mathrm{in}}(t))}{\partial t}\right|\,dt

(A.67b)

\displaystyle=\int_{0}^{1}\left|\frac{\partial f_{P}(x_{\mathrm{in}}(t))}{\partial x_{\mathrm{in}}(t)}\cdot\frac{\partial x_{\mathrm{in}}(t)}{\partial t}\right|\,dt

(A.67c)

\displaystyle=\int_{0}^{1}\left|\nabla_{x_{\mathrm{in}}}f_{P}(x_{\mathrm{in}})\cdot(x_{\mathrm{in}}^{\prime}-x_{\mathrm{in}})\right|\,dt

(A.67d)

\displaystyle\leq\int_{0}^{1}\norm{\nabla_{x_{\mathrm{in}}} f_P(x_{\mathrm{in}})}_{2}\norm{x_{\mathrm{in}}'-x_{\mathrm{in}}}_{2}\,dt

(A.67e)

\displaystyle\leq\sqrt{C^{\prime}}|\alpha_{P}|\norm{x_{\mathrm{in}}' - x_{\mathrm{in}}}_{2}

(A.67f)

\displaystyle\leq\sqrt{C^{\prime}}|\alpha_{P}|\sqrt{|I_{P}|}\norm{x_{\mathrm{in}}' - x_{\mathrm{in}}}_{\infty}

(A.67g)

\displaystyle\leq\sqrt{C^{\prime}}|\alpha_{P}|\sqrt{|I_{P}|}\frac{\delta_{2}}{2}

(A.67h)

\displaystyle\leq\frac{\epsilon}{2}|\alpha_{P}|.

(A.67i)

Here, in the third line, we use the chain rule. In the fifth line, we use the Cauchy-Schwarz inequality. In the sixth line, we use the smoothness condition from Lemma
2
to bound the
\ell_{2}
-norm of the gradient. In the seventh line, we use the fact that
\norm{y}_{2}\leq\sqrt{n}\norm{y}_{\infty}
where
n
is the number of elements in
y
. In the eighth line, we use the definition of
T_{x,P}
. Finally, in the last line, we use our choice of
\delta_{2}
as

\delta_{2}=\frac{1}{\left\lceil\frac{\sqrt{C^{\prime}|I_{P}|}}{\epsilon}\right\rceil}\leq\frac{\epsilon}{\sqrt{C^{\prime}|I_{P}|}}.

(A.68)

Combining this bound with Eq. (
A.66
) and plugging into Eq. (
A.65
), we have

|f_{P}(x^{\prime})-f_{P}(x)|<\frac{\epsilon}{2}|\alpha_{P}|+\frac{\epsilon}{2}|\alpha_{P}|=\epsilon|\alpha_{P}|,

(A.69)

as required.
∎

A.3
Simple form for ground state property

We can combine the results of the previous two sections to obtain the final result giving a simpler form for the ground state property
\Tr(O\rho(x))
.
The proof of this statement is simple given the previous results.

Theorem 3

(Simple form for
\Tr(O\rho(x))
)
.

Let
1/e>\epsilon>0
.
Given
\epsilon
, we define
\delta_{1}
according to Definition
1
with
\epsilon
set to
\epsilon/(2C)
for the constant
C
defined in Corollary
2
, and define
\delta_{2}
according to Definition
3
with
\epsilon
set to
\epsilon/2
.
The ground state property
\Tr(O\rho(x))
can be approximated by a simple function, i.e.,

|\Tr(O\rho(x))-g(x)|<\epsilon\left(\sum_{P\in S^{\mathrm{(geo)}}}|\alpha_{P}|\right),

(A.70)

where

is defined in Eq. (
A.60
).

Proof.

By the triangle inequality, we have

|\Tr(O\rho(x))-g(x)|\leq|\Tr(O\rho(x))-f(x)|+|f(x)-g(x)|.

(A.71)

Here, the first term can be bounded by Corollary
2
to obtain

(A.72)

Meanwhile, the second term in Eq. (

) can be bounded by Corollary
3
to obtain

Combining Eq. (
A.72
) and Eq. (
A.73
) in Eq. (
A.71
), we have

|\Tr(O\rho(x))-g(x)|<\epsilon\left(\sum_{P\in S^{\mathrm{(geo)}}}|\alpha_{P}|\right)

(A.74)

∎

A.4

In this section, we state and prove several technical lemmas for showing the existence of certain constants and bounding integrals of specific forms needed throughout Appendix
A
.
Throughout this section, we use the notation
b\triangleq\gamma/(2v_{\mathrm{lr}})
.
First, we show the existence of the constants utilized in Definition
1
.

Lemma 6
.

Given
a_{\mathrm{lr}},b>0
and
d\geq 1
, there exists a constant
C_{1}
large enough such that for all
1/e>\epsilon^{\prime}>0
and for all
\delta_{1}^{\prime}>C_{1}\log^{2}(1/\epsilon^{\prime})

\frac{a_{\mathrm{lr}}}{2}\delta_{1}^{\prime}-d\log(\delta_1')\geq\log\left(\frac{1}{\epsilon^{\prime}}\right).

(A.75)

Explicitly, such a constant

can be given by

C_{1}=\frac{(2d+\sqrt{4d^{2}+2a_{\mathrm{lr}}})^{2}}{a_{\mathrm{lr}}^{2}}.

(A.76)

Proof.

For simplicity, throughout this proof, let
x=\log(1/\epsilon')
. Because we assert that
1/e>\epsilon^{\prime}>0
, then
1<x<\infty
.
First, we consider the monotonicity of
f(\delta_{1}^{\prime})=\frac{a_{\mathrm{lr}}}{2}\delta_{1}^{\prime}-d\log(\delta_1')

Taking the derivative of
f
shows that
f(\delta_{1}^{\prime})
is monotonically increasing for
\delta_{1}^{\prime}\geq 2d/a_{\mathrm{lr}}
.
Since
\delta_{1}^{\prime}>C_{1}\log^{2}(1/\epsilon^{\prime})=C_{1}x^{2}\geq C_{1}\geq 2d/a_{\mathrm{lr}}
(note

), it suffices to establish the claim for
\delta_{1}^{\prime}=C_{1}x^{2}
, i.e.,

\frac{a_{\mathrm{lr}}}{2}C_{1}x^{2}-d\log(C_1 x^2)\geq x

(A.77)

for
x>1
. We show that our choice of
C_{1}
satisfies this inequality. First, using the inequality
\log(z)\leq 2(\sqrt{z}-1)
for
z>0
, we can apply this with
z=C_{1}x^{2}
to obtain

\frac{a_{\mathrm{lr}}}{2}C_{1}x^{2}-d\log(C_1x^2)\geq\frac{a_{\mathrm{lr}}}{2}C_{1}x^{2}-2d\sqrt{C_{1}}x+2.

(A.78)

Bounding this trivially because
x^{2}>x
for

, we have

\frac{a_{\mathrm{lr}}}{2}C_{1}x^{2}-d\log(C_1x^2)\geq\left(\frac{a_{\mathrm{lr}}}{2}C_{1}-2d\sqrt{C_{1}}\right)x.

(A.79)

Plugging in our choice of
C_{1}
and simplifying, we have

\displaystyle\frac{a_{\mathrm{lr}}}{2}C_{1}x^{2}-d\log(C_1x^2)

\displaystyle\geq\left(\frac{\left(2d+\sqrt{4d^{2}+a_{\mathrm{lr}}}\right)^{2}}{2a_{\mathrm{lr}}}-2d\left(\frac{2d+\sqrt{4d^{2}+a_{\mathrm{lr}}}}{a_{\mathrm{lr}}}\right)\right)x

(A.80a)

\displaystyle=\left(\frac{8d^{2}+2a_{\mathrm{lr}}+4d\sqrt{4d^{2}+2a_{\mathrm{lr}}}}{2a_{\mathrm{lr}}}-\frac{8d^{2}+4d\sqrt{4d^{2}+2a_{\mathrm{lr}}}}{2a_{\mathrm{lr}}}\right)x

(A.80b)

\displaystyle=x.

(A.80c)

Hence, we obtain the desired inequality.
∎

.

Given
b>0
, there exists a constant

and for all

Proof.

For simplicity, throughout this proof, let
x=\log(1/\epsilon')
. Because we assert that
1/e>\epsilon^{\prime}>0
, then

.
First, we consider the monotonicity of
f(\delta_{1}^{\prime})=\frac{2b\delta_{1}^{\prime}}{7\log^{2}(b(\delta_{1}^{\prime}+1))}-22\log(b(\delta_1'+1))

Taking the derivative of
f
shows that

is monotonically increasing for
\delta_{1}^{\prime}\geq(18b+(63\cdot 22/2))^{3}/b

for

Lemma 9

(Variant of Lemma 2.5 in
[
55
]
, Lemma 5 in
[
29
]
)
.

For
a>0
define

u_{a}(x)=e^{-a\frac{x}{\log^{2}(x)}}

on the domain
x\in(1,\infty)
, where
\log
denotes the natural logarithm. For all integers
k\geq 0
and
t\geq 5504
such that

a\frac{t}{\log^{2}t}>2k+2,

(A.95)

we have the bound

\int_{t}^{+\infty}x^{k}u_{a}(x)\,dx\leq\frac{1}{a\left(1-\frac{2k+2}{\tau(t)}\right)}t^{2k+2}u_{a}(t),

(A.96)

where
\tau(x)\triangleq ax/\log^{2}(x)
.

To prove this, we need a bound on the upper incomplete Gamma function:

Lemma 10

(Proposition 2.7 in
[
80
]
)
.

Take any real
n\geq 0
. Then,

\Gamma(n+1,z)\leq\frac{1}{1-\frac{n}{z}}z^{n}e^{-z},

(A.97)

for all real
z>n
.

Proof of Lemma
9
.

Define the function

\tau(x)\triangleq a\frac{x}{\log^{2}(x)}.

(A.98)

Here, because we are considering the domain
x\in(1,\infty)
, then this function is well-defined and differentiable. Moreover, it is always positive because
\log^{2}(x)\geq\log(x)>0
for
x>1
. Also, consider the derivative

\frac{d\tau}{dx}=a\left(\frac{\log(x)-2}{\log^{3}(x)}\right).

(A.99)

Again, this is well-defined because
\log^{3}(x)>0
for
x>1
. Furthermore, we see that if
x\geq e^{2}
, then
\frac{d\tau}{dx}>0
. Thus, for
x\geq e^{2}
,
\tau(x)
is monotone increasing. Ultimately, our goal is to bound the integral

\int_{t}^{+\infty}x^{k}u_{a}(x)\,dx=\int_{t}^{+\infty}x^{k}e^{-\tau(x)}\,dx

(A.100)

by using a substitution
\tau=\tau(x),d\tau=\frac{d\tau}{dx}dx
. Substituting in for
x
, we use the inverse
x=x(\tau)
and for the differential

Appendix B
Norm inequality for observables

The efficiency of learning depends strongly on the complexity of the target functions we would like to learn.
One way to characterize the complexity of the target function is to consider an appropriate norm of the function.
Given an observable
O=\sum_{P}\alpha_{P}P
specified by the Pauli coefficients
\alpha_{P}
, Theorem
3
shows that having a smaller
\ell_{1}
-norm
\sum_{P}|\alpha_{P}|
on the Pauli coefficients implies that the ground state property
\Tr(O \rho(x))
can be better approximated by a simple function.
This motivates the derivation of bounds on
\sum_{P}|\alpha_{P}|
.

A technical contribution of this work is to develop a norm inequality relating the
\ell_{1}
-norm of the Pauli coefficients
\sum_{P}|\alpha_{P}|
to the spectral norm
\norm{O}_{\infty}
(the largest singular value).
To state this result precisely, we first present some formal definitions.
Throughout the remainder of this section, we consider labelling the
n
qubits in a
d
-dimensional lattice with a
d
-tuple,
\ell=(\ell_{1},\dots,\ell_{d})
, where each
\ell_{k}\in\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}
.

Definition 4

(Domain of an observable)
.

Let
O
be an arbitrary observable in a finite
d
-dimensional space. Then, define the
domain

\mathsf{dom}(O)\subseteq\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}^{d}
of
O
to be the set of qubits that
O
acts nontrivially on.

Definition 5

(geometrically local with range
R
)
.

Let
O
be an arbitrary observable in a finite
d
-dimensional space and let
\mathsf{dom}(O)\subseteq\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}^{d}
be its domain. Moreover, let
\mathsf{dom}(O)_{k}=\pi_{k}(\mathsf{dom}(O))\subseteq\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}
, where
\pi_{k}:\mathbb{Z}^{d}\to\mathbb{Z}
is the projection map onto the
k
th coordinate.
Let
R_{O,k}\triangleq\max(\mathsf{dom}(O)_{k})-\min(\mathsf{dom}(O)_{k})
.
The observable
O
is
geometrically local with range
R
if
R_{O,k}\leq R_{k}
, for all
k=1,\dots,d
and

R\triangleq\prod_{k=1}^{d}R_{k}.

(B.1)

In cases when the range
R=\mathcal{O}(1)
is unimportant, we simply say that
O
is
geometrically local
.

We can now properly state the norm inequality relating the Pauli-1 norm to the spectral norm.

Theorem 4

(Detailed restatement of Theorem
2
)
.

Given an observable
O=\sum_{P}\alpha_{P}P
that can be written as a sum of geometrically local observables with range
R
in a finite
d
-dimensional space, we have

\sum_{P}|\alpha_{P}|\leq 2^{d}R\cdot 4^{R}\norm{O}_{\infty}.

(B.2)

If we additionally require that
\norm{O}_{\infty}=\mathcal{O}(1)
, we have the following corollary.

Corollary 4
.

Given an observable
O=\sum_{P}\alpha_{P}P
with
\norm{O}_{\infty}=\mathcal{O}(1)
that can be written as a sum of geometrically local observables in a finite
d
-dimensional space with
R=\mathcal{O}(1)
, we have
\sum_{P}|\alpha_{P}|=\mathcal{O}(1).

In order to establish the above norm inequality, we consider an explicit algorithm for constructing a state
\rho
satisfying
\sum_{Q}\left|\alpha_{Q}\right|\leq C\Tr(O \rho)
.
In this way, bounding
\Tr(O\rho)
above by
\norm{O}_{\infty}
gives the desired inequality.
We briefly discuss the idea of the algorithm.
First, we consider the set of all geometrically local blocks over the
n
qubits.
Then, we consider all Pauli observables
Q
with nonzero
\alpha_{Q}
and the qubits that
Q
acts on.
For each block, if the qubits that
Q
acts on are all inside that block, we put
Q
inside of this block.
If there are multiple such blocks, we choose an arbitrary one to put
Q
in so that each Pauli observable
Q
is in exactly one block.
After that, we separate all blocks into a few disjoint layers of blocks.
Each layer contains many blocks that are sufficiently far from one another, and each block contains some Pauli observables.
We select the layer that has the largest
\sum_{Q}|\alpha_{Q}|
, where this sum is over all Pauli observables inside that layer.
To construct the state
\rho
, we let
\rho
be the maximally mixed state on qubits outside of the selected layer.
For each block in the selected layer, we choose
\rho
to be a state that maximizes the sum of the Pauli terms in the block.
With a careful analysis, the constructed state
\rho
satisfies the desired norm inequality.

B.1
Facts and lemmas

Before proving Theorem
4
, we give a few definitions, facts and lemmas.

Definition 6

(geometrically local Pauli observables)
.

Throughout the appendix, we consider
S^{(\mathrm{geo})}
to be the set of all geometrically local Pauli observables with a constant range
R=\mathcal{O}(1)
.

The following fact can be easily shown by considering the Pauli decomposition of each geometrically local observable in the sum.

Fact 1
.

Any observable
O
that can be written as a sum of geometrically local observables can also be written as a sum of geometrically local Pauli observables. Thus, we can write
O=\sum_{P}\alpha_{P}P
, where
\alpha_{P}=0
for all
P\notin S^{(\mathrm{geo})}
.

A construction of the mixed state that we are going to use throughout the proof is the following.
The key idea is that
|\Tr(P_i \rho)|=1/k
for
i=1,\ldots,k
, and
|\Tr(P \rho)|=0
for any
P\in\{I,X,Y,Z\}^{\otimes n}\setminus\{I,P_{1},\ldots,P_{k}\}
.

Lemma 13
.

Let
P_{1},\dots,P_{k}\in\{I,X,Y,Z\}^{\otimes n}
. Suppose that
P_{i}\neq I^{\otimes n}
for all
i=1,\dots,k
. Then

\rho=\frac{I+\frac{\pm P_{1}\pm\cdots\pm P_{k}}{k}}{2^{n}}

(B.3)

is a mixed state, i.e., it is positive semidefinite and has unit trace.

Proof.

First, we can easily show that
\rho
has unit trace. Let
P_{i}=\bigotimes_{j=1}^{n}P_{i,j}
for all
i=1,\dots,k
, where
P_{i,j}\in\{I,X,Y,Z\}
. Then, we have

\displaystyle\Tr(\rho)

\displaystyle=\frac{1}{2^{n}}\left(\Tr(I)\pm\frac{1}{k}(\Tr(P_1)\pm\cdots\pm\Tr(P_k))\right)

(B.4a)

\displaystyle=\frac{1}{2^{n}}\left(2^{n}\pm\frac{1}{k}\left(\prod_{j=1}^{n}\Tr(P_{1,j})\pm\cdots\pm\prod_{j=1}^{n}\Tr(P_{k,j})\right)\right)

(B.4b)

\displaystyle=1,

(B.4c)

where the last equality follows because the trace of a nonidentity Pauli matrix is
0
, and we assume that
P_{i}\neq I^{\otimes n}
so that the
P_{i,j}
are not all identity.
To show that
\rho
is positive semidefinite, it suffices to prove that the eigenvalues of
(\pm P_{1}\pm\cdots\pm P_{k})/k
are between
-1
and
1
.
Then, when this is summed with the identity matrix which has eigenvalue
+1
, the eigenvalues are nonnegative. We see this using the spectral norm

\norm{\frac{\pm P_1 \pm\cdots\pm P_k}{k}}_{\infty}\leq\frac{1}{k}\left(\norm{P_1}_{\infty}+\cdots+\norm{P_k}_{\infty}\right)=1,

(B.5)

which concludes our proof.
∎

Now, we want to define an operation that is useful throughout the proof.

Definition 7

(Restriction of a Pauli operator)
.

Let
P\in\{I,X,Y,Z\}^{\otimes n}
. Write
P=\bigotimes_{\ell\in\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}^{d}}P_{\ell}
for
P_{\ell}\in\{I,X,Y,Z\}
. Let
S\subseteq\{1,\dots,\lfloor\sqrt[d]{n}\rfloor\}^{d}
be a subset of qubits. The
restriction of
P
to the subset of qubits
S
is the substring of Paulis that act on
S
:

\mathsf{restrict}(P;S)\triangleq P_{S}\triangleq\bigotimes_{\ell\in S}P_{\ell}.

(B.6)

In Definition
7
, the subscript notation is used to be consistent with the more standard notation of
P_{k}
to denote a Pauli acting on qubit
k
.

B.2
Proof of Theorem
4

The key idea is to upper bound
\sum_{P}|\alpha_{P}|
by a constant times
\Tr(O\rho)
for some test state
\rho
.
We construct such a
\rho
with a similar form to that seen in Lemma
13
.
Then, because
\rho
is positive semidefinite and has unit trace by Lemma
13
,
\Tr(O\rho)\leq\norm{O}_{\infty}
.
Putting everything together, we have

\sum_{P}|\alpha_{P}|\leq 2^{d}R\cdot 4^{R}\Tr(O\rho)\leq 2^{d}R\cdot 4^{R}\norm{O}_{\infty},

(B.7)

as required.
Thus, it suffices to consider this intermediate step of finding a quantum state
\rho
such that

.
To this end, we consider dividing our space of all Pauli observables into different sets and focus on one set, which educates our choice of
\rho
.

Consider some Pauli observable
P\in S^{(\mathrm{geo})}
, where
S^{(\mathrm{geo})}
is the set of all geometrically local Pauli observables.
Since
P
is geometrically local, by Definition
5
, there exist constants

for

We want to divide our

These blocks of qubits are

\vec{i}=(i_{1},\dots,i_{d})

Denote the buffer as

.

Moreover, we are considering possible shifts of these blocks by

qubits in each of the dimensions.
Notice that there are only

possible shifts in each dimension until the blocks align with the original positioning of another block.
Consider the related set consisting of the Pauli terms that act only on qubits in a given block

, or

(B.12)

We want to pick the set

\sum_{P\in U_{\vec{j}^{*}}}|\alpha_{P}|\geq\frac{1}{2^{d}R}\sum_{P}|\alpha_{P}|,

(B.14)

(B.15)

(B.16)

.
Explicitly, we define
\rho
as

\rho\triangleq\bigotimes_{\vec{i}}\left(\frac{1}{2^{R}}\left(I_{B_{(\vec{i},\vec{j}^{*})}}+\frac{1}{|S_{(\vec{i},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}Q_{B_{(\vec{i},\vec{j}^{*})}}\right)\right)\bigotimes_{\ell\in B^{\prime}_{\vec{j}^{*}}}\frac{I_{\ell}}{2}\triangleq\bigotimes_{\vec{i}}\rho_{\vec{i}}\bigotimes_{\ell\in B_{\vec{j}^{*}}^{\prime}}\frac{I_{\ell}}{2},

(B.17)

where
\delta_{\{\alpha_{Q}<0\}}
is
1
when
\alpha_{Q}<0
and
0
otherwise.
Also, the tensor product is again over all possible vectors
\vec{i}
such that each entry
i_{k}
ranges from
1
to
\lfloor\frac{\lfloor\sqrt[d]{n}\rfloor-j_{k}+R_{k}}{2R_{k}}\rfloor
.
Here, we are using the notation from Definition
7
to denote quantum operations restricted to their action on a given set of qubits.
By Lemma
13
,
\rho_{\vec{i}}
is a proper quantum state that is positive semidefinite and has unit trace; hence
\rho
is a quantum state.
Now, we want to calculate
\Tr(O\rho)
. Recall that
O=\sum_{P}\alpha_{P}P
.
Taking the trace, we have

\Tr(O\rho)=\sum_{P}\alpha_{P}\Tr(P\rho).

(B.18)

There are four cases that can occur regarding
\mathsf{dom}(P)
.

1.

P
acts nontrivially on some qubits in the buffer region, i.e.,
\mathsf{dom}(P)\subseteq B_{(\vec{i}_{P},\vec{j}^{*})}\cup B^{\prime}_{\vec{j}^{*}}
for some
\vec{i}_{P}
.

2.

P
acts trivially on all qubits in the buffer region, but
P
acts nontrivially on qubits in two or more blocks, i.e.,
\mathsf{dom}(P)\subseteq B_{(\vec{i}_{P,1},\vec{j}^{*})}\cup B_{(\vec{i}_{P,2},\vec{j}^{*})}
for some
\vec{i}_{P,1},\vec{i}_{P,2}
.

3.

P
acts nontrivially only on qubits in a single block but
P
is not in the set
U_{\vec{j}^{*}}
, i.e.,
\mathsf{dom}(P)\subseteq B_{(\vec{i}_{P},\vec{j}^{*})}
for some
\vec{i}_{P}
, but
P\notin S_{(\vec{i}_{P},\vec{j}^{*})}
.

4.

P
acts nontrivially only on qubits in a single block and
P
is in the set
U_{j^{*}}
, i.e.,
\mathsf{dom}(P)\subseteq B_{(\vec{i}_{P},\vec{j}^{*})}
for some
\vec{i}_{P}
and
P\in S_{(\vec{i}_{P},\vec{j}^{*})}
.

We compute
\Tr(P \rho)
for each of these cases.
We note that
\Tr(\rho_{\vec{i}})=1
in all these calculations.

For Case
1
, it suffices to consider the case where
P
acts on only one qubit in the buffer region, i.e. there exists a qubit
\ell^{*}\in B^{\prime}_{\vec{j}^{*}}
such that
\ell^{*}\in\mathsf{dom}(P)
and
\mathsf{dom}(P)\setminus\{\ell^{*}\}\subseteq B_{(\vec{i}_{P},\vec{j}^{*})}
.
Then, the state
P\rho
is as follows

\displaystyle P\rho

\displaystyle=\left(\bigotimes_{\vec{i}\neq\vec{i}_{P}}\rho_{\vec{i}}\bigotimes_{\begin{subarray}{c}\ell\in B_{\vec{j}^{*}}^{\prime}\\
\ell\neq\ell^{*}\end{subarray}}\frac{I_{\ell}}{2}\right)

(B.19a)

\displaystyle\otimes\left(\frac{1}{2^{R}}\left(P_{B_{(\vec{i}_{P},\vec{j}^{*})}}+\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i}_{P},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}P_{B_{(\vec{i}_{P},\vec{j}^{*})}}Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}\right)\otimes\frac{P_{\ell^{*}}}{2}\right),

(B.19b)

where we are again using the notation from Definition
7
.
Taking the trace of this state, since the trace of
I/2
is
1
, we have

\displaystyle\Tr(P\rho)

\displaystyle=\frac{\Tr\left(\frac{P_{\ell^{*}}}{2}\right)}{2^{R}}\Biggr(\Tr(P_{(B_{(\vec{i}_P, \vec{j}^*)})})

(B.20a)

\displaystyle+\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i}_{P},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}} Q_{B_{(\vec{i}_P, \vec{j}^*)}})\Biggr)

(B.20b)

\displaystyle=0,

(B.20c)

where the last equality follows because the trace of a nonidentity Pauli string is
0
and

\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}}Q_{B_{(\vec{i}_P, \vec{j}^*)}})=2^{R}\delta_{\{P_{B_{(\vec{i}_{P},\vec{j}^{*})}}=Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}\}}.

(B.21)

Here,
P_{B_{(\vec{i}_{P},\vec{j}^{*})}}\neq Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}
because
Q\in S_{(\vec{i}_{P},\vec{j}^{*})}
so that
Q
acts nontrivially only on qubits in
B_{(\vec{i}_{P},\vec{j}^{*})}
while
P
acts nontrivially on
\ell^{*}\notin B_{(\vec{i}_{P},\vec{j}^{*})}
.
Thus, Case
1
contributes
0
to
\Tr(O\rho)
.

Next, we consider Case
2
.
In Case
2
, we consider what happens if
P
acts nontrivially on qubits in more than one block, i.e.,
\mathsf{dom}(P)\subseteq B_{(\vec{i}_{P,1},\vec{j}^{*})}\cup B_{(\vec{i}_{P,2},\vec{j}^{*})}
.
However, this case is in fact not possible by construction because the buffer region between
B_{(\vec{i}_{P,1},\vec{j}^{*})}
and
B_{(\vec{i}_{P,2},\vec{j}^{*})}
is of size
R_{k}
in each of the dimensions.
Recall that
R_{k}
is the largest distance between two qubits that any
P
acts on in the
k
th dimension.
Thus, it is not possible for
P
to span across the buffer region, so this case cannot occur. Hence, it trivially contributes
0
to
\Tr(O\rho)
.

Now, we consider Case
3
.
From the previous two cases, we see that
P
can only act nontrivially on qubits in a single block
B_{(\vec{i}_{P},\vec{j}^{*})}
to contribute to
\Tr(O\rho)
.
However, by construction of the sets
S_{(\vec{i},\vec{j})}
, in order to make them disjoint, it is possible that
P\notin S_{(\vec{i}_{P},\vec{j}^{*})}
despite it acting on the correct block of qubits.
We show that this also contributes
0
to
\Tr(O\rho)
.
Taking the trace, we have

\Tr(P \rho)=\frac{1}{2^{R}}\left(\Tr(P_{(B_{(\vec{i}_P, \vec{j}^*)})})+\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i}_{P},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}} Q_{B_{(\vec{i}_P, \vec{j}^*)}})\right)=0,

(B.22)

where the last equality follows because the trace of a nonidentity Pauli string is
0
and

\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}}Q_{B_{(\vec{i}_P, \vec{j}^*)}})=2^{R}\delta_{\{P_{B_{(\vec{i}_{P},\vec{j}^{*})}}=Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}\}}.

(B.23)

Here,
P_{B_{(\vec{i}_{P},\vec{j}^{*})}}\neq Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}
because
Q\in S_{(\vec{i}_{P},\vec{j}^{*})}
while we know from this case that
P\notin S_{(\vec{i}_{P},\vec{j}^{*})}
.

Finally, we consider Case
4
.
From the previous cases, we see that the only remaining possibility is that
P
acts nontrivially on qubits in a single block
B_{(\vec{i}_{P},\vec{j}^{*})}
and is also contained in a set
S_{(\vec{i}_{P},\vec{j}^{*})}
.
Computing the trace, we have

\displaystyle\Tr(P\rho)

\displaystyle=\frac{1}{2^{R}}\left(\Tr(P_{(B_{(\vec{i}_P, \vec{j}^*)})})+\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i}_{P},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}} Q_{B_{(\vec{i}_P, \vec{j}^*)}})\right)

(B.24a)

\displaystyle=\frac{1}{2^{R}}\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}\sum_{Q\in S_{(\vec{i}_{P},\vec{j}^{*})}}(-1)^{\delta_{\{\alpha_{Q}<0\}}}\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}} Q_{B_{(\vec{i}_P, \vec{j}^*)}})

(B.24b)

\displaystyle=\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}(-1)^{\delta_{\{\alpha_{P}<0\}}}.

(B.24c)

Here, we are using that the trace of a nonidentity Pauli string is
0
and
\Tr(P_{B_{(\vec{i}_P, \vec{j}^*)}}Q_{B_{(\vec{i}_P, \vec{j}^*)}})=2^{R}\delta_{\{P_{B_{(\vec{i}_{P},\vec{j}^{*})}}=Q_{B_{(\vec{i}_{P},\vec{j}^{*})}}\}}
.
Because
P\in S_{(\vec{i}_{P},\vec{j}^{*})}
, there exists a
Q\in S_{(\vec{i}_{P},\vec{j}^{*})}
such that
P=Q
so that the sum over
S_{(\vec{i}_{P},\vec{j}^{*})}
then collapses to this
P
.
Thus, for this case,
P
contributes a nonzero amount to
\Tr(O \rho)
.
Summing over all
P\in U_{\vec{j}^{*}}
, we have a total contribution of

\sum_{P\in U_{\vec{j}^{*}}}\alpha_{P}\Tr(P\rho)=\sum_{P\in U_{\vec{j}^{*}}}\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}(-1)^{\delta_{\{\alpha_{P}<0\}}}\alpha_{P}=\sum_{P\in U_{\vec{j}^{*}}}\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}|\alpha_{P}|.

(B.25)

Thus, putting everything together, only Case
4
contributed a nonzero amount to
\Tr(O\rho)
, so we have

\Tr(O \rho)=\sum_{P\in U_{\vec{j}^{*}}}\frac{1}{|S_{(\vec{i}_{P},\vec{j}^{*})}|}|\alpha_{P}|.

(B.26)

Here, we know that

|S_{(\vec{i}_{P},\vec{j}^{*})}|\leq 4^{R}

(B.27)

because
|B_{(\vec{i}_{P},\vec{j}^{*})}|=R
and on
R=\prod_{k}R_{k}
qubits, there are
4^{R}
possible Pauli terms (i.e.,
I,X,Y,Z
on each of the qubits). Then, we have

\Tr(O\rho)\geq\frac{1}{4^{R}}\sum_{P\in U_{\vec{j}^{*}}}|\alpha_{P}|.

(B.28)

As explained previously, this suffices to conclude the proof.∎

\displaystyle\leq\sum_{P_{1},P_{2}\in S^{(\mathrm{geo})}}|\alpha_{P_{1}}||\alpha_{P_{2}}|\mathop{{\mathbb{E}}}\displaylimits_{x\sim\mathcal{D}}|h^{*}_{P_{1}}(x)-\Tr(P_1 \rho(x))||h^{*}_{P_{2}}(x)-\Tr(P_2 \rho(x))|

(C.22)

\displaystyle\leq\sum_{P_{1},P_{2}\in S^{(\mathrm{geo})}}|\alpha_{P_{1}}||\alpha_{P_{2}}|\sqrt{\mathop{{\mathbb{E}}}\displaylimits_{x\sim\mathcal{D}}|h^{*}_{P_{1}}(x)-\Tr(P_1 \rho(x))|^{2}}\sqrt{\mathop{{\mathbb{E}}}\displaylimits_{x\sim\mathcal{D}}|h^{*}_{P_{2}}(x)-\Tr(P_2 \rho(x))|^{2}}

(C.23)

\displaystyle\leq\left(\sum_{P\in S^{(\mathrm{geo})}}|\alpha_{P}|\right)^{2}\frac{1}{C^{2}}\left[(\epsilon_{1}+\epsilon_{2})^{2}+\epsilon_{3}\right]\leq(\epsilon_{1}+\epsilon_{2})^{2}+\epsilon_{3}.

(C.24)

This concludes the proof of the corollary.
∎

C.3
\ell_{1}
-Norm bound on coefficients of linear hypothesis

We now justify our choice of the hyperparameter
B>0
such that
\norm{\mathbf{w}}_{1}\leq B
.
From Appendix
A
, we constructed a function that approximates the ground state property. Explicitly, this function is defined as

g(x)\triangleq\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}f_{P}(x^{\prime})\mathds{1}[x\in T_{x^{\prime},P}]=\mathbf{w}^{\prime}\cdot\phi(x),

(C.25)

where in this case, the vector of coefficients
\mathbf{w}^{\prime}
, indexed by
x^{\prime}\in X_{P},P\in S^{(\mathrm{geo})}
, is defined as

\mathbf{w}^{\prime}_{x^{\prime},P}\triangleq f_{P}(x^{\prime}).

(C.26)

Thus, we see that the ML model, which learns functions of this form, has the capacity to approximate the target ground state property
\Tr(O\rho(x))
.
The actual function we learn,
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x)
could differ significantly from
g(x)=\mathbf{w}^{\prime}\cdot\phi(x)
because
\mathbf{w}^{\prime}
is unknown.
Nevertheless, we can utilize an upper bound
\norm{\mathbf{w}'}_{1}\leq B
to restrict the hypothesis set of the ML algorithm to functions of the form
h(x)=\mathbf{w}\cdot\phi(x)
such that
\norm{\mathbf{w}}_{1}\leq B
.
Thus, we find an upper bound on
\norm{\mathbf{w}'}_{1}
in the following lemma.

Lemma 14

(
\ell_{1}
-Norm bound)
.

Let
\mathbf{w}^{\prime}
be the vector of coefficients defined in Eq. (
C.26
). Then, we have the following bound on
\norm{\mathbf{w}'}_{1}
:

\norm{\mathbf{w}'}_{1}=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}|f_{P}(x^{\prime})|=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}.

(C.27)

Proof.

First, we can analyze the
|f_{P}(x^{\prime})|
term. Recall that
f_{P}
is just
\alpha_{P}\Tr(P\rho(\chi_P(x)))
, where
\chi_{P}(x)\in[-1,1]^{m}
sets parameters outside of
I_{P}
to
0
. Thus, we can bound its absolute value by

|f_{P}(x)|=|\alpha_{P}||\Tr(P\rho(\chi_P(x)))|\leq|\alpha_{P}|.

(C.28)

Plugging this into the
\ell_{1}
-norm of
\mathbf{w}^{\prime}
, we have

\displaystyle\norm{\mathbf{w}'}_{1}

\displaystyle=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}|f_{P}(x^{\prime})|

(C.29a)

\displaystyle\leq\sum_{P\in S^{\mathrm{(geo)}}}|X_{P}||f_{P}(x^{\prime})|

(C.29b)

\displaystyle\leq\max_{P\in S^{\mathrm{(geo)}}}|X_{P}|\sum_{Q\in S^{(\mathrm{geo})}}|\alpha_{Q}|.

(C.29c)

Thus, it suffices to count the number of elements in
X_{P}
.
Recall in Definition
3
that
X_{P}
is defined such that the parameter values for
c^{\prime}\notin I_{P}
are fixed to
0
while for
c^{\prime}\in I_{P}
,
x_{c^{\prime}}
can be any value in
\{0,\pm\delta_{2},\pm 2\delta_{2},\dots,\pm 1\}
.
Hence, it is clear that

|X_{P}|\leq\left|\left\{0,\pm\delta_{2},\pm 2\delta_{2},\dots,\pm 1\right\}\right|^{|I_{P}|}\leq\left(\frac{2}{\delta_{2}}+1\right)^{|I_{P}|}.

(C.30)

Moreover, by our choice of
\delta_{2}
in Eq. (
C.3
), we have

|X_{P}|\leq\left(2\left\lceil\frac{2\sqrt{C^{\prime}|I_{P}|}}{\epsilon_{1}}\right\rceil+1\right)^{|I_{P}|}.

(C.31)

Now, it remains to bound the size of
I_{P}
, defined in Eq. (
II.1
).
This size is simply the number of parameters that
h_{j}
depends on for some
h_{j}
with
d_{\mathrm{obs}}(h_{j},P)\leq\delta_{1}
.
By Eq. (
A.5
), we can bound the number of such
h_{j}
:

\sum_{j:d_{\mathrm{obs}}(h_{j},P)\leq\delta_{1}}1\leq b_{d}+c_{d}\delta_{1}^{d}.

(C.32)

Moreover, we assume that each
h_{j}
depends on
\mathcal{O}(1)
parameters. Suppose that each
h_{j}
depends on at most
q
parameters. Then, we can bound the size of
I_{P}
by

|I_{P}|\leq q(b_{d}+c_{d}\delta_{1}^{d}).

(C.33)

Utilizing this bound in Eq. (
C.31
), we obtain

|X_{P}|\leq\left(2\left\lceil\frac{2\sqrt{C^{\prime}q(b_{d}+c_{d}\delta_{1}^{d})}}{\epsilon_{1}}\right\rceil+1\right)^{q(b_{d}+c_{d}\delta_{1}^{d})}.

(C.34)

Plugging this into our
\ell_{1}
-norm bound from Eq. (
C.29c
), we have

\displaystyle\norm{\mathbf{w}'}_{1}

\displaystyle=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}|f_{P}(x^{\prime})|

(C.35a)

\displaystyle\leq\left(2\left\lceil\frac{2\sqrt{C^{\prime}q(b_{d}+c_{d}\delta_{1}^{d})}}{\epsilon_{1}}\right\rceil+1\right)^{q(b_{d}+c_{d}\delta_{1}^{d})}\sum_{Q\in S^{\mathrm{(geo)}}}|\alpha_{Q}|

(C.35b)

\displaystyle\leq D\left(2\left\lceil\frac{2\sqrt{C^{\prime}q(b_{d}+c_{d}\delta_{1}^{d})}}{\epsilon_{1}}\right\rceil+1\right)^{q(b_{d}+c_{d}\delta_{1}^{d})},

(C.35c)

where the second inequality follows from Corollary
4
, taking
D
as this constant. We can simplify this expression further by using that
\delta_{1}=C_{\mathrm{max}}\log^{2}(2C/\epsilon_{1})
for sufficiently small
\epsilon_{1}
according to Eq. (
C.1
).

\displaystyle\norm{\mathbf{w}'}_{1}

\displaystyle=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}|f_{P}(x^{\prime})|

(C.36a)

\displaystyle\leq D\left(2\left\lceil\frac{2\sqrt{C^{\prime}q(b_{d}+c_{d}(C_{\mathrm{max}}\log^{2}(2C/\epsilon_{1}))^{d})}}{\epsilon_{1}}\right\rceil+1\right)^{q(b_{d}+c_{d}(C_{\mathrm{max}}\log^{2}(2C/\epsilon_{1}))^{d})}

(C.36b)

\displaystyle=\left(\frac{\log^{2d}(1/\epsilon_{1})}{\epsilon_{1}}\right)^{\mathcal{O}(\log^{2d}(1/\epsilon_{1}))}

(C.36c)

\displaystyle=\left(\frac{1}{\epsilon_{1}}\right)^{\mathcal{O}(\log^{2d}(1/\epsilon_{1}))}\left(\log^{2d}(1/\epsilon_{1})\right)^{\mathcal{O}(\log^{2d}(1/\epsilon_{1}))}

(C.36d)

\displaystyle=2^{\mathcal{O}(\log^{2d+1}(1/\epsilon_{1}))}

(C.36e)

\displaystyle=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))},

(C.36f)

which is the promised scaling.
∎

C.4
Training error bound

Using the results in Appendix
A.3
, we can derive a bound on the training error of
g(x)=\mathbf{w}^{\prime}\cdot\phi(x)
discussed in the previous section.
The existence of
\mathbf{w}^{\prime}
then guarantees that the function
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x)
found by performing optimization to minimize training error will also yield a training error close to zero.
To prove this rigorously, we first write a precise definition of training error.

Definition 8

(Training error)
.

Given a function
h(x)
and a training dataset
\{(x_{\ell},y_{\ell})\}_{\ell=1}^{N}
. The
training error
is defined as

\hat{R}(h)=\min_{\mathbf{w}}\frac{1}{N}\sum_{\ell=1}^{N}|h(x_{\ell})-y_{\ell}|^{2}.

(C.37)

We can bound the training error in the following lemma.

Lemma 15

(Detailed restatement of Lemma
1
)
.

The function

g(x)=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}f_{P}(x^{\prime})\mathds{1}[x\in T_{x^{\prime},P}]=\mathbf{w}^{\prime}\cdot\phi(x),

(C.38)

achieves training error

\hat{R}(g)\leq(\epsilon_{1}+\epsilon_{2})^{2},

(C.39)

where the training error is defined in Definition
8
.

Proof.

This lemma follows directly from Theorem
3
. Let
\ell^{*}
be defined as

\ell^{*}=\mathop{\mathrm{argmax}}_{1\leq\ell\leq N}|g(x_{\ell})-y_{\ell}|^{2}.

(C.40)

Then, the training error can be bounded above by

\hat{R}(g)\leq|g(x_{\ell^{*}})-y_{\ell^{*}}|^{2}\leq\left(|g(x_{\ell^{*}})-\Tr(O\rho(x_{\ell^*}))|+|\Tr(O\rho(x_{\ell^*}))-y_{\ell^{*}}|\right)^{2},

(C.41)

where the last inequality follows by triangle inequality. Here, the second term can be bounded by
\epsilon_{2}
using definition of our training labels
y_{\ell}
. For the first term, let
D
be a constant such that

\sum_{P\in S^{\mathrm{(geo)}}}|\alpha_{P}|\leq D,

(C.42)

using Corollary
4
. Then, by Theorem
3
, we have

|g(x_{\ell^{*}})-\Tr(O\rho(x_{\ell^*}))|\leq\epsilon_{1}+\epsilon_{2}.

(C.43)

Putting everything together, we have

\hat{R}(g)\leq(\epsilon_{1}+\epsilon_{2})^{2},

(C.44)

which is the claimed result.
∎

Now consider the function
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x)
, where
\mathbf{w}^{*}
is obtained by minimizing the training error, such that the training error is larger than the minimum training error by at most
\epsilon_{3}/2
.
We can achieve this using an optimization algorithm described in Appendix
C.6
.
Formally, we have the following inequality,

\hat{R}(h^{*})\leq\frac{\epsilon_{3}}{2}+\min_{\begin{subarray}{c}\mathbf{w}\in\mathbb{R}^{m_{\phi}}\\
\norm{\mathbf{w}}_{1}\leq B\end{subarray}}\,\frac{1}{N}\sum_{\ell=1}^{N}\left|\mathbf{w}\cdot\phi(x_{\ell})-\Tr(O \rho(x_\ell))\right|^{2}.

(C.45)

Because we have set
B=2^{\mathrm{polylog}(1/\epsilon_{1})}
,

\norm{\mathbf{w}'}_{1}=\sum_{P\in S^{\mathrm{(geo)}}}\sum_{x^{\prime}\in X_{P}}|f_{P}(x^{\prime})|\leq 2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}=B.

(C.46)

Therefore, the minimum training error must be at most
\hat{R}(g)
,

\min_{\begin{subarray}{c}\mathbf{w}\in\mathbb{R}^{m_{\phi}}\\
\norm{\mathbf{w}}_{1}\leq B\end{subarray}}\,\frac{1}{N}\sum_{\ell=1}^{N}\left|\mathbf{w}\cdot\phi(x_{\ell})-\Tr(O \rho(x_\ell))\right|^{2}\leq\hat{R}(g).

(C.47)

Together, we have

\hat{R}(h^{*})\leq\hat{R}(g)+\frac{\epsilon_{3}}{2}\leq(\epsilon_{1}+\epsilon_{2})^{2}+\frac{\epsilon_{3}}{2}.

(C.48)

The last inequality follows from Lemma
15
.

C.5
Prediction error bound

With this bound on the training error, it remains to find a bound on the prediction error of our hypothesis function. To this end, we can use a standard result from machine learning theory about the prediction error of
\ell_{1}
-norm-constrained linear hypotheses trained using the LASSO algorithm
[
38
,
40
,
39
]
.

Theorem 6

(Theorem 11.16 in
[
40
]
)
.

Let
\mathcal{X}\subseteq\mathbb{R}^{A}
and
\mathcal{H}=\{\mathbf{x}\in\mathcal{X}\mapsto\mathbf{w}\cdot\mathbf{x}:\norm{\mathbf{w}}_{1}\leq B\}
. Let
S=((\mathbf{x}_{1},y_{1}),\dots,(\mathbf{x}_{N},y_{N}))\in(\mathcal{X}\times\mathcal{Y})^{N}
. Let
\mathcal{D}
denote a distribution over
\mathcal{X}\times\mathcal{Y}
according to which the training data
S
is drawn. Assume that there exists
r_{\infty}>0
such that for all
\mathbf{x}\in\mathcal{X}
,
\norm{\mathbf{x}}_{\infty}\leq r_{\infty}
and
M>0
such that
|h(x)-y|\leq M
for all
(x,y)\in\mathcal{X}\times\mathcal{Y}
. Then, for any
\delta>0
, with probability at least
1-\delta
, each of the following inequalities holds for all
h\in\mathcal{H}
:

\mathop{\mathbb{E}}_{(x,y)\sim\mathcal{D}}|h(x)-y|^{2}\triangleq R(h)\leq\hat{R}_{S}(h)+2r_{\infty}BM\sqrt{\frac{2\log(2A)}{N}}+M^{2}\sqrt{\frac{\log\frac{1}{\delta}}{2N}}

(C.49)

where
R(h)
is the prediction error for the hypothesis
h
and
\hat{R}_{S}(h)
is the training error of
h
on the training data
S
.

We can use this theorem to prove the prediction error bound in Theorem
5
.

Proof of prediction error in Theorem
5
.

We utilize Theorem
6
as well as our established lemmas.

First, we demonstrate that we satisfy the conditions of the theorem in our setting.
Here, we view
h
in Theorem
6
as a function of the higher-dimensional feature vector
\phi(x)
rather than the
m
-dimensional vector
x\in[-1,1]^{m}
so that
h
is a linear hypothesis.
In this perspective, our input space
\mathcal{X}
is the feature space
\{0,1\}^{m_{\phi}}\subseteq\mathbb{R}^{m_{\phi}}
, as the indicator functions we are evaluating only take
0
-
1
values.
In our case, the dimension
A
is given by

A=m_{\phi}\triangleq\sum_{P\in S^{\mathrm{(geo)}}}|X_{P}|.

(C.50)

Moreover, the training data we are given is
S=((\phi(x_{1}),y_{1}),\dots,(\phi(x_{N}),y_{N}))\in(\mathcal{X}\times\mathcal{Y})^{N}
, where
y_{\ell}
is such that

|y_{\ell}-\Tr(O\rho(x_\ell))|\leq\epsilon_{2}.

(C.51)

Again, we are thinking of
h
as a function that takes the input
\phi(x)
.
Furthermore, since
\phi(x_{\ell})\in\{0,1\}^{m_{\phi}}
for all
\ell=1,\dots,N
, we can see that
\norm{\phi(x_\ell)}_{\infty}\leq 1=r_{\infty}
.
Moreover, the hypothesis class
\mathcal{H}
is given by the set of the functions of the same form as
h
, i.e.,
\mathcal{H}=\{\phi(x)\in\mathcal{X}\mapsto\mathbf{w}\cdot\phi(x):\norm{\mathbf{w}}_{1}\leq B\}
with
B=2^{\mathrm{polylog}(1/\epsilon)}
.
By considering
M=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}
, we also have
|h(x_{\ell})-y_{\ell}|\leq M
for all
\ell=1,\dots,N
because

|h(x_{\ell})-y_{\ell}|\leq|\mathbf{w}\cdot\phi(x_{\ell})|+|y_{\ell}|\leq\norm{\mathbf{w}}_{1}\norm{\phi(x)}_{\infty}+2\leq 2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}+2=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))},

(C.52)

where the second inequality follows by Hölder’s inequality.
Furthermore, by Eq. (
C.48
),
the learned model
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x)
achieves
\hat{R}(h^{*})\leq(\epsilon_{1}+\epsilon_{2})^{2}+(\epsilon_{3}/2)
. Thus, by Theorem
6
,

R(h^{*})\leq(\epsilon_{1}+\epsilon_{2})^{2}+\frac{\epsilon_{3}}{2}+2BM\sqrt{\frac{2\log(2m_\phi)}{N}}+M^{2}\sqrt{\frac{\log{\frac{1}{\delta}}}{2N}}

(C.53)

with probability at least
1-\delta
.
In order to bound the prediction error above by
(\epsilon_{1}+\epsilon_{2})^{2}+\epsilon_{3}
, we need
N
to be large enough such that

2BM\sqrt{\frac{2\log(2m_\phi)}{N}}+M^{2}\sqrt{\frac{\log{\frac{1}{\delta}}}{2N}}\leq\frac{\epsilon_{3}}{2}.

(C.54)

We can upper bound
m_{\phi}
using the same approach as in the proof of Lemma
14
. Explicitly, using Eq. (
C.34
) and Eq. (
C.36
), we have

\displaystyle m_{\phi}

\displaystyle=\sum_{P\in S^{\mathrm{(geo)}}}|X_{P}|\leq\sum_{P\in S^{\mathrm{(geo)}}}\left(2\left\lceil\frac{\sqrt{C^{\prime}q(b_{d}+c_{d}\delta_{1}^{d})}}{\epsilon_{1}}\right\rceil+1\right)^{q(b_{d}+c_{d}\delta_{1}^{d})}

(C.55a)

\displaystyle=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\mathcal{O}(n),

(C.55b)

where the last equality follows because
|S^{(\mathrm{geo})}|=\mathcal{O}(n)
. Plugging everything into the left hand side of Eq. (
C.54
), we have

\displaystyle\hskip 10.0pt2BM\sqrt{\frac{2\log(2m_\phi)}{N}}+M^{2}\sqrt{\frac{\log{\frac{1}{\delta}}}{2N}}

(C.56a)

\displaystyle\leq 2\sqrt{2}\left(2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\right)^{2}\sqrt{\frac{\log\left(2\cdot 2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\mathcal{O}(n)\right)}{N}}

(C.56b)

\displaystyle+\frac{1}{\sqrt{2}}\left(2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\right)^{2}\sqrt{\frac{\log\frac{1}{\delta}}{N}}

(C.56c)

\displaystyle=2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\frac{1}{\sqrt{N}}\left(\sqrt{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))+\mathcal{O}(\log(n))}+\sqrt{\log\frac{1}{\delta}}\right).

(C.56d)

To upper bounded the above by
\frac{\epsilon_{3}}{2}
, we choose

\displaystyle N

\displaystyle=\frac{4}{\epsilon_{3}^{2}}\left(2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\right)^{2}\left(\sqrt{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))+\mathcal{O}(\log(n))}+\sqrt{\log\frac{1}{\delta}}\right)^{2}

(C.57a)

\displaystyle=2^{\mathcal{O}(\log(1/\epsilon_3)+\mathrm{polylog}(1/\epsilon_{1}))}\log(n / \delta).

(C.57b)

Together, the training data size
N
given above guarantees that
R(h^{*})\leq(\epsilon_{1}+\epsilon_{2})^{2}+\epsilon_{3}
with probability at least
1-\delta
.
∎

C.6
Computational time for training and prediction

Finally, we find the computation time required for the ML algorithm’s training and prediction. To this end, we utilize standard results about the training time of the LASSO algorithm
[
51
]
.

Proof of computational time in Theorem
5
.

The training time is dominated by the time required for
\ell_{1}
-regularized regression (LASSO) over the feature space defined by the feature map
\phi
.
It is well-known that to obtain a training error at most
(\epsilon_{3}/2)
larger than the optimal function value, the LASSO algorithm on the feature space can be executed in time
\mathcal{O}\left(\frac{m_{\phi}\log m_{\phi}}{\epsilon_{3}^{2}}\right)

[
51
]
, where
m_{\phi}
is the dimension of the feature space.
By Eq. (
C.55b
), we know that

m_{\phi}=\mathcal{O}(n)2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}

(C.58)

Plugging this into the time required for LASSO, we have

\displaystyle\mathcal{O}\left(\frac{m_{\phi}\log m_{\phi}}{\epsilon_{3}^{2}}\right)

\displaystyle=\mathcal{O}\left(\frac{\mathcal{O}(n)2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_{1}))}\log(\mathcal{O}(n)2^{\mathcal{O}(\mathrm{polylog}(1/\epsilon_1))})}{\epsilon_{3}^{2}}\right)

(C.59a)

\displaystyle=\mathcal{O}(n2^{\mathcal{O}(\log(1/\epsilon_3)+\mathrm{polylog}(1/\epsilon_{1}))}\left(\mathcal{O}(\mathrm{polylog(1/\epsilon_{1})})+\mathcal{O}(\log(n))\right))

(C.59b)

\displaystyle=n\log n\,2^{\mathcal{O}(\log(1 / \epsilon_3)+\mathrm{polylog(1/\epsilon_{1})})}

(C.59c)

\displaystyle=\mathcal{O}(nN),

(C.59d)

where the last equality follows by the definition of the training data size
N
.

The prediction time is the amount of time it takes to compute
h^{*}(x)=\mathbf{w}^{*}\cdot\phi(x_{\ell})
, which takes time
\mathcal{O}(m_{\phi})
. This can also be upper bounded by
\mathcal{O}(nN)
.
∎

Appendix D
Details of numerical experiments

For the numerical experiments, we consider the two-dimensional antiferromagnetic Heisenberg model.
In this setting, spin-
1/2
particles are placed on sites in a 2D lattice.
The Hamiltonian is

H=\sum_{\langle ij\rangle}J_{ij}(X_{i}X_{j}+Y_{i}Y_{j}+Z_{i}Z_{j}),

(D.1)

where the summation ranges over all pairs
\langle ij\rangle
of neighboring sites on the lattice and the couplings
\{J_{ij}\}
are sampled uniformly from the interval
[0,2]
.
Here, the parameter
x
is a list of all couplings
J_{ij}
so that the dimension of the parameter space is
m=O(n)
, where
n
is the system size.
We are interested in predicting ground state properties, which in this case are the two-body correlation functions for each pair of qubits on the lattice. In particular, this correlation function is the expectation value of

C_{ij}=\frac{1}{3}(X_{i}X_{j}+Y_{i}Y_{j}+Z_{i}Z_{j}),

(D.2)

for each pair of qubits
\langle ij\rangle
.

We generated training and testing data for this model using the same method as
[
29
]
.
For completeness, we briefly discuss this here.
For each parameter vector of random couplings sampled uniformly from
[0,2]
, we approximated the ground state using the density-matrix renormalization group (DMRG)
[
60
]
based on matrix product states (MPS)
[
61
]
.
We first consider an initial random MPS with bond dimension
\chi=10
and variationally optimize it using a singular value decomposition cutoff of
10^{-8}
.
We terminate the DMRG runs when the change in energy is less than
10^{-4}
.
After DMRG converges, we perform randomized Pauli measurements by locally rotating into the corresponding Pauli bases and sampling the rotated state
[
81
]
.
In this work, we utilize two different data sets: one which is the same as in
[
29
]
and the other which is generated in the same way but contains more data points.

We consider classical machine learning models given by first performing a feature mapping
\phi
on the input vector
x
and then running
\ell_{1}
-regularized regression (LASSO) over the feature
\phi(x)
space, as described in Appendix
C.1
.
However, while the indicator function feature map was a useful tool to obtain our rigorous guarantees, it is often hard to discretize a high-dimension parameter space into
X_{P}
in practice.
Thus, we instead utilize random Fourier features
[
59
]
.
One can think of this as a single layer of a randomly initialized neural network.
Explicitly, this feature map is

\phi:z\mapsto\begin{pmatrix}\cos\left(\frac{\gamma}{\sqrt{l}}(\omega_{1}\cdot z)\right)\\
\sin\left(\frac{\gamma}{\sqrt{l}}(\omega_{1}\cdot z)\right)\\
\vdots\\
\cos\left(\frac{\gamma}{\sqrt{l}}(\omega_{R}\cdot z)\right)\\
\sin\left(\frac{\gamma}{\sqrt{l}}(\omega_{R}\cdot z)\right)\end{pmatrix},

(D.3)

where
l
is the length of the vector
z
,
\gamma>0
and
R>0
are tunable hyperparameters, and
\omega_{i}
are
l
-dimensional vectors sampled from a multivariate standard normal distribution.
Here, for each vector
z
,
\phi(z)
is a
2R
-dimensional vector.
Thus, the hyperparameter
R
determines the length of the feature vector.
We consider a set of different hyperparameters:

\displaystyle R

\displaystyle\in\{5,10,20,40\},

(D.4)

\displaystyle\gamma

\displaystyle\in\{0.4,0.5,0.6,0.65,0.7,0.75\}.

(D.5)

Using this feature map, the ML algorithm is implemented as follows.
First, we decompose
x
into several vectors corresponding to local regions of a given local term of the Hamiltonian.
This is analogous to the discretization of the parameter space using
X_{P}
.
Explicitly, the decomposition is performed in the following way.
First, recall that in the 2D antiferromagnetic Heisenberg model, qubits are placed on sites in a 2D lattice.
