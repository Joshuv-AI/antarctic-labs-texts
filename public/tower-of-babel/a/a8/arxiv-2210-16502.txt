The solution set of fuzzy relation equations with addition-min composition
Meng Li, Xue-ping Wang School of Mathematical Sciences, Sichuan Normal University, Chengdu 610066, Sichuan, People’s Republic of China

Abstract
This paper deals with the resolutions of fuzzy relation equations with addition-min composition. When the fuzzy relation equations have a solution, we first propose an algorithm to find all minimal solutions of the fuzzy relation equations and also supply an algorithm to find all maximal solutions of the fuzzy relation equations, which will be illustrated, respectively, by numeral examples. Then we prove that every solution of the fuzzy relation equations is between a minimal solution and a maximal one, so that we describe the solution set of the fuzzy relation equations completely.

Introduction

The system of fuzzy relation equations with max-min composition was first studied by E. Sanchez
[
8
]
. The complete solution set of such
finite system is determined by the unique maximal solution and a finite number of minimal solutions
[
2
]
. In recent year, the theory of fuzzy
relation inequalities with addition-min composition has been applied to BitTorrent-like peer-to-peer (P2P) file sharing system widely
[
5
]
. In
such file sharing system, let
A_{1},A_{2},\cdots,A_{n}
be
n
users who are downloading some file datas simultaneously. Suppose that the
jth
user

A_{j}
sends the file data with quality level
x_{j}
to
A_{i}
, and the bandwidth between
A_{i}
and
A_{j}
is
a_{ij}
. Because of the bandwidth limitation,
the network traffic that
A_{i}
receives from
A_{j}
is actually
a_{ij}\wedge x_{j}
, and
A_{i}
receiving the file data from other users is
a_{i1}\wedge x_{1}+\cdots+a_{i{}i-1}\wedge x_{i-1}+a_{i{i+1}}\wedge x_{i+1}+\cdots+a_{in}\wedge x_{n}
. If the quality requirement of download traffic of
A_{i}
is at
least
b_{i}
(
b_{i}>0
), then the data transmission mechanism in the file sharing systems is reduced to the system of fuzzy relation inequations with
addition-min composition as follows:

\left\{\begin{array}[]{ll}a_{11}\wedge x_{1}+a_{12}\wedge x_{2}+\cdots+a_{1n}\wedge x_{n}\geq b_{1},\\
a_{21}\wedge x_{1}+a_{22}\wedge x_{2}+\cdots+a_{2n}\wedge x_{n}\geq b_{2},\\
\cdots\\
a_{m1}\wedge x_{1}+a_{m2}\wedge x_{2}+\cdots+a_{mn}\wedge x_{n}\geq b_{m},\end{array}\right.

(1.1)

where
a_{ij},x_{j}\in[0,1]
,
b_{i}>0

(i=1,2,\ldots,m;j=1,2,\ldots,n)
,
a_{ij}\wedge x_{j}=\min\{a_{ij},x_{j}\}
, and the operation

``+"
is the ordinary addition. The solution set of the system (
1.1
) and the related optimization problems have been
investigated
[
12
,
1
,
3
,
4
,
9
,
10
,
13
,
11
,
6
]
.

In a circumstances of wireless communication, the information is transmitted by the electromagnetic wave. As we know, a high radiation intensity can
ensure a good communication quality, but it will also damage the health of humans. Therefore, in the BitTorrent-like P2P file sharing systems, we are
usually facing that the quality requirement of download traffic of every
A_{i}
is exactly required to equal
b_{i}
(
b_{i}>0
) assigned. Then the file
sharing system (
1.1
) is transformed to fuzzy relation equations with addition-min composition as follows.

\left\{\begin{array}[]{ll}a_{11}\wedge x_{1}+a_{12}\wedge x_{2}+\cdots+a_{1n}\wedge x_{n}=b_{1},\\
a_{21}\wedge x_{1}+a_{22}\wedge x_{2}+\cdots+a_{2n}\wedge x_{n}=b_{2},\\
\cdots\\
a_{m1}\wedge x_{1}+a_{m2}\wedge x_{2}+\cdots+a_{mn}\wedge x_{n}=b_{m}.\end{array}\right.

(1.2)

In
[
10
]
, the system (
1.2
) is called the corresponding equations system of system (
1.1
), and Yang gave an equivalent condition for
a solution of the system (
1.2
) to be a minimal one. This article will focuses on the structure of the solution set of system (
1.2
) by
characterizing all minimal and maximal solutions of system (
1.2
).

The rest of this article is organized as follows. In Section 2, we present some relevant definitions and basic properties. In Section 3, we first give

1.2

) being a maximal solution, and then

1.2
) is between a minimal

1.2
) has a solution, then we describe the solution set of system (
1.2
). A conclusion is drawn in
Section 6.

2
Preliminaries

This section presents some basic definitions and results.

Let
I=\{1,2,\cdots,m\}
and
J=\{1,2,\cdots,n\}
be two index sets. For
x^{1}=(x_{1}^{1},x_{2}^{1},\cdots,x_{n}^{1})
,
x^{2}=(x_{1}^{2},x_{2}^{2},\cdots,x_{n}^{2})\in[0,1]^{n}

{x^{1}}\leq{x^{2}}
if and only if
{x_{j}}^{1}\leq{x_{j}}^{2}

{x^{1}}<{x^{2}}

{x_{j}}^{1}\leq{x_{j}}^{2}

{j_{0}}\in J

. Then system (
1.2
) can be tersely described as

\sum_{j\in J}a_{ij}\wedge x_{j}=b_{i},\forall i\in I

A\odot{x^{T}}={b^{T}},

where
A=(a_{ij})_{m\times n}
,
x=(x_{1},x_{2},\cdots,x_{n})
,
b=(b_{1},b_{2},\cdots,b_{m})
and

(a_{i1},a_{i2},\cdots,a_{in})\odot(x_{1},x_{2},\cdots,x_{n})^{T}=a_{i1}\wedge x_{1}+a_{i2}\wedge x_{2}+\cdots+a_{in}\wedge x_{n}.

System
(
1.2
) is called solvable if there is an
x\in[0,1]^{n}
such that
A\odot{x^{T}}={b^{T}}
. We denote the set of all the solutions of system
(
1.2
) by
\mathscr{X}=\{x\in[0,1]^{n}|A\odot x^{T}=b^{T}\}
, and
A\setminus B=\{x\in A\mid x\notin B\}
where
A
and
B
are two sets.

Definition 2.1
(
[
2
]
)

Let
\mathscr{X}\neq\emptyset
. Then
\hat{x}\in\mathscr{X}
is called a maximal solution of system (
1.2
) if and only if
x\geq\hat{x}
for
any
x\in\mathscr{X}
, implies
x=\hat{x}
, and
\check{x}\in\mathscr{X}
is called a minimal solution of system (
1.2
) if and only if
x\leq\check{x}
for any
x\in\mathscr{X}
, implies
x=\check{x}
.

Denote the set of all minimal solutions of system (
1.2
) by
\check{\mathscr{X}}
and the set of all maximal solutions of system (
1.2
) by

\hat{\mathscr{X}}
. Then the following two propositions are obvious.

Proposition 2.1

Let
x\in\mathscr{X}
. Then we have

(1)

x>0
.

(2)

For any
i\in I
,
j\in J
,
x_{j}\geq b_{i}-\sum\limits_{k\in J\setminus\{j\}}{a_{ik}\wedge x_{k}}\geq b_{i}-\sum\limits_{k\in J\setminus\{j\}}{a_{ik}}
.

(3)

For any
i\in I
,
j\in J
,
a_{ij}\geq b_{i}-\sum\limits_{k\in J\setminus\{j\}}{a_{ik}\wedge x_{k}}\geq b_{i}-\sum\limits_{k\in J\setminus\{j\}}a_{ik}
.

Proposition 2.2

Let
x^{1},x^{2}\in\mathscr{X}
. If
x^{1}\leq x\leq x^{2}
, then
x\in\mathscr{X}
.

3
Minimal solutions of system (
1.2
)

In this section, we first prove a necessary and sufficient condition for a solution of system (
1.2
) being a minimal one if

\mathscr{X}\neq\emptyset
, then we propose an algorithm to determine
\check{\mathscr{X}}
.

The following lemma is an equivalent description of Lemma 14 in
[
10

.

Lemma 3.1

Let
x=(x_{1},x_{2},\cdots,x_{n})\in\mathscr{X}
. Then
x\in\check{\mathscr{X}}
if and only if for any
j\in J
, there is an
i\in I
such that
x_{j}\leq a_{ij}
.

Let
\hat{\alpha}=(\hat{\alpha}_{1},\hat{\alpha}_{2},\cdots,\hat{\alpha}_{n})
with

\hat{\alpha}_{j}=\max\{a_{ij}|i\in I\}.

(3.1)

Then from Lemma
3.1
, we have the following remark.

Remark 3.1

Let
x=(x_{1},x_{2},\cdots,x_{n})\in\mathscr{X}
. Then
x\in\check{\mathscr{X}}
if and only if
x\leq\hat{\alpha}
.

Let
\check{\alpha}=(\check{\alpha}_{1},\check{\alpha}_{2},\cdots,\check{\alpha}_{n})
with

\check{\alpha}_{j}=\max\{0,b_{i}-\sum\limits_{k\in J\setminus\{j\}}a_{ik}|i\in I\}.

(3.2)

Then we have the following proposition.

Proposition 3.1

For any
x=(x_{1},x_{2},\cdots,x_{n})\in\mathscr{X}
, we have
x\geq\check{\alpha}
.

Proof.
Let
x=(x_{1},x_{2},\cdots,x_{n})\in\mathscr{X}
. According to Proposition
2.1
, we have
x_{j}\geq 0
and
x_{j}\geq b_{i}-\sum\limits_{k\in J\setminus\{j\}}{a_{ik}}
for any
i\in I
,
j\in J
, hence,
x_{j}\geq\check{\alpha}_{j}
.

\square

Remark
3.1
and Proposition
3.1
imply the following two remarks.

Remark 3.2

For any
x=(x_{1},x_{2},\cdots,x_{n})\in\check{\mathscr{X}}
, we have
\check{\alpha}\leq x\leq\hat{\alpha}
.

Remark 3.3

If
\check{\alpha}=(\check{\alpha}_{1},\check{\alpha}_{2},\cdots,\check{\alpha}_{n})\in\mathscr{X}
. Then
\check{\alpha}
is the unique minimal solution
of system (
1.2
).

Definition 3.1

For any
j\in J
, denote
|\{a_{ij}|\check{\alpha}_{j}<a_{ij},i\in I\}|=t_{j}
and
Q_{j}=\{q_{0j},q_{1j},q_{2j},\cdots,q_{t_{j}j}\}

\check{\alpha}_{j}=q_{0j}<q_{1j}<q_{2j}<\cdots<q_{t_{j}j}=\hat{\alpha}_{j}

Notice that if

\check{\alpha}_{j}=\hat{\alpha}_{j}
.

Denote

J^{*}=\{j\in J|\check{\alpha}_{j}=\hat{\alpha}_{j}\},

(3.3)

and
K=\{(k_{1},k_{2},\cdots,k_{n})|k_{j}\in K_{j}\mbox{ for any }j\in J\}
with

K_{j}=\left\{\begin{array}[]{ll}\{0\},j\in J^{*},\\
\\
\{k|\check{\alpha}_{j}<q_{kj}\leq\hat{\alpha}_{j}\mbox{ and }q_{kj}\in Q_{j}\},j\in J\setminus J^{*}.\end{array}\right.

(3.4)

Then from Lemma
3.1
, we have the following corollary.

Corollary 3.1

Let
x=(x_{1},x_{2},\cdots,x_{n})\in\mathscr{X}
. Then
x\in\check{\mathscr{X}}
if and only if there exists an
(k_{1},k_{2},\cdots,k_{n})\in K

.

Proof.
Let
x=(x_{1},x_{2},\cdots,x_{n})\in\check{\mathscr{X}}
. By Lemma
3.1
and Remark
3.2
, for any
j\in J
there is an
i\in I
such that

\check{\alpha}_{j}\leq x_{j}\leq a_{ij}\leq\hat{\alpha}_{j}
, which means that
\check{\alpha}_{j}=x_{j}=a_{ij}=\hat{\alpha}_{j}
for any

\check{\alpha}_{j}\leq x_{j}\leq a_{ij}\leq\hat{\alpha}_{j}

. Then

x_{j}\leq q_{{k_{j}}j}
for any

.

Conversely, suppose that there is a

x_{j}\leq q_{k_{j}j}
for any

\square

Let

(k_{1},k_{2},\cdots,k_{n})\in K

\\

\displaystyle=

\displaystyle\sum\limits_{j\in J^{*}}a_{ij}\wedge q_{0j}+\sum\limits_{j\in J\setminus J^{*}}[\delta_{ij}\cdot x_{j}+(1-\delta_{ij})\cdot a_{ij}],

``\cdot"
represents the ordinary multiplication and

\delta_{ij}=\left\{\begin{array}[]{l}1,q_{k_{j}j}\leq a_{ij},\\
0,a_{ij}\leq q_{({k_{j}-1})j}\end{array}\right.

, we have

\displaystyle b_{i}

\displaystyle=

\displaystyle\sum\limits_{j\in J^{*}}a_{ij}\wedge q_{0j}+\sum\limits_{j\in J\setminus J^{*}}[\delta_{ij}\cdot x_{j}+(1-\delta_{ij})\cdot a_{ij}]

\displaystyle=

\displaystyle\sum\limits_{j\in J^{*}}a_{ij}\wedge x_{j}+\sum\limits_{j\in J\setminus J^{*}}\delta_{ij}\cdot x_{j}+\sum\limits_{j\in J\setminus J^{*}}(1-\delta_{ij})\cdot a_{ij}

\displaystyle=

\displaystyle\sum\limits_{j\in J^{*}}a_{ij}\wedge x_{j}+\sum\limits_{j\in J\setminus J^{*},q_{k_{j}j}\leq a_{ij}}x_{j}+\sum\limits_{j\in J\setminus J^{*},a_{ij}\leq q_{({k_{j}-1})j}}a_{ij}

\displaystyle=

Theorem 3.2

For any
(k_{1},k_{2},\cdots,k_{n})\in K
, if

Example 3.1

Consider the following fuzzy relation equations:

,
\check{\alpha}_{2}=0.5

Step 3. For any

\check{\alpha}_{j}\neq\hat{\alpha}_{j}

(1) For

\left\{\begin{array}[]{l}0.3\leq x_{1}\leq 0.4,\\

(2) For

\left\{\begin{array}[]{l}0.3\leq x_{1}\leq 0.4,\\
0.5\leq x_{2}\leq 0.6,\\
0.5\leq x_{3}\leq 0.8,\\

(3) For
k=(2,1,1)

\left\{\begin{array}[]{l}0.4\leq x_{1}\leq 0.7,\\
0.5\leq x_{2}\leq 0.6,\\
0.4\leq x_{3}\leq 0.5,\\

\left\{\begin{array}[]{l}0.4\leq x_{1}\leq 0.7,\\

0.5\leq x_{3}\leq 0.8,\\
