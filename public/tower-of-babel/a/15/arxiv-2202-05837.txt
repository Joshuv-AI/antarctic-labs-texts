The nodal basis of C m C^{m} - P k ( 3 ) P_{k}^{(3)} and C m C^{m} - P k ( 4 ) P_{k}^{(4)} finite elements on tetrahedral and 4D simplicial grids
Shangyou Zhang

Abstract
. We construct the nodal basis of C m C^{m} - P k ( 3 ) P_{k}^{(3)} ( k ≥ 2 3 ​ m + 1 k\geq 2^{3}m+1 ) and C m C^{m} - P k ( 4 ) P_{k}^{(4)} ( k ≥ 2 4 ​ m + 1 k\geq 2^{4}m+1 ) finite elements on 3D tetrahedral and 4D simplicial grids, respectively. C m C^{m} - P k ( n ) P_{k}^{(n)} stands for the space of globally C m C^{m} ( m ≥ 1 m\geq 1 ) and locally piecewise n n -dimensional polynomials of degree k k on n n -dimensional simplicial grids. We prove the uni-solvency and the C m C^{m} continuity of the constructed C m C^{m} - P k ( 3 ) P_{k}^{(3)} and C m C^{m} - P k ( 4 ) P_{k}^{(4)} finite element spaces. A computer code is provided which generates the index set for the nodal basis of C m C^{m} - P k ( n ) P_{k}^{(n)} finite elements on n n -dimensional simplicial grids.
