2.
Elementary Proofs of Several Congruences from Andrews and Paule

In their work
[
2
]
, Andrews and Paule used significant tools based on the work of Smoot, which are derived from modular forms, in order to prove a number of congruences for the functions
d_{2}
and
d_{3}.
In this section, we wish to prove the majority of those results from Andrews and Paule using very elementary tools.

Theorem 2.1

(Corollary 5,
[
2
]
)
.

For all
n\geq 0,

d_{2}(3n+2)\equiv 0\pmod{3}.

Proof.

We have the following:

\displaystyle\sum_{n=0}^{\infty}d_{2}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{2}}{f_{1}^{7}}

\displaystyle=

\displaystyle\frac{f_{2}^{2}}{f_{1}}\frac{1}{f_{1}^{6}}

\displaystyle\equiv

\displaystyle\frac{1}{f_{3}^{2}}\left(\sum_{m\geq 0}q^{m(m+1)/2}\right)\pmod{3}

using Lemma
1.2
.
Now we simply need to determine whether
3n+2=m(m+1)/2
for some
m
and
n.
Completing the square means this is equivalent to determining whether

8(3n+2)+1=(2m+1)^{2}

or

24n+17=(2m+1)^{2}

or

2\equiv(2m+1)^{2}\pmod{3}.

This congruence never holds because 2 is a quadratic nonresidue modulo 3. Our result follows.
∎

Theorem 2.2

(Corollary 10,
[
2
]
)
.

For all
n\geq 0,

d_{3}(2n+1)\equiv 0\pmod{2}.

Proof.

Note that

\displaystyle\sum_{n=0}^{\infty}d_{3}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{3}}{f_{1}^{10}}

\displaystyle\equiv

\displaystyle\frac{f_{2}^{3}}{f_{2}^{5}}\pmod{2}

\displaystyle\equiv

\displaystyle\frac{1}{f_{2}^{2}}\pmod{2}.

Since
\frac{1}{f_{2}^{2}}
is an even function of
q,
the result follows.
∎

Theorem 2.3

(Corollary 12,
[
2
]
)
.

For all
n\geq 0,

d_{3}(4n+2)\equiv 0\pmod{2}.

Proof.

Thanks to the proof of Theorem
2.2
, we know

\displaystyle\sum_{n=0}^{\infty}d_{3}(n)q^{n}

\displaystyle\equiv

\displaystyle\frac{1}{f_{2}^{2}}\pmod{2}

\displaystyle\equiv

\displaystyle\frac{1}{{f_{4}}}\pmod{2}

Since
\frac{1}{{f_{4}}}
is a function of
q^{4},
the result follows.
∎

Theorem 2.4

(Corollary 13,
[
2
]
)
.

For all
n\geq 0,

d_{3}(4n+3)\equiv 0\pmod{4}.

Proof.

Using the generating function for
d_{3}
, we have

\displaystyle\sum_{n=0}^{\infty}d_{3}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{3}}{f_{1}^{10}}=\frac{f_{2}^{4}}{f_{1}^{12}}\frac{f_{1}^{2}}{f_{2}}

\displaystyle\equiv

\displaystyle\frac{f_{2}^{4}}{f_{2}^{6}}\frac{f_{1}^{2}}{f_{2}}\pmod{4}

\displaystyle=

\displaystyle\frac{1}{f_{2}^{2}}\left(\frac{f_{8}^{5}}{f_{4}^{2}f_{16}^{2}}-2q\frac{f_{16}^{2}}{f_{8}}\right)

using (
3
) in Lemma
1.6
above. Extracting the odd parts, dividing by
q
and replacing
q^{2}
by
q

\sum_{n=0}^{\infty}d_{3}(2n+1)q^{n}\equiv 2\frac{f_{8}^{2}}{f_{1}^{2}f_{4}}\equiv 2f_{2}^{5}\pmod{4}.

Since

∎

Theorem 2.5

(Corollary 14,
[
2
]
)
.

For all
n\geq 0,

d_{3}(5n+1)\equiv 0\pmod{5}.

Proof.

Using the generating function for
d_{3}
which we have seen above, we have

\displaystyle\sum_{n=0}^{\infty}d_{3}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{3}}{f_{1}^{10}}

\displaystyle\equiv

\displaystyle\frac{f_{2}^{3}}{f_{5}^{2}}\pmod{5}

\displaystyle=

\displaystyle\frac{1}{f_{5}^{2}}\left(\sum_{m=0}^{\infty}(-1)^{m}(2m+1)q^{m(m+1)}\right)

using Lemma
1.3
above. We now need to ask whether

can be represented as

and this is equivalent to asking whether

or

can be represented as

If this is the case, then we know

Thanks to the presence of the coefficient of

Theorem 2.6

(Corollary 15,
[
2
]
)
.

For all
n\geq 0,

\displaystyle d_{3}(5n+3)

\displaystyle\equiv

\displaystyle 0\pmod{5},

\displaystyle d_{3}(5n+4)

\displaystyle\equiv

\displaystyle 0\pmod{5}.

Proof.

In the proof of Theorem
2.5
, we noted that

\displaystyle\sum_{n=0}^{\infty}d_{3}(n)q^{n}

\displaystyle\equiv

\displaystyle\frac{1}{{f_{5}}^{2}}\left(\sum_{m=0}^{\infty}(-1)^{m}(2m+1)q^{m(m+1)}\right)\pmod{5}.

We now need to ask whether
5n+3
can be represented as
m(m+1),
and this is equivalent to asking whether
4(5n+3)+1
or

can be represented as

This would mean that

However, since 3 is a quadratic nonresidue modulo 5, we know that this cannot be the case. Similarly, note that

and 2 is the other quadratic nonresidue modulo 5. The two congruences which appear in the statement of the theorem follow.
∎

3.
New individual Congruences

In this section, we state and prove a set of new individual congruences. We begin with an extremely unexpected congruence modulo 11 satisfied by the function
d_{2}
(one of the functions which received a great deal of attention in Andrews and Paule
[
2
]
and was the primary focus in Smoot’s recent work
[

]

Theorem 3.1
.

For all
n\geq 0,

d_{2}(11n+7)\equiv 0\pmod{11}.

Proof.

We begin by noting that

\displaystyle\sum_{n=0}^{\infty}d_{2}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{2}}{f_{1}^{7}}

\displaystyle=

\displaystyle\frac{f_{1}^{4}f_{2}^{2}}{f_{1}^{11}}

\displaystyle\equiv

\displaystyle\frac{f_{1}^{4}f_{2}^{2}}{f_{11}}\pmod{11}.

Replacing
q
by
q^{2}
yields

\displaystyle\sum_{n=0}^{\infty}d_{2}(n)q^{2n}

\displaystyle\equiv

\displaystyle\frac{f_{2}^{4}f_{4}^{2}}{f_{22}}\pmod{11}.

Hence, in order to prove our result, we simply need to focus on
f_{2}^{4}f_{4}^{2}
mod 11.
Thanks to Lemma
1.9
and Lemma
1.10
, we know

\displaystyle f_{2}^{4}f_{4}^{2}

\displaystyle=

\displaystyle\frac{f_{2}^{5}}{f_{1}^{2}}\frac{f_{1}^{2}f_{4}^{2}}{f_{2}}

\displaystyle=

\displaystyle\sum_{j=-\infty}^{\infty}(-1)^{j}(3j+1)q^{3j^{2}+2j}\sum_{k=-\infty}^{\infty}(3k+1)q^{3k^{2}+2k}.

Thus, at this point, we need to ask whether
2(11n+7)
can be represented as

2(11n+7)=3j^{2}+2j+3k^{2}+2k.

This is equivalent to

24(11n+7)+8=(6j+2)^{2}+(6k+2)^{2}

which implies

(6j+2)^{2}+(6k+2)^{2}\equiv 0\pmod{11}

and this implies

(3j+1)^{2}+(3k+1)^{2}\equiv 0\pmod{11}.

Thus, if there is a representation of
2(11n+7)
as
3j^{2}+2j+3k^{2}+2k,
then we know that
11
divides
3j+1
and
11
divides
3k+1.
(Assume this is not true. Then neither
3j+1
nor
3k+1
is divisible by 11. However, we know that the quadratic residues modulo 11 are 1, 3, 4, 5, and 9. So,
(3j+1)^{2}+(3k+1)^{2}\not\equiv 0\pmod{11},
which is a contradiction.) Thus, we now know that the coefficient of
q^{3j^{2}+2j+3k^{2}+2k}
in the series representation for
f_{2}^{4}f_{4}^{2},
which is
(-1)^{j}(3j+1)(3k+1),
must be congruent to 0 modulo 11.
∎

\displaystyle=\frac{f_{2}^{\ell}}{f_{1}^{3\ell+1}}\equiv\frac{f_{2\ell}}{f_{\ell}^{3}}\frac{1}{f_{1}}

\displaystyle\equiv\frac{f_{2\ell}}{f_{\ell}^{3}}\sum_{n=0}^{\infty}p(n)q^{n}\pmod{\ell}.

Since
f_{2\ell}/f_{\ell}^{3}
is a function of

and

, the result follows.
∎

, we have

(19)

\sum_{n=0}^{\infty}d_{p-2}(n)q^{n}\equiv\frac{f_{2p}}{f_{p}^{3}}\left(\sum_{m=-\infty}^{\infty}(6m+1)q^{m(3m+1)/2}\right)\pmod{p}.

We want to know whether
m(3m+1)/2=pn+r
, for some
m
and
n
. This is equivalent to asking whether
24pn+24r+1=(6m+1)^{2}
, which implies
24r+1\equiv(6m+1)^{2}\pmod{p}
. However
24r+1
is a quadratic nonresidue modulo
p
. Therefore
d_{p-2}(pn+r)\equiv 0\pmod{p}.

∎

The theorem above is a fairly standard and classic result, providing exactly
(p-1)/2
congruences for each prime
p.
Interestingly enough, numerical evidence indicates that there are actually
(p-1)/2+1
or
(p+1)/2
such congruences for each prime
p.
We explain this additional “special” congruence for each prime
p\geq 5
here.

Theorem 4.2
.

Let
p\geq 5
be a prime and let
t
,
1\leq t\leq p-1
, be the unique value such that
24t+1\equiv 0\pmod{p}
. Then, for all
n\geq 0
,

d_{p-2}(pn+t)\equiv 0\pmod{p}.

Proof.

Thanks to Lemma
1.5
and (
19
) above, we need to ask whether
pn+t=m(3m+1)/2
for some integers
m
and
n
. Completing the square and looking the result modulo
p
yields
(6m+1)^{2}\equiv 24t+1\equiv 0\pmod{p}
. So
p
divides
(6m+1)^{2}
, which implies that
p
divides
6m+1
. Since the coefficient of
q^{m(3m+1)/2}
in the series that appears in Lemma
1.5
is exactly
6m+1
, it follows that the coefficient in question is congruent to
0
modulo
p
.
∎

Theorem 4.3
.

Let
p\geq 5
be a prime and let
r
,
1\leq r\leq p-1
, be a quadratic nonresidue modulo
p.
Then, for all
n\geq 0
,

d_{p-1}(pn+r)\equiv 0\pmod{p}.

Proof.

Using (
1
), we know that, for prime
p\geq 5,

\displaystyle\sum_{n=0}^{\infty}d_{p-1}(n)q^{n}

\displaystyle=\frac{f_{2}^{p-1}}{f_{1}^{3p-2}}

\displaystyle=\frac{f_{2}^{p}}{f_{1}^{3p}}\frac{f_{1}^{2}}{f_{2}}

\displaystyle\equiv\frac{f_{2p}}{f_{p}^{3}}\frac{f_{1}^{2}}{f_{2}}\pmod{p}

\displaystyle=\frac{f_{2p}}{f_{p}^{3}}\left(\sum_{j=-\infty}^{\infty}q^{j^{2}}\right)

using Lemma
1.6
above. The result immediately follows by recognizing that
\frac{f_{2p}}{f_{p}^{3}}
is a function of
q^{p}
and that
r
has been defined to be a quadratic nonresidue modulo
p.

∎

We next provide an overarching result which allows us to naturally generalize Theorems
2.1
–
2.6
above as well as Theorems
4.1
,
4.2
, and
4.3

Theorem 4.4
.

Let
p
be a prime,
k\geq 1,

j\geq 0,
and

be an integer such that
1\leq r\leq p-1.
If, for all
n\geq 0,

d_{k}(pn+r)\equiv 0\pmod{p},

then for all
n\geq 0,

d_{pj+k}(pn+r)\equiv 0\pmod{p}.

Proof.

Replacing
k
by
pj+k
in (
1
) we obtain

\displaystyle\sum_{n=0}^{\infty}d_{pj+k}(n)q^{n}

\displaystyle=\frac{f_{2}^{pj+k}}{f_{1}^{3pj+3k+1}}=\frac{f_{2}^{k}}{f_{1}^{3k+1}}\frac{f_{2}^{pj}}{f_{1}^{3pj}}

\displaystyle\equiv\frac{f_{2p}^{j}}{f_{p}^{3j}}\sum_{m=0}^{\infty}d_{k}(m)q^{m}\pmod{p}.

All the exponents of
q
coming from
{f_{2p}^{j}}/{f_{p}^{3j}}
are of the form of
pN
. Since
d_{k}(pm+r)\equiv 0\pmod{p}
, it follows that
d_{pj+k}(pn+r)\equiv 0\pmod{p}
.
∎

Theorem 4.7
.

For all
j\geq 0
and
n\geq 0
,

\displaystyle d_{9j+2}(9n+5)

\displaystyle\equiv

\displaystyle 0\pmod{9},

\displaystyle d_{9j+2}(9n+8)

\displaystyle\equiv

\displaystyle 0\pmod{9}.

Proof.

Using the generating function for
d_{2}
, we have

\displaystyle\sum_{n=0}^{\infty}d_{2}(n)q^{n}

\displaystyle=

\displaystyle\frac{f_{2}^{2}}{f_{1}^{7}}=\frac{1}{f_{1}^{9}}f_{1}^{2}f_{2}^{2}

\displaystyle\equiv

\displaystyle\frac{1}{f_{3}^{3}}f_{1}^{2}f_{2}^{2}\pmod{9}

\displaystyle\equiv

\displaystyle\frac{1}{f_{3}^{3}}\left(\frac{f_{6}f_{9}^{4}}{f_{3}f_{18}^{2}}-qf_{9}f_{18}-2q^{2}\frac{f_{3}f_{18}^{4}}{f_{6}f_{9}^{2}}\right)^{2}\pmod{9}

using Lemma
1.7
above. Extracting the terms involving
q^{3n+2}
, dividing by
q^{2}
and replacing
q^{3}
by
q
, we obtain

\sum_{n=0}^{\infty}d_{2}(3n+2)q^{n}\equiv-3f_{3}^{2}f_{6}^{2}\pmod{9}.

Since
f_{3}
and
f_{6}
are functions of
q^{3}
it follows that

\displaystyle d_{2}(9n+5)

\displaystyle\equiv

\displaystyle 0\pmod{9},

\displaystyle d_{2}(9n+8)

\displaystyle\equiv

\displaystyle 0\pmod{9},

which provides the basis case for an inductive proof. Thus, let us assume that
d_{9j+2}(9n+5)\equiv 0\pmod{9}
and
d_{9j+2}(9n+8)\equiv 0\pmod{9}
for some
j
. In order to complete the proof, we note that

\displaystyle\sum_{n=0}^{\infty}d_{9(j+1)+2}(n)q^{n}

\displaystyle=\frac{f_{2}^{9(j+1)+2}}{f_{1}^{27(j+1)+7}}=\frac{f_{2}^{9}}{f_{1}^{27}}\frac{f_{2}^{9j+2}}{f_{1}^{27j+7}}

\displaystyle=\frac{f_{2}^{9}}{f_{1}^{27}}\sum_{m=0}^{\infty}d_{9j+2}(m)q^{m}

(34)

\displaystyle\equiv\frac{f_{6}^{3}}{f_{9}^{3}}\sum_{m=0}^{\infty}d_{9j+2}(m)q^{m}\pmod{9}.

Using Lemma
1.3
, we have

f_{6}^{3}=\sum_{k\geq 0}(-1)^{k}(2k+1)q^{3k(k+1)}.

For all
k\geq 0
, we know that
3k(k+1)\equiv 0,6\pmod{9}
, with
3k(k+1)\equiv 6\pmod{9}
if and only if
k\equiv 1,4,7\pmod{9}
, which is equivalent to
2k+1\equiv 3,9,15\pmod{9}
. Thus, modulo

,

becomes

f_{6}^{3}\equiv\sum_{k\geq 0}a_{k}q^{9k}+3\sum_{k\geq 0}b_{k}q^{9k+6}\pmod{9},

for certain integer coefficients
a_{k}
and
b_{k}
. Hence, using (
34
) we obtain

\displaystyle\sum_{n=0}^{\infty}d_{9(j+1)+2}(n)q^{n}

\displaystyle\equiv\frac{1}{f_{9}^{3}}\left(\sum_{k\geq 0}a_{k}q^{9k}\sum_{m=0}^{\infty}d_{9j+2}(m)q^{m}\right.

\displaystyle\ \ \ \ \left.+3\sum_{k\geq 0}b_{k}q^{9k+6}\sum_{m=0}^{\infty}d_{9j+2}(m)q^{m}\right)\pmod{9}.

By the hypothesis, we see that the coefficients of

and
q^{9n+8}
in the first term of the congruence above are congruent to
0
modulo
9
. For the second term in the congruence above, namely

(35)

\sum_{m,k\geq 0}3b_{k}d_{9j+2}(m)q^{9k+m+6},

we note that
9k+m+6\equiv 5\pmod{9}
if and only if
m\equiv 8\pmod{9}
. In this case, we know that

for some

. By (

) in Corollary
4.5
, we have
d_{9j+2}(9n+8)\equiv 0\pmod{3}
, for all

, which yields

modulo

. However, we also know from (

) in Corollary
4.5

d_{9j+2}(9n+2)\equiv 0\pmod{3}

n
. Thus,

.
∎

5.
Concluding Remarks

We readily admit that the above results are not an exhaustive list of all of the congruences satisfied by the functions
d_{k}(n).
Indeed, there are many other congruences to consider. For example, computational evidence hints at the possibility of infinite families of congruences modulo arbitrarily high powers of 3 for the function
d_{11}(n)
as well as the possibility of infinite families of congruences modulo powers of 2 for
d_{7}(n)
and
d_{15}(n)
(in the spirit of the work completed by Smoot for
d_{2}
modulo powers of 3). Indeed, for
k=2^{j}-1
for some
j,
it is clear that the generating function for
d_{k}(n)
will have a structure that allows for a number of congruences to hold for small moduli. One must wonder whether an
infinite
family of congruences, modulo powers of 2, like the family in Theorem
1.1
holds for these special values of
k.
We leave such an investigation to the interested reader.
