Non-linear evolution in the re-summed next-to-leading order of perturbative QCD: confronting the experimental data
Carlos Contreras, Eugene Levin, Michael Sanhueza

Abstract
In this paper we compare the experimental HERA data with the next-to-leading order approach (NLO) of Ref. CLMS . This approach includes the re-summed NLO corrections to the kernel of the evolution equation, the correct asymptotic behaviour in the NLO at τ = r 2 ​ Q s 2 ≫ 1 \tau=r^{2}Q^{2}_{s}\,\gg\,1 ; the impact parameter dependence of the saturation scale in accord with the Froissarrt theorem as well as the non-linear corrections. In this paper, we successfully describe the experimental data with the quality, which is not worse, than in the leading order fits with larger number of the phenomenological parameters. It is demonstrated, that the data could be described, taking into account both the diffusion on ln ⁡ ( k T ) \ln(k_{T}) , which stems from perturbative QCD, and the Gribov’s diffusion in impact parameters. It is shown an ability to describe the data at rather large values of α ¯ S \bar{\alpha}_{S} .

The use of this variable indicates the main idea of our approach in the region of
\tau\,>\,1
: we
wish to match the solution of the non-linear Eq. (
35b
) with the solution of linear equation (see Eq. (
19
)) in the kinematic region where it has the form
MUT
:

N\,\,=\,\,N_{0}\,\exp\left(\bar{\gamma}\,z\right)~~~~\mbox{with}~~~~~z\,\,=\,\,\xi_{s}\,\,+\,\,\xi

(37)

and
\bar{\gamma}
is determined by Eq. (
24
). Eq. (
37
) leads to the initial and boundary conditions:

N\left(r^{2},Y\right)\,\,=\,\,N\left(\tau=1\right)\,\,=\,\,N_{0};~~~~~~~\frac{d\ln\left(N\left(r^{2},Y\right)\right)}{d\xi}|_{\tau=1}\,\,=\,\,\bar{\gamma};

(38)

Eq. (
35b
) has a traveling wave solution (see formula
3.4.1.1
of
Ref.
MATH
). For Eq. (
35b
) in the canonical form:

\frac{\partial^{2}\Omega\left(\xi_{s};\tilde{\zeta}\right)}{\partial t^{2}_{+}}\,\,-\,\,\frac{\partial^{2}\Omega\left(\xi_{s};\tilde{\zeta}\right)}{\partial t^{2}_{-}}\,\,\,=\,\,\sigma\,\,\Bigg(1-\,\exp\left(-\Omega\left(\xi_{s};\tilde{\zeta}\right)\right)\Bigg),

(39)

with
t_{\pm}=\xi_{s}\pm\xi
, the solution takes the form:

\int^{\Omega}_{\Omega_{0}}\frac{d\Omega^{\prime}}{\sqrt{C_{1}+\frac{2}{(\mu^{2}-\kappa^{2})}\sigma\left(\Omega^{\prime}+\exp\left(-\Omega^{\prime}\right)\right)}}\,\,=\,\,\mu t_{+}+\kappa t_{-}+C_{2}

(40)

where all constants have to be determined from the initial and boundary
conditions of Eq. (
38
). First we see that
C_{2}=0
and
\kappa=0
.
From the condition
\Omega^{\prime}_{z}/\Omega\,\,=\,\,\bar{\gamma}
at
t_{+}=0
we can find
C_{1}
. Indeed, differentiating Eq. (
40
) with respect to

t_{+}
one
can see that at
t_{+}=0
we have:

\frac{d\Omega}{dt_{+}}|_{t_{+}=0}\,\frac{1}{\sqrt{C_{1}\,\,+\,\,\frac{2\,\sigma}{\mu^{2}}\left(1\,\,+\,\,\frac{1}{2}\,\Omega^{2}_{0}\right)}}\,\,=\,\,\mu

(41)

From Eq. (
41
) one can see that choosing

C_{1}\,\,=\,\,-\,\frac{2\sigma}{\mu^{2}}\,\,+\,\,\Omega^{2}_{0}\left(1\,\,-\,\,\frac{\sigma}{\mu^{2}}\right);~~~~~\mbox{and}\,~~~\mu\,\,=\,\,\bar{\gamma}

(42)

we satisfy the initial condition
\frac{d\ln\left(\Omega\right)}{dz}|_{t_{+}=0}=\,\bar{\gamma}
of Eq. (
24
).

Finally, the solution of Eq. (
40
) can be re-written in the following
form for
\Omega_{0}\ll 1
:

\int^{\Omega}_{\Omega_{0}}\frac{d\Omega^{\prime}}{\sqrt{\Omega^{2}_{0}\,\left(1\,\,-\,\,\frac{\sigma}{\bar{\gamma}^{2}}\right)\,\,+\,\,\frac{2\,\sigma}{\bar{\gamma}^{2}}\left(-1\,\,+\,\,\Omega^{\prime}\,\,+\,\,\,e^{-\,\Omega^{\prime}}\right)}}\,\,=\,\,\bar{\gamma}\,z

(43)

One can see that Eq. (
43
) gives the geometric scaling solution
LETU
;
BALE
;
IIML
;
SGBK
which depends only on the variable
z
.
For
\Omega\to\Omega_{0}
and if
\Omega_{0}\ll 1
, Eq. (
43
) can be
solved explicitly giving

\Omega\,\,=\,\,\Omega_{0}\Bigg\{\cosh\left(\sqrt{\sigma}\left(\xi_{s}+\xi\right)\right)\,\,+\,\,\frac{\bar{\gamma}}{\sqrt{\sigma}}\,\sinh\left(\sqrt{\sigma}\left(\xi_{s}+\xi\right)\right)\Bigg\}

(44)

Eq. (
44
) gives the solution which depends only on one variable

z\,\,=\,\,\xi_{s}+\xi
,
and satisfies the initial conditions of Eq. (
38
).

At large
z
we obtain the solution
LETU
:

\Omega\left(z\right)\,\,=\,\,\frac{\sigma}{2}\,z^{2}\,\,+\,\,{\rm Const}

(45)

or in terms of the amplitude

N\left(z\right)\,\,=\,\,1\,\,-\,\,{\rm Const}\,e^{-\,\frac{\sigma}{2}\,z^{2}}

(46)

We wish to stress that Eq. (
46
) reproduces the
asymptotic solution to the BK equation in the NLO, which has been derived in
Refs.
CLMP
;
XCWZ
, for fixed
\bar{\alpha}_{S}
.

It should be noted that both solutions of Eq. (
44
) and Eq. (
45
)
can be derived directly from Eq. (

and
1\,-\,\exp\left(-\Omega\right)\,\,\to\,1
for
small
z

V
Conclusions

In this paper we compare with the experimental data the NLO approach of Ref.
CLMS
. In this approach we include
the re-summation procedure, suggested in
Refs.
SALAM
;
SALAM1
;
SALAM2
;
DIMST
, to fix the BFKL kernel in the NL0, but we treat differently the non-linear corrections. The advantage of our treatment is that we reproduce the correct asymptotic behaviour
at large
\tau=r^{2}Q^{2}_{s}
.

Fixing our phenomenological parameters from the fit to the experimental data on
F_{2}
DIS structure function in the region:
0.85\leq Q^{2}\leq 27\,GeV^{2}
and
x\leq 0.013
, we found that can describe these data with very good
