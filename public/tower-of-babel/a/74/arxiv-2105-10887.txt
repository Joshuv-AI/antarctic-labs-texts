Abstract
To investigate the interaction between the nucleon N N and nucleon resonance N ⁡ ( 1535 ) ​ 1 / 2 − N(1535)1/2^{-} , the η ​ d \eta d threshold structure connected to the isoscalar S S -wave N N - N ⁡ ( 1535 ) ​ 1 / 2 − N(1535)1/2^{-} system has been experimentally studied in the γ ​ d \gamma{d} → \to π 0 ​ η ​ d \pi^{0}\eta{d} reaction at incident photon energies ranging from the reaction threshold to 1.15 GeV. A strong enhancement is observed near the η ​ d \eta d threshold over the three-body phase-space contribution in the η ​ d \eta d invariant-mass distribution. An analysis incorporating the known isovector resonance 𝒟 12 \mathcal{D}_{12} with a spin-parity of 2 + 2^{+} in the π 0 ​ d \pi^{0}d channel reveals the existence of a narrow isoscalar resonance-like structure with 1 − 1^{-} in the η ​ d \eta d system. Using a Flatté parametrization, the mass is found to be 2.427 − 0.006 + 0.013 2.427_{-0.006}^{+0.013} GeV, close to the η ​ d \eta d threshold, and the width is ( 0.029 − 0.029 + 0.006 ​ GeV ) + ( 0.00 − 0.00 + 0.41 ) ​ p η ​ c \left(0.029_{-0.029}^{+0.006}{\rm\ GeV}\right)+\left(0.00_{-0.00}^{+0.41}\right)p_{\eta}c , where p η p_{\eta} denotes the η \eta momentum in the rest frame of the η ​ d \eta d system. The observed structure would be attributed to a predicted isoscalar 1 − 1^{-} η ​ N ​ N \eta NN bound state from η ​ N ​ N \eta NN and π ​ N ​ N \pi NN coupled-channel calculation, or an η ​ d \eta d virtual state owing to strong η ​ d \eta d attraction.

\eta d
