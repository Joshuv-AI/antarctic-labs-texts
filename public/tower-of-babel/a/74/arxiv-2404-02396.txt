Enhancing Diffusion-based Point Cloud Generation with Smoothness Constraint
Yukun Li, Liping Liu

Abstract
Diffusion models have been popular for point cloud generation tasks. Existing works utilize the forward diffusion process to convert the original point distribution into a noise distribution and then learn the reverse diffusion process to recover the point distribution from the noise distribution. However, the reverse diffusion process can produce samples with non-smooth points on the surface because of the ignorance of the point cloud geometric properties. We propose alleviating the problem by incorporating the local smoothness constraint into the diffusion framework for point cloud generation. Experiments demonstrate the proposed model can generate realistic shapes and smoother point clouds, outperforming multiple state-of-the-art methods.

There are also several diffusion-based generative models
[
13

20

The generation process can move the noisy point locations toward the original point cloud surface. The training aims to learn a score model to approximate the gradient of log-likelihood of the point cloud distribution, which is equivalent to learning the moving direction of the particles (points) during diffusion. However, both algorithms are discrete generative processes and thus cannot consider the shape of geometric information when learning point-moving directions. Compared with diffusion-based models for image data that learn the data distribution in the feature space, these models face a critical challenge in learning the 3D point location distribution. This paper aims to incorporate the local geometric constraints into a diffusion-based point cloud generation process to enforce surface smoothness. Our approach views the diffusion probabilistic model from a Bayesian perspective to consider the prior constraint of the point cloud.
Experiments demonstrate that our method is not only capable of generating realistic shapes but also generating smoother point clouds, outperforming multiple state-of-the-art methods.

Background

2.1
Tweedie’s Formula

Consider the noisy sample distribution
p(\hat{\mathbf{X}}|\mathbf{X})\sim\mathcal{N}(\mathbold{\mu},\sigma^{2}\mathbf{I})
, the Tweedie’s formula
[
21
,
22
]
tells us the optimum denoised sample can be achieved by computing the posterior expectation:

\displaystyle\mathbb{E}[\mathbf{X}|{\hat{\mathbf{X}}}]=\hat{\mathbf{X}}+\sigma^{2}\nabla_{\hat{\mathbf{X}}}\log p(\hat{\mathbf{X}})

(1)

Thus, for a diffusion model in which the forward step is modeled as
p(\hat{\mathbf{X}}|\mathbf{X})\sim\mathcal{N}(a_{i}\mathbf{x}_{0},b_{i}^{2}\mathbf{I})
, the formula can approximate the denoised sample
\mathbf{x}_{0}
:

\displaystyle\mathbb{E}[\mathbf{X}_{0}|{{\mathbf{X}_{i}}}]=({\mathbf{X}_{i}}+b_{i}^{2}\nabla_{{\mathbf{X}_{i}}}\log p({\mathbf{X}_{i}}))/a_{i}.

(2)

Here
a_{i}
and
b_{i}
are the drift and diffusion coefficients of the forward diffusion process. Our approach uses this equation to approximate the clean point cloud from the noisy samples at each time step during the reverse diffusion process.

2.2
Point Cloud Smoothness Property

Point clouds have extensive applications in computer vision and robotics. Nevertheless, raw point clouds are often affected by noise and irregularities resulting from data acquisition techniques or environmental factors
[
23
]
. One pivotal approach to improving the quality of point cloud generative models involves implementing smoothness constraints, primarily utilizing graph Laplacian matrices constructed from k-nearest neighbor (KNN) graphs
[
24
]
. This method characterizes the point cloud’s smoothness by quantifying the average difference between each point and its neighboring points, as expressed by the equation:

\displaystyle S(\mathbf{X})=\text{trace}(\mathbf{X}^{T}\mathbf{L}\mathbf{X})

(3)

Here
\mathbf{X}
represents the matrix of all points’ positions and
\mathbf{L}
stands for the Laplacian matrix derived from the KNN graph. Point cloud generative models can attain smoother surfaces by incorporating this smoothness constraint term into an optimization framework.

3
Approach

A point cloud consists of a set of points in 3D space. Each point cloud can be denoted by
\mathbf{X}=\{\boldsymbol{x}_{i}\}_{i=1}^{N}\in\mathbb{R}^{N\times 3}
, where
N
is the number of points, and
\boldsymbol{x}_{i}
is the 3D coordinates for point
i
. The dataset comprises
M
distinct point clouds, denoted as
\mathcal{D}=\{{\bf X}_{1},...{\bf X}_{M}\}
. The goal is to develop a model to generate a precise point cloud that faithfully captures the datasets’ shape geometry and variability. We formulate point cloud generation as a continuous particle diffusion process.

However, this problem introduces several unique challenges. Firstly, a single object can have different shapes (e.g., various airplane categories). Therefore, it is essential to model the global shape distribution and the individual point cloud distribution. Secondly, the diffusion probabilistic model captures the intermediate movement of points but may not consider local geometric information within the point cloud, potentially leading to a non-smooth surface during sampling.
To address these challenges, we propose a diffusion probabilistic model with a smoothness constraint to capture the local geometric features within point clouds effectively. The overall model structure is depicted in
Figure
1
. The model consists of an encoder, a diffusion decoder, and a latent diffusion module. The encoder
q_{\mathbold{\phi}}(\bf z|\bf X)
parameterized by
\mathbold{\phi}
learns a low dimensional latent embedding distribution for the given point cloud input to encode its global shape feature. Given a shape embedding
\mathbf{z}
, the diffusion decoder
p_{\boldsymbol{\psi}}(\bf X|\bf z)
reconstructs the original point cloud through a reverse diffusion process. Furthermore, to accurately model the shape latent embedding
\bf z
prior distribution, we use a latent diffusion module
p_{{\mathbold{\theta}}}(\bf z)
to transform a standard normal distribution to the aggregated posterior of the encoder.

Figure 1:
The overall structure of our model, containing three modules: Encoder module
q_{\mathbold{\phi}}(\mathbf{z}|\mathbf{X})
; The latent diffusion learns the latent prior distribution
p_{\mathbold{\theta}}(\mathbf{z})
; The decoder diffusion module learns a conditional diffusion model
p_{\boldsymbol{\psi}}{(\mathbf{X}|\mathbf{z})}
to reconstruct the original shape
\mathbf{X}
based on its embedding
\mathbf{z}
. A smoothness constraint is incorporated during the decoder reverse diffusion process.

3.1
Proposed Overall Model

Our model learns the point cloud distribution over a diverse shape pattern. As indicated by
[
16
]
, for the point cloud generation, it is not helpful to learn the marginal distribution
p(\mathbf{X})
across various shapes. Thereby, we model the distribution into the factorized format and incorporate the latent shape embedding distribution into consideration:
p_{\mathbold{\theta},\boldsymbol{\psi}}(\mathbf{X},\mathbf{z})=p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})p_{\mathbold{\theta}}(\mathbf{z})
, where
\mathbf{z}\in\mathbb{R}^{d}
is a latent d-dimensional variable that embeds the global shape pattern of the point cloud,
p_{\mathbold{\theta}}(\mathbf{z})
represents the latent embedding prior distribution.
p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})
is a conditional diffusion model given a specific global shape condition
\mathbf{z}
. The model trains the time-dependent score model
s_{\boldsymbol{\psi}}(\mathbf{X},\mathbf{z},t)
to learn the score function of
p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})
, which is the gradient of log-likelihood
\nabla_{\mathbf{X}}\log p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})
. The global shape posterior is approximated through another latent diffusion model
q_{\boldsymbol{\phi}}(\mathbf{z}|\mathbf{X})
. We maximize the
Evidence Lower Bound
(ELBO) on the data log-likelihood as Equation
3.1
to optimize the generative model.

\displaystyle\max_{\boldsymbol{\phi},\boldsymbol{\psi},\mathbold{\theta}}~\mathcal{L}(\mathbold{\phi},\boldsymbol{\psi},\mathbold{\theta})

\displaystyle=\mathbb{E}_{q{\phi}(\mathbf{z}|\mathbf{X})}\big[\log{p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})}\big]-\textrm{KL}\left(q{\phi}(\mathbf{z}|\mathbf{X})\;\|\;p{\theta}(\mathbf{z})\right)

\displaystyle=\mathbb{E}_{q{\phi}(\mathbf{z}|\mathbf{X})}\big[\log{p_{\boldsymbol{\psi}}(\mathbf{X}|\mathbf{z})}\big]+\mathbb{E}_{q{\phi}(\mathbf{z}|\mathbf{X})}\big[\log p{\theta}(\mathbf{z})\big]+\mathbb{H}\big[q{\phi}(\mathbf{z}|\mathbf{X})\big]

(4)

3.2
Sampling with Smoothness Constraint

The framework uses a conditioned diffusion probabilistic model to generate point clouds with diverse shapes. However, it is still challenging to generate the 3D point location distribution obeying the geometrical constraint on the 3D object.

We propose a graph Laplacian smoothness constraint on the decoder diffusion model
p_{\boldsymbol{\psi}}({\bf X}|\mathbf{z})
. Specifically, we incorporate the point cloud constraint into the sampling process. Suppose a constraint
\mathbf{H}
on the sample takes the form
p(\mathbf{H}|\bf{X})
, we consider a probabilistic model from Bayesian perspective:

\displaystyle p(\bf{X}|\mathbf{H},\mathbf{z})=\frac{p(\mathbf{H}|\bf{X},\mathbf{z})p(\bf{X}|\mathbf{z})}{p(\mathbf{H},\mathbf{z})}

(5)

We propose a Bayesian denoising method by taking the gradient of the posterior:

\displaystyle\nabla_{\bf{X}}\log p(\bf{X}|\mathbf{H},\mathbf{z})=\nabla_{\bf{X}}\log p(\bf{X}|\mathbf{z})+\nabla_{\bf{X}}\log p(\mathbf{H}|\bf{X},\mathbf{z})

(6)

The first term is learned by the decoder diffusion score model
s_{\boldsymbol{\psi}}(\mathbf{X},\mathbf{z},t)
, and the challenge is how to add the second Bayesian constraints term to each time step of the reverse diffusion process on noisy sample
\mathbf{X}_{t}
. To address this challenge, We consider the constraints on the inferred clean point clouds based on Tweedie’s formula:

\displaystyle\hat{\mathbf{X}}=\frac{\mathbf{X}_{t}+b_{t}^{2}\mathbf{s}_{\boldsymbol{\psi}}(\mathbf{X},\mathbf{z},t)}{a_{t}}.

(7)

Here
a_{t},b_{t}
are the drift and diffusion coefficients of the forward diffusion processes. Thus, we can construct a smoothness constraint based on the estimated clean point cloud
\hat{\bf{X}}
. The constraint is proportional to the graph Laplacian regularizer on the KNN graph of the point cloud to encourage more uniform point distribution during the sampling process:

\displaystyle\log p(\mathbf{H}|{\mathbf{X}},\mathbf{z})\propto-\text{trace}(\hat{\mathbf{X}}^{T}\mathbf{L}\hat{\mathbf{X}}),\text{where}\ \hat{\mathbf{X}}={\mathbf{X}_{t}+b_{t}^{2}s_{\boldsymbol{\psi}}(\mathbf{X}_{t},\mathbf{z},t)}/{a_{t}}.

(8)

Here
\hat{\bf{X}}
is the estimated clean point cloud data at each reverse diffusion time step, and
\bf{L}
is the graph Laplacian matrix.
Putting the Bayesian denoising method together, the reverse diffusion under the smoothness constraint can be represented by

\displaystyle\mathbf{X}_{{t-1}}=\mathbf{X}_{{t}}+\underbrace{[f_{t}(\mathbf{X}_{t})-g_{t}^{2}\mathbf{s}_{\boldsymbol{\psi}}(\mathbf{X}_{t},\mathbf{z},t)]\Delta_{t}}_{\text{parameterized by score model}}-\underbrace{\alpha\nabla_{\mathbf{X}_{t}}\{\text{trace}\ (\hat{\mathbf{X}}_{t}^{T}\mathbf{L}\hat{\mathbf{X}}_{t})\}}_{\text{smoothness constraint}}+g_{t}(\bf{X}_{t})\mathbf{z},\mathbf{z}\sim\mathcal{N}(0,I).

(9)

Here
\alpha
controls the relative weight of the smoothness constraint, and
f_{t},g_{t}
are the drift and diffusion coefficients of the forward diffusion process.

5
Conclusions

In this paper, we introduce a novel diffusion-based model for point cloud generation, incorporating not only the global geometry distribution but also integrating a local smoothness constraint into the generation process. Experimental results demonstrate that the proposed framework can produce realistic and smoother point cloud samples. The limitation of our approach is that we only consider the smoothness constraint on the point cloud.

Background: Diffusion-based Generative Model

We consider the diffusion process over data
\mathbf{X}
indexed with time
t\in[0,1],\{\mathbf{X}_{t}\}_{t=0}^{1}
. Here
\mathbf{X}_{0}\sim p_{0}(\mathbf{X})=p_{data}
,
\mathbf{X}_{1}\sim p_{1}(\mathbf{X})
, where
p_{1}(\mathbf{X})
approximates the Gaussian distribution
\mathcal{N}(\mathbf{0},\mathbf{I})
. The diffusion process can be modeled by Itô SDE
[
27
]
:

\displaystyle d\mathbf{X}_{t}=f_{t}(\mathbf{X},t)dt+g_{t}d\mathbf{w},

(11)

f_{t}
is a drift coefficient, and
g_{t}
is a diffusion coefficient.
The forward diffusion process smoothly transforms
\mathbf{X}
by adding infinitesimal noise
dw
at each infinitesimal step
dt
.

To generate samples following the data distribution, we start from the prior distribution and follow the reverse diffusion process, which is defined by:

\displaystyle d\mathbf{X}_{t}=[f_{t}(\mathbf{X}_{t})-g_{t}^{2}\nabla_{\mathbf{X}_{t}}\log p_{t}(\mathbf{X}_{t})]dt+g_{t}d\bar{\mathbf{w}},

(12)

The diffusion model training process learns the time-dependent score model
\mathbf{s}_{\theta}(\mathbf{X},t)
and minimizes the least square loss between the score function and the model output

\displaystyle\min\int_{0}^{1}\mathbb{E}_{p_{t}(\mathbf{X})}[\|\mathbf{s}_{\theta}(\mathbf{X},t)-\nabla_{\mathbf{X}}\log p_{t}(\mathbf{X})\|^{2}]dt

(13)

Thus, the sampling process replace the unknown score function
\nabla_{\mathbf{X}_{t}}\log p_{t}(\mathbf{X}_{t})
in Eq
12
with the score model
\mathbf{s}_{\theta}(\mathbf{X},t)
.

7
Details on Approach

7.1
Diffusion-based Prior Model

The prior model aims to capture the distribution of the global geometry of all point cloud shapes. A common choice is to use a fixed prior (e.g.,
\mathbf{z}\sim\mathcal{N}(\mathbf{0},\mathbf{I})
) in variational auto-encoder, but it can produce holes, then there exists a mismatch between the aggregated posterior
\sum_{i}q_{\boldsymbol{\phi}}(\mathbf{z}|\mathbf{X}^{(i)})
and the prior
p(\mathbf{z})
. Then, this can lead to some regions in the latent space that cannot be decoded into data-like samples.

Our proposed model uses a learnable prior model
p_{\theta}(\mathbf{z})
. The prior is flexible, such that it can catch up with the aggregated posterior, and then they can match each other better, thus alleviating the problem of prior holes. Here, we propose to use the diffusion process to learn the prior over the shape distribution.
Specifically, given a global geometry encoding
\mathbf{z}_{0}\sim q_{\boldsymbol{\phi}}(\mathbf{z}_{0}|\mathbf{X})
, we diffused
z_{0}
through a SDE defined in Eq.
11
to the standard Normal distribution
p(\mathbf{z}_{1})=\mathcal{N}(\mathbf{0},\mathbf{I})
, and we train a time-dependent score model
\mathbf{s}_{\mathbold{\theta}}(\mathbf{z}_{t},t)
to approximate the true score
\nabla_{\mathbf{z}_{t}}\log p_{\mathbold{\theta}}(\mathbf{z}_{t})
. For the generation process, the reversed SDE based on Eq.
12
is employed to generate samples that follow the prior distribution
p_{\mathbold{\theta}}(\mathbf{z}_{0})
. We use several layers of 1D convolution with residual connection for the score model. The details are in the experiment section.

7.2
Diffusion-based Conditional Decoder

In this section, we introduce the framework of the conditional diffusion model in the decoder part. Here, we consider the point cloud generation as a conditional diffusion process, where the condition is the global geometry encoding
\mathbf{z}\sim q_{\boldsymbol{\phi}}(\mathbf{z}|\mathbf{X})
. Similarly, we diffuse the points of the point cloud (particles) to the standard Normal distribution and learn a conditional score model
\mathbf{s}_{\boldsymbol{\psi}}(\mathbf{X}_{t},\mathbf{z},t)
to approximate the reverse moving direction of the points during the forward diffusion process (equivalent to the score
\nabla_{\mathbf{X}_{t}}\log p_{\boldsymbol{\psi}}(\mathbf{X}_{t}|\mathbf{z})
). For sampling, given a global geometry condition
\mathbf{z}
, we can use the score model
s_{\boldsymbol{\psi}}(\mathbf{X}_{t},\mathbf{z},t)
through the reverse SDE to move the noisy point cloud to the original point cloud distribution.

Specifically, the input of this network is the perturbed point cloud with Gaussian noise sampled from
\mathbf{X}_{t}\sim p_{t}(\mathbf{X}_{t}|\mathbf{X})

and the time embedding. We also concatenate the latent code
\mathbf{z}
as the condition to the input of each layer.

More Details on Experiments

8.1
Experiment Setup

Datasets:
In our experimental evaluation, we employed the widely used ShapeNet dataset
[
26
]
, a comprehensive benchmark for 3D shape understanding. The dataset comprises 51,127 shapes distributed across 55 different categories. To maintain consistency with prior work and ensure fair comparisons, we adopted the same dataset split as presented in
[
12
]
.

Within the ShapeNet dataset, e each 3D shape is depicted as a point cloud consisting of 2048 points uniformly sampled on the object’s surfaces. This representation of point clouds effectively captures the intricate geometric details of the shapes, making it a fitting input for our 3D shape understanding tasks.

For our comparative analysis, we specifically focused on three categories: airplanes, chairs, and cars. These categories represent different types of objects with varying shapes and complexities, making them suitable for assessing the performance of our model under diverse scenarios.

8.2
Implementation Detail

Hyperparameters:
The latent code dimension is set to 256. For the training stage, we set the batch size as 32. We utilized Adam optimizer with learning rate
2\times 10^{-3}
for the encoder and learning rate
2\times 10^{-4}
for the diffusion decoder module,
1\times 10^{-4}
for the latent diffusion module. The learning rate was kept constant for the first 1000 epochs and decreased linearly from 1000 to 2000 epochs. For sampling, We sample each point cloud with N = 2048 points. The time step is set to be
1000
steps for sampling.

Model architecture:
We use PointNet
[
30
]
as an encoder to map the input point cloud into a 512-dimension latent feature code
\mathbf{z}
. For the decoder and the prior diffusion module, we utilize OccNet
[
31
]
. We stacked 6 ResNet blocks with 256 dimensions for every hidden layer.

Evaluation metrics:

Suppose
P_{r}
is the set of reference point clouds for the generation task, and
P_{g}
is the set of generated point clouds. We adopt the following metrics:

1.

Minimum Matching Distance(MMD)

\footnotesize MMD(P_{r},P_{g})=\frac{1}{|P_{r}|}\sum_{P\in P_{r}}\min_{Q\in P_{g}}D(P,Q)

MMD calculates the average of the closest distances to each reference point cloud to measure the quality of the generated samples.

2.

Coverage score(COV)

\displaystyle\footnotesize COV(P_{r},P_{g})=\frac{|\{\arg min_{P\in P_{r}}D(P,Q)|Q\in P_{g}\}|}{|P_{r}|}

COV measures the variety of the generated samples to detect mode collapse.

3.
