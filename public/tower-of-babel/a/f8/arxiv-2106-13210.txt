Optimal Fine-grained Hardness of Approximation of Linear Equations
Mitali Bafna, Nikhil Vyas

Abstract
The problem of solving linear systems is one of the most fundamental problems in computer science, where given a satisfiable linear system ( A , b ) (A,b) , for A ∈ ℝ n × n A\in{\mathbb{R}}^{n\times n} and b ∈ ℝ n b\in{\mathbb{R}}^{n} , we wish to find a vector x ∈ ℝ n x\in{\mathbb{R}}^{n} such that A ​ x = b Ax=b . The current best algorithms for solving dense linear systems reduce the problem to matrix multiplication, and run in time O ⁡ ( n ω ) O(n^{\omega}) . We consider the problem of finding ε {\varepsilon} -approximate solutions to linear systems with respect to the L 2 L_{2} -norm, that is, given a satisfiable linear system ( A ∈ ℝ n × n , b ∈ ℝ n ) (A\in{\mathbb{R}}^{n\times n},b\in{\mathbb{R}}^{n}) , find an x ∈ ℝ n x\in{\mathbb{R}}^{n} such that | | A ​ x − b | | 2 ≤ ε ​ | | b | | 2 \lvert\lvert Ax-b\rvert\rvert_{2}\leq{\varepsilon}\lvert\lvert b\rvert\rvert_{2} . Our main result is a fine-grained reduction from computing the rank of a matrix to finding ε {\varepsilon} -approximate solutions to linear systems. In particular, if the best known O ⁡ ( n ω ) O(n^{\omega}) time algorithm for computing the rank of n × O ⁡ ( n ) n\times O(n) matrices is optimal (which we conjecture is true), then finding an ε {\varepsilon} -approximate solution to a dense linear system also requires Ω ~ ​ ( n ω ) \tilde{\Omega}(n^{\omega}) time, even for ε {\varepsilon} as large as ( 1 − 1 / poly ​ ( n ) ) (1-1/\text{poly}(n)) . We also prove (under some modified conjectures for the rank-finding problem) optimal hardness of approximation for sparse linear systems, linear systems over positive semidefinite matrices, well-conditioned linear systems, and approximately solving linear systems with respect to the L p L_{p} -norm, for p ≥ 1 p\geq 1 . At the heart of our results is a novel reduction from the rank problem to a decision version of the approximate linear systems problem. This reduction preserves properties such as matrix sparsity and bit complexity.

Our reduction:

At the heart of our results lies an “exact to approximate” reduction for

Definition 1.3

(
{\varepsilon}(n)
-Approximate Linear Decision problem

]
)

For a function
{\varepsilon}:\mathbb{N}\rightarrow[0,1]

(A\in{\mathbb{R}}^{m\times n},b\in{\mathbb{R}}^{m})

m=O(n)

1.

2.

1.2
Extensions

We prove several extensions of our main theorem using the reduction discussed above in the appendix. We can modify our main reduction so that it preserves the sparsity and condition number of the original instance to get the results for sparse and well-conditioned linear systems. To get hardness for PSD linear systems we need additional ideas beyond this reduction. We get the following results:

Sparse Linear Systems:

Linear equation solving has also been studied in the case of sparse linear systems. We know of
O(\text{nnz}(A)n)
time algorithms for solving a linear system
(A\in\mathbb{R}^{O(n)\times n},b)
where
\text{nnz}(A)
denotes the number of non-zero entries of
A

[
HS52
]
, so that when the sparsity of
A
is
\tilde{O}(n)
, these algorithms run in time
\tilde{O}(n^{2})
. Our reduction (discussed above), preserves the sparsity of the original matrix
A
and thus reduces the exact problem over sparse linear systems to the approximate problem over sparse ones. We start with an analogous conjecture to Conjecture
1
for finding the rank of a sparse matrix:

Conjecture 2

(Rank-finding Conjecture for Sparse matrices over RealRAM)
.

Finding the rank of a matrix
A\in{\mathbb{R}}^{m\times n}
with
m=O(n)
and
\text{nnz}(A)=\tilde{O}(n)
in RealRAM is
\Omega(n^{2})
-hard.

Under the above conjecture we show (see Corollary
4.4
) that solving
(1-1/n^{100})
-Approximate Linear Search problems on sparse linear systems is
\tilde{\Omega}(n^{2})
-hard, which is optimal up to poly-logarithmic factors.

Positive Semi-Definite Linear systems:

We give optimal hardness for the
(1-1/n^{100})
-approximate linear search problem when the matrix
A
is restricted to be positive semidefinite (see Corollary
4.9
). Recently there has been a lot of work for getting nearly linear-time approximation algorithms for restricted classes of matrices. For a slightly more restricted class of linear systems than PSD ones, called Strongly Diagonally Dominant (SDD) systems, Spielman and Teng gave near-linear time approximate solvers
[
ST14
]
, leaving near-linear time approximation algorithms for PSD linear systems as the next open problem. In fact, resolving the time-complexity for PSD linear systems was in mentioned as an open problem in
[
AKP19
]
, where they gave unconditional hardness for PSD linear systems for sublinear-time algorithms. Interestingly, we show that under Conjecture
3
, such solvers are not possible for PSD linear systems, thus giving a conditional separation of the time complexity required for approximately solving SDD linear systems versus PSD ones.

Well-conditioned linear systems:

We now turn our attention to the problem of solving well-conditioned (see Definition

) linear systems approximately. In Section
4.4

\tilde{\Omega}(n^{\omega})
-hardness of the well-conditioned rank-finding problem.

We also prove the following analogue of Corollary

Corollary 1.6

If there exists as

1.4
Further applications and related work

Recently, there has been a lot of progress on the algorithmic front for finding approximate solutions to restricted classes of linear systems
(A,b)
. In a breakthrough work, Spielman and Teng
[
ST14
]
obtained
\tilde{O}(\text{nnz}(A)\log(1/{\varepsilon}(n)))
-time algorithms for finding
{\varepsilon}(n)
-approximate solution to Laplacian systems and Strongly Diagonally Dominant (SDD) systems. This result was followed up by algorithms for more general classes of linear systems such as Connection Laplacians
[
KLP+16
]
and Directed Laplacian systems
[
CKP+17
]
. This raised the hope that such approximation algorithms could be obtained for more general classes of matrices such as truss stiffness matrices and total variation matrices. Kyng and Zhang
[
KZ17
]
showed that such algorithms for these slightly more general classes would imply approximation algorithms for general linear systems. Therefore, by composing our reduction with theirs, one immediate corollary we get is that solving approximately for these classes of restricted linear systems is as hard as the rank-finding problem.

In
[
KWZ20
]
the authors prove conditional hardness for the problems of Packing/Covering Linear Programs based on the hardness of approximately solving general linear equations. Prior to our work there was no evidence of hardness for approximately solving linear equations. Our results therefore imply hardness for these problems under the rank-finding problem.

Definition 2.3

(Condition number)
.

Condition number of a matrix
A\in{\mathbb{R}}^{m\times n}
where
n\leq m
and
A
has full column-rank is defined as:

\kappa(A)=\frac{\max\limits_{\lvert\lvert x\rvert\rvert_{2}=1}\lvert\lvert Ax\rvert\rvert}{\min\limits_{\lvert\lvert y\rvert\rvert_{2}=1}\lvert\lvert Ay\rvert\rvert}.

Note that when the matrix does not have full column rank the denominator becomes
0
and hence the condition number is undefined, so whenever we discuss the condition-number we assume that we are working with matrices that have full column-rank. For a square invertible matrix
A
we get that
\kappa(A)=\frac{\sigma_{1}}{\sigma_{n}}
, where
\sigma_{i}
is the
i^{th}
singular value.

We use the term well-conditioned to refer to a matrix with
\text{poly}(n)
condition-number.

3
Proof of Main Reduction (Theorem
1.2
)

In this section we will prove the reduction from the rank-finding problem to the approximate version of the linear decision problem. For simplicity, throughout this section we work on the RealRAM model of computation and wherever we do not state it we assume that this is the case, so we
do not
discuss the bit complexity of the reductions. Our reduction can be modified to work on the WordRAM which we do in Section
6
.

Theorem 3.1

(Restatement of Theorem
1.2
)
.

For all constants
c>0
, there exists a randomized Turing reduction in the RealRAM model of computation, from the rank-finding problem on
A\in\mathbb{R}^{m\times n}
to the
(1-1/n^{c})
-Approximate linear decision problem on
(A^{\prime}\in{\mathbb{R}}^{n^{\prime}\times n^{\prime}},\mathbf{1}^{n^{\prime}})
, with dimension
n^{\prime}=O(\max(m,n))
and sparsity
\tilde{O}(\text{nnz}(A))
, where in the YES case we have the additional property that the matrices produced have full rank. The reduction runs in time
\tilde{O}(\text{nnz}(A))
, produces
\text{polylog}(mn)
instances of the approximate linear decision problem and works with high probability.

We will prove this reduction in three steps:

1.

Lemma
3.5
: Rank-Finding Problem
\leq_{T}
Full Rank problem (see Definition
3.2
)

2.

Lemma
3.6
: Full Rank problem
\leq_{T}

(1/n^{O(1)})
-Approximate linear decision problem

3.

Lemma
3.7
:
1/n^{O(1)}
-Approximate linear decision problem
\leq

(1-1/n^{c})
-Approximate linear decision problem

Given the lemmas, it will be straightforward to combine these reductions to get that the linear decision problem reduces to the
(1-1/n^{c})
-Approximate linear decision problem.
Let us now show each of the steps stated above. We will prove the first reduction from the rank-finding problem to the full-rank problem. This is similar to a reduction by Wiedemann
[
Wie86
]
for finite fields. Let us formally introduce the Full rank problem.

Definition 3.2

(Full Rank Problem.)
.

Given a matrix
A\in{\mathbb{R}}^{n\times n}
, is
\text{rank}(A)=n
?

The intuition behind the following reduction from the rank-finding problem to the full-rank problem is the following: For a matrix
A\in{\mathbb{R}}^{m\times n}
with
m>n
and
\text{rank}(A)=k<n
, adding
t
“random” columns will give a full column rank matrix if and only if
t\geq n-k
. Hence we can binary search for the first value of
t
which gives us a full column rank matrix, yielding
k
.

We start by showing that adding a random column to a (non full column rank) matrix increases the dimension of its column space by
1
with high probability. To maintain the sparsity of the initial matrix, we add random sparse Gaussian vectors. This is similar to a reduction by Wiedemann
[
Wie86
]
for finite fields.

Lemma 3.3
.

Let
M\in{\mathbb{R}}^{m\times n}
be a matrix of rank
\geq r
. Then there exists a sampling procedure to sample
z\in{\mathbb{R}}^{m}
, with
\text{nnz}(z)=\min(m,m\log^{2}(m)/(m-r+1))
, that runs in time
\tilde{O}(\text{nnz}(z))
, such that the matrix
B=[M~z]
has
\text{rank}(B)\geq\min(r+1,m)
whp.

Proof.

Let
s=\min(m,m\log^{2}(m)/(m-r+1))
. If
s=m
let
S=[m]
, otherwise randomly choose
S\subseteq[m]
, by sampling
s
coordinates from
[m]
with replacement. If
i\notin S
, then set
z_{i}=0
, else sample it from
\mathcal{N}(0,1)
.

Now consider the matrix
B=[M~z]
. Suppose that
\text{rank}(M)\geq\min(r+1,m)
, then we already have that
\text{rank}(B)\geq\text{rank}(M)\geq\min(r+1,m)
. So we need to only prove that when
\text{rank}(M)=r<m
, then this procedure gives
\text{rank}(B)\geq r+1
. This is equivalent to proving that
z\notin\text{colspace}(M)
.

Let
W
be the orthogonal subspace to
\text{colspace}(M)
.
W
has dimension
m-r>0
and for all vectors
w\in W,u\in\text{colspace}(M)
,
\langle w,u\rangle=0
. We will prove that with large probability there exists a vector
v\in W
, such that
\langle v,z\rangle>0
, which implies that
z\notin\text{colspace}(M)
.

Since
\text{rank}(W)=m-r
, by Lemma
3.4
there exists vector
v\in W
which is non-zero on at least
m-r
coordinates. Let
G
denote the set of coordinates where
v
is non-zero with
\lvert G\rvert\geq m-r
.

Since
S
(the set of non-zero coordinates of
z
) is a large enough random set of coordinates, one can prove that
S,G
have a non-zero intersection. Formally,

\displaystyle\Pr[S\cap G=\phi]

\displaystyle=\left(\Pr_{i\sim[m]}[i\not\in G]\right)^{\lvert S\rvert}

\displaystyle\leq\left(r/m\right)^{m\log^{2}(m)/(m-r+1)}

\displaystyle\leq\frac{1}{m^{\log m}}.

Let us now consider the inner product between
z,v
. We have that,
\langle z,v\rangle=\sum_{i\in S\cap G}z_{i}v_{i}
, is a Gaussian random variable with non-zero variance if
S\cap G\neq\phi
, which implies that
\langle z,v\rangle\neq 0
whp. This implies that
z\notin\text{colspace}(M)
, and the matrix
B=[M~z]
has rank equal to
\min(r+1,m)
whp.
∎

Lemma 3.4
.

Let
W\subseteq\mathbb{R}^{n}
be a vector space of dimension
d
. Then there exists a vector
v\in W
such that
v
has non-zero entries on at least
d
coordinates.

Proof.

Since
\text{rank}(W)=d
, there exists vectors
v_{1},\ldots,v_{j}\in W
such that
G=\{k\mid\exists i(v_{i})_{k}\neq 0\}
satisfies
\lvert G\rvert\geq m-r
, else
W
would be a subset of
{\mathbb{R}}^{<m-r}
. We can now take a random linear combination of these vectors to get a vector that is non-zero on every coordinate in
G
. Consider the vector
v=\sum_{i}x_{i}\cdot v_{i}
, where each
x_{i}\sim\mathcal{N}(0,1)
. Using property
4
of Lemma
2.4
, we get that for every coordinate
j\in G
,
v_{j}
, is a Gaussian with zero mean and non-zero variance, hence the probability that it is zero is a measure-zero set. A union bound over all coordinates in
G
, gives us that whp,
v
in nonzero on all coordinates in
G
. From now on we assume that this is the case (as otherwise we can consider the reduction to have failed).
∎

We will now prove the reduction from Rank-Finding problem to the Full Rank problem.

Lemma 3.5
.

There exists a randomized Turing reduction which works w.h.p. from the Rank-Finding problem on
A\in{\mathbb{R}}^{m\times n}
to the Full rank problem, that runs in time
\tilde{O}(\text{nnz}(A))
and produces
O(\log m)
instances of the Full rank problem, such that all instances of the matrices produced have dimension
O(\max(m,n))\times O(\max(m,n))
and sparsity
\tilde{O}(\text{nnz}(A))
.

Proof.

Consider the linear system
Ax=b
. We will show that deciding whether there exists a satisfying solution reduces to the Full rank problem through the following sequence of reductions:

Linear System Decision
\leq_{T}
Rank-Finding Problem
\leq_{T}
Rank-Decision Problem
\leq_{T}
Full Column Span
\leq_{T}
Full Rank Problem

We will show that each of these steps preserves the sparsity of the matrix. Let us now describe every reduction above:

1.

Suppose we want to check satisfiability of
Ax=b
. Consider the matrix
A^{\prime}=[A~~b~]
, i.e. the matrix formed by appending the column vector
b
to the matrix
A
. The system
Ax=b
has a solution if and only if
rk(A)=rk(A^{\prime})
, so it suffices to find the rank of the matrices
A,A^{\prime}
. Hence we have reduced the linear system decision problem to the Rank-Finding Problem. Also note that
\text{nnz}(A^{\prime})=s+m=O(\text{nnz}(A))
as
\text{nnz}(A)\geq m
.

2.

Suppose we want to find the rank of a matrix
M\in{\mathbb{R}}^{m\times n}
. One can see that the rank of
M
is the largest integer
k\in[m]
for which
\text{rank}(M)\geq k
. Consider the Rank-Decision problem: Given a matrix
M
, is
\text{rank}(M)\geq k
or
<k
? Thus to find rank of
M
one can do a binary search over
k\in[m]
, to find the largest
k
for which
\text{rank}(M)\geq k
, using
\log m
calls to the rank-decision problem.

3.

Given a matrix
M\in{\mathbb{R}}^{m\times n}
, suppose we want to check if
\text{rank}(M)\geq k
or
<k
. From Lemma
3.3
, we know that if
\text{rank}(M)\geq k
, and we added a random vector
z_{1}
sampled according to the procedure therein, the rank of the new matrix
B_{1}=[M~z_{1}]
will be
\geq\min(r+1,m)
whp. The lemma gives us that the sparsity of
z_{1}
is
\min(m,m\log^{2}m/(m-k+1))
. Similarly, consider the matrix
B_{m-k}=[M~z_{1}~\ldots~z_{m-k}]
, where each
z_{i}
is sampled according to the sampling procedure in Lemma
3.3
and
\text{nnz}(z_{i})=\min(m,m\log^{2}m/(m-k-i+2))
. One can prove by a union bound on
i
, that whp, if the rank of matrix
B
was
\geq\min(k,m)
then the rank of each intermediate matrix
B_{i}
is
\geq\min(k+i,m)
whp, and hence
\text{rank}(B_{m-k})\geq\min(k+m-k,m)=m
, that is,
B_{m-k}
has full column span.

On the other hand, if
\text{rank}(B)<k
, then since we have appended only
m-k
vectors in creating
B_{m-k}
, the rank of
B_{m-k}<m
.

Hence to check if
\text{rank}(M)\geq k
or not, it suffices to check if
\text{rank}(B_{m-k})=m
or not. Note that the sparsity of
B_{m-k}
is
\text{nnz}(M)+\sum_{i}\text{nnz}(z_{i})\leq\text{nnz}(M)+m\log^{2}m\sum_{i\in[m]}1/i=\text{nnz}(M)+\tilde{O}(m)=\tilde{O}(\text{nnz}(M))
.

4.

Given a matrix
M\in{\mathbb{R}}^{m\times n}
, suppose we want to check if
\text{rank}(M)=m
or
<m
, i.e. does it have Full column span or not. The problem is trivial if
m>n
as then the rank of the matrix is
\leq n
and the instance is a NO instance. So we will assume that
m\leq n
. In this case, similar to the reduction above we will add rows
z_{1},z_{2},\ldots,z_{m-n}
. One can prove that this preserves sparsity and creates a full rank matrix whp if
\text{rank}(M)=m
to begin with.

Since each step succeeds whp, we can take a union bound over all steps to say that the whole reduction succeeds whp. Then we can compose all the reductions to get that the Linear system decision problem reduces to
O(\text{poly}\log m)
instances of the Full rank problem.
∎

We will now prove that the full rank problem reduces to the
(1/n^{O(1)})
-Approximate linear decision problem. As we will see in section
8
the full-rank problem is equivalent to the linear decision problem. Hence we can think of the next step as reducing the linear decision problem to the
(1/n^{O(1)})
-Approximate linear decision problem i.e. increasing an arbitrarily small gap between the YES and NO cases to an inverse-polynomial gap.

The idea behind the proof is that for a full-rank square matrix
A\in\mathbb{R}^{n\times n}
every vector
b\in\mathbb{R}^{n}
belongs in the column space of
A
and hence the linear system
(A,b)
is satisfiable.
On the other hand if
\text{rank}(A)<n
we expect a random vector
b
to be outside the column space of
A
and hence we expect the linear system
(A,b)
to be unsatisfiable.
We show a strengthened version of the previous statement by proving that w.h.p. for a random Gaussian vector
b
, it holds that for all
x
,

\lvert\lvert Ax-b\rvert\rvert\geq{\varepsilon}(n)\lvert\lvert b\rvert\rvert

for some
{\varepsilon}(n)=1/n^{O(1)}
.
We also show that we can rescale the rows of the linear system
(A,b)
to get the system
(A^{\prime},\mathbf{1}^{n})
while maintaining the property that
\lvert\lvert A^{\prime}x-\mathbf{1}^{n}\rvert\rvert\geq{\varepsilon}(n)\lvert\lvert\mathbf{1}^{n}\rvert\rvert
. We perform the rescaling to obtain
b=\mathbf{1}^{n}
as that will simplify our later reductions.

Lemma 3.6
.

Consider a matrix
M\in{\mathbb{R}}^{n\times n}
. There exists a randomized Turing reduction from the problem of checking whether
M
has full rank to the Linear Decision
(1/n^{O(1)})
-Approximation problem. The reduction runs in time
\tilde{O}(\text{nnz}(M))
, produces
\text{polylog}(n)
instances of the form
(M^{\prime}\in\mathbb{R}^{n\times n},\mathbf{1}^{n})
where in the YES case
M^{\prime}
is a full rank matrix, and works w.h.p.

Proof.

Let
M
be an
n\times n
matrix, and suppose that we need to check if it has full rank or not. We will reduce this problem to a linear system, by sampling a random vector
b\sim\mathcal{N}(0,1/n)^{n}
and checking satisfiability of the linear system
(M,b)
. We will now show the following properties:

1.

When
M
has full rank, then the linear system is satisfiable i.e. there exists an
x
such that
Mx=b
.

2.

When
M
does not have full rank, then for all
x\in{\mathbb{R}}^{n}
,
\lvert\lvert Mx-b\rvert\rvert_{2}\geq\lvert\lvert b\rvert\rvert/n^{12}
w.p.
1-O(1/\sqrt{n})
.

Property
1
above holds for the linear system since
M
has full column span if it has full rank, which means that
Mx=b
is satisfiable for all
b\in{\mathbb{R}}^{n}
. We will now prove Property
2
, by showing that w.p.
1-O(1/\sqrt{n})
,
b
has a large component in
\text{colspace}(M)^{\perp}
i.e. the subspace orthogonal to
\text{colspace}(M)
.

If
M
does not have full rank, then
\text{rank}(\text{colspace}(M))<n
. Let
V=\text{colspace}(M)
and
W=V^{\perp}
; since
V
has dimension
<n
, we have that
\dim(W)\geq 1
. So there exists a unit vector
w\in{\mathbb{R}}^{n}
, with
\lvert\lvert w\rvert\rvert=1
, such that
\langle w,a\rangle=0,\forall a\in\text{colspace}(M)
. From Lemma
2.6
, we have that any solution
x\in{\mathbb{R}}^{n}
will have error,
\lvert\lvert Mx-b\rvert\rvert\geq\lvert\lvert P_{W}(b)\rvert\rvert\leq\lvert\langle w,b\rangle\rvert
as
w\in W
and
w
is a unit vector. As
b\sim\mathcal{N}(0,1/n)^{n}
we have that
\langle w,b\rangle
is distributed as the Gaussian
\mathcal{N}(0,\lvert\lvert w\rvert\rvert_{2}^{2}/n)=\mathcal{N}(0,1/n)
by Lemma
2.4
. So we should expect
|\langle w,b\rangle|\approx 1/\sqrt{n}\approx\lvert\lvert b\rvert\rvert/\sqrt{n}
. Indeed we have that,

\displaystyle\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{\lvert\lvert b\rvert\rvert}{n^{2}}\right]

\displaystyle\leq\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{\lvert\lvert b\rvert\rvert}{n^{2}}\mathrel{\Big|}\lvert\lvert b\rvert\rvert\leq n\right]+\Pr[\lvert\lvert b\rvert\rvert\geq n]

\displaystyle\leq\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{1}{n}\right]+\Pr[\lvert\lvert b\rvert\rvert^{2}\geq n^{2}]

\displaystyle\leq\frac{\sqrt{n}}{n}+\Pr[\lvert\lvert b\rvert\rvert^{2}\geq n^{2}]\hskip 10.0pt\text{ Using property~\ref{prop:gp1} of Lemma~\ref{lem:gaussian}}

\displaystyle\leq\frac{1}{\sqrt{n}}+\frac{1}{n^{2}}\hskip 10.0pt\text{ Using property~\ref{prop:gp3} of Lemma~\ref{lem:gaussian}}

\displaystyle\leq O\left(\frac{1}{\sqrt{n}}\right)

which proves property
2
.

We have now reduced the Full column rank problem to the linear system
(M,b)
, such that in the YES case, we have that
Mx=b
and in the NO case, we have a gap of
1/n^{2}
. We will now show that one can reduce to a linear system
(M^{\prime},\mathbf{1}^{n})
. To get the
i^{th}
row of
M^{\prime}
, scale the
i^{th}
row of
M
by
1/b_{i}
, that is,
M^{\prime}_{ij}=M_{ij}/b_{i}
(we can do this as
b_{i}\neq 0
whp). It is easy to see that if there was a solution
x
for which
Mx=b
, then we also have that
M^{\prime}x=\mathbf{1}^{n}
.

We will now show that in the NO case, if for all
x\in{\mathbb{R}}^{n}
, we had that
\lvert\lvert Mx-b\rvert\rvert\geq\lvert\lvert b\rvert\rvert/n^{2}
, then for all
x\in{\mathbb{R}}^{n}
it holds that
\lvert\lvert M^{\prime}x-\mathbf{1}^{n}\rvert\rvert\geq\lvert\lvert\mathbf{1}^{n}\rvert\rvert/n^{12}
. First note that, by the properties of Gaussians in Lemma
2.4
, w.p.
\geq 1-O(1/\sqrt{n})
, every
b_{i}
satisfies
1/n^{2}\leq\lvert b_{i}\rvert\leq n^{2}
. Note the if one of these conditions is not satisfied we can just consider our reduction to have returned the wrong answer. This adds
O(1/\sqrt{n})
to our error probability which now in total is
O(1/\sqrt{n})+O(1/\sqrt{n})=O(1/\sqrt{n})
. Assuming every
b_{i}
satisfies
1/n^{2}\leq\lvert b_{i}\rvert\leq n^{2}
we have the following sequence of inequalities:

\displaystyle\lvert\lvert M^{\prime}x-\mathbf{1}^{n}\rvert\rvert_{2}^{2}

\displaystyle=\sum_{i}((M^{\prime}x)_{i}-1)^{2}

\displaystyle=\sum_{i}\frac{1}{b_{i}^{2}}((Mx)_{i}-b_{i})^{2}

\displaystyle\geq\frac{1}{n^{4}}\lvert\lvert Mx-b\rvert\rvert_{2}^{2},~~~~~~~\text{since }\forall i,|b_{i}|\leq n^{2}

\displaystyle\geq\frac{\lvert\lvert b\rvert\rvert^{2}}{n^{8}}

\displaystyle\geq\frac{\lvert\lvert\mathbf{1}^{n}\rvert\rvert^{2}}{n^{12}},~~~~~~~\text{since }\forall i,|b_{i}|\geq 1/n^{2},

which implies that for all
x\in{\mathbb{R}}^{n}
,
\lvert\lvert M^{\prime}x-\mathbf{1}^{n}\rvert\rvert\geq\lvert\lvert\mathbf{1}^{n}\rvert\rvert/n^{12}
.

This randomized algorithm currently works with probability
1-O(1/\sqrt{n})
; one can amplify the success probability to
1-1/n^{\log n}
by
\text{polylog}(n)
calls to the
(1/n^{12})=(1/n^{O(1)})
-approximate linear decision problem.
∎

We will now show that one can amplify the error in the NO case from
1/n^{O(1)}
to
1-1/n^{c}
for all constants
c
.

The following lemma works for all
{\varepsilon}(n),\delta(n)
, but we only state it for
{\varepsilon}(n)=1/n^{O(1)},\delta(n)=1/n^{c}
to maintain consistency with the later sections in which we will work over WordRAM.

Lemma 3.7
.

For all constants
c
and
{\varepsilon}(n)=1/n^{O(1)},\delta(n)=1/n^{c}
, there exists a deterministic many-one reduction from the
{\varepsilon}(n)
-Approximate linear search problem on the linear system
(A\in{\mathbb{R}}^{n\times n},\mathbf{1}^{n})
to the
(1-\delta(n))
-Approximate linear search problem on the linear system
(A^{\prime}\in{\mathbb{R}}^{n\times n},\mathbf{1}^{n})
, with
\text{nnz}(A^{\prime})=O(\text{nnz}(A))
. The reduction runs in time
\tilde{O}(\text{nnz}(A))
. Additionally if
A
is full rank then the matrix
A^{\prime}
produced is also full rank.

As this is a deterministic many-one reduction we also get a gap-amplifying reduction for the
{\varepsilon}(n)
-Approximate linear decision problem with the same parameters.

Proof.

We create the new linear system
(A^{\prime}\in{\mathbb{R}}^{n\times n},\mathbf{1}^{n})
, by combining equations from the linear system
(A,b)
in a cyclic manner. Let the vectors
a_{i}
’s be the rows of
A
. Then, create the
i^{th}
-equation in the new linear system as follows:

(t+1)\langle a_{i},x\rangle-t\langle a_{i+1},x\rangle=1,

where the addition wrt
i
is modulo
n
.

It is easy to see that that any
x
which satisfies the original linear system
(A,\mathbf{1}^{n})
also satisfies the new linear system
(A^{\prime},\mathbf{1}^{n})
. We have that
A^{\prime}=M\cdot A
, where
M\in{\mathbb{R}}^{n\times n}
, and

M=\begin{bmatrix}(t+1)&-t&0&\ldots&0&0\\
0&(t+1)&-t&\ldots&0&0\\
0&0&(t+1)&\ldots&0&0\\
&&&\vdots&\\
0&0&0&\ldots&(t+1)&-t\\
-t&0&0&\ldots&0&(t+1)\\
\end{bmatrix}

i.e.
M_{ii}=t+1
,
M_{i,i+1}=-t
and
M_{ij}=0
otherwise. It is easy to check that
M
has full rank. Hence if
A
had full rank then so does

4.4

In this section, we show conditional hardness of approximately solving well-conditioned linear systems. The condition number of a full-rank square matrix is the ratio of its maximum and minimum eigenvalues (see Definition
2.3
). If the entries of a matrix are all
O(\log n)
-bits then the condition number of this matrix is at most exponential in
n
(this is true even for rectangular full column-rank matrices). Therefore linear systems over matrices with polynomially-bounded condition number could be significantly easier to solve than general linear systems.

For the case of certain restricted classes of matrices such as directed Laplacians, the algorithm of Cohen et al
[
CKK+18
]
for the
{\varepsilon}(n)
-approximate linear search problem runs in time
\tilde{O}(\text{nnz}(A)\log({\kappa}(A)/{\varepsilon}(n)))
which is a near-linear time algorithm for
{\kappa}(A)=\text{poly}(n)
. This is a significant improvement over algorithms for directed Laplacian systems with no bound on the condition number (which run in time
\tilde{O}(n^{\omega})
).

But for general systems no such improvement is known!
Conjugate gradient
[
HS52
]
runs in time
\tilde{O}(\text{nnz}(A))
, when
\kappa(A)=\text{poly}\log n
, whereas when
\kappa(A)=\text{poly}(n)
this algorithm gives
no improvement
over the algorithm for general matrices.

We show that if we assume that the rank-finding problem is hard over well-conditioned matrices (

4.14
and
4.15
that our main reduction (Theorem
3.1
) in fact preserves the condition number of our original matrix. Then as a corollary we obtain the conditional hardness for approximately solving well-conditioned linear systems. Note that we show all the results here over the RealRAM but they can be easily modified to work on the WordRAM too.

Property
1
above holds for the linear system since
M
has full column span if it has full rank, which means that
Mx=b
is satisfiable for all
b\in{\mathbb{R}}^{n}
. We will now prove the second point, by showing that w.p.
1-O(1/\sqrt{n})
,
b
has a large component in
\text{colspace}(M)^{\perp}

If
M
does not have full rank, then
\text{rank}(\text{colspace}(M))<n
. Let
V=\text{colspace}(M)
and
W=V^{\perp}
; since
V
has dimension
<n
, we have that
\dim(W)\geq 1
. So there exists a unit vector
w\in{\mathbb{R}}^{n}
, with
\lvert\lvert w\rvert\rvert=1
, such that
\langle w,a\rangle=0,\forall a\in\text{colspace}(M)
. From Lemma
2.6
, we have that any solution
x\in{\mathbb{R}}^{n}
will have error,
\lvert\lvert Mx-b\rvert\rvert\geq\lvert\lvert P_{W}(b)\rvert\rvert\geq\lvert\langle w,b\rangle\rvert
as
w\in W
and
w
is a unit vector. For large
N
, we expect that the distribution of
\langle w,b\rangle
is near to the Gaussian
\mathcal{N}(0,\lvert\lvert w\rvert\rvert_{2}^{2}/n)=\mathcal{N}(0,1/n)
by Lemma
2.4
. So we should expect
|\langle w,b\rangle|\approx 1/\sqrt{n}\approx\lvert\lvert b\rvert\rvert/\sqrt{n}
. Define
e=b-b^{\prime}
and note that for all
i
,
\lvert e_{i}\rvert\leq 1/N
. Calculating exactly we get that
\langle w,b\rangle=\langle w,b^{\prime}\rangle+\langle w,e^{\prime}\rangle
. This implies that
\langle w,b^{\prime}\rangle-\sqrt{n}/N\leq\langle w,b\rangle\leq\langle w,b^{\prime}\rangle+\sqrt{n}/N
.

\displaystyle\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{\lvert\lvert b\rvert\rvert}{n^{2}}\right]

\displaystyle\leq\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{\lvert\lvert b\rvert\rvert}{n^{2}}\mathrel{\Big|}\lvert\lvert b\rvert\rvert\leq n\right]+\Pr[\lvert\lvert b\rvert\rvert\geq n]

\displaystyle\leq\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{1}{n}\right]+\Pr[\lvert\lvert b\rvert\rvert^{2}\geq n^{2}]

\displaystyle\leq\Pr\left[\lvert\langle w,b^{\prime}\rangle+\langle w,e\rangle\rvert\leq\frac{1}{n}\right]+\Pr[\lvert\lvert b^{\prime}\rvert\rvert^{2}+\lvert\lvert e\rvert\rvert^{2}\geq n^{2}]

\displaystyle\leq\Pr\left[\lvert\langle w,b^{\prime}\rangle\rvert\leq\frac{1}{n}+\frac{\sqrt{n}}{N}\right]+\Pr[\lvert\lvert b^{\prime}\rvert\rvert^{2}\geq n^{2}-\frac{\sqrt{n}}{N}]\hskip 20.0pt\text{[As $\lvert e_{i}\rvert\leq 1/N$]}

\displaystyle\leq\Pr\left[\lvert\langle w,b\rangle\rvert\leq\frac{2}{n}\right]+\Pr[\lvert\lvert b\rvert\rvert^{2}\geq n^{2}/2]

\displaystyle\leq\frac{2\sqrt{n}}{n}+\Pr[\lvert\lvert b\rvert\rvert^{2}\geq n^{2}/2]\hskip 10.0pt\text{ Using property~\ref{prop:gp1} of Lemma~\ref{lem:gaussian}}

\displaystyle\leq\frac{2}{\sqrt{n}}+\frac{2}{n^{2}}\hskip 10.0pt\text{ Using property~\ref{prop:gp3} of Lemma~\ref{lem:gaussian}}

\displaystyle\leq O\left(\frac{1}{\sqrt{n}}\right)

which proves property
2
.

The rest of the proof of this lemma proceeds in the same way as the proof of Lemma
3.6
.
∎

Finally we reduce the
(1/n^{O(1)})
-Linear Decision Approximation problem to the
(1-1/n^{c})
-Linear Decision Approximation problem over WordRAM. This is straightforward to work out from the analogous Lemma
3.7
in Section
4
.

Lemma 6.8
.

For all constants
c
and
{\varepsilon}(n)=1/n^{O(1)},\delta(n)=1/n^{c}
, there exists a deterministic many-one reduction from the
{\varepsilon}(n)
-Approximate linear search problem on the linear system
(A\in{\mathbb{R}}^{n\times n},\mathbf{1}^{n})
to the
(1-\delta(n))
-Approximate linear search problem on the linear system
(A^{\prime}\in{\mathbb{R}}^{n\times n},\mathbf{1}^{n})
, with
\text{nnz}(A^{\prime})=O(\text{nnz}(A))
. The reduction runs in time
\tilde{O}(\text{nnz}(A))
. Additionally if
A
is full rank then the matrix
A^{\prime}
produced is also full rank.

As this is a deterministic many-one reduction we also get a gap-amplifying reduction for the
{\varepsilon}(n)
-Approximate linear decision problem with the same parameters.

Proof Sketch.

The only operation that is performed in the proof of Lemma
3.7
is that the matrix
A
is multiplied with the “
M
” matrix. As the entries of
M
are of the order
n/({\varepsilon}(n)\delta(n))
our final bit complexity increases by an additive factor of
O(\log(n/({\varepsilon}(n)\delta(n))))
.

∎

Now we are ready to prove Lemma
6.4
.

Proof of Lemma
6.4
.

Similar to the proof of Theorem
1.2
, The proof follows by composing Lemma
6.6
, Lemma
6.7
and Lemma
6.8
(for
{\varepsilon}(n)=1/n^{O(1)}
and
\delta(n)=1/n^{c}
). The bit complexity of the final matrix is
O(\log n)+O(\log(n/({\varepsilon}(n)\delta(n))))=O((c+1)(\log n))
and the running time is

∎

To prove Corollary
6.2
we need the following decision to search reduction:

Lemma 6.9
.

Let
{\varepsilon}(n)=1/n^{O(1)}
, given an
A\in{\mathbb{Z}}^{m\times n},x,b
where
m=O(n),\mathcal{B}(A),\mathcal{B}(b)=\text{polylog}(n),\mathcal{B}(x)=\tilde{O}(n)
we can distinguish between:

1.

\lvert\lvert Ax-b\rvert\rvert\leq{\varepsilon}(n)\lvert\lvert b\rvert\rvert/2
.

2.

\lvert\lvert Ax-b\rvert\rvert\geq{\varepsilon}(n)\lvert\lvert b\rvert\rvert
.

w.h.p. in time
\tilde{O}(\text{nnz}(A)n)
.

Proof.

We start by noting that unlike the analogous decision-to-search reduction (Lemma
4.1
) in RealRAM we cannot proceed by directly evaluating
\lvert\lvert Ax-b\rvert\rvert
exactly as that would take time
\tilde{O}(\text{nnz}(A)n^{2})
in WordRAM as we are only given that
\mathcal{B}(x)=O(n)
. But we do not need to evaluate
\lvert\lvert Ax-b\rvert\rvert
exactly even approximately evaluating will be sufficient as long as the error is
<{\varepsilon}(n)\lvert\lvert b\rvert\rvert/2
.

For any
w
with entries of the form
a/N
where
a\in{\mathbb{Z}}
and
N=n^{6}
we can evaluate
\langle Ax-b,w\rangle=(wA)x-wb
in time
O(n\text{nnz}(A)
by first computing
u\coloneqq wA
and then evaluating
ux-vb
. We are able to get around
\tilde{O}(n^{3})
runtime as
x
is being only multiplied to a
1\times n
vector rather than a
n\times n
matrix.

To approximately evaluate
\lvert\lvert Ax-b\rvert\rvert
we will make use of the standard fact (from Lemma
2.4
) that for
v\sim\mathcal{N}(0,1/m)^{m}
we have
\langle Ax-b,v\rangle\sim\mathcal{N}(0,\lvert\lvert Ax-b\rvert\rvert^{2})
. We will sample
v_{1},v_{2},\ldots,v_{t}
i.i.d. from
\mathcal{N}(0,1/m)^{m}
, then by Lemma 1 of
[
LM00
]
we have that

\Pr\left[\left\lvert\sum\limits_{i=1}^{t}\langle Ax-b,v_{i}\rangle^{2}-t\cdot\lvert\lvert Ax-b\rvert\rvert^{2}\right\rvert>\lvert\lvert Ax-b\rvert\rvert^{2}(2\sqrt{tz}+2z)\right]\leq 2\cdot exp(-z).

Hence at
t=\log^{6}(n)
and
z=\log^{3}(n)
we have that w.h.p. (
\geq 1-1/n^{\log n}
)

\left\lvert\sum\limits_{i=1}^{t}\langle Ax-b,v_{i}\rangle^{2}-t\cdot\lvert\lvert Ax-b\rvert\rvert^{2}\right\rvert\leq\lvert\lvert Ax-b\rvert\rvert^{2}t/(\log n).

Let
w_{i}
be the vector obtained by rounding each entry of
v_{i}
to the nearest fraction of the form
a/N
where
N=n^{6}
. Then
\lvert\lvert v_{i}-w_{i}\rvert\rvert\leq 1/n^{5}
and hence

\left\lvert\sum\limits_{i=1}^{t}\langle Ax-b,w_{i}\rangle^{2}-t\cdot\lvert\lvert Ax-b\rvert\rvert^{2}\right\rvert\leq\lvert\lvert Ax-b\rvert\rvert^{2}t/(\log n)+\lvert\lvert Ax-b\rvert\rvert^{2}t/n\leq 2\lvert\lvert Ax-b\rvert\rvert^{2}t/(\log n).

Hence if
\lvert\lvert Ax-b\rvert\rvert\leq{\varepsilon}(n)\lvert\lvert b\rvert\rvert/2
we have that w.h.p.

\sum\limits_{i=1}^{t}\langle Ax-b,w_{i}\rangle^{2}\leq t\cdot{\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2}/4+2({\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2}/4)(t/(\log n))\leq t\cdot{\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2}/3.

On the other hand, if
\lvert\lvert Ax-b\rvert\rvert\geq{\varepsilon}(n)\lvert\lvert b\rvert\rvert
we have that w.h.p.

\sum\limits_{i=1}^{t}\langle Ax-b,w_{i}\rangle^{2}\geq t\cdot{\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2}-2({\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2})(t/(\log n))\geq t\cdot{\varepsilon}^{2}(n)\lvert\lvert b\rvert\rvert^{2}/2.

Hence we can distinguish between the two cases w.h.p in time
\tilde{O}(n\text{nnz}(A))
(as
t=\text{polylog}(n)
).

∎

Combining Lemma
6.4
and Lemma
6.9
give us Corollary
6.2
:

Proof of Corollary
6.2
.

For all constants
c
, Composing Conjecture
4
and Lemma
6.4
gives us
\tilde{\Omega}(n^{\omega})
hardness of
(1-1/n^{c})
-Approximate linear decision problem
(A\in{\mathbb{Z}}^{n\times n},b)
with bit complexity
O((c+1)\log(n))
where in the YES case we have the additional property that
A
has full rank. The hardness of
(1-1/n^{c})
-Approximate linear search problem with the same properties follows from the decision to search reduction from Lemma
6.9
.
∎

Starting from the WordRAM version of Conjecture

and using Lemma

we can establish that there does not exist a

7
Different notions of approximation

Our notion of “Linear Search
\epsilon
-Approximation problem” is easier than how the notion of approximately solving is usually defined
[
ST14
,
KZ17
]
:

Definition 7.1

(Linear System Approximation Problem)
.

Given a satisfiable linear system
(A\in{\mathbb{R}}^{m\times n},b\in{\mathbb{R}}^{m})
find an
x\in{\mathbb{R}}^{n}
such that:

\lvert\lvert Ax-\Pi_{A}(b)\rvert\rvert_{2}\leq\epsilon\lvert\lvert\Pi_{A}(b)\rvert\rvert_{2},

where
\Pi_{A}(b)
denotes the projection of the vector
b
onto the column space of
A
.

The above notion considers general linear systems rather then just satisfiable ones. For satisfiable linear systems their notion is equivalent to ours as in that case
\Pi_{a}(b)=b
. As we give conditional hardness for “Linear Search
\epsilon
-Approximation” this directly implies hardness for “Linear System Approximation Problem” (referred to as LSA in Kyng and Zhang
[
KZ17
]
). On the other hand, our
\tilde{\Omega}(n^{\omega})
hardness is tight even for finding a
x
such that
\lvert\lvert Ax-\Pi_{A}(b)\rvert\rvert_{2}=0
as we can do that in time
O(n^{\omega})

[
IMH82
]
by computing the pseudoinverse.

8
Equivalent Characterization of Our Conjectures

We will now prove that the Linear decision problem, the Rank-finding problem and the full rank problem are all equivalent. Thus our conjectures about hardness of Rank-Finding can be interpreted as hardness of any of these problems.

Lemma 8.1
.

There exists randomized turing reductions (to upto
\text{polylog}(n)
instances) in RealRAM which work w.h.p. between the following problems:

1.

Linear Decision Problem: Given
(A,b)
with
A\in\mathbb{R}^{O(n)\times O(n)}
with
\text{nnz}(A)=z+\tilde{O}(n)
does there exist a
x
such that
Ax=b
.

2.

Rank-Finding Problem: Given
B\in\mathbb{R}^{O(n)\times O(n)}
with
\text{nnz}(B)=z+\tilde{O}(n)
find
\text{rank}(B)
.

3.

Full-Rank Problem: Given
C\in\mathbb{R}^{n^{\prime}\times n^{\prime}}
with
n^{\prime}=O(n),\text{nnz}(C)=z+\tilde{O}(n)
, is
\text{rank}(C)=n^{\prime}
? or equivalently is the determinant of
C
non-zero.

Proof.

We have already reduced the Rank-Finding problem to the Full Rank problem in Lemma
3.5
and Full-Rank Problem to Linear Decision Problem in Lemma
3.6
while preserving sparsity in both the reductions.

We now reduce Linear Decision Problem to the Rank-Finding Problem.
Suppose we want to check satisfiability of the linear system
(A,b)
. Consider the matrix
A^{\prime}=[A~~b~]
, i.e. the matrix formed by appending the column vector
b
to the matrix
A
. The system
(A,b)
has a solution if and only if
rk(A)=rk(A^{\prime})
, so it suffices to find the rank of the matrices
A,A^{\prime}
. Hence we have reduced the linear system decision problem to the Rank-Finding Problem. Also note that
\text{nnz}(A^{\prime})=z+m=z+O(n)
.
∎

In fact as Theorem
1.2
reduces Rank-Finding problem to
(1-\delta(n))
-Approximate linear decision problem for all
\delta(n)>0
which is a subcase of linear decision problem. Hence we get that
(1-\delta(n))
-Approximate linear decision problem for all
\delta(n)>0
is also equivalent to the all three problems in Lemma
8.1
.

A similar equivalence exists in WordRAM:

Lemma 8.2
.

There exists randomized turing reductions (to upto
\text{polylog}(n)
instances) in RealRAM which work w.h.p. between the following problems:

1.

(A,b)
with
A\in\mathbb{Z}^{O(n)\times O(n)},\text{nnz}(A)=z+\tilde{O}(n),\mathcal{B}(A),\mathcal{B}(b)=O(\log n)
does there exist a
x
such that
Ax=b
.

2.

Rank-Finding Problem: Given
B\in\mathbb{Z}^{O(n)\times O(n)}
with
\text{nnz}(B)=z+\tilde{O}(n),\mathcal{B}(b)=O(\log n)
find
\text{rank}(B)
.

3.

Full-Rank Problem: Given
C\in\mathbb{R}^{n^{\prime}\times n^{\prime}}
with
n^{\prime}=O(n),\text{nnz}(C)=z+\tilde{O}(n),\mathcal{B}(C)=O(\log n)
, is
\text{rank}(C)=n^{\prime}
? or equivalently is the determinant of
C
non-zero.

Proof.

We have already reduced the Rank-Finding problem to the Full Rank problem in Lemma
6.6
and Full-Rank Problem to Linear Decision Problem in Lemma
6.7
while preserving sparsity in both the reductions.

We now reduce Linear Decision Problem to the Rank-Finding Problem.
Suppose we want to check satisfiability of the linear system
(A,b)
. Consider the matrix
A^{\prime}=[A~~b~]
, i.e. the matrix formed by appending the column vector
b
to the matrix
A
. The system
(A,b)
has a solution if and only if
rk(A)=rk(A^{\prime})
, so it suffices to find the rank of the matrices
A,A^{\prime}
. Hence we have reduced the linear system decision problem to the Rank-Finding Problem. Also note that
\text{nnz}(A^{\prime})=z+m=z+O(n)
and

∎
