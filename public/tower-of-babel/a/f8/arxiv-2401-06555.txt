Herbert Batte, Mahadi Ddamulira, Juma Kasozi, Florian Luca

Abstract
Let { L n } n ≥ 0 \{L_{n}\}_{n\geq 0} be the sequence of Lucas numbers. In this paper, we look at the exponential Diophantine equation L n − 2 x ​ 3 y = c L_{n}-2^{x}3^{y}=c , for n , x , y ∈ ℤ ≥ 0 n,x,y\in\mathbb{Z}_{\geq 0} . We treat the cases c ∈ − ℕ c\in-\mathbb{N} , c = 0 c=0 and c ∈ ℕ c\in\mathbb{N} independently. In the cases that c ∈ ℕ c\in\mathbb{N} and c ∈ − ℕ c\in-\mathbb{N} , we find all integers c c such that the Diophantine equation has at least three solutions. These cases are treated independently since we employ quite different techniques in proving the two cases.

2.1
Preliminaries

Here, we start with the well-known Binet formula for the sequence of Lucas numbers. It is given by

\displaystyle L_{n}=\alpha^{n}+\beta^{n},~~~\text{where}~~\alpha=\dfrac{1+\sqrt{5}}{2},~~\beta=\dfrac{1-\sqrt{5}}{2}.

(2.1)

Note that
\beta=-\alpha^{-1}
.

Assuming that
n\geq 10
, then by (
2.1
), we have

\displaystyle L_{n}=\alpha^{n}+\beta^{n}=\alpha^{n}\left(1+(-1)^{n}\alpha^{-2n}\right).

Since
n\geq 10
, then

\displaystyle 0.999\alpha^{n}<\alpha^{n}\left(1-\alpha^{-20}\right)\leq L_{n}\leq\alpha^{n}\left(1+\alpha^{-20}\right)<1.001\alpha^{n}.

(2.2)

Now, in the case that
c>0
, in (
1.2
), we have

\displaystyle 2^{x}3^{y}=L_{n}-c\leq L_{n}-1\leq\alpha^{n}.

This implies that

\displaystyle x,y<n\log\alpha.

(2.3)

Moreover, in the case that
c<0
, in (
1.2
), we have

\displaystyle 0.5\alpha^{n}<0.999\alpha^{n}<L_{n}=2^{x}3^{y}+c<2^{x}3^{y}.

This implies that
\alpha^{n}<2^{x+1}3^{y}
, or simply,

\displaystyle n\log\alpha<2\max\{(x+1)\log 2,y\log 3\}.

(2.4)

We recall one additional simple fact from calculus. This is Lemma 1 in
[
20
]
.

Lemma 2.1

(Lemma 1 in
[
20
]
)
.

If

satisfies

, then
|\log(1+x)|<\frac{3}{2}|x|
.

2.2
Linear forms in logarithms

We use several times Baker-types lower bounds for nonzero linear forms in two or three logarithms of algebraic numbers. There are many such bounds mentioned in the literature like that of Baker and Wüstholz from
[
1
]
or Matveev from
[
15

Definition 2.1
.

Let
\gamma
be an algebraic number of degree
d
with minimal primitive polynomial over the integers

a_{0}x^{d}+a_{1}x^{d-1}+\cdots+a_{d}=a_{0}\prod_{i=1}^{d}(x-\gamma^{(i)}),

where the leading coefficient
a_{0}
is positive. Then, the logarithmic height of
\gamma
is given by

h(\gamma):=\dfrac{1}{d}\Big(\log a_{0}+\sum_{i=1}^{d}\log\max\{|\gamma^{(i)}|,1\}\Big).

In particular, if
\gamma
is a rational number represented as
\gamma:=p/q
with coprime integers
p
and
q\geq 1
, then
h(\gamma)=\log\max\{|p|,q\}
.
The following properties of the logarithmic height function
h(\cdot)
will be used in the rest of the paper without further reference:

\displaystyle h(\gamma_{1}\pm\gamma_{2})

\displaystyle\leq h(\gamma_{1})+h(\gamma_{2})+\log 2;

\displaystyle h(\gamma_{1}\gamma_{2}^{\pm 1})

\displaystyle\leq h(\gamma_{1})+h(\gamma_{2});

\displaystyle h(\gamma^{s})

\displaystyle=|s|h(\gamma)\quad{\text{\rm valid for}}\quad s\in\mathbb{Z}.

With these properties, we can easily compute

\displaystyle h\left(\alpha^{x}+\xi\right)=h\left(\beta^{x}+\xi\right)\leq\dfrac{|x|\log\alpha}{2}+\log 2,~~~\text{for}~~\xi\in\{-1,1\}.

(2.5)

A linear form in logarithms is an expression

2.3
Reduced Bases for Lattices and LLL-reduction methods

Let
k
be a positive integer. A subset
\mathcal{L}
of the
k
-dimensional real vector space
\mathbb{R}^{k}
is called a lattice if there exists a basis
\{b_{1},b_{2},\ldots,b_{k}\}
of
\mathbb{R}^{k}
such that

\displaystyle\mathcal{L}=\sum_{i=1}^{k}\mathbb{Z}b_{i}=\left\{\sum_{i=1}^{k}r_{i}b_{i}\mid r_{i}\in\mathbb{Z}\right\}.

In this situation we say that
b_{1},b_{2},\ldots,b_{k}
form a basis for
\mathcal{L}
, or that they span
\mathcal{L}
. We
call
k
the rank of
\mathcal{L}
. The determinant
\text{det}(\mathcal{L})
, of
\mathcal{L}
is defined by

\displaystyle\text{det}(\mathcal{L})=|\det(b_{1},b_{2},\ldots,b_{k})|,

with the
b_{i}
being written as column vectors. This is a positive real number that does not depend on the choice of the basis (see
[
6
]
Sect 1.2).

Given linearly independent vectors
b_{1},b_{2},\ldots,b_{k}
in
\mathbb{R}^{k}
, we refer back to the Gram-Schmidt orthogonalization technique. This method allows us to inductively define vectors
b^{*}_{i}
(with
1\leq i\leq k
) and real coefficients
\mu_{i,j}
(for
1\leq j\leq i\leq k
). Specifically,

\displaystyle b^{*}_{i}

\displaystyle=b_{i}-\sum_{j=1}^{i-1}\mu_{i,j}b^{*}_{j},~~~\mu_{i,j}=\dfrac{\langle b_{i},b^{*}_{j}\rangle}{\langle b^{*}_{j},b^{*}_{j}\rangle},

where
\langle\cdot,\cdot\rangle
denotes the ordinary inner product on
\mathbb{R}^{k}
. Notice that
b^{*}_{i}
is the orthogonal projection of
b_{i}
on the orthogonal complement of the span of
b_{1},\ldots,b_{i-1}
, and that
\mathbb{R}b_{i}
is orthogonal to the span of
b^{*}_{1},\ldots,b^{*}_{i-1}
for
1\leq i\leq k
. It follows that
b^{*}_{1},b^{*}_{2},\ldots,b^{*}_{k}
is an orthogonal basis of
\mathbb{R}^{k}
.

Definition 2.3
.

The basis
b_{1},b_{2},\ldots,b_{n}
for the lattice
\mathcal{L}
is called reduced if

\displaystyle\|\mu_{i,j}\|

\displaystyle\leq\frac{1}{2},\quad\text{for}\quad 1\leq j<i\leq n,~~\text{and}

\displaystyle\|b^{*}_{i}+\mu_{i,i-1}b^{*}_{i-1}\|^{2}

\displaystyle\geq\frac{3}{4}\|b^{*}_{i-1}\|^{2},\quad\text{for}\quad 1<i\leq n,

where
\|\cdot\|
denotes the ordinary Euclidean length. The constant
\frac{3}{4}
above is arbitrarily chosen, and may be replaced by any fixed real number
v
with
\frac{1}{4}<v<1
, (see

# Import necessary libraries
from sage.all import *

# Define the Lucas sequence function using memoization for efficiency
@cached_function
def L(n):
if n == 0: return 2
if n == 1: return 1
return L(n-1) + L(n-2)

# Define the Lucas sequence modulo p^(k+1)
def lucas_mod(n, k, p):
if n == 0:
return 2
elif n == 1:
return 1
period = (p + 1) * p^k
L = [2 % (p^(k+1)), 1 % (p^(k+1))] + [0]*(period-2)
for i in range(2, period):
L[i] = (L[i-1] + L[i-2]) % (p^(k+1))
return L[n % period]

# Approximate sqrt(5) to a high precision
sqrt5_approx = sqrt(RealField(100)(5))

# Loop over p = 2 and p = 3
for p in [2, 3]:
# Define the p-adic field with precision 128
Qp_field = Qp(p, prec=128)

# Check for each odd d in the given range
d_values_with_n = []
for d in range(5, 321, 2):
found_n = False
for n in range(1001):
if (lucas_mod(n+d, 7, p) - lucas_mod(n, 7, p)) % (p^8) == 0:
d_values_with_n.append(d)
found_n = True
break

# Calculate n_0(d) for each d in d_values_with_n
n0_values = {}
for d in d_values_with_n:
for n in range(1, (p + 1) * p^7 + 1):
if (lucas_mod(n+d, 7, p) - lucas_mod(n, 7, p)) % (p^8) == 0:
n0_values[d] = n
break

# Define alpha and beta using the approximated sqrt(5)
alpha = (1 + sqrt5_approx) / 2
beta = (1 - sqrt5_approx) / 2

# Define P and Q
P = -sum([(1 - alpha^(p+1))^n / n for n in range(1, 121)])
Q = -sum([(1 - beta^(p+1))^n / n for n in range(1, 121)])

# Compute A and B
A = P + Q
B = P * Q

# For each d and its corresponding n_0(d), calculate the maximum nu_2
for d, n_0_d in n0_values.items():
# Initialize the coefficients u_k
u = [0]*19
u[0] = ((alpha^d - 1) * alpha^n_0_d * P^0 + (beta^d - 1) * beta^n_0_d * Q^0)
u[1] = ((alpha^d - 1) * alpha^n_0_d * P^1 + (beta^d - 1) * beta^n_0_d * Q^1)

# Compute the remaining coefficients using the recurrence relation
for k in range(2, 19):
u[k] = A * u[k - 1] - B * u[k - 2]

# Initialize z, the current modulus, and highest_power_of_2
z = 0
current_modulus = p^10
highest_power_of_2 = 0

# Iteratively update z and the modulus
for i in range(10, 128):
# Convert each term to a p-adic number and sum them up
f_z_terms = []
for k in range(19):
term = (p^7 * z)^k * u[k] / factorial(k)
f_z_terms.append(Qp_field(term))
f_z = sum(f_z_terms) % current_modulus

# Determine the next binary digit of z
for digit in [0, 1]:
test_z = z + p^i * digit
test_f_z_terms = []
for k in range(19):
term = (p^7 * test_z)^k * u[k] / factorial(k)
test_f_z_terms.append(Qp_field(term))
test_f_z = sum(test_f_z_terms) % (p^(i + 1))
if test_f_z == 0:
z = test_z
highest_power_of_2 = i
break

# Update the current modulus
current_modulus = p^(i + 1)

# Check if z exceeds the upper bound
if 2^highest_power_of_2 > 3.2e33:
break

# Output the final value of z for each d
if 2^highest_power_of_2 > 3.2e33:
print(f"For p = {p}, d = {d}, n_0(d) = {n_0_d}, the maximum v_p is achieved for
z = 2^{highest_power_of_2} (exceeds 3.2e33)")
else:
print(f"For p = {p}, d = {d}, n_0(d) = {n_0_d}, the maximum v_p is achieved for
z = 2^{highest_power_of_2} (does not exceed 3.2e33)")
