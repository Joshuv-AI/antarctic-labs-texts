Uniformly nonsquare Banach spaces have the fixed point property 1
Tim Dalby

Abstract
. Another proof that uniformly nonsquare Banach spaces have the fixed point property is presented.



2010 Mathematics Subject Classification
46B10, 47H09, 47H10

1.
Introduction

In [3] García-Falset, Llorens-Fuster and Mazcuñan-Navarroa were the first to show that a uniformly nonsquare Banach space has the Fixed Point Property, FPP. The proof is not direct as it uses the following chain of reasoning. The notation and definitions are explained in the next section.

A Banach space,
X
, is uniformly nonsquare if and only if
\rho^{\prime}_{X}(0)<1
, see [6]. This then implies that
X
is reflexive and
\Gamma_{X}^{\prime}(0)<1.
It is then shown that this implies
RW(a,X)<1+a
for some
a>0.
Finally, it was shown that
R(a,X)\leqslant RW(a,X)
which allowed a result of Domínguez-Benavides, [1], to be used to obtain the fixed point property.

In summary, the proof goes along the following path. The reverse implications are left out for ease of reading.

X
is uniformly nonsquare
\Rightarrow\rho^{\prime}_{X}(0)<1\Rightarrow X\mbox{ is reflexive and }\Gamma_{X}^{\prime}(0)<1\Rightarrow\mbox{there exist }a>0\mbox{ such that }RW(a,X)<1+a\Rightarrow R(a,X)<1+a\Rightarrow X
has the FPP.

The proof really shows the more general result that if
X
is reflexive and
\Gamma_{X}^{\prime}(0)<1
then
X
has the FPP with the main result coming as a corollary.

The proof in this paper goes down a more direct path. The idea is highlight the connection between the Fixed Point Property and the modulus of nearly uniform smoothness.

There will be a further two more papers on this topic presenting two more proofs that the property of uniformly nonsquare implies the FPP. These proofs will be from slightly different perspectives with intention of highlighting different aspects of Banach space geometry.

At this point, it is important to note that there is now a very direct proof of uniformly nonsquare implying the FPP curtesy of Dowling, Randrianantoanina and Turett, [2].

Now for the definitions and notation.

2.
Definitions

The modulus of uniform smoothness is

\rho_{X}(t)=\sup\left\{\frac{\displaystyle\|x+ty\|+\|x-ty\|}{\displaystyle 2}-1:x,y\in B_{X}\right\}

where
t\geqslant 0
and

\rho^{\prime}_{X}(0)=\lim_{t\rightarrow 0^{+}}\frac{\rho_{X}(t)}{t}.

The modulus of nearly uniform smoothness is

\Gamma_{X}(t)=\sup\left\{\inf_{n>1}\left(\frac{\|x_{1}+tx_{n}\|+\|x_{1}-tx_{n}\|}{2}-1\right)\right\},

where the supremum is taken over all basic sequences
(x_{n})
in
B_{X}
.

If
X
is reflexive then

\Gamma_{X}(t)=\sup\left\{\inf_{n>1}\left(\frac{\|x_{1}+tx_{n}\|+\|x_{1}-tx_{n}\|}{2}-1\right):(x_{n})\mbox{ in }B_{X},x_{n}\rightharpoonup 0\right\}.

Also

\Gamma_{X}^{\prime}(0)=\lim_{t\rightarrow 0^{+}}\frac{\Gamma_{X}(t)}{t}.

It is clear from the definitions that
\Gamma_{X}(t)\leqslant\rho_{X}(t)\mbox{ for all }t\geqslant 0.

So
\Gamma_{X}^{\prime}(0)\leqslant\rho^{\prime}_{X}(0).

In [3] it was shown that
\Gamma_{X}^{\prime}(0)<1
is equivalent to there exists
s>0
such that
\Gamma(s)<s.
†

Remark
It can be shown that this last condition on
\Gamma(s)
is equivalent to

\Gamma(s)<s\mbox{ for all }s>0.

3.
Result

Proposition 3.1
.

Let
X
be a reflexive Banach space where
\Gamma_{X}^{\prime}(0)<1
then
X
has the FPP.

Proof.

Assume
X
is a reflexive Banach space with
\Gamma_{X}^{\prime}(0)<1
. From †  we can find an
s>0
such that
\Gamma(s)<s.

Let
t=\frac{\displaystyle s}{\displaystyle 1+s}
then
0<t<1.

The usual set up is to assume
X
does not have the FPP and arrive at a contradiction. Using results from Goebel [4], Karlovitz [5] and Lin [7] plus an excursion to

\tilde{X}=l_{\infty}(X)/c_{0}(X)
and then back to
X
it can be shown that there exists a sequence with the following properties.

y_{n}\rightharpoonup y,\lim_{n\rightarrow\infty}\|y_{n}\|\mbox{ exists, }D[(y_{n})]=\limsup_{n\rightarrow\infty}\limsup_{m\rightarrow\infty}\|y_{n}-y_{m}\|\leqslant t\mbox{ and }\|y\|\leqslant 1-t.

To obtain the required contradiction, we need to show that
\lim_{n\rightarrow\infty}\|y_{n}\|
is uniformly away from 1.

Let
w_{n}=y_{n}-y\mbox{ and }w=y\mbox{ then }w_{n}\rightharpoonup 0.

Since
y_{n}=w_{n}+w
it is necessary to investigate upper bounds on
\|w_{n}+w\|.
This is done via
D[(w_{n})]=D[(y_{n})]\leqslant t.

It turns out that
\lim_{n\rightarrow\infty}\|w_{n}+w\|
bounded above by both

\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})+w\|\mbox{ and }\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})-w\|

as shown below.

Using lemma 3.2 in [3] there exists a subsequence
(w_{n_{k}})
such that

\limsup_{k\rightarrow\infty}\|w_{n_{k}}-w_{n_{k+1}}\|\leqslant D[(w_{n})]=D[(y_{n})]\leqslant t

and

\liminf_{k\rightarrow\infty}\|w_{n_{k}}-w_{n_{k+1}}+w\|\geqslant\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})+w\|

and

\liminf_{k\rightarrow\infty}\|w_{n_{k}}-w_{n_{k+1}}-w\|\geqslant\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})-w\|.

Using the weak lower semicontinuity of the norm,

\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})+w\|\geqslant\|w_{n}+w\|\mbox{ for all }n.

So
\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})+w\|\geqslant\liminf_{n\rightarrow\infty}\|w_{n}+w\|.

To obtain a similar inequality for
\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})-w\|
take
w_{n}^{*}\in S_{X^{*}}\mbox{ where }w^{*}_{n}(w_{n}+w)=\|w_{n}+w\|.
Because of the reflexivity of
X,B_{X^{*}}
is w*-sequentially compact. So, without loss of generality, we may assume that
w_{n}^{*}\stackrel{{\scriptstyle*}}{{\rightharpoonup}}w^{*}\mbox{ where }\|w^{*}\|\leqslant 1.

Now

\displaystyle\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})-w\|

\displaystyle\geqslant\liminf_{m\rightarrow\infty}(-w_{m}^{*})((w_{n}-w_{m})-w)

\displaystyle=\liminf_{m\rightarrow\infty}w_{m}^{*}(w_{m}+w)-w^{*}(w_{n})

\displaystyle=\liminf_{m\rightarrow\infty}\|w_{m}+w\|-w^{*}(w_{n}).

Therefore
\liminf_{n\rightarrow\infty}\liminf_{m\rightarrow\infty}\|(w_{n}-w_{m})-w\|\geqslant\liminf_{m\rightarrow\infty}\|w_{m}+n\|.

Thus

\displaystyle\lim_{n\rightarrow\infty}\|y_{n}\|

\displaystyle=\lim_{n\rightarrow\infty}\|w_{n}+w\|

\displaystyle\leqslant\left(\liminf_{k\rightarrow\infty}\|(w_{n_{k}}-w_{n_{k+1}})+w\|\right)\wedge\left(\liminf_{k\rightarrow\infty}\|(w_{n_{k}}-w_{n_{k+1}})-w\|\right)

\displaystyle\leqslant\frac{\liminf_{k\rightarrow\infty}\|(w_{n_{k}}-w_{n_{k+1}})+w\|+\liminf_{k\rightarrow\infty}\|(w_{n_{k}}-w_{n_{k+1}})-w\|}{2}.

This expression is starting to look like that used in the definition of
\Gamma(s)
since
(w_{n_{k}}-w_{n_{k+1}})
is weak null.

Next is some scaling so that
(w_{n_{k}}-w_{n_{k+1}})
becomes a weak null sequence in
B_{X}
and
w
is scaled so it too is in
B_{X}.

Choose
\alpha>0
such that
\alpha<\frac{\displaystyle s(s-\Gamma(s))}{\displaystyle(\Gamma(s)+s+2)(1+s)}.\qquad{\dagger}{\dagger}

This unusual fraction is chosen so that three inequalities a little further on, work out just right.

This means

\displaystyle\alpha(1+s)

\displaystyle<\frac{s(s-\Gamma(s))}{\Gamma(s)+s+2}

\displaystyle=\frac{2s(1+s)}{\Gamma(s)+s+2}-s.

Which leads to

s+\alpha(1+s)<\frac{2s(1+s)}{\Gamma(s)+s+2}

and

\frac{s+\alpha(1+s)}{s(1+s)}\left(\frac{\Gamma(s)+s+2}{2}\right)<1.

Let

v_{1}=\frac{\displaystyle w}{\displaystyle\frac{\displaystyle s+\alpha(1+s)}{\displaystyle s(1+s)}}

and

v_{k}=\frac{\displaystyle w_{n_{k}}-w_{n_{k+1}}}{\displaystyle\frac{\displaystyle s+\alpha(1+s)}{\displaystyle 1+s}}\mbox{ for }k>1.

Then
v_{k}\rightharpoonup 0\mbox{ and for large enough }k,\|w_{n_{k}}-w_{n_{k+1}}\|\leqslant t+\alpha
.

So for large
k
,

\displaystyle\|v_{k}\|

\displaystyle\leqslant\frac{\displaystyle t+\alpha}{\displaystyle\frac{s+\alpha(1+s)}{\displaystyle 1+s}}

\displaystyle=\frac{s+\alpha(1+s)}{s+\alpha(1+s)}

\displaystyle=1.

Also

\displaystyle\|v_{1}\|

\displaystyle\leqslant\frac{\displaystyle 1-t}{\displaystyle\frac{s+\alpha(1+s)}{\displaystyle s(1+s)}}

\displaystyle=\frac{s(1+s)}{s+\alpha(1+s)}\left(1-\frac{s}{1+s}\right)

\displaystyle=\frac{s}{s+\alpha(1+s)}

\displaystyle\leqslant 1.

Now back to the story about
\lim_{n\rightarrow\infty}\|w_{n}+w\|.

\frac{\displaystyle 1}{\displaystyle\frac{s+\alpha(1+s)}{\displaystyle s(1+s)}}\lim_{n\rightarrow\infty}\|w_{n}+w\|\leqslant\frac{\liminf_{k\rightarrow\infty}\|sv_{k}+v_{1}\|+\liminf_{k\rightarrow\infty}\|sv_{k}-v_{1}\|}{2}.

But

\inf_{k>1}\left(\frac{\displaystyle\|sv_{k}+v_{1}\|+\|sv_{k}-v_{1}\|}{\displaystyle 2}-1\right)\leqslant\Gamma(s).

So there exists
k_{0}
such that

\frac{\displaystyle\|sv_{k_{0}}+v_{1}\|+\|sv_{k_{0}}-v_{1}\|}{\displaystyle 2}-1\leqslant\Gamma(s)+\frac{\displaystyle s-\Gamma(s)}{\displaystyle 2}=\frac{\displaystyle\Gamma(s)+s}{\displaystyle 2}.

If the little bit added onto
\Gamma(s),\frac{\displaystyle s-\Gamma(s)}{\displaystyle 2}
, is different then so will be the expression in inequality ††.

Now

\displaystyle\frac{\displaystyle\liminf_{k\rightarrow\infty}\|sv_{k}+v_{1}\|+\liminf_{k\rightarrow\infty}\|sv_{k}-v_{1}\|}{\displaystyle 2}-1

\displaystyle\leqslant\frac{\displaystyle\|sv_{k_{0}}+v_{1}\|+\|sv_{k_{0}}-v_{1}\|}{\displaystyle 2}-1

\displaystyle\leqslant\frac{\displaystyle\Gamma(s)+s}{\displaystyle 2}.

Therefore

\displaystyle\lim_{n\rightarrow\infty}\|y_{n}\|

\displaystyle=\liminf_{n\rightarrow\infty}\|w_{n}+w\|

\displaystyle\leqslant\frac{s+\alpha(1+s)}{s(1+s)}\times\frac{\Gamma(s)+s+2}{2}

\displaystyle<1.

A contradiction, so
X
has the FPP.

∎

Corollary 3.2
.

If
X
is a Banach space that is uniformly nonsquare then
X
has the FPP.

Remark

1.

If
X
is uniformly nonsquare then there exists
s>0
such that
\rho(s)<s.
Can a proof be devised where this inequality is used instead of there exists
s>0
such that
\Gamma(s)<s?

2.

Following on from the Remark in Section 2, since any
s>0
can be used, does this allow a similar result but where the Banach-Mazur distance is used. That is, if
X
is a uniformly nonsquare Banach space and
Y
is another Banach space where the Banach-Mazur distance,
d(X,Y)<\beta
then
Y
has the FPP. Here the
\beta
is yet to be determined.
