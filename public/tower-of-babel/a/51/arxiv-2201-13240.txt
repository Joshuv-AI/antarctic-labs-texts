Grid-Free Monte Carlo for PDEs with Spatially Varying Coefficients - Supplemental Journal: TOG


Abstract




1.
Green’s Functions and Poisson Kernels

Here we provide the Green’s function
G^{\sigma}(x,y)
and Poisson kernel
P^{\sigma}(x,z)
for a constant coefficient screened Poisson equation on a ball
B(c)
in
2
D and
3
D. These quantities are needed to estimate the integral expression in Eq.
26
we derive for variable coefficient PDEs in the paper. Expressions for
\nabla_{x}G^{\bar{\sigma}}(x,y)
and
\nabla_{x}P^{\bar{\sigma}}(x,z)
are provided as well to estimate the spatial derivative of Eq.
26
. We also describe how to draw samples
y
inside
B(c)
from a probability density
p^{B}
that is proportional to the Green’s function. Derivations of
G^{\sigma}_{2D}
and
G^{\sigma}_{3D}
can be found in
Duffy 2015
.

1.1.
Centered Expressions

Assume that the point
x
lies at the center of a ball
B(c)
with radius
R
, and let
r:=|y-x|
. Then the Green’s function on
B(x)
in two and three dimensions is given by:

(1)

\displaystyle G^{\sigma}_{2D}(x,y)

\displaystyle=\frac{1}{2\pi}\underbrace{\left(K_{0}(r\sqrt{\sigma})-\frac{K_{0}(R\sqrt{\sigma})}{I_{0}(R\sqrt{\sigma})}I_{0}(r\sqrt{\sigma})\right)}_{Q^{\sigma}_{2D}(r)},

\displaystyle G^{\sigma}_{3D}(x,y)

\displaystyle=\frac{1}{4\pi}\sqrt{\frac{2\sqrt{\sigma}}{\pi r}}\left(K_{\frac{1}{2}}(r\sqrt{\sigma})-\frac{K_{\frac{1}{2}}(R\sqrt{\sigma})}{I_{\frac{1}{2}}(R\sqrt{\sigma})}I_{\frac{1}{2}}(r\sqrt{\sigma})\right)

\displaystyle=\frac{1}{4\pi}\underbrace{\left(\frac{e^{-r\sqrt{\sigma}}}{r}-\frac{e^{-R\sqrt{\sigma}}}{R}\left(\frac{\sinh(r\sqrt{\sigma})}{r\sqrt{\sigma}}\frac{R\sqrt{\sigma}}{\sinh(R\sqrt{\sigma})}\right)\right)}_{Q^{\sigma}_{3D}(r)},

where
I_{n}
,
I_{n+\frac{1}{2}}
and
K_{n}
,
K_{n+\frac{1}{2}}
(for
n=0,1,2,...
) denote
modified Bessel functions
of the first and second kind (resp.). Routines to efficiently evaluate these functions are available in numerical libraries such as
Boost

(
Schäling 2014
)
and
SciPy

(
Virtanen et al. 2019
)
.

To compute the probability density
p^{B}(x,y):=G^{\sigma}(x,y)/|G^{\sigma}(x)|
associated with these Green’s functions, we need to evaluate the integrated value of
G^{\sigma}
over all
y
on
B(x)
:

(2)

\displaystyle|G^{\sigma}_{2D}(x)|

\displaystyle:=\int_{B(x)}G^{\sigma}_{2D}(x,y)\mathop{}\!\mathrm{d}{y}\ =\ \frac{1}{\sigma}\left(1-\frac{1}{I_{0}(R\sqrt{\sigma})}\right),

\displaystyle|G^{\sigma}_{3D}(x)|

\displaystyle:=\int_{B(x)}G^{\sigma}_{3D}(x,y)\mathop{}\!\mathrm{d}{y}\ =\ \frac{1}{\sigma}\left(1-\frac{R\sqrt{\sigma}}{\sinh(R\sqrt{\sigma})}\right).

The Poisson kernel is defined as the normal derivative of the Green’s function along the boundary, i.e., for any point
z
on
\partial B(x)
,
P^{\sigma}(x,z):=\nabla_{z}G^{\sigma}(x,z)\cdot\vec{n}(z)
. In two and three dimensions it is given by:

(3)

\displaystyle P^{\sigma}_{2D}(x,z)

\displaystyle=\frac{1}{2\pi R}\left(\frac{1}{I_{0}(R\sqrt{\sigma})}\right),

\displaystyle P^{\sigma}_{3D}(x,z)

\displaystyle=\frac{1}{4\pi R^{2}}\left(\frac{R\sqrt{\sigma}}{\sinh(R\sqrt{\sigma})}\right).

Notice that in both dimensions, the Poisson kernel equals
\frac{1-\sigma|G^{\sigma}(x)|}{|\partial B(x)|}
. We exploit this property of the Poisson kernel to develop the delta tracking variant of WoS described in Sec.
5.1
of the paper.

1.2.
Off-centered Expressions

The next-flight variant of WoS from Sec.
5.2
in the paper requires off-centered versions of the Green’s function and Poisson kernel. In particular, assume
x
is an arbitrary point inside
B(c)
, and let
r_{-}:=\min(|x-c|,|y-c|)
and
r_{+}:=\max(|x-c|,|y-c|)
. Furthermore, let
\theta
define the angle between the vectors
x-c
and
y-c
in
2
D or
3
D. Then the off-centered Green’s function on
B(c)
is given by the infinite series:

\displaystyle\begin{multlined}G^{\sigma}_{2D}(x,y)=\frac{1}{2\pi}\sum_{n=-\infty}^{\infty}\cos(n\theta)\ I_{n}(r_{-}\sqrt{\sigma})\\
\left(K_{n}(r_{+}\sqrt{\sigma})-\frac{K_{n}(R\sqrt{\sigma})}{I_{n}(R\sqrt{\sigma})}I_{n}(r_{+}\sqrt{\sigma})\right),\end{multlined}

\displaystyle\begin{multlined}G^{\sigma}_{3D}(x,y)=\frac{1}{4\pi}\sum_{n=0}^{\infty}(2n+1)\ P_{n}(\cos(\theta))\left(\sqrt{\frac{\pi}{2r_{-}\sqrt{\sigma}}}I_{n+\frac{1}{2}}(r_{-}\sqrt{\sigma})\right)\\
\sqrt{\frac{2\sqrt{\sigma}}{\pi r_{+}}}\left(K_{n+\frac{1}{2}}(r_{+}\sqrt{\sigma})-\frac{K_{n+\frac{1}{2}}(R\sqrt{\sigma})}{I_{n+\frac{1}{2}}(R\sqrt{\sigma})}I_{n+\frac{1}{2}}(r_{+}\sqrt{\sigma})\right),\end{multlined}

where
P_{n}
denotes the recursively defined Legendre polynomials. As usual, the Poisson kernel can be computed by evaluating
\nabla_{z}G^{\sigma}(x,z)\cdot\vec{n}(z)
on
\partial B(c)
. We recover the expressions for
G^{\sigma}
and
P^{\sigma}
in
Section

1.1
when
x
coincides with the ball center
c
.

In practice, we observe that
100
to
200
terms are required to accurately approximate these series. To avoid this computational burden, we provide approximations for these off-centered quantities. In particular, let
\vec{u}:=x-c
,
\vec{v}:=y-c
and
\vec{w}:=y-x
. Then in two and three dimensions we have:

(8)

\displaystyle G^{\sigma}_{2D}(x,y)

\displaystyle=\frac{1}{2\pi}\left(Q^{\sigma}_{2D}(|\vec{w}|)-Q^{\sigma}_{2D}\left(\frac{R^{2}-\vec{u}\cdot\vec{v}}{R}\right)\right),

\displaystyle G^{\sigma}_{3D}(x,y)

\displaystyle=\frac{1}{4\pi}\left(Q^{\sigma}_{3D}(|\vec{w}|)-Q^{\sigma}_{3D}\left(\frac{R^{2}-\vec{u}\cdot\vec{v}}{R}\right)\right),

\displaystyle P^{\sigma}_{2D}(x,y)

\displaystyle=\frac{1}{2\pi}\left(V^{\sigma}_{2D}(|\vec{w}|)\frac{|\vec{v}|^{2}-\vec{u}\cdot\vec{v}}{|\vec{w}||\vec{v}|}+V^{\sigma}_{2D}\left(\frac{R^{2}-\vec{u}\cdot\vec{v}}{R}\right)\frac{\vec{u}\cdot\vec{v}}{R|\vec{v}|}\right),

\displaystyle P^{\sigma}_{3D}(x,y)

\displaystyle=\frac{1}{4\pi}\left(V^{\sigma}_{3D}(|\vec{w}|)\frac{|\vec{v}|^{2}-\vec{u}\cdot\vec{v}}{|\vec{w}||\vec{v}|}+V^{\sigma}_{3D}\left(\frac{R^{2}-\vec{u}\cdot\vec{v}}{R}\right)\frac{\vec{u}\cdot\vec{v}}{R|\vec{v}|}\right),

where

(9)

\displaystyle V^{\sigma}_{2D}(r)

\displaystyle:=\sqrt{\sigma}\left(K_{1}(r\sqrt{\sigma})+\frac{K_{0}(R\sqrt{\sigma})}{I_{0}(R\sqrt{\sigma})}I_{1}(r\sqrt{\sigma})\right),

\displaystyle V^{\sigma}_{3D}(r)

\displaystyle:=\sqrt{\sigma}\sqrt{\frac{2\sqrt{\sigma}}{\pi r}}\left(K_{\frac{3}{2}}(r\sqrt{\sigma})+\frac{K_{\frac{1}{2}}(R\sqrt{\sigma})}{I_{\frac{1}{2}}(R\sqrt{\sigma})}I_{\frac{3}{2}}(r\sqrt{\sigma})\right)

\displaystyle\begin{multlined}=\frac{\sqrt{\sigma}}{r}\left(e^{-r\sqrt{\sigma}}\left(1+\frac{1}{r\sqrt{\sigma}}\right)+\right.\\
\left.\frac{e^{-R\sqrt{\sigma}}}{\sinh(R\sqrt{\sigma})}\left(\cosh(r\sqrt{\sigma})-\frac{\sinh(r\sqrt{\sigma})}{r\sqrt{\sigma}}\right)\right).\end{multlined}

These expressions for
G^{\sigma}
and
P^{\sigma}
are exact when
x
lies at the center of
B(c)
, but begin to diverge slightly from the true values as
x
is moved closer to
\partial B(c)
and the value of coefficient
\sigma
is decreased; see
Fig.

1
. In our experiments, we observe that these approximate expressions provide sufficiently accurate results with the next-flight variant of WoS with far less compute, especially when the value of
\sigma
if large.

B(c)
from
Section

1.2
match exactly when
x
lies at the center of the ball.

x
is moved closer to

is decreased.

1.3.
Gradient Expressions

In
Section

2
of this document, we provide an integral expression for the gradient of a PDE solution at a point
x
. To estimate the gradient at the center of
B(x)
, we need to evaluate the gradients of the Green’s function and Poisson kernel. In two and three dimensions they are given by:

\displaystyle\begin{multlined}\nabla_{x}G^{\sigma}_{2D}(x,y)=\frac{(y-x)\sqrt{\sigma}}{2\pi r}\left(K_{1}(r\sqrt{\sigma})-\frac{K_{1}(R\sqrt{\sigma})}{I_{1}(R\sqrt{\sigma})}I_{1}(r\sqrt{\sigma})\right),\end{multlined}

\displaystyle\begin{multlined}\nabla_{x}G^{\sigma}_{3D}(x,y)=\frac{(y-x)\sqrt{\sigma}}{4\pi r^{2}}\left(e^{-r\sqrt{\sigma}}\left(1+\frac{1}{r\sqrt{\sigma}}\right)-\right.\\
\left.\left(\cosh(r\sqrt{\sigma})-\frac{\sinh(r\sqrt{\sigma})}{r\sqrt{\sigma}}\right)\left(\frac{e^{-R\sqrt{\sigma}}\left(1+\frac{1}{R\sqrt{\sigma}}\right)}{\cosh(R\sqrt{\sigma})-\frac{\sinh(R\sqrt{\sigma})}{R\sqrt{\sigma}}}\right)\right),\end{multlined}

\displaystyle\begin{multlined}\nabla_{x}P^{\sigma}_{2D}(x,z)=\frac{(z-x)\sigma}{2\pi R}\left(\frac{1}{R\sqrt{\sigma}\ I_{1}(R\sqrt{\sigma})}\right),\end{multlined}

\displaystyle\begin{multlined}\nabla_{x}P^{\sigma}_{3D}(x,z)=\frac{(z-x)\sigma}{4\pi R^{2}}\left(\frac{1}{\cosh(R\sqrt{\sigma})-\frac{\sinh(R\sqrt{\sigma})}{R\sqrt{\sigma}}}\right).\end{multlined}

1.4.
Sampling

To sample from the probability density
p^{B}:=G^{\sigma}(x,y)/|G^{\sigma}(x)|
associated with the
centered
Green’s functions
G^{\sigma}
in
Section

1.1
, we first pick a direction
\vec{y}
uniformly on the unit sphere
(
Arvo 2001
)
. A radius
r
is then sampled from the distribution
2\pi rp^{B}
in
2
D, or
4\pi r^{2}p^{B}
in
3
D, using rejection sampling. The extra factor in front of
p^{B}
accounts for the change of measure between polar and Cartesian coordinates. For rejection sampling, we bound the radial density by the following case dependent function:

(16)

\displaystyle h(R,\sigma)

\displaystyle:=\begin{cases}\max(2.2*\max(1/R,1/\sigma),0.6*\max(\sqrt{R},\sqrt{\sigma}))&R\leq\sigma,\\
\max(2.2*\min(1/R,1/\sigma),0.6*\min(\sqrt{R},\sqrt{\sigma}))&\text{otherwise}.\end{cases}

The final sample point is given by
y=r\vec{y}+x
.

Generating samples from an
off-centered
Green’s function
G^{\sigma}(x,y)
in
Section

1.2
is more challenging since we do not know of a closed-form expression for
|G^{\sigma}(x)|
. While using a uniform density
\frac{1}{|B(c)|}
for
p^{B}
suffices for unbiased sampling, more sophisticated techniques to generate samples according to the profile of
G^{\sigma}
exist. We recommend the weighted reservoir version of resampled importance sampling provided in
(
Bitterli et al. 2020
, Alg. 3)
.

2.
Spatial Gradient

Applications often require computing not just the solution to a PDE, but the spatial gradient of the solution as well. Fortunately, estimating the gradient
\nabla_{x}u(x)
of Eq.
26
from the paper at a point
x
adds virtually no cost on top of estimating the solution
u(x)
itself. In particular, either of our WoS algorithms can be used to evaluate the following integral expression for
\nabla_{x}u(x)
at the center of a ball
B(x)
:

(17)

\nabla_{x}u(x)=\frac{1}{\sqrt{\alpha(x)}}\left(\int_{B(x)}f^{\prime}(y,\sqrt{\alpha}\ u)\ \nabla_{x}G^{\bar{\sigma}}(x,y)\mathop{}\!\mathrm{d}{y}\ \right.+\\
\left.\int_{{\partial B}(x)}\sqrt{\alpha(z)}\ u(z)\ \nabla_{x}P^{\bar{\sigma}}(x,z)\mathop{}\!\mathrm{d}{z}\right)\ -\ \frac{u(x)}{2\alpha(x)}\nabla_{x}\alpha(x).

The value of
\nabla_{x}u(x)
only needs to be estimated in the first ball in any walk—the solution estimates it depends on can be computed recursively using the delta tracking or next-flight estimators; see Sec.
5
in the paper. Furthermore, the parameters
\bar{\sigma}
,
p^{B}
,
p^{\partial B}
,
{\mathbb{P}}^{B}
and
{\mathbb{P}}^{\partial B}
remain unchanged with either algorithm.

3.
Pseudo-code

Here we provide pseudo-code for the two variants of walk on spheres presented in Sec.
5
of the paper. To maintain consistency with the paper , we assume the transport coefficient
\vec{\omega}({x})=\vec{0}
over the entire domain.

Input:

A point
x\in\Omega
.

Output:

A single sample estimate
\widehat{u}(x)
of the solution to Eq.
1
.

/*
Compute distance and closest point to
x
on
\partial\Omega
*/

d,\overline{{x}}\leftarrow
DistanceToBoundary(
x
);

/*
Return boundary value
g
at
\overline{x}
if
x\in\partial\Omega_{\epsilon}
*/

if

d<\epsilon

then

return

g(\overline{x})

;

/*
Estimate source contribution at random point
y\in B(x)
*/

y\sim\frac{G^{\bar{\sigma}}(x,y)}{\lvert G^{\bar{\sigma}}(x)\rvert}
;

\widehat{S}\leftarrow\frac{\lvert G^{\bar{\sigma}}(x)\rvert}{\sqrt{\alpha(x)\alpha({y})}}f({y})

/*
Decide whether to sample volume or boundary term in Eq.
27
*/

if

\mu\sim\mathcal{U}\leq\bar{\sigma}\lvert G^{\bar{\sigma}}(x)\rvert

then

/*
Estimate solution at
y\in B(x)
; adjust estimate by null-event contribution from Eq.
21
*/

return

\sqrt{\frac{\alpha(y)}{\alpha(x)}}\left(1-\frac{\sigma^{\prime}(y)}{\bar{\sigma}}\right)\text{ DeltaTrackingEstimate}(y)+\widehat{S}
;

else

/*
Estimate solution at random point
z\in\partial B(x)
*/

z\sim\frac{1}{\lvert{\partial B}(x)\rvert}
;

return

\sqrt{\frac{\alpha(z)}{\alpha(x)}}\text{ DeltaTrackingEstimate}(z)+\widehat{S}
;

end if

DeltaTrackingEstimate(

.

Output:

A single sample estimate

1

/*
Compute distance and closest point to
x
on
\partial\Omega

d,\overline{{x}}\leftarrow
DistanceToBoundary(
x
);

/*
Return boundary value
g
at
\overline{x}
if
x\in\partial\Omega_{\epsilon}
*/

if

d<\epsilon

then

return

g(\overline{x})

;

/*
Initialize series expressions from Eq.
29
*/

\widehat{T}\leftarrow 0
;

\widehat{S}\leftarrow 0
;

/*
Initialize path throughput */

W\leftarrow 1
;

/*
Sample random exit point
z\in\partial B(x)
used across all entries in
\widehat{T}
*/

z\sim\frac{1}{\lvert{\partial B}(x)\rvert}
;

/*
Initialize temporary variable to track current sample point inside
B(x)
*/

x_{c}\leftarrow x

while

True

do

/*
Accumulate boundary contribution */

\widehat{T}
+=
\frac{P^{\bar{\sigma}}(x_{c},z)}{p^{\partial B}(z)}W
;

/*
Use path throughput as Russian Roulette probability to terminate loop */

{\mathbb{P}}^{\mathrm{RR}}=\min(1,W)
;

if

{\mathbb{P}}^{\mathrm{RR}}<\mu\sim\mathcal{U}

then

break

;

W
/=
{\mathbb{P}}^{\mathrm{RR}}
;

/*
Sample next random point
x_{n}\in B(x)
*/

x_{n}\sim\frac{1}{\lvert B(x)\rvert}
;

/*
Update path throughput */

W
*=
\frac{G^{\bar{\sigma}}(x_{c},x_{n})(\bar{\sigma}-\sigma^{\prime}(x_{n}))}{p^{B}(x_{n})}
;

/*
Accumulate source contribution */

S
+=
\frac{f(x_{n})}{\sqrt{\alpha(x_{n})}(\bar{\sigma}-\sigma^{\prime}(x_{n}))}W
;

/*
Update current sample point inside
B(x)
*/

x_{c}\leftarrow x_{n}

end while

/*
Estimate solution at
z\in\partial B(x)
*/

return

\frac{1}{\sqrt{\alpha(x)}}(\sqrt{\alpha(z)}\ \widehat{T}\text{ NextFlightEstimate}(z)+\widehat{S})
;
