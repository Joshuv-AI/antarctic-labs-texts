1.
Introduction

1.1.

The
pair correlation density
for a sequence of
N
numbers
\theta_{1},\dots,\theta_{N}
which are equidistributed modulo one as
N
tends to infinity, measures the distribution of spacings between the elements
\theta_{n}
of the sequence at distances of order of the mean spacing
N^{-1}
. More precisely, the
pair correlation function
is defined as follows

\mathrm{R}_{2}([a,b],\{\theta_{n}\}_{n},N)=\frac{1}{N}\#\bigg\{1\leq j\neq k\leq N\,\bigg|\,\theta_{j}-\theta_{k}\in\bigg[\frac{a}{N},\frac{b}{N}\bigg]+\mathbb{Z}\bigg\},

for any interval
[a,b]
.

The pair correlation function
\mathrm{R}_{2}(\,\cdot\,,\{\theta_{n}\}_{n},N)
is not a probability measure in general. However, if the sequence
\theta_{n}
arises from independent and uniformly distributed random variables on
[0,1]
, then it is well-known that

(1.1)

\mathrm{R}_{2}([a,b],\{\theta_{n}\}_{n},N)\to b-a,\text{ as }N\to\infty.

Thus, we will say that a deterministic sequence
\{\theta_{n}\}_{n}
exhibits
Poissonian pair correlation
if (
1.1
) holds for all intervals
[a,b]
.

At this point let us also remark the connection between a sequence exhibiting Poissonian pair correlation and equidistribution modulo one: the former condition implies the latter (see
[
GL17
,
ALP18
]
) but not vice-versa.

1.2.

In 1916, Weyl
[
Wey16
]
proved that the sequence of fractional parts
\{\alpha n^{d}\}_{n}
is equidistributed in
[0,1]
. A finer question in the context of the pseudo-randomness of such a sequence is whether the corresponding spacings behave like those of independent and uniformly distributed random variables on
[0,1]
.

For
d=1
the answer is no and in fact the consecutive spacings have at most three values; this result is commonly referred to as the Steinhaus conjecture or the three distance theorem (see
[
Sós57
,
“’Swi59
,
MS17
]
).

For
d\geq 2
, this is believed to be true for the
pair correlation statistics
depending only on the Diophantine properties of
\alpha
: We say that a real number
\alpha
is
Diophantine of type
\kappa
if there is a constant
c>0
such that

\bigg|\alpha-\frac{p}{q}\bigg|\geq\frac{c}{q^{\kappa}}

for all
p\in\mathbb{Z}
and
q\in\mathbb{N}_{>0}
. We say that
\alpha
is
Diophantine
if it is Diophantine of type
2+\epsilon
for any
\epsilon>0
. For reference, a rational number
\alpha
is of type
\kappa=1
; an irrational number
\alpha
is of type
\kappa\geq 2
; an algebraic irrational number
\alpha
, due to Roth’s theorem, is of type
\kappa=2+\epsilon
for all
\epsilon>0
.

Rudnick and Sarnak observed (see
[
RS98
]
Remark 1.2 or
[
Hea10
]
) that if
\alpha
is not Diophantine of type
d+1
, then
\{\alpha n^{d}\}_{n}
cannot exhibit Poissonian pair correlation (
1.1
). In the special case
d=2
, it seems likely to be true that
\{\alpha n^{2}\}_{n}
exhibits Poissonian pair correlation if
\alpha
is Diophantine of type
3-\epsilon
for every
\epsilon>0
.

However, one can find a set
P\subset\mathbb{R}
of full Lebesgue measure such that for any
\alpha\in P
, the sequence
\{\alpha n^{d}\}_{n}
exhibits Poissonian pair correlation (
1.1
). Results of this nature are commonly referred to as
metric Poisson pair correlation
. This was first proved by Rudnick and Sarnak
[
RS98
]
, but let us also mention proofs using different methods in the special case
d=2
by Marklof and Strömbergsson
[
MS03
]
as well as Heath-Brown
[
Hea10
]
.

Yet, as of this moment there is no specific
\alpha
for which the Poissonian pair correlation property (
1.1
) has been verified. The most compelling result so far for an explicit
\alpha
was proved by Heath-Brown
[
Hea10
]
, who showed that for a number
\alpha
of type
\kappa=\frac{9}{4}
the sequence
\{\alpha n^{2}\}_{n}
satisfies

(1.2)

\mathrm{R}_{2}(L[-1,1],\{\alpha n^{2}\}_{n},N)=2L+\mathcal{O}(L^{\frac{7}{8}})+\mathcal{O}((\log N)^{-1}),

for
1\leq L\leq\log N
as
N
and
L
tend to infinity.

In light of our result below, it seems plausible to expect
\{\alpha n^{2}\}_{n}
to exhibit Poissonian pair correlation if
\alpha
is Diophantine of type
3-\epsilon
for any
\epsilon>0
. In fact, this would follow from a conjecture due to Truelsen
[
Tru10
]
on the average value of
\tau_{M,N}(n)=\#\{(a,b)\in\mathbb{N}^{2}\,|\,a\leq M,\,b\leq N,\,ab=n\}

in short arithmetic progressions.

1.3.

Heath-Brown’s result (
1.2
) motivates the following notion, already introduced by Nair and Pollicott
[
NP07
]
. Namely, for
0\leq\sigma<2
let us set

\mathrm{R}_{2}^{\sigma}([a,b],\{\theta_{n}\}_{n},N)=\frac{1}{N^{2-\sigma}}\#\bigg\{1\leq j\neq k\leq N\,\bigg|\,\theta_{j}-\theta_{k}\in\bigg[\frac{a}{N^{\sigma}},\frac{b}{N^{\sigma}}\bigg]+\mathbb{Z}\bigg\}.

We say that a deterministic sequence
\{\theta_{n}\}_{n}
has
\sigma
-pair correlation
if

(1.3)

\mathrm{R}_{2}^{\sigma}([a,b],\{\theta_{n}\},N)\to b-a,\text{ as }N\to\infty,

holds for all intervals
[a,b]
. The case
\sigma=0
corresponds vaguely speaking to that of equidistribution on
[0,1]
and the case
\sigma=1
to that of Poissonian pair correlation. Moreover, note that for any two
0\leq\sigma_{1},\sigma_{2}<2

\mathrm{R}_{2}^{\sigma_{2}}([a,b],\{\theta_{n}\}_{n},N)=\frac{1}{N^{\sigma_{1}-\sigma_{2}}}\mathrm{R}_{2}^{\sigma_{1}}(N^{\sigma_{1}-\sigma_{2}}[a,b],\{\theta_{n}\},N)

and thus if a sequence
\{\theta_{n}\}_{n}
exhibits
\sigma
-pair correlation for some
\sigma
, then

\mathrm{R}_{2}(N^{1-\sigma}[a,b],\{\theta_{n}\}_{n},N)\sim N^{1-\sigma}(b-a),\text{ as }N\to\infty.

Analogously to the case
\sigma=1
, it is known that a sequence exhibiting
\sigma
-pair correlation for some
0<\sigma<1
is equidistributed in
[0,1]
(see
[
Ste20
]
).

In this note we obtain for the sequence
\theta_{n}=\alpha n^{2}
the following result

Theorem 1.1
.

Let
0\leq\sigma<1
and
2\leq\kappa<1+\frac{2}{\sigma}
. Suppose
\alpha
is Diophantine of type
\kappa
, then
\{\alpha n^{2}\}_{n}
exhibits
\sigma
-pair correlation (
1.3
), that is

(1.4)

\mathrm{R}_{2}^{\sigma}([a,b],\{\alpha n^{2}\},N)\to b-a,\text{ as }N\to\infty,

for all intervals
[a,b]
.

Let us note that the same method can be applied to other sequences of interest like the fractional parts of
\{\frac{\alpha n^{2}}{N}\}_{1\leq n\leq N}
(see
[
Mar10
]
).

In this context it is natural to understand the set of
0\leq\sigma<2
for which
\{\theta_{n}\}_{n}
exhibits
\sigma
-pair correlation. One can ask how large
\sigma
can be taken as to still expect the sequence
\{\theta_{n}\}_{n}
to exhibit
\sigma
-pair correlation. Thus, let us introduce the following quantity

\sigma(\{\theta_{n}\}_{n}):=\sup\bigg\{0\leq\sigma<2\,\bigg|\,\{\theta_{n}\}_{n}\text{ exhibits }\sigma\text{-pair correlation}\bigg\}.

With this notation,
Theorem

1.1
clearly implies

Corollary 1.2
.

Let
\alpha\in\mathbb{R}
be Diophantine of type
3-\epsilon
for any
\epsilon>0
, then
\sigma(\{\alpha n^{2}\})\geq 1
.

Moreover, for almost every
\alpha
we obtain using the approach of Rudnick and Sarnak
[
RS98
]

Theorem 1.3
.

For any
0\leq\sigma<\frac{1}{4}(9-\sqrt{17})=1.21922...
there is a set
P\subset\mathbb{R}
of full Lebesgue measure such that
\{\alpha n^{2}\}_{n}
exhibits
\sigma
-pair correlation for all
\alpha\in P
.

Similarly as above, this implies

Corollary 1.4
.

For almost all
\alpha\in\mathbb{R}
we have
\sigma(\{\alpha n^{2}\}_{n})\geq\frac{1}{4}(9-\sqrt{17})
.

More generally, for the sequence
\{\alpha n^{d}\}_{n}
with
d\geq 3
, we obtain in analogy to
Theorem

1.3
.

Theorem 1.5
.

For any
0\leq\sigma<2+2^{-d}-\sqrt{1+4^{-d}}
there is a set
P\subset\mathbb{R}
of full Lebesgue measure such that
\{\alpha n^{d}\}_{n}
exhibits
\sigma
-pair correlation for all
\alpha\in P
. Note that
2+2^{-d}-\sqrt{1+4^{-d}}>1
for all
d\in\mathbb{N}
and this expression converges to
1
as
d
tends to infinity.

The proof of
Theorem

1.5
goes along the exact same lines as that of
Theorem

1.3
with some minor modifications. A question that arises out of this study – albeit beyond the scope of this note – is whether there are numbers
\alpha
for which the sequence
\{\alpha n^{d}\}_{n}
exhibits
\sigma
-pair correlation for some
\sigma\geq 2+2^{-d}-\sqrt{1+4^{-d}}
.

1.4.

The strategy of the proof of
Theorem

1.1
is classical and relies on studying the frequency side of the counting problem

\frac{1}{N^{2-\sigma}}\#\bigg\{1\leq j\neq k\leq N\,\bigg|\,\alpha(j^{2}-k^{2})\in\bigg[\frac{a}{N^{\sigma}},\frac{b}{N^{\sigma}}\bigg]+\mathbb{Z}\bigg\}.

As this counting problem lies on the torus, it translates on the frequency side to sums of
theta sums
. For context, the classical problem of counting values of quadratic forms at integral points, which lies on the real line, translates on the frequency side to integrals of
theta sums
(see
[
BD58
,
Mar03
,
Göt04
,
But+22
]
).

We can view this problem as a counting problem regarding the distribution of values of the quadratic form
\begin{pmatrix}\alpha&0\\
0&-\alpha\end{pmatrix}
modulo one at integral points away from the isotropic rational subspaces.

From this point of view, two difficulties arise: On the one hand, the stabilizer of this form is a torus and thus we cannot exploit some standard techniques from homogeneous dynamics. On the other hand, the main difficulty in our case is the avoidance of isotropic rational subspaces. More precisely, the counting problem above leads us to study sums of the form

\sum_{n\in\mathbb{Z}\setminus\{0\}}\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\mathrm{i}\Omega_{n}(x,y)},

where
\Omega_{n}
is a quadratic form in the Siegel upper half-space of degree two such that the rational isotropic subspaces of the real part are precisely
\{(x,y)\in\mathbb{Z}^{2}\,|\,x=\pm y\}
. In
Lemma

3.3
we show that such an expression can essentially be rewritten as the difference of two theta series. However, we are unable to exploit this difference, which is the likely culprit of the deficiency in
Theorem

1.1
. Nevertheless, building upon a method going back to the seminal work of Götze
[
Göt04
]
, the bounds we obtain for both of these theta series are related to the number of Diophantine approximations
\alpha
up to a certain height. Vaguely speaking, the proof of
Theorem

1.1
reduces to the following counting problem

\frac{1}{N}\#\bigg\{\bm{v}\in\begin{pmatrix}N^{\frac{2+\sigma}{2}}&\\
&N^{-\frac{2+\sigma}{2}}\end{pmatrix}\begin{pmatrix}1&\alpha\\
&1\end{pmatrix}\mathbb{Z}^{2}\,\bigg|\,\|\bm{v}\|\leq N^{\frac{\sigma}{2}}\bigg\},

which can be seen to be of order
\mathcal{O}(N^{\sigma-1})
as long as
\alpha
is Diophantine of type specified in
Theorem

1.1
.

1.5.

Let us mention a few related results and further extensions regarding the pair correlation problem.

Zelditch
[
Zel98a
,
Zel98
]
studied the pair correlation for sequences of the form
\alpha N\phi(\frac{n}{N})+\beta n
, where
\phi
is a fixed polynomial satisfying
\phi^{\prime\prime}\neq 0
on
[-1,1]
and obtained metric results, similar to that of Sarnak and Rudnick
[
RS98
]
, with the caveat of dealing with the averaged pair correlation function. Marklof and Yesha
[
MY18
]
were able to prove and expand on Zelditch’s averaged pair correlation for the special case
\frac{(n-\alpha)^{2}}{2N}
for explicit
\alpha
satisfying a Diophantine condition.

Boca and Zaharescu
[
BZ00
]
studied the pair correlation of sequences of the form
\{f(n)\mod p\}_{1\leq n\leq N}
, where
f
is a rational function with integer coefficients.

Rudnick and Zaharescu
[
RZ99
]
obtained metric results for sequences of the form
\{\alpha a(n)\}
, where
a(n)
is a lacunary sequence. This motivated the study of the pair correlation problem from the point of view of the so-called additive energy (for a set
A
of real numbers, the additive energy
E(A)
is defined to be
\#\{(a,b,c,d)\in A^{4}\,|\,a+b=c+d\}
), which has proven to yield fruitful results. Let us mention in this regard results of Aistleitner, Larcher and Lewko
[
ALL17
]
, Bloom and Walker
[
BW20
]
, Aistleitner, El-Baz and Munsch
[
AEM21
]
.

The pair correlation of the sequence
\{\alpha n^{\theta}\}_{n}
has attracted special attention. For
\theta=\frac{1}{2}
, Elkies and McMullen
[
EM04
]
showed, using techniques from homogeneous dynamics, that the gap distribution of
\{\sqrt{n}\}_{n}
is not Poissonian. Surprisingly, after removing the perfect squares out of this sequence, El-Baz, Marklof and Vinogradov
[
EMV15
]
showed that the resulting sequence does exhibit Poissonian pair correlation. For
\theta\in(0,\frac{14}{41})
and
\alpha>0
, Lutsko, Sourmelidis and Technau
[
LST21
]
show that the sequence
\{\alpha n^{\theta}\}_{n}
exhibits Poissonian pair correlation without any further restrictions on
\alpha
. In particular their result gives an example of a sequence that exhibits Poissonian pair correlation, but not triple pair correlation.

1.6.

Finally let us elaborate more on the underlying motivation to this problem. The special case
d=2
is of particular interest due to its connection between number theory and theoretical physics. Namely, the distribution of spacings of the sequence
\{\alpha n^{2}\}_{n}
modulo one are related to the spacings between the energy levels of the
boxed oscillator

[
BT77
]
, a particle in a two-dimensional potential well with hard walls in one direction and harmonic binding in the other.

For a sequence of numbers
\theta_{1},\dots,\theta_{N}
modulo one, denote the corresponding
order statistics
on
[0,1]
by
\theta_{(1)}\leq\dots\leq\theta_{(N)}
. The corresponding
spacing measure
is given by

\mu_{2}(\{\theta_{n}\}_{n},N):=\frac{1}{N}\sum_{n=1}^{N}\delta_{N(\theta_{(j+1)}-\theta_{(j)})},

where we set
\theta_{(N+j)}=\theta_{(j)}
and
\delta_{x}
denotes the Dirac measure at
x
. If the sequence
\theta_{n}
arises from a sequence of independent and uniformly distributed random variables on
[0,1]
, then it is well-known that

(1.5)

\mu_{2}(\{\theta_{n}\}_{n},N)\to\mathrm{e}^{-x}\mathrm{d}x,\text{ as }N\to\infty.

We say that a deterministic sequence
\{\theta_{n}\}_{n}
is
Poissonian
if (
1.5
) holds.

The standard approach to the analysis of spacings is through
higher correlation functions
defined analogously as before by

\mathrm{R}_{k}(\prod_{i=1}^{k-1}[a_{i},b_{i}],\{\theta_{n}\}_{n},N)=\frac{1}{N}\#\bigg\{\bm{x}\in[N]^{k}\,\bigg|\,\theta_{x_{i}}-\theta_{x_{i+1}}\in[a_{i},b_{i}]\text{ for all }i\bigg\},

where
[N]^{k}
denotes the set of all
k
-tuples
\bm{x}=(x_{1},\dots,x_{k})
of
distinct
integers in
\{1,\dots,N\}
.
One can show that if all correlation functions are
Poissonian
, in the sense that

\mathrm{R}_{k}(\prod_{i=1}^{k-1}[a_{i},b_{i}],\{\theta_{n}\}_{n},N)\to\prod_{i=1}^{k-1}(b_{i}-a_{i}),\text{ as }N\to\infty,

then
\{\theta_{n}\}_{n}
is Poissonian.

In this generality, Rudnick, Sarnak and Zaharescu
[
RSZ01
]
proved that if
\alpha
is
not Diophantine of type
3
and the denominators of the corresponding rational approximations (for which the Diophantine property fails) are essentially square free, then
\{\alpha n^{2}\}_{n}
is
Poissonian along a subsequence
N_{j}
. Of course, as mentioned above, such a sequence cannot possibly be Poissonian along the entire sequence
N\in\mathbb{N}
; In fact, if
\alpha
is not Diophantine of type
3
, then there is a subsequence
N_{l}
for which
\mu_{2}(\{\alpha n^{2}\}_{n},N_{l})
converges to a measure supported on
\mathbb{N}_{0}
. Nevertheless, their analysis leads them to conjecture that
\{\alpha n^{2}\}_{n}
is
Poissonian
if
\alpha
is Diophantine of type
2+\epsilon
for every
\epsilon>0
and the denominators of the convergents to
\alpha
are essentially square free (see
[
RSZ01
]
for details).

2.
The Pair Correlation Functional and Test Functions

2.1.

Let
\{\theta_{n}\}_{n}
be a sequence and
0\leq\sigma<2
. For sufficiently fast decaying functions
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
we define the
\sigma
-pair correlation functional
to be

\mathrm{R}_{2}^{\sigma}(f,\psi,\{\theta_{n}\}_{n},N):=\frac{1}{N^{2-\sigma}}\sum_{\begin{subarray}{c}j,k\in\mathbb{Z}\\
\,|j|\neq|k|\end{subarray}}\psi\bigg(\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\bigg)\sum_{n\in\mathbb{Z}}f(N^{\sigma}(\theta_{j}-\theta_{k}+n)).

Note that with this definition we have

\mathrm{R}_{2}^{\sigma}([a,b],\{\theta_{n}\}_{n},N)=4\mathrm{R}_{2}^{\sigma}(\mathbbm{1}_{[a,b]},\mathbbm{1}_{[-1,1]^{2}},\{\theta_{n}\}_{n},N),

for any interval
[a,b]
.

2.2.

We shall approximate the indicator function corresponding to the interval
[a,b]
and the square
[-1,1]^{2}
from above and from below by a class of functions that are well-suited to this problem. More precisely, we will call a pair of functions
f:\mathbb{R}\to\mathbb{R},\psi:\mathbb{R}^{2}\to\mathbb{R}

test functions of class
\mathcal{P}
if

(2.1)

\displaystyle\begin{aligned} \widehat{f}\in C_{c}(\mathbb{R})\text{ or }\widehat{f}(t)=\mathrm{e}^{-2\pi|t|}\text{ and }\widehat{\psi}\in C_{c}(\mathbb{R}^{2}).\end{aligned}

The following approximation lemma by functions whose Fourier transform is compactly supported is well-known and modified slightly from
[
Mar03
]
(see §8.6.2-8.6.4). We provide a proof for completeness.

Lemma 2.1
.

Let
I\subset\mathbb{R}
be a closed (finite) interval,
g:\mathbb{R}\to\mathbb{R}_{\geq 0}
a non-negative and continuous function and
\epsilon>0
. There exist functions
h_{-}
and
h_{+}
such that

(2.2)

\displaystyle\begin{aligned} &\widehat{h_{\pm}}\in C_{c}(\mathbb{R}),\\
&-\frac{\epsilon}{\pi(1+s^{2})}\leq h_{-}(s)\leq g(s)\mathbbm{1}_{I}(s)\leq h_{+}(s),\;\text{ for all }s\in\mathbb{R},\\
&\int_{I}g(s)\,\mathrm{d}s\leq\widehat{h_{+}}(0)\leq\int_{I}g(s)\,\mathrm{d}s+\epsilon,\\
&\int_{I}g(s)\,\mathrm{d}s-\epsilon\leq\widehat{h_{-}}(0)\leq\int_{I}g(s)\,\mathrm{d}s.\end{aligned}

Proof.

Let
\chi_{\pm}\in C_{c}^{\infty}(\mathbb{R})
be compactly supported and continuous functions such that

\displaystyle 0\leq\chi_{-}\leq g\cdot\mathbbm{1}_{I}\leq\chi_{+},

\displaystyle\int_{\mathbb{R}}(\chi_{+}-\chi_{-})\mathrm{d}s<\epsilon.

Let us set

\displaystyle h_{\pm,\epsilon}(s)=\chi_{\pm}(s)\pm\frac{\epsilon}{\pi(1+s^{2})}.

Then,

\displaystyle 0\leq h_{-,\epsilon}(s)+\frac{\epsilon}{\pi(1+s^{2})}\leq g(s)\leq h_{+,\epsilon}(s)-\frac{\epsilon}{\pi(1+s^{2})},

\displaystyle\widehat{h_{\pm,\epsilon}}(u)=\widehat{\chi_{\pm}}(u)\pm\epsilon\,\mathrm{e}^{-2\pi|u|}.

Next, fix a continuous and compactly supported function
\chi\in C_{c}(\mathbb{R})
such that

\displaystyle\text{supp}(\chi)\subseteq[-2,2],

\displaystyle 0\leq\chi\leq 1,

\displaystyle\chi|_{[-1,1]}\equiv 1.

For
P\geq 1
, to be determined below, set

\displaystyle\widehat{h_{\pm,\epsilon,P}}(u)=\widehat{h_{\pm,\epsilon}}(u)\chi(\frac{u}{P})

and observe that
\widehat{h_{\pm,\epsilon,P}}\in C_{c}(\mathbb{R})
is continuous and compactly supported with
\text{supp}(\widehat{h_{\pm,\epsilon,P}})\subset[-2P,2P]
.
We claim that we can choose
P\geq 1
, depending on
\epsilon
and
\chi_{\pm}
only, such that

\displaystyle|h_{\pm,\epsilon,P}(s)-h_{\pm,\epsilon}(s)|\leq\frac{\epsilon}{\pi(1+s^{2})},\;\text{ for any }s\in\mathbb{R}.

Indeed, for some
C
depending on
\epsilon
and
\chi_{\pm}
we have on the one hand

\displaystyle|h_{\pm,\epsilon,P}(s)-h_{\pm,\epsilon}(s)|

\displaystyle\leq\int_{\mathbb{R}}|\widehat{h_{\pm,\epsilon}}(u)|\bigg(1-\chi\big(\frac{u}{P}\big)\bigg)\mathrm{d}u

\displaystyle\leq\int_{|u|\geq P}|\widehat{h_{\pm,\epsilon}}(u)|\,\mathrm{d}u\leq\frac{C}{P},

on the other hand, after integrating by parts twice,

\displaystyle|h_{\pm,\epsilon,P}(s)

\displaystyle-h_{\pm,\epsilon}(s)|

\displaystyle\leq\frac{1}{4\pi^{2}s^{2}}\bigg(\int_{|u|\geq P}|\widehat{h_{\pm,\epsilon}}^{\prime\prime}(u)|\mathrm{d}u

\displaystyle\qquad\qquad\qquad+\frac{2}{P}\int_{\mathbb{R}}|\widehat{h_{\pm,\epsilon}}^{\prime}(u)\chi\big(\frac{u}{P}\big)|\mathrm{d}u

\displaystyle\qquad\qquad\qquad\qquad\quad+\frac{1}{P^{2}}\int_{\mathbb{R}}|\widehat{h_{\pm,\epsilon}}(u)\chi^{\prime\prime}\big(\frac{u}{P}\big)|\mathrm{d}u\bigg)

\displaystyle\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\quad\leq\frac{C}{Ps^{2}}

and thus

\displaystyle|h_{\pm,\epsilon,P}(s)-h_{\pm,\epsilon}(s)|\leq\frac{C}{P}\min\bigg\{1,\frac{1}{s^{2}}\bigg\}\leq\frac{\epsilon}{\pi(1+s^{2})},

whenever
P\geq 2C\pi\epsilon^{-1}
. Hence, we conclude that

\displaystyle g(s)\mathbbm{1}_{I}(s)

\displaystyle\geq h_{-,\epsilon,P}(s)\geq g(s)\mathbbm{1}_{I}(s)-(\chi_{+}(s)-\chi_{-}(s))-2\frac{\epsilon}{\pi(1+s^{2})}

\displaystyle g(s)\mathbbm{1}_{I}(s)

\displaystyle\leq h_{+,\epsilon,P}(s)\leq g(s)\mathbbm{1}_{I}(s)+(\chi_{+}(s)-\chi_{-}(s))+2\frac{\epsilon}{\pi(1+s^{2})},

for all
s\in\mathbb{R}
, which implies

\displaystyle\widehat{g\cdot\mathbbm{1}_{I}}(0)\leq\int_{\mathbb{R}}h_{+,\epsilon,P}(s)\,\mathrm{d}s\leq\widehat{g\cdot\mathbbm{1}_{I}}(0)+3\epsilon,

\displaystyle\widehat{g\cdot\mathbbm{1}_{I}}(0)-3\epsilon\leq\int_{\mathbb{R}}h_{-,\epsilon,P}(s)\,\mathrm{d}s\leq\widehat{g\cdot\mathbbm{1}_{I}}(0).

Finally, also note by construction that

\displaystyle h_{-,\epsilon,P}\geq-\frac{\epsilon}{\pi(1+s^{2})}+h_{-,\epsilon}=\chi_{-}-2\frac{\epsilon}{\pi(1+s^{2})}\geq-2\frac{\epsilon}{\pi(1+s^{2})},

where we use that
\chi_{-}
is non-negative.
∎

2.3.

The sufficiency of the class of test functions introduced above is established by the following

Lemma 2.2
.

Suppose that for any two test functions
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
of class
\mathcal{P}
(see (
2.1
)) the following identity holds

\displaystyle\lim_{N\to\infty}\mathrm{R}_{2}^{\sigma}(f,\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)=\widehat{f}(0)\big(\mathcal{F}({\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}}})\big)(\bm{0}),

where
\cdot
denotes pointwise multiplication of two functions.
Then, for any
a<b

\displaystyle\lim_{N\to\infty}\mathrm{R}_{2}^{\sigma}([a,b],\{\theta_{j}\}_{j},N)=b-a.

Proof.

Let
\epsilon>0
. According to
Lemma

2.1
we can find
f_{\pm}:\mathbb{R}\to\mathbb{R}
such that

(2.3)

\displaystyle\begin{aligned} &\widehat{f_{\pm}}\in C_{c}(\mathbb{R}),\\
&-\frac{\epsilon}{\pi(1+s^{2})}\leq f_{-}(s)\leq\mathbbm{1}_{[a,b]}(s)\leq f_{+}(s),\;\text{ for all }s\in\mathbb{R},\\
&b-a\leq\widehat{f_{+}}(0)\leq b-a+\epsilon,\\
&b-a-\epsilon\leq\widehat{f_{-}}(0)\leq b-a.\end{aligned}

as well as
\psi_{\pm}:\mathbb{R}^{2}\to\mathbb{R}
satisfying

(2.4)

\displaystyle\begin{aligned} &\widehat{\psi_{\pm}}\in C_{c}(\mathbb{R}^{2}),\\
&\psi_{-}(\bm{v})\leq\mathbbm{1}_{[-1,1]^{2}}(\bm{v})\,\mathrm{e}^{\|\bm{v}\|^{2}}\leq\psi_{+}(\bm{v}),\;\text{ for all }\bm{v}\in\mathbb{R}^{2}\\
&\int_{[-1,1]^{2}}\mathrm{e}^{\|\bm{v}\|^{2}}\mathrm{d}\bm{v}\leq\widehat{\psi_{+}}(\bm{0})\leq\int_{[-1,1]^{2}}\mathrm{e}^{\|\bm{v}\|^{2}}\mathrm{d}\bm{v}+\epsilon,\\
&\int_{[-1,1]^{2}}\mathrm{e}^{\|\bm{v}\|^{2}}\mathrm{d}\bm{v}-\epsilon\leq\widehat{\psi_{-}}(\bm{0})\leq\int_{[-1,1]^{2}}\mathrm{e}^{\|\bm{v}\|^{2}}\mathrm{d}\bm{v}.\end{aligned}

By assumption, there is
N_{0}\in\mathbb{N}
such that for any
N\geq N_{0}

(2.5)

\displaystyle\big|R_{2}^{\sigma}(f_{\pm},\psi_{\pm}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)-\widehat{f}_{\pm}(0)\big(\mathcal{F}(\psi_{\pm}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})\big|<\epsilon,

(2.6)

\displaystyle\big|R_{2}^{\sigma}(\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})},\psi_{\pm}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)-2\epsilon\,\mathcal{F}(\psi_{\pm}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})(\bm{0})\big|<\epsilon,

where we use that

\displaystyle\int_{\mathbb{R}}\frac{\mathrm{e}^{-2\pi\mathrm{i}us}\mathrm{d}s}{\pi(1+s^{2})}=\mathrm{e}^{-2\pi|u|}.

Let
N\geq N_{0}
. Using (
2.3
), (
2.4
), (
2.5
) and (
2.6
), we obtain the upper bound

\displaystyle 4\mathrm{R}_{2}^{\sigma}({[a,b],\{\theta_{j}\}_{j},N})-4(b-a)

\displaystyle\quad\leq\mathrm{R}_{2}^{\sigma}(f_{+},\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)-\widehat{f_{-}}(0)\big(\mathcal{F}(\psi_{-}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\leq\epsilon+\widehat{f_{+}}(0)\big(\mathcal{F}(\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})-\widehat{f_{-}}(0)\big(\mathcal{F}(\psi_{-}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\quad=\epsilon+(\widehat{f_{+}}(0)-\widehat{f_{-}}(0))\big(\mathcal{F}(\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\quad\quad\quad\quad+\widehat{f_{-}}(0)\int_{\mathbb{R}^{2}}(\psi_{+}(\bm{v})-\psi_{-}(\bm{v}))\mathrm{e}^{-\|\bm{v}\|^{2}}\,\mathrm{d}\bm{v}

\displaystyle\quad\quad\quad\quad\quad\leq\epsilon+2\epsilon(12+\epsilon)+2\epsilon(b-a).

The corresponding lower bound is more delicate as
f_{-}
is not everywhere positive. However, due to
Lemma

2.1
,
f_{-}+\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})}\geq 0
as well as (
2.3
), (
2.4
), (
2.5
) and (
2.6
), we obtain

\displaystyle 4\mathrm{R}_{2}^{\sigma}({[a,b],\{\theta_{j}\}_{j},N})-4(b-a)

\displaystyle\quad\quad\quad\quad-\mathrm{R}_{2}^{\sigma}(\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})},\mathbbm{1}_{[-1,1]^{2}},\{\theta_{j}\}_{j},N)

\displaystyle\quad\geq\mathrm{R}_{2}^{\sigma}(f_{-},\psi_{-}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)-\widehat{f_{+}}(0)\big(\mathcal{F}(\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\quad\quad-\mathrm{R}_{2}^{\sigma}(\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})},(\psi_{+}-\psi_{-})\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)

\displaystyle\quad\geq-\epsilon+\widehat{f_{-}}(0)\big(\mathcal{F}(\psi_{-}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})-\widehat{f_{+}}(0)\big(\mathcal{F}(\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\quad\quad-\mathrm{R}_{2}^{\sigma}(\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})},(\psi_{+}-\psi_{-})\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)

\displaystyle\quad\quad\quad\quad-\widehat{f_{-}}(0)\int_{\mathbb{R}^{2}}(\psi_{+}(\bm{v})-\psi_{-}(\bm{v}))\mathrm{e}^{-\|\bm{v}\|^{2}}\mathrm{d}\bm{v}

\displaystyle\quad\quad\quad\quad\quad\quad-\mathrm{R}_{2}^{\sigma}(\frac{2\epsilon}{\pi(1+(\,\cdot\,)^{2})},(\psi_{+}-\psi_{-})\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)

\displaystyle\quad\geq-2\epsilon-(\widehat{f_{+}}(0)-\widehat{f_{-}}(0))\big(\mathcal{F}(\psi_{+}\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\big)(\bm{0})

\displaystyle\quad\quad\quad\quad-\widehat{f_{-}}(0)\int_{\mathbb{R}^{2}}(\psi_{+}(\bm{v})-\psi_{-}(\bm{v}))\mathrm{e}^{-\|\bm{v}\|^{2}}\mathrm{d}\bm{v}

\displaystyle\quad\geq-\epsilon-2\epsilon(12+\epsilon)-2\epsilon(b-a)-4\epsilon^{2}.

∎

2.4.

The following lemma allows us to establish the connection to the Geometry of Numbers in the next section. In fact, it shows that the main error term is roughly speaking an
incomplete theta sum
.

Lemma 2.3
.

Let
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
be test functions of class
\mathcal{P}
(see (
2.1
)). Then,

\displaystyle\mathrm{R}_{2}^{\sigma}(f,\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)

\displaystyle\quad=\widehat{f}(0)\mathcal{F}(\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})(\bm{0})

\displaystyle\qquad\quad+\widehat{f}(0)\bigg(\frac{1}{N^{2}}\sum_{\begin{subarray}{c}j,k\in\mathbb{Z}\\
|j|\neq|k|\end{subarray}}(\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\bigg(\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\bigg)-\widehat{f}(0)\mathcal{F}(\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})(\bm{0})\bigg)

\displaystyle\qquad\qquad\quad+\frac{1}{N^{2}}\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\sum_{n\neq 0}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)S(\{\theta_{j}\}_{j},N,n,\bm{\xi})\mathrm{d}\bm{\xi},

where
S(\{\theta_{j}\}_{j},N,n,\bm{\xi})
is given by

\displaystyle\sum_{\begin{subarray}{c}j,k\in\mathbb{Z}\\
|j|\neq|k|\end{subarray}}\exp\bigg\{-\frac{1}{N^{2}}(j^{2}+k^{2})+2\pi\mathrm{i}n(\theta_{j}-\theta_{k})+2\pi\mathrm{i}\langle\bm{\xi},\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\rangle\bigg\},

where
\langle\,\cdot\,,\,\cdot\,\rangle
denotes the Euclidean inner product. Let us remark that the second sum is
o(1)
as
N\to\infty
.

Proof.

Let
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
be test functions of class
\mathcal{P}
. The Poisson summation formula implies that
\mathrm{R}_{2}^{\sigma}(f,\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)
can be rewritten as

\displaystyle\widehat{f}(0)\frac{1}{N^{2}}\sum_{\begin{subarray}{c}j,k\in\mathbb{Z}\\
|j|\neq|k|\end{subarray}}(\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})\bigg(\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\bigg)

\displaystyle\qquad+\frac{1}{N^{2}}\sum_{n\neq 0}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)\sum_{\begin{subarray}{c}j,k\in\mathbb{Z}\\
|j|\neq|k|\end{subarray}}\psi\bigg(\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\bigg)\mathrm{e}^{-\frac{1}{N^{2}}(j^{2}-k^{2})}.

Finally, it suffices to note that

\displaystyle\psi\bigg(\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\bigg)=\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\mathrm{e}\bigg(\langle\bm{\xi},\frac{1}{N}\begin{pmatrix}j\\
k\end{pmatrix}\rangle\bigg)\,\mathrm{d}\bm{\xi}

and switch the order of integration and summation to obtain the claim.
∎

Let us record the following observation: Suppose that any two test functions
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
of class
\mathcal{P}
(see (
2.1
)) satisfy

\displaystyle\lim_{N\to\infty}\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\sum_{n\neq 0}\widehat{f}\bigg(\frac{n}{N}\bigg)S(\{\theta_{j}\}_{j},N,n,\bm{\xi})\mathrm{d}\bm{\xi}=0,

where
S(\{\theta_{j}\}_{j},N,n,\bm{\xi})
is as defined in
Lemma

2.3
. Then,

\displaystyle\lim_{N\to\infty}\mathrm{R}_{2}^{\sigma}(f,\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j}\}_{j},N)=\widehat{f}(0)\mathcal{F}(\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}})(\bm{0}).

Thus, it will be convenient to introduce the following error term

\displaystyle\mathrm{E}^{\sigma}(f,\psi,\{\theta_{j}\}_{j},N):=\frac{1}{N^{2}}\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\,\sum_{n\neq 0}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)S(\{\theta_{j}\}_{j},N,n,\bm{\xi})\mathrm{d}\bm{\xi},

for any test functions
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
of class
\mathcal{P}
.

3.
Passage to the Geometry of Numbers

3.1.

For
\mathfrak z=\mathfrak a+\mathrm{i}\mathfrak b\in\mathbb{H}
, where
\mathbb{H}
denotes the upper half plane, and
\bm{\xi}\in\mathbb{R}^{2}
let us introduce

\displaystyle\Omega_{\mathfrak z,\bm{\xi}}(x,y):=\pi\mathrm{i}\bigg(\mathfrak a(x^{2}-y^{2})+\mathrm{i}\mathfrak b(x^{2}+y^{2})\bigg)+2\pi\mathrm{i}\langle\bm{\xi},\begin{pmatrix}x\\
y\end{pmatrix}\rangle,\,(x,y)\in\mathbb{R}^{2}

as well as

\displaystyle\Psi_{\mathfrak z,\bm{\xi}}(x,y):=\exp\bigg\{\Omega_{\mathfrak z,\bm{\xi}}(x+y,x-y)\bigg\},\,(x,y)\in\mathbb{R}^{2}.

In this section we will show that

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}

can be thought of as the difference of two classical theta functions missing its leading terms. Many of the ideas contained in the next couple of paragraphs can be traced back to the work of Götze
[
Göt04
]
on quadratic forms.

Lemma 3.1
.

Let
\mathfrak z\in\mathbb{H}
and
\bm{\xi}\in\mathbb{R}^{2}
. Then,

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}=\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
xy\neq 0\end{subarray}}\Psi_{\mathfrak z,\bm{\xi}}(x,y)+\sum_{(x,y)\in\mathbb{Z}^{2}}\Psi_{\mathfrak z,\bm{\xi}}\big(x-\frac{1}{2},y+\frac{1}{2}\big).

Proof.

For
b\in\{0,1\}
let us set
\mathbb{Z}_{b}:=\{x\in\mathbb{Z}\,|\,x\equiv b\text{ mod }2\}
. The maps

\displaystyle\chi^{+}:\mathbb{Z}_{0}^{2}\cup\mathbb{Z}_{1}^{2}

\displaystyle\longrightarrow\mathbb{Z}^{2}

\displaystyle(x,y)

\displaystyle\longmapsto(\chi_{1}^{+}(x,y),\chi_{2}^{+}(x,y))=\bigg(\frac{x+y}{2},\frac{x-y}{2}\bigg),

\displaystyle\chi^{-}:(\mathbb{Z}_{0}\times\mathbb{Z}_{1})\cup(\mathbb{Z}_{1}\cup\mathbb{Z}_{0})

\displaystyle\longrightarrow\mathbb{Z}^{2}

\displaystyle(x,y)

\displaystyle\longmapsto(\chi_{1}^{-}(x,y),\chi_{2}^{-}(x,y))=\bigg(\frac{x+y+1}{2},\frac{x-y-1}{2}\bigg),

are bijections and with this notation note that
\big\{(x,y)\in\mathbb{Z}^{2}\,\big|\,|x|\neq|y|\big\}
can be partitioned as follows

\displaystyle(\mathbb{Z}_{0}\times\mathbb{Z}_{1})\cup(\mathbb{Z}_{1}\times\mathbb{Z}_{0})\cup\bigg\{(x,y)\in\mathbb{Z}_{0}^{2}\cup\mathbb{Z}_{1}^{2}\,\bigg|\chi_{1}^{+}(x,y)\chi_{2}^{+}(x,y)\neq 0\bigg\}.

For
(x,y)\in(\mathbb{Z}_{0}\times\mathbb{Z}_{1})\cup(\mathbb{Z}_{1}\times\mathbb{Z}_{0})
we have

\displaystyle\Omega_{\mathfrak z,\bm{\xi}}(x,y)=\Omega_{\mathfrak z,\bm{\xi}}(\chi_{1}^{-}(x,y)+\chi_{2}^{-}(x,y),\chi_{1}^{-}(x,y)-\chi_{2}^{-}(x,y)-1),

and for
(x,y)\in\mathbb{Z}_{0}^{2}\cup\mathbb{Z}_{1}^{2}
we have

\displaystyle\Omega_{\mathfrak z,\bm{\xi}}(x,y)=\Omega_{\mathfrak z,\bm{\xi}}(\chi_{1}^{+}(x,y)+\chi_{2}^{+}(x,y),\chi_{1}^{+}(x,y)-\chi_{2}^{+}(x,y)).

∎

Lemma 3.2
.

Let
\mathfrak z\in\mathbb{H}
and
\bm{\xi}\in\mathbb{R}^{2}
. Then,

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}

\displaystyle\qquad=\Psi_{\mathfrak z,\bm{\xi}}(\bm{0})+\bigg(2\sum_{x,y\in\mathbb{Z}^{2}}\Psi_{\mathfrak z,\bm{\xi}}(x,y)-\sum_{y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(0,y)-\sum_{x\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,0)\bigg)

\displaystyle\qquad\qquad+\sum_{x,y\in\mathbb{Z}^{2}}\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(x,\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},y)\bigg).

Note here, that
\Psi_{\mathfrak z,\bm{\xi}}(\bm{0})=1
.

Proof.

For simplicity let us write
\Omega_{\mathfrak z,\bm{\xi}}=\Omega
and
\Psi_{\mathfrak z,\bm{\xi}}=\Psi
. According to
Lemma

3.1
we have

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\exp\bigg\{\Omega(x,y)\bigg\}=\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
xy\neq 0\end{subarray}}\Psi(x,y)+\sum_{(x,y)\in\mathbb{Z}^{2}}\Psi\big(x-\frac{1}{2},y+\frac{1}{2}\big).

Let us first prove the following claim

\displaystyle\sum_{(x,y)\in\mathbb{Z}^{2}}\Psi\big(x-\frac{1}{2},y+\frac{1}{2}\big)=\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
xy\neq 0\end{subarray}}\bigg(\Psi(x,y)-\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg).

Fix
x\in\mathbb{Z}
, then

\displaystyle\sum_{y\in\mathbb{Z}}\Psi\big(x-\frac{1}{2},y+\frac{1}{2}\big)=\sum_{y\in\mathbb{Z}\setminus\{0\}}\bigg(\Psi(x-\frac{1}{2},\frac{y}{2})-\Psi(x-\frac{1}{2},y)\bigg)

and summing this expression over
x\in\mathbb{Z}
yields

\displaystyle\sum_{(x,y)\in\mathbb{Z}^{2}}\Psi\big(x-\frac{1}{2},y+\frac{1}{2}\big)=\sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\bigg(\Psi(x-\frac{1}{2},\frac{y}{2})-\Psi(x-\frac{1}{2},y)\bigg).

Finally, if we fix
y\in\mathbb{Z}\setminus\{0\}
, then

\displaystyle\sum_{x\in\mathbb{Z}}\Psi(x-\frac{1}{2},\frac{y}{2})=\sum_{x\in\mathbb{Z}\setminus\{0\}}\Psi(\frac{x}{2},\frac{y}{2})-\sum_{x\in\mathbb{Z}\setminus\{0\}}\Psi(x,\frac{y}{2}),\text{ and }

\displaystyle\sum_{x\in\mathbb{Z}}\Psi(x-\frac{1}{2},y)=\sum_{x\in\mathbb{Z}\setminus\{0\}}\Psi(\frac{x}{2},y)-\sum_{x\in\mathbb{Z}\setminus\{0\}}\Psi(x,y),

which proves the claim after summing these last two expressions over
y\in\mathbb{Z}\setminus\{0\}
.
Hence,

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega(x,y)}=\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
xy\neq 0\end{subarray}}\bigg(2\Psi(x,y)-\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg).

Fix
x\in\mathbb{Z}\setminus\{0\}
, then

\displaystyle\sum_{y\in\mathbb{Z}\setminus\{0\}}\bigg(2\Psi(x,y)-\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg)

\displaystyle\qquad=\sum_{y\in\mathbb{Z}}\bigg(2\Psi(x,y)+\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg)-\Psi(x,0)

and summing this expression over
x\in\mathbb{Z}\setminus\{0\}
yields

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\bigg(2\Psi(x,y)-\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg)

\displaystyle\qquad=\sum_{(x,y)\in\mathbb{Z}^{2}}\bigg(2\Psi(x,y)-\Psi(\frac{x}{2},y)-\Psi(x,\frac{y}{2})+\Psi(\frac{x}{2},\frac{y}{2})\bigg)

\displaystyle\qquad\qquad\quad-\sum_{y\in\mathbb{Z}}\Psi(0,y)-\sum_{x\in\mathbb{Z}}\Psi(x,0)+\Psi(\bm{0}).

∎

3.2.

For any
\mathfrak z=\mathfrak a+\mathrm{i}\mathfrak b\in\mathbb{H}
let us define for
b\in\{0,1\}

(3.1)

\displaystyle g_{\mathfrak z,b}:=\begin{pmatrix}\frac{1}{\sqrt{2\mathfrak b}}&\\
&\sqrt{2\mathfrak b}\end{pmatrix}\begin{pmatrix}1&2\mathfrak a\\
&1\end{pmatrix}\begin{pmatrix}2^{b}&\\
&\frac{1}{2^{b}}\end{pmatrix},

(3.2)

\displaystyle\Lambda_{\mathfrak z,b}:=g_{\mathfrak z,b}\mathbb{Z}^{2},

(3.3)

\displaystyle\Lambda^{*}_{\mathfrak z,b}=\bigg\{\bm{v}=\begin{pmatrix}v_{1}\\
v_{2}\end{pmatrix}\in\Lambda z\,\bigg|\,v_{2}\neq 0\bigg\},

and in addition to this set

(3.4)

\displaystyle\mathcal{C}_{b}(\mathfrak z,\bm{\xi},\bm{\eta}):=\sqrt{\frac{2}{\mathfrak b}}\sum_{\bm{v}\in\Lambda_{\mathfrak z,b}^{*}}\mathrm{e}^{-\pi\|\bm{v}+\frac{1}{\sqrt{2}\mathfrak b}\bm{\xi}\|^{2}+2\pi\mathrm{i}\frac{1}{\sqrt{2\mathfrak b}}\langle\bm{v},\bm{\eta}\rangle}

for any two
\bm{\xi},\bm{\eta}\in\mathbb{R}^{2}
. Note that
\sqrt{\mathfrak b}\,\mathcal{C}_{b}(\mathfrak z,\bm{\xi},\bm{\eta})
is majorized (up to a constant) from above by the Siegel transform of
\mathrm{e}^{-\pi\|\,\cdot\,\|^{2}}
over the affine lattice
\Lambda_{\mathfrak z,b}+\frac{1}{\sqrt{2\mathfrak b}}\bm{\xi}
.

Lemma 3.3
.

Let
\mathfrak z=\mathfrak a+\mathrm{i}\mathfrak b\in\mathbb{H}
and
F:\mathbb{R}^{2}\to\mathbb{R}
an integrable function which is even in the second variable, that is,
F(\xi_{1},-\xi_{2})=F(\xi_{1},\xi_{2})
. Then,

\displaystyle\int_{\mathbb{R}^{2}}F(\bm{\xi})\bigg(\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}\bigg)\,\mathrm{d}\bm{\xi}

\displaystyle\quad=\int_{\mathbb{R}^{2}}F(\bm{\xi})\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\bm{0})-\sqrt{\frac{2}{\mathfrak b}}\sum_{x\in\mathbb{Z}}\mathrm{e}^{-\frac{\pi}{2\mathfrak b}(2x+1+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}}\bigg)\,\mathrm{d}\bm{\xi}

\displaystyle\qquad+\int_{\mathbb{R}^{2}}F(\bm{\xi})\bigg(\mathcal{C}_{0}(\mathfrak z,\langle\bm{\xi},\bar{\bm{1}}\rangle\bm{e}_{1},\langle\bm{\xi},\underline{\bm{1}}\rangle\bm{e}_{2})-\mathcal{C}_{1}(\mathfrak z,\langle\bm{\xi},\bar{\bm{1}}\rangle\bm{e}_{1},\langle\bm{\xi},\underline{\bm{1}}\rangle\bm{e}_{2})\bigg)\,\mathrm{d}\bm{\xi},

where
\bar{\bm{1}}=\begin{pmatrix}1\\
1\end{pmatrix}
,
\underline{\bm{1}}=\begin{pmatrix}1\\
-1\end{pmatrix}
and
\mathcal{C}_{b}(\mathfrak z,\bm{\xi},\bm{\eta})
is defined as in (
3.4
).

Proof.

Let
\mathfrak z=\mathfrak a+\mathrm{i}\mathfrak b\in\mathbb{H}
and
\xi\in\mathbb{R}
. Recall from
Lemma

3.2
that

\displaystyle\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}

\displaystyle\qquad=\Psi(\bm{0})+\bigg(2\sum_{x,y\in\mathbb{Z}^{2}}\Psi_{\mathfrak z,\bm{\xi}}(x,y)-\sum_{y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(0,y)-\sum_{x\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,0)\bigg)

\displaystyle\qquad\qquad+\sum_{x,y\in\mathbb{Z}^{2}}\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(x,\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},y)\bigg).

A straightforward calculation shows that

\displaystyle\Omega_{\mathfrak z,\bm{\xi}}(x+y,x-y)=\pi\mathrm{i}\bigg(\mathfrak a4xy+\mathrm{i}2\mathfrak b(x^{2}+y^{2})\bigg)+2\pi\mathrm{i}x\langle\bm{\xi},\bar{\bm{1}}\rangle+2\pi\mathrm{i}y\langle\bm{\xi},\underline{\bm{1}}\rangle,

where

\bar{\bm{1}}=\begin{pmatrix}1\\
1\end{pmatrix}
and
\underline{\bm{1}}=\begin{pmatrix}1\\
-1\end{pmatrix}
. For any
r,s>0
let us state the following identities

\displaystyle\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(rx,sy)=\frac{1}{r\sqrt{2\mathfrak b}}\sum_{x,y\in\mathbb{Z}}\mathrm{e}^{-\pi s^{2}2\mathfrak by^{2}-\frac{\pi}{r^{2}2\mathfrak b}(x+2rs\mathfrak ay+r\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}y\langle s\bm{\xi},\underline{\bm{1}}\rangle},

\displaystyle\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(rx,sy)=\frac{1}{s\sqrt{2\mathfrak b}}\sum_{x,y\in\mathbb{Z}}\mathrm{e}^{-\pi r^{2}2\mathfrak bx^{2}-\frac{\pi}{s^{2}2\mathfrak b}(y+2rs\mathfrak ax+s\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}x\langle r\bm{\xi},\bar{\bm{1}}\rangle},

\displaystyle\sum_{x\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(rx,0)=\frac{1}{r\sqrt{2\mathfrak b}}\sum_{x\in\mathbb{Z}}\mathrm{e}^{-\frac{\pi}{r^{2}2\mathfrak b}(x+r\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}},

\displaystyle\sum_{y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(0,sy)=\frac{1}{s\sqrt{2\mathfrak b}}\sum_{y\in\mathbb{Z}}\mathrm{e}^{-\frac{\pi}{s^{2}2\mathfrak b}(y+s\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}}.

Let us only prove the first identity as the second one is analogous to the first one and the latter two can be inferred from the former two. Indeed, note that

\displaystyle\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(rx,sy)

\displaystyle=\sum_{y\in\mathbb{Z}}\mathrm{e}^{-2\pi s^{2}\mathfrak by^{2}+2\pi\mathrm{i}y\langle s\bm{\xi},\underline{\bm{1}}\rangle}\bigg(\sum_{x\in\mathbb{Z}}\mathrm{e}^{\pi\mathrm{i}(\mathrm{i}2r^{2}\mathfrak bx^{2})+2\pi\mathrm{i}x(2rs\mathfrak ay+\langle r\bm{\xi},\bar{\bm{1}}\rangle)}\bigg)

\displaystyle=\frac{1}{r\sqrt{2\mathfrak b}}\sum_{x,y\in\mathbb{Z}}\mathrm{e}^{-2\pi s^{2}\mathfrak by^{2}+2\pi\mathrm{i}y\langle s\bm{\xi},\underline{\bm{1}}\rangle-\frac{\pi}{r^{2}2\mathfrak b}(x+2rs\mathfrak ay+\langle r\bm{\xi},\bar{\bm{1}}\rangle)^{2}},

where we applied Poisson’s summation formula to the inner sum over
x
.

We first deduce, using the above identities, that

\displaystyle 2\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,y)-\sum_{x\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,0)-\sum_{y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(0,y)

\displaystyle\qquad=\frac{1}{\sqrt{2\mathfrak b}}\ \sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\mathrm{e}^{-\pi 2\mathfrak by^{2}-\frac{\pi}{2\mathfrak b}(x+2\mathfrak ay+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}y\langle\bm{\xi},\underline{\bm{1}}\rangle}

\displaystyle\qquad\qquad+\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in(\mathbb{Z}\setminus\{0\})\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak bx^{2}-\frac{\pi}{2\mathfrak b}(y+2\mathfrak ax+\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}x\langle\bm{\xi},\bar{\bm{1}}\rangle}.

Hence, if
F
is an even function in the second variable, it is plain to see that

\displaystyle\int_{\mathbb{R}^{2}}F(\bm{\xi})\bigg(2\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,y)-\sum_{x\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,0)-\sum_{y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(0,y)\bigg)\,\mathrm{d}\bm{\xi}

\displaystyle\quad=\sqrt{\frac{2}{\mathfrak b}}\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\mathrm{e}^{-\pi 2\mathfrak by^{2}-\frac{\pi}{2\mathfrak b}(x+2\mathfrak ay+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}y\langle\bm{\xi},\underline{\bm{1}}\rangle}\,\mathrm{d}\bm{\xi}.

On the other hand, we have

\displaystyle\frac{1}{2}\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})

\displaystyle\quad=\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{\mathfrak 2b}(2x+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}

and

\displaystyle\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(x,\frac{y}{2})

\displaystyle\quad=\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{2\mathfrak b}(x+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}

\displaystyle\quad=\frac{1}{2}\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})+\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{2\mathfrak b}(2x+1+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}.

Similarly, by symmetry from the previous case, we deduce

\displaystyle\frac{1}{2}\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})

\displaystyle\quad=\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{x}{2})^{2}-\frac{\pi}{2\mathfrak b}(2y+2\mathfrak a\frac{x}{2}+\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{x}{2}\langle\bm{\xi},\bar{\bm{1}}\rangle}

and

\displaystyle\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},y)

\displaystyle\quad=\frac{1}{2}\sum_{x,y\in\mathbb{Z}}\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})+\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{x}{2})^{2}-\frac{\pi}{2\mathfrak b}(2y+1+2\mathfrak a\frac{x}{2}+\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{x}{2}\langle\bm{\xi},\bar{\bm{1}}\rangle}.

Thus, we conclude that

\displaystyle\sum_{x,y\in\mathbb{Z}}\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(x,\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},y)\bigg)

\displaystyle\quad=-\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{2\mathfrak b}(2x+1+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}

\displaystyle\quad\quad\quad-\frac{1}{\sqrt{2\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{x}{2})^{2}-\frac{\pi}{2\mathfrak b}(2y+1+2\mathfrak a\frac{x}{2}+\langle\bm{\xi},\underline{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{x}{2}\langle\bm{\xi},\bar{\bm{1}}\rangle}.

and after integrating this expression against
F
, we obtain

\displaystyle\int_{\mathbb{R}^{2}}F(\bm{\xi})\sum_{x,y\in\mathbb{Z}}\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(x,\frac{y}{2})-\Psi_{\mathfrak z,\bm{\xi}}(\frac{x}{2},y)\bigg)\,\mathrm{d}\bm{\xi}

\displaystyle\quad=-\sqrt{\frac{2}{\mathfrak b}}\int_{\mathbb{R}^{2}}F(\bm{\xi})\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{2\mathfrak b}(2x+1+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}\,\mathrm{d}\bm{\xi}.

It is then easy to see that

\displaystyle\int_{\mathbb{R}^{2}}F(\bm{\xi})\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\mathrm{e}^{\Omega_{\mathfrak z,\bm{\xi}}(x,y)}\,\mathrm{d}\bm{\xi}

\displaystyle\quad=\int_{\mathbb{R}^{2}}F(\bm{\xi})\bigg(\Psi_{\mathfrak z,\bm{\xi}}(\bm{0})+\sqrt{\frac{2}{\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\mathrm{e}^{-\pi 2\mathfrak by^{2}-\frac{\pi}{2\mathfrak b}(x+2\mathfrak ay+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}y\langle\bm{\xi},\underline{\bm{1}}\rangle}

\displaystyle\quad\quad-\sqrt{\frac{2}{\mathfrak b}}\sum_{(x,y)\in\mathbb{Z}\times\mathbb{Z}}\mathrm{e}^{-\pi 2\mathfrak b(\frac{y}{2})^{2}-\frac{\pi}{2\mathfrak b}(2x+1+2\mathfrak a\frac{y}{2}+\langle\bm{\xi},\bar{\bm{1}}\rangle)^{2}+2\pi\mathrm{i}\frac{y}{2}\langle\bm{\xi},\underline{\bm{1}}\rangle}\bigg)\,\mathrm{d}\bm{\xi}

∎

Lemma 3.4
.

Let
\theta_{j}=\displaystyle{\alpha j^{2}}
and let

\displaystyle\mathrm{E}^{\sigma}(f,\psi,\{\theta_{j}\}_{j},N)\ll_{\psi,f}\frac{1}{N}+\mathrm{E}^{\sigma}_{\epsilon}(\psi,\{\theta_{j}\}_{j},N),

where

\displaystyle\frac{1}{N^{2}}\int_{\mathbb{R}^{2}}|\widehat{\psi}(\bm{\xi})|\sum_{1\leq|n|\leq N^{\sigma+\epsilon}}\sum_{b\in\{0,1\}}\mathcal{C}_{b}\bigg(\mathfrak z_{n,N}^{\alpha},\sqrt{\frac{\pi}{2}}N\langle\bm{\xi},\bar{\bm{1}}\rangle\bm{e}_{1},\bm{0}\bigg)\,\mathrm{d}\bm{\xi},

\displaystyle\bigg|\frac{1}{N^{2}}\int_{\mathbb{R}^{2}}\widehat{\psi}(\bm{\xi})\,\sum_{n\neq 0}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)S(\{\theta_{j}\}_{j},N,n,\bm{\xi})\mathrm{d}\bm{\xi},\bigg|

. It is easy to see that

\displaystyle S(\{\theta_{j}\}_{j},N,n,\bm{\xi})=\sum_{\begin{subarray}{c}(x,y)\in\mathbb{Z}^{2}\\
|x|\neq|y|\end{subarray}}\exp\bigg\{\Omega_{\mathfrak z_{n,N}^{\alpha},\frac{\bm{\xi}}{N}}(x,y)\bigg\},

where

4.
An Argument from the Geometry of Numbers

4.1.

For a two-dimensional unimodular lattice
\Delta\subset\mathbb{R}^{2}
denote by
a(\Delta)
the first successive minimum (its reciprocal is commonly referred to as the height) of
\Delta
(i.e. the length of the shortest non-zero vector in
\Delta
); It is well-known that
a(\Delta)\leq\frac{2}{\sqrt{3}}
. For any lattice
\Delta\subset\mathbb{R}^{2}
and any
\mu>0
let us denote by

(4.1)

\displaystyle\mathcal{N}_{\Delta}(\mu):=\bigg\{\bm{v}\in\Delta\,\bigg|\,\|\bm{v}\|\leq\mu\bigg\},

the number of lattice points contained in the disk of radius
\mu
. The following three Lemmas are basic results in the Geometry of Numbers. They can all be generalized to higher dimensions, but we restrict it here to the case of two dimensional unimodular lattices.

4.2.

The Lipschitz principle in the Geometry of Numbers
[
Dav51
]
is a well-known counting method for the number of lattice points in a bounded region in terms of the successive minima:

Lemma 4.1
.

Let
\Delta
be a two-dimensional unimodular lattice and
\mu>0
. Then,

\displaystyle\mathcal{N}_{\Delta}(\mu)\ll\begin{cases}1+\mu a(\Delta)^{-1},&\text{ if }a(\Delta)\leq\mu<a(\Delta)^{-1}\\
1+\mu^{2},&\text{ if }\mu\geq a(\Delta)^{-1}.\end{cases}

The implicit constant is independent of
\Delta
.

Proof.

Let us write
\Delta=g\mathbb{Z}^{2}
with
g\in\mathrm{SL}_{2}(\mathbb{R})
. It is well-known that there are
\gamma\in\mathrm{SL}_{2}(\mathbb{Z}),k\in\mathrm{SO}(2)
and
s\in[-\frac{1}{2},\frac{1}{2}]
such that

\displaystyle g\gamma=k\begin{pmatrix}a(\Delta)&\\
&a(\Delta)^{-1}\end{pmatrix}\begin{pmatrix}1&s\\
&1\end{pmatrix}.

Thus, if

\displaystyle\bm{v}=k\begin{pmatrix}a(\Delta)&\\
&a(\Delta)^{-1}\end{pmatrix}\begin{pmatrix}1&s\\
&1\end{pmatrix}\begin{pmatrix}x\\
y\end{pmatrix}\in\Delta,\;x,y\in\mathbb{Z}

satisfies
\|\bm{v}\|\leq\mu
, then

\displaystyle a(\Delta)|x+sy|\leq\mu,

\displaystyle a(\Delta)^{-1}|y|\leq\mu.

If
a(\Delta)\leq\mu<a(\Delta)^{-1}
, then
y=0
and thus
|x|\leq a(\Delta)^{-1}\mu
, which proves the first assertion. If
\mu\geq a(\Delta)^{-1}
, then there are at most
1+2a(\Delta)\mu
possibilities for
y
; And for each such
y
any
x\in\mathbb{Z}
satisfying
a(\Delta)|x+sy|\leq\mu
lies in an interval of length
2a(\Delta)^{-1}\mu
, from which we deduce that there are at most
1+2a(\Delta)^{-1}\mu
such integers. Thus, we conclude that there are at most
(1+2a(\Delta)\mu)(1+2a(\Delta)^{-1}\mu)\leq 1+\frac{4}{\sqrt{3}}\mu+6\mu^{2}
possible lattice points
\bm{v}\in\Delta
satisfying
\|\bm{v}\|\leq\mu
in this case.
∎

4.3.

In the following it will be convenient to introduce the following notation: For any
P,Q>0
and
\alpha\in\mathbb{R}
let us introduce the lattice

\displaystyle\Delta_{P,Q}^{\alpha}:=\begin{pmatrix}P&\\
&Q\end{pmatrix}\begin{pmatrix}1&\alpha\\
&1\end{pmatrix}\mathbb{Z}^{2}.

Moreover, we shall simply write
\Delta_{P}^{\alpha}
to denote
\Delta_{P,P^{-1}}^{\alpha}
. i.e.

\displaystyle\Delta_{P}^{\alpha}:=\begin{pmatrix}P&\\
&P^{-1}\end{pmatrix}\begin{pmatrix}1&\alpha\\
&1\end{pmatrix}\mathbb{Z}^{2}.

The height of such lattices is known to exhibit a better upper bound in terms of
P
than the trivial one when
\alpha
is Diophantine.

Lemma 4.2
.

Let
\alpha\in\mathbb{R}
be Diophantine of type
\kappa
.
Then, for any
P>\frac{2}{\sqrt{3}}
, we have

\displaystyle a(\Delta_{P}^{\alpha})^{-1}\leq c^{-\frac{1}{\kappa}}\,P^{1-\frac{2}{\kappa}}.

Proof.

Let
(p,q)=1
be a coprime integer pair such that

\displaystyle a(\Delta_{P}^{\alpha})^{2}=P^{2}(p+\alpha q)^{2}+P^{-2}q^{2},

and note that
q\neq 0
as long as
P>\frac{2}{\sqrt{3}}
. Thus,

\displaystyle a(\Delta_{P}^{\alpha})\geq P|p+\alpha q|\geq\frac{c\,P}{q^{\kappa-1}}\geq\frac{c\,a(\Delta_{P}^{\alpha})^{-\kappa+1}}{P^{\kappa-2}},

which proves the assertion.
∎

Lemma 4.3
.

Let
P,Q,\alpha\in\mathbb{R},C>0
and
\bm{u}\in\mathbb{R}^{2}
. Then, for any
Z,\zeta>0

\displaystyle\sum_{\bm{v}\in\Delta_{P,Q}^{\alpha}}\mathrm{e}^{-C\|\bm{v}+\bm{u}\|^{2}}\leq\bigg(1+\mathcal{N}_{\Delta_{(Z\zeta^{-1})^{1/2}}^{\alpha}}(\sqrt{2}(Z\zeta)^{\frac{1}{2}})\bigg)\sum_{\bm{v}\in\Delta^{0}_{P\zeta,QZ}}\mathrm{e}^{-C\frac{\|\bm{v}\|^{2}}{4}}.

In particular, if
P\zeta\gg 1
and
QZ\gg 1
, then

\displaystyle\sum_{\bm{v}\in\Delta_{P,Q}^{\alpha}}\mathrm{e}^{-C\|\bm{v}+\bm{u}\|^{2}}\ll 1+\mathcal{N}_{\Delta_{(Z\zeta^{-1})^{1/2}}^{\alpha}}(\sqrt{2}(Z\zeta)^{\frac{1}{2}}).

Proof.

For simplicity we prove this for
C=1
. Any element
\bm{v}\in\Delta_{P,Q}^{\alpha}
is of the form

\displaystyle\bm{v}=\begin{pmatrix}P(x+\alpha z)\\
Qz\end{pmatrix},\;x,z\in\mathbb{Z}

and so

\displaystyle\|\bm{v}+\bm{u}\|^{2}

\displaystyle=P^{2}\bigg(x+\alpha z+\frac{u_{1}}{P}\bigg)^{2}+Q^{2}\bigg(z+\frac{u_{2}}{Q}\bigg)^{2}

\displaystyle=(P\zeta)^{2}\frac{1}{\zeta^{2}}\bigg(x+\alpha z+\frac{u_{1}}{P}\bigg)^{2}+(QZ)^{2}\frac{1}{Z^{2}}\bigg(z+\frac{u_{2}}{Q}\bigg)^{2}.

For any
x,z\in\mathbb{Z}
(and consequently
\bm{v}
) there is a unique
\bm{m}=(m_{1},m_{2})\in\mathbb{Z}^{2}
such that

(4.2)

\displaystyle\begin{aligned} &\frac{1}{\zeta}\bigg(x+\alpha z+\frac{u_{1}}{P}\bigg)\in\bigg[m_{1}-\frac{1}{2},m_{1}+\frac{1}{2}\bigg),\\
&\frac{1}{Z}\bigg(z+\frac{u_{2}}{Q}\bigg)\in\bigg[m_{2}-\frac{1}{2},m_{2}+\frac{1}{2}\bigg).\end{aligned}

Observe, in this case, that

\displaystyle\bigg|\frac{1}{\zeta}\bigg(x+\alpha z+\frac{u_{1}}{P}\bigg)\bigg|\geq\frac{|m_{1}|}{2},

\displaystyle\bigg|\frac{1}{Z}\bigg(z+\frac{u_{2}}{Q}\bigg)\bigg|\geq\frac{|m_{2}|}{2}.

Let us denote by
\mathcal{B}_{\bm{m}}(\zeta,Z)
the collection of
\bm{v}\in\Delta
satisfying (
4.2
), then

\displaystyle\sum_{\bm{v}\in\Delta}\mathrm{e}^{-\|\bm{v}+\bm{u}\|^{2}}

\displaystyle\leq\sum_{\bm{m}\in\mathbb{Z}^{2}}\sum_{\bm{v}\in\mathcal{B}_{\bm{m}}(\zeta,Z)}\mathrm{e}^{-\|\bm{v}+\bm{u}\|}

\displaystyle\leq\sum_{\bm{m}\in\mathbb{Z}^{2}}\#\mathcal{B}_{\bm{m}}(\zeta,Z)\,\mathrm{e}^{-\frac{1}{4}\big((P\zeta)^{2}m_{1}^{2}+(QZ)^{2}m_{2}^{2}\big)}.

For each
\bm{m}\in\mathbb{Z}^{2}
, either
\#\mathcal{B}_{\bm{m}}(\zeta,Z)\leq 1
or
\mathcal{B}_{\bm{m}}(\zeta,Z)
contains at least two elements. In the latter case, fix an element of the form

\displaystyle\bm{w}_{0}=\begin{pmatrix}\frac{1}{\zeta}(x_{0}+\alpha z_{0}+\frac{u_{1}}{P})\\
\frac{1}{Z}(z_{0}+\frac{u_{2}}{Q})\end{pmatrix},\,x_{0},z_{0}\in\mathbb{Z}

satisfying (
4.2
), then for any other

\displaystyle\bm{w}=\begin{pmatrix}\frac{1}{\zeta}(x+\alpha z+\frac{u_{1}}{P})\\
\frac{1}{Z}(z+\frac{u_{2}}{Q})\end{pmatrix},\,x,z\in\mathbb{Z},

satisyfing (
4.2
) note that

\displaystyle\bm{w}-\bm{w}_{0}=\begin{pmatrix}\frac{1}{\zeta}((x-x_{0})+\alpha(z-z_{0}))\\
\frac{1}{Z}(z-z_{0})\end{pmatrix}\in[-1,1]^{2}.

Thus, if
\mathcal{B}_{\bm{m}}(\zeta,Z)
contains at least two elements, then

\displaystyle\#\mathcal{B}_{\bm{m}}(\zeta,Z)\leq\#\bigg\{\begin{pmatrix}x\\
z\end{pmatrix}\in\mathbb{Z}^{2}\,\bigg|\,|x+\alpha z|\leq\zeta,\,|z|\leq Z\,\bigg\}.

Finally observe that the inequalities

\displaystyle|x+\alpha z|\leq\zeta,\;|z|\leq Z

can be rewritten as

\displaystyle\bigg(\frac{Z}{\zeta}\bigg)^{\frac{1}{2}}|x+\alpha z|\leq(Z\zeta)^{\frac{1}{2}},\;\bigg(\frac{\zeta}{Z}\bigg)^{\frac{1}{2}}|z|\leq(Z\zeta)^{\frac{1}{2}}

and hence

\displaystyle\#\bigg\{\begin{pmatrix}x\\
z\end{pmatrix}\in\mathbb{Z}^{2}\,\bigg|\,|x+\alpha z|\leq\zeta,\,|z|\leq Z\,\bigg\}

\displaystyle\qquad=\#\bigg\{\bm{v}\in\Delta^{\alpha}_{(Z\zeta^{-1})^{1/2}}\,\bigg|\,\bm{v}\in[-(Z\zeta)^{\frac{1}{2}},(Z\zeta)^{\frac{1}{2}}]^{2}\bigg\}

\displaystyle\qquad\leq\mathcal{N}_{\Delta^{\alpha}_{(Z\zeta^{-1})^{1/2}}}(\sqrt{2}(Z\zeta)^{\frac{1}{2}}).

∎

4.4.

The following lemma is the main step towards
Theorem

1.1
.

Lemma 4.4
.

Let
\sigma>0,b\in\{0,1\}
and let
\alpha\in\mathbb{R}
be Diophantine of type
\kappa
. Then, for any
\epsilon>0
and any
u\in\mathbb{R}

\displaystyle\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{\bm{v}\in\Lambda_{\mathfrak z_{n,N}^{\alpha},b}^{*}}\mathrm{e}^{-\pi\|\bm{v}+u\bm{e_{1}}\|^{2}}\ll_{\epsilon}N^{\sigma-1+\epsilon}+N^{\sigma-\frac{2+\sigma}{\kappa}+\epsilon(1-\frac{1}{\kappa})},

where
\mathfrak z_{n,N}^{\alpha}
is defined in
Lemma

3.4
and
\Lambda_{\mathfrak z_{n,N}^{\alpha},b}\subset\Lambda_{\mathfrak z_{n,N}^{\alpha},b}^{*}
is defined as in (
3.2
) and (
3.3
). Note that the right-hand side decays to zero as
N\to\infty
as long as
\sigma<1
and
\kappa<1+\frac{2}{\sigma}
.

Proof.

Let us prove this for
b=0
only, as the case
b=1
is exactly the same. Let
\epsilon>0
to be determined below. Denote by
\tau(\,\cdot\,)
the divisor function and observe that

\displaystyle\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{\bm{v}\in\Lambda_{\mathfrak z_{n,N}^{\alpha}}^{*}}\mathrm{e}^{-\pi\|\bm{v}+u\bm{e_{1}}\|^{2}}

\displaystyle\quad=\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\mathrm{e}^{-2\pi^{2}N^{2}(x+4\alpha ny+\frac{u}{\sqrt{2\pi}N})^{2}-2\frac{y^{2}}{N^{2}}}

\displaystyle\quad\leq\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{(x,y)\in\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})}\mathrm{e}^{-2\pi^{2}N^{2}(x+4\alpha ny+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{8}\frac{(4yn)^{2}}{N^{2(1+\sigma+\epsilon)}}}

\displaystyle\quad\leq\frac{2}{N}\sum_{z=1}^{\infty}\tau(z)\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{8}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}.

Using the fact that
\tau(z)\ll_{\epsilon,\sigma}z^{\frac{\epsilon}{2(1+\sigma+2\epsilon)}}
, we first deduce

\displaystyle\sum_{1\leq z\leq N^{2(1+\sigma+2\epsilon)}}\tau(z)\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{8}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}

\displaystyle\qquad\ll_{\epsilon,\sigma}N^{\epsilon}\sum_{1\leq z\leq N^{2(1+\sigma+2\epsilon)}}\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{8}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}},

but we also have

\displaystyle\sum_{z\geq N^{2(1+\sigma+2\epsilon)}}\tau(z)\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{8}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}

\displaystyle\qquad\ll_{\epsilon,\sigma}\sum_{z\geq N^{2(1+\sigma+2\epsilon)}}z^{\frac{\epsilon}{2(1+\sigma+2\epsilon)}}\mathrm{e}^{-\frac{1}{16}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{16}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}

\displaystyle\qquad\ll_{\epsilon,\sigma}\sum_{z\geq N^{2(1+\sigma+2\epsilon)}}\sum_{x\in\mathbb{Z}}\mathrm{e}^{-2\pi^{2}N^{2}(x+\alpha z+\frac{u}{\sqrt{2\pi}N})^{2}-\frac{1}{16}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}},

where we use that for
z\geq N^{2(1+\sigma+2\epsilon)}

\displaystyle z^{\frac{\epsilon}{2(1+\sigma+2\epsilon)}}\mathrm{e}^{-\frac{1}{16}\frac{z^{2}}{N^{2(1+\sigma+\epsilon)}}}\leq 1,

for all
N
sufficiently large. Thus, we find that

(4.3)

\displaystyle\begin{aligned} &\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{\bm{v}\in\Lambda_{\mathfrak z_{n,N}^{\alpha}}^{*}}\mathrm{e}^{-\pi\|\bm{v}+u\bm{e_{1}}\|^{2}}\\
&\quad\ll_{\epsilon,\sigma}\frac{1}{N^{1-\epsilon}}\sum_{\bm{v}\in\Delta^{\alpha}_{N,(N^{1+\sigma+\epsilon})^{-1}}}\mathrm{e}^{-\frac{1}{16}\|\bm{v}+u\bm{e}_{1}\|^{2}}.\end{aligned}

Let us apply
Lemma

4.3
with
P=N,Q=(N^{1+\sigma+\epsilon})^{-1},\zeta=N^{-1},Z=N^{1+\sigma+\epsilon}
to obtain the following estimate

(4.4)

\displaystyle\sum_{\bm{v}\in\Delta^{\alpha}_{N,(N^{1+\sigma+\epsilon})^{-1}}}\mathrm{e}^{-\frac{1}{16}\|\bm{v}+u\bm{e}_{1}\|^{2}}\ll\bigg(1+\mathcal{N}_{\Delta^{\alpha}_{N^{(2+\sigma+\epsilon)/2}}}(\sqrt{2}N^{\frac{\sigma+\epsilon}{2}})\bigg).

Moreover, according to
Lemma

4.2
, since
\alpha
is Diophantine of type
\kappa
, we have

\displaystyle a(\Delta^{\alpha}_{N^{(2+\sigma+\epsilon)/2}})^{-1}\ll N^{\frac{2+\sigma+\epsilon}{2}(1-\frac{2}{\kappa})}.

Hence,
Lemma

4.1
implies

(4.5)

\displaystyle\mathcal{N}_{\Delta^{\alpha}_{N^{(2+\sigma+\epsilon)/2}}}(\sqrt{2}N^{\frac{\sigma+\epsilon}{2}})\ll N^{\sigma+\epsilon}+N^{\frac{2+\sigma+\epsilon}{2}(1-\frac{2}{\kappa})+\frac{\sigma+\epsilon}{2}}

The assertion follows now from (
4.3
), (
4.4
) and (
4.5
).
∎

Proof of
Theorem

1.1
.

According to
Lemma

2.2
it suffices to show

\displaystyle\lim_{N\to\infty}\mathrm{R}_{2}^{\sigma}(f,\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}},\{\theta_{j,N}\},N)=\widehat{f}(0)\big(\mathcal{F}({\psi\cdot\mathrm{e}^{-\|\,\cdot\,\|^{2}}})\big)(\bm{0}),

for any two test functions
f:\mathbb{R}\to\mathbb{R}
and
\psi:\mathbb{R}^{2}\to\mathbb{R}
of class
\mathcal{P}
. According to
Lemma

3.4
, this last identity follows if

\displaystyle\lim_{N\to\infty}\mathrm{E}^{\sigma}_{\epsilon}(f,\psi,\{\alpha j^{2}\}_{j},N)=0,

for some fixed
\epsilon>0
. It is plain to see that

\displaystyle E^{\sigma}_{\epsilon}(f,\psi,\{\alpha j^{2}\}_{j},N)\ll_{\psi,f}\sup_{u\in\mathbb{R}}\sum_{b\in\{0,1\}}\frac{1}{N}\sum_{1\leq n\leq N^{\sigma+\epsilon}}\sum_{\bm{v}\in\Lambda_{\mathfrak z_{n,N}^{\alpha},b}^{*}}\mathrm{e}^{-\pi\|\bm{v}+u\bm{e_{1}}\|^{2}}.

and the right-hand side is bounded above by
N^{\sigma-1+\epsilon}+N^{\sigma-\frac{2+\sigma}{\kappa}+\epsilon(1-\frac{1}{\kappa})}
by
Lemma

4.4
. We clearly require
\sigma<1
and
\kappa<1+\frac{2}{\sigma}
.
∎

5.
Upper Bound for
\sigma(\{n^{2}\alpha\}_{n})
for Almost Every
\alpha

5.1.

This section contains the proof of
Theorem

1.3
. It follows essentially the same strategy as that of Rudnick and Sarnak
[
RS98
]
up to some small modifications.

5.2.

The first step consists in showing that the
variance of the
\sigma
-pair correlation
is small. Let
f:\mathbb{R}\to\mathbb{R}
be a test function such that
\widehat{f}\in C_{c}(\mathbb{R})
has compact support and set

\displaystyle\mathrm{R}_{2}^{\sigma}(f,\{j^{2}\alpha\}_{j},N):=\mathrm{R}_{2}^{\sigma}(f,\mathbbm{1}_{[1,N]^{2}},\{j^{2}\alpha\}_{j},N),

as in
Section

2.1
. Following Rudnick and Sarnak
[
RS98
]
we define

\displaystyle\mathrm{X}_{N}(\alpha):=\mathrm{R}_{2}^{\sigma}(f,\{j^{2}\alpha\}_{j},N)-\widehat{f}(0).

Lemma 5.1
.

For any
\epsilon>0
, we have

\displaystyle\|X_{N}\|_{\mathrm{L}^{2}([0,1])}^{2}\ll_{f,\epsilon}\frac{1}{N^{2-\sigma-\epsilon}},

where
\|\,\cdot\,\|_{\mathrm{L}^{2}([0,1])}
denotes the standard norm on the
\mathrm{L}^{2}
-space on
[0,1]
with respect to the Lebesgue measure.

Proof.

Note that
\mathrm{X}_{N}
is a periodic function in the variable
\alpha
. Thus, we can express it as a Fourier series

\displaystyle\mathrm{X}_{N}(\alpha)=\sum_{l\in\mathbb{Z}}c_{l}(N)\mathrm{e}(l\alpha),

where

\displaystyle c_{l}=\frac{1}{N^{2}}\sum_{n\in\mathbb{Z}\setminus\{0\}}\sum_{\begin{subarray}{c}1\leq j\neq k\leq N\\
(j^{2}-k^{2})n=l\end{subarray}}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg),

and

\displaystyle c_{0}=\mathcal{O}(\frac{1}{N}),\text{ as }N\to\infty.

Note that
c_{l}(N)\ll\frac{\tau(|l|)^{2}}{N^{2}}
for any
l\neq 0
, where
\tau
denotes the divisor function, and hence for any fixed
\epsilon>0

\displaystyle c_{l}(N)\ll_{\epsilon}\frac{|l|^{\epsilon}}{N^{2}}\text{ for any }l\neq 0.

Moreover, for any fixed
\delta>0
and all sufficiently large
N

\displaystyle c_{l}(N)=0\text{ for all }l\geq N^{2+\sigma+\delta}.

It follows from these two observations together with Parseval’s identity that

(5.1)

\displaystyle\|\mathrm{X}_{N}\|_{\mathrm{L}^{2}([0,1])}^{2}\ll_{f,\epsilon}\frac{1}{N^{2-\sigma-\epsilon}}.

∎

5.3.

The second step consists in noticing that small variance leads to almost everywhere convergence of the
\sigma
-pair correlation along a sparse subsequence of Planck constants. Fix
0<\delta<1
such that

(5.2)

\displaystyle(2-\sigma)(1+\delta)>1

and choose
\epsilon>0
small enough such that
(2-\sigma-\epsilon)(1+\delta)>1
. Let
\{N_{m}\}_{m}
be a sequence of integers with

\displaystyle N_{m}\sim m^{1+\delta}.

Then, according to
Lemma

5.1
, we find

\displaystyle\infty>\sum_{m=1}^{\infty}\frac{1}{m^{(2-\sigma-\epsilon)(1+\delta)}}\gg_{f,\epsilon}\sum_{m=1}^{\infty}\|\mathrm{X}_{N_{m}}\|_{\mathrm{L}^{2}([0,1])}^{2}=\int_{0}^{1}\sum_{m=1}^{\infty}|\mathrm{X}_{N_{m}}(\alpha)|^{2}\,\mathrm{d}\alpha,

and consequently

(5.3)

\displaystyle\lim_{m\to\infty}\mathrm{X}_{N_{m}}(\alpha)=0\text{ for almost every }\alpha\in[0,1].

We can now choose a set
P(f)
of full measure in
[0,1]
such that for any
\alpha\in P(f)
,
\alpha
is Diophantine and satisfies (
5.3
).

5.4.

The final step consists in proving that for any
\alpha\in P(f)
, due to the Diophantine nature of
\alpha
, the oscillations
\mathrm{X}_{n}(\alpha)-\mathrm{X}_{N_{m}}(\alpha)
along the sparse subsequence
\{N_{m}\}_{m}
are small for all
N_{m}\leq n<N_{m+1}
.
As
n-N_{m}\leq N_{m+1}-N_{m}\ll N_{m}^{\delta}
it suffices to prove the following

Lemma 5.2
.

Let
0\leq\sigma<2
and
\delta>0
such that

(5.4)

\displaystyle\begin{aligned} &-2+\sigma+2\delta<0,\text{ and }\\
&-2+\frac{1}{2}+\sigma+\delta<0,\end{aligned}

and let
\alpha
be Diophantine. Then,

\displaystyle\sup_{0\leq l\leq N^{\delta}}|\mathrm{X}_{N+l}(\alpha)-\mathrm{X}_{N}(\alpha)|\to 0,\text{ as }N\to\infty.

In view of (
5.3
) and
Lemma

5.2
, it follows that

\displaystyle\lim_{N\to\infty}\mathrm{X}_{N}(\alpha)=0,

for all
\alpha\in P(f)
, as long as
\sigma
and
\delta
satisfy both (
5.2
) and (
5.4
). It is plain to see that these two requirements are satisfied if

\displaystyle 0\leq\sigma\leq 1\text{ and }0<\delta<1-\frac{\sigma}{2},\text{ or }

\displaystyle 1<\sigma<\frac{1}{4}(9-\sqrt{17})\text{ and }\frac{\sigma-1}{2-\sigma}<\delta<\frac{3}{2}-\sigma.

Theorem

1.3
follows then easily from this observation. The rest of this section will be devoted towards the proof of
Lemma

5.2
.

Proof of
Lemma

5.2
.

The number
\epsilon
will denote a small positive quantity, whose value will be adapted as needed during the argument. Let us set
M=N^{\sigma+\epsilon}
. Then, for all sufficiently large
N
we have

\displaystyle\mathrm{X}_{N}(\alpha)=\frac{1}{N^{2}}\sum_{0<|n|\leq M}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)\sum_{1\leq j\neq k\leq N}\mathrm{e}(n\alpha(j^{2}-k^{2})),\text{ as well as}

\displaystyle\mathrm{X}_{N+l}(\alpha)=\frac{1}{(N+l)^{2}}\sum_{0<|n|\leq M}\widehat{f}\bigg(\frac{n}{(N+l)^{\sigma}}\bigg)\sum_{1\leq j\neq k\leq N}\mathrm{e}(n\alpha(j^{2}-k^{2})).

for all
0\leq l\leq N^{\delta}
. Moreover, for any
0\leq l\leq N^{\delta}
, we have

\displaystyle\frac{1}{(N+l)^{2}}=\frac{1}{N^{2}}+\mathcal{O}(N^{-3+\delta}),

\displaystyle\widehat{f}\bigg(\frac{n}{(N+l)^{\sigma}}\bigg)=\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)+\mathcal{O}(N^{-1+\delta+\epsilon}),

where the last identity follows from
\frac{n}{(N+l)^{\sigma}}=\frac{n}{N^{\sigma}}+\mathcal{O}(\frac{MN^{\delta}}{N})
. Thus, it is easy to see that for
0\leq l\leq N^{\delta}
and
N
sufficiently large,

(5.5)

\displaystyle\begin{aligned} &\bigg|\mathrm{X}_{N+l}(\alpha)-\frac{1}{N^{2}}\sum_{0<|n|\leq M}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)\sum_{1\leq j\neq k\leq N+l}\mathrm{e}(n\alpha(j^{2}-k^{2}))\bigg|\\
&\ll\frac{1}{N^{3-\delta-\epsilon}}\sum_{0<n\leq M}\bigg|\sum_{1\leq j\neq k\leq N+l}\mathrm{e}(n\alpha(j^{2}-k^{2}))\bigg|\\
&\ll N^{-2+\sigma+\delta+2\epsilon}+\frac{1}{N^{3-\delta-\epsilon}}\sum_{0<n\leq M}\big|S_{\alpha}(n,N+l)\big|^{2},\end{aligned}

where

\displaystyle S_{\alpha}(n,N):=\sum_{1\leq j\leq N}\mathrm{e}(n\alpha j^{2}).

At this point let us note that we require

(5.6)

\displaystyle-2+\sigma+\delta<0.

5.4.1.

Let us provide a short proof of the fact that

(5.7)

\displaystyle\sum_{n=1}^{M}|S_{\alpha}(n,N)|^{2}\ll_{\epsilon}(NM)^{1+\epsilon},\text{ for any }\epsilon>0,

for a Diophantine number
\alpha
. Indeed, it is easy to see that (e.g. Lemma 3.1 in
[
Dav05
]
)

\displaystyle|S_{\alpha}(n,N)|^{2}\ll N+\sum_{v=1}^{N}\min\big\{N,\frac{1}{\|2\alpha nv\|_{\mathbb{Z}}}\big\},

where
\|\,\cdot\,\|_{\mathbb{Z}}
denotes the distance to the nearest integer.
Moreover,

\displaystyle\sum_{n=1}^{M}\sum_{v=1}^{N}\min\big\{N,\frac{1}{\|2\alpha nv\|_{\mathbb{Z}}}\big\}

\displaystyle\ll_{\epsilon}N^{\epsilon/2}\sum_{z=1}^{2MN}\min\big\{N,\frac{1}{\|\alpha z\|_{\mathbb{Z}}}\big\}

\displaystyle=N^{1+\epsilon/2}\bigg(\sum_{\begin{subarray}{c}1\leq z\leq 2MN\\
\|\alpha z\|_{\mathbb{Z}}\leq N^{-1}\end{subarray}}1\bigg)+N^{\epsilon/2}\sum_{\begin{subarray}{c}1\leq z\leq 2NM\\
\|\alpha z\|_{\mathbb{Z}}>N^{-1}\end{subarray}}\frac{1}{\|\alpha z\|_{\mathbb{Z}}}.

First observe that

\displaystyle\sum_{\begin{subarray}{c}1\leq z\leq 2MN\\
\|\alpha z\|_{\mathbb{Z}}\leq N^{-1}\end{subarray}}1\leq\mathcal{N}_{\Delta_{\sqrt{2M}N}}(2\sqrt{M})\ll M(MN)^{\epsilon/2},

where we use the notation introduced in
Section

4.1
and
Section

4.3
, as well as
Lemma

4.2
. Similarly, notice that

\displaystyle\sum_{\begin{subarray}{c}1\leq z\leq 2NM\\
\|\alpha z\|_{\mathbb{Z}}>N^{-1}\end{subarray}}\frac{1}{\|\alpha z\|_{\mathbb{Z}}}

\displaystyle\ll\sum_{r=0}^{\log_{2}(N)}2^{r}\sum_{\begin{subarray}{c}1\leq z\leq 2NM\\
2^{-(r+1)}\leq\|\alpha z\|_{\mathbb{Z}}\leq 2^{-r}\end{subarray}}1

\displaystyle\leq\sum_{r=0}^{\log_{2}(N)}2^{r}\mathcal{N}_{\Delta^{\alpha}_{\sqrt{2^{r+1}MN}}}(\sqrt{2^{-r+2}MN})

\displaystyle\ll(MN)^{1+\epsilon/2}.

5.4.2.

Let us return to the proof
Lemma

5.2
. In view of (
5.5
) and (
5.7
) we find that

(5.8)

\displaystyle\bigg|\mathrm{X}_{N+l}(\alpha)-\frac{1}{N^{2}}\sum_{0<|n|\leq M}\widehat{f}\bigg(\frac{n}{N^{\sigma}}\bigg)\sum_{1\leq j\neq k\leq N+l}\mathrm{e}(n\alpha(j^{2}-k^{2}))\bigg|\ll_{\epsilon}N^{-2+\sigma+\delta+\epsilon}

for any
\epsilon>0
. In order to relate this last estimate to the oscillation
|\mathrm{X}_{N+l}(\alpha)-\mathrm{X}_{N}(\alpha)|
, notice that

\displaystyle\bigg|\sum_{1\leq j\neq k\leq N+l}\mathrm{e}(n\alpha(j^{2}-k^{2}))-\sum_{1\leq j\neq k\leq N}\mathrm{e}(n\alpha(j^{2}-k^{2}))\bigg|

\displaystyle\ll\bigg|\sum_{k=N+1}^{N+l}\mathrm{e}(-n\alpha k^{2})\bigg|\bigg|\sum_{j=1}^{N}\mathrm{e}(-n\alpha j^{2})\bigg|+\bigg|\sum_{N+1\leq j\neq k\leq N+l}\mathrm{e}(n\alpha(j^{2}-k^{2}))\bigg|

\displaystyle\ll l|S_{\alpha}(n,N)|+l^{2}.

Thus,

\displaystyle|\mathrm{X}_{N+l}(\alpha)-\mathrm{X}_{N}(\alpha)|

\displaystyle\ll_{\epsilon,f}N^{-2+\sigma+\delta+\epsilon}+\frac{Ml^{2}}{N^{2}}+\frac{l}{N^{2}}\sum_{n=1}^{M}|S_{\alpha}(n,N)|

\displaystyle\ll N^{-2+\sigma+2\delta+\epsilon}+N^{-2+\frac{1}{2}+\sigma+\delta+\epsilon},

where we use that
0\leq l\leq N^{\delta}
and apply the Cauchy-Schwarz inequality to the sum in order to utilize the estimate (
5.7
). Clearly, at this point we require

-2+\sigma+2\delta<0
as well as
-2+\frac{1}{2}+\sigma+\delta<0
, where
0\leq\sigma<2
and
\delta>0
. Finally, observe that the requirement (
5.4
) implies (
5.6
).
∎
