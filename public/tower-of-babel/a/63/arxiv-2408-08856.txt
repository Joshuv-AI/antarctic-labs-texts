1
Introduction

First introduced by John Conway and summarised well in
[
3
]
, Conway Checkers, or Conway Soldiers, is an interesting mathematical game with a beautiful and possibly counterintuitive solution.

To set up the game, the player places a checker on each square below some initial line on an infinite checkerboard. The game is then to try and move a checker as high up the board as possible, where a checker moves by jumping over another checker it shares an edge with, removing the piece jumped over from the board.

Conway’s solution involved weighting each square of the board by powers of the golden ratio
\varphi
, such that whatever move the player makes, the total weight of all the squares with a checker on never increases. We follow terminology introduced by Conway and call this weight function a pagoda function. Using this, it is possible to show that, in finitely many moves, it is not possible to reach the 5
th
row above the initial line.

The use of these pagoda functions is very common in the study of games similar to Conway Checkers, for example Peg Solitaire. For a foundational text, see again
[
3
]
.

In
[
8
]
, the authors show a construction of how to reach row 5 when infinitely many moves are allowed to be made, as long as you consider each infinite amount of moves to occur in a finite time period, so it is possible to perform multiple sequences of infinite moves consecutively.

Many generalisations of this game have been considered. Some involve changing the moves allowed. In
[
2
]
, the authors consider the game except pieces move as in regular checkers, as introduced in
[
7
]
, jumping only diagonally. They also consider the case where pieces can move either diagonally or orthogonally.

Also in
[
2
]
, the authors use variations on Conway’s pagoda function, as well as some constructions, to find the minimal number of checkers that are required to reach certain rows in various different games, including the two mentioned above. This is also done in
[
1
]
, where the author uses an entirely different pagoda function to Conway’s, weighting each square on an arbitrarily large finite board by the
(n-t)
th
Fibonacci number, where
t
is the square’s taxicab distance from a target square and
n
is large enough.

Variations on the board the game is played on have also been considered. In
[
7
]
, the authors introduce the game played on a board with hexagonal cells, so that each piece has six choices of directions to jump. This is built upon by
[
2
]
, who again prove properties about the minimal number of checkers to reach the maximum row.

[
4
]
provides constructions on how to reach the highest possible rows on a number of different initial boards, including a board where all but the first quadrant is initially filled, and the same board rotated by an eighth of a turn.

In
[
9
]
, the author generalises the game to be played on an arbitrary connected, countable and locally finite graph. They show that on such a graph, a point is unreachable from some initial condition where all checkers are at least some distance
k
away if the size of the set of points distance
n
from that point is
O(\varphi^{\varepsilon n})
for an
\varepsilon<1
.

In
[
5
]
, the game is generalised from 2-dimensions to
d
-dimensions. The authors show that it is always possible to bring a checker to row
3d-2
and never row
3d-1
. We generalise this result further.

We consider a variant of the the game played in
d
-dimensions, as in
[
5
]
, where each square can hold any number of checkers, and the initial board position has
m
checkers occupying the squares instead of 1. We also consider the further generalisation, still with
m
checkers on each square, where instead of jumping over 1 checker, each checker moves by jumping over
k-1
checkers in a straight line, for some
k\geq 2
. We call this game the Conway
(m,k,d)
-game and prove the following theorem.

Theorem 1.1
.

In the Conway
(m,k,d)
-game, with
m>1
, the maximum row attainable
n_{M}
satisfies

\left\lfloor\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)\right\rfloor\ \leq\ n_{M}\ \leq\ \left\lfloor\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)\right\rfloor+1,

(1.1)

where
\phi_{k}
is the
k
-nacci constant as defined in Lemma
2.6
. In particular, we have that for almost all values of
m
, the upper bound is attainable. When
k=2
we have that for all
m\in\mathbb{N}

\left\lfloor\mathrm{log}_{\varphi}\left(m\right)\right\rfloor+3d-2\ \leq\ n_{M}\ \leq\ \left\lfloor\mathrm{log}_{\varphi}\left(m\right)\right\rfloor+3d-1.

(1.2)

Again, this upper bound is attainable for almost all
m
.

The result (
1.2
) follows for
m>1
from (
1.1
) and for
m=1
from results in
[
5
]
. For details on why we fail to prove (
1.1
) in the
m=1
case see Remark
5
.

The bound in (
1.1
) is logarithmic in
m
, and linear in
d
. Matching with intuition, this tells us that increasing the dimension gives much more power to move up the board than increasing the number of checkers. By Remark
2
, these bounds behave like
\log_{2}(m)+(d-1)\log_{2}(3)
as
k
grows.

Since the game in
d
-dimensions is very complicated, it is difficult to directly prove strong results about it. Instead we first prove results in the 1-dimensional case concerning how high a row can be reached, as well as how many checkers can be moved onto the first row. We then use these results to obtain bounds in the
d
-dimensional case.

We also use these results in 1-dimension to prove results about the maximum amount of checkers that can be moved onto a single square in higher dimensions, and show this asymptotically matches an upper bound for large
m
.

2
Definitions and Preliminaries

The original rules of Conway Checkers are as follows.

•

On an infinite checkerboard, start by placing a checker on each square below a certain arbitrary line. We call the top row of checkers row 0.

•

On each move, a checker jumps over an orthogonally adjacent checker and lands on the other side of it. The checker it jumped over is then removed.

When generalising to higher dimensions
d
, we consider the game as being played on
\mathbb{Z}^{d}
, with each point being a cell of the board.

Definition 2.1
.

Given a point
T\in\mathbb{Z}^{d}
, define the distance function
d\,(\cdot,T):\mathbb{Z}^{d}\to\mathbb{Z}_{\geq 0}
by

d(x,T)\ =\ \sum_{i=1}^{d}|x_{i}-T_{i}|,

(2.1)

the taxicab distance between
x
and
T
.

Definition 2.2
.

Given a function
f:\mathbb{Z}^{d}\to\mathbb{R}
, the
energy
of a boardstate
B
with respect to
f
is the sum of the function applied to each checker’s square. For example, if
f=1
then the energy of the boardstate is just the number of checkers on the board.

Definition 2.3
.

A function
p:\mathbb{Z}^{d}\to\mathbb{R}
is called a
pagoda function
if the energy of the board with respect to
p
is non-increasing for any possible move.

Theorem 2.4
.

We have the following two conditions on a boardstate being unattainable in finite time (where all energies are with respect to an arbitrary pagoda function).

(i)

For a target boardstate
B
, if the energy of
B
is greater than the initial energy of the board, then that boardstate is not attainable.

(ii)

If there are infinitely many checkers that are present in the initial boardstate and not present in the target state, then it is not possible to reach
B
in finitely many moves.

Proof.

To prove
(i)
we note that the board’s energy is non-increasing for all possible moves, hence no sequence of moves can lead to a boardstate with greater energy. To show
(ii)
we note that if there are infinitely many such checkers, then infinitely many checkers need to be moved. Since the rules only permit the moving of one checker at a time, it is not possible to reach
B_{0}
in finite time.
∎

Remark 1
.

Note that these conditions give no indication as to whether a state is attainable, only that it is not possible to reach.

Definition 2.5
.

We define the
k
-nacci sequence
F_{k}(n)
by the recurrence

a_{n+k}\ =\ a_{n}+a_{n+1}+\cdots+a_{n+k-1}

(2.2)

and initial conditions

F_{k}(0)\ =\ F_{k}(1)\ =\ \cdots\ =\ F_{k}(k-2)\ =\ 0,\;F_{k}(k-1)\ =\ 1.

(2.3)

Lemma 2.6
.

The characteristic polynomial of the
k
-nacci sequence,

1+x+\cdots+x^{k-1}-x^{k}

(2.4)

has only one root
\phi_{k}
with
|\phi_{k}|\geq 1
. In particular, this root is always real and lies in the interval
(1,2)
. We call this the
k
-nacci constant. In the case
k=2
, we denote this by
\varphi
, the golden ratio, equal to
\frac{1+\sqrt{5}}{2}
. We also have that all the roots of this polynomial are distinct.

Proof.

This follows by Rouché’s theorem. For a proof see, for example,
[
6
]
.
∎

Remark 2
.

We also have that
\phi_{k}\to 2
as
k\to\infty
. This is shown in
[
10
]
, which also gives an alternative proof to Lemma
2.6
.

Corollary 2.7
.

We have
F_{k}(n)\sim c\phi_{k}^{n}
, where
c
is real and positive.

Proof.

Since the roots of the characteristic polynomial are all distinct, the solution to the linear recurrence can be written as a sum of powers of the roots of its characteristic equation. We then have

F_{k}(n)\ =\ c\phi_{k}^{n}+A_{1}\rho_{1}^{n}+\cdots+A_{k-1}\rho_{k-1}^{n}

(2.5)

for a collection of
\rho_{i}
that lie inside the unit circle. It then clearly follows that

\lim_{n\to\infty}\frac{F_{k}(n)}{c\phi_{k}^{n}}\ =\ 1,

(2.6)

so
F_{k}(n)\sim c\phi_{k}^{n}
for some
c
. From the initial conditions in Definition
2.5
, we have that
F_{k}(n)
is real and non-negative for all
n\in\mathbb{N}
and
F_{k}(n)\to\infty
as
n\to\infty
, so
c
must be real and positive.
∎

Lemma 2.8
.

The solution to the recurrence

a_{n+k}\ =\ a_{n}+\cdots+a_{n+k-1}+1

(2.7)

with initial conditions

(a_{0},a_{1},a_{2},\dots,a_{k-1})\ =\ (1,2,4,\dots,2^{k-1})

(2.8)

is

a_{i}\ =\ \sum_{j=0}^{i}F_{k}(k-1+j).

(2.9)

Proof.

This follows from verifying the given solution and using uniqueness.
∎

Definition 2.9
.

We define the value
n_{M}
to be the maximum row attainable,

n_{M}\ :=\ \mathrm{max}\left(\{n:\text{row $n$ is attainable in finitely many moves}\}\right).

(2.10)

The initial boardstate contains a checker on each square below some line, denoted with the double bar in Table
1
. We call this row of checkers row 0. Hence we can count the total initial weight of the board by summing the weights of all squares with a checker. This gives

E_{0}\ =\ \frac{\alpha^{n}(1+\alpha)}{(1-\alpha)^{2}}.

(3.1)

We want the energy of the board to be non-increasing under all possible moves. To do this, we consider a move towards the target square. This has change in energy

\Delta E\ =\ \alpha^{k}(1-\alpha-\alpha^{2}).

(3.2)

It makes sense to set this to equal zero since moving toward the target is intuitively the ‘best’ possible move. We pick the value of
\alpha
with
|\alpha|<1
so that the initial energy is finite, giving
\alpha=\frac{\sqrt{5}-1}{2}=1/\varphi
and
E_{0}=\alpha^{n-5}
. Considering the change in energy under all other possible moves, both horizontal and vertical, it is easy to show that with this value of
\alpha
the energy must always be non-increasing.

Conway’s result, that row 5 is not attainable in finitely many moves, is then an immediate consequence of Theorem
2.4
. To see this, set
n=5
. Then we have
E_{0}=1
, but the energy of just the target square
T
is also 1. Hence
B
must just be the square
T

(i)
is violated. Then row 5 is not attainable in finitely many moves by
(ii)
.

It is possible to explicitly find a sequence of moves that will allow row 4 to be reached, and in fact this only requires a minimum of 20 checkers. A possible starting position with 20 checkers can be found in
[
3
]
.

4
Generalisations

We now generalise the game. We make the following alterations.

•

Each square can now have any number of checkers occupying it.

•

Each square that would usually start with a checker starts with
m
checkers.

•

Checkers now jump over
k-1
pieces instead of just one, removing a checker from each square they jump over.

When we consider this variant on the board
\mathbb{Z}^{d}
, we call this the Conway
(m,k,d)
-game. We define moves as jumping over
k-1
checkers instead of
k
for notational convenience. Note that earlier the condition that each checker can only jump into an empty square was not in fact relevant for the solution, the game behaved the same with or without this condition.

4.2

\mathbb{Z}
:

\mathbb{Z}

\displaystyle F(n+i+1)-\left(\sum_{j=0}^{i}F(j+1)\right)m

\displaystyle\sim\ \

\displaystyle c\varphi^{n+i+1}-cm\left(\varphi+\cdots+\varphi^{i+1}\right)

\displaystyle\sim\ \

\displaystyle c\left(\varphi^{n+i+1}-m\left(\frac{\varphi^{i+2}}{\varphi-1}\right)\right)

\displaystyle=\ \

\displaystyle c\varphi^{i+1}\left(\varphi^{n}-\frac{m\varphi}{\varphi-1}\right).

(4.6)

\varphi^{n-1}-\frac{m}{\varphi-1}\ <\ 0.

(4.7)

(4.8)

Hence we have equality and it is always possible to reach row

when
m>1
.

4.3
Solution in
\mathbb{Z}

We will now generalise this argument to the case when
k\geq 2
, which we will later use to prove Theorem
1.1
in full generality.

We need the following lemma.

Lemma 4.2
.

With
S_{i}(n)
defined as in (

), we have

\sum_{j=1}^{k}S_{k-j}(n)F_{k}(k-j+i)\ =\ F_{k}(n+i+k-1).

(4.9)

Proof.

Expanding this sum, we have

\displaystyle S_{0}F_{k}(i)+S_{1}F_{k}(i+1)+\cdots+S_{k-1}F_{k}(i+k-1)

\displaystyle=\

\displaystyle S_{k-1}F_{k}(i-1)+(S_{k-1}+S_{0})F_{k}(i)+(S_{k-1}+S_{1})F_{k}(i+1)+\cdots

\displaystyle\cdots+(S_{k-1}+S_{k-2})F_{k}(i+k-2).

(4.10)

Now note

\displaystyle S_{k-1}+S_{\ell}\ =\ 2

\displaystyle F_{k}(n+k-2)+2F_{k}(n+k-3)+\cdots

\displaystyle\cdots+2F_{k}(n+k-\ell-2)+F_{k}(n+k-\ell-3)+\cdots+F_{k}(n-1)

\displaystyle=\

\displaystyle F_{k}(n+k-1)+\cdots+F_{k}(n+k-\ell-2).

(4.11)

We compare this to

S_{\ell}\ =\ F_{k}(n+k-2)+\cdots+F_{K}(n+k-\ell-2),

(4.12)

and see that (
4.11
) is indexed one higher, with one additional term. Applying this to (
4.10
) gives that we can replace all instances of
n
in the expansion with
n+1
, as long as we replace all instances of
i
with
i-1
.

We can repeatedly apply this, replacing all
n
’s with
(n+i)
’s and all
i
’s with
0
’s. Notice now that the only term that remains non-zero is
S_{k-1}F_{k}(i+k-1)
. By definition,
S_{k-1}=F(n+k-1)
. Then the term
F_{k}(n+k-1)F_{k}(i+k-1)
becomes
F_{k}(n+i+k-1)
under the change of
i
’s and
n
’s, as required.
∎

Theorem 4.3
.

In the Conway
(m,k,1)
-game, for
m>1
, it is always possible to reach the highest row theoretically attainable, namely

\left\lfloor\mathrm{log}_{\phi_{k}}(m)-\mathrm{log}_{\phi_{k}}(\phi_{k}-1)\right\rfloor+1.

(4.13)

In the case
m=1
, it is only possible to reach the first row in finitely many moves.

Proof.

We first work for
m>1
. Along the same lines as the
k=2
case, and inspired by Lemma
4.1
, hoping to reach the
n
th
row, we want to add the following amounts of checkers to each square from row 0 down.

•

We want to add
S_{k-1}-m
checkers to row
0
, to reach
S_{k-1}
checkers.

•

We want to add
S_{k-2}-m
checkers to row
-1
, so that it has
S_{k-2}
checkers.

•

We also need to add
S_{k-1}-m
checkers to row
-1
, so we have enough checkers to support adding
S_{k-1}-m
to row
0
. This is a total of
S_{k-1}+S_{k-2}-2m
checkers to be added.

•

We need to add
S_{k-3}-m
checkers to row
-2
.

•

In row
-2
, we also need enough checkers to support adding the appropriate amount in the two rows above (as long as
k\geq 2
), which is
S_{k-2}+2S_{k-1}-3m
.

•

Continue this down, in row
-i
, add the number of checkers required in that square minus
m
(
(0-m)
for rows further down than
-(k-1)
, since they don’t require any checkers in to reach the

\sum_{j=1}^{k}S_{k-j}(n)F_{k}(k-j+i)-a_{i}m,

(4.14)

a_{i}=a_{i-1}+a_{i-2}+a_{i-3}+\dots+a_{i-k}+1

is

F_{k}(n+i+k-1)-\left(\sum_{j=0}^{i}F_{k}(k-1+j)\right)m.

(4.17)

We then seek a condition on this being eventually non-positive for consecutive rows, then no more checkers are needed on the squares to jump up to row
n
(again note that this is in only a finite section of the column).

Using Corollary
2.7
, we have

\displaystyle F_{k}(n+i+k-1)-\left(\sum_{j=0}^{i}F_{k}(k-1+j)\right)m

\displaystyle\sim\ \

\displaystyle c\phi_{k}^{n+i+k-1}-cm\left(\phi_{k}^{k-1}+\cdots+\phi_{k}^{k-1+i}\right)

\displaystyle\sim\ \

\displaystyle c\phi_{k}^{k-1}\left(\phi_{k}^{n+i}-m\left(\frac{\phi_{k}^{i+1}}{\phi_{k}-1}\right)\right)

\displaystyle=\ \

\displaystyle c\phi_{k}^{i+k-1}\left(\phi_{k}^{n}-\frac{m\phi_{k}}{\phi_{k}-1}\right),

(4.18)

which is eventually non-positive if

\phi_{k}^{n-1}-\frac{m}{\phi_{k}-1}\ <\ 0.

(4.19)

n_{M}\ \geq\ \left\lfloor\text{log}_{\phi_{k}}(m)-\text{log}_{\phi_{k}}(\phi_{k}-1)\right\rfloor+1.

(4.20)

We now find an upper bound. Using the standard pagoda function and energy arguments, we have that the total energy of the board is
E_{0}=\frac{m\alpha^{n}}{1-\alpha}
, where
\alpha=1/\phi_{k}
. We solve for
E_{0}>1
, giving

n_{M}\ \leq\ \left\lfloor\text{log}_{\phi_{k}}(m)-\text{log}_{\phi_{k}}(1-\alpha)\right\rfloor\ =\ \left\lfloor\text{log}_{\phi_{k}}(m)-\text{log}_{\phi_{k}}(\phi_{k}-1)\right\rfloor+1.

(4.21)

m=1

n_{M}\ \leq\ \left\lfloor\mathrm{log}_{\varphi}\left(m\right)-\mathrm{log}_{\varphi}\left(\varphi-1\right)\right\rfloor+1

.

Remark 3
.

4.4
Bounds on checkers in row 1

In order to project into lower dimensions, we find the maximum number of checkers that can be placed on row 1.

Lemma 4.4
.

In the Conway
(m,k,1)
-game, it is always possible to add
\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor
checkers to the first row, where
\phi_{k}
is the
k
-nacci constant. Further, it is never possible to add
\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor+1
checkers.

Proof.

We first find the upper bound. Set the target square to be on the first row, then we have that the initial energy of the board is

E_{0}\ =\ \frac{m\alpha}{1-\alpha}\ =\ \frac{m}{\phi_{k}-1}.

(4.23)

The energy of the target square is 1, so we can have at most
\left\lfloor E_{0}\right\rfloor
checkers in row 1.

We now want to find a lower bound. To put
\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor
checkers onto the first row, we require that many checkers on each of rows 0 to
-(k-1)
.

We set
M=\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor
, then have the following sequence.

•

Row
0
needs
M
checkers, so we need to add
M-m
.

•

Row
-1
also needs
M
checkers, however we also need enough checkers to add
M-m
to the first row. Hence we need to add
2M-2m
, since there are already
m
checkers on the square.

•

Row
-2
again needs
M
checkers, as well as enough checkers to support jumping into both the first and second rows. Hence we need to add
4M-4m
checkers to this row

•

Continue this down the board, always summing the amount needed to be added on the
k
squares above.

From this, we get that row
-i
requires

F_{k}(k+i)M-a_{i}m

(4.24)

checkers, where
a_{i}
satisfies
a_{i}=a_{i-1}+\cdots+a_{i-k}+1
. From Lemma
2.8
we have that number of checkers needed to be added to row
-i
is

F_{k}(k+i)M-\sum_{j=0}^{i}F_{k}(k-1+i)m.

(4.25)

As usual, we want this to be eventually negative, or equal to zero. To do this, we again use Corollary
2.7
.

\displaystyle F_{k}(k+i)M-\sum_{j=0}^{i}F_{k}(k-1+i)m

\displaystyle\sim\ \

\displaystyle c\phi_{k}^{k+1}M-c\left(\phi_{k}^{k-1}+\cdots+\phi_{k}^{k-1+i}\right)m

\displaystyle\sim\ \

\displaystyle\phi_{k}^{k+i}M-\phi_{k}^{k-1}\frac{\phi_{k}^{i+1}}{\phi_{k}-1}m

\displaystyle\sim\ \

\displaystyle\phi_{k}^{k+i}\left(M-\frac{m}{\phi_{k}-1}\right).

(4.26)

This is eventually less than or equal to zero if
M-\frac{m}{\phi_{k}-1}<0
. Notice

\displaystyle M-\frac{m}{\phi_{k}-1}\ =\ \left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor-\frac{m}{\phi_{k}-1}\ <\ 0,

(4.27)

so we are done, it is always possible to add
\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor
checkers onto the first row. Note again that this only uses a finite section of the column. This also holds when
m=1
, since
\phi_{k}\geq\varphi
.
∎

4.5
Bounds in
d
dimensions

We now have all the tools we need to prove Theorem
1.1
. We first prove the upper bound.

Lemma 4.5
.

In the Conway
(m,k,d)
-game, with
\phi_{k}
the
k
-nacci constant,

n_{M}\ \leq\ \left\lfloor\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)\right\rfloor+1.

(4.28)

Proof.

To find the initial energy in
d
-dimensions, we sum the energies of subspaces of dimension
d-1
. In particular, the energy of the board in
d
-dimensions,
E(d)
, is

(1+2\alpha+2\alpha^{2}+\cdots)E(d-1)\ =\ \frac{1+\alpha}{1-\alpha}\cdot E(d-1).

(4.29)

We have
E(1)=\frac{m\alpha^{n}}{1-\alpha}
, so

E(d)\ =\ m\alpha^{n}\frac{(1+\alpha)^{d-1}}{(1-\alpha)^{d}}.

(4.30)

As usual, we solve for
E(d)>1
and take floors to obtain the bound

n_{M}\ \leq\ \left\lfloor\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)\right\rfloor+1.

(4.31)

∎

Note that when we set
k=2
,
m=1
and hence
\phi_{k}=\varphi
this gives

n_{M}\ <\ 3d-1,

(4.32)

where we have strictness since in this case

\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)

(4.33)

is an integer. This agrees with the bounds found in

and

]
.

Theorem 4.6
.

In the Conway
(m,k,d)
-game, it is possible to reach the theoretically highest possible row for almost all choices of
m
.

Proof.

When projecting from
\mathbb{Z}^{d}
to
\mathbb{Z}^{d-1}
, it is possible to put
m+2\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor=\frac{\phi_{k}+1}{\phi_{k}-1}m-\varepsilon_{d-2}
checkers onto every square in the space of lower dimension, where
\varepsilon_{d-2}\in(0,2)
is twice the error from the floor function.

Hence, from
\mathbb{Z}^{d}
and projecting down to
\mathbb{Z}
, we have that on each square we can place

\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}m-\sum_{i=0}^{d-2}\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{i}\varepsilon_{i}

(4.34)

checkers. Note this is possible in finite time since all the algorithms used only require a finite section of the board.

Definition 4.7
.

We write
C(d)
for a constant of the form

C(d)\ =\ \sum_{i=0}^{d}\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{i}\varepsilon_{i},

(4.35)

for a collection of
\varepsilon_{i}\in(0,2)
.

Remark 4
.

Note that when we write
C(d)
the collection of
\varepsilon_{i}

Applying Theorem
4.3
, we then have that the maximum attainable row is

\left\lfloor\mathrm{log}_{\phi_{k}}\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}m-C(d-2)\right)-\mathrm{log}_{\phi_{k}}\left(\phi_{k}-1\right)\right\rfloor+1.

(4.36)

We also have

\displaystyle\mathrm{log}_{\phi_{k}}\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}-\frac{C(d-2)}{m}\right)

\displaystyle=\

\displaystyle\mathrm{log}_{\phi_{k}}\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}\right)+\mathrm{log}_{\phi_{k}}\left(1-\frac{C(d-2)}{m}\cdot\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}\right).

(4.37)

We define the following function.

Definition 4.8
.

Write

\mathcal{E}(m)\ :=\ -\mathrm{log}_{\phi_{k}}\left(1-\frac{C(d-2)}{m}\cdot\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}\right).

(4.38)

We then have that the maximum attainable row is

\left\lfloor\mathrm{log}_{\phi_{k}}\left(m\right)+\mathrm{log}_{\phi_{k}}\left(\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}\right)-\mathcal{E}(m)\right\rfloor+1.

(4.39)

We now fix
k,d
and write

A:=\frac{(\phi_{k}+1)^{d-1}}{(\phi_{k}-1)^{d}}.

(4.40)

Define

\displaystyle S

\displaystyle\ :=\ \{m:\text{the maximum row is unreachable in the $(m,k,d)$-game}\}

\displaystyle\ \ =\ \{m:\{\mathrm{log}_{\phi_{k}}\left(Am\right)\}<\mathcal{E}(m)\},

(4.41)

where
\{\mathrm{log}_{\phi_{k}}\left(Am\right)\}
denotes the fractional part of
\mathrm{log}_{\phi_{k}}\left(Am\right)
. We will show that
S
has lower asymptotic density 0. Clearly
\mathcal{E}(m)\to 0
as
m\to\infty
, so let
\varepsilon>0
, and there is
M
s.t.
\mathcal{E}(m)\leq\varepsilon
for each
m>M
. Then we have

\displaystyle S

\displaystyle\ \subseteq\ \{1,...,M\}\ \cup\ \{m:\{\mathrm{log}_{\phi_{k}}\left(Am\right)\}\leq\varepsilon\}

\displaystyle\ =\ \{1,...,M\}\ \cup\ \left(\bigcup_{c=1}^{\infty}\{m:c\leq\mathrm{log}_{\phi_{k}}\left(Am\right)\leq c+\varepsilon\}\right)

\displaystyle\ =\ \{1,...,M\}\ \cup\ \left(\bigcup_{c=1}^{\infty}\frac{\phi_{k}^{c}}{A}[1,\phi_{k}^{\varepsilon}]\right).

(4.42)

Since an interval of length
\ell
contains at most
\ell+1
integers, the set
\bigcup_{c=1}^{N}\frac{\phi_{k}^{c}}{A}[1,\phi_{k}^{\varepsilon}]
contains at most
N+\sum_{c=1}^{N}\frac{\phi_{k}^{c}}{A}(\phi_{k}^{\varepsilon}-1)
integers. Further,
\bigcup_{c=1}^{N}\frac{\phi_{k}^{c}}{A}[1,\phi_{k}^{\varepsilon}]\subseteq[0,\phi_{k}^{N+\varepsilon}]
, so the lower asymptotic density of
S
is at most

\lim_{N\to\infty}\frac{1}{\phi_{k}^{N+\varepsilon}-1}\left(M+N+\frac{\phi_{k}(\phi_{k}^{\varepsilon}-1)(\phi_{k}^{N}-1)}{A(\phi_{k}-1)}\right)\ =\ \frac{\phi_{k}(\phi_{k}^{\varepsilon}-1)}{A(\phi_{k}-1)\phi_{k}^{\varepsilon}}.

(4.43)

Since
A
is constant and
\varepsilon
arbitrary,
\frac{\phi_{k}(\phi_{k}^{\varepsilon}-1)}{A(\phi_{k}-1)\phi_{k}^{\varepsilon}}\to 0
as
\varepsilon\to 0
, so the lower asymptotic density of
S
is zero.
∎

Lemma 4.9
.

For any choice of

and

\mathcal{E}(m)\ <\ 1,

(4.44)

\mathcal{E}(m)

Proof.

We have

\displaystyle|\mathcal{E}(m)|\ =\

\displaystyle\left\lvert\mathrm{log}_{\phi_{k}}\left(1-\frac{C(d-2)}{m}\cdot\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}\right)\right\rvert.

We also have
|\mathrm{log}_{\phi_{k}}\left(x\right)|<1

\frac{C(d-2)}{m}\cdot\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}\ \in\ \left(1-\phi_{k},1-\frac{1}{\phi_{k}}\right),

(4.45)

or equivalently, since this quantity is positive and

C(d)\ <\ 2\frac{\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d+1}-1}{\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)-1}\ =\ (\phi_{k}+1)\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d}-1\right).

(4.47)

\displaystyle\frac{C(d-2)}{m}\cdot\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}

\displaystyle<\ \

\displaystyle\frac{1}{2}(\phi_{k}+1)\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-2}-1\right)\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}

\displaystyle<\ \

\displaystyle\frac{1}{2}(\phi_{k}+1)\left(\frac{\phi_{k}-1}{\phi_{k}+1}-\left(\frac{\phi_{k}-1}{\phi_{k}+1}\right)^{d-1}\right)

\displaystyle<\ \

\displaystyle\frac{1}{2}(\phi_{k}-1)

\displaystyle<\ \

4.6
Maximum number of checkers in one square

We finish with a bound on the maximum number of checkers that can be moved to occupy one square.

Theorem 4.11
.

In the Conway
(m,k,d)
-game, it is possible to reach a state with at least

\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d}m-C(d-1)

(4.51)

checkers on one square. Further, it is not possible to place more than
\left\lfloor\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d}m\right\rfloor
checkers onto a square.

Proof.

We will first project onto
\mathbb{Z}
in the usual way, obtaining

\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}m-C(d-2)

(4.52)

checkers on each square. Since the algorithm in Lemma
4.4
uses only a finite section of the board, by choosing a square sufficiently far down the board it is possible to add

2\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor\ =\ \frac{2m}{\phi_{k}-1}-\varepsilon

(4.53)

checkers onto the square, for some
\varepsilon\in(0,2)
. We do this by using the result of Lemma
4.4
to add
\left\lfloor\frac{m}{\phi_{k}-1}\right\rfloor
onto the square from above and below. We then have that, replacing
m
with the number of checkers we have amassed on each square, in one square we can place

\displaystyle\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}m-C(d-2)+\frac{2}{\phi_{k}-1}\left(\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d-1}m-C(d-2)\right)-\varepsilon

\displaystyle=\

\displaystyle\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d}m-\frac{\phi_{k}+1}{\phi_{k}-1}C(d-2)-\varepsilon

\displaystyle=\

\displaystyle\left(\frac{\phi_{k}+1}{\phi_{k}-1}\right)^{d}m-C(d-1)

(4.54)

checkers.

We now derive an upper bound. Choose a target square on the board that we will try to add checkers to, and weight the board in the usual way, by powers of
1/\phi_{k}
defined by the taxicab distance from the target square. By the same argument as in (
4.30
), we have

E(d)\ =\ (1+2\alpha+2\alpha^{2}+\cdots)E(d-1)\ =\ \frac{1+\alpha}{1-\alpha}\cdot E(d-1).

(4.55)

In this case, however, if the target square is
n
