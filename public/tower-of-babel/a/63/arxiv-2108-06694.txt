Martingale Transformations of Brownian Motion with Application to Functional Equations
M. Mania, R. Tevzadze

Abstract
. We describe the classes of functions f = ( f ⁡ ( x ) , x ∈ R ) f=(f(x),x\in R) , for which processes f ⁡ ( W t ) − E ​ f ​ ( W t ) f(W_{t})-Ef(W_{t}) and f ⁡ ( W t ) / E ​ f ​ ( W t ) f(W_{t})/Ef(W_{t}) are martingales. We study also the time-dependent martingale transformations of a Brownian Motion.

1
Introduction.

It is well known that if for a function
f=(f(x),x\in R)
the transformed process
(f(W_{t}),t\geq 0)
of a Brownian Motion
W

is a right-continuous martingale, then
f
is a linear function (see, Theorem 5.5 from
[
3
]
). It is also known that the time-dependent function
f=(f(t,x),t\geq 0,x\in R)
is a linear function of
x

if and only if the transformed process
(f(t,M_{t}),t\geq 0)
is a martingale for any martingale
M
and to this end to require the martingale property of
f(t,\sigma W_{t})
for two different

\sigma_{1}\neq\sigma_{2}\neq 0
is sufficient (see Corollary 1 of Theorem 2 from
[
6
]
).

In this paper we give simple generalizations of these results.
We describe the classes of functions
f
for which the processes
f(W_{t})-Ef(W_{t})
and

f(W_{t})/Ef(W_{t})
(for
f(x)>0
) are martingales. We prove that the process

f(W_{t})-Ef(W_{t})\;\;\;\;\;(\text{resp.}\;\;\;f(W_{t})/Ef(W_{t})),\;\;\;\;t\geq 0

is a right-continuous martingale if and only if the function
f(x)
is of the form

ax^{2}+bx+c\;\;\;(\text{resp.}\;\;\;ae^{\lambda x}+be^{-\lambda x}),

for some constants
a,b,c
and
\lambda
. Besides, we show that if
f(W_{t})-Ef(W_{t})
(resp.
f(W_{t})/Ef(W_{t}))
is only a martingale (without assuming the regularity of paths), then

f(x)
is equal to some square trinomial (resp. to the function
ae^{\lambda x}+be^{-\lambda x}
for some
a,b,\lambda
) almost everywhere with respect to the Lebesgue measure.

Our main motivation to consider such martingale transformations of a Brownian Motion was their relations with functional equations. We show that if the function

f=(f(x),x\in R)
is a measurable solution of the quadratic functional equation

f\left(x+y\right)+f\left(x-y\right)=2f\left(x\right)+2f\left(y\right)\;\;\;\text{for all}\;\;\;x,y\in R,

(1)

then the difference
f(W_{t})-Ef(W_{t})
is a martingale and if
f
is a strictly positive
solution of the D’Alembert functional equation

f\left(x+y\right)+f\left(x-y\right)=2f\left(x\right)f\left(y\right)\;\;\;\text{for all}\;\;\;x,y\in R,

(2)

then a martingale will be the process
f(W_{t})/Ef(W_{t})
. The above-mentioned descriptions of martingale functions enable us to
give equivalent characterization of the general measurable solution of equations (
1
) and (
2
) in martingale terms.

We consider also time-dependent functions
(f(t,x),t\geq 0,x\in R)
for which the transformed processes

{f(t,\sigma W_{t})}-{Ef(t,\sigma W_{t})}\;\;\;\text{ and}\;\;\;{f(t,\sigma W_{t})}/{Ef(t,\sigma W_{t})}

(3)

are martingales, where
\sigma
is a constant. To obtain simple structural properties for such functions, as for the case of functions
f=(f(x),x\in R)
, one needs some type
of growth conditions on the function
f
, or one should require the martingale property for transformed processes (
3
) at least for two different
\sigma\neq 0
. Corresponding assertions (Theorems 5-7)
are given in section 4.

2
Martingale transformations of a Brownian Motion

Let
W=(W_{t},t\geq 0)
be a standard Brownian Motion defined on a complete probability space
(\Omega,{\cal F},P)
with filtration

F=({{\cal F}}_{t},t\geq 0)
generated by the Brownian Motion
W
.

Theorem 1
. Let
f=(f(x),x\in R)
be a measurable strictly positive function . Then

a)
f(W_{t})
is integrable for every
t\geq 0
and the process

N_{t}=\frac{f(W_{t})}{Ef(W_{t})},\;\;\;t\geq 0,

is a right-continuous (
P
-a.s.) martingale if and only if the function
f
is of the form

f(x)=ae^{\lambda x}+be^{-\lambda x},

(4)

for some constants
a\geq 0,b\geq 0,ab\neq 0
and
\lambda\in R
.

b)
f(W_{t})
is integrable for every
t\geq 0
and the process

N_{t}
is a martingale if and only if the function
f(x)
coincides with the function
ae^{\lambda x}+be^{-\lambda x}

(for some constants
a\geq 0,b\geq 0,ab\neq 0
and
\lambda\in R
) almost everywhere with respect to the Lebesgue measure.

Proof.

a) Let the process
N_{t}
is a right-continuous (
P
-a.s.) martingale and let

g(t)\equiv Ef(W_{t})=\int_{R}f(y)\frac{1}{\sqrt{2\pi t}}e^{-\frac{y^{2}}{2t}}dy.

Since
E|f(W_{t})|<\infty
for all
t\geq 0
, the function
g(t)
will be continuous for any
t>0
.
Since
N_{t}
is right-continuous (
P
-a.s.)
and
g(t)
is continuous, the process
f(W_{t})
will be also right-continuous
P
-a.s..
This implies that the function
f(x)
is continuous (see Theorem 5.5 from
[
3
]
or Lemma A1 from
[
7
]
).

Let

F(t,x)=\frac{f(x)}{g(t)},\;\;\;\;t\geq 0,x\in R.

Since
F(t,W_{t})
is a martingale, we have that

F(t,W_{t})=\frac{f(W_{t})}{g(t)}=\frac{1}{g(T)}E(f(W_{T})/{\cal F}_{t})

(5)

P-a.s.
for all
t\leq T
. Let

u(t,x)=E(f(W_{T})/W_{t}=x).

Since
f
is positive,
u(t,x)
will be of the class
C^{1.2}
on
(0,T)\times R
and satisfies the ”backward” heat equation (see, e.g.
[
5
]
page 257)

\frac{\partial u}{\partial t}+\frac{1}{2}\frac{\partial^{2}u}{\partial x^{2}}=0,\;\;\;\;0<t<T,x\in R.

(6)

By the Markov property of
W

u(t,W_{t})=E(f(W_{T})/{\cal F}_{t})

and from (
5
) we have that

f(W_{t})=\frac{g(t)}{g(T)}u(t,W_{t})\;\;\;\;a.s.

Therefore,

\int_{R}{\big|f\left(x\right)-\frac{g(t)}{g(T)}u\left(t,x\right)\big|\frac{1}{\sqrt{2\pi t}}e^{-\frac{x^{2}}{2t}}dx}=0

which implies that for any
0<t\leq T

f\left(x\right)=\frac{g(t)}{g(T)}u\left(t,x\right)\quad

(7)

almost everywhere with respect to the Lebesgue measure. Since
f
and
u
are continuous, we obtain that for any
0<t<T

equality (
7
) is satisfied for all
x\in R
.

Since
g(t)>0
for all
t
, this implies that
g(t)
is differentiable,
f(x)
is two-times differentiable and

u\left(t,x\right)=\frac{g(T)}{g(t)}f\left(x\right)\;\;\;\text{for all}\;\;\;x\in R

(8)

for any
0<t<T
.

Therefore, it follows from (
6
) and (
8
) that

\frac{1}{2}\frac{g(T)}{g(t)}f^{\prime\prime}(x)-\frac{g(T)g^{\prime}(t)}{g^{2}(t)}f(x)=0,

which implies that

\frac{f^{\prime\prime}(x)}{f(x)}=2\frac{g^{\prime}(t)}{g(t)}.

(9)

Since the left-hand side of (
9
) does not depend on
t
and the right-hand side on
x
, both parts of (
9
) are equal to a constant, which
we denote by
c
. If
c<0
, then the general solution of equation
f^{\prime\prime}(x)=cf(x)
leads to
f(x)
which, with necessity, changes its sign,
hence
c=\lambda^{2}
for some
\lambda\in R
. Therefore, we obtain that

f^{\prime\prime}(x)=\lambda^{2}f(x)\;\;\;\text{and}\;\;\;g^{\prime}(t)=\frac{\lambda^{2}}{2}g(t).

for some constant
\lambda\in R
. Thus,

f(x)=ae^{\lambda x}+be^{-\lambda x},\;\;\;g(t)=Ef(W_{t})=(a+b)e^{\frac{\lambda^{2}}{2}t}.

Since the function
f
should be strictly positive, we shall have that
a\geq 0,b\geq 0,ab\neq 0

Now let us assume that the function
f
is of the form (
4
). Then
g(t)=E(ae^{\lambda W_{t}}+be^{-\lambda W_{t}})=(a+b)e^{\frac{\lambda^{2}}{2}t}
and the process

\frac{f(W_{t})}{Ef(W_{t})}=\frac{a}{a+b}e^{\lambda W_{t}-\frac{\lambda^{2}}{2}t}+\frac{b}{a+b}e^{-\lambda W_{t}-\frac{\lambda^{2}}{2}t}

is a martingale, as a linear combination of two exponential martingales.

b) Let
N_{t}
be a martingale and let

\tilde{f}(x)=\frac{g(t_{0})}{g(T)}u(t_{0},x),

for some
t_{0}>0
. It follows from (
7
) that

\lambda(x:f(x)\neq\tilde{f}(x))=0,

(10)

where
\lambda
is the Lebesgue measure and by definition of

the function
\tilde{f}(x)
is continuous (moreover, it is two-times differentiable).
It follows from (
10
) that
P(f(W_{t})=\tilde{f}(W_{t}))=1
for any
t\geq 0
and since
Ef(W_{t})=E\tilde{f}(W_{t})
,
we obtain that for any
t\geq 0

P\big(\frac{f(W_{t})}{Ef(W_{t})}=\frac{\tilde{f}(W_{t})}{E\tilde{f}(W_{t})}\big)=1.

This implies that the process
\tilde{f}(W_{t})/E\tilde{f}(W_{t})

is a continuous martingale and it follows from part a) of this theorem that
\tilde{f}(x)
is of the form (
4
).
Therefore,

f(x)
coincides with the function
ae^{\lambda x}+be^{-\lambda x}
almost everywhere with respect to the Lebesgue measure.

The converse is proved similarly to the part a) of this theorem.
∎

Theorem 2

3
Application to Functional Equations.

It was proved in
[
8
]
(see also
[
7
]
for multidimensional case) that if the function
f=(f(x),x\in R)
is a measurable solution of the Cauchy additive functional equation

f(x+y)=f(x)+f(y),\;\;\;\text{for all}\;\;\;x,y\in R,

then the transformed process
(f(W_{t}),t\geq 0)
is a right-continuous martingale, which (by Corollary 1 of Theorem 2) implies that
f
is a linear function.
Here we propose a similar characterization of solutions of the quadratic functional equation

f\left(x+y\right)+f\left(x-y\right)=2f\left(x\right)+2f\left(y\right)\;\;\;\text{for all}\;\;\;x,y\in R,

(21)

where for a measurable solution of this equation the process
f(W_{t})
is no longer a martingale, but a martingale will be the difference
f(W_{t})-Ef(W_{t})
, which enable us to use Theorem 2
and to give a martingale characterization of equation (
21
).

It is well known (see, e.g.,
[
2
]
,
[
9
]
), that the general measurable solution of equation
(\ref{q1})
is the function
f\left(x\right)=ax^{2},a\in R
. Moreover, in

[
2
]
equation (
21
) has been solved without any assumptions using the Hamel basis. We consider only the Lebesgue measurable solutions of (
21
)
and using Theorem 2 we characterize the general measurable solution of equation (

) in terms of martingales, which gives also a probabilistic proof of this assertion.

On Time-dependent Martingale Transformations of a Brownian Motion.

In this section we consider time-dependent functions
(f(t,x),t\geq 0,x\in R)

\sigma

.

Recall that a heat polynomial is any polynomial solution
of the heat equation
u_{t}+\frac{1}{2}u_{xx}=0
.

Theorem 5.
Let
f:(0,\infty)\times R\to R
be a continuous function, such that
f(t,W_{t})
is integrable for every
t\geq 0
and
n
is an integer
n\geq 1
. Then

f(t,W_{t})-Ef(t,W_{t})
is a martingale
satisfying condition:

C)
for some
C>0
the process

\langle f(\cdot,W)-g\rangle_{t}-C\int_{0}^{t}(1+s+W_{s}^{2})^{n-1}ds\;\;\text{is non-increasing},

if and only if
the function
f(t,x)
is of the form

f(t,x)=P(t,x)+c(t)

(45)

for some heat polynomial
P
of degree
n
and deterministic function
c(t),t\geq 0
.

Proof.

Let us prove the sufficiency, the necessity part of this theorem is evident.
The martingale property of the process
f(t,W_{t})-g(t)
and the continuity of the function
f
imply that

f(t,x)-g(t)=\int_{R}(f(T,y)-g(t))\frac{1}{\sqrt{2\pi(T-t)}}e^{-\frac{(y-x)^{2}}{2(T-t)}}dy.

(46)

It is evident that
f-g
is a weak solution of the heat equation. Indeed for every infinitely differentiable finite (on
(0,\infty)\times{R}
) function
\varphi
, with

supp\varphi\subset(0,T)\times R
for some
T>0
we have from (
46
) that

\displaystyle\int_{0}^{\infty}\int_{R}(f(s,y)-g(s))\big(\frac{\partial\varphi}{\partial t}(s,y)-\frac{1}{2}\varphi_{yy}(s,y)\big)dyds

\displaystyle=\int_{0}^{T}\int_{R}\int_{R}(f(T,x)-g(T))\frac{e^{-\frac{(x-y)^{2}}{2(T-s)}}}{\sqrt{2\pi(T-s)}}dx\big(\frac{\partial\varphi}{\partial t}(s,y)-\frac{1}{2}\varphi_{yy}(s,y)\big)dyds

\displaystyle=-\int_{0}^{T}\int_{R}(f(T,x)-g(T))\int_{R}\varphi(s,y)\big(\frac{\partial}{\partial t}+\frac{1}{2}\frac{\partial^{2}}{\partial y^{2}}\big)\frac{e^{-\frac{(x-y)^{2}}{2(T-s)}}}{\sqrt{2\pi(T-s)}}dydxds=0.

By hypoelipticity property of the heat equation
f(t,x)-g(t)
coincides with an infinitely differentiable function a.e. . Since
f(t,x)
is continuous the function
f(t,x)-g(t)
itself will be
infinitely differentiable. Therefore,
by the Ito formula we get

f(t,W_{t})-g(t)=f(0,0)-g(0)+\int_{0}^{t}f_{x}(s,W_{s})dW_{s},

which implies that
\langle f(\cdot,W)-g\rangle_{t}=\int_{0}^{t}(f_{x}(s,W_{s}))^{2}ds
.
The condition of this theorem gives
|f_{x}(s,W_{s})|^{2}\leq C(1+s+W_{s}^{2})^{n-1}
, which is equivalent to the inequality
|f_{x}(t,x)|\leq C(\sqrt{1+t+x^{2}})^{{n-1}}
.
Since
f_{x}
is the classical solution of the heat equation
by the Liouville theorem for heat equations
[
4
]
it follows that
f_{x}(t,x)
coincides a.e. with a heat polynomial of degree
n-1
. Therefore
f(t,x)
is of the form (
45
).
∎

The Hermite polynomial is defined by

H_{k}(t,x)=(-t)^{k}e^{x^{2}/2t}\frac{\partial^{k}}{\partial x^{k}}e^{-x^{2}/2t}
. Using the Taylor expansion for exponential function we get

\displaystyle\sum_{k=0}^{\infty}\sigma^{k}\frac{H_{k}(t,x)}{k!}=\sum_{k=0}^{\infty}\sigma^{k}\frac{(-t)^{k}e^{x^{2}/2t}\frac{\partial^{k}}{\partial x^{k}}e^{-x^{2}/2t}}{k!}

\displaystyle=e^{x^{2}/2t}\sum_{k=0}^{\infty}\frac{(-t\sigma)^{k}}{k!}\frac{\partial^{k}}{\partial x^{k}}e^{-x^{2}/2t}=e^{x^{2}/2t}e^{-(x-\sigma t)^{2}/2t}=e^{\sigma x-\frac{\sigma^{2}}{2}t}.

From the expansion
e^{\sigma x-\frac{\sigma^{2}}{2}t}=\sum_{n=0}^{\infty}\frac{H_{n}(t,x)}{n!}\sigma^{n}
follows that
\{H_{n}\}
are heat polynomials.
If
f(t,x)=\sum_{k=0}^{n}a_{k}(t)x^{n-k}
is arbitrary heat polynomial, then equalizing coefficients in the heat equation we get

\displaystyle a_{0}^{\prime}(t)=0,\;a_{2j}^{\prime}(t)=-\frac{(n-2j+2)(n-2j+1)}{2}a_{2j-2}(t),\;0<2j\leq n

\displaystyle a_{1}^{\prime}(t)=0,\;a_{2j+1}^{\prime}(t)=-\frac{(n-2j+3)(n-2j+2)}{2}a_{2j-1}(t),\;0<2j+1\leq n.

Hence solution of the system

\displaystyle a_{0}(t)=C_{0},

\displaystyle a_{2j}(t,C_{0},C_{2},...,C_{2j})

\displaystyle=-\frac{(n-2j+2)(n-2j+1)}{2}\int a_{2j-2}(t,C_{0},C_{2},...,C_{2j-2})dt+C_{2j},\;0<2j\leq n

\displaystyle a_{1}(t)=C_{1},

\displaystyle a_{2j+1}(t,C_{1},C_{3},...,C_{2j+1})

\displaystyle=-\frac{(n-2j+3)(n-2j+2)}{2}\int a_{2j-1}(t,C_{1},C_{3},...,C_{2j-1})dt+C_{2j+1},\;1<2j+1\leq n.

linearly depends on arbitrary constants
C_{0},C_{1},...,C_{n}
. Since
