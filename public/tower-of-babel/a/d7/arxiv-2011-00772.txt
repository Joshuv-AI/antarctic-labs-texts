Some extended hypergeometric matrix functions and their fractional calculus
Ashish Verma, Ravi Dwivedi, Vivek Sahai

Abstract
In this paper, we study some extended hypergeometric functions from matrix point of view. We have given the integral representations of these matrix functions. Finally, we obtain some generating function relations using fractional derivative operators. Keywords : Matrix functional calculus, Appell functions, Lauricella functions, Fractional derivative operators AMS Subject Classification : 15A15; 33C65.

The Gauss hypergeometric function and Kummer hypergeometric function are amongst the most appeared special functions in mathematics as well as in physics. Due to a wide range of applications, these hypergeometric functions have been studied from different aspects

In this paper, we study the matrix analogues of some extended hypergeometric functions of two and three variables. We obtain the integral representations for these matrix functions. Finally, we use the extended Riemann-Liouville derivative operator and obtain certain generating function relations in terms of these matrix functions. The section-wise treatment is as follows:

In Section 2, we give the basic definitions related to special matrix functions that are needed in the sequel. In Section 3, we define the extended Appell matrix functions and extended Lauricella matrix function. We also discuss the regions of convergence as well as the integral representations satisfied by these matrix functions. In Section 4, we define the matrix analogue of extended Riemann-Liouville derivative operators and transform several matrix functions under these derivative operators. Finally, in Section 5, we obtain certain generating function relations which turn out in terms of extended Appell matrix functions and extended Lauricella matrix function.

Preliminaries

Throughout the paper,
\mathbb{C}^{r\times r}
is the vector space of
r
-square matrices with complex entries. For a matrix
A\in\mathbb{C}^{r\times r}
the spectrum, denoted by
\sigma(A)

If

A

\mathbb{C}^{r\times r}
is said to be positive stable if
\Re(\lambda)>0
for all
\lambda\in\sigma(A)
.

If
A
is a positive stable matrix in
\mathbb{C}^{r\times r}
, then
\Gamma(A)
can be expressed as
[
10
]

\Gamma(A)=\int_{0}^{\infty}e^{-t}\,t^{A-I}\,dt.

(2.1)

Furthermore, if
A+kI
is invertible for all integers
k\geq 0
, then the reciprocal gamma matrix function is defined as
[
10
]

\Gamma^{-1}(A)=A(A+I)\dots(A+(n-1)I)\Gamma^{-1}(A+nI),\ n\geq 1.

(2.2)

If
M\in\mathbb{C}^{r\times r}
is a positive stable matrix and
n\geq 1
is an integer, then the gamma matrix function can also be defined in the form of a limit as
[
10
]

\Gamma(M)=\lim_{n\to\infty}(n-1)!\,(M)_{n}^{-1}\,n^{M}.

(2.3)

By application of the matrix functional calculus, the Pochhammer symbol for
A\in\mathbb{C}^{r\times r}
is given by
[
11
]

(A)_{n}=\begin{cases}I,&\text{if $n=0$},\\
A(A+I)\dots(A+(n-1)I),&\text{if $n\geq 1$}.\end{cases}

(2.4)

This gives

(A)_{n}=\Gamma^{-1}(A)\ \Gamma(A+nI),\qquad n\geq 1.

(2.5)

If
A
and
B
are positive stable matrices in
\mathbb{C}^{r\times r}
, then, for
AB=BA
, the beta matrix function is defined as
[
10

\displaystyle\mathfrak{B}(A,B)=\Gamma(A)\Gamma(B)\Gamma^{-1}(A+B)

\displaystyle=\int_{0}^{1}t^{A-I}(1-t)^{B-I}dt

(2.6)

\displaystyle=\int_{0}^{\infty}u^{A-I}(1+u)^{-(A+B)}du.

(2.7)

Let
A
,
B
and
\mathbb{X}
be positive stable and commuting matrices in
\mathbb{C}^{r\times r}
such that
A+kI
,
B+kI
and

[

]

\displaystyle\mathfrak{B}(A,B;\mathbb{X})=\int_{0}^{1}t^{A-I}(1-t)^{B-I}\exp\Big(\frac{-\mathbb{X}}{t(1-t)}\Big)dt.

(2.8)

Hence,

\displaystyle\mathfrak{B}(A,B;\mathbb{X})=\Gamma({A},\mathbb{X})\,\Gamma({B},\mathbb{X})\,\Gamma^{-1}({A+B},\mathbb{X}).

(2.9)

It is obvious that
\mathbb{X}=O
gives the original beta matrix function
[
10
]
.
Let
A
,
B
,

[

\displaystyle{}_{2}F_{1}(A,B;C;z)=\sum_{n=0}^{\infty}(A)_{n}(B)_{n}(C)_{n}^{-1}\frac{z^{n}}{n!}.

(2.10)

Furthermore, if

B

\displaystyle{{}_{2}F_{1}}(A,B;C;z)=

\displaystyle\left(\int_{0}^{1}(1-zt)^{-A}\,t^{B-I}(1-t)^{C-B-I}dt\right)

\displaystyle\times\Gamma^{-1}(B)\Gamma^{-1}(C-B)\Gamma(C).

(2.11)

Recently, Abdalla et.al generalized the Gauss and Kummer hypergeometric matrix function. Let
A
,

,

,

and
\mathbb{X}

The extended Riemann-Liouville fractional derivative of order

\displaystyle D_{z}^{\mu,p}\{f(z)\}

\displaystyle=\frac{1}{\Gamma{(-\mu)}}\int_{0}^{z}f(t)(z-t)^{-\mu-1}\exp\left(\frac{-pz^{2}}{t(z-t)}\right)dt,\quad\Re(\mu)<0,\Re(p)>0

(m= 1, 2,…)

\displaystyle D_{z}^{\mu,p}\{f(z)\}=

\displaystyle\frac{d^{m}}{dz^{m}}D_{z}^{\mu-m,p}\{f(z)\}

\displaystyle=

\displaystyle\frac{d^{m}}{dz^{m}}\left(\frac{1}{\Gamma{(-\mu+m)}}\int_{0}^{z}f(t)(z-t)^{-\mu+m-1}\exp\left(\frac{-pz^{2}}{t(z-t)}\right)dt\right)

(4.2)

where the path of integration is a line from
0
to
z
in the complex t-plane. For the case

, we obtain the classical
Riemann-Liouville fractional derivative operator.

Definition 1
.

\displaystyle D_{z}^{\mu,\mathbb{X}}\{f(z)\}=\frac{1}{\Gamma{(-\mu)}}\int_{0}^{z}f(t)(z-t)^{-\mu-1}\exp\left(\frac{-\mathbb{X}z^{2}}{t(z-t)}\right)dt

\displaystyle\frac{d^{m}}{dz^{m}}\left[\frac{1}{\Gamma{(-\mu+m)}}\int_{0}^{z}f(t)(z-t)^{-\mu+m-1}\exp\left(\frac{-\mathbb{X}z^{2}}{t(z-t)}\right)dt\right],

From (

5
Generating functions

Theorem 5.1
.

Let
A
,
B
and
\mathbb{X}
be positive stable matrices in
\mathbb{C}^{r\times r}
and
\lambda,\mu\in\mathbb{C}
such that
\Re(\mu)>\Re(\lambda)>0
. Then, for
|z|<|1-t|
, we have

\displaystyle\sum_{n=0}^{\infty}\frac{(A)_{n}}{n!}F^{(\mathbb{X})}(A+nI,B;B+(\mu-\lambda)I;z)\,t^{n}=(1-t)^{-A}F^{(\mathbb{X})}{(A,B;B+(\mu-\lambda)I;\frac{z}{1-t})}.

(5.1)

Proof.

Consider the matrix identity

\displaystyle[(1-z)-t]^{-A}=(1-t)^{-A}\Big[1-\frac{z}{1-t}\Big]^{-A},

which can be written as

\displaystyle\sum_{n=0}^{\infty}\frac{(A)_{n}}{n!}(1-z)^{-A}\left(\frac{t}{1-z}\right)^{n}=(1-t)^{-A}\Big[1-\frac{z}{1-t}\Big]^{-A}.

(5.2)

Now, multiplying by
z^{B-I}
in Equation (
5.2
) and applying the extended fractional derivative operator
D_{z}^{\lambda-\mu,\mathbb{X}}
, we can write

\displaystyle\sum_{n=0}^{\infty}\frac{(A)_{n}}{n!}D_{z}^{\lambda-\mu,\mathbb{X}}\{z^{B-I}(1-z)^{-A-nI}\}t^{n}=(1-t)^{-A}D_{z}^{\lambda-\mu,\mathbb{X}}\{z^{B-I}\Big[1-\frac{z}{1-t}\Big]^{-A}\}.

Using Theorem
4.2
, we get the desired result.
∎

Theorem 5.2
.

Let
A
,
B
,
B^{\prime}
and
\mathbb{X}

\mathbb{C}^{r\times r}
and

\displaystyle\sum_{n=0}^{\infty}\frac{(B^{\prime})_{n}}{n!}F^{(\mathbb{X})}(B-nI,A;A+(\mu-\lambda)I;z)\,t^{n}

\displaystyle=(1-t)^{-B^{\prime}}F_{1}{(A,B,B^{\prime};A+(\mu-\lambda)I;z,\frac{-zt}{1-t};\mathbb{X})}.

Proof.

Using (
5.2
), we have

\displaystyle\sum_{n=0}^{\infty}\frac{(B^{\prime})_{n}}{n!}(1-z)^{n}t^{n}=(1-t)^{-B^{\prime}}\Big[1-\frac{-zt}{1-t}\Big]^{-B^{\prime}}.

(5.3)

Now multiplying both sides of the Equation (

\displaystyle\sum_{n=0}^{\infty}\frac{(B^{\prime})_{n}}{n!}D_{z}^{\lambda-\mu,\mathbb{X}}\{z^{A-I}(1-z)^{-(B-nI)}\}t^{n}

Using the Theorems
4.2
