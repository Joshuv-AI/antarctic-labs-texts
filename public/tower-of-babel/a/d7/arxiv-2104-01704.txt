Safe Control Synthesis via Input Constrained Control Barrier Functions
Devansh R. Agrawal, Dimitra Panagou

Abstract
This paper introduces the notion of an Input Constrained Control Barrier Function (ICCBF), as a method to synthesize safety-critical controllers for non-linear control affine systems with input constraints. The method identifies a subset of the safe set of states, and constructs a controller to render the subset forward invariant. The feedback controller is represented as the solution to a quadratic program, which can be solved efficiently for real-time implementation. Furthermore, we show that ICCBFs are a generalization of Higher Order Control Barrier Functions, and thus are applicable to systems of non-uniform relative degree. Simulation results are presented for the adaptive cruise control problem, and a spacecraft rendezvous problem.



I
Introduction

Many cyber-physical systems are safety critical, that is, they require guarantees that safety constraints are not violated during operation. Safety is often modeled by defining a safe subset of the state space for a given system, within which the state trajectories must always evolve. Recently, set-theoretic methods, such as Control Barrier Functions (CBFs) have become increasingly popular as a means of constructing and verifying such controllers
[
1
,
2
,
3
,
4
]
.

Quadratic Programs (QPs) enforcing CBF conditions have become popular for synthesizing low-level controllers to ensure that system trajectories remain within the safe set. These QPs can be solved in real-time at the current state, enabling safety-critical controllers for a wide range of non-linear systems to be computed efficiently during operation.

Prior work on CBFs has largely focused on systems where a sufficiently large control authority is available to ensure forward invariance of the safe set. However in the presence of input constraints, only a subset of the safe set may be rendered forward invariant. A few methods have been proposed to compute such subsets of the safe set. These include reachability analysis by solving a Hamilton-Jacobi partial differential equations over the state-space
[
5
,
3
]
and Sum-of-Squares (SOS) based semi-definite programs, which employ the positivstellensatz theorem to provide a certificate of safety
[
6
,
7
]
. Both methods scale poorly with the dimension of the state-space, and SOS methods assume the dynamics and safety constraints can be expressed as polynomials. Some methods have also been proposed for dynamical systems of specific classes, for instance Euler-Lagrange systems
[
8
]
.

In this paper, we introduce the notion of an Input Constrained Control Barrier Function (ICCBF). An ICCBF guarantees that an input constrained controller can render a subset of the safe set forward invariant. We present the construction of these functions, and define the subset of the safe set, and a corresponding controller, such that the subset is guaranteed to be forward invariant under this controller. Furthermore, we show that ICCBFs represent a generalization of Higher Order CBFs (HOCBFs)
[
9
]
, enabling synthesis of input-constrained controllers for safe sets of higher, and non-uniform relative degree. Finally, the method is applied to an adaptive cruise control problem
[
10
]
, and a spacecraft rendezvous problem, demonstrating that ICCBFs define a safe controller that respects input constraints.

The paper is structured as follows: In Section 2, some preliminaries on set invariance, as well as the problem statement are presented. Section 3 presents the definition of ICCBFs, and the synthesis of corresponding feedback controllers for ensuring safety. Finally, simulation results are presented in section 4.

\mathcal{S}
at

.

In this work, since

Lemma 2
.

Consider the system (
1
). Let the set
\mathcal{S}
be defined by a continuously differentiable function
h:\mathcal{X}\rightarrow\mathbb{R}
, as per (
2
-
4
). Consider a controller
u:\mathcal{S}\rightarrow\mathcal{U}
, such that for any initial condition

, the closed-loop system (
1
) admits a globally unique solution. Then set

is forward invariant if and only if

L_{f}h(x)+L_{g}h(x)u(x)\geq 0\text{$\forall x\in\partial\mathcal{S}$}.

(6)

If

is a Zeroing Control Barrier Function (ZCBF), a controller that renders

forward invariant is guaranteed to exist

2
,
1
]
. The focus of this paper is on scenarios where

III
Input Constrained Control Barrier Functions

In this section we define Input Constrained Control Barrier Functions (ICCBFs). A brief motivation for the construction is provided, followed by the formal definitions. Finally a method to find ICCBFs is proposed.

III-A

Motivation

Fig. 1:
Visual representation of ICCBF method. The safe set
\mathcal{S}
and two intermediate sets
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are drawn. The final inner safe set
\mathcal{C}^{*}
is the intersection of each of these sets, and can be rendered forward invariant.

Suppose the safe set
\mathcal{S}
associated with
h
cannot be rendered forward invariant by any controller
u\in\mathcal{U}
. Then we define a function
b_{1}:\mathcal{X}\rightarrow\mathbb{R}
and a set
\mathcal{C}_{1}
(visualised in Figure
1
) as follows

\displaystyle b_{1}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[\dot{h}(x,u)+\alpha_{0}(h(x))]

(7)

\displaystyle\mathcal{C}_{1}

\displaystyle=\{x\in\mathcal{X}:b_{1}(x)\geq 0\}

(8)

where
\alpha_{0}
is some user specified extended class-
\mathcal{K}
function and the shorthand
\dot{h}(x,u)=L_{f}h(x)+L_{g}h(x)u
is used. Notice that since an infimum over
\mathcal{U}
is taken,
b_{1}
is only dependent on the state
x
, and not the input
u
.

The set
\mathcal{C}_{1}
has a useful property: Suppose there exists a point
x\in\mathcal{X}
such that
x\in\partial\mathcal{S}
and
x\in\mathcal{C}_{1}
, i.e.,
h(x)=0
and
b_{1}(x)\geq 0
. Then, from (
7
) it follows,
\inf_{u\in\mathcal{U}}[\dot{h}]\geq 0
, and therefore
\dot{h}\geq 0

for any

u\in\mathcal{U}
, i.e.,

\displaystyle x\in\partial\mathcal{S}\cap\mathcal{C}_{1}\implies\dot{h}(x,u)\geq 0,\forall u\in\mathcal{U}.

(9)

Thus the closed-loop vector field
f(x)+g(x)u
lies in the tangent cone of
\mathcal{S}
at
x
, i.e., no closed-loop trajectory can leave
\mathcal{S}
through such an
x
.

Now suppose there exists a Lipschitz continuous controller
u\in\mathcal{U}
such that
\mathcal{C}_{1}
is forward invariant. Then the set
\mathcal{S}\cap\mathcal{C}_{1}
is also forward invariant: Consider an initial condition
x(0)\in\mathcal{S}\cap\mathcal{C}_{1}
. Suppose there exists a
t>0
where
h(x(t))<0
. By continuity, there must be some
\tau\in[0,t)
where
h(x(\tau))=0
and
\dot{h}(x(\tau),u)<0
. However, since the controller renders
\mathcal{C}_{1}
forward invariant, we have
x(\tau)\in\partial S
and
x(\tau)\in\mathcal{C}_{1}
. By (
9
),
\dot{h}(x(\tau),u)\geq 0
, which is a contradiction. Therefore, trajectories cannot reach a state
x\not\in\mathcal{S}
.

To summarise, in systems where
\mathcal{S}
cannot be rendered forward invariant, the subset set
{\mathcal{S}\cap\mathcal{C}_{1}}
is forward invariant under any controller that renders
\mathcal{C}_{1}
forward invariant.

In defining
b_{1}
, we allowed the user to specify the extended class-
\mathcal{K}
function
\alpha_{0}
. However not all class-
\mathcal{K}
functions will admit a controller that renders
\mathcal{C}_{1}
forward invariant. Either a different class-
\mathcal{K}
function could be used, or we can repeat the same steps: define
b_{2}(x)=\inf_{u\in\mathcal{U}}[\dot{b}_{1}(x,u)+\alpha_{1}(b_{1}(x))]
and
\mathcal{C}_{2}=\{x\in\mathcal{X}:b_{2}(x)\geq 0\}
. Now any controller
u
that renders
\mathcal{C}_{2}
forward invariant also renders
\mathcal{C}_{1}\cap\mathcal{C}_{2}
forward invariant, and therefore the set
\mathcal{S}\cap\mathcal{C}_{1}\cap\mathcal{C}_{2}
is also forward invariant by the same controller. This idea is formalised in the next subsection.

III-B

ICCBFs

Consider the dynamical system (
1
) with bounded control inputs
u\in\mathcal{U}
and a safe set
\mathcal{S}
defined by a function
h:\mathcal{X}\rightarrow\mathbb{R}
, as per (
2
-
4
). Assume
h
is not a ZCBF. We define the following sequence of functions:

\displaystyle b_{0}(x)

\displaystyle=h(x)

(10)

\displaystyle b_{1}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}b_{0}(x)+L_{g}b_{0}(x)u+\alpha_{0}(b_{0}(x))]

(11)

\displaystyle b_{2}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}b_{1}(x)+L_{g}b_{1}(x)u+\alpha_{1}(b_{1}(x))]

(12)

\displaystyle b_{i+1}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}b_{i}(x)+L_{g}b_{i}(x)u+\alpha_{i}(b_{i}(x))]

(13)

\displaystyle b_{N}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}b_{N-1}(x)+L_{g}b_{N-1}(x)u

\displaystyle{}\quad{}\quad{}\quad{}\quad+\alpha_{N-1}(b_{N-1}(x))]

(14)

where each
\alpha_{i}
is some user-specified class-
\mathcal{K}
function, and
N
is a positive integer. We assume the functions

are sufficiently smooth such that

and its derivative are defined. Each function
b_{i}:\mathcal{X}\rightarrow\mathbb{R}
is a scalar function that only depends on the state. The time derivative
\dot{b}_{i}=\frac{db_{i}}{dx}\dot{x}=L_{f}b_{i}(x)+L_{g}b_{i}(x)u
is still affine in
u
.

Remark 1
.

Higher Order CBFs, as in
[
9
]
, are a special case of ICCBFs. For instance, in systems of relative degree 2,
L_{g}h(x)=0
for all
x\in\mathcal{S}
. In this case, in the construction of ICCBFs we have

\displaystyle b_{1}(x)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}h(x)+L_{g}h(x)u+\alpha_{0}(h(x))]

(15)

\displaystyle=\inf_{u\in\mathcal{U}}[L_{f}h(x)+\alpha_{0}(h(x))]

(16)

\displaystyle=L_{f}h(x)+\alpha_{0}(h(x))

(17)

which is exactly the function defined in
[
9
]
. This repeats for any relative degree greater than 2, and thus for a system with relative degree
\rho
, the first
\rho
expressions of ICCBFs are identical to those of HOCBFs. Moreover, ICCBFs can handle systems with non-uniform relative degree, by choosing
N
greater or equal to the largest relative degree of the system in
\mathcal{S}
.

Next, we define a family of sets,

\displaystyle\mathcal{C}_{0}

\displaystyle=\{x\in\mathcal{X}:b_{0}(x)\geq 0\}=\mathcal{S}

(18)

\displaystyle\mathcal{C}_{1}

\displaystyle=\{x\in\mathcal{X}:b_{1}(x)\geq 0\}

(19)

\displaystyle\mathcal{C}_{i}

\displaystyle=\{x\in\mathcal{X}:b_{i}(x)\geq 0\}

(20)

\displaystyle\mathcal{C}_{N}

\displaystyle=\{x\in\mathcal{X}:b_{N}(x)\geq 0\}

(21)

and the intersection of these sets

\displaystyle\mathcal{C}^{*}=\mathcal{C}_{0}\cap\mathcal{C}_{1}\cap...\cap\mathcal{C}_{N}

(22)

We assume the set
\mathcal{C}^{*}
is closed, non-empty and has no isolated points.

Definition 3
.

For the above construction, if there exists a class-
\mathcal{K}
function
\alpha_{N}
such that

\displaystyle\sup_{u\in\mathcal{U}}[L_{f}b_{N}(x)+L_{g}b_{N}(x)u+\alpha_{N}(b_{N}(x))]\geq 0\quad\forall x\in\mathcal{C}^{*},

(23)

then
b_{N}
is an
Input Constrained Control Barrier Function (ICCBF)
.

Note, this does not require
b_{N}
to be a ZCBF on
\mathcal{C}_{N}
. The definition only requires condition (
23
) to hold for all
x\in\mathcal{C}^{*}
which is a subset of
\mathcal{C}_{N}
. The main result of this paper can now be stated:

Theorem 1

(Main Result)
.

Given the input constrained dynamical system (
1
), if
b_{N}
, defined by (
10
-
14
), is an ICCBF, then any Lipschitz continuous controller
u:\mathcal{C}^{*}\rightarrow\mathcal{U}
such that
u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)
, where

\displaystyle K_{\text{\scalebox{.6}{ICCBF}}}(x)

\displaystyle=\{u\in\mathcal{U}:

\displaystyle L_{f}b_{N}(x)+L_{g}b_{N}(x)u\geq-\alpha_{N}(b_{N}(x))\}

(24)

renders the set
\mathcal{C}^{*}\subseteq\mathcal{S}
(
22
) forward invariant.

Proof.

Since
u
is a Lipschitz continuous controller, the closed-loop system (
1
) is also Lipschitz continuous. To show forward invariance of
\mathcal{C}^{*}
, we use Nagumo’s theorem on the closed-loop system. In particular, we show

\displaystyle[f(x)+g(x)u(x)]\in\hat{T}_{\mathcal{C}^{*}}(x),

\displaystyle\quad\forall u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x),\text{ and }\forall x\in\partial\mathcal{C}^{*},

(25)

where
\hat{T}_{\mathcal{C}^{*}}(x)
is the tangent cone of
\mathcal{C}^{*}
at
x
. At each
x\in\partial\mathcal{C}^{*}
, we have
b_{i}(x)=0
for some set, possibly all, of
i
’s in
\{0,...,N\}
. Let
\mathcal{I}(x)=\{i:b_{i}(x)=0\}
. Condition (
25
) is satisfied if,
\dot{b}_{i}(x,u(x))\geq 0
, for all
i\in\mathcal{I}(x)
, for all
x\in\mathcal{C}^{*}
, provided
u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)
. In other words, we show that for all
x\in\mathcal{C}^{*}
,

\displaystyle b_{i}(x)=0\implies\dot{b}_{i}(x,u(x))\geq 0,\forall u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)

(26)

for all
i\in\{0,...,N\}
.

Cases
i\in\{0,...,N-1\}
: Consider any
x\in\mathcal{C}^{*}\cap\partial\mathcal{C}_{i}
. Since
\mathcal{C}^{*}\subseteq\mathcal{C}_{i+1}
,
x\in\partial\mathcal{C}_{i}\cap\mathcal{C}_{i+1}
.
By (

20
),

\displaystyle\inf_{u\in\mathcal{U}}[L_{f}b_{i}(x)+L_{g}b_{i}(x)]

\displaystyle\geq 0

\displaystyle\therefore L_{f}b_{i}(x)+L_{g}b_{i}(x)

\displaystyle\geq 0,\quad\forall u\in\mathcal{U}

and therefore
\dot{b}_{i}(x,u)\geq 0
, for all
u\in\mathcal{U}
. Since
K_{\text{\scalebox{.6}{ICCBF}}}(x)\subseteq\mathcal{U}
, condition (

) is satisfied.

Case
i=N
: Consider
x\in\mathcal{C}^{*}\cap\partial\mathcal{C}_{N}
. Since
b_{N}
is an ICCBF and
b_{N}(x)=0
, by (

,
24
),

\displaystyle L_{f}b_{N}(x)+L_{g}b_{N}(x)u(x)\geq 0,\quad\forall u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)

and therefore
\dot{b}_{N}(x,u)\geq 0
for any
u(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)
.

In conclusion, we have shown that condition (
26
) is satisfied for all

, and therefore the conditions of Nagumo’s theorem are satisfied, which completes the proof.∎

Remark 2
.

The practical value of this construction is that for a given system, a set
\mathcal{S}
of safe states of practical importance can be specified, which may not be rendered forward invariant under the given system dynamics. By using ICCBFs, we remove states of the set
\mathcal{S}
, and construct an inner set for which we can find a controller that renders it forward invariant.

We would like to note a useful special case, the
simple ICCBF
:

Definition 4
.

In the above construction, if
\mathcal{C}^{*}
is a strict subset of
\mathcal{C}_{N}
, i.e.,
\mathcal{C}^{*}\subset\mathcal{C}_{N}
, then

is a

.

Theorem 2
.

For the dynamical system (
1
), if

is a simple ICCBF, all Lipschitz continuous controllers

render the set

Proof.

By definition, since
b_{N}
is a simple ICCBF,
\mathcal{C}^{*}
is a strict subset of
\mathcal{C}_{N}
. Then
\mathcal{C}^{*}\cap\partial\mathcal{C}_{N}=\emptyset
, i.e., there does not exist a

such that
b_{N}(x)=0
. Following Theorem
1
, we do not need to consider case where

in condition (

). The remaining cases, with

satisfy condition (

Remark 3
.

Intuitively, the existence of a simple ICCBF represents a system where the dynamics at the boundaries of
\mathcal{C}^{*}
are such that the unforced dynamics

dominate the forcing term

in driving the system towards safety. If a simple ICCBF is found, no safety critical controller is needed for the system to ensure state trajectories remain within the safe set, provided the system is initialised within
\mathcal{C}^{*}
.

QP-based Control Synthesis

Finally, similar to
[
2
,
3
]
, we define an optimization-based controller that will render

forward invariant. In this section, suppose the set
\mathcal{U}
can be expressed as a convex polytope, i.e.,
\mathcal{U}=\{u\in\mathbb{R}^{m}:Au\leq B\}
where
A\in\mathbb{R}^{p\times m}
and

. Then the a controller based on the solution to the following Quadratic Program (QP) renders the set
\mathcal{C}^{*}
forward invariant.

Theorem 3
.

Consider the dynamical system (
1
). Suppose

is an ICCBF associated with the class-
\mathcal{K}
function
\alpha_{N}
and inner safe set
\mathcal{C}^{*}
. Let

, where
\mathbb{R}^{m\times m}_{+}
is the set of real

positive definite matrices, and

be Lipschitz continuous cost functions. The solution to the following quadratic optimization problem

\displaystyle\begin{array}[]{rl}u^{*}(x)=\underset{u\in\mathbb{R}^{m}}{\operatorname*{argmin}}&\frac{1}{2}u^{T}H(x)u+F(x)^{T}u\\
\text{subject to}&L_{f}b_{N}(x)+L_{g}b_{N}(x)u\geq-\alpha_{N}(b_{N}(x))\\
&u\in\mathcal{U}\end{array}

yields an input-constrained feedback controller
u^{*}:\mathcal{C}^{*}\rightarrow\mathcal{U}
that renders
\mathcal{C}^{*}
forward invariant. Thus,
h(x(t))\geq 0
for all
t\geq t_{0}
, i.e. the system trajectories always evolve within the safe set
\mathcal{S}
.

Proof.

The constraints in (
3
) specify that
u^{*}(x)\in K_{\text{\scalebox{.6}{ICCBF}}}(x)
. Since the
u^{*}(x)
is a Lipschitz continuous controller, (following the same arguments as
[
12
, Thm. 8]
), by Theorem
1
, the controller
u^{*}(x)
obtained as the solution to the optimization problem (
3
) renders
\mathcal{C}^{*}
forward invariant.
∎

V
Conclusion

In this paper, we have presented a framework that allows input constraints to be explicitly included in the construction of control barrier functions and to guarantee that safety is maintained with an input-constrained controller. The construction identifies an inner safe set and a feedback controller to render the subset safe. The method was demonstrated in two cases, an adaptive cruise control problem and a spacecraft rendezvous control problem. An optimization based method was used to verify the conditions of the ICCBF. Directions for future work include investigating numerically efficient methods to automate the search of ICCBFs, and to compare the complexity with other reachability methods, in particular for systems with high-dimensional states. Finally, the robustness of this controller to noise and model mismatch could also be investigated.
