Research of the hereditary dynamic Riccati system with modification fractional differential operator of Gerasimov-Caputo
Tverdyi D.A, Parovik R.I

Abstract
In this paper, we study the Cauchy problem for the Riccati differential equation with constant coefficients and a modified Gerasimov-Caputo type fractional differential operator of variable order. Using Newton’s numerical algorithm, calculation curves are constructed taking into account different values of the Cauchy problem parameters. The calculation results are compared with the previously obtained results. The computational accuracy of the numerical algorithm is investigated. It is shown using the Runge rule that the computational accuracy tends to the accuracy of the numerical method when increasing the nodes of the calculated grid.

II
Some basic definitions

Here we will consider the main definitions from the theory of fractional calculus, and its aspects can be studied in more detail in books
Kilbas, Srivastava, and Trujillo 2006
;
Oldham and Spanier 1974
;
Miller and Ross 1993
.

Definition 1:
The Gerasimov-Caputo fractional derivative of variable order
\alpha(t)
has the form:

\displaystyle\partial^{\alpha(t)}_{0t}u(\tau)=\left\{\begin{array}[]{ll}\frac{1}{\Gamma(m-\alpha(t))}\int_{0}^{t}\frac{x^{(m)}(\tau)d\tau}{(t-\tau)^{\alpha(t)+1-m}},\qquad 0\leq m-1<\alpha(t)<m\\
\frac{d^{m}x(t)}{dt^{m}},\qquad m\in N.\end{array}\right.

where
\Gamma(z)=\int_{0}^{\infty}t^{z-1}\exp^{-t}dt,Re(z)>0
– Euler’s gamma function.

Definition 2:
Modified Gerasimov-Caputo fractional derivative of variable order
\gamma(t-\tau)
has the form:

\displaystyle\partial^{\gamma(t-\tau)}_{0t}u(\tau)=\left\{\begin{array}[]{ll}\frac{1}{\Gamma(m-\gamma(t-\tau))}\int_{0}^{t}\frac{x^{(m)}(\tau)d\tau}{(t-\tau)^{\gamma(t-\tau)+1-m}},\qquad 0\leq m-1<\gamma(t-\tau)<m\\
\frac{d^{m}x(t)}{dt^{m}},\qquad m\in N.\end{array}\right.

Derivatives of fractional variables of orders (1) and (2) are given in
Lorenzo and Hartley 2002
, and some of their properties are considered there.

Note 1:
Note that if the orders of fractional derivatives in (
II
) and (
II
) are constants, then they coincide and the operators are Gerasimov-Caputo derivatives of constant orders
Gerasimov 1948
;
Caputo 1969
.

III
Task definition

Consider the following hereditary equation that is the analogue of the equation of Rikkati:

\displaystyle\int_{0}^{t}K(t-\tau)\dot{u}(\tau)d\tau+a(t)u^{2}(t)+b(t)u(t)+c(t)=0

(7)

where
u(t)\in C[0,T]
– function of a solution,
K(t-\tau)
– memory function,
t\in[0,T]
– current time,
T>0
– simulation time,
a(t),b(t),c(t)
– coefficients set by the function.

Note 2:
Note that if the memory function
K(t-\tau)
is a Heaviside function, then the process has full memory; if it is a Dirac function, then there is no memory.

We will consider an intermediate case when the system gradually “forgets” its background over time. To do this, select the memory function as follows:

\displaystyle K(t-\tau)=\frac{(t-\tau)^{-\alpha(t)}}{\Gamma(1-\alpha(t))},\qquad 0<\alpha(t)<1

(8)

where
\alpha(t)
– a function that is responsible for the intensity of the process under study, then taking into account the Definition of 1 for
m=1
, we come to the following fractional Riccati equation of variable order:

\displaystyle\partial^{\alpha(t)}_{0t}u(\tau)+a(t)u^{2}(t)+b(t)u(t)+c(t)=0

(9)

for which the initial local condition is valid:

\displaystyle u(0)=u_{0},

(10)

Equation (
9
) and initial condition (
10
) form the Cauchy problem for the fractional Riccati equation of variable order. It was studied by the authors in
Tverdyi 2017
.

Let us introduce into consideration a different function of memory:

\displaystyle K(t-\tau)=\frac{(t-\tau)^{-\gamma(t-\tau)}}{\Gamma(1-\gamma(t-\tau))},\qquad 0<\gamma(t-\tau)<1

(11)

Here, the order of the
\gamma(t-\tau)
function with a lagging argument also determines the intensity of the process under consideration.

Taking into account (
11
) and Definition 2 for
m=1
, the fractional Riccati equation takes the form:

\displaystyle\partial^{\gamma(t-\tau)}_{0t}u(\tau)+a(t)u^{2}(t)+b(t)u(t)+c(t)=0

(12)

In the future, we will investigate the Cauchy problem (
12
), (
10
).

IV
The method of solving

Since the Cauchy problem (
12
) and (
10
) in General does not have an exact solution, we will use numerical methods to solve it. To do this, we divide the time interval
[0,T]
into
N
equal parts (grid nodes), where
h=\frac{T}{N}
is the sampling step
t_{n}=nh,n=0,\dots,N-1
, and the solution function
u(t_{n})=u_{n}
.

The approximation of the fractional derivative in equation (8) will take the form:

\displaystyle\partial^{\gamma(t-\tau)}_{0t}\approx\sum\limits_{i=1}^{k}\omega_{i,\gamma}\left(u_{k-i+1}-u_{k-i}\right),\qquad k=1,\dots,N

(13)

where,
\omega_{i,\gamma}
weight coefficients of the quadrature formula of trapezes.

Note that the method of approximating the Cauchy problem (
9
), (
10
) is based on the results of
Parovik 2014
.

Based on (
13
), the Cauchy problem (
12
) and (
10
) can be rewritten in the difference statement:

\displaystyle\sum\limits_{i=1}^{k}\omega_{i,\gamma}\left(u_{k-i+1}-u_{k-i}\right)+a_{k}u_{k}^{2}+b_{k}u_{k}+c_{k}=0,\qquad k=1,\dots,N

(14)

For the solution, the iterative Newton-Raphson method was used, which, as a rule, provides fast convergence.
The algorithm consists of the following steps:

1.

Define a function for forming a Jacobian:

\displaystyle f_{k}=\sum\limits_{i=1}^{k}\omega_{i,\gamma}\left(u_{k-i+1}-u_{k-i}\right)+a_{k}u^{2}_{k}+b_{k}u_{k}+c_{k},\qquad k=1,\dots,N

2.

Define the elements of the Jacobian:

\displaystyle R_{n,m}=\frac{df_{n}}{du_{m}},\qquad n=1,\dots,N,m=1,\dots,N

3.

Let’s write a matrix iterative equation of the form:

\displaystyle U_{m+1}=U_{m}-\frac{1}{J(U_{m})}F(U_{m})

(15)

where

\displaystyle U_{m}=\left(\begin{array}[]{c}u_{1}\\
u_{2}\\
\vdots\\
u_{N}\end{array}\right),F(U_{m})=\left(\begin{array}[]{c}f_{1}\\
f_{2}\\
\vdots\\
f_{N}\end{array}\right),J(U_{m})=\left(\begin{array}[]{cccc}R_{1,1}&R_{1,2}&\ldots&R_{1,N}\\
R_{2,1}&\ldots&\ldots&R_{2,N}\\
\vdots&\vdots&R_{3,3}&\vdots\\
R_{N,1}&\ldots&\ldots&R_{N,N}\end{array}\right)

4.

We start the iterative process until
r>\epsilon
, where
\epsilon=10^{-4}
– accuracy,
r=10^{3}\epsilon
– stop criterion, and
\|J(U_{m})\|\neq 0
– convergence criterion of the method, where
r=\|U_{m+1}-U_{m}\|\leq\epsilon
– stability criterion.

Note 3:
It should be noted that the main difficulty in applying this method is to find the inverse Jacobi matrix in (
15
). To solve this problem, we can use the Gauss – Jordan method
Lipschutz and Lipson 2009
.

VII
Conclusion

The Cauchy problem for the fractional Riccati equation (
12
), (
10
) with variable coefficients was considered. The proposed Cauchy problem is numerically analyzed using the Newton-Raphson method. The computational accuracy of the Runge rule for the applied numerical method is estimated. It is shown that the computational accuracy tends to the accuracy of the method as the number of calculated nodes increases. Next, we compared the solution of the Cauchy problem (
9
), (
10
) with the Cauchy problem (
12
), (
10
), which differ from each other, but maintain a common trend. This fact suggests that the Cauchy problem (
12
), (
10
) takes place and its solution can be used in the study of processes with saturation and memory effects, for example, in forecasting economic cycles and crises
Makarov and I.Parovik 2016
.
