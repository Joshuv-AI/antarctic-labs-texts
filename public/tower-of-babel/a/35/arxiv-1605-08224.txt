Chebyshev polynomial coefficient bounds for a subclass of bi-univalent functions
Şahsene Altınkaya, Sibel Yalçın

Abstract
In this work, considering a general subclass of bi-univalent functions and using the Chebyshev polynomials, we obtain coefficient expansions for functions in this class. Keywords: Chebyshev polynomials; bi-univalent functions; coefficient bounds; subordination. Mathematics Subject Classification, 2010: 30C45, 30C50.

Introduction and Definitions

Let
D
be the unit disk
\left\{z:z\in\mathbb{C}\text{ and }\left|z\right|<1\right\}\ ,

A
be the class of
functions analytic in
D,
satisfying the conditions

f(0)=0\text{ and}\ \ \ f^{\prime}(0)=1.

Then each function
f
in
A
has the Taylor expansion

f(z)=z+\overset{\infty}{\underset{n=2}{\sum}}a_{n}z^{n}.

(1)

Further, by
S
we shall denote the class of all functions in
A
which are
univalent in
D.

The Koebe one-quarter theorem
[
5
]
ensures that the image of
D

under every function
f
from
S
contains a disk of radius
\frac{1}{4}.

Thus every such univalent function has an inverse
f^{-1}
which satisfies

f^{-1}\left(f\left(z\right)\right)=z~,~\left(z\in D\right)

and

f\left(f^{-1}\left(w\right)\right)=w~,~\left(\left|w\right|<r_{0}\left(f\right)~,~r_{0}\left(f\right)\geq\frac{1}{4}\right),

where

f^{-1}\left(w\right)=w~-a_{2}w^{2}+\left(2a_{2}^{2}-a_{3}\right)w^{3}-\left(5a_{2}^{3}-5a_{2}a_{3}+a_{4}\right)w^{4}+\cdots.

A function
f\in A
is said to be bi-univalent in
D
if both
f
and
f^{-1}
are univalent in
D.
Let
\Sigma
represent the class of
bi-univalent functions in
D
given by (
1
). For some intriguing
examples of functions and characterization of the class
\Sigma,
one could
refer Srivastava et al.
[
14
]
, and the references stated
therein (see also,
[
12
]
). Recently there has been triggering ,

(see
[

,

]
,
[
9
]
,
[
10
]
,
[
13
]
) and obtain
non-sharp estimates on the first two Taylor-Maclaurin coefficients
|a_{2}|

and
|a_{3}|
. Not much is known about the bounds on the general coefficient
\ \left|a_{n}\right|
for
n\geq 4.
In the literature, there are
only a few works determining the general coefficient bounds
\left|a_{n}\right|
for the analytic bi-univalent functions (
[

\left|a_{n}\right|

\left(\ n\in\mathbb{N}\backslash\left\{1,2\right\};\ \ \mathbb{N}=\left\{1,2,3,...\right\}\right)

Chebyshev polynomials have become increasingly important in numerical
analysis, from both theoretical and practical points of view. There are four
kinds of Chebyshev polynomials. The majority of books and research papers
dealing with specific orthogonal polynomials of Chebyshev family, contain
mainly results of Chebyshev polynomials of first and second kinds
T_{n}(t)

and
U_{n}(t)
and their numerous uses in different applications, see for
example, Doha
[
6
]
and Mason
[
11
]
.

The Chebyshev polynomials of the first and second kinds are well known. In
the case of a real variable
x
on
\left(-1,1\right)
, they are defined by

T_{n}(t)=\cos n\theta,

U_{n}(t)=\frac{\sin(n+1)\theta}{\sin\theta},

where the subscript
n
denotes the polynomial degree and where
t=\cos\theta
.

If the functions
f
and
g
are analytic in
D,
then
f
is said to be
subordinate to
g,
written as

f\left(z\right)\prec g\left(z\right),\ \ \ \ \ \ \ \ \ \ \left(z\in D\right)

if there exists a Schwarz function
w\left(z\right),
analytic in
D,
with

w\left(0\right)=0~\ \text{and\ \ \ \ \ }\left|w\left(z\right)\right|<1\ \ \ \ \ \ \ \ \ \ \left(z\in D\right)

such that

f\left(z\right)=g\left(w\left(z\right)\right)\ \ \ \ \ \ \ \ \ \ \ \ \left(z\in D\right).

Definition 1

A function
f\in\Sigma
is said to be in the class
H_{\Sigma}\left(\lambda,t\right),

\lambda\geq 0\
and
t\in\left(\frac{\sqrt{2}}{2},1\right],
if the following subordination hold

\left(1-\lambda\right)\dfrac{zf^{\prime}\left(z\right)}{f\left(z\right)}+\lambda\left(1+\dfrac{zf^{\prime\prime}\left(z\right)}{f^{\prime}\left(z\right)}\right)\prec H(z,t)=\frac{1}{1-2tz+z^{2}}\ \ \ \ \ \ (z\in D)

(2)

and

\left(1-\lambda\right)\dfrac{wg^{\prime}\left(w\right)}{g\left(w\right)}+\lambda\left(1+\dfrac{wg^{\prime\prime}\left(w\right)}{g^{\prime}\left(w\right)}\right)\prec H(w,t)=\frac{1}{1-2tw+w^{2}}\ \ \ \ \ \ (w\in D)

(3)

where
g\left(w\right)=f^{-1}\left(w\right).

We note that if
t=\cos\alpha,\ \alpha\in\left(-\frac{\pi}{3},\frac{\pi}{3}\right),
then

\begin{array}[]{ll}H(z,t)&=\dfrac{1}{1-2tz+z^{2}}\\
&\\
&=1+\overset{\infty}{\underset{n=1}{\sum}}\dfrac{\sin(n+1)\alpha}{\sin\alpha}z^{n}\ \ \ (z\in D).\end{array}

Thus

H(z,t)=1+2\cos\alpha z+(3\cos^{2}\alpha-\sin^{2}\alpha)z^{2}+\cdots\ \ \ (z\in D).

Following see, we write

H(z,t)=1+U_{1}(t)z+U_{2}(t)z^{2}+\cdots\ \ \ (z\in D,\ \ t\in\left(-1,1\right)),

where
U_{n-1}=\dfrac{\sin(n\arccos t)}{\sqrt{1-t^{2}}}\ \ (n\in\mathbb{N})
are the Chebyshev polynomials of the second kind. Also it is known that

U_{n}(t)=2tU_{n-1}(t)-U_{n-2}(t),

and

\begin{array}[]{l}U_{1}(t)=2t,\\
\\
U_{2}(t)=4t^{2}-1,\\
\\
U_{3}(t)=8t^{3}-4t,\\
\vdots\end{array}

(4)

The Chebyshev polynomials
T_{n}(t),\ t\in[-1,1],\
of the first
kind have the generating function of the form

\overset{\infty}{\underset{n=0}{\sum}}T_{n}(t)z^{n}=\dfrac{1-tz}{1-2tz+z^{2}}\ \ \ (z\in D).

However, the Chebyshev polynomials of the first kind
T_{n}(t)
and the
second kind
U_{n}(t)
are well connected by the following relationships

\begin{array}[]{l}\dfrac{dT_{n}(t)}{dt}=nU_{n-1}(t),\\
\\
T_{n}(t)=U_{n}(t)-tU_{n-1}(t),\\
\\
2T_{n}(t)=U_{n}(t)-U_{n-2}(t).\end{array}

In this paper, motivated by the earlier work of Dziok et al.
[
4
]
, we use the Chebyshev polynomial expansions to provide estimates for
the initial coefficients of bi-univalent functions in
H_{\Sigma}\left(\lambda,t\right)
. We also solve Fekete-Szegö problem for functions in
this class.

Coefficient bounds for the function class
H_{\Sigma}\left(\lambda,t\right)

Theorem 2

Let  the function
f\left(z\right)
given by (
1

H_{\Sigma}\left(\lambda,t\right).

\left|a_{2}\right|\leq\frac{2t\sqrt{2t}}{\sqrt{\left|\left(1+\lambda\right)^{2}-4\left(\lambda+\lambda^{2}\right)t^{2}\right|}}

\left|a_{3}\right|\leq\frac{4t^{2}}{\left(1+\lambda\right)^{2}}+\frac{t}{1+2\lambda}.

Proof.
Let

2

(5)

and

\left(1-\lambda\right)\dfrac{wg^{\prime}\left(w\right)}{g\left(w\right)}+\lambda\left(1+\dfrac{wg^{\prime\prime}\left(w\right)}{g^{\prime}\left(w\right)}\right)=1+U_{1}(t)v(w)+U_{2}(t)v^{2}(w)+\cdots,

(6)

for some analytic functions
w,v\

w(0)=v(0)=0

\left|w(z)\right|<1,\left|v(w)\right|<1

From the

\left(1-\lambda\right)\dfrac{zf^{\prime}\left(z\right)}{f\left(z\right)}+\lambda\left(1+\dfrac{zf^{\prime\prime}\left(z\right)}{f^{\prime}\left(z\right)}\right)=1+U_{1}(t)c_{1}z+\left[U_{1}(t)c_{2}+U_{2}(t)c_{1}^{2}\right]z^{2}+\cdots,

(7)

and

\left(1-\lambda\right)\dfrac{wg^{\prime}\left(w\right)}{g\left(w\right)}+\lambda\left(1+\dfrac{wg^{\prime\prime}\left(w\right)}{g^{\prime}\left(w\right)}\right)=1+U_{1}(t)d_{1}w+\left[U_{1}(t)d_{2}+U_{2}(t)d_{1}^{2}\right]w^{2}+\cdots.

(8)

It is fairly well-known that if

(10)

(11)

(12)

From (

(13)

(14)

By adding (

Theorem 3

Let
\ f

H_{\Sigma}\left(\lambda,t\right)\

\left|a_{3}-\mu a_{2}^{2}\right|\leq\left\{\begin{array}[]{l}\dfrac{t}{1+2\lambda};\\
