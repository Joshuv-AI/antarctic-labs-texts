Abstract
In this paper, we study the quasi-two-body decays B → P ​ f 0 ​ ( 500 ) → P ​ π + ​ π − B\to Pf_{0}(500)\to P\pi^{+}\pi^{-} [with P = ( π , K , η , η ′ ) P=(\pi,K,\eta,\eta^{\prime}) ] within framework of perturbative QCD (PQCD) factorization approach. With the help of π \pi - π \pi distribution amplitude and scalar form factor F π ​ π ​ ( ω 2 ) F_{\pi\pi}(\omega^{2}) , we calculate the C ​ P CP averaged branching fraction and the C ​ P CP asymmetry for the quasi-two-body decays B → P ​ f 0 ​ ( 500 ) → P ​ π + ​ π − B\to Pf_{0}(500)\to P\pi^{+}\pi^{-} . Taking the quasi-two-body decay B + → π + ​ f 0 ​ ( 500 ) → π + ​ π + ​ π − B^{+}\to\pi^{+}f_{0}(500)\to\pi^{+}\pi^{+}\pi^{-} as an explicit example, we present the behavior of differential branching fraction and direct C ​ P CP violation versus the π \pi - π \pi invariant mass. The total branching fraction and direct C ​ P CP violation are ℬ ( B + → π + [ σ → ] π + π − ) = ( 1.78 ± 0.41 ± 0.51 ) × 10 − 6 \mathcal{B}(B^{+}\to\pi^{+}[\sigma\to]\pi^{+}\pi^{-})=(1.78\pm 0.41\pm 0.51)\times 10^{-6} and 𝒜 C ​ P ( B + → π + [ σ → ] π + π − ) = ( 29.8 ± 11.1 ± 13.0 ) % \mathcal{A}_{CP}(B^{+}\to\pi^{+}[\sigma\to]\pi^{+}\pi^{-})=(29.8\pm 11.1\pm 13.0)\% respectively. Our results could be tested by further experiments.

Compared with vector and tensor mesons, the identification of the scalar mesons is long-standing puzzle

Pelaez 2016
