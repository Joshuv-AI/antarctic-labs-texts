The [ 1 , 0 ] [1,0] -twisted generalized Reed-Solomon code
Canze Zhu 1, Qunying Liao 2

Abstract




Abstract.

In this paper, we not only give the parity check matrix of the
[1,0]
-twisted generalized Reed-Solomon (in short, TGRS) code, but also determine the weight distribution. Especially, we show that the
[1,0]
-TGRS code is not GRS or EGRS. Furthermore, we present a sufficient and necessary condition for any punctured code of the
[1,0]
-TGRS code to be self-orthogonal, and then construct several classes of self-dual or almost self-dual
[1,0]
-TGRS codes. Finally, basing on these self-dual or almost self-dual
[1,0]
-TGRS codes, we obtain some LCD
[1,0]
-TGRS codes.

Keywords.

[1,0]
-twisted generalized Reed-Solomon codes; MDS codes; NMDS codes; Self-dual codes; Almost self-dual codes; LCD codes.

An
[n,k,d]

\mathcal{C}

\mathbb{F}_{q}

\mathbb{F}_{q}^{n}

\mathcal{C}
is maximum distance separable (in short, MDS). For the near-optimal case, namely,
d=n-k
,

\mathcal{C}
is almost MDS (in short, AMDS).
\mathcal{C}
is said to be near MDS (in short, NMDS) if both
\mathcal{C}
and
\mathcal{C}^{\perp}
are AMDS. Since MDS codes and NMDS codes are very important in coding theory and applications
[
7
,
19
,
29
,
34
,

]
, the study of MDS codes or near MDS codes, including weight distributions, constructions, equivalence, self-dual properties, linear complementary dual (in short, LCD) properties, and so on, has attracted a lot of attention
[

,

,

,

,

,

,

,
23
,
31
,

,

]
. Especially, generalized Reed-Solomon (in short, GRS) codes are a class of MDS codes. A lot of self-dual, almost self-dual or LCD MDS codes are constructed based on GRS codes
[

,

,

,

,

,

,

.

In 2017, inspired by the construction for twisted Gabidulin codes
[
30
]
, Beelen et al. firstly introduced twisted Reed-Solomon (in short, TRS) codes, which is a generalization for Reed-Solomon codes, they also showed that TRS codes could be well decoded. Different from GRS codes, they showed that a twisted generalized Reed-Solomon (in short, TGRS) code is not necessarily MDS and presented a sufficient and necessary condition for a TGRS code to be MDS
[

In this paper, we focus on the
[1,0]
-twisted generalized Reed Solomon (in short, TGRS) code. This paper is organized as follows. In section 2, some basic notations and results about linear codes are given. In section 3, the parity check matrix and the weight distribution of the
[1,0]
-TGRS code are obtained, and then we show that the
[1,0]
-TGRS code is not GRS or EGRS. In section 4, a sufficient and necessary condition for any punctured code of the
[1,0]

[1,0]
-TGRS codes are constructed. In section 5, we conclude the whole paper.

2.1
GRS, EGRS and
[1,0]
-TGRS codes

2.1.1
GRS and EGRS codes

The definitions of the GRS code and the EGRS code are given in the following, respectively.

Definition 2.1
(
[
19
]
)

Let
\bm{\alpha}=(\alpha_{1},\ldots,\alpha_{n})\in\mathbb{F}_{q}^{n}
with
\alpha_{i}\neq\alpha_{j}

(i\neq j)
and

\bm{v}=(v_{1},\ldots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}
. Then
the GRS code is defined as

\displaystyle\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{v})=\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}))~|~f(x)\in\mathbb{F}_{q}[x],~\deg f(x)\leq k-1\}.

The EGRS code is defined as

\displaystyle\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{v},\infty)=\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}),f_{k-1})~|~f(x)\in\mathbb{F}_{q}[x],~\deg f(x)\leq k-1\},

where
f_{k-1}
is the coefficient of
x^{k-1}
in
f(x)
.

Especially,
\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{1})
and
\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{1},\infty)
are called RS code and ERS code, respectively.

The dual codes of the GRS code and the EGRS code are given in the following, respectively.

Lemma 2.1
(
[
21
]
)

Let
\bm{u}=(u_{1},\ldots,u_{n})
with
u_{j}=-\prod\limits_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})^{-1}
, then

\big(\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{1})\big)^{\perp}=\mathcal{GRS}_{n-k,n}(\bm{\alpha},\bm{u})

and

\big(\mathcal{GRS}_{k,n}(\bm{\alpha},\bm{1},\infty)\big)^{\perp}=\mathcal{GRS}_{n+1-k,n}(\bm{\alpha},\bm{u},\infty).

2.1.2
[1,0]
-TGRS codes

Definition 2.2
(
[
2
]
)

Let
t
,
h
and
k
be positive integers with

. For
\eta\in\mathbb{F}_{q}^{*}
, the set of
(k,t,h,\eta)
-twisted polynomials is defined as

\displaystyle\mathcal{V}_{k,t,h,\eta}=\Big\{f(x)=\sum\limits_{i=0}^{k-1}a_{i}x^{i}+\eta a_{h}x^{k-1+t}~|~a_{i}\in\mathbb{F}_{q}~(i=0,\ldots,k-1)\Big\},

which is a
k
-dimensional
\mathbb{F}_{q}
-linear subspace.

From the twisted polynomials linear space
\mathcal{V}_{k,1,0,\eta}
, the definition of the
[1,0]
-TGRS code is given as follows.

Definition 2.3
(
[
2
]
)

Let
\eta\in\mathbb{F}_{q}^{*}
,
\bm{\alpha}=(\alpha_{1},\ldots,\alpha_{n})\in\mathbb{F}_{q}^{n}
with
\alpha_{i}\neq\alpha_{j}

(i\neq j)

\bm{v}=(v_{1},\ldots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}

\displaystyle\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)=\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}))~|~f(x)\in\mathcal{V}_{k,1,0,\eta}\}.

Especially,
\mathcal{C}_{k,n}(\bm{\alpha},\bm{1},\eta)
is called the
[1,0]
-TRS code.

By Definition
2.2
, it is easy to see that the generator matrix of
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
is

\displaystyle G_{k}=\left(\begin{matrix}&v_{1}(1+\eta\alpha_{1}^{k})~&v_{2}(1+\eta\alpha_{2}^{k})~&\ldots~&v_{n}(1+\eta\alpha_{n}^{k})~\\
&v_{1}\alpha_{1}~&v_{2}\alpha_{2}~&\ldots~&v_{n}\alpha_{n}~\\
&\vdots~&\vdots&~&\vdots~\\
&v_{1}\alpha_{1}^{k-2}~&v_{2}\alpha_{2}^{k-2}~&\cdots~&v_{n}\alpha_{n}^{k-2}~\\
&v_{1}\alpha_{1}^{k-1}~&v_{2}\alpha_{2}^{k-1}~&\ldots~&v_{n}\alpha_{n}^{k-1}~\\
\end{matrix}\right).

(2.1)

For
P_{\bm{\alpha}}\neq 0
, Huang et al. gave a parity check matrix for
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
as follows.

Lemma 2.2
(Theorem
1

[
18
]
)

Let
a=\prod\limits_{i=1}^{n}\alpha_{i}\neq 0
and
u_{j}=\prod\limits_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})^{-1}
for any
j=1,\ldots,n
, then
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
has the parity check matrix

\displaystyle H^{*}_{n-k}=\left(\begin{matrix}&\frac{u_{1}}{v_{1}}~&\frac{u_{2}}{v_{2}}~&\ldots~&\frac{u_{n}}{v_{n}}~\\
&\frac{u_{1}}{v_{1}}\alpha_{1}~&\frac{u_{2}}{v_{2}}\alpha_{2}~&\ldots~&\frac{u_{n}}{v_{n}}\alpha_{n}~\\
&\vdots~&\vdots&~&\vdots~\\
&\frac{u_{1}}{v_{1}}\big(\alpha_{1}^{n-k-1}-\eta\frac{a}{\alpha_{1}}\big)~&\frac{u_{2}}{v_{2}}\big(\alpha_{2}^{n-k-1}-\eta\frac{a}{\alpha_{2}}\big)~&\cdots~&\frac{u_{n}}{v_{n}}\big(\alpha_{n}^{n-k-1}-\eta\frac{a}{\alpha_{n}}\big)~\\
\end{matrix}\right).

The following lemma shows that
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

Lemma 2.3
(Lemma
1

[
18
]
)

Let

\displaystyle S_{k}(\bm{\alpha})=\Big\{(-1)^{k}\prod\limits_{i\in I}^{n}\alpha_{i}~|~I\subsetneq\{1,\ldots,n\},~|I|=k\Big\},

(2.2)

then the following two assertions hold.

(1)

\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

(2)

In Theorem

2.2
Some notations for linear codes

2.2.1
The Schur product

The Schur product is defined as follows.

Definition 2.4

For
\mathbf{x}=(x_{1},\ldots,x_{n}),\mathbf{y}=(y_{1},\dots,y_{n})\in\mathbb{F}_{q}^{n}
, the Schur product between
\mathbf{x}
and
\mathbf{y}
is
defined as

\mathbf{x}\star\mathbf{y}:=(x_{1}y_{1},\ldots,x_{n}y_{n}).

The Schur product of two
q
-ary codes
\mathcal{C}_{1}
and
\mathcal{C}_{2}
with length
n
is
defined as

\displaystyle\mathcal{C}_{1}\star\mathcal{C}_{2}=\langle\mathbf{c}_{1}\star\mathbf{c}_{2}~|~\mathbf{c}_{1}\in\mathcal{C}_{1},\mathbf{c}_{2}\in\mathcal{C}_{2}\rangle.

Especially, for a code
\mathcal{C}
, we call
\mathcal{C}^{2}:=\mathcal{C}\star\mathcal{C}
the Schur square of
\mathcal{C}
.

Remark 2.2

For any linear codes
\mathcal{C}_{1}
and
\mathcal{C}_{2}
, if

\mathcal{C}_{1}=\langle\bm{v}_{1},\ldots,\bm{v}_{k_{1}}\rangle
and
\mathcal{C}_{2}=\langle\bm{w}_{1},\ldots,\bm{w}_{k_{2}}\rangle
with
\bm{v}_{i},\bm{w}_{j}\in\mathbb{F}_{q}^{n}~(i=1,\ldots,k_{1},~j=1,\ldots,k_{2})
, then

\displaystyle\mathcal{C}_{1}\star\mathcal{C}_{2}=\langle\bm{v}_{i}\star\bm{w}_{j}~(i=1,\ldots,k_{1},~j=1,\ldots,k_{2})\rangle,

(2.3)

By the definitions of the GRS code and the EGRS code, Lemma
2.1
and Remark
2.2
, we can get the following proposition directly.

Proposition 2.1

Let
\bm{u}=(u_{1},\ldots,u_{n})
, where
u_{j}=-\prod\limits_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})
for any
j=1,\ldots,n
.

(1)
If
k\leq\frac{n}{2}
, then

\displaystyle\mathcal{GRS}^{2}_{k,n}(\bm{\alpha},\bm{1})=\mathcal{GRS}_{2k-1,n}(\bm{\alpha},\bm{1})\text{~~~and~~~}\mathcal{GRS}_{k,n-1}^{2}(\bm{\alpha},\bm{1},\infty)=\mathcal{GRS}_{2k-1,n-1}(\bm{\alpha},\bm{1},\infty).

(2)
If
n\geq k\geq\frac{n}{2}-1
, then

\displaystyle\big(\mathcal{GRS}_{k,n}^{\perp}(\bm{\alpha},\bm{1})\big)^{2}=\mathcal{GRS}_{2n-2k-1,n}(\bm{\alpha},\bm{u}^{2})\text{~~~and~~~}\big(\mathcal{GRS}_{k,n}^{\perp}(\bm{\alpha},\bm{1},\infty)\big)^{2}=\mathcal{GRS}_{2n-2k-1,n-1}(\bm{\alpha},\bm{u}^{2},\infty).

2.2.2
The equivalence and punctured codes for linear codes

The definition of the equivalence for linear codes is given as follows.

Definition 2.5
(
[
29
]
)

Let
\mathcal{C}_{1}
and
\mathcal{C}_{2}
be linear codes over
\mathbb{F}_{q}
with length
n
. We say that
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are equivalent if
there exists a permutation
\pi\in S_{n}
and
\bm{v}=(v_{1},\dots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}
such that
\mathcal{C}_{2}=\Phi_{\pi,\bm{v}}(\mathcal{C}_{1})
, where

\displaystyle\Phi_{\pi,\bm{v}}:\mathbb{F}_{q}^{n}\to\mathbb{F}_{q}^{n},\quad(c_{1},\ldots,c_{n})\mapsto(v_{1}c_{\pi(1)},\ldots,v_{n}c_{\pi(n)}).

Remark 2.3

It is easy to see that
\mathcal{C}_{1}^{2}
and
\mathcal{C}_{2}^{2}
are equivalent when
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are equivalent.

The definition of the punctured code is given in the following.

Definition 2.6
(
[
29
]
)

For any positive integers
m
and
n
with
m\leq n
, let
\mathcal{C}
be a linear code over
\mathbb{F}_{q}
with length
n
, and
I=\{i_{1},\ldots,i_{m}\}\subseteq\{1,\ldots,n\}
. The punctured code for
\mathcal{C}
over
I
is defined as

\displaystyle\mathcal{C}_{I}=\{(c_{i_{1}},\ldots,c_{i_{m}})~|~(c_{1},\ldots,c_{i_{1}},\ldots,c_{i_{m}},\ldots,c_{n})\in\mathcal{C}\}.

Remark 2.4

(1)
Recalled that
A_{\bm{\alpha}}=\{\alpha_{1},\ldots,\alpha_{n}\}
, if
A_{\bm{\alpha}}=\mathbb{F}_{q}
, we always denote
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
to be
\mathcal{C}_{k,q}(\mathbb{F}_{q},\bm{v},\eta)
.

(2)
Any
[1,0]
-TGRS code is equivalent to a punctured code of
\mathcal{C}_{k,q}(\mathbb{F}_{q},\bm{v},\eta)
.

(3)
If
\bm{v}_{1},\bm{v}_{2}\in(\mathbb{F}_{q}^{*})^{n}

with

2.2.3
Self-orthogonal or LCD linear codes

The notations about LCD, self-orthogonal, self-dual or almost self-dual codes are given in the following, respectively.

For
\mathbf{a}=(a_{1},\ldots,a_{n})
,
\mathbf{b}=(b_{1},\ldots,b_{n})

\in\mathbb{F}_{q}^{n}
, the inner product is defined as

\langle\mathbf{a},\mathbf{b}\rangle=\sum\limits_{i=1}^{n}a_{i}b_{i},

and then
the dual code of
\mathcal{C}
is defined as

\mathcal{C}^{\perp}=\{\mathbf{c}^{{}^{\prime}}\in\mathbb{F}_{q}^{n}~|~\langle\mathbf{c}^{{}^{\prime}},\mathbf{c}\rangle=0~\text{for any}~\mathbf{c}\in\mathcal{C}\}.

If
\mathcal{C}\cap\mathcal{C}^{\perp}=0
, then
\mathcal{C}
is LCD.

If
\mathcal{C}\subseteq\mathcal{C}^{\perp}
, then
\mathcal{C}
is self-orthogonal. Especially, if
\mathcal{C}=\mathcal{C}^{\perp}
, then
\mathcal{C}
is self-dual.

If
\mathcal{C}
is self-orthogonal with length
n
odd and
\dim(\mathcal{C})=\frac{n-1}{2}
, then
\mathcal{C}
is almost self-dual.

In the following lemma, we present a sufficient and necessary condition for
\Phi_{1_{\pi},\bm{v}}(\mathcal{C}_{I})
to be self-orthogonal, where
1_{\pi}
is the identity of permutation group with order
n
.

Lemma 2.4

Let
n
and
m
be positive integers with
m\leq n
,
I=\{i_{1},\ldots,i_{m}\}\subseteq\{1,\ldots,n\}
, and
\bm{v}=(v_{1},\ldots,v_{m})\in(\mathbb{F}_{q}^{*})^{m}
. Then for a linear code
\mathcal{C}
over
\mathbb{F}_{q}
with length
n
,
\Phi_{1_{\pi},\bm{v}}(\mathcal{C}_{I})
is self-orthogonal if and only if there is some

\mathbf{c}\in(\mathcal{C}^{2})^{\perp}
such that for any
j\in\{1,\ldots,m\}
,

\displaystyle\mathrm{Supp}(\mathbf{c})=I~\text{and}~~c_{i_{j}}=v_{j}^{2}.

Proof
. By the definition,
\Phi_{1_{\pi},\bm{v}}(\mathcal{C}_{I})
is self-orthogonal if and only if

\displaystyle\sum\limits_{j=1}^{m}v_{j}c_{1,i_{j}}v_{j}c_{2,i_{j}}=0~~\text{~for~any~}\mathbf{c}_{t}=(c_{t,i_{1}},\ldots,c_{t,i_{m}})\in\mathcal{C}_{I}~(t=1,2),

namely,

\displaystyle\sum\limits_{j=1}^{m}v_{j}^{2}(c_{1,i_{j}}c_{2,i_{j}})=0~~\text{~for~any~}\mathbf{c}_{t}=(c_{t,i_{1}},\ldots,c_{t,i_{m}})\in\mathcal{C}_{I}~(t=1,2).

Equivalently, there is some
\mathbf{c}=(c_{1},\ldots,c_{n})\in(\mathcal{C}^{2})^{\perp}
such that for
j=1,\ldots,m
,

\displaystyle\mathrm{Supp}(\mathbf{c})=I~\text{and}~~c_{i_{j}}=v_{j}^{2}.

\hfill\Box

A sufficient and necessary condition for the linear code
\mathcal{C}
with generator matrix
G
to be LCD is presented in the following proposition.

Proposition 2.2
(Proposition
2.3

[
6
]
)

If
G
is a generator matrix for the
[n,k]
linear code
\mathcal{C}
, then
\mathcal{C}
is an LCD code if and only if the
k\times k
matrix
GG^{\mathrm{T}}
is nonsingular.

2.3
The weight distributions of NMDS codes

It is well-known that the weight distribution of the MDS code
[n,k,n−k+1]
over
\mathbb{F}_{q}
depends only on the values of
n
,
k
and
q
. While for the NMDS code
[n,k,n−k]
over
\mathbb{F}_{q}
, the weight distribution depends not only on the values of
n
,
k
and
q
, but also on the number of the minimum weight codewords, which can be seen in the following lemma.

Lemma 2.5
(Theorem
4.1
,
[
7
]
)

Let
\mathcal{C}
be an
[n,k,n-k]
NMDS code over
\mathbb{F}_{q}
and
A_{i}

(i=0,1,\ldots,n)
the number of codewords in
\mathcal{C}

with weight
i
. Then the weight distributions of
\mathcal{C}
and
\mathcal{C}^{\perp}
are given by

\displaystyle A_{n-k+s}=\binom{n}{k-s}\sum\limits_{j=0}^{s-1}(-1)^{j}\binom{n-k+s}{j}(q^{s-j}-1)\!+\!(-1)^{s}\binom{k}{s}A_{n-k}\quad(s=1,\ldots,k),

(2.4)

and

\displaystyle A_{k+s}^{\perp}=\binom{n}{k+s}\sum\limits_{j=0}^{s-1}(-1)^{j}\binom{k+s}{j}(q^{s-j}-1)\!+\!(-1)^{s}\binom{k}{s}A_{k}^{\perp}\quad(s=1,\dots,n-k).

(2.5)

Furthermore,

A_{n-k}=A_{k}^{\perp}.

Remark 2.5

Let
\mathcal{C}
be an
[n,k,n-k+1]
MDS code, then
A_{n-k}=A_{k}^{\perp}=0
, and the weight distributions for
\mathcal{C}
and
\mathcal{C}^{\perp}
are given in
(\ref{ANMDS})
and
(\ref{DNMDS})
, respectively.

3.1
The dual code of the
[1,0]
-TGRS code

The following lemma is useful for calculating the parity check matrix of
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
.

Lemma 3.1

For any
m\in\mathbb{N}^{+}
and
A\subseteq\mathbb{F}_{q}
with
|A|>2
, let

L_{A}(m)=\sum\limits_{\alpha\in A}\alpha^{m}\prod\limits_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta),

then

\displaystyle L_{A}(m)=\begin{cases}0,\quad&\text{if}~0\leq m\leq|A|-2;\\
-1,\quad&\text{if}~m=|A|-1.\end{cases}

(3.1)

Proof.
For any

\displaystyle\sum\limits_{\gamma\in\mathbb{F}_{q}}\gamma^{l}=\begin{cases}-1,\quad&\text{if}~(q-1)\mid l;\\
0,\quad&\text{otherwise}.\end{cases}

(3.2)

Then by
(\ref{lq1})
and

\displaystyle\prod\limits_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta)=\alpha^{q-|A|}-\sum\limits_{\beta\in\mathbb{F}_{q}\backslash A}\beta\alpha^{q-|A|-1}+\cdots+(-1)^{q-|A|}\prod\limits_{\beta\in\mathbb{F}_{q}\backslash A}\beta,

we have

\displaystyle\begin{aligned} L_{A}(m)=&\sum\limits_{\alpha\in A}\alpha^{m}\prod\limits_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta)\\

Theorem 3.1

Let
P_{\bm{\alpha},j}=(-1)^{n}\prod\limits_{\alpha\in A_{\bm{\alpha}}\backslash\{\alpha_{j}\}}\alpha
and

&\vdots~&\vdots&~&\vdots~\\

Namely,

\displaystyle\mathcal{C}_{k,n}^{\perp}(\bm{\alpha},\bm{v},\eta)

\displaystyle=

\displaystyle\Big\{\Big(\frac{u_{1}}{v_{1}}\big(g({\alpha_{1}})+g_{n-k-1}\eta P_{\bm{\alpha},1}\big),\ldots,\frac{u_{n}}{v_{n}}\big(g(\alpha_{n})+g_{n-k-1}\eta P_{\bm{\alpha},n}\big)\Big)~\Big|~\deg g(x)\leq n-k-1\Big\},

x^{n-k-1}
in

Proof

we can get

\displaystyle\tilde{H}=\left(\begin{matrix}&\alpha_{i_{1}}~&\alpha_{i_{2}}~&\ldots~&\alpha_{i_{n+1-k}}~\\

\displaystyle\mathrm{Rank}(H_{n-k})=n-k.

3.2
The Non-GRS (non-EGRS) property for
[1,0]
-TGRS codes

In this subsection, we show that
[1,0]
-TGRS codes are not GRS or EGRS by using the Schur product.

The Schur square for the
[1,0]
-TGRS code is given in the following lemma.

Lemma 3.2

If
k\geq 3
, then the following two assertions hold.

(1)
For
k\geq\frac{n}{2}
,

\mathcal{C}_{k,n}^{2}(\bm{\alpha},\bm{v},\eta)=\mathbb{F}_{q}^{n}.

(2)
For
3\leq k<\frac{n}{2}
,

\displaystyle\mathcal{C}_{k,n}^{2}(\bm{\alpha},\bm{v},\eta)=\mathcal{C}_{2k,n}(\bm{\alpha},\bm{v}^{2},\eta^{2}).

Proof
. It is enough to prove that
(1)
and
(2)
are both true for
\bm{v}=\mathbf{1}
. In fact, by the definition of
\mathcal{C}_{k,n}(\bm{\alpha},\bm{1},\eta)
and Remark
2.2
, for
k\geq 3
, we have

\displaystyle\begin{aligned} &\mathcal{C}_{k,n}^{2}(\bm{\alpha},\bm{1},\eta)\\
=&\left\langle\bm{\alpha}^{i+j},\bm{\alpha}^{i}\star(\bm{1}+\eta\bm{\alpha}^{k}),(\bm{1}+\eta\bm{\alpha}^{k})^{2}~(i=1,\ldots,k-1;j=1,\ldots,k-1)\right\rangle\\
=&\left\langle\bm{\alpha}^{i},\bm{\alpha}+\eta\bm{\alpha}^{k+1},\bm{\alpha}^{k-1}+\eta\bm{\alpha}^{2k-1},\bm{1}+2\eta\bm{\alpha}^{k}+\eta^{2}\bm{\alpha}^{2k}~(i=2,\ldots,2k-2)\right\rangle\\
=&\left\langle\bm{\alpha}^{i},\bm{1}+\eta^{2}\bm{\alpha}^{2k}~(i=1,\ldots,2k-1)\right\rangle\\
=&\begin{cases}\mathbb{F}_{q}^{n},\quad&\text{if~}2k\geq n;\\
\mathcal{C}_{2k,n}(\bm{\alpha},\bm{1},\eta^{2}),\quad&\text{if~}2k<n.\\
\end{cases}\end{aligned}

\hfill\Box

For
3\leq k\leq n-3
,
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

and

(1)

and Remark

\displaystyle\dim\Big(\big(\mathcal{C}_{k,n}^{\perp}(\bm{\alpha},\bm{v},\eta)\big)^{2}\Big)=2(n-k).

3.3
The weight distribution of the
[1,0]
-TGRS code

In this subsection, for any

and

, let

In the following theorem, we show that

\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

can be determined by

Let
A_{i}
and
A^{\perp}_{i}
be the number of codewords with Hamming weight
i

(i=0,1,\ldots,n)
in
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
and
\mathcal{C}_{k,n}^{\perp}(\bm{\alpha},\bm{v},\eta)

\displaystyle A_{n-k+s}

\displaystyle=

\displaystyle\begin{cases}(q-1)\#M(k,(-1)^{k}\eta^{-1},A_{\bm{\alpha}}),&\hskip 9.24994pt\text{if}~s=0;\\
\binom{n}{k-s}\sum\limits_{j=0}^{s-1}(-1)^{j}\binom{n-k+s}{j}(q^{s-j}-1)\!+\!(-1)^{s}(q-1)\binom{k}{s}\#M(k,(-1)^{k}\eta^{-1},A_{\bm{\alpha}}),&\hskip 9.24994pt\text{if}~s=1,\dots,k;\end{cases}

and

\displaystyle A_{k+s}^{\perp}

\displaystyle=

\displaystyle\begin{cases}(q-1)\#M(k,(-1)^{k}\eta^{-1},A_{\bm{\alpha}}),&\hskip 9.24994pt\text{if}~s=0;\\
\binom{n}{k+s}\sum\limits_{j=0}^{s-1}(-1)^{j}\binom{k+s}{j}(q^{s-j}-1)\!+\!(-1)^{s}(q-1)\binom{k}{s}\#M(k,(-1)^{k}\eta^{-1},A_{\bm{\alpha}}),&\hskip 9.24994pt\text{if}~s=1,\dots,n-k.\end{cases}

. By Lemma
2.3
, we know that
\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)
is MDS or NMDS. Then based on Lemma
2.5
, it is enough to
determine
A_{n-k}
.

For any

\mathbf{c}_{f}=(v_{1}f(\alpha_{1}),\ldots,v_{n}f(\alpha))\in\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)~~(f(x)\in\mathcal{V}_{k,1,0,\eta}),

let
\bm{w}_{\mathbf{c}_{f}}
be the Hamming weight of
\mathbf{c}_{f}
, then

\bm{w}_{\mathbf{c}_{f}}=n-k\text{~if and only if~}\#\{\alpha\in A_{\bm{\alpha}}~|~f(\alpha)=0\}=k.

Namely, there exist some
k

A\subsetneq A_{\bm{\alpha}}
and
\lambda\in\mathbb{F}_{q}^{*}

\displaystyle f(x)=\lambda\prod\limits_{\alpha\in A}(x-\alpha)=\lambda\bigg(x^{k}+\sum\limits_{i=1}^{k-1}(-1)^{k-i}\Big(\sum\limits_{I\subsetneq A,|I|=k-i}\prod\limits_{\alpha\in I}\alpha\Big)x^{i}+(-1)^{k}\prod\limits_{\alpha\in A}\alpha\bigg),

which leads that

\displaystyle A_{n-k}=

\displaystyle\#\bigg(V_{k,1,0,\eta}\cap\Big\{f(x)=\lambda\prod\limits_{\alpha\in\mathbb{F}_{q}\backslash A}(x-\alpha)~\Big|~\lambda\neq 0,~A\subsetneq A_{\bm{\alpha}}\Big\}\bigg)

\displaystyle=

\displaystyle(q-1)\#\Big\{A\subsetneq A_{\bm{\alpha}}~\Big|~|A|=k,~\prod\limits_{\alpha\in A}\alpha=(-1)^{k}\eta^{-1}\Big\}

\displaystyle=

\displaystyle(q-1)\#M(k,(-1)^{k}\eta^{-1},A_{\bm{\alpha}}).

(\gamma\beta_{1},\ldots,\gamma\beta_{k})\in M(k,a,\mathbb{F}_{q}^{*}).

\displaystyle\#M(k,b,\mathbb{F}_{q}^{*})\leq\#M(k,a,\mathbb{F}_{q}^{*}).

Similarly, we have

\displaystyle\#M(k,a,\mathbb{F}_{q}^{*})\leq\#M(k,b,\mathbb{F}_{q}^{*}).

Thus for any

\displaystyle\#M(k,a,\mathbb{F}_{q}^{*})=\#M(k,b,\mathbb{F}_{q}^{*}).

(3.5)

Furthermore, it is easy to see that

\displaystyle\sum_{a\in\mathbb{F}_{q}^{*}}\#M(k,a,\mathbb{F}_{q}^{*})=\binom{q-1}{k}.

(3.6)

Now by
(\ref{M2})
-
(\ref{M22})
, we have

\#M(k,b,\mathbb{F}_{q}^{*})=\frac{1}{q-1}\binom{q-1}{k}.

Lemma 4.1

For

\gamma
be a primitive element of
\mathbb{F}_{q}

(1)

(2)
If

\displaystyle\big(\mathcal{C}_{k,q}^{2}(\mathbb{F}_{q},\bm{1},\eta)\big)^{\perp}=\Big\{\big(g({\gamma^{1}}),\ldots,g(\gamma^{q-1}),g_{0}+\eta^{2}g_{q-1-2k}\big)~|~\deg g(x)\leq q-1-2k\Big\},

1

Now a sufficient and necessary condition for TGRS code to be self-orthogonal is given in the following theorem.

Theorem 4.1

For
3\leq k<\frac{q+1}{2}

(1)
If
0\in A_{\bm{\alpha}}

\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

j\in\{1,\ldots,n-1\}
and

\displaystyle g_{0}+\eta^{2}g_{q-1-2k}=v_{n}^{2},~~~~g(\alpha_{j})=v_{j}^{2},~~~~g(\beta)=0.

(4.1)

(2)
If

\mathcal{C}_{k,n}(\bm{\alpha},\bm{v},\eta)

g(x)=\sum\limits_{i=0}^{q-1-2k}g_{i}x^{i}\in\mathbb{F}_{q}[x]

j\in\{1,\ldots,n\}
and

\displaystyle g_{0}+\eta^{2}g_{q-1-2k}=0,~~~~g(\alpha_{j})=v_{j}^{2},~~~~g(\beta)=0.

(4.2)

Let
\gamma
be a primitive element of
\mathbb{F}_{q}

4.1

\bm{c}\in\big(\mathcal{C}_{k,q}^{2}(\mathbb{F}_{q},\bm{1},\eta)\big)^{\perp}

and

(1)
If

(2)

for any
j=1,\ldots,2k
, then the following two assertions hold.

(1)
If
\eta^{-1}\in\mathbb{F}_{q}^{*}\backslash S_{k}(\bm{\alpha})
, then
{\mathcal{C}}_{k,2k}(\bm{\alpha},\bm{v},\eta)
is a self-dual MDS code.

(2)
If
\eta^{-1}\in S_{k}(\bm{\alpha})
, then
{\mathcal{C}}_{k,2k}(\bm{\alpha},\bm{v},\eta)
is a self-dual NMDS code.

4.3
LCD
[1,0]
-TGRS codes from self-orthogonal
[1,0]
-TGRS codes

In this subsection, inspired by the Carlet et al’s method for constructing LCD linear codes from self-orthogonal linear codes
[
6
]
, we have the following

Lemma 4.2

For
q>3
, let
\mathcal{C}
be an
[n,k]
linear code over
\mathbb{F}_{q}
, then there exists some
I=\{i_{1},\ldots,i_{k}\}\subsetneq\{1,\ldots,n\}
such that
\mathcal{C}_{I}=\mathbb{F}_{q}^{k}
. Furthermore, for any
\beta\in\mathbb{F}_{q}\backslash\{0,-1,1\}
, let
\bm{v}=(v_{1},\ldots,v_{n})
with
v_{i}=1

(i\in I)
and
v_{i}=\beta

(i\notin I)
, if
\mathcal{C}
is self-orthogonal, then
\Phi_{1_{\pi},\bm{v}}(\mathcal{C})
is LCD.

Proof
. Let
G=\left[\begin{matrix}\bm{g}_{1},\ldots,\bm{g}_{n}\end{matrix}\right]
be a generator matrix of
\mathcal{C}
, where
\bm{g}_{i}=(g_{1,i},\ldots,g_{k,i})^{T}\in\mathbb{F}_{q}^{k}
, it is obvious that there exists some
I=\{i_{1},\ldots,i_{k}\}\subsetneq\{1,\ldots,n\}
such that
\mathcal{C}_{I}=\mathbb{F}_{q}^{k}
and
\mathrm{Rank}(G_{I})=k
, where
G_{I}=\left[\begin{matrix}\bm{g}_{i_{1}},\ldots,\bm{g}_{i_{k}}\end{matrix}\right]
.
Denote
I\!=\!\{i_{1},\ldots,i_{k}\}
with
i_{1}\!<\!\cdots\!<\!i_{k}
, and
\{j_{1},\ldots,j_{n-k}\}\!=\!\{1,\ldots,n\}\backslash I
with
j_{1}\!<\!\cdots\!<\!j_{n-k}
, let

\displaystyle J_{I}=\left[\begin{matrix}\bm{g}_{i_{1}},\ldots,\bm{g}_{i_{k}}\end{matrix}\right],~~P_{I}=\left[\begin{matrix}\bm{g}_{j_{1}},\ldots,\bm{g}_{j_{n-k}}\end{matrix}\right],~~J=\left[\begin{matrix}\bm{J}_{1},\ldots,\bm{J}_{n}\end{matrix}\right],~~P=\left[\begin{matrix}\bm{p}_{1},\ldots,\bm{p}_{{n}}\end{matrix}\right],

where

\displaystyle\bm{J}_{s}=\begin{cases}\bm{g}_{s},\quad&\text{if}~s\in I;\\
\bm{0},\quad&\text{if}~s\in\{1,\ldots,n\}\backslash I,\end{cases}\text{\quad\quad}\bm{p}_{s}=\begin{cases}\bm{g}_{s},\quad&\text{if}~s\in\{1,\ldots,n\}\backslash I;\\
\bm{0},\quad&\text{if}~s\in I.\end{cases}

Then
J_{I}
is full rank, and

\displaystyle G=J+P,~~~JP^{\mathrm{T}}=PJ^{\mathrm{T}}=\bm{0}_{k,k},~~~JJ^{\mathrm{T}}=J_{I}J_{I}^{\mathrm{T}},~~~PP^{\mathrm{T}}=P_{I}P_{I}^{\mathrm{T}}.

(4.6)

Furthermore, if
\mathcal{C}
is self-orthogonal, then

\displaystyle GG^{T}=\bm{0}_{k,k}.

(4.7)

Now by
(\ref{eq1})
-
(\ref{So})
, one has

\displaystyle J_{I}J_{I}^{\mathrm{T}}+P_{I}P_{I}^{\mathrm{T}}=\bm{0}_{k,k}.

(4.8)

Note that
\Phi_{1_{\pi},\bm{v}}(\mathcal{C})
has a generator matrix
\tilde{G}=J+\beta P
. Thus by
(\ref{eq1})
and
(\ref{JP})
, one has

\displaystyle\tilde{G}\tilde{G}^{T}=J_{I}J_{I}^{\mathrm{T}}+\beta^{2}P_{I}P_{I}^{\mathrm{T}}=(1-\beta^{2})J_{I}J_{I}^{\mathrm{T}}.

Since
J_{I}
is nonsingular and
\beta\in\mathbb{F}_{q}\backslash\{0,1,-1\}
, we know that
\tilde{G}\tilde{G}^{T}
is nonsingular, then by Proposition
2.2
,
\Phi_{1_{\pi},\bm{v}}(\mathcal{C})
is LCD.

\hfill\Box

Basing on Lemma
4.2
, we have the following theorem, which is useful for constructing LCD
[1,0]
-TGRS codes from self-orthogonal
[1,0]
-TGRS codes.

Theorem 4.11

For
q>3
, let
\beta\in\mathbb{F}_{q}\backslash\{0,-1,1\}
and
\bm{w}=(\underbrace{\beta,\ldots,\beta,}_{n-k}\underbrace{1,\ldots,1}_{k})
. If
0\in A_{\bm{\alpha}}
and
{\mathcal{C}}_{k,n}(\bm{\alpha},\bm{v},\eta)
is self-orthogonal, then
{\mathcal{C}}_{k,n}(\bm{\alpha},\bm{w}\star\bm{v},\eta)
is LCD.

Proof
. Note that
{\mathcal{C}}_{k,n}(\bm{\alpha},\bm{v},\eta)
is a linear code with the generator matrix
G_{k}
given in
(\ref{G1})
,
by extracting columns
n+1-k,\ldots,n
of
G_{k}
, we can get

\displaystyle\tilde{G}=\left(\begin{matrix}&v_{1}(1+\eta\alpha_{n+1-k}^{k})~&\cdots~&v_{n-1}(1+\eta\alpha_{n-1}^{k})~&v_{n}~\\
&v_{1}\alpha_{n+1-k}~&\cdots~&v_{n-1}\alpha_{n-1}~&0~\\
&\vdots~&\cdots~&\vdots&\vdots~\\
&v_{1}\alpha_{n+1-k}^{k-2}~&\cdots~&v_{n-1}\alpha_{n-1}^{k-2}~&0~\\
&v_{1}\alpha_{n+1-k}^{k-1}~&\cdots~&v_{n-1}\alpha_{n-1}^{k-1}~&0~\\
\end{matrix}\right)_{k\times k}

Since

\displaystyle\det(\tilde{G})=\left|\begin{matrix}&v_{n+1-k}\alpha_{n+1-k}~&\cdots~&v_{n-1}\alpha_{n-1}~\\
&\vdots~&\cdots~&\vdots~\\
&v_{n+1-k}\alpha_{n+1-k}^{k-2}~&\cdots~&v_{n-1}\alpha_{n-1}^{k-2}~\\
&v_{n+1-k}\alpha_{n+1-k}^{k-1}~&\cdots~&v_{n-1}\alpha_{n-1}^{k-1}~\\
\end{matrix}\right|\neq 0,

we know that
\tilde{G}
is nonsingular, which implies that the last
k
columns of
G_{k}
are linearly independent over
\mathbb{F}_{q}
, and so

\displaystyle{\mathcal{C}}_{k,n}(\bm{\alpha},\bm{v},\eta)_{I}=\mathbb{F}_{q}^{k},~\text{where}~I=\{n+1-k,\ldots,n\}.

(4.9)

So far, by
(\ref{L})
and Lemma
4.2
, we get the desired result.
\hfill\Box

(1)
If

, basing on those almost self-dual

5
Conclusions

In this paper, we got the following main results.

(1)
The weight distribution of the
[1,0]
-TGRS code is determined.

(2)
A parity check matrix for the
[1,0]
-TGRS code is given.

(3)

[1,0]
-TGRS codes are not GRS or EGRS.

(4)
A sufficient and necessary condition for any punctured code of the
[1,0]
-TGRS code to be self-orthogonal is presented.

(5)
Several classses of self-dual, almost self-dual, and LCD MDS or NMDS codes are constructed.
