Strongly Normalizing Higher-Order Relational Queries
Wilmer Ricciotti ORCID:0000-0002-2361-8538, James Cheney ORCID:0000-0002-1307-9286

Abstract
. Language-integrated query is a powerful programming construct allowing database queries and ordinary program code to interoperate seamlessly and safely. Language-integrated query techniques rely on classical results about the nested relational calculus, stating that its queries can be algorithmically translated to SQL, as long as their result type is a flat relation. Cooper and others advocated higher-order nested relational calculi as a basis for language-integrated queries in functional languages such as Links and F#. However, the translation of higher-order relational queries to SQL relies on a rewrite system for which no strong normalization proof has been published: a previous proof attempt does not deal correctly with rewrite rules that duplicate subterms. This paper fills the gap in the literature, explaining the difficulty with a previous proof attempt, and showing how to extend the ⊤ ⁣ ⊤ \top\top -lifting approach of Lindley and Stark to accommodate duplicating rewrites. We also show how to extend the proof to a recently-introduced calculus for heterogeneous queries mixing set and multiset semantics.

1.
Introduction

The Nested Relational Calculus (
\mathit{NRC}
)
[
BNTW95
]
provides a principled
foundation for integrating database queries into programming languages. Wong’s conservativity theorem
[
Won96
]
generalized the classic
flat-flat theorem
[
PG92
]
to show that for any nesting depth
d
, a query
expression over flat input tables returning collections of depth at
most
d
can be expressed without constructing intermediate results of
nesting depth greater than
d
. In the special case
d=1
, this
implies the flat-flat theorem, namely that a nested relational query
mapping flat tables to flat tables can be expressed in a semantically equivalent way using
the flat relational calculus.
In addition, Wong’s proof technique was constructive, and gave an
easily-implemented terminating rewriting algorithm for normalizing NRC queries to flat relational queries, which can in turn be easily translated to idiomatic SQL queries.
The basic approach has been extended
in a number of directions, including to allow for (nonrecursive)
higher-order functions in queries
[
Coo09b
]
, and to allow for
translating queries that return nested results to a bounded number of
flat relational queries
[
CLW14
]
.

Normalization-based techniques are used in language-integrated query systems such as
Kleisli
[
Won00
]
and Links
[
CLWY07
]
, and can
improve both performance and reliability of language-integrated query
in F#
[
CLW13
]
. However, most work on normalization
considers
homogeneous
queries in which there is a single
collection type (e.g. homogeneous sets or multisets).
Currently, language-integrated query systems such as C# and
F#
[
MBB06
]
support duplicate elimination via a

\mathtt{Distinct()}
method, which is translated to SQL queries in an ad
hoc way, and comes with no guarantees regarding completeness or
expressiveness as far as we know, whereas Database-Supported Haskell
(DSH)
[
UG15
]
supports duplicate elimination but
gives all operations list semantics and relies on more sophisticated
SQL:1999 features to accomplish this. Fegaras and Maier
[
FM00
]

propose optimization rules for a nested object-relational calculus with set and bag constructs
but do not consider the problem of conservativity with respect to flat queries.

Recently, we considered a
heterogeneous
calculus for mixed set
and bag queries
[
RC19
]
, and conjectured that it too
satisfies strong normalization and conservativity theorems. However,
in attempting to extend Cooper’s proof of normalization we discovered
a subtle problem, which makes the original proof incomplete.

Most techniques to prove the strong normalization property for higher-order
languages employ logical relations; among these, the Girard-Tait

reducibility
relation is particularly influential: reducibility
interprets types as certain sets of strongly normalizing terms enjoying
desirable closure properties with respect to reduction, called

candidates of reducibility

[
GLT89
]
. The fundamental theorem
then proves that every well-typed term is reducible, hence also strongly
normalizing. In its traditional form, reducibility has a limitation that
makes it difficult to apply it to certain calculi: the elimination form of
every type is expected to be a
neutral
term or, informally, an
expression that, when placed in an arbitrary evaluation context, does not
interact with it by creating new redexes. However, some calculi possess

commuting conversions
, i.e. reduction rules that apply to nested
elimination forms: such rules usually arise when the elimination form for a
type (say, pairs) is constructed by means of an auxiliary term of
any arbitrary, unrelated type. In this case, we expect nested elimination forms to
commute; for example, we could have the following commuting conversion hoisting
the elimination of pairs out of case analysis on disjoint unions:

\begin{array}[]{l}\mathbf{cases}~(\mathbf{let}~(a,b)=p~\mathbf{in}~t)~\mathbf{of}~\mathbf{inl}(x)\Rightarrow u;\mathbf{inr}(y)\Rightarrow v\\
\mathrel{\leadsto}\mathbf{let}~(a,b)=p~\mathbf{in}~\mathbf{cases}~t~\mathbf{of}~\mathbf{inl}(x)\Rightarrow u;\mathbf{inr}(y)\Rightarrow v\end{array}

where
p
has type
A\times B
,
t
has type
C+D
,
u,v
have type
U
,
and the bound variables
a,b
are chosen fresh for
u
and
v
.
Since in the presence of commuting conversions elimination forms are not neutral, a straightforward adaptation of reducibility to such languages is precluded.

1.1.
\top\top
-lifting and
\mathit{NRC}_{\lambda}

Cooper’s
\mathit{NRC}_{\lambda}

[
Coo09a
,
Coo09b
]
extends the simply typed lambda calculus with collection types whose elimination form is expressed by
comprehensions

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow N}\mathclose{\textbf{\lx@text@rbrace}}
, where
M
and
N
have a collection type, and the bound variable
x
can appear in
M
:

\Gamma\vdash N:\mathopen{\textbf{\lx@text@lbrace}}{S}\mathclose{\textbf{\lx@text@rbrace}}

\Gamma,x:S\vdash M:\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}

\Gamma\vdash\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow N}\mathclose{\textbf{\lx@text@rbrace}}:\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}

(we use bold-style braces
\mathopen{\textbf{\lx@text@lbrace}}{\cdot}\mathclose{\textbf{\lx@text@rbrace}}
to indicate collections as expressions or types of
\mathit{NRC}_{\lambda}
). In the rule above, we typecheck a comprehension destructuring collections of type
\mathopen{\textbf{\lx@text@lbrace}}{S}\mathclose{\textbf{\lx@text@rbrace}}
to produce new collections in
\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}
, where
T
is an unrelated type: semantically, this corresponds to the union of all the collections
M\left[{V}\middle/{x}\right]
, such that
V
is in
N
. According to the standard approach, we should attempt to define the reducibility predicate for the collection type
\mathopen{\textbf{\lx@text@lbrace}}{S}\mathclose{\textbf{\lx@text@rbrace}}
as:

\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{S}\mathclose{\textbf{\lx@text@rbrace}}}\triangleq\{{N:\forall x,T,\forall M\in\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}},\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow N}\mathclose{\textbf{\lx@text@rbrace}}\in\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}}}\}

(we use roman-style braces
\{{\cdot}\}
to express metalinguistic sets). Of course the definition above is circular, since it uses reducibility over collections to express reducibility over collections; however, this inconvenience could in principle be circumvented by means of impredicativity, replacing
\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}}
with a suitable, universally quantified candidate of reducibility (an approach we used in
[
RC17
]
in the context of justification logic). Unfortunately, the arbitrary return type of comprehensions is not the only problem: they are also involved in commuting conversions, such as:

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N|y\leftarrow P}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}}\mathrel{\leadsto}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow N}\mathclose{\textbf{\lx@text@rbrace}}|y\leftarrow P}\mathclose{\textbf{\lx@text@rbrace}}\qquad(y\notin FV(M))

Because of this rule, comprehensions are not neutral terms, thus we cannot use the closure properties of candidates of reducibility (in particular,
\mathrm{CR3}

[
GLT89
]
) to prove that a collection term is reducible.
To address this problem, Lindley and Stark proposed a revised notion of reducibility based
on a technique they called
\top\top
-lifting
[
LS05
]
.
\top\top
-lifting, which
derives from Pitts’s related notion of
\top\top
-closure
[
Pit98
]
, involves
quantification over arbitrarily nested, reducible elimination contexts (
continuations
);
the technique is actually composed of two steps:
\top
-lifting, used to define the set

\mathsf{Red}_{T}^{\top}
of reducible continuations for collections of type
T
in terms of
\mathsf{Red}_{T}
, and

\top\top
-lifting proper, defining
\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}}=\mathsf{Red}_{T}^{\top\top}
in terms of

\mathsf{Red}_{T}^{\top}
. In our setting, if we use
\mathcal{S}\mathcal{N}
to denote the set of strongly normalizing
terms, the two operations can be defined as follows:

\displaystyle\mathsf{Red}_{T}^{\top}

\displaystyle\triangleq\{{K:\forall M\in\mathsf{Red}_{T},K[\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}}\}

\displaystyle\mathsf{Red}_{T}^{\top\top}

\displaystyle\triangleq\{{M:\forall K\in\mathsf{Red}_{T}^{\top},K[M]\in\mathcal{S}\mathcal{N}}\}

Notice that, in order to avoid a circularity between the definitions of reducible collection
continuations and reducible collections, the former are defined by lifting a
reducible term
M
of type
T
to a singleton collection.

In
\mathit{NRC}_{\lambda}
, besides commuting conversions, we come across an additional problem concerning the property of distributivity of comprehensions over unions, represented by the following reduction rule:

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M\mathbin{\cup}N|x\leftarrow P}\mathclose{\textbf{\lx@text@rbrace}}\mathrel{\leadsto}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M|x\leftarrow P}\mathclose{\textbf{\lx@text@rbrace}}\mathbin{\cup}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N|x\leftarrow P}\mathclose{\textbf{\lx@text@rbrace}}

One can immediately see that in
\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M\mathbin{\cup}N|x\leftarrow\Box}\mathclose{\textbf{\lx@text@rbrace}}
the reduction above duplicates the hole, producing a multi-hole context that is not a continuation in the Lindley-Stark sense.

Cooper, in his work, attempted to reconcile continuations with
duplicating reductions. While considering extensions to his language,
we discovered that his proof of strong normalization presents a
nontrivial lacuna which we could only fix by relaxing the definition
of continuations to allow multiple holes. This problem affected both
the proof of the original result and our attempt to extend it, and has
an avalanche effect on definitions and proofs, yielding a more radical
revision of the
\top\top
-lifting technique which is the subject of
this paper.

The contribution of this paper is to place previous work on
higher-order programming for language-integrated query on a solid
foundation. As we will show, our approach also extends to proving
normalization for a higher-order heterogeneous collection calculus

\mathit{NRC}_{\lambda}(\mathit{Set},\mathit{Bag})

[
RC19
]
and we believe our proof technique
can be extended further.

This article is a revised and expanded version of a conference paper
[
RC20
]
. Compared with the conference paper, this
article refines the notion of
\top\top
-lifting by omitting a harmless, but unnecessary generalization, includes details of proofs that had to be left out, and expands the discussion of related work. In addition, we fully comment on
the extension of our result to a language allowing to freely mix and compose set queries and bag queries, which was only marginally
discussed in the conference version. We also solved a subtle problem with the treatment of variable capture in contexts by reformulating the statement of Lemma
9
.

We will allow ourselves to say “induction on the derivation of reduction” to mean the structural induction induced by the notion of congruence closure, followed by a case analysis on the basic reduction rules used as its base case.

We now discuss the basic reduction rules in more detail. 0-ary constants are values of atomic type and do not reduce. Applied constants (with positive arity) reduce when all of their arguments
are (0-ary) constants: the reduction rule relies on a fixed semantics
\left\llbracket{\cdot}\right\rrbracket
which assigns to each constant
c
of signature
\Sigma(c)=\overrightarrow{A^{\prime}_{n}}\to A
a function mapping constants
c^{\prime}_{1},\ldots,c^{\prime}_{n}
of type
\overrightarrow{A^{\prime}_{n}}
to values of type
A
. The rules for collections and conditionals are mostly standard. The reduction rule for the emptiness test is triggered when the argument
M
is not of relation type (but, for instance, of nested collection type) and employs comprehension to generate a (trivial) relation that is empty if and only if
M
is.

The normal forms of queries under these rewriting rules construct no
intermediate nested structures, and are straightforward to translate
to syntactically isomorphic (up to notational differences) and semantically equivalent SQL queries. For example, consider the following
\mathit{NRC}_{\lambda}
query which, given a table
t
, first wraps the
id
field of every tuple of
t
into a singleton, yielding a collection of singletons (i.e. a nested collection), then converts it back to a flat collection by performing the grand union of all of its elements:

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{y\mid y\leftarrow\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\mathopen{\textbf{\lx@text@lbrace}}{\mathopen{\textbf{\lx@text@lbrace}}{x.id}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}}\mid x\leftarrow t}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}}

The normal form of this query does not create the unnecessary intermediate nested collection:

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\mathopen{\textbf{\lx@text@lbrace}}{x.id}\mathclose{\textbf{\lx@text@rbrace}}\mid x\leftarrow t}\mathclose{\textbf{\lx@text@rbrace}}

Such a query is easily translated to SQL as:

{\color{blue}\mathtt{SELECT}}~x.id~{\color{blue}\mathtt{FROM}}~t~x

Cooper
[
Coo09b
]
and Lindley and
Cheney
[

]
give a full account of the translation from
\mathit{NRC}_{\lambda}
normal forms to SQL. Cheney
et al.
[
CLW13
]
showed how to improve the performance and
reliability of LINQ in F# using normalization and gave many examples
showing how higher-order queries support a convenient, compositional
language-integrated query programming style.

3.
Reducibility with branching continuations

We introduce here the extension of
\top\top
-lifting we use to derive a proof of strong normalization for
\mathit{NRC}_{\lambda}
. The main contribution of this section is a refined definition of continuations with branching structure and multiple holes, as opposed to the linear structure with a single hole used by standard
\top\top
-lifting. In our definition, continuations (as well as the more general notion of context) are particular forms of terms: in this way, the notion of term reduction can be used for continuations as well, without need for auxiliary definitions.

3.1.
Contexts and continuations

We start our discussion by introducing
contexts
, or terms with multiple, labelled holes that can be instantiated by plugging other terms (including other contexts) into them.

{defi}

[context]
Let us fix a countably infinite set
\mathcal{P}
of indices: a
context

is a term that may contain distinguished free variables
\mathop{\left[{p}\right]}
, also called

, where
p\in\mathcal{P}
. Holes are never bound by any of the binders (we disallow terms of the form
\lambda\mathop{\left[{p}\right]}.M
or
\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M\mid\mathop{\left[{p}\right]}\leftarrow N}\mathclose{\textbf{\lx@text@rbrace}}
).

Given a finite map from indices to terms
[p_{1}\mapsto M_{1},\ldots,p_{n}\mapsto M_{n}]
(
context instantiation
), the notation
C[p_{1}\mapsto M_{1},\ldots,p_{n}\mapsto M_{n}]
(
context application
) denotes the term obtained by simultaneously plugging
M_{1},\ldots,M_{n}
into the holes
\mathop{\left[{p_{1}}\right]},\ldots,\mathop{\left[{p_{n}}\right]}
. Notice that the
M_{i}
are allowed to contain holes.

We will use metavariables
\eta,\theta
to denote context instantiations.

{defi}

[support]
Given a context
C

\supp(C)
is defined as the set of the indices

such that
\mathop{\left[{p}\right]}
occurs in
C

\supp(C)\triangleq\{{p:\mathop{\left[{p}\right]}\in\FV(C)}\}

(it suffices to use
\FV(C)
as holes are never used as bound variables).

When a term does not contain any
\mathop{\left[{p}\right]}
, we say that it is a
pure
term; when it is important that a term be pure, we will refer to it by using overlined metavariables
\overline{L},\overline{M},\overline{N},\overline{R},\ldots

We introduce a notion of
permutable

{defi}

A context instantiation

is
permutable
iff for all
p\in\dom(\eta)
we have
\FV(\eta(p))\cap\dom(\eta)=\emptyset
.

The word “permutable” is explained by the following properties:

Lemma 1
.

Let
\eta
be permutable, and
p_{1},\ldots,p_{k}
be an enumeration of all the elements of
\dom(\eta)
without repetitions, in any order.
Then, for all contexts
C
, we have:

C\eta=C[p_{1}\mapsto\eta(p_{1})]\cdots[p_{k}\mapsto\eta(p_{k})]

Proof 3.1
.

By structural induction on
C
. The relevant case is when
C=\mathop{\left[{p_{i}}\right]}
, for some
i\in\{{1,...,k}\}
. By definition, the left-hand side
rewrites to
\eta(p_{i})
; we can express the right-hand side as

\mathop{\left[{p_{i}}\right]}\overrightarrow{[p_{j}\mapsto\eta(p_{j})]}_{j=1,\ldots,i-1}[p_{i}\mapsto\eta(p_{i})]\overrightarrow{[p_{j}\mapsto\eta(p_{j})]}_{j=i+1,\ldots,k}
. Then we prove:

•

\mathop{\left[{p_{i}}\right]}\overrightarrow{[p_{j}\mapsto\eta(p_{j})]}_{j=1,\ldots,i-1}=\mathop{\left[{p_{i}}\right]}
, because for all
j

p_{i}\neq p_{j}
;

•

\mathop{\left[{p_{i}}\right]}[p_{i}\mapsto\eta(p_{i})]=\eta(p_{i})
by definition;

•

\eta(p_{i})\overrightarrow{[p_{j}\mapsto\eta(p_{j})]}_{j=i+1,\ldots,k}=\eta(p_{i})
because, by the permutability hypothesis, for all

we have
that
\mathop{\left[{p_{j}}\right]}\notin\FV(\eta(p_{i}))
.

Then the right-hand side also rewrites to
\eta(p_{i})
, proving the thesis.

All the other cases are trivial, applying induction hypotheses where needed.

Lemma 2
.

Let
\eta
be permutable and let us denote by
\eta_{\lnot p}
the restriction of
\eta
to indices other than
p
. Then for all

we have:

C\eta=C[p\mapsto\eta(p)]\eta_{\lnot p}=C\eta_{\lnot p}[p\mapsto\eta(p)]

Proof 3.2
.

Immediate, by Lemma
1
.

We can now define continuations as certain contexts that capture how one or more collections can be used in a program.

{defi}

[continuation]
Continuations
K
are defined as the following subset of contexts:

\displaystyle K,H::=

\displaystyle\quad\mathop{\left[{p}\right]}\mathbin{~|~}\overline{M}\mathbin{~|~}K\mathbin{\cup}K\mathbin{~|~}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\overline{M}|x\leftarrow K}\mathclose{\textbf{\lx@text@rbrace}}\mathbin{~|~}\mathtt{\color{blue}where}~\overline{B}~\mathtt{\color{blue}do}~K

where for all indices
p
,
\mathop{\left[{p}\right]}
can occur at most once.

This definition differs from the traditional one in two ways: first, holes are decorated with an index; secondly, and most importantly, the production
K\mathbin{\cup}K
allows continuations to branch and, as a consequence, to use more than one hole. Note that the grammar above is ambiguous, in the sense that certain expressions like
\mathtt{\color{blue}where}~\overline{B}~\mathtt{\color{blue}do}~\overline{N}
can be obtained either from the production
\mathtt{\color{blue}where}~\overline{B}~\mathtt{\color{blue}do}~K
with
K=\overline{N}
, or as pure terms by means of the production
\overline{M}
: we resolve this ambiguity by parsing these expressions as pure terms whenever possible, and as continuations only when they are proper continuations.

An additional complication of
\mathit{NRC}_{\lambda}
when compared to the computational metalanguage for which
\top\top
-lifting was devised lies in the way conditional expressions can reduce when placed in an arbitrary context: continuations in the grammar above are not liberal enough to adapt to such reductions, therefore, like Cooper, we will need an additional definition of
auxiliary
continuations allowing holes to appear in the body of a comprehension (in addition to comprehension generators).

{defi}
[auxiliary continuation]
Auxiliary continuations are defined as the following subset of contexts:

\displaystyle Q,O::=

\displaystyle\quad\mathop{\left[{p}\right]}\mathbin{~|~}\overline{M}\mathbin{~|~}Q\mathbin{\cup}Q\mathbin{~|~}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{Q|x\leftarrow Q}\mathclose{\textbf{\lx@text@rbrace}}\mathbin{~|~}\mathtt{\color{blue}where}~\overline{B}~\mathtt{\color{blue}do}~Q

where for all indices
p
,
\mathop{\left[{p}\right]}
can occur at most once.

We can then see that regular continuations are a special case of auxiliary continuations;
however, an auxiliary continuation is allowed to branch not only with unions, but also with comprehensions.

We will denote the set of strongly normalizing terms by

For strongly normalizing terms (and by extension for context instantiations containing only strongly normalizing terms), we can introduce the concept of maximal reduction length.

{defi}

[maximal reduction length]
Let
M\in\mathcal{S}\mathcal{N}
: we define
\nu(M)
as the maximum length of all reduction sequences starting with
M
. We also define
\nu(\eta)
as
\sum_{p\in\dom(\eta)}\nu(\eta(p))
, whenever all the terms in the codomain of
\eta
are strongly normalizing.

Since each term can only have a finite number of contracta, it is easy to see that
\nu(M)
is defined for any
strongly normalizing term
M
. Furthermore,
\nu(M)
is strictly decreasing under reduction.

Lemma 4
.

For all strongly normalizing terms
M
, if
M\mathrel{\leadsto}M^{\prime}
, then
\nu(M^{\prime})<\nu(M)
.

Proof 3.4
.

If
\nu(M^{\prime})\geq\nu(M)
, by pre-composing

with a reduction chain of maximal length starting at

we obtain a new reduction chain starting at

with length strictly greater than

; this contradicts the definition of
\nu(M)
.

3.2.
Renaming reduction

According to the Definitions
3.1
and
3.1
, in order for a context to be a continuation or an auxiliary continuation, it must on one hand agree with the respective grammar, and on the other hand satisfy the condition that no hole occurs more than once. We immediately see that, since holes can be duplicated under reduction, the sets of plain and auxiliary continuations are not closed under reduction. For instance:

K=\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M\cup N\mid x\leftarrow\mathop{\left[{p}\right]}}\mathclose{\textbf{\lx@text@rbrace}}\mathrel{\leadsto}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{M\mid x\leftarrow\mathop{\left[{p}\right]}}\mathclose{\textbf{\lx@text@rbrace}}\cup\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N\mid x\leftarrow\mathop{\left[{p}\right]}}\mathclose{\textbf{\lx@text@rbrace}}=C

where
K
is a continuation, but
C
is not due to the two occurrences of
\mathop{\left[{p}\right]}
.
For this reason, we introduce a refined notion of renaming reduction which we can use to rename holes in the results so that each of them occurs at most one time.

{defi}

Given a term
M
with holes and a finite map
\sigma:\mathcal{P}\to\mathcal{P}
, we write
M\sigma
for the term obtained from
M
by replacing each hole
\mathop{\left[{p}\right]}
such that
\sigma(p)
is defined with
\mathop{\left[{\sigma(p)}\right]}
.

Even though finite renaming maps are partial functions, it is
convenient to extend them to total functions by taking
\sigma(p)=p

whenever
p\notin\dom(\sigma)
; we will write
\mathsf{id}
to denote the empty renaming map, whose total extension is the identity function on
\mathcal{P}
.

{defi}

[renaming reduction]

M

\sigma
-reduces to
N
(notation:
M\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}N
) iff
M\mathrel{\leadsto}N\sigma
.

Terms only admit a finite number of redexes and consequently, under regular reduction, any given term has a finite number of possible contracta. However, under renaming reduction, infinite contracta are possible: if

M\mathrel{\leadsto}N
, there may be infinite
R,\sigma
such that

N=R\sigma
. When a strongly normalizing term
M
admits infinite contracta, it does not necessarily have a maximal reduction sequence (just like the maximum of an infinite set of finite numbers is not necessarily defined). Fortunately, we can prove (Lemma
6
) that to every renaming
reduction chain there corresponds a plain reduction chain of the same
length, and vice-versa.

Lemma 5
.

If
M\mathrel{\leadsto}N
, then for all
\sigma
we have
M\sigma\mathrel{\leadsto}N\sigma
.

Proof 3.5
.

Routine induction on the derivation of
M\mathrel{\leadsto}N
.

Lemma 6
.

For every finite plain reduction sequence, there is a corresponding renaming reduction sequence of the same length (using the identity renaming
\mathsf{id}
); and conversely, for every finite renaming reduction sequence, there is a corresponding plain reduction sequence of the same length involving renamed terms. More precisely:

(1)

If
M_{0}\mathrel{\leadsto}\cdots\mathrel{\leadsto}M_{n}
, then
M_{0}\mathrel{\stackrel{{\scriptstyle\mathsf{id}}}{{\leadsto}}}\cdots\mathrel{\stackrel{{\scriptstyle\mathsf{id}}}{{\leadsto}}}M_{n}

(2)

If
M_{0}\mathrel{\stackrel{{\scriptstyle\sigma_{1}}}{{\leadsto}}}\cdots\mathrel{\stackrel{{\scriptstyle\sigma_{n-1}}}{{\leadsto}}}M_{n-1}\mathrel{\stackrel{{\scriptstyle\sigma_{n}}}{{\leadsto}}}M_{n}
, then
M_{0}\mathrel{\leadsto}\cdots M_{n-1}\sigma_{n-1}\cdots\sigma_{1}\mathrel{\leadsto}M_{n}\sigma_{n}\cdots\sigma_{1}

Proof 3.6
.

The first part of the lemma is trivial. For the second part, proceed by induction on the length of the reduction chain: in the inductive case, we have
M_{0}\mathrel{\stackrel{{\scriptstyle\sigma_{1}}}{{\leadsto}}}\cdots\mathrel{\stackrel{{\scriptstyle\sigma_{n}}}{{\leadsto}}}M_{n}\mathrel{\stackrel{{\scriptstyle\sigma_{n+1}}}{{\leadsto}}}M_{n+1}
by hypothesis and
M_{0}\mathrel{\leadsto}\cdots\mathrel{\leadsto}M_{n}\sigma_{n}\cdots\sigma_{1}
by induction hypothesis; to obtain the thesis, we only need to prove that

M_{n}\sigma_{n}\cdots\sigma_{1}\mathrel{\leadsto}M_{n+1}\sigma_{n+1}\sigma_{n}\cdots\sigma_{1}

In order for this to be true, by Lemma
5
, it is sufficient to show that
M_{n}\mathrel{\leadsto}M_{n+1}\sigma_{n+1}
; this is by definition equivalent to
M_{n}\mathrel{\stackrel{{\scriptstyle\sigma_{n+1}}}{{\leadsto}}}M_{n+1}
, which we know by hypothesis.

Corollary 7
.

Suppose
M\in\mathcal{S}\mathcal{N}
: if
M\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}M^{\prime}
, then
\nu(M^{\prime})
is defined and
\nu(M^{\prime})<\nu(M)
.

Proof 3.7
.

By Lemma
6
, for any plain reduction chain there exists a renaming reduction chain of the same length, and vice-versa. Thus, since plain reduction lowers the length of the maximal reduction chain (Lemma
4
), the same holds for renaming reduction.

The results above prove that the set of strongly normalizing
terms is the same under the two notions of reduction, thus
\nu(M)

can be used to refer to the maximal length of reduction chains starting at
M

either with or without renaming.

Our goal is to describe the reduction of pure terms expressed in the form of applied continuations. One first difficulty we need to overcome is that, as we noted, the sets of continuations (both regular and auxiliary) are not closed under reduction: the duplication of holes performed by reduction will produce contexts that are not continuations or auxiliary continuations because they do not satisfy the condition of the linearity of holes. Thankfully, renaming reduction allows us to restore the linearity of holes, as we show in the following lemma.

Lemma 8
.

(1)

For all continuations
K
, if
K\mathrel{\leadsto}C
, there exist a continuation
K^{\prime}
and a finite map
\sigma
such that
K\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}K^{\prime}
and
K^{\prime}\sigma=C
.

(2)

For all auxiliary continuations
Q
, if
Q\mathrel{\leadsto}C
, there exist an auxiliary continuation
Q^{\prime}
and a finite map
\sigma
such that
Q\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}Q^{\prime}
and
Q^{\prime}\sigma=C
.

Furthermore, the
\sigma,K^{\prime},Q^{\prime}
in the statements above can be chosen so that
\dom(\sigma)
is fresh with respect to any given finite set of indices
\mathcal{S}
.

Proof 3.8
.

Let
\mathcal{S}
be a finite set of indices and

Remark 10
.

It is important to understand that, unlike all other operations on terms, context instantiation is not defined on the abstract syntax, independently of the particular choice of names, but on the concrete syntax. In other words, all operations and proofs that do not use context instantiation work on alpha-equivalence classes of terms; but when context instantiation is used, say on a context
C
, we need to choose a representative of the alpha-equivalence class of
C
.

Thanks to Lemma

, we may assume without loss of generality that the representative of the alpha-equivalence class of

is chosen so that if

, then
Q\eta\mathrel{\leadsto}C^{\prime}\eta
. Technically, we prove that there exist

such that

,
C^{\prime}=_{\alpha}D^{\prime}
,
\theta
is equal to
\eta
up to renaming, and
O\theta\mathrel{\leadsto}D^{\prime}\theta
, but after the context instantiation is completed, we return to consider terms as equal up to alpha-equivalence. The result will be used in the proof of the following Lemma

, where we have clarified the technical parts.

Finally, given a non-special renaming reduction

For all context instantiations

and renamings

,
we define

as the context instantiation such that:

•

then

•

in all other cases,
\eta^{\sigma}(p)=p
.

The results above allow us to express what happens when a reduction duplicates the holes in a continuation which is then combined with a context instantiation.

K^{\prime}_{M}
such that
C[M]=K^{\prime}_{M}[M]
and
K[M]\mathrel{\leadsto}K^{\prime}_{M}[M]
.

Since he does not have branching continuations and renaming reductions, whenever a hole is duplicated, e.g.

K=\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N_{1}\cup N_{2}|x\leftarrow\Box}\mathclose{\textbf{\lx@text@rbrace}}\mathrel{\leadsto}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N_{1}|x\leftarrow\Box}\mathclose{\textbf{\lx@text@rbrace}}\cup\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N_{2}|x\leftarrow\Box}\mathclose{\textbf{\lx@text@rbrace}}=C

he resorts to obtaining a continuation from

simply by filling one of the holes with the term

:

K^{\prime}_{M}=\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N_{1}|x\leftarrow M}\mathclose{\textbf{\lx@text@rbrace}}\cup\bigcup\mathopen{\textbf{\lx@text@lbrace}}{N_{2}|x\leftarrow\Box}\mathclose{\textbf{\lx@text@rbrace}}

Hence,

. Unfortunately, subsequent proofs rely on the fact that

must decrease under reduction: since we have no control over
\nu(M)
, which could potentially be much greater than

, it may be that

.

In our setting, by combining Lemmas

and

which is a proper contractum of

. By Lemma

, we get

, as required by subsequent proofs.

More generally, the following lemma will help us in performing case analysis on the reduction of an applied continuation.

(classification of reductions in applied continuations)
.

Suppose

Proof 3.12

By induction on

For all context instantiations

For all contexts

Proof 3.14

(Proof sketch)

Lemma 17
.

Let
C_{1},C_{2}
be contexts and
\eta_{1},\eta_{2}
context instantiations. Then for all free variables
x
and sets of hole indices
\mathcal{S}

D

D\theta\sigma=_{\alpha}(C_{1}\eta_{1})\left[{C_{2}\eta_{2}}\middle/{x}\right]

•

•

\theta
is permutable

Proof 3.15
.

The proof is by induction on the size of

, followed by a case analysis on its structure. Here we consider the variable cases, lambda as a template for binder cases, and application as a template for cases with multiple subterms.

•

If

, and

•

If

, then
\mathop{\left[{p}\right]}\left[{C_{2}}\middle/{x}\right]=\mathop{\left[{p}\right]}
and
\mathop{\left[{p}\right]}\eta_{1}\left[{C_{2}\eta_{2}}\middle/{x}\right]=\eta_{1}(p)\left[{C_{2}\eta_{2}}\middle/{x}\right]

•

If

(the empty instantiation),

•

If

and by induction hypothesis we get that there exist

D_{0}\sigma_{0}=_{\alpha}C_{0}^{*}\left[{C_{2}}\middle/{x}\right]

D_{0}\theta_{0}\sigma_{0}=_{\alpha}C_{0}^{*}\eta_{1}^{*}\left[{C_{2}\eta_{2}}\middle/{x}\right]
, where the holes in

,

\begin{array}[]{rll}D\sigma&=&(\lambda y^{*}.D_{0})\sigma_{0}\\

•

and

,

\begin{array}[]{rll}D\sigma&=&(D_{11}~D_{12})\sigma_{11}\sigma_{12}\\

Lemma 18
.

Let
C,C^{\prime}
be contexts such that
C\mathrel{\leadsto}C^{\prime}
; then, for all context instantiations
\eta
, there exist a context

, context instantiation
\theta
, and renaming

D\sigma=_{\alpha}C^{\prime}
(and consequently

Proof 3.16
.

By structural induction on the derivation of
C\mathrel{\leadsto}C^{\prime}
. The property we need to prove essentially states that any reduction of
C
can still be performed after applying any instantiation
\eta
;
however, due to variable capture and the possibility that some redexes of

We present here the two interesting cases of the proof:

•

(\lambda x.C_{1})~C_{2}\mathrel{\leadsto}C_{1}\left[{C_{2}}\middle/{x}\right]

•

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{C_{1}\mid x\leftarrow\bigcup\mathopen{\textbf{\lx@text@lbrace}}{C_{2}\mid y\leftarrow C_{3}}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}}\mathrel{\leadsto}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{C_{1}\mid y\leftarrow C_{3},x\leftarrow C_{2}}\mathclose{\textbf{\lx@text@rbrace}}

\bigcup\mathopen{\textbf{\lx@text@lbrace}}{C_{1}\mid y\leftarrow C_{3},x\leftarrow C_{2}}\mathclose{\textbf{\lx@text@rbrace}}=_{\alpha}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{C_{1}\mid y^{*}\leftarrow C_{3},x\leftarrow C^{*}_{2}}\mathclose{\textbf{\lx@text@rbrace}}

, we obtain contexts

The following result, like many others in the rest of this section, proceeds by well-founded induction; we will use the following notation to represent well-founded relations:

•

<
stands for the standard less-than relation on
\mathbb{N}
, which is well-founded;

•

\lessdot
is the lexicographic extension of
<
to
k

\mathbb{N}^{k}
(for a given

), also well-founded;

•

\prec
will be used to provide a decreasing metric that depends on the specific proof: such metrics are defined as subsets of
\lessdot

Lemma 19
.

Let
C
be a context and
\eta
a context instantiation such that
C\eta\in\mathcal{S}\mathcal{N}
. Then we have:

(1)

C\in\mathcal{S}\mathcal{N}

(2)

\nu(C)\leq\nu(C\eta)

(3)

for all
p\in\dom(\eta)
, if
\mathop{\left[{p}\right]}\in\FV(C)
, then
\eta(p)\in\mathcal{S}\mathcal{N}
.

Proof 3.17
.

Property 3 follows immediately by induction on
\nu(C\eta)
by noticing that, since
\mathop{\left[{p}\right]}\in\FV(C)
implies that
\eta(p)
appears as a subexpression of
C\eta
, and since reduction is defined by congruence closure, every reduction of
\eta(p)
can be mimicked by a corresponding reduction within
C\eta
.

To prove the first two properties, we proceed by well-founded induction on
(C,\eta)
using the metric:

(C_{1},\eta_{1})\prec(C_{2},\eta_{2})\iff\exists\sigma:C_{2}\eta_{2}\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}C_{1}\eta_{1}

We consider all the possible contractions
C\mathrel{\leadsto}C^{\prime}
. By Lemma
18
, we find
D,\sigma,\theta
such that
C\eta\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}D\theta
and
D\sigma=_{\alpha}C^{\prime}
;
consequently,
C\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}D
. By induction hypothesis we obtain
D\in\mathcal{S}\mathcal{N}
and
\nu(D)\leq\nu(D\theta)<\nu(C\eta)
; we easily prove
D\sigma=_{\alpha}C^{\prime}\in\mathcal{S}\mathcal{N}
and
\nu(C^{\prime})=\nu(D)
.
Furthermore, since
\nu(C)=1+\max_{C^{\prime}:C\mathrel{\leadsto}C^{\prime}}\nu(C^{\prime})
and for all such
C^{\prime}
we have proved
\nu(C^{\prime})<\nu(C\eta)
, we get
\nu(C)\leq\nu(C\eta)
.

A similar property about the composition of continuations and frames follows immediately.

Corollary 20
.

If
Q\mathop{\vtop{\halign{#\cr\hfil\raise 0.86108pt\hbox{$\scriptscriptstyle p$}\hfil\crcr{$\bigcirc$}\crcr}}}F\in\mathcal{S}\mathcal{N}
, then

and
\nu(Q)\leq\nu(Q\mathop{\vtop{\halign{#\cr\hfil\raise 0.86108pt\hbox{$\scriptscriptstyle p$}\hfil\crcr{$\bigcirc$}\crcr}}}F)
.

Proof 3.18
.

By definition,
Q\mathop{\vtop{\halign{#\cr\hfil\raise 0.86108pt\hbox{$\scriptscriptstyle p$}\hfil\crcr{$\bigcirc$}\crcr}}}F=Q[p\mapsto F^{p}]
: then we use Lemma
19
, with
\eta=[p\mapsto F^{p}]
.

Lemma 21
.

Let
Q
be an auxiliary continuation, and let
\eta,\theta
be context instantiations s.t. their union is permutable. If
Q\eta\in\mathcal{S}\mathcal{N}
and
Q\theta\in\mathcal{S}\mathcal{N}
, then
Q\eta\theta\in\mathcal{S}\mathcal{N}
.

Proof 3.19
.

We assume that
\dom(\eta)\cup\dom(\theta)\subseteq\supp(Q)
(otherwise, we can find strictly smaller permutable
\eta^{\prime},\theta^{\prime}
such that
Q\eta\theta=Q\eta^{\prime}\theta^{\prime}
, and their domains are subsets of
\supp(Q)
). We show
Q\eta\in\mathcal{S}\mathcal{N}
and
Q\theta\in\mathcal{S}\mathcal{N}
imply
Q\in\mathcal{S}\mathcal{N}
,
\eta\in\mathcal{S}\mathcal{N}
and
\theta\in\mathcal{S}\mathcal{N}
; thus we can then prove the theorem by well-founded induction on
(Q,\eta,\theta)
using the following metric:

(Q_{1},\eta_{1},\theta_{1})\prec(Q_{2},\eta_{2},\theta_{2})\iff(\nu(Q_{1}),\left\|Q_{1}\right\|,\nu(\eta_{1})+\nu(\theta_{1}))\lessdot(\nu(Q_{2}),\left\|Q_{2}\right\|,\nu(\eta_{2})+\nu(\theta_{2}))

We show that all of the possible contracta of

are s.n. by case analysis on the contraction:

•

Q^{\prime}\eta^{\sigma}\theta^{\sigma}
, where
Q\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}Q^{\prime}
: it is easy to see that
\nu(\eta^{\sigma})
and
\nu(\theta^{\sigma})
are defined because
\nu(\eta)
and
\nu(\theta)
are; then the thesis follows from the induction hypothesis, knowing that

(Lemma

).

•

Q^{\prime}\eta^{*}\theta^{*}
where
Q^{\prime}=Q_{1}[q\mapsto Q_{2}\left[{\overline{L}}\middle/{x}\right]]
, for some

such that
Q=(Q_{1}\mathop{\vtop{\halign{#\cr\hfil\raise 0.86108pt\hbox{$\scriptscriptstyle q$}\hfil\crcr{$\bigcirc$}\crcr}}}\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\Box\mid x\leftarrow\mathopen{\textbf{\lx@text@lbrace}}{\overline{L}}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}})[q\mapsto Q_{2}]
and
\eta^{*}(p)=\eta(p)\left[{\overline{L}}\middle/{x}\right]
,
\theta^{*}(p)=\theta(p)\left[{\overline{L}}\middle/{x}\right]
for all
p\in\supp(Q_{2})
, otherwise
\eta^{*}(p)=\eta(p)
and
\theta^{*}(p)=\theta(p)
; since
Q\mathrel{\leadsto}Q^{\prime}
, we know
\nu(Q^{\prime})<\nu(Q)
; furthermore, since
Q\eta\mathrel{\leadsto}Q^{\prime}\eta^{*}
and
Q\eta\in\mathcal{S}\mathcal{N}
, it is easy to see that
Q^{\prime}\eta^{*}\in\mathcal{S}\mathcal{N}
and
\nu(\eta^{*})
is defined; similarly,
Q^{\prime}\theta^{*}\in\mathcal{S}\mathcal{N}
and
\nu(\theta^{*})
is defined; then
Q^{\prime}\eta^{*}\theta^{*}\in\mathcal{S}\mathcal{N}
by induction hypothesis.

•

Q\eta^{\prime}\theta
, where
\eta\mathrel{\leadsto}\eta^{\prime}
: the thesis follows by induction hypothesis, knowing
\nu(\eta^{\prime})<\nu(\eta)
(Lemma
4
).

•

Q_{0}[p\mapsto N]\eta_{0}\theta
where
Q=Q_{0}\mathop{\vtop{\halign{#\cr\hfil\raise 0.86108pt\hbox{$\scriptscriptstyle p$}\hfil\crcr{$\bigcirc$}\crcr}}}F
,
\eta=[p\mapsto M]\eta_{0}
, and

by means of a reduction at the interface.
By Lemma
20
we know
\nu(Q_{0})\leq\nu(Q)
; by Lemma
3
we prove
\left\|Q_{0}\right\|<\left\|Q\right\|
. We take
\eta^{\prime}=[p\mapsto N]\eta_{0}
: since

reduces to

and both terms are strongly normalizing, we have that
\nu(\eta^{\prime})
is defined. Then we observe

and obtain the thesis by induction hypothesis. A symmetric case with

is proved similarly.

Corollary 22
.

Q[p\mapsto M]^{\sigma}\in\mathcal{S}\mathcal{N}
iff for all

.

By the definition of

3.3.
Candidates of reducibility

We here define the notion of
candidates of reducibility
: sets of strongly normalizing terms enjoying certain closure properties that can be used to overapproximate the sets of terms of a certain type. Our version of candidates for
\mathit{NRC}_{\lambda}
is a straightforward adaptation of the standard definition given by Girard and like that one is based on a notion of
neutral terms
, i.e. those terms that, when placed in an arbitrary context, do not create additional redexes.

{defi}

[neutral term]
A term
M
is
neutral
if it belongs to the following grammar:

W\mathrel{::=}x\mathbin{~|~}c(\overrightarrow{M_{n}})\mathbin{~|~}M.\ell\mathbin{~|~}(M~N)\mathbin{~|~}\mathtt{\color{blue}empty}~M

where
n\geq 1
.

The set of neutral terms is denoted by
\mathcal{N}\mathcal{T}
.

Let us introduce the following notation for Girard’s CRx properties of sets
[
GLT89
]
:

•

\mathrm{CR1}(\mathcal{C})\triangleq\mathcal{C}\subseteq\mathcal{S}\mathcal{N}

•

\mathrm{CR2}(\mathcal{C})\triangleq\forall M\in\mathcal{C},\forall M^{\prime}.M\mathrel{\leadsto}M^{\prime}\mathrel{\Longrightarrow}M^{\prime}\in\mathcal{C}

•

\mathrm{CR3}(\mathcal{C})\triangleq\forall M\in\mathcal{N}\mathcal{T}.(\forall M^{\prime}.M\mathrel{\leadsto}M^{\prime}\mathrel{\Longrightarrow}M^{\prime}\in\mathcal{C})\mathrel{\Longrightarrow}M\in\mathcal{C}

The set
\mathcal{C}\mathcal{R}
of the candidates of reducibility is then defined as the collection of those sets of terms which satisfy all the CRx properties. Some standard results include the non-emptiness of candidates (in particular, all free variables are in every candidate) and that
\mathcal{S}\mathcal{N}\in\mathcal{C}\mathcal{R}
.

3.4.
Reducibility sets

In this section we introduce
reducibility sets
, which are sets of terms that we will use to provide an interpretation of the types of
\mathit{NRC}_{\lambda}
; we will then prove that reducibility sets are candidates of reducibility, hence they only contain strongly normalizing terms.
The following notation will be useful as a shorthand for certain operations on sets of terms that are used to define reducibility sets:

•

\mathcal{C}\to\mathcal{D}\triangleq\{{M:\forall N\in\mathcal{C},(M~N)\in\mathcal{D}}\}

•

\langle{\overrightarrow{\ell_{k}:\mathcal{C}_{k}}}\rangle\triangleq\{{M:\forall i=1,\ldots,k,M.\ell_{i}\in\mathcal{C}_{i}}\}

•

\mathcal{C}_{p}^{\top}\triangleq\{{K:\forall M\in\mathcal{C}.K[p\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}}\}

•

\mathcal{C}^{\top\top}\triangleq\{{M:\forall p,\forall K\in\mathcal{C}_{p}^{\top},K[p\mapsto M]\in\mathcal{S}\mathcal{N}}\}

The sets
\mathcal{C}_{p}^{\top}
and
\mathcal{C}^{\top\top}
are called the
\top
-lifting
and
\top\top
-lifting
of
\mathcal{C}
. These definitions refine the ones used in the literature by using indices:
\top
-lifting is defined with respect to a given index
p
, while the definition of
\top\top
-lifting uses any index (in the standard definitions, continuations only contain a single hole, and no indices are mentioned).

{defi}

[reducibility]
For all types
T
, the set
\mathsf{Red}_{T}
of reducible terms of type
T
is defined by recursion on
T
by means of the rules:

\begin{array}[]{rclcrcl}\mathsf{Red}_{A}&\triangleq&\mathcal{S}\mathcal{N}&&\mathsf{Red}_{S\to T}&\triangleq&\mathsf{Red}_{S}\to\mathsf{Red}_{T}\\
\mathsf{Red}_{\langle{\overrightarrow{\ell_{k}:T_{k}}}\rangle}&\triangleq&\langle{\overrightarrow{\ell_{k}:\mathsf{Red}_{T_{k}}}}\rangle&&\mathsf{Red}_{\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}}&\triangleq&\mathsf{Red}_{T}^{\top\top}\end{array}

Let us use metavariables
\mathcal{S},\mathcal{S}^{\prime},\ldots
to denote finite sets of indices: we provide a refined notion of
\top
-lifting
\mathcal{C}_{\mathcal{S}}^{\top}
depending on a set of indices rather than a single index, defined by pointwise intersection. This notation is useful to track a
\top
-lifted candidate under renaming reduction.

{defi}

\mathcal{C}_{\mathcal{S}}^{\top}\triangleq\bigcap_{p\in\mathcal{S}}\mathcal{C}_{p}^{\top}
.

{defi}

Let
\mathcal{C}
and
\mathcal{S}
be sets of terms and indices respectively, and
\sigma
a finite renaming: then we define
(\mathcal{C}_{\mathcal{S}}^{\top})^{\sigma}:=\mathcal{C}_{\sigma^{-1}(\mathcal{S})}^{\top}
, where
\sigma^{-1}(\mathcal{S})=\{{q:\sigma(q)\in\mathcal{S}}\}

We now proceed with the proof that all the sets
\mathsf{Red}_{T}
are candidates of reducibility: we will only focus on collections since for the other types the result is standard. The proofs of
\mathrm{CR1}
and
\mathrm{CR2}
do not differ much from the standard
\top\top
-lifting technique.

Lemma 23
.

Suppose
\mathrm{CR1}(\mathcal{C})
: then for all indices
p,q
,
\mathop{\left[{p}\right]}\in\mathcal{C}_{q}^{\top}
.

Proof 3.21
.

To prove the lemma, it is sufficient to show that for all
M\in\mathcal{C}
we have
\mathop{\left[{p}\right]}[q\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}
. This term is equal to either
\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}
(if
p=q
) or to
\mathop{\left[{p}\right]}
(otherwise); both terms are s.n. (in the case of
\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}
, this is because
\mathrm{CR1}
holds for
\mathcal{C}
, thus
M\in\mathcal{S}\mathcal{N}
).

Lemma 24

(CR1 for continuations)
.

For all
p
and all non-empty
\mathcal{C}
,
\mathcal{C}_{p}^{\top}\subseteq\mathcal{S}\mathcal{N}
.

Proof 3.22
.

We assume
K\in\mathcal{C}_{p}^{\top}
and
M\in\mathcal{C}
: by definition, we know that
K[p\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}
; then we have
K\in\mathcal{S}\mathcal{N}
by Lemma
19
.

Lemma 25

(CR1 for collections)
.

If
\mathrm{CR1}(\mathcal{C})
, then
\mathrm{CR1}(\mathcal{C}^{\top\top})
.

Proof 3.23
.

We need to prove that if
M\in\mathcal{C}^{\top\top}
, then
M\in\mathcal{S}\mathcal{N}
. By the definition of
\mathcal{C}^{\top\top}
, we know that for all
p
,
K[p\mapsto M]\in\mathcal{S}\mathcal{N}
whenever
K\in\mathcal{C}_{p}^{\top}
. Now assume any
p
, and by Lemma
23
choose
K=\mathop{\left[{p}\right]}
: then
K[p\mapsto M]=M\in\mathcal{S}\mathcal{N}
, which proves the thesis.

Lemma 26

(CR2 for collections)
.

If
M\in\mathcal{C}^{\top\top}
and
M\mathrel{\leadsto}M^{\prime}
, then
M^{\prime}\in\mathcal{C}^{\top\top}
.

Proof 3.24
.

Let
p
be an index, and take
K\in\mathcal{C}_{p}^{\top}
: we need to prove
K[p\mapsto M^{\prime}]\in\mathcal{S}\mathcal{N}
. By the definition of
M\in\mathcal{C}^{\top\top}
, we have
K[p\mapsto M]\in\mathcal{S}\mathcal{N}
; if
p\notin\supp(K)
,
K[p\mapsto M^{\prime}]=K[p\mapsto M]
and the thesis trivially holds; otherwise the instantiation is effective and we have
K[p\mapsto M]\mathrel{\leadsto}K[p\mapsto M^{\prime}]
, and this last term, being a contractum of a strongly normalizing term, is strongly normalizing as well. This proves the thesis.

In order to prove
\mathrm{CR2}
for all types (and particularly for collections), we do not need to establish an analogous property on continuations; however such a property is still useful for subsequent results (particularly
\mathrm{CR3}
). Its statement must, of course, consider that reduction may duplicate (or indeed delete) holes, and thus employs renaming reduction. We can show that whenever we need to prove a statement about
n
-ary permutable instantiations of
n
-ary continuations, we can simply consider each hole separately, as stated in the following lemma.

Lemma 27
.

K\in(\mathcal{C}_{\mathcal{S}}^{\top})^{\sigma}
if, and only if, for all
q\in\sigma^{-1}(\mathcal{S})
, we have
K\in\mathcal{C}_{q}^{\top}
.

In particular,
K\in(\mathcal{C}_{p}^{\top})^{\sigma}
if, and only if, for all
q
s.t.
\sigma(q)=p
, we have
K\in\mathcal{C}_{q}^{\top}
.

Proof 3.25
.

By definition of
(\cdot)^{\sigma}
and
(\cdot)^{\top}
:

K\in(\mathcal{C}^{\top}_{\mathcal{S}})^{\sigma}\iff K\in\mathcal{C}^{\top}_{\sigma^{-1}(\mathcal{S})}\iff K\in\bigcap_{q\in\sigma^{-1}(\mathcal{S})}\mathcal{C}^{\top}_{q}\iff\forall q\in\sigma^{-1}(\mathcal{S}),K\in\mathcal{C}^{\top}_{q}

Lemma 28

(CR2 for continuations)
.

If
K\in\mathcal{C}_{\mathcal{S}}^{\top}
and
K\mathrel{\stackrel{{\scriptstyle\sigma}}{{\leadsto}}}K^{\prime}
, then
K^{\prime}\in(\mathcal{C}_{\mathcal{S}}^{\top})^{\sigma}
.

Proof 3.26
.

By Lemma
27
and the definition of
(\cdot)^{\top}
, it suffices to prove that
K^{\prime}[q\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}
for all

such that

and

.
Then we know
K[\sigma(q)\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}
, and consequently
K^{\prime}[\sigma(q)\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]^{\sigma}\in\mathcal{S}\mathcal{N}
as well, since the latter is a contractum of the former; finally, by Corollary

K^{\prime}[q\mapsto\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}]\in\mathcal{S}\mathcal{N}

This is everything we need to prove

Lemma 29

(CR3 for collections)
.

Let

, and

Proof 3.27
.

By definition, we need to prove

whenever

for some index

. By Lemma

, knowing that

Equivalently, we prove that all the contracta of

•

(where

): to prove this term is s.n., by Corollary

K^{\prime}[q^{\prime}\mapsto M]\in\mathcal{S}\mathcal{N}
whenever

K[p\mapsto M^{\prime}]
(where

Theorem 30
.

For all types

,

.

Proof 3.28
.

Standard by induction on

. For

4.
Strong normalization

We have proved that the reducibility sets of all types are candidates of reducibility. We are now going to prove that every well-typed term is in the reducibility set corresponding to its type: strong normalization will then follow as a corollary, by using the
\mathrm{CR1}
property of candidates of reducibility.

The proof that well-typed terms are reducible is by structural induction on the derivation of the typing judgment. We will proceed by first proving lemmas that show the typing rules preserve reducibility, concluding at the end with the fundamental theorem.
Once again, we will focus our attention on the results corresponding to collection types, as the rest are standard.

Reducibility of singletons is trivial by definition, while that of empty collections is proved
in the same style as
[
Coo09a
]
, with the obvious adaptations.

Lemma 31

(reducibility for singletons)
.

For all
\mathcal{C}
, if
M\in\mathcal{C}
, then
\mathopen{\textbf{\lx@text@lbrace}}{M}\mathclose{\textbf{\lx@text@rbrace}}\in\mathcal{C}^{\top\top}
.

Proof 4.1
.

Trivial by definition of
\top
-lifting and
\top\top
-lifting.

Lemma 32
.

If
K\in\mathcal{S}\mathcal{N}
is a continuation, then for all indices
p
we have
K[p\mapsto\emptyset]\in\mathcal{S}\mathcal{N}
.

Corollary 33

(reducibility for
\emptyset
)
.

For all
\mathcal{C}
,
\emptyset\in\mathcal{C}^{\top\top}
.

As for unions, we will prove a more general statement on auxiliary continuations.

Lemma 34
.

For all auxiliary continuations
Q,O_{1},O_{2}
with pairwise disjoint supports, if
Q[p\mapsto O_{1}]\in\mathcal{S}\mathcal{N}
and

.

The proof of the lemma above follows the same style as
[
Coo09a
]
; however since our definition of auxiliary continuations is more general, the theorem statement mentions

rather than pure terms: the hypothesis on the supports of the continuations being disjoint is required by this generalization.

Corollary 35

(reducibility for unions)
.

If
M\in\mathcal{C}^{\top\top}
and
N\in\mathcal{C}^{\top\top}
, then
M\mathbin{\cup}N\in\mathcal{C}^{\top\top}
.

In some of the following proofs, a result that mirrors Lemma

Lemma 36
.

If
Q[p\mapsto M\mathbin{\cup}N]\in\mathcal{S}\mathcal{N}
, then
Q[p\mapsto M]\in\mathcal{S}\mathcal{N}
and
Q[p\mapsto N]\in\mathcal{S}\mathcal{N}
; furthermore, we have:

\displaystyle\nu(Q[p\mapsto M])\leq\nu(Q[p\mapsto M\mathbin{\cup}N])

\displaystyle\nu(Q[p\mapsto N])\leq\nu(Q[p\mapsto M\mathbin{\cup}N])

Proof 4.2
.

We assume
p\in\supp(Q)
(otherwise,
Q[p\mapsto M]=Q[p\mapsto N]=Q[p\mapsto M\mathbin{\cup}N]
, and the thesis holds trivially), then we show that any contraction in
Q[p\mapsto M]
has a corresponding non-empty reduction sequence in
Q[p\mapsto M\mathbin{\cup}N]
, and the two reductions preserve the term form, therefore no reduction sequence of
Q[p\mapsto M]
is longer than the maximal one in
Q[p\mapsto M\mathbin{\cup}N]
. The same reasoning applies to
Q[p\mapsto N]
.

Like in proofs based on standard
\top\top
-lifting, the most challenging cases are those dealing with commuting conversions – in our case, comprehensions and conditionals.

Lemma 37
.

Let

,

,

.

In this proof, we assume the names of bound variables are chosen so as to avoid duplicates, and are distinct from the free variables. We proceed by well-founded induction on

\begin{array}[]{l}(K_{1},p_{1},\overline{N_{1}},\overline{L_{1}})\prec(K_{2},p_{2},\overline{N_{2}},\overline{L_{2}})\\

(because

K[p\mapsto\emptyset]

•

(for

K_{0}[p\mapsto\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\bigcup\mathopen{\textbf{\lx@text@lbrace}}{\overline{M}|y\leftarrow\overline{N}}\mathclose{\textbf{\lx@text@rbrace}}|x\leftarrow\mathopen{\textbf{\lx@text@lbrace}}{\overline{L}}\mathclose{\textbf{\lx@text@rbrace}}}\mathclose{\textbf{\lx@text@rbrace}}]
, where

5.
Heterogeneous Collections

SQL allows a user to write queries that will evaluate to relations that are bags of tuples by means of constructs including
{\color{blue}\mathtt{SELECT}}
statements and
{\color{blue}\mathtt{UNION}}~{\color{blue}\mathtt{ALL}}
operations; additionally, it also allows constructs like
{\color{blue}\mathtt{SELECT}}~{\color{blue}\mathtt{DISTINCT}}
and
{\color{blue}\mathtt{UNION}}
to produce sets of tuples (more precisely, bags without duplicates); both kinds of constructs can be freely mixed in the same query. In contrast, the language
\mathit{NRC}_{\lambda}
we have discussed in the previous sections can only deal with one kind of collection (either sets or bags).

In a short paper
[
RC19
]
, we introduced a generalization of
\mathit{NRC}
called

\mathit{NRC}(\mathit{Set},\mathit{Bag})
that makes up for this shortcoming by allowing both set-valued and bag-valued
collections (with distinct types denoted by
\mathopen{\textbf{\lx@text@lbrace}}{T}\mathclose{\textbf{\lx@text@rbrace}}
and
\Lbag{T}\Rbag
),
along with mappings from bags to sets (deduplication
\delta
) and
from sets to bags (promotion
\iota
). We conjectured that this
language also satisfies a normalization property, allowing its normal forms to be translated to SQL. Here, we prove that
\mathit{NRC}(\mathit{Set},\mathit{Bag})
is, indeed, strongly normalizing,
even when extended to a richer language
\mathit{NRC}_{\lambda}(\mathit{Set},\mathit{Bag})
with
higher-order (nonrecursive) functions. Its syntax is a straightforward extension of
\mathit{NRC}_{\lambda}
:

\begin{array}[]{lrcl}\mathbf{types}&S,T&::=&\ldots\mathbin{~|~}\Lbag{T}\Rbag\\
\mathbf{terms}&L,M,N&::=&\ldots\mathbin{~|~}\mho\mathbin{~|~}\Lbag{M}\Rbag\mathbin{~|~}M\uplus N\mathbin{~|~}\biguplus\Lbag{M|x\leftarrow N}\Rbag\\
&&\mathbin{~|~}&\mathtt{\color{blue}where}_{\mathsf{bag}}~M~\mathtt{\color{blue}do}~N\mathbin{~|~}\delta M\mathbin{~|~}\iota M\end{array}

We use
\Lbag{T}\Rbag
to denote the type of bags containing elements of type
T
; similarly, the notations
\mho
,
\Lbag{M}\Rbag
,
M\uplus N
,

\biguplus\Lbag{M|x\leftarrow N}\Rbag
denote
empty and singleton bags,
bag disjoint union and bag comprehension; the language also includes conditionals on bags. The notations
\iota M
and
\delta N
stand, respectively, for the bag containing exactly one copy of each element of the set
M
, and for the set containing the elements of the bag
N
, forgetting about their multiplicity. We do not need to provide a primitive emptiness test for bags, since it can be defined anyway as
\mathtt{\color{blue}empty}_{\mathsf{bag}}~M:=\mathtt{\color{blue}empty}~\delta M
.

The simplified language

5.2.
Reducibility for
\mathit{NRC}_{\lambda\delta\iota}

We are now going to present an extension of the strong normalization proof for
\mathit{NRC}_{\lambda}
, allowing us to derive the same result for
\mathit{NRC}_{\lambda\delta\iota}
(and, consequently, for
\mathit{NRC}_{\lambda}(\mathit{Set},\mathit{Bag})
). Concretely, this extension involves adding some extra cases to some definitions and proofs; in a single case, we need to strengthen the statement of a lemma, whose proof remains otherwise close to its
\mathit{NRC}_{\lambda}
version.

For
\mathit{NRC}_{\lambda\delta\iota}
continuations and frames, we will allow extra cases including
\delta
and
\iota
, as follows:

\displaystyle K,H::=

\displaystyle\ldots\mathbin{~|~}\delta K\mathbin{~|~}\iota K

\displaystyle Q,O::=

\displaystyle\ldots\mathbin{~|~}\delta Q\mathbin{~|~}\iota Q

\displaystyle F::=

\displaystyle\ldots\mathbin{~|~}\delta\Box\mathbin{~|~}\iota\Box

We also extend the measures
\left|Q\right|_{p}
and

to account for the new cases.

{defi}
[extends
3.1
]
The measures
\left|Q\right|_{p}
and
\left\|Q\right\|_{p}
of
\mathit{NRC}_{\lambda}
are extended to

by means of the following additional cases:

\left|\delta Q\right|_{p}=\left|\iota Q\right|_{p}=\left|Q\right|_{p}+1\qquad\left\|\delta Q\right\|_{p}=\left\|\iota Q\right\|_{p}=\left\|Q\right\|_{p}+1

Renaming reduction in
\mathit{NRC}_{\lambda\delta\iota}
is defined in the same way as its
\mathit{NRC}_{\lambda}
counterpart.

We notice that terms in the form
\delta M

{defi}
[extends
3.3
]

\mathit{NRC}_{\lambda}
is extended to
\mathit{NRC}_{\lambda\delta\iota}
by means of the following additional production:

Since the type sublanguage of
\mathit{NRC}_{\lambda\delta\iota}
is the same as in
\mathit{NRC}_{\lambda}
, we can

reuse the definition of reducibility sets: however, it is intended that the terms and continuations appearing in these definitions are those of
\mathit{NRC}_{\lambda\delta\iota}
rather than
\mathit{NRC}_{\lambda}
. Similarly, the various technical lemmas involving contexts, continuations and instantiations use a uniform proof style that works seamlessly in
\mathit{NRC}_{\lambda\delta\iota}
; however, it is worth mentioning that Lemma

holds because the definitions of the measures

,

just like in
\mathit{NRC}_{\lambda}
; and that the proof of Lemma

in the reduction at the interface. The proofs showing that all the reducibility sets are candidates (Lemmas

6.
Related Work

This paper builds on a long line of research on normalization of
comprehension queries, a model of query languages popularized over 25
years ago by Buneman et al.
[
BNTW95
]
and inspired by Trinder and Wadler’s
work on comprehensions
[
TW89
,
Wad92
]
. Wong
[
Won96
]

proved conservativity via a strongly normalizing rewrite system, which
was used in
Kleisli
[
Won00
]
, a functional query
system, in which flat query expressions were normalized to SQL.
Libkin and Wong
[
LW94
,
LW97
]
investigated conservativity in the
presence of aggregates, internal generic functions, and bag
operations, and demonstrated that bag operations can be expressed
using nested comprehensions. However, their normalization results
studied bag queries by translating to relational queries with
aggregation, and did not consider higher-order queries, so they do not
imply the normalization results for
NRC_{\lambda}(Set,Bag)

given here.

Cooper
[
Coo09b
]
first investigated query normalization (and
hence conservativity) in the presence of higher-order functions. He
gave a rewrite system showing how to normalize homogeneous (that is,
pure set or pure bag) queries to eliminate intermediate occurrences of
nesting or of function types. However, although Cooper
claimed a proof (based on
\top\top
-lifting
[
LS05
]
) and
provided proof details in his PhD thesis
[
Coo09a
]
, there
unfortunately turned out to be a nontrivial lacuna in that proof, and
this paper therefore (in our opinion) contains the first

complete
proof of normalization for higher-order queries, even
for the homogeneous case.

Admittedly, our approach is sometimes difficult to work with: the difficulty lies with the notion of (variable capturing) context, along with rewrite rules involving substitutions and renaming of bound variables, as we noted in Section
3
; for this reason, it would be interesting to consider alternatives. The complexity of computing with contexts has been the object of research in higher-order rewriting and higher-order abstract syntax techniques (
[
vv06
,
PE88
]
). Another approach that could be more easily adapted to our scenario is to extend the language to allow hole variables to be decorated with explicit substitutions (
[
ACCL91
]
). In Section
3
we have shown that if an unapplied context reduces in a certain way, the same reduction does not have to be allowed when the context is applied to an instantiation. The simplest example we have shown of this phenomenon is:

\begin{array}[]{c}(\lambda z.\mathop{\left[{p}\right]})~N\mathrel{\leadsto}\mathop{\left[{p}\right]}\\
\text{but}\\
((\lambda z.\mathop{\left[{p}\right]})~N)[p\mapsto z]\not\mathrel{\leadsto}\mathop{\left[{p}\right]}[p\mapsto z]\end{array}

The reason for this discrepancy lies in the fact that while beta reduction yields a substitution replacing
z
with
N
, once this substitution meets the hole
\mathop{\left[{p}\right]}
, it is completely lost. If we replaced the meta-operation of substitution with new syntax
L\langle{x:=M}\rangle
denoting a (suspended) explicit substitution that will eventually replace with
M
all the free occurrences of
x
within
L
, we could write:

\begin{array}[]{c}(\lambda z.\mathop{\left[{p}\right]})~N\mathrel{\leadsto}\mathop{\left[{p}\right]}\langle{z:=N}\rangle\\
\text{and}\\
((\lambda z.\mathop{\left[{p}\right]})~N)[p\mapsto z]\mathrel{\leadsto}\mathop{\left[{p}\right]}\langle{z:=N}\rangle[p\mapsto z]=z\langle{z:=N}\rangle\end{array}

where the final term correctly reduces to
N
.
Holes with explicit substitutions have been studied in the context of dependently-typed lambda calculi, where they are more often known as
metavariables
, with applications to proof assistants (
[
Muñ01
]
).
We could study strong normalization in such an extended calculus,
however explicit substitutions are known to require a careful treatment of reduction for them to simultaneously preserve
confluence and strong normalization (see
[
Mel95
]
for a counterexample); more recent explicit substitution
calculi (e.g.
[
DG01
,
KL05
]
) often employ ideas from linear logic to ensure strong normalization is preserved.

Another approach, introduced by Bognar and De Vrijer, employs a
context calculus
(
[
BdV01
]
), i.e. an extension of the lambda calculus with additional operators to express context-building and instantiation, along with interfaces describing the evolution of contexts under reduction (“communication”). Under this approach, the context
(\lambda z.\mathop{\left[{p}\right]})~N
would be expressed as

\delta\mathop{\left[{p}\right]}.(\lambda z.\mathop{\left[{p}\right]}\langle{z}\rangle)~N

where the operator
\delta\mathop{\left[{p}\right]}.-
(unrelated to the deduplication operator of Section
5
) builds a context by abstracting over a hole variable
\mathop{\left[{p}\right]}
, and the syntax
\mathop{\left[{p}\right]}\langle{z}\rangle
expresses the fact that once
\mathop{\left[{p}\right]}
is instantiated with a term, this term will communicate with the context by means of the (captured) variable
z
. The term
z
to be plugged into the context would be represented as

\Lambda z.z

where the abstraction
\Lambda z.-
is provided to express the fact that this term can communicate with the context over the variable
z
. To apply this term to the context, we use the syntax
-\lceil-\rceil
:

(\delta\mathop{\left[{p}\right]}.(\lambda z.\mathop{\left[{p}\right]}\langle{z}\rangle)~N)\lceil\Lambda z.z\rceil

Here as well, we are allowed to beta reduce the context both in the unapplied and in the applied form:

\begin{array}[]{c}\delta\mathop{\left[{p}\right]}.(\lambda z.\mathop{\left[{p}\right]}\langle{z}\rangle)~N\mathrel{\leadsto}\delta\mathop{\left[{p}\right]}.\mathop{\left[{p}\right]}\langle{N}\rangle\\
\text{and}\\
(\delta\mathop{\left[{p}\right]}.(\lambda z.\mathop{\left[{p}\right]}\langle{z}\rangle)~N)\lceil\Lambda z.z\rceil\mathrel{\leadsto}(\delta\mathop{\left[{p}\right]}.\mathop{\left[{p}\right]}\langle{N}\rangle)\lceil\Lambda z.z\rceil\end{array}

where the final term can be further reduced to
(\Lambda z.z)\langle{N}\rangle
, and finally to
N
, as expected. Like explicit substitutions, the context calculus allows contexts to be reduced independently of an applied instantiation, potentially simplifying technical results such as those of Lemma
9
and
18
. Both techniques require fairly important extension to the language, type system and rewrite system, and will be considered in future work.

Since the fundamental work of Wong and others on the Kleisli system,
language-integrated query has gradually made its way into other
systems, most notably Microsoft’s .NET framework languages C# and F#
[
MBB06
]
, and the Web programming language Links
[
CLWY07
]
. Cheney et al.
[
CLW13
]

formally investigated the F# approach to language-integrated query
and showed that normalization results due to Wong and Cooper could be
adapted to improve it further; however, their work considered only
homogeneous collections. In subsequent work, Cheney et al.
[
CLW14
]
showed how
use normalization to perform
query shredding
for multiset queries, in which a
query returning a type with
n
nested collections can be implemented
by combining the results of
n
flat queries; this has been
implemented in Links
[
CLWY07
]
.

Higher-order relational queries have also been studied by Benedikt et
al.
[
BPV15
]
, where the focus was mostly on complexity of
the evaluation and containment problems. Their calculus focuses on
higher-order expressions composing operations over
flat

relational algebra operators only, where the base types are records
listing the fields of the relations. Thus, modulo notational
differences, their calculus is a sublanguage of
\mathit{NRC}
. In their setting, normalization up to
\beta
-reduction follows as a special
case of normalization for typed lambda-calculus; in our setting
the same approach would not work because collection and record types
can be combined arbitrarily in
\mathit{NRC}
and normalization involves rules
that nontrivially rearrange comprehensions and other collection operations.

Several recent efforts to formalize and reason about the semantics of
SQL are complementary to our work. Guagliardo and
Libkin
[
GL17
]
presented a semantics for SQL’s actual
behaviour in the presence of set and multiset operators (including bag
intersection and difference) as well as
incomplete information (nulls), and related the expressiveness of this
fragment of SQL with that of an algebra over bags with nulls. Chu et
al.
[
CWCS17
]
presented a formalized semantics for reasoning about
SQL (including set and bag semantics as well as aggregation/grouping,
but excluding nulls) using nested relational queries in Coq, while
Benzaken and Contejean
[
BC19
]
presented a semantics
including all of these SQL features (set, multiset,
aggregation/grouping, nulls), and formalized the semantics in Coq.
Kiselyov et al.
[
KK17
]
has proposed
language-integrated query techniques that handle sorting operations
(SQL’s
{\color{blue}\mathtt{ORDER}}~{\color{blue}\mathtt{BY}}
).

However, the above work on semantics has not considered query
normalization, and to the best of our knowledge normalization results
for query languages with more than one collection type were previously
unknown even in the first-order case. We are interested in extending
our results for mixed set and bag semantics to handle nulls,
grouping/aggregation, and sorting, thus extending higher-order
language integrated query to cover all of the most widely-used SQL
features. Normalization of higher-order
queries in the presence of all of these features simultaneously
remains an open problem, which we plan to consider next. In addition,
fully formalizing such normalization proofs also appears to be a
nontrivial challenge.

7.
Conclusions

Integrating database queries into programming languages has many
benefits, such as type safety and avoidance of common SQL injection
attacks, but also imposes limitations that prevent programmers from
constructing queries dynamically as they could by concatenating SQL
strings unsafely. Previous work has demonstrated that many useful
dynamic queries can be constructed safely using
higher-order
functions
inside language-integrated queries; provided such
functions are not recursive, it was believed, query expressions can be
normalized. Moreover, while it is common in practice for
language-integrated query systems to provide
support for SQL features such as mixed set and bag operators, it is
not well understood in theory how to normalize these queries in the
presence of higher-order functions.
Previous work on higher-order query normalization has considered only
homogeneous (that is, pure set or pure bag) queries, and in the
process of attempting to generalize this work to a heterogeneous
setting, we discovered a nontrivial gap in the previous proof of
strong normalization. We therefore prove strong normalization for
both homogeneous and heterogeneous queries for the first time.

As next steps, we intend to extend the Links implementation of
language-integrated query with heterogeneous queries and
normalization, and to investigate (higher-order) query normalization
and conservativity for the remaining common SQL features, such as
nulls, grouping/aggregation, and ordering.
