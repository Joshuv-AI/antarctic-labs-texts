1.
Introduction

Independent set.

An
r
-independent set is a subset of vertices of a given graph such that any two different vertices in the set have mutual distance greater than
r
. We focus on the following version of this problem: given a graph
G
and integers
r,k
we are asked to decide whether the given graph has an
r
-independent set of size
k
.

The unparametrized version of
r
-independent set is
NP
-hard, even in very restricted settings — for example for
r=1
and with restriction to planar graphs of maximum vertex degree
3
, as shown in
[
6
]
. Despite this, practically efficient algorithms are known. Examples include branching algorithms
[
10
]

[
11
]
, and algorithms utilizing reductions
[
2
]
. Cases of planar graphs and graphs of bounded degree are studied in detail, because branching factors can be lifted from restricted to general settings
[
3
]
.

Another line of research is focused on the parametrized version of the independent set problem — we measure the running time not only by size of input, but also in terms of
k
. Independent set admits a trivial algorithm with running time
O(n^{f(k)})
and it is believed that no quantitative improvement is possible. In particular, the hypothesis (called
\textit{W}[1]\not=
FPT
) that there is no algorithm working in time
f(k)n^{c}
(where
c
is a constant and
f
is computable function) is widely accepted in parametrized complexity theory and
FPT
-reduction to independent set problem serves as a basic tool for showing hardness. Parametrized problems solvable in time
f(k)n^{c}
, for some computable function
f
and constant
c
are called fix-parameter trackable algorithm (
FPT
). In search for
FPT
-algorithms, it is necessary to study this problem in more restricted settings, where both graph the class and parameter
k
are restricted.

The dual problem of
r
-dominating set is similarly hard and is well-studied on restricted graph classes. Our work inherits basic concepts from the corresponding study of
r
-dominating set on nowhere dense classes of graphs.

Nowhere dense graph classes.

Classes of nowhere dense graphs were introduced by Nešetřil and Ossona de Mendez in
[
8
]
and generalize many known families of sparse graphs, for example the following classes are nowhere dense: graphs with bounded treewidth, planar graphs and classes defined by a forbidden (even topological) minor. Many problems are effectively solvable on general classes of nowhere dense graphs, allowing to replace complicated topological arguments, originating from Robertson–Seymour graph structure theorem, by more general and simpler combinatorial proofs.

Definition 1
.

We say that a graph

We say that a class of graphs

Nowhere denseness can be characterized by many other conditions (some of them are described in

Dominating set.

A subset of vertices
X
of a graph
G
is called
r
-dominating if every vertex in
G
is at distance at most
r
from some vertex of
X
. The dominating set problem is the problem of determining if a given graph
G
has an
r
-dominating set of a given size
k
. The dominating set problem is a natural dual to the independent set problem (dominating set is a covering problem, while independent set is a packing problem).

In absence of restrictions on the class of graphs, parametrized
1
-independent set can be fpt-reduced to
1
-dominating set. This shows that on general graphs
1
-dominating set is at least as hard as independent set — in fact it is believed that it is strictly harder (this hypothesis is called
W[1]\not=W[2]
).

The computational complexity of dominating set on restricted graph classes is well studied.
FPT
-algorithms were developed in bigger and bigger classes of graphs, including classes of graphs defined by excluded minors. This line of research culminates in showing that nowhere dense graph classes are the largest subgraph-closed classes on which
r
-dominating set admits
FPT
algorithm. More precisely, in
[
4
]
the following dichotomy was shown:

Theorem 1
.

Let
\mathcal{C}
be a class of graphs, closed under taking subgraphs. Then:

•

if
\mathcal{C}
is nowhere dense, then for every

, the

-dominating set problem is in FPT.

•

if
\mathcal{C}
is not nowhere dense, then there is

such that the

-dominating set problem is as hard as on general graphs (it is

-hard).

My contribution.

In this work, two algorithms for the
r
-independent set problem are described. The ladder algorithm is invented by Michał Pilipczuk, Szymon Toruńczyk and Sebastian Siebertz. They originally developed an analogous algorithm for
r
-dominating set and adopted for independent set. The proof of correctness of the modified algorithm requires an analogous statement to Theorem

My contribution is the proof of Theorem
4
. During the proof I developed the definition of cowitness and found that it allows to characterize nowhere dense graph classes. The proof is constructive and allows a direct construction of an algorithm for

-independent set, which is the second algorithm presented here.

I wish to thank Michał Pilipczuk and Szymon Toruńczyk, who guided me during this work.

Greedy lemma.

We will use the following lemma:

Lemma 1

(Greedy lemma)
.

Fix a graph
G
, a set

and

(1)

3.
Algorithmic aspects

In this section we apply the obtained results to construct two algorithms for parametrized

-independent set in nowhere dense graph classes. The first approach uses direct cowitness search, as established in Theorem

3.1.
Algorithm for

-independent set by direct cowitness search

We want to prove the following Theorems.

Theorem 15
.

The problem of checking, given a graph

on a nowhere dense graph class
\mathcal{C}
.

Theorem 16

On nowhere dense classes
\mathcal{C}
, the problem of finding an

-independent set of size

(or conclude that it does not exist) can be solved in time
O(|G|(rk)^{d(1+o(1))}+\mbox{nc}_{\mathcal{C}}(\epsilon,r)^{k}(kr)^{dk(1+\epsilon+o(1))})
for some constant

which depends only on the class

.

Proof of Theorem

We check if every

Observe that whether given

Despite

It follows that the number of different submultisets of

Proof of Theorem

3.2.
Ladder algorithm

In this section we describe an alternative algorithm to find an
r
-independent set. It works correctly on any graph. When the input graphs are restricted to some class of graphs which satisfies additional properties (that are more general then the assumption of nowhere denseness), the presented algorithm works in linear

We will work with formulas of first order logic. For tuples
\overline{x}=(x^{1},\ldots,x^{n})

\overline{y}=(y^{1},\ldots,y^{m})

Definition 15

.

A class of graphs

Adler and Adler proved in

Theorem 17

The goal of this section is to prove the following:

Theorem 18

There is algorithm

Assumptions

Proof of theorem

Our algorithm tries to construct a generalized ladder for

Assume we have already constructed a ladder of length

Y

Assume that

If any

-independent, we can terminate concluding

. Assume otherwise. We aim at finding a set that witnesses that

is not

-independent for all odd

To find the witness we consider profiles. Whether

We proceed as follows:

(1)

We compute

(2)

We iterate over all subsets of

Assume that

We check if

•

If

— note that the size of

•

If

Halting property.

On classes of graphs satisfying (1) and (2), we make at most
d

form a ladder. The algorithm is correct by construction and we already argued that we produce a witness of size at most

To prove the halting property on general graphs we need to bound the length of the ladder. Observe that

is a strictly increasing family of sets (as a function of

(

In the next step, the algorithm will be checking whether there exists set not captured by

— this is equivalent to checking whether

has an
r
-independent set. If such a set is not found then the witness

is returned. If such a set

is found, then the ladder is enlarged by one step and the

-independent set

is returned in the subsequent step.
∎

For the ladder algorithm we use the bound of ladder length obtained by general argument of stability. For the particular

Practical evaluation of this algorithm is of independent interest. Various heuristic improvements seem reasonable — including playing splitter game more efficiently, using partial cowitnesses found in another branch of the cowitness finding algorithm, identifying and pruning unimportant vertices found during the ladder construction.
