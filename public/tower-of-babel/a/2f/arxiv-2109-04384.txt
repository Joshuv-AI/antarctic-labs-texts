Reachable sets for two-level open quantum systems driven by coherent and incoherent controls
Lev Lokutsievskiy, Alexander Pechen

Abstract
In this work, we study controllability in the set of all density matrices for a two-level open quantum system driven by coherent and incoherent controls. In [A. Pechen, Phys. Rev. A 84 , 042106 (2011)] an approximate controllability, i.e., controllability with some precision, was shown for generic N N -level open quantum systems driven by coherent and incoherent controls. However, the explicit formulation of this property, including the behavior of this precision as a function of transition frequencies and decoherence rates of the system, was not known. The present work provides a rigorous analytical study of reachable sets for two-level open quantum systems. First, it is shown that for N = 2 N=2 the presence of incoherent control does not affect the reachable set (while incoherent control may affect the time necessary to reach particular state). Second, the reachable set in the Bloch ball is described and it is shown that already just for one coherent control any point in the Bloch ball can be achieved with precision δ ∼ γ / ω \delta\sim\gamma/\omega , where γ \gamma is the decoherence rate and ω \omega is the transition frequency. Typical values are δ ≲ 10 − 3 \delta\lesssim 10^{-3} that implies high accuracy of achieving any density matrix. Moreover, we show that most points in the Bloch ball can be exactly reached, except of two lacunae of size ∼ δ \sim\delta . For two coherent controls, the system is shown to be completely controllable in the set of all density matrices. Third, the reachable set as a function of the final time is found and shown to exhibit a non-trivial structure.

\displaystyle\frac{\rmd\rho(t)}{\rmd t}=-\frac{\rmi}{\hbar}\Bigl[\omega\sigma_{z}+\kappa u(t)\sigma_{x},\rho(t)\Bigr]+\gamma(n(t)+1)\Big(\sigma^{-}\rho(t)\sigma^{+}-\frac{1}{2}\Big\{\sigma^{+}\sigma^{-},\rho(t)\Big\}\Big)

\displaystyle+\gamma n(t)\Big(\sigma^{+}\rho(t)\sigma^{-}-\frac{1}{2}\Big\{\sigma^{-}\sigma^{+},\rho(t)\Big\}\Big).

(1)

Here

is the coherent control,

is the incoherent control,
\omega>0
is the transition frequency of the qubit,
\kappa>0
is its coupling to the coherent control (e.g., dipole moment),
\gamma\geq 0
is the decoherence rate (for a given quantum system
\omega
,
\kappa
, and
\gamma
are some constants),

and
\sigma_{z}
are the

are the raising and lowering matrices,

and

stand for commutator and anti-commutator of two matrices, respectively. The Hamiltonian term in the commutator is written without loss of the generality. We set in the rest Planck constant
\hbar=1

Since the system is affine in both controls

and

Density matrix of the qubit can be conveniently parametrized as

\rho=\frac{1}{2}\left(\mathbb{I}+r_{x}\sigma_{x}+r_{y}\sigma_{y}+r_{z}\sigma_{z}\right),

where
\mathbf{r}=(r_{x},r_{y},r_{z})\in\mathbb{R}^{3}

In this representation, the dynamics of the controlled system can be written as

\dot{\mathbf{r}}=\omega f_{0}(\mathbf{r})+2\kappa f_{1}(\mathbf{r})u+\gamma f_{2}(\mathbf{r})n.

(2)

Here (see
[
22
]
)

\displaystyle f_{0}(\mathbf{r})

\displaystyle=\left(\begin{array}[]{ccc}0&-1&0\\
1&0&0\\

0&0&1\end{array}\right)\mathbf{r}+\frac{\gamma}{\omega}\left(\begin{array}[]{ccc}0\\

\displaystyle f_{1}(\mathbf{r})

\displaystyle=\left(\begin{array}[]{ccc}0&0&0\\
0&0&-1\\
0&1&0\end{array}\right)\mathbf{r};\qquad f_{2}(\mathbf{r})=-\left(\begin{array}[]{ccc}\frac{1}{2}&0&0\\

Below we study reachable sets for the system (

). It is known (see

In this paper, we analyze more precisely the sets of reachable points for the system (

Our main results are the following.

•

We find an exact estimation of the approximation accuracy

.

•

We show that the reachable set for the system controlled only by coherent control (i.e.

•

Obviously, if one leaves the system uncontrollable for a while (i.e. set

On another hand, we demonstrate that any pure states (that is not a rotation of

3
Coherent and incoherent controls

In this section we prove the following surprising fact: for a two-level system incoherent control does not extend the set of reachable points. A point
{\mathbf{r}}^{1}
is asymptotically reachable from
{\mathbf{r}}^{0}
for a control system if and only if
{\mathbf{r}}^{1}
belongs to the closure of the reachable set from
{\mathbf{r}}^{0}
. In other words, there exist trajectories of the system that start at
{\mathbf{r}}^{0}
and end arbitrary close to
{\mathbf{r}}^{1}
.

Thus the main result of this section can be formulated as follows:

Theorem 1

For any starting point
{\mathbf{r}}^{0}
the sets of asymptotically reachable points for system (
2

2

{\mathbf{r}}^{0}
in forward and backward time but for

C_{+}({\mathbf{r}}^{0})
and

C_{+}({\mathbf{r}}^{0})=\big\{{\mathbf{r}}^{1}:\exists T\geq 0,{\mathbf{r}}(t),u(t):\ \dot{\mathbf{r}}=\omega f_{0}({\mathbf{r}})+2\kappa f_{1}({\mathbf{r}})u,\ {\mathbf{r}}(0)={\mathbf{r}}^{0},{\mathbf{r}}(T)={\mathbf{r}}^{1}\big\},

We are really interested only in sets

4
Asymptotically reachable points

Recall that a point
{\mathbf{r}}^{1}
is called asymptotically reachable from the point
{\mathbf{r}}^{0}
, if for any arbitrary small
\varepsilon>0
there exists a trajectory of the control system that ends at a point in the distance at most
\varepsilon
from
{\mathbf{r}}^{1}
. Hence, the set of asymptotically reachable points is
{\rm cl\,}C_{+}({\mathbf{r}}^{0})
.

The main result of this section is that most of the asymptotically reachable points are in fact exactly reachable. Precisely,

Theorem 2

For any
{\mathbf{r}}^{0}
,

{\rm int\,}({\rm cl\,}C_{+}({\mathbf{r}}^{0}))\subset C_{+}({\mathbf{r}}^{0})\subset{\rm cl\,}C_{+}({\mathbf{r}}^{0})={\rm cl\,}({\rm int\,}C_{+}({\mathbf{r}}^{0})).

(10)

In other words, we make two non-obvious statements on the structure of the set
{\rm cl\,}C_{+}({\mathbf{r}}^{0})
of the asymptotically reachable points.

•

According to the first inclusion, if a neighborhood of a point
{\mathbf{r}}^{1}
consists of points that are asymptotically reachable from
{\mathbf{r}}^{0}
, then
{\mathbf{r}}^{1}
is in fact exactly reachable from
{\mathbf{r}}^{0}
.

According to the last equality, the difference between the set of asymptotically reachable points and the interior of the set of exactly reachable points is rather small and coincides with the latter boundary:

Using this theorem we are able to show a very convenient fact on how to transform asymptotic reachability to the exact one. Let
{\mathbf{r}}^{0}

Fast numerical engineering of optimal coherent control

In this section, we present a method of designing optimal coherent control for time minimization problem
T\to\min
for qubit control system (
2
). As we explained the optimal control
u(t)
can be found as the difference between
\dot{\theta}
and the r.h.s. of (
7
), i.e.

2\kappa u=\dot{\theta}+\omega\frac{z}{R}+\frac{1}{4}\gamma\sin 2\theta-\gamma\frac{1}{R}\cos\theta.

where
\theta
is a time optimal control in the auxiliary system (
13
) (where that
R<0
corresponds to substitution
\theta\mapsto\theta+\pi
). We use this method to numerically generate the reachable sets for
\gamma/\omega=0.1
and for different times
T
. As described above, the results are shown on Fig.
3
and Fig.
4
; the upper 2D plots are in the cylindrical coordinates on the plane
(z,R)
and the bottom 3D plots are obtained by rotation of the 2D sets around
O{\mathbf{r}}_{x}
axis. Movie (in the online version of the paper) on Fig.
5
shows evolution of the reachable set as a function of
T
.

Let us rescale the time
\tau=t\omega
. System (
13
) becomes

\cases{z^{\prime}_{\tau}=-\frac{1}{2}\frac{\gamma}{\omega}z-R\cos\theta;\\
R^{\prime}_{\tau}=z\cos\theta-\frac{1}{4}\frac{\gamma}{\omega}R(3-\cos 2\theta)+\gamma\sin\theta}.

(16)

For the latter Pontryagin maximum principle gives

\mathcal{H}=-p\left(\frac{1}{2}\frac{\gamma}{\omega}z+R\cos\theta\right)+q\left(z\cos\theta-\frac{1}{4}\frac{\gamma}{\omega}R(3-\cos 2\theta)+\gamma\sin\theta\right),

where
(p,q)
are conjugate variables to
(z,R)
. So we have

\cases{p^{\prime}_{\tau}=-\mathcal{H}^{\prime}_{z}=\frac{1}{2}\frac{\gamma}{\omega}p-q\cos\theta\\
q^{\prime}_{\tau}=-\mathcal{H}^{\prime}_{R}=p\cos\theta+\frac{1}{4}\frac{\gamma}{\omega}q(3-\cos 2\theta).}

(17)

Pontryagin maximum principle states that for
t\in[0;T]
optimal
\theta(t)
solves maximization problem

\mathcal{H}(\theta)\to\max_{\theta\in[0;2\pi]}.

Hence,
\theta
that maximizes
\mathcal{H}
becomes an (implicitly given) function
\theta(z,r,p,q)
. Unfortunately, numerical computation of a maximal point is a very time expensive procedure and it should be performed on each step of numerical ODE solving process. Hence, we suggest an alternative fast way to avoid this.

The idea is based on the fact that at any fixed point
(z,R)
, the r.h.s. of the rescaled auxiliary system (
16
) forms a strictly convex set for all
\theta\in[0;2\pi]
. Indeed, tangent vector
(\xi,\eta)
to this set is

\xi=\frac{\rmd z^{\prime}_{\tau}}{\rmd\theta}=R\sin\theta;\qquad\eta=\frac{\rmd R^{\prime}_{\tau}}{\rmd\theta}=\frac{\gamma}{\omega}\big(\cos\theta-R\sin\theta\cos\theta\big)-z\sin\theta.

It remains to note that vector
(\xi,\eta)
rotates strictly clockwise as
\theta
increases, since

\xi\eta^{\prime}_{\theta}-\eta\xi^{\prime}_{\theta}=\frac{\gamma}{\omega}R(R\sin^{3}\theta-1)<0.

Hence
\theta(z,r,p,q)
is a smooth function and its derivative can be easily found from linear on
\theta^{\prime}_{\tau}
equation
\mathcal{H}^{\prime}_{\theta}=0
. Indeed,
\rmd\mathcal{H}^{\prime}_{\theta}/\rmd\tau=0
gives

\theta^{\prime}_{\tau}=\frac{1}{8}\frac{\gamma}{\omega}\left[\frac{(pR+qz)(5\sin\theta+\sin 3\theta)-8p-4\frac{\gamma}{\omega}q\cos^{3}\theta}{(pR-qz)\cos\theta-\frac{\gamma}{\omega}q(\sin\theta+R\cos 2\theta)}\right].

Summarizing, together with (
16
) and (
17
), we obtain an ODE system on
(z^{\prime}_{\tau},R^{\prime}_{\tau},p^{\prime}_{\tau},q^{\prime}_{\tau},\theta^{\prime}_{\tau})
, which can be numerically solved very fast. The last thing we need is to find initial values of variables. For simplicity, assume that we are starting from the attracting point
6
6

6

These initial values can be chosen arbitrary.

z(0)=0\quad\textrm{and}\quad R(0)=1.

Conjugate variables can be rescaled by arbitrary positive multiplier, so without loss of generality we assume that
p(0)^{2}+q(0)^{2}=1
, i.e.

p(0)=\cos\psi_{0}\quad\textrm{and}\quad q(0)=\sin\psi_{0},

where
\psi_{0}
determine optimal trajectory starting from
(z=0,R=1)
. Last initial value
\theta(0)=\theta_{0}
can be found by solving simplified problem
\mathcal{H}(\theta)\to\max
just once for
\tau=0
:

(\mathcal{H}^{\prime}_{\theta})\big|_{z=0,R=1}=\cos\psi^{0}\sin\theta^{0}-\frac{\gamma}{\omega}\sin\psi^{0}\cos\theta^{0}(\sin\theta^{0}-1)=0

or

\cos\psi_{0}\sin\theta^{0}=\frac{\gamma}{\omega}\sin\psi^{0}\cos\theta^{0}(\sin\theta^{0}-1).

The latter equation has two solutions (one for maximal and another for minimal values of
\mathcal{H}
).

Now we give the last advise on reducing computational time. Note that system (
16
) depends only on one parameter
\gamma/\omega
. Suppose that
\gamma/\omega
is given, and we have numerically found a number of optimal trajectories for a
\psi_{0}
grid on
[0;2\pi]
. Then we can save the following table
(z^{1},R^{1})\mapsto(\psi^{0},\theta^{0})
– for each pair
(z^{1},R^{1})
in a grid on the unit circle
z^{2}+R^{2}\leq 1
we save the initial values of conjugate variables and the initial angle
\theta_{0}
of the corresponding optimal trajectory. Once the table is created, optimal trajectory from
(z=0,R=1)
to any point
(z^{1},R^{1})
can be found very fast, since we can immediately extract optimal initial values
(\psi_{0},\theta_{0})
from the table.

7
Conclusions

This work provides an explicit analytical study of reachable sets for an open two-level quantum system driven by coherent and incoherent controls. First, it is shown that for the two-level case the presence of incoherent control does not affect the reachable set (while incoherent control may affect the time necessary to reach particular state). Second, the reachable set is explicitly described in the Bloch ball. For the case of one coherent control it is shown that most points in the Bloch ball can be exactly reached, except of two lacunae of the size
\delta\sim\gamma/\omega
, where
\gamma
is the decoherence rate and
\omega
is the transition frequency. Thus any point in the Bloch ball can be achieved with precision
\delta
. Typical values are
\delta\lesssim 10^{-3}
that implies high accuracy of achieving any density matrix. For two coherent controls, the system is shown to become completely controllable in the set of all density matrices. Third, the reachable set as a function of the final time is explicitly described and shown to exhibit a non-trivial structure.
