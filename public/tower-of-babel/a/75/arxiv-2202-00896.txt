Moving lemmas in mixed characteristic and applications
Ivan Panin

Abstract
The present paper contains new geometric theorems proven in mixed characteristic case. We derive a bunch of cohomological consequences using these geometric theorems. Among them an isotropy result for quadratic spaces, a purity result for quadratic spaces, Grothendieck–Serre conjecture for groups S ​ L 1 , D SL_{1,D} , where D D is an Azumaya algebra. The Gersten conjecture for the functor K 2 K_{2} is proved. Bloch-Ogus type result is obtained as well. Suslin’s exact sequence is derived and its application to a finiteness result is given. A version of the Roitman theorem is proved. A very general result concerning the Cousin complex is obtained for any cohomology theory in the sense of Panin–Smirnov.

Definition 11.1
.

A presheaf with transfers on
Sch^{\prime}/V
is an additive presheaf
\cal F
such that for each finite flat
morphism
\pi:Y\to S
in
Sch^{\prime}/V
there is given a homomorphism
\text{Tr}_{Y/S}:\mathcal{F}(Y)\to\mathcal{F}(S)
.
Moreover these homomorphisms enjoy the following properties

(i) base change: if

is a
V
-morphism, then for
Y^{\prime}=S^{\prime}\times_{S}Y
and
F=pr_{Y}:Y^{\prime}\to Y

one has an equality
f^{*}\circ\text{Tr}_{Y/S}=\text{Tr}_{Y^{\prime}/S^{\prime}}\circ F^{*}:\mathcal{F}(Y)\to\mathcal{F}(S^{\prime})

(ii) additivity: if
Y=Y^{\prime}\sqcup Y^{\prime\prime}

Tr_{Y/S}=Tr_{Y^{\prime}/S}+Tr_{Y^{\prime\prime}/S}
;

(iii) normalization: if
\pi=id_{S}:S\to S

Tr_{Y/S}=id

An assignment
[\pi:Y\to S]\mapsto[Tr_{Y/S}:\mathcal{F}(Y)\to\mathcal{F}(S)]

\mathcal{F}
.
So, a presheaf with transfers on
Sch^{\prime}/V
is an additive presheaf
\cal F
equipped with a trace structure.

An étale sheaf with transfers on
Sch^{\prime}/V
is a presheaf with transfers which is an étale sheaf
on
(Sch^{\prime}/V)_{Et}
.
