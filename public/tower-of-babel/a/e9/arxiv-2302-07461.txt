1.
Introduction

The additive uniqueness, briefly AU, was initiated by Spiro in 1992
[
12
]
. She call a set
E\subset\mathbb{N}
a AU set for a set
S
of arithmetic functions if the condition

f\in S\text{ and }f(a+b)=f(a)+f(b)\text{ for all }a,b\in E

determines
f
uniquely. She showed that the set of prime numbers is AU for multiplicative functions
f
with
f(p_{0})\neq 0
for some
p_{0}
prime.

Two decades later, Fang
[
7
]
and Dubickas and Šarka
[
6
]
showed that the set of prime numbers with condition

f(p_{1}+p_{2}+\cdots+p_{k})=f(p_{1})+f(p_{2})+\cdots+f(p_{k})\text{ for fixed }k\geq 3

also determines the multiplicative function
f
uniquely if
f(p_{0})\neq 0
for some
p_{0}
prime. Henceforth, let us call such a set
k
-AU.

In 1996 Chung
[
4
]
studied condition

f(m^{2}+n^{2})=f(m^{2})+f(n^{2})\text{ for all }m,n\in\mathbb{N}

and showed that the set of positive squares is not AU for multiplicative functions.

The author, two decades later, showed that the set of positive squares is
k
-AU for
k\geq 3

[
8
]
. This is the first case for
k
-AU but not
\ell
-AU with
\ell<k
.

In this paper we show that the set of positive cubes is a
k
-additive uniqueness set, like the set of positive squares, for multiplicative functions when
k\geq 3
.

Theorem 1.1
.

The set of positive cubes is
k
-AU for
k\geq 3
. That is, if a multiplicative function
f_{k}
satisfies the condition

f_{k}(a_{1}^{3}+a_{2}^{3}+\cdots+a_{k}^{3})=f_{k}(a_{1}^{3})+f_{k}(a_{2}^{3})+\cdots+f_{k}(a_{k}^{3})

for all
a_{1},a_{2},\ldots,a_{k}\in\mathbb{N}
, then
f_{k}
is the identity function.

But,
f_{2}
is not determined uniquely. So, we proceed as follows:

§2

Classify the multiplicative functions
f_{2}
.

§3

Show that
f_{3}
is the identity function.

§4

Show that
f_{4}
is the identity function.

§5

Show that
f_{k}
is the identity function with
k\geq 5
.

In §6 we consider a variant problem: For fixed
k\geq 2
, if a multiplicative function

satisfies

g_{k}(a_{1}^{3}+a_{2}^{3}+\cdots+a_{k}^{3})=g_{k}(a_{1})^{3}+g_{k}(a_{2})^{3}+\cdots+g_{k}(a_{k})^{3}

for all
a_{1},a_{2},\ldots,a_{k}\in\mathbb{N}
, then is

determined uniquely? If we set
K(x_{1},\ldots,x_{k})=x_{1}^{3}+\cdots+x_{k}^{3}
, this problem is to find a multiplicative function

commutable with

.

In 2014 Bašić
[
1
]
showed that various multiplicative function
g
satisfies

g(a^{2}+b^{2})=g(a)^{2}+g(b)^{2}

and the author, a couple of years later, showed that a multiplicative function

is the identity function if
k\geq 3
is fixed and

g(a_{1}^{2}+a_{2}+\cdots+a_{k}^{2})=g(a_{1})^{2}+g(a_{2})^{2}+\cdots+g(a_{k})^{2}

holds for all
a_{1},a_{2},\ldots,a_{k}\in\mathbb{N}

[

]

In this section, we show that

and

is one of three functions.

2.

-additive uniqueness

The set of positive cubes is not (2-)AU for multiplicative functions. That is, although a multiplicative function

satisfies

f_{2}(a^{3}+b^{3})=f_{2}(a^{3})+f_{2}(b^{3})

Since

f_{2}(3)

n&\text{ otherwise,}\end{cases}

this function satisfies the additive condition but is not the identity function.

In general, we can characterize the function

completely.

a_{1},a_{2},\dots,a_{k}\in\mathbb{N}
, then
g_{k}
is the identity function.

The proof is similar to that of Theorem
1.1
. But, we use
g_{k}(n)^{3}=n^{3}
instead of
g_{k}(n^{3})=n^{3}
.

For
k=3
, we obtain
g_{3}(n)=n
for
n=1,2,3,4,5,9,11,43
by the
Mathematica
code, if we set
h_{n}=g_{3}(n)
:

Solve[h1 == 1 && h3 == h1^3 + h1^3 + h1^3
&& h2 h5 == h2^3 + h1^3 + h1^3 && h4 h9 == h3^3 + h2^3 + h1^3
&& h43 == h3^3 + h2^3 + h2^3 && h5 h11 == h3^3 + h3^3 + h1^3
&& h2 h3 h11 == h4^3 + h1^3 + h1^3 && h9 h11 == h4^3 + h3^3 + h2^3
&& h3 h43 == h4^3 + h4^3 + h1^3,
{h1, h2, h3, h4, h5, h9, h11, h43}]

It can be shown similarly that
g_{3}
fixes
2^{3m+1}
and
2^{3m+2}
. But, we cannot use
g_{3}(5\cdot 2^{3m+1})
as in the proof of Lemma
3.2
to show that
2^{3(m+1)}
is fixed. So, instead, we use

\displaystyle g_{3}(3\cdot 2^{3(m+1)})

\displaystyle=g_{3}\bigl((2^{3}+2^{3}+2^{3})\,2^{3m}\bigr)

\displaystyle=g_{3}(2^{m+1})^{3}+g_{3}(2^{m+1})^{3}+g_{3}(2^{m+1})^{3}.

By the same reason, we use

g_{3}(8\cdot 3^{3(m+1)})=g_{3}(6^{3}\cdot 3^{3m})=g_{3}\bigl((3^{3}+4^{3}+5^{3})\,3^{3m}\bigr)

to show
3^{m+1}
is fixed. This method can be also applied to Lemma
3.2
.

Now, we can say that
g_{3}(n)^{3}=n^{3}
for all
n\in\mathbb{N}
by the same method of Lemma
3.3
. But, we are not yet sure
g_{3}(n^{3})=n^{3}
. So, we are not sure that
\bigl(6\lambda^{2}(\lambda^{3}+3p^{r})^{2}\bigr)^{3}
is fixed by
g_{3}
in the LHS of Richmond’s representation

g_{3}\bigl(p^{r}\bigl(6\lambda^{2}(\lambda^{3}+3p^{r})^{2}\bigr)^{3}\bigr)=g_{3}(p^{r})\,g_{3}\bigl(\bigl(6\lambda^{2}(\lambda^{3}+3p^{r})^{2}\bigr)^{3}\bigr).

However,
g_{3}
fixes
(6N)^{3}
, since

\displaystyle g_{3}\bigl((6N)^{3}\bigr)

\displaystyle=g_{3}\bigl((3N)^{3}+(4N)^{3}+(5N)^{3}\bigr)

\displaystyle=g_{3}(3N)^{3}+g_{3}(4N)^{3}+g_{3}(5N)^{3}

\displaystyle=(3N)^{3}+(4N)^{3}+(5N)^{3}=(6N)^{3}.

So,
g_{3}(p^{r})=p^{r}
for all prime
p
and
r\geq 1
.

Then, we can show that
g_{4}
fixes
2^{3m+1}
and
2^{3m+2}
by the similar ways as in Lemma
4.1
. Also,
g_{4}(2^{3(m+1)})=2^{3(m+1)}
can be derived by

\displaystyle g_{4}(7\cdot 2^{3(m+1)})

\displaystyle=g_{4}(7\cdot 2^{3}\cdot 2^{3m})=g_{4}\bigl((1^{3}+1^{3}+3^{3}+3^{3})\,2^{3m}\bigr)

\displaystyle=g_{4}(2^{m})^{3}+g_{4}(2^{m})^{3}+g_{4}(3\cdot 2^{m})^{3}+g_{4}(3\cdot 2^{m})^{3}.

Thus, we can conclude that
g_{4}(p^{r})=p^{r}
by the similar way as in §4.

The proof for
k\geq 5
is almost identical to §5. If we set

,
t_{n}=1
or
