Criticality of the low-frequency conductivity for the bilayer quantum Heisenberg model
Yoshihiro Nishiyama

Abstract
The criticality of the low-frequency conductivity for the bilayer quantum Heisenberg model was investigated numerically. The dynamical conductivity (associated with the O ( 3 ) (3) symmetry) displays the inductor σ ⁡ ( ω ) = ( i ​ ω ​ L ) − 1 \sigma(\omega)=(i\omega L)^{-1} and capacitor i ​ ω ​ C i\omega C behaviors for the ordered and disordered phases, respectively. Both constants, C C and L L , have the same scaling dimension as that of the reciprocal paramagnetic gap Δ − 1 \Delta^{-1} . Then, there arose a question to fix the set of critical amplitude ratios among them. So far, the O ( 2 ) (2) case has been investigated in the context of the boson-vortex duality. In this paper, we employ the exact diagonalization method, which enables us to calculate the paramagnetic gap Δ \Delta directly. Thereby, the set of critical amplitude ratios as to C C , L L and Δ \Delta are estimated with the finite-size-scaling analysis for the cluster with N ≤ 34 N\leq 34 spins.
