Towards Universally Optimal Shortest Paths Algorithms in the Hybrid Model
Philipp Schneider, University of Bern, Switzerland

Abstract
A drawback of the classic approach for complexity analysis of distributed graph problems is that it mostly informs about the complexity of notorious classes of “worst case” graphs. Algorithms that are used to prove a tight (existential) bound are essentially optimized to perform well on such worst case graphs. However, such graphs are often either unlikely or actively avoided in practice, where benign graph instances usually admit much faster solutions. To circumnavigate these drawbacks, the concept of universal complexity analysis in the distributed setting was suggested by [Kutten and Peleg, PODC’95] and actively pursued by [Haeupler et al., STOC’21]. Here, the aim is to gauge the complexity of a distributed graph problem depending on the given graph instance. The challenge is to identify and understand the graph property that allows to accurately quantify the complexity of a distributed problem on a given graph. In the present work, we consider distributed shortest paths problems in the 𝖧𝖸𝖡𝖱𝖨𝖣 \mathsf{HYBRID} model of distributed computing, where nodes have simultaneous access to two different modes of communication: one is restricted by locality and the other is restricted by congestion . We identify the graph parameter of neighborhood quality and show that it accurately describes a universal bound for the complexity of certain class of shortest paths problems in the 𝖧𝖸𝖡𝖱𝖨𝖣 \mathsf{HYBRID} model.

1.1
The
\mathsf{HYBRID}
model

For the formal definition of the
\mathsf{HYBRID}
model, we rely on the concept of

[
10
]

Definition 1

(Synchronous Message Passing, cf.
[
10
]
)

Let
V
be a set of
n
nodes with unique identifiers ID
:V\!\to\![n]\!\stackrel{{\scriptstyle\text{def}}}{{=}}\!\{1,\ldots,n\}

Second, nodes conduct computations based on their current state and the set of received messages to compute their new state (randomized algorithms also include the result of a random function). Third, based on the new state, the next messages are sent.

The aim of the
\mathsf{HYBRID}
model is to reflect the fundamental concepts of

and

to capture the nature of distributed systems that combine both physical and logical networks.

[

]

The

1

Local mode:

\lambda

Global mode:

\gamma

1
1

1

The parameter

1.3
Universal Optimality

Our concept of universal optimality adheres closely to the one by
[
4
]
which bases itself on a description by
[
8
]
. Consider a graph problem
\Pi
. Then a problem instance of
(G,I)\in\Pi
consists of a graph
G
together with a (distributed) problem input
I
.
In the case of the
(k,\ell)
-SP problem,
I
assigns each node an ID in
[n]
, the IDs of its neighbors as well as the weights of the corresponding edges. The set of source and target nodes is also considered part of
I
, i.e., each node knows whether it is a source or target (or both) but has initially no such information about others.

For the purpose of comparison (see also
[
4
]
), we start by defining an even stronger concept, where an algorithm would be called
instance optimal
if it would be competitive with any algorithm optimized for a certain graph
G

and
instance
I
.

Definition 4

(Instance Optimality, see e.g.
[
8
,
4
]
)
.

Let
\mathcal{A}
be an algorithm that correctly computes the solution to some distributed graph problem
\Pi
with probability at least
p>0
in some computational model
\mathcal{M}
and takes
T_{\mathcal{A}}(G,I)
rounds for
(G,I)\in\Pi
. Then
\mathcal{A}
is called an
instance optimal
model
\mathcal{M}
algorithm with competitiveness
C
(omitted for
C\in\smash{\widetilde{O}}(1)
) if the following holds. For all
(G,I)\in\Pi
and for all algorithms
\mathcal{A}^{\prime}
that solve
\Pi
with probability at least
p
, we have

T_{\mathcal{A}}(G,I)\leq C\cdot T_{\mathcal{A}^{\prime}}(G,I).

Unfortunately, the concept of instance optimality is not very interesting in the
\mathsf{HYBRID}
model unless the problem
\Pi
admits very fast solutions in general. This is due to fact that in the
\mathsf{HYBRID}
model nodes can detect extremely fast if they live in a specific problem instance
(G,I)\in\Pi
by using the global network and exploit this knowledge accordingly (compare this to the analogous argument for
\mathsf{CONGEST}
by
[
4
]
). For an illustration, consider the following algorithm
\mathcal{A}^{\prime}
that is instance-optimized for
(G,I)
.

The instance
(G,I)
and a solution for that instance (i.e., the output that each node with a given ID makes) is all hard coded into
\mathcal{A}^{\prime}
. Then each node checks locally if its ID equals an ID in
(G,I)
and checks if all the input data it obtained equals the local data assigned to that ID by
I
. If that is the case, it outputs a 1 else a 0. The
n
-wise AND of all outputs of all nodes can be made public knowledge deterministically in just
\smash{O}(\log n)
rounds
[
1
]
. If the result is 1, then all nodes output the hard coded result. Else all nodes together run the trivial
O(D_{G})
round
\mathsf{LOCAL}
algorithm to solve the problem instance.

So unless a graph problem
\Pi
has
\smash{\widetilde{O}}(1)
complexity in
\mathsf{HYBRID}
in general, instance optimality with competitiveness
\smash{\widetilde{O}}(1)
is unattainable for an algorithm that is
oblivious
to
(G,I)
. For
k
-SSP there is in fact a polynomial (existential) lower bound of
\smash{\widetilde{\Omega}}\big(\!\sqrt{k}\big)
in
\mathsf{HYBRID}
due to
[
7
]
, so unless
k\in\smash{\widetilde{O}}(1)
there can be no instance optimal solution with competitiveness
\smash{\widetilde{O}}(1)
.
A more fruitful concept is to try to design algorithms that are competitive with the best algorithms that “know” the graph
G
but not
I\in\Pi_{G}:=\{I\mid(G,I)\in\Pi\}
.
Such an algorithm is called
universally optimal
, in the sense that it can “adapt” to the topology of
G
. Formally, we define this as follows.

Definition 5

(Universal Optimality, see
[
8
,
4
]
)
.

Let
\mathcal{A}
be an algorithm that correctly computes the solution to some distributed graph problem
\Pi
with probability at least
p>0
in some computational model
\mathcal{M}
and takes
T_{\mathcal{A}}(G,I)
rounds for
(G,I)\in\Pi
. Then
\mathcal{A}
is called a
universally optimal
model
\mathcal{M}
algorithm with competitiveness
C
(omitted for
C\in\smash{\widetilde{O}}(1)
) if the following holds. For all graphs
G
and for all algorithms
\mathcal{A}^{\prime}
that solve
\Pi
with probability at least
p
, we have

\max\limits_{I\in\Pi_{G}}T_{\mathcal{A}}(G,I)\leq C\cdot\max\limits_{I\in\Pi_{G}}T_{\mathcal{A}^{\prime}}(G,I).

The Graph Parameter Neighborhood Quality

We start by giving a fundamental graph parameter that describes the complexity of algorithms solving the
(k,\ell)
shortest paths problem (
(k,\ell)
-SP) where all nodes obtain the graph
G
as part of their input. Leaning on the nomenclature used by previous work (see, e.g.,
[
4
]
), we call this the neighborhood quality
\mathcal{NQ}(G,k,\gamma)
. Intuitively,
\mathcal{NQ}(G,k,\gamma)
describes how large the neighborhood of each node within a certain distance is that such a node can utilize on in order to communicate globally with others. This distance depends on
k
and
\gamma
, where
k
roughly reflects the ‘ìnformation” (measured in Shannon entropy
[
16
]
) each node has to learn and
\gamma
restricts the information a single node can receive over large distances per round.

To reflect the runtime of shortest paths algorithms in
G
, the parameter
\mathcal{NQ}(G,k,\gamma)
is defined inversely. Intuitively, neighborhoods of “higher quality” imply that
\mathcal{NQ}(G,k,\gamma)
is smaller. Since the trivial solution of
D_{G}
rounds is always possible using the local network even if nodes are required to learn huge amounts of information,
\mathcal{NQ}(G,k,\gamma)
has to be, in effect, upper bounded by
D_{G}
, which roughly means that neighborhoods play a bigger role on graphs with large diameter (on which global problems become interesting).

Definition 7
.

Let
G=(V,E)
be a local graph and
k\in[n]
. For
v\in V
let
N(d,v)=|\mathcal{B}(v,d)|
be the size of the
d
-hop neighborhood of
v
. Then we define the smallest neighborhood in distance
d\in[D_{G}]
as
N(d):=\min_{v\in V}N(d,v)
.
We define the neighborhood quality in the
\mathsf{HYBRID}(\infty,\gamma)
with respect to some
k\in[n]
as

\mathcal{NQ}(G,k,\gamma):=\min\limits_{d\in[D_{G}]}\max\Big(\tfrac{k}{N(d)\gamma},d\Big).

An equivalent definition that is slightly longer but sometimes useful for explanation is

\mathcal{NQ}(G,k,\gamma):=\max_{v\in V}\min\limits_{d\in[D_{G}]}\max\Big(\tfrac{k}{N(d,v)\gamma},d\Big).

An important property of
\mathcal{NQ}(G,k,\gamma)
is that it roughly strikes a balance between radius and size of the neighborhood of any node within that radius. This is reflected in the following technical lemma, which we will need later on.

Lemma 8
.

Let
G=(V,E)
be a graph and
k\in[n]
. Let
d^{\prime}
be such that the outer minimum of
\mathcal{NQ}(G,k,\gamma)
in Def.
7
is minimized and presume
d^{\prime}<D_{G}
. Then we have

(a)

d^{\prime}\!+\!1\geq k/N(d^{\prime})\gamma
(equivalently:
N(d^{\prime})\geq k/(d^{\prime}\!+\!1)\gamma
)

(b)

d^{\prime}\leq\mathcal{NQ}(G,k,\gamma)\leq d^{\prime}\!+\!1\leq D_{G}
(implies:
N(d^{\prime})\geq k/(\mathcal{NQ}(G,k,\gamma)\!+\!1)\gamma
)

Proof.

Note that as
d
increases by 1,
N(d)
increases by at least 1, because the neighborhood of each node within radius
d
gets at least one node larger as
d<D_{G}
and
G
is connected. This implies that
\tfrac{k}{N(d)\gamma}
strictly decreases in
d
. Let us assume (for a contradiction) that
d^{\prime}\!+\!1<\tfrac{k}{N(d^{\prime})\gamma}
. This implies that

\max\Big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\Big)=\max\Big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\!+\!1\Big)>\max\Big(\tfrac{k}{N(d^{\prime}+1)\gamma},d^{\prime}\!+\!1\Big),

which is a contradiction since
d^{\prime}
minimizes the term on the left, thus
d^{\prime}\!+\!1\geq\tfrac{k}{N(d^{\prime})\gamma}
. The claim
d^{\prime}\leq\max\big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\big)\leq d^{\prime}+1
follows immediately.
∎

The first indication that
\mathcal{NQ}(G,k,\gamma)
is a suitable parameter to describe a universal bound for
k
-SSP (which we prove in the subsequent sections) is obtained by relating it to the existential lower bound of
\smash{\widetilde{\Omega}}\big(\!\sqrt{k}\big)
in the standard
\mathsf{HYBRID}
model (i.e.,
\gamma\in\smash{\widetilde{O}}(1)
) by
[
6
,
2
]
that describes worst case instances for the
k
-SSP problem.

Lemma 9
.

Let
G
be a graph and
k\in[n]
. We have
1\leq\mathcal{NQ}(G,k,\gamma)\leq\sqrt{k/\gamma}+1.

Proof.

The value
\mathcal{NQ}(G,k,\gamma)
is always at least 1 for the given parameter range of
d
. Looking more closely at Definition
7
we see that
\mathcal{NQ}(G,k,\gamma)
is largest if there is a node that has only a very sparse neighborhood
N(d)\in\Theta(d)
. We consider the worst case where
G
is a path, thus
N(d,v)=d
for one endpoint
v
of that path. Assume that
d
and
N(d,v)
can attain real values, then
\min_{d\leq D_{G}}\max\big(\tfrac{k}{d\gamma},d\big)
is minimized if
\tfrac{k}{d\gamma}=d
, which implies
d=\sqrt{k/\gamma}
.
For integral
d
it is
\mathcal{NQ}(G,k,\gamma)\leq\max\big(\tfrac{k}{\lceil d\rceil\gamma},\lceil d\rceil\big)\leq\sqrt{k/\gamma}+1
.
∎

The lemma implies that the neighborhood quality is upper bounded by the existential lower bound
\mathcal{NQ}(G,k,\gamma)\in\smash{\widetilde{O}}\big(\!\sqrt{k}\big)
(where
\gamma\in\smash{\widetilde{O}}(1)
in the standard
\mathsf{HYBRID}
model). The proof also shows that there is in fact a problem instance
G,k
with a linear neighborhood such that
\mathcal{NQ}(G,k)\in\smash{\widetilde{\Omega}}\big(\!\sqrt{k}\big)
. In fact, graphs which feature an isolated, long path have frequently been used to obtain existential lower bounds for shortest paths problems in the
\mathsf{HYBRID}
model
[
2
,
6
,
7
]
.

In the following, we often consider the quality of the neighborhood of a single node
v\in V
, which we define as follows.

Definition 10
.

Let
G=(V,E)
be any fixed graph and consider any fixed
k\in[n]
for which the
k
-SSP problem needs to be solved on
G
. For
v\in V
we define

\mathcal{NQ}(v)=\min\limits_{d\in[D_{G}]}\max\Big(\tfrac{k}{N(v,d)\gamma},d\Big).

Notice that we use the size
N(d,v)
(cf. Definition
7
) of the neighborhood within
d

v
, thus
\mathcal{NQ}(v)
describes the neighborhood quality of a node
v
. In fact, we have
\mathcal{NQ}(G,k,\gamma)=\max_{v\in V}\mathcal{NQ}(v)
, see Definition
7
.
We often use
d_{v}
for the value that optimizes the outer minimum in the definition of
\mathcal{NQ}(v)
. In Section

on universal lower bounds, we will often relate to
v:=\argmax_{u\in V}\mathcal{NQ}(u)
.

Be aware that
\mathcal{NQ}(v)
also depends on the problem instance

and
\gamma
, but we omit to express this specifically for brevity. As a warm up, we show that the parameter
\mathcal{NQ}(G,k,\gamma)
can be computed efficiently in the
\mathsf{HYBRID}
model, in particular, we give an algorithm that takes roughly
\mathcal{NQ}(G,k,\gamma)
rounds.

Lemma 11
.

The parameter
\mathcal{NQ}(G,k,\gamma)
can be computed and made known to all nodes in the network in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds in the
\mathsf{HYBRID}
model.

Proof.

The idea is that each node locally computes
\mathcal{NQ}(v)
and then all nodes globally compute the maximum of those values to obtain
\mathcal{NQ}(G,k,\gamma)
(see Definition
7
). The first step works by each node exploring the local network to increasing depth
d
and locally computing
\max\big(\tfrac{k}{N(v,d)\gamma},d\big)
which takes
d
rounds using
\mathsf{LOCAL}
. To ensure that we do not look too deep, i.e., beyond
\smash{O}\big(\mathcal{NQ}(G,k,\gamma)\big)
, after each
\mathsf{LOCAL}
round we compute
\max_{v\in V}\max\big(\tfrac{k}{N(v,d)\gamma},d\big)=\max\big(\tfrac{k}{N(d)\gamma},d\big)
which takes
\smash{\widetilde{O}}(1)
rounds using the global network
\mathsf{NCC}
(see
[
1
]
).
3
3

3

Aggregation (e.g., computing of a maximum) of one value per node in
\smash{\widetilde{O}}(1)
in
\mathsf{NCC}
is not very hard, in particular if we are allowed to use randomization,
[
1
]
also offers a deterministic solution.

Since we alternate between a round of
\mathsf{LOCAL}
and a
\smash{\widetilde{O}}(1)
round aggregation via
\mathsf{NCC}
, the overall running time is
\smash{\widetilde{O}}(d^{\prime})
, where

is the depth to which we have to explore locally such that

\max\big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\big)=\min_{d\in[D_{G}]}\max\big(\tfrac{k}{N(d)\gamma},d\big)=\mathcal{NQ}(G,k,\gamma),

so it remains to quantify

.
As in our previous proof we use that

is strictly increasing in

, thus
\tfrac{k}{N(d)\gamma}
decreases strictly in
d
. Therefore, if after some
(d^{\prime}+1)
-th round (assuming

) in
\mathsf{LOCAL}
and the subsequent aggregation the nodes observe the condition

\max\big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\big)\leq\max\big(\tfrac{k}{N(d^{\prime}+1)\gamma},d^{\prime}\!+\!1\big)

then this term does not get any smaller for any

) thus
\mathcal{NQ}(G,k,\gamma)=\max\big(\tfrac{k}{N(d^{\prime})\gamma},d^{\prime}\big)

3
Neighborhood Quality - Upper Bound for
(k,\!\ell)
-SP

In this section we give an approximation algorithm with stretch
(1\!+\!\varepsilon)
for the
(k,\ell)
-SP problem for certain parameters of
k,\ell
that takes
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds for any graph
G=(V,E)
, which is competitive with the best algorithm optimized for
G
up to
\smash{\widetilde{\Theta}}(1)
factors (however the latter will only become apparent in Section
4
, where we show a corresponding lower bound that even holds for the
(k,1)
-SP problem). In particular, our solution works for
\ell\in\smash{\widetilde{O}}(1)
arbitrary sources and up to
\ell\leq\mathcal{NQ}(G,k,\gamma)
i.i.d. random sources.

To prove this, we draw on a recent algorithm
[
15
,
14
]
, which in turn employs techniques by
[
12
]
, to solve the SSSP problem in just
\smash{\widetilde{O}}(1)
rounds in the
\mathsf{HYBRID}
model. We express their result in the following Lemma.

Lemma 12

(see
[
14
]
)
.

A
(1\!+\!\varepsilon)
-approximation of SSSP can be computed in
\smash{\widetilde{O}}(1/\varepsilon^{2})
rounds in the
\mathsf{HYBRID}
model, w.h.p.
Furthermore, the
\ell
-SSP problem can be solved in
\smash{\widetilde{O}}\big(\!\sqrt{\ell/\gamma}\cdot\tfrac{1}{\varepsilon^{2}}\big)
rounds (for
\varepsilon>0
) w.h.p. in the
\mathsf{HYBRID}(\infty,\gamma)
model with stretch
3\!+\!\varepsilon
.

We stress that Lemma
12
by itself does not give a universally tight solution, since the corresponding parameter
\mathcal{NQ}(G,k,\ell)
for
\ell
could be very small, i.e.,
\mathcal{NQ}(G,k,\ell)\ll\sqrt{\ell}
(in case nodes have quite large neighborhoods in relative proximity). However, the result above can be used for a universally tight solution of the
(k,\ell)
-SP problem as follows.

We approximate the
\ell
-SSP problem where the
\ell\leq\mathcal{NQ}(G,k,\gamma)
target nodes take the role of source nodes. In particular, by Lemma
12
, all
k
source nodes learn their distance to each of the
\ell
targets. Thus we would be able to solve the
(k,\ell)
-SP problem if the
k
sources can communicate the corresponding distances to the
\ell
target nodes.

This corresponds to a message routing problem where all
k
source nodes have to deliver a message to each of the
\ell
targets. In Section
3.2
we show that this message routing problem can be solved in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds by gearing some of the techniques of
[
7
]
(algorithms for “token routing”) for the parameter
\mathcal{NQ}(G,k,\gamma)
by computing a structure of adaptive helper sets (Section
3.1
).
Here, two bottlenecks that prohibit a larger set of target nodes emerge.

The first bottleneck is the number
k
of messages that each target node has to receive. This is where we have to leverage the neighborhood quality
\mathcal{NQ}(G,k,\gamma)
and the random selection of target nodes. The neighborhood quality gives each target node access to enough neighbors that allows it to effectively receive all those messages. The random selection of target nodes implies that these are well spread over in the local network, thus none has to share its neighbors with too many others w.h.p.

The second bottleneck is that source nodes are arbitrary and can be locally highly concentrated. This means they cannot meaningfully rely on other nodes to help them to send their messages, thus the number of messages they have to send (and thus
\ell
) needs to be bounded.

3.1
Adaptive Helper Sets

To work around those bottlenecks and solve this routing problem we adapt the structure of so called “helper sets”. that was first employed in
[
6
]
and our definition accommodates the neighborhood quality of a graph
G
.

Definition 13

(cf.
[
6
]
)
.

Let
G=(V,E)
,
k\in[n]
and let
W\subseteq V
either be a set of
\ell\leq\mathcal{NQ}(G,k,\gamma)
i.i.d. random nodes or
\smash{\widetilde{O}}(1)
arbitrary nodes.
A family
\{H_{w}\subseteq V\mid w\in W\}
of
adaptive helper sets
has the following properties.

(1) Each
H_{w}
has size
\smash{\widetilde{\Theta}}\big(k/\gamma\mathcal{NQ}(G,k,\gamma)\big)
.

(2) For all
u\!\in\!H_{w}\!:hop(w,u)\!\in\!\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
.

(3) Each node is part of at most
\smash{\widetilde{O}}(1)
sets
H_{w}
.

The main difference to the helper sets by
[
6
]
is that we obtain a stronger guarantee on their size, by leveraging the graph parameter
\mathcal{NQ}(G,k,\gamma)
. We prove that we can compute such a helper set in the following lemma.

Lemma 14

(see
[
6
]
)
.

A family of adaptive helper sets
\{H_{w}\subseteq V\mid w\in W\}
as in Definition
13
can be computed w.h.p. in
\smash{\widetilde{O}}(\mathcal{NQ}(G,k,\gamma))
rounds in
\mathsf{HYBRID}(\infty,\gamma)
.

Proof.

First, nodes collaborate to compute the parameter
\mathcal{NQ}(G,k,\gamma)
in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds, see Lemma
11
. The next step is to compute a so called
(\alpha,\beta)
-ruling set
R\subseteq V
for some specific parameters
\alpha,\beta
. Such a set fulfills the property that any two nodes in
R
have hop distance at least
\alpha
and at the same time each node in
v\in V
has a “ruler”
r\in R
within
\beta
hops. If
\beta
is by a logarithmic factor larger than
\alpha
, then
R
can be computed in
\smash{\widetilde{O}}(\alpha)
rounds using only the local network (
[
3
]
achieves this in the
\mathsf{LOCAL}
model, whereas
[
5
]
shows that
\mathsf{CONGEST}
suffices).

We specifically compute a
(\alpha,\beta)
-ruling set with parameters
\alpha=2\mathcal{NQ}(G,k,\gamma)\!+\!1
,
\beta=2\mathcal{NQ}(G,k,\gamma)\lceil\log n\rceil
in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds using
[
3
,
5
]
. The next step to obtain the adaptive helper sets is to compute a clustering
C_{r}\subseteq V,r\in R
based on this ruling set, which partitions the nodes into clusters by each node
v
joining the cluster
C_{r}
of the ruler
r
that has smallest hop distance to
v
(break ties arbitrarily).

In a sense, such a clustering locally partitions
G
into “areas of responsibility”, and allows us to assign each node
w\in W
a helper set
H_{w}
from the cluster
C_{r}
that
w
is located in, in a fair way such that no node in
C_{r}
has to help too many nodes from
W
.
For this to work, the nodes in
C_{r}
first learn the sets
C_{r}
and
C_{r}\cap W
. Note that the diameter of
C_{r}
is in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
, because nodes can always join a cluster that is at distance at most
\beta
thus we can compute the required information in the same number of rounds using the local network. Then, for each node
w\in C_{r}\cap W
, each
v\in C_{r}
joins the helper set
H_{w}
with probability

q=\min\big(\tfrac{k}{\gamma\mathcal{NQ}(G,k,\gamma)}\cdot\tfrac{1}{|C_{r}|}\cdot 8c\ln n,1\big)

It is clear that this assignment of helper sets fulfills property (2) of Definition
13
due to the diameter of
C_{r}
. Let us now look at the size of each helper set. In case
q=1
this means that each node in the cluster
C_{r}
that
w
is located in is drafted into
H_{w}
. Furthermore, within
(\alpha\!-\!1)/2=\mathcal{NQ}(G,k,\gamma)
hops all nodes necessarily belong to
C_{r}
by definition of the ruling set. Now we have to exploit the neighborhood quality of
r
. Using Lemma
8
we have

|H_{w}|=|C_{r}|\geq N(d^{\prime})\geq k/(\mathcal{NQ}(G,k,\gamma)\!+\!1)\gamma\in\smash{\widetilde{\Theta}}\big(k/\gamma\mathcal{NQ}(G,k,\gamma)\big)

In case
q<1
, the expected size of
H_{w}
is
\mathbb{E}(|H_{w}|)=\tfrac{k}{\gamma\mathcal{NQ}(G,k,\gamma)}\cdot 8c\ln n
, which is chosen such that we can conveniently apply a Chernoff bound (given in Lemma
23
for completeness) to lower bound the size of
H_{w}
:

\Pr\Big(|H(X)|\leq(1-\tfrac{1}{2})\mathbb{E}(|H_{w}|)\Big)\leq\exp\Big(\!-\!\tfrac{\mathbb{E}(|H_{w}|)}{8}\Big)\leq\exp\Big(\!-\!\tfrac{8c\ln n}{8}\Big)=\tfrac{1}{n^{c}}.

Therefore, the size of
H_{w}
is at least
\mathbb{E}(|H_{w}|)/2\in\smash{\widetilde{O}}\big(k/\gamma\mathcal{NQ}(G,k,\gamma)\big)
w.h.p.

The third property is clear if
|W|\in\smash{\widetilde{O}}(1)
. Else, we use that since
W
consists of
\ell
nodes chosen i.i.d. randomly from all
n
nodes, thus the expected size of
C_{r}\cap W
is

\mathbb{E}\big(|C_{r}\cap W|\big)=|C_{r}|\cdot\tfrac{\ell}{n}\leq|C_{r}|\cdot\tfrac{\gamma\mathcal{NQ}(G,k,\gamma)}{k}.

Let
J_{v}=|\{w\in W\mid v\in H_{w}\}|
be the random number of helper sets that a node
v\in C_{r}
joins. In expectation these are at most
\mathbb{E}(J_{v})=q\cdot\mathbb{E}\big(|C_{r}\cap W|\big)\leq 8c\ln n
nodes. Again, we employ a Chernoff bound (Lemma
23
) to show
J_{v}\in\smash{\widetilde{O}}(1)
w.h.p.:

\Pr\big(J_{v}\geq(1+1)8c\ln n\big)\leq\exp\big(\!-\!\tfrac{8c\ln n}{3}\big)\leq\tfrac{1}{n^{c}}.

Finally, we have to mention that the number of events that must occur simultaneously w.h.p.
1-\frac{1}{n^{c}}
is polynomial in
n
. The constant
c
can be adapted such that
all
of them occur w.h.p. using a union bound (Lemma
25
).
∎

3.2
Solving the Routing Problem in
\boldmath\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds

Now, we are ready to efficiently solve the routing problem where each source has to send one distance label to each target in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds. Note that Theorem
15
is potentially much better than the
\smash{\widetilde{\Theta}}\big(\!\sqrt{k}\big)
complexity on worst case graphs (cf.
[
6
,
15
]
), as shown out in Lemma
9
.

Theorem 15
.

Given
k
source nodes and
\ell\in\smash{\widetilde{O}}(1)
arbitrary targets or
\ell\leq\mathcal{NQ}(G,k,\gamma)
i.i.d. random target nodes, where each source has
\ell
tokens of size
\smash{O}(\log n)
bits, one for each target. All tokens can be routed to their intended targets in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds w.h.p. in the
\mathsf{HYBRID}(\infty,\gamma)
model.

Proof.

First we compute the parameter
\mathcal{NQ}(G,k,\gamma)
in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds w.h.p. according to Lemma
11
. Let
S
be the set of
k
sources and let
T
be the set of
\ell
targets.
Next, the nodes in
T
broadcast their IDs, which can be accomplished w.h.p. in
\smash{\widetilde{O}}\big(\!\sqrt{\ell}\big)
rounds using the broadcast protocol by
[
2
]
so all nodes can order
T=\{t_{1},\dots,t_{\ell}\}
by ascending IDs. We also aggregate the number of sources
k
in
\smash{\widetilde{O}}(1)
rounds using the aggregation routine by
[
1
]
.

Then each
t\in T
computes its adaptive helper set
H_{t}
in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds w.h.p., as shown in Lemma
14
. The idea for the remaining proof is to assign each sender
s\in S
a helper
v\in H_{t}
of each target node
t\in T
. If
s
would know the helpers that are supposed to receive its tokens, then it could in theory send them its
\ell
tokens sequentially. This assignment can theoretically be done such that no helper has too many tokens to receive. The caveat is that there are too many helpers (close to
k
) and sources (
k
) to make their IDs known to each other in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds, so this is out of the question.

The required information to assign helpers of targets to senders can be condensed significantly by instead relaying tokens via a pseudo-random set of intermediate nodes (cf.
[
6
]
) using a hash-function selected randomly from a suitable universal family
\mathcal{H}
. For this to work it suffices to publish a small random seed using the global network.
The computational and probabilistic aspects of a suitable family
\mathcal{H}
from the literature (in particular the indpenece number of hash values) are summarized in Definition
29
and Lemma
30
in Appendix
B
.

We use a family
\mathcal{H}
consisting of functions
h:[k]\times[\ell]\to[n]
. That is,
h\in\mathcal{H}
maps a pair
(i,j),i\in[k],j\in[\ell]
to an intermediate node with ID
h(i,j)\in[n]
over which the token from source
i
to target
j
will be relayed.
Since the IDs and the order of the target nodes
T=\{t_{1},\dots,t_{\ell}\}
are publicly known, every node can relate index
j
to
ID(t_{j})
. The same is not true for the set of sources
S
, which we cannot publish as it is too large.
To this more cheaply, we define another family
\mathcal{G}
of functions
g:[n]\to[k]
intended to relate IDs of the sources
S
to indices
[k]
. In the following we assume the two random seeds to select
h\in\mathcal{H},g\in\mathcal{G}
are already known, so nodes can use
g,h
(we determine the size of the two seeds afterwards).

We are now ready to describe the transmission process. Here, nodes may assume multiple roles as senders, targets, helpers or intermediates and we are going to analyze and bound the workload of each node later. The rough idea is to first transmit all tokens from senders to intermediate nodes via the global network. Then helpers
H_{t_{j}}
request the tokens for target node
t_{j}
from the intermediate nodes. After the helpers obtained all tokens from intermediate nodes the target node
t_{j}
collects all tokens from its helpers via the local network.

In more detail, first
s\in S
sends each token and its identifier
ID(s)
to the corresponding intermediate node with ID
h\big(g(ID(s)),j\big)
, where
j\in[\ell]
is the intended target. We throttle the number messages per round to batches of size at most
b\in\Omega\big(\gamma/{\log^{2}n}\big)
, to not exceed the global receive capacity
\gamma
of intermediate nodes as we show later (note,
b\geq 1
for some
\gamma\in\smash{\widetilde{\Omega}}(1)
, cf., Definition
2
). After that, all tokens are located at intermediate nodes ready to be retrieved by the helpers
H_{t_{j}}
of target nodes
t_{j}\in T
.

For this purpose, each target
t_{j}\in T
creates
k
tasks
(i,j),i\in[k]
, which it distributes evenly among its helpers using the local network. Subsequently, each helper
v\in H_{t_{j}}
sends a request
(ID(v),i,j)
to the node with ID
h(i,j)
, for each task
(i,j)
it was assigned. Specifically,
v
sends a batch of size
b
of such requests per round. On receiving a request
(ID(v),i,j)
in the previous round, the node with ID
h\big(i,j\big)
responds by sending all tokens with source
s\in S
with
g(ID(s))=i
and target
t_{j}
to
v
. After all helpers received the responses for all of their requests in this way, the corresponding tokens adressed to target
t_{j}
are now located at its helpers
H_{t_{j}}
and the local network can be used to collect them.

We show two properties that complete the proof. Firstly, we prove that the number of rounds it takes to transmit all messages over the local and global network, respectively, is at most
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
. Secondly, we prove that the procedure correctly delivers all tokens addressed to any
t_{j}
. The main challenge here is to show that the number of global messages any node receives in any given round is bounded by
\gamma
, so that no messages are dropped and lost (see Definition
2
).

We start with the round complexity, which by the design of the algorithm can be split into rounds of only local or global communication. The only local communication that takes place is between target nodes
t_{j}\in T
and their helper sets
H_{t_{j}}
to assign tasks and subsequently collect the tokens. Since, by Lemma
14
, helpers
H_{t_{j}}
are within
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
hops of
t_{j}
and since the local network is unrestricted in terms of capacity we can do this for all helper sets in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds.

On the global network, we look at the round complexity of nodes in their different roles. First, the source nodes
S
send their
\ell
tokens sequentially to intermediate nodes defined by the hash functions
h,g
, which takes at most
\smash{\widetilde{O}}(\ell)\in\smash{\widetilde{O}}(\mathcal{NQ}(G,k,\gamma))
rounds. Consider a node
v
that is a member of at least one helper set
H_{t_{j}}
. In total, there are
|H_{t_{j}}|\in\smash{\widetilde{\Theta}}\big(k/\gamma\mathcal{NQ}(G,k,\gamma)\big)
helpers available to
t_{j}
for distributing its
k
tasks
(i,j)
. Thus
v
is assigned at most
\lceil k/|H_{t_{j}}|\rceil\in\smash{\widetilde{O}}(\gamma\mathcal{NQ}(G,k,\gamma))
tasks. By Lemma
14
,
v
has to help at most
\smash{\widetilde{O}}(1)
target nodes
t_{j}\in T
, thus the total assigned tasks by all
t_{j}\in T
, that
v
is a helper of is still
\smash{\widetilde{O}}(\gamma\mathcal{NQ}(G,k,\gamma))
. Since
v
sends
\gamma/b\in\smash{\widetilde{O}}(\gamma)
requests per round, the time to send all requests it was tasked with takes
\smash{\widetilde{O}}(\mathcal{NQ}(G,k,\gamma))
rounds.

Let us now look at some intermediate node
u
, i.e., a node that obtains at least one token by a sender
s
with
g(ID(s))=i
, which
u
has to forward to some helper
v
of some target
t_{j}
, after receiving the according request
(ID(v),i,j)
. We bound the number
X_{u}=|\{(i,j)\mid u=h(i,j)\}|
and the number
Y_{i}=|\{s\in S\mid i=g(ID(s))\}|
for
i\in[k]
. The random value
X_{u}
is the number pairs
(i,j)
that
u
is responsible for. The second is the number of ID’s of some
s\in S
for which an index in
i\in[k]
is “hit” by the hash function
g
, i.e.,
g(ID(s))=i
.

We assume that
h,g
provide i.i.d. randomness with
\smash{O}\big(\ell\log n\big)
independence. Then bounding
X_{u},Y_{i}
corresponds to simple balls into bins problems. For
X_{u}
, we have
k\cdot\ell
balls and
n\,(\geq k)
bins. For
Y_{i}
we have
|S|=k
balls and
k
bins (indices in
[k]
). We give a simple solution for these balls into bins problems in the separate Lemma
27
in Appendix
A
, which implies
X_{u}\in\smash{O}(\ell\log n)
and
Y_{i}\in\smash{O}(\log n)
w.h.p.
We conclude that no intermediate node
u
obtains more than
X_{u}\cdot Y_{i}\in\smash{\widetilde{O}}(\ell)
requests w.h.p., which means that
u
can forward all tokens which are requested within
\smash{\widetilde{O}}(\ell)
rounds w.h.p.

Let us finally come to the correctness, by which we mean that no node receives more than
\gamma
bits via the global network in any given round w.h.p., thus no message is dropped (cf., Definition
2
). Note that only intermediate nodes and helpers have to receive global messages in the algorithm described above. We start by showing the claim for intermediate nodes.

Given that no source node sends more than
b
tokens per round to intermediate nodes selected uniformly at random, then the number of received tokens per round is
\smash{O}(b)
w.h.p., by Lemma
28
. However, intermediate nodes are selected according to some hash function
h(i,j)
, where
g\big(ID(s)\big)=i
. Assuming
h
has independence at least
\Omega(b)
the claim of by Lemma
28
is retained, given that for any two sources
s_{1},s_{2}
it is
g\big(ID(s_{1})\big)\neq g\big(ID(s_{2})\big)
, since then we still have unique keys.

That is unfortunately not the case, however, the number of sources
s\in S
with the same value
i=g\big(ID(s)\big)
can instead be bounded by
Y_{i}\in\smash{O}(\log n)
w.h.p., that is, we can guarantee that no node receives more than
\smash{O}(b\cdot Y_{i})=\smash{O}(b\cdot\log n)
messages per round w.h.p. Given the maximum size of a message is
\smash{O}(\log n)
, the number of bits received per round is at most
\smash{O}(b\cdot\log^{2}n)
. Adjusting the constant in the batch size
b\in\Omega(\gamma/\log^{2}n)
accordingly, no intermediate node receives more than
\gamma
bits per round.

Finally we analyze the seeds for the required hash functions
h,g
that need to be shared. We require
h,g
to map values in sets that are at most as large as the ID space we are working with and these are required to provide i.i.d. randomness with independence
\smash{O}\big(\max(b,\ell\log n)\big)
. By Lemma
30
these requirements can be met using seeds of size at most
\smash{\widetilde{O}}\big(\max(\gamma,\ell)\big)
. Moreover, the seeds can be determined locally by a single node and then broadcast in
\smash{\widetilde{O}}(\ell)
rounds using the broadcast algorithm by
[
2
]
.
∎

3.3
Solving
(k,\ell)
-SSP in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds

It remains to combine the tools derived in the previous two subsections with the fast solutions for
\ell
-SSP to prove the following theorem.

Theorem 16
.

Let
\varepsilon>0
be an arbitrary constant. The
(k,\ell)
-SP problem can solved w.h.p. in the
\mathsf{HYBRID}(\infty,\gamma)
model in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds with stretch
(1\!+\!\varepsilon)
for
\ell\in\smash{O}(1)
and with stretch
(3\!+\!\varepsilon)
for
\ell\leq\mathcal{NQ}(G,k,\gamma)
i.i.d. random target nodes.

Proof.

The first step is to solve the
\ell
-SSP problem for the set of target nodes using Lemma
12
. Since we consider
\varepsilon
constant and
\ell\leq\mathcal{NQ}(G,k,\gamma)
, the round complexity for this step is at most
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
and the stretch is
1\!+\!\varepsilon
or
3\!+\!\varepsilon
depending on the set of target nodes. Afterwards, each source
s
knows its distance to each target
t
, but we require this to be the case the other way around in order to solve the
(k,\ell)
-SSP problem. This is now a simple application of Theorem
15
, where each source
s
puts its distance to each target
t
into a token, and all such tokens are delivered in
\smash{\widetilde{O}}\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds.
∎

4

(k,1)
-SP

We will show that the neighborhood quality parameter constitutes a lower bound for the

-SSP problem, even for the

-SP problem where only a single node must learn its distance to

Theorem 17

Assume each node obtains the local graph

Let us start with some of the required technical claims.

4.1
Technical Properties

The first lemma on the path to prove Theorem
17
shows that the nodes
V^{\prime}
outside a radius

of a node

of size roughly

, assuming

) and an assignment of weights can be given, such that distances from

to nodes in

In the proof we make an important case distinction on two fundamentally different layouts of

Lemma 18
.

Let
G=(V,E)
,

. Let

and there is a weight assignment

, s.t. for any two nodes

for any (fixed) polynomial

Proof.

Consider a breadth first search (BFS) tree

with root

of disjoint sub-trees in

Let

If

Otherwise, consider the tree

Now we can construct of

If this does not yet give us both sets

Next, we show that there is a node

Lemma 20

Let

The claim is clearly true in case of

Lemma 21

Let

\displaystyle\text{from (a): }\max\big(\tfrac{k}{N(v,d_{v})\gamma},d_{v}\big)\leq d_{v}+1\text{ { and } }

4.2
Proof of Theorem
17

Our goal for the remaining proof of the lower bound is to show that a node
v\in V
with a relatively small neighborhood within a radius (which is described by the neighborhood quality), has to learn a lot of information from outside that radius to learn its distance to all
k
sources, even if
v
is completely aware of the topology of
G
.

Since we are not allowed to modify edges of
G
, the remaining variables to “create” information that is unknown to
v
are the distances in
G
and the placement of the set of sources. Nevertheless, we will show a reduction from a so called node communication problem
[
7
]
to the
(k,1)
-SP problem (even when given
G
as part of its input) and we will see that this takes
\Omega\big(\mathcal{NQ}(G,k,\gamma)\big)
rounds.

The node communication problem was introduced as an abstraction for the problem where a part of the network has to learn some information that only another (distant) part of the network knows. To give a rough description of the problem, we have two sets of nodes
A
and
B
at hop distance at least
h
, where nodes in
B
“collectively know” the state of some random variable
X
and need to communicate it to
A
, which has no information about
X
.

It was shown
[
7
,
15
]
that a
\mathsf{HYBRID}
algorithm that solves the node communication problem induces a transcript of the global communication that happened during its execution that can be used to obtain a uniquely decodable code for
X
, which implies a lower bound for the size of the transcript by Shannons source coding theorem.

This, in turn, implies a lower bound for the number of rounds it must have taken to solve the two party communication problem (the formal definition of the node communication problem is given in Appendix

D
). We will use the following, slightly simplified version of the claim from
[
15
]
(which works even given that
G
is known).

Lemma 22

(cf.
[
7
,
15
]
)
.

Let
A,B
be disjoint node sets and let
h\leq\hop(A,B)
and
N:=|\mathcal{B}(A,h-1)|
.
Any algorithm that solves the node communication problem (formally given in Def.
35
) with
A,B
in the
\mathsf{HYBRID}(\infty,\gamma)
model with success probability at least
p
for any r.v.
X
, takes at least
\min\!\big(\frac{pH(X)-1}{N\cdot\gamma},\frac{h}{2}\!-\!1\big)
rounds in expectation.

Proof of Theorem
17
.

Let
G=(V,E)
be an arbitrary graph. Fix the target node
v:=\argmax_{v\in V}\mathcal{NQ}(v)
for which the
(k,1)
-SP problem needs to be solved on
G
. Furthermore, let
d_{v}:=\argmin_{d\in[D_{G}]}\max\big(\tfrac{k}{N(v,d)\gamma},d\big)
(cf. Definition
10
).

Note that we assume
d_{v}\geq 1
, which is the case unless
k\leq\gamma
. If indeed
k\leq\gamma
and
d_{v}=0
would be the case, then
\mathcal{NQ}(G,k,\gamma)\in\Theta(1)
thus the claim of the theorem becomes trivial. Due to Lemma
20
we have
N(v,d_{v}\!-\!1)\geq k/2
.

Now let us invoke Lemma
18
on
V^{\prime}:=V\setminus\mathcal{B}(v,d_{v}\!-\!1)
, which gives us two node sets
V_{1},V_{2}
with
V_{1},V_{2}\geq|V^{\prime}|/2\geq k/16=:k^{\prime}
and a weight assignment
w:E\to[W]
such that distances from
v
to a node in
V_{2}
is by a factor
q(n)
longer than to any node in
V_{1}
for any fixed polynomial
q
.

Consider a random bit string
X=(x_{i})_{i\in[k^{\prime}]},x_{i}\in\{0,1\}
of length
k^{\prime}
. We enumerate
k^{\prime}
nodes from each set
v_{1,i}\in V_{1},v_{2,i}\in V_{2}
with indices
i\in[k^{\prime}]
. Then, a set of
k^{\prime}
source nodes is selected from
V_{1}\cup V_{2}
according to
X
as follows: if
x_{i}=0
we tag
v_{i,1}
as a source, else we tag
v_{i,2}
as a source.

Assume that
v
is given the knowledge of the weight function
w
, the number
k^{\prime}
, the IDs of the nodes in
V_{1},V_{2}
and which index
i
is associated with which pair of IDs in
V_{1},V_{2}
(which can only make the problem simpler). This is in addition to the knowledge of the topology of
G
, which
v
is assumed to have anyway due to this being a universal lower bound.

Note that
v
does not have any initial knowledge whether
v_{1,i}
or
v_{2,i}
was selected as source and thus has no knowledge about
X
. Or to express this in terms of information theory: the initial state of
v
is independent from
X
. To finish setting up the node communication problem let us define
A:=\{v\}
and
B:=V_{1}\cup V_{2}
. Since

we have
\hop(A,B)\geq d_{v}-1
. We choose

. Finally, we have that

.

Presume that we solve the
(k,1)
-SP problem with approximation factor at most

(where the polynomial

with probability at least

.

We have therefore solved the node communication problem with the following parameters. The node

has learned, with probability of success

, the state a random variable

which it previously had zero knowledge of, which has Shannon entropy

(see Def.

Plugging those parameters into Lemma

.

It remains to relate this lower bound for the number of rounds to solve

-SP to the neighborhood quality

\displaystyle\min\big(a\cdot\tfrac{k}{N(v,d_{v}-1)\cdot\gamma},b\cdot d_{v}\big)

Lemma

\displaystyle=\min(a,b)\cdot\Big(\smash{\min\limits_{d\in[D_{G}]}}\max\big(\tfrac{k}{N(d)\cdot\gamma},d\big)-1\Big)

\displaystyle=\min(a,b)\cdot\big(\mathcal{NQ}(G,k,\gamma)-1\big)\phantom{\Big(\Big)}

Appendix A
Basic Probabilistic Concepts

We introduce a few basic probabilistic concepts that we are going to use thorughout this article.

Lemma 23

(Chernoff Bound)
.

We use the following forms of Chernoff bounds in our proofs:

\mathbb{P}\big(X>(1\!+\!\delta)\mu_{H}\big)\leq\exp\Big(\!-\!\frac{\delta\mu_{H}}{3}\Big),

with
X=\sum_{i=1}^{n}X_{i}
for i.i.d. random variables
X_{i}\in\{0,1\}
and
\mathbb{E}(X)\leq\mu_{H}
and
\delta\geq 1
. Similarly, for
\mathbb{E}(X)\geq\mu_{L}
and
0\leq\delta\leq 1
we have

\mathbb{P}\big(X<(1\!-\!\delta)\mu_{L}\big)\leq\exp\Big(\!-\!\frac{\delta^{2}\mu_{L}}{2}\Big).

Remark 24
.

Note that the first inequality even holds if we have
k
-wise independence among the random variables
X_{i}
for
k\geq\lceil\mu_{H}\delta\rceil
(c.f.,
[
13
]
Theorem 2, note that a substitution
\mu_{H}:=(1\!+\!\varepsilon)\mathbb{E}(X)
generalizes the result for any
\mu_{H}\geq\mathbb{E}(X)
).

Lemma 25

(Union Bound)
.

Let
E_{1},\ldots,E_{k}
be events, each taking place w.h.p. If
k\leq p(n)
for a polynomial
p
, then
E\coloneqq\bigcap_{i=1}^{k}E_{i}
also takes place w.h.p.

Proof.

Let
d\coloneqq\deg(p)\!+\!1
. Then there is an
n_{0}\geq 0
such that
p(n)\leq n^{d}
for all
n\geq n_{0}
. Let
n_{1},\ldots,n_{k}\in\mathbb{N}
such that for all
i\in\{1,\ldots,k\}
we have
\mathbb{P}(\overline{E_{i}})\leq\tfrac{1}{n^{c}}
for some (yet unspecified)
c>0
.
With Boole’s Inequality (union bound):

\displaystyle\mathbb{P}\big(\overline{E}\big)\!=\mathbb{P}\Big(\bigcup_{i=1}^{k}\overline{E_{i}}\Big)\leq\sum_{i=1}^{k}\mathbb{P}(\overline{E_{i}})\leq\sum_{i=1}^{k}\!\frac{1}{n^{c}}\leq\frac{p(n)}{n^{c}}\leq\frac{1}{n^{c-d}}

for all
n\geq n_{0}^{\prime}\coloneqq\max(n_{0},\ldots,n_{k})
. Let
c^{\prime}>0
be arbitrary. We choose
c\geq c^{\prime}\!\!+\!d
. Then
\mathbb{P}\big(\overline{E}\big)\leq\frac{1}{n^{c^{\prime}}}
for all
n\geq n_{0}^{\prime}
.
∎

Remark 26
.

If a constant number of events is involved we typically use the above lemma without explicitly mentioning it. It is possible to use the lemma in a nested fashion as long as the number of applications is polynomial in
n
.

An application of the lemmas above is the classic balls into bins problem that on an abstract level describes the maximum number of tasks per node of a i.i.d. random assignment of such tasks to nodes (i.e., balls into bins). We show the following bound.

Lemma 27
.

Given
\ell
bins and
at most

m
balls with
m\in\Omega(\ell\log n)
. We assign each ball to a bin i.i.d. and
k
-wise independently for some
k\in\Omega\big(\tfrac{m}{\ell}\big)
. Then no bin contains more than
a\cdot\tfrac{m}{\ell}
balls w.h.p. for some constant
a>1
and sufficiently large
n
.

Proof.

Let
X_{v}
be the number of balls that bin
v
contains. We have
\mathbb{E}\big(X_{v}\big)\leq\tfrac{m}{\ell}
. By the premise, we have
m\geq\xi\ell\ln n
for some constant
\xi
and large enough
n
. Let
c>0
be an arbitrary constant. We choose
a\geq(1\!+\!\frac{3c}{\xi})
. Then a Chernoff bound (Lemma
23
, combined with Remark
24
) yields

\mathbb{P}\Big(X_{v}\!>\!a\cdot\tfrac{m}{\ell}\Big)\leq\mathbb{P}\Big(X_{v}\!>\!(1\!+\!\tfrac{3c}{\xi})\tfrac{m}{\ell}\Big)\leq\exp\Big(\!-\!\frac{3\xi c\ln n}{3\xi}\Big)=\frac{1}{n^{c}}.

By the union bound given in Lemma
25
the event
\bigcap_{v\in V}X_{v}\!\leq\!\gamma
also takes place w.h.p.
∎

One application of the lemma for the balls into bins problem that we use in this work is given by following lemma.

Lemma 28
.

Presume some algorithm operating on a graph with
n
nodes takes at most
p(n)
rounds for some polynomial
p
. Let
m\in\Omega(\log n)
. Presume that each round, every node sends at most
m
messages via the global network to target nodes in
V
picked uniformly at random and
k
-wise independently for some
k\in\Omega(m)
. Then we can choose constant
a>1
such that every node receives at most
a\cdot m
messages per round w.h.p.

Proof.

Let
X_{v,r}
be the number of messages node
v
receives in round
r
. For bounding the probability of the events
X_{v,r}\leq a\cdot m
for all
v\in V
we are dealing with the balls into bins problem with
m\cdot n
balls and
n
bins. The claim for a single round follows from applying Lemma
27
.
By the union bound given in Lemma
25
the event
\bigcap_{r\leq p(n)}\big(\forall v\in V\!:X_{v,r}\!\leq\!am\big)
also takes place w.h.p.
∎

Appendix B
k-Wise Independent Hash Functions

We will use families of
k
-wise independent hash functions, which are defined as follows.

Definition 29
.

For finite sets
A,B
, let
\mathcal{H}
be a family consisting of hash functions
h:A\to B
. Then
\mathcal{H}
is called
k
-wise independent if for a random function
h\in\mathcal{H}
and for any
k
distinct keys
a_{1},\ldots,a_{k}\in A
we have that
h(a_{1}),\ldots,h(a_{k})\in B
are independent and uniformly distributed random variables in
B
.

From literature we know that such a family of hash functions exists in the following form (c.f.,
[
18
]
).

Lemma 30
.

For
A:=\{0,1\}^{a}
and
B:=\{0,1\}^{b}
, there is a family of
k
-wise independent hash functions
\mathcal{H}:=\{h:A\to B\}
such that selecting a random function from
\mathcal{H}
requires
k\!\cdot\!\max(a,b)
random bits and computing
h(x)
for any
x\in A
can be done in
poly(a,b,k)
time.

Remark 31
.

We can use a random member
h\in\mathcal{H}
of a family as described in Definition
29
to limit the number of messages any node receives in a given round. If all nodes send at most
\smash{O}(\log n)
messages to targets that are determined using that hash function
h
with a distinct key for each message, then any node receives at most
\smash{O}(\log n)
messages per round w.h.p. The details are given in Lemma
28
.

Appendix C
Skeleton Graphs in Hybrid Networks

Skeleton graphs have first been deployed by
[
17
]
and are a very useful concept in the context of the
\mathsf{HYBRID}
model see
[
2
,
6
]
. The basic idea of skeleton graphs is to sample a set of nodes of the local graph
G
with some probability
\frac{1}{x}
and then compute virtual edges among pairs of sampled nodes that are connected by a path of at most
h\in\smash{\widetilde{O}}(x)
hops, where the weight of that virtual edge corresponds to the length of that path. The formal definition is given as follows.

Definition 32
.

A skeleton graph
\mathcal{S}=(V_{\mathcal{S}},E_{\mathcal{S}})
of
G
, is obtained by sampling each node of
G
to
V_{\mathcal{S}}
with prob. at least
\frac{1}{x}
. The edges of
\mathcal{S}
are
E_{\mathcal{S}}\!=\!\{\{u,v\}\!\mid\!u,v\!\in\!V_{\mathcal{S}},\text{hop}(u,v)\!\leq\!h\}
with weights
d_{h}(u,v)
for
\{u,v\}\in E_{\mathcal{S}}
, for some appropriate
h\in\smash{\widetilde{O}}(x)
.

In
[
1
]
shows that
\mathcal{S}
gives a good approximation of the topology of the graph, in particular, with high probability, the distance between sampled nodes in the resulting skeleton graph equals the actual distance in the local graph.

Lemma 33

(cf.
[
1
]
)
.

A skeleton graph
\mathcal{S}=(V_{\mathcal{S}},E_{\mathcal{S}})
as given in Definition
32
is connected and for any
u,v\in\mathcal{S}
it is
d_{\mathcal{S}}(u,v)=d(u,v)
w.h.p. for some appropriately chosen
h\in\smash{\widetilde{O}}(x)
. Furthermore, the skeleton graph can be constructed in
h\in\smash{\widetilde{O}}(x)
rounds in the
\mathsf{LOCAL}
(and thus
\mathsf{HYBRID}
) model.

Appendix D
The Node Communication Problem

Our universal lower bounds is based on a reduction of an intermediate problem called the
node communication problem
, which describes the complexity of communicating information between distinct node sets in the
\mathsf{HYBRID}
model.

In the node communication problem we have two sets of nodes
A
and
B
, where nodes in
A
“collectively know” the state of some random variable
X
and need to communicate it to
B
.
The maximum amount of information that can be conveyed from
A
to
B
via global communication is fundamentally restricted by the nodes within
h
hops that each node set can rely on for global communication.

Definition 34

(Knowledge of Random Variables)
.

Let
V
be the set of nodes in a distributed network. Let
A\subseteq V
and let
S_{A}
be the state (including inputs) of all nodes in
A
(we interpret
S_{A}
as a random variable). Then the nodes in
A
collectively know the state of a random variable
X
if
H(X|S_{A})=0
(see Definition
36
), i.e., there is no new information in
X
provided that
S_{A}
is already known. Similarly, we say that
X
is unknown to
B\subseteq V
, if
H(X|S_{B})=H(X)
, meaning that all information in
X
is new even if
S_{B}
is known. Equivalently, we can define this as
S_{B}
and
X
being independent. We can extend these definitions to communication parties Alice and Bob with states
S_{\text{Alice}}
and
S_{\text{Bob}}
where Alice knows
X
if
H(X|S_{\text{Alice}})=0
and
X
is unknown to Bob if
H(X|S_{\text{Bob}})=H(X)
.

We can now set up the node communication problem.

Definition 35

(Node Communication Problem)
.

Let
G=(V,E)
be some graph. Let
A,B\subset V
be disjoint sets of nodes and
h:=hop(A,B)
. Furthermore, let
X
be a random variable whose state is collectively known by the nodes
A
but unknown to any set of nodes disjoint from
A
. An algorithm
\mathcal{A}
solves the
node communication problem
if the nodes in
B
collectively know the state of
X
after
\mathcal{A}
terminates. We say
\mathcal{A}
has success probability
p
if
\mathcal{A}
solves the problem with probability at least
p
for
any
state
X
can take.

The Shannon entropy of a random variable
X
can be thought of as the average information conveyed by a realization of
X
and is defined as follows.

Definition 36

(Entropy, c.f.,
[
16
]
)
.

The Shannon entropy of a random variable
X\!:\!\Omega\!\to\!S
is defined as
H(X):=-\!\sum_{x\in S}\mathbb{P}(X\!=\!x)\log\big(\mathbb{P}(X\!=\!x)\big)
. For two random variables
X,Y
the joint entropy
H(X,Y)
is defined as the entropy of
(X,Y)
. The conditional entropy is
H(X|Y)=H(X,Y)-H(Y)
.
