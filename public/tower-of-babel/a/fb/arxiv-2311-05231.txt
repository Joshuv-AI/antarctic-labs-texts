An optimal chromatic bound for the class of { P 3 ∪ 2 ​ K 1 , P 3 ∪ 2 ​ K 1 ¯ } \{P_{3}\cup 2K_{1},\overline{P_{3}\cup 2K_{1}}\} -free graphs
Athmakoori Prashant, S. Francis Raj

Abstract
In 1987, A. Gyárfás in his paper “Problems from the world surrounding perfect graphs” posed the problem of determining the smallest χ \chi -binding function for 𝒢 ⁡ ( F , F ¯ ) \mathcal{G}(F,\overline{F}) , when 𝒢 ⁡ ( F ) \mathcal{G}(F) is χ \chi -bounded. So far the problem has been attempted for only forest F F with four or five vertices. In this paper, we address the case when F = P 3 ∪ 2 ​ K 1 F=P_{3}\cup 2K_{1} and show that if G G is a { P 3 ∪ 2 ​ K 1 , P 3 ∪ 2 ​ K 1 ¯ } \{P_{3}\cup 2K_{1},\overline{P_{3}\cup 2K_{1}}\} -free graph with ω ⁡ ( G ) ≠ 3 \omega(G)\neq 3 , then it admits ω ⁡ ( G ) + 1 \omega(G)+1 as a χ \chi -binding function. Moreover, we also construct examples to show that this bound is tight for all values of ω ≠ 3 \omega\neq 3 .
