Matrix Representation of Arbitrarily Controlled Quantum Gates
Marco Lewis, Sadegh Soudjani, Paolo Zuliani

Abstract
Controlled operations allow for the entanglement of quantum registers. In particular, a controlled- U U gate allows an operation, U U , to be applied to the target register and entangle the results to certain values in the control register. This can be generalised by making use of the classical notion of conditional statements, where if a value (or state) satisfies some condition then a sequence of operations can be performed. A method is introduced to represent these generalised controlled operations that are based on classical conditional statements. Throughout examples are given to highlight the use of introduced gates.

Various notions of conditional statements have been suggested in different programming languages.
The
qwhile

[

This has the effect of still using a classical conditional statement, since once qubits are measured they can be considered classical (unless measured in a non-diagonal basis).

Another approach, which is the focus of this article, is the approach taken within the programming languages QCL
[

The problem faced with these conditional statements is that even though gates can be created from specific boolean expressions,
how can an arbitrary boolean function be used to control a quantum operation

For instance, consider the oracle in Grover’s algorithm, which requires a function

The main result of this article is a matrix representation for controlled operations based on an arbitrary function. One can use a common formula to determine the matrix of a controlled gate based on the possible control values and the unitary operations to be performed.

3.1
Binary Controlled Gates (BCGs)

Firstly, we introduce the concept of a

Definition 3.1
.

(Binary Controlled Gate)
Let
y\in[0\mathinner{\ldotp\ldotp}N)
. Define
CU_{y}:\mathcal{H}_{\text{sys}}\to\mathcal{H}_{\text{sys}}
as

CU_{y}\ket{x}\ket{\phi}=\begin{cases}\ket{x}U\ket{\phi}&\text{if $x=y$}\\
\ket{x}\ket{\phi}&\text{otherwise}\\
\end{cases}

(4)

This is a controlled operation that states that if the first
n
qubits are of the form
y
, then the operation
U
should be performed on the remaining
m

Lemma 3.1
.

Let
CU_{y}
be a BCG. Then, we have that

\displaystyle\matrixelement{i}{CU_y}{j}=

(5)

\displaystyle\begin{cases}\matrixelement{i-y M}{U}{j-y M}&\text{if $i,j\in[yM\mathinner{\ldotp\ldotp}(y+1)M)$}\\
\delta_{ij}&\text{otherwise}\end{cases}

Using the lemma just shown, we can verify that BCGs are valid quantum operations (
i.e.,
BCGs are unitary).

Lemma 3.2
.

Let
CU_{y}

3.2
Function Controlled Gates (FCG)

We want to extend the notion of BCGs so that we can perform the same operation on multiple binary values. This is where we introduce the notion of
function controlled gates
.

Definition 3.2
.

(Function Controlled Gate)
Let
f:[0\mathinner{\ldotp\ldotp}N)\to\{0,1\}
. Define
CU_{f}:\mathcal{H}_{\text{sys}}\to\mathcal{H}_{\text{sys}}
as

CU_{f}\ket{x}\ket{\phi}=\begin{cases}\ket{x}U\ket{\phi}&\text{if $f(x)=1$}\\
\ket{x}\ket{\phi}&\text{otherwise}\\
\end{cases}

(6)

The following lemma shows that we can construct an FCG using BCGs.

Lemma 3.3
.

Let
f^{-1}(1)=\{y\in[0\mathinner{\ldotp\ldotp}N):f(y)=1\}
. Then, we have that

CU_{f}=\prod_{y\in f^{-1}(1)}CU_{y}

(7)

Since BCGs are unitary operations and an FCG is a product of BCGs, it trivially follows that an FCG is unitary.

Corollary 3.3.1
.

Let
CU_{f}
be an FCG. Then
CU_{f}
is unitary.

Example 3.3
.

Consider the oracle gate of
f
, denoted
O_{f}
, where
O_{f}\ket{x}\ket{y}=\ket{x}\ket{y \oplus f(x)}
. By adding an ancillary qubit and recalling that
O_{f}^{-1}=O_{f}
, an FCG can be simulated by an oracle of
f
and controlled unitary gate with a control on one qubit (denoted
CU

\displaystyle\ket{x}\ket{0}\ket{\phi}

\displaystyle\xrightarrow{O_{f}\otimes I_{M}}\ket{x}\ket{f(x)}\ket{\phi}

\displaystyle\xrightarrow{I_{N}\otimes CU}\begin{cases}\ket{x}\ket{f(x)}U\ket{\phi}&\text{if $f(x)=1$}\\
\ket{x}\ket{f(x)}\ket{\phi}&\text{otherwise}\end{cases}

\displaystyle\xrightarrow{O_{f}\otimes I_{M}}\begin{cases}\ket{x}\ket{0}U\ket{\phi}&\text{if $f(x)=1$}\\
\ket{x}\ket{0}\ket{\phi}&\text{otherwise}\end{cases}

4
Matrix Representation of Function Controlled Gates

In this section, the main result of the article is shown and examples are given to highlight how it can be modified. Firstly, we show the matrix representation of FCGs.

Theorem 4.1
.

Let
CU_{f}
be a FCG. Then

\displaystyle\matrixelement{i}{CU_f}{j}=\delta_{ij}+f(y)(\matrixelement{i-y M}{U}{j-y M}-\delta_{ij})

(8)

if
i,j\in[yM\mathinner{\ldotp\ldotp}(y+1)M)
and
y\in[0\mathinner{\ldotp\ldotp}N)
.
Otherwise,
\matrixelement{i}{CU_f}{j}=0
.

Note that an FCG can be represented as a matrix of
M\times M
matrices. Given the result of Theorem
4.1
, these sub-matrices are either filled with
0
’s (if not on the diagonal) or are of the form
I_{M}+f(x)(U-I_{M})
where
x
is the current position on the diagonal.

2

2

The matrix form can be seen in
[
9
]
, where only a single qubit is used for the control and target of the operation.

Theorem
4.1
extends a result in
[
15
]
by allowing the unitary operation to act on a quantum register instead of a single qubit. The results of Theorem
4.1
are similar to the notion of a
quantum if-then
(QIT) operator defined in
[

]

The

\text{QIT}(F,U)
is dependent on a single-unitary operation
U

i.e.,

\text{QIT}(F,U)=F\otimes U+(I_{N}-F)\otimes I_{M}

Note that the terms are grouped by the identity on the target register rather than by the boolean function.

5
Applications

The main application of our work is in two areas: simulation of quantum circuits and verification.

For simulation, one advantage is that the user can represent an arbitrary controlled operation using a single FCG rather than a complex series of smaller controlled operations. This also has the additional benefit of providing a single operation to execute, rather than multiple operations that need to be executed.

Similarly, this matrix can be used in verification to check that a specified quantum circuit meets its intended behaviour. By using this format, we now have an easy way to reason about the function for an algorithm. Considering an implementation of Grover’s algorithm, we can specify the behaviour of
f
as

\exists m\text{ such that }\forall x,(f(x)=1\equiv x=m)

and encode in appropriate syntax for different tools.

6
Conclusion

In this article, two types of controlled gates were introduced: binary controlled gates and function controlled gates. We showed properties about these gates and provided examples to give motivation for their use. Specifically, the relation between function controlled gates and quantum conditional statements (such as those used in Silq
[
3
]
) has been demonstrated.

These gates can provide a useful way to easily create gates in simulators or for purposes of verifying quantum programs, requiring the user only to specify a function and unitary operation to perform. Further, these types of gates give a higher level method as to how controlled gates can be constructed, moving away from using circuit descriptions for conditional statements where it is not immediately obvious what a circuit is doing.
