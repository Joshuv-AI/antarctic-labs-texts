Model Checking Disjoint-Paths Logic on Topological-Minor-Free Graph Classes Note: This research is supported by the French-German Collaboration ANR/DFG Project UTMA (ANR-20-CE92-0027, DFG 446200270) “Unifying Theories for Multivariate Algorithms”. Journal: arXiv
Nicole Schirrmacher ⋆⋆ , Sebastian Siebertz ⋆⋆ , Giannos Stamoulis ⋆⋆⋆ Dimitrios M. Thilikos ⋆⋆⋆ , Alexandre Vigny ⋆⋆

Abstract
Disjoint-paths logic , denoted 𝖥𝖮 ​ + ​ 𝖣𝖯 \mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP} , extends first-order logic ( 𝖥𝖮 \mathsf{FO} ) with atomic predicates 𝖽𝗉 k ​ [ ( x 1 , y 1 ) , … , ( x k , y k ) ] \mathsf{dp}_{k}[(x_{1},y_{1}),\ldots,(x_{k},y_{k})] , expressing the existence of internally vertex-disjoint paths between x i x_{i} and y i y_{i} , for 1 ⩽ i ⩽ k 1\leqslant i\leqslant k . We prove that for every graph class excluding some fixed graph as a topological minor, the model checking problem for 𝖥𝖮 ​ + ​ 𝖣𝖯 \mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP} is fixed-parameter tractable. This essentially settles the question of tractable model checking for this logic on subgraph-closed classes, since the problem is hard on subgraph-closed classes not excluding a topological minor (assuming a further mild condition of efficiency of encoding).



Keywords:
Algorithmic meta-theorems, First-order logic, Separator logic, Disjoint paths logic, Topological minors, Fixed-parameter tractability.

Introduction

The model checking problem for a logic
\mathcal{L}
gets as input a structure and an
\mathcal{L}
-sentence and the question is to decide whether the sentence is true in the structure. Therefore, the model checking problem for
\mathcal{L}
expresses all
\mathcal{L}
-definable problems. For this reason, tractability results for model checking problems are often called
algorithmic meta theorems
, as they explain and unify tractability for all problems definable in the considered logic
\mathcal{L}
. A prime example of an algorithmic meta theorem is Courcelle’s theorem
[
5
]
stating that every problem definable in monadic second-order logic (
\mathsf{MSO}
) can be solved in linear time on every graph class with bounded treewidth. An algorithmic meta theorem not only provides a quick way to establish tractability of problems but in many cases, its proof abstracts away the essence of the algorithmic techniques required to solve them. Courcelle’s theorem captures the decomposability of
\mathsf{MSO}
-definable problems and a corresponding dynamic programming approach over tree decompositions of small width. Courcelle’s theorem was extended to graph classes with bounded cliquewidth
[
6
]
and it is known that these are essentially the most general graph classes on which we can expect efficient
\mathsf{MSO}
model
checking
[
21
,
30
]
.

Also the first-order (
\mathsf{FO}
) model checking problem has received considerable attention in the literature, see e.g.
[

[

\mathsf{FO}

\mathsf{FO}
, and, in some form, locality-based methods constitute the basis of all of the mentioned model checking results for
\mathsf{FO}
. Grohe, Kreutzer, and Siebertz
[
27
]
showed that the
\mathsf{FO}
model checking problem is fixed-parameter tractable on nowhere dense graph classes and when considering subgraph-closed classes this result is optimal
[
11

.
In a recent breakthrough, it was shown that the problem is fixed-parameter tractable on classes with bounded twin width
[
4

and, moreover, this result is optimal when considering classes of ordered structures
[

.

While
\mathsf{FO}
can express many interesting algorithmic properties, it also has some shortcomings. In particular, it cannot count and it can express

is most probably not fixed-parameter tractable even on planar graphs of maximum degree three
[
25
]
. Furthermore, these logics still fall short of being able to express many interesting algorithmic problems, involving “non-local” queries, studied in contemporary algorithmics. A classic problem of this kind is the
Disjoint Paths

Given a graph

Clearly, asking for a path joining pairs of terminals is not a local query as the size of such a path is unbounded.

Our results.

In this work, we prove that for every graph class excluding a fixed graph as a topological minor, the model checking problem for
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
is fixed-parameter tractable. More precisely, we prove the following result.

Theorem 1.1
.

Let
\mathscr{C}_{H}
be the class of graphs excluding a fixed graph
H
as a topological minor. Then, there is an algorithm that, given
G\in\mathscr{C}_{H}
and an
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
formula
\varphi(\bar{x})
and
\bar{v}\in V(G)^{|\bar{x}|}
, decides whether
G\models\varphi(\bar{v})
in time
f(\varphi)\cdot|V(G)|^{3}
, where
f
is a computable function depending on
H
.

This essentially settles the question of tractable model checking for
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
on subgraph-closed classes, since it is already known (see
[
38
]
) that the model checking problem for separator logic is AW[
\star
]-hard on subgraph-closed classes that do not exclude a topological minor and admit efficient encoding.

Beyond the direct application to classes that exclude a topological minor,
Theorem 1.1
has further applications for the design of parameterized algorithms as follows.
Suppose that
\Pi
is some
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
-expressible parameterized problem whose instance is a graph

and some integer

Suppose also

The topological minor containment of some particular graph (whose size depends on

Then, because of

As a characteristic example of the above, we mention the

Given a graph

Fomin, Lokshtanov, Panolan, Saurabh, and Zehavi proved in

Our techniques.

Our meta theorem combines the approaches of both
[
22
]
and
[
36
]
.
We start by decomposing the input graph into unbreakable parts, using the decomposition of Cygan, Lokshtanov, Pilipczuk, Pilipczuk, and Saurabh
[
7
]
.
On each part, we distinguish two cases. We handle the first case, when a part excludes a minor, by the model checking result for classes with excluded minors
[
22
]
.
In the second case, when a part contains large minors, we use a variant of the “
generic folio lemma
” proved by Robertson and Seymour in
[
37
]
, which was used by Grohe, Kawarabayashi, Marx, and Wollan
[
26
]
in order to show that testing topological minor containment is fixed-parameter tractable.
Based on this lemma, we prove that every formula
\varphi(\bar{x})
of disjoint-paths logic on unbreakable graphs with large complete graphs as minors is in fact equivalent to another first-order formula
\psi(\bar{x})
. This generalizes the results of
[
38
]
for separator logic to disjoint paths logic on unbreakable graphs with large clique minors.
We then use a dynamic programming approach over tree decomposable graphs to combine the solutions of the unbreakable parts into a global solution.

Our dynamic programming approach deviates from the standard approach for
\mathsf{MSO}
or
\mathsf{FO}
, which is based on the computation and combination of types building on the Feferman-Vaught decomposition theorem for these logics.
A similar decomposition also holds for disjoint paths logic, however, when decomposing over larger separators, the number of disjoint paths that need to be queried increases. As a consequence, the decomposition theorem cannot be applied unboundedly often in the dynamic programming procedure.
Instead, our approach uses the ideas of
[
34
]
and
[
26
]
, where large structures are replaced by small structures of the same type.
However, since the satisfiability problem already of plain
\mathsf{FO}
is undecidable, it is not possible to find representative structures of the same type whose size is bounded by any computable function.
However, since we can solve the model checking problem on each bag locally, we can compute a small representative of the game graph of the model checking game (enriched with further vertices to ensure the same connectivity for a fixed number of disjoint paths of the substructure). With an appropriate rewriting of formulas, this structure can serve as a small representative structure that can be maintained over the dynamic programming procedure.

Let us also comment on why we failed to use the framework of
[
38
]
to combine the solutions of the unbreakable parts into a global solution, but need to fall back to the dynamic programming approach. The obstacle arises from the fact that the tree decomposition into unbreakable parts (with parts of unbounded size) builds on an underlying tree with unbounded branching degree. This requires a “simultaneous” dynamic programming step when progressing from the children of a node to the node itself. Such a step was possible in the case of separator logic, and in fact for all properties that can be encoded as
\mathsf{FO}
formulas with
\mathsf{MSO}
subformulas that are essentially restricted to speak about the tree order of the tree decomposition into unbreakable parts (this logic is called
{\mathsf{FO}(\mathsf{MSO}(\preceq,A)\cup\Sigma)}
in
[
38
]
). We were not able to combine the disjoint paths queries simultaneously over unboundedly many child nodes of a node due to the many possibilities to route disjoint paths through the children (compare with the mentioned problems with the Feferman-Vaught decomposition theorem). This is in contrast to the comparatively simple connectivity queries of separator logic, where the solution for the children is unique and can be encoded into the torso of a bag. Note also that these problems cannot be handled by going to nice tree decompositions with an underlying binary tree. This translation requires a copying of bags (which are unboundedly large) and does not allow an encoding of the decomposition in a tree with a constant number of colors. This would be necessary such that logic cannot identify copies of a vertex.

A result that is weaker than ours follows also from the work of Lokshtanov, Ramanujan, Saurabh, and Zehavi
[
34
]
who proved the following result: For every
\mathsf{CMSO}
sentence
\varphi
, if there is an
\mathcal{O}(n^{d})
algorithm (for
d>4
) to test the truth of
\varphi
over unbreakable graphs, then there is an
\mathcal{O}(n^{d})
algorithm to test the truth of
\varphi
over all graphs. Since
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
is a fragment of MSO, our results on unbreakable graphs together with the result of
[
34
]
implies the
existence
of an
\mathcal{O}(n^{4})
model checking algorithm for every fixed
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
sentence
\varphi
on every class excluding a topological minor.
The main caveat of the proof based on the result of
[
34
]
is that it is non-constructive and we can only conclude the existence of an efficient model checking algorithm.
Au contraire
, our algorithm is fully constructive.

Graphs, unbreakability and disjoint-paths logic

Graphs.

All graphs in this paper are finite, undirected graphs without loops. We write
V(G)
for the vertex set and
E(G)
for the edge set of a graph
G
. We write
\|G\|
for
|V(G)|+|E(G)|
. Let
G
be a graph and

. A

-
v
-path

of pairwise different vertices such that

and

. The vertices

of

and the vertices

and

are its
endpoints
. Two vertices

are
connected
if there exists a path with endpoints
u,v
. A graph is connected if any two of its vertices are connected. Two paths
P,Q
are
internally vertex-disjoint
if no vertex of one path appears as an internal vertex of the other path. For a vertex subset
X\subseteq V(G)
, we write
G[X]
for the subgraph of
G
induced by
X
.

An acyclic and connected graph
T
is a
tree
. Assigning a distinguished vertex

as a root of a tree we impose a tree order
\preceq_{T}
on

by

lies on the unique path (possibly of length

) from
y
to

. If
x\preceq_{T}y
we call

an
ancestor
of
y
in
T
. Note that by this definition every node is an ancestor of itself. We drop the subscript
T
if it is clear from the context.
We write
\mathsf{parent}(x)
for the parent of a non-root node
x
of
T
, and
\mathsf{children}(x)
for the set of children of
x
in
T
. We define
\mathsf{parent}(r)=\bot
.

Minors and topological minors.

A graph

is a

of a graph

if

can be obtained from a subgraph of
G
by contracting edges. A
topological minor model
of a graph

is an injective mapping

that maps vertices of
H
to vertices of
G
and edges of
H
to pairwise internally vertex-disjoint paths in

the path

\eta(u)
and
\eta(v)
.
A graph

is a

of

.
We call a graph

H
-minor-free
and

We call a class

such that every member of
\mathscr{C}
is
H
-(topological-)minor-free.

Folios.

The set of all topological minors of a graph
G
is called the
folio
of
G
. We write
\textsf{is}(H)
for the number of isolated vertices of
H

\delta\in\mathbb{N}
, the

is the set of topological minors

|E(H)|+\textsf{is}(H)\leqslant\delta

in the

\delta
-folio of

(we identify isomorphic graphs).
A

is an undirected graph

\rho\colon R(G)\rightarrow\mathbb{N}
assigning a distinct positive integer label to each vertex of

is a

of a rooted graph

\rho(\eta(v))=\rho(v)

.

There is a bounded number

. For each such graph
X

. The rooted graph
G+X

\delta
-folio. The
x
-tuple of all possible
G+X

\delta
-folios is the
extended
\delta
-folio of
G
.

Let
G
be a rooted graph and let

be a weight function assigning a positive integer to each vertex of

. The
w

\delta
-folio of

is the subset of the
\delta
-folio of

containing those graphs

that have a model

satisfying the additional requirement that for every

, the degree of

in
H
is at most
w(\eta(v))
.

We call the
\delta
-folio of a graph
generic
if it contains every rooted graph
H
with
E(H)+\textsf{is}(H)\leqslant\delta
and
\rho(R(H))\subseteq\rho(R(G))
. We call it
rooted-generic
if it contains every such graph

with the additional requirement that every vertex of

is rooted. Note that hence a generic
\delta
-folio is rooted-generic, but not necessarily every rooted-generic
\delta
-folio is generic. We define the notions of generic and rooted-generic analogously for
w
-bounded folios.

Tree decompositions.

A
tree decomposition
of a graph
G
is a pair
\mathcal{T}=(T,\mathsf{bag})
, where
T
is a rooted tree and
\mathsf{bag}\colon V(T)\to 2^{V(G)}
is a mapping assigning to each node

of
T
its
bag

\mathsf{bag}(x)
, which is a subset of vertices of
G
such that the following conditions are satisfied:

1.

For every vertex
u\in V(G)
, the set of nodes
x\in V(T)
with
u\in\mathsf{bag}(x)
induces a nonempty and connected subtree of
T
.

2.

For every edge
\{u,v\}\in E(G)
, there exists a node
x\in V(T)
with
\{u,v\}\subseteq\mathsf{bag}(x)
.

Recall that if
r
is the root of
T
, then we have
\mathsf{parent}(r)=\bot
. We define
\mathsf{bag}(\bot)=\emptyset
.
For a node
x\in V(T)
, we define
the

of

as

\mathsf{adh}(x)\coloneqq\mathsf{bag}(\mathsf{parent}(x))\cap\mathsf{bag}(x);

the
cone at
x
as

\mathsf{cone}(x)\coloneqq\bigcup_{y\succeq_{T}x}\mathsf{bag}(y);

and the

x

\mathsf{comp}(x)\coloneqq\mathsf{cone}(x)\setminus\mathsf{adh}(x).

The
adhesion
of a tree decomposition

is defined as the largest size of an adhesion, that is,
\max_{x\in V(T)}|\mathsf{adh}(x)|
.

A tree decomposition
\mathcal{T}=(T,\mathsf{bag})
is

if for every non-root node
x\in V(T)

1.

the margin
\mathsf{mrg}(x)
is nonempty;

2.

the graph
G[\mathsf{comp}(x)]
is connected; and

3.

every vertex of
\mathsf{adh}(x)
has a neighbor in
\mathsf{comp}(x)
.

Unbreakability.

A
separation
in a graph
G
is a pair
(G_{1},G_{2})
of subgraphs
G_{1},G_{2}\subseteq G
such that
V(G_{1})\cup V(G_{2})=V(G)
and there is no edge with one endpoint in
V(G_{1})\setminus V(G_{2})
and the other endpoint in
V(G_{2})\setminus V(G_{1})
.
The
separator
of
G
is the intersection
V(G_{1})\cap V(G_{2})
and the
order
of a separation is the size of its separator.

For
q,k\in\mathbb{N}
, a subgraph
H
in a graph
G
is
(q,k)
-unbreakable
if for every separation
(G_{1},G_{2})
of
G
of order at most
k
, we have

|V(G_{1})\cap V(H)|\leqslant q\qquad\textrm{or}\qquad|V(G_{2})\cap V(H)|\leqslant q.

The notion of unbreakability can be lifted to tree decompositions by requiring it from every individual bag.

Definition 2.1
.

Fix
q,k\in\mathbb{N}
. A tree decomposition
\mathcal{T}=(T,\mathsf{bag})
of a graph
G
is strongly
(q,k)
-unbreakable if for every
x\in V(T)
,
G[\mathsf{bag}(x)]
is
(q,k)
-unbreakable in
G[\mathsf{cone}(x)]
.

Theorem 2.2

(
[
8
]
)
.

There is a function
q(k)\in 2^{\mathcal{O}(k)}
such that for every graph
G
and
k\in\mathbb{N}
, there exists a strongly
(q(k),k)
-unbreakable tree decomposition of

. Moreover, given

Given any strongly

-unbreakable decomposition we can refine it so that it becomes regular. Hence, we may assume that the tree decompositions constructed by the algorithm of
Theorem 2.2

Suppose

Signatures.

We will only consider finite relational signatures
\Sigma
consisting of unary (arity
1
) and binary (arity
2
) relation symbols. An alphabet is a signature consisting only of unary relation symbols. A
\Sigma
-structure

consists of a finite universe

and an interpretation

of each
m
-ary relation symbol

. When there is no ambiguity, we will not distinguish between relation symbols and their interpretations.

Graphs are represented as
\Sigma
-structures where the universe is the vertex set and
\Sigma
consists of one binary relation symbol
E(\cdot,\cdot)
, interpreted as the edge relation; that is, as an irreflexive and symmetric relation.

First-order logic (
\mathsf{FO}
).

For a fixed signature
\Sigma
, formulas of first-order logic (
\mathsf{FO}
) are constructed from atomic formulas of the form
x=y
, where
x
and
y
are variables, and
R(x_{1},\ldots,x_{m})
, where
R\in\Sigma
is an
m
-ary relation symbol and
x_{1},\ldots,x_{m}
are variables, by applying the Boolean operators
\neg
,
\wedge
and
\vee
, and existential and universal quantification
\exists x
and
\forall x
.

A variable
x
not in the scope of a quantifier is a free variable (we will not consider formulas with free set variables). A formula without free variables is a sentence.
We write
\varphi(\bar{x})
to indicate that the free variables of a formula
\varphi
are contained in the set of variables
\bar{x}
. A valuation of
\bar{x}
in a set

is a function
\bar{a}\rightarrow\bar{x}\to A
. Let

denote the set of all valuations of
\bar{x}
in

.

The satisfaction relation between
\Sigma
-structures and formulas is defined as usual by structural induction on the formula. When
\mathfrak{A}
is a
\Sigma
-structure,

is a formula with free variables contained in
\bar{x}
, and
\bar{a}\in V(\mathfrak{A})^{\bar{x}}
is a valuation of
\bar{x}

or
\mathfrak{A}\models\varphi(\bar{a})
to denote that

when the variables are evaluated by

. We let
\varphi(\mathfrak{A}):=\{\bar{a}\in A^{\bar{x}}\penalty\ |\penalty\ \mathfrak{A}\models\varphi(\bar{a})\}
.

\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
).

Assume that
\Sigma
contains a distinguished binary relation symbol

that will always be interpreted as the edge relation of a graph. For a
\Sigma
-structure

-structures and

of the variables

{G(\mathfrak{A})\models\mathsf{dp}_{k}[(s_{1},t_{1}),\ldots,(s_{k},t_{k})]}

4
Dynamic Programming using game trees

A standard way to approach the model checking problem is via the model checking game, see e.g.
[
24
]
. This game is played by two players, Falsifier and Verifier, where the aim of Falsifier is to prove that a given formula is false on a given structure, while Verifier tries to prove the opposite. The moves of the players naturally correspond to the quantifiers of the given formula.
After the players have chosen elements
v_{1},\ldots,v_{q}
, the atomic type of this tuple determines the winner of the game.
The game for
\mathsf{FO}
naturally gives rise to a game tree, which however, for a structure of size
n
and a formula with
q
quantifiers is of size
n^{q}
, which is too large for the purpose of efficient model checking. We refer to
[
18
, Chapter 4]
for a nice presentation of the game tree based method. Our goal is to compute an equivalent pruned version of the game tree which is furthermore enriched with disjoint paths information. The data structure for a node in the tree decomposition is this pruned game tree for the subgraph induced by all vertices in bags below the current node. Our presentation is inspired by
[
22
]
.

4.1
Signatures

Our goal is to reduce a given (rooted) graph
G
to a (rooted) graph
G^{\prime}
of small size such that the two graphs have equivalent game trees.

Signatures.

We use
\Psi_{\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}}^{r,h,\ell}
to denote the set of all quantifier-free
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
-formulas with
r
free variables whose vocabulary is the graphs of
h
colors and
\ell
roots. We treat equivalent formulas as equal (and choose one representative for each equivalence class, which is possible for quantifier-free formulas). Then the size of
\Psi_{\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}}^{r,h,\ell}
is upper-bounded by some constant depending only on
r
,
h
, and
\ell
. The
atomic type
of a tuple
\bar{v}\in(R\cup\{\bot\})^{r}
is the set of all atomic formulas that are true for
\bar{v}
in
G
.
Let
G
be a graph with
h
colors and
\ell
roots, let
R\subseteq V(G)
, and let
r\in\mathbb{N}
.
Given
\bar{v}\in(R\cup\{\bot\})^{r}
, we define
\mathsf{pattern}(G,\bar{v})

to be the conjunction of the atomic type of
\bar{v}

and

\mathsf{sig}^{0}(G,R,\bar{v})=\mathsf{pattern}(G,\bar{v}).

Also, for each
i\in[r-1]
and every
\bar{v}\in(R\cup\{\bot\})^{r-i}
,
we define

\mathsf{sig}^{i}(G,R,\bar{v})=\big\{\mathsf{sig}^{i-1}(G,R,\bar{v}u)\mid u\in R\cup\{\bot\}\big\}

Finally, we define

\mathsf{sig}^{r}(G,R)=\big\{\mathsf{sig}^{r-1}(G,R,v)\mid v\in R\cup\{\bot\}\big\}.

It is easy to observe the following (see e.g.
[
18
, Subsection 4.2]
and
[
22
, Lemma 4]
for proofs of this observation using different terminology).

Observation 4.1
.

Let
r\in\mathbb{N}
.
Let
G,G^{\prime}
be two colored rooted graphs and let
R\subseteq V(G)
and
R^{\prime}\subseteq V(G^{\prime})
.
Then if

\mathsf{sig}^{r}({G},R)=\mathsf{sig}^{r}({G}^{\prime},R^{\prime})
, it holds that
for every

\varphi=Q_{1}x_{1}\in R\ \ldots Q_{r}x_{r}\in R\ \psi(x_{1},\ldots,x_{r})
,
where
\psi(x_{1},\ldots,x_{r})
is a quantifier-free formula in
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
,
it holds that

(G,R)\models\varphi\iff(G^{\prime},R^{\prime})\models\varphi.

4.1
implies that to do model checking, it suffices to
compute a small graph with the same signature.

Extended signatures.

Let
G
be a colored rooted graph, let
R\subseteq V(G)
.
We use
B
to denote the set of roots of
G
.
There are
2^{\binom{|B|}{2}}
possible undirected graphs on
B
. For each such graph
H
we write
G+H
for the graph obtained from
G
by setting
G[B]=H
.
Observe that
(G+H,R)
may have a different signature.
The
extended signature
of
(G,R)

is the
2^{\binom{|B|}{2}}
-tuple of all these signatures and is denoted by

\mathsf{extended\text{-}sig}^{r}(G,R)
.

As the set of atomic types is finite, we conclude the following.

Observation 4.2
.

There is a function
f_{1}:\mathbb{N}^{3}\to\mathbb{N}
such that, for all
r,\ell,h\in\mathbb{N}
, every
h
-colored graph
G
with
\ell
roots and every
R\subseteq V(G)
,
there is a minimal set
R^{\prime}\subseteq R
of size at most
f_{1}(r,h,\ell)
such that
\mathsf{extended\text{-}sig}^{r}(G,R)=\mathsf{extended\text{-}sig}^{r}(G,R^{\prime})
.

In the next subsection, we describe how to compute this minimal representative and how to perform dynamic programming on the decomposition given in
Theorem 2.2
.

4.2
Finding small representatives with the same extended signature

In this subsection, we describe how to find small-size graphs of the same extended signature and same extended folio.
We distinguish two cases.
The first case is when the given graph contains a large clique as a minor.
The additional assumption, in this case, is that the graph is unbreakable.

4.2.1
Large clique minors

As a consequence of
3.2
, we have that in the case where the graph contains a large clique minor and is unbreakable, patterns are
\mathsf{FO}
-definable.
The definition of the signatures implies that if patterns are
\mathsf{FO}
-definable, then signatures are also
\mathsf{FO}
-definable.

Corollary 4.3
.

Let
k\in\mathbb{N}
, let
p=4k^{3}
, let
L=q(p)
, where
q
is the function of
Theorem 2.2
,
and let
t=\max\{6k^{3},2kL\}
.
Also, let
G
be a rooted (colored) graph that is
(L,p)
-unbreakable and contains
K_{t}
as a minor.
Then, for every
r\in\mathbb{N}
and every collection of vertices
v_{1},\ldots,v_{r}\in V(G)
, the pattern of
(G,v_{1},\ldots,v_{r})
is
\mathsf{FO}
-definable.
Moreover,
\mathsf{sig}^{r}(G,R)
is
\mathsf{FO}
-definable.

Since
\mathsf{FO}
model checking is tractable in
K_{t}
-topological-minor-free classes, in a
K_{t}
-topological-minor-free (rooted) graph
G
, we can compute its signature in
\mathsf{FPT}
-time.
We will also use the following result from
[
26
]
.

Proposition 4.4

(Lemma 2.2 of
[
26
]
)
.

There is a computable function
f_{2}\colon\mathbb{N}^{2}\to\mathbb{N}
such that
for every
\delta,\ell\in\mathbb{N}
and every extended
\delta
-folio
\mathcal{F}
,
the size of the minimum-size (in terms of vertices) rooted graph
G
on at most
\ell
roots
whose extended
\delta
-folio is
\mathcal{F}
is at most
f_{2}(\delta,\ell)
.

We obtain the following result which allows us to find,
given an unbreakable graph that contains large clique minors,
a small-size graph of the same extended signature and same extended folio.

Lemma 4.5
.

Let
k,\delta,r\in\mathbb{N}
, let
p=4k^{3}
, let
L=q(p)
, where
q
is the function of
Theorem 2.2
, and let
t=\max\{6k^{3},2kL\}
.
There is a constant
c_{k,r,\delta,h,\ell}
and an algorithm that given a colored rooted graph
G
that is

(L,p)
-unbreakable and contains
K_{t}
as a minor and a set
R\subseteq V(G)
,
outputs in quadratic time, a subgraph
G^{\prime}
of
G
(rooted on the same vertices)
and a set
R^{\prime}\subseteq V(G^{\prime})

such that
\mathsf{extended\text{-}sig}^{r}(G,R)=\mathsf{extended\text{-}sig}^{r}(G^{\prime},R^{\prime})
,
G^{\prime}
has the same extended
\delta
-folio as
G
,
and the size of
G^{\prime}
is at most
c_{k,r,\delta,h,\ell}
, where
\ell
is the number of roots of
G
and
h
is the number of colors of
G
.

Proof.

We set
c_{k,r,\delta,h,\ell}=f_{1}(r,h,\ell)\cdot f_{2}(2k,r)+f_{2}(\delta,\ell)
.
By
4.3
, we have that
\mathsf{sig}^{r}(G,R)
is
\mathsf{FO}
-definable.
Therefore, by applying the model checking algorithm of Dvořák, Král, and Thomas
[
11
]
, we can compute, in linear time, a minimal set of vertices
R^{\prime}
such that
\mathsf{extended\text{-}sig}^{r}(G,\mathbf{a},R)=\mathsf{extended\text{-}sig}^{r}(G,\mathbf{a},R^{\prime})
.
By
4.2
, it holds that
|R^{\prime}|\leqslant f_{1}(r,h,\ell)
.
Then, for every tuple
\bar{v}\in(R^{\prime}\cup\{\bot\})^{r}
,
we compute a minimum-size (in terms of vertices) subgraph
F_{\bar{v}}
of
G
rooted at
\bar{v}

such that
\mathsf{pattern}(G,\bar{v})=\mathsf{pattern}(F,\bar{v})
. This is done in quadratic time, using
4.4
.
Also, using
4.4
,
we compute a minimum-size subgraph
F^{\prime}
of
G
(rooted on the same vertices as
G
)
that has the same extended
\delta
-folio.
Thus
G[R^{\prime}\cup\bigcup_{\bar{v}\in(R^{\prime}\cup\{\bot\})^{r}}V(F_{\bar{v}})\cup V(F^{\prime})]
is the desired graph.
∎

Excluding large clique minors

We now deal with the case where the given graph does
not
contain large clique minors.
One can deduce the following result from the proof of
[
22
]
.

Lemma 4.6
.

Let
k,r\in\mathbb{N}
.
There is a constant
c_{k,r,\delta,h,\ell}^{\prime}
and an algorithm that given a colored rooted graph
G
that does not contain
K_{f_{3}(t)}
as a minor
and a set
R\subseteq V(G)
,
outputs in quadratic time, a subgraph
G^{\prime}
of
G
(rooted on the same vertices)
and a set
R^{\prime}\subseteq V(G^{\prime})

such that
\mathsf{extended\text{-}sig}^{r}(G,R)=\mathsf{extended\text{-}sig}^{r}(G^{\prime},R^{\prime})
,
G^{\prime}
has the same extended
\delta
-folio as
G
,
and the size of
G^{\prime}
is at most
c_{k,r,\delta,h,\ell}^{\prime}
, where
\ell
is the number of roots of
G
and
h
is the number of colors of
G
.

To prove
4.6
we need the following result from
[
22
]
.

Proposition 4.7

(Corollary 5 from
[
22
]
)
.

There are two functions
f_{3},f_{4}\colon\mathbb{N}\to\mathbb{N}

and an algorithm that given

t,l\in\mathbb{N}
,
a graph
G
,
and a formula
\varphi\in\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}

outputs, in time

, one of the following:

•

a minor model of

in

,
or

•

a set

,
a set

,
and a function

such that
{\sf tw}(G[V])\leqslant f_{4}(t)
and

G\models\psi(\bar{v})\Leftrightarrow G[V]\models\psi(f_{5}(\bar{v})),

for all

, where
\varphi=Q_{1}x_{1}\ldots Q_{t}x_{t}\psi(x_{1},\ldots,x_{t})
. When given

In fact, the function
f_{5}
of
4.7
maps every tuple
\bar{v}\in V(G)^{t}

of the same pattern.
Therefore, we observe that
\mathsf{extended\text{-}sig}^{r}(G,V(G))=\mathsf{extended\text{-}sig}^{r}(G[V],R)

Proof of
4.6
.

We first apply
4.7
and we obtain
a set
V\subseteq V(G)
,
a set
R\subseteq V
,
and a function
f_{5}\colon V(G)^{t}\rightarrow R^{t}

{\sf tw}(G[V])\leqslant f_{4}(t)

We observe that
\mathsf{extended\text{-}sig}^{r}(G,V(G))=\mathsf{extended\text{-}sig}^{r}(G[V],R)

Also, we enhance

and

by adding all vertices that are needed so that

and

-folio.
This is done using

.
We know that the resulting graph

Using Courcelle’s theorem, we can compute a subgraph
G^{\prime}
of
G[V]
and a set
R^{\prime}\subseteq V(G^{\prime})

such that
\mathsf{extended\text{-}sig}^{r}(G[V],R)=\mathsf{extended\text{-}sig}^{r}(G^{\prime},R^{\prime})
,

4.2.3
Combining game trees

We now prove the following result that intuitively says for every separation
(X,Y)
of a graph
G
,
one can safely replace
G[X]
by a subgraph of it (that also contains
X\cap Y
) of the same extended-signature without affecting the extended-signature of the whole graph.
This is on of the key arguments for the correctness of the dynamic programming algorithm described in
Section

4.3
.

Lemma 4.8
.

Let
G
be a graph rooted at some set
B
, let
R\subseteq V(G)
, and let
r\in\mathbb{N}
.
For every separation
(X,Y)
of
G
where
B\subseteq Y
,
and every annotated subgraph
(G^{\prime},R^{\prime})
of
G[X]
rooted at
X\cap Y
such that

\mathsf{extended\text{-}sig}^{r}(G[X],R)=\mathsf{extended\text{-}sig}^{r}(G^{\prime},R^{\prime})
,
it holds that

\mathsf{extended\text{-}sig}^{r}(G,R)=\mathsf{extended\text{-}sig}^{r}(G[Y\cup V(G^{\prime})],R^{\prime}).

Proof.

We say that two tuples
\bar{v},\bar{v}^{\prime}\in(X\cup\{\bot\})^{r}
are
compatible

if for every
i\in[r]
,

v_{i}=\bot\iff v_{i}^{\prime}=\bot
and
if
v_{i}\in X\cap Y
then
v_{i}=v_{i}^{\prime}
.
Let
\bar{v}\in(X\cup\{\bot\})^{r}
.
An
extension of
\bar{v}
with a tuple of elements of
(Y\setminus X)\cup\{\bot\}

is a tuple of
V(G)\cup\{\bot\}

obtained after replacing the
\bot
-elements of
\bar{v}

with a tuple of elements from
(Y\setminus X)\cup\{\bot\}
.
We use
\mathsf{xpattern}(G,\bar{v})
to denote the tuple of all different patterns, for each
(G^{H},\bar{v})
, where
G^{H}=(V(G),E(G)\cup E(H))
for some undirected graph
H
on the roots of
G
.

Claim 1
.

For every two compatible tuples
\bar{v},\bar{v}^{\prime}\in(X\cup\{\bot\})^{r}
,
if
\mathsf{xpattern}(G[X],\bar{v})

=

\mathsf{xpattern}(G[X],\bar{v}^{\prime})
,
then for every
extension
\bar{u},\bar{u}^{\prime}

of
\bar{v},\bar{v}^{\prime}

with the same tuple of elements from
(Y\setminus X)\cup\{\bot\}
,
it holds that

\mathsf{xpattern}(G,\bar{u})=\mathsf{xpattern}(G,\bar{u}^{\prime})
.

Proof of Claim 1
.

Let
\bar{v},\bar{v}^{\prime}\in(X\cup\{\bot\})^{r}
be two compatible tuples
such that
\mathsf{xpattern}(G[X],\bar{v})=\mathsf{xpattern}(G[X],\bar{v}^{\prime})
.
We fix some extension
\bar{u},\bar{u}^{\prime}

of
\bar{v},\bar{v}^{\prime}

with a collection of vertices from
(Y\setminus X)\cup\{\bot\}
.
We also fix some undirected graph
H
on the roots of
G

and we set
G^{H}=(V(G),E(G)\cup E(H))
.
We know that there is some
\psi\in\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
such that
\psi(\bar{u})=\mathsf{pattern}(G^{H},\bar{u})
.
By definition,
G^{H}\models\psi(\bar{u})
.

For every
\mathsf{dp}_{k}[(x_{1},y_{1}),\ldots,(x_{k},y_{k})]
that appears in
\psi
,
we will prove that if we set, for every
i\in[k]
,

x_{i}^{\prime}=u_{i}^{\prime}
(resp.
y_{i}^{\prime}=u_{i}^{\prime}
), if
x_{i}=u_{i}
(resp.
y_{i}^{\prime}=u_{i}
) and
x_{i}^{\prime}=x_{i}
(resp.
y_{i}^{\prime}=y_{i}
),
if
x_{i}\in X\cap Y
(resp.
y_{i}\in X\cap Y
),
then
G\models\mathsf{dp}_{k}[(x_{1},y_{1}),\ldots,(x_{k},y_{k})]
if and only if
G\models\mathsf{dp}_{k}[(x_{1}^{\prime},y_{1}^{\prime}),\ldots,(x_{k}^{\prime},y_{k}^{\prime})]
.

Suppose that
G\models\mathsf{dp}_{k}[(x_{1},y_{1}),\ldots,(x_{k},y_{k})]
.
This implies the existence of pairwise internally vertex-disjoint paths
P_{1},\ldots,P_{k}
in
G
,
where for every
i\in[k]
,

P_{i}
is an
(x_{i},y_{i})
-path.
The following arguments are inspired by the proof of
[
26
, Lemma 2.4]
.
We define a graph
F^{\star}
on
(X\cap Y)\cap\bigcup_{i\in[k]}V(P_{i})
such that two vertices
a,b
of
F^{\star}
are adjacent if there is some
i\in[k]
and a subpath of
P_{i}
with endpoints
a
and
b
and every internal vertex in
Y\setminus X
.
For every
ab\in E(F^{\star})
, we denote by
P_{ab}
this subpath.
For every path
P
in
G
that has endpoints in
X
, we use
P^{\langle X\rangle}
to denote
the path of
G[X]^{F^{\star}}
obtained by replacing subpaths of
P
whose internal vertices are in
Y\setminus X
by the appropriate edges of
F^{\star}
.
Similarly, if
Q
is a path of
G[X]^{F^{\star}}
, we denote by
Q^{(Y)}
the path of
G
obtained by replacing each edge
ab
of
F^{\star}
by the corresponding path
P_{ab}
.
For every
i\in[k]
,
we define a path
\hat{P}_{i}
as follows:

•

if
x_{i},y_{i}\in X
, then
\hat{P}_{i}=P_{i}^{\langle X\rangle}
,

•

if
x_{i}\in X
and
y_{i}\notin X
then
\hat{P}_{i}
is the
(x_{i},z_{i})
-subpath of
P_{i}
, where
z_{i}
is the last vertex of
P_{i}
(traversing from
x_{i}
to
y_{i}
) that belongs to
X
(we define
\hat{P}_{i}
analogously when
y_{i}\in X
and
y_{i}\in X
),

•

if
x_{i},y_{i}\notin X
, and
P_{i}
does not intersect
X
, then
\hat{P}_{i}
is defined as the empty graph,

•

if
x_{i},y_{i}\notin X
and
P_{i}
intersects
X
at a single vertex
z
, then
\hat{P}_{i}
is the trivial
(z,z)
-path,

•

if
x_{i},y_{i}\notin X
and
P_{i}
intersects
X
at least twice, then if
z
and
w
are the first and the last vertex of
P_{i}
in
X
, then
\hat{P}_{i}
is the
(z,w)
-subpath of
P_{i}^{\langle X\rangle}
.

Observe that the paths
\hat{P}_{1},\ldots,\hat{P}_{k}
are pairwise internally vertex-disjoint paths in
G[X]^{F^{\star}}
.
The fact that
\mathsf{xpattern}(G[X],\bar{v})=\mathsf{xpattern}(G[X],\bar{v}^{\prime})
implies the existence of a collection of paths
\hat{Q}_{1},\ldots,\hat{Q}_{k}
, where if
\hat{P}_{i}
has endpoints
z,w
then
\hat{Q}_{i}
has endpoints
z^{\prime},w^{\prime}
, where
z^{\prime}=v_{j}^{\prime}
if
z=v_{j}
(resp.
w^{\prime}=v_{j}^{\prime}
if
w=v_{j}
) for some
j\in[r]
,
and
z^{\prime}=z
(resp.
w^{\prime}=w
) otherwise, and
\hat{Q}_{1},\ldots,\hat{Q}_{k}

are pairwise internally vertex-disjoint paths in
G[X]^{F^{\star}}
.
Note that, if we set
Q_{i}=\hat{Q}_{i}^{(Y)}
for each
i\in[k]
,
then each
Q_{i}
is an
(x_{i}^{\prime},y_{i}^{\prime})
-path and
Q_{1},\ldots,Q_{k}
are pairwise internally vertex-disjoint paths of
G
.
Therefore
G\models\mathsf{dp}_{k}[(x_{1}^{\prime},y_{1}^{\prime}),\ldots,(x_{k}^{\prime},y_{k}^{\prime})]
.

For the reverse implication, i.e., that
G\models\mathsf{dp}_{k}[(x_{1}^{\prime},y_{1}^{\prime}),\ldots,(x_{k}^{\prime},y_{k}^{\prime})]
implies
G\models\mathsf{dp}_{k}[(x_{1},y_{1}),\ldots,(x_{k},y_{k})]
, the proof is symmetric.
Thus,
\mathsf{xpattern}(G,\bar{u})=\mathsf{xpattern}(G,\bar{u})
. This proves the claim.

Using the claim, we can observe that for every annotated subgraph
(G^{\prime},R^{\prime})
of
G[X]
rooted at
X\cap Y
such that

\mathsf{extended\text{-}sig}^{r}(G[X],R)=\mathsf{extended\text{-}sig}^{r}(G^{\prime},R^{\prime})
,
it holds that

\mathsf{extended\text{-}sig}^{r}(G,R)=\mathsf{extended\text{-}sig}^{r}(G[Y\cup V(G^{\prime})],R^{\prime}).

∎

4.3
Proof of
Theorem 1.1

Now we can finally proof
Theorem 1.1
which we repeat for convenience.

Theorem 1.9
.

Let
\mathscr{C}_{H}
be the class of graphs excluding a fixed graph
H
as a topological minor. Then, there is an algorithm that, given
G\in\mathscr{C}_{H}
and an
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
formula
\varphi(\bar{x})
and
\bar{v}\in V(G)^{|\bar{x}|}
, decides whether
G\models\varphi(\bar{v})
in time
f(\varphi)\cdot|V(G)|^{3}
, where
f
is a computable function depending on
H
.

We are given a
K_{t}
-topological-minor-free graph
G
and some formula
\varphi\in\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
.
First, we set
p=4k^{3}
(as in
3.2
) and
c_{\varphi,t}=\max\{c_{k,r},c_{k,r}^{\prime}\}
.
We call the algorithm of
Theorem 2.2
and we compute a
strongly
(q(p),p)
-unbreakable tree decomposition
\mathcal{T}=(T,\mathsf{bag})
of
G
of adhesion at most
q(p)
.
Then, in a bottom-up way, for every node
x\in V(T)
, we compute a graph
G_{x}^{\prime}
of size at most
c_{\varphi,t}
and a set
R_{x}^{\prime}\subseteq V(G_{x}^{\prime})
such that
\mathsf{extended\text{-}sig}^{r}(G_{x}^{\prime},R_{x}^{\prime})=\mathsf{extended\text{-}sig}^{r}(G[\mathsf{cone}(x)],R\cap\mathsf{cone}(x))
and
G_{x}^{\prime}
and
G[\mathsf{cone}(x)]
have the same extended
q(p)
-folio.
This is done as follows:
Suppose that for a node
x\in V(T)
, we have already computed a pair
(G_{z}^{\prime},R_{z}^{\prime})

where

5
Conclusion

In this work, we have fully classified the subgraph-closed classes admitting efficient encoding of topological minors on which model checking for
\mathsf{FO}\hskip 0.6pt\texttt{{+}}\hskip 1.0pt\mathsf{DP}
is fixed-parameter tractable. A natural next question is to study the model checking problem also for dense graph classes that are not necessarily closed under taking subgraphs.

Another interesting question is the following. In
[
36
]
the authors considered a framework where, after a polynomial time preprocessing, queries of separator logic can be answered in constant time. Is the same true for disjoint-paths logic? The most basic question is whether we can answer disjoint-paths queries in constant time (or even linear time) after preprocessing.
Even though we failed to implement the framework for model checking, it may be the case that we can extend the framework for query answering after preprocessing, since we can incorporate the data structure computed by dynamic programming.
Nevertheless, at this point, there are more difficulties because we do not know how to answer disjoint-paths queries in constant time in minor-closed classes.
It seems plausible that we can lift results for bounded genus graphs to almost embeddable graphs and use the structure theorem to improve the running time for classes with excluded minors to linear. Then using our methods we would be able to improve it for all graphs to linear after preprocessing. Based on the nature of the irrelevant vertex technique, it seems unlikely that we can improve the query time to constant.
