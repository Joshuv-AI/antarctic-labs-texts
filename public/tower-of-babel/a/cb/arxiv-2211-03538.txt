On Fork-free T-perfect Graphs
Yixin Cao, Shenghua Wang

Abstract
In an attempt to understanding the complexity of the independent set problem, Chvátal defined t-perfect graphs. While a full characterization of this class is still at large, progress has been achieved for claw-free graphs [Bruhn and Stein, Math. Program. 2012] and P 5 P_{5} -free graphs [Bruhn and Fuchs, SIAM J. Discrete Math. 2017]. We take one more step to characterize fork-free t-perfect graphs, and show that they are strongly t-perfect and three-colorable. We also present polynomial-time algorithms for recognizing and coloring these graphs.

3
Strong t-perfection

The
independent set polytope
of a graph is defined as the convex hull of the characteristic vectors of all independent sets in it. For a graph
G
, we define another polytope
P(G)

as the set of vectors
x\in\mathbb{R}^{V(G)}
satisfying

\displaystyle 0\leq x_{v}

\displaystyle\leq 1

\displaystyle\text{for every vertex }v,

(1)

\displaystyle x_{u}+x_{v}

\displaystyle\leq 1

\displaystyle\text{for every edge }uv,

\displaystyle x(V(C))

\displaystyle\leq\frac{|V(C)|-1}{2}

\displaystyle\text{for every odd cycle $C$ in }G,

where
x(S)=\sum_{v\in S}x_{v}
.
Clearly, the characteristic vector of every independent set of
G
satisfies all the constraints in (
1
). Thus, the independent set polytope is contained in
P(G)
. While the other direction is not true in general:
the vector
x=(\frac{1}{3},\frac{1}{3},\frac{1}{3},\frac{1}{3})^{\mathsf{T}}
is in
P(K_{4})
but is not in the independent set polytope of
K_{4}
because it does not satisfy the clique constraint.
A graph
G
is
t-perfect
if
P(G)
is precisely the independent set polytope of
G
, and
strongly t-perfect
if the system (
1
) is totally dual integral.
It is well known that every strongly t-perfect graph is t-perfect
[
13
,
27
]
, while the other direction remains an open problem.
The
K_{4}
is the smallest graph that is not t-perfect, hence not strongly t-perfect.
For a vertex
v\in V(G)
, the polytope
P(G-v)
is the projection of the intersection of
P(G)
and the hyperplane
x_{v}=0
on
\mathbb{R}^{V(G-v)}
. Therefore, t-perfection is preserved under vertex deletions.
Both t-perfection and strong t-perfection are also invariants with respect to t-contraction
[
17
,
7
]
.

A graph is
perfect
if it does not contain an odd hole or the complement of an odd hole. A graph is perfect if and only if its independent set polytope can be determined by the following linear system
[
25
,
12
]
:

\displaystyle x_{v}

\displaystyle\geq 0

\displaystyle\text{for every vertex }v,

(2)

\displaystyle x(K)

\displaystyle\leq 1

\displaystyle\text{for every clique }K\text{ in }G.

Note that a triangle constraint is both a clique constraint and an odd-cycle constraint. Moreover, the odd-cycle constraints in (
1
) can be restricted to induced odd cycles: those on non-induced ones are redundant.
In a
K_{4}
-free graph, the clique constraint of (
2
) degenerates to vertex, edge, and triangle constraints of (
1
).
On the other hand, if
G
is perfect, then it does not contain odd holes, and odd-cycle constraints of (
1
) degenerates to triangle constraints.
Thus, (
1
) and (
2
) coincide for a
K_{4}
-free perfect graph.
If the system (
2
) is totally dual integral, then
G
is perfect
[
13
,
12
]
.
Lovász
[
22
]
showed that the converse is also true.
Therefore, the system (
2
) is totally dual integral if and only if
G
is perfect; see also
[
27
]
for more details.

The final step of the proof relies on the duality of linear programming, for which we need to recall some known results.
For each weight function
w:V(G)\rightarrow\mathbb{Z}_{\geq 0}
, we can make a linear program out of (
1

. The dual of this linear program is a covering problem.
A

such that every vertex

lies in at least

The

-cover is the sum of the costs of its elements, where the cost of a vertex or an edge is one, and the cost of an odd cycle

(|C|-1)/2

For a vertex set

to denote
\sum_{v\in S}w(v)
. We use

to denote the maximum value of

The following is a consequence of linear programming duality.

(

]
)

A graph

-cover of cost

The following observation of Bruhn and Stein

Note that a vertex set

Proposition 3.8

(
[
7
]
)
.

Let

4
Recognition

We now describe an algorithm to decide whether a fork-free graph is (strongly) t-perfect.
We may assume without loss of generality that the input graph is connected; otherwise, we work on its components one by one.
The algorithm is based on Lemma
3.2
. The only condition of Lemma
3.2
(ii) that cannot be easily checked in polynomial time is that every odd hole has length five.
The following proposition bounds the length of the longest odd holes.

Proposition 4.1
.

Let
G
be a
\{K_{4},\mathrm{fork}\}
-free graph containing a five-hole
H
. If
H
satisfies
(
\star
)
, then
G
cannot contain an odd hole with length longer than
19
.

Proof.

Let
H^{\prime}
be a longest odd hole in
G
. Suppose for contradiction
|H^{\prime}|\geq 21
. At least
|H^{\prime}|-4
vertices of
H^{\prime}
are in
V(G)\setminus V(H)
.
Assume without loss of generality that
|U_{i}\cap V(H^{\prime})|
is maximized with
i=1
.
Then
|U_{1}\cap V(H^{\prime})|\geq\lceil\frac{|H^{\prime}|-4}{5}\rceil\geq 4
.
Since
U_{1}
is an independent set,
|U_{1}\cap V(H^{\prime})|\leq\frac{|H^{\prime}|-1}{2}
. There exists a vertex
x
in
V(H^{\prime})\setminus(V(H)\cup U_{1})
. By Propositions
2.6
(
i
), (
ii
), and (
v
) with
i=1
, the vertex
x
has at most one non-neighbor in
U_{1}\cap V(H^{\prime})
. But then
x
has at least three neighbors in
|H^{\prime}|
, contradicting that
H^{\prime}
is a hole.
∎

We are now ready to present the recognition algorithm and prove Theorem
1.2
.

Proof of Theorem
1.2
.

The input is a fork-free graph
G
.
We start by checking whether it contains a
K_{4}
,
W_{5}
,
C^{2}_{7}
, or
C_{10}^{2}
.
Since
K_{4}
,
W_{5}
,
C^{2}_{7}
, and
C_{10}^{2}
are not t-perfect, we return “no” if any of them is found.
If
G
does not contain a claw, then we call Bruhn–Schaudt algorithm
[
6
]
to decide whether
G
is t-perfect.
We then call the algorithm of Chudnovsky et al.
[
11
]
to test whether
G
contains an odd hole.
Since
G
does not contain
K_{4}
, it cannot contain the complement of any odd hole longer than seven. It does not contain
C^{2}_{7}
, which is the complement of
C_{7}
. Therefore, if
G
does not contain any odd hole, then
G
is perfect, and t-perfect (Proposition
3.1
), and we return “yes.”
In the rest,
G
contains a claw and an odd hole, and we check the conditions of Lemma
3.2
(ii).
We enumerate five-holes, and for each of them, test whether it satisfies
(
\star
)
. If any one does not, then return “no.”
Finally, we check whether
G
contains an odd hole of length between
7
and
19
. If any is found, then we can return “no.” If none is found, every odd hole has length five by Proposition
4.1
. Thus, we can return “yes.”
All the induced subgraphs we need to check have a constant number of vertices, and both algorithms we call
[
6
,
11
]
take polynomial time.
Thus, the whole algorithm runs in polynomial time.
∎
