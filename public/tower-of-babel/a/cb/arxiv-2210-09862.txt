Continuants and convergence of certain continued fractions
Daniel Duverney, Iekata Shiokawa

Abstract
. We give a concise introduction to the theory of continuants and show how Perron used them in his proof of Tietze theorem on the convergence of infinite semi-regular continued fractions, as well as for the study of the convergence of purely periodic continued fractions.

We prove first by induction on
n
that
B_{k,n}\geq 0
for
k\geq 0
and

n\geq-1.
This is true for

and
n=0
for all

Assuming that it is true for

and

we get by (

which proves that
B_{k,n+1}\geq 0
for all

Hence we have

(3.3)

B_{k-1,n+1}-B_{k,n}\geq\left(b_{k}-1\right)\left(B_{k,n}-B_{k+1,n-1}\right)\qquad\left(k\geq 1,n\geq 0\right).

However

This proves (

∎

Lemma 2
.

Let
\alpha
be the semi-regular continued fraction defined by

\lim_{n\rightarrow\infty}B_{n}=+\infty.

Proof.

[
10
, p.150-151]
Let

then by
(
3.2
)

(3.4)

B_{k-1,n+1}-B_{k,n}\geq B_{k+1,n-1}\geq 1\qquad\left(n\geq 1\right).

On the other hand, if
a_{k+1}=-1,
then by (
3.2
) and (
1.8
)

(3.5)

B_{k-1,n+1}-B_{k,n}\geq B_{k,n}-B_{k+1,n-1}\qquad\left(n\geq 0\right).

So in both cases

(3.6)

B_{k-1,n+1}-B_{k,n}\geq\min\left(1,B_{k,n}-B_{k+1,n-1}\right).

Consequently, if

Summing for

(3.7)

a_{k+1}=1\quad\Rightarrow\quad B_{k+n}\geq k+1\qquad\left(k\geq 1,n\geq 1\right).

If

then
B_{k-1,1}-B_{k,0}\geq 1
by taking

in
(
3.5
). Therefore by (

)

Hence summing again for

Now if

then clearly

by (

). On the other hand, if there exist infinitely

then

) and the proof of Lemma

We will need the following lemma, which is closely connected
to the method of power iteration in numerical analysis.

Lemma 3
.

Let
\left(u_{0},v_{0}\right)\in\mathbb{C}^{2}\smallsetminus\left(0,0\right)
and

M=\left(\begin{array}[c]{cc}a&c\\
b&d\end{array}\right),\quad\left(a,b,c,d\right)\in\mathbb{C}^{4},\quad b\neq 0,\quad ad-bc\neq 0.

Let
\lambda_{1}
and
\lambda_{2}
with
\left|\lambda_{1}\right|\geq\left|\lambda_{2}\right|
be the eigenvalues of
M,
and let

(u_{n},v_{n})
be defined recursively by

\left(\begin{array}[c]{c}u_{n+1}\\
v_{n+1}\end{array}\right)=M\left(\begin{array}[c]{c}u_{n}\\
v_{n}\end{array}\right)\quad\left(n\geq 0\right).

Define
\left(x_{1},x_{2}\right)
by
\lambda_{1}=bx_{1}+d
and

\lambda_{2}=bx_{2}+d
. Then:

(i) If
\left|\lambda_{1}\right|>\left|\lambda_{2}\right|,

v_{n}\neq 0
for all large
n
and

(4.1)

\displaystyle\lim_{n\rightarrow\infty}\frac{u_{n}}{v_{n}}

\displaystyle=x_{1}\quad\text{if\hskip 10.22217pt}u_{0}-v_{0}x_{2}\neq 0,

(4.2)

\displaystyle\lim_{n\rightarrow\infty}\frac{u_{n}}{v_{n}}

\displaystyle=x_{2}\quad\text{if\hskip 10.22217pt}u_{0}-v_{0}x_{2}=0.

(ii) If
\left|\lambda_{1}\right|=\left|\lambda_{2}\right|
and
\lambda_{1}\neq\lambda_{2},

u_{n}/v_{n}
is divergent, except if

u_{0}-v_{0}x_{1}=0\quad or\quad u_{0}-v_{0}x_{2}=0.

(iii) If
\lambda_{1}=\lambda_{2},

v_{n}\neq 0
for all large
n
and

\lim_{n\rightarrow\infty}u_{n}/v_{n}=x_{1}.

Proof.

We note first that
\lambda_{1}\neq 0
and
\lambda_{2}\neq 0
since
\det M=ad-bc\neq 0.
Let
f
be the linear transformation of
\mathbb{C}^{2}
whose
matrix in the standard basis is
M.
Let
e_{1},

e_{2},
and
w_{n}

\left(n\geq 0\right)
be defined by

e_{1}=\left(\begin{array}[c]{c}x_{1}\\
1\end{array}\right),\quad e_{2}=\left(\begin{array}[c]{c}x_{2}\\
1\end{array}\right),\quad w_{n}=\left(\begin{array}[c]{c}u_{n}\\
v_{n}\end{array}\right).

It is easy to check that
Me_{1}=\lambda_{1}e_{1}
and
Me_{2}=\lambda_{2}e_{2}.
Hence
e_{1}
and
e_{2}
are eigenvectors of
M
and
f
and they
form a basis of
\mathbb{C}^{2}
if
\lambda_{1}\neq\lambda_{2}
. In this
case, define
\mu_{1}
and
\mu_{2}
by

(4.3)

w_{0}=\mu_{1}e_{1}+\mu_{2}e_{2}.

We observe that

\mu_{1}=0\Leftrightarrow\left|\begin{array}[c]{cc}u_{0}&x_{2}\\
v_{0}&1\end{array}\right|=0\Leftrightarrow u_{0}-v_{0}x_{2}=0

and similarly
\mu_{2}=0\Leftrightarrow u_{0}-v_{0}x_{1}=0.
It results from
(
4.3
) that

(4.4)

w_{n}=f^{n}\left(w_{0}\right)=\mu_{1}\lambda_{1}^{n}e_{1}+\mu_{2}\lambda_{2}^{n}e_{2}\quad\left(n\geq 0\right).

Assume that
\left|\lambda_{1}\right|>\left|\lambda_{2}\right|.
If
\mu_{1}\neq 0,
we can write

w_{n}=\mu_{1}\lambda_{1}^{n}\left(e_{1}+\frac{\mu_{2}}{\mu_{1}}\left(\frac{\lambda_{2}}{\lambda_{1}}\right)^{n}e_{2}\right),

which proves that
v_{n}\neq 0
for all large
n
and (
4.1
) holds. If

\mu_{1}=0,
then (
4.2
) holds by (
4.4
), which proves
(i).

Now assume that
\left|\lambda_{1}\right|=\left|\lambda_{2}\right|
and
\lambda_{1}\neq\lambda_{2}.
Then
\lambda_{2}=\lambda_{1}e^{i\theta}
for some
\theta\in\left]0,2\pi\right[
and by
(
4.4
) we see that

(4.5)

w_{n}=\lambda_{1}^{n}\left(\mu_{1}e_{1}+\mu_{2}e^{in\theta}e_{2}\right)\quad\left(n\geq 0\right).

So if
\mu_{1}=0
or
\mu_{2}=0

is well-defined
and convergent. If
\mu_{1}\neq 0
and
\mu_{2}\neq 0,
then either
v_{n}=0

for infinitely many
n
and
u_{n}/v_{n}

\frac{u_{n}}{v_{n}}=\frac{\mu_{1}x_{1}+\mu_{2}e^{in\theta}x_{2}}{\mu_{1}+\mu_{2}e^{in\theta}}=x_{1}+\left(x_{2}-x_{1}\right)\frac{\mu_{2}}{\mu_{1}e^{-in\theta}+\mu_{2}},

which is divergent since
x_{2}\neq x_{1},

\mu_{1}\neq 0,

\mu_{2}\neq 0
and

\theta\in\left]0,2\pi\right[.
This proves
(ii)
. Finally, if

\lambda_{1}=\lambda_{2},
there exists a basis
\left(e_{1},e_{2}^{\prime}\right)
of
\mathbb{C}^{2}
such that
f(e_{2}^{\prime})=e_{1}+\lambda_{1}e_{2}^{\prime}
and so

(4.6)

w_{0}=\mu_{1}e_{1}+\mu_{2}e_{2}^{\prime}

for some
(\mu_{1},\mu_{2})\in\mathbb{C}^{2}
. As
f^{n}(e_{2}^{\prime})=n\lambda_{1}^{n-1}e_{1}+\lambda_{1}^{n}e_{2}^{\prime},
we get

If
\mu_{2}=0,
we see that

If
\mu_{2}\neq 0,

\lim_{n\rightarrow\infty}\frac{u_{n}}{v_{n}}=\lim_{n\rightarrow\infty}\frac{\left(\mu_{1}\lambda_{1}+n\mu_{2}\right)x_{1}+\lambda_{1}\mu_{2}x_{2}}{\left(\mu_{1}\lambda_{1}+n\mu_{2}\right)+\lambda_{1}\mu_{2}}=x_{1}
