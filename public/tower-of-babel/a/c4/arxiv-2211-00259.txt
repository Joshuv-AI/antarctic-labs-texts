Daniel Carter

Abstract
We prove that { K 3 ¯ , H } \{\overline{K_{3}},H\} -free graphs are not counterexamples to Hadwiger’s Conjecture, where H H is any one of 33 graphs on seven, eight, or nine vertices, or H = K 8 H=K_{8} . This improves on past results of Plummer-Stiebitz-Toft, Kriesell, and Bosse. The proofs are mostly computer-assisted.

2.2

2.2.1

The restriction that a graph has no stable set of size three means that if two vertices have a common nonneighbor, they must be adjacent. Thus if

\left\lceil\frac{\lvert G\rvert+2}{4}\right\rceil\geq\begin{cases}\lceil\frac{\lvert G\rvert}{4}\rceil&\text{if $\lvert G\rvert$ is even,}\\
\lceil\frac{\lvert G\rvert+3}{4}\rceil&\text{if $\lvert G\rvert$ is odd,}\end{cases}

\{\overline{K_{3}}\}

Sometimes we can get different results than Algorithm

4
Final Remarks

Call the
weight
(relative to an implementation
\mathcal{A}
of Algorithm
4
) of input
(H,G)
the sum over the graphs
H^{\prime}
added to
A
at any point in the algorithm (including
H
) of
2^{\lvert V(H^{\prime})\rvert}
, assuming
H\vdash_{\mathcal{A}}G
so that this weight is finite. This measure is designed to give a very rough estimate of the amount of time it takes for Algorithm
4
to prove HC-
\{\overline{K_{3}},G\}
starting from
H
. This is because there are several parts of the algorithm that scale exponentially (or at least super-polynomially) in the size of the graph
H^{\prime}
considered at some point:

•

When one constructs graphs by adding a vertex to
H^{\prime}
while either avoiding or introducing a dominating edge, there may be exponentially many such graphs.

•

In several places we must solve the subgraph isomorphism problem, which is NP-complete in general. Even though this is only polynomial-time for fixed
G
, recall that in some places we check if graphs are
A
-free with
A
containing possibly arbitrarily large graphs, so we are still potentially subject to the full NP-completeness of this problem.

•

Running Algorithm
3
requires possibly constructing an auxiliary graph with exponentially many vertices. Worse, we then try to find a clique cover of this graph with four cliques, which is equivalent to 4-coloring the complement graph and is thus NP-complete in general. The total running time of Algorithm
3
is therefore actually potentially doubly-exponential in the number of vertices of the input.
