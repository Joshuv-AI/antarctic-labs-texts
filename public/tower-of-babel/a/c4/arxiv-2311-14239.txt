Allpass impulse response modelling
Matthew R Flax <flatmax@flatmax.org>

Abstract




This document defines a method for FIR system modelling which is very
trivial as it only depends on phase introduction and removal (allpass
filters). As magnitude is not altered, the processing is numerically
stable. It is limited to phase alteration which maintains the time
domain magnitude to force a system within its linear limits.

1
Introduction

A trivial method for capturing the impulse response of a system is
to force it with impulses. The captured response is the impulse model
(impulse response) of the system. In practice forcing systems with
impulses either requires high energy signals or a very long time to
stack captures to reduce noise. Problems with using high energy signals
is that the systems become nonlinear and the impulse models do not
represent the linear components of system accurately.

By spreading the signal energy out in time, other common approaches
are to use uncorrelated noise signals or chirping sinusoids. The captured
output of the system from these forcing signals is then processed
in magnitude and phase to generate the impulse model of the system.
For example the Levinson-Durban algorithm is an auto-regressive process
which uses signal correlations and cross correlations to generate
the impulse model
[
1
]
. For a long impulse model,
the Levinson-Durban algorithm becomes computationally complex and
takes a long time.

Another direct method for impulse model generation is to simply divide
the captured signal (in the Fourier domain) from the reference signal
which is a simple form of deconvolution. This simple method of deconvolution
is numerically unstable for signals with no power at particular frequencies.

This document introduces a simple method for finite impulse response
(FIR) system identification. It is a very simple approach and is numerically
stable. The approach uses a band limited impulse (Section
2
)
and applies an allpass filter to generate a linear chirp (Section

3
). A system is forced with this
linear chirp (Section
4
) and the impulse
model of the system is produced by removing the phase of the allpass
filter (
5
). As magnitude is not used
in the processing, it is numerically stable.

The accuracy of the technique presented in this document is limited
by the noise level in the captured signal, as noise is not suppressed
by anything other then stacking.

7
Conclusion

This document defines a method for FIR system modelling which is very
trivial as it only depends on phase introduction and removal (allpass
filters). As magnitude is not altered, the processing is numerically
stable. It is limited to phase alteration which maintains the time
domain magnitude to force a system within its linear limits.

The approach starts with a band limited double sided impulse (zero
phase - see Section
2
). The impulse is
filtered (using an allpass filter) to produce a linear chirp, in Section

3
, see Figure
2
.
This chirp is used to force a system (in our example a random system
- shown in Figure
3
). Finally to find the impulse
model of the system, an inverted phase allpass filter is used to produce
a band limited model of the system (see Figure
4
).

The resulting system model captures both the phase and magnitude of
the system, but only within the specified frequency limits of the
band limited impulse.
