), we get

\sum_{n=0}^{\infty}B_{4}(n)q^{n}=\frac{(q^{4};q^{4})^{2}_{\infty}}{(q;q)^{2}_{\infty}}\equiv(q^{2};q^{2})^{3}_{\infty}\equiv(q;q)^{6}_{\infty}\pmod{4}.

(8.6)

Thus, we have

\sum_{n=0}^{\infty}B_{4}(n)q^{4n+1}\equiv q(q^{4};q^{4})^{6}_{\infty}\equiv\eta^{6}(4z)\pmod{4}.

(8.7)

By using Theorem
2.3
, we obtain
\eta^{6}(4z)\in S_{3}(\Gamma_{0}(16),\left(\frac{4^{6}}{\bullet}\right)).
Notice that
\eta^{6}(4z)
has a Fourier expansion i.e.

\eta^{6}(4z)=q-6q^{5}+9q^{9}-\cdots=\sum_{n=1}^{\infty}d(n)q^{n}.

(8.8)

Thus,
d(n)=0
if
n\not\equiv 1\pmod{4},
for all
n\geq 0.
From (
8.7
) and (
8.8
), comparing the coefficient of
q^{4n+1}
, we get

B_{4}(n)\equiv d(4n+1)\pmod{4}.

(8.9)

Since
\eta^{6}(4z)
is a Hecke eigenform (see
[
17
]
), it gives

\eta^{6}(4z)|T_{p}=\sum_{n=1}^{\infty}\left(d(pn)+p^{2}\cdot\left(\frac{4^{6}}{p}\right)d\left(\frac{n}{p}\right)\right)q^{n}=\lambda(p)\sum_{n=1}^{\infty}d(n)q^{n}.

Note that
\left(\frac{4^{6}}{p}\right)=1.
Comparing the coefficient of
q^{n}
on both sides of the above equation, we get

d(pn)+p^{2}\cdot d\left(\frac{n}{p}\right)=\lambda(p)d(n).

(8.10)

Since
d(1)=1
and
d(\frac{1}{p})=0,
if we put
n=1
in the above expression, we get
d(p)=\lambda(p).
As
d(p)=0
for all
p\not\equiv 1\pmod{4}
this implies that
\lambda(p)=0
for all
p\not\equiv 1\pmod{4}.
From (
8.10
) we get that for all
p\not\equiv 1\pmod{4}

d(pn)+p^{2}\cdot d\left(\frac{n}{p}\right)=0.

(8.11)

Now, we consider two cases here. If
p\not|n,
then
replacing
n
by
pn+r
with
\gcd(r,p)=1
in (
8.11
), we get

d(p^{2}n+pr)=0.

(8.12)

Replacing
n
by
4n-pr+1
in (
8.12
) and using (
8.9
), we get

B_{4}\left(p^{2}n+pr\frac{(1-p^{2})}{4}+\frac{p^{2}-1}{4}\right)\equiv 0\pmod{4}.

(8.13)

Since
p\equiv 3\pmod{4},
we have
4|(1-p^{2})
and
\gcd\left(\frac{(1-p^{2})}{4},p\right)=1,
when
r
runs over a residue system excluding the multiples of
p
, so does
r\frac{(1-p^{2})}{4}.

Thus for
p\nmid j,
(
8.13
) can be written as

B_{4}\left(p^{2}n+pj+\frac{p^{2}-1}{4}\right)\equiv 0\pmod{4}.

(8.14)

Now we consider the second case, when
p|n.
Here replacing
n
by
pn
in (
8.11
), we get

d(p^{2}n)=-p^{2}\cdot d\left(n\right).

(8.15)

Further substituting
n
by
4n+1
in (
8.15
) we obtain

d(4p^{2}n+p^{2})=-p^{2}\cdot d\left(4n+1\right).

(8.16)

Using (
8.9
) in (
8.16
), we get

B_{4}\left(p^{2}n+\frac{p^{2}-1}{4}\right)=-p^{2}\cdot B_{4}\left(n\right).

(8.17)

Let
p_{i}
be primes such that
p_{i}\equiv 3\pmod{4}.
Further note that

p_{1}^{2}p_{2}^{2}\cdots p_{k}^{2}n+\frac{p_{1}^{2}p_{2}^{2}\cdots p_{k}^{2}-1}{4}=p_{1}^{2}\left(p_{2}^{2}\cdots p_{k}^{2}n+\frac{p_{2}^{2}\cdots p_{k}^{2}-1}{4}\right)+\frac{p_{1}^{2}-1}{4}.

Repeatedly using (
8.17
) and (
8.14
), we get

\displaystyle B_{4}\left(p_{1}^{2}p_{2}^{2}\cdots p_{k}^{2}p_{k+1}^{2}n+\frac{p_{1}^{2}p_{2}^{2}\cdots p_{k}^{2}p_{k+1}\left(4j+p_{k+1}\right)-1}{4}\right)

\displaystyle\equiv(-p_{1}^{2})\cdot B_{4}\left(p_{2}^{2}\cdots p_{k}^{2}p_{k+1}^{2}n+\frac{p_{2}^{2}\cdots p_{k}^{2}p_{k+1}\left(3j+p_{k+1}\right)-1}{4}\right)\equiv\cdots

\displaystyle\equiv(-1)^{k}(p_{1}^{2}p_{2}^{2}\cdots p_{k}^{2})^{k}\cdot B_{4}\left(p_{k+1}^{2}n+p_{k+1}j+\frac{p^{2}_{k+1}-1}{4}\right)\equiv 0\pmod{4}

when
j\not\equiv 0\pmod{p_{k+1}}.
This completes the proof of the theorem.
∎
