Hyperstability of orthogonally 3-Lie homomorphism: an orthogonally fixed point approach
Vahid Keshavarz ∗ , Sedigheh Jahedi, Themistocles M. Rassias

Abstract
. In this paper, by using the orthogonally fixed point method, we prove the Hyers-Ulam stability and the hyperstability of orthogonally 3-Lie homomorphisms for additive ρ \rho -functional equation in 3-Lie algebras. Indeed, we investigate the Hyers-Ulam stability and the hyperstability of the system of functional equations { f ⁡ ( x + y ) − f ⁡ ( x ) − f ⁡ ( y ) = ρ ⁡ ( 2 ​ f ​ ( x + y 2 ) + f ⁡ ( x ) + f ⁡ ( y ) ) , f ⁡ ( [ [ x , y ] , z ] ) = [ [ f ⁡ ( x ) , f ⁡ ( y ) ] , f ⁡ ( z ) ] \displaystyle\left\{\begin{array}[]{ll}f(x+y)-f(x)-f(y)=\rho(2f(\frac{x+y}{2})+f(x)+f(y)),\\ \\ f([[x,y],z])=[[f(x),f(y)],f(z)]\end{array}\right. in 3-Lie algebras (where ρ \rho is a fixed real number with ρ ≠ 1 \rho\neq 1 ).

Definition 1.1
.

(i):
Let
X\neq\emptyset
and
\bot\subseteq X\times X
be a binary
relation. If
\bot
satisfies the following condition

\exists x_{0};(\forall y;y\bot x_{0})\hskip 5.69046ptor\hskip 5.69046pt(\forall y;x_{0}\bot y),

it is called an orthogonal set (briefly O-set). We denote this O-set by
(X,\bot)
.

(ii):
Let
(X,\bot)
be an O-set. A sequence
\{x_{n}\}_{n\in{N}}
is
called an orthogonal sequence (briefly O-sequence) if

(\forall n;x_{n}\bot x_{n+1})\hskip 5.69046ptor\hskip 5.69046pt(\forall n;x_{n+1}\bot x_{n}).

(iii):
If
(X,\bot)
is an O-set and
(X,d)
is a metric space then
(X,\bot,d)
is an orthogonally metric space. A mapping
f:X\to X
is a
\bot-
continuous in
x\in X
if for each O-sequence
\{x_{n}\}_{n\in{N}}
in
X
with
x_{n}\to x
,
f(x_{n})\to f(x)
. Obviously, every continuous mapping is
\bot-
continuous.

(iv):
Similarly, a Cauchy sequence
\{x_{n}\}
in
X
is said to be a cauchy orthogonally sequence ( briefly, cauchy O-sequence) if
\forall n\in A,

x_{n}\bot x_{n+1}
or
x_{n+1}\bot x_{n}.
An orthogonal space
(X,\bot,d)
is orthogonally complete (briefly O-complete) if every Cauchy O-sequence is convergent.

It is easy to see that every complete metric space is O-complete and
the converse is not true.

(v):
Let
(X,\bot,d)
be an orthogonally metric space and
0<\lambda<1
.
A mapping
f:X\to X
is said to be orthogonality contraction
with Lipschitz constant
\lambda
if

d(fx,fy)\leq\lambda d(x,y)\;\;\ if~x\bot y.

Remember that a Lie algebra is a Banach algebra endowed with the Lie product

[x,y]:=\frac{(xy-yx)}{2}.

Similarly, a 3-Lie algebra is a Banach algebra endowed with the product

\Big[[x,y],z\Big]:=\frac{[x,y]z-z[x,y]}{2}.

for all
x,y,z\in A
.

Definition 1.2
.

Let
A
and
B
be two 3-Lie algebras. A mapping
H:A\to B
is called a orthogonally 3-Lie homomorphism if

(i)
H
is a linear mapping.

(ii) For all
x,y,z\in A
with
x\bot y,~~x\bot z,~~y\bot z.

H([[x,y],z])=[[H(x),H(y)],H(z)].

Theorem 1.3
.

[
22
]

Let
(X,d,\bot)
be an O-complete generalized metric space. Let
T:X\to X
be
a
\perp
-preserving,
\perp
-continuous and
\bot
-
\lambda
-contraction.
Let
x_{0}\in X
satisfy for all
y\in X
,
x_{0}\perp y

or for all
y\in X
,
y\perp x_{0}
, and consider the “O-sequence of successive approximations.
with initial element
x_{0}
”:
x_{0}
,
T(x_{0})
,
T^{2}(x_{0})
, …,
T^{n}(x_{0})
, … .
Then, either
d(T^{n}(x_{0}),T^{n+1}(x_{0}))=\infty
for all

n\geq 0
, or there exists a positive integer
n_{0}
such that
d(T^{n}(x_{0}),T^{n+1}(x_{0}))<\infty

for all
n>n_{0}
. If the second alternative holds, then

(i): the O-sequence of
\{T^{n}(x_{0})\}
is convergent to a fixed point
x^{*}
of

(ii):
x^{*}
is the unique fixed point of

in
X^{*}=\{y\in X:d(T^{n}(x_{0}),y)<\infty\}

(iii): if
y\in X
, then

d(y,x^{*})\leq{1\over 1-\lambda}d(y,T(y)).

(2.1)

(2.2)

In the following theorem, we prove the Hyers-Ulam stability of orthogonally 3-Lie homomorphism in orthogonally 3-Lie algebras.

Theorem 2.2
.

Let
f:A\to B
be a mapping and let
\varphi:A^{2}\to[0,\infty)
and
\psi:A^{3}\to[0,\infty)
be two functions such that there exists an
L<1
with

(2.4)

\displaystyle\|\Delta_{\rho}f(x,y)\|\leq\varphi(x,y)

and

(2.5)

\displaystyle\|\Re f([[a,b],c])\|\leq\psi(a,b,c)

for all
x,y\in V_{\bot}
. If there exists a constant
0<L<1
such that

(2.6)

\displaystyle\varphi\left(\frac{x}{2},\frac{y}{2}\right)\leq\frac{L}{2}\varphi\left({x},y\right)

(2.7)

\displaystyle\psi\left(\frac{a}{2},\frac{b}{2},\frac{c}{2}\right)\leq\frac{L}{2^{3}}\psi\left(a,b,c\right)

for all
x,y,a,b,c\in V_{\bot}
, then there exists a unique orthogonally 3-Lie homomorphism
\Im:A\rightarrow B

such that

(2.8)

\displaystyle\|f(x)-\Im(x)\|\leq\frac{L}{2(1-L)}\varphi\left({x},x\right)

for all
x\in A
.

Proof.

It follows from (
2.6
) and (
2.7
) that

(2.9)

\displaystyle\lim_{n\to\infty}2^{n}\varphi\left(\frac{x}{2},\frac{y}{2}\right)=0\quad,\quad\lim_{n\to\infty}2^{3n}\psi\left(\frac{a}{2},\frac{b}{2},\frac{c}{2}\right)=0

for all
x,y,a,b,c\in V_{\bot}
. Letting
x=y=a=b=c=0
in (
2.9
) we get
\varphi(0,0)=0,\quad\psi(0,0,0)=0.

Consider the set

\Lambda:=\{g:A\to B\quad|\quad g(0)=0\quad g(x)\bot 2g(\frac{x}{2})\quad or\quad 2g(\frac{x}{2})\bot g(x)\}.

For every
g,h\in\Lambda
, define,

d(g,h):=\inf\{k\in(0,\infty)\quad|\quad\|g(x)-h(x)\|\leq k\varphi(x,x)\quad\forall x\in A\}.

Now, put the orthogonally relation
\bot
on
\Lambda
as follows: for all
g,h\in\Lambda

h\bot g\Leftrightarrow h(x)\bot g(x)\quad or\quad g(x)\bot h(x)\quad\forall x\in A.

It is easy to show
(\Lambda,d,\bot)
is an O-complete generalized metric space.

Now, consider the mapping
T:\Lambda\to\Lambda
defined by

Tg(x):=2g(\frac{x}{2})\quad\forall x\in A.

Clearly, T is
\bot
-preserving. As result for all
g,h\in\Lambda
with
g\bot h
and
x\in A,
if
d(g,h)<k,
then

\begin{split}&\|g(x)-h(x)\|\leq k\varphi(x,x)\\
&\|2g(\frac{x}{2})-2h(\frac{x}{2})\|\leq 2k\varphi(\frac{x}{2},\frac{x}{2})\\
&\|2g(\frac{x}{2})-2h(\frac{x}{2})\|\leq Lk\varphi(\frac{x}{2},\frac{x}{2})\\
&d(Tg,Th)\leq Lk.\end{split}

Hence we see that,

d(Tg,Th)\leq Ld(g,h)

for all
g,h\in\Lambda
, that is, T is a strictly
\bot
-contractive self mapping of
\Lambda
with the Lipschitz constant L. The function
T
is
\bot
-continuous. In fact, if
\{g_{n}\}
is an O-sequence in
\Lambda
which converges to
g\in\Lambda
, then for given
\varepsilon>0
, there exists
k>0
with
k<\varepsilon
and
n\in\mathbb{N}
such that

\|g_{n}(x)-g(x)\|\leq k\varphi(x,x)

for all
x\in\mathfrak{A}
and
n\in\mathbb{N}
.

By Theorem
1.3
, there exists a mapping
\Im:A\rightarrow B
satisfying the following:

1)
\Im
is a fixed point of T, i.e.

(2.10)

\displaystyle\Im(x)=2\Im(\frac{x}{2})\quad\forall x\in A.

The mapping
\Im
is a unique fixed point of
T
in set
\Omega=\{g\in\Lambda:d(f,g)<\infty\}
.

\Im
is a unique mapping satisfying (
2.10
) such that there exists a
k\in(o,\infty)
satisfying

\|f(x)-\Im(x)\|\leq k\varphi(x,x)\quad\forall x\in A.

2)
d(T^{n}f,\Im)\to 0
as
n\to\infty
. By Theorem
1.3
there exists a fixed point
\Im
of
T
such that

(2.11)

\displaystyle\Im(x)=\lim_{n\to\infty}2^{n}f(\frac{x}{2^{n}})\quad\forall\quad x\in A

On the other hand, it follows from (
2.4
), (
2.6
) and (
2.9

\begin{split}\|\Delta_{\rho}\Im(x,y)\|&=\lim_{n\to\infty}2^{n}\|\Delta_{\rho}f(\frac{x}{2^{n}},\frac{y}{2^{n}})\|\\
&\leq\lim_{n\to\infty}2^{n}\varphi(\frac{x}{2^{n}},\frac{y}{2^{n}})\\
&=0.\end{split}

So
\Delta_{\rho}\Im(x,y)=0
for all
x,y\in V_{\bot}.
By lemma
2.1
and [

]
,Theorem 2.2]

3)

, which implies that

Corollary 2.3
.

Let

be nonnegative real numbers, suppose

\displaystyle\|\Delta_{\rho}f(x,y)\|\leq\theta(\|x\|^{s}+\|y\|^{s})

for all

Then there exists a unique 3-Lie homomorphism
\Im:A\rightarrow B

such that

(2.14)

\displaystyle\|f(x)-A(x)\|\leq\frac{2\theta}{2^{r}-2}\|x\|^{s},\quad\quad\quad(for\quad s<1)

and

(2.15)

\displaystyle\|f(x)-A(x)\|\leq\frac{2\theta}{2-2^{s}}\|x\|^{s},\quad\quad\quad(for\quad s>1)

for all
x\in A
.

Proof.

The proof follows from Theorem
2.2
by taking

\varphi(x,y)=\theta(\|x\|^{r}+\|y\|^{r})

\psi(a,b,c)=\theta(\|a\|^{s}\cdot\|b\|^{s}\cdot\|c\|^{s}

for all
x,y,a,b,c\in V_{\bot}
. Then we can choose
L=2^{s-1}
in (
2.14
),
L=2^{1-s}
in (
2.15
) and we get the desired result.

Now, we will prove the hyperstability of orthogonally 3-Lie homomorphism in 3-Lie algebras in the following Theorem.

Theorem 2.4
.

Let
f:A\to B
be a mapping and
\varphi:A^{5}\to[0,\infty)
be a function such that

(2.16)

\displaystyle\|\Delta_{\rho}f(x,y)+\Re(a,b,c)\|\leq\varphi(0,y,a,b,c)

for all
x,y,a,b,c\in V_{\bot}.
If there exists a constant
0<L<1
such that

(2.17)

\displaystyle\varphi(0,\frac{y}{2},\frac{a}{2},\frac{b}{2},\frac{c}{2})\leq\frac{L}{2}\varphi(0,y,a,b,c)

for all
x,y,a,b,c\in V_{\bot},
then f is an orthogonally 3-Lie homomorphism.

Proof.

Letting
y=a=b=c=0
in (
2.16
) we have

(2.18)

\displaystyle\left\|f(x)-\frac{1}{2}f(2x)\right\|\leq\varphi(0,0,0,0,0)

for all
x\in A
. On the other hand, it follows from (
2.17
) that

(2.19)

\displaystyle\lim_{n\to\infty}2^{n}\varphi\left(0,\frac{y}{2},\frac{a}{2},\frac{b}{2},\frac{c}{2}\right)=0

for all
y,a,b,c\in V_{\bot}.
But
\varphi(0,0,0,0,0)=0
, so by (
2.16
),
f(x)=\frac{1}{2}f(2x)
and then for
n\in\mathbb{N}
and
x\in A
we get

(2.20)

\displaystyle f(x)=\frac{1}{2^{n}}f(2^{n}x).

From (
2.16
) and (
2.20
) we have

(2.21)

\begin{split}\|\Delta_{\rho}f(x,y)\|&=\frac{1}{2^{n}}\|\Delta_{\rho}f(2^{n}x,2^{n}y)\|\\
&\leq\frac{1}{2^{n}}\varphi\left(0,2^{n}y,0,0,0\right)\\
&=0\end{split}

for all
x,y\in V_{\bot}
. So, letting
n\to\infty
in (
2.21
) and using (
2.19
), we have
\|\Delta_{\rho}f(x,y)\|=0
for all
x,y\in V_{\bot}
.

On the other hand, we have

(2.22)

\begin{split}\|\Re f(a,b,c)\|&=\frac{1}{2^{n}}\|\Re f(2^{n}a,2^{n}b,2^{n}c)\|\\
&\leq\frac{1}{2^{n}}\varphi\left(0,0,2^{n}a,2^{n}b,2^{n}c\right)\\
&=0\end{split}

for all
a,b,c\in V_{\bot}
. Hence, by letting
n\to\infty
in (
2.22
) and using (
2.19
), we have

\Re f(a,b,c)=0\quad\quad\forall a,b,c\in V_{\bot}.

Therefore, f is orthogonally 3-Lie homomorphism.
∎
