Counterexamples to conjectures on the occupancy fraction of graphs
Stijn Cambie, Jorik Jooken

Abstract
The occupancy fraction of a graph is a (normalized) measure on the size of independent sets under the hard-core model, depending on a variable (fugacity) λ . \lambda. We present a criterion for finding the graph with minimum occupancy fraction among graphs with a fixed order, and disprove five conjectures on the extremes of the occupancy fraction and (normalized) independence polynomial for certain graph classes of regular graphs with a given girth.

1.1
Notation and definitions.

In this paper,
G
denotes a graph, and its order is denoted with
n
. We denote with
\alpha(G)
the independence number of
G
, the number of vertices in a maximum independent set. We let
I(G)
be the set of independent sets in
G
and
\left\lvert I(G)\right\rvert
is the number of independent sets of the graph. Here the empty set is counted as well.

For a set
S,
we consider the
partition function

P_{S}(\lambda)=\sum_{s\in S}\lambda^{s},
which is a polynomial in the fugacity
\lambda
.
We define
\mathbb{E}_{S}(\lambda)=\frac{\lambda P^{\prime}_{S}(\lambda)}{P_{S}(\lambda)}
.
3
3

3

P^{\prime}_{S}(\lambda)
represents the derivative of
P_{S}(\lambda)
with respect to
\lambda

This is the expected value when every element
s\in S
is taken with a probability proportional to
\lambda^{s}
and as such called the
expected value
of the set
S
.
If the values of
S
belong to
\{0,1,2,\ldots,k\},
we call the list of non-negative integers representing the number of times (the multiplicity) each element appears in
S
,
(s_{0},s_{1},s_{2},\ldots,s_{k})
the
multiplicity-tuple
of
S
. Here
s_{i}
denotes the multiplicity of
i
in
S
.

Definition 1.1
.

The number of independent sets with
k
vertices in a graph
G
is denoted with
i_{k}(G).

For a graph
G
with independence number
k=\alpha(G)
, let
S
be the set with multiplicity-tuple
\vec{i}(G)=(i_{0}(G),i_{1}(G),\ldots,i_{k}(G)).

Then
P_{G}(\lambda)=P_{S}(\lambda)
and
\alpha_{G}(\lambda)=\frac{1}{\left\lvert V(G)\right\rvert}\mathbb{E}_{S}(\lambda)
are the
partition function
and

of the graph

.

2
Elementary results on expected value of sets

One could expect that the expected value of a randomly drawn element according to a certain probability distribution, would decrease when the elements of the set decrease. It turns out this is not always the case in the hard-core model.

Example 2.1
.

Decreasing a value in a set, can increase the expectation.
Let
S=\{0,2,4\}
and
S^{\prime}=\{0,1,4\}.

Then
\mathbb{E}_{S}(\lambda)=\frac{2\lambda^{2}+4\lambda^{4}}{1+\lambda^{2}+\lambda^{4}}<\frac{\lambda+4\lambda^{4}}{1+\lambda+\lambda^{4}}=\mathbb{E}_{S^{\prime}}(\lambda)
for small positive values of
\lambda
.

While decreasing some elements does not necessarily lead to a decrease of the expected value, restricting the set to the smallest elements does.
When restricting to a subset of large elements, the expected value is larger.

Proposition 2.2
.

Let
S
be a set. Let
S=S_{1}\cup S_{2}
be a partition in some small and some large elements, i.e., where
\max S_{1}\leq\min S_{2}.

Then
\mathbb{E}_{S_{1}}(\lambda)\leq\max S_{1}\leq\min S_{2}\leq\mathbb{E}_{S_{2}}(\lambda)
for every
\lambda>0.

This implies that
\mathbb{E}_{S_{1}}(\lambda)\leq\mathbb{E}_{S}(\lambda)\leq\mathbb{E}_{S_{2}}(\lambda)
.

Proof.

The first inequality is trivial, as the expectation is between the minimum and maximum.
The second inequality is then a corollary of the first, since

\mathbb{E}_{S}(\lambda)=\frac{\lambda P^{\prime}_{S_{1}}(\lambda)+\lambda P^{\prime}_{S_{2}}(\lambda)}{P_{S_{1}}(\lambda)+P_{S_{2}}(\lambda)}
is a convex combination of
\mathbb{E}_{S_{1}}(\lambda)
and
\mathbb{E}_{S_{2}}(\lambda)
.
∎

Using this observation, we can provide a criterion that is sufficient to compare the expected value.

Proposition 2.3
.

Let
A
and
B
be the sets with multiplicity-tuples respectively
(a_{0},a_{1},\ldots,a_{k})
and
(b_{0},b_{1},\ldots,b_{k})
, whose elements are positive integers.
The condition
\frac{a_{i}}{a_{i-1}}\leq\frac{b_{i}}{b_{i-1}}
for every
1\leq i\leq k
ensures that

\mathbb{E}_{A}(\lambda)\leq\mathbb{E}_{B}(\lambda)
for every
\lambda\geq 0.

Proof.

Due to the given condition, we have that

(b_{0},b_{1},\ldots,b_{k})=c_{0}(a_{0},a_{1},\ldots,a_{k})+c_{1}(0,a_{1},a_{2},\ldots,a_{k})+\ldots+c_{k}(0,\ldots,0,a_{k}),

for some nonnegative reals
c_{i}.

We note that
\mathbb{E}_{B}(\lambda)
is a convex combination of
\mathbb{E}_{A}(\lambda)
and
\mathbb{E}_{A_{\geq i}}(\lambda)
for
1\leq i\leq k.
Here
A_{\geq i}=\{a\mid a\in A,a\geq i\}
is the subset of
A
containing all elements of
A
that are not smaller than
i.

By
2.2
,
\mathbb{E}_{A}(\lambda)\leq\mathbb{E}_{A_{\geq i}}(\lambda)
for every
i>0
and the conclusion follows.
∎

Theorem 3.1
.

There exists a cubic graph

7
for which
\alpha_{G}(\lambda)>\alpha_{H_{3,8}}(\lambda)
for every
\lambda>17.

Proof.

Let
G=G_{38}
be the graph in
https://houseofgraphs.org/graphs/49521

[
3
]
.
We can compute
\alpha_{G}(\lambda)
and
\alpha_{H_{3,8}}(\lambda)
explicitly from
\vec{i}(G)=(1,38,646,6498,43111,199120,658882,1583954,2777315

,3537622,3238356,2097330,947518,300924,72142,14802,2660,380,38,2)

This polynomial has only one change of sign, and by Descartes’ rule of signs, this implies that it has a single positive root.

For the study of the minimum occupancy fraction, we first prove the following proposition that compares graphs of the same order.

Proposition 4.1
.

Let
G
and
H
be two graphs of order
n
.
Suppose that
\alpha(G)\leq\alpha(H)
and

\frac{i_{k}(G)}{i_{k-1}(G)}\leq\frac{i_{k}(H)}{i_{k-1}(H)}

for every
1\leq k\leq\alpha(G).

Then
\alpha_{G}(\lambda)\leq\alpha_{H}(\lambda)
for every
\lambda\geq 0.

Proof.

If
\alpha(G)=\alpha(H),
this is immediate from
2.3
.
In the case that
\alpha(G)<\alpha(H)=\ell,
we note that
(i_{0}(H),i_{1}(H),\ldots,i_{\ell}(H))=(i_{0}(H),i_{1}(H),\ldots,i_{k}(H),0,\ldots,0)+(0,0,\ldots,0,i_{k+1}(H),\ldots,i_{\ell}(H)).

Let the corresponding sets with these three multiplicity-tuples be
S,S_{1},S_{2}.

Then
2.3
and
2.2
imply that
\alpha_{G}(\lambda)\leq\frac{1}{n}\mathbb{E}_{S_{1}}(\lambda)\leq\frac{1}{n}\mathbb{E}_{S}(\lambda)=\alpha_{H}(\lambda),
as desired.
∎

Conclusion

As such, the number of conjectures and questions that are likely to be true are narrowed down.

Appendix A
Details about computer search

We used a computer to determine the independence polynomial of a graph (and the occupancy fraction) with two independent algorithms. The first algorithm uses the built-in functions in Sage, whereas the second algorithm was implemented in C++. The latter is a simple, yet effective, backtracking algorithm that recursively enumerates all independent sets of a graph and derives the independence polynomial from this. The algorithm maintains an initially empty set and adds vertices recursively to this set by considering the vertices in an arbitrary order and branching into two possibilities: including the current vertex (if none of its neighbors are already in the set) or excluding the current vertex.
