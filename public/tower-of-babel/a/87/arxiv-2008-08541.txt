A characterization of always solvable trees in Lights Out game using the activation numbers of vertices
Ahmet Batal

Abstract
. Lights out is a game that can be played on any simple graph G G . A configuration assigns one of the two states on or off to each vertex. For a given configuration, the aim of the game is to turn all vertices off by applying a push pattern on vertices, where each push switches the state of the vertex and its neighbors. If every configuration of vertices is solvable, then we say that the graph is always solvable. We introduce a concept which we call the activation numbers of vertices and we prove several characterization results of graphs by using this concept. We show that for every always solvable graph there exists a chain of always solvable subgraphs where each subgraph differs from the preceding one by a vertex. We also characterize always solvable trees by showing that all always solvable trees can be constructed from always solvable subtrees by some special types of connections. We call the dimension of the space of null-patterns, which leave configurations unchanged, the nullity of the graph G G . We show that the nullity of a tree can be characterized by the cardinality of its minimal partition into always solvable subtrees.

Introduction

Lights out game on an undirected graph

or

(or simply a

is

which turns all lights

for a given initial configuration

is called

and

is called

(we may also say

If every configuration is solvable, then the graph

is called

(it is also called

by other authors

[

Let the order of

For a given graph, finding the pattern

The connection between the nullities of graphs related to each other by some type of graph operation such as edge/vertex join or removal was first considered by Amin et al.

We show that these classes can be realized from a different point of view in the case of classical lights out game where

Indeed, there is another way of categorizing vertices by checking in how many solving patterns of all-ones configuration a vertex is activated. Seeing this set of classes from the second point of view has important advantages. First, it makes it easier to see the existence of a vertex from a specific class in a graph or in a subgraph. Using this observation we prove our first main result Theorem

(2)

\tilde{\mathbf{c}}=N(G-e)\mathbf{p}=N(G)\mathbf{p}+J\mathbf{p}=\mathbf{c}+\mathbf{p}(w)\mathbf{c}_{u}+\mathbf{p}(u)\mathbf{c}_{w}.

Lemma 2.2
.

Let
u
be a vertex such that the configuration
\overline{\mathbf{c}_{u}}
is solvable. Then
u
is not activated in any solving pattern
\mathbf{p}
for
\overline{\mathbf{c}_{u}}
. In other words
\mathbf{p}(u)=0
for all
\mathbf{p}
satisfying
N\mathbf{p}=\overline{\mathbf{c}_{u}}
.

Proof.

We prove the lemma by applying induction on the size of the graph. Note that the lemma holds true for any graph without any edges. Assume that it holds true for any graph with size
n
. Let
G
be a graph with size
n+1
. Assume for a contradiction that there exists a pattern
\mathbf{p}
such that
\mathbf{p}(u)=1
and
N(G)\mathbf{p}=\overline{\mathbf{c}_{u}}
for some vertex

. Since
\overline{\mathbf{c}_{u}}(u)=0
and
\mathbf{p}(u)=1
, there must exist odd number of activated vertices adjacent to
u
. Let
w
be one of those adjacent vertices to
u
such that
\mathbf{p}(w)=1
. Let

. Then by (

) the pattern
\mathbf{p}
applied to the graph

solves the configuration
\overline{\mathbf{\mathbf{c}}_{u}}+\mathbf{c}_{u}+\mathbf{c}_{w}=\mathbf{1}+\mathbf{c}_{w}=\overline{\mathbf{\mathbf{c}}_{w}}

\mathbf{p}(w)=1

∎

Definition 2.3
.

We call a vertex

By [

Lemma 2.4

Let
\mathbf{c}
be a solvable configuration on a graph

for

Above lemma motivates us to make the following definition.

For a given solvable configuration

-always-activated or

-never-activated if

Proposition 2.6

A vertex

Let

On the other hand, by [

]

Proposition 2.7

A vertex

Lemma 2.8

Every always solvable graph has an always-activated vertex.

Proof.

Let

Lemma 4.1

Let

Proof.

By definition,

Definition 4.2

Let

Remark 4.3

Note that since

is always solvable, every graph

Theorem 4.4
.

For a nonempty tree

\pi(T)=\nu(T)+1
. In other words,

if and only if there exists a minimal PASS of

We first show

with
\nu(S)<n
. If

is a tree with

there exists an adjacent pair of half-activated vertices

From Table

must be a Type-
(1,1)
