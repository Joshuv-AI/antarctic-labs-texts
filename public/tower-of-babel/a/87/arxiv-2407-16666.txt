Abstract
. A Burling graph is an induced subgraph of some graph in Burling’s construction of triangle-free high-chromatic graphs. Equivalently, a Burling graph is a graph that admits a so-called strict frame representation. We provide a polynomial-time algorithm to decide whether a given graph is a Burling graph and if it is, to construct its strict frame representation. The representation then enables a polynomial-time algorithm for the maximum independent set problem in Burling graphs. As a consequence, we establish Burling graphs as the first known hereditary class of graphs that admits such an algorithm while not being χ \chi -bounded.

Introduction

A class of graphs is
\chi
-bounded
if the chromatic number of the graphs in the class is bounded by some function of the clique number.
In 1965, Burling
[
7

constructed an infinite sequence
B_{1},B_{2},\ldots
of triangle-free graphs with

that admit an intersection representation by axis-parallel boxes in

\chi

This answered a question by Asplund and Grünbaum
[
4

\mathbb{R}^{2}
is
\chi
-bounded.
The importance of Burling’s construction has been realized only in the last decade, since Pawlik et al.
[
33

34

devised its intersection representations by various geometric shapes in the plane, such as straight-line segments or axis-parallel rectangular frames.
Such representations imply that Burling’s construction excludes induced subdivisions of
1

As a consequence, they disprove a conjecture of Scott
[
40
]
that every class of graphs excluding induced subdivisions of a fixed graph is
\chi
-bounded.
This motivated further study of what graphs occur as induced subgraphs in Burling’s construction
[
9
,
13
,
36
,
37

Following Pournajafi and Trotignon
[
35
,
36

37
]

Burling graphs can be characterized in terms of so-called strict frame representations.
A

of a graph

assigns an axis-parallel rectangular frame to every vertex of

so that the edges of

Note that a frame is an empty rectangle (excluding the interior), so nested frames do not intersect.
A frame representation is

It follows from the construction in

Various aspects of graphs with frame representations (a.k.a. rectangle overlap graphs) were also studied in

The maximum independent set problem is to find, given an input graph
G
, an independent set in
G
of maximum size (or maximum weight, when the vertices of

Although the problem is

Indeed, we know many examples of graph classes in which the maximum independent set problem can be solved in polynomial time.
It turns out that these classes are also
\chi

A prominent example of a hereditary graph class with both discussed properties is the class of perfect graphs

Numerous other examples can be found among classes that are defined by geometric representations

Motivated by such examples, Thomassé, Trotignon, and Vušković
[

Being able to construct a strict frame representation, we can solve the maximum independent set problem (with weights) in Burling graphs in polynomial time via a known dynamic programming scheme due to Gavril
[

Therefore, since the class of Burling graphs is hereditary and not
\chi

[

There is a polynomial-time algorithm for the maximum independent set problem in Burling graphs with weights.

3.
Recognition

For this entire section, we fix a graph

for which we want to decide whether it is a Burling graph and if it is, to construct a Burling set
(V,\prec,\curvearrowright)
such that

.
All graph-theoretic terms will refer to the fixed graph

.
In particular, a

or an

will always mean a vertex or an edge of

.
We will be assuming that

is triangle-free, because a graph containing a triangle is never a Burling graph, and whether a graph contains a triangle can be decided trivially in polynomial time.

We will use the following notation and terminology.
Let

be the set of vertices (of

A set

A

A

For a vertex

A

For a set

A set

It is clear that every nested family has a nesting order.
The definition directly implies a polynomial-time algorithm to test whether a family

A

Maximum independent set

In this section, we present an algorithm for the maximum (weight) independent set problem in Burling graphs.
The core of the algorithm is a dynamic programming scheme developed by Gavril
[
18
,
19
]
(see also
[
8
]
) which reduces, for any class of families of geometric objects
\mathcal{F}
, the maximum (weight) independent set problem in the
overlap graphs
of families in
\mathcal{F}
to the maximum weight independent set problem in the
intersection graphs
of families in
\mathcal{F}
.
In our case,
\mathcal{F}
is the class of strict families of axis-parallel rectangles (defined just like strict families of frames except that rectangles include their interiors while frames do not).
Strict frame graphs are the overlap graphs of families in
\mathcal{F}
, while the intersection graphs of families in
\mathcal{F}
turn out to be chordal.

Say that a relation
\mathrel{R}
on a set
S
is
chordal
when it is acyclic and the following holds for all
x,y,z\in S
: if
x\mathrel{R}y
, and
x\mathrel{R}z
, and
y\neq z
, then
y\mathrel{R}z
or
z\mathrel{R}y
.
This term relates to well-known properties of chordal graphs.
In particular,
(S,E_{\smash{\mathrel{R}}})
is a chordal graph when
\mathrel{R}
is a chordal relation on
S
, and vice versa—for every chordal graph
G
, orienting every edge according to a so-called perfect elimination order gives rise to a chordal relation on the vertex set.
Apart from the next theorem, we will not use any particular properties of chordal graphs, so we omit further details.

Theorem 15

(Frank
[
17
]
)
.

There is a linear-time algorithm that, given a non-empty finite set
S
, a chordal relation
\mathrel{R}
on
S
, and a weight assignment
\mathsf{w}\colon S\to\mathbb{R}
, computes a maximum independent set in the graph
(S,E_{\smash{\mathrel{R}}})
with respect to the weight assignment
\mathsf{w}
.

Let
(V,\prec,\curvearrowright)
be a Burling set, and let
G=(V,E_{\smash{\curvearrowright}})
.
Let
\mathsf{w}\colon V\to\mathbb{R}
be a weight assignment according to which we want to compute a maximum independent set in
G
.
For a set
S\subseteq V
, let
\mathsf{w}(S)=\sum_{x\in S}\mathsf{w}(x)
.
Let
{\mathrel{R}}={\prec}\cup{\curvearrowright}
.

Lemma

4
and
axioms

(i)
–
(iii)
imply that the relation
\mathrel{R}
is chordal.
Let
V_{u}=\{x\in V\colon x\prec u\}
for all
u\in V
.
Note that if
x\in V_{u}
, then
V_{x}\subset V_{u}
.
The algorithm applies the dynamic programming technique on subproblems of the form
\mathfrak{I}(S)
defined for
S=V
and
S=V_{u}
for all

asks for a maximum independent set in the graph

.
The

.
A

Algorithm to solve

(
\mathfrak{I}(S)
)
.

1

If

2

For every

be a solution to the subproblem

Compute a maximum independent set

4

Report the set

as a solution to

.

Lemma 16

(cf.
[
19
, Lemma 2]
)
.

The algorithm to solve

is correct assuming that the smaller subproblems have been correctly solved.

Proof.

Let
I
be the set reported by the algorithm as a solution to
\mathfrak{I}(S)
.
Thus
I=\bigcup_{u\in I^{*}}(I_{u}\cup\{u\})
.
For every
u\in S
, since

and the set

is independent in

I_{u}\cup\{u\}
.
Suppose

for some distinct

.
Since
x\curvearrowright y
and

(iv)

.
Since
x=u
or
x\prec u
,
x\mathrel{R}v
, and

,

(i)
or
(iii)
entails

or

is independent in
(S,E_{\smash{{\mathrel{R}}|_{S}}})

This shows that

is an independent set in

.

Now, let

be an arbitrary independent set in
(S,E_{\smash{{\curvearrowright}|_{S}}})

It follows that
\mathsf{w}(J\cap V_{u})\leqslant\mathsf{w}(I_{u})

Concluding Remarks

Intersection graphs of axis-parallel rectangles in the plane are
NP
-hard to recognize
[
24
]
.
An easy adaptation of the proof in
[
24
]
shows that frame graphs, i.e., graphs admitting some (not necessarily strict) frame representation, are also
NP
-hard to recognize.
The maximum independent set problem is
NP
-hard for intersection graphs of axis-parallel unit squares
[
16
]
and for intersection graphs of horizontal and vertical segments
[
25
]
, either of which directly implies
NP
-hardness for frame graphs.
The situation is different for
directed frame graphs
, i.e., graphs with frame representations in which every intersecting pair of frames looks like in
Figure

1
(a) (which is the first condition from the definition of
strict
).
For directed frame graphs, the relation
\curvearrowright
defined as in
Figure

2
is chordal, and therefore the maximum independent set problem can be solved in polynomial time in the same way as described in
Section

5
provided that the corresponding relations
\prec
and
\curvearrowright
are given as part of the input.
This leaves the following question.

Problem 1
.

What is the complexity of recognizing directed frame graphs?

Burling graphs are induced subgraphs of Burling’s construction of triangle-free high-chromatic graphs.
What is the complexity of recognition and of computing a maximum independent set for other known constructions of triangle-free high-chromatic graphs?
This is not interesting for Mycielski’s construction
[
32
]
, which contains all triangle-free graphs as induced subgraphs
[
12
]
.
For induced subgraphs of Zykov’s construction
[
43
]
and Blanche Descartes’ construction
[
14
]
, both problems are
NP
-hard
[
30
]
.
For twin-cut graphs, i.e., induced subgraphs of the construction in
[
5
]
, recognition is in
P
while computing a maximum independent set is
NP
-hard
[
6
]
.

We will show in a follow-up work that, by contrast to the maximum independent set problem, the
k
-coloring problem remains
NP
-hard for Burling graphs for every
k\geqslant 3
, as it is for the other above-mentioned classes
[
6
,
30
]
.
This leads to the following analog of the Thomassé–Trotignon–Vušković question from
[
41
]
.

Problem 2
.

Is every hereditary class of graphs that admits a polynomial-time
3
-coloring algorithm
\chi
-bounded (assuming
\textup{\sf P}\neq\textup{\sf NP}
)?

As we have mentioned in the introduction, the recent flurry of research on Burling graphs has been mostly motivated by the conjecture of Scott
[
40
]
that the class
\mathcal{F}(H)
of graphs excluding induced subdivisions of
H
is
\chi
-bounded for every graph
H
.
Clearly, if no subdivision of
H
is a Burling graph, then Scott’s conjecture fails for
H
, because
\mathcal{F}(H)
contains all graphs
B_{1},B_{2},\ldots
from Burling’s construction.
Chudnovsky, Scott, and Seymour
[
10
]
conjectured that for every
H
, the chromatic number of graphs
G\in\mathcal{F}(H)
is bounded by a function of the clique number of
G
and the maximum
k
such that
G
contains an induced subgraph isomorphic to
B_{k}
.
This conjecture, if true, implies that if some subdivision of
H
is a Burling graph, then Scott’s conjecture holds for
H
.
Our recognition algorithm for Burling graphs can be adapted to a polynomial-time recognition algorithm of graphs
H
such that some subdivision of
H
is a Burling graph.
We omit the details, as this direction seems less compelling while the Chudnovsky–Scott–Seymour conjecture remains open.
However, very recently, the special case of the conjecture for graphs
G
that are string graphs has been proved
[
2
]
.
In particular, we now know that Burling graphs form a minimal hereditary class of graphs with unbounded chromatic number—the only known class of graphs with that property other than the (trivial) class of complete graphs.
