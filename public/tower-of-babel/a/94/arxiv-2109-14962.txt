Embedding in MDS codes and Latin cubes The study was carried out within the framework of the state contract of the Sobolev Institute of Mathematics (project no. 0314-2019-0017).
Vladimir N. Potapov

Abstract
An embedding of a code is a mapping that preserves distances between codewords. We prove that any code with code distance ρ \rho and length d d can be embedded into an MDS code with the same code distance and length but under a larger alphabet. As a corollary we obtain embeddings of systems of partial mutually orthogonal Latin cubes and n n -ary quasigroups. Keywords — Latin square, Latin cube, MOLS, MDS code, embedding
