Nielsen numbers of affine n n -valued maps on nilmanifolds
C. Deconinck, K. Dekimpe

Abstract
A nilmanifold is a quotient N ​ \ G \raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$} of a connected and simply connected nilpotent Lie group G G by a uniform lattice N N . In this paper we determine the Reidemeister and Nielsen number of affine n n -valued maps on such a nilmanifold. These are maps for which a given lifting to G G splits into n n affine maps of the Lie group G G . In order to obtain this result we also establish a way of computing the number of generalized twisted conjugacy classes on finitely generated torsion free nilpotent groups.



1
Introduction

Let
f:X\to X
be a continuous map on a reasonably nice topological space
X
(e.g.
X
is a finite polyhedron). Nielsen fixed point theory (see
[
12
]
,
[
13
]
,
[
14
]
and
[
15
]
) is a part of algebraic topology that provides a framework to determine the value of

\text{MF}(f)=\min\#\{{\rm Fix}(g)\mid g\simeq f\},

where
{\rm Fix}(g)=\{x\in X\mid g(x)=x\}
is the set of fixed points of
g
and
g\simeq f
denotes the fact that
g
is homotopic to
f
. This is done by attaching two numbers to the map
f
. First one divides the set
{\rm Fix}(f)
into so-called fixed point classes. This is done in such a way that for a map
g
homotopic to
f
, the fixed point classes of
g
are in one-to-one correspondence to those of
f
. In this way, the number of fixed point classes, called the Reidemeister number
R(f)
of
f
, is invariant under homotopy. Note that some of the fixed point classes of
f
(or of
g
) might be empty. In a second step, one attaches an integer to each fixed point class. This integer is the index of the fixed point class and a fixed point class is called essential if its index is non-zero. The idea is that an essential fixed point class can never become empty when considering homotopies, while a non-essential one can. The Nielsen number
N(f)
of the map
f
is then the number of essential fixed point classes of
f
. Also
N(f)
is homotopy invariant. This Nielsen number is a very good estimate for
{\rm MF}(f)
, indeed, by a result of F. Wecken we have that when
X
is a compact manifold of dimension different from two that
N(f)={\rm MF}(f)
for all self-maps of
X
(see
[
24
]
).

In general
R(f)
is fairly easy to compute using algebraic tools (
R(f)
equals the number of twisted conjugacy classes of the induced endomorphism on the fundamental group
\pi(X)
of
X
, see also Section
4
), while unfortunately
N(f)
is very often hard to compute. However, for some classes of manifolds one has been able to develop easy formulas to compute this Nielsen number. This is for instance the case for nilmanifolds. We will give more details on this class of manifolds in Section
3
, but for now it suffices to say that they are of the form
\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}
where
N
is a uniform lattice of a connected and simply connected nilpotent Lie group
G
. It is known that any map
f
on such a nilmanifold is homotopic to a map induced by an endomorphism
\varphi:G\to G,
and D. Anosov (
[
1
]
, see also
[
9
]
) showed that
N(f)=|\det(I-\varphi_{\ast})|
. Here
\varphi_{\ast}:\mathfrak{g}\to\mathfrak{g}
is the differential of
\varphi
at the identity element of
G
(so the induced endomorphism on the Lie algebra
\mathfrak{g}
of
G
).

In the eighties, H. Schirmer extended Nielsen theory, including Wecken’s result, to the setting of
n
-valued maps
f:X\multimap X
(
[
19
]
,
[
20
]
). These are maps that attach to each
x\in X
a subset
\{x_{1},x_{2},\ldots,x_{n}\}
of
X
with exactly
n
elements. Also here we require some kind of continuity (see Section
2
). In
[
2
]
, R.F. Brown showed that any
n
-valued map on a circle is homotopic to an affine
n
-valued map (which is the natural analogue of the single-valued linear maps on nilmanifolds) and he was also able to compute the Nielsen number in this case.

In this paper we will show how to compute the Nielsen number of any affine
n
-valued map on any nilmanifold. In fact the main result of this paper is Theorem
6.13
which nicely generalizes the formula of Anosov for the single-valued case. We do remark that in contrast to the single-valued case, it is no longer true that any
n
-valued map is homotopic to an affine
n
-valued map, but the class of affine
n
-valued maps is still very large and interesting.

This paper is organized as follows. In Section
2
we describe the approach to fixed point classes of
n
-valued maps as developed in
[
3
]
. In the next section we recall the basic facts about nilpotent Lie groups and nilmanifolds. Section
4
is purely group theoretical in nature as we construct a way to count the number of generalized twisted conjugacy classes in the case of finitely generated torsion free nilpotent groups. This is in fact an algebraic way of counting fixed point classes (so for computing
R(f)
) for
n
-valued maps. In Section
5
we introduce the class of affine
n
-valued maps and then apply the results from the previous section to find an easy formula for computing the Reidemeister number of such an affine
n
-valued map. In the last section finally, we compute the indices of all possible fixed point classes and this leads to the main result of this paper, namely a formula to compute the Nielsen number
N(f)
of an affine
n
-valued map.

2
Fixed point classes of
n
-valued maps

Further on, we will make use of the theory developed in
[
3
]
.
In this section, we recall some results from that paper.

Let the space
X
be a connected finite polyhedron.
The configuration space of
n
ordered points on
X
is

F_{n}(X)=\{(x_{1},x_{2},\dots,x_{n})\in X^{n}\;|\;x_{i}\neq x_{j}\text{ if }i\neq j\}

and is topologized as a subspace of the product space
X^{n}.

The configuration space of
n
unordered points on
X
is

D_{n}(X)=\{\{x_{1},x_{2},\dots,x_{n}\}\subseteq X\;|\;x_{i}\neq x_{j}\text{ if }i\neq j\}

and can be seen as the orbit space of
F_{n}(X)
under the free action of the symmetric group
\Sigma_{n}.

The quotient map
q:F_{n}(X)\to D_{n}(X)
induces the quotient topology on
D_{n}(X).

For a natural number
n>0,
an
n
-valued map
f:X\multimap X
is a set-valued function which is continuous, that is, both lower and upper semi-continuous, and such that
f(x)
contains exactly
n
elements for each
x.

We do not distinguish between the
n-
valued map
f:X\multimap X
and the corresponding single-valued function
f:X\to D_{n}(X),
which is continuous (as proved in
[
4
]
).
A fixed point of
f
is an element
x
such that
x\in f(x).

The set of all fixed points of
f
is denoted by
\Fix(f).

Let
p:\tilde{X}\to X
be the universal cover of
X
with covering group
\pi.
The orbit configuration space is defined as

\displaystyle F_{n}(\tilde{X},\pi)

\displaystyle=\{(\tilde{x}_{1},\tilde{x}_{2},\ldots,\tilde{x}_{n})\in\tilde{X}^{n}\;|\;p(\tilde{x}_{i})\neq p(\tilde{x}_{j})\mbox{ if }i\neq j\}

\displaystyle=\{(\tilde{x}_{1},\tilde{x}_{2},\ldots,\tilde{x}_{n})\in\tilde{X}^{n}\;|\;\pi\cdot\tilde{x}_{i}\neq\pi\cdot\tilde{x}_{j}\mbox{ if }i\neq j\}.

Xicoténcatl proved
[
25
]
that

p^{n}:F_{n}(\tilde{X},\pi)\to D_{n}(X):(\tilde{x}_{1},\tilde{x}_{2},\ldots,\tilde{x}_{n})\mapsto\{p(\tilde{x}_{1}),p(\tilde{x}_{2}),\ldots,p(\tilde{x}_{n})\}

is a covering map with covering group
\pi^{n}\rtimes\Sigma_{n}
and where the product in this group is given by

(\alpha_{1},\alpha_{2},\ldots,\alpha_{n};\sigma)(\beta_{1},\beta_{2},\ldots,\beta_{n};\rho)=(\alpha_{1}\beta_{\sigma^{-1}(1)},\alpha_{2}\beta_{\sigma^{-1}(2)},\ldots,\alpha_{n}\beta_{\sigma^{-1}(n)};\sigma\circ\rho).

Now we can lift any
n
-valued map
f:X\to D_{n}(X)
to a map

\bar{f}:\tilde{X}\to F_{n}(\tilde{X},\pi).

Since
F_{n}(\tilde{X},\pi)\subset\tilde{X}^{n},
the lifting
\bar{f}
splits in
n
single-valued maps:
\bar{f}=(\bar{f}_{1},\bar{f}_{2},\ldots,\bar{f}_{n}).

The maps
\bar{f}_{i}:\tilde{X}\to\tilde{X}
are called lift-factors.

\scriptstyle{p}
\scriptstyle{\bar{f}=(\bar{f}_{1},\bar{f}_{2},\ldots,\bar{f}_{n})}
\textstyle{F_{n}(\tilde{X},\pi)\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{p^{n}}
\textstyle{X\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{f}

Analogously to the single-valued case, where there is an equivalence relation on the set of all liftings,
we define an equivalence relation on the set of all lift-factors of the
n
-valued map
f:

\bar{f}_{i}\sim_{lf}\bar{f}_{j}^{\prime}\Leftrightarrow\exists\gamma\in\pi:\bar{f}_{i}=\gamma\bar{f}_{j}^{\prime}\gamma^{-1}.

The equivalence classes are called lift-factor classes, and the Reidemeister number
R(f)
of
f
is defined as the number of lift-factor classes.
If
n
-valued maps are homotopic, then they have the same Reidemeister number.

Analogously to the single-valued case, where we have a similar property with liftings instead of lift-factors,
the following holds in the
n
-valued case:

Theorem 2.1
.

Let
f\colon X\to D_{n}(X)
be an
n
-valued map
and
\bar{f}_{i},\bar{f}^{\prime}_{j}

two lift-factors of
f.

1.

If
\bar{f}_{i}\sim_{lf}\bar{f}^{\prime}_{j},

then
p\Fix(\bar{f}_{i})=p\Fix(\bar{f}^{\prime}_{j})
.

2.

If

p\Fix(\bar{f}_{i})\cap p\Fix(\bar{f}^{\prime}_{j})\neq\emptyset
then
\bar{f}_{i}\sim_{lf}\bar{f}^{\prime}_{j}.

Hence, we can write the fixed point set

\Fix(f)=\bigcup_{\bar{f}_{i}}p\Fix(\bar{f}_{i})
as the disjoint union

\Fix(f)=\bigcup_{[\bar{f}_{i}]}p\Fix(\bar{f}_{i}),

where the union is taken over all lift-factor classes.
The sets
p\Fix(\bar{f}_{i})
are called fixed point classes of
f.
It follows that the Reidemeister number, which is defined as the number of lift-factor classes, also equals the number of fixed point classes. Fixed point classes of
n
-valued maps were already defined by Schirmer in
1984, without the use of covering spaces (
[
19
]
).
The preceding definition of fixed point classes agrees with the one from Schirmer in the case we are considering non empty fixed point classes.
Also the notions of index and Nielsen number were generalized by Schirmer to the
n-
valued setting. The Nielsen number
N(f)
of
f
is defined as the number of fixed point classes of non-zero index, so
N(f)\leq R(f).

We fix a lifting
\bar{f}^{*}=(\bar{f}^{*}_{1},\bar{f}^{*}_{2},\ldots,\bar{f}^{*}_{n}):\tilde{X}\to F_{n}(\tilde{X},\pi)
of
f,
which we call the basic lifting. It holds that every lift-factor of
f
can be written as
\alpha\bar{f}^{*}_{i}
for an
\alpha\in\pi
and
i\in\{1,2,\dots,n\}.

The basic lifting of
f
defines a function

\psi_{f}:\pi\to\pi^{n}\rtimes\Sigma_{n}

by the requirement that

\forall\gamma\in\pi:\;\bar{f}^{\ast}\circ\gamma=\psi_{f}(\gamma)\circ\bar{f}^{\ast}.

We denote
\psi_{f}(\gamma)=(\phi_{1}(\gamma),\phi_{2}(\gamma),\ldots,\phi_{n}(\gamma);\sigma_{\gamma})
and it turns out that
\psi_{f}
is a homomorphism.
The map
\sigma:\pi\to\Sigma_{n}:\gamma\mapsto\sigma_{\gamma}
is also a homomorphism, but the maps
\phi_{i}:\pi\to\pi
are not homomorphisms in general. Using the product structure of
\pi^{n}\rtimes\Sigma_{n}
, one finds that the maps
\phi_{i}
satisfy the relation

\bar{f}_{i}^{\ast}\circ\gamma=\phi_{i}(\gamma)\circ\bar{f}_{\sigma_{\gamma}^{-1}(i)}^{\ast}.

(1)

We can translate
the equivalence relation
\sim_{lf}
on the set of lift-factors to an equivalence relation on
\pi\times\{1,2,\ldots,n\}:

\displaystyle\alpha\bar{f}^{*}_{i}\sim\beta\bar{f}^{*}_{j}

\displaystyle\iff\exists\gamma\in\pi:\left\{\begin{array}[]{ll}\sigma_{\gamma}(j)=i\\
\alpha=\gamma\beta\phi_{j}(\gamma^{-1}).\end{array}\right.

Because the map
\sigma:\pi\to\Sigma_{n}:\gamma\mapsto\sigma_{\gamma}
is a homomorphism, the relation

i\sim j\iff\exists\gamma\in\pi:\sigma_{\gamma}(j)=i

on
\{1,2,\dots,n\}
is an equivalence relation. It divides the lift-factors of the basic lifting into equivalence classes, where
\bar{f}^{*}_{i}
and
\bar{f}^{*}_{j}
are in the same class if
i\sim j.
Those classes are called the
\sigma-
classes of the basic lifting.
Let

\bar{f}^{*}_{i_{1}},\bar{f}^{*}_{i_{2}},\dots,\bar{f}^{*}_{i_{r}}

be representatives for the
\sigma-
classes.
It holds that

R(f)=R_{i_{1}}(f)+R_{i_{2}}(f)+\cdots+R_{i_{r}}(f)

(2)

where
R_{i_{k}}(f)
is the number of equivalence classes of the equivalence relation on
\pi
given by

\alpha\sim_{i_{k}}\beta\Leftrightarrow\exists\gamma\in S_{i_{k}}:\alpha=\gamma\beta\phi_{i_{k}}(\gamma^{-1}),

with

S_{i_{k}}=\{\gamma\in\pi\;|\;\sigma_{\gamma}(i_{k})=i_{k}\}.

Even though the map
\phi_{i_{k}}:\pi\to\pi

is not a homomorphism in general,
it is a homomorphism if we restrict the domain to
S_{i_{k}}
(which is a finite index subgroup of
\pi
).
Denoting the equivalence class of
\gamma\in\pi
by the relation
\sim_{i_{k}}
with
[\gamma]_{i_{k}},
we have

\Fix(f)=\bigcup_{k=1}^{r}\bigcup_{[\gamma]_{i_{k}}}p\Fix(\gamma\bar{f}^{*}_{i_{k}}),

where the last union is taken over all classes
[\gamma]_{i_{k}}
with
\gamma\in\pi.

The union is a disjoint union and some sets may be empty.

Nilpotent groups, Malcev completions and nilmanifolds

In this section we will recall some basic facts about finitely generated torsion free nilpotent groups and their Malcev completions.
For more details we refer the reader to
[
5
]
,
[
6
]
,
[
17
]
and
[
21
]
.

For a group
N
, we will use
\gamma_{i}(N)
(
i=1,2,\ldots
) to denote the terms of the lower central series of
N
. These terms are defined recursively via
\gamma_{1}(N)=N
and
\gamma_{i+1}(N)=[N,\gamma_{i}(N)]
. Recall that a group is said to be nilpotent if there is a positive integer
c
such that
\gamma_{c+1}(N)=1
. The smallest possible
c
for which
\gamma_{c+1}(N)=1
is called the nilpotency class of
N.

In this paper, we will be working with finitely generated torsion free nilpotent groups. Given such a group
N
, there exists a unique connected and simply connected nilpotent Lie group
G
containing
N
as a uniform lattice (i.e. as a discrete and cocompact subgroup). This Lie group
G
is called the Malcev completion of
N
. Conversely, if
N
is a uniform lattice of a connected and simply connected nilpotent Lie group
G
, then
N
is finitely generated and torsion free. The spaces we are considering in this paper are the nilmanifolds. These are exactly the quotient spaces

\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}
where
N
is a uniform lattice of a connected and simply connected nilpotent Lie group
G
. Hence there is a one-to-one correspondence between nilmanifolds and finitely generated torsion free nilpotent groups.

Now, let
N_{1}
and
N_{2}
be two such finitely generated torsion free nilpotent groups with Malcev completions
G_{1}
and
G_{2}
respectively. Then any morphism
\varphi:N_{1}\to N_{2}
extends uniquely to a Lie group morphism

\tilde{\varphi}:G_{1}\to G_{2}
. Moreover, when
\varphi
is an isomorphism (or injective or surjective), then so is
\tilde{\varphi}
.

Let
{\mathfrak{g}}
denote the Lie algebra of a connected and simply connected nilpotent Lie group
G
. It is well known that the exponential map
\exp:{\mathfrak{g}}\to G
is bijective in this case and we will denote the inverse by
\log:G\to{\mathfrak{g}}
.
When
\varphi:G\to G
is an endomorphism of the nilpotent Lie group
G
, we will use
\varphi_{\ast}:{\mathfrak{g}}\to{\mathfrak{g}}

to denote the differential of
\varphi
and we have a commutative diagram:

\scriptstyle{\varphi}
\scriptstyle{\log}

\scriptstyle{\log}
\textstyle{{\mathfrak{g}}\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces}

In this paper we will need a more concrete description of the Malcev completion associated to a given finitely generated nilpotent group
N
. For our purposes it turns out that it is useful to work with the isolators of the terms of the lower central series of
N
.

Definition
.

Let
H
be a subgroup of a group
K
. By the isolator of
H
in
K
, we will mean the following subset of
K
:

\sqrt[K]{H}=\{x\in K\mid\exists m>0:\;x^{k}\in H\}.

When
N
is a finitely generated torsion free nilpotent group of class
c
, we will use
N_{i}=\sqrt[N]{\gamma_{i}(N)}
to denote the isolator of the
i
-th term of the lower central series of
N
. The
N_{i}
are fully characteristic subgroups of
N
and they form a central series

1=N_{c+1}\leq N_{c}\leq N_{c-1}\leq\cdots\leq N_{2}\leq N_{1}=N

in which each quotient
N_{i}/N_{i+1}
is torsion free, in fact free abelian of finite rank, say
k_{i}
.
Note that
N_{i}
is the smallest subgroup of
N
, containing
\gamma_{i}(N)
and such that
N/N_{i}
is torsion free.
In fact
N_{i}
is the inverse image of the torsion group of
N/\gamma_{i}(N)
under the natural projection
N\to N/\gamma_{i}(N)
. So
[N_{i}:\gamma_{i}(N)]<\infty
. When
G
is the Malcev completion of
N
, then
N_{i}=\gamma_{i}(G)\cap N

(because of Lemma 1.2.6 in
[
7
]
).

Now, choose elements
a_{i,j}\in N_{i}
(
1\leq i\leq c,1\leq j\leq k_{i}
) in such a way that the

\overline{a}_{i,1}=a_{i,1}N_{i+1},\overline{a}_{i,2}=a_{i,2}N_{i+1},\dots,\overline{a}_{i,k_{i}}=a_{i,k_{i}}N_{i+1}

form a free generating set of the free abelian group
N_{i}/N_{i+1}\cong\mathbb{Z}^{k_{i}}.

The elements
a_{1,1},a_{1,2},\dots,a_{c,k_{c}}
form a so called Malcev basis of
N
and we will say that this Malcev basis is compatible with the isolators of the lower central series. Any element

can now be written uniquely in the form

\displaystyle x=a_{1,1}^{z_{1,1}}a_{1,2}^{z_{1,2}}\cdots a_{1,k_{1}}^{z_{1,k_{1}}}a_{2,1}^{z_{2,1}}\cdots a_{c,k_{c}}^{z_{c,k_{c}}}

(3)

for some integers

To shorten notation we will be using tuples

{z}_{1}=(z_{1,1},z_{1,2},\dots,z_{1,k_{1}}),{z}_{2}=(z_{2,1},z_{2,2},\dots,z_{2,k_{2}}),\dots,{z}_{c}=(z_{c,1},z_{c,2},\dots,z_{c,k_{c}})

and write

\displaystyle x={a}_{1}^{{z}_{1}}{a}_{2}^{{z}_{2}}\cdots{a}_{c}^{{z}_{c}}

(4)

instead of (

The following properties are well known.

.

Let

be a finitely generated torsion free nilpotent group and let

\forall{z}_{2}\in\mathbb{Z}^{k_{2}},

\forall{z}_{c}\in\mathbb{Z}^{k_{c}},

\displaystyle({a}_{1}^{{z}_{1}}{a}_{2}^{{z}_{2}}\cdots{a}_{c}^{{z}_{c}})^{m}={a}_{1}^{m{z}_{1}}{a}_{2}^{m{z}_{2}+q_{2}(m,{z}_{1})}\cdots{a}_{c}^{m{z}_{c}+q_{c}(m,{z}_{1},\dots,{z}_{c-1})}.

Using the polynomials

we can define a group structure on
\mathbb{R}^{k_{1}+k_{2}+\cdots+k_{c}}
by defining the product as

\displaystyle({x}_{1},{x}_{2},\dots,{x}_{c})({y}_{1},{y}_{2},\dots,{y}_{c})

\displaystyle=

\displaystyle\big({x}_{1}+{y}_{1},{x}_{2}+{y}_{2}+p_{2}({x}_{1},{y}_{1}),\dots,{x}_{c}+{y}_{c}+p_{c}({x}_{1},\dots,{x}_{c-1},{y}_{1},\dots,{y}_{c-1})\big).

In this way we obtain a Lie group
G
which is connected and simply connected and nilpotent.
The group
N
is a uniform lattice of the group
G
by identifying

{a}_{1}^{{z}_{1}}{a}_{2}^{{z}_{2}}\cdots{a}_{c}^{{z}_{c}}\in N
with
({z}_{1},{z}_{2},\dots,{z}_{c})\in G.

So
G
is the Malcev completion of
N.
By abuse of notation we will use
{a}_{1}^{{x}_{1}}{a}_{2}^{{x}_{2}}\cdots{a}_{c}^{{x}_{c}}
to denote the element
({x}_{1},{x}_{2},\dots,{x}_{c})
of
G
.

Let
\mathfrak{g}
be the Lie algebra of
G.
If we let
A_{i,j}=\log(a_{i,j})
(
1\leq i\leq c,1\leq j\leq k_{i}
) then the set
A_{1,1},A_{1,2},\dots,A_{1,k_{1}},A_{2,1},\dots,A_{c,k_{c}}
is a basis of
\mathfrak{g}
(as a vector space). Analogously as above, we will use
{x}_{i}{A}_{i}
as a shorthand for

x_{i,1}A_{i,1}+x_{i,2}A_{i,2}+\cdots+x_{i,k_{i}}A_{i,k_{i}}
.

The lower central series of
\mathfrak{g}
is defined analogously as for groups, i.e.
\gamma_{1}(\mathfrak{g})=\mathfrak{g}
and
\gamma_{i+1}(\mathfrak{g})=[\mathfrak{g},\gamma_{i}(\mathfrak{g})].
It holds that
\exp(\gamma_{i}(\mathfrak{g}))=\gamma_{i}(G).

A morphism
\varphi:G\to G
induces a morphism on

4
Generalized twisted conjugacy for nilpotent groups

For single-valued self-maps
f
, the Reidemeister number
R(f)
can be computed in an algebraic way by counting the number of twisted conjugacy classes, denoted by
R(f_{\ast})
, for the morphism
f_{\ast}
induced on the fundamental group of the space. In the setting of
n
-valued maps, we need a generalization of this concept.

Let
N
be a group (which in our case will always be a finitely generated, torsion free nilpotent group).
Suppose that
H\leq_{f}N
is a finite index subgroup of
N
and that we have a morphism
\phi:H\to N
. Then
\phi
determines an equivalence relation
\sim_{\phi}
on
N
by setting

\forall\alpha,\beta\in N:\;\alpha\sim_{\phi}\beta\iff\exists\gamma\in H:\alpha=\gamma\beta\phi(\gamma^{-1}).

Note that when
H=G
, this is the usual twisted conjugacy relation (see e.g.
[
8
]
,
[
10
]
,
[
11
]
,
[
18
]
and
[
22
]
), so we will refer to this relation as a generalized twisted conjugacy relation.

We will use
R(\phi)
to denote the number of equivalence classes of the generalized twisted conjugacy relation
\sim_{\phi}
and refer to this number as the Reidemeister number of
\phi
, just like for the ordinary twisted conjugacy relation. This Reidemeister number
R(\phi)
is either a positive integer or
\infty
.

Note that we already encountered this concept in Section
2
where we saw that

R(f_{i_{k}})
was equal to the number of generalized twisted conjugacy classes of the morphism

\phi_{i_{k}}:S_{i_{k}}\to\pi
. So we can rewrite formula (
2
) as

R(f)=R_{i_{1}}(f)+R_{i_{2}}(f)+\cdots+R_{i_{r}}(f)=R(\phi_{i_{1}})+R(\phi_{i_{2}})+\cdots+R(\phi_{i_{r}}).

As we will need to compute the number of fixed point classes of an
n-
valued map on a nilmanifold, it will be crucial for us to understand how to compute the number of generalized twisted conjugacy classes in case
N
is a finitely generated torsion free nilpotent group. This section is a rather technical section of which the main result in Theorem
4.14
is a formula to compute this number. But before we start developing this formula, let us first of all present a small example to illustrate this concept.

Example 4.1
.

Let
N=\mathbb{Z}
, the additive group of integers and let
H=n\mathbb{Z}
where
n=dm
and
d
and
m
are positive integers. Take
\phi:H\to N:z\mapsto\displaystyle\frac{z}{m}
.
Then we have that

\displaystyle\forall z_{1},z_{2}\in N=\mathbb{Z}:\;z_{1}\sim_{\phi}z_{2}

\displaystyle\iff

\displaystyle\exists nz\in H=n\mathbb{Z}:\;z_{1}=nz+z_{2}-\frac{nz}{m}

\displaystyle\iff

\displaystyle\exists z\in\mathbb{Z}:\;z_{1}-z_{2}=\left(n-\frac{n}{m}\right)z=(n-d)z.

In case
m\neq 1
(so
d\neq n
), we see that
z_{1}\sim_{\phi}z_{2}\iff z_{1}\equiv z_{2}\bmod n-d
and so
R(\phi)=n-d
.

On the other hand, when
m=1
(so
d=n
) we get that
z_{1}\sim_{\phi}z_{2}\iff z_{1}=z_{2}
and so
R(\phi)=\infty
.

As indicated above, the aim of this section is to develop a formula for computing
R(\phi)
for a morphism
\phi:H\to N
, where
H
is a finite index subgroup of a torsion free finitely generated
c
-step nilpotent group
N.
We again use the notation
N_{i}=\sqrt[N]{\gamma_{i}(N)}
for the isolators of the terms of the lower central series of
N
and analogously, we let
H_{i}=\sqrt[H]{\gamma_{i}(H)}
. It should be no surprise that the groups
H_{i}
are in fact closely related to the
N_{i}
as we show in the following lemma. We will use
G
to denote the Malcev completion of
N.

Lemma 4.2
.

With the notations introduced above, we have that
H_{i}=H\cap N_{i}
.

It follows that
H_{i}\leq_{f}N_{i}
and that there is a natural isomorphism

\frac{H_{i}}{H_{i+1}}\cong\frac{H_{i}N_{i+1}}{N_{i+1}}\cdot

Proof.

Note that
G
is also the Malcev completion of
H
(since
H
is of finite index in
N
), and so we have that
H_{i}=H\cap\gamma_{i}(G)=H\cap N\cap\gamma_{i}(G)=H\cap N_{i}
.
The fact that
H\leq_{f}N
, implies that
H\cap N_{i}\leq_{f}N_{i}
, hence
H_{i}\leq_{f}N_{i}
. We have the following equalities and the natural isomorphism from the second isomorphism theorem for groups:

\displaystyle\frac{H_{i}}{H_{i+1}}=\frac{H_{i}}{H\cap N_{i+1}}=\frac{H_{i}}{H_{i}\cap N_{i+1}}\cong\frac{H_{i}N_{i+1}}{N_{i+1}}\cdot

∎

Using the natural isomorphism
\frac{H_{i}}{H_{i+1}}\cong\frac{H_{i}N_{i+1}}{N_{i+1}}
from the lemma above, we may identify
\frac{H_{i}}{H_{i+1}}
with a finite index subgroup
of
\frac{N_{i}}{N_{i+1}}
(because
H_{i}
, and so also
H_{i}N_{i+1}
, is a finite index subgroup of
N_{i}
). Recall that in the previous section we already had chosen a fixed isomorphism

\frac{N_{i}}{N_{i+1}}\cong\mathbb{Z}^{k_{i}}
. Via this isomorphism the subgroup
\frac{H_{i}N_{i+1}}{N_{i+1}}
(and so also
\frac{H_{i}}{H_{i+1}}
) corresponds to a subgroup of finite index in
\mathbb{Z}^{k_{i}}
which can be written as
B_{i}\mathbb{Z}^{k_{i}}
for some matrix
B_{i}\in\mathbb{Z}^{k_{i}\times k_{i}}
. It holds that the index

\left[\frac{N_{i}}{N_{i+1}}:\frac{H_{i}N_{i+1}}{N_{i+1}}\right]=[\mathbb{Z}^{k_{i}}:B_{i}\mathbb{Z}^{k_{i}}]=|\det(B_{i})|.

Lemma 4.3
.

The morphism
\phi
induces for each
i\in\{1,2,\dots,c\}
a morphism

\phi_{i}:\frac{H_{i}N_{i+1}}{N_{i+1}}\to\frac{N_{i}}{N_{i+1}}:hN_{i+1}\mapsto\phi(h)N_{i+1}.

Proof.

The morphism
\phi:H\to N
has a unique extension (see Section
3
) to a morphism
\tilde{\phi}:G\to G
. As
\tilde{\phi}(\gamma_{i}(G))\subseteq\gamma_{i}(G)
we have that

\phi(H_{i})=\tilde{\phi}(H\cap\gamma_{i}(G))\subseteq\tilde{\phi}(H)\cap\gamma_{i}(G)\subseteq N\cap\gamma_{i}(G)=N_{i}
and
hence
\phi(h)\in N_{i}
for all
h\in H_{i}
. Moreover, if
hN_{i+1}=h^{\prime}N_{i+1}
, then
h^{-1}h^{\prime}\in N_{i+1}
and

\phi(h^{-1}h^{\prime})\in\tilde{\phi}(N_{i+1})\subseteq N_{i+1}
showing that
\phi(h)N_{i+1}=\phi(h^{\prime})N_{i+1}
and hence
\phi_{i}
is a well defined map, which is now easily seen to be a morphism.
∎

Recall that we had identified
N_{i}/N_{i+1}
with
\mathbb{Z}^{k_{i}}
and
H_{i}N_{i+1}/N_{i+1}
with the subgroup
B_{i}\mathbb{Z}^{k_{i}}
of
N_{i}/N_{i+1}=\mathbb{Z}^{k_{i}}
. Hence we will view

\phi_{i}
as a morphism
\phi_{i}:B_{i}\mathbb{Z}^{k_{i}}\to\mathbb{Z}^{k_{i}}
.

We will prove in this section that the product formula
R(\phi)=R(\phi_{1})R(\phi_{2})\cdots R(\phi_{c})
holds and therefore we first focus on the computation of
R(\psi)
in case

\psi
is a morphism
\psi:B\mathbb{Z}^{k}\to\mathbb{Z}^{k}
for some matrix
B\in\mathbb{Z}^{k\times k}
, with
\det B\neq 0
(meaning that
[\mathbb{Z}^{k}:B\mathbb{Z}^{k}]=|\det(B)|
). Note that in this situation, there exists a matrix
M\in\mathbb{Q}^{k\times k}
such that
\psi:B\mathbb{Z}^{k}\to\mathbb{Z}^{k}:\vec{z}\mapsto M\vec{z}
. The following proposition shows how to express
R(\psi)
in terms of
M
.
We will use
I_{k}
to denote the
k\times k
identity matrix and we also introduce the following notation:

Definition
.

Let
a\in\mathbb{R}
, then we define
|a|_{\infty}
as follows:

|a|_{\infty}=\left\{\begin{array}[]{cl}|a|&\mbox{when }a\neq 0\\
\infty&\mbox{when }a=0.\end{array}\right.

Proposition 4.4
.

Let
k
be a positive integer and
B\in\mathbb{Z}^{k\times k}
a matrix with
\det(B)\neq 0
. Let
\psi:B\mathbb{Z}^{k}\to\mathbb{Z}^{k}:\vec{z}\mapsto M\vec{z}
be a morphism which is determined by a
matrix
M\in\mathbb{Q}^{k\times k}
. Then

R(\psi)=[\mathbb{Z}^{k}:B\mathbb{Z}^{k}]|\det(I_{k}-M)|_{\infty}.

Remark 4.5
.

•

Although the matrix
M\in\mathbb{Q}^{k\times k}
, we must have that
MB
is a matrix with integral entries because the image of
\psi
is
MB\mathbb{Z}^{k}\subseteq\mathbb{Z}^{k}
.

•

Example
4.1
fits into the context of the above proposition, where
k=1
,
\psi=\phi
,
B
is a
1\times 1
matrix with entry
n
and

M
is a
1\times 1
matrix with entry
\displaystyle\frac{1}{m}
. The proposition predicts that

R(\psi)=[\mathbb{Z}:n\mathbb{Z}]|\det(1-\displaystyle\frac{1}{m})|=n(1-\displaystyle\frac{1}{m})=n-d
when
\det(1-\displaystyle\frac{1}{m})\neq 0
(
\iff m\neq 1
) and

R(\psi)=\infty
otherwise. This agrees with what we obtained by explicit calculation.

Proof of Proposition
4.4
.

We have that for
\vec{z}_{1},\vec{z}_{2}\in\mathbb{Z}^{k}
:

\displaystyle\vec{z}_{1}\sim_{\psi}\vec{z}_{2}

\displaystyle\iff

\displaystyle\exists\vec{z}\in B\mathbb{Z}^{k}:\;\vec{z}_{1}=\vec{z}+\vec{z}_{2}-\psi(\vec{z})

\displaystyle\iff

\displaystyle\exists\vec{z}\in B\mathbb{Z}^{k}:\;\vec{z}_{1}-\vec{z}_{2}=(I_{k}-M)\vec{z}.

So, we see that
R(\psi)
is the number of cosets of the subgroup
(I_{k}-M)B\mathbb{Z}^{k}
of
\mathbb{Z}^{k}
and hence we are looking for the index
[\mathbb{Z}^{k}:(I_{k}-M)B\mathbb{Z}^{k}]
. It is well known that for an integral
k\times k
matrix
A
it holds that
[\mathbb{Z}^{k}:A\mathbb{Z}^{k}]=|\det(A)|_{\infty}
. As
(I_{k}-M)B=B-MB
is an integral matrix and
\det(B)\neq 0
, we get that

R(\psi)=|\det((I_{k}-M)B)|_{\infty}=|\det(B)||\det(I_{k}-M)|_{\infty}=[\mathbb{Z}^{k}:B\mathbb{Z}^{k}]|\det(I_{k}-M)|_{\infty}.

∎

Remark 4.6
.

For each
i\in\{1,2,\dots,c\}
we view

\phi_{i}
as a morphism
B_{i}\mathbb{Z}^{k_{i}}\to\mathbb{Z}^{k_{i}}.

We introduce the notation
M_{i}
for the matrix in
\mathbb{Q}^{k_{i}\times k_{i}}
associated with this morphism:

\phi_{i}:B_{i}\mathbb{Z}^{k_{i}}\to\mathbb{Z}^{k_{i}}:\vec{z}\mapsto M_{i}\vec{z}.

From Proposition
4.4
, it follows that

R(\phi_{i})=[\mathbb{Z}^{k_{i}}:B_{i}\mathbb{Z}^{k_{i}}]|\det(I_{k_{i}}-M_{i})|_{\infty}=\bigg[\frac{N_{i}}{N_{i+1}}:\frac{H_{i}N_{i+1}}{N_{i+1}}\bigg]|\det(I_{k_{i}}-M_{i})|_{\infty}.

The following lemma and its proof is a straightforward generalization of a result of Gonçalves and Wong in
[

]
.

Lemma 4.7
.

Consider groups

As
\phi_{i}
can be seen as a morphism

For nilpotent groups, we now have

Lemma 4.9
.

Let
N
be a finitely generated, torsion free nilpotent group of nilpotency class
c,

H\leq_{f}N
and
\phi:H\to N
a morphism. If
|\Fix(\phi)|=\infty,
then there exists an

such that
\phi_{i}:\frac{H_{i}N_{i+1}}{N_{i+1}}\to\frac{N_{i}}{N_{i+1}}
has eigenvalue 1.

Let
h\in\Fix(\phi)\setminus\{1_{H}\}
and let
i\in\{1,2,\dots,c\}
be the biggest
i
such that
h\in H_{i}.
Then
hN_{i+1}\neq 1N_{i+1}
because otherwise
h\in N_{i+1}\cap H=H_{i+1}.
So
hN_{i+1}
is not the identity element, and
\phi_{i}(hN_{i+1})=hN_{i+1}.
It follows that
\phi_{i}
has eigenvalue 1.

Let
X\leq N.
We will use
\overline{X}
to denote the group
\overline{X}:=\frac{XN_{c}}{N_{c}}.
So
\overline{N}=\frac{NN_{c}}{N_{c}}=\frac{N}{N_{c}}
is a finitely generated, torsion free

\overline{(N_{i})}=\frac{N_{i}N_{c}}{N_{c}}=\frac{N_{i}}{N_{c}}
and
\overline{H}=\frac{HN_{c}}{N_{c}}.
Note that we introduced brackets in the notation
\overline{(N_{i})},
in order to clearly show the difference with
(\overline{N})_{i}.
The last group is
(\overline{N})_{i}=\big(\frac{N}{N_{c}}\big)_{i}=\sqrt[\frac{N}{N_{c}}\;\;]{\gamma_{i}\big(\frac{N}{N_{c}}\big)}.

Lemma 4.10
.

Let
N
be a finitely generated, torsion free nilpotent group of nilpotency class
c
and
H\leq_{f}N.
Then
\overline{H}\leq_{f}\overline{N}
and we have that
\overline{(N_{i})}=(\overline{N})_{i}
and
\overline{(H_{i})}=(\overline{H})_{i}
for all

Proof.

To prove
\overline{(N_{i})}\supseteq(\overline{N})_{i},
we choose an arbitrary
x\in\big(\frac{N}{N_{c}}\big)_{i}=\sqrt[\frac{N}{N_{c}}\;\;]{\gamma_{i}\big(\frac{N}{N_{c}}\big)}.
Then
x=yN_{c}
with

and
(yN_{c})^{k}=y^{k}N_{c}\in\gamma_{i}\big(\frac{N}{N_{c}}\big)
for a positive integer

Since
\gamma_{i}\big(\frac{N}{N_{c}}\big)=\frac{\gamma_{i}(N)N_{c}}{N_{c}},
it follows that
y^{k}\in\gamma_{i}(N)N_{c},
so
y^{k}=\alpha\beta
for certain
\alpha\in\gamma_{i}(N)
and
\beta\in N_{c}=\sqrt[N]{\gamma_{c}(N)}.
Let
l
be a positive integer for which
\beta^{l}\in\gamma_{c}(N).
Since
N_{c}\subseteq Z(N),
we know that
[\alpha,\beta]=1,
so

It follows that
y\in\sqrt[N]{\gamma_{i}(N)}=N_{i}
and we conclude that

To prove
\overline{(N_{i})}\subseteq(\overline{N})_{i},
we take an arbitrary

Since

there exists a positive integer

Then

\overline{(N_{i})}=(\overline{N})_{i}.

Recall that for a morphism

and hence also induced morphisms

Lemma 4.11
.

With the notation introduced above, we have that
R(\bar{(\phi)_{i}})=R(\phi_{i})
for all

We know that

\varphi_{i}\in\text{End}(G)

\psi_{f}:N\to N^{n}\rtimes\Sigma_{n}

with

\psi_{f}(\gamma)=(\phi_{1}(\gamma),\phi_{2}(\gamma),\ldots,\phi_{n}(\gamma);\sigma_{\gamma})
.
We have that for each
i\in\{1,2,\dots,n\}

R_{i}(f)=[N:S_{i}]\cdot|\det(I-\varphi_{i*})|_{\infty}

where
S_{i}=\{\gamma\in N\mid\sigma_{\gamma}(i)=i\}

and

R(f)=\sum_{i=1}^{n}|\det(I-\varphi_{i*})|_{\infty}.

In the formula above
\det(I-\varphi_{i*})
is computed by using the matrix expression of
\varphi_{i\ast}
with respect to a chosen basis of
\mathfrak{g}
.

Proof.

As the determinants
\det(I-\varphi_{i*})
are independent of the chosen basis for the vector space
\mathfrak{g}
we can fix a Malcev basis
a_{1,1},a_{1,2},\dots,a_{c,k_{c}}
for
N
which is compatible with the isolators of the lower central series and use the

A_{i,j}=\log(a_{i,j})
as a basis of
\mathfrak{g}
as before.

Let
i
be in
\{1,2,\dots,n\}.

If we denote conjugation with an element
g\in G
as

\mu(g):G\to G:x\mapsto\mu(g)(x)=gxg^{-1},

then, by Lemma
5.3
, the morphism
\phi_{i}:G\to G
is equal to
\phi_{i}=\mu(g_{i})\circ\varphi_{i},

so
\varphi_{i}=\mu(g_{i}^{-1})\circ\phi_{i}.

It follows that
\varphi_{i*}=\mu(g_{i}^{-1})_{*}\circ\phi_{i*}:\mathfrak{g}\to\mathfrak{g}

and therefore the matrix expression of
\varphi_{i*}

with respect to the basis
A_{1,1},A_{1,2},\dots,A_{c,k_{c}}

is

\begin{pmatrix}I_{k_{1}}&0&\ldots&&0\\
*&I_{k_{2}}&&&0\\
\vdots&*&\ddots&&\vdots\\
\vdots&&&\ddots&0\\
*&*&\ldots&*&I_{k_{c}}\end{pmatrix}\cdot\begin{pmatrix}M_{1}&0&\ldots&&0\\
*&M_{2}&&&0\\
\vdots&*&\ddots&&\vdots\\
\vdots&&&\ddots&0\\
*&*&\ldots&*&M_{c}\end{pmatrix}=\begin{pmatrix}M_{1}&0&\ldots&&0\\
*^{\prime}&M_{2}&&&0\\
\vdots&*^{\prime}&\ddots&&\vdots\\
\vdots&&&\ddots&0\\
*^{\prime}&*^{\prime}&\ldots&*^{\prime}&M_{c}\end{pmatrix},

because conjugation by
g_{i}^{-1}
induces the identity on each factor
\gamma_{l}(G)/\gamma_{l+1}(G)
.

Together with Theorem
4.14
, this implies that

R_{i}(f)=[N:S_{i}]\cdot\Big|\det\Big(I-\begin{pmatrix}M_{1}&0&&0\\
0&M_{2}&\cdots&0\\
\vdots&\vdots&\ddots&\vdots\\
0&0&\cdots&M_{c}\end{pmatrix}\Big)\Big|_{\infty}=[N:S_{i}]\cdot\Big|\det\Big(I-\varphi_{i*}\Big)\Big|_{\infty}.

Let now

\bar{f}^{*}_{i_{1}},\bar{f}^{*}_{i_{2}},\dots,\bar{f}^{*}_{i_{r}}

be representatives for the
\sigma-
classes of
\bar{f}^{*}.

As discussed in Section
2
, we get

R(f)=\sum_{k=1}^{r}R_{i_{k}}(f)=\sum_{k=1}^{r}[N:S_{i_{k}}]\cdot\Big|\det\Big(I-\varphi_{i_{k}*}\Big)\Big|_{\infty}=\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{i*}\Big)\Big|_{\infty},

where the last equality holds because the index
[N:S_{i_{k}}]
equals the number of elements in the
\sigma-
class of
i_{k}.

∎

6
Nielsen numbers of affine
n
-valued maps

To compute the Nielsen number of an
n
-valued affine map
f
, we will decompose
f
into its irreducible components as described by Staecker in Section 4 of
[
23
]
. Let
f:X\to D_{n}(X)
be an
n
-valued map. An
m
-valued map
g:X\to D_{m}(X)
(with
1\leq m\leq n
) is a submap of
f
when
g(x)\subseteq f(x)
for all
x\in X
. The map
f
is said to be irreducible when
f
does not have an
m
-valued submap with
m<n
.

For any
n
-valued map
f:X\to D_{n}(X)
there exist
r
(unique up to order) irreducible
n_{i}
-valued maps
f_{i}:X\to D_{n_{i}}(X)

with
n_{1}+n_{2}+\cdots+n_{r}=n
for some
r\in\{1,2,\ldots,n\}
, such that

f(x)=f_{1}(x)\cup f_{2}(x)\cup\cdots\cup f_{r}(x)
for all
x\in X
. We will refer to the
f_{i}
as the irreducible components of
f
.

Let
\bar{f}^{\ast}=(\bar{f}^{\ast}_{1},\bar{f}^{\ast}_{2},\ldots,\bar{f}^{\ast}_{n}):\tilde{X}\to F_{n}(\tilde{X},\pi)
be a fixed basic lifting of
f
determining a morphism
\psi_{f}:\pi\to\pi{{}^{n}}\rtimes\Sigma_{n}:\gamma\mapsto\psi_{f}(\gamma)=(\phi_{1}(\gamma),\phi_{2}(\gamma),\ldots,\phi_{n}(\gamma);\sigma_{\gamma})
as before and recall that we divided the lift-factors
\bar{f}^{\ast}_{i}
into equivalence classes, called
\sigma
–classes, by putting
\bar{f}^{\ast}_{i}\sim\bar{f}^{\ast}_{j}\Leftrightarrow i\sim j\Leftrightarrow\exists\gamma\in\pi:\sigma_{\gamma}(j)=i
.
When the
\sigma
–class of
\bar{f}^{\ast}_{i}
is given by
\{\bar{f}^{\ast}_{j_{1}}=\bar{f}^{\ast}_{i},\bar{f}^{\ast}_{j_{2}},\ldots,\bar{f}^{\ast}_{j_{m}}\}
, then
the map
g:X\to D_{m}(X):x\mapsto\{p(\bar{f}^{\ast}_{j_{1}}(\tilde{x})),p(\bar{f}^{\ast}_{j_{2}}(\tilde{x})),\ldots,p(\bar{f}^{\ast}_{j_{m}}(\tilde{x}))\}
, where

\tilde{x}\in\tilde{X}
is an element with
p(\tilde{x})=x
, is a well defined irreducible
m
-valued map which is one of the irreducible components of
f
and all irreducible components of
f
are obtained in this way. So the number of irreducible components of
f
equals the number of
\sigma
–classes.

Note that, when
f_{1},f_{2},\ldots,f_{r}
are the irreducible components of the
n
-valued map
f:X\to D_{n}(X)
, formula (
2
) can now also be interpreted as

R(f)=R(f_{1})+R(f_{2})+\ldots+R(f_{r}).

We also have the following result.

Proposition 6.1
.

(Corollary 4.7 from
[
23
]
) Let
f:X\to D_{n}(X)
be an
n
-valued map with irreducible components
f_{1},f_{2},\ldots,f_{r}
, then

N(f)=N(f_{1})+N(f_{2})+\cdots+N(f_{r}).

We will now apply this to affine
n
-valued maps on nilmanifolds. We start with the following observation.

Lemma 6.2
.

Let
\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}
be a nilmanifold and let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)
be an affine
n-
valued map with
basic lifting
\bar{f}^{\ast}=(\bar{f}^{\ast}_{1},\bar{f}^{\ast}_{2},\ldots,\bar{f}^{\ast}_{n})
. If
\bar{f}^{*}_{i}=(g_{i},\varphi_{i})
and
\bar{f}^{*}_{j}=(g_{j},\varphi_{j})
are in the same
\sigma-
class, then
\varphi_{i}=\varphi_{j}.

Proof.

The lift-factors
\bar{f}^{*}_{i}
and
\bar{f}^{*}_{j}
are in the same
\sigma-
class
if and only if
there exists a
\gamma\in N
such that
\sigma_{\gamma}^{-1}(i)=j.

For the element
\gamma
it holds that

\bar{f}^{*}_{i}\circ\gamma=\phi_{i}(\gamma)\circ\bar{f}^{*}_{j}.

Let
\gamma^{\prime}=\phi_{i}(\gamma).

Then for all
x\in G
we have that

(\bar{f}^{*}_{i}\circ\gamma)(x)=(\gamma^{\prime}\circ\bar{f}^{*}_{j})(x),

so

g_{i}\varphi_{i}(\gamma x)=\gamma^{\prime}g_{j}\varphi_{j}(x).

Taking
x=1
we get
g_{i}\varphi_{i}(\gamma)=\gamma^{\prime}g_{j}.

It follows that
g_{i}\varphi_{i}(\gamma x)=g_{i}\varphi_{i}(\gamma)\varphi_{i}(x)=\gamma^{\prime}g_{j}\varphi_{i}(x)

and so

g_{i}\varphi_{i}(\gamma x)=\gamma^{\prime}g_{j}\varphi_{j}(x)

reduces to

\gamma^{\prime}g_{j}\varphi_{i}(x)=\gamma^{\prime}g_{j}\varphi_{j}(x),

from which we get that

\varphi_{i}(x)=\varphi_{j}(x)
for all
x\in G
so
\varphi_{i}=\varphi_{j}.

∎

Remark 6.3
.

Note that when
f
is an irreducible affine
n
-valued map, there is only one
\sigma
–class and hence all the linear parts
\varphi_{i}
of all lift-factors are equal to each other and so we will just need one endomorphism
\varphi=\varphi_{i}\in{\text{End}}(G)
. By Proposition
6.1
it is enough to be able to compute the Nielsen number of irreducible affine
n
-valued maps. In order to achieve this, we will make a distinction in two cases, depending on whether or not the differential
\varphi_{\ast}
of the linear part has an eigenvalue 1 or not.

Before we start considering the two cases, we prove one more result that will be useful for both.

Lemma 6.4
.

Let
G
be a connected and simply connected nilpotent Lie group.
Suppose that
\varphi\in\text{End}(G)
is such that
\varphi_{*}\in\text{End}(\mathfrak{g})
does not have eigenvalue 1.
Then the map

\psi:G\to G:x\mapsto\varphi(x)x^{-1}
is bijective.

Proof.

We prove this by induction on the nilpotency class
c
of
G.

If
c=1,
then
G\cong\mathbb{R}^{k}
and
\varphi=\varphi_{*}.

In this case, the map
\psi
is
\varphi-\text{Id}_{\mathbb{R}^{k}},

which is bijective because
\det(\varphi-\text{Id}_{\mathbb{R}^{k}})\neq 0.

Suppose
c>1
and
\psi
is bijective if
G
has nilpotency class
c-1.

Note that
\varphi(\gamma_{c}(G))\subseteq\gamma_{c}(G),

so
\psi
induces a map

\bar{\psi}:\frac{G}{\gamma_{c}(G)}\to\frac{G}{\gamma_{c}(G)}:x\gamma_{c}(G)\mapsto\varphi(x)x^{-1}\gamma_{c}(G).

In fact
\bar{\psi}
is the map corresponding to the endomorphism

\bar{\varphi}:\frac{G}{\gamma_{c}(G)}\to\frac{G}{\gamma_{c}(G)}:x\gamma_{c}(G)\mapsto\varphi(x)\gamma_{c}(G)

and so
\bar{\psi}
is bijective because
\bar{\varphi}_{*}
also does not have 1 as an eigenvalue.
Let
\varphi^{\prime}=\varphi_{\mkern 4.0mu\vrule height=6.02777pt\mkern 4.0mu\gamma_{c}(G)},

then
\varphi^{\prime}(=\varphi^{\prime}_{*})
does not have 1 as an eigenvalue
and also

{\psi^{\prime}}:{\gamma_{c}(G)}\to{\gamma_{c}(G)}:x\mapsto\varphi^{\prime}(x)x^{-1}

is bijective.
To prove the surjectivity of
\psi,

suppose
y\in G.

Then there exists an
x^{\prime}\gamma_{c}(G)
such that

\bar{\psi}(x^{\prime}\gamma_{c}(G))=y\gamma_{c}(G).

This implies that

\varphi(x^{\prime})x^{\prime-1}=yz

for some
z\in\gamma_{c}(G).

Since
\psi^{\prime}
is bijective,
there exists a
z_{1}\in\gamma_{c}(G)

with
\varphi(z_{1})z_{1}^{-1}=z^{-1}.

Since
z_{1},\varphi(z_{1})\in\gamma_{c}(G)\subseteq Z(G),
we have

\varphi(x^{\prime}z_{1})(x^{\prime}z_{1})^{-1}=\varphi(x^{\prime})x^{\prime-1}\varphi(z_{1})z_{1}^{-1}=yzz^{-1}=y.

Hence for
x=x^{\prime}z_{1}

we have that

\psi(x)=y,

showing that
\psi
is surjective.
To prove the injectivity of
\psi,

suppose
\psi(x)=\psi(y).

Then
\varphi(x)x^{-1}=\varphi(y)y^{-1}
so

\varphi(x)x^{-1}\gamma_{c}(G)=\varphi(y)y^{-1}\gamma_{c}(G).

Since
\bar{\psi}
is bijective,
it follows that

x\gamma_{c}(G)=y\gamma_{c}(G)

and so

x=yz
for some
z\in\gamma_{c}(G).

But then

\varphi(x)x^{-1}=\varphi(yz)(yz)^{-1}=\varphi(y)y^{-1}\varphi(z)z^{-1}=\varphi(x)x^{-1}\varphi(z)z^{-1},

which implies that
\varphi(z)z^{-1}=1.

It follows that
z=1
because
\psi^{\prime}
is bijective
and consequently
x=y,

which was to be shown.
∎

6.1
The Nielsen number in case
\varphi_{\ast}
has eigenvalue 1

In this subsection we will show that
f
is homotopic to an
n
-valued map without fixed points, from which we will be able to conclude that
N(f)=0
.

Lemma 6.5
.

Let
l
be a positive integer.
For each
i\in\{1,2,\dots,l\},

let

h_{i}:\mathbb{R}^{n}\to\mathbb{R}

be a map.
Then there exists an
\epsilon\in\mathbb{R}

such that

h_{i}(z_{1},z_{2},\dots,z_{n})+\epsilon\neq 0

for all

z_{1},z_{2},\dots,z_{n}\in\mathbb{Z}

and all
i\in\{1,2,\dots,l\}.

Proof.

The set

A=\bigcup_{i=1}^{l}\{h_{i}(z_{1},z_{2},\dots,z_{n})|z_{j}\in\mathbb{Z}\}

is countable, so there exists an
r\in\mathbb{R}
such that
r\notin A.

Let
\epsilon=-r.

If there should be an
i\in\{1,2,\dots,l\}
and
z_{1},z_{2},\dots,z_{n}\in\mathbb{Z}
with

h_{i}(z_{1},z_{2},\dots,z_{n})+\epsilon=0,

then
h_{i}(z_{1},z_{2},\dots,z_{n})=r,
so
r\in A,
a contradiction.
Therefore we found an
\epsilon\in\mathbb{R}
such that for all
i\in\{1,2,\dots,l\}
and for all
z_{1},z_{2},\dots,z_{n}\in\mathbb{Z}:

h_{i}(z_{1},z_{2},\dots,z_{n})+\epsilon\neq 0.

∎

Lemma 6.6
.

Let
G
be a connected and simply connected
c
-step nilpotent Lie group.
Let
\varphi\in\text{End}(G)
with
\varphi_{*}
having eigenvalue 1.
Let
N
be a lattice of
G
and
g_{1},g_{2},\dots,g_{n}\in G.

Then there exists an
\alpha\in G
such that

g_{k}\varphi(x)\alpha\neq\gamma x

for all
x\in G,\gamma\in N
and
k=1,2,\dots,n.

Proof.

Let
a_{1,1},a_{1,2},\dots,a_{c,k_{c}}
be a Malcev basis as usual and use the matrices
M_{i}
for representing the induced endomorphism
on
\gamma_{i}(\mathfrak{g})/\gamma_{i+1}(\mathfrak{g})
as before.
Since
\varphi_{*}
has eigenvalue 1, there is a matrix
M_{i}
with eigenvalue 1.
Let
r
be the smallest index such that
M_{r}
has eigenvalue 1.
Without loss of generality, we may assume that
r=c,

because we can prove the lemma for
\frac{G}{\gamma_{r+1}(G)}
and then it follows for
G.

So we assume
G
is
c
-step nilpotent,
M_{c}
has eigenvalue 1 and
M_{i}
does not have eigenvalue 1 for
1\leq i\leq c-1
.
Since
\gamma_{c}(G)\cong\mathbb{R}^{k_{c}},
we can find a vector space basis

\{v_{1},v_{2},\dots,v_{k_{c}}\}
of
\mathbb{R}^{k_{c}}
such that the matrix expression of
\varphi_{c}
is of the form

\left(\begin{array}[]{c|ccc}1&0&\ldots&0\\
\hline\cr*&*&\ldots&*\\
\vdots&\vdots&\ddots&\vdots\\
&*&\ldots&*\end{array}\right)

with respect to this basis.
Let

V=\text{span}\{v_{1}\}

and

U=\text{span}\{v_{2},v_{3},\dots,v_{k_{c}}\},

then
U
and
V
are subgroups of
\gamma_{c}(G)
and hence of
G

and so we will keep using the multiplicative notation.
We get
\gamma_{c}(G)=VU
and
V=\{v_{1}^{r}|r\in\mathbb{R}\}.

Note that by the choice of basis we have that

\varphi(v_{1})=\varphi_{c}(v_{1})=v_{1}u
for some
u
in
U

and

\varphi(u)=\varphi_{c}(u)\subseteq U.

We claim that for a suitable choice of
\epsilon

we can take
\alpha=v_{1}^{\epsilon}.

Suppose that
x=a_{1}^{x_{1}}a_{2}^{x_{2}}\cdots a_{c}^{x_{c}},\gamma=a_{1}^{z_{1}}a_{2}^{z_{2}}\cdots a_{c}^{z_{c}}

and
k
satisfy

g_{k}\varphi(x)v_{1}^{\epsilon}=\gamma x.

Then, by considering the equation modulo
\gamma_{c}(G),

we get that

\bar{g}_{k}\bar{\varphi}(\bar{x})=\bar{\gamma}\bar{x}.

It follows that

\bar{\varphi}(\bar{x})\bar{x}^{-1}=\bar{g}_{k}^{-1}\bar{\gamma}.

(10)

From Lemma
6.4
,
it follows that

\bar{x}=\bar{a}_{1}^{x_{1}}\bar{a}_{2}^{x_{2}}\cdots\bar{a}_{c-1}^{x_{c-1}}

is uniquely determined by
\bar{g}_{k}
and
\bar{\gamma}.

So
x_{1},x_{2},\dots,x_{c-1}
are uniquely determined by
k
and
z_{1},z_{2},\dots,z_{c-1}.

This implies that
x^{\prime}=a_{1}^{x_{1}}a_{2}^{x_{2}}\cdots a_{c-1}^{x_{c-1}}

is uniquely defined by
k
and
z_{1},z_{2},\dots,z_{c-1}

and
x=x^{\prime}a_{c}^{x_{c}}.

We can write

a_{c}^{x_{c}}
as
a_{c}^{x_{c}}=v_{1}^{\alpha_{1}}u_{1}

with
\alpha_{1}\in\mathbb{R}
and
u_{1}\in U.

Now (
10
) implies that

\varphi(x^{\prime})x^{\prime-1}=g_{k}^{-1}\gamma v_{1}^{\alpha_{2}}u_{2}

with
\alpha_{2}\in\mathbb{R}
and
u_{2}\in U.

Remark that also
\alpha_{2}
is now completely determined by
k
and
z_{1},z_{2},\dots,z_{c}
because
x^{\prime}
is.
So
\alpha_{2}=h_{k}(z_{1},z_{2},\dots,z_{c})
for some map

h_{k}:\mathbb{R}^{k_{1}+k_{2}+\cdots+k_{c}}\to\mathbb{R}.

The equation

g_{k}\varphi(x)v_{1}^{\epsilon}=\gamma x

can now be written as

g_{k}\varphi(x^{\prime}v_{1}^{\alpha_{1}}u_{1})v_{1}^{\epsilon}=\gamma x^{\prime}v_{1}^{\alpha_{1}}u_{1}.

(11)

Note that

\varphi(v_{1}^{\alpha_{1}}u_{1})=v_{1}^{\alpha_{1}}u_{3}

for some
u_{3}\in U

and so (
11
) can be written as

\displaystyle g_{k}\varphi(x^{\prime})v_{1}^{\alpha_{1}}u_{3}v_{1}^{\epsilon}=\gamma x^{\prime}v_{1}^{\alpha_{1}}u_{1}

\displaystyle\iff

\displaystyle\varphi(x^{\prime})x^{\prime-1}=g_{k}^{-1}\gamma v_{1}^{-\epsilon}u_{4}\text{ for some }u_{4}\in U

\displaystyle\iff

\displaystyle g_{k}^{-1}\gamma v_{1}^{\alpha_{2}}u_{2}=g_{k}^{-1}\gamma v_{1}^{-\epsilon}u_{4}

\displaystyle\iff

\displaystyle v_{1}^{\alpha_{2}}u_{2}=v_{1}^{-\epsilon}u_{4}

\displaystyle\iff

\displaystyle v_{1}^{h_{k}(z_{1},z_{2},\ldots,z_{c})}u_{2}=v_{1}^{-\epsilon}u_{4}.

We know by Lemma
6.5
that we can choose
\epsilon

in such a way that none of the equations

h_{k}(z_{1},\dots,z_{c})+\epsilon=0

is satisfied, which proves the lemma.
∎

Theorem 6.7
.

Let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)

be an irreducible affine
n-
valued map
with basic lifting

\bar{f}^{*}=(g_{1}\varphi,g_{2}\varphi,\dots,g_{n}\varphi),

where
g_{1},g_{2},\dots,g_{n}\in G
and
\varphi\in\text{End}(G).

If
\varphi_{*}
has eigenvalue 1, then
N(f)=0.

Proof.

Applying Lemma
6.6

gives an element
\alpha\in G
such that
for all
x\in G
and
\gamma\in N
it holds that

\displaystyle g_{1}\varphi(x)\alpha\neq\gamma x,g_{2}\varphi(x)\alpha\neq\gamma x,\dots,g_{n}\varphi(x)\alpha\neq\gamma x.

(12)

Define

\bar{g}^{*}:G\to G^{n}:x\mapsto\big(g_{1}\varphi(x)\alpha,g_{2}\varphi(x)\alpha,\dots,g_{n}\varphi(x)\alpha\big).

As we know that
\bar{f}^{\ast}(x)=\big(g_{1}\varphi(x),g_{2}\varphi(x),\dots,g_{n}\varphi(x)\big)\in F_{n}(G,N)
, it easily follows that also
\bar{g}^{\ast}(x)\in F_{n}(G,N)
, so we will view
\bar{g}^{\ast}
as a map
from
G
to
F_{n}(G,N)
.

Let
\gamma\in N
and
x\in X.
Using (
1
),
we get

\displaystyle\bar{g}^{*}(\gamma x)

\displaystyle=\big(\bar{f}^{*}_{1}(\gamma x)\alpha,\bar{f}^{*}_{2}(\gamma x)\alpha,\dots,\bar{f}^{*}_{n}(\gamma x)\alpha\big)

\displaystyle=\big(\phi_{1}(\gamma)\bar{f}^{*}_{\sigma_{\gamma}^{-1}(1)}(x)\alpha,\phi_{2}(\gamma)\bar{f}^{*}_{\sigma_{\gamma}^{-1}(2)}(x)\alpha,\dots,\phi_{n}(\gamma)\bar{f}^{*}_{\sigma_{\gamma}^{-1}(n)}(x)\alpha\big)

\displaystyle=\psi_{f}(\gamma)\bar{g}^{*}(x).

It follows that
\bar{g}^{*}
is the basic lifting of a well defined
n
-valued map

g:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right).

Because of (
12
), the map
g
has no fixed points.
The maps
\bar{f}^{*}
and
\bar{g}^{*}
are homotopic by

\bar{F}^{*}:G\times[0,1]\to F_{n}(G,N):(x,t)\mapsto\big(g_{1}\varphi(x)\alpha^{t},g_{2}\varphi(x)\alpha^{t},\dots,g_{n}\varphi(x)\alpha^{t}\big).

This homotopy induces a homotopy between
f
and
g
. As
g
has no fixed points,
N(g)=0
and hence also
N(f)=0.

∎

Remark 6.8
.

For the
n
-valued affine map
f
from the previous theorem we have that

R(f)=\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{*}\Big)\Big|_{\infty}=n\Big|\det\Big(I-\varphi_{*}\Big)\Big|_{\infty}=\infty.

So
f
has infinitely many fixed point classes, all of index 0.

6.2
The Nielsen number in case
\varphi_{\ast}
does not have eigenvalue 1

In this case we want to show that each fixed point class exists of a single fixed point and that the index is non-zero.

Lemma 6.9
.

Let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)

be an irreducible affine
n-
valued map
with basic lifting

\bar{f}^{*}=(g_{1}\varphi,g_{2}\varphi,\dots,g_{n}\varphi),

where
g_{1},g_{2},\dots,g_{n}\in G
and
\varphi\in\text{End}(G).

If
\varphi_{*}
does not have eigenvalue 1, each fixed point class of
f
consists of a single point.

Proof.

Any lift-factor of
f
is of the form
\gamma g_{i}\varphi
for some
\gamma\in N
and some
i=1,2,\ldots,n
. The corresponding fixed point class is then
p\Fix(\gamma g_{i}\varphi)
. It is enough to show that
\Fix(\gamma g_{i}\varphi)
is a singleton. Note that
x\in\Fix(\gamma g_{i}\varphi)
if and only if
\varphi(x)x^{-1}=g_{i}^{-1}\gamma^{-1}
. By Lemma
6.4
, there is a unique such
x\in G
.
∎

We now prove that the index of such a fixed point class is never 0.

Lemma 6.10
.

Let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)

be an irreducible affine
n-
valued map
with basic lifting

\bar{f}^{*}=(g_{1}\varphi,g_{2}\varphi,\dots,g_{n}\varphi),

where
g_{1},g_{2},\dots,g_{n}\in G
and
\varphi\in\text{End}(G).

If
\varphi_{*}
does not have eigenvalue 1, then each fixed point class of
f
has index
\pm 1
.

Proof.

As in the previous lemma, a fixed point class is determined by a lift-factor, which is of the form
\gamma g_{i}\varphi
. The index of the corresponding fixed point class of
f
is the same as the index of the unique fixed point of the map
\gamma g_{i}\varphi:G\to G,
as defined by Schirmer on page 210 of
[
19
]
.
As in Section
3
, using Malcev coordinates, we identify
G
with
\mathbb{R}^{K}
(where
K=k_{1}+k_{2}+\cdots+k_{c}
) via

G\to\mathbb{R}^{K}:a_{1}^{x_{1}}a_{2}^{x_{2}}\ldots a_{c}^{x_{c}}\mapsto(x_{1},x_{2},\ldots,x_{c})
, where
x_{i}\in\mathbb{R}^{k_{i}}
. Recall that the Malcev coordinates also gave rise to isomorphisms
\gamma_{i}(G)/\gamma_{i+1}(G)\to\mathbb{R}^{k_{i}}
and the induced endomorphism by
\varphi
on

\gamma_{i}(G)/\gamma_{i+1}(G)
was represented by a matrix
M_{i}
.
If we now let
\gamma g_{i}=a_{1}^{\alpha_{1}}a_{2}^{\alpha_{2}}\ldots a_{c}^{\alpha_{c}}
, it follows from Theorem
3.2
that we can view the map
\gamma g_{i}\varphi:G\to G
as a map from
\mathbb{R}^{K}\to\mathbb{R}^{K}
which maps

(x_{1},x_{2},\ldots,x_{c})
to

(\alpha_{1}+M_{1}x_{1},\alpha_{2}+M_{2}x_{2}+q_{2}(x_{1}),\ldots,\alpha_{c}+M_{c}x_{c}+q_{c}(x_{1},x_{2},\ldots,x_{c-1})),

where
q_{i}(x_{1},x_{2},\ldots,x_{i-1})
is a polynomial depending on the variables
x_{1},x_{2},\ldots,x_{i-1}
(and on
\alpha_{1},\alpha_{2},\ldots,\alpha_{i-1}
and
M_{1},M_{2},\ldots,M_{i-1}
). Now let
x_{0}\in\mathbb{R}^{K}
be the unique fixed point of this map. In order to show that the index of this fixed point is non-zero we can consider the Jacobian
J_{x_{0}}
of this map at the point
x_{0}
. This Jacobian is of the form

\begin{pmatrix}M_{1}&0&\ldots&&0\\
*&M_{2}&&&0\\
\vdots&*&\ddots&&\vdots\\
\vdots&&&\ddots&0\\
*&*&\ldots&*&M_{c}\end{pmatrix}.

Note that also
\varphi_{\ast}
is of this form, with exactly the same blocks
M_{i}
on the diagonal (but other terms below the diagonal). As we assume that
1
is not an eigenvalue of
\varphi_{\ast}
, we also have that
1
is not an eigenvalue of
J_{x_{0}}
and so we get that

\det\Big(I-\begin{pmatrix}M_{1}&0&\ldots&&0\\
*&M_{2}&&&0\\
\vdots&*&\ddots&&\vdots\\
\vdots&&&\ddots&0\\
*&*&\ldots&*&M_{c}\end{pmatrix}\Big)\neq 0.

From page 12 of
[
14
]
,
it follows that the index equals the sign of the above determinant and hence equals
\pm 1
.
∎

Remark 6.11
.

Note that in the lemma above we have that the
M_{i}
’s appearing on the block diagonal of the Jacobian are the same for all lift-factors. This means that the index of the fixed point classes are either all equal to 1 or all equal to -1.

Theorem 6.12
.

Let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)

be an irreducible affine
n-
valued map
with basic lifting

\bar{f}^{*}=(g_{1}\varphi,g_{2}\varphi,\dots,g_{n}\varphi),

where
g_{1},g_{2},\dots,g_{n}\in G
and
\varphi\in\text{End}(G).

If
\varphi_{*}
does not have eigenvalue 1, then

N(f)=n\Big|\det\Big(I-\varphi_{*}\Big)\Big|.

Proof.

Indeed, there are

R(f)=\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{*}\Big)\Big|_{\infty}=n\Big|\det\Big(I-\varphi_{*}\Big)\Big|

fixed point classes, each of index
\pm 1
, so they are all essential. It follows that in this case
N(f)=R(f)=n\Big|\det\Big(I-\varphi_{*}\Big)\Big|
.
∎

6.3
The general case

We are now ready to prove the main result of this paper, which generalizes the well known formula of Anosov for computing the Nielsen number of single-valued maps on nilmanifolds.

Theorem 6.13
.

Let
f:\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\to D_{n}\left(\raisebox{-3.41432pt}{\small$N$\!}\backslash\raisebox{3.1298pt}{$\!G$}\right)

be an affine
n-
valued map
with basic lifting

\bar{f}^{*}=(g_{1}\varphi_{1},g_{2}\varphi_{2},\dots,g_{n}\varphi_{n}),

where
g_{1},g_{2},\dots,g_{n}\in G
and
\varphi_{1},\varphi_{2},\ldots,\varphi_{n}\in\text{End}(G).
Then

R(f)=\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{i*}\Big)\Big|_{\infty}\mbox{ and }N(f)=\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{i*}\Big)\Big|.

When
R(f)<\infty
, then
R(f)=N(f)
.

Proof.

The formula for the Reidemeister number was already obtained in Theorem
5.5
, so we only need to prove the formula for the Nielsen number.

By decomposing
f
into its irreducible components
f_{1},f_{2},\ldots,f_{r}
and by using the fact that
N(f)=N(f_{1})+N(f_{2})+\cdots+N(f_{r})
, it suffices to prove this theorem in case
f
is irreducible.
Note that in this case we have that
\varphi_{1}=\varphi_{2}=\cdots=\varphi_{n}
.

In case
\varphi_{1\ast}
has eigenvalue 1, we know by Theorem
6.7
that
N(f)=0
, but then we also have that
\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{i*}\Big)\Big|=0
since each term is 0. In the other case, Theorem
6.12
tells us that
N(f)=n\Big|\det\Big(I-\varphi_{1*}\Big)\Big|
but this also equals
\sum_{i=1}^{n}\Big|\det\Big(I-\varphi_{i*}\Big)\Big|
since all
\varphi_{i}
are the same.

The claim that
R(f)<\infty\Rightarrow R(f)=N(f)
is now obvious.
∎

We illustrate the obtained formulas with some examples.
Section 4 of
[
3
]
is devoted to the computation
of the Reidemeister and Nielsen number of the
3-
valued map

f:T^{2}\multimap T^{2}:p(t,s)\mapsto\left\{p(\frac{t}{2},-s),p(\frac{t+1}{2},-s),p(-t,-s+\frac{1}{2})\right\}

on the torus
T^{2}=\raisebox{-3.41432pt}{\small$\mathbb{Z}^{2}$\!}\backslash\raisebox{3.1298pt}{$\!\mathbb{R}^{2}$},

where
p:\mathbb{R}^{2}\to T^{2}
is the universal covering space.
The chosen basic lifting of
f
is
\bar{f}^{*}=(\bar{f}^{*}_{1},\bar{f}^{*}_{2},\bar{f}^{*}_{3}):\mathbb{R}^{2}\to F_{3}(\mathbb{R}^{2},\mathbb{Z}^{2}),

with the maps
\bar{f}^{\ast}_{i}:\mathbb{R}^{2}\to\mathbb{R}^{2}
(
i=1,2,3
) defined by

\displaystyle\bar{f}^{\ast}_{1}(t,s)

\displaystyle=(\frac{t}{2},-s),

\displaystyle\bar{f}^{\ast}_{2}(t,s)

\displaystyle=(\frac{t+1}{2},-s),

\displaystyle\bar{f}^{\ast}_{3}(t,s)

\displaystyle=(-t,-s+\frac{1}{2}).

The map
f
has six fixed points:

p(0,0),\;p(0,\frac{1}{2}),\;p(0,\frac{1}{4}),\;p(0,\frac{3}{4}),\;p(\frac{1}{2},\frac{1}{4}),\;p(\frac{1}{2},\frac{3}{4}).

In
[
3
]
we already found that
R(f)=6
(which was in fact done by using formula (
2
)),
and we also argued that the Nielsen number turns out to be the same in this case:
N(f)=6.

Now we can calculate those numbers easily again by using the above theorem.
With the notation from Theorem
6.13
,
we denote the affine lift-factors as

\displaystyle\bar{f}^{\ast}_{1}=\left(g_{1}=\begin{pmatrix}0\\
0\end{pmatrix},\varphi_{1}=\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\right),\;\bar{f}^{\ast}_{2}=\left(g_{2}=\begin{pmatrix}\frac{1}{2}\\
0\end{pmatrix},\varphi_{2}=\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\right)

\displaystyle\text{ and }\bar{f}^{\ast}_{3}=\left(g_{3}=\begin{pmatrix}0\\
\frac{1}{2}\end{pmatrix},\varphi_{3}=\begin{pmatrix}-1&0\\
0&-1\end{pmatrix}\right).

Since
G=\mathbb{R}^{2},

it holds that
\varphi_{i}=\varphi_{i*}
for
i=1,2,3

and thus we get

\displaystyle\sum_{i=1}^{3}

\displaystyle\Big|\det\Big(I-\varphi_{i*}\Big)\Big|_{\infty}

\displaystyle=\Big|\det\Big(I-\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty}+\Big|\det\Big(I-\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty}+\Big|\det\Big(I-\begin{pmatrix}-1&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty}.

This results in
1+1+4=6,
which is indeed equal to the Reidemeister number
R(f)
as computed before.
Since
R(f)<\infty,
Theorem
6.13
implies that
N(f)=R(f)=6,

which again is in accordance with the Nielsen number computed in
[
3
]
.
A slight modification of the map
f
in the third component
gives us another example.
Consider the
3-
valued map

g:T^{2}\multimap T^{2}:p(t,s)\mapsto\left\{p(\frac{t}{2},-s),p(\frac{t+1}{2},-s),p(t,-s+\frac{1}{2})\right\}

with basic lifting
\bar{g}^{*}=(\bar{g}^{*}_{1},\bar{g}^{*}_{2},\bar{g}^{*}_{3}):\mathbb{R}^{2}\to F_{3}(\mathbb{R}^{2},\mathbb{Z}^{2}),

where the maps
\bar{g}^{\ast}_{i}:\mathbb{R}^{2}\to\mathbb{R}^{2}
(
i=1,2,3
) are defined by

\displaystyle\bar{g}^{\ast}_{1}(t,s)

\displaystyle=(\frac{t}{2},-s),

\displaystyle\bar{g}^{\ast}_{2}(t,s)

\displaystyle=(\frac{t+1}{2},-s),

\displaystyle\bar{g}^{\ast}_{3}(t,s)

\displaystyle=(t,-s+\frac{1}{2}).

The map
g
has infinitely much fixed points:

p(0,0),\;p(0,\frac{1}{2})\text{ and }p(t,\frac{1}{4}),\;p(t,\frac{3}{4})\text{ for }t\in\mathbb{R}.

For the map
g
we have

\displaystyle\varphi_{1}=\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix},\varphi_{2}=\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\text{ and }\varphi_{3}=\begin{pmatrix}1&0\\
0&-1\end{pmatrix}.

We compute

\displaystyle\sum_{i=1}^{3}

\displaystyle\Big|\det\Big(I-\varphi_{i*}\Big)\Big|_{\infty}

\displaystyle=\Big|\det\Big(I-\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty}+\Big|\det\Big(I-\begin{pmatrix}\frac{1}{2}&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty}+\Big|\det\Big(I-\begin{pmatrix}1&0\\
0&-1\end{pmatrix}\Big)\Big|_{\infty},

which implies that
R(g)=|1|_{\infty}+|1|_{\infty}+|0|_{\infty}=1+1+\infty=\infty
.
For the Nielsen number on the other hand, we get

N(g)=|1|+|1|+|0|=2.
Note that the essential fixed point classes are
\{p(0,0)\}
and
\{p(0,\frac{1}{2})\}
.
