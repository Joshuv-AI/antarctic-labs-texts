On the Composition of Randomized Query Complexity and Approximate Degree
Sourav Chakraborty, Chandrima Kayal, Rajat Mittal, Manaswi Paraashar, Swagato Sanyal, Nitin Saurabh

Abstract
For any Boolean functions f f and g g , the question whether R ​ ( f ∘ g ) = Θ ~ ​ ( R ​ ( f ) ⋅ R ​ ( g ) ) \text{R}(f\circ g)=\widetilde{\Theta}(\text{R}(f)\cdot\text{R}(g)) , is known as the composition question for the randomized query complexity. Similarly, the composition question for the approximate degree asks whether deg ~ ​ ( f ∘ g ) = Θ ~ ​ ( deg ~ ​ ( f ) ⋅ deg ~ ​ ( g ) ) \widetilde{\text{deg}}(f\circ g)=\widetilde{\Theta}(\widetilde{\text{deg}}(f)\cdot\widetilde{\text{deg}}(g)) . These questions are two of the most important and well-studied problems in the field of analysis of Boolean functions, and yet we are far from answering them satisfactorily. It is known that the measures compose if one assumes various properties of the outer function f f (or inner function g g ). This paper extends the class of outer functions for which R and deg ~ \widetilde{\text{deg}} compose. A recent landmark result (Ben-David and Blais, 2020) showed that R ​ ( f ∘ g ) = Ω ⁡ ( noisyR ​ ( f ) ⋅ R ​ ( g ) ) \text{R}(f\circ g)=\Omega(\text{noisyR}(f)\cdot\text{R}(g)) . This implies that composition holds whenever noisyR ​ ( f ) = Θ ~ ​ ( R ​ ( f ) ) \text{noisyR}(f)=\widetilde{\Theta}(\text{R}(f)) . We show two results: 1. When R ​ ( f ) = Θ ​ ( n ) \text{R}(f)=\Theta(n) , then noisyR ​ ( f ) = Θ ​ ( R ​ ( f ) ) \text{noisyR}(f)=\Theta(\text{R}(f)) . In other words, composition holds whenever the randomized query complexity of the outer function is full. 2. If R composes with respect to an outer function, then noisyR also composes with respect to the same outer function. On the other hand, no result of the type deg ~ ​ ( f ∘ g ) = Ω ⁡ ( M ⁡ ( f ) ⋅ deg ~ ​ ( g ) ) \widetilde{\text{deg}}(f\circ g)=\Omega(M(f)\cdot\widetilde{\text{deg}}(g)) (for some non-trivial complexity measure M ⁡ ( ⋅ ) M(\cdot) ) was known to the best of our knowledge. We prove that deg ~ ​ ( f ∘ g ) = Ω ~ ​ ( bs ​ ( f ) ⋅ deg ~ ​ ( g ) ) , \widetilde{\text{deg}}(f\circ g)=\widetilde{\Omega}(\sqrt{\text{bs}(f)}\cdot\widetilde{\text{deg}}(g)), where bs ​ ( f ) \text{bs}(f) is the block sensitivity of f f . This implies that deg ~ \widetilde{\text{deg}} composes when deg ~ ​ ( f ) \widetilde{\text{deg}}(f) is asymptotically equal to bs ​ ( f ) \sqrt{\text{bs}(f)} . It is already known that both R and deg ~ \widetilde{\text{deg}} compose when the outer function is symmetric. We also extend these results to weaker notions of symmetry with respect to the outer function.

A crucial step towards understanding a complexity measure is: how does the complexity measure behave when two Boolean functions are combined to obtain a new function (i.e., what is the relationship between the measure of the resulting function and the measures of the two individual functions)

For any two Boolean functions

Composition of Boolean functions with respect to different complexity measures is a very important and useful tool in areas like communication complexity, circuit complexity and many more. To take an example, a popular application of composition is to create new functions demonstrating better separations (refer to

Ideas behind proof of Theorem
2.1

A crucial complexity measure that we use for the proof of Theorem

is called the

, first introduced by Ben-David and Blais
[
BDB20b
]
in order to study randomized query complexity.
Noisy randomized query complexity can be seen as a generalization of randomized query complexity where the algorithm can query a bit with any bias and only pays proportionally to the square of the bias in terms of cost

3.8

They give the following characterization of
\textnormal{noisyR}(f)

Theorem 2.2

(Ben-David and Blais
[
BDB20b
]
)
.

For all partial functions
f

n
-bits, we have

\textnormal{noisyR}(f)=\Theta\left(\frac{\textnormal{R}(f\circ\textnormal{GapMaj}_{n})}{n}\right),

(1)

\textnormal{GapMaj}_{n}

n

(n/2+2\sqrt{n})
(in which case the output is
-1

(n/2-2\sqrt{n})
(in which case the output is
1

We want to point out that the arity of
f
and Gap-Majority is the
same
in Theorem
2.2

Observation 2.3
.

Let
f
be a partial Boolean function on
n
bits. If
t(n)\geq 1

\displaystyle\textnormal{noisyR}(f)={\Omega}\left(\frac{\textnormal{R}(f\circ\textnormal{GapMaj}_{t(n)})}{t(n)}\right),

then
\textnormal{R}(f\circ g)={\Omega}((\textnormal{R}(f)\cdot\textnormal{R}(g))/t(n))
for all partial functions
g
.

In particular choosing

to be
(\log n)
, if the outer function
f
satisfies

\displaystyle\textnormal{noisyR}(f)={\Omega}\left(\frac{\textnormal{R}(f\circ\textnormal{GapMaj}_{\log n})}{\log n}\right).

(2)

then the above observation gives
\textnormal{R}(f\circ g)=\Omega((\textnormal{R}(f)\cdot\textnormal{R}(g))/(\log n))
for all partial functions
g

The Observation
2.3
allows us to approach the composition question for randomized query complexity in a conceptually fresh manner. The goal of proving that randomized query complexity composes for a function or a class of functions, say upto

2
holds for that function or class of functions for

.

We are able to show that Equation

Theorem 2.4

Let

be a partial function on
n

\textnormal{R}(f\circ\textnormal{GapMaj}_{t})=O\left(t\cdot\textnormal{noisyR}(f)+n\right)

Notice that this is a generalization of Ben-David and Blais’ characterization of

in one direction.
To give an idea of the proof, their characterization (Theorem

This seemingly inconsequential generalization allows us to complete the proof of Theorem

Furthermore, Theorem

2.3
Composition results when the outer functions has some symmetry

The class of symmetric functions capture many important function like
\mathsf{OR}
,

Recall that a function is symmetric when the function value only depends on the Hamming weight of the input; in other words, a function is symmetric iff its value on an input remains unchanged even after permuting the bits of the input. As noted earlier, both for

A natural question is, whether one can prove composition theorems when the outer function is

as well as on the Hamming weight of the whole input.

k
-junta symmetric functions can be seen as a mixture of symmetric functions and
k
-juntas. This class of functions has been considered previously in literature, particularly in
[
CFGM12
,
BWY15
]
where these functions plays a crucial role.
[
CFGM12
]

k
-junta symmetric functions for constant
k
.
Note that by definition an arbitrary
k
-junta (i.e., a function that depend on
k
variables) is also a
k
-junta symmetric function, since we can consider the dependence on Hamming weight to be trivial. Thus, this notion loses out on the symmetry of the function considered. We, therefore, consider the class of
strongly

k
-junta symmetric functions.

Definition 2.10

(Strongly
k
-junta symmetric function)
.

A
k
-junta symmetric function is called strongly
k
-junta symmetric if every variable is influential. In other words,
there exists a setting to the junta variables such that
the function value depends on the Hamming weight of the whole input in a non-trivial way.

We prove that if the outer function is strongly
\sqrt{n}
-junta symmetric (“strongly” indicating that the dependence on the Hamming weight is non-trivial) then
\widetilde{\deg}
composes. On the other hand, Theorem
2.1
implies that
R
composes for any strongly
k
-junta symmetric functions (as long as

).

Theorem 2.11
.

For any strongly
k
-junta symmetric function
f:\left\{0,1\right\}^{n}\to\left\{0,1\right\}
and any Boolean function
g:\left\{0,1\right\}^{m}\to\left\{0,1\right\}
, we have

•

\widetilde{\deg}(f\circ g)=\widetilde{\Theta}({\widetilde{\deg}(f)\cdot\widetilde{\deg}(g)})
where
k=O(\sqrt{n})
.

•

\textnormal{R}(f\circ g)=\widetilde{\Theta}({\textnormal{R}(f)\cdot\textnormal{R}(g)})
where
n-k=\Theta(n)
.

For the lack of space, the proof of the above theorem is given in Appendix
C
. Note that if one is able to prove the above theorem for
k
-junta-symmetric functions (without the requirement of “strongly”) for any non-constant

then we would have the full composition theorem.

Following is a formal definition of (partial) function composition.

3.1
Standard definitions and functions

3.1.1
Standard definition of complexity measures

We look at many different complexity measures in the paper, let us start with the formal definition of
R
and
\widetilde{\deg}
.

Definition 3.2

(Randomized query complexity
(\textnormal{R})
)
.

Let
f:\left\{0,1\right\}^{n}\to\{0,1,*\}
be a (possibly partial) Boolean function. A randomized query algorithm
A
computes
f
if

\forall x\in\textnormal{Dom}(f),\Pr[A(x)\neq f(x)]\leq 1/3
,
where the probability is over the internal randomness of the algorithm. The cost of the algorithm
A
,
cost
(A), is the number of queries made in the worst case over any input as well as internal randomness. The randomized query complexity of
f
, denoted by
\textnormal{R}(f)
, is defined as

\displaystyle\textnormal{R}(f)=\min_{A\text{ computes }f}\text{cost}(A).

Definition 3.3

(Approximate degree
(\widetilde{\deg})
)
.

A polynomial
p:\mathbb{R}^{n}\to\mathbb{R}
is said to approximate a Boolean function
f:\left\{0,1\right\}^{n}\to\{0,1\}
if

|p(x)-f(x)|\leq 1/3,\quad\forall x\in\left\{0,1\right\}^{n}
.
The approximate degree of
f
,
\widetilde{\deg}(f)
, is the minimum possible degree of a polynomial which approximates
f
.

Note that the constant
1/3
in the above definitions can be replaced by any constant strictly smaller than
1/2
which changes
\widetilde{\deg}(f)
by only a constant factor.

Other than
R
and
\widetilde{\deg}
, two important related measures are sensitivity (
\textnormal{s}(f)
) and block sensitivity (
\textnormal{bs}(f)
). While the sensitivity and block sensitivity of a total function is well defined, we note that for the case of partial functions there are at least two valid ways of extending the definition from total functions to partial functions. All our results in this paper will hold for partial functions with the following definitions of sensitivity and block sensitivity.

Definition 3.4
.

The sensitivity
\textnormal{s}(f,x)
of a function
f:\left\{0,1\right\}\to\left\{0,1,*\right\}
on
x
is the maximum number
s
such that there are indices
i_{1},i_{2},\dots,i_{s}\in[n]
with

f(x^{i_{j}})=1-f(x)
, for all
1\leq j\leq s
.
Here
x^{i}
is obtained from
x
by flipping the
i^{th}
bit.
The sensitivity of
f
is defined to be
\textnormal{s}(f)=\max_{x\in\textnormal{Dom}(f)}\textnormal{s}(f,x)
.

Similarly, the block sensitivity
\textnormal{bs}(f,x)
of a function
f:\left\{0,1\right\}\to\left\{0,1,*\right\}
on
x
is the maximum number
b
such that there are disjoint sets
B_{1},B_{2},\dots,B_{b}\subseteq[n]
with
f(x^{B_{j}})=1-f(x)
for all
1\leq j\leq b
.
Recall
x^{B_{j}}
is obtained from
x
by flipping all bits inside
B_{j}
.
The block sensitivity of
f
is defined to be
\textnormal{bs}(f)=\max_{x\in\textnormal{Dom}(f)}\textnormal{bs}(f,x)
.

In the definition of block sensitivity, the constraint that the blocks has to be disjoint can be relaxed by extending the definition to “fractional blocks”. This gives the measure of fractional block sensitivity.

Definition 3.5
.

The fractional block sensitivity
\textnormal{fbs}(f,x)
of a function
f:\left\{0,1\right\}\to\left\{0,1,*\right\}
on
x
is the maximum value of
\sum_{j=i}^{b}p_{j}
such that there are sets
B_{1},B_{2},\dots,B_{b}\subseteq[n]
and
p_{1},\dots,p_{b}\in(0,1]
satisfying the following two conditions.

•

For each
1\leq j\leq b
,
f(x^{B_{j}})=1-f(x)
, and

•

For each
1\leq i\leq n
,
\sum_{j\colon i\in B_{j}}p_{j}\leq 1
.

The fractional block sensitivity of
f
is defined to be
\textnormal{fbs}(f)=\max_{x\in\textnormal{Dom}(f)}\textnormal{fbs}(f,x)
.

For the composition of

The definition of

Definition 3.9

Proof of Theorem

.

Let
b=\textnormal{bs}(f)
and

be an input where

be disjoint minimal sets of variables that achieves the block sensitivity at

f(a)\neq f(a^{B_{i}})
for all
i\in[b]

a^{B_{i}}
denotes the Boolean string obtained
from
a
by flipping the bits at all the indices given by
B_{i}
. Define a partial function
f^{\prime}:\left\{0,1\right\}^{n}\to\{0,1,*\}
such that,

\displaystyle f^{\prime}(x)=\begin{cases}0&\text{if }x=a,\\
1&\text{if }x=a^{B_{i}},\text{ for some }i\in[b],\\
*&\text{otherwise}.\end{cases}

Note that
f

f^{\prime}
or its negation as a sub function.
Thus,

\widetilde{\deg}(f\circ g)\geq\widetilde{\mathrm{bdeg}}(f^{\prime}\circ g)
.

Since
g
is non-constant, we can fix the indices

according to

to obtain

We would now like to embed
\mathsf{PrOR}_{b}
over the remaining variables in

, let

be such that

\displaystyle I_{i}(x)=\begin{cases}0&\text{if }x=a|_{B_{i}},\\
1&\text{if }x=a^{B_{i}}|_{B_{i}},\\
*&\text{otherwise}.\end{cases}

Now observe that

can be rewritten as
\mathsf{PrOR}_{b}\circ(I_{1}\circ g,\ldots,I_{b}\circ g)
. We therefore have

\displaystyle\widetilde{\deg}(f\circ g)\geq\widetilde{\mathrm{bdeg}}(f^{\prime}\circ g)\geq

\displaystyle~\widetilde{\mathrm{bdeg}}(f^{\prime\prime}\circ g)=\widetilde{\mathrm{bdeg}}(\mathsf{PrOR}_{b}\circ(I_{1}\circ g,\ldots,I_{b}\circ g))

\displaystyle=\Omega\left(\frac{\sqrt{b}\cdot\min_{i}\widetilde{\mathrm{bdeg}}(I_{i}\circ g)}{\log b}\right)=\widetilde{\Omega}\left(\sqrt{b}\cdot\widetilde{\deg}(g)\right),

Conclusion

While our work makes progress on the composition problem for

We showed that the composition question for

is equivalent to the following open question (which is a generalization of Ben-David and Blais
[

]
result):

Open question 6.1
.

Let

Then,

?

In case of approximate degree composition,

can be replaced by some other complexity measures. In this regards we state the following open problems:

Open question 6.2
.

For all Boolean functions
f

•

\widetilde{\deg}(f\circ g)=\Omega(\sqrt{\deg(f)}\cdot\widetilde{\deg}(g))

•

]

Open question 6.3

Can we prove that
\widetilde{\deg}
and

In this section, we define some important Boolean functions that have been used in the paper. We start with Multiplexer Function or Addressing Function.

Definition A.1

\mathsf{MUX}:\left\{0,1\right\}^{k+2^{k}}\to\left\{0,1\right\}

.

Definition A.2

(
\mathsf{SINK}

Consider a tournament defined on

i<j

i

j

Definition A.3

(Rubinstein function

]
)

Let

be such that

A.1
Some properties of
\mathsf{SINK}
and Rubinstein function

Following is an easy observation.

Observation A.4
.

The sensitivity of

(k-1)
. Consider a tournament on vertices

such that

We now want to give an upper bound on the approximate degree of these two functions. For this, we first need the following generalization of approximate degree.

Definition A.5

(
\varepsilon
-Error Approximate Degree
(\widetilde{\deg}_{\varepsilon})

.

A polynomial

-approximate a Boolean function

\displaystyle|p(x)-f(x)|\leq\varepsilon,\quad\forall x\in\left\{0,1\right\}^{n}.

It is known (see

\varepsilon
-approximates

.

Also, the following theorem will be used in this section.

(
[
She13c
]
)
.

For all Boolean functions

and

.

We now upper bound the approximate degree of

and

Lemma A.7
.

For the sink function
\mathsf{SINK}:\left\{0,1\right\}^{\binom{k}{2}}\to\left\{0,1\right\}

Proof.

We first upper bound the approximate degree of

\mathbb{E}[X_{i}]=\mu_{T}
for all
i
, along with Equation
19
we have

\displaystyle\mathbb{E}[\ell_{r}]\leq T_{k}/\mu_{T}+12.

Summing over all
k
and using Equation
16
, the expected number of queries made by algorithm
B
is upper bounded by

\displaystyle O\left(\frac{\textnormal{noisyR}(f)}{\widehat{\gamma}^{2}\mu_{T}}+12n\right).

Thus the expected cost of
B
is upper bounded by

\displaystyle O\left(\frac{\textnormal{noisyR}(f)}{t\widehat{\gamma}^{2}\mu_{T}}+\frac{12n}{t}\right).

Since
\mu_{T}=\Omega(1/(t\widehat{\gamma}^{2}))
, the above quantity is upper bounded by

\displaystyle O\left(\textnormal{noisyR}(f)+\frac{n}{t}\right).

In order to complete the proof of the theorem, we show how to simulate
B
to obtain a randomized query algorithm
B^{\prime}
for
f\circ\textnormal{GapMaj}_{t}
of cost
O(t\cdot\textnormal{noisyR}(f)+n)
. The algorithm
B^{\prime}
simulates
B
in the following manner:

1.

if
b
queries
i
-th bit of
f
with bias
1
, for some
i\in[n]
, then
B^{\prime}
queries all the bits of
i
-th Gap-Majority inner function.

2.

if
B
queries
i
-th bit of
f
with bias
1/\sqrt{t}
, for some
i\in[n]
, then
B^{\prime}
queries a random bit of
i
-th Gap-Majority inner function.

The correctness of
B^{\prime}
follows directly from the simulation and the correctness of
B
. Also, in both the cases (1. and 2.), cost paid by
B^{\prime}
is
t
times the cost paid by
B
. Thus

\displaystyle\textnormal{R}(f\circ\textnormal{GapMaj}_{t})=O\left(t\cdot\textnormal{noisyR}(f)+n\right).

(20)

∎

Proof of Lemma
D.3
.

As mentioned in the statement of the lemma, the equality

\displaystyle\mu_{T}

\displaystyle=\frac{T}{\widehat{\gamma}}\ -\ \frac{2T}{\widehat{\gamma}}(1-\widehat{\gamma})^{T}\left(\frac{(1+\widehat{\gamma})^{T}-(1-\widehat{\gamma})^{T}}{(1+\widehat{\gamma})^{2T}-(1-\widehat{\gamma})^{2T}}\right),

(21)

follows from
[
Fel91
, Chapter XIV]
.

Next, we prove the second part of the lemma. The following inequalities are easy to observe.

\displaystyle(1+\widehat{\gamma})^{T}-(1-\widehat{\gamma})^{T}

\displaystyle\leq\frac{2\widehat{\gamma}T}{1-\widehat{\gamma}^{2}T^{2}},

\displaystyle(1+\widehat{\gamma})^{T}-(1-\widehat{\gamma})^{T}

\displaystyle\geq 2\widehat{\gamma}T,

\displaystyle(1-\widehat{\gamma})^{T}

\displaystyle\geq 1-T\widehat{\gamma}.

Using the above inequalities and Equation
21
we get the following bounds on
\mu_{T}

\displaystyle\frac{T^{2}}{(1+\widehat{\gamma}T)}\leq\mu_{T}\leq\frac{T}{\widehat{\gamma}}\left(\widehat{\gamma}T+4\widehat{\gamma}^{2}T^{2}-4\widehat{\gamma}^{3}T^{3}\right).

(22)

For
T=\Theta(1/\sqrt{t}\cdot\widehat{\gamma})
, the above expression implies that
\mu_{T}
is lower bounded by
\Omega(1/(t\cdot\widehat{\gamma}^{2}))
.

Now we use Equation
22
to upper bound
\mu_{2T}
in terms of
\mu_{T}
:

\displaystyle\mu_{2T}

\displaystyle\leq\frac{2T}{\widehat{\gamma}}\left(2\widehat{\gamma}T+16\widehat{\gamma}^{2}T^{2}-32\widehat{\gamma}^{3}T^{3}\right)

\displaystyle=\frac{T^{2}}{(1+\widehat{\gamma}T)}\cdot\frac{(1+\widehat{\gamma}T)}{T^{2}}\cdot\frac{2T}{\widehat{\gamma}}\left(2\widehat{\gamma}T+16\widehat{\gamma}^{2}T^{2}-32\widehat{\gamma}^{3}T^{3}\right)

\displaystyle\leq\frac{(1+\widehat{\gamma}T)}{T^{2}}\cdot\frac{2T}{\widehat{\gamma}}\left(2\widehat{\gamma}T+16\widehat{\gamma}^{2}T^{2}-32\widehat{\gamma}^{3}T^{3}\right)\cdot\mu_{T}

\displaystyle=2(1+\widehat{\gamma}T)\cdot\left(2+16\widehat{\gamma}T-32\widehat{\gamma}^{2}T^{2}\right)\cdot\mu_{T}.

Since
T=\Theta(1/(\sqrt{t}\cdot\widehat{\gamma}))
, for a suitable choice of constant, we have,

\displaystyle\mu_{2T}\leq 12\mu_{T}.

∎
