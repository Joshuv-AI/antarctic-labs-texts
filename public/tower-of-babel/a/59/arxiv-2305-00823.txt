Numerical Approximation of Stochastic Volterra Integral Equation Using Walsh Function
Prit Pritam Paikaray, Sanghamitra Beuria, Nigam Chandra Parida

Abstract
This paper provides a numerical approach for solving the linear stochastic Volterra integral equation using Walsh function approximation and the corresponding operational matrix of integration. A convergence analysis and error analysis of the proposed method for stochastic Volterra integral equations with Lipschitz functions are presented. Numerous examples with available analytical solutions demonstrate that the proposed method solves linear stochastic Volterra integral equations more precisely than existing techniques. In addition, the numerical behaviour of the method for a problem with no known analytical solution is demonstrated.

Definition 1

The first

The Walsh functions satisfy the following properties:

Orthonormality

The set of Walsh functions is orthonormal. i.e.,

\int_{0}^{1}w_{i}(t)w_{j}(t)dt=\Biggl\{\begin{aligned} 1&\quad\text{i=j,}\\
0&\quad\text{otherwise}.\end{aligned}

Completeness

For every

\int_{0}^{1}f^{2}(t)dt=\sum_{i=0}^{\infty}f_{i}^{2}\lvert\lvert w_{i}(t)\lvert\lvert^{2}

Walsh Function Approximation

Any real-valued function

The matrix form of the approximation is given by

One can see from

T_{W}T_{W}^{T}=mI\,\textrm{and}\,T_{W}^{T}=T_{W}

Similarly,

Lemma 3.2

(Integration of Walsh function)
.

Suppose that
W(t)
is a Walsh function vector, then the integral of

w.r.t.

be a Walsh function vector, then the integral of

,
|x(s)|\leq\sigma
and using Theorem
5.2
, we get

|k_{i}(s,t)x(s)-k_{im}(s,t)x_{m}(s)|\leq\sqrt{2}L_{i}h\sigma+(\rho_{i}+\sqrt{2}L_{i}h)|x(t)-x_{m}(t)|

(12)

which gives,

\displaystyle I_{1}

\displaystyle\leq

\displaystyle E\biggl(\biggl(\int_{0}^{t}\biggl|k_{1}(s,t)x(s)-k_{1m}(s,t)x_{m}(s)\biggr|ds\biggr)^{2}\biggr)

\displaystyle\leq

\displaystyle E\biggl(\biggl(\int_{0}^{t}\big(\sqrt{2}L_{i}h\sigma+(\rho_{i}+\sqrt{2}L_{i}h)|x(t)-x_{m}(t)|\big)ds\biggr)^{2}\biggr)

By Cauchy- Schwarz inequality, for
t>0
and
f\in L^{2}[0,1)

\biggl|\int_{0}^{t}f(s)ds\biggr|^{2}\leq t\int_{0}^{t}|f|^{2}ds

this implies,

\displaystyle I_{1}

\displaystyle\leq

\displaystyle E\biggl(2\int_{0}^{t}\biggl((\sqrt{2}L_{1}h\sigma)^{2}+(\rho_{1}+\sqrt{2}L_{1}h)^{2}|x(t)-x_{m}(t)|^{2}\biggr)ds\biggr)

Therefore,

\displaystyle I_{1}

\displaystyle\leq

\displaystyle 2(\sqrt{2}L_{1}h\sigma)^{2}+2(\rho_{1}+\sqrt{2}L_{1}h)^{2}E\biggl(\int_{0}^{t}|x(t)-x_{m}(t)|^{2}ds\biggr)

(13)

Now,

\displaystyle I_{2}\leq

\displaystyle E\biggl(\int_{0}^{t}\biggl|k_{2}(s,t)x(s)-k_{2m}(s,t)x_{m}(s)\biggr|^{2}ds\biggr)

\displaystyle\leq

\displaystyle 2E\biggl(\int_{0}^{t}\big((\sqrt{2}L_{2}h\sigma)^{2}+(\rho_{2}+\sqrt{2}L_{2}h)^{2}|x(t)-x_{m}(t)|^{2}\big)ds\biggr)

Hence,

\displaystyle I_{2}\leq

\displaystyle 2(\sqrt{2}L_{2}h\sigma)^{2}+2(\rho_{2}+\sqrt{2}L_{2}h)^{2}E\biggl(\int_{0}^{t}|x(t)-x_{m}(t)|^{2}ds\biggr)

(14)

Using Theorem
5.1
, equation (

) and (

) in (

), we get

\displaystyle E\big(|x(t)-x_{m}(t)|^{2}\big)

\displaystyle\leq

\displaystyle 5C^{2}h^{2}

\displaystyle+

\displaystyle 5\biggl(2(\sqrt{2}L_{1}h\sigma)^{2}+2(\rho_{1}+\sqrt{2}L_{1}h)^{2}E\biggl(\int_{0}^{t}|x(t)-x_{m}(t)|^{2}ds\biggr)\biggr)

\displaystyle+

\displaystyle 5\biggl(2(\sqrt{2}L_{2}h\sigma)^{2}+2(\rho_{2}+\sqrt{2}L_{2}h)^{2}E\biggl(\int_{0}^{t}|x(t)-x_{m}(t)|^{2}ds\biggr)\biggr)

\displaystyle E\big(|x(t)-x_{m}(t)|^{2}\big)

\displaystyle\leq

\displaystyle R_{1}+R_{2}\int_{0}^{t}E\bigl(|x(s)-x_{m}(s)|^{2}\bigr)ds

where,

\displaystyle E\big(|x(t)-x_{m}(t)|^{2}\big)

\displaystyle R_{1}\exp\biggl(\int_{0}^{t}R_{2}ds\biggr).

(16)

which implies that,

\|x(t)-x_{m}(t)\|_{2}^{2}=E\big(|x(t)-x_{m}(t)|^{2}\big)\leq R_{1}e^{R_{2}}=O(h^{2})

(17)

7
Conclusion

Due to the difficulty in determining the exact solution for the majority of SVIEs, numerical techniques are required to address these problems. Historically, several numerical solutions have been developed to approximate the solution of SVIEs. In addition, this article proposes a numerical method for approximating SVIE solutions. It also includes quantitative estimates for specific SVIEs. Error analysis of the methodology has been conducted to validate its dependability. As demonstrated in a number of preceding examples, numerical analysis demonstrates that the Walsh function approximation is preferable to existing methods for more precisely solving linear SVIEs. This concept could be expanded to include nonlinear SVIEs and SVIEs with singular kernels, which can be used to solve numerous physical problems.
