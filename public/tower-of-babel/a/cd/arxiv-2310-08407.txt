A quadric ansatz method for a certain class of second order PDEs
Prim Plansangkate

Abstract
We develop a procedure to implement the method of quadric ansatz to a class of second order partial differential equations (PDEs), which includes the four-dimensional Kähler-Einstein equation with symmetry and the one-sided type-D Einstein equation with nonzero scalar curvature. The procedure, which reduces the PDEs to ordinary differential equations (ODEs), involves imposing additional constraints to the form of the ansatz, depending on the exact form of the PDEs. Thus its applicability varies within the class. We identify applicable subclasses of a class of modified Toda equations, one of which includes the Kähler-Einstein equation with symmetry, and give the corresponding reduced ODEs. In addition, we obtain a quadric ansatz reduction for a family of Einstein-Weyl equations in arbitrary dimensions. Lastly, we suggest a particular form of equations for which our procedure appears to be most effective as the aforementioned constraints vanish, and also present some reduction results using another type of ansatz, namely the hyperplane ansatz.

2
An Extension of the Method of Quadric Ansatz

Let us first briefly review the method of quadric ansatz for a PDE of the form (
1.1
),

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)=0.

Implicitly differentiating the quadric ansatz (
1.2
),

\displaystyle M_{ij}(u)x^{i}x^{j}=C,

implies that

\frac{\partial u}{\partial x^{k}}=-\frac{2}{\dot{Q}}M_{kj}x^{j},

(2.1)

where
Q(\boldsymbol{x},u):=M_{ij}(u)x^{i}x^{j}
and

\displaystyle\dot{Q}:=\frac{\partial Q}{\partial u}=\dot{M}_{ij}\,x^{i}x^{j}.
Then
substituting (
2.1
) into (
1.1
) gives

{\bf X}^{T}\left(\frac{d}{du}({\bf MbM})-\frac{1}{2}\mbox{Tr}({\bf bM})\dot{\bf M}-\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}\ddot{\bf M}\right){\bf X}=0,

(2.2)

where
\displaystyle\dot{\bf M}:=\frac{d{\bf M}}{du},

{\bf X}^{T}=(x^{1}\,\dots\,x^{N})
is a row vector and the transpose of
{\bf X}.

The vanishing of the matrix in the bracket in (
2.2
) gives an equation which is regarded as a reduction of (
1.1
) by the quadric ansatz. Note, however, that for this equation to be an ODE for
{\bf M}
with respect to the independent variable
u,
one requires that
\displaystyle\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}
is a function of
u
only, with no explicit
\boldsymbol{x}
-dependence. With no prior knowledge of a solution
u(\boldsymbol{x}),
treating
u,x^{i}
as independent variables, it follows that

g\dot{\bf M}={\bf MbM},

for some function
g(u).
Differentiating the above equation and comparing it with the vanishing of the matrix in the bracket of (
2.2
),

\displaystyle\frac{d}{du}({\bf MbM})-\frac{1}{2}\mbox{Tr}({\bf bM})\dot{\bf M}-g\ddot{\bf M}=0,

implies that
\displaystyle\dot{g}:=\frac{dg}{du}=\frac{1}{2}\mbox{Tr}({\bf bM}).

Hence altogether one obtains the quadric ansatz reduction of (
1.1
) as a system of ODEs

g\dot{\bf M}={\bf MbM},\qquad\dot{g}=\frac{1}{2}\mbox{Tr}({\bf bM}).

(2.3)

Also, as shown in
[
19
]
, if
{\bf M}
is invertible, by introducing
{\bf N}=-{\bf M}^{-1}
the system
(
2.3
) becomes

g\dot{\bf N}={\bf b}\qquad g^{2}\det{\bf N}=\zeta,

(2.4)

where
\zeta
is an arbitrary nonzero constant.   For many cases, system (
2.4
) turns out to be easier to solve than (
2.3
).

Now consider a PDE of the form (
1.6
),

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)+T(\boldsymbol{x},u,u_{x^{i}})=0.

By substituting (
2.1
) into equation (
1.6
), one obtains instead of (
2.2
) the equation

{\bf X}^{T}\left(\frac{d}{du}({\bf MbM})-\frac{1}{2}\mbox{Tr}({\bf bM})\dot{\bf M}-\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}\ddot{\bf M}+\frac{\dot{Q}T}{4}\,\dot{\bf M}\right){\bf X}=0.

(2.5)

A way to proceed is to follow the same argument and require that both functions

\displaystyle\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}
and
\displaystyle\dot{Q}T
depend only on
u
with no explicit
\boldsymbol{x}
-dependence. The requirement on
\displaystyle\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}
gives the first equation of (
2.3
) as before, with
g(u)=\displaystyle\frac{{\bf X}^{T}({\bf MbM}){\bf X}}{{\bf X}^{T}\dot{\bf M}{\bf X}}.

Requiring that
\displaystyle\dot{Q}T
is also a function of
u
puts another constraint on
{\bf M}.

Let us write this as the existence of a function
\displaystyle\tau(u)
such that
\displaystyle\tau(u)=\frac{\dot{Q}T}{4}.
Differentiating the first equation of (
2.3
) and comparing it with the vanishing of the matrix in the bracket of (
2.5
),

{\displaystyle\frac{d}{du}({\bf MbM})-\frac{1}{2}\mbox{Tr}({\bf bM})\dot{\bf M}-g\ddot{\bf M}+\tau\dot{\bf M}=0,}

this time yields
\displaystyle\dot{g}=\frac{1}{2}\mbox{Tr}({\bf bM})-\tau.
Therefore we arrive at a system of ODEs almost the same as (
2.3
). As before, the assumption of an invertible
{\bf M}
yields another form of the system in terms of
{\bf N}=-{\bf M}^{-1}.
The result is given in the following proposition, using the notation as defined previously.

Given a PDE of the form
(

)

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)+T(\boldsymbol{x},u,u_{x^{i}})=0,

)

such that

\displaystyle g\dot{\bf M}

\displaystyle=

\displaystyle{\bf MbM},

(2.6)

\displaystyle\dot{g}

\displaystyle=

\displaystyle\frac{1}{2}{\rm{Tr}}({\bf bM})-\tau,

(2.7)

\displaystyle\tau

\displaystyle=

\displaystyle\frac{({\bf X}^{T}\dot{\bf M}{\bf X})\,T}{4}.

(2.8)

If
{\bf M}
is invertible and let

the system
(
2.6
,
2.7
)
is equivalent to

\displaystyle g\dot{\bf N}

\displaystyle=

\displaystyle{\bf b},

(2.9)

\displaystyle g^{2}\,e^{2\int(\tau/g)\,du}\,\det{\bf N}

\displaystyle=

\displaystyle\zeta,

(2.10)

where

is an arbitrary nonzero constant.

In Section
3
and
4
we apply the method of quadric ansatz described in Proposition

to two classes of PDEs. Let us note here that in solving the system (

,
2.7
,
2.8
), one could use (

) as a constraint on

and seek a form of

(e.g. setting some entries of

As (

this form of

will depend only on the additional term

and is independent of the part

\displaystyle\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)
of (

). One can then assume this form of

to solve (

,

), or (

A class of modified Toda equations

The

-Toda equation,

The equation is of the form (

Proposition 3.2

An equation of the form

4
The
n
-dKP Einstein-Weyl equation

Recall that an Einstein-Weyl (EW) structure is a triplet
(\mathcal{W},[h],D)
consisting of a manifold

\mathcal{W},
a conformal class of metrics
[h]
and a torsion-free connection
D
such that
D
is compatible with

[h]
in the sense that, choosing a representative metric
h\in[h],

Dh=\nu\otimes h
for some one-form
\nu,
and
the symmetrised Ricci tensor of
D
is proportional to
h.
Locally, the structure is determined by a system of PDEs for the components of
h
and
\nu.

In many instances, the system of PDEs reduces to a single scalar PDE.   For example , the dispersionless Kadomtsev-Petviashvili (dKP) equation,

u_{xt}-(uu_{x})_{x}-u_{yy}=0,

(4.1)

is well known to determine a
3
-dimensional Lorentzian EW structure admitting a parallel weighted vector field
[
7
]
.

The dKP equation and one of its generalisation, namely the
mn
-dKP equation
[
18
]
,

u_{xt}-(u^{m}u_{x})_{x}-u_{y_{1}y_{1}}-\dots-u_{y_{n}y_{n}}=0,

are of the form (
1.1
). Their quadric ansatz solutions have been studied in
[
9
,
8
]
.

Another generalisation of the dKP equation to
n+2
dimensions is given by

u_{xt}-(uu_{x})_{x}-u_{y_{1}y_{1}}-\dots-u_{y_{n}y_{n}}+\frac{2(n-1)}{n}u_{x}^{2}=0,

(4.2)

where
n\geq 1
is an integer. It is known
[
14
,
5
]
to govern a class of
(n+2)
-dimensional EW structures admitting a parallel null weighted vector field with a further assumption on the holonomy of the Weyl connection.
Equation (
4.2
), which we shall call the
n
-dKP Einstein-Weyl (
n
-dKP EW) equation, is however not of the form (
1.1
). It is of the form (
1.6
),

\displaystyle\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)+T=0,
where

\displaystyle\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)=u_{xt}-(uu_{x})_{x}-u_{y_{1}y_{1}}-\dots-u_{y_{n}y_{n}}
and
\displaystyle T\,=\,\lambda u_{x}^{2},
with
\displaystyle\lambda=\frac{2(n-1)}{n}.

In this section, we apply the method of the quadric ansatz described in Proposition
2.1
to (
4.2
). Our result is similar to that of Section
3.2
. That is, the constraints from (
2.8
) turn out to be too restrictive if one seeks a form of
{\bf M}
that satisfies (
2.8
) without assuming (
2.6
). Nevertheless, using (
2.6
) and the quadric ansatz itself, it is possible to find a nontrivial reduction if
{\bf M}
is assumed to be invertible and of a certain simple form. The result is summarised in Proposition
4.1
below.

Proposition 4.1

Equation
(
4.2
)
,

u_{xt}-(uu_{x})_{x}-u_{y_{1}y_{1}}-\dots-u_{y_{n}y_{n}}+\frac{2(n-1)}{n}u_{x}^{2}=0,

admits solutions given implicitly by the quadric ansatz
(
1.2
)
,
{\bf X}^{T}{\bf M}(u){\bf X}=C,
where
{\bf M}
is invertible and such that
{\bf N}=-{\bf M}^{-1}
is of the form

{\bf N}=\left(\begin{array}[]{c|ccc|c}Y&0&\cdots&0&\;Z\\
\hline\cr 0&&&&\;0\\
\vdots&&{\scalebox{1.2}{${\bf X}$}}&&\;\vdots\\
0&&&&\;0\\
\hline\cr Z&0&\cdots&0&\;0\end{array}\right),

if and only if
\displaystyle{\bf X}(u)=-2Z(u){\bf 1}_{n}
and

Assume
n>1,
the quadric ansatz reduction gives a third order ODE for

given by

\frac{-8(n-1)Z^{2}\dot{Z}\,\dddot{Z}+12\left(n-\frac{2}{3}\right)Z^{2}(\ddot{Z})^{2}+4(n-4)Z(\dot{Z})^{2}\ddot{Z}+(n+2)(n-2)(n-4)(\dot{Z})^{4}}{\big((n+2)(\dot{Z})^{2}-2Z\ddot{Z}\big)^{2}}=0.

(4.3)

Proof.
The
n
-dKP EW equation (
4.2
) can be written in the form
(
1.6

{\bf b}(u)=\left(\begin{array}[]{c|ccc|c}-u&0&\cdots&0&\;\frac{1}{2}\\
\hline\cr 0&&&&\;0\\
\vdots&&{\scalebox{1.2}{$-{\bf 1}_{n}$}}&&\;\vdots\\
0&&&&\;0\\
\hline\cr\frac{1}{2}&0&\cdots&0&\;0\end{array}\right),\quad\mbox{and}\quad T\,=\,\lambda u_{x}^{2}\quad\mbox{with}\quad\lambda=\frac{2(n-1)}{n}.

Recall from
[
8
]
that if
{\bf M}
is invertible, then equation (
2.9
),

implies that

{\bf N}=-{\bf M}^{-1}=\left(\begin{array}[]{c|ccc|c}Y&\beta_{1}&\cdots&\beta_{n}&\;Z\\
\hline\cr\beta_{1}&&&&\;\varepsilon_{1}\\
\vdots&&{\scalebox{1.2}{${\bf X}$}}&&\;\vdots\\
\beta_{n}&&&&\;\varepsilon_{n}\\
\hline\cr Z&\varepsilon_{1}&\cdots&\varepsilon_{n}&\;\phi\end{array}\right),

(4.4)

where

and

are constants,

are functions of

is an

Equation (

(4.5)

The system (

Now consider only a simple case where all constants

and

\hline\cr 0&&&&\;0\\

Equation (

\displaystyle\tau(u)=\frac{\lambda t^{2}}{\dot{Q}Z^{2}},

Further Remarks

5.1
Applicability of the quadric ansatz to certain forms of equations

There is no doubt that the method of quadric ansatz is well applicable to an equation of the ‘standard’ form (
1.1
),

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)=0.

We have demonstrated that the method can also be applied to
an equation of the form (
1.6
),

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)+T(\boldsymbol{x},u,u_{x^{i}})=0,

where our generalised procedure of Proposition
2.1
adds in condition (
2.8
) due to the term
T,
which puts additional constraints on the matrix
{\bf M}
of the ansatz.

Although depending on the term
T,
we find in our examples of Section
3
and
4
that the complicated form of the constraints makes the general analysis of all solutions constant on a central quadric impractical. Nevertheless, the method can be used to find particular classes of solutions.

In this section, we suggest a form of the additional term
T
in (
1.6
) such that (
2.8
)
does not yield any additional constraint on
{\bf M}.
Thus the quadric ansatz method is as effective to use with this type of equations as with an equation of the form (
1.1
). This term
T
is given by

T=m\,b^{ij}(u)\,\frac{\partial u}{\partial x^{i}}\,\frac{\partial u}{\partial x^{j}},

(5.1)

where
m
is a constant. Then, using (
2.1
), it can be shown that
\tau=mg.
Hence
(
2.8
) is satisfied by (
2.6
), and the quadric reduction is given solely by the pair (
2.6
,
2.7
) or (
2.9
,
2.10
), where
system (
2.9
,
2.10
) becomes

g\dot{\bf N}={\bf b},\qquad g^{2}e^{2mu}\det{\bf N}=\zeta.

(5.2)

Example
\boldsymbol{5.1}
With
T
given by (
5.1
), the
SU(\infty)
-Toda equation and the dKP equation are respectively modified to

u_{xx}+u_{yy}+(e^{u})_{zz}+m\,\Big(u_{x}^{2}+u_{y}^{2}+e^{u}u_{z}^{2}\Big)=0,

(5.3)

and

u_{xt}-(uu_{x})_{x}-u_{yy}-m(uu_{x}^{2}-u_{x}u_{t}+u_{y}^{2})=0.

Assuming the matrix

in the quadric ansatz is invertible, all quadric ansatz solutions to the above equations

For example, the solutions to (

in (

the ODE for

]
.

It would be interesting to see if an equation of the form (

) with

(

5.2
The hyperplane ansatz

In addition to the central quadric ansatz (
1.2
),

M_{ij}(u)x^{i}x^{j}=C,
one can of course consider an ansatz of a general quadric form including terms linear in
x^{i},

or a hypersurface ansatz of higher degree polynomials.

Here, we give a summary of the reduction by the hyperplane ansatz of two forms of equations. The first one is the form

b^{ij}(u)\,\frac{\partial^{2}u}{\partial x^{i}\partial x^{j}}=0,

(5.5)

and the second one is the standard form (
1.1
).

Our interest in the form (
5.5
) comes from an observation that two EW equations are of this form.
The first one is (
4.2
) with
n=2,

u_{xt}-uu_{xx}-u_{yy}-u_{zz}=0,

(5.6)

which locally determines an EW structure in four dimensions, where the metric
h
and the one-form
\nu
defining the structure is given by

h=dy_{1}^{2}+dy_{2}^{2}-4dxdt-4udt^{2},\qquad\nu=-2u_{x}dt.

The other equation of the form (
5.5
) is

u_{xx}+u_{yy}+e^{u}u_{zz}=0,

which can be shown by direct calculation to be the EW equation for the pair
(h,\nu)
given by

h=e^{u}(dx^{2}+dy^{2})+dz^{2}+dw^{2},\qquad\nu=u_{z}dz,

where
u(x,y,z)
is independent of one coordinate
w.

The hyperplane ansatz is given by

V_{i}(u)x^{i}=C,

(5.7)

where
{\bf V}=(V_{i}(u))
is a column vector whose components are functions of
u,

C
is a constant and the summation convention is used as before. The ansatz reduction can be obtained in a similar fashion to the quadric ansatz reduction. Let us describe this for equation (
5.5
).

Assuming the existence of a solution
u(\boldsymbol{x})
to (
5.5
) given implicitly by (
5.7
), implicit differentiation gives

\frac{\partial u}{\partial x^{k}}=-\frac{1}{\dot{Q}}V_{k},

(5.8)

where here
Q(\boldsymbol{x},u):=V_{i}(u)x^{i}
and

\displaystyle\dot{Q}:=\frac{\partial Q}{\partial u}=\dot{V}_{i}\,x^{i}.
Then
substituting (
5.8
) into (
5.5
) yields

\left(2({\bf\dot{V}}^{T}{\bf bV}){\bf\dot{V}}^{T}-({\bf V}^{T}{\bf bV}){\bf\ddot{V}}^{T}\right){\bf X}=0,

(5.9)

where
\displaystyle\dot{\bf V}:=\frac{d{\bf V}}{du},
and
{\bf X}
is the column vector whose transpose is the row vector
{{\bf X}^{T}=(x^{1}\,\dots\,x^{N})}
as before.

Similar to the method of quadric ansatz, one can regard the vanishing of the vector in the bracket of (
5.9
) as the reduced equation by the hyperplane ansatz. This gives a system of ODEs for the components
V_{i},
given by

\frac{d}{du}(\ln\dot{V}_{i})=2\frac{{\bf\dot{V}}^{T}{\bf bV}}{{\bf V}^{T}{\bf bV}},\quad\mbox{for all}\quad i=1,\dots,N.

(5.10)

Since every component
V_{i}
satisfies the same equation (
5.10
), denoting
V:=V_{1},
it follows that

V_{i}=m_{i}V+n_{i},\quad\mbox{for all}\quad i=2,\dots,N,

where
m_{i}
and
n_{i},

i=2,\dots,N,
are arbitrary constants. We now state the ODE for
V
in the following proposition.

Proposition 5.1

Given a PDE of the form
(
5.5
)
,

b^{ij}(u)\,\frac{\partial^{2}u}{\partial x^{i}\partial x^{j}}=0,\quad i,j=1,\dots,N,

a function
u(\boldsymbol{x})
defined implicitly by
(
5.7
)
,
V_{i}(u)x^{i}=C,
is a solution of
(
5.5
)
if the functions
V_{i}
for
i=2,\dots,N
are given by

V_{i}=m_{i}V+n_{i},
where
\displaystyle V:=V_{1},

m_{i}
and
n_{i}
are arbitrary constants, and
V(u)
satisfies the second order ODE

\ddot{V}=2\,\frac{FV+G}{FV^{2}+2GV+H}\,\dot{V}^{2},

with

F=b^{ij}m_{i}m_{j},\quad G=b^{ij}m_{i}n_{j},\quad H=b^{ij}n_{i}n_{j},

m_{1}=1
and
n_{1}=0.
The solution
u(\boldsymbol{x})
is thus given by a function of one variable
\displaystyle w:=\frac{C-n_{i}x^{i}}{m_{j}x^{j}}.

For an equation of the form (
1.1
),

\frac{\partial}{\partial x^{i}}\left(\,b^{ij}(u)\,\frac{\partial u}{\partial x^{j}}\,\right)=0,

the reduction follows similarly, with (
5.9
) replaced by

\left(\frac{d}{dt}({\bf V}^{T}{\bf bV})\,{\bf\dot{V}}^{T}-({\bf V}^{T}{\bf bV}){\bf\ddot{V}}^{T}\right){\bf X}=0.

The reduced ODE turns out to be the generalised Riccati equation (
5.11
).
