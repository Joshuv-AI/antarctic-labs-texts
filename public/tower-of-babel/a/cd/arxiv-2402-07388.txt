The Limits of Assumption-free Tests for Algorithm Performance
Yuetian Luo, Rina Foygel Barber

Abstract
Algorithm evaluation and comparison are fundamental questions in machine learning and statistics—how well does an algorithm perform at a given modeling task, and which algorithm performs best? Many methods have been developed to assess algorithm performance, often based around cross-validation type strategies, retraining the algorithm of interest on different subsets of the data and assessing its performance on the held-out data points. Despite the broad use of such procedures, the theoretical properties of these methods are not yet fully understood. In this work, we explore some fundamental limits for answering these questions with limited amounts of data. In particular, we make a distinction between two questions: how good is an algorithm 𝒜 \mathcal{A} at the problem of learning from a training set of size n n , versus, how good is a particular fitted model produced by running 𝒜 \mathcal{A} on a particular training data set of size n n ? Our main results prove that, for any test that treats the algorithm 𝒜 \mathcal{A} as a “black box” (i.e., we can only study the behavior of 𝒜 \mathcal{A} empirically), there is a fundamental limit on our ability to carry out inference on the performance of 𝒜 \mathcal{A} , unless the number of available data points N N is many times larger than the evaluation sample size n n of interest. (On the other hand, evaluating the performance of a particular fitted model is easy as long as a holdout data set is available—that is, as long as N − n N-n is not too small.) We also ask whether an assumption of algorithmic stability might be sufficient to circumvent this hardness result. Surprisingly, we find that the same hardness result still holds for the problem of evaluating the performance of 𝒜 \mathcal{A} , aside from a high-stability regime where fitted models are essentially nonrandom. Finally, we also establish similar hardness results for the problem of comparing multiple algorithms.

Introduction

Evaluating the performance of a regression algorithm, and comparing the performance of different algorithms, are fundamental questions in machine learning and statistics
(
Salzberg, 1997
;
Dietterich, 1998
;
Bouckaert, 2003
;
Demsar, 2006
;
Garcia and Herrera, 2008
;
Hastie et al., 2009
;
Raschka, 2018
)
.
When performing a data analysis, if the properties of the underlying data distribution are unknown, how can we determine which algorithms would model the data well?
For instance, for the task of predicting a real-valued response
Y
, which algorithm would have the smallest possible error?

Algorithm evaluation.

In general, given access to a limited amount of data drawn from an unknown distribution
P
on
\mathcal{X}\times\mathcal{Y}
,
and given a particular algorithm
\mathcal{A}
(chosen by the analyst), we would like to ask:

EvaluateAlg
: how well does algorithm
\mathcal{A}
perform on data drawn from
P
?

Writing
{\widehat{f}}
to denote the fitted model produced by running algorithm
\mathcal{A}
on a training data set,
a related question is to ask about the performance of the trained model
{\widehat{f}}
:

EvaluateModel
: how well does the fitted model
{\widehat{f}}
perform on data drawn from
P
?

Are these simply two different phrasings of the same question—or should we make a distinction between the two?

In practice, these two questions are often treated as interchangeable: for instance, a paper might
state that “Logistic regression performs well on this problem” (which suggests that the question
EvaluateAlg
is being
addressed), but then justify the statement by using a holdout set to evaluate the fitted model
{\widehat{f}}
produced by running logistic regression on a particular data set
(which is actually addressing the question
EvaluateModel
).
In this work, we argue that
these two questions are not equivalent
, and indeed,
answering
EvaluateAlg
may be impossible even in settings where
EvaluateModel
is trivial to answer.

Algorithm comparison.

In practice, rather than asking about the risk of a single algorithm, we might instead
be interested in comparing multiple algorithms to see which is best—for instance,
which algorithm (from a set of candidates) minimizes a certain measure of risk. To address this
setting, in this paper we will also consider questions of algorithm comparison.
As for the problem of evaluation, we might pose a question about the algorithms themselves:

CompareAlg
: which algorithm,
\mathcal{A}_{0}
or
\mathcal{A}_{1}
, performs better on data drawn from
P
?

Or, we might ask about the trained models returned by these algorithms—if
{\widehat{f}}_{0}
and
{\widehat{f}}_{1}
are the fitted models produced
by algorithms
\mathcal{A}_{0}
and
\mathcal{A}_{1}
, respectively, we ask:

CompareModel
: which fitted model,
{\widehat{f}}_{0}
or
{\widehat{f}}_{1}
, performs better on data drawn from
P
?

Again, while these two questions are sometimes treated as interchangeable, they are distinct in a meaningful way.
Indeed, which question is the “right” one to ask will necessarily depend on the goal of the analysis. For example,
a data analyst who seeks to build an accurate model, in order to then deploy this model for future predictions or some other task,
may be more interested in determining whether
{\widehat{f}}_{0}
or
{\widehat{f}}_{1}
will be more accurate for this task.
On the other hand, a researcher developing methodology in statistics or machine learning
who proposes a new algorithm will instead be more interested in comparing
\mathcal{A}_{0}
(their algorithm) against
\mathcal{A}_{1}
(an existing algorithm).
If the researcher creates a demo on a real data set to compare their method to existing work,
implicitly they are claiming that their method
\mathcal{A}_{0}
will perform better than the existing method
\mathcal{A}_{1}

on other data sets as well—they are not interested only in the particular fitted models produced in one specific experiment.
For a deeper discussion on the subtle distinctions between various questions we may ask when comparing (or evaluating)
algorithms, we refer the reader to
Dietterich, 1998
.

1.1
Problem formulation: evaluating an algorithm

In this section, we will formalize our questions for algorithm evaluation (we will return to the problem of algorithm comparison later on).

To formalize the two questions
EvaluateAlg
and
EvaluateModel
defined above, and understand the distinction between the two, we now introduce some notation.
Let
\ell
be a loss function, with
\ell(f(x),y)\geq 0
measuring the loss incurred by regression
function
f
on data point
(x,y)
.
Formally, we can write
\ell:\widehat{\mathcal{Y}}\times\mathcal{Y}\rightarrow\mathbb{R}_{+}
, where we are evaluating models
f:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}
.
For example:

•

When predicting a real-valued response, we might use squared loss or absolute-value loss,

\ell(f(x),y)=(y-f(x))^{2}\textnormal{ \ or \ }\ell(f(x),y)=|y-f(x)|,

with
\mathcal{Y}=\widehat{\mathcal{Y}}=\mathbb{R}
.

•

If instead
\mathcal{Y}=\{0,1\}
(a binary response), if
f(x)\in\widehat{\mathcal{Y}}=\{0,1\}
predicts the binary label then we might use the zero–one loss,

\ell(f(x),y)={\mathds{1}}_{f(x)\neq y}.

If instead we have
f(x)\in\widehat{\mathcal{Y}}=[0,1]
, predicting the probability of a positive label (i.e.,
f(x)
estimates
\mathbb{P}(Y=1\mid X=x)
), we might use
a hinge loss or logistic loss.

Given a particular choice of the loss function
\ell
, we define the risk of a model
f
as

R_{P}(f)=\mathbb{E}_{P}[\ell(f(X),Y)],

which is computed with respect to a test point sampled as
(X,Y)\sim P
.
Now consider a regression algorithm
\mathcal{A}
, which inputs a data set
\{(X_{i},Y_{i})\}_{i\in[n]}
and returns a fitted model
{\widehat{f}}_{n}
.
The fitted model
{\widehat{f}}_{n}
has risk
R_{P}({\widehat{f}}_{n})
—this captures the expected loss for the future performance of
{\widehat{f}}_{n}
, on test
data drawn from
P
.
Note we can write

R_{P}({\widehat{f}}_{n})=\mathbb{E}_{P}\left[\ell({\widehat{f}}_{n}(X),Y)\mid{\widehat{f}}_{n}\right],

the expected loss of the trained model when we average over the draw of a new
test point
(X,Y)\sim P
, but condition on the fitted model
{\widehat{f}}_{n}
(or equivalently, on
the draw of the training data,
\{(X_{i},Y_{i})\}_{i\in[n]}
).
This risk is random: it depends on the fitted model
{\widehat{f}}_{n}
, which will vary depending on the random draw of the training data.
In contrast, we could also measure the performance of
\mathcal{A}
by asking about its expected risk, over a random draw of the training data as well as the test point:

R_{P,n}(\mathcal{A})=\mathbb{E}_{P}\left[\ell({\widehat{f}}_{n}(X),Y)\right],

where now the expected value is taken with respect to a random draw
(X_{1},Y_{1}),\dots,(X_{n},Y_{n}),(X,Y)\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P
—that is, with respect to a random draw
of both the training and test data.
In particular, the model risk
R_{P}({\widehat{f}}_{n})
and algorithm risk
R_{P,n}(\mathcal{A})
are related as

R_{P,n}(\mathcal{A})=\mathbb{E}_{P}\left[R_{P}({\widehat{f}}_{n})\right].

With this notation in place, we can now make our questions,
EvaluateAlg
and
EvaluateModel
, more precise.

EvaluateAlg
: what is
R_{P,n}(\mathcal{A})
?  versus
EvaluateModel
: what is
R_{P}({\widehat{f}}_{n})
?

These two questions are different: a low value of
R_{P,n}(\mathcal{A})

tells us that
\mathcal{A}
tends to perform well for distribution
P
, while a low value of
R_{P}({\widehat{f}}_{n})
tells us that
this particular fitted model

produced by
\mathcal{A}
performs well. In particular, the latter statement could result from the fact that either
\mathcal{A}
is good or the particular data set at hand favors
\mathcal{A}
. Which question is the “right” question to ask, will depend on the context,
and we do not claim that one of these questions is more important than the other; instead, the aim of our paper is to understand
the distinction between these two questions, and to emphasize that the two questions should not be treated interchangeably.

Defining a hypothesis test.

There are many possible goals we might define for addressing
EvaluateAlg
or
EvaluateModel
:
for example, we might wish to construct a confidence interval for the risk
R_{P,n}(\mathcal{A})
or
R_{P}({\widehat{f}}_{n})
,
or to perform a hypothesis test assessing whether
R_{P,n}(\mathcal{A})
or
R_{P}({\widehat{f}}_{n})
lies above or below some prespecified threshold
\tau
,

\texttt{EvaluateAlg}:H_{0}:\,R_{P,n}(\mathcal{A})\geq\tau\textnormal{ \ versus \ }H_{1}:\,R_{P,n}(\mathcal{A})<\tau,

(1)

\texttt{EvaluateModel}:H_{0}:\,R_{P}({\widehat{f}}_{n})\geq\tau\textnormal{ \ versus \ }H_{1}:\,R_{P}({\widehat{f}}_{n})<\tau.

(2)

Indeed, it is not hard to see that
EvaluateModel
is an easy problem as long as we have a large holdout data. This is because after training model
{\widehat{f}}_{n}
, we can use the holdout data
\mathcal{D}_{\textnormal{hold}}
to estimate
R_{P}({\widehat{f}}_{n})
via computing
\frac{1}{|\mathcal{D}_{\textnormal{hold}}|}\sum_{(X_{i},Y_{i})\in\mathcal{D}_{\textnormal{hold}}}\ell({\widehat{f}}_{n}(X_{i}),Y_{i})
; if
|\mathcal{D}_{\textnormal{hold}}|
is large then this estimate is likely to be accuracy. While
EvaluateAlg
will be a harder problem, which is the problem of focus for the rest of the paper. To establish such a hardness result, it suffices to consider the problem of performing
the hypothesis test (
1
). This is because, if we have instead constructed a confidence interval
\widehat{C}

with a guarantee of containing the risk
R_{P,n}(\mathcal{A})
with probability
\geq 1-\alpha
, we can test (
1
)
at Type I error level
\alpha
by simply checking whether
\widehat{C}\subseteq[0,\tau)
.

Background

In this section, we formalize some definitions and give additional background for studying the properties of algorithms.
Formally, for data lying in some space
\mathcal{X}\times\mathcal{Y}
, we define an algorithm
\mathcal{A}
as a map

\mathcal{A}:\ \cup_{n\geq 0}(\mathcal{X}\times\mathcal{Y})^{n}\rightarrow\big\{\textnormal{measurable functions $\mathcal{X}\rightarrow\widehat{\mathcal{Y}}$}\big\}.

That is,
\mathcal{A}
takes as input
\{(X_{i},Y_{i})\}_{i\in[n]}
, a data set of any size, and returns a fitted model
{\widehat{f}}_{n}:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}
,
which maps a feature value
x
to a fitted value, or prediction,
{\widehat{y}}={\widehat{f}}_{n}(x)
.
For instance, for a real-valued response
Y\in\mathcal{Y}=\mathbb{R}
, we might take
\mathcal{A}
to be the least squares regression algorithm,
leading to linear fitted models
{\widehat{f}}_{n}
.
In many settings, commonly used algorithms
\mathcal{A}
will include some form of randomization—for instance, stochastic gradient
descent type methods. To accommodate this setting, we will expand the definition of an algorithm to take an additional argument,

\mathcal{A}:\ \cup_{n\geq 0}(\mathcal{X}\times\mathcal{Y})^{n}\times[0,1]\rightarrow\big\{\textnormal{measurable functions $\mathcal{X}\rightarrow\widehat{\mathcal{Y}}$}\big\}.

(3)

The fitted model
{\widehat{f}}_{n}=\mathcal{A}\big(\{(X_{i},Y_{i})\}_{i\in[n]};\xi\big)
is now obtained by running algorithm
\mathcal{A}

on data set
\{(X_{i},Y_{i})\}_{i\in[n]}
, with randomization provided by the argument
\xi\in[0,1]
,
which acts as a random seed.
1
1

1

Throughout this paper, we implicitly assume measurability for all
functions we define, as appropriate. In the case of the algorithm
\mathcal{A}
, this takes the following form:
we assume the measurability of the map

\left((x_{1},y_{1}),\ldots,(x_{n},y_{n}),\xi,x\right)\mapsto[\mathcal{A}(\{(x_{i},y_{i})\}_{i\in[n]};\xi)](x)
.
Of course, the general definition (
3
)
of a randomized algorithm also accommodates the deterministic (i.e., non-random) setting—we can simply choose an algorithm
\mathcal{A}

whose output depends only on the data set
\{(X_{i},Y_{i})\}_{i\in[n]}
, and ignores the second argument
\xi
.

With this notation in place, we are now ready to consider the question
EvaluateAlg
. To formalize the definition of risk
R_{P,n}(\mathcal{A})
introduced in Section
1

in a way that accommodates the case of randomized algorithms as in (
3
), we will define the risk
R_{P,n}(\mathcal{A})
as follows:

R_{P,n}(\mathcal{A})=\mathbb{E}\left[\ell\left({\widehat{f}}_{n}(X_{n+1}),Y_{n+1}\right)\right]\textnormal{ for }{\widehat{f}}_{n}=\mathcal{A}\big(\{(X_{i},Y_{i})\}_{i\in[n]};\xi\big),

(4)

where the expected value is taken with respect to the distribution of data points
(X_{i},Y_{i})\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P
for
i=1,\ldots,n+1

and an independent random seed
\xi\sim\textnormal{Unif}[0,1]
.

2.1
Black-box tests

To understand the difficulty of the question
EvaluateAlg
, we need to
formalize the limitations on what information is available to us, as the analyst, for performing inference on an algorithm’s risk.
For example, if we know the distribution
P
of the data, and know that our algorithm
\mathcal{A}
is given by
k
-nearest-neighbors (kNN) regression,
then we can derive a closed-form expression for the risk
R_{P,n}(\mathcal{A})
theoretically.
Clearly, this is not the setting of interest, since in practice we cannot rely on assumptions about the data
distribution—but in fact, even if
P
is unknown, estimating
R_{P,n}(\mathcal{A})
for a simple algorithm such as kNN
is relatively straightforward. In modern settings, however, a state-of-the-art algorithm
\mathcal{A}
is typically far more complex,
and may be too complicated to analyze theoretically. For this reason, in this work we consider
black-box
procedures
(
Myers et al., 2011
)
,
which analyze the algorithm
\mathcal{A}
via empirical evaluations, rather than theoretical calculations.
The intuition is this: if
\mathcal{A}
is implemented as a function in some software package, our procedure
is allowed
to call the function (perhaps as many times as we like, or perhaps with a computational budget), but is not able
to examine the implementation of
\mathcal{A}
(i.e., we cannot read the code that defines the function).

We formalize this black-box setting in the following definition, which is based on a similar construction given in
Kim and Barber, 2023
.

Definition 1

(Black-box test for algorithm evaluation)
.

Let
\mathfrak{D}=\cup_{m\geq 0}(\mathcal{X}\times\mathcal{Y})^{m}
denotes the space of data sets of any size. Consider any function
{\widehat{T}}
that takes as input an algorithm
\mathcal{A}
and a dataset
\mathcal{D}\in\mathfrak{D}
,
and returns a (possibly randomized) output
{\widehat{T}}(\mathcal{A},\mathcal{D})\in\{0,1\}
.
We say that
{\widehat{T}}
is a black-box test if it can be defined as follows:
2
2

2

For this definition, we assume measurability of
the map
(\mathcal{D},\zeta^{(1)},\zeta^{(2)},\dots,\zeta)\mapsto{\widehat{T}}(\mathcal{A},\mathcal{D})
, which inputs the initial data set
\mathcal{D}
and the
random seeds used throughout the construction of the test, and returns the output of the test
{\widehat{T}}(\mathcal{A},\mathcal{D})\in\{0,1\}
.

for some functions
g^{(1)},g^{(2)},\dots,g
, and for random seeds,
\zeta^{(1)},\zeta^{(2)},\dots,\zeta\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}\textnormal{Unif}[0,1]
,

1.

At stage
r=1
, generate a new dataset and a new random seed,

(\mathcal{D}^{(1)},\xi^{(1)})=g^{(1)}(\mathcal{D},\zeta^{(1)}),

and compute the fitted model
{\widehat{f}}^{(1)}=\mathcal{A}(\mathcal{D}^{(1)};\xi^{(1)})
.

2.

For each stage
r=2,3,\ldots
, generate a new dataset and a new random seed,

(\mathcal{D}^{(r)},\xi^{(r)})=g^{(r)}\big(\mathcal{D},(\mathcal{D}^{(s)})_{1\leq s<r},({\widehat{f}}^{(s)})_{1\leq s<r},(\zeta^{(s)})_{1\leq s\leq r},(\xi^{(s)})_{1\leq s<r}\big),

and compute the fitted model

{\widehat{f}}^{(r)}=\mathcal{A}(\mathcal{D}^{(r)};\xi^{(r)})
.

3.

Repeat until some stopping criterion is reached; let
{\widehat{r}}
denote the (data-dependent) total number of rounds.

4.

Finally, return

{\widehat{T}}(\mathcal{A},\mathcal{D})=g\big(\mathcal{D},(\mathcal{D}^{(r)})_{1\leq r\leq{\widehat{r}}},({\widehat{f}}^{(r)})_{1\leq r\leq{\widehat{r}}},(\zeta^{(r)})_{1\leq r\leq{\widehat{r}}},(\xi^{(r)})_{1\leq r\leq{\widehat{r}}},\zeta\big).

In this definition, at each stage
r
we are allowed to deploy the training algorithm
\mathcal{A}
on a data set
\mathcal{D}^{(r)}

that we have designed adaptively—e.g., by subsampling from the original data set
\mathcal{D}
, or by generating simulated data given the past information.
The random seeds
\zeta^{(1)},\zeta^{(2)},\ldots,\zeta
allow for randomization at each step of the procedure, if desired—for instance,
to allow for randomly subsampling from the original data set
\mathcal{D}
. (Of course,
we might choose to run a deterministic procedure, as a special case.)

An example of a black-box test.

As an example of the type of test that would satisfy Definition
1
, we can consider a cross-validation (CV) based estimate of risk. Assuming we have
N
data points
\{(X_{i},Y_{i})\}_{i\in[N]}
,
K
divides
N
and
n=N(1-1/K)
for some integer
K\geq 1
,
we can construct an estimator as follows:

•

Construct a partition
[N]=S_{1}\cup\dots\cup S_{K}
with
|S_{k}|=N/K
for each
k
.

•

For each
k=1,\dots,K
, define

{\widehat{f}}^{(k)}=\mathcal{A}(\mathcal{D}_{\backslash S_{k}};\xi_{k})

where
\mathcal{D}_{\backslash S_{k}}=\{(X_{i},Y_{i})\}_{i\in[N]\backslash S_{k}}
is a data set of size
n
,
and where
\xi_{k}\sim\textnormal{Unif}[0,1]
. Then estimate
the risk of each fitted model,

\widehat{R}({\widehat{f}}^{(k)})=\frac{1}{|S_{k}|}\sum_{i\in S_{k}}\ell({\widehat{f}}^{(k)}(X_{i}),Y_{i}).

•

Finally, average over all fitted models to define the CV estimate of risk:

\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})=\frac{1}{K}\sum_{k=1}^{K}\widehat{R}({\widehat{f}}^{(k)}),

(5)

and return a 1 or a 0 depending on whether
\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})<\tau
or
\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})\geq\tau
.

An example that is not black-box.

Tests that require
infinitely many executions of a black-box algorithm are not admissible under Definition
1
. For example, if
\mathcal{X}=\mathbb{R}^{d}
, then given a data set
\mathcal{D}_{N}
and an additional
test point
(x,y)
, we would not be able
to answer the question, “what is the maximum loss that could be incurred by adding a single data point to the data set”—that is,
a black-box test would be unable to calculate

\sup_{(x^{\prime},y^{\prime})\in\mathcal{X}\times\mathcal{Y}}\ell({\widehat{f}}_{(x^{\prime},y^{\prime})}(x),y)\textnormal{ where }{\widehat{f}}_{(x^{\prime},y^{\prime})}=\mathcal{A}\big(\mathcal{D}_{N}\cup\{(x^{\prime},y^{\prime})\};\xi\big).

This is because
evaluating the supremum requires training the model
{\widehat{f}}_{(x^{\prime},y^{\prime})}
for each
(x^{\prime},y^{\prime})\in\mathcal{X}\times\mathcal{Y}
, which cannot be accomplished
with any finite collection of calls to
\mathcal{A}
.
(On the other hand, computing the maximum loss over any test point,

\sup_{(x,y)\in\mathcal{X}\times\mathcal{Y}}\ell({\widehat{f}}(x),y)\textnormal{ where }{\widehat{f}}=\mathcal{A}\big(\mathcal{D}_{N}\big),

is possible, since this can be done with only a single call to
\mathcal{A}
; even though this supremum implicitly requires
infinitely many evaluations of
{\widehat{f}}
, this is permitted since the functions
g^{(1)},g^{(2)},\dots,g
in
Definition
1
are allowed to depend arbitrarily on the fitted models
{\widehat{f}}^{(1)},{\widehat{f}}^{(2)},\dots
. We make this distinction because, in practice, it is often the case that
\mathcal{A}
is complex but a
typical fitted model
{\widehat{f}}

is simple—e.g., a sophisticated variable selection procedure that results in a linear regression model.)

2.2
Additional related literature

Many statistical tests and heuristic methods have been proposed for algorithm evaluation and comparison. Given a large dataset,
using a holdout set, also known as sample splitting, is often recommended to evaluate or compare algorithms in practice
(
Hinton et al., 1995
;
Neal, 1998
)
(note that using a holdout set to evaluate a fitted model
{\widehat{f}}_{n}
is directly
addressing the question
EvaluateModel
, rather than
EvaluateAlg
).
With a limited sample size, resampling methods are more popular, including methods
such as cross-validation, and its variants such as
5\times 2
-fold cross-validation (CV)
(
Dietterich, 1998
)
, (corrected) repeated train-validation
(
Nadeau and Bengio, 2003
)
, and nested cross-validation
(
Varma and Simon, 2006
;
Raschka, 2018
)
.
As discussed earlier, many works in the literature have emphasized the qualitative difference between
EvaluateAlg
and
EvaluateModel
(e.g.,
Dietterich, 1998
;
Hastie et al., 2009
). Which of these questions is more useful to answer, may depend on the particular
application; for example,
Trippe et al., 2023
argued that
EvaluateModel
may be a more meaningful question in certain settings.
However, in settings where
EvaluateAlg
is the question of interest, how to perform inference on this target is less well understood.

Nadeau and Bengio, 2003
identified that ignoring the variability due to the randomness of the training set can severely undermine the validity of inference in
EvaluateAlg
. Classical results on CV have suggested that CV can consistently determine which of two algorithms
is better, but these results are generally asymptotic and require some restrictive conditions on the data distribution
(
Shao, 1993
;
Yang, 2007
)
. See also
Hastie et al., 2009
;
Arlot and Celisse, 2010
for surveys on model selection via CV. Based on the asymptotic normality of CV error, the recent work
Bayle et al., 2020
discussed how to compare the prediction error of averaged models of two algorithms (in the same spirit as
EvaluateModel
) in the CV procedure. Similar results have been also extended to compare the algorithm’s risk
(
Austern and Zhou, 2020
;
Li, 2023
)
. Understanding the estimand of CV and effectiveness of CV in evaluating a fitted model are also active areas of research
(
Bates et al., 2023
;
Iyengar et al., 2025
)
.
There are also many other methods available for estimating the prediction error of an algorithm other than CV; see, e.g.,
Rosset and Tibshirani, 2019
and references therein
for work in a nonparametric regression setting.

Our work also contributes to an important line of work on impossibility or hardness results in the statistics, especially in the distribution-free inference setting
(
Bahadur and Savage, 1956
;
Barber et al., 2021a
;
Shah and Peters, 2020
;
Barber, 2020
;
Medarametla and Candès, 2021
;
Kim et al., 2022
)
. The closest work to ours is
Kim and Barber, 2023
,
which establishes a hardness result for the problem of constructing an assumption-free test of algorithmic stability.

Finally, the literature on algorithmic stability is also very relevant to this work—we will give background
on this area of the literature in Section
4.1
, below.

3
Theoretical results for algorithm evaluation

In this section, we present our first main result, establishing the hardness of answering the question
EvaluateAlg
—or more concretely,
of performing the hypothesis test (
1
)—via a black-box procedure.
With the aim of avoiding placing any assumptions on the algorithm
\mathcal{A}
and on the distribution
P
,
we would like to provide an answer to
EvaluateAlg
that is uniformly valid over
all
possible
\mathcal{A}
and
P
.
Specifically, fixing a error tolerance level
\alpha
, an evaluation sample size
n
, an available dataset
\mathcal{D}_{N}=\{(X_{i},Y_{i})\}_{i\in[N]}\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P
of size
N
, and a risk
threshold
\tau>0
for our hypothesis test, we will consider tests
{\widehat{T}}={\widehat{T}}(\mathcal{A},\mathcal{D}_{N})

that satisfy

\mathbb{P}_{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\alpha\textnormal{ for any $\mathcal{A},P$ such that $R_{P,n}(\mathcal{A})\geq\tau$},

(6)

where the probability is taken with respect to the data set
\mathcal{D}_{N}
(as well as any randomization in the test
{\widehat{T}}
).
From this point on, we treat the allowed error level
\alpha\in(0,1)
, the risk threshold
\tau>0
, and sample sizes
n,N\geq 1
as fixed;
our results will give finite-sample (non-asymptotic) limits on power for this testing problem. We will see that power for any valid black-box
test for solving (
1
) is limited unless the available sample size
N
is much larger than
n
.

3.1
Limits of black-box tests for unbounded loss

First, we consider the setting of an unbounded loss function:

\sup_{{\widehat{y}}\in\widehat{\mathcal{Y}},y\in\mathcal{Y}}\ell({\widehat{y}},y)=\infty.

We will see that in this case, no black-box test can have better-than-random power for inference on the risk of
any
algorithm
\mathcal{A}
.

Theorem 1
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the loss
\ell
is unbounded, i.e.,
\sup_{{\widehat{y}},y}\ell({\widehat{y}},y)=\infty
.
Let
{\widehat{T}}
be a black-box test (as in Definition
1
),
and assume that
{\widehat{T}}
satisfies the assumption-free validity condition (
6
).
Then the power of
{\widehat{T}}
to detect low risk is bounded as follows:
for any
\mathcal{A}
and any
P
with
R_{P,n}(\mathcal{A})<\tau
,

\mathbb{P}_{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\alpha.

In other words, any black-box test is completely powerless for
any
algorithm
\mathcal{A}
and distribution
P
—the probability
of certifying low risk for
(\mathcal{A},P,n)
is no better than random.
From this point on, then, in this paper we will consider the case of a bounded loss.

Remark 1

(The infinite cardinality assumption)
.

In this theorem (and in all our results below), we assume that either
|\mathcal{X}|=\infty

or
|\mathcal{Y}|=\infty
, i.e., the data points lie in a space
\mathcal{X}\times\mathcal{Y}
that has infinite cardinality.
The reason for this assumption is that, for finite
\mathcal{X}\times\mathcal{Y}
, since the definition of a black-box test does not place any computational
constraints on the number of calls to
\mathcal{A}
, we can perform an exhaustive search
to fully characterize the behavior of
\mathcal{A}
.
Therefore, the problem of testing the risk of
\mathcal{A}

with no computational constraints
is meaningful only for an infinite-cardinality
space. On the other hand, in practice computational limits are a natural component of any testing problem, and therefore
inference on risk for a large but finite space
\mathcal{X}
likely will have power limited by some function of the computational budget.
We leave this more complex question for future work. (See also Appendix
A.1
for further discussion.)

3.2
Limits of black-box tests for bounded loss

In this section, we
establish limits on power for any universally valid black-box test on the testing problem (
1
), in a bounded loss setting.

We first define some additional notation. For a distribution
P
on
\mathcal{X}\times\mathcal{Y}
, let

R_{P}^{\max}=\sup_{f}R_{P}(f),

the largest possible risk of any function
f
for data drawn from
P
.
We are primarily interested in testing the hypothesis (
1
) for a threshold
\tau\leq R_{P}^{\max}

(because if we were instead considering
\tau>R_{P}^{\max}
, this would be a fundamentally simpler setting—
any
algorithm
will have risk
<\tau
over distribution
P
, so the hypothesis test would depend only on
P
, not on the algorithm
\mathcal{A}
).

We are now ready to state the theorem.

Theorem 2
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the loss
\ell
takes values in
[0,B]
.
Let
{\widehat{T}}
be a black-box test (as in Definition
1
),
and assume that
{\widehat{T}}
satisfies the assumption-free validity condition (
6
).
Let
\tilde{\tau}=\tau(1+\frac{\alpha^{-1}-1}{N})
.

Then the power of
{\widehat{T}}
to detect low risk is bounded as follows:
for any
\mathcal{A}
and any
P
with
R_{P,n}(\mathcal{A})<\tau
,

\mathbb{P}_{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\left[\alpha\left(1+\frac{\tilde{\tau}-R_{P,n}(\mathcal{A})}{R_{P}^{\max}-\tilde{\tau}}\right)^{N/n}\right]\wedge 1,

if we assume
\tilde{\tau}<R_{P}^{\max}
so that the denominator is positive.

In particular, as expected, if the risk
R_{P,n}(\mathcal{A})
is only slightly lower than
\tau
, then the power is
only slightly higher than
\alpha
(i.e., no better than random). But, even if the risk is low (e.g.,
R_{P,n}(\mathcal{A})=0
at the extreme),
if the available data is limited (e.g.,
N
is close to the evaluation sample size
n
),
then we see that the power can only be a constant multiple of
\alpha
. If the allowed error level
\alpha
is small,
we therefore cannot have a powerful test for
any
alternative. On the other hand, under the same setting as in Theorem
2
(that is, the black-box testing setting), we should clarify that
EvaluateModel
is relatively easy, as a test leveraging the holdout data can solve the problem. For instance if
N=n+m
, then we have a holdout set of
m
many data points with
which we can estimate
R_{P}({\widehat{f}}_{n})
up to error
\mathcal{O}_{P}(\frac{1}{\sqrt{m}})
—and therefore, testing whether
R_{P}({\widehat{f}}_{n})<\tau
is straightforward in the black-box setting.

Conversely, given a data set size
N
, if we wish to have high power for identifying whether an algorithm
\mathcal{A}
has low risk
R_{P,n}(\mathcal{A})
,
we need to choose a small sample size,
n\ll N
—but
for small
n
, the algorithm
\mathcal{A}
will likely return fitted models that are less accurate, i.e.,
the risk
R_{P,n}(\mathcal{A})
itself will likely be higher. (This type of tradeoff has been described by

Rinaldo et al., 2019
as the
inference–prediction tradeoff
, in a related setting.)

Remark 2

(Validity for randomized versus deterministic algorithms)
.

The results of Theorem
2
bound the power of any black-box test
{\widehat{T}}

when applied to any algorithm
\mathcal{A}
, including algorithms that may be randomized (i.e.,
\mathcal{A}(\mathcal{D};\xi)
has nontrivial
dependence on the random seed
\xi
). This is a stronger conclusion than if we only bounded power
for deterministic algorithms, but the assumption is stronger as well: the validity condition (
6
)
requires
{\widehat{T}}
to have a bounded error rate over all
\mathcal{A}
(including algorithms that are randomized).
We remark that the deterministic version of the result also holds: that is,
if we require validity (
6
) only with respect to deterministic
\mathcal{A}
(algorithms for which
\mathcal{A}(\mathcal{D};\xi)

does not have any dependence on
\xi
), then the bound on power given in Theorem
2

also holds for all deterministic
\mathcal{A}
(in fact, the same construction in the proof can be used for both versions of the result).

3.3
A matching bound

We will now show that the upper bound on the power given in Theorem
2
can be approximately
achieved, in certain settings, with a simple test that is based on splitting the data into independent batches.
For this result, we will consider the case that the loss
\ell
takes values in
\{0,1\}
.
For example, in the case of a categorical response
Y
(such as a binary label),
we might use the zero–one loss,

\ell({\widehat{y}},y)={\mathds{1}}_{{\widehat{y}}\neq y},

while if the response
Y
is real-valued, we might instead
use a thresholded loss,

\ell({\widehat{y}},y)={\mathds{1}}_{|{\widehat{y}}-y|>r},

which indicates whether the error of the prediction exceeds some allowed threshold
r
.

For this setting, we now construct a simple test based on splitting the data
\mathcal{D}_{N}
into independent batches of size
n+1
, as follows.
For each batch
j=1,\dots,\lfloor\frac{N}{n+1}\rfloor
, define a fitted model

{\widehat{f}}^{(j)}=\mathcal{A}(\mathcal{D}^{(j)};\xi^{(j)})\textnormal{ where }\mathcal{D}^{(j)}=\{(X_{i},Y_{i})\}_{i=(j-1)(n+1)+1}^{j(n+1)-1}\textnormal{ and }\xi^{(j)}\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}\textnormal{Unif}[0,1],

and evaluate the loss on the last data point of this batch,

\ell^{(j)}=\ell\big({\widehat{f}}^{(j)}(X_{j(n+1)}),Y_{j(n+1)}\big)\in\{0,1\}.

Note that, by construction,
\ell^{(j)}
’s are i.i.d. draws from a Bernoulli distribution with parameter
R_{P,n}(\mathcal{A})
.
Therefore, we can define our test by comparing the sum
S=\sum_{j=1}^{\lfloor N/(n+1)\rfloor}\ell^{(j)}
against a Binomial distribution:

\begin{split}{\widehat{T}}_{\textnormal{Binom}}(\mathcal{A},\mathcal{D}_{N})=\begin{cases}1,&S<k_{*},\\
1,&S=k_{*}\textnormal{ and }\zeta\leq a_{*},\\
0,&\textnormal{ otherwise},\end{cases}\end{split}

(7)

for a random value
\zeta\sim\textnormal{Unif}[0,1]
,
where the nonnegative integer
k_{*}
and value
a_{*}\in[0,1)
are chosen as the unique values satisfying

\mathbb{P}(\textnormal{Binomial}(\textstyle{\lfloor\frac{N}{n+1}\rfloor},\tau)<k^{*})+a^{*}\cdot\mathbb{P}(\textnormal{Binomial}(\textstyle{\lfloor\frac{N}{n+1}\rfloor},\tau)=k^{*})=\alpha.

Theorem 3
.

The test
{\widehat{T}}_{\textnormal{Binom}}
is a black-box test (as in Definition
1
),
and satisfies the assumption-free validity condition (
6
). Moreover,
if
\alpha<(1-\tau)^{\lfloor\frac{N}{n+1}\rfloor}
, then
for any
\mathcal{A}
and any
P
with
R_{P,n}(\mathcal{A})<\tau
, the power of
{\widehat{T}}_{\textnormal{Binom}}
is equal to

\mathbb{P}({\widehat{T}}_{\textnormal{Binom}}(\mathcal{A},\mathcal{D}_{N})=1)=\alpha\left(1+\frac{\tau-R_{P,n}(\mathcal{A})}{1-\tau}\right)^{\lfloor N/(n+1)\rfloor}\wedge 1.

Comparing this power calculation to the result of Theorem
2
,
we can see that in a setting where
n,N
are large and
R_{P}^{\max}\approx 1
, which is typically the case for loss functions mentioned above as for each
\widehat{y}
, there is always a
y
such that
\ell({\widehat{y}},y)=1
, the power of the simple test
{\widehat{T}}_{\textnormal{Binom}}

is nearly as high as the optimal power that can be achieved by any black-box test.
This may seem counterintuitive: how can this simple test be (nearly) optimal,
given that it uses the data very inefficiently—without any more sophisticated strategies such as cross-validation,
resampling, synthetic or perturbed data, etc? Nonetheless, comparing Theorem
2
and Theorem
3

reveals that the simple Binomial test, based only on sample splitting,
is nearly optimal because of the fundamental hardness of the problem.

A concrete example.

To take a simple example to make this concrete,
consider a binary response setting where
Y=f_{*}(X)\in\{0,1\}
(i.e.,
there is an oracle classifier
f_{*}
with perfect accuracy), with
\mathbb{P}_{P}(Y=0)=\mathbb{P}_{P}(Y=1)=0.5
, i.e., each label is equally likely.
Fix
\tau=0.5
, so that our hypothesis test (
1
) is simply asking whether the performance of
\mathcal{A}
is better
than random, and suppose we take
N=n+1
.
Then by Theorem
3
, we see that the power of the simple test
{\widehat{T}}_{\textnormal{Binom}}

is equal to
(2-2R_{P,n}(\mathcal{A}))\alpha
, which is
2\alpha
at most—a very low power when
\alpha
is small. However,
we can compare this to
Theorem
2
, which tells us that it is impossible for
any
black-box test to have power higher than
\approx(2-2R_{P,n}(\mathcal{A}))^{1+1/n}\alpha
,
again at most
\approx 2\alpha
.
On the other hand, if
N/n
is large, the power achieved by the test
{\widehat{T}}_{\textnormal{Binom}}
might be close to 1.

4
The role of algorithmic stability

Theorem
2
suggests that to alleviate the hardness result for algorithm evaluation, we must consider placing assumptions on either the data distribution
P
or the algorithm
\mathcal{A}
, since
any universally valid test
{\widehat{T}}
must necessarily have low power.

A large body of recent works suggests that in many contexts, algorithm stability helps CV-based methods achieve distribution-free guarantees
(
Kumar et al., 2013
;
Barber et al., 2021b
;
Austern and Zhou, 2020
;
Bayle et al., 2020
)
.
This suggests that this might also be the case for the problem of addressing
EvaluateAlg
: is estimating the risk
R_{P,n}(\mathcal{A})
achievable with a stability assumption, and no other conditions?
In this section, we will explore this possibility. Perhaps surprisingly, we will see that the hardness result of Theorem
2

remains the same, except in an extremely high-stability regime.

4.1
Background on algorithmic stability

At a high level,
algorithmic stability
expresses the idea that the fitted model produced
by an algorithm should not change massively under a slight perturbation to the input training data.
Algorithmic stability has long been a central notion in statistics and machine learning. Intuitively,
it is naturally a desirable property for learning algorithms—but it also leads to many downstream implications, as well.
For instance, it is known that stable algorithms tend to generalize better
(
Bousquet and Elisseeff, 2002
;
Shalev-Shwartz et al., 2010
)
. It also plays a critical role in a number of different problems, such as model selection
(
Meinshausen and Bühlmann, 2010
)
, reproducibility
(
Yu, 2013
)
, and predictive inference
(
Steinberger and Leeb, 2023
;
Barber et al., 2021b
)
. Stability is known to hold for many simple learning algorithms such as
k
-nearest neighbors
(
Devroye and Wagner, 1979
)
and ridge regression
(
Bousquet and Elisseeff, 2002
)
. It has also been shown to hold for any algorithm whose fitted models
are aggregated via bootstrapping or bagging
(
Breiman, 1996
;
Elisseeff et al., 2005
;
Soloff et al., 2024
)
.

There are also connections between stability and our ability to assess algorithmic performance;
for instance,
Dietterich, 1998
, in their discussion of the distinction between questions of assessing
models versus assessing algorithms, pointed out that addressing questions such as
EvaluateAlg

must “rely on the assumption that the performance of learning algorithms changes smoothly with changes
in the size of the training data”. A recent line of literature gives precise quantitative results
for the problem of estimating risk under strong stability conditions: specifically,
recent work by
Austern and Zhou, 2020
establishes asymptotic normality
of the cross-validation estimator
\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})
.
Related work by
Bayle et al., 2020
also establishes asymptotic normality of
\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})
under
weaker stability conditions.

On the other hand,
Kim and Barber, 2023
established a hardness result for the problem of proving empirically that a black-box algorithm is stable (i.e., establishing, via a black-box test, that stability holds for a given algorithm
\mathcal{A}
whose theoretical properties are unknown).

Defining algorithmic stability.

There are many different definitions of algorithmic stability in the literature (see, e.g.,
Bousquet and Elisseeff, 2002
and Appendix A of
Shalev-Shwartz et al., 2010
for some comparisons). In this work, we will consider the following notion of stability:

Let

be any algorithm, and let
P
be any distribution. Fix sample size
n\geq 1
.
Then we define the

and where the expectation is taken with respect to data points
(X_{1},Y_{1}),\dots,(X_{n},Y_{n}),(X_{n+1},Y_{n+1})
sampled i.i.d. from
P
and an independent random seed

4.2
Stability or consistency? Defining two regimes

First, we consider a regime with a strong stability assumption,

\beta_{1}(\mathcal{A},P,n)=\mathrm{o}(n^{-1})\textnormal{ \ or \ }\beta_{2}(\mathcal{A},P,n)=\mathrm{o}(n^{-1/2}).

(8)

The work of
Austern and Zhou, 2020
, mentioned above, studies the cross-validation estimator

\widehat{R}^{\textnormal{CV}}_{n}(\mathcal{A})
under a stability condition that is roughly equivalent to
the assumption that
\beta_{2}(\mathcal{A},P,n)=\mathrm{o}(n^{-1/2})
.
3
3

3

The related work of
Bayle et al., 2020
places a
\mathrm{o}(n^{-1/2})
bound on a related notion of
\ell_{2}
-stability referred to as the loss stability (also studied earlier by
Kumar et al., 2013
). Loss stability is a strictly weaker stability condition, and
in general is not sufficient for a consistency result (i.e., Proposition
1
).

In fact, this level of stability can be interpreted as a
consistency
assumption on the risk—as the following proposition shows.

Proposition 1
.

Fix any deterministic algorithm
\mathcal{A}
, any distribution
P
, and any
n\geq 1
. Let
{\widehat{f}}_{n}=\mathcal{A}(\{(X_{i},Y_{i})\}_{i\in n})
where the data points

(X_{i},Y_{i})
are sampled i.i.d. from
P
. Then it holds that

\mathbb{E}\left[\left|R_{P}({\widehat{f}}_{n})-R_{P,n}(\mathcal{A})\right|\right]\leq 2n\beta_{1}(\mathcal{A},P,n).

and

\mathbb{E}\left[\left(R_{P}({\widehat{f}}_{n})-R_{P,n}(\mathcal{A})\right)^{2}\right]^{1/2}\leq\sqrt{n}\beta_{2}(\mathcal{A},P,n)

Each bound is a straightforward consequence of the definition of
\ell_{1}
- or
\ell_{2}
-stability.
This result follows standard calculations and is similar to other results found in the stability literature, e.g.,
(
Celisse and Guedj, 2016
, Lemma 4)
.
(A more technical form of this result can also be established for the case of a randomized algorithm
\mathcal{A}
,
but for intuition, we restrict our attention to the deterministic case.)

Proposition
1
implies that, under the strong stability assumption (
8
),
it holds that

\mathbb{E}[(R_{P}({\widehat{f}}_{n})-R_{P,n}(\mathcal{A}))^{2}]=\mathrm{o}(1)
.
Consequently, if we assume that this condition holds, we can estimate
R_{P,n}(\mathcal{A})
simply by
estimating the risk
R_{P}({\widehat{f}}_{n})
of a
single
model
{\widehat{f}}_{n}
fitted on a training set of size
n
, which is relatively easy as long as we have a large holdout data as we have mentioned in Section
3.2
.

At a high level, then, if we assume
\beta_{q}(\mathcal{A},P,n)=\mathrm{o}(n^{-1/q})
for
either
q=1
or
q=2
, then the distinction between questions
EvaluateAlg
and
EvaluateModel

has essentially disappeared; estimating the risk of
\mathcal{A}
is “easy” for the trivial reason that it suffices
to estimate the risk
R_{P}({\widehat{f}}_{n})
of a single fitted model produced by
\mathcal{A}
.
(Of course, we would not expect this to be the optimal strategy for estimation and inference on
R_{P,n}(\mathcal{A})
.
In fact, in the setting
\beta_{2}(\mathcal{A},P,n)=\mathrm{o}(n^{-1/2})
along with some additional assumptions,
the work of
Austern and Zhou, 2020
establishes precise central limit theorem type result for the CV error which enables inference for the algorithm risk;
we do not describe the details since this is beyond the scope of the present paper.) A few common algorithms which satisfy this level of stability are
\ell_{q}
regularized algorithms (
q>1
) or soft-margin SVM
(
Bousquet and Elisseeff, 2002
;
Elisseeff et al., 2005
;
Wibisono et al., 2009
)
.
On the other hand, in many practical settings, even relatively simple algorithms exhibit high variability
and do not obey a consistency type property, i.e.,
\beta_{q}(\mathcal{A},P,n)
may be larger than
\mathcal{O}(n^{-1/q})
or may even
be
\mathcal{O}(1)
. This happens for instance in linear regression when
d\approx n
or in some sparse algorithms
(
Xu et al., 2011
)
.

We will now present our main results, showing that outside of the consistency regime,
there are fundamental limits on our ability to address
EvaluateAlg
with any black-box procedure.
In particular, for
\beta_{q}(\mathcal{A},P,n)\gtrsim n^{-1/q}
, we will establish a hardness result, analogous to Theorem
2
,
to show that outside of the consistency regime it is impossible to perform inference on
EvaluateAlg

with limited data. See Figure
1
for an illustration of the phase transition between these two regimes.

4.3
Limitations under stability

We next present our main theorem in the setting of algorithmic stability.
The following theorem holds for both
q=1
and
q=2
, i.e., for both
\ell_{1}
-stability and
\ell_{2}
-stability.

Theorem 4
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the loss
\ell
takes values in
[0,B]
.
Let
{\widehat{T}}
be a black-box test (as in Definition
1
),
and assume that
{\widehat{T}}
satisfies the stability-constrained validity condition,

\mathbb{P}_{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\alpha\textnormal{ for all $\mathcal{A},P$ such that $\beta_{q}(\mathcal{A},P,n)\leq\gamma_{q}$ and $R_{P,n}(\mathcal{A})\geq\tau$,}

(9)

for some stability parameter
\gamma_{q}\geq 2B/n^{1/q}
.
Let
\tilde{\tau}=\tau(1+\frac{\alpha^{-1}-1}{N})
.

Then the power of
{\widehat{T}}
to detect low risk is bounded as follows:
for any
\mathcal{A}
and any
P
with
\beta_{q}(\mathcal{A},P,n)\leq\gamma_{q}
and
R_{P,n}(\mathcal{A})<\tau
,

\mathbb{P}_{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\left[\alpha\left(1+\frac{\tilde{\tau}-R_{P,n}(\mathcal{A})}{R_{P}^{\max}-\tilde{\tau}}\right)^{N/n}\right]\wedge 1,

if we assume
\tilde{\tau}<R_{P}^{\max}
so that the denominator is positive.

Theorem
4
shows that, when we are outside the consistency regime (i.e.,
when the bound on
\ell_{q}
stability
\gamma_{q}
is at least as large as
\mathcal{O}(n^{-1/q})
),
the problem of estimating
R_{P,n}(\mathcal{A})
is just as hard as if we had no stability assumption at all (as in Theorem
2
). Thus, there is no intermediate regime on our ability
to answer the question
EvaluateAlg
: instead, we have a phase transition
between the consistency regime,
\gamma_{q}=\mathrm{o}(n^{-1/q})
, and the hardness results of our theorems, when
\gamma_{q}\gtrsim n^{-1/q}
.
As illustrated in Figure
1
, we must either assume that we are in the consistency regime (in
which case, it is essentially equivalent to simply answer the easier question
EvaluateModel
),
or without this assumption, it is impossible to have high power for testing
EvaluateAlg
.

5
Comparing multiple algorithms

In many practical settings, we may have multiple options for which algorithm to use—for example, different regression methods,
different architectures for a neural network, different choices of a tuning parameter, etc.
In this scenario, we therefore need to compare the performance of multiple algorithms, to determine which is best
for a particular application.
In this section, we examine the question of comparing the performance of two algorithms,
\mathcal{A}_{0}
and
\mathcal{A}_{1}
,
to build an understanding of the challenges of algorithm comparison.

5.1
Problem formulation: comparing two algorithms

We first recall the questions
CompareAlg
and
CompareModel
introduced in Section
1
.
Given two algorithms
\mathcal{A}_{0},\mathcal{A}_{1}
, we would like to determine which one is a better match for a particular data analysis task:

CompareAlg
: which algorithm,
\mathcal{A}_{0}
or
\mathcal{A}_{1}
, performs better on data drawn from
P
?

Of course, as for the problem of evaluating a single algorithm, we need to make a distinction between comparing
\mathcal{A}_{0},\mathcal{A}_{1}
,
versus comparing the fitted models produced by these algorithms:

CompareModel
: which fitted model,
{\widehat{f}}_{0}
or
{\widehat{f}}_{1}
, performs better on data drawn from
P
?

To formalize these questions, we again need to consider our notion of risk.
Given two models
f_{0},f_{1}:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}
,
we will define the quantity

\Delta_{P}(f_{0},f_{1})=\mathbb{E}_{P}\left[\psi(f_{0}(X),f_{1}(X),Y)\right],

where
\psi:\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}}\times\mathcal{Y}\rightarrow\mathbb{R}
is a “comparison function”. For example,
we might choose to take a difference in losses,

\psi(y^{\prime},y^{\prime\prime},y)=\ell(y^{\prime},y)-\ell(y^{\prime\prime},y)

(10)

so that
\Delta_{P}(f_{0},f_{1})=R_{P}(f_{0})-R_{P}(f_{1})
simply measures the difference in risk for the two models
f_{0},f_{1}
. Alternatively, we might choose

\psi(y^{\prime},y^{\prime\prime},y)={\mathds{1}}_{\ell(y^{\prime},y)>\ell(y^{\prime\prime},y)}-{\mathds{1}}_{\ell(y^{\prime},y)<\ell(y^{\prime\prime},y)},

(11)

so that
\Delta_{P}(f_{0},f_{1})

compares the frequency of how often one function has a smaller loss than the other.
From this point on, we will assume without comment that
\psi
satisfies an antisymmetry condition,

\psi(y^{\prime},y^{\prime\prime},y)=-\psi(y^{\prime\prime},y^{\prime},y),\textnormal{ for all $y\in\mathcal{Y}$, $y^{\prime},y^{\prime\prime}\in\widehat{\mathcal{Y}}$},

so that comparing
f_{0}
against
f_{1}
is equivalent (up to sign) to comparing
f_{1}
against
f_{0}
.
We will take the convention that a positive value of
\psi(y^{\prime},y^{\prime\prime},y)
indicates that
y^{\prime\prime}
is better than
y^{\prime}
, as a prediction for
y
(as in the examples above);
in other words,
\Delta_{P}(f_{0},f_{1})>0
indicates that
f_{1}
is better than
f_{0}
, for the problem of modeling data from distribution
P
.

Now, given algorithms
\mathcal{A}_{0},\mathcal{A}_{1}
for modeling our data,
we are now ready to formalize our comparison questions,
CompareAlg
and
CompareModel
.

CompareAlg
: what is
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})
?  versus
CompareModel
: what is
\Delta_{P}({\widehat{f}}_{0,n},{\widehat{f}}_{1,n})
?

The question
CompareModel
compares the fitted models

{\widehat{f}}_{0,n},{\widehat{f}}_{1,n}
obtained by training these algorithms on a particular data set of size
n
, given by
{\widehat{f}}_{l,n}=\mathcal{A}_{l}\big(\{(X_{i},Y_{i})\}_{i\in[n]};\xi\big)
for each
l=0,1
.
4
4

4

In this section we take the convention that the two algorithms,
\mathcal{A}_{0}
and
\mathcal{A}_{1}
, are run with the same random seed
\xi
.
The same types of results will hold regardless of this choice, with appropriate modifications to the definitions.
In contrast,
the question
CompareAlg
takes an expected value over the training set,

\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})=\mathbb{E}_{P}\left[\Delta_{P}({\widehat{f}}_{0,n},{\widehat{f}}_{1,n})\right],

with expected value taken with respect to the distribution of both the training data
\{(X_{i},Y_{i})\}_{i\in[n]}
and also the random seed
\xi\sim\textnormal{Unif}[0,1]
.

Similarly to the hypothesis test (
1
) defined
for the problem of algorithm evaluation, we now consider addressing
CompareAlg
via performing a hypothesis testing problem regarding whether
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})
lies below zero or above zero,

H_{0}:\,\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})\leq 0\textnormal{ \ versus \ }H_{1}:\,\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})>0,

(12)

Rejecting the null hypothesis means that there is enough evidence to conclude that
\mathcal{A}_{1}
is better than
\mathcal{A}_{0}
.

5.2
Defining a black-box test

Similar to Definition
1
, we can also define a black-box test in the algorithm comparison setting

Definition 3

(Black-box test for algorithm comparison)
.

Let
\mathfrak{D}=\cup_{m\geq 0}(\mathcal{X}\times\mathcal{Y})^{m}
denotes the space of data sets of any size. Consider any test
{\widehat{T}}
that takes as input two algorithms
\mathcal{A}_{0}
,
\mathcal{A}_{1}
, a dataset
\mathcal{D}\in\mathfrak{D}
, and returns a (possibly randomized) output
{\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D})\in\{0,1\}
. We say that
{\widehat{T}}
is a black-box test if it can be defined as follows: for some functions
g^{(1)},g^{(2)},\dots,g
, and for random seeds,
\zeta^{(1)},\zeta^{(2)},\dots,\zeta\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}\textnormal{Unif}[0,1]
,

1.

At stage
r=1
, generate a new dataset and a new random seed,

(\mathcal{D}^{(1)},\xi^{(1)})=g^{(1)}(\mathcal{D},\zeta^{(1)}),

and compute the fitted models
{\widehat{f}}_{0}^{(1)}=\mathcal{A}_{0}(\mathcal{D}^{(1)};\xi^{(1)})
and
{\widehat{f}}_{1}^{(1)}=\mathcal{A}_{1}(\mathcal{D}^{(1)};\xi^{(1)})
.

2.

For each stage
r=2,3,\ldots
, generate a new dataset and a new random seed,

(\mathcal{D}^{(r)},\xi^{(r)})=g^{(r)}\big(\mathcal{D},(\mathcal{D}^{(s)})_{1\leq s<r},({\widehat{f}}_{l}^{(s)})_{1\leq s<r;\,l=0,1},(\zeta^{(s)})_{1\leq s\leq r},(\xi^{(s)})_{1\leq s<r}\big),

and compute the fitted models

{\widehat{f}}_{0}^{(r)}=\mathcal{A}_{0}(\mathcal{D}^{(r)};\xi^{(r)})
and
{\widehat{f}}_{1}^{(r)}=\mathcal{A}_{1}(\mathcal{D}^{(r)};\xi^{(r)})
.

3.

Repeat until some stopping criterion is reached; let
{\widehat{r}}
denote the (data-dependent) total number of rounds.

4.

Finally, return

{\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D})=g\big(\mathcal{D},(\mathcal{D}^{(r)})_{1\leq r\leq{\widehat{r}}},({\widehat{f}}_{l}^{(r)})_{1\leq r\leq{\widehat{r}};\,l=0,1},(\zeta^{(r)})_{1\leq r\leq{\widehat{r}}},(\xi^{(r)})_{1\leq r\leq{\widehat{r}}},\zeta\big).

5.3
Main results for algorithm comparison

In this section, we present our main result on the limit of any universally valid black-box test on the testing problem (
12
). Again, we would like to provide an answer to
CompareAlg
that is uniformly valid over all possible
\mathcal{A}_{0},\mathcal{A}_{1}
and
P
.
Specifically, fixing a error tolerance level
\alpha\in(0,1)
and an evaluation sample size
n
, an available dataset
\mathcal{D}_{N}=\{(X_{i},Y_{i})\}_{i\in[N]}\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P
of size
N
, we will consider tests
{\widehat{T}}={\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})

that satisfy

\begin{split}\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{D}_{N},\mathcal{A}_{0},\mathcal{A}_{1})=1\right)\leq\alpha\text{ for any }\mathcal{A}_{0},\mathcal{A}_{1},P\text{ such that }\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})\leq 0.\end{split}

(13)

We will restrict our attention to comparison functions
\psi
that are bounded—the problem of testing
CompareAlg
is not meaningful in a setting where the comparison function
\psi
is unbounded (analogous to what was shown in Theorem
1
for the problem
EvaluateAlg
).
In order to state our results, we first introduce an analog of
R_{P}^{\max}
in this setting. For a distribution
P
on
\mathcal{X}\times\mathcal{Y}
, let

\begin{split}\Delta_{P}^{\max}&=\sup_{f_{0},f_{1}}\Delta_{P}(f_{0},f_{1}),\end{split}

the largest possible comparison risk of any two functions
f_{0}
and
f_{1}
for data drawn from
P
. We are now ready to state the result.

Theorem 5
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the comparison function
\psi
takes values in
[-B,B]
. Let
{\widehat{T}}
be a black-box test (as in Definition
3
),
and assume that
{\widehat{T}}
satisfies the assumption-free validity condition (
13
).

Then the power of
{\widehat{T}}
to compare algorithms is bounded as follows:
for any
\mathcal{A}_{0},\mathcal{A}_{1}
and any
P
with
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})>0
,

\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})=1\right)\leq\left[\alpha\left(1+\frac{\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})+\frac{B(\alpha^{-1}-1)}{N}}{\Delta_{P}^{\max}-\frac{B(\alpha^{-1}-1)}{N}}\right)^{N/n}\right]\wedge 1,

(14)

provided that
\Delta_{P}^{\max}>\frac{B(\alpha^{-1}-1)}{N}
so that the denominator is positive.

Since the term
\frac{B(\alpha^{-1}-1)}{N}
is negligible as long as
N
is large, the power is effectively bounded as
\alpha(1+\frac{\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})}{\Delta_{P}^{\max}})^{N/n}
. In particular, since
\Delta_{P}^{\max}\geq\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})
by definition, this means that power can only be a constant multiple of
\alpha
if
N\propto n
. Thus, similar to the interpretation for Theorem
2
, Theorem
5
suggests that when either
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})
is close to zero or
N\propto n
, then the power of any universally valid black-box test against any alternative is fairly low.

For the problem of algorithm evaluation, in the special case of a zero-one loss, we saw in Section
3.3
that the Binomial test proposed in (
7
)
provided a concrete example of a universally valid test that achieves a power nearly as high as the upper bound given in Theorem
2
.
Analogously, for the problem of algorithm comparison, it is again possible to construct a similar test (in this case, for special cases such as the comparison
function
\psi
given in (
11
)) to show that the upper bound on power in Theorem
5
is approximately tight.
Since the intuition and construction are similar to the case of algorithm comparison, we do not give the details in this work.

5.4
Algorithm comparison with a stability assumption

In this section, we study the role of stability in algorithm comparison: does the problem
CompareAlg

become easier if we assume that
\mathcal{A}_{0}
and
\mathcal{A}_{1}
are both stable algorithms?
As for algorithm evaluation, here for the problem of algorithm comparison, we will draw the same conclusion: aside from extremely high stability (i.e., the consistency regime), adding a stability assumption does not alter the hardness result for testing
CompareAlg
.

The following result considers a special case for the comparison function
\psi
: we assume that
\psi
is simply the difference in losses,
as in (
10
).
This theorem holds for both
q=1
and
q=2
, i.e., for both
\ell_{1}
-stability and
\ell_{2}
-stability.

Theorem 6
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the comparison function is given by
\psi(y^{\prime},y^{\prime\prime},y)=\ell(y^{\prime},y)-\ell(y^{\prime\prime},y)
, where the loss
\ell
takes values in
[0,B]
. Let
{\widehat{T}}
be a black-box test (as in Definition
3
),
and assume that
{\widehat{T}}
satisfies the stability-constrained validity condition,

\begin{split}\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})=1\right)\leq\alpha\textnormal{ for all $\mathcal{A}_{0},\mathcal{A}_{1},P$ such that}\\
\textnormal{ $\beta_{q}(\mathcal{A}_{l},P,n)\leq\gamma_{q}$ for each $l=0,1$ and
$\Delta_{n,P}(\mathcal{A}_{0},\mathcal{A}_{1})\leq 0$},\end{split}

(15)

for some stability parameter
\gamma_{q}\geq 2B/n^{1/q}
.

Then the power of
{\widehat{T}}
to compare algorithms is bounded as follows:
for any
\mathcal{A}_{0},\mathcal{A}_{1}
and any
P
with
\beta_{q}(\mathcal{A}_{l},P,n)\leq\gamma_{q}
for
l=0,1
and
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})<0
,

\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})=1\right)\leq\left[\alpha\left(1+\frac{\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})+\frac{B(\alpha^{-1}-1)}{N}}{\Delta_{P}^{\max}-\frac{B(\alpha^{-1}-1)}{N}}\right)^{N/n}\right]\wedge 1,

provided that
\Delta_{P}^{\max}>\frac{B(\alpha^{-1}-1)}{N}
so that the denominator is positive.

The bound on power is the same as that in Theorem
5
—that is, unless the bound
\gamma_{q}
on the
\ell_{q}
-stability
of the two algorithms is low enough for us to be in the consistency regime, the problem of comparing algorithms suffers from the same hardness result as before.

5.4.1
An alternative notion of stability

In Theorem
6
, we considered a particular notion of stability: we assumed that
each
algorithm,
\mathcal{A}_{0}
and
\mathcal{A}_{1}
,
is stable, relative to the loss function
\ell
. However, this framework only allows us to handle a particular comparison function
\psi
, namely, a difference of losses as in (
10
).

An alternative way to incorporate stability, which will allow us to work with an arbitrary comparison function
\psi
, is to define stability directly
on the
pair
of algorithms
\mathcal{A}_{0},\mathcal{A}_{1}
. (This type of condition was also considered by
Bayle et al., 2020
, but they only require the weaker loss stability in inferencing the difference of averaged model risks of two algorithms run in the CV procedure.)

We define the
\ell_{q}
-stability of the tuple
(\mathcal{A}_{0},\mathcal{A}_{1},P,n)
as

\beta_{q}(\mathcal{A}_{0},\mathcal{A}_{1},P,n)\\
:=\max_{j=1,\ldots,n}\mathbb{E}\left[\left|\psi({\widehat{f}}_{n0}(X_{n+1}),{\widehat{f}}_{n1}(X_{n+1}),Y_{n+1})-\psi({\widehat{f}}_{n0}^{-j}(X_{n+1}),{\widehat{f}}_{n1}^{-j}(X_{n+1}),Y_{n+1})\right|^{q}\right]^{1/q}.

(16)

where

{\widehat{f}}_{l,n}=\mathcal{A}_{l}(\{(X_{i},Y_{i})\}_{i\in[n]};\xi),\quad{\widehat{f}}^{-j}_{l,n}=\mathcal{A}_{l}(\{(X_{i},Y_{i})\}_{i\in[n]\backslash\{j\}};\xi),\quad l=0,1.

Notice that if
\psi
is a difference of losses, as in (
10
), then this condition is satisfied if
\mathcal{A}_{0},\mathcal{A}_{1}
are each stable
with respect to loss
\ell
—indeed we have

\beta_{q}(\mathcal{A}_{0},\mathcal{A}_{1},P,n)\leq\beta_{q}(\mathcal{A}_{0},P,n)+\beta_{q}(\mathcal{A}_{1},P,n).

However, it is possible to have
\beta_{q}(\mathcal{A}_{0},\mathcal{A}_{1},P,n)
small even if the individual algorithms are not stable
(if the comparison function serves to cancel noise terms, say).

We now state a hardness result under this alternative notion of stability. Again, this theorem holds for either
q=1
or
q=2
(
\ell_{1}
- or
\ell_{2}
-stability).

Theorem 7
.

Assume that either
|\mathcal{X}|=\infty
or
|\mathcal{Y}|=\infty
,
and that the comparison function
\psi
takes values in
[-B,B]
. Let
{\widehat{T}}
be a black-box test (as in Definition
3
),
and assume that
{\widehat{T}}
satisfies the stability-constrained validity condition,

\begin{split}\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})=1\right)\leq\alpha\textnormal{ for any $\mathcal{A}_{0},\mathcal{A}_{1},P$ such that}\\
\textnormal{ $\beta_{q}(\mathcal{A}_{0},\mathcal{A}_{1},P,n)\leq\gamma_{q}$ and
$\Delta_{n,P}(\mathcal{A}_{0},\mathcal{A}_{1})\leq 0$},\end{split}

(17)

for some stability parameter
\gamma_{q}\geq 4B/n^{1/q}
.

Then the power of
{\widehat{T}}
to compare algorithms is bounded as follows:
for any
\mathcal{A}_{0},\mathcal{A}_{1}
and any
P
with
\beta_{q}(\mathcal{A}_{0},\mathcal{A}_{1},P,n)\leq\gamma_{q}
and
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})>0
,

\mathbb{P}_{P}\left({\widehat{T}}(\mathcal{A}_{0},\mathcal{A}_{1},\mathcal{D}_{N})=1\right)\leq\left[\alpha\left(1+\frac{\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})+\frac{B(\alpha^{-1}-1)}{N}}{\Delta_{P}^{\max}-\frac{B(\alpha^{-1}-1)}{N}}\right)^{N/n}\right]\wedge 1,

provided that
\Delta_{P}^{\max}>\frac{B(\alpha^{-1}-1)}{N}
so that the denominator is positive.

Again, we have the same bound on power as before, even under an assumption of stability.

5.5
Relating algorithm comparison and algorithm evaluation

In this paper, we have considered two different problems regarding algorithms: comparing the risk of a single algorithm
\mathcal{A}
against a fixed threshold
\tau
, as in

EvaluateAlg
, or comparing the risks of two different algorithms
\mathcal{A}_{0},\mathcal{A}_{1}
against each other, as in
CompareAlg
.
While these problems are clearly related, the hypotheses being tested appear to be distinct, but in this section
we will show that the two testing problems are actually the same—in particular, the hypothesis test (
12
)
for algorithm comparison can be viewed as a special case of the test (
1
) for algorithm evaluation.

Specifically, if each algorithm
\mathcal{A}_{0},\mathcal{A}_{1}
returns fitted functions that are maps from
\mathcal{X}
to
\widehat{\mathcal{Y}}
, we will now consider
the
paired
algorithm
\tilde{\mathcal{A}}=(\mathcal{A}_{0},\mathcal{A}_{1})
that returns a function mapping from
\mathcal{X}
to
\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}}
. Namely,
for a data set
\mathcal{D}
and random seed
\xi\in[0,1]
, we define

\tilde{\mathcal{A}}(\mathcal{D};\xi)=\tilde{f}
, where
\tilde{f}:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}}
is the map given by

\tilde{f}(x)=({\widehat{f}}_{0}(x),{\widehat{f}}_{1}(x))\textnormal{ \ where \ }{\widehat{f}}_{l}=\mathcal{A}_{l}(\mathcal{D};\xi),\ l=0,1.

(18)

Next, we define

\begin{array}[]{cccc}\tilde{\ell}:&(\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}})\times\mathcal{Y}&\rightarrow&\mathbb{R}_{+}\\
&\rotatebox[origin]{90.0}{$\in$}&&\rotatebox[origin]{90.0}{$\in$}\\
&\big((y^{\prime},y^{\prime\prime}),y\big)&\mapsto&B-\psi(y^{\prime},y^{\prime\prime},y)\end{array}

as our new loss function. In particular, note that
\tilde{\ell}
takes values in
[0,2B]
, since
\psi
takes values in
[-B,B]
.

Now we will see how the risk of the new algorithm
\tilde{\mathcal{A}}
relates to the comparison problem for the pair
\mathcal{A}_{0},\mathcal{A}_{1}
.
Let
\tilde{R}_{P,n}
denote the risk of
\tilde{\mathcal{A}}
with respect to the new loss
\tilde{\ell}
, for data sampled from
P
.
For a fixed function
f:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}}
, let
f_{0}
and
f_{1}
be the first and second components of
f
, i.e.,

f(x)=(f_{0}(x),f_{1}(x))
. We have

\tilde{R}_{P}(f)=\mathbb{E}_{P}[\tilde{\ell}(f(X),Y)]=\mathbb{E}_{P}[B-\psi\big(f_{0}(X),f_{1}(X),Y)]=B-\Delta_{P}(f_{0},f_{1}).

Therefore, defining
\tilde{f}
,
{\widehat{f}}_{0}
, and
{\widehat{f}}_{1}
as in (
18
),

\tilde{R}_{P,n}(\tilde{\mathcal{A}})=\mathbb{E}[\tilde{R}_{P}(\tilde{f})]=\mathbb{E}[B-\Delta_{P}({\widehat{f}}_{0},{\widehat{f}}_{1})]=B-\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1}).

In other words, the comparison risk
\Delta_{P,n}(\mathcal{A}_{0},\mathcal{A}_{1})
for the pair
\mathcal{A}_{0},\mathcal{A}_{1}

is equivalent (up to a transformation) to the evaluation risk
\tilde{R}_{P,n}(\tilde{\mathcal{A}})
. This means that, by replacing the space
\widehat{\mathcal{Y}}
with
\widehat{\mathcal{Y}}\times\widehat{\mathcal{Y}}

(and
B
with
2B
),
we can rewrite the algorithm comparison problem as an algorithm evaluation problem:
the testing problem (
12
) for
CompareAlg
is the same as testing

H_{0}:R_{P,n}(\tilde{\mathcal{A}})\geq B\quad\text{v.s.}\quad H_{1}:R_{P,n}(\tilde{\mathcal{A}})<B,

which is equivalent to the hypothesis test (
1
) for
EvaluateAlg
if we take threshold
\tau=B
.
Indeed, as we will see in Appendix
B.3
,
the result in Theorem
7
can be easily obtained from the proof of Theorem
4
due to this correspondence.

6
Discussion

In this paper, we consider the tasks of algorithm/model evaluation and algorithm/model comparison.
Our main results characterize the difference between these questions and the limitations of black-box tests to perform inference on algorithmic questions, showing that
it is impossible for a universally valid test to
have high power under any alternative hypothesis, unless the number of available data is far higher than the target sample size.
Our results also show that an assumption of algorithmic stability is not sufficient to circumvent this hardness result, unless in the consistency regime.

Assessing the quality of models and modeling algorithms are common tasks in many fields, we believe that our results are
useful in clarifying the gap between questions that assess an algorithm (
EvaluateAlg
and
CompareAlg
), versus
questions that assess a particular fitted model produced by the algorithm (
EvaluateModel
and
CompareModel
).
While our results establish the hardness of these first two problems, even under a certain stability assumption,
an important open question for further research is whether there are alternative mild assumptions (on the algorithm and/or on the data)
that would enable powerful inference on
EvaluateAlg
and
CompareAlg
even under sample size constraints.

C_{1}
such that
\mathbb{P}({\widehat{r}}\leq C_{1})\geq 1-\epsilon/4
.
Next, for each
r=1,\dots,C_{1}
, the data set
\mathcal{D}^{(r)}
has a finite size
N_{r}
(again,
N_{r}
is a random variable and may be
arbitrarily large, but must be finite depending on
P
and
\mathcal{A}
). For each
r=1,\dots,C_{1}
, find some
C_{2,r}
such that
\mathbb{P}(N_{r}\leq C_{2,r})\geq 1-\epsilon/4C_{1}
.
Let
C_{2}=\max_{r=1,\dots,C_{1}}C_{2,r}
.
Therefore, with probability at least
1-\epsilon/2
,
{\widehat{T}}
runs for at most
C_{1}
many rounds,
and each round generates a data set
\mathcal{D}^{(r)}
with at most
C_{2}
many data points.
Let
\mathcal{E}
denote this event, so that we have
\mathbb{P}(\mathcal{E})\geq 1-\epsilon/2
. On the event
\mathcal{E}
,
then, the combined data set
\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})}
contains at most
N+C_{1}C_{2}
many data points.
Now consider a data point
(x,y)
for which

\mathbb{P}((x,y)\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})})\geq\epsilon.

(19)

For any such
(x,y)
, we have

\mathbb{P}(\textnormal{$\mathcal{E}$ holds, and }(x,y)\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})})\geq\epsilon-\mathbb{P}(\mathcal{E}^{c})\geq\epsilon/2.

(20)

Suppose there are
M
many different
(x_{i},y_{i})
pairs satisfying (
19
), then

\begin{split}N+C_{1}C_{2}&\geq\mathbb{E}[\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})}\cdot{\mathds{1}}_{\mathcal{E}}]\\
&\geq\mathbb{E}\left[(\sum_{i=1}^{M}{\mathds{1}}_{(x_{i},y_{i})\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})}})\cdot{\mathds{1}}_{\mathcal{E}}\right]\\
&=\sum_{i=1}^{M}\mathbb{P}\left(\textnormal{$\mathcal{E}$ holds, and }(x_{i},y_{i})\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})}\right)\\
&\overset{\eqref{ineq:lemma1-ineq2}}{\geq}M\epsilon/2,\end{split}

so we have
M\leq\frac{N+C_{1}C_{2}}{\epsilon/2}
, i.e., the inequality (
19
) can only hold for at most
\frac{N+C_{1}C_{2}}{\epsilon/2}
many data points.
∎

This result reveals how the assumption of infinite cardinality will be used—if only finitely many points
(x,y)

have probability
\geq\epsilon
of appearing at any point during the black-box test, then we can always find some other data point
(x^{\prime},y^{\prime})\in\mathcal{X}\times\mathcal{Y}

whose probability of appearing during the test is
<\epsilon
.
Moreover, the proof also suggests how we might
derive analogous results for
finite

\mathcal{X}\times\mathcal{Y}
under a computational constraint.
Specifically, if
{\widehat{T}}
is only allowed to call
\mathcal{A}
a bounded number of times, and if each run of
\mathcal{A}
is only allowed to input
a data set of some bounded size, then these constraints can be used in place of the (arbitrarily large) values
C_{1},C_{2}
in the proof above.

A.2
Proof of Theorem
1

Fix any
\mathcal{A}
and any
P
.
Let
\epsilon,\delta>0
be fixed and arbitrarily small constants.

Define a constant

C=\frac{\tau}{\left[1-\left(1-\delta/2\right)^{n}\right]\cdot\delta/2}.

Since
\sup_{{\widehat{y}},y}\ell({\widehat{y}},y)=\infty
, we can find some
{\widehat{y}}_{0},y_{0}
such that
\ell({\widehat{y}}_{0},y_{0})\geq C
.
And, by Lemma
1
, we can find some
(x_{*},y_{*})\in\mathcal{X}\times\mathcal{Y}
such that

\mathbb{P}((x_{*},y_{*})\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})})\leq\epsilon,

where
\mathcal{D}_{N}
denotes an i.i.d. sample from
P
, and
\mathcal{D}^{(1)},\dots,\mathcal{D}^{({\widehat{r}})}
denote
the data sets constructed when running
{\widehat{T}}(\mathcal{A},\mathcal{D}_{N})
.
Let
\mathcal{E}_{*}
be the event that
(x_{*},y_{*})\not\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})}
,
so that
\mathbb{P}(\mathcal{E}_{*})\geq 1-\epsilon
.

Next, we define a new distribution

P^{\prime}=(1-\delta)\cdot P+\delta/2\cdot(P_{X}\times\delta_{y_{0}})+\delta/2\cdot\delta_{(x_{*},y_{*})},

and a new algorithm
\mathcal{A}^{\prime}
as follows: for any
m\geq 0
, any
\mathcal{D}\in(\mathcal{X}\times\mathcal{Y})^{m}
,
and any
\xi\in[0,1]
,

\mathcal{A}^{\prime}(\mathcal{D};\xi)=\begin{cases}\mathcal{A}(\mathcal{D};\xi),&\textnormal{ if }(x_{*},y_{*})\not\in\mathcal{D},\\
f(x)\equiv{\widehat{y}}_{0},&\textnormal{ if }(x_{*},y_{*})\in\mathcal{D}.\end{cases}

That is, if
\mathcal{D}
contains the data point
(x_{*},y_{*})
, then
\mathcal{A}^{\prime}
returns the constant function that maps any
x
to the value
{\widehat{y}}_{0}
.
Now let
\mathcal{D}_{N}
be drawn i.i.d. from
P
, and let
\mathcal{D}_{N}^{\prime}
be drawn i.i.d. from
P^{\prime}
. By definition of
P^{\prime}
,
we can construct a coupling between these two data sets such that
\mathbb{P}(\mathcal{D}_{N}=\mathcal{D}_{N}^{\prime}\mid\mathcal{D}_{N})\geq(1-\delta)^{N}
.
Therefore, this means that

\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)\geq(1-\delta)^{N}\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N})=1).

Next, observe that on the event
\mathcal{E}_{*}
, we have
{\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N})={\widehat{T}}(\mathcal{A},\mathcal{D}_{N})
, almost surely.
Informally, this is because when running the black-box text
{\widehat{T}}
,
if we initialize at the same data set
\mathcal{D}_{N}
, and we never observe the data point
(x_{*},y_{*})
,
then
\mathcal{A}
and
\mathcal{A}^{\prime}
are returning the same fitted models at every iteration, and so
all iterations of the tests
{\widehat{T}}(\mathcal{A},\mathcal{D}_{N})
and
{\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N})
are identical to each other.
(A more formal proof of this type of statement can be found in the proof of
Kim and Barber, 2023
.)
In particular, we have

\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N})=1)\geq\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)-\mathbb{P}(\mathcal{E}_{*}^{c})\geq\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)-\epsilon.

Combining our calculations, then,

\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq(1-\delta)^{-N}\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)+\epsilon.

To complete the proof, we
now calculate the risk of the new algorithm and distribution: writing
\mathcal{D}_{n}^{\prime}
to denote a data set drawn i.i.d. from
P^{\prime}
, and
(X_{n+1}^{\prime},Y_{n+1}^{\prime})\sim P^{\prime}

as the test point,

\displaystyle R_{P^{\prime},n}(\mathcal{A}^{\prime})

\displaystyle=\mathbb{E}_{P^{\prime}}\left[\ell\big([\mathcal{A}^{\prime}(\mathcal{D}^{\prime}_{n};\xi)](X_{n+1}^{\prime}),Y_{n+1}^{\prime}\big)\right]

\displaystyle\geq\mathbb{E}_{P^{\prime}}\left[\ell\big([\mathcal{A}^{\prime}(\mathcal{D}^{\prime}_{n};\xi)](X_{n+1}^{\prime}),Y_{n+1}^{\prime}\big)\cdot{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}^{\prime}_{n}}\cdot{\mathds{1}}_{Y_{n+1}^{\prime}=y_{0}}\right]

\displaystyle=\mathbb{E}_{P^{\prime}}\left[\ell({\widehat{y}}_{0},y_{0})\cdot{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}^{\prime}_{n}}\cdot{\mathds{1}}_{Y_{n+1}^{\prime}=y_{0}}\right]

\displaystyle\geq C\cdot\mathbb{E}_{P^{\prime}}\left[{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}^{\prime}_{n}}\cdot{\mathds{1}}_{Y_{n+1}^{\prime}=y_{0}}\right]

\displaystyle\geq C\cdot\left[1-\left(1-\delta/2\right)^{n}\right]\cdot\delta/2

\displaystyle=\tau,

where the last step holds by definition of
C
.
Therefore, by validity of
{\widehat{T}}
(
6
), we must have

\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)\leq\alpha\ \Longrightarrow\ \mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq(1-\delta)^{-N}\alpha+\epsilon.

Since
\epsilon,\delta>0
can be taken to be arbitrarily small (while
N
is being treated as fixed),
this proves the theorem.

A.3
Proof of Theorem
2

Theorem
2
can be viewed as a special case of
Theorem
4
.
Specifically, since the loss takes values in
[0,B]
,
it holds trivially for any
(\mathcal{A},P,n)
that
\beta_{q}(\mathcal{A},P,n)\leq B
.
Thus, the result of Theorem
2
is implied by
applying Theorem
4
with stability parameter
\gamma_{q}=B
.

A.4
Proof of Theorem
4

The general proof idea is the following: for any
\mathcal{A}
and
P
such that
\beta_{q}(\mathcal{A},P,n)\leq\gamma_{q}
and
R_{P,n}(\mathcal{A})<\tau
, we can construct a new algorithm
\mathcal{A}^{\prime}
and a new distribution
P^{\prime}
such that
\beta_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq\gamma_{q}
and
R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq\tau
. Moreover, the constructed
(\mathcal{A}^{\prime},P^{\prime})
is sufficiently similar to
(\mathcal{A},P)
so that they are difficult to distinguish using limited
N
i.i.d. data points.

To make this idea precise, we begin by fixing any constant
c\in(0,1)
with

(1-c)^{n}\cdot R_{P,n}(\mathcal{A})+\left[1-(1-c)^{n}\right]\cdot R_{P}^{\max}>\tilde{\tau}.

(21)

We will show that

\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq(1-c)^{-N}\alpha.

(22)

In particular, since condition (
21
) holds for any
c
satisfying

(1-c)<\left(\frac{R_{P}^{\max}-\tilde{\tau}}{R_{P}^{\max}-R_{P,n}(\mathcal{A})}\right)^{1/n},

this implies

\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\alpha\left(\frac{R_{P}^{\max}-R_{P,n}(\mathcal{A})}{R_{P}^{\max}-\tilde{\tau}}\right)^{N/n}=\alpha\left(1+\frac{\tilde{\tau}-R_{P,n}(\mathcal{A})}{R_{P}^{\max}-\tilde{\tau}}\right)^{N/n},

as claimed. (Of course,
\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq 1
holds trivially.)

We now prove (
22
) holds for any fixed
c
satisfying (
21
).

A.4.1
Step 1: some preliminaries

First, if
1-c<(1/\alpha)^{-1/N}
, then no matter whether (
21
) holds or not, the desired bound (
22
) holds trivially, since the right-hand side of (
22
) is
>1
in this case.
Therefore we can restrict our attention to the nontrivial case where
1-c\geq(1/\alpha)^{-1/N}
.
This implies that

\tilde{\tau}=\tau\left(1+\frac{\alpha^{-1}-1}{N}\right)\geq\tau\cdot(1/\alpha)^{1/N}\geq\frac{\tau}{1-c}.

Combining this with (
21
) then yields

(1-c)\left[(1-c)^{n}\cdot R_{P,n}(\mathcal{A})+\left[1-(1-c)^{n}\right]\cdot R_{P}^{\max}\right]>\tau.

(23)

From this point on,
we let
\epsilon\in(0,c)
denote an arbitrarily small constant.
By definition of
R_{P}^{\max}
, we can find some function
f_{*}:\mathcal{X}\rightarrow\widehat{\mathcal{Y}}
such that

R_{P}(f_{*})\geq R_{P}^{\max}-\epsilon.

(24)

And, by Lemma
1
, we can find some
(x_{*},y_{*})\in\mathcal{X}\times\mathcal{Y}

such that

\mathbb{P}((x_{*},y_{*})\in\mathcal{D}_{N}\cup\mathcal{D}^{(1)}\cup\dots\cup\mathcal{D}^{({\widehat{r}})})\leq\epsilon,

(25)

where
\mathcal{D}_{N}
denotes an i.i.d. sample from
P
, and
\mathcal{D}^{(1)},\dots,\mathcal{D}^{({\widehat{r}})}
denote
the data sets constructed when running
{\widehat{T}}(\mathcal{A},\mathcal{D}_{N})
.

A.4.2
Step 2: constructing a new algorithm and a new distribution

We begin by explaining the intuition behind the construction of
P^{\prime}
and
\mathcal{A}^{\prime}
,
which is motivated by the procedure of the black-box test. As in the proof of Theorem
1
, we want
\mathcal{A}^{\prime}
to behave in the same way as
\mathcal{A}
on a typical dataset drawn from
P
, so that
{\widehat{T}}
cannot easily distinguish between
\mathcal{A}
and
\mathcal{A}^{\prime}
—but on the other hand, we want
R_{P,n}(\mathcal{A}^{\prime})\geq\tau

so that
{\widehat{T}}
is constrained to have a low probability of returning a
1
when run on
\mathcal{A}^{\prime}
(and consequently, also when run on the original algorithm of interest
\mathcal{A}
).

With this in mind, writing
P_{*}
as the distribution of
(X,Y)\sim P
conditional on the event
(X,Y)\neq(x_{*},y_{*})
, we
can express
P
as a mixture

P=(1-p_{*})\cdot P_{*}+p_{*}\cdot\delta_{(x_{*},y_{*})},

where
p_{*}=\mathbb{P}_{P}((X,Y)=(x_{*},y_{*}))
. Note that
p_{*}\leq\mathbb{P}((x_{*},y_{*})\in\mathcal{D}_{N})\leq\epsilon
by (
25
) (since
N\geq 1
), and
\epsilon\leq c
by assumption.
Now define a new distribution,

P^{\prime}=\frac{1-c}{1-p_{*}}\cdot P+\frac{c-p_{*}}{1-p_{*}}\cdot\delta_{(x_{*},y_{*})}=(1-c)\cdot P_{*}+c\cdot\delta_{(x_{*},y_{*})},

and a new algorithm
\mathcal{A}^{\prime}
, defined as

\mathcal{A}^{\prime}(\mathcal{D};\xi)=\begin{cases}\mathcal{A}(\mathcal{D};\xi),&\textnormal{ if }(x_{*},y_{*})\not\in\mathcal{D},\\
f_{*},&\textnormal{ if }(x_{*},y_{*})\in\mathcal{D}.\end{cases}

Exactly as in the proof of Theorem
1
, we can calculate

\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq\left(\frac{1-c}{1-p_{*}}\right)^{-N}\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)+\epsilon\leq(1-c)^{-N}\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)+\epsilon,

where
\mathcal{D}_{N}
,
\mathcal{D}_{N}^{\prime}
are data sets sampled i.i.d. from
P
and from
P^{\prime}
, respectively.

We will show below that the new algorithm
\mathcal{A}^{\prime}
and distribution
P^{\prime}
satisfy

R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq\tau
and
\beta_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq\gamma_{q}
, as long as we choose
\epsilon
to be sufficiently small.
This means that we must have

\mathbb{P}({\widehat{T}}(\mathcal{A}^{\prime},\mathcal{D}_{N}^{\prime})=1)\leq\alpha
, by the assumption (
9
) on the validity of
{\widehat{T}}
for testing
stable algorithms, and so we have

\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)\leq(1-c)^{-N}\alpha+\epsilon.

Since
\epsilon>0
can be chosen to be arbitrarily small, then, this verifies the bound (
22
),
which completes the proof of the theorem once we have verified the risk and stability of
(\mathcal{A}^{\prime},P^{\prime},n)
.

A.4.3
Step 3: verifying the risk

In this step we verify that
R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq\tau
.
Write
{\widehat{f}}_{n}^{\prime}=\mathcal{A}^{\prime}(\mathcal{D}_{n}^{\prime};\xi)
where
\mathcal{D}_{n}^{\prime}=\{(X_{i}^{\prime},Y_{i}^{\prime})\}
is sampled i.i.d. from
P^{\prime}
, and let
(X_{n+1}^{\prime},Y_{n+1}^{\prime})\sim P^{\prime}

be an independently drawn test point. We calculate

\displaystyle R_{P^{\prime},n}(\mathcal{A}^{\prime})

\displaystyle=\mathbb{E}\left[\ell({\widehat{f}}_{n}^{\prime}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\right]\geq\mathbb{E}\left[\ell({\widehat{f}}_{n}^{\prime}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right]

\displaystyle\geq\mathbb{E}\left[\ell({\widehat{f}}_{n}^{\prime}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(x_{*},y_{*})\not\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right]

\displaystyle\hskip 72.26999pt+\mathbb{E}\left[\ell({\widehat{f}}_{n}^{\prime}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right]

\displaystyle=\mathbb{E}\left[\ell({\widehat{f}}_{n}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(x_{*},y_{*})\not\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right]

\displaystyle\hskip 72.26999pt+\mathbb{E}\left[\ell(f_{*}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right],

where the last step holds by definition of the modified algorithm
\mathcal{A}^{\prime}
.
Since the distribution
P^{\prime}
places mass
c
on the point
(x_{*},y_{*})
, we can rewrite this as

\displaystyle R_{P^{\prime},n}(\mathcal{A}^{\prime})

\displaystyle\geq(1-c)^{n+1}\mathbb{E}\left[\ell({\widehat{f}}_{n}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\mid(x_{*},y_{*})\not\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})\right]

\displaystyle\hskip 72.26999pt+(1-c)\left[1-(1-c)^{n}\right]\cdot\mathbb{E}\left[\ell(f_{*}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\mid(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})\right].

And, since
P=(1-c)P_{*}+c\delta_{(x_{*},y_{*})}
, a data point
(X,Y)\sim P^{\prime}
has distribution
P_{*}
if we condition on the event
(X,Y)\neq(x_{*},y_{*})
.
This means that we can write

\mathbb{E}\left[\ell({\widehat{f}}_{n}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\mid(x_{*},y_{*})\not\in\mathcal{D}_{n}^{\prime},(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})\right]=R_{P_{*},n}(\mathcal{A}),

the risk of the original algorithm
\mathcal{A}
for data drawn from
P_{*}
, while

\mathbb{E}\left[\ell(f_{*}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\mid(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})\right]=R_{P_{*}}(f_{*}),

the risk of the function
f_{*}
for a test point drawn from
P_{*}
.
Therefore,

R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq(1-c)^{n+1}\cdot R_{P_{*},n}(\mathcal{A})+(1-c)\left[1-(1-c)^{n}\right]\cdot R_{P_{*}}(f_{*}).

Now we bound these remaining risk terms.
First, since
P=(1-p_{*})P_{*}+p_{*}\delta_{(x_{*},y_{*})}
, we
can relate
R_{P_{*},n}(\mathcal{A})
to
R_{P,n}(\mathcal{A})
as follows:
writing
\mathcal{D}_{n}=\{(X_{i},Y_{i})\}_{i\in[n]}
and
(X_{n+1},Y_{n+1})
to denote training
and test data points sampled i.i.d. from
P
, and
{\widehat{f}}_{n}=\mathcal{A}(\mathcal{D}_{n};\xi)
as the fitted model, we have

R_{P,n}(\mathcal{A})=\mathbb{E}\left[\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})\right]\\
\leq(1-p_{*})^{n+1}\mathbb{E}\left[\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})\mid(x_{*},y_{*})\not\in\mathcal{D}_{n}\cup\{(X_{n+1},Y_{n+1}\}\right]+\left[1-(1-p_{*})^{n+1}\right]B\\
=(1-p_{*})^{n+1}\cdot R_{P_{*},n}(\mathcal{A})+\left[1-(1-p_{*})^{n+1}\right]\cdot B\leq R_{P_{*},n}(\mathcal{A})+\epsilon(n+1)B,

since
p_{*}\leq\epsilon
and so
\left[1-(1-p_{*})^{n+1}\right]\leq\left[1-(1-\epsilon)^{n+1}\right]\leq(n+1)\epsilon
. Rearranging terms,

R_{P_{*},n}(\mathcal{A})\geq R_{P,n}(\mathcal{A})-\epsilon(n+1)B.

Similarly, we have

R_{P}(f_{*})=(1-p_{*})R_{P_{*}}(f_{*})+p_{*}\ell(f_{*}(x_{*}),y_{*})\leq(1-p_{*})R_{P_{*}}(f_{*})+p_{*}B\leq R_{P_{*}}(f_{*})+\epsilon B,

and we also know that
R_{P}(f_{*})\geq R_{P}^{\max}-\epsilon
by (
24
). So,

R_{P_{*}}(f_{*})\geq R_{P}^{\max}-\epsilon(1+B).

Combining everything, then,

R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq(1-c)^{n+1}\cdot\left[R_{P,n}(\mathcal{A})-\epsilon(n+1)B\right]+(1-c)\left[1-(1-c)^{n}\right]\cdot\left[R_{P}^{\max}-\epsilon(1+B)\right]\\
\geq(1-c)\Big[(1-c)^{n}\cdot R_{P,n}(\mathcal{A})+\left[1-(1-c)^{n}\right]\cdot R_{P}^{\max}\Big]-\epsilon\left(1+(n+1)B\right)\\
>\tau-\epsilon\left(1+(n+1)B\right),

by (
23
). We therefore have

R_{P^{\prime},n}(\mathcal{A}^{\prime})\geq\tau

for sufficiently small
\epsilon>0
, as desired.

A.4.4
Step 4: verifying the stability

In this step we verify that
\beta_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq\gamma_{q}
.
Let
(X_{1},Y_{1}),\dots,(X_{n+1},Y_{n+1})\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P
, and let
(X_{1}^{\prime},Y_{1}^{\prime}),\dots,(X_{n+1}^{\prime},Y_{n+1}^{\prime})\stackrel{{\scriptstyle\textnormal{iid}}}{{\sim}}P^{\prime}
.
Define
\mathcal{D}_{n}=\{(X_{i},Y_{i})\}_{i\in[n]}
, let
\mathcal{D}_{n+1}=\{(X_{i},Y_{i})\}_{i\in[n+1]}
, and let

\mathcal{D}_{n}^{(-j)}=\{(X_{i},Y_{i})\}_{i\in[n]\backslash\{j\}}
. Define
\mathcal{D}^{\prime}_{n}
,
\mathcal{D}^{\prime}_{n+1}
, and
\mathcal{D}^{\prime}_{n}{}^{(-j)}
analogously.
Let
{\widehat{f}}_{n}=\mathcal{A}(\mathcal{D}_{n};\xi)
and
{\widehat{f}}_{n}^{(-j)}=\mathcal{A}(\mathcal{D}_{n}^{(-j)};\xi)
, and
{\widehat{f}}_{n}^{\prime}=\mathcal{A}^{\prime}(\mathcal{D}_{n}^{\prime};\xi)
and
{\widehat{f}}_{n}^{\prime}{}^{(-j)}=\mathcal{A}^{\prime}(\mathcal{D}^{\prime}_{n}{}^{(-j)};\xi)
.

First, we work with the stability of
(\mathcal{A},P,n)
. We have

\displaystyle\gamma^{q}_{q}\geq\beta^{q}_{q}(\mathcal{A},P,n)

\displaystyle=\mathbb{E}\left[\left|\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})-\ell({\widehat{f}}_{n}^{(-j)}(X_{n+1}),Y_{n+1})\right|^{q}\right]

\displaystyle\geq\mathbb{E}\left[{\mathds{1}}_{(x_{*},y_{*})\not\in\mathcal{D}_{n+1}}\left|\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})-\ell({\widehat{f}}_{n}^{(-j)}(X_{n+1}),Y_{n+1})\right|^{q}\right]

\displaystyle=(1-p_{*})^{n+1}\cdot\mathbb{E}_{P_{*}}\left[\left|\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})-\ell({\widehat{f}}_{n}^{(-j)}(X_{n+1}),Y_{n+1})\right|^{q}\right]

\displaystyle\geq(1-\epsilon)^{n+1}\cdot\mathbb{E}_{P_{*}}\left[\left|\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})-\ell({\widehat{f}}_{n}^{(-j)}(X_{n+1}),Y_{n+1})\right|^{q}\right],

since conditional on
(x_{*},y_{*})\not\in\mathcal{D}_{n+1}
, the data points
(X_{i},Y_{i})
are i.i.d. draws from
P_{*}
, and since
p_{*}\leq\epsilon
.
Similarly, we can calculate

\displaystyle\beta^{q}_{q}(\mathcal{A}^{\prime},P^{\prime},n)

\displaystyle=\mathbb{E}\left[\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\right]

\displaystyle=\mathbb{E}\left[{\mathds{1}}_{(x_{*},y_{*})\not\in\mathcal{D}_{n+1}^{\prime}}\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\right]

\displaystyle\hskip 14.45377pt+\mathbb{E}\left[{\mathds{1}}_{(x_{*},y_{*})\in\mathcal{D}_{n+1}^{\prime}}\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\right]

\displaystyle=(1-c)^{n+1}\mathbb{E}\left[\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\ \big|\ (x_{*},y_{*})\not\in\mathcal{D}_{n+1}^{\prime}\right]

\displaystyle\hskip 14.45377pt+\left[1-(1-c)^{n+1}\right]\mathbb{E}\left[\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\ \big|\ (x_{*},y_{*})\in\mathcal{D}_{n+1}^{\prime}\right].

Next, on the event

(x_{*},y_{*})\not\in\mathcal{D}_{n+1}^{\prime}
, we have
{\widehat{f}}^{\prime}_{n}={\widehat{f}}_{n}
and
{\widehat{f}}^{\prime}_{n}{}^{(-j)}={\widehat{f}}_{n}^{(-j)}
, and the data points
(X_{i}^{\prime},Y_{i}^{\prime})
are i.i.d. draws from
P_{*}
.
So,

\mathbb{E}\left[\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\ \big|\ (x_{*},y_{*})\not\in\mathcal{D}_{n+1}^{\prime}\right]\\
=\mathbb{E}_{P_{*}}\left[\left|\ell({\widehat{f}}_{n}(X_{n+1}),Y_{n+1})-\ell({\widehat{f}}_{n}^{(-j)}(X_{n+1}),Y_{n+1})\right|^{q}\right]\leq(1-\epsilon)^{-(n+1)}\cdot\gamma^{q}_{q}.

And, if
(x_{*},y_{*})\in\mathcal{D}^{\prime}_{n}{}^{(-j)}
, then
{\widehat{f}}^{\prime}_{n}={\widehat{f}}^{\prime}_{n}{}^{(-j)}
, so

\mathbb{E}\left[\left|\ell({\widehat{f}}^{\prime}_{n}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})-\ell({\widehat{f}}^{\prime}_{n}{}^{(-j)}(X^{\prime}_{n+1}),Y^{\prime}_{n+1})\right|^{q}\ \big|\ (x_{*},y_{*})\in\mathcal{D}_{n+1}^{\prime}\right]\\
\leq B^{q}\cdot\mathbb{P}((x_{*},y_{*})\not\in\mathcal{D}^{\prime}_{n}{}^{(-j)}\mid(x_{*},y_{*})\in\mathcal{D}_{n+1}^{\prime})\leq B^{q}\cdot\frac{2}{n+1},

where the last step holds since data points
\{(X_{i}^{\prime},Y_{i}^{\prime})\}_{i\in[n+1]}
are exchangeable, so if
(x_{*},y_{*})
appears at least once in a data set of size
n+1
,
with probability at least
\frac{n-1}{n+1}
it appears in the subset given by the
n-1
many indices
[n]\backslash\{j\}
.
Combining these calculations,

\beta^{q}_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq(1-c)^{n+1}\cdot(1-\epsilon)^{-(n+1)}\cdot\gamma^{q}_{q}+\left[1-(1-c)^{n+1}\right]\cdot B^{q}\cdot\frac{2}{n+1}.

By assumption,
\gamma^{q}_{q}\geq B^{q}\cdot\frac{2}{n}
, so
we have

\beta^{q}_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq\gamma^{q}_{q}\cdot\left[(1-c)^{n+1}\cdot(1-\epsilon)^{-(n+1)}+\left[1-(1-c)^{n+1}\right]\cdot\frac{n}{n+1}\right].

Since
c>0
, we therefore have
\beta^{q}_{q}(\mathcal{A}^{\prime},P^{\prime},n)\leq\gamma^{q}_{q}
for sufficiently small
\epsilon>0
, as desired.

(29)

And, by Lemma

P

We will show below that the new algorithms

\psi

For each
l=0,1

\displaystyle\mathbb{E}\left[\ell({\widehat{f}}_{l,n}^{\prime}(X_{n+1}^{\prime}),Y_{n+1}^{\prime})\cdot{\mathds{1}}_{(X_{n+1}^{\prime},Y_{n+1}^{\prime})\neq(x_{*},y_{*})}\right]

C.1
Proof of Theorem
3

First, we have
S\sim\text{Binomial}(\lfloor N/(n+1)\rfloor,R_{P,n}(\mathcal{A}))
by construction. First, we verify the validity of this test. Fix any
\mathcal{A}
,
P
with

\begin{split}\mathbb{P}({\widehat{T}}(\mathcal{A},\mathcal{D}_{N})=1)&=\mathbb{P}(S<k_{*})+a_{*}\mathbb{P}(S=k_{*})\\

where the last step holds by our choice of

\displaystyle\mathbb{E}\left[\left(R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j-1)})\big)-R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j)})\big)\right)^{2}\right]

\displaystyle=\mathbb{E}\left[2\textnormal{Var}\left(R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j-1)})\big)\mid\tilde{\mathcal{D}}_{n}^{(j)}\right)\right]

\displaystyle\leq\mathbb{E}\left[2\mathbb{E}\left[\left(R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j-1)})\big)-R_{P}\big(\mathcal{A}(\tilde{\mathcal{D}}_{n}^{(j)})\big)\right)^{2}\mid\tilde{\mathcal{D}}_{n}^{(j)}\right]\right]

\displaystyle=2\mathbb{E}\left[\left(R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j-1)})\big)-R_{P}\big(\mathcal{A}(\tilde{\mathcal{D}}_{n}^{(j)})\big)\right)^{2}\right]

\displaystyle\leq 2\beta_{2}^{2}(\mathcal{A},P,n),

where the last inequality holds by definition of
\ell_{2}
-stability.
This is true for each
j=1,\dots,n
. Therefore, by the Efron–Stein Inequality
(
Efron and Stein, 1981
;
Steele, 1986
)
,
since
R_{P,n}(\mathcal{A})=\mathbb{E}[R_{P}({\widehat{f}}_{n})]
,
it holds that

\mathbb{E}\left[\left(R_{P}({\widehat{f}}_{n})-R_{P,n}(\mathcal{A})\right)^{2}\right]\leq\frac{1}{2}\sum_{j=1}^{n}\mathbb{E}\left[\left(R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j-1)})\big)-R_{P}\big(\mathcal{A}(\mathcal{D}_{n}^{(j)})\big)\right)^{2}\right]=n\beta_{2}^{2}(\mathcal{A},P,n).

This completes the proof for
q=2
.
