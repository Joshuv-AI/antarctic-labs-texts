Set-Theoretic and Type-Theoretic Ordinals Coincide PubID: pubid: 979-8-3503-3587-3/23/$31.00 ©2023 IEEE
Tom de Jong 1 , Nicolai Kraus 1 , Fredrik Nordvall Forsberg 2 and Chuangjie Xu 3

Abstract
In constructive set theory, an ordinal is a hereditarily transitive set. In homotopy type theory (HoTT), an ordinal is a type with a transitive, wellfounded, and extensional binary relation. We show that the two definitions are equivalent if we use (the HoTT refinement of) Aczel’s interpretation of constructive set theory into type theory. Following this, we generalize the notion of a type-theoretic ordinal to capture all sets in Aczel’s interpretation rather than only the ordinals. This leads to a natural class of ordered structures which contains the type-theoretic ordinals and realizes the higher inductive interpretation of set theory. All our results are formalized in Agda.

[

]
. This original

II
Ordinals in type theory and set theory

We start by reviewing both the set-theoretic and type-theoretic approaches to
ordinals.
We then recall the higher inductive construction of a model of constructive set
theory in homotopy type theory
[
9
, §10.5]
,
allowing us to consider the set-theoretic ordinals inside homotopy type theory,
and to prove that they coincide with the type-theoretic ordinals.
Finally, we revisit a recursive aspect of our proof and provide alternative
non-recursive constructions, which require paying close attention to type
universe levels.

II-A

Ordinals in homotopy type theory

The theory of ordinals in homotopy type theory was introduced in the HoTT

[

Cantor’s original definition of ordinal numbers was that of isomorphism

representatives of a given isomorphism class in homotopy type theory

Hence, we can use the well-ordered sets directly to represent ordinals.

Constructively, the following (classically equivalent) formulation is better behaved.

In constructive set theory, following Powell
[

]
, the standard

Definition 16

A set

Note how this definition makes essential use of how the membership

Example 17

The sets

Definition 18

.

A
set-theoretic ordinal
is a hereditarily transitive set, i.e., a
transitive set whose elements are all transitive sets.

The first three sets of
Example

17
are all ordinals, but the
fourth is not, because its member
\{\{\emptyset\}\}
is non-transitive.

The elements of an ordinal are not only transitive sets: they are in fact
ordinals again, as shown by the following standard argument.

Lemma 19

(

)
.

Being an ordinal is hereditary: the elements of a set-theoretic ordinal are
themselves ordinals.

Proof.

Let
x
be a set-theoretic ordinal and
y\in x
. Then
y
is a
transitive set by assumption. Moreover, if
z\in y
, then
z
is again a
transitive set, because
z\in x
by transitivity of
x
.
∎

II-C

Set theory in homotopy type theory

In order to relate the set-theoretic and type-theoretic approaches to ordinals,
we recall a higher inductive
[
9
, §6]
construction of a model
of constructive set theory inside homotopy type theory
from
[
9
, §10.5]
.
The model may be seen as a refinement of Aczel’s
[
10
]
interpretation
of constructive set theory in type theory, and is referred to as the

cumulative hierarchy
in the HoTT book
[
9
]
and the

iterative hierarchy
in Gylterud
[
23
]
.

It is convenient to introduce the following terminology before proceeding.

Definition 20

(

Equal images)
.

Two maps
f:A\to X
and
g:B\to X
with the same codomain are said
to have
equal images
if for every
a:A
, there exists some

b:B
such that
f\,a=g\,b
, and conversely, for every
b:B
,
there exists some
a:A
with
g\,b=f\,a
.

Definition 21

(

Cumulative hierarchy
\mathbb{V}
;
[
9
, Def 10.5.1]
)
.

The
cumulative hierarchy

\mathbb{V}
with respect to a type universe
\mathcal{U}

is the higher inductive type with the following constructors:

(i)

for every type
A:\mathcal{U}
and
f:A\to\mathbb{V}
we have an element of

\mathbb{V}
, denoted by
\Vsetop\left(A,f\right)
;

(ii)

for every two types
A,B:\mathcal{U}
and maps
f:A\to\mathbb{V}
and

g:B\to\mathbb{V}
, if
f
and
g
have equal images, then we have an
identification
\Vsetop\left(A,f\right)=\Vsetop\left(B,g\right)
;

(iii)

set-truncation, i.e., for every
x,y:\mathbb{V}
and
p,q:x=y
, we
have an identification
p=q
.

\mathbb{V}
is a model of set theory by
[
9
, Thm 10.5.8]
.
It is instructive to see how to represent the sets
\emptyset
,

\{\emptyset\}
and
\{\emptyset,\{\emptyset\}\}

from
Example

17
in
\mathbb{V}
:

•

The empty set
\emptyset
is represented as

\raise 0.5776pt\hbox{$\ulcorner$}\hbox{$\emptyset$}\raise 0.5776pt\hbox{$\urcorner$}\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\Vsetop\left(\mathbf{0},!\right)
where

is the
unique map from
\mathbf{0}
to
\mathbb{V}
.

•

The singleton set
\{\emptyset\}
may be represented by setting

\raise 0.5776pt\hbox{$\ulcorner$}\hbox{$\{\emptyset\}$}\raise 0.5776pt\hbox{$\urcorner$}\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\Vsetop\left(\mathbf{1},\mathop{\lambda}{\star}\mathrel{.}\raise 0.5776pt\hbox{$\ulcorner$}\hbox{$\emptyset$}\raise 0.5776pt\hbox{$\urcorner$}\right)
.

•

Finally, the set
\{\emptyset,\{\emptyset\}\}
can be encoded as

\Vsetop\left(\mathbf{2},f\right)
where
f(0)\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\raise 0.5776pt\hbox{$\ulcorner$}\hbox{$\emptyset$}\raise 0.5776pt\hbox{$\urcorner$}
and

f(1)\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\raise 0.5776pt\hbox{$\ulcorner$}\hbox{$\{\emptyset\}$}\raise 0.5776pt\hbox{$\urcorner$}

The second constructor of
\mathbb{V}
ensures that the elements have the correct

means that the elements
\Vsetop\left(\mathbf{2},f\right)

Observe that
\mathbb{V}
is a large type, i.e., it lives in the next universe

\mathcal{U}^{+}
. Following
[
9
, §10.5]
, we now define the set
membership and the subset relation on

, so that we can define

\mathbb{V}
.

Definition 22

(

Set membership

on
\mathbb{V}
)
.

We define the

relation

{\in}:\mathbb{V}\to\mathbb{V}\to\Prop_{\mathcal{U}^{+}}
inductively as:

x\in\Vsetop\left(A,f\right)\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\exists(a:A).{f\,a=x}.

This is well-defined because
\Prop_{\mathcal{U}^{+}}
is a set (in the sense of HoTT),
and if
f
and
g
have equal images, then
{x\in\Vsetop\left(A,f\right)}
holds
exactly when
x\in\Vsetop\left(B,g\right)
does.

Definition 23

(

Subset relation
\subseteq
)
.

We define the
subset relation

{\subseteq}:{\mathbb{V}\to\mathbb{V}\to\Prop_{\mathcal{U}^{+}}}
as

x\subseteq y\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\forall(v:\mathbb{V}).{v\in x\to v\in y}.

The type
\mathbb{V}
models Myhill’s Constructive Set Theory
[
23
]
, and
in fact all of Zermelo-Fraenkel set theory with Choice, if we assume the axiom
of choice in type theory
[
27
]
. In the following, we will in
particular need the following two set-theoretic axioms:

Lemma 24

(

Items (i) and (vii) of
[
9
, Thm 10.5.8]
)
.

The following two set-theoretic axioms are satisfied by
\mathbb{V}
:

(i)

extensionality:
two elements
x
and
y
of
\mathbb{V}
are equal
if and only if
x\subseteq y
and
y\subseteq x
, and

(ii)

\in
-induction:
for any prop-valued family

P:\mathbb{V}\to\Prop
, if, for every
x:\mathbb{V}
, we have
P(x)
whenever

P(y)
holds for all
y\in x
, then

holds at every element of

\mathbb{V}
. ∎

The set membership relation allows us to formulate the set-theoretic notions
of
Section

II-B
for
\mathbb{V}
, and hence, to define the type
of set-theoretic ordinals in
\mathbb{V}
.

Definition 25

(

Type of set-theoretic ordinals)
.

The
type
\mathbb{V}_{\textup{ord}}
of set-theoretic ordinals
is the
\Sigma
-type of
those
x:\mathbb{V}
such that
x
is a set-theoretic ordinal in the sense
of
Definition

18
.

The subtype of set-theoretic ordinals is then an example of a type-theoretic
ordinal, which we show to be equal to the type
\mathsf{Ord}
of type-theoretic
ordinals in the next subsection.

Theorem 26

(

)
.

Set membership makes
\mathbb{V}_{\textup{ord}}
into a type-theoretic ordinal.

Proof.

Wellfoundedness follows from
\in
-induction, and set membership is a
transitive relation on
\mathbb{V}_{\textup{ord}}
: if we have set-theoretic ordinals

x,y,z:\mathbb{V}_{\textup{ord}}
such that
x\in y
and
y\in z
, then
x\in z
,
because
z
is a transitive set.
For extensionality, assume that we have
x,y:\mathbb{V}_{\textup{ord}}
such that

u\in x\leftrightarrow u\in y
for every
u:\mathbb{V}_{\textup{ord}}
. We need to show that
x=y
. By extensionality
in the sense of
Lemma

24
, it suffices to show that

v\in x\leftrightarrow v\in y
for all
v:\mathbb{V}
.
But if
v\in x
, then
v:\mathbb{V}_{\textup{ord}}
, because being a set-theoretic ordinal
is hereditary (

). Hence,

v\in y
by assumption. Similarly,
v\in y
implies
v\in x
, so that

x=y
, as desired.
∎

II-D

Set-theoretic and type-theoretic ordinals coincide

Having reviewed the necessary preliminaries, we prove in this subsection that
the set-theoretic and type-theoretic ordinals coincide. More precisely, we
construct an isomorphism of type-theoretic ordinals between
\mathbb{V}_{\textup{ord}}
and

\mathsf{Ord}
by constructing maps in both directions.

Definition 27

(

\Phi
)
.

The map
\Phi:\mathsf{Ord}\to\mathbb{V}
is defined by transfinite recursion on

\mathsf{Ord}
as

\Phi(\alpha)\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\Vsetop\left(\alpha,\mathop{\lambda}{a}\mathrel{.}\Phi(\alpha\mathbin{\downarrow}a)\right)

The function
\Phi
is well-defined, because for every
a:\alpha
, the initial segment

\alpha\mathbin{\downarrow}a
is strictly smaller than
\alpha
, as
ordinals.

Lemma 28

(

)
.

The map
\Phi
is injective and preserves and reflects the strict and weak
orders, i.e., for every two type-theoretic ordinals
\alpha,\beta:\mathsf{Ord}
,
we have

(i)

\alpha=\beta\;\leftrightarrow\;\Phi\,\alpha=\Phi\,\beta
,

(ii)

\alpha<\beta\;\leftrightarrow\;\Phi\,\alpha\in\Phi\,\beta
, and

(iii)

\alpha\leq\beta\;\leftrightarrow\;\Phi\,\alpha\subseteq\Phi\,\beta
.

Proof.

That
\Phi
preserves equality is automatic.

\alpha<\beta\Rightarrow\Phi\,\alpha\in\Phi\,\beta

If
\alpha<\beta
, then we have
b:\beta
such that

\alpha=\beta\mathbin{\downarrow}b
. Hence, in this case, we have

\Phi\,\alpha=\Phi(\beta\mathbin{\downarrow}b)
, viz.
\Phi\,\alpha\in\Phi\,\beta
by the definitions of
{\in}

and
\Phi
.

\alpha\leq\beta\Rightarrow\Phi\,\alpha\subseteq\Phi\,\beta

For
x\in\Phi\,\alpha
, we get an
a
with
x=\Phi(\alpha\mathbin{\downarrow}a)

by definition.
Proposition

9
gives us
b
such that

\alpha\mathbin{\downarrow}a=\beta\mathbin{\downarrow}b
, and hence
x\in\Phi\,\beta
,
as desired.

Injectivity –
\Phi\,\alpha=\Phi\,\beta\Rightarrow\alpha=\beta

We do transfinite induction on

\mathsf{Ord}
. Assume
\alpha:\mathsf{Ord}
and the induction hypothesis:
for every element
a:\alpha
and ordinal
\beta:\mathsf{Ord}
, if

\Phi(\alpha\mathbin{\downarrow}a)=\Phi\,\beta
, then

\alpha\mathbin{\downarrow}a=\beta
. We must prove that

\Phi\,\alpha=\Phi\,\beta
implies
\alpha=\beta
for all ordinals

\beta:\mathsf{Ord}
.
So assume that
\beta:\mathsf{Ord}
is such that

\Phi\,\alpha=\Phi\,\beta
. We show that
\alpha\leq\beta
; the
reverse inequality is proved similarly. By
Proposition

9
, it
suffices to prove that
\alpha\mathbin{\downarrow}a<\beta
for every
a:\alpha
.
For such
a:\alpha
we have

\Phi(\alpha\mathbin{\downarrow}a)\in\Phi\,\alpha=\Phi\,\beta
, and hence, there
exists some
b:\beta
with

\Phi(\alpha\mathbin{\downarrow}a)=\Phi(\beta\mathbin{\downarrow}b)
. Our induction hypothesis
then yields
\alpha\mathbin{\downarrow}a=\beta\mathbin{\downarrow}b
, and hence the desired

\alpha\mathbin{\downarrow}a<\beta
.

\Phi\,\alpha\in\Phi\,\beta\Rightarrow\alpha<\beta

If
\Phi\,\alpha\in\Phi\,\beta
, then there exists some
b:\beta

with
\Phi\,\alpha=\Phi(\beta\mathbin{\downarrow}b)
, and hence
\alpha<\beta

by injectivity of
\Phi
.

\Phi\,\alpha\subseteq\Phi\,\beta\Rightarrow\alpha\leq\beta

Suppose
\Phi\,\alpha\subseteq\Phi\,\beta
. Then for every

a:\alpha
, there exists some
b:\beta
with

{\Phi(\alpha\mathbin{\downarrow}a)=\Phi(\beta\mathbin{\downarrow}b)}
.
Injectivity of
\Phi
and
Proposition

9

imply
\alpha\leq\beta
.
∎

Lemma 29

(

)
.

The map
\Phi:\mathsf{Ord}\to\mathbb{V}
factors through the inclusion

\mathbb{V}_{\textup{ord}}\hookrightarrow\mathbb{V}
.

Proof.

We first show directly that
\Phi\,\alpha
is a transitive set for every

\alpha:\mathsf{Ord}
: if we have
x,y:\mathbb{V}
with

x\in y\in\Phi\,\alpha
, then there exists
a:\alpha
with

x=\Phi(\alpha\mathbin{\downarrow}a)
and hence
b:\alpha\mathbin{\downarrow}a
with

y=\Phi\left(\left(\alpha\mathbin{\downarrow}a\right)\mathbin{\downarrow}b\right)
. But

(\alpha\mathbin{\downarrow}a)\mathbin{\downarrow}b
and
\alpha\mathbin{\downarrow}b
are equal
ordinals by
Lemma

11
, so

y=\Phi(\alpha\mathbin{\downarrow}b)
and thus
y\in\Phi\,\alpha
, as desired.

Now we prove that
\Phi\,\alpha
is a set-theoretic ordinal for every

\alpha:\mathsf{Ord}
by transfinite induction on
\mathsf{Ord}
. We just established
that
\Phi\,\alpha
is a transitive set and if
x\in\Phi\,\alpha
, then

x=\Phi(\alpha\mathbin{\downarrow}a)
for some
a:\alpha
, so that
x
must be
a transitive set by the induction hypothesis.
∎

Thus, one half of the desired isomorphism is given by

{\Phi:\mathsf{Ord}\to\mathbb{V}_{\textup{ord}}}
. We define a map in the other direction now.

Definition 30

(

\Psi
)
.

We define
\Psi:\mathbb{V}\to\mathsf{Ord}
recursively by

\Psi(\Vsetop\left(A,f\right))\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\bigvee_{a:A}\left(\Psi(f\,a)+\mathbf{1}\right).

This map is well-defined because
\mathsf{Ord}
is a set, and if
f
and
g

have equal images then the suprema
\Psi(\Vsetop\left(A,f\right))
and

\Psi(\Vsetop\left(B,g\right))
are seen to coincide.

Remark 31
.

This function above assigns the
rank
to a set and is well-known in set
theory, see for example
[
2
, p. 743]

and
[
8
, Def 9.3.4]
.

Proposition 32

(

)
.

When restricted to
\mathbb{V}_{\textup{ord}}
, the map
\Psi
is a section of
\Phi
, i.e.,
for
x:\mathbb{V}_{\textup{ord}}
, we have
\Phi(\Psi\,x)=x
.

Proof.

Since we are proving a proposition, the induction principle of
\mathbb{V}
implies
that it suffices to prove that for every
A:\mathcal{U}
and
f:A\to\mathbb{V}
such
that
\Vsetop\left(A,f\right)
is a set-theoretic ordinal, the equality

\Phi(\Psi(\Vsetop\left(A,f\right)))=\Vsetop\left(A,f\right)
holds, assuming the
induction
hypothesis
:
\Phi(\Psi(f\,a))=f\,a
holds for all
a:A
.
(Note that every
f\,a
is a set-theoretic ordinal if
\Vsetop\left(A,f\right)
is.)
We compute that

\Phi(\Psi(\Vsetop\left(A,f\right)))=\Vsetop\left(s,\mathop{\lambda}{y}\mathrel{.}\Phi\left(s\mathbin{\downarrow}y\right)\right),

where
s\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\bigvee_{a:A}\left(\Psi(f\,a)+\mathbf{1}\right)
.
We now use the second constructor of
\mathbb{V}
to prove that

\Vsetop\left(s,\mathop{\lambda}{y}\mathrel{.}\Phi\left(s\mathbin{\downarrow}y\right)\right)
is equal to

\Vsetop\left(A,f\right)
, i.e., we show that
\mathop{\lambda}{y}\mathrel{.}\Phi\left(s\mathbin{\downarrow}y\right)

and
f
have the same image.
It is convenient to set up some notation: we write
c_{a}
for

\Psi(f\,a)+\mathbf{1}
.

In one direction, suppose that
a:A
, then

f\,a=\Phi(\Psi(f\,a))=\Phi\left({c_{a}}\mathbin{\downarrow}{\inr\star}\right)=\Phi\left(s\mathbin{\downarrow}[a,\inr\star]\right),

where the first equality holds by induction hypothesis and the second and
third by
Lemmas

13
and
15
,
respectively.

Conversely, if we have
y:s
, then by
Lemma

15

there exist some
a:A
and
w:c_{a}
such that

s\mathbin{\downarrow}y=c_{a}\mathbin{\downarrow}w
.
There are now two cases: either
w=\inr\star
or
w=\inl x
with

x:\Psi(f\,a)
.
If
w=\inr\star
, then, as before,

\Phi(s\mathbin{\downarrow}y)=\Phi(c_{a}\mathbin{\downarrow}\inr\star)=\Phi(\Psi(f\,a))=f\,a.

So suppose that
w=\inl x
with
x:\Psi(f\,a)
. It is here that we
use our assumption that
\Vsetop\left(A,f\right)
is a set-theoretic ordinal.
Indeed, since
\Psi(f\,a)\mathbin{\downarrow}x
is an initial segment of

\Psi(f\,a)
, we have

\Phi(\Psi(f\,a)\mathbin{\downarrow}x)\in\Phi(\Psi(f\,a))=f\,a

by
Lemma

28
and the induction hypothesis.
But
f\,a\in\Vsetop\left(A,f\right)
and the latter is a transitive set, so

\Phi(\Psi(f\,a)\mathbin{\downarrow}x)\in\Vsetop\left(A,f\right)
.
By definition of set membership, this means that there exists some
a^{\prime}:A

with
\Phi(\Psi(f\,a)\mathbin{\downarrow}x)=f(a^{\prime})
.
Finally,

\Phi(s\mathbin{\downarrow}y)=\Phi(c_{a}\mathbin{\downarrow}\inl x)=\Phi(\Psi(f\,a)\mathbin{\downarrow}x)=f(a^{\prime}),

where the second equality holds by
Lemma

13
.
Hence,
f
and
\Phi(s\mathbin{\downarrow}-)
have the same image,
completing the proof.
∎

We are now ready to prove the main theorem of
Section

II
: the
type-theoretic and set-theoretic ordinals coincide.

Theorem 33

(

)
.

The ordinals
\mathsf{Ord}
and
\mathbb{V}_{\textup{ord}}
are isomorphic (as type-theoretic
ordinals). Hence, by univalence, they are equal.

Proof.

By
Lemma

29
we have a map
\Phi:\mathsf{Ord}\to\mathbb{V}_{\textup{ord}}
. Moreover, it is an injection by
Lemma

28
and a (split)
surjection by
Proposition

32
. Hence,
\Phi
is a
bijection. But
Lemma

28
tells us that it also preserves and
reflects the strict orders, so it is an isomorphism of ordinals
by
Lemma

10
.
∎

II-E

Revisiting the rank of a set

The recursive nature of the map
\Psi
from
Definition

30
that computes the rank
of a set in
\mathbb{V}
is convenient for proving properties by induction. It is
possible, however, to give a conceptually simpler and non-recursive
description, although this requires paying close attention to size issues.

Definition 34

(

Type of elements,
\totalspace x
)
.

Given an element
{x:\mathbb{V}}
, we write
\totalspace x
for its type of
elements, i.e.,

\totalspace x\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\Sigma(y:\mathbb{V}).{y\in x}.

Proposition 35

(

)
.

If
x:\mathbb{V}
is a set-theoretic ordinal, then
\totalspace x
ordered by

{\in}
is a type-theoretic ordinal.

Proof.

Since being a set-theoretic ordinal is hereditary, we have

\totalspace x=\Sigma(y:\mathbb{V}_{\textup{ord}}).{y\in x}
, so that the
former inherits the ordinal structure from
\mathbb{V}_{\textup{ord}}
.
∎

It now becomes important to pay close attention to type universe parameters, so
we will annotate them with subscripts. Notice that the
\totalspace
-operation
does not define a map
\mathbb{V}_{\mathcal{U}}\to\mathsf{Ord}_{\mathcal{U}}
like
\Psi
does, but rather a
map
\mathbb{V}_{\mathcal{U}}\to\mathsf{Ord}_{\mathcal{U}^{+}}
, because the cumulative hierarchy
\mathbb{V}_{\mathcal{U}}
with
respect to the universe
\mathcal{U}
is itself a type in the next universe
\mathcal{U}^{+}
.

Still, we will prove that
\Psi(x)
and
\totalspace x
are

isomorphic
ordinals for every set-theoretic ordinal
x:\mathbb{V}_{\mathcal{U}}
, even
though they cannot be equal due to their different sizes.
However, we can do a bit better by observing, as in the HoTT book
[
9
, Lem 10.5.5]
,
that the cumulative hierarchy is locally small (in the sense of
Rijke
[
28
]
), meaning its identity types are
\mathcal{U}
-valued up to
equivalence. Then we observe that
\totalspace(\Vsetop\left(A,f\right))
is equal to the
image of
f
, which is equivalent to a type in
\mathcal{U}
thanks to the fact that

\mathbb{V}
is a locally small set.
This general fact on small images of maps into locally small sets is a “set
replacement principle”, discussed by Rijke
[
28
]
and
de Jong and Escardó
[
26
]
.
Specifically, the image of
f
is equivalent to the set quotient
A/{\sim}
,
where
A
is the domain of
f
and
{\sim}
relates two elements if
f

identifies them. We then make the quotient
A/{\sim}
into an ordinal by
defining
[a]<[b]
as
f\,a\in f\,b
.
Finally, we can resize
A/{\sim}
to an ordinal in
\mathcal{U}
by using that

\mathbb{V}
is locally small and by employing a
\mathcal{U}
-valued membership relation,
as explained below.

We stress that none of the above constructions rely on propositional resizing
principles.

II-E
1
The cumulative hierarchy is locally small

We again follow
[
9
, §10.5]
in defining a recursive
bisimulation relation that makes
\mathbb{V}
a locally small type.

Definition 36

(

[
9
, Def 10.5.4]
)
.

The

\displaystyle\hskip 3.0pt\times\left(\forall(b:B).\exists(a:A).{g\,b\approx f\,a}\right).

Lemma 37

(

[

]
)

For every

, we have an equivalence of propositions

Hence, the bisimulation relation captures equality on

.
This also allows us to define a

-valued membership relation.

(

)

inductively by

Lemma 39

(

)
.

For every
x,y:\mathbb{V}_{\mathcal{U}}
, we have an equivalence of propositions

.

Proof.

By
\mathbb{V}
-induction and
Lemma

37
.
∎

II-E
2
The set quotients

Throughout this subsection, assume that we are given

and

such that
\Vsetop\left(A,f\right)
is a set-theoretic ordinal.
We show that the type of elements of
\Vsetop\left(A,f\right)
is given by a suitable
quotient of

III
Generalizing from ordinals to sets

Since we now understand the subtype of
\mathbb{V}
that consists of exactly the
hereditarily transitive sets, it is a natural goal to characterize the full type

\mathbb{V}

{\lx@inpgf@ignorespaces\mathbb{V}_{\textup{ord}}}
{\lx@inpgf@ignorespaces\mathsf{Ord}}
{\lx@inpgf@ignorespaces\mathbb{V}}
{\lx@inpgf@ignorespaces?}
\scriptstyle{\lx@inpgf@ignorespaces\simeq}
\scriptstyle{\lx@inpgf@ignorespaces\simeq}

to complete the square on the left, by generalizing the notion of type-theoretic
ordinals.
Since arbitrary

certainly need to give up transitivity. However, as discussed in the
introduction, doing so and simply considering
extensional wellfounded

is insufficient to complete the square. Our solution is to further
equip them with
covering markings
. We then develop a generalization of
the theory of type-theoretic ordinals that matches

Giving up transitivity as an assumption, we at times need to consider the
transitive and reflexive-transitive closure of a given relation

smallest proposition-valued such relations that include

\mathrel{<^{+}}
and
\mathrel{<^{*}}
respectively. In type theory, it is standard to implement
\mathrel{<^{+}}
and
\mathrel{<^{*}}
using inductive
families describing sequences of steps, which then can be propositionally
truncated to ensure proof-irrelevance.

III-A

Mewos: marked extensional wellfounded order relations

We start by defining the generalization of type-theoretic ordinals that we need
to complete the above square.

Definition 47

(

A

As for ordinals, the extensionality of the relation

Further note that, by univalence, an equality

Our second main result is that

{\lx@inpgf@ignorespaces\mathsf{Ord}}
{\lx@inpgf@ignorespaces\mathbb{V}}
{\lx@inpgf@ignorespaces{\mathsf{MEWO}_{\mathsf{cov}}}}

III-B

The main concepts that we need to generalize from type-theoretic ordinals are

(

)

The arguments are copies of the proofs for type-theoretic ordinals

For type-theoretic ordinals, a bounded simulation is a simulation whose domain

III-C

Subtleties caused by markings

Observing how bounded simulations interact with other (possibly bounded)
simulations reveals the complete change of view we are forced to make when
generalizing from ordinals to mewos. This is indeed intended since we claim
(and prove) that
\leq
and
<
correspond to
\subseteq
and
\in
, and for
arbitrary sets, the latter relations fail to have many properties that one might
associate with the former relations.

The first point is that
X<Y
generally does not imply
X\leq Y
. A bounded
simulation
X<Y
gives rise to a function
f:X\to Y
via the composition of
the function underlying
e:X=(Y\mathop{\downarrow^{+}}y)
and the first projection

(Y\mathop{\downarrow^{+}}y)\to Y
. However, the first projection is in general not a
simulation as it may not preserve markings.
A counter-example is the covered mewo
\circ\leftarrow\bullet
, i.e., the mewo
with two comparable elements, the larger of which is marked (denoted by

\bullet
), while the smaller is not (denoted by
\circ
). Since

(\circ\leftarrow\bullet)\mathop{\downarrow^{+}}\bullet
is, by definition, simply
\bullet
,
there is a bounded simulation from
\bullet
to
\circ\leftarrow\bullet
.
However, there is no simulation as the marking is not preserved. The crux here
is that the operation
\mathop{\downarrow^{+}}
changes the marking.
The translation to the language of sets is that
\{\emptyset\}
is an element,
but not a subset, of
\{\{\emptyset\}\}
.

Secondly, the
<
relation on mewos is not transitive. The principle that
“an initial segment of an initial segment is an initial segment” does not
hold. A simple counter-example is the empty mewo
\emptyset
together with

\bullet
and
\circ\leftarrow\bullet
. We have bounded simulations

\emptyset<\bullet<(\circ\leftarrow\bullet)
, but no bounded simulation

\emptyset<(\circ\leftarrow\bullet)
. In this case, the translation is that

\emptyset
is an element of
\{\emptyset\}
, which itself is an element of

\{\{\emptyset\}\}
; the latter however does not have
\emptyset
as an element.

For technical reasons, it is occasionally useful to use mewos that ensure that
the discussed properties do hold. This can be achieved by changing the marking
to the trivial one:

Definition 56

(

Trivializing the marking,

\overline{X}
)
.

If
X
is a mewo, we write
\overline{X}
for the mewo that has the same
carrier and order as
X
, but where every element is marked.

In the language of
\mathbb{V}
-sets,
\overline{X}
is the union of all the sets
represented by elements (of elements of elements …) of
X
. Note that

\overline{X}
is still not transitive and thus not a type-theoretic
ordinal. Nevertheless, this operation allows us to recover several important
properties of type-theoretic ordinals:

Lemma 57

(

)
.

For given mewos
X
,
Y
, and
Z
, we have:

(i)

for every
x:X
, the first projection
(X\mathop{\downarrow^{+}}x)\to\overline{X}
is a
simulation;

(ii)

X<Y\to X\leq\overline{Y}
;

(iii)

X<Y\to Y<Z\to X<\overline{Z}
.

Proof.

As the conditions involving markings now are vacuously true, the arguments for
type-theoretic ordinals apply.
∎

As a demonstration of how this is useful, we can show the following technical lemma:

Lemma 58

(

)
.

Given a mewo
X
, the function
x\mapsto X\mathop{\downarrow^{+}}x
is injective:

(X\mathop{\downarrow^{+}}x_{1})=(X\mathop{\downarrow^{+}}x_{2})
implies
x_{1}=x_{2}
.

Proof.

We show that

implies that any
predecessor of
x_{1}
is also a predecessor of
x_{2}
; extensionality of
X

then gives the claimed injectivity.
To do this, let us consider the following diagram:

X\mathop{\downarrow^{+}}x_{1}
\overline{X}
X\mathop{\downarrow^{+}}x_{2}
f
\mathsf{fst}
\mathsf{fst}

All maps are simulations and, by uniqueness of simulations
(
Lemma

51
), the diagram necessarily commutes.
Given a predecessor
{x<x_{1}}
, it is marked in
X\mathop{\downarrow^{+}}x_{1}
by
construction, and since

preserves markings,

is marked as well,
i.e., we have

. But since the diagram commutes, we have

as elements of

.
∎

A consequence is that bounded simulations are unique:

Corollary 59

(

)
.

For mewos
X
and
Y
, the type

of bounded simulations is a

Proof.

By definition,
X<Y\equiv\Sigma(y:Y).(X=(Y\mathop{\downarrow^{+}}y))
. Assume

(y,p),(y^{\prime},q):X<Y
. By the above lemma, we then have
y=y^{\prime}
since

(Y\mathop{\downarrow^{+}}y)=X=(Y\mathop{\downarrow^{+}}y^{\prime})
, and

since
\mathsf{MEWO}
is a set. Hence

, as desired.
∎

III-D

Simulations and coverings

As we have seen, bounded simulations and simulations are tricky to compare. The
first step towards improving this situation is to characterize a simulation via

Lemma 60

A mewo can have the property that its marking alone already fully determines how

Lemma 65

(

Proof.

Let

.

\Rightarrow

III-E

Constructions on mewos

Recall the rank function
\Psi:\mathbb{V}\to\mathsf{Ord}
from

\mathbb{V}

certainly not a simulation. We have seen that we can turn it into a simulation
by restricting its domain to

for our current goal of characterizing

\mathbb{V}

the codomain from
\mathsf{Ord}
to
\mathsf{MEWO}
. Doing this requires us to generalize the

\mathsf{Ord}
that we used to construct the rank function.
In
Definition

12

While it would be possible to phrase this definition in full generality for
mewos, we restrict ourselves for simplicity to the case of interest (the
successor), which already contains the crucial ideas.

There is however an important difference. The successor operation for
type-theoretic ordinals, if translated to and written in the notation of set
theory, maps a set
S
to
S\cup\{S\}
.
This is of course required in order not to leave the realm of
transitive

sets (and orders). For mewos, we need to slightly refine the function so that
it corresponds to the (non-transitive)
singleton operation

S\mapsto\{S\}

Definition 67

(

Singleton,
\{X\}
)
.

For a given mewo
X
, we define the
singleton order

\{X\}
to be
the marked order with carrier
X+\mathbf{1}
and the order given as follows:

•

(\inl x<\inl y)
if and only if
x<y
;

•

(\inl x<\inr\star)

\mar(x)
;

•

(\inr\star<z)
false for all

\inr\star
.

It is worth pointing out how this
almost
generalizes the successor
operation of a type-theoretic ordinal. Since such an ordinal is a completely
marked (and transitive) mewo, the second clause above matches exactly the sum
operation given in
Definition

12
when the second summand is
\mathbf{1}
.
However, a faithful generalization of
Definition

would in the end
mark not only
\inr\star
, but also all elements that were marked in

.

Another critical point to note is that, for an arbitrary mewo
X
, the
singleton
\{X\}
need not be a mewo. As an example, consider the mewo

\circ
with exactly one element, which is unmarked. If we now take its
singleton, neither this existing element nor the newly added element has any
predecessors. Since they are not equal, extensionality is missing.
The obstacle in this example is that the original marking is insufficient.
Fortunately, if we start with a
covered
mewo, the successor is not only
extensional but also covered again:

Lemma 68

(

)
.

If

.

Proof.

Wellfoundedness is immediate. Regarding extensionality, the interesting case
is comparing an element of the form
\inl x
with
\inr\star
. It suffices to
show that their predecessors are not the same. To do so, observe that
x
is
covered in
X
, i.e., there exists
x_{0}
with
x\mathrel{<^{*}}x_{0}
. By construction,

x_{0}
is a predecessor of
\inr\star
, while wellfoundedness ensures that it
cannot possibly be a predecessor of
\inl x
.
Coveredness: The element
\inr\star
is marked and thus trivially covered.
To see that an arbitrary
\inl x
is covered, note that there exists a marked

x_{0}
with

in

, implying that
\inl x

∎

We are ready to prove our second main theorem, and complete the

and

We have seen that the relation

on

is therefore a (large) mewo. Similarly,
{\mathsf{MEWO}_{\mathsf{cov}}}

To show that they are equal as such, we construct simulations between them.

Lemma 74

(

)
.

We have a simulation
\mathbb{V}\leq{\mathsf{MEWO}_{\mathsf{cov}}}
.

Proof.

We define the function
\Psi:\mathbb{V}\to{\mathsf{MEWO}_{\mathsf{cov}}}
underlying the simulation by
induction on the input by defining

\Psi(\Vsetop\left(A,f\right))\;\mathrel{\vcentcolon\mspace{-1.2mu}\equiv}\;\bigcup_{a:A}\left(\{\Psi(f\,a)\}\right).

We need to verify that extensionally equal representatives are mapped to equal

.

The following observation is helpful to see that
\Psi
is a simulation: the
predecessors (i.e., elements) of

are exactly the elements of the

Regarding monotonicity, assume we have elements
{v_{1}\in v_{2}}
in

(

)

IV
Conclusion

Working in homotopy type theory, we have shown that the set-theoretic ordinals in

\mathbb{V}
coincide with the type-theoretic ordinals.
Moreover, by generalizing from type-theoretic ordinals to covered mewos, we
have captured
all
sets in
\mathbb{V}
.

A natural question is whether similar results can be obtained by working inside
set theory instead. E.g., we expect the type-theoretic ordinals in the cubical
sets model
[
29
]
of homotopy type theory to coincide with
the set-theoretic ordinals, using the Mostowski collapse
lemma
[
30
]
.
Another, orthogonal question is whether the presentation of
\mathbb{V}
as the type
of covered mewos can shed any light on the open problem
[
9
, below
Cor 10.5.9]
of whether
\mathbb{V}
satisfies the
strong collection

and
subset collection
axioms of Constructive ZF set theory.
Moreover, it would be interesting to study how other, different notions of
constructive ordinals, such as Taylor’s
plumb ordinals

[
6
]
,
behave in a type-theoretic setting.
