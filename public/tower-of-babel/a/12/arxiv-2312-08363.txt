On the Computational Hardness of Quantum One-Wayness
Bruno P. Cavalar, Eli Goldin, Matthew Gray, Peter Hall, Yanyi Liu, Angelos Pelecanos

Abstract
There is a large body of work studying what forms of computational hardness are needed to realize classical cryptography. In particular, one-way functions and pseudorandom generators can be built from each other, and thus require equivalent computational assumptions in order to be realized. Furthermore, the existence of either of these primitives implies that 𝖯 ≠ 𝖭𝖯 \mathsf{P}\neq\mathsf{NP} , which gives a lower bound on the necessary hardness. One can also define versions of each of these primitives with quantum output: respectively one-way state generators and pseudorandom state generators. Unlike in the classical setting, it is not known whether either primitive can be built from the other. Although it has been shown that pseudorandom state generators for certain parameter regimes can be used to build one-way state generators, the implication has not been previously known in full generality. Furthermore, to the best of our knowledge the existence of one-way state generators has no known implications in traditional complexity theory. We show that pseudorandom states compressing n n bits to log ⁡ n + 1 \log n+1 qubits can be used to build one-way state generators and that pseudorandom states compressing n n bits to ω ⁡ ( log ⁡ n ) \omega(\log n) qubits are themselves one-way state generators. This is a nearly optimal result, since pseudorandom states with fewer than c ​ log ⁡ n c\log n -qubit output can be shown to exist unconditionally. We also show that any one-way state generator can be broken by a quantum algorithm with classical access to a 𝖯𝖯 \mathsf{PP} oracle. An interesting implication of our results is that a t ⁡ ( n ) t(n) -copy one-way state generator exists unconditionally, for every t ⁡ ( n ) = o ⁡ ( n / log ⁡ n ) t(n)=o(n/\log n) . This contrasts nicely with the previously known fact that O ⁡ ( n ) O(n) -copy one-way state generators require computational hardness. We also outline a new route towards a black-box separation between one-way state generators and quantum bit commitments.

Introduction

The vast majority of useful classical cryptographic primitives share the following property: they can be used to build one-way functions in a black-box
manner.
A one-way function is a function on bit-strings which can be
efficiently evaluated but is hard to invert. In this sense, one-way
functions can be thought of as a “minimal” cryptographic primitive.
However, any one-way function can be broken by an efficient algorithm with
access to an
\mathsf{NP}
oracle. This means that if
\mathsf{P}=\mathsf{NP}
, then one-way
functions do not exist. As it is unknown whether
\mathsf{P}=\mathsf{NP}
or not, the existence
of one-way functions, and thus all of classical cryptography, must rely on computational assumptions.

This issue led to the natural desire to “map out” the world of classical cryptography. Over many years, cryptographers have done a fairly good job of figuring out which cryptographic primitives can be built from each other. This cartography helps give a sense of the relative strength of assuming the existence of different cryptographic primitives.

As an example, it is known how to construct one-way functions from any key
exchange protocol, i.e. a protocol where two parties can agree on a secret
using only communication over a public channel
[
1
]
. However,
there is strong evidence that building a key exchange protocol from a
one-way function is difficult
[
2
]
. The primitives which can be
built from one-way function form a crypto-complexity class known as
“MiniCrypt”
[
3
]
. Two cryptographic primitives in this
class of particular note are pseudorandom generators and commitment
schemes. A pseudorandom generator is a deterministic function which maps a
small amount of randomness to a longer string indistinguishable from
random. A commitment scheme is a process by which a party can encode some
string into a “commitment”, such that later the party can prove this
“commitment” was an encoding of the original string.

In recent years, cryptographers have started to consider what happens if we allow cryptographic primitives to have quantum output. Here, the landscape of relations between primitives looks very different. Of particular note, it was shown that quantum key distribution, a quantum variant of key exchange, exists unconditionally
[
4
,
5
]
. On the other hand, it is known that the quantum versions of one-way functions, pseudorandom generators, and commitments cannot be secure against information-theoretic attackers, and thus require some computational hardness in order to exist
[
6
,
7
,
8
]
. These variants are known as one-way state generators, pseudorandom state generators, and quantum bit commitments respectively.

However, it is still unclear what this hardness looks like from a complexity perspective. In particular, it is known there exists an oracle relative to which
\mathsf{BQP}\supseteq\mathsf{NP}
, but all three of these primitives exist

The main goal of this work is to broaden our understanding of the hardness of quantum primitives, with a particular focus on one-way state generators. In particular, we show two main results:

1.

One-way state generators can be built from pseudorandom states
for nearly all parameter regimes requiring computational hardness.

2.

If one-way state generators exist, then
\mathsf{BQP}\neq\mathsf{PP}
.

These main results bring along a number of interesting implications. The following are of particular note:

1.

A fixed-copy version of one-way state generators exists unconditionally.

2.

If we can show that quantum bit commitments exist relative to a
\mathsf{PP}
oracle, then there is a black-box separation showing it is unlikely that we will be able to build one-way state generators from quantum bit commitments.

1.1
Results

We now recall a few key concepts from quantum cryptography

Pseudorandom State Generators (PRS).

A pseudorandom state generator, originally defined in
[
7

k

k

\ket{\phi_{k}}

The relationship between the length of the input key
n

11

Quantum cryptography, computational complexity, and

1.2.1
Building one-way state generators from pseudorandom state generators

Expanding PRS.

We will begin this section by detailing the argument from
[
13
]
that an expanding PRS is also a OWSG. Recall that an expanding PRS maps
n
-bit strings to
m
-qubit quantum states, where
m\geq(1+c)n
for some
c>0
. The natural reduction which uses the OWSG adversary to also break the PRS works. Let
\mathcal{A}
be a OWSG adversary which outputs
k^{\prime}
such that
\ket{\phi_{k^{\prime}}}
close to
\ket{\phi_{k}}
using
t
copies of
\ket{\phi_{k}}
. Given
t+1
copies of a state
\ket{\psi}
, we can test whether it is an output of the PRS or Haar-random as follows: run
\mathcal{A}
on the first
t
copies to get a state
\ket{\phi_{k^{\prime}}}
, and compare
\ket{\phi_{k^{\prime}}}
with the last copy of
\ket{\psi}
.

If
\ket{\psi}=\ket{\phi_{k}}
for some
k
, then
\ket{\phi_{k^{\prime}}}
will be close to
\ket{\phi_{k}}
. If
\ket{\psi}
is Haar-random, then since it is a random state on
(1+c)n
qubits, with high probability it is far from
\ket{\phi_{k}}
for all
2^{n}
values of
k
. This is because
\frac{2^{n}}{2^{(1+c)n}}
is negligible in
n
.

Improvement to shrinking PRS.

To improve this result to PRS with

O(\log n)
bit output, we simply improve the analysis of the exact same
reduction. We make the following simple observation about Haar-random
states: for any fixed
m
-qubit state
\ket{\phi}
, the probability that a
Haar-random state
\ket{\psi}
is “close” to
\ket{\phi}
is

2^{-\Omega(2^{m})}
. Thus, in the reduction above, if
\ket{\psi}
is a
Haar-random state on
\omega(\log n)
qubits,
then,
by a union bound, with high probability it is far from
\ket{\phi_{k}}
for
all
2^{n}
values of
k
. This argument is enough to derive
Theorem
1.2
.
Using
amplification
[
10
]
, we also find that OWSGs can be

even from a PRS which outputs
\log n+O(1)
qubits,
obtaining

Theorem

1.1

1.2.2
Breaking one-way state generators with a
\mathsf{PP}
oracle

The power of
\mathsf{PP}
in the quantum setting.

\mathsf{PP}
is typically defined by referring to Turing machines or randomized algorithms. These definitions are not very useful when dealing with quantum computing. However, it turns out that
\mathsf{PP}
has an equivalent formulation with much more obvious quantum applications, known as
\mathsf{PostBQP}

[
21
]
.
\mathsf{PostBQP}
refers to the class of problems efficiently solvable by uniform quantum circuits with the additional ability to
postselect
. Postselection is another word for performing conditional sampling, and in the quantum setting refers to the ability to choose the result of a measurement and acquire the corresponding residual state. Thus, to break any OWSG with a
\mathsf{PP}
oracle, it suffices to define an algorithm which breaks the OWSG given oracle access to some language in
\mathsf{PostBQP}
.

One-way puzzles.

Instead of breaking OWSGs with a
\mathsf{PostBQP}
oracle directly, we rely on a recent result which constructs an interesting classical output primitive, a one-way puzzle, from any OWSG
[
8
]
. Formally, a one-way puzzle is a pair of algorithms
(\mathsf{Samp},\mathsf{Ver})
where
\mathsf{Samp}
samples a key-puzzle pair
(k,s)
such that
\mathsf{Ver}(k,s)
outputs
1
with overwhelming probability.
\mathsf{Samp}
is required to be an efficient quantum algorithm, and
\mathsf{Ver}
is allowed to be any arbitrary function. The security requirement is that given
s
, it is hard for an adversary to find a
k^{\prime}
such that
\mathsf{Ver}(k^{\prime},s)=1
. Morally, a one-way puzzle is a one-way function where the input and output are sampled together.

It is clear that any one-way puzzle
(\mathsf{Samp},\mathsf{Ver})
can be broken by an
adversary with the ability to postselect. Given a puzzle
s
, the adversary
can simply run
\mathsf{Samp}
up until it would measure the output state, and then
postselect on the output puzzle being
s
. Measuring the output key will
then give a
k^{\prime}
which with high probability will satisfy
\mathsf{Ver}(s,k^{\prime})=1
.
This attack can be viewed as a search version of the attack of
[
9
]

against any
\lambda
-output PRS.

Attack with decision oracle.

But note that this attack makes use of postselecting directly. It is unclear how to translate this into an attack with a decision oracle for
\mathsf{PP}
. To solve this, we show that it is possible in general to perform conditional sampling given access to a
\mathsf{PP}
oracle:

Lemma 1.6

(Informal version of Lemma
4.2
)
.

Let
\mathsf{Samp}
be a (uniform) quantum polynomial time algorithm
such that

\mathsf{Samp}(1^{n})
outputs a
pair of classical strings
(k,s)
.
There exists a poly-time
quantum algorithm
\mathcal{A}
and a
\mathsf{PP}
language
\mathcal{L}
such
that
\mathcal{A}^{\mathcal{L}}
takes as input
s^{\prime}
and outputs
k^{\prime}
,
and whose distribution
has total variation distance at most
1/n
from the distribution
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
defined by

\Pr[(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}\to k^{\prime}]=\Pr_{\mathsf{Samp}(1^{n})\to(k,s)}[k=k^{\prime}|s=s^{\prime}].

(In other words,
we denote by
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}

the distribution of keys generated by
\mathsf{Samp}(1^{n})

conditioned on the puzzle being equal to
s^{\prime}
.)

This lemma is in some sense a “search-to-decision” style argument for

\mathsf{PP}
. The argument goes along the same lines as the search-to-decision
reduction for
\mathsf{SAT}
. Note that with a
\mathsf{PostBQP}
oracle, we can test
whether or not it is possible for an algorithm
\mathsf{Samp}
to produce any given
output
x
by simply postselecting on
x
being produced by
\mathsf{Samp}
.

A naive approach to sampling
k^{\prime}
from
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
is to sample
k^{\prime}
bit by bit. It is possible with a
\mathsf{PP}
oracle to check whether any given output is in the range of
\mathsf{Samp}
. Thus, we can begin by checking whether
(1,s^{\prime})
is in the range of
\mathsf{Samp}
with all but the first bit of the key discarded. If so, we can set the first bit of
k^{\prime}
to be
1
, otherwise
0
. In the next step, we can check whether
(k^{\prime}_{1}\circ 1,s^{\prime})
is in the range of
\mathsf{Samp}
with all but the second bit of the key discarded. If so, we can set the second bit of
k^{\prime}
to be
1
, otherwise
0
. Repeating this process for each bit of the key will uniformly select an output
k^{\prime}
from the range of
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
.

However,
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
is not necessarily a flat distribution, and so the resulting distribution on
k^{\prime}
may be very different from
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
. However, this can be resolved by noticing a key fact. Using a
\mathsf{PP}
oracle, it is possible to
estimate the probability
that the first bit of the output of
\mathsf{Samp}
is
1
conditioned on the output puzzle being
s^{\prime}
. Thus, we can use the same technique as before, but instead of just setting each bit of
k^{\prime}
, we can sample each bit according to our approximation of the correct conditional distribution. Although the error will add up, we can set our initial error to be small enough that the distribution over
k^{\prime}
will be sufficiently close to
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
.

Applying Lemma
1.6
to our postselecting attack against one-way puzzles gives us an efficient quantum attack against one-way puzzles using a
\mathsf{PP}
oracle. As one-way puzzles can be built from one-way state generators, this immediately implies Theorem
1.5
.

More on search-to-decision reductions using a
\mathsf{PP}
oracle.

The
ability of a postselection oracle to aid in search-to-decision reductions
was first noted by
[
22
]
, where it was shown that a quantum
poly-time algorithm can find a
\mathsf{QMA}
witness by making one quantum
query to a
\mathsf{PP}
oracle. They use very different techniques, and in fact
our algorithm requires many classical queries instead of one quantum query.

1.3
Conclusion and Future work

We showed two new results about one-way state generators.
We proved that their existence is implied by almost all computational PRSs, and
that
O(n)
-copy OWSGs
can be broken by QPT algorithms with access to a
\mathsf{PP}

oracle.
These results bring the cartography of OWSGs much more in line
with that of PRSs.

Further research directions.

We outline two major lines of research
which are left open by this paper.

Separating OWSG and quantum bit commitments.

The two recent papers
[
8
]
and
[
16
]
make
clear that proving that quantum bit commitments exist relative to a random
oracle and any classical oracle (with access to the random oracle) would
suffice to show a black box separation between OWSGs and quantum bit
commitments. It follows from our results
that a black box separation between quantum bit commitments
and OWSGs can be achieved by proving a weaker
statement, namely that there exists an oracle
\mathcal{O}
relative
to which quantum bit commitments exist and
\mathsf{PP}^{\mathcal{O}}\subseteq\mathsf{BQP}^{\mathcal{O}}
.

Since it is now known from
[
8
]
that
OWSGs imply quantum bit commitments, proving this conjecture and the accompanying
separation would provide strong evidence that quantum bit commitments are
(at least among the quantum cryptographic primitives so far proposed) the
minimal assumption for quantum cryptography.

OWSG
\rightarrow
PRS.

We have now shown that
PRSs imply OWSGs
in nearly the greatest possible generality,
and that the existence of either have equivalent known
complexity ramifications. This gives additional motivation to the question
of whether these primitives are equivalent (as their classical equivalents are known to be).
Proving either an equivalence or separation (even for a limited
copy setting) would be an exciting accomplishment that would greatly
clarify the cartography of quantum cryptography.

Open questions.

There are two open questions which we would like to see
an answer for.

Optimal PRS
\rightarrow
OWSG Reduction.

OWSGs are inherently computational objects, meaning they cannot be implied by statistical primitives. Currently we know that

•

PRSs with
m\geq\log n
output qubits require computational assumptions.

•

There exists a
c\in(0,1)
s.t. statistical PRSs with
m\leq c\log n
output qubits exist. So the existence of PRSs in this regime cannot imply OWSGs.

•

PRS with
m\geq\log n+1
output qubits imply OWSGs.

This leaves the question open of whether a PRS with
m\in(c\log n,\,\log n]
output qubits imply the existence of OWSGs. The smallest improvement to this space would be to show that a PRS with
m=\log n
output qubits imply OWSGs.
Other possible tightening would be to show that, for any
c<1
, a statistical PRS with
m\leq c\log n
exist, though this would show the surprising result that just over 1 bit of randomness
per amplitude is enough to achieve statistical closeness to Haar-random
states.

Parameter regimes for which OWSGs don’t exist.

It would be very interesting to know which parameter regimes it can be shown OWSGs do not exist in. We conjecture that much
like how
O(\log n)
output classical OWFs cannot exist,
m=O(\log\log n)
output qubit OWSGs cannot exist unconditionally.
It would be good to have a complete
understanding of how
OWSGs
behave
in different parameter
regimes, and a proof of its non-existence in that setting would help
to clarify this picture.

2.2
Quantum information theory and cryptography

We denote by
{\mathbb{S}}(N)
the set of

N

We identify the set of

{\mathbb{S}}(2^{n})
.
We denote by

Quantum cryptography.

We start by introducing the notion of pseudorandom state generators (PRS)
[
7
]
.
Roughly speaking, given a classical key
k
, a PRS maps
k
to a quantum pure state
\ket{\phi_{k}}
. The security guarantee is that the output of a PRS on a random input should look like a random state. That is, it is hard for any quantum adversary to distinguish a random
\ket{\phi_{k}}
from a Haar random state.

Definition 2.3

(Pseudorandom States, Definition 2 of
[
7
]
)
.

Let
\lambda
be the security parameter and
let
{\mathcal{K}}
be a set of binary strings referred to as the
key space
.
Let
G
be a QPT algorithm that on input
k\in{\mathcal{K}}
outputs a pure quantum
state
\ket{\phi_{k}}
over
n=n(\lambda)
qubits.
We say
G
is
(t,\varepsilon)
-pseudorandom if the distribution over
outputs is
\varepsilon
-indistinguishable from Haar random given

t
copies.
In other words, for any QPT adversary
\mathcal{A}
,
we have

\left|\Pr_{k\leftarrow\mathcal{K}}[\mathcal{A}(\ket{\phi_{k}}^{\otimes t})=1]-\Pr_{\ket{\psi}\leftarrow\text{Haar}(n)}[\mathcal{A}(\ket{\psi}^{\otimes t})=1]\right|\leq\varepsilon.

We say that
G
is pseudorandom if it is
\left(\lambda^{c},\frac{1}{\lambda^{c}}\right)
-pseudorandom for all
c>0
, and that it is t-pseudorandom or a t-copy PRS if it is
\left(t,\frac{1}{\lambda^{c}}\right)
-pseudorandom for all
c>0
.

We turn to introducing the notion of one-way state generators (OWSGs)
[
13
]
.
A OWSG maps a classical key
k
to quantum state
\ket{\phi_{k}}
. The security guarantee
of a OWSG is that, given any polynomial number of copies of
\ket{\phi_{k}}
,
it is hard for a quantum algorithm to find keys
k^{\prime}
such

\ket{\phi_{k}},\ket{\phi_{k^{\prime}}}
have noticeable overlap.
OWSGs can also be
defined to have mixed state outputs
[
10
]
, although we
will not consider this variant in this work.

Definition 2.4

(One-Way State Generators, Definition 4.1 of
[
10
]
)
.

Let
\lambda
be the security parameter
and
let
{\mathcal{K}}
be a set of binary strings referred to as the
key space
.
Let
G
be a QPT algorithm that on input

k\in{\mathcal{K}}

outputs a pure quantum state
\ket{\phi_{k}}
.
We say
G is
(t,\varepsilon)
-one-way if the outputs are hard to invert with
accuracy at least
\varepsilon
.
In other words, for any QPT adversary
\mathcal{A}
,
we have

\mathop{{}\mathbb{E}}_{\begin{subarray}{c}k\leftarrow\mathcal{K}\\
k^{\prime}\leftarrow\mathcal{A}(\ket{\phi_{k}}^{\otimes t})\end{subarray}}\left[\left|\braket{\phi_{k}|\phi_{k^{\prime}}}\right|^{2}\right]\leq\varepsilon.

We say that
G
is one-way or strongly one way if it is
\left(\lambda^{c},\frac{1}{\lambda^{c}}\right)
-one-way for all
c>0
, and that it is t-one-way, a t-copy OWSG, or a t-copy strong OWSG if it is
\left(t,\frac{1}{\lambda^{c}}\right)
-one-way for all
c>0
.

We remark that all of the results in this paper
will also hold for
the more general definition of (pure-state) one-way state generators
that was introduced
in the later work of Morimae and
Yamakawa
[
13
]
, where the one-way state generator is
allowed to have a separate quantum key generation
procedure.
2
2

2

The results we show in

Section

imply the existence of one-way state generators in
the sense of
Definition

2.4
in various settings.
Since these are more restricted objects than the ones considered in the
more general definition of
[
13
]
, our results will also implies their
existence in the same settings and with an analogous parameter regime.
Furthermore, since our oracle QPT algorithm in
Section

4
comes
from an algorithm breaking
one-way puzzles
, and one-way puzzles were
proved in
[
8
]
to follow from the “general” pure state OWSGs of
[
13
]
,
our algorithm will therefore also break
OWSGs with a quantum key generation procedure.

Our techniques, however, do not generalize to
the mixed-state OWSGs defined in the later work of Morimae
and Yamakawa
[
13
]
.

We will rely on the notion of one-way puzzles, defined in
[
8
]
. A one-way puzzle is a pair of algorithms
(\mathsf{Samp},\mathsf{Ver})
where
\mathsf{Samp}
samples a key-puzzle pair
(k,s)
such that
\mathsf{Ver}(k,s)
outputs
1
with overwhelming probability.
\mathsf{Samp}
is required to be an efficient quantum algorithm, and
\mathsf{Ver}
is allowed to be any arbitrary function. The security requirement is that given
s
, it is hard for an adversary to find a
k^{\prime}
such that
\mathsf{Ver}(k^{\prime},s)=1
.

Definition 2.5

(One-Way Puzzles
[
8
]
)
.

Let
\lambda
be the security parameter.
A one-way puzzle is a pair of sampling and verification algorithms
(\mathsf{Samp},\mathsf{Ver})
with the following syntax.

•

\mathsf{Samp}(1^{\lambda})\to(k,s)
is a (uniform) quantum
polynomial time algorithm that outputs a pair of classical
strings
(k,s)
. We refer to
s
as the puzzle and
k
as its
key. Without loss of generality we may assume that
k\in\{0,1\}^{\lambda}
.

•

\mathsf{Ver}(k,s)\to\top~\text{or}~\bot
, is an unbounded
algorithm that on input any pair of classical strings
(k,s)

halts and outputs either
\top
or
\bot
.

These satisfy the following properties.

•

Correctness.
Outputs of the sampler pass verification with overwhelming probability, i.e.,

\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{\lambda})}[\mathsf{Ver}(k,s)=\top]=1-\mathsf{negl}(\lambda).

•

Security.
Given
s
, it is (quantumly) computationally infeasible to find
k
satisfying
\mathsf{Ver}(k,s)=\top
, i.e., for every polynomial-sized quantum circuit
\mathcal{A}
,

\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{\lambda})}[\mathsf{Ver}(\mathcal{A}(s),s)=\top]=\mathsf{negl}(\lambda).

An important recent result due to Khurana and Tomer
[
8
]

states that one-way state generators imply one-way puzzles.
This will be crucial for our algorithm in
Section

4
.

Theorem 2.6

(
[
8
, Theorem 4.2]
)
.

If there exists a
(O(n),\mathsf{negl}(n))
-OWSG, then there exists a one-way puzzle.

Probability distributions

We recall a few standard probability distributions, the chi-squared distribution

Lemma

Definition 2.7

(Chi-squared distribution)
.

Let
X_{1},\dots,X_{k}

be independent normal random variables
with mean

The

chi-square distribution with

Definition 2.8

(Fisher-Snedecor distribution)
.

Let

.
The

Fisher-Snedecor distribution with
a
and
b

F(a,b)\sim\frac{\chi^{2}(a)/a}{\chi^{2}(b)/b}=\frac{b}{a}\cdot\frac{\chi^{2}(a)}{\chi^{2}(b)}.

We now recall the definition of the beta function and its variations
in order to express the cumulative distribution function
of the
F

The

is defined as

B(a,b):=\int_{0}^{1}x^{a-1}(1-x)^{b-1}\,dx.

The

is defined as

B(t;a,b):=\int_{0}^{t}x^{a-1}(1-x)^{b-1}\,dx.

The

is defined as

I_{x}(a,b):=\frac{B(x;a,b)}{B(a,b)}.

Lemma 2.9

(Cumulative distribution function of the
F
-distribution)
.

The cumulative distribution function
p_{a,b}(t)

of
the

p_{a,b}(t)=I_{at/(at+b)}(a/2,b/2).

In particular, we have

\Pr_{\mathbf{Y}\leftarrow F(a,b)}[\mathbf{Y}\leq\theta]=\frac{\int_{0}^{(a\theta)/(a\theta+b)}x^{a-1}(1-x)^{b-1}\,dx}{\int_{0}^{1}x^{a-1}(1-x)^{b-1}\,dx}.

3
One-way state generators from compressing pseudorandom states

We construct both weak and strong
t
-copy one-way state generators from

(t+1)
-copy compressing pseudorandom states. Before this the only known
reduction worked for expanding PRS mapping
n
-bit strings to
cn
-qubit
states
[
13
]
for some
c>1
.
To generalize this reduction, we rely on the
following concentration inequality, which informally states that, with high
probability, any fixed state is unlikely to be close to Haar-random states.
We will then use this in Theorem
3.2
to bound how
well a OWSG inverter can distinguish outputs of a PRS from Haar-random states.

Lemma 3.1

(Concentration of Haar States
3
3

3

In

[
9
]
the author refers to a closely related
inequality as following from “standard concentration inequalities, or even
an explicit computation”. However we were unable to find an actual proof
of the inequality in either the citation listed
[
30
]
, or
in the paper which it cites
[
31
]
.
Consequently we decided to include a proof here for completeness.
)
.

Let
\ket{\phi_{0}}
be any state of dimension
N=2^{n}
. Then, for any
s>0
,
we have

\Pr_{\ket{\psi}\sim\text{Haar}(n)}\left[\left|\braket{\phi_{0}|\psi}\right|^{2}\geq\frac{1}{s}\right]\leq\left(\frac{s}{s+1}\right)^{N-1}.

Proof.

Since the Haar distribution is invariant under unitary transformations, without loss of generality we assume
\ket{\phi_{0}}=\ket{0}
.

Muller
[
32
]
showed that sampling from the Haar distribution is equivalent to sampling
\ket{\psi}
as

\ket{\psi}\propto\sum_{x}(\alpha_{x}+\beta_{x}i)\ket{x},

where each
\alpha_{x},\beta_{x}
is sampled according to the standard Gaussian with expectation 0 and standard deviation 1. Then, we define the random variable
Y
as

Y:=\frac{\alpha_{0}^{2}+\beta_{0}^{2}}{\sum_{x\neq 0}\alpha_{x}^{2}+\beta_{x}^{2}}.

Expanding out the inner product gives us

\left|\braket{0|\psi}\right|^{2}=\frac{\alpha_{0}^{2}+\beta_{0}^{2}}{\sum_{x}(\alpha_{x}^{2}+\beta_{x}^{2})}\leq Y.

But observe that each
\alpha_{x},\beta_{x}
is sampled independently, and
so
Y
is distributed as the ratio of two chi-squared random variables.
So, we see that
Y
is sampled as a (scaled)
F
-distribution as
follows:

Y\sim\frac{\chi^{2}(2)}{\chi^{2}(2N-2)}\sim\frac{2}{2N-2}\cdot F(2,2N-2).

We conclude by
Lemma

2.9
that

\displaystyle\begin{split}\Pr\left[Y\geq\frac{1}{s}\right]&=\Pr\left[F(2,2N-2)\geq\frac{N-1}{s}\right]\\
&=1-\frac{\int_{0}^{\frac{1}{s+1}}(1-x)^{N-2}dx}{\int_{0}^{1}(1-x)^{N-2}dx}\\
&=1-\frac{\left[-\frac{1}{N-1}\cdot(1-x)^{N-1}\right]_{0}^{1/(s+1)}}{\left[-\frac{1}{N-1}\cdot(1-x)^{N-1}\right]_{0}^{1}}\\
&=1-\frac{\left[(1-x)^{N-1}\right]_{0}^{1/(s+1)}}{\left[(1-x)^{N-1}\right]_{0}^{1}}\\
&=1+\left(\left(1-\frac{1}{s+1}\right)^{N-1}-1\right)\\
&=\left(\frac{s}{s+1}\right)^{N-1},\\
\end{split}

where

[f(x)]_{0}^{1}=f(1)-f(0)
.
Since

\Pr_{\ket{\psi}\sim\text{Haar}(N)}\left[\left|\braket{\phi_{0}|\psi}\right|^{2}\geq\frac{1}{s}\right]\leq\Pr\left[Y\geq\frac{1}{s}\right],

we are done.
∎

Using this lemma we first show a general result
stating that state generators that are pseudorandom must also be one-way.
We then apply the result
in two
different parameter regimes.
While
[
9
]
only claims that
PRSs
with
m=n
output bits
can be broken
by
\mathsf{PP}
,
[
11
]
calls out that the proof can be
extended to the case when
m\geq\log n+c
.
For this regime, we show that
PRSs are weak OWSGs. We then show that slightly less compressing PRSs (
m=\omega(\log n)
) are strong OWSGs.
In all these three results, the number of copies
falls by 1 moving from a PRS to a OWSG. While we end up focusing on
sublinear-copy PRSs in the next subsection, these reductions work in the
default many-copy setting considered in most papers on quantum
cryptographic primitives.

Lemma 3.2
.

For all
f(n)
and for

\delta=2^{n}\cdot\left(\frac{f(n)}{f(n)+1}\right)^{(2^{m}-1)}+\frac{1}{f(n)},

if

is a state generator taking
n
-bit
strings to
m
-qubit pure states which is
\left(t+1,\varepsilon\right)
-pseudorandom, then it is also
(t,\varepsilon+\delta)
-one way.

Proof.

For the sake of contradiction, assume that there exists an adversary

\mathcal{A}
that can succeed with probability larger than
\varepsilon+\delta
in the
t
-copy
one-wayness game (
Definition

2.4
). We will construct a new adversary
\mathcal{A}^{\prime}
for the
pseudorandomness game as follows:

Algorithm 1

Adversary
\mathcal{A}^{\prime}
in the pseudorandomness game

Input
:
\ket{\psi}^{\otimes(t+1)}
.

Output
:
0
if
\ket{\psi}
is pseudorandom,
1
if
\ket{\psi}
is Haar random.

1:

Run
\mathcal{A}
on the first
t

k^{\prime}\leftarrow\mathcal{A}(\ket{\psi}^{\otimes t})

2:

Measure the last copy of
\ket{\psi}

in the basis

\left\{\left\lvert\phi_{k^{\prime}}\middle\rangle\!\middle\langle\phi_{k^{\prime}}\right\rvert,I-\left\lvert\phi_{k^{\prime}}\middle\rangle\!\middle\langle\phi_{k^{\prime}}\right\rvert\right\}

3:

return
1 if the result is
\left\lvert\phi_{k^{\prime}}\middle\rangle\!\middle\langle\phi_{k^{\prime}}\right\rvert
, else

Observe that when
\mathcal{A}^{\prime}
is given a pseudorandom input, it outputs

with probability at least

\Pr_{k\leftarrow\mathcal{K}}\left[\mathcal{A}^{\prime}\left(\ket{\phi_{k}}^{\otimes(t+1)}\right)=1\right]=\mathop{\mathbb{E}}_{k\leftarrow\mathcal{K}}\left[\left|\braket{\phi_{k}|\phi_{k^{\prime}}}\right|^{2}\middle|k^{\prime}\leftarrow\mathcal{A}\left(\ket{\phi_{k}}^{\otimes t}\right)\right]>\varepsilon+\delta,

where the key space
{\mathcal{K}}
is equal to
\left\{0,1\right\}^{n}
here.
Thus, it suffices remains to bound the probability that
\mathcal{A}^{\prime}
detects a Haar random state:

\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\mathcal{A}^{\prime}\left(\ket{\psi}^{\otimes(t+1)}\right)=1\right]\leq\delta.

By construction, we have

\displaystyle\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\mathcal{A}^{\prime}\left(\ket{\psi}^{\otimes(t+1)}\right)=1\right]=

\displaystyle~\mathop{\mathbb{E}}_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\left|\braket{\psi|\phi_{k}}\right|^{2}\middle|k\leftarrow\mathcal{A}\left(\ket{\psi}^{\otimes t}\right)\right]

\displaystyle=

\displaystyle~\int_{\mathbb{S}(2^{m})}d\mu(\psi)\cdot\sum_{k\in\{0,1\}^{n}}\Pr\left[k\leftarrow\mathcal{A}\left(\ket{\psi}^{\otimes t}\right)\right]\cdot\left|\braket{\psi|\phi_{k}}\right|^{2}

\displaystyle\leq

\displaystyle~\int_{\mathbb{S}(2^{m})}d\mu(\psi)\cdot\max_{k\in\{0,1\}^{n}}\left|\braket{\psi|\phi_{k}}\right|^{2}.

Where
\mu(\psi)
is the Haar measure on the space of
m
-qubit pure
states. We will now partition the set of
m
-qubit pure states into the
states that are ‘close’ to a pseudorandom state
\ket{\phi_{k}}
, and the
states that are ‘far’ from all pseudorandom states. Formally, we define

A_{f}:=\left\{\ket{\psi}\in\mathbb{S}(2^{m})\middle|\max_{k}\left|\braket{\psi|\phi_{k}}\right|^{2}\geq\frac{1}{f(n)}\right\}.

The set of states that are ‘far’ from all pseudorandom states is its complement,

B_{f}:=\left\{\ket{\psi}\in\mathbb{S}(2^{m})\middle|\max_{k}\left|\braket{\psi|\phi_{k}}\right|^{2}<\frac{1}{f(n)}\right\}.

We proceed with computing the integral separately for the two sets:

\displaystyle\int_{\mathbb{S}(2^{m})}d\mu(\psi)\cdot\max_{k\in\{0,1\}^{n}}\left|\braket{\psi|\phi_{k}}\right|^{2}=

\displaystyle~\int_{A_{f}}d\mu(\psi)\cdot\max_{k\in\{0,1\}^{n}}\left|\braket{\psi|\phi_{k}}\right|^{2}

\displaystyle+\int_{B_{f}}d\mu(\psi)\cdot\max_{k\in\{0,1\}^{n}}\left|\braket{\psi|\phi_{k}}\right|^{2}

\displaystyle\leq

\displaystyle~\int_{A_{f}}d\mu(\psi)+\max_{\begin{subarray}{c}\ket{\psi}\in B_{f}\\
k\in\{0,1\}^{n}\end{subarray}}\left|\braket{\psi|\phi_{k}}\right|^{2}

\displaystyle<

\displaystyle~\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\exists k\middle|\left|\braket{\psi|\phi_{k}}\right|^{2}\geq\frac{1}{f(n)}\right]+\frac{1}{f(n)}

\displaystyle\leq

\displaystyle~\sum_{k\in\mathcal{K}}\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\left|\braket{\psi|\phi_{k}}\right|^{2}\geq\frac{1}{f(n)}\right]+\frac{1}{f(n)}.

Lemma

3.1
implies that

\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\mathcal{A}^{\prime}\left(\ket{\psi}^{\otimes(t+1)}\right)=1\right]\leq 2^{n}\cdot\left(\frac{f(n)}{1+f(n)}\right)^{2^{m}-1}+\frac{1}{f(n)}=\delta.

We conclude

\left|\Pr_{k\leftarrow\mathcal{K}}\left[\mathcal{A}^{\prime}\left(\ket{\psi}^{\otimes(t+1)}\right)=1\right]-\Pr_{\ket{\psi}\leftarrow\text{Haar}(m)}\left[\mathcal{A}^{\prime}\left(\ket{\psi}^{\otimes(t+1)}\right)=1\right]\right|>\varepsilon.\qed

Using this general result we can specify to the two theorems below.

Theorem 3.3

(PRSs imply OWSGs)
.

If

G

is a state generator taking
n
-bit strings to
m>\log n+c
qubit states (with
c\geq 1
)
which is
(t+1,\varepsilon)
-pseudorandom, then
G
is also
(t,\varepsilon+3/4)
-one-way.

Proof.

Take
Lemma

3.2
with
f(n)=2
, and
m>\log n+c
. We get that

\displaystyle\delta

\displaystyle\leq 2^{n}\cdot\left(\frac{2}{3}\right)^{n\cdot 2^{c}-1}+\frac{1}{2}

\displaystyle=\frac{3}{2}\cdot\left(\frac{2^{2^{c}+1}}{3^{2^{c}}}\right)^{n}+\frac{1}{2}.

Since
c>1
, the left term becomes less than
1/4
for sufficiently large
n
, and thus
\delta<3/4
.
∎

Using amplification arguments from
[
10
]
,
these
(t,\varepsilon+3/4)
-OWSGs can be used to construct strong OWSGs with negligible probability of inversion.

This reduction is nearly optimal.
[
14
]
showed that there exist statistical many-copy PRSs with
c\log n
output bits for some
c<1
. As shown later strong OWSGs must imply computational assumptions (e.g.
\mathsf{BQP}\neq\mathsf{PP}
) so they cannot be implied by statistical or information theoretic primitives. Consequently there can be no proof that PRSs with output shorter than
c\log n
qubits imply OWSGs, meaning our proof is optimal up to multiplicative constant factors.

We can also show that PRSs with
superlogarithmic output
are themselves strong OWSGs.

Theorem 3.4

(PRSs are strong OWSGs)
.

If

G

is a state generator taking
n
-bit
strings to

m=\omega(\log n)
-qubit
states which is

(t+1,\varepsilon)
-pseudorandom, then it is also

(t,\varepsilon+\mathsf{negl}(n))
-one way.

Proof.

Take
Lemma

3.2
and set

f(n)=\frac{2^{m}-1}{2^{m/2}}-1
.
Note that
f(n)=2^{\Omega(m)}=n^{\omega(1)}
.
We get

\begin{split}\delta&=2^{n}\cdot\left(\frac{f(n)}{f(n)+1}\right)^{2^{m}-1}+\frac{1}{f(n)}\\
&\leq 2^{n}\cdot\left(1-\frac{1}{f(n)+1}\right)^{2^{m}-1}+\mathsf{negl}(n)\\
&\leq 2^{n}\cdot\left(\frac{1}{e}\right)^{2^{m/2}}+\mathsf{negl}(n)\\
&=2^{n-\Omega(n^{\omega(1)})}+\mathsf{negl}(n)\\
&=\mathsf{negl}(n).\qed\end{split}

3.1
Unconditional OWSGs from efficient approximate

-designs

We first observe that any efficient

-approximate

.

-approximate

2.11

4
Breaking one-way state generators with a PP oracle

In this section, we show how to break one-way state generators (OWSGs)
with a
\mathsf{PP}
oracle.
Since one-way state generators imply one-way puzzles
(
Theorem

2.6
, due to
[
8
]
),
it suffices to show how to break one-way puzzles using a
\mathsf{PP}

oracle.
Recall that a one-way puzzle is a pair of sampling and verification
quantum algorithms

(\mathsf{Samp},\mathsf{Ver})
(see
Definition

2.5
).
The algorithm
\mathsf{Samp}(1^{n})
outputs a pair
(k,s)
, where
k
is referred to
as the key and
s
as the puzzle.
To break the one-way puzzle, it suffices to create a quantum algorithm

{\mathcal{A}}

that, given a puzzle
s
, returns a key
k^{\prime}
such that

\mathsf{Ver}(k^{\prime},s)
is accepted with non-negligible probability.

Our strategy to construct
{\mathcal{A}}
is as follows.
Given a puzzle
s
sampled according to

\mathsf{Samp}
,
we will sample a key
k

according to the conditional distribution of keys that are sampled together
with
s
.
This will suffice to break the one-way puzzle, as
\mathsf{Ver}

accepts pairs from
\mathsf{Samp}
with
(1-\mathsf{negl})
-probability.
To sample from this distribution,
we first show how to use the
\mathsf{PP}
oracle to estimate the conditional probability,
and finally how to sample according to a distribution that is close to the true conditional distribution.

We view our strategy as inspired by Kretschmer’s
[
9
]
idea for breaking pseudorandom state generators with a
\mathsf{PP}
oracle, together with a search-to-decision reduction for
\mathsf{PP}
.

Lemma 4.1
.

Let
S
be a (uniform) quantum polynomial time algorithm that outputs
n
bits, denoted as a pair of a string
x
, and a bit
b
. There exists a poly-time quantum algorithm
\mathcal{A}
and a
\mathsf{PP}
language
\mathcal{L}
such that
\mathcal{A}^{\mathcal{L}}
can estimate the distribution of bit
b
, conditioned on the output string
x
. Formally,

p_{x,b}-\frac{1}{n^{2}}\leq\mathcal{A}^{\mathcal{L}}(S,1^{n},x,b)\leq p_{x,b}+\frac{1}{n^{2}}

where
p_{x,b}=\Pr\left[S(1^{n})=(x,b)|S(1^{n})\in\{(x,0),(x,1)\}\right]
.

Proof.

Our quantum algorithm
\mathcal{A}
will take as input the algorithm

S
, a unary description of the length
1^{n}
, the outputs
(x,b)
, and will estimate the conditional
probability of
b
, conditioned on the first output of
S
being
x
.

Definition of the
\mathsf{PP}
language.

We will describe the
\mathsf{PP}
language
\mathcal{L}
in terms of a

PromisePostBQP
algorithm
\mathcal{B}(S,x,t)
.
This will define a promise problem which is computed by

\mathcal{B}(S,x,t)
.
By the equivalence

\mathsf{PromisePostBQP}=\mathsf{PromisePP}
, this gives us a promise problem in
\mathsf{PromisePP}
.
Since
\mathsf{PromisePP}
is a syntactic class, this can be extended to a
language
{\mathcal{L}}\in\mathsf{PP}
.
However, later on our algorithm
{\mathcal{A}}
will only depend on the
behaviour of the oracle to
{\mathcal{L}}
on inputs that satisfy the promise
condition of the promise problem defined by
\mathcal{B}(S,x,t)
.

We first assume without loss of generality that any measurements in
S
are delayed until the very end of the algorithm.
The algorithm
\mathcal{B}
will simulate
S
and postselect
on the output measurements matching
x
. Conditioned on
postselection succeeding, the output register for
b
will contain the pure state
\sqrt{p_{x,0}}\ket{0}+\sqrt{p_{x,1}}\ket{1}
.
Then
\mathcal{B}
measures the register of
b
,
and repeats this procedure
r=\Theta(n^{4})
times,
outputting
1
if the
measurements
yields

1
at least a
\frac{t}{2n^{2}}
fraction of the time.
This ends the description of the
\mathsf{PromisePostBQP}
algorithm

{\mathcal{B}}(S,x,t)
.

Which inputs
(S,x,t)
are accepted by
{\mathcal{B}}
?
Let

\mathbf{b}_{1},\dots,\mathbf{b}_{r}

denote the random variables that correspond to the value of the
b
register at each simulation of
S
by
\mathcal{B}
.
We define
\mathbf{B}=\sum_{i}\mathbf{b}_{i}
to be their sum.
Note that
\mathbf{B}/r

is the fraction of measurements that yield a
1

in the algorithm
{\mathcal{B}}
,
and recall that we accept if this fraction is at least

t/(2n^{2})
.
By
standard concentration inequalities (e.g., Chebyshev’s),
when the number of repetitions
r
is at least
\Theta(n^{4})
, then

\Pr_{\mathbf{b}_{1},\dots,\mathbf{b}_{r}}\left[\left|\frac{\mathbf{B}}{r}-p_{x,1}\right|>\frac{1}{4n^{2}}\right]<\frac{1}{3}.

This implies that,
if
p_{x,1}\geq\frac{t}{2n^{2}}+\frac{1}{4n^{2}}
,
then

\frac{\mathbf{B}}{r}>\frac{t}{2n^{2}}

with probability
2/3
.
Moreover, if

p_{x,1}\leq\frac{t}{2n^{2}}-\frac{1}{4n^{2}}
,
then

\frac{\mathbf{B}}{r}<\frac{t}{2n^{2}}

with probability
2/3
.
We conclude

\begin{cases}(S,x,t)\in{\mathcal{L}},&\text{if }\quad p_{x,1}\geq\frac{t}{2n^{2}}+\frac{1}{4n^{2}},\\
(S,x,t)\not\in{\mathcal{L}},&\text{if }\quad p_{x,1}\leq\frac{t}{2n^{2}}-\frac{1}{4n^{2}}.\end{cases}

(1)

Note that this only gives us information about the output of
{\mathcal{B}}

on inputs
(S,x,t)
such that

\left|p_{x,1}-\frac{t}{2n^{2}}\right|\geq\frac{1}{4n^{2}}
.
Henceforth we will
call this inequality the
promise condition
.
We remark that, if

(S,x,t)
does not satisfy the promise condition,
then

(S,x,t+1)
satisfies it.
Indeed,
if

\left|p_{x,1}-\frac{t}{2n^{2}}\right|<\frac{1}{4n^{2}}
,
we have

p_{x,1}\leq\frac{t}{2n^{2}}+\frac{1}{4n^{2}}=\frac{t+1}{2n^{2}}-\frac{1}{2n^{2}}+\frac{1}{4n^{2}}=\frac{t+1}{2n^{2}}-\frac{1}{4n^{2}},

and therefore

\left|p_{x,1}-\frac{t+1}{2n^{2}}\right|\geq\frac{1}{4n^{2}}
.
In particular, we obtain that

(S,x,t+1)\notin{\mathcal{L}}
.

Description of
{\mathcal{A}}^{\mathcal{L}}
.

Given access to this
\mathsf{PP}
language,
\mathcal{A}
will query the oracle on the inputs

\{(S,x,0),\dots,(S,x,2n^{2})\}
.
Then
\mathcal{A}
will output
\frac{t}{2n^{2}}
,
for the smallest
t
such that

(S,x,t)
is rejected by the oracle
(if
(S,x,t)

is accepted
for all
t
,
then
\mathcal{A}
outputs

1
).
Note that, if

(S,x,t-1)
is accepted by the oracle,
and
(S,x,t)
is rejected, then one of the following three things must
have happened:

1.

(S,x,t-1)\in{\mathcal{L}}
and

(S,x,t)\not\in{\mathcal{L}}
, or

2.

(S,x,t-1)
does not satisfy the promise condition,
and

(S,x,t)\not\in{\mathcal{L}}
, or

3.

(S,x,t-1)\in{\mathcal{L}}
and

(S,x,t)
does not satisfy the promise condition.

As we observed above, it never occurs that

(S,x,t-1)
does not satisfy the promise condition,
and

(S,x,t)\in{\mathcal{L}}
.
By inspection, using (
1
), in all of those three cases we get
that
the value
\frac{t}{2n^{2}}
is
an additive
approximation to
p_{x,1}
with error at most
\frac{1}{n^{2}}
.
Additionally, since
p_{x,0}=1-p_{x,1}
, the value
\frac{2n^{2}-t}{2n^{2}}
is an additive approximation for
p_{x,0}
.
∎

When
\mathsf{Samp}(1^{n})\to(k,s)
is
is a uniform quantum polynomial-time algorithm
outputting a pair of classical strings

(k,s)
,
we will denote by

(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}

the distribution of keys
k
output by

\mathsf{Samp}(1^{n})
, conditioned on the puzzle being
s^{\prime}
.

Lemma 4.2
.

Let
\mathsf{Samp}
be a (uniform) quantum polynomial time algorithm
such that

\mathsf{Samp}(1^{n})
outputs a
pair of classical strings
(k,s)
, denoted as the key and the puzzle
respectively, where
k\in\left\{0,1\right\}^{n}
.
There exists a poly-time
quantum algorithm
\mathcal{A}
and a
\mathsf{PP}
language
\mathcal{L}
such
that
\mathcal{A}^{\mathcal{L}}
takes as input a puzzle
s^{\prime}
and outputs
a key
k^{\prime}
,
and whose distribution
has total variation distance at most
1/n
from
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
.
In other words,
we have

\left(k^{\prime}\mid k^{\prime}\leftarrow\mathcal{A}^{\mathcal{L}}(1^{n},s^{\prime})\right)\approx_{\frac{1}{n}}(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}.

Proof.

On a high level, the algorithm
\mathcal{A}
will output a key
k^{\prime}
by
sampling its bits one by one. At the
i^{th}
iteration, it will use
the first
i-1
bits of
k^{\prime}
to estimate the distribution of the

i^{th}
bit using a
\mathsf{PP}
oracle, as in
Lemma

4.1
. Then it
will sample the
i^{th}
bit of
k^{\prime}
according to this estimated
distribution. The
\mathsf{PP}
language
\mathcal{L}
that we use is the same
as the one shown to exist in that lemma.

In more detail, let us define
the sequence

\{\mathcal{S}^{\leq i}\}_{i\in[n]}

of algorithms based on
\mathsf{Samp}
, where
\mathcal{S}^{\leq i}
is the (uniform) quantum polynomial
time algorithm that simulates
\mathsf{Samp}
, but only outputs the puzzle
s
and
the first
i
bits of the key
k
.

On input
(1^{n},s^{\prime})
, the algorithm
\mathcal{A}
will proceed in
n
iterations.
In the first iteration, it will use
Lemma

4.1
on

\mathcal{S}^{\leq 1}
with output
s^{\prime}
and estimate (up to
\frac{1}{n^{2}}
additive
error) the probability that the first bit of the key is
1
,
conditioned on the puzzle
s^{\prime}
. Call this estimate
\tilde{p}_{1}
.
The algorithm
will then sample the first bit of
k^{\prime}
according to the
Bernoulli distribution defined by
\tilde{p}_{1}
.

Now
\mathcal{A}
proceeds by sampling the remaining bits. In the

i^{\rm th}
iteration, it uses
Lemma

4.1
with the sampler

\mathcal{S}^{\leq i}
and outputs an estimate
\tilde{p}_{i}
of the probability
that the
i^{\rm th}
bit of
k^{\prime}
is
1
, conditioned on the puzzle
s^{\prime}

and the first
i-1
bits of
k^{\prime}
. Then it samples the
i^{\rm th}
bit
according to the estimated distribution.
Finally,
\mathcal{A}
outputs
k^{\prime}

after the end of the
n^{\rm th}
iteration.

It remains to show that the output distribution of
\mathcal{A}
is
close to
(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
, the output distribution of
\mathsf{Samp}(1^{n})
conditioned on the
puzzle
s^{\prime}
. We will show this via a hybrid argument.

Let
{\mathcal{D}}_{0}:=(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
be the true distribution of the key
k
conditioned on
the puzzle
s^{\prime}
.
We define
n
hybrid distributions
{\mathcal{D}}_{i}
for
i\in\{1,\dots,n\}
on keys.
The hybrid
{\mathcal{D}}_{i}
runs in
n
iterations and in each
iteration samples the next bit of the key. In the first
i
iterations
(that correspond to the first
i
bits),
the distribution
{\mathcal{D}}_{i}
uses the estimated
probabilities
\tilde{p_{1}},\dots,\widetilde{p_{i}}
. The final
n-i
bits are sampled according
to the true conditional probabilities (i.e., according to

(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}
, conditioned on the outcome of the previous bits).
Note that

{\mathcal{D}}_{n}
now corresponds to the output distribution of our algorithm

\mathcal{A}
. We show that every two consecutive distributions are at
most
\frac{1}{n^{2}}
far in total variation distance,
and thus the total distance between the
true distribution of the key and the output distribution
of
\mathcal{A}
is
at most
\frac{1}{n}
from the triangle inequality.

Claim 4.3
.

For every
i\in\left\{0,\dots,n-1\right\}
, we have

\mathsf{d}_{\mathsf{TV}}({\mathcal{D}}_{i},{\mathcal{D}}_{i+1})\leq\frac{1}{n^{2}}.

Proof.

Before diving into the proof, we introduce some useful notation.
We use
k_{[x,y]}
to denote the length-
(y-x+1)
substring that includes bits
\{x,\dots,y\}
of
k
.
Additionally, even though
{\mathcal{D}}_{i}
is a distribution over

n
-bit strings, we will abuse notation and consider the probability assigned to substrings of the form
k_{[x,y]}
. In that case, we write

{\mathcal{D}}_{i}(k_{[x,y]}):=\Pr_{k^{\prime}\leftarrow{\mathcal{D}}_{i}}\left[k^{\prime}_{[x,y]}=k_{[x,y]}\right].

We will also consider the probability assigned to substrings
k[x,y]
, conditioned on a prefix
k_{[1,x]}
, in which case we write

{\mathcal{D}}_{i}\left(k_{[x,y]}\middle|k_{[1,x-1]}\right):=\Pr_{k^{\prime}\leftarrow{\mathcal{D}}_{i}}\left[k^{\prime}_{[x,y]}=k_{[x,y]}\middle|k^{\prime}_{[1,x-1]}=k_{[1,x-1]}\right].

With this notation in place, a direct calculation suffices
for the
i=0
case. In particular, observe that

\displaystyle{\mathcal{D}}_{1}(k)

\displaystyle={\mathcal{D}}_{1}\left(k_{[1,1]}\right)\cdot{\mathcal{D}}_{1}\left(k_{[2,n]}\middle|k_{[1,1]}\right)

\displaystyle={\mathcal{D}}_{1}\left(k_{[1,1]}\right)\cdot{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right),

and similarly
{\mathcal{D}}_{0}(k)={\mathcal{D}}_{0}\left(k_{[1,1]}\right)\cdot{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right)
.
Note that, because of

Lemma

4.1
,
we have

\left|{\mathcal{D}}_{0}\left(k_{[1,1]}\right)-{\mathcal{D}}_{1}\left(k_{[1,1]}\right)\right|\leq 1/n^{2}
.
The total variation distance satisfies:

\displaystyle\mathsf{d}_{\mathsf{TV}}({\mathcal{D}}_{0},{\mathcal{D}}_{1})

\displaystyle=\frac{1}{2}\sum_{k\in\{0,1\}^{n}}\left|{\mathcal{D}}_{0}(k)-{\mathcal{D}}_{1}(k)\right|

\displaystyle=\frac{1}{2}\sum_{k\in\{0,1\}^{n}}\left|{\mathcal{D}}_{0}\left(k_{[1,1]}\right)\cdot{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right)-{\mathcal{D}}_{1}\left(k_{[1,1]}\right)\cdot{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right)\right|

\displaystyle\leq\frac{1}{2}\sum_{k\in\{0,1\}^{n}}\left|{\mathcal{D}}_{0}\left(k_{[1,1]}\right)-{\mathcal{D}}_{1}\left(k_{[1,1]}\right)\right|\cdot\left|{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right)\right|

\displaystyle\leq\frac{1}{2n^{2}}\sum_{k\in\{0,1\}^{n}}\left|{\mathcal{D}}_{0}\left(k_{[2,n]}\middle|k_{[1,1]}\right)\right|

\displaystyle\leq\frac{1}{n^{2}}.

Let us now consider the distributions

{\mathcal{D}}_{i},{\mathcal{D}}_{i+1}
.
They both sample bits
1
up to
i
using the estimated probabilities,
and bits
i+2
up to
n
with the true conditional probabilities.
Write
{\mathcal{D}}_{i+1}
as

\displaystyle{\mathcal{D}}_{i+1}(k)

\displaystyle={\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\cdot{\mathcal{D}}_{i+1}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\cdot{\mathcal{D}}_{i+1}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

\displaystyle={\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\cdot{\mathcal{D}}_{i+1}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

and similarly
{\mathcal{D}}_{i}
as

\displaystyle{\mathcal{D}}_{i}(k)

\displaystyle={\mathcal{D}}_{i}\left(k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

\displaystyle={\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right).

Note that, because of

Lemma

4.1
,
we have

\left|{\mathcal{D}}_{i}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)-{\mathcal{D}}_{i+1}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\right|<1/n^{2}.

The total variation distance satisfies:

\displaystyle\mathsf{d}_{\mathsf{TV}}({\mathcal{D}}_{i},{\mathcal{D}}_{i+1})

\displaystyle=\frac{1}{2}\sum_{k\in\{0,1\}^{n}}\left|{\mathcal{D}}_{i}(k)-{\mathcal{D}}_{i+1}(k)\right|

\displaystyle\leq\frac{1}{2}\sum_{k\in\{0,1\}^{n}}{\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\cdot\left|{\mathcal{D}}_{i}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)-{\mathcal{D}}_{i+1}\left(k_{[i+1,i+1]}\middle|k_{[1,i]}\right)\right|\cdot{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

\displaystyle\leq\frac{1}{2n^{2}}\sum_{k\in\{0,1\}^{n}}{\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\cdot{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

\displaystyle=\frac{1}{2n^{2}}\sum_{k_{[1,i]}\in\{0,1\}^{i}}{\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)\sum_{k_{[i+1,i+1]}\in\{0,1\}}\sum_{k_{[i+2,n]}\in\{0,1\}^{n-i-1}}{\mathcal{D}}_{i}\left(k_{[i+2,n]}\middle|k_{[1,i+1]}\right)

\displaystyle=\frac{1}{n^{2}}\sum_{k_{[1,i]}\in\{0,1\}^{i}}{\mathcal{D}}_{i+1}\left(k_{[1,i]}\right)

\displaystyle=\frac{1}{n^{2}}.\qed

As observed above,
by the triangle inequality we obtain from
the Claim
that
{\mathcal{D}}_{n}
, which is the
output distribution of our algorithm
{\mathcal{A}}
, has total variation

1/n
from

(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}

∎

Theorem 4.4
.

For any one-way puzzle

(\mathsf{Ver},\mathsf{Samp})
, there exists a
\mathsf{PP}
language
\mathcal{L}
, and a poly-time quantum algorithm
\mathcal{A}^{\mathcal{L}}
such that

\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}\left[\mathsf{Ver}\left(\mathcal{A}^{\mathcal{L}}(s),s\right)=\top\right]\geq\frac{1}{2}.

Proof.

From the correctness property of the OWPuzzle, it holds that

\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}\left[\mathsf{Ver}(k,s)=\top\right]\geq 1-\mathsf{negl}(n).

Recall that

(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}

is the distribution over keys
output by
\mathsf{Samp}
, conditioned on the puzzle being equal to
s^{\prime}
.
It is clear that sampling the puzzle first, and then the key
does not change their joint distribution, and thus

\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow(\mathsf{Samp}\,|\,s)^{\mathsf{key}}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right]\geq 1-\mathsf{negl}(n).

Given a puzzle
s
,
Lemma

4.2
implies that there
exists a quantum polynomial-time algorithm
\mathcal{A}
and a
\mathsf{PP}

language
\mathcal{L}
, such that
\mathcal{A}^{\mathcal{L}}(s^{\prime})

outputs a key
k^{\prime}
according to a distribution
\tilde{D}_{s^{\prime}}

such that

\tilde{D}_{s^{\prime}}\approx_{1/n}(\mathsf{Samp}\,|\,s^{\prime})^{\mathsf{key}}.

(2)

We have

\displaystyle\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow\tilde{D}_{s}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right]

\displaystyle=\sum_{s^{\prime}}\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow\tilde{D}_{s}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right|s=s^{\prime}]\cdot\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}[s=s^{\prime}].

Now note that, conditioned on
s=s^{\prime}
,
the event

\left\{\mathsf{Ver}(k^{\prime},s)=\top\right\}

depends only on
k^{\prime}\leftarrow\widetilde{D}_{s^{\prime}}
,
and thus we may use (
2
) to get

\displaystyle\Pr

{}_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow\tilde{D}_{s}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right]

\displaystyle\geq\sum_{s^{\prime}}\left(\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow(\mathsf{Samp}\,|\,s)^{\mathsf{key}}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right|s=s^{\prime}]-1/n\right)\cdot\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}[s=s^{\prime}]

\displaystyle=\sum_{s^{\prime}}\left(\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow(\mathsf{Samp}\,|\,s)^{\mathsf{key}}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right|s=s^{\prime}]\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}[s=s^{\prime}]\right)-(1/n)\cdot\Pr_{(k,s)\leftarrow\mathsf{Samp}(1^{n})}[s=s^{\prime}]

\displaystyle=\Pr_{\begin{subarray}{c}(k,s)\leftarrow\mathsf{Samp}(1^{n})\\
k^{\prime}\leftarrow(\mathsf{Samp}\,|\,s)^{\mathsf{key}}\end{subarray}}\left[\mathsf{Ver}(k^{\prime},s)=\top\right]-1/n\geq 1-1/n-\mathsf{negl}(n)>1-2/n.

This completes our argument.
∎

[

]
