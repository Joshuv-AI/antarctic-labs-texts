Optimal Communication for Classic Functions in the Coordinator Model and Beyond
Hossein Esfandiari, Praneeth Kacham, Vahab Mirrokni, David P. Woodruff, Peilin Zhong

Abstract
In the coordinator model of communication with s s servers, given an arbitrary non-negative function f f , we study the problem of approximating the sum ∑ i ∈ [ n ] f ⁡ ( x i ) \sum_{i\in[n]}f(x_{i}) up to a 1 ± ε 1\pm\varepsilon factor. Here the vector x ∈ ℝ n x\in\mathbb{R}^{n} is defined to be x = x ⁡ ( 1 ) + ⋯ + x ⁡ ( s ) x=x(1)+\cdots+x(s) , where x ⁡ ( j ) ≥ 0 x(j)\geq 0 denotes the non-negative vector held by the j j -th server. A special case of the problem is when f ⁡ ( x ) = x k f(x)=x^{k} which corresponds to the well-studied problem of F k F_{k} moment estimation in the distributed communication model. We introduce a new parameter c f ​ [ s ] c_{f}[s] which captures the communication complexity of approximating ∑ i ∈ [ n ] f ⁡ ( x i ) \sum_{i\in[n]}f(x_{i}) and for a broad class of functions f f which includes f ⁡ ( x ) = x k f(x)=x^{k} for k ≥ 2 k\geq 2 and other robust functions such as the Huber loss function, we give a two round protocol that uses total communication c f ​ [ s ] / ε 2 c_{f}[s]/\varepsilon^{2} bits, up to polylogarithmic factors. For this broad class of functions, our result improves upon the communication bounds achieved by Kannan, Vempala, and Woodruff (COLT 2014) and Woodruff and Zhang (STOC 2012), obtaining the optimal communication up to polylogarithmic factors in the minimum number of rounds. We show that our protocol can also be used for approximating higher-order correlations. Our results are part of a broad framework for optimally sampling from a joint distribution in terms of the marginal distributions held on individual servers. Apart from the coordinator model, algorithms for other graph topologies in which each node is a server have been extensively studied. We argue that directly lifting protocols from the coordinator model to other graph topologies will require some nodes in the graph to send a lot of communication. Hence, a natural question is the type of problems that can be efficiently solved in general graph topologies. We address this question by giving communication efficient protocols in the so-called personalized CONGEST model for solving linear regression and low rank approximation by designing composable sketches . Our sketch construction may be of independent interest and can implement any importance sampling procedure that has a monotonicity property.

In modern applications data is often distributed across multiple servers and communication is a bottleneck. This motivates minimizing the communication cost for solving classical functions of interest. A standard model of distributed computation is the

In the coordinator model, we measure the efficiency of a protocol by looking at the following: (i) the overall number of bits of communication required by the protocol and (ii) the number of rounds of communication in the protocol. In each round of communication, each of the servers sends a message to the coordinator based on their input and messages from the coordinator in previous rounds. Based on the messages received from all the servers in this round and earlier rounds, the coordinator sends a possibly distinct message to each of the servers. Thus, in a protocol with one round, each of the servers sends a message to the coordinator based
only
on their inputs and the coordinator has to compute the output based only on these messages. We additionally assume that all the servers and the coordinator have access to a shared source of randomness which they can use to sample shared random variables.

1.2
Our Techniques

Sampling from “Additively-Defined” Distributions.

At the heart of our results for approximating
\sum_{i=1}^{n}f(x_{i})=\sum_{i=1}^{n}f(\sum_{j=1}^{s}x_{i}(j))
is a general technique to sample from an “additively-defined” distribution using only one round of communication. To obtain our tightest communication bounds, our algorithm for approximating
\sum_{i=1}^{n}f(x_{i})
does not use this protocol in a black-box way, but the techniques used are similar to the ones used in this protocol. In this setting, the
j
-th server holds a non-negative vector
p(j)\in\mathbb{R}^{n}_{\geq 0}
and the coordinator wants to sample from a distribution over
[n]
with the probability of sampling
i\in[n]
being proportional to

q_{i}=p_{i}(1)+\cdots+p_{i}(s).

Additionally if the coordinate
i
is sampled by the coordinator, the coordinator also needs to be able to estimate the probability with which
i
is sampled. This is an important requirement to obtain (approximately) unbiased estimators in applications involving importance sampling. If the coordinator just wants to sample from the distribution, it can run the following simple protocol: first, each server
j
samples a coordinate
\mathbf{i}_{j}
from its local distribution, i.e.,
\operatorname{Pr\/}[\mathbf{i}_{j}=i]=p_{i}(j)/\sum_{i}p_{i}(j)
. Each server sends the coordinate
\mathbf{i}_{j}
along with the quantity
\sum_{i}p_{i}(j)
to the coordinator. The coordinator then samples a random server
\mathbf{j}
from the distribution
\operatorname{Pr\/}[\mathbf{j}=j]=(\sum_{i}p_{i}(j))/\sum_{j^{\prime}}(\sum_{i}p_{i}(j^{\prime}))
and then takes
\mathbf{i}_{\mathbf{j}}
, i.e., the coordinate sent by the server
\mathbf{j}
, to be the sample. We note that

\displaystyle\operatorname{Pr\/}[\mathbf{i}_{\mathbf{j}}=i]=\sum_{j}\operatorname{Pr\/}[\mathbf{j}=j]\operatorname{Pr\/}[\mathbf{i}_{j}=i]=\sum_{j}\frac{\sum_{i^{\prime}}p_{i^{\prime}}(j)}{\sum_{j}\sum_{i^{\prime}}p_{i^{\prime}}(j)}\cdot\frac{p_{i}(j)}{\sum_{i^{\prime}}p_{i^{\prime}}(j)}=\frac{\sum_{j}p_{i}(j)}{\sum_{j}\sum_{i^{\prime}}p_{i^{\prime}}(j)}=\frac{q_{i}}{\sum_{i^{\prime}}q_{i^{\prime}}}.

Hence the distribution of
\mathbf{i}_{\mathbf{j}}
is
correct
. But notice that there is no easy way for the coordinator to estimate the probability of sampling
\mathbf{i}_{\mathbf{j}}
since it may not receive any information about this coordinate from the other servers. Therefore, to obtain the probability with which
\mathbf{i}_{\mathbf{j}}
was sampled, the coordinator needs another round of communication, which we wish to avoid.

We will now give a protocol that can also approximate the sampling probabilities with only one round of communication. The protocol we describe here is a simpler version of the full protocol in Section
3
. Consider the following way of sampling from the distribution in which
i
has a probability proportional to
q_{i}
. Let
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
be independent standard exponential random variables. Let

i^{*}=\argmax_{i\in[n]}\mathbf{e}_{i}^{-1}q_{i}=\argmax_{i\in[n]}\mathbf{e}_{i}^{-1}(p_{i}(1)+\cdots+p_{i}(s)).

By standard properties of the exponential random variable, we have

\operatorname{Pr\/}[i^{*}=i]=\frac{\sum_{j}p_{i}(j)}{\sum_{j}\sum_{i^{\prime}}p_{i^{\prime}}(j)}=\frac{q_{i}}{\sum_{i^{\prime}}q_{i^{\prime}}}.

Hence, the random variable
i^{*}
also has the
right
distribution. The advantage now is that we can additionally show that with a high probability,

\sum_{i}\mathbf{e}_{i}^{-1}\left(\sum_{j}p_{i}(j)\right)\leq(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}\sum_{j}p_{i^{*}}(j).

In other words, if we define
s
vectors
r(1),\ldots,r(s)
, one at each of the servers, such that
r_{i}(j)=\mathbf{e}_{i}^{-1}p_{i}(j)
and define
r=\sum_{j=1}^{s}r(j)
, then the coordinate
r_{i^{*}}
is a
1/(C\log^{2}n)

\ell_{1}

heavy hitter
, as in
r_{i^{*}}\geq\|r\|_{1}/(C\log^{2}n)
.

Suppose a deterministic sketch matrix
S\in\mathbb{R}^{m\times n}
is an
\alpha
-incoherent matrix for
\alpha=\varepsilon/(4C\log^{2}n)
. Here we say that a matrix
S
is
\alpha

have unit Euclidean norm and for any
i\neq i^{\prime}\in[n]

|\langle S_{*i},S_{*i^{\prime}}\rangle|\leq\alpha
. Nelson, Nguyen and Woodruff
[
35
]
give constructions of such matrices with
m=O(\log(n)/\alpha^{2})
rows and show that for any vector
x
,

\|x-S^{\top}Sx\|_{\infty}\leq\alpha\|x\|_{1}.

Now suppose that each server
j
computes the vector
S\cdot r(j)
and uses
O(\operatorname{polylog}(n)/\varepsilon^{2})
words of communication to send the vector
S\cdot r(j)
to the coordinator. The coordinator receives the vectors
S\cdot r(1),\ldots,S\cdot r(s)
and computes the vector
S\cdot r=S\cdot r(1)+\cdots+S\cdot r(s)
and can then compute a vector
r^{\prime}=S^{\top}Sr
satisfying

\|r-r^{\prime}\|_{\infty}\leq\alpha\|r\|_{1}.

Conditioned on the event that
\|r\|_{1}\leq(C\log^{2}n)\cdot r_{i^{*}}
, as
\alpha
is set to be
\varepsilon/(4C\log^{2}n)
, we obtain that

r^{\prime}_{i^{*}}=(1\pm\varepsilon/4)\cdot r_{i^{*}}

and for all
i\neq i^{*}
, we have
r^{\prime}_{i}\leq r_{i}+(\varepsilon/4)\cdot r_{i^{*}}
. Using properties of exponential random variables, we can also show that with probability
\geq 1-O(\varepsilon)
,
\max_{i}r_{i}\geq(1+\varepsilon)\cdot\text{second-max}_{i}\,r_{i}
. Conditioned on this event as well, we obtain that for all
i\neq i^{*}
,
r^{\prime}_{i}<r_{i^{*}}(1-\varepsilon/4)\leq r^{\prime}_{i^{*}}
. Hence the largest coordinate in the vector
r^{\prime}
is exactly
i^{*}
and the value
r_{i^{*}}
can be recovered up to a
1\pm\varepsilon/4
factor. Overall, the coordinator can find a coordinate
\hat{i}
and a value
\hat{q}=\mathbf{e}_{\hat{i}}\cdot(r_{\hat{i}})^{\prime}
such that for all
i\in[n]
,

\displaystyle\operatorname{Pr\/}[\hat{i}=i\ \text{and}\ \hat{q}\in(1\pm\varepsilon/4)q_{i}]=\frac{q_{i}}{\sum_{i^{\prime}}q_{i^{\prime}}}\pm O(\varepsilon).

(3)

Thus this procedure lets us sample from a distribution close to that of the desired distribution while at the same time lets us approximate the probability of the drawn sample. In Section
3
, we give a protocol, which instead of using incoherent matrices, uses an “
\ell_{1}
sampling-based” algorithm to compute the coordinate
i^{*}
and approximate the value
q_{i^{*}}
. We end up obtaining a sample
\hat{i}\in[n]
and a value
\hat{q}
for which

\displaystyle\operatorname{Pr\/}[\hat{i}=i\,\text{and}\,\hat{q}=(1\pm\varepsilon)\frac{q_{i}}{\sum_{i^{\prime}}q_{i^{\prime}}}]=(1\pm\varepsilon)\frac{q_{i}}{\sum_{i^{\prime}}q_{i^{\prime}}}\pm\frac{1}{\operatorname{poly}(n)}.

(4)

Additionally, computing the coordinate
\hat{i}
does not require
\Omega(n)
time at the coordinator using the protocol in Section

.

Function Sum Approximation.

Our aim is to obtain an algorithm which approximates the sum
\sum_{i=1}^{n}f(x_{i})=\sum_{i=1}^{n}f(\sum_{j=1}^{s}x_{i}(j))
up to a
1\pm\varepsilon
factor for a non-negative, super-additive function
f
. The protocol described above for sampling from additively-defined distributions shows that correlating randomness across all the servers using exponential random variables is a powerful primitive in this context.

In the function sum approximation problem, each server holds a non-negative vector
x(1),\ldots,x(s)
, respectively, and the coordinator wants to approximate
\sum_{i}f(x_{i})=\sum_{i}f(\sum_{j}x_{i}(j))
. Suppose that each server
j
defines a vector
p(j)\in\mathbb{R}^{n}
such that
p_{i}(j)=f(x_{i}(j))
. Then the above described protocol can be used to sample approximately from the distribution in which
i
has probability

(1\pm\varepsilon)\frac{f(x_{i}(1))+\cdots+f(x_{i}(s))}{\sum_{i^{\prime}}\sum_{j}f(x_{i^{\prime}}(j))}\pm\frac{1}{\operatorname{poly}(n)}.

Using super-additivity and the definition of the parameter
c_{f}[s]
, we obtain that the above probability is at least

(1\pm\varepsilon)\frac{f(x_{i})}{c_{f}[s]\cdot\sum_{i^{\prime}}f(x_{i^{\prime}})}\pm\frac{1}{\operatorname{poly}(n)}.

This distribution is off by a multiplicative
c_{f}[s]
factor from the distribution we need to sample coordinates from in order to estimate
\sum_{i}f(x_{i})
with a low variance. Thus, we need
O(c_{f}[s]/\varepsilon^{2})
samples from the above distribution, and this overall requires a communication of
O(s\cdot c_{f}[s]/\varepsilon^{4})
bits, which is more than the total communication required by the protocol of
[
29
]
.

Additionally, when the coordinate
i
is sampled, the protocol lets us estimate
f(x_{i}(1))+\cdots+f(x_{i}(s))
, but the quantity we want to construct an estimator for is the value
f(x_{i}(1)+\cdots+x_{i}(s))
, which requires an additional round of communication and defeats the point of obtaining a protocol that can approximate the sampling probability in the same round. Overall, a protocol based on this procedure requires
O(s\cdot c_{f}[s]\cdot\operatorname{polylog}(n)/\varepsilon^{4})
bits of communication and two rounds of communication.

Thus, we need a different technique to obtain algorithms which can approximate
\sum_{i}f(x_{i})
more efficiently. We continue to use exponential random variables to correlate the randomness across the servers but instead heavily use the max-stability property to design our protocol. Let
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
be independent standard exponential random variables. The max-stability property asserts that for any
f_{1},\ldots,f_{n}\geq 0
, the random variable
\max(f_{1}/\mathbf{e}_{1},\ldots,f_{n}/\mathbf{e}_{n})
has the same distribution as
(\sum_{i=1}^{n}f_{i})/\mathbf{e}
where
\mathbf{e}
is also a standard exponential random variable. Now using the
median
of
O(1/\varepsilon^{2})
independent copies of the random variable
(\sum_{i=1}^{n}f_{i})/\mathbf{e}
, we can compute an approximation of
\sum_{i=1}^{n}f_{i}
up to a
1\pm\varepsilon
factor with high probability. Thus, in the coordinator model, if there is a protocol that can find the value of the random variable
\max_{i}f(x_{i})/\mathbf{e}_{i}
, then we can use it to compute a
1\pm\varepsilon
approximation to
\sum_{i}f(x_{i})
by running the protocol for
O(1/\varepsilon^{2})
independent copies of the exponential random variables. From here on, we explain how we construct such a protocol.

Given the exponential random variables
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
, define

i^{*}\coloneqq\argmax_{i\in[n]}\mathbf{e}_{i}^{-1}f(x_{i}).

As mentioned above we would like to find the value of
\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})
. The “heavy-hitter” property we used previously shows that with probability
\geq 1-\frac{1}{\operatorname{poly}(n)}
,

\displaystyle\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i})\leq(C\log^{2}n)\cdot\max_{i}\mathbf{e}_{i}^{-1}f(x_{i}).

(5)

This is the main property that leads to a communication efficient algorithm that can identify the max coordinate
i^{*}
and the value
x_{i^{*}}
. From here on, condition on the above event.

Note that we are shooting for a protocol that uses at most

with a probability
\geq 1-\frac{1}{\operatorname{poly}(n)}
. Fix a server

. Consider the random variable
\mathbf{i}

\operatorname{Pr\/}[\mathbf{i}=i]={\mathbf{e}_{i}^{-1}f(x_{i}(j))}/{\sum_{i\in[n]}\mathbf{e}_{i}^{-1}f(x_{i}(j))}.

Since the server

\textnormal{{{SC}}}_{j}\coloneqq\set{\mathbf{i}_{1},\ldots,\mathbf{i}_{N}}

The Personalized CONGEST Model.

We focus on constructing
\ell_{2}
-subspace embeddings, though the arguments here are analogous for
\ell_{p}
-subspace embeddings by using the
\ell_{p}
-sensitivities instead of the leverage scores, defined below.
Recall that given an
n\times d
matrix
A
, we say that a matrix
M
is
1/2
subspace embedding for
A
if
for all vectors
x
,

\|Mx\|_{2}^{2}=(1\pm 1/2)\|Ax\|_{2}^{2}
.
Subspace embeddings have numerous applications in obtaining fast algorithms for problems such as linear regression, low rank approximation, etc.

Our main technique is to use the
same
uniform random variables across all the servers to
coordinate
the random samples across all the servers in a useful way.
For simplicity, assume that there is a node
\alpha
connected to
s
neighbors (servers) such that the
j
-th neighbor holds a matrix
A^{(j)}\in\mathbb{R}^{n_{j}\times d}
, which does not have any duplicate rows. Further assume that we want to compute a subspace embedding for the matrix
A
obtained by the union of the rows of the matrices
A^{(j)}
, i.e., if a row
v
is present in say both
A^{(1)}
and
A^{(2)}
, it appears only once in the matrix
A
.

Given a matrix
A
, we recall the standard definition of the leverage scores for each of the rows of
A
, as well as the standard construction to obtain a subspace embedding from the leverage scores. If
v
is a row of the matrix
A
, define the leverage score
\tau_{A}(v)
of v to be:

\tau_{A}(v)\coloneqq\max_{x:Ax\neq 0}\frac{|\langle v,x\rangle|^{2}}{\|Ax\|_{2}^{2}}
.
For convenience, we define
\tau_{A}(v)=0
if
v
is not a row of the matrix
A
.
One has that the sum of the leverage scores of all the rows in a matrix
A
is at most
d
. Now construct the
n\times n
random diagonal matrix
\mathbf{D}
as follows: for each
i\in[n]
independently set
\mathbf{D}_{i,i}
to be
1/\sqrt{p_{i}}
with probability
p_{i}=\min(1,q_{i})
where
q_{i}\geq C\tau_{A}(a_{i})\log d
and
a_{i}
is the
i
-th row of
A
, and set it to
0
otherwise. We note that since
\sum_{i\in[n]}\tau_{A}(a_{i})\leq d
, the random matrix
\mathbf{D}
has at most
O(d\log d)
nonzero entries with a large probability. One can now show that if
C
is large enough, then with probability
\geq 99/100
, the matrix
\mathbf{D}A
is a
1/2
subspace embedding for
A
. We note that the matrix
\mathbf{D}A
has at most
O(d\log d)
nonzero rows with a large probability. This algorithm is known as
leverage score sampling
.

Going back to our setting, we want to implement leverage score sampling on the matrix
A
which is formed by the
union
of the rows of the matrices
A^{(1)},\ldots,A^{(s)}
, i.e., we only count a row once even if it appears on multiple servers. As in the coordinator model where we used the same exponential random variables across servers, a key idea we use in the CONGEST model is
correlated randomness
. This time, for each possible row
v
that could be held by any server, all the servers choose the same threshold
h(v)
uniformly at random from the interval
[0,1]
. We treat
h(\cdot)
as a fully random hash function mapping row
v
to a uniform random number from the interval
[0,1]
.

Each server
j
now computes the
\ell_{2}
leverage score of each of the rows in its matrix
A^{(j)}
. Note if
v
is held by two different servers
j\neq j^{\prime}
, then it could be that
\tau_{A^{(j)}}(v)\neq\tau_{A^{(j^{\prime})}}(v)
.

Server
j
sends all its rows
v
that satisfy
h(v)\leq C\tau_{A^{(j)}}(v)\log d
to node
\alpha
. Additionally, assume that the server sends the value
\tau_{A^{(j)}}(v)
along with the row
v
. Since
h(v)
is picked uniformly at random from the interval
[0,1]
, the probability that a row
v
is sent to the node
\alpha
by the
j
-th server is
\min(1,C\tau_{j}(v)\log d)
. Hence, each server is implementing leverage score sampling of its own rows and sending all the rows that have been sampled to node
\alpha
.

Now we note that if
v
is a row of the matrix
A^{(j)}
, then
\tau_{A^{(j)}}(v)\geq\tau_{A}(v)
which directly follows from the definition of leverage scores. For any
v
that is a row of the matrix
A
, we have
\tau_{A}(v)\leq\max_{j\in[s]}\tau_{A^{(j)}}(v)
. Since
h(v)
is same across all the servers, then the probability that a row
v
of the matrix
A
is sent to the node
\alpha
is exactly,
\min(1,\max_{j\in[s]}C\tau_{A^{(j)}}(v)\log d)
. For all the rows
v
that are received by node
\alpha
, it can also compute
\min(1,\max_{j\in[s]}C\tau_{A^{(j)}}(v)\log d)
since it also receives the values
\tau_{A^{(j)}}(v)
from all the servers that send the row
v
. Now using the fact that
\tau_{A}(v)\leq\max_{j\in[s]}\tau_{A^{(j)}}(v)
for all rows
v
of
A
, the union of rows that are received by the node
\alpha
correspond to a leverage score sampling of the matrix
A
. Since the node
\alpha
can also compute the probability that each row it receives was sampled with, it can appropriately scale the rows and obtain a subspace embedding for the matrix
A
. In the above procedure, each server
j
sends at most
O(d\log d)
rows and therefore the subspace embedding constructed by the node
\alpha
for matrix
A
has at most
O(sd\log d)
rows.

Even though we described a procedure to compute a subspace embedding of the union of neighboring matrices at a single node
\alpha
, if the nodes send the rows that are under the threshold
h(v)
to all their neighbors, this procedure can simultaneously compute a subspace embedding at each node for a matrix that corresponds to the union of neighbor matrices of that node. This solves the
1
-neighborhood version of the more general
\Delta
-neighborhood problem we introduced.

Now consider how we can compute a subspace embedding for the distance
2
neighborhood matrix. Note that we cannot run the same procedure on
1
-neighborhood subspace embeddings to obtain
2
-neighborhood subspace embeddings. We again use the monotonicity of leverage scores. Consider the node
\alpha
and the matrix
A
as defined before. Let
v
be a row that it receives from one of its neighbors in the first round. Suppose the node
\alpha
can compute
\tau_{A}(v)
, the leverage score of
v
with respect to the matrix
A
. Now the node
\alpha
forwards the row
v
to its neighbors if
h(v)\leq C\tau_{A}(v)\log d
. Suppose
\beta
is neighbor of the node
\alpha
. Thus, after the second round, the rows received by
\beta
then correspond to performing a leverage score sampling of the distance-
2
neighborhood matrix for the node
\beta
and it can then compute a subspace embedding for that matrix!

Now the main question is how can the node
\alpha
compute the leverage scores
\tau_{A}(v)
? By definition of a subspace embedding, we note that if
M
is a subspace embedding for
A
, then
M
can be used to approximate
\tau_{A}(v)
. Since we already saw that the node
\alpha
can compute a subspace embedding for the
1
-neighborhood matrix, it can also approximate
\tau_{A}(v)
for all the rows
v
that it receives. However an issue arises where we are using the set of rows that
\alpha
receives in the first round themselves to approximate their leverage scores and therefore their sampling probabilities in the second round. This leads to correlations and it is unclear how to analyze leverage score sampling with such correlations. To solve for this issue, we use two independent hash functions
h_{1}(\cdot)
and
h_{2}(\cdot)
. Using the sample of rows received by the node
\alpha
when the
1
-neighborhood procedure from above is run using hash function
h_{1}(\cdot)
, it computes a subspace embedding for the matrix
A
and then uses this subspace embedding to approximate the leverage scores of the rows that it receives when the
1
-neighborhood procedure run using hash function
h_{2}(\cdot)
. The node
\alpha
then uses these approximate leverage scores to decide which of the rows that it received are to be forwarded to its neighbors. This decouples the probability computation and the sampling procedure and the proof of leverage score sampling goes through.

This procedure is similarly extended to compute subspace embeddings for the
\Delta
-neighborhood matrices at each node in the graph. In each round, we use a fresh subspace embedding and use it to compute approximate leverage scores and filter out the rows and then forward them to the neighbors. This way of decorrelating randomness is similar to the
sketch switching
method for adversarial streams in
[
6
]
, though we have not seen it used in this context.

This general procedure of collecting data from neighbors,
shrinking
the collected data and transferring the data to all the neighbors is called “graph propagation”. Any procedure such as ours above which can handle duplicates can be readily applied in this framework so that each node in the graph can simultaneously learn some statistic/solve a problem over the data in its neighborhood.

2.1
Notation

For a positive integer
n

[n]
to denote the set
\set{1,\ldots,n}
. For two non-negative numbers
a

b
and a parameter
0<\varepsilon<1

a=(1\pm\varepsilon)b
if
(1-\varepsilon)b\leq a\leq(1+\varepsilon)b

x\in\mathbb{R}^{n}
and
k\geq 1
,
\|x\|_{k}=(\sum_{i}|x_{i}|^{k})^{1/k}
denotes the
\ell_{k}
norm of the vector
x

F_{k}(x)
for
\|x\|_{k}^{k}
. Given a matrix
A
,
\left\|A\right\|_{F}
denotes the Frobenius norm defined as
(\sum_{i,j}A_{ij}^{2})^{1/2}
and for an index
i
,
A_{i}
denotes the
i
-th row of matrix
A
. We use the notation
\tilde{O}(f)
to hide the factors that are polylogarithmic in the parameters of the problem such as the dimension or
1/\varepsilon
where
\varepsilon

k

to hide the multiplicative factors that depend purely on

.

2.2
Exponential Random Variables

We use the following properties of exponential random variables extensively throughout the paper.

1.

If
\mathbf{e}
is a standard exponential random variable, then
\operatorname{Pr\/}[\mathbf{e}\geq C\log n]=1/n^{C}
and
\operatorname{Pr\/}[\mathbf{e}\leq t]\leq t
for any
C,t\geq 0
.

2.

If
f_{1},\ldots,f_{n}\geq 0
are arbitrary and
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
are standard exponential random variables, then
\max_{i}\mathbf{e}_{i}^{-1}f_{i}
has the same distribution as
\mathbf{e}^{-1}(\sum_{i}f_{i})
. This property is referred to as “max-stability”. This shows that with probability
\geq 1-1/n^{C},\max_{i}\mathbf{e}_{i}^{-1}f_{i}\geq(\sum_{i}f_{i})/C\log n
.

3.

In the same setting, if
i^{*}=\argmax_{i}\mathbf{e}_{i}^{-1}f_{i}
, then
\operatorname{Pr\/}[i^{*}=i]=f_{i}/\sum_{j}f_{j}
.

4.

Let
\mathbf{e}_{1},\ldots,\mathbf{e}_{t}
are
t
independent standard exponential random variables. If
t=\Omega(1/\varepsilon^{2})
, then

\displaystyle\operatorname{Pr\/}[(1-\varepsilon)\ln(2)\leq\textnormal{median}(\mathbf{e}_{1},\ldots,\mathbf{e}_{t})\leq(1+\varepsilon)\ln(2)]\geq 9/10.

Hence for any
F>0
,
\textnormal{median}(F/\mathbf{e}_{1},\ldots,F/\mathbf{e}_{t})\cdot\ln(2)\in[(1-\varepsilon)F,(1+\varepsilon)F]
with probability
\geq 9/10
.

We use the following lemma extensively which shows that with a probability
\geq 1-1/\operatorname{poly}(n)
,
\sum_{i}\mathbf{e}_{i}^{-1}f_{i}\leq(C\log^{2}n)\max_{i}\mathbf{e}_{i}^{-1}f_{i}
.

Lemma 2.1
.

Given any
f_{1},\ldots,f_{n}\geq 0
, let
F=\sum_{i=1}^{n}f_{i}
. With probability
\geq 1-1/\operatorname{poly}(n)
,

\displaystyle\frac{\max f_{i}/\mathbf{e}_{i}}{\sum_{i=1}^{n}f_{i}/\mathbf{e}_{i}}\geq\frac{1}{C\log^{2}n}.

Proof.

Condition on the event that
1/n^{3}\leq\mathbf{e}_{i}\leq 3\log n
for all
i
. The event has a probability of at least
1-2/n^{2}
by a union bound. Let the event be denoted
\mathcal{E}
. Conditioned on
\mathcal{E}
, we have
\max_{i}f_{i}/\mathbf{e}_{i}\leq n^{3}F
. Now consider the interval
I=[F/(Cn\log n),n^{3}F]
. The values
f_{i}/\mathbf{e}_{i}
that are smaller than
F/(Cn\log n)
contribute at most
F/(C\log n)
to the sum
\sum_{i=1}^{n}f_{i}/\mathbf{e}_{i}
.

Partition the interval
I
into
I_{1},\ldots,
such that
I_{j}=[2^{j-1}(F/(Cn\log n)),2^{j}(F/(Cn\log n)))
. Note that there are at most
O(\log n)
such intervals. We will use the fact that conditioned on
\mathcal{E}
, the random variables
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
are still independent.

Let
\mathbf{X}_{j}
be the number of indices
i
such that
f_{i}/\mathbf{e}_{i}\in I_{j}
. We have

\displaystyle\sum_{i}f_{i}/\mathbf{e}_{i}\leq\frac{F}{C\log n}+\sum_{j=0}^{O(\log n)}2^{j}\mathbf{X}_{j}\frac{F}{Cn\log n}.

Let
\mathbf{Y}_{ij}=1
if
f_{i}/\mathbf{e}_{i}\geq 2^{j-1}(F/(Cn\log n))
and
\mathbf{Y}_{ij}=0
otherwise. Note that
\mathbf{X}_{j}\leq\sum_{i=1}^{n}\mathbf{Y}_{ij}
and that for a fixed
j
, the random variables
\mathbf{Y}_{ij}
are mutually independent given
\mathcal{E}
. We have

\displaystyle\operatorname{Pr\/}[\mathbf{Y}_{ij}=1\mid\mathcal{E}]=\operatorname{Pr\/}\left[\mathbf{e}_{i}\leq\frac{Cn\log n}{2^{j-1}}\frac{f_{i}}{F}\mid\mathcal{E}\right]\leq\frac{2Cn\log n}{2^{j-1}}\frac{f_{i}}{F}

since the p.d.f. of the exponential distribution is bounded above by
1
and
\operatorname{Pr\/}[\mathcal{E}]\geq 1/2
. By linearity of expectation,
\operatorname{E\/}[\sum_{i}\mathbf{Y}_{ij}\mid\mathcal{E}]\leq 2Cn\log n/(2^{j-1})
. By Bernstein’s inequality, we get

\displaystyle\operatorname{Pr\/}[\sum_{i}\mathbf{Y}_{ij}\geq(\operatorname{E\/}[\sum_{i}\mathbf{Y}_{ij}\mid\mathcal{E}]+t)\mid\mathcal{E}]\leq\exp\left(-\frac{t^{2}/2}{2Cn\log n/(2^{j-1})+t/3}\right).

Setting
t=2Cn\log n/(2^{j-1})+6\log n
, we obtain that

\displaystyle\operatorname{Pr\/}[\sum_{i}\mathbf{Y}_{ij}\geq(\operatorname{E\/}[\sum_{i}\mathbf{Y}_{ij}\mid\mathcal{E}]+t)\mid\mathcal{E}]\leq\frac{1}{n^{2}}.

We union bound over all
j
and obtain that for all
j
,

\displaystyle\mathbf{X}_{j}\leq\frac{2Cn\log n}{2^{j-1}}+6\log n.

Additionally, we note that if
\mathbf{X}_{j}\neq 0
, then
2^{j}(F/(Cn\log n))\leq 2\max_{i}f_{i}/\mathbf{e}_{i}
. Now,

\displaystyle\sum_{i}f_{i}/\mathbf{e}_{i}\leq\frac{F}{C\log n}+\sum_{j:\mathbf{X}_{j}\neq 0}2^{j}\mathbf{X}_{j}\frac{F}{Cn\log n}

\displaystyle\leq\sum_{j:\mathbf{X}_{j}\neq 0}\left(\frac{2Cn\log n}{2^{j-1}}\frac{2^{j}F}{Cn\log n}+(6\log n)\max_{i}f_{i}/\mathbf{e}_{i}\right)

\displaystyle\leq O(F\log n)+O(\log^{2}n)\max_{i}f_{i}/\mathbf{e}_{i}.

As
\max_{i}f_{i}/\mathbf{e}_{i}\geq F/(3\log n)
with probability
\geq 1-1/n^{2}
conditioned on
\mathcal{E}
, we get that with probability
\geq 1-1/\operatorname{poly}(n)
,

\displaystyle\frac{\max_{i}f_{i}/\mathbf{e}_{i}}{\sum_{i}f_{i}/\mathbf{e}_{i}}\geq\frac{1}{C\log^{2}n}.

If
\max_{i}f_{i}/\mathbf{e}_{i}\geq(\sum_{i}f_{i}/\mathbf{e}_{i})/C\log^{2}n
, we obtain that for any parameter
T\geq 1
,

\displaystyle|\{i\mid f_{i}/\mathbf{e}_{i}\geq(1/T)\max_{i}f_{i}/\mathbf{e}_{i}\}|\leq TC\log^{2}n

which shows that there are only a small number of indices for which
f_{i}/\mathbf{e}_{i}
is comparable to
\max_{i}f_{i}/\mathbf{e}_{i}
.

3
Sampling from Additively-Defined Distributions

Consider the setting of
s
servers with a coordinator. Assume that the
j
-th server has a non-negative vector
p(j)\in\mathbb{R}^{n}
and the coordinator wants
N
independent samples from the distribution supported on
[n]
with the probability of
i\in[n]
being

\displaystyle q_{i}\coloneqq\frac{\sum_{j}p_{i}(j)}{\sum_{i,j}p_{i}(j)}.

(6)

For each sample, we would ideally also want an estimate to the probability of obtaining that sample. The sampling probabilities are necessary to scale the statistics appropriately to obtain unbiased estimators. A simple one round algorithm for sampling from such a distribution is for all the servers
j
to send the value
\sum_{i}p_{i}(j)
and an index
i
with probability proportional to
p_{i}(j)
. The coordinator then picks a server
j
with probability proportional to
\sum_{i}p_{i}(j)
and chooses the index
i
that the server
j
sampled. Note that the coordinate
i
sampled this way has the desired distribution. While this sampling procedure only requires one round of communication, note that the coordinator does not have the value
\sum_{j}p_{i}(j)
nor even a way to estimate it. Hence if the index
i
was sampled by the coordinator, it is not clear how to compute (or even approximate)
q_{i}
without further rounds of communication. If another round of communication is allowed, the coordinator can send the sampled coordinate
i
to all the servers which in turn report the values
p_{i}(j)
from which the coordinator can compute
q_{i}
exactly.

Using exponential random variables, we show that there is a protocol using which the coordinator can sample a coordinate
i
and approximate the probability
q_{i}
with only one round of communication.

Let
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
be independent exponential random variables that all the servers (and the coordinator) sample using the shared randomness. Each server
j
locally computes
\mathbf{e}_{i}^{-1}p_{i}(j)
. Let
i^{*}\coloneqq\argmax_{i}\mathbf{e}_{i}^{-1}\sum_{j}p_{i}(j)
. As we have seen, the probability distribution of
i^{*}
is exactly as in (
6
) and the advantage now is that with probability
\geq 1-1/\operatorname{poly}(n)
,

\displaystyle\frac{\mathbf{e}_{i^{*}}^{-1}\sum_{j}p_{i^{*}}(j)}{\sum_{i,j}\mathbf{e}_{i}^{-1}p_{i}(j)}\geq\frac{1}{C\log^{2}n}.

We can further show the following lemma which is helpful to isolate the max coordinate
i^{*}
.

Lemma 3.1
.

Let
f_{1},\ldots,f_{n}\geq 0
. and
i^{*}=\argmax_{i\in[n]}\mathbf{e}_{i}^{-1}f_{i}
where
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
are independent standard exponential random variables. We have for all
i\in[n]
that

\displaystyle\frac{f_{i}}{\sum_{i^{\prime}}f_{i^{\prime}}}\geq\operatorname{Pr\/}\left[i^{*}=i\ \text{and}\ \mathbf{e}_{i^{*}}^{-1}f_{i^{*}}\geq(1+\varepsilon)\max_{i^{\prime}\neq i^{*}}\mathbf{e}_{i}^{-1}f_{i^{\prime}}\right]\geq\frac{f_{i}}{(1+\varepsilon)\sum_{i^{\prime}}f_{i^{\prime}}}.

Proof.

Fix
i\in[n]
. The probability in the theorem statement is equivalent to the probability of
\mathbf{e}_{i}^{-1}f_{i}\geq(1+\varepsilon)\max_{i^{\prime}\neq i}\mathbf{e}_{i^{\prime}}^{-1}f_{i^{\prime}}
. The probability is clearly at most
f_{i}/\sum_{i^{\prime}}f_{i^{\prime}}
.

By min-stability of exponential random variables,
\max_{i^{\prime}\neq i}\mathbf{e}_{i^{\prime}}^{-1}f_{i^{\prime}}
is distributed as
\mathbf{e}^{-1}\sum_{i^{\prime}\neq i}f_{i^{\prime}}
. Note that the exponential random variable
\mathbf{e}
is independent of
\mathbf{e}_{i}
. By standard arguments,

\operatorname{Pr\/}[\mathbf{e}_{i}^{-1}f_{i}\geq\mathbf{e}^{-1}(1+\varepsilon)\sum_{i^{\prime}\neq i}f_{i}^{\prime}]=\frac{f_{i}}{f_{i}+(1+\varepsilon)\sum_{i^{\prime}\neq i}f_{i^{\prime}}}\geq\frac{f_{i}}{(1+\varepsilon)\sum_{i^{\prime}}f_{i^{\prime}}}.\qed

Thus,
\mathbf{e}_{i^{*}}^{-1}\sum_{j}p_{i^{*}}(j)
in addition to capturing a
significant
portion of the interval
\sum_{i,j}\mathbf{e}_{i}^{-1}p_{i}(j)
is also at least a
1+\varepsilon
factor larger than the second largest value. We use these properties to prove the following theorem:

Theorem 3.2
.

Given that each server
j
has a non-negative vector
p(j)\in\mathbb{R}^{n}
, define
q_{i}\coloneqq\sum_{j}p_{i}(j)
. Algorithm
1
outputs FAIL only with probability
O(\varepsilon)
and conditioned on not failing, for all
i\in[n]

\displaystyle\operatorname{Pr\/}[\hat{i}=i\ \text{and}\ \hat{q}\in(1\pm O(\varepsilon))\frac{q_{i}}{\sum_{i}q_{i}}]=(1\pm O(\varepsilon))\frac{q_{i}}{\sum_{i}q_{i}}\pm 1/\operatorname{poly}(n).

The algorithm uses only one round and has a total communication of
O(s\operatorname{polylog}(n)/\varepsilon^{2})
words.

Proof.

All the random variables used in the proof are as defined in the algorithm. The algorithm fails to sample if
\max_{i}\mathbf{X}_{i}\leq S/(2C\log^{2}n)
or if
\mathbf{X}_{(1)}\leq(1+\varepsilon/2)\mathbf{X}_{(2)}
. Let
\mathcal{E}
denote the event that
\max_{i}\mathbf{e}_{i}^{-1}q_{i}\geq\sum_{i}\mathbf{e}_{i}^{-1}q_{i}/4C\log^{2}n
and
(\max_{i}\mathbf{e}_{i}^{-1}q_{i})\geq(1+\varepsilon/4)\cdot\text{second-max}_{i}\,\mathbf{e}_{i}^{-1}q_{i}
. We now bound
\operatorname{Pr\/}[\mathcal{E}\mid\lnot\text{FAIL}]
. By Bayes’ theorem, we have

\displaystyle\operatorname{Pr\/}[\mathcal{E}\mid\lnot\text{FAIL}]=\frac{\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}]\operatorname{Pr\/}[\mathcal{E}]}{\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}]\operatorname{Pr\/}[\mathcal{E}]+\operatorname{Pr\/}[\lnot\text{FAIL}\mid\lnot\mathcal{E}]\operatorname{Pr\/}[\lnot\mathcal{E}]}.

We have
\operatorname{Pr\/}[\mathcal{E}]\geq 1/(1+\varepsilon/4)-1/\operatorname{poly}(n)
from the above lemma. Let
\mathcal{E}^{\prime}
denote the event that
\max_{i}\mathbf{e}_{i}^{-1}q_{i}\geq\sum_{i}\mathbf{e}_{i}^{-1}q_{i}/C\log^{2}n
and
(\max_{i}\mathbf{e}_{i}^{-1}q_{i})\geq(1+\varepsilon)\cdot\text{second-max}_{i}\,\mathbf{e}_{i}^{-1}q_{i}
. We note that
\mathcal{E}^{\prime}\subseteq\mathcal{E}
and that
\operatorname{Pr\/}[\mathcal{E}^{\prime}]\geq 1/(1+\varepsilon)-1/\operatorname{poly}(n)
. Now,

\displaystyle\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}]\geq\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}^{\prime}]\operatorname{Pr\/}[\mathcal{E}^{\prime}\mid\mathcal{E}]\geq\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}^{\prime}]\operatorname{Pr\/}[\mathcal{E}^{\prime}].

Condition on
\mathcal{E}^{\prime}
and let
i^{*}=\argmax\mathbf{e}_{i}^{-1}q_{i}

S\geq O(C^{2}\log^{5}n/\varepsilon^{2})

Additionally, for all other indices
i

\displaystyle\operatorname{Pr\/}[\mathbf{X}_{i}\geq S\frac{\mathbf{e}_{i}^{-1}q_{i}}{\sum_{i}\mathbf{e}_{i}^{-1}q_{i}}+\frac{\varepsilon}{8}\frac{S}{C\log^{2}n}]\leq 1/\operatorname{poly}(n).

Taking a union bound over all the indices
i\neq i^{\prime}
, we get that with probability

\displaystyle\mathbf{X}_{i}<S\frac{\mathbf{e}_{i}^{-1}q_{i}}{\sum_{i}\mathbf{e}_{i}^{-1}q_{i}}+\frac{\varepsilon}{4}\frac{S}{C\log^{2}n}\leq S\frac{\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}}{\sum_{i}\mathbf{e}_{i}^{-1}q_{i}}(1/(1+\varepsilon)+\varepsilon/8)\leq\frac{1-\varepsilon/5}{1+\varepsilon/2}S\frac{\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}}{\sum_{i}\mathbf{e}_{i}^{-1}q_{i}}

when

and we get

\displaystyle\operatorname{Pr\/}[\lnot\text{FAIL}\mid\mathcal{E}]\geq(1-1/\operatorname{poly}(n))(1/(1+\varepsilon)-1/\operatorname{poly}(n)).

Now similarly, we show that
\operatorname{Pr\/}[\text{FAIL}\mid\lnot\mathcal{E}]
is large. Condition on
\lnot\mathcal{E}
and again let
i^{*}=\max_{i}\mathbf{e}_{i}^{-1}q_{i}

\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}/\sum_{i}\mathbf{e}_{i}^{-1}q_{i}\leq 1/4C\log^{2}n

\max_{i}\mathbf{X}_{i}<S/(2C\log^{2}n)
with probability
\geq 1-1/\operatorname{poly}(n)
. Suppose
\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}/\sum_{i}\mathbf{e}_{i}^{-1}q_{i}>1/4C\log^{2}n
but
\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}/\sum_{i}\mathbf{e}_{i}^{-1}q_{i}<(1+\varepsilon/4)\cdot\text{second-max}_{i}\,\mathbf{e}_{i}^{-1}q_{i}
. By using a Chernoff bound, we get
\mathbf{X}_{(1)}<(1+\varepsilon/2)\mathbf{X}_{(2)}
with a probability
\geq 1-1/\operatorname{poly}(n)
. Hence,
\operatorname{Pr\/}[\text{FAIL}\mid\lnot\mathcal{E}]\geq 1-1/\operatorname{poly}(n)
. Thus, overall

\displaystyle\operatorname{Pr\/}[\mathcal{E}\mid\lnot\text{FAIL}]=1-1/\operatorname{poly}(n).

Now, conditioned on
\lnot\text{FAIL}
and
\mathcal{E}
, with probability
\geq 1-1/\operatorname{poly}(n)
,
\hat{i}=i^{*}
and

\displaystyle\mathbf{Y}_{\hat{i}}/S=\mathbf{Y}_{i^{*}}/S=(1\pm\varepsilon/2)\frac{\mathbf{e}_{i^{*}}^{-1}q_{i^{*}}}{\sum_{i}\mathbf{e}_{i}^{-1}q_{i}}

and hence,
\hat{q}=(1\pm\varepsilon/2)q_{i^{*}}/\sum_{i}q_{i}

\displaystyle\operatorname{Pr\/}[\hat{i}=i\mid\lnot\text{FAIL}]

\displaystyle=\operatorname{Pr\/}[\hat{i}=i\mid\lnot\text{FAIL},\mathcal{E}]\operatorname{Pr\/}[\mathcal{E}\mid\lnot\text{FAIL}]+\operatorname{Pr\/}[\hat{i}=i\mid\lnot\text{FAIL},\lnot\mathcal{E}]\operatorname{Pr\/}[\lnot\mathcal{E}\mid\lnot\text{FAIL}]

\displaystyle=\operatorname{Pr\/}[i^{*}=i\mid\mathcal{E}]\pm 1/\operatorname{poly}(n)

\displaystyle=\frac{q_{i}}{\sum_{i}q_{i}}(1\pm O(\varepsilon))\pm 1/\operatorname{poly}(n),

where the last inequality is from the previous lemma.

Sampling from General Distributions

As the above theorem shows, Algorithm
1
can sample approximately from very general “additively-defined” distributions. As a simple application, we show that it can be used to obtain a leverage score sample from the deduplicated matrix. In this setting, each server
j
has a matrix
A^{(j)}
with
d
columns. Assume that each row
a_{i}
of the matrix
A^{(j)}
is associated with a tag
t_{i}
. Assume that across all the servers, a tag
t
is always associated with the same row. Let
A
be the matrix formed by the rows that correspond to distinct tags across the servers. For example, suppose a pair of row and tag
(a,t)
is present in the servers
1
,
2
and
3
. In this deduplicated case, the matrix
A
has only one copy of the row
a
. Suppose server
1
has a pair
(a,1)
and server
2
has a pair
(a,2)
i.e., the same row is associated with different tags at different servers, then the matrix
A
has both the copies of the row. We want to sample rows of
A
from the associated
\ell_{2}
leverage score distribution. For a row
a
of the matrix
A
, the leverage score of
a
with respect to
A
is defined as

\displaystyle\tau_{A}(a)\coloneqq\max_{x}\frac{|\langle a,x\rangle|^{2}}{\|Ax\|_{2}^{2}}.

If the row
a
is not in the matrix
A
, we define
\tau_{A}(a)=0
. An important property of the leverage score distribution is that
\sum_{a\in A}\ell_{A}(a)=\text{rank}(A)\leq d
since
A
has
d
columns.
Given a tag
t
, let
a_{t}
be the row associated with the tag
t
. As the matrix
A
is formed by the “union” of all the matrices
A^{(1)},\ldots,A^{(t)}
, for any
x
we have
\|Ax\|_{2}^{2}\geq\|A^{(j)}x\|_{2}^{2}
. Hence if
a
is a row of the matrix
A^{(j)}
, then
\tau_{A^{(j)}}(a)\geq\tau_{A}(a)
. Let the tags be drawn from a set
T
. Each server
j
can now define a
|T|
-dimensional vector
p(j)
such that for each
t\in T

\displaystyle p_{t}(j)=\tau_{A^{(j)}}(a_{t}).

Here we note that if the tag
t
is not present in the matrix
A^{(j)}
, we have
p_{t}(j)=0
. We now have for any tag
t
,

\displaystyle\frac{\sum_{j=1}^{s}p_{t}(j)}{\sum_{j=1}^{s}\sum_{t\in T}p_{t}(j)}=\frac{\sum_{j=1}^{s}\tau_{A^{(j)}}(a_{t})}{\sum_{j=1}^{s}\sum_{t\in T}\tau_{A^{(j)}}(a_{t})}\geq\frac{\tau_{A}(a_{t})}{\sum_{j=1}^{s}\text{rank}(A^{(j)})}\geq\frac{\tau_{A}(a_{t})}{s\cdot\text{rank}(A)}.

Here, we used the monotonicity of leverage scores which directly follows from the definition. Such a sampling distribution is an
s
-approximate leverage score distribution and has numerous applications such as computing subspace embeddings
[
39
]
. This application shows that Algorithm
1
can sample from useful distributions and importantly give approximations to the probabilities of the samples using only one round of communication.

While this very general sampling procedure can be used to construct a subspace embedding for the deduplicated matrix in the coordinator model, it is unclear how to extend these algorithms to more general topologies to obtain algorithms in the personalized CONGEST model in which we want the protocols to have additional nice properties as discussed in the introduction. In later sections, we define the concept of composable sketches and how they are useful to obtain protocols in the personalized CONGEST model.

Recall that we say a non-negative function
f
satisfies “approximate invertibility” with parameters
\theta,\theta^{\prime},\theta^{\prime\prime}>1
if the following hold:

1.

for all
x_{1},x_{2}\geq 0
, it holds that
f(x_{1})+f(x_{2})\leq f(x_{1}+x_{2})
which additionally implies that
f(0)=0
,

2.

for all
x
,
f(\theta^{\prime}x)\geq\theta f(x)
, and

3.

for all
x
,
f(x/(4\cdot\sqrt{\theta}\cdot\theta^{\prime}))\geq f(x)/\theta^{\prime\prime}
.

Note that plugging
x=f^{-1}(z)
in the second property above, we get
\theta^{\prime}f^{-1}(z)\geq f^{-1}(\theta z)
.
We now define
\varepsilon_{1}\coloneqq 1/\theta^{\prime\prime}
and
\varepsilon_{2}\coloneqq 1-1/\theta^{\prime\prime}
. We can show that for all values of
0\leq x_{2}\leq x_{1}
, if
f(x_{2})\leq\varepsilon_{1}f(x_{1})
, then
f(x_{1}-x_{2})\geq(1-\varepsilon_{2})f(x_{1})
. This essentially shows that if
f(x_{2})
is very small as compared to
f(x_{1})
, then
f(x_{1}-x_{2})
can not be very small when compared to
f(x_{1})
. These properties make the function
f
“approximately invertible”, meaning that good approximations for
f(x)
will let us approximate the preimage
x
as well. We say that a function
f
that satisfies the above properties is “approximately invertible” with parameters
\theta,\theta^{\prime},\theta^{\prime\prime}
.

Note that for an integer
s\geq 1
, we defined
c_{f}[s]
to be the smallest number such that for all
x_{1},\ldots,x_{s}\geq 0
,

\displaystyle f(x_{1}+\cdots+x_{s})\leq\frac{c_{f}[s]}{s}\left(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{s})}\right)^{2}.

Using the Cauchy-Schwarz inequality, we additionally have

f(x_{1}+\cdots+x_{s})\leq c_{f}[s]\left(f(x_{1})+\cdots+f(x_{s})\right)

for all
x_{1},\ldots,x_{s}\geq 0
.
We show that the parameter
c_{f}[s]
as a function of
s
cannot grow arbitrarily. Consider arbitrary integers
s,t\geq 1
. The following lemma shows that
c_{f}[s\cdot t]\leq c_{f}[s]\cdot c_{f}[t]
which implies that the function
c_{f}[s]
is upper bounded by a polynomial in
s
with a degree that depends only on
c_{f}[2]
.

Lemma 4.1
.

For any
x_{1},x_{2},\ldots,x_{s\cdot t}\geq 0
,

\displaystyle f(x_{1}+\cdots+x_{s\cdot t})\leq\frac{c_{f}[s]\cdot c_{f}[t]}{s\cdot t}\left(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{s\cdot t})}\right)^{2}.

Proof.

By definition of
c_{f}[s]
, we obtain

\displaystyle f(x_{1}+\cdots+x_{s\cdot t})

\displaystyle\leq\frac{c_{f}[s]}{s}\left(\sqrt{f(x_{1}+\cdots+x_{t})}+\sqrt{f(x_{t+1})+\cdots+f(x_{2\cdot t})}+\cdots+\sqrt{f(x_{(s-1)\cdot t+1}+\cdots+f(x_{s\cdot t}))}\right)^{2}.

Now we use
c_{f}[t]
to expand the internal terms, to get

\displaystyle f(x_{1}+\cdots+x_{s\cdot t})\leq\frac{c_{f}[s]}{s}\frac{c_{f}[t]}{t}\left(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{s\cdot t})}\right)^{2}.

By definition of
c_{f}[s\cdot t]
, we obtain
c_{f}[s\cdot t]\leq c_{f}[s]\cdot c_{f}[t]
.
∎

The above lemma upper bounds the growth of the parameter
c_{f}[s]
. We now lower bound the growth and show that
c_{f}[s]
must grow at least linearly in the parameter
s
.

Lemma 4.2
.

If
s\geq t
, then
c_{f}[s]\geq c_{f}[t]\cdot s/t
.

Proof.

Let
x_{1},\ldots,x_{t}\geq 0
be arbitrary.

\displaystyle f(x_{1}+\cdots+x_{t})

\displaystyle=f(x_{1}+\cdots+x_{t}+\underbrace{0+\cdots+0}_{s-t})

\displaystyle\leq\frac{c_{f}[s]}{s}\left(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{t})}+\underbrace{\sqrt{f(0)}+\cdots+\sqrt{f(0)}}_{s-t}\right)^{2}

\displaystyle\leq\frac{c_{f}[s]}{s}(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{t})})^{2}

where we used
f(0)=0
in the last inequality.
Hence by definition of
c_{f}[t]
, we get
c_{f}[t]/t\leq c_{f}[s]/s
from which we obtain that
c_{f}[s]\geq c_{f}[t]\cdot s/t
.
∎

Using the above properties, we obtain that
c_{f}[s]\leq c_{f}[2^{\lceil\log_{2}(s)\rceil}]\leq(c_{f}[2])^{\lceil\log_{2}(s)\rceil}\leq c_{f}[2]\cdot s^{\log_{2}c_{f}[2]}
which shows that
c_{f}
only grows at most
polynomially
in the number of servers
s
and the degree of growth is upper bounded
\log_{2}c_{f}[2]
. For example, if
f(x)=x^{k}
, then we can show
c_{f}[2]=2^{k-1}
from which we obtain that
c_{f}[s]\leq(2s)^{k-1}
for all the values of
s
.

In addition, if
c_{f}[t]\geq c_{f}[s]/\alpha
for some value
\alpha
, using the second property above, we obtain
c_{f}[s]\geq c_{f}[t]\cdot s/t\geq(c_{f}[s]/\alpha)\cdot(s/t)
which implies
t\geq s/\alpha
. Thus if
c_{f}[t]
is “comparable” to
c_{f}[s]
, then
t
is “comparable” to
s
as well. This is a property that we critically use in the analysis of our algorithm.

Protocol Description and Analysis

We now recall the overview of the algorithm we presented in the introduction and define some notation that we use throughout our analysis. All the servers together with the coordinator use the shared randomness and sample standard exponential random variables
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
and the goal of the coordinator is to compute

\displaystyle\max_{i}\mathbf{e}_{i}^{-1}f(x_{i}).

Define
i^{*}\coloneqq\argmax_{i}\mathbf{e}_{i}^{-1}f(x_{i})
. We have seen that the median of
O(1/\varepsilon^{2})
independent copies of the random variable
\max_{i}\mathbf{e}_{i}^{-1}f(x_{i})
can be used to compute a
1\pm\varepsilon
approximation to
\sum_{i}f(x_{i})
with high probability. Throughout the analysis, we condition on the event that

\displaystyle\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i})\leq(C\log^{2}n)\cdot\max_{i}\mathbf{e}_{i}^{-1}f(x_{i}).

We have seen that this event holds with probability
\geq 1-1/\operatorname{poly}(n)
over the exponential random variables. Now fix a server
j\in[s]
. The server
j
samples
N
independent copies of the random variable
\mathbf{i}
supported in the set
[n]
and has a distribution defined as

\displaystyle\operatorname{Pr\/}[\mathbf{i}=i]=\frac{\mathbf{e}_{i}^{-1}f(x_{i})}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i})}.

Let
\textnormal{{{SC}}}_{j}
denote the set of coordinates that are sampled by the server
j
. The server
j
then sends the set
\textnormal{{{SC}}}_{j}
along with (i) the sum
\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))
and (ii) the values
x_{i}(j)
for
i\in\textnormal{{{SC}}}_{j}
to the coordinator using
O(N)
words of communication.

The coordinator defines the set
\textnormal{{{SC}}}\coloneqq\bigcup_{j}\textnormal{{{SC}}}_{j}
as the union of the sets of coordinates that are sampled at different servers. We will first show that the coordinate
i^{*}\in\textnormal{{{SC}}}
with a large probability if
N
is large enough.

4.1
The coordinate
i^{*}
is sampled

Lemma 4.3
.

If
N\geq(C_{\ref{lma:i-star-is-sampled}}\log^{3}n)\cdot c_{f}[s]/s
for a universal constant

large enough, then the coordinate

with a probability

Proof.

Let
q_{i^{*}}(j)=\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}(j))/\sum_{i\in[n]}\mathbf{e}_{i}^{-1}f(x_{i}(j))
be the probability that the random variable
\mathbf{i}=i^{*}
(note that the random variable
\mathbf{i}
has a different distribution at each server) and
p_{i^{*}}(j)
be the probability that
i^{*}\in\textnormal{{{SC}}}_{j}
. We have

\displaystyle p_{i^{*}}(j)=1-\left(1-q_{i^{*}}(j)\right)^{N}.

If
q_{i^{*}}(j)=(4\log n)/N
, then
p_{i^{*}}(j)\geq 1-(1-q_{i^{*}}(j))^{N}\geq 1-\exp(-q_{i^{*}}(j)N)\geq 1-\exp(-4\log n)\geq 1-1/n^{4}
which implies that
i^{*}\in\textnormal{{{SC}}}_{j}\subseteq\textnormal{{{SC}}}
with probability
\geq 1-1/n^{4}
and we are done. Otherwise,

\displaystyle p_{i^{*}}(j)=1-(1-q_{i^{*}}(j))^{N}\geq\frac{Nq_{i^{*}}(j)}{4\log n}(1-1/n^{4})

(7)

using the concavity of the function
1-(1-x)^{N}
in the interval
[0,4\log n/N]
.

Since each of the servers samples the coordinates independently, the probability that
i^{*}\in\textnormal{{{SC}}}
is
1-(1-p_{i^{*}}(1))(1-p_{i^{*}}(2))\cdots(1-p_{i^{*}}(s))\geq 1-\exp(-\sum_{j}p_{i^{*}}(j))
. So, showing that the sum
\sum_{j}p_{i^{*}}(j)
is large implies that
i^{*}
is in the set
SC
with a large probability. Assume that for all
j
,
q_{i^{*}}(j)<4\log n/N
since otherwise we already have that the coordinate
i^{*}\ \in\textnormal{{{SC}}}
with probability
\geq 1-1/n^{4}
. Now using (
7
)

\displaystyle\sum_{j}p_{i^{*}}(j)\geq\frac{N}{8\log n}\sum_{j}q_{i^{*}}(j)=\frac{N}{8\log n}\sum_{j}\frac{\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}.

We will now give a lower bound on the the sum in the above equation using the following simple lemma and the definition of the parameter
c_{f}[s]
.

Lemma 4.4
.

Let
a_{1},\ldots,a_{s}\geq 0
and
b_{1},\ldots,b_{s}>0
be arbitrary. Then,

\displaystyle\sum_{j\in[s]}\frac{a_{j}}{b_{j}}\geq\frac{(\sum_{j\in[s]}\sqrt{a_{j}})^{2}}{\sum_{j}b_{j}}.

Proof.

We prove the lemma by using the Cauchy-Schwarz inequality. Since we assume that
b_{j}>0
for all
j
, we can write

\displaystyle\sum_{j\in[s]}\sqrt{a_{j}}=\sum_{j\in[s]}\sqrt{\frac{a_{j}}{b_{j}}}\sqrt{b_{j}}.

Using the Cauchy-Schwarz inequality, we get

\displaystyle\sum_{j\in[s]}\sqrt{a_{j}}=\sum_{j\in[s]}\sqrt{\frac{a_{j}}{b_{j}}}\sqrt{b_{j}}\leq\sqrt{\sum_{j\in[s]}\frac{a_{j}}{b_{j}}}\sqrt{\sum_{j\in[s]}b_{j}}.

Squaring both sides and using the fact that
\sum_{j\in[s]}b_{j}>0
, we get

\displaystyle\sum_{j\in[s]}\frac{a_{j}}{b_{j}}\geq\frac{(\sum_{j\in[s]}\sqrt{a_{j}})^{2}}{\sum_{j\in[s]}b_{j}}.

Letting
a_{j}=\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}(j))
and
b_{j}=\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))
in the above lemma, we get

\displaystyle\sum_{j}\frac{\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}\geq\frac{\mathbf{e}_{i^{*}}^{-1}(\sum_{j\in[s]}\sqrt{f(x_{i^{*}}(j))})^{2}}{\sum_{j}\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}.

Using the definition of
c_{f}[s]
, we obtain

\displaystyle\left(\sum_{j\in[s]}\sqrt{f(x_{i^{*}}(j))}\right)^{2}\geq\frac{s}{c_{f}[s]}(f(x_{i^{*}}(1)+\cdots x_{i^{*}}(s)))=\frac{s}{c_{f}[s]}f(x_{i^{*}}).

Using the super-additivity of the function
f
, we get

\displaystyle\sum_{j}\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))=\sum_{i}\mathbf{e}_{i}^{-1}\sum_{j}f(x_{i}(j))\leq\sum_{i}\mathbf{e}_{i}^{-1}f(\sum_{j}x_{i}(j))=\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}).

Since we conditioned on the event that
\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i})\leq(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})
, we get

\displaystyle\sum_{j}\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))\leq(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

We therefore have

\displaystyle\sum_{j}\frac{\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}\geq\frac{s}{c_{f}[s]}\frac{\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})}{(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})}\geq\frac{s}{C\log^{2}n\cdot c_{f}[s]}.

Thus, if
N\geq(32C\log^{3}n)\cdot c_{f}[s]/s
, then
\sum_{j}p_{i^{*}}(j)\geq 4\log n
which implies that
i^{*}
is in the set
SC
with probability
\geq 1-1/n^{4}
. Letting
C_{\ref{lma:i-star-is-sampled}}\coloneqq 32C
, we have the proof.
∎

When
N\gg c_{f}[s]\log^{3}n/s
as is required by the above lemma, the set
\textnormal{{{SC}}}=\bigcup_{j}\textnormal{{{SC}}}_{j}
may have a size of
\Omega(c_{f}[s]\log^{3}n)
which is quite large. Conditioned on the event that
i^{*}\in\textnormal{{{SC}}}
, we now want to compute a small subset
\textnormal{{{PL}}}\subseteq\textnormal{{{SC}}}
such that

4.2
Computing the set

Recall we condition on the event that

\displaystyle\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i})\leq(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})

and that
i^{*}\in\textnormal{{{SC}}}

for each

For all

\mathbf{e}_{i^{*}}^{-1}f(\hat{x}_{i^{*}})\geq\alpha\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})

Fix an index

\textnormal{{Ignore}}_{i^{*}}
can be ignored as we can make
\mathbf{e}_{i^{*}}^{-1}f(\hat{x}_{i^{*}})
large even without them.
∎

So we only have to focus on the servers for which the quantity
\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))
lies in the interval

\displaystyle\left[\frac{\varepsilon_{1}(1-\varepsilon_{2})}{4Cs^{2}}\sum_{i,j}\mathbf{e}_{i}^{-1}f(x_{i}(j)),\max_{j}\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))\right].

Now define
F_{\text{start}}\coloneqq\frac{\varepsilon_{1}(1-\varepsilon_{2})}{4Cs^{2}}\sum_{i,j}\mathbf{e}_{i}^{-1}f(x_{i}(j))
and partition the above interval into intervals
[F_{\text{start}},(\sqrt{\theta}F_{\text{start}})]
,
[(\sqrt{\theta})F_{\text{start}},(\sqrt{\theta})^{2}F_{\text{start}}]
,
\ldots
, and so on. Note that there are at most

\displaystyle B=O\left(\frac{\log(s^{2}/\varepsilon_{1}(1-\varepsilon_{2}))}{\log\theta}\right)

(10)

such intervals. Let
I^{(a,b)}_{i}
for
a=0,1,\ldots,A-1
and
b=0,1,\ldots,B-1
be the set of servers
j
for which

\displaystyle\frac{\mathbf{e}_{i}^{-1}f(x_{i}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}\in[(\sqrt{\theta})^{a}P_{\text{start}},(\sqrt{\theta})^{a+1}P_{\text{start}}],

and

\displaystyle\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))\in[(\sqrt{\theta})^{b}F_{\text{start}},(\sqrt{\theta})^{b+1}F_{\text{start}}].

If the set
|I^{(a,b)}_{i}|
is large, then the number of servers
j\in I^{(a,b)}_{i}
at which
i
is sampled is concentrated which can then in turn be used to approximate
|I^{(a,b)}_{i}|
. But if
|I^{(a,b)}_{i}|
is too small, then we cannot obtain a good approximation using the number of servers in the set
I^{(a,b)}_{i}
that sample
i
. In the following lemma, we show that the contribution from servers in the sets
I^{(a,b)}_{i}
needs to be considered only if
|I^{(a,b)}_{i}|
is large. Let
\textnormal{{Bad}}_{i}
denote the set of tuples
(a,b)
for which

\displaystyle c_{f}[|I^{(a,b)}_{i}|]\leq\frac{c_{f}[s]}{c_{f}[A\cdot B]\cdot(A\cdot B)\cdot(\sqrt{\theta})^{a+1}/(1-\varepsilon_{2})^{2}}.

(11)

Let
\textnormal{{Good}}_{i}
be the set of all the remaining tuples
(a,b)
. We first note that the coordinator cannot determine if a particular tuple
(a,b)
is in the set
\textnormal{{Bad}}_{i}
. Using the properties of
c_{f}[s]
, we get that if
(a,b)\in\textnormal{{Good}}_{i}
, then

\displaystyle|I_{i}^{(a,b)}|\geq\frac{s}{c_{f}[A\cdot B]\cdot(A\cdot B)\cdot(\sqrt{\theta})^{a+1}/(1-\varepsilon_{2})^{2}}.

Lemma 4.7
.

The contribution from servers
j\in\bigcup_{(a,b)\in\textnormal{{Bad}}_{i}}I^{(a,b)}_{i}
can be ignored.

Proof.

By definition of the set of servers
I^{(a,b)}_{i}
,

\displaystyle\sum_{j\in I^{(a,b)}_{i}}\mathbf{e}_{i}^{-1}f(x_{i}(j))

\displaystyle\leq\sum_{j\in I_{i}^{(a,b)}}(\sqrt{\theta})^{a+1}P_{\text{start}}\sum_{i^{\prime}\in[n]}\mathbf{e}_{i^{\prime}}^{-1}f(x_{i^{\prime}}(j))

\displaystyle\leq(\sqrt{\theta})^{a+1}P_{\text{start}}\sum_{i^{\prime}\in[n]}\mathbf{e}_{i^{\prime}}^{-1}\sum_{j\in I_{i}^{(a,b)}}f(x_{i^{\prime}}(j))

\displaystyle\leq(\sqrt{\theta})^{a+1}P_{\text{start}}\sum_{i^{\prime}\in[n]}\mathbf{e}_{i^{\prime}}^{-1}f(x_{i^{\prime}})

\displaystyle\leq(\sqrt{\theta})^{a+1}P_{\text{start}}\cdot(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

By definition of the parameter
c_{f}
, we have

\displaystyle\mathbf{e}_{i}^{-1}f\left(\sum_{(a,b)\in\textnormal{{Bad}}_{i}}\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)\right)

\displaystyle\leq c_{f}[A\cdot B]\left(\sum_{(a,b)\in\textnormal{{Bad}}_{i}}\mathbf{e}_{i}^{-1}f(\sum_{j\in I^{(a,b)}_{i}}x_{i}(j))\right)

\displaystyle\leq c_{f}[A\cdot B]\sum_{(a,b)\in\textnormal{{Bad}}_{i}}c_{f}[|I^{(a,b)}_{i}|]\sum_{j\in I^{(a,b)}_{i}}\mathbf{e}_{i}^{-1}f(x_{i}(j))

\displaystyle\leq c_{f}[A\cdot B]\sum_{(a,b)\in\textnormal{{Bad}}_{i}}c_{f}[|I^{(a,b)}_{i}|]\cdot(\sqrt{\theta})^{a+1}P_{\text{start}}\cdot(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}})

\displaystyle\leq c_{f}[A\cdot B]\sum_{(a,b)\in\textnormal{{Bad}}_{i}}c_{f}[|I^{(a,b)}_{i}|]\cdot(\sqrt{\theta})^{a+1}\cdot\frac{\varepsilon_{1}}{c_{f}[s]\cdot(C\log^{2}n)}\cdot(C\log^{2}n)\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

Using (
11
), we get

\displaystyle\mathbf{e}_{i}^{-1}f\left(\sum_{(a,b)\in\textnormal{{Bad}}_{i}}\sum_{j\in I_{i}^{(a,b)}}x_{i}(j)\right)\leq(1-\varepsilon_{2})^{2}\varepsilon_{1}\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

Taking
i=i^{*}
, we get that

\displaystyle\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}-\sum_{j\in\textnormal{{Small}}_{i^{*}}}x_{i^{*}}(j)-\sum_{j\in\textnormal{{Ignore}}_{i^{*}}}x_{i^{*}}(j)-\sum_{(a,b)\in\textnormal{{Bad}}_{i}}\sum_{j\in I^{(a,b)}_{i^{*}}}x_{i^{*}}(j))\geq(1-\varepsilon_{2})^{3}\cdot\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

Thus the contribution from the servers in the set
I^{(a,b)}_{i}
for tuples
(a,b)\in\textnormal{{Bad}}_{i}
can be ignored.
∎

Now we show that the coordinator can compute
\hat{x}_{i}
by essentially approximating the following quantity:

\displaystyle x_{i}-\sum_{j\in\textnormal{{Small}}_{i}}x_{i}(j)-\sum_{j\in\textnormal{{Ignore}}_{i}}x_{i}(j)-\sum_{(a,b)\in\textnormal{{Bad}}_{i}}\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)

\displaystyle=\sum_{j\in\textnormal{{Large}}_{i}}x_{i}(j)+\sum_{(a,b)\in\textnormal{{Good}}_{i}}\sum_{j\in I_{i}^{(a,b)}}x_{i}(j).

4.2.4
Algorithm to compute
\hat{x}_{i}

We will go on to give an algorithm that can approximate
\hat{x}_{i}
given the samples that the coordinator receives in the first round. We have already seen that given an index
i
, all the servers in the set
\textnormal{{Large}}_{i}
sample the coordinate
i
with a large probability and therefore we can compute the quantity
\sum_{j\in\textnormal{{Large}}_{i}}x_{i}(j)
exactly with high probability. We have also seen that the contribution from servers that are in the set
\textnormal{{Small}}_{i}
and in the set
\textnormal{{Ignore}}_{i}
can be ignored.

The main remaining contribution to
x_{i}
that is to be accounted is from tuples
(a,b)\in\textnormal{{Good}}_{i}
. An important issue we need to solve for is the fact that the coordinator cannot determine if a given tuple
(a,b)
is in the set
\textnormal{{Good}}_{i}
or in
\textnormal{{Bad}}_{i}
. We will show that if
(a,b)\in\textnormal{{Good}}_{i}
, then
i
is sampled at many servers in the set
I^{(a,b)}_{i}
and depending on the
absolute
number of servers in
I^{(a,b)}_{i}
that sample
i
, we mark a tuple
(a,b)
as “probably good for
i
”. We argue that, with high probability, all tuples
(a,b)\in\textnormal{{Good}}_{i}
are marked “probably good for
i
” and that for the tuples
(a,b)
in
\textnormal{{Bad}}_{i}
that are marked “probably good for
i
”, we will still obtain good approximations for
|I^{(a,b)}_{i}|
.

The following lemma shows why approximating
|I_{i}^{(a,b)}|
is enough to approximate the contributions of the servers in the set
I^{(a,b)}_{i}
.

Lemma 4.8
.

The value
|I^{(a,b)}_{i}|
can be used to approximate
\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)
up to a factor of
\theta^{\prime}
.

Proof.

For all servers
j\in I^{(a,b)}_{i}
, by definition, we have

\displaystyle(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}}\leq\mathbf{e}_{i}^{-1}(f(x_{i}(j)))\leq(\sqrt{\theta})^{a+b+2}P_{\text{start}}F_{\text{start}}

which further implies using the monotonicity of
f
that

\displaystyle f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})\leq x_{i}(j)\leq f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b+2}P_{\text{start}}F_{\text{start}})\leq\theta^{\prime}f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}}).

Now we note

\displaystyle\frac{\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)}{\theta^{\prime}}\leq|I^{(a,b)}_{i}|\cdot f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})\leq\sum_{j\in I^{(a,b)}_{i}}x_{i}(j).

We will then show that the expected number of servers in the set
I^{(a,b)}_{i}
that sample
i
can be used to obtain an approximation for
|I^{(a,b)}_{i}|
.

Lemma 4.9
.

Let
p_{i}(j)\coloneqq 1-(1-q_{i}(j))^{N}
denote the probability that the coordinate
i
is among the
N
coordinates sampled at server
j
. For any tuple
(a,b)
,

\displaystyle|I^{(a,b)}_{i}|\cdot\frac{(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})}{\sqrt{\theta}}\leq\sum_{j\in I^{(a,b)}_{i}}p_{i}(j)\leq|I^{(a,b)}_{i}|\cdot(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N}).

Proof.

Using monotonicity and concavity of the function
1-(1-x)^{N}
in the interval
[0,1]
, for all
j\in I^{(a,b)}_{i}
, we have

\displaystyle(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})\geq p_{i}(j)\geq\frac{(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})}{\sqrt{\theta}}.

Summing the inequalities over all
j\in I^{(a,b)}_{i}
gives the proof.
∎

If
\sum_{j\in I^{(a,b)}_{i}}p_{j}
is large enough, we obtain using a Chernoff bound that the number of servers in
I^{(a,b)}_{i}
at which
i
is sampled is highly concentrated around the mean
\sum_{j\in I^{(a,b)}_{i}}p_{j}
and using the above lemmas, we can obtain an estimate for
|I^{(a,b)}_{i}|
and therefore estimate
\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)
. We will follow this approach to approximate
\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)
. Let
\mathbf{X}^{(a,b)}_{i}
be the number of servers in
j\in I^{(a,b)}_{i}
that sample the coordinate
i
. By linearity of expectation, we have
\operatorname{E\/}[\mathbf{X}^{(a,b)}_{i}]=\sum_{j\in I^{(a,b)}_{i}}p_{j}
. We will now use the following standard concentration bounds.

Lemma 4.10
.

Let
\mathbf{Y}_{j}
for
j\in[t]
be a Bernoulli random variable with
\operatorname{Pr\/}[\mathbf{Y}_{j}=1]=p_{j}
. Let
\mathbf{Y}_{1},\ldots,\mathbf{Y}_{t}
be mutually independent and
\mathbf{X}=\mathbf{Y}_{1}+\cdots+\mathbf{Y}_{t}
. Then the following inequalities hold:

1.

If
\sum_{j}p_{j}\geq 100\log n
, then

\displaystyle\operatorname{Pr\/}[\mathbf{X}=(1\pm 1/3)\sum_{j=1}^{t}p_{j}]\geq 1-1/n^{3}.

2.

For any values of
p_{1},\ldots,p_{t}
,

\displaystyle\operatorname{Pr\/}[\mathbf{X}<2\sum_{j=1}^{t}p_{j}+4\log n]\geq 1-1/n^{4}.

Proof.

To prove the first inequality, we use the multiplicative Chernoff bound. We have

\displaystyle\operatorname{Pr\/}[\mathbf{X}=(1\pm 1/3)\sum_{j=1}^{t}p_{j}]\leq 2\exp\left(-\frac{\sum_{j=1}^{t}p_{j}}{27}\right).

If
\sum_{j=1}^{t}p_{j}\geq 100\log n
, then the RHS is at most
1/n^{3}
. To prove the second inequality, we use the Bernstein concentration bound. We get

\displaystyle\operatorname{Pr\/}[\mathbf{X}\geq 2\sum_{j=1}^{t}p_{j}+4\log n]\leq\exp\left(-\frac{(\sum_{j}p_{j}+4\log n)^{2}}{\sum_{j}p_{j}+(\sum_{j}p_{j}+4\log n)/3}\right)\leq\exp(-4\log n)\leq 1/n^{4}.

We note that if
\sum_{j}p_{j}\geq 100\log n
, then with probability
\geq 1-1/n^{3}
, we have
\mathbf{X}=(1\pm 1/3)\log n\geq 66\log n
and if
\sum_{j}p_{j}\leq 30\log n
, then with probability
\geq 1-1/n^{4}
, we have
\mathbf{X}<64\log n
. Thus the value of
\mathbf{X}
can be used to separate the cases of
\sum_{j}p_{j}\geq 100\log n
or
\sum_{j}p_{j}\leq 30\log n
with high probability.

Now we show that if
(a,b)\in\textnormal{{Good}}_{i}
and
N
is large enough, then
\sum_{j\in I^{(a,b)}_{i}}p_{j}\geq 100\log n
.

Lemma 4.11
.

If
(a,b)\in\textnormal{{Good}}_{i}
and the number of samples
N
at each coordinator satisfies

\displaystyle N\geq O\left(\frac{c_{f}[s]}{s}\cdot\frac{c_{f}[A\cdot B]\cdot(A\cdot B)\cdot\sqrt{\theta}\cdot\log^{4}n}{\varepsilon_{1}(1-\varepsilon_{2})^{2}}\right),

then either
(\sqrt{\theta})^{a+1}P_{\text{start}}\geq 4\log n/N
or
\sum_{j\in I^{(a,b)}_{i}}p_{j}\geq 100\log n
.

Proof.

Assume
(\sqrt{\theta})^{a+1}P_{\text{start}}<4\log n/N
. By concavity of the function
1-(1-x)^{N}
in the interval
[0,1]
,

\displaystyle 1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N}\geq\frac{N(\sqrt{\theta})^{a+1}P_{\text{start}}}{4\log n}(1-1/n^{4}).

For
(a,b)\in\textnormal{{Good}}_{i}
, we then obtain

\displaystyle\sum_{j\in I^{(a,b)}_{i}}p_{j}

\displaystyle\geq|I^{(a,b)}_{i}|\cdot\frac{N(\sqrt{\theta})^{a+1}P_{\text{start}}}{4\log n\sqrt{\theta}}(1-1/n^{4})

\displaystyle\geq\frac{s}{c_{f}[A\cdot B]\cdot(A\cdot B)\cdot(\sqrt{\theta})^{a+1}/(1-\varepsilon_{2})^{2}}\frac{N(\sqrt{\theta})^{a+1}\varepsilon_{1}}{4C\log^{3}n\cdot c_{f}[s]\cdot\sqrt{\theta}}\cdot(1-1/n^{4})

\displaystyle\geq 100\log n.\qed

With a high probability, for all coordinates
i
and all servers
j
in the set
I^{(a,b)}_{i}
for some
a
with
(\sqrt{\theta})^{a+1}P_{\text{start}}\geq 4\log n/N
, the coordinate
i\in\textnormal{{{SC}}}_{j}
. So the contribution from such servers can be computed exactly akin to the servers in the set
\textnormal{{Large}}_{j}
.

Now consider all the tuples
(a,b)\in\textnormal{{Good}}_{i}
with
(\sqrt{\theta})^{a+1}P_{\text{start}}<4\log n/N
. The above lemma shows that
\sum_{j\in I^{(a,b)}_{i}}p_{j}\geq 100\log n
. Thus, if we mark all the tuples
(a,b)
with
\mathbf{X}^{(a,b)}_{i}\geq 66\log n
as “probably good for
i
”, then with a probability
\geq 1-1/n^{2}
, all the tuples
(a,b)
in
\textnormal{{Good}}_{i}
are marked as “probably good for
i
” and any tuple
(a,b)\in\textnormal{{Bad}}_{i}
marked as “probably good for
i
” satisfies

\displaystyle\mathbf{X}^{(a,b)}_{i}\leq 2.5\sum_{j\in I^{(a,b)}_{i}}p_{j}.

We now consider the following algorithm for computing
\hat{x}_{i}
using which we then compute
\textnormal{{Est}}_{i}
:

1.

Let
\mathbf{S}_{i}=\{j\mid i\in\textnormal{{{SC}}}_{j}\}
be the set of all the servers that sample the coordinate
i
.

2.

Let
\hat{x}_{i}\leftarrow 0
denote our initial estimate for
x_{i}
.

3.

Let
\mathbf{L}_{i}=\{j\in\mathbf{S}\mid\frac{\mathbf{e}_{i}^{-1}f(x_{i}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}>\frac{4s}{c_{f}[s]\log^{2}n}\}
. This corresponds to the servers in
\textnormal{{Large}}_{i}
that have sampled
i
. With high probability,
\mathbf{L}_{i}=\textnormal{{Large}}_{i}
. Note that we know the value
x_{i}(j)
for all
j\in\mathbf{L}_{i}
.

4.

Update
\hat{x}_{i}\leftarrow\hat{x}_{i}+\sum_{j\in\mathbf{L}_{i}}x_{i}(j)
.

5.

Update
\mathbf{S}_{i}\leftarrow\mathbf{S}_{i}\setminus\mathbf{L}_{i}
.

6.

Let
\mathbf{Sm}_{i}=\{j\in\mathbf{S}_{i}\mid\frac{\mathbf{e}_{i}^{-1}f(x_{i}(j))}{\sum_{i}\mathbf{e}_{i}^{-1}f(x_{i}(j))}<\frac{\varepsilon_{1}}{c_{f}[s]\cdot(C\log^{2}n)}\}
. Corresponds to the servers in
\textnormal{{Small}}_{i}
that have sampled
i
and therefore the contribution from these servers can be ignored.

7.

Update
\mathbf{S}_{i}\leftarrow\mathbf{S}_{i}\setminus\mathbf{Sm}_{i}
.

8.

For each
a=0,1,\ldots,A-1
and
b=0,1,\ldots,B-1
, set
\mathbf{S}^{(a,b)}_{i}\leftarrow\{j\in\mathbf{S}_{i}\mid j\in I^{(a,b)}_{i}\}
. Note that since for all
j\in\mathbf{S}_{i}
, we know the value of
x_{i}(j)
and therefore we can compute the set
\mathbf{S}^{(a,b)}_{i}
.

9.

For all tuples
(a,b)
with
(\sqrt{\theta})^{a+1}P_{\text{start}}>4\log n/N
, with high probability
\mathbf{S}^{(a,b)}_{i}=I^{(a,b)}_{i}
and we update
\hat{x}_{i}\leftarrow\hat{x}_{i}+\sum_{j\in\mathbf{S}^{(a,b)}_{i}}x_{i}(j)
.

10.

For all other tuples
(a,b)
, if
|\mathbf{S}^{(a,b)}_{i}|\geq 66\log n
, we mark
(a,b)
as “probably good for
i
” and ignore the rest of the tuples.

11.

For all tuples
(a,b)
marked as “probably good for
i
”, we update

\displaystyle\hat{x}_{i}\leftarrow\hat{x}_{i}+\frac{(2/5)|\mathbf{S}_{i}^{(a,b)}|}{1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N}}f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}}).

12.

Compute
\textnormal{{Est}}_{i}\coloneqq\mathbf{e}_{i}^{-1}f(\hat{x}_{i})
.

Using all the lemmas we have gone through till now, we will argue that for all
i\in\textnormal{{{SC}}}
,
\hat{x}_{i}\leq x_{i}
with a high probability, which proves that
\textnormal{{Est}}_{i}
is upper bounded by
\mathbf{e}_{i}^{-1}f(x_{i})
. We then prove
\textnormal{{Est}}_{i^{*}}
is large.

Lemma 4.12
.

With probability
\geq 1-1/n
, for all
i\in[n]
,
\hat{x}_{i}\leq x_{i}
which implies
\textnormal{{Est}}_{i}\leq\mathbf{e}_{i}^{-1}f(x_{i})
.

Proof.

Consider a fixed
i
. We will argue about contributions from different types of servers to
\hat{x}_{i}
separately. By Lemma
4.5
, we have
\mathbf{L}_{i}=\textnormal{{Large}}_{i}
with probability
\geq 1-1/n^{3}
and the contribution
\sum_{j\in\textnormal{{Large}}_{i}}x_{i}(j)
to
x_{i}
is estimated correctly. We deterministically exclude all the servers in
\textnormal{{Small}}_{i}
and therefore we do not overestimate the contribution of
\sum_{j\in\textnormal{{Small}}_{i}}x_{i}(j)
to
x_{i}
.

Now consider the tuples
(a,b)
for
a=0,1,\ldots,A-1
and
b=0,1,\ldots,B-1
. If
a
is such that
(\sqrt{\theta})^{a+1}P_{\text{start}}\geq 4\log n/N
, we again have
\mathbf{S}^{(a,b)}_{i}=I^{(a,b)}_{i}
with a large probability similar to the analysis of Lemma
4.5
and therefore we estimate the contribution of such servers to
x_{i}
exactly.

If
(\sqrt{\theta})^{a+1}P_{\text{start}}<4\log n/N
and
(a,b)\in\textnormal{{Good}}_{i}
, then Lemma
4.11
shows that
\sum_{j\in I^{(a,b)}_{i}}p_{j}\geq 100\log n
. We then obtain using Lemma
4.10
that
66\log n\leq|\mathbf{S}^{(a,b)}_{i}|\leq(4/3)\sum_{j\in I^{(a,b)}_{i}}p_{j}
with a large probability. Using Lemma
4.9
, we get that

\displaystyle\frac{|\mathbf{S}_{i}^{(a,b)}|}{(4/3)(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})}\leq|I^{(a,b)}_{i}|.

Using Lemma
4.8
, we then obtain that

\displaystyle\frac{|\mathbf{S}_{i}^{(a,b)}|}{(4/3)(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})}f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})

\displaystyle\leq|I^{(a,b)}_{i}|f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})\leq\sum_{j\in I^{(a,b)}_{i}}x_{i}(j).

Hence, the contribution of tuples
(a,b)\in\textnormal{{Good}}_{i}
is not overestimated. If
(a,b)\in\textnormal{{Bad}}_{i}
and
(a,b)
is marked “probably good for
i
”, then using Lemma
4.10
, we get

\displaystyle|\mathbf{S}_{i}^{(a,b)}|\leq\frac{5}{2}\sum_{j\in I^{(a,b)}_{i}}p_{j}

and using the same series of steps as above, we get

\displaystyle\frac{|\mathbf{S}_{i}^{(a,b)}|}{(5/2)(1-(1-(\sqrt{\theta})^{a+1}P_{\text{start}})^{N})}f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})

\displaystyle\leq|I^{(a,b)}_{i}|f^{-1}(\mathbf{e}_{i}(\sqrt{\theta})^{a+b}P_{\text{start}}F_{\text{start}})\leq\sum_{j\in I^{(a,b)}_{i}}x_{i}(j)

which again shows that the contribution of tuples
(a,b)
in
\textnormal{{Bad}}_{i}
but are marked “probably good for
i
” is also not overestimated. Overall we get that with a probability
\geq 1-O(1/n^{2})
,
\hat{x}_{i}\leq x_{i}
. Using a union bound we have the proof.
∎

We now show that
\textnormal{{Est}}_{i^{*}}
is large with a large probability.

Lemma 4.13
.

With probability
\geq 1-1/n^{2}
,

\displaystyle\textnormal{{Est}}_{i^{*}}\geq\frac{(1-\varepsilon_{2})^{2}}{\theta^{\prime\prime}}\mathbf{e}_{i^{*}}^{-1}f(x_{i^{*}}).

Proof.

By Lemma
4.5
,
\mathbf{L}_{i^{*}}=\textnormal{{Large}}_{i^{*}}
and therefore the contribution to
x_{i^{*}}
from the servers in
\textnormal{{Large}}_{i^{*}}
is captured by
\hat{x}_{i^{*}}
. We argued that contribution to
\hat{x}_{i^{*}}
from servers in
\textnormal{{Small}}_{i^{*}}\cup\textnormal{{Ignore}}_{i^{*}}
can be ignored.

Now consider the tuples
(a,b)
for
a=0,1,\ldots,A-1
and
b=0,1,\ldots,B-1
. If
(\sqrt{\theta})^{a+1}P_{\text{start}}\geq(4\log n)/N
, then
\mathbf{S}^{(a,b)}_{i^{*}}=I^{(a,b)}_{i^{*}}
with probability
\geq 1-1/n^{3}
and therefore the contribution from the servers in
I^{(a,b)}_{i^{*}}
is captured exactly by
\hat{x}_{i^{*}}
. If
(a,b)\in\textnormal{{Bad}}_{i^{*}}
, then we argued in Lemma
4.7
that we need not capture the contribution from those servers. So any contribution from servers in
\textnormal{{Bad}}_{i^{*}}
marked as “probably good for
i^{*}
” will only help in increasing

Now consider

Higher-Order Correlations

Kannan, Vempala, and Woodruff
[
29
]
also study the problem of approximating higher order correlations and list a few applications of the problem in their paper. In this problem, there are
s
servers and the
j
-th server holds a set of
n
-dimensional vectors

. Given a parameter
k

\displaystyle M(f,g,W_{1},\ldots,W_{s})\coloneqq\sum_{i_{1},i_{2},\ldots,i_{k}\,\text{distinct}}f\left(\sum_{j}\sum_{v\in W_{j}}g(v_{i_{1}},v_{i_{2}},\ldots,v_{i_{k}})\right)

As they mention, for each server
j
, we can create a vector
w(j)
with

components (one for each tuple
(i_{1},\ldots,i_{k})
with distinct values of

) defined as

\displaystyle[w(j)]_{(i_{1},i_{2},\ldots,i_{k})}\coloneqq\sum_{v\in W_{j}}g(v_{i_{1}},v_{i_{2}},\ldots,v_{i_{k}}).

Now running the function sum approximation protocol on the vectors
w(1),\ldots,w(s)
with the function
f
, we can compute a
1\pm\varepsilon
approximation for

using a total of

\displaystyle O_{\theta,\theta^{\prime},\theta^{\prime\prime}}\left(\frac{c_{f}[s]}{\varepsilon^{2}}\cdot\operatorname{polylog}(r)\right)=O_{\theta,\theta^{\prime},\theta^{\prime\prime}}\left(\frac{c_{f}[s]}{\varepsilon^{2}}\cdot\operatorname{poly}(k,\log n)\right)

dimensional vectors

which end up occupying
O(n^{k})
space which is prohibitive when

4.15

O(n^{k})

We first solve for the issue of sharing
O(n^{k})
exponential random variables across all the servers. In Appendix
C

[
34
]
. The seed for Nisan’s PRG needs to be only of length
O(k^{2}\log^{2}(n/\varepsilon))
and hence the shared randomness across the servers is only of this size.

The main reason we need the vectors

is so that the server
j
can sample independent copies of the random variable
(\mathbf{i}_{1},\ldots,\mathbf{i}_{k})
with probability distribution

\displaystyle\operatorname{Pr\/}[(\mathbf{i}_{1},\ldots,\mathbf{i}_{k})=(i_{1},\ldots,i_{k})]=\frac{(\mathbf{e}_{(i_{1},\ldots,i_{k})})^{-1}[w(j)]_{(i_{1},\ldots,i_{k})}}{\sum_{i_{1}^{\prime},\ldots,i_{k}^{\prime}}(\mathbf{e}_{(i_{1}^{\prime},\ldots,i_{k}^{\prime})})^{-1}[w(j)]_{(i_{1}^{\prime},\ldots,i_{k}^{\prime})}}

where

is an independent standard exponential random variable. But we note that to sample from this distribution, the protocol does not need
O(n^{k})
space. Consider the lexicographic ordering of the tuples
(i_{1},\ldots,i_{k})
with all
i_{1},\ldots,i_{k}
distinct. The algorithm goes over the tuples in the lexicographic orders, computes the value of
(\mathbf{e}_{(i_{1},\ldots,i_{k})})^{-1}[w(j)]_{(i_{1},\ldots,i_{k})}
by generating the random variable
\mathbf{e}_{(i_{1},\ldots,i_{k})}
using Nisan’s PRG and then uses a
reservoir sampling
algorithm to sample a tuple form the above defined distribution. This entire process can be accomplished using a constant amount of space and hence implementing the function sum approximation protocol on the vectors
w(1),\ldots,w(s)
can be accomplished without using
\Theta(n^{k})
space at each of the servers. Hence we have the following theorem:

Theorem 5.1

\displaystyle W\coloneqq\sum_{i}f(x_{i})=\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}+Q\right)\cdot f(y^{*})+\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)+\left(\frac{1}{4\varepsilon^{2}}+V\right)\cdot f(sy^{*})

where
Q,U,V
denote the deviations from the means for each type of coordinate. Note that we have
f(0)=0
and hence no contribution from such random variables. Now, the
s
-BTX problem is exactly to determine if
|U|\geq 2/\varepsilon
or
|U|\leq 1/\varepsilon
and we want to show that a protocol to approximate
\sum_{i}f(x_{i})
can be used to distinguish between the cases.

We now define
x^{\text{left}}=\sum_{j=1}^{s/2}x(j)
and
x^{\text{right}}=\sum_{j=s/2+1}^{s}x(j)
. Let
W^{\text{left}}\coloneqq\sum_{i}f(x^{\text{left}}_{i})
and
W^{\text{right}}\coloneqq\sum_{i}f(x^{\text{right}}_{i})
. We now note that

\displaystyle W^{\text{left}}+W^{\text{right}}=\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}+Q\right)\cdot f(y^{*})+\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)+\left(\frac{1}{4\varepsilon^{2}}+V\right)\cdot 2\cdot f(sy^{*}/2).

Note that for the function
f
, we have
f(sy^{*})=\beta\cdot 2\cdot f(sy^{*}/2)
for some
\beta>1
. Hence,

\displaystyle\beta(W^{\text{left}}+W^{\text{right}})-W=(\beta-1)\left(\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}+Q\right)\cdot f(y^{*})+\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)\right).

Let
\mathcal{P}
be a protocol that can approximate
\sum_{i}f(x_{i})
, up to a
1\pm\alpha\varepsilon
factor, when the vector
x
is distributed across
s
servers. Let
\widetilde{W}
,
\widetilde{W}^{\text{left}}
and
\widetilde{W}^{\text{right}}
be the
1\pm\alpha\varepsilon
approximations for
W
,
W^{\text{left}}
and
W^{\text{right}}
computed by running the protocol
\mathcal{P}
on three different instances of the function sum approximation problem. We first note that for the vector
x
constructed using the inputs
(b(1),\ldots,b(s))
, we have
\sum_{i}f(x_{i})\leq\frac{s\cdot c_{f}[s]}{\varepsilon^{2}}f(y^{*})+\frac{1}{\varepsilon^{2}}f(sy^{*})\leq\frac{2\cdot f(sy^{*})}{\varepsilon^{2}}
with probability
1
where we used the fact that
s\cdot c_{f}[s]\cdot f(y^{*})=f(sy^{*})
. Hence,

\displaystyle\widetilde{W}=W\pm\frac{\alpha\cdot 2\cdot f(sy^{*})}{\varepsilon},\quad\widetilde{W}^{\text{left}}=W^{\text{left}}\pm\frac{\alpha\cdot 2\cdot f(sy^{*})}{\varepsilon},\quad\text{and}\quad\widetilde{W}^{\text{right}}=W^{\text{right}}\pm\frac{\alpha\cdot 2\cdot f(sy^{*})}{\varepsilon}

which then implies

\displaystyle\beta(\widetilde{W}^{\text{left}}+\widetilde{W}^{\text{right}})-\widetilde{W}

\displaystyle=\beta(W^{\text{left}}+W^{\text{right}})-W\pm\frac{6\alpha\beta}{\varepsilon}f(sy^{*})

\displaystyle=(\beta-1)\left(\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}+Q\right)\cdot f(y^{*})+\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)\right)\pm\frac{6\alpha\beta}{\varepsilon}f(sy^{*}).

Now, we note that with a large constant probability over the distribution
\nu
, the random variable
Q
satisfies

\displaystyle|Q|\leq\frac{C\sqrt{s\cdot c_{f}[s]}}{\varepsilon}

for a large enough constant
C
by a simple application of a Chernoff bound. Hence, with a union bound on the above event and the correctness of the protocol on inputs
x
,
x^{\text{left}}
and
x^{\text{right}}
, we get

\displaystyle\beta(\widetilde{W}^{\text{left}}+\widetilde{W}^{\text{right}})-\widetilde{W}

\displaystyle=(\beta-1)\cdot\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)+(\beta-1)\cdot\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}\right)\cdot f(y^{*})

\displaystyle\quad\pm(\beta-1)\frac{C\sqrt{s\cdot c_{f}[s]}}{\varepsilon}f(y^{*})\pm\frac{6\alpha\beta}{\varepsilon}f(sy^{*}).

Dividing the expression by
(\beta-1)
, we get

\displaystyle\frac{\beta(\widetilde{W}^{\text{left}}+\widetilde{W}^{\text{right}})-\widetilde{W}}{\beta-1}

\displaystyle=\left(\frac{1}{2\varepsilon^{2}}+U\right)\cdot f(sy^{*}/2)+\left(\frac{s\cdot c_{f}[s]-1}{2\varepsilon^{2}}\right)f(y^{*})

\displaystyle\quad\pm\frac{C\sqrt{s\cdot c_{f}[s]}}{\varepsilon}f(y^{*})\pm\frac{6\alpha\beta}{\varepsilon(\beta-1)}f(sy^{*})

We now use
f(sy^{*})=s\cdot c_{f}[s]\cdot f(y^{*})
,
f(sy^{*}/2)=s\cdot c_{f}[s]\cdot f(y^{*})/2\beta
to obtain that

\displaystyle\frac{\beta(\widetilde{W}^{\text{left}}+\widetilde{W}^{\text{right}})-\widetilde{W}}{\beta-1}=\frac{s\cdot c_{f}[s]\cdot f(y^{*})}{2\beta}\cdot\left(\frac{1}{2\varepsilon^{2}}+U+\frac{(s\cdot c_{f}[s]-1)\cdot 2\beta}{2\varepsilon^{2}\cdot s\cdot c_{f}[s]}\pm\frac{2C\cdot\beta}{\varepsilon\sqrt{s\cdot c_{f}[s]}}\pm\frac{12\alpha\beta^{2}}{\varepsilon(\beta-1)}\right).

If
s\geq C^{\prime}\cdot\beta
, then
\sqrt{s\cdot c_{f}[s]}\geq s\geq C^{\prime}\cdot\beta
as well. If
C^{\prime}\geq 8C
, and
\alpha\leq(\beta-1)/72\beta^{2}
, then

\displaystyle\frac{\beta(\widetilde{W}^{\text{left}}+\widetilde{W}^{\text{right}})-\widetilde{W}}{\beta-1}=\frac{s\cdot c_{f}[s]\cdot f(y^{*})}{2\beta}\cdot\left(\frac{1}{2\varepsilon^{2}}+U+\frac{(s\cdot c_{f}[s]-1)\cdot 2\beta}{2\varepsilon^{2}\cdot s\cdot c_{f}[s]}\pm\frac{5}{12\varepsilon}\right).

Hence, we can distinguish between the case when
|U|\leq 1/\varepsilon
or
|U|\geq 2/\varepsilon
using the expression on the LHS of the above equality. As,
n=s\cdot c_{f}[s]
, the lower bound for the
s
-BTX problem implies that any randomized protocol that approximates
\sum_{i}f(x_{i})
in the coordinator model when the vector
x
is split between
s
servers, up to a
1\pm\left(\frac{1}{72\beta}-\frac{1}{72\beta^{2}}\right)\varepsilon
factor, with probability
\geq 1-\delta
for a small enough constant
\delta
, must use a total communication of
\Omega(c_{f}[s]/\varepsilon^{2})
bits.
∎

5.2
F_{k}
Estimation Lower Bound for 1-round Algorithms

We use the multi-player set disjointness problem to show that a one round protocol for
F_{k}
estimation using shared randomness requires a total of
\tilde{\Omega}(s^{k-1}/\varepsilon^{k})
bits of communication. In the one-way
blackboard
private-coin communication model, it is known that the
t
-player
promise
set disjointness problem, with sets drawn from
[n]
, has a communication lower bound of
\Omega(n/t)
. In this problem, each of the
t
servers receives a subset of
[n]
with the promise that the sets received by all the servers are either mutually disjoint or that there is exactly one element that is present in all the subsets.

The one round algorithms in our paper can be
implemented
in the standard
1
-way bloackboard model: In this model, all the servers in a deterministic order
write
the information on a publicly viewable blackboard. The total communication in this model is then the total number of bits written on the blackboard. The one round algorithms in the coordinator model are strictly weaker as each server sends its information to the coordinator without even looking at others bits. The lower bound of
\Omega(n/t)
in the 1-way blackboard model was shown in
[
12
]
and later
[
24
]
extended the
\Omega(n/t)
lower bound to an arbitrary number of rounds.

Theorem 5.3
.

Given
s\geq 3
servers each having an
n
dimensional vector
x(1),\ldots,x(s)
respectively, any 1-round
F_{k}
estimation algorithm, in which the servers send a single message to the coordinator, that approximates
F_{k}(x)
up to
1\pm\varepsilon
factor with probability
\geq 9/10
over the randomness in the protocol, must use
\Omega_{k}(s^{k-1}/\varepsilon^{k}\log(s/\varepsilon))
bits of total communication.

Proof.

The lower bounds in
[
12
,
24
]
hold even with shared randomness, but are not stated that way, so one can also argue as follows to handle shared randomness: suppose there is a public coin algorithm in the
1
-way blackboard communication model using a total of
c
bits of communication. Then by Newman’s equivalence
[
33
]
of private-coin vs public-coin protocols up to an additive logarithmic increase in the communication, there is a private coin algorithm in the one-way blackboard communication model using a total of
c+O(\log(nt))
bits. The first player samples one of the strings pre-shared among all the servers and announces the index of the string on the blackboard and then the remaining servers proceed with the computation using this string as the shared random bits. Hence,
c=\Omega(n/t)-O(\log nt)
and when
t\leq n^{\alpha}
for a constant
\alpha<1
, we obtain that
\Omega(n/t)
bits is a lower bound on the communication complexity of 1-way public coin protocols in the blackboard model that solve the
s
-player set disjointness problem.

In our model, the
F_{k}
estimation algorithm is even weaker than the
1
-way public coin protocol in the blackboard model as all the servers send their bits to the coordinator without looking at others bits. Hence, the lower bound of
\Omega(n/t)
bits can be used to lower bound the communication complexity.

Let
n=s^{k}/\varepsilon^{k}
and
t=s/2
. Consider the instance of a
t
player set-disjointness problem. We will encode the problem as approximating the
F_{k}
moment of an
n
dimensional vector distributed over
s
servers.

For
j=1,\ldots,s/2
, the player
j
encodes the subset
S_{j}\subseteq[n]
they receive as an
n
dimensional vector
x(j)
by putting
1
in the coordinates corresponding to the items in the set and
0
otherwise.

Now each of the
s/2
servers runs a
(1/Cn)
-error protocol in the coordinator model (as in the protocol fails with probability at most
1/Cn
) to approximate
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}
and sends the transcript to the central coordinator. The central coordinator chooses appropriate vectors
x(s/2+1),\ldots,x(s)
and using the transcripts from the
s/2
servers finds a
1+\varepsilon
approximation to
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}
by running the
(1/Cn)
-error protocol for estimating
F_{k}
moments.

Let
\|\sum_{j=1}^{s/2}x(j)\|_{k}^{k}=T
. Fix an index
i\in[n]
. The central coordinator creates the vectors
x{(s/2+1)},\ldots,x{(s/2+s/2)}
to be all be equal and have a value of
2/\varepsilon
in coordinate
i
and remaining positions have value
0
. Now consider a NO instance for the set disjointness problem. Then
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}\leq(T-1)+(s/\varepsilon+1)^{k}
.

Let
T^{\prime}
be such that
(1-\varepsilon^{\prime})T\leq T^{\prime}\leq(1+\varepsilon^{\prime})T
. Then,

\displaystyle(1+\varepsilon^{\prime})\|\sum_{j=1}^{s}x(j)\|_{k}^{k}\leq\frac{1+\varepsilon^{\prime}}{1-\varepsilon^{\prime}}T^{\prime}-(1+\varepsilon^{\prime})+(1+\varepsilon^{\prime})(s/\varepsilon+1)^{k}.

Now consider a YES instance. If all the sets intersect in
i
, then
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}=T-(s/2)^{k}+(s/\varepsilon+s/2)^{k}
. Now,

\displaystyle(1-\varepsilon^{\prime})\|\sum_{i=1}^{s}x(j)\|_{k}^{k}\geq\frac{1-\varepsilon^{\prime}}{1+\varepsilon^{\prime}}T^{\prime}-(1-\varepsilon^{\prime})(s/2)^{k}+(1-\varepsilon^{\prime})(s/\varepsilon+s/2)^{k}.

If

\displaystyle\frac{1-\varepsilon^{\prime}}{1+\varepsilon^{\prime}}T^{\prime}-(1-\varepsilon^{\prime})(s/2)^{k}+(1-\varepsilon^{\prime})(s/\varepsilon+s/2)^{k}>\frac{1+\varepsilon^{\prime}}{1-\varepsilon^{\prime}}T^{\prime}-(1+\varepsilon^{\prime})+(1+\varepsilon^{\prime})(s/\varepsilon+1)^{k},

we have a test for set disjointness. The above is implied by

\displaystyle(1-\varepsilon^{\prime})(s/\varepsilon+s/2)^{k}-(1+\varepsilon^{\prime})(s/\varepsilon+1)^{k}-(1-\varepsilon^{\prime})(s/2)^{k}\geq\frac{4\varepsilon^{\prime}}{1-(\varepsilon^{\prime})^{2}}T^{\prime}

which is further implied by

(1-\varepsilon^{\prime})(s/\varepsilon+s/2)^{k}-(1+\varepsilon^{\prime})(s/\varepsilon+1)^{k}-(1-\varepsilon^{\prime})(s/2)^{k}\geq{8\varepsilon^{\prime}}T.

As
T\leq(s/\varepsilon)^{k}+(s/2)^{k}
, we obtain that the above is implied by

\displaystyle(1-\varepsilon^{\prime})(1/\varepsilon+1/2)^{k}-(1+\varepsilon^{\prime})(1/\varepsilon+1/s)^{k}-(1-\varepsilon^{\prime})(1/2^{k})\geq 8\varepsilon^{\prime}(1/\varepsilon^{k}+1/2^{k}).

For
s\geq 3
,

\displaystyle\left(\frac{1/\varepsilon+1/2}{1/\varepsilon+1/s}\right)^{k}\geq\left(\frac{1/\varepsilon+1/2}{1/\varepsilon+1/3}\right)^{k}\geq(1+\varepsilon/8).

Hence, setting
\varepsilon^{\prime}=\varepsilon/C
for a large enough constant implies that

\displaystyle(1-\varepsilon^{\prime})(1/\varepsilon+1/2)^{k}-(1+\varepsilon^{\prime})(1/\varepsilon+1/s)^{k}\geq\frac{\varepsilon}{16}(1/\varepsilon+1/2)^{k}

For
k\geq 2
, we further get

\displaystyle(1-\varepsilon^{\prime})(1/\varepsilon+1/2)^{k}-(1+\varepsilon^{\prime})(1/\varepsilon+1/s)^{k}-(1-\varepsilon^{\prime})(1/2^{k})\geq\frac{\varepsilon}{32}(1/\varepsilon+1/2)^{k}.

By picking
C
large enough, we obtain
(\varepsilon/32)(1/\varepsilon+1/2)^{k}\geq 8\varepsilon^{\prime}(1/\varepsilon^{k}+1/2^{k})
. Thus, if a
1\pm\varepsilon^{\prime}
approximation of
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}
for any
i\in[n]
(note that the vectors
x(s/2+1),\ldots,x(s)
depend on which
i
we are using) exceeds
(1+\varepsilon^{\prime})T^{\prime}/(1-\varepsilon^{\prime})-(1+\varepsilon^{\prime})+(1+\varepsilon^{\prime})(s/\varepsilon+1)^{k}
, then we can output YES to the set disjointness instance and otherwise output NO. Note that we needed to union bound over the
n+1
instances of the problem, i.e., that we compute
T^{\prime}
such that
(1-\varepsilon^{\prime})T\leq T^{\prime}\leq(1+\varepsilon^{\prime})T
and later for each
i\in[n]
, we want a
1\pm\varepsilon^{\prime}
approximation to the appropriately defined
\|\sum_{j=1}^{s}x(j)\|_{k}^{k}
and hence we use a
1/Cn
error protocol.

Thus, any distributed protocol which outputs a
1+\varepsilon/C
approximation to the
F_{k}
approximation problem with probability
\geq 1-\varepsilon^{k}/Cs^{k}
must use a total communication of
\Omega_{k}(s^{k-1}/\varepsilon^{k})
bits. Consequently, an algorithm which succeeds with a probability
\geq 9/10
must use
\Omega_{k}(s^{k-1}/\log(s/\varepsilon)\varepsilon^{k})
bits of total communication since the success probability of such an algorithm can be boosted to a failure probability
O(\varepsilon^{k}/s^{k})
by simultaneous independent copies of the protocol.
∎

6
Neighborhood Propagation via Composable Sketches

We define composable sketches and show how using a neighborhood propagation algorithm, composable sketches can be used so that all nodes in a graph with arbitrary topology can simultaneously compute statistics of the data in a distance
\Delta
neighborhood of the node. Typically the distance parameter
\Delta
is taken to be a small constant but can be as large as the diameter of the underlying graph.

We use
\mathcal{A}
to denote a dataset. Each item in the dataset is of the form
({\rm{key}},{\rm{val}})
where the keys are drawn from an arbitrary set
T
and the values are
d
-dimensional vectors. We use the notation
\mathcal{A}.{\rm{vals}}
to denote the matrix with rows given by the values in the dataset. We say two datasets
\mathcal{A}
and
\mathcal{B}
are
conforming
if for all
{\rm{key}}
s present in both the datasets, the corresponding
{\rm{val}}
s in both the datasets are the same. We use the notation
\mathcal{A}\cup\mathcal{B}
to denote the union of both the datasets. In the following, we assume that all the relevant datasets are conforming. A composable sketch
{\rm{sk}}(\mathcal{A})
is a summary of the data items
\mathcal{A}
.
The sketch
{\rm{sk}}(\cdot)
must support the following three operations:

1.

Create
(\mathcal{A})
: given data items
\mathcal{A}
, generate a sketch
{\rm{sk}}(\mathcal{A})
.

2.

Merge
({\rm{sk}}(\mathcal{A}_{1}),{\rm{sk}}(\mathcal{A}_{2}),\cdots,{\rm{sk}}(\mathcal{A}_{k}))
:
given the sketches
{\rm{sk}}(\mathcal{A}_{1}),\cdots,{\rm{sk}}(\mathcal{A}_{k})
for sets of data items
\mathcal{A}_{1},\cdots,\mathcal{A}_{k}
which may have overlaps,
generate a composable sketch
{\rm{sk}}(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{k})
for the union of data items
\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{k}
.

3.

Solve
({\rm{sk}}(\mathcal{A}))
: given a sketch
{\rm{sk}}(\mathcal{A})
of data items
\mathcal{A}
, compute a solution with for a pre-specified problem with respect to
\mathcal{A}
.

Note that
{\rm{sk}}(\mathcal{A})
need not be unique and randomization is allowed during the construction of the sketch and merging. We assume that
Create
,
Merge
and
Solve
procedures have access to a shared uniform random bit string.

A core property of the above composable sketch definition is that it handles duplicates. Consider the following problem over a graph
G=(V,E)
. Each vertex of the graph represents a user/server. For a node
u
, we represent their dataset with
\mathcal{S}_{u}
, a set of
({\rm{key}},{\rm{val}})
pairs. Given a parameter
\Delta
,
each
node in the graph wants to compute statistics or solve an optimization problem over the data of all the nodes within a distance
\Delta
from the node. For example, with
\Delta=1
, each node
u
may want to solve a regression problem defined by the data at node
u
and all the neighbors
u
.

As composable sketches handle duplicates, the following simple algorithm can be employed to solve the problems over the
\Delta
neighborhood of each node
u
.

1.

Each node
u
computes
{\rm{sk}}(\mathcal{S}_{u})
and communicates to all its neighbors.

2.

Repeat
\Delta
rounds: in round
i
, each node
u
computes

\displaystyle{\rm{sk}}(\mathcal{S}^{i}_{u})

\displaystyle={\rm{sk}}(\bigcup_{v:\set{v,u}\in E}\mathcal{S}^{i-1}_{v})=\textsc{Merge}({\rm{sk}}(\mathcal{S}_{v_{1}}^{i-1}),\cdots,{\rm{sk}}(\mathcal{S}_{v_{k}}^{i-1}))

and sends the sketch to all its neighbors.
Here we use
{\rm{sk}}(\mathcal{S}_{u}^{0})
to denote
{\rm{sk}}(\mathcal{S}_{u})
.

3.

Each node
u
in the graph outputs a solution over its
\Delta
neighborhood via first computing
\textsc{Merge}({\rm{sk}}(\mathcal{S}_{u}^{0}),{\rm{sk}}(\mathcal{S}_{u}^{1}),{\rm{sk}}(\mathcal{S}_{u}^{2}),\ldots,{\rm{sk}}(\mathcal{S}_{u}^{\Delta}))
and then using the
\textsc{Solve}(\cdot)
procedure.

Notice that the capability of handling duplicates is crucial for the above neighborhood propagation algorithm to work. For example, a node
v
at a distance
2
from
u
maybe connected to
u
through two disjoint paths and hence
u
receives the sketch of
u
’s data from two different sources. So it is necessary for the sketch to be duplicate agnostic to not overweight data of vertices that are connected through many neighbors. Another nice property afforded by composable sketches is that a node sends the same “information” to all its neighbors meaning that a node does not perform different computations determining what information is to be sent to each of its neighbors.

In the following section, we give a composable sketch for computing an
\ell_{p}
subspace embedding and show that it can be used to solve
\ell_{p}
regression problems as well as the low rank approximation problem.

7
Composable Sketches for Sensitivity Sampling

We assume
\mathcal{A}_{1},\ldots,\mathcal{A}_{s}
are conforming datasets. Let
\mathcal{A}\coloneqq\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}
. We give a composable sketch construction such that using
{\rm{sk}}(\mathcal{A})
, we can compute an
\ell_{p}
subspace embedding for the matrix
\mathcal{A}.{\rm{vals}}
. Another important objective is to make the size of the sketch
{\rm{sk}}(\mathcal{A})
as small as possible so that sketches can be efficiently communicated to neighbors in the neighborhood propagation algorithm.

Given a matrix
A\in\mathbb{R}^{n\times d}
, we say that a matrix
M\in\mathbb{R}^{m\times d}
is an
\varepsilon

\ell_{p}
-subspace embedding for
A
if for all
x\in\mathbb{R}^{d}
,

\displaystyle\|Mx\|_{p}^{p}=(1\pm\varepsilon)\|Ax\|_{p}^{p}.

\ell_{p}
subspace embeddings have numerous applications and are heavily studied in the numerical linear algebra literature. We will now define the so-called
\ell_{p}
sensitivities and how they can be used to compute subspace embeddings.

7.1
\ell_{p}
Sensitivity Sampling

The
\ell_{p}
sensitivities are a straightforward generalization of the leverage scores. Given a matrix
A
and a row
a
of the matrix, the
\ell_{p}
sensitivity of
a
w.r.t. the matrix
A
is defined as

\displaystyle\tau^{\ell_{p}}_{A}(a)\coloneqq\max_{x:Ax\neq 0}\frac{|\langle a,x\rangle|^{p}}{\|Ax\|_{p}^{p}}.

The
\ell_{p}
sensitivities measure the importance of a row to be able to estimate
\|Ax\|_{p}^{p}
given any vector
x
. Suppose that a particular row
a
is orthogonal to all the other rows of the matrix
A
, we can see that
a
is very important to be able to approximate
\|Ax\|_{p}^{p}
up to a multiplicative factor. It can be shown that if the matrix
A
has
d
columns, then the sum of
\ell_{p}
sensitivities
\sum_{a\in A}\tau_{A}^{\ell_{p}}(a)\leq d^{\max(p/2,1)}

[
32
]
. Now we state the following sampling result which shows that sampling rows of the matrix
A
with probabilities depending on the sensitivities and appropriately rescaling the sampled rows gives an
\ell_{p}
subspace embedding.

Theorem 7.1
.

Given a matrix
A
and a vector
v\in[0,1]^{n}
such that for all
i\in[n]
,
v_{i}\geq\beta\tau_{A}^{\ell_{p}}(a_{i})
for some
\beta\leq 1
, let a random diagonal matrix
\mathbf{S}
be generated as follows: for each
i\in[n]
independently, set
\mathbf{S}_{ii}=(1/p_{i})^{1/p}
with probability
p_{i}
and
0
otherwise. If
p_{i}\geq\min(1,C_{1}\beta^{-1}v_{i}(C_{2}d\log(d/\varepsilon)+\log(1/\delta))/\varepsilon^{2})
for large enough constants
C_{1}
and
C_{2}
, then with probability
\geq 1-\delta
, for all
x\in\mathbb{R}^{d}
,

\displaystyle\|\mathbf{S}Ax\|_{p}=(1\pm\varepsilon)\|Ax\|_{p}.

Given constant factor approximations for the
\ell_{p}
sensitivities we can define the probabilities
p_{i}
such that the matrix
\mathbf{S}
has at most
O(d^{\max(p/2,1)}(d\log(d/\varepsilon)+\log 1/\delta)/\varepsilon^{2})
non-zero entries with a large probability. The proof of the above theorem proceeds by showing that for a fixed vector
x
, the event
\|\mathbf{S}Ax\|_{p}=(1\pm\varepsilon)\|Ax\|_{p}
holds with a high probability and then using an
\varepsilon
-net argument to extend the high probability guarantee for a single vector
x
to a guarantee for all the vectors
x
. For
p=2
, we can show that in the above theorem
p_{i}\geq\min(1,C_{1}\beta^{-1}v_{i}(C_{2}\log(d/\varepsilon)+\log 1/\delta)\varepsilon^{-2})
suffices to construct a subspace embedding. So, in all our results for the special case of
2
, only
\tilde{O}(d)
rows need to be sampled.

We will now show a construction of a composable sketch
{\rm{sk}}(\mathcal{A})
given a dataset
\mathcal{A}
. The composable sketch
{\rm{sk}}(\mathcal{A})
can be used to construct an
\ell_{p}
subspace embedding for the matrix
\mathcal{A}.{\rm{vals}}
. Importantly, we note that given composable sketches
{\rm{sk}}(\mathcal{A})
and
{\rm{sk}}(\mathcal{B})
, the sketches can be merged only when
\mathcal{A}
and
\mathcal{B}
are conforming and the sketches
{\rm{sk}}(\mathcal{A})
and
{\rm{sk}}(\mathcal{B})
are constructed using the same randomness in a way which will become clear after we give the sketch construction.

We parameterize our sketch construction with an integer parameter
t
that defines the number of times a sketch can be merged with other sketches. We denote the sketch by
{\rm{sk}}_{t}(\mathcal{A})
if it is “mergeable”
t
times. Merging
{\rm{sk}}_{t}(\mathcal{A})
and
{\rm{sk}}_{t^{\prime}}(\mathcal{A})
gives
{\rm{sk}}_{\min(t,t^{\prime})-1}(\mathcal{A}\cup\mathcal{B})
. Naturally, the size of the sketch increases with the parameter
t
. We will first show how the sketch
{\rm{sk}}_{t}(\mathcal{A})
is created.

7.2
Sketch Creation

Given a dataset
\mathcal{A}
and a parameter
t
, we pick
t
independent
fully random
hash functions
h_{1},\ldots,h_{t}
mapping keys to uniform random variables in the interval
[0,1]
. Thus for each
{\rm{key}}
, the value
h_{i}({\rm{key}})
is an independent uniform random variable in the interval
[0,1]
. Given such hash functions
h_{1},h_{2},\ldots,h_{t}
, first for each
({\rm{key}},{\rm{val}})\in\mathcal{A}
, we compute
\tilde{\tau}_{{\rm{key}}}
that satisfies

\displaystyle(1+\varepsilon)^{t}\tau^{\ell_{p}}_{\mathcal{A}.{\rm{vals}}}({\rm{val}})\leq\tilde{\tau}_{{\rm{key}}}\leq(1+\varepsilon)^{t+1}\tau_{\mathcal{A}.{\rm{vals}}}^{\ell_{p}}({\rm{val}}).

Note that we are free to choose
\tilde{\tau}_{{\rm{key}}}
to be any value in the above interval. To allow randomness in computing the values of
\tilde{\tau}_{{\rm{key}}}
, we introduce another parameter
\gamma
. We assume that with probability
1-\gamma
, for all
{\rm{key}}\in\mathcal{A}.\text{keys}
,
\tilde{\tau}_{{\rm{key}}}
satisfies the above relation. When creating the sketch from scratch, as we can compute exact
\ell_{p}
sensitivities, we can take
\gamma
to be
0
. The only requirement is that the value of
\tilde{\tau}_{{\rm{key}}}
must be computed independently of the hash functions
h_{1},\ldots,h_{t}
.

For each
{\rm{key}}\in\mathcal{A}.\text{keys}
, let
p_{{\rm{key}}}=C\tilde{\tau}_{{\rm{key}}}(d\log d/\varepsilon+\log 1/\delta)\varepsilon^{-2}
and now for each
h_{i}
, define

\displaystyle\textsf{senSample}(\mathcal{A},h_{i},t)\coloneqq\{({\rm{key}},{\rm{val}},\min(p_{{\rm{key}}},1))\mid({\rm{key}},{\rm{val}})\in\mathcal{A},h_{i}({\rm{key}})\leq p_{{\rm{key}}}\}.

The sketch
{\rm{sk}}_{t,0}(\mathcal{A})
is now defined to be the collection
(\textsf{senSample}(\mathcal{A},h_{1},t),\ldots,\textsf{senSample}(\mathcal{A},h_{t},t))
. The procedure is described in Algorithm
2
. Note that for each
({\rm{key}},{\rm{val}})\in\mathcal{A}
,

\displaystyle\operatorname{Pr\/}_{h_{i}}[({\rm{key}},{\rm{val}},*)\in\textsf{senSample}(\mathcal{A},h_{i},t)]

\displaystyle=\min(p_{{\rm{key}}},1)

\displaystyle\geq\min(C\tau_{\mathcal{A}.{\rm{vals}}}^{\ell_{p}}({\rm{val}})(d\log(d/\varepsilon)+\log 1/\delta)\varepsilon^{-2},1).

Hence, the construction of the set
\textsf{senSample}(\mathcal{A},h_{i},t)
is essentially performing
\ell_{p}
sensitivity sampling as in Theorem
7.1
and for sampled rows it also stores the probability with which they were sampled. Thus, a matrix constructed appropriately using
\textsf{senSample}(\mathcal{A},h_{i},t)
will be a subspace embedding for the matrix
\mathcal{A}.{\rm{vals}}
with probability
\geq 1-\delta
.

Throughout the construction, we ensure that the sketch
{\rm{sk}}_{t,\gamma}(\mathcal{A})=(\textsf{senSample}(\mathcal{A},h_{1},t)
, …,
\textsf{senSample}(\mathcal{A},h_{t},t))
satisfies the following definition.

Definition 7.2
.

A sketch
(\textsf{senSample}(\mathcal{A},h_{1},t),\ldots,\textsf{senSample}(\mathcal{A},h_{t},t))
is denoted
{\rm{sk}}_{t,\gamma}(\mathcal{A})
if with probability
\geq 1-\gamma
(over randomness independent of
h_{1},\ldots,h_{t}
), for each
({\rm{key}},{\rm{val}})\in\mathcal{A}
, there exist values
\tilde{\tau}_{{\rm{key}}}
(computed independently of the hash functions
h_{1},\ldots,h_{t}
) such that

\displaystyle(1+\varepsilon)^{t}\tau^{\ell_{p}}_{\mathcal{A}.{\rm{vals}}}({\rm{val}})\leq\tilde{\tau}_{{\rm{key}}}\leq(1+\varepsilon)^{t+1}\tau^{\ell_{p}}_{\mathcal{A}.{\rm{vals}}}({\rm{val}})

(12)

and for
p_{{\rm{key}}}=C\tilde{\tau}_{{\rm{key}}}(d\log d/\varepsilon+\log 1/\delta)\varepsilon^{-2}
,

\displaystyle\textsf{senSample}(\mathcal{A},h_{i},t)=\{({\rm{key}},{\rm{val}},\min(p_{{\rm{key}}},1))\mid({\rm{key}},{\rm{val}})\in\mathcal{A},h_{i}({\rm{key}})\leq p_{{\rm{key}}}\}.

(13)

Note that using the bounds on the sum of
\ell_{p}
sensitivities, we obtain that with probability
\geq 1-\gamma-\exp(-d)
, the size of the sketch
{\rm{sk}}_{t,\gamma}(\mathcal{A})
is
O(t(1+\varepsilon)^{t+1}d^{\max(p/2,1)}(d\log d/\varepsilon+\log 1/\delta)\varepsilon^{-2})
. By Theorem
7.1
, we obtain that given a sketch
{\rm{sk}}_{t,\gamma}(\mathcal{A})
, Algorithm
3
computes a subspace embedding for the matrix
\mathcal{A}.{\rm{vals}}
. Thus, we have the following theorem.

Theorem 7.3
.

Given
{\rm{sk}}_{t,\gamma}(\mathcal{A})
constructed with parameters
\varepsilon,\delta
, Algorithm
3
returns a matrix that with probability
\geq 1-\gamma-\delta
satisfies, for all
x
,

\displaystyle\|Mx\|_{p}^{p}=(1\pm\varepsilon)\|\mathcal{A}.{\rm{vals}}\cdot x\|_{p}^{p}.

We now show how to compute a sketch for
\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}
given sketches
{\rm{sk}}_{t_{1},\gamma_{1}}(\mathcal{A}_{1}),\ldots,{\rm{sk}}_{t_{s},\gamma_{s}}(\mathcal{A}_{s})
for
s
conforming datasets
\mathcal{A}_{1},\ldots,\mathcal{A}_{s}
.

7.3
Merging Sketches

Theorem 7.4
.

Let
\mathcal{A}_{1},\ldots,\mathcal{A}_{s}
be conforming datasets. Given sketches
{\rm{sk}}_{t_{1},\gamma_{1}}(\mathcal{A}_{1}),\ldots,{\rm{sk}}_{t_{s},\gamma_{s}}(\mathcal{A}_{s})
constructed using the same hash functions

and parameters

7.3.1
Proof Outline

In the original sketch creation procedure, we compute approximations to the
\ell_{p}
sensitivities which we use to compute a value
p_{{\rm{key}}}
and keep all the
({\rm{key}},{\rm{val}})
pairs satisfying
h({\rm{key}})\leq p_{{\rm{key}}}
. We argued that the original sketch creation is essentially an implementation of the
\ell_{p}
sensitivity sampling algorithm in Theorem
7.1
. Now, given sketches of
\mathcal{A}_{1},\ldots,\mathcal{A}_{s}
, we want to
simulate
the
\ell_{p}
sensitivity sampling of the rows in the matrix
(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}).{\rm{vals}}
to create the sketch
{\rm{sk}}(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{k})
. An important property of the
\ell_{p}
sensitivities is the
monotonicity
– the
\ell_{p}
sensitivity of a row only goes down with adding new rows to the matrix. Suppose we have a way to compute
\ell_{p}
sensitivities of the rows of the matrix
(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}).{\rm{vals}}
. Suppose a row
a\in\mathcal{A}_{1}.{\rm{vals}}
. Then the probability that it has to be sampled when performing
\ell_{p}
sensitivity sampling on the matrix
(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}).{\rm{vals}}
is smaller than the probability that the row has to be sampled when performing
\ell_{p}
sensitivity sampling on the matrix
\mathcal{A}_{1}.{\rm{vals}}
. Thus, the rows that we ignored when constructing
{\rm{sk}}(\mathcal{A}_{1})
“don’t really matter” as the
\ell_{p}
sensitivity sampling of the rows of
(\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}).{\rm{vals}}
when performing using the same hash function
h
would also not have sampled that row since
h({\rm{key}})
was already larger than the probability that
\mathcal{A}_{1}
assigned to the row
a
which is in turn larger than the probability that
\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{t}
assigned to the row
a
.

The above argument assumes that we have a way to approximate the
\ell_{p}
sensitivity of a row with respect to the matrix
\mathcal{A}_{1}\cup\cdots\cup\mathcal{A}_{s}
and sensitivity sampling requires that these approximations be independent of the hash function
h
we are using to simulate sensitivity sampling. We now recall that each
{\rm{sk}}_{t,\gamma}(\mathcal{A})
has
t
independent copies of the
senSample
data structure. We show that one of the copies can be used to compute approximate sensitivities and then perform the
\ell_{p}
sensitivity sampling on the other copies. Thus, each time we merge a
{\rm{sk}}_{t,\gamma}(\cdot)
data structure, we lose a copy of the
senSample
data structure in the sketch which is why the sketch
{\rm{sk}}_{t,\gamma}(\cdot)
can be merged only
t
times in the future.

Let

-1\end{bmatrix}\|_{p}^{p}.

Thus, if the matrix
M

\varepsilon

\displaystyle\tilde{x}=\argmin_{x}\|M\begin{bmatrix}x\\

\ell_{p}

7.6
Low Rank Approximation

We consider the Frobenius norm low rank approximation. Given a matrix
A
, a rank parameter
k
we want to compute a rank
k
matrix
B
such that
\|A-B\|_{\mathsf{F}}^{2}
is minimized. The optimal solution to this problem can be obtained by truncating the singular value decomposition of the matrix
A
to its top
k
singular values. As computing the exact singular value decomposition of a matrix
A
is slow, the approximate version of low rank approximation has been heavily studied in the literature
[
18
]
. In the approximate version, given a parameter
\varepsilon
, we want to compute a rank-
k
matrix
B
such that

\displaystyle\|A-B\|_{\mathsf{F}}^{2}\leq(1+\varepsilon)\min_{\text{rank-}k\,B}\|A-B\|_{\mathsf{F}}^{2}.

As the number of rows in
A
is usually quite large, the version of the problem which asks to only output a
k
dimensional subspace
V
of
\mathbb{R}^{d}
is also studied:

\displaystyle\|A(I-\mathbb{P}_{V})\|_{\mathsf{F}}^{2}\leq(1+\varepsilon)\min_{\text{rank-}k\,B}\|A-B\|_{\mathsf{F}}^{2}.

Here
\mathbb{P}_{V}
denotes the orthogonal projection matrix onto the subspace
V
.

We show that using composable sketches for
\ell_{2}
sensitivity sampling, we can solve the low rank approximation problem. While the composable sketch for
\ell_{2}
sensitivity sampling has
\tilde{O}(d)
rows, we will show that for solving the low rank approximation problem, the composable sketch need only have
\tilde{O}(k)
rows. We use the following result.

Theorem 7.6

(
[
16
, Theorem 4.2]
)
.

If
A
is an
n\times d
matrix and
\mathbf{R}
is a
d\times m
random sign matrix for
m=O(k\log(1/\delta)/\varepsilon)
, then with probability
\geq 1-\delta
,

\displaystyle\min_{\text{rank-}k\,X}\|A\mathbf{R}X-A\|_{\mathsf{F}}^{2}\leq(1+\varepsilon)\min_{\text{rank-}k\,B}\|A-B\|_{\mathsf{F}}^{2}.

Using the affine embedding result of
[
18
]
, if
\mathbf{L}
is now a leverage score sampling matrix, meaning that
\mathbf{L}
is a diagonal matrix with the entry
1/\sqrt{p_{i}}
for the rows that are sampled by the leverage score sampling algorithm as in Theorem
7.1
, then for all matrices
X

\displaystyle\|\mathbf{L}A\mathbf{R}X-\mathbf{L}A\|_{\mathsf{F}}^{2}=(1\pm\varepsilon)\|A\mathbf{R}X-A\|_{\mathsf{F}}^{2}.

Hence, if

\displaystyle\tilde{X}=\argmin_{\text{rank-}k\,X}\|\mathbf{L}A\mathbf{R}X-\mathbf{L}A\|_{\mathsf{F}}^{2},

then
\|A\mathbf{R}\tilde{X}-A\|_{\mathsf{F}}^{2}\leq(1+O(\varepsilon))\min_{\text{rank-}k\,B}\|A-B\|_{\mathsf{F}}^{2}
which implies that
\|A(I-\mathbb{P}_{\text{rowspace}(\mathbf{R}\tilde{X})})\|_{\mathsf{F}}^{2}\leq(1+O(\varepsilon))\min_{\text{rank-k}\,B}\|A-B\|_{\mathsf{F}}^{2}
.

Thus, if
\mathbf{R}
is a random sign matrix with
O(k\log(1/\delta)/\varepsilon)
rows, then
{\rm{sk}}_{t,\gamma}(\mathcal{A}.{\rm{vals}}\cdot\mathbf{R})
, along with the corresponding rows in
\mathcal{A}.{\rm{vals}}
for the rows in
{\rm{sk}}_{t,\gamma}(\mathcal{A}.{\rm{vals}}\cdot\mathbf{R})
, can be used to compute a
1+\varepsilon
approximation to the low rank approximation problem. As the matrix
\mathcal{A}.{\rm{vals}}\cdot\mathbf{R}
has only
\tilde{O}(k)
rows, the composable sketch
{\rm{sk}}_{t,\gamma}(\mathcal{A}.{\rm{vals}}\cdot\mathbf{R})
has a number of rows that depends only on
k
as well.

Appendix B
Huber Loss Function

Given a parameter
\tau
, the Huber loss function
f
is defined as
f(x)=x^{2}/(2\tau)
if
|x|\leq\tau
and
f(x)=|x|-\tau/2
if
|x|\geq\tau
. In this work we consider only the values of
x\geq 0
. We will now examine various properties of the Huber loss function.

B.1
Super-additivity

One can verify that the huber loss function is convex and
f(0)=0
. Consider arbitrary
x,y\geq 0
. Since
f
is convex in the interval
[0,x+y]
, we get

\displaystyle f(x)\leq\frac{x}{x+y}f(x+y)\quad\text{and}\quad f(y)\leq\frac{y}{x+y}f(x+y).

Adding both the inequalities, we get
f(x)+f(y)\leq f(x+y)
. Thus we have the following lemma:

Lemma B.1
.

If
f
is convex and
f(0)=0
, then for any
x,y\geq 0
, we have
f(x+y)\geq f(x)+f(y)
.

B.2
Bounding
c_{f}[s]

We note that when
f
denotes the Huber loss function with parameter
\tau
, the function
\sqrt{f}
is concave on the interval
[0,\infty)
. Now consider arbitrary
x_{1},\ldots,x_{s}\geq 0
. By concavity of
\sqrt{f}
in the interval
[0,x_{1}+\cdots+x_{s}]
, we get

\displaystyle\sqrt{f(x_{j})}\geq\frac{x_{j}}{x_{1}+\cdots+x_{s}}\sqrt{f(x_{1}+\cdots+x_{s})}

for all
j=1,\ldots,s
. By adding all the inequalities,

\displaystyle\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{s})}\geq\sqrt{f(x_{1}+\cdots+x_{s})}

which implies

\displaystyle f(x_{1}+\cdots+x_{s})\leq\left(\sqrt{f(x_{1})}+\cdots+\sqrt{f(x_{s})}\right)^{2}

and therefore that
c_{f}[s]\leq s
when
f
is the Huber loss function.

Appendix C
Derandomizing Exponential Random Variables using Nisan’s PRG

Our algorithm for estimating higher-order correlations assumes that we have access to
O(n^{k})
independent exponential random variables, which raises the question how these are stored since the protocol later requires the values of these random variables. We now argue that Nisan’s PRG
[
34
]
can be used to derandomize the exponential random variables and that all the required exponential random variables can be generated using a short seed of length
O(k\log^{2}(n/\varepsilon))
.

Note that using
O(k\log(n/\varepsilon))
bits of precision, we can sample from a discrete distribution that approximates the continuous exponential random variables up to a
1\pm\varepsilon
factor since by a simple union bound if we sample
O(n^{k}/\varepsilon^{2})
exponential random variables, then they all lie in the interval
[\operatorname{poly}(\varepsilon)\cdot n^{-O(k)},O(k\log n/\varepsilon)]
with a
1-1/\operatorname{poly}(n)
probability. Let
b=O(k\log(n/\varepsilon))
. We can use
b
uniform bits to sample from this discrete distribution and store the sampled discrete random variables using
b
bits as well while ensuring that the discrete random variable has all the properties we use of the continuous random variable. Let
\mathbf{e}
be the random variable drawn from this discrete distribution and let
\mathbf{e}_{1},\ldots,\mathbf{e}_{n}
independent copies of this discrete random variable. Since the distribution of
\mathbf{e}
is obtained by discretizing the continuous exponential random variable into powers of
1+\varepsilon/4
, we have that
\max(f_{i}/\mathbf{e}_{i})
has the same distribution of
(\sum_{i}f_{i})/\mathbf{e}
up to a
1\pm\varepsilon/4
factor and with probability
\geq 1-1/\operatorname{poly}(n)
,
\sum_{i}\mathbf{e}_{i}^{-1}f_{i}\leq(C\log^{2}n)\cdot\max_{i}f_{i}/\mathbf{e}_{i}
still holds with a slightly larger value of
C
.

To run the protocol for approximating higher-order correlations, we need to generate the same
r^{\prime}=O(\binom{n}{k}\cdot k!\cdot\varepsilon^{-2})
exponential random variables at all the servers and the coordinator. Suppose that the exponential random variables are generated using a random string of length
b\cdot r^{\prime}
as follows: we use the first
b\cdot\binom{n}{k}\cdot k!
bits to generate the first set of exponential random variables, one for each coordinate of the form
(i_{1},\ldots,i_{k})
for distinct
i_{1},\ldots,i_{k}\in[n]
. We use the second set of
b\cdot\binom{n}{k}k!
random bits to generate second set of exponential random variables and so on we generate
m=O(1/\varepsilon^{2})
sets of exponential random variables necessary for implementing the protocol. Let
\mathbf{e}^{(t)}_{(i_{1},i_{2},\ldots,i_{k})}
be the discrete exponential random variable corresponding to the coordinate
(i_{1},\ldots,i_{k})
in the
t
-th set of random variables.

Let
f
be a vector with coordinates of the form
(i_{1},\ldots,i_{k})
for distinct
i_{1},\ldots,i_{k}\in[n]
. Now consider the following simple “small-space” algorithm Alg. It makes a pass on the length
b\cdot r
string reading
b
blocks at a time and maintains the following counts:

1.

CountLess: The number of values
t
such that

\max_{i_{1},\ldots,i_{k}}(\mathbf{e}_{(i_{1},\ldots,i_{k})}^{(t)})^{-1}f_{(i_{1},\ldots,i_{k})}\geq(1+\varepsilon)\frac{\sum_{i_{1},\ldots,i_{k}}f_{(i_{1},\ldots,i_{k})}}{\ln 2},

2.

CountMore: The number of values
t
such that

\max_{i_{1},\ldots,i_{k}}(\mathbf{e}_{(i_{1},\ldots,i_{k})}^{(t)})^{-1}f_{(i_{1},\ldots,i_{k})}\leq(1-\varepsilon)\frac{\sum_{i_{1},\ldots,i_{k}}f_{(i_{1},\ldots,i_{k})}}{\ln 2},

3.

CountHeavy: The number of values
t
such that

\sum_{(i_{1},\ldots,i_{k})}(\mathbf{e}^{(t)}_{(i_{1},\ldots,i_{k})})^{-1}f_{(i_{1},\ldots,i_{k})}\leq(C\log^{2}n)\max_{i_{1},\ldots,i_{k}}(\mathbf{e}_{(i_{1},\ldots,i_{k})}^{(t)})^{-1}f_{i_{1},\ldots,i_{k}}.

Note that the algorithm can keep track of all these random variables only using
O(b)
bits of space as follows: When processing the first set of discrete exponential random variables, the algorithm keeps track of cumulative sum and cumulative max corresponding to those set of random variables and at the end updates the counts appropriately. It discards the stored cumulative sum and cumulative max values and starts processing the second set of random variables and so on.

We now note using the properties of continuous exponential random variables that when the discrete exponential random variables are sampled in the above defined manner using a fully random string, then with probability
\geq 99/100
, using the union bound over the properties of continuous exponential random variables, the following happen:

1.

\texttt{CountLess}<m/2
,

2.

\texttt{CountMore}<m/2
, and

3.

\texttt{CountHeavy}=m
.

The first two properties from the fact that the median of
O(1/\varepsilon^{2})
independent copies of the random variable
(\sum_{(i_{1},\ldots,i_{k})}f_{(i_{1},\ldots,i_{k})})/\mathbf{e}
concentrates in the interval
[(1-\varepsilon)\sum_{(i_{1},\ldots,i_{k})}f_{(i_{1},\ldots,i_{k})}/\ln 2,(1+\varepsilon)\sum_{(i_{1},\ldots,i_{k})}f_{(i_{1},\ldots,i_{k})}/\ln 2]
and hence both the counts are at most
m/2
. The third property follows from using a union bound on the event in Lemma
2.1
.
Since the algorithm
Alg
uses only a space of
O(b)
bits and the number of required random bits is
\exp(b)
, if the discrete exponential random variables are constructed using a pseudorandom string drawn from Nisan’s PRG with a seed length of
O(b^{2})
bits, the above properties continue to hold with probability
\geq 98/100
. Hence, the protocol run with discrete exponential random variables constructed using Nisan’s PRG continues to succeed in outputting a
1\pm\varepsilon
approximation to the higher-order correlation defined by the functions
f
and
g
also succeeds with probability
\geq 98/100
.
