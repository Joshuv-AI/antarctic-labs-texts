Introduction

Time
and
space
are arguably the two most fundamental measures of computational resources in the theory of computation. Time-space tradeoff studies the (im)possibility of solving computational problems simultaneously in low space and time. Among many problems studied in this area,
Element Distinctness
is a fundamental one.

Element Distinctness
: Given (read-only random access to) a list of
n
positive integers
a_{1},\dots,a_{n}
, each taking value in
[1,\mathrm{poly}(n)]
, decide whether all
a_{i}
’s are distinct.

Upper bounds.
We start our discussion with upper bounds. If we have
O(n)
words (each word has
O(\log n)
bits) of working space, we can solve the problem just by sorting. This costs
\widetilde{O}(n)
1
1

1

For brevity, throughout this article, we use
\widetilde{O}(f)
to hide
\mathrm{polylog}(f,n)
factors.
time
but
\Omega(n)
space. On the other hand, we can enumerate every pair of indices to check if there is a colliding pair. This costs
\Omega(n^{2})
time but only requires
O(1)
space. More generally, by applying a low-space sorting algorithm
[
MP80
,
PR98
]
,
Element Distinctness
can be solved in time
T(n)
and space
S(n)
for every
T(n),S(n)
such that
T(n)\cdot S(n)\geq n^{2}
. For
comparison-based
model, this is known to be optimal
[
BFadH+87
,
Yao94
]
.

Surprisingly, if we consider non-comparison-based algorithms, a better tradeoff can be achieved. In 2013, Beame, Clifford, and Machmouchi
[
BCM13
]
gave a non-comparison-based algorithm (which we call the BCM algorithm henceforth) for
Element Distinctness
with time-space tradeoff
T(n)\leq\widetilde{O}(n^{3/2}/S(n)^{1/2})
,
assuming a random oracle
: read-only random access to polynomially many random bits that do not count towards the space complexity. This assumption is strong: it assumes that there is a large table of random bits to which the algorithm has free and random access. A more practical model is called
one-way
access to random bits. That is, the algorithm can request a random bit (i.e., toss a coin) at each time, but cannot read random bits requested in the past (unless it stores the bits in its own working memory).

The CJWW algorithm.
For the case that
S(n)={\mathsf{polylog}}(n)
, the random oracle assumption was removed in a recent breakthrough by Chen, Jin, Williams and Wu
[
CJWW22
]
, who gave the first truly low-space algorithm for
Element Distinctness
that beats pairwise-comparison: their algorithm runs in
O({\mathsf{polylog}}(n))
space and
\widetilde{O}(n^{3/2})
time, with typical one-way access to random bits.

However, the algorithm by Chen
et al.
does not naturally extend to a smooth time-space tradeoff as the BCM algorithm does. The analysis in
[
CJWW22
]
is involved and carefully tailored to the case
S(n)=O({\mathsf{polylog}}(n))
. Therefore, it is not clear from their proof whether the case
S(n)=O({\mathsf{polylog}}(n))
and
S(n)=n^{\Omega(1)}
have any inherent difference. It was asked as an open question in
[
CJWW22
]
whether their algorithm can be generalized to a tradeoff result.

Lower bounds.
One might also wonder whether the tradeoff
T(n)\cdot S(n)^{1/2}\approx\Theta(n^{3/2})
is tight, even assuming a random oracle. While the current technique fails to give a matching lower bound (the best lower bound for
Element Distinctness
is barely superlinear
[
Ajt05
]
), for a closely related problem, the same algorithmic idea still applies, and a
matching
lower bound exists. We consider the
Set Intersection
problem.

Set Intersection
: Given two integer sets represented by two (not necessarily sorted) input lists
(a_{1},\dots,a_{n})
,
(b_{1},\dots,b_{n})
which are promised to not contain duplicates, print all the elements in the intersection
A\cap B
.

Note that
Set Intersection
can be seen as a variant of
Element Distinctness
: now the task is to find collisions between two lists, and the algorithm needs to output
all collisions
. The BCM algorithm applies to
Set Intersection
and gives the same tradeoff
T(n)\cdot S(n)^{1/2}=\Theta(n^{3/2})
.

The work by Patt-Shamir and Peleg
[
PP93
]
and by Dinur
[
Din20
]
showed that any
S(n)
-space algorithm for
Set Intersection
must use time
T(n)\geq\Omega(n^{3/2}/S(n)^{1/2})
, even if the printed elements can be in any order, and each element in
A\cap B
is allowed to be printed multiple times. Therefore, assuming a
random oracle
, we conclude that
T(n)\cdot S(n)^{1/2}\approx\Theta(n^{3/2})
is the optimal time-space tradeoff for
Set Intersection
.

Chen
et al.

[
CJWW22
]
also gave a randomized algorithm for
Set Intersection
that runs in time
O(n^{3/2})
and space
O({\mathsf{polylog}}(n))
. Given the lower bound, the running time is optimal in the regime
S(n)=O({\mathsf{polylog}}(n))
. Still, it is open whether one can generalize their algorithm to achieve the optimal time-space tradeoff.

The CJWW pseudorandom hash family.
The main technical tool behind the CJWW algorithm is a construction of a small hash family
{\mathcal{H}}\subseteq\{h:[m]\to[n]\}
, which is samplable using
O(\log^{3}n\log\log n)
random bits. This also implies that every
h\in{\mathcal{H}}
admits a short description (namely, the random seed used to generate
h
). They then use a random
\mathbf{h}\sim{\mathcal{H}}
to replace the random oracle required by the BCM algorithm, and show that it does not degrade the success probability of the algorithm too much (thanks to a certain pseudorandom property).

The pseudorandom hash family by Chen
et al.
is based on the iterative restriction framework
[
AW89
]
. Roughly speaking, the iterative restriction framework starts by assuming that
\mathbf{h}:[m]\to[n]
is truly random function, and gradually fills in entries of
\mathbf{h}
with pseudorandom elements. In pseudorandomness literature, people have utilized this methodology to construct pseudorandom generators (PRG) for various computational models
[
GMR+12
,
TX13
,
HLV18
,
LV20
,
FK18
,
MRT19
]
. However, in all these PRG results, the statistical tests considered are not adaptive, in the sense that the target circuit/program always reads its input in a
pre-defined
pattern.

Remarkably, the algorithm by Chen
et al.
provides a non-trivial example, showing that the iterative restriction construction can fool some classes of highly-adaptive tests, where the future query to the (pseudorandom) hash function
\mathbf{h}
heavily depends on the previous responses returned by
\mathbf{h}
. This motivates us to further explore the capability of pseudorandom objects constructed by the iterative restriction framework.

1.1
Our Results

The main result of this paper is an affirmative answer to the open questions left by
[
CJWW22
]
. Namely, we extend the algorithm by Chen
et al.
to the whole time-space tradeoff, matching the tradeoff offered by the BCM algorithm.
Our result is mainly based on an improved analysis of the pseudorandom hash family constructed by Chen
et al.

[
CJWW22
]
. Along the way, we also prove some new pseudorandom properties of the hash family, which seem difficult to establish by other means. Therefore, we think the analysis may be of independent interest to the pseudorandomness community. We elaborate on our contributions below.

Algorithmic results.
We start with the algorithm side. First, we show an improved time-space tradeoff for
Element Distinctness
and
Set Intersection
that beats sorting.

Theorem 1
.

For every complexity bound
S(n),T(n):\mathbb{N}\to\mathbb{N}
such that
S(n)^{1/2}\cdot T(n)\geq n^{1.5}
, there is a Monte Carlo algorithm solving
Element Distinctness
in time
O(T(n)\cdot{\mathsf{polylog}}(n))
and space
O(S(n)\cdot{\mathsf{polylog}}(n))
with one-way access to random bits. Moreover, when there is a colliding pair, the algorithm reports one with high probability.

Theorem 2
.

For every complexity bound
S(n),T(n):\mathbb{N}\to\mathbb{N}
such that
S(n)^{1/2}\cdot T(n)\geq n^{1.5}
, there is a Monte Carlo algorithm solving
Set Intersection
in time
O(T(n)\cdot{\mathsf{polylog}}(n))
and space
O(S(n)\cdot{\mathsf{polylog}}(n))
with one-way access to random bits. The algorithm prints elements in no particular order, and the same element may be printed multiple times.

In light of Dinur’s lower bounds
[
Din20
]
, Theorem
2
is optimal up to polylogarithmic factors. Even if we believe the tradeoff given by Theorem
1
is not tight, new ideas are required to separate
Element Distinctness
from its multi-output variant
Set Intersection
. Using current techniques, Theorem
1
seems hard to improve, even allowing random oracles or considering the non-uniform low-space model (i.e. branching programs).

In the extremely low-space regime, the algorithm by Chen
et al.

[
CJWW22
]
needs
\Omega(\log^{3}n\log\log n)
bits of working memory to store the seed for the hash function. As a byproduct of our improved analysis, we reduce the seed length to
O(\log^{3}n)
bits. Consequently, now we only need
O(\log^{3}n)
bits of working space to start beating the trivial pairwise-comparison algorithm.

Theorem 3
.

Both
Element Distinctness
and
Set Intersection
can be solved by a Monte Carlo algorithm that runs in
\widetilde{O}(n^{3/2})
time, uses
O(\log^{3}n)
bits of working space and no random oracle.

\mathbf{x}_{1},\dots,\mathbf{x}_{c_{d}}
. For each
i\in[c_{d}]
, it samples
q_{i}\sim\mathrm{Geom}(1/2)
, and
q_{i}-1

\mathbf{x}_{i,2},\dots,\mathbf{x}_{i,q_{i}}
. It also sets
\mathbf{x}_{i,1}:=\mathbf{x}_{i}
. After that, it sends the vertices
(\mathbf{x}_{i,j})_{i\in[c_{d}],j\in[q_{i}]}
to
\mathbf{h}_{d-1}
, asking
\mathbf{h}_{\leq d-1}
to generate
\left|\sum_{i}q_{i}\right|
walk sequences with the given starting points.

In particular, when
d=1
,
\mathbf{h}_{1}
just outputs these vertices (there is no
\mathbf{h}_{0}
). They constitute the final walk sequence.

Digest.
Under the two simplifying assumptions, we claim that the walk sequence generated by the parallelized process is identically distributed as the original walk.
To see this, note that in the original sequence, when
\mathbf{h}_{t}
passes
\mathbf{x}_{1}
down to
\mathbf{h}_{t-1}
, it needs to wait for
\mathbf{h}_{\leq t-1}
to do the walk and send back the vertex
\mathbf{x^{\prime}}
such that
\mathbf{h}_{\leq t-1}(a_{\mathbf{x^{\prime}}})\equiv 0
6
6

6

Given Assumption
1
that we are always visiting new entries, and Assumption
2
that each new entry of
\mathbf{h}_{t-1}
is
0
with probability
\frac{1}{2}
, such
\mathbf{x^{\prime}}
exists with probability
1
.
.
However, under Assumption
1
, we can tell for sure that
\mathbf{h}_{t}(a_{\mathbf{x^{\prime}}})
must have not been reached before,
and under Assumption
2
, we know that
\mathbf{h}_{t}(a_{\mathbf{x^{\prime}}})
is a random element from
[n]\cup\{0\}
with
\Pr[\mathbf{h}_{t}(a_{\mathbf{x^{\prime}}})=0]=1/2
.

Therefore, without knowing exactly what
\mathbf{x}^{\prime}
is, we can tell that
\mathbf{h}_{t}
sends the second query to
\mathbf{h}_{t-1}
with probability
\frac{1}{2}
.
When this does happen, it sends a uniformly random vertex from
[n]
. Moreover, the next time
\mathbf{h}_{t}
receives a vertex
\mathbf{x}^{\prime\prime}
from
\mathbf{h}_{t-1}
, the same argument applies: with probability
\frac{1}{2}

\mathbf{h}_{t}
finds that
\mathbf{h}_{t}(a_{\mathbf{x}^{\prime\prime}})\neq 0

In general, independently of
\mathbf{h}_{1},\dots,\mathbf{h}_{t-1}

\mathbf{h}_{t}

\mathbf{h}_{t-1}

and each vertex is uniformly random in

The same argument also applies to lower level hashes

.

We call this new process a parallelized walk, because (under two assumptions) this process breaks the “sequential” natural of the random walk. Intuitively, for each
d\in[t]
,
\mathbf{h}_{d}
receives (roughly)
c_{d}\approx 2^{t-d}
starting vertices from
\mathbf{h}_{d+1}
and is asked to generate
c_{d}
sequences. Knowing all these starting vertices,
\mathbf{h}_{d}
can process these
c_{d}

\mathbf{h}_{d}
will then pass
c_{d-1}\approx 2^{t-d+1}
starting vertices to the next level in a batch. One can visualize the parallelized walk as a hierarchical structure with
t
levels
(\mathbf{h}_{t},\dots,\mathbf{h}_{1})
and roughly
2^{t}=\sqrt{n}
branches (see Figure
2
for an illustration). In the following, we denote this structure as the walk tree (see Section
4
for its formal definition).

Next, we will explain how to remove the two simplifying assumptions and prove the desired probability lower bound (
3
).

Lower-bounding (
3
) and removing Assumption
2
.
We first explain how to remove Assumption
2
and sketch our strategy for proving (
3
). Having parallelized the walk, this is indeed straightforward. Since we only want to know if a given pair
(p,q)
have been reached in the walk, we can enumerate two “branches” in the walk tree, and observe if they hit
p,q
. Since we have parallelized the walk sequence, each vertex in the walk tree only depends on its ancestors. Recall
\kappa=O(\log n)
and
\Pr[\mathrm{Geom}(1/2)>\kappa/10]<\frac{1}{\mathrm{poly}(n)}
. With high probability, each
\mathbf{h}_{d}
makes no more than
\frac{\kappa}{10}
steps in a branch. Hence, using
\kappa
-wise independent hash functions suffices for fooling the observation of two branches.

Also note that by setting
\kappa
larger by a constant factor, the same argument holds even if we observe a constant number of branches in the walk tree. Namely, if we only observe
O(1)
branches in the walk tree, we cannot distinguish between the case that
\mathbf{h}_{i}
’s are truly random and the case that they are barely
\kappa
-wise independent. In the following, we refer to this property as “constant-wise independence” of the walk tree. This observation is important for the
c
-connecting property, as well as the tradeoff result.

Since we have set
t\approx\frac{1}{2}\log n
, there will be roughly
2^{t}
branches in the walk tree. We have shown that these branches appear to be “constant-wise” independent. Therefore, the probability that two of those branches hit
p,q
is roughly

\frac{2^{t}}{n}\cdot\frac{2^{t}}{n}\approx\frac{1}{n}

as desired.

Removing Assumption
1
.
Now we explain the idea for removing Assumption
1
, which is the most technical part of the proof. To begin with, note that Assumption
1
is indeed true for a prefix of the walk sequence (namely, before the walk reaches a vertex
\mathbf{x}_{i}
such that
a_{\mathbf{x}_{i}}=a_{\mathbf{x}_{j}}
for some
j<i
).

There is an “obvious” way to achieve Assumption
1
: during the random walk, if some
\mathbf{h}_{d}
attempts to query an entry
\mathbf{h}_{d}(a_{\mathbf{x}_{i}})
for the second (or more) time, it samples a new element from
[n]\cup\{0\}
to replace
\mathbf{h}_{d}(a_{\mathbf{x}_{i}})
. In this way, effectively, the hash function is always accessing new entries, and we can lower-bound the probability of hitting both
p
and
q
by
\frac{2^{2t}}{n^{2}}\approx\frac{1}{n}
. However, in this process we also count in some invalid contribution: if the walk visits the same vertex
\mathbf{x}
twice before hitting
p
and
q
, then we know the contribution from this walk is “invalid”. To subtract invalid contribution, we enumerate
i,j,u,v
such that
i,j<\max(u,v)
, and calculate the probability that
a_{\mathbf{x}_{i}}=a_{\mathbf{x}_{j}}
and
(\mathbf{x}_{u},\mathbf{x}_{v})=(p,q)
. In this process, we only observe
4
branches in the walk tree, by the constant-wise independence of the walk tree, we can (roughly) upper bound the probability by
\frac{1}{n^{3}}
(Fixing
a_{\mathbf{x}_{i}}
, we have
a_{\mathbf{x}_{j}}=a_{\mathbf{x}_{i}}
w.p.
\frac{1}{n}
, and
(\mathbf{x}_{u},\mathbf{x}_{v})=(p,q)
w.p.
\frac{1}{n^{2}}
). Summing up
(i,j,u,v)
, the amount of invalid contribution is bounded by
\frac{2^{4t}}{n^{3}}
. Therefore,
\frac{2^{2t}}{n^{2}}-\frac{2^{4t}}{n^{3}}
would be a valid lower bound for
\Pr[p,q\in\{\mathbf{x}_{i}\}]
. In the actual proof, we set
t=\frac{1}{2}\log n-5
. This gives
\frac{2^{2t}}{n^{2}}-\frac{2^{4t}}{n^{3}}\geq(2^{-10}-2^{-20})\cdot\frac{1}{n}\geq\Omega(1/n)
, as desired.

Unfortunately, there is a subtle but critical flaw in this argument: the “resampling” operation breaks the
\kappa
-wise independence of the hash function! Consider the following
T
-round interaction between a
\kappa
-wise independent hash function
\mathbf{h}_{d}
and an adversary
\mathcal{A}
.

•

In the
i
-th round, based on the interaction history,
\mathcal{A}
chooses and sends
y\in[m]
to
\mathbf{h}_{d}
.
\mathbf{h}_{d}
sends
\mathbf{h}_{d}(y)
back to
\mathcal{A}
. Meanwhile,
\mathbf{h}_{d}
also resets
\mathbf{h}_{d}(y)
to a uniformly random element.

If
\mathbf{h}_{d}
was sampled as a truly-random hash,
\mathbf{h}_{d}
would stay truly-random after the interaction. However, if
\mathbf{h}_{d}
is from a
\kappa
-wise independent distribution, then
\mathcal{A}
might cause
\mathbf{h}_{d}
to be highly biased after the interaction. Back to our example, it is not clear how
\mathbf{h}_{d}
is interacting with
\mathbf{h}_{\leq d-1}
. In the worst case, if
\mathbf{h}_{\leq d-1}
interacts with
\mathbf{h}_{d}
“adversarially” and
\mathbf{h}_{d}
chooses to resample for all queries, then
\mathbf{h}_{d}
will no longer be
\kappa
-wise independent after the first few rounds of communication.

We are ready to introduce our final idea, which is the key to simplify the analysis. Since describing the idea precisely requires quite a bit technical work, we only present the high-level idea here, and refer interested readers to Section
4
for its detail (in particular, see Algorithm
2
and Lemma
5
). Roughly speaking, we show that we do not need to do the “resampling” for every query to the hash functions. Recall that to prove the lower bound, we only need to observe two branches in the walk tree. We show that, we only need to do “resample” in the “observed part” of the walk tree. There are two intuitions for this idea. First, in order to prove that the observed part is random, we do not really care about the remaining part of the walk tree. Therefore, only resampling for the observed part suffices to establish the proof. Second, in the observed part, each hash function is queried for at most
\kappa
times, the
\kappa
-wise independence suffices to ensure the randomness of query results (in particular, the “adversarial attack” issue mentioned above does not exist anymore).

Comparison with CJWW

Our idea of using iterative restriction construction is directly inspired by
[
CJWW22
]
. Therefore, it is worthwhile to compare our results with theirs. While our technical analysis shares some similarities with
[
CJWW22

, in order to simplify the

Conceptual idea.
Conceptually, we propose to view the walk sequence as generated by “communication between
t
independent hash functions”. While this conceptual idea does not bring any immediate technical consequence, it is nevertheless crucial for obtaining the final proof. The main structure that the iterative restriction framework offers us is that the
t

\mathbf{h}_{1},\dots,\mathbf{h}_{t}
are independent. It turns out the “communication” perspective is a desired way to exploit this structure. Essentially, when we “parallelize” the random walk, we are reducing the many-round communication between
\mathbf{h}_{i}
’s to a one-way, top-down communication from
\mathbf{h}_{t}
down to
\mathbf{h}_{1}
, which is the key for the final proof.

Moreover, from the communication perspective, it is easy to show that we can use
\kappa
-wise
almost
independent hash functions to generate
\mathbf{h}_{1},\dots,\mathbf{h}_{d}
. This is a claim that seems difficult to obtain through the analysis by
[
CJWW22
]
(in fact, this answers a question posed in
[
CJWW22
]
). Although this observation does not reduce the overall seed length
7
7

7

We need
\Theta(\log n)
bits to describe an entry of the hash
h:[m]\to[n]
. Therefore, requiring
\mathbf{h}
to be almost
\kappa
-wise independent reduces to constructing an almost
\Theta(\kappa\log n)
-wise independent binary string, which brings the total seed length to
\Theta(\kappa\log n)
. On the other hand, sampling a perfect
\kappa
-wise independent hash also requires
\Theta(\kappa(\log n+\log m))
random bits.
, it adds one more evidence suggesting that the communication perspective provides a fairly powerful “conceptual method” to analyze pseudorandom objects that consist of several independent building blocks. We hope this idea can help understand more pseudorandom properties of the iterative restriction framework.

The concept of “communication” is not new in the pseudorandomness literature (See, e.g.,
[
INW94

NZ96

IMZ12

BRRY14

For example, to prove the extractor-based PRG for read-once branching program, the standard method works by splitting the program into two halves, and arguing that the “message” passed from the first half to the second is so small that we can use an extractor to “refresh” the random seed (see

2.3
Extensions

From the communication perspective, we have shown that the parallelized walk sequence appears random if we only observe a constant number of vertices in the walk (i.e., the “constant-wise independent” property of the walk tree). This allows us to prove the
c
-connecting property (Theorem
4
) easily. However, to obtain the tradeoff result, new ingredients are required.

Review of the BCM tradeoff.
Let us first review the tradeoff given by the BCM algorithm
[
BCM13
]
. Let
k\leq n
. Suppose we have access to a random hash
h:[m]\to[n]
and
\widetilde{O}(k)
bits of working memory. In this case, the BCM algorithm randomly selects
k
starting vertices and produces
k
walks. We assume
a_{p}=a_{q}
is the only colliding pair in the input array.
[
BCM13
]
shows that, if there are two walks hitting
p
and
q
, the algorithm can find the pair
(p,q)
with
\widetilde{O}(k)
bits of working memory.
[
BCM13
]
further shows that in a single trial, the algorithm succeeds in hitting both
p
and
q
with probability
\Omega\left(\frac{k}{n}\right)
, while the running time of one trial is bounded by
\widetilde{O}(\sqrt{kn})
. Running
\widetilde{O}(n/k)
trials independently succeeds in finding the pair with high probability. The total running time is
\widetilde{O}(n^{3/2}/\sqrt{k})
.

Now, to fool the tradeoff algorithm with the pseudorandom hash family, it seems we need at least
k
-wise independence to simultaneously monitor the
k
walks. While we can store the seed for
k
-wise independent hash functions (we have
\widetilde{O}(k)
working space now), we cannot afford the
\Omega(k)
time overload to evaluate a
k
-wise independent hash function.

A “local” analysis of the BCM tradeoff

We show
k
-wise independence is
not
necessary. In particular, we observe that there is a “local” proof of the BCM tradeoff. Roughly speaking, by “local” we mean that to lower bound the success probability in one trial, one only needs to consider some simple probabilities that only involve a constant number of vertices in the
k
walks. Consequently, the hash family constructed from
O(\log n)
-wise independent primitives yields the same
\Omega(k/n)
success probability, allowing us to remove the random oracle assumption.

To illustrate the idea, we sketch the “localized proof” for truly random hash
\mathbf{h}:[m]\to[n]
below. Suppose
\mathbf{x}^{1},\dots,\mathbf{x}^{k}
are the
k
random starting vertices. Let
c>0
be a sufficiently small constant. For each starting vertex
\mathbf{x}^{i}
, consider the first
L=c\sqrt{n/k}
steps of move in the
i
-th walk. Namely, for each
i\in[k]
, we consider

\mathbf{x}^{i}_{1}=\mathbf{x}^{i},\penalty\ \penalty\ \penalty\ \mathbf{x}^{i}_{2}=\mathbf{h}(a_{\mathbf{x}^{i}_{1}}),\penalty\ \penalty\ \penalty\ \dots,\penalty\ \penalty\ \penalty\ \mathbf{x}^{i}_{L}=\mathbf{h}(a_{\mathbf{x}^{i}_{L-1}}).

Note that it takes
O(\sqrt{nk})
time to go through these sequences (this corresponds to the running time of the BCM algorithm). Our goal is to prove
\Pr[p,q\in\{\mathbf{x}^{i}_{j}\}_{i\in[k],j\in[L]}]\geq\Omega(k/n)
.

A coupling-based proof.
For the purpose of analysis, we imagine
k
sequences
(\mathbf{y}^{i}_{1},\dots,\mathbf{y}^{i}_{L}),\forall i\in[k]
that are jointly distributed with
\mathbf{x}^{i}_{j}
and are defined as follows. For each
i\in[k]
, we set
\mathbf{y}^{i}_{1}=\mathbf{x}^{i}_{1}
. For each
j=1,\dots,L-1
, if
a_{\mathbf{x}^{i}_{j}}=a_{\mathbf{x}^{i^{\prime}}_{j^{\prime}}}
for some
(i^{\prime},j^{\prime})<(i,j)
(in the lexicographical order), we set
\mathbf{y}^{i}_{j+1},\dots,\mathbf{y}^{i}_{L}
as uniform and independent elements from
[n]
and complete the construction for the
i
-th sequence. Otherwise let
\mathbf{y}^{i}_{j+1}=\mathbf{x}^{i}_{j+1}
.

If
\mathbf{h}
is a truly random hash, the list
(\mathbf{y}^{i}_{j})_{i\in[k],j\in[L]}
contains
kL
independent and uniform elements. This is because every
\mathbf{y}^{i}_{j}
is obtained by either querying a new entry in
\mathbf{h}
or sampling a uniformly random element. For every pair
((i_{1},j_{1}),(i_{2},j_{2}))\in([k]\times[L])^{2}
, let
{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})
denote the event that all of following hold.

1.

First,
\mathbf{y}^{i_{1}}_{j_{1}}=p
and
\mathbf{y}^{i_{2}}_{j_{2}}=q
.

2.

For every
(i_{1},j_{3}),(i_{4},j_{4})
such that
j_{3}<j_{1}
and
(i_{4},j_{4})<(i_{1},j_{3})
, we have
a_{\mathbf{y}^{i_{1}}_{j_{3}}}\neq a_{\mathbf{y}^{i_{4}}_{j_{4}}}
.

3.

For every
(i_{2},j_{5}),(i_{6},j_{6})
such that
j_{5}<j_{2}
and
(i_{6},j_{6})<(i_{2},j_{5})
, we have
a_{\mathbf{y}^{i_{2}}_{j_{5}}}\neq a_{\mathbf{y}^{i_{6}}_{j_{6}}}
.

4.

For all
(i_{7},j_{7})<(i_{1},j_{1})
, it holds
\mathbf{y}^{i_{7}}_{j_{7}}\neq p
. For all
(i_{8},j_{8})<(i_{2},j_{2})
, it holds
\mathbf{y}^{i_{8}}_{j_{8}}\neq q
.

Here, Conditions 2 and 3 ensure that
\mathbf{y}^{i_{1}}_{j_{1}}=\mathbf{x}^{i_{1}}_{j_{1}}
and
\mathbf{y}^{i_{2}}_{j_{2}}=\mathbf{x}^{i_{2}}_{j_{2}}
. Condition
4
ensures the events
\{{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})\}_{i_{1},j_{1},i_{2},j_{2}}
are mutually disjoint. Moreover, we observe that each
{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})
implies
\mathbbm{1}\{p,q\in\{\mathbf{x}^{i}_{j}\}_{i\in[k],j\in[L]}\}
. Hence, we may conclude that

\Pr[p,q\in\{\mathbf{x}^{i}_{j}\}_{i\in[k],j\in[L]}]\geq\sum_{(i_{1},j_{1}),(i_{2},j_{2})}\Pr[{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})].

To lower bound
\Pr[{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})]
, we further decompose it into even simpler events by applying a union bound:

\displaystyle\Pr[{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})]

\displaystyle\geq\Pr[\mathbf{y}^{i_{1}}_{j_{1}}=p\land\mathbf{y}^{i_{2}}_{j_{2}}=q]-

\displaystyle\penalty\penalty\penalty\penalty\displaystyle\sum_{j_{3},(i_{4},j_{4})}\Pr[\mathbf{y}^{i_{1}}_{j_{1}}=p\land\mathbf{y}^{i_{2}}_{j_{2}}=q\land a_{\mathbf{y}^{i_{1}}_{j_{3}}}=a_{\mathbf{y}^{i_{4}}_{j_{4}}}]-

\displaystyle\penalty\penalty\penalty\penalty\displaystyle\sum_{j_{5},(i_{6},j_{6})}\Pr[\mathbf{y}^{i_{1}}_{j_{1}}=p\land\mathbf{y}^{i_{2}}_{j_{2}}=q\land a_{\mathbf{y}^{i_{2}}_{j_{5}}}=a_{\mathbf{y}^{i_{6}}_{j_{6}}}]-

\displaystyle\penalty\penalty\penalty\penalty\displaystyle\sum_{(i_{7},j_{7})}\Pr[\mathbf{y}^{i_{1}}_{j_{1}}=p\land\mathbf{y}^{i_{2}}_{j_{2}}=q\land\mathbf{y}^{i_{7}}_{j_{7}}=p]-

\displaystyle\penalty\penalty\penalty\penalty\displaystyle\sum_{(i_{8},j_{8})}\Pr[\mathbf{y}^{i_{1}}_{j_{1}}=p\land\mathbf{y}^{i_{2}}_{j_{2}}=q\land\mathbf{y}^{i_{8}}_{j_{8}}=q]

\displaystyle\geq\frac{1}{n^{2}}-O\left(\frac{kL^{2}}{n^{3}}\right)-O\left(\frac{kL}{n^{3}}\right)

\displaystyle\geq\frac{1}{n^{2}}-O\left(\frac{c^{2}}{n^{2}}\right).

In the summation above, the enumeration of indices (
j_{3},i_{4},j_{4},
etc.) follows the rule specified by Condition
2
-
4
, which we omit for brevity.

Choosing
c>0
to be small enough, we can lower bound
\Pr[{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})]
by
\Omega(1/n^{2})
. Finally, we may take a summation over all
(i_{1},j_{1}),(i_{2},j_{2})
to get:

\Pr\left[p,q\in\{\mathbf{x}^{i}_{j}\}_{i\in[k],j\in[L]}\right]\geq\sum_{(i_{1},j_{1}),(i_{2},j_{2})}\Pr[{\mathcal{E}}^{1}(i_{1},j_{1},i_{2},j_{2})]\geq\Omega\left(\frac{k^{2}L^{2}}{n^{2}}\right)\geq\Omega\left(\frac{k}{n}\right).

Conclusion.
Note that the proof above is highly local, in the sense that we reduce the task of lower-bounding
\Pr[p,q\in\{\mathbf{x}^{i}_{j}\}]
to analyzing a collection of simpler events, each involving only a constant number of vertices. To show the same lower bound for the pseudorandom hash, we use the same high-level proof strategy. But we will work with the walk tree and use our Lemma

2.4
Future Directions

Our work raises several directions for further research. We highlight two of them below. We also refer interested readers to
[
CJWW22
]
for discussions about more related work.

The power of iterative restriction.
The iterative restriction approach was first developed by Ajtai and Wigderson in their seminal work
[
AW89
]
, where they gave the first non-trivial pseudorandom generator (PRG) for constant-depth Boolean circuits (a.k.a.
\mathsf{AC}^{0}
circuits). In recent years, people have successfully applied this framework to give PRGs for various computational models
[
GMR+12
,
TX13
,
HLV18
,
LV20
,
FK18
,
MRT19
]
. However, as we have mentioned, in all these PRG results, the target circuit/program always reads its input in a pre-defined pattern.

Both
[
CJWW22
]
and our new result suggest that the iterative restriction is more versatile than we thought: they can fool some highly adaptive tests, in which the future query to the hash function heavily depends on previous responses. Also, the analysis is drastically different from the common paradigm in the PRG analysis (i.e., the “simplify-under-restrictions” lemma and hybrid argument combo). It would be interesting to see if there is a deeper connection between the new results and previous PRG results. In particular, it is known that the iterative restriction framework can fool fixed-order read-once branching program
[
FK18
]
(known as ROBP in literature). Note that the cycle-finding procedure can by captured by a special class of branching programs, where the program reads variables in an adaptive fashion, with the promise that every “acceptance path” is read-once. Can we formulate a computation model that (1) captures ROBP and the cycle-finding procedure as special cases, and (2) can be fooled by the iterative restriction construction?

Reduce the seed length further.
Can we reduce the seed length for the hash family further? One natural choice for such improvement would be reducing the
O(\log n)
-level pseudorandom hash family to constant levels. Even more ambitiously, what if we use two hash functions
\mathbf{h}_{1}:[m]\to[n]\cup\{0\}
and
\mathbf{h}_{2}:[m]\to[n]
and construct
\mathbf{h}=\mathbf{h}_{1}+\mathbbm{1}[\mathbf{h}_{1}=0]\cdot\mathbf{h}_{2}
. Intuitively, we let the walk alternate between
\mathbf{h}_{1}
and
\mathbf{h}_{2}
, with the hope that each
\mathbf{h}_{i}

\displaystyle=\sum_{k=0}^{\tau}2^{-k}\cdot\penalty\ \penalty\ \left(f(c,t-1)+\sum_{\begin{subarray}{c}n_{0}+n_{1}+\ldots+n_{k}=c\\
n_{i}\geq 0\\
c>n_{k}>0\end{subarray}}\penalty\ \penalty\ \prod_{i:n_{i}>0}\sum_{\begin{subarray}{c}S_{i}^{\prime}\subseteq S^{t-1}\\
|S_{i}^{\prime}|=n_{i}\end{subarray}}2^{1-|P^{(t-1)}(S_{i}^{\prime})|}\right)

\displaystyle=\sum_{k=0}^{\tau}2^{-k}\cdot\penalty\ \penalty\ \left(f(c,t-1)+\sum_{\begin{subarray}{c}n_{0}+n_{1}+\ldots+n_{k}=c\\
n_{i}\geq 0\\
c>n_{k}>0\end{subarray}}\penalty\ \penalty\ \prod_{i:n_{i}>0}f(n_{i},t-1)\right).

For non-negative integers
n_{0},n_{1},\ldots,n_{k}
, if
c>n_{k}>0
holds when
\sum_{i=0}^{k}=c
, we have
n_{i}<c
for all
0\leq i\leq k
. According to our assumption of the inductive step, we have
f(n_{i},t-1)\leq 2^{n_{i}\cdot(t-1)}
. Therefore,

\displaystyle f(c,t)

\displaystyle=\sum_{k=0}^{\tau}2^{-k}\cdot\left(f(c,t-1)+\sum_{\begin{subarray}{c}n_{0}+n_{1}+\ldots+n_{k}=c\\
n_{i}\geq 0\\
c>n_{k}>0\end{subarray}}\penalty\ \penalty\ \prod_{i:n_{i}>0}f(n_{i},t-1)\right)

\displaystyle\leq\sum_{k=0}^{\tau}2^{-k}\cdot\left(f(c,t-1)+\sum_{\begin{subarray}{c}n_{0}+n_{1}+\ldots+n_{k}=c\\
n_{i}\geq 0\\
c>n_{k}>0\end{subarray}}\penalty\ \penalty\ \prod_{i:n_{i}>0}2^{n_{i}\cdot(t-1)}\right)

\displaystyle=\sum_{k=0}^{\tau}2^{-k}\cdot\left(f(c,t-1)+\sum_{\begin{subarray}{c}n_{0}+n_{1}+\ldots+n_{k}=c\\
n_{i}\geq 0\\
c>n_{k}>0\end{subarray}}\penalty\ \penalty\ 2^{c\cdot(t-1)}\right)

\displaystyle=\sum_{k=0}^{\tau}2^{-k}\cdot\left(f(c,t-1)+\left(\binom{c+k-1}{c-1}-1\right)\cdot 2^{c\cdot(t-1)}\right)

\displaystyle\leq\sum_{k=0}^{+\infty}2^{-k}\cdot\left(f(c,t-1)+\left(\binom{c+k-1}{c-1}-1\right)\cdot 2^{c\cdot(t-1)}\right)

\displaystyle\leq\sum_{k=0}^{+\infty}2^{-k}\cdot\left(f(c,t-1)-2^{c\cdot(t-1)}\right)+2^{c\cdot t-1}\cdot\sum_{k=0}^{+\infty}2^{-(c+k-1)}\binom{c+k-1}{c-1}

\displaystyle\leq 2\cdot\left(f(c,t-1)-2^{c\cdot(t-1)}\right)+2^{c\cdot t}.

The last step is based on Lemma
14
. In this way, we have

\displaystyle f(c,t)-2^{c\cdot t}

\displaystyle\leq 2\cdot\left(f(c,t-1)-2^{c\cdot(t-1)}\right)

\displaystyle\leq 2^{2}\cdot\left(f(c,t-2)-2^{c\cdot(t-2)}\right)

\displaystyle\leq\ldots

\displaystyle\leq 2^{t-1}\cdot\left(f(c,1)-2^{c}\right)

\displaystyle\leq 0,

which implies

. This completes the proof.

∎

. Recall its statement as follows.

It is obvious that

\displaystyle\sum_{\ell^{1},\ldots,\ell^{c}\in S^{t}}2^{1-|P^{(t)}(\{\ell^{1},\ldots,\ell^{c}\})|}\leq c!\cdot\sum_{\ell^{1}\leq\ldots\leq\ell^{c}\in S^{t}}2^{1-|P^{(t)}(\{\ell^{1},\ldots,\ell^{c}\})|}.

(17)

Appendix B
c
-Connecting is Asymptotically Optimal

In this section, we show that the probability lower bound in Definition
1
is asymptotically optimal by proving the following claim.

Claim 4
.

For every constant
c\geq 2
, there is a constant
C_{c}\geq 1
satisfying the following. For all large enough
n,m\geq 1
such that
m\geq n^{2}
, suppose
{\mathcal{H}}
is a distribution over hash functions
h:[m]\to[n]
. Then there is an injective mapping
a:[n]\to[m]
and
c
vertices
1\leq u_{1}<\dots<u_{c}\leq[n]
such that

\displaystyle\Pr_{\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}[u_{i}\in\mathsf{Out}_{a,\mathbf{h}}(\mathbf{x}),\forall i\in[c]]\leq C_{c}\cdot n^{-c/2}.

(18)

Proof sketch.

Let
{\mathcal{H}}
be an arbitrary distribution over hash functions
h:[m]\to[n]
. Let
\mathcal{A}
denote the uniform distribution over all mappings from
[n]
to
[m]
. Consider sampling
\mathbf{a}\in\mathcal{A}
(Note that
\mathbf{a}
is not necessarily injective). For every fixed
h\in\supp({\mathcal{H}})
,
(h\circ\mathbf{a})
is a random mapping from
[n]
to
[n]
where
\Pr_{\mathbf{a}}[(h\circ\mathbf{a})(x)=y]=\frac{|h^{-1}(y)|}{m}
. By a birthday-paradox style argument, we have

\Ex_{\mathbf{a}\sim\mathcal{A},\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|\right]\leq O(\sqrt{n}).

In fact, with some extra effort, one can show that the distribution of
|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|
decays to
0
exponentially fast, and there is a constant
D_{c}\geq 1
(
D_{c}
depends on
c
) such that

\Ex_{\mathbf{a}\sim\mathcal{A},\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[\binom{|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|}{c}\right]\leq D_{c}n^{c/2}.

Let
A^{I}=\{a|a:[n]\to[m]\text{ is injective}\}
. By a simple union bound, we have
\Pr_{\mathbf{a}\sim\mathcal{A}}[\mathbf{a}\in A^{I}]\geq 1-\frac{1}{m}\binom{n}{2}\geq\frac{1}{2}
. Moreover, conditioning on
\mathbf{a}\in A^{I}

\mathbf{a}

\Ex_{\mathbf{a}\sim A^{I},\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[\binom{|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|}{c}\right]\leq\frac{1}{\Pr_{\mathbf{a}\sim\mathcal{A}}[\mathbf{a}\in A^{I}]}\cdot\Ex_{\mathbf{a}\sim\mathcal{A},\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[\binom{|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|}{c}\right]\leq 2D_{c}n^{c/2}.

We choose

. Suppose the theorem statement does not hold. Then:

\displaystyle\Ex_{\mathbf{a}\sim A^{I},\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[\binom{|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|}{c}\right]

\displaystyle=\Ex_{\mathbf{a}\sim A^{I}}\Ex_{\mathbf{h}\sim{\mathcal{H}},\mathbf{x}\sim[n]}\left[\binom{|\mathsf{Out}_{\mathbf{a},\mathbf{h}}(\mathbf{x})|}{c}\right]

\displaystyle\geq\Ex_{\mathbf{a}\sim A^{I}}\left(\binom{n}{c}\cdot C_{c}\cdot n^{-c/2}\right)

\displaystyle\geq\frac{C_{c}}{c!\cdot 2^{c}}\cdot n^{c/2}

\displaystyle\text{(Assume $n\geq 2c$)}

\displaystyle>2D_{c}n^{c/2}.

This leads to a contradiction. Therefore, there must be an injective mapping
a\in A^{I}
and
c
vertices
1\leq u_{1}<\dots<u_{c}\leq n
for which (
18
) holds.
∎
