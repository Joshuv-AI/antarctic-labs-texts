Object generators, categories, and everyday set theory
Frank Quinn

Abstract




1.
Introduction

In
Object generators, relaxed sets, and a foundation for mathematics
,
[
Q
]
, we introduced an axiomatic environment much more general than set theory. This contains a version of set theory that turns out to be the one implicitly used in mainstream mathematics for the last century. It is also a good setting for abstract category theory. This paper is a short user’s guide to the development.

One drawback of the general setting for everyday use is that it uses non-binary logic. In Section
2
we see that starting at a slightly higher level gives quick access to the set theory, with only standard binary logic. We illustrate its advantages by proving some of the axioms that have to be assumed in traditional approaches.

Next, it is well-known that the object known traditionally as the “universe”, “ordinal numbers” or “class of all sets” cannot itself be a set, but in traditional theories little else can be said about it. In Section
3
we describe some of the properties of the analogous object in relaxed set theory. It turns out that one reason it has remained so mysterious is that these properties cannot be formulated in standard binary logic. The work-arounds give concrete illustrations of the assertion logic needed for the full object-generator context.

Finally, in Section
4
, we show object-generator theory provides a good setting for categories. These have never fit well with traditional axiomatic set theories. Early material was robust enough that the mismatch could be ignored, but it is increasingly uncomfortabe with more subtle developments, eg. various kinds of higher-order categories. We illustrate the effectiveness of the new setting with a full-precision proof of the existence of skeleta, and its standard corollary that the category of small categories is ordinary.

2.
Everyday set theory

Most mathematicians use naïve set theory, with the admonition “don’t say ‘set of all sets’ ”. We trace the history in more detail elsewhere, but the short version is that naïve set theory was already being used successfully before Russell’s Paradox became widely known, in 1902. The paradox seriously disrupted the study of set theory, but had essentially no impact on mainstream practice. In fact, customary usage of naïve set theory has solidly supported mathematical development for more than a century. In this section we formulate relaxed set theory so it is essentially the same as naïve set theory. In a sense this “explains” why the naïve theory has been so successful.

The results used to illustrate the theory focus on a weakness of traditional axiomatic set theory: criteria for more-primitive objects to be sets.

2.1.
Primitive ingredients

Primitives are starting points for deductive developments. Since their properties cannot be deduced from lower-level material, success depends on technical consistency, and on them being understood and used in the same way by different users. Terminology here is intended to help with this.

Objects

The primitive objects here are “collection of elements”, and functions of these. As usual, a function
f\colon A\to B
assigns an element
f[x]\in B
to each
x\in A
. Technically these are the same as “object generator” and “morphism”, but different terms are used to indicate different usage. “Collections of elements” indicates immediate use of binary logic, instead of the assertion logic of the general theory.

Logic

We are concerned with binary functions, ie. functions to a collection with two elements, here denoted by
\textsf{y/n}:=\{\textsf{yes},\textsf{no}\}
. The native logic of the theory is the usual logic of binary functions induced by logical operations on
\{\textsf{yes},\textsf{no}\}
. It does not include either a general notion of equality or of quantification.

A notion of ‘sameness’ is used in §
2.2
(2). The precise version requires non-binary logic, so it is used informally here and clarified in specific cases. ‘Sameness’ could be avoided by more-systematic use of equivalence relations, but this is unnecessarily complicated and is not upward compatible.

Hypotheses

The primitive hypotheses are:

Two:

There is a collection of elements with exactly two elements;

Choice:

If
f\colon A\to B
is a surjective function (of collections of elements) then there is a function
s\colon B\to A
so that
f\circ s=\textsf{id}_{B}
;

Infinity:

The natural numbers support quantification; and

Quantification:

If a logical domain supports quantification, then so does its powerset.

The point of (3) is that the natural numbers can be constructed as a logical domain using Two and Choice, but we cannot show it supports quantification.

2.2.
Definitions

(1)

A
binary function
on a collection of elements is a function that has values in the two-element collection
y/n
.

(2)

A
logical domain
is a collection of elements with a binary pairing
D\times D\to\textsf{y/n}
that detects whether elements are the ‘same’ (see Note (1)) or not. Such pairings are denoted, as usual, by ‘=’, so
a=b
has value ‘yes’ if
a
and
b
are the same, and ‘no’ otherwise.

(3)

The
powerset
of a logical domain is the collection of all binary functions on it. Powersets are denoted
\textsf{P}[D]
.

(4)

A domain
D

supports quantification
if there is a binary function
\textsf{P}[D]\to\textsf{y/n}
that detects the empty (always ‘
no
’) function.

(5)

A (relaxed)
set
is a logical domain that supports quantification.

Notes

(1)

As explained above, use of term ‘same’ in (2) is imprecise at this stage, and the precise meaning will be made explicit on a case-by-case basis.

(2)

A binary function determines a subcollection, consisting of the elements on which the function has value ‘yes’. The traditional focus is on the subcollection, but here we often find it advantageous to emphasize the function. This requires some notation. For example, suppose
A
is a domain with a partial order
\leq\colon A\times A\to\textsf{y/n}
, and
a\in A
. Then
(\#<a)
is the function that returns ‘yes’ if
\#
is strictly smaller than
a
. Here
\#
is a dummy variable for elements of
A
, used to avoid having to introduce extra names. For instance “
(\#<a)[b]=(b<a)
” replaces the traditional “
f[b]
, where
f[x]:=(x<a)
”. Note the use of square brackets to denote function evaluation: if
f
is a function then
f[a]
denotes its value on
a
. This avoids confusion with grouping, and again avoids extra notation.

(3)

In standard notation the function
\textsf{P}[D]\to\textsf{y/n}
that detects the empty function is
f\mapsto(\forall x\in D,f[x]=\textsf{no})
. A point here is that if this one quantification expression is implemented by a binary function, then all quantification expressions over
D
are.

(4)

The Quantification Hypothesis asserts that first-order quantification implies infinite-order quantification. This is assumed here. Without this, things are more complicated and “sets” must be defined as domains that support infinite-order quantification. The appendix to
[
Q
]
explains why we feel this assumption is reasonable.

2.3.
Equivalence relations

This is a standard way to get sets from more-primitive data.

Recall that an equivalence relation on a collection of elements is a pairing
\simeq\colon A\times A\to\textsf{y/n}
that is symmetric (
x\simeq y)\Rightarrow(y\simeq x)
), transitive (
x\simeq y)\textsf{\,{and}\,}(y\simeq z)\Rightarrow(x\simeq z)
), and reflexive (
x\simeq x)
). Given this, define
equivalence classes
to be binary functions of the form
\#\mapsto(\#\simeq x)
for some
x\in A
. Denote the collection of equivalence classes by
A/\!\!\simeq
.
Define an equality pairing on
A/\!\!\simeq
as follows: if
f,g\colon A\to\textsf{y/n}
are equivalence classes, then there are
x,y\in A
with
f[\#]=(\#\simeq x)
and
g[\#]=(\#\simeq y)
. Then define
(f=g):=(x\simeq y)
. It is easy to check that this is independent of the choice of
x,y
, and
f\simeq g
implies these are the same as functions. Therefore:

Corollary
.

(A/\!\!\simeq,=)
is a logical domain.

For example (see §
4.2
) if
\mathcal{C}
is an ordinary catrgory then “is
x
isomorphic to
y
?” defines an equivalence relation on objects. This gives the collection of isomorphism classes of objects the structure of a logical domain.

2.4.
Unions

We begin with a general statement, then explain what it says about unions. This is Proposition 3.5 of
[
Q
]
:

Proposition

(Union lemma)
.

Suppose
A
is a collection of elements,
B
is a logical domain, and
f\colon A\to B
is a function onto
B
. Then
A
is a set if and only if
B
and each point-preimage
f^{-1}[b]
are sets.

Not only is this stronger than the Union axiom in, for instance Zermillo-Fraenkel-Choice set theory, but we are proving it rather than assuming it.

Proof

This expands the proof in
[
Q
]
. We begin with the “only if” direction, so suppose
A
is a set.
B
is assumed to be a logical domain, so we need to show that it supports quantification. Composition with
f
gives a function
\textsf{P}[B]\to\textsf{P}[A]
, and this is injective since
f
is assumed to be surjective. Composing with the empty-detecting function
\textsf{P}[A]\to\textsf{y/n}
therefore gives a function on
\textsf{P}[B]
that detects the empty function.

Next we show each
f^{-1}[p]
is a set. The logical-domain structure on
A
restricts to make
f^{-1}[p]
a logical domain. The function
c\colon A\to\textsf{y/n}
defined by
a\mapsto(f[a]=p)
, where “=” denotes the logical-domain structure of
B
, has support
f^{-1}[p]
. Now a function
\textsf{P}[f^{-1}[p]\to\textsf{P}[A]
is defined by
h\mapsto(c[\#]=\textsf{yes})\textsf{\,{and}\,}(h[\#]=\textsf{yes})
. It is easy to see that this is injective, so composing with the empty-detecting function on
\textsf{P}[A]
gives an empty-detecting function on
f^{-1}[p]
. This shows it is a set.

The “if” direction is the more useful one. Suppose
B
and the preimages are sets. The first step is to show
A
is a logical domain by exhibiting an equality pairing. Since
B
is a set there is an equality pairing
\stackrel{{\scriptstyle B}}{{=}}\colon B\times B\to\textsf{y/n}
. Similarly, for each
b\in B
there is an equality pairing
\stackrel{{\scriptstyle b}}{{=}}
on the preimage. The equality pairing on
A
is given by

(x\stackrel{{\scriptstyle A}}{{=}}y):=(f[x]\stackrel{{\scriptstyle B}}{{=}}f[y])\textsf{\,{and}\,}(x\stackrel{{\scriptstyle f[x]}}{{=}}y).

Finally we show
A
supports quantification. A binary function
h\colon A\to\textsf{y/n}
is empty if and only restrictions to
f^{-1}[\#]
are empty, for all
\#\in B
. The preimages are sets, so applying the empty-detecting functions on each of those gives a binary function on
B
that takes
b
to ‘yes’ if the restriction to

f^{-1}[b]
is empty. The original function is empty if and only if this function is identically ‘yes’, or equivalently if the negation is empty. Applying the empty-detecting function on
\textsf{P}[B]
therefore gives an empty-detecting function on
A
, as required.
∎

Unions

To relate this to unions, suppose we have a collection of sets, indexed by a set. Denote these by
A_{\#}
, defined for
\#\in B
. For example, if
S
is a set of objects in a category then
(x,y)\mapsto\textsf{morph}[x,y]
is a collection of sets indexed by
S\times S
.

Corollary
.

The disjoint union
\amalg_{\#\in B}A_{\#}
is a set.

Proof: The disjoint union is the collection of elements of the form
(b,a)
where
b\in B
and
a\in A_{b}
. Denote the disjoint union by
C
, then there is a function
C\to B
defined by
(b,a)\mapsto b
. Now apply the Proposition to conclude
C
is a set.∎

If the
A_{\#}
are all subsets of a logical domain (e.g ZFC sets are all subsets of its Universe) then we can take the internal union. But there is a function from the disjoint union onto an internal union so, by the Proposition above, the Corollary implies the same conclusion for internal unions.

2.5.
Products and functions

Suppose
A,B
are sets and
f\colon A\to B
is a surjective function. A
section
of
f
is a function
g\colon B\to A
such that
f\circ g=\textsf{id}
. Alternately, if we view the point-inverses
f^{-1}[b]
as a family of sets indexed by
B
, then the standard notation for the collection of all sections is the product
\prod_{b\in B}f^{-1}[b]
.

The sections can be identified with a subcollection of the powerset
\textsf{P}[A]
, namely the
h\colon A\to\textsf{y/n}
such that for each
b\in B
there is a unique
a\in f^{-1}[b]
with
h[a]=\textsf{yes}
. But
A
is a set, so
\textsf{P}[A]
is a set, and a subcollection of a set is a set. Therefore products of sets are sets.∎

Similarly, if
A,B
are sets then we denote the collection of all functions
A\to B
by
\textsf{fn}[A,B]
. This can be identified with a subcollection of the powerset
\textsf{P}[A\times B]
.

3.
Large domains

A logical domain is said to be
large
if it does not support quantification.
\mathbb{W}
is the logical domain whose elements are equivalence classes of well-ordered sets,
[
Q
]
, §4.3. This corresponds to the universe, or ordinal numbers, of a traditional axiomatic set theory and, consequently, is not a set. In relaxed set theory what goes wrong is that it does not support quantification, so is large in the sense above. Unlike traditional axiomatic set theory we can say quite a bit about it. Proofs are given in
[
Q
]
; here we focus on the non-binary logic in the statements.

3.1.
The universal almost well-order

The orders on its elements induce a linear order on
\mathbb{W}
. This cannot be a well-order because these require quantification, but it is an
almost
well-order in the sense that the orders induced on bounded subdomains are well-orders.

Lemma
.

Suppose
A\subset\mathbb{W}
is a subdomain.

(1)

A
is the support of a binary function in
\textsf{P}[\mathbb{W}]
;

(2)

A
is bounded if and only if it is a set (ie. supports quantification);

(3)

A
is cofinal if and only if it is order-isomorphic to
\mathbb{W}
; but

(4)

there is no binary function defined on
\textsf{P}[\mathbb{W}]
that detects which case occurs.

Item (1) is nontrivial, and is Proposition 5.5 in
[
Q
]
. In standard binary logic (2) and (3) are equivalent, being negations of each other. However, (4) shows that binary logic does not apply. It might be helpful to read (2) as “
A
is
known
to be bounded if and only if it is
known
to support quantification”. Trying to negate this gives only that nothing is
known
, which has no logical content.
We expand on (4). By (1), subdomains of
\mathbb{W}
correspond to elements of
\textsf{P}[\mathbb{W}]
. The bounded and cofinal elements are disjoint, and their union gives all of
\textsf{P}[\mathbb{W}]
. Nonetheless, there is no binary function on
\textsf{P}[\mathbb{W}]
that distinguishes the two cases.

3.2.
Equivalence to
\mathbb{W}

Proposition
.

For a logical domain
A
the following are equivalent:

(1)

There is a bijection
A\simeq\mathbb{W}
;

(2)

there is a function
A\to\mathbb{W}
with point preimages sets, and image cofinal in
\mathbb{W}
; and

(3)

there are injective (or surjective) functions
A\to\mathbb{W}
and
\mathbb{W}\to A
.

Again, these properties are not binary, so this should be read as “knowing one case applies implies knowing the others”. (3) follows from the Cantor-Bernstein theorem, see
[
Q
]
3.3. This theorem requires the injections to have binary image, but images in
\mathbb{W}
are known to be binary. The image of
\mathbb{W}\to A
is binary because the composition
\mathbb{W}\to A\to\mathbb{W}
identifies it as an image in
\mathbb{W}
. Applications, eg. to category theory, usually use case (2).

3.3.
Minimality

The “minimality” of
\mathbb{W}
mentioned above is:

Proposition
.

A logical domain
A
does
not
support quantification if and only if there is an injection
\mathbb{W}\to A
.

As above, both directions in this implication are assertions, and there is no binary function on domains that identifies which case applies. Injections
\mathbb{W}\to A
are obtained by recursion, and this gives no information about whether or not the image is binary. Comparing with the previous proposition we see that if there is an injection whose image is not binary then
A
cannot inject into
\mathbb{W}
.

4.
Categories

Here we illustrate the convenience of object-generator theory as a setting for categories. We give a formally-complete proof of the existence of skeleta, and apply this to show small categories have small functor categories. These results have been essentially known for more than fifty years, though earlier foundations were not sufficient for formally complete proofs.
We assume familiarity with §3, 4 of
[
Q
]

4.1.
Definition

A category
\mathcal{C}
in the terminology here is:

(1)

an object generator
\textsf{obj}_{\mathcal{C}}
;

(2)

for every pair
A,B{\in\in}\textsf{obj}_{\mathcal{C}}
a ‘morphism’ object generator
\textsf{morph}[A,B]

(3)

for every triple
A,B,C{\in\in}\textsf{obj}_{\mathcal{C}}
a ‘composition’ morphism
*\colon\textsf{morph}[A,B]\times\textsf{morph}[B,C]\to\textsf{morph}[A,C]
;

(4)

composition is associative: for every quadruple
A,B,C,D{\in\in}\textsf{obj}_{\mathcal{C}}
the two orders of composition give the same morphism

\textsf{morph}[A,B]\times\textsf{morph}[B,C]\times\textsf{morph}[C,D]\to\textsf{morph}[A,D];

(5)

for every object
A{\in\in}\mathcal{C}
there is an ‘identity’ morphism
\textsf{id}_{A}{\in\in}\textsf{morph}[A,A]
so that
f{\in\in}\textsf{morph}[A,B]
implies
\textsf{id}_{A}*f{\;!\!\!=\,}f{\;!\!\!=\,}f*\textsf{id}_{B}
.

The ‘
*
’ notation for composition reverses the usual order:
f*g=g\circ f
. We use it here because the expressions are slightly easier to write and parse.

Domain and range matching error

The composability criterion for morphisms is sometimes stated as: if
f\in\textsf{morph}[A,B],g\in\textsf{morph}[C,D]
, then they are composable if
B=C
. This assumes ‘
B=C
’ is a binary function that returns ‘yes’ if they are the same, ‘no’ otherwise. In other words this assumes the collection of objects is a logical domain. However this is rarely the case, so this formulation is generally unavailable. The statement is correct if the assertion form
B{\;!\!\!=\,}C
is used, but then it does not function as a test for composability.

Examples

Object generators and their morphisms form a category. Explicitly,
A{\in\in}\textsf{obj}_{\textsf{OG}}
means “
A
is an object generator”, and
F{\in\in}\textsf{morph}_{\textsf{OG}}[A,B]
means “
F
is a morphism of object generators
A\to B
”. Composition is composition of generator morphisms, and associativity is explained at the end of §3.2 in
[
Q
]
.

Sets and functions form a category denoted by
Set
.

Functors etc.

Functors, and natural transformations of functors are defined as usual (see
[
ML
]
, §I).
Categories and functors form a category.

4.2.
Isomorphism classes

A category is
ordinary
if the morphism generators are all sets. The category
OG
described above is not ordinary; the category of sets is ordinary.
In this section we see that isomorphism classes of objects in an ordinary category constitute a logical domain.

Isomorphism classes

Suppose
X,Y{{\in\in}}\mathcal{A}
are objects in a category. An
isomorphism
is, as usual, a morphism
i{\in\in}\textsf{morph}[X,Y]
such that there exists a morphism
j{\in\in}\textsf{morph}[Y,X]
so that the compositions
i*j
and
j*i
are identities. If
i
is an isomorphism then, again as usual, the inverse
j
is unique, and is also an isomorphism. Composition of isomorphisms give isomorphisms. The isomorphisms in a category thus define a subcategory, which we denote by
\textsf{iso}[\mathcal{A}]
.

If
\mathcal{A}
is an ordinary category then “is there an isomorphism
X\to Y
?” defines a binary function of
X,Y
. This gives an equivalence relation on objects, and the equivalence classes form a logical domain. We denote this by
\textsf{obj}\mathcal{A}/\textsf{iso}
. There is a quotient morphism (of object generators)
q\colon\textsf{obj}\mathcal{A}\to\textsf{obj}\mathcal{A}/\textsf{iso}
.

Since functors preserve identity morphisms, they also preserve isomorphisms. A functor
F\colon\mathcal{A}\to\mathcal{B}
therefore induces a function
F\colon\textsf{obj}\mathcal{A}/\textsf{iso}\to\textsf{obj}\mathcal{B}/\textsf{iso}
. In other words
\textsf{obj}\#/\textsf{iso}
is a functor, from ordinary categories and functors, to domains and functions.

4.3.
Skeleta

A category
\mathcal{S}
is
skeletal
if the objects
\textsf{obj}\mathcal{S}
constitute a logical domain and isomorphic objects are equal.
This is equivalent to: the quotient function, from objects to isomorphism classes, is a bijection.

A
skeleton
of a category
\mathcal{A}
is a skeletal category and a functor
s\colon\mathcal{S}\to\mathcal{A}
that induces a bijection on isomorphism classes of objects, and is a bijection on morphism sets.

Theorem
.

(Existence of skeleta)

(1)

Every ordinary category has a skeleton;

(2)

the inclusion of a skeleton is an equivalence of categories. More precisely, if
s\colon\mathcal{S}\to\mathcal{A}
is the inclusion of a skeleton then there is a functor
q\colon\mathcal{A}\to\mathcal{S}
so that
q\circ s
is the identity of
\mathcal{S}
and
s\circ q
is naturally equivalent to the identity of
\mathcal{A}
.

Corollary
.

(Uniqueness) If
s_{n}\colon\mathcal{S}_{n}\to\mathcal{A}
for
n=1,2
are skeleta, then there is an isomorphism of categories
T\colon\mathcal{S}_{1}\to\mathcal{S}_{2}
so that
s_{2}\circ T
is naturally equivalent to
s_{1}
.

For the Corollary, let
q_{2}\colon\mathcal{A}\to\mathcal{S}_{2}
be the natural inverse in item (2) of the proposition. Then
T=p_{2}\circ s_{1}
is the desired isomorphism.∎

The proof of the Proposition is routine, modulo use of the strong form of ‘Choice’. We give details to illustrate this.

For the first step note that the quotient
q\colon\textsf{obj}\mathcal{(}A)\to\textsf{obj}\mathcal{(}A)/\textsf{iso}
is known to be a surjective morphism of generators. Choice therefore asserts that there is a section,
h\colon\textsf{obj}\mathcal{(}A)/\textsf{iso}\to\textsf{obj}\mathcal{(}A)
. Define a category
\mathcal{S}
with objects the equivalence classes
\textsf{obj}\mathcal{(}A)/\textsf{iso}
and morphisms
\textsf{morph}_{\mathcal{S}}[x,y]:=\textsf{morph}_{\mathcal{A}}[h[x],h[y]]
. It should be clear that
\mathcal{S}
is skeletal. We get a functor
s\colon\mathcal{S}\to\mathcal{A}
by the section
h
on objects, and the identity on morphisms. It should be clear that this is a skeleton.

The next step is to extend the quotient function
p\colon\textsf{obj}\mathcal{(}A)\to\textsf{obj}\mathcal{(}A)/\textsf{iso}=\textsf{obj}\mathcal{(}S)
to a functor.
To begin, consider the object generator with objects
(a,\theta)
, where
a
is an object in
\mathcal{(}A)
and
\theta
is an isomorphism
a\simeq h[q[a]]
. The forgetful morphism from this to
\textsf{obj}\mathcal{(}A)
is onto, so again we can chose a section. Denote this by
a\mapsto(a,\theta_{1}[a])
. We tidy this up a bit. Define
\theta_{2}
by

\textstyle{a\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\theta[a]}
\textstyle{h[a]\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\theta[h[a]]^{-1}}
\textstyle{h[a].}

Then
\theta_{2}
has the benefit that it takes an image object
h[b]
to
(h[b],\textsf{id})
. Note that we cannot get
\theta_{2}
by saying “for objects in the image of
h
, define
\theta_{2}[h[a]]:=(h[a],\textsf{id})
and extend randomly to other objects”. For this to be valid we would need a binary function on
\textsf{obj}\mathcal{(}A)
that detects the image of
h
, and there is generally no such function.

Now extend
q
to morphisms by: for
f\colon a\to b
,
q[f]
is the composition

\textstyle{h[q[a]]\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\hskip 8.19447pt\theta_{2}[a]^{-1}}
\textstyle{a\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{f}
\textstyle{b\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\theta_{2}[b]\hskip 8.19447pt}
\textstyle{h[q[b]]}

Recall that this is a morphism in
\mathcal{S}
because
h
is the identity on morphisms.

The proof is completed by observing that
q
is a functor;
q\circ h=\textsf{id}[\mathcal{S}]
; and
\theta_{2}
is a natural equivalence
h\circ q\simeq\textsf{id}[\mathcal{A}]
. ∎

4.4.
Functor categories

The goal of this section is to verify the standard proof that the category of small categories is ordinary.

Proposition
.

suppose
\mathcal{A}
is small. Then

(1)

if
\mathcal{B}
is small then so is the functor category
\textsf{funct}[\mathcal{A},\mathcal{B}]
; and

(2)

if
\textsf{obj}[\mathcal{B}/\textsf{iso}
injects into
\mathbb{W}
then the same is true for the functor category.

The part of (2) not covered by (1) is if
\textsf{obj}\mathcal{B}/\textsf{iso}
is bijective with
\mathbb{W}
. In this case the functor category can be either small or large, but no larger than
WW
. We don’t actually know if there are logical domains larger than
\mathbb{W}
; if not then (2) gives no information. As usual there is no binary function that detects which possibility occurs.

Functors are the objects of the functor category, and natural equivalences are the isomorphisms. Thus we want to show that natural equivalence classes of functors has the size indicated. Compositions with equivalences induce equivalence of functor categories. Existence of skeleta therefore reduces the problem to skeletal categories.

Suppose
\mathcal{K}
is ordinary and skeletal. Let
\textsf{morph}[\mathcal{K}]
denote the union of
\textsf{morph}_{\mathcal{K}}[A,B]
over all pairs of objects
A,B\in\textsf{obj}[\mathcal{K}]
. There is a projection
\textsf{morph}[\mathcal{K}]\to\textsf{obj}[\mathcal{K}]\times\textsf{obj}[\mathcal{K}]
and, because
\mathcal{K}
is ordinary, point preimages are sets. The Union lemma show the union has the same size as the objects:
If
\mathcal{K}
is small then
\textsf{morph}[\mathcal{K}]
is small,
if
\mathcal{K}
is big, then
\textsf{morph}[\mathcal{K}]
is big.

We can now complete the proof of the proposition. Suppose
\mathcal{A},\mathcal{B}
are skeletal, with
\mathcal{A}
small. Then a functor induces a function of total morphism domains
\textsf{morph}[\mathcal{A}]\to\textsf{morph}[\mathcal{B}]
, and is determined by this. Therefore the functors
\textsf{funct}[\mathcal{A},\mathcal{B}]
are a subset of all functions
\textsf{fn}[\textsf{morph}[\mathcal{A}],\textsf{morph}[\mathcal{B}]]
.
If
\mathcal{B}
is small then both morphism domains are sets, the functions are a set, and the functors are also a set. This completes case (1).

If
\textsf{obj}[\mathcal{B}]/\textsf{iso}
is bijective to
\mathbb{W}
then so is
\textsf{morph}[\mathcal{B}]
, and so is the function domain

\textsf{fn}[\textsf{morph}[\mathcal{A}],\textsf{morph}[\mathcal{B}]]
. The functors are thus a subdomain of something bijective to
\mathbb{W}
so either small or bijective to
\mathbb{W}
. ∎
