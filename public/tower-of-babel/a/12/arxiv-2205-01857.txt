Monomial Operators
Jim Agler, John E. M c Carthy

Abstract
We study monomial operators on L 2 ​ [ 0 , 1 ] L^{2}[0,1] , that is bounded linear operators that map each monomial x n x^{n} to a multiple of x p n x^{p_{n}} for some p n p_{n} . We show that they are all unitarily equivalent to weighted composition operators on a Hardy space. We characterize what sequences p n p_{n} can arise. In the case that p n p_{n} is a fixed translation of n n , we give a criterion for boundedness of the operator.



1
Introduction

When studying polynomial approximation in
L^{2}[0,1]
, the following class of operators arises naturally.

Definition 1.1
.

A
monomial operator
is a bounded linear operator
T:L^{2}[0,1]\to L^{2}[0,1]
with the property that there exist constants
c_{n}
and
p_{n}
so that

T:x^{n}\mapsto c_{n}\,x^{p_{n}}\qquad\forall n\in{\mathbb{N}}.

(1.2)

If, in addition, there is some
\tau
so that
p_{n}=n+\tau
for every
n
, we call it
a
flat monomial operator
.

The powers
p_{n}
may be complex, but must lie in the half plane

{\mathbb{S}}:=\{s\in\mathbb{C}:\re(s)>-\frac{1}{2}\},

in order for
x^{p_{n}}
to lie in
L^{2}
.
Well-known examples of monomial operators include the
Hardy operator
H

\displaystyle H:f

\displaystyle\mapsto

\displaystyle\frac{1}{x}\int_{0}^{x}f(t)dt

\displaystyle Hx^{n}

\displaystyle=

\displaystyle\frac{1}{n+1}x^{n};

the operator
M_{x}
of multiplication by
x
; and the Volterra operator

\displaystyle V=M_{x}H:f

\displaystyle\mapsto

\displaystyle\int_{0}^{x}f(t)dt

\displaystyle Vx^{n}

\displaystyle=

\displaystyle\frac{1}{n+1}x^{n+1}.

In
[
2
]
the authors studied flat monomial operators, and showed that they all
leave invariant every subspace of the form

\{f\in L^{2}[0,1]:f=0{\rm\ on\ }[0,t]\}.

It was shown independently by Brodskii
[
6
]
and Donoghue
[
10
]
that these subspaces
are exactly the invariant subspaces for the Volterra operator.

It is the purpose of this note to examine general monomial operators of the form (
1.2
).
To describe them, it is convenient to introduce a Hardy space associated with
{\mathbb{S}}
.
The Hardy space of the unit disk, which we denote
H^{2}(\mathbb{D})
, is the Hilbert space of holomorphic functions on

\mathbb{D}
with finite norm, where the norm is given by

\|\phi\|^{2}_{H^{2}(\mathbb{D})}\ =\ \sup_{0<r<1}\frac{1}{2\pi}\int_{0}^{2\pi}|\phi(re^{i\theta})|^{2}d\theta.

There are two distinct definitions for the Hardy space of a half-plane. Let
\lambda
be the linear fractional transformation
give by

\lambda(s)=\frac{s}{s+1},

(1.3)

that takes
{\mathbb{S}}
onto
\mathbb{D}
.

Definition 1.4
.

By
H^{2}({\mathbb{S}})
we mean
\{\phi\circ\lambda:\phi\in H^{2}(\mathbb{D})\}
, and the norm is defined so
that
\phi\mapsto\phi\circ\lambda
is unitary.

An equivalent definition of
H^{2}({\mathbb{S}})
is the set of functions
f
that are holomorphic in
{\mathbb{S}}
and such that

|f|^{2}
has a harmonic majorant there. The norm squared is equal to the value of this harmonic majorant at
0
.
If
f\in H^{2}({\mathbb{S}})
, then it has boundary values a.e. (see e.g.
[
11
]
), and the norm is given by

\|f\|^{2}\ =\ \frac{1}{2\pi}\int_{-\infty}^{\infty}\frac{|f(-\frac{1}{2}+it)|^{2}}{t^{2}+\frac{1}{4}}dt.

(1.5)

The reproducing kernel for
H^{2}({\mathbb{S}})
is given by

k(s,u)\ =\ \langle k_{u},k_{s}\rangle\ =\ \frac{(1+s)(1+\bar{u})}{1+s+\bar{u}}.

(1.6)

In light of (
1.6
), the map

\displaystyle U:L^{2}[0,1]

\displaystyle\to

\displaystyle H^{2}({\mathbb{S}})

\displaystyle x^{s}

\displaystyle\mapsto

\displaystyle\frac{1}{1+s}k_{\bar{s}}

extends to a unitary from
L^{2}[0,1]
onto
H^{2}({\mathbb{S}})
.
In
[
1
]
we show that for any
f\in L^{2}
, we have

Uf(s)=(1+s)\int_{0}^{1}f(x)x^{s}dx.

If
T
is a monomial operator, we shall
define

\widehat{T}\ =\ UTU^{*}:H^{2}({\mathbb{S}})\to H^{2}({\mathbb{S}}).

(1.7)

One might wonder whether the definition of monomial operator should require that it take
x^{s}
to some multiple of a monomial for every
s\in{\mathbb{S}}
; our first theorem asserts that this always happens, just by assuming it on the natural numbers.
It also shows that, after moving to the Hardy space as in (
1.7
), monomial operators correspond to the adjoints of weighted composition operators.

If
g
is a holomorphic function on some domain, let us define

g^{\cup}(s)\ =\ \overline{g(\overline{s})}.

By (
1.5
) we see that if
f\in H^{2}({\mathbb{S}})
, then
\|f^{\cup}\|_{H^{2}({\mathbb{S}})}=\|f\|_{H^{2}({\mathbb{S}})}
.

Theorem 1.8
.

Let
T:L^{2}[0,1]\to L^{2}[0,1]
be a monomial operator given by (
1.2
).
Then there exists a holomorphic map
\beta:{\mathbb{S}}\to{\mathbb{S}}
and a function
g\in H^{2}({\mathbb{S}})
so
that, for every
s\in{\mathbb{S}}
, we have

T(x^{s})\ =\ \frac{1+\beta(s)}{1+s}g(s)\ x^{\beta(s)}.

(1.9)

Moreover, we have

\widehat{T}^{*}f(s)\ =\ g^{\cup}(s)f(\beta^{\cup}(s))\qquad\forall f\in H^{2}({\mathbb{S}}).

(1.10)

Equation (
1.10
) says

\widehat{T}^{*}\ =\ M_{g^{\cup}}C_{\beta^{\cup}},

where
C_{\beta}
denotes the composition operator
f\mapsto f\circ\beta
, and
M_{g}
denotes the multiplication
operator
f\mapsto gf
.

Weighted composition operators have been studied for some time. See
e.g.
[
12
,
8
,
15
,
9
,
5
,
4
,
7
]
.
By Littlewood’s subordination principle, the operator
C_{\beta}
is always bounded whenever
\beta
is a holomorphic self-map of
{\mathbb{S}}

[
16
, Thm. 10.4.2]
. A multiplication operator
M_{h}
is bounded if and only if
h\in H^{\infty}({\mathbb{S}})
.
It was observed in
[
14
]
that
it is possible
for the product
M_{h}C_{\beta}
to be bounded even when
M_{h}
is not.

A consequence of Theorem
1.8

is that it allows us to specify what sequences
p_{n}
can occur in (
1.2
).

Corollary 1.11
.

Let
(p_{n})
be a sequence in
{\mathbb{S}}
. Then there exists some choice of scalars
c_{n}
, not all zero, so that

T:x^{n}\mapsto c_{n}x^{p_{n}}
extends to be a bounded linear operator on
L^{2}[0,1]
if and only if

\left[\frac{p_{m}+\overline{p_{n}}+1}{m+n+1}\right]\ \geq\ 0.

In Section
3
we study which pairs of functions
\beta
and
g

give rise to a bounded operator in (
1.9
).
We answer this question only for flat monomial operators, i.e. when
\beta(s)=s+\tau
for some constant
\tau
. If
\Re(\tau)<0
, it follows from Corollary
1.11
that such a
T
can never be bounded.

If
\Re(\tau)\geq 0
, we have:

Theorem 1.12
.

Let
\Re(\tau)\geq 0
, and let
T
be defined by

T(x^{n})\ =\ \frac{1+n+\tau}{1+n}g(n)\ x^{n+\tau}

for some function
g\in H^{2}({\mathbb{S}})
.

(i) If
\Re(\tau)>0
, then

T
extends to be a bounded linear operator from
L^{2}[0,1]
to
L^{2}[0,1]

if and only if
the Poisson integral of
|g|^{2}
is bounded on
all half-planes that are strictly contained in
{\mathbb{S}}
.

(ii) If
\Re(\tau)=0
, then
T
is bounded if and only if
g
is bounded on
{\mathbb{S}}
.

This theorem is proved in Theorems
3.3
and
3.6
.

Proof of Theorem
1.8

Proof of Theorem
1.8
.

Step 1. Let
\widehat{T}
be given by (
1.7
).
Define
g
by
g^{\cup}=\widehat{T}^{*}1
.
We have

\displaystyle\widehat{T}k_{n}

\displaystyle\ =\

\displaystyle UT(1+n)x^{n}

\displaystyle=

\displaystyle(1+n)Uc_{n}x^{p_{n}}

\displaystyle=

\displaystyle c_{n}\frac{1+n}{1+p_{n}}k_{\overline{p_{n}}}.

Since
k_{0}=1
, we have

\displaystyle\langle g^{\cup},k_{n}\rangle

\displaystyle\ =\

\displaystyle\langle 1,c_{n}\frac{1+n}{1+p_{n}}k_{\overline{p_{n}}}\rangle

\displaystyle=

\displaystyle\overline{c_{n}}\frac{1+n}{1+\overline{p_{n}}}.

This gives

g(n)\ =\ c_{n}\frac{1+n}{1+p_{n}},

and so we can write

\widehat{T}k_{n}\ =\ g(n)k_{\overline{p_{n}}}.

(2.1)

For any
u\in{\mathbb{S}}
, let
h_{u}=\widehat{T}^{*}k_{u}
.
We get from (
2.1
)

\displaystyle\langle h_{u},k_{n}\rangle

\displaystyle\ =\

\displaystyle g^{\cup}(n)\langle k_{u},k_{\overline{p_{n}}}\rangle

\displaystyle\Rightarrow\quad h_{u}(n)

\displaystyle=

\displaystyle g^{\cup}(n)\frac{(1+\bar{u})(1+\overline{p_{n}})}{1+\bar{u}+\overline{p_{n}}}

(2.2)

\displaystyle\Rightarrow\quad h_{u}^{\cup}(n)

\displaystyle\ =\

\displaystyle g(n)\frac{(1+u)(1+{p_{n}})}{1+u+{p_{n}}}.

(2.3)

Define
\beta
by

\beta(s)\ =\ \frac{(1+u)(h_{u}^{\cup}(s)-g(s))}{(1+u)g(s)-h_{u}^{\cup}(s)}.

(2.4)

As
g
and
h_{u}
are both in the Hardy space
H^{2}({\mathbb{S}})
, a priori we know that
\beta
is in the
Nevanlinna class of meromorphic functions on
{\mathbb{S}}
, the class of quotients of
H^{2}
functions.
Moreover, it follows from (
2.3
) that

p_{n}\ =\ \frac{(1+u)(h_{u}^{\cup}(n)-g(n))}{(1+u)g(n)-h_{u}^{\cup}(n)}\ =\ \beta(n).

Observe that
{\mathbb{N}}
is not a zero set for
H^{2}({\mathbb{S}})
—indeed,
(\lambda(n)=\frac{n}{n+1})
is not a Blaschke sequence for
H^{2}(\mathbb{D})
. Therefore it is a set of uniqueness for the Nevanlinna class, and hence

\beta
is the unique function in the class that satisfies
\beta(n)=p_{n}
.
In particular, the definition (
2.4
) is actually independent of
u
.

We can write (
2.2
) as

(\widehat{T}^{*}k_{u})(n)\ =\ g^{\cup}(n)k_{u}(\beta^{\cup}(n))\qquad\forall n\in{\mathbb{N}}.

(2.5)

Since
{\mathbb{N}}
is a set of uniqueness, (
2.5
) holds everywhere

(\widehat{T}^{*}k_{u})(s)\ =\ g^{\cup}(s)k_{u}(\beta^{\cup}(s))\qquad\forall s\in{\mathbb{S}}.

(2.6)

Step 2. We must show that
\beta:{\mathbb{S}}\to{\mathbb{S}}
.
Suppose there is some point
s\in{\mathbb{S}}
where
g(s)\neq 0
and
\beta^{\cup}(s)=w
is in
\mathbb{C}\setminus{\mathbb{S}}
.
Then there is a sequence
q_{n}
such that each
q_{n}
is a finite linear combination of kernel functions,

\|q_{n}\|\leq 1
, and
q_{n}(w)\to\infty
. By (
2.6
), we have

(\widehat{T}^{*}q_{n})(s)\ =\ g^{\cup}(s)q_{n}(w).

(2.7)

The right-hand side of (
2.7
) tends to infinity, the left-hand side is bounded by
\|T\|\|k_{s}\|
, a contradiction.
Since
\beta^{\cup}
is meromorphic, we conclude that whenever
g^{\cup}(s)\neq 0
then
\beta(s)\in{\mathbb{S}}
.
Therefore any singularities of
\beta^{\cup}
on the zero set of
g^{\cup}
are removable, so we conclude that
\beta^{\cup}
,
and hence also
\beta
, is a self-map of
{\mathbb{S}}
.

Thus we have proved (
1.10
) for any finite linear combination of kernel functions, and so,
by a limiting argument, it is true for all
f\in H^{2}({\mathbb{S}})
.

Step 3. From (
2.6
), we have

\displaystyle\langle\widehat{T}k_{s},k_{u}\rangle

\displaystyle=

\displaystyle\overline{\langle\widehat{T}^{*}k_{u},k_{s}\rangle}

\displaystyle\ =\

\displaystyle g(\bar{s})\overline{k_{u}(\beta^{\cup}(s))}

\displaystyle=

\displaystyle g(\bar{s})\frac{(1+u)(1+\beta(\bar{s}))}{1+u+\beta(\bar{s}))}

\displaystyle=

\displaystyle g(\bar{s})k_{\beta^{\cup}(s)}(u).

So

\widehat{T}k_{s}\ =\ g(\bar{s})k_{\beta^{\cup}(s)}.

(2.8)

Therefore

\displaystyle Tx^{s}

\displaystyle\ =\

\displaystyle U^{*}\widehat{T}U[x^{s}]

\displaystyle=

\displaystyle U^{*}\widehat{T}[\frac{1}{1+s}k_{\bar{s}}]

\displaystyle=

\displaystyle U^{*}[\frac{1}{1+s}g(s)k_{\overline{\beta(s)}}]

\displaystyle=

\displaystyle\frac{1+\beta(s)}{1+s}g(s)x^{\beta(s)}.

This proves (
1.9
).

Proof of Corollary
1.11
.

By Theorem
1.8
, a necessary condition for the
existence of a non-zero bounded
T
that maps each
x^{n}
to a multiple of
x^{p_{n}}
is that there be some
holomorphic self-map
\beta
of
{\mathbb{S}}
that maps
n
to
p_{n}
. This condition is also sufficient, since
choosing

c_{n}\ =\ \frac{1+p_{n}}{1+n}

gives
UTU^{*}
is the adjoint of
C_{\beta^{\cup}}
, which is bounded.

When is there a map
\beta:{\mathbb{S}}\to{\mathbb{S}}
that interpolates
n
to
p_{n}
?
Composing with the Riemann map
\lambda
from (
1.3
), this is equivalent to asking when
there exists
\phi=\lambda\beta\lambda^{-1}
from
\mathbb{D}
to
\mathbb{D}
that maps
\frac{n}{n+1}
to

\frac{p_{n}}{p_{n}+1}
.
By Pick’s theorem
[
3
, Thm. 1.81]
, this occurs if and only if

\left[\frac{1-\frac{p_{m}}{p_{m}+1}\frac{\overline{p_{n}}}{\overline{p_{n}}+1}}{1-\frac{m}{m+1}\frac{\bar{n}}{\bar{n}+1}}\right]\ \geq\ 0.

(2.9)

Rearranging (
2.9
), we get

\left[\frac{m+1}{p_{m}+1}\frac{\bar{n}+1}{\overline{p_{n}}+1}\frac{p_{m}+\overline{p_{n}}+1}{m+\bar{n}+1}\right]\ \geq\ 0.

As conjugating by the rank one operator

\left[\frac{m+1}{p_{m}+1}\frac{\bar{n}+1}{\overline{p_{n}}+1}\right]

does not affect positivity, and
n=\bar{n}
, we get that an interpolating
\beta
exists if and only if

\left[\frac{p_{m}+\overline{p_{n}}+1}{m+n+1}\right]\ \geq\ 0.

\Box

3
Flat Monomial Operators

In this section, we shall consider operators of the form

T:x^{n}\mapsto c_{n}x^{n+\tau},

(3.1)

and in particular when they are bounded.
Note first that if
\tau=\tau_{0}+i\tau_{1}
, with
\tau_{0}
and
\tau_{1}
real, then the effect of
\tau_{1}
is to multiply everything in the range by
x^{i\tau_{1}}
, which is unimodular. So without loss of generality we can assume that
\tau
is real. Moreover, by Corollary
1.11
,
T
can only be bounded if
\tau\geq 0
.

Let us first handle the case
\tau=0
. In the terminology of Theorem
1.8
,
\beta(s)=s
, so
T
is bounded if and only if there is a bounded function
g
on
{\mathbb{S}}
that satisfies
g(n)=c_{n}
.
By Pick’s theorem, this happens if and only if

\left[\frac{1-c_{m}\overline{c_{n}}}{1+m+n}\right]\ \geq\ 0.

(3.2)

So we get:

Theorem 3.3
.

The map
T:x^{n}\mapsto c_{n}x^{n}
extends to be a bounded linear map if and only if (
3.2
) holds.
Moreover, if it is non-zero, it is never compact.

When
\tau>0
, how do we determine whether (
3.1
) extends to be bounded?
Let

\gamma(s)\ =\ s+\tau.

(3.4)

We must find
g\in H^{2}({\mathbb{S}})
that satisfies

g(n)\ =\ \overline{c_{n}}\ \frac{1+n}{1+n+\tau}.

Then
T
is bounded if and only if
M_{g}C_{\gamma}
is bounded.
(We have changed notation slightly from Theorem
1.8
to avoid the use of
g^{\cup}
and
to emphasize that we have a fixed choice of
\beta
).
To investigate
M_{g}C_{\gamma}
, we turn to the Poisson kernel.

The Poisson kernel for
{\mathbb{S}}
at a point
s=-\frac{1}{2}+\sigma+it
is given by

P_{-\frac{1}{2}+\sigma+it}(-\frac{1}{2}+iy)\ =\ \frac{1}{\pi}\frac{\sigma}{\sigma^{2}+(y-t)^{2}}.

The Poisson integral of some function
f
defined on the line
\{\Re(s)=-\frac{1}{2}\}
is given by

P[f](-\frac{1}{2}+\sigma+it)\ =\ \frac{1}{\pi}\int_{-\infty}^{\infty}\frac{\sigma}{\sigma^{2}+(y-t)^{2}}f(-\frac{1}{2}+iy)dy

It is convenient to introduce another Hardy space,
{\mathcal{H}}^{2}({{\mathbb{S}}})
.

Definition 3.5
.

The space
{\mathcal{H}}^{2}({{\mathbb{S}}})
consists of all functions
f
that are holomorphic in
{\mathbb{S}}
and satisfy

\sup_{x>-\frac{1}{2}}\int_{-\infty}^{\infty}|f(x+iy)|^{2}dy<\infty.

Every function
f\in{\mathcal{H}}^{2}({{\mathbb{S}}})
has non-tangential boundary limits almost everywhere, and its norm is then
given by (see
[
13
]
):

\|f\|^{2}_{{\mathcal{H}}^{2}({{\mathbb{S}}})}\ =\ \int_{-\infty}^{\infty}|f(-\frac{1}{2}+iy)|^{2}dy.

Let us write

{\mathbb{H}}_{\rho}:=\{s\in\mathbb{C}:\Re(s)>\rho\}.

So
{\mathbb{S}}={\mathbb{H}}_{\frac{1}{2}}
in this notation.

Theorem 3.6
.

The operator
M_{g}C_{\gamma}
is bounded if and only if the Poisson integral of
|g|^{2}

is bounded on some (and hence every) half-plane
{\mathbb{H}}_{\rho}
for
\rho>-\frac{1}{2}
.

Proof of Thm.
3.6
.

The map

W:f(s)\mapsto\frac{1}{\sqrt{2\pi}}\frac{1}{s+1}f(s)

is a unitary from
H^{2}({\mathbb{S}})
onto
{\mathcal{H}}^{2}({{\mathbb{S}}})
. One checks

WM_{g}C_{\gamma}W^{*}\ =\ M_{\frac{s+\tau+1}{s+1}g(s)}C_{\gamma}.

(3.7)

For
s
in
{\mathbb{S}}
we have

1\leq|\frac{s+\tau+1}{s+1}|\leq 1+2\tau,

so for boundedness purposes we can drop this factor in (
3.7
) and conclude
that
M_{g}C_{\gamma}
is bounded on
H^{2}({\mathbb{S}})
if and only if it is bounded on
{\mathcal{H}}^{2}({{\mathbb{S}}})
.
Thus we wish to know for which
g
does

\int_{-\infty}^{\infty}|g(-\frac{1}{2}+iy)|^{2}|f(-\frac{1}{2}+\tau+iy)|^{2}dy\ \lesssim\ \int_{-\infty}^{\infty}|f(-\frac{1}{2}+iy)|^{2}dy

hold?
This is the same as asking when integrating along the vertical line
\{\Re(s)=-\frac{1}{2}+\tau\}

with weight
|g(-\frac{1}{2}+iy)|^{2}
is a Carleson measure for
{\mathcal{H}}^{2}({{\mathbb{S}}})
.
By
[
13
, VI.3]
, this happens if and only if

\sup_{\sigma>0,t\in\mathbb{R}}\int_{-\infty}^{\infty}\frac{\sigma}{(\tau+\sigma)^{2}+(y-t)^{2}}|g(-\frac{1}{2}+iy)|^{2}dy\ =C\ <\ \infty.

(3.8)

Taking
\sigma=\tau
in (
3.8
), we get that
M_{g}C_{\gamma}
is bounded implies

\sup_{t\in\mathbb{R}}\int_{-\infty}^{\infty}\frac{\tau}{(2\tau)^{2}+(y-t)^{2}}|g(-\frac{1}{2}+iy)|^{2}dy\ \leq\ K,

for some constant
K
,
so

\sup_{t\in\mathbb{R}}\int_{-\infty}^{\infty}\frac{\tau}{(\tau)^{2}+(y-t)^{2}}|g(-\frac{1}{2}+iy)|^{2}dy\ \leq\ 4K.

If
u=-\frac{1}{2}+\tau+\sigma+it
is any point in the half-plane
{\mathbb{H}}_{-\frac{1}{2}+\tau}
,
we have

P_{u}(-\frac{1}{2}+iy)\ =\ \frac{1}{\pi}\frac{\sigma+\tau}{(\sigma+\tau)^{2}+(y-t)^{2}}.

As

\frac{\sigma+\tau}{(\tau+\sigma)^{2}+(y-t)^{2}}\ \leq\frac{\sigma}{(\tau+\sigma)^{2}+(y-t)^{2}}+\frac{\tau}{(\tau)^{2}+(y-t)^{2}},

we conclude that (
3.8
) implies that the Poisson integral of
|g|^{2}
is bounded on

{\mathbb{H}}_{-\frac{1}{2}+\tau}
.
Conversely, the boundedness of
the Poisson integral of
|g|^{2}
on
{\mathbb{H}}_{-\frac{1}{2}+\tau}
implies (
3.8
).

Finally, to see that boundedness of the Poisson integral of
|g|^{2}
on
{\mathbb{H}}_{-\frac{1}{2}+\sigma}

implies boundedness on
{\mathbb{H}}_{-\frac{1}{2}+\rho}
for any
0<\rho<\sigma
,
we just observe that

\frac{1}{\pi}\frac{\rho}{\rho^{2}+(y-t)^{2}}\ \leq\ (\frac{\sigma^{2}}{\rho^{2}})\frac{1}{\pi}\frac{\sigma}{\sigma^{2}+(y-t)^{2}}.

\Box

Example 3.9

Let
\tau>0
, and take
g(s)=\frac{1}{(1+s)(s+\frac{1}{2})^{c}}
for some
0<c<\frac{1}{2}
.
Then
g
is not bounded on
{\mathbb{S}}
, so
M_{g}
is not bounded.
But

\displaystyle P[|g|^{2}](-\frac{1}{2}+\sigma+it)

\displaystyle\ =\

\displaystyle\frac{1}{\pi}\int_{-\infty}^{\infty}\frac{\sigma}{\sigma^{2}+(y-t)^{2}}\frac{1}{|y|^{2c}}\frac{1}{\frac{1}{4}+y^{2}}dy

\displaystyle\leq

\displaystyle\frac{1}{\pi\sigma}\int_{-\infty}^{\infty}\frac{1}{|y|^{2c}}\frac{1}{\frac{1}{4}+y^{2}}dy

\displaystyle\frac{1}{\pi\sigma}\left[\frac{8}{1-2c}+2\pi\right]

{\mathbb{H}}_{\rho}
, so by Theorem
3.6

M_{g}C_{\gamma}
is bounded.

4
Unitary Monomial Operators

Bourdon and Narayan characterized unitary weighted composition operators
[
5
]
.
Their theorem (translated to
{\mathbb{S}}
) is:

Theorem 4.1
.

(Bourdon-Narayan)
The operator
M_{g}C_{\beta}
is unitary on
H^{2}({\mathbb{S}})
if and only if

\beta
is an automorphism of
{\mathbb{S}}
and
g(s)=e^{i\theta}k_{s_{0}}/\|k_{s_{0}}\|
,
where
s_{0}=\beta^{-1}(0)
.

We shall give a proof of their theorem directly in the context of monomial operators.
First, let us describe the automorphisms of
{\mathbb{S}}
in a convenient way.

Lemma 4.2
.

The function
\beta:{\mathbb{S}}\to\mathbb{C}
is an automorphism of
{\mathbb{S}}
if and only if there is a function
\phi:{\mathbb{S}}\to\mathbb{C}
so that

\frac{1+\beta(s)+\overline{\beta(t)}}{1+s+\overline{t}}\ =\ \phi(s)\overline{\phi(t)}.

(4.3)

Proof:
Notice that
\beta
is an automorphism of
{\mathbb{S}}
if and only if
b:=\lambda\circ\beta\circ\lambda^{-1}
is an automorphism of
\mathbb{D}
.
By Pick’s theorem (see
[
3
, Sec. 2.6]
) the latter occurs if and only if

\frac{1-\overline{b(w)}b(z)}{1-\bar{w}z}\ =\ \overline{\psi(w)}\psi(z)

(4.4)

for some function
\psi
on
\mathbb{D}
.
Doing some algebra, (
4.4
) becomes (
4.3
) with

\phi(s)\ =\ \frac{1+\beta(s)}{1+s}\psi(\frac{s}{1+s}).

\Box

Consequently, we have the following characterization of unitary monomial operators (which can also be derived from Bourdon-Narayan and Theorem
1.8
).

Theorem 4.5
.

The operator

T:x^{s}\mapsto c(s)x^{\beta(s)}

is unitary on
L^{2}[0,1]
if and only if
\beta
is an automorphism of
{\mathbb{S}}
and
c(s)
is defined by

c(s)\ =\ \frac{e^{i\theta}}{\sqrt{1+2\Re\beta(0)}}\frac{1+\overline{\beta(0)}+\beta(s)}{1+s}.

(4.6)

Proof:
Since
\beta
is holomorphic by Theorem
1.8
and
has to be non-constant for
T
to be bounded, the range of
T
must be dense. Therefore it is unitary if and only if it is isometric.
It is isometric if and only if for every
s,t
we have

\displaystyle\langle x^{s},x^{t}\rangle

\displaystyle\ =\

\displaystyle\langle c(s)x^{\beta(s)},c(t)x^{\beta(t)}\rangle

\displaystyle\Leftrightarrow\quad\frac{1}{1+s+\bar{t}}

\displaystyle\ =\

\displaystyle\frac{c(s)\overline{c(t)}}{1+\beta(s)+\overline{\beta(t)}}.

That means (
4.4
) holds, so
\beta
is an automorphism. Letting
t=0

we get

c(0)\ =\ e^{i\theta}\sqrt{1+2\Re\beta(0)},

and solving for
c(s)
we get
(
4.6
).

Conversely, suppose (
4.6
) holds and
\beta
is an automorphism. By Lemma
4.2
, we have
(
4.3
) for some
\phi
. Letting
t=0
and solving, we get that
\phi
is given by (
4.6
).

\Box
