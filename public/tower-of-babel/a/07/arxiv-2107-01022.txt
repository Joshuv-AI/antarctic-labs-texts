My last fixed point theorem MSC: 54H25
Lech Pasicki

Abstract
In this note a far extension of the Banach fixed point theorem is proved.



Definition 1
(
[
1
, Definition 6.1]
)

A mapping
p\colon X\times X\to[0,\infty)
is a felt metric for
X
if the following system of conditions
is satisfied:

\displaystyle p(x,y)=0\textit{ yields }x=y,\quad\mbox{$x,y\in X$},

(1a)

\displaystyle p(x,y)=p(y,x),\quad\mbox{$x,y\in X$},

(1b)

\displaystyle\begin{split}&\textit{for each }\epsilon>0\textit{ there exists a }\delta>0\textit{ such that }\\
&p(z,y)<\delta\textit{ yields }|p(z,x)-p(y,x)|<\epsilon,\quad x,y,z,\in X.\end{split}

(1c)

A felt metric space
(X,p)
(its topology is generated by balls) is
0
-complete, if for each sequence

(x_{n})_{n\in\mathbb{N}}
in
X
, such that
\mbox{$\lim_{m,n\to\infty}$}\mbox{$p(x_{n},x_{m})$}=0
, there exists an
x\in X
for which
\mbox{$\lim_{n\to\infty}$}\mbox{$p(x_{n},x)$}=0
; a selfmapping
f

on
X
is
0
-continuous at an
x\in X
, if
\mbox{$\lim_{n\to\infty}$}\mbox{$p(x_{n},x)$}=0
yields
\mbox{$\lim_{n\to\infty}$}p(fx\mbox{${}_{n}$},fx)=0
, for each sequence

(x_{n})_{n\in\mathbb{N}}
in
X
;
f
is
0
-continuous if it is
0
-continuous at each
x\in X
.

In
[
1
, Theorem 6.6]
the following condition was used:

\begin{split}&\textit{for each }\alpha>0\textit{ there exists an }\epsilon>0\textit{ such that}\\
&\alpha-\epsilon<p(y,x)<\alpha+\epsilon\textit{ yields }p(fy,fx)\leq\alpha,\quad\mbox{$x,y\in X$}.\end{split}

(2)

Now, let us prove a result stronger than
[
1
, Theorem 6.6]
.

Theorem 2

Assume that
p
is a felt metric for
X
,
f
is a selfmapping on
X
,
x\mbox{${}_{n}$}=\mbox{$f^{n}x_{0}$}
,
n\in\mathbb{N}
,
\mbox{$\lim_{n\to\infty}$}p(x\mbox{${}_{n+1}$},x\mbox{${}_{n}$})=0
,
and let (
2
) or

\begin{split}&\textit{for each }\alpha>0\textit{ there exists an }\epsilon>0\textit{ such that}\\
&\alpha\leq p(y,x)<\alpha+\epsilon\textit{ yields }p(fy,fx)\leq\alpha,\quad\mbox{$x,y\in X$}\end{split}

(3)

be satisfied (equivalent conditions). If
(X,p)
is
0
-complete, then there exists an
x\in X
such that

\mbox{$\lim_{n\to\infty}$}p(x\mbox{${}_{n}$},x)=p(x,x)=0
and
fx=x
.

Proof. In particular, for
\alpha=p(y,x)>0
, condition (
2
) as well as (
3
) yields

p(fy,fx)\leq p(y,x)
,
i.e.

f
is nonexpansive (for
p(y,x)>0
), and conditions (
2
),
(
3
) are equivalent (one may assume
\alpha-\epsilon>0
in (
2
)). Now, in view of

[
1
, Theorem 6.6]
, if
(X,p)
is
0
-complete, then for some
x\in X
we have

\mbox{$\lim_{n\to\infty}$}p(x\mbox{${}_{n}$},x)=p(x,x)=0
. From (
1c
) it follows that

\mbox{$\lim_{n\to\infty}$}|p(x\mbox{${}_{n+1}$},fx)-p(x,fx)|=\mbox{$\lim_{n\to\infty}$}p(x\mbox{${}_{n+1}$},x)=0.

(4)

If
p(x\mbox{${}_{n}$},x)=0
holds for all
n>\mbox{$n_{0}$}
, then
x=x\mbox{${}_{n}$}=x\mbox{${}_{n+1}$}
and we get
fx=fx\mbox{${}_{n}$}=x\mbox{${}_{n+1}$}=x
. Therefore,
one may assume
p(x\mbox{${}_{n}$},x)>0
for infinitely many
n\in\mathbb{N}
. Suppose
p(x,fx)=2\beta>0
. Then
(see (
4
)) we obtain
p(x\mbox{${}_{n+1}$},fx)>\beta
for large
n\in\mathbb{N}
. Let us consider an
n\in\mathbb{N}
such that

0<p(x\mbox{${}_{n}$},x)=\alpha<\beta
. Now, (
3
) yields
\beta<p(x\mbox{${}_{n+1}$},fx)\leq\alpha
, a
contradiction. Consequently,
p(x,fx)=0
, and
fx=x
(see (
1a
)).
\quad\square

Theorem
2
is a far extension of the Banach theorem, as for
0\leq c<1
one can calculate the
respective
\epsilon>0
(see (
3
)) from the subsequent formula

p(fy,fx)\leq cp(y,x)\leq c(\alpha+\epsilon)\leq\alpha.
