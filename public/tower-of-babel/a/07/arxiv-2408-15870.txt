BIM-SLAM: Integrating BIM Models in Multi-session SLAM for Lifelong Mapping using 3D LiDAR
M. A. Vega Torres & A. Braun & A. Borrmann

Abstract
While 3D Light Detection and Ranging sensor technology is becoming more advanced and cheaper every day, the growth of digitalization in the Architecture, Engineering and Construction industry contributes to the fact that 3D building information models (BIM models) are now available for a large part of the built environment. These two facts open the question of how 3D models can support 3D Light Detection and Ranging long-term Simultaneous Localization and Mapping in indoor, Global Positioning System-denied environments. This paper proposes a methodology that leverages building information models to create an updated map of indoor environments with sequential Light Detection and Ranging measurements. Session data (pose graph-based map and descriptors) are initially generated from building information models. Then, real-world data is aligned with the session data from the model using multi-session anchoring while minimizing the drift on the real-world data. Finally, the new elements not present in the building information model are identified, grouped, and reconstructed in a surface representation, allowing a better visualization next to the building information model. The framework enables the creation of a coherent map aligned with the building information model that does not require prior knowledge of the initial pose of the robot, and it does not need to be inside the map.



Keywords -

BIM, Multi-Session SLAM, Pose-Graph Optimization, Localization, Mapping, 3D LiDAR.

Introduction

The ability to align, compare, and manage data acquired at different times that could be spaced apart by long periods, also known as long-term map management, is crucial in real-world robotic applications.

Since the real world is permanently evolving and changing, long-term map management is essential for autonomous robot navigation and users who want to use the map to understand the current situation and its evolution.
In particular, in an emergency, an up-to-date map can serve first responders to increase situational awareness and support decision-making to save lives efficiently and safely
[
1
]
.

Maps are usually created with mobile robots equipped with sensors and leveraging Simultaneous Localization and Mapping algorithms to enable fast and automated workflows.
However, these maps are commonly disconnected from any preliminary information, creating a map that may suffer from significant drift and does not allow change detection or comparison with a prior map.
However, these maps are commonly disconnected from any preliminary information, creating a map that may suffer from significant drift and does not allow change detection or comparison with a prior map.

Nonetheless, a georeferenced building information model is available for most contemporary buildings and can be used as a reference map to enable accurate Light Detection and Ranging localization and mapping.

In addition, the robot’s pose in the coordinate system of the building information model could be retrieved with a localization algorithm
[
2
]
.
Given this pose, the building information model could support autonomous robotic tasks.
For example, path planning, object inspection
[
3
]
or maintenance and repair
[
4
]
.

As will be discussed in Section
2
, several researchers have investigated the use of Building Information Modeling for robot localization
[
2
]
.
However, only a few aim to create an accurate, updated map aligned with the information from the building information model.

Furthermore, most of them also require a perfect estimation of the robot’s initial position, which must be inside the prior map.
On top of that, almost no method considers discrepancies between the reference building information model and the real world.
While we allow discrepancies between the reference building information model and the real world, we also assume that the model still represents a reliable map suitable for localization, i.e., the BIM contains enough features that coincide geometrically with the real world.

To address this challenge, we propose a novel framework that allows the improvement of a map created with mobile 3D LiDAR data. The map is corrected as it is aligned with a BIM model, allowing a better understanding of the scene and change detection for long-term map management.

First, we create session data from building information models.
Session data (SD) represent data collected from the exact location at various periods. These data are very convenient for performing offline operations between sessions, e.g., inter-session alignment
[
5
]
or place recognition
[
6
]
.

A proposed ground-truth multi-session anchoring uses these Session Data to align and rectify another query Session Data with a reference building information model.

Finally, the aligned data is compared against the building information model, and positive differences are represented as reconstructed surfaces, enabling a better understanding of the current environment.

Overall, the proposed technique aims to contribute to accurately mapping indoor Global Positioning System-denied environments and posterior long-term map management.

2
Related research

Besides having the potential to support robot localization, a 3D building information model can be used as a prior map to create accurate, updated 3D maps and allow fast autonomous navigation.

This section will overview state-of-the-art methods, which used prior building information, i.e., building information models or floor plans, to support robot localization and also methods that support mapping.

2.1
BIM-based 2D Light Detection and Ranging localization and mapping

Follini et al. 2020
[

The same algorithm was used by

Hendrikx et al. 2021
proposed an approach that, instead of using an Occupancy Grid Map, applies a robot-specific world model representation extracted from an Industry Foundation Classes file for 2D-Light Detection and Ranging localization.
In their factor graph-based localization approach, the system queries semantic objects in its surroundings (lines, corners, and circles) and creates data associations between them and the laser measurements.
More recently, in

Instead of using a building information model,

Later, they proposed an improved pipeline for long-term localization and mapping in dynamic environments performing better than Monte Carlo Localization in the pose tracking problem
[

In our previous work
[

Based on these findings, and in an effort to facilitate the transition from Particle Filter to Graph-based Localization methods, we also contributed with an open source method that converts Occupancy Grid Map to Pose Graph-based Maps for robust robot pose tracking.

2.2
BIM-based 3D Light Detection and Ranging localization and mapping

Other methods have explored 3D Light Detection and Ranging localization with building information models.

A high-accuracy robotic building construction system was proposed by

Later the pipeline was reconfigured to create a self-improving semantic perception method that can better handle clutter in the environment

This method is very convenient; however, since they use Cartographer in localization mode, the robot must have its initial pose inside the boundaries of the prior map to be localized and create an aligned map.

Recently,
[

introduced a semantic Iterative Closest Point method that can leverage the 3D geometry and the semantic information of a building information model for data associations achieving a robust 3D Light Detection and Ranging localization method. Their framework proposes a BIM-to-Map conversion, converting the 3D model into a semantically enriched point cloud.
Their experiments show that they can achieve effective 3D Light Detection and Ranging-only localization with a building information model.

[

proposed another relevant approach; here, instead of using object semantics for localization, they use geometric and topological information in the form of walls and rooms. With this information, they create Situational Graphs (S-Graphs), which are then used for accurate pose tracking.
Later, they enhanced their method allowing the creation of a map prior to localization and posterior matching and merging with an A-graph (extracted from building information models). The final merged map was denoted as an informed Situational Graph (iS-Graph)
[
22

.

In
[
23
]
, the authors introduced direct Light Detection and Ranging localization (DLL), a fast direct 3D point cloud-based localization technique using 3D Light Detection and Ranging.
They employ a registration technique that does not require features or point correspondences and is based on non-linear optimization of the distance between the points and the map.
The approach can track the robot’s pose with sub-decimeter accuracy by rectifying the expected pose from odometry. The method demonstrated better performance than AMCL 3D.

While numerous strategies aiming to leverage building information models for Light Detection and Ranging localization and mapping have emerged.
Most of them have focused on real-time localization without allowing a better estimation of previous poses with pose-graph-based optimization techniques.

Moreover, almost all must have a good initial pose inside the given map.
Without this initial pose and if the robot starts from a point where the building information model is not visible, there is no possibility for localization or the creation of an aligned map.
Furthermore, most focused on something different than automatically identifying the environmental discrepancies.

In this paper, we propose a method that handles these issues, demonstrating that it is possible to retrieve an accurate, aligned, updated, optimized map close to the ground truth and identify positive differences.
The method also works if the robot’s starting position is not inside the map.

3.2
BIM-based session data generation

Using parts of our previous contribution
[
2
]
, 3D Light Detection and Ranging Session Data with ground truth poses can be created from the building information model.
As a first step, an Occupancy Grid Map is created from the model, which is then used to determine the path where a robot will be simulated.
The generation of Session Data from an Occupancy Grid Map is performed with the open source Occupancy Grid Map to Pose Graph-based map package
[
2
]
, with a slight modification.
Instead of simulating 2D laser scan Robot Operating System messages with ray casting, we leverage the Gazebo physics simulation engine
[
24
]
to simulate the complete 3D Light Detection and Ranging scans.
This simulation is done by sending navigational goals to a simulated robot and leaving it to navigate autonomously with the Robot Operating System Navigation Stack through the estimated path provided by the Wavefront Coverage Path Planner of Occupancy Grid Map to Pose Graph-based map.

The navigational goals are found by retrieving only one waypoint out of 20 in the list of generated waypoints from the Path Planner.
In this way, the waypoints are separated by a considerable distance but still allow the robot to navigate the complete path without skipping any region.
Then the selected waypoints are passed as navigational goals (with pose and orientation) to Gazebo only when the simulated robot is at a certain distance to the next selected waypoint.
These navigational goals are necessary to allow the robot to execute the whole exploration smoothly without unnecessary stops or skipping previous navigational goals.

It is necessary to recall that in this step, the semantics of the building information model are leveraged, extracting only permanent structures (for example, walls, ceilings, and floors) and excluding spaces, non-permanent or Light Detection and Ranging-invisible objects (like doors, windows, or curtain walls).
Please, refer to
[
2
]
for more details about this step.

3.3
Ground-truth multi-session anchoring

Given the Session Data from the real-world data
\mathcal{S_{Q}}
, denoted as
query

\mathcal{S_{GT}}
, denoted as

\mathcal{S_{Q}}
with
\mathcal{S_{GT}}

To align these maps, we use anchor node-based inter-session loop factors, as described in
[
5
]
,
[
25
]
,
[

]
,
[

Instead of optimizing the poses of the two sessions, we do not allow modifications of the ground truth session created from the model.
This step is based on the assumption that, while there can be discrepancies between the reference building information model and the real world, the model still represents a reliable map suitable for localization.

In order to avoid alterations to the current session in
\mathcal{S_{GT}}
, we add its poses as
prior factors
with a very low variance (i.e.,
1\text{\times}{10}^{-100}\text{\,}\mathrm{}
) in its noise model, to the pose-graph optimization problem.

Anchor nodes
represent the transformation from the local frame of each session graph to a standard global reference frame.
Once the poses of each session are transformed into the global frame (via the anchor nodes), a comparison of the measurements between sessions is possible.

As outlined in
Kim et al. 2010
, the anchor node can successfully approximate the offset between sessions. Besides allowing faster convergence to the least-squares solvers, anchor nodes allow each session to optimize their poses before global constraints are observed
[
27
]
.

This characteristic is beneficial for long-term mapping since it allows the creation of a first consistent map in the state of the environment at the time the data was collected. Once a map is created with a new session, the anchor nodes allow finding the transformation that aligns that session with another reference one.
In our case, the reference session is extracted from the building information model.

3.4
Aligned map construction and Change detection

With the calculated poses on the same coordinate system, a map can be created by placing the respective laser scans
\mathcal{P}_{Q,i}
in the estimated poses
{}^{W}\mathbf{x}_{Q,i}^{*}
, which are now in the BIM coordinate system.

Once the 3D map of the current state of the environment is aligned with the building information model, a comparison of the two maps is possible.
A distance threshold is set to differentiate between objects present in the model and the new objects in the updated environment, also known as
Positive Differences
.

A signed distance computation lets us determine which points are close to and far from the mesh.
Close points allow confirming building information model elements, and far points are considered new elements, i.e., elements not present in the model.

In the next step, a density-based clustering algorithm (DBSCAN) is used to split the point cloud of detected Positive Differencess into segments of points that are close to each other and might represent single objects.
This results in better visualization of the new objects in combination with the model, allowing a better scene understanding.

Finally, each cluster of the Positive Differencess is converted to a mesh representation created using cubes from a Voxel Grid of the point cloud.

Compared with other surface reconstruction methods, voxels represent the actual geometry of the objects visible in the scene.
A final result is visible on
5
.

5
Discussion

While in terms of drift reduction, our method performs only slightly better than state-of-the-art Simultaneous Localization and Mapping algorithms, as shown in Table
1
.
The main advantage of the proposed technique relies on the alignment of the acquired sensor data with the building information model.
The method also allows the creation of a map without the sensor being inside the prior map (as localization algorithms would require) or knowing its initial position.

We also show how the aligned sensor data can improve situational awareness (see Figure
5
). Moreover, once the data is aligned, the model can be leveraged to identify new and missing components and clean the point cloud, removing unnecessary noisy points from the surroundings. These features would enable robust long-term map data management, using less memory than needed and saving all the information in one reference coordinate system.

However, our pipeline still presents some limitations. For example, in the case of significant levels of discrepancies between the reference building information model and the real world, the minimal overlap between the scan and the BIM, or symmetric environments, the correct alignment may not be possible with our method.
Adjustments in creating the point cloud descriptors or the corresponding matching process might be necessary to address this issue.

Nonetheless, the method is not restricted to Manhattan-world environments with enclosed rooms, like in
[
22
]
, nor does it require manual input of the robot’s initial position in the map like the one proposed in
[
19
]
.

Avenues for future research include enhancements in the place recognition algorithm (here, we use Scan Context); leveraging topological and semantic information from the building information model to make most robust the alignment and optimization process; and improvements on the extraction of Session Data from building information models, in terms of speed and feature extraction, perhaps with a faster rendering method.

6
Conclusions

This paper presents a modular pipeline to allow 3D Light Detection and Ranging data alignment and change detection with a building information model as a reference map. Contrary to several other approaches, we aim to create an accurate, consistent map of the current state rather than focusing on real-time performance.
The method does not need to know the robot’s initial position, nor does the robot need to start inside the given map.
In this way, our framework allows map alignment and extension even if the reference building information model is no longer visible or if only a part of the model is scanned.

In the future, we would like to test the method on Session Data with more environmental changes and to enhance the change detection module to handle negative differences, i.e., when parts of the original building information model are no longer present in the environment.
