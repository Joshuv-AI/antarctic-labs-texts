Abstract
. In this paper, we investigate space-time tradeoffs for answering conjunctive queries with access patterns (CQAPs). The goal is to create a space-efficient data structure in an initial preprocessing phase and use it for answering (multiple) queries in an online phase. Previous work has developed data structures that trades off space usage for answering time for queries of practical interest, such as the path and triangle query. However, these approaches lack a comprehensive framework and are not generalizable. Our main contribution is a general algorithmic framework for obtaining space-time tradeoffs for any CQAP. Our framework builds upon the 𝖯𝖠𝖭𝖣𝖠 \mathsf{PANDA} algorithm and tree decomposition techniques. We demonstrate that our framework captures all state-of-the-art tradeoffs that were independently produced for various queries. Further, we show surprising improvements over the state-of-the-art tradeoffs known in the existing literature for reachability queries.



1.
Introduction

We study a class of problems that splits an algorithmic task into two phases: the
preprocessing phase
, which computes a space-efficient data structure from the input, and the
online phase
, which uses the data structure to answer requests of a specific form over the input as fast as possible. Many important algorithmic tasks such as set intersection problems
(
Cohen2010
;
goldstein2017conditional
)
, reachability in directed graphs
(
agarwal2011approximate
;
agarwal2014space
;
cohen2010hardness
)
, histogram indexing
(
chan2015clustered
;
kociumaka2013efficient
)
, and problems related to document retrieval
(
afshani2016data
;
larsen2015hardness
)
can be expressed in this way. The fundamental algorithmic question related to these problems is to find
the tradeoff between the space
S
necessary for storing the data structures and the time
T
for answering a request.

Let us look at one of the simplest tasks in this setup. Consider the
2
-
Set Disjointness
problem: given a universe of elements
U
and a collection of
m
sets
S_{1},\dots,S_{m}\subseteq U
, we want to create a data structure such that for any pair of integers
1\leq i,j\leq m
, we can efficiently decide whether
S_{i}\cap S_{j}
is empty or not. It is well-known that the space-time tradeoff for
2
-
Set Disjointness
is captured by the equation
S\cdot T^{2}=O(N^{2})
, where
N
is the total size of all sets
(
Cohen2010
;
goldstein2017conditional
)
. Similar tradeoffs have also been established for other data structure problems. In the
k
-
Reachability
problem
(
goldstein2017conditional
;
Cohen2010
)
we are given as input a directed graph
G=(V,E)
, an arbitrary pair of vertices
u,v
, and the goal is to decide whether there exists a path of length
k
between
u
and
v
. The data structure obtained was conjectured to be optimal by
(
goldstein2017conditional
)
, and the conjectured optimality was used to develop conditional lower bounds for other problems, such as approximate distance oracles
(
agarwal2011approximate
;
agarwal2014space
)
where no progress has been made in improving the upper bounds in the last decade. In the
edge triangle detection
problem
(
goldstein2017conditional
)
, we are given as input a graph
G=(V,E)
, and the goal is to develop a data structure that can answer whether a given edge
e\in E
participates in a triangle or not. Each of these problems has been studied in isolation and therefore, the algorithmic insights are not readily generalizable into a comprehensive framework.

In this paper, we cast many of the above problems into answering
Conjunctive Queries with Access Patterns (CQAPs)
over a relational database. For example, by using the relation
R(x,y)
to encode that element
x
belongs to set
y
,
2
-
Set Disjointness
can be captured by the following CQAP:
\varphi(\mid y_{1},y_{2})\leftarrow R(x,y_{1})\land R(x,y_{2})
. The expression
\varphi(\mid y_{1},y_{2})
can be interpreted as follows: given values for
y_{1},y_{2}
, compute whether the query returns true or not. Different access patterns capture different ways of accessing the result of the CQ and result in different tradeoffs.

Tradeoffs for enumerating Conjunctive Query results under static and dynamic settings have been a subject of previous research
(
olteanu2016factorized
;
greco2013structural
;
deep2018compressed
;
CQAP
;
kara19
;
kara2019counting
)
. However, previous work either focuses on the tradeoff between preprocessing time and answering time
(
CQAP
;
kara19
;
kara2019counting
)
, or the tradeoff between space and delay in enumeration
(
olteanu2016factorized
;
deep2018compressed
)
. In this paper, we focus explicitly on the tradeoff between space and answering time, without optimizing for preprocessing time. Most closely related to our setting is the problem of answering Boolean CQs
(
deep2021space
)
. In that work, the authors slightly improve upon the data structure proposed in
(
deep2018compressed
)
and adapt it for Boolean CQ answering. Further,
(
deep2021space
)
identified that the conjectured tradeoff for the
k
-reachability problem is suboptimal by showing slightly improved tradeoffs for all
k\geq 3
. The techniques used in this paper are quite different and a vast generalization of the techniques used in
(
deep2021space
)
. The proposed improvements in
(
deep2021space
)
for
k
-reachability are already captured in this work and in many cases, surpass the ones from
(
deep2021space
)
.

Our Contribution.

Our key contribution is a general algorithmic framework for obtaining space-time tradeoffs for any CQAP. Our framework builds upon the
PANDA
algorithm
(
DBLP:conf/pods/Khamis0S17
)
and tree decomposition techniques
(
gottlob2014treewidth
;
Marx13
)
. Given any CQAP, it calculates a tradeoff that can find the best possible time for a given space budget. To achieve this goal, we need two key technical contributions.

First, we introduce the novel notion of
partially-materialized tree decompositions
(PMTDs) that allow us to capture different possible materialization strategies on a given tree decomposition (
Section 3
). At a high level, a PMTD augments a tree decomposition with information on which bags should be materialized and which should be computed online. To use a PMTD, we propose a variant of the Yannakakis algorithm (
Subsection 3.1
) such that during the online phase we incur only the cost of visiting the non-materialized bags.

The second key ingredient is an extension of the
PANDA
algorithm
(
DBLP:conf/pods/Khamis0S17
)
that computes a disjunctive rule in two phases. The computation of a disjunctive rule allows placing an answer to any of the targets in the head of the rule. A key technical component in the
PANDA
algorithm is the notion of a
Shannon-flow inequality
. For any Shannon-flow inequality, one can construct a proof sequence that has a direct correspondence with relational operators. Consequently, a proof sequence can be transformed into a join algorithm.
The disjunctive rules we consider are computed in two phases: in the first phase (preprocessing), we can place an answer only to targets that will be materialized during the preprocessing phase. In the second phase (online), we place an answer to the remaining targets. We call these rules
2-phase disjunctive rules
(
Subsection 4.1
). To achieve this 2-phase computation, we introduce a type of Shannon-flow inequalities, called
joint Shannon-flow inequalities
(
Section 5
), such that each inequality gives rise to a space-time tradeoff. The joint Shannon-flow inequality generates two parallel proof sequences, one proof sequence for the preprocessing phase and another proof sequence for the answering phase. This transformation allows us to use the
PANDA
algorithm as a blackbox on each of the proof sequences independently and is instrumental in achieving space-time tradeoffs.

We demonstrate the versatility of our framework by recovering state-of-the-art space-time tradeoffs for Boolean CQAPs,
2
-
Set Disjointness
as well as its generalization
k
-
Set Disjointness
, and
k
-
Reachability
(
Section 6
). We also apply our framework to the previously unstudied setting of space-time tradeoffs (in the static setting) for access patterns over a subset of
hierarchical queries
, a fragment of acyclic CQs that is of great interest
(
dalvi2009probabilistic
;
berkholz2017answering
;
kara19
;
idris2017dynamic
;
deep2021enumeration
;
bonifati2020analytical
)
. Interestingly, we can recover strategies that are very similar to how specialized enumeration algorithms with provable guarantees work for this class of CQs
(
kara19
;
deep2021enumeration
)
. More importantly, we improve state-of-the-art tradeoffs. Our most interesting finding is that we can obtain complex tradeoffs for
k
-
Reachability
that exhibit different behavior for different regimes of
S
. For the
3
-
Reachability
problem, we show how to improve the tradeoff for a significant part of the spectrum. For the
4
-
Reachability
problem, we are able to show (via a rather involved analysis) that the space-time tradeoff can be improved
everywhere
when compared to the conjectured optimal! These results falsify the proposed optimal tradeoff of
S\cdot T^{2/(k-1)}=\widetilde{O}(|E|^{2})
for
k
-
Reachability
for regimes that are even larger than what was shown in
(
deep2021space
)
.

2.
Background

Conjunctive Query.
We associate a Conjunctive Query (CQ)
\varphi
with a hypergraph
\mathcal{H}=([n],\mathcal{E})
, where
[n]=\{1,\dots,n\}
and
\mathcal{E}\subseteq 2^{[n]}
. The body of the query has atoms
R_{F}
, where
F\in\mathcal{E}
. To each node
i\in[n]
, we associate a variable
x_{i}
. The CQ is then

\varphi(\mathbf{x}_{H})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}),

where
\mathbf{x}_{I}
denotes the tuple
(x_{i})_{i\in I}
for any
I\subseteq[n]
.
The variables in
\mathbf{x}_{H}
are called the
head variables
of the CQ. The CQ is
full
if
H=[n]
and
Boolean
if
H=\emptyset
. We use
\varphi
to denote the output of the CQ
\varphi
.

Degree Constraints.

A
degree constraint
is a triple
(X,Y,N_{Y|X})
where
X\subset Y\subseteq[n]
and
N_{Y|X}
is a natural number. A relation
R_{F}
is said to
guard
the degree constraint
(X,Y,N_{Y|X})
if
X\subset Y\subseteq F
and for every tuple
\mathbf{t}_{X}
(over
X
),

\max_{\mathbf{t}_{X}}\deg_{F}(Y|\mathbf{t}_{X})\leq N_{Y|X},

where
\deg_{F}(Y|\mathbf{t}_{X})=\left|\Pi_{Y}(\sigma_{X=\mathbf{t}_{X}}R_{F})\right|
. We use
\mathsf{DC}
to denote a set of degree constraints and say that
\mathsf{DC}
is guarded by a database instance
\mathcal{D}
if every
(X,Y,N_{Y|X})\in\mathsf{DC}
is guarded by some relation in
\mathcal{D}
. A degree constraint
(X,Y,N_{Y|X})
is a
cardinality constraint
if
X=\emptyset
. Throughout this work, we make the following assumptions on
\mathsf{DC}
guarded by a database instance
\mathcal{D}
:

•

(best constraints assumption)
w.l.o.g, for any
X\subset Y\subseteq[n]
,
there is at most one
(X,Y,N_{Y|X})\in\mathsf{DC}
. This assumption can be maintained by only keeping the minimum
N_{Y|X}
if there is more than one.

•

for every relation
R_{F}\in\mathcal{D}
, there is a
cardinality constraint

(\emptyset,F,|R_{F}|\stackrel{{\scriptstyle\text{def}}}{{=}}N_{F|\emptyset})\in\mathsf{DC}
. The
size
of the database
\mathcal{D}
is denoted as
|\mathcal{D}|\stackrel{{\scriptstyle\text{def}}}{{=}}\max_{R_{F}\in\mathcal{D}}|R_{F}|
.

In this work, we use degree constraints to measure data complexity. All logs are in base
2
, unless otherwise stated.

2.1.
CQs with Access Patterns

We define CQs with access patterns following the definition from
(
CQAP
)
:

Definition 2.1 (CQ with access patterns).

A Conjunctive Query with
Access Patterns
(CQAP) is an expression of the form

\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}),

where
A\subseteq[n]
is called the
access pattern
of the query.

The access pattern tells us how a user accesses the result of the CQ. In particular, the user will provide an instance of a relation
Q_{A}(\mathbf{x}_{A})
, which we call an
access request
. The task is then to return the result of the following CQ, denoted as
\varphi
, where

\varphi(\mathbf{x}_{H})\leftarrow Q_{A}(\mathbf{x}_{A})\wedge\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}).

We call
\varphi
the
access CQ
. The most natural access request is one where
|Q_{A}|=1
; in other words, the user provides only one fixed value for every variable
x_{i},i\in A
. This can be thought of as using the CQ result as an index with search key
\mathbf{x}_{A}
. By allowing the access request
Q_{A}
to consist of more tuples, we can capture other scenarios. For example, one can take a stream of access requests of size
1
and batch them together to obtain a (possibly faster) answer for all of them at once. Prior work
(
deep2018compressed
;
CQAP
)
has only considered the case where
|Q_{A}|=1
.

2.2.
Problem Statement

Let
\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})
be a CQAP under degree constraints
\mathsf{DC}
guarded by the input relations. In addition, we denote by
\mathsf{AC}
another set of degree constraints known in prior, guarded by any access request
Q_{A}
. Similar to
\mathsf{DC}
, we that assume there is a cardinality constraint
(\emptyset,A,|Q_{A}|=N_{A|\emptyset})\in\mathsf{AC}
guarded by
Q_{A}
. For example, the case where
|Q_{A}|=1
can be interpreted as a cardinality constraint
(\emptyset,A,1)\in\mathsf{AC}
.
Given a database instance
\mathcal{D}
guarding
\mathsf{DC}
, our goal is to construct a data structure, such that we can answer any access request as fast as possible. More formally, we split query processing into two phases:

Preprocessing phase::

it constructs a data structure in space
\widetilde{O}(S)
1
1

1

The notation
\widetilde{O}
hides a polylogarithmic factor in
|\mathcal{D}|
.
. The overall space cost takes the form
\widetilde{O}(S+|\mathcal{D}|)
, where
S
is called the
intrinsic space cost
of the data structure and
|\mathcal{D}|
is the (unavoidable) space cost for storing the database.

Online phase:
:

given an access request
Q_{A}
(guarding
\mathsf{AC}
), it returns the results of the access CQ
\varphi
using the data structure built in the preprocessing phase. The (worst-case) answering time is then
\widetilde{O}(T+|Q_{A}|)+O(|\varphi|)
, where
T
is called the
intrinsic time cost
and
|Q_{A}|+|\varphi|
is the (unavoidable) time cost of reading the access request
Q_{A}
and enumerating the output. For the Boolean case and when
|Q_{A}|=1
, the answering time simply becomes
\widetilde{O}(T)
.

In this work, we study the tradeoffs between the two intrinsic quantities,
S
and
T
, which we will call an
intrinsic tradeoff
.
At one extreme, the algorithm stores nothing, thus
S=O(1)
, and we answer each access request from scratch. At the other extreme, the algorithm stores the results of the CQ
\varphi_{M}(\mathbf{x}_{H\cup A})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F})

as a hash table with index key
\mathbf{x}_{A}
. For any access request
Q_{A}
, we simply evaluate the query
\varphi(\mathbf{x}_{H})\leftarrow Q_{A}\wedge\varphi_{M}
in the online phase by probing each tuple of
Q_{A}
in the hash table. If
H\supseteq A
, then any access request can be answered in (instance-optimal) time
O(|Q_{A}|+|\varphi|)
, in which case
T=O(1)
.

Example 2.2 (
k
-Set Disjointness).

In this problem, we are given sets
S_{1},\dots,S_{m}
with elements drawn from the same universe
U
. Each access request asks whether the intersection between
k
sets is empty or not. By encoding the family of sets as a binary relation
R(y,x)
such that element
y
belongs to set
x
, we can express the problem as the following CQAP:

(1)

\displaystyle\varphi(\mid\mathbf{x}_{[k]})\leftarrow\bigwedge_{i\in[k]}R(y,x_{i}).

If we also want to enumerate the elements in their intersection, we would instead use the non-Boolean version:

(2)

\displaystyle\varphi(y\mid\mathbf{x}_{[k]})\leftarrow\bigwedge_{i\in[k]}R(y,x_{i}).

Example 2.3 (
k
-Reachability).

Given a direct graph
G
, the
k
-reachability problem asks, given a pair vertices
(u,v)
, to check whether they are connected by a path of length
k
. Representing the graph as a binary relation
R(x,y)
, we can model this problem through the following CQAP (the
k
-path query):

\phi_{k}(\mid x_{1},x_{k+1})\leftarrow\bigwedge_{i\in[k]}R(x_{i},x_{i+1}).

We can also check whether there is a path of length at most
k
by combining
the results of
k
such queries (one for each
1,\dots,k
).

In this work, we focus on the CQAP such that
H\supseteq A
. If we are given a CQAP where
H\nsupseteq A
, we replace the head of the CQAP with
\varphi(\mathbf{x}_{H\cup A}\mid\mathbf{x}_{A})
, and simply project on the desired results in the end.

3.
Partially Materialized Tree Decompositions

In this section, we introduce a type of tree decomposition that augments a decomposition with information about what bags we want to materialize.

Definition 3.1 (Tree Decomposition).

A
tree decomposition
of a hypergraph
\mathcal{H}=([n],\mathcal{E})
is a pair

(\mathcal{T},\chi)
where
(i)

\mathcal{T}
is an undirected tree, and
(ii)

\chi:V(\mathcal{T})\rightarrow 2^{[n]}
is a mapping that assigns to every node
t\in V(\mathcal{T})
a subset of
[n]
, called the
bag
of
t
, such that

(1)

For every hyperedge
F\in\mathcal{E}
, the set
F
is contained in some bag; and

(2)

For each vertex
x\in[n]
, the set of nodes
\{t\mid x\in\chi(t)\}
forms a (non-empty) connected subtree of
\mathcal{T}
.

Take a tree decomposition
(\mathcal{T},\chi)
and a node
r\in V(\mathcal{T})
. We define
\textsf{TOP}_{r}(x)
as the highest node in
\mathcal{T}
containing
x
in its bag if we root the tree at
r
. We now say that
(\mathcal{T},\chi)
is
free-connex w.r.t.
r
if for any
x\in H
and
y\in[n]\setminus H
,
\textsf{TOP}_{r}(y)
is not an ancestor of
\textsf{TOP}_{r}(x)

(
Secure
)
. We say that
(\mathcal{T},\chi)
is free-connex if it is free-connex w.r.t. some
r\in V(\mathcal{T})
.

We can now introduce our key concept of a partially materialized tree decomposition, tailored for CQAPs. Let
\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})
be a CQAP such that
A\subseteq H
. Let
\mathcal{H}
be the hypergraph associated with
\varphi(\mathbf{x}_{H})
, the access CQ.

Definition 3.2 (PMTD).

A
Partially Materialized Tree Decomposition (PMTD)
of the CQAP
\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})
with
H\supseteq A
is a tuple
(\mathcal{T},\chi,M,r)
such that the following properties hold:

(1)

(\mathcal{T},\chi)
is a free-connex tree decomposition of
\mathcal{H}
w.r.t. node
r
, called the root ; and

(2)

A\subseteq\chi(r)
; and

(3)

M\subseteq V(\mathcal{T})
such that whenever
t\in M
then all the nodes of its subtree (w.r.t. orienting the tree away from
r
) are in
M
.

Given a PMTD
(\mathcal{T},\chi,M,r)
, we call
M
the
materialization set
. We also associate with each node
t\in V(\mathcal{T})
a
view
with variables
\mathbf{x}_{\nu(t)}
, where the mapping
\nu:V(\mathcal{T})\rightarrow 2^{[n]}
is defined as follows. If the node
t\notin M
, then
\nu(t)\stackrel{{\scriptstyle\text{def}}}{{=}}\chi(t)
and the view is of the form
T_{\nu(t)}(\mathbf{x}_{\nu(t)})
, called a
T
-view
. Otherwise,
t\in M
. If
t=r\in M
, define
\nu(r)\stackrel{{\scriptstyle\text{def}}}{{=}}\chi(t)\cap H
. Let
p
be the parent node of a non-root node
t\in M
and define

\displaystyle\nu(t)

\displaystyle\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\chi(t)\cap(H\cup\chi(p))&\text{ if }p\notin M\\
\chi(t)\cap H&\text{ if }p\in M\text{ and }\chi(t)\cap H\nsubseteq\chi(p)\cap H\\
\emptyset&\text{ if }p\in M\text{ and }\chi(t)\cap H\subseteq\chi(p)\cap H.\end{cases}

The view (for each
t\in M
) then is of the form
S_{\nu(t)}(\mathbf{x}_{\nu(t)})
, called the
S
-view
. This definition of
S
-views corresponds to running a bottom-up semijoin-reduce pass of the Yannakakis algorithm in the materialization set
M
of the free-connex tree decomposition
(\mathcal{T},\chi)
. Indeed, any variables in
\chi(t)\setminus\nu(t)
are safely projected out after the semijoin-reduce.

On a high level,
M
specifies the type of views associated with each bag (
S
-view or
T
-view), and
\nu(\cdot)
pinpoints the schema of that view (possibly empty). A PMTD appoints its
S
-views to be materialized in the preprocessing phase and its
T
-views to be computed in the online phase. In the case where
M=\emptyset
, every view in the decomposition is obtained in the online phase. When
H=A
or
H=[n]
, the free-connex property does not put any additional restrictions on the tree decompositions for a PMTD.

Here,
(x_{1},x_{4})

Redundancy & Domination.

We say that a tree decomposition is
non-redundant
if no bag is a subset of another bag. We say that a tree decomposition
(\mathcal{T}_{1},\chi_{1})
is
dominated
by another tree decomposition
(\mathcal{T}_{2},\chi_{2})
if every bag of
(\mathcal{T}_{1},\chi_{1})
is a subset of some bag of
(\mathcal{T}_{2},\chi_{2})
. Here, we will generalize both notions to PMTDs.

Definition 3.4 (PMTD Redundancy).

A PMTD
(\mathcal{T},\chi,M,r)
is
non-redundant
if
(1)
for
t\in M
,
\nu(t)\neq\emptyset
and no
\nu(t)
is a subset of another; and
(2)
for
t\notin M
, no
\nu(t)
is a subset of another.

Definition 3.5 (PMTD Domination).

A PMTD
(\mathcal{T}_{1},\chi_{1},M_{1},r_{1})
is dominated by another PMTD
(\mathcal{T}_{2},\chi_{2},M_{2},r_{2})
if
(1)
for every node
t_{1}\in M_{1}
, there is some node
t_{2}\in M_{2}
such that
\nu(t_{1})\subseteq\nu(t_{2})
, and
(2)
for every node
t_{1}\in V(\mathcal{T}_{1})\setminus M_{1}
, there is some node
t_{2}\in V(\mathcal{T}_{2})\setminus M_{2}
such that
\nu(t_{1})\subseteq\nu(t_{2})
.

For PMTDs, both redundancy and domination are defined using the materialization set and views instead of the bags. For PMTDs with
M=\emptyset
, both PMTD redundancy and domination become equivalent to the standard definition.

4.
General Framework

Consider a CQAP
\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F})
with
H\supseteq A
. Recall that our goal is to find the best space-time tradeoffs under degree constraints
\mathsf{DC}
(guarded by input relations) and
\mathsf{AC}
(guarded by any access requests
Q_{A}
), as specified in
Subsection 2.2
. Our main algorithm is parameterized by:

•

\mathcal{P}=\{P_{i}\}_{i\in I}
, a (finite) indexed set of non-redundant and non-dominant PMTDs such that
P_{i}=(\mathcal{T}_{i},\chi_{i},M_{i},r_{i})
for every
i\in I
. Including all such PMTDs in

•

4.1.
2-Phase Disjunctive Rules

In this section, we define a specific type of disjunctive rule that will be necessary to acquire the
S
-views and
T
-views for PMTDs. We start by recalling the notion of a disjunctive rule. A disjunctive rule has the exact body of a CQ, while the head is a disjunction of output relations
T_{B}(\mathbf{x}_{B})
, which we call
targets
. Let
\mathsf{BT}\subseteq 2^{[n]}
be a non-empty set, then a
disjunctive rule

\rho
takes the form:

(4)

\rho:\quad\bigvee_{B\in\mathsf{BT}}T_{B}(\mathbf{x}_{B})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}).

Given a database instance
\mathcal{D}
, a
model
of
\rho
is a tuple
(T_{B})_{B\in\mathsf{BT}}
of relations, one for each target, such that the logical implication indicated by (
4
) holds. More precisely, for any tuple
\mathbf{a}
that satisfies the body, there is a target
T_{B}\in(T_{B})_{B\in\mathsf{B}}
such that
\Pi_{B}(\mathbf{a})\in T_{B}
. The
size
of a model is defined as the maximum size of its output relations and the
output size
of a disjunctive rule
\rho
, denoted as
|\rho|
, is defined as the minimum size over all models.

For our purposes, we define a type of disjunctive rules, called
2-phase disjunctive rules
.

Definition 4.1 (2-phase Disjunctive Rules).

A
2-phase disjunctive rule

\rho
defined by a CQAP
\varphi(\mathbf{x}_{H}\mid\mathbf{x}_{A})
is a single disjunctive rule that takes the body of the access CQ
\varphi
, while the head has two sets of output relations. In other words,
\rho
takes the form

(5)

\rho:\quad\bigvee_{B\in\mathsf{BS}}S_{B}(\mathbf{x}_{B})\vee\bigvee_{B\in\mathsf{BT}}T_{B}(\mathbf{x}_{B})\leftarrow Q_{A}(\mathbf{x}_{A})\wedge\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}),

where
\mathsf{BS},\mathsf{BT}\subseteq 2^{[n]}
and at most one can be empty. A
model
of
\rho
thus consists of two sets of output relations,
i.e. the
S
-targets

(S_{B})_{B\in\mathsf{BS}}
and the
T
-targets

(T_{B})_{B\in\mathsf{BT}}
.

As the name suggests, a model of a 2-phase disjunctive rule
\rho
is computed in two phases, the preprocessing and online phase:

Preprocessing phase::

we obtain the
S
-targets
(S_{B})_{B\in\mathsf{BS}}
using a
preprocessing disjunctive rule

(6)

\displaystyle\rho_{S}

\displaystyle:\quad\bigvee_{B\in\mathsf{BS}}S_{B}(\mathbf{x}_{B})\leftarrow\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F}),

The space cost for storing the
S
-targets is
\widetilde{O}(S_{\rho})
, and the overall space cost is
\widetilde{O}(S_{\rho}+|\mathcal{D}|)
. The preprocessing phase has no knowledge of
Q_{A}
except for the degree constraints
\mathsf{AC}
, so as to explicitly force the
S
-targets to be universal for any instance of access request.

Online phase::

given an access request
Q_{A}
(under
\mathsf{AC}
), we obtain the
T
-targets
(T_{B})_{B\in\mathsf{BT}}
using an
online disjunctive rule

(7)

\displaystyle\rho_{T}

\displaystyle:\quad\bigvee_{B\in\mathsf{BT}}T_{B}(\mathbf{x}_{B})\leftarrow Q_{A}(\mathbf{x}_{A})\wedge\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F})

in time and space
\widetilde{O}(T_{\rho})
. The overall time is
\widetilde{O}(T_{\rho}+|Q_{A}|)
.

If
\mathsf{BS}=\emptyset
, then the model is computed from scratch in the online phase (and vice versa).
As in
Subsection 2.2
, our focus is on analyzing the space-time tradeoffs between the two intrinsic quantities,
S_{\rho}
and
T_{\rho}
.

For the next part, assume that we have a 2-phase algorithm (called
\mathsf{2PP}
) that, given a space budget
S
, has a preprocessing procedure
\mathsf{2PP}\text{-}\mathsf{Preprocess}
using space
S_{\rho}\leq S
and an online procedure
\mathsf{2PP}\text{-}\mathsf{Online}
using time (and space)
T_{\rho}
. We will discuss this algorithm in the next section.

4.2.
Preprocessing Phase

As a first step, we construct from
\mathcal{P}
a set of 2-phase disjunctive rules as follows. Let
\nu_{i}
be the mapping for associated views of
P_{i}
. Let us define the cartesian product
\mathbf{A}=\times_{i\in I}\{V(\mathcal{T}_{i})\}
and let

. Informally, every element
\mathbf{a}\in\mathbf{A}
picks one view from every PMTD in the indexed set. For every
\mathbf{a}\in\mathbf{A}

is the materialization set of PMTD

\displaystyle\bigvee_{\mathbf{a}_{i}\in M_{i}}S_{\nu_{i}(\mathbf{a}_{i})}(\mathbf{x}_{\nu_{i}(\mathbf{a}_{i})})\vee\bigvee_{\mathbf{a}_{i}\notin M_{i}}T_{\nu_{i}(\mathbf{a}_{i})}

\displaystyle(\mathbf{x}_{\nu_{i}(\mathbf{a}_{i})})\leftarrow Q_{A}(\mathbf{x}_{A})\wedge\bigwedge_{F\in\mathcal{E}}R_{F}(\mathbf{x}_{F})

The body of the rule is the same independent of

. The head of the rule introduces an
S
-target whenever the corresponding bag is in the materialization set of the PMTD (using the corresponding view); otherwise, it introduces a
T
-target. There are exactly
M
2-phase disjunctive rules constructed from the given set of PMTDs, which is a query-complexity quantity.

5.

Let
\rho

(guarded by

T_{123}\vee S_{13}\leftarrow Q_{13}(x_{1},x_{3}),R_{1}(x_{1},x_{2}),R_{2}(x_{2},x_{3}).

This rule is the only rule we obtain from considering two PMTDs for the 2-reachability query.
To compute a disjunctive rule,
\mathsf{PANDA}
starts with a
Shannon-flow inequality
, which is an inequality over set functions
h:2^{[n]}\rightarrow\mathbb{R}_{+}
that must hold for any set function that is a polymatroid
2
2

2

A polymatroid is a set function
h:2^{[n]}\rightarrow\mathbb{R}_{+}
that is non-negative, monotone, and submodular, with
h(\emptyset)=0
.
. For our purposes, we need a
joint Shannon-flow inequality
, which holds over two set functions
{\color[rgb]{0,0,1}h_{S}},{\color[rgb]{1,0,0}h_{T}}
that must be polymatroids. Intuitively,
{\color[rgb]{0,0,1}h_{S}}
governs the preprocessing phase, while
{\color[rgb]{1,0,0}h_{T}}
governs the online phase. The joint Shannon-flow inequality for our example is:

\displaystyle\underbrace{{\color[rgb]{0,0,1}h_{S}}(1)+{\color[rgb]{1,0,0}h_{T}}(2|1)}_{R_{1}}+\underbrace{{\color[rgb]{0,0,1}h_{S}}(3)+{\color[rgb]{1,0,0}h_{T}}(2|3)}_{R_{2}}+2\underbrace{{\color[rgb]{1,0,0}h_{T}}(13)}_{Q_{13}}\geq\underbrace{{\color[rgb]{0,0,1}h_{S}}(13)}_{S_{13}}+2\underbrace{{\color[rgb]{1,0,0}h_{T}}(123)}_{T_{123}}

where
h(Y|X)=h(Y)-h(X)
. The right-hand side includes terms of
{\color[rgb]{0,0,1}h_{S}}
that correspond to
S
-targets and terms of
{\color[rgb]{1,0,0}h_{T}}
that correspond to
T
-targets. The left-hand side includes a term of
{\color[rgb]{1,0,0}h_{T}}
that corresponds to the access request
Q_{A}
, and possibly terms of
{\color[rgb]{0,0,1}h_{S}}
(
{\color[rgb]{1,0,0}h_{T}}
) that encode the degree constraints
\mathsf{DC}
(
\mathsf{DC}\cup\mathsf{AC}
). More importantly, it contains terms that correlate the two polymatroids by splitting an input relation with attributes
Y
into two parts, either
(i)

{\color[rgb]{0,0,1}h_{S}}(X)+{\color[rgb]{1,0,0}h_{T}}(Y|X)
, or
(ii)

{\color[rgb]{1,0,0}h_{T}}(X)+{\color[rgb]{0,0,1}h_{S}}(Y|X)
, where
X\subseteq Y
. Intuitively, the first split materializes the heavy
X
-values and sends everything else to the online phase, while the second split preprocesses the light
X
-values and sends the heavy
X
-values to the online phase. In our example, relation
R_{1}
is split into
{\color[rgb]{0,0,1}h_{S}}(1)+{\color[rgb]{1,0,0}h_{T}}(2|1)
, and each part is sent to a different polymatroid.
Using the coefficients of the above joint Shannon-flow inequality, we get the following intrinsic space-time tradeoff:

S\cdot T^{2}\cong|Q_{13}|^{2}\cdot|\mathcal{D}|^{2}

We will use the
\cong
notation to mean that
S\cdot T^{2}=\widetilde{O}(|Q_{13}|^{2}\cdot|\mathcal{D}|^{2})
. Generally, we show (for a formal definition, see
Theorem D.6
):

Theorem 5.1 (Informal).

Every joint Shannon-flow inequality for a 2-phase disjunctive rule implies a space-time tradeoff computed by reading the coefficients of the inequality.

The above theorem requires that we are given a joint Shannon-flow inequality to obtain a space-time tradeoff. We additionally show that, given a space budget
S
, we can also compute via a linear program the optimal inequality that will result in the best possible answering time.

6.2.
Tradeoffs via Fractional Edge Covers

Let
\varphi(\mathbf{x}_{A}\mid\mathbf{x}_{A})
be a CQAP with hypergraph
([n],\mathcal{E})
of
\varphi
. A fractional edge cover of
S\subseteq[n]
is an assignment
\mathbf{u}=(u_{F})_{F\in\mathcal{E}}
such that
(i)

u_{F}\geq 0
, and
(ii)
for every
i\in S
,
\sum_{F:i\in F}u_{F}\geq 1
. For any fractional edge cover
\mathbf{u}
of
[n]
, we define the
slack
of
\mathbf{u}
w.r.t.
A\subseteq[n]
:

\alpha(\mathbf{u},A)\stackrel{{\scriptstyle\text{def}}}{{=}}\min_{i\notin A}\sum_{F\in\mathcal{E}:i\in F}u_{F}.

In other words, the slack is the maximum factor by which we can scale down the fractional cover
\mathbf{u}
so that it remains a valid edge cover of the variables not in
A
. Hence
(u_{F}/\alpha(\mathbf{u},A))_{F\in\mathcal{E}}
is a fractional edge cover of
[n]\setminus A
. We always have
\alpha(\mathbf{u},A)\geq 1
.

Theorem 6.1.

Let
\varphi(\mathbf{x}_{A}\mid\mathbf{x}_{A})
be a CQAP. Let
\mathbf{u}
be any fractional edge cover of the hypergraph of
\varphi
.
Then, for any input database
\mathcal{D}
, and any access request, the following intrinsic tradeoff holds:

S\cdot T^{\alpha(\mathbf{u},A)}\cong|Q_{A}|^{\alpha(\mathbf{u},A)}\cdot\prod_{F\in\mathcal{E}}|R_{F}|^{u_{F}}

The above theorem can also be shown as a corollary of Theorem 1 in
(
deep2018compressed
)
. However, the data structure used in
(
deep2018compressed
)
is much more involved, since its goal is to also bound the delay during enumeration (while we are interested in total time instead). A simpler construction with the same tradeoff was shown in
(
deep2021space
)
. Our framework recovers the same result using a simple materialization strategy with two PMTDs.

6.3.
Tradeoffs via Tree Decompositions

Let
\varphi(\mathbf{x}_{A}\mid\mathbf{x}_{A})
be a CQAP. In the previous section, we recovered a space-time tradeoff using two trivial PMTDs. Here, we will show how our framework recovers a better space-time tradeoff by considering a larger set of PMTDs that corresponds to one decomposition.

Pick any arbitrary non-redundant free-connex decomposition
(\mathcal{T},\chi,r)
. We start by taking any set of nodes that are not ancestors of each other in the decomposition as a materialization set. Then, for each node
t
in the materialization set, we merge all bags in the subtree of
t
into the bag of
t
(and truncate the subtree). By ranging over all such materialization sets, we construct a fixed (finite) set of PMTDs. We say that this set of PMTDs is
induced
from
(\mathcal{T},\chi,r)
.
We now input the induced set of PMTDs to our general framework. To discuss the obtained space-time tradeoff, take any assignment of a fractional edge cover
\mathbf{u}_{t}
to each node
t\in V(\mathcal{T})
and let
u^{*}_{t}
be its total weight. Let
A_{t}
denote the common variables between node
t
and its parent (for the root,
A_{r}=A
), and define
\alpha_{t}=\alpha(\mathbf{u}_{t},A_{t})
to be the slack in node
t
w.r.t.
A_{t}
. Now, take the nodes
P
of any root-to-leaf path in
\mathcal{T}
. We can show that any such path
P
generates the following intrinsic tradeoff:

S^{\sum_{t\in P}1/\alpha_{t}}\cdot T\cong|Q_{A}|\cdot|\mathcal{D}|^{\sum_{t\in P}u^{*}_{t}/\alpha_{t}}

To obtain the final space-time tradeoff, we take the worst such tradeoff across all root-to-leaf paths. We show in Appendix
E.2
how to obtain this tradeoff, and also show why it recovers prior results
(
deep2021space
)
. Our framework guarantees that adding PMTDs to the induced set we considered here can only make this tradeoff better.

7.
Related Work

Set Intersection and Distance Oracles.

Space-time tradeoffs for query answering (exact and approximate) has been an active area of research across multiple communities in the last decade
(
kociumaka2013efficient
;
afshani2016data
;
larsen2015hardness
;
Cohen2010
)
. Cohen and Porat
(
Cohen2010
)
introduced the fast intersection problem and presented a data structure to enumerate the intersection of two sets with guarantees on the total answering time. Goldstein et. al
(
goldstein2017conditional
)
formulated the
k
-reachability problem on graphs, and showed a simple recursive data structure which achieves the
S\cdot T^{2/(k-1)}=O(|\mathcal{D}|^{2})
tradeoff. They also conjectured that the tradeoff is optimal and used it to justify the optimality of an approximate distance oracle proposed by
(
agarwal2014space
)
. The study of (approximate) distance oracles over graphs was initiated by Patrascu and Roditty
(
patrascu2010distance
)
, where lower bounds are shown on the size of a distance oracle for sparse graphs based on a conjecture about the best possible data structure for a set intersection problem. Cohen and Porat
(
cohen2010hardness
)
also connected set intersection to distance oracles. Agarwal et al.
(
agarwal2011approximate
;
agarwal2014space
)
introduced the notion of
stretch
of an oracle that controls the error allowed in the answer. Further, for stretch-2 and stretch-3 oracles, we can achieve tradeoffs
S\cdot T=O(|\mathcal{D}|^{2})
and
S\cdot T^{2}=O(|\mathcal{D}|^{2})
respectively, and for any integer
k>0
, a stretch-
(1+1/k)
oracle exhibits an
S\cdot T^{1/k}=O(|\mathcal{D}|^{2})
tradeoff. Unfortunately, no lower bounds are known for non-constant query time.

Space/Delay Tradeoffs.
A different line of work considers the problem of enumerating query results of a non-Boolean query, with the goal of minimizing the
delay
between consecutive tuples of the output. In constant delay enumeration
(
Segoufin13
;
BaganDG07
)
, the goal is to achieve constant delay for a CQ after a preprocessing step of linear time (and space); however, only a subset of CQs can achieve such a tradeoff. Factorized databases
(
OlteanuZ15
)
achieve constant delay enumeration after a more expensive super-linear preprocessing step for any CQ. If we want to reduce preprocessing time further, it is necessary to increase the delay. Kara et. al
(
kara19
)
presented a tradeoff between preprocessing time and delay for enumerating the results of any hierarchical CQ under static (and dynamic) settings. Deng et.al
(
DBLP:conf/icdt/DengL023
)
initiates the study of the space-query tradeoffs for range subgraph counting and range subgraph listing problems. The problem of CQs with access patterns was first introduced by Deep and Koutris
(
deep2018compressed
)
(under the restriction
|Q_{A}|=1
), but the authors only consider full CQAPs. Previous work
(
X17
)
considered the problem of constructing space-efficient views of graphs to perform graph analytics, but did not offer any theoretical guarantees. More recently, Kara et. al
(
CQAP
)
studied tradeoffs between preprocessing time, delay, and update time for CQAPs. They characterized the class of CQAPs that admit linear preprocessing time, constant delay enumeration, and constant update time.
All of the above results concern the tradeoff between space (or preprocessing time) and delay, while our work focuses on the total time to answer the query. Our work is most closely related to the non-peer-reviewed work in
(
deep2021space
)
. There, the authors also study the problem of building tradeoffs for Boolean CQs. The authors propose two results that slightly improve upon
(
deep2018compressed
)
. They were also the first to recognize that the
k
-reachability tradeoff is not optimal by proposing a small improvement for
k\geq 3
. The results in our work are a vast generalization that is achieved using a more comprehensive framework. For the dynamic setting,
(
berkholz2017answering
)
initiated the study of answering CQs under updates. Recently,
(
kara2019counting
)
presented an algorithm for counting the number of triangles under updates.
(
CQAP
)
proposed dynamic algorithms for CQAPs and provided a syntactic characterization of queries that admit constant time per single-tuple update and whose output tuples can be enumerated with constant delay.

CQ Evaluation.
Our proposed framework is based on recent advances in efficient CQ evaluation, and in particular the
PANDA
algorithm
(
DBLP:conf/pods/Khamis0S17
)
. This powerful algorithmic result follows a long line of work on query decompositions
(
gottlob2014treewidth
;
Marx13
;
Marx10
)
, worst-case optimal algorithms
(
NgoRR13
)
, and connections between CQ evaluation and information theory
(
KhamisNR16
;
KhamisK0S20
)
.

8.
Conclusion

In this paper, we present a framework for computing general space-time tradeoffs for answering CQs with access patterns. We show the versatility of our framework by demonstrating how it can capture state-of-the-art tradeoffs for problems that have been studied separately. The application of our framework has also uncovered previously unknown tradeoffs. Many open problems remain, among which are obtaining (conditional) lower bounds that match our upper bounds, and investigating how to make our approach practical.

Many open problems remain that merit further work. In particular, there are no known lower bounds to prove the optimality of the space-time tradeoffs. The optimality of existing space-time tradeoffs for approximate distance oracles is also now an open problem again and we believe our proposed framework should be able to improve the upper bounds. It would also be very interesting to see the applicability of this framework in practice. In particular, our framework can be extended to also include views that have been precomputed, which is a common setting. In this regard, challenges remain to optimize the constants in the time complexity to ensure implementation feasibility.

Algorithms for 2-phase Disjunctive Rules

Let
\rho
be a 2-phase disjunctive rule taking the form (
5
), under degree constraints
\mathsf{DC}
(guarded by input relations) and degree constraints
\mathsf{AC}
(guarded by access request
Q_{A}
).
In this section, we introduce a naïve algorithm that uses the
\mathsf{PANDA}
algorithm to obtain a model of
\rho
in two phases. First, we present some necessary terminologies and results.

C.1.
Background

Entropic Functions.

Given a disjunctive rule
(
4
)
, a set function
h:2^{[n]}\rightarrow\mathbb{R}_{+}
is
entropic
if there is a joint probability distribution on
[n]
such that
h(F)
is the marginal entropy of
F
for any
F\subseteq[n]
. Let
\Gamma_{n}^{*}
be the set of all entropic functions and
h(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}h(Y)-h(X)
. Under a given set of degree constraints
\mathsf{DC}
, any joint distribution on
[n]
conforms to the constraints
h(Y|X)\leq n_{Y|X}
, where
n_{Y|X}\stackrel{{\scriptstyle\text{def}}}{{=}}\log N_{Y|X}
, for each
(X,Y,N_{Y|X})\in\mathsf{DC}
.

Polymatroid.

A polymatroid is a set function
h:2^{[n]}\rightarrow\mathbb{R}_{+}
that is non-negative, monotone, and submodular, with
h(\emptyset)=0
. To be precise, monotonicity implies that
h(Y)\geq h(X)
for any
X\subseteq Y\subseteq[n]
and let
h(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}h(Y)-h(X)
, then submodularity implies that
h(I|I\cap J)\geq h(I\cup J|J)
for any
I,J\subseteq[n]
. Let
\Gamma_{n}
be the set of all polymatroids on
[n]
. As every entropic function is a polymatroid, it holds that
\Gamma_{n}^{*}\subseteq\Gamma_{n}
.

Size Bound for Disjunctive Rules.
Let
\rho
be a disjunctive rule of the form (
4
). Let
\mathcal{D}
be a database instance under a given set of degree constraints
\mathsf{DC}
. The set

\mathsf{HDC}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{h:2^{[n]}\rightarrow\mathbb{R}_{+}|\bigwedge_{\left(X,Y,N_{Y|X}\right)\in\mathsf{DC}}h(Y|X)\leq\log N_{Y|X}\right\}

contains all entropic functions
h
on
[n]
satisfying the degree constraints
\mathsf{DC}
. Fix a closed subset
\mathcal{F}\subseteq\mathbb{R}^{2^{n}}_{+}
. We define the log-size-bound with respect to
\mathcal{F}
of a disjunctive rule
\rho
to be the quantity:

\mathsf{LogSizeBound}_{\mathcal{F}}(\rho)\stackrel{{\scriptstyle\text{def}}}{{=}}\max_{h\in\mathcal{F}}\min_{B\in\mathsf{BT}}h(B)

Then for the output size of
\rho
, we have the following theorem
(see Theorem 1.5 in
[
24
]
)
:

Theorem C.1 (
[
24
]
).

Let
\rho
be any disjunctive rule (
4
) under degree constraints
\mathsf{DC}
. Then for any database instance
\mathcal{D}
satisfying
\mathsf{DC}
, the following holds:

\log|\rho|\leq\underbrace{\mathsf{LogSizeBound}_{\Gamma_{n}^{*}\cap\mathsf{HDC}}(\rho)}_{\textit{entropic bound}}\leq\underbrace{\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}}_{\textit{polymatroid bound}}(\rho),

The entropic bound is tight under degree constraints in the worst case. However, its computation is often hard in general. The polymatroid bound is tight if
\rho
is a CQ (i.e. has a single target) and there are only cardinality constraints, in which case the polymatroid bound degenerates into the AGM bound. However, it is not tight under general degree constraints.

The
\mathsf{PANDA}
Algorithm.
Given a disjunctive rule
\rho
of the form (
4

\mathsf{PANDA}
algorithm takes a database instance
\mathcal{D}
, a set of degree constraint
\mathsf{DC}
(guarded by

\widetilde{O}(2^{\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}(\rho)}).

The reader can refer to Theorem 1.7 in
[
24
]
for details.
For now, we will treat

algorithm as a blackbox; we will later present how it works.

C.2.
The 2-phase Framework

In this section, we introduce a 2-phase algorithmic framework that we will follow to design 2-phase algorithms for a 2-phase disjunctive rule of the form
(
5
).

Let
\mathcal{D}
be a database instance and
Q_{A}
be an arbitrary access request. We assume that
hash tables on necessary index keys (of input relations and degrees of tuples in input relations)
can be pre-built at the start of the preprocessing phase as needed by the framework. That is, we assume constant-time accesses of tuples and degrees of tuples in the input relations during both phases. There are at most
O(2^{2n})
hash tables to be pre-built per input relation
R_{F}
(that is, for every
(Y,X)
-pair where
X\subset Y\subseteq F\in\mathcal{E}
), so the space cost for storing all necessary hash tables is
O(|\mathcal{D}|)
in data complexity. Recall that we also assume w.l.o.g the following
best constraint assumption
: we only keep at most one
(X,Y,N_{Y|X})\in\mathsf{DC}
for each
X\subset Y\subseteq[n]
(keep the minimum
N_{Y|X}
if there are more than one).

Split Steps.
Let
R\in\mathcal{D}
be the guard of a cardinality constraint
(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
. A
split step
on a
(Y,X)
-pair, where
\emptyset\neq X\subset Y\subseteq Z
, applies Lemma 6.1 of
[
24
]
and partitions
R_{Y}\stackrel{{\scriptstyle\text{def}}}{{=}}\Pi_{Y}(R)
into
k=2\log N_{Z\mid\emptyset}
sub-tables, i.e.
R_{Y}^{(1)},\ldots,R_{Y}^{(k)}
, such that
N_{X|\emptyset}^{(j)}\cdot N_{Y|X}^{(j)}\leq N_{Z\mid\emptyset}
, for all
j\in[k]
, where

\displaystyle N_{X|\emptyset}^{(j)}

\displaystyle\stackrel{{\scriptstyle\text{def}}}{{=}}\left|\Pi_{X}(R_{Y}^{(j)})\right|

\displaystyle N_{Y|X}^{(j)}

\displaystyle\stackrel{{\scriptstyle\text{def}}}{{=}}\deg_{R_{Y}^{(j)}}(Y|X).

For each of these sub-tables
R_{Y}^{(j)}
, we create a subproblem with inputs
(\mathcal{D}^{(j)},\mathsf{DC}^{(j)})
, where
\mathcal{D}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\mathcal{D}\cup\{R_{Y}^{(j)}\}
denotes the input tables and

\mathsf{DC}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\mathsf{DC}\cup\left\{(\emptyset,X,N_{X|\emptyset}^{(j)}),(X,Y,N_{Y|X}^{(j)})\right\}

denotes the degree constraints guarded by
\mathcal{D}^{(j)}
.

A sequence of split steps
on
(Y_{1},X_{1}),(Y_{2},X_{2}),\ldots,(Y_{\ell},X_{\ell})
, applies the first split step on the
(Y_{1},X_{1})
-pair, generating
k_{1}=O(\log|\mathcal{D}|)
subproblems with inputs
(\mathcal{D}^{(j)},\mathsf{DC}^{(j)})
, where
j\in[k_{1}]
. Then, for each subproblem, applies the second split step on the
(Y_{2},X_{2})
-pair, generating
O((\log|\mathcal{D}|)^{2})
subproblems. This iterative process goes on until every split step in the sequence is applied, thus it generates
O(poly(\log|\mathcal{D}|))
subproblems in total.

The 2-phase Framework.

Now we formally characterize our 2-phase algorithmic framework. Let
S
be the given space budget. We denote the task of obtaining a model for a 2-phase disjunctive rule
\rho
(of the form (
5
)) with input relations
\mathcal{D}\cup\{Q_{A}\}
satisfying degree constraints
\mathsf{DC}\cup\mathsf{AC}
as
\rho(\mathcal{D}\cup\{Q_{A}\},\mathsf{DC}\cup\mathsf{AC})

split steps
to partition
\rho(\mathcal{D}\cup\{Q_{A}\},\mathsf{DC}\cup\mathsf{AC})
into
O(poly(\log|\mathcal{D}|))
subproblems. Then, the
j
-th subproblem with input
\mathcal{D}^{(j)}
and degree constraint
\mathsf{DC}^{(j)}\supseteq\mathsf{DC}
, denoted as
\rho(\mathcal{D}^{(j)}\cup\{Q_{A}\},\mathsf{DC}^{(j)}\cup\mathsf{AC})
, either

(1)

generates
S
-targets
(S_{B}^{(j)})_{B\in\mathsf{BS}}
as a model of the preprocessing disjunctive rule
\rho_{S}
of the form (
6
) using
\mathsf{PANDA}
, provided that the output size of
\rho_{S}
is within
\widetilde{O}(S)
; or

(2)

generates
T
-targets
(T_{B}^{(j)})_{B\in\mathsf{BT}}
as a model of the online disjunctive rule
\rho_{T}
of the form (
7

\mathsf{PANDA}
.

In other words, the subproblem
\rho(\mathcal{D}^{(j)}\cup\{Q_{A}\},\mathsf{DC}^{(j)}\cup\mathsf{AC})
is conquered by applying
\mathsf{PANDA}
to obtain either a model
\rho_{S}
with input relations
\mathcal{D}^{(j)}
under degree constraint
\mathsf{DC}^{(j)}
, denoted as
\rho_{S}(\mathcal{D}^{(j)},\mathsf{DC}^{(j)})
, or a model of
\rho_{T}
with input relations
\mathcal{D}^{(j)}\cup\{Q_{A}\}
under degree constraint
\mathsf{DC}^{(j)}\cup\mathsf{AC}

-targets and

Analysis of the 2-phase Framework.
Next, we analyze the intrinsic space-time tradeoff (specified in
Subsection 4.1
, between
S_{\rho}
and
T_{\rho}
) that can be obtained by the 2-phase framework introduced above. First, the split steps incur a poly-logarithmic factor on both
S_{\rho}
and
T_{\rho}
and spawn
O(poly(\log|\mathcal{D}|))
subproblems. Then, the
j
-th spawned subproblem
\rho(\mathcal{D}^{(j)}\cup\{Q_{A}\},\mathsf{DC}^{(j)}\cup\mathsf{AC})
is conquered by
\mathsf{PANDA}
in one of the two phases. Note that
\mathsf{DC}^{(j)}\supseteq\mathsf{DC}
contains extra degree constraints due to the split steps. For ease of analysis, we separate out the extra constraints by defining a set
\mathsf{SC}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\mathsf{DC}^{(j)}\setminus\mathsf{DC}
. To apply the polymatroid bound, we use two polymatroids,
{\color[rgb]{0,0,1}h_{S}}\in\Gamma_{n}
to represent the preprocessing phase and
{\color[rgb]{1,0,0}h_{T}}\in\Gamma_{n}
to represent the online phase. We define

\mathsf{HDC}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{h:2^{[n]}\rightarrow\mathbb{R}_{+}|\bigwedge_{\left(X,Y,N_{Y|X}\right)\in\mathsf{DC}}h(Y|X)\leq\log N_{Y|X}\right\}

\mathsf{HSC}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{h:2^{[n]}\rightarrow\mathbb{R}_{+}|\bigwedge_{\left(X,Y,N_{Y|X}\right)\in\mathsf{SC}^{(j)}}h(Y|X)\leq\log N_{Y|X}\right\}

\mathsf{HAC}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{h:2^{[n]}\rightarrow\mathbb{R}_{+}|\bigwedge_{\left(X,Y,N_{Y|X}\right)\in\mathsf{AC}}h(Y|X)\leq\log N_{Y|X}\right\}

where
h(Y|X)=h(Y)-h(X)
, to denote collections of set functions that satisfy
\mathsf{DC}
,
\mathsf{SC}^{(j)}
and
\mathsf{AC}
, respectively. The 2-phase framework enforces that
{\color[rgb]{0,0,1}h_{S}}
conforms to
\mathsf{HDC}\cap\mathsf{HSC}^{(j)}
and
{\color[rgb]{1,0,0}h_{T}}
conforms to
\mathsf{HDC}\cap\mathsf{HSC}^{(j)}\cap\mathsf{HAC}
. Thus, the
j
-th subproblem costs space
\widetilde{O}(S_{\rho}^{(j)})
in the preprocessing phase, where

(10)

\displaystyle\log S_{\rho}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\mathsf{LogSizeBound}_{{\color[rgb]{0,0,1}h_{S}}\in\Gamma_{n}\cap\mathsf{HDC}\cap\mathsf{HSC}^{(j)}}(\rho_{S})

provided that
S_{\rho}^{(j)}\leq S
. Otherwise,
j
-th subproblem costs time (and space)
\widetilde{O}(T_{\rho}^{(j)})
, where

(11)

\displaystyle\log T_{\rho}^{(j)}\stackrel{{\scriptstyle\text{def}}}{{=}}\mathsf{LogSizeBound}_{{\color[rgb]{1,0,0}h_{T}}\in\Gamma_{n}\cap\mathsf{HDC}\cap\mathsf{HSC}^{(j)}\cap\mathsf{HAC}}(\rho_{T})

By conquering all subproblems, we conclude that
S_{\rho}=\max_{j}S_{\rho}^{(j)}\leq S
and
T_{\rho}=\max_{j}T_{\rho}^{(j)}
.

C.3.
A Naïve 2-phase Algorithm

In this section, we use the 2-phase framework to design a 2-phase algorithm for a 2-phase disjunctive rule
\rho
that attains the smallest possible
T_{\rho}
for a fixed space budget
S
.

Recall that for each
(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
, there are at most
2^{2n}

(Y,X)
-pairs with
\emptyset\neq X\subset Y\subseteq Z
. Thus, the total number of distinct split steps is a constant in data complexity. To exploit the full potential of split steps, we design a naïve 2-phase algorithm that applies a sequence of all distinct split steps. Also, recall that a finite sequence of split steps spawns
O(poly(\log|\mathcal{D}|))
subproblems.

The Naïve Algorithm.

As said, the naïve algorithm first applies a sequence of all distinct split steps. Intuitively, this partitions
\mathcal{D}
into its most fine-grained pieces. Let
\rho(\mathcal{D}^{(j)}\cup\{Q_{A}\},\mathsf{DC}^{(j)}\cup\mathsf{AC})
be the
j
-th subproblem spawned after the sequence of all distinct split steps. Recall that
\mathsf{SC}^{(j)}=\mathsf{DC}^{(j)}\setminus\mathsf{DC}
. The following
splitting property
is a direct result of a sequence of all distinct split steps on
\mathsf{DC}
: for any
(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
and
(Y,X)
-pair with
\emptyset\neq X\subset Y\subseteq Z
, there are some
(\emptyset,X,N_{X|\emptyset}^{(j)}),(X,Y,N_{Y|X}^{(j)})\in\mathsf{SC}^{(j)}
such that
N_{X|\emptyset}^{(j)}\cdot N_{Y|X}^{(j)}\leq N_{Z|\emptyset}
.
Though each subproblem varies in its own
\mathsf{SC}^{(j)}
, the splitting property holds across all subproblems. To encode the splitting property, we define split constraints.

Definition C.2 (Split Constraints).

Let
\mathsf{DC}
be a set of degree constraints. A
split constraint
is a triple
(X,Y|X,N_{Z|\emptyset})
where
\emptyset\neq X\subset Y\subseteq Z,(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
. A relation
R_{F}
is said to guard a split constraint
(X,Y|X,N_{Z|\emptyset})
if
R_{F}
guards
(\emptyset,Z,N_{Z|\emptyset})
. The set of all split constraints spanned from
\mathsf{DC}
, is denoted as

\mathsf{SC}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{(X,Y|X,N_{Z|\emptyset})\mid\emptyset\neq X\subset Y\subseteq Z,(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}\right\}.

Intuitively, each triple
(X,Y|X,N_{Z|\emptyset})\in\mathsf{SC}
encodes the splitting property for the
(Y,X)
-pair on
(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
. Since we assume that every
(\emptyset,Z,N_{Z|\emptyset})\in\mathsf{DC}
has at least one guard, every
(X,Y|X,N_{Z|\emptyset})\in\mathsf{SC}
is guarded by some
R_{F}\in\mathcal{D}
.

The naïve algorithm stores
S
-views for

\rho_{S}(\mathcal{D}^{(j)},\mathsf{DC}^{(j)})
whenever its polymatroid bound, as specified in (
10
), is no larger than
\log S
. Otherwise, it applies
\mathsf{PANDA}
algorithm as a black box for
\rho_{T}(\mathcal{D}^{(j)}\cup\{Q_{A}\},\mathsf{DC}^{(j)}\cup\mathsf{AC})
in the online phase in time as specified in (
11
).

Analysis of the Naïve Algorithm.

The naïve algorithm exploits the full potential of the framework (by exhausting all possible split steps) and gets the best possible
T_{\rho}
when
S_{\rho}\leq S
(up to a poly-logarithmic factor). In particular, we state the following theorem for the best possible
T_{\rho}
:

Theorem C.3.

For a 2-phase disjunctive rule (
5
), under space budget
S
, the naïve algorithm obtains
T_{\rho}=2^{\mathsf{OBJ}(S)}
, where

(12)

\displaystyle\mathsf{OBJ}(S)=\max_{\begin{subarray}{c}{\color[rgb]{0,0,1}h_{S}}\in\mathsf{HDC},{\color[rgb]{1,0,0}h_{T}}\in\mathsf{HDC}\cap\mathsf{HAC}\\
({\color[rgb]{0,0,1}h_{S}},{\color[rgb]{1,0,0}h_{T}})\in(\Gamma_{n}\times\Gamma_{n})\cap\mathsf{HSC}\end{subarray}}

\displaystyle\min_{B\in\mathsf{BT}}{\color[rgb]{1,0,0}h_{T}}(B)

\displaystyle\textit{s.t. }

\displaystyle\color[rgb]{0,0,1}{\displaystyle h_{S}}(B)>\log S,

\displaystyle B\in\mathsf{BS},

assuming that
\mathsf{OBJ}(S)
is postive and bounded.

Proof.

Merging (
10
) and (
11
), we get that
\log T_{\rho}^{(j)}
for the
j
-th subproblem can be expressed as

(13)

\displaystyle\log T^{(j)}_{\rho}=\max_{\begin{subarray}{c}{\color[rgb]{0,0,1}h_{S}}\in\mathsf{HDC}\cap\mathsf{HSC}^{(j)}\\
{\color[rgb]{1,0,0}h_{T}}\in\mathsf{HDC}\cap\mathsf{HSC}^{(j)}\cap\mathsf{HAC}\\
{\color[rgb]{0,0,1}h_{S}},{\color[rgb]{1,0,0}h_{T}}\in\Gamma_{n}\end{subarray}}

\displaystyle\min_{B\in\mathsf{BT}}{\color[rgb]{1,0,0}h_{T}}(B)

\displaystyle\textit{s.t. }

\displaystyle\color[rgb]{0,0,1}{\displaystyle h_{S}}(B)>\log S,

\displaystyle B\in\mathsf{BS}.

Note that the maximin optimization (
13
) is subproblem-dependent, since it is constrained on
\mathsf{HSC}^{(j)}
. To avoid this dependency, we recall that the naïve algorithm dictates the splitting property. Thus, we define the (subproblem-independent) set
\mathsf{SC}
as follows:

\displaystyle\mathsf{HSC}\stackrel{{\scriptstyle\text{def}}}{{=}}\left\{({\color[rgb]{0,0,1}h_{S}},{\color[rgb]{1,0,0}h_{T}}):2^{[n]}\times 2^{[n]}\rightarrow\mathbb{R}^{2}_{+}|\bigwedge_{(X,Y|X,N_{Z|\emptyset})\in\mathsf{SC}}({\color[rgb]{0,0,1}h_{S}}(X)+{\color[rgb]{1,0,0}h_{T}}(Y|X)\leq\log N_{Z|\emptyset})\wedge({\color[rgb]{0,0,1}h_{S}}(Y|X)+{\color[rgb]{1,0,0}h_{T}}(X)\leq\log N_{Z|\emptyset})\right\},

where
{\color[rgb]{0,0,1}h_{S}}(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}{\color[rgb]{0,0,1}h_{S}}(Y)-{\color[rgb]{0,0,1}h_{S}}(X),{\color[rgb]{1,0,0}h_{T}}(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}{\color[rgb]{1,0,0}h_{T}}(Y)-{\color[rgb]{1,0,0}h_{T}}(X)
.
\mathsf{HSC}
is a universal collection of set functions pairs
satisfying the splitting property and thus, it correlates
{\color[rgb]{0,0,1}h_{S}}
and
{\color[rgb]{1,0,0}h_{T}}
. Since every subproblem satisfies the splitting property, it holds that
\mathsf{HSC}^{(j)}\times\mathsf{HSC}^{(j)}\subseteq\mathsf{HSC}
. By relaxing
\mathsf{HSC}^{(j)}\times\mathsf{HSC}^{(j)}
to
\mathsf{HSC}
, we get the desired upper bound (
12
) for
T_{\rho}
.
∎

By assigning
{\color[rgb]{1,0,0}h_{T}}
to be always
0
, it is easy to see that the feasible region of (
12
) is empty if and only if

\mathsf{LogSizeBound}_{{\color[rgb]{0,0,1}h_{S}}\in\Gamma_{n}\cap\mathsf{HDC}}(\rho_{S})\leq\log S,

in which case we can simply store the
S
-views within space
\widetilde{O}(S)
. Otherwise, the feasibility of (
12
) is guaranteed. However, the naïve algorithm has the following drawbacks in terms of practicality:
(1)
the exhaustive splitting steps can incur a large poly-logarithmic factor;
(2)
for every subproblem, we need to run
\mathsf{PANDA}
from scratch with a new instance,
(3)
the space-time tradeoff obtained is hard to interpret. In the following sections, we introduce the 2-phase
\mathsf{PANDA}
algorithm, called
\mathsf{2PP}
, that also attains the intrinsic tradeoff as specified in (
12
), while efficiently addressing these two drawbacks and it obtains much practical/interpretable intrinsic tradeoff(s).

Appendix D
The
\mathsf{2PP}
algorithm

The 2-phase
\mathsf{PANDA}
(
\mathsf{2PP}
) algorithm, similar to
\mathsf{PANDA}
, is built on a class of inequalities called the joint Shannon-flow inequalities. In this section, we first present some background on Shannon-flow inequalities, and then our extension to joint inequalities. Finally, we present the
\mathsf{2PP}
algorithm.

D.1.
Shannon-flow Inequalities

The following inequality

(14)

\displaystyle\sum_{X\subset Y\subseteq[n]}\delta_{Y|X}\cdot h(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}\sum_{X\subset Y\subseteq[n]}\delta_{Y|X}\cdot(h(Y)-h(X))\geq\sum_{\emptyset\neq Z\subseteq[n]}\lambda_{Z|\emptyset}\cdot h(Z|\emptyset),

is called a
Shannon-flow inequality
if it holds for any polymatroid function
h\in\Gamma_{n}
and all
\delta_{Y|X}
and
\lambda_{Z|\emptyset}
are some non-negative rational coefficients, i.e.,
\delta_{Y|X},\lambda_{Z|\emptyset}\in\mathbb{Q}_{+}
. To concisely represent Shannon-flow inequalities, we define the conditional polymatroid as in
[
24
]
.

Conditional Polymatroids.

Let
\mathcal{C}\subseteq 2^{[n]}\times 2^{[n]}
denote the set of all pairs
(X,Y)
such that
\emptyset\subseteq X\subset Y\subseteq[n]
. A vector
\boldsymbol{h}\in\mathbb{R}^{\mathcal{C}}_{+}
has coordinates indexed by pairs
(X,Y)\in\mathcal{C}
and we denote the corresponding coordinate value of
\boldsymbol{h}
by
h(Y|X)
. A vector
\boldsymbol{h}
is called a
conditional polymatroid
if and only if there is a polymatroid
h
such that
h(Y|X)=h(Y)-h(X)
; and, we say that the polymatroid
h
defines the conditional polymatroid
\boldsymbol{h}
. In particular,
\boldsymbol{h}=(h(Y|X))_{(X,Y)\in\mathcal{C}}
.

If for (
14
), we define
\lambda_{Z|X}=0
for any
\emptyset\neq X\subset Z\subseteq[n]
, then each of
\{\delta_{Y|X}\},\{\lambda_{Y|X}\}
can be interpreted as vectors over
(X,Y)
pairs, where
\emptyset\subseteq X\subset Y\subseteq[n]
. We denote them as
\boldsymbol{\delta},\boldsymbol{\lambda}
, respectively. Thus, the Shannon-flow inequality (
14
) can be re-written into an inequality on conditional polymatroids, i.e. the
\mathbb{Q}_{+}^{\mathcal{C}}
space, as
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
, where
\langle\cdot,\cdot\rangle
denotes dot product.

Proof Sequences.
One of the major contributions from
[
24
]
says that any Shannon-flow inequality
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
can be proved by just applying the following
4
rules:

(R1)

submodularity rule

\displaystyle h(I\cup J|J)-h(I|I\cap J)

\displaystyle\leq 0,\quad I\perp J

(R2)

monotonicity rule

\displaystyle-h(Y|\emptyset)+h(X|\emptyset)

\displaystyle\leq 0,\quad X\subset Y

(R3)

composition rule

\displaystyle h(Y|\emptyset)-h(Y|X)-h(X|\emptyset)

\displaystyle\leq 0,\quad X\subset Y

(R4)

decomposition rule

\displaystyle-h(Y|\emptyset)+h(Y|X)+h(X|\emptyset)

\displaystyle\leq 0,\quad X\subset Y

where
I\perp J
means
I\nsubseteq J
and
J\nsubseteq I
.
(R1)
and
(R2)
come exactly from the submodularity and monotonicity properties of polymatroids.
(R3)
and
(R4)
simply follow from the definition of
h(Y|X)=h(Y)-h(X)
. All the rules can also be vectorized over all
(X,Y)
pairs, where
\emptyset\subseteq X\subset Y\subseteq[n]
. For every
I\perp J
, we define a vector
\boldsymbol{s}_{I,J}
, and for every
X\subset Y
, we define three vectors
\boldsymbol{m}_{X,Y},\boldsymbol{c}_{X,Y},\boldsymbol{d}_{Y,X}
such that the linear rules above can be written using dot-products:

(R1)

submodularity rule

\displaystyle\langle\boldsymbol{s}_{I,J},\boldsymbol{h}\rangle

\displaystyle\leq 0,\quad I\perp J

(R2)

monotonicity rule

\displaystyle\langle\boldsymbol{m}_{X,Y},\boldsymbol{h}\rangle

\displaystyle\leq 0,\quad X\subset Y

(R3)

composition rule

\displaystyle\langle\boldsymbol{c}_{X,Y},\boldsymbol{h}\rangle

\displaystyle\leq 0,\quad X\subset Y

(R4)

decomposition rule

\displaystyle\langle\boldsymbol{d}_{Y,X},\boldsymbol{h}\rangle

\displaystyle\leq 0,\quad X\subset Y

A
proof sequence
of a Shannon-flow inequality
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
is a sequence
\mathsf{ProofSeq}\stackrel{{\scriptstyle\text{def}}}{{=}}(w_{1}\boldsymbol{f}_{1},w_{2}\boldsymbol{f}_{2},\ldots,w_{\ell}\boldsymbol{f}_{\ell})
of length
\ell
satisfying all of the following:

(1)

\boldsymbol{f}_{i}\in\{\boldsymbol{s}_{I,J},\boldsymbol{m}_{X,Y},\boldsymbol{c}_{X,Y},\boldsymbol{d}_{Y,X}\}
for every
i\in[\ell]
, called a
proof step
;

(2)

w_{i}\in\mathbb{Q}_{+}
for every
i\in[\ell]
, called the
weight
of the proof step
\boldsymbol{f}_{i}
;

(3)

the vectors
\boldsymbol{\delta}_{0}\stackrel{{\scriptstyle\text{def}}}{{=}}\boldsymbol{\delta},\boldsymbol{\delta}_{1},\ldots,\boldsymbol{\delta}_{\ell}
defined by
\boldsymbol{\delta}_{i}=\boldsymbol{\delta}_{i-1}+w_{i}\cdot\boldsymbol{f}_{i}
are non-negative rational vectors;

(4)

\boldsymbol{\delta}_{\ell}\geq\boldsymbol{\lambda}
(element-wise comparison).

A proof sequence
(w_{1}\boldsymbol{f}_{1},w_{2}\boldsymbol{f}_{2},\ldots,w_{\ell}\boldsymbol{f}_{\ell})
implies the following inequalities for all polymatroids
h\in\Gamma_{n}
,

\langle\boldsymbol{\delta},\boldsymbol{h}\rangle=\langle\boldsymbol{\delta}_{0},\boldsymbol{h}\rangle\geq\cdots\geq\langle\boldsymbol{\delta}_{\ell},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle,

which provides a step-by-step proof for the Shannon-flow inequality
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
. The following theorem (also Theorem 2 in
[
35
]
) is a direct result from Theorem B.12 and Proposition B.13 in
[
24
]
.

Theorem D.1 (
[
24
]
).

For any Shannon-flow inequality
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
such that
\|\boldsymbol{\lambda}\|_{1}=1
, there is a proof sequence of length
O(poly(2^{n}))
.

Theorem D.1
implies that there is a proof sequence for a Shannon-flow inequality that is exponentially long in the number of variables
n
, but it is of constant length under fixed query sizes.

D.2.
Joint Shannon-flow Inequalities

To motivate our study of joint Shannon-flow inequalities, we first give a characterization of the optimal objective value of the maximin optimization problem (
12
),
\mathsf{OBJ}(S)
, through the following class of LPs

(15)

\mathbf{L}(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}},S)\stackrel{{\scriptstyle\text{def}}}{{=}}\max_{\begin{subarray}{c}{\color[rgb]{0,0,1}h_{S}}\in\mathsf{HDC},{\color[rgb]{1,0,0}h_{T}}\in\mathsf{HDC}\cap\mathsf{HAC}\\

parameterized by two vectors,
\boldsymbol{\lambda}_{\mathsf{BT}}\stackrel{{\scriptstyle\text{def}}}{{=}}(\lambda_{B})_{B\in\mathsf{BT}}\in{\mathbb{Q}_{+}^{\mathsf{BT}}}
with

and
\boldsymbol{\theta}_{\mathsf{BS}}\stackrel{{\scriptstyle\text{def}}}{{=}}(\theta_{B})_{B\in\mathsf{BS}}\in{\mathbb{Q}_{+}^{\mathsf{BS}}}
. Equivalently, any

(16)

\displaystyle(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})\in\left\{(\mathbf{a}_{T},\mathbf{a}_{S})\mid\mathbf{a}_{T}\in\mathbb{Q}_{+}^{\mathsf{BT}},\mathbf{a}_{S}\in\mathbb{Q}_{+}^{\mathsf{BS}},\|\mathbf{a}_{T}\|_{1}=1\right\}

gives rise to an LP of the form (
15
) with optimal objective value
\mathbf{L}(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}},S)
.

Lemma D.2.

Let
S
be a fixed quantity. For any
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
as specified in (
16
), the optimal objective value of (
12
),
\mathsf{OBJ}(S)
satisfies,

\mathsf{OBJ}(S)\leq\mathbf{L}(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}},S)

Moreover, assuming that
\mathsf{OBJ}(S)
is positive and bounded, there is an optimal
(\boldsymbol{\lambda}^{*}_{\mathsf{BT}},\boldsymbol{\theta}^{*}_{\mathsf{BS}})
satisfying (
16
) such that

\mathsf{OBJ}(S)=\mathbf{L}(\boldsymbol{\lambda}^{*}_{\mathsf{BT}},\boldsymbol{\theta}^{*}_{\mathsf{BS}},S).

Instead of proving
Lemma D.2
directly, we prove a slightly more general lemma (Lemma
D.3
) that may be of independent interest.

Lemma D.3.

Let
\boldsymbol{A}\in\mathbb{Q}^{\ell\times m},\boldsymbol{b}\in\mathbb{R}^{\ell},\boldsymbol{D}\in\mathbb{Q}_{+}^{m\times{\color[rgb]{0,0,0}{\noindent q}}}

be a matrix with columns

and polyhedron

be the optimal objective value of the following optimization problem (assume

(17)

\displaystyle\max_{\mathbf{x}\in P}

\displaystyle\min_{k\in[p]}\boldsymbol{c}_{k}^{\top}\mathbf{x}

\displaystyle\quad\text{s.t. }

\displaystyle\boldsymbol{D}^{\top}\mathbf{x}\geq\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S.

If
w^{*}
is positive and bounded, then for any vectors
\mathbf{z},\mathbf{u}\in\mathbb{Q}_{+}^{p}

\|\mathbf{z}\|_{1}=1

(18)

\displaystyle L(\mathbf{z},\mathbf{u})\stackrel{{\scriptstyle\text{def}}}{{=}}\max_{\mathbf{x}\in P}

\displaystyle(\boldsymbol{C}\mathbf{z})^{\top}\mathbf{x}+(\boldsymbol{D}^{\top}\mathbf{x}-\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}

satisfies
w^{*}\leq L(\mathbf{z},\mathbf{u})
. In particular, there is a pair of vectors
\mathbf{z}^{*}\in\mathbb{Q}_{+}^{p},\mathbf{u}^{*}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}}

\|\mathbf{z}^{*}\|_{1}=1
such that
w^{*}=L(\mathbf{z}^{*},\mathbf{u}^{*})
.

Proof.

First, we introduce
\mathbf{u}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}}
as the Lagrange multiplier for (
17
) and obtain

\displaystyle w^{*}

\displaystyle\leq\max_{\mathbf{x}\in P}\min_{\mathbf{u}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}}}\quad\min_{k\in[p]}\left(\boldsymbol{c}_{k}^{\top}\mathbf{x}+(\boldsymbol{D}^{\top}\mathbf{x}-\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}\right)

\displaystyle\leq\max_{\mathbf{x}\in P}\min_{\mathbf{u}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}},\mathbf{z}\in\mathbb{Q}_{+}^{p},\|\mathbf{z}\|_{1}=1}\quad(\boldsymbol{C}\mathbf{z})^{\top}\mathbf{x}+(\boldsymbol{D}^{\top}\mathbf{x}-\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}

\displaystyle\leq\min_{\mathbf{u}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}},\mathbf{z}\in\mathbb{Q}_{+}^{p},\|\mathbf{z}\|_{1}=1}\max_{\mathbf{x}\in P}\quad(\boldsymbol{C}\mathbf{z})^{\top}\mathbf{x}+(\boldsymbol{D}^{\top}\mathbf{x}-\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}

where the third equality is because of the Minimax Inequality. Therefore, we have shown that for any vectors
\mathbf{u}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}},\mathbf{z}\in\mathbb{Q}_{+}^{p}

\|\mathbf{z}\|_{1}=1
,

. Next, we show that there are vectors
\mathbf{u}^{*}\in\mathbb{Q}_{+}^{{\color[rgb]{0,0,0}{\noindent q}}},\mathbf{z}^{*}\in\mathbb{Q}_{+}^{p}

\displaystyle\max_{\mathbf{x},w}

\displaystyle w

\displaystyle\quad\text{s.t. }

\displaystyle\boldsymbol{A}\mathbf{x}\leq\boldsymbol{b}

\displaystyle\boldsymbol{D}^{\top}\mathbf{x}\geq\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S

\displaystyle\boldsymbol{C}^{\top}\mathbf{x}\geq\mathbf{1}_{p}w

(w^{*},\mathbf{x}^{*})

\displaystyle\leq(\boldsymbol{A}^{\top}\mathbf{y}^{*})^{\top}\mathbf{x}-(\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}^{*}

\displaystyle\leq\boldsymbol{b}^{\top}\mathbf{y}^{*}-(\mathbf{1}_{{\color[rgb]{0,0,0}{\noindent q}}}\log S)^{\top}\mathbf{u}^{*}

\displaystyle=w^{*}

strong duality

X\subset Z\end{subarray}}\gamma_{Z|X,X}\right)

\displaystyle{\color[rgb]{0,0,0}\mathsf{inflow}_{T}(Z)}\stackrel{{\scriptstyle\text{def}}}{{=}}\quad

\displaystyle\left(\sum_{X:(X,Z)\in\mathsf{DC}\cup\mathsf{AC}}{\color[rgb]{0,0,0}(\delta_{T})_{Z\mid X}}-\sum_{Y:(Z,Y)\in\mathsf{DC}\cup\mathsf{AC}}{\color[rgb]{0,0,0}(\delta_{T})_{Y\mid Z}}\right)+\left(-\sum_{X:X\subset Z}{\color[rgb]{0,0,0}(\mu_{T})_{X,Z}}+\sum_{Y:Z\subset Y}{\color[rgb]{0,0,0}(\mu_{T})_{Z,Y}}\right)

\displaystyle+\left(\sum_{\begin{subarray}{c}I\perp J\\
I\cap J=Z\end{subarray}}{\color[rgb]{0,0,0}(\sigma_{T})_{I,J}}+\sum_{\begin{subarray}{c}I\perp J\\
I\cup J=Z\end{subarray}}{\color[rgb]{0,0,0}(\sigma_{T})_{I,J}}-\sum_{J:J\perp Z}{\color[rgb]{0,0,0}(\sigma_{T})_{Z,J}}\right)

\displaystyle+\left(\sum_{\begin{subarray}{c}Z:(Z,Y|Z)\in\mathsf{SC}\\
Z\subset Y\end{subarray}}\gamma_{Y|Z,Z}-\sum_{\begin{subarray}{c}Z:(Z,Y|Z)\in\mathsf{SC}\\
Z\subset Y\end{subarray}}\gamma_{Z,Y|Z}+\sum_{\begin{subarray}{c}Z:(X,Z|X)\in\mathsf{SC}\\
X\subset Z\end{subarray}}\gamma_{X,Z|X}\right)

Next, we introduce the
joint Shannon-flow inequalities
.

Definition D.4 (Joint Shannon-flow Inequality).

The inequality

(23)

\displaystyle\sum_{(X,Y)\in\mathsf{DC}}{\color[rgb]{0,0,1}h_{S}}(Y|X)\cdot(\delta_{S})_{Y|X}

\displaystyle+\sum_{(X,Y)\in\mathsf{DC}\cup\mathsf{AC}}{\color[rgb]{1,0,0}h_{T}}(Y|X)\cdot(\delta_{T})_{Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}({\color[rgb]{0,0,1}h_{S}}(X)+{\color[rgb]{1,0,0}h_{T}}(Y|X))\cdot\gamma_{X,Y|X}

\displaystyle+\sum_{(X,Y|X)\in\mathsf{SC}}({\color[rgb]{0,0,1}h_{S}}(Y|X)+{\color[rgb]{1,0,0}h_{T}}(X))\cdot\gamma_{Y|X,X}\geq\sum_{B\in\mathsf{BS}}\theta_{B}\cdot{\color[rgb]{0,0,1}h_{S}}(B)+\sum_{B\in\mathsf{BT}}\lambda_{B}\cdot{\color[rgb]{1,0,0}h_{T}}(B),

is called a
joint Shannon-flow inequality
if it holds for all
({\color[rgb]{0,0,1}h_{S}},{\color[rgb]{1,0,0}h_{T}})\in\Gamma_{n}\times\Gamma_{n}
and all coefficients are non-negative rational numbers.

By assigning either polymatroid to be always
0
, the above inequality implies the following two Shannon-flow inequalities, called the
participating Shannon-flow inequalities
.

(24)

\displaystyle\sum_{(X,Y)\in\mathsf{DC}}{\color[rgb]{0,0,1}h_{S}}(Y|X)\cdot(\delta_{S})_{Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}{\color[rgb]{0,0,1}h_{S}}(X)\cdot\gamma_{X,Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}{\color[rgb]{0,0,1}h_{S}}(Y|X)\cdot\gamma_{Y|X,X}

\displaystyle\geq\sum_{B\in\mathsf{BS}}\theta_{B}\cdot{\color[rgb]{0,0,1}h_{S}}(B)

(25)

\displaystyle\sum_{(X,Y)\in\mathsf{DC}\cup\mathsf{AC}}{\color[rgb]{1,0,0}h_{T}}(Y|X)\cdot(\delta_{T})_{Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}{\color[rgb]{1,0,0}h_{T}}(Y|X)\cdot\gamma_{X,Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}{\color[rgb]{1,0,0}h_{T}}(X)\cdot\gamma_{Y|X,X}

\displaystyle\geq\sum_{B\in\mathsf{BT}}\lambda_{B}\cdot{\color[rgb]{1,0,0}h_{T}}(B)

It will be convenient to write a joint Shannon-flow inequality as inequalities over conditional polymatroid. The polymatroid
{\color[rgb]{0,0,1}h_{S}}
defines a conditional polymatroid
{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}
and the polymatroid
{\color[rgb]{1,0,0}h_{T}}
defines a conditional polymatroid
{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}
. More precisely, we define the vectors
\boldsymbol{\lambda},\boldsymbol{\theta}\in\mathbb{Q}^{\mathcal{C}}_{+}
(extend to
(X,Y)
pairs where
\emptyset\subseteq X\subset Y\subseteq[n]
) with coordinate values assigned as the following:

\lambda(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\lambda_{B}&\text{ when }Y=B,X=\emptyset\\
0&\text{ otherwise }\end{cases}\qquad\theta(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\theta_{B}&\text{ when }Y=B,X=\emptyset\\
0&\text{ otherwise }\end{cases}

and similarly, we define the vectors
\boldsymbol{\delta}_{S},\boldsymbol{\delta}_{T}\in\mathbb{Q}^{\mathcal{C}}_{+}
with coordinate values:

\delta_{S}(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}(\delta_{S})_{Y|X}&\text{ when }(X,Y)\in\mathsf{DC}\\
0&\text{ otherwise }\end{cases}\qquad\delta_{T}(Y|X)\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}(\delta_{T})_{Y|X}&\text{ when }(X,Y)\in\mathsf{DC}\cup\mathsf{AC}\\
0&\text{ otherwise }\end{cases}

Lastly, the coefficients
\left\{\gamma_{X,Y|X}\mid(X,Y|X)\in\mathsf{SC}\right\}\cup\left\{\gamma_{Y|X,X}\mid(X,Y|X)\in\mathsf{SC}\right\}
contributes to the coefficients of both inequalities (
24
) and (
25
). We define a pair of vectors
\boldsymbol{\gamma}_{S},\boldsymbol{\gamma}_{T}\in\mathbb{Q}^{\mathcal{C}}_{+}
as the following:

\displaystyle\gamma_{S}(Y|X)

\displaystyle\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\gamma_{U,V|U}&\text{ when }Y=U,X=\emptyset,(U,V|U)\in\mathsf{SC}\\
\gamma_{V|U,U}&\text{ when }Y=V,X=U,(U,V|U)\in\mathsf{SC}\\
0&\text{ otherwise }\end{cases}

\displaystyle\gamma_{T}(Y|X)

\displaystyle\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\gamma_{U,V|U}&\text{ when }Y=V,X=U,(U,V|U)\in\mathsf{SC}\\
\gamma_{V|U,U}&\text{ when }Y=U,X=\emptyset,(U,V|U)\in\mathsf{SC}\\
0&\text{ otherwise }\end{cases}

for tracking the contributions to
{\color[rgb]{0,0,1}\boldsymbol{h}_{S}},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}
, respectively. Let
\boldsymbol{g}_{S}\stackrel{{\scriptstyle\text{def}}}{{=}}\boldsymbol{\delta}_{S}+\boldsymbol{\gamma}_{S}
and
\boldsymbol{g}_{T}\stackrel{{\scriptstyle\text{def}}}{{=}}\boldsymbol{\delta}_{T}+\boldsymbol{\gamma}_{T}
, then the two inequalities (
24
) and (
25
) can be re-written using dot-products:

(26)

\displaystyle\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle\stackrel{{\scriptstyle\text{def}}}{{=}}\langle\boldsymbol{\delta}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\gamma}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle

\displaystyle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle

(27)

\displaystyle\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\stackrel{{\scriptstyle\text{def}}}{{=}}\langle\boldsymbol{\delta}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle+\langle\boldsymbol{\gamma}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

\displaystyle\geq\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

Moreover, the joint Shannon-flow inequality (
23
) can be written as

(28)

\displaystyle\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

\displaystyle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

Theorem D.5.

The inequality (
28
) is a joint Shannon-flow inequality if and only if there are non-negative vectors of rationals
\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T}
such that all constraints of the dual (
22
) are satisfied. In particular, we call
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
a witness for the joint Shannon-flow inequality.

Proof.

Proposition 5.6 in
[
24
]
states that: (
26
) is a Shannon-flow inequality if and only if there is a
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S})\geq\mathbf{0}
(called a witness in
[
24
]
) such that
(\boldsymbol{g}_{S},\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S})
satisfies the set of constraints:

\left\{\mathsf{inflow}_{S}(Z)\geq\theta_{Z}\mid\emptyset\neq Z\subseteq[n]\right\};

similarly, (
27
) is a Shannon-flow inequality if and only if there is a (witness)
(\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})\geq\mathbf{0}
such that
(\boldsymbol{g}_{T},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
satisfies the set of constraints:

\left\{\mathsf{inflow}_{T}(Z)\geq\lambda_{Z}\mid\emptyset\neq Z\subseteq[n]\right\}.

Recall the formulation of (
22
), these two sets of constraints form exactly all the constraints in (
22
). Thus, (
28
) is a joint Shannon-flow inequality if and only if there is a
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})\geq\mathbf{0}
such that
(\boldsymbol{g}_{S},\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{g}_{T},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
satisfies all the constraints of the dual (
22
).
∎

Theorem
D.5
implies that a feasible solution of the dual (
22
), and in particular the component

\left\{(\delta_{S})_{Y|X}\mid(X,Y)\in\mathsf{DC}\right\}\cup\left\{(\delta_{T})_{Y|X}\mid(X,Y)\in\mathsf{DC}\right\}\cup\left\{\gamma_{X,Y|X}\mid(X,Y|X)\in\mathsf{SC}\right\}\cup\left\{\gamma_{Y|X,X}\mid(X,Y|X)\in\mathsf{SC}\right\}

in conjunction with
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
, defines a joint Shannon-flow inequality (
23
). The component
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
of the dual, by
Theorem D.5
, is a witness for the joint Shannon-flow inequality. Note that the joint Shannon-flow inequality implies that

\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\leq\sum_{(X,Y)\in\mathsf{DC}}n_{Y|X}\cdot(\delta_{S})_{Y|X}+\sum_{(X,Y)\in\mathsf{DC}\cup\mathsf{AC}}n_{Y|X}\cdot(\delta_{T})_{Y|X}+\sum_{(X,Y|X)\in\mathsf{SC}}n_{Z|\emptyset}\cdot(\gamma_{X,Y|X}+\gamma_{Y|X,X})

where the right-hand side is exactly
\ell(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
by taking the optimal solution of the dual (
22
) (by strong duality).
We have established that: for an arbitrary
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
satisfying (
16
), we can construct a joint Shannon-flow inequality,

\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle,

having a witness
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
, such that its implied upper bound coincides with
\ell(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
.

D.3.
A Brief Review/Augmentation of the
\mathsf{PANDA}
Algorithm

This section provides a brief review of the
\mathsf{PANDA}
algorithm. Let
\rho
be a disjunctive rule (
4
) under degree constraints
\mathsf{DC}
. At a high level,
\mathsf{PANDA}
does the following:

Step 1.

find a vector of non-negative rationals
\boldsymbol{\lambda}_{\mathsf{BT}}=(\lambda_{B})_{B\in{\mathsf{BT}}}
with
\|\boldsymbol{\lambda}_{\mathsf{BT}}\|_{1}=1
, extend it to a vector (over conditional polymatroid)
\boldsymbol{\lambda}\in\mathbb{Q}^{\mathcal{C}}_{+}
and
\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}(\rho)=\max_{h\in\Gamma_{n}\cap\mathsf{HDC}}\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
, where the right-hand side is a linear program;

Step 2.

find an optimal dual solution
(\boldsymbol{\delta},\boldsymbol{\sigma},\boldsymbol{\mu})
to the linear program,
\max_{h\in\Gamma_{n}\cap\mathsf{HDC}}\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
, so that

\mathsf{OBJ}\stackrel{{\scriptstyle\text{def}}}{{=}}\sum_{(X,Y)\in\mathsf{DC}}\log N_{Y\mid X}\cdot\delta_{Y\mid X}=\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}(\rho)

and
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
forms a Shannon-flow inequality;

Step 3.

construct a proof sequence
\mathsf{ProofSeq}
of length
O(poly(2^{n}))
for the Shannon-flow inequality
\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
(see
Theorem D.1
);

Step 4.

run a
\mathsf{PANDA}
instance, denoted as
\mathsf{PANDA}(\mathcal{D},\mathsf{DC},(\boldsymbol{\lambda},\boldsymbol{\delta}),\mathsf{ProofSeq})
, which interprets each proof step of
\mathsf{ProofSeq}
as a relational operation on the input relation, where each operation is guaranteed to take time
\widetilde{O}(2^{\mathsf{OBJ}})
. Overall, the
\mathsf{PANDA}
instance runs in time
\widetilde{O}(2^{\mathsf{OBJ}})
and computes a model of size
\widetilde{O}(2^{\mathsf{OBJ}})
.

In particular, the
\mathsf{PANDA}
instance maintains the following
4
invariants on its inputs, i.e.
(\mathcal{D},\mathsf{DC},(\boldsymbol{\lambda},\boldsymbol{\delta}),\mathsf{ProofSeq})
:

\mathsf{PANDA}
invariants.

(1)

Degree-support invariant:
For every
\delta_{Y|X}>0
, there exist
Z\subseteq X,W\subseteq Y
such that
W-Z=Y-X
and
(Z,W,N_{W|Z})\in\mathsf{DC}
. The degree constraint is said to support the positive
\delta_{Y|X}
. If there are more than one
(Z,W,N_{W|Z})\in\mathsf{DC}
supporting
\delta_{Y|X}
, we choose the one with minimum
N_{W|Z}
and call it the supporting constraint of
\delta_{Y|X}
.

(2)

0<\|\boldsymbol{\lambda}\|_{1}\leq 1

(3)

The Shannon flow inequality along with the supporting degree constraints satisfy
\sum_{(X,Y)}n(\delta_{Y\mid X})\leq\|\boldsymbol{\lambda}\|_{1}\cdot\mathsf{OBJ}
where

n(\delta_{Y\mid X})\stackrel{{\scriptstyle\text{def}}}{{=}}\begin{cases}\delta_{Y\mid X}\cdot n_{W\mid Z}&\text{ if }\delta_{Y\mid X}>0\text{ and }\\
&(Z,W,N_{W\mid Z})\text{ supports it }\\
0&\text{ if }\delta_{Y\mid X}=0.\end{cases}

and we call the quantity
\sum_{(X,Y)}n(\delta_{Y\mid X})
the
potential
.

(4)

For every
\delta_{Y|\emptyset}>0
, the supporting degree constraint
(\emptyset,Y,N_{Y|\emptyset})
satisfies
n_{Y|\emptyset}\leq\mathsf{OBJ}
.

A slight augmentation on
\mathsf{PANDA}
.

For our purposes, we augment
\mathsf{PANDA}
slightly to take non-optimal proof sequences. More precisely, suppose instead of Step 1 and 2, we are given vectors
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\delta}_{\mathsf{DC}})
and witness
(\boldsymbol{\sigma},\boldsymbol{\mu})
such that by extending both vectors as
\boldsymbol{\lambda},\boldsymbol{\delta}\in\mathbb{Q}^{\mathcal{C}}_{+}
,

\langle\boldsymbol{\delta},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda},\boldsymbol{h}\rangle
forms a (not necessarily optimal) Shannon-flow inequality with witness
(\boldsymbol{\sigma},\boldsymbol{\mu})
. Note that the implied upper bound
\mathsf{OBJ}
satisfies

\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}(\rho)\leq\mathsf{OBJ}\stackrel{{\scriptstyle\text{def}}}{{=}}\sum_{(X,Y)\in\mathsf{DC}}\log N_{Y\mid X}\cdot\delta_{Y\mid X},

but not necessarily coincides with
\mathsf{LogSizeBound}_{\Gamma_{n}\cap\mathsf{HDC}}(\rho)
.
In such cases, following Step 3 and 4, we show that the
\mathsf{PANDA}
instance (taking the non-optimal proof sequence for the given Shannon-flow inequality as input), runs in time as predicated by the non-optimal Shannon-flow inequality, i.e.
\widetilde{O}(2^{\mathsf{OBJ}})
.

The augmentation is as follows. We observe that in the proof of correctness of
\mathsf{PANDA}

[
24
]
, only invariant
(4)
(at the beginning of the
\mathsf{PANDA}
instance) relies on the optimality of proof sequences. However, as argued in Proposition 6.2, if initially for some
\delta_{Y|\emptyset}>0
,
n_{Y|\emptyset}>\mathsf{OBJ}
, then we could replace the original Shannon-flow inequality with a new Shannon-flow inequality
\langle\boldsymbol{\delta}^{\prime},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda}^{\prime},\boldsymbol{h}\rangle
along with witness
(\boldsymbol{\sigma}^{\prime},\boldsymbol{\mu}^{\prime})
such that invariants (1)-(3) hold, and the length of the proof sequence decreases by at least
1
. We can repeat this replacement step iteratively until invariant
(4)
is satisfied. If invariant
(4)
is never satisfied, then we will end up with a proof sequence of length
0
, in which case
the Shannon-flow inequality becomes a trivial one,
\langle\boldsymbol{\delta}_{0},\boldsymbol{h}\rangle\geq\langle\boldsymbol{\lambda}_{0},\boldsymbol{h}\rangle
, for some
\boldsymbol{\lambda}_{0},\boldsymbol{\delta}_{0}
with
0<\|\boldsymbol{\lambda}_{0}\|_{1}\leq 1
(by invariant (2)) and
\boldsymbol{\delta}_{0}\geq\boldsymbol{\lambda}_{0}
(element-wise comparison).

This implies that any input relation
R_{F}
where
(\lambda_{0})_{F|\emptyset}>0
can be a model and there is an
n_{F|\emptyset}\leq\mathsf{OBJ}
that can be appointed as
the
output model (so the model size is
\widetilde{O}(2^{\mathsf{OBJ}})
), because otherwise,

\sum_{F:(\lambda_{0})_{F|\emptyset}>0}\frac{(\lambda_{0})_{F|\emptyset}}{\|\boldsymbol{\lambda}_{0}\|_{1}}\cdot n_{F|\emptyset}>\sum_{F:(\lambda_{0})_{F|\emptyset}>0}\frac{(\lambda_{0})_{F|\emptyset}}{\|\boldsymbol{\lambda}_{0}\|_{1}}\cdot\mathsf{OBJ}=\mathsf{OBJ},

and this contradicts invariant (3). For the
\mathsf{2PP}
algorithm, we implicitly assume that
\mathsf{PANDA}
is equipped with this minor augmentation.

D.4.
The Algorithm

While
\mathsf{2PP}
follows a similar structure as the naïve algorithm (and uses the 2-phase algorithmic framework), it is guided by a joint Shannon-flow inequality to execute only the necessary split steps and
\mathsf{PANDA}
instances, which provides more practicality and interpretability. In particular, we will show the following theorem for
\mathsf{2PP}
.

Theorem D.6.

Let
\rho
be a 2-phase disjunctive rule of the form (
5
) satisfying degree constraints
\mathsf{DC}
(guarded by the input relations) and
\mathsf{AC}
(guarded by the access request). Let
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})\in\left\{(\mathbf{a}_{T},\mathbf{a}_{S})\mid\mathbf{a}_{T}\in\mathbb{Q}_{+}^{\mathsf{BT}},\mathbf{a}_{S}\in\mathbb{Q}_{+}^{\mathsf{BS}},\|\mathbf{a}_{T}\|_{1}=1\right\}
.
The
\mathsf{2PP}
algorithm obtains a model of
\rho
in two phases and attains the following (smooth) intrinsic trade-off:

(29)

\displaystyle S_{\rho}^{\|\boldsymbol{\theta}_{\mathsf{BS}}\|_{1}}\cdot T_{\rho}\cong 2^{\ell(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})}

where
\cong
hides a poly-logarithmic factor at the right-hand side.

Note that the intrinsic trade-off can be equivalently written as

(30)

\displaystyle S_{\rho}^{\|\boldsymbol{\theta}_{\mathsf{BS}}\|_{1}}\cdot T_{\rho}\cong\prod_{(X,Y)\in\mathsf{DC}}N_{Y|X}^{(\delta_{S})_{Y|X}}\cdot\prod_{(X,Y)\in\mathsf{DC}\cup\mathsf{AC}}N_{Y|X}^{(\delta_{S})_{Y|X}}\cdot\prod_{(X,Y|X)\in\mathsf{SC}}N_{Z|\emptyset}^{\gamma_{X,Y|X}+\gamma_{Y|X,X}}

In particular, given a fixed
S
for
S_{\rho}
, we can construct from
Lemma D.2
(using complementary slackness)
(\boldsymbol{\lambda}_{\mathsf{BT}}^{*},\boldsymbol{\theta}_{\mathsf{BS}}^{*})
such that
\mathsf{OBJ}(S)=\mathbf{L}(\boldsymbol{\lambda}_{\mathsf{BT}}^{*},\boldsymbol{\theta}_{\mathsf{BS}}^{*},S)
. Since
\ell(\boldsymbol{\lambda}_{\mathsf{BT}}^{*},\boldsymbol{\theta}_{\mathsf{BS}}^{*})-(\log S)\cdot\|\boldsymbol{\theta}_{\mathsf{BS}}^{*}\|_{1}=\mathbf{L}(\boldsymbol{\lambda}_{\mathsf{BT}}^{*},\boldsymbol{\theta}_{\mathsf{BS}}^{*},S)
,
Theorem D.6
recovers the best possible instrinsic trade-off as specified in (
12
). In the rest of this section, we present the
\mathsf{2PP}
algorithm, and defer the full proof of
Theorem D.6
to the next section.

Preparation phase.

Similar to
\mathsf{PANDA}
,
\mathsf{2PP}
has a preparation phase to construct the necessary inputs for a
\mathsf{2PP}
instance. First, we construct from the given
(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
a joint Shannon-flow inequality,
\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle
and a witness for it,
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
. Recall that the joint Shannon-flow inequality implies an upper bound coincides with
\ell(\boldsymbol{\lambda}_{\mathsf{BT}},\boldsymbol{\theta}_{\mathsf{BS}})
.

Second, we construct a proof sequence for the joint Shannon-flow inequality. The idea is to build two parallel proof sequences for its two participating Shannon-flow inequalities and stitch them together. Recall that the two participating Shannon-flow inequalities are

\displaystyle\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle

\displaystyle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle

\displaystyle\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

\displaystyle\geq\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle

From the proof of
Theorem D.5
,
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S})
is a witness for
\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle
and
(\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
is a witness for
\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\geq\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle
. We normalize the Shannon-flow inequality
\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle
into

\langle\widetilde{\boldsymbol{g}}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle\geq\langle\widetilde{\boldsymbol{\theta}},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle
, where
\widetilde{\boldsymbol{g}}_{S}\stackrel{{\scriptstyle\text{def}}}{{=}}\boldsymbol{g}_{S}/\|\boldsymbol{\theta}\|_{1}
and
\widetilde{\boldsymbol{\theta}}\stackrel{{\scriptstyle\text{def}}}{{=}}\boldsymbol{\theta}/\|\boldsymbol{\theta}\|_{1}
, with a new witness
(\widetilde{\boldsymbol{\sigma}}_{S},\widetilde{\boldsymbol{\mu}}_{S})\stackrel{{\scriptstyle\text{def}}}{{=}}(\boldsymbol{\sigma}_{S}/\|\boldsymbol{\theta}\|_{1},\boldsymbol{\mu}_{S}/\|\boldsymbol{\theta}\|_{1})
. From
Theorem D.1
, we can construct a proof sequence
\mathsf{ProofSeq}(S)
for the Shannon-flow inequality
\langle\widetilde{\boldsymbol{g}}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle\geq\langle\widetilde{\boldsymbol{\theta}},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle
and a proof sequence
\mathsf{ProofSeq}(T)
for
\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\geq\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle
, where both proof sequences have length
O(poly(2^{n}))
,
n
being the number of variables. We say that
\mathsf{ProofSeq}(S)
and
\mathsf{ProofSeq}(T)
are
the participating proof sequences
for the joint Shannon-flow inequality. As a brief summary, in the preparation phase,
\mathsf{2PP}
:

(1)

(see
Theorem D.5
) constructs a joint Shannon-flow inequality
\langle\boldsymbol{g}_{S},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{g}_{T},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle\geq\langle\boldsymbol{\theta},{\color[rgb]{0,0,1}\boldsymbol{h}_{S}}\rangle+\langle\boldsymbol{\lambda},{\color[rgb]{1,0,0}\boldsymbol{h}_{T}}\rangle
with a witness
(\boldsymbol{\sigma}_{S},\boldsymbol{\mu}_{S},\boldsymbol{\sigma}_{T},\boldsymbol{\mu}_{T})
; and

(2)

(see
Theorem D.1
) constructs a

\displaystyle h([n])

. Equivalently, we get

\displaystyle|Q_{A}|\cdot|\mathcal{D}|^{\sum_{j\in[\ell]}u^{*}_{j}/\alpha_{j}}\cong S^{\sum_{j\in[\ell]}1/\alpha_{j}}\cdot T.

In the above tradeoff, for a given
S
, (assume

), we get

\displaystyle\log T

\displaystyle=\sum_{j\in[\ell]}\frac{u^{*}_{j}}{\alpha_{j}}\cdot\log|\mathcal{D}|-\sum_{j\in[\ell]}(1/\alpha_{j})\log S

\displaystyle=\sum_{j\in[\ell]}(1/\alpha_{j})\cdot(u^{*}_{j}\log|\mathcal{D}|-\log S)

One observation is that if some bag
t_{j}
on the path

has an AGM bound that is not greater than
S
, then the materialization of

’s corresponding
S
-view

can be fully materialized as the model for (

). Otherwise, for every

, we have that

is non-negative for every

, thus the above expression for

monotonically increases as

increases. Therefore, the most expensive tradeoff corresponds to the disjunctive rule of the form in (

) that starts from the root and ends at a leaf. To obtain the final space-time tradeoffs, we simply take the worst tradeoffs across all the root-to-leaf paths in
\mathcal{T}
.

Before we conclude this section, we show that the tradeoff we obtained in (
35
) across all root-to-leaf paths of a fixed tree decomposition
(\mathcal{T},\chi)
recovers (and possibly improves over) Theorem 13 of
[
13
]
, without incurring extra hyper-parameters. Indeed, in (
35
), the authors set a hyper-parameter
\delta(t)
for every
t\in V(\mathcal{T})
and
let the online answering time to be
T=|\mathcal{D}|^{\sum_{j\in[\ell]}\delta(t_{j})}
, where
t_{1},\ldots,t_{\ell}
is a root-to-leaf path of
\mathcal{T}
that maximizes
\sum_{j\in[\ell]}\delta(t_{j})
. Suppose we construct a 2-phase disjunctive rule of the form (
35
) for this root-to-leaf path,
t_{1},\ldots,t_{\ell}
, then for any fractional edge cover
u^{*}_{j},j\in[\ell]
, it holds that (by rewriting (
35
))

\displaystyle\log_{|\mathcal{D}|}S

\displaystyle=\frac{1}{\sum_{j\in[\ell]}(1/\alpha_{j})}\cdot\left(\sum_{j\in[\ell]}\frac{u^{*}_{j}}{\alpha_{j}}-\log_{|\mathcal{D}|}T\right)

\displaystyle=\frac{1}{\sum_{j\in[\ell]}(1/\alpha_{j})}\cdot\left(\sum_{j\in[\ell]}\frac{u^{*}_{j}}{\alpha_{j}}-\sum_{j\in[\ell]}\delta(t_{j})\right)

\displaystyle=\frac{1}{\sum_{j\in[\ell]}(1/\alpha_{j})}\cdot\sum_{j\in[\ell]}\frac{1}{\alpha_{j}}(u^{*}_{j}-\delta(t_{j})\cdot\alpha_{j})

\displaystyle\leq\max_{j\in[\ell]}\left(\sum_{F\in\mathcal{E}}u_{F}^{(j)}-\delta(t_{j})\cdot\alpha_{j}\right).

The last inequality holds because for all
w_{i}\geq 0
such that
\sum_{i}w_{i}=1
,
\sum_{i=1}^{n}\gamma_{i}w_{i}\leq\max_{i}\gamma_{i}
. Setting
w_{i}=\frac{1}{\alpha_{i}}\cdot\frac{1}{\sum_{j\in[\ell]}(1/\alpha_{j})}
, we get the desired expression. Thus, it is easy to see that the tradeoff we obtained in (
35
) across all root-to-leaf paths of a fixed tree decomposition indeed recovers results in
[
13
]
.
