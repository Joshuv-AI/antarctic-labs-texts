Generalization of ( [ e ] , [ e ] ∨ [ c ] ) ([e],[e]\vee[c]) -Ideals Of BE-algebras
Ahmad Fawad Ali, Saleem Abdullah, Muhammad Sarwar Kamran, Muhammad Aslam

Abstract
. In this paper, using N N -structure, the notion of an N N -ideal in a BE-algebra is introduced. Conditions for an N N -structure to be an N N -ideal are provided. To obtain a more general form of an N N -ideal, a point N N -structure which is ( k k conditionally) employed in an N N -structure is proposed. Using these notions, the concept of an ( [ e ] , [ e ] ∨ [ c k ] ) ([e],[e]\vee[c_{k}]) -ideal is introduced and related properties are investigated. ( [ e ] , [ e ] ∨ [ c k ] ) ([e],[e]\vee[c_{k}]) -ideal is a generalized form of ( [ e ] , [ e ] ∨ [ c ] ) ([e],[e]\vee[c]) -ideal. Characterizations of ( [ e ] , [ e ] ∨ [ c k ] ) ([e],[e]\vee[c_{k}]) -ideals are discussed.
