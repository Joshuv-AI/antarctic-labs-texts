Introduction

Let
\mathbb{R}_{+}
denote the set of all non-negative real numbers. Given a ground set
\mathcal{X}
, a set function
g:2^{\mathcal{X}}\rightarrow\mathbb{R}_{+}
is called a submodular function if for any subset
S,T\subseteq\mathcal{X}
,
g(S)+g(T)\geq g(S\cup T)+g(S\cap T)

[
6
,
23
]
and recommendation system
[
19
,
26
]

A natural extension of a submodular function is a
k
-submodular function, where an argument of a
k
-submodular function is a collection of
k
disjoint subsets
\textbf{s}=(S_{1},S_{2},\dots,S_{k})
, rather than a single set in the traditional subnmodular set function. Therefore, a submodular function is a special case of
k
-submodular function when
k=1
. Huber and Kolmogorov
[
4
]
introduced the concept of a
k
-submodular function and studied minimization of
k
-submodular functions. Due to its universality and diminishing return property,

-submodular functions have many applications in real world, such as
k
-topic influence maximization problem
[
15
,
16

17

and sensor placement with
k
types of sensors
[

,

Maximization of
k
-submodular functions under various constraints have also been studied in recent years. For the unconstrained problem, Ward and Živný
[
28

first designed a deterministic
1/3
-approximation algorithm and a randomized
1/(1+a)
approximation algorithm where

Later, Iwata et al.
[
5

-approximation algorithm for the monotone case. Using the framework of

improved the approximation ratio to

.
Ohsaka and Yoshida
[
12
]
studied the total size (i.e.,
|\cup_{i\in[k]}S_{i}|\leq B

B\geq 0

where

Further, Xiao et al.
[

studied maximization of non-monotone

Sakaue
[

studied maximization of a monotone

\frac{1}{2}
-approximation algorithm. For a knapsack constraint, Tang
[

gave a 0.4-approximation algorithm for the monotone case. This result was improved to
\frac{1}{2}-\epsilon

[
26

using the multilinear extension method.

In applications, due to the increasing scale in data volumes and the nature of problems, it is impractical to store all data and hence necessary to design streaming algorithms that could process data as it arrives. Streaming algorithms have the advantage of using limited memory and less time, but still could return a reasonable solution. Pham et al.

studied streaming algorithms for the

Spaeh, Ene and Nguyen

Our Contribution
. In this paper, we consider

-SC in the streaming setting. We generalize the previous work
[

from the uniform cost to the general non-negative weighted cost. Three algorithms are devised to resolve this problem. The first algorithm is based on the assumption of knowing the optimal solution value. Later, we provide Algorithm

Preliminaries

Given a finite set
\mathcal{X}
of size
n
and a positive integer
k
, we define
[k]=\{1,2,\dots,k\}
. Let
(k+1)^{\mathcal{X}}=\{(S_{1},S_{2}\dots S_{k})|S_{i}\subseteq\mathcal{X},S_{i}\cap S_{j}=\emptyset,\text{ for all }i,j\in[k]\}
be the set of all
k
disjoint subsets of
\mathcal{X}
. Each subset in
(k+1)^{\mathcal{X}}
is called
k
-set. We denote
0
as
(\emptyset,\emptyset,\dots\emptyset)
for simplicity. Given a
k
-set
\textbf{s}=(S_{1},S_{2},\dots,S_{k})\in(k+1)^{\mathcal{X}}
, let
\textbf{s}(x)=i
if
x\in S_{i}
and
i
is called the
position
in
x
;
\textbf{s}(x)=0
if
x\notin S_{i}
.

For
k
-sets
\textbf{s}=(S_{1},S_{2}\dots S_{k})
and
\textbf{t}=(T_{1},T_{2}\dots T_{k})\in(k+1)^{\mathcal{X}}
, two operations meet and join
\textbf{s}\sqcap\textbf{t}
and
\textbf{s}\sqcup\textbf{t}
is defined as following

\textbf{s}\sqcap\textbf{t}=(S_{1}\cap T_{1},S_{2}\cap T_{2},\dots,S_{k}\cap T_{k}),

\textbf{s}\sqcup\textbf{t}=(S_{1}\cup T_{1}\backslash\bigcup\limits_{i\neq 1}(S_{i}\cup T_{i}),\dots,S_{k}\cup T_{k}\backslash\bigcup\limits_{i\neq k}(S_{i}\cup T_{i})).

A function
g:(k+1)^{\mathcal{X}}\rightarrow\mathbb{R}_{+}
is
k
-submodular
if
k
-sets
s
and
\textbf{t}\in(k+1)^{\mathcal{X}}
, we have

g(\textbf{s})+g(\textbf{t})\geq g(\textbf{s}\sqcap\textbf{t})+g(\textbf{s}\sqcup\textbf{t}).

In this paper, we assume that
g
is non-negative and normalized, i.e.,
g(\textbf{s})\geq 0
for all
\textbf{s}\in(k+1)^{\mathcal{X}}
and
g(\textbf{0})=0
. We also assume that an oracle is given to access the
k
-submodular function; the oracle is a black box returning
g(\textbf{s})
for a given
k
-set
s
.
We write
\textbf{s}\sqsubseteq\textbf{t}
if and only if
S_{i}\subseteq T_{i}
for each
i\in[k]
. A function
g
is

if for any
s
and
\textbf{t}\in(k+1)^{\mathcal{X}}
with
\textbf{s}\sqsubseteq\textbf{t}
, we have
g(\textbf{s})\leq g(\textbf{t})
. Let
E(\textbf{s})=S_{1}\cup S_{2}\dots\cup S_{k}
. Let
(x,i)
denote a pair where
x\in\mathcal{X}
and
i
is the position. Therefore, a
k
-set
s
can also be written as
\textbf{s}=\{(x_{1},i_{1}),(x_{2},i_{2}),\dots,(x_{j},i_{j})\}
where
x_{p}\in E(\textbf{s})
and
i_{p}=\textbf{s}(x_{p})
for
1\leq p\leq j
. Adding an element
x\notin E(\textbf{s})
to the
S_{i}
can be written as
\textbf{s}\sqcup(x,i)
. Define

\Delta_{x,i}g(\textbf{x})=g(\textbf{s}\sqcup(x,i))-g(\textbf{s})

as the marginal gain. We introduce some basic but useful properties of a
k
-submodular function which is crucial in the analysis of our algorithm.
From
[
28
]
, a
k
-submodular function

has
orthant

submodularity
, that is,

\Delta_{x,i}g(\textbf{s})\geq\Delta_{x,i}g(\textbf{t})

where
\textbf{s}\sqsubseteq\textbf{t}\in(k+1)^{\mathcal{X}}
,
x\notin E(\textbf{t})
and

. Also, a
k
-submodular function has

, i.e., if
x\notin E(\textbf{s})
, then

\Delta_{x,i}g(\textbf{s})+\Delta_{x,j}g(\textbf{s})\geq 0

for any

with

.

Lemma 1

[
24

Given a
k
-submodular function

, we have

g(\textbf{t})\leq g(\textbf{s})+\sum\limits_{x\in E(\textbf{t})\backslash E(\textbf{s})}\Delta_{x,\textbf{t}(x)}g(\textbf{s}).

for any

,
\textbf{t}\in(k+1)^{\mathcal{X}}
such that
\textbf{s}\sqsubseteq\textbf{t}
.

&\leq\sum\limits_{x\in E(\textbf{v})\backslash E(\textbf{x})}\max_{i\in[k]}\frac{\Delta_{x,i}g(\textbf{x}^{m_{x}})}{w(x)}w(x)\\
&\leq\sum\limits_{x\in E(\textbf{v})\backslash E(\textbf{x})}\theta w(x)\\
&\leq\theta w(\textbf{v}).\end{split}

(6)

The first inequality holds from orthant submodularity of

; and the third inequality is true because

(7)

Next, we consider the case that there exist

\displaystyle=g(\textbf{x}^{m_{x}})+g(\textbf{x}^{m_{x}}\sqcup(x,i^{\prime}))-g(\textbf{x}^{m_{x}})

\displaystyle=\sum\limits_{p=1}^{m_{x}}[g(\textbf{x}^{p})-g(\textbf{x}^{p-1})]+g(\textbf{x}^{m_{x}}\sqcup(x,i^{\prime}))-g(\textbf{x}^{m_{x}})

\displaystyle=\sum\limits_{p=1}^{m_{x}}\frac{\Delta_{x_{p},i_{p}}g(\textbf{x}^{p-1})}{w(x_{p})}w(x_{p})+\frac{\Delta_{x,i^{\prime}}g(\textbf{x}^{m_{x}})}{w(x)}w(x)

\displaystyle\geq\sum\limits_{p=1}^{m_{x}}\theta w(x_{p})+\theta w(x)

\displaystyle=\theta w(\textbf{x}^{m_{x}})+\theta w(x)

\displaystyle=\theta w(\textbf{x}^{m_{x}}\sqcup(x,i^{\prime}))

\displaystyle\geq\theta A.

The first inequality holds due to monotonicity of

Conclusion

We provide three streaming algorithms for the weighted
k
-Submodular Cover problem with the theoretical guarantee of approximation ratio, memory and number of queries. The approximation ratio is
O(\frac{1}{\epsilon})
for both monotone and non-monotone case. The one-pass algorithm would use

queries of the

-submodular function oracle. In the unconstrained non-monotone

-submodular maximization problem, the best result is near
\frac{1}{2}
.
But in our algorithm,
\beta
is
\frac{1-\epsilon}{3}
when the function is non-monotone. In the future, we’d like to investigate how to close this gap without increasing the performance cost too much.
