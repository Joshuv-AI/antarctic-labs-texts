Robust Adaptive Generalized Correntropy-based Smoothed Graph Signal Recovery with a Kernel Width Learning
Razieh Torkamani, Hadi Zayyani, Farokh Marvasti

Abstract
This paper proposes a robust adaptive algorithm for smooth graph signal recovery which is based on generalized correntropy. A proper cost function is defined, which takes the smoothness and generalized correntropy into account. The generalized correntropy used in this paper employs the generalized Gaussian density (GGD) function as the kernel. The proposed adaptive algorithm is derived and a kernel width learning-based version of the algorithm is suggested. The simulation results confirm the performance of the proposed algorithm for learning the kernel-width to the fixed correntropy kernel version of the algorithm. Moreover, some theoretical analysis of the proposed algorithm are provided. In this regard, firstly, the convexity analysis of the cost function is discussed. Secondly, the uniform stability of the algorithm is investigated. Thirdly, the mean convergence analysis is also added. Finally, the computational complexity analysis of the algorithm is incorporated. In addition, some synthetic and real-world experiments show the efficiency of the proposed algorithm in comparison to some other adaptive algorithms in the literature of adaptive graph signal recovery.

2
Smoothed graph signal recovery model

Let
\mathcal{G}=\{\mathcal{V},\mathcal{E}\}
defines an undirected graph consisting of a set of
N
nodes
{\cal V}=\{1,2,....N\}
. A set edges
{\cal E}=\{W_{ij}\}_{i,j\in{\cal V}}
is defined such that
W_{ij}>0
if there is a link between nodes
i
and
W_{ij}=0
otherwise. The adjacency matrix
\mathbf{W}
is an
N\times N
symmetric matrix and consists the collection of all the weights
W_{ij}(i,j=1,2,...,N)
. Suppose
D_{i}=\sum_{j=1}^{N}{W_{ij}}
denote the degree of node
i
; then the degree matrix of a graph is defined as a diagonal matrix
\mathbf{D}=\mathrm{diag}(D_{i})
. The Laplacian matrix is also defined as
\mathbf{L}=\mathbf{D}-\mathbf{W}
.

A graph signal is shown as
\mathbf{x}\in{\mathbb{R}}^{N\times 1}
, where
N
is the number of nodes. Given the signals of
M
vertices, the signal at time index
n
can be written as

\mathbf{y}[n]=\Phi[n]\mathbf{x}+\mathbf{v}[n]

(1)

where
\mathbf{v}
is the is the
N\times 1
noise vector which no assumption is made for it throughout this paper, and
\Phi[n]\in\mathbf{R}^{N\times N}
is the diagonal sampling matrix at time
n
in which the
i^{\prime}
th diagonal element is “one” if and only if the
i^{\prime}
th node has been sampled, otherwise this element is ”zero” and this row takes the value of all-zero.

The aim of GSR is to reconstruct the graph signal
\mathbf{x}
from the sampled observations
\mathbf{y}[n]
. To this end, it is necessary to assume some prior knowledge about the signals
\mathbf{x}
. On the other hand, most of the real-world graph signals are smooth on the underlying graph, such that the value of neighbor nodes tend to be more analogous than those of distant nodes. In this paper, we exploit the smoothness assumption of deterministic graph signals in the recovery process, which can be characterized by a quadratic form as

S(\mathbf{x})=\lVert\mathbf{L}^{\frac{1}{2}}\mathbf{x}\rVert=\mathbf{x}^{T}\mathbf{L}\mathbf{x},

(2)

which measures the variations of signal samples over the graph, and can be rewritten as

S(\mathbf{x})=\sum_{(i,j)\in{\cal E}}{W_{ij}(x_{j}-x_{i})^{2}},

(3)

where
x_{i}
is the
i^{\prime}
th element of
\mathbf{x}
. The smaller the value of function
S(\mathbf{x})
, the smoother the graph signal
\mathbf{x}
.

3
Generalized correntropy

Let
x
and
y
be two random variables with
F_{xy}(x,y)
as the joint probability distribution function. Then, the definition of the correntropy is
[
27
]

V(x,y)=\mathbb{E}\{\kappa(x,y)\}=\int{\kappa(x,y)dF_{xy}(x,y)},

(4)

where
\mathbb{E}
stands for the expectation operator, and
\kappa(x,y)
is a kernel function. A usual kernel used in the correntropy is the Gaussian kernel:

\kappa(x,y)=\frac{1}{\sqrt{2\pi}\sigma}\exp(-\frac{e^{2}}{2\sigma^{2}})=\frac{1}{\sqrt{2\pi}\sigma}\exp(-\rho e^{2}),

(5)

where
e=x-y
,
\sigma>0
is the kernel width, and
\rho=1/2\sigma^{2}
. Here, we use generalized Gaussian density function (GGD) with zero-mean as the kernel function of the correntropy
[
27
]
:

G_{\alpha,\beta}(e)=\frac{\alpha}{2\beta\Gamma(1/\alpha)}\exp(-|\frac{e}{\beta}|^{\alpha})=z_{\alpha,\beta}\exp(-\rho|e|^{\alpha})

(6)

where
\alpha>0
and
\beta>0
are the shape and width (scale) parameters, respectively,
\Gamma(.)
is the gamma function,
\rho=1/\beta^{\alpha}
, and
z_{\alpha,\beta}=\alpha/(2\beta\Gamma(1/\alpha))
denotes the normalization constant. Using this GGD density function, and defining

V(x,y)=\mathbb{E}(G_{\alpha,\beta}(e))

(7)

leads to generalized correntropy. As it is evident, substituting
\alpha=2
leads to the correntropy with the Gaussian kernel. In practice, usually the joint pdf of
x
and
y
is not known, and only a limited number of samples
\{(x_{i},y_{i})\}_{i=1}^{N}
are available. Thus, an estimate of generalized correntropy is obtained directly from samples as

\hat{V}(x,y)=\frac{1}{N}\sum_{i=1}^{N}{(G_{\alpha,\beta}(x_{i}-y_{i}))}=\frac{1}{N}\sum_{i=1}^{N}{(G_{\alpha,\beta}(e_{i}))}

(8)

which we use in the current work, and we call it total generalized correntropy (TGC). In
[
27
]
, the generalized correntropy has been used as an estimation cost in signal recovery and a metric called the generalized correntropic loss (GC-loss) function is defined as

\displaystyle J_{GC-loss}(x,y)

\displaystyle=G_{\alpha,\beta}(0)-V_{\alpha,\beta}(x,y)=z_{\alpha,\beta}-\mathbb{E}[G_{\alpha,\beta}(e_{i})]

\displaystyle=z_{\alpha,\beta}\{1-\mathbb{E}[\exp(-\rho|e_{i}|^{\alpha})]\}

(9)

where we have assumed the same kernel width for all samples, for simplicity. In the current work, we use an estimator of GC-loss function, called total GC-loss (TGC-loss) function as

\displaystyle J_{TGC-loss}(x,y)

\displaystyle=G_{\alpha,\beta}(0)-\hat{V}_{\alpha,\beta}(x,y)=z_{\alpha,\beta}-\frac{1}{N}\sum_{i=1}^{N}{[G_{\alpha,\beta}(e_{i})]}

\displaystyle=z_{\alpha,\beta}\{1-\frac{1}{N}\sum_{i=1}^{N}[\exp(-\rho|e_{i}|^{\alpha})]\}

(10)

Thus, the unknown signal
x
can be reconstructed from the measurements
y
by minimizing the above TGC-loss function.

The proposed adaptive algorithm

4.1
TGC-loss based smoothed graph signal recovery

Jointly applying the correntropy introduced in section
3

\mathbf{x}
from sampled, noisy observations
\mathbf{y}[n]
can be defined as minimization of the following cost function

f(\mathbf{x})=\frac{1}{2}\mathbf{x}^{T}\mathbf{L}\mathbf{x}+\frac{\gamma}{2}z_{\alpha,\beta}\{1-\frac{1}{N}\sum_{i=1}^{N}[\exp(-\rho|e_{i}|^{\alpha})]\},

(11)

where

denotes the
i

\mathbf{e}
,
\Phi_{i,i}

th diagonal element of the
\Phi

\gamma

and

are defined similar to (
6
). The first term in the above objective function encourages the smoothness of the reconstructed graph signal, and minimizing the second term is equivalent to maximizing the generalized correntropy, which maximizes the similarity between the observed and estimated graph signals.

4.2
Adaptive algorithm

In this section we exploit the stochastic gradient descent algorithm for the reconstruction of graph signal, which is a robust algorithm that has simple implementation and low computational cost, and, hence, is the most popular algorithm among the adaptive methods. The recovery process consists of estimating the smooth signal

4.3
Kernel width estimation

One of the parameters in the kernel function of the generalized correntropy is the scale parameter, which controls the width of the kernel function, and directly relates to the steady-state performance, convergence rate, and impulsive noise rejection. On the other hand, it is a free parameter that is often selected by the user. The value of the kernel width depend on the application properties, and, hence, determining an optimal value for it is important. In this paper, we have introduced a novel algorithm to address this issue, in which we assume a prior distribution on the (inverse of) the kernel width, and, then, learn its maximum a posteriori (MAP) estimate in an iterative procedure using the expectation maximization (EM) algorithm. The prior distribution must be chosen in such a way that it is a conjugate to the GGD distribution used for generalized correntropy, in order to obtain the posterior distribution in a closed form. Let
\theta_{i}=1/\beta_{i}
, then we assume a generalized Gamma distribution (G
\Gamma
D) with hyperparameters
a_{0}
,
d_{0}
, and
p_{0}
over
\theta_{i}
as

p(\theta_{i})=G\Gamma D(a_{0},d_{0},p_{0})=\frac{p_{0}/d_{0}^{a_{0}}}{\Gamma(d_{0}/p_{0})}\theta_{i}^{d_{0}-1}\exp\left(-\left(\frac{\theta_{i}}{d_{0}}\right)^{a_{0}}\right)

(16)

Thus, we can write

{\cal L}(\theta_{i};x_{i}[n])\propto G_{\alpha,\beta}(e_{i}[n]).p(\theta_{i})

(17)

where
{\cal L}
is the marginal likelihood of the observed data. Define
Q(\theta_{i}|\theta_{i}[n])
as the expected value of the log-likelihood function of
\theta_{i}
, given
y_{i}[n]
and the current estimate of the parameter (
\theta_{i}[n]
, where
n
is the time index); then we can write the expectation step as

E-step:

\displaystyle Q(\theta_{i}|\theta_{i}[n])

\displaystyle=\left<\ln({\cal L}(\theta_{i};x_{i}[n],y_{i}[n]))\right>

\displaystyle=\left<\ln(G_{\alpha,\beta}(e_{i}[n]))+\ln(p(\theta_{i}))\right>+\mathrm{const.}

\displaystyle=\ln(\theta_{i})-\theta_{i}^{\alpha}|e_{i}[n]|^{\alpha}+(d_{0}-1)\ln(\theta_{i})-a_{0}^{-p_{0}}\theta_{i}^{p_{0}}+\mathrm{const.}

(18)

Substituting
p_{0}=\alpha
, we have

Q(\theta_{i}|\theta_{i}[n])=d_{0}\ln(\theta_{i})-\left(|e_{i}[n]|^{\alpha}+a_{0}^{-\alpha}\right)\theta_{i}^{\alpha}

(19)

In maximization step, we search for the parameter
\theta_{i}
that maximize the above quantity:

M-step:

\theta_{i}[n+1]=\mathop{\mathrm{argmin}}_{\theta_{i}}Q(\theta_{i}|\theta_{i}[n])

(20)

which leads to the following update equations for hyperparameters

\displaystyle d[n+1]=d_{0}+1

\displaystyle a_{i}[n+1]=\left(\frac{1}{|e_{i}[n]|^{\alpha}+a_{0}^{-\alpha}}\right)^{\frac{1}{\alpha}}

(21)

5
Theoretical analysis

5.1
Convexity analysis

In this subsection, we study the convexity of the cost function (
11
). It has been proved in the literature that the first term of the cost function, which takes into account the smoothness of the signal, is convex. Therefore, we only discuss the second term, which is related to the correntropy, and we call it
\hat{f}
, i.e.,

\hat{f}(\mathbf{e}[n])=z_{\alpha,\beta}\{1-\frac{1}{N}\sum_{i=1}^{N}[\exp(-\rho|e_{i}[n]|^{\alpha})]\}

(23)

Theorem 1
.

Let
\mathbf{e}[n]=(e_{1}[n],...,e_{N}[n])^{T}
. Thus, we have

i)
if
0<\alpha<1
, then the cost function (
11
) is concave at any
\mathbf{e}
with
e_{i}\neq 0,\quad\forall i=1:N
;

ii)
if
\alpha>1
, then the cost function (
11
) is convex at any
\mathbf{e}
with
e_{i}\neq 0
and
|e_{i}[n]|<(\frac{\alpha-1}{\rho\alpha})^{\frac{1}{\alpha}},\quad\forall i=1:N
;

iii)
if
\rho\longrightarrow 0
, then, for
0<\alpha<1
the cost function (
11
) is concave at any
\mathbf{e}
with
e_{i}\neq 0
, and for
\alpha>1
, the cost function (
11
) is convex at any
\mathbf{e}
with
e_{i}\neq 0
.

Proof.

Let
\mathbf{H}(\mathbf{e})
denote the Hessian of the
\hat{f}
with respect to
\mathbf{e}[n]
. Thus, we have

h_{i,j}=\begin{cases}\rho z_{\alpha,\beta}\alpha T(e_{i})|e_{i}[n]|^{\alpha-2}\exp(-\rho|e_{i}[n]|^{\alpha})&\text{if }i=j,\\
0&\text{if }i\neq j\end{cases}

where
h_{i,j}
is the
(i,j)
’th element of the Hessian matrix
\mathbf{H}(\mathbf{e})
, and
T(v)=\alpha-1-\rho\alpha|v|^{\alpha}
. Thus, from the above equation, one can see that the sufficient condition for the convexity of
\hat{f}
is

\alpha-1-\rho\alpha|e_{i}[n]|^{\alpha}>0,\forall i=1:N

(24)

which leads to

(\frac{\alpha-1}{\rho\alpha})^{\frac{1}{\alpha}}>|e_{i}[n]|,\forall i=1:N.

(25)

Therefore, another sufficient condition for convexity of the cost function is

(\frac{\alpha-1}{\rho\alpha})^{\frac{1}{\alpha}}>|e|_{\mathrm{max}},

(26)

where
|e|_{\mathrm{max}}
is the maximum possible value of
|e_{i}[n]|
which usually occurs at the initialization step of the algorithm. It can be see that if
0<\alpha<1
, then we have
\mathbf{H}(\mathbf{e})<{\bf{0}}
at any
\mathbf{e}
with
e_{i}\neq 0,\quad\forall i=1:N
. Moreover, if
\alpha>1
, then
\mathbf{H}(\mathbf{e})>{\bf{0}}
at any
\mathbf{e}
with
e_{i}\neq 0
and
|e_{i}[n]|<(\frac{\alpha-1}{\rho\alpha})^{\frac{1}{\alpha}},\quad\forall i=1:N
. On the other hand, when
\rho\longrightarrow 0
, thus, for
0<\alpha<1
, we have
\mathbf{H}(\mathbf{e})<{\bf{0}}
at any
\mathbf{e}
with
e_{i}\neq 0
and for
\alpha>1
, we have
\mathbf{H}(\mathbf{e})>{\bf{0}}
at any
\mathbf{e}
with
e_{i}\neq 0
.
∎

5.2
Uniform stability performance

In this subsection, we use uniform decreasing condition of the cost function to analyze the uniform stability performance of the proposed GSR algorithm, which is

\Delta f=f(\mathbf{x}[n+1])-f(\mathbf{x}[n])<0.

(27)

The motivation for considering this uniform decrease in the cost function arises from a theorem in mathematical analysis which states that if a function of a sequence is decreasing and the function is lower bounded (for example be positive in our case), then the sequence converges
[
35
]
.

According to the cost function defined by equation (
11
), we have

\displaystyle\Delta f=

\displaystyle\frac{1}{2}\mathbf{x}^{T}[n+1]\mathbf{L}\mathbf{x}[n+1]-\frac{1}{2}\mathbf{x}^{T}[n]\mathbf{L}\mathbf{x}_{[}n]

\displaystyle+\frac{\gamma z_{\alpha,\beta}}{2N}\sum_{i=1}^{N}[\exp(-\rho|e_{i}[n]|^{\alpha})-\exp(-\rho|e_{i}[n+1]|^{\alpha})]

(28)

which, using equation (
15
) can be approximated as

\displaystyle\Delta f=

\displaystyle\frac{1}{2}[\left((\mathbf{I}-\xi\mathbf{L})\mathbf{x}[n]-\frac{\xi\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n])\right)^{T}\mathbf{L}

\displaystyle\times\left((\mathbf{I}-\xi\mathbf{L})\mathbf{x}[n]-\frac{\xi\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n])\right)-\mathbf{x}^{T}[n]\mathbf{L}\mathbf{x}[n]]

\displaystyle+\frac{\gamma z_{\alpha,\beta}}{2N}\sum_{i=1}^{N}{\exp(-\rho|e_{i}[n]|^{\alpha})\left(1-\exp\left(-\rho\left(|e_{i}[n+1]|^{\alpha}-|e_{i}[n]|^{\alpha}\right)\right)\right)}

\displaystyle\cong

\displaystyle\frac{\xi^{2}}{2}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\mathbf{L}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))

\displaystyle-\xi(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\mathbf{L}\mathbf{x}[n]

\displaystyle-\frac{\rho\gamma z_{\alpha,\beta}}{2N}\sum_{i=1}^{N}{\exp(-\rho|e_{i}[n]|^{\alpha})\left(|e_{i}[n+1]|^{\alpha}-|e_{i}[n]|^{\alpha}\right)}

(29)

The last term at the summation of the above equation can be rewritten as

\displaystyle|e_{i}[n+1]|^{\alpha}-|e_{i}[n]|^{\alpha}

\displaystyle=|e_{i}[n]+\Phi_{i}(\mathbf{x}[n]-\mathbf{x}[n+1])|^{\alpha}-|e_{i}[n]|^{\alpha}

\displaystyle=|e_{i}[n]+\Phi_{i}\tilde{\mathbf{e}}[n]|^{\alpha}-|e_{i}[n]|^{\alpha}

\displaystyle\cong|e_{i}[n]|^{\alpha}+\Delta P_{i}-|e_{i}[n]|^{\alpha}=\Delta P_{i}

(30)

where
\tilde{\mathbf{e}}[n]=\mathbf{x}[n]-\mathbf{x}[n+1]
, and we have

\displaystyle\Delta P_{i}=

\displaystyle|e_{i}[n]+\Phi_{i}\tilde{\mathbf{e}}[n]|^{\alpha}-|e_{i}[n]|^{\alpha}\cong|e_{i}[n]|^{\alpha}\left(1+\alpha\frac{\Phi_{i}\tilde{\mathbf{e}}[n]}{e_{i}[n]}\right)

\displaystyle-|e_{i}[n]|^{\alpha}\cong\alpha|e_{i}[n]|^{\alpha-1}\Phi_{i}\tilde{\mathbf{e}}[n]

(31)

On the other hand, from (
15
) we have
\tilde{\mathbf{e}}[n]=\xi(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))
, and
\Phi_{i}=\mathbf{h}_{i}^{T}\Phi^{T}
, thus, the summation term at the last line of (
5.2
) can be rewritten as

\displaystyle\frac{\rho\gamma z_{\alpha,\beta}}{2N}

\displaystyle\sum_{i=1}^{N}{\exp(-\rho|e_{i}[n]|^{\alpha})\left(|e_{i}[n+1]|^{\alpha}-|e_{i}[n]|^{\alpha}\right)}

\displaystyle=

\displaystyle\xi\frac{\alpha\rho\gamma z_{\alpha,\beta}}{2N}\sum_{i=1}^{N}\left({\exp(-\rho|e_{i}[n]|^{\alpha})|e_{i}[n]|^{\alpha-1}\mathbf{h}_{i}^{T}\Phi^{T}}\right)

\displaystyle\times(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))

\displaystyle=

\displaystyle\frac{\xi\alpha\rho\gamma z_{\alpha,\beta}}{2}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\Phi g(\mathbf{e}[n])

(32)

Finally, we have

\displaystyle\Delta f=

\displaystyle\frac{\xi^{2}}{2}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\mathbf{L}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))

\displaystyle-\xi(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\mathbf{L}\mathbf{x}[n]

\displaystyle-\frac{\xi\alpha\rho\gamma z_{\alpha,\beta}}{2}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\Phi g(\mathbf{e}[n])

\displaystyle=

\displaystyle\frac{\xi^{2}}{2}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}\mathbf{L}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))

\displaystyle-\xi(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))^{T}(\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n]))

(33)

As mentioned above, the condition of uniform stability is that
\Delta f
always be negative, which happens if we have

0<\xi<\frac{2\mathbf{v}^{T}\mathbf{v}}{\mathbf{v}^{T}\mathbf{L}\mathbf{v}},

where
\mathbf{v}\triangleq\mathbf{L}\mathbf{x}[n]+\frac{\rho\alpha\gamma z_{\alpha,\beta}}{2}\Phi g(\mathbf{e}[n])
. Therefore, using the Rayleigh quotient theorem, the sufficient condition for uniform stability is

0<\xi<\frac{2}{\lambda_{max}},

(34)

where
\lambda_{max}
is the maximum eigenvalue of the matrix
\mathbf{L}
.

5.3
Mean performance

In this subsection, we study the steady-state mean performance of the proposed algorithm. According to equation (
15
), we have

\mathbb{E}[\mathbf{x}[n+1]]=(\mathbf{I}-\xi\mathbf{L})\mathbb{E}[\mathbf{x}[n]]-\xi^{\prime}\Phi\mathbb{E}[g(\mathbf{e}[n])]

(35)

where
\xi^{\prime}=\frac{\xi\rho\alpha\gamma z_{\alpha,\beta}}{2}
, and
g(\mathbf{e}[n])
is defined by (
14
). When the kernel parameter
\rho
is small enough, we have

\displaystyle g(\mathbf{e}[n])\cong

\displaystyle\sum_{i=1}^{N}{\big((1-\rho|e_{i}[n]|^{\alpha})|e_{i}[n]|^{\alpha-1}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i}\big)}

\displaystyle=

\displaystyle\sum_{i=1}^{N}{\left(|e_{i}[n]|^{\alpha-1}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i}\right)}

\displaystyle-\sum_{i=1}^{N}{\left(\rho|e_{i}[n]|^{2\alpha-1}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i}\right)}

(36)

Thus, we have

\displaystyle\mathbb{E}\left[g(\mathbf{e}[n])\right]=

\displaystyle\mathbb{E}\left[\sum_{i=1}^{N}{\left(|e_{i}[n]|^{\alpha-1}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i}\right)}\right]

\displaystyle-\mathbb{E}\left[\sum_{i=1}^{N}{\left(\rho|e_{i}[n]|^{2\alpha-1}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i}\right)}\right]

(37)

By defining
\mathbb{E}[\sum_{i=1}^{N}{(\rho|e_{i}[n]|^{m}\mathrm{sign}(e_{i}[n])\mathbf{h}_{i})}]=\mathbf{U}_{n,m}
, the above equation can be rewritten as

\mathbb{E}[g(\mathbf{e}[n])]=\mathbf{U}_{n,\alpha-1}-\rho\mathbf{U}_{n,2\alpha-1}

(38)

and, thus

\mathbb{E}[\mathbf{x}[n+1]]=(\mathbf{I}-\xi\mathbf{L})\mathbb{E}[\mathbf{x}[n]]-\xi^{\prime}\Phi(\mathbf{U}_{n,\alpha-1}-\rho\mathbf{U}_{n,2\alpha-1})

(39)

Let
\mathbb{E}[\mathbf{x}[n]]=\mathbf{P}_{n}
, thus we have

\mathbf{P}_{n+1}=(\mathbf{I}-\xi\mathbf{L})\mathbf{P}_{n}-\xi^{\prime}\Phi(\mathbf{U}_{n,\alpha-1}-\rho\mathbf{U}_{n,2\alpha-1})=\mathbf{B}\mathbf{P}_{n}+\mathbf{r}_{n}

(40)

where
\mathbf{B}=\mathbf{I}-\xi\mathbf{L}
, and
\mathbf{r}_{n}=-\xi^{\prime}\Phi(\mathbf{U}_{n,\alpha-1}-\rho\mathbf{U}_{n,2\alpha-1})
. As can be seen, the above equation is a recursive equation, and we can write

\mathbb{E}[\mathbf{x}[n]]=\mathbf{P}_{n}=\mathbf{B}^{n}\mathbf{P}_{0}+\mathbf{B}^{n-1}\mathbf{r}_{0}+\mathbf{B}^{n-2}\mathbf{r}_{1}+...+\mathbf{B}\mathbf{r}_{n-2}+\mathbf{r}_{n-1}

(41)

\mathbb{E}[\mathbf{x}[n+1]]=\mathbf{P}_{n+1}=\mathbf{B}^{n+1}\mathbf{P}_{0}+\mathbf{B}^{n}\mathbf{r}_{0}+\mathbf{B}^{n-1}\mathbf{r}_{1}+...+\mathbf{B}\mathbf{r}_{n-1}+\mathbf{r}_{n}

(42)

As the algorithm reaches the steady-state, we have
\mathbb{E}[\mathbf{x}[n]]\to\mathbb{E}[\mathbf{x}[n+1]]
, which implies that

\displaystyle\mathbf{P}_{n+1}-\mathbf{P}_{n}\to 0

\displaystyle\implies(\mathbf{B}-I)(\mathbf{B}^{n}\mathbf{P}_{0}+\mathbf{B}^{n-1}\mathbf{r}_{0}+\mathbf{B}^{n-2}\mathbf{r}_{1}+...+\mathbf{B}\mathbf{r}_{n-2}+\mathbf{r}_{n-1})+\mathbf{r}_{n}\to 0

that yields

-\xi\mathbf{L}(\mathbf{B}^{n}\mathbf{P}_{0}+\mathbf{B}^{n-1}\mathbf{r}_{0}+\mathbf{B}^{n-2}\mathbf{r}_{1}+...+\mathbf{B}\mathbf{r}_{n-2}+\mathbf{r}_{n-1})+\mathbf{r}_{n}\to 0

(44)

Based on the previous assumption that the kernel parameter
\rho
is small enough, we have
\mathbf{U}_{n,m}\to 0,\forall m
, and, then,
\mathbf{r}_{n}\to 0
, thus, we can write

\mathbf{P}_{n+1}-\mathbf{P}_{n}\to-\xi\mathbf{L}(\mathbf{B}^{n}\mathbf{P}_{0})

(45)

which tend to zero if
\mathbf{B}^{n}=(\mathbf{I}-\xi\mathbf{L})^{n}=0
, i.e.,

0<1-\xi\lambda_{i}<1,\forall i=1:N

which yields

0<\xi<\frac{1}{\lambda_{max}}

(46)

where where
\lambda_{i}
and
\lambda_{max}
are the eigenvalues and the maximum eigenvalue of the matrix
\mathbf{L}
, respectively.

7
Conclusion

In this paper, a general correntropy-based adaptive graph signal recovery algorithm is devised which is suitable for robust smoothed graph signal recovery in the presence of impulsive noise. The proposed adaptive algorithm suggests to use a cost function which is a combination of graph smoothness term and a generalized correntroy term. The generalized correntropy term has two parameter of exponent and kernel width. A kernel width learning mechanism is developed in the algorithm which is based on Bayesian inference of
\beta
. Moreover, a convexity analysis of the cost function, the uniform stability, the mean convergence of the algorithm, and the complexity analysis is added in the section of theoretical analysis. In the simulation results, the benefit of learning
\beta
is firstly shown. Then, in the experiments presented in the simulation results section, it was deduced that the proposed GC-GSR algorithm has the best result in comparison to other competing algorithms which are LMS and LMP. Moreover, the experiments verify the robustness of the proposed algorithm.
