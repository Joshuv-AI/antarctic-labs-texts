Abstract
. The Kakeya conjecture is generally formulated as one the following statements: every compact/Borel/arbitrary subset of ℝ n \mathbb{R}^{n} that contains a (unit) line segment in every direction has Hausdorff dimension n n ; or, sometimes, that every closed/Borel/arbitrary subset of ℝ n \mathbb{R}^{n} that contains a full line in every direction has Hausdorff dimension n n . These statements are generally expected to be equivalent. Moreover, the condition that the set contains a line (segment) in every direction is often relaxed by requiring a line (segment) for a “large” set of directions only, where large could mean a set of positive ( n − 1 ) (n-1) -dimensional Lebesgue measure. Here we prove that all the above forms of the Kakeya conjecture are indeed equivalent. In fact, we prove that there exist d ≤ n d\leq n and a compact set C ⊂ ℝ n C\subset\mathbb{R}^{n} of Hausdorff dimension d d that contains a unit line segment in every direction (and also a closed set of dimension d d that contains a line in every direction) such that every set S ⊂ ℝ n S\subset\mathbb{R}^{n} that contains a line segment in every direction of a set of Hausdorff dimension n − 1 n-1 , must have dimension at least d d . A crucial lemma we use is the following: For every Borel set A ⊂ ℝ n A\subset\mathbb{R}^{n} of positive Lebesgue measure there exists a compact set E E of upper Minkowski dimension zero such that the Minkowski sum A + E A+E has non-empty interior. This lemma can be also used to obtain results on the duality of Hausdorff and packing dimensions via additive complements: For any non-empty Borel set A ⊂ ℝ n A\subset\mathbb{R}^{n} we show that dim H A = n − inf { dim P B : B ⊂ ℝ n Borel , A + B = ℝ n } , and dim P A = n − inf { dim H B : B ⊂ ℝ n Borel , A + B = ℝ n } . \begin{split}\dim_{H}A&=n-\inf\{\dim_{P}B:B\subset\mathbb{R}^{n}\textrm{ Borel},\ A+B=\mathbb{R}^{n}\},\text{ and}\\ \dim_{P}A&=n-\inf\{\hdim B:B\subset\mathbb{R}^{n}\textrm{ Borel},\ A+B=\mathbb{R}^{n}\}.\end{split}

1.
Introduction

1.1.
Equivalent forms of the Kakeya conjecture

The Kakeya conjecture is a famous open problem in geometric measure theory, related to harmonic analysis and additive combinatorics. It is frequently stated in many different forms, most of which (at least the more conservative ones) are generally expected to be to equivalent to each other. The aim of this paper is to show that many of these are indeed equivalent.

Let us agree on what we mean by
the Kakeya conjecture
in this paper. We will say that a subset of
\mathbb{R}^{n}
is a
Besicovitch set
if it contains a unit line segment in every direction.
The
Kakeya conjecture
is the statement that every Besicovitch
set has Hausdorff dimension
n
.
This trivially holds for
n=1
, known to be true for
n=2

(Davies
[
4
]
) and open for
n\geq 3
.

The Kakeya conjecture is sometimes stated for compact Besicovitch sets only. The variant in which
we require full lines instead of line segments also
appears often (in which case, we might want to require the set to be closed).

It is widely believed that all of these variants
are equivalent.
Moreover, it is also believed that the condition of having a line segment in
every
direction can be relaxed: requiring a line segment in a set of directions of positive
(n-1)
-dimensional Lebesgue measure should give rise to an equivalent conjecture.
Those lower bounds for the Hausdorff dimension of compact
Besicovitch sets that are obtained via partial
results for the Kakeya maximal function conjecture
give the very same bounds for compact sets that contain line segments in directions forming a set of positive
(n-1)
-dimensional Lebesgue measure.

In this paper we show that these forms of the Kakeya conjecture are equivalent. In fact, we prove that the Hausdorff dimension of all sets mentioned above (that could feature in a form of the Kakeya conjecture) are minimized by the Hausdorff dimension of a compact Besicovitch set. More precisely, we prove the following theorem.

Theorem 1.1
.

For every
n
there is a unique real number
d\leq n
with the following properties.

(1)

There exists a
compact
Besicovitch set of Hausdorff dimension
d
, that is, a compact set that contains a
unit line segment
in
every
direction.

(2)

There exists a
closed
set of Hausdorff dimension
d
that contains a
line
in
every
direction.

(3)

Let
D
be a set of directions (a subset of
\mathbb{RP}^{n-1}
) of Hausdorff dimension
n-1
, and let
S
be an arbitrary subset of
\mathbb{R}^{n}
that contains a line segment in every direction of
D
. Then
S
has Hausdorff dimension at least
d
.

In particular, this theorem implies that for every compact Besicovitch set there is a closed set of the same Hausdorff dimension that contains
lines
in every direction. It appears that this was not known. Our proof of this is rather short, the Baire category theorem in a carefully designed complete metric space gives this result (in Lemma
2.1
).

In fact, it turns out that a typical compact Besicovitch set in the Baire category sense (see Section
2
for the precise setup) has the above minimal Hausdorff dimension
d
.
This implies that it is enough to solve the Kakeya problem
for compact Besicovitch sets that have the same properties as the
typical compact Besicovitch sets.
For example, it is not hard to show that in a typical compact Besicovitch set
B\subset\mathbb{R}^{n}
the collection
\mathcal{L}
of the lines
of the unit line segments of
B
has Hausdorff dimension

n-1
and packing dimension
2n-2
.
Thus it is enough to prove the Kakeya conjecture
for compact Besicovitch sets with these properties.
Recently, Wang and Zahl
[
16
]
posed the Sticky
Kakeya conjecture, which is the
\dim_{P}\mathcal{L}=n-1
special
case of the Kakeya conjecture, and they proved it
for the
n=3
case.
As we saw above, the
\hdim\mathcal{L}=n-1
or the

\dim_{P}\mathcal{L}=2n-2

special case would imply the Kakeya conjecture.

Some steps in the proof of Theorem
1.1
are of course straightforward, and some are not. For example, it is known that given an arbitrary Besicovitch set, there is always a Borel Besicovitch set with the same Hausdorff dimension (see the proof of Lemma
2.4
).
Given a Borel Besicovitch set
B
, one could hope that techniques from descriptive set theory could yield a compact Besicovitch set
B^{\prime}
of the same dimension, perhaps as a subset of
B
. This is impossible.
Still, this is almost what we do. The Borel Besicovitch set
B
can assumed to be
G_{\delta}
(the intersection of countably many open sets).
Then we can obtain a compact subset
B^{\prime}\subset B
that contains unit line segments in directions of
D
, where
D
is some set of directions of positive
(n-1)
-dimensional measure. So
B^{\prime}
is compact, has small dimension, but does not contain line segments in every direction. One question remains: Given a set
B^{\prime}
that contains many line segments, can we obtain a set
B^{\prime\prime}
(of the same dimension) that contains line segments in all directions? The set of directions,
D
, in general, is a nowhere dense compact set, therefore taking the union of countably many affine images of
B^{\prime}
will not help. Still, perhaps surprisingly, the answer is positive.
The key observation is that the following lemma could be true and it is all we need to complete the proof.

Lemma 1.2
.

Let
A\subset\mathbb{R}^{d}
be measurable with positive Lebesgue measure. Then there is a compact set
E
of upper Minkowski dimension zero such that
A+E
has non-empty interior.

The proof of this lemma, perhaps unsurprisingly, is a random construction, building on analogous covering statements for finite sets/groups.

Theorem
1.1
and the techniques used in this paper have their limits, of course.
The Kakeya maximal function conjecture is generally considered to be stronger than the Kakeya conjecture, so it is no surprise that we do not prove here that the latter implies the former. However, the Kakeya maximal function conjecture implies that certain other “almost Besicovitch” sets have full Hausdorff dimension as well, but the techniques in this paper do not seem to handle some of these. For example, this is the case with those compact sets
C\subset\mathbb{R}^{n}
for which there is a line in every direction that intersects
C
in a set of positive
1
-dimensional Lebesgue measure. The Kakeya maximal function conjecture implies that these sets
C
have Hausdorff dimension
n
. It is unclear if the Kakeya conjecture implies the same.
(One might think that Lemma
1.2
is applicable here as well and could give us a Besicovitch set of the same dimension as
C
. Unfortunately, this is not the case.)

1.2.
Extending line segments to lines and more conjectures.

We have seen above that the distinction between full lines and line segments does not play any role in the Kakeya conjecture. Indeed, for every set containing line segments in all directions there is another set, of equal Hausdorff dimension, that contains lines in all directions. However, from another perspective, the distinction between lines and line segments is at the heart of the Kakeya conjecture: what happens if we insist on extending the line segments we have to full lines?

In
[
9
]
, one of us formulated the
Line segment extension conjecture, which states that for any collection
of line segments the Hausdorff dimension of their union
is the same as the Hausdorff dimension of the union
of the corresponding lines. In
[
9
]
it is proved
that this holds in the plane and the general case
would imply that any Besicovitch set in
\mathbb{R}^{n}

has Hausdorff dimension at least
n-1
and
Minkowski dimension
n
.

In this paper, we prove that the following conjecture is
equivalent
to the Kakeya conjecture:

Conjecture 1.3

(General Kakeya conjecture)
.

Let
E
be an arbitrary subset of
\mathbb{R}^{n}
and let

D
be
the set of directions in which
E
contains a line
segment.
Then

\hdim E\geq\hdim D+1,

provided
D
is non-empty.

We claim that Conjecture
1.3
implies the above mentioned Line segment extension conjecture of
[
9
]
.
Indeed, let
S
be the union of a collection of line segments
in
\mathbb{R}^{n}
, let
L
be the union of the collection of the corresponding lines, let
s=\hdim L
and fix
\varepsilon>0
.
Then,
using a result of Mattila
[
13
, 10.10. Theorem]
about the Hausdorff dimension of intersections of a given set with planes,
there exists a hyperplane
H
such that
\hdim L\cap H>s-1-\varepsilon
. By taking a projective transformation
\psi
that maps
H
to
the hyperplane at infinity (see e.g.
[
9
]
for a similar argument) we get
\psi(S)
, which contains a
line segment in a set of directions of Hausdorff dimension
s-1-\varepsilon
.
Then, using that projective transformations preserve Hausdorff dimension, and Conjecture
1.3
, we obtain

\hdim S=\hdim\psi(S)\geq s-1-\varepsilon+1=s-\varepsilon=\hdim L-\varepsilon\geq\hdim S-\varepsilon
,
which completes the proof of the claim.

The above mentioned connections can be summarised as
follows.

\text{Kakeya conjecture}\Longleftrightarrow\text{General Kakeya conjecture}\\
\big\Downarrow\\
\text{Line segment extension conjecture}\\
\big\Downarrow\\
\text{Every Besicovitch set in }\mathbb{R}^{n}\text{ has Hausdorff dimension at least }n-1\\
\big\Downarrow\\
\text{Kakeya Conjecture for upper Minkowski dimension}

We remark that by modifying the proof in
[
17
]

of the fact that the Kakeya maximal function conjecture
implies the Kakeya conjecture, one can prove directly that
the Kakeya maximal function conjecture also implies Conjecture
1.3
.

The equivalence of Conjecture
1.3
and the Kakeya conjecture actually follows from the following strengthening of Theorem
1.1
.

Theorem 1.4
.

For every
n\geq 2
there exist a compact Besicovitch
set
B\subset\mathbb{R}^{n}
and a closed set
F\subset\mathbb{R}^{n}
that
contains a line in every direction such that

\hdim B=\hdim F
and the following holds.

If
E
is an arbitrary subset of
\mathbb{R}^{n}
and

D
is a non-empty set of directions such that
E

contains a line segment in every direction of
D
, then

\hdim E\geq\hdim B-(n-1-\hdim D).

In fact, a typical choice of
B
and
F
are good, in the sense of the Baire category theorem, applied in a suitable metric space.

Remark 1.5
.

By a result in
[
6
]
, if
\mathcal{L}
is a non-empty
family of lines that cover a set
E\subset\mathbb{R}^{n}

such that every line of
\mathcal{L}
intersects
E
in a set of
Hausdorff dimension
1
, then

\hdim E=\dim\mathcal{L}+1
, provided that
\dim\mathcal{L}\leq 1
.
Since the map that assigns to every line its direction is
Lipschitz, this result implies
Theorem
1.4
for
n=2
and
also that
the General Kakeya Conjecture above
holds whenever
\hdim D\leq 1
.
(Thus a possible way to get closer to
the General Kakeya Conjecture
and so also to the
Kakeya conjecture is to weaken the restriction

\hdim D\leq 1
to
\hdim D\leq t
for larger
t
.
Clearly, the equivalence of the Kakeya conjecture and
the General Kakeya Conjecture
can be even more useful if one tries to disprove the
Kakeya conjecture.)

1.3.
Duality between the Hausdorff and
packing dimension of additive complements

Our main tool for proving Theorem
1.4
(and thus Theorem
1.1
) is the following extension of Lemma
1.2
.

Lemma 1.6
.

(1)

Let
A\subset\mathbb{R}^{n}
be measurable with positive Lebesgue measure. Then there is a compact set
E
of upper Minkowski dimension zero such that
A+E
has non-empty interior.

(2)

Let
A\subset\mathbb{R}^{n}
be a non-empty Borel set of Hausdorff dimension greater than
s
.
Then there is a compact set
E
of upper Minkowski dimension
n-s

such that
A+E
has non-empty interior.

To prove (1), a universal random set
E
will be constructed
such that for any fixed set
A
the random set
E
has
all the required properties, almost surely.
We will see that (2) follows from (1) by techniques that are now fairly standard.

This second part of Lemma
1.6
motivates a spin-off project, unrelated to the Kakeya conjecture.
The following two theorems show a striking duality between Hausdorff and packing dimensions via additive complements.

Theorem 1.7
.

For every non-empty Borel set
A\subset\mathbb{R}^{n}
,

(1.1)

\begin{split}\dim_{H}A&=n-\inf\{\ubdim B\,:\,B\subset\mathbb{R}^{n}\textrm{ is compact},\ \text{int}\,(A+B)\neq\emptyset\}\\
&=n-\inf\{\dim_{P}B\,:\,B\subset\mathbb{R}^{n}\textrm{ is compact},\ \text{int}\,(A+B)\neq\emptyset\}\\
&=n-\inf\{\dim_{P}B\,:\,B\subset\mathbb{R}^{n}\textrm{ is Borel},\ A+B=\mathbb{R}^{n}\}.\end{split}

Theorem 1.8
.

For any non-empty Borel set
A\subset\mathbb{R}^{n}
,

(1.2)

\begin{split}\dim_{P}A&=n-\inf\{\hdim B:B\subset\mathbb{R}^{n}\textrm{ compact},\ \text{int}\,(A+B)\neq\emptyset\}\\
&=n-\inf\{\hdim B:B\subset\mathbb{R}^{n}\textrm{ Borel},\ A+B=\mathbb{R}^{n}\}.\end{split}

The first of these, Theorem
1.7
, follows from Lemma
1.6
.

Proof of Theorem
1.7
.

It is well known (see e.g. in
[
13
]
) that for
any Borel sets
U
and
V
we have

\dim_{H}(U\times V)\leq\dim_{H}(U)+\dim_{P}(V)
.
Since
A+B
is a projection of
A\times B
,
this implies that whenever
A
and
B
are Borel sets
and
A+B=\mathbb{R}^{n}
then
\dim_{H}(A)+\dim_{P}(B)\geq n
.
Therefore the last expression is at most
\hdim A
,
so it remains to prove “
\leq
” instead of the
equalities. The first one clearly follows from
Lemma
1.6
(2), the second from
the well-known fact that
packing dimension is always less than or equal to the
upper Minkowski dimension,
and the third one from the fact that

\mathbb{R}^{n}
can be covered by countably many translates
of any set with non-empty interior.
∎

The proof of Theorem
1.8
is nearly identical, but the reference to Lemma
1.6
(2) has to be replaced by a reference to the following theorem.

Theorem 1.9
.

For any
A\subset\mathbb{R}^{n}
Borel (or analytic) set with

\dim_{P}A>s
there exists a compact set
B\subset\mathbb{R}^{n}

such that
B
has zero
(n-s)
-dimensional Hausdorff measure
and
A+B
has non-empty interior.

This theorem will be proved in Section
3
.

Theorem
1.8
is not without history.
The identity (
1.2
) is closely related to the following identity, which was proved independently
by Bishop and Peres
[
1
]
and by Y. Xiao
[
18
]
.

Theorem 1.10

(Bishop–Peres, Xiao (1996))
.

For any non-empty Borel set
A\subset\mathbb{R}^{n}
,

\dim_{P}(A)=\sup\{\hdim(A\times B)-\hdim B:B\subset\mathbb{R}^{n}\textrm{ compact}\}.

Note that Theorem
1.8
implies
the Bishop–Peres–Xiao theorem. So we actually obtain a new (and in fact much shorter) proof of Theorem
1.10
.

Remark 1.11
.

One might wonder whether infimum can be replaced by
minimum in Theorems
1.7
and
1.8
.
We claim that in general the answer is negative for both.

For Theorem
1.7
this is witnessed by a set

A=\cup_{n=1}^{\infty}A_{n}
,
where each
A_{n}
is a Borel set with

\hdim A_{n}<\hdim A
. Indeed, by the product theorem we used before, for any Borel
B
with
\dim_{P}B=n-\hdim A

we have
\dim(A_{n}+B)<n
, so
A+B=\cup_{n=1}^{\infty}A_{n}+B

is a set of measure zero, so it cannot have non-empty
interior.

By switching
\hdim
and
\dim_{P}
we get a construction for
Theorem
1.8
as well.

Proof of Theorem
1.4

using Lemma
1.6

2.1.
Baire category argument in the compact case

Our first goal is proving the following.

Lemma 2.1
.

For any non-empty compact set of
directions
E\subset\mathbb{RP}^{n-1}
the following hold:

(1) Among those compact subsets of
\mathbb{R}^{n}
that contain
a unit line segment in every direction in
E

there exists one,
B_{\min}
,
with minimal Hausdorff dimension.

(2) There exists a closed set
F\subset\mathbb{R}^{n}
that
contains a line in every direction in
E

and
\hdim F=\hdim B_{\min}
.

To prove Lemma
2.1
we use
a Baire category argument.
We use a setup similar to that in
[
2
]
.
Fix
n\geq 1
. For non-empty compact sets
C\subset\mathbb{R}^{n}
and

E\subset\mathbb{RP}^{n-1}
let

\mathcal{K}(C,E)=\{K\subset C\times E\textrm{ compact}:\proj_{2}K=E\},

where
\proj_{2}
denotes projection to the second
coordinate.
Note that
\proj_{2}K=E
means that
for each
e\in E
there is a
p\in C
with
(p,e)\in K
.

By fixing a natural metric on
\mathbb{RP}^{n-1}

and then on the product
\mathbb{R}^{n}\times\mathbb{RP}^{n-1}
we equip

\mathcal{K}(C,E)
with the Hausdorff metric. Clearly,
\mathcal{K}(C,E)

is a closed subset of the space of all compact subsets of

C\times E
, and hence it is a complete metric space.
In particular, Baire category theorem holds for
\mathcal{K}(C,E)
,
so we can speak about a typical
K\in\mathcal{K}(C,E)
in
the Baire category sense: a property
P
holds for a typical

K\in\mathcal{K}(C,E)
if

\{K\in\mathcal{K}(C,E)\ :\ P\textrm{ holds for }K\}

is residual
in
\mathcal{K}(C,E)
, or equivalently, if there is a dense

G_{\delta}
set
\mathcal{G}\subset\mathcal{K}(C,E)
such that the property
holds for every
K\in\mathcal{G}
.

For
K\in\mathcal{K}(C,E)
and
\ell\in(0,\infty]
let

S_{\ell}(K)=\bigcup_{(p,e)\in K}s(p,e,\ell),

where
s(p,e,\ell)
denotes the closed line segment
of length
\ell
with midpoint
p
and direction
e

for finite
\ell
, and the line through
p
and direction

e
for
\ell=\infty
. Clearly,
S_{\ell}(K)
is a compact set that contains a line segment in any direction
e\in E

for finite
\ell
, and it a closed set which contains
a line in every direction for
\ell=\infty
.
In particular,

S_{1}(K)
is a compact Besicovitch set for any
K\in\mathcal{K}(C,\mathbb{RP}^{n-1})
for any compact
C\subset\mathbb{R}^{n}
.

By the above observations, the last claim of the
following lemma completes the proof of
Lemma
2.1
by taking
B_{\min}=S_{1}(K)

and
F=S_{\infty}(K)
for a typical

K\in\mathcal{K}([0,1]^{n},E)
.

Lemma 2.2
.

Let
E\subset\mathbb{RP}^{n-1}
be a non-empty compact set of
directions and let

B\subset\mathbb{R}^{n}
be a compact set which contains a unit line
segment in every direction
e\in E
.
Then the following statements hold.

(1)

For any
\ell\in(0,\infty)
and compact set
C\subset\mathbb{R}^{n}

with non-empty interior there exists
K\in\mathcal{K}(C,E)
such
that
\dim_{H}S_{\ell}(K)\leq\dim_{H}B
.

(2)

For a typical
K\in\mathcal{K}([0,1]^{n},E)
we have

\dim_{H}S_{\ell}(K)\leq\dim_{H}(B)
for every
\ell\in(0,\infty]
.

(3)

For a typical
K\in\mathcal{K}([0,1]^{n},E)
we have

\dim_{H}S_{\ell}(K)\leq\dim_{H}(B^{\prime})
for every
\ell\in(0,\infty]

and any compact set
B^{\prime}\subset\mathbb{R}^{n}
which contains a unit line
segment in every direction
e\in E
.

Proof.

(1)
Let
B(a,r)
be a ball contained in
C
.
Choose finitely many compact subsets

B_{1},\ldots,B_{k}
of
B
such that every unit line segment
in
B
is contained in at least one of the sets
B_{i}
, and
for each
i
the midpoints of the unit line segments are contained
in a ball of radius
r/\ell
. By translating each
B_{i}

such that the center of the corresponding ball goes to
a
,
taking their union and magnifying by
\ell
from
a

we get a compact set
B^{\prime}
of Hausdorff dimension
at most
\dim_{H}B

which contains a line segment
of length
\ell
with midpoint in
B(a,r)\subset C
in every direction.
Then letting
K=\{(p,e)\in C\times E\ :s(p,e,\ell)\subset B^{\prime}\}

we obtain
K\in\mathcal{K}(C,E)
such
that
\dim_{H}S_{\ell}(K)\leq\dim_{H}B^{\prime}\leq\dim_{H}B
.
(A similar argument can be found in
[
5
]
.)

(2)
Since
S_{\infty}=\cup_{\ell=1}^{\infty}S_{\ell}
and
countable intersection of residual sets is residual,
it is enough to prove the claim for finite
\ell
.

Let
d=\dim_{H}(B)
and let

\mathcal{G}=\{K\in\mathcal{K}([0,1]^{n},E)\ :\ \dim_{H}S_{\ell}(K)\leq d\}.

A standard straightforward argument
(see e.g. in
[
2
, Proof of Lemma 2.2]
) gives
that
\mathcal{G}
is a
G_{\delta}
set in
\mathcal{K}([0,1]^{n},E)
.
Thus it is enough to prove that
\mathcal{G}
is dense in

\mathcal{K}([0,1]^{n},E)
.

So fix
\delta>0
and
K\in\mathcal{K}([0,1]^{n},E)
.
We need to find a
K^{\prime}\in\mathcal{G}
with
d_{H}(K^{\prime},K)<\delta
.
Choose finitely many compact sets
C_{i}\subset[0,1]^{n}
and

E_{i}\subset E
all with diameter less than
\delta/2
such that

K\subset\bigcup_{i=1}^{k}C_{i}\times E_{i}

and that
(C_{i}\times E_{i})\cap K
and
\text{int}\,C_{i}
are
non-empty for each
i
.

For each i, by applying the first part of the lemma for

C=C_{i}
and
E=(\proj_{2}K)\cap E_{i}
,
we obtain a non-empty compact set

K_{i}\subset C_{i}\times E_{i}
such that

\proj_{2}K_{i}=(\proj_{2}K)\cap E_{i}

and
\dim_{H}S_{\ell}(K_{i})\leq d
.
Then
K^{\prime}=K_{1}\cup\ldots\cup K_{k}
is a set in
\mathcal{G}
with

d_{H}(K^{\prime},K)<\delta
.

(3) Let
s
be the infimum of the Hausdorff
dimension of those compact sets that
contain a unit line segment in every
direction of
E
. Let
B_{k}
be a sequence
of such sets with
\hdim B_{k}\to s
.
Then applying (2) to each
B_{k}
and using
that having countably many typical property
is still typical we obtain (3).
∎

Applying (3) of Lemma
2.2
for
E=\mathbb{RP}^{n-1}

we obtain
the following result.

Corollary 2.3
.

Among compact Besicovitch sets, there exists one with minimal Hausdorff dimension.

This result is not new, although perhaps it has not been published before. Its proof does not require the specific complete metric space we used here. Instead, one could just use the space of compact Besicovitch sets in the Hausdorff metric, and prove that a typical set has minimal Hausdorff dimension. (This follows the general rule that typical sets, in any setting, always have minimal Hausdorff dimension.) A similar space was considered by T. Körner
[
11
]
; he proved that a typical compact Besicovitch set has zero Lebesgue measure, giving a new proof for the existence of Besicovitch sets of zero measure.

2.2.
Getting compactness

The next step is to make a compact construction from
a general one.

Lemma 2.4
.

Let
B\subset\mathbb{R}^{n}

be an arbitrary set which
contains a line segment in a set of directions
of positive outer measure.
Then there exists a compact set
E\subset\mathbb{R}^{n}

with
\hdim E\leq\hdim B

which contains a
line segment
in a compact set of directions of positive
measure.

We can also guarantee the existence of a line
such that the projection of each of these line
segments to this line has at least a fixed length.

Proof.

We can choose two parallel hyperplanes such that the direction of those line segments in
B
that have endpoints on these hyperplanes span a set of positive
(n-1)
-dimensional Lebesgue outer measure.
We may assume that these
parallel hyperplanes are
\{0\}\times\mathbb{R}^{n-1}
and

\{1\}\times\mathbb{R}^{n-1}
.
By the regularity of the Hausdorff measure,
B
is contained
in a
G_{\delta}
-set
B^{\prime}
of the same Hausdorff dimension.
Let

X=\{(a,b)\times\mathbb{R}^{n-1}\times\mathbb{R}^{n-1}:S(a,b)\subset B^{\prime}\},

where

S(a,b)=\{(t,at+b):t\in[0,1]\}.

It is straightforward to check that the fact that
B^{\prime}

is
G_{\delta}
implies that
X
is
G_{\delta}
as well.
Let
A^{\prime}=\proj_{1}X
. Being a projection of a Borel set,
A^{\prime}
is analytic, therefore Lebesgue measurable.
By our assumptions about
B
and
B^{\prime}
, and since
a
determines
the direction of
S(a,b)
, the set
A^{\prime}
has positive
(
n-1
-dimensional) measure.

Applying the Jankov–von Neumann theorem
(see e.g. in
[
8
]
) to
X\subset\mathbb{R}^{n-1}\times\mathbb{R}^{n-1}

we get a Lebesgue measurable function

f:A^{\prime}\to\mathbb{R}^{n-1}
with
\graph(f)\subset X
.
By Luzin’s theorem there exists a compact set
A\subset A^{\prime}

of positive measure such that the restriction

g=f|A:A\to\mathbb{R}^{n-1}
is continuous.
Let

E=\bigcup_{a\in A}S(a,g(a)).

Since
g
is continuous and
A
is compact,

E
is compact as well.
Note also that by construction,
E\subset B^{\prime}
,
so
\hdim E\leq\hdim B^{\prime}=\hdim B
.
Finally, clearly the projection of each

S(a,g(a))
to the first axis has unit length.
∎

2.3.
Getting all directions

For
a,b\in\mathbb{R}^{n-1}
consider the line and its “slope”

(2.1)

\ell(a,b)=\{(t,at+b):t\in\mathbb{R}\}\qquad\textrm{and}\qquad D(\ell(a,b))=a.

Note that this way we get exactly those lines of
\mathbb{R}^{n}
that
are not perpendicular to the first coordinate axis.
Clearly
D(\ell(a,b))
determines the direction of the line
and in fact there is a locally Lipschitz bijection between
the directions and the
D
of these lines.

The following lemma explains the setting in which Lemma
1.6
will be applied. Basically, given a set containing many line segments, we will use Lemma
1.6
to construct a not-much-larger set that contains even more line segments.

Lemma 2.5
.

Let
\mathcal{L}
be a collection of lines in
\mathbb{R}^{n}
such that
none of them are perpendicular to the first coordinate axis.
Let
E\subset\mathbb{R}^{n}
be arbitrary and
C\subset\mathbb{R}^{n-1}
be
a bounded set.

Then there exist a collection
\mathcal{L}^{\prime}
of lines in
\mathbb{R}^{n}

and a set
E^{\prime}\subset\mathbb{R}^{n}
with the following properties.

(1)
\hdim E^{\prime}\leq\hdim E+\ubdim C
.

(2)
D(\mathcal{L}^{\prime})=D(\mathcal{L})+C
.

(3) For every
\ell^{\prime}\in\mathcal{L}^{\prime}
there exists
\ell\in\mathcal{L}

such that
\proj_{1}(E\cap\ell)\subset\proj_{1}(E^{\prime}\cap\ell^{\prime})
.

Furthermore, if
E
and
C
are compact, then so is
E^{\prime}
.

Proof.

Let

h((t,u),v)=(t,u+tv)\qquad(t\in[0,1],u,v\in\mathbb{R}^{n-1})

and

E^{\prime}=h(E\times C).

If
E
and
C
are compact then
E^{\prime}
is clearly compact.

Using that
h:((\mathbb{R}\times\mathbb{R}^{n-1})\times\mathbb{R}^{n-1})\to\mathbb{R}^{n}

is locally Lipschitz and
a well known dimension estimate on product sets
(see e.g. in
[
13
]
), we get

\dim_{H}E^{\prime}\leq\dim_{H}(E\times C)\leq\dim_{H}E+\ubdim C,

which gives (1).

By defining

\mathcal{L}^{\prime}=\{\ell(a+c,b):\ell(a,b)\in\mathcal{L},\ c\in C\},

(2) clearly holds.

To prove (3) let
\ell^{\prime}\in\mathcal{L}^{\prime}
.
Then
\ell^{\prime}=\ell(a+c,b)
for some
\ell(a,b)\in\mathcal{L}

and
c\in C
.
It is enough to show that

\proj_{1}(E\cap\ell(a,b))\subset\proj_{1}(E^{\prime}\cap\ell(a+c,b)).

So let
t\in\proj_{1}(E\cap\ell(a,b))
.
Then
(t,at+b)\in E
.
Thus
h((t,at+b),c)\in E^{\prime}
.
Since

h((t,at+b),c)=(t,at+b+ct)\in\ell(a+c,b)

as well,
this implies that indeed
t\in\proj_{1}(E^{\prime}\cap\ell(a+c,b)
,
which completes the proof.
∎

Now we can prove, from Lemma
1.6
, the following weak version of
Theorem
1.1
.

Theorem 2.6
.

Let
d
be the Hausdorff dimension of a set in
\mathbb{R}^{n}
that contains a line segment in a set of directions
with positive outer measure.
Then

(1)

there is a
compact set
of Hausdorff dimension at most
d
that contains a
unit line segment
in every direction;

(2)

and there is a
closed set
of Hausdorff dimension at most
d

that contains a
line
in every direction.

Proof.

By Lemma
2.1
, it is enough to prove
the first part of the theorem.

Let
B\subset\mathbb{R}^{n}
be a set of Hausdorff dimension
d
that contains a line segment in a set of directions of
positive outer measure.
By Lemma
2.4
, there is a compact set
E
with
\hdim E\leq\hdim B
that contains a line segment
in
a compact set of directions of
positive measure
such that the projections of these line segments
to a fixed line has at least a fixed length.
We may assume that this line is the first axis
and this length is
1
.

Let
\mathcal{L}
be the collection of the lines of these
line segments.
Then, using the notation (
2.1
),

D(\mathcal{L})
is a compact set of positive
(
n-1
-dimensional Lebesgue) measure
and for every
\ell\in\mathcal{L}
the projection

\proj_{1}(E\cap\ell)
contains an interval of length
1
.

By Lemma
1.6
,
there exists a compact
C\subset\mathbb{R}^{n-1}
with

\ubdim C=0
and
\text{int}\,(D(\mathcal{L})+C)\neq\emptyset
.
Let
\mathcal{L}^{\prime}
be the collection of the lines and
E^{\prime}
be the set
we obtain by applying Lemma
2.5
.

Then
E^{\prime}
is compact,

\hdim E^{\prime}\leq\hdim E+\ubdim C\leq\hdim B+0=d,

and every line of
\mathcal{L}^{\prime}
intersects
E^{\prime}
in a line segment
of length at least
1
.
Since
D(\mathcal{L}^{\prime})=D(\mathcal{L})+C
has non-empty interior
this implies that
a suitable finite union of rotated copies
of

is a compact set of
Hausdorff dimension at most
d

which contains a unit line segment in every direction.
∎

2.4.
Besicovitch set from an arbitrary set and
the proof of Theorem
1.4

First we construct a Besicovitch set from an
arbitrary set.
Note that the following result clearly implies that
the General Kakeya Conjecture (Conjecture
1.3
)
is equivalent to the Kakeya conjecture.

Theorem 2.7
.

Let

be a subset of

and let

be

contains a line

By suitably rotating

.
Let
\mathcal{L}
be the collection of those lines in

that are not perpendicular to the first coordinate axis

By our assumptions and using notation (

.

Fix

By applying (2) of Lemma

for

Let
\mathcal{L}^{\prime}
be the collection of the lines and

.
Then

(2.2)

, this implies that

Now it is easy to prove our most general result,

Proof of Theorem
1.4
.

Let
B
and

be the (typical) sets we obtain when

2.1
is applied to

(as

).

and

3.
Proof of Theorem
1.9

The proof is based on a variant of a theorem
of Lorentz
[
12
]
in additive combinatorics.
For completeness we present a full proof of the
statement we need, by using a simple argument of I. Z. Ruzsa
[
14
]
.
The following lemma and its short proof
is a straightforward modification of Lemma 5.2 of

[
14
]
, which is a more general statement
but only in
\mathbb{Z}_{q}
.

Lemma 3.1

(Ruzsa)
.

Let
G
be a finite Abelian group of order
q

and let
A
be a subset of
G
with cardinality

|A|\geq tq
for some
0<t<1
and let

k=\left\lceil(\log q)/{t}\right\rceil
.

Then there exists
B\subset G
with
cardinality
k
such that
A+B=G
.

Proof.

The proof is the same as in
[
14
]
, it is
included for completeness.
Choose
B
as a random
k
-element subset
of
G
, by taking each
q\choose k

k
-element
subset of
G
with equal probability.
Fix
g\in G
.
Since
g\not\in A+B
if and only if
B\cap(g-A)=\emptyset
, the probability of this event is

(3.1)

{{q-|A|}\choose k}/{q\choose k}\leq{{q(1-t)}\choose k}/{q\choose k}<(1-t)^{k}.

Thus the expected value of
|G\setminus(A+B)|
is
less than
(1-t)^{k}q\leq e^{-tk}q\leq 1
, so
with positive probability
A+B=G
.
∎

Lemma 3.2

(Higher dimensional variant
of a theorem of Lorentz
[
12
]
)
.

Let
U\subset\{0,1,\ldots,m-1\}^{n}
with

|U|\geq m^{\alpha}
.
Then there exists

V\subset\{-(m-1),-(m-2),\ldots,m-1\}^{n}

such that

U+V\supset\{0,1,\ldots,m-1\}^{n}

and

|V|\leq 2^{n}\lceil n\cdot m^{n-\alpha}\cdot\log m\rceil
.

Proof.

We apply Lemma
3.1
to

G=\mathbb{Z}_{m}^{n},q=m^{n},t=m^{\alpha-n}
to obtain a set

B\subset\mathbb{Z}_{m}^{n}
such that
U+B=\mathbb{Z}_{m}
and

|B|\leq\left\lceil(\log m^{n})/m^{\alpha-n}\right\rceil=\lceil n\cdot m^{n-\alpha}\cdot\log m\rceil
.
By taking
2^{n}
copies of
B
we get a

V\subset\{-m,-(m-1),\ldots,m-1\}^{n}
with the right
cardinality and with
U+V\supset\{0,1,\ldots,m-1\}^{n}
.
Note that for the last containment any
v\in V
with
any
-m
coordinate would
be superfluous, so we can can suppose that

V\subset\{-(m-1),-(m-2),\ldots,m-1\}^{n}
, which
completes the proof.
∎

The following technical lemma would be obvious
without taking the interiors of the cubes, this

Lemma 3.3
.

If

then there exists arbitrarily large

Proof.

Let

\mathcal{Q}_{m}

\overline{\mathcal{Q}}_{m}

\mathcal{Q}_{m}

The condition

By Chebyshev’s theorem there exist distinct

.

Let

For every

(3.2)

|V|\leq 2^{n}\lceil n\cdot m^{n-s^{\prime}}\cdot\log m\rceil.

Then let

\mathcal{J}^{e}=\{b+(h/m)v+[-h/m,h/m]^{n}\ :\ v\in V\}.

Then (
1
) and (
5
) clearly
holds for
k+1
, so it remains to show (
3.2
)
and (
3.3
).
Note that (
3.2
) follows from (
3.4
)
and (
3.5
).

It remains to check (
3.3
).
Note that

\{(1/3)(I^{\prime}+J^{\prime})\ :\ (I^{\prime},J^{\prime})\in\mathcal{I}^{e}\times J^{e}\}=\{a+b+(h/m)(u+v)+[0,h/m]^{n}\ :\ u\in U,v\in V\}.

Since
U+V\supset\{0,1,\ldots,m-1\}^{n}
, the union
of these cubes indeed cover

\frac{1}{3}(I+J)=a+b+[0,h]^{n}
,
which completes the proof of (
3.3
)
and the lemma.
∎

Proof of Theorem
1.9
.

By a result of H. Joyce and D. Preiss
[
7
]

there exists a compact set
A^{\prime}\subset A
with
\dim_{P}A^{\prime}>s
.
We can clearly suppose that
A^{\prime}\subset(0,1)^{n}
.
Let
\mathcal{C}
be the collection of those open
cubes that intersect
A^{\prime}
in a set of packing dimension
at most
s
, and let
\mathcal{C}^{\prime}
be those cubes in
\mathcal{C}
that
have vertices with rational coordinates only.
Then cubes in
\mathcal{C}
and
\mathcal{C}^{\prime}
have the very same
union
U
and, since
\mathcal{C}^{\prime}
is countable,

\dim_{P}(A^{\prime}\cap U)\leq s
. Thus
A^{\prime\prime}=A^{\prime}\setminus U
is a
non-empty compact
subset of
[0,1]^{n}
such that for any open cube
Q

that intersects
A^{\prime\prime}
,

\ubdim(Q\cap A^{\prime\prime})\geq\dim_{P}(Q\cap A^{\prime\prime})>s
.
Therefore Lemma
3.4
can be applied
to
A^{\prime\prime}
.
∎

4.
Proof of Lemma
1.6

Our first goal is to show that (1) implies (2) in Lemma
1.6
.
For this we need the following lemma.
This argument was also used
in
[
10
, Theorem 2.9]
.

Lemma 4.1
.

For every
s,t\in[0,n]
and non-empty
Borel set
A\subset\mathbb{R}^{n}
of Hausdorff dimension
s
there is a compact
set
B\subset\mathbb{R}^{n}
of upper Minkowski dimension
t
such that
A+B
has Hausdorff dimension
\min(s+t,n)
. If
s+t>n
, it has positive Lebesgue measure.

Proof.

Let
B_{1}
be a compact set (for example a self-similar set)
with
\hdim B_{1}=\ubdim B_{1}=t
.
Then
\hdim(A\times B_{1})=s+t
, so by the projection
theorem of Marstrand and Mattila, its orthogonal
projection to almost every
n
-dimensional subspace
of
\mathbb{R}^{2n}
has Hausdorff
\min(s+t,n)
and it has
positive Lebesgue measure if
s+t>n
.
This implies that a suitable affine copy of
B_{1}

has all the properties we wanted for
B
.
∎

Proof of (1)
\Rightarrow
(2) in Lemma
1.6
.

Let
A\subset\mathbb{R}^{n}
be a non-empty Borel set of Hausdorf
dimension greater than
s
.
By a theorem of Davies
[
3
]
,
A
contains a
compact subset of Hausdorf
dimension greater than
s
, so we can suppose
that
A
is compact.
By Lemma
4.1
there exists a compact set

B_{1}\subset\mathbb{R}^{n}
of upper Minkowski dimension
n-s
such
that
A+B
has positive Lebesgue measure.
By applying (1) of Lemma
1.6
to the compact set

A+B
we obtain a compact set
E_{1}
of upper Minkowski
dimension zero such that
(A+B)+E_{1}
has non-empty
interior. Then
E=B+E_{1}
is a compact set of
upper Minkowski dimension
n-s
such that
A+E

has non-empty interior.
∎

It remains to prove (1) of Lemma
1.6
.
Let
d_{j}
and
m_{j}
be increasing sequences of integers. Let
1\leq m_{j}\leq d_{j}^{n}
. We now define a random compact set.
For each positive integer
d
we divide
[0,1]^{n}
into
d^{n}
grid cubes of equal side length
and denote by
f^{d}_{1},\ldots,f^{d}_{d^{n}}
the homothetic
maps that map
[0,1]^{n}
onto these cubes.
Consider the finite sequences

(i_{1},\ldots,i_{k})\in\{1,\ldots,m_{1}\}\times\ldots\times\{1,\ldots,m_{k}\}

and to each of them we assign a random number

j(i_{1},\ldots,j_{k})\in\{1,\ldots,d_{k}^{n}\}

by choosing for each

(i_{1},\ldots,i_{k-1})

distinct
j(i_{1},\ldots,i_{k-1},1),\ldots,j(i_{1},\ldots,i_{k-1},m_{k})
randomly such that
each selection has probability
{d_{k}^{n}\choose m_{k}}^{-1}
.
Let

E_{k}=\bigcup_{i_{1}=1}^{m_{1}}\ldots\bigcup_{i_{k}=1}^{m_{k}}f^{d_{1}}_{j(i_{1})}\circ f^{d_{2}}_{j(i_{1},i_{2})}\ldots\circ f^{d_{k}}_{j(i_{1},\ldots,i_{k})}([0,1]^{n})

and let
E=\bigcap E_{k}
.

With this construction, the upper Minkowski dimension of
E
(always) satisfies

(4.1)

\limsup_{k}\frac{\log(m_{1}\ldots m_{k})}{\log(d_{1}\ldots d_{k})}\leq\overline{\dim}_{M}(E)\leq\limsup_{k}\frac{\log((m_{1}\ldots m_{k})m_{k+1})}{\log((d_{1}\ldots d_{k})m_{k+1}^{1/n})}.

We will only use the upper bound.

Fix

d_{k}=2^{k}

and

m_{k}=\min(k^{2n+5},d_{k}^{n});

this is a choice that will work but it is not optimal in any sense.
Then the random compact set
E
has Minkowski dimension zero by (
4.1
).
Thus the following theorem will complete the proof
of Lemma
1.6
.

Theorem 4.2
.

Let
A\subset\mathbb{R}^{n}
be a
Lebesgue measurable
set of positive Lebesgue measure. Let
E
be the random compact set as described above. Then
A+E
has non-empty interior almost surely.

Proof.

It is enough to show that the probability in question is positive since Kolmogorov’s zero–one law can be applied: We claim that it is a tail event that the set
A+E
has non-empty interior. That is, if we change the construction of
E
arbitrarily in finitely many levels to obtain
E^{\prime}
, then
A+E
has non-empty interior if and only if
A+E^{\prime}
has non-empty interior. Indeed,
E^{\prime}
can be covered by finitely many translates of
E
and vice versa. Therefore the same applies to
A+E
and
A+E^{\prime}
. The Baire category theorem concludes the argument.

The following statement enables us to replace the set
A
with another that has uniform lower bounds on the local densities around every point.

Lemma 4.3
.

Let
r_{k}
,
\varepsilon_{k}
be decreasing
sequences of positive reals tending to zero such that

\sum\varepsilon_{k}<\infty.

Let
A_{0}\subset\mathbb{R}^{n}
be a
Lebesgue measurable set of positive measure.
Then there is a non-empty
compact subset
A\subset A_{0}

such that

(4.2)

\exists k_{0}\geq 1\ \ \forall k\geq k_{0}\ \ \forall x\in A\ \ \lambda(A\cap(x+[-r_{k},r_{k}]^{n}))\geq(2r_{k})^{n}\varepsilon_{k}.

Proof.

By regularity we may assume that
A_{0}
is compact.
Note that if (
4.2
) holds for
A
then it also
holds for its closure, so we do not need to
guarantee the compactness of
A
.

By modifying
\varepsilon_{k}
, we may assume that each
r_{k}
is an integer power of
1/2
and it is enough to prove that the density of
A
in every closed dyadic grid cube of side length
r_{k}
it intersects is at least
\varepsilon_{k}
(for every sufficiently large
k
).

By applying Lebesgue’s density theorem,
choose
k_{0}
and a dyadic grid cube
I
of side length
r_{k_{0}}
such that

(4.3)

\lambda(A_{0}\cap I)\geq\lambda(I)/2\qquad\textrm{and}\qquad\sum_{k=k_{0}}^{\infty}\varepsilon_{k}<1/4,

and let
A_{1}=A_{0}\cap I
.
We define a finite or infinite sequence of nested sets
A_{1}\supset A_{2}\supset\cdots
recursively.
Suppose that
A_{j}
is already defined.
Take a maximal (closed) dyadic grid cube

J_{j}\subset I
with side length
r_{k_{j}}
such that
J_{j}
intersects
A_{j}
and
the density of
A_{j}
in
J_{j}
is less than
\varepsilon_{k_{j}}
.
If there is no such cube, then we let

A=A_{j}
. Otherwise let
A_{j+1}=A_{j}\setminus J_{j}
and continue the procedure.
If this procedure does not terminate after finitely many
steps then let
A=\cap_{j=1}^{\infty}A_{j}
.

If the sequence terminates after finitely many steps, then the density of
A
in every dyadic grid cube of side length
r_{k}
it intersects is at least
\varepsilon_{k}
for
every
k\geq k_{0}
. Otherwise, although the sequence
k_{j}
is not necessarily
non-decreasing, it must be unbounded since there are only
finitely many dyadic grid cubes of given size in
I
.
Using also that we always took maximal cubes, this implies
that the density of
A
in every dyadic grid cube of side length
r_{k}
it intersects is at least
\varepsilon_{k}
for
every
k\geq k_{0}
.

It remains to prove that
A
is non-empty.
Using first the fact that
for each
k
the subtracted cubes
J_{j}
of side length

r_{k}
are nonoverlapping subcubes of

I
and then (
4.3
), we obtain

\lambda(A)\geq\lambda(A_{1})-\lambda(I)\sum_{k=k_{0}}^{\infty}\varepsilon_{k}\geq\lambda(I)/2-\lambda(I)/4>0.

∎

We continue with the proof of Theorem
4.2
.
Recall that
d_{k}
and
m_{k}
are already defined.
Let

\varepsilon_{k}=1/k^{2}\qquad\textrm{and}\qquad r_{k}=\frac{\varepsilon_{k}}{20nd_{1}\cdots d_{k}}.

By applying Lemma
4.3
,
we may assume that the set
A
is compact
for which (
4.2
) holds.

Our aim is, essentially, to show that if

A+E_{k}\supset[0,1]^{n},

then with large probability,

A+E_{k+1}\supset[0,1]^{n}.

We will prove a similar implication, but we will need to consider some additional sets. Let

\alpha_{k}=1-\varepsilon_{k}/(10n),

and

\beta_{k}=1-2\varepsilon_{k}/(10n).

For each
k\geq 0
, consider the
m_{1}\cdots m_{k}
many cubes forming
E_{k}
and replace each of these with another cube of the same midpoint but of side length
\alpha_{k}/(d_{1}\cdots d_{k})
. Take their union to obtain the set
E^{\prime}_{k}
. We also form
E^{\prime\prime}_{k}
from
E_{k}
in the same way but replacing
\alpha_{k}
with
\beta_{k}
.

Claim 4.4
.

There exists
k_{0}
such that for every
k\geq k_{0}
,

\mathbb{P}\big(A+E^{\prime}_{k+1}\supset A+E^{\prime}_{k})\geq 1-2^{-k}.

In fact the same estimate holds conditionally if we fix
E_{k}
arbitrarily.

Proof.

Assume that
E_{k}
is fixed. Fix any
x\in A+E^{\prime}_{k}
. First we will estimate the probability that

x\in A+E^{\prime\prime}_{k+1}.

Since
x\in A+E^{\prime}_{k}
, we can fix
a\in A
and
e\in E^{\prime}_{k}
such that
x=a+e
. Let
I^{\prime}
be the cube of
E^{\prime}_{k}
that contains
e
. Let
I
be the corresponding cube of
E_{k}
.
Consider the
d_{k+1}^{n}
many grid cubes that
I
is divided into during the construction of the random set
E_{k+1}
. Let these be
I_{j}
(
1\leq j\leq d_{k+1}^{n}
). We will denote the corresponding
\beta_{k}
-shrinked versions of these by
I^{\prime\prime}_{j}
. Then the random set

E^{\prime\prime}_{k+1}\cap I

contains the union of
m_{k+1}
many of these cubes
I^{\prime\prime}_{j}
chosen uniformly randomly.

Denoting side lengths of cubes by
|\cdot|
, now consider the cube

J=[-|I|\varepsilon_{k}/(20n),\ |I|\varepsilon_{k}/(20n)]^{n}=[-r_{k},r_{k}]^{n}.

By the choice of
\alpha_{k}
, we have

I^{\prime}+J=I.

Since
e\in I^{\prime}
, we have

e+J\subset I.

Let
\mathcal{I}
be the collection of those cubes
I_{j}
that are contained in
e+J
.
Similarly, let
\mathcal{I}^{\prime\prime}
be the collection of those cubes
I^{\prime\prime}_{j}
that are contained by
e+J
.
Then we have

\lambda\left((e+J)\cap\bigcup\mathcal{I}\right)\geq(|J|-2|I|/d_{k+1})^{n}=|J|^{n}\left(1-\frac{20n}{\varepsilon_{k}d_{k+1}}\right)^{n}

and

(4.4)

\displaystyle\lambda\left((e+J)\cap\bigcup\mathcal{I}^{\prime\prime}\right)

\displaystyle\geq

\displaystyle\beta_{k}^{n}|J|^{n}\left(1-\frac{20n}{\varepsilon_{k}d_{k+1}}\right)^{n}\geq|J|^{n}\left(\beta_{k}-\frac{20n}{\varepsilon_{k}d_{k+1}}\right)^{n}

\displaystyle\geq

\displaystyle|J|^{n}\left(1-\frac{3\varepsilon_{k}}{10n}\right)^{n}\geq|J|^{n}\left(1-\frac{3\varepsilon_{k}}{10}\right),

assuming, in the penultimate inequality, that
k
(and thus
d_{k}
) is large enough so that

\frac{20n}{\varepsilon_{k}d_{k+1}}<\frac{\varepsilon_{k}}{10n}

holds.

If
k
is large enough, by (
4.2
), we have

\lambda(A\cap(a-J))\geq\varepsilon_{k}|J|^{n}.

Using that
x=a+e
and that Lebesgue measure is isometry invariant, we obtain

(4.5)

\lambda\Big((e+J)\cap(x-A)\Big)\geq\varepsilon_{k}|J|^{n}.

Combining (
4.4
) and (
4.5
) we obtain

(4.6)

\lambda\Big((e+J)\cap(x-A)\cap\bigcup\mathcal{I}^{\prime\prime}\Big)\geq(\varepsilon_{k}-3\varepsilon_{k}/10)|J|^{n}\geq 7\varepsilon_{k}|J|^{n}/10=c_{n}\varepsilon_{k}^{n+1}|I|^{n},

where
c_{n}=7/(10^{n+1}n^{n})
.
This implies that
x-A
intersects at least

c_{n}\varepsilon_{k}^{n+1}d_{k}^{n}

many cubes
I^{\prime\prime}_{j}
(of
\mathcal{I}^{\prime\prime}
). If
E^{\prime\prime}_{k+1}
contains one of these, say
I^{\prime\prime}_{j}
, then

\emptyset\neq(x-A)\cap I^{\prime\prime}_{j}\subset(x-A)\cap E^{\prime\prime}_{k+1}

and therefore
x\in A+E^{\prime\prime}_{k+1}
.
Since by construction
E^{\prime\prime}_{k+1}
contains
uniformly randomly chosen
m_{k+1}
many of

I_{1}^{\prime\prime},\ldots,I^{\prime\prime}_{d_{k+1}^{n}}
,
as in (
3.1
) we obtain that
the probability that
E^{\prime\prime}_{k+1}
does not contain any of
the at least
c_{n}\varepsilon_{k}^{n+1}d_{k+1}^{n}
many

I_{j}^{\prime\prime}
that intersect
x-A
is at most

(1-c_{n}\varepsilon_{k}^{n+1})^{m_{k+1}}.

Therefore the probability of
x\notin A+E^{\prime\prime}_{k+1}
is at most

(4.7)

(1-c_{n}\varepsilon_{k}^{n+1})^{m_{k+1}}.

Now let

\delta=\varepsilon_{k+1}/(20nd_{1}\cdots d_{k+1}).

Comparing
\delta
with
\alpha_{k+1}
and
\beta_{k+1}
we obtain

(4.8)

B(E^{\prime\prime}_{k+1},\delta)\subset E^{\prime}_{k+1}.

For simplicity, assume that
A\subset[0,1]^{n}
. Let
S
be a maximal
\delta
-separated subset of
A+E^{\prime}_{k}\subset[0,2]^{n}
.
Then

|S|\leq C_{n}\delta^{-n}

for some constant
C_{n}
depending on
n
only, and we have

(4.9)

A+E^{\prime}_{k}\subset B(S,\delta).

Now note that if
S\subset A+E^{\prime\prime}_{k+1}
(which may or may not hold), then (by (
4.8
) and (
4.9
)),

A+E^{\prime}_{k}\subset B(S,\delta)\subset B(A+E^{\prime\prime}_{k+1},\delta)=A+B(E^{\prime\prime}_{k+1},\delta)\subset A+E^{\prime}_{k+1}.

Now vary
x
over the points of
S
. By (
4.7
), the probability that
S\subset A+E^{\prime\prime}_{k+1}
is at least

1-|S|(1-c_{n}\varepsilon_{k}^{n+1})^{m_{k+1}}.

Therefore

\mathbb{P}(A+E^{\prime}_{k}\subset A+E^{\prime}_{k+1})\geq 1-|S|(1-c_{n}\varepsilon_{k}^{n+1})^{m_{k+1}}

where the probability can be understood conditional on fixing
E_{k}
arbitrarily.
The choice of
d_{k}=2^{k}
and
m_{k}=k^{2n+5}
(for large enough
k
) gives that

|S|\leq C^{\prime}_{n}\,2^{nk^{2}}/\varepsilon_{k+1}^{n}=C^{\prime}_{n}\,2^{nk^{2}}(k+1)^{2n}

and

(1-c_{n}\varepsilon_{k}^{n+1})^{m_{k+1}}=\left(1-\frac{7}{(10k^{2})^{n+1}n^{n}}\right)^{(k+1)^{2n+5}}\leq 2^{-C^{\prime\prime}_{n}k^{3}},

where the constants
C^{\prime}_{n}
,
C^{\prime\prime}_{n}
(and later
C^{\prime\prime\prime}_{n}

as well) are positive and depend only on

.
Therefore

\mathbb{P}(A+E^{\prime}_{k}\subset A+E^{\prime}_{k+1})\geq 1-C^{\prime}_{n}(k+1)^{2n}2^{nk^{2}}2^{-C^{\prime\prime}_{n}k^{3}}\geq 1-2^{-C^{\prime\prime\prime}_{n}k^{3}}\geq 1-2^{-k}

when
k
is large enough. This finishes the proof of the Claim.
∎

Applying the claim for
k\geq k_{0}
, we obtain that with positive probability,

A+E^{\prime}_{k_{0}}\subset A+E^{\prime}_{k_{0}+1}\subset\cdots.

Therefore, with positive probability,

A+E^{\prime}_{k_{0}}\subset A+E.

Since
E^{\prime}_{k_{0}}
and thus

have non-empty interior, this finishes the proof of Theorem

.
∎
