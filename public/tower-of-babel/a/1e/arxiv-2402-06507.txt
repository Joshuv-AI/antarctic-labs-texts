Non-Conforming Finite Element Method For Constrained Dirichlet Boundary Control Problem
Sudipto Chowdhury, Divay Garg

Abstract
This article examines the Dirichlet boundary control problem governed by the Poisson equation, where the control variables are square integrable functions defined on the boundary of a two dimensional bounded, convex, polygonal domain. It employs an ultra weak formulation and utilizes Crouzeix-Raviart finite elements to discretize the state variable, while employing piecewise constants for the control variable discretization. The study demonstrates that the energy norm of an enriched discrete optimal control is uniformly bounded with respect to the discretization parameter. Furthermore, it establishes an optimal order a priori error estimate for the control variable.



Keywords:

Optimal control problem, Crouziex-Raviart, Finite element method, A priori error analysis, Control constraints

65N30, 65N15, 65N12, 65K10

Introduction

We consider the control constrained Dirichlet boundary control problem on a convex and bounded polygonal domain
\displaystyle\Omega\subseteq\mathbb{R}^{2}
. We denote the polygonal boundary of the domain
\displaystyle\Omega
by
\displaystyle\Gamma:=\cup_{j=1}^{k}\Gamma_{j}
, where
\displaystyle\Gamma_{j}
is a straight line segment for all
\displaystyle 1\leq j\leq k
. The minimization problem seeks a pair
\displaystyle(\bar{y},\bar{u})\in L_{2}(\Omega)\times U_{ad}
such that

\displaystyle\displaystyle J(\bar{y},\bar{u})=\min_{(y,u)\in L_{2}(\Omega)\times U_{ad}}J(y,u),

(1.1)

subject to the following second order elliptic equation:

\displaystyle\displaystyle\begin{cases}-\Delta y&=f\quad\text{in}\quad\Omega,\\
\hskip 11.38092pty&=u\quad\text{on}\quad\Gamma.\end{cases}

(1.2)

The given function
\displaystyle f\in L_{2}(\Omega)
denotes the force which acts on the system externally and
\displaystyle U_{ad}\subseteq L_{2}(\Gamma)
is the set of admissible controls which will be defined later. The quadratic cost functional

\displaystyle J(\cdot,\cdot):L_{2}(\Omega)\times L_{2}(\Gamma)\rightarrow\mathbb{R}
is defined in the following manner:

\displaystyle\displaystyle J(y,u):=\frac{1}{2}\int_{\Omega}|y-y_{d}|^{2}\,dx+\frac{\alpha}{2}\int_{\Gamma}|u|^{2}\,ds,

(1.3)

where
\displaystyle y_{d}\in L_{2}(\Omega)
is the given desired state and
\displaystyle\alpha>0
is known parameter which is introduced for the regularization.
The state equation (
1.2
) under the standard weak formulation is not well posed for
\displaystyle u\in L_{2}(\Gamma)
as the weak solution of (
1.2
) lie in
\displaystyle H^{1}(\Omega)
space and therefore by trace theorem
[
7
]
, the first trace of it must lie in
\displaystyle H^{1/2}(\Gamma)
which is not the case in this formulation. There are multiple techniques available in the literature to overcome this variational difficulty, one of which is to use the method of transposition which is also known as the ultra weak formulation
[
11
,
24
]
. In brevity, we discuss the method of transposition. Define a test function space as follows:

\displaystyle\displaystyle X:=\{\phi\in H^{1}_{0}(\Omega):\Delta\phi\in L_{2}(\Omega)\}.

By elliptic regularity theory on convex polygonal domains, we have
\displaystyle X=H^{2}(\Omega)\cap H^{1}_{0}(\Omega)
.
Now, we obtain the ultra weak formulation of the state equation (
1.2
). Multiplying
\displaystyle\phi\in X
in both sides of (
1.2
) and then integrate both the sides to find

\displaystyle\displaystyle-\int_{\Omega}\Delta y\,\phi\,dx

\displaystyle\displaystyle=\int_{\Omega}f\,\phi\,dx.

A use of integration by parts in the above equation yields

\displaystyle\displaystyle\int_{\Omega}f\,\phi\,dx

\displaystyle\displaystyle=\int_{\Omega}\nabla y\cdot\nabla\phi\,dx-\int_{\Gamma}\phi\,\frac{\partial y}{\partial n}\,ds

\displaystyle\displaystyle=\int_{\Omega}\nabla y\cdot\nabla\phi\,dx,

where we have used the fact that
\displaystyle\phi\in H^{1}_{0}(\Omega)
to get the last equality. The idea in the method of transposition is to apply the integration by parts once more. By doing so, we get

\displaystyle\displaystyle\int_{\Omega}f\,\phi\,dx

\displaystyle\displaystyle=-\int_{\Omega}y\,\Delta\phi\,dx+\int_{\Gamma}y\,\frac{\partial\phi}{\partial n}\,ds.

Thus, the ultra weak formulation of (
1.2
) can be stated as: Given
\displaystyle f\in L_{2}(\Omega)
and
\displaystyle u\in L_{2}(\Gamma)
, find
\displaystyle y\in L_{2}(\Omega)
such that

\displaystyle\displaystyle(y,\Delta\phi)

\displaystyle\displaystyle=-(f,\phi)+\langle u,\partial\phi/\partial n\rangle\quad\forall~\phi\in X,

(1.4)

where
\displaystyle(\cdot,\cdot)
and
\displaystyle\langle\cdot,\cdot\rangle
denotes the
\displaystyle L_{2}
inner product on the domain
\displaystyle\Omega
and its boundary
\displaystyle\Gamma
respectively. Another approach to study second order Dirichlet boundary control problem is to
transform the Dirichlet boundary condition into Robin’s type boundary condition
[
12
]
. Other method is to employ the energy space based approach in which the control is penalized in the energy space
\displaystyle H^{1/2}(\Gamma)

[
13
,
26
]
. In this article the control variable is discretized with piecewise constant finite elements while the state and adjoint states are discretized using first-order non conforming Crouzeix Raviart finite elements.

In the finite element analysis for the Dirichlet boundary control problems addressed so far in the literature polynomial degrees used to discretize the state variable or the adjoint state variable and the control variable happens to be the same. But in this article we have discretized the control variable with piecewise constant finite elements whereas the state and adjoint variables are discretized using Crouzeix Raviart finite elements. Therefore the main challenge is to associate the discrete state variables with the discrete control variables via an invertible bounded linear operator such that the operator norm of the inverse remains uniformly bounded with respect to the discretization parameter
\displaystyle h>0
(to be defined later).
In order to construct this operator in (
4.21
) a mild restriction on the triangulation is imposed (discussed in Section 4 ).
This constitutes one of the main novelties of this article. Apart from this an enrichment operator is introduced satisfying the orthogonality described in Theorem
3.4
, which plays a crucial role in the entire analysis. Moreover in Theorem
4.1
,
4.2
,
4.3
,
5.2
and
4.5
several super convergence results are derived, which also contributes significantly to the novelty of this article.

Any generic member of

\displaystyle x_{1}

Remark 2.1
.

When
\displaystyle v
belongs to
\displaystyle H^{2}(\Omega)
, the trace of its gradient, denoted by
\displaystyle\nabla v|_{\Gamma}
, lies in
\displaystyle H^{1/2}(\Gamma)^{2}
. If
\displaystyle\Gamma
has a smooth boundary, the outwards unit normal vector
\displaystyle n
is continuous, allowing the definition of the normal derivative
\displaystyle\partial_{n}v=n\cdot\nabla v
to be well defined. Thus
\displaystyle\partial_{n}v\in H^{1/2}(\Gamma)
for
\displaystyle v\in H^{2}(\Omega)
and the following estimate holds:

\displaystyle\displaystyle\|\partial_{n}v\|_{H^{1/2}(\Gamma)}\leq C\|v\|_{H^{2}(\Omega)},\quad v\in H^{2}(\Omega).

However, this estimate is not applicable for polygonal boundaries
\displaystyle\Gamma
, which are only Lipschitz continuous. Nonetheless, for
\displaystyle v\in H^{2}(\Omega)
, we still have
\displaystyle\partial_{n}v|_{\Gamma_{j}}\in H^{1/2}(\Gamma_{j})
for each straight component
\displaystyle\Gamma_{j}
,
\displaystyle 1\leq j\leq k
of
\displaystyle\Gamma
. To accommodate this, we introduce the space
\displaystyle\tilde{H}^{1/2}(\Gamma):=\{v\in L_{2}(\Gamma),v|_{\Gamma_{j}}\in H^{1/2}(\Gamma_{j})\quad\forall~1\leq j\leq m\}
. We denote by
\displaystyle\tilde{H}^{-1/2}(\Gamma)
the completion of
\displaystyle L_{2}(\Gamma)
with respect to the following dual norm on
\displaystyle L_{2}(\Gamma)

\displaystyle\displaystyle\|\mu\|_{\tilde{H}^{-1/2}(\Gamma)}:=\sup\limits_{v\in X\setminus\{0\}}\frac{\langle\mu,\partial_{n}v\rangle}{\|v\|_{H^{2}(\Omega)}}\leq\sup_{v\in\tilde{H}^{1/2}(\Gamma),v\neq 0}\frac{\langle\mu,v\rangle}{\|v\|_{\tilde{H}^{1/2}(\Gamma)}}.

Note that
\displaystyle\tilde{H}^{-1/2}(\Gamma)
is not in general the dual space of
\displaystyle\tilde{H}^{1/2}(\Gamma)
. In the case of a smooth boundary
\displaystyle\Gamma
,
the mapping
\displaystyle\partial_{n}:X\rightarrow H^{1/2}(\Gamma)
is surjective, so
\displaystyle\tilde{H}^{-1/2}(\Gamma)=H^{-1/2}(\Gamma)
.

For any
\displaystyle u\in\tilde{H}^{-1/2}(\Gamma)
, the harmonic extension of
\displaystyle u
is denoted by
\displaystyle y_{u}\in L_{2}(\Omega)
which satisfies the following equation:

\displaystyle\displaystyle(y_{u},\Delta\phi)

\displaystyle\displaystyle=\langle u,\partial_{n}\phi\rangle\quad\forall~\phi\in X.

(2.1)

The function
\displaystyle u\in\tilde{H}^{-1/2}(\Gamma)
is known as the ultra weak trace of
\displaystyle y_{u}\in L_{2}(\Omega)
and the following trace estimate holds true:

\displaystyle\displaystyle\|u\|_{\tilde{H}^{-1/2}(\Gamma)}=\sup\limits_{\phi\in X\setminus\{0\}}\frac{(y_{u},\Delta\phi)}{\|\phi\|_{H^{2}(\Omega)}}\lesssim\|y_{u}\|_{L_{2}(\Omega)}.

Furthermore, if
\displaystyle u\in H^{1/2}(\Gamma)
, then
\displaystyle y_{u}\in H^{1}(\Omega)
becomes the standard harmonic extension of
\displaystyle u
such that it satisfies the following equation:

\displaystyle\displaystyle(\nabla y_{u},\nabla\phi)=0\quad\forall~\phi\in V.

In this case
\displaystyle u\in H^{1/2}(\Gamma)
is simply the trace of
\displaystyle y_{u}
in the sense that
\displaystyle y_{u}|_{\Gamma}=u
.

2.1
Optimality System

In this section, we write the model Dirichlet boundary optimal control problem and derive the corresponding optimality system by applying the first order necessary optimality conditions. For
\displaystyle(f,u)\in L_{2}(\Omega)\times L_{2}(\Gamma)
, define
\displaystyle(y_{f},y_{u})\in L_{2}(\Omega)\times L_{2}(\Omega)
to be the solutions of the following equations:

\displaystyle\displaystyle(y_{f},\Delta\phi)

\displaystyle\displaystyle=-(f,\phi)\quad\forall~\phi\in X,

(2.2)

\displaystyle\displaystyle(y_{u},\Delta\phi)

\displaystyle\displaystyle=\langle u,\partial_{n}\phi\rangle\quad\forall~\phi\in X.

(2.3)

In view of (
2.2
)-(
2.3
), the ultra weak solution
\displaystyle y\in L_{2}(\Omega)
of (
1.4
) can be written as
\displaystyle y=(y_{f}+y_{u})
. In addition, if the given data satisfy
\displaystyle(f,u)\in L_{2}(\Omega)\times H^{1/2}(\Gamma)
, then we can recover the standard weak formulation, i.e. the following holds:

\displaystyle\displaystyle\begin{cases}y&=y_{f}+y_{u},~y_{f}\in H^{1}_{0}(\Omega),~y_{u}\in H^{1}(\Omega),\\
y_{u}&=u\quad\text{on}~\Gamma,\\
a(y_{f},v)&=(f,v)-a(y_{u},v)\quad\forall~v\in H^{1}_{0}(\Omega),\end{cases}

(2.4)

where
\displaystyle a(\cdot,\cdot):H^{1}(\Omega)\times H^{1}(\Omega)\rightarrow\mathbb{R}
is a symmetric bilinear form given by:

\displaystyle\displaystyle a(v,w)

\displaystyle\displaystyle=\int_{\Omega}\nabla v\cdot\nabla w\,dx\quad\forall~v,w\in H^{1}(\Omega).

The bilinear form
\displaystyle a(\cdot,\cdot)
defines a continuous mapping on
\displaystyle H^{1}(\Omega)
and coercive map on
\displaystyle H^{1}_{0}(\Omega)
. Set
\displaystyle V=H^{1}_{0}(\Omega)
and
\displaystyle Q=H^{1}(\Omega)
. Given that
\displaystyle\Omega
is a convex polygonal domain, for
\displaystyle u=0

\displaystyle y
of (
1.2

\displaystyle H^{2}(\Omega)\cap H^{1}_{0}(\Omega)

a priori

\displaystyle\displaystyle\|y\|_{H^{2}(\Omega)}\leq C\|f\|_{L_{2}(\Omega)}.

The subsequent lemma affirms the well-posed-ness of the boundary value problem (
1.2

\displaystyle u\in\tilde{H}^{-1/2}(\Gamma)

Lemma 2.2
.

For any given
\displaystyle u\in\tilde{H}^{-1/2}(\Gamma)
and
\displaystyle f\in H^{-2}(\Omega)

1.4

\displaystyle y\in L_{2}(\Omega)

\displaystyle\displaystyle\|y\|_{L_{2}(\Omega)}\leq C\Big(\|f\|_{H^{-2}(\Omega)}+\|u\|_{\tilde{H}^{-1/2}(\Gamma)}\Big),

(2.5)

where
\displaystyle H^{-2}(\Omega)
is the dual space of
\displaystyle X
.

Proof.

For
\displaystyle f\in H^{-1}(\Omega)
and
\displaystyle u\in H^{1/2}(\Gamma)
, there exists a unique weak solution
\displaystyle y\in H^{1}(\Omega)
of (
1.2

2.4

\displaystyle\displaystyle-(y,\Delta\phi)

\displaystyle\displaystyle=(f,\phi)-\langle u,\partial_{n}\phi\rangle\quad\forall~\phi\in X,

is the solution of (

\displaystyle\displaystyle\begin{cases}-\Delta z&=y\quad\text{in}\quad\Omega,\\
\hskip 11.38092ptz&=0\quad\text{on}\quad\Gamma.\end{cases}

By elliptic regularity theory,

\displaystyle H^{-1}(\Omega)\subseteq H^{-2}(\Omega)
and
\displaystyle H^{1/2}(\Gamma)\subseteq\tilde{H}^{-1/2}(\Gamma)

\displaystyle\displaystyle U_{ad}:=\{u\in L_{2}(\Gamma):u_{a}\leq u(x)\leq u_{b}~~\text{a.e}~~x\in\Gamma\},

\displaystyle u_{a}
,
\displaystyle u_{b}

\displaystyle\in\mathbb{R}

\displaystyle u_{a}<u_{b}

\displaystyle\displaystyle J(\bar{y},\bar{u})=\min_{(y,u)\in L_{2}(\Omega)\times U_{ad}}J(y,u),

Theorem 2.4
.

The optimal control problem (

\displaystyle(\bar{y},\bar{u})\in L_{2}(\Omega)\times U_{ad}

\displaystyle\displaystyle\bar{y}=\bar{y}_{f}+y_{\bar{u}},\quad\bar{y}_{f},~y_{\bar{u}}\in L_{2}(\Omega),

\displaystyle\displaystyle(\bar{y}_{f},\Delta\phi)=-(f,\phi)\quad\forall~\phi\in X,

(2.9)

\displaystyle\displaystyle(y_{\bar{u}},\Delta\phi)=\langle\bar{u},\partial_{n}\phi\rangle\quad\forall~\phi\in X,

\displaystyle\displaystyle(\bar{y}-y_{d},y_{u}-y_{\bar{u}})+\alpha\langle\bar{u},u-\bar{u}\rangle\geq 0\quad\forall~u\in U_{ad}.

(2.11)

Proof.

By utilizing the solution operator
\displaystyle S(\cdot,\cdot)

\displaystyle\displaystyle\min_{u\in U_{ad}}j(u),

\displaystyle\bar{u}\in U_{ad}

2.2
Regularity of the Optimal Control

In this fragment, we obtain the regularity of the optimal variables namely
\displaystyle\bar{y}
and
\displaystyle\bar{u}
which are useful for the subsequent analysis. Introduce an adjoint state
\displaystyle\theta\in V
such that it satisfies the following variational formulation:
find
\displaystyle\theta\in V

\displaystyle\displaystyle(\nabla v,\nabla\theta)=(\bar{y}-y_{d},v)\quad\forall~v\in V.

By elliptic regularity theory for convex polygonal domain

\displaystyle\theta\in X
and it satisfies the following

\displaystyle\displaystyle\|\theta\|_{H^{2}(\Omega)}

\displaystyle\displaystyle\leq C\|\bar{y}-y_{d}\|_{L_{2}(\Omega)}.

Using integration by parts and density arguments in (

\displaystyle\displaystyle(v,\Delta\theta)

\displaystyle\displaystyle=-(\bar{y}-y_{d},v)\quad\forall~v\in L_{2}(\Omega).

Since
\displaystyle\theta\in H^{2}(\Omega)
, it implies
\displaystyle\partial_{n}\theta\in\tilde{H}^{1/2}(\Gamma)
. For any

, using (

) for

\displaystyle\displaystyle(\bar{y}-y_{d},y_{u}-y_{\bar{u}})

\displaystyle\displaystyle=-(y_{u}-y_{\bar{u}},\Delta\theta)

\displaystyle\displaystyle=-\langle u-\bar{u},\partial_{n}\theta\rangle,

where we have used (

) to observe the last equality. Hence, the inequality (

) reduces to

\displaystyle\displaystyle\alpha\langle\bar{u},u-\bar{u}\rangle-\langle u-\bar{u},\partial_{n}\theta\rangle

which implies

\displaystyle\displaystyle\langle\alpha\bar{u}-\partial_{n}\theta,u-\bar{u}\rangle\geq 0\quad\forall~u\in U_{ad}.

(2.15)

It follows from (

\displaystyle\displaystyle\bar{u}(x)=P_{[u_{a},u_{b}]}\Big(\dfrac{1}{\alpha}(\partial_{n}\theta)(x)\Big),\quad\text{for almost every}~x\in\Gamma,

\displaystyle\mathbb{R}
