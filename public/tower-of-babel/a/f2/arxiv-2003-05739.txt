Training Mixture Density Networks with full covariance matrices
Jakob Kruse

Abstract
Mixture Density Networks are a tried and tested tool for modelling conditional probability distributions. As such, they constitute a great baseline for novel approaches to this problem. In the standard formulation, an MDN takes some input and outputs parameters for a Gaussian mixture model with restrictions on the mixture components’ covariance. Since covariance between random variables is a central issue in the conditional modeling problems we were investigating, I derived and implemented an MDN formulation with unrestricted covariances. It is likely that this has been done before, but I could not find any resources online. For this reason, I have documented my approach in the form of this technical report, in hopes that it may be useful to others facing a similar situation.



Machine Learning, Invertible Neural Networks, Normalizing Flow, Fourier Curve, ICML

1
Preliminaries

The standard normal – or Gaussian – distribution acts as the foundation for countless modelling approaches in statistics and machine learning.
As opposed to a single Gaussian, which is a very limited model, mixtures of multivariate Gaussians can represent or approximate almost any density of interest while remaining intuitive and easy to handle.

1.1
Gaussian mixture model

The density at point
\mathbf{x}
under an
N
-dimensional Gaussian mixture model with
K
components is a weighted sum of the densities under each Gaussian component:

\displaystyle p(\mathbf{x})

\displaystyle=\sum_{i=1}^{K}\omega_{i}\cdot p_{i}(\mathbf{x})

(1)

\displaystyle=\sum_{i=1}^{K}\omega_{i}\cdot\mathcal{N}(\mathbf{x}\,|\,\bm{\mu}_{i},\bm{\Sigma}_{i})

\displaystyle=\sum_{i=1}^{K}\omega_{i}\cdot\frac{\exp{\left(\sminus\tfrac{1}{2}(\mathbf{x}-\bm{\mu}_{i})^{\top}\cdot\bm{\Sigma}_{i}^{\sminus 1}\cdot(\mathbf{x}-\bm{\mu}_{i})\right)}}{\sqrt{\left(2\pi\right)^{K}\cdot|\bm{\Sigma}_{i}|}}

We can leave out the constant factor and get

\displaystyle p(\mathbf{x})

\displaystyle\propto\sum_{i=1}^{K}\omega_{i}\cdot\frac{\exp{\left(\sminus\tfrac{1}{2}(\mathbf{x}-\bm{\mu}_{i})^{\top}\cdot\bm{\Sigma}_{i}^{\sminus 1}\cdot(\mathbf{x}-\bm{\mu}_{i})\right)}}{\sqrt{|\bm{\Sigma}_{i}|}},

\displaystyle\text{all with component weights}\sum_{i=1}^{K}\omega_{i}=1.

(2)

Each component has a mean
\bm{\mu}_{i}
and a covariance matrix
\bm{\Sigma}_{i}
.
A common simplification is to restrict the covariance matrices to be diagonal,
in which case the determinant required in the denominator reduces to the product of the diagonal entries.

Since these diagonal entries must be strictly positive, a convenient parameterization is
\bm{\Sigma}_{i}^{\sminus 1}=\bar{\bm{\sigma}}_{i}^{\top}\cdot\mathbf{I}_{N}\cdot\bar{\bm{\sigma}}_{i}
with
(\bar{\bm{\sigma}}_{i})_{j}=\exp{(\bm{\sigma}_{i})_{j}}
for some unconstrained vector
\bm{\sigma}_{i}
.
With this the denominator just becomes the product

\displaystyle\frac{1}{\sqrt{|\bm{\Sigma}_{i}|}}

\displaystyle=\frac{1}{\sqrt{\prod_{j=1}^{N}(\bar{\bm{\sigma}}_{i})^{-2}_{j}}}=\prod_{j=1}^{N}(\bar{\bm{\sigma}}_{i})_{j}

and the above density can be expressed as

\displaystyle p(\mathbf{x})

\displaystyle\propto\sum_{i=1}^{K}\omega_{i}\cdot\exp{\left(\sminus\tfrac{1}{2}\|(\mathbf{x}-\bm{\mu}_{i})\odot\bar{\bm{\sigma}}_{i}\|_{2}^{2}\right)}\cdot\prod_{j=1}^{N}(\bar{\bm{\sigma}}_{i})_{j}

(3)

For numerical stability we can compute the contribution of each single component
p_{i}(\mathbf{x})
as a sum in log-space as

\displaystyle\log p_{i}(\mathbf{x})

\displaystyle\propto\sminus\tfrac{1}{2}\|(\mathbf{x}-\bm{\mu}_{i})\odot\bar{\bm{\sigma}}_{i}\|_{2}^{2}+\sum_{j=1}^{N}\log\ (\bar{\bm{\sigma}}_{i})_{j}

\displaystyle\propto\sminus\tfrac{1}{2}\|(\mathbf{x}-\bm{\mu}_{i})\odot\bar{\bm{\sigma}}_{i}\|_{2}^{2}+\sum_{j=1}^{N}(\bm{\sigma}_{i})_{j}

(4)

1.2
Mixture Density Networks

A Mixture Density Network
(
Bishop 1994
)
, or MDN for short, is a neural network that outputs parameters
\omega_{i|\theta},\bm{\mu}_{i|\theta},\bm{\sigma}_{i|\theta}
for all components
i
of a Gaussian mixture model
p_{\theta}
based on some input
\mathbf{y}
, where
\theta
are the trainable network weights.
As such, an MDN parameterizes the conditional density
p_{\theta}(\mathbf{x}\,|\,\mathbf{y})
.

The standard objective for training an MDN is maximum likelihood of a training set
X,Y
under
p_{\theta}(\mathbf{x}\,|\,\mathbf{y})
.
To this end, we minimize the
negative log-likelihood
with respect to the network parameters
\theta
:

\displaystyle\mathcal{L}(\theta)

\displaystyle=\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\big[\sminus\log p_{\theta}(\mathbf{x}\,|\,\mathbf{y})\big]

(5)

\displaystyle\propto\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\Biggl[\sminus\log\sum_{i=1}^{K}\omega_{i|\theta}\cdot\exp\Big(\!\sminus\!\tfrac{1}{2}\big\|(\mathbf{x}\sminus\bm{\mu}_{i|\theta})

\displaystyle\hskip 70.0001pt\odot\bar{\bm{\sigma}}_{i|\theta}\big\|_{2}^{2}+\sum_{j=1}^{N}(\bm{\sigma}_{i|\theta})_{j}\Big)\Biggr]

(6)

Using Jensen’s inequality, we can pull the logarithm into the sum.
This yields an upper bound on the negative log-likelihood with more robust behavior especially during early training, when the predicted parameters are still somewhat volatile:

\displaystyle\mathcal{L}(\theta)

\displaystyle\leq\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\Biggl[\sminus\sum_{i=1}^{K}\Big(\log\omega_{i|\theta}-\tfrac{1}{2}\big\|(\mathbf{x}\sminus\bm{\mu}_{i|\theta})

\displaystyle\hskip 70.0001pt\odot\bar{\bm{\sigma}}_{i|\theta}\big\|_{2}^{2}+\sum_{j=1}^{N}(\bm{\sigma}_{i|\theta})_{j}\Big)\Biggr]

(7)

We can minimize this loss function via back-propagation and standard gradient descent methods for deep learning.

1.3
Sampling

To sample one value
\mathbf{x}
from a Gaussian mixture, we first pick a mixture component
i
with probability proportional to its weight
\omega_{i}
and then draw
\mathbf{x}
from
p_{i}(\mathbf{x})
.
In practice and in the case of diagonal covariance matrices, this means

\displaystyle\mathbf{x}

\displaystyle\sim\mathcal{N}(\mathbf{x}\,|\,\bm{\mu}_{i},\bm{\Sigma}_{i})

\displaystyle=\bm{\mu}_{i}+\bm{\eta}\oslash\bar{\bm{\sigma}}_{i}\text{ \ with }\bm{\eta}\sim\mathcal{N}\left(\bm{\eta}\,|\,\mathbf{0},\mathbf{I}_{N}\right),

where
\bm{\mu}_{i}
and
\bar{\bm{\sigma}}_{i}
can be direct outputs of an MDN for all
i
.

2
Full covariance matrices

A multivariate Gaussian with strictly diagonal covariance matrix, as we have used above for the mixture components, has strong limitations as to what densities can be modelled.

Figure

1
shows this for three components in 2d space:
while components of the unconstrained mixture on the left can be oriented arbitrarily in the plane, components of the diagonal mixture on the right can only be scaled along the axes of the coordinate system.

We want to make use of the much greater flexibility of the unconstrained model, but avoid the costly computation of full matrix inverses and determinants, as well as covariance matrices that do not describe valid Gaussian densities.
In the following, we will therefore show a parameterization that guarantees a valid density while offering (relatively) efficient training and sampling.

Figure 1
:
Difference between a Gaussian mixture with full covariances
(left)
and with diagonal covariances, i.e. axis-parallel
(right)

2.1
Parameterization

If we look at the general density formula for a single mixture component
p_{i}(\mathbf{x})
, we can pull the covariance matrix
\bm{\Sigma}_{i}
from the denominator and rewrite as:

\displaystyle p_{i}(\mathbf{x})

\displaystyle\propto\frac{\exp{\left(\sminus\tfrac{1}{2}(\mathbf{x}\sminus\bm{\mu}_{i})^{\top}\bm{\Sigma}_{i}^{\sminus 1}(\mathbf{x}\sminus\bm{\mu}_{i})\right)}}{\sqrt{|\bm{\Sigma}_{i}|}}

\displaystyle\propto\exp{\left(\sminus\tfrac{1}{2}(\mathbf{x}\sminus\bm{\mu}_{i})^{\top}\bm{\Sigma}_{i}^{\sminus 1}(\mathbf{x}\sminus\bm{\mu}_{i})\right)}\cdot|\bm{\Sigma}_{i}|^{\sminus\frac{1}{2}}

\displaystyle\propto\exp{\left(\sminus\tfrac{1}{2}(\mathbf{x}\sminus\bm{\mu}_{i})^{\top}\bm{\Sigma}_{i}^{\sminus 1}(\mathbf{x}\sminus\bm{\mu}_{i})\right)}\cdot|\bm{\Sigma}_{i}^{\sminus 1}|^{\frac{1}{2}}

(8)

Now
\bm{\Sigma}_{i}
only occurs in the equation as its inverse, the
precision matrix

\bm{\Sigma}_{i}^{\sminus 1}
.

For a valid multivariate Gaussian,
\bm{\Sigma}_{i}
and
\bm{\Sigma}_{i}^{\sminus 1}
must be positive-definite matrices.
We can thus characterize the precision matrix
\bm{\Sigma}_{i}^{\sminus 1}
by its Cholesky decomposition using an upper triangular matrix
\bar{\mathbf{U}}_{i}
with strictly positive diagonal entries:

\displaystyle\bm{\Sigma}_{i}^{\sminus 1}

\displaystyle=\bar{\mathbf{U}}_{i}^{\top}\bar{\mathbf{U}}_{i}

(9)

Once again we can use the exponential function to enforce positivity of the diagonal, by taking

\displaystyle(\bar{\mathbf{U}}_{i})_{jk}

\displaystyle=\begin{cases}(\mathbf{U}_{i})_{jk},&\text{if }j\neq k\\
\exp\,(\mathbf{U}_{i})_{jk},&\text{otherwise}\end{cases}

(10)

for an unconstrained upper triangular matrix
\mathbf{U}_{i}
predicted by the MDN.

This offers an efficient way to compute the matrix determinant in
equation

8
as the product of the diagonal entries of the Cholesky factor
\bar{\mathbf{U}}_{i}
:

\displaystyle\left|\bm{\Sigma}_{i}^{\sminus 1}\right|

\displaystyle=\left|\bar{\mathbf{U}}_{i}^{\top}\bar{\mathbf{U}}_{i}\right|

\displaystyle=\left|\bar{\mathbf{U}}_{i}^{\top}\right|\cdot\left|\bar{\mathbf{U}}_{i}\right|

\displaystyle=\prod_{j=1}^{N}\text{diag}\big(\bar{\mathbf{U}}_{i}^{\top}\big)_{j}\cdot\prod_{j=1}^{N}\text{diag}\big(\bar{\mathbf{U}}_{i}\big)_{j}

\displaystyle=\left(\prod_{j=1}^{N}\text{diag}\big(\bar{\mathbf{U}}_{i}\big)_{j}\right)^{\!2}

\displaystyle\left|\bm{\Sigma}_{i}^{\sminus 1}\right|^{\frac{1}{2}}

\displaystyle=\prod_{j=1}^{N}\text{diag}\big(\bar{\mathbf{U}}_{i}\big)_{j}

(11)

Its numerically more stable logarithm has the form

\displaystyle\log\left|\bm{\Sigma}_{i}^{\sminus 1}\right|^{\frac{1}{2}}

\displaystyle=\sum_{j=1}^{N}\log\text{diag}\big(\bar{\mathbf{U}}_{i}\big)_{j}

\displaystyle=\sum_{j=1}^{N}\text{diag}\big(\mathbf{U}_{i}\big)_{j}\,.

(12)

With this, we can express the log-density under one mixture component
p_{i}(\mathbf{x})
as

\displaystyle\log p_{i}(\mathbf{x})

\displaystyle\propto\sminus\tfrac{1}{2}(\mathbf{x}\!\sminus\!\bm{\mu}_{i})^{\top}\bm{\Sigma}_{i}^{\sminus 1}(\mathbf{x}\!\sminus\!\bm{\mu}_{i})+\log|\bm{\Sigma}_{i}^{\sminus 1}|^{\frac{1}{2}}

\displaystyle\propto\sminus\tfrac{1}{2}(\mathbf{x}\!\sminus\!\bm{\mu}_{i})^{\top}\bar{\mathbf{U}}_{i}^{\top}\cdot\bar{\mathbf{U}}_{i}(\mathbf{x}\!\sminus\!\bm{\mu}_{i})+\sum_{j=1}^{N}\text{diag}\big(\mathbf{U}_{i}\big)_{j}

\displaystyle\propto\sminus\tfrac{1}{2}\left\|\bar{\mathbf{U}}_{i}(\mathbf{x}\!\sminus\!\bm{\mu}_{i})\right\|_{2}^{2}+\sum_{j=1}^{N}\text{diag}\big(\mathbf{U}_{i}\big)_{j}\ ,

(13)

which is remarkably similar to the max-likelihood loss used to train normalizing flow networks.

Note that the number of parameters the MDN has to predict grows linearly with the number
K
of mixture components, but quadratically with the number of dimensions
N

since the triangular matrix
\mathbf{U}_{i}
must be populated for each component.

2.2
Training

With the above parameterization, we need the MDN to output parameters
\omega_{i|\theta},\bm{\mu}_{i|\theta}
and
\mathbf{U}_{i|\theta}
for each mixture component
p_{i|\theta}(\mathbf{x})
.
We optimize the network weights
\theta
according to the same maximum likelihood criterion used in
equation

5
, which now takes the form

\displaystyle\mathcal{L}(\theta)

\displaystyle=\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\big[\sminus\log p_{\theta}(\mathbf{x}\,|\,\mathbf{y})\big]

\displaystyle\propto\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\Biggl[\sminus\log\sum_{i=1}^{K}\omega_{i|\theta}\cdot\exp\Big(\sum_{j=1}^{N}\text{diag}\big(\mathbf{U}_{i|\theta}\big)_{j}

\displaystyle\hskip 70.0001pt-\tfrac{1}{2}\left\|\bar{\mathbf{U}}_{i|\theta}(\mathbf{x}\!\sminus\!\bm{\mu}_{i|\theta})\right\|_{2}^{2}\Big)\Biggr].

(14)

Jensen’s inequality again gives us an upper bound to be used in the early training regime:

\displaystyle\mathcal{L}(\theta)

\displaystyle\leq\mathbb{E}_{\mathbf{x}\in X,\mathbf{y}\in Y}\Biggl[\sminus\sum_{i=1}^{K}\Big(\log\omega_{i|\theta}+\sum_{j=1}^{N}\text{diag}\big(\mathbf{U}_{i|\theta}\big)_{j}

\displaystyle\hskip 70.0001pt-\tfrac{1}{2}\left\|\bar{\mathbf{U}}_{i|\theta}(\mathbf{x}\!\sminus\!\bm{\mu}_{i|\theta})\right\|_{2}^{2}\Big)\Biggr]

(15)

2.3
Sampling

After running the network to obtain parameters
\omega_{i},\bm{\mu}_{i},\mathbf{U}_{i}
for a Gaussian mixture model, we start by choosing one component
i
as described earlier.
Samples from a multivariate Gaussian with full covariance are drawn as

\displaystyle\mathbf{x}

\displaystyle\sim\mathcal{N}(\mathbf{x}\,|\,\bm{\mu}_{i},\bm{\Sigma}_{i})

\displaystyle=\bm{\mu}_{i}+\mathbf{L}_{i}\cdot\bm{\eta}

with
\bm{\eta}\sim\mathcal{N}\left(\bm{\eta}\,|\,\mathbf{0},\mathbf{I}_{N}\right)
and
\mathbf{L}_{i}
chosen to factorize the covariance matrix such that
\bm{\Sigma}_{i}=\mathbf{L}_{i}\mathbf{L}_{i}^{\top}
.

Noting that the parameterization we have introduced for our network already gives us the Cholesky root
\bar{\mathbf{U}}_{i}
of the precision matrix, i.e.
\bm{\Sigma}_{i}^{\sminus 1}=\bar{\mathbf{U}}_{i}^{\top}\bar{\mathbf{U}}_{i}
, we can use inverse of its transpose
\mathbf{L}_{i}=\bar{\mathbf{U}}_{i}^{\sminus\top}
to factorize the covariance matrix
1
1

1

https://math.stackexchange.com/a/2489142
.
Since
\bar{\mathbf{U}}_{i}^{\top}
is triangular, this inversion can be performed efficiently via back substitution.

3
Implementation

An implementation of the model described above using
pytorch
can be found in our Framework for Easily Invertible Architectures,

FrEIA
2
2

2

https://github.com/VLL-HD/FrEIA
, under the module name
GaussianMixtureModel
.

In the context of this framework, the GMM acts as an invertible building block which maps between a data point
\mathbf{x}
and its latent code
\bm{\eta}
.
Invertibility is given either by specifying (or reproducibly sampling) a fixed component index
i
, or by extending the map to consider all mixture components simultaneously, which is also needed for training.

The GMM block has no parameters of its own, but instead takes
\bm{\omega}\in\mathbb{R}^{b\times K}
,
\bm{\mu}\in\mathbb{R}^{b\times K\times N}
,
\mathbf{U}\in\mathbb{R}^{b\times K\times N(N-1)/2}
and the optional index
i
as conditional inputs.
The values
\bm{\omega},\bm{\mu}
and
\mathbf{U}
should come from a feed-forward network taking
\mathbf{y}
as input.
Then the latter network can be trained via back-propagation through the GMM block, using the negative log-likelihood loss function which is also supplied.
