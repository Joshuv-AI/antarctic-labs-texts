GRASP: A Goodness-of-Fit Test for Classification Learning
Adel Javanmard, Mohammad Mehrabi

Abstract
Performance of classifiers is often measured in terms of average accuracy on test data. Despite being a standard measure, average accuracy fails in characterizing the fit of the model to the underlying conditional law of labels given the features vector ( Y | X Y|X ), e.g. due to model misspecification, over fitting, and high-dimensionality. In this paper, we consider the fundamental problem of assessing the goodness-of-fit for a general binary classifier. Our framework does not make any parametric assumption on the conditional law Y | X Y|X , and treats that as a black box oracle model which can be accessed only through queries. We formulate the goodness-of-fit assessment problem as a tolerance hypothesis testing of the form H 0 : 𝔼 [ D f ( 𝖡𝖾𝗋𝗇 ( η ( X ) ) ∥ 𝖡𝖾𝗋𝗇 ( η ^ ( X ) ) ) ] ≤ τ , H_{0}:{\mathbb{E}}\Big[D_{f}\Big(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X))\Big)\Big]\leq\tau\,, where D f D_{f} represents an f f -divergence function, and η ⁡ ( x ) \eta(x) , η ^ ​ ( x ) \widehat{\eta}(x) respectively denote the true and an estimate likelihood for a feature vector x x admitting a positive label. We propose a novel test, called GRASP for testing H 0 H_{0} , which works in finite sample settings, no matter the features (distribution-free). We also propose model-X GRASP designed for model-X settings where the joint distribution of the features vector is known. Model-X GRASP uses this distributional information to achieve better power. We evaluate the performance of our tests through extensive numerical experiments.

Introduction

In classification learning, one is given a set of training data
\{(x_{i},y_{i})\}_{i\leq n}
(with
x_{i}
representing multi-dimensional feature vector and
y_{i}
representing label variables), and aims to learn a model which can be used to predict the labels on new feature vectors. Classification algorithms are backbone of machine learning systems and undoubtedly one of the prominent statistical learning tools in data processing. There has been a plethora of classification methods proposed in the literature ranging from logistic regression and generalized linear models to more complex models such as boosting, random forests, and neural networks. In practice, the performance of these methods is often assessed in terms of accuracy on a test (hold-out) dataset, with the hope that it is a good indicator of the predictive performance of the model on unseen data points. Despite being used widely, the classification accuracy alone does not necessarily characterize the deviations of the learnt model from the underlying data generating process. Indeed relying solely on it as a measure of performance can be misleading due to model misspecification, and over/under fitting. This leads to the following fundamental question:

(*) How well does a classifier learn the ground truth data generating law between the feature vector and the label?

Developing a statistical test for the above question has a myriad of applications. It can flag the inherent and systematic flaws of a model, and its poor generalization to unseen population. Further, it provides a more holistic and honest assessment of the model performance, which is of paramount importance with the rise of reproducibility issues in modern data analysis. In particular, with the practice of data sharing, many datasets are used routinely as benchmark to compare different models. However, perpetual use of public datasets, without proper mechanism to access them to ensure validity of inferences, causes spurious discoveries and overfitting; learning models which performs well on benchmark datasets but generalize poorly to unseen datasets
[
RAN14
,
JM18
,
DFH+15
,
DFH+17
]
. Another application of such test is for models built by commercial “machine learning as a service” providers such as Google and Amazon. They provide platforms where one can upload a dataset and a data classification task and pay to construct a model. Therefore, it is important to decide if the current model is sufficiently good (in a statistically sound sense) or to continue training process, which incurs additional cost.

Among other applications, the proposed methodology can be used in
K
-fold framework to choose the optimal model with respect to its goodness-of-fit, rather than its empirical accuracy on the hold-out set.

In statistics, question (*) is often formulated as goodness-of-fit test. However, most of the existing literature focus on specific parametric models, such as logistic regression, and do not apply to more complicated models such as neural network or random forest. An exception is the very recent seminal work of

1.1
Related works

Goodness-of-fit.
Once a model is fitted to data, it is important to assess the quality of the fit. Several methods have been developed for testing goodness-of-fit of generalized linear models under the low-dimensional setting (
d\ll n
) with a focus on logistic regression and multinomial models
[
HL80
,
LCVH91
,
Tsi80
,
SW91
,
LWY02
,
HH02
,
OR92
,
Far96
]
. For the high-dimensional setting,
[
SB18
]
proposed a framework for testing goodness-of-fit of high-dimensional linear models by using parametric bootstrap to calibrate the estimate model for scaled residuals.
[
JSBS20
]
proposed the generalized residual prediction (GRP) test for goodness-of-fit testing of high-dimensional generalized linear models. The aforementioned works focus on a class of parametric models, particularly for linear and generalized linear models. For a non-parametric setting,
[
ZDY21
]
proposed the binary adaptive goodness-of-fit test (BAGofT), where it tests for the perfect match of the test model and the ground-truth conditional probability, in an asymptotic regime.

While the existing methods for testing goodness-of-fit mostly focus on contexts where the estimate model has asymptotic convergence to the ground truth law, we propose a method that is flexible for arbitrarily complex classifiers independent of their predictive performance. In addition, it can be used under the high-dimensional setting (
d\gg n
) as well and still generates a high resolution p-value for moderately large number of samples. In addition, we consider the tolerance testing scheme which is more general than the perfect match testing (i.e.
\eta=\widehat{\eta}
, a.s.), making it more useful in practice. Our proposed method also allows to consider a variety of metrics, including the average absolute distance, and the excess cross entropy, among many others.

We would like to highlight a distinction between our problem and the conventional setup for testing goodness-of-fit. In our setup, the model estimate
\widehat{\eta}
is learned on the training data and is subsequently evaluated on an independent test data. In hypothesis (
3
), the model estimate
\widehat{\eta}
is fixed and the randomness stems solely from the test data. This differs from other goodness-of-fit setups, such as those described in
[
ZDY21
,
JSBS20
]
, where the statistical inference takes into account the variability of the training set. For example, the phrase ‘finite sample size’ in those work refers to the size of the training data, while in our setting it refers to the size of the test data.

Prediction error.
Estimating the prediction performance of a model is one of the core tasks in data-driven applications
[
HTFF09
]
. In particular, it can serve as a benchmark for model selection. Covariance penalty (CP) and cross validation (CV) are two of widely used methods to estimate the prediction performance of a regression model
[
Aka98
,
Mal00
,
Efr86
,
Efr04
]
. However, It has been shown recently that such methods are not statistically accurate in measuring the out-of-the sample performance of models. In fact,
[
RT19
,
Wag20
]
showed that covariance penalty and AIC statistic
[
Aka98
]
methods reflect the in-sample prediction error. In addition,
[
BHT21
]
revealed potential inaccuracies of cross validation, and argued that it indeed measures
average
prediction accuracy over many
hypothetical
datasets. In this work, we take another perspective on model’s prediction error. For a broad class of models (e.g., neural networks, decision trees, boosting algorithms, etc), and for the widely used negative likelihood loss (a.k.a. cross entropy), our framework allows to compare the model loss with the optimal oracle loss. Formally, for the estimate probabilistic model
\widehat{p}_{Y|X}(y|x)
, for specific choice of
f
-divergence function, we can test the null hypothesis testing:

\displaystyle{\mathbb{E}}_{(x,y)\sim\mathcal{P}}[-\log\widehat{p}_{Y|X}(y|x)]-\min_{\widetilde{p}_{Y|X}}\left\{{\mathbb{E}}_{(x,y)\sim\mathcal{P}}[-\log\widetilde{p}_{Y|X}(y|x)]\right\}\leq\tau\,.

Note that the minimum for the second term is achieved at
\tilde{p}_{Y|X}=p_{Y|X}
.

Calibration.
With the rise of deploying machine learning systems in real-life, the confidence of these systems in their predictions is of a great importance. Classification procedures often output a confidence value
\widehat{\pi}\in[0,1]
along with their predicted value
\widehat{y}
, which is supposed to indicate the model certainty about
\widehat{y}

y

[

nix19

VWA+19
,
WLZ19
,
KLM19
]

[

is a well-known metric to measure the calibration of models, where it is formally defined as

.

In
[
LHHD22
]
, authors proposed a method for testing for the perfect calibration of generic predictive models in multi-class classification problems. The initial intuition behind model calibration is to test for the closeness of classification models to the ground truth law, but mathematically has a different formulation for the goodness-of-fit testing problem considered in the current work. In an extreme instance, a model is well calibrated if
{\mathbb{E}}[\eta(X)|\widehat{\eta}(X)=\eta]=\eta
(regression setting), but in (
1
) with e.g, the average absolute difference metric, a perfect fit (
\tau

, almost surely.

Hypothesis testing for nonparametric regression functions.
In
[
MS18
]
, the authors construct confidence sets for the regression function in nonparametric binary regression with an unknown design density. It is assumed that the the regression function
\eta(.)
and the marginal probability density function of the features belong to a continuous class of Sobolev type spaces. Other than results on adaptive parameter estimation, this work provides a framework for testing the null hypothesis that the regression function is equal to 1/2 versus its alternative, while allowing the marginal density function to be a general function in a Sobolev type space. Furthermore, it is shown that

More on this line of research,

1.2
Summary of contributions and organization

In this paper, we introduce a novel method for tolerance testing of average distance of classifiers to the underlying conditional law of labels. Our proposed method, called GRASP can be used for arbitrarily complex black-box models (with only query access), with no parametric assumption whatsoever, and no matter the features. GRASP can be used in high-dimensional setting where the features dimension can exceed the sample size. We propose two variants of GRASP , one controls the type I error in finite sample settings, and the other (less conservative) version controls the type I error in asymptotic setting. Through extensive numerical experiments, we show that GRASP achieves high statistical power.

For model-X settings, where the distribution of features can be well approximated, we propose model-X GRASP which is built upon similar ideas as in the distribution-free version but harnesses the knowledge of features distribution to improve statistical power.

Here is an outline of the next sections:

Problem formulation

Under a binary classification setting, for a given test model
\widehat{\eta}:\mathcal{X}\to[0,1]
, we are interested in measuring its average distance to the oracle model
\eta(x)={\mathbb{P}}(y=+1|x)
. The test model
\widehat{\eta}(\cdot)
can be any arbitrarily complex predictive model, such as a fitted logistic regression, or the last layer of a trained neural network.
We focus on a class of distances between
\eta
and
\widehat{\eta}
which are inspired by
f
-divergence of distributions. We start by the definition of
f
-divergence of two density functions.

Definition 2.1
.

(
f
-divergence)
Consider a convex and continuous function
f:{\mathbb{R}}\to{\mathbb{R}}
. For two probability density functions
p,q
that are defined with respect to the Lebesgue measure
\mu
over
\mathcal{X}\subset{\mathbb{R}}^{d}
, define the
f
-divergence between them as the following

D_{f}(p\|q)=\int qf\left(\frac{p}{q}\right){\rm d}\mu\,.

Specializing this definition to Bernoulli distributions, with parameters
a,b
, we obtain the following definition:

D_{f}(\mathsf{Bern}(a)\|\mathsf{Bern}(b))=bf\left(\frac{a}{b}\right)+(1-b)f\left(\frac{1-a}{1-b}\right)\,.

(2)

For the rest of this paper, we will focus on the class of measures
D_{f}(\mathsf{Bern}(\eta(x))\|\mathsf{Bern}(\widehat{\eta}(x)))
parametrized by function
f
as distance between the test model
\widehat{\eta}
and the ground truth model
\eta
. For some nonnegative value
\tau
, we consider the following hypothesis testing problem:

\displaystyle H_{0}

\displaystyle:{\mathbb{E}}\left[D_{f}\Big(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X))\Big)\right]\leq\tau

\displaystyle H_{A}

\displaystyle:{\mathbb{E}}\left[D_{f}\Big(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X))\Big)\right]>\tau\,.

(3)

with
H_{0}
representing the null hypothesis and
H_{A}
the alternative.

Lemma 2.2
.

The followings hold:

1.

By choosing
f(t)=\frac{1}{2}|t-1|
(total variation distance) we get

{\mathbb{E}}\left[D_{\mathsf{TV}}(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X)))\right]={\mathbb{E}}[|\widehat{\eta}(X)-\eta(X)|]\,.

2.

For the choice of
f(t)=t\log t
(KL divergence), we get

{\mathbb{E}}\left[D_{\mathsf{KL}}(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X)))\right]=\mathsf{CE}(\widehat{\eta})-\mathsf{CE}(\eta)\,,

where for a model

\mathsf{CE}(\widehat{\eta})=-{\mathbb{E}}[\eta(X)\log\widehat{\eta}(X)+(1-\eta(X))\log(1-\widehat{\eta}(X))]\,.

The minimum cross-entropy loss is achieved when

For the choice of

\displaystyle{\mathbb{E}}\left[D_{\mathsf{H}}(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X)))\right]={\mathbb{E}}\left[\Big(\sqrt{\eta(X)}-\sqrt{\widehat{\eta}(X)}\Big)^{2}+\Big(\sqrt{1-\eta(X)}-\sqrt{1-\widehat{\eta}(X)}\Big)^{2}\right]\,.

\displaystyle\frac{1}{L}\sum\limits_{\ell=1}^{L}{f(Lp_{\ell})}

\displaystyle\leq{\mathbb{E}}\left[D_{f}\big(\mathcal{L}(T(X,W)|X)\|\mathcal{L}(T(X,\widetilde{W})|X)\big)\right]

In many applications, we may have access to a large amount of unsupervised data (covariate data without corresponding labels) in addition to a limited number of labeled observations.
Motivated by this trend,

]
proposed model-X setup where it assumes no knowledge of the conditional distribution of labels

Model-X setup is also relevant in experimental design, where we control the covariate distribution and so it is known to us, e.g., in randomized controlled trials, as well as sensitivity analysis of quantitive models
[
SRA+08

[

TVZ+22

JM21
]
for other related work on this topic.)

Using similar ideas as in GRASP , in this section we propose model-X GRASP , which uses the covariates distribution to improve the power in flagging the differences between the estimate model

Size of the model-X GRASP test

We first start with the following assumption, which assumes a density function for the random variable
T(X,W)
. This is the unconditional version of Assumption
3.3
, and is used in our analysis of the test in a model-X setting.

Assumption 4.2
.

Consider the following cumulative distribution functions:

\displaystyle F_{o}(t)

\displaystyle={\mathbb{P}}(T(X,W)\leq t)\,,

\displaystyle F_{c}(t)

\displaystyle={\mathbb{P}}(T({\widetilde{X}},\widetilde{W})\leq t)\,,

where
x,\tilde{x}\sim\mathcal{P}_{X}
independently,
w
is given by (
11
) and
\widetilde{w}\sim\mathsf{Unif}[0,1]
. Assume that the density functions of cdfs
F_{o}
and
F_{c}
exist and show them by
f_{o}(t)
and
f_{c}(t)
, respectively. In addition, consider a measure on the interval
[0,1]
defined with the cdf
\omega(u):=F_{o}(F_{c}^{-1}(u))
. Suppose that this measure is absolutely continuous with respect to the Lebesgue measure, and denote its density function (Radon–Nikodym derivative) by
\psi(u)
.

In our next result we show that the
f
-divergence between the multinomial distribution of
\mathbf{V}_{n,L}
(output of algorithm
3
) and the uniform multinomial distribution is bounded by the distance of the random variables
T(x,w)
and
T(\tilde{x},\widetilde{w})
.

Proposition 4.3
.

Let
\mathbf{V}_{n,L}=[V_{1},...,V_{L}]
be outputs of Algorithm
3
, then
\mathbf{V}_{n,L}
has a multinomial distribution with
L
outcomes and nominal probabilities
p_{1},\dots,p_{L}
. Under the setting of Assumption
4.2
, for a score function
T:\mathcal{X}\times[0,1]\to{\mathbb{R}}
, the following holds

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})

\displaystyle\leq D_{f}(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W})))\,.

In addition, if the function
\psi(u)
from Assumption
4.2
is continuous, the above inequality becomes equality as

grow to infinity:

\lim_{L\to\infty}\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})=D_{f}(\mathcal{L}(T(X,W)),\mathcal{L}(T({\widetilde{X}},\widetilde{W})))\,.

The proof of this proposition is given in Section
A.10
. The next Theorem follows from the combination of Propositions

and
4.3
, along with the data processing inequality for

Theorem 4.4

.

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})

The proof of this theorem is given in Section

The result of this theorem allows us to perform statistical inference on the complex expression

from the uniform multinomial distribution, similar to the distribution-free version.

4.3
Choice of the score function

In summary, our analysis in the previous section showed the following chain of inequalities:

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})

\displaystyle\leq D_{f}(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W})))

\displaystyle\leq D_{f}(\mathcal{L}(X,W)\|\mathcal{L}({\widetilde{X}},\widetilde{W}))

\displaystyle={\mathbb{E}}\left[D_{f}(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X)))\right]\,,

(12)

where the first inequality follows from Proposition
4.3
, the second one is an application of the data processing inequality, and the third line is the claim proved in Proposition
4.1
.

In order to increase the power of the test (make it less conservative), our guide is to choose score functions for which the gap between the leftmost side and the rightmost side in the chain of inequality is minimum.

For the first inequality, as shown in Proposition
4.3
(second part), the gap vanishes for large values of
L
and
K
. Focusing on the second inequality, we seek score functions
T
such that

D_{f}(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W})))=D_{f}(\mathcal{L}(X,W)\|\mathcal{L}({\widetilde{X}},\widetilde{W}))\,.

(13)

A trivial choice is
T(x,w)=(x,w)
, however, we would like to have scores with one-dimensional range, since we need to compare the scores values of the original samples and the counterfeits.

We proceed our discussion with providing a brief background on the variational representation of
f
-divergences, with the following statement borrowed from
[
NWJ10
, Lemma 1]
.

Lemma 4.6
.

For two probability density functions
q,p
on
\mathcal{X}\subset{\mathbb{R}}^{d}
and a set of measurable functions
\mathcal{G}
, we have

D_{f}(p\|q)\geq\sup_{\varphi\in\mathcal{G}}\int(\varphi p-f^{*}(\varphi)q){\rm d}\mu\,,

(14)

where
f^{*}
is the conjugate dual of
f
. In addition, the equality is achieved if the subdifferential
\partial f(p/q)
contains an element of
\mathcal{G}
.

For the reader’s convenience, we provide the proof of Lemma
4.6
in Section
A.12
.

Proposition 4.7
.

For two probability density functions
p,q
over
\mathcal{X}\subset{\mathbb{R}}^{d}
and function
f
as per Definition
2.1
, let
\sigma\in\partial f(p/q)
. Then, for
X_{p}\sim p
and
X_{q}\sim q
the
f
-divergence between distributions of
\sigma(X_{p})
and
\sigma(X_{q})
is equal to the
f
-divergence of distributions
p
and
q
. Formally,

D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))=D_{f}(p\|q)\,.

The proof of this proposition is given in
A.13
.

Going back to our discussion on the choice of score function
T(x,w)
, observe that by an application of Proposition
4.7
, condition (
13
) is satisfied for
T(x,w)\in\partial f\left(p_{X,W}(x,w)/p_{{\widetilde{X}},\widetilde{W}}(x,w)\right)
. Since
\widetilde{W}\sim\mathsf{Unif}[0,1]
, independent from
{\widetilde{X}}\sim\mathcal{P}_{X}
, we have

\frac{p_{X,W}(x,w)}{p_{{\widetilde{X}},\widetilde{W}}(x,w)}=p_{W|X}(w|x)\,.

In addition, from the construction of
w
, cf. Algorithm
3
, we have

\displaystyle{\mathbb{P}}(w|x)

\displaystyle={\mathbb{P}}(y=1|x){\mathbb{P}}(w|x,y=1)+{\mathbb{P}}(y=0|x){\mathbb{P}}(w|x,y=0)

\displaystyle=\frac{\eta(x)}{\widehat{\eta}(x)}{\mathbb{I}}(w\leq\widehat{\eta}(x))+\frac{1-\eta(x)}{1-\widehat{\eta}(x)}{\mathbb{I}}(\widehat{\eta}(x)\leq w)\,.

(15)

Putting things together, the optimal score function is given by

T(x,w)\in\partial f\left(\frac{\eta(x)}{\widehat{\eta}(x)}{\mathbb{I}}(w\leq\widehat{\eta}(x))+\frac{1-\eta(x)}{1-\widehat{\eta}(x)}{\mathbb{I}}(\widehat{\eta}(x)\leq w)\right)\,.

We next note that our test statistics in Algorithm
3
is based on the
relative ranking
of the score values, not the absolute values.
For an increasing function
g
, the rank values obtained by the score functions
T
and
g\circ T
are the same. In particular, since
f
is convex its derivative is a non-decreasing function, and so we can simply consider the ratio of densities.
When
f
is not strictly-convex, we may have ties in the ordering with respect to the above derivation. We use the following rule which also breaks ties.

T^{\mathsf{opt}}(x,w)=\frac{\eta(x)}{\widehat{\eta}(x)}{\mathbb{I}}(w\leq\widehat{\eta}(x))+\frac{1-\eta(x)}{1-\widehat{\eta}(x)}{\mathbb{I}}(\widehat{\eta}(x)\leq w)\,.

(16)

As can be seen
T^{\mathsf{opt}}(x,w)
involves the true model
\eta(x)
which is unknown. To cope with this issue, we consider two routes:

•

Model-agnostic approach:
We use
T^{\mathsf{opt}}(x,w)
with replacing
\eta(x)=\frac{1}{2}
.

•

GAN-based approach:
We propose an optimization inspired by generative adversarial networks (GANs) to approximate the ratio of densities
p_{X,W}(x,w)/p_{{\widetilde{X}},\widetilde{W}}(x,w)
.

Our next subsection gives a brief background overview on GANs and the details of our GAN-based approach.

4.3.1
Generative Adversarial Nets (GANs)

The GANs framework was introduced by
[
GPAM+14
]
to generate samples from the population of given data samples
x\in\mathcal{X}\subset{\mathbb{R}}^{d}
. This framework can be perceived as a game between a generator that tries to learn data distribution
p_{X}
and produce fake samples that are statistically close to the original data, and a discriminator that tries to discriminate samples of the generator from the original data samples.

It is a repeated game where each player aims to improve her model with respect to her objective. Starting from noise sample
z\in{\cal Z}\subset{\mathbb{R}}^{k}
with density function
p_{Z}
, the generator produce fake samples in the data space
\mathcal{X}
via a mapping
G(z;\theta_{g})
, where
G:{\cal Z}\to\mathcal{X}
is a differentiable neural network with parameters
\theta_{g}
. The discriminator, on the other side, has access to another neural network
D(x;\theta_{d})
that represents the likelihood of data
x
coming from the original data distribution
p_{X}
. This game can be cast as the following min-max optimization problem

\min_{\theta_{g}}\max_{\theta_{d}}\left\{{\mathbb{E}}_{X}\Big[\log D(X;\theta_{d})\Big]+{\mathbb{E}}_{Z}\Big[\log\big(1-D(G(Z;\theta_{g});\theta_{d})\big)\Big]\right\}\,.

(17)

As evident from the above formulation, the discriminator aims to increase the likelihood of the original samples coming from
p_{X}
, while simultaneously lower the likelihood of fake sample
G(z;\theta_{g})
coming from the same distribution. The generator, on the other hand, aims to find a model
G(z;\theta_{g})
which generates samples with high likelihood of coming from
p_{X}
. As shown in
[
GPAM+14
]
, the above optimization problem has a global optimum at
p_{g}=p_{X}
, where
p_{g}
stands for the distribution of samples
G(z;\theta_{g})
with
z\sim p_{Z}
.

We follow the GANs framework by considering
\mathcal{L}(X,W)
as the original data distribution. In addition, we assume that the generator at each round produces the randomizations
(\tilde{x},\widetilde{w})
, and update the discriminator to discriminate
(x,w)
from
(\tilde{x},\widetilde{w})
. The major distinction with the original GAN setup is dropping a separate network for the generator as the generated samples are always coming from
\mathcal{L}({\widetilde{X}},\widetilde{W})
. Optimization problem (
17
) then reduces to:

\max_{\theta_{d}}\left\{{\mathbb{E}}_{(X,W)}\Big[\log D((X,W);\theta_{d})\Big]+{\mathbb{E}}_{({\widetilde{X}},\widetilde{W})}\Big[\log\big(1-D(({\widetilde{X}},\widetilde{W});\theta_{d})\big)\Big]\right\}\,.

(18)

The next result connects the optimal discriminator
D(x)
(solution of (
18
)) and the likelihood ratio function. This proposition is borrowed from
[
GPAM+14
, Proposition 1]
.

Proposition 4.8
.

Let
D^{*}(x,w)
be the maximizer of optimization problem (
18
). Then we have

D^{*}(x,w)=\frac{p_{X,W}(x,w)}{p_{X,W}(x,w)+p_{{\widetilde{X}},\widetilde{W}}(x,w)}\,.

Since we only have one network, we only update the parameters of the discriminative network
D
. For this end, we adopt the same optimization procedure used in
[
GPAM+14
,
NCT16
]
, where at each step given a mini-batch of samples
\left\{(x^{1},w^{1}),\dots,(x^{m},w^{m})\right\}
and
\left\{(\tilde{x}^{1},\widetilde{w}^{1}),\dots,(\tilde{x}^{m},\widetilde{w}^{m})\right\}
we use the following stochastic gradient ascent:

\theta_{d}^{(t+1)}=\theta_{d}^{(t)}+\frac{\beta_{t}}{m}\sum_{i=1}^{m}\nabla_{\theta_{d}}\left[\log D\Big((x^{i},w^{i});\theta_{d}^{(t)}\Big)+\log\Big(1-D\big((\tilde{x}^{i},\widetilde{w}^{i});\theta_{d}^{(t)}\big)\Big)\right]\,,

with step size
\beta_{t}
.
The gradients of the above optimization problem can be efficiently computed using back-propagation algorithms. Let
{\widehat{\theta}}_{d}
be the resulting estimate after convergence. Considering Proposition
4.8
and our discussion below Proposition
4.7
, we consider the following score function

T(x,w)=\frac{D((x,w),{\widehat{\theta}}_{d})}{1-D((x,w),{\widehat{\theta}}_{d})}\,.

6
Solving the optimization problem for GRASP decision rules

The optimization problems (
5
) have convex objectives and constraints (
f
-divergence ball), and therefore we have a convex optimization problem. We use an iterative optimization procedure to find the optimal solution. It is worth highlighting that vanilla projected gradient descent requires projection onto the
f
-divergence ball, which can be computationally complex for large
L
or when selecting certain
f
divergence functions. To circumvent this issue, we explore an alternative approach by leveraging conditional gradient methods (Frank-Wolfe
[
FW56
]
) that avoid the need for such projections. This adoption of conditional gradient method is also motivated by the observation that minimizing a linear objective over an
f
-divergence ball has a simpler to analyze dual formulation
[
BTDHDW+13
,
ND16
]
. We first provide a brief overview of conditional gradient methods.

We consider a convex differentiable objective function
g:{\mathbb{R}}^{L}\to{\mathbb{R}}
and a compact convex set
\mathcal{P}\subset{\mathbb{R}}^{L}
. Given the optimization problem of minimizing
g
over
\mathcal{P}
, the following iterative rule is considered by conditional gradient methods:

p_{t+1}=\gamma_{t}q_{t}+(1-\gamma_{t})p_{t}\,,\quad q_{t}=\arg\min_{q\in\mathcal{P}}q^{\sf T}\nabla g(p_{t})\,,

(26)

where
\gamma_{t}
is the step size and can beset as
\gamma_{t}=\frac{1}{t+2}
.

Getting back to initial optimization problems (
5
), we have

U^{\mathsf{finite}}_{\tau}(\mathbf{V}_{n,L})=\min_{p\in\mathcal{U}_{\tau}}\frac{1}{n}\sum_{\ell=1}^{L}\frac{(V_{\ell}-np_{\ell})^{2}}{p_{\ell}+1/L}\,,\quad U^{\mathsf{asym}}_{\tau}(\mathbf{V}_{n,L})=\min_{p\in\mathcal{U}_{\tau}}\frac{1}{n}\sum_{\ell=1}^{L}\frac{(V_{\ell}-np_{\ell})^{2}}{p_{\ell}}\,,

(27)

where the constraint set
\mathcal{U}_{\tau}
is given by

{\mathcal{U}}_{\tau}=\left\{p\in{\mathbb{R}}^{L}\text{ s.t. }\quad p\geq 0,\quad\sum_{\ell=1}^{L}p_{\ell}=1,\quad\sum_{\ell=1}^{L}f(Lp_{\ell})\leq L\tau\right\}\,.

We next focus on solving the linearization of objective functions (
26
) over the
f
-divergence ball, which is needed in the update rule (
26
). This problem has been studied before by
[
BTDHDW+13
,
Sha17
]
for general continuous distributions. For the reader’s convenience, we state the result for the specific case of the problem over discrete distributions.

Proposition 6.1
.

For
x\in{\mathbb{R}}^{L}
and
\tau\geq 0

\displaystyle D_{f}\left(\mathcal{L}(X,W)\|\mathcal{L}({\widetilde{X}},\widetilde{W})\right)

\displaystyle={\mathbb{E}}\left[\int_{0}^{1}f\left({p_{W|X}(w|X)}\right){\rm d}w\right]\,.

(51)

Also from the construction of
w
, it is easy to see that

\displaystyle p_{W|X}(w|x)

\displaystyle={\mathbb{P}}(y=+1|x)p_{W|Y,X}(w|y=+1,x)+{\mathbb{P}}(y=0|x)p_{W|Y,X}(w|y=0,x)

\displaystyle=\frac{\eta(x)}{\widehat{\eta}(x)}{\mathbb{I}}(w\leq\widehat{\eta}(x))+\frac{1-\eta(x)}{1-\widehat{\eta}(x)}{\mathbb{I}}(w\geq\widehat{\eta}(x))\,.

(52)

Plugging (
A.6
) into (

) brings us to

\displaystyle D_{f}\left(\mathcal{L}(X,W)\|\mathcal{L}({\widetilde{X}},\widetilde{W})\right)

\displaystyle={\mathbb{E}}\left[\int_{0}^{\widehat{\eta}(X)}f\left(\frac{\eta(X)}{\widehat{\eta}(X)}\right){\rm d}w+\int_{\widehat{\eta}(X)}^{1}f\left(\frac{1-\eta(X)}{1-\widehat{\eta}(X)}\right){\rm d}w\right]

\displaystyle={\mathbb{E}}\left[\widehat{\eta}(X)f\left(\frac{\eta(X)}{\widehat{\eta}(X)}\right)+(1-\widehat{\eta}(X))f\left(\frac{1-\eta(X)}{1-\widehat{\eta}(X)}\right)\right]

\displaystyle={\mathbb{E}}\left[D_{f}\left(\mathsf{Bern}(\eta(X))\|\mathsf{Bern}(\widehat{\eta}(X))\right)\right]\,,

which completes the proof.

Proof of Proposition

We adopt the shorthand
\tau_{1}
for
\tau^{\mathsf{finite}}_{n,L,\alpha}
and

for

\tau_{1}

A.8
Proof of Proposition
3.8

The first inequality in Proposition
3.8
is a direct result of Jenson’s inequality applied on the convex function
f
. The last equation is also shown in the proof of Proposition
3.4
, for the complete proof we refer to the chain of relations started in (
41
). In this section, we focus on proving the first equation, in which we need to show that

\displaystyle\lim_{L\to\infty}\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})=\int_{0}^{1}f({\mathbb{E}}[\psi(u;X)]){\rm d}u\,.

(53)

Let
b_{j}(M,u)
denote the
j
-th Bernstein polynomial of degree
M
, which is given by

b_{j}(M,u)=\binom{M}{j}u^{j}(1-u)^{M-j}\,.

Then the probability
p_{\ell}
given in (
31
) can be written as

\displaystyle p_{\ell}=\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}b_{j}(M,u){\mathbb{E}}[\psi(u;X)]{\rm d}u\,.\quad\forall\ell\in[L]\,

(54)

In the next step, from the first assumption we have a.s.
|\psi(u;X)|\leq C
, and by an application of dominated convergence theorem we can change the order of derivative and expectation and get

\frac{{\rm d}}{{\rm d}u}{\mathbb{E}}[\omega(u;X)]={\mathbb{E}}[\psi(u;X)]\,.

Next, by using this in (
54
) and then by partial integration we arrive at

p_{\ell}=-\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}\frac{\partial b_{j}(M,u)}{\partial u}{\mathbb{E}}[\omega(u;X)]{\rm d}u\,.\quad\forall\ell\in[L]\,.

(55)

On the other hand, by simple algebraic calculation, it is easy to get the following identity for Bernstein polynomials:

\frac{\partial b_{j}(M,u)}{\partial u}=M(b_{j-1}(M-1,u)-b_{j}(M-1,u))\,,

(56)

where we set the convention
\binom{n}{k}=0
for
k>n
and
k<0
.
Using (
56
) in (
55
) gives us

p_{\ell}=M\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}{\mathbb{E}}[\omega(u;X)](b_{j}(M-1,u)-b_{j-1}(M-1,u)){\rm d}u\,.\quad\forall\ell\in[L]\,

Moving the summation inside the integration we obtain

p_{\ell}=M\int_{0}^{1}{\mathbb{E}}[\omega(u;X)](b_{K\ell-1}(M-1,u)-b_{K(\ell-1)-1}(M-1,u)){\rm d}u\,.\quad\forall\ell\in[L]\,

(57)

On the other hand, it is easy to check that

\displaystyle\int_{0}^{1}b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle=\int_{0}^{1}b_{K(\ell-1)-1}(M-1,u){\rm d}u=\frac{1}{M}\,.

(58)

Using the identities (
58
) and (
57
), we write

\displaystyle{\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]-{p_{\ell}}

\displaystyle=M\int_{0}^{1}\bigg({\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega(u;X)\right]\bigg)b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle\;+M\int_{0}^{1}\bigg({\mathbb{E}}[\omega(u;X)]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]\bigg)b_{K(\ell-1)-1}(M-1,u){\rm d}u\,.

Since almost surely
|\frac{\partial}{\partial u}\psi(u;X)|\leq C
for
u\in(0,1)
, we realize that
|\psi(u;X)|
is bounded by
C
almost surely, thereby
\omega(u;X)
is
C
-Lipschitz. Using this along with the triangle inequality we get

\displaystyle\left|{\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]-{p_{\ell}}\right|

\displaystyle\leq MC\int_{0}^{1}\Big|\frac{\ell}{L}-u\Big|b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle\;+MC\int_{0}^{1}\Big|u-\frac{\ell-1}{L}\Big|b_{K(\ell-1)-1}(M-1,u){\rm d}u\,.

(59)

We continue by writing the above expressions in terms of a Beta distribution.
Recall that the pdf of Beta distribution
\mathsf{Beta}(\alpha,\beta)
with shape parameters
(\alpha,\beta)
is given by
\frac{u^{\alpha-1}(1-u)^{\beta-1}}{B(\alpha,\beta)}
, where
B(\alpha,\beta):=\int_{0}^{1}u^{\alpha-1}(1-u)^{\beta-1}{\rm d}u
. For integer values
a,b
,
B(a,b)
has a closed form and is given by
B(a,b)=\frac{(a-1)!(b-1)!}{(a+b-1)!}
. Therefore, we have

\displaystyle Mb_{K\ell-1}(M-1,u)

\displaystyle=M{M-1\choose K\ell-1}u^{K\ell-1}(1-u)^{M-K\ell}

\displaystyle=\frac{M!}{(K\ell-1)!(M-K\ell)!}u^{K\ell-1}(1-u)^{M-K\ell}

\displaystyle=\frac{u^{K\ell-1}(1-u)^{M-K\ell}}{B(K\ell,M-K\ell+1)}\,.

Using a similar expression for
Mb_{K(\ell-1)-1}(M-1,u)
we write (
59
) as follows:

\displaystyle\frac{1}{C}\left|{\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]-{p_{\ell}}\right|

\displaystyle\leq{\mathbb{E}}_{u\sim\mathsf{Beta}(K\ell,M-K\ell+1)}\left[\Big|\frac{\ell}{L}-u\Big|\right]

\displaystyle\;+{\mathbb{E}}_{u\sim\mathsf{Beta}(K(\ell-1),M-K(\ell-1)+1)}\left[\Big|u-\frac{\ell-1}{L}\Big|\right]\,.

(60)

Since the mean of
\mathsf{Beta}(\alpha,\beta)
is given by
\alpha/(\alpha+\beta)
, the above Beta distributions have mean values of
\ell/L
and
(\ell-1)/L
, respectively (recall that
M+1=KL
). Therefore the terms on the right-hand side of (
60
) are indeed the mean absolute deviation of two Beta distributions. Further, using Jenson’s inequality we know that for arbitrary random variable
S
we have

{\mathbb{E}}[|S-{\mathbb{E}}[S]|]\leq{\rm Var}[S]^{1/2}\,.

Using this in (
60
) yields

\displaystyle\frac{1}{C}\left|{\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]-{p_{\ell}}\right|

\displaystyle\leq{\rm Var}\left[\mathsf{Beta}(K\ell,M-K\ell+1)\right]^{1/2}

\displaystyle\;+{\rm Var}\left[\mathsf{Beta}(K(\ell-1),M-K(\ell-1)+1)\right]^{1/2}\,.

(61)

In the next step, note that

{\rm Var}\left(\mathsf{Beta}(\alpha,\beta)\right)=\frac{\alpha\beta}{(\alpha+\beta)^{2}(\alpha+\beta+1)}\leq\frac{1}{4(\alpha+\beta)}\,,

(62)

where the last inequality follows from
(\alpha+\beta)^{2}\geq 4\alpha\beta
.
Combining (
61
) and (
62
) yields

\frac{1}{C}\left|{\mathbb{E}}\left[\omega\Big(\frac{\ell}{L};X\Big)\right]-{\mathbb{E}}\left[\omega\Big(\frac{\ell-1}{L};X\Big)\right]-{p_{\ell}}\right|\leq\frac{2}{2\sqrt{M+1}}=\frac{1}{\sqrt{KL}}\,.

(63)

Now from the mean value theorem, we know that there exists
s_{\ell}(X)\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]
such that

\omega\Big(\frac{\ell}{L};X\Big)-\omega\Big(\frac{\ell-1}{L};X\Big)=\frac{1}{L}\psi(s_{\ell}(X);X)\,.

(64)

Combining (
64
) and (
63
) yields

\lim_{K\to\infty}Lp_{\ell}={\mathbb{E}}\left[\psi(s_{\ell}(X);X)\right]\,,~\text{ where }s_{\ell}(x)\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]\,.

(65)

We are now ready to prove the claim of (
53
). Introduce function
\sigma(u)={\mathbb{E}}[\psi(u;X)]
, we have

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f({\mathbb{E}}\left[\psi(u;X)\right]){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f(Lp_{\ell})-L\int_{\frac{\ell-1}{L}}^{\frac{\ell}{L}}(f\circ\sigma)(u){\rm d}u\right]\,.

(66)

Given that
\psi(u,X)
is almost surely continuous, it is easy to observe that
\sigma(u)
is also continuous. In the next step, by another application of the mean value theorem for the continuous function
f\circ\sigma
, there exists
t_{\ell}\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]
such that

L\int_{\frac{\ell-1}{L}}^{\frac{\ell}{L}}(f\circ\sigma)(u){\rm d}u=(f\circ\sigma)(t_{\ell})\,.

(67)

By combining (
66
) and (
67
) we get

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f({\mathbb{E}}\left[\psi(u;X)\right]){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f(Lp_{\ell})-f\circ\sigma(t_{\ell})\right]\,,

(68)

and using continuity of
f
along with (
65
) and (
68
) we obtain

\displaystyle\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f({\mathbb{E}}[\psi(u;X)]){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f({\mathbb{E}}[\psi(s_{\ell}(X);X)])-f({\mathbb{E}}[\psi(t_{\ell};X)])\right]\,.

(69)

For the rest of the proof, we show that for every
{\varepsilon}>0
for sufficiently large
L
the right hand side of (
69
) is smaller than
{\varepsilon}
. For this end, we start by the fact that since
f
is a continuous function, therefore on the compact set
[0,C]
must be uniformly continuous. This implies that there exists
\delta>0
such that for every
r_{1},r_{2}\in[0,C]
with
|r_{1}-r_{2}|\leq\delta
we have
|f(r_{1})-f(r_{2})|\leq{\varepsilon}
. In the next step, we define values
r_{1}^{(\ell)}={\mathbb{E}}[\psi(s_{\ell}(X);X)]
and
r_{2}^{(\ell)}={\mathbb{E}}[\psi(t_{\ell};X)]
. We then claim that for sufficiently large value of

such that

we have

and

(proof of this claim is provided later). An immediate consequence of uniform continuity yields

, by plugging this into (

\displaystyle\left|\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f({\mathbb{E}}[\psi(u;X)]){\rm d}u\right|

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left|f({\mathbb{E}}[\psi(s_{\ell}(X);X)])-f({\mathbb{E}}[\psi(t_{\ell};X)])\right|

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left|f(r_{1}^{(\ell)})-f(r_{2}^{(\ell)})\right|\leq{\varepsilon}\,.

By letting

can be chosen arbitrarily small and so

\displaystyle\lim_{L\to\infty}\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})=\int_{0}^{1}f({\mathbb{E}}[\psi(u;X)]){\rm d}u\,.

We are only left to prove our claim that for every

, and get

Proof of Proposition
4.3

The proof for the first part, is basically almost similar to the proof of Proposition
3.4
. The minor difference is that the arguments should be followed for the function
\psi(u)
from Assumption
4.2
instead of conditional functions
\psi(u;x)
from Assumption
3.3
, and also careful treatment of conditional expectations with respect to covariates
x
. We provide the complete proof here for the reader’s convenience.

First, it is easy to observe that the joint distribution of
(V_{1},\dots,V_{L})
is a multinomial distribution with probabilities
(p_{1},\dots,p_{L})
where
p_{\ell}
denotes the probability of random variables
(X,W)
admitting label
\ell
for
\ell\in[L]
. In accordance with Algorithm
3
, each sample
(X,W)
has
M
counterfeits
({\widetilde{X}}_{1},\widetilde{W}_{1}),\dots,({\widetilde{X}}_{M},\widetilde{W}_{M})
where
\widetilde{W}_{i}
are iid random variables distributed as
\mathsf{Unif}[0,1]
, and
{\widetilde{X}}_{i}
are iid from
\mathcal{P}_{X}

, and

We know that random variables

,

are independent, which gives us the following:

\displaystyle=\sum_{j=K(\ell-1)}^{K\ell-1}\int{\mathbb{P}}(\text{ exactly }j\text{ of }T_{j\in[M]}\text{ are smaller than }t){\rm d}P_{T}(t)

The last relation follows from the iid property of random variables

along with the definitions of

4.2
. By using the dummy variable

in the inner integral of (

\psi(u)
as density function of

. We write the above probability as

For
\ell\in[L]

By an application of Jensen’s inequality and using the convexity of

Equivalently this can be rewritten as

Plugging (

) into (

.

First from the definition of polynomial
\beta_{\ell}(u)

\displaystyle=\sum_{j=0}^{M}\binom{M}{j}u^{j}(1-u)^{M-j}=(u+1-u)^{M}=1\,.

Using (
79
) in (

) we have

(81)

which together with (

) gives

(82)

The last step above follows from (
80
).

We next use the definition of
\psi(u)
in the right hand side of (

) to obtain

\displaystyle\int_{0}^{1}f(\psi(u)){\rm d}u

\displaystyle=\int_{0}^{1}f\Big(\frac{f_{o}(F_{c}^{-1}(u))}{f_{c}(F_{c}^{-1}(u))}\Big){\rm d}u

\displaystyle=\int_{-\infty}^{\infty}f\Big(\frac{f_{o}(t)}{f_{c}(t)}\Big)f_{c}(t){\rm d}t

\displaystyle=D_{f}\left(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W}))\right)\,,

where the last relation comes from the definition of

divergence and density functions

and
f_{c}(t)
.

We next proceed to the proof of the second part. By virtue of characterization in (
83
), we need to show that

\displaystyle\lim_{L\to\infty}\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})=\int_{0}^{1}f(\psi(u)){\rm d}u\,.

Let
b_{j}(M,u)
denote the
j
-th Bernstein polynomial of degree
M
, which is given by

b_{j}(M,u)=\binom{M}{j}u^{j}(1-u)^{M-j}\,.

Then the probability
p_{\ell}
given in (
72
) can be written as

\displaystyle p_{\ell}=\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}b_{j}(M,u)\psi(u){\rm d}u\,.\quad\forall\ell\in[L]\,

Next, partial integration yields

p_{\ell}=-\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}\frac{\partial b_{j}(M,u)}{\partial u}\omega(u){\rm d}u\,.\quad\forall\ell\in[L]\,.

(85)

On the other hand, by simple algebraic calculation, it is easy to get the following identity for Bernstein polynomials:

\frac{\partial b_{j}(M,u)}{\partial u}=M(b_{j-1}(M-1,u)-b_{j}(M-1,u))\,,

(86)

where we set the convention
\binom{n}{k}=0
for
k>n
and
k<0
.
Using (
86
) in (
85
) gives us

p_{\ell}=M\sum_{j=K(\ell-1)}^{K\ell-1}\int_{0}^{1}\omega(u)(b_{j}(M-1,u)-b_{j-1}(M-1,u)){\rm d}u\,.\quad\forall\ell\in[L]\,

Moving the summation inside the integration we obtain

p_{\ell}=M\int_{0}^{1}\omega(u)(b_{K\ell-1}(M-1,u)-b_{K(\ell-1)-1}(M-1,u)){\rm d}u\,.\quad\forall\ell\in[L]\,

(87)

On the other hand, it is easy to check that

\displaystyle\int_{0}^{1}b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle=\int_{0}^{1}b_{K(\ell-1)-1}(M-1,u){\rm d}u=\frac{1}{M}\,.

(88)

Using the identities (
88
) and (
87
), we write

\displaystyle\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)-{p_{\ell}}

\displaystyle=M\int_{0}^{1}\bigg(\omega\Big(\frac{\ell}{L}\Big)-\omega(u)\bigg)b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle\;+M\int_{0}^{1}\bigg(\omega(u)-\omega\Big(\frac{\ell-1}{L}\Big)\bigg)b_{K(\ell-1)-1}(M-1,u){\rm d}u\,.

Since
\psi(.)
is continuous on
[0,1]
, therefore it is
B
-bounded. This means that
\omega(.)
is
B
-Lipschitz. Using this along with the triangle inequality we get

\displaystyle\left|\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)-{p_{\ell}}\right|

\displaystyle\leq MB\int_{0}^{1}\Big|\frac{\ell}{L}-u\Big|b_{K\ell-1}(M-1,u){\rm d}u

\displaystyle\;+MB\int_{0}^{1}\Big|u-\frac{\ell-1}{L}\Big|b_{K(\ell-1)-1}(M-1,u){\rm d}u\,.

(89)

We continue by writing the above expressions in terms of a Beta distribution.
Recall that the pdf of Beta distribution
\mathsf{Beta}(\alpha,\beta)
with shape parameters
(\alpha,\beta)
is given by
\frac{u^{\alpha-1}(1-u)^{\beta-1}}{B(\alpha,\beta)}
, where
B(\alpha,\beta):=\int_{0}^{1}u^{\alpha-1}(1-u)^{\beta-1}{\rm d}u
. For integer values
a,b
,
B(a,b)
has a closed form and is given by
B(a,b)=\frac{(a-1)!(b-1)!}{(a+b-1)!}
. Therefore, we have

\displaystyle Mb_{K\ell-1}(M-1,u)

\displaystyle=M{M-1\choose K\ell-1}u^{K\ell-1}(1-u)^{M-K\ell}

\displaystyle=\frac{M!}{(K\ell-1)!(M-K\ell)!}u^{K\ell-1}(1-u)^{M-K\ell}

\displaystyle=\frac{u^{K\ell-1}(1-u)^{M-K\ell}}{B(K\ell,M-K\ell+1)}\,.

Using a similar expression for
Mb_{K(\ell-1)-1}(M-1,u)
we write (
89
) as follows:

\displaystyle\frac{1}{B}\left|\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)-{p_{\ell}}\right|

\displaystyle\leq{\mathbb{E}}_{u\sim\mathsf{Beta}(K\ell,M-K\ell+1)}\left[\Big|\frac{\ell}{L}-u\Big|\right]

\displaystyle\;+{\mathbb{E}}_{u\sim\mathsf{Beta}(K(\ell-1),M-K(\ell-1)+1)}\left[\Big|u-\frac{\ell-1}{L}\Big|\right]\,.

(90)

Since the mean of
\mathsf{Beta}(\alpha,\beta)
is given by
\alpha/(\alpha+\beta)
, the above Beta distributions have mean values of
\ell/L
and
(\ell-1)/L
, respectively (recall that
M+1=KL
). Therefore the terms on the right-hand side of (
90
) are indeed the mean absolute deviation of two Beta distributions. Further, using Jenson’s inequality we know that for arbitrary random variable
S
we have

{\mathbb{E}}[|S-{\mathbb{E}}[S]|]\leq{\rm Var}[S]^{1/2}\,.

Using this in (
90
) yields

\displaystyle\frac{1}{B}\left|\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)-{p_{\ell}}\right|

\displaystyle\leq{\rm Var}\left[\mathsf{Beta}(K\ell,M-K\ell+1)\right]^{1/2}

\displaystyle\;+{\rm Var}\left[\mathsf{Beta}(K(\ell-1),M-K(\ell-1)+1)\right]^{1/2}\,.

(91)

In the next step, note that

{\rm Var}\left(\mathsf{Beta}(\alpha,\beta)\right)=\frac{\alpha\beta}{(\alpha+\beta)^{2}(\alpha+\beta+1)}\leq\frac{1}{4(\alpha+\beta)}\,,

(92)

where the last inequality follows from
(\alpha+\beta)^{2}\geq 4\alpha\beta
.
Combining (
91
) and (
92
) yields

\frac{1}{B}\left|\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)-{p_{\ell}}\right|\leq\frac{2}{2\sqrt{M+1}}=\frac{1}{\sqrt{KL}}\,.

(93)

Now from the mean value theorem, we know that there exists
s_{\ell}\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]
such that

\omega\Big(\frac{\ell}{L}\Big)-\omega\Big(\frac{\ell-1}{L}\Big)=\frac{1}{L}\psi(s_{\ell})\,.

(94)

Combining (
94
) and (
93
) yields

\lim_{K\to\infty}Lp_{\ell}=\psi(s_{\ell})\,,~\text{ for some }s_{\ell}\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]\,.

(95)

We are now ready to prove the claim of (
84
). Write

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f(\psi(u)){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f(Lp_{\ell})-L\int_{\frac{\ell-1}{L}}^{\frac{\ell}{L}}(f\circ\psi)(u){\rm d}u\right]\,.

(96)

By another application of the mean value theorem for the continuous function
f\circ\psi
, there exists
t_{\ell}\in\left[\frac{\ell-1}{L},\frac{\ell}{L}\right]
such that

L\int_{\frac{\ell-1}{L}}^{\frac{\ell}{L}}(f\circ\psi)(u){\rm d}u=(f\circ\psi)(t_{\ell})\,.

(97)

By combining (
96
) and (
97
) we get

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f(\psi(u)){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f(Lp_{\ell})-f\circ\psi(t_{\ell})\right]\,,

(98)

and using continuity of
f
along with (
95
) and (
98
) we obtain

\displaystyle\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f(\psi(u)){\rm d}u

\displaystyle=\frac{1}{L}\sum_{\ell=1}^{L}\left[f\circ\psi(s_{\ell})-f\circ\psi(t_{\ell})\right]\,.

(99)

Next since
f\circ\psi
is continuous on the compact set
[0,1]
, it is uniformly continuous. This implies that for every arbitrary
{\varepsilon}>0
, there exists
\delta>0
such that if
|u_{1}-u_{2}|\leq\delta
, then we have
|f\circ\psi(u_{1})-f\circ\psi(u_{2})|\leq{\varepsilon}
. Choose
L
sufficiently large such that
1/L<\delta
. Since both
t_{\ell},s_{\ell}
belong to the interval
[(\ell-1)/L,\ell/L]
we get that
|s_{\ell}-t_{\ell}|<\delta
, and therefore
|f\circ\psi(s_{\ell})-f\circ\psi(t_{\ell})|\leq{\varepsilon}
. Using this observation in (
99
) we see that for every arbitrary small
{\varepsilon}>0
and sufficiently large
L
we have

\displaystyle\left|\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})-\int_{0}^{1}f(\psi(u)){\rm d}u\right|

\displaystyle\leq\frac{1}{L}\sum_{\ell=1}^{L}\left|f\circ\psi(s_{\ell})-f\circ\psi(t_{\ell})\right|\leq{\varepsilon}\,.

By letting
L
go to infinity,
{\varepsilon}
can be chosen arbitrarily small and so

\displaystyle\lim_{L\to\infty}\lim_{K\to\infty}\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})=\int_{0}^{1}f(\psi(u)){\rm d}u\,.

(100)

This completes the proof of the claim (
84
), and so the proof of the second part of Proposition
4.3
.

A.11
Proof of Theorem
4.4

As we showed in Proposition
4.3
(first part), we have:

\displaystyle\frac{1}{L}\sum_{\ell=1}^{L}f(Lp_{\ell})\leq D_{f}(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W})))\,.

Also, by an application of the data processing inequality we have

D_{f}\left(\mathcal{L}(T(X,W))\|\mathcal{L}(T({\widetilde{X}},\widetilde{W}))\right)\leq D_{f}\left(\mathcal{L}(X,W)\|\mathcal{L}({\widetilde{X}},\widetilde{W})\right)\,.

The result then follows from Proposition

.

A.12
Proof of Lemma
4.6

Using the definition of
f
-divergence and conjugate function we have

\displaystyle D_{f}(p\|q)

\displaystyle=\int qf\left(\frac{p}{q}\right){\rm d}\mu

\displaystyle\geq\int q\sup_{\varphi\in\mathcal{G}}\left\{\frac{\varphi p}{q}-f^{*}\left(\varphi\right)\right\}{\rm d}\mu

\displaystyle\geq\sup_{\varphi\in\mathcal{G}}\int\left(\varphi p-f^{*}(\varphi)q\right){\rm d}\mu\,.

This completes the proof of the lower bound. Next we show that this bound becomes tight if
\sigma\in\partial f(p/q)
, for any
x\in\mathcal{X}
(Here,
p,q
and
\sigma
are evaluated at any
x\in\mathcal{X}
). The definition of subdifferential implies that for every measurable function
h:\mathcal{X}\to{\mathbb{R}}
we have

f(h)-f\left(\frac{p}{q}\right)\geq\sigma h-\frac{\sigma p}{q}\,.

This gives us

f\left(\frac{p}{q}\right)\leq\frac{\sigma p}{q}-(\sigma h-f(h))\,.

Since this holds for every measurable function
h
we get

f\left(\frac{p}{q}\right)\leq\frac{\sigma p}{q}-\sup_{h}(\sigma h-f(h))\,.

In the next step, by using the definition of the conjugate dual function we get

qf\left(\frac{p}{q}\right)\leq{\sigma p}-qf^{*}(\sigma)\,.

This completes the proof.

A.13
Proof of Proposition
4.7

Since
X_{p}\sim p
and
X_{q}\sim q
, we get
D_{f}(p\|q)=D_{f}(\mathcal{L}(X_{p})\|\mathcal{L}(X_{q}))
and by an application of the data processing inequality we obtain

\displaystyle D_{f}(p\|q)=D_{f}(\mathcal{L}(X_{p})\|\mathcal{L}(X_{q}))\geq D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))\,.

We next show the other direction, i.e.,

D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))\geq D_{f}(p\|q)\,.

(101)

Let
\widetilde{p}
and
\widetilde{q}
denote the density functions of
\sigma(X_{p})
and
\sigma(X_{q})
respectively. By using Lemma
4.6
for density functions
\widetilde{p},\widetilde{q}
and a class of measurable functions
\mathcal{G}=\{g:{\mathbb{R}}\to{\mathbb{R}}\}
we get

D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))\geq\sup_{g\in\mathcal{G}}\int\left(g\widetilde{p}-f^{*}(g)\widetilde{q}\right){\rm d}\mu\,.

(102)

Next, by rewriting (
102
) in terms of expectations we arrive at

D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))\geq\sup_{g\in\mathcal{G}}\left\{{\mathbb{E}}_{t\sim\widetilde{p}}[g(t)]-{\mathbb{E}}_{t\sim\widetilde{q}}[f^{*}(g(t))]\right\}\,.

We then change the expectation measures to get

D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))\geq\sup_{g\in\mathcal{G}}\left\{{\mathbb{E}}[g(\sigma(X_{p}))]-{\mathbb{E}}[f^{*}(g(\sigma(X_{q})))]\right\}\,.

(103)

We consider the identity function
g(t)=t
defined over the real line, with the convention that
g(\infty)=\infty
.
Evaluating the right-hand side of (
103
) at
g
we get

\displaystyle D_{f}(\mathcal{L}(\sigma(X_{p}))\|\mathcal{L}(\sigma(X_{q})))

\displaystyle\geq{\mathbb{E}}[\widetilde{g}(\sigma(X_{p}))]-{\mathbb{E}}[f^{*}(\widetilde{g}(\sigma(X_{q})))

\displaystyle={\mathbb{E}}[\sigma(X_{p})]-{\mathbb{E}}[f^{*}(\sigma(X_{q}))]\,.

(104)

We also know from Lemma
4.6
that for
\sigma\in\partial f(p/q)
we have

{\mathbb{E}}[\sigma(X_{p})]-{\mathbb{E}}[f^{*}(\sigma(X_{q})))=D_{f}(p\|q)\,.

(105)

Combining (
104
) and (
105
) yields (
101
) and completes the proof.

Appendix B
Proof of Proposition
6.1

The Lagrangian of
\min\limits_{q\in{\mathcal{U}}_{\tau}}q^{\sf T}x
is given by

L(q;\eta,\lambda)=q^{\sf T}x+\lambda\left(\frac{1}{L}\sum\limits_{\ell=1}^{L}f(Lq_{\ell})-\tau\right)+\eta\left(\sum\limits_{\ell=1}^{L}q_{\ell}-1\right)\,.

In this case, the dual objective function is

D(\lambda,\eta)=\min_{q\geq 0}\left[q^{\sf T}x+\frac{\lambda}{L}\sum\limits_{\ell=1}^{L}f(Lq_{\ell})-{\lambda\tau}+\eta(\sum\limits_{\ell=1}^{L}q_{\ell}-1)\right]\,.

The constraints are decoupled and minimization can be moved inside, this yields

D(\lambda,\eta)=-\eta-\lambda\tau+\sum\limits_{\ell=1}^{L}\min\limits_{q_{\ell}\geq 0}\left[q_{\ell}x_{\ell}+\frac{\lambda}{L}f(Lq_{\ell})+\eta q_{\ell}\right]\,.

Using the conjugate dual definition
f(s)=\sup\limits_{t\geq 0}[st-f(t)]
yields

D(\lambda,\eta)=-\eta-\lambda\tau-\frac{\lambda}{L}\sum\limits_{\ell=1}^{L}f^{*}\left(-\frac{x_{\ell}+\eta}{L\lambda}\right)\,.

In this formulation the optimal
q_{\ell}
is such that

-\frac{x_{\ell}+\eta}{L\lambda}\in\partial f(q_{\ell})\,.

(106)

Given that in this problem the strong duality holds (Slater’s condition for
\tau>0
), using
\lambda^{*},\eta^{*}
as solutions of
\arg\min_{\lambda\geq 0,\eta}-D(\lambda,\eta)
in (
106
) completes the proof.
