On solutions of the distributional Bellman equation
Julian Gerstenberg, Ralph Neininger, Denis Spiegel

Abstract
In distributional reinforcement learning not only expected returns but the complete return distributions of a policy are taken into account. The return distribution for a fixed policy is given as the solution of an associated distributional Bellman equation. In this note we consider general distributional Bellman equations and study existence and uniqueness of their solutions as well as tail properties of return distributions. We give necessary and sufficient conditions for existence and uniqueness of return distributions and identify cases of regular variation. We link distributional Bellman equations to multivariate affine distributional equations. We show that any solution of a distributional Bellman equation can be obtained as the vector of marginal laws of a solution to a multivariate affine distributional equation. This makes the general theory of such equations applicable to the distributional reinforcement learning setting.



Keywords:
distributional reinforcement learning; distributional Bellman equation; random difference equation; perpetuity; Markov decision process; regular variation; machine learning

AMS subject classifications:
Primary: 60E05, 60H25, Secondary: 68T05, 90C40

Introduction

The objective in reinforcement learning (RL) is to teach an agent that sequentially interacts with an environment to choose ’good’ actions. For each action the agent receives an immediate real-valued reward. The rewards are accumulated over time resulting in the so-called
return
, which describes the overall performance of the agent. Randomness may be involved at all levels of this interaction: in choosing actions, the environment reacting to actions and/or in the rewards received by the agent. Hence, the return is to be considered random as well. In more classical approaches to RL problems the randomness is averaged out and only the expected return is considered when evaluating the performance of an agent. In
[
1
]
, not only the expectation but the complete distribution of the return was considered, introducing what is now known as
distributional
RL, see
[
2
]
.

Mathematically, a RL problem is typically modeled by a
Markov decision process
(MDP), that is as a particular type of a discrete-time stochastic control problem. An overview of the classical MDP theory and its applications is presented in
[
3
]
. For more details on distributional RL using notations similar to here we refer to
[
4
,
2
]
.

For any measurable space
\mathcal{X}
we write
\mathscr{P}(\mathcal{X})
for the set of probability distributions on
\mathcal{X}
. The distribution (law) of a
\mathcal{X}
-valued random variable (RV)
X
is denoted by
\mathcal{L}(X)=\mathbb{P}[X\in\cdot~]\in\mathscr{P}(\mathcal{X})
. We also write short
X\sim\mu
, if
\mathcal{L}(X)=\mu\in\mathscr{P}(\mathcal{X})
. In case
\mathcal{X}
is countable, discrete distributions
\nu\in\mathscr{P}(\mathcal{X})
can be identified with functions
\nu:\mathcal{X}\rightarrow[0,1]
satisfying
\sum_{x\in\mathcal{X}}\nu(x)=1
. For a random variable
X
and an event
A
with
\mathbb{P}[A]>0
we write
\mathcal{L}(X|A)\in\mathscr{P}(\mathcal{X})
for the conditional distribution of
X
given
A
.

Let
\mathcal{S}
and
\mathcal{A}
be non-empty finite sets. A MDP on states
\mathcal{S}
and actions
\mathcal{A}
is a function

\rho:\mathcal{S}\times\mathcal{A}\rightarrow\mathscr{P}(\mathcal{S}\times\mathbb{R}),~~(s,a)\mapsto\rho_{(s,a)}.

(1.1)

The interpretation is as follows:
\mathcal{S}
is the set of states an environment can occupy and
\mathcal{A}
the set of possible actions the agent can perform. If in state
s\in\mathcal{S}
the agent performs action
a\in\mathcal{A}
the environment reacts with a (possibly random) successor state
S
together with a (possibly random) real-valued reward
R
having joint distribution
(S,R)\sim\rho_{(s,a)}\in\mathscr{P}(\mathcal{S}\times\mathbb{R})
. How an agent chooses its actions can be modeled by a (stationary)
policy

\pi:\mathcal{S}\rightarrow\mathscr{P}(\mathcal{A}),~~s\mapsto\pi_{s}.

(1.2)

An agent that is in state
s
and acts according to policy
\pi
chooses a (possibly random) action
A
distributed as
A\sim\pi_{s}\in\mathscr{P}(\mathcal{A})
.

Suppose an agent acting according to
\pi
. Starting at time
t=0
from a possibly random state
S^{(0)}
the following dynamic is defined inductively: at time
t\in\mathbb{N}_{0}
the agent finds itself in state
S^{(t)}
, chooses action
A^{(t)}\sim\pi_{S^{(t)}}
(independent of the past given
S^{(t)}
) and the environment reacts with the next state
S^{(t+1)}
and immediate reward
R^{(t)}
jointly distributed as
(S^{(t+1)},R^{(t)})\sim\rho_{(S^{(t)},A^{(t)})}
(independent of the past given
(S^{(t)},A^{(t)})
). The resulting stochastic process

(S^{(t)},A^{(t)},R^{(t)})_{t\in\mathbb{N}_{0}}

(1.3)

is called
Markov reward process
in
[
2
]
or
full MDP
in
[
4
]
. To emphasize that the distribution of the stochastic process (
1.3
) depends on
\pi
, we write
\mathbb{P}^{\pi}
instead of
\mathbb{P}
.

A suitable way to judge the overall performance of the agent is to choose a
discount factor

\gamma\in(0,1)
and to consider the discounted accumulated rewards, the so-called
return
:

G=R^{(0)}+\gamma R^{(1)}+\gamma^{2}R^{(2)}+\cdots=\sum_{t=0}^{\infty}\gamma^{t}R^{(t)}.

(1.4)

The return
G
is defined as an infinite series of random variables and its existence as a
\mathbb{R}
-valued random variable is not automatically guaranteed, for example if rewards are (extremely) heavy-tailed. Theorem
1
below provides a complete characterization of when the return
G
exists almost surely as a
\mathbb{R}
-valued random variable starting from any state
S^{(0)}=s
. The relation of Theorem
1
to earlier results is discussed in Remarks
2
,
3
and
4
. In various applications, heavy-tailed reward distributions are not encountered. For instance, if rewards are obtained as a deterministic function of states and actions, the rewards become bounded, and the existence of the return
G
easily follows by a geometric series argument. However, unbounded and even heavy-tailed reward distributions are of interest in various applications: fields in which RL approaches have been considered and heavy-tailed distributions play a crucial role include insurance and finance. See
[
5
]
and
[
6
]
for RL approaches to pricing and trading and
[
7
]
for the role of heavy-tailed distributions in that field. Another research area in which heavy-tailed reward distributions have been considered recently is the study of multi-armed bandit models, which corresponds to an MDP with only a single state,
|\mathcal{S}|=1
. In
[
8
]
the authors report on several studies in this direction, including linear bandits
[
9
]
,
[
10
]
, pure exploration
[
11
]
, Lipschitz-bandits
[
12
]
, Bayesian optimization
[
13
]
and Thompson sampling
[
14
]
. Notably, in the latter work a particular emphasis is placed on
\alpha
-stable reward distributions, which is an assumption also covered by our analysis, see Theorem
4
and Example
3
. It is worth noting that all of these works consider finite horizon non-discounted returns rather than infinite discounted returns. Our analysis offers a theoretical justification for the inclusion of heavy-tailed reward distributions in infinite discounted reward scenarios.

Remark 1
.

The case
\gamma=0
is sometimes considered in RL literature, resulting in
G=R^{(0)}
and trivializing many of the research questions we investigate here. Although we do not discuss this case further, it should be noted that several parts of our results remain applicable even when
\gamma=0
.

Suppose the return
G
exists as a
\mathbb{R}
-valued RV starting from any state
s
. Of interest in
distributional policy evaluation
are the distributions of the return starting from given states. The
state(-action) return distributions
are defined by

\displaystyle\eta^{\pi}_{s}

\displaystyle=\mathbb{P}^{\pi}[G\in\cdot~|S^{(0)}=s],~~~s\in\mathcal{S},

(1.5)

\displaystyle\eta^{\pi}_{(s,a)}

\displaystyle=\mathbb{P}^{\pi}[G\in\cdot~|S^{(0)}=s,A^{(0)}=a],~~~(s,a)\in\mathcal{S}\times\mathcal{A}.

In
[
2
]
the collection
\eta^{\pi}=(\eta^{\pi}_{s})_{s\in\mathcal{S}}
is called
return distribution function
. The state(-action) return distributions can be found as solutions to the
distributional Bellman equations
, which we now explain. For
r\in\mathbb{R},\gamma\in(0,1)
let
f_{r,\gamma}:\mathscr{P}(\mathbb{R})\rightarrow\mathscr{P}(\mathbb{R})
be the map that sends
\nu=\mathcal{L}(X)
to
f_{r,\gamma}(\nu)=\mathcal{L}(r+\gamma X)
. Using the recursive structure of the return,
G=R^{(0)}+\gamma G^{\prime}
with
G^{\prime}=\sum_{t=0}^{\infty}\gamma^{t}R^{(t+1)}
, and Markov properties of (
1.3
) it is seen that state and state-action return distributions are related by

\displaystyle\eta^{\pi}_{s}

\displaystyle=\sum_{a\in\mathcal{A}}\pi_{s}(a)\eta^{\pi}_{(s,a)},~~~s\in\mathcal{S},

(1.6)

\displaystyle\eta^{\pi}_{(s,a)}

\displaystyle=\int_{\mathcal{S}\times\mathbb{R}}f_{r,\gamma}\big(\eta^{\pi}_{s^{\prime}}\big)d\rho_{(s,a)}(s^{\prime},r),~~~(s,a)\in\mathcal{S}\times\mathcal{A}.

Substituting the formulas in one another yields the distributional Bellman equations, which come in two forms: one for states and one for state-actions:

\displaystyle\eta^{\pi}_{s}

\displaystyle=\sum_{a\in\mathcal{A}}\int_{\mathcal{S}\times\mathbb{R}}\pi_{s}(a)f_{r,\gamma}\big(\eta^{\pi}_{s^{\prime}}\big)d\rho_{(s,a)}(s^{\prime},r),~~~s\in\mathcal{S},

(1.7)

\displaystyle\eta^{\pi}_{(s,a)}

\displaystyle=\int_{\mathcal{S}\times\mathbb{R}}\sum_{a^{\prime}\in\mathcal{A}}\pi_{s^{\prime}}(a^{\prime})f_{r,\gamma}\big(\eta^{\pi}_{(s^{\prime},a^{\prime})}\big)d\rho_{(s,a)}(s^{\prime},r),~~~(s,a)\in\mathcal{S}\times\mathcal{A}.

The distributional Bellman equations are a system of
|\mathcal{S}|
resp.
|\mathcal{S}\times\mathcal{A}|
one-dimensional distributional equations in
\mathbb{R}
. The right hand side of the equations can be used to introduce the
distributional Bellman operator
, which for the state return distributions is defined as:

\displaystyle\mathcal{T}^{\pi}:\mathscr{P}(\mathbb{R})^{\mathcal{S}}\longrightarrow\mathscr{P}(\mathbb{R})^{\mathcal{S}},~~~\eta=(\eta_{s})_{s\in\mathcal{S}}

\displaystyle\longmapsto\mathcal{T}^{\pi}(\eta)=\Big(\mathcal{T}^{\pi}_{s}(\eta)\Big)_{s\in\mathcal{S}}

(1.8)

\displaystyle\text{with $s$-th component function}

\displaystyle\mathcal{T}^{\pi}_{s}(\eta)=\sum_{a\in\mathcal{A}}\int_{\mathcal{S}\times\mathbb{R}}\pi_{s}(a)f_{r,\gamma}\big(\eta_{s^{\prime}}\big)d\rho_{(s,a)}(s^{\prime},r).

No assumption on the MDP
\rho
nor the policy
\pi
is needed to define (
1.8
) and the relation to the state return distributions is as follows: if the return
G
, starting from any state
s
, converges almost surely in
\mathbb{R}
then the return distribution function
\eta^{\pi}=(\eta^{\pi}_{s})_{s\in\mathcal{S}}
is a fixed point of
\mathcal{T}^{\pi}
, that is
\eta^{\pi}=\mathcal{T}^{\pi}(\eta^{\pi})
. We explore this connection in more detail.

We write
\log^{+}(x)=\log(x)
for
x\geq 1
and
\log^{+}(x)=0
for
x<1
. The definition of ’essential state’ is given before Theorem
2
. One result of this note is the following:

Theorem 1
.

The following are equivalent:

(i)

\mathcal{T}^{\pi}
has a fixed point
\eta\in\mathscr{P}(\mathbb{R})^{\mathcal{S}}
,

(ii)

G=\sum_{t=0}^{\infty}\gamma^{t}R^{(t)}
converges
\mathbb{P}^{\pi}[~\cdot~|S^{(0)}=s]
-almost surely in
\mathbb{R}
for every initial state
s\in\mathcal{S}
,

(iii)

\int_{\mathcal{S}\times\mathbb{R}}\log^{+}(|r|)d\rho_{(s,a)}(s^{\prime},r)<\infty
for every pair
(s,a)\in\mathcal{S}\times\mathcal{A}
that is essential with respect to the law of the Markov chain
(S^{(t)},A^{(t)})_{t\in\mathbb{N}_{0}}
under
\mathbb{P}^{\pi}
,

(iv)

For every
\nu\in\mathscr{P}(\mathbb{R})^{\mathcal{S}}
as
n\rightarrow\infty
the sequence
\big(\mathcal{T}^{\pi}\big)^{\circ n}(\nu)
of
n
-th iterations of
\mathcal{T}^{\pi}
converges weakly in the product space
\mathscr{P}(\mathbb{R})^{\mathcal{S}}
.

If these hold the fixed point of
\mathcal{T}^{\pi}
is unique, given by the return distribution function
\eta^{\pi}
and

\big(\mathcal{T}^{\pi}\big)^{\circ n}(\nu)\rightarrow\eta^{\pi}
weakly as
n\rightarrow\infty
for every
\nu\in\mathscr{P}(\mathbb{R})^{\mathcal{S}}
.

A theorem that reads analogously can be formulated for the distributional Bellman operator
\mathcal{T}^{\pi}:\mathscr{P}(\mathbb{R})^{\mathcal{S}\times\mathcal{A}}\rightarrow\mathscr{P}(\mathbb{R})^{\mathcal{S}\times\mathcal{A}}
defined in terms of state-actions. We cover both cases simultaneously by introducing simplified notations in Section
1.2
that allow to analyze the distributional Bellman operator, its fixed point equations and its solutions more conveniently. In Section
2
we present our main results in these notations, Theorem
1
will follow from the more general Theorem
2
presented there. For connections to a model and results in
[
15
]
see Remark
2
.

Besides giving necessary and sufficient conditions for the existence of solutions to the distributional Bellman equations, we also study properties of their solutions, that is of the return distribution function
\eta^{\pi}
(and also state-action return distributions). We consider tail probability asymptotics
\eta^{\pi}_{s}((-\infty,-x))
and
\eta^{\pi}_{s}((x,\infty))
as
x\rightarrow\infty
, in Theorem
3
we identify cases of exponential decay and existence of
p
-th moments and in Theorem
4
we cover regular variation. A possible application of the latter is in Distributional Dynamic Programming (see Chapter 5 in
[
2
]
), see Remark
6
of the present note.

Building upon our simplified notation we explore the connection of the distributional Bellman equations to multivariate distributional equations of the form
\textbf{X}\overset{d}{=}\textbf{A}\textbf{X}+\textbf{B}
in Section
2.1
. This connection seems to have not been noticed in the literature so far and can be used to apply available results in that field to the distributional RL setting – we do that when proving Theorem
4
by applying results presented in
[
16
]
.

Before we switch to the simplified notation and present the main results, we shortly present the
ordinary
Bellman equations for convenience.

1.1
The ordinary Bellman equations

The following is well-known and the standard setting in much of the distributional RL literature: if reward distributions
\rho_{(s,a)}(\mathcal{S}\times\cdot)\in\mathscr{P}(\mathbb{R})
have finite expectations for all
(s,a)
, the return converges almost surely and has finite expectations as well; this also follows from Theorems
2
and
3
presented in this note. In many classical approaches to RL only expected returns are used for policy evaluation, the
state values
and
state-action values
are defined by

\displaystyle v^{\pi}_{s}

\displaystyle=\mathbb{E}^{\pi}[G|S^{(0)}=s]=\int_{\mathbb{R}}g~d\eta^{\pi}_{s}(g),

(1.9)

\displaystyle q^{\pi}_{(s,a)}

\displaystyle=\mathbb{E}^{\pi}[G|S^{(0)}=s,A^{(0)}=a]=\int_{\mathbb{R}}g~d\eta^{\pi}_{(s,a)}(g).

The collection
v^{\pi}=(v^{\pi}_{s})_{s\in\mathcal{S}}
is called state value function and
q^{\pi}
state-action value function. They can be found as solutions to the (ordinary)
Bellman equations
, which can be derived from their distributional counterparts (
1.7
) using linearity of expectation. For action
a
in state
s
let
r_{(s,a)}\in\mathbb{R}
be the expected reward and
p_{(s,a)}\in\mathscr{P}(\mathcal{S})
the distribution of the next state, that is

\displaystyle r_{(s,a)}

\displaystyle=\int r~d\rho_{(s,a)}(s^{\prime},r)=\mathbb{E}^{\pi}[R^{(t)}|S^{(t)}=s,A^{(t)}=a],

(1.10)

\displaystyle p_{(s,a)}

\displaystyle=\rho_{(s,a)}(\cdot\times\mathbb{R})=\mathbb{P}^{\pi}[S^{(t+1)}\in\cdot~|S^{(t)}=s,A^{(t)}=a].

The ordinary Bellman equations are a system of
|\mathcal{S}|
(resp.
|\mathcal{S}\times\mathcal{A}|
) linear equations in the same number of unknowns and read as follows

\displaystyle v^{\pi}_{s}

\displaystyle=\sum_{a\in\mathcal{A}}\pi_{s}(a)\Big[r_{(s,a)}+\gamma\sum_{s^{\prime}\in\mathcal{S}}p_{(s,a)}(s^{\prime})v^{\pi}_{s^{\prime}}\Big],~~s\in\mathcal{S},

(1.11)

\displaystyle q^{\pi}_{(s,a)}

\displaystyle=r_{(s,a)}+\gamma\sum_{s^{\prime}\in\mathcal{S}}p_{(s,a)}(s^{\prime})\sum_{a^{\prime}\in\mathcal{A}}\pi_{s^{\prime}}(a^{\prime})q^{\pi}_{(s^{\prime},a^{\prime})},~~(s,a)\in\mathcal{S}\times\mathcal{A}.

As in the distributional setting, one can use the right-hand side of these equations to define the (ordinary) Bellman operators (
\mathbb{R}^{\mathcal{S}}\rightarrow\mathbb{R}^{\mathcal{S}}
for states) such that (
1.11
) are equivalent to the associated fixed point equation of these operators.

When judging a policy based on expected returns,
\pi
is considered to be at least as good as some other policy
\tilde{\pi}
if
v^{\pi}\geq v^{\tilde{\pi}}
pointwise at each
s
. Classical MDP theory shows that there always exists a policy at least as good as every other policy. Being able to calculate expected returns is not just of interest for evaluating
\pi
, but also to improve it: the policy
\pi^{\prime}
defined by
\pi^{\prime}_{s}=\delta_{\argmax_{a\in\mathcal{A}}q^{\pi}_{(s,a)}}
is at least as good as
\pi
. This leads to an iterative algorithm known as
policy iteration
: starting from an initial policy
\pi^{(0)}
and letting
\pi^{(k+1)}=\big(\pi^{(k)}\big)^{\prime}
it can be shown that
v^{\pi^{(k)}}
converges as
k\rightarrow\infty
to the state value function of an optimal policy.

1.2
Simplified Notations

We introduce simplified notations and define the distributional Bellman operator in this setting. Let
d\in\mathbb{N}
and
(R_{1},J_{1}),\dots,(R_{d},J_{d})
be random pairs such that each
R_{i}
is real-valued and
J_{i}
is discrete taking values in
[d]=\{1,\dots,d\}
. For each
i\in[d]
it is
\mathcal{L}(R_{i},J_{i})\in\mathscr{P}(\mathbb{R}\times[d])
the joint distribution of the random pair
(R_{i},J_{i})
. The random pairs
(R_{1},J_{1}),\dots,(R_{d},J_{d})
together with some constant
\gamma\in(0,1)
define (a version of) the
distributional Bellman operator
as follows:

\mathcal{T}:\mathscr{P}(\mathbb{R})^{d}\longrightarrow\mathscr{P}(\mathbb{R})^{d},~~~\eta=\left(\begin{matrix}\eta_{1}\\
\vdots\\
\eta_{d}\end{matrix}\right)\longmapsto\mathcal{T}(\eta)=\left(\begin{matrix}\mathcal{T}_{1}(\eta)\\
\vdots\\
\mathcal{T}_{d}(\eta)\end{matrix}\right),

the
i
-th coordinate function
\mathcal{T}_{i}:\mathscr{P}(\mathbb{R})^{d}\rightarrow\mathscr{P}(\mathbb{R})
being

\mathcal{T}_{i}(\eta)=\mathcal{T}_{i}(\eta_{1},\dots,\eta_{d})=\mathcal{L}(R_{i}+\gamma G_{J_{i}}),

(1.12)

where on the right hand side
\mathcal{L}(G_{j})=\eta_{j}
for each
j\in[d]
and
G_{1},\dots,G_{d},(R_{i},J_{i})
are independent.

Example 1

(State return)
.

Let
\rho
be a MDP and
\pi
a stationary policy. Let
d=|\mathcal{S}|
and choose an arbitrary enumeration
i=s
to identify
[d]
with
\mathcal{S}
. Let
i=s,j=s^{\prime}
and
B\subseteq\mathbb{R}
measurable. Consider the joint distribution

\displaystyle\mathbb{P}[R_{i}\in B,J_{i}=j]

\displaystyle=\mathbb{P}^{\pi}[R^{(t)}\in B,S^{(t+1)}=s^{\prime}|S^{(t)}=s]

\displaystyle=\sum_{a\in\mathcal{A}}\pi_{s}(a)\rho_{(s,a)}(\{s^{\prime}\}\times B).

In this case
\mathcal{T}
in (
1.12
) is the same as
\mathcal{T}^{\pi}
in (
1.8
).

Example 2

(State-action return)
.

Let
\rho
be a MDP and
\pi
a stationary policy. Let
d=|\mathcal{S}\times\mathcal{A}|
and choose an arbitrary enumeration
i=(s,a)
to identify
[d]
with
\mathcal{S}\times\mathcal{A}
. Let
i=(s,a),j=(s^{\prime},a^{\prime})
and
B\subseteq\mathbb{R}
measurable. Consider the joint distribution

\displaystyle\mathbb{P}[R_{i}\in B,J_{i}=j]

\displaystyle=\mathbb{P}^{\pi}[R^{(t)}\in B,S^{(t+1)}=s^{\prime},A^{(t+1)}=a^{\prime}|S^{(t)}=s,A^{(t)}=a]

\displaystyle=\rho_{(s,a)}(\{s^{\prime}\}\times B)\pi_{s^{\prime}}(a^{\prime}).

In this case the distributions
\mathcal{L}(R_{i},J_{i}),i\in[d]
completely encode both
\rho
and
\pi
and, provided existence, state-action return distributions
(\eta^{\pi}_{(s,a)})_{(s,a)\in\mathcal{S}\times\mathcal{A}}
are fixed points of
\mathcal{T}
.

The connection to distributional RL shows that it is of interest to understand the fixed points of
\mathcal{T}
, that is probability distributions
\eta\in\mathscr{P}(\mathbb{R})^{d}
satisfying

\eta=\mathcal{T}(\eta).

(1.13)

Let
G_{1},\dots,G_{d}
be real-valued random variables with
\eta_{i}=\mathcal{L}(G_{i})
. Then (
1.13
) is equivalent to the distributional Bellman equations, which is a system of
d
one-dimensional distributional equations

G_{i}\overset{d}{=}R_{i}+\gamma G_{J_{i}},~~i\in[d],

(1.14)

where
\overset{d}{=}
(also denoted by
=_{d}
) denotes equality in distribution and in the
i
-th equation
G_{1},\dots,G_{d},(R_{i},J_{i})
are independent,
i\in[d]
. For
i,j\in[d]
let

p_{ij}=\mathbb{P}[J_{i}=j]~~\text{and}~~\mu_{ij}=\mathcal{L}(R_{i}|J_{i}=j),

where in case
p_{ij}=0
we set
\mu_{ij}=\delta_{0}
, the Dirac measure in
0
. It holds
\mathbb{P}[R_{i}\in\cdot,J_{i}=j]=p_{ij}\mu_{ij}(\cdot)
. Let
F_{i}(x)=\mathbb{P}[G_{i}\leq x]
be the cumulative distribution function (cdf) of real-valued random variable
G_{i}
. A third equivalent formulation of the distributional Bellman equations (
1.14
) in terms of cdf’s is

F_{i}(\cdot)=\sum_{j=1}^{d}p_{ij}\int_{-\infty}^{\infty}F_{j}\Big(\frac{\cdot~-~r}{\gamma}\Big)d\mu_{ij}(r),~~i\in[d].

(1.15)

The distributional Bellman equations in terms of cdfs appeared in the literature before, for instance, in
[
17
]
or, in a more specific form, in
[
18
]
.

We study the following aspects regarding solutions to the distributional Bellman equations, i.e., fixed points of
\mathcal{T}
:

•

Existence and uniqueness for which conditions being necessary and sufficient are given in Theorem
2
, see also Remark
3
.

•

Tail probability asymptotics. That is, if
\eta
is a fixed point of
\mathcal{T}
with
i
-th component
\eta_{i}=\mathcal{L}(G_{i})
we study the asymptotic behavior of
\mathbb{P}[G_{i}>x]
and
\mathbb{P}[G_{i}<-x]
as
x\rightarrow\infty
. Depending on properties of the distributions
\mathcal{L}(R_{1},J_{1}),\dots,\mathcal{L}(R_{d},J_{d})
we identify cases of

–

exponential decay and existence of
p
-th moments, see Theorem
3

–

regular variation, see Theorem
4
.

In Section
2.1
we explain how our findings relate to the area of multivariate distributional fixed point equations of the form

\textbf{X}\overset{d}{=}\textbf{A}\textbf{X}+\textbf{B},

(1.16)

in which
\textbf{X},\textbf{B}
are random

a random

In case

. This is a simple special case of a one-dimensional distributional equation

, also called perpetuity equation, for which the existence and uniqueness of solutions as well as their properties have been studied in great detail, see, e.g.,
[

]
,

]

]

Let
\gamma\in(0,1)
and
(R_{1},J_{1}),\dots,(R_{d},J_{d})
be the

-valued random pairs defining the Bellman operator

as in (

(I_{t})_{t\in\mathbb{N}_{0}},~~(R_{ijt})_{(i,j)\in[d]^{2},t\in\mathbb{N}_{0}},

(2.1)

in which

•

(I_{t})_{t\in\mathbb{N}_{0}}
is a
[d]
-valued homogeneous Markov chain having transition probabilities

and a uniform starting distribution, that is for any path

it holds that

\mathbb{P}[I_{0}=i_{0},\dots,I_{T}=i_{T}]=d^{-1}p_{i_{0}i_{1}}p_{i_{1}i_{2}}\cdots p_{i_{T-1}i_{T}},

•

(R_{ijt})_{(i,j)\in[d]^{2},t\in\mathbb{N}_{0}}
forms an array of independent real-valued random variables with

in particular, for each pair
(i,j)
, the sequence

is independent identically distributed (iid) with distribution

•

and

From now on we omit quantification of indices in array-like quantities once the index-ranges have been introduced.

Using RVs (

with

and
G_{1},\dots,G_{d},(R_{ijt})_{ijt},(I_{t})_{t}

To introduce some basic definitions from Markov chain theory let

be states. We write

if there exists

with

Theorem 2
.

The following conditions are equivalent:

(i)

\mathcal{T}
has a (unique) fixed point,

(ii)

\mathbb{E}[\log^{+}|R_{i}|]<\infty
for all essential
i
,

(iii)

The infinite series
G=\sum_{t=0}^{\infty}\gamma^{t}R_{I_{t},I_{t+1},t}
is almost surely (absolutely) convergent,

(iv)

\mathcal{T}^{\circ n}_{i}(\nu)
converges weakly as
n\rightarrow\infty
for each

for some (all)
\nu\in\mathscr{P}(\mathbb{R})^{d}
.

If one and hence all of (i)–(iv) hold, then the unique fixed point
\eta\in\mathscr{P}(\mathbb{R})^{d}
of
\mathcal{T}
has
i
-th component

\eta_{i}=\mathcal{L}(G|I_{0}=i)=\mathcal{L}\Big(\sum\nolimits_{t=0}^{\infty}\gamma^{t}R_{I_{t},I_{t+1},t}~\big|~I_{0}=i\Big).

(2.3)

Remark 2
.

In
[
15
]
a model of iterations of random univariate affine linear maps within a Markovian environment is introduced and its stability is studied. This model is similar to our version of the distributional Bellman operator in (

[

the Markov chain is allowed to have countable state space but required to be ergodic whereas the present Markov chain in the distributional RL setting has finite spate space and no further restrictions. The results in Section 3 of

with similar underlying techniques based on

Note that for a real-valued random variable

Of course, we have

Hence, by Theorem

, a sufficient condition for the existence of a fixed point of

Let

. If for all

then

2.

\mathbb{E}[\exp(\beta|R_{j}|)]<\infty

\mathbb{E}[\exp(\beta|G_{i}|)]<\infty

3.

\mathbb{E}[|R_{j}|^{p}]<\infty
then

The first property transfer is fundamental in MDP theory, while property transfers of the second type are well-established in perpetuity equation theory (cf. Theorem 2.4.1 in
[

). The third is common throughout the Distributional RL literature (cf. Remark

Remark 3
.

For

let

be the

The space

is a complete metric space and so is the product

with

\mathcal{T}_{|\mathscr{P}_{p}(\mathbb{R})^{d}}
of

to

maps to
\mathscr{P}_{p}(\mathbb{R})^{d}
and is a

-contraction with respect to

. Banach’s fixed point theorem yields that the operator

. The latter also follows from our results: if

. Now

Remark 4
.

Theorem
2

Next we focus on asymptotic behavior of tail probabilities
\mathbb{P}[X>x]
and
\mathbb{P}[X<-x]
as

. Each of the three properties stated in Theorem
3
above directly yields asymptotic bounds, in the latter two cases by applying Markov’s inequality:

1.

if

\mathbb{P}[X>x]=\mathbb{P}[X<-x]=0
for all

2.

if
\mathbb{E}[\exp(\beta|X|)]<\infty
for some

\limsup_{x\rightarrow\infty}\frac{\log\mathbb{P}[X>x]}{x}\leq-\beta~~\text{and}~~\limsup_{x\rightarrow\infty}\frac{\log\mathbb{P}[X<-x]}{x}\leq-\beta,

3.

if
\mathbb{E}[|X|^{p}]<\infty
for some

then
\mathbb{P}[X>x],\mathbb{P}[X<-x]
are
\mathrm{O}(x^{-p})
as

With this at hand, in each of the three cases presented in Theorem

\mathbb{P}[G_{i}>x]
and
\mathbb{P}[G_{i}<-x]
as
x\rightarrow\infty
.

Besides the three classical properties discussed so far, a further interesting and important property of (the distribution of) a random variable
X
implying
\mathbb{E}[\log^{+}|X|]<\infty
is that of

. Regularly varying distributions represent a broad and adaptable class of heavy-tailed distributions, containing several important distribution families as specific cases, see Example
3
. As mentioned in the introduction, previous applied works have investigated scenarios that involve heavy-tailed reward distributions. Consequently, understanding in-depth how heavy-tailed reward behavior is reflected in the returns is of interest, a question that Theorem
4
answers in the case of regular variation.

Regular variation is directly defined in terms of the asymptotic behavior of the tail probabilities
\mathbb{P}[X>x]
and
\mathbb{P}[X<-x]
as
x\rightarrow\infty
. First, a function
f:(0,\infty)\rightarrow[0,\infty)
with
f(x)>0
for all
x>x_{0}
is called
regularly varying with index
\beta\in\mathbb{R}
if it is measurable and

\lim_{x\rightarrow\infty}\frac{f(tx)}{f(x)}=t^{\beta}~~~\text{for every}~t>0.

A function
L:(0,\infty)\rightarrow[0,\infty)
is called
slowly varying
if it is regularly varying with index
\beta=0
, so
L(tx)/L(x)\rightarrow 1
for every
t>0
. Every regularly function
f
with index
\beta
is of the form
f(x)=x^{\beta}L(x)
for some slowly varying function
L
, see
[
23
]
.

Following
[
16
]
, a real-valued random variable
X
is called
regularly varying with index
\alpha>0
if

a)

the function
x\mapsto\mathbb{P}[|X|>x]
is regularly varying with index
-\alpha
and

b)

left and right tail probabilities are
asymptotically balanced
: for some
q\in[0,1]

\lim_{x\rightarrow\infty}\frac{\mathbb{P}[X>x]}{\mathbb{P}[|X|>x]}=q~~\text{and}~~\lim_{x\rightarrow\infty}\frac{\mathbb{P}[X<-x]}{\mathbb{P}[|X|>x]}=1-q.

An equivalent definition reads as follows: a real-valued random variable
X
is regularly varying with index
\alpha>0
if and only if there exists a slowly varying function
L
and some
q\in[0,1]
such that

\lim_{x\rightarrow\infty}\frac{\mathbb{P}[X>x]}{x^{-\alpha}L(x)}=q~~\text{and}~~\lim_{x\rightarrow\infty}\frac{\mathbb{P}[X<-x]}{x^{-\alpha}L(x)}=1-q.

(2.4)

In this situation we have
\mathbb{P}[|X|>x]=\mathbb{P}[X>x]+\mathbb{P}[X<-x]\sim x^{-\alpha}L(x)
as
x\rightarrow\infty
, so
\mathbb{P}[|X|>x]
is regularly varying of index
-\alpha
, and the tail probabilities are asymptotically balanced.

Similar to the other three properties, regular variation transfers from rewards to returns in the following sense:

Theorem 4
.

Let
i\in[d]
,
\alpha>0
and
L
a slowly varying function. Suppose for all
j
with
i\rightarrow j
there exist
q_{j}\in[0,1]
and
c_{j}\in[0,\infty)
, with
c_{j}>0
for at least one
j
, such that

\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}>x]}{x^{-\alpha}L(x)}=q_{j}c_{j}~~~\text{and}~~~\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}<-x]}{x^{-\alpha}L(x)}=(1-q_{j})c_{j}.

(2.5)

Then with

w_{ij}=\sum_{t=0}^{\infty}(1-\gamma^{\alpha})\gamma^{\alpha t}\mathbb{P}[I_{t}=j|I_{0}=i],

that is
w_{ij}=\mathbb{P}[I_{N}=j|I_{0}=i]
with
N\sim\geometric(1-\gamma^{\alpha})
independent of
(I_{t})_{t}
, it holds that

\lim_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}>x]}{x^{-\alpha}L(x)}=\frac{\sum_{j=1}^{d}w_{ij}q_{j}c_{j}}{1-\gamma^{\alpha}}~~~\text{and}~~~\lim_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}<-x]}{x^{-\alpha}L(x)}=\frac{\sum_{j=1}^{d}w_{ij}(1-q_{j})c_{j}}{1-\gamma^{\alpha}}.

(2.6)

In particular,
G_{i}
is regularly varying with index
\alpha
.

A regularly varying random variable

\mathbb{P}[R>x]\sim qcx^{-\alpha}
and
{\mathbb{P}[R<-x]\sim(1-q)cx^{-\alpha}}
for some constants

Remark 6

(Application in Distributional Dynamic Programming)
.

The goal in Distributional Dynamic Programming is to perform distributional policy evaluation on a computer. A major problem to solve is that probability distributions
\eta_{s}\in\mathscr{P}(\mathbb{R})
are infinite dimensional objects and hence some form of approximation has to be applied in practice. Several approaches are discussed in Chapter 5 of
[
2
]
. Additional issues arise in cases of Pareto-like tail behaviors with unbounded support as in Example

justifies to model the tails of the state-value distributions a priori as a Pareto-like distribution, the correct choice of asymptotic parameters is given by (

). We plan to report on such issues in future work.

2.1
Connection to multivariate fixed point equations

A prevalent method for examining probabilistic behaviors of systems involves coupling techniques, wherein multiple dependent versions of a system of interest are constructed and their collective behavior is analyzed. In this section, we adapt this approach to our specific context, demonstrating how it allows for the application of results from the well-established theory of multivariate distributional fixed point equations in the study of distributional Bellman equations.

A first key insight is that the operator
\mathcal{T}:\mathscr{P}(\mathbb{R})^{d}\to\mathscr{P}(\mathbb{R})^{d}
, defined in (
1.12
), depends on the random pairs
(R_{1},J_{1}),\dots,(R_{d},J_{d})
only through their marginal laws

\big(\mathcal{L}(R_{1},J_{1}),\dots,\mathcal{L}(R_{d},J_{d})\big)\in\mathscr{P}(\mathbb{R}\times[d])^{d},

(2.7)

recall the definition of
\mathcal{T}=(\mathcal{T}_{1},\dots,\mathcal{T}_{d})
being

\displaystyle\mathcal{T}:\mathscr{P}(\mathbb{R})^{d}\longrightarrow\mathscr{P}(\mathbb{R})^{d},~~~~\mathcal{T}\big(\mathcal{L}(G_{1}),\dots,\mathcal{L}(G_{d})\big)

\displaystyle=\big(\mathcal{L}(R_{1}+\gamma G_{J_{1}}),\dots,\mathcal{L}(R_{d}+\gamma G_{J_{d}})\big),

where in the
i
-th component the random variables
G_{1},\dots,G_{d},(R_{i},J_{i})
are independent. However, the second key insight is that the independence of
G_{1},\dots,G_{d}
is not necessary for the definition: any random vector
(\tilde{G}_{1},\dots,\tilde{G}_{d})
having the same marginal laws as
(G_{1},\dots,G_{d})
and being independent of
(R_{i},J_{i})
satisfies
\mathcal{L}(R_{i}+\gamma\tilde{G}_{J_{i}})=\mathcal{L}(R_{i}+\gamma G_{J_{i}})
.

By a
coupling
of
(R_{1},J_{1}),\dots,(R_{d},J_{d})
we understand any way the random pairs could be defined on a common probability space, thus having a joint distribution

\mathcal{L}\big((R_{1},J_{1}),\dots,(R_{d},J_{d})\big)\in\mathscr{P}((\mathbb{R}\times[d])^{d}).

(2.8)

A coupling (
2.8
) induces an operator
\mathcal{S}
on
\mathscr{P}(\mathbb{R}^{d})
given by

\displaystyle\mathcal{S}:\mathscr{P}(\mathbb{R}^{d})\longrightarrow\mathscr{P}(\mathbb{R}^{d}),~~~\mathcal{S}\big(\mathcal{L}(G_{1},\dots,G_{d})\big)=\mathcal{L}\big(R_{1}+\gamma G_{J_{1}},\dots,R_{d}+\gamma G_{J_{d}}\big),

where on the right hand side
(G_{1},\dots,G_{d})
and
((R_{1},J_{1}),\dots,(R_{d},J_{d}))
are independent. The two key insights mentioned above yield that
\mathcal{S}
and
\mathcal{T}
are related by

\mathcal{S}(\zeta)\circ\mathrm{pr}^{-1}_{i}=\mathcal{T}_{i}(\zeta\circ\mathrm{pr}^{-1}_{1},\dots,\zeta\circ\mathrm{pr}^{-1}_{d}),~~i\in[d],\zeta\in\mathscr{P}(\mathbb{R}^{d}),

(2.9)

with
\mathrm{pr}_{i}:\mathbb{R}^{d}\to\mathbb{R}
being the
i
-th coordinate projection and hence
\zeta\circ\mathrm{pr}_{i}^{-1}\in\mathscr{P}(\mathbb{R})
the
i
-th marginal law of
\zeta\in\mathscr{P}(\mathbb{R}^{d})
. An immediate consequence of (
2.9
) of interest to us is

\displaystyle\mathcal{L}(G_{1},

\displaystyle\dots,G_{d})=\zeta\in\mathscr{P}(\mathbb{R}^{d})~~\text{is a fixed point of $\mathcal{S}$}

\displaystyle\Longrightarrow~~(\mathcal{L}(G_{1}),\dots,\mathcal{L}(G_{d}))=(\zeta\circ\mathrm{pr}_{1}^{-1},\dots,\zeta\circ\mathrm{pr}_{d}^{-1})\in\mathscr{P}(\mathbb{R})^{d}~~\text{is a fixed point of $\mathcal{T}$}.

(2.10)

Corollary
1
below implies the following converse of this implication: if
\mathcal{T}
has a (unique) fixed point
(\mathcal{L}(G_{1}),\dots,\mathcal{L}(G_{d}))
then for
any
coupling (
2.8
) the induced operator
\mathcal{S}
has a unique fixed point which, due to (
2.1
), takes the form of a coupling
\mathcal{L}(G_{1},\dots,G_{d})
of
G_{1},\dots,G_{d}
. This justifies the following approach to study (fixed points of)
\mathcal{T}
:
choose a convenient coupling (
2.8
) and study its induced operator
\mathcal{S}
, in particular the marginal laws of a fixed point of
\mathcal{S}
. We use this approach proving Theorem
4
, where it is most convenient to consider
(R_{1},J_{1}),\dots,(R_{d},J_{d})
to be independent.

One advantage of this coupling approach is that it enables access to numerous results from the field of multivariate fixed point equations, as we explain in the following.

Let
\mathcal{S}
be induced by a coupling (
2.8
). Define the random
d
-dimensional vector

\textbf{R}=(R_{1},\dots,R_{d})^{T}

and the random
d\times d
matrix

\textbf{J}=(\textbf{J}_{ij})_{(i,j)\in[d]\times[d]}~~\text{with}~~\textbf{J}_{ij}=\gamma\cdot 1(J_{i}=j).

The coupling is then completely encoded in the joint distribution
\mathcal{L}(\textbf{J},\textbf{R})\in\mathscr{P}\big(\mathbb{R}^{d\times d}\times\mathbb{R}^{d}\big)
. Moreover, for any random vector
\textbf{G}=(G_{1},\dots,G_{d})^{T}
it holds

\textbf{J}\textbf{G}+\textbf{R}=\big(R_{1}+\gamma G_{J_{1}},\dots,R_{d}+\gamma G_{J_{d}}\big)^{T}

and hence, if
G
is independent of
(\textbf{J},\textbf{R})
, it holds that

\mathcal{S}(\mathcal{L}(\textbf{G}))=\mathcal{L}(\textbf{J}\textbf{G}+\textbf{R})

and
\mathcal{L}(\textbf{G})\in\mathscr{P}(\mathbb{R}^{d})
is a fixed point of
\mathcal{S}
if and only if

\textbf{G}\overset{d}{=}\textbf{J}\textbf{G}+\textbf{R}.

(2.11)

Note that (
2.11
) is a single distributional equation in
\mathbb{R}^{d}
, whereas the distributional Bellman equations, see (
1.14
), are a system of
d
distributional equations in
\mathbb{R}
. Multivariate fixed point equations like (
2.11
) have long been studied for general joint laws
\mathcal{L}(\textbf{J},\textbf{R})\in\mathscr{P}(\mathbb{R}^{d\times d}\times\mathbb{R}^{d})
under various types of assumptions, some of them directly applicable to the situation presented here. A comprehensive overview of the theory of multivariate distributional fixed point equations and its applications, in particular to stochastic difference equations and many important stochastic time-series models, is presented in
[
16
]
.

Theorem
2
can be used to show the following results in which
(\textbf{J}^{(t)},\textbf{R}^{(t)})_{t\in\mathbb{N}_{0}}
are iid copies of
(\textbf{J},\textbf{R})
.

Corollary 1
.

For any operator
\mathcal{S}
induced by a coupling (
2.8
) the following statements are equivalent

(i)

\mathcal{S}
has a (unique) fixed point,

(ii)

\mathcal{S}^{\circ n}(\zeta)
converges weakly as
n\rightarrow\infty
for some (all)
\zeta\in\mathscr{P}(\mathbb{R}^{d})
,

(iii)

The infinite series
\textbf{G}=\sum_{t=0}^{\infty}\Big[\prod_{s=0}^{t-1}\textbf{J}^{(s)}\Big]\textbf{R}^{(t)}
is almost surely (absolutely) convergent,

(iv)

\mathcal{T}
has a (unique) fixed point,

(v)

\mathbb{E}[\log^{+}|R_{i}|]<\infty
for all essential
i
.

If one and hence all of these hold, then the unique fixed point
\zeta\in\mathscr{P}(\mathbb{R}^{d})
of
\mathcal{S}
is given by the law of the infinite vector-valued series
\mathcal{L}(\textbf{G})
in (iii) and the unique fixed point of
\mathcal{T}
is the vector of marginal laws of
\zeta
.

Proposition 1

For

let
S_{n}=\sum_{t=0}^{n-1}\gamma^{t}X_{K_{t},t}
. Then the following are equivalent

(i)

S_{n}
converges in distribution as

(ii)

S_{n}
converges almost surely as
n\rightarrow\infty
.

(iii)

\mathbb{E}[\log^{+}|X_{lt}|]<\infty
for each accessible essential state
l\in[L]

Proof.

Every finite state space Markov chain with probability one finally takes values in one of its irreducible components, hence to show (iii)
\Leftrightarrow
(ii) we can reduce to the case that
(K_{t})_{t}
is irreducible, in particular every state is accessible essential in this case.

(iii)
\Rightarrow
(ii): We assume
\mathbb{E}[\log^{+}|X_{lt}|]<\infty
for all
l
. Let
0<c<\log(1/\gamma)
and
\tilde{c}=\log(1/\gamma)-c>0
. For each

let

A_{t}=\{\gamma^{t}|X_{K_{t},t}|\geq\exp(-ct)\}=\{\log^{+}|X_{K_{t},t}|\geq\tilde{c}t\}.

(3.3)

We show
\sum_{t=0}^{\infty}\mathbb{P}[A_{t}]<\infty
and apply the Borel–Cantelli lemma. Conditioning on
K_{t}=l
and bounding

\displaystyle\sum_{t=0}^{\infty}\mathbb{P}[A_{t}]=\mathbb{P}[A_{0}]+\sum_{t=1}^{\infty}\mathbb{P}\Big[\frac{\log^{+}|X_{K_{t},t}|}{\tilde{c}}\geq t\Big]

\displaystyle\leq\mathbb{P}[A_{0}]+\sum_{l=1}^{L}\sum_{t=1}^{\infty}\mathbb{P}\Big[\frac{\log^{+}|X_{l,t}|}{\tilde{c}}\geq t\Big]

\displaystyle\leq\mathbb{P}[A_{0}]+\sum_{l=1}^{L}\mathbb{E}\Big[\frac{\log^{+}|X_{l,t}|}{\tilde{c}}\Big]<\infty.

The Borel–Cantelli lemma implies that
A_{t}^{c}=\{\gamma^{t}|X_{K_{t},t}|<\exp(-ct)\}
occurs for all but finitely many

almost surely and hence almost surely

, since the tail of the infinite sum is a.s. finally dominated by that of the geometric series

. Hence,
S_{n}
is absolutely convergent and thus convergent almost surely.

(ii)
\Rightarrow

p_{jj^{\prime}}>0
. This yields
\mathbb{P}[|R_{I_{t},I_{t+1},t}|\leq K|I_{0}=i]=1
for every
t
and hence
|G_{i}|\leq\sum_{t}\gamma^{t}|R_{I_{t},I_{t+1},t}|\leq K/(1-\gamma)
almost surely.

2. Due to Theorem
2
we can consider the situation of Proposition
2
via
l=(i,j)
,
X_{lt}=R_{ijt}
and
K_{t}=(I_{t},I_{t+1})
having starting distribution
\mathbb{P}[K_{0}=(i,j)]=p_{ij}
. In this situation a state
l=(i^{\prime},j)
is accessible with respect to
(K_{t})_{t}
if and only if
i\rightarrow i^{\prime}
and
p_{i^{\prime}j}>0
. So
G_{i}
has the same distribution as the almost sure limit
\sum_{t=0}^{\infty}\gamma^{t}X_{K_{t},t}
and one obtains
\mathbb{E}[\exp(\beta|G_{i}|)]<\infty
.

3. We have
\mathbb{E}[|R_{j}|^{p}]=\sum_{j^{\prime}}p_{jj^{\prime}}\mathbb{E}[|R_{jj^{\prime}t}|^{p}]
hence
\mathbb{E}[|R_{j}|^{p}]<\infty
for all
j
with
i\rightarrow j
implies
\mathbb{E}[|R_{jj^{\prime}t}|^{p}]<\infty
for all
(j,j^{\prime})
with
i\rightarrow j
and
p_{jj^{\prime}}>0
. Let
||R_{jj^{\prime}t}||_{p}=\mathbb{E}[|R_{jj^{\prime}t}|^{p}]^{1/p}
and
K=\max_{(j,j^{\prime})}||R_{jj^{\prime}t}||_{p}
where the maximum runs over all relevant pairs
(j,j^{\prime})
, hence
K<\infty
. Let the Markov chain
(I_{t})_{t}
be started in state
I_{0}=i
. Then
G_{i,T}=\sum_{t=0}^{T}\gamma^{t}R_{I_{t},I_{t+1},t}\to G_{i}
almost surely as
T\to\infty
and the process
(I_{t},I_{t+1})_{t}
only visits pairs
(j,j^{\prime})
with
||R_{jj^{\prime}t}||_{p}\leq K<\infty
. Since
||\cdot||_{p}
is a norm, for
T^{\prime}>T

\displaystyle||G_{i,T^{\prime}}-G_{i,T}||_{p}=\Big\|\sum_{t=T+1}^{T^{\prime}}\gamma^{t}R_{I_{t},I_{t+1},t}\Big\|_{p}\leq\sum_{t=T+1}^{T^{\prime}}||\gamma^{t}R_{I_{t},I_{t+1},t}||_{p}\leq K\cdot\sum_{t=T+1}^{T^{\prime}}\gamma^{t}\rightarrow 0~~\text{as}~\min\{T,T^{\prime}\}\to\infty,

hence
(G_{i,T})_{T\in\mathbb{N}}
is a Cauchy sequence with respect to
||\cdot||_{p}
. The associated
L_{p}
-space is complete, hence there is a random variable
\tilde{G}_{i}
in
L_{p}
, that is
||\tilde{G}_{i}||_{p}<\infty
, such that
||G_{i,T}-\tilde{G}_{i}||_{p}\to 0
. This mode of convergence also implies
G_{i,T}\to\tilde{G}_{i}
in probability. The almost sure convergence
G_{i,T}\to G_{i}
implies that
G_{i,T}\to G_{i}
in probability. Limits with respect to convergence in probability are almost surely unique, hence
\tilde{G}_{i}=G_{i}
with probability one and
||G_{i}||_{p}=||\tilde{G}_{i}||_{p}<\infty
.
∎

3.3
Regularly varying tails: Proof of Theorem
4

Our second main theorem is the result about regular variation of fixed points of
\mathcal{T}
, see Theorem
4
. As noted before, our proof makes use of the well-developed theory for multivariate fixed point equations

\textbf{G}\overset{d}{=}\textbf{J}\textbf{G}+\textbf{R},~~~\text{$\textbf{G}$ and $(\textbf{J},\textbf{R})$ independent}.

(3.11)

In particular, a notion of regular variation for
multivariate
distributions, extending the one-dimensional case, has been explored in the context of equations such as (
3.11
) under various assumptions on the joint law
\mathcal{L}(\textbf{J},\textbf{R})\in\mathscr{P}(\mathbb{R}^{d\times d}\times\mathbb{R}^{d})
. Below, we use the coupling approach explained in Section
2.1
to apply some of the available results in proving Theorem
4
.

First we introduce the multivariate notion of regular variation in random vectors and state some facts we use in the proof. We refer the reader to Appendix C in
[
16
]
for more details on the basic properties of multivariate regular variation. Let
\bar{\mathbb{R}}=\mathbb{R}\cup\{-\infty,\infty\}
be the extended real numbers and let
\bar{\mathbb{R}}^{d}_{0}=\bar{\mathbb{R}}^{d}\setminus\{0\}
. A
\mathbb{R}^{d}
-valued random vector
X
is called
regularly varying
if there exists a non-null Radon measure
\mu
on
\bar{\mathbb{R}}^{d}_{0}
, that does not charge infinite points, such that

\lim_{x\rightarrow\infty}\frac{\mathbb{P}\big[x^{-1}\textbf{X}\in C\big]}{\mathbb{P}[|\textbf{X}|>x]}=\mu(C)~~~\text{for every measurable $\mu$-continuity set $C\subseteq\bar{\mathbb{R}}^{d}_{0}$},

(3.12)

note that
|\cdot|
denotes the euclidean norm on
\mathbb{R}^{d}
. The measure
\mu
is called the
limit measure
of regular variation of the random vector
X
. The following are well-known facts about regularly varying random vectors, again we refer to Appendix C in
[
16
]

•

If
\mu
is the limit measure of regular variation of a random vector
X
, then there is a unique
\alpha>0
, called the
index of regular variation
, such that
\mu(tC)=t^{-\alpha}\mu(C)
for every
\mu
-continuity set
C
and
t>0
.

•

If (
3.12
) is satisfied with index of regular variation
\alpha>0
, then the set
C=\{\textbf{x}\in\mathbb{R}^{d}|~|\textbf{x}|>1\}
is a
\mu
-continuity set and hence, because
\{x^{-1}\textbf{X}\in C\}=\{|\textbf{X}|>x\}
, it holds
\mu(C)=1
and

x\mapsto\mathbb{P}[|\textbf{X}|>x]

is a regularly varying function with index
-\alpha
. Further, the set
\{\textbf{x}\in\mathbb{R}^{d}|\textbf{w}^{T}\textbf{x}>1\}
is a
\mu
-continuity set for each
\textbf{w}\in\mathbb{R}^{d}
,

•

X
is regularly varying with index
\alpha>0
if and only if there exists a distribution
\Xi\in\mathscr{P}(\mathbb{S}^{d-1})
on the unit sphere
\mathbb{S}^{d-1}=\{\textbf{x}\in\mathbb{R}^{d}|~|\textbf{x}|=1\}
such that for every
t>0

\frac{\mathbb{P}[|\textbf{X}|>tx,\frac{\textbf{X}}{|\textbf{X}|}\in\cdot~]}{\mathbb{P}[|\textbf{X}|>x]}\overset{w}{\rightarrow}t^{-\alpha}\Xi(\cdot)~~~~\text{as $x\rightarrow\infty$},

(3.13)

where
\overset{w}{\rightarrow}
is weak convergence of finite measures.

The following theorem can be obtained easily as a special case of Theorem 4.4.24 in
[
16
]
, note that the empty product of (random) matrices is the identity matrix.

Theorem 5
.

Let
(R_{1},J_{1}),\dots,(R_{d},J_{d})
be a coupling,
\textbf{R}=(R_{1},\dots,R_{d})^{T}
and
\textbf{J}=(\textbf{J}_{ij})_{ij}
with
\textbf{J}_{ij}=\gamma 1(J_{i}=j)
, see Section
2.1
. Suppose
R
is regularly varying with index
\alpha>0
and limit measure
\mu_{\textbf{R}}
. Then the multivariate distributional fixed point equation (
3.11
) has a unique solution
G
which is regularly varying with index
\alpha
. In particular, with
(\textbf{J}^{(s)})_{s\in\mathbb{N}_{0}}
being iid copies of
J
, it holds

\lim_{x\rightarrow\infty}\frac{\mathbb{P}[x^{-1}\textbf{G}\in C]}{\mathbb{P}[|\textbf{R}|>x]}=\sum_{t=0}^{\infty}\mathbb{E}\Big[\mu_{\textbf{R}}\Big(\Big\{~\textbf{x}\in\mathbb{R}^{d}~\Big|~\Big(\prod\nolimits_{s=0}^{t-1}\textbf{J}^{(s)}\Big)\textbf{x}\in C~\Big\}\Big)\Big]

(3.14)

for every
\mu_{\textbf{R}}
-continuity set
C
and

\mathbb{P}[|\textbf{G}|>x]\sim c\cdot\mathbb{P}[|\textbf{R}|>x]~\text{as}~x\to\infty,

(3.15)

where
c>0
equals the right hand side of (
3.14
) evaluated at
C=\{\textbf{x}\in\mathbb{R}^{d}~|~|\textbf{x}|>1\}
.

Proof.

Since
C=\{\textbf{x}\in\mathbb{R}^{d}~|~|\textbf{x}|>1\}
is a
\mu
-continuity set that satisfies
\mathbb{P}[|\textbf{G}|>x]=\mathbb{P}[x^{-1}|\textbf{G}|\in C]
the asymptotic expression (
3.15
) follows from (
3.14
). The remaining part of the theorem is a direct consequence of Theorem 4.4.24 from
[
16
]
by noticing that the additional necessary assumptions stated in that theorem,
\mathbb{E}[|\textbf{J}|^{\alpha}]<1
and
\mathbb{E}[|\textbf{J}|^{\alpha+\delta}]<\infty
for some
\alpha>0
and
\delta>0
, are satisfied in our situation of interest as
\textbf{J}_{ij}=\gamma 1(J_{i}=j)
and hence
|\textbf{J}|=\gamma<1
.
∎

In Theorem
5
an arbitrary coupling
(R_{1},J_{1}),\dots,(R_{d},J_{d})
is considered and the (multivariate) regular variation of
\textbf{R}=(R_{1},\dots,R_{d})^{T}
, which is an assumption there, transfers over to the (multivariate) regular variation of
\textbf{G}=(G_{1},\dots,G_{d})^{T}
, whose marginal laws are the solutions to the distributional Bellman equations of interest in Theorem
4
. Moreover, multivariate regular variation of
G
can be used to show univariate regular variation of
G_{1},\dots,G_{d}
by testing (
3.12
) on sets of the form
C=\{\textbf{x}\in\mathbb{R}^{d}~|~\pm\textbf{e}_{j}^{T}\textbf{x}>1\}
with
\textbf{e}_{j}\in\mathbb{R}^{d}
being unit vectors. Note that Theorem
4
concerns solutions of the distributional Bellman operator
\mathcal{T}
. Hence, the result of that theorem only depends on the marginal laws
(\mathcal{L}(R_{1},J_{1}),\dots,\mathcal{L}(R_{d},J_{d}))
and hence Theorem
5
, which assumes presence of a coupling satisfying certain properties, is
not
directly applicable there. But, as explained in Section
2.1
, results about coupled situations can become useful by choosing a convenient coupling
\mathcal{L}((R_{1},J_{1}),\dots,(R_{d},J_{d}))
that makes certain arguments work out. In the following proof this will be the case when an independence coupling is considered: independence of
R_{1},\dots,R_{d}
together with the assumptions of Theorem
4
implies that the random vector
\textbf{R}=(R_{1},\dots,R_{d})^{T}
is regularly varying in the multivariate sense, so Theorem
5
becomes applicable. We now present technical details:

Proof of Theorem
4
.

Let
(R_{1},J_{1}),\dots,(R_{d},J_{d})
be independent. Let
\textbf{e}_{j}\in\mathbb{R}^{d}
be the
j
-th unit vector and

\textbf{R}=(R_{1},\dots,R_{d})^{T}=\sum_{j=1}^{d}R_{j}\cdot\textbf{e}_{j},

that is we express
R
as a sum of independent random vectors. In the following, we rely on well-established results from the theory of (multivariate) regular variation which show that regular variation is transferred to sums of
independent
random variables (vectors) each having this property.

First, we determine the asymptotic behavior of
\mathbb{P}[|\textbf{R}|>x]
as
x\to\infty
: let
i\in[d]
be fixed. Only those pairs
(R_{j},J_{j})
with
i\rightarrow j
are relevant for the distribution of
G_{i}
, hence we assume w.l.o.g. that
i\rightarrow j
holds for all
j
, that is for every
j\in[d]
there exists constants
q_{j}\in[0,1]
and
c_{j}\in[0,\infty)
such that

\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}>x]}{x^{-\alpha}L(x)}=q_{j}c_{j}~~~\text{and}~~~\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}<-x]}{x^{-\alpha}L(x)}=(1-q_{j})c_{j},

(3.16)

where
\alpha>0
and
L
is a slowly varying function. This implies for every
j

c_{j}=\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[|R_{j}|>x]}{x^{-\alpha}L(x)}=\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}^{2}>x^{2}]}{x^{-\alpha}L(x)}=\lim\limits_{y\rightarrow\infty}\frac{\mathbb{P}[R_{j}^{2}>y]}{y^{-\alpha/2}\tilde{L}(y)}~~~\text{with}~~~\tilde{L}(y)=L(\sqrt{y}).

The function
\tilde{L}
is slowly varying which shows that
R_{j}^{2}
is regularly varying with index
\alpha/2
in case
c_{j}>0
and
\mathbb{P}[R_{j}^{2}>x]=o(x^{-\alpha/2})
as
x\to\infty
in case
c_{j}=0
. In such a situation, and since
R_{1}^{2},\dots,R^{2}_{d}
are independent by choice of coupling, standard results from the theory of regular variation apply, see Section 1.3.1 in
[
29
]
, and show

\displaystyle\mathbb{P}[R_{1}^{2}+\dots+R_{d}^{2}>y]

\displaystyle\sim\mathbb{P}[R_{1}^{2}>y]+\dots+\mathbb{P}[R_{d}^{2}>y]~~\text{as}~y\to\infty

and hence, by re-substituting
x^{2}
for
y
,

\displaystyle\mathbb{P}[R_{1}^{2}+\dots+R_{d}^{2}>x^{2}]

\displaystyle\sim\mathbb{P}[R_{1}^{2}>x^{2}]+\dots+\mathbb{P}[R_{d}^{2}>x^{2}]\sim(c_{1}+\dots+c_{d})x^{-\alpha}L(x)~~\text{as}~x\to\infty,

that is

\lim_{x\to\infty}\frac{\mathbb{P}[|\textbf{R}|>x]}{x^{-\alpha}L(x)}=c_{1}+\dots+c_{d}.

(3.17)

Next, we give an argument to show that
R
is regularly varying with index
\alpha
(in the multivariate sense): let
\sgn(R_{j})\in\{-1,1\}
be the sign of
R_{j}
, so that
|R_{j}\textbf{e}_{j}|=|R_{j}|
and
\frac{R_{j}\textbf{e}_{j}}{|R_{j}\textbf{e}_{j}|}=\sgn(R_{j})\textbf{e}_{j}
in case
R_{j}\neq 0
. If
c_{j}>0
then
R_{j}\textbf{e}_{j}
is regularly varying at index
\alpha>0
in the multivariate sense, the spectral measure
\Xi_{j}\in\mathscr{P}(\mathbb{S}^{d-1})
is given by

\Xi_{j}=q_{j}\delta_{\textbf{e}_{j}}+(1-q_{j})\delta_{-\textbf{e}_{j}}=\lim_{x\rightarrow\infty}\mathbb{P}[\sgn(R_{j})\textbf{e}_{j}\in\cdot~||R_{j}|>x].

Applying standard arguments, see Lemma C.3.1 in
[
16
]
, it is easily seen that
\textbf{R}=\sum_{j=1}^{d}R_{j}\textbf{e}_{j}
(a sum of independent random vectors) is regularly varying at index
\alpha
. Let
\mu_{\textbf{R}}
be the associated measure. We are now able to apply Theorem
5
to the solution
\textbf{G}=(G_{1},\dots,G_{d})^{T}
of the distributional equation (
3.11
).

First, we evaluate the limit measure
\mu_{\textbf{R}}
at some sets of interest: Combining (
3.16
) and (
3.17
) yields for every
j\in[d]

\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~|~\textbf{e}_{j}^{T}\textbf{x}>1\big\}\Big)=\lim_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}>x]}{\mathbb{P}[|\textbf{R}|>x]}=\frac{q_{j}c_{j}}{c_{1}+\dots+c_{d}}.

(3.18)

As in Theorem
5
, let
(\textbf{J}^{(s)})_{s\in\mathbb{N}_{0}}
be a sequence of iid copies of
J
. For every
t\in\mathbb{N}_{0}
the entry of the random matrix
\prod_{s=0}^{t-1}\textbf{J}^{(s)}
at position
(i,j)\in[d]^{2}
equals
\gamma^{t}\cdot 1(I_{it}=j)
, where
(I_{it})_{i\in[d],t\in\mathbb{N}_{0}}
are
[d]
-valued random variables such that for every
i\in[d]
the sequence
(I_{it})_{t}
has the same law as
(I_{t})_{t}
under
\mathbb{P}[~\cdot~|I_{0}=i]
.

By Theorem
5
for every
i\in[d]
it holds that

\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}>x]}{\mathbb{P}[|\textbf{R}|>x]}=\sum_{t=0}^{\infty}\mathbb{E}\Big[\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~\big|~\textbf{e}_{i}^{T}\Big(\prod\nolimits_{s=0}^{t-1}\textbf{J}^{(s)}\Big)\textbf{x}>1\big\}\Big)\Big].

(3.19)

Using
\mu_{\textbf{R}}(tC)=t^{-\alpha}\mu_{\textbf{R}}(C)
for every
t\in\mathbb{N}_{0}
it holds

\displaystyle\mathbb{E}\Big[\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~\big|~\textbf{e}_{i}^{T}\Big(\prod\nolimits_{s=0}^{t-1}\textbf{J}^{(s)}\Big)\textbf{x}>1\big\}\Big)\Big]

\displaystyle=\mathbb{E}\Big[\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~\big|~\gamma^{t}\textbf{e}_{I_{it}}^{T}\textbf{x}>1\big\}\Big)\Big]

\displaystyle=\gamma^{\alpha t}\sum_{j\in[d]}\mathbb{P}[I_{t}=j|I_{0}=i]\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~|~\textbf{e}_{j}^{T}\textbf{x}>1\big\}\Big)

\displaystyle=\gamma^{\alpha t}\sum_{j\in[d]}\mathbb{P}[I_{t}=j|I_{0}=i]\frac{q_{j}c_{j}}{c_{1}+\dots+c_{d}}

and hence

\displaystyle\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}>x]}{\mathbb{P}[|\textbf{R}|>x]}

\displaystyle=\sum_{t=0}^{\infty}\gamma^{\alpha t}\sum_{j\in[d]}\mathbb{P}[I_{t}=j|I_{0}=i]\frac{q_{j}c_{j}}{c_{1}+\dots+c_{d}}

\displaystyle=\frac{1}{1-\gamma^{\alpha}}\sum_{j\in[d]}\mathbb{P}[I_{N}=j|I_{0}=i]\frac{q_{j}c_{j}}{c_{1}+\dots+c_{d}},

where
N\sim\geometric(\gamma^{\alpha})
is independent of
(I_{t})_{t}
. With
w_{ij}=\mathbb{P}[I_{N}=j|I_{0}=i]
and (
3.17
) we have

\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}>x]}{x^{-\alpha}L(x)}=\frac{\sum_{j\in[d]}w_{ij}q_{j}c_{j}}{1-\gamma^{\alpha}}.

(3.20)

The tail asymptotic of
\frac{\mathbb{P}[G_{i}<-x]}{x^{-\alpha}L\left(x\right)}
can be calculated the same way using

\mu_{\textbf{R}}\Big(\big\{\textbf{x}\in\mathbb{R}^{d}~|~\textbf{e}_{j}^{T}\textbf{x}<-1\big\}\Big)=\lim_{x\rightarrow\infty}\frac{\mathbb{P}[R_{j}<-x]}{\mathbb{P}[|\textbf{R}|>x]}=\frac{(1-q_{j})c_{j}}{c_{1}+\dots+c_{d}}.

(3.21)

To see that
G_{i}
is regularly varying with index
\alpha
note that
\mathbb{P}[|G_{i}|>x]=\mathbb{P}[G_{i}>x]+\mathbb{P}[G_{i}<-x]\sim(\sum_{j=1}^{d}w_{ij}c_{j})x^{-\alpha}L(x)
is a regularly varying function of index
\alpha
and the balance equation hold:

\displaystyle\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}>x]}{\mathbb{P}[|G_{i}|>x]}

\displaystyle=\frac{\sum_{j=1}^{d}q_{j}w_{ij}c_{j}}{\sum_{j=1}^{d}w_{ij}c_{j}}~~\text{and}

\displaystyle\lim\limits_{x\rightarrow\infty}\frac{\mathbb{P}[G_{i}<-x]}{\mathbb{P}[|G_{i}|>x]}

\displaystyle=\frac{\sum_{j=1}^{d}(1-q_{j})w_{ij}c_{j}}{\sum_{j=1}^{d}w_{ij}c_{j}}=1-\frac{\sum_{j=1}^{d}q_{j}w_{ij}c_{j}}{\sum_{j=1}^{d}w_{ij}c_{j}}.

∎
