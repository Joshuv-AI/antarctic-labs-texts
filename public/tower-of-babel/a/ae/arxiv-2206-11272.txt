easyFermi : a graphical interface for performing Fermi -LAT data analyses Journal: Astronomy and Computing
Raniere de Menezes 1,2

Abstract
Since its launch in 2008, the Fermi Large Area Telescope (LAT) allowed us to peek into the extremely energetic side of the Universe with unprecedented sensitivity and resolution. The tools available for analyzing Fermi -LAT data are the Fermitools and Fermipy , both of which can be scripted in Python and run via command lines in a terminal or in web-based interactive computing platforms. In this work, we are providing the community with easyFermi , an open-source user-friendly graphical interface for performing basic to intermediate analyses of Fermi -LAT data in the framework of Fermipy . With easyFermi , the user can quickly measure the γ \gamma -ray flux and photon index, build spectral energy distributions, light curves, test statistic maps, test for extended emission and even relocalize the coordinates of γ \gamma -ray sources. The tutorials for easyFermi are available on YouTube and GitHub, allowing the user to learn how to use Fermi -LAT data in about 10 min.

3
Behind the scenes

The graphical interface and data analysis provided by
easyFermi
strongly depend on the
Python
packages
PyQt5
and
Fermipy
, although requiring minimum maintenance. Once the user sets the desired configurations and start the process,
easyFermi
automatically organizes all these information with
PyQt5
and communicates them to
Fermipy
, thereafter starting a binned likelihood analysis. This process generates several data subproducts, as a list of selected events, a counts cube, an exposure map, a livetime cube, and a source map
11
11

11

More details on these data subproducts here:
https://fermi.gsfc.nasa.gov/ssc/data/analysis/scitools/binned_likelihood_tutorial.html
.

Before fitting the model to the data in the region of interest (ROI), we first optimize the ROI model with the
Fermipy
function
optimize()
to ensure that all parameters are close to their global likelihood maxima, and then look for uncataloged sources with the function
find_sources()
(this one can be disabled by the user). The model is then fitted to the data using the minimizer
MINUIT
and the main results for the target are saved in the file “Target_results.txt”. For the full set of results including all sources in the ROI, the user can access the files “Results.fits” or “Results.npy”.

3.1
Current spectral models

In
easyFermi
we use the spectral models from the
Fermi
-LAT third and fourth source catalogs
[
3
,
2
, 3FGL and 4FGL, respectively;]
, namely i) the power-law model, defined by

\frac{dN}{dE}=N_{0}\left(\frac{E}{E_{0}}\right)^{\gamma},

where
N_{0}
is the normalization (in units of cm
-2
s
-1
MeV
-1
),
E
is the photon energy,
E_{0}
is the pivot energy, and
\gamma
is the photon index; ii) the log-parabolic model
[
9
]
defined by

\frac{dN}{dE}=N_{0}\left(\frac{E}{E_{0}}\right)^{-\alpha-\beta\log(E/E_{0})},

where
\alpha
and
\beta
are indexes describing the hardness and curvature of the spectrum; and iii) the power-law with a super exponential cutoff

\frac{dN}{dE}=N_{0}\left(\frac{E}{E_{0}}\right)^{\gamma}\exp(-aE^{b}),

where
a
and
b
are the exponential factor and index describing the shape of the spectral cutoff. If the target is listed in one of the
Fermi
-LAT catalogs,
easyFermi
automatically uses the cataloged spectral model in the analysis, otherwise a new source with a power-law spectrum is added to the ROI model. The user can always change the spectral model for the target under the checkbox “Change model”. Depending on the feedback by the users of
easyFermi
, we can add more spectral models in the next software releases.

3.2
Automatic configuration

For those using the
Standard
mode of
easyFermi
, the following set of configurations apply.

1.

The ROI is defined as an
L\times L
square with size depending on the adopted starting energy (
E_{min}
), i.e.
L=15^{\circ},12^{\circ}
or
10^{\circ}
for
E_{min}<500
MeV, 500 MeV
\leq E_{min}<1000
MeV and
E_{min}\geq 1000
MeV, respectively.

2.

For the same energy ranges defined in the previous item, we set the maximum zenith angle to
z_{max}=90^{\circ},100^{\circ}
or
105^{\circ}
.

3.

The classification and point spread function type for each event are filtered with
evclass

=128
and
evtype

=3
, while the adopted instrument response function is
P8R3_SOURCE_V3
and the dataset is divided in 8 bins per energy decade.

4.

The radius from the ROI center in which the parameters of the sources are allowed to vary during the fit is defined as
R_{free}=L/2
, where
L
is the size of the ROI.

The experienced user can change all of these configurations by passing a customized configuration file to
easyFermi
under the selection of the “custom” button and by modifying the entries in the “Advanced configurations” box (see Figure
1
).

3.3
Recovering the state of the analysis

A very useful characteristic of
easyFermi
is that it allows the user to recover the latest state of the analysis, such that the user can quit
easyFermi
and continue the exact same analysis some time later. Once the analysis is done, the state of the graphical interface is automatically saved in the file “GUI_status.npy” in the output directory, and can easily be recovered by clicking on “Load GUI state” in the “Menu” button of the toolbar.

4.1
Goodness of fit

The detection, flux determination and spectral modeling of
Fermi
-LAT sources with
easyFermi
is accomplished by means of a binned likelihood optimization technique
[
1
]
, using
MINUIT
as the minimizer. The multi-dimensional minimization of parameters, however, is not an easy task and is susceptible to fail. To be sure that the fit properly converged, the user can follow the information in the
Log
box in the graphical interface (see Figure
1
), where the following information is displayed depending on the success of the fit:

1.

Fit quality: 3. Excellent fit. Full accurate covariance matrix.

2.

Fit quality: 2. Reasonable fit. Full matrix, but forced positive-definite (i.e. not accurate).

3.

Fit quality: 1. Poor fit. Diagonal approximation only, not accurate.

4.

Fit quality: 0. Bad fit. Error matrix not calculated.

For any fit quality value other than 3, we recommend the user to rerun the analysis changing the configurations in the panel
Free source radius
, in the “Advanced configurations” box. In this panel, the user can select the radius (from the ROI center) defining the circular region in which the parameters of the
\gamma
-ray sources are left free to vary, can fix the spectral shape of the target or of all sources in the ROI, and can freeze the Galactic and Isotropic diffuse emission models. For a step-by-step guide on the quality/goodness of fit, the user is invited to follow the tutorial on YouTube
12
12

12

https://www.youtube.com/channel/UCeLCfEoWasUKky6CPNN_opQ
.

5
Validation, performance, and maintenance

The results obtained with
easyFermi
are exactly the same as those obtained with
Fermipy
, since
easyFermi
is actually running
Fermipy
in the background. We tested this by performing several analyses (e.g., the light curves, SEDs and TS maps for ROIs centered on PG1551+113, 3C 273, 3C279, Omega Centauri, and the extended lobes of Centaurus A) with
easyFermi
and comparing the results with pure
Fermipy
analyses. In terms of performance, an analysis done with
easyFermi
takes basically as much CPU time and RAM as an analysis done directly with
Fermipy
on the terminal, however,
easyFermi
is slightly faster and uses less RAM than an analysis performed with
Fermipy
in web-based interactive computing platforms. To test if
easyFermi
is properly working, we recommend the user to follow the tutorial on GitHub/YouTube
13
13

13

https://github.com/ranieremenezes/easyFermi
. Furthermore, the user can check if both
Fermipy
and
easyFermi
are working smoothly by simply typing

$ python

>> from fermipy.gtanalysis import GTAnalysis

>> import easyFermi

If both modules are successfully imported, the installation is fine.

The maintenance of
easyFermi
will be done such that the users can ask for the repair of possible issues via GitHub and in a way that we guarantee its compatibility with the upcoming releases of the
Fermitools
and
Fermipy
.

6
Conclusions

The
easyFermi
graphical interface is a user-friendly tool that allows astronomers from all niches to use
Fermi
-LAT
\gamma
-ray data. This tool is especially indicated for those scientists just starting in the field of high-energy astrophysics, and can be used for several goals like building a light curve, computing a
\gamma
-ray spectrum, or looking for extended
\gamma
-ray emission. Furthermore,
easyFermi
is meant to be simple. For more complex types of analyses, we refer the user to
Fermipy
and
Fermitools
.

The tutorials and source code for
easyFermi
can be found online
14
14

14

https://github.com/ranieremenezes/easyFermi
and allow the user to learn how to use
Fermi
-LAT data in just a few minutes. Bug reports and proposals for new functionality should be made through the GitHub issue tracker. Although minimum maintenance is required, we aim to keep
easyFermi
updated and in synergy with
Fermipy
, hence new versions of the tool can be released in the future. We also plan to make a similar graphical interface for the Cherenkov Telescope Array
[
7
]
and possibly for other Imaging Atmospheric Cherenkov Telescopes in the near future.
