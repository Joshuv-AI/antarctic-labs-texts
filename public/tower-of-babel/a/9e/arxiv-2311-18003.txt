Subsystem CSS codes, a tighter stabilizer-to-CSS mapping, and Goursat’s Lemma
Michael Liaofan Liu, Nathanan Tantivasadakarn, Victor V. Albert

Abstract
The CSS code construction is a powerful framework used to express features of a quantum code in terms of a pair of underlying classical codes. Its subsystem extension allows for similar expressions, but the general case has not been fully explored. Extending previous work of Aly et. al. [ quant-ph/0610153 ], we determine subsystem CSS code parameters, express codewords, and develop a Steane-type decoder using only data from the two underlying classical codes. We show that any subsystem stabilizer code can be “doubled” to yield a subsystem CSS code with twice the number of physical, logical, and gauge qudits and up to twice the code distance. This mapping preserves locality and is tighter than the Majorana-based mapping of Bravyi, Leemhuis, and Terhal [ New J. Phys. 12 083039 (2010) ]. Using Goursat’s Lemma, we show that every subsystem stabilizer code can be constructed from two nested subsystem CSS codes satisfying certain constraints, and we characterize subsystem stabilizer codes based on the nested codes’ properties.



I
Introduction and summary of results

An extensive theory of quantum error-correcting codes has been developed to protect quantum computers from noise
Knill and Laflamme 1997
;
Aharonov and Ben-Or 2008
;
Shor 1995

. Qualitatively, a quantum error-correcting code describes how to “hide” quantum information within a protected subsystem of a quantum system, such that noise within the quantum system can be detected and removed from the protected subsystem. The class of quantum error-correcting codes called
stabilizer codes

Gottesman 1997
;
Calderbank et al. 1997

remains the most promising route to a working and robust quantum computer, in part due to extra structure that is useful for promptly detecting and correcting errors.

We are interested in the special class of
subsystem stabilizer codes

Poulin 2005
;
Klappenecker and Sarvepalli 2006

, which correspond to the nontrivial normal subgroups of a Pauli group.
While subsystem stabilizer codes can be derived from subspace stabilizer codes by using only a subset of the original logical qudits to store quantum information, such codes can exhibit advantageous and/or inherently different properties from subspace stabilizer codes such as lower weights of check operators
Bravyi et al. 2012
, new fault-tolerant protocols
Anderson et al. 2014
, the association with more general types of anyon theories in two dimensions
Ellison et al. 2023a
, as well as single-shot error correction in three dimensions
Bombín 2015
;
Kubica and Vasmer 2022a
.
The extra data used to define subsystem stabilizer codes yields a richer code structure, warranting its own investigation.

A large part of our work studies
subsystem CSS codes

Aly et al. 2006
;
Aly and Andreas 2008

, where the corresponding normal subgroup admits a generating set consisting of
X
-type and
Z
-type Pauli operators.
Subsystem CSS codes generalize subspace CSS codes
Calderbank and Shor 1996
;
Steane 1996a
;
Steane 1996b

, of which there are many useful examples
Kitaev 2003
;
Bombin and Martin-Delgado 2006
, recently culminating in the first asymptotically good quantum low-density parity-check codes
Freedman and Hastings 2021
;
Portnoy 2023
;
Dinur et al. 2023
. Subspace CSS codes have rich connections to classical coding theory
Calderbank et al. 1998
;
Hivadi 2018
;
Steane 1999
and homology theory
Bravyi and Hastings 2014
;
Bombin and Martin-Delgado 2007
;
Breuckmann 2018
, and they admit a recovery procedure that utilizes classical linear codes to independently correct
X
-type and
Z
-type Pauli errors
Calderbank and Shor 1996
;
Nielsen and Chuang 2010
. Thus, it is interesting to investigate the generalization of subspace CSS codes to the subsystem setting. Indeed, many subsystem stabilizer codes are CSS
Bacon 2006
;
Bacon and Casaccino 2006
;
Chamberland et al. 2020
, so a general theory of subsystem CSS codes would apply to a broad class of examples developed to date.

To study subsystem CSS codes, we adopt a linear-algebraic perspective that streamlines previous proofs and distills the essential mathematical ideas
Haah 2013
.
This places subsystem CSS codes on the same footing as subspace CSS codes, allowing us to generalize many important features of subspace CSS codes to the subsystem setting.

Our main tool is the symplectic representation, which allows us to view a subsystem stabilizer code as a subspace of a vector space by considering Pauli groups modulo phase factors. In this representation, the structure and parameters of a subsystem stabilizer code are encoded in a “tower” of subspaces, which can then be manipulated using tools from linear algebra
Tignol and Amitsur 1986
;
Meng and Guo 2022
;
Anderson and Camillo 2009
to yield several general results.

Our results include a mapping from subsystem stabilizer codes to subsystem CSS codes, a fleshing out of the connection between subsystem CSS codes and classical coding theory, a general recovery procedure for subsystem CSS codes, and a characterization of subsystem stabilizer codes based on Goursat’s Lemma from group theory.

In Section
II
, we review the theory of Pauli groups and subsystem stabilizer codes, and we explain how to translate these objects to the linear algebraic framework.

In Section
III
, we review the subspace CSS construction and its generalization to the subsystem case.
While the subspace CSS construction utilizes two classical linear codes
Huffman et al. 2021

under certain constraints, the subsystem CSS construction utilizes two classical linear codes with no constraints.
We express the logical and gauge codewords in terms of the two underlying classical linear codes.

In Section
IV
, we show that the performance of subsystem CSS codes is comparable to that of subsystem stabilizer codes. More precisely, we show that every modular-qudit subsystem stabilizer code
can be “doubled” to yield a subsystem CSS code with twice the number of physical, logical, and gauge qudits and up to twice the code distance.

In Section
V
, we present an error-correction procedure for subsystem CSS codes that generalizes the well-known Steane procedure for subspace CSS codes (see, e.g.,
Calderbank and Shor 1996
;
Nielsen and Chuang 2010
;
Gottesman 2010
).
While specific instances of this procedure have been presented previously
Bravyi and Cross 2015
;
Gayatri and Sarvepalli 2018
;
Kubica and Vasmer 2022b
;
Brown et al. 2016
;
Bravyi et al. 2013
;
Higgott and Breuckmann 2021
;
Andrist et al. 2012
, we are unaware of a presentation of the general case that uses only information from the underlying classical linear codes.
Our error-correction procedure for subsystem CSS codes decodes up to arbitrary actions on the gauge qudits, and the corresponding classical step in our error-correction procedure decodes up to prescribed “redundant” subcodes obtained from the underlying classical codes.
We explore an alternative decoder that generalizes the recovery procedure for the Bacon–Shor code
Bacon 2006
in Appendix
C
.

In Section
VI
, we show that every subsystem stabilizer code can be constructed from two subsystem CSS codes satisfying certain constraints, much as every subsystem CSS code can be constructed from two classical codes.
We investigate the structure of a given subsystem stabilizer code in terms of its two underlying subsystem CSS codes, and we define two code families that can be viewed as generalizations of subsystem CSS codes from this perspective (see Fig.
2
).

Finally, we provide concluding remarks in Section
VII
. Most proofs have been deferred to Appendix
A
for readability.

II
Preliminaries

In Section
II.1
, we review the construction of Pauli groups. In Section
II.2
, we explain how to interpret Pauli groups as vector spaces, and we review the related theory of bilinear forms on vector spaces. In Section
II.3
, we review the construction of subsystem stabilizer codes. Finally, in Section
II.4
, we explain how to interpret subsystem stabilizer codes as subspaces of vector spaces, and we define the properties of subsystem stabilizer codes in the vector space setting.

II.1
Pauli groups

Consider a quantum system with
n
prime qudits, each of dimension
p
. The Hilbert space of this system is given by the quantization of
G\coloneqq\mathbb{F}_{p}^{n}
, i.e.,

\mathbb{H}\coloneqq\left\langle\{\left|g\right\rangle\mid g\in G\}\right\rangle\cong{\left(\mathbb{C}^{p}\right)}^{\otimes n}.

(1)

Acting on this space is a special class of linear operators called
Pauli operators
, denoted by
X^{a},Z^{b}
for any
a,b\in G
. For any basis vector
\left|g\right\rangle\in\mathbb{H}
, the Pauli operators act as

\displaystyle X^{a}\left|g\right\rangle

\displaystyle\coloneqq\left|a+g\right\rangle\text{ and}

(2)

\displaystyle Z^{b}\left|g\right\rangle

\displaystyle\coloneqq e^{\frac{2\pi i}{p}b\cdot g}\left|g\right\rangle,

(3)

where
\cdot
is the usual dot product on
G
. One verifies the relations

\displaystyle X^{a}Z^{b}X^{c}Z^{d}

\displaystyle=e^{\frac{2\pi i}{p}b\cdot c}X^{a+c}Z^{b+d}\text{ and}

(4)

\displaystyle X^{a}Z^{b}X^{c}Z^{d}

\displaystyle=e^{\frac{2\pi i}{p}(b\cdot c-a\cdot d)}X^{c}Z^{d}X^{a}Z^{b}

(5)

among the Pauli operators. We define the
weight
of a Pauli operator to be the number of qudits on which it acts nontrivially. The Pauli operators generate the
Pauli group
, which is given explicitly by

\displaystyle\mathcal{P}

\displaystyle\coloneqq\left\langle\left\{X^{a},Z^{b}\,\middle|\,a,b\in G\right\}\right\rangle

(6)

\displaystyle=\left\{e^{\frac{2\pi i}{p}\kappa}X^{a}Z^{b}\,\middle|\,\kappa\in\mathbb{F}_{p},a,b\in G\right\}.

We remark that in other works, the phase factors included in the Pauli group may differ depending on whether
p
is odd or even
Miller 2019
;
Ellison et al. 2023a
;
Dauphinais et al. 2023
. This will not matter much for our work, since we will henceforth consider Pauli groups modulo phase factors.

II.2
Pauli groups as vector spaces

In light of Eqs. (
4
) and (
6
), one sees that the Pauli group modulo phases is essentially equivalent to the vector space
G\times G
. Formally, letting

\Phi\coloneqq\left\{e^{\frac{2\pi i}{p}\kappa}\,\middle|\,\kappa\in\mathbb{F}_{p}\right\}

(7)

denote the collection of phases in the Pauli group, one verifies that the map

\displaystyle\mathcal{P}/\Phi

\displaystyle\to G\times G

(8)

\displaystyle\Phi X^{a}Z^{b}

\displaystyle\mapsto(a,b)

is a vector space isomorphism. For most of this work, it will be convenient to view the Pauli group modulo phases as the vector space
G\times G
. We review the necessary theory below
Haah 2013
;
Tignol and Amitsur 1986
.

A function
\xi:G\times G\to\mathbb{F}_{p}
is called
bilinear
if

\displaystyle\xi(a+\lambda\,b,c)

\displaystyle=\xi(a,c)+\lambda\,\xi(b,c)\text{ and}

(9)

\displaystyle\xi(a,b+\lambda\,c)

\displaystyle=\xi(a,b)+\lambda\,\xi(a,c),

symmetric
if

\xi(a,b)=\xi(b,a),

(10)

antisymmetric
if

\xi(a,b)=-\xi(b,a),

(11)

and
nondegenerate
if

\xi(a,G)=0\implies a=0.

(12)

We call
\xi
a
form
if it is bilinear and nondegenerate. Henceforth,
\xi
will denote a symmetric or antisymmetric form,
\theta
will denote a symmetric form, and
\omega
will denote an antisymmetric form. Every subspace
H\leq G
has a
complement with respect to

\xi

H^{\xi}\coloneqq\left\{a\in G\,\middle|\,\xi(a,H)=0\right\}\leq G.

(13)

One verifies that

\displaystyle\dim H+\dim H^{\xi}

\displaystyle=\dim G\text{ and}

(14)

\displaystyle\left(H^{\xi}\right)^{\xi}

\displaystyle=H.

(15)

Moreover, if
K\leq G
is another subspace, then

\displaystyle(H+K)^{\xi}

\displaystyle=H^{\xi}\cap K^{\xi}\text{ and}

(16)

\displaystyle(H\cap K)^{\xi}

\displaystyle=H^{\xi}+K^{\xi}.

(17)

A symmetric form
\theta
on
G
passes naturally to a symmetric form

((a,b),(c,d))\mapsto\theta(a,c)+\theta(b,d)

(18)

on
G\times G
, which by abuse of notation we also call
\theta
(note that for the Pauli group,
\theta
is the dot product). In addition, the original symmetric form
\theta
on
G
induces the antisymmetric form

\omega((a,b),(c,d))\coloneqq\theta(b,c)-\theta(a,d)

(19)

on
G\times G
(note that for the Pauli group,
\omega
encodes the commutation of the Pauli operators as in Eq. (
5
)). Direct products behave well with respect to these induced forms. Indeed, if
H_{X}\times H_{Z}\leq G\times G
, then

\displaystyle\left(H_{X}\times H_{Z}\right)^{\theta}

\displaystyle=H_{X}^{\theta}\times H_{Z}^{\theta}\text{ and}

(20)

\displaystyle\left(H_{X}\times H_{Z}\right)^{\omega}

\displaystyle=H_{Z}^{\theta}\times H_{X}^{\theta}.

(21)

For any
a=(a_{1},\ldots,a_{n}),b=(b_{1},\ldots,b_{n})\in G
, we call

\wt(a)\coloneqq\left|\left\{j\in\left\{1,\ldots,n\right\}\mid a_{j}\neq 0\right\}\right|

(22)

the
weight
of
a
, and we call

\swt(a,b)\coloneqq\left|\left\{j\in\left\{1,\ldots,n\right\}\mid\left(a_{j},b_{j}\right)\neq(0,0)\right\}\right|

(23)

the
symplectic weight
of
(a,b)
. For any nontrivial
S\subseteq G
and
T\subseteq G\times G
, we write

\displaystyle\min\wt(S)

\displaystyle\coloneqq\underset{a\in S\setminus\{0\}}{\min}\wt(a)\text{ and}

(24)

\displaystyle\min\swt(T)

\displaystyle\coloneqq\underset{(a,b)\in T\setminus\{0\}}{\min}\swt(a,b).

(25)

Note that the weight of a Pauli operator
X^{a}Z^{b}
is equal to the symplectic weight of the corresponding vector
(a,b)
.

Finally, for any algebraic objects
G,H
, we write

G
H
l

(26)

to indicate that
H\leq G
and, if
G,H
are vector spaces, that
\dim G/H=l
.

II.3
Subsystem stabilizer codes

A subsystem stabilizer code can be interpreted as a subspace stabilizer code with some of its logical qudits relegated to gauge qudits.
This necessitates the use of a “gauge group” to determine the gauge qudits.

In the usual formalism for subsystem stabilizer codes
Poulin 2005
;
Dauphinais et al. 2023
, one begins with an abelian “stabilizer group”
\mathcal{S}\leq\mathcal{P}
whose intersection with
\Phi
is trivial. Then, one considers the centralizer of
\mathcal{S}
, denoted
\mathcal{C}(\mathcal{S})
, which is the subgroup of all Pauli operators that commute with everything in
\mathcal{S}
. Finally, one selects a “gauge group”
\mathcal{G}\leq\mathcal{C}(\mathcal{S})
whose center is
\left\langle\Phi,\mathcal{S}\right\rangle
. These relationships can be summarized in the tower of normal subgroups

\mathcal{P}
\mathcal{C}(\mathcal{S})
\mathcal{G}
\left\langle\Phi,\mathcal{S}\right\rangle
\Phi

(27)

which encodes the parameters of the subsystem stabilizer code. Indeed, the number of logical (resp. gauge) qudits in
\mathcal{G}
is given by half the size of any minimal generating set for
\mathcal{C}(\mathcal{S})/\mathcal{G}
(resp.
\mathcal{G}/{\left\langle\Phi,\mathcal{S}\right\rangle}
). Moreover, the distance of
\mathcal{G}
is defined to be the minimum weight of a Pauli operator in
\mathcal{C}(\mathcal{S})\setminus\mathcal{G}
.

Observe that every tower as in Eq. (
27
) determines a gauge group
\Phi\leq\mathcal{G}\leq\mathcal{P}
. Conversely, every gauge group
\Phi\leq\mathcal{G}\leq\mathcal{P}
determines a tower as in Eq. (
27
). Thus, in the usual formalism, a
subsystem stabilizer code
is defined to be a subgroup
\Phi\leq\mathcal{G}\leq\mathcal{P}
. Moreover, one calls
\mathcal{G}
a
subsystem CSS code
if
\mathcal{G}
admits a generating set that consists only of
X
-type or
Z
-type Pauli operators.

Any subsystem stabilizer code
\mathcal{G}
generates a von Neumann algebra
\Alg\mathcal{G}
of linear operators on the physical Hilbert space
\mathbb{H}
. This algebra induces an orthogonal decomposition of
\mathbb{H}
as
Poulin 2005
;
Dauphinais et al. 2023
;
Harlow 2017

\mathbb{H}\cong\underset{\tau\mathcal{C}(\mathcal{S})\in\mathcal{P}/\mathcal{C}(\mathcal{S})}{\bigoplus}\tau(\mathbb{L}\otimes\mathbb{G}),

(28)

where
\mathbb{L}\otimes\mathbb{G}
is the subspace of
\mathbb{H}
fixed by the stabilizer group
\mathcal{S}
. With respect to this decomposition, the algebra
\Alg\mathcal{G}
takes the form

\Alg\mathcal{G}\cong\underset{\tau\mathcal{C}(\mathcal{S})\in\mathcal{P}/\mathcal{C}(\mathcal{S})}{\bigoplus}\tau{\left(\mathbbm{1}_{\mathbb{L}}\otimes\End(\mathbb{G})\right)}\tau^{-1},

(29)

where
\End(\mathbb{G})
denotes the collection of linear operators on
\mathbb{G}
. We call
\mathcal{G}
a
subspace stabilizer code
if the gauge space
\mathbb{G}
is one-dimensional.

27
) modulo phase factors, since this allows us to apply tools from linear algebra to analyze subsystem stabilizer codes. To begin, recall that

In this section, we show that every subsystem stabilizer code can be used to construct a subsystem CSS code with comparable parameters. Our construction is simple to express in the notation of Sections

V
Recovery procedure for subsystem CSS codes

Having shown that subsystem CSS codes achieve performance comparable to that of subsystem stabilizer codes, we now study subsystem CSS codes in greater detail. In this section, we present a recovery procedure to correct an unknown Pauli error affecting the physical Hilbert space of a subsystem CSS code. Our recovery procedure generalizes the usual Steane-type decoder for subspace stabilizer codes
Calderbank and Shor 1996
;
Nielsen and Chuang 2010
;
Gottesman 2010
to the subsystem setting.

To begin, let
H=H_{X}\times H_{Z}\leq G\times G
be a subsystem CSS code. Let
\mathbb{L}\otimes\mathbb{G}\leq\mathbb{H}
be the codespace of
H
, i.e., the fixed space of the stabilizer group of
H
. Suppose that a code state

\left|\psi\right\rangle=\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}\right\rangle\in\mathbb{L}\otimes\mathbb{G}

(68)

is corrupted by a Pauli error
X^{a}Z^{b}\in\mathcal{P}
, where
(a,b)\in G\times G
. Our recovery procedure identifies the error
(a,b)
up to some unknown gauge term in
H_{X}\times H_{Z}
.

The first step in our recovery procedure is purely quantum: in Section
V.1
, we use gauge generator measurements to determine the syndrome of the Pauli error. The second step in our recovery procedure is purely classical: in Section
V.2
, we use two classical linear codes to identify the Pauli error up to gauge terms. Our discussion focuses on correcting the
X
-component of the error; correcting the
Z
-component is similar.

V.1
Quantum step: syndrome measurement

We determine the syndrome of the Pauli error by measuring gauge generators. Usually, the syndrome of a Pauli error is defined to be its commutation with each of the stabilizer generators. In the linear algebraic framework, the syndrome of a Pauli error is defined (for subsystem CSS codes) as follows.

Definition 2
.

Let
H=H_{X}\times H_{Z}\leq G\times G
be a subsystem CSS code. Let
(a,b)\in G\times G
. Let

\displaystyle\Syn_{X}:G

\displaystyle\to G/{\left(H_{X}+H_{Z}^{\theta}\right)}

(69)

\displaystyle a

\displaystyle\mapsto a+\left(H_{X}+H_{Z}^{\theta}\right)

and

\displaystyle\Syn_{Z}:G

\displaystyle\to G/{\left(H_{Z}+H_{X}^{\theta}\right)}

(70)

\displaystyle b

\displaystyle\mapsto b+\left(H_{Z}+H_{X}^{\theta}\right)

be the canonical projections. We call
\Syn_{X}(a)
the
syndrome
of
a
and similarly for
b
.

For intuition, note that the space
H_{X}+H_{Z}^{\theta}
is precisely the space of all
X
-type logical operators, i.e., the space of all
X
-type Pauli operators that commute with all the
Z
-type stabilizers in
H_{Z}\cap H_{X}^{\theta}
. Thus, the syndrome of an
X
-type error
a
is precisely the set of all
X
-type Pauli operators with the same
Z
-type stabilizer commutations as
a
.

Now, our goal is to use gauge generator measurements to determine the syndrome of
a
. To begin, fix bases for the spaces

\begin{array}[]{cc}H_{X}=\left\langle h_{X}\right\rangle&H_{Z}=\left\langle h_{Z}\right\rangle\\
H_{X}\cap H_{Z}^{\theta}=\left\langle{s_{X}}\right\rangle&H_{Z}\cap H_{X}^{\theta}=\left\langle{s_{Z}}\right\rangle\end{array}.

(71)

Observe that for each basis vector
{s_{Z}}
in
H_{Z}\cap H_{X}^{\theta}
, we have

{s_{Z}}=\sum_{h_{Z}}c_{h_{Z}}h_{Z}

(72)

for some
c_{h_{Z}}\in\mathbb{F}
, so

Z^{{s_{Z}}}=\prod_{h_{Z}}\left(Z^{h_{Z}}\right)^{c_{h_{Z}}}.

(73)

That is, every
Z
-type stabilizer generator
Z^{{s_{Z}}}
can be written as a product of
Z
-type gauge generators
Z^{h_{Z}}
. Now, the stabilizer generators
X^{{s_{X}}}
,
Z^{{s_{Z}}}
and the
Z
-type gauge generators
Z^{h_{Z}}
all commute, so there exists an orthonormal basis
\left\{\left|e_{i}\right\rangle\right\}_{i}
for
\mathbb{H}
in which the
X^{{s_{X}}}
,
Z^{{s_{Z}}}
, and
Z^{h_{Z}}
are all diagonal. Write the corrupted state in this basis, i.e.,

X^{a}Z^{b}\left|\psi\right\rangle=\sum_{i}\psi_{i}\left|e_{i}\right\rangle,

(74)

where the
\psi_{i}\in\mathbb{C}\setminus 0
. Since
\left|\psi\right\rangle\in\mathbb{L}\otimes\mathbb{G}
, by applying
Z^{{s_{Z}}}
to both sides above, we find that

Z^{{s_{Z}}}\left|e_{i}\right\rangle=e^{\frac{2\pi i}{p}\theta({s_{Z}},a)}\left|e_{i}\right\rangle

(75)

for each
\left|e_{i}\right\rangle
in Eq. (
74
). Similarly, applying
X^{{s_{X}}}
to both sides in Eq. (
74
), we find that

X^{{s_{X}}}\left|e_{i}\right\rangle=e^{-\frac{2\pi i}{p}\theta({s_{X}},b)}\left|e_{i}\right\rangle

(76)

for each
\left|e_{i}\right\rangle
in Eq. (
74
). Now, since the
\left|e_{i}\right\rangle
are also eigenstates of the
Z^{h_{Z}}
, measuring any
Z^{h_{Z}}
projects the corrupted state
X^{a}Z^{b}\left|\psi\right\rangle
onto a subspace spanned by some subset of the
\left|e_{i}\right\rangle
in Eq. (
74
). Thus, by Eq. (
73
), if we measure each gauge generator
Z^{h_{Z}}
and multiply each corresponding measurement outcome
c_{h_{Z}}
times, we obtain the value
e^{\frac{2\pi i}{p}\theta({s_{Z}},a)}
, from which we can determine
\theta({s_{Z}},a)
. Repeating this for each
{s_{Z}}
, we can determine the image of
a
under the linear map
a\mapsto\sum_{{s_{Z}}}\theta({s_{Z}},a){s_{Z}}
on
G
. Since this map has kernel
{\left(H_{Z}\cap H_{X}^{\theta}\right)}^{\theta}=H_{X}+H_{Z}^{\theta}
, we can determine
a+\left(H_{X}+H_{Z}^{\theta}\right)=\Syn_{X}(a)
, as desired.

We claim that this procedure does not disturb the logical component of the corrupted state. To see this, recall that the gauge generators
Z^{h_{Z}}
are of the form

Z^{h_{Z}}\cong\underset{\tau}{\bigoplus}\,{\tau\left(\mathbbm{1}_{\mathbb{L}}\otimes U_{\mathbb{G}}^{\tau}\right)\tau^{-1}}

(77)

for some unitaries
U_{\mathbb{G}}^{\tau}\in\End(\mathbb{G})
. Since any projection onto an eigenspace of
Z^{h_{Z}}
can be written as a polynomial in
Z^{h_{Z}}
, any measurement of
Z^{h_{Z}}
effects a projection of the form

P\cong\underset{\tau}{\bigoplus}\,{\tau\left(\mathbbm{1}_{\mathbb{L}}\otimes P_{\mathbb{G}}^{\tau}\right)\tau^{-1}}

(78)

on
X^{a}Z^{b}{\left(\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}\right\rangle\right)}
, where the
P_{\mathbb{G}}^{\tau}\in\End({\mathbb{G}})
are some projections. Thus, after measuring the
Z^{h_{Z}}
, the corrupted state is of the form
X^{a}Z^{b}{\left(\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime}\right\rangle\right)}
for some gauge state
\left|\psi_{\mathbb{G}}^{\prime}\right\rangle\in\mathbb{G}
.

Finally, since the state
\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime}\right\rangle
still belongs to the codespace
\mathbb{L}\otimes\mathbb{G}
, one can apply an analogous procedure to determine
\Syn_{Z}(b)
by measuring the
X
-type gauge generators
X^{h_{X}}
, and after this procedure, the state of the system is
X^{a}Z^{b}{\left(\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime\prime}\right\rangle\right)}
for some
\left|\psi_{\mathbb{G}}^{\prime\prime}\right\rangle\in\mathbb{G}
. This concludes the first step in our recover procedure.

We remark that our syndrome measurement procedure uses homogeneous scheduling of gauge generator measurements. That is, in our procedure, all
Z
-type gauge generators are measured, and subsequently all
X
-type gauge generators are measured. However, other measurement schedules might be relevant for fault-tolerant implementations of our recovery procedure; this is related to the notion of “gauge fixing”
Higgott and Breuckmann 2021
;
Solanki and Sarvepalli 2023
. Indeed, the special case of our recovery procedure for subspace CSS codes (i.e., the Steane recovery procedure) is fault-tolerant
Gottesman 2010
. Future work could investigate potential fault-tolerant implementations of our generalized recovery procedure for subsystem CSS codes.

V.2
Classical step: error recovery

In the first step of our recovery procedure, we determined the syndrome
\Syn_{X}(a)
of the error
a
. That is, we determined the image of
a
under the map

\displaystyle\Syn_{X}:G\to G/{\left(H_{X}+H_{Z}^{\theta}\right)}.

(79)

In the second step of our recovery procedure, we use
\Syn_{X}
as the parity check of the classical linear code
H_{X}+H_{Z}^{\theta}
to identify the error
a
up to gauge terms in
H_{X}
. To begin, we introduce a general notion of a classical linear code capable of identifying an error up to some prescribed “redundant” subcode.

Definition 3
.

Let
N
be a vector space over
\mathbb{F}_{p}
. A
classical linear code
is a subspace
K\leq N
. A
parity check
for
K
is a linear map
F:N\to M
such that
\ker F=K
. A
redundant subcode
for
K
is a subspace
R\leq K
. We say that
K
has
logical dimension

k\coloneqq\dim K
and
physical dimension

n\coloneqq\dim N
. The
distance of
K
with respect to
R
is

d^{R}\coloneqq\min\wt(K\setminus R).

(80)

To summarize these parameters, we call
K
an
\left[n,k,d^{R}\right]
code.

Now, suppose that we only wish to identify an error
a\in N
up to some redundant subcode
R
. That is, suppose that we only wish to recover the coset
a+R
from the syndrome
Fa
of the error. As shown in the following proposition, this is possible when
a+R
contains some vector of sufficiently small weight relative to the code distance
d^{R}
.

Proposition 3
.

Let
K
be a classical linear code with parity check
F:N\to M
and redundant subcode
R
. Let
a\in N
be unknown, but suppose that
Fa
is known. Suppose that
\min\wt(a+R)<\frac{d^{R}}{2}
. Then we can determine
a+R
, i.e., we can determine
a+k
for some unknown redundant vector
k\in R
.

Proof.

See Appendix
A.3
.
∎

The special case of Proposition
3
with trivial redundant subcode is well known
Huffman et al. 2021
. We state it as a corollary below for a sanity check.

Corollary 1
.

Let
K
be a classical linear code with parity check
F:N\to M
. Let
a\in N
be unknown, but suppose that
Fa
is known. Suppose that
\wt(a)<\frac{\min\wt K}{2}
. Then we can determine
a
.

Let us return to the second step of our recovery procedure. Suppose that
H=H_{X}\times H_{Z}
is an
\left[\left[n,k,r,d\right]\right]
subsystem CSS code. Write
k_{X}\coloneqq\dim{\left(H_{X}+H_{Z}^{\theta}\right)}
and
k_{Z}\coloneqq\dim{\left(H_{Z}+H_{X}^{\theta}\right)}
(note that
k_{X}+k_{Z}=n+k+r
by Proposition
1
). Let
d^{H_{X}},d^{H_{Z}}
be as in Proposition
2
. One verifies from the definitions that
H_{X}+H_{Z}^{\theta}
with parity check
\Syn_{X}
and redundant subcode
H_{X}
is an
[n,k_{X},d^{H_{X}}]
classical linear code, and
H_{Z}+H_{X}^{\theta}
with parity check
\Syn_{Z}
and redundant subcode
H_{Z}
is an
[n,k_{Z},d^{H_{Z}}]
classical linear code.

Now, suppose that the error
a
satisfies
\min\wt(a+H_{X})<\frac{d^{H_{X}}}{2}
. Then by Proposition
3
, we can recover the error class
a+H_{X}
from the syndrome
\Syn_{X}(a)
, which was previously determined. To correct the
X
-type error, we can pick any
a+h_{X}\in a+H_{X}
and apply
{\left(X^{a+h_{X}}\right)}^{-1}
to the corrupted code state
X^{a}Z^{b}{\left(\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime\prime}\right\rangle\right)}
, which yields the state
Z^{b}{\left(\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime\prime\prime}\right\rangle\right)}
. Assuming that the error
b
satisfies
\min\wt(b+H_{Z})<\frac{d^{H_{Z}}}{2}
, we can apply a similar procedure to correct the
Z
-type error and restore the state
\left|\psi_{\mathbb{L}}\right\rangle\otimes\left|\psi_{\mathbb{G}}^{\prime\prime\prime\prime}\right\rangle
. This concludes the second step in our recovery procedure.

We remark that the second step in our recovery procedure performs as well as can be expected, given that the distance of the parent subsystem CSS code is
d=\min\{d^{H_{X}},d^{H_{Z}}\}
(as shown in Proposition
2
). Indeed, if the original Pauli error
X^{a}Z^{b}
satisfies
\swt(a,b)<\frac{d}{2}
, which is the usual correctability condition for subsystem stabilizer codes, then
a
and
b
satisfy
\wt(a)<\frac{d^{H_{X}}}{2}
and
\wt(b)<\frac{d^{H_{Z}}}{2}
, so by the above discussion, the second step in our recovery procedure succeeds.

One might note that the second step in our recovery procedure identifies a little more than just the coset
a+H_{X}
. In fact, as indicated in the proof of Proposition
3
, our recovery procedure always identifies a representative
a+h_{X}
of
a+H_{X}
with weight less than
\frac{d^{H_{X}}}{2}
(provided that such a representative exists). One might ask whether a weaker recovery procedure exists, which only recovers the coset
a+H_{X}
and nothing else. We explore this idea further in Appendix
C
.

VI
Structure of subsystem stabilizer codes

After a detailed study of subsystem CSS codes, we now turn our attention to the structure of general subsystem stabilizer codes. Our main observation is that every subsystem stabilizer code is associated with two subsystem CSS codes and an isomorphism that determine the structure of the subsystem stabilizer code. In Section
VI.1
, we formalize this observation using Goursat’s Lemma. Then, in Section
VI.2
, we investigate the structure of subsystem stabilizer codes by associating two subsystem CSS codes to each subsystem stabilizer code in Eq. (
33
), just as we associated two classical linear codes to each subsystem CSS code in Eq. (
37
). Finally, in Section
VI.3
, we apply this theory to introduce two generalizations of subsystem CSS codes.

VI.1
Goursat data of the gauge group

We can quantify the degree of “non-CSS-ness” of any subsystem stabilizer code
H\leq G\times G
by sandwiching it between two subsystem CSS codes,

N\leq H\leq E,

(81)

where the
internal CSS code

N
is the largest subsystem CSS code
contained in
H
, and the
external CSS code

E
is the
smallest subsystem CSS code containing
H
.

The internal CSS code consists of all elements in the gauge group that are purely

X
-type or purely
Z
-type, i.e., all
X^{a}
and
Z^{b}
where
X^{a},Z^{b}\in\mathcal{G}
. In particular, the internal CSS code equals
H
iff
H
is itself a subsystem CSS code, and the internal CSS code is trivial iff
H
has no pure
X
or pure
Z
elements.

The external CSS code is constructed by independently peeling off the
X
- and
Z
-components of each element in the gauge group. That is, the external CSS code contains all
X^{a}
and
Z^{b}
such that
X^{a}Z^{b}\in\mathcal{G}
. In particular, the external CSS code equals
H
iff
H
is itself a subsystem CSS code, and the external CSS code always contains
H
.

If
H
is not a subsystem CSS code, the inclusions

N<H<E

(82)

are strict. In particular, the internal code is a strict subspace of
the external code, since there are elements of
E
that cannot be
obtained by taking products of the pure gauge group elements
in
N
. The relative size of the internal and external codes corresponds to the number of non-CSS elements in the gauge group. This claim is made precise using Goursat’s Lemma.

Goursat’s Lemma associates a gauge group with a set of
Goursat
data
— the internal code
N=N_{X}\times N_{Z}
, the external code
E=E_{X}\times E_{Z}
, and an isomorphism
\phi:E_{X}/N_{X}\to E_{Z}/N_{Z}
that associates the
X
- and
Z
-components of each gauge group element
(e_{X},e_{Z})\in H
up to pure
X,Z
elements:

e_{X}+N_{X}\mathrel{{\mathop{\rightleftharpoons}\limits}}e_{Z}+N_{Z}.

(83)

In other words, for each gauge group element
(e_{X},e_{Z})
, the isomorphism
\phi
associates the non-pure component of
e_{X}
with the non-pure component of its partner
e_{Z}
.
The number of such independent pairs quantifies the “non-CSS-ness” of the code: if
E_{X}/N_{X}
has one element, then
H
is CSS, but if
E_{X}/N_{X}
is large, then
H
is highly “non-CSS”. This is all stated formally below.

Lemma 2

(Goursat’s Lemma)
.

Let
G
be a vector space.

(1)

Let
H\leq G\times G
. Define

\displaystyle{E_{X}}

\displaystyle\coloneqq\{{e_{X}}\in G\mid\exists{e_{Z}}\in G,({e_{X}},{e_{Z}})\in H\},

(84a)

\displaystyle{E_{Z}}

\displaystyle\coloneqq\{{e_{Z}}\in G\mid\exists{e_{X}}\in G,({e_{X}},{e_{Z}})\in H\},

(84b)

\displaystyle{N_{X}}

\displaystyle\coloneqq\{{n_{X}}\in G\mid({n_{X}},0)\in H\},\text{ and}

(84c)

\displaystyle{N_{Z}}

\displaystyle\coloneqq\{{n_{Z}}\in G\mid(0,{n_{Z}})\in H\}.

(84d)

For each
{e_{X}}\in{E_{X}}
, define

\phi({e_{X}}+{N_{X}})\coloneqq{e_{Z}}+{N_{Z}},

(85)

where
({e_{X}},{e_{Z}})\in H
. Then

\begin{array}[]{c}G\times G\\
|\\
{E_{X}}\times{E_{Z}}\\
|\\
{N_{X}}\times{N_{Z}}\\
\end{array}

(86)

and

{E_{X}}/{N_{X}}\overset{\phi}{\xrightarrow{\sim}}{E_{Z}}/{N_{Z}}.

(87)

(2)

Conversely, let

\begin{array}[]{c}G\times G\\
|\\
{E_{X}}\times{E_{Z}}\\
|\\
{N_{X}}\times{N_{Z}}\\
\end{array}

(88)

and

{E_{X}}/{N_{X}}\overset{\phi}{\xrightarrow{\sim}}{E_{Z}}/{N_{Z}}.

(89)

Define

\displaystyle H\coloneqq\{({e_{X}},{e_{Z}})\in{E_{X}}

\displaystyle\times{E_{Z}}\,|

(90)

\displaystyle\phi({e_{X}}+{N_{X}})

\displaystyle={e_{Z}}+{N_{Z}}\}.

Then
H\leq G\times G
.

(3)

The constructions in
(1)
and
(2)
are inverses.

Proof.

This is
(
Meng and Guo 2022
, Theorem 3)
. See also
(
Anderson and Camillo 2009
, Theorem 4)
.
∎

We emphasize that item
(3)
above states that the correspondence between
H
and its Goursat data is bijective. Thus, we can write

\begin{array}[]{ccccc}&&G\times G&&\\
G\times G&&|&&\\
|&\longleftrightarrow&{E_{X}}\times{E_{Z}}&,&\phi\\
H&&|&&\\
&&{N_{X}}\times{N_{Z}}&&\end{array}

(91)

to indicate that the subsystem stabilizer code on the left-hand side corresponds via Lemma
2
to the Goursat data on the right-hand side.

Goursat’s Lemma implicitly states that the subsystem stabilizer code
H
consists of “blocks” (i.e., cosets) of
N_{X}\times N_{Z}
inside
E_{X}\times E_{Z}
. The isomorphism
\phi
essentially pairs pure
X
elements
e_{X}
with pure
Z
elements
e_{Z}
to obtain the representatives
(e_{X},e_{Z})
of these cosets comprising
H
. We illustrate this in Fig.
1
and state it formally below.

Proposition 4
.

Suppose that Eq. (
91
) holds. Fix a basis

\left\{{e_{X}^{j}}+{N_{X}}\right\}_{j}

(92)

for
{E_{X}}/{N_{X}}
, and consider the basis

\left\{\phi\left({e_{X}^{j}}+{N_{X}}\right)\eqqcolon{e_{Z}^{j}}+{N_{Z}}\right\}_{j}

(93)

for
{E_{Z}}/{N_{Z}}
. Then

\displaystyle H=\Bigg\{\Bigg(

\displaystyle\sum_{j}c_{j}{e_{X}^{j}}+{n_{X}},\sum_{j}c_{j}{e_{Z}^{j}}+{n_{Z}}\Bigg)\in{E_{X}}\times{E_{Z}}\,\Bigg|\,

(94)

\displaystyle c_{j}\in\mathbb{F}_{p},{n_{X}}\in{N_{X}},{n_{Z}}\in{N_{Z}}\Bigg\}.

Moreover,
H
is a subsystem CSS code iff
{E_{X}}={N_{X}}
, which occurs iff
{E_{Z}}={N_{Z}}
.

Proof.

See Appendix
A.4
.
∎

As indicated in Eq. (

), the isomorphism
\phi
specifies which
X
-type operators
{e_{X}^{j}}
and

-type operators
{e_{Z}^{j}}
are “paired together” to form generators of

. We illustrate this in the following example.

Example 4

(5-qubit code)
.

The five-qubit code
Laflamme et al. 1996

\mathcal{G}=\langle\mathcal{S},\Phi\rangle
.

Inspecting the stabilizer generators of this code in Eq. (

), we see that there are no elements of the gauge group that are purely
X
-type or
Z
-type. Thus, the internal code
N_{X}\times N_{Z}

On the other hand, the external code
E_{X}\times E_{Z}
is generated by splitting the gauge group into its
X
-part and
Z
-part. That is, with a slight abuse of notation, we have

\displaystyle{E_{X}}

\displaystyle=\langle IXXII,IIXXI,IIIXX,XIIIX\rangle\text{ and}

(95)

\displaystyle{E_{Z}}

\displaystyle=\langle ZIIZI,IZIIZ,ZIZII,IZIZI\rangle.

(96)

\phi
is constructed from combinations of
{e_{X}}\in{E_{X}}

{e_{X}}{e_{Z}}\in\mathcal{G}
. Thus, again with a slight abuse of notation, the action of

\displaystyle IXXII

\displaystyle\mapsto ZIIZI,

\displaystyle IIXXI

\displaystyle\mapsto IZIIZ,

(97)

\displaystyle IIIXX

\displaystyle\mapsto ZIZII,

\displaystyle XIIIX

\displaystyle\mapsto IZIZI.

(98)

\displaystyle{E_{X}}

\displaystyle=\langle XXIII,IXXII,IIXXI,IIIXX\rangle\text{ and}

(99)

\displaystyle{E_{Z}}

\displaystyle=\langle ZZIII,IZZII,IIZZI,IIIZZ\rangle.

(100)

The external code can be gauged fixed to obtain the
[[5,1,0,3]]

and

are dressed logicals.

The Goursat data of a subsystem stabilizer code
H
can be expressed explicitly in terms of its generators. This is useful for explicitly computing the Goursat data of subsystem stabilizer codes.

Proposition 5
.

Suppose that

\dim G\times l

\begin{array}[]{ccccc}&&G\times G&&\\

&&\pi_{X}{\left(\ker\pi_{Z}\right)}\times\pi_{Z}{\left(\ker\pi_{X}\right)}&&\end{array}

for some isomorphism

. Moreover,

.

) provides an alternative characterization of subsystem CSS codes that can be readily checked given the generators of

. Indeed, to check whether a given subsystem stabilizer code is a subsystem CSS code, one can compute spanning sets for
\ker\pi_{X}
and
\ker\pi_{Z}
, take their union to form a spanning set for
\ker\pi_{X}+\ker\pi_{Z}

.

VI.2
Goursat data of the stabilizer group

The stabilizer group
H\cap H^{\omega}
of a subsystem stabilizer code
H
can be described in terms of the Goursat data of
H
. More broadly, our goal in this section is to determine the Goursat data of each subsystem stabilizer code in Eq. (
33
) in terms of the Goursat data of
H
, just as we determined the classical linear codes comprising each subsystem CSS code in Eq. (
37
) in terms of the classical linear codes comprising
H
.

We first derive the Goursat data of the gauge-preserving group
H^{\omega}
in terms of that of
H
.

Proposition 6
.

Suppose that

\begin{array}[]{ccccc}&&G\times G&&\\
G\times G&&|&&\\
|&\longleftrightarrow&{E_{X}}\times{E_{Z}}&,&\phi\\
H&&|&&\\
&&{N_{X}}\times{N_{Z}}&&\end{array}.

(106)

Then there exist isomorphisms
\phi_{X},\phi_{Z}
in the diagram

{N_{Z}^{\theta}}/{E_{Z}^{\theta}}\overset{\phi_{Z}}{\xrightarrow{\sim}}{E_{Z}}/{N_{Z}}\overset{\phi^{-1}}{\xrightarrow{\sim}}{E_{X}}/{N_{X}}\overset{\phi_{X}}{\xleftarrow{\sim}}{N_{X}^{\theta}}/{E_{X}^{\theta}},

(107)

such that with

\phi^{\omega}\coloneqq\phi_{X}^{-1}\phi^{-1}\phi_{Z},

(108)

we have

\begin{array}[]{ccccc}&&G\times G&&\\
G\times G&&|&&\\
|&\longleftrightarrow&N_{Z}^{\theta}\times N_{X}^{\theta}&,&\phi^{\omega}\\
H^{\omega}&&|&&\\
&&E_{Z}^{\theta}\times E_{X}^{\theta}&&\end{array}

(109)

Proof.

See Appendix
A.6
.
∎

Intuitively, this proposition states that if a subsystem stabilizer code
H
corresponds to the subsystem CSS codes
N\leq H\leq E
, then the complement
H^{\omega}
corresponds to the subsystem CSS codes
E^{\omega}\leq H^{\omega}\leq N^{\omega}
(c.f. Eq. (
21
)).

Next, we derive the Goursat data of an intersection of codes
H\cap\tilde{H}
in terms of the Goursat data of the original codes
H
and
\tilde{H}
. This result is slightly more general than is needed to determine the Goursat data of the stabilizer
H\cap H^{\omega}
, since
\tilde{H}
does not have to equal
H^{\omega}
.

Proposition 7
.

Suppose that

\begin{array}[]{ccccc}&&G\times G&&\\
G\times G&&|&&\\
|&\longleftrightarrow&{E_{X}}\times{E_{Z}}&,&\phi\\
H&&|&&\\
&&{N_{X}}\times{N_{Z}}&&\end{array}

VI.3
Characterizing subsystem stabilizer codes using the Goursat data of the stabilizer group

Here, we characterize subsystem stabilizer codes according to the Goursat data of their stabilizer groups (see Fig.
2
for a summary).

Figure 2:
Venn diagram depicting features of subsystem stabilizer codes with maximal and minimal stabilizer groups, per Def.
4
. A code has minimal stabilizer iff its stabilizer group is CSS. A code has minimal and maximal stabilizer iff its gauge group is CSS. Every subspace stabilizer code has maximal stabilizer, but there are codes with maximal stabilizer that are not subspace stabilizer codes.

Recall that a subsystem stabilizer code
H
can equivalently be described by its Goursat data — the internal CSS code
N
, the external CSS code
E
, and the isomorphism
\phi
. Here, we are interested in the number of blocks in the stabilizer group
H\cap H^{\omega}
of
H
(see Figure
1
). To motivate this inquiry, recall that the stabilizer group has one block iff it is CSS, and the stabilizer group has many blocks iff it is “far from CSS”. As we will show, the number of blocks in the stabilizer group is upper bounded by a function of
N
and
E
. This upper bound is independent of the particular isomorphism
\phi
, which determines the true number of blocks in the stabilizer group of
H
. Thus, for fixed internal and external codes
N
and

and
E
.

Definition 4
.

Let

\begin{array}[]{ccccc}&&G\times G&&\\
G\times G&&|&&\\
|&\longleftrightarrow&{E_{X}}\times{E_{Z}}&,&\phi\\
H&&|&&\\
&&{N_{X}}\times{N_{Z}}&&\end{array}.

(116)

6
and
7

\begin{array}[]{ccccc}&&\left({E_{X}}\cap{N_{Z}^{\theta}}\right)\times\left({E_{Z}}\cap{N_{X}^{\theta}}\right)&&\\

&&\left({N_{X}}\cap{E_{Z}^{\theta}}\right)\times\left({N_{Z}}\cap{E_{X}^{\theta}}\right)&&\end{array}

(117)

for some subspace

(119)

Proposition 8

A subsystem stabilizer code has both maximal and minimal stabilizer iff it is a subsystem CSS code.

Proof.

Observe that a subsystem stabilizer code has minimal stabilizer iff its underlying stabilizer group is CSS. We remark that such codes have multiple characterizations.

VII
Conclusion

In this work, we study subsystem stabilizer codes in a linear algebraic framework by viewing Pauli groups as vector spaces and subsystem stabilizer codes as subspaces via the symplectic representation.
This perspective allows us to construct a doubling map that converts any modular-qudit subsystem stabilizer code into a subsystem CSS code with comparable parameters (see Theorem
1
).

The linear algebraic perspective also elucidates the correspondence between a subsystem CSS code and a pair of classical linear codes, yielding an explicit basis of codewords (see Section
III
), a generalized Steane-type recovery procedure (see Section
V
), and other results (see Appendices
C
and
D
).

Finally, the linear-algebraic perspective enables a characterization of subsystem stabilizer codes via Goursat’s Lemma, which yields two generalizations of subsystem CSS codes (see Section
VI
).

We conclude with questions and outlook for future investigations.

Does the Goursat-based characterization in Section

simplify significantly for subspace stabilizer codes?

6.

(\implies)

Appendix D
Parameterizing the codespace of a subsystem CSS code

In this appendix, we parameterize the codespace of a subsystem CSS code
H=H_{X}\times H_{Z}
in terms of the underlying classical codes
H_{X}
and
H_{Z}
. The main result is as follows.

Proposition 11
.

Let
H=H_{X}\times H_{Z}
be a subsystem CSS code. Write

\displaystyle{\left(H_{X}+H_{Z}^{\theta}\right)}/H_{X}

\displaystyle={\left\{l_{i}+H_{X}\right\}}_{i}\text{ and}

(203)

\displaystyle H_{X}/{\left(H_{X}\cap H_{Z}^{\theta}\right)}

\displaystyle={\left\{g_{j}+H_{X}\cap H_{Z}^{\theta}\right\}}_{j},

(204)

where all elements on the right-hand side are distinct. For any
a\in G
, write

\left|a+H_{X}\cap H_{Z}^{\theta}\right\rangle=\sum_{s\in H_{X}\cap H_{Z}^{\theta}}\left|a+{s}\right\rangle.

(205)

Then the codespace of
H
is

\mathbb{L}\otimes\mathbb{G}=\spn{\left\{\left|l_{i}+g_{j}+H_{X}\cap H_{Z}^{\theta}\right\rangle\right\}_{i,j}}.

(206)

Proof.

Say that
H
has parameters
[[n,k,r,d]]
. From the standard theory of stabilizer codes, the codespace
\mathbb{L}\otimes\mathbb{G}
has dimension
p^{k}p^{r}

Scherer 2019
. Moreover, one verifies that every state of the form

\left|l_{i}+g_{j}+H_{X}\cap H_{Z}^{\theta}\right\rangle

(207)

is fixed by every stabilizer of
H
and so belongs to the codespace
\mathbb{L}\otimes\mathbb{G}
. Thus, we must show that the set

\left\{\left|l_{i}+g_{j}+H_{X}\cap H_{Z}^{\theta}\right\rangle\right\}_{i,j}

(208)

contains exactly
p^{k}p^{r}
distinct elements. To see this, note that by Proposition
2
, the index
i
ranges over an index set of size
p^{k}
, and the index
j
ranges over an index set of size
p^{r}
. Moreover, suppose that

\left|l_{i}+g_{j}+H_{X}\cap H_{Z}^{\theta}\right\rangle=\left|l_{i^{\prime}}+g_{j^{\prime}}+H_{X}\cap H_{Z}^{\theta}\right\rangle.

(209)

(210)
