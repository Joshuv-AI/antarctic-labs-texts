Abstract
. We define a version of the Ehrenfeucht–Fraïssé game in the setting of metric model theory and continuous first-order logic and show that the second player having a winning strategy in a game of length n n exactly corresponds to being elementarily equivalent up to quantifier rank n n . We then demonstrate the usefulness of the game with some examples. Finally, we discus connections between the game of length ω \omega and infinitary logic.



2020 Mathematics Subject Classification
03C66

1.
Introduction

One of the important classical results of finite model theory is the connection between Ehrenfeucht–Fraïssé game of length
n
and elementary equivalence up to quantifier rank
n
. In a finite relational signature, two structures satisfy the same sentences of quantifier rank
\leq n
if and only if the second player has a winning strategy in the EF game of length
n
between the structures. If the signature is not finite, then one needs to restrict the plays of the game to finite pieces of the signature. If the signature is not relational, then the connection between the length of the game and quantifier rank becomes more complicated and tied to nesting of function symbols.

In this paper, we replicate the classical connection between elementary equivalence up to quantifier rank
n
and length
n
EF games for continuous logic. Essentially the same game has appeared in lecture notes of Hart
[
Har12
]
but, at least to the knowledge of the authors, no systematic study of it has been conducted. Classically, a tool fine-tuned for quantifier rank allows for more (in)expressivity results than a tool that can only be used to show full elementary equivalence, and such is the case also in the realm of metric structures.

In the last section, we discus infinite and dynamic versions of the game and connect it to infinitary logic. The connections between games and infinitary extensions of continuous first-order logic turn out not to be as straightforward as the connection between first-order continuous logic and games of finite length.

2.
Basic Definitions and Facts

2.1.
Moduli of Uniform Continuity

In the study of the semantics of continuous first-order logic, one important concept is that of a modulus of uniform continuity for a given function between metric spaces. At least two variants are found in the literature:

(i)

A function
\Delta\colon[0,\infty)\to[0,\infty)
is a modulus for a function
f\colon M\to M^{\prime}
, where
M
and
M^{\prime}
are metric spaces, if for every
\varepsilon>0
and
x,y\in M
,

d(x,y)<\Delta(\varepsilon)\implies d(f(x),f(y))\leq\varepsilon.

(ii)

A function
\Delta\colon[0,\infty)\to[0,\infty)
is a modulus for a function
f\colon M\to M^{\prime}
if
\Delta(0)=0
,
\Delta
is continuous at
0
and for all
x,y\in M
, we have

d(f(x),f(y))\leq\Delta(d(x,y)).

It is easy to see that the former kind of a modulus for
f
exists if and only if the latter kind of a modulus for
f
exists if and only if
f
is uniformly continuous. We adopt the latter formulation of a modulus, as it is more convenient in our setting. We may also make more assumptions about
\Delta
to make it behave more nicely without losing generality. If
\Delta
is a modulus for
f
, then by setting

\Delta^{\prime}(t)=\inf\{at+b\mid\text{$a,b\in[0,\infty)$ and $\Delta(s)\leq as+b$ for all $s\in[0,\infty)$}\}

we obtain another modulus
\Delta^{\prime}
for
f
, with the additional properties that
\Delta^{\prime}
is continuous (everywhere), non-decreasing and also subadditive. We will be refering to moduli
\Delta
with such properties without a mention to any particular function
f
whose modulus
\Delta
would be. This leads to the following definition.

Definition 2.1
.

Let
\Delta\colon[0,\infty)\to[0,\infty)
be a function.

(i)

We call
\Delta
a
modulus (of uniform continuity)
if

(a)

it vanishes at zero, i.e.
\Delta(0)=0
,

(b)

it is non-decreasing and subadditive, i.e.

\Delta(x)\leq\Delta(x+y)\leq\Delta(x)+\Delta(y)

for all
x,y\in[0,\infty]
, and

(c)

it is continuous.

(ii)

If
f\colon M\to M^{\prime}
is a function between two metric spaces, then we say that
f

obeys
or
respects

\Delta
if

d(f(x),f(y))\leq\Delta(d(x,y))

for all
x,y\in M
.

2.3.
Partial Isomorphisms and Elementary Equivalence

Definition 2.7
.

Let
\varepsilon\geq 0
, let
\Delta
be a modulus, and let
\mathfrak{A}
and
\mathfrak{B}
be
\sigma
-structures.

(i)

A partial function

is called a partial

-isomorphism if for all atomic

-formulae

and

\left|\varphi^{\mathfrak{A}}(a_{0},\dots,a_{k-1})-\varphi^{\mathfrak{B}}(f(a_{0}),\dots,f(a_{k-1}))\right|\leq\varepsilon.

(ii)

A partial
\varepsilon
-isomorphism is a function which is a partial
(\varepsilon,\Delta)
-isomorphism for every modulus
\Delta
. A partial isomorphism is a partial
0
-isomorphism. If the function is total and surjective, we drop the word “partial”.

Note that our definition of a partial isomorphism does not require that, whenever

is a partial isomorphism,

and

for all constant symbols

. However, if we do have

, then for all

,

\displaystyle d(c^{\mathfrak{B}},f(c^{\mathfrak{A}}))=\left|d(c^{\mathfrak{A}},c^{\mathfrak{A}})-d(c^{\mathfrak{B}},f(c^{\mathfrak{A}})\right|\leq\varepsilon,

whence

.

. We write

3.
The Space of
\Delta
-formulae

In this section we show that for a given modulus
\Delta
and a natural number
n
, the set of
\Delta
-formulae with a fixed finite set of free variables and quantifier rank
\leq n
, equipped with the logical distance, is a
totally bounded
pseudometric space. A (pseudo)metric space
M
is totally bounded, or
precompact
, if for any
\varepsilon>0
,
M
can be covered with finitely many sets of diameter
<\varepsilon
. If
M
is complete, then it is totally bounded if and only if it is compact.

Totally boundedness is, in a sense, approximate finiteness. A set of formulae of
\mathrm{CFO}
being totally bounded with respect to the logical distance defined below corresponds to a set of formulae of classical first-order logic being finite up to logical equivalence. We begin by showing the set of atomic formulae is totally bounded exactly when the signature is finite and relational.

Definition 3.1
.

The logical distance between two
\sigma
-formulae
\phi(\bar{x})
and
\psi(\bar{x})
with the same free variables is defined as

d(\varphi,\psi)=\sup_{\mathfrak{A}\in\str(\sigma)}\sup_{\bar{a}\in\mathfrak{A}^{k}}\left|\varphi^{\mathfrak{A}}(\bar{a})-\psi^{\mathfrak{A}}(\bar{a})\right|.

Note that two formulae are logically equivalent if and only if their logical distance is
0
.

Lemma 3.2
.

Given
k<\omega
, the set of atomic
\sigma
-formulae
\varphi(v_{0},\dots,v_{k-1})
equipped with the logical distance is totally bounded if and only if
\sigma
is relational and finite.

Proof.

We first show that if
\sigma
contains a function symbol
f
, then the space is not totally bounded. Without loss of generality
f
is unary. For each
n<\omega
, let
\mathfrak{A}_{n}
be a
\sigma
-structure whose domain is the
n
-element discrete metric space
\{0,\dots,n-1\}
and
f^{\mathfrak{A}_{n}}(i)=i+1\mod n
. We define terms
t_{i}
,
i<\omega
, by setting
t_{0}=v_{0}
and
t_{i+1}=f(t_{i})
. Then we let
\varphi_{i}(v_{0})=d(t_{0},t_{i})
. Note that
t_{i}^{\mathfrak{A}_{n}}(0)=(f^{\mathfrak{A}_{n}})^{i}(0)=i\mod n
for all
i
. Now for
i<j
,

\displaystyle d(\varphi_{i},\varphi_{j})

\displaystyle\geq\left|\varphi_{i}^{\mathfrak{A}_{j}}(0)-\varphi_{j}^{\mathfrak{A}_{j}}(0)\right|

\displaystyle=\left|d\left(t_{0}^{\mathfrak{A}_{j}}(0),t_{i}^{\mathfrak{A}_{j}}(0)\right)-d\left(t_{0}^{\mathfrak{A}_{j}}(0),t_{j}^{\mathfrak{A}_{j}}(0)\right)\right|

\displaystyle=\left|d(0,i)-d(0,0)\right|

\displaystyle=d(0,i)

\displaystyle=1.

Hence the space cannot be covered by finitely many balls of radius
1/2
.

Then suppose that
\sigma
is relational. We show that the space is discrete. Let
P,Q\in\sigma\cup\{d\}
be two distinct predicates and denote
\varphi=P(t_{0}(\bar{v}),\dots,t_{n-1}(\bar{v}))
and
\psi=Q(t^{\prime}_{0}(\bar{v}),\dots,t^{\prime}_{m-1}(\bar{v}))
for some terms
t_{i}
and
t^{\prime}_{j}
. We let
\mathfrak{A}
be the two-element discrete space, making it a
\sigma
-structure by setting
P^{\mathfrak{A}}\equiv 0
and
R^{\mathfrak{A}}\equiv 1
for any
R\in\sigma\setminus\{P\}
(or vice versa if it happens that

), whence

\displaystyle d(\varphi,\psi)

\displaystyle\geq\sup_{\bar{a}\in\mathfrak{A}^{k}}\left|P^{\mathfrak{A}}(t_{0}^{\mathfrak{A}}(\bar{a}),\dots,t_{n-1}^{\mathfrak{A}}(\bar{a}))-Q^{\mathfrak{A}}((t^{\prime}_{0})^{\mathfrak{A}}(\bar{a}),\dots,(t_{m-1})^{\mathfrak{A}}(\bar{a}))\right|

\displaystyle=1.

Then let
\varphi=P(t_{0},\dots,t_{n-1})
and
\psi=P(t^{\prime}_{0},\dots,t^{\prime}_{n-1})
, where for at least one

we have

. As

is relational, each term is either a constant symbol or a variable, and distinguishing between the two is irrelevant in this context, as it does not make a difference whether we define suitable interpretations for constants or find suitable parameters; hence we may assume they are all constants. Let

be such that
t_{i}\neq t^{\prime}_{i}
. Now let
\mathfrak{B}
be the two-element discrete space, with
t_{i}^{\mathfrak{B}}=0
,
(t^{\prime}_{i})^{\mathfrak{B}}=1
and

5.
Applications of the EF games

Compact structures in metric model theory correspond to finite structures in classical model theory. If

Let

Even more is true classically: the first-order theory of a finite structure is categorical, i.e. it has a unique model up to isomorphism. This is because a finite structure has only finitely many elements, relations and functions, so one can cook up a sentence that exactly describes each of these.

These are discrete and hence complete, so they are well-defined

\varepsilon>0

\mathrm{\mathbf{I}}
is doomed to lose the EF game of any finite length of precision

between
\mathfrak{A}
and
\mathfrak{B}
because with precision
\varepsilon
he has no way to tell apart two elements that are
\varepsilon
-close to each other using just the metric.
∎

If
\mathfrak{A}
is a finite metric structure with cardinality
n
, then if
\mathfrak{B}
is another structure with cardinality
\neq n
, there is a sentence

such that
\varphi^{\mathfrak{A}}\neq\varphi^{\mathfrak{B}}
. Yet, there is no sentence that would dictate that the cardinality of a structure is

. This result uses the finer structure of elementary equivalence.

Corollary 5.5
.

For
\sigma=\emptyset
and any

, there is no

-sentence

such that for any
\sigma
-structure

\mathfrak{A}\models\varphi=0\iff\left|\mathfrak{A}\right|\geq n.

Proof.

For simplicity, we prove this for

. Suppose such a
\varphi
exists. Let
\Theta
be for
\varphi
as in Lemma

. Then let
\mathfrak{A}
be the discrete metric space
\{0,1\}
with
d(0,1)=1
. Now, as
\left|\mathfrak{A}\right|\neq 3
, we must have
\varphi^{\mathfrak{A}}>0
. Let
\varepsilon>0
be such that
\Theta(\varepsilon)<\varphi^{\mathfrak{A}}
. Then let
\mathfrak{B}
be the metric space
\{0,1,2\}

and

. Now we play

. The stategy of
\mathrm{\mathbf{II}}
is to pretend the elements

and

are the same element and play according to the “isomorphism”

,

. Clearly we have

\left|d^{\mathfrak{A}}(0,1)-d^{\mathfrak{B}}(0,1)\right|=\left|d^{\mathfrak{A}}(0,1)-d^{\mathfrak{B}}(0,2)\right|=0<\varepsilon

\left|d^{\mathfrak{A}}(1,1)-d^{\mathfrak{B}}(1,2)\right|=d^{\mathfrak{B}}(1,2)=\frac{\varepsilon}{2}<\varepsilon.

Hence

wins. But by Lemma

\Theta(\varepsilon)<\varphi^{\mathfrak{A}}=\left|\varphi^{\mathfrak{A}}-\varphi^{\mathfrak{B}}\right|\leq\Theta(\varepsilon),

a contradiction.
∎

6.
Infinite and Dynamic Games

Having replicated the connection between first-order logic and EF games of finite length in the metric setting, the next natural question is what kind of infinitary logic the game of length
\omega
would correspond to. Classically, the second player has a winning strategy in an EF game of length
\omega
between two structures
\mathfrak{A}
and
\mathfrak{B}
if and only if
\mathfrak{A}
and
\mathfrak{B}
satisfy the same sentences of the logic
\mathcal{L}_{\infty\omega}
.

There are several different definitions for an infinitary version of
\mathrm{CFO}
; a comparison of their expressive power is performed in
[
Eag17
]
. As a natural counterpart of (finitary) conjunction is the continuous connective
\max
, the natural counterpart of infinitary conjunction is supremum. If one desires an infinitary extension of
\mathrm{CFO}
whose formulae are continuous, then one needs to restrict the use of supremum in some way.
5
5

5

Whether or not one restricts suprema for continuity reasons, one of course needs to assume that the free variables of formulae of
\Phi
are contained in a given finite set of variables, as is the case also in the classical setting.
One such way, employed by
[
BYI09
]
, is to assume
\sup\Phi
is a well-formed formula only when
\Phi
is an equicontinuous set of formulae, as witnessed by some modulus
\Delta
which is respected by each
\varphi\in\Phi
. In
[
Eag14
]
, no such restriction is made, resulting in a discontinuous logic.

Whether the continuity restriction be placed on suprema or not, it can be immediately noted that the game defined in Definition
4.1
does not quite do the trick for us. Consider the signature
\sigma=\{P_{i}\mid i<\omega\}
, where each
P_{i}
is a unary predicate with
\modulus(P_{i})=\frac{1}{i+1}\id
. Then denote
\varphi_{i}(x)=\min\{(i+1)P_{i}(x),1\}
for
i<\omega
. These are well-defined formulae of
\mathrm{CFO}
and respect the modulus
\id
. Hence the formula
\varphi=\sup_{i<\omega}\varphi_{i}
is a well-defined formula of
\mathcal{L}_{\omega_{1}\omega}
in the sense of both
[
BYI09
]
and
[
Eag14
]
. Then, let
A_{i}
,
i<\omega
, be infinite sets such that
A_{i+1}\subseteq A_{i}
and
A_{i}\setminus A_{i+1}
is infinite for all
i<\omega
, and
\bigcap_{i<\omega}A_{i}
contains a single element. Let
B_{i}
,
i<\omega
, be a similar decreasing sequence of infinite sets but with
\bigcap_{i<\omega}B_{i}=\emptyset
. Now we make
A_{0}
and
B_{0}
discrete
\sigma
-structures
\mathfrak{A}
and
\mathfrak{B}
by setting

P_{i}^{\mathfrak{A}}(t)=\frac{d(t,A_{i})}{i+1}\quad\text{and}\quad P_{i}^{\mathfrak{B}}(t)=\frac{d(t,B_{i})}{i+1}.

Now
\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EF}^{\varepsilon}_{\omega}\left(\mathfrak{A},\mathfrak{B}\right)
for any
\varepsilon>0
: if
\mathrm{\mathbf{I}}
plays plays the element
a
inhabiting
\bigcap_{i<\omega}A_{i}
, then
\mathrm{\mathbf{II}}
responds with any
b\in B_{n}
such that
2/(n+1)<\varepsilon
; then for any
i\leq n
,
a\in A_{i}
and
b\in B_{i}
, so

\left|P_{i}^{\mathfrak{A}}(a)-P_{i}^{\mathfrak{B}}(b)\right|=0<\varepsilon,

and for
i>n

\left|P_{i}^{\mathfrak{A}}(a)-P_{i}^{\mathfrak{B}}(b)\right|\leq P_{i}^{\mathfrak{A}}(a)+P_{i}^{\mathfrak{B}}(b)=\frac{d(a,A_{i})}{i+1}+\frac{d(b,B_{i})}{i+1}\leq\frac{2}{i+1}<\frac{2}{n+1}<\varepsilon.

On the other hand,
(\inf_{x}\sup_{i}\varphi_{i})^{\mathfrak{A}}=0
but
(\inf_{x}\sup_{i}\varphi_{i})^{\mathfrak{B}}=1
, so
\mathfrak{A}
and
\mathfrak{B}
do not even satisfy the same sentences of
\mathcal{L}_{\omega_{1}\omega}
of quantifier rank
1
.

The essence of the problem seems to be the following: preserving atomic formulae arbitrarily well is not enough to preserve the supremum arbitrarily well unless one can exactly preserve the values of atomic formulae. This is due to connectives. It would seem we need a way to restrict more than just the precision at a given play. One way to modify the game would be to put in a modulus
\Delta
as a parameter:
\mathrm{\mathbf{II}}
wins the game
\mathrm{EF}^{\varepsilon,\Delta}_{\omega}\left(\mathfrak{A},\mathfrak{B}\right)
if the function resulting from a play is a
(\varepsilon,\Delta)
-isomorphism instead of just an
\varepsilon
-isomorphism. For finite signatures, this restriction adds nothing, as is seen in the proof of Theorem
4.3
, but for infinite signatures it may help us find winning strategies. However, the problem posed by the above example will not go away with this addition: in the example,
\mathrm{\mathbf{II}}
will have a winning strategy in any
\mathrm{EF}^{\varepsilon,\Delta}_{\omega}\left(\mathfrak{A},\mathfrak{B}\right)
for
\Delta\geq\id
.

A similar problem is encountered in
[
BYDNT17
]
, where the logic of
[
BYI09
]
is further studied and a version of Scott’s isomorphism theorem is proved for separable metric structures in a countable signature. Their solution is to define a fragment of
\mathcal{L}_{\omega_{1}\omega}
such that every

is equivalent to a sentence of this fragment, with possibly higher quantifier rank. We can adapt this approach to our game and get a connection between
\mathcal{L}_{\infty\omega}
-equivalence and infinite games. However, it is not clear whether every
\mathcal{L}_{\infty\omega}
-sentence has a normal form in this fragment, as the result of
[
BYDNT17
]
employs the machinery of descriptive set theory to show this for
\mathcal{L}_{\omega_{1}\omega}
, and going above
\omega_{1}
would seem to require results of generalized descriptive set theory. We leave the question about the normal form open for future research.

\mathfrak{B}

r_{\alpha,n}^{\mathfrak{A},\mathfrak{B}}(\bar{a},\bar{b})<\varepsilon
, we have
\sup_{a^{\prime}\in\mathfrak{A}}\inf_{b\in\mathfrak{B}}r_{\beta,n+1}^{\mathfrak{A},\mathfrak{B}}(\bar{a}a^{\prime},\bar{b}b)<\varepsilon
. Hence, in particular,
\inf_{b\in\mathfrak{B}}r_{\beta,n+1}^{\mathfrak{A},\mathfrak{B}}(\bar{a}a,\bar{b}b)<\varepsilon
, so there is
b\in\mathfrak{B}
with
r_{\beta,n+1}^{\mathfrak{A},\mathfrak{B}}(\bar{a}a,\bar{b}b)<\varepsilon
. We let
\mathrm{\mathbf{II}}
play
b
as a response on the first round. By the induction hypothesis,
\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EFD}_{\beta}^{\varepsilon,\Omega}\left((\mathfrak{A},\bar{a}a),(\mathfrak{B},\bar{b}b)\right)
, so following her strategy in this
\beta
-game,
\mathrm{\mathbf{II}}
survives the rest of the play in the
\alpha
-game.
∎

We write
\mathfrak{A}\equiv_{\alpha}^{\Omega}\mathfrak{B}
if
\varphi^{\mathfrak{A}}=\varphi^{\mathfrak{B}}
for all
\Omega
-sentences of quantifier rank
\leq\alpha
. If
\mathfrak{A}\equiv_{\alpha}^{\Omega}\mathfrak{B}
for all
\alpha
, we write
\mathfrak{A}\equiv_{\infty}^{\Omega}\mathfrak{B}
.

Corollary 6.7
.

The following are equivalent for all structures
\mathfrak{A}
and
\mathfrak{B}
, ordinals
\alpha
and non-negative reals
\varepsilon
.

(i)

\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EFD}_{\alpha}^{\delta,\Omega}\left((\mathfrak{A},\bar{a}),(\mathfrak{B},\bar{b})\right)
for all
\delta>\varepsilon
.

(ii)

\left|\varphi^{\mathfrak{A}}(\bar{a})-\varphi^{\mathfrak{B}}(\bar{b})\right|\leq\varepsilon
for all
n
,
\bar{a}\in\mathfrak{A}^{n}
and
\bar{b}\in\mathfrak{B}^{n}
.

In particular,
\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EFD}_{\alpha}^{\Omega}\left(\mathfrak{A},\mathfrak{B}\right)
if and only if
\mathfrak{A}\equiv_{\alpha}^{\Omega}\mathfrak{B}
.

\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EF}^{\varepsilon,\Omega}_{\omega}\left((\mathfrak{A},\bar{a}),(\mathfrak{B},\bar{b})\right)

\alpha
.

Proof.

Similar to the classical proof, see e.g.

]
.
∎

Corollary 6.9
.

\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EF}^{\Omega}_{\omega}\left(\mathfrak{A},\mathfrak{B}\right)
if and only if
\mathfrak{A}\equiv_{\infty}^{\Omega}\mathfrak{B}
.

It is shown in
[
BYDNT17
]
that for any countable signature
\sigma
, there is a modulus
\Omega_{\sigma}
such that every
\sigma
-sentence of
\mathcal{L}_{\omega_{1}\omega}
is equivalent to an
\Omega_{\sigma}
-sentence. From this we obtain the following.

Corollary 6.10
.

\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EFD}_{\alpha}^{\Omega_{\sigma}}\left(\mathfrak{A},\mathfrak{B}\right)
for all
\alpha<\omega_{1}
if and only if
\mathfrak{A}
and
\mathfrak{B}
satisfy the same sentences of
\mathcal{L}_{\omega_{1}\omega}
.

It remains as an open question whether
\mathrm{\mathbf{II}}\mathbin{\raisebox{0.8pt}{$\uparrow$}}\mathrm{EF}^{\Omega_{\sigma}}_{\omega}\left(\mathfrak{A},\mathfrak{B}\right)
if and only if
\mathfrak{A}
and
\mathfrak{B}
satisfy the same sentences of
\mathcal{L}_{\infty\omega}
. This is tied to the open question about whether every formula of
\mathcal{L}_{\infty\omega}
is equivalent to an
\Omega_{\sigma}
-formula. For uncountable signatures
\sigma
, the existence of a universal weak modulus
\Omega_{\sigma}
seems unlikely.
