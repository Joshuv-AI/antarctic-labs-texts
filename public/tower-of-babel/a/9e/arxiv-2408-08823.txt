Optimal Symmetries in Binary Classification
Vishal S. Ngairangbam, and Michael Spannowsky

Abstract
We develop a theoretical foundation for designing group-equivariant neural networks that align the choice of symmetries with the underlying probability distributions of the data. Utilising the general structure of fibre decompositions on the domain under group equivariant maps and its relation to that of the likelihood ratio, we present a theoretical framework for identifying group actions that maintain optimal classification performance via the Neyman-Pearson lemma. This provides a unified methodology for improving classification accuracy especially in fundamental applications where one has knowledge of the inherent symmetries of the distributions and how they are broken by measurement. As an application to jet classification at the Large Hadron Collider, we find that there can be performance gains when one utilises smaller permutation symmetries within the constituents. This work offers insights and practical guidelines for constructing more effective group equivariant architectures in diverse machine-learning contexts.

Introduction

Equivariant neural networks, which leverage symmetries inherent in data, have shown significant promise in enhancing classification accuracy, data efficiency, and convergence speed. However, selecting an appropriate group and defining its actions across the various layers of the network remains a complex task, particularly for applications requiring adherence to specific symmetries. This research aims to establish a foundational framework for designing equivariant neural network architectures by utilising stabiliser groups.

In the context of equivariant function approximation, a critical insight is that the preimage of a target element in the output space can be characterised by the subset of the orbit of an input element, restricted to those connected by elements of the stabiliser group of the target. This understanding simplifies the choice of group
\mathcal{G}
and its actions, aligning them with the equivalence class of the target function’s fibres in the input space.

This paper provides a theoretical basis for designing equivariant architectures in scientific applications where known symmetries play a crucial role. By grounding the architecture design in first principles, we aim to explain empirical successes observed in data-driven applications and enhance the effectiveness of these architectures in practical scenarios.

Our contribution:

In this work, we utilise the minimal fibres that any group invariant or equivariant function should have and connect it to the optimality of a particular symmetry. Although the result is a simple extension of the well-known Neyman Pearson lemma
[
1
]
where an optimal binary classifier should have the same fibre decomposition in the domain of the two probabilities as the likelihood ratio, it provides a transparent basis for maximally utilising domain-knowledge in simulation-based inference, which is quickly gaining popularity in various disciplines.
Defining a compatible symmetry as one that induces compatible fibres on the domain with a given likelihood ratio, we find that:

•

if the support of the two probabilities contain an entire orbit of a compatible symmetry, then equivariant functions under any non-trivial action on the co-domain of group that is contained in such a symmetry has incompatible fibres with the likelihood ratio (see observation
5
)

•

there always exists a maximal symmetric action of a group
\mathcal{G}_{0}
after which one can include non-trivial equivariant
\mathcal{G}
-actions groups that contain the
\mathcal{G}_{0}
-action as a proper subgroup restriction as long as the corresponding
\mathcal{G}
-action of group element does not belong to
\mathcal{G}_{0}
takes any element out of the support (see observation
6
)

•

As a practical application, we analyse the optimality of permutation symmetries in jet classification at the Large Hadron Collider and find that permutation over the entire jet constituents can be suboptimal especially, near the resonant mass beak of the boosted resonant particles. This is substantiated by numerical experiments where we find differences improvements in performance when one utilises the bottom quark information in top classification. Moreover, this difference increases when one reduces the mass window of the selection criterion. Similarly, we also verify the improvement in quark/gluon classification by reducing the permutation symmetries via the particle’s charge information.

Preliminaries

Fibres of a function:

Our work relies on studying the minimal fibre structure induced by symmetries on the likelihood ratio and its relation to different group equivariant functions. A fibre is formally defined as:

Definition 1
.

Given a function
f:\mathcal{X}\to\mathcal{Y}
, the fibre of an element
\mathbf{y}
in the image of
f
denoted as
f^{-1}(\mathbf{y})
, is the set of all elements of
\mathcal{X}
which gets mapped to
\mathbf{y}
via
f
:

f^{-1}(\mathbf{y})=\{\mathbf{x}\in\mathcal{X}\;:\;\mathbf{f}(\mathbf{x})=\mathbf{y}\}\quad.

The fibres of all element in
\text{Im}(f)
divide
\mathcal{X}
into equivalence classes. This means that the set of fibres of any function partitions the domain
\mathcal{D}
into mutually exclusive subsets. This holds true for any equivalence class in any given set, i.e. any element
\mathbf{x}\in\mathcal{X}
can only belong to a single equivalence class. We utilise this basic fact implicitly in different parts of the work.

Group actions:

The main idea underlying symmetries is the action of groups on an underlying set. Group actions and some related terminologies are defined as follows.

Definition 2
.

Given a group
\mathcal{G}
and a set
\mathcal{X}
, the left-action of
\mathcal{G}
on
\mathcal{X}
is a map
\mathbf{A}:\mathcal{G}\times\mathcal{X}\to\mathcal{X}
with the following properties:

1.

\mathbf{A}(e,\mathbf{X})=\mathbf{X}
for the identity element
e\in\mathcal{G}
and any
\mathbf{X}\in\mathcal{X}
, and

2.

\mathbf{A}(g_{1},\mathbf{A}(g_{2},\mathbf{X}))=\mathbf{A}(g_{1}g_{2},\mathbf{X})
for all
g_{1},g_{2}\in\mathcal{G}
and
\mathbf{X}\in\mathcal{X}
.

A
\mathcal{G}
-action will be denoted as
(\mathcal{G},\mathbf{A}(g,\mathbf{X}))
. Any set always admits the trivial action where
\mathbf{A}(g,\mathbf{X})=\mathbf{X}
for any group element
g
and all elements
\mathbf{X}
of the set
\mathcal{X}
.
Consequently, even for the same group
\mathcal{G}
, one can have two actions
\mathbf{A}_{1}(g,\mathbf{X})
and
\mathbf{A}_{2}(g,\mathbf{X})
acting on the same set
\mathcal{X}
, which are not necessarily the same functions. This motivates defining the equality of two
\mathcal{G}
-actions as follows.

Definition 3
.

Two
\mathcal{G}
-actions
(\mathcal{G}_{1},\mathbf{A}_{1}(g,\mathbf{X}))
and
(\mathcal{G}_{2},\mathbf{A}_{2}(g,\mathbf{X}))
acting on the same set
\mathcal{X}\ni\mathbf{X}
are equal if and only if
\mathcal{G}_{1}
is isomorphic to
\mathcal{G}_{2}
, via an invertible map
i:\mathcal{G}_{1}\to\mathcal{G}_{2}
and
\mathbf{A}_{1}(g,\mathbf{X})=\mathbf{A}_{2}(i(g),\mathbf{X})
for all
g\in\mathcal{G}_{1}
and
\mathbf{X}\in\mathcal{X}
.

We will primarily concern ourselves with faithful group actions. They are defined as:

Definition 4
.

A
\mathcal{G}
-action
\mathbf{A}(g,\mathbf{X})
on a set
\mathbf{X}
is faithful if
A(g,\mathbf{X})=\mathbf{X}
for all
\mathbf{X}\in\mathcal{X}
then
g=e
.

Primarily, we will be utilising the property of a faithful action that any group element
g
moves at least one element
\mathbf{X}_{g}
of the set
\mathcal{X}
.

Definition 5
.

The orbit of an element
\mathbf{X}\in\mathcal{X}
under the group action
\mathbf{A}(g,\mathbf{X})
of the group
\mathcal{G}
, is the set of all elements
\mathbf{X}^{\prime}\in\mathcal{X}
for which there is a group element
g\in\mathcal{G}
such that
\mathbf{X}^{\prime}=\mathbf{A}(g,\mathbf{X})
.

We will write the orbit of a
\mathcal{G}
-action characterised by a vector of group invariants
\mathbf{I}
as

\Omega^{\mathcal{X}}(\mathbf{I})=\{\mathbf{X}^{\prime}=\mathbf{A}(g,\mathbf{X}):\{\mathbf{X},\mathbf{X}^{\prime}\}\subset\mathcal{X}\text{ and }g\in\mathcal{G}\}\quad.

(1)

The set of all distinct orbits divides
\mathcal{X}
into equivalence classes.

Definition 6
.

The stabiliser group of an element
\mathbf{X}\in\mathcal{X}
with respect to the
\mathcal{G}
-action
\mathbf{A}
, is the set of all group elements
g
which leave
\mathbf{X}
invariant. Mathematically, we will denote it as

\mathcal{L}^{\mathbf{A}}(\mathbf{X})=\{g\in\mathcal{G}:\mathbf{X}=\mathbf{A}(g,\mathbf{X})\}\subseteq\mathcal{G}

A group representation
\rho:\mathcal{G}\to GL(m,\mathbb{R})
, naturally induces a linear action
\mathbf{A}_{\rho}:\mathcal{G}\times\mathbb{R}^{m}\to\mathbb{R}^{m}
on
\mathbb{R}^{m}
of the form
\mathbf{A}_{\rho}(g,\mathbf{x})=\rho(g)\,\mathbf{x}
. In the rest of the paper, we will be primarily concerned with such actions of a given transformation group on
\mathbb{R}^{m}
. We will work under the relaxation that these actions need not be closed in the domain of the target function
\mathcal{D}\subset\mathbb{R}^{m}
, i.e. there may be group elements
g\in\mathcal{G}
which takes a point
\mathbf{x}\in\mathcal{D}
to
\rho(g)\,\mathbf{x}=\mathbf{x}^{\prime}\notin\mathcal{D}
. For a pedagogical overview of common transformation groups see
[
27
]
.

Group equivariant functions:

Symmetries are built into neural networks using group equivariant maps, defined as follows.

Definition 7
.

A function
\mathbf{f}:\mathcal{X}\to\mathcal{H}
between two spaces
\mathcal{X}
and
\mathcal{H}
which both admit group actions, say
\mathbf{A}_{\mathcal{X}}
and
\mathbf{A}_{\mathcal{H}}
respectively, for a group
\mathcal{G}
is said to be
\mathcal{G}
-equivariant if
\mathbf{f}
commutes with the group actions, i.e.,

\mathbf{f}(\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}))=\mathbf{A}_{\mathcal{H}}(g,\mathbf{f}(\mathbf{X}))\quad,

(2)

for every
g\in\mathcal{G}
and
\mathbf{X}\in\mathcal{X}
. The map
\mathbf{f}
is
\mathcal{G}
-invariant if the action
\mathbf{A}_{\mathcal{H}}
is trivial, i.e.,
\mathbf{A}_{\mathcal{H}}(g,\mathbf{H})=\mathbf{H}
for all
g\in\mathcal{G}
and any
\mathbf{H}\in\mathcal{H}
.

Likelihood ratio and hypothesis testing:

We first outline a non-technical and intuitive picture of the ubiquitous Neyman-Pearson lemma
[
1
]
which we will then connect to optimal binary classification. Consider an observed data
\mathbf{X}
and we hypothesise that it originates from either
P_{0}(\mathbf{X},\Theta_{0})
or
P_{1}(\mathbf{X},\Theta_{1})
, where
\Theta_{\alpha}
are parameters of the probability distribution. Those hypotheses where the probabilities are completely specified are said to be
simple
, i.e., each of the parameters
\Theta_{\alpha}
are fixed to specific values for
\alpha\in\{0,1\}
. The Neyman-Pearson lemma applies to scenarios where the two hypotheses are simple and exhaustive, i.e., the data can originate from only these two completely specified probabilities. The null hypothesis
H_{0}
, where
\mathbf{X}
follows
P_{0}
, is usually chosen to represent the currently understood phenomena, while the alternate hypothesis
H_{1}
, where
\mathbf{X}
follows
P_{1}
, are taken to describe possible phenomena in the new regime probed by the experiment.

The power of a statistical test is the probability of correctly rejecting the null hypothesis when the alternate hypothesis is true. At the same time, the significance is the probability of rejecting the null hypothesis when it is true. The Neyman-Pearson lemma states that the likelihood ratio
\lambda(\mathbf{X})=P_{1}(\mathbf{X})/P_{0}(\mathbf{X})
is uniformly the most powerful test statistic via which we can accept that
\mathbf{X}
originated from
P_{1}
for a given significance. Notably, a binary classification problem with an appropriate loss function (including binary cross-entropy) reduces to approximating a monotonic function of the likelihood ratio
[
28
]
.

Optimal binary classification:

As we aim to connect binary classification with the Neyman-Pearson optimality of hypothesis tests, we will utilise an analogous and straightforward definition of optimality in binary classification following the standard formulation of the receiver operator characteristics curve.
Let us take the binary classification of a sample
\mathbf{X}
sampled from either
P_{0}(\mathbf{X})
or
P_{1}(\mathbf{X})
with the same support
\mathcal{D}\subset\mathbb{R}^{m}
, where we are interested in maximally selecting those samples originating from
P_{1}
. Often, the support of the alternate hypothesis’ probability distribution function (pdf)
P_{1}
is contained within that of the null hypothesis
P_{0}
. On the other hand, if there is some part of
P_{1}
’s support outside
P_{0}
, any event obtained in this region trivially can only follow the alternate hypothesis. We are, therefore, primarily interested in those non-trivial cases where the data falls in the intersection of the support of
P_{0}
and
P_{1}
. For a given classifier
\hat{f}:\mathcal{D}\to\mathbb{R}
which learns the underlying class assignment map by segregating samples from
P_{1}
to negative values, dependent on a threshold
t\in\mathbb{R}
the cumulative distribution of
\hat{y}=\hat{f}(\mathbf{X})
under
P_{\alpha}
are

\epsilon_{\alpha}=C_{\alpha}(t)=\int_{\mathcal{D}}dV\,P_{\alpha}(\mathbf{X})\;\Theta(\hat{y}<t)\quad,

where
dV
is the volume element in
\mathcal{D}
. Therefore,
\epsilon_{1}
is the true positive rate and
\epsilon_{0}
is the false positive rate and the former can be cast as a function of the later using the threshold
t
,
\epsilon_{1}=C_{1}\circ C^{-1}_{0}(\epsilon_{0})=\text{ROC}(\epsilon_{0})
. We now have the following definition of an optimal binary classifier.

Definition 8
.

A binary classifier for data sampled from two distributions
P_{0}(\mathbf{x})
and
P_{1}(\mathbf{x})
is optimal in accepting samples from
P_{1}
at a given tolerance
\epsilon_{0}
of accepting false samples from
P_{0}
, if it has the highest possible acceptance of samples
\epsilon_{1}
from
P_{1}
.

The connection to Neyman-Pearson’s optimality of the likelihood ratio can be seen as follows. For each
\mathbf{X}
, if the null hypothesis
H_{0}
is that the underlying distribution is
P_{0}
and the alternate hypothesis
H_{1}
is that it is
P_{1}
, it is straightforward to see that
\epsilon_{0}
is the significance of the test and
\epsilon_{1}
is its power. Therefore, we have the following observation.

Observation 1
.

A binary classifier
\hat{f}:\mathcal{D}\to\mathbb{R}
of data
\mathbf{X}\in\mathcal{D}
sampled from either
P_{0}(\mathbf{X})
or
P_{1}(\mathbf{X})
is an optimal classifier for all values of
\epsilon_{0}
, if and only if it is a monotonic function of the likelihood ratio
P_{1}(\mathbf{X})/P_{0}(\mathbf{X})
.

The relaxation to a monotonic function of the likelihood ratio follows from the integral definition of
\epsilon_{\alpha}
depending implicitly on the threshold, i.e., we are interested in choosing regions in
\mathcal{D}
divided by hypersurfaces which have constant likelihood ratios. For a
d
-dimensional domain, these are at least
d-1
dimensional, and therefore, they are computationally non-trivial to evaluate in high dimensions even when one can write down closed-form expressions for the probabilities. Additionally, a necessary condition for any function to be the optimal classifier is to have an identical fibre decomposition in the domain
\mathcal{D}
with the likelihood ratio.

4
Minimal fibres of group equivariant functions

Since a necessary optimality condition in binary classification is to have the same fibre decomposition in the domain
\mathcal{D}
, we now describe the minimal fibres of group of equivariant functions.

4.1
Invariant functions

Let
\mathbf{h}:\mathcal{X}\to\mathcal{H}
be a
\mathcal{G}
-invariant function, i.e. for any
\mathbf{X}\in\mathcal{X}
and all
g\in\mathcal{G}
,

\mathbf{h}(\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}))=\mathbf{h}(\mathbf{X})\quad.

(3)

This means that if
\mathbf{X}\in\Omega^{\mathcal{X}}(\mathbf{I})
then for all
\mathbf{X}^{\prime}=\mathbf{A}_{\mathcal{X}}(g,\mathbf{X})\in\Omega^{\mathcal{X}}(\mathbf{I})
,
\mathbf{h}(\mathbf{X}^{\prime})=\mathbf{h}(\mathbf{X})
. Therefore, we have the following observation:

Observation 2
.

The fibre of an element
\mathbf{H}=\mathbf{h}(\mathbf{X})\in\mathcal{H}
in the image of a
\mathcal{G}
-invariant function
\mathbf{h}:\mathcal{X}\to\mathcal{H}
is at least as large as the orbit
\Omega^{\mathcal{X}}(\mathbf{I})
of
\mathbf{X}\in\mathcal{X}
of the action
\mathbf{A}_{\mathcal{X}}
. If the map is equal for elements belonging to distinct orbits, the fibre becomes enlarged to the union of these orbits.

Let
\mathbf{h}(\mathbf{X})
become equal for
\mathbf{X}
in all orbits parametrized by
\mathbf{I}
in the set
\mathcal{F}
of orbit invariants
\mathbf{I}
. The fibre
\mathbf{h}(\mathbf{X})
for any
\mathbf{X}
in these orbits is

\mathbf{h}^{-1}(\mathbf{X})=\bigcup_{\mathbf{I}\in\mathcal{F}}\Omega^{\mathcal{X}}(\mathbf{I})\quad.

(4)

4.2
Equivariant functions

Let
\mathbf{f}:\mathcal{X}\to\mathcal{H}
be a
\mathcal{G}
-equivariant function with respect to the actions
\mathbf{A}_{\mathcal{X}}
and
\mathbf{A}_{\mathcal{H}}
on
\mathcal{X}
and
\mathcal{H}
, respectively. If
\mathbf{X}^{\prime}=\mathbf{A}_{\mathcal{X}}(g,\mathbf{X})
is in the orbit of
\mathbf{X}
, from Eq
2
, we have
\mathbf{f}(\mathbf{X}^{\prime})=\mathbf{A}_{\mathcal{H}}(g,\mathbf{f}(\mathbf{X}))
. It is straightforward to see that

g\in\mathcal{L}^{\mathbf{A}_{\mathcal{H}}}(\mathbf{f}(\mathbf{X}))\implies\mathbf{f}(\mathbf{X}^{\prime})=\mathbf{f}(\mathbf{X})\quad,

(5)

i.e., if
\mathbf{X}
and
\mathbf{X}^{\prime}
are connected by a group element
g
which belongs to the stabiliser group of the action
\mathbf{A}_{\mathcal{H}}
at
\mathbf{f}(\mathbf{X})
, then
\mathbf{X}^{\prime}
is contained in the fibre
\mathbf{f}^{-1}(\mathbf{H})
of
\mathbf{H}=\mathbf{f}(\mathbf{X})
.
Therefore, similar to the case for invariant maps, we have the following observation:

Observation 3
.

The fibre of an element
\mathbf{H}=\mathbf{f}(\mathbf{X})\in\mathcal{H}
in the image of a
\mathcal{G}
-equivariant function
\mathbf{f}:\mathcal{X}\to\mathcal{H}
, is at least as large as the subset of the orbit of
\mathbf{X}
connected by an element
g
in the stabiliser group of
\mathbf{A}_{\mathcal{H}}
at
\mathbf{H}
. If the map is equal for elements belonging to distinct orbits in
\mathcal{X}
, the fibre becomes enlarged to the union of all such sets.

Define the subset of the orbit
\Omega^{\mathcal{X}}(\mathbf{I})
dependent on
\mathbf{H}=\mathbf{f}(\mathbf{X})
as

\mathcal{O}(\mathbf{I},\mathbf{H})=\{\mathbf{X}^{\prime}=\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}):g\in\mathcal{L}^{\mathbf{A}_{\mathcal{H}}}(\mathbf{H})\}\quad.

(6)

If
\mathbf{f}(\mathbf{X})
become equal for
\mathbf{X}
in all such subsets of distinct orbits parametrized by
\mathbf{I}
in the subset
\mathcal{F}\subseteq\mathcal{I}
.
The fibres can be written as

\mathbf{f}^{-1}(\mathbf{H})=\bigcup_{\mathbf{I}\in\mathcal{F}}\,\mathcal{O}(\mathbf{I},\mathbf{H})\quad.

(7)

As expected, the invariant result is a special case when the action
\mathbf{A}_{\mathcal{H}}
is trivial, i.e. the stabiliser group of any element
\mathbf{H}\in\mathcal{H}
is the group
\mathcal{G}
and
\mathcal{O}(\mathbf{I},\mathbf{H})=\Omega^{\mathcal{X}}(\mathbf{I})
for any
\mathbf{H}
.

As we will be primarily concerned with probabilities with support on a subset
\mathcal{D}\subset\mathcal{X}
where
\mathcal{X}=\mathbb{R}^{m}
, the fibres become the intersection of the respective sets with the domain
\mathcal{D}
. At this point, we point out that for general equivariant function approximation, a correct symmetry (whether invariant or equivariant) is one which does not mix the fibres of a target function through the minimal fibres induced via group equivariance.

5
Optimal symmetries in binary classification

In fundamental applications, more often than not, the probabilities are invariant under some transformation group action on the domain
\mathcal{D}
. Even when closed-form expressions are not known, various first-principle arguments require the probabilities to be invariant under a transformation group. In this section, we answer the question of which symmetries retain the optimality of a classifier when the symmetry of the two probabilities is known a priori. We ignore the effects of noise in our mathematical description while we observe that the findings persist in the presence of noise in our numerical experiments.

5.1
Compatible, closed, and maximal group symmetries

Definition
8
considers optimality in terms of performance alone. To connect with the structure of fibres that some assumed group equivariance endows on the domain, we first define a correct symmetry for binary classification as:

Definition 9
.

A
\mathcal{G}
-action on
\mathcal{X}
is a compatible symmetry for binary classification of classes sampled from two probability densities
P_{0}(\mathbf{X})
and
P_{1}(\mathbf{X})_{1}
with support
\mathcal{D}\subseteq\mathcal{X}
if its acts faithfully on
\mathcal{D}
and for any orbit
\Omega^{\mathcal{X}}(\mathbf{I})\subset\mathcal{X}
, the intersection
\mathcal{D}\cap\Omega^{\mathcal{X}}(\mathbf{I})\subset\mathcal{X}
is either empty or it is contained in a single fibre of the likelihood ratio
\lambda(\mathbf{X})
.

The requirement of a faithful group action naturally excludes the trivial action of any given group as a correct symmetry and we will exclude non-faithful group actions in our analysis. Additionally, the definition’s negation naturally leads to an incompatible symmetry for binary classification, i.e. there is at least one
\mathbf{X}\in\mathcal{D}
and
g\in\mathcal{G}
such that
\lambda(\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}))\neq\lambda(\mathbf{X})
when
\mathbf{A}_{\mathcal{X}}(g,\mathbf{X})\in\mathcal{D}
. Thus, this naturally translates to the following self-evident observation.

Observation 4
.

A
\mathcal{G}
-action on
\mathcal{X}
is compatible with the likelihood ratio
\lambda(\mathbf{X})
if and only if for every
\mathbf{X}\in\mathcal{D}
,
g\in\mathcal{G}
such that
\mathbf{X}^{\prime}=\mathbf{A}_{\mathcal{X}}(g,\mathbf{X})\in\mathcal{D}
we have
\lambda(\mathbf{X}^{\prime})=\lambda(\mathbf{X})
.

Thus, any compatible group action need not have its entire orbit in
\mathcal{D}
, since the requirement of equality is mandated only when the group action moves points within the support
\mathcal{D}
. This leaves room for equivariance under groups that contain the “largest" symmetry of the likelihood ratio as a proper subgroup as long as the additional group elements take any
\mathbf{X}
outside of
\mathcal{D}
. Before that, we can operationalise this observation to define the notion of a closed symmetry and a maximal symmetry of a binary classification task.

Definition 10
.

A compatible
\mathcal{G}_{c}
-action, say
\mathbf{A}_{c}(g,\mathbf{X})
is a closed symmetry of a likelihood ratio if one can find at least one orbit of the action in
\mathcal{D}
, i.e
\Omega^{\mathcal{X}}(\mathbf{I}_{0})\subset\mathcal{D}
for some orbit
\Omega^{\mathcal{X}}(\mathbf{I}_{0})
of
\mathbf{A}_{c}(g,\mathbf{X})
in
\mathcal{X}
.

Definition 11
.

A
\mathcal{G}_{0}
-action, say
\mathbf{A}_{0}(g,\mathbf{X})
, is a maximal symmetry of some likelihood ratio
\lambda(\mathbf{x})
if it is a compatible symmetry, and for any
\mathcal{G}
-action
\mathbf{\tilde{A}}_{\mathcal{X}}(g,\mathbf{X})
that reduces to
\mathbf{A}_{0}
when restricted to
\mathcal{G}_{0}
as a proper subgroup, we have
\mathbf{\tilde{A}}_{\mathcal{X}}(\tilde{g},\mathbf{X})\notin\mathcal{D}
for every
\tilde{g}\in\mathcal{G}\setminus\mathcal{G}_{0}
and
\mathbf{X}\in\mathcal{D}
.

Note that since we require faithfulness for compatibility, it is not mandatory for every likelihood ratio to have a compatible symmetry resulting in the absence of closed or maximal symmetries. Nevertheless, if
\mathcal{G}_{c}
or
\mathcal{G}_{0}
exists, they characterise co-domain actions which maintain compatible fibre decomposition with the likelihood ratio.

5.2
Characterising compatible co-domain group actions

Utilising closed and maximal symmetries, we now characterise families of equivariant functions that will maintain a compatible fibre decomposition with the likelihood ratio. First, consider that we have closed symmetry of the likelihood ratio. If any
\mathcal{G}
-action on the domain can be obtained by some restriction of
\mathbf{A}_{c}
to some subgroup (not necessarily proper) of
\mathcal{G}_{c}
, then every group element
g\in\mathcal{G}
has some
\mathbf{X}\in\mathcal{D}
such that
\lambda(\mathbf{X})=\lambda(\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}))\neq 0
. Thus, the corresponding action on the co-domain
\mathbf{A}_{\mathcal{H}}
must act trivially for any element
g\in\mathcal{G}
since otherwise
f(\mathbf{A}_{\mathcal{X}}(g,\mathbf{X}))\neq f(\mathbf{X})
for any function
f(\mathbf{X})
and
\mathbf{X}\in\mathcal{D}
. This can be captured as the following observation:

Observation 5
.

If
\mathbf{A}_{\mathcal{X}}
is a compatible action of a group
\mathcal{G}\subseteq\mathcal{G}_{c}
that is obtained by the restriction of a closed action
\mathbf{A}_{c}
to
\mathcal{G}
, then a function
f:\mathcal{D}\to\mathcal{H}
that is equivariant under any action
\mathbf{A}_{\mathcal{H}}
that acts non-trivially on the image
\text{Im}(f)\subseteq\mathcal{H}
will have an incompatible fibre decomposition with the likelihood ratio
\lambda(\mathbf{X})
in
\mathcal{D}
.

Since the fibre decomposition is function specific, the restriction on the co-domain action is restricted to its image. However, from the perspective of function approximation by a neural network, the image changes dynamically during training which therefore forbids non-trivial action on the co-domain. Thus, under practical considerations, characterising a closed action
\mathbf{A}_{c}
of some group
\mathcal{G}_{c}
forbids any non-trivial equivariance on the co-domain that is obtained by some restriction to a subgroup of
\mathcal{G}_{0}
.

As we have assumed that compatible group actions need not have an entire orbit in the support
\mathcal{D}
, there can be situations where there are no closed symmetries even when there are compatible ones. However, there is some maximal symmetry when there are compatible ones.
Consider any compatible
\mathcal{G}
-action that reduces to the maximal action
\mathbf{A}_{0}
under a restriction to
\mathcal{G}_{0}
as a proper subgroup. If the two hypotheses are exhaustive (i.e. simple) and correct, no data can fall outside
\mathcal{D}
even when the group action
\mathbf{A}_{\mathcal{X}}
can take observed data outside under some transformation. Thus, if any element
\tilde{g}\in\mathcal{G}\setminus\mathcal{G}_{0}
takes every point in
\mathcal{D}
outside of it, then the
\mathcal{G}
-action is compatible under definition
9
. To have a compatible fibre decomposition in this case, it is sufficient for the action
\mathbf{A}_{\mathcal{H}}
to act trivially for all
g\in\mathcal{G}_{0}
. Thus, we state this as an observation:

Observation 6
.

If
\mathcal{G}_{0}
is a proper subgroup of
\mathcal{G}
, and the restriction of
\mathbf{A}_{\mathcal{X}}
to
\mathcal{G}_{0}
reproduces
\mathbf{A}_{0}
then equivariant functions
f:\mathcal{D}\to\mathcal{H}
under the codomain action
\mathbf{A}_{\mathcal{H}}
have compatible fibre decomposition with
\lambda(\mathbf{X})
in
\mathcal{D}
if for any
\mathbf{X}\in\mathcal{D}
and
\tilde{g}\in\mathcal{G}\setminus\mathcal{G}_{0}
, we have
\mathbf{A}_{\mathcal{X}}(\tilde{g},\mathbf{X})\notin\mathcal{D}
, and
\mathbf{A}_{\mathcal{H}}(g_{0},\mathbf{H})=\mathbf{H}
for any
\mathbf{H}\in\text{Im}(f)
for
g_{0}\in\mathcal{G}_{0}
.

Evidently, there is no requirement on the action
\mathbf{A}_{\mathcal{H}}(\tilde{g},\mathbf{H})
for
\tilde{g}\in\mathcal{G}\setminus\mathcal{G}_{0}
since by construction no two elements in
\mathcal{D}
are connected by such elements. Nevertheless, these can effect function approximation when one extrapolates to data that is not strictly contained in the support
\mathcal{D}
. This could happen, for instance, in the presence of noise, or when the assumed probabilities do not exactly describe the true sampling distributions. As we are neither analysing the effect of noise nor the behaviour of equivariant models on data with different characteristics, we will restrict our discussions to invariant models since under the two observations above, one requires a trivial action on the co-domain.

5.3
Practical consequences

In machine learning literature, one has various notions of correctness
[
29
,
30
]
and optimality
[
31
]
. Nevertheless, the observations made on this work provides a complementary understanding of the theory of correct, incorrect, and extrinsic equivariance developed in ref.
[
29
,
30
]
with regards to binary classification. Explicitly, while the notion of correct and incorrect symmetries are tied to the support
\mathcal{D}
and the target function, extrinsic equivariance where the group action takes elements in
\mathcal{D}
to regions where there is zero probability can either be beneficial or detrimental. From observation
6
, we see that the utility of such extrinsic equivariance for binary classification tasks (or any general group invariant task) can be inferred by the relation of the stabilisers of the co-domain’s action to the group
\mathcal{G}_{0}
.

In fundamental applications, our findings provide a rigorous basis for intelligent design of architectures based on the likelihood ratio. Especially for new-physics searches in particle colliders like the Large Hadron Collider (LHC), except for the process of hadronisation, one has a concrete and verified first-principles understanding of the sampling probability distributions from the underlying Lagrangian. These are utilised in the rich ecosystem of simulation tools generally based on Monte-Carlo methods. Often due to this rich knowledge, the symmetries assumed in the forward process is utilised in the design of architectures. However, it has been found that these symmetries need to be explicitly reduced based on the inverse problem of statistical inference through likelihoods. A prototypical example is the classification of jets (collimated sprays of particles) to infer how they were produced in the initial collision. While the need for a strictly reduced continuous symmetry contained in the Lorentz group O(1,3) has been identified, state-of-the-art architectures generally consider permutation invariance over the entire jet constituents even when there is differentiating information like charge, and the type of quark that lead to the jet.

For instance, to distinguish a top jet from one originating from a quark or a gluon, information of the bottom quark provides a reduced permutation symmetry amongst different constituents. This difference arises from the initial stages of the physical evolution described by perturbative dynamics of the Lagrangian. A top quark decays into a bottom quark and a
W
boson, and a top jet must always contain a bottom quark. On the other hand, not all quarks and gluon jets consist of bottom quark but can arise if the initial particle was a bottom quark or if a gluon splits to an bottom-antibottom pair during the perturbative parton shower evolution. Therefore, one requires a reduced permutation symmetry to utilise this information efficiently. Explicitly, the set of constituents of the jet
J=\{p_{1},p_{2},....,p_{n}\}
partitions into two mutually exclusive subsets
S_{1}
and
S_{2}
, where the constituents in (say)
S_{1}
originate from the bottom quark, and those in
S_{2}
from the
W
boson. The invariant mass-squared
m^{2}=p^{\mu}.p_{\nu}
of the
S_{2}
set should fall near that of the
W
boson mass for a true top jet. Additionally, if any combination of four vectors between the two sets falls near the
W
boson’s mass it is not likely to originate from a top quark. Thus, this information is available when we have permutation invariants that do not mix the two sets.

Another example of the suitability of a reduced permutation symmetry is in quark-gluon classification, where due to the difference in colour charge and electric charge, there is a difference in the particle content of different species of particles. However, there is no first-principles understanding of since the low energy fragmentation process has large non-perturbative effects. Nevertheless, in terms of raw performance, there is a theoretical impetus to utilise reduced permutation symmetries based on the particle content of the jets.

6.2
Jet classification

As a concrete application to fundamental applications, we consider jet classification at the Large Hadron Collider and the effect of different symmetry groups. The general purpose detectors at LHC collects huge amounts of highly granular data based on the different components of the detector. These contain information about the four-momentum
p_{\mu}\equiv(E,p_{x},p_{y},p_{z})
, the charge, and the type of particles. Based on the likelihood ratio constructed out of the matrix-elements of a process, the largest continuous symmetry corresponds to the longitudinal invariant subgroup O(1,1)
{}_{l}\otimes
O(2)
t
where the O(1,1)
l

(E,p_{z})
and the
O(2)_{l}

(p_{y},p_{x})

p_{\mu}

Moreover, since there are group elements in O(1,3) (for instance transverse boosts) that do not belong to the longitudinal boost invariant subgroup that can change the likelihoods due to the finite detector resolutions, the Lorentz group is an incompatible symmetry. However, the longitudinal subgroup is not the maximal group
\mathcal{G}_{0}
since one has to consider permutation symmetries within the constituents. This depends on the particular tagging scenario and selection criteria. For both scenarios, we consider the combination of the two continuous groups with two permutation symmetries: one over the entire final state particles
S_{n}

\otimes_{t=1}^{N}S_{m_{t}}

7
Conclusions

In this work, we have presented a novel framework for characterising optimal group symmetries in binary classification tasks. Our theoretical analysis and experimental results demonstrate that the optimal selection of group symmetries, aligned with the intrinsic properties of the underlying data distribution, is critical for enhancing both generalisation and sample efficiency.

Leveraging the Neyman-Pearson optimality of monotonic invertible functions of the likelihood ratio, we argue that any binary classification task has an associated fibre decomposition on the support of the two probabilities. Thus compatibility of different symmetries with the likelihood ratio can be ascertained by the
minimal fibres
that any group invariance imposes on the domain via its orbits. In this sense, we identify the role of the maximal symmetry defined as the smallest group whose action on the domain has the largest minimal fibres decomposition compatible with the likelihood ratio on the support of the probabilities. Consequently, we find that when any group action on the domain results from a restriction of this maximal symmetry to some subgroup, any non-trivial group action on the co-domain (observation
5
) has incompatible fibre decompositions. On the other hand, we characterise properties of group actions that reduces to this maximal symmetry under a proper subgroup restriction which still maintains compatibility (observation
6
). Thus our work provides a concrete basis for the design of optimal and symmetric architectures based on the underlying likelihood ratio.

We demonstrated a basic example of how the insights can be put into action considering a toy binary classification scenario. Furthermore, we demonstrated how the observations can help guide symmetric architecture design for jet tagging at the Large Hadron Collider. Concretely, we identified a still overlooked feature in current literature where one considers permutation invariance over all jet constituents as suboptimal. For the decay of heavy resonant particles like the top quark, numerical evidence suggests that such reduced permutation symmetries becomes more important when the jet mass goes closer to its mass peak.

Future work will focus on extending this framework to multi-class classification problems and exploring the utility of our approach in other domains where symmetries play a crucial role, such as in physics-based simulations and high-dimensional data analysis. Additionally, we aim to investigate further the impact of noise and other real-world factors on the performance of group equivariant architectures to enhance their robustness and applicability in practical scenarios.

Appendix A
Details of architecture and training

Group equivariant message passing:

Our architecture is based on the group equivariant message passing operations of ref.
[
12
]
for the classical groups.
At the
l
-th stage of the message passing operation, the equivariant operations takes the scalar node representations
\mathbf{h}^{(l)}_{i}
and the vector node representation
\mathbf{x}^{(l)}_{i}
via the following equations:

\displaystyle\mathbf{m}^{(l+1)}_{ij}

\displaystyle=\Phi^{(l+1)}_{e}(\mathbf{h}^{(l)}_{i},\mathbf{h}^{(l)}_{j},\mathbf{e}_{ij}^{(l)})\quad,

(8a)

\displaystyle\mathbf{x}_{i}^{(l+1)}

\displaystyle=\mathbf{x}^{(l)}_{i}+\sum_{j\in\mathcal{N}(i)}\;\mathbf{v}^{(l)}_{ij}\;\Phi^{(l+1)}_{x}(\mathbf{m}^{(l+1)}_{ij})\quad,

(8b)

\displaystyle\mathbf{m}^{(l+1)}_{i}

\displaystyle=\sum_{j\in\mathcal{N}(i)}\;\mathbf{m}^{(l+1)}_{ij}\quad,

(8c)

\displaystyle\mathbf{h}^{(l+1)}_{i}

\displaystyle=\Phi^{(l+1)}_{h}(\mathbf{h}^{(l)}_{i},\mathbf{m}^{(l+1)}_{i})\quad.

(8d)

Where
\mathbf{v}^{(l)}_{ij}=\mathbf{x}^{(l)}_{i}-\mathbf{x}^{(l)}_{j}
for the inhomogeneous group E(3), and
\mathbf{v}^{(l)}_{i,j}=\mathbf{x}^{(l)}_{j}
for the rest. For the toy experiments, the scalar edge attributes are
\mathbf{e}^{(l)}_{ij}=(|\mathbf{x}^{(l)}_{i}-\mathbf{x}^{(l)}_{j}|^{2},\langle\mathbf{x}_{i},\mathbf{x}_{j}\rangle)
for the O(3) and O(2) groups while for the E(3) group it is
\mathbf{e}^{(l)}_{ij}=|\mathbf{x}^{(l)}_{i}-\mathbf{x}^{(l)}_{j}|^{2}
. For the jet classification tasks on four vectors
\mathbf{x}_{i}\equiv p_{\mu}=(E,p_{x},p_{y},p_{z})
, we consider the Minkowski metric
\eta_{\mu\nu}=\text{diag}(-1,1,1,1)
for the O(1,3) group, while for the O(1,1)
{}_{l}\otimes
O(2)
t
case, we additionally take
\eta^{l}_{\mu\nu}=\text{diag}(-1,0,0,-1)
and
\eta^{t}_{\mu\nu}=\text{diag}(0,1,1,0)
. For each metric signature, we construct three two-body invariants:
s_{ij}=\langle\mathbf{x}_{i}+\mathbf{x}_{j},\mathbf{x}_{i}+\mathbf{x}_{j}\rangle
,
d_{ij}=\langle\mathbf{x}_{i}-\mathbf{x}_{j},\mathbf{x}_{i}-\mathbf{x}_{j}\rangle
, and
c_{ij}=\langle\mathbf{x}_{i},\mathbf{x}_{j}\rangle
. To alleviate the exponentially separated scales present in parton showers, we use the function
R(e)=\text{sign}(e)\log(|e|+1)
for these three inner products.
Thus, we have three and nine edge scalars for the O(1,3) and O(1,1)
{}_{l}\otimes
O(2)
t
groups, respectively. The functions
\Phi_{e}^{(l+1)}
,
\Phi^{(l+1)}_{x}
and
\Phi^{(l+1)}_{h}
are MultiLayer Perceptrons (MLPs), with
\Phi^{(l+1)}_{x}
’s output a single value made to fall in the open unit interval via the sigmoid activation function.

Hyperparameters:

For all architectures, we have a total of three equivariant message passing operations which uses ReLU activation in all input and hidden layers. All MLPs have two hidden layers of sixty nodes for the toy experiments and one-hundred and twenty eight nodes for jet-classification.
The output of all
\Phi^{(l+1)}_{e}
also correspond to the same dimensions as the hidden layers which unambiguously fixes the input dimensions of the other two functions. While
\Phi^{(l+1)}_{x}
has a sigmoid output activation, we do not apply any non-linear activation to the other outputs. We forego the vector update at the final layer and use only the mean global representation of each scalar node representation as input to a classifier. For the reduced permutation symmetries, we concatenate the mean scalar representation over each factor in
\otimes_{t}\;S_{m_{t}}
. The classifier network has a single output node with sigmoid activation. With this set of hyperparameter values, the invariant models have 120k parameters while the equivariant ones have 130k parameters for the toy scenario. For jet classification with
S_{n}
symmetry, the O(1,1)
{}_{l}\otimes
O(2)
t
and O(1,3) models have 451k and 447k trainable parameters, respectively. For the reduced permutation symmetries, the O(1,3) models have 480k and 512k parameters for the top tagging and quark gluon tagging scenarios, respectively, while for the O(1,1)
{}_{l}\otimes
O(2)
t
group they have and 484k and 516k parameters.

Training:

All network training uses binary cross entropy loss and is trained ten times from random initialisation for hundred epochs. We use the
Adam
optimiser
[
35
]
with initial learning rate of 0.001, which decays by a factor of 0.5 if the validation loss has not improved over three epochs. We use
PyTorch
