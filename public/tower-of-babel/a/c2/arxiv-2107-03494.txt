The folded concave Laplacian spectral penalty learns block diagonal sparsity patterns with the strong oracle property
Iain Carmichael

Abstract
Structured sparsity is an important part of the modern statistical toolkit. We say a set of model parameters has block diagonal sparsity up to permutations if its elements can be viewed as the edges of a graph that has multiple connected components. For example, a block diagonal correlation matrix with K K blocks of variables corresponds to a graph with K K connected components whose nodes are the variables and whose edges are the correlations. This type of sparsity captures clusters of model parameters. To learn block diagonal sparsity patterns we develop the folded concave Laplacian spectral penalty and provide a majorization-minimization algorithm for the resulting non-convex problem. We show this algorithm has the appealing computational and statistical guarantee of converging to the oracle estimator after two steps with high probability, even in high-dimensional settings. The theory is then demonstrated in several classical problems including covariance estimation, linear regression, and logistic regression.



Keywords:

Structured sparsity;
spectral graph theory;
non-convex optimization;
majorization-minimization;

high-dimensions

1.2
Related literature

To our knowledge, we provide the first general purpose framework for block diagonal estimation that comes with strong statistical and computational guarantees.
Some existing bespoke methods for particular problems
(
Tan et al., 2015
;
Asteris et al., 2015
;
Devijver and Gallopin, 2018
)
come with strong guarantees, but these methods do not naturally extend to other statistical models.
The existing literature on Laplacian spectral constraints typically provides weak computational guarantees (e.g. eventual convergence to a stationary point), but no statistical guarantees
(
Nie et al., 2016
;
Egilmez et al., 2017
;
Nie et al., 2017
;
Kumar et al., 2019
;
Carmichael, 2020
)
.
The recent work of
Tam and Dunson, 2020
proposes a Laplacian spectral penalty for neural network regularization that is a special case of the FCLS penalty for a single Laplacian eigenvalue.

The FCLS penalty should not be confused with other penalties that make use of graph information
(
Smola and Kondor, 2003
;
Ando and Zhang, 2007
;
Sharpnack et al., 2012
;
Jiang et al., 2013
;
Li et al., 2020
)
.
In these approaches a fixed graph known ahead of time and is used to incorporate prior graph structural information.
In our setting the graph is learned and the Laplacian is used to uncover unknown graph structure.

1.3
Network constructions and notation

Suppose

Let

Definition 1.1
.

For a hollow symmetric matrix

\mathcal{BS}\left(A\right)_{ij}=\mathbf{1}\left(\text{nodes }i\text{ and }j\text{ are in the same connected component of }\mathcal{S}\left(A\right)\right).

)
.
For a symmetric matrix

For a weighted graph with positive edges whose adjacency matrix is given by

, the number of zero eigenvalues of

.
Furthermore, the indicator vectors (i.e. the vectors in

To index the edges we will write either

2
Block diagonal sparsity with Laplacian spectral regularization

Consider estimating a model parameter,
\beta\in\mathbb{R}^{D}
, by minimizing some loss function
\ell\left(\beta\right)
.
Throughout the body of the paper we assume the model parameter can be viewed as the edges of an adjacency matrix,
\mathcal{A}(\beta)\in\mathbb{R}^{d\times d}
where
D={d\choose 2}
.
Suppose we know a priori that the target model parameter has a block diagonal sparsity structure.
We would then like to solve the following block diagonally constrained problem,

\displaystyle\underset{\beta\in\mathbb{R}^{D}}{\textup{minimize}}

\displaystyle\ell(\beta)

(1)

\displaystyle\text{subject to }

\displaystyle\mathcal{A}(|\beta|)\text{ has at least K connected components},

where
K
is a tuning parameter.
This constraint set is non-convex and, even worse, seems combinatorial.

Problem (
1
) can be made amenable to continuous optimization approaches by recalling that the number of zero eigenvalues of the Laplacian count the number of connected components of a graph.
Thus the (combinatorial) sparsity constraint of (
1
) is equivalent to the (continuous) spectral constraint,
\lambda_{(K)}(\mathcal{L}(|\beta|))=0

(
Nie et al., 2016
;
Nie et al., 2017
;
Kumar et al., 2019
;
Carmichael, 2020
)
.
Instead of solving such a constrained problem, we develop a related penalized approach that leads to an efficient algorithm with strong statistical and computational guarantees.

2.1
Folded concave Laplacian spectral penalty

For a function
g_{\tau}:\mathbb{R}\to\mathbb{R}
and matrix
X\in\mathbb{R}^{d\times d}
we write
g_{\tau}\circ\lambda(X)=\sum_{i=1}^{d}g_{\tau}(\lambda_{i}(X))
.

Definition 2.1
.

For a vector
\beta\in\mathbb{R}^{{d\choose 2}}
and concave increasing function
g_{\tau}:\mathbb{R}\to\mathbb{R}
, the folded concave Laplacian spectral (FCLS) penalty is given by

s_{\tau}\left(\beta\right):=\frac{1}{2}g_{\tau}\circ\lambda(\mathcal{L}(|\beta|))=:\frac{1}{2}t_{\tau}\left(|\beta|\right).

(2)

Remark 2.1
.

We can check that
t_{\tau}\left(\beta\right)
is concave when
g_{\tau}
is concave e.g. by Theorem 7.17 of
Beck, 2017
.
Therefore
s_{\tau}(\cdot)
is concave in
|\beta|
hence the name “folded concave”.
Note that if
g_{\tau}
is the identity then
s_{\tau}\left(\beta\right)=||\beta||_{1}
i.e. the FCLS penalty reduces to the LASSO.

The FCLS penalty encourages sparsity in the Laplacian eigenvalues thus encouraging
\mathcal{A}(\beta)
to have multiple connected components.
We therefore consider the following penalized problem

\underset{\beta\in\mathbb{R}^{D}}{\textup{minimize}}\;\;\ell(\beta)+\frac{1}{2}g_{\tau}\circ\lambda(\mathcal{L}(|\beta|)).

(3)

Informally, the penalized Problem (
3
) is to the constrained Problem (
1
) as Lasso/SCAD penalized problems are to
L_{0}
constrained problems.

2.2
Local linear approximation algorithm

We next derive a majorization-minimization (MM) algorithm for Problem (

(

The key observation is that

Definition 2.2

We say a surrogate function

f(x)=Q(x|x)\text{ for all }x\text{ and }f(x)\leq Q(x|y)\text{ for all }x,y.

Since

The composition of this surrogate function with the absolute value function,
Q(\beta|b):=\overline{Q}(|\beta|\Big||b|)

Next we give an explicit form for the gradient,

For

3
Oracle properties of the FCLS penalty

This section studies two questions:

1.

When is the

(made precise below) a stationary point of the FCLS penalized Problem (
3

2.

When does the LLA algorithm find the block oracle solution after exactly two steps?

Section

answers the first question, thus providing theoretical guarantees for a theoretical estimator that we are by no means guaranteed to find.
Section

)

Sections

3.1
When the oracle is a stationary point

Our goal is to estimate some “target” parameter,
\beta^{*}\in\mathbb{R}^{D}
where
D={d\choose 2}
.
For example,
\beta^{*}
might be the upper triangular entries of a correlation matrix for a
d
dimensional random vector.

The results below depend on the following graph quantities.
Let
\mathcal{G}^{*}
be the binary graph whose adjacency matrix is given by the support graph,
\mathcal{S}\left(\mathcal{A}(\beta^{*})\right)
.
Let
\mathcal{S}^{*}
be the connected component support set i.e.
\mathcal{S}^{*}=\{(i,j):\mathcal{BS}\left(\mathcal{A}(\beta^{*})\right)_{ij}=1,i<j\}
; this is the support set we will attempt to estimate.
Also let
K_{\text{cc}}^{*}
be the number of connected components of
\mathcal{G}^{*}
, let
d^{*}_{\text{max}}
be the largest number of nodes in a connected component and let
d^{*}_{\text{min}}
be the smallest size of a connected component that is not an isolated vertex.

A
block oracle
estimator,
\widehat{\beta}^{\text{oracle}}
, is a solution to the following constrained problem

\displaystyle\underset{\beta\in\mathbb{R}^{D}}{\textup{minimize}}

\displaystyle\ell(\beta)

(8)

\displaystyle\text{subject to }

\displaystyle\beta_{\mathcal{S}^{*^{C}}}=0.

In other words, a block oracle knows the true between block edges for the target parameter.
Note this estimator is unaware of any within block edges that are zero.
For simplicity we assume Problem (
8
) has a unique solution,
\widehat{\beta}^{\text{oracle}}
, which satisfies the first order necessary conditions
\nabla_{\mathcal{S}^{*}}\ell(\widehat{\beta}^{\text{oracle}})=0
.

We next define two sets specifying the values of
\beta
that satisfy regularity conditions.
Let

)

7
Discussion

This paper makes four contributions:
we propose the FCLS penalty,
provide a majorization-minimization algorithm based on a weighted Lasso surrogate function,
develop a theoretical framework showing this penalty obeys the strong oracle property after 2 steps of the LLA algorithm,
and show this theory applies to several standard statistical models.
The two step convergence guarantees in Sections
4
and
5
apply in ultra-high dimensional settings with an appropriate initializer (e.g. the Lasso estimate). The theory should apply to many statistical models beyond those studied in these two sections.

The simulations in Section
6
show that the FCLS penalized models outperform competing methods such as hard-thresholding or the entrywise SCAD penalty.
The rates provided in Sections
4
and
5
, however, are often worse than known rates for the entrywise competitors
(
Fan et al., 2014
)
.
These two facts suggest there is room for improvement in the theory of FCLS penalized models.

Finally we point out a few additional lines of future inquiry.
Appendix
A
sketches extensions of the FCLS penalty to rectangular and multi-array settings, which may be interesting for a variety of applications such as multi-response regression. While we focus on the penalized estimator, Problem (
3
), the results in Section
3
can be adapted to a constrained formulation of this problem similar to ones considered in
(
Nie et al., 2016
;
Nie et al., 2017
;
Kumar et al., 2019
)
.
In reality we may not expect
\beta^{*}
to be perfectly block diagonal, but rather approximately block diagonal e.g. when
||\lambda\left(\mathcal{L}(|\beta^{*}|)\right)||_{q}
is small for some
q\in[0,1]
.
Extending our theory to this approximately block diagonal setting may be useful.
Decomposing
\beta=\beta_{\text{block diag}}+\beta_{\text{sparse}}
into the sum of a block diagonal plus sparse vector – in the spirit of
(
Candès et al., 2011
;
Tan et al., 2014
)
– may also be of interest for applications.

Appendix A

In the body of the paper we assumed

Then we used the FCLS penalty to impose a block diagonal structure on

This section extends this idea to block diagonal rectangular matrices and multi-arrays (see Figure

We sketch the main ideas, but do not pursue a detailed investigation here.

A.1
Rectangular matrices and the bipartite FCLS penalty

Suppose
\beta\in\mathbb{R}^{RC}

\textsc{mat}(\beta)\in\mathbb{R}^{R\times C}

Let

\mathcal{A}_{\text{bp}}(\beta)=\begin{bmatrix}0&\textsc{mat}(\beta)\\
\textsc{mat}(\beta)^{T}&0\end{bmatrix}\in\mathbb{R}^{(R+C)\times(R+C)}

(49)

\textsc{mat}(x)

Forcing

to have multiple connected components forces
\textsc{mat}(\beta)
to have a block diagonal structure e.g. see Figure

Let

s_{\text{bp},\tau}(\beta):=\frac{1}{2}g_{\tau}\circ\lambda(\mathcal{L}(\mathcal{A}_{\text{bp}}(|\beta|))),

(50)

FCLS penalty.
We can then use the LLA algorithm presented in Section

to solve the following problem

\underset{\beta\in\mathbb{R}^{RC}}{\textup{minimize}}\;\;\ell(\beta)+s_{\text{bp},\tau}(\beta).

(51)

A.2
Multi-arrays and the hypergraph FCLS penalty

In the previous section we saw how to view a rectangular matrix as a bipartite graph.
There we viewed the rows and columns as vertices and the edges as connections between two vertices.
In this section we start with a multi-array
A\in\mathbb{R}^{d^{(1)}\times\dots\times d^{(V)}}
and show how to view it as a graph whose connected components define a multi-array block diagonal structure.
The key step is to view the entries of
A
as the hyperedges of a certain hypergraph.
Then we can follow the outline of the previous section and develop a multi-array version of the FCLS penalty.
The discussion in this section closely follows
(
Zhou et al., 2006
;
Carmichael, 2020
)
.

A
hypergraph
is a generalization of a graph where the hyperedges can connect more than two vertices
(
Berge, 1984
;
Zhou et al., 2006
)
.
Formally a binary hypergraph
\mathcal{H}=(\mathcal{V},\mathcal{E})
is a collection of vertices
\mathcal{V}
and hyperedges
\mathcal{E}
where each hyperedge is a subset of
V
with at least two elements (we do not allow self-loops here!)
For example, a binary graph is a hypergraph where each subset in
\mathcal{E}
has exactly two elements.
A weighted hypergraph
\mathcal{H}=(\mathcal{V},\mathcal{E},\mathcal{W})
has an additional map
\mathcal{W}:\mathcal{E}\to\mathbb{R}_{+}
that assigns a positive number to each hyperedge (we only consider positive weights for simplicity).

Next we interpret a multi-array
14
14

14

We will assume the entries of
A
are positive; we can always take absolute values to make this happen!

A\in\mathbb{R}^{d^{(1)}\times\dots\times d^{(V)}}_{+}
as a hypergraph,
\mathcal{H}(A)
where the vertices are

\mathcal{V}(A):=\{(v,i):v\in[V],i\in[d^{(v)}]\}

i.e. the generalization of rows and columns to multi-arrays.
Note
|\mathcal{V}(A)|=s:=\sum_{v=1}^{V}d^{(v)}
.
The hyperedges correspond to the non-zero entries of
A
.
In other words the hyperedge
\{(1,i^{(1)}),\dots,(V,i^{(V)})\}\subseteq\mathcal{V}(A)
is present if and only if
A_{i^{(1)},\dots,i^{(V)}}\neq 0
.
Note each present hyperedge has exactly
V
elements; each edge contains exactly one element from each axis of
A
.
The hyperedge weights are then given by the entries of
A
.

We can identify the blocks of the multi-array
A
with the connected components of the hypergraph
\mathcal{H}(A)
.
For example, the multi-array in Figure
1(c)
has 4 connected components.
The first connected component is
\{(1,1),(2,1),(3,1)\}
and corresponds to the bottom left red block i.e. the entry
A_{111}
.
The second connected component is
\{(v,j):j=2,3,v=1,2,3\}
and corresponds to the green block whose entries are
\{A_{ijk}:i,j,k=2,3\}
.
The isolated vertex
(1,6)
is also a connected component corresponding to an empty block.

Next we map the weighted hypergraph of
A
into a weighted
V
-partite graph that we call the
hypergraph adjacency matrix
.
15
15

15

This adjacency matrix implicitly defines a weighted, undirected graph.

Let
\mathcal{HA}(A)\in\mathbb{R}^{s\times s}
be a hollow symmetric matrix whose rows/columns are indexed by the vertices,
\mathcal{V}(A)
.
The entries of this matrix correspond to a (weighted) graph where edges can only occur between two vertices on different axes of
A
e.g.
(a,k^{(a)})
and
(b,k^{(b)})
where
a\neq b
.
The weight of such an edge is equal to

\mathcal{HA}(A)_{(a,k^{(a)}),(b,k^{(b)})}=\sum_{v\in[V]/\{a,b\}}\sum_{j^{(v)}=1}^{d^{(v)}}\mathcal{HA}(A)_{j^{(1)},\dots,k^{(a)},\dots,k^{(b)},\dots j^{(V)}}.

(52)

In other words, we take a two-dimensional slice of
A
by fixing axes
a,b
and squash the other dimensions down into this slice via summation.
See Figure 10.c of
Carmichael, 2020
.
Note
\mathcal{HA}(A)
is equivalent to the hypergraph adjacency matrix defined at the end of Section 2 in
(
Zhou et al., 2006
)
.
This graph captures the connected component information of
\mathcal{H}(A)
.

Proposition A.1
.

There is a one-to-one correspondence between the connected components of the hypergraph
\mathcal{H}(A)
and the connected components of the graph
\mathcal{HA}(A)
.

The advantage of working with the graph
\mathcal{HA}(A)
is we can use the previously developed Laplacian approach to imposing a connected component structure.
In other words, the spectrum of
\mathcal{L}(\mathcal{HA}(A))
captures the connected components of
\mathcal{HA}(A)
and therefore also
\mathcal{H}(A)
.

Finally suppose we have a model parameter
\beta\in\mathbb{R}^{p}
where
p:=\prod_{v=1}^{V}d^{(v)}
that can be viewed as the entries of a multi-array
\textsc{arr}(x)\in\mathbb{R}^{d^{(1)}\times\dots\times d^{(V)}}
.
We then define the
hypergraph folded Laplacian spectral penalty
as

s_{\text{hyper},\tau}(\beta):=\frac{1}{2}g_{\tau}\circ\lambda\circ\mathcal{L}\circ\mathcal{HA}\circ\textsc{arr}(|\beta|).

(53)

We can use the LLA algorithm presented in Section
2.2
with minor modifications to solve the following problem

\underset{\beta\in\mathbb{R}^{p}}{\textup{minimize}}\;\;\ell(\beta)+s_{\text{hyper},\tau}(\beta)

(54)

that will impose a block diagonal structure on
\textsc{arr}(|\beta|)
.

Appendix B
Specifying the largest value for the FCLS tuning parameter

In practice we need to compute the tuning path of solutions to the FCLS penalized Problem (
3
) over a range of
\tau
values in
[0,\tau_{\text{max}}]
.
For Lasso penalized problems, we can often find an intelligent choice for the maximal tuning parameter
(
Friedman et al., 2010
)
.

Definition B.1
.

For a given loss function
\ell(\cdot)
we say
\gamma_{\text{lasso-killer-lbd}}\in\mathbb{R}_{+}
is a killer Lasso lower bound if
16
16

16

This value does not have to exist!
for all weight vectors
c\in\mathbb{R}^{D}_{+}
satisfying
\min(c)\geq\gamma_{\text{lasso-killer-lbd}}
the solution to the following weighted Lasso problem is 0

\underset{\beta\in\mathbb{R}^{D}}{\textup{minimize}}\;\;\ell(\beta)+\sum_{j=1}^{D}c_{j}|\beta_{j}|.

(55)

We are not required to find the possible smallest value of
\gamma_{\text{lasso-killer-lbd}}
.
For convex loss functions

\gamma_{\text{lasso-killer-lbd}}=||\nabla\ell(0)||_{\text{max}},

(56)

is a killer Lasso lower bound.
17
17

17

To see this note
0
is a stationary point if there is a solution to the first order necessary condition
\nabla_{\beta}\ell(0)+c\odot\nabla||0||_{1}=0
. Recalling the form of the sub-gradient of the
L_{1}
norm we obtain the stated bound. Of course we need something like strict convexity to guarantee that 0 is the
unique
stationary point.

For the loss functions considered in Sections
4
and
5
we have the following explicit expressions:

•

For the Frobenius norm loss function in (
28
),
\gamma_{\text{lasso-killer-lbd}}=||\widehat{\beta}^{\text{ok}}||_{\text{max}}
.

•

For the least squares loss function without an intercept in (
39
),
\gamma_{\text{lasso-killer-lbd}}=\frac{1}{n}||X^{T}y||_{\text{max}}
.

•

For the logistic loss function without an intercept in (
44
),
\gamma_{\text{lasso-killer-lbd}}=\frac{1}{n}||X^{T}(\frac{1}{2}\mathbf{1}_{n}-y)||_{\text{max}}
.

We can use a killer Lasso lower bound to obtain the largest reasonable tuning parameter value for the LLA algorithm from Section
2.2
.

Proposition B.1
.

Let
\widehat{\beta}^{\text{initial}}\in\mathbb{R}^{D}
be the initializer to the LLA algorithm for Problem (
3
) where
g_{\tau}(\cdot)
satisfies Definition
3.1
.
Suppose
\gamma_{\text{lasso-killer-lbd}}
is a killer lasso lower bound and let

\tau_{\text{FCLS-killer-lbd}}:=\max\left(\frac{\lambda_{\text{max}}\left(\mathcal{L}(|\widehat{\beta}^{\text{initial}}|)\right)}{b_{1}},\frac{\gamma_{\text{lasso-max}}}{a_{1}}\right).

(57)

Then for all
\tau\geq\tau_{\text{FCLS-killer-lbd}}
the LLA algorithm initialized from

Lemma C.2
.

Let

be symmetric and positive semi-definite.
Suppose

Proof.

of Proposition

Following the discussion in Section

and the fact that

is concave we need only check the super-gradient formula (

is a surrogate function.

Let

be given by

.
By Theorem 6 of
(

, we have the super-differential formula

where

Let

be any matrix of eigenvectors of

and

where the final equality is readily verified using (
74
).

\frac{d}{dx}t_{\tau}\left(x\right)=\mathcal{M}(V,w)
.
We therefore conclude
Q
is a surrogate function.
Note that

is convex since each entry of
\mathcal{M}(V,w)
is non-negative by (

Next we show the choice of eigenvectors does not matter.
Let

First note that flipping the sign of a column of

Thus if all of the eigenvalues are unique the claim follows.

WLOG assume that the first
K

Then

for some orthonormal matrix

\displaystyle||V(i,:)-V(j,:)||_{2,w}^{2}

\displaystyle=||V_{1:K}(i,:)-V_{1:K}(j,:)||_{2,w_{1:K}}^{2}+||V_{(K+1):D}(i,:)-V_{(K+1):D}(j,:)||_{2,w_{(K+1):D}}^{2}

Finally we check that majorizing at

Finally, suppose
