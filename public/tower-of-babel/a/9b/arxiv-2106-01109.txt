Improvement over Pinball Loss Support Vector Machine
Pritam Anand, Reshma Rastogi and Suresh Chandra

Abstract
Recently, there have been several papers that discuss the extension of the Pinball loss Support Vector Machine (Pin-SVM) model, originally proposed by Huang et al., [ 1 ] [ 2 ] . Pin-SVM classifier deals with the pinball loss function, which has been defined in terms of the parameter τ \tau . The parameter τ \tau can take values in [ − 1 , 1 ] [-1,1] . The existing Pin-SVM model requires to solve the same optimization problem for all values of τ \tau in [ − 1 , 1 ] [-1,1] . In this paper, we improve the existing Pin-SVM model for the binary classification task. At first, we note that there is major difficulty in Pin-SVM model (Huang et al. [ 1 ] ) for − 1 ≤ τ < 0 -1\leq\tau<0 . Specifically, we show that the Pin-SVM model requires the solution of different optimization problem for − 1 ≤ τ < 0 -1\leq\tau<0 . We further propose a unified model termed as Unified Pin-SVM which results in a QPP valid for all − 1 ≤ τ ≤ 1 -1\leq\tau\leq 1 and hence more convenient to use. The proposed Unified Pin-SVM model can obtain a significant improvement in accuracy over the existing Pin-SVM model which has also been empirically justified by extensive numerical experiments with real-world datasets.



I
Introduction

Support Vector Machines (SVMs)
[
3
]
[
4
]
[
5
]
are popular machine learning algorithms. These algorithms are based on Structural Risk Minimization (SRM) principle
[
4
]
. For binary classification problem with given training set
T=\{(x_{i},y_{i}):x_{i}\in\mathbf{R}^{n},y_{i}\in\{-1,1\},i=1.2,...,\textit{l}\}
, SVM models obtain a separating kernel generated decision function
w^{T}\phi(x_{i})+b=0
by minimizing a good trade-off between the empirical risk and model complexity in its optimization problem. SVM models use a loss function to measure the empirical risk of the given training set. For minimizing the model complexity, SVM models minimize a regularization term in their optimization problem.

The standard C-SVM model minimizes the Hinge loss function along with the
L_{2}
-norm regularization in its formulation. Thus, it minimizes

\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}L_{Hinge}(1-y_{i}(w^{T}\phi(x_{i})+b)),

(1)

where
L_{Hinge}=max(u,0)
is the Hinge loss function and
C_{0}\geq 0
is the user supplied parameter. The use of Hinge loss function in C-SVM model makes it ignore the data points which satisfy
y_{i}(w^{T}\phi(x_{i})+b)>1
. There are few data points satisfying
y_{i}(w^{T}\phi(x_{i})+b)\leq 1
, which contribute for the empirical risk. These data points are called ‘support vectors’ and lie near the boundary of the separating hyperplane
w^{T}\phi(x)+b=0
. The separating hyperplane in C-SVM model is only constructed by using these support vectors. This causes the sparsity in C-SVM model. But, data points near the boundary of the separating hyperplane may be noisy which can mislead the resulting separating hyperplane.
To improve the C-SVM model, Huang et al.
[
2
]
have suggested to use the pinball loss function
[
6
]
in SVM model. For the classification problem, the pinball loss function is given by

L^{\tau\geq 0}_{pin}(u)=\begin{cases}u,~~\mbox{if}~~u\geq 0,\\
-\tau u,otherwise,\end{cases}

(2)

where
0\leq\tau\leq 1
is its parameter. For
\tau=0
, the pinball loss function reduces to the Hinge loss function. For
\tau=1
, it reduces to the
l_{1}
loss function.

The Pin-SVM model (Huang et al.,
[
2
]
) minimizes the empirical risk using the pinball loss function along with the
L_{2}
-norm regularization in its formulation. This leads to the following optimization problem

\displaystyle\min_{(w,b)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}L^{\tau\geq 0}_{pin}(1-y_{i}(w^{T}\phi(x_{i})+b)),

which can be equivalently converted to the following optimization problem

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}\xi_{i}

(3)

subject to,

\displaystyle\hskip-113.81102pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i},

\displaystyle\hskip-113.81102pty_{i}(w^{T}\phi(x_{i})+b)\leq 1+\frac{\xi_{i}}{\tau},

where
\xi_{1},\xi_{2},..,\xi_{l}
are slack variables and
C_{0},~0\leq\tau\leq 1
are user supplied parameters.

The pinball loss function in Pin-SVM model penalizes (assigns positive risk) every data point but, with different rate. Data points satisfying
y_{i}(w^{T}\phi(x_{i})+b)\leq 1
are penalized with unit rate and other data points are penalized with comparatively lower rate
\tau
. This penalization in Pin-SVM model causes it to also minimize the scatter of data points along the separating hyperplane. But then, it takes away the very nice property of SVM, namely sparsity. However, the Pin-SVM model is a general SVM model in the sense that it can reduce to the standard C-SVM model for its parameter
\tau=0
.

To reduce the effect of the unbalanced class labeling, we consider a
l
-dimensional vector
C=(C_{1},C_{2},\ldots C_{l})
, rather than a single constant
C_{0}
, such that

C_{i}=\begin{cases}C_{0},~~~~~~~~~~~~y_{i}=+1,\\
pC_{0},~~~~~~~~~~~~y_{i}=-1,\end{cases}

(4)

where
p
is defined as

p=~\frac{\mbox{number of data points on `Class +1'}}{\mbox{number of data points in `Class -1'}}

and seek the solution of following optimization problem

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+\sum_{i=1}^{l}C_{i}\xi_{i}

(5)

subject to,

\displaystyle\hskip-113.81102pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i},

\displaystyle\hskip-85.35826pty_{i}(w^{T}\phi(x_{i})+b)\leq 1+\frac{\xi_{i}}{\tau},\tau\geq 0.

Rather than solving the primal problem (
5
), we prefer to solve its Wolfe’s dual problem, which is obtained as follows

\displaystyle\min_{(\alpha,\beta)}\frac{1}{2}\sum_{i=1}^{l}\sum_{j=1}^{l}(\alpha_{j}-\beta_{j})(\alpha_{i}-\beta_{i})y_{i}y_{j}K(x_{i},x_{j})

(6)

\displaystyle\hskip-312.9803pt-\sum\limits_{i=1}^{l}(\alpha_{i}-\beta_{i})

subject to,

\displaystyle\hskip-290.21811pt\sum\limits_{i=1}^{l}(\alpha_{i}-\beta_{i})y_{i}=0,

\displaystyle\hskip-213.39566ptC_{i}-\alpha_{i}-\frac{1}{\tau}\beta_{i}=0,~~for~i=1,2,..,l,

\displaystyle\hskip-227.62204pt\alpha_{i}\geq 0,~~\beta_{i}\geq 0,~~for~i=1,2,..,l.

More information about properties of pinball loss function and Pin-SVM model can be found in (Huang et al.,
[
2
]
).

describes the optimization problem of Pin-SVM model for
-1\leq\tau<0
as proposed in (Hunag et al.,
[
1
]
).
In section

, we derive the right optimization problem for Pin-SVM model for
-1\leq\tau<0
. In section

II
Pinball loss function with negative
\tau
value and SVM model

Huang et al. extended the pin-ball loss function for negative
\tau
using the same expression in their work (Huang et al.
[
1
]
) . The pinball loss function with negative
\tau
is given by

L^{\tau\leq 0}_{pin}(u)=\begin{cases}u,~~~~~~\mbox{if}~~u\geq 0.\\
-\tau u,~~othewise.\\
\end{cases}

(7)

The above pinball loss function (
7
) is convex loss function for
\tau\geq-1
.
Huang et al. have formulated the Pin-SVM model for
-1\leq\tau<0
using

\displaystyle\min_{(w,b)}\frac{1}{2}||w||_{2}^{2}+C\sum_{i=1}^{l}L^{\tau\leq 0}_{pin}(1-y_{i}(w^{T}\phi(x_{i})+b)).

(8)

For minimizing (
8
), they have chosen to minimize the following Quadratic Programming Problem (QPP)

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+\sum_{i=1}^{l}C_{i}\xi_{i}

(9)

subject to,

\displaystyle\hskip-99.58464pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i},

\displaystyle\hskip-91.04881pty_{i}(w^{T}\phi(x_{i})+b)\leq 1+\frac{\xi_{i}}{\tau},

where
-1\leq\tau<0
is user supplied parameter.
It should be noted that, Huang et al. have used the same Pin-SVM optimization problem for both positive and negative values of
\tau
in
[-1,1]
. Contrary to this, we claim in the next section of this paper that the Pin SVM model for
-1\leq\tau<0
requires the solution of a QPP which is different from (
9
).

III
Pin-SVM with negative
\tau
values

This paper improves the existing Pin-SVM model for
-1\leq\tau<0
(Huang et al.,
[
1
]
). We shall show that the optimization problem of existing Pin-SVM model for
-1\leq\tau<0
obtained in (Huang et al.,
[
1
]
) is not correct and derive the right optimization problem for it.

The pinball loss function (
7
) has been used in (Huang et al.,
[
1
]
[
2
]
) for
-1\leq\tau\leq 1
.
At first, we consider the loss function

L_{pin}^{\tau}(u)=max(u,-\tau u)

(10)

for
-1\leq\tau\leq 1
. For
-1\leq\tau\leq 1
, we can obtain

max(u,-\tau u)=\begin{cases}u,~~~\mbox{if}~u\geq 0.\\
-\tau u,\mbox{ otherwise}.\end{cases}

It makes us realize that the pinball loss function is equivalent to the
max(u,-\tau u)
for
-1\leq\tau\leq 1
.

Now, we shall state and justify our claim about the existing Pin-SVM model with
-1\leq\tau<0
. We claim that the Pin-SVM model with
-1\leq\tau<0
(problem (
8
)) is not equivalent to the solving QPP (
9
) used in (Huang et al.,
[
1
]
) and vice-versa. The justification of this claim is detailed as follows.

The Pin-SVM for
-1\leq\tau<0
(problem (
8
)) is equivalent to

\displaystyle\min_{(w,b)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}max((1-y_{i}(w^{T}\phi(x_{i})+b)),

\displaystyle-\tau(1-y_{i}(w^{T}\phi(x_{i})+b)))\mbox{~where~}-1\leq\tau<0.

(11)

Let us consider slack variables
\xi_{i}=max((1-y_{i}(w^{T}\phi(x_{i})+b)),-\tau(1-y_{i}(w^{T}\phi(x_{i})+b))),i=1,2,...,\textit{l}
. Then, the optimization problem (
11
) of Pin-SVM can be given by

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}\xi_{i}

(12)

subject to,

\displaystyle\hskip-184.9429pt\xi_{i}\geq 1-y_{i}(w^{T}\phi(x_{i})+b),

\displaystyle\hskip-108.12047pt\xi_{i}\geq-\tau(1-y_{i}(w^{T}\phi(x_{i})+b)),-1\leq\tau<0.

Since
\tau<0
in above optimization problem (
12
), so its second constraint

\displaystyle\xi_{i}\geq-\tau(1-y_{i}(w^{T}\phi(x_{i})+b))\mbox{~is equivalent to~}

\displaystyle\hskip-312.9803pty_{i}(w^{T}\phi(x_{i})+b)\geq 1+\frac{\xi_{i}}{\tau}.

Similarly, the first constraint of problem (
12
)

\displaystyle\xi_{i}\geq 1-y_{i}(w^{T}\phi(x_{i})+b)\mbox{~is equivalent to~}

(13)

\displaystyle\hskip-256.0748pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i}.

Now, optimization problem (
12
) can be obtained as

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}\xi_{i}

(14)

subject to,

\displaystyle\hskip-128.0374pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i},

\displaystyle\hskip-128.0374pty_{i}(w^{T}\phi(x_{i})+b)\geq 1+\frac{\xi_{i}}{\tau},

where
-1\leq\tau<0
,
which is different from QPP (
9
) used in (Huang et al.,
[
1
]
). It also infers that QPP (
14
) is the actual minimizer of the Pin-SVM model with
-1\leq\tau<0
(problem (
8
)).

III-A

Solution of QPP for Pin-SVM with negative
\tau

For unbalanced training set, the Pin-SVM optimization problem with
-1\leq\tau<0
can also be modified as

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+\sum_{i=1}^{l}C_{i}\xi_{i}

(15)

subject to,

\displaystyle\hskip-128.0374pty_{i}(w^{T}\phi(x_{i})+b)\geq 1-\xi_{i},

\displaystyle\hskip-128.0374pty_{i}(w^{T}\phi(x_{i})+b)\geq 1+\frac{\xi}{\tau},

where
C_{i}
are as defined in (
4
) and
-1\leq\tau<0
.
In order to find the solution of above primal problem, we need to derive its corresponding Wolfe‘s dual problem. For this, we construct the Lagrangian function for primal problem (
15
) as follows

\displaystyle L(w,b,\xi_{i},\alpha_{i},\beta_{i})=\frac{1}{2}||w||_{2}^{2}+C\sum_{i=1}^{l}\xi_{i}

\displaystyle-\sum_{i=1}^{l}{\alpha_{i}}(y_{i}(w^{T}\phi(x_{i})+b)-1+\xi_{i})

\displaystyle-\sum_{i=1}^{l}{\beta_{i}}(y_{i}(w^{T}\phi(x_{i})+b)-1-\frac{\xi_{i}}{\tau}).

(16)

We list some relevant Karush-Kuhn-Tucker(KKT) conditions for the optimization problem (
15
) as follows

\displaystyle\hskip-56.9055pt\frac{\partial L}{\partial w}=w-\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})y_{i}\phi(x_{i})=0,

(17)

\displaystyle\hskip-99.58464pt\frac{\partial L}{\partial b}=\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})y_{i}=0,

(18)

\displaystyle\hskip-42.67912pt\frac{\partial L}{\partial\xi_{i}}=C-\alpha_{i}+\frac{1}{\tau}\beta_{i}=0,i=1,2,..,l.

(19)

Using the KKT conditions, the Wolfe’s dual of the primal problem (
15
) can be obtained as follows

\displaystyle\min_{(\alpha,\beta)}\frac{1}{2}\sum_{i=1}^{l}\sum_{j=1}^{l}(\alpha_{j}+\beta_{j})(\alpha_{i}+\beta_{i})y_{i}y_{j}(\phi(x_{i})^{T}\phi(x_{j}))

\displaystyle\hskip-341.43306pt-\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})

subject to,

\displaystyle\hskip-284.52756pt\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})y_{i}=0,

\displaystyle\hskip-298.75394ptC-\alpha_{i}+\frac{1}{\tau}\beta_{i}=0,

\displaystyle\hskip-256.0748pt\alpha_{i}\geq 0,~~\beta_{i}\geq 0,i=1,2,..,l.

By using a positive semi-definite kernel
K(x_{i},x_{j})=\phi(x_{i})^{T}\phi(x_{j})
, satisfying Mercer condition (Mercer,
[
7
]
), the above dual problem can be obtained as

\displaystyle\min_{(\alpha,\beta)}\frac{1}{2}\sum_{i=1}^{l}\sum_{j=1}^{l}(\alpha_{j}+\beta_{j})(\alpha_{i}+\beta_{i})y_{i}y_{j}K(x_{i},x_{j})

(20)

\displaystyle\hskip-284.52756pt-\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})

subject to,

\displaystyle\hskip-298.75394pt\sum\limits_{i=1}^{l}(\alpha_{i}+\beta_{i})y_{i}=0,

\displaystyle\hskip-298.75394ptC-\alpha_{i}+\frac{1}{\tau}\beta_{i}=0,

\displaystyle\hskip-256.0748pt\alpha_{i}\geq 0,~~\beta_{i}\geq 0,~~i=1,2,..,l.

After obtaining the solution of the dual problem (
20
), the value of
w
can be obtained from the KKT condition (
17
) as follows

\displaystyle w=\sum_{i=1}^{l}(\alpha_{i}+\beta_{i})y_{i}\phi(x_{i}).

(21)

Let us now define the following set

~~~~~~~~~~~~~~~~~S=\{i:\alpha_{i}>0,\beta_{i}>0\}
,

Using the complementary slackness condition, we compute the values of the
b
for each
i\in S
, from

b=y_{i}-w^{T}\phi(x_{i})=y_{i}-\sum_{j=1}^{l}(\alpha_{j}+\beta_{j})y_{j}K(x_{j},x_{i})

(22)

and take their average value as the final value of the bias
b
.
For given test point
x\in{R}^{n}
, the decision function is obtained as

\displaystyle f(x)=sign(w^{T}\phi(x)+b)

(23)

\displaystyle\hskip-113.81102pt=sign~(\sum\limits_{j=1}^{l}(\alpha_{j}+\beta_{j})y_{j}K(x_{j},x)+b).

IV
A unified QPP for solving Pin-SVM problem

We can observe that minimizing the Pin-SVM problem with positive and negative
\tau
value in
[-1,1]
results into two different QPPs. Minimizing different QPPs for negative and positive
\tau
value in Pin-SVM problem may not be handful for searching best
\tau\in[-1,1]
, which corresponds to the optimal accuracy. Taking motivation from this, we also propose a unified optimization problem which can obtain the solution of Pin-SVM problem without bothering about the sign of its parameter
\tau
. For a given
\tau\in[-1,1]
, the Pin-SVM model should minimize

\displaystyle\min_{(w,b)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}(max(1-y_{i}(w^{T}\phi(x_{i})+b)

\displaystyle,-\tau(1-y_{i}(w^{T}\phi(x_{i})+b)).

After introducing the slack variable
\xi_{i}=max(1-y_{i}(w^{T}\phi(x_{i})+b),-\tau(1-y_{i}(w^{T}\phi(x_{i})+b))
, the Pin-SVM problem becomes

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+C_{0}\sum_{i=1}^{l}\xi_{i}

(24)

subject to,

\displaystyle\hskip-128.0374pt\xi_{i}\geq 1-y_{i}(w^{T}\phi(x_{i})+b),

\displaystyle\hskip-113.81102pt\xi_{i}\geq-\tau(1-y_{i}(w^{T}\phi(x_{i})+b)).

For the unbalanced training set, the suitable Pin-SVM problem can be given by

\displaystyle\min_{(w,b,\xi)}\frac{1}{2}||w||_{2}^{2}+\sum_{i=1}^{l}C_{i}\xi_{i}

(25)

subject to,

\displaystyle\hskip-128.0374pt\xi_{i}\geq 1-y_{i}(w^{T}\phi(x_{i})+b),

\displaystyle\hskip-99.58464pt\xi_{i}\geq-\tau(1-y_{i}(w^{T}\phi(x_{i})+b)).

We obtain the Lagrangian function for the primal problem (
25
) as follow

\displaystyle L(w,b,\xi_{i},\alpha_{i},\beta_{i})=\frac{1}{2}||w||^{2}+\sum_{i=1}^{l}C_{i}\xi_{i}

\displaystyle-\sum_{i=1}^{l}{\alpha_{i}}(y_{i}(w^{T}\phi(x_{i})+b)-1+\xi_{i})

(26)

\displaystyle\hskip-156.49014pt-\sum\limits_{i=1}^{l}{\beta_{i}}(\tau(1-y_{i}(w^{T}\phi(x_{i})+b))+\xi_{i}).

We list some relevant KKT optimality conditions for the optimization problem (
25
) as follows.

\displaystyle\hskip-56.9055pt\frac{\partial L}{\partial w}=w-\sum\limits_{i=1}^{l}(\alpha_{i}-\tau\beta_{i})y_{i}\phi(x_{i})=0,

(27)

\displaystyle\hskip-99.58464pt\frac{\partial L}{\partial b}=\sum\limits_{i=1}^{l}(\alpha_{i}-\tau\beta_{i})y_{i}=0,

(28)

\displaystyle\hskip-71.13188pt\frac{\partial L}{\partial\xi_{i}}=C_{i}-\alpha_{i}-\beta_{i}=0,~i=1,2,..,l

(29)

Using the KKT optimality conditions, the Wolfe’s dual of the primal problem (
25
) is obtained as follows

\displaystyle\min_{(\alpha,\beta)}\frac{1}{2}\sum_{i=1}^{l}\sum_{j=1}^{l}(\alpha_{j}-\tau\beta_{j})(\alpha_{i}-\tau\beta_{i})y_{i}y_{j}K(x_{i},x_{j})

(30)

\displaystyle\hskip-312.9803pt-\sum\limits_{i=1}^{l}(\alpha_{i}-\tau\beta_{i})

subject to,

\displaystyle\hskip-298.75394pt\sum\limits_{i=1}^{l}(\alpha_{i}-\tau\beta_{i})y_{i}=0,

\displaystyle\hskip-312.9803ptC_{i}-\alpha_{i}-\beta_{i}=0,

\displaystyle\hskip-256.0748pt\alpha_{i}\geq 0,~\beta_{i}\geq 0,~~~i=1,2,..,l.

If we consider the replacement of variable
\beta:=|\tau|\beta
in dual problem (
30
) and define a signum function
s_{u}=\begin{cases}1~~\mbox{if}~u\geq 0,\\
-1,~~otherwise,\end{cases}
then, the dual problem (
30
) can be given by

\displaystyle\min_{(\alpha,\beta)}\frac{1}{2}\sum_{i=1}^{l}\sum_{j=1}^{l}(\alpha_{j}-s_{\tau}\beta_{j})(\alpha_{i}-s_{\tau}\beta_{i})y_{i}y_{j}K(x_{i},x_{j})

(31)

\displaystyle\hskip-312.9803pt-\sum\limits_{i=1}^{l}(\alpha_{i}-s_{\tau}\beta_{i})

subject to,

\displaystyle\hskip-298.75394pt\sum\limits_{i=1}^{l}(\alpha_{i}-s_{\tau}\beta_{i})y_{i}=0,

\displaystyle\hskip-312.9803ptC_{i}-\alpha_{i}-\frac{\beta_{i}}{|\tau|}=0,

\displaystyle\hskip-256.0748pt\alpha_{i}\geq 0,~\beta_{i}\geq 0,~~i=1,2,..,l.

It is notable that for
0\leq\tau\leq 1
, the proposed dual problem (
31
) is equivalent to dual problem (
6
) of Pin-SVM model. For
-1\leq\tau<0
, the proposed dual problem (
31
) can be found to be equivalent to the dual problem (
20
) of Pin-SVM model for
-1\leq\tau<0
. This is because
\tau=s_{\tau}|\tau|
.

After obtaining the solution of the dual problem (
31
), the value of
w
can be given by

\displaystyle w=\sum_{i=1}^{l}(\alpha_{i}-s_{\tau}\beta_{i})y_{i}\phi(x_{i}).

(32)

For finding the value of
b
, we consider each index
i
such that
\alpha_{i}>0
and
\beta_{i}>0
, and compute the value of
b
using the complementary slackness condition as follow

b=y_{i}-w^{T}\phi(x_{i})=y_{i}-\sum_{j=1}^{l}(\alpha_{j}-s_{\tau}\beta_{j})y_{j}K(x_{j},x_{i}).

(33)

We consider the final value of
b
by taking the average over all possible values of
b
.
For given test point
x\in{R}^{n}
, the decision function is obtained as

\displaystyle f(x)=sign(w^{T}\phi(x)+b)

(34)

\displaystyle\hskip-113.81102pt=sign~(\sum\limits_{j=1}^{l}(\alpha_{j}-s_{\tau}\beta_{j})y_{j}K(x_{j},x)+b).

VI
Conclusions

This paper proposes a significant improvement over the Pin-SVM model. For this, it re-look the pinball loss function for
-1\leq\tau<0
and its corresponding optimization problem used in the Pin-SVM model. It finds that the optimization problem used in (Huang et al,
[
1
]
) fails to minimize the pinball loss function for
-1\leq\tau<0
in its true sense. Thereafter, it develops the right optimization problem which can minimize the pinball loss function for
-1\leq\tau<0
in its true sense.

It makes us realize that the Pin-SVM model requires to solve different QPP for its positive and negative
\tau
values in
[-1,1]
. Taking motivation from this, we further propose a Unified Pin-SVM QPP which can be used to solve the Pin-SVM model without bothering the sign of its parameter
\tau
in
[-1,1]
. The proposed Unified Pin-SVM model can obtain a significant improvement in accuracy over the Pin-SVM model, as it can also minimize the pinball loss function with
-1\leq\tau<0
in true sense. We have performed extensive numerical experiments with nineteen real-world datasets and shown empirically that the proposed Unified Pin-SVM model can always obtain an improvement over the existing Pin-SVM model.
