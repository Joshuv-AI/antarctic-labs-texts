Abstract
It is well known that to fulfill their full potential, the design of polar codes must be tailored to their intended decoding algorithm. While for SC ( SC ) decoding, information theoretically optimal constructions are available, the code design for other decoding algorithms (such as BP ( BP ) decoding) can only be optimized using extensive Monte Carlo simulations. We propose to view the design process of polar codes as a graph search problem and thereby approaching it more systematically. Based on this formalism, the design-time complexity can be significantly reduced compared to state-of-the-art GenAlg ( GenAlg ) and deep learning-based design algorithms. Moreover, sequences of rate-compatible polar codes can be efficiently found. Finally, we analyze both the complexity of the proposed algorithm and the error-rate performance of the constructed codes.

Polar codes, as introduced in

The reliability refers to the information after decoding and, thus, is not a universal code property, but also dependent on the decoder.
and carries the information (i.e., information set), while the remaining

The code

\mathbf{x}=\mathbf{u}\cdot\mathbf{G}_{N},\qquad\mathbf{G}_{N}=\begin{bmatrix}1&0\\

An alternative notation for specifying the sets

Throughout this paper, we will use

II-B

Polar Code Reliability Sequences

Practical applications require a simple change of the code rate whenever the channel conditions vary. For a fixed blocklength

2
2

2

In literature, ascending reliability is commonly used. However, descending order results in easier notation.

\mathcal{A}=\{i\in Q_{j}|j<k\}.

Examples for reliability sequences are based on the Bhattacharyya parameter
[
1
]
,
\beta
-expansion
[
20
]
and the 5G sequence
[
21
]
.

Remark:
Reliability sequences are in general sub-optimal. In other words, given a channel and decoding algorithm, the optimal code designs
\mathcal{A}_{k}
for each

\mathcal{A}_{k-1}\subset\mathcal{A}_{k}

For most polar decoding algorithms besides

With the number of simulated frame errors

The frame errors are independent events, and hence, the number of observed frame errors

3
3

3

In contrast, bit errors after decoding are not independent events, and hence, the outlined method only works for

However, according to the

\delta=\sqrt{\frac{\hat{P}_{\mathrm{FE}}\cdot\left(1-\hat{P}_{\mathrm{FE}}\right)}{N_{\mathrm{T}}}}\cdot Q^{-1}(\alpha),

(1)

(

[

Note that the approximation becomes inaccurate if

To relate different polar code designs to each other, we propose to use a (directed) graph. Each polar code design (i.e.,
\mathbf{A}
-vector) corresponds to a vertex. Two codes
\mathcal{A}
and
\mathcal{A}^{\prime}
differing exactly by one frozen/unfrozen bit are connected by an edge, and the edge label indicates the bit position in which they differ, i.e.,

\mathcal{A}\frac{j}{\qquad}\mathcal{A}^{\prime}\quad\Leftrightarrow\quad\mathcal{A}^{\prime}=\mathcal{A}\cup\{j\}.

Note that this is identical to the Hasse diagram of all information sets ordered by inclusion. We define the partial order

\mathcal{A}\prec\mathcal{A}^{\prime}\quad\Leftrightarrow\quad\mathcal{A}\subset\mathcal{A}^{\prime}

that can also compare codes not directly neighboring, but connected via a chain of edges.
This notion of order is motivated by the fact that the
FER
of two codes
\mathcal{A}
and
\mathcal{A}^{\prime}
with
\mathcal{A}\prec\mathcal{A}^{\prime}
at identical
E_{\mathrm{s}}/N_{0}
fulfill
P_{\mathrm{FE}}(\mathcal{A})\leq P_{\mathrm{FE}}(\mathcal{A}^{\prime})
, as the decoder of
\mathcal{A}
has access to more a priori information (additional frozen bits) than the decoder of
\mathcal{A}^{\prime}
. Therefore, the graph implies some local “smoothness” of the
FER
in the neighborhood around each code.

N=8
is shown. Note that we implicitly assume increasing code dimensions from left to right and, thus, the direction of the edges is omitted for readability.

V
Conclusion

In this paper, we introduced a new perspective on polar code design as a search on a graph. This makes it possible to systematically optimize a single code design and also find reliability sequences for rate-compatible polar codes. To this end, we proposed two algorithms for traversing the graph and showed that they provide lower computational complexity than other Monte Carlo simulation based design methods and can result in better code designs with respect to the error-rate performance.

The proposed methods are very general and can be easily applied to other decoding algorithms such as
SCAN
,
BPL
(
BPL
) and
AED
. In particular, the graph can be altered such that the resulting codes follow desired properties such as the partial order of synthetic channels.
