. 1.
Introduction and statement of main result

In this work, we consider a homogenous Neumman initial-boundary value problem (IBVP) for the following two-species chemotaxis system with Lotka-Volterra type competitive kinetics and signal production:

\begin{cases}u_{t}=\Delta u-\chi_{1}\nabla\cdot(u\nabla w)+\mu_{1}u(1-u^{\theta-1}-a_{1}v),&x\in\Omega,t>0,\\[5.69046pt]
v_{t}=\Delta v-\chi_{2}\nabla\cdot(v\nabla w)+\mu_{2}v(1-v-a_{2}u),&x\in\Omega,t>0,\\[5.69046pt]
w_{t}=\Delta w-w+\alpha u+\beta v,&x\in\Omega,t>0,\\[5.69046pt]
\frac{\partial u}{\partial\nu}=\frac{\partial v}{\partial\nu}=\frac{\partial w}{\partial\nu}=0,&x\in\partial\Omega,t>0,\\[5.69046pt]
u(x,0)=u_{0}(x),\ v(x,0)=v_{0}(x),\ w(x,0)=w_{0}(x),\ &x\in\Omega,\end{cases}

(1.1)

where
\Omega\subset\mathbb{R}^{N}

(N\geq 2)
is a bounded domain with smooth boundary
\partial\Omega
and

\partial\Omega

(u_{0},v_{0},w_{0})

\chi_{1},\chi_{2},\mu_{1},\mu_{2},\alpha,\beta
are positive constants,
a_{1},a_{2}
are nonnegative constants, and the exponent
\theta>1
.

\begin{cases}u_{0}\geq 0,\ v_{0}\geq 0,\ w_{0}\geq 0,\ \ r=\max\left\{2,\ \frac{N(2-\theta)}{2(\theta-1)}\right\},\\[7.11317pt]
(u_{0},\ v_{0},\ w_{0})\in L^{1}(\Omega)\times L^{1}(\Omega)\times L^{r}(\Omega).\end{cases}

Theorem 1.1
.

Let
\Omega\subset\mathbb{R}^{N}

(N\geq 2)
be a bounded domain with smooth boundary, the initial data
(u_{0},v_{0},w_{0})
fulfill (
1.6
), the model parameters
\chi_{1},\chi_{2},\mu_{1},\mu_{2},\alpha,\beta>0
,

(1.7)

Then there exists at least one triple

of nonnegative functions satisfying

\begin{cases}u\in L^{\infty}((0,\infty);L^{1}(\Omega)),\\[7.11317pt]
v\in L^{\infty}((0,\infty);L^{1}(\Omega))\ \ \ \\[7.11317pt]
w\in\bigcap_{p\in[1,\frac{N+2}{N+1})}L^{p}_{loc}([0,\infty);W^{1,p}(\Omega)),\end{cases}

which is a global generalized solution of (
1.1

2.
Preliminaries and the concept of generalized solution

In order to make our notion of generalized solution more intuitive and understandable (which, motivated mainly from in
[
42
]
, is based beyond integration by parts), we first introduce an approximating system for (
1.2
), which is globally and classically solvable. To this end, for
\varepsilon\in(0,1)
and
r
given by (
1.6
), we fix function families
(u_{0\varepsilon})_{\varepsilon\in(0,1)}\subset C^{0}(\overline{\Omega})
,
(v_{0\varepsilon})_{\varepsilon\in(0,1)}\subset C^{0}(\overline{\Omega})
and
(w_{0\varepsilon})_{\varepsilon\in(0,1)}\subset W^{1,\infty}(\Omega)
such that
u_{0\varepsilon},v_{0\varepsilon}
and
w_{0\varepsilon}
are nonnegative and

\|u_{0\varepsilon}\|_{L^{1}}\leq 1+\|u_{0}\|_{L^{1}},\ \ \|v_{0\varepsilon}\|_{L^{1}}\leq 1+\|v_{0}\|_{L^{1}},\ \ \|w_{0\varepsilon}\|_{L^{r}}\leq 1+\|w_{0}\|_{L^{r}},

(2.1)

and, as
\varepsilon\searrow 0
, that

\begin{cases}u_{0\varepsilon}\rightarrow u_{0}\ \ \textmd{in}~L^{1}(\Omega)\ \ \textmd{and}\ \textmd{a.e.}\ \textmd{in}\ \Omega,\cr v_{0\varepsilon}\rightarrow v_{0}\ \ \textmd{in}~L^{1}(\Omega)\ \ \textmd{and}\ \textmd{a.e.}\ \textmd{in}\ \Omega,\cr w_{0\varepsilon}\rightarrow w_{0}\ \ \textmd{in}~L^{r}(\Omega)\ \ \textmd{and}\ \textmd{a.e.}\ \textmd{in}\ \Omega.\end{cases}

(2.2)

In our forthcoming analysis, the involving model parameters only bring more inconvenient computations, play inessential roles and will not change our conclusion. Hence, except the key parameter
\theta
, we assume all other parameters to be unit:

\chi_{1}=\chi_{2}=\mu_{1}=\mu_{2}=a_{1}=a_{2}=1.

(2.3)

Then, we are ready to formulate a convenient approximating system of (
1.1
):

\begin{cases}u_{\varepsilon t}=\Delta u_{\varepsilon}-\nabla\cdot(u_{\varepsilon}\nabla w_{\varepsilon})+u_{\varepsilon}(1-u_{\varepsilon}^{\theta-1}-v_{\varepsilon}),&x\in\Omega,t>0,\\[5.69046pt]
v_{\varepsilon t}=\Delta v_{\varepsilon}-\nabla\cdot(v_{\varepsilon}\nabla w_{\varepsilon})+v_{\varepsilon}(1-v_{\varepsilon}-u_{\varepsilon}),&x\in\Omega,t>0,\\[5.69046pt]
w_{\varepsilon t}=\Delta w_{\varepsilon}-w_{\varepsilon}+\frac{u_{\varepsilon}+v_{\varepsilon}}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})},&x\in\Omega,t>0,\\[5.69046pt]
\frac{\partial u_{\varepsilon}}{\partial\nu}=\frac{\partial v_{\varepsilon}}{\partial\nu}=\frac{\partial w_{\varepsilon}}{\partial\nu}=0,&x\in\partial\Omega,t>0,\\[5.69046pt]
u_{\varepsilon}(x,0)=u_{0\varepsilon}(x),\ v_{\varepsilon}(x,0)=v_{0\varepsilon}(x),\ w_{\varepsilon}(x,0)=w_{0\varepsilon}(x),\ &x\in\Omega.\end{cases}

(2.4)

By well-known local well-posed in chemotaxis related systems, the IBVP (
2.4
) admits a unique nonnegative and classical solution
(u_{\varepsilon},v_{\varepsilon},w_{\varepsilon})
defined on
\overline{\Omega}\times(0,T_{\varepsilon,max})
. Now, applying the widely known smoothing
L^{p}
-
L^{q}
-estimates of the
Neumann heat semigroup
(e^{t\Delta})_{t\geq 0}
in
\Omega
(cf.
[
36
,
46
]
) to the third equation in (
2.4
), one can easily see that
\|\nabla w_{\varepsilon}(\cdot,t)\|_{L^{\infty}}
is uniformly bounded on
(0,T_{\varepsilon,max})
. With this key estimate, one can easily use semigroup or energy estimate to show that both
\|u_{\varepsilon}(\cdot,t)\|_{L^{\infty}}
and
\|v_{\varepsilon}(\cdot,t)\|_{L^{\infty}}
are uniformly bounded on
(0,T_{\varepsilon,max})
. These enable one to conclude first global existence (
T_{\varepsilon,max}=\infty
) and then boundedness, as stated in the following lemma.

Lemma 2.1
.

Let
\theta>1
and
\Omega\subset\mathbb{R}^{N}

(N\geq 1)
be a bounded domain with smooth boundary and let the initial data
(u_{0\varepsilon},v_{0\varepsilon},w_{0\varepsilon})
be as described above. Then for each
\varepsilon\in(0,1)
, there exist a triple of nonnegative functions

\left\{\begin{array}[]{lll}u_{\varepsilon}\in C^{0}(\overline{\Omega}\times(0,\infty))\cap C^{2,1}(\overline{\Omega}\times(0,\infty)),\cr v_{\varepsilon}\in C^{0}(\overline{\Omega}\times(0,\infty))\cap C^{2,1}(\overline{\Omega}\times(0,\infty)),\cr w_{\varepsilon}\in\bigcap\limits_{q>N}C^{0}([0,\infty);W^{1,q}(\Omega))\cap C^{2,1}(\overline{\Omega}\times(0,\infty)),\end{array}\right.

and that
(u_{\varepsilon},v_{\varepsilon},w_{\varepsilon})
solves (
2.4
) classically. Furthermore, for
t>0
,

\int_{\Omega}u_{\varepsilon}(\cdot,t)\leq m_{1}:=\max\left\{1+\|u_{0}\|_{L^{1}},\ \ (\theta-1)\left(\frac{2}{\theta}\right)^{\frac{\theta}{\theta-1}}|\Omega|\right\},

(2.5)

\int_{\Omega}v_{\varepsilon}(\cdot,t)\leq m_{2}:=\max\left\{1+\|v_{0}\|_{L^{1}},\ \ |\Omega|\right\}

(2.6)

and, for all
T>0
,

\int^{T}_{0}\int_{\Omega}u^{\theta}_{\varepsilon}\leq m_{1}T+1+\|u_{0}\|_{L^{1}},

(2.7)

\int^{T}_{0}\int_{\Omega}v^{2}_{\varepsilon}\leq m_{2}T+1+\|v_{0}\|_{L^{1}}.

(2.8)

Finally, if
\theta>\frac{2N-2}{N}
, then, for

\begin{cases}1\leq p\leq\max\left\{2,\ \frac{N(2-\theta)}{2(\theta-1)}\right\},&\text{ if }N=2,3,\\[7.11317pt]
1\leq p\leq\max\left\{1,\ \frac{N(2-\theta)}{2(\theta-1)}\right\},&\text{ if }N\geq 4,\end{cases}

(2.9)

there exists
C_{2}=C_{2}(p)>0
such that

\|w_{\varepsilon}(\cdot,t)\|_{L^{p}}\leq C_{2},\ \ \ \forall t>0.

(2.10)

Proof.

As outlined above, the global existence follows, see details in similar systems
[
22
,
39
]
. Now, integrating the first equation in (
2.4
) over
\Omega
by parts and using the nonnegativity of
u_{\varepsilon}
and
v_{\varepsilon}
, we obtain

\frac{d}{dt}\int_{\Omega}u_{\varepsilon}\leq\int_{\Omega}\left(u_{\varepsilon}-u_{\varepsilon}^{\theta}\right)\leq-\int_{\Omega}u_{\varepsilon}+(\theta-1)\left(\frac{2}{\theta}\right)^{\frac{\theta}{\theta-1}}|\Omega|.

(2.11)

Solving this simple ODI (ordinary differential inequality) directly, we get

\int_{\Omega}u_{\varepsilon}\leq\|u_{0\varepsilon}\|_{L^{1}}e^{-t}+(\theta-1)\left(\frac{2}{\theta}\right)^{\frac{\theta}{\theta-1}}|\Omega|\left(1-e^{-t}\right),

which along with (
2.1
) entails (
2.5
). Now, an integration of (
2.11
) from
0
to
T
and a use of (
2.5
) imply (
2.7
). The estimates for
v_{\varepsilon}
in (
2.6
) and (
2.8
) can be easily obtained in the same way via setting
\theta=2
.

To derive an
\varepsilon
-independent bound for
w_{\varepsilon}
, we first use variation-of-constants formula to write the
w_{\varepsilon}
-equation in (
2.4
) as

w_{\varepsilon}(\cdot,t)=e^{t(\Delta-1)}w_{0\varepsilon}+\int_{0}^{t}e^{(t-s)(\Delta-1)}\frac{(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}ds.

For
p
satisfying (
2.9
), we first clearly have
p\leq r
by (
1.6
), and then, since
\theta>\frac{2N-2}{N}
we see that
p<\frac{N}{(N-2)^{+}}
or equivalently
N-(N-2)p>0
. Then we apply the well-known smoothing
L^{p}
-
L^{q}
type estimates of the
Neumann heat semigroup
(e^{t\Delta})_{t\geq 0}
along with (
2.1
), (
2.5
) and (
2.6
) to deduce

\begin{split}\|w_{\varepsilon}(\cdot,t)\|_{L^{p}}&\leq e^{-t}\|e^{t\Delta}w_{0\varepsilon}\|_{L^{p}}+\int^{t}_{0}\left\|e^{-(t-s)}e^{(t-s)\Delta}\frac{(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}\right\|_{L^{p}}ds\\
&\leq c_{1}\|w_{0\varepsilon}\|_{L^{p}}+c_{1}\int^{t}_{0}\left[1+(t-s)^{-\frac{N}{2}(1-\frac{1}{p})}\right]e^{-(t-s)}\left\|(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)\right\|_{L^{1}}ds\\
&\leq c_{2}\|w_{0\varepsilon}\|_{L^{r}}+c_{2}\int^{t}_{0}\left[1+\tau^{-\frac{N}{2}(1-\frac{1}{p})}\right]e^{-\tau}d\tau\\
&\leq c_{2}\left(1+\|w_{0}\|_{L^{r}}\right)+c_{2}\left(2+\frac{2p}{N-(N-2)p}\right),\ \ \ \forall t>0,\end{split}

yielding immediately the desired
\varepsilon
-independent bound (
2.10
).
∎

Evidently, a formal limit of (
2.4
) as
\varepsilon\rightarrow 0+
yields (
1.1
) with (
2.3
). In the sequel, we shall carry out rigourous limiting procedure to construct a generalized solution to (
1.1
) out of (
2.4
). To this purpose, we provide the following evolution identity, which is an important preparation for our concept of generalized solution.

Lemma 2.2
.

For
\varepsilon\in[0,1)
and
T\in(0,\infty]
, let

from

\begin{split}&\int_{\Omega}\partial_{t}\{\phi(u)\xi(w)\}\cdot\psi\cr&=-\int_{\Omega}\Bigl|\nabla(\Phi(u)\sqrt{\xi(w)})+\Bigl\{\frac{\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\cdot\frac{\xi^{\prime}(w)}{\sqrt{\xi(w)}}-\frac{1}{2}\Phi(u)\frac{\xi^{\prime}(w)}{\sqrt{\xi(w)}}\cr&\ \ \ \ -\frac{1}{2}u\sqrt{\phi^{\prime\prime}(u)}\cdot\sqrt{\xi(w)}\Bigl\}\nabla w\Bigl|^{2}\psi\cr&\ \ \ \ -\int_{\Omega}\Bigl\{\phi(u)\xi^{\prime\prime}(w)-\frac{\phi^{\prime 2}(u)}{\phi^{\prime\prime}(u)}\cdot\frac{\xi^{\prime 2}(w)}{\xi(w)}-\frac{1}{4}u^{2}\phi^{\prime\prime}(u)\xi(w)\Bigl\}\cdot|\nabla w|^{2}\psi\cr&\ \ \ \ -\int_{\Omega}\frac{\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\sqrt{\xi(w)}\nabla(\Phi(u)\sqrt{\xi(w)})\cdot\nabla\psi\cr&\ \ \ \ +\int_{\Omega}\Bigl\{u\phi^{\prime}(u)\xi(w)-\phi(u)\xi^{\prime}(w)+\frac{1}{2}\frac{\Phi(u)\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\xi^{\prime}(w)\Bigl\}\nabla w\cdot\nabla\psi\cr&\ \ \ \ +\int_{\Omega}\Bigl\{u(1-u^{\theta-1}-v)\phi^{\prime}(u)\xi(w)+\left(\frac{u+v}{1+\varepsilon(u+v)}-w\right)\phi(u)\xi^{\prime}(w)\Bigl\}\cdot\psi.\end{split}

(2.12)

Proof.

Honest computations via (

) and using the fact that

\nabla u=\frac{1}{\sqrt{\phi^{\prime\prime}(u)\xi(w)}}\nabla\left(\Phi(u)\sqrt{\xi(w)}\right)-\frac{1}{2}\frac{\Phi(u)}{\sqrt{\phi^{\prime\prime}(u)}}\cdot\frac{\xi^{\prime}(w)}{\xi(w)}\nabla w,

∎

Definition 2.3
.

Let
(u,v,w)
be a triple of nonnegative functions satisfying

\begin{cases}\left(u,v,w\right)\in\left(L^{1}_{loc}(\overline{\Omega}\times[0,\infty)),L^{1}_{loc}(\overline{\Omega}\times[0,\infty)),L^{1}_{loc}([0,\infty);W^{1,1}(\Omega))\right),\\[7.11317pt]
u(1-u^{\theta-1}-v),\ \ \ v(1-v-u)\in L^{1}_{loc}(\overline{\Omega}\times[0,\infty)),\\[7.11317pt]
\nabla\ln(v+1),\ \ \ \frac{v}{v+1}\nabla w\in L^{2}_{loc}(\overline{\Omega}\times[0,\infty);\mathbb{R}^{N}).\end{cases}

(2.13)

Then
(u,v,w)
will be called a global generalized solution of (
1.1
) if

\begin{split}&-\int^{\infty}_{0}\int_{\Omega}\ln(v+1)\psi_{t}-\int_{\Omega}\ln(v_{0}+1)\psi(\cdot,0)\cr&\geq\int^{\infty}_{0}\int_{\Omega}|\nabla\ln(v+1)|^{2}\psi-\int^{\infty}_{0}\int_{\Omega}\nabla\ln(v+1)\cdot\nabla\psi\\
&\ \ +\int^{\infty}_{0}\int_{\Omega}\frac{v}{v+1}\nabla w\cdot\nabla\psi-\int^{\infty}_{0}\int_{\Omega}\frac{v\psi}{v+1}\nabla w\cdot\nabla\ln(v+1)\\
&\ \ \ \ +\int^{\infty}_{0}\int_{\Omega}\frac{v\psi}{v+1}(1-v-u)\end{split}

(2.14)

and

\begin{split}&-\int^{\infty}_{0}\int_{\Omega}w\psi_{t}-\int_{\Omega}w_{0}\psi(\cdot,0)\\
&=-\int^{\infty}_{0}\int_{\Omega}\nabla w\cdot\nabla\psi-\int^{\infty}_{0}\int_{\Omega}w\psi+\int^{\infty}_{0}\int_{\Omega}(u+v)\psi\end{split}

(2.15)

for all nonnegative
\psi\in C^{\infty}_{0}(\Omega\times[0,\infty))
, if

\int_{\Omega}u(\cdot,t)\leq\int_{\Omega}u_{0}+\int^{t}_{0}\int_{\Omega}u(1-u^{\theta-1}-v)\ \ \textmd{for}\ \textmd{a.e.}\ t>0,

(2.16)

and if there exist functions
\left(\phi,\xi,\Phi\right)\in\left(C^{2}([0,\infty))\right)^{3}
such that

\phi^{\prime}<0,\ \ \xi>0\ \ \textmd{and}\ \ \phi^{\prime\prime}>0\ \ \textmd{on}\ [0,\infty),\ \ \Phi^{\prime}=\sqrt{\phi^{\prime\prime}}\ \ \textmd{on}\ [0,\infty),

(2.17)

that

\Bigl\{\phi(u)\xi^{\prime\prime}(w)-\frac{\phi^{\prime 2}(u)}{\phi^{\prime\prime}(u)}\cdot\frac{\xi^{\prime 2}(w)}{\xi(w)}-\frac{1}{4}u^{2}\phi^{\prime\prime}(u)\xi(w)\Bigl\}|\nabla w|^{2},\ \ u\phi^{\prime}(u)\xi(w)|\nabla w|,

\phi(u)\xi^{\prime}(w)|\nabla w|,\ \ \frac{\Phi(u)\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\xi^{\prime}(w)|\nabla w|\text{ and }u(1-u^{\theta-1}-v)\phi^{\prime}(u)\xi(w)\ \text{ as well as}

u\phi(u)\xi^{\prime}(w),v\phi(u)\xi^{\prime}(w)\text{ and }w\phi(u)\xi^{\prime}(w)\ \text{ belong to }\ L^{1}_{loc}(\overline{\Omega}\times[0,\infty))

(2.18)

that

\Phi(u)\sqrt{\xi(w)}\in L^{2}_{loc}([0,\infty);W^{1,2}(\Omega)),

(2.19)

and that for each nonnegative
\varphi\in C^{\infty}_{0}(\Omega\times[0,\infty))
, the following inequality holds:

\begin{split}&-\int^{\infty}_{0}\int_{\Omega}\phi(u)\xi(w)\varphi_{t}-\int_{\Omega}\phi(u_{0})\xi(w_{0})\varphi(\cdot,0)\cr&\leq-\int^{\infty}_{0}\int_{\Omega}\Bigl|\nabla(\Phi(u)\sqrt{\xi(w)})+\Bigl\{\frac{\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\cdot\frac{\xi^{\prime}(w)}{\sqrt{\xi(w)}}-\frac{1}{2}\Phi(u)\frac{\xi^{\prime}(w)}{\sqrt{\xi(w)}}\cr&\ \ \ \ -\frac{1}{2}u\sqrt{\phi^{\prime\prime}(u)}\cdot\sqrt{\xi(w)}\Bigl\}\nabla w\Bigl|^{2}\varphi\cr&\ \ \ \ -\int^{\infty}_{0}\int_{\Omega}\Bigl\{\phi(u)\xi^{\prime\prime}(w)-\frac{\phi^{\prime 2}(u)}{\phi^{\prime\prime}(u)}\cdot\frac{\xi^{\prime 2}(w)}{\xi(w)}-\frac{1}{4}u^{2}\phi^{\prime\prime}(u)\xi(w)\Bigl\}\cdot|\nabla w|^{2}\varphi\cr&\ \ \ \ -\int^{\infty}_{0}\int_{\Omega}\frac{\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\sqrt{\xi(w)}\nabla(\Phi(u)\sqrt{\xi(w)})\cdot\nabla\varphi\cr&\ \ \ \ +\int^{\infty}_{0}\int_{\Omega}\Bigl\{u\phi^{\prime}(u)\xi(w)-\phi(u)\xi^{\prime}(w)+\frac{1}{2}\frac{\Phi(u)\phi^{\prime}(u)}{\sqrt{\phi^{\prime\prime}(u)}}\xi^{\prime}(w)\Bigl\}\nabla w\cdot\nabla\varphi\cr&\ \ +\int^{\infty}_{0}\int_{\Omega}\left\{u(1-u^{\theta-1}-v)\phi^{\prime}(u)\xi(w)+\left(u+v-w\right)\phi(u)\xi^{\prime}(w)\right\}\cdot\varphi\end{split}

Lemma 2.5
.

(Gagliardo-Nirenberg interpolation inequality

Let

Lemma 3.1
.

For
\theta>1
, there exists
C_{1}>0
such that, for all
T>0
,

\int^{T}_{0}\int_{\Omega}|u_{\varepsilon}(1-u_{\varepsilon}^{\theta-1}-v_{\varepsilon})|+\int^{T}_{0}\int_{\Omega}|v_{\varepsilon}(1-v_{\varepsilon}-u_{\varepsilon})|\leq C_{1}(1+T),\ \ \forall\varepsilon\in(0,1).

(3.1)

Moreover, we have

\sup_{\varepsilon\in(0,1)}\sup_{t>0}\int_{\Omega}u_{\varepsilon}(\cdot,t)+\sup_{\varepsilon\in(0,1)}\sup_{t>0}\int_{\Omega}v_{\varepsilon}(\cdot,t)<+\infty.

(3.2)

Proof.

The estimate (
3.2
) follows directly from (
2.6
) and (
2.7
).
To show (
3.1
), for simplicity, we let
f_{\varepsilon}=u_{\varepsilon}(1-u^{\theta-1}_{\varepsilon}-v_{\varepsilon})
and decompose
f_{\varepsilon}=f_{\varepsilon}^{+}-f_{\varepsilon}^{-}
where

f_{\varepsilon}^{+}:=\max\{f_{\varepsilon},0\}=\begin{cases}u_{\varepsilon}(1-u^{\theta-1}_{\varepsilon}-v_{\varepsilon}),&u^{\theta-1}_{\varepsilon}+v_{\varepsilon}\leq 1,\\[7.11317pt]
0,&u^{\theta-1}_{\varepsilon}+v_{\varepsilon}>1,\end{cases}\leq 1

(3.3)

and

f_{\varepsilon}^{-}:=\max\{-f_{\varepsilon},0\}=\begin{cases}0,&u^{\theta-1}_{\varepsilon}+v_{\varepsilon}\leq 1,\\[7.11317pt]
-u_{\varepsilon}(1-u^{\theta-1}_{\varepsilon}-v_{\varepsilon}),&u^{\theta-1}_{\varepsilon}+v_{\varepsilon}>1.\end{cases}

Integrating the first equation in (
2.4
) over
\Omega
by parts, we get

\frac{d}{dt}\int_{\Omega}u_{\varepsilon}=\int_{\Omega}f_{\varepsilon}(u_{\varepsilon},v_{\varepsilon}),

which upon being integrated from
0
to
T
along with (
2.1
) yields

-\int_{0}^{T}\int_{\Omega}f_{\varepsilon}(u_{\varepsilon},v_{\varepsilon})=\int_{\Omega}u_{0\varepsilon}-\int_{\Omega}u_{\varepsilon}(\cdot,T)\leq 1+\int_{\Omega}u_{0}.

(3.4)

Then, using (
3.3
), (
3.4
) and the fact
|f_{\varepsilon}|=f_{\varepsilon}^{+}+f_{\varepsilon}^{-}=2f^{+}-f
, we infer

\begin{split}\int^{T}_{0}\int_{\Omega}|f_{\varepsilon}(u_{\varepsilon},v_{\varepsilon})|&=2\int^{T}_{0}\int_{\Omega}f_{\varepsilon}^{+}(u_{\varepsilon},v_{\varepsilon})-\int^{T}_{0}\int_{\Omega}f_{\varepsilon}(u_{\varepsilon},v_{\varepsilon})\cr&\leq 2|\Omega|T+1+\int_{\Omega}u_{0},\end{split}

(3.5)

yielding the estimate for
u_{\varepsilon}
in (
3.1
). The estimates for
v_{\varepsilon}
in (
3.1
) follows in a similar way via setting
\theta=2
.
∎

Lemma 3.2
.

The global solution of (
2.4
) satisfies, for all
T>0
, that

(u_{\varepsilon})_{\varepsilon\in(0,1)}\text{ and }(v_{\varepsilon})_{\varepsilon\in(0,1)}\text{ are uniformly integrable over }\Omega\times(0,T).

(3.6)

Proof.

The uniform integrability in (
3.6
) is implied directly from (
2.7
) and (
2.8
). Indeed, given
\eta>0
and
T>0
, we put

\delta=\left(\frac{\eta^{\theta}}{m_{1}T+1+\|u_{0}\|_{L^{1}}}\right)^{\frac{1}{\theta-1}}.

Then for any measurable set
E\subset\Omega\times(0,T)
with
|E|<\delta
, since
\theta>1
we use Hölder’s inequality to derive from (
2.7
) that

\int\int_{E}u_{\varepsilon}\leq\left(\int_{0}^{T}\int_{\Omega}u_{\varepsilon}^{\theta}\right)^{\frac{1}{\theta}}|E|^{\frac{\theta-1}{\theta}}<\left(m_{1}T+1+\|u_{0}\|_{L^{1}}\right)^{\frac{1}{\theta}}\delta^{\frac{\theta-1}{\theta}}=\eta,

giving rise to the uniform integrability of
(u_{\varepsilon})_{\varepsilon\in(0,1)}
. Similarly, the uniform integrability of
(v_{\varepsilon})_{\varepsilon\in(0,1)}
follows from (
2.8
). Alternatively, one can also deduce (
3.6
) from (
3.1
) of Lemma
3.1
.
∎

Lemma 3.3
.

Let
p\in[1,\frac{N+2}{N+1})
. Then for any
T>0
,
(w_{\varepsilon})_{\varepsilon\in(0,1)}
is relatively compact with respect to the strong topology in
L^{p}((0,T);W^{1,p}(\Omega))
.

Proof.

The essential idea has been
illustrated in
[
42
, Lemma 5.1]
. We here alternatively show the short proof. We proceed with no loss of
generality that
p>1
, and then, we pick a constant
\eta
fulfilling

\frac{1}{2}<\eta<\frac{N+2-Np}{2p}\Longrightarrow 1-\eta-\frac{N}{2}(1-\frac{1}{p})>0,\ 1-\left[\eta+\frac{N}{2}(1-\frac{1}{p})\right]p>0.

(3.7)

Let
A
be the realization of
-\Delta+1
under the homogeneous Neumann boundary condition in
L^{p}(\Omega)
. Then the fact
\eta>\frac{1}{2}
shows that the domain
D(A^{\eta})
of its fractional power
A^{\eta}
satisfies

D(A^{\eta})\text{ is compactly embedded into }W^{1,p}(\Omega).

(3.8)

For
T>0
, by the semigroup representation of
w_{\varepsilon}
-equation in (
2.4
) together with the well-known smoothing properties of heat semigroup
(e^{-tA})_{t\geq 0}
(cf.
[
36
]
), thanks to (
3.7
) and the
L^{1}
-boundedness information in (
2.1
) and (
3.2
), there exist positive constants
c_{1}=c_{1}(p)
and
c_{2}=c_{2}(p)
such that, for all
t\in(0,T)
and each
\varepsilon\in(0,1)
,

\begin{split}\|A^{\eta}w_{\varepsilon}(\cdot,t)\|_{L^{p}}&=\Bigl\|A^{\eta}e^{-tA}w_{0\varepsilon}+\int^{t}_{0}A^{\eta}e^{-(t-s)A}\frac{(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}ds\Bigl\|_{L^{p}}\cr&\leq c_{1}t^{-\eta-\frac{N}{2}(1-\frac{1}{p})}\|w_{0\varepsilon}\|_{L^{1}}\cr&\ +c_{1}\int^{t}_{0}(t-s)^{-\eta-\frac{N}{2}(1-\frac{1}{p})}\Bigl\|\frac{(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})(\cdot,s)}\Bigl\|_{L^{1}}ds\cr&\leq c_{2}t^{-\eta-\frac{N}{2}(1-\frac{1}{p})}+c_{2}\int^{t}_{0}(t-s)^{-\eta-\frac{N}{2}(1-\frac{1}{p})}ds\cr&\leq c_{2}t^{-\eta-\frac{N}{2}(1-\frac{1}{p})}+\frac{c_{2}}{1-\eta-\frac{N}{2}(1-\frac{1}{p})}T^{1-\eta-\frac{N}{2}(1-\frac{1}{p})},\end{split}

which upon being integrated from
0
to
T
and a use of (
3.7
) allows us to see

\begin{split}&\int^{T}_{0}\|A^{\eta}w_{\varepsilon}(\cdot,t)\|^{p}_{L^{p}}\cr&\leq\frac{2^{p-1}c^{p}_{2}T^{1-p[\eta+\frac{N}{2}(1-\frac{1}{p})]}}{1-p[\eta+\frac{N}{2}(1-\frac{1}{p})]}+2^{p-1}T\left(\frac{c_{2}T^{1-\eta-\frac{N}{2}(1-\frac{1}{p})}}{1-\eta-\frac{N}{2}(1-\frac{1}{p})}\right)^{p},\ \ \forall\varepsilon\in(0,1).\end{split}

(3.9)

On the other hand, for
\varphi\in C^{\infty}(\overline{\Omega})
and
t>0
, we deduce from (
2.4
) that

\begin{split}\left|\int_{\Omega}w_{\varepsilon t}(\cdot,t)\varphi\right|&=\left|-\int_{\Omega}\nabla w_{\varepsilon}\cdot\nabla\varphi-\int_{\Omega}w_{\varepsilon}\varphi+\int_{\Omega}\frac{(u_{\varepsilon}+v_{\varepsilon})}{1+\varepsilon(u_{\varepsilon}+v_{\varepsilon})}\varphi\right|\\[7.11317pt]
&\leq\|\nabla w_{\varepsilon}\|_{L^{p}}\|\nabla\varphi\|_{L^{\frac{p}{p-1}}}+\left(\|u_{\varepsilon}\|_{L^{1}}+\|v_{\varepsilon}\|_{L^{1}}+\|w_{\varepsilon}\|_{L^{1}}\right)\|\varphi\|_{L^{\infty}}.\end{split}

Notice that our assumption on

implies
\frac{p}{p-1}>N+2
, the Sobolev embedding shows that

W^{1,\frac{p}{p-1}}(\Omega)\hookrightarrow L^{\infty}(\Omega)
. Thus, there exists
c_{3}=c_{3}(p)>0
such that, for all
t>0
and any
\varepsilon\in(0,1)
,

\|w_{\varepsilon t}(\cdot,t)\|_{(W^{1,\frac{p}{p-1}})^{\ast}}\leq c_{3}\left(\|\nabla w_{\varepsilon}\|_{L^{p}}+\|w_{\varepsilon}\|_{L^{1}}+\|u_{\varepsilon}\|_{L^{1}}+\|v_{\varepsilon}\|_{L^{1}}\right).

In light of (
3.2
), (
3.8
) and (
3.9
), for every

, we infer

(w_{\varepsilon t})_{\varepsilon\in(0,1)}\text{ is bounded in }\ L^{p}((0,T);(W^{1,\frac{p}{p-1}}(\Omega))^{*}),

which along with the Aubin-Lions lemma, (
3.8
) and (
3.9

∎

Lemma 3.4
.

Let
\theta>\frac{2N-2}{N}
. Then for all

there exists

such that

\int^{T}_{0}\int_{\Omega}\frac{v_{\varepsilon}^{2}}{(1+v_{\varepsilon})^{2}}|\nabla w_{\varepsilon}|^{2}\leq C_{3}(1+T),\ \ \ \ \forall\varepsilon\in(0,1)

(3.10)

and

Proof.

Multiplying the third equation in (

) by

, integrating by parts and using the Young inequality, we have, for any

,

\begin{split}&\frac{1}{2}\frac{d}{dt}\int_{\Omega}w_{\varepsilon}^{2}+\int_{\Omega}|\nabla w_{\varepsilon}|^{2}+\int_{\Omega}w_{\varepsilon}^{2}\\

&\leq\eta\int_{\Omega}w_{\varepsilon}^{\frac{\theta}{\theta-1}}+\frac{1}{\theta}\left(\frac{\theta-1}{\theta\eta}\right)^{\theta-1}\int_{\Omega}u_{\varepsilon}^{\theta}+\eta\int_{\Omega}w_{\varepsilon}^{2}+\frac{1}{4\eta}\int_{\Omega}v_{\varepsilon}^{2}.\end{split}

Now, we put

This directly gives rise to the estimate (

Lemma 3.5

Then

also, for all

\liminf_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}|\nabla\ln(v_{\varepsilon}+1)|^{2}\psi\geq\int^{\infty}_{0}\int_{\Omega}|\nabla\ln(v+1)|^{2}\psi

(3.42)

and

\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}\nabla\ln(v_{\varepsilon}+1)\cdot\nabla\psi=\int^{\infty}_{0}\int_{\Omega}\nabla\ln(v+1)\cdot\nabla\psi.

(3.43)

By (

), (
3.34
) and (
3.37
), up to a further subsequence, we have

\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}\frac{v_{\varepsilon}}{v_{\varepsilon}+1}\nabla w_{\varepsilon}\cdot\nabla\psi=\int^{\infty}_{0}\int_{\Omega}\frac{v}{v+1}\nabla w\cdot\nabla\psi.

(3.44)

Thanks to (
3.10
) and (

), we infer from Hölder inequality that

\begin{split}&\int^{\infty}_{0}\int_{\Omega}\left|\frac{v_{\varepsilon}}{v_{\varepsilon}+1}\nabla w_{\varepsilon}\cdot\nabla\ln(v_{\varepsilon}+1)\right|\\
&\leq\left(\int^{T}_{0}\int_{\Omega}\left|\frac{v_{\varepsilon}}{v_{\varepsilon}+1}\nabla w_{\varepsilon}\right|^{2}\right)^{\frac{1}{2}}\left(\int^{T}_{0}\int_{\Omega}\left|\nabla\ln(v_{\varepsilon}+1)\right|^{2}\right)^{\frac{1}{2}}\\
&\leq c_{2}(1+T),\ \ \ \forall\varepsilon\in(0,1),\end{split}

which together with (
3.34
), (
3.35
) and (
3.37
) implies (up to a further subsequence) that

\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}\frac{v_{\varepsilon}\psi}{v_{\varepsilon}+1}\nabla w_{\varepsilon}\cdot\nabla\ln(v_{\varepsilon}+1)=\int^{\infty}_{0}\int_{\Omega}\frac{v\psi}{v+1}\nabla w\cdot\nabla\ln(v+1).

(3.45)

By the convergence properties in (
2.2
), (
3.33
), (
3.34
), (
3.35
) and the uniform integrability in (
3.1
), one can easily derive that

\begin{cases}\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}\ln(v_{\varepsilon}+1)\psi_{t}=\int^{\infty}_{0}\int_{\Omega}\ln(v+1)\psi_{t},\\[7.11317pt]
\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int_{\Omega}\ln(v_{0\varepsilon}+1)\psi(\cdot,0)=\int_{\Omega}\ln(v_{0}+1)\psi(\cdot,0),\\[7.11317pt]
\lim_{\varepsilon=\varepsilon_{j}\searrow 0}\int^{\infty}_{0}\int_{\Omega}\frac{v_{\varepsilon}\psi}{v_{\varepsilon}+1}(1-v_{\varepsilon}-u_{\varepsilon})=\int^{\infty}_{0}\int_{\Omega}\frac{v\psi}{v+1}(1-v-u).\end{cases}

(3.46)

Substituting (
3.42
), (
3.43
), (
3.44
), (
3.45
) and (
3.46
) into
(
3.41
), we arrive at the inequality stated in (
2.14
).
