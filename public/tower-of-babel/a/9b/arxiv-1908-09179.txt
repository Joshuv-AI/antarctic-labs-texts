2.2
Conventions about matrices

In the following, we will use matrices. We shall use a slightly nonstandard

That is, a

We let

If

-matrix (where

denote the

-matrix

A_{k-1,0}&A_{k-1,1}&\cdots&A_{k-1,\ell-1}\end{array}\right).

If

, then a

means a

-matrix. Thus, a column vector of size

has the form
\left(\begin{array}[c]{c}a_{0}\\
a_{1}\\
\vdots\\

As usual, we shall equate

Conventions about infinite matrices

\left(\begin{array}[c]{cccc}a_{0,0}&a_{0,1}&a_{0,2}&\cdots\\

If

\displaystyle\left(AB\right)_{i,k}

\displaystyle=\sum\limits_{j=0}^{v-1}A_{i,j}B_{j,k}

(1)

\displaystyle\ \ \ \ \ \ \ \ \ \ \text{for all }i\in\left\{0,1,\ldots,u-1\right\}\text{ and }k\in\left\{0,1,\ldots,w-1\right\}.

Definition 2.1

Definition 2.2

A matrix

Note that we did not require our matrix

quasi-triangularity is meant to be a tameness condition, meant to guarantee

4
A Weyl-algebraic application

4.1
The claim

We shall now restrict ourselves to a more special situation.

Namely, we let
\mathbb{K}
be a commutative ring, and we assume that the ring

\mathbb{L}
is a
\mathbb{K}
-algebra.

Consider the polynomial ring
\mathbb{K}\left[t\right]
in one variable

t
over
\mathbb{K}
. For each polynomial
g\in\mathbb{K}\left[t\right]

and each
n\in\mathbb{N}
, we let
g^{\left(n\right)}
be the
n

derivative of
g
; that is,

g^{\left(n\right)}=\dfrac{d^{n}}{dt^{n}}g.

(21)

Thus, in particular,
g^{\left(0\right)}=g
and
g^{\left(1\right)}=g^{\prime}
(where
g^{\prime}
denotes the derivative
\dfrac{d}{dt}g
of

g
).

Recall that we fixed
a\in\mathbb{L}
. Furthermore, let
h\in\mathbb{L}
and

x\in\mathbb{L}
be such that

\left[a,x\right]=h\ \ \ \ \ \ \ \ \ \ \text{and}\ \ \ \ \ \ \ \ \ \ \left[h,a\right]=0\ \ \ \ \ \ \ \ \ \ \text{and}\ \ \ \ \ \ \ \ \ \ \left[h,x\right]=0.

This situation is actually fairly common:

Example 4.1
.

Let
D
be the differentiation operator

\mathbb{K}\left[t\right]\rightarrow\mathbb{K}\left[t\right],\ \ \ \ \ \ \ \ \ \ g\mapsto\dfrac{d}{dt}g.

Let
T
be the “multiplication by
t
” operator

\mathbb{K}\left[t\right]\rightarrow\mathbb{K}\left[t\right],\ \ \ \ \ \ \ \ \ \ g\mapsto tg.

Then, the three operators
D
,
T
and
\operatorname*{id}\nolimits_{\mathbb{K}\left[t\right]}
belong to the
\mathbb{K}
-algebra

\operatorname*{End}\nolimits_{\mathbb{K}}\left(\mathbb{K}\left[t\right]\right)
of all endomorphisms of the
\mathbb{K}
-module
\mathbb{K}\left[t\right]
. These three operators satisfy

\left[D,T\right]=\operatorname*{id}\nolimits_{\mathbb{K}\left[t\right]},\ \ \ \ \ \ \ \ \ \ \left[\operatorname*{id}\nolimits_{\mathbb{K}\left[t\right]},D\right]=0\ \ \ \ \ \ \ \ \ \ \text{and}\ \ \ \ \ \ \ \ \ \ \left[\operatorname*{id}\nolimits_{\mathbb{K}\left[t\right]},T\right]=0.

Hence, we can obtain an example of the situation we are considering by setting

\mathbb{L}=\operatorname*{End}\nolimits_{\mathbb{K}}\left(\mathbb{K}\left[t\right]\right)
,
a=D
,
x=T
and
h=\operatorname*{id}\nolimits_{\mathbb{K}\left[t\right]}
.

Further examples can be obtained by varying this one. For example, if

\mathbb{K}
is a field, then
\mathbb{K}\left[t\right]
can be replaced
by the field of rational functions
\mathbb{K}\left(t\right)
.
Alternatively, if
\mathbb{K}=\mathbb{R}
, then
\mathbb{K}\left[t\right]

can be replaced by the algebra of
C^{\infty}
-functions
\mathbb{R}\rightarrow\mathbb{R}
.

Other examples appear in the theory of Weyl algebras and of
2
-step nilpotent
Lie algebras.

Now, we return to the generality of
\mathbb{K}
,
\mathbb{L}
,
a
,
h
,
x

and
m
satisfying
\left[a,x\right]=h
and
\left[h,a\right]=0
and

\left[h,x\right]=0.

For any polynomial
g\in\mathbb{K}\left[t\right]
, we define an
m\times m
-matrix
V_{g}\in\mathbb{L}^{m\times m}
by

V_{g}=\left(\begin{cases}\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j},&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}\right)_{0\leq i<m,\ 0\leq j<m}.

(22)

This matrix
V_{g}
looks as follows:

•

If
g\in\mathbb{K}\left[t\right]
and
m\in\mathbb{N}
, then

V_{g}=\left(\begin{smallmatrix}g^{\left(0\right)}\left(x\right)&0&0&\cdots&0\\
g^{\left(1\right)}\left(x\right)\cdot h&g^{\left(0\right)}\left(x\right)&0&\cdots&0\\
g^{\left(2\right)}\left(x\right)\cdot h^{2}&2g^{\left(1\right)}\left(x\right)\cdot h&g^{\left(0\right)}\left(x\right)&\cdots&0\\
\vdots&\vdots&\vdots&\ddots&\vdots\\
g^{\left(m-1\right)}\left(x\right)\cdot h^{m-1}&\left(m-1\right)g^{\left(m-2\right)}\left(x\right)\cdot h^{m-2}&\tbinom{m-1}{2}g^{\left(m-3\right)}\left(x\right)\cdot h^{m-3}&\cdots&g^{\left(0\right)}\left(x\right)\end{smallmatrix}\right).

•

If
g\in\mathbb{K}\left[t\right]
and
m=\infty
, then

V_{g}=\left(\begin{array}[c]{ccccc}g^{\left(0\right)}\left(x\right)&0&0&0&\cdots\\
g^{\left(1\right)}\left(x\right)\cdot h&g^{\left(0\right)}\left(x\right)&0&0&\cdots\\
g^{\left(2\right)}\left(x\right)\cdot h^{2}&2g^{\left(1\right)}\left(x\right)\cdot h&g^{\left(0\right)}\left(x\right)&0&\cdots\\
g^{\left(3\right)}\left(x\right)\cdot h^{3}&3g^{\left(2\right)}\left(x\right)\cdot h^{2}&3g^{\left(1\right)}\left(x\right)\cdot h&g^{\left(0\right)}\left(x\right)&\cdots\\
\vdots&\vdots&\vdots&\vdots&\ddots\end{array}\right).

Now, Tom Copeland has found the following identity
[
MO337766
]
:

Theorem 4.2
.

Let
n\in\mathbb{N}
be such that
n<m
. Let

g\in\mathbb{K}\left[t\right]
. Then,

\left(g\left(x\right)\cdot a\right)^{n}=e_{0}^{T}\left(V_{g}S\right)^{n}H_{1}.

This identity will easily follow from Theorem
2.7
(applied to

b=g\left(x\right)
), once we can show the following:

Proposition 4.3
.

Let
g\in\mathbb{K}\left[t\right]
. Then,

U_{g\left(x\right)}=V_{g}
.

We shall thus mostly focus on proving Proposition
4.3
.

4.2
How derivatives appear in commutators

The main idea of our proof will be the following proposition, which relates
derivatives in
\mathbb{K}\left[t\right]
to commutators in
\mathbb{L}
:

Proposition 4.4
.

(a)
We have
ax^{i}=x^{i}a+ix^{i-1}h
for each
positive integer
i
.

(b)
We have
a\cdot g\left(x\right)=g\left(x\right)\cdot a+g^{\prime}\left(x\right)\cdot h
for each
g\in\mathbb{K}\left[t\right]
.

Here, of course,
g^{\prime}
means the derivative
\dfrac{d}{dt}g
of the
polynomial
g
.

Proof 4.5

(Proof of Proposition
4.4
.)
.

The definition of
\left[a,x\right]
yields
\left[a,x\right]=ax-xa
. Hence,
ax-xa=\left[a,x\right]=h
. Thus,
ax=xa+h
.

From
\left[h,x\right]=0
, we obtain
0=\left[h,x\right]=hx-xh
(by
the definition of
\left[h,x\right]
). In other words,
hx=xh
.

(a)
We shall prove Proposition
4.4

(a)
by
induction on
i
:

Induction base:
Comparing
a\underbrace{x^{1}}_{=x}=ax=xa+h
with

\underbrace{x^{1}}_{=x}a+1\underbrace{x^{1-1}}_{=x^{0}=1}h=xa+h
, we find

ax^{1}=x^{1}a+1x^{1-1}h
. In other words, Proposition
4.4

(a)
holds for
i=1
. This completes the induction base.

Induction step:
Let
n
be a positive integer. Assume that
Proposition
4.4

(a)
holds for
i=n
. We must prove that
Proposition
4.4

(a)
holds for
i=n+1
.

We have assumed that Proposition
4.4

(a)
holds for

i=n
. In other words, we have
ax^{n}=x^{n}a+nx^{n-1}h
.

Now,

\displaystyle a\underbrace{x^{n+1}}_{=x^{n}x}

\displaystyle=\underbrace{ax^{n}}_{=x^{n}a+nx^{n-1}h}x=\left(x^{n}a+nx^{n-1}h\right)x=x^{n}\underbrace{ax}_{=xa+h}+nx^{n-1}\underbrace{hx}_{=xh}

\displaystyle=\underbrace{x^{n}\left(xa+h\right)}_{=x^{n}xa+x^{n}h}+n\underbrace{x^{n-1}x}_{=x^{n}}h=\underbrace{x^{n}x}_{=x^{n+1}}a+\underbrace{x^{n}h+nx^{n}h}_{=\left(n+1\right)x^{n}h}

\displaystyle=x^{n+1}a+\left(n+1\right)\underbrace{x^{n}}_{=x^{\left(n+1\right)-1}}h=x^{n+1}a+\left(n+1\right)x^{\left(n+1\right)-1}h.

In other words, Proposition
4.4

(a)
holds for
i=n+1
.
This completes the induction step. Thus, Proposition
4.4

(a)
is proven by induction.

(b)
Let
g\in\mathbb{K}\left[t\right]
. Write the polynomial
g

in the form
g=\sum\limits_{i=0}^{k}g_{i}t^{i}
for some
k\in\mathbb{N}
and some

g_{0},g_{1},\ldots,g_{k}\in\mathbb{K}
. Thus, the definition of the
derivative
g^{\prime}
yields
g^{\prime}=\sum\limits_{i=1}^{k}ig_{i}t^{i-1}
.
Substituting
x
for
t
in this equality, we find

g^{\prime}\left(x\right)=\sum\limits_{i=1}^{k}\underbrace{ig_{i}}_{=g_{i}i}x^{i-1}=\sum\limits_{i=1}^{k}g_{i}ix^{i-1}.

(23)

Substituting
x
for
t
in the equality
g=\sum\limits_{i=0}^{k}g_{i}t^{i}
, we
obtain
g\left(x\right)=\sum\limits_{i=0}^{k}g_{i}x^{i}
. Hence,

\displaystyle a\cdot\underbrace{g\left(x\right)}_{=\sum\limits_{i=0}^{k}g_{i}x^{i}}

\displaystyle=a\cdot\sum\limits_{i=0}^{k}g_{i}x^{i}=\sum\limits_{i=0}^{k}g_{i}ax^{i}=g_{0}a\underbrace{x^{0}}_{=1}+\sum\limits_{i=1}^{k}g_{i}\underbrace{ax^{i}}_{\begin{subarray}{c}=x^{i}a+ix^{i-1}h\\
\text{(by Proposition \ref{prop.deriv1}
{(a)})}\end{subarray}}

\displaystyle\ \ \ \ \ \ \ \ \ \ \left(\text{here, we have split off the addend for
}i=0\text{ from the sum}\right)

\displaystyle=g_{0}a+\underbrace{\sum\limits_{i=1}^{k}g_{i}\left(x^{i}a+ix^{i-1}h\right)}_{=\sum\limits_{i=1}^{k}g_{i}x^{i}a+\sum\limits_{i=1}^{k}g_{i}ix^{i-1}h}=g_{0}a+\sum\limits_{i=1}^{k}g_{i}x^{i}a+\sum\limits_{i=1}^{k}g_{i}ix^{i-1}h.

Comparing this with

\displaystyle\underbrace{g\left(x\right)}_{=\sum\limits_{i=0}^{k}g_{i}x^{i}}\cdot a+\underbrace{g^{\prime}\left(x\right)}_{\begin{subarray}{c}=\sum\limits_{i=1}^{k}g_{i}ix^{i-1}\\
\text{(by (\ref{pf.prop.deriv1.b.g'(x)}))}\end{subarray}}\cdot h

\displaystyle=\left(\sum\limits_{i=0}^{k}g_{i}x^{i}\right)\cdot a+\left(\sum\limits_{i=1}^{k}g_{i}ix^{i-1}\right)\cdot h=\underbrace{\sum\limits_{i=0}^{k}g_{i}x^{i}a}_{\begin{subarray}{c}=g_{0}x^{0}a+\sum\limits_{i=1}^{k}g_{i}x^{i}a\\
\text{(here, we have
split off the}\\
\text{addend for }i=0\text{ from the sum)}\end{subarray}}+\sum\limits_{i=1}^{k}g_{i}ix^{i-1}h

\displaystyle=g_{0}\underbrace{x^{0}}_{=1}a+\sum\limits_{i=1}^{k}g_{i}x^{i}a+\sum\limits_{i=1}^{k}g_{i}ix^{i-1}h=g_{0}a+\sum\limits_{i=1}^{k}g_{i}x^{i}a+\sum\limits_{i=1}^{k}g_{i}ix^{i-1}h,

we obtain
a\cdot g\left(x\right)=g\left(x\right)\cdot a+g^{\prime}\left(x\right)\cdot h
. This proves Proposition
4.4

(b)
.

Note that we have not used the condition
\left[h,a\right]=0
in
Proposition
4.4
; but we will use it now:

Proposition 4.6
.

Let
b\in\mathbb{L}
. Then,
\operatorname*{ad}\nolimits_{a}\left(bh^{i}\right)=\operatorname*{ad}\nolimits_{a}\left(b\right)\cdot h^{i}
for each
i\in\mathbb{N}
.

Proof 4.7

(Proof of Proposition
4.6
.)
.

From
\left[h,a\right]=0
, we obtain
0=\left[h,a\right]=ha-ah
(by the definition of
\left[h,a\right]
). In other words,
ha=ah
. Hence,

h^{i}a=ah^{i}\ \ \ \ \ \ \ \ \ \ \text{for each }i\in\mathbb{N}\text{.}

(24)

[
Proof of (
24
):
This follows by
induction on
i
, using
ha=ah
in the induction step.]

Now, let
i\in\mathbb{N}
. Then, the definition of
\operatorname*{ad}\nolimits_{a}
yields

\operatorname*{ad}\nolimits_{a}\left(b\right)=\left[a,b\right]=ab-ba\ \ \ \ \ \ \ \ \ \ \left(\text{by the definition of }\left[a,b\right]\right).

But the definition of
\operatorname*{ad}\nolimits_{a}
also yields

\displaystyle\operatorname*{ad}\nolimits_{a}\left(bh^{i}\right)

\displaystyle=\left[a,bh^{i}\right]=a\left(bh^{i}\right)-\left(bh^{i}\right)a\ \ \ \ \ \ \ \ \ \ \left(\text{by the definition of }\left[a,bh^{i}\right]\right)

\displaystyle=abh^{i}-b\underbrace{h^{i}a}_{\begin{subarray}{c}=ah^{i}\\
\text{(by
(\ref{pf.prop.deriv.triv-comm.hia}))}\end{subarray}}=abh^{i}-bah^{i}=\underbrace{\left(ab-ba\right)}_{=\operatorname*{ad}\nolimits_{a}\left(b\right)}h^{i}

\displaystyle=\operatorname*{ad}\nolimits_{a}\left(b\right)\cdot h^{i}.

This proves Proposition
4.6
.

Corollary 4.8
.

Let
g\in\mathbb{K}\left[t\right]
. Let
p\in\mathbb{N}
. Then,

\operatorname*{ad}\nolimits_{a}^{p}\left(g\left(x\right)\right)=g^{\left(p\right)}\left(x\right)\cdot h^{p}.

Proof 4.9

(Proof of Corollary
4.8
.)
.

We shall prove Corollary

4.8
by induction on
p
:

Induction base:
Comparing
\underbrace{\operatorname*{ad}\nolimits_{a}^{0}}_{=\operatorname*{id}}\left(g\left(x\right)\right)=\operatorname*{id}\left(g\left(x\right)\right)=g\left(x\right)

with
\underbrace{g^{\left(0\right)}}_{=g}\left(x\right)\cdot\underbrace{h^{0}}_{=1}=g\left(x\right)
, we obtain
\operatorname*{ad}\nolimits_{a}^{0}\left(g\left(x\right)\right)=g^{\left(0\right)}\left(x\right)\cdot h^{0}
. In other words, Corollary
4.8

holds for
p=0
. This completes the induction base.

Induction step:
Let
n\in\mathbb{N}
. Assume that Corollary

4.8
holds for
p=n
. We must prove that Corollary

4.8
holds for
p=n+1
.

We have assumed that Corollary
4.8
holds for
p=n
. In other
words, we have

\operatorname*{ad}\nolimits_{a}^{n}\left(g\left(x\right)\right)=g^{\left(n\right)}\left(x\right)\cdot h^{n}.

Now,

\displaystyle\underbrace{\operatorname*{ad}\nolimits_{a}^{n+1}}_{=\operatorname*{ad}\nolimits_{a}\circ\operatorname*{ad}\nolimits_{a}^{n}}\left(g\left(x\right)\right)

\displaystyle=\left(\operatorname*{ad}\nolimits_{a}\circ\operatorname*{ad}\nolimits_{a}^{n}\right)\left(g\left(x\right)\right)=\operatorname*{ad}\nolimits_{a}\left(\underbrace{\operatorname*{ad}\nolimits_{a}^{n}\left(g\left(x\right)\right)}_{=g^{\left(n\right)}\left(x\right)\cdot h^{n}}\right)

\displaystyle=\operatorname*{ad}\nolimits_{a}\left(g^{\left(n\right)}\left(x\right)\cdot h^{n}\right)=\operatorname*{ad}\nolimits_{a}\left(g^{\left(n\right)}\left(x\right)\right)\cdot h^{n}

(25)

(by Proposition
4.6
, applied to
b=g^{\left(n\right)}\left(x\right)
and
i=n
).

But Proposition
4.4

(b)
(applied to
g^{\left(n\right)}
instead of
g
) yields

a\cdot g^{\left(n\right)}\left(x\right)=g^{\left(n\right)}\left(x\right)\cdot a+\left(g^{\left(n\right)}\right)^{\prime}\left(x\right)\cdot h.

In view of
\left(g^{\left(n\right)}\right)^{\prime}=g^{\left(n+1\right)}
(this follows from the definitions of
g^{\left(n\right)}

and
g^{\left(n+1\right)}
), we can rewrite this as

a\cdot g^{\left(n\right)}\left(x\right)=g^{\left(n\right)}\left(x\right)\cdot a+g^{\left(n+1\right)}\left(x\right)\cdot h.

(26)

Now, the definition of
\operatorname*{ad}\nolimits_{a}
yields

\displaystyle\operatorname*{ad}\nolimits_{a}\left(g^{\left(n\right)}\left(x\right)\right)

\displaystyle=\left[a,g^{\left(n\right)}\left(x\right)\right]=a\cdot g^{\left(n\right)}\left(x\right)-g^{\left(n\right)}\left(x\right)\cdot a

\displaystyle\ \ \ \ \ \ \ \ \ \ \left(\text{by the definition of }\left[a,g^{\left(n\right)}\left(x\right)\right]\right)

\displaystyle=g^{\left(n+1\right)}\left(x\right)\cdot h\ \ \ \ \ \ \ \ \ \ \left(\text{by (\ref{pf.cor.deriv-ad.4})}\right).

Hence, (
25
) becomes

\operatorname*{ad}\nolimits_{a}^{n+1}\left(g\left(x\right)\right)=\underbrace{\operatorname*{ad}\nolimits_{a}\left(g^{\left(n\right)}\left(x\right)\right)}_{=g^{\left(n+1\right)}\left(x\right)\cdot h}\cdot h^{n}=g^{\left(n+1\right)}\left(x\right)\cdot\underbrace{h\cdot h^{n}}_{=h^{n+1}}=g^{\left(n+1\right)}\left(x\right)\cdot h^{n+1}.

In other words, Corollary
4.8
holds for
p=n+1
. This completes
the induction step. Thus, Corollary
4.8
is proven by induction.

4.3
Proofs of Proposition
4.3
and Theorem

4.2

Proof 4.10

(Proof of Proposition
4.3
.)
.

If
b\in\mathbb{L}
is
arbitrary, then

\left(U_{b}\right)_{i,j}=\begin{cases}\dbinom{i}{j}\operatorname*{ad}\nolimits_{a}^{i-j}\left(b\right),&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}

(27)

for each
i\in\left\{0,1,\ldots,m-1\right\}
and
j\in\left\{0,1,\ldots,m-1\right\}
(by (
3
)).

On the other hand, (
22
) shows that

\left(V_{g}\right)_{i,j}=\begin{cases}\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j},&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}

(28)

for each
i\in\left\{0,1,\ldots,m-1\right\}
and
j\in\left\{0,1,\ldots,m-1\right\}
.

Now, let us fix
i\in\left\{0,1,\ldots,m-1\right\}
and
j\in\left\{0,1,\ldots,m-1\right\}
. We shall prove that
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
.

Indeed, we are in one of the following two cases:

Case 1:
We have
i\geq j
.

Case 2:
We have
i<j
.

Let us first consider Case 1. In this case, we have
i\geq j
. Hence,

i-j\in\mathbb{N}
. Thus, Corollary
4.8
(applied to
p=i-j
)
yields

\operatorname*{ad}\nolimits_{a}^{i-j}\left(g\left(x\right)\right)=g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j}.

Now, (
27
) (applied to
b=g\left(x\right)
)
yields

\displaystyle\left(U_{g\left(x\right)}\right)_{i,j}

\displaystyle=\begin{cases}\dbinom{i}{j}\operatorname*{ad}\nolimits_{a}^{i-j}\left(g\left(x\right)\right),&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}=\dbinom{i}{j}\underbrace{\operatorname*{ad}\nolimits_{a}^{i-j}\left(g\left(x\right)\right)}_{=g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j}}\ \ \ \ \ \ \ \ \ \ \left(\text{since }i\geq j\right)

\displaystyle=\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j}.

Comparing this with

\displaystyle\left(V_{g}\right)_{i,j}

\displaystyle=\begin{cases}\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j},&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}\ \ \ \ \ \ \ \ \ \ \left(\text{by (\ref{pf.prop.copeland-main.Vgij=})}\right)

\displaystyle=\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j}\ \ \ \ \ \ \ \ \ \ \left(\text{since }i\geq j\right),

we obtain
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
. Thus,
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
is proven in Case 1.

Let us next consider Case 2. In this case, we have
i<j
. Hence,
(
28
) becomes

\left(V_{g}\right)_{i,j}=\begin{cases}\dbinom{i}{j}g^{\left(i-j\right)}\left(x\right)\cdot h^{i-j},&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}=0\ \ \ \ \ \ \ \ \ \ \left(\text{since }i<j\right).

But (
27
) (applied to
b=g\left(x\right)
)
yields

\left(U_{g\left(x\right)}\right)_{i,j}=\begin{cases}\dbinom{i}{j}\operatorname*{ad}\nolimits_{a}^{i-j}\left(g\left(x\right)\right),&\text{if }i\geq j;\\
0,&\text{if }i<j\end{cases}=0\ \ \ \ \ \ \ \ \ \ \left(\text{since }i<j\right).

Comparing these two equalities, we find
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
. Thus,
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
is proven in Case 2.

We have now proven the equality
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
in both Cases 1 and 2. Hence, this
equality always holds.

Now, forget that we fixed
i
and
j
. We thus have shown that
\left(U_{g\left(x\right)}\right)_{i,j}=\left(V_{g}\right)_{i,j}
for all

i\in\left\{0,1,\ldots,m-1\right\}
and
j\in\left\{0,1,\ldots,m-1\right\}
. In other words, each entry of the
m\times m
-matrix

U_{g\left(x\right)}
equals the corresponding entry of the
m\times m
-matrix
V_{g}
. Hence,
U_{g\left(x\right)}=V_{g}
. This proves
Proposition
4.3
.

Proof 4.11

(Proof of Theorem
4.2
.)
.

Theorem
2.7
(applied to

b=g\left(x\right)
) yields

\left(g\left(x\right)\cdot a\right)^{n}=e_{0}^{T}\left(\underbrace{U_{g\left(x\right)}}_{\begin{subarray}{c}=V_{g}\\
\text{(by Proposition
\ref{prop.copeland-main})}\end{subarray}}S\right)^{n}H_{1}=e_{0}^{T}\left(V_{g}S\right)^{n}H_{1}.

This proves Theorem
4.2
.
