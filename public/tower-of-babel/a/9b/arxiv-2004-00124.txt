Axiomatizing Hybrid XPath with Data
Carlos Areces, Raul Fervari

Abstract
. In this paper we introduce sound and strongly complete axiomatizations for XPath with data constraints extended with hybrid operators. First, we present HXPath = \text{HXPath}_{=} , a multi-modal version of XPath with data, extended with nominals and the hybrid operator @ @ . Then, we introduce an axiomatic system for HXPath = \text{HXPath}_{=} , and we prove it is strongly complete with respect to the class of abstract data models, i.e., data models in which data values are abstracted as equivalence relations. We prove a general completeness result similar to the one presented in, e.g., [ BtC06 ] , that ensures that certain extensions of the axiomatic system we introduce are also complete. The axiomatic systems that can be obtained in this way cover a large family of hybrid XPath languages over different classes of frames, for which we present concrete examples. In addition, we investigate axiomatizations over the class of tree models, structures widely used in practice. We show that a strongly complete, finitary, first-order axiomatization of hybrid XPath over trees does not exist, and we propose two alternatives to deal with this issue. We finally introduce filtrations to investigate the status of decidability of the satisfiability problem for these languages.

1.
XPath as a Modal Logic with Data Tests

XPath is, arguably, the most widely used query language for the
eXtensible Markup Language (XML). Indeed, XPath is implemented in
XSLT
[
wad00
]
and XQuery
[
wwwc02
]
and it is used in many
specification and update languages (e.g., Saxon). It is,
fundamentally, a general purpose language for addressing, searching,
and matching pieces of an XML document. It is an open standard and
constitutes a World Wide Web Consortium (W3C)
Recommendation
[
xpath:w3c
]
. In
[
kost:xpat15
]
XPath is
adapted to be used
as a powerful query language over knowledge bases.
Core-XPath
[
GKP05
]
is the fragment of XPath 1.0 containing the
navigational behaviour of XPath. It can express properties of the
underlying tree structure of the XML document, such as the label (tag
name) of a node, but it cannot express conditions on the actual data
contained in the attributes. In other words, it is essentially a

classical modal
logic

[
blackburn2001modal
,
HML06
]
. For instance the path
expressions
child, parent
and
descendant-or-self
are
basically the modal operators
\lozenge
,
\lozenge^{-}
and

\lozenge^{*}
respectively.

Core-XPath has been well studied from a modal logic point of view. For
instance, its satisfiability problem is known to be decidable even in
the presence of Document Type Definitions
(DTDs)
[
M04
,
BFG08
]
. Moreover, it is known that it is equivalent,
in terms of expressive power, to first-order logic with two variables
(FO2) over an appropriate signature on trees
[
MdR05
]
, and that it
is strictly less expressive than Propositional Dynamic Logic (PDL)
with converse over trees
[
BK08
]
. Sound and complete
axiomatizations for Core-XPath have been introduced
in
[
CateM09
,
cateLM10
]
. It has been argued that the study of
XPath
from a modal logic point of view is not merely a theoretical challenge
but it has also concrete applications. For instance, by investigating
the
expressive power
of
XPath
fragments it is possible to
determine if an integrity constraint can be simplified. Also, query
containment and query equivalence –two fundamental tasks in query
optimization– can be reduced to the
satisfiability problem
. In
particular these results have direct impact on, e.g., security
[
fan04
]
,
type checking
[
MartensN07
]
and consistency of XML
specifications
[
Arenas2002
]
.

However, from a database perspective, Core-XPath falls short to define the most important construct in a query language: the

join
. Without the ability to relate nodes based on the actual
data values of the attributes, the logic’s expressive power is
inappropriate for many applications. The extension of Core-XPath with
(in)equality tests between attributes of elements in an XML document
is named Core-Data-XPath in
[
BojanczykMSS09
]
. Here, we will call
this logic
\text{XPath}_{=}
. Models of
\text{XPath}_{=}
are usually data trees which can be
seen as XML documents. A data tree is a tree whose nodes contain a
label from a finite alphabet and a data value from an infinite domain.
From a modal logic perspective, these data trees are a particular
class of
relational models
. In recent years other data structures have
been considered, and
\text{XPath}_{=}
has been used to query these
structures. In particular, in this article we
consider arbitrary
data graphs
as models for
\text{XPath}_{=}
. Data
graphs are the underlying mathematical structure in
graph
databases
(see, e.g.,
[
LV12
,
Robinson:2013
,
AnglesG08
]
) and it
is important to study the metalogical properties of languages to query
this particular kind of models (see,
e.g.,
[
LibkinMV16
,
AbriolaBFF18
]
). In this respect, we focus on a
variant of
\text{XPath}_{=}
which provides us with several interesting
expressivity features.

One of the characteristic advantages of graph databases is that they
directly exhibit the
topology
of the data. Most of the
approaches for querying these databases have focused on exploring the
topology of the underlying graph exclusively. However, little
attention has been paid to queries that check how the actual data
contained in the graph nodes relates with the topology.
\text{XPath}_{=}

allows comparison of data values by equality or inequality, even
though it does not grant access to the concrete data values themselves.

The main characteristic of
\text{XPath}_{=}
is to allow formulas of the form

\langle\alpha=\beta\rangle
and
\langle\alpha\neq\beta\rangle
, where
\alpha,\beta

are path expressions that navigate the graph using accessibility
relations: successor, predecessor, and for the particular case of tree-like
models,
descendant, next-sibling, etc.; and
can make tests in intermediate nodes. In addition, in this work we
consider the novel ‘
@
’ navigation operator that allows us to jump to named
nodes. The formula
\langle\alpha=\beta\rangle
(respectively

\langle\alpha\neq\beta\rangle
) is true at a node
x
of a data graph if
there are nodes
y,z
that can be reached by paths satisfying the
expressions
\alpha
and
\beta
respectively, and such that the data value of
y
is
equal (respectively different) to the data value of
z
.

The benefits of having data comparisons is described in the following example.
Consider a social network which stores the information about the
friendship relation between persons, and also stores the date of birth
of each individual in the network. This scene can be represented as in
Figure
1
. Topological information is not sufficient
to distinguish the Alice on the left,
A1
from the Alice on the
right,
A2
(formally, these two nodes are bisimilar for the basic
modal logic). However, the expression ‘the person that is friend of
someone born the same day” expressible in
\text{XPath}_{=}
, is true only at

A1
.

Recent articles investigate
\text{XPath}_{=}
from a modal perspective. For
example, satisfiability and evaluation are discussed
in
[
FigPhD
,
FigueiraS11
,
Figueira12ACM
]
, while model theory and
expressivity are studied
in
[
ADF14
,
ICDT14
,
ICDT14Jair
,
ADF17IC
,
KR16
,
AbriolaBFF18
]
. Query
power and complexity of several
\text{XPath}_{=}
fragments are investigated
in
[
LibkinMV16
,
FigueiraD:2018
]
. In
[
BaeldeLS15
]
, a Gentzen-style sequent
calculus is given for a very restricted fragment of
\text{XPath}_{=}
, named
DataGL. In DataGL, data comparisons are allowed only between the
evaluation point and its successors. An extension of the equational
axiomatic system from
[
cateLM10
]
is introduced
in
[
AbriolaDFF17
]
, allowing downward navigation and
equality/inequality tests.

In this article, we will focus on the proof theory of
\text{XPath}_{=}

extended with hybrid operators. It has been argued that the inclusion
of hybrid operators in a modal language leads to a better proof
theory
[
brau:hybr
]
. In particular, it can lead to general
completeness results for axiomatizations by enabling Henkin style
completeness proofs
[
blackburn2001modal
,
BtC06
]
. Moreover, we
will focus on strong completeness results (i.e., the axiomatizations
we introduce characterize the consequence relation

\Gamma\vdash\varphi
and not only theoremhood
\vdash\varphi
).

First results using hybridization
techniques were introduced in
[
ArecesF16
]
for a basic axiomatic
system for
\text{XPath}_{=}
. In
[
ArecesFS17
]
nominals are
used as labels in a tableaux system.

Contribution.

We will introduce a Hilbert-style axiomatization for
\text{XPath}_{=}
with
forward navigation for multiple accessibility relations, multiple
equality/inequality comparisons, and where node expressions are
extended with nominals (special labels that are valid in only one
node), and path expressions are extended with the hybrid operator
@

(allowing the navigation to some particular named node). We call this
logic
Hybrid XPath with Data
(denoted
\text{HXPath}_{=}
). The language we consider
is a variant of
XPath
fragments for data graphs in the literature.
It improves the expressive power of the fragment
\text{XPath}_{=}

from
[
KR16
,
AbriolaBFF18
]
, e.g., by enabling us to express global
properties. On the other hand, it has similarities with the
fragment GXPath
core
(eq)
from
[
LibkinMV16
]
. GXPath
core
(eq) allows us to express data
properties of nodes that are reachable in a finite number of steps,
due to the reflexive-transitive navigation on atomic steps. However,
the hybrid operator
@
in
\text{HXPath}_{=}
is enough to capture some of its
expressivity by allowing us to ‘jump’ to nodes that are not accessible
in one step, or that are simply not connected with the current
node. One of the advantages of our approach, is that hybrid operators
add only first-order behaviour, whereas reflexive-transitive closure
needs second-order expressivity.

We will take advantage of hybrid operators to prove completeness using
a Henkin-style model construction as presented
in
[
Gold1984
,
blackburn2001modal
,
BtC06
,
SchroderP10
]
. In fact, the
use of the so-called unorthodox inference rules (i.e., inference
rules involving side conditions) will help us define an axiom system
whose completeness can be automatically extended to more expressive
logics.

Summing up, our contributions in this article are the
following:

•

We define a sound and strongly complete axiomatic system for
multi-modal
\text{HXPath}_{=}
, refining the axioms and rules first presented
in
[
ArecesF16
]
.

•

We give a Henkin-style completeness proof, proving that the system is
strongly complete for any extension given by pure axioms (formulas
involving only nominals) and existential rules (instantiations of
first-order formulas with quantification pattern
\forall\exists

followed by an
\text{HXPath}_{=}
-formula). This gives us a strong completeness
result with respect to a wide variety of frame classes.

•

Even though the main focus of our work is axiomatizing node
expressions, we also provide as a by-product strong completeness results for
path expressions.

•

We discuss concrete extensions of
\text{HXPath}_{=}
in which completeness
is automatically obtained. In particular we explore backward and
sibling navigation, and equality inclusion.

•

We show that a strongly complete, finitary, first-order
axiomatization of hybrid XPath over trees does not exist. Then we
introduce an infinite pure axiomatic system that is strongly complete
for a slightly larger class of tree models. We also prove that this
system is weakly complete over tree models. As a corollary of the
method we use, we conclude that the satisfiability problem
for
\text{HXPath}_{=}
on trees is decidable in
ExpSpace
.

•

Finally, we prove that the satisfiability problem for the
multi-modal logic
\text{HXPath}_{=}
and some of its pure extensions is
decidable in
NExpTime
, using filtrations to establish a bounded
finite model property. To our knowledge, the best known lower bound
can be obtained by
PSpace
-hardness of mono-modal hybrid
XPath
with forward
navigation
[
ArecesFS17
]
.

Related Work.

It is argued in
[
BtC06
]
that hybrid logic is a natural setting
for deductive systems involving Kripke semantics. By having nominals
in the language, it is possible to imitate the role of first-order
constants to obtain a Henkin-style completeness proof. Moreover,
hybrid operators provide all the necessary machinery to get general
completeness results for a wide variety of systems. The claim is that
allowing the use of
unorthodox rules
, we can define a basic
axiomatic system that can be extended with
pure
axioms
and
existential rules
, which lets us obtain
complete extensions with respect to diverse classes of frames, automatically.

One of the first proof systems for data-aware fragments of
XPath
was
introduced in
[
BaeldeLS15
]
. It is a Gentzen-style system for a
very restricted language named
DataGL
, interpreted on finite data trees.
In
DataGL
formulas of the form
\Diamond_{=}\varphi
are read as:

“the current node
has the same data as a descendant where
\varphi
holds”
. They
introduced a sound and weakly complete sequent calculus for
DataGL
and
established
PSpace
-completeness for its validity problem.

An equational system which extends the one presented for navigational
fragments of
XPath
in
[
cateLM10
]
was introduced
in
[
AbriolaDFF17
]
. The authors consider first the fragment of

\text{XPath}_{=}
without inequality tests, over data trees.
Therein, the proof of weak completeness relies on a
normal form theorem for both node and path expressions, and on a
canonical model construction for consistent formulas in normal form
inspired by
[
fine75
]
. When inequality is also taken into account,
similar ideas can be used but the canonical model construction and the
corresponding completeness proof become quite complex.

A Hilbert-style axiomatization for
\text{XPath}_{=}
extended with hybrid
operators and backward navigation was first introduced in
[
ArecesF16
]
,
using ideas from hybrid logic: nominals play the role of first-order
constants in a Henkin-style completeness proof. The system we present
herein is a vast extension of the work from
[
ArecesF16
]
, and it
automatically encompasses a large family of logics.

In
[
ArecesFS17
]
nominals are used as labels in a tableaux system for
a restricted variant of
\text{HXPath}_{=}
with only one accessibility relation and one
equality relation. The tableaux calculus
is shown to be sound, complete and terminating, and it is used to
prove that the satisfiability problem for such logic is
PSpace
-complete.

Organization.

The article is organized as follows. In Section
2
we introduce the syntax, semantics
and a notion of bisimulation for
\text{HXPath}_{=}
. We define the axiomatic system
\mathsf{HXP}
in
Section
3
and we prove its completeness. We finish that section by
introducing extensions of
\mathsf{HXP}
and their complete axiomatizations
with pure axioms and existential rules. In Section
4
we introduce an axiomatic
system for
XPath
over the class of data trees.
Then, we use filtrations to show
that the satisfiability problem of
\text{HXPath}_{=}
is decidable in
Section
. To
conclude, in Section
we discuss the results and
introduce future lines of research.

2.
Hybrid XPath with Data

In this section we introduce the syntax and semantics for the logic we

\text{HXPath}_{=}
for short).
Then, we present a notion of bisimulation for

2.1.
Syntax and Semantics of
\text{HXPath}_{=}

Thoughout the text, let
\mathsf{Prop}
be a countable set of propositional
symbols; let
\mathsf{Nom}
be a countable set of nominals such that

\mathsf{Prop}\cap\mathsf{Nom}=\emptyset
; and let
\mathsf{Mod}
and
\mathsf{Eq}
be sets
of modal and equality symbols, respectively.

Definition
\thethm

(Syntax)
.

The sets
\mathsf{PExp}
of path expressions (which we will note as

\alpha
,
\beta
,
\gamma
,
\ldots
) and
\mathsf{NExp}
of node
expressions (which we will note as
\varphi
,
\psi
,
\theta
,

\ldots
) of
\text{HXPath}_{=}
are defined by mutual recursion as follows:

\displaystyle\mathsf{PExp}\;

\displaystyle\mathrel{{\mathop{:}}{\mathop{:}}}=\;{\mathsf{a}}\mathrel{\,\mid\,}@_{i}\mathrel{\,\mid\,}[\varphi]\mathrel{\,\mid\,}\alpha\beta

\displaystyle\mathsf{NExp}\;

\displaystyle\mathrel{{\mathop{:}}{\mathop{:}}}=\;p\mathrel{\,\mid\,}i\mathrel{\,\mid\,}\neg\varphi\mathrel{\,\mid\,}\varphi\wedge\psi\mathrel{\,\mid\,}\langle\alpha=_{e}\beta\rangle\mathrel{\,\mid\,}\langle\alpha\neq_{e}\beta\rangle,

where
p\in\mathsf{Prop}
,

,
\mathsf{a}\in\mathsf{Mod}
,

,

, and

.
We will refer to members of
\mathsf{PExp}\cup\mathsf{NExp}
as

. In what follows, when referring to expressions
of
\text{HXPath}_{=}
we will reserve the term

for members of

\mathsf{NExp}
. We say that an expression is

if it
does not contain propositional symbols.

Notice that path expressions occur in node expressions in
data

of the form
\langle\alpha=_{e}\beta\rangle
and

\langle\alpha\neq_{e}\beta\rangle
, while node expressions occur in path
expressions in
tests
like
[\varphi]
.

In what follows we will always use
*
for

and
\not=_{e}
, when
the particular operator used is not relevant. Other Boolean operators
are defined as usual:
\varphi\vee\psi:=\neg(\neg\varphi\wedge\neg\psi)
, and

\varphi\rightarrow\psi:=\neg\varphi\vee\psi
. Below we define other operators as

.

Let
\alpha,\beta,\delta

:=

:=

[\top]

:=

\neg\langle\alpha\neq_{e}\beta\rangle

We now define the structures that will be used to evaluate
formulas in the language.

Definition
\thethm

(Hybrid Data Models)
.

An
abstract hybrid data model
is a tuple
\mathcal{M}=\langle M,

\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V},\mathit{nom}\rangle
,
where
M
is a non-empty set of elements; for each
e\in\mathsf{Eq}
,

{\sim_{e}}\subseteq M\times M
is an equivalence relation between
elements of
M
; for each
\mathsf{a}\in\mathsf{Mod}
,

{R_{\mathsf{a}}}\subseteq M\times M
is the associated accessibility
relation;
\mathit{V}:M\rightarrow 2^{\mathsf{Prop}}
is the valuation function; and

\mathit{nom}:\mathsf{Nom}\rightarrow M
is a function that assigns nominals to certain
elements. Given
m\in M
,
(\mathcal{M},m)
is called a
pointed
model
(parentheses are usually dropped).

An
abstract data frame
(or just
frame
) is a tuple

\mathcal{F}=\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}}\rangle
. Let

\mathfrak{F}
be a class of frames, its
class of
models
is

\mathsf{Mod}(\mathfrak{F})=\{\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V},\mathit{nom}\rangle\mid\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\rangle\in\mathfrak{F},\text{ for $\mathit{V},\mathit{nom}$ arbitrary}\}
.

A
concrete hybrid data model
is a tuple

\mathcal{M}=\langle M,D,\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V},\mathit{nom},data\rangle
, where
M
is a
non-empty set of elements;
D
is a non-empty set of data; for each

\mathsf{a}\in\mathsf{Mod}
,
{R_{\mathsf{a}}}\subseteq M\times M
is the associated
accessibility relation;
\mathit{V}:M\rightarrow 2^{\mathsf{Prop}}
is the valuation
function;
\mathit{nom}:\mathsf{Nom}\rightarrow M
is a function which names some nodes; and

data:\mathsf{Eq}\times M\rightarrow D
is a function which assigns a data
value to each node of the model (for each type of equality
considered in the model).

Concrete data models are most commonly used in applications, where we
encounter data from an infinite alphabet (e.g., alphabetic strings)
associated to the nodes in a semi-structured database, and different
ways of comparing this data. It is easy to see that to each concrete
data model we can associate an abstract data model where
data is replaced by an equivalence relation that links all nodes with
the same data, for each equality symbol from
\mathsf{Eq}
.
Vice-versa, each abstract data model can be
“concretized” by assigning to each pair node and symbol from
\mathsf{Eq}
,
its equivalence data class as data. We will prove soundness and
completeness over the class of abstract data models and, as a corollary,
obtain completeness over concrete data models.

Definition
\thethm

(Semantics)
.

Let
\mathcal{M}=\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V},\mathit{nom}\rangle
be an abstract data model, and

We define the semantics of
\text{HXPath}_{=}

\begin{array}[]{r@{ \ \ \iff\ \ }l}\mathcal{M},m,n\models\mathsf{a}\ \ \mbox{iff}&mR_{\mathsf{a}}n\\

3.
Axiomatization

In this section we introduce the axiomatic system
\mathsf{HXP}
for

\text{HXPath}_{=}
. It is an extension of an axiomatic system for the hybrid

\mathcal{HL}(@)
which adds nominals and the

[

extensions of the language

3.2.
Extended Axiomatic Systems

In the next section we will prove that not only

is complete
with respect to the class of all models, but that extensions of

with

and

preserve completeness with respect to the corresponding class of

The use of nominals, and in particular pure axioms and existential saturation rules, allows us to characterize
classes of models that are not definable without them. For instance, the
hybrid axiom

forces the accessibility relation
related to

in the model to be

which cannot be expressed in the basic modal logic. In this way, we can express
properties about the underlying topology of a data model and also impose restrictions about the data fields. For instance,
the axiom

that will be discussed in Section

expresses that if two nodes coincide in the data field

must also coincide in the data field
d

Standard Translation.

In order to establish frame

Definition
\thethm
.

The correspondence language for expressions of

\begin{array}[]{lcl}\mathsf{ST}^{\prime}_{x}(i)&=&x=x_{i}\\

\mathsf{ST}^{\prime}_{x}(\neg\varphi)&=&\neg\mathsf{ST}^{\prime}_{x}(\varphi)\\
\mathsf{ST}^{\prime}_{x}(\varphi\wedge\psi)&=&\mathsf{ST}^{\prime}_{x}(\varphi)\wedge\mathsf{ST}^{\prime}_{x}(\psi)\\

\mathsf{ST}^{\prime}_{x,y}(\alpha\beta)&=&\exists z.~\mathsf{ST}^{\prime}_{x,z}(\alpha)\wedge\mathsf{ST}^{\prime}_{z,y}(\beta),\end{array}

.

interesting properties.

Definition 3.15

)

\begin{array}[]{l@{~=~}l@{\quad\quad\quad}l@{~=~}l}{\mid}\mathsf{a}{\mid}&2&{\mid}p{\mid}&1,~p\in\mathsf{Prop}\cup\mathsf{Nom}\\

{\mid}[\varphi]{\mid}&1+{\mid}\varphi{\mid}&{\mid}\varphi\wedge\psi{\mid}&{\mid}\varphi{\mid}+{\mid}\psi{\mid}\\
{\mid}\alpha\beta{\mid}&{\mid}\alpha{\mid}+{\mid}\beta{\mid}&{\mid}\langle\alpha*\beta\rangle{\mid}&{\mid}\alpha{\mid}+{\mid}\beta{\mid},\end{array}

Lemma 3.16

(Truth Lemma)
.

Let

\varphi
be a node expression and
\alpha

(IH2):

\mathcal{M}_{\Gamma},\Delta_{i},\Delta_{j}\models\alpha~~\mbox{iff}~~@_{i}\langle\alpha\rangle j\in\Gamma.

The proof is a double induction argument, proceeding first on the
structural complexity of
\varphi
and
\alpha

of path-formulas as per Definition

First, we prove the base cases:

-

(by

@_{i}\langle\mathsf{a}\rangle j\in\Gamma

\Delta_{j}=\Delta_{k}
, and because we know that

,

3.4.
Completeness for path formulas

The main contribution of this article is a characterization of (local) semantic
consequence between node formulas by means of an axiomatic
system. Given that soundness of an axiomatic system is usually
granted, this is the main outcome of the strong completeness result we
just proved. In the setting of XPath it also makes sense to discuss
the issue of inference between path formulas. Path inference
can be traced back to
[
Pratt91
]
, in the context of dynamic algebras.
We will now show how Theorem
2
can also be used to
characterize path inference.

First, recall that previous work like
[
cateLM10
,
AbriolaDFF17
]

provided
equational
axiomatizations that characterize
theorems of the form
\vdash\varphi\equiv\psi
(for
\varphi,\psi

node expressions) and
\vdash\alpha\equiv\beta
(for
\alpha,\beta

path expressions). The first are obviously covered by our results that
characterize theoremhood for arbitrary node expressions (in this
case
\equiv
is nothing more than
\leftrightarrow
). For
equivalence between path formulas the following proposition suffices:

Proposition 3.22
.

Let
\alpha,\beta
be path expressions in
\text{HXPath}_{=}
, then
\models\alpha\equiv\beta
iff
\models@_{i}\langle\alpha\rangle j\leftrightarrow@_{i}\langle\beta\rangle j
for
i,j
not appearing in
\alpha,\beta
.

Hence, completeness for equivalence theorems between path formulas follow from
Theorem
2
. More interesting is to consider whether a
strong completeness result for path consequence is also possible.
We need first to introduce this notion. There exists at least two natural
possible definitions:

Definition 3.23
.

Let
\Lambda\cup\{\alpha\}
be a set of path formulas in
\text{HXPath}_{=}
,
and let
\mathfrak{C}
be a class of models.
Define

•

\Lambda\models^{1}_{\mathfrak{C}}\alpha
iff for any model

\mathcal{M}\in\mathfrak{C}
, (
\forall m,n
,

\mathcal{M},m,n\models\Lambda
implies
\mathcal{M},m,n\models\alpha
).

•

\Lambda\models^{2}_{\mathfrak{C}}\alpha
iff for any model

\mathcal{M}\in\mathfrak{C}
,
(
\forall m,n
,
\mathcal{M},m,n\models\Lambda
implies
\forall m,n
,
\mathcal{M},m,n\models\alpha
).

As before we write
\models
instead of
\models_{\mathfrak{C}}
if
the intended class is clear from context. From the above definition
it is easy to show that
\models^{1}_{\mathfrak{C}}
implies

\models^{2}_{\mathfrak{C}}
but not vice versa.
Now, both
\models^{1}
and
\models^{2}
can be captured using Theorem
2
.

Theorem 3.23
.

Let
\Pi
be a set of pure axioms and
\mathrm{P}
be a set of existential
saturation rules. Let
\mathfrak{C}=\mathsf{Mod}(\mathfrak{F})

for
\mathfrak{F}
the class of frames satisfying
\textsf{FC}(\Pi)\wedge\textsf{FC}(\mathrm{P})
.
Let
\Lambda\cup\{\alpha\}
be a set of path expressions in
\text{HXPath}_{=}

then

(1)

implies
\{@_{i}\langle\beta\rangle j\mid\beta\in\Lambda\}\vdash@_{i}\langle\alpha\rangle j
,
for
i,j
not in
\Lambda\cup\{\alpha\}
.

(2)

\Lambda\models^{2}_{\mathfrak{C}}\alpha
implies
\{@_{i}\langle\beta\rangle j\mid\beta\in\Lambda\}\vdash@_{k}\langle\alpha\rangle l
,
for
i,j,k,l
not in
\Lambda\cup\{\alpha\}
.

.

The result is a corollary of Theorem

because the
following hold:

(1)

\Lambda\models^{1}_{\mathfrak{C}}\alpha
iff
\{@_{i}\langle\beta\rangle j\mid\beta\in\Lambda\}\models_{\mathfrak{C}}@_{i}\langle\alpha\rangle j
,
for
i,j
not in
\Lambda\cup\{\alpha\}
.

.

3.5.
Some Concrete Examples of Pure Extensions

In this section we introduce some extensions of
\text{HXPath}_{=}
, and their
corresponding extended axiomatic systems. In all cases, we can apply
the result from previous section and automatically obtain
completeness, since we only use pure axioms and/or existential
saturation rules.

Backwards Navigation.

We start with the language
\text{HXPath}_{=}(\shortminus)
, i.e.,
\text{HXPath}_{=}
extended with the

\mathcal{M},x,y\models\mathsf{a^{\shortminus}}~~\mbox{iff}~~yR_{\mathsf{a}}x.

additional modal operator from
\mathsf{Mod}
(to which all rules and axioms of
\mathsf{HXP}

apply), and in addition we will insist that in models of
\text{HXPath}_{=}(\shortminus)
,
this accessibility relation is always interpreted as the inverse of

\mathsf{a}
.

Formally, consider two modal symbols
\mathsf{a}
and
\mathsf{a^{\shortminus}}
in
\mathsf{Mod}
(and
assume that their respective accessibility relations in a model are

R_{\mathsf{a}}
and
R_{\mathsf{a^{\shortminus}}}
). Define the set
\Pi_{1}
of pure axioms
that characterizes the interaction between
\mathsf{a}
and
\mathsf{a^{\shortminus}}
as

Axioms for
\mathsf{a},\mathsf{a^{\shortminus}}

down-up

\vdash i\rightarrow[\mathsf{a}]\langle\mathsf{a^{\shortminus}}\rangle i

up-down

\vdash i\rightarrow[\mathsf{a^{\shortminus}}]\langle\mathsf{a}\rangle i

Since the axioms presented above are pure, the axiom system we obtain
is complete for models obtained from frames satisfying
\textsf{FC}(\Pi_{1})
.
It is a simple exercise to verify that
\textsf{FC}(\Pi_{1})
is equivalent to

\forall x.\forall y.(R_{\mathsf{a}}(x,y)\leftrightarrow R_{\mathsf{a^{\shortminus}}}(y,x))
.

Proposition 3.25
.

\mathsf{HXP}+\Pi_{1}
is sound and strongly complete for
\text{HXPath}_{=}(\shortminus)
.

We consider now the extension of

Consider now three modal symbols

4.
Hybrid XPath on Trees

The Henkin-style model construction from Section
3.3

provides us with the tools to obtain complete axiomatizations for a
wide variety of extensions of
\text{HXPath}_{=}
. However there are interesting
cases in which completeness is not a direct corollary of the
results we already presented. One such case is the class of tree
models which we call
\mathfrak{C}_{tree}
.

We will devote this section to investigate hybrid
XPath
over the
class of tree models. First, in Section
4.1
we
will show that it is not possible to get a strongly complete finitary
first-order axiomatization over trees. In
Section
4.2
we show that it is possible to obtain a
strongly complete infinite first-order axiomatization over a slightly
larger class of models, while in Section
4.3
we
prove that this axiomatization is weakly complete for
\mathfrak{C}_{tree}
.

Tree models are interesting in this context since
XPath
is commonly used as a query
language over
XML
documents; and mathematically, the relational structure of
an
XML
document is a tree. In our setting, this consists of asking that the
union of all relations in a model has a tree-shape.

Without loss of generality, in the rest of this section we will work
in a mono-modal setting, with a unique basic path expression
\mathsf{a}
,
and with single equality/inequality comparisons denoted
=
and

\neq
. The path expression
\mathsf{a}
will be interpreted over an
accessibility relation
R_{\mathsf{a}}
, representing the union of all the
accessibility relations in the model. To achieve this, we need to work
in a signature where the set
\mathsf{Mod}
is finite. Therefore, we can include the
followig additional axiom:

\mathsf{a}
-definition

\langle\mathsf{a}\rangle\top\leftrightarrow\langle\mathsf{a}_{1}\cup\ldots\cup\mathsf{a}_{k}\rangle\top

with
\mathsf{Mod}=\{\mathsf{a}_{1},\ldots,\mathsf{a}_{k}\}

It is a straightforward exercise to show that this axiom characterizes
R_{\mathsf{a}}
as the union
of all the relations of the model, in a signature where
\mathsf{Mod}
is finite.
As a consequence, in this section we will focus on axiomatizing
R_{\mathsf{a}}
as the
acessibility relation of a tree.
In this way, we obtain
the intended meaning for
XPath
as a query language for
XML
documents.

Hence, a model in this signature is a tuple

\mathcal{M}=\langle M,\sim,R_{\mathsf{a}},\mathit{V},\mathit{nom}\rangle
, in which
we have a unique data equality relation
\sim
and the
accessibility relation
R_{\mathsf{a}}
.

4.1.
Failure of Strong Completeness over Trees

Let us start by formally defining the structures we will consider.

Definition 4.1
.

\mathfrak{C}_{tree}
is defined as the class of abstract hybrid data
models
\langle M,\sim,R_{\mathsf{a}},\mathit{V},\mathit{nom}\rangle
satisfying:

•

there is a unique point in
M
without predecessors by

R_{\mathsf{a}}
, which we call the
root
;

•

every node
n\in M
is reachable from the root by
R_{\mathsf{a}}

in zero or more steps;

•

for all
n,l,l^{\prime}\in M
, if
lR_{\mathsf{a}}n
and

l^{\prime}R_{\mathsf{a}}n
, then
l=l^{\prime}
; and

•

there is no
n\in M
such that
n
is reachable by
R_{\mathsf{a}}

from itself in one or more steps.

Intuitively, a model

\langle M,\sim,R_{\mathsf{a}},\mathit{V},\mathit{nom}\rangle
is in
\mathfrak{C}_{tree}
if
\langle M,R_{\mathsf{a}}\rangle

is a tree.

In order to show that there is no finitary first-order axiomatization
for
\text{HXPath}_{=}
over
\mathfrak{C}_{tree}
, we will use a standard tool from first-order
model theory: the
compacteness
theorem. In particular, we will
show that
\text{HXPath}_{=}
over
\mathfrak{C}_{tree}
is not compact, and consequently, a
finitary axiomatization may not exist (see, e.g.,
[
Enderton:2001
]

for details).

Proposition 4.2
.

\text{HXPath}_{=}
is not compact over the class
\mathfrak{C}_{tree}
.

Proof 4.3
.

We need to show that there exists an infinite set of

\text{HXPath}_{=}
-formulas such that every finite subset

\Gamma^{fin}\subset\Gamma
is satisfiable in the class
\mathfrak{C}_{tree}
, but

\Gamma
is not.

Without loss of generality, we will use natural numbers as names for nominals,
i.e.,
\mathsf{Nom}={\rm Nature}
. We start by defining the following formula indicating that, at
the given point, the nominal
k
is the only one satisfied from the set
\{0,\ldots,n\}
:

\mathsf{Only}^{n}_{k}=@_{k}(\underset{0\leq j\neq k\leq n}{\bigwedge}\neg j).

We can define for

\par In the previous section we already obtained decidability for $\text{HXPath}_{=}$ on trees.
In this section we introduce \emph{filtrations}, a notion which will
help us to establish a bounded finite model property and an upper
bound for the complexity of satisfiability for
$\text{HXPath}_{=}(\shortminus)$ over the
class of all abstract hybrid data models. Recall that $\text{HXPath}_{=}(\shortminus)$ is the
extension of $\text{HXPath}_{=}$ with inverse modalities.
\par In Section~\ref{sec:prelim} we introduced path expressions of the form
$\alpha\cup\beta$ as an abbreviation, but this definition potentially
leads to an exponential blow up in the size of the formula. In this
section we will consider $\cup$ as part of the language of $\text{HXPath}_{=}(\shortminus)$ to
avoid this blow up.
\par\begin{definition}Let $\Sigma$ be a set of formulas of $\text{HXPath}_{=}$. We say that $\Sigma$
is {closed} if:
\begin{itemize}\itemize@item@$\neg\varphi\in\Sigma$ implies $\varphi\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\varphi\wedge\psi\in\Sigma$ implies $\varphi,\psi\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\langle\alpha*\beta\rangle\in\Sigma$ implies
$\langle\alpha\rangle\top,\langle\beta\rangle\top\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\langle[\varphi]\rangle\top\in\Sigma$ implies $\varphi\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\langle@_{i}\rangle\top\in\Sigma$ implies $i\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\langle\alpha\beta\rangle\top\in\Sigma$ implies
$\langle\alpha\rangle\top,\langle\beta\rangle\top\in\Sigma$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\langle\alpha\cup\beta\rangle\top\in\Sigma$ implies
$\langle\alpha\rangle\top,\langle\beta\rangle\top\in\Sigma$.
\end{itemize}\end{definition}\par\begin{definition}Let $\Sigma$ be a closed set of formulas, and $\mathcal{M}$ be an
abstract hybrid data model with $m,n$ states in $\mathcal{M}$. We define
$m\leftrightsquigarrow_{\Sigma}n$ if and only if for all $\varphi\in\Sigma$
($\mathcal{M},m\models\varphi$ iff $\mathcal{M},n\models\varphi$).
\end{definition}\par Now let us introduce filtration, the construction that will help us to
obtain a \emph{small model property} and give us decidability.
\par\begin{definition}Let $\mathcal{M}=\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{R_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V},\mathit{nom}\rangle$, be an abstract hybrid data model, and $\Sigma$ a closed set of formulas. A {filtration of $\mathcal{M}$ via $\Sigma$} is any
$\mathcal{M}^{f}=\langle M^{f},\{\sim^{f}_{e}\}_{e\in\mathsf{Eq}},\{R^{f}_{\mathsf{a}}\}_{\mathsf{a}\in\mathsf{Mod}},\mathit{V}^{f},\mathit{nom}^{f}\rangle$, such that
\begin{itemize}\itemize@item@$M^{f}=M_{/\leftrightsquigarrow_{\Sigma}}$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@If $mR_{\mathsf{a}}n$ then $[m]R^{f}_{\mathsf{a}}[n]$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@If $[m]R_{\mathsf{a}}^{f}[n]$ then for all $\langle\mathsf{a}\rangle\top\in\Sigma$,
for all $m^{\prime}\in[m]$ there exists $n^{\prime}\in[n]$ such that $\mathcal{M},m^{\prime},n^{\prime}\models\mathsf{a}$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$[m]\sim_{e}^{f}[n]$ iff $m\sim_{e}n$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\mathit{nom}^{f}(i)=[\mathit{nom}(i)]$
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\itemize@item@$\mathit{V}^{f}([m])=\{p\mid p\in\mathit{V}(m)\}$.
\end{itemize}The \emph{smallest filtration} is a filtration that satisfies
$$[m]R_{\mathsf{a}}^{f}[n]\text{ iff there exist }m^{\prime}\in[m],n^{\prime}\in[n]\text{ such that }m^{\prime}R_{\mathsf{a}}n^{\prime}.$$\end{definition}\par\par\begin{theorem}Let $\mathcal{M}$ be an abstract hybrid data model and $\mathcal{M}^{f}$ a filtration of $\mathcal{M}$ for a closed set $\Sigma$. Then
\begin{enumerate}\enumerate@item@For all $\varphi\in\Sigma$, for all $m\in\mathcal{M}$, $\mathcal{M}^{f},[m]\models\varphi$
iff $\mathcal{M},m\models\varphi$, and
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\enumerate@item@For all $\langle\alpha\rangle\top\in\Sigma$, for all $m,n\in\mathcal{M}$,
$\mathcal{M}^{f},[m],[n]\models\alpha$ iff for all $m^{\prime}\in[m]$
there exists $n^{\prime}\in[n]$ such that $\mathcal{M},m^{\prime},n^{\prime}\models\alpha$.
\end{enumerate}\end{theorem}\par\begin{proof}By structural induction. First we prove $1$. The base and Boolean
cases are simple. Let us consider
$\langle\alpha=_{e}\beta\rangle\in\Sigma$.
$\mathcal{M}^{f},[m]\models\langle\alpha=_{e}\beta\rangle$ iff there are
$[n],[u]$ such that
\begin{enumerate}\enumerate@item@$\mathcal{M}^{f},[m],[n]\models\alpha$ iff (by IH and $\langle\alpha\rangle\top\in\Sigma$)
there exist $m^{\prime}\in[m],n^{\prime}\in[n]$ such that $\mathcal{M},m^{\prime},n^{\prime}\models\alpha$,
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\enumerate@item@$\mathcal{M}^{f},[m],[u]\models\beta$ iff (by IH and $\langle\beta\rangle\top\in\Sigma$)
there exist $m^{\prime\prime}\in[m],u^{\prime}\in[u]$ such that
$\mathcal{M},m^{\prime\prime},u^{\prime}\models\beta$, and
\par\vskip 4.0pt\vskip 4.0pt plus 2.0pt minus 1.0pt\enumerate@item@$[n]\sim_{e}^{f}[u]$ iff (definition of $\mathcal{M}^{f}$) $n\sim_{e}u$.
Since $[n]=[n]^{\prime}$ and $[u]=[u]^{\prime}$ we have $n^{\prime}\sim_{e}u^{\prime}$.
\end{enumerate}Notice that the problem is that $m^{\prime}$ might be different from $m^{\prime\prime}$. Suppose for contradiction that
$\mathcal{M},m^{\prime},u^{\prime}\not\models\beta$. Since $\langle\beta\rangle\top\in\Sigma$, $m^{\prime}\in[m]$, and $u^{\prime}\in[u]$, by using $(ii)$ above we get
$\mathcal{M}^{f},[m],[u]\not\models\beta$, which is a contradiction.
Therefore, $\mathcal{M},m^{\prime}\models\langle\alpha=_{e}\beta\rangle$.
The case for $\langle\alpha\neq_{e}\beta\rangle$ is similar.
\vskip 6.0pt plus 2.0pt minus 2.0pt\par\noindent Now let us prove $2$:
\par\noindent- Case $\langle[\varphi]\rangle\top\in\Sigma$. For the left to the right
direction, suppose $\mathcal{M}^{f},[m],[n]\models[\varphi]$, iff
$[m]=[n]$ and $\mathcal{M}^{f},[m]\models\varphi$. By $1$ we have
$\mathcal{M},m\models\varphi$, then by definition of $[m]$,
$\mathcal{M},m^{\prime}\models\varphi$, for all $m^{\prime}\in[m]$. Hence
$\mathcal{M},m^{\prime},m^{\prime}\models[\varphi]$ as wanted, since $m^{\prime}\in[n]$.
\par For the other direction, suppose that for all $m^{\prime}\in[m]$ there
exists $n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models[\varphi]$. Then
$m^{\prime}=n^{\prime}$ and $\mathcal{M},m^{\prime}\models\varphi$. By $1$,
$\mathcal{M}^{f},[m^{\prime}]\models\varphi$, and since $[m]=[m^{\prime}]$,
$\mathcal{M}^{f},[m]\models\varphi$. Therefore
$\mathcal{M}^{f},[m],[n]\models[\varphi]$, because $n^{\prime}=m^{\prime}$ implies
$[n]=[n^{\prime}]=[m^{\prime}]=[m]$.
\vskip 3.0pt plus 1.0pt minus 1.0pt\par\noindent- Case $\langle@_{i}\rangle\top\in\Sigma$. For the left to the right direction
suppose $\mathcal{M}^{f},[m],[n]\models@_{i}$, iff $\mathit{nom}^{f}(i)=[n]$.
By definition of $\mathit{nom}^{f}$, we have $\mathit{nom}^{f}(i)=[\mathit{nom}(i)]$, then
$\mathit{nom}(i)=n$. Hence $\mathcal{M},m,n\models@_{i}$.
\par For the other direction, suppose that for all $m^{\prime}\in[m]$ there
exists $n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models@_{i}$, iff
$\mathit{nom}(i)=n^{\prime}$. Then $[n^{\prime}]=\{n^{\prime}\}=[n]$, therefore
$\mathcal{M}^{f},[m],[n]\models@_{i}$.
\vskip 3.0pt plus 1.0pt minus 1.0pt\par\noindent- Case $\langle\mathsf{a}\rangle\top\in\Sigma$. For the left to the right
direction suppose $\mathcal{M}^{f},[m],[n]\models\mathsf{a}$, iff
$[m]R_{\mathsf{a}}^{f}[n]$. Then, since $\langle\mathsf{a}\rangle\top\in\Sigma$, for
all $m^{\prime}\in[m]$ there exists $n^{\prime}\in[n]$ s.t.
$\mathcal{M},m^{\prime},n^{\prime}\models\mathsf{a}$ (by the second condition on the definition
of $R_{\mathsf{a}}^{f}$), as wanted.
\par For the right to the left direction, suppose for all $m^{\prime}\in[m]$
there exists $n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\mathsf{a}$. Then
$m^{\prime}R_{\mathsf{a}}n^{\prime}$, and by the first condition of the definition of
$R_{\mathsf{a}}^{f}$ we have $[m^{\prime}]R_{\mathsf{a}}^{f}[n]$, iff
$[m]R_{\mathsf{a}}^{f}[n]$. Hence,
$\mathcal{M}^{f},[m],[n]\models\mathsf{a}$.
\vskip 3.0pt plus 1.0pt minus 1.0pt\par\noindent- Case $\langle\alpha\beta\rangle\top\in\Sigma$. For the left to the right
direction suppose $\mathcal{M}^{f},[m],[n]\models\alpha\beta$, iff
there exists $[z]$ such that $\mathcal{M}^{f},[m],[z]\models\beta$
and $\mathcal{M}^{f},[z],[n]\models\alpha\beta$. By IH, for all
$m^{\prime}\in[m]$ there exists $z^{\prime}\in[z]$ s.t.
$\mathcal{M},m^{\prime},z^{\prime}\models\alpha$ and for all $z^{\prime}\in[z]$ there exists
$n^{\prime}\in[n]$ s.t. $\mathcal{M},z^{\prime},n^{\prime}\models\beta$. This implies that for
all $m^{\prime}\in[m]$ there exists $n^{\prime}\in[n]$
s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\alpha\beta$.
\par For the other direction, suppose for all $m^{\prime}\in[m]$ there exists
$n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\alpha\beta$. Then there
exists $z^{\prime}$ s.t. $\mathcal{M},m^{\prime},z^{\prime}\models\alpha$ and
$\mathcal{M},z^{\prime},n^{\prime}\models\beta$. By IH we have
$\mathcal{M}^{f},[m],[z^{\prime}]\models\alpha$ and
$\mathcal{M}^{f},[z^{\prime}],[n]\models\beta$. Hence
$\mathcal{M}^{f},[m],[n]\models\alpha\beta$.
\vskip 3.0pt plus 1.0pt minus 1.0pt\par\noindent- Case $\langle\alpha\cup\beta\rangle\top\in\Sigma$. For the left to the right
direction suppose $\mathcal{M}^{f},[m],[n]\models\alpha\cup\beta$, iff
$\mathcal{M}^{f},[m],[n]\models\alpha$ or
$\mathcal{M}^{f},[m],[n]\models\beta$. By IH, for all $m^{\prime}\in[m]$
there exists $n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\alpha$ or
$\mathcal{M},m^{\prime},n^{\prime}\models\beta$. This implies that for all $m^{\prime}\in[m]$
there exists $n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\alpha\cup\beta$.
\par For the other direction, suppose for all $m^{\prime}\in[m]$ there exists
$n^{\prime}\in[n]$ s.t. $\mathcal{M},m^{\prime},n^{\prime}\models\alpha\cup\beta$, iff
$\mathcal{M},m^{\prime},n^{\prime}\models\alpha$ or $\mathcal{M},m^{\prime},n^{\prime}\models\beta$. By IH we
have $\mathcal{M}^{f},[m],[n]\models\alpha$ or
$\mathcal{M}^{f},[m],[n]\models\beta$. Hence
$\mathcal{M}^{f},[m],[n]\models\alpha\cup\beta$.
\end{proof}\par As it happens for many modal logics the previous result gives us a
bounded model property for satisfiability: if a formula $\varphi$ is
satisfiable it is satisfiable in a model of size at most exponential
in the size of $\varphi$. Moreover, filtrations preserve some
structural properties of the accessibility relations. In particular
the following is true:
\par\begin{proposition}Let $\mathcal{M}=\langle M,\{\sim_{e}\}_{e\in\mathsf{Eq}},\{\rightarrow_{a}\}_{a\in\mathsf{Mod}},\mathit{V},\mathit{nom}\rangle$ be a
model, and let $\mathcal{M}^{f}$ be the smallest filtration of $\mathcal{M}$.
Then, $\mathsf{a^{\shortminus}}=(\mathsf{a})^{-1}$ implies $(\mathsf{a^{\shortminus}})^{f}=(\mathsf{a}^{f})^{-1}$
\end{proposition}\par\begin{proof}Suppose that $\mathsf{a^{\shortminus}}=(\mathsf{a})^{-1}$.
We want to prove that $(\mathsf{a^{\shortminus}})^{f}=(\mathsf{a}^{f})^{-1}$. Then suppose
$[m]R_{\mathsf{a^{\shortminus}}}^{f}[n]$. Since $f$ is the smallest filtration,
there exist $m^{\prime}\in[m],n^{\prime}\in[n]$ such that $m^{\prime}R_{\mathsf{a^{\shortminus}}}n^{\prime}$.
But by hypothesis, we have $n^{\prime}R_{\mathsf{a}}m^{\prime}$, and by definition
of filtration we get $[n^{\prime}]R_{\mathsf{a}}^{f}[m^{\prime}]$. Since $[m^{\prime}]=[m]$
and $[n^{\prime}]=[n]$, we obtain $[n]R_{\mathsf{a}}^{f}[m]$.
\end{proof}\par As a result we obtain an upper bound for the complexity of
satisfiability.
\par\begin{corollary}The satisfiability problem of $\text{HXPath}_{=}(\shortminus)$ is in {NExpTime}. \end{corollary}\par On the other hand, if we consider sibling navigation the argument does
not work. In the figure below we represent a relation $R_{\mathsf{a}}$ by black
arrows, and the sibling relation $R_{\mathsf{s}}$ by dotted arrows. Let
$\Sigma=\{\langle\mathsf{a}\rangle\top\}$. The model on the right is the
filtration by $\Sigma$ of the model on the left. As we can see, any
filtration collapses $v$ and $u$ into a unique equivalence class with
a reflexive arrow, but the sibling relation must be
irreflexive. Hence the notion of filtration we introduced
is not appropriate to handle siblings.

We introduced a sound and strongly complete axiomatization for
$\text{HXPath}_{=}$, i.e., the language XPath with forward navigation for multiple
accessibility relations; multiple equality/ inequality data
comparisons; and where node expressions are extended with nominals,
and path expressions are extended with the hybrid operator $@$. The
{hybridization} of XPath allowed us to apply a completeness
argument similar to the one used for the hybrid logic $\mathcal{HL}(@)$ shown in,
e.g.,~\cite[cite]{[\@@bibref{}{BtC06}{}{}]}. This ensures that certain extensions of the
axiomatic system we introduce are also strongly complete. The
axiomatic systems that can be obtained in this way cover a large
family of hybrid XPath languages over different classes of frames.
\par Our system extends the calculus introduced previously
in~\cite[cite]{[\@@bibref{}{ArecesF16}{}{}]}. The most important improvement is that we
provide a minimal system which can be extended with axioms and rules
of certain kind, such that strong completeness immediately follows.
The kind of axioms and rules we allow in the extensions ensures
completeness with respect to a large family of frame classes. We
showed interesting examples of such extensions. In particular, we
obtain a strongly complete axiomatization for the logic extended with
backward and sibling navigation, and for data equality inclusion.
\par One particularly interesting class of structures used in practice is the class
of \emph{tree models}, since the main applications of \text{XPath} in, e.g.,
web semantics are related to XML documents. From a mathematical point
of view, XML documents are trees. In this respect, we investigate
axiomatizations for $\text{HXPath}_{=}$ on tree models.
First, we showed that there is no
finitary first-order axiomatization which is strongly complete for
$\text{HXPath}_{=}$ on trees. Then we discussed two alternatives for dealing with
tree-like structures. On the one hand, it is possible to relax some
condition on the models. We consider the class $\mathfrak{C}_{forest^{-}}$, which are
forest-like models but possibly with infinite chains with respect to
the predecessor relation. More precisely, we extend the basic axiom
system with an infinite set of pure axioms to strongly axiomatize the
class $\mathfrak{C}_{forest^{-}}$. Another alternative is giving up \emph{strong}
completeness. We showed weak completeness for the class $\mathfrak{C}_{tree}$, using
pure axioms.
\par We also investigated the status of decidability for the satisfiability
problem of $\text{HXPath}_{=}$ and some extensions. We used a standard technique
in modal logics named \emph{filtrations}~\cite[cite]{[\@@bibref{}{blackburn06}{}{}]}. The
filtration method is a way to build finite models by taking a large
model and collapsing as many states as possible. We replicate this
technique for $\text{HXPath}_{=}(\shortminus)$, and obtain a {NExpTime} upper bound for its
satisfiability problem. We showed that filtrations do not work on
some extensions of $\text{HXPath}_{=}$. In particular, for the case of tree
models we proved that the satisfiability problem is decidable in {ExpSpace} using a more specialized approach.
\par As future work, it would be interesting to investigate $\text{XPath}_{=}$
fragments with the reflexive-transitive path $\mathsf{a}^{*}$. One of the
main limitations of the framework we introduced in this paper is that
it can only axiomatize first-order languages. For that reason,
transitive closure operators cannot be accounted for, and a different
proof strategy is needed. We conjecture that it is possible to adapt
the results from~\cite[cite]{[\@@bibref{}{HKT00}{}{}]} for Propositional Dynamic Logic (PDL) to
obtain a weakly complete axiom system for $\text{HXPath}_{=}(*)$ (i.e., $\text{HXPath}_{=}$
extended with $\mathsf{a}^{*}$) over the class of all models. However, for
axiomatizing $\text{HXPath}_{=}(*)$ over trees, the filtration technique used
in~\cite[cite]{[\@@bibref{}{HKT00}{}{}]} does not seem to work, and new developments are needed,
as for other logics with fix point operators over tree-like structures
(see, e.g., the case of ${\rm CTL}^{*}$ in~\cite[cite]{[\@@bibref{}{Rey01}{}{}]}).
\par The exact computational complexity of the logics we considered has not
been investigated yet. It has been proved that $\text{XPath}_{=}$ with single
accessibility and data relations extended with hybrid operators is
{PSpace}-complete~\cite[cite]{[\@@bibref{}{ArecesFS17}{}{}]}. Moreover, we provided upper bounds for
multi-modal $\text{HXPath}_{=}(\shortminus)$ over arbitrary models and for $\text{HXPath}_{=}$ on trees, but
without giving a tight lower bound. It would be also interesting to
investigate the complexity of the multi-modal languages we studied in
this article, enriched with backward and sibling navigation,
reflexive-transitive closures, and over the class of trees. We
conjecture that we can adapt the automata proof given
in~\cite[cite]{[\@@bibref{}{FigPhD}{}{}]}, with the method used to account for hybrid operators
presented in~\cite[cite]{[\@@bibref{}{SattlerVardi-IJCAR}{}{}]} to get exact bounds.
