Abstract
. This paper reveals some new structural property for the i i -quantum group 𝐔 ı ​ ( n ) {\mathbf{U}^{\imath}(n)} and constructs a certain hyperalgebra from the new structure which has connections to finite symplectic groups at the modular representation level. This work is built on certain finite dimensional ℚ ⁡ ( υ ) \mathbb{Q}({\upsilon}) -algebras 𝓢 ı ​ ( n , r ) {{\boldsymbol{{\mathcal{S}}}}^{\imath}(n,r)} whose integral form 𝒮 𝒵 ı ​ ( n , r ) {{\mathcal{S}}_{\mathcal{Z}}^{\imath}(n,r)} is investigated as a convolution algebra arising from the geometry of type C C in [ BKLW18 ] . We investigate 𝒮 𝒵 ı ​ ( n , r ) {{\mathcal{S}}_{\mathcal{Z}}^{\imath}(n,r)} as an endomorphism algebra of a certain q q -permutation module over the Hecke algebra of type C r C_{r} and interpret the convolution product as a composition of module homomorphisms. We then prove that the action of 𝐔 ı ​ ( n ) {\mathbf{U}^{\imath}(n)} on the r r -fold tensor space of the natural representation of 𝐔 ⁡ ( 𝔤 ​ 𝔩 2 ​ n ) {\mathbf{U}}(\mathfrak{gl}_{2n}) (via an embedding 𝐔 ı ​ ( n ) ↪ 𝐔 ⁡ ( 𝔤 ​ 𝔩 2 ​ n ) {\mathbf{U}^{\imath}(n)}\hookrightarrow{\mathbf{U}}(\mathfrak{gl}_{2n}) ) coincides with an action given by multiplications in 𝓢 ı ​ ( n , r ) {{\boldsymbol{{\mathcal{S}}}}^{\imath}(n,r)} . In this way, we re-establish the surjective homomorphism from 𝐔 ı ​ ( n ) {\mathbf{U}^{\imath}(n)} to 𝓢 ı ​ ( n , r ) {{\boldsymbol{{\mathcal{S}}}}^{\imath}(n,r)} due to Bao–Wang [ BW18 ] . We then embed 𝐔 ı ​ ( n ) {\mathbf{U}^{\imath}(n)} into the direct product of 𝓢 ı ​ ( n , r ) {{\boldsymbol{{\mathcal{S}}}}^{\imath}(n,r)} and completely determine its image. This gives a new realisation for 𝐔 ı ​ ( n ) {\mathbf{U}^{\imath}(n)} and, as an application, the aforementioned hyperalgebra is an easy consequence of this new construction.
