Abstract
. We provide new techniques to construct sets of reals without perfect subsets and with the Hurewicz or Menger covering properties. In particular, we show that if the Continuum Hypothesis holds, then there are such sets which can be mapped continuously onto the Cantor space. These results allow to separate the properties of Menger and 𝖲 1 ​ ( Γ , O ) {\mathsf{S}_{1}(\Gamma,\mathrm{O})} in the realm of sets of reals without perfect subsets and solve a problem of Nowik and Tsaban concerning perfectly meager subsets in the transitive sense. We present also some other applications of the mentioned above methods.

Introduction

Throughout this paper, we assume that a set
X
with a given topological property is a subset of the Cantor space
{2^{\omega}}
or its square.
A set
X
is
Menger
if for any sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open covers of
X
, there are finite sets
\mathcal{F}_{0}\subseteq\mathcal{U}_{0},\mathcal{F}_{1}\subseteq\mathcal{U}_{1},\dotsc
such that the family
\{\,\bigcup\mathcal{F}_{n}:n\in\omega\,\}
covers
X
.
If in addition the family
\{\,\bigcup\mathcal{F}_{n}:n\in\omega\,\}
is a
\gamma
-cover
of
X
, i.e., for every
x\in X
, the set
\{\,n:x\in\bigcup\mathcal{F}_{n}\,\}
is co-finite, then the set
X
is
Hurewicz
.
Each
\sigma
-compact set is Hurewicz and each Hurewicz set is Menger.
By the results of Bartoszyński–Shelah
[
5
]
and Tsaban–Zdomskyy
[
25
]
, there are uniform constructions of sets in ZFC which show that none of these implications are reversible in the realm of sets of reals.
The above properties are central in the combinatorial covering propeties theory and found applications in such areas as forcing
[

]
, function spaces
[
20
]
, Ramsey theory in algebra
[
24
]
, combinatorics of discrete subspaces
[

]
, hyperspaces with the Vietoris topology
[

]
, products of Lindelöf spaces
[

22
]
and products of paracompact spaces
[

]
.

Each of the considered properties has a combinatorial characterization using continuous mappings into the Baire space
{\omega^{\omega}}
.
A set

is Menger (Hurewicz) if and only if every continuous image of
X
into
{\omega^{\omega}}
is non-dominating (bounded)
[

]
.
It follows that each of these properties has a

, i.e., the minimal cardinality of a subset of
{\omega^{\omega}}
not having a given property.
The critical cardinality for Menger is the dominating number
\mathfrak{d}
and for Hurewicz it is the bounding number
\mathfrak{b}
.
A set is
totally imperfect
if it does not contain a perfect subset, i.e., a homeomorphic copy of
{2^{\omega}}
.
Known constructions of totally imperfect sets which are Menger or Hurewicz involve category-theoretic, measure-theoretic, combinatorial or forcing methods.
However, each of these constructions provide a set satisfying
{\mathsf{S}_{1}(\Gamma,\mathrm{O})}

[
7
,
19
,
11
]
.
A set
X

\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open
\gamma
-covers of
X
, there are sets
U_{0}\in\mathcal{U}_{0},U_{1}\in\mathcal{U}_{1},\dotsc
such that the family
\{\,U_{n}:n\in\omega\,\}
covers
X
.
The critical cardinality for
{\mathsf{S}_{1}(\Gamma,\mathrm{O})}
is
\mathfrak{d}
and the following implications hold
[
7
]
.

{\lx@inpgf@ignorespaces\sigma\text{-compact}}
Hurewicz
Menger
{\lx@inpgf@ignorespaces{\mathsf{S}_{1}(\Gamma,\mathrm{O})}}
totally imperfect

The only ZFC examples for separation Hurewicz or Menger from
{\mathsf{S}_{1}(\Gamma,\mathrm{O})}
are not satisfactory, i.e., they are the Cantor space and, more generally, sets containing perfect subsets.
Prior to this research, there hadn’t been totally imperfect examples, even under some additional assumptions beyond ZFC.

Using various set-theoretic assumptions which are weak portions of the Continuum Hypothesis, we construct totally imperfect Hurewicz or Menger sets which can be mapped continuously onto the Cantor cube.
Each of already known strategies to construct totally imperfect sets with these properties have substantial limitations which prevent from reaching such a goal.
These results have consequences for separation of considered properties.
Another benefit is a solution of the below problem which was formulated independently by Nowik and Tsaban (in oral communication).
By

we mean a standard group operation in
{2^{\omega}}
, i.e., for every

we have

(x\oplus y)(n):=(x(n)+y(n))(\bmod 2)

for all natural numbers

.
For a set

and an element

, let

.
A set
X\subseteq{2^{\omega}}
is
perfectly meager
if for any perfect set
P\subseteq{2^{\omega}}
, the set
X\cap P
is meager in the relative topology of
P
.
By the result of Just–Miller–Scheepers–Szeptycki
[
7
, Theorem 5.5]
any totally imperfect Hurewicz subset of
{2^{\omega}}
is perfectly meager.
A set

14

\sigma
-compact set

(Nowik
[

Each Hurewicz set in

Theorem 3.1
.

Assume that
\operatorname{cov}(\mathcal{M})=\mathfrak{c}
.
Then there is a Menger totally imperfect set
X\subseteq{2^{\omega}}\times{2^{\omega}}
with
\pi[X]={2^{\omega}}
.

Lemma 3.2
.

Let
M_{0},\allowbreak M_{1},\allowbreak\dotsc
be an increasing sequence of closed sets in
{2^{\omega}}\times{2^{\omega}}
such that the sets
M_{n}|_{x}
are nowhere dense in
{2^{\omega}}
for all natural numbers
n
and every
x\in{2^{\omega}}
.
Then there is a
\sigma
-compact set
D\subseteq{2^{\omega}}\times{2^{\omega}}
disjoint from
\bigcup_{n\in\omega}M_{n}
such that the sets
D|_{x}
are dense in
{2^{\omega}}
for all elements
x\in{2^{\omega}}
.

Proof.

Let
B_{0},\allowbreak B_{1},\allowbreak\dotsc
be an enumeration of all basic clopen sets in
{2^{\omega}}\times{2^{\omega}}
.
Fix a natural number
m
.
By Lemma
2.5
, there is a compact set
D_{m}\subseteq B_{m}
disjoint from the set
\bigcup_{n\in\omega}M_{n}
such that
\pi[D_{m}]=\pi[B_{m}]
.
Take
D:=\bigcup_{m\in\omega}D_{m}
.
∎

Let
\mathcal{G}
be the family of all
G_{\delta}
-sets
G\subseteq{2^{\omega}}\times{2^{\omega}}
such that the sets
G|_{x}
are dense in
{2^{\omega}}
for all elements
x\in{2^{\omega}}
.

Lemma 3.3
.

Let
X\subseteq{2^{\omega}}\times{2^{\omega}}
be a Menger set and
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
be a sequence of open covers of
X
, where each family
\mathcal{U}_{n}
is open in
{2^{\omega}}\times{2^{\omega}}
and the set
\bigcap_{n\in\omega}\bigcup\mathcal{U}_{n}
is in
\mathcal{G}
.
Then there are finite sets
\mathcal{F}_{0}\subseteq\mathcal{U}_{0},\mathcal{F}_{1}\subseteq\mathcal{U}_{1},\dotsc
such that the family
\bigcup_{n\in\omega}\mathcal{F}_{n}
covers
X
and the set
\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}
is in
\mathcal{G}
.

Proof.

Let
M_{n}:={2^{\omega}}\times{2^{\omega}}\setminus\bigcup\mathcal{U}_{n}
for all natural numbers
n
.
Let
D\subseteq{2^{\omega}}
be a
\sigma
-compact set from Lemma
3.2
applied to the sequence
M_{0},\allowbreak M_{1},\allowbreak\dotsc
.
Since the set
X\cup D
is Menger, there are finite sets
\mathcal{F}_{n}\subseteq\mathcal{U}_{n}
for all natural numbers
n
such that the family
\bigcup_{n\in\omega}\mathcal{F}_{n}
covers
X\cup D
.
∎

Proof of Theorem
3.1
.

Let
{\bigl\{\,(\mathcal{U}_{0}^{(\alpha)},\mathcal{U}_{1}^{(\alpha)},\dotsc):\alpha<\mathfrak{c}\,\bigr\}}
be an enumeration of all countable sequences
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open families in
{2^{\omega}}\times{2^{\omega}}
such that the sets
\bigcap_{n\in\omega}\bigcup\mathcal{U}_{n}
are in
\mathcal{G}
.
Let
{\bigl\{\,(\mathcal{V}_{0}^{(\alpha)},\mathcal{V}_{1}^{(\alpha)},\dotsc):\alpha<\mathfrak{c}\,\bigr\}}
be an enumeration of all other countable sequences of open families in
{2^{\omega}}\times{2^{\omega}}
, let
\{\,P_{\alpha}:\alpha<\mathfrak{c}\,\}
be an enumeration of all perfect sets in
{2^{\omega}}\times{2^{\omega}}
and
{2^{\omega}}=\{\,x_{\alpha}:\alpha<\mathfrak{c}\,\}
.

By recursion on
\alpha<\mathfrak{c}
, we construct finite sets
\mathcal{F}_{0}^{(\alpha)}\subseteq\mathcal{U}_{0}^{(\alpha)},\mathcal{F}_{1}^{(\alpha)}\subseteq\mathcal{U}_{1}^{(\alpha)},\dotsc
, elements
u_{\alpha},w_{\alpha}\in{2^{\omega}}\times{2^{\omega}}
and
p_{\alpha}\in P_{\alpha}
with the following properties:

(
i)

the set
F_{\alpha}:=\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}^{(\alpha)}
is in
\mathcal{G}
,

(
ii)

\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}\cap G_{\alpha}\subseteq F_{\alpha}
, where
G_{\alpha}:=\bigcap_{n\in\omega}\bigcup\mathcal{U}^{(\alpha)}_{n}
,

(
iii)

u_{\alpha},w_{\alpha}\in\bigcap_{\beta\leq\alpha}F_{\beta}
,

(
iv)

u_{\alpha},w_{\alpha}\notin\{\,p_{\beta}:\beta\leq\alpha\,\}
,

(
v)

w_{\alpha}\notin H_{\alpha}
, where
H_{\alpha}:=\bigcap_{n\in\omega}\bigcup\mathcal{V}_{n}^{(\alpha)}
,

(
vi)

\pi(w_{\alpha})=x_{\alpha}
.

Pick
p_{0}\in P_{0}
.
By Lemma
3.3
there are finite sets
\mathcal{F}_{0}^{(0)}\subseteq\mathcal{U}_{0}^{(0)},\mathcal{F}_{1}^{(0)}\subseteq\mathcal{U}_{1}^{(0)},\dotsc
such that the set
F_{0}:=\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}^{(0)}
is in
\mathcal{G}
.
The sets
F_{0}|_{x}
are dense in
{2^{\omega}}
for all elements
x\in{2^{\omega}}
.
Since the set
H_{0}:=\bigcap_{n\in\omega}\bigcup\mathcal{V}_{n}^{(0)}
is not in
\mathcal{G}
, there is an element
x\in{2^{\omega}}
such that the set
H_{0}|_{x}
is not dense in
{2^{\omega}}
, and thus

\bigl(F_{0}|_{x}\bigr)\setminus\bigl(H_{0}|_{x}\bigr)\neq\emptyset.

Pick elements

u_{0}\in\bigl(F_{0}\cap(\{x_{0}\}\times{2^{\omega}})\bigr)\setminus\{p_{0}\}\text{\quad and\quad}w_{0}\in F_{0}\setminus\bigl(H_{0}\cup\{p_{0}\}\bigr).

Fix an ordinal number
\alpha<\mathfrak{c}
and assume that the objects mentioned above have been constructed for all
\beta<\alpha
.
Pick
p_{\alpha}\in P_{\alpha}\setminus\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}
.
Since
\alpha<\operatorname{cov}(\mathcal{M})\leq\mathfrak{d}
, the set
\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}\cap G_{\alpha}
has cardinality smaller than
\mathfrak{d}
, which is the critical cardinal number for the Menger property, and thus this set is Menger.
By Lemma
3.3
there are finite sets
\mathcal{F}_{0}^{(\alpha)}\subseteq\mathcal{U}_{0}^{(\alpha)},\mathcal{F}_{1}^{(\alpha)}\subseteq\mathcal{U}_{1}^{(\alpha)},\dotsc
such that the set
F_{\alpha}:=\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}^{(\alpha)}
is in
\mathcal{G}
and

\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}\cap G_{\alpha}\subseteq F_{\alpha}.

The intersection of less than
\operatorname{cov}(\mathcal{M})

dense
G_{\delta}
-sets in
{2^{\omega}}
and a subset of
{2^{\omega}}
with nonempty interior is nonempty.
For each
\beta\leq\alpha

the sets
F_{\beta}|_{x}
are dense
G_{\delta}
-sets in
{2^{\omega}}
for all elements
x\in{2^{\omega}}
.
Since the set
H_{\alpha}:=\bigcap_{n\in\omega}\bigcup\mathcal{V}^{(\alpha)}_{n}
is not in
\mathcal{G}
, there is
x\in{2^{\omega}}
such that the set
H_{\alpha}|_{x}
is not dense in
{2^{\omega}}
, i.e., the set
{2^{\omega}}\setminus H_{\alpha}|_{x}
has nonempty interior.
Since
\alpha<\operatorname{cov}(\mathcal{M})
, we can pick elements

u_{\alpha}\in\bigl(\bigcap_{\beta\leq\alpha}F_{\beta}\cap(\{x_{\alpha}\}\times{2^{\omega}})\bigr)\setminus\{\,p_{\beta}:\beta\leq\alpha\,\}

and

w_{\alpha}\in\bigcap_{\beta\leq\alpha}F_{\beta}\setminus\bigl(H_{0}\cup\{\,p_{\beta}:\beta\leq\alpha\,\}\bigr)

This completes our recursive construction.
Let
X:=\{\,u_{\alpha},w_{\alpha}:\alpha<\mathfrak{c}\,\}
.

Let
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
be a sequence of open covers of
X
.
For each ordinal number
\alpha<\mathfrak{c}
we have
w_{\alpha}\notin H_{\alpha}=\bigcap_{n\in\omega}\bigcup\mathcal{V}_{n}^{(\alpha)}
, and thus none of the sequences
\mathcal{V}_{0}^{(\alpha)},\mathcal{V}_{1}^{(\alpha)},\dotsc
is a sequence of covers of
X
.
Consequently, there is an ordinal number
\alpha<\mathfrak{c}
such that the sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
is equal to
\mathcal{U}_{0}^{(\alpha)},\mathcal{U}_{1}^{(\alpha)},\dotsc
.
By
(ii)
we have

\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}=\{\,u_{\beta},w_{\beta}:\beta<\alpha\,\}\cap G_{\alpha}\subseteq F_{\alpha}=\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}^{(\alpha)}

and by
(iii)
we have

\{\,u_{\beta},w_{\beta}:\alpha\leq\beta<\mathfrak{c}\,\}\subseteq F_{\alpha}=\bigcup_{n\in\omega}\bigcup\mathcal{F}_{n}^{(\alpha)}.

Then the family
\bigcup_{n\in\omega}\mathcal{F}_{n}^{(\alpha)}
covers
X
, and thus the set
X
is Menger.

By
(iv)
the set
X
is totally imperfect and by
(v)
we have
\pi[X]={2^{\omega}}
.
∎

Corollary 3.4
.

Assume that
\operatorname{cov}(\mathcal{M})=\mathfrak{c}
.
There is a Menger totally imperfect set which is not
{\mathsf{S}_{1}(\Gamma,\mathrm{O})}
.

4.
More consequences

4.1.
On the problem of Nowik and Tsaban

The set from Theorem
2.1
provides a negative answer to the question from Problem
1.2
under
\operatorname{cov}(\mathcal{N})=\mathfrak{b}=\mathfrak{c}
.
On the other hand it is consistent with ZFC that all Hurewicz totally imperfect sets have cardinalities strictly smaller than
\mathfrak{c}
.
By the results of Miller
[
10
]
and Zakrzewski
[
27
]
, this holds in the Cohen model, and by the result of Miller
[
10
]
also in the Sacks model.
In these cases an affirmative answer to Problem
1.2
follows from Theorem
1.1
.

4.2.
Everywhere meager and everywhere null

A subset
A
of a Polish space
X
is
universally meager

[
27
,
28
,
3
,
4
]
if for any Borel isomorphism between
X
and a Polish space
Y
, the image of
A
under the map is meager.
A set
X\subseteq{2^{\omega}}
is
everywhere meager

[
8
]
if for each set
a\in{[\omega]^{\omega}}
the set
X_{a}:=\{\,x\upharpoonright a:x\in X\,\}
is meager in
2^{a}
.
Kraszewski proved that there is a universally meager set in
{2^{\omega}}
which is not everywhere meager
[
8
, Theorem 4.1]
.
We give a consistently negative answer to a weaker version of the following question.

Problem 4.1

(Kraszewski
[
8
, Problem 1]
)
.

Is every PMT subset of
{2^{\omega}}
everywhere meager?

A set
X\subseteq{2^{\omega}}
is
countably perfectly meager
if for any sequence
P_{0},\allowbreak P_{1},\allowbreak\dotsc
of perfect subsets of
{2^{\omega}}
, there is an
F_{\sigma}
-set
F\subseteq{2^{\omega}}
containing
X
and the sets
P_{n}\cap F
are meager in
P_{n}
for all natural numbers
n
.
Equivalently, the set
X
is countably perfectly meager if for each perfect set
P
and a countable set
Q
there is an
F_{\sigma}
-set
F
containing
X
such that for every
q\in Q
, the set
F\cap(q+P)
is meager in
q+P
.
Every Hurewicz totally imperfect subset of
{2^{\omega}}
is countably perfectly meager
[
15
]
.
By the results of Pol–Zakrzewski
[
15
]
and Weiss–Zakrzewski
[
26
]
there is consistently a universally meager set which is not countably perfectly meager.

Lemma 4.2
.

If
X\subseteq{2^{\omega}}
is a set whose continuous image into
{2^{\omega}}
is not meager, then a homeomorphic copy of
X
in
{2^{\omega}}
is not everywhere meager.

Proof.

Let
f\colon X\to{2^{\omega}}
be a continuous map, whose image
f[X]
is not meager in
{2^{\omega}}
.
Then the set

Y:=\{\,(x,f(x)):x\in X\,\},

the graph of the function
f
, is a homeomorphic copy of
X
in
{2^{\omega}}\times{2^{\omega}}
.
Fix disjoint sets
a,b\in{[\omega]^{\omega}}
with
a\cup b=\omega
.
Let
\psi_{a}\colon{2^{\omega}}\to 2^{a}
and
\psi_{b}\colon{2^{\omega}}\to 2^{b}
be homeomorphisms.
Then the map
\psi:=\psi_{a}\times\psi_{b}
is a homeomorphism from
{2^{\omega}}\times{2^{\omega}}
to
2^{a}\times 2^{b}
.
Let
\phi\colon 2^{a}\times 2^{b}\to{2^{\omega}}
be a homeomorphism such that
\phi(x,y):=x\cup y
for all
(x,y)\in 2^{a}\times 2^{b}
.
Then the set

Z:=(\phi\circ\psi)[Y]

is a homeomorphic copy of
X
such that the set
Z_{b}=\psi_{b}[f[X]]
is not meager in
2^{b}
.
∎

The following result answers Problem
4.1
in which PMT sets are replaced by countably perfectly meager sets in the negative.

Corollary 4.3
.

Assume that
\operatorname{cof}(\mathcal{N})=\mathfrak{b}=\mathfrak{c}
.
Then there is a totally imperfect Hurewicz (and thus countably perfectly meager) subset of
{2^{\omega}}
which is not everywhere meager.

Proof.

Let
X
be a set from Theorem
2.1
.
By Lemma
4.2
, there is a homeomorphic copy
Y
of
X
in
{2^{\omega}}
which is not everywhere meager.
Since
Y
is totally imperfect and Hurewicz, by the result of Pol–Zakrzewski
[
15
]
, it is countably perfectly meager.
∎

According to a characterization of universally meager sets due to Zakrzewski
[
27
, Theorem 2.1]
, a subset of a Polish space is universally meager if and only if every Borel isomorphic image of this set into a Polish space is meager.
It follows that universally meager sets are preserved by homeomorphisms.
By the result of Pol and Zakrzewski
[
15
, Theorem 3.1.3]
consistently countably perfectly meager sets are not preserved by homeomorphisms.
We do not know whether of everywhere meager sets are preserved by homeomorphisms.

4.3.
The property
\mathsf{U}_{n}(\Gamma,\Gamma)

A set
X
satisfies
\mathsf{U}_{n}(\Gamma,\Gamma)
if for any sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open
\gamma
-covers of
X
, there are sets
\mathcal{F}_{0}\subseteq\mathcal{U}_{0},\mathcal{F}_{1}\subseteq\mathcal{U}_{1},\dotsc
such that
\left|\mathcal{F}_{n}\right|=n
for all
n
’s and the family
\{\,\bigcup\mathcal{F}_{n}:n\in\omega\,\}
is a
\gamma
-cover of
X
.
This property was investigated by Tsaban
[
23
]
in the context of sets with the Hurewicz property and the property
{\mathsf{S}_{1}(\Gamma,\Gamma)}
.
A set
X
satisfies
{\mathsf{S}_{1}(\Gamma,\Gamma)}
if for any sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open
\gamma
-covers of
X
, there are sets
U_{0}\in\mathcal{U}_{0},U_{1}\in\mathcal{U}_{1},\dotsc
such that the family
\{\,U_{n}:n\in\mathbb{N}\,\}
is a
\gamma
-cover of
X
.
Each set satisfying
{\mathsf{S}_{1}(\Gamma,\mathrm{O})}
is totally imperfect
[
23
, Lemma 1.16]
.
Using a similar argument, we can show that any set satisfying
\mathsf{U}_{n}(\Gamma,\Gamma)
is totally imperfect, too.
A
\mathfrak{b}
-scale set
is a subset of the Cantor space
{\operatorname{P}(\omega)}
of the form
\{\,x_{\alpha}:\alpha<\mathfrak{b}\,\}\cup\mathrm{Fin}
, where
\{\,x_{\alpha}:\alpha<\mathfrak{b}\,\}
is an unbounded subset of
{[\omega]^{\omega}}
such that for every
\alpha<\beta<\mathfrak{b}
, we have
x_{\alpha}\leq^{*}x_{\beta}
.
Such a set exists in ZFC and is an example of a Hurewicz totally imperfect set given by Bartoszyński–Shelah
[
5
]
.
The only known example which distinguishes the properties
{\mathsf{S}_{1}(\Gamma,\Gamma)}
and Hurewicz in the class of totally imperfect sets is a
\mathfrak{b}
-scale set
[
16
]
under
\mathfrak{b}=\mathfrak{c}
.
By the results of Tsaban
[
23
, Theorems 3.3 and 3.8]
any
\mathfrak{b}
-scale set satisfies
\mathsf{U}_{n}(\Gamma,\Gamma)
, and thus any continuous image of a
\mathfrak{b}
-scale set into
{2^{\omega}}
is totally imperfect.
Tsaban asked the following question.

Problem 4.4

(
[
23
, Problem 3.9]
)
.

Is there a totally imperfect Hurewicz set which is not
\mathsf{U}_{n}(\Gamma,\Gamma)
?

Our example constructed in Theorem
2.1
provides a negative answer to the above question under
\operatorname{cov}(\mathcal{N})=\mathfrak{b}=\mathfrak{c}
.
