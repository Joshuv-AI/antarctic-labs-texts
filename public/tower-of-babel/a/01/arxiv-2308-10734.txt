A Study of the Probability Distribution of the Balls in Bins Process with Power Law Feedback
Samuel Forbes

Abstract
We analyse the balls in bins process with feedback with primary focus on the power law feedback function f ⁡ ( ω ) = η ​ ω γ f(\omega)=\eta\omega^{\gamma}\, , η > 0 \eta>0\, γ ≥ 0 \gamma\geq 0\, . Using the recursive solution to the master equation we find for power law feedback numerical evidence that the probability mass function for finite time scales asymptotically with ω − γ \omega^{-\gamma}\, for γ > 1 \gamma>1\, . We also provide simulations supporting a previous result by Oliveira (corollary to Theorem 4 in [ 13 ] ) that the tail of the losers scale as ω − ( γ − 1 ) \omega^{-(\gamma-1)}\, but extending to N ≥ 2 N\geq 2 bins. We thus find evidence that the balls in bins process with power law feedback produces power law distributions as is common to many real world phenomena.

Overview of Some Existing Results

As mentioned in the introduction, interesting properties of the feedback model are already known. In particular, conditions on the feedback function
f(\omega)
leads to monopoly where one agent gains all but a finite number of balls and fixed rankings where the order of agents from richest to poorest (most balls to least) becomes fixed after a certain period of time. As these cases may have broad applications to models of real world phenomena as discussed in the introduction we reproduce them in this section.

Conclusion

The form of the recursive mass function solution (
5
) to the master equation for the feedback process is not particularly tractable. However the first term (
8
) is analytical and for finite time and for the power law feedback function (
2
) with
\gamma>1
is a regularly varying sequence asymptotically dominated by
\omega^{-\gamma}\propto 1/f(\omega)\,.

We showed numerically in Section
3
that this first term provides a good approximation under certain parametrisations.
We also provided simulations in Section
4
suggesting the tail of the losers scale as
\omega^{-(\gamma-1)}
for general
N\geq 2
agents. This gives partial evidence that the corollary to Theorem 4 in Oliveira
[
13
]
, stated in Section
2
, holds for power law feedback and
N\geq 2
agents. As power law distributions appear in many real world phenomena with possible feedback mechanisms we believe these are interesting results.

Definition 4
.

A positive, measureable function
f
defined on
[k,\infty)
for some
k\geq 0
is
regularly varying
if for all
\lambda>0

\lim_{x\rightarrow\infty}\frac{f(\lambda x)}{f(x)}=\lambda^{\rho}

for some index
\rho\in\mathbb{R}\,.

For a function
l
satisfying the conditions in Definition
4
with the particular case of
\rho=0
so that

\lim_{x\rightarrow\infty}\frac{l(\lambda x)}{l(x)}=1

then
l
is called
slowly varying
. In particular
l(x):=f(x)/x^{\rho}
where
f
is some regularly varying function with index
\rho
is a slowly varying function. Thus any regularly function
f
can be written as

f(x)=l(x)x^{\rho}

where
l
is a slowly varying function. By the representation theorem we have for all
\gamma>0
that

l(x)x^{-\gamma}\rightarrow 0
as
x\rightarrow\infty
thus if the index is
\rho=-\gamma<0
then the regularly varying function
f(x)=l(x)x^{-\gamma}
is dominated asymptotically by
x^{-\gamma}\,.

\{\theta(\omega)\,:\,\omega=\omega_{0},\omega_{0}+1,\dots\}:=\{\theta(\omega)\}
of positive terms.

Definition 5

(See

]
)
.

We call the sequence

\theta(\omega)\simeq k\alpha(\omega)\quad\text{some }k>0

\lim_{\omega\rightarrow\infty}\omega(1-\alpha(\omega-1)/\alpha(\omega))=\rho\quad\text{some index }\rho\in\mathbb{R}

If

then it can be embedded into a regularly varying function with index

]

Let us show that the sequence
\{\hat{p}(\omega)\}
defined by (
8
) is a regularly varying sequence. With

\alpha(\omega)=\left(\prod_{j=\omega_{0}+1}^{\omega}\frac{1}{1-(\omega_{0}/j)^{\gamma}}\right)\frac{1}{\omega^{\gamma}}

then
\{\alpha(\omega)\}
is a positive sequence and we see

\hat{p}(\omega)\simeq e^{-\eta\omega_{0}^{\gamma}t}\omega_{0}^{\gamma}\alpha(\omega)

satisfies the first condition of a regularly varying sequence. Now for
\gamma>1
we have

\displaystyle\omega(1-\alpha(\omega-1)/\alpha(\omega))

\displaystyle=\omega\left(1-\frac{1/(\omega-1)^{\gamma}}{1/(1-(\omega_{0}/\omega)^{\gamma})\cdot 1/\omega^{\gamma}}\right)

\displaystyle=\omega\left(1-\frac{\omega^{\gamma}-\omega_{0}^{\gamma}}{(\omega-1)^{\gamma}}\right)

\displaystyle=\omega\left(1-\frac{1}{(1-1/\omega)^{\gamma}}-\frac{\omega_{0}}{(\omega-1)^{\gamma}}\right)

\displaystyle=\omega\left(1-(1+\gamma/\omega+\mathcal{O}(1/\omega^{\gamma}))-\frac{\omega_{0}}{(\omega-1)^{\gamma}}\right)

\displaystyle=-\gamma+\mathcal{O}(1/\omega^{\gamma-1})

\displaystyle\rightarrow-\gamma\quad\text{ as }\omega\rightarrow\infty\,.
