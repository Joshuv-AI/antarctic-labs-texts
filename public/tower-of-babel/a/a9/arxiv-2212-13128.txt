Closed-Form Solutions of Zero Dimensional ϕ 4 \phi^{4} -Field Theory Using Bessel Functions: A Non-Perturbative Approach
Ranjiva Munasinghe

Abstract
The integral ∫ − ∞ ∞ e − x 2 − g ​ x 4 ​ 𝑑 x \int_{-\infty}^{\infty}e^{-x^{2}-gx^{4}}dx is used as an introductory learning tool in the study of Quantum Field Theory and path integrals. Typically it is analysed via perturbation theory. Close form solutions have been quoted but it is not clear how they were derived. So I set about deriving the close form solution on my own and using the same methodology obtain closed form expressions for the even positive integer moments.



1
Introduction

Path integrals, Feynman diagrams and perturbation theory are well-established tools in the study of Quantum Field Theory (QFT). A typical introduction to these techniques is via "toy model"

Z(g)=\frac{1}{\sqrt{\pi}}\int_{-\infty}^{\infty}e^{-x^{2}-gx^{4}}dx\;\;\;g\geq 0.

(1)

The function
Z(g)
is referred to as the partition function of i)
the zero dimensional anharmonic oscillator

[

\phi^{4}
-field theory

[

weak coupling

Z(g)\sim\sum_{n=0}^{N}(-1)^{n}\frac{\Gamma(2n+1/2)}{n!\sqrt{\pi}}g^{n}.

In the

[

Z(g)\sim g^{-1/4}\sum_{n=0}^{N}(-1)^{n}\frac{\Gamma(n/2+1/4)}{2n!\sqrt{\pi}}g^{-n/2}.

(3)

The references

Z(g)=\frac{1}{\sqrt{4\pi g}}\exp\left[\frac{1}{8g}\right]K_{1/4}\left(\frac{1}{8g}\right).

We first prove the formula in

[

I(\gamma,\beta)=\int_{0}^{\infty}\exp\left[-2\gamma^{2}x^{2}-\beta^{2}x^{4}\right]dx

We are interested in the setting
\beta,\gamma\in\mathbb{R}

[
3

x=\frac{\sqrt{2}\gamma}{\beta}\sinh\left(\frac{\xi}{4}\right).

Using (

\displaystyle=

\displaystyle 2^{-3/2}\frac{\gamma}{\beta}\exp\left[\frac{\gamma^{4}}{2\beta^{2}}\right]K_{1/4}\left(\frac{\gamma^{4}}{2\beta^{2}}\right)

3
Closed Form Expression for The Moments

Let us return to partition function (
1
). We note that the integrand is an even function and should thus only have even (positive integer) moments given by the formula:

\biggl<x^{2n}\biggr>=\frac{1}{Z(g)}\cdot\frac{2}{\sqrt{\pi}}\int_{0}^{\infty}x^{2n}\exp\left[-x^{2}-gx^{4}\right]dx

(12)

To obtain our closed form expression we proceed as before, now using the variable transformation

\displaystyle x

\displaystyle=

\displaystyle\frac{1}{\sqrt{g}}\sinh\left(\frac{\xi}{4}\right)

(13)

\displaystyle dx

\displaystyle=

\displaystyle\frac{1}{4\sqrt{g}}\cosh\left(\frac{\xi}{4}\right)d\xi.

(14)

Using (
5
), (
13
) and (
14
) we re-write ((
12
), using the shorthand sh (ch) for sinh (cosh):

\biggl<x^{2n}\biggr>=\mathcal{N}\int_{0}^{\infty}\mathrm{sh}^{2n}(\xi/4)\cdot\mathrm{ch}(\xi/4)\exp\left[-\frac{1}{8g}\mathrm{ch}(\xi)\right]d\xi

(15)

Note the normalization factor
\mathcal{N}=\mathcal{N}(n,g)
:

\mathcal{N}(n,g)=\frac{1}{Z(g)}\cdot\frac{e^{1/8g}}{\sqrt{4\pi g^{2n+1}}}=\left[g^{n}\cdot K_{1/4}\left(\frac{1}{8g}\right)\right]^{-1}

We now make use of

\sinh^{2n}(x)=\left[\cosh^{2}(x)-1\right]^{n}=\sum_{k=0}^{n}\binom{n}{k}(-1)^{n-k}\mathrm{ch}^{2k}(x),

to transform (
15
) to

\biggl<x^{2n}\biggr>=\mathcal{N}\sum_{k=0}^{n}\binom{n}{k}(-1)^{n-k}\int_{0}^{\infty}\mathrm{ch}^{2k+1}(\xi/4)\exp\left[-\frac{1}{8g}\mathrm{ch}(\xi)\right]d\xi

(16)

We first use the trigonometric identity for odd powers of cosine
[
8
]
and then apply Osborn’s rule
[
9
]
to convert the identity to the hyperbolic analogue:

\cosh^{2k+1}(x)=\frac{1}{4^{k}}\sum_{m=0}^{k}\binom{2k+1}{m}\mathrm{ch}((2k+1-2m)\cdot x)

Then we finish up (
16
)

\displaystyle\biggl<x^{2n}\biggr>

\displaystyle=

\displaystyle\mathcal{N}\sum_{k=0}^{n}\binom{n}{k}\frac{(-1)^{n-k}}{4^{k}}\sum_{m=0}^{k}\binom{2k+1}{m}\times

(17)

\displaystyle\int_{0}^{\infty}\mathrm{ch}\left(\frac{(2(k-m)+1)\xi}{4}\right)\exp\left[-\frac{1}{8g}\mathrm{ch}(\xi)\right]d\xi

\displaystyle=

\displaystyle\mathcal{N}\sum_{k=0}^{n}\binom{n}{k}\frac{(-1)^{n-k}}{4^{k}}\sum_{m=0}^{k}\binom{2k+1}{m}K_{\frac{2(k-m)+1}{4}}\left(\frac{1}{8g}\right)

In general we see that (
17
) is of the form

\biggl<x^{2n}\biggr>=\left[(4g)^{n}\cdot K_{1/4}\left(\frac{1}{8g}\right)\right]^{-1}\sum_{m=0}^{n}c_{m}^{(n)}\cdot K_{\frac{2m+1}{4}},

(18)

where with a little work we see that the coefficients
c_{m}^{(n)}
can be expressed as:

c_{m}^{(n)}=\sum_{k=m}^{n}(-1)^{n-k}4^{n-k}\binom{n}{k}\binom{2k+1}{k-m}

(19)

The coefficients can be simplified when starting from the top in descending order - for example the first few entries are

\displaystyle c_{n}^{(n)}

\displaystyle=

\displaystyle 1

(20)

\displaystyle c_{n-1}^{(n)}

\displaystyle=

\displaystyle 1-2n

(21)

\displaystyle c_{n-2}^{(n)}

\displaystyle=

\displaystyle n(2n-3)

(22)

\displaystyle c_{n-3}^{(n)}

\displaystyle=

\displaystyle\frac{n(1-2n)(2n-5)}{3}

(23)

The even moments (
2n
) for
n=1,2,3
are then given by:

\displaystyle\biggl<x^{2}\biggr>

\displaystyle=

\displaystyle\frac{1}{4g}\left[\frac{K_{3/4}\left(\frac{1}{8g}\right)}{K_{1/4}\left(\frac{1}{8g}\right)}-1\right]

(24)

\displaystyle\biggl<x^{4}\biggr>

\displaystyle=

\displaystyle\frac{1}{16g^{2}}\left[\frac{K_{5/4}\left(\frac{1}{8g}\right)-3K_{3/4}\left(\frac{1}{8g}\right)}{K_{1/4}\left(\frac{1}{8g}\right)}+2\right]

(25)

\displaystyle\biggl<x^{6}\biggr>

\displaystyle=

\displaystyle\frac{1}{64g^{3}}\left[\frac{K_{7/4}\left(\frac{1}{8g}\right)-5K_{5/4}\left(\frac{1}{8g}\right)+9K_{3/4}\left(\frac{1}{8g}\right)}{K_{1/4}\left(\frac{1}{8g}\right)}-5\right]

Discussion

Along the way the trick I used to derived the expression also enables one to write a closed form expression for the moments.
