Abstract
Let U U be a universe on n n elements, let k k be a positive integer, and let ℱ \mathcal{F} be a family of (implicitly defined) subsets of U U . Classically, these problems can be solved via inclusion–exclusion in 2 n ​ n O ⁡ ( 1 ) 2^{n}n^{O(1)} time [ BHK09 ] . It is obtained by combining three algorithms that have the best running time for some values of c c . When c ≤ 1.147899 c\leq 1.147899 , our algorithm is slightly faster than ( 2 + c ) n / 2 ​ n O ⁡ ( 1 ) (2+c)^{n/2}n^{O(1)} ; when c c approaches 1 1 , it matches the O ⁡ ( 1.7274 n ​ | ℱ | O ⁡ ( 1 ) ) O\left(1.7274^{n}|\mathcal{F}|^{O(1)}\right) running time of [ ABI+19 ] for Set Cover when | ℱ | |\mathcal{F}| is subexponential in n n . Preliminaries

For a proposition

is a function that returns

Asymptotic notation.

The

-notation is similar to the usual

-notation but allows to hide polynomial factors in the input size. The

-notation hides polylogarithmic factors.
We make heavy use of Stirling’s approximation for factorials, which implies that
\binom{n}{k}=O^{*}\left(\left(\frac{n}{k}\right)^{k}\cdot\left(\frac{n}{n-k}\right)^{n-k}\right)
, and of the binomial theorem,
\sum_{k=0}^{n}\binom{n}{k}x^{k}y^{n-k}=(x+y)^{n}
.

Set Systems.

An

]

.
The implicit set system

is said to be

, and (b) there exists a polynomial time algorithm that given

and a subset

.
Throughout this paper, we consider only polynomial time computable implicit set systems.
We define a

implicit set system
\Phi

,
U_{I}
and a subset

of

, determines whether

, where the downward closure

contains all sets in

and their subsets.

For any subset of elements

For a subset polynomial time computable implicit set system

Quantum Algorithms.

It is known that most classical branching algorithms have a quadratic speedup on quantum machines. As
[
SM22
]
, we also rely on the following results.

Theorem 1

(
[
Gro96
,
BBHT98
]
)
.

Let
A:\{1,2,\dots,N\}\rightarrow\{0,1\}
be a bounded-error quantum algorithm with running time

. Then, there is a bounded-error quantum algorithm computing
\bigvee_{x\in\{1,\dots,N\}}A(x)
with running time
\tilde{O}(\sqrt{N}T)
.

Theorem 2

(
[
DH96
]
)
.

Let
A:\{1,2,\dots,N\}\rightarrow\{0,1\}
be a bounded-error quantum algorithm with running time

\min_{x\in\{1,\dots,N\}}A(x)
with running time

.

In our context,

is an algorithm exploring paths in superposition from the root to the leaves of the search tree of a classical branching algorithm.
The amplitudes of this exploration depend on estimates of the sizes of the subtrees, either by relying on an analysis of the classical branching algorithm
[

[

For a simple branching algorithm with running time

in this way; we simply say that we apply Grover’s search to the branching algorithm.

Let
\Phi(I)=(U,\mathcal{F})
be a polynomial time computable implicit set family for which we would like to determine whether there is a

-cover (assuming

),

We say that a simple branching algorithm

Our algorithm uses a divide-and-conquer strategy where the universe is twice partitioned into two.

Definition 3
.

For a family of subsets

Observe that

(U,\mathcal{F})

(L,r(\mathcal{F},L))

-partition (resp., a

-packing or a

-cover) and
(R,r(\mathcal{F},R))

k_{r}
-partition (resp., a

-packing or a

-cover), where

and

.
We say that a

-packing, or

-cover
(S_{1},\dots,S_{k})

In this section we prove the following theorem.

Theorem 4
.

Suppose there is a simple (classical) branching algorithm

Faster Computation of the Chromatic Number

Assume the vertex set of input graph
G=(V,E)
can be partitioned into independent sets
C=(I_{1},I_{2},\dots,I_{\chi})
where
\chi
is the chromatic number of
G
. Denote by
n
the number of vertices of
G
.

Using the algorithm from
Theorem 4
, we can compute the chromatic number of
G
in
O(1.8554^{n})
time. The family of subsets
\mathcal{F}
corresponds to the independent sets of
G
and the family
e(X,r(\mathcal{F},X))
corresponds to the maximal independent sets of
G[X]
, which can be enumerated by a simple branching algorithm
A
in
O(3^{|X|/3})
time
[
FK10
]
.
We now prove a stronger result.

Theorem 8
.

There is a bounded-error quantum algorithm, which for a graph on
n
vertices, computes the chromatic number in
O(1.7956^{n})
time.

Assume, w.l.o.g., that
|I_{1}|\geq|I_{2}|\geq|I_{3}|\geq|I_{4}|\geq\dots\geq|I_{\chi}|
.

In the first step, we use the algorithm from
Theorem 3
with
\alpha=0.27
and store the result in QRAM. That is, for each
\alpha
-small subset
X\subset V
, we find the chromatic number of
X
by finding the smallest
k
such that there exists a
k
-partition of
X
into independent sets. This takes
O^{*}(\binom{n}{0.27\cdot n})=O^{*}(1.79187^{n})
time.

We then consider a few different possibilities for the large sets in
C
and present an algorithm which finds a partition into a smallest number of independent sets for each of these cases. These possibilities cover all configurations of
C
so one result is guaranteed to find the chromatic number by detecting the partition
C
above, or an equivalent partition. The cases are as follows:

1.

G
contains a vertex subset of size at least
0.48\cdot n
that is the union of at most five sets in
C
.

We check for
k
-coloring for all
1\leq k\leq n
and take the minimum valid value of
k
as the chromatic number. To check for a certain
k
, we use Grover’s search over all
Q\subset V
where
|Q|\leq 0.52\cdot n
and check whether
G-Q
is 5-colorable. If it is 5-colorable, we compute its chromatic number by checking its
k^{\prime}
-colorability for
k^{\prime}<5
. We then solve the instance
(Q,r(\mathcal{F},Q))
to find a
k_{Q}
-coloring, where
k_{Q}=k-\chi(G-Q)
, using Grover’s search to divide
Q
into
(QL,QR)
where
|QL|\geq 0.27\cdot n
and
k_{QL}+k_{QR}=k_{Q}
. For
(QL,r(\mathcal{F},QL))
(and similarly for
QR
) we use Grover’s search on the branching algorithm
A
to enumerate candidate sets
S_{1}\in e(QL,r(\mathcal{F},QL))
; if
|QL|-|S_{1}|>0.27\cdot n
, then this branch is unsuccessful; otherwise, find
\chi(QL\setminus S_{1})
in QRAM.

The running time of this case with quantum 5-coloring in
O^{*}(1.4695^{n})

[
SM22
]
is

\displaystyle\;O^{*}\left(\sum_{l=0}^{\lfloor 0.52\cdot n\rfloor}\sqrt{\binom{n}{l}}\left(\sum_{l^{\prime}=\lceil\frac{l}{2}\rceil}^{l}\sqrt{\binom{l}{l^{\prime}}3^{l^{\prime}/3}}+1.4695^{n-l}\right)\right)

\displaystyle=

\displaystyle\;O^{*}\left(\sqrt{\sum_{l=0}^{\lfloor 0.52\cdot n\rfloor}\binom{n}{l}\sum_{l^{\prime}=\lceil\frac{l}{2}\rceil}^{l}\binom{l}{l^{\prime}}3^{l^{\prime}/3}}+\sqrt{\sum_{l=\lceil 0.48\cdot n\rceil}^{n}\binom{n}{l}\left(1.4695^{l}\right)^{2}}\right)

\displaystyle=

\displaystyle\;O^{*}\left(\sqrt{\binom{n}{0.52\cdot n}2.4423^{0.52\cdot n}}+\sqrt{(1+1.4695^{2})^{n}}\right)

\displaystyle=

\displaystyle\;O^{*}\left(1.7831^{n}+1.7775^{n}\right)=O^{*}(1.7831^{n})

\displaystyle<0.48\cdot n

\displaystyle<0.48\cdot n

\displaystyle\;\>\Longrightarrow

\displaystyle\;|I_{1}|+|I_{2}|+\dots+|I_{6}|

\displaystyle<0.576\cdot n,

\displaystyle 0.424\cdot n<|V\setminus\bigcup_{i=1}^{6}I_{i}|\leq 0.52\cdot n.

k
-coloring for all

8
Enumeration of Minimal Subset Dominating Sets

In this section, we prove that the number of minimal dominating sets of a graph that are subsets of some linear-sized subset of vertices
X
is at most
O^{*}\left((2-\varepsilon)^{|X|}\right)
. Moreover, they can be enumerated by a simple branching algorithm whose running time is within a polynomial factor of this bound.

Theorem 9
.

There is a simple branching algorithm, which, given any graph
G=(V,E)
and any subset of vertices
X\subseteq V
with
|X|\geq d\cdot|V|
for some
d>0
,
enumerates all minimal dominating sets of
G
that are subsets of
X
in
O^{*}\left((2-\varepsilon_{d})^{|X|}\right)
time, for some
\varepsilon_{d}>0
.

The theorem will follow from a slightly more general theorem about minimal set covers of a set system.
From a graph
G=(V,E)
and a vertex subset
X\subseteq V
, we obtain a set system
(U,\mathcal{F})
where
U=V
and a set
S_{x}\in\mathcal{F}
for each
x\in X
that contains the closed neighborhood of vertex
x
in the graph
G
:
S_{x}=N_{G}[x]
.
Then, there is a 1-to-1 correspondence between inclusion-wise minimal dominating sets in
G
that are subsets of
X
and inclusion-wise minimal set covers of
(U,\mathcal{F})
.

Theorem 10
.

There is a simple branching algorithm, which, given any set system
(U,\mathcal{F})
with
|U|\leq r\cdot|\mathcal{F}|
for some
r>0
,
enumerates all minimal set covers of
(U,\mathcal{F})
in
O^{*}\left(2^{(1-\varepsilon_{r})\cdot|\mathcal{F}|}\right)
time, for some
\varepsilon_{r}>0
.

[
FGPS08
]
proved
Theorem 9
for
X=V
and
Theorem 10
for
r=1
. In particular, their algorithm enumerates all minimal dominating sets of a graph on
n
vertices in
O(1.7159^{n})
time.

Proof.

Let
r>0
.
Let
\varepsilon=\frac{3(r+1)-\log(2^{3(r+1)}-1)}{3(r+1)^{2}}
.
Consider the measure

\displaystyle\mu(U,\mathcal{F})=(1-(r+1)\varepsilon)|\mathcal{F}|+\varepsilon|U|

which associates a weight of
1-(r+1)\varepsilon>0
to each set and a weight of
\varepsilon>0
to each element of a set system
(U,\mathcal{F})
.
We will show that every set system
(U,\mathcal{F})
has at most
2^{\mu(U,\mathcal{F})}
minimal set covers by induction on
|\mathcal{F}|
.
For a set system with
|U|\leq r\cdot|\mathcal{F}|
, this number is
2^{(1-(r+1)\varepsilon)|\mathcal{F}|+\varepsilon|U|}\leq 2^{(1-\varepsilon)\cdot|\mathcal{F}|}
.
The proof can easily be turned into a simple branching algorithm enumerating all minimal set covers whose search tree is the induction tree of this proof.

The statement trivially holds when
|\mathcal{F}|=0
since such an instance has at most
1
minimal set cover.
For the induction, we consider three cases.

1.

\mathcal{F}
contains a set
S
with
|S|\geq 3(r+1)
. Any minimal set cover either contains
S
or not. Those that do not contain
S
are also minimal set covers of
(U,\mathcal{F}\setminus\{S\})
and those that contain
S
are made up of
S
and a minimal set cover of
(U\setminus S,\mathcal{F}\setminus\{S\})
. For the induction, we would like that

\displaystyle 2^{\mu(U,\mathcal{F}\setminus\{S\})}+2^{\mu(U\setminus S,\mathcal{F}\setminus\{S\})}

\displaystyle\leq 2^{\mu(U,\mathcal{F})}

\displaystyle\iff

\displaystyle 2^{\mu(U,\mathcal{F})-(1-(r+1)\varepsilon)}+2^{\mu(U,\mathcal{F})-(1-(r+1)\varepsilon)-|S|\cdot\varepsilon}

\displaystyle\leq 2^{\mu(U,\mathcal{F})}

\displaystyle\iff

\displaystyle 2^{-1+(r+1)\varepsilon}+2^{-1+(r+1)\varepsilon-|S|\cdot\varepsilon}

\displaystyle\leq 1

\displaystyle\;\Longleftarrow\;

\displaystyle 2^{-1+(r+1)\varepsilon}+2^{-1-2(r+1)\varepsilon}

\displaystyle\leq 1,

and this inequality holds because
\varepsilon\leq\frac{1}{r+1}\log\left(\frac{1+\sqrt{5}}{2}\right)
.

2.

There is an element
u\in U
with frequency at most
3(r+1)
, i.e.,
u
occurs in at most
3(r+1)
sets of
\mathcal{F}
. Denote the sets that contain
u
by
\mathcal{S}=\{S\in\mathcal{F}:u\in S\}
. Since
u
needs to be covered, each set cover contains at least one set from
\mathcal{S}
. We use induction on all
2^{|\mathcal{S}|}-1
choices of including at least one set from
\mathcal{S}
into the set covers and excluding the remaining sets from
\mathcal{S}
; each such choice leads to a set cover instance where we remove all sets in
\mathcal{S}
, and we remove all elements covered by the sets that are included in the set covers. Each such choice reduces the measure
\mu
by more than
|\mathcal{S}|\cdot(1-(r+1)\varepsilon)
. Now, we would therefore like that

\displaystyle(2^{|\mathcal{S}|}-1)\cdot 2^{\mu(U,\mathcal{F})-|\mathcal{S}|\cdot(1-(r+1)\varepsilon)}

\displaystyle\leq 2^{\mu(U,\mathcal{F})}

\displaystyle\iff

\displaystyle(2^{|\mathcal{S}|}-1)\cdot 2^{-|\mathcal{S}|\cdot(1-(r+1)\varepsilon)}

\displaystyle\leq 1

\displaystyle\iff

\displaystyle 2^{-|\mathcal{S}|\cdot(1-(r+1)\varepsilon)}

\displaystyle\leq(2^{|\mathcal{S}|}-1)^{-1}

\displaystyle\iff

\displaystyle-|\mathcal{S}|\cdot(1-(r+1)\varepsilon)

\displaystyle\leq-\log(2^{|\mathcal{S}|}-1)

\displaystyle\iff

\displaystyle(r+1)\varepsilon-1

\displaystyle\leq\frac{-\log(2^{|\mathcal{S}|}-1)}{|\mathcal{S}|}

\displaystyle\iff

\displaystyle\varepsilon

\displaystyle\leq\frac{|\mathcal{S}|-\log(2^{|\mathcal{S}|}-1)}{(r+1)|\mathcal{S}|}

Note that
\frac{|\mathcal{S}|-\log(2^{|\mathcal{S}|}-1)}{(r+1)|\mathcal{S}|}
decreases when
|\mathcal{S}|
increases, and for the maximum possible value of
|\mathcal{S}|
, which is
3(r+1)
, the inequality holds with equality for the value of
\varepsilon
given in the beginning of the proof.

3.

It remains to consider the case where all sets have size less than
3(r+1)
and all elements have frequency more than
3(r+1)
. Since the sum of set sizes equals the sum of element frequencies, we have that
|\mathcal{F}|\geq|U|
. Here, we use the result of Fomin et al.
[
FGPS08
]
who proved that the number of minimal set covers is at most
1.7159^{|\mathcal{F}|}
. For the induction, we would like that

\displaystyle 1.7159^{|\mathcal{F}|}

\displaystyle\leq 2^{\mu(U,\mathcal{F})}

\displaystyle\iff

\displaystyle 2^{|\mathcal{F}|\log 1.7159}

\displaystyle\leq 2^{(1-(r+1)\varepsilon)|\mathcal{F}|+\varepsilon|U|}

\displaystyle\;\Longleftarrow\;

\displaystyle 0.779|\mathcal{F}|

\displaystyle\leq(1-(r+1)\varepsilon)|\mathcal{F}|

\displaystyle\iff

\displaystyle\varepsilon\leq\frac{0.221}{r+1}

and this inequality holds for the value of
\varepsilon
given in the beginning of the proof.

This concludes the proof of the theorem.
∎
