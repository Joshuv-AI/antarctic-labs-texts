Let
\mathcal{H}[a,n]

consisting of the univalent functions. The Carathéodory class
\mathcal{P}
consists of the analytic functions
p

\mathbb{D}
of the form
p(z)=1+p_{1}z+p_{2}z^{2}+\cdots,
having positive real part in
\mathbb{D}
. Consider two analytic functions
f
and

in
\mathbb{D}

is subordinate to

, if
f(z)=g(\omega(z))
, where
\omega
is a Schwarz function such that
\omega(0)=0
and
|\omega(z)|<1

g
is univalent in
\mathbb{D}

if and only if
f(0)=g(0)
and
f(\mathbb{D})\subseteq g(\mathbb{D})

[
6

unified many subclasses of starlike and convex functions, as follows:

(1.1)

\mathcal{S}^{*}(\phi)=\left\{f\in\mathcal{S}:\dfrac{zf^{\prime}(z)}{f(z)}\prec\phi(z)\right\}\text{ and }\mathcal{C}(\phi)=\left\{f\in\mathcal{S}:1+\dfrac{zf^{\prime\prime}(z)}{f^{\prime}(z)}\prec\phi(z)\right\},

where
\phi
is an analytic function having positive real part in
\mathbb{D}
and
\phi^{\prime}(0)>0
such that
\phi(\mathbb{D})
is symmetric with respect to the real axis and starlike with respect to
\phi(0)=1
. For
\phi(z)=(1+z)/(1-z)
, the above classes, respectively reduces to
\mathcal{S}^{*}
, the class of starlike univalent functions and
\mathcal{C}
, the class of convex univalent functions. Recall that the
p
-valent function
f(z)=z^{p}+a_{p+1}z^{p+1}+\cdots
is convex if and only if

(1.2)

\RE\left(1+\dfrac{zf^{\prime\prime}(z)}{f^{\prime}(z)}\right)>0,\quad z\in\mathbb{D}.

This class is extensively studied in
[
2
]
. We may now conclude:

Definition 1.1
.

The function
f\in\mathcal{H}
is convex univalent in
\mathbb{D}
if and only if (
1.2
) holds.

Moreover, the univalence criteria for such functions is illustrated recently in
[
10
]
as follows:

Lemma 1.2
.

[
10

Let the function
q(z)=z+a_{2}z^{2}+\cdots
be analytic in
\mathbb{D}
such that
q(z)q^{\prime}(z)/z\neq 0

satisfying
1+\RE\left(zq^{\prime\prime}(z)/q^{\prime}(z)\right)>\alpha
in
\mathbb{D}
is univalent if and only if
-1/2\leq\alpha\leq 0
.

Geometrically, it is also known that a function
f(z)
is convex(starlike) function if it maps
\mathbb{D}
onto a convex(starlike) domain. A function
f\in\mathcal{H}
is starlike if and only if it satisfies

(1.3)

\RE\left(\dfrac{zf^{\prime}(z)}{f(z)}\right)>0,\quad z\in\mathbb{D}.

This characterization for starlikeness of functions in
\mathcal{H}
cannot be extended to
\mathcal{H}[a,1]
. We can see this in case of
f_{0}(z)=(1+z)/(1-z)\in\mathcal{H}[1,1]
, which maps the unit disk
\mathbb{D}
onto a convex domain, hence starlike in
\mathbb{D}
but fails to satisfy (
1.3

\RE(zf_{0}^{\prime}(z)/f_{0}(z))=\RE(2z/(1-z^{2}))\not>0
. This reveals that the normalization

is essential, which is not followed by functions in
\mathcal{H}[a,1]

(a\neq 0)
. But, the characterization of convex functions

, given in Definition
1.1
can be extended to convex functions in
\mathcal{H}[a,1]
as follows:

Lemma 1.3
.

The function
\tilde{f}(z)=a+a_{1}z+a_{2}z^{2}+\cdots\in\mathcal{H}[a,1]
is convex univalent in
\mathbb{D}
if and only if it satisfies

(1.4)

\RE\left(1+\dfrac{z\tilde{f}^{\prime\prime}(z)}{\tilde{f}^{\prime}(z)}\right)>0,\quad z\in\mathbb{D}.

Proof.

Consider a function
f(z)=\tfrac{\tilde{f}(z)-a}{a_{1}}
, then
f\in\mathcal{H}
and we get

(1.5)

\RE\left(1+\dfrac{z\tilde{f}^{\prime\prime}(z)}{\tilde{f}^{\prime}(z)}\right)=\RE\left(1+\dfrac{zf^{\prime\prime}(z)}{f^{\prime}(z)}\right).

Now, if we assume
\tilde{f}
is convex univalent in
\mathbb{D}
, then geometrically so is the function

. Thus equation (
1.4

1.1
and equation (
1.5

1.4
) holds, then equation (
1.2
) holds true using equation (
1.5

1.1

is convex univalent in
\mathbb{D}
and geometrically so is

Now, we recall that a first order differential equation of the type:

(1.7)

M(x,y)dx+N(x,y)dy=0,

where

have continuous partial derivatives in some domain

\tfrac{\partial M}{\partial y}=\tfrac{\partial N}{\partial x}

\int M(x,y)dx+\int\tilde{N}(y)dy=c,

where

, which is independent of

Definition 1.5
.

Let

and

\psi(p(z),zp^{\prime}(z))\prec h(z),

which further implies

\psi(q(z),nzq^{\prime}(z))=h(z).

Then the differential subordintion (

if and only if the following conditions hold:

\emph{(i)}

\psi
can be expressed as
\widetilde{M}(z,p)+N(z,p)\penalty\ p^{\prime}(z)
such that
\tfrac{\partial\widetilde{M}}{\partial p}=\tfrac{\partial N}{\partial z}
for all
n
.

\emph{(ii)}
For
n=1
, the equation (
1.10
) reduces to an exact differential equation:

M(z,q)\penalty\ dz+N(z,q)\penalty\ dq=0,

or equivalently
\tfrac{\partial M}{\partial q}=\tfrac{\partial N}{\partial z}
, where
M(z,q):=\widetilde{M}(z,q)-h(z)
.

In the present investigation, we mainly focus on the following exact type of differential subordinations:

(1.11)

(\beta p(z)+\gamma)^{-\alpha}\left(\dfrac{(\beta p(z)+\gamma)}{\beta(1-\alpha)}+zp^{\prime}(z)\right)\prec h(z),

and

(1.12)

\displaystyle\dfrac{1}{\sqrt{\gamma\beta}}\arctan\left(\sqrt{\dfrac{\beta}{\gamma}}p^{1-\alpha}(z)\right)+\left(\dfrac{1-\alpha}{\beta p^{2(1-\alpha)}(z)+\gamma}\right)\dfrac{zp^{\prime}(z)}{p^{\alpha}(z)}\prec h(z),

is a non vanishing convex univalent function in
\mathbb{D}
with

and

[

\psi_{i}(q(z),nzq^{\prime}(z))=h(z)\quad(i=1,2).

Now we show that the above two differential subordinations are exact. Take
\widetilde{M}(z,p):=\tfrac{(\beta p+\gamma)^{1-\alpha}}{\beta(1-\alpha)}
and
N(z,p):=\tfrac{z}{(\beta p+\gamma)^{\alpha}}
in (

1.13

(1.14)

M(z,q)\penalty\ dz+N(z,q)\penalty\ dq=0

1.11

(1.15)

\displaystyle\int M(z,q)\penalty\ dz+\int\tilde{N}(z)\penalty\ dq=c,

where

is equal to that part of the expression

, which is independent of

\displaystyle q(z)=\dfrac{\left(\dfrac{\beta(1-\alpha)}{nz^{1/n}}\int_{0}^{z}h(t)t^{(1/n)-1}dt\right)^{\tfrac{1}{1-\alpha}}-\gamma}{\beta}.

Similarly, we can show that
