All S S invariant gluon OPEs on the celestial sphere
Shamik Banerjee a , b {}^{\,a,b} , Raju Mandal a , b {}^{\,a,b} , Sagnik Misra a , b {}^{\,a,b} , Sudhakar Panda a , c {}^{\,a,c} , Partha Paul d {}^{\,d}

Abstract
S S algebra is an infinite dimensional Lie algebra which is known to be the symmetry algebra of some gauge theories. It is a "coloured version" of the w 1 + ∞ w_{1+\infty} . In this paper we write down all possible S S invariant (celestial) OPEs between two positive helicity outgoing gluons and also find the Knizhnik-Zamolodchikov type null states for these theories. Our analysis hints at the existence of an infinite number of S S invariant gauge theories which include the (tree-level) MHV-sector and the self-dual Yang-Mills theory.

-invariance does not fix the value of the integer
n
. Hence we can get a discrete infinite family of
S
-invariant OPEs for different choices of the integer
n
. Each of these consistent OPEs correspond to a
S
invariant theory of gluons. But, at present we do not know the Lagrangian description of these theories except perhaps the self-dual Yang-Mills theory.

8
Knizhnik-Zamolodchikov type null states

Knizhnik-Zamolodchikov (KZ) type null states contain descendants of the holomorphic translation generator
L_{-1}
on the celestial sphere. They can be obtained algebraically by determining the relevant primary descendant but in our case we can bypass this tedious procedure if we use the OPE commutativity

\begin{gathered}\mathcal{O}^{a,+}_{\Delta_{1}}(z_{1},\bar{z}_{1})\mathcal{O}^{b,+}_{\Delta_{2}}(z_{2},\bar{z}_{2})=\mathcal{O}^{b,+}_{\Delta_{2}}(z_{2},\bar{z}_{2})\mathcal{O}^{a,+}_{\Delta_{1}}(z_{1},\bar{z}_{1})\end{gathered}

(26)

The reason behind this is that the
\mathcal{O}(z_{12}^{0}\bar{z}_{12}^{0})
terms of the OPE, as written in (
22
), are not manifestly symmetric under the exchange (
26
). Therefore OPE commutativity imposes non-trivial constraints on the OPE coefficients and one such constraint is essentially the KZ equation. The process can be further simplified if make the operator
\mathcal{O}^{b,+}_{\Delta_{2}}(z_{2},\bar{z}_{2})
leading soft by taking the limit
\Delta_{2}\to 1
. Now a straightforward calculation gives the KZ type null state

\boxed{\begin{split}K^{a}(\Delta)=\xi^{a}(\Delta)-i\sum_{k=1}^{n}M^{a}_{k}(\Delta+1)=0.\end{split}}

(27)

where

\xi^{a}(\Delta)=C_{A}L_{-1}\mathcal{O}^{a,+}_{\Delta}-(\Delta+1)R^{1,b}_{-1,0}R^{1,b}_{0,0}\mathcal{O}^{a,+}_{\Delta}-R^{0,b}_{-\frac{1}{2},\frac{1}{2}}R^{1,b}_{0,0}\mathcal{O}^{a,+}_{\Delta+1}

(28)

is the KZ type null state in the MHV-sector
Banerjee:2020vnt
and
M^{a}_{k}(\Delta)
is the antisymmetric part of the null state
M^{ab}_{k}(\Delta)
defined in (
13
). We have also used the identity
f^{abx}f^{aby}=C_{A}\delta^{xy}
in deriving the KZ type null state equation (
27
).

Another null state equation involving the descendant
L_{-1}\mathcal{O}^{a,+}_{\Delta}
can be obtained from (
26
) in a similar way by taking the subleading conformal soft limit
\Delta_{2}\to 0
. It is given by

\begin{split}(\Delta-1)\xi^{a}(\Delta)-\sum_{k=1}^{n}(\Delta+k)M^{a}_{k}(\Delta+1)=0.\end{split}

(29)

Now multiplying equation (
27
) by
(\Delta-1)
and then subtracting it from (
29
) we get the following (current algebra) null state

\chi^{1,a}_{n}(\Delta)=\sum_{k=1}^{n}(k+1)M_{k}^{a}(\Delta)=0

(30)

One can continue this procedure and get other current algebra null states by taking conformal soft limits
\Delta_{2}\rightarrow k,\ k\leq-1
. We can denote them by
\{\chi^{1}_{n}(\Delta),\chi^{2}_{n}(\Delta),\cdots\}
. However, it can be shown that after a finite iteration this procedure stops due to the truncation (
21
).

8.1
S invariance of the KZ type null state

In this section we show that the KZ type null state (
27
) is
S
-invariant.

First of all, the states
M_{k}^{ab}(\Delta)
, and as a result
M^{a}_{k}(\Delta)=f^{abc}M^{bc}_{k}(\Delta)
, are annihilated by
H^{0}_{0,1}
. Therefore the state
K^{a}(\Delta)
is a primary of
\overline{sl_{2}(R)}
because the KZ type null state (
28
) in the MHV-sector is annihilated
Banerjee:2020vnt
by
H^{0}_{0,1}
.

Similarly, one can show after some algebra that the following relation holds

\begin{gathered}R^{0,c}_{\frac{1}{2},\frac{1}{2}}\ K^{a}(\Delta)=(\Delta-2)if^{cax}K^{x}(\Delta-1)-(n+2)f^{cbx}f^{aby}M^{xy}_{n+1}(\Delta)+f^{cax}\chi^{1,x}_{n}(\Delta)\\
+f^{cby}f^{bax}\left[\sum_{k=1}^{n}(k+1)M_{k}^{yx}(\Delta)+2E^{yx}(\Delta)\right]+f^{cab}f^{byx}E^{yx}(\Delta)\end{gathered}

(31)

where

E^{yx}(\Delta)=(\Delta-2)R^{1,y}_{-1,0}\mathcal{O}^{x,+}_{\Delta-1}+R^{0,y}_{-\frac{1}{2},\frac{1}{2}}\mathcal{O}^{x,+}_{\Delta}

(32)

Now we know that, in a theory in which the
\mathcal{O}(z_{12}^{0}\bar{z}_{12}^{0})
OPE truncates at
k=n
, i.e, (
21
) holds, both
M_{n+1}^{bc}(\Delta)
and
\chi^{1,a}_{n}(\Delta)
are null states. Thus we can set them to 0 and get,

\begin{gathered}R^{0,c}_{\frac{1}{2},\frac{1}{2}}\ K^{a}(\Delta)=(\Delta-2)if^{cax}K^{x}(\Delta-1)+f^{cby}f^{bax}\left[\sum_{k=1}^{n}(k+1)M_{k}^{yx}(\Delta)+2E^{yx}(\Delta)\right]+f^{cab}f^{byx}E^{yx}(\Delta)\end{gathered}

(33)

We show in Appendix (
C
) that the second and the third terms on the RHS of (
33
) are actually zero. Taking this into account we get

\begin{gathered}R^{0,c}_{\frac{1}{2},\frac{1}{2}}\ K^{a}(\Delta)=(\Delta-2)if^{cax}K^{x}(\Delta-1)\end{gathered}

(34)

Thus we see that
R^{0,c}_{\frac{1}{2},\frac{1}{2}}
maps the KZ type null state
K^{a}(\Delta)
to linear combination of other null states in the theory. Hence, the null state equation

K^{a}(\Delta)=0

(35)

is
S
invariant.
