The Scholz conjecture on addition chain is true for infinitely many integers with ℓ ⁡ ( 2 ​ n ) = ℓ ⁡ ( n ) \ell(2n)=\ell(n)
Amadou TALL

Abstract
It is known that the Scholz conjecture on addition chains is true for all integers n n with ℓ ⁡ ( 2 ​ n ) = ℓ ⁡ ( n ) + 1 \ell(2n)=\ell(n)+1 . There exists infinitely many integers with ℓ ⁡ ( 2 ​ n ) ≤ ℓ ⁡ ( n ) \ell(2n)\leq\ell(n) and we don’t know if the conjecture still holds for them. The conjecture is also proven to hold for integers n n with v ⁡ ( n ) ≤ 5 v(n)\leq 5 and for infinitely many integers with v ⁡ ( n ) = 6 v(n)=6 . There is no specific results on integers with v ⁡ ( n ) = 7 v(n)=7 . In [ 14 ] , an infinite list of integers satisfying ℓ ⁡ ( n ) = ℓ ⁡ ( 2 ​ n ) \ell(n)=\ell(2n) and v ⁡ ( n ) = 7 v(n)=7 is given. In this paper, we prove that the conjecture holds for all of them.

Introduction

Let
n
be a positive integer. The problem of finding a minimal addition chain for
n
is quite interesting. Addition chains can give the fastest exponentiation methods. Knowing a good way to reach
n
from
1
leads to a method of computing
x^{n}
.

Definition 1

An addition chain for a positive integer
n
is a set of integers
\{a_{0}=1<a_{1}<a_{2}<\ldots<a_{r}=n\}

such that every element
a_{k}
can be written as sum
a_{i}+a_{j}
of preceding elements of the set.

Definition 2

We define
\ell(n)
as the smallest
r
for which there exists an addition chain
\{a_{0}=1<a_{1}<a_{2}<\ldots<a_{r}=n\}
for
n
.

Definition 3

Let
n
be an integer. We define
v(n)
as the number of ”1”s in its binary expansion. Let us also define by
\lambda(n)=\lceil\log_{2}(n)\rceil
.

The problem of finding
\ell(n)
for a given
n
is known to be NP–complete. An integer
n
can also have several distinct minimal addition chains.
One of the most efficient method is the so-called ”fast exponentiation” which refers to the binary method. It is also called the ”double–and–add” method. It is proven to be the fastest method for all integers with
v(n)\leq 3
.
It is proven that

Theorem 1.1

Let
n
be a positive integer. Then,

1.

If
v(n)=1
, meaning
n=2^{a}
then
\ell(n)=a

2.

IF
v(n)=2
, meaning
n=2^{a}+2^{b}
then
\ell(n)=a+1

3.

IF
v(n)=3
, meaning
n=2^{a}+2^{b}+2^{c}
then
\ell(n)=a+2

It become interesting to look at techniques based on the binary expansion of
n
.
If
v(n)=4
, then
n=2^{a}+2^{b}+2^{c}+2^{d}
and
\ell(n)\in\{a+2,a+3\}
. And it is the same case for

\ell(n)\in\{a+3,a+4,a+5\}

In
[
14

\ell(n)=a+4
.

It seems to be difficult to characterize the integers based on their binary representation. In
[
5

5
small steps in their minimal addition chains, meaning

The Scholz conjecture give a bound on the length of minimal addition chains for integers with only
1

Conjecture 1

Let
n
be a positive integer. We have

\ell(2^{n}-1)\leq\ell(n)+n-1.

Let us define the notion of short addition chain, which is not necessarily minimal as follows

Let
n

2^{n}-1

\ell(n)+n-1

In

. Later, Thurber
[
15

. Aiello and Subbaru

Thanks to Hatem

3

v(n)=6

and
\ell(n)=\lambda(n)+5

In 2005, Neill Clift

n<5784689
, the first non-hansen number. No results is known on integers with
v(n)=7
and
\ell(n)=\lambda(n)+4
.

Now, let us look at the product of integers. Thanks to the factor method, we can see that

\ell(mn)\leq\ell(m)+\ell(n),\forall m,\ n

We are tempted to believe that
\ell(2n)=\ell(n)+1

Lemma 1

It the Scholz conjecture hold for

Proof

Let

be another positive integer, we have

\ell(n)+n-1+n+1=\ell(n)+2n=\ell(n_{0})+n_{0}-1.

The chain is

\mathcal{C}=\{1,~2,~\ldots,~2^{n}-1,~2(2^{n}-1),~2^{2}(2^{n}-1),\ldots,~2^{n}(2^{n}-1),~2^{n}(2^{n}-1)+(2^{n}-1)=2^{2n}-1\}
