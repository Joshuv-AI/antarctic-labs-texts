Reduction of Register Pushdown Systems with Freshness Property to Pushdown Systems in LTL Model Checking Note: Funding: This work was partially supported by JSPS KAKENHI Grant Numbers JP19H04083 and JP20K20625.
Yoshiaki Takata, Ryoma Senda, Hiroyuki Seki

Abstract
Pushdown systems (PDS) are known as an abstract model of recursive programs, and model checking methods for PDS have been studied. Register PDS (RPDS) are PDS augmented by registers to deal with data values from an infinite domain in a restricted way. A linear temporal logic (LTL) model checking method for RPDS with regular valuations has been proposed; however, the method requires the register automata (RA) used for representing a regular valuation to be backward-deterministic. This paper proposes another approach to the same problem, in which the model checking problem for RPDS is reduced to that problem for PDS by constructing a PDS bisimulation equivalent to a given RPDS. The construction in the proposed method is simpler than the previous model checking method and does not require RAs deterministic or backward-deterministic, and the bisimulation equivalence clearly guarantees the correctness of this reduction. On the other hand, the proposed method requires every RPDS (and RA) to have the freshness property, in which whenever the RPDS updates a register with a data value not stored in any register or the stack top, the value should be fresh. This paper also shows that this model checking problem with regular valuations defined by general RA is undecidable, and thus the freshness constraint is essential in the proposed method.



1
Introduction

A pushdown system (PDS) is a pushdown automaton without input
and is well known as an abstract model of
recursive programs
[
1
,
2
]
.
The model checking problem for a PDS
\mathcal{P}
, i.e. testing whether all runs of
\mathcal{P}
conforms to a given specification

\varphi
,
has been studied for various logics such as
linear temporal logic (LTL) and branching-time temporal
logic
[
1
,
2
,
3
]
.
In
[
4
]
,
the LTL model checking of PDS with
regular valuations was investigated and
shown to be decidable.
A valuation is a function that labels
each configuration in a run with
a subset of atomic propositions.
A regular valuation is a valuation that
labels each configuration
c
of a PDS
with atomic propositions
depending on whether
the stack contents in
c
match a given regular pattern.

Although PDS is a natural model of recursive programs,
it cannot deal with data values directly.
Register automata (RA) were introduced as an extension of
finite automata (FA) by adding the capability of
dealing with data values in a restricted way
[
5
]
.
RA has attracted attention as a formal model of navigational queries
concerning data values to structured data
such as XML documents
[
6
]
.
RA has also been considered as
a formal model of software systems with
unbounded resources
in e.g. runtime verification
[
7
]

and reactive synthesis
[
8
]
.
Similarly to extending FA to RA, PDS were extended to
pushdown register systems (PDRS)
[
9
]
and
register pushdown systems (RPDS)
[
10
]
,
both of them are equivalent each other,
and the reachability problem for them has been shown
to be EXPTIME-complete.

In previous work
[
11
]
,
we have investigated the LTL model checking problem
with regular valuations for RPDS
and proposed
a method for solving the problem.
This method is a natural extension of the model checking method
for PDS in
[
4
]
.
Similarly to
the method in
[
4
]
that reduces the model checking problem
to the emptiness problem for Büchi pushdown systems,
in
[
11
]
we introduced
Büchi register pushdown systems (BRPDS) and showed
a reduction of the model checking problem
to the emptiness problem for BRPDS.
Note that the regular valuations in
[
11
]
were
defined in terms of
backward-deterministic RA,
in which
every configuration
has a unique predecessor configuration for each
input data value.
This constraint is essential because
unlike FA, determinization is not possible for
general RA.

In this paper,
we work on the same problem
in a different approach.
We reduce the model checking problem for RPDS
to that problem for PDS
by constructing a PDS
\mathcal{P}^{\prime}

bisimulation equivalent
[
12
]

to a given RPDS
\mathcal{P}
.
In the same way,
we also construct an FA
\mathcal{A}^{\prime}
bisimulation equivalent
to an RA
\mathcal{A}
used for a regular valuation.
The bisimulation equivalences between

\mathcal{P}
and
\mathcal{P}^{\prime}
and between
\mathcal{A}
and
\mathcal{A}^{\prime}

guarantee the correctness of this reduction.
The construction of a PDS bisimulation equivalent to an RPDS
is basically the same as
the one used in our recent work
[
13
]

on reactive synthesis from specifications
given by deterministic register pushdown automata (DRPDA).
In
[
13
]
, we construct a pushdown automaton (PDA)
simulating a DRPDA for reducing
the realizability problem for DRPDA to
the same problem for PDA.
The proposed method in this paper is an application
of this construction to the model checking problem,
where not only RPDS but also RA used for a regular valuation
can be reduced to models without data values
in a uniform way,
and the correctness of the reduction of the model checking
problem can be proved easily based on bisimulation equivalence.

Another feature of the proposed method is that
it does not require RA used for regular valuations
to be deterministic or backward-deterministic.
However,
the proposed method requires
every RPDS (and RA) to have
the freshness property instead,
in which whenever the RPDS updates a register with a data value
not stored in any register or the stack top,
the value should be fresh, i.e. not used before.
This paper also shows that the LTL model checking
problem for RPDS with regular valuations
defined by general RA is undecidable
(Theorem
1
), and
this fact compels
the proposed method to require
the freshness property
instead of requiring RA
to be deterministic or backward-deterministic.

Advantages of the proposed method are summarized as follows:
(i) The construction in the proposed method
is much simpler than the method
in
[
11
]
.
The bisimulation equivalence between an RPDS and
a PDS clearly
shows the correctness of the reduction.
We have proved this bisimulation equivalence
using a proof assistant software Coq
[
14
]
.
(ii) By the proposed method,
we can apply existing model checking tools for PDS
to solving the model checking problem for RPDS.
(iii) The method does not require RA used for regular valuations
to be deterministic or backward-deterministic,
though it requires the freshness property instead.
Showing the undecidability of the model checking problem
in the general case
is another contribution of the paper.

The rest of the paper is organized as follows.
We define basic notions in Section
2
,
RPDS and RA in Section
3
, and
the LTL model checking problem for RPDS with regular valuations
in Section
4
.
In Section
4
,
we also show that
this problem is undecidable in general.
In Section
5
,
we introduce the freshness property and
redefine the semantics of RPDS so that
every RPDS has this property.
In Section
6
,
we show the construction of a PDS bisimulation equivalent to
a given RPDS,
which is the main part of the proposed method.
We conclude the paper
in Section
7
.

Preliminaries

Let
\mathbb{N}=\{1,2,\ldots\}
,
\mathbb{N}_{0}=\{0\}\cup\mathbb{N}
,
and
[n]=\{1,2,\ldots,n\}

n\in\mathbb{N}
.
We assume a countable set
D

.
For a given

,

(of data values to
k

Let

be the set of assignments to

Sometimes we consider an assignment

d\in\theta
means
d=\theta(i)
for some
i\in[k]
.

For a set
A
,
let
A^{*}
and

be the sets of
finite and infinite words over
A
, respectively.
Let
A^{\infty}=A^{*}\cup A^{\omega}
.
For a word

\alpha\in A^{\infty}
,
let
\alpha(i)\in A
be the
i
-th element of
\alpha
and
\alpha(i\,{:})=\alpha(i)\alpha(i+1)\ldots
for
i\geq 0
.
Let
snd
be the function over pairs that gives the second element
of a pair;
i.e.,
\texttt{snd}((a,b))=b
. For a word
w=(a_{0},b_{0})(a_{1},b_{1})\ldots
over pairs,
let
\texttt{snd}(w)=b_{0}b_{1}\ldots
.

For a relation
\Rightarrow
,
let
\Rightarrow^{*}
be the reflexive transitive closure of
\Rightarrow
.

2.1
Linear Temporal Logic (LTL)

The definition of LTL formulas we used is the same
as
[
4
]
.
Let
\mathit{At}
be a finite set of
atomic propositions
,
and let
\Sigma=2^{\mathit{At}}
.
An
LTL formula
over
\mathit{At}
is given by the following syntax:

\varphi::=\texttt{tt}\mid A\mid\neg\varphi\mid\varphi_{1}\land\varphi_{2}\mid\mathbin{\mathcal{X}}\varphi\mid\varphi_{1}\mathbin{\mathcal{U}}\varphi_{2}

where
A\in\mathit{At}
.
For an infinite word
w\in\Sigma^{\omega}
,
the satisfaction relation
\models
is defined as follows:

\displaystyle w

\displaystyle\models\texttt{tt},

\displaystyle w

\displaystyle\models A

\displaystyle\iff\

\displaystyle A\in w(0),

\displaystyle w

\displaystyle\models\neg\varphi

\displaystyle\iff\

\displaystyle w\not\models\varphi,

\displaystyle w

\displaystyle\models\varphi_{1}\land\varphi_{2}

\displaystyle\iff\

\displaystyle w\models\varphi_{1}\text{ and }w\models\varphi_{2},

\displaystyle w

\displaystyle\models\mathbin{\mathcal{X}}\varphi

\displaystyle\iff\

\displaystyle w(1\,{:})\models\varphi,

\displaystyle w

\displaystyle\models\varphi_{1}\mathbin{\mathcal{U}}\varphi_{2}\

\displaystyle\iff\

\displaystyle\exists j:(w(j\,{:})\models\varphi_{2})

\displaystyle{}\land(\forall i<j:w(i\,{:})\models\varphi_{1}).

We also define
\Diamond\varphi=\texttt{tt}\mathbin{\mathcal{U}}\varphi
and

\Box\varphi=\neg\Diamond(\neg\varphi)
.

2.2
Pushdown systems and finite automata

For a finite set
\Gamma
, we define the set

\texttt{Com}(\Gamma)
of
commands
over
\Gamma
as

\texttt{Com}(\Gamma)=\{\texttt{pop},\texttt{skip}\}\cup\{\texttt{push}(\gamma)\mid\gamma\in\Gamma\}
.

Definition 1

A
pushdown system
(PDS)

\mathcal{P}
over a stack alphabet
\Gamma

is a pair
(P,\Delta)
, where

P
is a finite set of
states
and

\Delta\subseteq P\times\Gamma\times P\times\texttt{Com}(\Gamma)

is a set of
transition rules
.
We write an element
(p,\gamma,q,\mathit{com})\in\Delta
as

(p,\gamma)\to(q,\mathit{com})
for readability.

Let
\mathit{ID}_{\mathcal{P}}=P\times\Gamma^{*}
and call each element of

\mathit{ID}_{\mathcal{P}}

an
instantaneous description
(ID) of
\mathcal{P}
.
The transition relation
\Rightarrow_{\mathcal{P}}
of
\mathcal{P}

is the smallest relation over
\mathit{ID}_{\mathcal{P}}

satisfying the following inference rule,
where

\texttt{upds}^{\prime}(\gamma v,\mathit{com}^{\prime})=v
,
\gamma v
, or
\gamma^{\prime}\gamma v

if
\mathit{com}^{\prime}=\texttt{pop}
,
skip
, or
\texttt{push}(\gamma^{\prime})
, respectively.

\begin{array}[]{l}(p,\gamma)\to(q,\mathit{com}^{\prime})\in\Delta\\
\hline\cr(p,\gamma v)\Rightarrow_{\mathcal{P}^{\prime}}(q,\texttt{upds}^{\prime}(\gamma v,\mathit{com}^{\prime}))\end{array}

A
run
of
\mathcal{P}
is a sequence
\rho\in\mathit{ID}_{\mathcal{P}}^{\omega}

such that
\rho(i)\Rightarrow_{\mathcal{P}}\rho(i+1)
for
i\geq 0
.

We define nondeterministic finite automata as follows,
which is used
for representing a (regular) subset of IDs of some PDS.

Definition 2

A
nondeterministic finite automaton
(NFA)

\mathcal{A}
over an alphabet
\Gamma
is a quadruple

(Q,I,F,\delta)
,
where
(Q,\delta)
is a PDS over
\Gamma
where

\delta
consists of pop rules only,

I\subseteq Q
is a set of
initial states
, and

F\subseteq Q
is a set of
final states
.
We call
(Q,\delta)
the
base PDS
of
\mathcal{A}
.
The set
\mathit{ID}_{\!\mathcal{A}}
of IDs and the transition relation
of
\mathcal{A}
are the same as those of its base PDS.
We write the transition relation of
\mathcal{A}
as
\vdash_{\mathcal{A}}
.
The
language

L(\mathcal{A})
of
\mathcal{A}
is a subset of
\mathit{ID}_{\!\mathcal{A}}

defined as

L(\mathcal{A})=\{(p,w)\in I\times\Gamma^{*}\mid(p,w)\vdash_{\mathcal{A}}^{*}(q,\varepsilon)
for some
q\in F\}
.

When we use an NFA
\mathcal{A}
for representing a subset of IDs
of a PDS
\mathcal{P}=(P,\Delta)
,
we let the set of the initial states of
\mathcal{A}
be
P
.

Definition 3

For a PDS
\mathcal{P}=(P,\Delta)
,
we call a subset
C\subseteq\mathit{ID}_{\mathcal{P}}

regular

if there exists an NFA
\mathcal{A}=(Q,P,F,\delta)
that satisfies

C=L(\mathcal{A})
.

2.3
Equivalence relations over registers

Let
\Phi_{k}
be the set of
equivalence relations
over
the set of
2k+1
symbols

X_{k}=\{\mathtt{x}_{1},\ldots,\mathtt{x}_{k},\allowbreak\mathtt{x}^{\prime}_{1},\ldots,\mathtt{x}^{\prime}_{k},\allowbreak\mathtt{x}_{\texttt{top}}\}
.
We write
a\equiv_{\phi}b
and
a\not\equiv_{\phi}b
to mean

(a,b)\in\phi
and
(a,b)\notin\phi
, respectively,
for
a,b\in X_{k}
and
\phi\in\Phi_{k}
.
Intuitively,
each
\phi\in\Phi_{k}
represents the equality and inequality
among the data values in the registers and the stack top,
as well as the transfer of the values in the registers
between two assignments.
Two assignments
\theta,\theta^{\prime}\in\Theta_{k}

and a value
d
at the stack top satisfy
\phi
,
denoted as
(\theta,d,\theta^{\prime})\models\phi
,
iff for
i,j\in[k]
,

\displaystyle\mathtt{x}_{i}\equiv_{\phi}\mathtt{x}_{j}

\displaystyle\Leftrightarrow\theta(i)=\theta(j),

\displaystyle\mathtt{x}_{i}\equiv_{\phi}\mathtt{x}_{\texttt{top}}

\displaystyle\Leftrightarrow\theta(i)=d,

\displaystyle\mathtt{x}_{i}\equiv_{\phi}\mathtt{x}^{\prime}_{j}

\displaystyle\Leftrightarrow\theta(i)=\theta^{\prime}(j),\quad

\displaystyle\mathtt{x}^{\prime}_{j}\equiv_{\phi}\mathtt{x}_{\texttt{top}}

\displaystyle\Leftrightarrow\theta^{\prime}(j)=d,

\displaystyle\mathtt{x}^{\prime}_{i}\equiv_{\phi}\mathtt{x}^{\prime}_{j}

\displaystyle\Leftrightarrow\theta^{\prime}(i)=\theta^{\prime}(j).

We will use elements of
\Phi_{k}
to specify
transition rules of a register pushdown system with
k
registers
(
k
-RPDS), defined in the next section.

Let
\Phi^{\prime}_{k}
be the set of equivalence relations over
the
k
symbols
\{\mathtt{x}_{1},\ldots,\mathtt{x}_{k}\}
.
An assignment
\theta\in\Theta_{k}
satisfies
\phi^{\prime}\in\Phi^{\prime}_{k}
,
denoted as
\theta\models\phi^{\prime}
,
iff for
i,j\in[k]
,

\mathtt{x}_{i}\equiv_{\phi^{\prime}}\mathtt{x}_{j}\iff\theta(i)=\theta(j)
.
Elements of
\Phi^{\prime}_{k}
will be used to specify
accepting conditions of a register automaton with
k
registers
(
k
-RA).

Let
\texttt{lat}:\Phi_{k}\to\Phi^{\prime}_{k}
be the function defined as:

\forall i,j\in[k]:\mathtt{x}_{i}\equiv_{\texttt{lat}(\phi)}\mathtt{x}_{j}
iff
\mathtt{x}^{\prime}_{i}\equiv_{\phi}\mathtt{x}^{\prime}_{j}
.

4
LTL model checking problem and valuations

We fix a finite set
\mathit{At}
of atomic propositions,
and let
\Sigma=2^{\mathit{At}}
.

A
valuation
for a
k
-RPDS
\mathcal{P}=(P,\Delta)
is
a function

\Lambda:\mathit{ID}_{\mathcal{P}}\to\Sigma
,
which labels each ID of
\mathcal{P}
with
a subset of atomic propositions.
We extend the domain of
\Lambda
to

(\mathit{ID}_{\mathcal{P}})^{\infty}
in the usual way;
i.e.,

\Lambda(c_{0}c_{1}\ldots)=\Lambda(c_{0})\Lambda(c_{1})\ldots
.

Definition 7

The
LTL model checking problem
for RPDS is defined
as:

Instance:

a
k
-RPDS
\mathcal{P}=(P,\Delta)
,
an LTL formula
\varphi
over
\mathit{At}
,
a valuation
\Lambda:\mathit{ID}_{\mathcal{P}}\to\Sigma
,
and an ID
c_{0}\in\mathit{ID}_{\mathcal{P}}
.

Question:

Does every run

\rho\in(\mathit{ID}_{\mathcal{P}})^{\omega}
of
\mathcal{P}

with
\rho(0)=c_{0}

5
Freshness property

The method proposed in this paper requires that
the transition relation
\Rightarrow_{\mathcal{P}}
of every
k
-RPDS
(including
k
-RA)

\mathcal{P}

should have
the
freshness property
stated as follows:
If
(p,\theta,du)\Rightarrow_{\mathcal{P}}(q,\theta^{\prime},u^{\prime})

by a rule
r

and the updated assignment
\theta^{\prime}
contains
a data value
d^{\prime}
not in
\theta\cup\{d\}
,
then
d^{\prime}
must be “fresh”; i.e.,

d^{\prime}
should have never appeared in the computation
from a starting configuration to
(p,\theta,du)
.
Since the set
D
of data values is infinite,
such a fresh data value
d^{\prime}
always exists
whenever the rule
r
can be applied to
(p,\theta,du)
above.

To define the freshness property formally,
we slightly modify the semantics of
k
-RPDS so that
each stack cell keeps
the assignment at the time when the cell is pushed into the stack.
The assignments “saved” in the stack are used only for
choosing a fresh data value and do not affect
the behavior of an RPDS in other ways.
We redefine the set
\mathit{ID}_{\mathcal{P}}
of IDs of
a
k
-RPDS
\mathcal{P}=(P,\Delta)
as

\mathit{ID}_{\mathcal{P}}=P\times\Theta_{k}\times(D\times\Theta_{k})^{*}

and the transition relation
\Rightarrow_{\mathcal{P}}
as follows:

\begin{array}[]{l}(p,\phi)\to(q,\mathit{com})\in\Delta\quad(\theta,d,\theta^{\prime})\models\phi\\
\texttt{frsp}(\theta^{\prime};d,\theta;\theta^{\prime\prime}\texttt{snd}(u))\\
\hline\cr(p,\theta,(d,\theta^{\prime\prime})u)\Rightarrow_{\mathcal{P}}(q,\theta^{\prime},\texttt{upds}((d,\theta^{\prime\prime})u,\theta^{\prime},\mathit{com}))\end{array}

where

\texttt{upds}((d,\theta^{\prime\prime})u,\theta^{\prime},\mathit{com})=u
,
(d,\theta^{\prime\prime})u
,
or
(\theta^{\prime}(j),\theta^{\prime})(d,\theta^{\prime\prime})u

if
\mathit{com}=\texttt{pop}
,
skip
, or
\texttt{push}(j)
, respectively,
and

\texttt{frsp}(\theta^{\prime};d,\theta;\theta_{n}\ldots\theta_{1})

is a predicate
that is true iff
for each
i\in[k]
,

\theta^{\prime}(i)\in\theta\cup\{d\}
or

\theta^{\prime}(i)\notin\theta_{1}\cup\ldots\cup\theta_{n}
.
That is,
each value
\theta^{\prime}(i)
in the updated assignment
is either
the value
\theta(l)
of some register,
the value
d
at the stack top,
or a fresh value that has not appeared in
\theta_{n}\ldots\theta_{1}
.

We say an ID

(p,\theta_{n},(d_{n-1},\theta_{n-1})\allowbreak\ldots(d_{1},\theta_{1}))\in\mathit{ID}_{\mathcal{P}}

is
proper
if
for
\forall i,j,l\in[n]
with
i<j\leq l
,

d_{i},\theta_{i},\theta_{j},\theta_{l}
satisfy

d_{i}\in\theta_{i}
and

\bigl(\forall m\in[k]:\theta_{i}(m)\notin\theta_{j}
implies
\theta_{i}(m)\notin\theta_{l}\bigr)
and
\bigl(d_{i}\notin\theta_{j}
implies
d_{i}\notin\theta_{l}\bigr)
.
Under the assumption of the freshness property,
every ID reachable from a proper starting ID is also proper.
We assume the starting ID
c_{0}
given to the model checking problem
is proper.

Note that
RA with the freshness property is similar to
session automata (SA)
[
16
]
, which is a special case
of fresh-register automata (FRA)
[
17
]
.
An SA has the same structure as RA
but requires an input data value
to be either a value stored in some register or
a value not used before.
On the other hand,
RA in this paper can update
registers with data values not given as input
but chosen arbitrary from values satisfying a guard condition,
and the freshness constraint is imposed only on values not given as input.

6.1
Bisimulation relation between an RPDS and a PDS

The bisimulation equivalence
[
12
]
is a basic notion
to capture the equivalence of behaviors of
two state transition systems.
We review the definition of
the notion in this subsection.
We will show the construction of
a PDS bisimulation equivalent to a given RPDS
in Section

.

Definition 9

For an RPDS
\mathcal{P}=(P,\Delta)
and a PDS
\mathcal{P}^{\prime}=(P^{\prime},\Delta^{\prime})
,
we call a relation
R\subseteq\mathit{ID}_{\mathcal{P}}\times\mathit{ID}_{\mathcal{P}^{\prime}}

a
bisimulation relation
between
\mathcal{P}
and
\mathcal{P}^{\prime}

if
R
satisfies the following:

(1)

For every
c_{1},c_{2}\in\mathit{ID}_{\mathcal{P}}
and
c^{\prime}_{1}\in\mathit{ID}_{\mathcal{P}^{\prime}}
,
if
c_{1}\Rightarrow_{\mathcal{P}}c_{2}
and
(c_{1},c^{\prime}_{1})\in R
,
then
\exists c^{\prime}_{2}\in\mathit{ID}_{\mathcal{P}^{\prime}}:c^{\prime}_{1}\Rightarrow_{\mathcal{P}^{\prime}}c^{\prime}_{2}

and
(c_{2},c^{\prime}_{2})\in R
.

(2)

For every
c_{1}\in\mathit{ID}_{\mathcal{P}}
and
c^{\prime}_{1},c^{\prime}_{2}\in\mathit{ID}_{\mathcal{P}^{\prime}}
,
if
c^{\prime}_{1}\Rightarrow_{\mathcal{P}^{\prime}}c^{\prime}_{2}
and
(c_{1},c^{\prime}_{1})\in R
,
then
\exists c_{2}\in\mathit{ID}_{\mathcal{P}}:c_{1}\Rightarrow_{\mathcal{P}}c_{2}

and
(c_{2},c^{\prime}_{2})\in R
.

For an RA
\mathcal{A}=(Q,I,\xi,\delta)
and an NFA
\mathcal{A}^{\prime}=(Q^{\prime},I^{\prime},F,\delta^{\prime})
,
we call a relation
R\subseteq\mathit{ID}_{\!\mathcal{A}}\times\mathit{ID}_{\!\mathcal{A}^{\prime}}

a bisimulation relation between
\mathcal{A}
and
\mathcal{A}^{\prime}

if
R
is a bisimulation relation between

(Q,\delta)
and
(Q^{\prime},\delta^{\prime})
and
also satisfies:

(3)

If
(c,c^{\prime})\in R
,
then
c\in\mathit{Acc}_{\mathcal{A}}
iff
c^{\prime}=(q,\varepsilon)
and
q\in F
.

An RPDS
\mathcal{P}
and a PDS
\mathcal{P}^{\prime}

(or an RA
\mathcal{A}
and an NFA
\mathcal{A}^{\prime}
)
are
bisimulation equivalent

if there is a bisimulation relation between them.

By definition, we obtain the following propositions.

Proposition 2

If there is a bisimulation relation
R
between
an RA
\mathcal{A}
and an NFA
\mathcal{A}^{\prime}
,
then
for any pair
(c,c^{\prime})\in R
,

c\in L(\mathcal{A})
iff
c^{\prime}\in L(\mathcal{A}^{\prime})
.

Proposition 3

Let
\mathcal{P}
be an RPDS and
\mathcal{P}^{\prime}
be a PDS.
Let
\Lambda:\mathit{ID}_{\mathcal{P}}\to\Sigma
and

\Lambda^{\prime}:\mathit{ID}_{\mathcal{P}^{\prime}}\to\Sigma
be their valuations
and
c_{0}\in\mathit{ID}_{\mathcal{P}}
and
c^{\prime}_{0}\in\mathit{ID}_{\mathcal{P}^{\prime}}
be
their IDs.
If there is a bisimulation relation
R

between
\mathcal{P}
and
\mathcal{P}^{\prime}
such that

(c_{0},c^{\prime}_{0})\in R
and

\Lambda(c)=\Lambda^{\prime}(c^{\prime})

for every
pair
(c,c^{\prime})\in R
, then:

(i)

For every run
\rho
of
\mathcal{P}

with
\rho(0)=c_{0}
,
there exists a run
\rho^{\prime}
of
\mathcal{P}^{\prime}

with
\rho^{\prime}(0)=c^{\prime}_{0}
such that

\Lambda(\rho)=\Lambda^{\prime}(\rho^{\prime})
.

(ii)

For every run
\rho^{\prime}
of
\mathcal{P}^{\prime}

with
\rho^{\prime}(0)=c^{\prime}_{0}

there exists a run
\rho
of
\mathcal{P}

6.3
Construction of PDS simulating RPDS

For a
k
-RPDS
\mathcal{P}=(P,\Delta)
,
we construct a PDS
\mathcal{P}^{\prime}=(P^{\prime},\Delta^{\prime})

bisimulation equivalent to
\mathcal{P}
.
The set of states of
\mathcal{P}^{\prime}
is

P^{\prime}=P\times\Phi_{k}
,
and the stack alphabet of
\mathcal{P}^{\prime}
is
\Phi_{k}
.

\mathcal{P}^{\prime}
must simulate
\mathcal{P}
without keeping data values in the stack.
When popping off the stack top,

\mathcal{P}^{\prime}
must know whether or not the data value
in the new stack top of
\mathcal{P}
equals the
current

value of each register.
For this purpose,
\mathcal{P}^{\prime}
keeps an abstract “history”
of the register assignments
represented by a sequence of equivalence relations
in the stack,
which tells whether each of the data values
in the stack of
\mathcal{P}
equals the current value of each register.
The second component of each state of
\mathcal{P}^{\prime}

is “the last element” of the abstract history,
which represents the accumulated updates
since the current stack top has been pushed into the stack.
Because a PDS cannot replace the symbol at the new stack top
when
pop
or
skip
is performed,

\mathcal{P}^{\prime}
keeps the last element of the history in its finite state
and updates it in every transition.

For example, configuration

(q,\theta_{2},(d_{1},\theta_{1})(d_{0},\theta_{0}))

of
\mathcal{P}
is simulated by configuration

((q,\phi_{2}),\phi_{1}\phi_{0})
of
\mathcal{P}^{\prime}
,
where
(\theta_{0},d_{0},\theta_{1})\models\phi_{1}
and

(\theta_{1},d_{1},\theta_{2})\models\phi_{2}
.
Equivalence relation
\phi_{1}
abstractly represents
the updates of assignments between
when
d_{0}
has been pushed and when
d_{1}
has been pushed.
Similarly,

\phi_{2}
represents
the updates of assignments since

d_{1}
has been pushed.

The set
\Delta^{\prime}
of transition rules of
\mathcal{P}^{\prime}
is
the smallest set satisfying
the following inference rules.

\displaystyle\begin{array}[]{l}(q,\phi_{3})\to(q^{\prime},\texttt{skip})\in\Delta\quad\phi_{1}\odot\phi_{2}\quad\phi_{2}\odot_{\mathtt{T}}\phi_{3}\\
\hline\cr((q,\phi_{2}),\phi_{1})\to((q^{\prime},\phi_{2}\circ_{\mathtt{T}}\phi_{3}),\texttt{skip})\in\Delta^{\prime}\end{array}

\displaystyle\begin{array}[]{l}(q,\phi_{3})\to(q^{\prime},\texttt{pop})\in\Delta\quad\phi_{1}\odot\phi_{2}\quad\phi_{2}\odot_{\mathtt{T}}\phi_{3}\\
\hline\cr((q,\phi_{2}),\phi_{1})\to((q^{\prime},\phi_{1}\circ(\phi_{2}\circ_{\mathtt{T}}\phi_{3})),\texttt{pop})\in\Delta^{\prime}\end{array}

\displaystyle\begin{array}[]{l}(q,\phi_{3})\to(q^{\prime},\texttt{push}(j))\in\Delta\quad\phi_{1}\odot\phi_{2}\quad\phi_{2}\odot_{\mathtt{T}}\phi_{3}\\
\hline\cr((q,\phi_{2}),\phi_{1})\to((q^{\prime},({\phi_{3}})^{=}_{j}),\texttt{push}(\phi_{2}\circ_{\mathtt{T}}\phi_{3}))\in\Delta^{\prime}\end{array}

In the above inference rules,
\phi_{2}\circ_{\mathtt{T}}\phi_{3}

represents the accumulation of the update of registers
by
\phi_{3}
into
\phi_{2}
.
When
pop
is performed,

\phi_{1}
at the stack top is composed into

\phi_{2}\circ_{\mathtt{T}}\phi_{3}
,
which then represents the accumulated updates
since the new stack top has been pushed into the stack.
When
push
is performed,

\phi_{2}\circ_{\mathtt{T}}\phi_{3}
is pushed into the stack because
the current assignment is “the assignment when the stack top was pushed
into the stack.”
In this case,
\mathcal{P}^{\prime}
sets the second component of the state
to
({\phi_{3}})^{=}_{j}
,
which represents the current assignment
(which is the result of the update by
\phi_{3}
)
equals the assignment saved in the stack top.

In the same way,
we construct an NFA
\mathcal{A}^{\prime}_{A}
, as a PDS with pop rules only,
from
\mathcal{A}_{A}=(Q_{A},P,\allowbreak\xi_{A},\delta_{A})
for each
A\in\mathit{At}
.
Moreover, let the set of initial states and the set of final states
of
\mathcal{A}^{\prime}_{A}
be

P\times\Phi_{k}
and

\{(p,\phi)\mid(p,\texttt{lat}(\phi))\in\xi_{A}\}
,
respectively, for each
A\in\mathit{At}
.
Let
\mathit{ID}_{\!\mathcal{A}}=\bigcup_{A\in\mathit{At}}\mathit{ID}_{\!\mathcal{A}_{A}}

and
\mathit{ID}_{\!\mathcal{A}^{\prime}}=\bigcup_{A\in\mathit{At}}\mathit{ID}_{\!\mathcal{A}^{\prime}_{A}}
.

We assume that the stack
u_{0}
in
the given starting ID

c_{0}=(p_{0},\theta^{\prime}_{0},u_{0})
is not empty,
and let
(d_{0},\theta_{0})
be the last (bottom-most) element of
u_{0}
.
Note that the last element of the stack of

every
ID reachable from
c_{0}
equals
(d_{0},\theta_{0})
,
because an ID with empty stack has no successor
and thus any computation cannot alter the stack bottom.

Let
R\subseteq\mathit{ID}_{\!\mathcal{A}}\times\mathit{ID}_{\!\mathcal{A}^{\prime}}

be the smallest relation satisfying the following:

7
Conclusion

This paper proposed a method for
solving the LTL model checking problem for RPDS
with regular valuations,
in which the problem is reduced to the same problem for PDS.
In contrast to the method for the same problem
proposed in
[
11
]
,
the method in this paper does not require
RA used for a regular valuation to be
deterministic or backward-deterministic.
On the other hand, the method in this paper requires
every RPDS and RA has the freshness property instead.
This paper also showed that
the LTL model checking problem for RPDS with regular valuations
defined by general RA is undecidable,
and thus the freshness constraint is essential in this method.
