A Note on the Subcubes of the n-Cube
Hans Ulrich Simon

Abstract
In the year 1990, Béla Bollobás, Imre Leader and Andrew Radcliffe considered the following combinatorial problem: given three parameters k k , n n and q q , find a set of k k vertices in the binary n n -cube which contains a maximal number of q q -dimensional subcubes. 1 1 1 They also discussed the analogous problem for the grid [ ℓ ] n [\ell]^{n} at place of the binary n n -cube. It was shown that an optimal solution is given by the k k vertices which coincide with the binary representations of the number 0 , 1 , … , k − 1 0,1,\ldots,k-1 . Two proofs were presented. The proof given in [ 2 ] is particularly elegant and short. Here we show that also the other proof, the one given in [ 3 ] , becomes quite simple and short when it is combined with a lemma from Graham whose publication dates back to 1970 [ 4 ] . As a second application of Graham’s lemma, we solve a recursive equation (related to the optimization problem that we discussed before) that might be considered interesting in its own right.

For each pair

, where
[a:b]=\emptyset
if
a>b
.
Instead of
[1:b]
, we simply write
[b]
. Sets of the form

will be called

.

As usual, the
n
-cube is the graph with vertex set
B_{n}=\{0,1\}^{n}

and an edge between vertices
u
and
v
iff
u
and
v
differ
in exactly one bit. We denote by
\bin(i)\in B_{n}
with
i\in[0:2^{n}-1]

the binary representation of
i
(with leading zeros so as to
make it an
n

we denote by

the number of ones in
\bin(i)
and define

by setting
h_{q}(i)=\binom{h(i)}{q}
.

For each
r\in[0:n-1]
, the
n
-cube
B_{n}
decomposes into
the
(n-1)
-cubes

B_{n}(r,0)=\{x\in B_{n}:x_{r}=0\}\ \mbox{ and }\ B_{n}(r,1)=\{x\in B_{n}:x_{r}=1\}\kern 5.0pt.

More generally, a set
S\subseteq B_{n}
decomposes into

S(r,0)=\{x\in S:x_{r}=0\}\ \mbox{ and }\ S(r,1)=\{x\in S:x_{r}=1\}\kern 5.0pt.

A
q
-dimensional subcube of
B_{n}
is a subset
of
B_{n}
that is of the form

\{x\in B_{n}:\mbox{$x_{i}=b(i)$ for all $i\in Q$}\}\kern 5.0pt,

where
Q\subseteq[0:n-1]
is a set of size
n-q
and

is a function which assigns a bit pattern to the elements of
Q
.
Note that
B_{n}
is an
n
-dimensional subcube of itself.
B_{n}(r,0)

and
B_{n}(r,1)
are
(n-1)
-dimensional subcubes of
B_{n}
. The edges
(resp. the vertices) in
B_{n}
are the
1
-dimensional
(resp.
0
-dimensional) subcubes.

Throughout the paper, we will view the vertices of
B_{n}
as
binary representations of the numbers from
0
to
2^{n}-1
.
For this reason, we think of the components of
x\in B_{n}

as being indexed from
n-1
downto
0
,
i.e.,
x=(x_{n-1},\ldots,x_{1},x_{0})
and
\sum_{i=0}^{n-1}x_{i}2^{i}

is the number represented by
x
.

2
Maximal Number of Subcubes Contained in k-Sets

Here is the formal definition of the problem we are considering:

Given

the parameters
n\geq 1
,
0\leq q\leq n

and
1\leq k\leq 2^{n}
,

find

a set
S\subseteq B_{n}
of size
k
which contains
a maximal number of
q
-dimensional subcubes.

We refer to this problem as problem
P_{q}(k,n)
.
The number of
q
-dimensional subcubes contained in
S
is
denoted by
m_{q}(S)
. The number of
q
-dimensional subcubes
contained in an optimal solution for problem
P_{q}(k,n)
is
denoted
m_{q}(k,n)
,
i.e.,
m_{q}(k,n)=\max\{m_{q}(S):S\subseteq B_{n},|S|=k\}
.

Example 2.1

(Trivial Observations)
.

The problem
P_{q}(k,n)
is trivial if
k<2^{q}
, if
q=0
,
or if
k\in\{1,2^{n}\}
. If
k<2^{q}
, then
m_{q}(k,n)=0

because no set of a size less than
2^{q}
can possibly contain
a
q
-dimensional subcube. The
0
-dimensional subcubes are
the vertices of the
n
-cube, i.e., the elements of
B_{n}
.
Hence any set
S\subseteq B_{n}
of size
k
contains
k

0
-dimensional
subcubes so that
m_{0}(k,n)=k
. For obvious reasons,
setting
k=1
or
k=2^{n}
also trivializes the problem.

The smallest value of
q
leading to nontrivial problems
P_{q}(k,n)

is the value
1
.
P_{1}(k,n)
is the problem of finding
a set
S\subseteq B_{n}
of size
k
which contains the largest possible
number of edges (=
1
-dimensional subcubes) of the
n
-cube.
This problem was posed and solved by Sergiu Hart
[
5
]
.
He showed that the set
S^{*}_{k,n}:=\{\bin{0},\bin(1),\ldots,\bin(k-1)\}

is an optimal solution of the problem
P_{1}(k,n)
.
2
2

2

The main
result in
[
5
]
is somewhat more general. Hart defines
so-called “good
k
-subsets” of
B_{n}
and shows that any good
set is an optimal solution.
Note that the set
S^{*}_{k,n}
has
a dependence on
n
(albeit a weak one), because the elements
of
S^{*}_{k,n}
are elements in
B_{n}
(
n
-bit vectors).

As already observed in
[
3
]
, the number of
q
-dimensional
subcubes contained in
S^{*}_{k,n}
is easy to determine:

m_{q}(S^{*}_{k,n})=\sum_{j=0}^{k-1}h_{q}(j)\kern 5.0pt.

As shown in
[
3
,
2
]
, no set
S\subseteq B_{n}
of size
k

can contain more than
m_{q}(S^{*}_{k,n})
many
q
-dimensional subcubes.
In other words: the same set
S^{*}_{k,n}
that is the optimal solution
of the problem
P_{1}(k,n)
is also an optimal solution of
the problem
P_{q}(k,n)
regardless of how
q
is chosen. The proof
given in
[
2
]
is particularly elegant and short. The authors
define so-called “
i
-compressions” (
i=0,1,\ldots,n-1
) which operate
on sets
S\subseteq B_{n}
of size
k
. It is shown inductively that
an
i
-compression of
S
does not contain less
q
-dimensional subcubes
than
S
itself. Hence an optimal choice can always be made among
the sets
S
which are fully compressed in the sense that each

i
-compression maps
S
to itself. The definition of
i
-compressions
in
[
2
]
implies that the set
S_{k,n}^{*}
is fully compressed.
Moreover, as also shown in
[
2
]
,
S_{k,n}^{*}
is the best
choice among all fully compressed sets and therefore an optimal
solution for
P_{q}(k,n)
. For details, see
[
2
]
.

The proof given in
[
3
]
is comparably lengthy.
But, as we will show in the next section, this proof can be
considerably simplified when another result, Graham’s lemma
from
[
4
]
, is brought into play.

3
A Proof Based on Special Bijections

Definition 3.1

(Special Bijections)
.

Let
I=[i_{0}:i_{0}+s-1]
and
J=[j_{0}:j_{0}+s-1]
with
j_{0}>i_{0}

be two sub-intervals of
[0:2^{n}-1]
, each of size
s
.
A bijection
P:I\rightarrow J
is said to be
special
if
h(i)\leq h(P(i))

for each
i\in I
and, in addition, all these inequalities are strict in
case that
I
and
J
are non-overlapping (i.e., in case that
i_{0}+s-1<j_{0}
).

We will make use of the following result (dating back to the year 1970):

Lemma 3.2

(
[
4
,
6
]
)
.

Let
I=[i_{0}:i_{0}+s-1]
and
J=[j_{0}:j_{0}+s-1]
with
j_{0}>i_{0}

be two sub-intervals of
[0:2^{n}-1]
, each of size
s
. If
i_{0}=0
,
then there exists a special bijection
P:I\rightarrow J
.

Here are some easy-to-prove facts regarding special bijections:

Lemma 3.3
.

Let
I=[i_{0}:i_{0}+s-1]
and
J=[j_{0}:j_{0}+s-1]
with
j_{0}>i_{0}

be sub-intervals of
[0:2^{n}-1]
which allow for a special bijection.
Let
g:\mathbbm{N}_{0}\rightarrow\mathbbm{R}
be a non-decreasing function. Then the following
hold:

1.

\sum_{i\in I}g(h(i))\leq\sum_{j\in J}g(h(j))
.

2.

If
I
and
J
are non-overlapping and
g
is strictly increasing,
then
\sum_{i\in I}g(h(i))<\sum_{j\in J}g(h(j))
.

3.

For each
0\leq q\leq n
, let
h_{q}:[0:2^{n}-1]\rightarrow\mathbbm{N}_{0}
be the function
given by
h_{q}(i)=\binom{h(i)}{q}
. Suppose that
I
and
J
are
non-overlapping. Then, for all
1\leq q\leq n
,
we have that
\sum_{i\in I}(h_{q}(i)+h_{q-1}(i))\leq\sum_{j\in J}h_{q}(j)
.

Proof.

Let
P:I\rightarrow J
be a special bijection, i.e.,
h(i)\leq h(P(i))

for each
i\in I
and all of these inequalities are strict in case
that
I
and
J
are non-overlapping. Since
g
is non-decreasing,
it follows that

\sum_{i\in I}g(h(i))\leq\sum_{i\in I}g(h(P(i)))=\sum_{j\in J}g(h(j))

and the inequality between the first two terms will be strict
if
I
and
J
are non-overlapping and
g
is strictly increasing.
This proves the first two statements of the lemma. The following
calculation shows the correctness of the third statement:

\displaystyle\sum_{i\in I}(h_{q}(i)+h_{q-1}(i))

\displaystyle=

\displaystyle\sum_{i\in I}\left(\binom{h(i)}{q}+\binom{h(i)}{q-1}\right)=\sum_{i\in I}\binom{h(i)+1}{q}

\displaystyle\leq

\displaystyle\sum_{i\in I}\binom{h(P(i))}{q}=\sum_{j\in J}\binom{h(j)}{q}=\sum_{j\in J}h_{q}(j)\kern 5.0pt.

The inequality in this calculation holds for two reasons.
First, the third statement of the lemma makes the assumption
that
I
and
J
are non-overlapping. Hence
h(i)+1\leq h(P(i))

for each
i\in I
. Second, the function
m\mapsto\binom{m}{q}

is non-decreasing. These observations complete the proof.
∎

The following theorem establishes
S^{*}_{k,n}
as an optimal
solution for the problem
P_{q}(k,n)
. The proof that we present
below essentially coincides with the easy part of the proof
from
[
3
]
. The hard part of that proof will be simply
replaced by a cross-reference to Lemmas
3.2

and
3.3
.

Theorem 3.4

(
[
3
,
2
]
)
.

For any choice of
n\geq 1
,
1\leq k\leq 2^{n}
and
0\leq q\leq n
,
let
P_{q}(k,n)
be the problem of finding a set
S\subseteq B_{n}
of size
k

that contains the largest possible number of
q
-dimensional subcubes.
For this problem, the set
S^{*}_{k,n}=\{\bin(0),\bin(1),\ldots,\bin(k-1)\}

with
m_{q}(S^{*}_{k,n})=\sum_{j=0}^{k-1}h_{q}(j)
is an optimal solution.

Proof.

The proof proceeds by induction on
k
. As the result is trivial
for
k=1
, one may assume that
k\geq 2
. Let
S\subseteq B_{n}
be any set
consisting of
k
vertices in
B_{n}
. Choose an index
r\in[0:n-1]

such that the set
S
has non-empty intersections with both of the
subcubes
B_{n}(r,0)
and
B_{n}(r,1)
so that the sets
S(r,0)

and
S(r,1)
are both non-empty. Set
k_{0}:=|S(r,0)|

and
k_{1}=|S(r,1)|
. For reasons of symmetry, one may assume
that
k_{1}\leq k_{0}
. With these notations, the following hold:

\displaystyle m_{q}(S)

\displaystyle\leq

\displaystyle m_{q}(S(r,0))+m_{q}(S(r,1))+m_{q-1}(S(r,1))

\displaystyle\leq

\displaystyle\sum_{j=0}^{k_{0}-1}h_{q}(j)+\sum_{i=0}^{k_{1}-1}(h_{q}(i)+h_{q-1}(i))

\displaystyle=

\displaystyle\sum_{j=0}^{k-1}h_{q}(j)-\sum_{j=k_{0}}^{k-1}h_{q}(j)+\sum_{i=0}^{k_{1}-1}(h_{q}(i)+h_{q-1}(i))

\displaystyle\stackrel{{\scriptstyle(*)}}{{\leq}}

\displaystyle\sum_{j=0}^{k-1}h_{q}(j)=m_{q}(S^{*}_{k,n})\kern 5.0pt.

The first inequality holds because each
q
-dimensional subcube
that is contained in
S
is either contained in
S(r,0)
, or contained
in
S(r,1)
, or composed of a
(q-1)
-dimensional subcube in
S(r,1)

and a corresponding
(q-1)
-dimensional subcube in
S(r,0)
. The second
inequality results from an application of the inductive hypothesis.
The final inequality (marked
(*)
) is the non-trivial one. It is
proven in
[
3
]
by a series of technical results. But note
that this inequality is immediate from Lemma
3.2
and the
third assertion in Lemma
3.3
. The latter
assertion applies because the intervals
I=[0:k_{1}-1]
and
J=[k_{0}:k-1]

are non-overlapping. Hence the proof of Theorem
3.4

is complete.
∎

For
r\in[n]
and
b\in\{0,1\}
such that
1\leq|S(r,b)|\leq|S(r,1-b)|
,
we refer to

m_{q}(S)\leq m_{q}(S(r,1-b))+m_{q}(S(r,b))+m_{q-1}(S(r,b))

(1)

as the
three-term decomposition of
m_{q}(S)
along dimension
r
.
The decomposition is said to be
exact
if (
1
)
holds with equality.

4
A Recursion Involving a Max-Expression

Here comes one more application of Lemmas
3.2

and
3.3
:

Lemma 4.1
.

For
1\leq k\leq 2^{n}
and
1\leq q\leq n
, consider the following
inductive definition of a function
F_{q}(k)
:

\displaystyle F_{q}(1)

\displaystyle=

\displaystyle 0\kern 5.0pt.

\displaystyle F_{q}(k)

\displaystyle=

\displaystyle\max_{1\leq k^{\prime}\leq k/2}\left(F_{q}(k^{\prime})+F_{q}(k-k^{\prime})+F_{q-1}(k^{\prime})\right)\kern 5.0pt.

Then

F_{q}(k)=\sum_{i=0}^{k-1}h_{q}(i)\kern 5.0pt.

(2)

Proof.

We first observe that an inequality of the form
i<2^{\ell}
implies
that
h(2^{\ell}+i)=1+h(i)
and therefore

h_{q}(2^{\ell}+i)=\binom{h(2^{\ell}+i)}{q}=\binom{1+h(i)}{q}=\binom{h(i)}{q}+\binom{h(i)}{q-1}=h_{q}(i)+h_{q-1}(i)\kern 5.0pt.

(3)

The proof of equation (
2
) will proceed by induction
over
k
. Clearly
F_{q}(1)=0=\binom{0}{q}=h_{q}(0)
.
Hence (
2
) holds for
k=1
.
For
k\geq 2
, choose
r
such that
2^{r}<k\leq 2^{r+1}
.
The inequality
F_{q}(k)\geq\sum_{i=0}^{k-1}h_{q}(i)

can be obtained as follows:

\displaystyle F_{q}(k)

\displaystyle\geq

\displaystyle F_{q}(k-2^{r})+F_{q}(2^{r})+F_{q-1}(k-2^{r})

\displaystyle=

\displaystyle\sum_{i=0}^{k-2^{r}-1}(h_{q}(i)+h_{q-1}(i))+\sum_{i=0}^{2^{r}-1}h_{q}(i)

\displaystyle=

\displaystyle\sum_{i=2^{r}}^{k-1}h_{q}(i)+\sum_{i=0}^{2^{r}-1}h_{q}(i)=\sum_{i=0}^{k-1}h_{q}(i)\kern 5.0pt.

The first equation in this calculation is true by the inductive hypothesis.
Furthermore, since
k\leq 2^{r+1}
, we have that
k-2^{r}-1<2^{r}
.
Hence equation (
3
) applies and we obtain the second equation
in the above calculation.

Choose now
1\leq k^{\prime}\leq k/2

such that
F_{q}(k)=F_{q}(k^{\prime})+F_{q}(k-k^{\prime})+F_{q-1}(k^{\prime})
.
We still have to show that
F_{q}(k)\leq\sum_{i=0}^{k-1}h_{q}(i)
.
By another application of the inductive hypothesis, we see that
it is sufficient to show that

\sum_{i=0}^{k^{\prime}-1}(h_{q}(i)+h_{q-1}(i))\leq\sum_{j=0}^{k-1}h_{q}(j)-\sum_{j=0}^{k-k^{\prime}-1}h_{q}(j)=\sum_{j=k-k^{\prime}}^{k-1}h_{q}(j)\kern 5.0pt.

(4)

Thanks to
k^{\prime}\leq k/2
, the intervals
I:=[0:k^{\prime}-1]

and
J:=[k-k^{\prime}:k-1]
are non-overlapping. It follows from
Lemma
3.3
that
(I,J)
admits a
special bijection. An inspection of the third statement in
Lemma
3.2
reveals that (
4
)
is valid.
∎

Comparing the recursive definition of
F_{q}(k)
in
Lemma
4.1
with the three-term decomposition of
m_{q}(S)
,
it becomes evident that
F_{q}(k)\geq m_{q}(S)
holds for all sets
S\subseteq B_{n}

of size
k
. Since
F_{q}(k)=\sum_{j=0}^{k-1}h_{q}(j)=m_{q}(S^{*}_{k,n})
,
Lemma
4.1
gives us another option for proving
the optimality of
S^{*}_{k,n}
. But here we are more interested in
using optimal solutions for problem
P_{q}(k,n)
in order to find
maximizers
1\leq k^{\prime}\leq k/2
of
F_{q}(k^{\prime})+F_{q}(k-k^{\prime})+F_{q-1}(k^{\prime})
.
An inspection of Lemma
4.1
reveals that
a set
S\subseteq B_{n}
of size
k
satisfies the optimality
condition
m_{q}(S)=F_{q}(k)
only if the following hold for each
r\in[n]

such that
S(r,0),S(r,1)\neq\emptyset
:

1.

The three-term decomposition of
m_{q}(S)
along dimension
r
is exact.

2.

The number
k^{\prime}=\min\{|S(r,0)|,|S(r,1)|\}
is a maximizer
of
F_{q}(k^{\prime})+F_{q}(k-k^{\prime})+F_{q-1}(k^{\prime})
subject to
1\leq k^{\prime}\leq k/2
.

As in
[
1
]
, we say that
(k-k_{1},k_{1})
with
1\leq k_{1}\leq k/2

is a
hypercubic partition of
k
if there exists a bit position
r

such that
k_{1}=|S^{*}_{k,n}(r,1)|
. In other words:

k_{1}
of the vertices
\bin(0),\bin(1),\ldots,\bin(k-1)

belong to the subcube
B_{n}(r,1)
and the remaining
k-k_{1}
of them
belong to the subcube
B_{n}(r,0)
. Since
S^{*}_{k,n}

contains
F_{q}(k)
many
q
-dimensional subcubes,
we obtain the following result:

Corollary 4.2
.

Let
F_{q}
be the function from Lemma
4.1
.
Let
(k-k_{1},k_{1})
with
1\leq k_{1}\leq k/2
be a hypercubic partition of
k
.
Then
k^{\prime}=k_{1}
is a maximizer of
F_{q}(k^{\prime})+F_{q}(k-k^{\prime})+F_{q-1}(k^{\prime})

subject to
1\leq k^{\prime}\leq k/2
,
i.e.,
F_{q}(k)=F_{q}(k-k_{1})+F_{q}(k_{1})+F_{q-1}(k_{1})
.

For instance,
(\lceil k/2\rceil,\lfloor k/2\rfloor)
is
a hypercubic partition of
k
as witnesses by
j=0
(the position
of the least significant bit). If
r
satisfies
2^{r}<k\leq 2^{r+1}
,
then
(2^{r},k-2^{r})
is a hypercubic partition too. This is witnessed
by choosing
j=r
(the position of the most significant bit).

For the special case
q=1
, it is shown in
[
1
]
that
k^{\prime}=k_{1}

is a maximizer of
F_{1}(k^{\prime})+F_{1}(k-k^{\prime})+k^{\prime}
if and only if
(k-k_{1},k_{1})

is a hypercubic partition of
k
. The “only-if” direction is not
generally true for
q>1
.
