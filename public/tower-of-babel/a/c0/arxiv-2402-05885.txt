Eugene : Explainable Unsupervised Approximation of Graph Edit Distance with Generalized Edit Costs
Aditya Bommakanti, Harshith Reddy Vonteri, Panagiotis Karras, Sayan Ranu

Abstract
The need to identify graphs with small structural distances from a query arises in various domains such as biology, chemistry, recommender systems, and social network analysis. Among several methods for measuring inter-graph distance, Graph Edit Distance (GED) is preferred for its comprehensibility, though its computation is hindered by NP-hardness. Unsupervised methods often face challenges in providing accurate approximations. State-of-the-art GED approximations predominantly utilize neural methods, which, however, have several limitations: (i) They lack an explanatory edit path corresponding to the approximated GED; (ii) They require the NP-hard generation of ground-truth GEDs for training; (iii) They necessitate separate training on each dataset. In this paper, we propose Eugene , an efficient algebraic unsupervised method that approximates GED while providing edit paths corresponding to the approximated cost. Extensive experimental evaluation demonstrates that Eugene achieves state-of-the-art performance in GED estimation and exhibits superior scalability across diverse datasets and generalized cost settings.

Despite superior accuracy compared to unsupervised counterparts, neural approaches suffer from notable drawbacks:

•

Reliance on NP-hard ground

2.1
Mapping GED to Graph Alignment

3.2
Optimization Strategy

While Eq. (
7
) offers a closed-form expression for
Ged
, finding the permutation matrix (equivalently node mapping) that minimizes this expression is notoriously hard, as the space of permutation matrices is not convex. To circumvent this non-tractability, we note that if the unrestricted graph alignment
(Eq. (
3
)) is relaxed over the set of doubly stochastic matrices
\mathbb{W}^{n}
instead of the more restrictive set of permutation matrices, then the optimization problem is convex
(
Bento & Ioannidis 2018
)
. Inspired by this property, we solve generalized graph alignment (Eq. (
7
)), which is equivalent to solving GED, over the domain of double stochastic matrices
\mathbb{W}^{n}
. Formally, the relaxed problem is stated as follows.

\begin{gathered}\min_{P\in\mathbb{W}^{n}}\frac{||\tilde{A}P-P\tilde{B}||_{F}^{2}}{2}+tr(P^{T}D)\\
\text{Constraints: }P\textbf{1}=\textbf{1},P^{T}\textbf{1}=\textbf{1},0\leq P_{ij}\leq 1\end{gathered}

(10)

Eq.
10
is convex, as it aims to minimize a convex function over a convex domain
(
Boyd & Vandenberghe 2004
)
. Hence, it can be solved with Adam
(
Kingma & Ba 2015
)
to obtain the optimal doubly-stochastic matrix. Yet, this matrix does not yield a solution to our problem, which needs to be a permutation matrix. At this juncture, we note the following connection between these two matrix domains.

Lemma 1
.

A doubly-stochastic matrix
A
with
tr(A^{T}(J-A))=0
is a permutation matrix.

Proof.

Given that
tr(A^{T}(J\!-\!A))\!=\!0
, it follows that
\sum_{i}\sum_{j}a_{ij}\cdot(1\!-\!a_{ij})\!=\!0
. Since
A
is doubly-stochastic,
0\leq a_{ij}\leq 1
for all
i
and
j
, hence
a_{ij}\!\cdot\!(1\!-\!a_{ij})
is non-negative for
1\leq i,j\leq n
. Thus,
a_{ij}\!\cdot\!(1\!-\!a_{ij})\!=\!0
for all
i
and
j
. It follows that
a_{ij}
must be either 0 or 1 for each
i
and
j
. As
A
is doubly-stochastic and all its entries are either 0 or 1, by definition
A
is a permutation matrix.
∎

We utilize this connection to add a bias to our objective function in the following form.

\begin{gathered}\min_{P}\!\frac{||\tilde{A}\!P\!-\!P\!\tilde{B}||_{F}^{2}}{2}\!+\!\mu\cdot(tr(P^{T}\!D))+\lambda\cdot(tr(P^{T}\!(J\!-\!P)))\\

3.4
Properties of
Eugene

Interpretable solution:

Eugene
not only outputs the approximated GED, but also the permutation matrix (equivalently node mapping) corresponding to this distance. This enables
Eugene
to also return the edit path from graph
\mathcal{G}_{1}
to
\mathcal{G}_{2}
, which neural approximators do not provide.

Upper bound:
As the true GED is the minimum edit cost over all possible node alignments, the returned GED upper-bounds the true GED. Neural approximators of GED do not provide any guarantees on the error direction.

Unsupervised and CPU-bound executions:
Unlike neural approximators,
Eugene
does not require any training data, which is NP-hard to generate. Furthermore, the entire computation is CPU-bound. This computation pipeline offers more environmentally friendly and computationally lightweight solution for approximating GED.

Efficacy:

Eugene

•

Scalability:

Eugene

Efficiency and Environmental Impact:

Eugene

Cost Settings:
We evaluate the performance of
Eugene
and the baseline methods under three different cost settings:

•

Case 1 (Non-uniform edit costs):
The node insertion cost is 3, node deletion cost is 1, edge insertion and deletion costs are 2, and the node substitution cost is 0.

•

Case 2 (Non-uniform edit costs with substitution):
In addition to the above-mentioned costs, substituting nodes with unequal labels incurs an additional cost. If the substituted node label is the 1-nearest neighbor (1-NN) based on the similarity ranking of node labels, the cost is 1; otherwise, the cost is 2. As an illustrative case, the distance between two labels is taken as the difference between their label IDs.

•

Case 3 (Uniform edit costs):
The node/edge insertion and deletion costs are 1, while node substitution cost is 0.

Metrics:
We use two metrics to assess GED approximation and interpretability:

(i)

Mean Absolute Error (MAE), and

(ii)

Strict Interpretability (SI).

MAE serves as a metric to quantify the closeness of the predicted GED to the true GED. SI is measured as the fraction of graph pairs for which the predicted GED matches the true GED. A match between the predicted and true GED indicates that the alignment produced by the method is optimal. Consequently, SI reflects the algorithm’s ability to produce the optimal node mapping and serves as a measure of interpretability.

5
Conclusions

We introduced
Eugene
, an unsupervised method that provides explainable estimates of GED based on an algebraic representation and relaxation of the resulting optimization. Through extensive comparative analysis, we demonstrated that
Eugene
achieves state-of-the-art performance in GED estimation and offers superior scalability compared to baselines across diverse datasets. Additionally, due to its unsupervised nature,
Eugene
eliminates the need for generating supervisory data via NP-hard computations. These features position
Eugene
as a promising candidate for practical applications in graph similarity measurement. As our implementation relies solely on CPU resources, it is open to further optimization and enhancement.

Impact Statement

This work introduces an efficient algebraic method,
Eugene
, to approximate Graph Edit Distance (GED), a critical problem in domains such as biology, chemistry, recommender systems, and social network analysis. Unlike state-of-the-art neural methods,
Eugene
eliminates the need for computationally expensive ground truth generation and dataset-specific training, making it accessible and scalable for real-world applications. Furthermore, the method produces explanatory edit paths, enhancing interpretability and transparency, which are vital for applications in sensitive domains such as healthcare and social systems.

The broader societal impact of this work is positive, as it promotes computational efficiency and interpretable graph analysis without reliance on resource-intensive or opaque neural methods. We do not foresee any ethical concerns arising out of this work.

A
Related Work

Supervised Methods:

GraphEdx

(
Jain et al. 2024
)
represents each graph as a set of node and edge embeddings and learn the alignments using a Gumbel-Sinkhorn permutation generator, additionally ensuring that the node and edge alignments are consistent with each other.
Greed

(
Ranjan et al. 2022
)
employs a siamese network to generate graph embeddings in parallel and estimates the Graph Edit Distance (GED) by computing the norm of their difference.
Eric

(
Zhuo & Tan 2022
)
eliminates the need for explicit node alignment by leveraging a regularizer and computes similarity using a Neural Tensor Network (NTN) and a Multi-Layer Perceptron (MLP) applied to graph-level embeddings obtained from a Graph Isomorphism Network (GIN).
GMN

(
Li et al. 2019
)
assess graph similarity using Euclidean distance between embeddings and exist in two variants:
Gmn-Embed
(late interaction) and
GMN-Match
(early interaction), both utilizing message passing to capture structural similarities.
SimGNN

(
Bai et al. 2019
)
combines graph-level and node-level embeddings, where a Neural Tensor Network processes graph-level embeddings, while a histogram-based feature vector derived from node similarities enhances the similarity computation.
H2mn

(
Zhang et al. 2021
)
utilizes hypergraphs to model higher-order node similarity, employing a subgraph matching module at each convolution step before aggregating the final graph embeddings via a readout function and passing them through an MLP.
Egsc

(
Qin et al. 2021
)
introduces an Embedding Fusion Network (EFN) within a Graph Isomorphism Network (GIN) to generate unified embeddings for graph pairs, which are further processed through an EFN and an MLP to compute the final similarity score.

Unsupervised Methods:

F1

(
Lerouge et al. 2017
)
,
Adj-Ip

(
Justice & Hero 2006
)
, and
Compact-MIP

(
Blumenthal & Gamper 2020
)
employ a mixed integer programming framework based on the LP-GED paradigm to approximate the GED. In contrast,
Branch-Tight

(
Blumenthal & Gamper 2018
)
iteratively solves instances of the linear sum assignment problem or the minimum-cost perfect bipartite matching problem.

B.7
Efficiency

Table
J
presents the running time of unsupervised methods on the benchmark datasets for the entire test set. Among these methods,
Branch-Tight
demonstrates the fastest runtimes but exhibits the poorest accuracy among all 11 baselines in Table
2
across datasets and cost settings. Excluding
Branch-Tight
,
Eugene
achieves superior runtime performance compared to other unsupervised methods on the Molhiv, Code2, Mutag and IMDB datasets. On the AIDS, COIL-DEL and Triangles datasets,
Adj-Ip
demonstrates better run times, and
Eugene
is second best. Importantly,
Eugene
achieves a significant accuracy advantage while maintaining competitive efficiency, reinforcing its position as both an effective and efficient solution for GED approximation.

Time Complexity Analysis:
The objective function (Eq. (
11
)) includes matrix multiplications with a worst-case time complexity of
\mathcal{O}(n^{3})
. Gradient calculations also have a worst-case complexity of
\mathcal{O}(n^{3})
due to matrix multiplications. Thus, the overall time complexity becomes
\mathcal{O}(T\cdot n^{3})
, where
T
is the number of computation epochs. Additionally, as the algorithm is CPU-bound, GED computations for each graph pair can be massively parallelized by leveraging multi-core CPUs and hyperthreading.
