Correlators of arbitrary untwisted operators and excited twist operators for N N branes at angles.
Igor Pesando

Abstract
We compute the generic correlator with L L untwisted operators and N N (excited) twist fields for branes at angles on T 2 T^{2} and show that it is given by a generalization of the Wick theorem. We give also the recipe to compute efficiently the generic OPE between an untwisted operator and an excited twisted state.



keywords: D-branes, Conformal Field Theory

Introduction and conclusions

Since their introduction, D-branes have been very important in the formal
development of string theory as well as in attempts to apply string
theory to particle phenomenology and cosmology.
However, the requirement of chirality in any physically realistic
model leads to a somewhat restricted number of possible D-brane
set-ups. An important class is intersecting brane models where
chiral fermions can arise at the intersection of two branes at angles.
An important issue for these models is the computation of Yukawa
couplings and flavour changing neutral currents.

Besides the previous computations many other computations
often involve correlators of twist fields and excited
twist fields.
It is therefore important and interesting in its own to be able to
compute these correlators also because it is annoying to be able to
compute, at least theoretically, all possible correlators involving
all kinds of excited spin fields while not being able to do so with
twist fields.

knowledge of the Green function in presence of twist fields and of the

2.1
The local description

Locally at the interaction point

\displaystyle Re(e^{-i\pi\alpha_{t}}X^{\prime}_{loc}|_{\sigma=0})=Im(e^{-i\pi\alpha_{t}}X_{loc}|_{\sigma=0})-g_{t}=0

\displaystyle Re(e^{-i\pi\alpha_{t+1}}X^{\prime}_{loc}|_{\sigma=\pi})=Im(e^{-i\pi\alpha_{t+1}}X_{loc}|_{\sigma=\pi})-g_{t+1}=0

\displaystyle=e^{\int d{x_{a}}\int d{x_{b}}J_{1I}({x_{a}})J_{2J}({x_{b}})G^{IJ}_{N=2,bou}({x_{a}},{x_{b}};\{0,\epsilon;\infty;\bar{\epsilon}\})}:{\cal S}_{T}[J_{1}]{\cal S}_{T}[J_{2}]:

\displaystyle=e^{\int d{x_{a}}\int d{x_{b}}J_{1I}({x_{a}})J_{2J}({x_{b}})G^{IJ}_{U,bou}({x_{a}},{x_{b}})}{\cal S}_{T}[J_{1}+J_{2}]

(67)

where we have added and subtracted

\int d{x_{a}}\int d{x_{b}}J_{1I}({x_{a}})J_{2J}({x_{b}})G^{IJ}_{U,bou}({x_{a}},{x_{b}})

to the exponent in order to complete the prefactor in
eq. (
66
) in the case where
J=J_{1}+J_{2}

and used the symmetry

\Delta^{IJ}{{}_{bou}}({x_{a}},{x_{b}})=\Delta^{JI}{{}_{bou}}({x_{b}},{x_{a}})
.
Having verified that the generating function (
56
) gives
vertices with the same OPEs as the untwisted ones we can exam the
reason which leads to it (
[
25
]
,
[
29
]
,
[
26
]
).
In operatorial formalism the normal ordered vertex
(
64
) for the untwisted case
can be obtained from a regularized non
normal ordered generating function by a multiplicative renormalization as

{\cal S}_{U}[J]=\lim_{\eta\rightarrow 0^{+}}{\cal N}(\eta)~{\cal S}_{U,reg}[J,\eta]

(68)

where the regularized generating function is defined by a point splitting as

{\cal S}_{U,reg}[J,\eta]=e^{\int dx_{a}J_{I}(x_{a})[X^{I(+)}_{U}(x_{a},x_{a})+X^{I(-)}_{U}(x_{a}e^{-\eta},x_{a}e^{-\eta})]}

(69)

without normal ordering and the multiplicative renormalization is
given by the inverse of the factor we get by normal ordering the
regularized generating function

{\cal N}(\eta)=e^{-\frac{1}{2}\int d{x_{a}}\int d{x_{b}}J_{I}({x_{a}})J_{J}({x_{b}})G^{IJ}_{U,bou}({x_{a}},{x_{b}}e^{-\eta})}

(70)

Now the generating function for the twisted string is defined in an
analogous way
by regularizing the non normal ordered generating function
and then renormalizing
in a minimal way using the same renormalization factor as in the
untwisted case (
70
), explicitly

{\cal S}_{T}[J]=\lim_{\eta\rightarrow 0^{+}}{\cal N}(\eta)~{\cal S}_{T,reg}[J,\eta]

(71)

with

{\cal S}_{T,reg}[J,\eta]=e^{\int dx_{a}J_{I}(x_{a})[X^{I(+)}(x_{a},x_{a})+X^{I(-)}(x_{a}e^{-\eta},x_{a}e^{-\eta})]}

(72)

3.4
Getting excited twists

We are interested in excited twist states hence we would now
write a kind of SDS vertex which generates these states
(
35
).
The main observation is then that

\partial_{u_{loc}}^{n-1}\left[{u_{loc}}^{\bar{\epsilon}}\partial_{u_{loc}}X_{loc}({u_{loc}},{{\bar{u}}_{loc}})\right]=(n-1)!~{k_{\epsilon}}\alpha_{n-1+\epsilon}^{\dagger}+O({u_{loc}})

(73)

therefore a normal ordered products of these operators gives directly an
excited twist state, e.g.

\displaystyle\lim_{{u_{loc}}\rightarrow 0}

\displaystyle:\partial_{u_{loc}}^{n-1}\left[{u_{loc}}^{\bar{\epsilon}}\partial_{u_{loc}}X_{loc}({u_{loc}},{{\bar{u}}_{loc}})\right]\partial_{u_{loc}}^{m-1}\left[{u_{loc}}^{\epsilon}\partial_{u_{loc}}{\bar{X}}_{loc}({u_{loc}},{{\bar{u}}_{loc}})\right]:|T\rangle

\displaystyle={k_{\epsilon}}k_{\bar{\epsilon}}(n-1)!(m-1)!\alpha_{n-1+\epsilon}^{\dagger}\bar{\alpha}_{m-1+\epsilon}^{\dagger}|T\rangle=\left(\partial^{n}X\partial^{m}{\bar{X}}\sigma_{\epsilon,f}\right)(0)|0\rangle_{SL(2)}

(74)

The generating function for products of these operators is obviously

\displaystyle{\cal T}(d,\bar{d})=

\displaystyle\lim_{{u_{loc}}\rightarrow 0}:\exp\left\{\sum_{n=1}^{\infty}\left[\bar{d}_{n}\partial_{u_{loc}}^{n-1}\left[{u_{loc}}^{\bar{\epsilon}}\partial_{u_{loc}}X_{loc}({u_{loc}},{{\bar{u}}_{loc}})\right]+d_{n}\partial_{u_{loc}}^{n-1}\left[{u_{loc}}^{\epsilon}\partial_{u_{loc}}{\bar{X}}_{loc}({u_{loc}},{{\bar{u}}_{loc}})\right]\right]\right\}:

(75)

since

\displaystyle\left[\prod_{n=1}^{\infty}\left(\partial^{n}_{u}X\right)^{N_{n}}\left(\partial^{n}_{u}\bar{X}\right)^{\bar{N}_{n}}\sigma_{\epsilon,f}\right](0)|0\rangle_{SL(2)}\leftrightarrow\lim_{{u_{loc}}\rightarrow 0}\left.\prod_{n=1}^{\infty}\frac{\partial^{N_{n}}}{\partial\bar{d}_{n}^{N_{n}}}\frac{\partial^{\bar{N}_{n}}}{\partial d_{n}^{\bar{N}_{n}}}{\cal T}(d,\bar{d})\right|_{\bar{d}=d=0}|T\rangle

(76)

Comparing with eq. (
48
) we realize that there is not the exponent
quadratic in
d
, this means that the abstract operator corresponding
to e.g. eq. (
74
) is not simply

\lim_{u\rightarrow x}\partial_{u}^{n-1}\left[(u-x)^{\bar{\epsilon}}\partial_{u}X\right]\partial_{u}^{m-1}\left[(u-x)^{\epsilon}\partial_{u}{\bar{X}}\right]

but it is

\displaystyle\lim_{u\rightarrow x}\Big(

\displaystyle\partial_{u}^{n-1}\left[(u-x)^{\bar{\epsilon}}\partial_{u}X\right]\partial_{u}^{m-1}\left[(u-x)^{\epsilon}\partial_{u}{\bar{X}}\right]

\displaystyle-\partial_{u}^{n-1}\partial_{v}^{m-1}\left[(u-x)^{\bar{\epsilon}}(v-x)^{\epsilon}\partial_{u}\partial_{v}\Delta^{z{\bar{z}}}_{c}(u-x,{\bar{u}}-x;v-x,{\bar{v}}-x;\epsilon)|_{v=u}\right]\Big)

(77)

in fact computing its OPE with the twist field
\sigma_{\epsilon,f}(x)
as in section
3.1
we get

\displaystyle\Big(\partial_{u}^{n-1}\left[(u-x)^{\bar{\epsilon}}\partial_{u}X\right]\partial_{u}^{m-1}\left[(u-x)^{\epsilon}\partial_{u}{\bar{X}}\right]

\displaystyle-\partial_{u}^{n-1}\partial_{v}^{m-1}\left[(u-x)^{\bar{\epsilon}}(v-x)^{\epsilon}\partial_{u}\partial_{v}\Delta^{z{\bar{z}}}_{c}\right]\Big)\sigma_{\epsilon,f}(x)

\displaystyle\sim\left(\partial^{n}X\partial^{m}{\bar{X}}\sigma_{\epsilon,f}\right)(x)+O(u-x)

(78)

Notice that this OPE explains why we can use
u-x
as argument of

\Delta^{z{\bar{z}}}
and not another function which behaves as

u-x+O(u-x)^{2}
.
We conclude therefore that the generating function for the abstract
operators which give excited twists is given by

\displaystyle{\cal T}_{abs}(d,\bar{d})=

\displaystyle\exp\left\{\sum_{n=1}^{\infty}\left[\bar{d}_{n}\partial_{u}^{n-1}\left[(u-x)^{\bar{\epsilon}}\partial_{u}X(u,{\bar{u}})\right]+d_{n}\partial_{u}^{n-1}\left[(u-x)^{\epsilon}\partial_{u}{\bar{X}}(u,{\bar{u}})\right]\right]\right\}

\displaystyle\exp

\displaystyle\left\{-\sum_{n,m=1}^{\infty}\bar{d}_{n}~d_{m}~\partial^{n-1}_{u}~\partial^{m-1}_{v}|_{v=u}\left[(u-x)^{\bar{\epsilon}}(v-x)^{\epsilon}\partial_{u}\partial_{v}\Delta^{z{\bar{z}}}_{c}(u-x,{\bar{u}}-x;v-x,{\bar{v}}-x;\epsilon)\right]\right\}

(79)

Explicitly this means that

\displaystyle\left[\prod_{n=1}^{\infty}\left(\partial^{n}_{u}X\right)^{N_{n}}\left(\partial^{n}_{u}\bar{X}\right)^{\bar{N}_{n}}\sigma_{\epsilon,f}\right](x)=\lim_{u\rightarrow x}\left.\prod_{n=1}^{\infty}\frac{\partial^{N_{n}}}{\partial\bar{d}_{n}^{N_{n}}}\frac{\partial^{\bar{N}_{n}}}{\partial d_{n}^{\bar{N}_{n}}}{\cal T}_{abs}(d,\bar{d})\right|_{\bar{d}=d=0}\sigma_{\epsilon,f}(x)

(80)

4
The path integral approach

The classic method
[
1
]
to compute twists correlators
is by the path integral

\displaystyle\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle=\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}Xe^{-S_{E}}

(81)

where
{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})
is the space of string configurations
satisfying the boundary conditions (
22
) and
(
21
).
Since the integral is quadratic we can then efficiently
separate the classical fields from the quantum fluctuations as

X(u,\bar{u})=X_{cl}(u,\bar{u};\{x_{t},\epsilon_{t},f_{t}\})+X_{q}(u,\bar{u};\{x_{t},\epsilon_{t}\})

(82)

where
X_{cl}
satisfies the previous boundary conditions
(
20
,
21
)
while
X_{q}

satisfies the same boundary conditions but with all
f_{t}=0
.
After this splitting we obtain

\displaystyle\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle={\cal N}(x_{t},\epsilon_{t})e^{-S_{E,cl}(x_{t},\epsilon_{t},f_{t})}

(83)

where the factor
{\cal N}(x_{t},\epsilon_{t})
is the quantum contribution.
In particular when all
f_{t}
are equal, i.e.
f_{t}=f
the classical action

S_{E,cl}(x_{t},\epsilon_{t},f_{t}=f)
is zero since the branes are the
boundary of a zero area polygon
therefore we can identify

{\cal N}(x_{t},\epsilon_{t})=\langle\sigma_{\epsilon_{1},f_{1}=f}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}=f}(x_{N})\rangle

(84)

which is also true for the quantum fluctuation for which
f=0
.
Our aim is now to compute correlators with both (excited) twist field
operators and untwisted operators
V_{\xi_{i}}(x_{i})
(
i=1\dots L
)
associated with the untwisted state
\xi_{i}
of which the ones in
eq. (
39
) are a particular case.
We start with correlators with plain twist field operators which can
be computed as

\displaystyle\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\prod_{i=1}^{L}V_{\psi_{i}}(x_{i})\rangle=\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}X~\prod_{i=1}^{L}V_{\psi_{i}}(x_{i})~e^{-S_{E}}

(85)

To do so we notice that it is by far easier not to compute the previous
correlator but to compute the generating function of all the
correlators, i.e. the Reggeon vertex, in the form of the previous path integral
(
81
) plus linear sources

\displaystyle V_{N+L}(J_{i})=\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}X~e^{-S_{E}+\sum_{i=1}^{L}\int dx~J_{iI}(x)X^{I}(x,x)}

(86)

where
J_{iI}(x)=\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}\delta(x-x_{i})

since all untwisted operators can be obtained by taking derivatives
with respect to the coefficients
c_{(i)nI}
as explained in the
previous section.
This starting point is very similar to
(
[
30
]
,
[
24
]
) where it was
recognized that the generator for all closed (super)string amplitudes
is a quadratic path integrals.
The idea in the previous papers is that the appropriate boundary
condition for R and/or NS sector can be obtained simply by inserting

linear
sources with the desired boundary conditions.
Because of this assumption the quantum fluctuations are the same for
all the amplitudes: from the purely NS to the mixed ones.
It was later realized that this prescription misses a proper treatment
of quantum fluctuations
[
31
]

and that when this part is considered the
amplitudes factorize correctly
[
8
]
.

4.1
Boundary correlators with non excited twists on
\mathbb{R}^{2}

Our strategy is therefore to compute the path integral
(
86
) by properly defining it in order to
regularize the divergences
which arise as usual because of current self interactions.
Taking inspiration from what is done for deriving the generating
function we first regularize the
\delta
functions in the currents,
a step which corresponds to the point splitting in operatorial formalism
and then subtract the self interaction of the untwisted string.
We are therefore led to consider the path integral

\displaystyle V_{N+L}(J_{i})=\lim_{\{\eta_{i}\}\rightarrow 0}

\displaystyle\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}X~e^{-S_{E}}

\displaystyle\times

\displaystyle\prod_{i=1}^{L}\left[e^{-\frac{1}{2}\int d{x_{a}}\int d{x_{b}}J_{iI}({x_{a}},\eta_{i})J_{iJ}({x_{b}},\eta_{i})G^{IJ}_{U(t_{i}),bou}({x_{a}},{x_{b}})}e^{\int dx~J_{iI}(x,\eta_{i})X^{I}(x,x)}\right]

(87)

where the regularized currents are defined as

J_{iI}(x,\eta_{i})=\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}\delta(x-x_{i};\eta_{i})

(88)

with
\delta(x-x_{i};\eta_{i})
a regularization of the
\delta
such
that
\lim_{\eta_{i}\rightarrow 0}\delta(x-x_{i};\eta_{i})=\delta(x-x_{i})
and

G^{IJ}_{U(t_{i}),bou}({x_{a}},{x_{b}})
is the untwisted Green function
with boundary conditions which depends on the brane on which the point

x_{i}
is. This dependence is the reason why we have written
U(t_{i})
.

It is then immediate to compute the previous path integral
by using the splitting of
X
into quantum and classical part
(
82
) and get

\displaystyle V_{N+L}(J_{i})

\displaystyle=\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{i=1}^{L}e^{\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}X^{I}_{cl}(x_{i},x_{i})}

\displaystyle\times

\displaystyle\prod_{i=1}^{L}e^{\frac{1}{2}\sum_{n=0}^{\infty}c_{(i)nI}\sum_{m=0}^{\infty}c_{(i)mJ}\partial^{n}_{x_{i}}\partial^{m}_{\hat{x}_{i}}\Delta^{IJ}_{(N,M),bou(i)}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})|_{\hat{x}_{i}=x_{i}}}

\displaystyle\times

\displaystyle\prod_{1\leq i<j\leq L}e^{\sum_{n=0}^{\infty}c_{(i)nI}\sum_{m=0}^{\infty}c_{(j)mJ}\partial^{n}_{x_{i}}\partial^{m}_{x_{j}}G^{IJ}_{(N,M),bou}(x_{i},x_{j};\{x_{t},\epsilon_{t}\})}

(89)

where we have introduced the boundary Green function

G^{IJ}_{(N,M),bou}(x_{i},x_{j};\{x_{t},\epsilon_{t}\})=G^{IJ}_{(N,M)}(x_{i}+i0^{+},x_{i}-i0^{+};x_{j}+i0^{+},x_{j}-i0^{+};\{x_{t},\epsilon_{t}\})

(90)

in presence of
N
twist
fields
\sigma_{\epsilon_{t},f_{t}=0}(x_{t})
(with
f_{t}=0
since these
terms come from the quantum fluctuations) in the sector

M=\sum_{t=1}^{N}\epsilon_{t}

and the regularized Green function

\Delta^{IJ}_{(N,M),bou(i)}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})=G^{IJ}_{(N,M),bou}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})-G^{IJ}_{U(t_{i}),bou}(x_{i},\hat{x}_{i})

(91)

As it happened for the
N=2
boundary Green function and its regularized
version all the components of the boundary Green function are
proportional to real symmetric functions
G_{(N,M),bou}(x_{i},x_{j})

and
\Delta_{(N,M),bou(i)}(x_{i},x_{j})
respectively up to phases.
Using the result from the appendix (
D
) where
the explicit expressions for
G_{(N,M),bou}(x_{i},x_{j})

and
\Delta_{(N,M),bou}(x_{i},x_{j})
are given we can
then write

\displaystyle V_{N+L}(J_{i})

\displaystyle=\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{i=1}^{L}e^{\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}X^{I}_{cl}(x_{i},x_{i})}

\displaystyle\times

\displaystyle\prod_{i=1}^{L}e^{\sum_{n=0}^{\infty}c_{(i)n\parallel D_{t_{i}}}\sum_{m=0}^{\infty}c_{(i)m\parallel D_{t_{i}}}\partial^{n}_{x_{i}}\partial^{m}_{\hat{x}_{i}}\Delta_{(N,M),bou(i)}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})|_{\hat{x}_{i}=x_{i}}}

\displaystyle\times

\displaystyle\prod_{1\leq i<j\leq L}e^{2\sum_{n=0}^{\infty}c_{(i)n\parallel D_{t_{i}}}\sum_{m=0}^{\infty}c_{(j)m\parallel D_{t_{i}}}\partial^{n}_{x_{i}}\partial^{m}_{x_{j}}G_{(N,M),bou}(x_{i},x_{j};\{x_{t},\epsilon_{t}\})}

(92)

where
c_{n\parallel D_{t_{i}}}
are defined as in
eq. (
59
) and
t_{i}
is chosen by the brane on which

x_{i}
lies, i.e.
{x_{t_{i}+1}}<x_{i}<{x_{t_{i}}}
.

4.1.1
Some consequences

There are now two immediate consequences. The first and more trivial
is that all correlators with just one derivative vertex have
contribution only from the classical solution
X_{cl}

[
5
]
, i.e

\displaystyle\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\partial_{x}^{n}X^{I}(x,x)\rangle=\partial_{x}^{n}X^{I}_{cl}(x,x)\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

(93)

The second and more interesting is that all correlators can be
essentially computed with Wick theorem plus classical contributions
plus self interactions which are absent in Wick theorem. This implies
that a string in presence of not excited twist fields (defects)
is free and can be
quantized almost in the usual manner.

4.1.2
Some examples

As a first example we want to compute the correlator of a tachyon with

N
twist fields

\displaystyle\langle e^{ik_{I}X^{I}(x,x)}\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle=V_{N+1}|_{c_{1}=ik,\bar{c}_{1}=i\bar{k}}

\displaystyle=\langle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle~e^{ik\bar{X}_{cl}(x,x)+i\bar{k}X_{cl}(x,x)}e^{-k_{\parallel D_{t}}^{2}\Delta_{(N,M),bou(i)}(x,x)}

(94)

which shows that untwisted matter sees a kind of form factor of the
interacting twisted matter in accord with the result from OPE and what
discussed in
[
26
]
for the case of a stringy instanton.
Again a priori we can take
k^{I}
not parallel to the brane
D_{t}
but
the explicit form of the Green function implies a
projection in the direction parallel to
D_{t}

It is interesting to compare the previous result with what we can get
using the OPE (
61

Using the OPE at the leading order we get

\displaystyle\langle e^{ik_{I}X^{I}(x,x)}\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle\sim(x-{x_{t}})^{-\alpha^{\prime}k^{2}_{\parallel D_{t}}}e^{-\frac{1}{2}R^{2}(\epsilon_{t})\alpha^{\prime}k^{2}_{\parallel D_{t}}}e^{i(k\bar{f}_{t}+\bar{k}f_{t})}\langle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle

and the result shown in app.

(97)

Secondly let us consider the correlator of a gauge boson with twisted matter

\displaystyle\langle\epsilon_{I}\partial_{x}X^{I}e^{ik_{I}X^{I}(x,x)}

\displaystyle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle=\langle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle~e^{ik\bar{X}_{cl}(x,x)+i\bar{k}X_{cl}(x,x)}e^{-k_{\parallel D_{t}}^{2}\Delta_{(N,M),bou(i)}(x,x)}

\displaystyle\sqrt{2}e^{-i\pi\alpha_{t}}\epsilon_{\parallel D_{t}}\left(\partial_{x}X_{cl}(x,x)+\sqrt{2}e^{i\pi\alpha_{t}}ik_{\parallel D_{t}}\partial_{x}\Delta_{(N,M),bou(i)}(x,\hat{x})|_{\hat{x}=x}\right)

(98)

which exhibits the same structure as the vertex
(
62
) and the OPE it can be
computed using it.

Next we consider the interaction of two tachyons with the twisted

\displaystyle\langle

\displaystyle e^{ik_{1I}X^{I}(x_{1},x_{1})}e^{ik_{2I}X^{I}(x_{2},x_{1})}\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle=V_{N+2}|_{c_{j}=ik_{j},\bar{c}_{j}=i\bar{k}_{j}}

\displaystyle=

\displaystyle\langle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle\prod_{j=1}^{2}\left[e^{ik_{j}\bar{X}_{cl}(x_{j},x_{j})+i\bar{k}_{j}X_{cl}(x_{j},x_{j})}e^{-k_{\parallel D_{t_{j}}}^{2}\Delta_{(N,M),bou(i)}(x_{j},x_{j})}\right]

\displaystyle e^{-k_{\parallel D_{t_{1}}}k_{\parallel D_{t_{2}}}G_{(N,M),bou}(x_{1},x_{2})}

(99)

where

and is given in eq. (
159
) whose explicit
expression (
158
)
implies that only the momenta parallel to the brane on

Finally, we consider a more lengthy example

\displaystyle\langle

\displaystyle(\partial_{x}^{2}X\partial_{x}X\partial_{x}\bar{X})(x_{1})(\partial_{x}^{2}\bar{X})(x_{2})\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle=\frac{\partial^{3}}{\partial\bar{c}_{(1)2}\partial\bar{c}_{(1)1}\partial c_{(1)1}}\frac{\partial}{\partial c_{(2)2}}V_{N+2}\Big|_{c_{(j)n}=0}

\displaystyle=

\displaystyle\langle\prod_{t=1}^{N}\sigma_{\epsilon_{t},f_{t}}(x_{t})\rangle\Bigg[(\partial_{x}^{2}X_{cl}\partial_{x}X_{cl}\partial_{x}\bar{X}_{cl})(x_{1})(\partial_{x}^{2}\bar{X}_{cl})(x_{2})

\displaystyle+e^{i\pi(-\alpha_{t_{1}}-\alpha_{t_{2}})}~(\partial_{x}^{2}X_{cl}\partial_{x}X_{cl})(x_{1})~\partial_{x_{1}}\partial_{x_{2}}^{2}G_{(N,M),bou}(x_{1},x_{2})

\displaystyle+e^{i\pi(\alpha_{t_{1}}-\alpha_{t_{2}})}~(\partial_{x}^{2}X_{cl}\partial_{x}\bar{X}_{cl})(x_{1})~\partial_{x_{1}}\partial_{x_{2}}^{2}G_{(N,M),bou}(x_{1},x_{2})

\displaystyle+\frac{1}{2}~\partial_{x}^{2}X_{cl}(x_{1})\partial_{x}\bar{X}_{cl}(x_{2})~\partial_{x_{1}}\partial_{\hat{x}_{1}}\Delta_{(N,M),bou}(x_{1},\hat{x}_{1})|_{\hat{x}_{1}=x_{1}}

\displaystyle+e^{2i\pi\alpha_{t_{1}}}~\partial_{x}\bar{X}_{cl}(x_{1})\partial_{x}\bar{X}_{cl}(x_{2})~\partial_{x_{1}}^{2}\partial_{\hat{x}_{1}}\Delta_{(N,M),bou}(x_{1},\hat{x}_{1})|_{\hat{x}_{1}=x_{1}}

\displaystyle+\frac{1}{2}e^{i\pi(\alpha_{t_{1}}-\alpha_{t_{2}})}~\partial_{x_{1}}\partial_{\hat{x}_{1}}\Delta_{(N,M),bou}(x_{1},\hat{x}_{1})|_{\hat{x}_{1}=x_{1}}~\partial_{x_{1}}^{2}\partial_{x_{2}}^{2}G_{(N,M),bou}(x_{1},x_{2})

\displaystyle+\frac{1}{2}e^{i\pi(\alpha_{t_{1}}-\alpha_{t_{2}})}~\partial_{x_{1}}^{2}\partial_{\hat{x}_{1}}\Delta_{(N,M),bou}(x_{1},\hat{x}_{1})|_{\hat{x}_{1}=x_{1}}~\partial_{x_{1}}\partial_{x_{2}}^{2}G_{(N,M),bou}(x_{1},x_{2})

\displaystyle+\frac{1}{2}e^{i\pi(\alpha_{t_{1}}-\alpha_{t_{2}})}~\partial_{x_{1}}^{2}\partial_{\hat{x}_{1}}\Delta_{(N,M),bou}(x_{1},\hat{x}_{1})|_{\hat{x}_{1}=x_{1}}~\partial_{x_{1}}\partial_{x_{2}}^{2}G_{(N,M),bou}(x_{1},x_{2})\Bigg]

(100)

4.2
Boundary correlators with non excited twists on
T^{2}

The wrapping contributions have been studied for the pure twist field
correlators in

[
32
]
for the N=3 case and in

[
14
]
for
the case
M=N-2
and there is not any difference among the different

M
values therefore the results obtained there are valid.
Let us anyhow quickly review them.
Given a minimal
N
-polygon in
T^{2}
with vertices
\{f_{t}\}
,
i.e. with all vertices in the fundamental cell,
we can consider non minimal polygons which wrap the
T^{2}
.
These can be easierly described
as polygons which have vertices
\{\tilde{f}_{t}\}

in the covering
\mathbb{R}^{2}
where
T^{2}\equiv R^{2}/\Lambda
with
the lattice defined as
\Lambda=\{n_{1}e_{1}+n_{2}e_{2}|n_{1},n_{2}\in\mathbb{Z}\}
.
These configurations give an additive contribution to the classical
path integral as

\displaystyle V_{N+M}^{(T^{2})}(J_{i})

\displaystyle=\sum_{\{\tilde{f}_{t}\}}\left[\langle\sigma_{\epsilon_{1},\tilde{f}_{1}}(x_{1})\dots\sigma_{\epsilon_{N},\tilde{f}_{N}}(x_{N})\rangle\prod_{i=1}^{M}e^{\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}X^{I}_{cl}(x_{i},x_{i};\{x_{t},\epsilon_{t},\tilde{f}_{t}\})}\right]

\displaystyle\times

\displaystyle\prod_{i=1}^{M}e^{\frac{1}{2}\sum_{n=0}^{\infty}c_{(i)nI}\sum_{m=0}^{\infty}c_{(i)mJ}\partial^{n}_{x_{i}}\partial^{m}_{\hat{x}_{i}}\Delta^{IJ}_{(N,M),bou(i)}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})|_{\hat{x}_{i}=x_{i}}}

\displaystyle\times

\displaystyle\prod_{1\leq i<j\leq M}e^{\sum_{n=0}^{\infty}c_{(i)nI}\sum_{m=0}^{\infty}c_{(j)mJ}\partial^{n}_{x_{i}}\partial^{m}_{x_{j}}G^{IJ}_{(N,M),bou}(x_{i},x_{j};\{x_{t},\epsilon_{t}\})}

(101)

In order to determine the possible vertices
\{\tilde{f}_{t}\}

without redundancy it is necessary to keep a vertex fixed and then
expand the polygon. For definiteness we keep fixed the vertex
\tilde{f}_{1}=f_{1}

which lies at the intersection between
D_{N}
and
D_{1}
.
We then move the next vertex
f_{2}
along the
D_{1}
brane.
Explicitly we write
\tilde{f}_{2}=\tilde{f}_{1}+(f_{2}-f_{1})+n_{1}t_{1}=f_{2}+n_{1}t_{1}
with
n_{1}\in\mathbb{Z}
and

t_{1}
the shortest tangent vector to
D_{1}
which is in
\Lambda
.
We can now continue for all the other vertices for which we have

\tilde{f}_{t}=\tilde{f}_{t-1}+(f_{t}-f_{t-1})+n_{t-1}t_{t-1}=f_{t}+\sum_{k=1}^{t-1}n_{k}t_{k}
.
For consistency we need requiring
\tilde{f}_{N+1}\equiv\tilde{f}_{1}=f_{1}
,
therefore the possible wrapped polygons are obtained from the solution
of the Diophantine equation

\displaystyle\sum_{{\hat{t}}=1}^{N}n_{\hat{t}}t_{\hat{t}}=0

(102)

which cannot be solved in general terms but only on a case by case
basis as discussed in
[
14
]
.

4.3
Chiral correlators with non excited twists.

As a warming up for the computation of excited twist fields which we
perform in the next section we consider the interaction of chiral
vertices with plain twists.

We can now follow the same strategy we used in section

4.1
and compute the path integral with the
insertion of an arbitrary number
L_{c}
of currents which act as
generating functions for the chiral vertex operators.
As done for the boundary correlators in section
4.1

we first regularize the currents
and then subtract the self interaction of the untwisted string.
We are therefore led to consider the path integral

\displaystyle V_{N+L_{c}}(J_{c})=\lim_{\{\eta_{c}\}\rightarrow 0}

\displaystyle\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}X~e^{-S_{E}}

\displaystyle\times

\displaystyle\prod_{c=1}^{L_{c}}\Big[e^{-\frac{1}{2}\int d^{2}u_{a}\int d^{2}u_{b}J_{cI}(u_{a},\eta_{c})J_{cJ}(u_{b},\eta_{c})\partial_{u_{a}}\partial_{u_{b}}G^{IJ}_{U(t_{c})}(u_{a},{\bar{u}}_{a};u_{b},{\bar{u}}_{b})}

\displaystyle e^{\int d^{2}u~\partial_{u}J_{cI}(u,\eta_{c})\partial_{u}X^{I}(u,{\bar{u}})}\Big]

(103)

where in the second line we have written the regularization factor
analogous to the one used in section
4.1

which regularizes the currents in the third line.
In the previous expression the regularized currents are defined as

J_{cI}(u,{\bar{u}},\eta_{c})=\sum_{n=1}^{\infty}c_{(c)nI}\partial^{n-1}_{u}\delta^{2}(u-u_{c};\eta_{c})

(104)

with
\delta^{2}(u-u_{c};\eta_{c})
a regularization of the
\delta^{2}()
such
that
\lim_{\eta_{c}\rightarrow 0}\delta^{2}(u;\eta_{c})=\delta^{2}(u)
.
Notice that we need using a
\delta^{2}()
in the previous expression
since we use “directional” derivatives along
u
.
To subtract the self interaction of the untwisted string we
used
G^{IJ}_{U(t_{c})}(u_{a},{\bar{u}}_{a};u_{b},{\bar{u}}_{b})
, the untwisted Green
function computed for an arbitrary
t_{c}
since we chose to consider
currents with at least one derivative
\partial_{u}
so that only
G^{z{\bar{z}}}_{U}
give with a non vanishing contribution which is also
independent on the brane
D_{t}
.

Finally performing the path integral we get

\displaystyle V_{N+L_{c}}(J_{c})

\displaystyle=\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{c=1}^{L_{c}}\Bigg\{e^{\sum_{n=1}^{\infty}c_{(c)nI}\partial^{n-1}_{u_{c}}[\partial_{u}X^{I}_{cl}(u_{c},{\bar{u}}_{c})]}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n,m=1}^{\infty}c_{(c)nI}c_{(c)mJ}\partial^{n}_{u_{d}}\partial^{m}_{v_{\hat{c}}}\Delta_{(N,M)(c)}^{IJ}(u_{c},{\bar{u}}_{c};v_{c},{\bar{v}}_{c};\{x_{\hat{t}},\epsilon_{\hat{t}}\})|_{v_{c}=u_{c}}]}\Bigg\}

\displaystyle\times

\displaystyle\prod_{1\leq c<\hat{c}\leq N}e^{\sum_{n,m=1}^{\infty}d_{(c)nI}d_{(\hat{c})mJ}\partial^{n}_{u_{t}}\partial^{m}_{v_{\hat{t}}}G_{(N,M)}^{IJ}(u_{c},{\bar{u}}_{c};v_{\hat{c}},{\bar{v}}_{\hat{c}};\{x_{t},\epsilon_{t}\})}

(105)

where we have written the dependence on the complex conjugate
variables such as
{\bar{u}}
even if the derivatives are independent in
order to be consistent with the notation used in the boundary case.
The regularized chiral Green function is defined as expected as

\displaystyle\partial_{u}\partial_{v}\Delta_{(N,M)(c)}^{IJ}(u,{\bar{u}};v,{\bar{v}}\{x_{\hat{t}},\epsilon_{\hat{t}}\})

\displaystyle=\partial_{u}\partial_{v}G_{(N,M)}^{IJ}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})-\partial_{u}\partial_{v}G^{IJ}_{U(t)}(u,{\bar{u}};v,{\bar{v}};\epsilon_{t})

(106)

and we notice that the subtraction term is different from zero only
when
IJ=z{\bar{z}}
or
IJ={\bar{z}}z
because of the derivatives.

4.4
Correlators of excited twists on
\mathbb{R}^{2}

Finally we can compute the correlators of excited twist fields by
letting the appropriate chiral currents collide with the twist fields.
We follow the same strategy we used in section

4.1
and in the previous section
4.3

and compute the path integral with the
insertion of one generating function (
79
) for each twist field.
As done for the boundary correlators in section
4.1

we first regularize the
\delta^{2}()
functions in the currents
and then subtract the self interaction of the untwisted string.
We are therefore led to consider the path integral

\displaystyle V_{N}(K_{t})=

\displaystyle\lim_{\{u_{t}\}\rightarrow\{x_{t}\}}\lim_{\eta_{t}\rightarrow 0}\int_{{\cal M}(\{x_{t},\epsilon_{t},f_{t}\})}{\cal D}X~e^{-S_{E}}

\displaystyle\times

\displaystyle\prod_{t=1}^{N}\Big[e^{-\frac{1}{2}\int d^{2}u_{a}\int d^{2}u_{b}K_{tI}(u_{a},\eta_{t})K_{tJ}(u_{b},\eta_{t})(u_{a}-x_{t})^{\epsilon_{tI}}(u_{b}-x_{t})^{\epsilon_{tJ}}\partial_{u_{a}}\partial_{u_{b}}G^{IJ}_{U(t)}(u_{a},{\bar{u}}_{a};u_{b},{\bar{u}}_{b})}

\displaystyle e^{\int d^{2}u~K_{tI}(u,\eta_{t})(u-x_{t})^{\epsilon_{tI}}\partial_{u}X^{I}(u,{\bar{u}})}

\displaystyle e^{-\int d^{2}u_{a}\int d^{2}u_{b}K_{tz}(u_{a},\eta_{t})K_{t{\bar{z}}}(u_{b},\eta_{t})\left[(u_{a}-x_{t})^{\bar{\epsilon}_{t}}(u_{b}-x_{t})^{\epsilon_{t}}\partial_{u_{a}}\partial_{u_{b}}\Delta^{z{\bar{z}}}_{c}(u_{a}-x_{t},{\bar{u}}_{a}-x_{t};u_{b}-x_{t},{\bar{u}}_{b}-x_{t};\epsilon_{t})\right]}\Big]

(107)

where in the second line we have written the regularization factor
analogous to the one used in section
4.1

which regularizes the third line and finally in the last line we have
the necessary subtraction term which is in eq. (
79
).
In the previous expression the regularized currents are defined as

K_{tI}(u,{\bar{u}},\eta_{t})=\sum_{n=1}^{\infty}d_{(t)nI}\partial^{n-1}_{u}\delta^{2}(u-u_{t};\eta_{t})

(108)

with
\delta^{2}(u-u_{t};\eta_{t})
a regularization of the
\delta^{2}()

as in previous section.

For writing a more compact expression we have also used
\epsilon_{tI}

defined as

\epsilon_{tz}=\bar{\epsilon}_{t},~~~\epsilon_{t{\bar{z}}}=\epsilon_{t}

(109)

Finally performing the path integral we get

\displaystyle V_{N}(K_{t})

\displaystyle=\lim_{\{u_{t}\}\rightarrow\{x_{t}\}}\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{t=1}^{N}\Bigg\{e^{\sum_{n=1}^{\infty}d_{(t)nI}\partial^{n-1}_{u_{t}}[(u_{t}-x_{t})^{\epsilon_{tI}}\partial_{u}X^{I}_{cl}(u_{t},{\bar{u}}_{t})]}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n,m=1}^{\infty}d_{(t)nI}d_{(t)mJ}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{t}}[(u_{t}-x_{t})^{\epsilon_{tI}}(v_{t}-x_{t})^{\epsilon_{tJ}}\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{IJ}(u_{t},{\bar{u}}_{t};v_{t},{\bar{v}}_{t};\{x_{\hat{t}},\epsilon_{\hat{t}}\})]|_{v_{t}=u_{t}}}\Bigg\}

\displaystyle\times

\displaystyle\prod_{1\leq t<{\hat{t}}\leq N}e^{\sum_{n,m=1}^{\infty}d_{(t)nI}d_{({\hat{t}})mJ}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{\hat{t}}}[(u_{t}-x_{t})^{\epsilon_{tI}}(v_{\hat{t}}-x_{\hat{t}})^{\epsilon_{{\hat{t}}J}}\partial_{u}\partial_{v}G_{(N,M)}^{IJ}(u_{t},{\bar{u}}_{t};v_{\hat{t}},{\bar{v}}_{\hat{t}};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]}

(110)

where we have defined the regularized Green function at the twist
fields
t
to be

\displaystyle\partial_{u}\partial_{v}

\displaystyle\Delta_{(N,M)(t)}^{IJ}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})=

\displaystyle=

\displaystyle\partial_{u}\partial_{v}\Delta_{(N,M)(c)}^{IJ}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})-\partial_{u}\partial_{v}\Delta^{IJ}_{c}(u-x_{t},{\bar{u}}-x_{t};v-x_{t},{\bar{v}}-x_{t};\epsilon_{t})

\displaystyle=\partial_{u}\partial_{v}G_{(N,M)}^{IJ}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})-\partial_{u}\partial_{v}G_{N=2}^{IJ}(u-x_{t},{\bar{u}}-x_{t};v-x_{t},{\bar{v}}-x_{t};\epsilon_{t})

(111)

and we used
G_{U(t)}^{IJ}(u-x_{t},v-x_{t})=G_{U(t)}^{IJ}(u,v)

to write the last line
and again we have written the dependence on
{\bar{u}}
and
{\bar{v}}
even if
the derivatives are independent on them for having a consistent notation.
Actually because of the chiral derivatives the previous expression
simplifies in two cases to

\displaystyle\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{zz}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})

\displaystyle=\partial_{u}\partial_{v}G_{(N,M)}^{zz}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})

\displaystyle\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{{\bar{z}}{\bar{z}}}(u,{\bar{u}};v,{\bar{v}};;\{x_{\hat{t}},\epsilon_{\hat{t}}\})

\displaystyle=\partial_{u}\partial_{v}G_{(N,M)}^{{\bar{z}}{\bar{z}}}(u,{\bar{u}};v,{\bar{v}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})

(112)

It is interesting to notice that regularized Green functions are
got by subtracting the divergent part with the proper monodromy at the
point of regularization which at the points where a twist field is
located means
G_{N=2}
while in all other points means
G_{U}
.
In particular both

(u-x_{t})^{\epsilon_{tI}}(v-x_{t})^{\epsilon_{tJ}}\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{IJ}

and

(u-x_{t})^{\epsilon_{tI}}(v-x_{t})^{\epsilon_{tJ}}\partial_{u}\partial_{v}G_{(N,M)}^{IJ}

are analytic functions at
u=x_{t}
whose explicit expression is given
in appendix
E
.

More explicitly the previous generating function can be written as

\displaystyle V_{N}(K_{t})

\displaystyle=\lim_{\{u_{t}\}\rightarrow\{x_{t}\}}\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{t=1}^{N}\Bigg\{e^{\sum_{n=1}^{\infty}\left[\bar{d}_{(t)n}\partial^{n-1}_{u_{t}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}\partial_{u}X_{cl}(u_{t},{\bar{u}}_{t})]+d_{(t)n}\partial^{n-1}_{u_{t}}[(u_{t}-x_{t})^{\epsilon_{t}}\partial_{u}{\bar{X}}_{cl}(u_{t},{\bar{u}}_{t})]\right]}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n,m=1}^{\infty}\bar{d}_{(t)n}\bar{d}_{(t)m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{t}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}(v_{t}-x_{t})^{\bar{\epsilon}_{t}}\partial_{u}\partial_{v}G_{(N,M)(t)}^{zz}(u_{t},{\bar{u}}_{t};v_{t},{\bar{v}}_{t};\{x_{\hat{t}},\epsilon_{\hat{t}}\})]|_{v_{t}=u_{t}}}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n,m=1}^{\infty}d_{(t)n}d_{(t)m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{t}}[(u_{t}-x_{t})^{\epsilon_{t}}(v_{t}-x_{t})^{\epsilon_{t}}\partial_{u}\partial_{v}G_{(N,M)(t)}^{{\bar{z}}{\bar{z}}}(u_{t},{\bar{u}}_{t};v_{t},{\bar{v}}_{t};\{x_{\hat{t}},\epsilon_{\hat{t}}\})]|_{v_{t}=u_{t}}}

\displaystyle\times

\displaystyle e^{\sum_{n,m=1}^{\infty}\bar{d}_{(t)n}d_{(t)m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{t}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}(v_{t}-x_{t})^{\epsilon_{t}}\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{z{\bar{z}}}(u_{t},{\bar{u}}_{t};v_{t},{\bar{v}}_{t};\{x_{\hat{t}},\epsilon_{\hat{t}}\})]|_{v_{t}=u_{t}}}\Bigg\}

\displaystyle\times

\displaystyle\prod_{1\leq t<{\hat{t}}\leq N}\Bigg\{e^{\sum_{n,m=1}^{\infty}\bar{d}_{(t)n}\bar{d}_{({\hat{t}})m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{\hat{t}}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}(v_{\hat{t}}-x_{\hat{t}})^{\bar{\epsilon}_{{\hat{t}}}}\partial_{u}\partial_{v}G_{(N,M)}^{zz}(u_{t},{\bar{u}}_{t};v_{\hat{t}},{\bar{v}}_{\hat{t}};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]}

\displaystyle\times e^{\sum_{n,m=1}^{\infty}d_{(t)n}d_{({\hat{t}})m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{\hat{t}}}[(u_{t}-x_{t})^{\epsilon_{t}}(v_{\hat{t}}-x_{\hat{t}})^{\epsilon_{{\hat{t}}}}\partial_{u}\partial_{v}G_{(N,M)}^{{\bar{z}}{\bar{z}}}(u_{t},{\bar{u}}_{t};v_{\hat{t}},{\bar{v}}_{\hat{t}};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]}

\displaystyle\times e^{\sum_{n,m=1}^{\infty}\bar{d}_{(t)n}d_{({\hat{t}})m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{\hat{t}}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}(v_{\hat{t}}-x_{\hat{t}})^{\epsilon_{{\hat{t}}}}\partial_{u}\partial_{v}G_{(N,M)}^{z{\bar{z}}}(u_{t},{\bar{u}}_{t};v_{\hat{t}},{\bar{v}}_{\hat{t}};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]}

\displaystyle\times e^{\sum_{n,m=1}^{\infty}d_{(t)n}\bar{d}_{({\hat{t}})m}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{\hat{t}}}[(u_{t}-x_{t})^{\epsilon_{t}}(v_{\hat{t}}-x_{\hat{t}})^{\bar{\epsilon}_{{\hat{t}}}}\partial_{u}\partial_{v}G_{(N,M)}^{{\bar{z}}z}(u_{t},{\bar{u}}_{t};v_{\hat{t}},{\bar{v}}_{\hat{t}};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]}\Bigg\}

(113)

Some examples

\displaystyle\langle\left(\partial^{n}X\sigma_{\epsilon_{t},f_{t}}\right)\prod_{{\bar{t}}\neq t}\sigma_{\epsilon_{\bar{t}},f_{\bar{t}}}\rangle=\frac{\partial}{\partial\bar{d}_{(t)nz}}V_{N}|_{d=\bar{d}=0}

(114)

where the limit is not strictly necessary since the expression

F

\displaystyle\langle

\displaystyle\left(\partial^{n}X\partial^{m}\bar{X}\sigma_{\epsilon_{t},f_{t}}\right)\prod_{{\bar{t}}\neq t}\sigma_{\epsilon_{\bar{t}},f_{\bar{t}}}\rangle=\frac{\partial^{2}}{\partial\bar{d}_{(t)nz}\partial d_{(t)mz}}V_{N}|_{d=\bar{d}=0}

\displaystyle\langle

\displaystyle=\langle\prod_{{\bar{t}}}\sigma_{\epsilon_{\bar{t}},f_{\bar{t}}}\rangle\lim_{u_{t,{\hat{t}}}\rightarrow x_{t,{\hat{t}}}}\Big[\partial^{n-1}_{u_{t}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}\partial_{u}X_{cl}(u_{t})]\partial^{m-1}_{u_{\hat{t}}}[(u_{\hat{t}}-x_{\hat{t}})^{\bar{\epsilon}_{{\hat{t}}}}\partial_{u}X_{cl}(u_{\hat{t}})]

\displaystyle+\partial^{n-1}_{u_{t}}\partial^{m-1}_{u_{\hat{t}}}[(u_{t}-x_{t})^{\bar{\epsilon}_{t}}(u_{\hat{t}}-x_{\hat{t}})^{\epsilon_{{\hat{t}}}}\partial_{u_{t}}\partial_{u_{\hat{t}}}G_{(N,M)}^{z{\bar{z}}}(u_{t},{\bar{u}}_{t};u_{\hat{t}},{\bar{u}}_{\hat{t}};\{x_{\hat{t}},\epsilon_{\hat{t}}\})]\Big]

(116)

This correlator is the correlator of eq. (4.83) of

[
5
]
, i.e.

\langle\tau_{\alpha}(x_{1})\tau_{1-\alpha}(x_{2})\sigma_{\beta}(x_{3})\sigma_{1-\beta}(x_{4})\rangle
when we set
N=4
,
n=m=1
and

\epsilon_{1}=\alpha
,
\epsilon_{2}=1-\alpha
,

\epsilon_{3}=\beta
and

4.5
Correlators of boundary operators and excited twists on
\mathbb{R}^{2}

Finally we can assemble the results from previous section to write the
generating function for correlators of boundary operators and excited
twists on
R^{2}
to be

\displaystyle V_{N+L}(K_{t},J_{i})

\displaystyle=\lim_{\{u_{t}\}\rightarrow\{x_{t}\}}\langle\sigma_{\epsilon_{1},f_{1}}(x_{1})\dots\sigma_{\epsilon_{N},f_{N}}(x_{N})\rangle

\displaystyle\times

\displaystyle\prod_{t=1}^{N}\Bigg\{e^{\sum_{n=1}^{\infty}d_{(t)nI}\partial^{n-1}_{u_{t}}[(u_{t}-x_{t})^{\epsilon_{tI}}\partial_{u}X^{I}_{cl}(u_{t},{\bar{u}}_{t})]}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n,m=1}^{\infty}d_{(t)nI}d_{(t)mJ}\partial^{n-1}_{u_{t}}\partial^{m-1}_{v_{t}}[(u_{t}-x_{t})^{\epsilon_{tI}}(v_{t}-x_{t})^{\epsilon_{tJ}}\partial_{u}\partial_{v}\Delta_{(N,M)(t)}^{IJ}(u_{t},{\bar{u}}_{t};v_{t},{\bar{v}}_{t};\{x_{\bar{t}},\epsilon_{\bar{t}}\})]|_{v_{t}=u_{t}}}\Bigg\}

\displaystyle\times

\displaystyle\prod_{i=1}^{L}\Bigg\{e^{\sum_{n=0}^{\infty}c_{(i)nI}\partial^{n}_{x_{i}}X^{I}_{cl}(x_{i},x_{i})}

\displaystyle\times

\displaystyle e^{\frac{1}{2}\sum_{n=0}^{\infty}c_{(i)nI}\sum_{m=0}^{\infty}c_{(i)mJ}\partial^{n}_{x_{i}}\partial^{m}_{\hat{x}_{i}}\Delta^{IJ}_{(N,M),bou(i)}(x_{i},\hat{x}_{i};\{x_{t},\epsilon_{t}\})|_{\hat{x}_{i}=x_{i}}}\Bigg\}

\displaystyle\times

We can now make an educated guess of the generating function of the

the generating function for the antichiral part times
