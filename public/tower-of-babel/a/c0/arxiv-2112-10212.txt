Hiding pebbles when the output alphabet is unary
Gaëtan Douéneau-Tabot

Abstract
Pebble transducers are nested two-way transducers which can drop marks (named “pebbles”) on their input word. Blind transducers have been introduced by Nguyên et al. as a subclass of pebble transducers, which can nest two-way transducers but cannot drop pebbles on their input. In this paper, we study the classes of functions computed by pebble and blind transducers, when the output alphabet is unary. Our main result shows how to decide if a function computed by a pebble transducer can be computed by a blind transducer. We also provide characterizations of these classes in terms of Cauchy and Hadamard products, in the spirit of rational series. Furthermore, pumping-like characterizations of the functions computed by blind transducers are given.

Class membership problems.

We finally show how to decide whether
a polyregular function with unary output is polyblind. It is by far the most
involved and technical result of this paper. Furthermore,
the construction of a blind transducer is effective, hence
this result can be viewed as program
optimization. Indeed, given a program with nested loops,
our algorithm is able to build an equivalent program using “blind” loops
if it exists.

In general, decision problems for transductions
are quite difficult to solve, since contrary to regular languages,
there are no known “canonical” objects (such as a minimal automaton)
to represent (poly)regular functions. It is thus complex to
decide an intrinsic property of a function,
since it can be described in several seemingly unrelated
manners. Nevertheless, the membership problem from rational series to
polyregular (resp. regular) functions was shown to be decidable
in
[
7
,
6
]
.
It is in fact equivalent to checking if the output of the rational series
is bounded by a polynomial (resp. a linear function)
in its input’s length.

However, both polyregular and polyblind functions can have
polynomial growth rates. To discriminate between them,
we thus introduce the new notion of
repetitiveness

(which is a pumping-like property
for functions) and show that it exactly
captures the polyregular functions
that are polyblind. The proof is a rather complex induction
on the depth
k\geq 1
of the
k
-pebble transducer representing
the function. We show at the same time that repetitiveness
is decidable and that a blind transducer can effectively be built
whenever this property holds.
Partial results were obtained in
[
6
]

to decide “blindness” of the functions computed by

2
-pebble transducers.
Some of our tools are inspired by this paper,
such as the use of bimachines and factorization forests.
Nevertheless, our general result requires new proof techniques (e.g. the induction
techniques which insulate the term of
“highest growth rate” in the function) and concepts
(e.g. repetitiveness).

Preliminaries

\mathbb{N}
is the set of nonnegative integers.
If

is
\{i,i{+}1,\dots,j\}\subseteq\mathbb{N}

(empty if

i.e. a finite set of letters.
The empty word is denoted by

If

be its length,
and for

If

If

We assume that the reader is familiar with the basics of automata theory,
in particular one-way and two-way automata, and monoid morphisms.

Two-way transducers.

A deterministic two-way transducer is a deterministic
two-way automaton (with input in
A^{*}
) enhanced with the ability to produce
outputs (from
B^{*}
) when performing a transition. The output of the transducer is
defined as the concatenation of these productions along the unique accepting
run on the input word (if it exists): it thus describes
a (partial) function
A^{*}\rightarrow B^{*}
. Its behavior is
depicted in Figure
4
.
A formal definition can be found e.g. in
[

These machines compute the class of
regular functions
.

Example 1

The function

Example 2

Given

Blind and pebble transducers.

Blind and pebble transducers
extend two-way transducers by allowing to “nest” such machines.
A

For

-blind (resp.

-pebble) transducer

from a position

of its input

(k{-}1)
-blind (resp.
(k{-}1)
-pebble) transducer with input

(resp.
w[1{:}i{-}1]\underline{w[i]}w[i{+}1{:}|w|]

i.e.

where position

is marked).
The two-way transducer then uses the
output of this submachine as if it was the output produced
along its transition. The intuitive behaviors are depicted
for

Formal definitions can be found e.g.

Example 3
.

Let

processes its input from left to right, and it calls inductively a

-blind transducer

each time it it sees an

.

Example 4
.

The function
{2}\operatorname{\textsf{-powers}}:a^{n_{1}}b\cdots a^{n_{m}}b\mapsto\sum_{i=1}^{m}n_{i}^{2}

2
-pebble transducer.
Its main transducer ranges over all the

Similarily, the function

Definition 5
.

We define the class of
polyregular functions

(resp.
polyblind functions
) as the class of
functions computed by a
k
-pebble (resp.
k
-blind) transducer
for some

.

It is not hard to see that polyblind functions are a subclass of polyregular functions.
Indeed, a blind transducer is just a pebble transducer “without pebbles”.

Bimachines.

In this paper, we shall describe formally the regular, polyregular and polyblind functions with
another computation model. A
bimachine
is a transducer which makes
a single left-to-right pass on its input,
but it can use a morphism into a finite monoid to check regular properties
of the prefix (resp. suffix) ending (resp. starting) in the current position.
This notion of bimachines enable us to easily use algebraic techniques
in the proofs, and in particular
factorization forests

over finite monoids.

Definition 6
.

A bimachine
\mathcal{M}\coloneqq(A,M,\mu,\lambda)
is:

•

an input alphabet
A
, a finite monoid
M
and a monoid morphism
\mu:A^{*}\rightarrow M
;

•

an output function
\lambda:M\times A\times M\rightarrow\mathbb{N}
.

\mathcal{M}
computes
f:A^{*}\rightarrow\mathbb{N}

defined by

f(w)\coloneqq\sum_{i=1}^{|w|}\lambda(\mu(w[1{:}i{-}1]),w[i],\mu(w[i{+}1{:}|w|]))

for
w\in A^{*}
.
The production of each term of this sum is depicted intuitively
in Figure
5
.

\begin{subarray}{c}w[i]\end{subarray}
\begin{subarray}{c}w[1{:}i{-}1]\end{subarray}
\begin{subarray}{c}w[i{+}1{:}|w|]\end{subarray}
\begin{subarray}{c}\mu(w[1{:}i{-}1])\end{subarray}
\begin{subarray}{c}\mu(w[i{+}1{:}|w|])\end{subarray}

When dealing with bimachines, we consider without loss of generality total functions
such that

(the domains of two-way transducers are

In this context, it is well known that regular
functions of type

are exactly those computed by bimachines

Now we recall how

Intuitively, a

enriched with the possibility to launch a submachine
for each letter of the input (it outputs the sum of all the outputs
returned by these submachines).

Remark 9
.

For pebble bimachines,
a natural question is whether the inner bimachines can ask which
pebble was dropped by which ancestor, or whether they can only see
that “there is a pebble”. Both models are in fact equivalent,
since the number of pebbles is bounded.

Now we recall in Theorem
10

that pebble and blind bimachines are respectively equivalent to the
aforementioned pebble and blind transducers. More interestingly,
the marble bimachines (which call “prefixes”)
also correspond to pebble transducers.
In our proofs, we shall preferentially use the
marble model to represent polyregular functions.

[

of functions. Furthermore,
k
-blind transducers
and
k
-blind bimachines compute the same class
of functions.

4
Membership problem from polyregular to polyblind

In this section, we state the most technical and interesting
result of this paper, which consists in deciding
if a polyregular function is polyblind. We also give in Theorem
23

a semantical characterization of polyregular functions
which are polyblind, using the notion of
repetitiveness
.
Intuitively, a
k
-repetitive function is a function which,
when given two places in a word where the same
factor is repeated, cannot distinguish between the first and the second place.
Hence its output only depends on the total number
of repetitions of the factor.

Definition 18

(Repetitive function)
.

Let

.
We say that

is

and

.
Let

defined by:

W:X_{1},\dots,X_{k}\mapsto\left(\alpha_{0}\prod_{i=1}^{k}{u_{i}}^{\omega X_{i}}\alpha_{i}\right).

and let
w\coloneqq W(1,\dots,1)
.
Then there exists a function

such that
for all
{\overline{X}}\coloneqq X_{1},\dots,X_{k}\geq 3

and
{\overline{Y}}\coloneqq Y_{1},\dots,Y_{k}\geq 3
, we have:

f(\alpha w^{2\omega-1}W({\overline{X}})w^{\omega-1}W({\overline{Y}})w^{\omega}\beta)=F(X_{1}+Y_{1},\dots,X_{k}+Y_{k})

.

If

is

-repetitive,

is also
(k{-}1)
-repetitive,
by considering an empty

.

Let us now give a few examples
in order so see when this criterion holds, or not.

If

For all

We are now ready to state our main result of this paper.

.

By Theorem

The rest of this paper is devoted to the proof of Theorem

5.1
Polyblind functions are repetitive

Intuitively, a blind transducer cannot distinguish between two
“similar” iterations of a given factor in a word,
since it cannot drop a pebble for doing so. We get the following
using technical but conceptually easy pumping arguments.

Proposition 28
.

A polyblind function is
k
-repetitive for all

Proof idea.

We first show that a regular function
(computed by a bimachine without external functions) is

as the idempotent index of the monoid used by the bimachine.
Then, it is easy to conclude by noting that

-repetitiveness
is preserved under sums and Hadamard products.
∎

The induction which proves Theorem

also requires the following result. Its proof is obvious
since

-repetitiveness is clearly preserved under subtractions.

Claim 29

If

k
-repetitive
and

k
-repetitive.

7
Outlook

This paper provides a technical solution
to a seemingly difficult membership
problem. This result can be interpreted
both in terms of nested transducers (i.e. programs with visible or
blind recursive calls) and in terms of rational series. We conjecture that
the new techniques introduced here (especially
the induction techniques), and the concepts of
productions on words and forests,
give an interesting toolbox to tackle
other decision problem for transducers
such as equivalence or membership issues.
It could also be interesting to characterize
polyblind functions as the series computed by specific
weighted automata over
(\mathbb{N},+,\times)
.

Appendix B
Properties of productions

In the forthcoming appendices, we denote by
\{\!\!\{s_{1}{\ddagger}r_{1},\dots,s_{n}{\ddagger}r_{n}\}\!\!\}

a multiset with
n
distinct elements
s_{1},\dots,s_{n}
, in which
r_{i}\geq 0
is the
multiplicity of
s_{i}
(thus the cardinal is
r_{1}+\cdots+r_{n}
).

B.1
Proof of Lemma
32

We want to show that if
J_{1},\dots J_{n}
is a partition of
[1{:}|w|]
,
then:

f(w)=\sum_{\{\!\!\{I_{1},\dots,I_{k}\}\!\!\}\subseteq\{J_{1},\dots,J_{n}\}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{I_{1},\dots,I_{k}\}\!\!\}\right).

Sublemma 61
.

Let
\mathcal{M}
be a
k
-marble bimachine which computes
a function
f:A^{*}\rightarrow\mathbb{N}
. Then
for all
w\in A^{*}
we have:

f(w)=\sum_{\{\!\!\{i_{1},\dots,i_{k}\}\!\!\}\subseteq[1{:}|w|]}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i_{1},\dots,i_{k}\}\!\!\}\right)=\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{[1{:}|w|]{{\ddagger}}k\}\!\!\}\right).

Proof.

The second equality
is obtained by definition of
\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{[1{:}|w|]{{\ddagger}}k\}\!\!\}\right)
.
We show the first one by induction on
k\geq 1
. The base
case is trivial, let us assume that
k\geq 2
. Let
\mathcal{M}=(A,M,\mu,\mathfrak{H},\lambda)

be the
k
-marble bimachine which computes
f
. For
1\leq i_{k}\leq|w|
,
let
\mathfrak{h}_{i_{k}}\coloneqq\lambda(\mu(w[1{:}i_{k}{-}1]),w[i_{k}],\mu(w[i_{k}{+}1{:}|w|]))\in\mathfrak{H}

and
\mathcal{M}_{\mathfrak{h}_{i_{k}}}
be the
(k{-}1)
-marble bimachine which computes it.
Then we have:

\displaystyle f(w)

\displaystyle=\sum_{i_{k}=1}^{|w|}\mathfrak{h}_{i_{k}}(w[1{:}i_{k}])\begin{subarray}{c}\text{{\penalty\ \penalty\ by definition of a bimachine with external
marble functions}}\end{subarray}

\displaystyle=\sum_{i_{k}=1}^{|w|}\sum_{\{\!\!\{i_{1}\leq\cdots\leq i_{k{-}1}\}\!\!\}\subseteq{[1{:}i_{k}]}}\operatorname{\textsf{prod}}_{\mathcal{M}_{\mathfrak{h}_{i_{k}}}}^{w[1{:}i_{k}]}\left(\{\!\!\{i_{1},\dots,i_{k{-}1}\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ by induction hypothesis}}\end{subarray}

\displaystyle=\sum_{\{\!\!\{i_{1}\leq\dots\leq i_{k{-}1}\leq i_{k}\}\!\!\}\subseteq{[1{:}|w|]}}\operatorname{\textsf{prod}}_{\mathcal{M}_{\mathfrak{h}_{i_{k}}}}^{w[1{:}i_{k}]}\left(\{\!\!\{i_{1},\dots,i_{k{-}1}\}\!\!\}\right)

\displaystyle=\sum_{\{\!\!\{i_{1}\leq\dots\leq i_{k}\}\!\!\}\subseteq{[1{:}|w|]}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i_{1},\dots,i_{k}\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ by definition of }}\operatorname{\textsf{prod}}_{\mathcal{M}}.\end{subarray}

∎

We now show how to decompose a production
when one set is split.

Definition 62
.

We say that
(r_{1},\dots,r_{n})\in\mathbb{N}^{n}

is a
k
-sum if
n\geq 0
and
r_{1}+\cdots+r_{n}=k
.
We denote by
\Sigma_{k}
the set of

k
-sums.

Sublemma 63
.

Let
\mathcal{M}
be a
k
-marble bimachine,
w\in A^{*}
,

I_{1},\dots,I_{n}
be disjoint subsets of
[1{:}|w|]

and
(r_{1},\dots,r_{n})\in\Sigma_{k}
.
Assume that
I_{1}=J\uplus J^{\prime}
, then:

\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{I_{1}{\ddagger}r_{1},\dots,I_{n}{\ddagger}r_{n}\}\!\!\}\right)=\sum_{{(j,j^{\prime})\in\Sigma_{r_{1}}}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{J{{\ddagger}}j,J^{\prime}{\ddagger}j^{\prime},I_{2}{{\ddagger}}r_{2},\dots,I_{n}{{\ddagger}}r_{n}\}\!\!\}\right).

Proof.

By definition of productions and since the sets are disjoint, we have:

\displaystyle\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{I_{1}{\ddagger}r_{1},\dots,I_{n}{\ddagger}r_{n}\}\!\!\}\right)

\displaystyle=\sum_{\begin{subarray}{c}\{\!\!\{i^{1}_{1},\dots,i^{1}_{r_{1}}\}\!\!\}\subseteq I_{1}\end{subarray}}\cdots\sum_{\begin{subarray}{c}\{\!\!\{i^{n}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\subseteq I_{n}\end{subarray}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i^{1}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\right)

\displaystyle=\sum_{\begin{subarray}{c}0\leq j\leq r_{1}\\
\{\!\!\{i^{1}_{1},\dots,i^{1}_{j}\}\!\!\}\subseteq J\\
\{\!\!\{i^{1}_{j+1},\dots,i^{1}_{r_{1}}\}\!\!\}\subseteq J^{\prime}\end{subarray}}\sum_{\begin{subarray}{c}\{\!\!\{i^{2}_{1},\dots,i^{2}_{r_{2}}\}\!\!\}\subseteq I_{2}\end{subarray}}\cdots\sum_{\begin{subarray}{c}\{\!\!\{i^{n}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\subseteq I_{n}\end{subarray}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i^{n}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\right)

The last line is obtained since
J
and
J^{\prime}
are disjoint. It is easy
to see that it corresponds to the expression we are looking for.
∎

This result is generalized by induction to
any partition of
I_{1}
in Sublemma
64
.

Sublemma 64
.

Let
\mathcal{M}
be a
k
-marble bimachine,
w\in A^{*}
,

I_{1},\dots,I_{n}
be disjoint subsets of
[1{:}|w|]

and

Assume that

,

Proof.

The result is shown by induction on

with Sublemma

.
∎

,

\displaystyle f(w)

\displaystyle=\sum_{(r_{1},\dots,r_{n})\in\Sigma_{k}}\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{J_{1}{\ddagger}r_{1},\dots,J_{n}{\ddagger}r_{n}\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ \penalty\ by Sublemma\penalty\ \ref{slem:f-prod} and

B.2
Proof of Proposition-Definition
34

We shall in fact show Proposition-Definition
67
,
which is a generalization of Proposition-Definition
34
.
It shall be useful in the rest of these appendices.

Sublemma 66
.

Let
\mathcal{M}=(A,M,\mu,\mathfrak{H},\lambda)
be a
k
-marble bimachine.
Let
a_{1},\dots,a_{n}\in A
,
(r_{1},\dots,r_{n})\in\Sigma_{k}
,

w\coloneqq v_{0}a_{1}\cdots a_{n}v_{n}\in A^{*}
and

w^{\prime}\coloneqq v^{\prime}_{0}a_{1}\cdots a_{n}v^{\prime}_{n}\in A^{*}

such that
\mu(v_{j})=\mu(v^{\prime}_{j})
for all
0\leq j\leq n
.
For
1\leq j\leq n
let
i_{j}\in[1{:}|w|]
(resp.
i^{\prime}_{j}\in[1{:}|w^{\prime}|]
) be the position
of
a_{j}
in
w
(resp.
w^{\prime}
). Then

\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i_{1}{\ddagger}r_{1},\dots,i_{n}{\ddagger}r_{n}\}\!\!\}\right)=\operatorname{\textsf{prod}}_{\mathcal{M}}^{w^{\prime}}\left(\{\!\!\{i^{\prime}_{1}{\ddagger}r_{1},\dots,i^{\prime}_{n}{\ddagger}r_{n}\}\!\!\}\right).

Proof.

The proof is done by induction on
k\geq 1
.
For
k=1
the base case is obvious, let us assume that
k=2
.
Without loss of generality assume that
r_{n}\geq 1
.
Let
\mathfrak{h}\coloneqq\lambda(\mu(w[1{:}i_{n}{-}1]),w[i_{n}],\mu(w[i_{n}{+}1{:}|w|]))

and
\mathfrak{h}^{\prime}\coloneqq\lambda(\mu(w^{\prime}[1{:}i^{\prime}_{n}{-}1]),w[i^{\prime}_{n}],\mu(w[i^{\prime}_{n}{+}1{:}|w^{\prime}|]))
.
Note that
i_{1}<\cdots<i_{n}
and
i^{\prime}_{1}<\cdots<i^{\prime}_{n}
.
Thanks to the hypotheses of Sublemma
66
we get
\mathfrak{h}=\mathfrak{h}^{\prime}
.
Let
\mathcal{M}_{\mathfrak{h}}
be the submachine computing
\mathfrak{h}
, we get:

\displaystyle\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i_{1}{\ddagger}r_{1},\dots,i_{n}{\ddagger}r_{n}\}\!\!\}\right)

\displaystyle=\operatorname{\textsf{prod}}_{\mathcal{M}_{\mathfrak{h}}}^{w[1{:}i_{n}]}\left(\{\!\!\{i_{1}{\ddagger}r_{1},\dots,i_{n}{\ddagger}(r_{n}{-}1)\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ \penalty\ by definition}}\end{subarray}

\displaystyle=\operatorname{\textsf{prod}}_{\mathcal{M}_{\mathfrak{h}}}^{w^{\prime}[1{:}i^{\prime}_{n}]}\left(\{\!\!\{i^{\prime}_{1}{\ddagger}r_{1},\dots,i^{\prime}_{n}{\ddagger}(r_{n}{-}1)\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ \penalty\ by induction hypothesis}}\end{subarray}

\displaystyle=\operatorname{\textsf{prod}}_{\mathcal{M}}^{w^{\prime}}\left(\{\!\!\{i^{\prime}_{1}{\ddagger}r_{1},\dots,i^{\prime}_{n}{\ddagger}r_{n}\}\!\!\}\right)\begin{subarray}{c}\text{{\penalty\ \penalty\ \penalty\ by definition}}\end{subarray}.

∎

Let us now give an extension of Equation
1

to state our generalization of Proposition-Definition
34
.
Let
(r_{1},\dots,r_{n})\in\Sigma_{k}
,

w\coloneqq v_{0}u_{1}\cdots u_{n}v_{n}\in A^{*}
, and
for
1\leq i\leq n
, let
I_{i}\subseteq[1{:}|w|]
be the set of positions corresponding to
w_{i}
.
We define:

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(v_{0}{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\bm{\rrbracket}}_{r_{1}}v_{1}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{n}\bm{\rrbracket}}_{r_{n}}v_{n}\right)\coloneqq\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{I_{1}{\ddagger}r_{1},\dots,I_{n}{\ddagger}r_{n}\}\!\!\}\right).

Note that Equation
1
is the case when

r_{i}=1
for all
1\leq i\leq n
(thus
n=k
). On the other
hand, if
r_{i}=0
, then the element
{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{i}\bm{\rrbracket}}_{r_{i}}
can be equivalently replaced
by
\mu(u_{i})
(it means that in fact
u_{i}
is not
used when making the production).

Proposition-Definition 67
.

Let
\mathcal{M}=(A,M,\mu,\mathfrak{H},\lambda)
be a
k
-marble bimachine.
Let
(r_{1},\dots,r_{n})\in\Sigma_{k}
,
v_{0}u_{1}\cdots u_{n}v_{n}\in A^{*}

and
v^{\prime}_{0}u_{1}\cdots u_{n}v^{\prime}_{n}\in A^{*}

such that
\mu(v_{i})=\mu(v^{\prime}_{i})
for all
0\leq i\leq n
.
Then we have

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(v_{0}{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\bm{\rrbracket}}_{r_{1}}v_{1}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{n}\bm{\rrbracket}}_{r_{n}}v_{n}\right)=\operatorname{\textsf{prod}}_{\mathcal{M}}\left(v^{\prime}_{0}{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\bm{\rrbracket}}_{r_{1}}v^{\prime}_{1}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{n}\bm{\rrbracket}}_{r_{n}}v^{\prime}_{n}\right).

Let
m_{i}\coloneqq\mu(v_{i})=\mu(v^{\prime}_{i})
, we define

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(m_{0}{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\bm{\rrbracket}}_{r_{1}}m_{1}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{n}\bm{\rrbracket}}_{r_{n}}m_{n}\right)

as the previous value.

Proof.

Let
w\coloneqq v_{0}u_{1}\cdots u_{n}v_{n}
and
w^{\prime}\coloneqq v_{0}u^{\prime}_{1}\cdots u^{\prime}_{n}v_{n}
.
Let
I_{1},\dots,I_{n}\subseteq[1{:}|w|]
(resp.
I^{\prime}_{1},\dots,I^{\prime}_{n}\subseteq[1{:}|w^{\prime}|]
)
be the sets of positions of
u_{1},\dots,u_{n}
in
w
(resp.
w^{\prime}
). For
1\leq i\leq n
,
let
\sigma_{i}:I_{i}\rightarrow I^{\prime}_{i}
be the unique monotone (for
<
) bijection
between these sets.
Then if
\{\!\!\{i^{1}_{1},\dots,i^{1}_{r_{1}}\}\!\!\}\subseteq I_{1},\dots,\{\!\!\{i^{n}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\subseteq I_{n}
,
it follows from Sublemma
66
that:

\displaystyle\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{i^{1}_{1},\dots,i^{1}_{r_{1}}\}\!\!\}\uplus\cdots\uplus\{\!\!\{i^{n}_{1},\dots,i^{n}_{r_{n}}\}\!\!\}\right)

\displaystyle=\operatorname{\textsf{prod}}_{\mathcal{M}}^{w^{\prime}}\left(\{\!\!\{\sigma_{1}(i^{1}_{1}),\dots,\sigma_{1}(i^{1}_{r_{1}})\}\!\!\}\uplus\cdots\uplus\{\!\!\{\sigma_{n}(i^{n}_{1}),\dots,\sigma_{n}(i^{n}_{r_{n}})\}\!\!\})\right).

Finally we get
\operatorname{\textsf{prod}}_{\mathcal{M}}^{w}\left(\{\!\!\{I_{1}{\ddagger}r_{1},\dots,I_{n}{\ddagger}r_{n}\}\!\!\}\right)=\operatorname{\textsf{prod}}_{\mathcal{M}}^{w^{\prime}}\left(\{\!\!\{I^{\prime}_{1}{\ddagger}r_{1},\dots,I^{\prime}_{n}{\ddagger}r_{n}\}\!\!\}\right)
by summing
all the terms of the above form.
∎

B.3
Further results

In this subsection, we establish further properties of
productions which are to be used later.
We first give an analogous of Sublemma
64
,
in order to “split” the productions on the factors.

Lemma 68
.

Let
\mathcal{M}=(A,M,\mu,\mathfrak{H},\lambda)
be a
k
-marble bimachine.

Let
v_{1}\cdots v_{n}u_{1}\cdots u_{X}v^{\prime}_{1}\cdots v^{\prime}_{n^{\prime}}\in A^{*}
and

(\delta_{1},\dots,\delta_{n},r,\delta^{\prime}_{1},\dots,\delta^{\prime}_{n^{\prime}})\in\Sigma_{k}
.

Let
\mathcal{L}\penalty\ \coloneqq{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v_{1}\bm{\rrbracket}}_{\delta_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v_{p}\bm{\rrbracket}}_{\delta_{n}}

and
\mathcal{R}\coloneqq{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v^{\prime}_{1}\bm{\rrbracket}}_{\delta^{\prime}_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v^{\prime}_{p^{\prime}}\bm{\rrbracket}}_{\delta^{\prime}_{n^{\prime}}}
,
then we have:

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\cdots u_{X}\bm{\rrbracket}}_{r}\penalty\ \mathcal{R}\right)=\sum_{(r_{1},\dots,r_{X})\in\Sigma_{r}}\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{1}\bm{\rrbracket}}_{r_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u_{X}\bm{\rrbracket}}_{r_{X}}\penalty\ \mathcal{R}\right)

Proof.

We consider those productions as productions
of sets of positions within the word
v_{1}\cdots v_{n}u_{1}\cdots u_{X}v^{\prime}_{1}\cdots v^{\prime}_{n^{\prime}}
.
The result follows from Sublemma
64

by choosing
J_{1},\dots,J_{X}
as the positions
corresponding to
u_{1},\dots,u_{X}
,
and using Proposition-Definition
67
.
∎

We now want to describe in a more precise way
what happens in Lemma
68

when
u_{1}=\cdots=u_{X}=u
and
\mu(u)
is
an idempotent. This is the purpose of Lemma
69

below. Given
r\geq 0
and
(r_{1},\dots,r_{X})\in\Sigma_{r}

we define
\operatorname{\textsf{shape}}(r_{1},\dots,r_{X})
as the tuple
obtained from
(r_{1},\dots,r_{X})
by replacing
the maximal blocks of the form

by a single
0
.
For instance
\operatorname{\textsf{shape}}(0,1,0,0,0,1,2)=(0,1,0,1,2)\in\Sigma_{4}
.
Let
\operatorname{\textsf{Shapes}}_{r}
be the set of all
shapes of elements of
\Sigma_{r}

(note that
\operatorname{\textsf{Shapes}}_{r}
is a finite subset of
\Sigma_{r}
).

Lemma 69
.

Let
\mathcal{M}=(A,M,\mu,\mathfrak{H},\lambda)
be a
k
-marble bimachine.

Let
(\delta_{1},\dots,\delta_{n},r,\delta^{\prime}_{1},\dots,\delta^{\prime}_{n})\in\Sigma_{k}

and
v_{1},\dots,v_{n},u,v^{\prime}_{1},\dots,v^{\prime}_{n^{\prime}}\in A^{*}
.
Assume that

is an idempotent.
Let
\mathcal{L}\penalty\ \coloneqq{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v_{1}\bm{\rrbracket}}_{\delta_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}v_{n}\bm{\rrbracket}}_{\delta_{n}}

.
If

, then:

1.

\displaystyle\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u^{X}\bm{\rrbracket}}_{r}\penalty\ \mathcal{R}\right)=\sum_{s=(s_{1},\dots,s_{Y})\in\operatorname{\textsf{Shapes}}_{r}}P_{s}(X)\times\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{s_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{s_{Y}}\penalty\ \mathcal{R}\right)

where

is a polynomial in
X
of degree at most
r

which is independent of
\mathcal{L},\mathcal{R}
and
u
;

2.

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u^{X}\bm{\rrbracket}}_{r}\penalty\ \mathcal{R}\right)
is a polynomial
in
X
of degree at most
r
;

3.

the coefficient in
X
of
the polynomial
\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u^{X}\bm{\rrbracket}}_{r}\penalty\ \mathcal{R}\right)
is:

(a)

if

;

(b)

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ e{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}e\penalty\ \mathcal{R}\right)
if

.

Proof.

We have

\displaystyle\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u^{X}\bm{\rrbracket}}_{r}\penalty\ \mathcal{R}\right)=\sum_{(r_{1},\dots,r_{X})\in\Sigma_{r}}\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{r_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{r_{X}}\penalty\ \mathcal{R}\right)
by Lemma

.
We shall recombine several terms of this sum thanks to the claim below.

Claim 70
.

Let
(r_{1},\dots,r_{X})\in\Sigma_{r}

and
(s_{1},\dots,s_{Y})\coloneqq\operatorname{\textsf{shape}}(r_{1},\dots,r_{X})
, then:

\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{r_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{r_{X}}\penalty\ \mathcal{R}\right)=\operatorname{\textsf{prod}}_{\mathcal{M}}\left(\mathcal{L}\penalty\ {\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{s_{1}}\cdots{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{s_{Y}}\penalty\ \mathcal{R}\right)

{claimproof}

Transforming several consecutive
{\color[rgb]{0.1,0.1,1}\bm{\llbracket}u\bm{\rrbracket}}_{0}

in a single one corresponds to transforming the
concatenation of several idempotent
e=\mu(u)
in a single one.

Given
s\in\operatorname{\textsf{Shapes}}_{r}
