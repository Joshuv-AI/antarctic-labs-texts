New Distributed Source Encryption Framework
Yasutada Oohama and Bagus Santoso

Abstract
We pose and investigate the distributed secure source coding based on the common key cryptosystem. This cryptosystem includes the secrecy amplification problem for distributed encrypted sources with correlated keys using post-encryption-compression, which was posed investigated by Santoso and Oohama. In this paper we propose a new security criterion which is more natural compared with the commonly used security criterion which is based on the upper-bound of mutual information between the plaintext and the ciphertext. Under this criterion, we establish the necessary and sufficient condition for the secure transmission of correlated sources.

III-A

Proposed Security Criterion

In this section, we introduce our proposed security criterion.
In the following arguments all logarithms are taken
to the base natural.
The adversary
{\cal A}
tries to estimate

({{\mbox{\boldmath$X$}}_{1}},{{\mbox{\boldmath$X$}}_{2}})\in\mathcal{X}_{1}\times\mathcal{X}_{1}^{n}

from

(C_{1}^{m_{1}},

C_{2}^{m_{2}})
.

The mutual information (MI) between
({\mbox{\boldmath$X$}}_{1},{\mbox{\boldmath$X$}}_{2})
and

(C_{1}^{m_{1}},C_{2}^{m_{2}})

denoted by

\Delta_{\rm MI}^{(n)}:=I(C_{1}^{m_{1}}C_{2}^{m_{2}};{\mbox{\boldmath$X$}}_{1}{\mbox{\boldmath$X$}}_{2})

indicates a leakage of information on
({\mbox{\boldmath$X$}}_{1},{\mbox{\boldmath$X$}}_{2})

from
(C_{1}^{m_{1}},C_{2}^{m_{2}})
.
In this sense it seems to be quite natural
to adopt the mutual information
\Delta_{\rm MI}^{(n)}

as a security criterion.
On the other hand,
directly using
\Delta_{\rm MI}^{(n)}
as a security criterion
of the cyptosystem has some problem that this value
depends on the statistical property of
({\mbox{\boldmath$X$}}_{1},{\mbox{\boldmath$X$}}_{2})

In this paper we propose a new security criterion, which is based on

but overcomes the above problem.

Definition 1

Let
(\overline{\mbox{\boldmath$X$}}_{1},\overline{\mbox{\boldmath$X$}}_{2})

be an arbitrary random variable
taking values in

The maximum mutual information criterion denoted

\displaystyle\Delta_{{\rm max-MI}}^{(n)}=\Delta_{{\rm max-MI}}^{(n)}(\Phi_{1}^{(n)},\Phi_{2}^{(n)},\Psi^{(n)}|{p}_{K_{1}K_{2}}^{n})

\displaystyle:=\max_{p_{\overline{\mbox{\tiny\boldmath$X$}}_{1}\overline{\mbox{\tiny\boldmath$X$}}_{2}}\in{\cal P}({\cal D}^{(n)})}I(\overline{C}_{1}^{m_{1}}\overline{C}_{2}^{m_{2}};\overline{\mbox{\boldmath$X$}}_{1}\overline{\mbox{\boldmath$X$}}_{2}).

Intuitively, one can see

\displaystyle\overline{\Delta}_{{\rm max-MI}}^{(n)}=\overline{\Delta}_{{\rm max-MI}}^{(n)}(\Phi_{1}^{(n)},\Phi_{2}^{(n)}|{p}_{K_{1}K_{2}}^{n})

\displaystyle:=\max_{p_{\overline{\mbox{\tiny\boldmath$X$}}_{1}\overline{\mbox{\tiny\boldmath$X$}}_{2}}\in{\cal P}({\cal X}_{1}^{n}\times{\cal X}_{2}^{n})}I(\overline{C}_{1}^{m_{1}}\overline{C}_{2}^{m_{2}};\overline{\mbox{\boldmath$X$}}_{1}\overline{\mbox{\boldmath$X$}}_{2}).

By definition it is obvious that

and

\Delta_{\rm max-MI}^{(n)}\leq\overline{\Delta}_{{\rm max-MI}}^{(n)}
.
We have the following proposition

,

\Delta_{{\rm max-MI}}^{(n)}
, and

\overline{\Delta}_{{\rm max-MI}}^{(n)}

Proposition 1

a)

We have the following:

\max\{{\Delta}_{{\rm MI}}^{(n)},{\Delta}_{{\rm max-MI}}^{(n)}\}\leq\overline{\Delta}_{{\rm max-MI}}^{(n)}.

b)

We assume that

{\cal D}^{(n)}\subseteq{\rm Supp}(p_{X_{1}X_{2}}^{n})={\rm Supp}^{n}(p_{X_{1}X_{2}}).

Under this assumption, if

\Delta_{\rm MI}^{(n)}=

I(C_{1}^{m_{1}}C_{2}^{m_{2}};{\mbox{\boldmath$X$}}_{1}{\mbox{\boldmath$X$}}_{2})=0,

then we have
\Delta_{{\rm max-MI}}^{(n)}=0
.
This implies that
\Delta_{{\rm max-MI}}^{(n)}
is valid as a
measure of information leakage.

c)

We have the following.

\displaystyle{\Delta}_{{\rm max-MI}}^{(n)}

\displaystyle\geq\begin{array}[t]{ll}\max\{&m_{1}\log{|{\cal X}_{1}|}-nH(K_{1}),\\
&m_{2}\log{|{\cal X}_{2}|}-nH(K_{2}),\\
&m_{1}\log{|{\cal X}_{1}|}+m_{2}\log{|{\cal X}_{2}|}-nH(K_{1}K_{2})\}.\end{array}

III-B

Strong Converse for the Distributed Source Encryption

To state our results on
\mathcal{R}(\varepsilon,\delta|p_{X_{1}X_{2}},p_{K_{1}K_{2}})
for
(\varepsilon,\delta)\in[0,\varepsilon_{0}]\times(0,1)

define the following two regions:

\displaystyle\mathcal{R}_{\mathrm{sw}}(p_{X_{1}X_{2}}):=\{(R_{1},R_{2}):\

\displaystyle R_{1}\geq H(X_{1}|X_{2}),

\displaystyle R_{2}\geq H(X_{2}|X_{1}),

\displaystyle R_{1}+R_{2}\geq H(X_{1}X_{2})\},

\displaystyle\mathcal{R}_{\mathrm{key}}(p_{K_{1}K_{2}}):=\{(R_{1},R_{2}):\

\displaystyle R_{1}\leq H(K_{1}),R_{2}\leq H(K_{2}),

\displaystyle R_{1}+R_{2}\leq H(K_{1}K_{2})\}.

Santoso and Oohama

[
1
]
,

[
2
]

proved that the bound

,

p_{K_{1}K_{2}})

Theorem 1

For each

Outline of the proof of this theorem will be given in the
next section. We next derive one outer bound by a simple
observation based on previous works on the distributed
source coding for correlted sources.
From the communication
scheme we can see that the common key cryptosysytem

Theorem 2

For each
(\varepsilon,\delta)\in(0,\varepsilon_{0}]\times(0,1)

\displaystyle\mathcal{R}(\varepsilon,\delta|p_{X_{1}X_{2}},p_{K_{1}K_{2}})\subseteq\mathcal{R}_{\mathrm{sw}}(p_{X_{1}X_{2}}).

In this paper we prove that
for some
\varepsilon_{0}>0

the set

p_{K_{1}K_{2}})

\mathcal{R}(\varepsilon,\delta|p_{X_{1}X_{2}},

As an immediate consequence of

Proposition 2

If

Theorem 3

For each

\displaystyle\mathcal{R}(\varepsilon,\delta|p_{X_{1}X_{2}},p_{K_{1}K_{2}})\subseteq\mathcal{R}_{\mathrm{key}}(p_{K_{1}K_{2}}).

\displaystyle=\mathcal{R}(p_{X_{1}X_{2}},p_{K_{1}K_{2}})=\mathcal{R}(\varepsilon,\delta|p_{X_{1}X_{2}},p_{K_{1}K_{2}}).
