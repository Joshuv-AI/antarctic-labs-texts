Abstract
In this paper, we first construct thermofield double states for bosonic string theory in the light-cone gauge. We then obtain a coherent-thermal string state and a thermal-coherent string state. We use the covariance matrix approach to calculate the circuit complexity of coherent-thermal string states. In this approach, we generate the optimal geodesics by a horizontal string generator, and then obtain the circuit complexity using the length of the minimal geodesics in the group manifold.

2
TFD state of quantum bosonic strings

In this section, we shall build the TFD state for the bosonic string, and then they will be used to construct TC and CT states for strings. This will be done by using the tensor product of two Hilbert spaces for string states. Then CT states will be used for the study of circuit complexity.

2.1
String State

Here, we shall briefly discuss the required bosonic string quantization framework for building up the corresponding string state. The Polyakov action, which describes the world sheet of bosonic string theory, can be written as

\displaystyle\textbf{S}=\frac{1}{4\pi\alpha^{\prime}}\int d\sigma^{2}\eta^{\alpha\beta}\partial_{\alpha}X_{\mu}\partial_{\beta}X^{\mu}

(2.1)

Here
\alpha^{\prime}
is related to the length of string
l_{s}^{2}
. We can apply the
Neumann boundary conditions for open strings, and write the solution to the equations of motion obtained from the Polyakov action as

\displaystyle X^{\mu}\left(\tau,\sigma\right)=x^{\mu}+l_{s}\tau p^{\mu}+il_{s}\sum_{m>0}\frac{1}{m}{{\alpha}}^{\mu}_{m}e^{-im\tau}cos(m\sigma)

(2.2)

The Polyakov action has gauge degrees of freedom, so before quantizing this theory, we have to remove these unphysical gauge degrees of freedom. Usually, the BRST formalism in conformal gauge is used to quantize this theory
[
63
]
. Thus, after adding a gauge fixing term in the conformal gauge, the corresponding ghost term is also added to the Polyakov action. The sum of the Polyakov action with this gauge fixing term and ghost term represents a new effective action. This new effective action is invariant under the BRST transformation. The Noether charge corresponding to the BRST invariance of the effective action is represented by the BRST charge
Q
. The physical states of the theory are defined to be the states which satisfy
Q|\rm{phy}>=0
. It has been demonstrated that the BRST quantization in conformal gauge is equivalent to light-cone quantization
[
64
,
65
]
. Thus, it is possible to consistently analyze string theory in light-cone gauge
[
66
,
67
]
. In fact, in a light-cone gauge, the physical sector decouples from the ghost sector of the theory
[
68
,
69
,
70
]
. This decoupling is similar to the decoupling which occurs in ordinary electrodynamics
[
71
]
. Due to this decoupling, it is possible to use the light-cone gauge, and directly analyze the physical sector of the theory
[
66
,
67
]
. It is important to note that the light-cone gauge string theory is physically equivalent to the conformal field string theory. In fact, the finite field-dependent BRST transformation can be used to relate the generating functional for string theory in light-cone gauge to the generating functional for string theory in conformal gauge
[
72
]
.

Thus, in a light-cone gauge, we can directly remove the gauge degrees of freedom, and analyze the physical string states. In the light-cone gauge, first, the target space coordinates are defined as
\{X^{+},X^{-}\},[X^{i}]_{i=1}^{24}
, where
X^{+}=(X^{0}+X^{25}),
and
X^{-}=(X^{0}-X^{25})
. Then it is observed that the
X^{+}
direction does not contain any string oscillations, and the oscillation in the
X^{-}
direction can be expressed in terms of other string oscillations. Therefore, in the light-cone gauge, we can only deal with the physical string oscillations in
[X^{i}]_{i=1}^{24}
directions, and these can be used to obtain information about the theory. Thus, the commutation algebras in light-cone gauge can be expressed as
[{\alpha}_{m}^{i},{\alpha}_{-m}^{j}]=m\eta^{ij}
. In this scenario, it is conventional to identify the momenta of the center of mass with the zero mode frequency as
\alpha_{0}^{i}={l_{s}}{}p^{i}/\sqrt{2}=\sqrt{2\pi T}p^{i}
with
i=1\cdots 24
. It is straightforward to show that the negative and positive frequency modes
{\alpha}_{-m}^{i},{\alpha}_{m}^{i}
behave as raising and lowering operators, respectively, with the total number operator being
{N}=\textstyle\sum_{m>0}\sum_{i=1}^{24}mN_{i,m}=\sum_{m>0}\sum_{i=1}^{24}({\alpha}_{-m}^{i}{\alpha}_{m}^{i})
. Thus, the ground state
|0;p\rangle
is defined to be annihilated by the lowering operators and to be an eigenstate of the center of mass momenta,

{\alpha}_{m}^{i}|0;p\rangle=0,
with
m>0,
and
{p}^{i}|0;p\rangle=p^{i}|0;p\rangle
.
Within the framework, the excited string states can now be built by acting the raising operator
{\alpha}_{-m}^{i}
on the ground state of momentum
p
as
\textstyle{{\alpha}_{-m}^{i}|{0;p}\rangle}
. By using the ground state raising operators
\alpha_{-m}^{i}
for
m>0
, the generic string state can be created.
[
76
]

\displaystyle|{N;p}\rangle

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}{\frac{1}{\sqrt{{m}^{N_{i,m}}N_{i,m}!}}}{({{\alpha}}_{-m}^{i})}^{N_{i,m}}|{0;p}\rangle

(2.3)

where
N_{i,m}
is the occupation number of excitations of the
m
th mode in the transverse
i
direction. The energy of the string goes like the level (number operator),

N=\sum_{i=1}^{24}\sum_{m=1}^{\infty}mN_{i,m}

(2.4)

It may be noted that unlike usual quantum mechanics, where such states are obtained using the Hamiltonian, here they are obtained using an alternative operator called the mass-squared operator
{M}^{2}

[
62
]
. This mass operator can, in turn, be related to the number operator
N
using the mass-shell condition
[
67
]

{M}^{2}=p^{\mu}p_{\mu}=\frac{1}{\alpha^{\prime}}\left(\sum_{m>0}\sum_{i=1}^{24}\alpha_{-m}^{i}.\alpha_{m}^{i}-{a}\right)=\frac{1}{\alpha^{\prime}}(N-a),

(2.5)

It may be noted that the mass-shell condition related
M^{2}
to
N
, and
N
is in turn related to the occupation number using
{N}=\textstyle\sum_{i=1}^{24}\sum_{m>0}mN_{i,m}
. The value of the normal ordering constant for open strings is
a=1
, and so the lowest state is a tachyonic scalar (with
{M}^{2}<0
).

Thus, even though there is a mathematical similarity at the level of commutation algebra with a harmonic oscillator, the physics of this system described is very different
[
4
]
. For simple quantum mechanical systems, like a harmonic oscillator, different states are classified by their energies, and the circuit complexity is calculated with respect to those states. Here, the different modes of a string represent different particles, and the circuit complexity is used to investigate the properties of this internal dynamics of string theory. However, due to the mathematical similarity of the commutator algebra of string theory and a harmonic oscillator, standard methods can be used to mathematically analyze string theory
[
62
]
.
By following the standard method of constructing the coherent states, we can define
{\alpha}_{m}|\varphi_{m}\rangle=\varphi_{m}|\varphi_{m}\rangle
to obtain the coherent state of a single world-sheet mode in terms of
|k\rangle
string states, the complete methodology can be seen in Appendix,

|\varphi^{i}_{m}\rangle=\sum_{n=0}^{\infty}\frac{\varphi_{m}^{n}e^{{-\frac{|\varphi^{i}_{m}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}|k\rangle.

(2.6)

where
k=nm
.
By repeating this procedure for different modes, the total coherent state can be obtained via the following relation

|\Phi\rangle=\prod_{m\geq 1}\prod_{i=1}^{24}|\varphi^{i}_{m}\rangle.

(2.7)

It may be noted that the same expression of the single-mode coherent state
(
2.6
)
can be obtained by operating the factorized displacement operator
{D}(\varphi^{i}_{m})
on the ground state
|0;p\rangle

|\varphi^{i}_{m}\rangle={D}(\varphi^{i}_{m})|0;p\rangle,\quad\text{with}\quad{D}(\varphi^{i}_{m})=\exp(\varphi^{i}_{m}{\alpha}^{i}_{-m}-{\varphi^{i*}_{m}{\alpha}^{i}_{m}}).

(2.8)

The time evolution of the coherent state
(
2.7
)
is calculated as follows (with
k=nm
)

\displaystyle|\Phi(t)\rangle

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\sum_{n=0}^{\infty}e^{-i\sqrt{\frac{{N}_{i,m}-1}{\alpha^{\prime}}}t}\frac{\varphi_{m}^{n}e^{{-\frac{|\varphi^{i}_{m}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}|k\rangle

(2.9)

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\sum_{n=0}^{\infty}\frac{\varphi_{m}^{n}e^{{-\frac{|\varphi^{i}_{m}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}{\Big(1-i{\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}t\Big)}|k\rangle,

which will be used later in our study.
It may be noted that the momentum of the string
p
is related to the occupation number by the mass-shell condition. Average of the mass-squared can be written as
\langle\hat{M}^{2}\rangle=\langle\Phi|\hat{M}^{2}|\Phi\rangle
. String coherent state
|\Phi\rangle
can be expressed in terms of
|k\rangle
states, and are not the mass eigenstates as seen in Appendix.

Thus, the total momentum of the coherent state can occur through various combinations of modes (which physically correspond to different particles). Hence, it is possible to have different occupation numbers for the same momentum
p
. However, each of those combinations has to satisfy the mass-shell conditions, as the mass-shell condition related the operator
M^{2}
to
N
, which in turn is related to the occupation number as
N_{i,m}
.

Now we would like to introduce the new set of states
{|{N;p,\Phi\rangle}}
which will be used to construct suitable thermal states. These states will be produced by displacement operator acting upon the energy eigenstates
[
61
]

|{N;p,{\Phi}\rangle}\equiv{D{(\Phi)}}|{N;p}\rangle

(2.10)

where the displacement operator is defined as

{D{(\Phi)}}\equiv{\prod_{m\geq 1}\prod_{i=1}^{24}{D{(\varphi_{m}^{i})}}}\equiv{\prod_{m\geq 1}\prod_{i=1}^{24}\exp{(\varphi^{i}\alpha^{i}_{-m}-\varphi^{*i}\alpha^{i}_{m})}}

(2.11)

These new sets of states are now constructed using the operators,

{b}^{i}_{-m}\equiv{D{(\varphi^{i}_{m})}}{\alpha}_{-m}^{i}{{D}^{-1}{(\varphi^{i}_{m})}}
.
By using Baker-Campbell-Hausdorff (BCH) formula, we can write for total strings

{b}^{i}_{-m}\equiv\big[\alpha_{-m}^{i}-m\phi^{*i}_{m}\big]
.
So in this case the string state can be viewed as a ground state because of

{b}^{i}_{m}|{\varphi^{i}}_{m}\rangle=0
, such that we have

\displaystyle{b}^{i}_{m}|{N_{i,m};p,{\varphi^{i}}_{m}}\rangle

\displaystyle=

\displaystyle\sqrt{(N_{i,m};p)}\Big|{((N_{i,m};p)-{m}),{\varphi^{i}}_{m}}\Big\rangle

(2.12)

\displaystyle{b}^{i}_{-m}|{N_{i,m};p,{\varphi^{i}}_{m}}\rangle

\displaystyle=

\displaystyle\sqrt{(N_{i,m};p)+{m}}\Big|((N_{i,m};p)+{m}),\varphi^{i}_{m}\Big\rangle

(2.13)

So that we can obtain our general string state as

\displaystyle|{N;p,{\Phi}}\rangle

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\Bigg[{\frac{({b}^{i}_{-m})^{N_{i,m}}}{\sqrt{{m}^{N_{i,m}}N_{i,m}!}}}\Bigg]|{0;p,{\varphi^{i}}_{m}}\rangle

(2.14)

This is the expression for string state. This state is obtained by the action of these new operators
B=\prod_{m\geq 1}\prod_{i=1}^{24}{b}^{i}_{-m}
on the vacuum state
|{0;p,{\Phi}}\rangle
.

2.2
Thermal String State

Finite temperature problems in thermal theories are built on the zero-temperature formulations of the associated theory. Therefore, before delving into the construction of the bosonic string TFD state, one has to define the vacuum. Let us start with the consideration that the zero-temperature vacuum consists of two components, the left vacuum
|0;p,R\rangle
(living in a Hilbert space
\mathcal{H}^{(L^{i})}
), and the right vacuum
|0;p,R\rangle
(living in another Hilbert space
\mathcal{H}^{(R^{i})}
). Therefore, the composite space
\mathcal{H}
in which the vacuum
|0;p,L\rangle\otimes|0;p,R\rangle

[
4
]

\mathcal{H}=\prod_{i=1}^{24}\mathcal{H}^{(L^{i})}\otimes\mathcal{H}^{(R^{i})}.

The ladder operators
{{\alpha}^{L^{i}}_{m}},{{\alpha}^{L^{i}}_{-m}},{{\alpha}^{R^{i}}_{m}},{{\alpha}^{R^{i}}_{-m}}

\displaystyle[{\alpha}_{m}^{L^{i}},{\alpha}_{-m}^{L^{i}}]=[{\alpha}_{m}^{R^{i}},{\alpha}_{-m}^{R^{i}}]=m

\displaystyle[{\alpha}_{m}^{L^{i}},{\alpha}_{-m}^{R^{i}}]=[{\alpha}_{m}^{R^{i}},{\alpha}_{-m}^{L^{i}}]=0.

(2.17)

It should be noted that the vacuum state

with the commutation relations defined by
(
2.16
)
and
(
2.17

\displaystyle{\alpha}^{R^{i}}_{m}\rightarrow{a}^{R^{i}}_{m}(\beta)={U}_{m}(\beta){\alpha}^{R^{i}}_{m}{U}_{m}^{\dagger}(\beta)=\Big[\cosh\theta_{m}(\beta){\alpha}^{R^{i}}_{m}-\sinh\theta_{m}(\beta){\alpha}^{{L^{i}}\dagger}_{m}\Big],

\displaystyle[{\alpha}_{m}^{L^{i}}(\beta),{\alpha}^{R^{i}}_{-m}(\beta)]=[{\alpha}_{m}^{R^{i}}(\beta),{\alpha}^{L^{i}}_{-m}(\beta)]=0.

Here,

\displaystyle\cosh\theta_{m}(\beta)

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\Big[e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}{U}_{m}(\beta)|0;p,L\rangle|0;p,R\rangle\Big]

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\Big[e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{U}_{m}(\beta,t)|0;p,L\rangle|0;p,R\rangle\Big],

where
{U}_{m}(\beta,t)
and
{U}_{m}(\beta)
are unitarily equivalent, i.e.

{U}_{m}(\beta,t)=\prod_{i=1}^{24}e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}{U}_{m}(\beta)e^{it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}.

(2.33)

Collecting the expression of
{U}_{m}(\beta)
from
(
2.21
)
, we rewrite
(
2.33
)
as follows

{U}_{m}{(\beta,t)}=\prod_{i=1}^{24}\exp\left[\left(\theta{{}_{m}{(\beta)}}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}({\alpha}^{L^{i}}_{-m}{{\alpha}^{R^{i}}_{-m}}-{\alpha}^{L^{i}}_{m}{\alpha}^{R^{i}}_{m})e^{it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}\right)\right].

(2.34)

Now, we can use the BCH formula to calculate,

e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}({\alpha}^{L^{i}}_{-m}{{\alpha}^{R^{i}}_{-m}}-{\alpha}^{L^{i}}_{m}{\alpha}^{R^{i}}_{m})e^{it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}=e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{L^{i}}_{-m}{{\alpha}^{R^{i}}_{-m}}-{\alpha}^{L^{i}}_{m}{\alpha}^{R^{i}}_{m}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}.

(2.35)

The relation
(
2.35
)
simplifies
(
2.34
)
as

{U}_{m}{(\beta,t)}=\prod_{i=1}^{24}\exp\left[\Big(\left\{Z_{m}(\beta){\alpha}^{L^{i}}_{-m}{{\alpha}^{R^{i}}_{-m}}-Z_{m}^{\ast}(\beta){\alpha}^{L^{i}}_{m}{\alpha}^{R^{i}}_{m}\right\}\Big)\right],

(2.36)

where
Z_{m}(\beta)=\theta{{}_{m}{(\beta)}}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}
. We can rewrite
(
2.36
)
in a more compact Gaussian form by expressing the ladder operators in terms of the canonical variables
{\zeta}^{a}=\prod_{m}\prod_{i=1}^{24}{\zeta}^{a_{m}}_{L^{i},R^{i}}
with
{\zeta}^{a_{m}}_{L^{i},R^{i}}=({X}_{m}^{L^{i}},{X}_{m}^{R^{i}},{P}_{m}^{L^{i}},{P}_{m}^{R^{i}})

\displaystyle{\alpha}^{L^{i}}_{m}=\frac{1}{\sqrt{2}}\left({X}^{L^{i}}_{m}+i{P}^{L^{i}}_{m}\right),\quad{\alpha}^{R^{i}}_{m}=\frac{1}{\sqrt{2}}\left({X}^{R^{i}}_{m}+i{P}^{R^{i}}_{m}\right),

(2.37)

\displaystyle{\alpha}^{L^{i}}_{-m}=\frac{1}{\sqrt{2}}\left({X}^{L^{i}}_{m}-i{P}^{L^{i}}_{m}\right),\quad{\alpha}^{R^{i}}_{-m}=\frac{1}{\sqrt{2}}\left({X}^{R^{i}}_{m}-i{P}^{R^{i}}_{m}\right)

(2.38)

also, we can write the unitary operator for total string modes as,

{U}{(\beta,t)}=\prod_{m\geq 1}\prod_{i=1}^{24}\exp\left[-\frac{i}{2}K^{(0)}_{{a_{m}}{b_{m}}}{\zeta}^{a_{m}}_{L^{i},R^{i}}{\zeta}^{b_{m}}_{L^{i},R^{i}}\right],

(2.39)

where
K^{(0)}_{{a_{m}}{b_{m}}}
can be expressed as

K^{(0)}_{{a_{m}}{b_{m}}}=\theta_{m}(\beta)\left(\begin{array}[]{c c c c}0&\sin\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)&0&\cos\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)\\
\sin\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)&0&\cos\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)&0\\

\cos\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)&0&-\sin\Big(\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t\Big)&0\end{array}\right).

(2.40)

Therefore, it turns out that the TFD state is a Gaussian state along with an unimportant phase, and such a form will be useful for calculating the complexity in the covariance matrix approach as we will show later.

3
String Coherent State in Thermal Field

We are now ready to study the string coherent state in the thermal field. Before constructing the string thermal coherent
|\text{TC}\rangle_{s}
and coherent-thermal
|\text{CT}\rangle_{s}
states, we shall introduce the coherent state first. By following the standard definition, we can write the string coherent state as

|\gamma;p,L\rangle|\eta;p,R\rangle=\prod_{m\geq 1}\prod_{i=1}^{24}{D}_{m}(\gamma,\eta)|0;p,L\rangle|0;p,R\rangle

(3.1)

where the displacement operator is given by

{D}_{m}(\gamma,\eta)\equiv{D}_{m}^{L^{i}}(\gamma){D}_{m}^{R^{i}}(\eta)=\exp\left(\gamma{\alpha}^{L^{i}}_{-m}+\eta{\alpha}^{R^{i}}_{-m}-\gamma^{\ast}{\alpha}^{L^{i}}_{+m}-\eta^{\ast}{\alpha}^{R^{i}}_{+m}\right)

(3.2)

with
\gamma
and
\eta
being complex parameters, which characterize the eigenvalues of the left- and right-hand-side annihilation operators respectively. The operation of
{D}_{m}(\gamma)
and
{D}_{m}(\eta)
on the left and right-hand side annihilation operators displaces them in the optical phase space by
\gamma
and
\eta
, respectively

\displaystyle{D}_{m}^{L^{i}}(\gamma){\alpha}^{L^{i}}_{m}{D}_{m}^{\dagger{L^{i}}}(\gamma)=\Big[{\alpha}^{L^{i}}_{m}-m\gamma\Big]={b}^{L^{i}}_{m},

(3.3)

\displaystyle{D}_{m}^{R^{i}}(\eta){\alpha}^{R^{i}}_{m}{D}_{m}^{\dagger{R^{i}}}(\eta)=\Big[{\alpha}^{R^{i}}_{m}-m\eta\Big]={b}^{R^{i}}_{m}.

(3.4)

A similar rule is also applied to the creation operators. Given the relations
(
3.3
)
and
(
3.4
)
, it is straightforward to verify that the operator

{\mathcal{V}_{m}}(\beta)=\exp\left[{\theta_{m}{(\beta)}}({b}^{L^{i}}_{-m}{{b}^{R^{i}}_{-m}}-{b}^{L^{i}}_{m}{b}^{R^{i}}_{m})\right]

(3.5)

is unitarily equivalent to
{U}_{m}(\beta)
(defined in
(
2.21
)
), i.e.
{\mathcal{V}_{m}}(\beta)={D}_{m}(\gamma,\eta){U}_{m}(\beta){D}_{m}^{\dagger}(\gamma,\eta)
.

3.1
Coherent-Thermal String State

The coherent-thermal state
|\text{CT}\rangle_{s}
is built by operating the operator
{\mathcal{V}}(\beta)
on the coherent state

|\text{CT}\rangle_{s}={\mathcal{V}}(\beta)|\gamma;p,L\rangle|\eta;p,R\rangle={\mathcal{V}}(\beta){D}(\gamma,\eta)|0;p,L\rangle|0;p,R\rangle.

(3.6)

Since,
{\mathcal{V}}(\beta)
and
{U}(\beta)
are related by a unitary transformation, we can express
(
3.6
)
as follows

|\text{CT}\rangle_{s}={D}(\gamma,\eta){U}(\beta)|0;p,L\rangle|0;p,R\rangle={D}(\gamma,\eta)|\text{TFD}\rangle_{s},

(3.7)

where we have used the relation
(
2.28
)
. Therefore, the coherent-thermal state
|\text{CT}\rangle_{s}
can also be defined as a state where the vacuum is first thermalized and then displaced in the optical phase space. By using the exact expression of
|\text{TFD}\rangle_{s}
from
(
2.30
)
, we can obtain the exact form of
|\text{CT}\rangle_{s}
as given in the following

|\text{CT}\rangle_{s}=\prod_{m\geq 1}\prod_{i=1}^{24}\left[1-\exp\left\{\frac{-m\beta\sqrt{N_{i,m}}}{\sqrt{\alpha^{\prime}}}\right\}\right]^{\frac{D-2}{2}}\exp\left\{\frac{-m\beta\sqrt{N_{i,m}}}{{2}\sqrt{\alpha^{\prime}}}\right\}|N_{i,m};\gamma;p,L_{i}\rangle|N_{i,m};\eta;p,R_{i}\rangle,

(3.8)

Now, for a local observer situated on the left hand side, the reduced density matrix becomes

{\rho}^{L}_{CT}=\prod_{m}\prod_{i=1}^{24}{\rho}^{L^{i}}_{m}=\prod_{m}\prod_{i=1}^{24}Tr_{\mathcal{H}^{R^{i}}}|CT\rangle_{m}\ {}_{m}\langle CT|=Tr_{\mathcal{H}^{R}}|CT\rangle_{s}\ {}_{s}\langle CT|

(3.9)

By following the same procedure as discussed in section
2.2
, we can obtain the time evolution of the coherent-thermal state as

\displaystyle|\text{CT}(t)\rangle_{s}

\displaystyle=

\displaystyle e^{-i\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}t}|\text{CT}\rangle_{s}

(3.10)

\displaystyle=

\displaystyle{D}(\gamma,\eta,t)e^{-i\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}t}|\text{TFD}\rangle_{s}

\displaystyle=

\displaystyle{D}(\gamma,\eta,t)|\text{TFD}(t)\rangle_{s},

where

{D}(\gamma,\eta,t)=e^{i\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}t}{D}(\gamma,\eta)e^{i\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}t}.

(3.11)

We utilize the BCH formula to compute the following

\displaystyle e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{L^{i}}_{-m}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}

\displaystyle=

\displaystyle\exp\left[\frac{-imt\sqrt{N_{i,m}}}{\sqrt{\alpha^{\prime}}}\right]{\alpha}^{L^{i}}_{-m},

(3.12)

\displaystyle e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{R^{i}}_{-m}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}

\displaystyle=

\displaystyle\exp\left[\frac{-imt\sqrt{N_{i,m}}}{\sqrt{\alpha^{\prime}}}\right]{\alpha}^{R^{i}}_{-m},

(3.13)

\displaystyle e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{L^{i}}_{m}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}

\displaystyle=

\displaystyle\exp\left[\frac{-imt\sqrt{N_{i,m}}}{\sqrt{\alpha^{\prime}}}\right]{\alpha}^{L^{i}}_{m},

(3.14)

\displaystyle e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{R^{i}}_{m}e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}

\displaystyle=

\displaystyle\exp\left[\frac{-imt\sqrt{N_{i,m}}}{\sqrt{\alpha^{\prime}}}\right]{\alpha}^{R^{i}}_{m}

(3.15)

This leads to the simplification of
(
3.11
)

\displaystyle{D}(\gamma,\eta;t)=\prod_{m\geq 1}\prod_{i=1}^{24}\exp\left[\left\{\gamma e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{L^{i}}_{-m}+\eta e^{-it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{R^{i}}_{-m}\right.\right.

\displaystyle\left.\left.-\gamma^{\ast}e^{it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{L^{i}}_{m}-\eta^{\ast}e^{it\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}}{\alpha}^{R^{i}}_{m}\right\}\right].

(3.16)

Let us now express
(
3.1
)
in a more compact form in terms of the canonical variables
{\zeta}^{a_{m}}_{L^{i},R^{i}}=({X}_{m}^{L^{i}},{X}_{m}^{R^{i}},{P}_{m}^{L^{i}},

{P}_{m}^{R^{i}})
as

\displaystyle{D}(\gamma,\eta;t)

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\exp\left[-{i}\lambda_{a_{m}}{\zeta}^{a_{m}}\right]

(3.17)

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\exp\left[-i(\lambda_{X_{m}^{L^{i}}}X_{m}^{L^{i}}+\lambda_{X_{m}^{R^{i}}}X_{m}^{R^{i}}+\lambda_{P_{m}^{L^{i}}}P_{m}^{L^{i}}+\lambda_{P_{m}^{R^{i}}}P_{m}^{R^{i}})\right]

where

\displaystyle\lambda_{{X}^{L^{i}}_{m}}={\sqrt{2}}\left[\text{Re}[\gamma(L)]\sin\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)-\text{Im}[\gamma(L)]\cos\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)\right],

(3.18)

\displaystyle\lambda_{{P}^{L^{i}}_{m}}={\sqrt{2}}\left[\text{Re}[\gamma(L)]\cos\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)-\text{Im}[\gamma(L)]\sin\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)\right],

(3.19)

\displaystyle\lambda_{{X}^{R^{i}}_{m}}={\sqrt{2}}\left[\text{Re}[\eta(R)]\sin\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)-\text{Im}[\eta(R)]\cos\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)\right],

(3.20)

\displaystyle\lambda_{{P}^{R^{i}}_{m}}={\sqrt{2}}\left[\text{Re}[\eta(R)]\cos\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)-\text{Im}[\eta(R)]\sin\left(mt\sqrt{\frac{N_{i,m}}{\alpha^{\prime}}}\right)\right].

(3.21)

where
m\sqrt{N_{i,m}/\alpha^{\prime}}
is the frequency of the string for the

3.2
Thermal-Coherent String State

In contrast to the coherent-thermal state defined in
(
3.7
)
, the thermal coherent state is defined by a state where the vacuum is first displaced in the optical phase space and then thermalized

|\text{TC}\rangle_{m}={U}_{m}(\beta){D}_{m}(\gamma,\eta)|0;p,L\rangle|0;p,R\rangle={U}_{m}(\beta)|\gamma;p,L\rangle|\eta;p,R\rangle.

(3.22)

Using the Bogoliubov transformations, it can be shown that the thermal-coherent states are the eigenstates of the thermal annihilation operators, i.e.

\displaystyle{a}^{L^{i}}_{m}(\beta)|\text{TC}\rangle_{m}

\displaystyle=

\displaystyle\gamma|\text{TC}\rangle_{m},

(3.23)

\displaystyle{a}^{R^{i}}_{m}(\beta)|\text{TC}\rangle_{m}

\displaystyle=

\displaystyle\eta|\text{TC}\rangle_{m}.

(3.24)

It indicates that the thermal-coherent state
|\text{TC}\rangle_{m}
can be obtained by displacing the thermal vacuum state
|\text{TFD}\rangle_{m}
in the optical phase space

|\text{TC}\rangle_{m}={D}_{m}(\gamma,\eta,\beta)|\text{TFD}\rangle_{m}.

(3.25)

Here the displacement operator can be written as

\displaystyle{D}_{m}(\gamma,\eta,\beta)

\displaystyle\equiv

\displaystyle{U}_{m}(\beta){D}_{m}(\gamma,\eta){U}_{m}^{\dagger}(\beta)

(3.26)

\displaystyle=

\displaystyle\exp\left[\left\{\gamma{a}^{L^{i}}_{-m}(\beta)+\eta{a}^{R^{i}}_{-m}(\beta)-\gamma^{\ast}{a}^{L^{i}}_{m}(\beta)-\eta^{\ast}{a}^{R^{i}}_{m}(\beta)\right\}\right]

\displaystyle=

\displaystyle\exp\left[\left\{\tilde{\gamma}(\beta){a}^{L^{i}}_{-m}+\tilde{\eta}(\beta){a}^{R^{i}}_{-m}-\tilde{\gamma}^{\ast}(\beta){a}^{L^{i}}_{m}-\tilde{\eta}^{\ast}(\beta){a}^{R^{i}}_{m}\right\}\right]

\displaystyle=

\displaystyle{D}_{m}(\tilde{\gamma},\tilde{\eta}),

where
\tilde{\gamma}(\beta)
and
\tilde{\eta}(\beta)
are given by

\displaystyle\tilde{\gamma}(\beta)

\displaystyle=

\displaystyle\left\{\cosh\theta_{m}(\beta)\gamma+\sinh\theta_{m}(\beta)\eta^{\ast}\right\},

(3.27)

\displaystyle\tilde{\eta}(\beta)

\displaystyle=

\displaystyle\left\{\cosh\theta_{m}(\beta)\eta+\sinh\theta_{m}(\beta)\gamma^{\ast}\right\}.

(3.28)

From
(
3.26
)
, it is obvious that the operators
{D}_{m}(\gamma,\eta,\beta)
and
{D}_{m}(\tilde{\gamma},\tilde{\eta})
are physically equivalent apart from a parameter transformation given by
(
3.27
)
and
(
3.28
)
. Thus, we can rewrite
(
3.25
)
as

\displaystyle|\text{TC}(\gamma,\eta)\rangle_{m}

\displaystyle=

\displaystyle{D}_{m}(\tilde{\gamma},\tilde{\eta})|\text{TFD}\rangle_{m}=|\text{CT}(\tilde{\gamma},\tilde{\eta})\rangle_{m},

(3.29)

\displaystyle|\text{TC}(\gamma,\eta)\rangle_{s}

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}{D}_{m}(\tilde{\gamma},\tilde{\eta})|\text{TFD}\rangle_{m}=\prod_{m\geq 1}\prod_{i=1}^{24}|\text{CT}(\tilde{\gamma},\tilde{\eta})\rangle_{m},

(3.30)

which indicates that the coherent-thermal and thermal-coherent states are physically equivalent apart from their different parameter dependents. The parameters being related to the temperature, one can conclude that the states
|\text{CT}\rangle_{s}
and
|\text{TC}\rangle_{s}
apparently possess a similar eigenvalue space with different parameter dependence. The time-evolution of the the state
|\text{TC}\rangle_{s}
is realized as,

\displaystyle|\text{TC}(t)\rangle_{s}

\displaystyle=

\displaystyle e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}|\text{TC}\rangle_{s}

(3.31)

\displaystyle=

\displaystyle{D}(\gamma,\eta,\beta,t)e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}|\text{TFD}\rangle_{s}

\displaystyle=

\displaystyle{D}(\gamma,\eta,\beta,t)|\text{TFD}(t)\rangle_{s},

where

\displaystyle{D}(\gamma,\eta,\beta;t)

\displaystyle=

\displaystyle e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}{D}(\gamma,\eta,\beta)e^{it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}

(3.32)

\displaystyle=

\displaystyle e^{-it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}{D}(\tilde{\gamma},\tilde{\eta})e^{it\sqrt{\frac{{N_{i,m}}-1}{\alpha^{\prime}}}}

\displaystyle=

\displaystyle{D}(\tilde{\gamma},\tilde{\eta},t).

Thus, we can state

|\text{TC}_{s}(\gamma,\eta,t)\rangle=|\text{CT}_{s}(\tilde{\gamma},\tilde{\eta},t)\rangle,

(3.33)

which clearly suggests that the rest of the analysis from
(
3.12
)
to
(
3.21
)
is similar to that of
|\text{CT}\rangle_{s}
apart from the transformation of the parameters
(\gamma,\eta)\rightarrow(\tilde{\gamma},\tilde{\eta})
, which we do not repeat here.

4
Circuit Complexity

In this section, we will adopt the covariance matrix approach to calculate the circuit complexity for coherent-thermal
|\text{CT}_{s}\rangle
and thermal-coherent
|\text{CT}_{s}\rangle
string states. However, we shall compute it for the
|\text{CT}_{s}\rangle
only, as the same analysis will be equally valid for
|\text{TC}_{s}\rangle
, which we have discussed in detail in the previous section. Remember that both
|\text{CT}_{s}\rangle
and
|\text{TC}_{s}\rangle
are non-Gaussian, and our aim is to study the circuit complexity for the non-Gaussian string state. Now, we can Consider the string system with target space coordinates and momentum as

\displaystyle{\zeta}^{a}=\prod_{m\geq 1}\prod_{i=1}^{24}{\zeta}^{a_{m}}_{L^{i},R^{i}}=\prod_{m\geq 1}\prod_{i=1}^{24}({X}^{R^{i}}_{m},{X}^{L^{i}}_{m},{P}^{R^{i}}_{m},{P}^{L^{i}}_{m}),

(4.1)

\displaystyle{\zeta}^{b}=\prod_{m\geq 1}\prod_{i=1}^{24}{\zeta}^{b_{m}}_{L^{i},R^{i}}=\prod_{m\geq 1}\prod_{i=1}^{24}\left(\begin{array}[]{c}{X}^{R^{i}}_{m}\\
{X}^{L^{i}}_{m}\\
{P}^{R^{i}}_{m}\\
{P}^{L^{i}}_{m}\\
\end{array}\right),

The commutation relations of
m
-canonical world-sheet variables can be written as

\left[{\zeta}^{a_{m}}_{L^{i},R^{i}},{\zeta}^{b_{m}}_{L^{i},R^{i}}\right]=im{\Omega}^{{a_{m}}{b_{m}}}_{L^{i},R^{i}},\quad\text{where}\quad{{\Omega}}^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}=\left(\begin{array}[]{c c}0&I\\
-I&0\\
\end{array}\right).

(4.7)

Thus, the commutation relations for the target space can be written as

\displaystyle\left[{\zeta}^{a},{\zeta}^{b}\right]=i\prod_{m\geq 1}\prod_{i=1}^{24}m{{\Omega}}^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}.

(4.8)

Here, we have taken a product of world-sheet coordinates and momentum
{\zeta}^{a_{m}}_{L^{i},R^{i}}
to obtain the target space coordinates and momentum
{\zeta}^{a}
.
In what follows, we shall suppress the operator symbol. Here,
{{\Omega}}^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}
is an anti-symmetric tensor, which can be utilized to raise the indices, for instance

T_{...c_{m}a_{m}d_{m}...}\equiv{\Omega}^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}{T_{...{c_{m}}{b_{m}}{d_{m}}...}}.

(4.9)

The one-point function for a pure Gaussian state is known to vanish. Let’s consider an arbitrary string state
|\psi_{m}\rangle
of string mode “
m
”, such that its symmetric two-point function may be expressed as
[
61
]

G^{{a}{b}}=\prod_{m\geq 1}\prod_{i=1}^{24}G^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}=\prod_{m\geq 1}\prod_{i=1}^{24}\frac{1}{2}\langle{\psi_{m}}|\{\zeta^{a_{m}}_{L^{i},R^{i}},\zeta^{b_{m}}_{L^{i},R^{i}}\}|\psi_{m}\rangle,

(4.10)

where the symbol
\{\cdot,\cdot\}
represents the anti-commutation relation. If an arbitrary string
state
|\psi_{m}\rangle
is a pure Gaussian state with

\prod_{m}\prod_{i=1}^{24}\langle{\psi_{m}}|\{\zeta^{a_{m}}_{L^{i},R^{i}},\zeta^{b_{m}}_{L^{i},R^{i}}\}|\psi_{m}\rangle=0
, then it is completely characterized by
its symmetric two-point function, often referred to as its (symmetric) covariance matrix method
[
60
]
. However, as we can consider states which are non-Gaussian, the corresponding one-point functions are non-vanishing
[
61
]
. Collecting the expressions from
(
2.39
)
and
(
3.17
)
, we can write the time-evolution of the coherent-thermal state as

|\text{CT}(t)\rangle_{s}=\prod_{m\geq 1}\prod_{i=1}^{24}\Bigg\{\exp\left[-\frac{i}{2}\lambda_{a_{m}}\zeta^{a_{m}}_{L^{i},R^{i}}\right]\exp\left[-\frac{i}{2}K^{(0)}_{{a_{m}}{b_{m}}}\zeta^{a_{m}}_{L^{i},R^{i}}\zeta^{b_{m}}_{L^{i},R^{i}}\right]\Bigg\}|0;p,L\rangle|0;p,R\rangle.

(4.11)

Here we have dropped the overall phase factor
\exp{(-i\sqrt{\frac{N_{i,m}-1}{\alpha^{\prime}}}t)}
of strings. For generalizing the covariance matrix approach, we shall consider a general string reference state
|\psi_{m}\rangle_{\mathcal{R}}
of string mode “
m
”, which can be Gaussian or non-Gaussian. The state
(
4.11
)
is connected to the string reference state
|\psi_{m}\rangle_{\mathcal{R}}
by two unitary transformations

\displaystyle|\text{CT}(t)\rangle_{s}=\prod_{m\geq 1}\prod_{i=1}^{24}\mathbb{U}_{m_{1}}({L,R})\mathbb{U}_{m_{2}}({L^{i},R^{i}})|\psi_{m}\rangle_{\mathcal{R}},

\displaystyle\mathbb{U}_{m_{1}}({L^{i},R^{i}})=\exp\left[-\frac{i}{2}\lambda_{a_{m}}\zeta^{a_{m}}_{L^{i},R^{i}}\right],

\displaystyle\mathbb{U}_{m_{2}}({L^{i},R^{i}})=\exp\left[-\frac{i}{2}K_{{a_{m}}{b_{m}}}\zeta^{a_{m}}_{L^{i},R^{i}}\zeta^{b_{m}}_{L^{i},R^{i}}\right].

(4.12)

The first one,
\mathbb{U}_{m_{1}}({L^{i},R^{i}})
causes the
m
-translations of the canonical variables
\zeta^{a_{m}}_{L^{i},R^{i}}
for which the gaussianity of the reference state is broken. Thus, we need to modify the relation
(
4.10
)
. For this, let us introduce the following one-point function

\varphi^{a}=\prod_{m\geq 1}\prod_{i=1}^{24}\varphi^{a_{m}}_{L^{i},R^{i}}\equiv\prod_{m\geq 1}\prod_{i=1}^{24}{\langle\psi_{m}|\zeta^{a_{m}}_{L^{i},R^{i}}}{|\psi_{m}\rangle},

(4.13)

and study how the one-point functions
\prod_{m\geq 1}\prod_{i=1}^{24}\varphi^{a_{m}}_{L^{i},R^{i}}
and the symmetric two-point functions
\prod_{m\geq 1}\prod_{i=1}^{24}

G^{{a_{m}}{b_{m}}}_{L^{i},R^{i}}
behave under the
m^{th}
unitary transformation
\mathbb{U}_{m_{1}}(L,R)\mathbb{U}_{m_{2}}({L^{i},R^{i}})
. Now we can express
\mathbb{U}_{1}^{\dagger}\zeta^{a}\mathbb{U}_{1}
as

\displaystyle\mathbb{U}_{1}^{\dagger}\zeta^{a}\mathbb{U}_{1}

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}\mathbb{U}_{m_{1}}^{\dagger}({L^{i},R^{i}})\zeta^{a_{m_{1}}}_{L^{i},R^{i}}\mathbb{U}_{m_{1}}({L^{i},R^{i}})

The quantum circuit connecting the string target state

\prod_{m\geq 1}\mathcal{U}_{m}
be unique. There can be many such transformations that can connect the string reference state to the string target state and the corresponding geodesics may have different lengths. Our task is to find an optimal unitary transformation that determines the minimal geodesic in the group manifold. The length of the minimal geodesic is termed as the circuit complexity
[
60
]
. For example, one can find the existence of a stabilizer subgroup
S
for the string reference state, i.e.
\forall~\prod_{m\geq 1}\mathcal{U}_{m_{S}}\in S
which results in
[

\displaystyle U_{S}|\Psi\rangle_{\mathcal{R}}=\prod_{m\geq 1}\prod_{i=1}^{24}\mathcal{U}_{m_{S}}|\psi_{m}\rangle_{\mathcal{R}}

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}e^{(\mathcal{B}_{m_{S}})}|\psi_{m}\rangle_{\mathcal{R}}

(4.29)

\displaystyle=

\displaystyle\prod_{m\geq 1}\prod_{i=1}^{24}|\psi_{m}\rangle_{\mathcal{R}}=|\Psi\rangle_{\mathcal{R}},

where
{\mathcal{B}_{m_{S}}}
is the generator of the sub-algebra
\mathcal{S}
. This implies that if the unitary
\prod_{m\geq 1}e^{(\mathcal{A}_{m})}
(or a geodesic
\mathcal{Y}_{m}(\tau)=\prod_{m\geq 1}e^{(\tau\mathcal{A}_{m})}
in the group manifold) connects the reference state to the target state, there will be many unitaries that can achieve the target state of the total string modes because of

\big\{e^{(\mathcal{A})}e^{(\mathcal{B}_{S})}\big\}|\Psi\rangle_{\mathcal{R}}=e^{\mathcal{A}}|\Psi\rangle_{\mathcal{R}}=|\Psi\rangle_{T}.

(4.30)

The unitaries
\mathcal{U}_{S}
involving factors in the stabilizer subgroup always add to the length of the geodesic in the space of circuits, while only trivially acting on the reference. That is the reason for restricting the subspace of circuits transverse to the stabilizer subspace. In other words, the geodesics corresponding to the unitaries
\mathcal{U}_{S}
that connects the reference state to the target state will not have the minimal length. Therefore, it is obvious that the optimal geodesic can not correspond to any unitary that belongs to the stabilizer subgroup. To find the optimal geodesic, we use the inner product on the Lie algebra of the transformation group
[
61
]

\langle{\mathcal{A}},{\mathcal{B}}\rangle=\prod_{m\geq 1}\prod_{i=1}^{24}\langle{\mathcal{A}_{m}},{\mathcal{B}_{m}}\rangle_{i}=\prod_{m\geq 1}\prod_{i=1}^{24}Tr({\mathcal{A}_{m}}\bar{G}_{m_{\mathcal{R}}}({L^{i},R^{i}}){\mathcal{B}_{m}^{T}}\bar{g}_{m_{\mathcal{R}}}({L^{i},R^{i}})),

(4.31)

where
{\mathcal{A}},{\mathcal{B}}
are total generators for strings,
\bar{G}_{\mathcal{R}}
is extended covariant metric associated with the string reference state and
\bar{g}_{\mathcal{R}}
is its inverse matrix. Subsequently, we use the string horizontal subspace that is transverse to the stabilizer string sub-algebra,

\mathcal{H}:=\prod_{m\geq 1}\prod_{i=1}^{24}\{\mathcal{A}_{m}\in\mathcal{G}_{m}|\langle{\mathcal{A}_{m}},{\mathcal{B}_{m_{S}}}\rangle_{i}=0,\quad\forall\;\;{\mathcal{B}_{S}}\in S\}

(4.32)

It is obvious that the horizontal generator
\mathcal{A}=\prod_{m\geq 1}{\mathcal{A}_{m}}\in{\mathcal{H}}
does not belong to the stabilizer string sub-algebra. Therefore, the optimal geodesic in our case will still be generated by a horizontal string generator i.e,
\mathcal{Y}_{m}(\tau)=\prod_{m\geq 1}e^{{(\tau\mathcal{A}_{m}})}
. Thus the complexity of the string target state will be given by

\mathcal{C}\Big(\prod_{m\geq 1}\prod_{i=1}^{24}|\psi^{i}_{m}\rangle_{\mathcal{R}}\rightarrow\prod_{m\geq 1}\prod_{i=1}^{24}|\psi^{i}_{m}\rangle_{T}\Big)=\prod_{m\geq 1}\prod_{i=1}^{24}\|\mathcal{A}_{m}\|_{i}.

(4.33)

Therefore, evaluating the string complexity is equivalent to finding the horizontal generator
\mathcal{A}_{m}

|\Psi\rangle_{T}=\prod_{m\geq 1}\prod_{i=1}^{24}|\psi^{i}_{m}\rangle_{T}=e^{\mathcal{A}}|\Psi\rangle_{\mathcal{R}}.

(4.34)

Thus, we have explicitly obtained the circuit complexity of coherent-thermal states
|CT\rangle_{s}
in bosonic string theory. This was done using the covariance matrix approach. Here we generated the optimal geodesics by a horizontal string generator
\mathcal{A}
and then obtained the circuit complexity using the length of the minimal geodesics in the group manifold. Similar results have been obtained for a simple quantum mechanical system

As string theory in light-cone gauges could be mathematically represented as a number of harmonic oscillators, these results could be viewed as a mathematical generalization of the earlier results obtained for a simple quantum mechanical system. 5
Conclusions

In this paper, we first used the Polyakov action, which describes the world sheet of bosonic string theory, to obtain the string coherent state.
After that, we introduce a new set of states to construct thermal states, which we call string TFD states.
We defined the zero temperature vacuum, which consisted of one left vacuum and one right vacuum. We constructed left and right Hilbert spaces from these vacuum states. Then we defined the total Hilbert space as a tensor product of left and right Hilbert spaces.
We investigated the thermal bosonic open strings in contact with thermal reservoirs.
After that, we introduce the unitary Bogoliubov transformation to construct TFD states.
We also explicitly calculate the density matrix by tracing over the right degrees of freedom.
We construct the coherent thermal string state by operating the unitary Bogoliubov operator on the string coherent state and, then, calculate its time evolution.
Then we construct thermal coherent string states, where we first displace the vacuum in the optical phase and then thermalize it.
We adopted a covariance matrix approach to calculate the circuit complexity for the coherent-thermal string state. We generate the optimal geodesics by a horizontal string generator and define the complexity by the length of the minimal geodesics in the group manifold. Thus, the calculation of string circuit complexity was equivalent to finding a horizontal generator.

It is possible to use the results of this present paper, to analyze the circuit complexity for specific reference states. This can be done by investigating the circuit complexity when the reference state is a Gaussian state like the TFD state or the vacuum state.
It would be interesting to extend this work to superstring theories. This can be done by first constructing a coherent state in a specific superstring theory. Then we can generalize the construction of such a coherent state to a thermal coherent state. This can be used to obtain the circuit complexity for such thermal states of superstring theory. However, before analyzing the circuit complexity for such thermal states of superstring theory, we need to analyze the circuit complexity for supersymmetric field theories. It would also be interesting to analyze the effect of background fields on the circuit complexities. It would also be interesting to analyze the effect of T-duality on circuit complexities. It is expected that for bosonic string theory, the circuit complexity will be invariant under a T-duality. It would be interesting to analyze the effect of T-duality and mirror symmetry on the circuit complexities of superstring theories. This work can then be analyzed to such theories with background fields.

It would be interesting to analyze the circuit complexity of string theory in conformal gauges. It is known that string theory in conformal gauge is equivalent to string theory in
light-cone gauge. However, unlike in light-cone gauges, where the ghost sector decouples from the physical sector of the theory, the effect of the ghost sector has to be explicitly studied in conformal gauges. This is usually done using the BRST formalism, so it would be interesting to analyze the circuit complexity for a bosonic string using the BRST formalism. The BRST charge can also be used to construct the cubic string field theory. It would be possible to use the cubic string field theory to investigate the circuit complexity of a system of strings interacting with each other through a cubic string interaction. This can be done by generalizing the results of this paper to cubic string field theory. It is possible to use finite field-dependent BRST transformation to relate light-cone string theory to string theory in conformal gauge. Thus, we can use the finite field BRST transformations to obtain the circuit complexity in conformal gauges using the results of this paper.

It is possible to construct quadrature operators for thermal string states. Then these quadrature operators can be used to analyze generalized string coherent states. Such quadrature operators for thermal string states can be obtained from quadrature operators for different thermal modes of a string. It would be interesting to construct and analyze such quadrature operators for both open and closed bosonic string states. This can then be used to obtain the circuit complexity for such states. We can also use these states to perform quantum state tomography for thermal string states. It is expected that this can also be generalized to quadrature operators for string field theories and, then, use it to analyze circuit complexity for a system of interacting strings. It would be interesting to analyze the effect of dualities on the circuit complexity using these quadrature operators.

for
b\neq 0
, and we obtain a non-vanishing expression only for
k=nm
. So,
using the expression for
\langle b|\varphi_{m}\rangle
in the general expression for
\langle k|\varphi_{m}\rangle
, we obtain

\langle k|\varphi_{m}\rangle=\frac{\varphi_{m}^{n}e^{{-\frac{|\varphi_{m}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(k-(n-1)m)}}

(5.23)

Using this expression for
\langle k|\varphi_{m}\rangle
(with
k=nm
) in the general expression for string world-sheet mode coherent states, we can write an explicit expression for a string world-sheet mode coherent state as

|\varphi_{m}\rangle=\sum_{n=0}^{\infty}\frac{\varphi_{m}^{n}e^{{-\frac{|\varphi_{m}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}|k\rangle

(5.24)

By repeating this procedure for different string modes, we can obtain string world-sheet mode coherent states for different string modes.
Using these string world-sheet mode coherent states, a coherent state for strings in the target space can be expressed as

|\Phi\rangle=\prod_{m}|\varphi_{m}\rangle

(5.25)

Average of the mass-squared can be written as
\langle\hat{M}^{2}\rangle=\langle\Phi|\hat{M}^{2}|\Phi\rangle
. String coherent state
|\Phi\rangle
can be expressed in terms of
|k\rangle
states as

\displaystyle\langle\Phi|\hat{M}^{2}|\Phi\rangle

\displaystyle=

\displaystyle\prod_{i=1}^{24}\prod_{m\geq 1}\langle\varphi_{m}^{i}|\frac{1}{\alpha^{\prime}}(\hat{N}_{i,m}-1)|\varphi_{m}^{i}\rangle

(5.26)

\displaystyle=

\displaystyle\prod_{i=1}^{24}\prod_{m\geq 1}\sum_{k}\Big\langle k\Big|\frac{(\varphi^{i}_{m})^{\frac{k}{m}}e^{{-\frac{|{\varphi^{i}_{m}}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}\Big|\frac{1}{\alpha^{\prime}}(\hat{N}_{m}^{i}-1)\Big|\frac{(\varphi^{i}_{m})^{\frac{k}{m}}e^{{-\frac{|{\varphi^{i}_{m}}|^{2}}{2}}}}{\sqrt{k(k-m)(k-2m)...(m)}}\Big|k\Big\rangle

\displaystyle=

\displaystyle\prod_{i=1}^{24}\prod_{m\geq 1}\sum_{k}\frac{(\varphi^{i}_{m})^{\frac{2k}{m}}e^{{-|{\varphi^{i}_{m}}|^{2}}}}{{k(k-m)(k-2m)...(m)}}\Big\{\frac{1}{\alpha^{\prime}}(k-1)\Big\}.

As
i
and
m
increases, the value of average energy
\langle\Phi|\hat{M}^{2}|\Phi\rangle
drops accordingly, because of the exponential term
e^{{-|{\varphi^{i}_{m}}|^{2}}}
. It may be noted here that the string coherent state
|\Phi\rangle
is not a mass eigenstate. Thus, we get a convergent result, which resembles what happens for coherent states of a harmonic oscillator in quantum mechanics.
