Conservativity of Type Theory over Higher-order Arithmetic
Benno van den Berg, Daniël Otten

Abstract
We investigate how much type theory is able to prove about the natural numbers. A classical result in this area shows that dependent type theory without any universes is conservative over Heyting Arithmetic (HA). We build on this result by showing that type theories with one level of universes are conservative over Higher-order Heyting Arithmetic (HAH). Although this clearly depends on the specific type theory, we show that the interpretation of logic also plays a major role. For proof-irrelevant interpretations, we will see that strong versions of type theory prove exactly the same higher-order arithmetical formulas as HAH. Conversely, proof-relevant interpretations prove strictly more second-order arithmetical formulas than HAH, however they still prove exactly the same first-order arithmetical formulas. Along the way, we investigate the different interpretations of logic in type theory, and to what extent dependent type theories can be seen as extensions of higher-order logic. We apply our results by proving De Jongh’s theorem for type theory.

1
Introduction

The arithmetical statements that are provable in a theory reveal a lot of about its properties.
It determines its consistency strength, its logic, which functions it can prove to be recursive, and which other theories it can prove to be consistent.
In this work, we investigate this for dependent type theories with a single level of universes.
Taking a general approach: we consider predicative and impredicative versions of type theory, intensional and extensional versions, and a wide array of type constructors.
We also consider a large range of interpretations of higher-order logic in type theory: proof-relevant and proof-irrelevant interpretations of logical connectives, and three different interpretations of power sets.

Main Results.

Strong versions of type theory with a single level of universes prove:

•

the same
higher-order
arithmetical formulas as HAH for
proof-irrelevant
interpretations,

◦

the same
higher-order
first-order
arithmetical formulas as HAH for
proof-irrelevant
proof-relevant
interpretations.

Moreover, this result is maximal: type theories can prove more second-order arithmetical formulas than HAH for proof-relevant interpretations (the axiom of choice, for example).
The main type theory that we consider is a version of the Calculus of Inductive Constructions (
\lambda\mathrm{C}{+}
), specified in
section 4
.
Conservativity for weaker type theories follows from this.

We construct a model for
\lambda\mathrm{C}{+}
based on subsingletons, partial equivalence relations (PERs), and assemblies.
The innovation is that we only use arithmetical notions, which gives us a realizability interpretation of
\lambda\mathrm{C}{+}
in HAH.
We obtain the proof-irrelevant result by showing that the composition of interpretations HAH
{}\to\lambda
C
{+}\to{}
HAH is the identity up to logical equivalence.
The proof-relevant result is more involved.
First, we conservatively extend HAH with primitive notions for partial application.
Then, we conservatively add a computational choice principle based on Hilbert-style epsilon-constants.
Lastly, we modify our model and proof using this principle.
To formulate these extensions, we define and use a higher-order version of Beeson’s logic of partial terms.
Lastly, we use our results to prove a De Jongh’s theorem for type theory, which indicates that the rules of these type theories do not ‘disrupt’ their intuitionistic natures.

2
Higher-order Arithmetic

We start by stating the various theories of natural numbers.
Although they share the same language and axioms, these theories differ in their underlying logic.
First, we explain and motivate these logics.
Then, we will introduce the various theories of arithmetic.

2.1
Higher-order Logic

Motivation.

There are many versions of higher-order logic, and the notation is not standardised.
So, before giving a formal introduction, we will first motivate our choices.
Our version of higher-order logic can quantify over relations; this directly generalises
n
-th-order logic.
There are also versions that quantify over functions.
We observe that in intuitionistic logic, quantifying over relations is more expressive than quantifying over functions:

•

We can encode an
n
-ary function
f
as an
(n+1)
-ary relation
R
satisfying
\forall\vec{x}\,\exists!y\,R(\vec{x},y)
, see for instance
[
35
, Section 2.7]
.
This means that we can replace
\exists f\,\dots
and
\forall f\,\dots
with
\exists R\,(\forall\vec{x}\,\exists!y\,R(\vec{x},y)\land\dots)
and
\forall R\,(\forall\vec{x}\,\exists!y\,R(\vec{x},y)\to\dots)
.

•

In classical logic, if we have terms
a\neq b
, then it is also possible to encode an
n
-ary relation
R
as an
n
-ary function
f
satisfying
\forall\vec{x}\,(f(\vec{x})=a\lor f(\vec{x})=b)
.
However, in intuitionistic logic, this only encodes those
R
that satisfy
\forall\vec{x}\,(R(\vec{x})\lor\neg R(\vec{x}))
.

So, for simplicity, we present higher-order logic using only quantifiers over relations.
Our second observation is that it is often enough to consider only unary relations:

•

If the theory can encode tuples, then instead of quantifying over an
n
-ary relation
R
, we can quantify over a unary relation
X
: we replace
R(x_{0},\dots\,x_{n-1})
with
X(\langle x_{0},\dots,x_{n-1}\rangle)
.

As we will see, this is true for arithmetic, so for our purposes it is sufficient to quantify over unary relations.
These are just subsets so we will use the set theoretic notation
x\in X
for
X(x)
.
Restricting to the unary case gives us ‘monadic’ versions of logic.

Definition 1
.

A
monadic higher-order logic
is a many-sorted logic with a sort for every numeral
n=0,1,\dots
.
If we write
a^{n}
, then the term
a
is of the
n
-th sort, intuitively a member of the
n
-th power set of the domain.
Terms are built using function symbols
f
, which each have a signature
n_{0}\times\dots\times n_{k-1}\to m
.
We also allow relation symbols, which each have a signature
n_{0}\times\dots\times n_{k-1}
.
We always assume that the language has relation symbols
=^{n}:n\times n
and
\in^{n}:n\times(n+1)
.
Formulas are given by:

A,B,\dots~::=~R(a_{0}^{n_{0}},\dots,a_{k-1}^{n_{k-1}})~|~\bot\,|~\top~|~A\lor B~|~A\land B~|~A\to B~|~\exists x^{n}\,B[x^{n}]~|~\forall x^{n}\,B[x^{n}].

There are classical and intuitionistic versions of higher-order logic.
For both we take standard inference rules for propositional logic, quantifiers, and equality.
In addition, we have two axiom schemes for the element relation; for any
n
and any formula
P[z^{n}]
we have the axioms:

\displaystyle\forall X^{n+1}\,\forall Y^{n+1}\,(\forall z^{n}\,(z\in X\leftrightarrow z\in Y)\to X=Y),

(extensionality)

\displaystyle\exists X^{n+1}\,\forall z^{n}\,(z\in X\leftrightarrow P[z]).

(comprehension)

To reduce clutter, we omit the sorts in places where they can easily be inferred.

Definition 2
.

We define
monadic
n
-th-order logic
as the restriction of monadic higher-order logic to the sorts
0,\dots,n-1
.

Defining Logical Connectives.

We could also formulate second or higher-order logic in an even more minimalistic way, using only
\in
,
\to
, and
\forall
.
This is because, by quantifying over a proposition
Z
(a nullary relation), we can define the other logical connectives:

\displaystyle\bot

\displaystyle\coloneqq\forall Z\,Z,

(false)

\displaystyle\top

\displaystyle\coloneqq\forall Z\,(Z\to Z),

(true)

\displaystyle A\lor B

\displaystyle\coloneqq\forall Z\,((A\to Z)\to(B\to Z)\to Z),

(disjunction)

\displaystyle A\land B

\displaystyle\coloneqq\forall Z\,((A\to(B\to Z))\to Z),

(conjunction)

\displaystyle\exists x^{n}\,B[x]

\displaystyle\coloneqq\forall Z\,(\forall x^{n}\,(B[x]\to Z)\to Z).

(existential quantifier)

We can use similar definitions in monadic versions of logic by filling in an arbitrary variable
x^{0}
.
For example, we could define
\bot
as
\forall X^{1}\,(x\in X)
and
\top
as
\forall X^{1}\,(x\in X\to x\in X)
.
Similarly, we can define equality using Leibniz’s principle:

\displaystyle(a=^{n}b)

\displaystyle\coloneqq\forall X^{n+1}\,(a\in X\to b\in X).

(equality)

It is a nice exercise to show that these formulas indeed satisfy the correct inference rules.
This alternative definition will allow us to simplify our proof for conservativity.

2.2
Arithmetic

Language and Axioms.

The language of our arithmetical theories consists of a zero constant
0:0
(a nullary function symbol), a successor function
\mathsf{S}:0\to 0
, addition
+:0\times 0\to 0
, and multiplication
\times:0\times 0\to 0
.
We have axioms stating that
0
and
\mathsf{S}
are jointly injective:

\displaystyle\forall y\,(\mathsf{S}(y)\neq 0),

\displaystyle\forall x\,\forall y\,(\mathsf{S}(x)=\mathsf{S}(y)\to x=y).

In addition, we have axioms for addition and multiplication:

\displaystyle\forall y\,(0+y=\text{\vphantom{${0}$}\hskip-0.1308pt\smash{${y}$}\hskip-0.1308pt}),

\displaystyle\forall x\,\forall y\,(\mathsf{S}(x)+y=\mathsf{S}(x+y)),

\displaystyle\forall y\,(0\times y=0),

\displaystyle\forall x\,\forall y\,(\mathsf{S}(x)\times y=(x\times y)+x).

And we have an axiom scheme for induction; for every formula
A[x]
we have the axiom:

A[0]\land\forall x(A[x]\to A[\mathsf{S}(x)])\to\forall x\,A[x].

Definition 3

(Peano and Heyting arithmetic)
.

We define the following theories, all with the same language and axioms above, and each with different logical inference rules:

\begin{array}[]{ccc}&\text{classical}&\text{intuitionistic}\\
\cline{2-3}\cr\lx@intercol\hfil n\text{-th-order}\lx@intercol\vrule\lx@intercol&\mathrm{PA}n&\mathrm{HA}n\\
\lx@intercol\hfil\text{higher-order}\lx@intercol\vrule\lx@intercol&\mathrm{PA}\text{\vphantom{${n}$}\smash{${\mathrm{H}}$}\hskip-0.74883pt\hskip-0.74883pt}&\mathrm{HA}\text{\vphantom{${n}$}\smash{${\mathrm{H}}$}\hskip-0.74883pt\hskip-0.74883pt}\end{array}

HAH is stronger than HA
ω
, where we can quantify over functions instead of relations
[
34
]
.

Tuples and Recursion Theory.

One might wonder why we only include addition and multiplication, instead of going further and including exponentiation.
This is because addition and multiplication already allow us to encode tuples, which is sufficient to develop recursion theory.
First, define a bijection
\mathbb{N}\times\mathbb{N}\to\mathbb{N}

[
7
]
, and use it to define tuples:

\displaystyle\langle a,b\rangle\coloneqq((a+b)\times\mathsf{S}(a+b))/2+b

\displaystyle\langle a_{0},\dots,a_{n-1}\rangle

\displaystyle\coloneqq\langle a_{0},\langle a_{1},\dots,\langle a_{n-2},a_{n-1}\rangle\rangle\rangle.

We can define
b^{a}=c
as a formula stating: there exists a tuple
\langle x_{0},\dots,x_{a}\rangle
such that
x_{0}=1
, for every
i<a
we have
x_{i+1}=x_{i}\times b
, and
x_{a}=z
.
Other primitive recursive functions can be defined in a similar way.
For a more detailed explanation, see
[
6
,
17
,
21
]
.

3
Interpreting Higher-order Arithmetic in Type Theory

An interpretation of HAH-formulas in type theory can be divided into three parts: defining natural numbers, logical connectives, and power sets in type theory.
For each part there are multiple options, which come with different requirements on the type theory.
These requirements make sure that the type theory satisfies the rules and axioms of HAH for the interpretation.
We systematically consider the three parts in the following subsections, and, in the end, we will have a clear overview of the various interpretations.
For now, we assume that we have a standard version of dependent type theory, like the predicative Martin-Löf type theory
[
26
]
, or the impredicative Calculus of (Inductive) Constructions
[
10
,
4
,
30
]
.
In the next section we define a strong version of type theory (
\lambda\mathrm{C}{+}
) that allows all interpretations.

3.1
Interpreting Natural Numbers

We will assume a type of natural numbers with inference rules:

\displaystyle\mathrlap{\hbox{$\vbox{\hbox{\hskip 22.68057pt\hbox{}}\hbox{\hskip 0.0pt\raise 0.0pt\hbox{\raise 3.29727pt\hbox{\hbox{\raise 0.0pt\hbox{\raise 1.72218pt\hbox{\vrule width=45.36115pt,height=0.51663pt}}}\thinspace\raise-1.35283pt\hbox{$\mathbb{N}$-F,}}}}\vbox{\vskip-2.00558pt\hbox{\hskip 3.00003pt\hbox{$\displaystyle\vdash\mathbb{N}:\mathsf{Type}\mathstrut$}}}}$}}

\displaystyle\mathllap{\hbox{$\vbox{\vbox{\hbox{\hskip 5.22227pt\hbox{\hbox{$\displaystyle{\Gamma\vdash n:\mathbb{N}}\mathstrut$}\hbox{$\displaystyle\mathstrut$}}}\vskip-2.03337pt}\hbox{\hskip 0.0pt\raise 0.0pt\hbox{\raise 3.32504pt\hbox{\hbox{\raise 0.0pt\hbox{\raise 1.72218pt\hbox{\vrule width=47.14117pt,height=0.51663pt}}}\thinspace\raise-1.32504pt\hbox{$\mathbb{N}$-I${}_{\mathsf{S}}$,}}}}\vbox{\vskip-2.03337pt\hbox{\hskip 3.00003pt\hbox{$\displaystyle\Gamma\vdash\mathsf{S}\,n:\mathbb{N}\mathstrut$}}}}$}}

\displaystyle\mathclap{\hbox{$\vbox{\vbox{\hbox{\hskip 3.00003pt\hbox{\hbox{$\displaystyle{\Gamma,n:\mathbb{N}\vdash C[n]:\mathsf{Type}}\mathstrut$}\hbox{$\displaystyle{\qquad{\Gamma\vdash c:C[0]}}\qquad{\Gamma\vdash f:\Pi(n:\mathbb{N})\,(C[n]\to C[\mathsf{S}\,n])}\mathstrut$}}}\vskip-2.00558pt}\hbox{\hskip 0.0pt\raise 0.0pt\hbox{\raise 3.29727pt\hbox{\hbox{\raise 0.0pt\hbox{\raise 1.72218pt\hbox{\vrule width=311.14978pt,height=0.51663pt}}}\thinspace\raise-1.35283pt\hbox{$\mathbb{N}$-E,}}}}\vbox{\vskip-2.00558pt\hbox{\hskip 99.72577pt\hbox{$\displaystyle\Gamma\vdash\mathsf{ind}^{\mathbb{N}}_{C}\,c\,f:\Pi(n:\mathbb{N})\,C[n]\mathstrut$}}}}$}}

\displaystyle\mathrlap{\hbox{$\vbox{\hbox{\hskip 31.70438pt\hbox{}}\hbox{\hskip 0.0pt\raise 0.0pt\hbox{\raise 3.32504pt\hbox{\hbox{\raise 0.0pt\hbox{\raise 1.72218pt\hbox{\vrule width=63.40875pt,height=0.51663pt}}}\thinspace\raise-1.3806pt\hbox{$\mathbb{N}$-$\beta_{0}$,}}}}\vbox{\vskip-2.03337pt\hbox{\hskip 3.00003pt\hbox{$\displaystyle\mathsf{ind}^{\mathbb{N}}_{C}\,c\,f\,0\equiv c\mathstrut$}}}}$}}

\displaystyle\mathllap{\hbox{$\vbox{\hbox{\hskip 69.45973pt\hbox{}}\hbox{\hskip 0.0pt\raise 0.0pt\hbox{\raise 3.32504pt\hbox{\hbox{\raise 0.0pt\hbox{\raise 1.72218pt\hbox{\vrule width=138.91946pt,height=0.51663pt}}}\thinspace\raise-1.3806pt\hbox{$\mathbb{N}$-$\beta_{\mathsf{S}}$.}}}}\vbox{\vskip-2.03337pt\hbox{\hskip 3.00003pt\hbox{$\displaystyle\mathsf{ind}^{\mathbb{N}}_{C}\,c\,f\,(\mathsf{S}\,n)\equiv f\,n\,(\mathsf{ind}^{\mathbb{N}}_{C}\,c\,f\,n)\mathstrut$}}}}$}}

It is sufficient for the
\beta
-reduction rules to be satisfied propositionally, an example that satisfies this is the definition of natural numbers using
\mathrm{W}
-types
[
26
,
13
]
.

A non-example is the Church encoding of natural numbers in an impredicative type theory.
In such a type theory, there exists a special universe
\mathsf{Prop}
that is closed under products over all types.
So, if we have an arbitrary type
A
, and for
x:A
a type
B[x]:\mathsf{Prop}
, then we always have
\Pi(x:A)\,B[x]:\mathsf{Prop}
.
This gives allows for self-referential definitions, that define a type in
\mathsf{Prop}
by quantifying over all types in
\mathsf{Prop}
; for example, the Church naturals:

\mathbb{N}\coloneqq\Pi(C:\mathsf{Prop})\,(C\to((C\to C)\to C)):\mathsf{Prop}.

The idea is that a numeral
n
can be encoded as
\lambda C\,\lambda c\,\lambda f\,f^{n}\,c
.
For
0\coloneqq\lambda C\,\lambda c\,\lambda f\,c
and
\mathsf{S}\,n\coloneqq\lambda C\,\lambda c\,\lambda f\,f\,(n\,C\,c\,f)
it indeed satisfies the formation and introduction rules.
However, it only satisfies a weak form of the elimination rule.
For
\mathsf{rec}^{\mathbb{N}}_{C}\,c\,f\coloneqq\lambda n.\,n\,C\,c\,f
we have:

\displaystyle{\Gamma\vdash C:\mathsf{Prop}}\mathstrut
\displaystyle{{\qquad{\Gamma\vdash c:C}}\qquad{\Gamma\vdash f:C\to C}}\qquad{\Gamma\vdash n:\mathbb{N}}\mathstrut

\mathbb{N}
-E, weak.

\displaystyle\Gamma\vdash\mathsf{rec}^{\mathbb{N}}_{C}\,c\,f:\mathbb{N}\to C\mathstrut

This is weaker in two ways: (a) it only gives functions instead of dependent functions, and (b) the codomain must be in
\mathsf{Prop}
.
From the perspective of category theory this means that we only have a weak natural numbers object
[
2
]
, and crucially, from a logical perspective this will mean that we cannot prove the axiom scheme of induction.

In the Calculus of Constructions it is not possible to define a type in
\mathsf{Prop}
that satisfies the strong elimination rule
[

]
.
The same story is true for other inductive types: we can define types that satisfy the correct introduction rules, however they only satisfy a weak version of the elimination rules
[

]
.
There is some exciting recent work in this area
[

,
32
]
: using some additional assumptions (

,

3.2
Interpreting Logical Connectives

Logical connectives are the most influential part: we have proof-relevant and proof-irrelevant interpretations.
We think of these as white box and black box interpretations respectively:

\displaystyle(A\lor B)^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}+B^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}},

\displaystyle(A\lor B)^{\bullet}

\displaystyle\coloneqq\|A^{\bullet}+B^{\bullet}\|,

\displaystyle(A\land B)^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\times B^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}},

\displaystyle(A\land B)^{\bullet}

\displaystyle\coloneqq\phantom{\|}A^{\bullet}\times B^{\bullet},

\displaystyle(A\to B)^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\to B^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}},

\displaystyle(A\to B)^{\bullet}

\displaystyle\coloneqq\phantom{\|}A^{\bullet}\to B^{\bullet},

\displaystyle(\text{\vphantom{${\forall}$}\hskip 0.0pt\smash{${\exists}$}\hskip 0.0pt}x^{A}\,B[x])^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq\text{\vphantom{${\Pi}$}\hskip 0.13889pt\smash{${\Sigma}$}\hskip 0.13889pt}(x:A)\,B[x]^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}},

\displaystyle(\text{\vphantom{${\forall}$}\hskip 0.0pt\smash{${\exists}$}\hskip 0.0pt}x^{A}\,B[x])^{\bullet}

\displaystyle\coloneqq\|\text{\vphantom{${\Pi}$}\hskip 0.13889pt\smash{${\Sigma}$}\hskip 0.13889pt}(x:A)\,B[x]^{\bullet}\|,

\displaystyle(\forall x^{A}\,B[x])^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq\Pi(x:A)\,B[x]^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}},

\displaystyle(\forall x^{A}\,B[x])^{\bullet}

\displaystyle\coloneqq\phantom{\|}\Pi(x:A)\,B[x]^{\bullet}.

The difference is that the proof-irrelevant interpretation uses propositional-truncation
[
37
, Section 3.7]
.
This makes sure that the type is always an h-proposition: a type of which every two terms are equal.
Conversely, for the proof-relevant interpretation: a term of the type shows how we know that the formula is true.
So, a proof for
A\lor B
consists of a proof for
A
or a proof for
B
, while a proof for
\exists x^{A}\,B[x]
consists of an
a:A
and a proof of
B[a]
.

3.3
Interpreting Power Sets

Power sets are the most difficult part to interpret.
In type theory, the power type is usually defined as
\mathcal{P}\,A\coloneqq A\to\mathcal{U}
, where
\mathcal{U}
is a universe.
We define:

\displaystyle(X=^{n}Y)^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq X=_{\mathcal{P}^{n}\mathbb{N}}Y,

\displaystyle(X=^{n}Y)^{\bullet}

\displaystyle\coloneqq\|X=_{\mathcal{P}^{n}\mathbb{N}}Y\|

\displaystyle(x\in^{n}X)^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}

\displaystyle\coloneqq X\,x,

\displaystyle(x\in^{n}X)^{\bullet}

\displaystyle\coloneqq\|X\,x\|.

To satisfy extensionality and comprehension, we need to make assumptions on
\mathcal{U}
:

•

To satisfy extensionality, it is necessary and sufficient for
\mathcal{U}
to satisfy:

\displaystyle\mathsf{funext}

\displaystyle:\Pi(f,f^{\prime}:A\to\mathcal{U})\,(\Pi(x:A)\,(f\,x=f^{\prime}\,x)\to(f=f^{\prime})),

\displaystyle\mathsf{propext}

\displaystyle:\Pi(P,P^{\prime}:\mathcal{U})\,((P\leftrightarrow P^{\prime})\to(P=P^{\prime})).

Note that
\mathsf{propext}
implies that
\mathcal{U}
only contains h-propositions: if
p:P
, then
P\leftrightarrow\mathbb{1}
so
P=\mathbb{1}
, which means that for any
p^{\prime}:P
we have
p=p^{\prime}
.
We can remove these requirements by changing the interpretation.
First, consider the equivalence relation on
A\to\mathcal{U}
given by:
X\sim Y\coloneqq\Pi(z:A)\,(X\,z\leftrightarrow Y\,z)
.
One option is to interpret
X=^{n}Y
using this equivalence relation instead of equality.
The other option is to assume that we have quotient types and to define
\mathcal{P}\,A\coloneqq(A\to\mathcal{U})/{\sim}
.
In the strong type theory that we consider in the next section, all three options can be shown to be equivalent, see
Appendix C
.
So, these alternatives do not affect the conservativity results.

•

To satisfy comprehension, we need to assume some amount of impredicativity.
For the proof-irrelevant interpretation, we do not have to make the entire universe impredicative.
It is sufficient to assume propositional-resizing: for any h-proposition, there exists a type in
\mathcal{U}
that is equivalent to it.
To see this, consider an HAH-formula
P[z^{n}]
.
We see that
P[z^{n}]^{\bullet}
is an h-proposition, so, there exists a type in
\mathcal{U}
that is equivalent to it.
This gives us an
X:\mathcal{P}^{n+1}\,\mathbb{N}
such that for every
z:\mathcal{P}^{n}\,\mathbb{N}
we have
X\,z\leftrightarrow P[z]^{\bullet}
.

4
Type Theory

Now that we have seen the options for interpreting HAH in type theory, we will formulate a strong version of type theory that allows all interpretations.
This theory is impredicative, extensional, and includes inductive types.
By proving conservativity for this strong version, we also obtain conservativity results for weaker versions: most notably for more predicative, and intensional versions of type theory.

Our type theory, which we call
\lambda
C
+
, can be seen as a version of the Calculus of Inductive Constructions
[
10
,
4
,
30
]
with only one level of universes.
It has two impredicative type universes:
\mathsf{Prop},\mathsf{Set}:\mathsf{Type}
.
It is extensional, so definitional equality and propositional equality coincide, which implies that we have function extensionality and uniqueness of identity proofs
[
18
]
.
We assume that we have
\mathbb{0},\mathbb{1},\mathbb{2},\dots,\mathbb{N},\Sigma,\Pi,\mathrm{W},{=},\|\cdot\|
, and quotient types.
Note that the universes are both types themselves, so we can use them to construct new types like
\mathsf{Prop}\times\mathsf{Set}
and
\mathbb{N}\to\mathsf{Prop}
.
We use
\mathsf{Prop}
to interpret logical connectives and power sets.
For this, we assume that
\mathsf{Prop}
satisfies the axiom of propositional extensionality.
This implies that the types in
\mathsf{Prop}
are h-propositions.
We use
\mathsf{Set}
to interpret the natural numbers, that is, we assume
\mathbb{N}:\mathsf{Set}
.
Because we have uniqueness of identity proofs, in particular we see that every type in
\mathsf{Set}
is an h-set.
Both universes are at the same level, that is, we do
not
have
\mathsf{Prop}:\mathsf{Set}
or
\mathsf{Set}:\mathsf{Prop}
.
However, we do assume that
\mathsf{Prop}
is a subuniverse of
\mathsf{Set}
, so
A:\mathsf{Prop}
implies
A:\mathsf{Set}
, and we have that
A:\mathsf{Set}
implies
A:\mathsf{Type}
.
The full rules of the type theory are stated in
Appendix A
.

5
Interpreting Type Theory in Higher-order Arithmetic

To interpret our type theory in arithmetic, we will construct a model of
\lambda
C
+
using only notions that we can express within HAH.
Our model can be seen as an modification of Hyland’s small complete category
[
19
]
, which forms a model for the calculus of constructions
[
31
]
.
Our description can be incorporated into one of the usual categorical frameworks for type theory, such as comprehension categories
[
20
]
, or categories with families
[
18
]
.
The main idea is that we interpret our universes using the following categories:

\displaystyle\mathsf{Prop}

\displaystyle\rightsquigarrow\mathsf{Subsing}~~

\displaystyle\text{(the category of subsingletons)},

\displaystyle\mathsf{Set}

\displaystyle\rightsquigarrow\mathsf{PER}~~

\displaystyle\text{(the category of partial equivalence relations)},

\displaystyle\mathsf{Type}

\displaystyle\rightsquigarrow\mathsf{Assem}~~

\displaystyle\text{(the category of assemblies or }\mathcal{K}_{1}\text{{}-sets)}.

We will show that these categories have the right structure to interpret
\lambda\mathrm{C}{+}
, namely: embeddings
\mathsf{Subsing}\hookrightarrow\mathsf{PER}\hookrightarrow\mathsf{Assem}
, that we can encode
\mathsf{Subsing}
and
\mathsf{PER}
as objects in
\mathsf{Assem}
, that we can define
\mathbf{0},\mathbf{1},\mathbf{2},\dots,\mathbf{N},\Sigma,\Pi,\mathrm{W},=,\|\cdot\|,{/}
, and that
\mathsf{propext}
and
\mathsf{reflexion}
are satisfied.
We use this model to interpret every type in
\lambda
C
+
as a formula in HAH: the formula stating that the type is inhabited in the model.
However, first we show why a naive model—of propositions, sets, and types in
\lambda
C
+
as sets in HAH or ZFC—cannot work.
The notions we define for this naive approach will be useful to define our actual model.

5.1
Sets in HAH

Conventions.

The sets in HAH are all subsets of
\mathcal{P}^{n}(\mathbb{N})
for some
n
.
It will be very convenient if we can view
\mathcal{P}^{n}(\mathbb{N})
as a subset of
\mathcal{P}^{n+1}(\mathbb{N})
.
Our motivation for this is that we want to define notions such as
\Sigma(a\in A)\,B[a],\Pi(a\in A)\,B[a],\mathrm{W}(a\in A)\,B[a]
.
If we view the hierarchy as cumulative, then we only need to define these notions for the case where
A
and all
B[a]
are subsets of the same
\mathcal{P}^{n}(\mathbb{N})
.
One way to achieve this is by considering
x\in\mathbb{N}
to be equal to
\{\cdots\{x\}\cdots\}\in\mathcal{P}^{n}(\mathbb{N})
.
This already gives us a cumulative hierarchy.
For example:
\{0,2\}\in\mathcal{P}(\mathbb{N})
is viewed as
\{\{0\},\{2\}\}\in\mathcal{P}^{2}(\mathbb{N})
, and
\{\{\{0\}\},\{\{2\}\}\}\in\mathcal{P}^{3}(\mathbb{N})
, and so on.
More formally: we define inclusions
\iota_{n}:\mathcal{P}^{n}(\mathbb{N})\to\mathcal{P}^{n+1}(\mathbb{N})
by
\iota_{0}(x)\coloneqq\{x\}
and
\iota_{n+1}(X)\coloneqq\{\iota_{n}(x)~|~x\in X\}
.
These are embeddings because they preserve
\in
-relation: we have
x\in Y
iff
\iota_{n}(x)\in\iota_{n+1}(Y)
.
From now on, we will use these emdeddings implicitly.

Secondly, it is convenient if we extend our definition of pairs from natural numbers to sets.
We do this using the disjoint union, for
A,B\subseteq\mathcal{P}^{n}(\mathbb{N})
we inductively define:

\langle A,B\rangle\coloneqq\{p\in\mathcal{P}^{n}(\mathbb{N})~|~\exists(a\in A)\,(p=\langle 0,a\rangle)\lor\exists(b\in B)\,(p=\langle 1,b\rangle)\}\in\mathcal{P}^{n}(\mathbb{N}).

Definitions.

Now we can inductively define
\Sigma,\Pi,\mathrm{W}
inside HAH.
If we have a set
A\subseteq\mathcal{P}^{n}(\mathbb{N})
and for every
a\in A
a set
B[a]\subseteq\mathcal{P}^{n}(\mathbb{N})
, then we define the dependent Cartesian product and dependent function space as follows:

\displaystyle\Sigma(a\in A)\,B[a]

\displaystyle\coloneqq\{\text{\vphantom{${P}$}\hskip 1.38889pt\smash{${p}$}\hskip 1.38889pt}\text{\vphantom{${{}\subseteq{}}$}\hskip 0.55556pt\smash{${\in}$}\hskip 0.55556pt}\text{\vphantom{${\Sigma(a\in A)\,B[a]}$}\smash{${\mathcal{P}^{n}(\mathbb{N})}$}\hskip 16.677pt\hskip 16.677pt}~|~\text{\vphantom{${\forall}$}\hskip 0.0pt\smash{${\exists}$}\hskip 0.0pt}(a\in A)\,\text{\vphantom{${\exists!}$}\hskip 2.2222pt\hskip 2.2222pt\smash{${\exists}$}}(b\in B[a])\,(\langle a,b\rangle=\text{\vphantom{${P}$}\hskip 1.38889pt\smash{${p}$}\hskip 1.38889pt})\}

\displaystyle\subseteq\mathcal{P}^{n}(\mathbb{N}),

\displaystyle\Pi(a\in A)\,B[a]

\displaystyle\coloneqq\{P\subseteq\Sigma(a\in A)\,B[a]~|~\forall(a\in A)\,\exists!(b\in B[a])\,(\langle a,b\rangle\text{\vphantom{${{}={}}$}\hskip 0.55556pt\smash{${\in}$}\hskip 0.55556pt}P)\}

\displaystyle\subseteq\mathcal{P}^{n+1}(\mathbb{N}).

To define
\mathrm{W}(a\in A)\,B[a]
we have to define labelled trees in HAH.
A tree for
A
and
B
must satisfy the following: every node has a label
a\in A
, and precisely one child for every
b\in B[a]
.
We will encode a tree by describing the set of finite paths starting at the root.
So, a tree will be a set
T\subseteq\mathcal{P}^{n}(\mathbb{N})
whose elements are of the form
\langle a_{0},b_{0},a_{1},\dots,a_{n-1},b_{n-1},a_{n}\rangle
such that for every
i
we have
a_{i}\in A
and
b_{i}\in B[a_{i}]
.
This set should be:

•

inhabited: there exists an
a\in A
such that
\langle a\rangle\in T
;

•

downward-closed: if
\langle a_{0},b_{0},a_{1},\dots,a_{n},b_{n},a_{n+1}\rangle\in T
then
\langle a_{0},b_{0},a_{1},\dots,a_{n}\rangle\in T
;

•

complete: if we have
\langle a_{0},b_{0},a_{1},\dots,a_{n}\rangle\in T
and
b_{n}\in B[a_{n}]
then there exists an
a_{n+1}\in A
such that
\langle a_{0},b_{0},a_{1},\dots,a_{n},b_{n},a_{n+1}\rangle\in T
;

•

consistent: if
\langle a_{0},b_{0},a_{1},\dots,b_{n-1},a_{n}\rangle,\langle a_{0},b_{0},a_{1},\dots,b_{n-1},a_{n}^{\prime}\rangle\in T
then
a_{n}=a_{n}^{\prime}
.

For two paths
p,q\in T
, we write
p\sqsubseteq q
iff
p
is a subpath of
q
, that is, iff we can write
p=\langle a_{0},b_{0},a_{1},\dots,a_{n}\rangle
and
q=\langle a_{0},b_{0},a_{1},\dots,a_{m}\rangle
where
n\leq m
.
We call a tree
T
well-founded iff the inverse relation
\sqsupseteq
is well-founded.
Now for
A,B[a\in A]\subseteq\mathcal{P}^{n}(\mathbb{N})
we define:

\displaystyle\mathrm{W}(a\in A)\,B[a]

\displaystyle\coloneqq\{T\subseteq\mathcal{P}^{n}(\mathbb{N})~|~T\text{ is a well-founded tree for $A$ and $B[a]$}\}

\displaystyle\subseteq\mathcal{P}^{n+1}(\mathbb{N}).

Problems.

It is important to note for
A,B[a\in A]\subseteq\mathcal{P}^{n}(\mathbb{N})
that, while
\Sigma(a\in A)\,B[a]
is still a subset of
\mathcal{P}^{n}(\mathbb{N})
, we see that
\Pi(a\in A)\,B[a]
and
\mathrm{W}(a\in A)\,B[a]
are both subsets of
\mathcal{P}^{n+1}(\mathbb{N})
.
So
\Pi
and
\mathrm{W}
increase the level.
This is a problem: if we interpret
\mathsf{Prop}
and
\mathsf{Set}
as subsets of some
\mathcal{P}^{n}(\mathbb{N})
then they cannot be closed under
\Pi
and
\mathrm{W}
.
This problem exists in general for naive interpretations of impredicative type theory.
If we interpret an impredicative universe as a set
\mathcal{U}
in ZFC, then for
A,B\in\mathcal{U}
we must have
A\to B\coloneqq\Pi(a\in A)\,B\in\mathcal{U}
.
If
\mathcal{U}
contains a set
A
with at least two elements, then we get a contradiction for the cardinality:

\displaystyle\textstyle|\Pi(B\in\mathcal{U})\,(B\to A)|

\displaystyle=\textstyle|(\Sigma(B\in\mathcal{U})\,B)\to A|

(by Currying)

\displaystyle\geq\textstyle|\mathcal{P}(\Sigma(B\in\mathcal{U})\,B)|

(because
|A|\geq 2
)

\displaystyle\geq\textstyle|\mathcal{P}(\Pi(B\in\mathcal{U})\,(B\to A))|

(because
\Pi(B\in\mathcal{U})\,(B\to A)\in\mathcal{U}
)

\displaystyle>\textstyle|\Pi(B\in\mathcal{U})\,(B\to A)|.

(by Cantor’s diagonal argument)

This counterexample comes from lectures of Hyland and Streicher, see
[
24
,
31
]
.
If
\mathcal{U}
only consists of subsingletons, then we have no contradiction, and we obtain a model for simple type theories like ML0 and
\lambda\mathrm{C}

[
33
]
.
Indeed, we use this approach to interpret
\mathsf{Prop}
as the set
\mathsf{Subsing}\coloneqq\mathcal{P}(\{*\})
.
The intuitive idea behind the other categories,
\mathsf{PER}
and
\mathsf{Assem}
, is that we restrict
\Pi(a\in A)\,B[a]
to functions that are in some sense computable.

5.2
Subsingletons, PERs, and Assemblies

In this subsection we define the three categories that we use to model
\lambda
C
+
.
This first category is simple: subsets of a singleton
\{*\}
:

Definition 4

(subsingleton)
.

A
subsingleton
is a subset
S\subseteq\{*\}
.
A
subsingleton morphism
from
S
to
T
is just a function from
S
to
T
.

Because we want our model to satisfy propositional extensionality, we always consider subsets of the same singleton
\{*\}
.
Note that we cannot prove intuitionistically for every
S\subseteq\{*\}
that
S=\emptyset
or
S=\{*\}
, so
\mathcal{P}(\{*\})
can be large
[
25
]
.

The next categories are more interesting and use a notion of compatibility.
We use Kleene’s first algebra
[
22
,
23
,
9
]
: the fact that natural numbers can be seen as codes for partial computable functions.
For
f,n\in\mathbb{N}
, we will write
f\,n\downarrow
iff the partial computable function encoded by
f
is defined on the natural number
n
, and
f\,n
for the result.
In
section 7
we will consider a conservative extension of HAH where these are primitive notions that satisfy a computational choice principle.
This will be needed to show conservativity in the proof-relevant case.
For now however, think of
f\,n
as Kleene-application.

Definition 5

(PER)
.

A
partial equivalence relation (PER)
is a relation
R\subseteq\mathbb{N}\times\mathbb{N}
that is symmetric and transitive.
For a PER
R
we define:

\displaystyle\operatorname{dom}(R)

\displaystyle\coloneqq\{\text{\vphantom{${m}$}\hskip 1.38889pt\smash{${n}$}\hskip 1.38889pt}\in\mathbb{N}~|~\langle n,\text{\vphantom{${m}$}\hskip 1.38889pt\smash{${n}$}\hskip 1.38889pt}\rangle\in R\}=\{n\in\mathbb{N}~|~\exists(m\in\mathbb{N})\,\langle n,m\rangle\in R\},

(domain)

\displaystyle[n]_{R}

\displaystyle\coloneqq\{m\in\mathbb{N}~|~\langle n,m\rangle\in R\},

(equivalence class)

\displaystyle\mathbb{N}/R

\displaystyle\coloneqq\{[n]_{R}~|~n\in\operatorname{dom}(R)\}.

(quotient)

A PER morphism from
R
to
S
is a function
F:\mathbb{N}/R\to\mathbb{N}/S
that is ‘tracked’ by some
f\in\mathbb{N}
, meaning that
a\in\operatorname{dom}(R)
implies
f\,a\downarrow
and
f\,a\in F([n]_{R})
.

Suppose that we have a type and that we want to define a PER that models it.
The idea is that we view natural numbers as potential codes or realizers for terms of the type.
The relation consists of those pairs of natural numbers that encode the same term.
This explains why we consider PER’s: this relation is obviously symmetric and transitive, but not necessarily reflexive because not every natural number has to encode a term.
Using this principle we define PER’s that model
\mathbb{0},\mathbb{1},\mathbb{2},\dots
, and
\mathbb{N}
:

\displaystyle\mathbf{n}\coloneqq\{\langle i,j\rangle~|~i=j\land i<n\},~~(\text{for }n=0,1,2,\dots)

\displaystyle\mathbf{N}\coloneqq\{\langle i,j\rangle~|~i=j\}.

The next category generalises this idea of modelling types:

Definition 6

(assembly)
.

An
n
-assembly consists of a set
\mathcal{A}\subseteq\mathcal{P}^{n}(\mathbb{N})
and a relation
{\Vdash}\subseteq\mathbb{N}\times\mathcal{A}
such that for every
A\in\mathcal{A}
there exists an
a\in\mathbb{N}
such that
a\Vdash_{\mathcal{A}}A
.
For an
n
-assembly
\mathcal{A}
we will write
|\mathcal{A}|
for the set and
\Vdash_{\mathcal{A}}
for the relation; we call
|\mathcal{A}|
the domain and
\Vdash_{\mathcal{A}}
the realizability relation.
An
n
-assembly morphism from
\mathcal{A}
to
\mathcal{B}
is a function
F
from
\mathcal{A}
to
\mathcal{B}
that is ‘tracked’ by some
f\in\mathbb{N}
, meaning that for every
A\in\mathcal{A}
and
a\in\mathbb{N}
with
a\Vdash_{\mathcal{A}}A
we have
f\,a\downarrow
and
f\,a\Vdash_{\mathcal{B}}F(A)
.

The inclusions
\iota_{n}:\mathcal{P}^{n}(\mathbb{N})\to\mathcal{P}^{n+1}(\mathbb{N})
also give us a cumulative hierarchy of assemblies.

Cumulativity.

We can view any subsingleton
S\subseteq\{*\}
as a PER
\{\langle i,j\rangle~|~*\in S\}
; in this way
\mathsf{Subsing}
forms a full subcategory of
\mathsf{PER}
.
Similarly we can view any PER
R
as a 1-assembly with domain
\mathbb{N}/R
and realizability relation
\in
; in this way
\mathsf{PER}
forms a full subcategory of
\mathsf{Assem}^{1}
.
This means that we have embeddings:
\mathsf{Subsing}\hookrightarrow\mathsf{PER}\hookrightarrow\mathsf{Assem}^{1}
.
Lastly, for any set
A\subseteq\mathcal{P}^{n}(\mathbb{N})
, we get an
n
-assembly
\nabla A
with domain
A
and the total realizability relation
\mathbb{N}\times A
; in this way
\mathcal{P}^{n}(\mathbb{N})
also forms a full subcategory of
\mathsf{Assem}^{n}
.

Universes.

We have to show that we can see the sets
\mathsf{Subsing}
and
\mathsf{PER}
as assemblies to model
\mathsf{Prop}:\mathsf{Type}
and
\mathsf{Set}:\mathsf{Type}
.
For
\mathsf{Subsing}
this is easy, if we take
*\coloneqq 0
, then we have
\mathsf{Subsing}=\mathcal{P}(\{0\})\subseteq\mathcal{P}(\mathbb{N})
so we get an 1-assembly
\nabla\mathsf{Subsing}
.
Similarly, we can consider a PER to be a subset of
\mathbb{N}\times\mathbb{N}\coloneqq\Sigma(x\in\mathbb{N})\,\mathbb{N}\subseteq\mathbb{N}
, so we get a
1
-assembly
\nabla\mathsf{PER}
.

5.3
Modelling Type Constructors

We define
\Sigma,\Pi,\mathrm{W}
for assemblies by restring the definitions for sets to those elements which are realised.
So, for
\mathcal{A},\mathcal{B}[A\in\mathcal{A}]\in\mathsf{Assem}^{n}
and
\mathcal{Q}=\Sigma,\Pi,\mathrm{W}
, we define the assembly
\mathcal{Q}(A\in\mathcal{A})\,\mathcal{B}[A]
by taking
|\mathcal{Q}(A\in\mathcal{A})\,\mathcal{B}[A]|\coloneqq\{Q\in\mathcal{Q}(A\in|\mathcal{A}|)\,|\mathcal{B}[A]|~|~\exists(q\in\mathbb{N})\,(q\Vdash Q)\}
, where
\Vdash
is defined as follows for the different quantifiers:

(\text{\vphantom{${\mathrm{W}}$}\hskip 1.52779pt\smash{${\Sigma}$}\hskip 1.52779pt})

We say
\text{\vphantom{${t}$}\hskip-0.71007pt\hskip-0.71007pt\smash{${p}$}}\Vdash\text{\vphantom{${T}$}\smash{${P}$}\hskip-0.2882pt\hskip-0.2882pt}
iff we have
\mathsf{pr}_{0}(p)\Vdash_{\mathcal{A}}\mathsf{pr}_{0}(P)
and
\mathsf{pr}_{1}(p)\Vdash_{\mathcal{B}[A]}\mathsf{pr}_{1}(P)
.

(\text{\vphantom{${\mathrm{W}}$}\hskip 1.3889pt\smash{${\Pi}$}\hskip 1.3889pt})

We say
\text{\vphantom{${t}$}\hskip-1.18057pt\hskip-1.18057pt\smash{${f}$}}\Vdash\text{\vphantom{${T}$}\smash{${F}$}\hskip-0.29341pt\hskip-0.29341pt}
iff for every
A\in\mathcal{A}
and
a\Vdash_{\mathcal{A}}A
we have
f\,a\downarrow
and
f\,a\Vdash_{\mathcal{B}[A]}F(A)
.

(\mathrm{W})

We say
t\Vdash T
iff for every
\langle A_{0},B_{0},A_{1},\dots,A_{n-1},B_{n-1},A_{n}\rangle\in T
and
b_{0}\Vdash_{\mathcal{B}[A_{0}]}B_{0},\dots,

b_{n-1}\Vdash_{\mathcal{B}[A_{n-1}]}B_{n-1}
we have that for
t_{0},\dots,t_{n-1}\in\mathbb{N}
given inductively by
t_{0}\coloneqq t
and
t_{i+1}\coloneqq(\mathsf{pr}_{1}(t_{i}))\,b_{i}
we have for every
i<n+1
that
t_{i}\downarrow
and
\mathsf{pr}_{0}(t_{i})\Vdash_{\mathcal{A}}A_{i}
.

Now that we have defined
\Sigma,\Pi,\mathrm{W}
for assemblies, we use this to define these notions also for subsingletons and PER’s.
This is possible because of the following observation:

Proposition 7
.

Suppose that
\mathcal{A}\in\mathsf{Assem}^{n}
and for every
A\in\mathcal{A}
that
\mathcal{B}[A]\in\mathsf{Assem}^{n}
.

•

If
\mathcal{A}
and all
\mathcal{B}[A]
are isomorphic to a subsingleton/PER, then
\Sigma(A\in\mathcal{A})\,\mathcal{B}[A]
is as well.

•

If all
\mathcal{B}[A]
are isomorphic to a subsingleton/PER, then
\Pi(A\in\mathcal{A})\,\mathcal{B}[A]
is as well.

•

If
\mathcal{A}
is isomorphic to a subsingleton/PER, then
\mathrm{W}(A\in\mathcal{A})\,\mathcal{B}[A]
is as well.

Note that this is precisely what we need to model our formation rules.
In particular, we can model the impredicative rule for products: up to isomorphism, we have that
\Pi(A\in\mathcal{A})\,\mathcal{B}[A]
always lives in the same category as the
\mathcal{B}[A]
, regardless of
\mathcal{A}
.

For
\mathcal{A}\in\mathsf{Assem}^{n}
we define propositional equality and truncation as subsingletons:

\displaystyle(A=_{\mathcal{A}}A^{\prime})

\displaystyle\coloneqq\{*~|~A=A^{\prime}\}\in\mathsf{Subsing},

\displaystyle\|\mathcal{A}\|

\displaystyle\coloneqq\{*~|~\exists(A\in\mathcal{A})\}\in\mathsf{Subsing}.

Lastly, if we have
\mathcal{A}\in\mathsf{Assem}^{n}
and for every
A,A^{\prime}\in\mathcal{A}
an
\mathcal{R}[A,A^{\prime}]\in\mathsf{Assem}^{n}
, then we define
\mathcal{A}/\mathcal{R}\in\mathsf{Assem}^{n+1}
by taking
|\mathcal{A}/\mathcal{R}|\coloneqq|\mathcal{A}|/\{\langle A,A^{\prime}\rangle~|~\exists(R\in\mathcal{R}[A,A^{\prime}])\}
and
q\Vdash Q
iff there exists an
A\in Q
such that
q\Vdash A
.
We can extend this to PER’s and subsingletons using:

Proposition 8
.

If
\mathcal{A}\in\mathsf{Assem}^{n}
is isomorphic to a subsingleton/PER, then
\mathcal{A}/\mathcal{R}
is as well.

5.4
Interpretation

Model.

Now that we have all of the building blocks, we pack everything together to build our model.
Using simultaneous induction on the derivation we define:

•

for any well-formed context
\Gamma
an
n
-assembly
\llbracket\Gamma\rrbracket
for some
n
;

•

for any judgement
\Gamma\vdash A:\mathsf{Type}
a function
\llbracket\Gamma\vdash A:\mathsf{Type}\rrbracket:\llbracket\Gamma\rrbracket\to\mathsf{Assem}^{n}
for some
n
;

•

for any judgement
\Gamma\vdash a:A
a morphism
\llbracket\Gamma\vdash a:A\rrbracket:\llbracket\Gamma\rrbracket\to\llbracket\Gamma\vdash A:\mathsf{Type}\rrbracket
.

Here contexts are the only part that we have not yet discussed.
We define

using

:

\displaystyle\llbracket\rrbracket

\displaystyle\coloneqq\mathbf{1},

\displaystyle\llbracket\Gamma,x:A\rrbracket

\displaystyle\coloneqq\Sigma(G\in\llbracket\Gamma\rrbracket)\,\llbracket\Gamma\vdash A:\mathsf{Type}\rrbracket(G).

The other two judgements use the structure that we have defined in the previous sections: the embeddings
\mathsf{Subsing}\hookrightarrow\mathsf{PER}\hookrightarrow\mathsf{Assem}^{1}
, the assemblies

and
\nabla\mathsf{PER}
, and the constructions
\mathbf{n},\mathbf{N},\Sigma,\Pi,\mathrm{W},=,\|\cdot\|,/
.
The full model is given in
Appendix B
.

Realizability.

Now that we have defined a model for
\lambda\mathrm{C}{+}
within
\mathrm{HAH}
, we consider the two interpretations
\smash{\mathrm{HAH}\stackrel{{\scriptstyle*}}{{\rightarrow}}\lambda\mathrm{C}{+}\to\mathrm{HAH}}
given by
*=\bullet,{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}
.
The idea is as follows: for a formula
A
, we get types
\Gamma_{A}\vdash A^{\bullet}:\mathsf{Prop}
and

7
Proof-relevant Conservativity

The proof-relevant interpretation turns our to be more difficult.
Here there exists a second-order formula that is not provable in HAH
[
8
]

[

\forall Z^{1}\,(\forall x^{0}\,\exists y^{0}\,\langle x,y\rangle\in Z\to\exists F^{1}\,(\forall x^{0}\,\exists!y^{0}\,\langle x,y\rangle\in F\land\forall x^{0}\,\forall y^{0}\,(\langle x,y\rangle\in F\to\langle x,y\rangle\in Z)).

This means that our best hope is to prove conservativity only for first-order formulas.
It turns our that this holds, but to prove it we have to modify our model and approach.

In the proof of
Theorem 9

\in
,
\to
, and
\forall
.
Because our conservativity will only hold for first-order formulas, we cannot use this shortcut.
It turns out that

Similarly, we can define

and

.
First we write out what
\langle z,z^{\prime}\rangle\in\llbracket A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket

.

In
\mathrm{HAH}

\displaystyle\langle z,z^{\prime}\rangle

\displaystyle\in\llbracket(\text{\vphantom{${\forall x^{0}B[x]}$}\hskip-2.1962pt\smash{${\text{\vphantom{${A}$}\hskip 1.10706pt\smash{${a}$}\hskip 1.10706pt}\text{\vphantom{${{}\to{}}$}\hskip-3.63196pt\smash{${=^{0}}$}\hskip-3.63196pt}\text{\vphantom{${B}$}\hskip 1.89757pt\smash{${b}$}\hskip 1.89757pt}}$}\hskip-2.1962pt})^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket

\displaystyle\langle z,z^{\prime}\rangle

\displaystyle\in\llbracket(\text{\vphantom{${\forall x^{0}B[x]}$}\hskip 5.59721pt\smash{${A\text{\vphantom{${{}\to{}}$}\hskip-0.83334pt\smash{${\land}$}\hskip-0.83334pt}B}$}\hskip 5.59721pt})^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket

\displaystyle\leftrightarrow\text{\vphantom{${\forall x,x^{\prime}\,(\langle x,x^{\prime}\rangle}$}\hskip 1.72906pt\hskip 1.72906pt\smash{${\langle\mathsf{pr}_{0}\,z,\hskip 2.0pt\mathsf{pr}_{0}\,z^{\prime}\rangle}$}}\in\llbracket A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket\text{\vphantom{${{}\to{}}$}\hskip-0.83334pt\smash{${\land}$}\hskip-0.83334pt}\langle\mathsf{pr}_{1}\,z,\hskip 2.0pt\mathsf{pr}_{1}\,z^{\prime}\rangle\in\llbracket B^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket,

Now, we will prove conservativity by using one extra assumption: that we have Hilbert-style epsilon constants.
That is, we assume for every first-order formula

\displaystyle\forall\vec{x}\,(\exists y\,A[\vec{x},y]\to\epsilon_{y.A}\,\vec{x}\downarrow),

First, we show how this allows us to prove conservativity:

What remains is proving that we can make this assumption.
Here, we translate the approach of

First, in

7.1
Higher-order Logic of Partial Terms

We will consider a higher-order version of the logic of partial terms by Beeson
[
3
, Section VI.1]
.
In this logic, function symbols are allowed to correspond to partial functions.
So, if we have a function symbol
f
then
f(\vec{x})
is not necessarily defined.
For every term
a
we add a new atomic formula
a\,\downarrow
, which stands for ‘
a
is defined’.
We add the following inference rules:

\downarrow
-var,

\displaystyle\Gamma\vdash x^{n}\downarrow,\mathstrut

\displaystyle{\Gamma\vdash f(a_{0}^{n_{0}},\dots,a_{k-1}^{n_{k-1}})\downarrow}\mathstrut

\downarrow
-fun,

\displaystyle\Gamma\vdash a_{i}^{n_{i}}\downarrow\mathstrut

\displaystyle{\Gamma\vdash R(a_{0}^{n_{0}},\dots,a_{k-1}^{n_{k-1}})}\mathstrut

\downarrow
-rel.

\displaystyle\Gamma\vdash a_{i}^{n_{i}}\downarrow\mathstrut

Note that we view
=^{n}
and
\in^{n}
as relation symbols, so the
\downarrow
-rel rule applies.
In addition, we modify the exists introduction and forall elimination rules:

\displaystyle{\Gamma\vdash B[a^{n}]}\mathstrut
\displaystyle\qquad{\Gamma\vdash a^{n}\downarrow}\mathstrut

\exists
-I,

\displaystyle\Gamma\vdash\exists x^{n}\,B[x^{n}]\mathstrut

\displaystyle{\Gamma\vdash\forall x^{n}\,B[x^{n}]}\mathstrut
\displaystyle\qquad{\Gamma\vdash a^{n}\downarrow}\mathstrut

\forall
-E.

\displaystyle\Gamma\vdash B[a^{n}]\mathstrut

The other rules are the same as those of higher-order logic.
In this logic, is often useful to consider a weaker notion of equality that also holds for terms that are not defined:
a^{n}\simeq b^{n}\coloneqq a\downarrow\lor b\downarrow\to a=b
.

Any theory in higher-order logic can be seen as a theory in the higher-order logic of partial terms by adding for every function symbol
f:(n^{0},\dots,n^{k})\to m
the axiom
\forall x_{0}^{n_{0}}\,\dots\,\forall x_{k}^{n^{k}}\,f(x_{0},\dots,x_{k})\downarrow
.
Accordingly, we will view HAH as a theory in this new logic.

7.2
HAHP: Adding Primitive Application

In HAHP, we extend the language with a binary partial function symbol
\mathsf{app}:(0,0)\rightharpoonup 0
, and constants
\mathsf{k},\mathsf{s},\mathsf{suc},\mathsf{rec}:0
which stand for natural numbers encoding basic functions:
\mathsf{k}
and
\mathsf{s}
give a partial combinatory algebra
[
5
]
,
\mathsf{suc}
computes the successor function, and
\mathsf{rec}
allows us to do recursion.
We abbreviate
\mathsf{app}(a,b)
as
a\,b
.
For
\mathsf{k},\mathsf{s},\mathsf{suc},\mathsf{rec}
, we add the axioms:

\displaystyle\forall x\,\forall y\,(\mathsf{k}\,x\,y=x),

\displaystyle\forall x\,\mathsf{suc}\,x=\mathsf{S}(x),

\displaystyle\forall x\,\forall y\,(\mathsf{s}\,x\,y\downarrow),

\displaystyle\forall x\,\forall y\,(\mathsf{rec}\,x\,y\,0=x),

\displaystyle\forall x\,\forall y\,\forall z\,(\mathsf{s}\,x\,y\,z\simeq(x\,z)\,(y\,z)),

\displaystyle\forall x\,\forall y\,\forall z\,(\mathsf{rec}\,x\,y\,(\mathsf{S}\,z)\simeq y\,z\,(\mathsf{rec}\,x\,y\,z)).

The reason for
\mathsf{k}
and
\mathsf{s}
is that they are used to define lambda abstraction:

\displaystyle\lambda x\,x

\displaystyle\coloneqq\mathsf{s}\,\mathsf{k}\,\mathsf{k},

\displaystyle\lambda x\,\mathsf{S}(b[x])

\displaystyle\coloneqq\lambda x\,(\text{\vphantom{${\mathsf{add}}$}\hskip 0.84724pt\smash{${\mathsf{suc}}$}\hskip 0.84724pt}\,b[x]),

\displaystyle\lambda x\,\text{\vphantom{${x}$}\hskip 0.69386pt\smash{${c}$}\hskip 0.69386pt}

\displaystyle\coloneqq\mathsf{k}\,c,\qquad(\text{if $c\neq x$})

\displaystyle\lambda x\,b[x]+c[x]

\displaystyle\coloneqq\lambda x\,(\mathsf{add}\,b[x]\,c[x]),

\displaystyle\lambda x\,(b[x]\,c[x])

\displaystyle\coloneqq\mathsf{s}\,(\lambda x\,b[x])\,(\lambda x\,b[x]),

\displaystyle\lambda x\,b[x]\times c[x]

\displaystyle\coloneqq\lambda x\,(\text{\vphantom{${\mathsf{add}}$}\hskip-0.18054pt\smash{${\mathsf{mul}}$}\hskip-0.18054pt}\,b[x]\,c[x]),

where
\mathsf{add}\coloneqq\lambda y\,\mathsf{rec}\,\text{\vphantom{${1}$}\hskip-0.1308pt\smash{${y}$}\hskip-0.1308pt}\,(\lambda i\,\lambda r\,\text{\vphantom{${\mathsf{add}}$}\hskip 0.84724pt\smash{${\mathsf{suc}}$}\hskip 0.84724pt}\,r)
and
\mathsf{mul}\coloneqq\lambda y\,\mathsf{rec}\,1\,(\lambda i\,\lambda r\,\mathsf{add}\,r\,y)
.

These lambda functions are enough to construct our model in HAHP using
\mathsf{app}
as our application.
From now on, we will view
*\in\llbracket A^{\bullet}\rrbracket
and
\exists z\,\langle z,z\rangle\in\llbracket A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}\rrbracket
as HAHP-formulas.

Theorem 13
.

\mathrm{HAHP}
is conservative over
\mathrm{HAH}
.

Proof.

Kleene-application satisfies the axioms of HAHP.
Here,
\mathsf{app}(a,b)
is the application of the partial recursive function encoded by
a
to
b
.
See
[
36
, Proposition 9.3.12]
for more.
∎

7.3
HAHP
\bm{\epsilon}
: Adding Computable Choice

In HAHP
\epsilon
, we extend the theory even further by adding a constant
\epsilon_{\exists yA}:0
for every HAH-formula
A[x_{0}^{0},\dots,x_{k-1}^{0},y^{0}]
, and adding the following axioms:

\displaystyle\forall\vec{x}\,(\exists y\,A[\vec{x},y]\to{\epsilon_{\exists y\,A}\,\vec{x}\downarrow}),

\displaystyle\forall\vec{x}\,({\epsilon_{\exists y\,A}\,\vec{x}\downarrow}\to A[\vec{x},\epsilon_{\exists y\,A}\,\vec{x}]).

These constants can be thought of as a choice function that miraculously choose a value that satisfies the formula if such a value exists.
Such functions do not exist for Kleene-application, so HAHP
\epsilon
is not conservative over HAHP.
However, perhaps surprisingly, the theory is conservative over HAH as we will prove in the remainder of this subsection.

Proposition 14
.

Suppose that
A[x^{0},y^{0}]
is an
\mathrm{HAH}
-formula and let
\mathrm{HAHP}R
be the extension of
\mathrm{HAHP}
with a relation symbol
R:(0,0)
and axioms:

\displaystyle\forall x\,!y\,R(x,y),

\displaystyle\forall x\,(\exists y\,A[x,y]\to\exists y\,R(x,y)),

\displaystyle\forall x\,\forall y\,(R(x,y)\to A[x,y]),

where
!y
means ‘at most one
y
’ which is defined by
!y\,B[y]\coloneqq\forall y\,\forall y^{\prime}\,(B[y]\land B[y^{\prime}]\to y=y^{\prime})
.
Then
\mathrm{HAHP}R
is conservative over
\mathrm{HAHP}
.

Proof.

We prove this using forcing.
We define a forcing condition
P
to be a finite approximation of the relation
R
: a finite set of pairs
\{\langle x_{0},y_{0}\rangle,\dots,\langle x_{n-1},y_{n-1}\rangle\}
where the
x_{i}
are distinct and for every
i<n
we have
A(x_{i},y_{i})
.
For a forcing condition
P
and an
\mathrm{HAHP}R
-formula
A
we define a
\mathrm{HAHP}
-formula
P\Vdash_{R}A
with induction on
A
:

\displaystyle P\Vdash_{R}A

\displaystyle\coloneqq A,

(if
A
is an atomic HAHP-formula)

\displaystyle P\Vdash_{R}R(x,y)

\displaystyle\coloneqq\forall(P^{\prime}\supseteq P)\,\exists(P^{\prime\prime}\supseteq P^{\prime})\,(\langle x,y\rangle\in P^{\prime\prime}),

\displaystyle P\Vdash_{R}A\lor B

\displaystyle\coloneqq\forall(P^{\prime}\supseteq P)\,\exists(P^{\prime\prime}\supseteq P^{\prime})\,((P^{\prime\prime}\Vdash_{R}A)\lor(P^{\prime\prime}\Vdash_{R}B)),

\displaystyle P\Vdash_{R}A\land B

\displaystyle\coloneqq(P\Vdash_{R}A)\land(P\Vdash_{R}B),

\displaystyle P\Vdash_{R}A\to B

\displaystyle\coloneqq\forall(P^{\prime}\supseteq P)\,((P^{\prime}\Vdash_{R}A)\to(P^{\prime}\Vdash_{R}B)),

\displaystyle P\Vdash_{R}\exists x^{n}\,B[x]

\displaystyle\coloneqq\forall(P^{\prime}\supseteq P)\,\exists(P^{\prime\prime}\supseteq P^{\prime})\,\exists x^{n}\,(P^{\prime\prime}\Vdash_{R}B[x^{n}]),

\displaystyle P\Vdash_{R}\forall x^{n}\,B[x]

\displaystyle\coloneqq\forall(P^{\prime}\supseteq P)\,\forall x^{n}\,(P^{\prime}\Vdash_{R}B[x]).

As usual, we can prove with induction for every
\mathrm{HAHP}R
-formula
A
that we have:

\displaystyle\mathrm{HAHP}\vdash\forall P\,\forall(P^{\prime}\supseteq P)\,((P\Vdash_{R}A)\to(P^{\prime}\Vdash_{R}A)),

\displaystyle\mathrm{HAHP}\vdash\forall P\,(\forall(P^{\prime}\supseteq P)\,\exists(P^{\prime\prime}\supseteq P^{\prime})\,(P^{\prime\prime}\Vdash_{R}A)\to(P\Vdash_{R}A)),

and with induction for every
\mathrm{HAHP}
-formula
B
that we have:

\displaystyle\mathrm{HAHP}\vdash\forall P\,((P\Vdash_{R}B)\leftrightarrow B).

Using this, we show for every
\mathrm{HAHP}R
-formula
A
that
\mathrm{HAHP}R\vdash A
implies
\mathsf{HAHP}\vdash\forall P\,(P\Vdash_{R}A)
with induction on the proof of
\mathsf{HAHP}R\vdash A
.
This is tedious but straightforward.
See also the proof of
[
38
, Proposition 2.5]
where they show a similar statement.

This shows that
\mathsf{HAHP}R
is conservative over
\mathsf{HAHP}
: suppose for a
\mathsf{HAHP}
-formula
B
that we have
\mathsf{HAHP}R\vdash B
, then we have
\mathsf{HAHP}\vdash\forall P\,(P\Vdash_{R}B)
and therefore
\mathsf{HAHP}\vdash B
.
∎

Proposition 15
.

Suppose that
A[x^{0},y^{0}]
is an
\mathrm{HAH}
-formula and let
\mathrm{HAHP}f
be the extension of
\mathrm{HAHP}
with a partial function symbol
f:0\rightharpoonup 0
and axioms:

\displaystyle\forall x\,(\exists y\,A[x,y]\to f(x)\downarrow),

\displaystyle\forall x\,(f(x)\downarrow\to A[x,f(x)]).

Then
\mathrm{HAHP}f
is conservative over
\mathrm{HAHP}
.

Proof.

This follows because every
n
-ary function symbol
f
can be encoded as an
(n+1)
-ary relation symbol
R
and an axiom
\forall\vec{x}\,!y\,R(\vec{x},y)
.
The axioms of
14
are precisely the axioms of this proposition under this encoding.
For a similar translation in more detail, see
[
35
, Section 2.7]
.
∎

Proposition 16
.

Suppose that
A[x^{0},y^{0}]
is an
\mathrm{HAH}
-formula and let
\mathrm{HAHP}\mathsf{c}
be the extension of
\mathrm{HAHP}
with a constant
\mathsf{c}:0
and axioms:

\displaystyle\forall x\,(\exists y\,A[x,y]\to\mathsf{c}\,x\downarrow),

\displaystyle\forall x\,(\mathsf{c}\,x\downarrow\to A[x,\mathsf{c}\,x]).

Then
\mathrm{HAHP}\mathsf{c}
is conservative over
\mathrm{HAH}
.

Proof.

We work in
\mathrm{HAHP}f
and use our existing evaluation
\mathsf{eval}(a,b)
to define a new evaluation
\mathsf{eval}^{f}(a,b)
, which can use the partial function symbol
f
as an oracle.

The informal idea to calculate
\mathsf{eval}^{f}(a,b)
is the following.
We start by calculating
\mathsf{eval}(a,b)
.
If this returns a value
\langle 0,x_{0}\rangle
then that means that the function
a
wants to ask the oracle for the result of applying
f
to
x_{0}
.
So we supply this value and run the function again, now we calculate
\mathsf{eval}(a,\langle b,f(x_{0})\rangle)
.
If this returns a value
\langle 0,x_{1}\rangle
then the function
a
want another result from the oracle so we calculate
\mathsf{eval}(a,\langle b,f(x_{0}),f(x_{1})\rangle)
.
We keep doing this until
a
eventually returns a value
\langle 1,c\rangle
in which case we say
\mathsf{eval}^{f}(a,b)=c
.

More formally, we say that the formula
\mathsf{eval}^{f}(a,b)=c
is true if there exists a sequence
\langle x_{0},\dots,x_{n-1}\rangle
such that:

•

for every
i<n
we have
\mathsf{eval}(a,\langle b,f(x_{0}),\dots,f(x_{i-1})\rangle)=\langle 0,x_{i}\rangle
;

•

\mathsf{eval}(a,\langle b,f(x_{0}),\dots,f(x_{n-1})\rangle)=\langle 1,c\rangle
.

For this new evaluation we can define new constants
\mathsf{k}^{f},\mathsf{s}^{f},\mathsf{suc}^{f},\mathsf{rec}^{f}
which leads to a new lambda abstraction
\lambda^{f}
.
For the details, see
[
39
, Theorem 2.2]
.

We can use this to show that
\mathrm{HAHP}\mathsf{c}
is conservative over
\mathrm{HAH}
.
For any
\mathrm{HAHP}\mathsf{c}
-formula
A
we relativize the evaluation and constants to
f
to get an
\mathrm{HAHP}f
-formula
A^{f}
, we can prove with induction that we have
\mathrm{HAHP}\mathsf{c}\vdash A
iff
\mathrm{HAHP}f\vdash A^{f}
.
For an
\mathrm{HAH}
-formula
B
we see that
B^{f}
is the same as
B
so
\mathrm{HAHP}\mathsf{c}\vdash B
implies
\mathrm{HAHP}f\vdash B
which implies
\mathrm{HAH}\vdash B
.
∎

Theorem 17
.

\mathrm{HAHP}\epsilon
is conservative over
\mathrm{HAH}
.

Proof.

Suppose that we have
\mathsf{HAHP}\epsilon\vdash A
for an
\mathsf{HAH}
-formula
A
.
Note that the proof for
A
can only use a finite amount of choice functions, say
\epsilon_{\exists y\,B_{i}}
for
i<n
.
We can modify the proof of
A
to use only the choice function
\epsilon_{\exists y\,C}
where
C[z,y]\coloneqq\bigwedge_{i<n}\forall\vec{x}\,(z=\langle i,\vec{x}\rangle\to B_{i}[\vec{x},y])
.
So the theorem follows from the previous proposition.
∎

Corollary 18

(proof-relevant conservativity)
.

For a first-order arithmetical formula
A
, we have that
\mathrm{HAH}
proves
A
iff there exists a term
a
such that
\lambda\mathrm{C}{+}
proves
\Gamma_{A}\vdash a:A^{\text{\vphantom{${\bullet}$}\hskip 0.0pt\smash{${\circ}$}\hskip 0.0pt}}
.

Proof.

This follows from
Theorem 12
and
Theorem 17
in the same way as
10
.
∎

8
De Jongh’s Theorem for Type Theory

In this section we discuss an application of our results and our initial motivation.
De Jongh’s original theorem shows that the axioms of HA respect the intuitionistic logic:

Theorem 19

(De Jongh
[
11
]
)
.

Let
A[P_{0},\dots,P_{n-1}]
be a propositional formula with propositional variables
P_{0},\dots,P_{n-1}
.
If
A
is not provable in intuitionistic propositional logic then we can construct sentences
B_{0},\dots,B_{n-1}
in the language of
\mathrm{HA}
such that
A[B_{0},\dots,B_{n-1}]
is not provable in
\mathrm{HA}
.

De Jongh and Smorynski also prove a similar theorem for HA2
[
12
]
.
This is not the case for any theory, for example ZF: there are propositional formulas that are not provable intuitionistically, but for which every concrete instance can be derived intuitionistically from the axioms of ZF
[
14
]
.
Recently, Robert Passmann has shown that De Jongh’s theorem does hold for CZF and IZF (which are equivalent to ZF classically but not intuitionistically)
[
28
,
29
]
.
Our goal was to prove similar results for type theory.
First we observe that we can use Passman’s proof to obtain a new result for HAH:

Corollary 20
.

De Jongh’s Theorem holds for
\mathrm{HAH}
.

Proof.

This theorem follows from Passmann’s proof for IZF because of the following two observations: HAH can be seen as a subtheory of IZF, and the sentences
B_{0},\dots,B_{n-1}
used by Passmann can already be stated in the language of HAH.
See
Appendix D
.
∎

Now, using our conservativity results, we see the following:

Corollary 21
.

De Jongh’s Theorem holds for
\lambda\mathrm{C}{+}
(and smaller type theories) for both the proof-relevant and proof-irrelevant interpretations of (higher-order) logic.

9
Conclusion and Future Work

Our results give us a new way of looking at proof-(ir)relevance.
While these two interpretations prove different second-order formulas, we see that they can still coincide for first-order formulas.
In addition, we obtain a characterisation of the arithmetical formulas provable in type theory:

•

without universes: less formulas than HA, see
[
3
, Theorem 7.5.1]
.

•

with one level of impredicative universes: the same formulas as HAH, see Theorems
9
,
12
.

•

with one level of predicative universes: less formulas than HAH, see
subsection 3.3
.

It would be interesting to consider more levels of universes: to which arithmetical theories does this correspond?
In addition, if can find a predicative version of higher-order logic, then this could give a more precise characterisation for predicative universes.

, using the elimination rule for quotient types.

(e)

Appendix D
De Jongh’s Theorem for HAH

Corollary

(De Jongh’s theorem for
\mathrm{HAH}
)
.

Let
A[P_{0},\dots,P_{n-1}]
be a propositional formula with propositional variables
P_{0},\dots,P_{n-1}
.
If
A
is not provable in intuitionistic propositional logic then we can construct sentences
B_{0},\dots,B_{n-1}
in the language of
\mathrm{HAH}
such that
A[B_{0},\dots,B_{n-1}]
is not provable in
\mathrm{HAH}
.

Proof.

Firstly, every higher-order arithmetical formula can be seen as a first-order formula in the language of set theory by interpreting
\exists x^{n}
as
\exists(x\in\mathcal{P}^{n}(\omega))
and
\forall x^{n}
as
\forall(x\in\mathcal{P}^{n}(\omega))
.
IZF proves the axioms of HAH so we can view HAH as a subtheory of IZF.
Now, in the proof of De Jongh’s theorem for IZF, Passmann
[
28
]
constructs suitable
B_{0},\dots,B_{n-1}
of the form:

\textstyle\bigvee_{k}(\Gamma_{k}\land\bigwedge_{l}\neg(\neg\Delta_{l}\land\Delta_{l+1})),

where
\Gamma_{k}
and
\Delta_{l}
are roughly the following set theoretic formulas:

\displaystyle\Gamma_{k}\coloneqq(|\mathcal{P}(1)|<k),

\displaystyle\Delta_{l}\coloneqq(|\mathcal{P}(\aleph_{0})|<\aleph_{l}).

More precisely, the formula
\Gamma_{k}
can be stated in the language of HAH as follows:

\displaystyle\Gamma_{k}

\displaystyle\coloneqq\textstyle\forall X_{0}^{1}\,\cdots\,\forall X_{k-1}^{1}\,(\bigwedge_{i<k}(\forall y^{0}(y\in X_{i}\to y=0))\to\bigvee_{i<j<k}(x_{i}=x_{j})).

Note that
\Gamma_{k}
is not trivial in constructive set theory because we cannot prove for every set of the form
\{x\in 1\,|\,A\}
that it equal to
0=\emptyset
or
1=\{\emptyset\}
.
For
\Delta_{l}
we can take any of the equivalent definitions for the statement
|\mathcal{P}(\aleph_{0})|<\aleph_{l}
in ZFC.
One possible definition of
\Delta_{l}
in the language of HAH is the following:

\displaystyle\Delta_{l}

\displaystyle\coloneqq\textstyle\forall\mathcal{X}_{0}^{2}\,\cdots\,\forall\mathcal{X}_{l}^{2}\,(\bigwedge_{i<l+1}\mathsf{is\text{-}infinite}(\mathcal{X}_{i})\to\bigvee_{i<j<l+1}(|\mathcal{X}_{i}|=|\mathcal{X}_{j}|)).

Note that the
\mathcal{X}_{i}
are of level 2 so in IZF they will be interpreted as elements of
\mathcal{P}^{2}(\omega)
which are subsets of
\mathcal{P}(\omega)
.
So
\Delta_{l}
states that for any
l+1
infinite subsets of
\mathcal{P}(\mathbb{N})
there must be two that have the same cardinality.
This means that we have at most
l
infinite subsets of
\mathcal{P}(\mathbb{N})
with distinct cardinalities, in which case we would have
\mathbb{\omega}=\aleph_{0},\dots,\aleph_{l-1}=\mathcal{P}(\omega)
.
Here we make use of the following definitions:

\displaystyle|X^{n+1}|=|Y^{n+1}|

\displaystyle\coloneqq\exists\text{\vphantom{${Y^{n+1}}$}\hskip 0.24306pt\hskip 0.24306pt\smash{${Z^{n+1}}$}}\,(\forall(x\in X)\,\exists!(\text{\vphantom{${x}$}\hskip 0.22684pt\smash{${y}$}\hskip 0.22684pt}\in\text{\vphantom{${X}$}\hskip 0.52083pt\smash{${Y}$}\hskip 0.52083pt})\,(\langle x,y\rangle\in Z)\land{}

\displaystyle\phantom{{}\coloneqq\exists\text{\vphantom{${Y^{n+1}}$}\hskip 0.24306pt\hskip 0.24306pt\smash{${Z^{n+1}}$}}\,(}\forall(\text{\vphantom{${x}$}\hskip 0.22684pt\smash{${y}$}\hskip 0.22684pt}\in\text{\vphantom{${X}$}\hskip 0.52083pt\smash{${Y}$}\hskip 0.52083pt})\,\exists!(x\in X)\,(\langle x,y\rangle\in Z)),

\displaystyle\mathsf{is\text{-}infinite}(X^{n+1})

\displaystyle\coloneqq\text{\vphantom{${\forall}$}\hskip 0.0pt\smash{${\exists}$}\hskip 0.0pt}Y^{n+1}\,(\text{\vphantom{${\forall}$}\hskip 0.0pt\smash{${\exists}$}\hskip 0.0pt}(x\in X)\,(x\notin Y)\land\forall(y\in Y)\,(y\in X)\land|X|=|Y|).

Note that we use Dedekinds definition of infinity because it is easier to state in the language of HAH.
It is equivalent to the usual notion of infinity in ZFC.
Now, suppose that we have a propositional formula
A[P_{0},\dots,P_{n-1}]
that is not provable in intuitionistic logic.
Passmann shows that there are
B_{0},\dots,B_{n-1}
such that
A[B_{0},\dots,B_{n-1}]
is not provable in IZF.
But we can view
B_{0},\dots,B_{n-1}
as HAH-formulas and then
A[B_{0},\dots,B_{n-1}]
is certainly not provable in HAH because we can view HAH as a subtheory of IZF.
∎
