1
Introduction

Recently, the invention of quantum computers was so revolutionary that they bring transformative challenges in a variety of fields, especially for the traditional cryptographic blockchain, and it may become a real thread for most of the cryptocurrencies in the market. That is, it becomes inevitable to consider to implement a post-quantum cryptography, which is also referred to as quantum-resistant cryptography, and post-quantum ledger for attaining quantum resistance in blockchains.

One of the known quantum cryptography is the so-called, quantum key distribution (QKD). There exists a conceptually huge gap between the quantum key distribution and the public key cryptography (PKC). The security of key-encryption in QKD relies based on the mathematical foundation of quantum information theory, in contrast to traditional PKC that relies on the computational difficulty of the algebraic structure of elliptic curves over finite fields, which can not provide any mathematical proof as to the actual complexity of reversing the mathematical functions used. The key ingredient of QKD is based on the fundamental principle of quantum mechanics, in which the process of measuring a quantum system disturbs the system. If there is some third-party attacks to read the encrypted data, the quantum state in a Hilbert space, which is initially a superposition of several states in the Hilbert space, reduces to a single state that differs from the original state.

(Perfect secure)

(1)

Recall that One-Time Pad is a Shanon’s cipher

\displaystyle({\mathcal{K}},\mathcal{M},\mathcal{C})

\displaystyle|{\mathcal{K}}|=|{\mathcal{M}}|=|{\mathcal{C}}|=\{0,1\}^{L}

2.3
Block cipher

Definition 2.20

(Block cipher)
.

A block cipher is a deterministic cipher
\displaystyle{\mathcal{E}}=({\mathsf{Gen}},{\mathsf{Enc}},{\mathsf{Dec}})
whose message space and cipher space are given by the same set
\displaystyle{\mathcal{S}}
. We call
\displaystyle S
as the data block space, and whose element
\displaystyle s\in S
is referred as the data block.

There is a famous product of block cipher, which is the so-called, AES (Advanced Encryption Standard). The AES keys (or, AES data block) has 128-bit strings, hence the size of data block space is given by
\displaystyle|\mathcal{S}|=2^{128}
. The key ingredient of block cipher is that we choose two steps for choosing random numbers: 1) random choice of keys, 2) random permutation of a chosen key. We denotes the set of all permutations on
\displaystyle\mathcal{S}
as
\displaystyle{\mathsf{Perm{[\mathcal{S}]}}}
. The size of those set is given by
\displaystyle|{\mathsf{Perm{[\mathcal{S}]}}}|=|\mathcal{S}|!
. In the case of AES scheme with
\displaystyle|\mathcal{S}|=2^{128}
, the number of permutations is about

|{\mathsf{Perm{[\mathcal{S}]}}}|\cong 2^{2^{135}}\;,

(12)

while the number of permutations defined by 128-bit strings AES scheme is at most
\displaystyle 2^{128}
. More precisely, block cipher is constructed to behave as pseudo-random permutations. Because there are
\displaystyle 2^{\ell}!
permutations on
\displaystyle\ell
-bit strings, it is said that a secure block cipher should be computational indistinguishable from a random permutation.

A block cipher
\displaystyle{\mathcal{E}}

\displaystyle{\mathcal{A}}

Let

\displaystyle{\mathcal{E}}

\displaystyle k\in{\mathcal{K}}

\displaystyle i

\displaystyle{\mathsf{Enc}}(k,x_{i})\in\mathcal{S}

\displaystyle{\mathcal{A}}

\displaystyle(x_{q+1},\,y)
, where
\displaystyle x_{q+1}\notin\{x_{1},\cdots,x_{q}\}
. The adversary
\displaystyle{\mathcal{A}}
wins this prediction game if
\displaystyle y={\mathsf{Enc}}(k,x_{q+1})
.

Furthermore, if
\displaystyle{\mathcal{E}}
is unpredictable, then it is secure against key-recovery, which means that every efficient adversary wins the following key-recovery game with negligible probability. In the key-recovery game, the adversary interacts with the challenger as the same with the prediction game, except that at the end, the adversary
\displaystyle{\mathcal{A}}
outputs a candidate key
\displaystyle k^{\prime}\in{\mathcal{K}}
, and
\displaystyle{\mathcal{A}}
wins the game if
\displaystyle k^{\prime}=k
.

Combining those two implications, if
\displaystyle{\mathcal{E}}
is a secure block cipher, it must be secure against key-recovery. Moreover, if
\displaystyle{\mathcal{E}}
is secure against key-recovery, it must be the case that
\displaystyle|{\mathcal{K}}|
is large (
i.e.
, super-poly). We can see this as follows. An adversary can always win the key-recovery game with the probability
\displaystyle 1/|{\mathcal{K}}|
by simply choosing the key
\displaystyle k^{\prime}\in{\mathcal{K}}
at random. If
\displaystyle|{\mathcal{K}}|
is not super-poly, then this probability
\displaystyle 1/|{\mathcal{K}}|
is non-negligible.

We can trade success probability for running-time proceeding a different attack, called an exhaustive search attack. In the exhaustive search attack, the adversary
\displaystyle{\mathcal{A}}
makes a few, arbitrary queries
\displaystyle\{x_{1},\cdots,x_{q}\}
in the key-recovery game to obtain the responses
\displaystyle\{y_{1},\cdots,y_{q}\}
. One may argue — at least, assuming that
\displaystyle|{\mathcal{S}}|\leq|{\mathcal{K}}|
and
\displaystyle|{\mathcal{K}}|
is super-poly — that for fairly small values of
\displaystyle q
(in fact,
\displaystyle q=2
), with all but negligible probability, only one key satisfies

y_{i}={\mathsf{Enc}}(k,x_{i})~{\mathrm{for}}~i=1,\cdots,q\;.

(14)

If there is only one such key, the key that the adversary finds will be the one that is chosen by the challenger, and the adversary will win the game. Thus, the adversary wins the key-recovery game with all but negligible probability; however, the running time is linear in
\displaystyle|{\mathcal{K}}|
.

Definition 2.23

(ECB cipher)
.

Let
\displaystyle{\mathcal{E}}=({\mathsf{Gen}},{\mathsf{Enc}},{\mathsf{Dec}})
be a block cipher defined over
\displaystyle({\mathcal{K}},\mathcal{S},\mathcal{S})
. For any poly-bounded
\displaystyle\ell\geq 1
, we can define a block cipher
\displaystyle{\mathcal{E}}^{\prime}
defined over
\displaystyle({\mathcal{K}},\mathcal{S}^{\leq\ell},\mathcal{S}^{\leq\ell})
as follows.

•

For
\displaystyle k\in{\mathcal{K}}
and
\displaystyle m\in\mathcal{S}^{\leq\ell}
with
\displaystyle v=|m|

{\mathsf{Enc}}(k,m)^{\prime}=\left({\mathsf{Enc}}(k,m[0]),\cdots,{\mathsf{Enc}}(k,m[v-1])\right)\;.

(15)

•

For
\displaystyle k\in{\mathcal{K}}
and
\displaystyle c\in\mathcal{S}^{\leq\ell}
with
\displaystyle v=|c|

(16)

We call this block cipher
\displaystyle{\mathcal{E}}^{\prime}
as the
\displaystyle\ell
-wise electronic code book (ECB) cipher derived from the block cipher
\displaystyle{\mathcal{E}}
.

Theorem 2.6
.

Let
\displaystyle\mathcal{E}=({\mathsf{Gen}},{\mathsf{Enc}},{\mathsf{Dec}})
be a block cipher defined over
\displaystyle(\mathcal{K},\mathcal{S},\mathcal{S})
. Let
\displaystyle\ell\in{\mathbb{N}}
be any poly-bounded value, and
\displaystyle{\mathcal{E}}^{\prime}
be the
\displaystyle\ell
-wise ECB cipher derived from
\displaystyle{\mathcal{E}}
, but with the message space restricted to all sequences of at most
\displaystyle\ell
distinct data blocks. If
\displaystyle{\mathcal{E}}
is a secure block cipher, then
\displaystyle{\mathcal{E}}^{\prime}
is semantically secure.

The block ciphers are the most primitive scheme in cryptography. In practice, constructing block ciphers use the same scheme, called the iterated block cipher. At first, we chooses a simple block cipher,
\displaystyle\mathcal{E}=({\mathsf{Gen}},{\mathsf{Enc}},{\mathsf{Dec}})
defined over
\displaystyle({\mathcal{K}},\mathcal{S},\mathcal{S})
, which is apparently insecure at this time. This block cipher is called as the round cipher. Second, we chooses a PRG
\displaystyle G
that is used to generate
\displaystyle n
-sequence of pseudo-random keys
\displaystyle(k_{1},\cdots,k_{n})
from
\displaystyle k\in{\mathcal{K}}
. In this case, the PRG
\displaystyle G
is called as the key expansion function. More precisely speaking, the second step in constructing the iterated block cipher is proceeded in iterative ways, that is,

•

Key expansion:

(k_{1},\cdots,k_{n})=G(k)\;,~{\mathrm{for}}~n\in{\mathbb{N}}\;,~k\in{\mathcal{K}}\;.

(17)

•

Iteration: for each
\displaystyle i=1,\cdots,n
, we apply the encryption function with the generated pseudo-random key
\displaystyle k_{i}
, and outputs

y={\mathsf{Enc}}(k_{n},{\mathsf{Enc}}(k_{n-1},\cdots,{\mathsf{Enc}}(k_{2},{\mathsf{Enc}}(k_{1},x)))\cdots)\;.

(18)

At each step, the operation of encryption function
\displaystyle{\mathsf{Enc}}
is called the round, and the generated sequence of keys are called the round keys. The iteration of decryptions is almost the same except that the round keys are applied in reverse order.

x={\mathsf{Dec}}(k_{1},{\mathsf{Dec}}(k_{2},\cdots,{\mathsf{Dec}}(k_{n-1},{\mathsf{Dec}}(k_{n},y)))\cdots)\;.

(19)

One of the most famous algorithm of the round cipher is known as the Data Encryption Standard (DES). A strengthen version of the DES is called as the Triple-DES (3DES), which consists of three times of the rounds with each key space having
\displaystyle 56
-bits key strings, hence the key length is
\displaystyle 3\times 56=168
. The Triple-DES has been approved through the year 2030 by the NIST as the U.S. standard in 1998. However, in 2002, it was superseded by the more secured AES algorithm, which has
\displaystyle 128
-bits in each key space, and
\displaystyle 10
times of the rounds.

Definition 2.24

(Hash function)
.

A hash function
\displaystyle H
is a deterministic algorithm, whose inputs are a key
\displaystyle k
and a message
\displaystyle m
, its output
\displaystyle t=H(k,m)
is called as digest. The hash function is defined over the space
\displaystyle({\mathcal{K}},\mathcal{M},\mathcal{T})

\displaystyle\mathcal{T}
is the space in which the digest
\displaystyle t
lies. In general, for two messages
\displaystyle m_{1},m_{2}\in\mathcal{M}
with
\displaystyle m_{1}\neq m_{2}
and
\displaystyle k\in\mathcal{K}
, we say those two messages form collision for the hash function
\displaystyle H
under the key
\displaystyle k
if

H(k,m_{1})=H(k,m_{2})\;.

(20)

In general, since the size of the space
\displaystyle\mathcal{T}
is much smaller than that of the space
\displaystyle\mathcal{M}
, it often happens to occur the collisions for the hash function
\displaystyle H
. However, it is necessary condition that the collision-less property of the hash function when using it in cryptography. In practice, it is enough to satisfy the weak collision-less property, in which the adversary must find a collision with no information on the keys at all.

Definition 2.25

(Attack Game 6 — collision-less security)

The adversary
\displaystyle{\mathcal{A}}
outputs two distinct messages
\displaystyle m_{1},m_{2}\in\mathcal{M}

\displaystyle{\mathcal{A}}

H(k,m_{1})=H(k,m_{2})\;.

(21)

We define
\displaystyle{\mathcal{A}}

\displaystyle H

\displaystyle{\mathcal{A}}

(Universal hash function)
.

Let
\displaystyle H

2.6
Key-exchange protocol

The quotient group
\displaystyle({\mathbb{Z}}/n{\mathbb{Z}})^{\times}
is defined by
\displaystyle({\mathbb{Z}}/n{\mathbb{Z}})^{\times}=\{0,\cdots,n-1\}
, whose order is given by the Euler’s totient function
\displaystyle\varphi(n)=|({\mathbb{Z}}/n{\mathbb{Z}})^{\times}|
. For prime
\displaystyle p

\displaystyle\varphi(p)=p-1
. The group
\displaystyle({\mathbb{Z}}/n{\mathbb{Z}})^{\times}
becomes cyclic if and only if
\displaystyle n=1,2,4,p^{k}
or
\displaystyle n=2p^{k}
where
\displaystyle p
is odd prime and
\displaystyle k>0
. The quotient group becomes the cyclic group
\displaystyle C_{n}
, that is given by

({\mathbb{Z}}/n{\mathbb{Z}})^{\times}\cong C_{\varphi(n)}\;,~\text{where}~\varphi(p^{k})=\varphi(2p^{k})=p^{k}-p^{k-1}\;.

(25)

By definition, the group becomes cyclic if and only if it has a generator
\displaystyle g
, that is, each element can be written by the powers of
\displaystyle g
:

C_{\varphi(n)}=\{g^{0}\,g^{1},\cdots,g^{\varphi(n)-1}\}\;.

(26)

The Diffie-Hellman key-exchange protocol is briefly described as follows.

•

Alice computes
\displaystyle\alpha\in{\mathbb{Z}}_{q}
,
\displaystyle u=g^{\alpha}\in C_{p-1}
, and sends the output
\displaystyle u
to Bob.

•

Bob computes
\displaystyle\beta\in{\mathbb{Z}}_{q}
,
\displaystyle v=g^{\beta}\in C_{p-1}
, and sends the output
\displaystyle v
to Alice.

•

Alice computes
\displaystyle w=v^{\alpha}
upon receiving
\displaystyle v
from Bob.

•

Bob computes
\displaystyle w=u^{\beta}
upon receiving
\displaystyle u
from Alice.

Then, the secret shared between them is given by

w=v^{\alpha}=g^{\alpha\beta}=u^{\beta}\;.

(27)

It is said that the Diffie-Hellman key-exchange protocol is secure if and only if the following property holds:

\text{For given}~g^{\alpha},g^{\beta}\in C_{p-1}\;,\text{where}~\alpha,\beta\in{\mathbb{Z}}_{q},\text{it is hard to computes}~g^{\alpha\beta}\in C_{p-1}\;.

(28)

This security property is called the computational Diffie-Hellman assumption.

3
Quantum Cryptography

3.1
Qubits, Entanglement, and Quantum Gates

At the beginning, we summarize basic notions in describing for the quantum computers and quantum cryptography. In classical computers, the fundamental unit is a ’bit’, which can be either 0 or 1. In quantum computers, the fundamental unit is a ’qubit’, which is a superposition of 0 and 1. In general, a single qubit state is written as a state in the Hilbert space
\displaystyle{\cal{H}}={\mathbb{C}}^{2}

\big|\psi\rangle=\alpha\,\big|0\rangle+\beta\,\big|1\rangle\;,

(30)

where
\displaystyle|\alpha|^{2}+|\beta|^{2}=1
with the basis
\displaystyle{\mathcal{B}}_{z}=\left\{\big|0\rangle,\,\big|1\rangle\right\}
. We can always make change of a basis to another one by using a unitary transformation. The following basis are also often used

\big|\pm\rangle=\frac{\big|0\rangle\pm\big|1\rangle}{\sqrt{2}}\;,

(31)

and we denote it as
\displaystyle{\mathcal{B}}_{x}=\left\{\big|+\rangle,\,\big|-\rangle\right\}
.

We can construct a
\displaystyle N
qubit system from single qubit systems by taking
\displaystyle N
tensor products of the Hilbert spaces as
\displaystyle{\cal{H}}^{\otimes N}=\otimes_{i=1}^{N}{\cal{H}}_{i}
.
For instance, 2 qubit state is spanned by 3 basis states when taking the orthogonal conditions into account. That is, taking a tensor product of two Hilbert spaces
\displaystyle{\cal{H}}_{1}\otimes{\cal{H}}_{2}={\mathbb{C}}^{2}\otimes{\mathbb{C}}^{2}
, the 2 qubit state can be expressed by

\big|\psi_{1}\rangle\otimes\big|\psi_{2}\rangle=\big|\psi_{1}\psi_{2}\rangle\in{\cal{H}}_{1}\otimes{\cal{H}}_{2}\;,

(32)

where
\displaystyle\big|\psi_{1}\rangle\in{\cal{H}}_{1}
and
\displaystyle\big|\psi_{2}\rangle\in{\cal{H}}_{2}
. We will often abbreviate
\displaystyle\big|\psi_{1}\rangle\otimes\big|\psi_{2}\rangle
to
\displaystyle\big|\psi_{1}\psi_{2}\rangle
, etc.

An important property in quantum information theory is the so-called, ’entanglement’, which refers to the quantum correlation between different qubits. In order to give more formal definition to that, we define a density operator
\displaystyle\rho
associated to a given qubit
\displaystyle\big|\psi\rangle
as follows.

\rho=\big|\psi\rangle\langle\psi\big|\;.

(33)

The qubit is called a pure state if and only if the density operator satisfies the following condition,

\rho^{2}=\rho\;.

(34)

Equivalently, a qubit state in the Hilbert space
\displaystyle{\cal{H}}_{1}\otimes{\cal{H}}_{2}
is called a pure state if it can be expressed in the separable form:
\displaystyle\big|\psi_{1}\rangle\otimes\big|\psi_{2}\rangle
. On the other hand, a qubit state which cannot be written in such a separable way is called the entangled state. The standard basis for the two qubits consists of four orthonormal states which is called as the Bell states. The Bell states can be expressed as follows.

\displaystyle\displaystyle\big|\Psi_{1}^{\pm}\rangle

\displaystyle\displaystyle=

\displaystyle\displaystyle\frac{\big|01\rangle\pm\big|10\rangle}{\sqrt{2}}\;,

\displaystyle\displaystyle\big|\Psi_{2}^{\pm}\rangle

\displaystyle\displaystyle=

\displaystyle\displaystyle\frac{\big|00\rangle\pm\big|11\rangle}{\sqrt{2}}\;.

These states are maximally entangled.

A unitary operator that acts on a small number of qubits (say, up to 3) is called ’quantum gate’ (or, gate). That is a quantum analogous to the classical gates like ’AND’, ’OR’, and ’NOT’.
If we take a set of basis in the Hilbert space
\displaystyle{\cal{H}}
, the quantum gates are defined by the outer products

\displaystyle\displaystyle\big|0\rangle\langle 0\big|

\displaystyle\displaystyle=

\displaystyle\displaystyle\begin{pmatrix}1&0\\
0&0\end{pmatrix}\,,~~\big|0\rangle\langle 1\big|=\begin{pmatrix}0&1\\
0&0\end{pmatrix}\;,

\displaystyle\displaystyle\big|1\rangle\langle 0\big|

\displaystyle\displaystyle=

\displaystyle\displaystyle\begin{pmatrix}0&0\\
1&0\end{pmatrix}\,,~~\big|1\rangle\langle 1\big|=\begin{pmatrix}0&0\\
0&1\end{pmatrix}\;.

The Pauli matrices are examples of
\displaystyle 1
-qubit gates.

\displaystyle\displaystyle{\mathsf{I}}

\displaystyle\displaystyle=

\displaystyle\displaystyle\big|0\rangle\langle 0\big|+\big|1\rangle\langle 1\big|\;,

\displaystyle\displaystyle{\mathsf{X}}

\displaystyle\displaystyle=

\displaystyle\displaystyle\big|0\rangle\langle 1\big|+\big|1\rangle\langle 0\big|\;,

\displaystyle\displaystyle{\mathsf{Y}}

\displaystyle\displaystyle=

\displaystyle\displaystyle-i\big|0\rangle\langle 1\big|+i\big|1\rangle\langle 0\big|\;,

\displaystyle\displaystyle{\mathsf{Z}}

\displaystyle\displaystyle=

\displaystyle\displaystyle\big|0\rangle\langle 0\big|-\big|1\rangle\langle 1\big|\;.

Among those quantum gates, the bit-flip gate
\displaystyle{\mathsf{X}}
(
a.k.a.
, NOT-gate) negates the computational basis,
i.e.
, it swaps
\displaystyle\big|0\rangle
and
\displaystyle\big|1\rangle
. The phase-flip gate
\displaystyle{\mathsf{Z}}
puts a minus sign in front of a qubit state
\displaystyle\big|1\rangle
. Another important
\displaystyle 1
-qubit gate is the phase-shift gate,
\displaystyle{\mathsf{R}}_{\phi}
, which merely rotate the phase of the qubit state
\displaystyle\big|1\rangle
by
\displaystyle\phi
, that is,
\displaystyle{\mathsf{R}}_{\phi}\big|1\rangle=e^{i\phi}\big|1\rangle
. Note that
\displaystyle{\mathsf{Z}}
is a special case of
\displaystyle{\mathsf{R}}_{\phi}
with
\displaystyle\phi=\pi
. Moreover,
\displaystyle{\mathsf{R}}_{\phi}
gate with
\displaystyle\phi=\pi/4
is often called as
\displaystyle T
-gate. In practice, the most relevant
\displaystyle 1
-qubit gate is the so-called, Hadamard gate
\displaystyle{\mathsf{H}}
, which is given by

{\mathsf{H}}=\frac{1}{\sqrt{2}}\,\begin{pmatrix}1&1\\
1&-1\end{pmatrix}

(35)

The actions of the Hadamard gate
\displaystyle{\mathsf{H}}
on the qubits exchange one basis to the other.

\displaystyle\displaystyle{\mathsf{H}}\,\big|0\rangle

\displaystyle\displaystyle=

\displaystyle\displaystyle\big|+\rangle\;,\quad{\mathsf{H}}\,\big|1\rangle=\big|-\rangle\;,

\displaystyle\displaystyle{\mathsf{H}}\,\big|+\rangle

\displaystyle\displaystyle=

\displaystyle\displaystyle\big|0\rangle\;,\quad{\mathsf{H}}\,\big|-\rangle=\big|1\rangle\;.

The crucial property of the Hadamard gate is that if we act it to the qubit state with a superposition
\displaystyle\big|0\rangle+\big|1\rangle
, then we have

{\mathsf{H}}\,\frac{1}{\sqrt{2}}\left(\big|0\rangle+\big|1\rangle\right)=\big|0\rangle\;.

(36)

The result of disappearance in the initial qubit state

3.3
Quantum Key Distribution

The goal of Quantum Key Distribution (QKD) is to provide a way to share the secrete key between two parties, Alice and Bob. The
\displaystyle{\mathsf{BB84}}
protocol is one of the first examples to realize the QKD. The basic procedures of
\displaystyle{\mathsf{BB84}}
is described as follows.

1.

Alice chooses a random bit and random basis using a random generator.

2.

Alice encodes the chosen bit and sends the qubit to Bob by using a quantum channel.

3.

Bob chooses a random basis using a random generator.

4.

Bob measures the received qubit in the chosen basis and decodes the bit.

5.

If Alice and Bob have the same basis, then they can share the same bit, and if not the case, they can only share the same bit withe a probability of 1/2, and they can share a different bit with the same probability of 1/2.

6.

Alice and Bob repeat the steps 1 to 5 until a reasonable amount of bits have been exchanged.

7.

After that they share the basis used for encoding and decoding for using the classical channel.

8.

They discard every bit where the basis are not the same one, and keeps the others without revealing the value of bits.

9.

To verify that nobody eavesdropped, they publicly share a reasonable amount of bits and verify that they agree. If they agree on all the bits, they discard the used bits and keep the secret key. If they disagree, they discard the secret key and start again.

At the end of this procedure, Alice and Bob share the identical and secured secrete key. This

4
Cryptographic Algorithms

The primary cryptographic algorithms of blockchain basically consist of three types of cryptographic algorithms: cryptographic hash functions, symmetric cryptographic algorithms, and asymmetric cryptographic algorithms. The basic difference between symmetric cryptographic algorithms and asymmetric cryptographic algorithms is in the way to distribute the cryptographic keys. The use of Federal Information Processing Standard (FIPS) is approved by the security of commerce. The National Institute of Standards and Technology (NIST) has published a Special Publication (SP) which gives a standardization procedure as similar to the FIPS provided by the security of commerce.

4.1
Cryptographic Hash Algorithms

A cryptographic hash algorithm is a cryptographic primitive algorithm that basically map input data of any length to fixed length values. There are basically three types of security properties in the cryptographic hash algorithm (or hash function
\displaystyle H
).

1.

One-way function
:

It is practically impossible to reverse the process from the hash value to the input value such that
\displaystyle H(x)=y
.

2.

Weak-collision resistance
:

It is practically impossible to find another distinct value of
\displaystyle x^{\prime}
for a given input value of
\displaystyle x
, such that the output of hash function match
\displaystyle H(x)=H(x^{\prime})~(x\neq x^{\prime})
.

3.

Strong-collision resistance
:

It is practically impossible to find two distinct values of
\displaystyle x
and
\displaystyle x^{\prime}
in such a way that the output of hash function match
\displaystyle H(x)=H(x^{\prime})
.

4.2
Symmetric Cryptographic Algorithms

Symmetric cryptographic algorithm (or secret-key algorithm) uses a single, unique secrete-key in both encryption and decryption of the data. In order to make this algorithm much more secured, several symmetric cryptographic algorithms have been approved by NIST for the protection of sensitive data. The symmetric cryptographic algorithm combined with the use of hash function has been specified and approved in SP-800.

4.3
Asymmetric Cryptographic Algorithms

Asymmetric cryptographic algorithm (or public-key algorithm) uses a pair of keys, a public-key and a private-key which are related to each other. The public-key may be made public without reducing the security of the process, but the private-key must remain secrete if the cryptographic protection is to remain effective.

4.3.1
Digital Signatures Algorithms

Digital signatures algorithms are used to provide identity authorization, integrity authorization, source authorization, and support for non-repudiation. Digital signatures are used in conjunction with hash functions The FIPS-186 specifies algorithms that are approved for the computation of digital signatures. It specifies several types of algorithms; RSA algorithm, the Elliptic Curve digital signature algorithm (ECDSA), and the Edwards Curve digital signature algorithm (EdDSA). The FIPS-186 also specifies additional requirements in each algorithms, which include the key sizes for each algorithms, and methods for generating the key pairs.

1.

RSA scheme
:

The RSA scheme is the most simple public-key algorithm, which is approved in FIPS-186 for the generation and verification of digital signatures, and specified in PKCS-1 and RFC-9017. Since the RSA digital signature scheme has a mathematically hard problem, that is so called, the Integer Factorization Problem (IFP), most of the cryptocurrencies do not use the RSA digital signature scheme.

2.

ECDSA scheme
:

The ECDSA digital signature scheme is approved and specified in FIPS-186, and is used to generate and verify the digital signatures based on the use of elliptic curves. Since the ECDSA digital signature scheme is more secured than the RSA scheme. most of the major cryptocurrencies, such as Bitcoin (BTC), Ethereum (ETH), Ripple (XRP), have adopted the ECDSA scheme.

3.

EdDSA scheme
:

The EdDSA digital signature scheme is adopted in FIPS-186 and described in RFC-8032. While the ECDSA scheme requires the use of a random (unique) value for the generation of each signature, the EdDSA scheme is deterministic, that is, the unique value for the generation of each signature is computed by the private key. While it is not as widely adopted as ECDSA, some cryptocurrencies, such as Monero (XMR), Zcash (ZEC), Stellar (XLM), have adopted EdDSA for their digital signature algorithm.

4.3.2
Key Establishment Schemes

Asymmetric cryptographic algorithms are used to set up keys to be used in communicating between entities. The scheme is a set of transformations that provide a cryptographic service. The scheme is used in a protocol that actually performs the communication needed for the key establishment process. There are two types of approved key establishment schemes; discrete-log-based scheme and integer factorization scheme. SP-800 specifies key establishment schemes that use RSA algorithm is also approved to use for key establishment, as well as for the generation and verification of digital signatures.

1.

Diffie-Hellman (DH) and MQV
:

SP-800 specifies key establishment schemes that use discrete-log-based algorithms. Two algorithms are approved for key agreement; Diffie-Hellman (DH) and MQV.

2.

RSA
:

RSA algorithm can be used for key establishment, as well as for the generation and verification of digital signatures. Its use for key establishment is specified in SP-800, it specifies approved methods for both key agreement and key transport.
