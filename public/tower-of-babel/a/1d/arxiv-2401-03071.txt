Software Implementation of Digital Filtering via Tustin’s Bilinear Transform
Connor W. Herron

Abstract
The purpose of this work is to provide some notes on a software implementation for digital filtering via Tustin’s Bilinear Transform. The first section discusses how to solve for the input/output coefficients by hand using a generalized approach called Horner’s method. The second section presents some results of this generalized digital filtering approach using the IHMC Open Robotics Software (ORS) stack and Simulation Construction Set 2 (SCS2) [ 2 , 3 ] . This generalized approach can solve for the digital coefficients for any causal transfer function.



1
Introduction

The purpose of this package is to build digital filters which can run in control loops at a consistent known frequency,
f_{l}
. We can represent filters in their continuous transfer function form:

H(s)=\frac{Y(s)}{X(s)}=\frac{b_{0}s^{\rm m}+b_{1}s^{\rm m-1}+...+b_{\rm m-1}s+b_{\rm m}}{a_{0}s^{\rm n}+a_{1}s^{\rm n-1}+...+a_{\rm n-1}s+a_{\rm n}}

(1)

where
\rm m\leq n
for the transfer function to be causal. We are looking to convert the transfer function,
H(s)
, to a digital filter of the following form

\begin{split}y_{0}&=\rm\hat{b}_{0}y_{1}+\hat{b}_{1}y_{2}+...+\hat{b}_{\rm n-1}y_{\rm n-1}+\hat{a}_{0}x_{0}+\hat{a}_{1}x_{1}+...+\hat{a}_{\rm n-1}x_{\rm n-1}+\hat{a}_{\rm n}x_{\rm n}\\
&=\hat{\textbf{b}}^{T}\textbf{y}+\hat{\textbf{a}}^{T}\textbf{x}\end{split}

(2)

where
\hat{\textbf{b}},\textbf{y}\in\mathbb{R}^{\rm n-1\times 1}
,
\hat{\textbf{b}}=\rm{col}[\hat{b}_{0},\hat{b}_{1},...,\hat{b}_{\rm n-1}]
and
\hat{\textbf{a}},\textbf{x}\in\mathbb{R}^{\rm n\times 1}
,
\hat{\textbf{a}}=\rm{col}[\hat{a}_{0},\hat{a}_{1},...,\hat{a}_{\rm n-1},\hat{a}_{\rm n}]
where
\hat{b}_{i},\hat{a}_{i}\in\mathbb{R}
are scalars with
0\leq i\leq n
refers to the output order. The vectors
\textbf{x}=\rm{col}[x_{0},x_{\rm 1},...,x_{\rm n-1},x_{\rm n}]
and
\textbf{y}=\rm{col}[y_{1},y_{\rm 2},...,y_{\rm n-1}]
represent the input/output “history” where the subscript represents the loop iteration (eg.
x_{0}
is the current input,
x_{1}
is the previous input,
x_{2}
is the previous previous input, etc.).
Equation (
2
) must be solved in a loop running at a consistent frequency,
f_{l}
, where the input/output histories must be updated. Failure to achieve a consistent frequency will no longer represent the desired transfer function. The input/output coefficient vectors
\hat{\textbf{a}},\,\hat{\textbf{b}}
are constant throughout the control sequence and only need to be solved during initialization.
The goal of this work is to describe a general approach which solves for the digital representation of any continuous, causal transfer function, which translates to solving for a set of input/output coefficients,
\hat{\textbf{a}},\,\hat{\textbf{b}}
to be used in Eq. (
2
) as part of a control loop.

2
Examples

The digital transformation used here is Tustin’s Bilinear Transform method, which simply represents the continuous frequency variable

s=f_{l}\cdot ln(z)=2f_{c}\cdot\big[\frac{z-1}{z+1}+\frac{1}{3}\cdot(\frac{z-1}{z+1})^{3}+\frac{1}{5}\cdot(\frac{z-1}{z+1})^{5}+\frac{1}{7}\cdot(\frac{z-1}{z+1})^{7}\big]

s=2f_{l}\frac{z-1}{z+1}

(3)

where
f_{l}
is the digital loop frequency at which Eq. (
2
) is solved at. After solving the example using the general method, I’ll show an alternative approach which is more software friendly.

2.1
General Method

2.1.1
Example 1: General Method

This first example is a simple 1st order, unity-gain, low-pass transfer function of the form

H(s)=\frac{1}{\frac{s}{\omega_{0}}+1},\quad\omega_{0}=0.1\,\text{rad/s}

H(s)=\frac{1}{10s+1}

(4)

where we want to solve for a set of digital input/output coefficient vectors
\hat{\textbf{a}},\hat{\textbf{b}}
from Eq. (
2
).

If we have a loop frequency of
f_{l}=0.1
Hz (chosen simply chosen for mathematical convenience, and is considerably lower than normal loop speeds), we can substitute Eq. (
3
) in (
4
) to get

\displaystyle H[z]

\displaystyle=\frac{1}{10\cdot(2\cdot 0.1\frac{z-1}{z+1})+1}

\displaystyle H[z]

\displaystyle=\frac{z+1}{2\cdot(z-1)+z+1}

\displaystyle H[z]

\displaystyle=\frac{Y[z]}{X[z]}=\frac{z+1}{3z-1}

where we can split the transfer function into
Y[z]
and
X[z]
components

\displaystyle Y[z](3z-1)

\displaystyle=X[z](z+1)

\displaystyle Y[z](1-\frac{1}{3}z^{-1})

\displaystyle=X[z](\frac{1}{3}+\frac{1}{3}z^{-1})

Finally, we can derive our digital filter

y_{0}=\frac{1}{3}y_{1}+\frac{1}{3}x_{0}+\frac{1}{3}x_{1}

(5)

where our set of input/output coefficient vectors is

\boxed{\hat{\textbf{a}}^{T}=[\frac{1}{3},\,\frac{1}{3}],\quad\text{and}\quad\hat{\textbf{b}}^{T}=[\frac{1}{3}]}

(6)

While this approach is relatively simple to complete by hand, it’s quite difficult to generalize to more difficult examples. In this next example, the desired transfer function is 2nd order.

2.1.2
Example 2: General Method

The 2nd order low-pass, Butterworth is a common filter of the form

H(s)=\frac{\omega_{c}^{2}}{s^{2}+\sqrt{2}\omega_{c}s+\omega_{c}^{2}}

(7)

For simple numerical values, I’ll choose
\omega_{c}=\sqrt{2}
rad/s, with
f_{l}=1
Hz. We can start by immediately plugging in Eq. (
3
) where

\displaystyle H(s)

\displaystyle=\frac{2}{s^{2}+2s+2}

\displaystyle H[z]

\displaystyle=\frac{2}{(2f_{l}\frac{z-1}{z+1})^{2}+2(2f_{l}\frac{z-1}{z+1})+2}

\displaystyle H[z]

\displaystyle=\frac{2(z+1)^{2}}{(4f_{l}^{2}(z-1)^{2}+4f_{l}(z-1)(z+1))+2(z+1)^{2}}

\displaystyle H[z]

\displaystyle=\frac{2(z^{2}+2z+1))}{(4(z^{2}-2z+1)+4(z^{2}-1)+2(z^{2}+2z+1)}

\displaystyle H[z]

\displaystyle=\frac{2z^{2}+4z+2}{4z^{2}-8z+4+4z^{2}-4+2z^{2}+4z+2}

\displaystyle H[z]

\displaystyle=\frac{Y[z]}{X[z]}=\frac{2z^{2}+4z+2}{10z^{2}-4z+2}

where we can finally split the transfer function into
Y[z]
and
X[z]
components

\displaystyle Y[z](10z^{2}-4z+2)

\displaystyle=X[z](2z^{2}+4z+2)

\displaystyle Y[z](1-0.4z^{-1}+0.2z^{-2})

\displaystyle=X[z](0.2+0.4z^{-1}+0.2z^{-2})

Finally, our digital filter can be derived as

y_{0}=0.4y_{1}-0.2y_{2}+0.2x_{0}+0.4x_{1}+0.2x_{2}

(8)

and the set of input/output coefficient vectors is

\boxed{\hat{\textbf{a}}=[0.2,\,0.4,\,0.2],\quad\text{and}\quad\hat{\textbf{b}}=[0.4,\,-0.2]}

(9)

Using the general method, it can be hard to write an algorithm to find
\hat{\textbf{a}},\,\hat{\textbf{b}}
for any transfer function. In addition, a generalized method could be computational expensive, which isn’t a deal breaker since this task would be completed during initialization prior to loop running, but we may have hundreds of filters and it would be good to consider efficiency.

2.2
Horner’s Method

Horner’s method is a convienent way of solving the
H(s)\rightarrow H[z]
conversion in a stepwise manner which is mathematically equivalent and software generalizable to any causal transfer function
[
1
]
. Horner’s method relies on the fact that we can rewrite Tustin’s bilinear transform as

\begin{split}\frac{1}{s}&=\frac{1}{2f_{l}}\cdot\frac{z+1}{z-1}\\
&=\frac{1}{2f_{l}}\cdot\frac{z+1-1+1}{z-1}\\
&=\frac{1}{2f_{l}}\cdot(\frac{2}{z-1}+1)\end{split}

(10)

In this method, instead of simply substituting Eq. (
3
) into the transfer function, this method retains the polynomial orders of power while separately considering the numerator and denominator. The method will convert

\displaystyle\begin{split}F(s)\rightarrow F(x)\rightarrow F(x+1)\rightarrow F(\frac{1}{x}+1)&\rightarrow F(\frac{2}{x}+1)\rightarrow F(\frac{2}{x-1}+1)\\
&\equiv F\left(\frac{1}{2f_{l}}\cdot(\frac{2}{z-1}+1)\right)=F[z]\end{split}

(11)

Note:
The variable
x
is a general variable to transition between layers of the
F(s)\rightarrow F[z]
, where
x
is not equivalent between layers. In addition, the multiplication of
2f_{l}
can take place in an step in transition where I’ve chosen to the first step where
F(s)\rightarrow F(x)
. In addition, there are steps here where the same multiplication will take place across the numerator and denominator for convenience while being mathematically equivalent.

3
Results

3.1
Chirp Signals

I’ll show some comparisons of transfer functions using the intended model and results of an input/output response of that model’s filter with an exponential chirp input. A chirp signal is a sinusoid whose frequency changes
linearly
or
exponentially
with time depending on the desired waveform. This type of signal can be used to sweep through a frequency spectrum for generating a bode plot of the linear system. Personally, I prefer using exponential chirp signals so that the number of data points spent on each frequency matches the log-scale graph of the bode plot (i.e. we get more data points on lower-frequencies that we usually care more about). Alternatively, one could use a sequence of sinusoids instead of a dynamic sinusoid. That allows you to separate the transient and steady state responses, which is otherwise impossible to separate in a chirp signal response.

Here’s the equation of the frequency change,
\omega_{\rm c}(t)
, with respect to time for linear and exponential chirp signals

\omega_{\rm c}^{\rm lin}(t)=\left(\frac{\omega_{\rm max}-\omega_{\rm min}}{T}\right)\cdot t+\omega_{\rm min}

(19)

\omega_{\rm c}^{\rm exp}(t)=\omega_{\rm min}\cdot\left(\frac{\omega_{\rm max}}{\omega_{\rm min}}\right)^{\frac{t}{T}}

(20)

Figure 1:
Linear and Exponential Chirp Waveforms from 0.01 to 2.5 Hz with amplitude of 1

Where
\omega_{\rm min}
is the minimum frequency in rad/s,
\omega_{\rm max}
is the maximum frequency in rad/s, and
T
is total time in seconds. Using (
19
) and (
20
), the chirp signal for a digital system can be represented as

\displaystyle\cos_{i}

\displaystyle=\cos(\omega_{c}[t]\cdot\Delta t)\cos_{i-1}-\sin(\omega_{c}[t]\cdot\Delta t)\sin_{i-1}

(21)

\displaystyle\sin_{i}

\displaystyle=\sin(\omega_{c}[t]\cdot\Delta t)\cos_{i-1}+\cos(\omega_{c}[t]\cdot\Delta t)\sin_{i-1}

(22)

Finally, the chirp equation is represented by the following

x_{i}=A\sin_{i}

(23)

where
A
refers to the amplitude. Figure
1
shows a plot of linear and exponential chirp signals where
\omega_{\rm min}=2\pi\cdot 0.01
rad/s,
\omega_{\rm max}=2\pi\cdot 2.5
rad/s,
T=10
sec, and
A=1
.

3.2
Software Implementation of Digital Filtering

The algorithm for generating and using the filter in a control loop can be summarized by the following pseudocode:

Using a filter in a control loop.

\hat{\textbf{a}}

and

\hat{\textbf{b}}

\text{D}_{z}=\text{solve}_{\text{Fs}\rightarrow\text{Fz}}(\text{D}_{s})

\text{Scale }\text{N}_{z}\text{ and }\text{D}_{z}\text{ coefficients by }\text{D}_{z}\text{[0].}

\text{Multiply }\text{D}_{z}\text{ coefficients by -1 and solve for the }\hat{\textbf{a}}\text{ and }\hat{\textbf{b}}\text{ column vectors.}

firstTick = true

% Run Control Loop.

% Initialize output and input history vectors to first input.

firstTick

\textbf{y}=x_{0}\cdot\textbf{col}(1)_{\rm(n-1)\times 1}

\triangleright
Heuristic for avoiding high outputs during initialization.

\textbf{x}=x_{0}\cdot\textbf{col}(1)_{\rm n\times 1}

firstTick = false

end

if

% Update input vector, where
\textbf{x}\in\mathbb{R}^{\rm n\times 1}
.

\textbf{x}=[x_{0},\,x_{1},\,...\,x_{\rm n-1},x_{\rm n}]^{T}

% Solve for next filtered output.

y_{0}=\hat{\textbf{b}}^{T}\textbf{y}+\hat{\textbf{a}}^{T}\textbf{x}

% Update output vector, where
\textbf{y}\in\mathbb{R}^{\rm n-1\times 1}
.

\textbf{y}=[y_{0},\,y_{1},\,...\,y_{\rm n-2},\,y_{\rm n-1}]^{T}

end

while
