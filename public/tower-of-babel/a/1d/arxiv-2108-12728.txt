Abstract
. Let n n be an integer greater or equal than 3 3 . We give a simultaneous generalization of ( n − 2 ) (n-2) -exact categories and n n -angulated categories, and we call it one-sided n n -suspended categories. One-sided n n -angulated categories are also examples of one-sided n n -suspended categories. We provide a general framework for passing from one-sided n n -suspended categories to one-sided n n -angulated categories. Besides, we give a method to construct n n -angulated quotient categories from Frobenius n n -prile categories. These results generalize their works by Jasso for n n -exact categories, Lin for ( n + 2 ) (n+2) -angulated categories and Li for one-sided suspended categories.
