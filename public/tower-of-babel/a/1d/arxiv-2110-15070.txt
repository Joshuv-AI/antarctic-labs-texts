Improved Strongly Polynomial Algorithms for Deterministic MDPs, 2VPI Feasibility, and Discounted All-Pairs Shortest Paths
Adam Karczmarz

Abstract
We revisit the problem of finding optimal strategies for deterministic Markov Decision Processes (DMDPs), and a closely related problem of testing feasibility of systems of m m linear inequalities on n n real variables with at most two variables per inequality (2VPI). We give a randomized trade-off algorithm solving both problems and running in O ~ ​ ( n ​ m ​ h + ( n / h ) 3 ) \widetilde{O}(nmh+(n/h)^{3}) time using O ~ ​ ( n 2 / h + m ) \widetilde{O}(n^{2}/h+m) space for any parameter h ∈ [ 1 , n ] h\in[1,n] . In particular, using subquadratic space we get O ~ ​ ( n ​ m + n 3 / 2 ​ m 3 / 4 ) \widetilde{O}(nm+n^{3/2}m^{3/4}) running time, which improves by a polynomial factor upon all the known upper bounds for non-dense instances with m = O ⁡ ( n 2 − ϵ ) m=O(n^{2-\epsilon}) . Moreover, using linear space we match the randomized O ~ ​ ( n ​ m + n 3 ) \widetilde{O}(nm+n^{3}) time bound of Cohen and Megiddo [SICOMP‘94] that required Θ ~ ​ ( n 2 + m ) \tilde{\Theta}(n^{2}+m) space. Additionally, we show a new algorithm for the Discounted All-Pairs Shortest Paths problem, introduced by Madani et al. [TALG‘10], that extends the DMDPs with optional end vertices. For the case of uniform discount factors, we give a deterministic algorithm running in O ~ ​ ( n 3 / 2 ​ m 3 / 4 ) \widetilde{O}(n^{3/2}m^{3/4}) time, which improves significantly upon the randomized bound O ~ ​ ( n 2 ​ m ) \widetilde{O}(n^{2}\sqrt{m}) of Madani et al.

Introduction

Linear programming is one of the most fundamental problems in optimization and algorithm design.
Polynomial-time algorithms solving linear programming relying on linear algebraic techniques have been known
for decades
[
Kar84
,
Kha79
]
, and the recently developed solutions run in the
current matrix multiplication time
[
vdB20
,
CLS21
,
JSWZ21
]
.
All the known polynomial algorithms are
weakly polynomial
. This means
the number of arithmetic operations they perform depends on the magnitude of
the numbers used to describe the
m
constraints and
n
variables of a linear program (LP).
It remains a challenging open problem whether there exists a
strongly polynomial

[
Meg83b
]
algorithm
whose worst-case number of arithmetic operations can be bounded by a polynomial in
n
and
m
exclusively.
The quest for such an algorithm led to strongly polynomial algorithms
for some important restricted classes of LPs, such as shortest paths,
minimum cost flows
[
Orl93
,
Tar85
]
, ’’combinatorial‘‘ LPs
[
Tar86
,
DNV20
]
, generalized maximum flows
[
OV20
,
Vég17
]
,
and (discounted) Markov Decision Processes
[
HMZ13
,
Ye11
]
.

One of the simplest classes of LPs for which no strongly polynomial
algorithm is known is the class of LPs such that each constraint involves at most
two variables – so-called
two variables per inequality (2VPI)
programs.
Optimizing 2VPI programs can be reduced to solving the uncapacitated generalized minimum cost flow problem,
for which a
combinatorial
(i.e., not relying on algebraic techniques)
weakly polynomial algorithm is known
[
Way02
]
.
1
1

1

Wayne’s algorithm
[
Way02
]
in fact works
even for the capacitated generalized minimum cost flow problem.

Interestingly, strongly polynomial algorithms are known
for a seemingly only slightly easier problem of testing the
feasibility
of a 2VPI program,
where there is no objective function to optimize
and any solution satisfying the constraints is sought.

In this paper, we revisit the
2VPI feasibility
problem and a closely related problem
of (discounted)
Deterministic Markov Decision Processes
(DMDPs) in the strongly polynomial regime.

2VPI feasibility.

The 2VPI feasibility problem has a rich history, and first weakly polynomial time
algorithms
[
Asp81
,
AS80
]
have been developed around the same time as
Khachiyan‘s breakthrough weakly polynomial algorithm for solving general LPs
[
Kha79
]
. Megiddo
[
Meg83b
]
initiated the
quest for strongly polynomial linear programming algorithms and obtained an
\widetilde{O}(mn^{3})
time strongly
polynomial algorithm for 2VPI feasibility using his
parametric search
technique
[
Meg83a
]
.
Subsequently, Cohen and Megiddo
[
CM94
]
found faster strongly polynomial algorithms:
a deterministic one running in
O(mn^{2}(\log^{2}{n}+\log{m}))
, and a randomized one running
in
\widetilde{O}(n^{3}+mn)
time. Hochbaum and Naor
[
HN94
]
showed a slightly faster
deterministic algorithm running in
O(mn^{2}\log{m})
time using a different approach.
These algorithms
[
CM94
,
HN94
]
remain the current state of the art
and all rely on parametric search in some way.
However, their drawback is that they use
\Theta(n^{2}+m)
space
which seems inherent (as will be explained later on).
This stands in sharp contrast with the earlier algorithm of Megiddo
[
Meg83b
]
which needs linear space.

Recently, Dadush et al.
[
DKNV21
]
showed a strongly polynomial algorithm
for 2VPI that instead uses a label-correcting
approach reminiscent of the classical Bellman-Ford algorithm. However, this algorithm
runs in
O(m^{2}n^{2})
time, and thus is slower by at least a linear factor than all the known parametric
search-based methods.

Monotone 2VPI systems and graphs.

It is well-known (see e.g.,
[
DKNV21
,
HMNT93
]
) that testing 2VPI feasibility can be reduced to the
monotone
case (M2VPI)
where each inequality has at most one positive coefficient and at most one negative coefficient.
Let
(x)_{v\in V}
be the variables, and let us index the inequalities
with the elements of a set
E
of size
m
.
Then, after normalization, each inequality
e
with variables
x_{u},x_{v}
(denoted
uv
) is of the form

x_{u}\leq c(e)+\gamma(e)\cdot x_{v}\hskip 8.53581pt\text{for all }uv=e\in E

(1)

where
c:E\to\mathbb{R}
and
\gamma:E\to\mathbb{R}_{+}
. Clearly, such a system
of inequalities can be conveniently represented using a directed multigraph
G=(V,E)

with
n
vertices and
m
edges.
2
2

2

Throughout (in particular in (
1
)), we use the notation

or

to pinpoint that
the tail and the head of the edge
e
are
u
and
v
respectively. We stress that we allow many edges

with the same tail and head and thus

m
might exceed
n^{2}
, e.g.,
m
might be exponential in

.

M2VPI systems, if feasible, have a unique

pointwise maximal
(
pointwise minimal
) solution
{x^{\max}}=({x_{v}^{\max}})_{v\in V}
(
{x^{\min}}=({x_{v}^{\min}})_{v\in V}
, respectively).
This means that for all feasible points
x
we have
x_{v}\leq{x_{v}^{\max}}
(
x_{v}\geq{x_{v}^{\min}}
, respectively) for every
v\in V
.
It might be the case that some
{x_{v}^{\max}}
equal
\infty
(or
{x_{v}^{\min}}
equal
-\infty
) if the feasibility region is unbounded.

Interestingly, variants of some of the known 2VPI feasibility algorithms (see e.g.
[
CM94
,
DKNV21
]
)
also find the pointwise maximal (and symmetrically, pointwise minimal)
solution in the monotone case.

Deterministic Markov Decision Processes.

Markov Decision Processes (MDPs) are a popular model for sequential decision making
under uncertainty. Given is a set of
states

V
and a set of actions
E

of the form
e=(s(e),p(e),c(e),\gamma(e))
, where
s(e)\in V
,
p(e)
is a probability distribution
over
V
,
c(e)\in\mathbb{R}
, and
\gamma(e)\in(0,1)
(
\gamma(e)
is usually called a
discount factor
). At a state
v\in V
, the
controller
of an MDP
has to pick an action
e\in E
with
s(e)=v
(which is assumed to exist). Doing so, the controller gets an immediate reward
c(e)
.
Then, with probability
1-\gamma(e)
, the process stops. Otherwise, the controller gets transferred
to another state
w\in V
with probability
p(e)(w)
.
The goal is to find a
policy
(i.e., a strategy) for the controller that allows him to maximize the total
reward in this infinite stochastic process.
The optimal strategy for the MDPs is always deterministic and history independent (see e.g.,
[
Put90
]
),
and thus can be described using a function
\sigma
mapping each state
v
to one of the edges
e\in E
with
s(e)=v
.
By solving an MDP we typically mean finding one such
\sigma
. It is known that an MDP instance can be solved
using linear programming
[
d’E63
]
.
Interestingly, strongly polynomial algorithms are known if the discount factors
\gamma(a)
are all
equal to a constant
\gamma\in(0,1)

[
HMZ13
,
Ye11
]
.

In more restricted deterministic Markov Decision Processes (DMDPs), for each
a\in A
the distribution
p(a)

satisfies
p(a)(w)=1
for some
w\in V
. As a result, the action determines the next state uniquely.
Such an MDP can be represented as a directed graph
G
with a corresponding edge
e=uv
for each action
e\in E
with
s(e)=u
and
p(e)(v)=1
.
The optimal policy
\sigma
maps each vertex to one of its outgoing edges.
An optimal policy for a DMDP can be obtained by finding the pointwise maximal solution to the system (
1
),
which, since
\gamma(e)\in(0,1)
for all
e\in E
, always exists and is bounded (for a proof, see e.g.,
[
MTZ10
]
).

Currently, the most efficient known strongly polynomial algorithms for solving DMDPs in full generality
are those testing 2VPI feasibility
[
CM94
,
HN94
]
(see also
[
Mad00
]
).
Less efficient strongly polynomial algorithms that avoid parametric search have also been described
[
DKNV21
,
HKZ14
]
.

The special case when all discount factors
\gamma(e)
are uniform (equal to
\gamma
, where
\gamma
can be a parameter,
not necessarily a constant) gained a lot of attention.
Madani et al.
[
MTZ10
]
showed an
O(mn)
time algorithm for this case.
Note that improving upon this bound would be a large breakthrough since
O(nm)
remains the best
known strongly polynomial bound even for the simpler problem of negative cycle detection.
Weaker strongly polynomial upper bounds can be obtained by analyzing the performance of the simplex algorithm on such DMDPs
[
PY15
,
HKZ14
]
.

Discounted APSP.

Madani et al.
[
MTZ10
]
also studied the following extension
of the DMDPs. Suppose the controller is allowed to end the process
after entering a fixed state
t\in V
, which is equivalent to adding a zero-cost loop action to
t
.
The
discounted all-pairs shortest paths
problem asks to find an optimal policy for every possible
start/end state pair
s,t\in V
.

Besides of the motivation arising from DMDPs, the discounted APSP problem is interesting in its
own as a natural generalization of the standard APSP problem. In this generalization, the cost of a path

P=eQ
for some
e\in E
is given by
c(P)=c(e)+\gamma(e)\cdot c(Q)
(for
\gamma(e)\leq 1
).
Note that in the standard APSP problem we have
\gamma(e)=1
for all
e\in E
.

The discounted APSP problem turns out to be challenging because
the shortest paths do not possess the optimal substructure property anymore (except for the path suffixes)
and, as a result, the standard
\widetilde{O}(nm)
or
O(n^{3})
time algorithms for APSP fail (see
[
MTZ10
]
).
However, one can quite easily solve the problem in
O(mn^{2})
time by applying
a reverse Bellman-Ford algorithm
n
times.

Madani et al.
[
MTZ10
]
showed that despite the additional challenges,
in the
uniform
case (when
\gamma(e)
is equal for all
e
,
and thus the cost of a path
P=e_{0}\cdots e_{k}
is given by
c(P)=\sum_{i=0}^{k}c(e)\cdot\gamma^{i}
),
the discounted APSP problem can be solved in
\widetilde{O}(n^{2}\sqrt{m})
time with a randomized algorithm.
Note that this bound is
\widetilde{O}(n^{3})
for all
m
and
\widetilde{O}(n^{2.5})
for sparse graphs.
3
3

3

In the uniform case, it does not make sense to consider the case
m>n^{2}
.

They asked whether there exists an
\widetilde{O}(nm)
time algorithm for discounted APSP in the uniform case whose
performance would match, up to polylogarithmic factors, the known algorithms solving the standard APSP problem.

Our results

First of all, we show a strongly polynomial time-space trade-off algorithm for computing

.

For any
h\in[1,n]
,

\widetilde{O}(mnh+(n/h)^{3})
expected time
and
O(m)+\widetilde{O}(n^{2}/h)
space. If the system is feasible, the algorithm computes the pointwise
maximal solution. The time bound holds with high probability.

Recall that due to known reductions
[

can be used
to solve the 2VPI feasibility problem in full generality and also to compute an optimal policy

In particular, by a suitable choice of the parameter

There exist Las Vegas algorithms solving monotone 2VPI systems:

1.

in
\widetilde{O}(nm+n^{3/2}m^{3/4})

\widetilde{O}(n^{3/2}m^{1/4})+O(m)
space,

in
\widetilde{O}(nm+n^{3})
expected time using
O(n+m)
space.

1.2
Technical overview

A simple randomized linear-space algorithm.

Our first contribution is a simple Las Vegas randomized algorithm
computing a pointwise maximal solution of a monotone 2VPI system in
O(mn^{2}\log{m})
time and
linear
space.
Note that this matches the best known deterministic time bound
[
HN94
]
which is
achieved using
\Theta(n^{2}+m)
space.

Like all the previous polynomial algorithms designed specifically for 2VPI feasibility,
we make use of Shostak‘s characterization
[
Sho81
]
of the pointwise maximal solution
{x^{\max}}
(see Theorem
2.1
).
Roughly speaking, it says that for any
v\in V
,
{x_{v}^{\max}}
equals the minimum
upper bound on
x_{v}
that can be devised from a simple path/simple cycle pair

(P,C)
such that
P=v\to w
for some
w\in V
and
C
is a cycle in
G
going through
w

whose product
\gamma(C)
of values
\gamma(e)
is less than
1
.
It is easy to verify that such a cycle
C
implies some absolute upper bound on
x_{w}
,
whereas such a path
P
implies an upper bound on
x_{v}
as a function of
x_{w}
.

Megiddo‘s algorithm
[
Meg83b
]
uses this characterization in the following way.
Let
\phi_{w}
be the tightest upper bound that can be obtained using a simple cycle
C

going through
w
. Megiddo shows that each
cycle bound

\phi_{w}
can be computed in
O(mn^{2}\log{m})
time and linear space
with parametric search.
This is possible since
\phi_{w}<\xi
can be evaluated in
O(mn)
time using a Bellman-Ford-style procedure of depth
O(n)
.
6
6

6

Here,
by the depth we mean the parallel time of the algorithm.

Thus, computing the cycle bounds
\phi_{w}
for all
n
possible

takes
O(mn^{3}\log{m})
time.
It is not difficult to show that
{x^{\max}}
can be obtained by propagating
the bounds
\phi_{w}
using a Bellman-Ford-style procedure running in
O(nm)
time and linear space.

On the other hand, the state-of-the-art algorithms for 2VPI feasibility
[
CM94
,
HN94
]
do not compute cycle bounds
at all. They instead use the following
key lemma attributed to Aspvall and Shiloach
[
AS80
]
.
7
7

7

The attribution is made consistently throughout
the previous work, e.g., in
[
CM94
,
HN94
]

Lemma 1.4
.

Let
v\in V

\xi\in\mathbb{R}

O(nm)

Cohen and Megiddo

’’locating‘‘ a value

{x_{v}^{\max}}
.
Roughly speaking, the procedure behind Lemma

tighter than
\xi

Hochbaum and Naor
[
HN94
]
use Lemma
1.4
to eliminate a single variable

by replacing it with up to

So, reducing the instance in terms of the number of variables comes at a cost of densifying

The deterministic algorithm of Cohen and Megiddo

leverages Lemma

The above explains why for both these approaches
[

,
HN94
]
,

Moreover, the usage of Lemma

To match the

]

Moreover, if

As a result, parametric search can compute

Interestingly, this property of cycle bounds does not apply to certificates considered

The trade-off algorithm.

Our space-time trade-off is obtained by combining the described
linear-space algorithm with the
\widetilde{O}(n^{3}+nm)
time algorithm of Cohen and Megiddo
[
CM94
]
.
Namely, for some threshold parameter
h
, we handle computing cycle bounds incurred
by short cycles of length less than
h
in
\widetilde{O}(nmh)
time using
O(\log{h})
initial phases of the linear-space algorithm.
Next, we show that computing the cycle bounds incurred by long cycles of length
h
or more
can be reduced, again via sampling, to a smaller (but necessarily dense) 2VPI instance with
\widetilde{O}(n/h)
variables
and
\widetilde{O}((n/h)^{2})
inequalities. Such an instance can be solved in
\widetilde{O}((n/h)^{3})
time.
Finally, we show that this reduction can be performed in
\widetilde{O}(nmh)
time and using
\widetilde{O}(n^{2}/h)
space.
The reduction constitutes another application of parametric search.
However, the key that enables its efficient implementation
is the main trick behind the randomized algorithm of Cohen and Megiddo
[
CM94
]
, i.e.,
an
\widetilde{O}(nm)
expected time procedure that can run
Lemma
1.4
for every vertex
v\in V
(critically, for each
v
with a different threshold
\xi_{v}
) in parallel (see Lemma

We now note that whereas the

Certificates of infeasibility.

Shostak‘s characterization
[
Sho81
]
(Theorem

)
states that if a monotone 2VPI system is infeasible, then there exists a minimal
certificate

that consists of at most two cycles and at most one path in
G
.
In applications, e.g., in Wayne‘s generalized minimum cost flow algorithm
[
Way02
]
, simply declaring
a monotone 2VPI system infeasible (which can be easily done by checking if the obtained pointwise
maximal solution violates the system (
1
)) is not enough, and a certificate of infeasibility is required.
Moreover, computing such certificates is a bottleneck in Wayne‘s algorithm.
We observe that constructing a certificate can be a very subtle task and it can make
2VPI feasibility algorithms considerably more complicated (see Section
8
).
Our simple randomized algorithm is capable of constructing a certificate of infeasibility,
and thus we improve the space requirement of Wayne‘s algorithm to linear when relying
on a
\widetilde{O}(mn^{2})
time 2VPI feasibility algorithm.
However, our trade-off algorithm can only provide such a certificate
conditionally
on
whether the randomized algorithm of Cohen and Megiddo
[
CM94
]
has this property.
While Wayne
[
Way02
, Section 6.2]
claims that all the previously known 2VPI feasibility algorithms have
this property, we are unsure this applies to
[
CM94
]
.
That being said, it is very likely that that (already complicated) algorithm can be suitably extended.
Then, our trade-off algorithm leads to a faster combinatorial generalized minimum cost flow algorithm.

Whenever we write

Sometimes when referring to a cycle we interpret it as a subgraph of

Let

Sometimes, for a cycle

beforehand, but its existence proves
that
y^{*}_{g}<(y^{*}_{g})^{R}
for some

Clearly, we can find one such

in
O(n)
time.

Since
y_{g}^{*}=\min_{w\in V}\min_{P\in\mathcal{P}_{g,w}^{3n}}\left\{c(P)+\gamma(P)\cdot x^{*}_{w}\right\}
,
the following lemma,
proved in Section

can be used to produce such a walk

that

.

Lemma 3.5
.

Let
s,t\in V
and
\alpha\in\mathbb{R}
. Then, an
s\to t
walk

lexicographically minimizing the pair

can be constructed in

time and linear space.

We can thus request from the algorithm solving Problem

a walk/closed walk pair

with
\gamma(D)<1
such that
x^{*}_{w_{g}}=c(F)+\gamma(F)\cdot\phi(D)
.
Symmetrically, we can construct a walk
S_{g}^{R}=u_{g}\to g
, and a pair

(note that

are walks in

such that
(y^{*}_{g})^{R}=\left((\phi(D^{R})-c(F^{R}))/\gamma(F^{R})\right)-c(S_{g}^{R}))/\gamma(S_{g}^{R})

Observe that then the closed walks

along with the walk

4
A simple randomized linear-space algorithm

In this section, we describe a simple randomized algorithm
solving Problem
3.3
.
The following lemma gives a method for computing values
\phi_{v,k}
for any
k
.
The proof is quite technical and and is deferred to Section
8
.

Lemma 4.1
.

Let
v\in V
and
k\leq n
.
Then, in
O(mk^{2}\log{m})
time and linear space one can
compute either the value

\phi_{v,k}
(along with a closed walk
C\in\mathcal{C}_{v}^{k}
such that
\gamma(C)<1
and
\phi(C)=\phi_{v,k}

if
\phi_{v,k}\neq\infty
)
or a set of at most two closed walks certifying the infeasibility of the system.

Note that Problem
3.3
can be easily solved deterministically
in
O(mn^{3}\log{m})
time by setting
x^{*}_{v}=\phi_{v,n}
for each
v\in V
.
However, for example, for large distinguished cycles
C\in\mathcal{C}^{*}

it would be enough to set
x^{*}_{u}=\phi_{u,|C|}
for just one vertex
u\in V(C)
,
instead of all
|C|
vertices. Unfortunately, it is not clear how to
construct
\mathcal{C}^{*}
deterministically without computing
\phi_{v,n}
for all
v\in V
,
which again takes
O(mn^{3}\log{m})
time.
We will thus use random sampling to hit all the distinguished cycles.
For example, to hit all distinguished cycles of length
\Theta(n)
with high probability,
only
\widetilde{O}(1)
samples are needed.

The simple randomized algorithm proceeds in
O(\log{n})
phases numbered
0,\ldots,\ell
, where
\ell
is the largest
integer such that
2^{\ell}\leq n
.
Initially,
x_{v}^{*}=\infty
for all
v
. Consider the
j
-th phase. In the
j
-th phase we repeat the following

t_{j}=\lceil n/2^{j}\rceil\cdot(\ell+2-j)^{3}
times. First, sample a vertex
v\in V
uniformly at random.
Then, compute
\phi_{v,2^{j+1}}
using Lemma
4.1
and set
x_{v}^{*}:=\min(x_{v}^{*},\phi_{v,2^{j+1}})
.
If Lemma
4.1
fails with a certificate of infeasibility, we terminate
with that certificate.

Lemma 4.2
.

If no certificate of infeasibility is produced, then
with constant probability, for each distinguished cycle
C\in\mathcal{C}^{*}
there exists
v\in V(C)

such that
\phi(D_{v})\leq x_{v}^{*}\leq\phi_{v,|C|}
for some
D_{v}\in\mathcal{C}_{v}^{n}
.

Proof.

Denote by
p
the probability that we fail to achieve the goal from the lemma‘s statement.
So our aim is on proving that
p
is bounded from above by a constant less than
1
.

Let
\mathcal{C}^{*}_{j}\subseteq\mathcal{C}^{*}
be the subset of cycles of
\mathcal{C}^{*}
of size between
2^{j}
and
2^{j+1}
.
Since the cycles in
\mathcal{C}^{*}
are vertex-disjoint, we have
\sum_{C\in\mathcal{C}^{*}}|C|\leq n
.
As a result,
|\mathcal{C}^{*}_{j}|\leq n/2^{j}
.

In the following,
to hit a cycle
C\in\mathcal{C}^{*}_{j}
means to sample a vertex that is an element of
V(C)
.
Clearly, after a cycle is hit with
v\in V(C)
, we set
x^{*}_{v}
to a value no more than
\phi_{v,2^{j+1}}\leq\phi_{v,|C|}
.
Let
p_{j}
be the probability that during phase
j
we fail to hit some
C\in\mathcal{C}^{*}_{j}
.
By the union bound, we have:

p\leq\sum_{j=0}^{\ell}p_{j}.

Imagine that we sample vertices in the
j
-th phase indefinitely.
For any
S\subseteq\mathcal{C}^{*}_{j}
, let
the random variable
X_{j,S}
denote the minimal number of initial
samples in the
j
-th phase that hit every cycle in
S
at least once.

We now show that for any
S\subseteq\mathcal{C}^{*}_{j}
,
\mathbb{E}[X_{j,S}]\leq\frac{n}{2^{j}}\cdot\sum_{i=1}^{|S|}\frac{1}{i}
.
We prove the claim by induction on
|S|
. The case
S=\emptyset
is trivial.
For any
C\in\mathcal{C}^{*}_{j}
, the probability that a sample hits the cycle
C
is clearly
|C|/n
.
Moreover, let
y=\sum_{C\in S}|C|
.
We have:

\displaystyle\mathbb{E}[X_{j,S}]

\displaystyle=1+\left(\sum_{C\in S}\frac{|C|}{n}\cdot\mathbb{E}[{X_{j,S\setminus\{C\}}}]\right)+\frac{n-y}{n}\cdot\mathbb{E}[X_{j,S}]

\displaystyle\leq 1+\left(\sum_{C\in S}\frac{|C|}{n}\cdot\left(\frac{n}{2^{j}}\cdot\sum_{i=1}^{|S|-1}\frac{1}{i}\right)\right)+\frac{n-y}{n}\cdot\mathbb{E}[X_{j,S}]

\displaystyle\leq 1+\frac{y}{2^{j}}\cdot\left(\sum_{i=1}^{|S|-1}\frac{1}{i}\right)+\left(1-\frac{y}{n}\right)\cdot\mathbb{E}[X_{j,S}].

By a simple transformation, and since
y\geq|S|\cdot 2^{j}
, we obtain:

\mathbb{E}[X_{j,S}]\leq\frac{n}{y}+\frac{n}{2^{j}}\cdot\sum_{i=1}^{|S|-1}\frac{1}{i}\leq\frac{n}{2^{j}}\cdot\frac{1}{|S|}+\frac{n}{2^{j}}\cdot\sum_{i=1}^{|S|-1|}\frac{1}{i}=\frac{n}{2^{j}}\cdot\sum_{i-1}^{|S|}\frac{1}{i},

as desired.
By the obtained bound and
|\mathcal{C}^{*}_{j}|\leq n/2^{j}
, we have:

\mathbb{E}\left[X_{j,\mathcal{C}^{*}_{j}}\right]\leq\frac{n}{2^{j}}\cdot\sum_{i=1}^{|\mathcal{C}^{*}_{j}|}\frac{1}{i}\leq\frac{n}{2^{j}}\left(\ln\frac{n}{2^{j}}+1\right)\leq\frac{n}{2^{j}}\cdot\log_{2}{\frac{2n}{2^{j}}}\leq\frac{n}{2^{j}}(\ell+2-j).

Since in the
j
-th phase we perform sampling
t_{j}=\lceil n/2^{j}\rceil\cdot(\ell+2-j)^{3}
times, we have:

p_{j}\leq\mathbb{P}\left[X_{j,\mathcal{C}^{*}_{j}}>t_{j}\right]\leq\mathbb{P}\left[X_{j,\mathcal{C}^{*}_{j}}>\mathbb{E}\left[X_{j,\mathcal{C}^{*}_{j}}\right]\cdot(\ell+2-j)^{2}\right]\leq\frac{1}{(\ell+2-j)^{2}},

where the latter bound above follows by Markov‘s inequality.
Consequently, we have:

p\leq\sum_{j=0}^{\ell}p_{j}\leq\sum_{j=0}^{\ell}\frac{1}{(\ell+2-j)^{2}}\leq\left(\sum_{j=1}^{\infty}\frac{1}{i^{2}}\right)-1=\frac{\pi^{2}}{6}-1<\frac{2}{3},

which concludes the proof.
∎

Lemma 4.3
.

The
\ell+1
phases of the algorithm require
O(mn^{2}\log{m})
time and linear space.

Proof.

By Lemma
4.1
, the running time can be bounded as follows:

\sum_{j=0}^{\ell}\left(O\left(m\cdot(2^{j})^{2}\log{m}\right)\cdot\left\lceil\frac{n}{2^{j}}\right\rceil\cdot(\ell+2-j)^{3}\right)=O\left(nm\log{m}\cdot\sum_{j=0}^{\ell}2^{j}(\ell+2-j)^{3}\right).

Moreover, we have:

\sum_{j=0}^{\ell}2^{j}(\ell-j+1)^{3}=2^{\ell+2}\cdot\sum_{j=0}^{\ell}\frac{(\ell+2-j)^{3}}{2^{\ell+2-j}}\leq 2^{\ell+2}\cdot\sum_{j=0}^{\infty}\frac{j^{3}}{2^{j}}=2^{\ell+2}\cdot O(1)=O(n).

∎

Remark 4.4
.

The purpose of using
\lceil n/2^{j}\rceil\cdot(\ell+2-j)^{3}
samples instead of simply e.g.,
\Theta(\lceil n/2^{j}\rceil\cdot\ell)

(which would guarantee high probability correctness) in the
j
-th phase
is to save an
O(\log n)
factor in the final expected time bound.

Lemma 4.5
.

There is a Las Vegas algorithm solving a monotone 2VPI system (or producing a minimal certificate
of infeasibility) in
O(mn^{2}\log{m})
expected time
and linear space.
With high probability, the algorithm finishes in
O(mn^{2}\cdot\log{m}\cdot\log{n})
time.

Proof.

The lemmas
4.2
and
4.3
combined show that
\ell+1
phases produce a correct solution or certify infeasibility with probability at least
1/3

in
O(mn^{2}\log{m})
time.

We now discuss how to verify whether the algorithm made a mistake and we need to rerun it.
Consider some run of the algorithm.
If the run failed with a certificate, then we can stop since the system is infeasible for sure.
Otherwise, the run attempted to compute a pointwise maximal solution
x
.
If
x
does not satisfy (
1
), which can be tested in
O(m)
time, then the run failed to produce a certificate,
so we restart.
Otherwise,
x
certifies that the system is feasible, so we only need to verify whether
x
is indeed pointwise maximal.
Clearly, if for some
u
we have
x_{u}<\min_{uv=e\in E}\{c(e)+\gamma(e)\cdot x_{v}\}
, then
one can increase
x_{u}
slightly without violating the inequalities and obtain a better solution.
So the run indeed made a mistake.
Otherwise,
x
is a vertex of the feasible polytope.
So if
x
is not optimal, it is possible to move to an adjacent vertex which improves
the objective function
\sum_{v\in V}x_{v}
.
Therefore, for each

with
x_{u}=c(e)+\gamma(e)\cdot x_{v}
we need
to check whether for some
\alpha>0
one can increase
x_{u}
by
\alpha
and
x_{v}
by
\gamma(e)\alpha

without violating any of the other inequalities.
This can be easily verified in
O(nm)
time or even near-linear time.

Clearly, the expected number of times the algorithm is repeated before producing
a correct answer is at most
3
.
Within
O(\log{n})
repeats, the failure probability gets decreased to inversely polynomial in
n
.

Since we only store the values
x_{v}^{*}
for
v\in V
, the used space is linear by Lemma
4.1
.
∎

6
Discounted All-Pairs Shortest Paths

Let
\gamma\in(0,1)
be a fixed discount factor.
Let
G=(V,E)
be a weighted directed graph with edge costs given by
c:E\to\mathbb{R}
.
For a walk
P\subseteq G
, its cost
c(P)
is defined
as it was before but with
\gamma(e)\equiv\gamma
for all
e\in E
.
So, if
P=e_{1}\ldots e_{k}
, then
c(P)=\sum_{i=1}^{k}c(e_{i})\cdot\gamma^{i-1}
.
Since
\gamma(e)=\gamma
for all
e
, we can assume that
G
is simple (and thus
m=O(n^{2})
)
and thus writing
c(uv)
is unambiguous.

A
discounted shortest path
from
s
to
t
is a finite
s\to t

walk
P
minimizing
c(P)
.
Let
\delta^{k}_{G}(s,t)
be the minimum cost of a
s\to t

walk with
exactly

k
edges.
The
discounted distance

\delta_{G}(s,t)
is defined as
\inf_{k\geq 0}\delta^{k}_{G}(s,t)
.
Madani et al.
[
MTZ10
]
showed that
\delta_{G}(s,t)
is not necessarily attained
by a finite path even if all edge costs are positive. So, in particular, a discounted
shortest path needs not be simple. However, they showed
[
MTZ10
, Lemma 5.8]
the following reduction.

Lemma 6.1
.

[
MTZ10
]

In
O(nm)
time, the discounted APSP problem on
G
can be reduced to a discounted APSP
problem on a graph
G^{\prime}
with
|V(G^{\prime})|=O(n)
and
|E(G^{\prime})|=O(n+m)
such that:

(1)

each
v\in V(G)
is assigned two corresponding vertices
v^{\prime},v^{\prime\prime}
in
V(G^{\prime})
,

(2)

for all
u,v\in V(G)
we have
\delta_{G}(u,v)=\delta_{G^{\prime}}(u^{\prime},v^{\prime\prime})
,

(3)

for all
s,t\in V(G^{\prime})
there exists a finite simple path
P=s\to t
in
G^{\prime}
such that
c(P)=\delta_{G^{\prime}}(s,t)
,

(4)

if
k
is minimum such that
\delta_{G^{\prime}}^{k}(s,t)=\delta_{G^{\prime}}(s,t)
, then for

every
walk
Q=s\to t
in
G^{\prime}
such that
c(Q)=\delta_{G^{\prime}}(s,t)
and
|Q|=k
,
Q
is a simple path.

Proof.

The properties (1)-(3) are proved in
[
MTZ10
, Lemma 5.8]
. We now argue that
property (4) holds as well. Suppose
Q
is not a simple path, then, it
can be expressed as
Q_{1}CQ_{2}
, where
C
is a non-empty closed walk.
We have
c(CQ_{2})<c(Q_{2})
, as otherwise we would have
\delta_{G^{\prime}}(s,t)\leq c(Q_{1}Q_{2})\leq c(Q_{1}CQ_{2})=\delta_{G^{\prime}}(s,t)

and
Q_{1}Q_{2}
would have less than
k
edges, which is impossible.
Consequently,
we obtain:

\delta_{G}^{\prime}(s,t)\leq c(Q_{1}CCQ_{2})=c(Q_{1}C)+\gamma(Q_{1}C)\cdot c(CQ_{2})<c(Q_{1}C)+\gamma(Q_{1}C)\cdot c(Q_{2})=c(Q_{1}CQ_{2}),

that is,
\delta_{G}^{\prime}(s,t)<\delta_{G}^{\prime}(s,t)
,
a contradiction.
∎

In the following, we assume that the above reduction has been applied and we reset
G:=G^{\prime}
. As a result, we only
need to compute
\min_{k=0}^{n}\{\delta_{G}^{k}(s,t)\}
for all
s,t\in V
.
For simplicity, in the following we put

\delta_{G}(s,t):=\min_{k=0}^{n}\{\delta_{G}^{k}(s,t)\}
.
Moreover, for each pair
s,t\in V
, let
\ell_{s,t}

denote the minimal number of edges on an
s\to t
walk
with the minimum cost
\delta_{G}(s,t)
.
By Lemma
6.1
, all discounted shortest
s\to t
paths
with
\ell_{s,t}
edges are simple.

We concentrate
on computing the values
\delta_{G}(s,t)
and not the respective paths themselves.
However, the given algorithms can be easily extended to produce the representation
of all discounted shortest paths within the same asymptotic time bound.
Note that due to the following simple facts (observed in
[
MTZ10
]
), the discounted
shortest paths to a single fixed target vertex
t\in V
(from all possible sources)
can be represented using a tree.

Observation 6.2
.

Let
P=s\to t
be a discounted shortest path. Then, every suffix of
P
is
a discounted shortest path. More formally, if
P=P_{1}P_{2}
, where
P_{2}
is
a
w\to t
path, then
P_{2}
is a discounted shortest path, i.e.,
c(P_{2})=\delta_{G}(w,t)
.

Proof.

We have
c(P)=c(P_{1})+\gamma^{|P_{1}|}\cdot c(P_{2})
. If there existed another path

Q=w\to t
with
c(Q)<c(P_{2})
,
P_{1}Q
would have smaller cost than

P_{1}P_{2}
since
\gamma>0
.
Then
P
would not be shortest.
∎

Observation 6.3
.

Let
P=s\to t
be a discounted shortest path. Let
1\leq k\leq|P|
.
Then the
k
-prefix of
P
forms a path with the smallest cost
among paths with exactly
k
edges and same respective endpoints.
More formally, if
P=P_{1}P_{2}
, where
P_{1}
is
a
s\to w
path and
|P_{1}|=k
, then
c(P_{1})=\min\{c(P):P\in\mathcal{P}_{s,w}^{k},|P|=k\}
.

Proof.

We have
c(P)=c(P_{1})+\gamma^{k}\cdot c(P_{2})
. If there existed another path

Q=s\to w
with
|Q|=k
, then
\gamma(P_{1})=\gamma(Q)
and
c(Q)<c(P_{1})
, so
QP_{2}
would have a smaller cost than

P_{1}P_{2}
.
∎

In the following lemmas, we introduce the building blocks of our algorithm
for discounted APSP.

Lemma 6.4
.

Let
t\in V
and
k\geq 1
. One can compute
\delta^{\leq k}_{G}(s,t)=\min_{j=0}^{k}\{\delta^{j}_{G}(s,t)\}

for all
s\in V
and
j=0,\ldots,k
in
O(mk)
time.

Proof.

For
j=0
we have
\delta^{\leq 0}_{G}(t,t)=0
and
\delta^{\leq 0}_{G}(s,t)=\infty
for
s\neq t
.
Note that by Observation
6.2
, for any
j>0
and
s\in V

we have

\delta^{\leq j}_{G}(s,t)=\min\left(\delta^{\leq j-1}_{G}(s,t),\min_{su\in E}\{c(su)+\gamma\cdot\delta_{G}^{\leq j-1}(u,t)\}\right).

As a result, all the values
\delta^{\leq k}_{G}(s,t)
of interest can be computed using
k
Bellman-Ford-style
steps that take
O(m)
time each.
∎

Lemma 6.5
.

Let
s\in V
and
k\geq 1
. One can compute
\delta^{j}_{G}(s,t)
for all
j=0,\ldots,k
and
t\in V

in
O(mk)
time.

Proof.

We have
\delta^{0}_{G}(t,t)=0
and
\delta^{0}_{G}(s,t)=\infty
for
s\neq t
.
By Observation
6.3
, for any
j>0
and

we have

\delta^{j}_{G}(s,t)=\min_{ut\in E}\{\delta^{j-1}_{G}(s,u)+\gamma^{j-1}\cdot c(ut)\}.

As a result, all the required
\delta^{j}_{G}(s,t)
can be computed in
O(mk)
time.
∎

Lemma 6.6
.

Let
s\in V
and
k\geq 1
. Then, in
O(mk)
time one can construct
a data structure

answering the following queries.

For a given vector
(v,x_{1},\ldots,x_{l})\in V\times\mathbb{R}^{l}

Proof.

The first step is to compute

and

.
For a given

.
The lower envelope

Note that

can be interpreted as a plot of the function

The data structure consists of the envelopes

Since the coordinates

\gamma^{\prime}:E^{\prime}\to\mathbb{R}
.
For each
uv=e\in E
, we have a corresponding
uv=e^{\prime}\in E^{\prime}
with

c^{\prime}(e)=c(e)/\gamma(e)
and
\gamma^{\prime}(e)=1/\gamma(e)
.
Moreover, for each
v\in V
, we have an edge
vt=e^{\prime}_{v}\in E^{\prime}

with
c^{\prime}(e^{\prime}_{v})=-\xi_{v}
,
\gamma^{\prime}(e^{\prime}_{v})=1
.
Note that we have a negative GAP in
G^{\prime}
iff for some walk
P=w\to v

and a cycle
C
with
\gamma^{\prime}(C)>1
, we have

c^{\prime}(Pe^{\prime}_{v})<\phi^{\prime}_{w}(C)
, or equivalently
c^{\prime}(P)-\gamma^{\prime}(P)\cdot\xi_{v}<\frac{c^{\prime}_{w}(C)}{1-\gamma^{\prime}(C)}
.
This in turn is equivalent to

\frac{1}{\gamma(P^{R})}\cdot(c(P^{R})-\xi_{v})<\frac{c_{w}(C^{R})}{\gamma(C^{R})-1}.

Therefore we have,
c(P^{R})+\gamma(P^{R})\cdot\phi_{w}(C^{R})<\xi_{v}
and
P^{R}
is a
v\to w
walk, and
C^{R}
is a
w\to w
closed walk
with
\gamma(C^{R})<1
. This proves that there is a 1-1 correspondence
between negative GAPs in
G^{\prime}
, and certificates that we seek for in
G
.

Finally, the algorithm that we described is equivalent to that of
[
RW09
, Figure 2]
:
applied to
G^{\prime}
, that algorithm computes walks
Q_{w,j}^{\prime}=w\to v
minimizing
c^{\prime}(Q_{w,j}^{\prime})-\gamma^{\prime}(Q_{w,j}^{\prime})\cdot\xi_{v}
,
which is equivalent to maximizing
\xi_{v}-c^{\prime}(Q_{w,j}^{\prime})=\frac{1}{\gamma((Q_{w,j}^{\prime})^{R})}\left(\xi_{v}-c((Q_{w,j}^{\prime})^{R})\right)
.
So by substituting
Q_{w,j}:=(Q_{w,j}^{\prime})^{R}
the algorithm computes walks
Q_{w,j}=v\to w
in
G

maximizing
\frac{1}{\gamma(Q_{w,j}}\left(\xi_{v}-c(Q_{w,j})\right)
, which is precisely what
our version of the algorithm does. The tie-braking rules are the same as well.
∎

To guarantee consistency, when picking a vertex
w
in the above lemma to produce
a certificate
(P_{w},C)
, we use
w
with
y_{w,j-1}>\phi_{w}(C)

that is minimal according to some fixed order on
V
.

Lemma 9.4
.

Let
{x_{v}^{\max}}<\xi_{v}
and
{x_{u}^{\max}}\geq\xi_{u}
for all
u\in V\setminus\{v\}
.
Then, the algorithm terminates with a certificate
(P_{w},C)
that does not depend
on
\{\xi_{u}:u\in V\setminus\{v\}\}
.

Proof.

Suppose the algorithm run for
\xi
produces a certificate
(P_{w},C)
in phase
j
.
Recall that by construction,
P_{w}=e_{1}\ldots e_{k}
, where
e_{i}=v_{i-1}v_{i}
, and
v_{0}=v
,
v_{k}=w
,
and
y_{v,j-1}=\xi_{v}
.
For any
i
, we have

y_{v_{i},j-1}=(y_{v_{i-1},j-2}-c(e_{i}))/\gamma(e_{i})\leq(y_{v_{i-1},j-1}-c(e_{i}))/\gamma(e_{i}).

Therefore, by chaining such inequalities, for any
i
we have:

y_{w,j-1}\leq(y_{v_{i-1},j-1}-c(e_{i}\ldots e_{k}))/\gamma(e_{i}\ldots e_{k}).

Suppose for some
v_{i}
,
i\geq 0
,
Q_{v_{i},j-1}
is not a
v\to v_{i}
path, but a
u\to v_{i}

path, for some
u\neq v
.
Then,

y_{v_{i},j-1}=(\xi_{u}-c(Q_{v_{i},j-1}))/\gamma(Q_{v_{i},j-1}),

and thus

y_{w,j-1}\leq(\xi_{u}-c(Q_{v_{i},j-1}e_{i+1}\ldots e_{k}))/\gamma(Q_{v_{i},j-1}e_{i+1}\ldots e_{k}).

As a result, we obtain:

c(Q_{v_{i},j-1}e_{i+1}\ldots e_{k})+\gamma(Q_{v_{i},j-1}e_{i+1}\ldots e_{k})\cdot y_{w,j-1}\leq\xi_{u}.

This, in combination with
y_{w,j-1}>\phi_{w}(C)
, shows that
{x_{u}^{\max}}<\xi_{u}
, a contradiction.
This proves that
Q_{v_{i},j-1}
is a
v\to v_{i}
path for all
i
.

Next we prove that for each
z\in V(C)
,
Q_{z,j}
is a
v\to z
walk.
Let
C=e_{0}\ldots e_{k-1}
such that
e_{i}=u_{i}u_{(i+1)\bmod{k}}
.
Split the sequence of vertices appearing on
C
(in order) into maximal segments
u_{g},\ldots,u_{h}
such that

y_{u_{g},j}>y_{u_{g},j-1}
and
y_{u_{l},j}=y_{u_{l},j-1}
for all

l=g+1,\ldots,h
.
Such a split is possible since
y_{w,j}>y_{w,j-1}
.
For each segment, we have
y_{u_{(h+1)\bmod k},j}>y_{u_{(h+1)\bmod k},j-1}
.

Consider an arbitrary such segment. We have already proved
that
Q_{u_{(h+1)\bmod k},j-1}
is a
v\to u_{(h+1)\bmod k}
path, since the choice
of the vertex
w
only required
y_{w,j}>y_{w,j-1}
.
We also have
Q_{u_{h},j}=Q_{u_{(h+1)\bmod k},j-1}\cdot e_{h}
since
p_{u_{h},j}=e_{h}
.
Hence,
Q_{u_{h},j}
is a
v\to u_{h}
path.
But
y_{u_{h},j}=y_{u_{h},j-1}
, so in fact
Q_{u_{h},j-1}=Q_{u_{h},j}
is also a
v\to u_{h}
path.
Analogously, we inductively prove that subsequently
Q_{u_{h-1},j}=Q_{u_{h-1},j-1},Q_{u_{h-2},j}=Q_{u_{h-2,j-1}},\ldots,Q_{u_{g+1},j}=Q_{u_{g+1},j-1}

are also walks starting in
v
.
Finally, from
Q_{u_{g+1},j-1}=v\to u_{g+1}
we conclude that
Q_{u_{g},j}=v\to u_{g}
.

Now, consider a vector
(\xi^{*})_{u\in V}
such that
\xi_{v}^{*}=\xi_{v}

and
\xi^{*}_{u}={x_{u}^{\max}}
for all
u\in V\setminus\{v\}
.
For any other vector
(\xi^{\prime})_{v\in V}
that satisfies
the requirements of the lemma, we have
\xi^{\prime}_{u}\leq\xi^{*}_{u}
for all
u\in V
.
By Lemma
9.3
, running the algorithm with the input
\xi^{*}

produces some certificate
(P_{s}^{*},C^{*})
for some
s\in V
, and
running it with the input
\xi^{\prime}
produces a certificate
(P_{t}^{\prime},C^{\prime})
for some

t\in V
.

Denote by
Q_{w,j}^{*},y_{w,j}^{*}
and
Q_{w,j}^{\prime},y_{w,j}^{\prime}
the respective paths
Q_{w,j}
and values
y_{w,j}

for the inputs
\xi^{*}
and
\xi^{\prime}
respectively.
Note that for any
w,j
we have
y_{w,j}^{*}\geq y_{w,j}^{\prime}
by the definition of
\xi^{*}
.
Moreover, since
\xi^{*}_{v}=\xi^{\prime}_{v}
, we have that
Q_{w,j}^{*}=v\to w
implies
that
Q_{w,j}^{\prime}=Q_{w,j}^{*}
.

Suppose that the certificate
(P_{s}^{*},C^{*})
is produced in phase
j
and
s
is chosen minimal possible.
Then, as we have proved, for all
z\in V(P_{s}^{*})
,
Q_{z,j-1}^{*}
is a
v\to z
walk.
Moreover, for all
z\in V(C^{*})
,
Q_{z,j}^{*}
is a
v\to z
walk.
Consequently,
Q_{z,j-1}^{\prime}=Q_{z,j-1}^{*}
for all
z\in V(P_{s}^{*})
, and
Q_{z,j}^{\prime}=Q_{z,j}^{*}

for all
z\in V(C^{*})
.
As a result, the same cycle
C^{*}
exists in
H_{j}
and the same path
P_{s}^{*}

exists in
H_{j-1}
for the input
\xi^{\prime}
. We conclude that the algorithm
run for
\xi^{\prime}
will terminate with
(P_{s}^{*},C^{*})
unless it terminates earlier,
i.e., in an earlier phase or in the phase
j
with a smaller vertex
t
.

Now suppose that for the input
\xi^{\prime}
, the algorithm terminates earlier (at phase
j
)
than if it was run with the input
\xi^{*}
.
Note that then we need to either have (i)
Q_{z,j-1}^{*}=w\to z
for some
z\in V(P_{t}^{\prime})
and
w\in V\setminus\{v\}
,
or we have (ii)
Q_{z,j}^{*}=w\to z
for some
z\in V(C^{\prime})
and
w\in V\setminus\{v\}
–
otherwise the run with the input
\xi^{*}
would have terminated no later than that for
\xi^{\prime}
.

Consider the case (i). Then,
y_{z,j-1}^{*}\geq y_{z,j-1}^{\prime}
and if
P_{t}^{\prime}=R_{1}R_{2}
, where
R_{1}=v\to z
and
R_{2}=z\to t
,
we would obtain similarly as before
c(Q_{z,j-1}\cdot R_{2})+\gamma(Q_{z,j-1}\cdot R_{2})\cdot y^{\prime}_{t,j-1}\leq\xi_{w}
,
which, along with
y^{\prime}_{t,j-1}<\phi_{t}(C^{\prime})
would imply
{x_{w}^{\max}}<\xi_{w}
, a contradiction.

Now let us focus on (ii). Let
C^{\prime}=C_{1}C_{2}
, where
t\to z=C_{1}=e_{0}\ldots e_{l}
and
C_{2}=z\to t
.
Let
e_{i}=u_{i}u_{i+1}
, so that
u_{0}=t
and
u_{l+1}=z
.
By chaining the inequalities on

we obtain

\phi_{t}(C^{\prime})<y^{\prime}_{t,j-1}<y^{\prime}_{t,j}\leq(y^{\prime}_{z,j}-c(C_{2}))/\gamma(C_{2})\leq(y^{*}_{z,j}-c(C_{2}))/\gamma(C_{2})=(\xi^{*}_{w}-c(Q_{z,j}^{*}C_{2}))/\gamma(Q_{z,j}^{*}C_{2})
.
As a result, we have
c(Q_{z,j}^{*}C_{2})+\gamma(Q_{z,j}^{*}C_{2})\cdot\phi_{t}(C^{\prime})<\xi^{*}_{w}
.
So,
{x_{w}^{\max}}<\xi^{*}_{w}
, a contradiction.

We conclude that for any input
\xi^{\prime}
, the algorithm has to terminate with the same certificate
as for the input
\xi^{*}
.
As a result, it terminates with the same certificate for any
\xi
satisfying the requirements
of the lemma.
