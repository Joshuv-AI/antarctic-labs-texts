QuPeD: Quantized Personalization via Distillation with Applications to Federated Learning
Kaan Ozkara, Navjot Singh, Deepesh Data, Suhas Diggavi

Abstract
Traditionally, federated learning (FL) aims to train a single global model while collaboratively using multiple clients and a server. Two natural challenges that FL algorithms face are heterogeneity in data across clients and collaboration of clients with diverse resources . In this work, we introduce a quantized and personalized FL algorithm QuPeD that facilitates collective (personalized model compression) training via knowledge distillation (KD) among clients who have access to heterogeneous data and resources. For personalization, we allow clients to learn compressed personalized models with different quantization parameters and model dimensions/structures. Towards this, first we propose an algorithm for learning quantized models through a relaxed optimization problem, where quantization values are also optimized over. When each client participating in the (federated) learning process has different requirements for the compressed model (both in model dimension and precision), we formulate a compressed personalization framework by introducing knowledge distillation loss for local client objectives collaborating through a global model. We develop an alternating proximal gradient update for solving this compressed personalization problem, and analyze its convergence properties. Numerically, we validate that QuPeD outperforms competing personalized FL methods, FedAvg, and local training of clients in various heterogeneous settings.

Problem Formulation

Our goal in this paper is for clients to collaboratively learn personalized quantized models (with potentially different precision and model sizes/types). To this end, below, we first state our final objective function that we will end up optimizing in this paper for learning personalized quantized models, and then in the rest of this section we will describe the genesis of this objective.

Recall from (
1
), in the traditional FL setting, the local loss function at client
i
is denoted by
f_{i}
. For personalized compressed model training, we define the following augmented loss function at client
i
:

\displaystyle F_{i}({\bf x}_{i},{\bf c}_{i},{\bf w})

\displaystyle:=(1-\lambda_{p})\left(f_{i}({\bf x}_{i})+f_{i}(\widetilde{Q}_{{\bf c}_{i}}({\bf x}_{i}))\right)+\lambda R({\bf x}_{i},{\bf c}_{i})

(2)

\displaystyle+\lambda_{p}\left(f^{KD}_{i}({\bf x}_{i},{\bf w})+f^{KD}_{i}(\widetilde{Q}_{{\bf c}_{i}}({\bf x}_{i}),{\bf w})\right).

Here,
{\bf w}\in\mathbb{R}^{d}
denotes the global model,
{\bf x}_{i}\in\mathbb{R}^{d_{i}}
denotes the personalized model of dimension
d_{i}
at client
i
,
{\bf c}_{i}\in\mathbb{R}^{m_{i}}
denotes the model quantization centers (where
m_{i}
is the number of centers),
\widetilde{Q}_{{\bf c}_{i}}
denotes the soft-quantization function with respect to (w.r.t.) the set of centers
{\bf c}_{i}
,
R({\bf x}_{i},{\bf c}_{i})
denotes the distance function,
f^{KD}_{i}
denotes the knowledge distillation (KD) loss
[
16
]
between the two input models on client
i

\lambda
is a design parameter for enforcing quantization (large
\lambda
forces weights to be close to respective centers), and
\lambda_{p}
controls the weighted average of regular loss and KD loss functions (higher
\lambda_{p}
can be used when client data is limited). We will formally define the undefined quantities later in this section.
Consequently, our main objective becomes:

\displaystyle\min_{\begin{subarray}{c}{\bf w}\in\mathbb{R}^{d},\{{\bf x}_{i}\in\mathbb{R}^{d_{i}},{\bf c}_{i}\in\mathbb{R}^{m_{i}}:i=1,\ldots,n\}\end{subarray}}\hbox{$\left(\vbox to0.0pt{}\right.$}F\hbox{$\left(\vbox to0.0pt{}\right.$}{\bf w},\{{\bf x}_{i}\},\{{\bf c}_{i}\}\hbox{$\left)\vbox to0.0pt{}\right.$}:=\frac{1}{n}\sum_{i=1}^{n}F_{i}({\bf x}_{i},{\bf c}_{i},{\bf w})\hbox{$\left)\vbox to0.0pt{}\right.$}.

(3)

Thus, our formulation allows different clients to have personalized models
{\bf x}_{1},\ldots,{\bf x}_{n}
with different dimensions
d_{1},\ldots,d_{n}
and architectures, different number of quantization levels
m_{1},\ldots,m_{n}
(larger the
m_{i}
, higher the precision), and different quantization values in those quantization levels.
Note that there are two layers of personalization, first is due to data heterogeneity, which is reflected in clients learning different models
{\bf x}_{1},\ldots,{\bf x}_{n}
, and second is due to resource diversity, which is reflected in clients learning models with different sizes, both in terms in dimension as well as precision.

In Section
2.1
, we motivate how we came up with the first three terms in (
2
), which are in fact about a centralized setting because the function
f_{i}
and the parameters involved, i.e.,
{\bf x}_{i},{\bf c}_{i}
, are local to client
i
; and then, in Section
2.2
, we motivate the use of the last two terms containing
f^{KD}_{i}
in (
2
).

2.1
Model Compression in the Centralized Setup

Consider a setting where an objective function
f:\mathbb{R}^{d+m}\to\mathbb{R}
(which could be a neural network loss function) is optimized over both the quantization centers
{\bf c}\in\mathbb{R}^{m}
and the assignment of model parameters (or weights)
{\bf x}\in\mathbb{R}^{d}
to those centers. There are two ways to approach this problem, and we describe these approaches, their limitations, and the possible resolutions below.

Approach 1.
A natural approach is to explicitly put a constraint that weights belong to the set of centers, which suggests solving the following problem:
\min_{{\bf x},{\bf c}}f({\bf x})+\delta_{{\bf c}}({\bf x})
,
where
\delta_{{\bf c}}
denotes the indicator function for
{\bf c}\in\mathbb{R}^{m}
, and for any
{\bf c}\in\mathbb{R}^{m},{\bf x}\in\mathbb{R}^{d}
, define
\delta_{{\bf c}}({\bf x}):=0
if
\forall

j\in[d]
,
x_{j}=c
for some
c\in\{c_{1},\ldots,c_{m}\}
, otherwise, define
\delta_{{\bf c}}({\bf x}):=\infty
. However, the discontinuity of
\delta_{{\bf c}}({\bf x})
makes minimize this objective challenging. To mitigate this, like recent works
[
2
,
34
]
, we can approximate
\delta_{{\bf c}}({\bf x})
using a distance function
R({\bf x},{\bf c})
that is continuous everywhere (
e.g.
, the
\ell_{1}
-distance,
R({\bf x},{\bf c}):=\min\{\frac{1}{2}\|{\bf z}-{\bf x}\|_{1}:z_{i}\in\{c_{1},\cdots,c_{m}\},\forall i\}
).
3
3

3

[
2
]
and
[
34
]
proposed to approximate the indicator function
\delta_{{\bf c}}({\bf x})
using a distance function
R_{\bf c}({\bf x})
, where
{\bf c}
is fixed, and unlike ours, it is not a variable that the loss function is optimized over.
This suggests solving:

\displaystyle\min_{{\bf x},{\bf c}}f({\bf x})+\lambda R({\bf x},{\bf c}).

(4)

The centers are optimized to be close to the mean or median (depending on
R
) of the weights; however, there is no guarantee that this will help minimizing objective
f
. We believe that modeling the direct effect that centers have on the loss is crucial for a complete quantized training (see Appendix
D
for empirical verification of this fact), and our second approach is based on this idea.

Approach 2.
We can embed the quantization function into the loss function itself, thus solving the problem:
\min_{{\bf x},{\bf c}}\hbox{$\left(\vbox to0.0pt{}\right.$}h({\bf x},{\bf c}):=f(Q_{{\bf c}}({\bf x}))\hbox{$\left)\vbox to0.0pt{}\right.$}
,
where for every
{\bf x}\in\mathbb{R}^{d},{\bf c}\in\mathbb{R}^{m}
, the (hard) quantization function is defined as
Q_{{\bf c}}({\bf x})_{i}:=c_{k}
, where
k=\argmin_{j\in[m]}\{|x_{i}-c_{j}|\}
, which maps individual weights to the closest centers.
Note that
Q_{{\bf c}}({\bf x})
is actually a staircase function for which the derivative w.r.t.
{\bf x}
is 0 almost everywhere, which discourages the use of gradient-based methods to optimize the above objective.
To overcome this, similar to
[
33
,
11
]
, we can use a
soft
quantization function
\widetilde{Q}_{\bf c}({\bf x})
that is differentiable everywhere with derivative not necessarily 0. For example, element-wise
sigmoid
or
tanh
functions, used by
[
33
]
and
[
11
]
, respectively.
4
4

4

In their setup, the quantization centers are fixed. In contrast, we are also optimizing over these centers.

This suggests the following relaxation:

\displaystyle\min_{{\bf x},{\bf c}}\hbox{$\left(\vbox to0.0pt{}\right.$}h({\bf x},{\bf c}):=f(\widetilde{Q}_{\bf c}({\bf x}))\hbox{$\left)\vbox to0.0pt{}\right.$}.

(5)

Though we can observe the effect of centers on neural network loss in (
5
)
5
5

5

Non-relaxed version of the optimization problem for the first time formalizes the heuristic updates that are employed for quantization values in works such as
[
12
,
29
]
. In particular gradient descent on centers using
\nabla_{{\bf c}}f(Q_{{\bf c}}(x))
is equivalent to the updates in
[
12
,
29
]
.
; however, the gradient w.r.t.
{\bf x}
is heavily dependent on the choice of
\widetilde{Q}_{\bf c}
and optimizing over
{\bf x}
might deviate too much from optimizing the neural network loss function. For instance, in the limiting case when
\widetilde{Q}_{\bf c}({\bf x})\rightarrow Q_{\bf c}({\bf x})
, gradient w.r.t.
{\bf x}
is
0
almost everywhere; hence, every point becomes a first order stationary point.

Our proposed objective for model quantization.

Our aim is to come up with an objective function that would not diminish the significance of both
{\bf x}
and
{\bf c}
in the overall procedure. To leverage the benefits of both, we combine both optimization problems (
4
) and (
5
) into one problem:

\min_{{\bf x},{\bf c}}\hbox{$\left(\vbox to0.0pt{}\right.$}F_{\lambda}({\bf x},{\bf c}):=f({\bf x})+f(\widetilde{Q}_{\bf c}({\bf x}))+\lambda R({\bf x},{\bf c})\hbox{$\left)\vbox to0.0pt{}\right.$}.

(6)

Here, the first term preserves the connection of
{\bf x}
to neural network loss function, and the second term enables the optimization of centers w.r.t. the neural network training loss itself. As a result, we obtain an objective function that is continuous everywhere, and for which we can use Lipschitz tools in the convergence analysis – which previous works did not exploit. In fact, we show the existence of Lipschitz parameters for a specific soft quantization function
\widetilde{Q}_{\bf c}({\bf x})
based on
sigmoid
in Appendix
A
.

Remark 1
.

It is important to note that with this new objective function, we are able to optimize not only over weights but also over centers. This allows us to theoretically analyze how the movements of the centers affect the convergence. As far as we know, this has not been the case in the literature of quantized neural network training.
Moreover, we observe numerically that optimizing over centers improves performance of the network; see Appendix
D
.

2.2
Towards Personalized Quantized Federated Learning: Knowledge Distillation

Note that the objective function defined in (
6
) can be used for learning a quantized model locally at any client. There are multiple ways to extend that objective for learning personalized quantized models (PQMs) via collaboration. For example, when all clients want to learn personalized models with the
same
dimension (but with different quantization levels), then one natural approach is to add an
\ell_{2}
penalty term in the objective that would prevent local models from drifting away from the global model and from simply fitting to local data. This approach, in fact, has been adopted in
[
8
,
14
]
for learning personalized models and in
[
23
]
for heterogeneous FL, though not quantized ones. In our previous work QuPeL
[
28
]
we analyzed a quantized approach for learning PQMs (having the
same
dimension). In Section
5
, we demonstrate that QuPeD (for the same task but using KD as opposed to the
\ell_{2}
penalty) outperforms QuPeL.

In this paper, since we allow clients to learn PQMs with potentially
different
dimensions, the above approach of adding a
\ell_{2}
penalty term in the objective is not feasible. Observe that, the purpose of incorporating a
\ell_{2}
penalty in the objective is to ensure that the personalized models do not have significantly different output class scores compared to the global model which is trained using the data generated at all clients; this does not, however, require the global model to have the same dimension as that of local models and can be satisfied by augmenting the local objective (
6
) with a certain
knowledge distillation
(KD) loss. In our setting, since clients’ goal is to learn personalized models with different dimensions that may also have
different
quantization levels, we augment the local objective (
6
) with two separate KD losses:
f^{KD}_{i}({\bf x}_{i},{\bf w})
and
f^{KD}_{i}(\widetilde{Q}_{{\bf c}_{i}}({\bf x}_{i}),{\bf w})
, where the first one ensures that the behavior of
{\bf x}_{i}\in\mathbb{R}^{d_{i}}
is not very different from that of
{\bf w}\in\mathbb{R}^{d}
, and the second one ensures the same for the quantized version of
{\bf x}_{i}
and
{\bf w}
.
Formally, we define them using KL divergence as follows:
f^{KD}_{i}({\bf x}_{i},{\bf w}):=D_{KL}(s^{w}_{i}({\bf w})\|s_{i}({\bf x}_{i}))
and
f^{KD}_{i}(\widetilde{Q}_{{\bf c}_{i}}({\bf x}_{i}),{\bf w}):=D_{KL}(s^{w}_{i}({\bf w})\|s_{i}(\widetilde{Q}_{{\bf c}_{i}}({\bf x}_{i})))
, where
s^{w}_{i}
and
s_{i}
denote functions whose inputs are global and personalized models, respectively – and data samples implicitly – and outputs are the softmax classification probabilities of the network.

We need to train
{\bf x}_{i}
and
{\bf w}
mutually. Identifying the limitations of existing approaches for theoretical analysis (as mentioned in related work in Section
1
), we use reverse KL updates (
i.e.
, taking gradient steps w.r.t. the first parameter in
D_{KL}(\cdot,\cdot)
) to train the teacher network
{\bf w}
from the student network
{\bf x}_{i}
. This type of update can be shown to converge and also empirically outperforms
[
31
]
(see Section
5
). We want to emphasize that though there are works
[
21
,
24
]
that have used KD in FL and studied its performance (only empirically), ours is the first work that carefully formalizes it as an optimization problem (that also incorporate quantization) which is necessary to analyze convergence properties.

Convergence result.
Now we state our main convergence result (proved in Section

({\bf x},{\bf c})\in\mathbb{R}^{d+m}

Theorem 1
.

Consider running Algorithm

for

{\bf G}^{t}:=[\nabla_{{\bf x}^{t+1}}F_{\lambda}\left({\bf x}^{t+1},{\bf c}^{t}\right)^{T},\nabla_{{\bf c}^{t+1}}F_{\lambda}\left({\bf x}^{t+1},{\bf c}^{t+1}\right)^{T}]^{T}

Theorem
1

Remark 2
.

In Theorem
1
, we see that gradient norm decays without any constant error terms. The convergence rate depends on Lipschitz smoothness constants of
f
and
f(\widetilde{Q}_{{\bf c}}(.))
through
L_{\max}
and
L_{\min}
. Choosing a smoother
\widetilde{Q}_{{\bf c}}(.)
would speed up convergence; however, if chosen too small, this could result in an accuracy loss when hard-quantizing the parameters at the end of the algorithm.

Remark 3

(Number of centers and convergence)
.

The number of quantization levels
m
has a direct effect on convergence through the soft quantization function
\widetilde{Q}_{{\bf c}}({{\bf x}})
and Lipschitz constants. Note that as
m\to\infty
, we have
\widetilde{Q}_{{\bf c}}({{\bf x}})\to{\bf x},\forall{\bf x}
. In this case,
\widetilde{Q}_{{\bf c}}({{\bf x}})
is
0
-smooth and
1
-Lipschitz w.r.t. all parameters. As a result, we would have
L_{\min}=L
and
L_{\max}=2L
. Note that the ratio
\nicefrac{{L^{2}_{\max}}}{{L_{\min}}}
increases as the quantization becomes more aggressive, and consequently, aggressive quantization has a scaling effect on convergence rate.

Remark 4

(Resource and data heterogeneity.)
.

Firstly, our observation from Remark
3
holds here as well. Aggressive quantization has a scaling effect on all the terms through
L^{(i)}_{\max}
. Now the interesting question is: how does having different model structures across clients affect the convergence rate of Theorem
2
? Note that in Assumptions
A.3, A.5
, we assume clients have different client-specific gradient bounds; this results in client specific
L^{(i)}_{\max}
, and consequently
\overline{\kappa}
, which couples resource and data heterogeneity across clients. Here we make an important first observation regarding the coupled effect of data and resource heterogeneity on the convergence rate. Suppose data distributions are fixed across clients (i.e.,
\kappa_{i}
’s are fixed) and we need to choose models for each client in the federated ecosystem. Then, for a fast convergence, for the clients that have local data that is not a representative of the general distribution (large
\kappa_{i}
), it is critical to choose models with small smoothness parameter (e.g., choosing a less aggressive quantization); whereas, clients with data that is representative of the overall data distribution (small
\kappa_{i}
) can tolerate having a less smooth model.

7.3
Proof Outline with Client Sampling

Incorporating partial client participation and analyzing the resulting algorithm is fairly simple. Essentially only changes are in Lemma
1
and Corollary
1
, as everything before that is for local updates only. Now we give a summary of what changes:

Let
\mathcal{K}_{t}
denote the set of clients that participates at time
t
, where
|\mathcal{K}_{t}|=K
, i.e.,
K
clients participate in the training process at any time. In this case, we define the average parameter

and the gradient
{\bf g}^{t}
as the average over the respective parameters of only the active clients at time
t
; we also define
\gamma_{t}
similarly.

•

Change in the proof of Lemma
1
:
In the proof of Lemma
1
, the second term on the RHS of the second inequality, with the above modification will be equal to
\|\frac{1}{K}\sum_{k\in\mathcal{K}_{t}}\nabla_{\mathbf{w}^{j}}F_{k}(\mathbf{x}_{k}^{j+1},\mathbf{c}_{k}^{j+1},\mathbf{w}^{j})-\nabla_{\mathbf{w}^{j}}F_{i}(\mathbf{x}_{i}^{j+1},\mathbf{c}_{i}^{j+1},\mathbf{w}^{j})\|^{2}
. Earlier, the average was over all clients from

to

and this term was bounded by

using Assumption A.6. Now, we can use the Jensen’s inequality (iteratively) and Assumption A.6 and bound this by

•

Remaining convergence proof:
Now, continuing the exact same convergence proof and using the modified bounds of Lemma 1 and Corollary

This is the modification in the entire proof.

\displaystyle\frac{1}{n}\sum_{i=1}^{n}\hbox{$\left\|\vbox to0.0pt{}\right.$}\nabla_{{\bf w}}f_{i}({\bf w})-\nabla_{{\bf w}}f({\bf w})\hbox{$\left\|\vbox to0.0pt{}\right.$}^{2}\leq B,

\displaystyle x_{i}({\bf w}^{t})

\displaystyle:=\underset{{\bf x}\in\mathbb{R}^{d}}{\arg\min}\left\{\left\langle{\bf x}-{\bf x}^{t}_{i},\nabla f_{i}\left({\bf x}^{t}_{i}\right)\right\rangle+\left\langle{\bf x}-{\bf x}^{t}_{i},\nabla_{{\bf x}^{t}_{i}}f_{i}(\widetilde{Q}_{{\bf c}^{t}_{i}}({\bf x}^{t}_{i}))\right\rangle+\left\langle{\bf x}-{\bf x}^{t}_{i},\lambda_{p}({\bf x}^{t}_{i}-{\bf w}^{t})\right\rangle\right.

A.3
Alternating Proximal Steps

We define the following functions:
f:\mathbb{R}^{d}\rightarrow\mathbb{R},\widetilde{Q}:\mathbb{R}^{d+m}\rightarrow\mathbb{R}^{d}
, and we also define
h({\bf x},{\bf c})=f(\widetilde{Q}_{\bf c}({\bf x})),h:\mathbb{R}^{d+m}\rightarrow\mathbb{R}
where
{\bf x}\in\mathbb{R}^{d}\text{ and }{\bf c}\in\mathbb{R}^{m}
. Note that here
\widetilde{Q}_{\bf c}({\bf x})
denotes
\widetilde{Q}({\bf x},{\bf c})
. Throughout our paper we will use
\widetilde{Q}_{\bf c}({\bf x})
to denote
\widetilde{Q}({\bf x},{\bf c})
, in other words both
{\bf c}
and
{\bf x}
are inputs to the function
\widetilde{Q}_{\bf c}({\bf x})
. We propose an alternating proximal gradient algorithm. Our updates are as follows:

\displaystyle{\bf x}^{t+1}=\text{prox}_{\eta_{1}\lambda R(\cdot,{\bf c}^{t})}({\bf x}^{t}-\eta_{1}\nabla f({\bf x}^{t})-\eta_{1}\nabla_{{\bf x}^{t}}f(\widetilde{Q}_{{\bf c}^{t}}({\bf x}^{t})))

(1)

\displaystyle{\bf c}^{t+1}=\text{prox}_{\eta_{2}\lambda R({\bf x}^{t+1},\cdot)}({\bf c}^{t}-\eta_{2}\nabla_{{\bf c}^{t}}f(\widetilde{Q}_{{\bf c}^{t}}({\bf x}^{t+1})))

For simplicity we assume the functions in the objective function are differentiable, however, our analysis could also be done using subdifferentials.

Our method is inspired by
[
4
]
where the authors introduce an alternating proximal minimization algorithm to solve a broad class of non-convex problems as an alternative to coordinate descent methods. In this work we construct another optimization problem that can be used as a surrogate in learning quantized networks where both model parameters and quantization levels are subject to optimization. In particular,
[
4
]
considers a general objective function of the form
F({\bf x},{\bf y})=f({\bf x})+g({\bf y})+\lambda H({\bf x},{\bf y})
, whereas, our objective function is tailored for learning quantized networks:
F_{\lambda}({\bf x},{\bf c})=f({\bf x})+f(\widetilde{Q}_{{\bf c}}({\bf x}))+\lambda R({\bf x},{\bf c})
. Furthermore, they consider updates where the proximal mappings are with respect to functions
f,g
, whereas in our case the proximal mappings are with respect to the distance function
R({\bf x},{\bf c})
to capture the soft projection.

A.4
A Soft Quantization Function

In this section we give an example of the soft quantization function that can be used in previous sections. In particular, we can define the following soft quantization function:
\widetilde{Q}_{\bf c}({\bf x}):\mathbb{R}^{d+m}\rightarrow\mathbb{R}^{d}

[

]
.

Assumption.
For all
j\in[m]

is in a compact set. In other words, there exists a finite

such that

.

\widetilde{Q}_{\bf c}({\bf x})
is continuously and infinitely differentiable everywhere.

Fact 2
.

\sigma({\bf x})
is a Lipschitz continuous function.

Fact 3
.

Sum of Lipschitz continuous functions is also Lipschitz continuous.

Fact 4
.

Product of bounded and Lipschitz continuous functions is also Lipschitz continuous.

Fact 5
.

Let

be the i’th output then if

In our convergence analysis, we require that

and
{\bf c}
.

.

\widetilde{Q}_{\bf c}({\bf x})

-Lipschitz continuous and

-smooth with respect to
{\bf x}

Proof.

First we prove Lipschitz continuity. Note,

\displaystyle\frac{\partial\widetilde{Q}_{\bf c}({\bf x})_{i}}{\partial x_{j}}=\begin{cases}0,\text{ if }i\neq j\\

For smoothness note that,

\widetilde{Q}_{\bf c}({\bf x})

D.1
Proximal Updates

For the implementation of Algorithm
1
,
2
, we consider
\ell_{1}
-loss for the distance function
R({\bf x},{\bf c})
. In other words,
R({\bf x},{\bf c})=\min\{\frac{1}{2}\|{\bf z}-{\bf x}\|_{1}:z_{i}\in\{c_{1},\cdots,c_{m}\},\forall i\}
. For simplicity, we define
\mathcal{C}=\{{\bf z}:z_{i}\in\{c_{1},\cdots,c_{m}\},\forall i\}
.
For the first type of update (update of
{\bf x}
) we have:

\displaystyle\text{prox}_{\eta_{1}\lambda R(\cdot,{\bf c})}({\bf y})

\displaystyle={\argmin_{{\bf x}\in\mathbb{R}^{d}}}\left\{\frac{1}{2\eta_{1}}\left\|{\bf x}-{\bf y}\right\|_{2}^{2}+\lambda R({\bf x},{\bf c})\right\}

\displaystyle={\argmin_{{\bf x}\in\mathbb{R}^{d}}}\left\{\frac{1}{2\eta_{1}}\left\|{\bf x}-{\bf y}\right\|_{2}^{2}+\frac{\lambda}{2}\min_{{\bf z}\in\mathcal{C}}\|{\bf z}-{\bf x}\|_{1}\right\}

\displaystyle={\argmin_{{\bf x}\in\mathbb{R}^{d}}}\min_{{\bf z}\in\mathcal{C}}\left\{\frac{1}{2\eta_{1}}\left\|{\bf x}-{\bf y}\right\|_{2}^{2}+\frac{\lambda}{2}\|{\bf z}-{\bf x}\|_{1}\right\}

This corresponds to solving:

\displaystyle\min_{{\bf z}\in\mathcal{C}}{\min_{{\bf x}\in\mathbb{R}^{d}}}\left\{\frac{1}{\eta_{1}}\left\|{\bf x}-{\bf y}\right\|_{2}^{2}+\lambda\|{\bf z}-{\bf x}\|_{1}\right\}

Since both
\ell_{1}
and squared
\ell_{2}
norms are decomposable; if we fix
{\bf z}
, for the inner problem we have the following solution to soft thresholding:

\displaystyle x^{\star}({\bf z})_{i}=\begin{cases}y_{i}-\frac{\lambda\eta_{1}}{2},\quad\text{if }y_{i}-\frac{\lambda\eta_{1}}{2}>z_{i}\\
y_{i}+\frac{\lambda\eta_{1}}{2},\quad\text{if }y_{i}+\frac{\lambda\eta_{1}}{2}<z_{i}\\
z_{i},\quad\text{otherwise}\end{cases}

(9)

As a result we have:

\displaystyle\min_{{\bf z}\in\mathcal{C}}\left\{\frac{1}{\eta_{1}}\left\|x^{\star}({\bf z})-{\bf y}\right\|_{2}^{2}+\lambda\|{\bf z}-x^{\star}({\bf z})\|_{1}\right\}

This problem is separable, in other words we have:

\displaystyle{\bf z}^{\star}_{i}=\argmin_{z_{i}\in\{c_{1},\cdots,c_{m}\}}\left\{\frac{1}{\eta_{1}}(x^{\star}({\bf z})_{i}-y_{i})^{2}+\lambda|z_{i}-x^{\star}({\bf z})_{i}|\right\}\ \forall i

Substituting
x^{\star}({\bf z})_{i}
and solving for
z_{i}
gives us:

\displaystyle{\bf z}^{\star}_{i}=\argmin_{z_{i}\in\{c_{1},\cdots,c_{m}\}}\left\{|z_{i}-y_{i}|\right\}\ \forall i

Or equivalently we have,

\displaystyle{\bf z}^{\star}=\argmin_{{\bf z}\in\mathcal{C}}\|{\bf z}-{\bf y}\|_{1}=Q_{\bf c}({\bf y})

(10)

As a result,
\text{prox}_{\eta_{1}\lambda R(\cdot,{\bf c})}(\cdot)
becomes the soft thresholding operator:

\displaystyle\text{prox}_{\eta_{1}\lambda R(\cdot,{\bf c})}({\bf y})_{i}=\begin{cases}y_{i}-\frac{\lambda\eta_{1}}{2},\quad\text{if }y_{i}\geq Q_{\bf c}({\bf y})_{i}+\frac{\lambda\eta_{1}}{2}\\
y_{i}+\frac{\lambda\eta_{1}}{2},\quad\text{if }y_{i}\leq Q_{\bf c}({\bf y})_{i}-\frac{\lambda\eta_{1}}{2}\\
Q_{\bf c}({\bf y})_{i},\quad\text{otherwise}\end{cases}

(11)

And for the second type of update we have
\text{prox}_{\eta_{2}\lambda R({\bf x},\cdot)}(\cdot)
becomes:

\displaystyle\text{prox}_{\eta_{2}\lambda R({\bf x},\cdot)}(\bm{\mu})

\displaystyle={\argmin_{{\bf c}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}\left\|{\bf c}-\bm{\mu}\right\|_{2}^{2}+\lambda R({\bf x},{\bf c})\right\}

\displaystyle={\argmin_{{\bf c}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}\left\|{\bf c}-\bm{\mu}\right\|_{2}^{2}+\frac{\lambda}{2}\min_{{\bf z}\in\cal C}\|{\bf z}-{\bf x}\|_{1}\right\}

\displaystyle={\argmin_{{\bf c}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}\left\|{\bf c}-\bm{\mu}\right\|_{2}^{2}+\frac{\lambda}{2}\|Q_{\bf c}({\bf x})-{\bf x}\|_{1}\right\}

(12)

Then,

\displaystyle\text{prox}_{\eta_{2}\lambda R({\bf x},\cdot)}(\bm{\mu})_{j}

\displaystyle={\argmin_{{\bf c}_{j}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}(c_{j}-\mu_{j})^{2}+\frac{\lambda}{2}\sum_{i=1}^{d}|Q_{\bf c}({\bf x})_{i}-x_{i}|\right\}

\displaystyle={\argmin_{{\bf c}_{j}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}(c_{j}-\mu_{j})^{2}+\frac{\lambda}{2}\sum_{i=1}^{d}\mathbbm{1}(Q_{{\bf c}}({\bf x})_{i}=c_{j})|c_{j}-x_{i}|\right\}

We remark that the second term of the optimization problem is hard to solve; in particular we need to know the assignments of
x_{i}
to
c_{j}
. In the algorithm, at each time point
t
, we are given the previous epoch’s assignments. We can utilize that and approximate the optimization problem by assuming
{\bf c}^{t+1}
will be in a neighborhood of
{\bf c}^{t}
. We can take the gradient of
R({\bf x}^{t+1},{\bf c})
at
{\bf c}={\bf c}^{t}
while finding the optimal point. This is also equivalent to optimizing the first order Taylor approximation around
{\bf c}={\bf c}^{t}
.
As a result we have the following optimization problem:

\displaystyle\text{prox}_{\eta_{2}\lambda R({\bf x}^{t+1},\cdot)}(\bm{\mu})_{j}\approx{\argmin_{{\bf c}_{j}\in\mathbb{R}^{m}}}\left\{\frac{1}{2\eta_{2}}(c_{j}-\mu_{j})^{2}+\frac{\lambda}{2}\sum_{i=1}^{d}\mathbbm{1}(Q_{{\bf c}^{t}}({\bf x}^{t+1})_{i}=c^{t}_{j})|c^{t}_{j}-x^{t+1}_{i}|\right.

\displaystyle\left.+(c_{j}-c^{t}_{j})\frac{\lambda}{2}\sum_{i=1}^{d}\mathbbm{1}(Q_{{\bf c}^{t}}({\bf x}^{t+1})_{i}=c^{t}_{j})\frac{\partial|c^{t}_{j}-x^{t+1}_{i}|}{\partial c^{t}_{j}}\right\}

In our implementation, we take
\frac{\partial|c^{t}_{j}-x^{t+1}_{i}|}{\partial c^{t}_{j}}
as
1
if
c^{t}_{j}>x^{t+1}_{i}
,
-1
if
c^{t}_{j}<x^{t+1}_{i}
and
0
otherwise. Now taking the derivative with respect to
c_{j}
and setting it to 0 gives us:

\displaystyle\text{prox}_{\eta_{2}\lambda R({\bf x}^{t+1},\cdot)}(\bm{\mu})_{j}

\displaystyle\approx\mu_{j}-\frac{\lambda\eta_{2}}{2}(\sum_{i=1}^{d}\mathbbm{1}(Q_{{\bf c}^{t}}({\bf x}^{t+1})_{i}=c^{t}_{j})\mathbbm{1}(x^{t+1}_{i}>c^{t}_{j})

\displaystyle\hskip 56.9055pt-\sum_{i=1}^{d}\mathbbm{1}(Q_{{\bf c}^{t}}({\bf x}^{t+1})_{i}=c^{t}_{j})\mathbbm{1}(x^{t+1}_{i}<c^{t}_{j}))

Proximal map pulls the updated centers toward the median of the weights that are assigned to them.

Using
P\rightarrow\infty
.
In the experiments we observed that using
P\rightarrow\infty
, i.e. using hard quantization function produces good results and also simplifies the implementation. The implications of

are as follows:

•

We take
\nabla_{\bf x}f(\widetilde{Q}_{\bf c}({\bf x}))=0
