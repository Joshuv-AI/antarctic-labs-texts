Multi-dimensional c c -almost periodic type functions and applications
M. Kostić

Abstract
. In this paper, we analyze multi-dimensional Bohr ( ℬ , c ) ({\mathcal{B}},c) -almost periodic type functions. The main structural characterizations for the introduced classes of Bohr ( ℬ , c ) ({\mathcal{B}},c) -almost periodic type functions are established. Several applications of our abstract theoretical results to the abstract Volterra integro-differential equations in Banach spaces are provided, as well.

The notion of almost periodicity was introduced by the Danish mathematician H. Bohr

The set consisting of all

The function

As emphasized in

Example 1.1

(cf. also
[

Suppose that a closed linear operator

Under some assumptions,

is a unique classical solution of the abstract Cauchy problem

\displaystyle u_{t}(t,x)=Au(t,x)+F(t,x),\ t\geq 0,\ x\in{\mathbb{R}}^{n};\ u(0,x)=u_{0}(x),

Fix a positive real number

As in the case that

the

-almost periodic behaviour of function

Suppose, for example, that the function

\displaystyle\Bigl|

\displaystyle u_{t_{0}}(x+\tau)-cu_{t_{0}}(x)\Bigr|\leq\int^{t_{0}}_{0}\int_{{\mathbb{R}}^{n}}|F(s,x+\tau-y)-cF(s,x-y)|\cdot\bigl|E\bigl(t_{0},y\bigr)\bigr|\,dy\,ds

\displaystyle\leq\epsilon\int^{t_{0}}_{0}\int_{{\mathbb{R}}^{n}}\bigl|E\bigl(t_{0},y\bigr)\bigr|\,dy\,ds

and corresponding definitions.

Example 1.2
.

In this example, we will observe an interesting feature of the famous d’Alambert formula, which has been used by S. Zaidman
[
22
, Example 5]
in a slightly different context (for almost periodic functions of one real variable).
Let
a>0;
then it is well known that the regular solution of the wave equation
u_{tt}=a^{2}u_{xx}
in domain
\{(x,t):x\in{\mathbb{R}},\ t>0\},
equipped with the initial conditions

is given by the d’Alambert formula

u(x,t)=\frac{1}{2}\bigl[f(x-at)+f(x+at)\bigr]+\frac{1}{2a}\int^{x+at}_{x-at}g(s)\,ds,\quad x\in{\mathbb{R}},\ t>0.

Let us suppose that the function
x\mapsto(f(x),g^{[1]}(x)),

x\in{\mathbb{R}}

is
c
-almost periodic, where

g^{[1]}(\cdot)\equiv\int^{\cdot}_{0}g(s)\,ds.
Then the solution

u(x,t)
can be extended to the whole real line in the time variable and this solution is
c
-almost periodic in
(x,t)\in{\mathbb{R}}^{2}.
To verify this, fix a positive real number
\epsilon>0.
Then there exists a finite real number
l>0
such that any subinterval
I
of
{\mathbb{R}}
of length
l
contains a point
\tau\in I
such that

(1.1)

\displaystyle|f(x+\tau)-cf(x)|+\Bigl|g^{[1]}(x+\tau)-cg^{[1]}(x)\Bigr|<\epsilon,\quad x\in{\mathbb{R}}.

Furthermore, we have (
x,\ t,\ \tau_{1},\ \tau_{2}\in{\mathbb{R}}
):

(1.2)

\displaystyle\begin{split}\Bigl|u\bigl(x&+\tau_{1},t+\tau_{2}\bigr)-cu(x,t)\Bigr|\\
&\leq\frac{1}{2}\Bigl|f\bigl((x-at)+(\tau_{1}-a\tau_{2})\bigr)-cf(x-at)\Bigr|\\
&+\frac{1}{2}\Bigl|f\bigl((x+at)+(\tau_{1}+a\tau_{2})\bigr)-cf([x+at+(\tau_{1}+a\tau_{2})]-(\tau_{1}+a\tau_{2}))\Bigr|\\
&+\frac{1}{2a}\Bigl|g^{[1]}\bigl((x-at)+(\tau_{1}-a\tau_{2})\bigr)-cg^{[1]}(x-at)\Bigr|\\
&+\frac{1}{2a}\Bigl|g^{[1]}\bigl((x+at)-(\tau_{1}-a\tau_{2})\bigr)-cg^{[1]}(x+at)\Bigr|.\end{split}

Let
(t_{1},t_{2})\in{\mathbb{R}}^{2}.
Then the interval
[-t_{1}-at_{2}-(l/2),-t_{1}-at_{2}+(l/2)]
contains the point
\tau^{\prime}
and
the interval
[t_{1}-at_{2}-(l/2),t_{1}-at_{2}+(l/2)]
contains the point
\tau^{\prime\prime}
such that the equation (
1.1

\tau
replaced therein with any of the numbers
\tau^{\prime},\ \tau^{\prime\prime}.
Setting
\tau_{1}:=(\tau^{\prime\prime}-\tau^{\prime})/2

and
\tau_{2}:=(-\tau_{1}-\tau_{2})/2a,
it can be easily shown that

and
|\tau_{2}-t_{2}|\leq l/2a
, so that the final conclusion simply follows from the corresponding definition and (

1.1.
Almost periodic functions on
{\mathbb{R}}^{n}

Suppose that
F:{\mathbb{R}}^{n}\rightarrow X
is a continuous function. Let us recall that
F(\cdot)
is said to be almost periodic if and only if for each
\epsilon>0

there exists
l>0
such that for each
{\bf t}_{0}\in{\mathbb{R}}^{n}
there exists
{\bf\tau}\in B({\bf t}_{0},l)
such that

\displaystyle\bigl\|F({\bf t}+{\bf\tau})-F({\bf t})\bigr\|\leq\epsilon,\quad{\bf t}\in{\mathbb{R}}^{n}.

This is equivalent to saying that for any sequence
({\bf b}_{n})
in
{\mathbb{R}}^{n}
there exists a subsequence
({\bf a}_{n})
of
({\bf b}_{n})

such that
(F(\cdot+{\bf a}_{n}))
converges in
C_{b}({\mathbb{R}}^{n}:X).

The vector space of all almost periodic functions
F:{\mathbb{R}}^{n}\rightarrow X
is denoted by
AP({\mathbb{R}}^{n}:X).
Any almost periodic function
F:{\mathbb{R}}^{n}\rightarrow X
is bounded and
AP({\mathbb{R}}^{n}:X)
is the Banach space equipped with the sup-norm.

Any trigonometric polynomial in
{\mathbb{R}}^{n}
is almost periodic and a continuous function
F(\cdot)
is almost periodic if and only if there exists a sequence of trigonometric polynomials in
{\mathbb{R}}^{n}
which converges uniformly to
F(\cdot);

let us recall that a trigonometric polynomial in
{\mathbb{R}}^{n}
is any linear combination of functions like
{\bf t}\mapsto e^{i\langle{\bf\lambda},{\bf t}\rangle},

{\bf t}\in{\mathbb{R}}^{n},
where
{\bf\lambda}\in{\mathbb{R}}^{n}
and
\langle\cdot,\cdot\rangle
denotes the usual inner product in
{\mathbb{R}}^{n}.

Any almost periodic function
F:{\mathbb{R}}^{n}\rightarrow X
is also uniformly continuous, the mean value

M(F):=\lim_{T\rightarrow+\infty}\frac{1}{(2T)^{n}}\int_{{\bf s}+K_{T}}F({\bf t})\,d{\bf t}

exists and it does not depend on
s\in{\mathbb{R}}^{n};
here,

K_{T}:=\{{\bf t}=(t_{1},t_{2},\cdot\cdot\cdot,t_{n})\in{\mathbb{R}}^{n}:|t_{i}|\leq T\mbox{ for }1\leq i\leq n\}.
We define the Bohr-Fourier coefficient
F_{\lambda}\in X
by

F_{\lambda}:=M\Bigl(e^{-i\langle\lambda,{\bf\cdot}\rangle}F(\cdot)\Bigr),\quad\lambda\in{\mathbb{R}}^{n},

and the Bohr spectrum
\sigma(F)
of
F
by

\sigma(F):=\bigl\{\lambda\in{\mathbb{R}}^{n}:F_{\lambda}\neq 0\bigr\}.

It is well known that
\sigma(F)

is at most a countable set. By
AP_{\Lambda}({\mathbb{R}}^{n}:X)

we denote the set consisting of all almost periodic functions
F:{\mathbb{R}}^{n}\rightarrow X

such that
\sigma(F)\subseteq\Lambda.
As is well known, for every almost periodic function
F\in AP_{\Lambda}({\mathbb{R}}^{n}:X),

we can always find a sequence
(P_{k})
of trigonometric polynomials in
{\mathbb{R}}^{n}
which uniformly converges to
F(\cdot)
on
{\mathbb{R}}^{n}

and satisfies that
\sigma(P_{k})\subseteq\Lambda
for all
k\in{\mathbb{N}};
see e.g.,
[
20
, Chapter 1, Section 2.3]
.

The main aim of this section is to analyze Bohr

denotes a non-empty collection of non-empty subsets of

We will consider the following notion, which can be also analyzed on general topological (semi-)groups; see the references quoted in

Definition 2.1
.

Suppose that
\emptyset\neq I\subseteq{\mathbb{R}}^{n},

F:I\times X\rightarrow Y
is a continuous function and
I+I\subseteq I.
Then we say that:

(i)

-almost periodic if and only if for every
B\in{\mathcal{B}}
and
\epsilon>0

{\bf t}_{0}\in I

{\bf\tau}\in B({\bf t}_{0},l)\cap I
such that

\displaystyle\bigl\|F({\bf t}+{\bf\tau};x)-cF({\bf t};x)\bigr\|_{Y}\leq\epsilon,\quad{\bf t}\in I,\ x\in B.

(ii)

F(\cdot;\cdot)
is
({\mathcal{B}},c)
-uniformly recurrent if and only if for every
B\in{\mathcal{B}}

there exists a sequence
({\bf\tau}_{k})
in
I
such that
\lim_{k\rightarrow+\infty}|{\bf\tau}_{k}|=+\infty
and

\displaystyle\lim_{k\rightarrow+\infty}\sup_{{\bf t}\in I;x\in B}\bigl\|F({\bf t}+{\bf\tau}_{k};x)-cF({\bf t};x)\bigr\|_{Y}=0.

If
X\in{\mathcal{B}},
then it is also said that
F(\cdot;\cdot)
is Bohr
c
-almost periodic (
c
-uniformly recurrent); if
c=1,
then we also say that
F(\cdot;\cdot)
is Bohr
{\mathcal{B}}
-almost periodic (
{\mathcal{B}}
-uniformly recurrent) [Bohr almost periodic (uniformly recurrent)].

Unless stated otherwise, we will assume that

henceforth.

Suppose that
