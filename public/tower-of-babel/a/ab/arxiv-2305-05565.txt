Greedy heuristics and linear relaxations for the random hitting set problem
Gabriel Arpino 1, Daniil Dmitriev 2, Nicolo Grometto 3

Abstract
. Consider the Hitting Set problem where, for a given universe 𝒳 = { 1 ​ … , n } \mathcal{X}=\left\{1\ldots,n\right\} and a collection of subsets 𝒮 1 , … , 𝒮 m \mathcal{S}_{1},\ldots,\mathcal{S}_{m} , one seeks to identify the smallest subset of 𝒳 \mathcal{X} which has nonempty intersection with every element in the collection. We study a probabilistic formulation of this problem, where the underlying subsets are formed by including each element of the universe with probability p p , independently of one another. For large enough values of n n , we rigorously analyse the average case performance of Lovász’s celebrated greedy algorithm [ 10 ] with respect to the chosen input distribution. In addition, we study integrality gaps between linear programming and integer programming solutions of the problem.



1.
Introduction

Hitting Set
is a classical problem in combinatorial optimization which, for a given ground set
\mathcal{X}:=\left\{1,...,n\right\}
of elements and a collection
\mathcal{C}:=\left\{\mathcal{S}_{1},...,\mathcal{S}_{m}\right\}
of subsets of
\mathcal{X}
, asks to identify the smallest set
\mathcal{S}\subseteq\mathcal{X}
that intersects every subset in
\mathcal{C}
.
Hitting Set
arises naturally from the study of
Minimum Vertex Covers on Hypergraphs
(
MVCH
), upon viewing hyperedges as subsets and vertices as elements of the ground set.
In addition, it is dual to the
Set Cover
problem
[
12
]
, which has a rich history in computational complexity theory, including appearing as one of Karp’s 21 NP-complete problems. The aim of the present work is to expand our understanding of the hardness of typical
Hitting Set
instances, by analysing its average-case complexity with respect to a large class of random inputs generated by assigning each element of the ground set to any subset with fixed probability
p
, independently. To further delineate the purpose of this work, let us recall that
Hitting Set
has the following integer programming (
IP
) formulation,

(1.1)

\text{val}\textsubscript{{IP} }:=\begin{cases}\begin{aligned} &\underset{{\boldsymbol{x}}}{\text{minimize}}&&\|{\boldsymbol{x}}\|_{1}\\
&\text{subject to}&&{\boldsymbol{A}}{\boldsymbol{x}}\geq\mathbf{1},\>{\boldsymbol{x}}\in\left\{0,1\right\}^{n},\end{aligned}\end{cases}

where the
i
-th row of
{\boldsymbol{A}}\in\left\{0,1\right\}^{m\times n}
provides a binary encoding of the membership of the elements of
\mathcal{X}
in the set
\mathcal{S}_{i}
and
\mathbf{1}:=(1,\ldots,1)\in\mathbb{R}^{m}
. With the vertex cover formulation of the problem at hand, we note that
{\boldsymbol{A}}
consists of the incidence matrix of the underlying hypergraph.
In particular, the first constraint in (
1.1
) ensures that each set in
\mathcal{C}
is hit by a prescribed candidate solution vector. A natural convex relaxation is obtained by allowing fractional solutions, and may be expressed as the following linear program (
LP
),

(1.2)

\text{val}\textsubscript{{LP} }:=\begin{cases}\begin{aligned} &\underset{{\boldsymbol{x}}}{\text{minimize}}&&\|{\boldsymbol{x}}\|_{1}\\
&\text{subject to}&&{\boldsymbol{A}}{\boldsymbol{x}}\geq\mathbf{1},\>{\boldsymbol{x}}\in[0,1]^{n}.\end{aligned}\end{cases}

Whilst clearly
\text{val}\textsubscript{{LP} }\leq\text{val}\textsubscript{{IP} }
, tightness need not hold in general. In fact, for
m=n
and
{\boldsymbol{A}}\in\left\{0,1\right\}^{n\times n}
chosen such that each row and column contains exactly
k
ones, for some fixed
1<k<n
, an optimal solution is provided by
{\boldsymbol{x}}^{*}_{\texttt{LP}}=\left(1/k,...,1/k\right)
, which is not integral, thus leading to a strictly smaller objective whenever
n/k
is not an integer. This evidences the existence of a significant
integrality gap
, quantified by the ratio
\text{val}\textsubscript{{IP} }/\text{val}\textsubscript{{LP} }
. In
[
10
]
, Lovász proved an essentially optimal worst-case upper bound on the
Hitting Set
multiplicative integrality gap of
1+\log d_{\mathtt{max}}
, where
d_{\mathtt{max}}
corresponds to the maximum degree in the underlying hypergraph.
This is obtained by analysing the
Greedy
algorithm (Algorithm
1
), which constructs a vertex cover by sequentially adding vertices with the highest degree amongst the uncovered edges, and will be discussed in more detail in the next sections. However, in many natural examples, the maximum degree
d_{\mathtt{max}}
grows with the number of vertices in the hypergraph, thus leading to progressively worse bounds for increasingly large hypergraphs. Besides being arguably the most natural candidate for solving
Hitting Set
, the greedy algorithm has been shown to be essentially the best possible polynomial time approximation algorithm
[
13
]
for the worst-case instances of this classical problem. In particular, the greedy algorithm has an approximation ratio of
O(\log m)
, thus finding coverings that may be at most
C\log m
times as large as the minimum one, for a large enough constant
C>0
.

Despite extensive work conducted on
Hitting Set
in the last decades, a gap remains in our understanding of the typical performance of linear programming and the greedy algorithm on random problem instances. We hence pose the following questions:

(1)

For which regimes of
m,n,p
are there (multiplicative) integrality gaps in random instances of
Hitting Set
?

(2)

What is the average case performance of the greedy algorithm with respect to a chosen input distribution?

In the present work, we provide answers to the above questions

with high probability
(w.h.p.) in a non-asymptotic sense, in the setting where the cardinality
n
of the ground set
\mathcal{X}

is large but finite. We will prove the absence of integrality gaps in a wide regime of
n,m,p
, by conducting an average case analysis of an algorithm that outputs integral covers of matching size to the fractional ones. In addition, a rigorous analysis of the greedy routine will follow by a straightforward reduction. The forthcoming results are valid under the conditions listed below, which will be assumed to hold throughout.

Assumption 1
.

We assume that

(1.1)

Each element
j\in\mathcal{X}
is assigned to any subset
\mathcal{S}_{i}
,
i\in[m]
with probability
p\equiv p(n)
, independently. That is,
{\boldsymbol{A}}\in\{0,1\}^{m\times n}
is such that
A_{ij}\overset{\text{iid}}{\sim}\mathrm{Bernoulli}(p)
;

(1.2)

n
is intended to be large but finite;

(1.3)

m\equiv m(n)=\mathrm{poly}(n)
, i.e.
\exists c,C>0
, such that
cn^{c}\leq m\leq Cn^{C}
for
n
large enough;

(1.4)

There exist
\delta\in(0,1)
, such that
p\equiv p(n)
satisfies
1/n^{\delta}\leq p\leq 1/2
, for all
n
large enough.

Note that in Assumption
1.3
, the upper bound is chosen to avoid trivial solutions w.h.p., which e.g. arise in the setting where the number of sets grows exponentially in the cardinality of
\mathcal{X}
. In addition, Assumption
1.4
is by no means restrictive, since one can show that for
m=\text{poly}(n)
and
np\ll\log n
, we have that w.h.p.,
{\boldsymbol{A}}
contains an all-zero row, i.e. no feasible solution for
IP
. The requirement
p\leq 1/2
is chosen for technical convenience and can be relaxed to any constant
p
, encompassing the regime in
[
8
]
.

Our contributions stem from the study of the size of the inclusion sets
I_{j}:=\left\{i\in[m]\>:\>j\in\mathcal{S}_{i}\right\}
, for
j\in[n]
, which in the
MVCH
formulation of the problem at hand correspond to the degrees of vertices in the underlying hypergraph. The key quantity under scrutiny is the average inclusion set size, that is
{{\mathbb{E}}}|I_{j}|=mp
, for all
j
, under the present distributional assumptions. This quantity exhibits two separate regimes of interest, referred to as the
sparse
,
mp\ll\log{n}
, and
dense
,
mp\gg\log{n}

d_{\mathtt{max}}:=\max_{j\in[n]}|I_{j}|
. We characterize the integrality gap behaviour up to multiplicative constants and analyse Lovász’s
Greedy
algorithm
[
10
]
in these two regimes w.h.p as
n\to\infty
. We do this by proving the success of a simple greedy heuristic, the
BlockGreedy
algorithm (Algorithm
2
). Throughout, we use the notation
\text{val}_{\mathtt{Gr}}

Alg

2.
Notation and conventions

For integers
k\in\mathbb{N}
, we write
[k]:=\left\{1,...,k\right\}
. We denote vectors, matrices by bold-faced Roman letters
\mathbf{x},{\boldsymbol{A}}\in\mathbb{R}^{k},\mathbb{R}^{k\times k}
, respectively, for some
k\in\mathbb{N}
. Define the
inclusion set
of an element, or node,
j\in[n]
as
I_{j}=\left\{i\in[m]:j\in\mathcal{S}_{i}\right\}
. We denote the
\ell_{1}
norm of the
j
-th column of
{\boldsymbol{A}}
by
X_{j}
,
j\in[n]
, noting that
X_{j}=|I_{j}|
and
X_{1},\ldots X_{n}\overset{\text{iid}}{\sim}\mathrm{Binomial}(m,p)
. In addition, we let
d_{\mathtt{max}}\equiv d_{\mathtt{max}}(X_{1},\ldots,X_{n}):=\max_{i\in[n]}X_{i}
. We use
{{\mathbb{E}}},\text{Var}
to denote expectation and variance, respectively. By
\lesssim
,
\gtrsim
we denote inequalities up to constants. We let
A\sim B
denote that
A\lesssim B\lesssim A
for large enough
n
. We let
\log
denote the natural logarithm.

For possibly random functions
f(n),g(n)
, we let
\{f\lesssim g\}
denote a sequence of events
\{f(n)\leq Ag(n)\}
for some constant
A>0
independent of
n
. Consequently,
{\mathbb{P}}(f\lesssim g)
is viewed as a function of
n
. The notation for other inequalities is defined analogously.
We say that a sequence of events
\left\{A_{n}\right\}
holds
with high probability
(w.h.p.) with respect to a probability measure
\mathbb{P}
if there exists a constant
c>0
, independent of
n
, such that
\mathbb{P}(A_{n})\geq 1-n^{-c}
, for large enough values of
n
.

3.
Related Work

Perhaps the most well-known algorithm for solving
Hitting Set
, or equivalently
MVCH
, is the greedy algorithm of Lovász
[
10
]
, with runtime complexity
O(mn^{2})
. This algorithm, which constructs a cover by sequentially adding elements of the ground set which hit the largest number of remaining subsets, was initially studied by Lovász
[
10
]
and Johnson
[
9
]
independently, for deterministic hypergraphs. Lovász analyses the greedy algorithm to obtain an upper bound on the
Hitting Set
integrality gap of
1+\log d_{\mathtt{max}}
. However, for many natural examples, the maximum degree grows with the number of vertices in the hypergraph, leading to progressively worse bounds as the size increases. Slavik
[
13
]
developed the tightest known analysis, showing that the greedy algorithm is essentially the best-possible polynomial-time approximation algorithm for set cover, with an approximation ratio of
O(\log m)
.

Nevertheless, much less is known about the typical performance of polynomial-time algorithms on random instances of
Hitting Set
. Closing this gap is important from a theoretical standpoint and for applications in combinatorial inference. A prime example of this is found in
group testing
, a classical inference problem where one aims to identify a small subset of defective items within a large population by conducting the smallest number of pooled tests, with applications ranging from the analysis of communication protocols
[
6
]
to DNA sequencing
[
4
]
and search problems
[
3
]
. In
[
8
]
, Iliopulos and Zadik consider the smallest hitting set as an estimator in the setting of the group testing problem, referring to it as the
Smallest Satisfying Set
estimator. In particular, they provide extensive empirical evidence supporting the claim that the class of instances of the random hitting set problem induced by non-adaptive group testing is tractably solvable by computers.

The analysis of a random instance of
Hitting Set
appears in the work of Mézard and Tarzia and relies on nonrigorous techniques from statistical physics
[
11
]
. This work considers regular uniform hypergraphs, where the degree of vertices and the size of edges are fixed and assumed to be constant. Depending on these values, they showed phase transitions between the replica symmetry, 1-replica symmetry breaking, and full replica symmetry breaking phases, which characterize the complexity of the optimization landscape for this problem in the average case setting.

Another instance was studied by Telelis and Zissimopoulos
[
14
]
in the setting of random Bernoulli hypergraphs, where elements belong to subsets independently with
fixed
probability
p\in(0,1)
. Their analysis concerns the asymptotic regime where the size
n
of the ground set scales to infinity. In this setting, they study the average-case performance of a simple deterministic algorithm which approximates random
Hitting Set
within an additive error term of order at most
\log m
almost everywhere. This gives an improvement over Lovász’s argument in
[
10
]
, since in this setting
d_{\mathtt{max}}
is at most of order
m
. However, the analysis in
[
14
]
does not capture the case of sparse hypergraphs obtained for
p\to 0
as
n\to\infty
and, more broadly, any regime where
p
scales with the size of the ground set
n
. The analysis in
[
14
]
also does not prove guarantees for the
Greedy
algorithm in the chosen parameter regime.

For completeness, we also bring to the reader’s attention a more recent line of work
[
1
,
2
]
, where the authors obtain bounds on (additive) integrality gaps between the value of a random integer program
\max{\boldsymbol{c}}^{T}{\boldsymbol{x}},{\boldsymbol{A}}{\boldsymbol{x}}\leq{\boldsymbol{b}},{\boldsymbol{x}}\in\left\{0,1\right\}^{n}
with
m
constraints and that of its linear programming relaxation for a wide range of distributions on
({\boldsymbol{A}},{\boldsymbol{b}},{\boldsymbol{c}})
, holding w.h.p. as
n\rightarrow\infty
. These include the case where the entries of
{\boldsymbol{A}}
are uniformly distributed on an integer interval consisting of at least three elements and where the columns of
{\boldsymbol{A}}
are distributed according to an isotropic logconcave distribution. However, these fail to capture the setting where
{\boldsymbol{A}}
is sparse with entries in
\left\{0,1\right\}
, which is of interest for
Hitting Set
.

4.
Bounds on
val
LP

and
val
IP

The aim of this section is to obtain preliminary bounds on
\text{val}\textsubscript{{LP} },\text{val}\textsubscript{{IP} }
, starting from the following deterministic lower bound on
val
LP

, which holds across all regimes of
m,n,p
.

Lemma 1
.

We have that

\text{val}\textsubscript{{LP} }\geq\frac{m}{d_{\mathtt{max}}}.

Proof.

Let
{\boldsymbol{x}}^{*}_{\texttt{LP}}=({\boldsymbol{x}}_{1}^{*},{\boldsymbol{x}}_{2}^{*},\ldots,{\boldsymbol{x}}_{m}^{*})
be an optimal solution for (
1.2
). Since
{\boldsymbol{A}}{\boldsymbol{x}}^{*}_{\texttt{LP}}\geq\mathbf{1}
entrywise, by summing all entries we obtain that

m\leq\sum_{i}{\boldsymbol{x}}^{*}_{i}X_{i}\leq d_{\mathtt{max}}\sum_{i}{\boldsymbol{x}}^{*}_{i}=d_{\mathtt{max}}\text{val}\textsubscript{{LP} }.

which upon rearranging yields the desired result.
∎

In addition to the above, we have the following elementary upper bound on
val
LP

, which holds both in the sparse and dense regime.

Lemma 2
.

There exists
c>0
, independent of
n
, such that

{\mathbb{P}}\left(\text{val}\textsubscript{{LP} }\lesssim\frac{1}{p}\right)\geq 1-\exp\left(-cn^{1-\delta}\right).

This also implies that
{\mathbb{P}}(\texttt{IP}\text{ is feasible})\geq 1-\exp\left(-cn^{1-\delta}\right).

Proof.

Consider the candidate feasible solution
\hat{{\boldsymbol{x}}}:=\frac{1}{\tilde{C}np}\mathbf{1}
, for some constant
0<\tilde{C}<1
. The following results from applying a union bound over constraints and the standard Chernoff bound.

\displaystyle{\mathbb{P}}\left(\hat{{\boldsymbol{x}}}\>\text{not feasible}\right)

\displaystyle={\mathbb{P}}\left(\exists i\in[m]:\left({\boldsymbol{A}}\hat{{\boldsymbol{x}}}\right)_{i}<1\right)

\displaystyle\leq m{\mathbb{P}}\left(\text{Bin}(n,p)<\tilde{C}np\right)

\displaystyle\leq n^{C}\exp\left(-\frac{(1-\tilde{C})^{2}np}{2}\right)

\displaystyle\leq\exp\left(-cn^{1-\delta}\right).

The desired conclusion follows by considering the complementary event to the one above and noting that
\left\|\hat{{\boldsymbol{x}}}\right\|_{1}\sim 1/p
. Note that the event
\{\hat{{\boldsymbol{x}}}\text{ is feasible for }\texttt{LP}\}
implies the event
\{\texttt{IP}\text{ is feasible}\}
.
∎

Lemma
1
clearly implies that
\text{val}\textsubscript{{IP} }\geq m/d_{\mathtt{max}}
. However, when
mp\gg\log n
, this lower bound is not precise. Indeed, we will apply the first moment method to prove a tighter lower bound on
val
IP

. We first recall the following properties of the Lambert
W
function, which consists of the solution to the equation
ye^{y}=x
, for
x\geq 0
.

Lemma 3

(Lambert
W
function,
[
7
]
)
.

For any
x\geq e
, there holds that

(4.1)

\displaystyle\log x-\log\log x+\frac{\log\log x}{2\log x}\leq W_{0}(x)\leq\log x-\log\log x+\frac{e}{e-1}\frac{\log\log x}{\log x}.

In particular,

(4.2)

\displaystyle W_{0}(x)=\log x-\log\log x+o(1),\quad\text{as}\quad x\rightarrow\infty.

In addition, for any
x\geq 1/e
, the following identity is satisfied

(4.3)

\displaystyle W_{0}(x)=\log\frac{x}{W_{0}(x)}.

We now provide a tighter lower bound for
val
IP

in the regime
mp\gg\log{n}
through the first moment method.

Lemma 4
.

If
mp\gg\log n
, we have that, for any
D\geq 1
, for
n
large enough,

{\mathbb{P}}\left(\text{val}\textsubscript{{IP} }\gtrsim\frac{1}{p}\log\left(\frac{mp}{\log n}\right)\right)\geq 1-n^{-D}.

Proof of Lemma
4
.

Fix
D\geq 1
.
Let
Z_{k}:=\lvert\left\{{\boldsymbol{x}}\in\left\{0,1\right\}^{m}:{\boldsymbol{A}}{\boldsymbol{x}}\geq\mathbf{1},\|{\boldsymbol{x}}\|_{1}=k\right\}\rvert
be the number of feasible solutions of norm exactly
k
. Clearly,
Z_{k}\leq Z_{k+1}
for any
k\geq 0
. We also have that

\displaystyle\mathbb{E}Z_{k}

\displaystyle=\sum_{\|{\boldsymbol{x}}\|=k}{\mathbb{P}}\left({({\boldsymbol{A}}{\boldsymbol{x}})_{i}\geq 1,\forall i\in[m]}\right)=\binom{n}{k}\left(1-(1-p)^{k}\right)^{m}.

We will now show that for
k\ll\frac{1}{p}\log\left(\frac{mp}{\log n}\right)
, we have
\mathbb{E}Z_{k}\leq n^{-D}
. Using that
p\leq 1/2
from Assumption
1.4
and that for
x\in(0,\frac{1}{2})
, we have
(1-x)^{y}\geq e^{-2xy}
, we can bound

\displaystyle\mathbb{E}Z_{k}

\displaystyle=\binom{n}{k}(1-(1-p)^{k})^{m}\leq n^{k}\left(1-e^{-2pk}\right)^{m}

\displaystyle\leq n^{k}e^{-me^{-2pk}}=\exp\left\{k\log n-me^{-2pk}\right\}.

Therefore,
\mathbb{E}Z_{k}\leq n^{-D}
will follow from

(4.4)

2pke^{2pk}\leq-2Dpe^{2pk}+\frac{2mp}{\log n}.

Since
k\ll\frac{1}{p}\log\left(\frac{mp}{\log n}\right)
, we also have that
k\leq k_{\ast}\coloneqq\frac{1}{2p}W_{0}\left(\frac{mp}{D\log n}\right)
for
n
large enough. For
k=k_{\ast}
,
the left hand side of (
4.4
) is equal to
\frac{mp}{D\log n}
, while the right hand side is lower bounded by
\frac{mp}{\log n}
. Since
D\geq 1
, we recover that
\mathbb{E}Z_{k}\leq n^{-D}
. Note that for
n
large enough,
\text{val}\textsubscript{{IP} }\ll\frac{1}{p}\log\frac{mp}{\log n}
implies that
Z_{k_{\ast}}>0
. Therefore, applying Markov’s inequality, we get that

(4.5)

\displaystyle{\mathbb{P}}\left(\text{val}\textsubscript{{IP} }\ll\frac{1}{p}\log\left(\frac{mp}{\log n}\right)\right)\leq{\mathbb{P}}\left(Z_{k_{\ast}}>0\right)\leq\mathbb{E}Z_{k_{\ast}}\leq n^{-D},

and the proof follows by considering the complementary events. Note that using similar derivations, one can also show that for
k^{\ast}\coloneqq\frac{1}{p}\log\left(\frac{1}{\delta}\frac{mp}{\log n}\right)
, where
\delta
is defined in Assumption
1.4
, we have
\mathbb{E}Z_{k^{\ast}}\geq 1
.
∎

5.
Analysis of
d_{\mathtt{max}}

In this section we will first estimate the size of
{{\mathbb{E}}}d_{\mathtt{max}}
and subsequently show that w.h.p.
d_{\mathtt{max}}\lesssim{{\mathbb{E}}}d_{\mathtt{max}}
, which suffices for the purposes of this work. For additional arguments concerning concentration of
d_{\mathtt{max}}
around its mean, we refer the reader to Lemmas
11
,
10
.

In order to deal with the more delicate sparse regime where
mp\ll\log n
, we state the following technical lemma, whose proof is presented in Appendix B.

Lemma 5
.

For
mp\ll\log{n}
,
\varepsilon>0
, and
n
large enough, we have

{\mathbb{P}}\left(\mathrm{Bin}(m,p)=\left\lceil{\frac{\varepsilon}{8}\frac{\log{n}}{\log\left(\log n/mp\right)}}\right\rceil\right)\geq n^{-\varepsilon}.

We proceed to estimate
\mathbb{E}d_{\mathtt{max}}
, by differentiating the sparse and dense regimes for the average inclusion set size. The following lemma characterizes the two distinct regimes of the maximum inclusion set size
\max_{j\in[n]}|I_{j}|
.

Lemma 6

(Maximum of Binomials)
.

Let
X_{1},\ldots,X_{n}\overset{\underset{\mathrm{iid}}{}}{\sim}Bin(m,p)
. Under the conditions in Assumption
1
, it holds that

\displaystyle\mathbb{E}d_{\mathtt{max}}=\mathbb{E}\max_{i\in[n]}X_{i}\sim\begin{cases}\frac{\log{n}}{\log\left(\log n/mp\right)}&\text{, if }mp\ll\log{n},\\
mp&\text{, if }mp\gtrsim\log{n}.\end{cases}

Proof.

For ease of notation, let us define
b_{n}:=\frac{\log n}{mp},\>b_{n}^{*}:=\frac{1}{e}\left(b_{n}-1\right)
,
g_{n}:=\frac{\log{n}}{\log\left(\log n/mp\right)}
. We begin by proving the desired upper bound. By Jensen’s inequality and bounding the maximum of positive values by their sum, for any
\lambda>0
, we obtain

\displaystyle\mathbb{E}\max_{i\in[n]}X_{i}

\displaystyle\leq\frac{1}{\lambda}\log\mathbb{E}\exp\left(\lambda\max_{i\in[n]}X_{i}\right)=\frac{1}{\lambda}\log\mathbb{E}\left(\max_{i\in[n]}\exp\left(\lambda X_{i}\right)\right)\leq\frac{1}{\lambda}\log\sum_{i\in[n]}\mathbb{E}\exp(\lambda X_{i}).

Finally, computing the moment generating function of binomial random variables, together with the inequality
1-x\leq e^{-x}
yields

\displaystyle\mathbb{E}\max_{i\in[n]}X_{i}=\frac{\log{n}+m\log{(1-p(1-e^{\lambda}))}}{\lambda}\leq\frac{\log{n}-mp(1-e^{\lambda})}{\lambda}.

In the regime where
mp\gtrsim\log n
, we may choose
\lambda>0
arbitrary, independent of
n
, from which it immediately follows that
{{\mathbb{E}}}\max_{i\in[n]}X_{i}\lesssim mp
.

For
mp\ll\log n
, we proceed by differentiating the last line in the above display and setting the resulting expression to zero. From this, we may choose
\lambda
as the solution of the following.

e^{\lambda-1}\left(\lambda-1\right)=b_{n}^{*}

Under the present assumptions, this is expressed in terms of the Lambert W function as
\lambda=1+W_{0}(b_{n}^{*})
, so that by (
4.3
), we obtain

\displaystyle{{\mathbb{E}}}\max_{i\in[n]}X_{i}\leq\frac{\log n\left(1-\frac{1}{b_{n}}+\frac{b_{n}^{*}}{b_{n}}\frac{e}{W_{0}(b_{n}^{*})}\right)}{1+W_{0}(b_{n}^{*})}\sim g_{n}.

In the dense
mp\gtrsim\log{n}
regime, a matching lower bound is easily obtained by noting that
{{\mathbb{E}}}\max_{i\in[n]}X_{i}\geq{{\mathbb{E}}}X_{1}=mp
.

To deal with the sparse regime, let
\tau=1/16
. From Markov’s inequality,

\displaystyle\mathbb{E}\max_{i\in[n]}X_{i}

\displaystyle\geq\tau g_{n}{\mathbb{P}}\left(\max_{i\in[n]}X_{i}=\lceil\tau g_{n}\rceil\right)=\tau g_{n}\left(1-\left(1-{\mathbb{P}}\left(X_{1}=\lceil\tau g_{n}\rceil\right)\right)^{n}\right).

Hence, applying Lemma
5
, for
n
large enough,

\displaystyle\mathbb{E}\max_{i\in[n]}X_{i}\geq\tau g_{n}\left(1-\left(1-n^{-1/2}\right)^{n}\right)\geq(\tau/2)g_{n},

thus providing a matching lower bound for the sparse regime.
∎

Remark 1
.

We note that in the sparse regime
mp\ll\log n
, there holds that
mp\ll\mathbb{E}d_{\mathtt{max}}\ll\log n
, whereas in the dense regime
mp\gg\log n
, we have that
mp\sim\mathbb{E}d_{\mathtt{max}}\gg\log n
. In the threshold regime
mp\sim\log n
, the average and maximum of
X_{i}
’s become of the same order, that is
mp\sim\mathbb{E}d_{\mathtt{max}}\sim\log n
. The smooth transition is visible from the proof by noting that in this regime,
b_{n},b_{n}^{*},W_{0}(b_{n}^{*})\sim 1
.

We conclude this section by bounding
d_{\mathtt{max}}
by its expectation from above, up to multiplicative constants w.h.p.. Whilst this one sided result suffices for the forthcoming analysis, we expect a matching lower bound to hold as well. Additional insights into the concentration of
d_{\mathtt{max}}
may be found in Lemmas
10
,
11
, in Appendix A.

Lemma 7
.

Let
X_{1},\ldots,X_{n}\overset{\underset{\mathrm{iid}}{}}{\sim}Bin(m,p)
. Then, there exist constants
c,\tilde{c}>0
, independent of
n
, such that

{\mathbb{P}}\left(\max_{i\in[n]}X_{i}\geq c\cdot{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)\leq\frac{1}{n^{\tilde{c}}}

That is,
\max_{i\in[n]}X_{i}\lesssim{{\mathbb{E}}}\max_{i\in[n]}X_{i}
w.h.p..

Proof.

Let us consider the sparse and dense regimes separately.

In the dense regime for
mp\gtrsim\log n
, there exist constants
c_{1},c_{2},c_{3}>0
such that
c_{1}mp\leq{{\mathbb{E}}}\max_{i\in[n]}X_{i}\leq c_{2}mp
, as argued in Lemma
6
, and
mp\geq c_{3}\log n
. We apply the union and Chernoff bounds as in Lemma
9
to obtain, for any
t\geq 1/c_{1}
,

\displaystyle{\mathbb{P}}\left(\max_{i\in[n]}X_{i}\geq t\cdot{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)

\displaystyle\leq n{\mathbb{P}}\left(X_{1}\geq tc_{1}mp\right)

\displaystyle\leq n\exp\left(-\frac{(tc_{1}-1)^{2}mp}{1+tc_{1}}\right)

\displaystyle\leq n\exp\left(-\frac{c_{3}(tc_{1}-1)^{2}\log n}{1+tc_{1}}\right).

It now suffices to choose
t
as a function of
c_{1},c_{3}
such that
\frac{c_{3}(tc_{1}-1)^{2}}{1+tc_{1}}>1
. By rearranging and solving the resulting quadratic equation, it follows immediately that any
t>\frac{1}{c_{1}}+\frac{1+\sqrt{1+8c_{3}}}{2c_{3}c_{1}}>\frac{1}{c_{1}}
suffices. Hence, there exist universal constants
c,\tilde{c}
, such that the desired conclusion holds.

We now consider the sparse regime
mp\ll\log n
, where by Lemma
6
there exists
c_{4}>0
such that
mp\leq c_{4}\log n/\log\left(\frac{\log n}{\log mp}\right)
. Notice that for any
\lambda>0
,
\max_{i\in[n]}X_{i}\leq\frac{1}{\lambda}\log\sum_{i=1}^{n}e^{\lambda X_{i}}
. We apply Markov’s inequality to obtain, for any
t>0
,

\displaystyle{\mathbb{P}}\left(\max_{i\in[n]}X_{i}\geq t\cdot{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)

\displaystyle\leq{\mathbb{P}}\left(\sum_{i=i}^{n}e^{\lambda X_{i}}\geq e^{\lambda t{{\mathbb{E}}}\max_{i\in[n]}X_{i}}\right)

\displaystyle\leq\frac{n{{\mathbb{E}}}e^{\lambda X_{1}}}{\exp\left(\lambda t\>{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)}

\displaystyle=\frac{n\left(1-p+pe^{\lambda}\right)^{m}}{\exp\left(\lambda t\>{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)}

\displaystyle\leq\exp\left(\log n+mp\left(e^{\lambda}-1\right)-\frac{\lambda t\>c_{4}\log n}{\log\left(\frac{\log n}{mp}\right)}\right),

where we used that
1+x<e^{x}
to obtain the last inequality. Finally, by choosing
t=3/c_{4}
and
\lambda=\log\left(\log n/mp\right)
, we obtain

\displaystyle{\mathbb{P}}\left(\max_{i\in[n]}X_{i}\geq\frac{3}{c_{4}}\cdot{{\mathbb{E}}}\max_{i\in[n]}X_{i}\right)\leq\frac{1}{n}.

∎

The aim of the present section is to conduct a rigorous analysis of the standard
Greedy
algorithm for the hitting set problem, within the prescribed Bernoulli random setting. In particular, we show that this routine succeeds at constructing hitting sets of optimal size w.h.p., as in the results of Section
4
, up to multiplicative constants. This is done by first analysing a variation of the greedy heuristic, and subsequently proceeding by a reduction argument.

The core principle of
Greedy
is to construct a feasible solution in steps, by sequentially adding to the candidate solution an element which hits the largest number of remaining sets. In the chosen setting, where elements are added to sets with equal probability and independent of each other, we have precise estimates on the number of subsets hit by an element which is
picked first
. In fact, the size of this set is given by the maximum of independent Binomial random variables, which was analysed in Section
5
. However, this very first step introduces nontrivial dependencies amongst the remaining matrix columns and significantly complicates keeping track of the marginal gains of each subsequent element addition to the candidate solution.

In order to circumvent this issue, we introduce a modified greedy routine, which we refer to as
BlockGreedy
algorithm, where the elements of the ground set
[n]
are split into separate sets, which we call blocks. At the
t
-th iteration, the algorithm picks the largest column from the first
t
blocks only. By choosing the number of blocks appropriately, one is guaranteed to find enough independent columns at each iteration, whilst finding a solution of optimal size. Also, the additional block constraint allows us to analyse how many subsets are hit by each chosen element, not just the first one, by still relying on fundamental properties of independent Binomial random variables.

BlockGreedy
is detailed in Algorithm
2
, whilst informally, it works as follows.

(1)

Let
K
be the size of the solution (suggested by theoretical analysis);

(2)

Uniformly at random split
n
columns into
K
blocks with
n/K
columns per block;

(3)

Start with an empty set of possible choices of columns;

(4)

At the
t
-th iteration, first add the columns
from the
t
-th block (Step
6
).
Then, perform one greedy step on the current
set of possible choices (Step
7
);

(5)

If after
K
iterations of the algorithm, some subsets remain uncovered, we use a trivial covering, i.e., covering each subset by a separate column. This can be done with high probability.

Let
v_{t}
be the element which is picked at the
t

,

be the number of new subsets that are hit by
v_{t}
,
and

t

In order to analyse how many elements

has picked, we will introduce the sequence

f_{1},f_{2},\ldots,f_{s}
, with

, such that the following holds:

(1)

for each

, we have

, w.h.p.;

(2)

F_{s}=m
;

(3)

if

, then

, otherwise,
s\lesssim\text{val}\textsubscript{{IP} }
.

The first and second properties ensure that

picks at most
s

and the last property gives optimal bounds on

One way to guarantee that

succeeds is to prove that among the choices of

,
there was an element

which hits at least
f_{t}

it is enough to look for

in

Note that unless

, we have that

since each subset is hit by at least one element w.h.p..
Therefore, it will be enough to find a sequence

.
This allows us to reduce the problem of proving the effectiveness of

new subsets.
This boils down to computing

Lemma 8
.

Let
\varepsilon>0
. Consider the following choices of
f_{1},f_{2},\ldots
:

\displaystyle(i)\quad\text{if }mp\lesssim\log n,\text{ for some constants }\tau>0\text{ and }1<\alpha<\beta,

\displaystyle f_{t}=\left\lceil\left(\alpha/\beta\right)^{k}\tau\mathbb{E}d_{\mathtt{max}}\right\rceil\qquad\text{where }k\text{ is such that}\quad\beta^{-k-1}m<m-F_{t-1}\leq\beta^{-k}m;

\displaystyle(ii)\quad\text{if }mp\gg\log n,\ \text{and }\ \log mp\ll\log n,

\displaystyle f_{t}=\left\lceil mp(1-p)^{t-1}\right\rceil\quad\text{if}\quad t\leq t^{*}\coloneqq\left\lceil\frac{1}{p}\log\left(\frac{mp}{\log n}\right)\right\rceil,

\displaystyle f_{t}=\tilde{f}_{t-t^{*}},\quad\text{otherwise, where }\tilde{f}_{t}\text{ is the sequence from the case }mp\lesssim\log n;

\displaystyle(iii)\quad\text{otherwise, i.e., when }\log mp\gtrsim\log n,

\displaystyle f_{t}=\left\lceil mp(1-p)^{t-1}\right\rceil.

Then, there exists
K
, such that

(6.1)

\displaystyle(i)\qquad

\displaystyle F_{K}\geq m-K;

\displaystyle(ii)\qquad

\displaystyle\text{if }mp\lesssim\log n,

\displaystyle\text{ then }K\sim\text{val}\textsubscript{{LP} };

\displaystyle\text{if }mp\gg\log n,

\displaystyle\text{ then }K\sim\text{val}\textsubscript{{IP} }.

Furthermore, for this sequence
f_{t}
(which depends on
\varepsilon
), for any
t\leq K
,

(6.2)

{\mathbb{P}}(\mathrm{Bin}(m-F_{t-1},p)\geq f_{t})\geq n^{-\varepsilon}.

Note that the implicit constants in the statements
K\sim\text{val}\textsubscript{{LP} }
or
K\sim\text{val}\textsubscript{{IP} }
depend on
\varepsilon
.

This lemma highlights the crucial dependency of the problem
on the relationship between the average degree,
mp
, and
\log n
. We comment on the intuition behind the proof, which can be found in Appendix C. As was shown in Section
5
,
\mathbb{E}d_{\mathtt{max}}
grows identically to the expected value whenever the expected value is large (
mp\gtrsim\log n
) and is away from it otherwise. This is the core property for the proof.

When
mp\sim n^{\gamma}
for some
\gamma>0
, the analysis is straightforward, as just picking random columns is good enough (i.e., picking
f_{t}=\left\lceil mp(1-p)^{t-1}\right\rceil
). More challenging cases arise when the average degree is close to
\log n
, e.g.
mp=\log^{2}n
(dense) ,
mp=\log n
, or
mp=\log n/\log\log n
(sparse). Here we need to carefully track how the maximum degree changes. We look for an element which i) covers a large number of subsets, i.e., close to the expected maximum number,
\mathbb{E}d_{\mathtt{max}}
and ii) can be found with large enough probability. The second property is important for the reduction to the standard
Greedy
algorithm, whose direct analysis presents substantial difficulties, and is done later in this section. The quantity
\mathbb{E}d_{\mathtt{max}}
is sensitive to
mp
whenever the latter is close to
\log{n}
. Hence, we need to adjust which element we look for accordingly. This is done by setting
f_{t}=\left\lceil\left(\alpha/\beta\right)^{k}\tau\mathbb{E}d_{\mathtt{max}}\right\rceil
and increasing the parameter
k
as the number of remaining rows,
m-F_{t}
, decreases.

For example, consider the case
mp=\log^{2}n
. First, we can only pick a random element, since it will be as good as the maximal element. However, during the execution of the algorithm, the problem becomes more sparse, and if we continue to pick random elements, we will construct a suboptimal solution. Therefore, once we are in the regime
mp\sim\log n
, we start to gradually increase how much the newly picked element will cover, with respect to a random element.

It is now straightforward to prove the following theorem, which makes rigorous the statements in Section
1
.

Theorem 1
.

Under Assumption
1
, we have that

(6.3)

\displaystyle(i)\text{ if }\ mp\lesssim\log n\ \text{then, for any }\varepsilon>0\text{ and }n\text{ large enough},

\displaystyle{\displaystyle\mathbb{P}}\left(\text{val}\textsubscript{{Alg}}\lesssim\frac{m}{\mathbb{E}d_{\mathtt{max}}}\right)\geq 1-\exp\left(-n^{1-\delta-\varepsilon}\right);

\displaystyle(ii)\text{ if }\ mp\gg\log n,\text{ then, for any }\varepsilon>0\text{ and }n\text{ large enough},

\displaystyle{\displaystyle\mathbb{P}}\left(\text{val}\textsubscript{{Alg}}\lesssim\frac{1}{p}\log\left(\frac{mp}{\log n}\right)\right)\geq 1-\exp\left(-n^{1-\delta-\varepsilon}\right).

Note that if
mp\gtrsim n^{\gamma}
for some
\gamma>0
, then
\log\frac{mp}{\log n}\sim\log n
, and the bound in
(ii)
can be simplified.

Proof.

The main idea of the proof is to analyse the distribution of the columns that are added at each step
t
. These columns are independent, and for each newly added column, the number of additional subsets which it covers is distributed according to
\mathrm{Bin}(m-F_{t-1},p)
, where
F_{t-1}
is the number of subsets which are already covered. Lemma
8
allows us to lower bound
F_{t}
, and we show now that we can do this with high probability.

Fix
\varepsilon>0
and let
\varepsilon^{\prime}\coloneqq\varepsilon/4
. Let
f_{1},f_{2},\ldots
be the sequence from Lemma
8
for
\varepsilon^{\prime}
and
K
be the value for which (
6.1
) is satisfied, i.e.
F_{K}\geq m-K
. Notice that
K\leq C\max\left\{\frac{m}{{{\mathbb{E}}}d_{\mathtt{max}}},\frac{1}{p}\log(\frac{mp}{\log{n}})\right\}
for some constant
C>0
, for
n
large enough. We uniformly at random split
n
elements (columns) into
K
groups of size
n/K
each (assuming without loss of generality that
K
divides
n
, otherwise we consider groups of size
\left\lfloor n/K\right\rfloor
), so that
\mathcal{B}_{t}
yields a new set of
n/K
elements at each iteration
t\leq K
and
\mathcal{B}_{t}=\varnothing
for
t>K
. We say that the algorithm fails at step
t
if before step
t
, at least
m-F_{t-1}
subsets are covered, but after step
t
less than
m-F_{t}
sets are covered.
Using that, for
n
large enough,
(i)
columns in each newly added block are independent,
(ii)

{\mathbb{P}}\left(\mathrm{Bin}(m-F_{t-1},p)\geq f_{t}\right)\geq n^{-\varepsilon^{\prime}}
, and
(iii)

, we get

\displaystyle{\mathbb{P}}\left(\text{{BlockGreedy} fails at step t}\right)

\displaystyle\overset{(i)}{\leq}\left({\mathbb{P}}\left(\mathrm{Bin}(m-F_{t-1},p)<f_{t}\right)\right)^{n/K}

\displaystyle\overset{(ii)}{\leq}\left(1-n^{-\varepsilon^{\prime}}\right)^{n/K}

\displaystyle\overset{(iii)}{\leq}\exp\left(-n^{1-\delta-2\varepsilon^{\prime}}\right).

We then proceed by applying a union bound to obtain the result,

\displaystyle{\mathbb{P}}\left(\texttt{BlockGreedy}\text{ fails during first }K\text{ steps}\right)

\displaystyle\leq\sum_{t=1}^{K}{\mathbb{P}}\left(\texttt{BlockGreedy}\text{ fails at step t}\right)

\displaystyle\leq K\cdot\exp\left(-n^{1-\delta-2\varepsilon^{\prime}}\right)

\displaystyle\leq\exp\left(-n^{1-\delta-3\varepsilon^{\prime}}\right),

where the second inequality holds since, by definition, the algorithm runs for
K
iterations, and the third one holds for
n
large enough.
We proved that
BlockGreedy
succeeds in finding at most
K
elements such that at most

sets remain uncovered. Since by construction,
m-F_{K}\leq K
, we can cover the remaining rows trivially using that
IP
is feasible by Lemma
2
with high probability, which proves that

{\mathbb{P}}\left(\text{val}\textsubscript{{Alg}}\leq 2K\right)\geq 1-\exp\left(-n^{1-\delta-4\varepsilon^{\prime}}\right)=1-\exp\left(-n^{1-\delta-\varepsilon}\right),

for
n
large enough. Recalling that
K\lesssim\text{val}\textsubscript{{LP} }
for
mp\lesssim\log n
, and that
K\lesssim\text{val}\textsubscript{{IP} }
for
mp\gg\log n
, finishes the proof.
∎

Theorem 2

Under Assumption

k!\geq(k/e)^{k}
in the last inequality.
Since
K\leq C\max\left\{\frac{m}{{{\mathbb{E}}}d_{\mathtt{max}}},\frac{1}{p}\log(\frac{mp}{\log{n}})\right\}
and
1/p\leq n^{\delta}
, there exists a constant
\tilde{C}>0
large enough, such that
K\leq\tilde{C}n^{\delta}\log n
. Therefore, using independence of the reshuffling between the copies, we can compute

(6.6)

\displaystyle{\mathbb{P}}\left(\text{val}\textsubscript{{Alg}}<\text{\text{val}\textsubscript{{Gr}}}\text{ over all $J$ copies}\right)

\displaystyle=\left(1-{\mathbb{P}}\left(\text{val}\textsubscript{{Alg}}\geq\text{\text{val}\textsubscript{{Gr}}}\text{ for }1\text{ copy}\right)\right)^{J}

\displaystyle\leq(1-e^{-2K})^{J}

\displaystyle\leq\exp\left(-e^{\sqrt{n}-2\tilde{C}n^{\delta}\log{n}}\right).

Combining (
6.4
), (
6.5
) and (
6.6
), we showed that
{\mathbb{P}}\left(\text{\text{val}\textsubscript{{Gr}}}>2K\right)\leq\exp\left(-\sqrt{n}\right)
for
n
large enough, which finishes the proof.
∎

.

We note that the
\delta<1/2
condition in Theorem

7.
Discussion and Open Questions

Our work characterises multiplicative integrality gaps for the random hitting set problem. In this section, we discuss the intuition behind our main results, together with open questions and conjectures.

7.1.
Summary of our results and proof techniques.

We identified that the nature of integrality gaps depends on the size of the inclusion set, also viewed as the sparsity of the underlying hypergraph. In particular, when the average degree of a vertex is small, i.e., when each element belongs to a small number of subsets, we proved that there exists only a constant gap between linear and integer program solutions, together with a simple algorithmic solution. The situation changes when the hypergraph becomes dense, where we show an increasing integrality gap. This separation stems mostly from the property of the binomial distribution, where the maximum of random variables grows identically to the expected value whenever the expected value is large, but is away from it if
mp\ll\log n
.

In our analysis of
BlockGreedy
, we track this change of behaviour using a geometric series, which means that the further we are in the execution of the algorithm, the larger the ratio between the element we pick and the average element will be. This picture coincides exactly with how the binomial distribution will behave if we decrease the average degree: for large instances, it will look approximately as a Gaussian, but when the average degree is small, Poisson approximation starts to dominate, the right tail becomes heavier, and the difference between
d_{\mathtt{max}}
and
mp
increases. Our analysis tracks the transition between Gaussian and Poisson-like behavior.

7.2.
Multiplicative vs. additive integrality gaps

Our result only concerns multiplicative gaps, but the constants in our analysis can be large. This might be a consequence of the generality of the studied problem. For example, if one focuses only on the case of constant
p
, which immediately implies a very dense instance in our characterization,
[
14
]
proves that a simple algorithm is optimal for approximating the integer program up to a small additive error. Proving similar upper bounds on the constant in more general cases is an interesting open problem. Based on numerical experiments, we formulate the following conjectures.

Conjecture 1

(Very sparse)
.

For
mp\ll 1
,

(7.1)

\frac{\text{\text{val}\textsubscript{{Gr}}}}{\text{val}\textsubscript{{LP} }}\to 1.

Conjecture 2

(Sparse)
.

For
1\lesssim mp\ll\log n
,

(7.2)

\frac{\text{\text{val}\textsubscript{{Gr}}}}{\text{val}\textsubscript{{IP} }}\to 1,\qquad\qquad\frac{\text{val}\textsubscript{{IP} }}{\text{val}\textsubscript{{LP} }}\to C_{1},

where
1<C_{1}<1.5
.

Conjecture 3

(Dense)
.

For
mp\gg\log n
,

(7.3)

\frac{\text{\text{val}\textsubscript{{Gr}}}}{\text{val}\textsubscript{{IP} }}\to C_{2},

where
1\leq C_{2}<1.5
.

7.3.
Analysis of a linear program solution.

One motivation for studying the gaps between the integer and linear programs together with the solutions of linear programs themselves is to construct a rounding scheme which converts a fractional solution to an integer one. We believe this is another interesting direction for future work. In particular, numerical experiments show that entries which have large value in the fractional solution have a strong tendency to correspond to elements that are picked for the integer solution. This supports the claim that a combination of the greedy and linear programming approach might be fruitful in efficiently solving
Hitting Set
. One approach for further study consists of first solving a linear program, initializing
{\boldsymbol{x}}
with the largest elements in the linear solution, and greedily covering the remaining subsets.
