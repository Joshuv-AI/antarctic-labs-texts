Countability versus Computability
Hantao Zhang

Abstract
We investigate the connection between countability and computability. It is known that a set computable if and only if it admits a computable counting bijection and that a set is decidable if and only if it admits an increasing computable counting bijection. We further show that a set is countable if and only if it admits a counting order , which is a well-order satisfying the nearby property. Based on this property, we provide a procedure whose existence gives a necessary and sufficient condition for the countability of a set. This procedure is an algorithm if and only if the set is computable. Given an infinite set S S of natural numbers, we prove the coexistence of a counting bijection of S S and its characteristic function in first-order arithmetic. In the process of proving this result, we found that the standard proof that every set of natural numbers is countable is invalid.

Introduction

In 1874, Georg Cantor published the first proof that
there is no one-to-one correspondence between the set of all real
numbers (which is uncountable) and the set of all natural numbers
(which is countable)
[
3
]
. In 1891, Cantor simplified his proof using the
well-known diagonal argument, which has since found important applications in
both set theory and computability theory
[
15
]
.

In the 1930s, several independent attempts were made to formalize the
notion of computability:
Kurt Gödel’s partial recursive functions
[
9
]
,
Alonzo Church’s lambda calculus
[
4
]
, and
Turing’s formal model, later known as Turing machines
[
21
]
.
Church and Turing proved that these three notions of
computable functions coincide and proposed the well-known conjecture
called the
Church-Turing thesis
: A function is computable if it can be computed
by a Turing machine
[
5
]
. Other formal attempts to characterize computability,
including Kleene’s recursion theory
[
13
]

and von Neumann’s random-access
stored-programs (RASP)
[
6
]
, have further strengthened this view.

Nine decades have passed, yet it remains puzzling that the deep connection
between countability and computability has not been fully investigated.
The most related work is the theory of numberings that uses computable
mappings
[
1
]
. This approach successfully introduced
computability for the arithmetical hierarchy, which
cover many uncomputable problems
[
2
]
.
Hack
et al.
also used computable bijections as a tool to exploit the computability beyond Turing machines
in the framework of ordered structures that cover uncountable sets
[
11
]
.
Our investigation is focused on the connection between countability and computability
over countable sets and has not attempted to introduce any new computing models
beyond Turing machines.

To facilitate the presentation of our investigation, we first review some key concepts.
Following Cantor, a set
S
is
countable
if either
S
is finite or there exists
a bijection
f:{\cal N}\mapsto S
, where
{\cal N}
is the set of natural numbers
[
3
]
.
From now on, we refer to any such
bijection
f:{\cal N}\mapsto S
as a
counting bijection
of
S
.
We say
S
is
countably infinite
if it is infinite and countable.
It is easy to see that
S
is countably infinite if and only if it
admits a counting bijection.

S
is said to be
enumerable
if it is either finite or admits a computable counting bijection.
If
S
is unenumerable, then every counting bijection of
S
(if exists) is uncomputable.

S
is
increasingly countable
if
S\subseteq{\cal N}
and
it has an increasing counting bijection
f
(i.e.,
f(x)>f(y)
whenever
x>y
).
A
characteristic function
of
S\subseteq{\cal N}
is a total Boolean function

f:{\cal N}\mapsto\{0,1\}
such that
S
is equal to
\{x\in{\cal N}\mid f(x)=1\}
.
Since
f
is total, all the characteristic functions of
S
are equivalent.

Our investigation of the connection between countability
and computability has focused on three main topics:

1.

Our initial investigation shows that
a formal language
L
is Turing recognizable if and only if
L
is enumerable, and that

L
is decidable if and only if
L
has an increasing computable counting bijection
[
23
]
.
This provides an alternative method for determining whether a formal language is
decidable, undecidable yet recognizable, or unrecognizable.

2.

We introduce the concept of
nearby order
which requires that
the number of distinct elements lying between any two elements
(when placed according to the order) be finite. A
counting order

is a nearby well-order. We prove that a set
S
is countable
if and only if
S
admits a counting order.
Given a counting order
\succeq
, one can design a procedure
deleteMin
(S,\succeq)

that removes the minimal element from
S
. We show that

S
is countable if and only if such a procedure exists,
and that
S
is enumerable if and only if
deleteMin
(S,\succeq)
is an algorithm.
This yields a necessary and sufficient procedural criterion for countability.

3.

By
first-order arithmetic
, we mean a collection of
the axiom systems in the language of first-order logic for the theory of natural numbers.

Peano arithmetic
is a typical example of first-order arithmetic
[
17
]
.
Definability in first-order arithmetic has greater expressivity power than the axiom system
of
partial recursive functions
, which are equivalent to Turing machines.
Given a set
S
of natural numbers, we prove that
a counting bijection of
S
is definable in first-order arithmetic
if and only if a characteristic function of
S
is definable in first-order arithmetic.
In the process of proving this result, we found that the standard proof of the claim
that every subset of
{\cal N}
is countable is incorrect.
Although this claim is widely accepted in logic and mathematics,
this would imply that the set of all functions definable in first-order
arithmetic is uncountable—a contradiction to the fact that
only a countable number of functions can be definable in first-order arithmetic.

This article is a substantial revision of
[
22
]
. The next three sections
address the three topics outlined above, respectively.
The common theme running through these topics is the relationship between countability
and computability. The first topic illustrates how the computability of a set
relates to the properties of its counting bijections.
The second topic offers a procedural respective on countable sets.
The final topic goes beyond Turing computability and demonstrates
how counting bijections and characteristic functions are related.

2
Equivalence of Recognizable and Enumerable

The main part of this section appears in the textbook
[
23
]

and is used here as background material for the entire article.
We assume familiarity with the basic concepts of theory of computation

[
15
,
23
]
.

Given a Turing machine
M
, the language
L(M)

recognized
by
M
is said to be
recognizable
.
A set is
computable
if and only if it can be represented by a recognizable language. If
M

halts on every input, then
L(M)
is
decidable
and
M
is a
decider
. A function
f:{\cal N}\mapsto{\cal N}
, where
{\cal N}
denotes the set of
natural numbers, is
computable
if
f
can be computed by a
Turing machine
M
. The machine
M
is said to be an
algorithm
if
M

halts on every input; in this case,
f
is
total computable

(i.e., both total and computable).

We need a computing model called
enumerator
, which is a
variant of Turing machine. Informally, an enumerator is a Turing machine
M

equipped with an attached printer
[
15
]
. The machine
M
uses the printer as an
output device to print strings. The set
E(M)
of printed strings is
the language
enumerated
by
M
. The following result is known
for enumerators
[
15
,
23
]
:

Theorem 2.1

(a)
If
L=E(M)
, where
M
is an enumerator, then
L
is recognizable.

(b)
If
L
is a recognizable formal language, there exists an
enumerator
M
such that
L=E(M)
and every printed string by
M
is
unique.

Let
g:\Sigma^{*}\mapsto{\cal N}
be a computable
bijection, where
\Sigma^{*}
is the set of all finite-length strings over
the alphabet
\Sigma
. For any
x,y\in\Sigma^{*}
,
we define
\succeq
over
\Sigma^{*}
by
x\succeq y
if
g(x)\geq g(y)
.
The order
\succeq
is called the
canonical order
of
\Sigma^{*}
.
For any formal language
L\subseteq\Sigma^{*}
, a bijection
f:{\cal N}\mapsto L

is
increasing
if
f(x)\succeq f(y)
whenever
x\geq y
for any
x,y\in{\cal N}
.
For decidable languages, the following result is known
[
15
,
23
]
.

Theorem 2.2

An infinite formal language
L
is decidable if and only if there exists an
enumerator
M
such that
L=E(M)
and the printed strings are
increasing in the canonical order.

The following two propositions show that a formal language is
enumerable if and only if it is recognizable
[
23
]
.

Proposition 2.3

Every recognizable formal language is enumerable.

Proof
. Suppose
L
is recognizable. The case when
L
is finite is
trivial. If
L
is infinite, by Theorem
2.1
(b)
, we
have an enumerator
M
such that
L=E(M)
and every printed string
by
M
is unique, then
E(M)
is countable because
the order in which the strings are printed by
M
defines a
computable bijection
f:{\cal N}\mapsto E(M)
. That is, for
n\in{\cal N}
, we
compute
f(n)
by algorithm
A(n)
as follows:

Algorithm

A(n)
: Let
c:=0
and simulate
M
.
When a string
x
is printed by
M
, check if
c=n
. If yes, return

x
; otherwise,
c:=c+1
and continue the simulation.

Algorithm
A
will terminate because
E(M)
is infinite and
c
, which
records the number of printed strings by
M
, will reach
n

eventually.
A(n)
can be modified as
B(w)
to compute
f^{-1}(w)

for
w\in E(M)
: Instead of checking
c=n
, check if
x=w
and, if
yes, return
c
. Since both
f
and
f^{-1}
are total functions,
f

is a bijection. Algorithm
A(n)
is the evidence that
f
is
computable.
\square

Proposition 2.4

Every enumerable formal language is recognizable.

Proof
. The case when formal language
L
is finite is trivial. If
L

is enumerable, then there exists a computable bijection

f:{\cal N}\mapsto L
, Thus, we may use
f
to design an enumerator
M
that
prints strings
f(0)
,
f(1)
,
f(2)
, and so on. It is evident that

E(M)=L
. By Theorem
2.1
(a)
,
L
is recognizable.

\square

The following theorem combines the above two propositions into one and extends
the result from formal languages to general sets
[
23
]
.

Theorem 2.5

An infinite set is enumerable if and only if it is computable.

Proof
. If a set
S
is enumerable, then there exists a computable counting
bijection
f:{\cal N}\mapsto S
. Then
S=\{f(n)\mid n\in{\cal N}\}

because
f
is a bijection.
S
is computable because

f(n)
is computable.

When
S
is unenumerable, there are two cases to consider:

S
can be represented by a formal language or not. If yes, then
S

is unrecognizable by Proposition
2.3
, thus uncomputable. If not,
then
S
cannot be recognized by any Turing machine, thus
uncomputable.
\square

The above result is useful when we want to show some sets are
countable. For instance, if we know a set is recognizable, then this
set is enumerable, hence countable. If a set is unrecognizable, then
it is unenumerable. It is known that the collection of recognizable
sets is closed under intersection (i.e., the intersection of any two
recognizable sets is recognizable). It implies that the intersection
of two enumerable sets is enumerable, thus countable.

The following theorem is important about formal languages
[
23
]
.

Theorem 2.6

If
L
is an infinite formal language, then

1.

L
is decidable if and only if there exists an increasing and computable
bijection
f:{\cal N}\mapsto L
.

2.

L
is recognizable if and only if there exists a computable bijection
f:{\cal N}\mapsto L
.

3.

L
is unrecognizable if and only if every bijection
f:{\cal N}\mapsto L
is uncomputable.

Proof
. For (1), by Theorem
2.2
,
L

is decidable if and only if the elements of
L
can be enumerated in increasing
order. This enumeration defines an increasing and computable bijection
as in the proof of Proposition
2.3
, and an increasing and
computable bijection will produce an enumerator that enumerates
elements in increasing order as in the proof of Proposition
2.4
.
Theorem
2.2
is then used to obtain the expected result.

(2) comes from Theorem
2.5
, as
“
L
is recognizable” is equivalent to “
L
is enumerable”, and the latter
means “there exists a computable bijection
f:{\cal N}\mapsto L
.”

(3) is logically equivalent to (2).

\square

The above theorem holds if
L
is a set of natural numbers and
shows that the properties of counting bijection

f:{\cal N}\mapsto L
is crucial to dictate whether
L
is decidable or
computable. In particular, if
L
is computable yet undecidable, then
its counting bijection must be computable but not increasing.

Example 2.7

Consider the following encoding of some decision problems,
where
\langle M\rangle\in\Sigma^{*}
is the string encoding Turing machine
M

[
15
]
.

•

E_{TM}=\{\langle M\rangle\mid L(M)=\emptyset\,\mbox{\rm for Turing machine}~M\}

•

N_{TM}=\{\langle M\rangle\mid L(M)\neq\emptyset\,\mbox{\rm for Turing machine}~M\}

•

All_{TM}=\{\langle M\rangle\mid L(M)=\Sigma^{*}\,\mbox{\rm for Turing machine}~M\}

They are formal languages since
\langle M\rangle\in\Sigma^{*}
.

E_{TM}
,
N_{TM}
, and
All_{TM}
are the encoding of all Turing
machines that accept, respectively, nothing, something, and
everything.
N_{TM}
is the complement of
E_{TM}
. It is known that

N_{TM}
is recognizable and
E_{TM}
is unrecognizable. By
Proposition
2.3
,
N_{TM}
is enumerable. By Proposition
2.4
,
E_{TM}

is unenumerable. Both
All_{TM}
and its complement,

\overline{All_{TM}}
, are unrecognizable, hence, unenumerable.

\square

3
A Procedure for Countability

In mathematics, a
poset
(partial order set) is a pair

(S,\succeq)
, where
S
is a set and
\succeq
is a partial order of

S
—that is,
\succeq
is an antisymmetric, transitive, and reflexive
relation on
S
. For any
a,b\in S
, we write

a\succ b
to mean
a\succeq b
and
a\neq b
.
The order
\succeq
is
total
if, for any
a,b\in S
, exactly one of
a\succ b
,

b\succ a
, or
a=b
holds. It is
well-founded
if every non-empty
subset of
S
has a minimal element with respect to
\succeq
.
The order
\succeq
is a
well-order
if it is both total and well-founded. Finally,
\succeq
is
dense
if, for any
a,b\in S
with
a\succ b
, there exists an element
c\in S

such that
a\succ c\succ b
.

Definition 3.1

Given a poset
(S,\succeq)
,

\succeq
is said to be nearby if, for any two elements

a,b\in S
, the set
\{c\in S\mid a\succ c\succ b\}

is finite;

\succeq
is said to be a counting order of

S
if
\succeq
is a nearby well-order.

Example 3.2

Here are a few examples:
\geq
is a counting order of
{\cal N}
;
\geq
is not a
counting order for
{\cal Z}
, the set of integers, because
\geq
is not a
well-order of
{\cal Z}
.

Let
\geq
be the order on
{\cal N}\times{\cal N}
such that

(x_{1},y_{1})\geq(x_{2},y_{2})
if
x_{1}>x_{2}
or

x_{1}=x_{2}
and
y_{1}\geq y_{2}
(that is,
\geq
is a lexicographic order of

{\cal N}\times{\cal N}
).
\geq
is a well-order of
{\cal N}\times{\cal N}
. However,

\geq
is not a counting order because it is not nearby. There
are infinite pairs between
(0,0)
and
(1,0)
:
the set
\{(0,n+1)\mid n\in{\cal N}\}
is infinite.

Note that a dense order is never nearby, and
the concepts of “nearby” and “non-dense” are different:

\geq
on
{\cal N}\times{\cal N}
is neither dense nor nearby.

\square

When proving that the set of reals is not countable,
Cantor’s diagonal argument is used to show that the assumed counting order is
not nearby because some elements are left out of the order.
The following result shows the connection between counting order
and countability.

Theorem 3.3

A set is countable if and only if it admits a counting order.

Proof
. The finite case is trivial, so we consider only infinite sets.
If
S
is countable, then
S
has a counting bijection
f:{\cal N}\mapsto S
.
Define
\succeq
over
S
by
f(x)\succeq f(y)
if
x\geq y
for any
x,y\in{\cal N}
.
Then
\succeq
is a nearby well-order of
S
, since
\geq
is a nearby well-order of
{\cal N}
.

On the other hand, let
\succeq
be a nearby well-order of
S
.
For any
n\in{\cal N}
, define
g(n)
to be the
(n+1)^{th}
minimal element of
S

under
\succ
.
g:{\cal N}\mapsto S
is injective because
i^{th}
minimal element
is different from
j^{th}
minimal element if
i\neq j
.

g
is surjective because
\succeq
is a counting order. That is,
let
a=min(S)
,
b\in S
and
a\neq b
. Since
\succeq
is nearby,
the set
X=\{c\in S\mid b\succ c\succ a\}
is finite.
If
|X|=n
, then
b
is the
(n+2)^{th}
minimal element of
S
. Hence,
for any
b\in S
, there exists
m\in{\cal N}
,
g(m)=b
. Thus,

g
is a counting bijection of
S
.

\square

If
S
is computable yet undecidable, by Theorem
2.6
,
we can obtain a computable bijection
f:{\cal N}\mapsto S
, where
f
is not increasing
(with respect to
\geq
).
In the above proof, from
f
, we obtain a counting order
\succeq
of
S

such that
f
is increasing with respect to
\succeq
. Obviously,
\succeq
is different
from
\geq
.

In the second part of the above proof, we defined the function

g(n)
to be the
(n+1)^{th}
minimal element of
S

under
\succ
. The same idea was used in the proof of the claim
that every set of natural numbers is countable
[
19
]
.
If
S
is undecidable, then
g
cannot be computable if
\succ
is
>
over
{\cal N}
,
because an increasing computable
g
implies that
S
is decidable.

Theorem
3.3
claims that a set has a counting bijection if and only if it has a counting order. This
provides a necessary and sufficient condition for countably infinite sets.

Given a poset
(S,\succeq)
, where
\succeq
is a counting order of
S
,
we will design a procedure
deleteMin
(S,\succeq)

that removes the minimal element (with respect to
\succeq
)
from
S
and returns the minimal element.
This procedure offers a new perspective for studying countability.

Theorem 3.4

1.

S
is countable if and only if procedure deleteMin
(S,\succeq)
exists.

2.

S
is enumerable if and only if there exists an algorithm deleteMin
(S,\succeq)
.

Proof
. In the following proof, we consider only infinite sets as the finite case is trivial.

(1)
By Theorem
3.3
,
S
is countable if and only if
S
has a counting
order. Procedure
deleteMin
(S,\succeq)
exists
if and only if
\succeq
exists, because for nonempty
S
,

min(S,\succeq)=x\leftrightarrow(x\in S\and\forall y\in S~\neg(x\succ y)).

We may design
deleteMin
(S,\succeq)
which scans
S

once to locate
min(S,\succeq)
, deletes it from
S
and returns it.

(2)
If
S
is enumerable, there exists a computable bijection
f:{\cal N}\mapsto S

and
S=\{f(n)\mid n\in{\cal N}\}
. In fact,
f
is total computable since
f
is total.
Thus, the Turing machine that computes
f
is an algorithm.
As in the proof of Theorem
3.3
, for any
x,y\in{\cal N}
, we define
\succeq
by

f(x)\succeq f(y)
whenever
x\geq y
. Then
min(S,\succeq)=f(0)

and the successive calls of
deleteMin
(S,\succeq)

will return
f(0)
,
f(1)
,
f(2)
, …. Since
f
is total computable,
so is
deleteMin
(S,\succeq)
.
On the other hand, if
deleteMin
(S,\succeq)
is an algorithm, for any
n\in{\cal N}
,
let
f(n)
be the element returned by the
(n+1)^{th}
call of
deleteMin
(S,\succeq)
,
then
f
is a computable counting bijection of
S
.

\square

Theorem
3.4
gives us a necessary and sufficient condition for an
enumerable set
S
: Having an algorithm
deleteMin
with a
counting order
\succeq
. Using algorithm
deleteMin
,
every element of
S
can be enumerated one by
one from the smallest by the counting order
\succeq
.
If
S
is a formal language, then the enumerated numbers are not
necessarily increasing in the canonical order. For instance, let
H
be the
formal language for the halting problem of Turing machines.
Since
H
is computable yet undecidable,
H
cannot be
increasingly enumerated in the canonical order (see Theorem
2.2
).

Unproven Statements about Countable Sets

The claim that “every subset of
{\cal N}
is countable”
is widely accepted and taught in many college courses.
The claim has several equivalent statements.

Proposition 4.1

The following statements are logically equivalent:

1.

Any subset of a countable set is countable.

2.

Any subset of
{\cal N}
is countable.

3.

If there is an injective function from set
S
to
{\cal N}
, then
S
is
countable.

4.

If there is a surjective function from
{\cal N}
to
S
, then
S
is
countable.

Proof
.
(1)\Rightarrow(2)
:
{\cal N}
is countable.

(2)\Rightarrow(3)
: Let
f:S\mapsto{\cal N}
be injective and

X=\{f(x)\mid x\in S\}
. Since
X\subseteq{\cal N}
,
X
is countable
by
(2)
. Note that
f:S\mapsto X
is a bijection from
S
to
X
,
that is,
S
and
X
are the same size. So,
S
must be countable.

(3)\Rightarrow(4)
: Let
g:{\cal N}\mapsto S
be surjective, then
for every
x\in S
, the set
g^{-1}(x)=\{y\mid g(y)=x\}

is not empty. Define
f:S\mapsto{\cal N}
by
f(x)=min(g^{-1}(x))
,
then
f
is injective. By
(3)
,
S
is countable.

(4)\Rightarrow(1)
: Let
X\subseteq S
and
S
be countable. If
X
is
finite, then
X
is countable. If
X
is infinite, then

S
must be infinite and there exists a bijection
h:{\cal N}\mapsto S
. Let

a
be an element of
X
. Define
g:{\cal N}\mapsto X
by
g(x)=h(x)
if

h(x)\in X
, otherwise
g(x)=a
. Then
f
is surjective. By

(4)
,
S
is countable. If
g
is not required to be total, then
“
g(x)=a
” is not needed when
h(x)\notin X
.
\square

If these statements are true, we may have an alternative yet simpler definition of
“countable”: A set
S
is
countable
if there is an injective
function from
S
to
{\cal N}
. Some textbooks use this definition

[
7
]
. This definition does not matter whether
S
is finite or
not and uses only injection, not bijection.

These statements appear in many
textbooks on logic
[
8
]
, set theory
[
10
,
12
]
,
discrete mathematics
[
16
]
,
or theory of computation
[
14
]
.
In a textbook on set theory
[
7
]

published in 1977, the author wrote without proof that
“obviously every subset of a countable set is countable.”
It also appears in an influential textbook by Terence
Tao
[
19

(Proposition 8.1.5).

Proposition 8.1.5
of
[
19
]

Let
X
be an
infinite subset of the natural numbers
{\cal N}
. Then there exists a
unique bijection
f:{\cal N}\mapsto X
which is increasing, in the sense
that
f(n+1)>f(n)
for all
n\in{\cal N}
. In particular,
X
has
equal cardinality with
{\cal N}
and is hence countable.

Proposition 8.1.5 claims that
every subset of
{\cal N}
is increasingly countable, which is stronger
than the claim that every subset of
{\cal N}
is countable.
We show later that the two claims are equivalent in first-order arithmetic.
Unfortunately, Proposition 8.1.5 lacks a valid proof because its proof
leads to a contradiction.
In fact, none of the four statements in Proposition
4.1
has a valid proof.
Hence, their validity remains an open problem.

In the following, we show what went wrong in the proof of Proposition 8.1.5
by starting with a formal definition of “definable”. By convention,
an axiom system
L
is a language of logic which uses an alphabet to construct
formulas and define inference rules. Some of these formulas are designated to be
axioms

and some of these formulas are
theorems
which are deduced
from the axioms and the inference rules. The power of an axiom system
is measured by its set of theorems.

Given an axiom system
L
,
the semantics of syntactic items in
L
is specified in a metalanguage
M
which defines truths
of the formulas in
L
. After Tarski’s approach on undefinability,
people often use an algebraic structure, called
model
of
L
,
to describe the semantics of
L

[
20
]
.
For instance, the structure of natural numbers is used as the standard model of first-order arithmetic.
This model is used to define
true arithmetic

T
, the set of all sentences
(i.e., closed formulas) of
L
which are true in the model.
This model consists of
{\cal N}
(called the
underlying set
),
a collection of arithmetic operations on
{\cal N}
,
and a set of
axioms
that these operations must satisfy.
These operations are presented by relations or functions over the underlying set..
Informally, a relation (or a function) of the model is said to be “definable” if
the relation can be specified by a formula of
L
.

We assume that in any axiom system
L
of first-order arithmetic,
a natural number
n
is represented
by the
numeral

\overline{n}=s^{n}(0)
, where
0
and
s
(the unary
successor

function) are the symbols of
L
.

Definition 4.2

For any axiom system
L
using
0
and
s(x)
,
a relation
p(n_{1},n_{2},...,n_{k})
in a model of
L
, where
n_{i}\in{\cal N}
for
1\leq i\leq k
,
is said to be definable in
L

if there exists a formula
\phi(x_{1},x_{2},...,x_{k})
of
L

such that
p(n_{1},n_{2},...,n_{k})
is true if and only if
\phi(\overline{n_{1}},\overline{n_{2}},...,\overline{n_{k}})
is true.
A set
S\subseteq{\cal N}
is said to be definable in
L

if
S=\{n\in{\cal N}\mid p(n)\}
, where
p(n)
is a unary relation definable in
L
.

For instance, let
F
be the axiom system for
partial recursive functions

(no universal quantifiers in any formula).
According to the Church-Turing thesis, a set is definable in
F
if and only if it is computable.
Conventional operations appearing in the standard model of natural numbers
are all definable in first-order arithmetic (both quantifiers are allowed),
as their definitions can be expressed by the formulas of first-order arithmetic.

Since a function is a special case of relation and a relation is often regarded
as a Boolean function, the above definition applies to functions and we will
use functions as a synonym of relation.
We will use the following proposition later.

Proposition 4.3

For any axiom system
L
, if a model of
L
uses
{\cal N}
as its underlying set,
then the set of functions of the model definable in
L
is countable.

Proof
. Since
{\cal N}
is countable, the alphabet of
L
must countable, because

{\cal N}
cannot serve as the underlying set for an uncountable alphabet.
Thus, the set of formulas of
L
is countable, because each formula uses
a finite set of symbols. Hence, the set of functions defined
by these formulas is countable.

\square

If a set is definable in an axiom system
L
, it does not imply that
its characteristic function is definable in
L
. That is,
if
S=\{n\in{\cal N}\mid p(n)\}
, the unary relation
p(n)
is not necessarily
a characteristic function of
S
, unless
p(n)
is total.
For instance, if
S=\{n\in{\cal N}\mid p(n)\}
is decidable, then
p(n)
is its characteristic function.
If
S
is computable yet undecidable, then
p(n)
is not its characteristic function in
F
,
since
p(n)
is not total in
F
.
On the other hand, if the characteristic function of
S
is definable in
L
,

S
is definable in
L
.

A proof sketch of Proposition 8.1.5 goes as follows
[
19
]
:
Since the standard order
<
is a well-order of
X\subseteq{\cal N}
,
X
has a minimal element under
<
,
say
a_{0}=min(X)
. Let

X_{0}=X
and, for
i>0
,
X_{i}=X_{i-1}-\{a_{i-1}\}
, where

a_{i}=min(X_{i})
, we obtain an increasing sequence

a_{0}<a_{1}<a_{2}<...

along with the sequence
X_{0},X_{1},X_{2},...
.
Define
f:{\cal N}\mapsto X
by
f(n)=a_{n}=min(X_{n})
, it is evident that
f
is an
increasing bijection (see the proof of Theorem
3.3
).
Hence,
X
is increasingly countable.

Proposition 4.4

The increasing counting bijection constructed in
the proof of Proposition 8.1.5 is definable in first-order arithmetic.

Proof
. At first, the function
min(X)
can be defined in first-order arithmetic:

(min(X)=a)\leftrightarrow(a\in X\and\forall b\in X~\neg(a>b)).

Secondly, the counting bijection
f:{\cal N}\mapsto X
in the proof can be expressed
by the function
g
defined as follows: For all
x\in{\cal N}
,
f(n)=g(X,n)
, where

\begin{array}[]{rcl}g(X,0)&=&min(X)\\
g(X,n+1)&=&g(X-\{min(X)\},n)\end{array}

Assuming
X_{0}=X
and, for
i>0
,
X_{i}=X_{i-1}-\{a_{i-1}\}
, where

a_{i}=min(X_{i})
.
It is straightforward to check that

f(n)=g(X_{0},n)=g(X_{1},n-1)=g(X_{2},n-2)=\cdots=g(X_{n},0)=min(X_{n})=a_{n}.

Hence, the proof of Proposition 8.1.5 can be carried out in first-order arithmetic.

\square

The following result presents a close connection between
the definability of sets and their counting bijections in first-order arithmetic.

Theorem 4.5

Let
S
be an infinite set of natural numbers.
The following statements are equivalent in first-order arithmetic.

1.

An increasing counting bijection of
S
is definable in first-order arithmetic.

2.

A counting bijection of
S
is definable in first-order arithmetic.

3.

A characteristic function of
S
is definable in first-order arithmetic.

Proof
.
(1)\Rightarrow(2)
:
(1)
is a special case of
(2)
.

(2)\Rightarrow(3)
:
Let
f:{\cal N}\mapsto S
be a counting bijection of
S
. For any
n\in{\cal N}
, let

p(n)
be
\exists x~(f(x)=n)
. Then
n\in S
if and only if
p(n)
is true.
If
f
is definable in first-order arithmetic, so is
p
.
Since
f
is total,
p(n)
is total, too. Hence,
p(n)
is a characteristic function of
S
.

(3)\Rightarrow(1)
:
Suppose
p(n)
is a characteristic function of
S
that is definable in first-order arithmetic.
For any
n\in{\cal N}
, define
f(n)=g(n,0)
,
where
g:{\cal N}\times{\cal N}\mapsto{\cal N}
is defined as follows:

\begin{array}[]{rcl}g(0,m)&=&{\bf if}\ p(m)~{\bf then}\ m~{\bf else}\ g(0,m+1)\\
g(n+1,m)&=&{\bf if}\ p(m)~{\bf then}\ g(n,m+1)~{\bf else}\ g(n+1,m+1)\end{array}

Let
S=\{a_{0},a_{1},a_{2},...\}\subseteq{\cal N}
such that
a_{i}<a_{i+1}
for
i\in{\cal N}
.
We show below that
f(n)=a_{n}
by induction on
n
. For the base case,

f(0)=g(0,0)
. The recursive calls of
g(0,0)
will return the least
m
such that

p(m)
is true. Obviously,
m=a_{0}
.

Now we consider the inductive case.
For any
n\in{\cal N}
,
g(n+1,0)
visits
0,1,...,a_{0}
(as the second parameter of
g
)
before the first parameter of
g
is decreased by
1

in the recursive calls of
g
. Similarly,
g(n,a_{0}+1)

will visit
a_{0}+1,...,a_{1}
;
g(n-1,a_{1}+1)
will visit
a_{1}+1,...,a_{2}
, and so on,
during the recursive calls. Finally,
g(0,a_{n}+1)
will return
a_{n+1}
,
the minimal number of
S-\{f(0),f(1),...,f(n)\}
.
It is ready to check that

f(n+1)=g(n+1,0)=g(n,a_{0}+1)=g(n-1,a_{1}+1)=\cdots=g(0,a_{n}+1)=a_{n+1}.

It is easy to check that
f
is an increasing counting bijection of
S

and
f
is definable in first-order arithmetic.
Note that
g(n,m)
is total because

S
is infinite and
p(m)
is true for an infinite number of
m
.

\square

The above theorem shows the coexistence of a counting bijection
and a characteristic function for an infinite set of natural numbers.
That is, if one exists, so does the other; if one does not exist, neither does the other.

The
arithmetical hierarchy
classifies formulas of first-order arithmetic by the use
of (unbounded) quantifiers
[
18
]
. The classifications of
formulas are denoted by
\Sigma^{0}_{n}
(and
\Pi^{0}_{n}
) for
n\in{\cal N}

(
0
in the superscript denotes first-order).
For
n>0
, a
\Sigma^{0}_{n}
formula is equivalent to a prenex formula
that begins with some existential quantifiers and alternates
n-1

times between series of existential and universal quantifiers.
Analogously, a
\Pi^{0}_{n}
formula, where
n>0
, is equivalent to a prenex formula
that begins with some universal quantifiers and then alternates.
A set of natural numbers defined by a formula of
\Sigma^{0}_{n}
(
\Pi^{0}_{n}
)
is called a
\Sigma^{0}_{n}
-
set
(
\Pi^{0}_{n}
-
set
).
It is known that each
\Sigma^{0}_{0}
-set is decidable;
each
\Sigma^{0}_{1}
-set is (partial) computable;
each
\Pi^{0}_{1}
-set is co-computable. For
n>1
,
a
\Sigma^{0}_{n}
-set may be uncomputable
[
18
]
.
Since the arithmetical hierarchy provides an infinite sequence of collections of
problems with increasing complexity,
it has been viewed as a test bed for computability beyond Turing machines.
The expressiveness powers of the arithmetical hierarchy and first-order arithmetic
are equivalent.
Theorem
4.5
shows for the first time the equivalence
of first-order arithmetical sets and the countable sets definable in first-order arithmetic.
It also displays the connection between the existence of counting bijections
and computability beyond Turing machines.

Since the power set of
{\cal N}
is uncountable, by Proposition
4.3
,
there exist uncountably many subsets of
{\cal N}
that
are undefinable in first-order arithmetic, because each distinct subset of
{\cal N}

needs a distinct Boolean function of first-order arithmetic for its definition.
If an infinite
S\subseteq{\cal N}
is undefinable in first-order arithmetic,
so is the characteristic function of
S
. By Theorem
4.5
, any counting
bijection of
S
is undefinable in first-order arithmetic, which contradicts
the claim that every subset of
{\cal N}
is countable.

Proposition 4.6

Proposition 8.1.5 of
[
19
]
lacks a valid proof.

Proof
. By Proposition
4.3
, there
are uncountably many subsets of
{\cal N}
which are undefinable
in first-order arithmetic, and so are their characteristic functions and counting bijections.
On the other hand, the proof of Proposition 8.1.5 defines a counting bijection
for every infinite set
X\subseteq{\cal N}
. By Proposition
4.4
, using
X
as a parameter,
this definition can be expressed by a single formula of first-order arithmetic (no
distinct formula for each distinct set). Apparently, there exists a contradiction
when
X
is used as parameter.

What is the role of using
X
as parameter?
The variable
X
denotes only its existence as a subset of
{\cal N}
. However, it does not imply
the existence of its characteristic function.
X
often appears together with
the operator
\in
, such as in formula
a\in X
.
For any axiom system
L
of first-order arithmetic, where
{\cal N}
is the underlying set in its model,
the interpretation of
\in
in the formula
a\in X
is the characteristic function of
X
of the model for
L
.
We need this function to tell if an element is a member of
X
or not in the model.

The proof of Proposition 8.1.5 implicitly assumed that the characteristic function exists for every
X\subset{\cal N}
.
For instance, the proof uses the definition of
min(X)
,

min(X)=a\leftrightarrow(a\in X\and\forall b\in X~\neg(a>b)),

and the interpretations of
a\in X
and
b\in X
need the characteristic functions of
X
.
If the characteristic function of
X
is undefinable in first-order arithmetic, then
the implicit assumption is false. For the validity of the proof, we need
the condition that “the characteristic function of
X
is definable in first-order arithmetic.”
Proposition 8.1.5 simply ignored this condition, an error of hasty generalization.
Hence, the proof of Proposition 8.1.5 cannot be valid as it leads to the contradiction.

\square

Example 4.7

A notable example of undefinable sets comes from Tarski’s undefinability theorem.
Let
T^{*}
denote the set of Gödel numbers of all true sentences
in the standard model of first-order arithmetic. The following three propositional variables
have no consistent interpretations:

•

p
means “
T^{*}
is definable in first-order arithmetic.” It is well-known that

p
is false
[
20
,
17
]
.

•

q
means “
T^{*}
has a counting bijection definable in first-order arithmetic.”
By Proposition 8.1.5
[
19
]
,
T^{*}\subset{\cal N}
has a
counting bijection definable in first-order arithmetic (Proposition
4.4
).
Hence,
q
must be true.

•

r
means “the characteristic function of
T^{*}
is definable
in first-order arithmetic.” If
r
is true, then
p
must be true because
the characteristic function of
T^{*}
provides a definition of
T^{*}
.
If
r
is false, then
q
must be false by Theorem
4.5
.

In short, we cannot find a consistent interpretation for
\{p,q,r\}
.

\square

5
Conclusions

In Cantor’s time, the notion of
computability
had not yet been
formally defined.
Cantor used the word
count
to indicate that an operation is performed.
It turns out that the properties of counting bijections are closely
related to computability.
Our initial investigation shows that
a set is computable if and only if it has a computable counting bijection,
and that a set is decidable if and only if it has an increasing
and computable counting bijection
[
23
]
.
In this article, we provide a procedural perspective on countability.
We show that a set
S
is countable if and only there exists
a procedure
deleteMin
(S,\succeq)
that deletes
the minimal element of
S
according to
\succeq
, a counting order of
S
.
Moreover,
S
is computable if and only if
deleteMin
(S,\succeq)
is
an algorithm. This result further strengthens the relationship between
countability and computability.

For computability beyond Turing machines, one may use first-order
arithmetic as a specification tool. We show that, for an infinite set
S

of natural numbers, a characteristic function of
S
is definable in first-order arithmetic
if and only if a counting bijection of
S
is definable in first-order arithmetic.
In the process of proving this result, we found that the standard proof
of the claim that every subset of
{\cal N}
is countable is invalid, as
the proof of the claim leads to the conclusion that the set of counting
bijections definable in first-order arithmetic is uncountably many,
which contradicts the fact that only a countable number of counting bijections
is definable in first-order arithmetic.

Without a valid proof, the claim remains an open problem.
Proving it appears to be very challenging.
By Proposition
4.3
, the claim cannot be proved within any axiom
system whose model uses
{\cal N}
as the underlying set.
We may need an axiom system that does not use
{\cal N}
as its underlying set.
It is unclear how
{\cal N}
and the counting bijections of
S\subseteq{\cal N}

are defined in this axiom system.
According to Gödel’s incompleteness theorems
[
9
]
, every
sufficiently powerful axiom system has inherent limitations.
These limitations may introduce a set of natural numbers whose countability cannot
be established in the same axiom system.
There appears to be no upper
bound on the difficulty or complexity in either computability or countability.
