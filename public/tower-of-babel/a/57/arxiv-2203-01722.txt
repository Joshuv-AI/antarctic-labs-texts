A Remark on Evolution Equation of Stochastic Logical Dynamic Systems
Changxi Li, Jun-e Feng, Daizhan Cheng, Xiao Zhang

Abstract
Modelling is an essential procedure in analyzing and controlling a given logical dynamic system (LDS). It has been proved that deterministic LDS can be modeled as a linear-like system using algebraic state space representation. However, due to the inherently non-linear, it is difficult to obtain the algebraic expression of a stochastic LDS. This paper provides a unified framework for transition analysis of LDSs with deterministic and stochastic dynamics. First, modelling of LDS with deterministic dynamics is reviewed. Then modeling of LDS with stochastic dynamics is considered, and non-equivalence between subsystems and global system is proposed. Next, the reason for the non-equivalence is provided. Finally, consistency condition is presented for independent model and conditional independent model.

However, most of existing results focused on LDS with deterministic dynamics. The reason comes from two aspects: (

This paper aims at providing a unified framework for modeling LDSs with deterministic and stochastic dynamics. First, modeling of LDS with deterministic dynamics is reviewed. Then modeling of LDS with stochastic dynamics is considered, and non-equivalence between subsystems and global system is proposed. Next, the reason for the non-equivalence is revealed. Finally, consistency condition is presented for independent model and conditional independent model.

III
Algebraic Expression of LDS with Deterministic Dynamics

Suppose the evolutionary rule for each node is deterministic. Consider a subset nodes
U\subseteq N
. Define a projection matrices
\Phi_{U}
as follows

\Phi_{U}:=\otimes_{j=1}^{n}\gamma_{j}

where

\gamma_{j}:=\begin{cases}I_{k_{j}},~j\in U\\
{\bf 1}_{k_{j}}^{T},~j\notin U.\end{cases}

By virtue of vector expression to
x_{i}
and
x
, the subsystems (
II
) can be described as follows

\displaystyle\begin{array}[]{llcc}\begin{cases}x_{1}(t+1)=M_{1}\ltimes_{i\in N_{1}}x_{i}(t)=M_{1}\Phi_{N_{1}}x(t)\vskip 4.30554pt\\
x_{2}(t+1)=M_{2}\ltimes_{i\in N_{2}}x_{i}(t)=M_{2}\Phi_{N_{2}}x(t)\vskip 4.30554pt\\
~~\vdots\\
x_{n}(t+1)=M_{n}\ltimes_{i\in N_{n}}x_{i}(t)=M_{n}\Phi_{N_{n}}x(t),\end{cases}\end{array}

where
x_{i}(t)\in\Delta_{k_{i}},~x(t)=\ltimes_{i=1}^{n}x_{i}(t),
and
M_{i}\in\mathcal{L}_{k_{i}\times k}
is the structure matrix of
f_{i}
with
k=\prod\limits_{i=1}^{n}k_{i}.

Denote by
\hat{M}_{i}=M_{i}\Phi_{N_{i}}.

Therefore, the global evolutionary equation can be obtained as

\displaystyle x(t+1)=Mx(t),

(7)

where

\displaystyle M=\hat{M}_{1}*\hat{M}_{2}*\cdots*\hat{M}_{n}.

(8)

According to (
8
), global evolutionary equation (
7
) can be obtained from subsystems (
III
). On the other hand, if the global evolutionary equation (
7
) is given, can we obtain the subsystems (
III
)? The following result reveals that the subsystems (
III
) can be obtained from global evolutionary equation (
7
).

Proposition
III.1

Consider LDS (
II
) with its global evolutionary equation (
7
). Then
M_{i}
of subsystems (
III
) can be obtained as follows

\hat{M}_{i}=\Phi_{i}M,~~i=1,2,\cdots,n.

Proof:

For any
x(t)\in\Delta_{k}
, we have

\displaystyle\begin{array}[]{lllcc}\Phi_{i}Mx(t)&=&\Phi_{i}x(t+1)&\\
&=&(\otimes_{j=1}^{n}\gamma_{j})(\otimes_{i=1}^{n}x_{i}(t+1))&\\
&=&x_{i}(t+1).&\\
\end{array}

The last equality comes from the following property of Kronecker product
(A⊗B)(C⊗D)=AC⊗BD.

∎

Proposition

reveals that global evolutionary equation (

V
Explanation for the Non-equivalence

Before investigating the non-equivalence, the following definitions are necessary.

Definition
V.1

Consider three random variables
X,Y,Z
.

(i)

Random variables
X
and
Y
are
independent
if

\displaystyle\begin{array}[]{llcc}&\Pr(X=x,Y=y)=\Pr(X=x)\Pr(Y=y),&\\
&~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~\forall x\in X,y\in Y.&\end{array}

(ii)

Random variables
X
and
Y
are
conditional independent
on
Z
if

\displaystyle\begin{array}[]{lllccc}&&\Pr(X=x,Y=y|Z=z)&\\
&=&\Pr(X=x|Z=z)\Pr(Y=y|Z=z),&\\
&&~~~~~~\forall x\in X,y\in Y,z\in Z.&\end{array}

Remark
V.2

It should be pointed out that neither independent implies to conditional independent nor conditional independent implies to independent.

Assumption
V.3

(
Independence Assumption
)
The random variables
x_{1}(t),x_{2}(t),\cdots,x_{n}(t)
are independent for any
t>0.

Suppose Assumption
V.3
is satisfied, then the probability of
x(t+1)=j
is

\displaystyle\begin{array}[]{lllcc}&&\Pr\big(x(t+1)=j\big)&\\
&=&\Pr\big(x_{1}(t+1)=j_{1},\cdots,x_{n}(t+1)=j_{n}\big)&\\
&=&\prod\limits_{i=1}^{n}\Pr\big(x_{i}(t+1)=j_{i}\big)&\\
&=&\prod\limits_{i=1}^{n}\Pr\big(\bigcup\limits_{r=1}^{k}\{x(t)=r\},x_{i}(t+1)=j_{i}\big)&\\
&=&\prod\limits_{i=1}^{n}\Pr\big(\bigcup\limits_{r=1}^{k}\{x(t)=r,x_{i}(t+1)=j_{i}\}\big)&\\
&=&\prod\limits_{i=1}^{n}\Big[\sum\limits_{r=1}^{k}\Pr\big(x(t)=r,x_{i}(t+1)=j_{i}\big)\Big]&\\
&=&\prod\limits_{i=1}^{n}\Big[\sum\limits_{r=1}^{k}\Pr\big(x(t)=r\big)\Pr\big(x_{i}(t+1)=j_{i}|x(t)=r\big)\Big]&\\
&=&\prod\limits_{i=1}^{n}\big[\Row_{j_{i}}(\hat{Q}_{i})p(t)\big].&\\
\end{array}

According to (
V
), the state probability vector can be calculated as

\displaystyle\begin{array}[]{lllccc}\begin{bmatrix}\Pr\big(x(t+1)=1\big)\vskip 3.87498pt\\
\Pr\big(x(t+1)=2\big)\vskip 3.87498pt\\
\vdots\\
\Pr\big(x(t+1)=k\big)\end{bmatrix}&=&\begin{bmatrix}\prod\limits_{i=1}^{n}\Row_{1}(\hat{Q}_{i})p(t)\\
\vdots\\
\prod\limits_{i=1}^{n}\Row_{k_{i}}(\hat{Q}_{i})p(t)\end{bmatrix}&\\
&=&\ltimes_{i=1}^{n}[\hat{Q}_{i}p(t)]&\end{array}

Recall equation (
IV
), it is easy to know that (
V
) is equivalent to (
IV
) under Assumption
V.3
(independence condition).

Assumption
V.4

(

)
The random variables

Suppose Assumption

\displaystyle\begin{array}[]{lllcc}&&\Pr\big(x(t+1)=j\big)&\\

Recall equation (

Proposition
V.5

Consider LDS with global evolutionary equation (

VI
Consistency Condition Exploration

According to above analysis, we know that (

Proposition
VI.1

(
Consistency Condition
)
System (
IV
) and (
14
) are equivalent, if and only if, for any
p\in\Upsilon_{k}
the following equation is satisfied

\displaystyle HR_{k}^{n-1}p=H\ltimes p^{n},

(36)

where
R_{k}=diag\{\delta_{k}^{1},\delta_{k}^{1},\cdots,\delta_{k}^{k}\}
and

H=\ltimes_{i=1}^{n}(I_{k^{i-1}}\otimes\hat{Q}_{i}).

VII
Conclusion

As one of the fundamental problems, modeling is an essential procedure before controlling a given LDS. This paper provided a unified framework for modeling LDSs
with deterministic and stochastic dynamics. We first reviewed the modeling of deterministic LDS. Then non-equivalence between subsystem and global system for stochastic LDS is considered, and non-equivalence between subsystem and global system is proposed. And the reasons for the non-equivalence was provided. Finally, consistency condition was presented for independent model and conditional independent model.
