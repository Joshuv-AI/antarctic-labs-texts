Maximum-likelihood fits of piece-wise Pareto distributions with finite and non-zero core
Benjamin F. Maier

Abstract
We discuss multiple classes of piece-wise Pareto-like power law probability density functions p ⁡ ( x ) p(x) with two regimes, a non-pathological core with non-zero, finite values for support 0 ≤ x ≤ x min 0\leq x\leq x_{\mathrm{min}} and a power-law tail with exponent − α -\alpha for x > x min x>x_{\mathrm{min}} . The cores take the respective shapes (i) p ⁡ ( x ) ∝ ( x / x min ) β p(x)\propto(x/x_{\mathrm{min}})^{\beta} , (ii) p ⁡ ( x ) ∝ exp ⁡ ( − β ⁡ [ x / x min − 1 ] ) p(x)\propto\exp(-\beta[x/x_{\mathrm{min}}-1]) , and (iii) p ⁡ ( x ) ∝ [ 2 − ( x / x min ) β ] p(x)\propto[2-(x/x_{\mathrm{min}})^{\beta}] , including the special case β = 0 \beta=0 leading to core p ⁡ ( x ) = const p(x)=\mathrm{const} . We derive explicit maximum-likelihood estimators and/or efficient numerical methods to find the best-fit parameter values for empirical data. Solutions for the special cases α = β \alpha=\beta are presented, as well. The results are made available as a Python package.



I
Introduction

Non-negative data that is distributed with a “heavy tail” is abundant
Newman 2010
;
Barabási and Pósfai 2016
;
Chotikapanich 2008
;
Clauset et al. 2009
;
Broido and Clauset 2019
. There is a whole zoo of theoretical distributions used to describe such data
Chotikapanich 2008
;
Clauset et al. 2009
;
Broido and Clauset 2019
, one of them the Pareto distribution with a power-law tail
p(x)\propto x^{-\alpha}
where
\alpha>1

Chotikapanich 2008
. This distribution is only non-zero, however, for support
x\geq x_{\mathrm{min}}
because of the function’s pathological behavior at
x=0
. Yet, more often than not, real-world data does not follow a “lower cutoff” behavior, instead the empirical probability density function (pdf) reaches finite values for data points that are smaller
Clauset et al. 2009
;
Virkar and Clauset 2014
.

Previous work derived and presented maximum-likelihood estimation methods to fit the tail observed in the distributions of empirical data, disregarding values below a threshold
x_{\mathrm{min}}

Alstott et al. 2014
;
Clauset et al. 2009
. Doing so is entirely reasonable because the shape of the distribution’s tail strongly determines the outcome of dynamical systems
Newman 2010
;
Pastor-Satorras et al. 2015
or is an indicator for a system’s criticality
Schwabl 2006
. Nonetheless, there might be situations in which the finite, non-zero core of an empirical distribution might be of interest. One such example is the accurate estimation of an empirical contact distribution’s first and second moment which are important for epidemic threshold estimations
Pastor-Satorras et al. 2015
and can both be heavily skewed by outliers. Here, robustly estimating the entire distribution by means of maximum-likelihood estimation may be a more resilient method than simply computing the moments from the data itself.

Therefore, we discuss multiple piece-wise distribution functions that have non-pathological behavior below a threshold, i.e. have non-zero and finite probabilities for support
0\leq x\leq x_{\mathrm{min}}
in the following. Each of the distributions takes an additional shape parameter
\beta
to describe the behavior of the core. For each of the models, we define the log-likelihood and semi-analytical methods to find the parameter values that maximize it given a set of data points. Note that we only present solutions for continuous support
\{x\in\mathbb{R}:x\geq 0\}
.

We make the results available as an open-source Python package
Maier 2023a
;
Maier 2023b
.

II
Methods

II.1
Definitions

We mainly discuss piece-wise Pareto distributions of the form

\displaystyle p(x)=\begin{cases}C\gamma(x,x_{\mathrm{min}},\beta),&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(1)

on the support
x\in\{x^{\prime}\in\mathbb{R}:x\geq 0\}
(with a few exceptions where
x>0
). The parameters are bounded as
\alpha>1
and
x_{\mathrm{min}}>0
. Other bounds will be discussed when appropriate. The respective functions
\gamma
will be referred to as ‘core’ hereinafter. The normalization constant can be found as

\displaystyle C(\alpha,x_{\mathrm{min}},\beta)=\left(\frac{x_{\mathrm{min}}}{\alpha-1}+\int\limits_{0}^{x_{\mathrm{min}}}\gamma(x,x_{\mathrm{min}},\beta)\right)^{-1}.

(2)

Given a set of observations
x_{i}\in\Omega
and a threshold
x_{\mathrm{min}}
we split the data into a set
S\subseteq\Omega
of observations that are smaller than or equal to
x_{\mathrm{min}}
, and a set
\Lambda\subseteq\Omega
that contains observations larger than the threshold, i.e.
\Lambda=\{x_{i}\in\Omega:x_{i}>x_{m}\}
and
S=\Omega-\Lambda
, with
n_{S}\equiv|S|
and
n_{\Lambda}\equiv|\Lambda|
, as well as
n=|\Omega|=n_{S}+n_{\Lambda}
.

The likelihood of a set of observations given a distribution and a parameter set
\{\alpha,x_{\mathrm{min}},\beta\}
is therefore

\displaystyle\mathcal{L}(\Omega|\alpha,x_{\mathrm{min}},\beta)

\displaystyle=C^{n}(\alpha,x_{\mathrm{min}},\beta)\prod_{i=1}^{n_{\Lambda}}\left(\frac{x_{\mathrm{min}}}{x_{i}}\right)^{\alpha}\prod_{i=1}^{n_{S}}\gamma(x_{i},x_{\mathrm{min}},\beta).

(3)

Consequently, the log-likelihood is given as

\displaystyle\ln\mathcal{L}

\displaystyle=n\ln C(\alpha,x_{\mathrm{min}},\beta)-\alpha n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}

\displaystyle\ \ +n_{S}\big<\ln\gamma(x,x_{\mathrm{min}},\beta)\big>_{S}

(4)

where we denote as
\left<f(x)\right>_{X}=(1/n_{X})\sum_{i\in X}f(x_{i})
the average over observations in set
X
. Please note that
\left<\ln\left(x/{x_{\mathrm{min}}}\right)\right>_{\Lambda}=\left<\ln x\right>_{\Lambda}-\ln x_{\mathrm{min}}
, i.e. the average can be taken independently from
x_{\mathrm{min}}
for support regions where the sets
\Lambda
and
S
are constant. Furthermore, we have
\left<\ln\left(x/{x_{\mathrm{min}}}\right)\right>_{\Lambda}>0
as per the definition of
\Lambda
.

II.2
General outline of the procedure to find best-fit parameters

To find parameter values
\hat{\alpha}
,
\hat{x}_{\mathrm{min}}
, and
\hat{\beta}
that maximize the likelihood of a model given a dataset, we proceed as follows.

Typically, we first assume that
x_{\mathrm{min}}
and
\beta
are constant and known. Then we solve the equation
\partial\ln\mathcal{L}/\partial\alpha=0
, finding
\hat{\alpha}
. In a next step, we solve
\partial\ln\mathcal{L}/\partial\beta=0
for
\alpha
to find
\hat{\alpha}_{\beta}
. Then,
\hat{\beta}
is given as the solution of
\hat{\alpha}=\hat{\alpha}_{\beta}
.

Now, consider the following. Define as
Y=(y_{1},y_{2},\dots,y_{m})
the ordered tuple of
unique
elements of
\Omega
. For
x_{\mathrm{min}}\in[y_{i},y_{j})
, the sets
\Lambda
and
S
are constant. Therefore, we can use
\partial\ln\mathcal{L}/\partial x_{\mathrm{min}}=0
in concurrence with the previous solutions to find (
\hat{\alpha}
,
\hat{x}_{\mathrm{min}}
,
\hat{\beta}
), under the condition that
y_{j}\leq\hat{x}_{\mathrm{min}}<y_{j+1}
,
\hat{\alpha}>1
as well as conditions for
\beta
. In general, it is possible that the maximum likelihood is located at boundary value
\hat{x}_{\mathrm{min}}=y_{j}
with
\partial\ln\mathcal{L}/\partial x_{\mathrm{min}}\neq 0
.

With this in mind, iterate through
x_{\mathrm{min}}=y_{1},\dots,y_{m-1}
, construct the respective sets
\Lambda
and
S
, then compute
\hat{\alpha}
and
\hat{\beta}
under the assumption that
x_{\mathrm{min}}=y_{j}=\mathrm{const.}
, afterwards attempt to find a local maximum on the interval
x_{\mathrm{min}}\in[y_{j},y_{j+1})
.

III
Results

III.1
Power-law core

III.1.1
General case

The “pow-Pareto” pdf is given as

\displaystyle p(x)=\begin{cases}C\left(x/x_{\mathrm{min}}\right)^{\beta},&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(5)

for
\beta>-1
and with normalization constant

\displaystyle C=\frac{(\alpha-1)(\beta+1)}{y(\alpha+\beta)}.

(6)

Note that the pdf has a singularity at
x=0
for
-1<\beta<0
but is normalizable nonetheless. We discuss the special case
\beta=0
in Sec.
III.4
.
The log-likelihood is

\displaystyle\ln\mathcal{L}

\displaystyle=n\ln\left(\frac{(\alpha-1)(\beta+1)}{y(\alpha+\beta)}\right)-\alpha n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}

\displaystyle\qquad-\alpha n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S},

(7)

with derivative

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}

\displaystyle=\frac{(\beta+1)n}{(\alpha-1)(\alpha+\beta)}-n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda},

(8)

For constant
\beta
and
x_{\mathrm{min}}
, this yields

\displaystyle\hat{\alpha}=\frac{1}{2}\left(1-\beta+(1+\beta)\sqrt{1+\frac{4n}{(\beta+1)n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}\right)}}\right).

(9)

The second solution leads to values
\hat{\alpha}\leq 1
and can therefore be ignored.

For varying
\beta
we have

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\beta}

\displaystyle=\frac{(\alpha-1)n}{(\beta+1)(\alpha+\beta)}-n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}

(10)

which yields

\displaystyle\hat{\alpha}

\displaystyle=\frac{n+\beta(\beta+1)n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}}{n-(\beta+1)n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}}

(11)

and consequently, by equating Eq. (
9
) and Eq. (
11
) the two solutions

\displaystyle\hat{\beta}_{+}

\displaystyle=-1+\frac{n}{n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}+\sqrt{n_{\Lambda}n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}}}

(12)

\displaystyle\hat{\beta}_{-}

\displaystyle=-1+\frac{n}{n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}-\sqrt{n_{\Lambda}n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}}}

(13)

Only
\hat{\beta}_{+}
generally meets the condition
\beta>-1
, nonetheless, it is computationally cheap to check both solutions.

For regions
x_{\mathrm{min}}\in[y_{j},y_{j+1})
, the sets
\Lambda
and
S
are constant. We have

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial x_{\mathrm{min}}}

\displaystyle=-\frac{n-\alpha n_{\Lambda}+\beta n_{S}}{x_{\mathrm{min}}}

(14)

and therefore

\displaystyle\hat{\alpha}=\frac{n(\beta+1)-\beta n_{\Lambda}}{n_{\Lambda}}

(15)

where we used
n_{S}=n-n_{\Lambda}
. We put this in Eq. (
8
) and solve for
\ln x_{\mathrm{min}}
to find

\displaystyle\ln\hat{x}_{\mathrm{min}}

\displaystyle=\frac{n_{\Lambda}}{(\beta+1)(n-n_{\Lambda})}+\left<\ln x\right>_{\Lambda}.

(16)

Both these results only depend on
\beta
, which is why we can use them in Eq. (
10
) to find

\displaystyle\hat{\beta}

\displaystyle=-1+\frac{n_{\Lambda}-n_{S}}{n_{S}(\left<\ln x\right>_{S}-\left<\ln x\right>_{\Lambda})}.

(17)

Note that because
\left<\ln x\right>_{S}<\left<\ln x\right>_{\Lambda}
, the condition
\beta>-1
is only met if
n_{S}>n_{\Lambda}
.
As described in the Methods section, we can iterate through the ordered tuple
Y
to find the maximum as either of the boundaries of an interval
[y_{j},y_{j+1})
or within the interval.

III.1.2
Special case
\beta=\alpha

The “forced pow-Pareto” pdf is given as

\displaystyle p(x)=\begin{cases}C\left(x/x_{\mathrm{min}}\right)^{\alpha},&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(18)

with

\displaystyle C=\frac{\alpha^{2}-1}{2y\alpha}.

(19)

The log-likelihood is

\displaystyle\ln\mathcal{L}

\displaystyle=n\ln\left(\frac{\alpha^{2}-1}{2y\alpha}\right)-\alpha n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}-\alpha n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S},

(20)

with derivative

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}

\displaystyle=\frac{\left(\alpha^{2}+1\right)n}{\alpha^{3}-\alpha}-n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}-n_{S}\left<\ln\left(\frac{x_{\mathrm{min}}}{x}\right)\right>_{S},

(21)

While this equation is in principle solvable, the three solutions are not very insightful. We can compute the second derivative

\displaystyle\frac{\partial^{2}\ln\mathcal{L}}{\partial\alpha^{2}}

\displaystyle=-\frac{\left(\alpha^{4}+4\alpha^{2}-1\right)n}{\alpha^{2}\left(\alpha^{2}-1\right)^{2}}

(22)

And use both in Newton’s method to find
\hat{\alpha}
as the root of Eq. (
21
).

For regions
x_{\mathrm{min}}\in[y_{j},y_{j+1})
, the sets
\Lambda
and
S
are constant. We have

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial x_{\mathrm{min}}}

\displaystyle=-\frac{n-\alpha n_{\Lambda}+\alpha n_{S}}{x_{\mathrm{min}}}

(23)

and therefore

\displaystyle\hat{\alpha}=\frac{n}{n_{\Lambda}-n_{S}}.

(24)

Note that (i) for
n_{\Lambda}=n_{S}
there is no zero, (ii) for
n_{S}>n_{\Lambda}
the solution for
\hat{\alpha}
becomes negative and is therefore out of our range. We put this result in Eq. (
21
) and solve for
\ln x_{\mathrm{min}}
to find

\displaystyle\ln\hat{x}_{\mathrm{min}}

\displaystyle=1-\frac{n^{2}}{2n_{\Lambda}n_{S}}+\frac{n_{S}\left<\ln x\right>_{S}-n_{\Lambda}\left<\ln x\right>_{\Lambda}}{n_{S}-n_{\Lambda}}.

(25)

We can proceed as above, iterating through the ordered tuple
Y
to find the maximum as either of the boundaries of an interval
[y_{j},y_{j+1})
or within the interval.

III.2
Exponential core

III.2.1
General case

The “exp-Pareto” pdf is defined as

\displaystyle p(x)=\begin{cases}C\exp\Big[-\beta(x/x_{\mathrm{min}}-1)\Big],&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(26)

for
x_{\mathrm{min}}>0
,
\beta\neq 0
, and
\beta\neq\alpha
and with normalization constant

\displaystyle C=\frac{\beta(\alpha-1)}{x_{\mathrm{min}}\Big((\alpha-1)(e^{\beta}-1)+\beta\Big)}.

(27)

The log-likelihood is given as

\displaystyle\ln\mathcal{L}

\displaystyle=n\left[\ln\beta+\ln(\alpha-1)-\ln x_{\mathrm{min}}-\ln\Big((\alpha-1)(e^{\beta}-1)+\beta\Big)\right]

\displaystyle\ \ -\alpha n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}-\beta n_{S}\left(\frac{\left<x\right>_{S}}{x_{\mathrm{min}}}-1\right)

(28)

with derivative

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}

\displaystyle=\frac{n}{\alpha-1}-\frac{n\left(e^{\beta}-1\right)}{(\alpha-1)(e^{\beta}-1)+\beta}-n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda},

(29)

such that for constant
\beta
and
x_{\mathrm{min}}
we find

\displaystyle\hat{\alpha}

\displaystyle=1-\frac{\beta}{2\left(e^{\beta}-1\right)}\left(1-\sqrt{1+\frac{4n\left(e^{\beta}-1\right)}{\beta n_{\Lambda}\left<\ln(x/x_{\mathrm{min}})\right>_{\Lambda}}}\right).

(30)

The second solution to
\alpha
would give
\hat{\alpha}<1
which he have ruled out (note that
\beta/(e^{\beta}-1)>0
for negative and positive beta—the second solution has a plus sign preceding the root, which would yield
\hat{\alpha}<1
). Moreover, we have

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\beta}

\displaystyle=-\frac{(\alpha-1)\left(e^{\beta}(\beta-1)+1\right)n}{\beta\left((\alpha-1)e^{\beta}-\alpha+\beta+1\right)}-n_{S}\left(\frac{\left<x\right>_{S}}{x_{\mathrm{min}}}-1\right).

(31)

For a fixed value of
x_{\mathrm{min}}
, one may find
\hat{\beta}
numerically as the solution to
\partial\ln\mathcal{L}/\partial\beta\big|_{\alpha=\hat{\alpha}}=0
.

If we allow
x_{\mathrm{min}}
to vary, too, we have

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial x_{\mathrm{min}}}

\displaystyle=\frac{-nx_{\mathrm{min}}+n_{\Lambda}x_{\mathrm{min}}\alpha+n_{S}\left<x\right>_{S}\beta}{x_{\mathrm{min}}^{2}}

(32)

for values of
x_{\mathrm{min}}
where the sets
\Lambda
and
S
are constant. Setting Eqs. (
31
) and (
32
) equal to zero and solving for
x_{\mathrm{min}}
gives the conditions

\displaystyle\hat{x}_{\mathrm{min}}

\displaystyle=\frac{\beta n_{S}\left<x\right>_{S}\left((\alpha-1)e^{\beta}-\alpha+\beta+1\right)}{\beta n_{S}\left((\alpha-1)e^{\beta}-\alpha+\beta+1\right)-(\alpha-1)\left(e^{\beta}(\beta-1)+1\right)n},

(33)

\displaystyle\hat{x}_{\mathrm{min}}

\displaystyle=\frac{\beta n_{S}\left<x\right>_{S}}{n-\alpha n_{\Lambda}}.

(34)

Equating both and using the identity
n=n_{S}+n_{\Lambda}
, we can find
\hat{\alpha}
as

\displaystyle\hat{\alpha}=1+\frac{n_{S}}{n_{\Lambda}}\frac{\beta}{e^{\beta}-1}.

(35)

The second solution gives
\alpha=\beta
, which we have ruled out. The solution above (Eq. (
34
)) gives

\displaystyle\hat{x}_{\mathrm{min}}=\left<x\right>_{S}\frac{\beta}{1-\beta/(e^{\beta}-1)}.

(36)

Using this expression in Eq. (
30
) and equating the resulting expression with Eq. (
35
), we find the function

\displaystyle z(\beta)=-2n+n_{\Lambda}\left(1+\sqrt{1+\frac{4\left(e^{\beta}-1\right)n}{\beta n_{\Lambda}\left[\left<\ln x\right>_{\Lambda}-\ln\left<x\right>_{S}+\ln\left(1/\beta+1/\{1-e^{\beta}\}\right)\right]}}\right)

(37)

the root of which gives
\hat{\beta}
.

To find the global maximum of the log-likelihood, one iterates over all intervals
[y_{j},y_{j+1})
checking both at the left boundary and within the interval.

III.2.2
Special case
\beta=\alpha

In
Clauset et al. 2009
, an additional model for non-pathological cores was introduced, namely

\displaystyle p(x)=\begin{cases}C\exp\Big[-\alpha(x/x_{\mathrm{min}}-1)\Big],&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(38)

(or “forced exp-Pareto”) with normalization constant

\displaystyle C=\frac{\alpha(\alpha-1)}{x_{\mathrm{min}}\Big((\alpha-1)e^{\alpha}+1\Big)}.

(39)

Note that for this case we have both continuity in
p(x)
as well as its first derivative at
x=x_{\mathrm{min}}
.

The log-likelihood is given as

\displaystyle\ln\mathcal{L}=n\ln C-\alpha n_{\Lambda}\left(\left<\ln x\right>_{\Lambda}-\ln{x_{\mathrm{min}}}\right)-\alpha n_{S}\left(\frac{1}{x_{\mathrm{min}}}\left<x\right>_{S}-1\right).

(40)

with
\Lambda
and
S
defined as above. The derivative for
\alpha
can be found as

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}

\displaystyle=n\frac{1}{\alpha}+n\frac{1}{\alpha-1}-n\frac{\alpha e^{\alpha}}{(\alpha-1)e^{\alpha}+1}-n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}

\displaystyle\ \ -n_{S}\left(\frac{\left<x\right>_{S}}{x_{\mathrm{min}}}-1\right),

(41)

the zero of which can be found numerically.

For regions where the sets
\Lambda
and
S
are constant, the derivative by
x_{\mathrm{min}}
is given as

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial x_{\mathrm{min}}}=-\frac{n}{x_{\mathrm{min}}}+\frac{\alpha n_{\Lambda}}{x_{\mathrm{min}}}+\frac{\alpha n_{S}\left<x\right>_{S}}{x_{\mathrm{min}}^{2}}

(42)

and therefore

\displaystyle\hat{\alpha}=\frac{nx_{\mathrm{min}}}{n_{\Lambda}+n_{S}\left<x\right>_{S}}.

(43)

Now we can proceed similarly to above, iterating through the ordered set of unique observation values
y_{j}\in Y
. For each pair of observations
(y_{j},y_{j+1})
we can find the numerical solution of the equation

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}\Big|_{\alpha=\hat{\alpha}}=0

(44)

using the bisection method on the interval
x_{\mathrm{min}}\in[y_{j},y_{j+1}]
to find
\hat{x}_{\mathrm{min}}
.

III.3
Algebraic core

III.3.1
General case

We define the “alg-Pareto” pdf as

\displaystyle p(x)=\begin{cases}C\left[2-\left(x/x_{\mathrm{min}}\right)^{\beta}\right],&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(45)

for
\beta>0
and with normalization constant

\displaystyle C=\frac{1}{x_{\mathrm{min}}}\frac{(\alpha-1)(\beta+1)}{2\alpha\beta-\beta+\alpha}.

(46)

Note that the pdf has a singularity at
x=0
for
-1<\beta<0
but is normalizable nonetheless. We discuss the special case
\beta=0
in Sec.
III.4
.

The log-likelihood is given as

\displaystyle\ln\mathcal{L}

\displaystyle=n\ln C-\alpha n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}+n_{S}\left<\ln\left[2-\left(\frac{x}{x_{\mathrm{min}}}\right)^{\beta}\right]\right>_{S},

(47)

In order to find the value of
\alpha
that maximizes
\mathcal{L}
given
x_{\mathrm{min}}
and
\beta
, we compute

\displaystyle\frac{\partial}{\partial\alpha}\ln\mathcal{L}

\displaystyle=-n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}+n\frac{\beta+1}{(\alpha-1)(2\alpha\beta-\beta+\alpha)}.

(48)

The zero of this expression gives us our estimator for the exponent

\displaystyle\hat{\alpha}

\displaystyle=\frac{3\beta+1}{4\beta+2}+\frac{1}{4\beta+2}\sqrt{\frac{(1+\beta)(4+\lambda+\beta(8+\lambda))}{\lambda}},\ \mathrm{with}

(49)

\displaystyle\lambda

\displaystyle=\frac{n_{\Lambda}}{n}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}

(50)

Note that
(3\beta+1)/(4\beta+2)<1
for
\beta>-1
, which is why we disregard the second solution of the above equation that would give us exponents
\hat{\alpha}<1
, i.e. in a parameter regime we exclude.

Next, we want to find the maximum-likelihood estimator for
x_{\mathrm{min}}
for support regions where
\Lambda
and
S
are constant. Then, we find

\displaystyle\frac{\partial}{\partial x_{\mathrm{min}}}\ln\mathcal{L}

\displaystyle=-\frac{n}{x_{\mathrm{min}}}+\frac{\alpha n_{\Lambda}}{x_{\mathrm{min}}}+\frac{n_{S}}{x_{\mathrm{min}}}\left<\frac{1}{2(x_{\mathrm{min}}/x)^{\beta}-1}\right>_{S},

(51)

and thus
\hat{x}_{\mathrm{min}}
is determined by the equation

\displaystyle\left<\frac{1}{2(\hat{x}_{\mathrm{min}}/x)^{\beta}-1}\right>_{S}-\frac{n}{n_{S}}-\frac{n_{\Lambda}}{n_{S}}\left(\frac{3\beta+1}{4\beta+2}+\frac{1}{4\beta+2}\sqrt{\frac{(1+\beta)(4+\lambda+\beta(8+\lambda))}{\lambda}}\right)=0

(52)

where
\hat{\alpha}
is given by Eq. (
49
). Now we can iterate over intervals
x_{\mathrm{min}}\in[y_{j},y_{j+1})
to find the maximum either at interval boundaries or within, using the bisection method.

Unfortunately, for varying
\beta
we have to resort to maximizing Eq. (
47
) numerically. Since we do have a method to find
\hat{x}_{\mathrm{min}}
and
\hat{\alpha}
given
\beta
, we can use a one-dimensional Nelder–Mead method to find
\hat{\beta}
.

III.3.2
Special case
\beta=\alpha

The “forced alg-Pareto” pdf is given as

\displaystyle p(x)

\displaystyle=\begin{cases}C\left[2-\left(x/x_{\mathrm{min}}\right)^{\alpha}\right],&0\leq x\leq x_{\mathrm{min}}\\
C\left(x_{\mathrm{min}}/x\right)^{\alpha},&x>x_{\mathrm{min}}\end{cases}

(53)

\displaystyle C

\displaystyle=\frac{1}{x_{\mathrm{min}}}\frac{\alpha^{2}-1}{2\alpha^{2}}.

(54)

Note that for this case we have both continuity in
p(x)
as well as its first derivative at
x=x_{\mathrm{min}}
.

The log-likelihood is given by

\displaystyle\ln\mathcal{L}

\displaystyle=-n\ln x_{\mathrm{min}}+n\ln(\alpha^{2}-1)-n(\ln 2+2\ln\alpha)

\displaystyle\ \ -\alpha n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}+n_{S}\left<\ln\left[2-\left(\frac{x}{x_{\mathrm{min}}}\right)^{\alpha}\right]\right>_{S}.

(55)

The derivative by
\alpha
(for pre-determined
x_{\mathrm{min}}
) is

\displaystyle\frac{\partial\ln\mathcal{L}}{\partial\alpha}

\displaystyle=-n_{\Lambda}\left<\ln\left(\frac{x}{x_{\mathrm{min}}}\right)\right>_{\Lambda}+\frac{2n\alpha}{\alpha^{2}-1}-\frac{2n}{\alpha}

\displaystyle\ \ -n_{S}\left<\frac{\ln{\left(x/{x_{\mathrm{min}}}\right)}}{2\left({x}/{x_{\mathrm{min}}}\right)^{-\alpha}-1}\right>_{S}.

(56)

The zero of this equation can be found using the Newton–Raphson method.
Since, again, the sets
\Lambda
and
S
are constant on the interval
x_{\mathrm{min}}\in[y_{j},y_{j+1})
, one may proceed by iterating through all data intervals and finding the maximum within each interval with the Nelder–Mead method.

III.4
Uniform core

We define the “uni-Pareto” pdf as

\displaystyle p(x)

\displaystyle=\begin{cases}C&x\leq x_{\mathrm{min}}\\
C(x_{\mathrm{min}}/x)^{\alpha}&x>x_{\mathrm{min}}\end{cases}

(57)

\displaystyle C

\displaystyle=\frac{\alpha-1}{\alpha}\frac{1}{x_{\mathrm{min}}}.

(58)

We compute the log-likelihood as

\displaystyle\ln\mathcal{L}=n\ln\left(\frac{\alpha-1}{\alpha}\frac{1}{x_{\mathrm{min}}}\right)-\alpha n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}

(59)

with derivative

\displaystyle\frac{\partial}{\partial\alpha}\ln\mathcal{L}

\displaystyle=n\left(\frac{1}{\alpha-1}-\frac{1}{\alpha}\right)-n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}

(60)

for constant
x_{\mathrm{min}}
. Demanding
\partial\ln\mathcal{L}/\partial\alpha=0
and
\alpha>1
gives us the estimator

\displaystyle\hat{\alpha}=\frac{1}{2}+\sqrt{\frac{1}{4}+\frac{n}{n_{\Lambda}\left<\ln\frac{x}{x_{\mathrm{min}}}\right>_{\Lambda}}}.

(61)

For regions where
\Lambda
and
S
are constant, we find

\displaystyle\frac{\partial}{\partial x_{\mathrm{min}}}\ln\mathcal{L}

\displaystyle=-n\frac{1}{x_{\mathrm{min}}}+\alpha n_{\Lambda}\frac{1}{x_{\mathrm{min}}},

(62)

so we have to solve

\displaystyle 0

\displaystyle=\frac{n}{(\alpha-1)\alpha}-n_{\Lambda}\left<\ln x\right>_{\Lambda}+n_{\Lambda}\ln x_{\mathrm{min}}

(63)

\displaystyle 0

\displaystyle=\frac{\alpha n_{\Lambda}-n}{x_{\mathrm{min}}}.

(64)

Then

\displaystyle\hat{\alpha}=\frac{n}{n_{\Lambda}}

(65)

solves the second equation. Putting this solution in the first equation gives

\displaystyle\ln\hat{x}_{\mathrm{min}}

\displaystyle=\left<\ln x\right>_{\Lambda}-\frac{n_{\Lambda}}{n-n_{\Lambda}}.

(66)

The determinant of the Hessian of this problem gives

\displaystyle\mathrm{det}(H)=-n_{\Lambda}^{2}\exp\Big(\dots\Big),

(67)

which, for a two-dimensional problem like this, means that the only extremum
(\hat{a},\hat{x}_{\mathrm{min}})
is a saddle point, i.e. one cannot find a better maximum than given by
x_{\mathrm{min}}\in Y
, which in turn means that iterating over unique observation values and then finding
\hat{x}_{\mathrm{min}}=y_{j}
that maximizes
\ln\mathcal{L}
suffices.

IV
Discussion and conclusion

We discussed how to fit three classes of piece-wise Pareto-like distributions to data using maximum-likelihood estimation, with the distributions reaching non-zero and finite values for support region
0\leq x\leq x_{\mathrm{min}}
.

The results presented in this study are neither particularly insightful nor exciting. Nonetheless, they might be of use to future analyses dealing with data that is distributed according to any of the proposed shapes.

In the future and if the use case demands it, the results may be extended to discrete random variates.

Furthermore, in a future analysis, the principle of splitting observations into sets of values below and above a threshold
x_{\mathrm{min}}
might be used for efficiently minimizing the Kullback-Leibler divergence between piece-wise finite-core models and data if the data is only accessible in binned form.

Appendix A
Properties of the alg-Pareto distribution

The mean is finite for
\alpha>2
and given as

\displaystyle\left<x\right>

\displaystyle=x_{\mathrm{min}}\frac{\left(\alpha-1\right)\left(\beta+1\right)\left(\beta+\left(\alpha-2\right)\left(\beta+1\right)+2\right)}{\left(\alpha-2\right)\left(\beta+2\right)\left(2\alpha\beta+\alpha-\beta\right)}.

(68)

The second moment is finite for
\alpha>3
and given as

\displaystyle\left<x^{2}\right>

\displaystyle=x_{\mathrm{min}}^{2}\frac{\left(\alpha-1\right)\left(\beta+1\right)\left(3\beta+\left(\alpha-3\right)\left(2\beta+3\right)+9\right)}{3\left(\alpha-3\right)\left(\beta+3\right)\left(2\alpha\beta+\alpha-\beta\right)}.

(69)

The cdf is

\displaystyle F{\left(x\right)}=\begin{cases}\frac{x}{x_{\mathrm{min}}}\left(2\beta+2-\left(\frac{x}{x_{\mathrm{min}}}\right)^{\beta}\right)\frac{\alpha-1}{2\alpha\beta+\alpha-\beta}&\text{for}\>x\leq x_{\mathrm{min}}\\
1-\frac{\beta+1}{2\alpha\beta+\alpha-\beta}\left(\frac{x_{\mathrm{min}}}{x}\right)^{\alpha-1}&\text{otherwise}\end{cases}.

(70)

The inverse of the cdf is

\displaystyle F^{-1}(q)

\displaystyle=x_{\mathrm{min}}\left(\frac{\beta+1}{(1-q)(2\alpha\beta+\alpha-\beta)}\right)^{1/({\alpha-1})}

(71)

\displaystyle\mathrm{for\ }q

\displaystyle\geq\frac{(\alpha-1)(2\beta+1)}{2\alpha\beta+\alpha-\beta}.

(72)

For values of
q
smaller than the critical probability, the inverse has to be found as the root of the function

\displaystyle\varphi(x)=-q+\frac{x}{x_{\mathrm{min}}}\left(2\beta+2-\left(\frac{x}{x_{\mathrm{min}}}\right)^{\beta}\right)\frac{\alpha-1}{2\alpha\beta+\alpha-\beta}

(73)

with derivative

\displaystyle\varphi^{\prime}(x)=\left[2-\left(\frac{x}{x_{\mathrm{min}}}\right)^{\beta}\right]\frac{(\alpha-1)(\beta+1)}{x_{\mathrm{min}}(2\alpha\beta+\alpha-\beta)}.

(74)

The inverse of the cdf can be used to find median and percentiles, and for sampling from the distribution by setting random variates
X=F^{-1}(q)=q
with
q\sim\mathcal{U}(0,1)
being a uniform random variate on the interval
[0,1)
.

Appendix B
Properties of exp-Pareto distribution

The mean is finite for
\alpha>2
and given as

\displaystyle\left<x\right>=x_{\mathrm{min}}\left(\frac{\alpha(2-\alpha+\beta)-\beta}{(\alpha-2)\left((\alpha-1)(e^{\beta}-1)+\beta\right)}+\frac{1}{\beta}\right)

(75)

The second moment finite for
\alpha>3
and given as

\displaystyle\left<x^{2}\right>=\frac{(\alpha-1)y^{2}\left(\alpha\left(-\beta(\beta+2)+2e^{\beta}-2\right)-6e^{\beta}+\beta(\beta(\beta+3)+6)+6\right)}{(\alpha-3)\beta^{2}\left((\alpha-1)(e^{\beta}-1)+\beta\right)}.

(76)

The cdf is

\displaystyle F{\left(x\right)}=\begin{cases}\frac{(\alpha-1)e^{\beta}}{(\alpha-1)\left(e^{\beta}-1\right)+\beta}\left(1-e^{-\beta x/x_{\mathrm{min}}}\right)&\text{for}\>x\leq x_{\mathrm{min}}\\
1-\frac{\beta}{\beta+(\alpha-1)(e^{\beta}-1)}\left(\frac{x_{\mathrm{min}}}{x}\right)^{\alpha-1}&\text{otherwise}.\end{cases}

(77)

The inverse of the cdf is

\displaystyle F^{-1}(q)=\begin{cases}x_{\mathrm{min}}\left(\frac{(1-q)\left((\alpha-1)e^{\beta}-\alpha+\beta+1\right)}{\beta}\right)^{1/{(1-\alpha)}}&q\leq 1-\frac{\beta}{(\alpha-1)(e^{\beta}-1)+\beta}\\
-\frac{x_{\mathrm{min}}}{\beta}\ln\left(1+q\left(\frac{e^{-\beta}(\alpha-\beta-1)}{\alpha-1}-1\right)\right)&\text{otherwise}\end{cases}

(78)

and can be used to find median and percentiles, and for sampling from the distribution by setting random variates
X=F^{-1}(q)=q
with
q\sim\mathcal{U}(0,1)
being a uniform random variate.

Properties of the pow-Pareto distribution

The mean is finite for
\alpha>2
and given as

\displaystyle\left<x\right>=x_{\mathrm{min}}\frac{2(\alpha-1)\alpha(\beta+1)}{\left(\alpha^{2}-4\right)(\alpha+\beta)}.

(79)

The second moment is finite for
\alpha>3
and given as

\displaystyle\left<x^{2}\right>=x_{\mathrm{min}}^{2}\frac{(\alpha-1)(\beta+1)}{(\alpha-3)(\beta+3)}

The cdf is

\displaystyle F{\left(x\right)}=\begin{cases}\frac{\alpha-1}{\alpha+\beta}\left(\frac{x}{x_{\mathrm{min}}}\right)^{\beta+1}&\text{for}\>x\leq x_{\mathrm{min}}\\
1-\frac{\beta+1}{\alpha+\beta}\left(\frac{x_{\mathrm{min}}}{x}\right)^{\alpha-1}&\text{otherwise}.\end{cases}

(81)

(82)

and can be used to find median and percentiles, and for sampling from the distribution by setting random variates

Appendix D
MLE estimators for a generative contact distribution model: The Santa Fe model

The following is not incredibly related to the rest of this paper other than that it deals with fitting a model that comes with a heavy tail and a finite core, but we still think it should be written down somewhere so it will not get lost in the nirvana of tex-files, and this appendix does not feel like the worst place to do it.

A generative model to obtain long-tail contact distributions was proposed in
Cantwell et al. 2020
. As the cited work was the result of a group effort during the Santa Fe complex system’s summer school 2018, we will refer to the model as the “Santa Fe” model hereinafter.
In this modeling framework, every individual is associated with a normally distributed propensity
Z_{i}\sim\mathcal{N}(0,1)
to form contacts. Additionally, every possible connection
(i,j)
is associated with a normally distributed contact propensity
Y_{ij}\sim\mathcal{N}(0,1)
. Then, we can construct a mixed-effect
(i,j)
-specific contact propensity as

\displaystyle X_{ij}=\sqrt{\rho}(Z_{i}+Z_{j})+\sqrt{1-2\rho}Y_{ij},\qquad 0\leq\rho<1/2.

(83)

The first term of this equation implies that the propensity for a single contact to be established between two nodes can potentially be influenced by the individuals’ respective propensities to build contacts at all. The influence of individual contact propensities can be controlled with the parameter
\rho
. In
Cantwell et al. 2020
it was shown that even though the
X_{ij}
are normally distributed, thresholding them by a value
t
that determines whether or not a contact is actually established can lead to a heavy-tailed contact distribution of asymptotic form

\displaystyle p_{k}

\displaystyle=\frac{1}{N-1}\sqrt{\frac{1-\rho}{\rho}}\mathrm{exp}\left[-\left(\frac{1-2\rho}{2\rho}\right)y_{k}^{2}+ty_{k}\left(\frac{\sqrt{1-\rho}}{\rho}\right)-\frac{t^{2}}{2\rho}\right],

(84)

\displaystyle y_{k}

\displaystyle=\Phi^{-1}\left(1-\frac{k}{n-1}\right),

(85)

with
\Phi^{-1}(x)
being the inverse cdf of the normal distribution
\mathcal{N}(0,1)
. Note that this approximation is valid for
N\gg 1
individuals in the system and contacts per individuals
k>0
(even though the model perfectly allows for
k=0
—only the approximation fails).

While a method to fit degree distributions was presented in
Cantwell et al. 2020
, it only relies on fixing
t
and
\rho
such that the mean and variance of the underlying data match those of the theoretical values of the model. Since the variance is not very resilient with regard to fluctuations in the tail, we want to take a maximum-likelihood approach to obtain
t
and
\rho
instead.

Given a set of observations
k_{i}\in\Omega
, the log-likelihood to observe the data given the model is

\displaystyle\ln\mathcal{L}

\displaystyle=-n\ln{\left(N-1\right)}-nt\left<y_{k}\right>\frac{\sqrt{1-\rho}}{\rho}-n\left<y_{k}^{2}\right>\frac{1-2\rho}{2\rho}

\displaystyle\ \ +\frac{n}{2}\big(\ln{\left(1-\rho\right)-\ln{\left(\rho\right)}}\big)-\frac{nt^{2}}{2\rho}.

(86)

Demanding
\partial\ln\mathcal{L}/\partial t=0
yields

\displaystyle\hat{t}=\left<y_{k}\right>\sqrt{1-\rho}.

(87)

With
\partial\ln\mathcal{L}/\partial\rho=0
we find

\displaystyle\hat{\rho}=\frac{\left<y_{k}^{2}\right>-\left<y_{k}\right>^{2}}{\left<y_{k}^{2}\right>-\left<y_{k}\right>^{2}+1}.

(88)

In practice, the system size
N
depends on the experimental conditions under which the data was collected. Because the likelihood of observing large values of contact numbers (i.e. on the order of the system size) is vanishingly small for large social systems, the exact number of
N
will not necessarily matter too much.
