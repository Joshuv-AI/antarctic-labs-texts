Linear programming on the Stiefel manifold Thanks: Accepted by SIAM J. Optim.
Mengmeng Song, Yong Xia

Abstract
Linear programming on the Stiefel manifold (LPS) is studied for the first time. It aims at minimizing a linear objective function over the set of all p p -tuples of orthonormal vectors in ℝ n {\mathbb{R}}^{n} satisfying k k additional linear constraints. Despite the classical polynomial-time solvable case k = 0 k=0 , general (LPS) is NP-hard. According to the Shapiro-Barvinok-Pataki theorem, (LPS) admits an exact semidefinite programming (SDP) relaxation when p ⁡ ( p + 1 ) / 2 ≤ n − k p(p+1)/2\leq n-k , which is tight when p = 1 p=1 . Surprisingly, we can greatly strengthen this sufficient exactness condition to p ≤ n − k p\leq n-k , which covers the classical case p ≤ n p\leq n and k = 0 k=0 . Regarding (LPS) as a smooth nonlinear programming problem, we reveal a nice property that under the linear independence constraint qualification, the standard first- and second-order local necessary optimality conditions are sufficient for global optimality when p + 1 ≤ n − k p+1\leq n-k .

Introduction

The Stiefel manifold
[
36
]
is the set of all
p
-tuples of orthonormal vectors in
{\mathbb{R}}^{n}
where
p\in\{1,\cdots,n\}
. We denote it by

St_{n,p}=\{X\in{\mathbb{R}}^{n\times p}:~X^{T}X=I_{p}\},

where
I_{p}
is the identity matrix of order
p
. The two extreme cases
St_{n,1}
and
St_{n,n}
correspond to the unit sphere and “orthogonal group”, respectively.
St_{n,p}
is connected if
p<n
, and has two connected components if
p=n

[
30
]
.

The fundamental linear optimization on the Stiefel manifold
[
1
]
reads as

\min_{X\in St_{n,p}}{\rm tr}(A_{0}X),

(LS)

where
A_{0}\in{\mathbb{R}}^{p\times n}
and
{\rm tr}(\cdot)
is the trace of matrix
(\cdot)
. (
LS
) can be globally solved by the singular value decomposition
[
43
]
, and the optimal value is equal to minus the sum of all singular values of
A_{0}
.
In fact, (
LS
) dates back to von Neumann’s trace inequality
[
38
]
. Furthermore, (
LS
) is equivalent to the minimization over the convex hull of
St_{n,p}
, which can be exactly characterized by linear matrix inequalities
[
45
]
.
Problem (
LS
) has an application in the projection onto
St_{n,p}

[
19
,
27
,
31
]
, more precisely,

\arg\min_{X\in St_{n,p}}\|A_{0}^{T}-X\|_{F}^{2}=\arg\min_{X\in St_{n,p}}{\rm tr}(-A_{0}X),

(1)

where
\|\cdot\|_{F}
is the Frobenius norm.

In this paper, we consider the following linear programming on the Stiefel manifold:

\begin{array}[]{cl}\min&{\rm tr}(A_{0}X)\\
{\rm s.t.}&X\in E_{n,p,k}\triangleq\{X\in St_{n,p}:~a_{i}^{l}\leq{\rm tr}(A_{i}X)\leq a_{i}^{u},~i=1,\cdots,k\},\end{array}

(LPS)

where
A_{i}\in{\mathbb{R}}^{p\times n}
,
a_{i}^{l}\in{\mathbb{R}}\cup\{-\infty\},
and
a_{i}^{u}\in{\mathbb{R}}\cup\{+\infty\}
for
i=1,\cdots,k
. We assume
E_{n,p,k}\neq\emptyset
. (
LPS
) encompasses several important problem instances, namely binary linear programming (Example
2.1
), Hadamard conjecture (Example
2.3
), and linear sum assignment problem (Example
2.4
), as special cases. Notably, the first one highlights NP-hardness of general (
LPS
). (
LPS
) also has applications in a class of minimax Stiefel manifold optimization problems (Example
2.5
). Moreover, (
LPS
) serves as the crucial subproblem in each iteration of both extended sequential linear programming (Section
2.2.1
) and extended Kelley’s cutting plane method (Section
2.2.2
).
These two methods are utilized to address the constrained optimization problem under an additional Stiefel manifold constraint.

Note that (
LPS
) is not a manifold optimization problem except some special cases, such as (
LS
).
The feasible set of (
LPS
),
E_{n,p,k}
, may not be a manifold, even without inequality constraints and with only one equality constraint, see the discussion in Section
5
.
Problem (
LPS
) is the linear programming problem on the Stiefel manifold, thus is a special class of constrained manifold optimization (CMO).
CMO refers to the constrained optimization problem with an additional manifold constraint, see
[
25
,
42
,
48
]
.
Globally solving methods of CMO usually assume geodesically convexity of the feasible set, for example,
[
42
]
. However, even the simple case
E_{n,1,1}
, which corresponds to the intersection of a unit sphere and a linear inequality constraint, is not geodesically convex if it contains more than a half of the sphere but not the entire sphere
[
37
]
.
Other CMO-solving methods that can be applied to (
LPS
) cannot gurantee convergence to the globally optimal solution, such as the augmented Lagrangian method and the exact penalty method presented by Liu and Boumal
[
25
]
.
If we regard (
LPS
) as an nonlinear programming (NLP) problem, it is also hard to globally solve due to the presence of
p(p+1)/2
nonconvex quadratic constraints
[
26
]
.

Fortunately, the concept of hidden convexity has unveiled novel prospects for globally solving nonconvex problems, attracting significant attention within the research community.
As defined in
[
44
]
,

hidden convexity
refers to the property of having a convex reformulation and allowing for a polynomial-time solving method.
Hidden convexity is often analyzed through convex relaxation exactness, strong duality, and optimality conditions, etc.

Based on the representation of
St_{n,p}
, (
LPS
) is a case of quadratic matrix optimization (QMP) problems
[
7
]
.
Beck
[
8
]
showed that QMP with a limited number of linear constraints admits an exact semidefinite programming (SDP) relaxation by using the classical Shapiro-Barvinok-Pataki theorem
[
5
,
29
,
33
]
.
Furthermore, in that case, the globally optimal solution of QMP can be extracted from that of the SDP relaxation.
It is a direct corollary that (
LPS
) with
p(p+1)/2\leq n-k
is hidden convex. We illustrate in Example
4.13
that this condition is tight when
p=1

[
8
]
, but fails to hold true in case
p\geq\sqrt{2n}
.
To our surprise, by carefully analyzing the structure of
E_{n,p,k}
, we can greatly strengthen the condition to
p\leq n-k
. The new result implies hidden convexity of (
LS
) by setting
p\leq n
and
k=0
.

For hidden convex optimization without any local nonglobal minimizer, it could be expected to characterize global optimality based on local information.
It is known that the first- and
second-order local necessary optimality conditions are sufficient for global optimality of
the homogeneous trust-region subproblem
[
30
]
,
QMP problems arising from high-rank Burer-Monteiro factorizations
[
11
]
of SDP problems
[
10
,
39
]
, and so on.
For hidden convex optimization with at least one local nonglobal minimizer, local optimality conditions are characterized case by case.
The nonconvex trust-region subproblem has at most one local nonglobal minimizer
[
28
]
, at which the first- and second-order sufficient optimality conditions are necessary
[
40
]
.
This property is extended to the homogeneous quadratic optimization with two quadratic constraints
[
34
]
and the problem jointing trust-region subproblem with convex optimization
[
35
]
.

Our second contribution in this paper is to show that
under the linear independence constraint qualification (LICQ), the first- and second-order
local
necessary optimality conditions are sufficient for the
global
optimality of (
LPS
) when
p+1\leq n-k
.

The remainder of this paper is organized as follows.
Section 2 gives plenty of applications of (
LPS
).
Section 3 obtains an SDP relaxation of (
LPS
) via two approaches and an exactness result inheriting from that of QMP.
Section 4 establishes a significantly strengthened sufficient condition for the exactness of the same SDP relaxation. Section 5 characterizes global optimality by the standard first- and second-order necessary local optimality conditions. Conclusions and open questions are presented in Section 6.

2.1
Classical (
LPS

We present classical optimization models that can be reformulated as (

Our main focus is to investigate the computational complexity of globally solving (

Example 2.1
.

Binary linear programming is a variant of linear programming in which the variables are additionally constrained to be either
-1
or
1

[

Let

\begin{array}[]{cl}\min\limits_{X\in St_{n,1}}&\sqrt{n}a^{T}X\\
{\rm s.t.}&\sqrt{n}AX\leq b,\\
&-\frac{1}{\sqrt{n}}\leq X_{i}\leq\frac{1}{\sqrt{n}},~i=1,\cdots,n,\end{array}

since

\{-1,1\}^{n}=\left\{\sqrt{n}X:~-\frac{1}{\sqrt{n}}\leq X_{i}\leq\frac{1}{\sqrt{n}},~i=1,\cdots,n,~X\in St_{n,1}\right\}.

(2)

The NP-hardness of the binary linear programming
[

]

(

). For completeness, we also present a proof in the Appendix.

Proposition 2.2
.

General (

) is NP-hard.

Hadamard conjecture is another (

.

A Hadamard matrix is a square matrix with entries of either

It has abundant applications in design theory, binary codes and so on, see

The longstanding Hadamard conjecture focuses on the existence of Hadamard matrices for

The existence of a Hadamard matrix with dimension

Example 2.4
.

Linear sum assignment problem

2.2
Methods of solving CMO with (
LPS
) as the subproblem

We demonstrate the applicability of (
LPS
) as the vital subproblem in both extended sequential linear programming and extended Kelley’s cutting plane method for solving CMO.

2.2.1
Extended sequential linear programming

Sequential linear programming (SLP) was developed by Griffith and Stewart
[
20
]
for solving NLP problems. The SLP approach converts an NLP problem into a series of linear programming (LP) problems using the first-order Taylor expansion.

Consider the constrained optimization problem on the Stiefel manifold
St_{n,p}
:

\begin{array}[]{cl}\min\limits_{X\in St_{n,p}}&f_{0}(X)\\
{\rm s.t.}&a_{i}^{l}\leq f_{i}(X)\leq a_{i}^{u},\ i=1,\cdots,k,\end{array}

where
k\geq 0
,
a_{i}^{l}\in{\mathbb{R}}\cup\{-\infty\},\ a_{i}^{u}\in{\mathbb{R}}\cup\{+\infty\}
for
i=1,\cdots,k
, and
f_{i}
is first-order differential for
i=0,1,\cdots,k
.
To solve (
2.2.1
), we extend SLP from the Euclidean space to the Stiefel manifold
St_{n,p}
. In iteration
t+1
, we solve the
(
LPS
)-subproblem

\begin{array}[]{cl}\min\limits_{X\in St_{n,p}}&\nabla f_{0}(X^{t})^{T}(X-X^{t})\\
{\rm s.t.}&a_{i}^{l}\leq\nabla f_{i}(X^{t})^{T}(X-X^{t})+f_{i}(X^{t})\leq a_{i}^{u},\ i=1,\cdots,k,\end{array}

where
X^{t}
is obtained from iteration
t
and
\nabla f
represents the gradient of function
f
.
It is worth noting that the convergence result of the original SLP typically requires an additional trust-region constraint such as

{\|X-X^{t}\|}_{F}^{2}\leq\delta^{t}

(9)

in each iteration, where
\delta^{t}>0
represents the square of the trust-region radius.
For points
X
and
X^{t}
in
St_{n,p}
, (
9
) is equivalent to the linear constraint

{\rm tr}((X^{t})^{T}X)\geq p-\delta^{t}/2.

Thus, the involved subproblem remains an (
LPS
) case.

2.2.2
Extended Kelley’s cutting plane method

Kelley’s cutting plane method, introduced by Kelley
[
23
]
, is a classical approach for solving unconstrained convex problems that may be nonsmooth. If there exists a globally optimal point, the problem can be reformulated as a linear minimization problem over a compact convex set, by a similar approach used in (
5
).

In each iteration of Kelley’s cutting plane method, a linear minimization problem is solved under the constraints of updated cutting planes. To maintain manageable complexity, nonbinding constraints are often dropped in each step
[
26
]
. Kelley’s method converges to the optimal solution under mild assumptions
[
23
]
.

We consider an extension of Kelley’s cutting plane method to solve the problem under an additional Stiefel manifold constriant:

\begin{array}[]{cl}\min\limits_{X\in St_{n,p}\cap\Omega}&{\rm tr}(A_{0}X),\end{array}

(10)

where
\Omega
is a closed convex set in
\mathbb{R}^{n\times p}
.
In each iteration, we keep
St_{n,p}
and update the polyhedron that contains
\Omega
using the same approach as in the original Kelley’s cutting plane method. Consequently, each iteration requires solving a linear programming problem on
St_{n,p}
, which is an instance of (
LPS
).
The convergence result remains, as the sequence of objective values will monotonically decrease in the same way as the original Kelley’s cutting plane method.

A more recent advancement was made by Drori and Teboulle
[
18
]
, who presented a variant of Kelley’s cutting plane method with an optimal convergence rate. It is unknown whether this optimal method can be extended to solve (
10
).

3
SDP relaxation

We first present a direct SDP relaxation for (

) in Section
3.1
. In Section

, the same relaxation is reobtained based on the QMP reformulation of (

3.1
The first approach

The nonconvexity of (
LPS
) comes from the quadratic equality constraints due to
St_{n,p}
. We start from the geometric characteristics of
St_{n,p}
.

Lemma 3.6
.

(
[
45
, Lemma 1]
)

The convex hull of
St_{n,p}
is

\{X\in{\mathbb{R}}^{n\times p}:~X^{T}X\preceq I_{p}\}.

(11)

Replacing
St_{n,p}
with (
11
) yields the conic convex optimization relaxation:

\begin{array}[]{cl}\min\limits_{X\in{\mathbb{R}}^{n\times p}}&{\rm tr}(A_{0}X)\\
{\rm s.t.}&a_{i}^{l}\leq{\rm tr}(A_{i}X)\leq a_{i}^{u},~i=1,\cdots,k,\\
&X^{T}X\preceq I_{p}.\end{array}

(CR)

For
X\in{\mathbb{R}}^{n\times p}
, define

Y=\begin{bmatrix}I_{n}&X\\
X^{T}&I_{p}\end{bmatrix}\in{\mathbb{S}}^{n+p}.

(12)

According to the following congruent transformation

Y=\begin{bmatrix}I_{n}&0\\
X^{T}&I_{p}\end{bmatrix}\begin{bmatrix}I_{n}&0\\
0&I_{p}-X^{T}X\end{bmatrix}\begin{bmatrix}I_{n}&X\\
0&I_{p}\end{bmatrix},

(13)

it holds that

X^{T}X\preceq I_{p}\Longleftrightarrow Y\succeq 0.

(14)

By (
12
) and (
14
), the conic convex optimization (
CR
) is equivalent to the following
SDP problem:

\begin{array}[]{cl}\min\limits_{Y\in{\mathbb{S}}^{n+p}}&{\rm tr}(B_{0}Y)\\
{\rm s.t.}&a_{i}^{l}\leq{\rm tr}(B_{i}Y)\leq a_{i}^{u},~i=1,\cdots,k,\\
&Y_{[1:n]}=I_{n},\ Y_{[n+1:n+p]}=I_{p},\\
&Y\succeq 0,\end{array}

(SDR)

where

B_{i}=\frac{1}{2}\begin{bmatrix}0_{n}&A_{i}^{T}\\
A_{i}&0_{p}\end{bmatrix}{\rm\ for\ }i=0,1,\cdots,k.

(15)

We present the relationships among (
LPS
), (
CR
), and (
SDR
) in the following, and put the proofs in the Appendix.

Lemma 3.7
.

Suppose
\mathcal{F}\eqref{eq:LPS-SDP3}\neq\emptyset
. Then
(

Proposition 3.8
.

If (

SDR
) is exact, i.e.,
v\eqref{eq:LPS-SDP3}=v\eqref{eq:LP_s}
.

3.2
The second approach

In this subsection, we reestablish the SDP relaxation (
SDR
) by first reformulating (
LPS
) as a case of QMP
[
7
]
and then employing its SDP relaxation presented in
[
8
]
.
QMP is the quadratically constrained quadratic optimization in terms of a matrix variable,

\begin{array}[]{cl}\min\limits_{X\in{\mathbb{R}}^{n\times p}}&q_{0}(X)\\
{\rm s.t.}&q_{i}(X)\leq(=)0,~i=1,\cdots,m,\end{array}

(QMP)

where each involved quadratic function is of the form

q_{i}(X)={\rm tr}(XQ_{i}X^{T})+2{\rm tr}(A_{i}X)+a_{i},

with
Q_{i}\in{\mathbb{R}}^{p\times p}
,
A_{i}\in{\mathbb{R}}^{p\times n}
, and
a_{i}\in{\mathbb{R}}
for
i=0,\cdots,m
.

Beck
[
8
]
equivalently homogenized QMP as

\begin{array}[]{cl}\min\limits_{X\in{\mathbb{R}}^{n\times p},\ Z\in{\mathbb{R}}^{p\times p}}&{\rm tr}\left(\begin{bmatrix}\frac{a_{0}}{n}I_{n}&A_{0}^{T}\\
A_{0}&Q_{0}\end{bmatrix}\begin{bmatrix}I_{n}&X\\
X^{T}&Z\end{bmatrix}\right)\\
{\rm s.t.}&{\rm tr}\left(\begin{bmatrix}\frac{a_{i}}{n}I_{n}&A_{i}^{T}\\
A_{i}&Q_{i}\end{bmatrix}\begin{bmatrix}I_{n}&X\\
X^{T}&Z\end{bmatrix}\right)\leq(=)0,\ i=1,\cdots,m,\\
&X^{T}X=Z.\end{array}

Denote

C_{i}=\begin{bmatrix}\frac{a_{i}}{n}I_{n}&A_{i}^{T}\\
A_{i}&Q_{i}\end{bmatrix}{\rm\ for\ }i=0,\cdots,m,\ {\rm and}~Y=\begin{bmatrix}I_{n}&X\\
X^{T}&Z\end{bmatrix}.

According to Schur’s complement theorem, we have

\displaystyle X^{T}X=Z\Longleftrightarrow Y\succeq 0{\rm\ and\ }{\rm rank}(Y)=n.

Dropping the rank constraint leads to the following SDP
relaxation
[
8
]

\begin{array}[]{cl}\min\limits_{Y\in{\mathbb{R}}^{(n+p)\times(n+p)}}&{\rm tr}\left(C_{0}Y\right)\\
{\rm s.t.}&{\rm tr}\left(C_{i}Y\right)\leq(=)0,\ i=1,\cdots,m,\\
&Y_{[1:n]}=I_{n},\\
&Y\succeq 0.\end{array}

(16)

The following exactness result was presented based on the classical Shapiro-Barvinok-Pataki theorem
[
5
,
29
,
33
]
, which can be found in Remark
3.11
.

Lemma 3.9
.

(
[
8
, Theorem 2.2]
)

If problem (
16
) is solvable and
m\leq n
, then problem (
QMP
) is solvable and
{\rm val}\eqref{eq:qapc2}={\rm val}\eqref{eq:QMP}
.

Problem (
LPS
) reads as a QMP case

\begin{array}[]{cl}\min\limits_{X\in{\mathbb{R}}^{n\times p}}&{\rm tr}(A_{0}X)\\
{\rm s.t.}&a_{i}^{l}\leq{\rm tr}(A_{i}X)\leq a_{i}^{u},~i=1,\cdots,k,\\
&{\rm tr}(XE^{ij}X^{T})=\delta_{ij},~1\leq i\leq j\leq p,\end{array}

(17)

where
\delta_{ij}=e_{i}^{T}e_{j}
is the Kronecker delta. Applying the relaxation (
16
) to (
17
) gives

\begin{array}[]{cl}\min\limits_{Y\in{\mathbb{R}}^{{(n+p)}\times{(n+p)}}}&{\rm tr}(B_{0}Y)\\
{\rm s.t.}&a_{i}^{l}\leq{\rm tr}(B_{i}Y)\leq a_{i}^{u},~i=1,\cdots,k,\\
&{\rm tr}(E^{ij}Y_{[n+1:n+p]})=\delta_{ij},~1\leq i\leq j\leq p\Leftrightarrow Y_{[n+1:n+p]}=I_{p},\\
&Y_{[1:n]}=I_{n},\\
&Y\succeq 0,\end{array}

(18)

where
B_{0},\cdots,B_{k}
are defined in (
15
).
The relaxation (
18
) coincides with our relaxation (
SDR
).

3.3
Exactness

Under the assumption that

a_{i}^{l}=a_{i}^{u}{\rm\ or\ }a_{i}^{l}=-\infty{\rm\ or\ }a_{i}^{u}=+\infty,\ \forall i=1,\cdots,k,

(19)

problem (
17
) is a QMP case with

k+p(p+1)/2
constraints.
As a direct corollary of Lemma
3.9
, (
18
) (or equivalently, (
SDR
))
is exact when

\frac{p(p+1)}{2}\leq n-k.

(20)

Note that the Shapiro-Barvinok-Pataki theorem
[
5
,
29
,
33
]
plays a key role in the exactness proof of Lemma
3.9
.
To get rid of the assumption (

), we slightly extend the Shapiro-Barvinok-Pataki theorem to the bilateral case.

Lemma 3.10
.

Let
n_{1}>n_{2}
. Consider
\mathcal{B}:=\{Y\in{\mathbb{S}}^{n_{1}}:\ Y\succeq 0,\ a_{i}^{l}\leq{\rm tr}(B_{i}Y)\leq\ a_{i}^{u},~i=1,\cdots,m\}
and assume

. If

, then

(21)

holds for all

.

Remark 3.11
.

The original Shapiro-Barvinok-Pataki theorem can be seen as a specific case of Lemma
3.10
when the additional condition (
19
) is satisfied.
Expanding upon this, it is straightforward to get Lemma

.
To illustrate, let us consider an extreme point

of the set

Then,

remains an extreme point of the following set

Applying the original Shapiro-Barvinok-Pataki theorem to the set (

) yields the result (

).

As mentioned above, the exactness result of (

) under conditions (

) and (

Proposition 3.12

\mathcal{F}\eqref{eq:LPS-SDP3}\neq\emptyset

4

On the one hand, we use the following example to show that condition (

) when

.

Example 4.13
.

Consider an instance of (

,

, and

\begin{array}[]{cl}\min\limits_{X\in St_{2,1}}&-x_{1}-x_{2}\\

&x_{2}\leq 0.\end{array}

The relaxation (

By Lemma

On the other hand, when

We now present our strengthened result.

Theorem 4.14
.

When
p\leq n-k
,

v\eqref{eq:LPS-SDP3}=v\eqref{eq:LP_s}
.

Proof 4.15
.

Without loss of generalization, we assume that
\mathcal{F}\eqref{eq:LPS-SDP3}\neq\emptyset
. Otherwise,
v\eqref{eq:LPS-SDP3}=v\eqref{eq:LP_s}=+\infty
. Since the objective function of (
SDR
) is linear, there exists an optimal solution of (
SDR
) satisfying

Y\in\mathcal{E}(\mathcal{F}\eqref{eq:LPS-SDP3})
.
According to Proposition
3.8
, it is sufficient to show that
{\rm rank}(Y)\leq n
.
Suppose, on the contrary,
{\rm rank}(Y)=n+s
for some
s\in\{1,\cdots,p\}
.

The remaining proof consists of four steps.

Step 1: Decomposition of matrix
Y
based on its rank.

Since
Y
is feasible for (
SDR
), we can rewrite
Y
as in (
12
)
for some
X\in{\mathbb{R}}^{n\times p}
. According to (
14
) and
Y\succeq 0
, we have

I_{p}-X^{T}X\succeq 0.

(24)

It follows from

{\rm rank}(Y)={\rm rank}(I_{n})+{\rm rank}(I_{p}-X^{T}X)=n+{\rm rank}(I_{p}-X^{T}X)

(25)

and assumption
{\rm rank}(Y)=n+s
that

\ {\rm rank}(I_{p}-X^{T}X)=s.

(26)

Based on (
24
)-(
26
),
there exists a full-column-rank matrix
C\in{\mathbb{R}}^{p\times s}
such that

I_{p}-X^{T}X=CC^{T}
.
Define

U=\begin{bmatrix}I_{n}&0_{n\times s}\\
X^{T}&C\end{bmatrix}\in{\mathbb{R}}^{(n+p)\times(n+s)}.

(27)

Then,
U
is of full column rank, and

Y=UU^{T}.

Step 2: Formulation of a linear system in condition that if the linear system has a nonzero solution, then
Y\notin\mathcal{E}(\mathcal{F}\eqref{eq:LPS-SDP3})
holds.

Consider the following linear system in terms of matrix
D
:

\displaystyle{\rm tr}(B_{i}UDU^{T})=0,~i=1,\cdots,k,

(28)

\displaystyle{UDU^{T}}_{[1:n]}=0_{n},

(29)

\displaystyle{UDU^{T}}_{[n+1:n+p]}=0_{p},

(30)

\displaystyle D\in{\mathbb{S}}^{n+s}.

(31)

If (
28
)-(
31
) has a nonzero solution
D
, then define

Y(\epsilon):=Y+\epsilon UDU^{T}=U(I+\epsilon D)U^{T},~\epsilon\in{\mathbb{R}}.

(32)

Since
Y
is feasible for (
SDR
),
for any
\epsilon\in{\mathbb{R}}
, we have

\displaystyle{\rm tr}(B_{i}Y(\epsilon))={\rm tr}(B_{i}U(I+\epsilon D)U^{T})={\rm tr}(B_{i}Y)\in[a_{i}^{l},a_{i}^{u}],~i=1,\cdots,k,

(33)

\displaystyle Y(\epsilon)_{[1:n]}={U(I+\epsilon D)U^{T}}_{[1:n]}={UU^{T}}_{[1:n]}=I_{n},

(34)

\displaystyle Y(\epsilon)_{[n+1:n+p]}={U(I+\epsilon D)U^{T}}_{[n+1:n+p]}={UU^{T}}_{[n+1:n+p]}=I_{p},

(35)

\displaystyle Y(\epsilon)=U(I+\epsilon D)U^{T}=Y(\epsilon)^{T}.

(36)

Moreover, by the definition of
Y(\epsilon)
, for any
\epsilon
such that
|\epsilon|
is sufficiently small, it holds that

Y(\epsilon)=U(I+\epsilon D)U^{T}\succeq 0.

(37)

Since
U
has the full-column rank, it follows from
D\neq 0
that
UDU^{T}\neq 0
.
By (
32
)-(
37
),
Y(\epsilon)\neq Y
is feasible for (
SDR
) when
\epsilon\neq 0
and
|\epsilon|
is sufficiently small.
Combining with
Y=(Y(\epsilon)+Y(-\epsilon))/2
, we obtain a contradiction that
Y\not\in\mathcal{E}(\mathcal{F}\eqref{eq:LPS-SDP3})
.

Step 3: Analysis of the coefficient matrix of the linear system (
28
)-(
31
).

Now, it suffices to show that the linear system (
28
)-(
31
) has a nonzero solution.
Firstly, we rewrite (
29
) as

{\rm tr}(E^{ij}UDU^{T})=0,\ \forall\ 1\leq i,\ j\leq n.

(38)

By the definition of
U
(
27
), one can verify that

U^{T}E^{ij}U=E^{ij},~1\leq i,\ j\leq n,

and hence

D_{ij}={\rm tr}(E^{ij}D)={\rm tr}(U^{T}E^{ij}UD)={\rm tr}(E^{ij}UDU^{T}),~1\leq i,\ j\leq n.

Thus, equations (
38
) are equivalent to

D_{ij}=0,\ \forall\ 1\leq i,j\leq n.

(39)

Secondly, (
30
) holds if and only if

{\rm tr}(U^{T}E^{(n+i)(n+j)}UD)={\rm tr}(E^{(n+i)(n+j)}UDU^{T})=0,\ \forall\ 1\leq i,j\leq p.

(40)

Let
x_{i}\in{\mathbb{R}}^{n}
be the
i
-th column of
X
and
c_{i}\in{\mathbb{R}}^{s}
be the
i
-th column of
C^{T}
for
i=1,\cdots,p
. Then one can verify that

U^{T}E^{(n+i)(n+j)}U=\begin{bmatrix}x_{i}x_{j}^{T}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix},~1\leq i,j\leq p.

(41)

Substituting (
41
) into (

) yields

{\rm tr}\left(\begin{bmatrix}x_{i}x_{j}^{T}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)=0,\ \forall 1\leq i,j\leq p,

which are equivalent to

\displaystyle 0=

\displaystyle\ 2{\rm tr}\left(\begin{bmatrix}x_{i}x_{j}^{T}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)

\displaystyle=

\displaystyle\ 2{\rm tr}\left(\begin{bmatrix}0_{n}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)~~~~({\rm since}~\eqref{eq:D222})

\displaystyle=

\displaystyle\ {\rm tr}\left(\begin{bmatrix}0_{n}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)+{\rm tr}\left(D^{T}\begin{bmatrix}0_{n}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}^{T}\right)

\displaystyle=

\displaystyle\ {\rm tr}\left(\begin{bmatrix}0_{n}&x_{i}c_{j}^{T}\\
c_{i}x_{j}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)+{\rm tr}\left(\begin{bmatrix}0_{n}&x_{j}c_{i}^{T}\\
c_{j}x_{i}^{T}&c_{j}c_{i}^{T}\end{bmatrix}D\right)~~~~({\rm since}~\eqref{eq:D4})

\displaystyle=

\displaystyle\ {\rm tr}\left(\begin{bmatrix}0_{n}&x_{i}c_{j}^{T}\\
c_{j}x_{i}^{T}&c_{i}c_{j}^{T}\end{bmatrix}D\right)+{\rm tr}\left(\begin{bmatrix}0_{n}&x_{j}c_{i}^{T}\\
c_{i}x_{j}^{T}&c_{j}c_{i}^{T}\end{bmatrix}D\right),~\forall 1\leq i,j\leq p.

(42)

We denote
D\in{\mathbb{S}}^{n+s}
as

\displaystyle D=\begin{bmatrix}D_{11}&D_{12}\\
D_{21}&D_{22}\end{bmatrix},

where
D_{11}\in{\mathbb{S}}^{n}
,
D_{12}\in{\mathbb{R}}^{n\times s}
,
D_{21}=D_{12}^{T}
,
D_{22}\in{\mathbb{S}}^{s}
. Let
{\rm vt}(\cdot)=({\rm vec}(\cdot))^{T}
.
Define

\displaystyle d

\displaystyle=

\displaystyle\begin{bmatrix}{\rm vt}(D_{11})&{\rm vt}(D_{12})&{\rm vt}(D_{21})&{\rm vt}(D_{22})\end{bmatrix}^{T}\in{\mathbb{R}}^{(n+s)^{2}},

\displaystyle M_{1}

\displaystyle=

\displaystyle\begin{bmatrix}\cdots&\cdots&\cdots&\cdots\\
{\rm vt}(0_{n})&{\rm vt}(x_{i}c_{j}^{T})&{\rm vt}(c_{j}x_{i}^{T})&{\rm vt}(c_{i}c_{j}^{T})\\
\cdots&\cdots&\cdots&\cdots\end{bmatrix}_{1\leq i,j\leq p}\in{\mathbb{R}}^{p^{2}\times(n+s)^{2}},

\displaystyle M_{2}

\displaystyle=

\displaystyle\begin{bmatrix}\cdots&\cdots&\cdots&\cdots\\
{\rm vt}(0_{n})&{\rm vt}(x_{j}c_{i}^{T})&{\rm vt}(c_{i}x_{j}^{T})&{\rm vt}(c_{j}c_{i}^{T})\\
\cdots&\cdots&\cdots&\cdots\end{bmatrix}_{1\leq i,j\leq p}\in{\mathbb{R}}^{p^{2}\times(n+s)^{2}}.

Since
{\rm tr}(AB^{T})={\rm vt}(A)({\rm vt}(B))^{T}
holds for any matrices

and

, we can reformulate (

) as

(M_{1}+M_{2})d=0.

(43)

As the rows of

and

are the same except for the sort order, we have

{\rm rank}(M_{1})={\rm rank}(M_{2})={\rm rank}(M_{1}+M_{2}).

(44)

For any

, define the

as

\displaystyle M_{1}^{i}=

\displaystyle\begin{bmatrix}\cdots&\cdots&\cdots&\cdots\\
{\rm vec}(0_{n})&{\rm vec}(x_{i}c_{j}^{T})&{\rm vec}(c_{j}x_{i}^{T})&{\rm vec}(c_{i}c_{j}^{T})\\

Then, it follows from (

)-(

{\rm rank}(M_{1}+M_{2})={\rm rank}(M_{1})\leq\sum_{i=1}^{p}{\rm rank}(M_{1}^{i})\leq ps.

(46)

Step 4: Verification that the linear system has a nonzero solution.

In sum, the linear equations (
29
)-(

) are equivalent to (
39
) and (

), respectively. The rank of the coefficient matrix of (

) is

, and that of (

.
The symmetry condition (

To sum up the above analysis, the whole system (

\displaystyle R\leq\

\displaystyle k+n^{2}+ps+\frac{(n+s)(n+s-1)}{2}-\frac{n(n-1)}{2}

\displaystyle=

\displaystyle\ k+\frac{n(n+1)}{2}+ps+\frac{(n+s)(n+s-1)}{2}.

\displaystyle\frac{(n+s)(n+s+1)}{2}-\left[k+\frac{n(n+1)}{2}+ps\right]

\displaystyle\frac{s(s+1)}{2}+(n-p)(s-1)

\displaystyle\geq

\displaystyle 1,~~~~~({\rm since}\ s\geq 1,~p\leq n).

Consequently, (

5
Sufficient global optimality conditions based on local information

In this section, we regard (
LPS
) as an NLP problem, and focus on studying whether local necessary optimality conditions could guarantee global optimality.

We have revealed hidden convexity of (
LPS
) when
p\leq n-k
in previous sections. However, as shown by the following example, it does not mean that any local minimizer of (
LPS
) is globally optimal.

Example 5.28
.

Consider an instance of (
LPS
) with
p=1
,
n=2
and
k=1
:

\begin{array}[]{cl}\min\limits_{x\in St_{2,1}}&-x_{1}-2x_{2}\\
{\rm s.t.}&x_{1}\leq 0.\end{array}

It is not difficult to verify that
(0,1)^{T}
is the unique global minimizer, and
(0,-1)^{T}
is a local nonglobal minimizer.

As a well-known result, if the KKT condition holds and the corresponding Lagrangian function is convex with respect to the primal variables, then the global optimality holds. For completeness, we present the corresponding result for (
LPS
) with a detailed proof in the Appendix.

Lemma 5.29
.

Let
X^{*}\in E_{n,p,k}
. If there exist
\lambda_{i}\in{\mathbb{R}}
for
i=1,\cdots,k
and
\Lambda\succeq 0
such that

\displaystyle A_{0}^{T}+\sum_{i=1}^{k}\lambda_{i}A_{i}^{T}+X^{*}\Lambda=0,

(57)

\displaystyle{\rm tr}(A_{i}X^{*})-a_{i}\leq 0,\ i=1,\cdots,k,\ X^{*T}X^{*}=I_{p},

(58)

\displaystyle\lambda_{i}^{+}({\rm tr}(A_{i}X^{*})-a_{i}^{u})=\lambda_{i}^{-}({\rm tr}(A_{i}X^{*})-a_{i}^{l})=0,\ i=1,\cdots,k,

(59)

then
X^{*}
is a global minimizer of (
LPS
).

Considering (
LPS
) as an NLP problem in terms of the vector variable in
{\mathbb{R}}^{np}
,
we obtain that, under certain assumptions, the standard first- and second-order necessary optimality conditions are sufficient for the global minimizer. The proof is presented in the Appendix.

Lemma 5.30
.

Assume
p(p+1)/2+1\leq n-k
. Let
X^{*}\in E_{n,p,k}
satisfy LICQ, and the standard first- and second-order necessary optimality conditions. Then
X^{*}
is a global minimizer of (
LPS
).

To our surprise, the above result can be greatly strengthened by more careful analysis.

Theorem 5.31
.

Suppose
p+1\leq n-k
. Let
X^{*}\in E_{n,p,k}
satisfy LICQ, and the first- and second-order necessary optimality conditions. Then,
X^{*}
is a global minimizer of (

).

Proof 5.32
.

Let
X^{*}=[X_{1}^{*},\cdots,X_{p}^{*}]
. There exist vectors
X_{p+1}^{*},\cdots,X_{n}^{*}\in{\mathbb{R}}^{n}
such that

Consider the orthogonal linear transformation

\displaystyle X^{T}X=I_{p}\Longleftrightarrow Z^{T}Z=I_{p},

\displaystyle{\rm tr}(A_{i}X)={\rm tr}(A_{i}QZ),\ i=0,\cdots,k.

Define
\tilde{A}_{i}=A_{i}Q

\begin{array}[]{cl}\min\limits_{Z\in St_{n,p}}&{\rm tr}(\tilde{A}_{0}Z)\\
{\rm s.t.}&a_{i}^{l}\leq{\rm tr}(\tilde{A}_{i}Z)\leq a_{i}^{u},~i=1,\cdots,k.\end{array}

Moreover, under any nonsingular linear transformation, LICQ and the first- and second-order necessary optimality conditions remain invariant. So, without loss of generality, we simply assume that

Define the set of active indices for linear inequality constraints as

\displaystyle{\rm tr}(A_{i}V)=0,\ i\in\mathcal{A},

\displaystyle V_{i}^{T}X^{*}_{j}+V_{j}^{T}X^{*}_{i}=0,\ \forall 1\leq i\leq j\leq p,

\displaystyle{\rm vec}(V)^{T}(\Lambda\otimes I_{n}){\rm vec}(V)\geq 0.

Define

Then equations (

is skew-symmetric.

In sum, by collecting all strictly upper triangular entries of the skew-symmetric matrix

,
U_{ij}

(1\leq i<j\leq n)
,
as

[u^{T},\ {\rm vec}(W)^{T}]b_{i}=0,\ i\in\mathcal{A}\Longrightarrow[u^{T},\ {\rm vec}(W)^{T}]M\left[\begin{matrix}u\\

Since

On the other hand,

Remark 5.33

According to Example

Based on Theorem

Remark 5.36
.

There are two trivial cases of (

) where the feasible sets are manifolds: (i)
k=0
; (ii)

and all linear constraints are equality ones.
In case (i), the feasible set is

6
Conclusion

We have introduced a new optimization model (
LPS
) by adding
k
linear constraints to the linear optimization on the Stiefel manifold
St_{n,p}
.
We provided some applications of (
LPS
), from which we showed that (
LPS
) is NP-hard in general.
Moreover, (
LPS
) also serves as the key subproblem in extended algorithms to
solve constrained optimization problems with an additional Stiefel manifold constraint.
Following the slightly extended Shapiro-Barvinok-Pataki theorem,
we verified that (
LPS
) admits an exact SDP relaxation when
p(p+1)/2\leq n-k
.
Our analysis showed that this sufficient condition can be greatly strengthened to
p\leq n-k
,
which includes the classical case
p\leq n
and
k=0
.
The hidden convexity, particularly in the case of
p-1=n-k
, remains unknown. It should be noted that hidden convexity does not mean that any local minimizer of (
LPS
) is globally optimal. Regarding (
LPS
) as a smooth NLP problem, we showed that, at a feasible point satisfying LICQ, the standard first- and second-order necessary optimality conditions are sufficient for the global optimality when
p+1\leq n-k
. When and only when LICQ holds at all feasible points of (
LPS
) is unknown. Another theoretical question is when and only when the intersection of a hyperplane and
St_{n,p}
remains a manifold.
