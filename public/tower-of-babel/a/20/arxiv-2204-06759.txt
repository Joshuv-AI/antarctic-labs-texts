Iterative Inner/outer Approximations for Scalable Semidefinite Programs using Block Factor-width-two Matrices
Feng-Yi Liao, Yang Zheng

Abstract
In this paper, we propose iterative inner/outer approximations based on a recent notion of block factor-width-two matrices for solving semidefinite programs (SDPs). Our inner/outer approximating algorithms generate a sequence of upper/lower bounds of increasing accuracy for the optimal SDP cost. The block partition in our algorithms offers flexibility in terms of both numerical efficiency and solution quality, which includes the approach of scaled diagonally dominance (SDD) approximation as a special case. We discuss both the theoretical results and numerical implementation in detail. Our main theorems guarantee that the proposed iterative algorithms generate monotonically decreasing upper (increasing lower) bounds. Extensive numerical results confirm our findings.



I
Introduction

Semidefinite programs (SDPs) are a class of convex optimization problems over the positive semidefinite (PSD) cone. The standard primal and dual SDPs are in the form of

\displaystyle p^{\star}:=\min_{X}\quad

\displaystyle\langle C,X\rangle

\displaystyle\mathrm{subject~to}\quad

\displaystyle\langle A_{i},X\rangle=b_{i},\quad i=1,\ldots,m,

(1a)

\displaystyle X\in\mathbb{S}^{n}_{+},

\displaystyle d^{\star}:=\max_{y,Z}\quad

\displaystyle b^{{\mathsf{T}}}y

\displaystyle\mathrm{subject~to}\quad

\displaystyle Z+\sum_{i=1}^{m}A_{i}y_{i}=C,

(1b)

\displaystyle Z\in\mathbb{S}^{n}_{+},

where

are the problem data,

denotes the standard inner product in an approximate space. We assume the strong duality holds for the primal and dual SDPs (
1

Semidefinite optimization (

[

Overcoming the challenge of scalability has received much attention

While the SDD approximation brings considerable computational efficiency in solving (

These methods

Recently, a new block extension of SDD matrices, called

II-A

DD and SDD matrices

The class of (scaled-) diagonally dominant matrices is defined as follows

]

Definition 1

A symmetric matrix
A=[a_{ij}]\in\mathbb{S}^{n}
is diagonally dominant (DD) if and only if

a_{ii}\geq\sum_{j\neq i}|a_{ij}|,\ i=1,2,\ldots,n.\vskip 2.84526pt

(2)

Definition 2

A symmetric matrix

is scaled diagonally dominant (SDD) if and only if there exists a diagonal matrix

with positive entries such that

is DD.

We denote the set of of

DD matrices as

and the set of

]

An SDD matrix

has an equivalent characterization as a factor-width-two matrix, i.e.,

where each column of

contains at most two non-zero elements

13
]
. Furthermore,

A\!\in\!SDD_{n}\Leftrightarrow A\!=\!\!\!\sum_{1\leq i<j\leq n}E_{ij}^{{\mathsf{T}}}M_{ij}E_{ij},\text{with}\;M_{ij}\!\in\!\mathbb{S}^{2}_{+},

(3)

where

with
i
th entry in row 1 and
j
th entry in row 2 being 1 and other entries being zero.

It is not difficult to see that (
2

3
) can be reformulated to a set of second-order constraints. Thus approximating
\mathbb{S}^{n}_{+}
by

(

respectively) in (

[

]
. This computational feature is one main motivation in the recent studies
[

,
14

The maximum stable set problem

The maximum stable set problem is a classical combinatorial problem, which aims to find the stability number of a graph. A
stable set
of a undirected graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
is a set of nodes of
\mathcal{G}
such that there are no edges between them. The maximum stable number of
\mathcal{G}
, denoted as
\alpha(\mathcal{G})

\alpha(\mathcal{G})
is greater than an integer

is well-known to be NP-complete
[
25
]
.
This problem can be formulated as

\displaystyle\alpha(\mathcal{G})\coloneqq\max_{x_{i}}

\displaystyle\sum_{i=1}^{n}x_{i}

(27)

\displaystyle\mathrm{subject~to}

\displaystyle x_{i}\in\{0,1\},\quad i=1,2,\ldots,n,

\displaystyle x_{i}x_{j}=0,\quad\forall(i,j)\in\mathcal{E}.

A well-known SDP-based upper bound, introduced in
[
26
]
, can be computed by

\displaystyle\vartheta(\mathcal{G})\coloneqq\max_{X}

\displaystyle\langle J,X\rangle

(28)

\displaystyle\mathrm{subject~to}

\displaystyle\langle I,X\rangle=1,

\displaystyle X_{ij}=0,\quad\forall(i,j)\in\mathcal{E},

\displaystyle X\succeq 0,

J
is an all-one matrix and

is the identity matrix. The cost of (
28

\acute{a}
sz theta number, denoted as

, which provides an upper bound

and

Binary quadratic optimization

Binary quadratic optimization is another classical combinatorial problem, in which we have a quadratic cost and a binary decision variable

\displaystyle\min_{x}

[

\displaystyle\min_{X}

\displaystyle\langle Q,X\rangle

(30)

\displaystyle\mathrm{subject~to}

\displaystyle X_{ii}=1,\quad i=1,2,\ldots,n,

\displaystyle X\in\mathbb{S}^{n}_{+},

which returns a lower bound for (
29
).

We apply Algorithm

for inner approximations of (

\alpha=\{10,\ldots,10\}
, and
\beta=\{20,\ldots,20\}
. We set the maximum iteration as

. The results are shown in Figure

\beta
obtains almost optimal solution (
\geq 99.9\%
optimality) within
10

70\%
optimality while taking a longer time (the longer time consumption is related to the large number of small blocks; see Remark
