TIAViz: A Browser-based Visualization Tool for Computational Pathology Models
Mark Eastwood, John Pocock, Mostafa Jahanifar, Adam Shephard, Skiros Habib, Ethar Alzaid, Abdullah Alsalemi, Jan Lukas Robertus, Nasir Rajpoot, Shan Raza, Fayyaz Minhas

Abstract
\absection Summary Digital pathology has gained significant traction in modern healthcare systems. This shift from optical microscopes to digital imagery brings with it the potential for improved diagnosis, efficiency, and the integration of AI tools into the pathologists workflow. A critical aspect of this is visualization. Throughout the development of a machine learning (ML) model in digital pathology, it is crucial to have flexible, openly available tools to visualize models, from their outputs and predictions to the underlying annotations and images used to train or test a model. We introduce TIAViz, a Python-based visualization tool built into TIAToolbox which allows flexible, interactive, fully zoomable overlay of a wide variety of information onto whole slide images, including graphs, heatmaps, segmentations, annotations and other WSIs. The UI is browser-based, allowing use either locally, on a remote machine, or on a server to provide publicly available demos. \absection Availability and Implementation This tool is open source and is made available at: https://github.com/TissueImageAnalytics/tiatoolbox and via pip installation (pip install tiatoolbox) and conda as part of TIAToolbox. \absection Contact For any queries please contact Mark.Eastwood@warwick.ac.uk, or raise an issue in the associated git repository above. \absection Supplementary information Further documentation can be found at: https://tia-toolbox.readthedocs.io/en/latest/visualization.html . Some demos that use the described tool can be found here: tiademos.dcs.warwick.ac.uk .

Introduction

In bioinformatics and digital pathology, the need for advanced visualization tools is driven by the growing complexity and prevalence of AI models capable of providing additional context and predictions to pathologists when viewing slides.

TIAViz is a browser-based visualization tool designed for the analysis of digital pathology model outputs. Developed as part of the TIAToolbox
[
10
]
open-source digital pathology toolbox, and utilizing the Bokeh
[
11
]
visualization library, it provides a platform for viewing high-resolution pathology slides and overlaying model outputs or annotations in a fully zoomable and interactive viewer. This tool helps address the increasing demand in digital pathology for robust and flexible visualization options capable of handling complex medical imaging data and model outputs in a variety of different forms, with a particular focus on use within a research context.
As all code is written in Python it can be integrated quickly into Python-based machine learning workflows.

There are some excellent open source tools for digital pathology already available. The foremost of these is probably QuPath
[
2
]
, a fully featured, java-based platform for analysis of histological images. For many use-cases, we would highly recommend QuPath, such as for creating and working with annotations, interactive pixel-level analysis and modelling. However, there are a few areas in which TIAViz can offer functionality that is difficult or not provided in QuPath. Firstly,
as a browser-based visualization tool, TIAViz can be launched on a remote machine and used to view slides/overlays from that remote machine in a browser window on the local machine. This can be very useful, especially in the research context as ML pipelines and model
outputs are often run and stored on remote compute resources.

Additionally, it’s browser-based nature allows it to be used to provide online servers showcasing the capabilities of models, which can be extremely useful for collaboration and to allow members of the DP (Digital Pathology) community to better understand and explore models created by others.

TIAViz is written in Python, using TIAToolbox
[
10
]
and Bokeh
[
11
]
. As such, it can be easier to integrate into Python-based ML workflows, in particular those that already use elements of TIAToolbox, and has a much simpler code-base allowing it to potentially be adapted or customized quite easily to a specific use case when the desired visualization task cannot be achieved with the tool’s inbuilt capabilities.

Another tool is cytomine
https://cytomine.com/
, which is browser-based but is limited in what can be overlaid (for example graphs are not supported). Similarly, HistomicsTK (
https://github.com/DigitalSlideArchive/HistomicsTK
) is an option with a powerful set of tools for annotation creation, management, and image analysis, but again graphs are not supported and it is less well suited to quickly visualizing ML model output.

2
Technical Details

TIAToolbox is a suite of unit-tested image analysis and machine learning tools developed for the CPath community, making it possible for a variety of users to construct and reproduce CPath analytical pipelines with cutting-edge methods. TIAViz builds on the capabilities of TIAToolbox, utilizing two core components of the package. Firstly, TIAToolbox provides the capability to read a wide variety of image formats, and a flask-based tileserver serves image tiles on the fly to allow for responsive navigation around large WSIs.

Secondly, TIAToolbox offers an SQLite-based database for storing annotations, as geometries paired with a properties dictionary. Methods are provided to allow efficient and powerful querying of the store, to select annotations by some combination of spatial location or conditions on their property values.

We add significantly to the tileserver and annotation store, and introduce a variety of classes and functions to facilitate rendering of annotation overlay tiles directly from an annotation store, and for conversion of some common annotation types to an AnnotationStore database.

The interface itself is developed using the Bokeh visualization library, a powerful Python toolkit for creating interactive plots and dashboards. This choice of technology facilitates dynamic data visualization and interactivity, essential for handling the complex data typical in digital pathology.

3
Features and Capabilities

Figure 1:
Overview of TIAViz architecture and capabilities. Panel A: High level architecture and data flow. B: Graph overlay features. C: Overlay of annotations and segmentation. D: Image-based overlays. E: Dual linked window capabilities.

TIAViz is capable of overlaying a wide variety of model outputs and other information onto a WSI. A straightforward file structure is assumed, requiring all slides to be in a designated ‘slides’ folder, and all overlays - including graphs, segmentations, heatmaps, etc. - in an ‘overlays’ folder. The tool automatically pairs overlays with slides based on if an overlay filename stem contains the slide stem, streamlining the process of data visualization.

3.1
Annotation and Segmentation Overlays

The tool is capable of overlaying geometries provided in various formats. TIAViz uses the TIAToolbox SQLiteStore to store annotations and segmentations as Annotation objects, which consist of a geometry and any associated properties. GeoJSON files, and .dat file output from TIAtoolbox segmentation models, can also be loaded in the interface.

We provide a powerful selection of UI elements to interactively control how annotations are displayed, allowing individual types to be toggled on/off independently, filtering of annotations according to mathematical expressions, and offering a wide variety of options to allow coloring annotations according to any values in their properties dictionary. Detailed annotation properties can be viewed by double-clicking on an annotation, as illustrated in supplementary Fig 2.

3.2
Heatmaps and Whole Slide Overlays

TIAViz supports the overlay of multiple low-resolution heatmaps, and/or additional WSI overlays each as separate layers. Low-res images must be provided with the same aspect ratio as the parent image, and will be upscaled accordingly. An example of a UMAP
[
9
]
reduction of a swin-transformer
[
8
]
featuremap into 3-D (RGB) space is shown in
1
Panel C.

3.3
Graph Overlays

Graphs are becoming an increasingly popular way of representing large sections of tissue in histology images, paired with graph neural network (GNN) models for prediction
[
1
]
. TIAViz allows graphs to be overlaid onto WSIs in tandem with other overlay types, and can color nodes according to provided features or model output. Users can control the display of nodes and edges individually. The tool accepts graph data in a JSON dictionary format. Examples of this can be seen in
1
. Futher information about node features can be viewed when hovering over a node, as illustrated in supplementary Fig 3.

3.4
Interactive AI Environment

Models can be run interactively in the UI. HoVer-Net
[
7
]
is the first model available this way and can be used to segment small regions of a slide interactively.
GPT-vision has been shown to have some ability to evaluate medical images
[
12
]
. TIAViz provides the ability to highlight a region of a slide and send it to GPT-vision within the interface. Drawn annotations (for example circling a feature of interest) can be included in the sent image, and referenced in the prompt. Examples can be seen in supplementary Fig 1. We believe this sort of functionality could be very powerful in the future with multi-modal models fine-tuned for medical images, as it would allow pathologists to interact intuitively in natural language with an AI assistant. Code for this addition is available in a fork of TIAViz at
https://github.com/measty/tiatoolbox
.

3.5
Other Features

A powerful feature of this tool is the ability to display multiple overlays simultaneously. Any combination of one graph overlay, one annotation-based overlay, and multiple image-based overlays (either WSIs or low resolution non-pyramidal images) can be shown.

It is also possible to display two slides (or two views of the same slide) side by side, and add overlays to each independently, as shown in
1
, Panel E. Slide navigation will be linked between the two windows. This is extremely useful for viewing registered slides, comparing different model output for the same slide, or simply showing the base image next to an overlaid image.

A JSON configuration file can be provided which can define a variety of defaults for a given project, such as default colors for specific types. More information can be found in the documentation
https://tia-toolbox.readthedocs.io/en/latest/visualization.html
.

4
Example Applications

The TIAToolbox visualization tool has been utilized in a range of research works in digital pathology, some of which we will cover here to illustrate its flexibility.

IGUANA
: This is an interpretable graph neural network for screening normal endoscopic large bowel biopsies
[
6
]
. The pipeline for this model involves the segmentation of glands and several different cell types, which are used to build a gland graph with interpretable node features calculated from gland and nearby cell segmentations. These features were developed in collaboration with pathologists to capture aspects of glandular morphology and the surrounding lamina propria that they consider when making their diagnosis. TIAViz is highly suitable for visualizing such information, providing the ability to simultaneously overlay gland and cell segmentations together with the gland graph, and visually highlight the glands determined by the model to contribute most highly to an abnormal diagnosis. An online demo illustrating the IGUANA model can be found at
https://iguana.dcs.warwick.ac.uk/
.

Social Network Analysis (SNA)
: In
[
13
]
, SNA is used to characterize patches of WSI based on the relative locations of cells in the tissue. These features are used to create an enhanced IDaRS-based model
[
3
]
to predict molecular pathways and mutations in colorectal cancer. The task is treated as a Multiple instance learning problem. TIAViz provides a convenient way to visualize the most positive instances (patches) on a WSI, as can be seen in
https://tiademos.dcs.warwick.ac.uk/Bokeh_app?demo=sna
.

Gene group analysis
: Work in
[
4
]
has identified groups of genes with co-dependent expression and predicted their status from WSI images using a graph neural network. These gene groups allow to capture the gene expression state of a patient with a small number of binary variables that are biologically meaningful. Further, the groups can be used to associate histological phenotypes (cellular composition, mitotic counts, grading, etc.) with underlying gene expression patterns. Our visualization tool provides a convenient interface to explore the predicted expression of the gene groups and visualize their variation and correlation with visual features over a WSI, as illustrated at
https://tiademos.dcs.warwick.ac.uk/Bokeh_app?demo=HiGGsXplore
.

MesoGraph
: In
[
5
]
, TIAViz is used to overlay subtype predictions onto mesothelioma TMA cores as can be seen at
https://tiademos.dcs.warwick.ac.uk/Bokeh_app?demo=mesograph
. The model illustrated here is a GNN on the cell graphs of the TMAs, using both morphological and local deep features to describe each cell.

5
Discussion and Conclusions

TIAViz is a powerful and flexible tool for visualization and exploration of digital pathology models. It is most useful in a research context where its browser-based nature allows use on remote machines and to provide online demos for collaborative purposes. As it is built in Python it also lends itself to quick integration, iteration and adaptation within the Python-based machine learning pipelines commonly used in digital pathology research.

There are some areas for improvement. One of these is performance optimization when handling very large datasets, a common challenge in digital pathology. The tool can be slow on initial loading in the case of large numbers of annotations, though it is generally quite responsive after this initial delay. We aim to improve this in the future. We also plan to widen the variety of tools in TIAToolbox that can be run directly within the interface. Currently, HoVer-Net can be used within the interface, but there is scope to widen the options there.

The possibility also exists to provide a visualization server allowing users to upload a slide and overlay to visualize. We currently have a prototype server for this which may be developed into a visualization service for the digital pathology community in the future.
