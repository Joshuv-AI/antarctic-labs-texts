Decentralized Non-Convex Learning with Linearly Coupled Constraints: Algorithm Designs and Application to Vertical Learning Problem Thanks: Jiawei Zhang and Songyang Ge contributed equally. Part of the work was presented in IEEE ICASSP 2020 [ 1 ] .
Jiawei Zhang, Songyang Ge, Tsung-Hui Chang, Zhi-Quan Luo

Abstract
Motivated by the need for decentralized learning, this paper aims at designing a distributed algorithm for solving nonconvex problems with general linear constraints over a multi-agent network. In the considered problem, each agent owns some local information and a local variable for jointly minimizing a cost function, but local variables are coupled by linear constraints. Most of the existing methods for such problems are only applicable for convex problems or problems with specific linear constraints. There still lacks a distributed algorithm for solving such problems with general linear constraints under the nonconvex setting. To tackle this problem, we propose a new algorithm, called proximal dual consensus (PDC) algorithm, which combines a proximal technique and a dual consensus method. We show that under certain conditions the proposed PDC algorithm can generate an ϵ \epsilon -Karush-Kuhn-Tucker solution in 𝒪 ⁡ ( 1 / ϵ ) \mathcal{O}(1/\epsilon) iterations, achieving the lower bound for distributed non-convex problems up to a constant. Numerical results are presented to demonstrate the good performance of the proposed algorithms for solving two vertical learning problems in machine learning over a multi-agent network.

Application Examples

Data partition for horizontal learning (Left) and

Problem
(P)
appears in many engineering applications. As mentioned in Section
1
, one classical example is the consensus formulation of the finite sum problem
\min_{{\bm{x}}}\sum_{i=1}^{N}f_{i}({\bm{x}})
. Specifically, consider a multi-agent network with
N
connected agents, and each agent
i
,
i\in[N]
, has a local copy of
{\bm{x}}
, denoted as
{\bm{x}}_{i}\in\mathbb{R}^{n}
. Suppose that
\tilde{}{\bm{A}}\in\mathbb{R}^{N\times N}
is the incidence matrix of the network graph.
One can have the following consensus formulation of the finite sum problem

\displaystyle\min_{{\bm{x}}=[{\bm{x}}_{1}^{\top},\cdots,{\bm{x}}_{N}^{\top}]^{\top}}

\displaystyle~\sum_{i=1}^{N}f_{i}({\bm{x}}_{i})

(2a)

s.t.

\displaystyle(\tilde{}{\bm{A}}\otimes{\bm{I}}_{n}){\bm{x}}=\mathbf{0},

(2b)

where (
2b
) ensures all
{\bm{x}}_{i}
’s are the same to each other. In the machine learning literature, the finite sum problem corresponds to the conventional
horizontal learning
problem where the data samples are partitioned and distributively owned
by the agents
[
4
]
(left of Fig.
1
), and such problem has been extensively studied
[
4
,
26
,
27
]
.
Unlike (
2
), in this section we discuss an important but less discussed learning problem: the
vertical learning
problem, where the agents own all data samples
but part of their features only (right of Fig.
1
)
[
30
,
31
]
. Such problems appear, for example, in collaborative
learning between multiple parties who hold different aspects of information for the
same set of samples.
Using two examples below, we show that the vertical learning problem can be expressed as the form
of
(P)
.

Example 1
(
Empirical risk minimization)

Consider a standard empirical risk minimization problem as follows

\min_{{\bm{w}}}~\sum\limits_{k=1}^{M}\psi({\bm{b}}_{k}^{\top}{\bm{w}},{\bm{v}}_{k})+R({\bm{w}}),

(3)

where
M
is the number of data samples,
{\bm{b}}_{k}
and
{\bm{v}}_{k}
are respectively the
feature vector and (one-hot vector) label
for the
k
-th sample,

{\bm{w}}\in\mathbb{R}^{nN}
is the parameter to be optimized,

\psi
is the (possible non-convex) loss function, and
R(\cdot)
is a regularization function.

Let us consider to solve problem (
3
) over a multi-agent
network with
N
agents under the vertical learning setting. Each agent
i
owns all
M
data samples but has part of the data features only. Specifically,
assume that each sample
{\bm{b}}_{k}
is partitioned as
{\bm{b}}_{k}=[{\bm{b}}_{1,k}^{\top},\cdots,{\bm{b}}_{N,k}^{\top}]^{\top}
, where
{\bm{b}}_{i,k}\in\mathbb{R}^{n}
, and each agent
i
owns
samples with only partial features
\{{\bm{b}}_{i,k}\}_{k=1}^{M}
, for all
i\in[N]
.
Let the parameter vector

{\bm{w}}
be partitioned in the same fashion, i.e.,

{\bm{w}}=[{\bm{w}}_{1}^{\top},\cdots,{\bm{w}}_{N}^{\top}]^{\top}
, and assume the regularization term

R({\bm{w}})=\sum_{i=1}^{N}R_{i}({\bm{w}}_{i})
. So, each agent
i
under the vertical learning setting maintains only a subset of the model parameters
{\bm{w}}_{i}
.

Then, problem (
3
) can be reformulated as

\displaystyle\min_{{{\bm{w}}},{\bm{w}}_{0}}~

\displaystyle\sum\limits_{k=1}^{M}\psi\big(w_{0,k},{\bm{v}}_{k}\big)+\sum_{i=1}^{N}R_{i}({\bm{w}}_{i})

(4a)

\displaystyle{\rm s.t.}~

\displaystyle\sum_{i=1}^{N}{\bm{b}}_{i,k}^{\top}{\bm{w}}_{i}-w_{0,k}=0,~k\in[M],

(4b)

where
{\bm{w}}_{0}=[w_{0,1},\ldots,w_{0,M}]^{\top}
is an introduced variable.
Further define
{{\bm{B}}}_{i}=[{\bm{b}}_{i,1},\cdots,{\bm{b}}_{i,M}]^{\top}
,
i\in[N]
, and let

\Psi({\bm{w}}_{0})=\sum_{k=1}^{M}\psi(w_{0,k},{\bm{v}}_{k})
.
Thus (
4
) can be written as

\displaystyle~~\min_{\begin{subarray}{c}{\bm{w}}_{1},\ldots,{\bm{w}}_{N},\\
{\bm{w}}_{0}\end{subarray}}~

\displaystyle\Psi({\bm{w}}_{0})+\sum_{i=1}^{N}R_{i}({\bm{w}}_{i})

(5a)

\displaystyle~~\mathrm{s.t.}~

\displaystyle\sum_{i=1}^{N}{\bm{B}}_{i}{\bm{w}}_{i}-{\bm{w}}_{0}={\bm{0}}.

(5b)

One can see that the above problem (
5
) is indeed an instance of

(P)
. It corresponds to the vertical learning problem where each agent
i
knows partial feature matrix
{\bm{B}}_{i}
, regularizer
R_{i}
and partial model parameter
{\bm{w}}_{i}
, for all
i\in[N]
; the variable
{\bm{w}}_{0}
and

Example 2
(
Classification by neural network)

Consider to train a neural network (NN) for classification as shown in Fig.

The mapping of the

\displaystyle{\bm{w}}_{0,k}=\sum_{i=1}^{N}{\bm{W}}_{i}^{\top}{\bm{b}}_{i,k}=\sum_{i=1}^{N}({\bm{b}}_{i,k}^{\top}\otimes{\bm{I}}_{K}){\bm{w}}_{i},

where

\displaystyle\min_{\begin{subarray}{c}{\bm{w}}_{1},\cdots,{\bm{w}}_{N},\\

\displaystyle\sum\limits_{k=1}^{M}L\big(F_{\bm{\theta}}({\bm{w}}_{0,k}^{\top}),{\bm{v}}_{k}\big)

(8a)

\displaystyle{\rm s.t.}~

\displaystyle\sum_{i=1}^{N}{\bm{B}}_{i}{\bm{w}}_{i}-{\bm{w}}_{0}={\bm{0}},

where
\textstyle{\bm{B}}_{i}=\textstyle[({\bm{b}}_{i,1}^{\top}\otimes{\bm{I}}_{K})^{\top},\cdots,({\bm{b}}_{i,M}^{\top}\otimes{\bm{I}}_{K})^{\top}]^{\top}

{\bm{w}}_{0}=[{\bm{w}}_{0,1}^{\top},\ldots,{\bm{w}}_{0,M}^{\top}]^{\top}

As a result, the distributed optimization problem

3.1
Network Model and Assumptions

The multi-agent network is modeled as an undirected graph
\mathcal{G}=(\mathcal{E},\mathcal{N})
, where

\mathcal{E}
is the set of edges and
\mathcal{N}
is the set of agents. Each agent can only
communicate and exchange information with its neighbors, i.e., agents
i,j
can
communicate with each other if and only if
(i,j)\in\mathcal{E}
.

Let us define some useful notations regarding the network graph.
The neighbouring set of agent
i
is defined as
\mathcal{N}_{i}=\{j\in\mathcal{N}~|~(i,j)\in\mathcal{E}\}
. Let
\tilde{}{\bm{D}}={\rm diag}\{|\mathcal{N}_{1}|,\cdots,|\mathcal{N}_{N}|\}\in\mathbb{R}^{N\times N}
be the degree matrix of
\mathcal{G}
.
The agent-edge incidence matrix is defined as
\tilde{}{\bm{A}}\in\mathbb{R}^{|\mathcal{E}|\times|\mathcal{N}|}
which has

\tilde{}{\bm{A}}_{e,i}=1
and
\tilde{}{\bm{A}}_{e,j}=-1

for
j>i
and
e=(i,j)\in\mathcal{E}
, and zeros otherwise.

\tilde{}{\bm{L}}^{-}=\tilde{}{\bm{A}}^{\top}\tilde{}{\bm{A}}
is the (signed) Laplacian matrix
of
\mathcal{G}
. Then

\tilde{}{\bm{L}}^{+}=2\tilde{}{\bm{D}}-\tilde{}{\bm{L}}^{-}

is the signless Laplacian matrix of
\mathcal{G}
. Both
\tilde{}{\bm{L}}^{-}
and
\tilde{}{\bm{L}}^{+}
are positive semi-definite and describe the connectivity of the network.
For ease of later use, we also define

\displaystyle{\bm{A}}=\tilde{}{\bm{A}}\otimes{\bm{I}}_{M}=[{\bm{A}}_{1},\ldots,{\bm{A}}_{N}],

\displaystyle{\bm{L}}^{+}=\tilde{}{\bm{L}}^{+}\otimes{\bm{I}}_{M}=\begin{bmatrix}({\bm{L}}_{1}^{+})^{\top},\cdots,({\bm{L}}_{N}^{+})^{\top}\end{bmatrix}^{\top},

\displaystyle{\bm{L}}^{-}=\tilde{}{\bm{L}}^{-}\otimes{\bm{I}}_{M}=\begin{bmatrix}({\bm{L}}_{1}^{-})^{\top},\cdots,({\bm{L}}_{N}^{-})^{\top}\end{bmatrix}^{\top},

and let
\lambda_{\max}
be the maximum eigenvalue
of
{\bm{L}}^{+}
.

We make the following
assumption for the network.

Assumption 1

The graph
\mathcal{G}
is connected.

It means that for any
i,j\in\mathcal{N}
, there exists at least one path connecting
i

and
j
. Assumption
1
is commonly made in the literature
of distributed optimization.

For problem
(P)
, we make the following assumption.

Assumption 2

Each
f_{i}
is continuously differentiable and
\nabla f_{i}
is Lipschitz continuous
with constant
\gamma^{+}>0
.

Under Assumption
2
, there exists
a (possibly negative) constant
\gamma^{-}
such that

{\langle}\nabla f_{i}({\bm{x}}_{i})-\nabla f_{i}({\bm{x}}_{i}^{\prime}),{\bm{x}}_{i}-{\bm{x}}_{i}^{\prime}{\rangle}\geq\gamma^{-}\|{\bm{x}}_{i}-{\bm{x}}_{i}^{\prime}\|^{2},

(9)

for all
{\bm{x}}_{i},{\bm{x}}_{i}^{\prime}\in\mathbb{R}^{n}
.
Note that if
\gamma^{-}
is negative, then
f_{i}
is not a convex function.

3.2
Algorithm Development

The proposed PDC method is motivated by the proximal approach recently presented in

[
17
]
for non-convex constrained optimization.
In particular, like
[
17
]
, we consider a “proximal” counterpart of
(P)

\displaystyle\min_{{\bm{x}}_{i},i\in[N]}~

\displaystyle\sum_{i=1}^{N}f_{i}({\bm{x}}_{i})+\frac{p}{2}\sum_{i=1}^{N}\|{\bm{x}}_{i}-{\bm{z}}_{i}\|^{2}

(10a)

s.t.

\displaystyle\sum_{i=1}^{N}{\bm{B}}_{i}{\bm{x}}_{i}={\bm{q}},

(10b)

where
p>-\gamma^{-}
is a penalty parameter and

{\bm{z}}=({\bm{z}}_{1}^{\top},\ldots,{\bm{z}}_{N}^{\top})^{\top}
is
an introduced proximal variable.
Note that (
10
)
is still not a convex problem for the joint variable
({\bm{x}}^{\top},{\bm{z}}^{\top})^{\top}
, but it is convex with respect to
{\bm{x}}
when
{\bm{z}}
is fixed. So, the proximal problem (
10
) can be regarded as a convex approximation of problem
(P)
around the given point
{\bm{z}}
.

Let us denote
({\bm{x}}({\bm{z}}),{\bm{y}}_{0}({\bm{z}}))
as a primal-dual optimal solution of (
10
) with fixed
{\bm{z}}
. One can verify that
({\bm{x}}({\bm{z}}),{\bm{y}}_{0}({\bm{z}}))

is a KKT solution of
(P)
, i.e., satisfying

\displaystyle\nabla f_{i}({\bm{x}}_{i}({\bm{z}}_{i}))+{\bm{B}}_{i}^{\top}{\bm{y}}_{0}({\bm{z}})=\mathbf{0},\forall i\in[N]

(11a)

\displaystyle\sum_{i=1}^{N}{\bm{B}}_{i}{\bm{x}}_{i}({\bm{z}}_{i})-{\bm{q}}=\mathbf{0},

(11b)

if and only if

\displaystyle{\bm{x}}({\bm{z}})={\bm{z}}.

(12)

In
[
17
]
, the authors proposed to handle (
10
) by
using one step of primal-dual gradient update in each iteration
r
, followed by
updating
\{{\bm{z}}^{r}\}
by

\displaystyle{\bm{z}}^{r+1}={\bm{z}}^{r}+\beta({\bm{x}}^{r+1}-{\bm{z}}^{r}),

(13)

where
0<\beta<1
is a positive stepsize. Notice that for
\beta=1
, the algorithm may oscillate.
It is shown that (
13
) with sufficiently small
\beta
can stabilize the primal-dual
sequence and the algorithm can achieve a KKT solution of
(P)
.
However, the algorithm in
[
17
]
is a centralized algorithm and cannot solve

(P)
over the multi-agent network.

To obtain a distributed algorithm,
we consider employing the dual consensus method in
[
7
]

to deal with the (strongly convex) proximal problem (
10
) when
{\bm{z}}
is fixed.
First, by the Lagrange duality theory
[
32
]
, (
10
) is equivalent to its dual problem when
{\bm{z}}
is fixed

\displaystyle\max_{{\bm{y}}_{0}\in\mathbb{R}^{M}}~\sum_{i=1}^{N}\bigg(\phi_{i}({\bm{y}}_{0},{\bm{z}}_{i})-{\bm{y}}_{0}^{\top}\frac{{\bm{q}}}{N}\bigg),

(14)

where
{\bm{y}}_{0}
is the dual variable associated with the constraint (
10b
), and

\displaystyle\phi_{i}({\bm{y}}_{0},{\bm{z}}_{i})=\min_{{\bm{x}}_{i}\in\mathbb{R}^{n}}f_{i}({\bm{x}}_{i})+\frac{p}{2}\|{\bm{x}}_{i}-{\bm{z}}_{i}\|^{2}+{\bm{y}}^{\top}_{0}{\bm{B}}_{i}{\bm{x}}_{i},

(15)

for
i\in[N],

are concave dual functions of
{\bm{y}}_{0}
.
In order to solve this dual problem in a decentralized manner, we let
{\bm{y}}_{i}\in\mathbb{R}^{M}
be the local copy of
{\bm{y}}_{0}
at agent
i
. Then,
\phi_{i}
can be
written as

\displaystyle\phi_{i}({\bm{y}}_{i},{\bm{z}}_{i})=\min_{{\bm{x}}_{i}\in\mathbb{R}^{n}}f_{i}({\bm{x}}_{i})+\frac{p}{2}\|{\bm{x}}_{i}-{\bm{z}}_{i}\|^{2}+{\bm{y}}^{\top}_{i}{\bm{B}}_{i}{\bm{x}}_{i},

(16)

for
i\in[N]
.
As the right hand side of (
16
) is a strongly convex problem with respect to
{\bm{x}}_{i}
,
\phi_{i}({\bm{y}}_{i},{\bm{z}}_{i})
is smooth
and concave with respect to
{\bm{y}}_{i}
according to the Danskin’s theorem
[
33
]
, and
\nabla\phi_{i}({\bm{y}}_{i},{\bm{z}}_{i})
is Lipschitz continuous
with constant
\frac{1}{p+\gamma^{-}}

[
34
]
.
Next, similar to (
2
), we consider the following consensus
constrained counterpart

\displaystyle\max_{{\bm{y}}=({\bm{y}}_{1}^{\top},\cdots,{\bm{y}}_{N}^{\top})^{\top}}~

\displaystyle\sum_{i=1}^{N}\bigg(\phi_{i}({\bm{y}}_{i},{\bm{z}}_{i})-{\bm{y}}_{i}^{\top}\frac{{\bm{q}}}{N}\bigg)

(17a)

Conclusions

In this paper, two new distributed algorithms, i.e., the PDC and the IPDC
algorithms, for solving the
non-convex linearly constrained problem
{\sf(P)}
over the multi-agent network
have been proposed. These algorithms can be regarded as extensions of the dual
consensus ADMM method in
[
7
]
to the challenging non-convex settings, by
leveraging the proximal technique in
[
17
]
.
While the algorithm development is rather straightforward, it turns out that proving
the convergence and convergence rate of the proposed algorithms are not. By
developing some key error bounds and perturbation bounds, we have shown that, under
mild conditions on the algorithm parameters, the proposed algorithms both can
converge to a KKT solution of problem
{\sf(P)}
with a complexity order of

\mathcal{O}(1/\epsilon)
. Through experiments on a non-convex logistic regression
problem and an NN-based MNIST classification task,
we have demonstrated the good convergence behaviors of the proposed algorithms with
respect to various parameter settings.

To the best of our knowledge, the presented distributed algorithms and convergence analyses are the first for the linearly constrained non-convex problem
{\sf(P)}
. In the future, it is worthwhile to extend the current PDC framework to mini-batch
stochastic gradient descent (SGD)
[
42
,
43
]
, local SGD

[
44
]
, online learning
[
45
]
,
and to handle more complex learning problems with heterogeneous data distribution
[
46
]
, and hybrid partitioned data samples and features
[
47
]
.
Inspired by the simulation results in Section
5.2
, it is also meaningful to
analyze convergence properties of the proposed algorithm for ReLU neural networks
[
48
,
49
]
or devise distributed algorithms for general non-smooth problem
{\sf(P)}
.
Finally, as we discuss after Corollary
1
, it needs more efforts to understand how graph topology and data matrix can affect the algorithm convergence. Besides, it is also important to devise optimal distributed schemes as in
[
28
]
for the general problem
(P)
.

Lemma 10

Let
F(x,y)=f(x)+y^{\top}Ax+v^{\top}y-\frac{1}{2}y^{\top}Qy
, where
f(x)
is a strongly convex, smooth function,
Q
is a positive semi-definite matrix and
v\in\mathrm{Image}(Q)
. Then the saddle point of
F(x,y)
exists, i.e., the solution of the problem
P1
exists

\displaystyle P1:\min_{x}\max_{y}F(x,y).

(A.1)

Proof of Lemma
10
:
First, by the basic property of quadratic optimization,
\arg\max_{y}F(x,y)
exists if and only if

\displaystyle Ax\in\mathrm{Image}(Q).

(A.2)

Let
\mathrm{rank}(Q)=r
.
Without loss of generality, we assume
Q=\begin{bmatrix}Q_{11}&Q_{12}\\
Q_{12}&Q_{22}\end{bmatrix}
and
Q_{11}\in\mathbb{R}^{r\times r}
is of full rank.
Let
P=\begin{bmatrix}Q_{11}\\
Q_{12}\end{bmatrix}
and
Y=\{y\in\mathbb{R}^{m}\mid y_{r+1}=\cdots=y_{m}=0\}
.

Also let
\mathrm{Image}(Q)=\{w\mid Bw=0\}
, where the rows of
B\in\mathbb{R}^{(m-r)\times m}
are the basis for
\mathrm{Null}(Q)
.
Define
X=\{x\in\mathbb{R}^{n}\mid BAx=0\}
. Then,
x\in X
implies
x\in\mathrm{Image}(Q)
. For any
\tilde{x}\in X
, there exists some
\tilde{y}\in Y
such that

\displaystyle\tilde{y}=\arg\max_{y\in\mathbb{R}^{m}}F(\tilde{x},y).

(A.3)

In fact, the matrix
P
is of rank
r
. Therefore,
\mathrm{Image}(Q)=\mathrm{Image}(P)
.
Notice that
-A\tilde{x}-v\in\mathrm{Image}(Q)=\mathrm{Image}(P)
.
It implies that there exists some
u\in\mathbb{R}^{r}
such that

-A\tilde{x}-v=Pu.

Hence, if
\tilde{y}=(u^{T},0,\cdots,0)^{T}\in Y\subseteq\mathbb{R}^{m}
, we have

\nabla_{y}F(\tilde{x},\tilde{y})=A\tilde{x}+v+Q\tilde{y}=0.

Consequently,
For any
\tilde{x}\in X
, there exists some
\tilde{y}\in Y
such that

\tilde{y}=\arg\max_{y\in Y}F(\tilde{x},y).

Then consider the following constrained strongly convex-strongly concave min-max problem:

\displaystyle P2:\min_{x\in X}\max_{y\in Y}F(x,y).

(A.4)

Note that
F(x,y)
is strongly concave for
y
in
Y
, thus
P2
is a strongly convex-strongly concave min-max problem. Since a strongly convex (concave) function has a compact sublevel set, by
[
50
, Prop. 3.6.9]
, there exists a saddle point for problem
P2
.
Suppose that
(\bar{x},\bar{y})
is a saddle point of P2.
Since
\bar{x}\in X
, there exists
y\in Y
such that,

\bar{y}=\arg\max_{y\in Y}F(\bar{x},y)=\arg\max_{y\in\mathbb{R}^{m}}F(\bar{x},y).

(A.5)

Hence,
\nabla_{y}F(\bar{x},\bar{y})=0.

We construct a saddle point of P1.
Since
\bar{x}=\arg\min_{x\in X}F(x,\bar{y})
, by the KKT conditions, there exists some multiplier
\lambda\in\mathbb{R}^{m-r}
such that

\displaystyle\nabla f(\bar{x})+A^{T}\bar{y}+A^{T}B^{T}\lambda=0

\displaystyle BA\bar{x}=0.

Let
x^{*}=\bar{x}
and
y^{*}=\bar{y}+B^{T}\lambda
, we have

\nabla_{x}F(x^{*},y^{*})=0

and

\displaystyle\nabla_{y}F(x^{*},y^{*})

\displaystyle=

\displaystyle-Qy^{*}+v+Ax^{*}

\displaystyle=

\displaystyle(-Q\bar{y}+v+A\bar{x})+Q(\bar{y}-y^{*})

\displaystyle=

\displaystyle\nabla_{y}F(\bar{x},\bar{y})+Q(-B^{T}\lambda)

\displaystyle=

\displaystyle 0,

where the last equality is because the rows of
B
spans
\mathrm{Null}(Q)
.
We finish the proof.
\blacksquare
