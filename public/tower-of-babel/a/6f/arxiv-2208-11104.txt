Error Estimates for a Linearized Fractional Crank-Nicolson FEM for Kirchhoff type Quasilinear Subdiffusion Equation with Memory
Lalit Kumar

Abstract
In this paper, we develop a linearized fractional Crank-Nicolson-Galerkin FEM for Kirchhoff type quasilinear time-fractional integro-differential equation ( 𝒟 α ) \left(\mathcal{D}^{\alpha}\right) . In general, the solutions of the time-fractional problems exhibit a weak singularity at time t = 0 t=0 . This singular behaviour of the solutions is taken into account while deriving the convergence estimates of the developed numerical scheme. We prove that the proposed numerical scheme has an accuracy rate of O ⁡ ( M − 1 + N − 2 ) O(M^{-1}+N^{-2}) in L ∞ ​ ( 0 , T , L 2 ​ ( Ω ) ) L^{\infty}(0,T;L^{2}(\Omega)) as well as in L ∞ ​ ( 0 , T , H 0 1 ​ ( Ω ) ) L^{\infty}(0,T;H^{1}_{0}(\Omega)) , where M M and N N are the degrees of freedom in the space and time directions respectively. A numerical experiment is presented to verify the theoretical results.



Keywords:

Fractional Crank-Nicolson scheme, Finite element method (FEM), Nonlocal, Fractional time derivative, Graded mesh, Integro-differential equation.

Further complexity of the problem (

Based on the above mentioned approximations, we construct a fully discrete formulation (

In this way, this is the first work in the literature which contributes a robust and efficient second-order (in time ) accurate linearized numerical scheme for the Kirchhoff type time-fractional problems with memory operator.

u^{n}-w^{n}=\rho^{n}
and
u_{h}^{n}-w^{n}=\theta^{n}
. Using weak formulation (

W
α

), modified Ritz-Volterra projection operator (
2.7
) in the fully discrete numerical scheme (
3.24
) we get

\displaystyle\left({}^{\sigma}\mathbb{D}^{\alpha}_{t}\theta^{n},v_{h}\right)+\left(1+\|\nabla\tilde{u}_{h}^{n-1,\sigma}\|^{2}\right)\left(\nabla\theta^{n,\sigma},\nabla v_{h}\right)

(3.45)

\displaystyle=\left({}^{C}\mathcal{D}^{\alpha}_{t_{n-\sigma}}\rho,v_{h}\right)+\left(\mathcal{T}_{w}^{n-\sigma},v_{h}\right)+\left(1+\|\nabla u^{n-\sigma}\|^{2}\right)\left(\nabla\mathcal{L}_{w}^{n-\sigma},\nabla v_{h}\right)

\displaystyle+\left(\|\nabla u^{n-\sigma}\|+\|\nabla\tilde{u}_{h}^{n-1,\sigma}\|\right)\left(\|\nabla\tilde{\mathcal{L}}_{u}^{n-\sigma}+\nabla\tilde{\rho}^{n-1,\sigma}+\nabla\tilde{\theta}^{n-1,\sigma}\|\right)\left(\nabla w^{n,\sigma},\nabla v_{h}\right)

\displaystyle+\left(\mathcal{Q}^{n-\sigma}_{w},\theta^{n}\right)+\sum_{j=1}^{n-1}\tilde{\tau}_{j}(\nabla\theta^{j},\nabla v_{h}).

Put
v_{h}=\theta^{n}
in (
3.45
) and using (
3.8
) along with Cauchy-Schwarz inequality we obtain

\displaystyle{}^{\sigma}\mathbb{D}^{\alpha}_{t}\|\theta^{n}\|^{2}+\|\nabla\theta^{n}\|^{2}

(3.46)

\displaystyle\lesssim\|^{C}\mathcal{D}^{\alpha}_{t_{n-\sigma}}\rho\|~\|\theta^{n}\|+\|\mathcal{T}_{w}^{n-\sigma}\|~\|\theta^{n}\|+\left(1+\|\nabla u^{n-\sigma}\|^{2}\right)\|\nabla\mathcal{L}_{w}^{n-\sigma}\|~\|\nabla\theta^{n}\|

\displaystyle+\left(\|\nabla u^{n-\sigma}\|+\|\nabla\tilde{u}_{h}^{n-1,\sigma}\|\right)\left(\|\nabla\tilde{\mathcal{L}}_{u}^{n-\sigma}\|+\|\nabla\tilde{\rho}^{n-1,\sigma}\|+\|\nabla\tilde{\theta}^{n-1,\sigma}\|\right)\|\nabla w^{n,\sigma}\|~\|\nabla\theta^{n}\|

\displaystyle+\left(\mathcal{Q}^{n-\sigma}_{w},\theta^{n}\right)+\sum_{j=1}^{n-1}\tilde{\tau}_{j}\|\nabla\theta^{j}\|~\|\nabla\theta^{n}\|+\|\nabla\theta^{n-1}\|~\|\nabla\theta^{n}\|.

Definition of
~{}^{\sigma}\mathbb{D}^{\alpha}_{t}\|\theta^{n}\|^{2}
(
3.4
), approximation properties of modified Ritz-Volterra projection operator (
2.10
)-(
2.11
) and local truncation errors (
3.9
), (
3.12
), (
3.13
), (
3.17
) yield

\displaystyle\|\theta^{n}\|^{2}+c_{n,n}^{-1}\|\nabla\theta^{n}\|^{2}

(3.47)

\displaystyle\lesssim c_{n,n}^{-1}h^{2}~\|\theta^{n}\|+c_{n,n}^{-1}t_{n-\sigma}^{-\alpha}~N^{-\min\left\{r\alpha,~3-\alpha\right\}}~\|\theta^{n}\|

\displaystyle+c_{n,n}^{-1}\left(1+\|\nabla u^{n-\sigma}\|^{2}\right)N^{-\min\left\{r\alpha,~2\right\}}~\|\nabla\theta^{n}\|

\displaystyle+c_{n,n}^{-1}\left(\|\nabla u^{n-\sigma}\|+\|\nabla\tilde{u}_{h}^{n-1,\sigma}\|\right)\left(N^{-\min\left\{r\alpha,~2\right\}}+h+\|\nabla\tilde{\theta}^{n-1,\sigma}\|\right)\|\nabla w^{n,\sigma}\|\|\nabla\theta^{n}\|

\displaystyle+c_{n,n}^{-1}N^{-\min\left\{r(1+\alpha),~2\right\}}\|\nabla\theta^{n}\|+c_{n,n}^{-1}\sum_{j=1}^{n-1}\tilde{\tau}_{j}\|\nabla\theta^{j}\|~\|\nabla\theta^{n}\|+c_{n,n}^{-1}\|\nabla\theta^{n-1}\|~\|\nabla\theta^{n}\|

\displaystyle+c_{n,n}^{-1}\sum_{j=1}^{n-1}\left(c_{n,j+1}-c_{n,j}\right)\|\theta^{j}\|^{2}.

Using the definition of weighted
H^{1}(\Omega)
norm (
3.25
) and a priori bound on weak solution
u
(
2.5
), fully discrete solution
u_{h}^{n}
(
3.27
) and modified Ritz-Volterra projection operator (
2.8
) in (
3.47
) we obtain

\displaystyle\||\theta^{m}\||

\displaystyle\lesssim c_{m,m}^{-1}h^{2}+c_{m,m}^{-1}t_{m-\sigma}^{-\alpha}~N^{-\min\left\{r\alpha,~3-\alpha\right\}}+c_{m,m}^{-1/2}N^{-\min\left\{r\alpha,~2\right\}}

(3.48)

\displaystyle+c_{m,m}^{-1/2}\left(N^{-\min\left\{r\alpha,~2\right\}}+h\right)+c_{m,m}^{-1/2}N^{-\min\left\{r(1+\alpha),~2\right\}}

\displaystyle+c_{m,m}^{-1/2}\sum_{j=1}^{m-1}\tilde{w}_{j}c_{j,j}^{1/2}\||\theta^{j}\||+c_{m,m}^{-1}\sum_{j=1}^{m-1}\left(c_{m,j+1}-c_{m,j}\right)\||\theta^{j}\||,

where

\tilde{w}_{j}=\begin{cases}\tilde{\tau}_{j},&1\leq j\leq m-3,\\
1+\tilde{\tau}_{j},&j=m-2,\\
2+\tilde{\tau}_{j},&j=m-1.\end{cases}

(3.49)

Using
c_{m,m}^{-1}\lesssim\tau_{m}^{\alpha}\lesssim t_{m}^{\alpha}
and discrete Gronwall inequality we obtain

\displaystyle\||\theta^{m}\||

\displaystyle\lesssim\left(h+N^{-\min\left\{r\alpha,~2\right\}}\right)\exp\left(\sum_{j=1}^{m-1}\tilde{w}_{m,j}\right),

(3.50)

where
\tilde{w}_{m,j}=c_{m,m}^{-1/2}\tilde{w}_{j}c_{j,j}^{1/2}+c_{m,m}^{-1}\left(c_{m,j+1}-c_{m,j}\right)
.
Follow the proof of estimate (
3.35
) to conclude

\||\theta^{m}\||\lesssim\left(h+N^{-\min\left\{r\alpha,~2\right\}}\right).

(3.51)

Finally triangle inequality and the best approximation property (
2.10
) implies

\|u^{m}-u_{h}^{m}\|\lesssim\|\rho^{m}\|+\|\theta^{m}\|\lesssim h^{2}+h+N^{-\min\left\{r\alpha,~2\right\}}\lesssim h+N^{-\min\left\{r\alpha,~2\right\}}.

(3.52)

By choosing
h=M^{-1}
, where
M
is the degree of freedom in the space direction we get

\|u^{m}-u_{h}^{m}\|\lesssim\left(M^{-1}+N^{-\min\left\{r\alpha,~2\right\}}\right).

(3.53)

Similar approach will work for the case
n=1
also.

To prove the estimate (
3.44
) one case use (
3.43
) but then we will have a loss of accuracy of order
\left(\frac{\alpha}{2}\right)
as follows

\|\nabla u^{m}-\nabla u_{h}^{m}\|\lesssim\tau_{m}^{-\alpha/2}\left(M^{-1}+N^{-\min\left\{r\alpha,~2\right\}}\right).

(3.54)

To recover this loss of accuracy, we make use of the discrete Laplacian operator (
2.9
).
Substitute
v_{h}=-\Delta_{h}\theta^{n}
in (
3.45
) and follow the arguments of the proof of estimate (
3.53
) to conclude (
3.44
).

5
Concluding remarks

In this work, we developed a linearized fractional Crank-Nicolson-Galerkin scheme (
3.23
)-(
3.24
) which reduces the computational cost in comparison to the Newton-Raphson method. Using a weighted
H^{1}(\Omega)
norm (
3.25
), we derived a priori bounds (
3.26
) and convergence estimates (
3.43
)-(
3.44
) for the solutions of the proposed numerical scheme. We proved that the convergence rates are of
O\left(M^{-1}+N^{-2}\right)
in
L^{\infty}(0,T;L^{2}(\Omega))
norm as well as in
L^{\infty}(0,T;H^{1}_{0}(\Omega))
norm. Finally we offered the numerical results which perfectly support the sharpness of the theoretical claims.
