CRIL: A Concurrent Reversible Intermediate Language
Shunya Oguchi Shoji Yuen

Abstract
We present a reversible intermediate language with concurrency for translating a high-level concurrent programming language to another lower-level concurrent programming language, keeping reversibility. Intermediate languages are commonly used in compiling a source program to an object code program closer to the machine code, where an intermediate language enables behavioral analysis and optimization to be decomposed in steps. We propose CRIL (Concurrent Reversible Intermediate Language) as an extension of RIL used by Mogensen for a functional reversible language, incorporating a multi-thread process invocation and the synchronization primitives based on the P-V operations. We show that the operational semantics of CRIL enjoy the properties of reversibility, including the causal safety and causal liveness proposed by Lanese et al., checking the axiomatic properties. The operational semantics is defined by composing the bidirectional control flow with the dependency information on updating the memory, called annotation DAG . We show a simple example of ‘airline ticketing’ to illustrate how CRIL preserves the causality for reversibility in imperative programs with concurrency.

Introduction

Reversible programming languages have been proposed to describe
reversible computation where the control flows
both forward and backward
[
25
,
5
,
24
,
7
]
.
They directly describe reversible computation and develop new
aspects of software development since reversibility holds all information
at any point of execution. In forward-only execution, the computation
can overwrite the part of its intermediate history unless it is used
in the following computation for efficiency.
In analyzing the behavior, such as debugging, it is common to replay
the execution to the point in focus to recreate the lost part of history.
For a concurrent program, replaying the execution is usually difficult since
updating shared resources among multiple control threads
depends on the runtime environment.

Intermediate languages mediate the translation from the source language
to a low-level machine language for execution. Step-by-step translation
via intermediate languages is a common technique for optimization in
compilers. The intermediate language in LLVM
[
15
]
is often used as a behavioral
model for program analysis.

Mogensen uses RIL
[
17
]
as an intermediate language with reversibility
for a functional reversible language in the memory usage analysis.
RSSA
[
18
]
based on RIL is used
for compiling and optimizing Janus programs
[
10
,
4
]
.
Reversibility with concurrency has been studied in
process calculi
[
3
,
21
,
12
,
11
]
,
in event structures
[
19
,
20
,
22
,
16
]

and recently in programming languages such as Erlang
[
13
]
and
a simple imperative programming language
[
7
,
9
]
.

We propose a reversible intermediate language CRIL by extending
RIL. CRIL extends RIL by allowing multiple blocks to run
concurrently and the synchronization primitive based on the P-V operations.
In CRIL, concurrent blocks interact with each other via shared variables.
To establish the reversibility for concurrent programs, the causality among
shared variables has to be preserved. Unlike sequential reversible
programs, even if one step of a program is reversible, the whole program is not reversible in general
since shared variables may not be reversed correctly.

To make a program of CRIL reversible, we give the operational semantics as the labeled
transition system,
\mbox{\it LTSI}_{CRIL}
, as
the composition of the operational semantics with one-step reversibility and
a data structure called ‘annotation DAG’.
An annotation DAG accumulates the causality of updating memory in a forward
execution and rolls back the causality to control the
reversed flow in the backward execution. We show that
\mbox{\it LTSI}_{CRIL}
has the basic properties
for reversibility proposed in
[
14
]
. Using the approach of

[
14
]
, it is shown that
\mbox{\it LTSI}_{CRIL}
enjoys the
Causal Safety

and the
Causal Liveness
, which are important in analyzing CRIL programs compositionally.

By translating a high-level programming language to CRIL,
\mbox{\it LTSI}_{CRIL}
works as a virtual machine,
and its behavior is guaranteed to be reversible. CRIL enables fine-grained behavioral analysis
such as optimization and reversible debugging. In section 4, we present a simple example of
airline ticketing given in
[
6
]
to enable reversible debugging.

The paper is organized as follows. Section 2 presents the syntax of CRIL
and the operational semantics for control flow. Section 3 introduces
annotation DAG as a data structure to store the causality of updating
memory. We define
\mbox{\it LTSI}_{CRIL}
as the operational semantics for CRIL
and show the reversibility of
\mbox{\it LTSI}_{CRIL}
, which is followed by the airline ticketing example
in section 4. Section 5 presents concluding remarks.

Square Property(SP)

For
a\in\mathsf{Lab}
, when
C\xrightleftharpoons{\ \ a\ \ }_{\hskip-7.83612pt\mathrm{\mathrm{{\ prog\ }}}}C^{\prime}
, we write

C\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{\ prog\ }}C^{\prime}
and
C^{\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{\ prog\ }}C
.
Similarly, when
A\xrightleftharpoons{\ \ a\ \ }_{\hskip-7.83612pt\mathrm{\mathrm{\ ann\ }}}A^{\prime}
, we write

A\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{\ ann\ }}A^{\prime}
and
A^{\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{\ ann\ }}A
.

By the definition of the independence transitions, the square property of
the
\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{\ prog\ }}
is immediately shown.

Proposition 3
.

Suppose
C\xrightarrow{\alpha}_{\mathrm{{prog}}}C^{\prime}
,
C\xrightarrow{\beta}_{\mathrm{{prog}}}C^{\prime\prime}
,
and
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then there are the cofinal transitions
C^{\prime}\xrightarrow{\beta}_{\mathrm{{prog}}}C^{\prime\prime\prime}
and

C^{\prime\prime}\xrightarrow{\alpha}_{\mathrm{{prog}}}C^{\prime\prime\prime}
.

For annotation DAGs, we need to trace the difference of nodes and edges
added or deleted by
\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}
to show the square property.
We use the following notation to present differences in annotation DAGs:

For
o:(V,E_{R},E_{W})\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}(V^{\prime},E^{\prime}_{R},E^{\prime}_{W})
,

\mathsf{diff}(o)=\begin{cases}(V^{\prime}-V,E^{\prime}_{R}-E_{R},E^{\prime}_{W}-E_{W})&\mbox{if }\alpha\in\mathsf{Lab},\\
(V-V^{\prime},E_{R}-E^{\prime}_{R},E_{W}-E^{\prime}_{W})&\mbox{if }\alpha\in\underline{\mathsf{Lab}}\end{cases}

(V,E_{R},E_{W})\odot^{\alpha}(\Delta V,{\Delta E_{R}},{\Delta E_{W}})=\begin{cases}(V\cup\Delta V,E_{R}\cup{\Delta E_{R}},E_{W}\cup{\Delta E_{W}})&\mbox{if }\alpha\in\mathsf{Lab},\\
(V-\Delta V,E_{R}-{\Delta E_{R}},E_{W}-{\Delta E_{W}})&\mbox{if }\alpha\in\underline{\mathsf{Lab}}\end{cases}

Proposition 4
.

Let
\mathsf{diff}(A\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})=(\Delta V^{\alpha},\Delta E_{R}^{\alpha},\Delta E_{W}^{\alpha})

and
\mathsf{diff}(A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime})=(\Delta V^{\beta},\Delta E_{R}^{\beta},\Delta E_{W}^{\beta})

with
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then,
\Delta V^{\alpha}\cap\Delta V^{\beta}=\Delta E_{R}^{\alpha}\cap\Delta E^{\beta}_{R}=\Delta E^{\alpha}_{W}\cap\Delta E^{\beta}_{W}=\varnothing
.

Proof.

For some
v_{\alpha}
and
v_{\beta}
,

\Delta V^{\alpha}=\{v_{\alpha}\}
and
\Delta V^{\beta}=\{v_{\beta}\}
.

\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
implies
v_{\alpha}\neq v_{\beta}
.
All the edges of
\Delta E_{R}^{\alpha}\uplus\Delta E^{\alpha}_{W}
come into
v_{\alpha}

and all the edges of
\Delta E_{R}^{\beta}\uplus\Delta E^{\beta}_{W}
come into
v_{\beta}
.
Therefore,
\Delta V^{\alpha}\cap\Delta V^{\beta}=\Delta E_{R}^{\alpha}\cap\Delta E^{\beta}_{R}=\Delta E^{\alpha}_{W}\cap\Delta E^{\beta}_{W}=\varnothing
.
∎

Proposition 5
.

Suppose
A\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime}

and
A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime}

with
a\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then
there is
A^{\prime\prime\prime}
such that

A^{\prime\prime}\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}

and
\mathsf{diff}(A\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})=\mathsf{diff}(A^{\prime\prime}\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime})
.

Proof.

Assume
A=(V,E_{R},E_{W})
,
A^{\prime\prime}=(V^{\prime\prime},E^{\prime\prime}_{R},E^{\prime\prime}_{W})
,
and
a=(p_{a},Rd_{a},Wt_{a})
.

A^{\prime\prime}\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}
for some
A^{\prime\prime\prime}
since
a\in\mathsf{Lab}
.

a\mathrel{\iota}_{\mathrm{lab}}\beta
implies that

\mathsf{max}_{p_{a}}(A)=\mathsf{max}_{p_{a}}(A^{\prime\prime})
and

\mathsf{last}(r,E_{W})=\mathsf{last}(r,E^{\prime\prime}_{W})

for
r\in Rd_{a}
.
Therefore,
\mathsf{diff}(A\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})=\mathsf{diff}(A^{\prime\prime}\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime})
.
∎

Proposition 6
.

Suppose
A\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime}

and
A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime}

with
\underline{a}\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then
there is
A^{\prime\prime\prime}
such that

A^{\prime\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}

and
\mathsf{diff}(A\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})=\mathsf{diff}(A^{\prime\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime})
.

Proof.

Assume
\mathsf{diff}(A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime})=(\Delta V^{\beta},\Delta E_{R}^{\beta},\Delta E_{W}^{\beta})
,
and
a=(p_{a},Rd_{a},Wt_{a})
.
Let
v=(p_{a},\mathsf{max}_{p_{a}}(V))
.

\underline{a}\mathrel{\iota}_{\mathrm{lab}}\beta
implies that
no edges in
\Delta E^{\beta}_{R}\uplus\Delta E^{\beta}_{W}
go out from
v

and
v^{\prime}
such that
v^{\prime}\stackrel{{\scriptstyle r}}{{\dashrightarrow}}v
in
A
.
Therefore,
A^{\prime\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}
for some
A^{\prime\prime\prime}
.

\underline{a}\mathrel{\iota}_{\mathrm{lab}}\beta
and
\underline{a}\in\underline{\mathsf{Lab}}
derive

\mathsf{diff}(A\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})=\mathsf{diff}(A^{\prime\prime}\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime})
.
∎

Proposition 7
.

Suppose
A\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime}

and
A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime}

with
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then
A^{\prime\prime}\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}
,
where
A^{\prime\prime\prime}=A^{\prime\prime}\odot^{\alpha}\mathsf{diff}(A\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})

Proof.

Proposition
5
and
6

derive
A^{\prime\prime}\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime\prime}
.

Proposition 8
.

Suppose
A\xrightarrow{\alpha}_{\mathrm{ann}}A^{\prime}
,

A\xrightarrow{\beta}_{\mathrm{ann}}A^{\prime\prime}
,
and
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
.
Then there are the cofinal transitions

A^{\prime}\xrightarrow{\beta}_{\mathrm{ann}}A^{\prime\prime\prime}
and

A^{\prime\prime}\xrightarrow{\alpha}_{\mathrm{ann}}A^{\prime\prime\prime}
.

Proof.

By proposition
4
,
\mathsf{diff}(A\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime})
and

\mathsf{diff}(A\stackrel{{\scriptstyle\beta}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime\prime})
are disjoint if
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta

we have

and

∎

Lemma 1

(Square Property)
.

Whenever

t:{(C_{P},A_{P})}\xrightarrow{\alpha}{(C_{Q},A_{Q})}
,

u:{(C_{P},A_{P})}\xrightarrow{\beta}{(C_{R},A_{R})}
,
and
t\mathrel{\iota}u
,
then there are cofinal transitions

u^{\prime}:{(C_{Q},A_{Q})}\xrightarrow{\beta}{(C_{S},A_{S})}
,
and
t^{\prime}:{(C_{R},A_{R})}\xrightarrow{\alpha}{(C_{S},A_{S})}
.

Backward Transitions are Independent (BTI)

BTI
is useful for reversibility because an available backward
transition does not depend on any other backward transition. In CRIL,
a label of
\mbox{\it LTSI}_{CRIL}
gives the information to establish BTI.

Lemma 2

(Backward Transitions are Independent)
.

Whenever
t:{(C_{P},A_{P})}\xrightarrow{\underline{a}}{(C_{Q},A_{Q})}
,

u:{(C_{P},A_{P})}\xrightarrow{\underline{b}}{(C_{R},A_{R})}
,
and
t\neq u
,
then
t\mathrel{\iota}u
.

Proof.

Assume
A_{P}=(V,E_{R},E_{W})
,

a=(p_{a},Rd_{a},Wt_{a})
, and
b=(p_{b},Rd_{b},Wt_{b})
.
Let
v_{a}=(p_{a},\mathsf{max}_{p_{a}}(V))

and
v_{b}=(p_{b},\mathsf{max}_{p_{b}}(V))
.

Assume
p_{a}\preceq p_{b}
.
Then
p_{a}=p_{b}
holds from the operational semantics.

p_{a}=p_{b}
derives
t=u
, which contradicts
t\neq u
.
Therefore,
p_{a}\not\preceq p_{b}
holds.
Similarly,
p_{b}\not\preceq p_{a}
also holds.

Assume
Rd_{a}\cap Wt_{b}\neq\varnothing
.
There exists
r\in Rd_{a}\cap Wt_{b}
.
If
r\in Wt_{a}
, then
\mathsf{last}(r,E_{W})=v_{a}
and

\mathsf{last}(r,E_{W})=v_{b}
.
Therefore
p_{a}=p_{b}
, however it contradicts
p_{a}\not\preceq p_{b}
.
If
r\not\in Wt_{a}
, then
\mathsf{last}(r,E_{W})\stackrel{{\scriptstyle r}}{{\dashrightarrow}}v_{a}\in E_{R}
.

r\in Wt_{b}
derives
\mathsf{last}(r,E_{W})=v_{b}
.
Therefore
v_{b}\stackrel{{\scriptstyle r}}{{\dashrightarrow}}v_{a}\in E_{R}
, however it contradicts
that no edges go out from
v_{b}
derived from
u
.
Therefore
Rd_{a}\cap Wt_{b}=\varnothing
.
Similarly,
Rd_{b}\cap Wt_{a}=\varnothing
also holds.
∎

Well-Foundedness (WF)

For a backward transition
(C,A)\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}(C^{\prime},A^{\prime})
, the number of nodes of
A^{\prime}

is strictly less than that of
A
.
Since the number of vertices of annotation DAG is finite,
it is not possible to remove vertices infinitely.

Coinitial Propagation of Independence (CPI)

Given a commuting square with independence at one corner, CPI allows us
to deduce independence between coinitial transitions at the other three corners.

Lemma 3

(Coinitial Propagation of Independence)
.

Suppose

t:{(C_{P},A_{P})}\xrightarrow{\alpha}{(C_{Q},A_{Q})}
,

u:{(C_{P},A_{P})}\xrightarrow{\beta}{(C_{R},A_{R})}
,

u^{\prime}:{(C_{Q},A_{Q})}\xrightarrow{\beta}{(C_{S},A_{S})}
,

t^{\prime}:{(C_{R},A_{R})}\xrightarrow{\alpha}{(C_{S},A_{S})}
,
and
t\mathrel{\iota}u
.
Then
u^{\prime}\mathrel{\iota}\underline{t}
.

Proof.

t\mathrel{\iota}u
implies
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
.
Since
\beta\mathrel{\iota}_{\mathrm{lab}}\underline{\alpha}
,

u^{\prime}\mathrel{\iota}\underline{t}
.
∎

3.3.2
Events

The properties above make
\mbox{\it LTSI}_{CRIL}
pre-reversible.
Next, we check if
\mbox{\it LTSI}_{CRIL}
can derive
events for establishing reversibility.
Following
[
14
]
,
events in
\mbox{\it LTSI}_{CRIL}
are derived as an equivalence over transitions.

Definition 8
.

Let
\sim
be the smallest equivalence relation on transitions satisfying:
if
t:{(C_{P},A_{P})}\xrightarrow{\alpha}{(C_{Q},A_{Q})}
,

u:{(C_{P},A_{P})}\xrightarrow{\beta}{(C_{R},A_{R})}
,

u^{\prime}:{(C_{Q},A_{Q})}\xrightarrow{\beta}{(C_{S},A_{S})}
,

t^{\prime}:{(C_{R},A_{R})}\xrightarrow{\alpha}{(C_{S},A_{S})}
,
and
t\mathrel{\iota}u
,
then
t\sim t^{\prime}
.
The equivalence classes of forward transitions
[(C_{P},A_{P})\stackrel{{\scriptstyle a}}{{\rightarrow}}(C_{Q},A_{Q})]
,
are the events.
The equivalence classes of backward transitions
[(C_{P},A_{P})\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}(C_{Q},A_{Q})]
,
are the reverse events.

Given
\gamma=\alpha_{1}\cdots\alpha_{n}\in(\mathsf{Lab}\uplus\underline{\mathsf{Lab}})^{\ast}
, a sequence of transitions

(C_{0},A_{0})\stackrel{{\scriptstyle\alpha_{1}}}{{\rightarrow}}\cdots\stackrel{{\scriptstyle\alpha_{n}}}{{\rightarrow}}(C_{n},A_{n})
is written as
s:(C_{0},A_{0})\stackrel{{\scriptstyle\gamma}}{{\rightarrow}}_{\ast}(C_{n},A_{n})
.

Since the transitions of program configurations in
\mbox{\it LTSI}_{CRIL}

\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{prog}}

have no control for reversibility,
events are substantially derived from the operations of annotation DAGs.

Definition 9
.

Let
\sim_{\mathrm{ann}}
be the smallest equivalence relation over operations of annotation DAGs satisfying:
if
o_{1}:A_{P}\xrightarrow{\alpha}_{\mathrm{ann}}A_{Q}
,

o_{2}:A_{P}\xrightarrow{\beta}_{\mathrm{ann}}A_{R}
,

o_{2}^{\prime}:A_{Q}\xrightarrow{\beta}_{\mathrm{ann}}A_{S}
,

o_{1}^{\prime}:A_{R}\xrightarrow{\alpha}_{\mathrm{ann}}A_{S}
,
and
\alpha\mathrel{\iota}_{\mathrm{lab}}\beta
,
then
o_{1}\sim o^{\prime}_{1}
.
[A\stackrel{{\scriptstyle a}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime}]_{\mathrm{ann}}
and
[A\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}_{\mathrm{ann}}A^{\prime}]_{\mathrm{ann}}
are the forward and
backward equivalence classes by
\sim_{\mathrm{ann}}
.

Proposition 9
.

For
t:{(C_{P},A_{P})}\xrightarrow{\alpha}{(C_{Q},A_{Q})}
and

t^{\prime}:{(C_{R},A_{R})}\xrightarrow{\alpha}{(C_{S},A_{S})}
, the following holds.

t\sim t^{\prime}

iff
o\sim_{\mathrm{ann}}o^{\prime}

and
\exists\gamma.(C_{P},A_{P})\stackrel{{\scriptstyle\gamma}}{{\rightarrow}}_{\ast}(C_{R},A_{R})

where
o:A_{P}\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A_{Q}
and
o^{\prime}:A_{R}\stackrel{{\scriptstyle\alpha}}{{\rightarrow}}_{\mathrm{ann}}A_{S}
.

Intuitively, operations for annotation DAGs are independent if they add or remove
nodes and edges at unrelated places. If
o_{1}\sim_{\mathrm{ann}}o_{2}
, then
o_{1}
and

o_{2}
add or remove the same fragment of annotation DAGs to or from the nodes
of the same causality. In
\mbox{\it LTSI}_{CRIL}
, the equivalence over operations of annotation DAGs
is considered as an
event
.
This shows that events for reversibility are consistently defined over

\mbox{\it LTSI}_{CRIL}
, meaning the operational semantics is detailed enough to give
the
IRE
property as follows, which is necessary for our objectives.

Independence Respects Events (IRE)

Lemma 4

(Independence Respects Events)
.

Suppose
t\sim t^{\prime}\mathrel{\iota}u
.
Then
t\mathrel{\iota}u
.

Proof.

If
t\sim t^{\prime}
,
t
has the same label as
t^{\prime}
. Then,
t\mathrel{\iota}u
.
∎

Causal Safety and Causal Liveness

Let
\sharp(s,[A\stackrel{{\scriptstyle a}}{{\rightarrow}}A^{\prime}]_{\mathrm{ann}})
be the number of occurrences of transitions
t
in
s

such that
t\in[(C,A)\stackrel{{\scriptstyle a}}{{\rightarrow}}(C^{\prime},A^{\prime})]

the number of occurrences of transitions
t
in
s
such that

t\in[(C,A)\stackrel{{\scriptstyle\underline{a}}}{{\rightarrow}}(C^{\prime},A^{\prime})]

Using the result of
[

]

1

Theorem 1

(Causal Safety)
.

Whenever
(C_{P},A_{P})\xrightarrow{a}(C_{Q},A_{Q})

for all
t
in
s

(Causal Liveness)
.

Whenever
{(C_{P},A_{P})}\xrightarrow{a}{(C_{Q},A_{Q})}
,

s:{(C_{Q},A_{Q})}\xrightarrow{\gamma}_{*}{(C_{R},A_{R})}

\sharp(s,[A_{P}\stackrel{{\scriptstyle a}}{{\rightarrow}}A_{Q}])=0
,
and
{(C_{P},A_{P})}\stackrel{{\scriptstyle a}}{{\rightarrow}}{(C_{Q},A_{Q})}\mathrel{\iota}t:(C,A)\stackrel{{\scriptstyle b}}{{\rightarrow}}(C^{\prime},A^{\prime})
for all
t
in
s

such that
\sharp(s,[A\stackrel{{\scriptstyle a}}{{\rightarrow}}A^{\prime}])>0

with
{(C_{P},A_{P})}\stackrel{{\scriptstyle a}}{{\rightarrow}}{(C_{Q},A_{Q})}\sim{(C_{S},A_{S})}\stackrel{{\scriptstyle a}}{{\rightarrow}}{(C_{R},A_{R})}

{(C_{S},A_{S})}\xrightarrow{a}{(C_{R},A_{R})}

{(C_{P},A_{P})}\stackrel{{\scriptstyle a}}{{\rightarrow}}{(C_{Q},A_{Q})}\sim{(C_{S},A_{S})}\stackrel{{\scriptstyle a}}{{\rightarrow}}{(C_{R},A_{R})}

5
Concluding remarks

We have proposed CRIL as a reversible concurrent intermediate language.
CRIL is an extension of RIL
[
17
]
to enable running multiple
subroutines as processes running in parallel.
CRIL is intended to be fairly low-level in that each instruction is at a level
similar to the three-address codes to mediate
the translation from a high-level program to a machine-oriented code.
The operational semantics of CRIL defined as
\mbox{\it LTSI}_{CRIL}
is shown to have
the properties of Causal Safety and Causal Liveness under the independence of
concurrent processes and shared memory update. By the result of
[
14
]
,

\mbox{\it LTSI}_{CRIL}
also satisfies other properties: Parabolic lemma, Causal Consistency, Unique
Transition, and Independence of Diamonds.

As related work,

[
2
]
provides a compiler from ROOPL++
to PISA
[
23
]

with no intermediate language, where the translation from an object-oriented source program to the low-level PISA code
is a big task.

[
7
]
proposes an annotation to a concurrent imperative
program while executing forward, where the annotation is attached directly to the source program
for reversing the execution.

[
8
]
investigates its properties of reversibility.
CRIL uses a similar idea as Hoey’s, but CRIL is at a rather lower level
to provide a finer granularity for
detailed analysis in translation, such as optimization.

[
9
]
presents a collection of
simple stack machines with a fork and merge
mechanism, where the causality is embedded in the runtime.

For future work, we have focused only on the fundamental properties. We will investigate further how more properties in reversibility
contribute to behavioral analysis for concurrent programs. Currently, the dependency of
the heap memory
M
is treated as one memory resource.
More detailed dependency is necessary for practical use.
Deriving the optimization technique in the front-end part of compilers is
future work via the reversible version of SSA, such as RSSA
[
18
]
for
concurrent imperative programs.
CRIL is based on the shared memory model.
Incorporating channel-based communications is also future work
to use for the message-passing model like Erlang
[
13
]
.
