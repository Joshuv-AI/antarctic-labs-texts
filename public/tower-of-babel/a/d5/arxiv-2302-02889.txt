Matrix factorizations and pentagon maps
Pavlos Kassotakis

Abstract
. We propose a specific class of matrices which participate in factorization problems that turn to be equivalent to constant and entwining (non-constant) pentagon, reverse-pentagon or Yang-Baxter maps, expressed in non-commutative variables. In detail, we show that factorizations of order N = 2 N=~2 matrices of this specific class are equivalent to the homogeneous normalization map . From order N = 3 N=3 matrices, we obtain an extension of the homogeneous normalization map, as well as novel entwining pentagon, reverse-pentagon and Yang-Baxter maps.

Remark 2.1
.

Let
\tau:\mathbb{X}\times\mathbb{X}\mapsto\mathbb{X}\times\mathbb{X}
the transposition map i.e.
\tau:(x,y)\mapsto(y,x).
For pentagon and reverse-pentagon maps it is easy to verify the following:

•

a map
S:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{X}\times\mathbb{X},
is a pentagon map if and only if
\tau\circ S\circ\tau
is a reverse-pentagon map;

•

an invertible map
S:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{X}\times\mathbb{X},
is a pentagon map if and only if
S^{-1}
is a reverse-pentagon map;

•

an invertible map
S:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{X}\times\mathbb{X},
is a pentagon map if and only if
\tau\circ S^{-1}\circ\tau
is a pentagon map. The map
\tau\circ S^{-1}\circ\tau
is referred to as the opposite pentagon map and it is denoted as
S^{op}.
Similar statements hold for reverse-pentagon maps.

Proposition 2.2
.

Let
S^{(q)}:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{X}\times\mathbb{X},

q\in\{1,\ldots,5\},
be entwining (non-constant) pentagon maps and let be the maps
\chi,\psi:\mathbb{X}\rightarrow\mathbb{X}.
Then the maps

\displaystyle Q^{(1)}:=(\chi\times id)\circ S^{(1)},

\displaystyle Q^{(2)}:=(\chi\times id)\circ S^{(2)},

\displaystyle Q^{(4)}:=S^{(4)}\circ(id\times\psi),

\displaystyle Q^{(5)}:=S^{(5)}\circ(id\times\psi),

satisfy the following entwining (non-constant) pentagon equation

(2)

\displaystyle Q^{(1)}_{12}\circ S^{(3)}_{13}\circ Q^{(5)}_{23}=Q^{(4)}_{23}\circ Q^{(2)}_{12}.

Mappings
\chi
and
\psi,
will be called boundary maps.

A similar statement holds for the entwining (non-constant) reverse-pentagon maps

\displaystyle\bar{S}^{(q)}:\mathbb{X}\times\mathbb{X}\rightarrow\mathbb{X}\times\mathbb{X},

\displaystyle q\in\{1,\ldots,5\}.

Proof.

Since
S^{(q)}
are non-constant pentagon maps, we have

\displaystyle Q^{(1)}_{12}\circ S^{(3)}_{13}\circ Q^{(5)}_{23}=\chi_{1}\circ S^{(1)}_{12}\circ S^{(3)}_{13}\circ S^{(5)}_{23}\circ\psi_{3}=\chi_{1}\circ S^{(4)}_{23}\circ S^{(2)}_{12}\circ\psi_{3}.

But there is

\displaystyle\chi_{1}\circ S^{(4)}_{23}\circ S^{(2)}_{12}\circ\psi_{3}=S^{(4)}_{23}\circ\psi_{3}\circ\chi_{1}\circ S^{(2)}_{12}=Q^{(4)}_{23}\circ Q^{(2)}_{12},

and that proves that relation (
2
) holds.
∎

3.
Matrix factorizations pentagon and reverse-pentagon maps

Let
I_{N}
the order
N
identity matrix and let
p_{k},

k\in\{1,\ldots,K\},

be a set of
k
distinct positive integers
l_{j}
i.e.

p_{k}=\{l_{1},\ldots,l_{k}\},\quad k\in\{1,\ldots,K\}.

Let also
q_{\lambda},

\lambda\in\{1,\ldots,K\},
be a set of
\lambda
distinct positive integers
m_{j}
i.e.

q_{\lambda}=\{m_{1},\ldots,m_{\lambda}\}.

Denote with
V_{j}(x),

j\in p_{k}
the
N-
component row vectors

V_{j}(x):=(x^{l_{j},1},x^{l_{j},2},\ldots,x^{l_{j},N}),

with
x^{l_{j},1},x^{l_{j},2},\ldots,x^{l_{j},N}
elements of a skew field.

We consider the matrices
A^{p_{k}}(x),
which are defined by substituting the lines
l_{1},\ldots,l_{k}
of the identity matrix
I_{N}
with the vectors
V_{1}(x),\ldots,V_{k}(x),
respectively. Similarly we define the matrices
A^{q_{\lambda}}(x).
The matrices
A^{p_{k}}(x)
and
A^{q_{\lambda}}(x)
participate in the following re-factorization problems

(4)

\displaystyle A^{p_{k}}(u)A^{q_{\lambda}}(v)=A^{q_{\lambda}}(y)A^{p_{k}}(x).

Unless otherwise stated, among the re-factorisation problems (
4
) we concentrate to the ones that:

(1)

|p_{k}|=|q_{\lambda}|
so
k=\lambda;

(2)

p_{k}\cap q_{\lambda}=\emptyset;

(3)

k=N/2,
when
N
is even,
k=(N-1)/2,
when
N
is odd.

When the three conditions above are satisfied, without loss of generality we have

•

p_{k}=p=\{1,\ldots,N/2\},

q_{k}=q=\{N/2+1,\ldots,N\},
when
N
is even,

•

p_{k}=p=\{1,\ldots,\frac{N-1}{2}\},

q_{k}=q=\{\frac{N-1}{2}+1,\ldots,N-1\},
when
N
is odd.

Then we have the single re-factorization problem

(5)

\displaystyle A^{p}(u)A^{q}(v)=A^{q}(y)A^{p}(x),

that turns equivalent to the map

\phi^{p,q}:(x,y)\mapsto(u,v)=(u(x,y),v((x,y)).

The following statements are in order.

(1)

The map
\phi^{p,q}
is a pentagon map.

(2)

The inverse map
\left(\phi^{p,q}\right)^{-1},
is equivalent to
A^{q}(v)A^{p}(u)=A^{p}(x)A^{q}(y).

(3)

Mapping
\phi^{p,q}
is birational.

(4)

For the map
\phi^{q,p},
there is

\phi^{q,p}=\tau\circ\left(\phi^{p,q}\right)^{-1}\circ\tau\equiv\left(\phi^{q,p}\right)^{op},

and it is equivalent to

\displaystyle A^{q}(u)A^{p}(v)=A^{p}(y)A^{q}(x).

(5)

The re-factorization problem

(6)

\displaystyle\left(A^{p}(u)\right)^{T}\left(A^{q}(v)\right)^{T}=\left(A^{q}(y)\right)^{T}\left(A^{p}(x)\right)^{T},

where the superscript
(T)
stands for the transpose of a matrix, turns equivalent to the reverse-pentagon map

\bar{\phi}^{p,q}:(x,y)\mapsto(u,v)=(u(x,y),v((x,y)).

The statements above can be easily proven. For instance let us sketch the proof of statement
(1)
. For the proof we have to distinguish two cases, that is when the order
N
of the matrices is even or odd. For even
N
(
N=2k
), we have
p=\{1,\ldots,k\}
and
q=\{k+1,\ldots,2k\}
so

\displaystyle A^{\{1,\ldots,k\}}(x)=\left(\begin{array}[]{c|c}{\bf x}^{1}&{\bf x}^{2}\\
\hline\cr{\bf 0}_{k}&{\bf I}_{k}\end{array}\right),

\displaystyle A^{\{k+1,\ldots,2k\}}(x)=\left(\begin{array}[]{c|c}{\bf I}_{k}&{\bf 0}_{k}\\
\hline\cr{\bf x}^{1}&{\bf x}^{2}\end{array}\right),

where
{\bf 0}_{k}
the order
k
zero matrix,
{\bf I}_{k}
the order
k
identity matrix and
{\bf x}^{i},

i=1,2,
stands for
k\times k
block matrices. Then it is clear that the re-factorization problem

\displaystyle A^{\{1,\ldots,k\}}(u)A^{\{k+1,\ldots,2k\}}(v)=A^{\{k+1,\ldots,2k\}}(y)A^{\{1,\ldots,k\}}(x),

coincides with the
N=2
re-factorization problem

(7)

\displaystyle A^{\{1\}}(u)A^{\{2\}}(v)=A^{\{2\}}(y)A^{\{1\}}(x),

when we consider the variables
x^{1,j},y^{1,j},u^{1,j},v^{1,j},

j=1,2,
that participate in (
7
) to be
k\times k
matrices with entries in
A^{\times}.
So what is valid for the order
N=2
re-factorization problem (
7
), also holds for the re-factorization problem of order
N=2k.
In the following Section we prove that (
7
) is equivalent to a pentagon map and that together with a similar analysis on odd-order re-factorization problems of the form (
5
), suffices as a proof of statement
(1)
.

3.1.

and the

For

there is

0&1\end{pmatrix},\quad A^{\{2\}}(x)=\begin{pmatrix}1&0\\

and the re-factorization problem

A^{\{1\}}(u)A^{\{2\}}(v)=A^{\{2\}}(y)A^{\{1\}}(x),

that reads:

(8)

\displaystyle\begin{pmatrix}u^{1,1}+u^{1,2}v^{2,1}&u^{1,2}v^{2,2}\\
v^{2,1}&v^{2,2}\end{pmatrix}=\begin{pmatrix}x^{1,1}&x^{1,2}\\
y^{2,1}x^{1,1}&y^{2,2}+y^{2,1}x^{1,2}\end{pmatrix}.

For simplicity, we denote
x^{(i)}:=x^{1,i},

u^{(i)}:=u^{1,i},

y^{(i)}:=y^{2,i}

v^{(i)}:=v^{2,i},

i=1,2

and (

which we will denote for simplicity as

The map

coincides (when all multiplications are taken in opposite order) with the

that was introduced in
[

]

explicitly reads:

(9)

\displaystyle\phi:\left(x^{(1)},x^{(2)};y^{(1)},y^{(2)}\right)\mapsto\left(u^{(1)},u^{(2)};v^{(1)},v^{(2)}\right),

where:

(10)

\displaystyle u^{(1)}=x^{(1)}-x^{(2)}\left(y^{(2)}+y^{(1)}x^{(2)}\right)^{-1}y^{(1)}x^{(1)},

\displaystyle u^{(2)}=x^{(2)}\left(y^{(2)}+y^{(1)}x^{(2)}\right)^{-1},

(11)

\displaystyle v^{(1)}=y^{(1)}x^{(1)},

\displaystyle v^{(2)}=y^{(2)}+y^{(1)}x^{(2)}.

Note that, mapping
\phi,
admits the reduction

y^{(1)}+y^{(2)}=1,
and the reduced map coincides with the pentagon map obtained in
[

]

Proposition 3.1
.

The map

Proof.

By direct computation (see the proof of Proposition

is a pentagon map i.e. it satisfies

where

\phi_{12}=\phi\times id,\quad\phi_{23}=id\times\phi,\quad\phi_{13}=(id\times\tau)\circ\phi_{12}\circ(id\times\tau),

and
\tau
the transposition map i.e.
\tau:(x,y)\mapsto(y,x)

∎

4.
Conclusions

In this article we have proposed a specific class of matrices that their associated re-factorization problems turned equivalent either to pentagon, reverse-pentagon, or Yang-Baxter maps. We thoroughly examined the order
N=2
and
N=3
matrices and explicitly obtained the associated maps.
For higher order matrices of the proposed form, further studies are required.

As an example, let us briefly consider the case where the order of the matrices that participate in re-factorization problems is
N=4.
In this case, the maps

\phi^{\{i_{1},i_{2}\},\{j_{1},j_{2}\}},
where

j_{1}\neq j_{2},
and

9

of (

Note that the maps
\phi^{\{1\},\{2,3\}},

\phi^{\{2,3\},\{4\}},
and
\phi^{\{1\},\{4\}}
satisfy the following entwining Yang-Baxter equation

\displaystyle\phi^{\{1\},\{2,3\}}_{12}\circ\phi^{\{1\},\{4\}}_{13}\circ\phi^{\{2,3\},\{4\}}_{23}=\phi^{\{2,3\},\{4\}}_{23}\circ\phi^{\{1\},\{4\}}_{13}\circ\phi^{\{1\},\{2,3\}}_{12}.
