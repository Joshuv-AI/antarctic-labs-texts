Approximating Subset Sum Ratio faster than Subset Sum
Karl Bringmann

Abstract
Subset Sum Ratio is the following optimization problem: Given a set of n n positive numbers I I , find disjoint subsets X , Y ⊆ I X,Y\subseteq I minimizing the ratio max ⁡ { Σ ⁡ ( X ) / Σ ⁡ ( Y ) , Σ ⁡ ( Y ) / Σ ⁡ ( X ) } \max\{\Sigma(X)/\Sigma(Y),\Sigma(Y)/\Sigma(X)\} , where Σ ⁡ ( Z ) \Sigma(Z) denotes the sum of all elements of Z Z . Subset Sum Ratio is an optimization variant of the Equal Subset Sum problem. It was introduced by Woeginger and Yu in ’92 and is known to admit an FPTAS [Bazgan, Santha, Tuza ’98]. The best approximation schemes before this work had running time O ⁡ ( n 4 / ε ) O(n^{4}/\varepsilon) [Melissinos, Pagourtzis ’18], O ~ ​ ( n 2.3 / ε 2.6 ) \widetilde{O}(n^{2.3}/\varepsilon^{2.6}) and O ~ ​ ( n 2 / ε 3 ) \widetilde{O}(n^{2}/\varepsilon^{3}) [Alonistiotis et al. ’22]. In this work, we present an improved approximation scheme for Subset Sum Ratio running in time O ⁡ ( n / ε 0.9386 ) O(n/\varepsilon^{0.9386}) . Here we assume that the items are given in sorted order, otherwise we need an additional running time of O ⁡ ( n ​ log ⁡ n ) O(n\log n) for sorting. Our improved running time simultaneously improves the dependence on n n to linear and the dependence on 1 / ε 1/\varepsilon to sublinear. For comparison, the related Subset Sum problem admits an approximation scheme running in time O ⁡ ( n / ε ) O(n/\varepsilon) [Gens, Levner ’79]. If one would achieve an approximation scheme with running time O ~ ​ ( n / ε 0.99 ) \widetilde{O}(n/\varepsilon^{0.99}) for Subset Sum, then one would falsify the Strong Exponential Time Hypothesis [Abboud, Bringmann, Hermelin, Shabtay ’19] as well as the Min-Plus-Convolution Hypothesis [Bringmann, Nakos ’21]. We thus establish that Subset Sum Ratio admits faster approximation schemes than Subset Sum. This comes as a surprise, since at any point in time before this work the best known approximation scheme for Subset Sum Ratio had a worse running time than the best known approximation scheme for Subset Sum.

Techniques

We contribute several novel ideas for solving Subset Sum Ratio. First, in Section
3
we develop a linear-time reduction that replaces one instance of size
n
by
n
instances of size
\polylog(1/\varepsilon)
. Solving these
n
instances independently naturally leads to a running time that depends linearly on
n
. For example, if we solve each of these
n
instances of size
\polylog(1/\varepsilon)
by the known
O(n^{4}/\varepsilon)
-time algorithm
[
18
]
then we obtain an algorithm running in total time
O(n/\varepsilon\polylog(1/\varepsilon))
, which already significantly improves the state of the art.
We expect future work on Subset Sum Ratio to make frequent use this reduction.

After this reduction, in Section
4
the remaining goal is to solve Subset Sum Ratio in time

. The specific polynomial dependence on

no longer matters at this point. We combine a delicate pigeonhole argument with ideas from rounding, sumsets, and computational geometry in an intricate way to achieve our goal. Along the way, we solve instances with optimal value more than
\sqrt{2}
to optimality. See Section
4.1
for a more detailed overview of this part.

Open Problems

Our running time of
O(n/\varepsilon^{0.9386})
is unlikely to be optimal. We leave the following open problems: (1) Is a running time of the form
\widetilde{O}(n+1/\poly(\varepsilon))
possible? (2) Can one show a (conditional) lower bound ruling out time

for some constant

such that Subset Sum Ratio is in time
O(n/\varepsilon^{c})
.

2
Preliminaries

For a set
X
we write
\Sigma(X):=\sum_{x\in X}x
. For two sets
X,Y
their ratio is defined as

R(X,Y):=\max\{\Sigma(X)/\Sigma(Y),\Sigma(Y)/\Sigma(X)\}.

The optimal ratio of a set
I\subset\mathbb{R}_{>0}
is

\textup{OPT}(I):=\min\{R(X,Y)\mid\textup{disjoint }X,Y\subseteq I\}.

Throughout the paper we use the convention
x/0=\infty
for any
x\in\mathbb{R}
with
x\geq 0
. This ensures that the optimum ratio is attained by non-empty
X,Y
(unless
|I|\leq 1
).
With this notation, we can define the Subset Sum Ratio problem.

Definition 2

(Subset Sum Ratio Problem (
SSR
))
.

Given a set
I\subset\mathbb{R}_{>0}
of size
n\geq 2
and a number
\varepsilon\in(0,1)
, compute disjoint subsets
X,Y\subseteq I
with
R(X,Y)\leq(1+\varepsilon)\textup{OPT}(I)
.

Let
I
be an instance of
SSR
of size
n
. We write
I[1],\ldots,I[n]
for its items, and we assume that these items are sorted as
I[1]\leq\ldots\leq I[n]
. We use the notation
I[i\,..\,j]:=\{I[i],I[i+1],\ldots,I[j]\}
for any integers
1\leq i\leq j\leq n
. We sometimes also use this notation for
i<1
or
j>n
, with the meaning
I[i\,..\,j]:=I[\max\{1,i\}\,..\,\min\{n,j\}]
.

For sets
X,Y
and real
\alpha
we write
\alpha\cdot X:=\{\alpha x\mid x\in X\}
,
X/\alpha:=\alpha^{-1}\cdot X
,
X+Y:=\{x+y\mid x\in X,y\in Y\}
, and
X-Y:=X+((-1)\cdot Y)
.

All logarithms in this paper are base 2, unless stated otherwise.

Since our algorithms use rounding, as intermediate objects we sometimes obtain multisets rather than sets. We therefore extend the above notation in the natural way to multisets. In particular, we say that
X,Y\subseteq I
are disjoint if
X,Y
are multisets such that for every
z\in\mathbb{R}_{>0}
the sum of the multiplicities of
z
in
X
and in
Y
is at most the multiplicity of
z
in
I
. It follows that whenever
I
contains any number at least twice, then
\textup{OPT}(I)=1
, by letting
X
and
Y
consist of this number. For this reason, multisets are a trivial boundary case (which nevertheless needs to be treated in our algorithms).

We sometimes use
\widetilde{O}
notation to hide polylogarithmic factors, that is,
\widetilde{O}(T)=\bigcup_{c\geq 0}O(T\log^{c}T)
. In Section
4
we will use
O^{*}
notation to hide
\poly(n)
factors.

Machine Model

We assume a model of computation where standard arithmetic operations on input numbers, including rounding, can be performed in constant time. An example is the Real RAM model with floor function, as is used in many papers.

Alternatively, our algorithms also work in a machine model with floating point arithmetic. Observe that, since we are only interested in a
(1+\varepsilon)
-approximation for Subset Sum Ratio, we can safely change every input number by a factor
1+\varepsilon
, in particular we can round every input number to a number of the form
(1+\varepsilon i)2^{j}
, for integers
0\leq i\leq 1/\varepsilon
and
j\in\mathbb{Z}
. In other words, without loss of generality we can assume that our input numbers come in floating point format with a
\log(1/\varepsilon)
-bit mantissa. We assume that the exponent also is an
O(\log(n/\varepsilon))
-bit integer, and we assume that the usual arithmetic operations on floating point numbers with
O(\log(n/\varepsilon))
-bit mantissa and exponent take constant time. This is a realistic model of computation. Our algorithm can be analyzed in this model and has the same running time guarantee as on the Real RAM. We omit the error analysis that would be necessary to show that floating point approximation is sufficient inside our algorithm; instead we formally analyze our algorithm in the Real RAM model.

For comparison, the standard model of fine-grained complexity is the Word RAM, where each cell stores a
w
-bit integer for
w=O(\log n)
, and the usual arithmetic and logical operations on two cells take constant time. However, Subset Sum Ratio makes not much sense in this model, as it can be solved exactly in polynomial time. Indeed, the pigeonhole principle (see Observation
7
below) implies that any instance on more than
w
many
w
-bit integers has optimal ratio
1
. Thus, we can ignore all but
w
of the given
n
input numbers, and find a ratio-1 solution among these
w
numbers by brute force in time
O(3^{w})=\poly(n)
. This issue is avoided by the floating point model since
O(\log(n/\varepsilon))
-bit exponent and mantissa allow to store integers in the range
[1,2^{\poly(n/\varepsilon)}]
, approximated up to a factor
1+\poly(\varepsilon/n)
. The issue is avoided by the Real RAM model, since cells can store arbitrary integers. As discussed above, for simplicity we work in the Real RAM model in this paper.

3
A Reduction to Few Items

In this section we present a reduction that replaces an
SSR
instance of size
n
by
n
instances of size
\polylog(1/\varepsilon)
. Combining this with known approximation schemes immediately yields a simple
\widetilde{O}(n/\varepsilon)
-time algorithm for
SSR
.

3.1
Setting up the Relaxed Subproblem
\textup{SSR}_{\textup{L}}

Consider an
SSR
instance
I
of size
n
.
Suppose we guess the largest element appearing in an optimal solution
(X,Y)
. That is, we iterate over all choices of
\ell\in\{1,\ldots,n\}
and for each choice we want to determine disjoint subsets
X,Y\subseteq I[1\,..\,\ell]
such that
X
or
Y
contains
I[\ell]
and
R(X,Y)
is minimized. We introduce the following notation for this purpose:

\textup{OPT}_{\textup{L}}(I):=\min\{R(X,Y)\mid\textup{disjoint }X,Y\subseteq I,\,\max(I)\in X\cup Y\}.

By guessing the largest item
I[\ell]
in an optimal solution and then restricting to sets containing
I[\ell]
, we observe that

\displaystyle\textup{OPT}(I)=\min_{1\leq\ell\leq|I|}\textup{OPT}_{\textup{L}}(I[1\,..\,\ell]).

(1)

This naturally leads to the following subproblem.

Definition 3

(Subset Sum Ratio containing Largest element (
\textup{SSR}_{\textup{L}}
))
.

Given a set
I\subset\mathbb{R}_{>0}
of size
n\geq 2
and a number
\varepsilon\in(0,1)
, compute disjoint subsets
X,Y\subseteq I
with
R(X,Y)\leq(1+\varepsilon)\textup{OPT}_{\textup{L}}(I)
.

Comparing with the definition of
SSR
(Definition
2
), the only difference is that we compare to
\textup{OPT}_{\textup{L}}(I)
instead of
\textup{OPT}(I)
. A subtle and important detail of
\textup{SSR}_{\textup{L}}
is that we compare with the optimal solution containing the largest item (namely
\textup{OPT}_{\textup{L}}(I)
), but we do not enforce the computed solution
(X,Y)
to contain the largest item. We will make use of this detail in Section
4
, where we design several algorithms for
\textup{SSR}_{\textup{L}}
, only some of which ensure picking the largest item.

3.2
Reduction to
\textup{SSR}_{\textup{L}}

By equation (
1
), in order to solve
SSR
on instance
I
it suffices to solve
\textup{SSR}_{\textup{L}}
on the
n
instances
I[1\,..\,\ell]
for all
1\leq\ell\leq n
. This property was used in previous algorithms, see e.g.
[
21
,
18
]
. Note that this property alone is insufficient for our results, since already writing down all instances
I[1\,..\,\ell]
would take total time
\Omega(n^{2})
, while we will achieve a running time that has linear dependence on
n
.

Our main new structural insight is that it suffices to consider the largest
\polylog 1/\varepsilon
items in
I[1\,..\,\ell]
. That is, instead of solving the
\textup{SSR}_{\textup{L}}
instances
I[1\,..\,\ell]
we solve the
\textup{SSR}_{\textup{L}}
instances
I[\ell-\polylog 1/\varepsilon\,..\,\ell]
for each
1\leq\ell\leq n
. More precisely, we prove the following analogue of equation (
1
).

Lemma 4
.

For any
I\subset\mathbb{R}_{>0}
and any
\varepsilon\in(0,1)
we have

\displaystyle\textup{OPT}(I)\leq\min_{1\leq\ell\leq n}\textup{OPT}_{\textup{L}}(I[\ell-\polylog 1/\varepsilon\,..\,\ell])\leq(1+\varepsilon)\textup{OPT}(I).

(2)

To describe the
\polylog 1/\varepsilon
-term more precisely, we define for any
x\geq 1
the number
\LL(x)
to be the smallest integer with
2^{\LL(x)}>\LL(x)\cdot x+1
. One can show that
\log x\leq\LL(x)\leq\log x+O(\log\log x)
. With this notation, the
\polylog 1/\varepsilon
-term in the lemma can be set to
\LL^{2}(4/\varepsilon):=(\LL(4/\varepsilon))^{2}=O(\log^{2}(1/\varepsilon))
.

We will prove Lemma
4
in Section
3.3
below.
Let us first see that equation (
2
) yields a reduction from
SSR
to
\textup{SSR}_{\textup{L}}
.

Theorem 5

(Reduction)
.

If
\textup{SSR}_{\textup{L}}
can be solved in time
T_{\textup{L}}(n,\varepsilon)
, then
SSR
can be solved in time

O(n\cdot T_{\textup{L}}(\polylog 1/\varepsilon,\,\varepsilon/3)).

Proof.

Write
I_{\ell}:=I[\ell-\polylog 1/\varepsilon\,..\,\ell]
. By running an
\textup{SSR}_{\textup{L}}
algorithm on each instance
I_{\ell}
we obtain disjoint subsets
X_{\ell},Y_{\ell}\subseteq I_{\ell}
with ratios
R(X_{\ell},Y_{\ell})\leq(1+\varepsilon)\cdot\textup{OPT}_{\textup{L}}(I_{\ell})
. The best solution
(X,Y)
among
(X_{1},Y_{1}),\ldots,(X_{n},Y_{n})
thus has a ratio of

R(X,Y)=\min_{1\leq\ell\leq n}R(X_{\ell},Y_{\ell})\leq\min_{1\leq\ell\leq n}(1+\varepsilon)\cdot\textup{OPT}_{\textup{L}}(I_{\ell})\stackrel{{\scriptstyle(\ref{eq:reduction})}}{{\leq}}(1+\varepsilon)^{2}\textup{OPT}(I).

Since for
\varepsilon\in(0,1)
we have
(1+\varepsilon)^{2}\leq 1+3\varepsilon
, by replacing
\varepsilon
by
\varepsilon/3
we obtain a solution to the
SSR
instance
I
. The total running time is
O(n\cdot T_{\textup{L}}(\polylog 1/\varepsilon,\,\varepsilon/3))
.
∎

Note that the above reduction naturally leads to algorithms for
SSR
whose running time depends linearly on
n
, since the factor
T_{\textup{L}}(\polylog 1/\varepsilon,\,\varepsilon/3)
is independent of
n
.
Observe that any algorithm for
SSR
also solves
\textup{SSR}_{\textup{L}}
(cf. Definitions
2
and
3
). Thus, we can e.g. plug the known
\widetilde{O}(n^{4}/\varepsilon)
-time algorithm for
SSR

[
18
]
into the above reduction. This yields an algorithm for
SSR
with running time
O(\frac{n}{\varepsilon}\polylog\frac{1}{\varepsilon})
. We remark that this already significantly improves the state of the art running time for
SSR
.

In Section
4
, we will design an improved
\textup{SSR}_{\textup{L}}
algorithm with running time
O(\poly(n)/\varepsilon^{0.93856})
. Plugging this into the above reduction yields time
O(n/\varepsilon^{0.9386})
(where we hide
\polylog(1/\varepsilon)
factors by rounding the exponent of
1/\varepsilon
). This proves our main result Theorem
1
.

For now it remains to prove Lemma
4
.

3.3
Proof of Lemma
4

Let us start by discussing the the main difficulty in proving Lemma
4
:
The step from equation (
1
) to (
2
) is non-trivial, because it can happen that for some values
\ell
we have

\textup{OPT}_{\textup{L}}(I[\ell-\polylog 1/\varepsilon\,..\,\ell])\gg\textup{OPT}_{\textup{L}}(I[1\,..\,\ell]).

We illustrate this situation in the following example.

Example 6
.

Consider
I=\{1,2,\ldots,n-2,n-1,{n\choose 2}\}
and
\ell=n
, so that
I[1\,..\,\ell]=I
. Then:

•

\textup{OPT}_{\textup{L}}(I[1\,..\,\ell])=1
.

To see this, set
X=\{1,2,\ldots,n-2,n-1\}
and
Y=\{{n\choose 2}\}
and note that
X,Y
are disjoint subsets of
I[1\,..\,\ell]
and
Y
contains
I[\ell]
, so
(X,Y)
is a feasible solution for
\textup{OPT}_{\textup{L}}(I[1\,..\,\ell])
. Since
\Sigma(X)=\sum_{i=1}^{n-1}i={n\choose 2}=\Sigma(Y)
we have
R(X,Y)=1
and thus
\textup{OPT}_{\textup{L}}(I[1\,..\,\ell])=1
.

•

\textup{OPT}_{\textup{L}}(I[\ell-\polylog 1/\varepsilon\,..\,\ell])\gg 1
assuming
n\gg\polylog 1/\varepsilon
.

Indeed, note that
\polylog 1/\varepsilon
many items below
n
sum to at most
n\cdot\polylog 1/\varepsilon\ll{n\choose 2}
. Thus, for any disjoint subsets
X,Y
with
\max(X\cup Y)=I[\ell]
one of the sets sums to at least
{n\choose 2}
and the other set sums to at most
n\cdot\polylog 1/\varepsilon\ll{n\choose 2}
. It follows that their ratio is
\gg 1
.

So indeed this is an example where for some value
\ell
we have
\textup{OPT}_{\textup{L}}(I[\ell-\polylog 1/\varepsilon\,..\,\ell])\gg\textup{OPT}_{\textup{L}}(I[1\,..\,\ell])
.

Nevertheless, equation (
2
) still holds in this example (and in general, as we prove below). To see this, we shift our attention to
\ell^{\prime}=n-1
, and observe that:

•

\textup{OPT}_{\textup{L}}(I[\ell^{\prime}-3\,..\,\ell^{\prime}])=1
.

Indeed,
X=\{n-1,n-4\}
and
Y=\{n-2,n-3\}
are disjoint subsets of
I[\ell^{\prime}-3\,..\,\ell^{\prime}]
and both sum to
2n-5
. Since
X
contains
I[\ell^{\prime}]
,
(X,Y)
is a feasible solution for
\textup{OPT}_{\textup{L}}(I[\ell^{\prime}-3\,..\,\ell^{\prime}])
, we obtain

4
Solving
\textup{SSR}_{\textup{L}}
with Sublinear Dependence on
1/\varepsilon

For the whole section we are given an
\textup{SSR}_{\textup{L}}
instance
I\subset\mathbb{R}_{>0}
of size
n
and a number
\varepsilon\in(0,1)
. In light of Lemma
4
reducing the number of items to
\polylog 1/\varepsilon
, we do not care about the running time dependence on
n
; any polynomial dependence is fine. However, our goal is to decrease the running time dependence on
1/\varepsilon
to sublinear, more precisely to
1/\varepsilon^{0.93856}
. In other words, in this section we want to design an
\textup{SSR}_{\textup{L}}
algorithm running in time
O^{*}(1/\varepsilon^{0.93856})
, where the
O^{*}
notation hides polynomial factors in
n
.

4.1
Algorithm Overview

Our algorithm is an intricate combination of a pigeonhole argument with ideas from rounding, sumsets, and computational geometry.

A Failed Approach

Let us first discuss a simple approach and why it fails.
We want to use two ideas. Idea (1): It is safe to round all items to multiples of
\max(I)\cdot\varepsilon/n
. Indeed, we want to solve an
\textup{SSR}_{\textup{L}}
instance and thus are only interested in subsets containing the largest item
\max(I)
, and rounding to multiples of
\max(I)\cdot\varepsilon/n
changes the ratio
R(X,Y)
of sets
X,Y
with
\max(I)\in X\cup Y
by at most a factor
1+\varepsilon
.
Idea (2): The pigeonhole principle guarantees the existence of two equal subset sums if we have more than a logarithmic number of items. In particular, it turns out that if after rounding we have more than
\log(\Theta(n^{2}/\varepsilon))
items, then two disjoint subsets have equal rounded sum.
Thus, we are done unless
n\leq\log(\Theta(n^{2}/\varepsilon))
, which solves to
n\leq\log 1/\varepsilon+\Theta(\log\log 1/\varepsilon)
.
But then
n
is small enough to run an exact algorithm in time
O(1.7088^{n})=O(1/\varepsilon^{0.773})
, which is sublinear in
1/\varepsilon
as desired.

The issue is that ideas (1) and (2) do not work together nicely. Indeed, the equal subset sums that are guaranteed by the pigeonhole principle not necessarily contain
\max(I)
, and thus can have much smaller sum than
\max(I)
. But if they have much smaller sum, then the rounding with respect to multiples of
\max(I)\cdot\varepsilon/n
was too coarse to say anything about their true sums even if their rounded sums are equal.
3
3

3

It is easy to construct instances where this situation appears. Consider for example
\varepsilon=1/100
and
I=\{100^{0},100^{1},\ldots,100^{8},100^{9},100^{100}\}
, where after rounding to multiples of
\max(I)\cdot\varepsilon/n
all items (except
\max(I)
) are rounded to the same value, and the pigeonhole principle yields a trivial solution on the rounded instance, but the unrounded instance has no solution with ratio
<50
.

Therefore, this simple approach fails. Our actual approach is significantly more complicated and subtle, and it makes the combination of ideas (1) and (2) work despite the issues with the simple approach, using a variety of additional tricks. It can be instructive to consider Lemma
11
, which guarantees that some “large” item (i.e., some item in
T
) is selected by the pigeonhole solution, and thus can be seen as a remedy for the issue that the pigeonhole principle does not guarantee to select the maximum item.

Our Actual Approach

We start by splitting
I
into its largest
\tau
items
T
(top) and the remaining items
B=I\setminus T
(bottom).
In one part of our algorithm, we would like to perform meet in the middle on
T
and
B
. Meet in the middle is standard for the Equal Subset Sum problem: Compute the sets
P^{\prime}:=\{\Sigma(X)-\Sigma(Y)\mid\text{disjoint }X,Y\subseteq T\}
and
Q^{\prime}:=\{\Sigma(X)-\Sigma(Y)\mid\text{disjoint }X,Y\subseteq B\}
in sorted order. Then for each
p\in P^{\prime}
perform binary search over
Q^{\prime}
to check whether
p\in Q^{\prime}
. If we find a match, then we obtain sets
X_{T},Y_{T}\subseteq T
and
X_{B},Y_{B}\subseteq B
with
\Sigma(X_{T})-\Sigma(Y_{T})=\Sigma(Y_{B})-\Sigma(X_{B})
. The sets
X=X_{T}\cup X_{B}
and
Y=Y_{T}\cup Y_{B}
thus form an Equal Subset Sum solution.
However, for Subset Sum Ratio there is an additional difficulty: Sets with closer sums
\Sigma(X_{T})-\Sigma(Y_{T})
and
\Sigma(Y_{B})-\Sigma(X_{B})
could have smaller sums
\Sigma(X_{T})+\Sigma(X_{B})
and
\Sigma(Y_{T})+\Sigma(Y_{B})
, and thus could have a worse ratio. Therefore, the goal is not simply to find two numbers in
P^{\prime}
and
Q^{\prime}
that are as close as possible, as in general there can be a tradeoff between closeness and magnitude.
It turns out that to generalize meet in the middle we have to consider the point sets
P:=\{(\Sigma(X)-\Sigma(Y),\Sigma(X)+\Sigma(Y))\mid\text{disjoint }X,Y\subseteq T\}
and
Q:=\{(\Sigma(X)-\Sigma(Y),\Sigma(X)+\Sigma(Y))\mid\text{disjoint }X,Y\subseteq B\}
. (Moreover, if two points in
P
have the same
x
-coordinate then we can remove the lower of the two points from
P
, similarly for
Q
.) The goal then turns out to be maximizing
\frac{p_{y}+q_{y}}{|p_{x}+q_{x}|}
over all points
(p,q)\in P\times Q
. By further rearrangements, we reduce this to a computational geometry problem on slopes and convex hulls that can be solved in near-linear time.

The resulting algorithm solves
\textup{SSR}_{\textup{L}}
in time
O^{*}(|P|+|Q|)
. For
P
we use the simple bound
|P|\leq 3^{\tau}
, since each of the
\tau
elements of
T
can be in
X
or in
Y
or in neither of them.
To be able to bound
|Q|
, we need to combine this algorithm with rounding. It turns out that we can afford to round items to multiples of
\frac{\varepsilon}{n}\max(T)
while still computing a
(1+\varepsilon)
-approximation.
Since all coordinates of points in
Q
are bounded by
O(n\cdot\max(B))\leq O(n\cdot\min(T))
, after this rounding we obtain a bound of
|Q|=O^{*}(1/\varepsilon\cdot\min(T)/\max(T))
, which is sublinear in
1/\varepsilon
whenever
\min(T)\ll\max(T)
. This provides one situation in which we have a sufficiently good bound on
|Q|
.
Another such situation happens if (after rounding)
B
creates few different subset sums. We can bound
|Q|
by the square of the number of subset sums of
B
, and thus we obtain a fast algorithm if the number of different subset sums is small.

The remaining case is that
\min(T)
is not much smaller than
\max(T)
and (the rounded)
B
generates many different subset sums. In this case, we make use of a refined pigeonhole argument: We show that if the product of the number of subset sums of (the rounded)
B
and the number of subset sums of (the rounded)
T
is large enough, then they are guaranteed to have a (rounded) solution
{\widetilde{X}},{\widetilde{Y}}
with ratio
R({\widetilde{X}},{\widetilde{Y}})=1
containing at least one item of
T
. Before rounding, these sets
{\widetilde{X}},{\widetilde{Y}}
then correspond to sets
X,Y
with
R(X,Y)\leq 1+\varepsilon
.
We show that this pigeonhole argument is always applicable in the remaining case that we need to consider.
Since ratio
R({\widetilde{X}},{\widetilde{Y}})=1
means
\Sigma({\widetilde{X}})=\Sigma({\widetilde{Y}})
, in this part of the algorithm we can use standard meet in the middle to actually find such sets
{\widetilde{X}},{\widetilde{Y}}
.

A major technical difficulty is that the pigeonhole argument does not guarantee a solution containing
\max(I)
— it only guarantees picking some item in
T
. This in particular means that in the pigeonhole-based algorithm we can only afford to round to multiples of
\frac{\varepsilon}{n}\min(T)
(instead of
\frac{\varepsilon}{n}\max(T)
as in the geometric algorithm). That the two parts of the algorithm use different roundings causes significant difficulties.

Finally, our analysis of the above algorithms only works when the optimal value is at most a constant. We handle the case of large optimal value by presenting an algorithm for
\textup{SSR}_{\textup{L}}
that computes a solution of ratio at most
\max\{\sqrt{2},\textup{OPT}_{\textup{L}}(I)\}
. This yields a simple
\sqrt{2}
-approximation algorithm, but more importantly it solves instances with optimal value at least
\sqrt{2}
to optimality.

\displaystyle{\cal S}(Z_{i})={\cal S}(Z_{i-1})\cup\{s+z_{i}\mid s\in{\cal S}(Z_{i-1})\}.

(6)

If we know

Definition 9

\displaystyle P(I)

Lemma 10

.

as

P(I)={\cal U}\big(P^{\prime}\cup\{(p_{x}+I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\cup\{(p_{x}-I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\big).

If all three sets on the right hand side are sorted by
x
-coordinate, we can generate
P(I)
in sorted order by merging three sorted sets and removing dominated points. Thus, the running time for this step is
O(|P^{\prime}|)
, and the total running time to compute
P(I)
is
O\left(\sum_{i=1}^{n-1}|P(I[1\,..\,i])|\right)\leq O(n\cdot|P(I)|)
.

We similarly generate the set
P_{L}(I)
from
P^{\prime}=P(I[1\,..\,n-1])
as

P_{L}(I)={\cal U}\big(\{(p_{x}+I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\cup\{(p_{x}-I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\big).

We similarly generate the set
P_{N}(I)
from
P^{\prime}=P(I[1\,..\,n-1])
as
P_{N}(\emptyset)=\emptyset
and for
n\geq 1
:

P_{N}(I)={\cal U}\big(P_{N}(I[1\,..\,n-1])\cup\{(p_{x}+I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\cup\{(p_{x}-I[n],p_{y}+I[n])\mid p\in P^{\prime}\}\big).

Clearly the same running time bounds apply to
P_{L}(I)
and
P_{N}(I)
.
∎

4.3
A Refined Pigeonhole Principle and its Application to
\textup{SSR}_{\textup{L}}

Our improved algorithm starts with the following refinement of the pigeonhole principle (which should be compared with the basic Observation
7
).

Lemma 11

(Refined Pigeonhole)
.

Let
I\subseteq\mathbb{N}
be partitioned into
I=B\cup T
. If
|{\cal S}(B)|\cdot|{\cal S}(T)|>\Sigma(B)+\Sigma(T)+1
, then there exist disjoint sets
X,Y\subseteq I
with
\Sigma(X)=\Sigma(Y)
and
(X\cup Y)\cap T\neq\emptyset
.

Proof.

Consider all pairs
(x_{B},x_{T})\in{\cal S}(B)\times{\cal S}(T)
. Note that for each such pair we have
x_{B}+x_{T}\in\{0,\ldots,\Sigma(B)+\Sigma(T)\}
. By the assumption
|{\cal S}(B)|\cdot|{\cal S}(T)|>\Sigma(B)+\Sigma(T)+1
and the pigeonhole principle, there exist two different pairs
(x_{B},x_{T}),(y_{B},y_{T})\in{\cal S}(B)\times{\cal S}(T)
with equal sum
x_{B}+x_{T}=y_{B}+y_{T}
. These pairs correspond to sets
X_{B},Y_{B}\subseteq B,X_{T},Y_{B}\subseteq T
with
\Sigma(X_{B})=x_{B}
,
\Sigma(X_{T})=x_{T}
,
\Sigma(Y_{B})=y_{B}
,
\Sigma(Y_{T})=y_{T}
.
We let
X^{\prime}:=X_{B}\cup X_{T}
and
Y^{\prime}:=Y_{B}\cup Y_{T}
.
Removing their intersection, we obtain disjoint sets
X:=X^{\prime}\setminus(X^{\prime}\cap Y^{\prime})
and
Y:=Y^{\prime}\setminus(X^{\prime}\cap Y^{\prime})
. These disjoint sets have equal sum, since

\displaystyle\Sigma(X)=\Sigma(X^{\prime})-\Sigma(X^{\prime}\cap Y^{\prime})

\displaystyle=x_{B}+x_{T}-\Sigma(X^{\prime}\cap Y^{\prime})

\displaystyle=y_{B}+y_{T}-\Sigma(X^{\prime}\cap Y^{\prime})=\Sigma(Y^{\prime})-\Sigma(X^{\prime}\cap Y^{\prime})=\Sigma(Y).

Finally, we argue that
(X\cup Y)\cap T\neq\emptyset
. Since
x_{B}+x_{T}=y_{B}+y_{T}
and the pairs
(x_{B},x_{T}),(y_{B},y_{T})
are different, it follows that
x_{T}\neq y_{T}
. We thus have

\Sigma(X\cap T)=x_{T}-\Sigma(X^{\prime}\cap Y^{\prime}\cap T)\neq y_{T}-\Sigma(X^{\prime}\cap Y^{\prime}\cap T)=\Sigma(Y\cap T).

It follows that at least one of
X\cap T
or
Y\cap T
must be nonempty, and thus
(X\cup Y)\cap T\neq\emptyset
.
∎

We now use the refined pigeonhole principle to solve a very specific special case of the
\textup{SSR}_{\textup{L}}
problem.

Lemma 12
.

Let
I\subset\mathbb{R}_{>0}
be a (multi-)set of size
n
consisting of numbers that are integer multiples of
\beta\in\mathbb{R}_{>0}
, and let
\tau\in\mathbb{N}
. Let
T
be the largest
\tau
items of
I
, let
B:=I\setminus T
be the remaining items.
If
|{\cal S}(B)|>n\max(I)/(\beta 2^{\tau})+1
then there exist disjoint
X,Y\subseteq I
with
R(X,Y)=1
and
(X\cup Y)\cap T\neq\emptyset
, and we can compute such
X,Y
in time
O^{*}(\max(I)^{2}/(\beta^{2}4^{\tau})+3^{\tau})
.

Proof.

Note that scaling all numbers by
\beta
reduces to the case
\beta=1
, so it suffices to prove the lemma in the case
\beta=1
, which is equivalent to
I\subset\mathbb{N}
.

The algorithms works as follows:

1.

Enumerate all pairs
(X,Y)
of disjoint subsets of
T
. This can be done naively in time
O^{*}(3^{\tau})
, as each element of
T
can go into
X
or into
Y
or into neither. If we find non-empty disjoint subsets
X,Y\subseteq T
with
\Sigma(X)=\Sigma(Y)
, then we have
R(X,Y)=1
and thus we are done.

Hence, from now on we can assume that no non-empty disjoint subsets
X,Y\subseteq T
satisfy
\Sigma(X)=\Sigma(Y)
.
This implies that there are no two different subsets
X^{\prime},Y^{\prime}\subseteq T
with equal sum
\Sigma(X^{\prime})=\Sigma(Y^{\prime})
. Indeed, for any such sets
X^{\prime},Y^{\prime}
we could remove their intersection, obtaining disjoint sets
X:=X^{\prime}\setminus(X^{\prime}\cap Y^{\prime})
and
Y:=Y^{\prime}\setminus(X^{\prime}\cap Y^{\prime})
with the same sum
\Sigma(X)=\Sigma(X^{\prime})-\Sigma(X^{\prime}\cap Y^{\prime})=\Sigma(Y^{\prime})-\Sigma(X^{\prime}\cap Y^{\prime})=\Sigma(Y)
. Hence, from now on no two subset sums of
T
are equal, that is, we have
|{\cal S}(T)|=2^{\tau}
.

2.

Write
B=\{b_{1},\ldots,b_{m}\}
and
B_{j}:=\{b_{1},\ldots,b_{j}\}
. For
j=1,2,\ldots
compute the set
{\cal S}(B_{j})
by Lemma
8
, and stop at the first
j
with
|{\cal S}(B_{j})|>n\max(I)/2^{\tau}+1
. Note that by the assumption in the lemma statement, we indeed stop for some
j\leq m
. Since
|{\cal S}(B_{j})|\leq 2|{\cal S}(B_{j-1})|
(which follows from equation (
6
)), we also have
|{\cal S}(B_{j})|=O(n\max(I)/2^{\tau}+1)
.

3.

Compute
P:=\{\Sigma(X)-\Sigma(Y)\mid\text{disjoint }X,Y\subseteq B_{j}\}
and
Q:=\{\Sigma(X)-\Sigma(Y)\mid\text{disjoint }X,Y\subseteq T,X\cup Y\neq\emptyset\}
. These sets can be computed in time
O^{*}(|P|)
and
O^{*}(|Q|)
, by applying Lemma
10
to compute
P(B_{j})
and
P_{N}(T)
and then removing the
y
-coordinates of the computed points.

4.

From
|{\cal S}(B_{j})|>n\max(I)/2^{\tau}+1
and
|{\cal S}(T)|=2^{\tau}
we obtain
|{\cal S}(B_{j})|\cdot|{\cal S}(T)|>n\max(I)+1\geq\Sigma(B_{j})+\Sigma(T)+1
. That is, the Refined Pigeonhole Lemma
11
is applicable, and it shows existence of disjoint sets
X,Y\subseteq B_{j}\cup T
with
\Sigma(X)=\Sigma(Y)
and
(X\cup Y)\cap T\neq\emptyset
. Consider
p:=\Sigma(X\cap B_{j})-\Sigma(Y\cap B_{j})\in P
and
q:=\Sigma(Y\cap T)-\Sigma(X\cap T)\in Q
. Then
p-q=\Sigma(X)-\Sigma(Y)=0
, so it follows that
P\cap Q\neq\emptyset
.

We use meet in the middle to find some
x\in P\cap Q
. In other words, we iterate over all
p\in P
and for each
p
we perform binary search over
Q
to test whether
p\in Q
.
After finding
x\in P\cap Q
, by appropriate bookkeeping during the construction of
P
and
Q
we can reconstruct disjoint sets
X_{B},Y_{B}\subseteq B_{j}
with
x=\Sigma(X_{B})-\Sigma(Y_{B})
, as well as disjoint sets
X_{T},Y_{T}\subseteq T
with
x=\Sigma(Y_{T})-\Sigma(X_{T})
and
X_{T}\cup Y_{T}\neq\emptyset
. Setting
X:=X_{B}\cup X_{T}
and
Y:=Y_{B}\cup Y_{T}
now yields disjoint sets
X,Y\subseteq I
with
R(X,Y)=1
and
(X\cup Y)\cap T\neq\emptyset
. This finishes the algorithm.

We argued correctness in the algorithm description. Regarding running time, note that step 1 runs in time
O^{*}(3^{\tau})
, step 2 runs in time
O^{*}(|{\cal S}(B_{j})|)=O^{*}(\max(I)/2^{\tau}+1)
, and steps 3 and 4 run in time
O^{*}(|P|+|Q|)
. We can easily bound
|Q|\leq 3^{\tau}
. For
|P|
we observe that we can write each element of
P
as a difference of two elements of
{\cal S}(B_{j})
, and thus
|P|\leq|{\cal S}(B_{j})|^{2}=O(n^{2}\max(I)^{2}/4^{\tau}+1)
.
In total, we thus obtain running time
O^{*}(\max(I)^{2}/4^{\tau}+3^{\tau})
.
∎

4.4
Generalized Meet in the Middle via Computational Geometry

We will use some tools from computational geometry, specifically convex hulls and tangent lines of convex hulls. These tools can be used to determine the maximum slope of any line through two points in two given point sets, as shown by the following lemma.

Lemma 13

(
[
17
]
)
.

Given sets
P,Q\subset\mathbb{R}^{2}
of
n
points in the plane, in time
O(n\log n)
we can compute for each point
p\in P
the maximum slope of a line through
p
and a point
q\in Q
to the right of
p
, that is, we compute

s_{p}:=\max\left\{\frac{q_{y}-p_{y}}{q_{x}-p_{x}}\;\bigg|\;\,q\in Q,\,p_{x}<q_{x}\right\}\text{ for each }p\in P.

Proof.

Mehlhorn and Ray
[
17
]
describe a simple
O(n\log n)
-time algorithm for this problem (see their Section 3.1). They also describe a faster
O(n)
-time algorithm assuming that the points are given in sorted order, but this log-factor improvement is irrelevant in our context.
For convenience, in the following we sketch the simple
O(n\log n)
-time algorithm by Mehlhorn and Ray.

We first sort
P\cup Q
by
x
-coordinates.
Then we scan the points
P\cup Q
from right to left, maintaining an array containing the upper convex hull
\cal C
of the seen points in
Q
. There are two types of events to process:

(1) When we reach a point
p\in P
, then we want to find the point
q\in Q
to the right of
p
maximizing the slope of the line through
p
and
q
. This point must lie on
\cal C
, more precisely we are looking for the tangent point on
\cal C
of the tangent line touching
\cal C
and passing through
p
. This tangent point can be found by standard binary search in time
O(\log n)
.

(2) When we reach a point
q\in Q
, then we update
\cal C
by using the standard incremental algorithm for computing the convex hull of points in the plane: We iterate over the points in
\cal C
starting from the leftmost, to enumerate all points that are removed from the upper hull after inserting
q
. Then we add
q
to
\cal C
.

Note that every point is added exactly once to the convex hull, and thus every point is removed at most once from the convex hull. It follows that the total running time of the updates in (2) is
O(n)
.
In total, the running time is
O(n\log n)
.∎

Lemma 14
.

Given sets
P,Q\subset\mathbb{R}^{2}
of
n
points in the plane, in time
O(n\log n)
we can compute the maximum of
(q_{y}-p_{y})/|q_{x}-p_{x}|
over all
(p,q)\in P\times Q
.

Proof.

We sort the points by
x
-coordinate to determine whether any
p\in P,q\in Q
have equal
x
-coordinate, and thus whether the result is
\infty
.
Thus, assume from now on that there are no such points, and the result is finite. We split the term to be maximized into:

\alpha:=\max\left\{\frac{q_{y}-p_{y}}{q_{x}-p_{x}}\;\bigg|\;p\in P,q\in Q,p_{x}<q_{x}\right\}\quad\text{and}\quad\beta:=\max\left\{\frac{q_{y}-p_{y}}{p_{x}-q_{x}}\;\bigg|\;p\in P,q\in Q,q_{x}<p_{x}\right\}.

In order to compute
\alpha
, we apply Lemma
13
on
P
and
Q
and take the maximum over all computed values
s_{p}
,
p\in P
. To compute
\beta
, we apply Lemma
13
on
P^{\prime}:=\{(-p_{x},p_{y})\mid p\in P\}
and
Q^{\prime}:=\{(-q_{x},q_{y})\mid q\in Q\}
and take the maximum over all computed values
s_{p}
,
p\in P^{\prime}
.
Finally, we return the maximum of
\alpha
and
\beta
.
∎

Lemma 15
.

Given sets
P,Q\subset\mathbb{R}^{2}
of
n
points in the plane satisfying
r_{y}\geq r_{x}
for all
r\in P\cup Q
, in time
O(n\log n)
we can compute the minimum of
(p_{y}+q_{y}+|p_{x}+q_{x}|)/(p_{y}+q_{y}-|p_{x}+q_{x}|)
over all
(p,q)\in P\times Q
.

Proof.

We rearrange

\frac{p_{y}+q_{y}+|p_{x}+q_{x}|}{p_{y}+q_{y}-|p_{x}+q_{x}|}=1+2\frac{|p_{x}+q_{x}|}{p_{y}+q_{y}-|p_{x}+q_{x}|}=1+2\left(\frac{p_{y}+q_{y}}{|p_{x}+q_{x}|}-1\right)^{-1}.

Denote by
\mu
the maximum of
(p_{y}+q_{y})/|p_{x}+q_{x}|
over all
p\in P,q\in Q
. It follows that our goal is to compute
1+2/(\mu-1)
. Note that
\mu
can be computed by applying Lemma
14
to
P^{\prime}:=\{(-p_{x},-p_{y})\mid p\in P\}
and
Q
. ∎

Now we use this geometric tool for the
\textup{SSR}_{\textup{L}}
problem, to obtain a generalization of the meet in the middle approach for Equal Subset Sum. Specifically, we apply the geometric tool to the point sets
P(B)
and
P_{L}(T)
(recall Definition
9
).

Lemma 16
.

Given a multiset
I\subset\mathbb{R}_{>0}
of size
n
that is partitioned into
I=T\cup B
with
\max(I)\in T
, write
S:=|P(B)|+|P_{L}(T)|
. Then in time
O^{*}(S)
we can compute
\textup{OPT}_{\textup{L}}(I)
, as well as an optimal solution realizing
\textup{OPT}_{\textup{L}}(I)
(i.e., disjoint subsets
X,Y\subseteq I
with
\max(I)\in X\cup Y
and
R(X,Y)=\textup{OPT}_{\textup{L}}(I)
).

Proof.

The algorithm works as follows.

1.

Generate the point sets
P(B)
and
P_{L}(T)
using Lemma
10
.

2.

Run Lemma
15
on
P:=P(B)
and
Q:=P_{L}(T)
to compute the value

\mu=\min\left\{\frac{p_{y}+q_{y}+|p_{x}+q_{x}|}{p_{y}+q_{y}-|p_{x}+q_{x}|}\;\bigg|\;p\in P,q\in Q\right\}.

3.

Return the number
\mu
.

To show correctness of this algorithm, we need to show that
\mu=\textup{OPT}_{\textup{L}}(I)
. To this end, consider disjoint
X,Y\subseteq I
with
\max(I)\in X\cup Y
. Consider the corresponding points

\displaystyle p

\displaystyle=\big(\Sigma(X\cap B)-\Sigma(Y\cap B),\,\Sigma(X\cap B)+\Sigma(Y\cap B)\big),

\displaystyle q

\displaystyle=\big(\Sigma(X\cap T)-\Sigma(Y\cap T),\,\Sigma(X\cap T)+\Sigma(Y\cap T)\big).

Observe that
p\in P
and
q\in Q
. Thus, we described a mapping
\Phi
from pairs
(X,Y)
, where
X,Y
are disjoint subsets of
I
with
\max(I)\in X\cup Y
, to pairs
(p,q)\in P\times Q
. Observe that the mapping
\Phi
is surjective.

We rewrite the definition of
R(X,Y)
to obtain

R(X,Y)=\frac{\max\{\Sigma(X),\Sigma(Y)\}}{\min\{\Sigma(X),\Sigma(Y)\}}=\frac{\Sigma(X)+\Sigma(Y)+|\Sigma(X)-\Sigma(Y)|}{\Sigma(X)+\Sigma(Y)-|\Sigma(X)-\Sigma(Y)|}=\frac{p_{y}+q_{y}+|p_{x}+q_{x}|}{p_{y}+q_{y}-|p_{x}+q_{x}|}.

This shows that the surjective mapping
\Phi
maintains the value
R(X,Y)
. It follows that by minimizing
\frac{p_{y}+q_{y}+|p_{x}+q_{x}|}{p_{y}+q_{y}-|p_{x}+q_{x}|}
over all
(p,q)\in P\times Q
we compute the minimum value
R(X,Y)
over all disjoint
X,Y\subseteq I
with
\max(I)\in X\cup Y
. As the latter is the definition of
\textup{OPT}_{\textup{L}}(I)
, we obtain
\mu=\textup{OPT}_{\textup{L}}(I)
. This proves correctness of the algorithm.

Regarding running time, note that step 1 runs in time
O^{*}(S)
and step 2 runs in time
O(S\log S)
. By the simple bounds
|P_{L}(J)|\leq|P(J)|\leq 3^{|J|}
for any set
J
, we observe that
\log S\leq O(\log(3^{n}))=O(n)
and thus step 2 runs in time
O(nS)=O^{*}(S)
as well.

Note that the above algorithm only computes the value
\textup{OPT}_{\textup{L}}(I)
, but not an optimal solution realizing this value. It is easy to augment the geometric tool (Lemma
15
) to not only compute the value
\mu
, but also the points
(p,q)
realizing this value, and to augment the point set generation (Lemma
10
) to label each point by the last added item and a pointer to the previous point, so that the sets generating the points
p
and
q
can be reconstructed in time
O(n)
. We omit the details.
∎

4.5
Preparations on Rounding

Here we give two lemmas that bound the difference of the ratio
R(X,Y)
of two sets
X,Y
and the ratio
R({\widetilde{X}},{\widetilde{Y}})
of sets
{\widetilde{X}},{\widetilde{Y}}
that are the outcome of rounding
X
and
Y
. We later use these lemmas to argue correctness of algorithms that round items.

Lemma 17

(Rounding I)
.

Let
I\subset\mathbb{R}_{>0}
of size
n
and let
\delta>0
. Round up each item in
I
to a multiple of
\delta
and call the resulting (multi-)set
\widetilde{I}
. Consider disjoint
{\widetilde{X}},{\widetilde{Y}}\subseteq{\widetilde{I}}
with
R({\widetilde{X}},{\widetilde{Y}})=1
.
Further assume that
\delta\leq\frac{\varepsilon}{2n}\max({\widetilde{X}}\cup{\widetilde{Y}})
. Let
X,Y\subseteq I
be the sets corresponding to
{\widetilde{X}},{\widetilde{Y}}
before rounding. Then we have
R(X,Y)\leq 1+\varepsilon
.

Proof.

Note that we have
\Sigma(X)\leq\Sigma({\widetilde{X}})\leq\Sigma(X)+\delta n
and
\Sigma(Y)\leq\Sigma({\widetilde{Y}})\leq\Sigma(Y)+\delta n
. This yields

\displaystyle R(X,Y)

\displaystyle=\max\left\{\frac{\Sigma(X)}{\Sigma(Y)},\frac{\Sigma(Y)}{\Sigma(X)}\right\}\leq\max\left\{\frac{\Sigma({\widetilde{X}})}{\Sigma({\widetilde{Y}})-\delta n},\frac{\Sigma({\widetilde{Y}})}{\Sigma({\widetilde{X}})-\delta n}\right\}.

Since
\delta\leq\frac{\varepsilon}{2n}\max({\widetilde{X}}\cup{\widetilde{Y}})
and we have
\max({\widetilde{X}}\cup{\widetilde{Y}})\leq\Sigma({\widetilde{X}})=\Sigma({\widetilde{Y}})
, we obtain

\displaystyle R(X,Y)

\displaystyle\leq\max\left\{\frac{\Sigma({\widetilde{X}})}{(1-\varepsilon/2)\Sigma({\widetilde{Y}})},\frac{\Sigma({\widetilde{Y}})}{(1-\varepsilon/2)\Sigma({\widetilde{X}})}\right\}=\frac{1}{1-\varepsilon/2}\leq 1+\varepsilon,

where we used
1/(1-\varepsilon/2)\leq 1+\varepsilon
for
\varepsilon\in(0,1)
.
∎

Lemma 18

(Rounding II)
.

Let
I\subset\mathbb{R}_{>0}
of size
n
with
\textup{OPT}_{\textup{L}}(I)\leq 2
and let
0<\delta\leq\frac{\varepsilon}{9n}\max(I)
. Round up each item in
I
to a multiple of
\delta
and call the resulting set
\widetilde{I}
. Consider disjoint
{\widetilde{X}},{\widetilde{Y}}\subseteq{\widetilde{I}}
with
\max({\widetilde{I}})\in{\widetilde{X}}\cup{\widetilde{Y}}
and
R({\widetilde{X}},{\widetilde{Y}})=\textup{OPT}_{\textup{L}}({\widetilde{I}})
. Let
X,Y\subseteq I
be the sets corresponding to
{\widetilde{X}},{\widetilde{Y}}
before rounding. Then we have

R(X,Y)\leq(1+\varepsilon)\cdot\textup{OPT}_{\textup{L}}(I).

Proof.

We start by proving
\textup{OPT}_{\textup{L}}({\widetilde{I}})\leq(1+\tfrac{\varepsilon}{9})\textup{OPT}_{\textup{L}}(I)
. To this end, consider an optimal solution for
\textup{OPT}_{\textup{L}}(I)
, i.e., disjoint
X^{\prime},Y^{\prime}\subseteq I
with
\max(I)\in X^{\prime}\cup Y^{\prime}
and
R(X^{\prime},Y^{\prime})=\textup{OPT}_{\textup{L}}(I)
.
By symmetry we can assume
\Sigma(X^{\prime})\geq\Sigma(Y^{\prime})
. Since
\max(I)\in X^{\prime}\cup Y^{\prime}
we have
\Sigma(X^{\prime})\geq\max(I)
, which implies
\delta n\leq\frac{\varepsilon}{9}\Sigma(X^{\prime})
.
Let
{\widetilde{X}}^{\prime},{\widetilde{Y}}^{\prime}\subseteq{\widetilde{I}}
be the sets corresponding to
X^{\prime},Y^{\prime}
after rounding.
Note that
\Sigma(X^{\prime})\leq\Sigma({\widetilde{X}}^{\prime})\leq\Sigma(X^{\prime})+\delta n
and
\Sigma(Y^{\prime})\leq\Sigma({\widetilde{Y}}^{\prime})\leq\Sigma(Y^{\prime})+\delta n
.
This yields

\displaystyle\textup{OPT}_{\textup{L}}({\widetilde{I}})\leq R({\widetilde{X}}^{\prime},{\widetilde{Y}}^{\prime})=\max\left\{\frac{\Sigma(\widetilde{X}^{\prime})}{\Sigma(\widetilde{Y}^{\prime})},\frac{\Sigma(\widetilde{Y}^{\prime})}{\Sigma(\widetilde{X}^{\prime})}\right\}

\displaystyle\leq\max\left\{\frac{\Sigma(X^{\prime})+\delta n}{\Sigma(Y^{\prime})},\frac{\Sigma(Y^{\prime})+\delta n}{\Sigma(X^{\prime})}\right\}

\displaystyle\leq\frac{(1+\frac{\varepsilon}{9})\Sigma(X^{\prime})}{\Sigma(Y^{\prime})}

\displaystyle=(1+\tfrac{\varepsilon}{9})R(X^{\prime},Y^{\prime})=(1+\tfrac{\varepsilon}{9})\textup{OPT}_{\textup{L}}(I).

Now consider the sets
{\widetilde{X}},{\widetilde{Y}},X,Y
from the lemma statement.
By symmetry we can assume
\Sigma(X)\geq\Sigma(Y)
. Then we have

\displaystyle\max(I)

\displaystyle=\max(X\cup Y)

since
\max({\widetilde{I}})\in{\widetilde{X}}\cup{\widetilde{Y}}

\displaystyle\leq\Sigma(X)

since
\Sigma(X)\geq\Sigma(Y)

\displaystyle\leq\Sigma({\widetilde{X}})

by rounding up

\displaystyle\leq\textup{OPT}_{\textup{L}}({\widetilde{I}})\cdot\Sigma({\widetilde{Y}})

as
{\widetilde{X}},{\widetilde{Y}}
is an optimal solution for
\textup{OPT}_{\textup{L}}({\widetilde{I}})

\displaystyle\leq(1+\tfrac{\varepsilon}{9})\textup{OPT}_{\textup{L}}(I)\cdot\Sigma({\widetilde{Y}})

as shown in the first paragraph of this proof

\displaystyle\leq(1+\tfrac{\varepsilon}{9})\cdot 2\cdot\Sigma({\widetilde{Y}})

by assumption
\textup{OPT}_{\textup{L}}(I)\leq 2

\displaystyle\leq 4\cdot\Sigma({\widetilde{Y}}).

Together with
\delta\leq\frac{\varepsilon}{9n}\max(I)
we obtain
\delta n\leq\tfrac{4\varepsilon}{9}\Sigma({\widetilde{Y}})
and
\delta n\leq\tfrac{\varepsilon}{9}\Sigma({\widetilde{X}})
.
Note that we have
\Sigma(X)\leq\Sigma({\widetilde{X}})\leq\Sigma(X)+\delta n
and
\Sigma(Y)\leq\Sigma({\widetilde{Y}})\leq\Sigma(Y)+\delta n
.
We thus obtain

\displaystyle R(X,Y)=\max\left\{\frac{\Sigma(X)}{\Sigma(Y)},\frac{\Sigma(Y)}{\Sigma(X)}\right\}

\displaystyle\leq\max\left\{\frac{\Sigma({\widetilde{X}})}{\Sigma({\widetilde{Y}})-\delta n},\frac{\Sigma({\widetilde{Y}})}{\Sigma({\widetilde{X}})-\delta n}\right\}

\displaystyle\leq\max\left\{\frac{\Sigma({\widetilde{X}})}{(1-\tfrac{4\varepsilon}{9})\Sigma({\widetilde{Y}})},\frac{\Sigma({\widetilde{Y}})}{(1-\tfrac{\varepsilon}{9})\Sigma({\widetilde{X}})}\right\}

\displaystyle\leq\frac{R({\widetilde{X}},{\widetilde{Y}})}{1-\tfrac{4\varepsilon}{9}}=\frac{\textup{OPT}_{\textup{L}}({\widetilde{I}})}{1-\tfrac{4\varepsilon}{9}}\leq\frac{1+\tfrac{\varepsilon}{9}}{1-\tfrac{4\varepsilon}{9}}\textup{OPT}_{\textup{L}}(I)\leq(1+\varepsilon)\textup{OPT}_{\textup{L}}(I),

where in the last step we used
(1+\tfrac{\varepsilon}{9})/(1-\tfrac{4\varepsilon}{9})\leq 1+\varepsilon
for any
\varepsilon\in(0,1)
.
∎

4.6
Putting the Pieces Together

Now we are ready to prove a lemma which is almost the main result of Section
4
, except that it has the additional requirement
\textup{OPT}_{\textup{L}}(I)\leq 2
. We will remove this requirement in Section
4.7
.

Lemma 19
.

We can solve an
\textup{SSR}_{\textup{L}}
instance
(I,\varepsilon)
in time
O^{*}(1/\varepsilon^{0.93856})
, assuming
\textup{OPT}_{\textup{L}}(I)\leq 2
.

Proof.

To achieve this result we combine two algorithms.

Algorithm 1.

This algorithm works as follows:

1.

For a parameter
\tau\in\mathbb{N}
to be chosen later, partition
I
into its largest
\tau
numbers
T
(top) and the remaining numbers
B=I\setminus T
(bottom).

2.

Round up all numbers in
I=B\cup T
to multiples of
\alpha:=\frac{\varepsilon}{9n}\max(I)
, obtaining
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}}={\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}}\cup{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}}
. Apply Lemma
16
to compute disjoint
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}},{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}\subseteq{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}}
with
\max({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}})\in{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}}\cup{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}
realizing
\textup{OPT}_{\textup{L}}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}})
. By Lemma
18
, the sets
X,Y\subseteq I
corresponding to
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}},{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}
before rounding have ratio
R(X,Y)\leq(1+\varepsilon)\textup{OPT}_{\textup{L}}(I)
, so we are done.

For analyzing the running time we introduce the parameter
\psi:=\max(T)/\min(T)
.
Note that Step 3 is dominated by the call to Lemma
16
, which runs in time
O^{*}(S)
where
S=|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|+|P_{L}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}})|
(recall Definition
9
for
P(.)
and
P_{L}(.)
). We bound
|P_{L}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}})|\leq 3^{\tau}
(since every element of
T
can be in
X
or in
Y
or in neither of them).
For
|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|
, we note that the
x
-coordinates of points in
P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})
are multiples of
\alpha=\frac{\varepsilon}{9n}\max(I)=\frac{\varepsilon}{9n}\max(T)
of absolute value at most
n\cdot\max({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})\leq n\cdot\min({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}})\leq n\cdot(\min(T)+\alpha)
. Hence, the number of different
x
-coordinates is at most
2n\cdot(\min(T)+\alpha)/\alpha+1=O^{*}(1/(\varepsilon\psi)+1)
. Since each point in
P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})
has a unique
x
-coordinate, we obtain
|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|=O^{*}(1/(\varepsilon\psi)+1)
. The total running time thus is
O^{*}(1/(\varepsilon\psi)+3^{\tau})
. This finishes the analysis of Algorithm 1.

Algorithm 2.

We now extend the previous algorithm to also make use of Lemma
12
. Algorithm 2 works as follows:

1.

Partition
I
into its largest
\tau
numbers
T
(top) and the remaining numbers
B=I\setminus T
(bottom).

2.

Round up all numbers in
I=B\cup T
to multiples of
\beta:=\frac{\varepsilon}{2n}\min(T)
, obtaining
{\widetilde{I}}={\widetilde{B}}\cup{\widetilde{T}}
.
Check whether
|{\cal S}({\widetilde{B}})|>n\max({\widetilde{I}})/(\beta 2^{\tau})+1
in time
O^{*}(\max({\widetilde{I}})/(\beta 2^{\tau})+1)
by running the algorithm from Lemma
8
. If this check succeeds, then Lemma
12
is applicable. In this case, we run the algorithm from Lemma
12
on
{\widetilde{I}}={\widetilde{B}}\cup{\widetilde{T}}
, which is guaranteed to compute disjoint
{\widetilde{X}},{\widetilde{Y}}\subseteq{\widetilde{I}}
with
({\widetilde{X}}\cup{\widetilde{Y}})\cap{\widetilde{T}}\neq\emptyset
and
R({\widetilde{X}},{\widetilde{Y}})=1
. Now Lemma
17
is applicable to
{\widetilde{X}},{\widetilde{Y}}
, since
\beta=\frac{\varepsilon}{2n}\min(T)\leq\frac{\varepsilon}{2n}\min({\widetilde{T}})\leq\frac{\varepsilon}{2n}\max({\widetilde{X}}\cup{\widetilde{Y}})
. By Lemma
17
, the sets
X,Y\subseteq I
corresponding to
{\widetilde{X}},{\widetilde{Y}}
before rounding have ratio
R(X,Y)\leq 1+\varepsilon
. If we label each number in
{\widetilde{I}}
by its original number in
I
we can reconstruct
X,Y
from
{\widetilde{X}},{\widetilde{Y}}
in time
O^{*}(1)
, so we are done.

Hence, from now on we can assume
|{\cal S}({\widetilde{B}})|\leq n\max({\widetilde{I}})/(\beta 2^{\tau})+1
, so that Lemma
12
is not applicable.

3.

Round up all numbers in
I=B\cup T
to multiples of
\alpha:=\frac{\varepsilon}{9n}\max(T)
, obtaining
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}}={\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}}\cup{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}}
. Apply Lemma
16
to compute disjoint
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}},{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}\subseteq{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}}
with
\max({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}})\in{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}}\cup{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}
realizing
\textup{OPT}_{\textup{L}}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{I}$}}})
. By Lemma
18
, the sets
X,Y\subseteq I
corresponding to
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}},{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{Y}$}}}
before rounding have ratio
R(X,Y)\leq(1+\varepsilon)\textup{OPT}_{\textup{L}}(I)
, so we are done.

To analyze the running time of Algorithm 2, note that

\displaystyle\max({\widetilde{I}})/\beta

\displaystyle\leq 1+\max(I)/\beta

since we rounded up to multiples of
\beta

\displaystyle=1+\max(T)\cdot n/(\varepsilon\min(T))

since
T
contains the largest item of
I

\displaystyle=O^{*}(\psi/\varepsilon)

by definition of
\psi

(7)

Hence, running Lemma
12
in step 2 takes time
O^{*}(\max({\widetilde{I}})^{2}/(\beta^{2}4^{\tau})+3^{\tau})=O^{*}(\psi^{2}/(\varepsilon^{2}4^{\tau})+3^{\tau})
. The remaining running time of step 2 is dominated by this term.

As in Algorithm 1, Step 3 is dominated by the call to Lemma
16
, which runs in time
O^{*}(S)
where
S=|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|+|P_{L}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}})|
. We again bound
|P_{L}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{T}$}}})|\leq 3^{\tau}
. For
|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|
we now use a different bound.
We observe that each
x
-coordinate of a point in
P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})
can be written as the difference of two numbers in
{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})
. We can thus bound
|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|\leq|{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|^{2}
. As we will show in Claim
20
below, we have
|{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|=O^{*}(|{\cal S}({\widetilde{B}})|)
. Recall that after step 2 we can assume
|{\cal S}({\widetilde{B}})|=O^{*}(\max({\widetilde{I}})/(\beta 2^{\tau})+1)
, which we can simplify to
|{\cal S}({\widetilde{B}})|=O^{*}(\psi/(\varepsilon 2^{\tau})+1)
by using inequality (
7
). Combining these bounds yields
|P({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|=O^{*}(\psi^{2}/(\varepsilon^{2}4^{\tau})+1)
.
The total running time of Algorithm 2 is thus
O^{*}(\psi^{2}/(\varepsilon^{2}4^{\tau})+3^{\tau})
.

Claim 20
.

We have
|{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|=O^{*}(|{\cal S}({\widetilde{B}})|)
.

Proof.

Let
X\subseteq B
and consider the corresponding subsets
{\widetilde{X}}\subseteq{\widetilde{B}}
and
{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}}\subseteq{\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}}
.
Note that
\Sigma(X)\leq\Sigma({\widetilde{X}})<\Sigma(X)+|X|\cdot\beta\leq\Sigma(X)+n\beta
, and similarly
\Sigma(X)\leq\Sigma({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}})<\Sigma(X)+n\alpha
. Thus, their difference is bounded by
|\Sigma({\widetilde{X}})-\Sigma({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}})|<n\alpha
.

Now round up all numbers in
{\cal S}({\widetilde{B}})
to multiples of
\alpha
and remove duplicates to obtain a set
S
. Observe that
|S|\leq|{\cal S}({\widetilde{B}})|
. The number
s\in S
corresponding to
\Sigma({\widetilde{X}})\in{\cal S}({\widetilde{B}})
satisfies
\Sigma({\widetilde{X}})\leq s<\Sigma({\widetilde{X}})+\alpha
, and thus by triangle inequality
|s-\Sigma({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}})|\leq|s-\Sigma({\widetilde{X}})|+|\Sigma({\widetilde{X}})-\Sigma({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{X}$}}})|<(n+1)\alpha
.
Note that there are at most
2n+1
multiples of
\alpha
within distance less than
(n+1)\alpha
of
s
. It follows that
{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})
can be covered by
2n+1
translates of
S
, more precisely we have

{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})\subseteq S+\{-n\alpha,-(n+1)\alpha,\ldots,(n-1)\alpha,n\alpha\},

where we use the sumset notation
A+B=\{a+b\mid a\in A,b\in B\}
. Since
|A+B|\leq|A|\cdot|B|
, we obtain
|{\cal S}({\widetilde{\raisebox{0.0pt}[0.85pt]{$\widetilde{B}$}}})|\leq(2n+1)|S|\leq(2n+1)|{\cal S}({\widetilde{B}})|=O^{*}(|{\cal S}({\widetilde{B}})|)
.
∎

Since Algorithm 1 runs in time
O^{*}(1/(\varepsilon\psi)+3^{\tau})
and Algorithm 2 runs in time
O^{*}(\psi^{2}/(\varepsilon^{2}4^{\tau})+3^{\tau})
, by running the better of Algorithm 1 and Algorithm 2 we obtain an algorithm running in time

O^{*}(\min\{1/(\varepsilon\psi),\psi^{2}/(\varepsilon^{2}4^{\tau})\}+3^{\tau}).

Note that both terms in the minimum coincide when
\psi=\varepsilon^{1/3}4^{\tau/3}
. Thus, by running Algorithm 1 when
\psi\geq\varepsilon^{1/3}4^{\tau/3}
and Algorithm 2 when
\psi<\varepsilon^{1/3}4^{\tau/3}
we obtain an algorithm running in time
O^{*}(1/(\varepsilon^{4/3}4^{\tau/3})+3^{\tau})
.
Finally, we determine the optimal choice of
\tau
by equating the two summands, obtaining
\tau=4/3\cdot\log_{3\cdot 4^{1/3}}(1/\varepsilon)
(rounded to the closest integer). With this choice of
\tau
, the running time becomes

O^{*}(3^{4/3\cdot\log_{3\cdot 4^{1/3}}(1/\varepsilon)})=O^{*}((1/\varepsilon)^{4/3\log(3)/\log(3\cdot 4^{1/3})}).

We numerically evaluate the exponent to be
\approx 0.93855745...
. In particular, our running time is
O^{*}(1/\varepsilon^{0.93856})
.
This finishes the proof of Lemma
19
.
∎

4.7
The Case of Large Optimal Value

Finally, we remove the assumption
\textup{OPT}_{\textup{L}}(I)\leq 2
.
To this end, we present a simple
\sqrt{2}
-approximation algorithm, which is conceptually somewhat simpler than the
(1+\sqrt{5})/2
-approximation algorithm by Woeginger and Yu
[
22
]
. Importantly, we prove that our approximation algorithm computes an optimal solution if the optimal value is large, i.e.,
\textup{OPT}_{\textup{L}}(I)\geq\sqrt{2}
.

Lemma 21

(
\sqrt{2}
-approximation)
.

Given
I\subset\mathbb{R}_{>0}
of size
n
, in time
O(n)
we can compute disjoint
X,Y\subseteq I
with
\max(I)\in X\cup Y
and
R(X,Y)\leq\max\{\sqrt{2},\textup{OPT}_{\textup{L}}(I)\}
.

Proof.

As usual, we consider
I
to be an array
I[1\,..\,n]
and assume
I[1]\leq\ldots\leq I[n]
, so
\max(I)=I[n]
.
Let
s:=\Sigma(I[1\,..\,n-1])
. If
s\leq I[n]
, then we claim that the optimal solution for
\textup{OPT}_{\textup{L}}(I)
is
X=\{I[n]\}
and
Y=I[1\,..\,n-1]
, resulting in
\textup{OPT}_{\textup{L}}(I)=R(X,Y)=\Sigma(X)/\Sigma(Y)=I[n]/s
. Indeed, one of
X
or
Y
must contain
I[n]
, so suppose
I[n]\in X
. Then
\Sigma(X)\geq I[n]
and
\Sigma(Y)\leq s
, so
R(X,Y)\geq\Sigma(X)/\Sigma(Y)\geq I[n]/s
. Thus, our chosen sets
X,Y
are optimal.
It follows that in case
s\leq I[n]
we can easily compute an optimal solution.

So consider the case
s>I[n]
. Then we pick the largest
1\leq i\leq n-1
such that
\Sigma(I[i\,..\,n-1])>I[n]
. Note that such a value
i
exists since
\Sigma(I[1\,..\,n-1])=s>I[n]
. Moreover, we have
i<n-1
, since
\Sigma(I[n-1\,..\,n-1])=I[n-1]\leq I[n]
by sortedness.
We now set
X:=\{I[n]\}
,
Y:=I[i\,..\,n-1]
, and
Y^{\prime}:=I[i+1\,..\,n-1]
. Note that
\Sigma(Y)>\Sigma(X)\geq\Sigma(Y^{\prime})
. Moreover, by sortedness we have
I[i]\leq I[i+1]\leq\Sigma(Y^{\prime})
and thus
\Sigma(Y)=\Sigma(Y^{\prime})+I[i]\leq 2\Sigma(Y^{\prime})
. Hence, the better of the solutions
(X,Y)
and
(X,Y^{\prime})
has ratio

\min\left\{R(X,Y),R(X,Y^{\prime})\right\}=\min\left\{\frac{\Sigma(Y)}{\Sigma(X)},\frac{\Sigma(X)}{\Sigma(Y^{\prime})}\right\}\leq\sqrt{\frac{\Sigma(Y)}{\Sigma(Y^{\prime})}}\leq\sqrt{2}.

In both cases we obtain a solution of ratio at most
\max\{\sqrt{2},\textup{OPT}_{\textup{L}}(I)\}
. Implementing this algorithm in time
O(n)
is straightforward, for pseudocode see Algorithm
1
.
∎

\textup{OPT}_{\textup{L}}(I)
(and thus solves the

\textup{OPT}_{\textup{L}}(I)\geq\sqrt{2}
. Moreover, it runs in time

, as otherwise we already solved the

O^{*}(1/\varepsilon^{0.93856})
