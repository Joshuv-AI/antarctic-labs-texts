Box Dimension and Fractional Integrals of Multivariate Fractal Interpolation Functions
Vishal Agrawal, Megha Pandey, Tanmoy Som

Abstract
. In this article, we construct the multivariate fractal interpolation functions for a given data points and explore the existence of α \displaystyle\alpha -fractal function corresponding to the multivariate continuous function defined on [ 0 , 1 ] × ⋯ × [ 0 , 1 ] ( q -times ) \displaystyle[0,1]\times\cdots\times[0,1](q\text{-times}) . The parameters are selected such that the corresponding fractal version preserves some of the original function’s properties, for instance if the given function is Hölder continuous, then the corresponding α \displaystyle\alpha -fractal function is also Hölder continuous. Moreover, we explore the restriction of α \displaystyle\alpha -fractal function on the co-ordinate axis. Furthermore, the box dimension and Hausdorff dimension of the graph of the multivariate α \displaystyle\alpha -fractal function and its restriction are investigated. In the last section, we prove that mixed Riemann-Liouville fractional integral of fractal function satisfies a self-referential equation.

Multivariate Fractal Interpolation Function

The data of interpolation is given as

\left\{\left(x_{1,i_{1}},\ldots,x_{q,i_{q}},z_{(1,i_{1}),\ldots,(q,i_{q})}\right):i_{1}=0,1,\ldots,M_{1};~\ldots~;i_{q}=0,1,\ldots,M_{q}\right\},

\displaystyle 0=x_{k,0}<\cdots<x_{k,M_{k}}=1

\displaystyle I_{k}

\displaystyle I_{k}

\displaystyle k^{th}

\displaystyle I^{q}

For our convenience, we use the following notations in the rest of the study:

\displaystyle\Sigma_{k}=\{1,2,\ldots,k\},

\displaystyle\Sigma_{k,0}=\{0,1,\ldots,k\},

\displaystyle\partial\Sigma_{k,0}=\{0,k\}

\displaystyle\Sigma_{k,0}=\{1,2,\ldots,k-1\}.
Further, a net
\displaystyle\Delta

\displaystyle I^{q}

\Delta:=\left\{(x_{1,i_{1}},\ldots,x_{q,i_{q}})\in I^{q}:i_{k}\in\Sigma_{M_{k},0},~0=x_{k,0}<\ldots<x_{k,M_{k}}=1,~k\in\Sigma_{q}\right\}.

\displaystyle i_{k}\in\Sigma_{M_{k}}

\displaystyle u_{k,i_{k}}:I_{k}\rightarrow I_{k,i_{k}}
such that

\displaystyle u_{k,i_{k}}(x_{k,0})=

\displaystyle x_{k,i_{k}-1},\quad\quad u_{k,i_{k}}(x_{k,M_{k}})=x_{k,i_{k}},\text{ if $\displaystyle i_{k}$ is odd,}

(3.1)

\displaystyle u_{k,i_{k}}(x_{k,0})=

\displaystyle x_{k,i_{k}},\quad\quad u_{k,i_{k}}(x_{k,M_{k}})=x_{k,i_{k}-1},\text{ if $\displaystyle i_{k}$ is even, and }

\displaystyle\left\lvert u_{k,i_{k}}(x)-u_{k,i_{k}}(y)\right\rvert

\displaystyle\leq\mu_{k,i_{k}}\lvert x-y\rvert\text{ for all }x,y\in I_{k},\text{ and }0<\mu_{k,i_{k}}<1.

It is easy to observe from the definition of

\begin{cases}\eta(i,0)=i-1,\quad\eta(i,M_{1})=\cdots=\eta(i,M_{q})=i,&\text{ when $\displaystyle i$ is odd,}\\

\displaystyle K=I^{q}\times\mathbb{R}

Lemma 4.1
.

Let
\displaystyle f:I^{q}\rightarrow\mathbb{R}
be continuous on
\displaystyle I^{q}.
Then,
\displaystyle\dim_{H}\big(\mathcal{G}(f)\big)\geq q.

Proof.

Define a Lipschitz function
\displaystyle T:\mathcal{G}(f)\rightarrow I^{q}
by
\displaystyle T\big((x_{1},\ldots,x_{q},f(x_{1},\ldots,x_{q}))\big)=(x_{1},\ldots,x_{q}).
Recall that if
\displaystyle f:A\subseteq\mathbb{R}^{n}\to\mathbb{R}^{m}
is a Lipschitz function, then
\displaystyle\dim_{H}\big(f(A)\big)\leq\dim_{H}(A).
Hence, we get
\displaystyle\dim_{H}\big(T(\mathcal{G}(f))\big)\leq\dim_{H}\big(\mathcal{G}(f)\big).
It is straightforward to verify that the function
\displaystyle T
is surjective and thus the conclusion.
∎

\displaystyle\leq\overline{\lim}_{m\rightarrow\infty}\frac{\log\Big(2M^{mq}+M^{m(q+1)}M_{2}\alpha_{\max}^{m}\Big)}{m\log(M)}

\displaystyle=q+1+\frac{\log(\alpha_{\max})}{\log(M)}.

(c) If
\displaystyle\alpha_{\max}\leq\frac{1}{M_{1}^{\sigma}},
then we have

Osc_{f^{\alpha}}[D_{{(i_{1})_{1}\dots(i_{1})_{m}(i_{2})_{1}\dots(i_{2})_{m}\dots(i_{q})_{1}\dots(i_{q})_{m}}}]\leq\frac{Osc_{f^{\alpha}}[I^{q}]+m2^{\sigma/2}(K^{*}+K_{s})}{M_{1}^{m\sigma}}.

\displaystyle\overline{\lim}_{\delta\rightarrow 0}\frac{\log\Big(N_{\delta}(\mathcal{G}(f^{\alpha}))\Big)}{-\log(\delta)}

\displaystyle\leq

\displaystyle\overline{\lim}_{m\rightarrow\infty}\frac{\log\Big(2M^{mq}+M^{mq}M_{1}^{(1-\sigma)m}\big(Osc_{f^{\alpha}}[I^{q}]+m2^{\sigma/2}(K^{*}+K_{s})\big)\Big)}{m\log(M)}=q+1-\sigma.

∎

is well-defined. Note that

\displaystyle\displaystyle[T_{f}g]_{\sigma}

\displaystyle\displaystyle=

\displaystyle\displaystyle\max_{(i_{1},\dots,i_{q})\in\overset{q}{\underset{k=1}{\prod}}\Sigma_{M_{k}}}\underset{(x_{1},\ldots,x_{q}),(y_{1},\ldots,y_{q})\in\overset{q}{\underset{k=1}{\prod}}I_{k,i_{k}}}{\sup_{(x_{1},\ldots,x_{q})\neq(y_{1},\ldots,y_{q})}}\frac{|T_{f}g(x_{1},\ldots,x_{q})-T_{f}g(y_{1},\ldots,y_{q})|}{\|(x_{1},\ldots,x_{q})-(y_{1},\ldots,y_{q})\|_{2}^{\sigma}}
