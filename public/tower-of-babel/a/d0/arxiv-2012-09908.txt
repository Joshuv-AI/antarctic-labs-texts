A model reference adaptive system approach for nonlinear online parameter identification
Barbara Kaltenbacher, Tram Thi Ngoc Nguyen

Abstract




Abstract.

Dynamical systems, for instance in model predictive control, often contain unknown parameters, which must be determined during system operation. Online, or on-the-fly, parameter identification methods are therefore necessary. The challenge of online methods is that one must continuously estimate parameters as experimental data becomes available. The existing techniques in the context of time-dependent partial differential equations exclude the case where the system depends nonlinearly on the parameters. Based on a model reference adaptive system approach, we present an online parameter identification method for nonlinear infinite-dimensional evolutionary systems.

Keyword.

Online method, online estimation, reference adaptive system, parameter identification, infinite-dimensional systems, partial differential equations.

1
Introduction

Evolutionary, spatially dependent processes in science and engineering are usually modeled by time dependent partial differential equations (PDEs). These models often contain finite or infinite dimensional parameters, such as spatially varying drift or diffusion coefficients, as well as source terms, whose values are unknown and have to be recovered on the basis of indirect observations of the system. Whenever parameter identification needs to take place during the operation of the considered system – as is the case in e.g. model predictive control – so-called online methods have to be employed.

Model reference adaptive systems (MRAS) do so by setting up a dynamic update law for both the parameter and the state, where the evolutionary system for the state is a modification of the original model, while the parameter evolution is driven by the observation mismatch. Additionally, stabilizing terms are introduced.
Online parameter identification has been extensively studied in the finite dimensional setting, e.g.
[
8
,
17
,
21
]
; however, when it come to infinite dimensional models as arising in the context of PDEs, less is known so far.
We refer to the literature review in
[
2
,
14
,
15
]
for MRAS-based approaches in the PDE context. In the field of inverse problems
[
11
,
13
]
, the idea of treating the unknown parameter and the state as an extended variable can be founded in
[
7
,
9
,
10
,
18
]
Following up on
[
3
]
, which in turn was strongly inspired by
[
2
]
and
[
15
]
, we here extend the scope to problems that are nonlinear not only with respect to the state, but also with respect to the parameter – a situation that could not be tackled by the MRAS approaches investigated so far.
To this end, we first focus on the situation of complete state observations. This may be extended to the case of partial observations, following the principles of
[
3
,

]
, however with additional difficulties and obstacles arising due to parameter nonlinearity. As such, investigations on partial observations are postponed to future work.
In this context, we wish to point to recent progress on ensemble Kalman filters for inverse problems, see, e.g.,

The underlying state system

\displaystyle u^{*}(0)=u_{0}

(2)

1.2
The adaptive system

To derive an update law, we first extend the originally stationary
parameter to be a function of time, however, with zero time derivative. This yields the
equivalent model system

\displaystyle D_{t}q

\displaystyle=0

(4)

\displaystyle D_{t}u^{*}+f(q,u^{*})

\displaystyle=g

(5)

\displaystyle(q,u^{*})(0)=(q^{*},u_{0}).

(6)

corresponding to the
model system
(
1
)-(
2
), where notationally

Hence, the parameter

Online identification means that the parameter identification, the data collection process and the system operation are taking place simultaneously. During these processes, the data

To this end, we propose the

\displaystyle D_{t}q+\sigma(D_{t}z+f(q,z)-g)-f^{\prime}_{q}(\tilde{q},z)^{*}(u-z)

\displaystyle=0

(7)

\displaystyle D_{t}u+f(q,z)+\mathcal{C}(\|q\|_{H})(u-z)

\displaystyle=g

(8)

\displaystyle(q,u)(0)=(q_{0},u_{0}),

(9)

to be solved for
(q,u).

At this point, the parameter estimate

clearly depends on time. The reference adaptive system is compatible with the equivalent model system in the sense that compared to (
4
)-(
5
), the emerging terms in (
7
)-(
8
) continuously decrease the discrepancy
(u(t)-z(t))
. This leads to a progressive improvement of

from

towards the exact parameter

as times evolves. To fulfill this,

and

In the adaptive system,

is the solution to the model system (

)-(
2
) measured by the observation process (
3
).

is an initial guess for

are stationary parameters in

lies in some time-dependent parameter space

, and
\tilde{q}\in\mathcal{Q}
is some point in which

is differentiable. The state estimate

\mathcal{U}
.
\mathcal{Q}

Following usual partial derivative notation, but without strictly demanding Fréchet differentiablility,

we assume

\displaystyle f^{\prime}_{q}(\tilde{q},z)\in L^{\infty}([0,\infty);\mathcal{L}(H,U^{*}))

to be a linearization of

with respect to its first variable; typically just the Gâteaux derivative.
Here, the inclusion
f^{\prime}_{q}(\tilde{q},z)(t)\in\mathcal{L}(H,U^{*})
corresponds to the bound of
\|q-q^{*}\|_{H}
in
H
as assumed in
(A3)
.

Moreover,
\sigma\in\{0,1\}
is a switching parameter, which is set to zero if

) and to one
otherwise
.
Equally important,
q\mapsto\mathcal{C}(\|q\|_{H})
is possibly
nonlinear and for fixed

,

\mathcal{C}(\|q(t)\|_{H})
is a linear operator in
\mathcal{L}(U,U^{*})
, whose structure will later be specified in Assumption

.
The adjoint of the linearization of

The model reference adaptive system (
7
)-(
9
) is well-defined due to

\displaystyle g-D_{t}z=f(q^{*},z)\in L^{2}([0,\infty);U^{*})\subseteq L^{2}([0,\infty);Q^{*})

\displaystyle f^{\prime}_{q}(\tilde{q},z):L^{2}([0,\infty);H)\to L^{2}([0,\infty);U^{*})

\displaystyle f^{\prime}_{q}(\tilde{q},z)^{*}:L^{2}([0,\infty);U)\to L^{2}([0,\infty);H)\subset L^{2}([0,\infty);Q^{*}).

This results in

, which is a conventional choice for image spaces in the context of time-dependent PDEs.

We search for the solution of the adaptive system in the spaces

\displaystyle u\in\mathcal{U}:=L^{2}([0,\infty);U)\cap H^{1}([0,\infty);U^{*})\cap L^{\infty}([0,\infty);H)

(10)

\displaystyle q\in\mathcal{Q}:=L^{2}([0,\infty);H)\cap H^{1}([0,\infty);Q^{*})\cap L^{\infty}([0,\infty);H).

(11)

The reference system (

)-(

) mimics the model system (

)-(

) and (

in (

\displaystyle r(t):=u(t)-z(t)\to 0\quad\text{and}\quad e(t):=q(t)-q^{*}\to 0\quad\text{as }t\to\infty.

(12)

In order to establish the convergence (

Assumption 1.1
.

(A1)

For the exact parameter
q^{*}\in Q
, the exact state
u^{*}\in\mathcal{U}

uniquely
exists, and

is the full measurement data.

(A2)

For
\tilde{q}\in\mathcal{Q}
the operator

is a linearization of

at

in the sense that for any

,

\|f(q,z)-f(q^{*},z)-f^{\prime}_{q}(\tilde{q},z)(q-q^{*})\|_{U^{*}}\leq L(\|q\|_{H})\|q-q^{*}\|_{H}.

for some monotonically increasing function
L:[0,\infty)\to[0,\infty)
.

(A3)

If in
(A2)
one has
L\not\equiv 0
, i.e.,
\sigma=1
, then there exists a constant

such that for all

,

\langle f(q,z)-f(q^{*},z),q-q^{*}\rangle_{Q^{*},Q}\geq C_{\text{coe}}\|q-q^{*}\|_{H}^{2}.

(A4)

\mathcal{C}
is chosen such that for given

, and all

\displaystyle\langle\mathcal{C}(\|q\|_{H})v,v\rangle_{U^{*},U}

\displaystyle\geq\left(\frac{L^{2}(\|q\|_{H})}{2C_{\text{coe}}}+M\right)\|v\|_{U}^{2}=:\widetilde{M}(\|q\|_{H})\|v\|_{U}^{2}

(13)

\displaystyle\langle\mathcal{C}(\|q\|_{H})v,w\rangle_{U^{*},U}

\displaystyle\leq\widetilde{N}(\|q\|_{H})\|v\|_{U}\|w\|_{U}

(14)

for some constant
M>0
and some monotonically increasing function
\widetilde{N}:[0,\infty)\to[0,\infty)

Indeed, the model reference adaptive system (
7
)-(
9
) is an extension of the system devised in

]

\displaystyle D_{t}q-f(\cdot,z)^{*}(u-z)

\displaystyle=0

(15)

\displaystyle D_{t}u+f(q,z)+\mathcal{C}(u-z)

\displaystyle=g

(16)

\displaystyle(q,u)(0)=(q_{0},u_{0}).

(17)

As shown in

In (

For simplicity of exposition, and since the linear case has already been discussed in

Remark 1.4

If

Remark 1.5
.

The estimate in assumption

\forall M,\exists L(M)\geq 0:\|f(q,z)-f(q^{*},z)\|_{U^{*}}\leq L(M)\|q-q^{*}\|_{H}\quad\forall q,q^{*}\in Q:\|q\|_{H},\|q^{*}\|_{H}\leq M.

In addition,

Indeed, let us consider,

{\color[rgb]{0,0,0}R_{\epsilon}:=}\frac{1}{\epsilon}\|f(q+\epsilon\xi,z)-f(q,z)-\epsilon f^{\prime}_{q}(q,z)\xi\|_{L^{2}([0,T),U^{*})}{\color[rgb]{0,0,0}=:}\left(\int_{0}^{\infty}r_{\epsilon}(t)^{2}dt\right)^{\frac{1}{2}}.

Under the assumption of local Lipschitz continuity, by choosing

\displaystyle\|f^{\prime}_{q}(q(t),z(t))\xi(t)\|_{U^{*}}

\displaystyle=\lim_{\epsilon\rightarrow 0}\left\|\frac{f(q(t)+\epsilon\xi(t),z(t))-f(q(t),z(t))}{\epsilon}\right\|_{U^{*}}

Convergence analysis of the error system

\displaystyle 0

4
Conclusions and outlook

In this paper, we have proposed and analyzed an online parameter identification method
for problems governed by nonlinear time-dependent PDEs. Our approach introduces a dynamic update law for both the state and the parameter via a model reference adaptive system. This system contains a linear PDE for the state and an auxiliary nonlinear one for the stationary parameter. Under suitable structural assumptions on the operators, unique existence results for this nonlinear adaptive system were given. In addition, by evaluating the error system, we proved that the solution to the adaptive system converges to the exact state and parameter for both exact as well as noisy data. Our key contribution is that we tackle the case where the system of PDEs is not only nonlinear with respect to the state, but also nonlinear with respect to the parameters; this situation has not been investigated thus far.

There are several future directions which could extend the study we have presented. Numerical experiments to illustrate the performance of our scheme are yet to be provided, and would be a natural continuation of this work. In the present work, we restrict ourselves to the case where the full state is measured. A modified scheme for the practically relevant situation of partial state observation is highly desirable.

Likewise, perturbations not only of the data but also of the model
f
would be of high practical interest.

Finally, an extension of our result in the framework of time dependent parameters is also an appealing topic.
