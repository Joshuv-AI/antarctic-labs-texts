Growth and decay of Hölder moduli AMS Subject Classification (2020): 42B25 (primary); 42C15, 42C40 (secondary). Key words: vaguelets, wavelets, almost-orthogonality.
Michael Wilson

Abstract
If f : 𝐑 d → 𝐂 f:{{\bf R}^{d}}\to{\bf C} is bounded and f f ’s Hölder α \alpha -modulus of continuity grows no faster than ( 1 + | x | ) M (1+|x|)^{M} ( M ≥ 0 M\geq 0 ) then, for every ϵ > 0 \epsilon>0 , there is a β > 0 \beta>0 such that f f ’s Hölder β \beta -modulus grows no faster than ( 1 + | x | ) ϵ (1+|x|)^{\epsilon} . We use this easy fact to show that, if | f | |f| decays as fast as ( 1 + | x | ) − R (1+|x|)^{-R} (for R > 0 R>0 ) and f f ’s α \alpha -Hölder modulus grows no faster than ( 1 + | x | ) M (1+|x|)^{M} , then, for every 0 ≤ R ′ < R 0\leq R^{\prime}<R , there is a β > 0 \beta>0 such that f f ’s β \beta -Hölder modulus decays as fast as ( 1 + | x | ) − R ′ (1+|x|)^{-R^{\prime}} . We apply this to strengthen a result of Coifman and Meyer on almost-orthogonality of vaguelet families and to derive other useful facts about vaguelets and vaguelet-like functions.
