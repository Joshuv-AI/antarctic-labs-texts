On the minimum weights of binary LCD codes and ternary LCD codes
Makoto Araya, Masaaki Harada, Ken Saito

Abstract
Linear complementary dual (LCD) codes are linear codes that intersect with their dual codes trivially. We study the largest minimum weight d 2 ​ ( n , k ) d_{2}(n,k) among all binary LCD [ n , k ] [n,k] codes and the largest minimum weight d 3 ​ ( n , k ) d_{3}(n,k) among all ternary LCD [ n , k ] [n,k] codes. The largest minimum weights d 2 ​ ( n , 5 ) d_{2}(n,5) and d 3 ​ ( n , 4 ) d_{3}(n,4) are partially determined. We also determine the largest minimum weights d 2 ​ ( n , n − 5 ) d_{2}(n,n-5) , d 3 ​ ( n , n − i ) d_{3}(n,n-i) for i ∈ { 2 , 3 , 4 } i\in\{2,3,4\} , and d 3 ​ ( n , k ) d_{3}(n,k) for n ∈ { 11 , 12 , … , 19 } n\in\{11,12,\ldots,19\} .

2.1
Definitions and notations

Let
\mathbb{F}_{q}
denote the finite field of order
q
,
where
q
is a prime power.
A linear
[n,k]
code over
\mathbb{F}_{q}
is a
k
-dimensional vector
subspace of
\mathbb{F}_{q}^{n}
.
All codes in this paper are linear, and
codes means are linear codes.
Codes over
\mathbb{F}_{2}
and
\mathbb{F}_{3}
are called
binary
and

ternary
, respectively.
The
weight

\wt(x)
of a vector
x\in\mathbb{F}_{q}^{n}
is
the number of non-zero components of
x
.
A vector of an
[n,k]
code
C
over
\mathbb{F}_{q}

is called a
codeword
.
The minimum non-zero weight of all codewords in
C
is called
the
minimum weight
of
C
.
An
[n,k]
code with minimum weight
d
is called an
[n,k,d]
code.
Two codes
C
and
C^{\prime}
over
\mathbb{F}_{q}
are
equivalent

if there is a monomial matrix
P
with

C^{\prime}=C\cdot P
, where

C\cdot P=\{xP\mid x\in C\}
.
For any
[n,k,d]
code over
\mathbb{F}_{q}
, it is known that

n\geq\sum_{i=0}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil
.
This bound is well known as the
Griesmer bound
.
For a given set of parameters
q,n,k
,
define

g_{q}(n,k)=\max\left\{d\in\mathbb{Z}_{\geq 0}~\middle|~n\geq\sum_{i=0}^{k-1}\left\lceil\frac{d}{q^{i}}\right\rceil\right\},

where
\mathbb{Z}_{\geq 0}
denotes the set of nonnegative integers.

The
dual
code
C^{\perp}
of an
[n,k]
code
C

over
\mathbb{F}_{q}
is defined as

C^{\perp}=\{x\in\mathbb{F}_{q}^{n}\mid\langle x,y\rangle=0\text{ for all }y\in C\},

where
\langle x,y\rangle=\sum_{i=1}^{n}x_{i}{y_{i}}

for
x=(x_{1},x_{2},\ldots,x_{n}),y=(y_{1},y_{2},\ldots,y_{n})\in\mathbb{F}_{q}^{n}
.
The minimum weight of the dual code
C^{\perp}
of a code
C
is called
the
dual distance
of
C
and it is denoted by
d^{\perp}
.
A code
C
is
self-orthogonal
if
C\subset C^{\perp}
.

A code
C
over
\mathbb{F}_{q}
is called

linear complementary dual
(LCD for short)
if
C\cap C^{\perp}=\{\mathbf{0}_{n}\}
,
where
\mathbf{0}_{n}
denotes the zero vector of length
n
.
Let
d_{q}(n,k)
denote the largest minimum weight among all LCD
[n,k]

codes over
\mathbb{F}_{q}
.
The following characterization is due to Massey
[
14
]
.

Proposition 2.1
.

Let
C
be a code over
\mathbb{F}_{q}
with generator matrix
G
.
Then the following properties are equivalent:

(i)

C
is LCD,

(ii)

C^{\perp}
is LCD,

(iii)

GG^{T}
is nonsingular,
where

G^{T}
denotes the transpose of a matrix
G
.

Throughout this paper, we use the above proposition
without mentioning this,
when we determine whether a given code is LCD or not.

G_{q,k}(m)=\left(h_{q,k,1}\cdots h_{q,k,1}\cdots h_{q,k,[k]_{q}}\cdots h_{q,k,[k]_{q}}\right).

(1)

.
We denote by

(

By considering all vectors

(3)

3
LCD codes meeting the Griesmer bound

Ward
[
17
]
studied the divisibility of codes meeting the Griesmer
bound.
The following lemma is a consequence of
[
17
, Theorem 1]
, however,
it is a powerful tool for our study in
Sections
4
and
5
.

Lemma 3.1
.

(i)

If
k
is odd and
d
is even, then there is no binary LCD
[n,k,d]
code
meeting the Griesmer bound for every positive integer
n
.

(ii)

If
d\equiv 0\pmod{3}
, then there is no ternary LCD
[n,k,d]
code
meeting the Griesmer bound for every positive integers
n
and
k
.

Proof.

(i)

Suppose that there is a binary LCD
[n,k,d]
code
C

meeting the Griesmer bound.
If
d
is even, then

C
is an even code
[
17
, Theorem 1]
.
Any binary even LCD code must have even dimension
[
7
, Theorem 5]
.

(ii)

Suppose that there is a ternary LCD
[n,k,d]
code
C

meeting the Griesmer bound and
d\equiv 0\pmod{3}
.
By
[
17
, Theorem 1]
,
the weight of any codeword in
C
is a multiple of
3
.
It is known that the weights of all codewords in
C
are
multiples of
3

if and only if
C
is self-orthogonal
(see e.g. the proof of
[
13
, Theorem 2.1]
).
This is a contradiction.

This completes the proof.
∎

Remark 3.2
.

A similar argument shows the nonexistence of a
binary LCD
[n,k,d]
code
meeting the Griesmer bound for
d\equiv 0\pmod{4}

(see the proof of
[
9
, Proposition 3.9]
).

It was shown that
d_{2}(k+1,k)=2
and
1
if

k
is even and odd, respectively
[
9
, Proposition 3.2]
.
This result is generalized, as an example of the above lemma.

Proposition 3.3
.

For a positive integer
k\geq 3
and a positive integer
s
,

d_{2}((2^{k}-1)s+k+1,k)=\begin{cases}2^{k-1}s+2\text{ if $k$ is even,}\\
2^{k-1}s+1\text{ if $k$ is odd.}\end{cases}

Proof.

Suppose that
k\geq 3
.
Then, by Lemma
2.2
, there is a binary LCD

[(2^{k}-1)s+k+1,k,2^{k-1}s+d_{2}(k+1,k)]
code for every positive integer
s
.
For every positive integer
s
,
the Griesmer bound is the same as the following bound:

d_{2}((2^{k}-1)s+k+1,k)\leq 2^{k-1}s+2.

Note that the equality holds in the above bound if and only if
the equality holds in the Griesmer bound.
When
k
is odd,
by Lemma
3.1
(i),
there is no binary LCD

[(2^{k}-1)s+k+1,k,2^{k-1}s+2]
code for every positive integer
s
.
The result follows.
∎

In addition, by Lemma
3.1
(i), we determine the
largest minimum weights

d_{2}(127s+15,7)
,

d_{2}(127s+23,7)
and
d_{2}(511s+17,9)

for a nonnegative integer

.

.

For a nonnegative integer

\begin{array}[]{ll}d_{2}(127s+15,7)=64s+5,&d_{2}(127s+23,7)=64s+9,\\

Let

By the Griesmer bound, we have

\begin{array}[]{ll}d_{2}(127s+15,7)\leq 64s+6,&d_{2}(127s+23,7)\leq 64s+10,\\

For

(511s+17,9,256s+6)\end{array}\right\},

each binary
[n,k,d]

Since

is odd and

is even,
by Lemma

(i), it is not LCD.
Hence, we have

\begin{array}[]{ll}d_{2}(127s+15,7)\leq 64s+5,&d_{2}(127s+23,7)\leq 64s+9,\\
d_{2}(511s+17,9)\leq 256s+5.\end{array}

It is known that

[

In this section, we determine

.
We also determine the largest minimum weights
d_{3}(20,k)

4

We employ two methods for constructing ternary codes.

•

Method I:
Every ternary
[n,k,d]
code is equivalent to a code
with generator matrix of form:

\left(\begin{array}[]{cc}I_{k}&A\end{array}\right),

where
A
is a
k\times(n-k)
matrix and

I_{k}
denotes the identity matrix of order
k
.
Let
r_{i}
be the
i
-th row of
A
.
Here, we may assume that
A
satisfies the following conditions:

(a)

r_{1}=(\mathbf{0}_{n-k-d+1},\mathbf{1}_{d-1})
,

(b)

the weight of
r_{i}
is at least
d-1

(i\in\{2,3,\ldots,k\})
,

(c)

the first nonzero element of
r_{i}
is
1

(i\in\{2,3,\ldots,k\})
,

(d)

r_{1}<r_{2}<\cdots<r_{k}
if
d\geq 3
and

r_{1}\leq r_{2}\leq\cdots\leq r_{k}
if
d\leq 2
,

where
we consider some order
<
on
the set of vectors of length
n-k
.
The set of matrices
A
is constructed, row by row, under
the assumption that the minimum weight of the ternary

[n+m-k,m]
code with generator matrix of form:

\left(\begin{array}[]{ccccc}&r_{1}\\
I_{m}&\vdots\\
&r_{m}\\
\end{array}\right)

is at least
d
for each
m\in\{2,3,\ldots,k-1\}
.
It is obvious that the set of the ternary
[n,k,d]

codes obtained by this method
contains a set of all inequivalent ternary
[n,k,d]
codes.

•

Method II:
Let
C
be a ternary code.
Let
C(t)
be the set of all codewords which are
0
in a fixed
coordinate
t
.
The ternary code obtained from
C(t)
by deleting the
coordinate
t
in each codeword is called a
shortened code
of
C
.
A shortened code of a ternary
[n,k,d]
code with
d\geq 2

is a ternary
[n-1,k,d]
code if the deleted coordinate
is zero in all codewords and a ternary
[n-1,k-1,d^{\prime}]

code with
d^{\prime}\geq d
otherwise.
By considering the inverse operation of shortening,
every ternary
[n,k,d]
code with
d\geq 2
is constructed from some
ternary
[n-1,k-1,d^{\prime}]
code with
d^{\prime}\geq d
.
It is obvious that the set of the ternary
[n,k,d]

codes obtained by this method
contains a set of all inequivalent ternary
[n,k,d]
codes.
This method is useful for small
k
.

We describe how our computer calculation determined
the minimum weights
d_{3}(n,k)
.
Let
d_{3}^{\text{all}}(n,k)
denote the largest minimum weight
among all ternary
[n,k]
codes.
For a given pair
(n,k)
,
we checked whether there is a ternary LCD
[n,k,d_{3}^{\text{all}}(n,k)]

If there is no ternary LCD
[n,k,d_{3}^{\text{all}}(n,k)]
code,
then
we checked whether there is a ternary LCD
[n,k,d_{3}^{\text{all}}(n,k)-1]

code or not.
By continuing this process, we determined the minimum weights
d_{3}(n,k)

for
n\in\{11,12,\ldots,19\}
.
We also determined the minimum weights
d_{3}(20,k)

with
4
exceptions.
The largest minimum weights

.

Lemma 7.3
.

Suppose that
i
is an integer with
2\leq i\leq n-1
.

(i)

There is a ternary LCD
[n,n-i,2]
code.

(ii)

If
n>\frac{3^{i}-1}{2}
, then
d_{3}(n,n-i)=2
.

Proof.

Let
C
be a ternary
[n,n-i]
code with parity-check matrix
H
, where

H=\begin{cases}\left(\begin{array}[]{cccccccccc}1&0&1&1&1&\cdots&1\\
0&1&1&1&0&\cdots&0\\
\end{array}\right)&\text{ if }i=2,\\
\left(\begin{array}[]{cccccccccc}&&1&1&1&\cdots&1\\
&I_{i}&1&1&0&\cdots&0\\
&&\mathbf{0}_{i-2}^{T}&\mathbf{0}_{i-2}^{T}&\mathbf{0}_{i-2}^{T}&\cdots&\mathbf{0}_{i-2}^{T}\\
\end{array}\right)&\text{ if }i\in\{3,4,\ldots,n-1\}.\end{cases}

Since

HH^{T}=\begin{cases}\left(\begin{array}[]{cccccccccc}n-1&2\\
2&0\end{array}\right)&\text{ if }i=2,\\
\left(\begin{array}[]{cccccccccc}n-i+1&2&&\mathbf{0}_{i-2}&\\
2&0&&\mathbf{0}_{i-2}&\\
\mathbf{0}_{i-2}^{T}&\mathbf{0}_{i-2}^{T}&&I_{i-2}&\\
\end{array}\right)&\text{ if }i\in\{3,4,\ldots,n-1\},\end{cases}

the code
C
is LCD.
By the construction, it is trivial that
C
has minimum weight
2
.
This proves the assertion (i).

Suppose that there is a ternary
[n,n-i,d]
code.
By the sphere-packing bound, if

, then

n\leq\frac{3^{i}-1}{2}
.
This proves the assertion (ii).
