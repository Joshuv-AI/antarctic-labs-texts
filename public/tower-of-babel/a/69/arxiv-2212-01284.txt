Graph Coloring as a Measure of Network Vulnerability
Grace Mulry Mia DesStefano Mason Nakamura Rodrigo Rios Nathan Shank

Abstract
We consider new parameters for conditional network vulnerability related to graph coloring. We define a network to be in operation if the chromatic number (or index) is greater than some specified value k k . The parameters of interest, the minimum k k -chromatic number and the minimum k k -chromatic index consider the least number of failures in the network which could render the network inoperable. In this paper, we consider edge failure, vertex failures, as well as mixed failures for paths, cycles, and complete graphs.



1
Introduction

Networks, modeled as graphs, can represent many things, including social networks, computational networks, electrical networks, neural networks, or transportation networks. The underlying structure of the network is vital to is operation. Network vulnerability parameters focus on investigating the stability of networks given a particular parameter of interest, which signifies if the network is operational or in a failure state. Network vulnerability can be thought of as the study of how much damage (e.g. number of removed vertices or edges) to a network must be done for it to enter a failure state.

Initially, in the 1970’s and 80’s, network vulnerability focused on connectivity. More recently, other parameters have been of interest. Harary
[
9
]
generalized the idea for other models by considering a property
P
and a network
G
to be operational if there is a component of
G
which contains property
P
. Thus, a network is in a failure state if no component has property
P
. Some examples of parameters that have been studied include diameter
[
3
]
, domination
[
5
]
, and many variations on component order (see
[
2
]
,
[
6
]
, and
[
7
]
for example).

Through this paper we will assume that
G
is a simple graph. We will consider the chromatic number of
G
, denoted
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G)
, as well as the chromatic index of
G
, denoted
\lambda(G)
, to define the failure states. Recall that the chromatic number of a graph
G
is the minimum number of colors needed to color the vertices of a graph so that no two adjacent vertices are the same color. The chromatic index of a graph is the minimum number of colors needed to color the edges of a graph such that no vertex is incident to two edges of the same color. For other graph theory notation and terminology, we will follow
[
10
]
.

There are many applications of graph coloring, more specifically chromatic number and chromatic index. Chromatic number can assist in scheduling, organizing radio stations, traffic signaling, puzzle solver, and register allocation. Chromatic index has many applications in scheduling and communication networks (see
[
8
]
and
[
4
]
for example).

However, investigating the vulnerability of networks based on these parameters also has practical applications, as it lets us know, quantitatively, the amount that a graph might be disturbed when variables change. For example, the study of network vulnerability can help inform how to construct the most reliable schedules possible for an organization in terms of the parameter; so, if one person is removed, the schedule still holds.

In Chapter
2
, we will focus on chromatic number, whereas Chapter
3
will focus on the chromatic index. For each of these chapters, we will consider edge removal, followed by vertex removal, and then mixed removal where vertices are removed first and then edges. We will demonstrate the parameters with results for paths, cycles, and complete graphs. In chapter
4
, we will briefly discuss some extensions as well as other interesting graph classes to consider.

Chromatic Number

In this chapter, we will consider the chromatic number as the parameter of interest. Section
2.1
will consider edge removal, Section
2.2
will consider vertex removal, and Section
2.3

2.1
Edge Removal

The goal of this parameter is to find the minimum number of edges that can be removed so that the remaining graph has a chromatic number less than
k
, for some positive integer
k
. To do this, we will first define a
k
-chromatic number edge removal set
as a set of edges, so that when removed, the resulting graph has a chromatic number less than or equal to
k
. Since we are trying to do this as efficiently as possible, the parameter of interest will be the size of the smallest
k
-chromatic number edge removal set. This is made more formal in the following definitions:

Definition 2.1
.

Given a positive integer
k
and a graph
G=(V,E)
, we say a set of edges
E^{\prime}\subseteq E
is a
k
-chromatic number edge removal set
if
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G-E^{\prime})\leq k
.

Definition 2.2
.

Let
\mathcal{E}
be the set of all
k
-chromatic number edge removal sets. Define the
k
-chromatic number edge removal parameter
as

\chi_{e}^{k}(G)=\min\{|E^{\prime}|:E^{\prime}\in\mathcal{E}\}.

Any set
E^{\prime\prime}\in\mathcal{E}
where
|E^{\prime\prime}|=\chi_{e}^{k}(G)
will be called a
minimum
k
-chromatic number edge removal set
.

For any graph
H
, if
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(H)\leq k
, then
H
is in a
failure state.
If
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(H)>k
, then
H
is not in a failure state and our network remains in an
operable state
. Thus,
\chi_{e}^{k}(H)=0
if and only if
H
is in a failure state.

If
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G)=1
, then
|E(G)|=0
. Otherwise, any edge will require at least two , one for each of the vertices incident to that edge. Thus we have the following simple lemma for the case when
k=1
.

Lemma 2.3
.

For any graph
G=(V,E)
, if
k=1
,
\chi_{e}^{k}(G)=|E|
.

We will now consider the path graphs,
P_{n}
, as well as cycle graphs,
C_{n}
.

Theorem 2.4
.

If
P_{n}
is a path graph on
n
vertices then

\chi_{e}^{k}(P_{n})=\begin{cases}0&\text{ if }k>1,\\
n-1&\text{ if }k=1.\end{cases}

Proof.

Notice that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(P_{n})=2
. Therefore, if
k>1
,
P_{n}
is already in a failure state. The other case follows from Lemma
2.3
.
∎

Theorem 2.5
.

If
C_{n}
is a cycle graph on
n
vertices then

\chi_{e}^{k}(C_{n})=\begin{cases}n&\text{ if }k=1,\\
n\pmod{2}&\text{ if }k=2,\\
0&\text{ if }k>2.\end{cases}

Proof.

Consider the cases where
k=2
and
k>2
, as in the case where
k=1
is Lemma
2.3
.

1.

Case
k=2
:
In
n
is an even integers, it is known that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})=2
and thus
\chi_{e}^{k}(C_{n})=0
. If
n
is an odd integer, then
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})=3
, and thus at least one edge removal is necessary. No additional edges need to be removed since
C_{n}-\{e\}=P_{n}
which is already in a failure state according to Theorem
2.4
.

2.

Case
k>2
:
Note that for all positive integers
n
,
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})\leq 3
and so when
k>2
(or
k\geq 3
)
C_{n}
is already in a failure state.

∎

Now, we turn our attention to complete graphs,
K_{n}
. Recall that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(K_{n})=n
. If
k>n
, then
K_{n}
is already in a failure state and
\chi_{e}^{k}(K_{n})=0
. Therefore, we will only consider the case where
k\leq n
.

To proceed, we will need to use the well-known Turán graph.

Definition 2.6
.

For positive integers
n\geq k
, the Turán graph, denoted
T(n,k)=(V,E)
, as a complete multipartite graph with
k
parts,
V_{1},V_{2},\ldots,V_{k}
, which partition
V
such that
-1\leq|V_{i}|-|V_{j}|\leq 1
for all
1\leq i\leq j\leq k
.

This is to say that
T(n,k)
is a complete multipartite graph containing
k
parts of nearly equal size. Note that
T(n,k)
does not have a
K_{k+1}
as a subgraph since there are only
k
parts. We will denote the number of edges in the Turán graph by
|(T(n,k)|
. Notice that if
p
and
q
are non-negative integers so that
n=pk+q
and
0\leq q<k
then

|T(n,k)|=\binom{n}{2}-\left(q\binom{p+1}{2}+(k-q)\binom{p}{2}\right).

Theorem 2.7
.

Let
K_{n}
be a complete graph on
n
vertices. For any positive integers
k\leq n
, find non-negative integers
p
and
q
so that
n=pk+q
and
0\leq q<k
. Then,

\chi_{e}^{k}(K_{n})=q\binom{p+1}{2}+(k-q)\binom{p}{2}.

Proof.

By Turán’s Theorem (see
[
10
]
pg 208), if
G
is any graph of order
n
with
|V(G)|>|T(n,k)|
, then
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G)\geq k+1
since
G
must contains a
K_{k+1}
as an induced subgraph. Since
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(T(n,k))=k
, we can conclude that

\displaystyle\chi_{e}^{k}(K_{n})

\displaystyle=|E(K_{n})|-|T(n,k)|

\displaystyle=q\binom{p+1}{2}+(k-q)\binom{p}{2}.

∎

2.2
Vertex Removal

We will now turn our attention to the case of vertex removal. We proceed as before by considering all
k
-chromatic number vertex removal sets
and then finding the size of the minimum of these sets.

Definition 2.8
.

Given a positive integer
k
and a graph
G=(V,E)
, we say a set of vertices
V^{\prime}\subseteq V
is a
k
-chromatic number vertex removal set
if
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G-V^{\prime})\leq k
.

Definition 2.9
.

Let
\mathcal{V}
be the set of all
k
-chromatic number vertex removal sets. Define
k
-chromatic number vertex removal parameter
as

\chi_{v}^{k}(G)=\min\{|V^{\prime}|:V^{\prime}\in\mathcal{V}\}.

Any set
V^{\prime\prime}\in\mathcal{V}
where
|V^{\prime\prime}|=\chi_{v}^{k}(G)
will be called a
minimum
k
-chromatic number vertex removal set
. As before, any graph
H
with
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(H)\leq k
is in a
failure state.

Below are the results for chromatic number with vertex removal for paths, cycles, and complete graphs.

Theorem 2.10
.

If
P_{n}
is a path graph on
n
vertices then

\chi_{v}^{k}(P_{n})=\begin{cases}0&\text{if $k\geq 2$},\\
\big\lfloor\frac{n}{2}\big\rfloor&\text{if $k=1$}.\end{cases}

Proof.

Consider the cases when
k\geq 2
and
k=1
.

1.

Case
k\geq 2
:
Note that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(P_{n})\leq 2
. Thus,
P_{n}
is already in a failure state if
k\geq 2
.

2.

Case
k=1
:
When
k=1
, removing every other vertex on the path will produce a graph which is one-colorable and thus in a failure state, so
\chi_{v}^{k}(P_{n})\leq\big\lfloor\frac{n}{2}\big\rfloor
.
Assume there is a
k
-chromatic number vertex removal set
V^{\prime}
with
|V^{\prime}|=\big\lfloor\frac{n}{2}\big\rfloor-1
. Each vertex removal inherently removes at most 2 edges. So
P_{n}-V^{\prime}
would have
n-1-2\left(\big\lfloor\frac{n}{2}\big\rfloor-1\right)\geq 1
edges remaining and therefore has
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(P_{n}-V^{\prime})>1
. This implies that
\chi_{v}^{k}(P_{n})\geq\big\lfloor\frac{n}{2}\big\rfloor.

∎

Theorem 2.11
.

If
C_{n}
is a path graph on
n
vertices then

\chi_{v}^{k}(C_{n})=\begin{cases}0&\text{if $k\geq 3$},\\
\left(n\ (\mathrm{mod}\ 2)\right)+(2-k)\lfloor\frac{n}{2}\rfloor&\text{if $k<3$}.\\
\end{cases}

Proof.

Consider each case:

1.

Case
k\geq 3
:
Note that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})\leq 3
. Thus,
C_{n}
is already in a failure state if
k\geq 3
.

2.

Case
k=2
and
n
is even: Note that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})=2
and therefore is already in a failure state.

3.

Case
k=1
or
k=2
and
n
is odd:
The first vertex we remove will result in
P_{n-1}
for which we can follow Theorem
2.10
.

Note that the second two cases both produce
\chi_{v}^{k}(C_{n})=\left(n\ (\mathrm{mod}\ 2)\right)+(2-k)\lfloor\frac{n}{2}\rfloor.

∎

Theorem 2.12
.

If
K_{n}
is a complete graph on
n
vertices then

\chi_{v}^{k}(K_{n})=\begin{cases}0&\text{ if $k\geq n$},\\
n-k&\text{ if $k<n$}.\end{cases}

Proof.

If
k\geq n
, then
K_{n}
is already in a failure state. Note that for any
v\in V(K_{n})
,
K_{n}-\{v\}=K_{n-1}
. From this, along with the fact that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(K_{i})=i
, it is clear that
\chi_{v}^{k}(K_{n})=n-k
for
k<n
.
∎

2.3
Mixed Removal

In many applications, the vertices and edges are prone to failure. Therefore, Beineke and Harary
[
1
]
introduced the
connectivity function
of a graph that considered the mixed failure case. Since vertex removals have the potential to cause more than one edge removal, mixed connectivity assumes we remove vertices first and then remove edges. Hence, we need to have two parameters, one for the chromatic number which renders our network inoperable and one for the initial number of vertices we are allowed to remove. The goal in mixed removal, given these two parameters, is to find the minimum number of additional edges we must remove to produce a failure state.

As before, we will define edge sets that can be removed to satisfy our failure condition and then find the smallest size of one of these edge sets.

Definition 2.13
.

Given positive integers
k
and
j
and a graph
G=(V,E)
, we say a set of edges
E^{\prime}\subseteq E
is a
k
-chromatic number
j
-mixed edge removal set
if there exists a set of vertices
V^{\prime}\subseteq V
with
|V^{\prime}|=j
so that
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(G-V^{\prime}-E^{\prime})\leq k
.

Definition 2.14
.

For any positive integer
j
, let
\mathcal{M}_{j}
be the set of all
k
-chromatic number
j
-mixed edge removal sets. Define the
k
-chromatic index edge removal parameter
as

\chi_{j}^{k}(G)=\min\{|E^{\prime}|:E^{\prime}\in\mathcal{M}_{j}\}.

Any set
E^{\prime}\in\mathcal{M}_{j}
where
|E^{\prime}|=\chi_{j}^{k}(G)
will be called a
minimum
k
-chromatic number
j
-mixed edge removal set
.

Note that for any graph,
G
, if
j\geq\chi_{v}^{k}(G)
, then
\chi_{j}^{k}(G)=0
since removing
j
vertices can produce a failure state. We now demonstrate this parameter for paths, cycles, and complete graphs.

Theorem 2.15
.

If
P_{n}
is a path graph on
n
vertices then for any
0\leq j\leq\big\lfloor\frac{n}{2}\big\rfloor
we have

\chi_{j}^{k}(P_{n})=\begin{cases}n-1-2j&\text{ if $k=1$},\\
0&\text{ if $k\geq 2$.}\end{cases}

Proof.

Observe that if
k\geq 2
, then
P_{n}
is already in a failure state since
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(P_{n})\leq 2
. If
k=1
, we must remove all edges to reach a failure state. Removing any
j
vertices will remove at most
2j
edges. Therefore, we need to remove at least
n-1-2j
edges. This implies
\chi_{j}^{k}(P_{n})\geq n-1-2j
.

1.

Case 1: If
j<\big\lfloor\frac{n}{2}\big\rfloor
then we can remove every other vertex of degree 2 so that we remove exactly
2j
edges. Thus,
\chi_{j}^{k}(P_{n})=n-1-2j
.

2.

Case 2: If
j=\big\lfloor\frac{n}{2}\big\rfloor
, then removing every other vertex will remove all
n-1
edges. This implies
\chi_{j}^{k}(P_{n})=0=n-1-2j
.

∎

Theorem 2.16
.

If
C_{n}
is a cycle graph on
n\geq 3
vertices then for any

0\leq j\leq\big\lfloor\frac{n}{2}\big\rfloor
we have

\chi_{j}^{k}(C_{n})=\begin{cases}1&\text{if $n$ is odd, $k=2$, and $j=0$},\\
n-2j&\text{if $k=1$},\\
0&\text{otherwise}.\\
\end{cases}

Proof.

1.

Case 1: If
k\geq 3
then
\chi_{j}^{k}(C_{n})=0
since
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})\leq 3
.

2.

Case 2: If
k=2
, the only case we need to consider are odd cycles since
{\mathchoice{\raisebox{0.0pt}{$\displaystyle\chi$}}{\raisebox{0.0pt}{$\textstyle\chi$}}{\raisebox{0.0pt}{$\scriptstyle\chi$}}{\raisebox{0.0pt}{$\scriptscriptstyle\chi$}}}(C_{n})=3
when
n
is odd. If
n
is odd, removing one vertex or edge will put
C_{n}
in a failure state.

3.

Case 3: If
k=1
and
j\geq 1
then,

\chi_{j}^{k}(C_{n})=\chi_{j-1}^{k}(P_{n-1}),

and the result holds from Theorem
2.15
.

4.

Case 4: If
k=1
and
j=0
, then
\chi_{j}^{k}(C_{n})=\chi_{e}^{k}(C_{n})=|E|=n
.

∎

Theorem 2.17
.

If
K_{n}
is a complete graph on
n
vertices then for any

0\leq j\leq n-k
we have

\chi_{j}^{k}(K_{n})=\begin{cases}0&\text{ if $k\geq n$},\\
|E(K_{n-j})|-|T(n-j,k)|&\text{ if $k<n$}.\end{cases}

Proof.

If
k\geq n
, then
\chi_{j}^{k}(K_{n})=0
since
K_{n}
is already in a failure state.
If
k<n
, the removal of any
j
vertices will result in
K_{n-j}
. Hence
\chi_{j}^{k}(K_{n})=\chi_{e}^{k}(K_{n-j})
and the result follows by Theorem
2.7

∎

3
Chromatic Index

We will now turn our attention to chromatic index, which involves coloring the edges rather than the vertices. As before, Section
3.1
will consider edge removal, Section
3.2
will consider vertex removal, and Section
3.3
will consider mixed removal.

3.1
Edge Removal

As before, we will now define
k
-chromatic index edge removal sets and the minimum size of these sets will be our parameter of interest. This parameter seems to fit well with edge removal since we are coloring the edges.

Definition 3.1
.

Given a positive integer
k
and a graph
G=(V,E)
, we say a set of edges
E^{\prime}\subseteq E
is a
k
-chromatic index edge removal set
if
\lambda(G-E^{\prime})\leq k
.

Definition 3.2
.

Let
\mathcal{E}
be the set of all
k
-chromatic index edge removal sets. Define the
k
-chromatic edge removal parameter
as

\lambda_{e}^{k}(G)=\min\{|E^{\prime}|:E^{\prime}\in\mathcal{E}\}.

Any set
E^{\prime\prime}\in\mathcal{E}
where
|E^{\prime\prime}|=\lambda_{e}^{k}(G)
will be called a
minimum
k
-chromatic index edge removal set
.

Given a proper coloring of the graph, we can easily see that an upper bound for our parameter would be the number of edges that are colored with a value larger than
k
. This would produce a failure state. However, since association of colors with numerical values is somewhat arbitrary, this does not always give the fewest number of edges that might be removed. This will be explored briefly in Chapter
4
.

We now demonstrate how the
k
-chromatic index edge removal parameter works on paths, cycles, and complete graphs.

Theorem 3.3
.

If
P_{n}
is a path graph on
n
vertices then

\lambda_{e}^{k}(P_{n})=\begin{cases}0&\text{if}\ k>1,\\
\big\lfloor\frac{n-1}{2}\big\rfloor&\text{if}\ k=1.\\
\end{cases}

Proof.

Since
\lambda(P_{n})\leq 2
for
n\in\mathbb{N}
, if
k>1
, then
P_{n}
is already in a failure state.
However, if
k=1
, then if we remove every other edge along the path starting with an edge between two vertices of degree two, we can see that
\lambda_{e}^{k}(P_{n})\leq\big\lfloor\frac{n-1}{2}\big\rfloor
. Notice that if
E^{\prime}
was a minimum
1
-chromatic index edge removal set, then
P_{n}-E^{\prime}
can not have a vertex of degree 2. Notice that
P_{n}
has
n-2
vertices of degree 2. Therefore, we need to remove at least
\big\lceil\frac{n-2}{2}\big\rceil
edges. But,
\big\lceil\frac{n-2}{2}\big\rceil\geq\big\lfloor\frac{n-1}{2}\big\rfloor
which completes the proof.
∎

Theorem 3.4
.

If
C_{n}
is a cycle graph on
n
vertices then

\lambda_{e}^{k}(C_{n})=\begin{cases}0&\text{if}\ k>2,\\
n\ (\mathrm{mod}\ 2)&\text{if}\ k=2,\\
1+\big\lfloor\frac{n-1}{2}\big\rfloor&\text{if}\ k=1.\\
\end{cases}

Proof.

Since
\lambda(C_{n})\leq 2
for
n
even and
\lambda(C_{n})\leq 3
for
n
odd, we examine the cases for differing
n
’s. If
k>2
, then
C_{n}
is already in a failure state.

1.

Case
k>2
:
Note that for all positive integers
n
,
\lambda(C_{n})\leq 3
and so when
k>2
(or
k\geq 3
)
C_{n}
is already in a failure state.

2.

Case
k=2
:
If
n
is an even integer, it is known that
\lambda(C_{n})=2
and thus
\lambda_{e}^{k}(C_{n})=0
. If
n
is an odd integer, then
\lambda(C_{n})=3
and thus at least 1 edge removal is necessary. No additional edges need to be removed since
C_{n}-\{e\}=P_{n}
which is already in a failure state by
3.3
.

3.

Case
k=1
:
Because
P_{n}=C_{n}-\{e\}
for any edge
e
we have
\lambda_{e}^{k}(C_{n})=1+\lambda_{e}^{k}(P_{n})
.

∎

Theorem 3.5
.

For any positive integer
k\leq n
we have

\lambda_{e}^{k}(K_{n})=\begin{cases}0&\text{if}\ k\geq n,\\
\binom{n}{2}-\left\lfloor{\frac{n}{2}}\right\rfloor k&\text{if}\ k<n.\\
\end{cases}

Proof.

Note that if
E^{\prime}\subseteq E(K_{n})
is a minimum
k
-chromatic index edge removal set so that
|E^{\prime}|\leq\binom{n}{2}-\lfloor\frac{n}{2}\rfloor k
, then
|E(K_{n}-E^{\prime})|>\lfloor\frac{n}{2}\rfloor k
. This would imply that a
k
-edge coloring of
K_{n}-E^{\prime}
would have at least one color used more than
\lfloor\frac{n}{2}\rfloor
times and therefore is not a proper edge coloring. This implies that
\lambda_{e}^{k}(K_{n})\geq\binom{n}{2}-\lfloor\frac{n}{2}\rfloor k.

Let
n^{\prime}=\left\lfloor{\frac{n+1}{2}}\right\rfloor 2-1
. So
n^{\prime}=n
if
n
is odd and
n^{\prime}=n-1
if
n
is even. In this way, we know that
\lambda(K_{n})=n^{\prime}
and we will label these colors
\{a_{1},a_{2},\ldots,a_{n^{\prime}}\}
. Notice that any color is used exactly
\left\lfloor{\frac{n}{2}}\right\rfloor
times.
Consider the spanning subgraph
H
of
K_{n}
which includes all the edges whose colors are contained in the set
\{a_{1},a_{2},\ldots,a_{k}\}
. Thus,
H
is
k
-edge colorable and, therefore,
E(K_{n})-E(H)
is a
k
-chromatic index edge removal set. Since
|E(H)|=\left\lfloor{\frac{n}{2}}\right\rfloor k
and
H
is a subgraph of
K_{n}
we have

\displaystyle\lambda_{e}^{k}(K_{n})

\displaystyle\leq|E(K_{n})-E(H)|

\displaystyle=\binom{n}{2}-\left\lfloor{\frac{n}{2}}\right\rfloor k.

∎

3.2
Vertex Removal

Now we consider the chromatic index with vertex removal.

Definition 3.6
.

Given a positive integer
k
and a graph
G=(V,E)
, we say a set of vertices
V^{\prime}\subseteq V
is a
k
-chromatic index vertex removal set
if
\lambda(G-V^{\prime})\leq k
.

Definition 3.7
.

Let
\mathcal{V}
be the set of all
k
-chromatic index vertex removal sets. Define the
k
-chromatic index vertex removal parameter
as

\lambda_{v}^{k}(G)=\min\{|V^{\prime}|:V^{\prime}\in\mathcal{V}\}.

Any set
V^{\prime\prime}\in\mathcal{V}
where
|V^{\prime\prime}|=\lambda_{v}^{k}(G)
will be called a
minimum
k
-chromatic index vertex removal set
.

We now demonstrate how this works on paths, cycles, and complete graphs.

Theorem 3.8
.

If
P_{n}
is a path graph on
n
vertices then

\lambda_{v}^{k}(P_{n})=\begin{cases}0&\text{if}\ k>1,\\
\lfloor\frac{n}{3}\rfloor&\text{if}\ k=1.\\
\end{cases}

Proof.

It is easy to see that
P_{3}
,
P_{4}
, and
P_{5}
all have a minimum
k
-chromatic index edge vertex removal set of size 1.
Consider a path
P_{n}
,
n\geq 6
, where
V=\{v_{1},\ldots,v_{n}\}
. Note that
P_{n}-\{v_{n-2}\}=P_{n-3}+P_{2}.
So it is clear that
\lambda_{v}^{k}(P_{n})\leq\lambda_{v}^{k}(P_{n-3})+1=\lfloor\frac{n-3}{3}\rfloor+1=\lfloor\frac{n}{3}\rfloor.

Notice that any
k
-chromatic index vertex removal set,
V^{\prime}
, for
P_{n}
, must contain at least one vertex from the set
\{v_{n-2},v_{n-1},v_{n}\}
; call this vertex
v
. Then
P_{n}-\{v\}
contains a path of length at least
n-3
and therefore we must remove at least
\lfloor\frac{n-3}{3}\rfloor
additional vertices. So
\lambda_{v}^{k}(P_{n})\geq 1+\lfloor\frac{n-3}{3}\rfloor=\lfloor\frac{n}{3}\rfloor

∎

Theorem 3.9
.

Given any positive integer
n\geq 3
we have

\lambda_{v}^{k}(C_{n})=\begin{cases}0&\text{ if }k\geq 3,\\
n\ (\mathrm{mod}\ 2)&\text{ if $k=2$},\\
1+\lambda_{v}^{k}(P_{n-1})&\text{ if }k=1.\end{cases}

Proof.

Following the proof for Theorem
3.3
, we will only consider the following cases:

1.

Case
k=2
:
If
k=2
and
n
is even, an even cycle will have a chromatic index of 2, so no vertices must be removed. If
k=2
and
n
is odd, 1 vertex must be removed which will result in
P_{n-1}
and paths have a chromatic index of 2.

2.

Case
k=1
:
Because
P_{n-1}=C_{n}-\{v\}
for any vertex
v
we have

\lambda_{v}^{k}(C_{n})=1+\lambda_{v}^{k}(P_{n-1})=1+\lfloor\frac{n-1}{3}\rfloor.

∎

Theorem 3.10
.

For any positive integer
k
,

\lambda_{v}^{k}(K_{n})=\begin{cases}0&\text{if $k\geq n$},\\
n-k-\big(k\ (\mathrm{mod}\ 2)\big)&\text{if $k<n$}.\end{cases}

Proof.

Note that
\lambda(K_{n})=n-1
is
n
is even and
\lambda(K_{n})=n
if
n
is odd. Consider first when
k\geq n
. Then, we know
\lambda(K_{n})=n
or
n-1
, so either way the graph is already in a failure state and
\lambda_{v}^{k}(K_{n})=0
.
Now consider when
k<n
and
k
is odd. We also note that
n>2
since
\lambda(K_{2})=1
, which is already a failure state. When
k
is odd, we know that a
K_{k}
will have a chromatic index of
k
. However, we also know that
K_{k+1}
will have a chromatic number of
k
since
k+1
is even. Because we want to find the minimum amount of vertices necessary to remove to put the graph in a failure state, we will want to remove all except
k+1
. So, we have
\lambda_{v}^{k}(K_{n})=n-(k+1)
when
k
is odd.
We now consider when
k<n
and
k
is even. Notice that it is impossible to obtain a graph with a chromatic index of exactly
k
, so instead we want to obtain a graph with a chromatic index of
k-1
, and do so as efficiently as possible. For even
k
values,
\lambda(K_{k+1})=\lambda(K_{k})+2
. So, since
\lambda(K_{k})=k-1
, we can see that the quickest way to attain a chromatic index of less than
k
is by removing all but
k
vertices. That is,
\lambda_{v}^{k}(K_{n})=n-k
when
k
is even.

∎

3.3
Mixed Removal

When we consider mixed removal, we will always be given two positive integer parameters,
j
and
k
and proceed by removing
j
vertices first and then removing edges until we reach a failure state, indicated by a chromatic index less than or equal to
k
. The smallest edge set, taken over all sets of
j
vertices is the minimum
k
-chromatic index
j
-mixed edge removal.

Definition 3.11
.

Given positive integers
k
and
j
and a graph
G=(V,E)
, we say a set of edges
E^{\prime}\subset E
is a
k
-chromatic index
j
-mixed edge removal set
if there exists a set of vertices
V^{\prime}\subset V
with
|V^{\prime}|=j
so that
\lambda(G-V^{\prime}-E^{\prime})\leq k
.

Definition 3.12
.

For any positive integer
j
, let
\mathcal{N}_{j}
be the set of all
k
-chromatic index
j
-mixed edge removal sets. Define the
k
-chromatic index
j
-mixed edge removal parameter
as

\lambda_{j}^{k}(G)=\min\{|E^{\prime}|:E^{\prime}\in\mathcal{N}_{j}\}.

Any set
E^{\prime}\in\mathcal{N}_{j}
where
|E^{\prime}|=\chi_{j}^{k}(G)
will be called a
minimum
k
-chromatic index
j
-mixed edge removal set
.

As before, we demonstrate this parameter on paths, cycles, and complete graphs.

Theorem 3.13
.

If
P_{n}
is a path graph on
n
vertices then for any
0\leq j\leq\big\lfloor\frac{n}{2}\big\rfloor
we have

\lambda_{j}^{k}(P_{n})=\begin{cases}\big\lfloor\frac{n-3j-1}{2}\big\rfloor&\text{ if $k=1$},\\
0&\text{ if $k\geq 2$ or $n\leq 3j+2$.}\end{cases}

Proof.

Observe that if
k\geq 2
, then
P_{n}
is already in a failure state since
\lambda(P_{n})\leq 2
.

For
k=1
, note that if
n\leq 3j+2
, then
\lambda_{j}^{k}(P_{n})=0
since
\lambda_{v}^{k}(P_{n})=\lfloor\frac{n}{3}\rfloor\leq\lfloor\frac{3j+2}{3}\rfloor=j
. Assume
n\geq 3j+3
. The failure state must consist of isolated copies of
P_{2}
. Let
P_{n}
be a path graph defined in the standard way so that
V(P_{n})=\{v_{1},v_{2},\ldots v_{n}\}
with
v_{i}
adjacent to
v_{i+1}
. Consider
V^{\prime}=\{v_{3},v_{6},\ldots v_{3j}\}
. Then
P_{n}-V^{\prime}
consists of isolated copies of
P_{2}
and a single copy of
P_{n-3j}.
Since
\lambda_{e}^{k}(P_{n-3j})=\big\lfloor\frac{n-3j-1}{2}\big\rfloor
, we see
\lambda_{j}^{k}(P_{n})\leq\big\lfloor\frac{n-3j-1}{2}\big\rfloor.

For a path graph, the total degree is
2(n-1)
. If we remove
j
vertices and
m
edges from
P_{n}
, then the total degree must be less than or equal to
2(n-1)-4j-2m
which implies the average degree must be less than or equal to
\frac{2(n-1)-4j-2m}{n-j}.
If
H\subset P_{n}
is in a failure state, then the average degree in
H
must be at most 1. Thus,
\frac{2(n-1)-4j-2m}{n-j}\leq 1
, which is equivalent to

\frac{n-3j-1}{2}\leq m+\frac{1}{2}
. Taking floors of both sides and noting that
m
is already an integer we have
\big\lfloor\frac{n-3j-1}{2}\big\rfloor\leq m
. So
\lambda_{j}^{k}(P_{n})\geq\big\lfloor\frac{n-3j-1}{2}\big\rfloor
which completes the proof.
∎

Theorem 3.14
.

If
C_{n}
is a cycle graph on
n
vertices then for any
0\leq j\leq\big\lfloor\frac{n}{2}\big\rfloor
we have

\lambda_{j}^{k}(C_{n})=\begin{cases}\lambda_{e}^{k}(C_{n})&\text{ if $j=0$},\\
0&\text{ if $k\geq 3$},\\
0&\text{ if $k=2$ and $j\geq 1$},\\
\lambda_{j-1}^{k}(P_{n-1})&\text{ if $k=1$ and $j\geq 1$}.\\
\end{cases}

Proof.

Notice that if
j=0
then we just need to consider
\lambda_{e}^{k}(C_{n})
which is Theorem
3.4
.
If
j\geq 1
and
k=2
, then we are either in a failure state (
n
even) or by removing a vertex we will be in a failure state (
n
odd).
If
k=1
and
j\geq 1
, the first vertex removal will result in
P_{n-1}
so we can consider mixed removal on
P_{n-1}
which is Theorem
3.13
.
∎

Theorem 3.15
.

If
K_{n}
is a complete graph on
n
vertices then for any
0\leq j\leq\big\lfloor\frac{n}{2}\big\rfloor
we have

\lambda_{j}^{k}(K_{n})=\begin{cases}0&\text{ if $k\geq n-j$},\\
\binom{n-j}{2}-\lfloor\frac{n-j}{2}\rfloor k&\text{ if $k<n-j$}.\end{cases}

Proof.

If
k\geq n-j
consider two additional cases of
n-j\leq k<n
and
n\leq k
. If it is the case that
n\leq k
then it it follows,

\lambda(K_{n})\leq n\leq k.

If it is the case that
n-j\leq k<n
, the removal of
j
vertices will result in
K_{n-j}
at which,

\lambda(K_{n-j})\leq n-j\leq k.

When
k<n-j
invoke the appropriate case of Theorem
3.5

∎

Conclusion

Note that if we are trying to use at most
k
colors, we could put our network into a failure state by removing any vertex (edge) which has a label greater than
k
. However, this is not always the optimal solution and the numerical values of for the colors are arbitrary. See, for example, consider the graph
G
in Figure
1
whose vertices are colored using the numbers
\{1,2,3\}
. Notice that chromatic number of the graph is three and each of the colors must be used at least three times to properly color the graph. However,

by removing the two vertices labeled

Graph

with

.

So far, our attention has been limited to demonstrating these network vulnerability parameters for paths, cycles, and complete graphs. Unsurprisingly finding a solution for paths naturally leads to a solution for cycles. Complete graphs require finding the particular graph construction given a particular order,
n
, and size,
m
, without going over a specific coloring. In this way, it is more so a question about extremal graph theory.

These graph classes are easy enough to analyze since their structures are uniquely determined by some parameter
n
(mainly number of vertices). There are other such classes such as wheels, stars, and friendship graphs, whose construction is explicitly determined by some parameters which could also be studied. However, consideration could also be given to study the chromatic network vulnerability parameters outlined here on other graph classes whose construction is not as explicit. For example, trees,
r
-regular graphs, and planar graphs should be considered. There are also other coloring parameters that may be more intuitively associated with reliability that can not be studied. For example, complete chromatic number with mixed removal is a natural extension.

Another interesting extension would be to consider the vulnerability parameter for other classes of graphs, specifically
G(n,m)
which is the set of graph with order
n
and size
m
. Finding the minimum and maximum value of our parameters over the set
G(n,m)
will tell us the least and most reliable networks we can construct for a given size and order. Using data generated from some python script
here
, we have been able to find certain minimums and explore certain maximums. In some way the question about maximum is more difficult since it requires finding the least optimum removal set over a set of already optimized removals.
