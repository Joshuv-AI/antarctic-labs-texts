Parameterizations of Immiscible Two-Phase Flow in Porous Media
Håkon Pedersen and Alex Hansen

Abstract
A fundamental variable characterizing immiscible two-phase flow in porous media is the wetting saturation, which is the ratio between the pore volume filled with wetting fluid and the total pore volume. More generally, this variable comes from a specific choice of coordinates on some underlying space, the domain of variables that can be used to express the volumetric flow rate. The underlying mathematical structure allows for the introduction of other variables containing the same information, but which are more convenient from a theoretical point of view. We introduce along these lines polar coordinates on this underlying space, where the angle plays a role similar to the wetting saturation. We derive relations between these new variables based on the Euler homogeneity theorem. We formulate these relations in a coordinate-free fashion using differential forms. Lastly, we discuss and interpret the co-moving velocity in terms of this coordinate-free representation.

V
Coordinate-Free Representation

Since the difference between the thermodynamic- and seepage velocities in the
previous section was shown to sit in the
tangent vector components
, we can
benefit from a examining the problem from a position where these components are
easier to work with. In this section, we therefore introduce
differential
forms
and
exterior algebra

f63
;
mtw17
to make this treatment
more economic. In addition, this makes it easier to formulate the equations met
so far in a way that does not depend on the coordinate system used.

Equation (
44
),
Q=\hat{v}_{r}A_{r}
, may be differentiated to give

dQ=\hat{v}_{r}dA_{r}+d\hat{v}_{r}A_{r}=\hat{v}_{r}dA_{r}+\hat{v}_{r}^{\prime}A_{r}d\phi\;,

(70)

where
\hat{v}_{r}^{\prime}=d\hat{v}_{r}/d\phi
. Here,
dQ
,
dA_{r}
and
d\phi
are
one-forms. We furthermore have that

\displaystyle dQ

\displaystyle=

\displaystyle\left(\frac{\partial Q}{\partial A_{r}}\right)_{\phi}dA_{r}+\left(\frac{\partial Q}{\partial\phi}\right)_{A_{r}}d\phi

(71)

\displaystyle=

\displaystyle\hat{v}_{r}dA_{r}+\hat{v}_{\phi}A_{r}d\phi\;.

Comparing equations (
70
) and (
71
) gives

\hat{v}_{\phi}=\hat{v}_{r}^{\prime}\;.

(72)

We do the same using the coordinate system
(A_{w},A_{n})
. From equation
(
50
), we find

\displaystyle dQ

\displaystyle=

\displaystyle\hat{v}_{w}dA_{w}+\hat{v}_{n}dA_{n}+A_{w}d\hat{v}_{w}+A_{n}d\hat{v}_{n}

(73)

\displaystyle=

\displaystyle\hat{v}_{w}dA_{w}+\hat{v}_{n}dA_{n}\;.

This implies the relation

A_{w}d\hat{v}_{w}+A_{n}d\hat{v}_{n}=0\;.

(74)

This equation corresponds to the
Gibbs-Duhem
equation in thermodynamics,
which is a statement of the dependency amongst the intensive variables.

We express
\hat{v}_{w}
and
\hat{v}_{n}
in terms of
\hat{v}_{r}
and
\hat{v}_{\phi}
by
inverting equations (
61
) and (
62
) to find

\displaystyle\hat{v}_{w}\ =\ \hat{v}_{r}\cos\phi-\hat{v}_{\phi}\sin\phi\;,

(75)

\displaystyle\hat{v}_{n}\ =\ \hat{v}_{r}\sin\phi+\hat{v}_{\phi}\cos\phi\;.

(76)

By applying the exterior derivative, we get the relations

\displaystyle d\hat{v}_{w}\ =\ \cos\phi\ d\hat{v}_{r}-\sin\phi\ d\hat{v}_{\phi}-\hat{v}_{n}d\phi\;,

(77)

\displaystyle d\hat{v}_{n}\ =\ \sin\phi\ d\hat{v}_{r}+\cos\phi\ d\hat{v}_{\phi}+\hat{v}_{w}d\phi\;.

(78)

Combining equations (
75
) to (
78
) with the Gibbs-Duhem equation
(
74
) gives

\frac{d\hat{v}_{r}}{d\phi}=\hat{v}_{\phi}\;,

(79)

which is identical to equation (
72
). Hence, this is the
Gibbs-Duhem equation in polar coordinates.

The thermodynamic velocity, equation (
59
), is therefore given by

\hat{\vec{v}}=\hat{v}_{r}\vec{e}_{r}+\hat{v}_{r}^{\prime}\vec{e}_{\phi}\;.

(80)

We now have one of the main results of Hansen et al.
hsbkgv18
in a very compact form,

\vec{v}=\hat{v}_{r}\vec{e}_{r}+(\hat{v}_{r}^{\prime}+\hat{v}_{m})\vec{e}_{\phi}\;.

(81)

We note that since
\hat{v}_{r}
only depends on
\phi
, the same must be true for
\hat{v}_{m}
. Hence,

\hat{v}_{m}=\hat{v}_{m}(\phi)
. We here see that the relation between the thermodynamic-
and seepage velocities are not captured in the extensive structure tied to the
radial coordinate, but instead in the intensive quantities which only has a
dependency on
\phi
.

We now differentiate equation (
56
),
Q={\vec{v}}\cdot{\vec{A}}
written in the saturation coordinate
system, to find

dQ=v\ dA_{p}+\frac{dv}{dS_{w}}A_{p}dS_{w}\;.

(82)

We note that

dA_{p}=dA_{w}+dA_{n}\;,

(83)

from differentiating equation (

\displaystyle dS_{w}

\displaystyle=

\displaystyle\left(\frac{\partial S_{w}}{\partial A_{w}}\right)_{A_{n}}dA_{w}+\left(\frac{\partial S_{w}}{\partial A_{n}}\right)_{A_{w}}dA_{n}

(84)

\displaystyle=

\displaystyle\frac{1}{A_{p}^{2}}\left(A_{n}dA_{w}-A_{w}dA_{n}\right)\;,

using equation (
4
). We combine equations (
82
) to
(
84

(85)

By using equation (
13

15
) and
(
16

transformations (
19
) and (

), we may write

\displaystyle dQ

\displaystyle=

\displaystyle\hat{v}_{w}dA_{w}+\hat{v}_{n}dA_{n}=\left(v_{w}-(1-S_{w})v_{m}\right)dA_{w}

(86)

\displaystyle+

\displaystyle\left(v_{n}+S_{w}v_{m}\right)dA_{n}\;.

Equating (
85
) and (
86
) gives equations (
24
) and (
25
).

Let us now rewrite the differential
dQ
as follows,

\displaystyle dQ

\displaystyle=

\displaystyle d[A_{p}v]=d[A_{p}(S_{w}\hat{v}_{w}+(1-S_{w})\hat{v}_{n})]

\displaystyle=

\displaystyle A_{p}(\hat{v}_{w}-\hat{v}_{n})dS_{w}+v\ dA_{p}\;,

where we have used equation (

). We now combine this equation with equation (

\frac{dv}{dS_{w}}=\hat{v}_{w}-\hat{v}_{n}\;.

(88)

By using equations (

We differentiate
Q
a second time, which is zero according to the Poincaré lemma

mtw17

We see that this is indeed so by using equation (

\displaystyle d^{2}Q

\displaystyle=

\displaystyle d(\hat{v}_{r}dA_{r}+\hat{v}_{r}^{\prime}A_{r}d\phi)

\displaystyle=

\displaystyle\hat{v}_{r}^{\prime}\left(d\phi\wedge dA_{r}\right)+\hat{v}_{r}^{\prime}\left(dA_{r}\wedge d\phi\right)

\displaystyle(\hat{v}_{r}^{\prime}-\hat{v}_{r}^{\prime})d\phi\wedge dA_{r}=0\;,

where the wedge

The same equation expressed in the coordinate system
(A_{w},A_{n})

\displaystyle d^{2}Q

\displaystyle=

\displaystyle d(\hat{v}_{w}dA_{w}+\hat{v}_{n}dA_{n})

\displaystyle\left[\left(\frac{\partial\hat{v}_{n}}{\partial A_{w}}\right)_{A_{n}}-\left(\frac{\partial\hat{v}_{w}}{\partial A_{n}}\right)_{A_{n}}\right]dA_{w}\wedge dA_{n}

\displaystyle=

\displaystyle 0\;.

We rewrite the coefficient in terms of the saturation coordinate system,

\displaystyle\left(\frac{\partial\hat{v}_{n}}{\partial A_{w}}\right)_{A_{n}}-\left(\frac{\partial\hat{v}_{w}}{\partial A_{n}}\right)_{A_{n}}

\displaystyle\frac{d\hat{v}_{n}}{dS_{w}}\left(\frac{\partial S_{w}}{\partial A_{w}}\right)_{A_{n}}-\frac{d\hat{v}_{w}}{dS_{w}}\left(\frac{\partial S_{w}}{\partial A_{n}}\right)_{A_{w}}

VI
The co-moving velocity in coordinate-free representation

The co-moving velocity appears in several equations above.
Common to all of them is that they all are written out in terms of a given coordinate system.
We may write the representation of the co-moving velocity in the saturation coordinate system, equation (
28
), as

A_{p}v_{m}=\vec{A}\cdot\frac{d\vec{v}}{dS_{w}}\;.

(92)

We may write equation (
65
) in polar coordinates as

A_{r}\hat{v}_{m}=-\vec{A}\cdot\frac{d\vec{v}}{d\phi}\;.

(93)

Expressed in terms of the seepage velocities, we have that

dQ\ =\ v_{w}dA_{w}+v_{n}dA_{n}+A_{w}dv_{w}+A_{n}dv_{n}\;.

(94)

In order to obtain an expression for the co-moving velocity which is independent of
coordinate system, we construct

\displaystyle A_{w}dv_{w}+A_{n}dv_{n}=v_{m}\ \frac{A_{n}dA_{w}-A_{w}dA_{n}}{A_{w}+A_{n}}

(95)

\displaystyle=

\displaystyle v_{m}A_{p}dS_{w}=-\hat{v}_{m}A_{r}d\phi\;,

where the second line only reflects equations (
92
) and (
93
).

We write
dQ
as

\displaystyle dQ=d[\vec{A}\cdot\hat{\vec{v}}]\ =

\displaystyle\ \hat{v}^{i}dA_{i}\;,

(96)

using equation (
74
). Here, Einstein summation convention has been
applied, with the index
i
running over

\left\{w,n\right\}
in the basis
\left(A_{w},A_{n}\right)
.
In terms of the seepage velocities, this becomes

\displaystyle dQ=d[\vec{A}\cdot\vec{v}]=v^{i}dA_{i}+A^{i}dv_{i}\;.

(97)

Combining equation
(
96
), (
97
) and (
66
) gives us

\hat{v}_{m}^{i}dA_{i}+A^{i}dv_{i}=0

(98)

where
\hat{v}_{m}^{i}
denotes the components of

\hat{\vec{v}}_{m}
. This holds in any coordinate system, since it is just
obtained by differentiating a function, namely
\vec{A}\cdot\vec{v}
. We have
therefore obtained an expression for the co-moving velocity which is independent
of the chosen coordinate system.

We can introduce
vector-valued differential forms

mtw17
to make
a connection between the interpretation in terms of (tangent) vectors used up
until now and the language of differential forms.
Let
\left\{\vec{e}_{i}\right\}
be an arbitrary basis for vectors on the area space as

We now take
\vec{A}
as an example. We write

(99)

where
A
is now regarded as a vector-valued differential form (thus seeing
\vec{e}_{i}
as components
written out in the
\beta^{i}
basis, i.e., a reversal of view point),
the
\beta_{i}
are
0
-forms, just functions, and the index
i

runs over the coordinate indices. We can still treat
A
as a vector, but the
difference in viewpoints is apparent when we apply the exterior
derivative

to

mtw17
.
Strictly speaking, the exterior derivative
d
should be replaced by the

exterior covariant derivative
in this setting, a generalization of
d

which is defined on both tangent vectors and forms (there is currently no term
in equation (
100
) that reflect the changes in
the basis

\vec{e}_{i}
). The terms

are then possible to interpret in terms of

. However, this is outside the scope of the current

If we write out equation (

\left(A_{w},A_{n}\right)

\displaystyle\ -\sin\phi\ \vec{e}_{w}+\cos\phi\ \vec{e}_{n}\;,

which are equivalent to the corresponding basis vectors in equation
(

) and (
41
), but interpreteted as

-forms. We then compute

\displaystyle d\omega_{r}\ =

\displaystyle\ \vec{e}_{\phi}d\phi\;,

(104)

\displaystyle d\omega_{\phi}\ =

\displaystyle\ -\omega_{r}d\phi\;,

(105)

so that

\displaystyle dA=d(A_{r}\omega_{r})\ =

\displaystyle\ dA_{r}\omega_{r}+A_{r}d\omega_{r}

\displaystyle\ dA_{r}\vec{e}_{r}+A_{r}\vec{e}_{\phi}d\phi\;,

where we in the second equality has used that

VII
Conclusion and discussion

The aim of this work has been to formulate the immiscible two-phase flow in porous media problem
as a
geometrical problem
in area space. We did this by

•

defining the two pore area variables
A_{w}
and
A_{n}
and consider the space they span,

•

endow this space with different coordinate systems,
(A_{w},A_{n})
,
(A_{p},S_{w})
and

(A_{r},\phi)
, pointing out that expressions that using the polar coordinate system simplifies
the discussion considerably,

•

recognizing the meaning of the volumetric flow rate being a
degree-
1
homogeneous function when expressing it in polar coordinates,
and deriving a number of properties related to the different velocities
in the problem; the seepage velocities, the thermodynamic velocities and
the co-moving velocity,

•

using differential forms to derive relations between the different velocities, and lastly,

•

formulate an expression for the co-moving velocity which is independent of the coordinates
on the underlying space.

We remind the reader of the following equations.
The difference between the thermodynamic and seepage velocities may be expressed by combining equations (
96
)
and (
97
),

dQ=\hat{v}^{i}dA_{i}=A^{i}dv_{i}+v^{i}dA_{i}\;.

(112)

The co-moving velocity is given by equation (
66
),

\vec{v}=\hat{\vec{v}}+\hat{\vec{v}}_{m}\;.

These equations lead us to the three central equations summarizing the central results of this paper.
They are equation (
58
),

\vec{v}\cdot\vec{A}=Q\;,

equation (
69
),

\hat{\vec{v}}_{m}\cdot\vec{A}=0\;,

and equation (
98
),

\hat{v}_{m}^{i}dA_{i}+A^{i}dv_{i}=0

It is clear from this discussion that the co-moving velocity,
v_{m}
, which together with the average seepage velocity

v
, determines
v_{w}
and
v_{n}
through the transformations (
24
) and (
25
), cannot be found by any
measurement of the volumetric flow rate
Q
or any expression gotten from it and it alone such as
dQ
. The
fundamental question, which remains open is the following: is it possible to measure the co-moving velocity
v_{m}

without
explicitly measuring
v_{w}
and
