2.
Preliminary

First of all we must introduce the classes of harmonic convex set as follow:

Definition 2.1
.

[
18
]

Let
X
be a linear space. A nonempty subset
D
of
X
is said harmonic convex, if for all
x,y\in D
and
t\in[0,1]
, we have:

\frac{xy}{tx+(1-t)y}\in D.

In
[
6
]
, İ. İscan introduced a new variation of convexity called harmonically convex function and defines it as a real function
f:D\rightarrow\mathbb{R}
that for all
x,y\in D
and
t\in[0,1]
, satisfies the following expression:

(2.1)

f\left(\frac{xy}{tx+(1-t)y}\right)\leq tf(y)+(1-t)f(x).

If in (
2.1
) the sense of inequality is changed, it is obtained that
f
is harmonically concave.

In the same way, M. A. Noor
et al.
(see
[
18
]
) extends this definition to strongly convexity.

Definition 2.2
.

[
18
]

A function
f:D\subset\mathbb{R}\backslash\{0\}\rightarrow\mathbb{R}
is said to be strongly harmonic convex function with modulus
c>0
, if

(2.2)

f\left(\frac{xy}{tx+(1-t)y}\right)\leq tf(y)+(1-t)f(x)-ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}.

The function
f
is said to be strongly harmonic mid-convex function with modulus
c>0
, if (
2.2
) is assumed only for
t=\frac{1}{2}
, that is:

f\left(\frac{2xy}{x+y}\right)\leq\frac{f(x)+f(y)}{2}-\frac{c}{4}\left\|\frac{x-y}{xy}\right\|^{2}.

Remark 2.3
.

In the following
B
denote the closed unit ball of
Y
and
c>0
a scalar. Also, we consider
X,Y
linear spaces and we denote
c(Y),cc(Y),n(Y)
as the convex, compact convex and not empty subsets of
Y
, respectively.

In this sense, G. Santana
et. al.
in
[
19
]
the definition of strongly harmonic convex function and set-valued function are combined, then introduced the strongly harmonic convex set-valued function with modulus
c>0
as follows:

Definition 2.4
.

[
19
]

Let
X,Y
be two linear spaces and
D\subset X
a harmonically convex set. A set-valued function
F:D\rightarrow n(Y)
is called
strongly harmonic convex with modulus
c>0
if:

(2.3)

tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}B\subset F\left(\frac{xy}{tx+(1-t)y}\right).

for all
x,y\in D
,
t\in[0,1]
and
B
a unitary ball of
Y
.

If we consider
c=0
in (
2.3
),
F
is a
harmonic convex set-valued function
and considering
t=1/2
in (
2.3
), them
F
is a
strongly harmonic midconvex set-valued function with modulus
c>0
, if:

\frac{F(y)+F(x)}{2}+\frac{c}{4}\left\|\frac{x-y}{xy}\right\|^{2}B\subset F\left(\frac{2xy}{x+y}\right).

Definition 2.5
.

[
8
]

A function
f:[a,b]\subset\mathbb{R}\backslash\{0\}\rightarrow\mathbb{R}
is said to be harmonic symmetric with respect to
\frac{2ab}{a+b}
, if

f(x)=f\left(\frac{abx}{(a+b)x-ab}\right),

for all
x\in[a,b].

Given this definition for functions, we introduce the analog version for set-valued functions in the following definition.

Definition 2.6
.

A set-valued function
F:D\subset X\backslash\{0\}\rightarrow n(Y)
is said to be harmonic symmetric with respect to
\frac{2ab}{a+b}
, if

F(x)=F\left(\frac{abx}{(a+b)x-ab}\right),

holds for all
x\in D.

We introduce the following result which give some relationship between strongly harmonic convex set-valued function with modulus
c>0
and harmonic convex set-valued function.

Lemma 2.7
.

i)

A set-valued function
F:D\subset X\rightarrow n(Y)
is strongly harmonic convex with modulus
c>0
, if and only if, the set-valued function
G(x)=F(x)+c\left\|\frac{1}{x}\right\|^{2}B
is harmonic convex.

ii)

A set-valued function
F:D\subset X\rightarrow n(Y)
is strongly harmonic mid-convex modulus
c>0
, if and only if, the set-valued function
G(x)=F(x)+c\left\|\frac{1}{x}\right\|^{2}B
is harmonic mid-convex.

Proof.

i):

First, let’s prove the sufficient condition. Since
F:D\subset X\rightarrow n(Y)
is a strongly harmonic set-valued function with modulus
c
, then for all
x,y\in D
,
t\in[0,1]
and
B
a unitary ball of
Y
, we have:

\displaystyle G\left(\frac{xy}{tx+(1-t)y}\right)

\displaystyle=

\displaystyle F\left(\frac{xy}{tx+(1-t)y}\right)+c\left\|\frac{tx+(1-t)y}{xy}\right\|^{2}B

\displaystyle\supset

\displaystyle\left[tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}B\right]+c\left\|\frac{tx+(1-t)y}{xy}\right\|^{2}B

\displaystyle=

\displaystyle\left[tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{1}{y}-\frac{1}{x}\right\|^{2}B\right]+c\left\|\frac{t}{y}+\frac{1-t}{x}\right\|^{2}B

\displaystyle=

\displaystyle tF(y)+(1-t)F(x)+ct(1-t)\left[\left\|\frac{1}{y}\right\|^{2}-\frac{2}{xy}+\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle\hskip 82.51282pt+c\left[\left\|\frac{t}{y}\right\|^{2}+\frac{2t(1-t)}{xy}+\left\|\frac{1-t}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle tF(y)+(1-t)F(x)+ct(1-t)\left[\left(\frac{1}{1-t}\right)\left\|\frac{1}{y}\right\|^{2}+\left(\frac{1}{t}\right)\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle t\left(F(y)+c\left\|\frac{1}{y}\right\|^{2}B\right)+(1-t)\left(F(x)+c\left\|\frac{1}{x}\right\|^{2}B\right)

\displaystyle=

\displaystyle tG(y)+(1-t)G(x),

which gives that
G
is harmonic convex set-valued function.

Moreover, to demonstrate the necessary condition, if
G
is harmonic convex set-valued function, then we have:

\displaystyle F\left(\frac{xy}{tx+(1-t)y}\right)

\displaystyle=

\displaystyle G\left(\frac{xy}{tx+(1-t)y}\right)-c\left\|\frac{tx+(1-t)y}{xy}\right\|^{2}B

\displaystyle\supset

\displaystyle[tG(y)+(1-t)G(x)]-c\left\|\frac{tx+(1-t)y}{xy}\right\|^{2}B

\displaystyle=

\displaystyle tG(y)+(1-t)G(x)-c\left[\left\|\frac{t}{y}\right\|^{2}+\frac{2t(1-t)}{xy}+\left\|\frac{1-t}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle t\left(G(y)-c\left\|\frac{1}{y}\right\|^{2}B\right)+(1-t)\left(G(x)-c\left\|\frac{1}{x}\right\|^{2}B\right)

\displaystyle+ct(1-t)\left[\left\|\frac{1}{y}\right\|^{2}-\frac{2}{xy}+\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}B,

which show that
F
is strongly harmonic convex set-valued function with modulus
c>0
.

ii):

To prove this item, we will start by demonstrate the validity of sufficiency. Since
F
strongly harmonic mid-convex set-valued function with modulus
c>0
. Then:

\displaystyle G\left(\frac{2xy}{x+y}\right)

\displaystyle=

\displaystyle F\left(\frac{2xy}{x+y}\right)+c\left\|\frac{x+y}{2xy}\right\|^{2}B

\displaystyle\supseteq

\displaystyle\left[\frac{F(x)+F(y)}{2}+\frac{c}{4}\left\|\frac{x-y}{xy}\right\|^{2}B\right]+\frac{c}{4}\left\|\frac{x+y}{xy}\right\|^{2}B

\displaystyle=

\displaystyle\frac{F(x)+F(y)}{2}+\frac{c}{4}\left[2\left\|\frac{1}{y}\right\|^{2}+2\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle\frac{F(x)+F(y)}{2}+\frac{c}{2}\left\|\frac{1}{y}\right\|^{2}B+\frac{c}{2}\left\|\frac{1}{x}\right\|^{2}B

\displaystyle=

\displaystyle\frac{G(x)+G(y)}{2},

which gives that
G
is a harmonic mid-convex set-valued function.

To the necessary implication we will consider that
G
is harmonic mid-convex set-valued function. Then we have

\displaystyle F\left(\frac{2xy}{x+y}\right)

\displaystyle=

\displaystyle G\left(\frac{2xy}{x+y}\right)-c\left\|\frac{x+y}{2xy}\right\|^{2}B

\displaystyle\supseteq

\displaystyle\frac{G(x)+G(y)}{2}-\frac{c}{4}\left[\left\|\frac{1}{y}\right\|^{2}+\frac{2}{xy}+\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle\frac{G(x)-c\left\|\frac{1}{x}\right\|^{2}B}{2}+\frac{G(y)-c\left\|\frac{1}{y}\right\|^{2}B}{2}+\frac{c}{4}\left[\left\|\frac{1}{y}\right\|^{2}-\frac{2}{xy}+\left\|\frac{1}{x}\right\|^{2}\right]B

\displaystyle=

\displaystyle\frac{F(x)+F(y)}{2}+\frac{c}{4}\left\|\frac{x-y}{xy}\right\|^{2}B,

which shows that
F
is a strongly harmonic mid-convex set-valued function with modulus
c>0
.

∎

3.
Main Results

To start with the main results of this work which is to obtain some Hermite-Hadamard inequalities for functions, we need the following proposition.

Proposition 3.1
.

Let
D=[a,b]\subseteq X\backslash\{0\}
and consider the function
G:\left[\frac{1}{b},\frac{1}{a}\right]\rightarrow n(Y)
defined by
G(t)=F\left(\frac{1}{t}\right)
. Then
F
is strongly harmonic convex set-valued function on
[a,b]
with modulus
c>0
, if and only if,
G
is strongly convex set-valued function on
\left[\frac{1}{b},\frac{1}{a}\right]
with modulus
c>0
.

Proof.

First, let’s prove the sufficient condition.

Let
F
be a strongly harmonic convex set-valued function with modulus
c>0
. Then

tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}B\subseteq F\left(\frac{xy}{tx+(1-t)y}\right)

for all
x,y\in[a,b]
,
t\in[0,1]
and
c>0
.

Now, consider
G(t)=F\left(\frac{1}{t}\right)
and suppose that
x=\frac{1}{x_{2}}
and
y=\frac{1}{x_{1}}
in
[a,b]
. First, from the left side of the previous expression we have:

\displaystyle tF(y)+(1-t)F(x)+ct(1-t)\left\|\frac{x-y}{xy}\right\|^{2}B

\displaystyle=

\displaystyle tF\left(\frac{1}{x_{1}}\right)+(1-t)F\left(\frac{1}{x_{2}}\right)+ct(1-t)\left\|\frac{\frac{1}{x_{2}}-\frac{1}{x_{1}}}{\frac{1}{x_{2}}\frac{1}{x_{1}}}\right\|^{2}B

\displaystyle=

\displaystyle tG(x_{1})+(1-t)G(x_{2})+ct(1-t)\|x_{2}-x_{1}\|^{2}B,

while on the right side we get:

\displaystyle F\left(\frac{\frac{1}{x_{2}}\frac{1}{x_{1}}}{t\frac{1}{x_{2}}+(1-t)\frac{1}{x_{1}}}\right)

\displaystyle=

\displaystyle F\left(\frac{1}{tx_{1}+(1-t)x_{2}}\right)

\displaystyle=

\displaystyle G(tx_{1}+(1-t)x_{2}).

Accordingly,

tG(x_{1})+(1-t)G(x_{2})+ct(1-t)\|x_{2}-x_{1}\|^{2}B\subseteq G(tx_{1}+(1-t)x_{2})

for all
x_{1},x_{2}\in\left[\frac{1}{b},\frac{1}{a}\right]
,
t\in[0,1]
and
c>0
.

Thus
G
is strongly convex set-valued function modulus
c
.

Now, let’s try the necessary condition.

Let
G
strongly convex set-valued function with modulus
c>0
, then:

tG(x_{1})+(1-t)G(x_{2})+ct(1-t)\|x_{2}-x_{1}\|^{2}B\subseteq G(tx_{1}+(1-t)x_{2}),

for all
x_{1},x_{2}\in\left[\frac{1}{b},\frac{1}{a}\right]
,
t\in[0,1]
and
c>0
.

Whereas
G(t)=F\left(\frac{1}{t}\right)
,
x=\frac{1}{x_{2}}
and
y=\frac{1}{x_{1}}
in
\left[\frac{1}{b},\frac{1}{a}\right]
, from the left side of the previous expression we have:

\displaystyle tG\left(\frac{1}{x_{2}}\right)+(1-t)G\left(\frac{1}{x_{1}}\right)+ct(1-t)\left\|\frac{1}{x_{1}}-\frac{1}{x_{2}}\right\|^{2}B

\displaystyle=

\displaystyle tF(x_{2})+(1-t)F(x_{1})+ct(1-t)\left\|\frac{x_{2}-x_{1}}{x_{2}x_{1}}\right\|^{2}B.

On the right side of contention we have:

\displaystyle G\left(t\frac{1}{x_{2}}+(1-t)\frac{1}{x_{1}}\right)

\displaystyle=

\displaystyle G\left(\frac{tx_{1}+(1-t)x_{2}}{x_{2}x_{1}}\right)

\displaystyle=

\displaystyle F\left(\frac{x_{2}x_{1}}{tx_{1}+(1-t)x_{2}}\right).

Then

tF(x_{2})+(1-t)F(x_{1})+ct(1-t)\left\|\frac{x_{2}-x_{1}}{x_{2}x_{1}}\right\|^{2}B\subseteq F\left(\frac{x_{2}x_{1}}{tx_{1}+(1-t)x_{2}}\right),

for all
x_{1},x_{2}\in[a,b]
,
t\in[0,1]
and
c>0
.
Thus
F
is strongly harmonic convex set-valued function with modulus
c
.

∎

Now, using the Proposition
3.1
, we obtain a new result of Hermite-Hadamard inequality type for strongly harmonic convex set-valued functions.

Theorem 3.2
.

Let
D
be a harmonic set of
X
and
F:D\subset X\rightarrow n(Y)
strongly harmonic convex set-valued function modulus
c>0
. If
F
is Aumann integrable (see
[
1
]
), then:

\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)}{x^{2}}dx+\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B\subset F\left(\frac{2ab}{a+b}\right),

and

\frac{F(a)+F(b)}{2}+\frac{c}{6}\left\|\frac{b-a}{ab}\right\|^{2}B\subset\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)}{x^{2}}dx,

for all
a,b\in D
,
t\in[0,1]
and
B
a unitary ball of
Y
.

Proof.

Let
G(t)=F\left(\frac{1}{t}\right)
be a strongly convex set-valued function modulus
c>0
, then
G
satisfies (
2.4
) and (
2.5
) for all
x,y\in D
, i.e.:

\frac{1}{y-x}\int_{x}^{y}G(t)dt+\frac{c}{12}(y-x)^{2}B\subset G\left(\frac{x+y}{2}\right),

and

\frac{G(x)+G(y)}{2}+\frac{c}{6}(y-x)^{2}B\subset\frac{1}{y-x}\int_{x}^{y}G(t)dt,

for all
t\in[x,y]
. Now consider
G(t)=F\left(\frac{1}{t}\right)
with
t\in\left[\frac{1}{b},\frac{1}{a}\right]
, then on the one hand, we take:

\frac{1}{\frac{1}{b}-\frac{1}{a}}\int_{\frac{1}{b}}^{\frac{1}{a}}F\left(\frac{1}{t}\right)dt+\frac{c}{12}\left(\frac{1}{a}-\frac{1}{b}\right)^{2}B\subset F\left(\frac{1}{\frac{\frac{1}{b}+\frac{1}{a}}{2}}\right).

Thus,

\frac{ab}{b-a}\int_{\frac{1}{b}}^{\frac{1}{a}}F\left(\frac{1}{t}\right)dt+\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B\subset F\left(\frac{2ab}{a+b}\right).

Then, by Aumann’s definition, we take the following result:

\displaystyle\int_{\frac{1}{b}}^{\frac{1}{a}}F\left(\frac{1}{t}\right)dt

\displaystyle=

\displaystyle\left\{\int_{\frac{1}{b}}^{\frac{1}{a}}f\left(\frac{1}{t}\right)dt:f\in F\right\}

\displaystyle=

\displaystyle\left\{\int_{a}^{b}\frac{f(x)}{x^{2}}dx:f\in F\right\}

\displaystyle=

\displaystyle\int_{a}^{b}\frac{F(x)}{x^{2}}dx.

Therefore,

\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)}{x^{2}}dx+\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B\subset F\left(\frac{2ab}{a+b}\right).

On the other hand, we have that:

\frac{F\left(\frac{1}{\frac{1}{b}}\right)+F\left(\frac{1}{\frac{1}{a}}\right)}{2}+\frac{c}{6}\left\|\frac{b-a}{ab}\right\|^{2}B\subset\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)}{x^{2}}dx,

and this is,

\frac{F(a)+F(b)}{2}+\frac{c}{6}\left\|\frac{b-a}{ab}\right\|^{2}B\subset\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)}{x^{2}}dx.

∎

Theorem 3.3
.

Let
F,G:D\rightarrow n(Y)
be strongly harmonic convex set-valued function with modulus
c>0
. If
F,G
are Aumann integrable, then:

(3.1)

\frac{1}{6}M(a,b)+\frac{1}{3}N(a,b)+S(a,b)\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B+\frac{c^{2}}{30}\left\|\frac{b-a}{ab}\right\|^{4}B\subset\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)G\left(\frac{abx}{(a+b)x-ab}\right)}{x^{2}}dx,

where

M(a,b)=F(a)G(a)+F(b)G(b),

N(a,b)=F(a)G(b)+F(b)G(a),

S(a,b)=F(a)+F(b)+G(a)+G(b),

Proof.

Let
F,G
strongly harmonic convex set-valued functions with modulus
c>0
. Then:

\displaystyle\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)G\left(\frac{abx}{(a+b)x-ab}\right)}{x^{2}}dx

\displaystyle=

\displaystyle\int_{0}^{1}F\left(\frac{ab}{ta+(1-t)b}\right)G\left(\frac{ab}{(1-t)a+tb}\right)dt

\displaystyle\supseteq

\displaystyle\int_{0}^{1}\left[tF(b)+(1-t)F(a)+ct(1-t)\left\|\frac{b-a}{ab}\right\|^{2}B\right]

\displaystyle\hskip 85.35826pt\left[tG(a)+(1-t)G(b)+ct(1-t)\left\|\frac{b-a}{ab}\right\|^{2}B\right]dt

\displaystyle=

\displaystyle F(a)G(a)\int_{0}^{1}(1-t)^{2}dt+F(b)G(a)\int_{0}^{1}t^{2}dt

\displaystyle\hskip 85.35826pt+[F(a)G(a)+F(b)G(b)]\int_{0}^{1}t(1-t)dt

\displaystyle\hskip 85.35826pt+c\left\|\frac{b-a}{ab}\right\|^{2}B[F(a)+G(b)]\int_{0}^{1}t(1-t)^{2}dt

\displaystyle\hskip 85.35826pt+c\left\|\frac{b-a}{ab}\right\|^{2}B[F(b)+G(a)]\int_{0}^{1}t^{2}(1-t)dt

\displaystyle\hskip 85.35826pt+c^{2}\left\|\frac{b-a}{ab}\right\|^{4}B\int_{0}^{1}t^{2}(1-t)^{2}dt

\displaystyle=

\displaystyle\frac{F(a)G(b)+F(b)G(a)}{3}+\frac{F(a)G(a)+F(b)G(b)}{6}

\displaystyle+[F(a)+F(b)+G(a)+G(b)]\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B+\frac{c^{2}}{30}\left\|\frac{b-a}{ab}\right\|^{4}B

\displaystyle=

\displaystyle\frac{1}{6}M(a,b)+\frac{1}{3}N(a,b)+S(a,b)\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B+\frac{c^{2}}{30}\left\|\frac{b-a}{ab}\right\|^{4}B,

which is the required result.
∎

Theorem 3.5
.

Let
F,G:D\subset X\rightarrow n(Y)
be two strongly harmonic convex set-valued functions with modulus
c>0
. If
F,G
are Aumann integrable on
[a,b]
, then:

\frac{1}{6}M(a,b)+\frac{1}{3}N(a,b)+S(a,b)\frac{c}{12}\left\|\frac{b-a}{ab}\right\|^{2}B+\frac{c^{2}}{30}\left\|\frac{b-a}{ab}\right\|^{4}B\subset\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)G(x)}{x^{2}}dx,

where
M(a,b),N(a,b)
and
S(a,b)
are given by theorem
3.3
.

Proof.

Let
F,G
be two strongly harmonic convex set-valued functions with modulus
c>0
. Then:

\displaystyle\frac{ab}{b-a}\int_{a}^{b}\frac{F(x)G(x)}{x^{2}}dx

\displaystyle=

\displaystyle\int_{0}^{1}F\left(\frac{ab}{ta+(1-t)b}\right)G\left(\frac{ab}{ta+(1-t)b}\right)dt

\displaystyle\supseteq

\displaystyle\int_{0}^{1}\left[tF(b)+(1-t)F(a)+ct(1-t)\left\|\frac{b-a}{ab}\right\|^{2}B\right]\left[tG(b)+(1-t)G(a)+ct(1-t)\left\|\frac{b-a}{ab}\right\|^{2}B\right]dt

\displaystyle\frac{1}{3}[F(a)G(a)+F(b)G(b)]+\frac{1}{6}[F(a)G(b)+F(b)G(a)]+\frac{c}{12}[F(a)+F(b)+G(a)+G(b)]\left\|\frac{b-a}{ab}\right\|^{2}

\displaystyle+\frac{c^{2}}{30}\left\|\frac{b-a}{ab}\right\|^{4}B
