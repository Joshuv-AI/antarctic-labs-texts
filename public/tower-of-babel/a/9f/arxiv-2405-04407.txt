Super-Exponential Regret for UCT, AlphaGo and Variants
Laurent Orseau, Rémi Munos

Abstract
We improve the proofs of the lower bounds of Coquelin and Munos 2007 that demonstrate that UCT can have exp ⁡ ( … ​ exp ⁡ ( 1 ) ​ … ) \exp(\dots\exp(1)\dots) regret (with Ω ⁡ ( D ) \Omega(D) exp terms) on the D D -chain environment, and that a ‘polynomial’ UCT variant has exp 2 ⁡ ( exp 2 ⁡ ( D − O ⁡ ( log ⁡ D ) ) ) \exp_{2}(\exp_{2}(D-O(\log D))) regret on the same environment — the original proofs contain an oversight for rewards bounded in [ 0 , 1 ] [0,1] , which we fix in the present draft. We also adapt the proofs to AlphaGo’s MCTS and its descendants ( e.g. , AlphaZero, Leela Zero) to also show exp 2 ⁡ ( exp 2 ⁡ ( D − O ⁡ ( log ⁡ D ) ) ) \exp_{2}(\exp_{2}(D-O(\log D))) regret.

Remark 1
.

Since the environment is deterministic, algorithms could take advantage of this by not visiting terminal states more than once, meaning that the lower bounds would not apply to such algorithms.
To make matters more interesting, we can instead assume that there is no terminal state and that the tree is an infinite binary tree.
This forces search algorithms to visit the same nodes multiple times in search of better rewards elsewhere in the tree.
(Making the environment stochastic would substantially complicate the analysis.)

UCT lower bound

UCT uses the following formula,
for
i\in\{d,d^{\prime}\}
for all
d<D
:

\displaystyle B_{i,t+1}=X_{i,t}+\sqrt{\frac{2\ln m_{d-1,t}}{m_{i,t}}}\,.

(16)

Similarly to the previous sections, on the trajectory
T+1
we obtain, for all
d<D
,

\displaystyle B_{d^{\prime},T+1}

\displaystyle\leq B_{d^{\prime},T}\,,

(17)

\displaystyle 1-\frac{d}{D}+\sqrt{\frac{2\ln m_{d-1,T}}{m_{d^{\prime},T}}}

\displaystyle\leq 1-\frac{d+1}{D}+\sqrt{\frac{2\ln m_{d-1,T}}{m_{d,T}}}\,,

(18)

from which we deduce (omitting
T

\displaystyle\sqrt{\frac{2\ln m_{d-1}}{m_{d}}}

\displaystyle\geq\frac{1}{D}\,,

(19)

\displaystyle m_{d-1}

\displaystyle\geq\exp\left(\frac{m_{d}}{2D^{2}}\right)\,.

(20)

Observe that starting the recursion with
m_{d}\leq 2D^{2}
gives at most

which is less than

(for

) and the recurrence actually converges to a number close to 1.

large enough, that is, we need to find some
\hat{d}

\displaystyle\exp\left(\frac{m_{\hat{d}}}{2D^{2}}\right)\geq 2m_{\hat{d}}\,.

If

then it can be shown that the relation above is true for all

From

which means that

We conclude that

\displaystyle m_{0}\geq\exp(\dots\exp(\exp(4D^{3}/2D^{2})/2D^{2})\dots/2D^{2})\,,
