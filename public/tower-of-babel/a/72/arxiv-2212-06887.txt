Beyond the Galvin–Hindman–Furstenberg Theorem: Partition regularity of IP sets in arbitrary semigroups
Yonatan Gadot and Boaz Tsaban

Abstract
. According to Furstenberg, an infinite parallelepiped (IP) set in a semigroup is a set that contains a sequence a 1 , a 2 , … a_{1},\allowbreak a_{2},\allowbreak\dots , together with all finite sums a i 1 + ⋯ + a i m a_{i_{1}}+\dotsb+a_{i_{m}} , for natural numbers m m and i 1 < ⋯ < i m i_{1}<\dotsb<i_{m} . Using a method of Galvin, Hindman proved that IP sets of natural numbers are partition regular : For each finite partition of an IP set, some part must be an IP set, too. Furstenberg noted that the same proof applies to arbitrary semigroups. However, in a semigroup with idempotents, an IP set may be a singleton. A proper IP set is one where the witnessing sequence a 1 , a 2 , … a_{1},\allowbreak a_{2},\allowbreak\dots may be chosen to be bijective (in ℕ \mathbb{N} , every IP set is proper). We provide a complete characterization of semigroups where the proper IP sets are partition regular, and show that this property is equivalent to several other fundamental notions of additive Ramsey theory. Using our results, we prove that if there is a monochromatic proper IP set for each finite coloring of a semigroup, then for each finite coloring of the semigroup there are infinitely many, pairwise disjoint, proper IP sets sharing the same color.

1.
Introduction

Ramsey theory deals with the phenomenon that, whenever a rich mathematical structure is partitioned into finitely many parts,
at least one of the parts is mathematically rich.
A family of sets is
partition regular
if, for each finite partition of a set from the family,
there is a part that is also in this family.
A
finite coloring
of a set is a function from that set into a finite set of colors.
A subset of the colored set is
monochromatic
if all of its members have the same color.
Thus, a family of sets is partition regular if and only if for each finite coloring of a set in the family,
there is in the family a monochromatic subset of the colored set.

For clarity and compatibility of notation, we use additive notation for all,
including noncommutative
, semigroups.
Thus, the results of this paper hold for all, commutative and noncommutative, semigroups.
For a sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in a semigroup, let

\FS(a_{1},\allowbreak a_{2},\allowbreak\dots):=\{\,a_{i_{1}}+\dotsb+a_{i_{m}}:m\geq 1,i_{1}<\dotsb<i_{m}\,\}.

A subset of a semigroup is an
infinite parallelepiped (IP)
set if it contains a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
, for some
sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in the semigroup. For convenience, we define that IP sets are not necessarily of the form

\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
; it suffices for them to contain a set of this form.
Hindman’s celebrated Finite Sums Theorem
[
5
, Theorem 3.1]
asserts that
for each finite coloring of the natural numbers, there is a monochromatic IP set.
Using the Stone-Čech compactification, Galvin and Glazer provided an elegant proof
of Hindman’s Theorem, that applies to all semigroups
[
2
, Thorem 10.3]
.
Furstnberg
[
3
, Proposition 8.13]
attributes the following stronger assertion to Hindman.
Hindman proves this assertion in the case of
\mathbb{N}
, and attributes his result to Galvin
[
6
, Corrolary 2.9]
.

Theorem 1

(Furstenberg–Galvin–Hindman)
.

For each semigroup, the family of IP sets is partition regular.

In the semigroup
\mathbb{N}
of natural numbers, every IP set contains a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
where the
sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
is
bijective
. Thus, in
\mathbb{N}
, the term “infinite parallelepiped” is justified.
However, as defined above, an IP set in a general semigroup may be a singleton! Indeed, for each idempotent element
e

in a semigroup, we have
\FS(e,e,\dotsc)=\{e\}
. The following definition rectifies this problem.

Definition 2
.

A
proper IP
set in a semigroup is a set that contains a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
, for some

bijective
sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in the semigroup.

For a sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in a semigroup and a natural number
n
, let

\displaystyle\FS(a_{1},\dotsc,a_{n})

\displaystyle:=\{\,a_{i_{1}}+\dotsm+a_{i_{m}}:1\leq m,i_{1}<\dotsb<i_{m}\leq n\,\}.

Lemma 3
.

Every infinite set of the form
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
(and thus every superset of such a set) is a proper IP set.

Proof.

Let
n
be a natural number. Since

\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)=\FS(a_{1},\dotsc,a_{n})\cup\FS(a_{n+1},a_{n+2},\dotsc)\\
\cup(\FS(a_{1},\dotsc,a_{n})+\FS(a_{n+1},a_{n+2},\dotsc)),

the set
\FS(a_{n+1},\allowbreak a_{n+2},\dotsc)
must be infinite.
It follows that we can construct a bijective sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
such that for each
n
there is an index
m_{n}
such that

b_{n}\in\FS(a_{1},\dotsc,a_{m_{n}})
and
b_{n+1}\in\FS(a_{m_{n}+1},a_{m_{n}+2},\dotsc)
. Clearly,
\FS(b_{1},\allowbreak b_{2},\allowbreak\dots)\subseteq\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
.
∎

In general, the proper IP sets need not be partition regular. Consider the fan semilattice
S
, colored
as follows:

\textstyle{{\color[rgb]{0,0.59,0}\bullet}}
\textstyle{{\color[rgb]{0,0.59,0}\bullet}}
\textstyle{{\color[rgb]{0,0.59,0}\bullet}}
\textstyle{{\color[rgb]{0,0.59,0}\bullet}}
\textstyle{\dotsm}
\textstyle{{\color[rgb]{1,0,0}\bullet}\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces}

The entire semilattice is a proper IP set, but the only monochromatic IP set for this coloring is a singleton.
It follows that, for a semigroup to have the proper IP sets partition regular, it may not include the fan
semilattice as a subsemigroup.

For which semigroups are the proper IP sets partition regular?
This problem was raised, for example, by Andrews and Goldbring
[
1
, Question 4.9]
.
We provide a complete solution:
the proper IP sets in a semigroup are partition regular if and only if
the semigroup has no subsemigroup of one of three explicit types.
We also establish the equivalence of this feature to other fundamental notions of
additive coloring theory.
Finally, using our results, we prove that if a semigroup
S
contains a monochromatic proper IP set for each finite coloring of the entire semigroup,
then for each finite coloring it contains
infinitely many
pairwise disjoint monochromatic proper IP sets.

2.
Proper sumsequences

Let
a_{1},\allowbreak a_{2},\allowbreak\dots
be a sequence in a semigroup.
For a finite index set
F=\{i_{1},\dotsc,i_{m}\}
with
i_{1}<\dotsb<i_{m}
, let

a_{F}:=a_{i_{1}}+\dotsb+a_{i_{m}}.

For finite index sets
F_{1},F_{2}\subseteq\mathbb{N}
, we write
F_{1}<F_{2}
if all elements of the set
F_{1}
are smaller than all elements of the set
F_{2}
.
The sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
is
proper

[
10
, Definition 1.3]
if
a_{F_{1}}\neq a_{F_{2}}
for all
F_{1}<F_{2}
.

Remark 4
.

A proper IP set need not contain a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
for a proper sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
.
However, since proper sequences are bijective, an IP set containing a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
for a proper sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
must be a proper IP set.
These notions of properness are only partially related.

Lemma 5
.

Every bijective sequence in a group has a proper subsequence.

Proof.

Let
a_{1},\allowbreak a_{2},\allowbreak\dots
be a bijective sequence in a group. We construct a proper subsequence
b_{1}:=a_{m_{1}},b_{2}:=a_{m_{2}},\dotsc
by induction.

Let
m_{1}:=1
.
Assume that
m_{1}\dotsc,m_{n}
are defined.
Since the set
A:=\FS(b_{1},\allowbreak\dotsc,\allowbreak b_{n})\cup\{0\}
is finite, so is the set
-A+A
.
Choose an index
m_{n+1}
such that

a_{m_{n+1}}\in\FS(a_{m_{n}+1},a_{m_{n}+2},\dotsc)\setminus(-A+A).

Let
F_{1}<F_{2}
be finite index sets, and let
n:=\max F_{2}
. Then there is
a\in A:=\FS(b_{1},\dotsc\allowbreak,b_{n-1})\cup\{0\}
such that

b_{F_{2}}=a+b_{n}
, and
a+b_{n}\notin A
, whereas
b_{F_{1}}\in A
.
∎

A
sumsequence
(traditionally called
sum subsystem
)
of a sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
is a sequence
a_{F_{1}},a_{F_{2}},\dotsc
, for an increasing sequence

F_{1}<F_{2}<\dotsb
of finite index sets.
The proof of Lemma
3
shows that if a set
\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
is infinite, then the sequence

a_{1},\allowbreak a_{2},\allowbreak\dots
has a bijective sumsequence.
Among other things, our main result (Theorem
15
)
characterizes the semigroups where every bijective sequence has a proper sumsequence.

Proposition 6
.

A sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in a semigroup has a proper sumsequence if and only if
it has a sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
with
\bigcap_{n=1}^{\infty}\FS(b_{n},b_{n+1},\dotsc)=\emptyset
.

Proof.

(
\Rightarrow
) Let
b_{1},\allowbreak b_{2},\allowbreak\dots
be a proper sumsequence.

(\Leftarrow)
We construct a proper subsequence
b_{m_{1}},b_{m_{2}},\dotsc
of the sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
.

Let
m_{1}:=1
.
Assume that we have defined
m_{1},\dotsc,m_{n}
.
Since the set
\FS(b_{m_{1}},\allowbreak\dotsc,\allowbreak b_{m_{n}})
is finite and
\bigcap_{m=1}^{\infty}\FS(b_{m},b_{m+1},\dotsc)=\emptyset
,
we can choose an index
m_{n+1}
with

\FS(b_{m_{1}},\dotsc,b_{m_{n}})\cap\FS(b_{m_{n+1}},b_{m_{n+1}+1},\dotsc)=\emptyset.

Let
c_{1}:=b_{m_{1}},c_{2}:=b_{m_{2}},\dotsc
. For each
n
, we have

\FS(c_{1},\dotsc,c_{n})\cap\FS(c_{n+1},c_{n+2},\dotsc)=\emptyset.

Let
F_{1}<F_{2}
be finite index sets. Let
n:=\max F_{1}
.
Then
c_{F_{1}}\in\FS(c_{1},\dotsc,c_{n})
and
c_{F_{2}}\in\FS(c_{n+1},c_{n+2},\dotsc)
,
and thus
c_{F_{1}}\neq c_{F_{2}}
.
∎

In particular, if a sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
has no proper sumsequence, then the set

\bigcap_{n=1}^{\infty}\FS(a_{n},\allowbreak a_{n+1},\dotsc)
is nonempty.

Lemma 7
.

Let
S
be a semigroup and
a_{1},\allowbreak a_{2},\allowbreak\dots
be a bijective sequence with no proper sumsequence.
Let
A_{\infty}:=\bigcap_{n=1}^{\infty}\FS(a_{n},a_{n+1},\dotsc)
.
Then:

(1)

For each element
s\in A_{\infty}
and each
n
, there is a finite index set
F\geq n
with
such that
s=a_{F}
.

(2)

The set
A_{\infty}
is a subsemigroup of
S
.

(3)

Every sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
in
A_{\infty}

is a sumsequence of
a_{1},\allowbreak a_{2},\allowbreak\dots
.

Proof.

(1) For each
n
, we have
s\in\FS(a_{n},a_{n+1},\dotsc)
.

(2) By Lemma
6
, we have
A_{\infty}\neq\emptyset
.
Let
s_{1},s_{2}\in A_{\infty}
. For each
n
, by (1) there are index sets
n\leq F_{1}<F_{2}

with
s_{1}=a_{F_{1}}
and
s_{2}=a_{F_{2}}
.
Then
s_{1}+s_{2}=a_{F_{1}\cup F_{2}}\in\FS(a_{n},a_{n+1},\dotsc)
.
Thus,
s_{1}+s_{2}\in A_{\infty}
.

(3) This follows from (1).
∎

Definition 8
.

A bijective sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
in a semigroup is
minimal
if, for each bijective sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
of
a_{1},\allowbreak a_{2},\allowbreak\dots
, we have

\bigcap_{n=1}^{\infty}\FS(b_{n},b_{n+1},\dotsc)=\bigcap_{n=1}^{\infty}\FS(a_{n},a_{n+1},\dotsc).

Proposition 9
.

Let
S
be a semigroup and
a_{1},\allowbreak a_{2},\allowbreak\dots
be a bijective sequence with no proper sumsequence.
There is a bijective sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
of
a_{1},\allowbreak a_{2},\allowbreak\dots
such that:

(1)

The set
\bigcap_{n=1}^{\infty}\FS(b_{n},b_{n+1},\dotsc)
is a finite subsemigroup of
S
.

(2)

The sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
is minimal.

Proof.

(1) By Lemma
7
, the set
\bigcap_{n=1}^{\infty}\FS(a_{n},a_{n+1},\dotsc)
is a subsemigroup of
S
.
If it is finite, then we are done. Thus, assume that it is infinite.
By a theorem of Shevrin
[
8
]
, this subsemigroup has one of the following subsemigroups:

(1)

(\mathbb{N},+)
.

(2)

An infinite periodic group.

(3)

An infinite right or left zero semigroup.

(4)

(\mathbb{N},\wedge)

.

(5)

(\mathbb{N},\vee)

m\vee n=\operatorname{max}\{m,n\}

(6)

An infinite semigroup

with

(7)

The fan semilattice

The semigroups of types (1)–(5) have proper sequences, and by Lemma

every such sequence is a sumsequence of the initial sequence. Thus, our subsemigroup

with
\bigcap_{n=1}^{\infty}\FS(b_{n},b_{n+1},\dotsc)

By Lemma

b_{1},\allowbreak b_{2},\allowbreak\dots
is a sumsequence of the sequence
a_{1},\allowbreak a_{2},\allowbreak\dots
.

(2) Since the semigroup
\bigcap_{n=1}^{\infty}\FS(b_{n},\allowbreak b_{n+1},\dotsc)
is finite, we can move to
a bijective sumsequence
c_{1},\allowbreak c_{2},\allowbreak\dots
of
b_{1},\allowbreak b_{2},\allowbreak\dots
such that the set
\bigcap_{n=1}^{\infty}\FS(c_{n},\allowbreak c_{n+1},\dotsc)
is minimal with respect to inclusion.
∎

First, assume that there are an idempotent element

Next, towards a contradiction, assume that for each idempotent

Corollary 13
.

Let

•

•

Proof.

12

Consider a finite coloring of the complete graph with the set of vertices

(3)

. Hence

S^{\prime}:=\{\,s_{n}:n\in\mathbb{N}\,\}\cup A_{\infty}\subseteq S

is an infinite subset. For each
n
, we have
s_{n}+s_{n}=2\cdot m^{\prime}_{n}\cdot c_{n}\in A_{\infty}
by the definition of
m^{\prime}_{n}
.
For each
n\neq k
, we have

s_{n}+s_{k}=m^{\prime}_{n}\cdot c_{n}+m^{\prime}_{k}\cdot c_{k}\in A_{\infty}

by Statement
5
. It follows that
S^{\prime}
is an infinite semigroup and
S^{\prime}+S^{\prime}\subseteq A_{\infty}
is finite as requested.

Otherwise, we may assume that
m_{n}\leq 3
for all
n
. By moving to an appropriate subsequence using Ramsey’s theorem, we may assume that either
2\cdot c_{n}=2\cdot c_{k}
for all
n<k
, or
2\cdot c_{n}\neq 2\cdot c_{k}
for all
n<k
.

In the first case, it follows from Equation
5
that
2\cdot c_{1}+c_{n}=3\cdot a\in A_{\infty}
for
n\neq 1
, and
2\cdot c_{1}+c_{1}=2\cdot c_{2}+c_{1}=3\cdot a\in A_{\infty}
. Consider the subset

S^{\prime}:=\{\,c_{n}:n\in\mathbb{N}\,\}\cup\{\,2\cdot c_{1},b\,\}\cup A_{\infty}\leq S.

For each
n<m
,
c_{n}+c_{m}\in A_{\infty}
and
c_{m}+c_{n}=b
. By Equation
4
, we have
b+c_{n}=c_{n}+b\in A_{\infty}
for all
n
.
It is clear now that
S^{\prime}
is an infinite subsemigroup with
S^{\prime}+S^{\prime}\subseteq\{\,2\cdot c_{1},b\,\}\cup A_{\infty}
finite.

In the second case,
S^{\prime}:=\{\,2\cdot c_{n}:n\in\mathbb{N}\,\}\cup A_{\infty}
is an infinite subset. Since
m_{n}\leq 3
for each
n
, we have
2\cdot c_{n}+2\cdot c_{n}=4\cdot c_{n}\in A_{\infty}
. By Equation
5
,
2\cdot c_{n}+2\cdot c_{m}\in A_{\infty}
for all
n\neq m
.
It follows that
S^{\prime}
is an infinite subsemigroup, and
S^{\prime}+S^{\prime}\subseteq A_{\infty}
is finite.

Case 3.2
. There is a subsequence
c_{1},\allowbreak c_{2},\allowbreak\dots
such that
\{\,m\cdot c_{n}:m\in\mathbb{N}\,\}
is finite and

\{\,m\cdot c_{n}:m\in\mathbb{N}\,\}\cap A_{\infty}=\emptyset

for all
n
. For each
n
, let
e_{n}:=m_{n}\cdot c_{n}
be an idempotent. There is an idempotent
e=k\cdot a\in A_{\infty}
, and we can assume that
k\geq 2
. By Equation
5
, we may compute for all
n\neq l
,

e_{n}+e_{l}=k\cdot e_{n}+k\cdot e_{l}=k\cdot m_{n}\cdot c_{n}+k\cdot m_{l}\cdot c_{l}=(m_{n}+m_{l})\cdot k\cdot a=(m_{n}+m_{l})\cdot e=e.

We can define now an embedding of the fan lattice into
S
given by:

\phi(n):=\begin{cases}e&n=1,\\
e_{n}&2\leq n\end{cases}.

Case 3.3
. There is a subsequence
c_{1},\allowbreak c_{2},\allowbreak\dots
such that
\{\,m\cdot c_{n}:m\in\mathbb{N}\,\}\cong\mathbb{N}
for all
n
.
First, notice that for
n<k
and
m_{1},m_{2}\in\mathbb{N}
,
m_{1}\cdot c_{n}\neq m_{2}\cdot c_{k}
.
Otherwise, we would have a contradiction by

(m_{1}+1)\cdot c_{n}=c_{n}+m_{1}\cdot c_{n}=c_{n}+m_{2}\cdot c_{k}\in A_{\infty}

since
c_{n}+c_{k}\in A_{\infty}
and
A_{\infty}
is an ideal.

Once again, let
e=k\cdot a\in A_{\infty}
be the idempotent of
A_{\infty}
(for some
k\geq 2
). By Equation
5
, for all
n_{1}\neq n_{2}
and all
l_{1}
and
l_{2}
, we have

l_{1}\cdot k\cdot c_{n_{1}}+l_{2}\cdot k\cdot c_{n_{2}}=(l_{1}+l_{2})\cdot k\cdot a=(l_{1}+l_{2})\cdot e=e.

In a similar way,

l_{1}\cdot k\cdot c_{n_{1}}+e=e+l_{1}\cdot k\cdot c_{n_{1}}=(l_{1}+1)\cdot k\cdot a=(l_{1}+1)\cdot e=e

We can define now an embedding of the semigroup of type
(c)
into
S
:

\phi(s):=\begin{cases}m\cdot k\cdot c_{n}&s=(n,m)\\
e&s=0\end{cases}.\qed

4.
A solution of a problem of Andrews and Goldbring

An infinite semigroup
S
is
moving
if for each infinite
A\subseteq S
and each finite
F\subseteq S
,
there are elements
a_{1},\dotsc,a_{k}\in A
such that
\{a_{1}+s,\dotsc,a_{k}+s\}\not\subseteq F

for all but finitely many
s\in S
.
Golan and Tsaban
[
4
]
proved that in every moving semigroup, the proper IP sets are partition regular.
Andrews and Goldbring
[
1
]
asked whether partition regularity of proper IP sets characterizes moving semigroups.
Our main theorem implies the following answer.

Corollary 16
.

There is a non-moving semigroup
S
where the proper IP sets are partition regular.

Proof.

Steinberg
[
9
]
proved that the following semigroup has finite-to-one right addition, but is not moving:

S:=\langle\,t,x_{0},x_{1},\dotsc:x_{0}+t=x_{0},x_{i}+t=x_{i-1},i>0\,\rangle.

Since this semigroup has finite-to-one right addition, it does not include a subsemigroup of the types in Theorem
15
.
It follows that the proper IP sets in the semigroup
S
are partition regular.
∎

5.
Hindman’s Theorem with infinitely many proper IP sets

We use our results to prove that every semigroup satisfying Hindman’s Finite Sums Theorem with the monochromatic set
being proper IP, has a much stronger property.

Lemma 17
.

Every sequence in a semigroup has a sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
of one of the following types:

(1)

For all natural numbers
n<m
,
b_{n}+b_{m}=b_{n}
.

(2)

For all natural numbers
n
, we have

\FS(b_{1},\dotsc,b_{n})\cap(\FS(b_{1},\dotsc,b_{n})+b_{n+1})=\emptyset.

Proof.

Let
a_{1},\allowbreak a_{2},\allowbreak\dots
be a sequence in a semigroup
S
. Assume that
a_{1},\allowbreak a_{2},\allowbreak\dots
does not have a sumsequence of the second type.
We construct by induction a sumsequence
c_{1},\allowbreak c_{2},\allowbreak\dots
together with a sumsequence
b^{(n)}_{1},b^{(n)}_{2},\dotsc
for each
n
, such that the following conditions hold for each
n
:

(1)

c_{n}\in\FS(b^{(n)}_{1},b^{(n)}_{2},\dotsc)
.

(2)

For each
s\in\FS(b^{(n+1)}_{1},b^{(n+1)}_{2},\dotsc)
, we have
c_{n}+s=c_{n}
.

Define
b^{(1)}_{1},b^{(1)}_{2},\dotsc:=a_{1},\allowbreak a_{2},\allowbreak\dots
. Assume we have defined
c_{1},\dotsc,c_{n-1}
and a sumsequence
b^{(i)}_{1},b^{(i)}_{2},\dotsc
for all
1\leq i\leq n
. By moving to a tail of the sumsequence, we may assume there is a number
k
such that
c_{1},\dotsc,c_{n-1}\in\FS(a_{1},\dotsc,a_{k})
and
b^{(n)}_{1},b^{(n)}_{2},\dotsc\in\FS(a_{k+1},a_{k+2},\dotsc)
.

Since the sumsequence
b^{(n)}_{1},b^{(n)}_{2},\dotsc
does not have a sumsequence of the second type, there is a maximal
finite

sumsequence
s_{1},\dotsc,s_{k}
of the second type. Let
F_{1}<\dotsb<F_{k}
be the corresponding index sets.
For each finite index set
F_{k}<H
, we have

\FS(s_{1},\dotsc,s_{k})\cap(\FS(s_{1},\dotsc,s_{k})+b^{(n)}_{H})\neq\emptyset.

Thus, there are elements
x,y\in\FS(s_{1},\dotsc,s_{k})
such that
x+b^{(n)}_{H}=y
.
Let
m:=\max F_{k}
. Define a finite coloring of
\FS(b^{(n)}_{m+1},b^{(n)}_{m+2},\dotsc)
by

\chi\colon\FS(b^{(n)}_{m+1},b^{(n)}_{m+2},\dotsc)\to(\FS(s_{1},\dotsc,s_{k}))^{2}

such that
\chi(b^{(n)}_{H})=(x,y)
implies
x+b^{(n)}_{H}=y
.
By Theorem
14
, there is a sumsequence
t_{1},\allowbreak t_{2},\allowbreak\dots
of
b^{(n)}_{m+1},\allowbreak b^{(n)}_{m+2},\dotsc
such that the set
\FS(t_{1},\allowbreak t_{2},\allowbreak\dots)
is monochromatic.
Let
x,y\in\FS(s_{1},\dotsc,s_{k})
be such that
x+t_{H}=y
for each finite sum
t_{H}\in\FS(t_{1},\allowbreak t_{2},\allowbreak\dots)
.
For each
t_{H}\in\FS(t_{2},t_{3},\dotsc)
, we have

y+t_{H}=x+t_{1}+t_{H}=x+t_{\{1\}\cup H}=y.

Define
c_{n}:=y
and
b^{(n+1)}_{1},b^{(n+1)}_{2},\dotsc:=t_{2},t_{3},\dotsc
.

We thus have a sumsequence
c_{1},\allowbreak c_{2},\allowbreak\dots
of
a_{1},\allowbreak a_{2},\allowbreak\dots
such that for all
n<m
, we have
c_{m}\in\FS(b^{(n+1)}_{1},\allowbreak b^{(n+1)}_{2},\dotsc)
and therefore
c_{n}+c_{m}=c_{n}
. This is a sumsequence of the first type.
∎

While Lemma
17
holds for arbitrary sequences, it is mainly interesting for
proper
sequences. Indeed, if a sequence has no proper sumsequence, then
there is an idempotent element such that the constant sequence
e,e,e,\dotsc
is a sumsequence of the given sequence
[
10
, Proposition 1.7]
.
This is a sequence of the first type in the Lemma, but we are interested in bijective sequences. Sumsequences of proper sequences are proper and, in particular, bijective.

Proposition 18
.

Every proper sequence in a semigroup has a sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
such that

b_{F}\neq b_{G}
for all disjoint finite index sets
F
and
G
.

Proof.

Let
a_{1},\allowbreak a_{2},\allowbreak\dots
be a proper sequence.
There is a (necessarily, bijective) sumsequence
b_{1},\allowbreak b_{2},\allowbreak\dots
of
a_{1},\allowbreak a_{2},\allowbreak\dots
of one of the types specified in Lemma
17
.

If
b_{1},\allowbreak b_{2},\allowbreak\dots
is a sequence of the first type, then

b_{F}=b_{\min F}\neq b_{\min G}=b_{G}.

Assume that
b_{1},\allowbreak b_{2},\allowbreak\dots
is a sequence of the second type. We may assume that
\max F<\max G
.
If
G
is a singleton, then
F<G
and
b_{F}\neq b_{G}
, by the properness of the sequence.
And if not, then
b_{F}\in\FS(b_{1},\dotsc,b_{\max G-1})
and
b_{G}\in\FS(b_{1},\dotsc,b_{\max G-1})+b_{\max G}
.
Since

\FS(b_{1},\dotsc,b_{\operatorname{max}G-1})\cap(\FS(b_{1},\dotsc,b_{\operatorname{max}G-1})+b_{\operatorname{max}G})=\emptyset,

we have
b_{F}\neq b_{G}
.
∎

Corollary 19
.

Let
a_{1},\allowbreak a_{2},\allowbreak\dots
be a proper sequence in a semigroup. The IP set
A=\FS(a_{1},\allowbreak a_{2},\allowbreak\dots)
can be partitioned into infinitely many proper IP sets.

Proof.

Let
b_{1},\allowbreak b_{2},\allowbreak\dots
be a sumsequence of
a_{1},\allowbreak a_{2},\allowbreak\dots
as in Proposition
18
.
Let
\mathbb{N}=\bigcup_{n=1}^{\infty}I_{n}
be a partition of the natural numbers into infinitely many infinite sets.
For each
n
, enumerate
I_{n}=\{\,i^{(n)}_{1},i^{(n)}_{2},\dots\,\}
in increasing order, and let

A_{n}:=\FS(b_{i^{(n)}_{1}},\allowbreak b_{i^{(n)}_{2}},\dotsc)
.
We obtain infinitely many disjoint proper IP subsets of the set
A
.
(The elements that do not belong to any set
A_{n}
may be added to
A_{1}
, for example.)
∎

Theorem 20
.

Let
S
be a semigroup where every finite coloring has a monochromatic proper IP set.
For each finite coloring of the semigroup
S
, there are infinitely many, pairwise disjoint, monochromatic proper IP sets.

Proof.

If the semigroup has a proper sequence, then the assertion follows from Theorem
14
and Corollary
19
.

Thus, assume there is no proper sequence in the semigroup.
Let
c
be a finite coloring of
S
.
By induction, we construct a sequence
A_{1},\allowbreak A_{2},\allowbreak\dots
of monochromatic, pairwise disjoint, proper IP sets.
We construct each set
A_{i}
together with a sequence
a^{(i)}_{1},a^{(i)}_{2},\dotsc
such that
A_{i}=\FS(a^{(i)}_{1},a^{(i)}_{2},\dotsc)
and the set
B_{i}:=\FS_{\geq 2}(a^{(i)}_{1},a^{(i)}_{2},\dotsc)
is finite.

Assume we have defined the sets
A_{1},\dotsc,A_{m}
, with the attached sequences
a^{(i)}_{1},a^{(i)}_{2},\dotsc

and sets
B_{i}
for
1\leq i\leq m
. Let
A:=\bigcup_{i=1}^{m}A_{i}
and
B:=\bigcup_{i=1}^{m}B_{i}
.
Define a new finite coloring
c^{\prime}
of the semigroup
S
by fixing two new colors
\alpha
and
\beta
, and setting

c^{\prime}(s):=\begin{cases}c(s)&s\in S\setminus(\bigcup_{i=1}^{m}A_{i}),\\
\alpha&s\in A\setminus B\\
\beta&s\in B\end{cases}.

Let
\FS(b_{1},\allowbreak b_{2},\allowbreak\dots)
, for a bijective sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
, be monochromatic for the new coloring.

Since the set
B
is finite, the color is not
\beta
.

Assume that the color is
\alpha
. By moving to a subsequence, we may assume that there is
i
with

b_{1},\allowbreak b_{2},\allowbreak\dots\in A_{i}\setminus B
. Since the sequence
b_{1},\allowbreak b_{2},\allowbreak\dots
is bijective in the set
\{\,a_{1},\allowbreak a_{2},\allowbreak\dots\,\}
,
there are indices
j_{1}<k_{1}
and
j_{2}<k_{2}
with
b_{j_{1}}=a_{j_{2}}
and
b_{k_{1}}=a_{k_{2}}
.
It follows that

b_{j_{1}}+b_{k_{1}}=a_{j_{2}}+a_{k_{2}}\in B,

and thus the color of the sum
b_{j_{1}}+b_{k_{1}}
is
\beta
; a contradiction.

Thus,
\FS(b_{1},\allowbreak b_{2},\allowbreak\dots)\subseteq S\setminus(\bigcup_{i=1}^{m}A_{i})
.
Since the colorings
c
and
c^{\prime}
agree on the set
S\setminus(\bigcup_{i=1}^{m}A_{i})
,
and the set
\FS(b_{1},\allowbreak b_{2},\allowbreak\dots)
is
c^{\prime}
-monochromatic, it is also
c
-monochromatic.

Since there are no proper sequences in the semigroup, by Proposition
12
, there is a bijective sumsequence
s_{1},\allowbreak s_{2},\allowbreak\dots
of

b_{1},\allowbreak b_{2},\allowbreak\dots
such that the set
\FS_{\geq 2}(s_{1},\allowbreak s_{2},\allowbreak\dots)
is finite.
Define
a^{(m+1)}_{1},a^{(m+1)}_{2},\dotsc:=s_{1},\allowbreak s_{2},\allowbreak\dots
,
A_{m+1}:=\FS(s_{1},\allowbreak s_{2},\allowbreak\dots)
, and
B_{m+1}:=\FS_{\geq 2}(s_{1},\allowbreak s_{2},\allowbreak\dots)
.
Since the sequence
s_{1},\allowbreak s_{2},\allowbreak\dots
is a sumsequence of
b_{1},\allowbreak b_{2},\allowbreak\dots
, the set
A_{m+1}
is a subset of the
c
-monochromatic set
\FS(b_{1},\allowbreak b_{2},\allowbreak\dots)
, which in turn is disjoint from the sets
A_{1},\dotsc,A_{m}
, as required.
∎

We point out that the second part of the last proof cannot be omitted:
There are semigroups with no proper sequences,
where every finite coloring has a monochromatic proper IP set.
