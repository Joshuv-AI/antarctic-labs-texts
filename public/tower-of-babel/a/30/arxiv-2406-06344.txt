Parametric kernel low-rank approximations using tensor train decomposition Thanks: Submitted to the editors DATE.
Abraham Khan, Arvind K. Saibaba

Abstract
Computing low-rank approximations of kernel matrices is an important problem with many applications in scientific computing and data science. We propose methods to efficiently approximate and store low-rank approximations to kernel matrices that depend on certain hyperparameters. The main idea behind our method is to use multivariate Chebyshev function approximation along with the tensor train decomposition of the coefficient tensor. The computations are in two stages: an offline stage, which dominates the computational cost and is parameter-independent, and an online stage, which is inexpensive and instantiated for specific hyperparameters. A variation of this method addresses the case that the kernel matrix is symmetric and positive semi-definite. The resulting algorithms have linear complexity in terms of the sizes of the kernel matrices. We investigate the efficiency and accuracy of our method on parametric kernel matrices induced by various kernels, such as the Matérn kernel, through various numerical experiments on problem setups up to three spatial dimensions and two parameter dimensions. Our methods have speedups up to 200 × 200\times in the online time compared to other methods with similar complexity and comparable accuracy.

Introduction

A kernel is a function of type
\kappa:\mathbb{R}^{d}\times\mathbb{R}^{d}\rightarrow\mathbb{R}
. Given two sets of points
\mathcal{X}=\{\boldsymbol{x}_{1},\dots,\boldsymbol{x}_{N_{s}}\}\subseteq\mathbb{R}^{d}
and
\mathcal{Y}=\{\boldsymbol{y}_{1},\dots,\boldsymbol{y}_{N_{t}}\}\subseteq\mathbb{R}^{d}
, which we refer to as the source and target points respectively, we define a kernel matrix
\boldsymbol{K}(\mathcal{X},\mathcal{Y})\in\mathbb{R}^{N_{s}\times N_{t}}
with entries

[\boldsymbol{K}(\mathcal{X},\mathcal{Y})]_{i,j}=\kappa(\boldsymbol{x}_{i},\boldsymbol{y}_{j}),\qquad 1\leq i\leq N_{s},1\leq j\leq N_{t}.

Kernel matrices arise in many instances in applied mathematics; for example, Gaussian Processes, N-body simulations, integral equations, etc. However, kernel matrices are dense (depending on the support of
\kappa
) and, therefore, a central challenge is storing and computing kernel matrices when the number of source and target points
N_{s}
and
N_{t}
are large. The naïve approach has a complexity
\mathcal{O}(N_{s}N_{t})
floating point operations (flops), which is not practically applicable. Hence, it is desirable to develop low-rank approximation methods that have linear complexity in the number of source and target points.

The singular value decay of a kernel matrix
\boldsymbol{K}(\mathcal{X},\mathcal{Y})
is dependent on both the spatial configuration and the interactions between source and target points, as well as the smoothness of the kernel function
\kappa
. To quantify the level of interaction between the source and target points, we introduce the source box
\mathcal{B}_{s}=\bigtimes_{i=1}^{d}[\alpha^{s}_{i},\beta^{s}_{i}]
and the target box
\mathcal{B}_{t}=\bigtimes_{i=1}^{d}[\alpha^{t}_{i},\beta^{t}_{i}]
, such that
\mathcal{X}\subseteq\mathcal{B}_{s}
and
\mathcal{Y}\subseteq\mathcal{B}_{t}
, the boxes
\mathcal{B}_{s}
and
\mathcal{B}_{t}
can have varying degrees of intersection. Identifying and computing low-rank approximations of kernel matrices when the boxes
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are separated, is an important step in many kernel evaluation algorithms such as the fast multipole method and hierarchical matrices.

This paper tackles a slightly more general problem setting. In many applications, the behavior of a kernel function
\kappa
depends on several parameters (sometimes denoted
\boldsymbol{\theta}\in\Theta
) that influence its behavior and by extension the behavior of the corresponding kernel matrix. In these applications, often the kernel low-rank approximation must be computed efficiently for several instances of the parameters
\boldsymbol{\theta}
. More concretely, given a (parametric) kernel function
\kappa:\mathbb{R}^{d}\times\mathbb{R}^{d}\times\mathbb{R}^{d_{\theta}}\rightarrow\mathbb{R}
we define the corresponding parametric kernel matrix as

[\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})]_{i,j}=\kappa(\boldsymbol{x}_{i},\boldsymbol{y}_{j};{\boldsymbol{\theta}}),\qquad\boldsymbol{x}_{i}\in\mathcal{X},\quad\boldsymbol{y}_{j}\in\mathcal{Y},\quad\boldsymbol{\theta}\in\Theta,

(1)

for
1\leq i\leq N_{s}
and
1\leq j\leq N_{t}
. Similar to the source and target boxes, the parameter space
\Theta
is enclosed in a parameter box
\mathcal{B}_{\boldsymbol{\theta}}=\bigtimes_{i=1}^{d_{\theta}}[\alpha^{p}_{i},\beta^{p}_{i}]
. Our goal is to construct a parametric low-rank approximation of the form

\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})\approx\boldsymbol{SH}(\boldsymbol{\theta})\boldsymbol{T}^{\top},

(2)

where the matrices
\boldsymbol{S}\in\mathbb{R}^{N_{s}\times s}
and
\boldsymbol{T}\in\mathbb{R}^{N_{t}\times t}
represent the factor matrices corresponding to the source and target matrices respectively. Importantly, these factor matrices are independent of the parameter
\boldsymbol{\theta}
, and the parametric dependence only enters through the core matrix
\boldsymbol{H}(\boldsymbol{\theta})\in\mathbb{R}^{s\times t}
. We assume that the ranks satisfy
\max\{s,t\}\ll\min\{N_{s},N_{t}\}
. The advantage of this representation is clear if much of the computation can be offloaded to an offline stage, and the cost of evaluating
\boldsymbol{H}(\boldsymbol{\theta})
for a new parameter value in the online stage is much cheaper than evaluating the kernel matrix from scratch. A special but important case is when the kernel is symmetric (and perhaps positive definite) and the source and target points coincide. We refer to this as the
global
case, and the resulting low-rank approximation the
global low-rank approximation
.

There are several situations where such a (parametric) low-rank approximation is beneficial. In Gaussian processes, one has to optimize over the hyperparameters that define the kernel. This requires expensive evaluations of the kernel matrix, and perhaps additionally its derivatives with respect to the hyperparameters, at each step of the optimization routine. This similar situation also arises in hierarchical Bayesian inverse problems, where Gaussian processes are used to define the prior distributions, and there are additional hyperparameters to be determined
[
22
]
. The parametric low-rank representation (
2
) can be used instead of the kernel matrix in an outer loop computation, or can be used as a preconditioner to accelerate an iterative method (e.g., conjugate gradients) for the solution of the linear system involving the kernel matrix.

Our approach

At the heart of our approach is a multivariate Chebyshev interpolation of the function
f_{\kappa}:\mathbb{R}^{D}\rightarrow\mathbb{R}
where
D=2d+d_{\theta}
and is defined as

f_{\kappa}(\boldsymbol{\xi})=\kappa(\boldsymbol{x},\boldsymbol{y};{\boldsymbol{\theta}}),\qquad\boldsymbol{\xi}=(\boldsymbol{x},\boldsymbol{\theta},\boldsymbol{y}).

(3)

Note that the specific ordering of the variables is essential for our algorithm. For example, in a typical problem setting involving three spatial dimensions
d=3
and two parameter dimensions
d_{\theta}=2
, the resulting dimension
D=8
makes Chebyshev interpolation challenging. Consequently, a coefficient expansion of
n
points in each dimension gives a coefficient tensor of size
n^{D}
, which can be challenging to construct and store, for example, when
n=27
. To address this challenge, we further compress the coefficient tensor in the tensor train (TT) format without explicitly forming it first. This roughly comprises the offline stage. In the online stage, a small amount of work is needed independent of the number of source and target points, and new kernel evaluations are not required.

Contributions

The specific contributions and features of our work are as follows:

1.

We propose a new algorithm, Parametric Tensor Train Kernel (PTTK), that computes the low-rank approximation of parametric kernel matrices by combining multivariate Chebyshev interpolation with the TT-decomposition,

when the source and target points are either weakly or strongly admissible. Our algorithm involves a two-stage process, comprising an offline (pre-computation) stage and an online stage. A version of this algorithm also applies to non-parametric kernel low-rank approximations.

2.

We perform a detailed analysis of the cost involving computations and storage. The offline cost is linear in the number of source and target points (i.e., w.r.t.
N_{s}
and
N_{t}
). However, during the online stage, when a specific instance of
\boldsymbol{\theta}\in\Theta
is provided, the runtime becomes independent of
N_{s}
and
N_{t}
. The algorithms are accompanied by an analysis of the error.

3.

We adapt our algorithm to handle a global low-rank approximation where the source and target points coincide (i.e.,
\mathcal{X}=\mathcal{Y}
). If, additionally, the kernel matrix is symmetric and positive semi-definite, we adapt our approach to ensure these properties are retained by the low-rank approximation with a small additional cost in the online stage that does not affect the overall complexity.

4.

We demonstrate the efficiency of our methods on various non-parametric and parametric kernels with applications including multivariate interpolation, partial differential and integral equations, and Gaussian processes. For weakly or strongly admissible boxes, the algorithms can achieve moderate to high accuracy
10^{-5}-10^{-9}
, whereas for the global low-rank case the algorithms achieve low to moderate accuracy
10^{-2}-10^{-5}
depending on the smoothness of the kernels. We compare our implementation against other algorithms also with linear complexity, but our approach outperforms existing methods due to the low online time (up to
200\times
speedup).

5.

We propose a new method for initializing the index sets used in the tensor train greedy-cross algorithm that may be of independent interest beyond this paper.

We also note that the numerical experiments show good performance on problems up to
D=8
dimensions (three spatial and two parameter dimensions). Future work involves investigating the performance of the methods in higher dimensions. The code to reproduce the tables is located at
https://github.com/awkhan3/ParametricTensorTrainKernel
.

Related work

We discuss some related work for low-rank kernel approximations, but since this is a vast area, we limit ourselves to a few references to give some context.
We first consider the case of obtaining a low-rank approximation of a kernel matrix, that is not necessarily parametric. An optimal low-rank approximation, in an orthogonally invariant norm, can be computed using the truncated SVD. However, the cost of this method is prohibitively expensive for large values of
N_{s},N_{t}
since it involves forming the kernel matrix first and then compressing it. Approaches such as interpolatory decompositions and randomized SVD
[
21
]
can alleviate this computational cost, but are still very expensive. It is desirable to develop algorithms that have linear dependence on
N_{s}
and
N_{t}
. In this category, there are certain versions of Adaptive Cross Approximation (ACA)
[
2
,
3
]
, black-box fast multipole method
[
15
]
, and Nyström approximation
[
7
]
. Certain analytic techniques such as multipole expansions
[
18
]
, Taylor expansions, equivalent densities
[
45
]
, and proxy point method
[
44
]
. For the global case, and for kernels that define positive semi-definite matrices there are various techniques such as Nyström’s method
[
43
]
, random Fourier features
[
35
,
1
]
, and randomly pivoted Cholesky
[
10
]
. There is also the hybrid cross-approximation method
[
6
]
, which uses polynomial interpolation to obtain a first approximation and then uses a cross-approximation technique to obtain the final low-rank approximation.

To our knowledge, the parametric case has been addressed only in a handful of papers
[
36
,
14
,
26
]
specifically for kernel matrices. In
[
25
,
32
]
, the authors treat the more general case of parameter-dependent low-rank approximations. We now discuss the relationship between our work and the above references for kernel matrices. The closest work to the present paper is
[
36
]
, which also uses a multivariate Chebyshev expansion followed by a compression of the coefficient tensor using Tucker decomposition. The main differences with the above approach are that (1) we use the TT-decompsition, which can potentially scale to higher dimensions than the Tucker decomposition (2) we use the TT-cross approximation, which avoids forming the tensor explicitly. As in
[
36
]
, our approach also has linear cost in
N_{s}
and
N_{t}
but has a more favorable computational complexity with respect to the number of Chebyshev points and the dimensions. Our work is also related to
[
40
]
, which does not deal specifically with kernel approximations but develops algorithms for high-dimensional function approximation.

In
[
26
]
, obtaining a low-rank approximation of a parametric kernel matrix that is symmetric and positive semi-definite is done by applying ACA to an affine linear expansion of
\boldsymbol{K}(\mathcal{X},\mathcal{X};\boldsymbol{\theta})
w.r.t.
\boldsymbol{\theta}
, and this affine linear expansion is obtained through the empirical interpolation method. The goal is to use precomputation (offline stage) to obtain a low-rank factorization of the parametric kernel matrix where each factor depends on
\boldsymbol{\theta}
; hence, the online time of the proposed method is dependent on
N_{s}
and
N_{t}
. Our method is not constrained to the global symmetric case and has a more efficient online stage.

In
[
14
]
, a shift-invariant kernel is expressed in terms of a feature map, as a consequence of Bochner’s Theorem, and a Gauss-Legendre quadrature-based approach is used that gives a low-rank approximation in the form of (
2
).
As with our proposed algorithm, the online time does not depend on
N_{s}
nor
N_{t}
. However, as in
[
36
]
, the method has an exponential dependence on the number of features and is expensive for even modest dimensions. Furthermore, it also appears to be constrained to the global symmetric case and requires explicit knowledge of the feature map; our method does not suffer from these issues since it only relies on kernel evaluations.

2.1
Matrix Operations

In this section, we define some matrix operations that will come in handy when dealing with tensors. Consider two arbitrary matrices
\boldsymbol{G}\in\mathbb{R}^{s\times m}
and
\boldsymbol{H}\in\mathbb{R}^{p\times k}
.
We define the Kronecker product
\boldsymbol{G}\otimes\boldsymbol{H}

to be a
\mathbb{R}^{sp\times mk}
block matrix:

\boldsymbol{G}\otimes\boldsymbol{H}=\begin{bmatrix}g_{1,1}\boldsymbol{H}&g_{1,2}\boldsymbol{H}&\cdots&g_{1,m-1}\boldsymbol{H}&g_{1,m}\boldsymbol{H}\\
g_{2,1}\boldsymbol{H}&g_{2,2}\boldsymbol{H}&\cdots&g_{2,m-1}\boldsymbol{H}&g_{2,m}\boldsymbol{H}\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
g_{s,1}\boldsymbol{H}&g_{s,2}\boldsymbol{H}&\cdots&g_{s,m-1}\boldsymbol{H}&g_{s,m}\boldsymbol{H}\\
\end{bmatrix}.

We now define matrices
\boldsymbol{A}\in\mathbb{R}^{s\times q},\boldsymbol{B}\in\mathbb{R}^{p\times q}
. We denote the symbol
\rtimes
as the Khatri-Rao product, which we define as

\displaystyle\boldsymbol{A}\rtimes\boldsymbol{B}

\displaystyle=\left[\begin{array}[]{ c | c | c | c}\boldsymbol{a}_{1}\otimes\boldsymbol{b}_{1}&\boldsymbol{a}_{2}\otimes\boldsymbol{b}_{2}&\dots&\boldsymbol{a}_{q}\otimes\boldsymbol{b}_{q}\end{array}\right]\in\mathbb{R}^{sp\times q}

where
\boldsymbol{a}_{i}
and
\boldsymbol{b}_{i}
are the column vectors of matrices
\boldsymbol{A}
and
\boldsymbol{B}
, for
1\leq i\leq q
, respectively. We denote the symbol
\ltimes
as the face-splitting product, also referred to as the transposed Khatri-Rao product, which we define in terms of the Khatri-Rao product:

\boldsymbol{A}^{\top}\ltimes\boldsymbol{B}^{\top}=(\boldsymbol{A}\rtimes\boldsymbol{B})^{\top}.

Lastly, both the face-splitting product and Khatri-Rao product satisfy some mixed-product properties with the Kronecker product

\displaystyle(\mathbf{G}^{\top}\otimes\mathbf{H}^{\top})(\mathbf{A}\rtimes\mathbf{B})=(\mathbf{G}^{\top}\mathbf{A})\rtimes(\mathbf{H}^{\top}\mathbf{B}),

(4)

\displaystyle(\mathbf{A}^{\top}\ltimes\mathbf{B}^{\top})(\mathbf{G}\otimes\mathbf{H})=(\mathbf{A}^{\top}\mathbf{G})\ltimes(\mathbf{B}^{\top}\mathbf{H}).

2.2
Tensor Basics

We define a tensor
\boldsymbol{\mathcal{X}}\in\mathbb{R}^{n_{1}\times n_{2}\times\dots\times n_{N}}
for
N\in\mathbb{N}
as a multi-dimensional array. Indexing into a tensor
\boldsymbol{\mathcal{X}}
is represented by
x_{i_{1},i_{2},\dots,i_{N}}
or alternatively
[\boldsymbol{\mathcal{X}}]_{i_{1},\dots,i_{N}}
, where each index
i_{j}
ranges from
1
to
n_{j}
for
1\leq j\leq N
. We define the Chebyshev norm of
\boldsymbol{\mathcal{X}}
as

\|\boldsymbol{\mathcal{X}}\|_{C}=\max_{i_{1},\dots,i_{N}}|x_{i_{1},i_{2},\dots,i_{N}}|.

Similarly, the Frobenius norm of a tensor
\boldsymbol{\mathcal{X}}
is defined as the square root of the sum of squares of all the entries and is given by the formula

\|\boldsymbol{\mathcal{X}}\|_{F}=\sqrt{\sum_{i_{1}=1}^{n_{1}}\dots\sum_{i_{N}=1}^{n_{N}}|x_{i_{1},i_{2},\dots,i_{N}}|^{2}}.

We now describe the mode-k product that will be used in this paper. For a matrix,
\boldsymbol{A}\in\mathbb{R}^{m\times n_{k}}
, one can define the mode-
k
product of
\boldsymbol{\mathcal{X}}
w.r.t.
\boldsymbol{A}
as

\boldsymbol{\mathcal{Y}}=\boldsymbol{\mathcal{X}}\times_{k}\boldsymbol{A}
where the tensor
\boldsymbol{\mathcal{Y}}
has entries

y_{i_{1},\dots,i_{k-1},j,i_{k+1},\dots,i_{N}}=\sum^{n_{k}}_{i_{k}=1}x_{i_{1},\dots,i_{d}}a_{j,i_{k}},\qquad 1\leq j\leq m.

Let
(i_{1},i_{2},\dots i_{j})
be an arbitrary multi-index for
1\leq j\leq N
where
1\leq i_{j}\leq n_{j}
, and we denote
\overline{i_{1},i_{2},\dots,i_{j}}
to be the little endian flattening of the multi-index into a single index defined by the formula

\overline{i_{1},i_{2},\dots,i_{j}}=i_{1}+(i_{2}-1)n_{1}+(i_{3}-1)n_{1}n_{2}+\ldots+(i_{j}-1)n_{1}n_{2}\ldots n_{j-1}.

We can now define the tensor unfolding matrix
\boldsymbol{X}^{\{j\}}
of size
\prod^{j}_{i=1}n_{i}\times\prod_{i=j+1}^{N}n_{i}
whose entries are given by

[\boldsymbol{X}^{\{j\}}]_{\overline{i_{1},\dots,i_{j}},\overline{i_{j+1},\dots,i_{N}}}=x_{i_{1},i_{2},\dots,i_{N-1},i_{N}},\quad 1\leq i_{j}\leq n_{j},1\leq j\leq N.

We can also define the tensor unfolding matrix through MATLAB’s reshape command

\boldsymbol{X}^{\{j\}}=\textrm{reshape}(\boldsymbol{\mathcal{X}},\prod_{i=1}^{j}n_{i},\prod_{i=j+1}^{N}n_{i}),\qquad 1\leq j\leq N.

Lastly, considering an arbitrary matrix
\boldsymbol{A}\in\mathbb{R}^{m\times k}
, we now define the twist tensors
\boldsymbol{\mathcal{T}}^{(1)}(\boldsymbol{A})\in\mathbb{R}^{1\times m\times k}
,
\boldsymbol{\mathcal{T}}^{(2)}(\boldsymbol{A})\in\mathbb{R}^{m\times 1\times k}
and
\boldsymbol{\mathcal{T}}^{(3)}(\boldsymbol{A})\in\mathbb{R}^{m\times k\times 1}
of
\boldsymbol{A}
as the tensors with entries

[\boldsymbol{\mathcal{T}}^{(1)}(\boldsymbol{A})]_{1,i,j}=a_{i,j},\quad[\boldsymbol{\mathcal{T}}^{(2)}(\boldsymbol{A})]_{i,1,j}=a_{i,j},\textrm{ and }\quad[\boldsymbol{\mathcal{T}}^{(3)}(\boldsymbol{A})]_{i,j,1}=a_{i,j},

(5)

for
1\leq i\leq m
and
1\leq j\leq k
.

2.4
Multivariate Chebyshev Interpolation

We review some background on multivariate Chebyshev interpolation. We define
T_{k}(x)=\cos(k\cos^{-1}(x))
to be the Chebyshev polynomial of the first kind of degree
k
, and we then define an invertible linear map,
\varphi_{[\alpha,\beta]}:[-1,1]\rightarrow[\alpha,\beta]
that maps the Chebyshev nodes of the first kind on an interval
[-1,1]
to the interval
[\alpha,\beta]
as follows:

\varphi_{[\alpha,\beta]}(x)=\frac{\alpha-\beta}{2}x+\frac{\alpha+\beta}{2}.

We begin by selecting Chebyshev nodes
\{\zeta_{j}\}_{j=1}^{n}
within the interval
[-1,1]
corresponding to the roots of the Chebyshev polynomial
T_{n}(x)
. Next, we define
\eta_{i}=\varphi_{[a,b]}(\zeta_{i})
for
1\leq i\leq n
.
We then define the basis polynomial
\phi^{[a,b]}(\eta_{i},\cdot)
on the interval
[a,b]
as

\phi^{[a,b]}(\eta_{i},x)=\frac{1}{n}+\frac{2}{n}\sum^{n-1}_{k=1}T_{k}(\varphi^{-1}_{[a,b]}(\eta_{i}))T_{k}(\varphi^{-1}_{[a,b]}(x)).

(7)

The interpolating properties of the basis polynomial with respect to the Chebyshev nodes
\{\eta_{i}\}_{i=1}^{n}
are demonstrated in the proof of Lemma
1
. In particular, we show
\phi^{[a,b]}(\eta_{i},\eta_{j})=\delta_{i,j}
for
1\leq i,j\leq n
. We can now use (
7
) to define a degree
n-1
polynomial that interpolates a function
g:[a,b]\rightarrow\mathbb{R}
on the nodes
\eta_{1},\eta_{2},\dots,\eta_{n}
as

\pi_{n-1}(x)=\sum^{n}_{i=1}g(\eta_{i})\phi^{[a,b]}(\eta_{i},x).

(8)

This result is perhaps well-known in the literature; here, we restate it so that it will be useful for the later discussion.

Lemma 1
.

Let
\zeta_{1},\zeta_{2},\dots,\zeta_{n}
be the
n
Chebyshev nodes of the first kind in the interval
[-1,1]
. Then

\max_{x\in[-1,1]}\sum^{n}_{k=1}|\phi^{[-1,1]}(\zeta_{k},x)|\leq\lambda_{n-1}\leq\frac{2}{\pi}\log(n)+1,

where
\lambda_{n-1}
is the Lebesgue constant; see
[
41
, Theorem 15.2]
.

Proof.

For
1\leq i\leq n
define the indicator function
\mathbf{1}_{\zeta_{i}}:[-1,1]\rightarrow\mathbb{R}
such that

\mathbf{1}_{\zeta_{i}}(t)=\begin{cases}1&\text{if }t=\zeta_{i}\\
0&\text{otherwise}.\end{cases}

The basis functions
\{\phi^{[-1,1]}(\zeta_{i},x)\}_{i=1}^{n}
are interpolants for the nodes
\{\zeta_{i}\}_{i=1}^{n}
which follows from
[
28
, Theorem
6.7]
.
Let
i
be an arbitrary integer such that
1\leq i\leq n
, we can write the interpolant of
\mathbf{1}_{\zeta_{i}}
in two different bases as

\sum^{n}_{k=1}\mathbf{1}_{\zeta_{i}}(\zeta_{k})\phi^{[-1,1]}(\zeta_{k},x)=\sum^{n}_{k=1}\mathbf{1}_{\zeta_{i}}(\zeta_{k})\ell_{k}(x),

where
\{\ell_{k}\}_{k=1}^{n}
are the Lagrange basis polynomials defined on the Chebyshev nodes
\zeta_{1},\zeta_{2},\dots,\zeta_{n}
. Since both bases are polynomials of degree
n-1
with the same roots, by the fundamental theorem of algebra, they must be the same, i.e.,

\phi^{[-1,1]}(\zeta_{i},x)=\ell_{i}(x),\quad\forall x\in\mathbb{R},\>1\leq i\leq n.

We now obtain our desired bound:

\max_{x\in[-1,1]}\sum^{n}_{k=1}|\phi^{[-1,1]}(\zeta_{k},x)|\leq\max_{x\in[-1,1]}\sum^{n}_{k=1}|\ell_{k}(x)|\leq\lambda_{n-1}\leq\frac{2}{\pi}\log(n)+1.

This completes the proof.

Multivariate approximation

For ease of notation, we define

(\alpha_{j},\beta_{j})=\left\{\begin{array}[]{ll}(\alpha_{j}^{s},\beta_{j}^{s})&1\leq j\leq d\\
(\alpha_{j-d}^{p},\beta_{j-d}^{p})&d+1\leq j\leq d+d_{\theta}\\
(\alpha^{t}_{j-d+d_{\theta}},\beta^{t}_{j-d+d_{\theta}})&d+d_{\theta}+1\leq j\leq D.\end{array}\right.\qquad

(9)

Given the Chebyshev nodes
\{\zeta_{i}\}_{i=1}^{n}
, we define the set of interpolating points
\{\eta_{i}^{(j)}\}_{i=1}^{n}
for
1\leq j\leq D
as

\eta^{(j)}_{i}=\varphi_{[\alpha_{j},\beta_{j}]}(\zeta_{i}).

(10)

We now consider a multivariate Chebyshev approximation of
f_{\kappa}
(
3
) of the form

f_{\kappa}(\boldsymbol{\xi})\approx\sum_{i_{1}=1}^{n}\dots\sum^{n}_{i_{D}=1}m_{i_{1},i_{2},\dots,i_{D}}\prod^{D}_{j=1}\phi^{[\alpha_{j},\beta_{j}]}(\eta^{(j)}_{i_{j}},\xi_{j}),

(11)

where
\boldsymbol{\mathcal{M}}\in\mathbb{R}^{n\times\dots\times n}
is a
D
dimensional coefficient tensor with each mode size
n
with entries

m_{i_{1},i_{2},\dots,i_{D}}=f_{\kappa}(\boldsymbol{\eta}),\quad\boldsymbol{\eta}=(\eta^{(1)}_{i_{1}},\eta^{(2)}_{i_{2}},\dots,\eta^{(D)}_{i_{D}}),\qquad 1\leq i_{j}\leq n,1\leq j\leq D.

Tensor notation

We express the same function approximation using tensor notation. Let
\boldsymbol{x}=(x_{1},\dots,x_{d})\in\mathcal{X}
and
\boldsymbol{y}=(y_{1},\dots,y_{d})\in\mathcal{Y}
represent arbitrary points from the source and target set. We define the vectorized source and target polynomials,
\boldsymbol{q}^{s}_{i}
and
\boldsymbol{q}^{t}_{i}
, for
1\leq i\leq d
as

\displaystyle\boldsymbol{q}^{s}_{i}(x_{i})=

\displaystyle\begin{bmatrix}\phi^{[\alpha^{s}_{i},\beta^{s}_{i}]}(\eta^{(i)}_{1},x_{i})&\dots&\phi^{[\alpha^{s}_{i},\beta^{s}_{i}]}(\eta^{(i)}_{n},x_{i})\end{bmatrix}\in\mathbb{R}^{1\times n},

(12)

\displaystyle\boldsymbol{q}^{t}_{i}(y_{i})=

\displaystyle\begin{bmatrix}\phi^{[\alpha^{t}_{i},\beta^{t}_{i}]}(\eta^{(d+d_{\theta}+i)}_{1},y_{i})&\dots&\phi^{[\alpha^{t}_{i},\beta^{t}_{i}]}(\eta^{(d+d_{\theta}+i)}_{n},y_{i})\end{bmatrix}\in\mathbb{R}^{1\times n}.

Let
\boldsymbol{\theta}=(\theta_{1},\theta_{2},\dots,\theta_{d_{\theta}})\in\Theta
, and we define the vectorized polynomial that encodes points in the parameter space as

\boldsymbol{q}^{p}_{i}(\theta_{i})=\begin{bmatrix}\phi^{[\alpha^{p}_{i},\beta^{p}_{i}]}(\eta^{(d+i)}_{1},\theta_{i})&\dots&\phi^{[\alpha^{p}_{i},\beta^{p}_{i}]}(\eta^{(d+i)}_{n},\theta_{i})\end{bmatrix}\in\mathbb{R}^{1\times n},

(13)

for
1\leq i\leq d_{\theta}
. With the notation we have established so far, (
11
) can now be rewritten as

f_{\kappa}(\boldsymbol{\xi})\approx\boldsymbol{\mathcal{M}}\times_{i=1}^{d}\boldsymbol{q}_{i}^{s}(\xi_{i})\times_{i=d+1}^{d+d_{\theta}}\boldsymbol{q}^{p}_{i-d}(\xi_{i})\times_{i=d+d_{\theta}+1}^{D}\boldsymbol{q}_{i-(d+d_{\theta})}^{t}(\xi_{i}).

(14)

We now discuss how the Chebyshev interpolation of the function
f_{\kappa}
translates to a parametric low-rank approximation of the kernel matrix. To this end, we follow the approach in
[
15
,
36
]
which we now summarize.

Parametric low-rank approximation

We now define the factor matrices for the source and target points. The source factor matrices
\boldsymbol{U}_{1},\dots,\boldsymbol{U}_{d}\in\mathbb{R}^{N_{s}\times n}
and the target factor matrices
\boldsymbol{V}_{1},\dots,\boldsymbol{V}_{d}\in\mathbb{R}^{N_{t}\times n}
are defined as

\boldsymbol{U}_{i}=\begin{pmatrix}\boldsymbol{q}^{s}_{i}([\boldsymbol{x}_{1}]_{i})\\
\vdots\\
\boldsymbol{q}^{s}_{i}([\boldsymbol{x}_{N_{s}}]_{i})\end{pmatrix},\quad\boldsymbol{V}_{i}=\begin{pmatrix}\boldsymbol{q}^{t}_{i}([\boldsymbol{y}_{1}]_{i})\\
\vdots\\
\boldsymbol{q}^{t}_{i}([\boldsymbol{y}_{N_{t}}]_{i})\end{pmatrix}\qquad\textrm{for }\>1\leq i\leq d.

(15)

We now introduce the source matrix
\boldsymbol{F}_{s}\in\mathbb{R}^{N_{s}\times n^{d}}
and the target matrix
\boldsymbol{F}_{t}\in\mathbb{R}^{N_{t}\times n^{d}}
defined as follows using the face-splitting product

\boldsymbol{F}_{s}=\boldsymbol{U}_{d}\ltimes\boldsymbol{U}_{d-1}\ltimes\ldots\ltimes\boldsymbol{U}_{1},\qquad\boldsymbol{F}_{t}=\boldsymbol{V}_{d}\ltimes\boldsymbol{V}_{d-1}\ltimes\ldots\ltimes\boldsymbol{V}_{1}.

(16)

It should be noted that the matrices
\boldsymbol{F}_{s}
and
\boldsymbol{F}_{t}
are not formed explicitly in our calculations, and we only need to store the factor matrices
\{\boldsymbol{U}_{j},\boldsymbol{V}_{j}\}_{j=1}^{d}
.
We define the parametric tensor
\boldsymbol{\mathcal{M}}_{F}(\boldsymbol{\theta})
to be

\boldsymbol{\mathcal{M}}_{F}(\boldsymbol{\theta})=\boldsymbol{\mathcal{M}}\times_{i=d+1}^{d+d_{\theta}}\boldsymbol{q}^{p}_{i-d}(\theta_{i-d}).

(17)

We are now able to iterate over the source and target points in conjunction with (
14
), resulting in the approximation
[
36
, Section 4]

\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})\approx\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}.

(18)

This approximation is of the form (
2
) but is not feasible for practical scenarios. Observing that the tensor
\boldsymbol{\mathcal{M}}
contains
n^{D}
elements, it should be noted that in practical scenarios, the value of
n^{D}
can often become quite large, potentially larger than the product
N_{s}N_{t}
. In such a situation,
\boldsymbol{K}(\mathcal{X},\mathcal{Y};\boldsymbol{\theta})
cannot be considered to be low-rank. The Tucker approach proposed in
[
36
]
further compresses the core tensor
\boldsymbol{\mathcal{M}}
, but it is computationally expensive even for
d=3
and
d_{\theta}=2
, since
D=8
. To deal with this challenge, we further compress the tensor
\boldsymbol{\mathcal{M}}
using the TT format.

3
Parametric TT Kernel (PTTK) Approximation

In this section, we present the PTTK method for parametric low-rank approximations. The algorithm is split into two stages, an offline stage which is independent of a specific value of
\boldsymbol{\theta}
, and an online stage in which the low-rank approximation is instantiated for a specific value of
\bar{\boldsymbol{\theta}}
. In Section
3.1
, we go over the details of the PTTK method by first discussing the offline stage and then the online stage. In Section
3.2
, we discuss the computational and storage cost associated with the PTTK method, the main point being the computational cost of the offline stage is linear in
N_{s}
and
N_{t}
while the computational cost of the online stage is independent of
N_{s}
and
N_{t}
. In Section
3.3
, we derive an error bound for the low-rank approximation to an arbitrary parametric kernel matrix in terms of the error of the TT-cross approximation and multivariate polynomial interpolation. In Section
3.4
, we discuss the error bound given in the previous section, introduce the concept of admissibility, and discuss the smoothness of
f_{\kappa}
within the context of the spatial configuration of
\mathcal{B}_{s}
and
\mathcal{B}_{t}
. Lastly, in Section
3.5
, we discuss how to apply our PTTK method to the global case (
\mathcal{X}=\mathcal{Y}
), where the parametric kernel function is also symmetric and positive definite, and it is desirable to preserve these properties in the approximation.

3.1
Main algorithm

The algorithm has two stages: an offline stage where a majority of the computations are conducted and is applicable to the entire parameter range
\Theta
, and an online stage where the computations are focused on a specific parameter
\bar{\boldsymbol{\theta}}
.

The offline stage

In the offline stage, there are four phases. In Phase 1, we compute the Chebyshev approximation of the function
f_{\kappa}:\mathbb{R}^{D}\rightarrow\mathbb{R}
(here
D=2d+d_{\theta}
) and the factor matrices
\{\boldsymbol{U}_{j}\}_{j=1}^{d}
,
\{\boldsymbol{V}_{j}\}_{j=1}^{d}
that define the source matrix
\boldsymbol{F}_{s}
and the target matrix
\boldsymbol{F}_{t}
, respectively.

In Phase 2, we now compute a TT approximation to the coefficient tensor
\boldsymbol{\mathcal{M}}
, defined in the previous section, by applying the TT greedy-cross algorithm (Algorithm
7
) on the function
f_{\kappa}
which defines the entries of the tensor
\boldsymbol{\mathcal{M}}
. We now obtain the following TT approximation

\boldsymbol{\mathcal{M}}\approx\widehat{\boldsymbol{\mathcal{M}}}\equiv[\boldsymbol{\mathcal{G}}_{1},\boldsymbol{\mathcal{G}}_{2},\dots,\boldsymbol{\mathcal{G}}_{D}],

where
\boldsymbol{\mathcal{G}}_{i}\in\mathbb{R}^{r_{i-1}\times n\times r_{i}}
for
1\leq i\leq D
with the convention
r_{0}=r_{D}=1
.
The ranks of
\widehat{\boldsymbol{\mathcal{M}}}
depend on the properties of
f_{\kappa}
such as smoothness, behavior of its derivatives, the domain on which it is defined, etc.
For more details we refer to Section
3.4
. Let
\boldsymbol{\theta}\in\Theta
, and we now define the matrix
\boldsymbol{H}(\boldsymbol{\theta})\in\mathbb{R}^{r_{d}\times r_{d+d_{\theta}}}
as

\boldsymbol{H}(\boldsymbol{\theta})\equiv\boldsymbol{H}_{1}(\theta_{1})\cdots\boldsymbol{H}_{d_{\theta}}(\theta_{d_{\theta}})\qquad\text{where}\quad\boldsymbol{H}_{j}(\theta_{j})\equiv\boldsymbol{\mathcal{G}}_{d+j}\times_{2}\boldsymbol{q}^{p}_{j}(\theta_{j}).

(19)

Observe that we can obtain a TT-decomposition of the tensor
\widehat{\boldsymbol{\mathcal{M}}}_{F}(\boldsymbol{\theta})
in terms of the TT-cores of
\widehat{\boldsymbol{\mathcal{M}}}
as

\widehat{\boldsymbol{\mathcal{M}}}_{F}(\boldsymbol{\theta})=[\boldsymbol{\mathcal{G}}_{1},\dots,\boldsymbol{\mathcal{G}}_{d},\boldsymbol{\mathcal{T}}^{(2)}(\boldsymbol{H}(\boldsymbol{\theta})),\boldsymbol{\mathcal{G}}_{d+d_{\theta}+1},\dots,\boldsymbol{\mathcal{G}}_{D}].

(20)

Here
\boldsymbol{\mathcal{T}}^{(\cdot)}(\cdot)
is a twisting tensor function defined in (
5

(\boldsymbol{\mathcal{T}}^{(2)}(\boldsymbol{H}(\boldsymbol{\theta})))^{\{1\}}=\boldsymbol{H}(\boldsymbol{\theta})
and the term represents a degenerate tensor (matrix). We now use unfolding formula (
6

\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})
in terms of the cores of the tensor

\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})=\boldsymbol{L}\boldsymbol{H}(\boldsymbol{\theta})\boldsymbol{R}^{\top},

where the matrices
\boldsymbol{L}
and
\boldsymbol{R}
are defined implicitly by the formulas (see (

\boldsymbol{L}=\prod_{i=1}^{d-1}(\boldsymbol{I}_{n^{d-i}}\otimes\boldsymbol{G}^{\{2\}}_{i})\boldsymbol{G}^{\{2\}}_{d},\qquad\boldsymbol{R}^{\top}=\boldsymbol{G}^{\{1\}}_{d+d_{\theta}+1}\prod_{i=1}^{d-1}(\boldsymbol{G}^{\{1\}}_{d+d_{\theta}+1+i}\otimes\boldsymbol{I}_{n^{i}}).

An important point is that the matrices
\boldsymbol{L}
and
\boldsymbol{R}
are not formed explicitly. The summary of the story so far is

\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})\approx\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\approx(\boldsymbol{F}_{s}\boldsymbol{L})\boldsymbol{H}(\boldsymbol{\theta})(\boldsymbol{F}_{t}\boldsymbol{R})^{\top}.

3.2
Computational and Storage Cost

We now give details on the computational and storage costs of Algorithms
2
and
3
.

Computational Cost

Let us first consider the computational cost of the offline stage, as described in Algorithm
2
. Forming the factor matrices
\boldsymbol{U}_{j}
and
\boldsymbol{V}_{j}
for each
j
requires
\mathcal{O}(n^{2}(N_{s}+N_{t}))
flops since it requires
\mathcal{O}(n^{2})
flops to evaluate a vectorized polynomial at a point. In all there are
2d
factor matrices for an overall cost of
\mathcal{O}(n^{2}d(N_{s}+N_{t}))
flops. In Phase 2, the computational cost of Algorithm
7
is
\mathcal{O}(Dnr^{3})
flops and
\mathcal{O}(Dnr^{2})
kernel evaluations. With an additional cost of
\mathcal{O}(Dn^{2})
kernel evaluations and
\mathcal{O}(Dn^{2})
flops for the initialization (Algorithm
8
). Recall that
r
is the maximum rank of the TT approximation. In Phase 3, forming the products
(\boldsymbol{U}_{i}\ltimes\boldsymbol{S})\boldsymbol{G}_{i}^{\{2\}}
and
\boldsymbol{G}_{D-i}^{\{1\}}(\boldsymbol{T}\rtimes\boldsymbol{V}_{d-i}^{\top})
for each
i
requires
\mathcal{O}((N_{s}+N_{t})nr^{2})
flops, so the total computational cost of Phase 3 is
\mathcal{O}((N_{s}+N_{t})dnr^{2})
flops. Lastly, Phase 4 requires applying TT rounding (Algorithm
1
) to the TT tensor,

[\boldsymbol{\mathcal{T}}^{(1)}({\boldsymbol{S}}),\boldsymbol{\mathcal{G}}_{d+1},\dots,\boldsymbol{\mathcal{G}}_{d+d_{\theta}},\boldsymbol{\mathcal{T}}^{(3)}(\boldsymbol{T}^{\top})],

which requires
\mathcal{O}(d_{\theta}nr^{3}+N_{s}r^{2}+N_{t}r^{2})
flops. We now consider the computational cost of the online stage, as described in Algorithm
3
. Evaluating the
d_{\theta}
vectorized parametric polynomials at a point requires
\mathcal{O}(d_{\theta}n^{2})
flops. Performing a mode-2 contraction with tensors
\boldsymbol{\mathcal{G}}_{d+i}
for
1\leq i\leq d_{\theta}
and a
n
dimensional vectorized parametric polynomial requires
\mathcal{O}(nr^{2})
flops, and mode-2 contraction must be performed
d_{\theta}
times, which gives us an overall computational cost of
\mathcal{O}(d_{\theta}(nr^{2}+n^{2}))
flops. Then forming the matrix
\widehat{\boldsymbol{H}}
requires
\mathcal{O}(d_{\theta}r^{3})
flops. The overall computational cost for the offline stage is
\mathcal{O}(d(nr^{2}+n^{2})(N_{s}+N_{t})+Dnr^{3}+Dn^{2})
flops and
\mathcal{O}(Dn^{2}+Dnr^{2})
kernel evaluations. The overall computation cost for the online stage is

\mathcal{O}(d_{\theta}(n^{2}+nr^{2}+r^{3}))
flops. An important point here is that only the offline stage requires kernel evaluations and has a computational cost dependent on
N_{s}
and
N_{t}
; the cost of the online stage does not have any dependence on
N_{s}
and
N_{t}
.

Storage Cost

The storage cost of our PTTK method is determined by the cost to store the matrices
\boldsymbol{S},\boldsymbol{T}
and TT-cores
\{\boldsymbol{\mathcal{G}}_{d+1},\boldsymbol{\mathcal{G}}_{d+2},\dots,\boldsymbol{\mathcal{G}}_{d+d_{\theta}}\}
. Therefore, the storage cost of our PTTK method is

N_{s}r_{d}+N_{t}r_{d+d_{\theta}}+\sum_{j=1}^{d_{\theta}}nr_{d+j-1}r_{d+j}
floating point numbers.

3.3
Error analysis

There are two sources of error in the PTTK approximation: the error due to the Chebyshev approximation and the error due to the TT approximation. We make assumptions on the smoothness of
f_{\kappa}
(see (
3
)) and the error in the TT approximation. Let
\Xi=\mathcal{B}_{s}\times\Theta\times\mathcal{B}_{t}\subset\mathbb{R}^{D}
be the domain of
f_{\kappa}
, which we can write as the hypercube
\Xi=\bigtimes_{i=1}^{D}[\alpha_{i},\beta_{i}]
, and we define

\textrm{diam}_{\infty}(\Xi)\equiv\max\{\beta_{i}-\alpha_{i}:1\leq i\leq D\}.

We assume
f_{\kappa}\in C^{\infty}(\Xi)
, and there exist
C_{f}\geq 0,\gamma_{f}>0
, and
\sigma\in\mathbb{N}
such that the following bound

\sup_{\boldsymbol{x}\in\Xi}|\partial^{v}_{i}f_{\kappa}(\boldsymbol{x})|\leq\frac{C_{f}(v+\sigma-1)!}{\gamma_{f}^{v}(\sigma-1)!}\quad\textrm{holds for all integers }1\leq i\leq D,v\geq 0.

(21)

Additionally, for integers
k\geq 1
we define the following term

E(k)\equiv 2eDC_{f}(\lambda_{k-1}+1)^{D}(k+1)^{\sigma}\left(1+\frac{\textrm{diam}_{\infty}(\Xi)}{\gamma_{f}}\right)\varsigma\left(\frac{2\gamma_{f}}{\textrm{diam}_{\infty}(\Xi)}\right)^{-k}

where the function
\varsigma
is defined to be
\varsigma:r\mapsto r+\sqrt{1+r^{2}}
.

Proposition 2
.

Consider the notation and assumptions established in this section. The error in the PTTK approximation satisfies

\max_{\theta\in\Theta}\|\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})-\boldsymbol{S}\boldsymbol{H}(\boldsymbol{\theta})\boldsymbol{T}^{\top}\|_{C}\leq E(n)+\lambda_{n-1}^{D}\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C},

where
\widehat{\boldsymbol{\mathcal{M}}}
is the TT approximation of
\boldsymbol{\mathcal{M}}
. Recall
\lambda_{n-1}
indicates the Lebesgue constant of the Chebyshev nodes.

In the bound above, the error has two components
E(n)
which represents the error in the Chebyshev approximation and the second term
\lambda_{n-1}^{D}\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C}
that represents the error in the TT approximation which is amplified by the interpolation through the factor
\lambda_{n-1}^{D}
. The factor
E(n)
shows exponential decay with the number of Chebyshev points
n
, whereas the factor
\lambda_{n-1}^{D}
shows polylogarithmic growth in
n
.

Proof of Proposition
2
.

Using the expression
\boldsymbol{SH}(\boldsymbol{\theta})\boldsymbol{T}^{\top}=\boldsymbol{F}_{s}\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}
and the triangle inequality, we obtain

\displaystyle\|\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})-\boldsymbol{SH}(\boldsymbol{\theta})\boldsymbol{T}^{\top}\|_{C}\leq

\displaystyle\underbrace{\|\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})-\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\|_{C}}_{\equiv\alpha}~+

(22)

\displaystyle\underbrace{\|\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}-\boldsymbol{F}_{s}\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\|_{C}}_{\equiv\beta}.

We deal with both the terms separately.

We tackle the first term
\alpha
. By the assumptions on
f_{\kappa}
and as a consequence of Corollary 4.21 in
[
5
]
, the error in the Chebyshev norm satisfies

\max_{\boldsymbol{\theta}\in\Theta}\|\boldsymbol{K}(\mathcal{X},\mathcal{Y};{\boldsymbol{\theta}})-\boldsymbol{F}_{s}\boldsymbol{M}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\|_{C}\leq E(n).

(23)

We tackle the second term
\beta
. Fix a point
\boldsymbol{\xi}=(\boldsymbol{x},\boldsymbol{\theta},\boldsymbol{y})\in\mathcal{X}\times\Theta\times\mathcal{Y}
at which the Chebyshev norm of the term
\beta
is acquired. For this point
\boldsymbol{\xi}
, the corresponding entry of
\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}
can be expressed as
\boldsymbol{\mathcal{M}}\times_{j=1}^{D}\boldsymbol{\phi}_{j}(\xi_{j})
, where the vectors of polynomials
\boldsymbol{\phi}_{j}(\cdot)
are defined as (see (
12
) and (
13

\boldsymbol{\phi}_{j}(\xi_{j})=\left\{\begin{array}[]{cc}\boldsymbol{q}_{j}^{s}(\xi_{j})&1\leq j\leq d\\
\boldsymbol{q}_{j-d}^{p}(\xi_{j})&d+1\leq j\leq d+d_{\theta}\\
\boldsymbol{q}^{t}_{j-(d+d_{\theta})}(\xi_{j})&d+d_{\theta}+1\leq j\leq D.\end{array}\right.

Similarly, with the notation just defined, the corresponding entry of
\boldsymbol{F}_{s}\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}
can be expressed as
\widehat{\boldsymbol{\mathcal{M}}}\times_{j=1}^{D}\boldsymbol{\phi}_{j}(\xi_{j})
. Therefore, we can bound the error

as

\displaystyle\|\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}-\boldsymbol{F}_{s}\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\|_{C}=

\displaystyle|(\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}})\times_{j=1}^{D}\boldsymbol{\phi}_{j}(\xi_{j})|

\displaystyle\leq

\displaystyle|\sum_{i_{1},\dots,i_{D}}(\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}})_{i_{1},\dots,i_{D}}\prod_{j=1}^{D}[\boldsymbol{\phi}_{j}(\xi_{j})]_{i_{j}}|,

\displaystyle\leq

\displaystyle\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C}|\sum_{i_{1},\dots,i_{D}}\prod_{j=1}^{D}|[\boldsymbol{\phi}_{j}(\xi_{j})]_{i_{j}}|.

Next, we use the equality
\sum_{i_{1},\dots,i_{D}}\prod_{j=1}^{D}|[\boldsymbol{\phi}_{j}(\xi_{j})]_{i_{j}}|=\prod_{j=1}^{D}\left(\sum_{i_{j}=1}^{n}|[\boldsymbol{\phi}_{j}(\xi_{j})]_{i_{j}}|\right)
to write

\displaystyle\|\boldsymbol{F}_{s}\boldsymbol{M}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}-\boldsymbol{F}_{s}\widehat{\boldsymbol{M}}_{F}^{\{d\}}(\boldsymbol{\theta})\boldsymbol{F}_{t}^{\top}\|_{C}\leq

\displaystyle\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C}\prod_{j=1}^{D}\|\boldsymbol{\phi}_{j}(\xi_{j})\|_{1}

\displaystyle\leq

\displaystyle\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C}(\lambda_{n-1})^{D}.

The inequality

follows from Lemma

. The stated result follows by plugging the intermediate results (

) and (

) into (

).

assume the existence of a TT approximation
\widehat{\boldsymbol{\mathcal{M}}}
. In this next result, we show that such an approximation can be found.

Proposition 3
.

Consider the notation and assumptions established in this section.
For an integer

s.t.
1\leq p\leq n
, there exists a TT decomposition of
\boldsymbol{\mathcal{M}}
, which we label as
\widehat{\boldsymbol{\mathcal{M}}}
with TT ranks

for
1\leq k<D-1
(

The proof strategy is based on
[

]
.
The idea is to construct a multi-variate Chebyshev polynomial

that interpolates

at the
p^{D}
Chebyshev nodes defined on

using the method outlined in Section

. We define the tensor
\widehat{\boldsymbol{\mathcal{M}}}
with entries

[\widehat{\boldsymbol{\mathcal{M}}}]_{i_{1},i_{2},\dots,i_{D}}=g(\eta^{(1)}_{i_{1}},\eta^{(2)}_{i_{2}},\dots,\eta^{(D)}_{i_{D}}),\quad 1\leq j\leq D,1\leq i_{j}\leq p.

Note, the Chebyshev nodes
\{\eta^{(j)}_{i_{j}}\}_{i_{j}=1}^{p}
for
1\leq j\leq D
are associated with the Chebyshev polynomial
g
.
Then, by Lemma 3.1 and (3.3) from
[
39
]
, we can conclude there exists an exact TT decomposition of
\widehat{\boldsymbol{\mathcal{M}}}
,

\widehat{\boldsymbol{\mathcal{M}}}=[\boldsymbol{\mathcal{C}}_{1},\boldsymbol{\mathcal{C}}_{2},\dots,\boldsymbol{\mathcal{C}}_{D}],

with TT ranks

for

. Next, by the assumptions on

and as a consequence of Corollary 4.21 in
[

]
, we have

\|\boldsymbol{\mathcal{M}}-\widehat{\boldsymbol{\mathcal{M}}}\|_{C}\leq\|f_{\kappa}-g\|_{\infty}\leq E(p).

If

3.4
Discussion of error analysis

We have demonstrated that the TT ranks of
\widehat{\boldsymbol{\mathcal{M}}}
are bounded, and have derived a relationship between the TT ranks of
\widehat{\boldsymbol{\mathcal{M}}}
and the derivatives of
f_{\kappa}
(see (
21
)). Note the bound is quite pessimistic concerning the TT ranks, and this is to be expected since we did not assume additional structure on
f_{\kappa}
. The existence of an approximation of
f_{\kappa}
into a summation of separable basis functions allows us to derive a relationship between the TT ranks and the TT approximation error. In the context of Proposition
3
, this approximation was obtained via multi-variate Chebyshev interpolation. The following
[
42
,
35
,
11
,
19
]
discuss approximations of specific classes of kernel functions into a summation of separable basis functions.

We now introduce the concept of admissibility. We first define the distance between
\mathcal{B}_{s}
and
\mathcal{B}_{t}
:

\textrm{dist}(\mathcal{B}_{s},\mathcal{B}_{t})=\min_{\boldsymbol{x}\in\mathcal{B}_{s},\boldsymbol{y}\in\mathcal{B}_{t}}\|\boldsymbol{x}-\boldsymbol{y}\|_{2}.

We say that
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are
admissible
whenever
\textrm{dist}(\mathcal{B}_{s},\mathcal{B}_{t})>0
and we say that
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are
weakly admissible
whenever
\mathcal{B}_{s}
and
\mathcal{B}_{t}
intersect at a single point. This definition for
\mathcal{B}_{s}
and
\mathcal{B}_{t}
being admissible is chosen because many kernels (for example, the Bi-harmonic kernel) have singularity at the origin. See Table
1
for a listing of kernels used in the numerical experiments section and their definitions.

Let us first consider the kernel functions
\kappa
that are nonparametric (i.e.
d_{\theta}=0
). If
\kappa
is asymptotically smooth (Definition 4.14 from
[
20
]
) and
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are admissible, then
f_{\kappa}\in C^{\infty}(\Xi)
, by Lemma E.5 from
[
20
]
.
This means the Bi-harmonic, Laplace-3D, Laplace-2D, and Thin-plate kernels, which are known to be asymptotically smooth, result in
f_{\kappa}\in C^{\infty}(\Xi)
if
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are admissible.

We now turn to the parametric case. We consider the special case that
\kappa
is an isotropic kernel with just the length scale parameter; as in,
\boldsymbol{\theta}=(\ell)
s.t.
\ell>0
and

\kappa(\boldsymbol{x},\boldsymbol{y};\ell)=g\left(\frac{\|\boldsymbol{x}-\boldsymbol{y}\|_{2}}{\ell}\right),

where
g:\mathbb{R}_{+}\rightarrow\mathbb{R}
. This special case is of importance, since it covers the majority of parametric kernels considered in this paper. We also first consider the admissible case (
\text{dist}(\mathcal{B}_{s},\mathcal{B}_{t})>0
). If
g
is in
C^{\infty}(\mathbb{R}_{+})
then
f_{\kappa}\in C^{\infty}(\Xi)
by Theorem 3.1 from
[
13
]
. All the parametric kernels we consider, such as the Exponential, Matérn (with a fixed
\nu
), and Thin-Plate spline, can be expressed in the isotropic form where
g\in C^{\infty}(\mathbb{R}^{+})
. Hence, many of the parametric kernels we consider result in
f_{\kappa}\in C^{\infty}(\Xi)
whenever
\textrm{dist}(\mathcal{B}_{s},\mathcal{B}_{t})>0.
Even if
\mathcal{B}_{s}
and
\mathcal{B}_{t}
are not admissible, some kernels such as the Squared-Exponential and Multiquadric kernel result in
f_{k}\in C^{\infty}(\Xi)
.

3.5
Global low-rank approximation

In this section, we consider the case that the source and target boxes (
\mathcal{B}_{s}
and
\mathcal{B}_{t}
) are the same and assume that the source and target points (
\mathcal{X}
and
\mathcal{Y}
) are the same. If the matrix kernel function
\kappa(\boldsymbol{x},\boldsymbol{y};{\boldsymbol{\theta}})=\kappa(\boldsymbol{y},\boldsymbol{x};{\boldsymbol{\theta}})
is symmetric in its arguments, then the low-rank approximation should be symmetric, and if the kernel function is symmetric positive definite, then the approximation ought to also be symmetric positive semi-definite. The algorithms described in Section
3.1
currently do not consider the problem’s symmetry nor the kernel function being positive definite when
\mathcal{X}=\mathcal{Y}
. However, we can modify them appropriately, which we will now discuss.

Method

Given a matrix
\boldsymbol{A}\in\mathbb{R}^{m\times m}
, its symmetric part
\frac{1}{2}(\boldsymbol{A}+\boldsymbol{A}^{\top})
is the best symmetric approximation to
\boldsymbol{A}

[
4
, Theorem IX.7.1]
. Therefore, to obtain a symmetric low-rank approximation, we can work with the symmetric part, i.e.,

\frac{1}{2}\left(\boldsymbol{SH}(\boldsymbol{\bar{\theta}})\boldsymbol{T}^{\top}+\boldsymbol{T}(\boldsymbol{H}(\boldsymbol{\bar{\theta}}))^{\top}\boldsymbol{S}^{\top}\right)=\begin{bmatrix}\boldsymbol{S}&\boldsymbol{T}\end{bmatrix}\widehat{\boldsymbol{H}}\begin{bmatrix}\boldsymbol{S}^{\top}\\
\boldsymbol{T}^{\top}\end{bmatrix},

(25)

where
\widehat{\boldsymbol{H}}
is a block matrix defined as

\widehat{\boldsymbol{H}}\equiv\begin{bmatrix}&\frac{1}{2}\boldsymbol{H}(\boldsymbol{\bar{\theta}})\\
\frac{1}{2}(\boldsymbol{H}(\boldsymbol{\bar{\theta}}))^{\top}&\end{bmatrix}.

Therefore, this low-rank representation can be obtained without any additional storage requirements, but the downside is that the rank of the low-rank approximation is doubled. We now take the thin QR decomposition of the block matrix composed of
\boldsymbol{S}
and
\boldsymbol{T}
as

\begin{bmatrix}\boldsymbol{S}&\boldsymbol{T}\end{bmatrix}=\boldsymbol{QR}.

We designate this point of the method as the end of the offline stage because the matrices
\boldsymbol{Q}
and
\boldsymbol{R}
can be pre-computed and stored.

\widehat{\boldsymbol{\Lambda}}

\widehat{\boldsymbol{U}}

\boldsymbol{Z}=\boldsymbol{Q}\widehat{\boldsymbol{U}}

\boldsymbol{K}(\mathcal{X},\mathcal{X};{\boldsymbol{\bar{\theta}}})\approx\boldsymbol{Z}\widehat{\boldsymbol{\Lambda}}\boldsymbol{Z}^{\top}

\boldsymbol{A}=\widehat{\boldsymbol{U}}\widehat{\boldsymbol{\Lambda}}\widehat{\boldsymbol{U}}^{\top}

\boldsymbol{K}(\mathcal{X},\mathcal{X};{\boldsymbol{\bar{\theta}}})\approx\boldsymbol{Q}\boldsymbol{A}\boldsymbol{Q}^{\top}.

(26)

flops. For PTTK-Global-1, forming the matrix
\boldsymbol{U}\boldsymbol{\Lambda}\boldsymbol{U}^{\top}

\boldsymbol{\Lambda}

\boldsymbol{U}

5
Conclusions

In this work, we proposed a low-rank black box approximation scheme of parametric kernel matrices via multivariate polynomial approximation and the tensor train decomposition. Our method can be applied to kernel matrices induced by various kernels and varying spatial configurations of source and target points (
\mathcal{X}=\mathcal{Y}
or
\mathcal{X}\neq\mathcal{Y}
), if the kernel function is sufficiently smooth over the chosen parameter space.
After an offline stage, our method outperforms existing methods with an efficient online phase that does not depend on
N_{s}
nor
N_{t}
. Our method works well for three spatial and low parameter dimensions; an investigation of the extension to higher dimensions is left for future work. For future work, we can also consider the TT-matrix form of the coefficient tensor (
\boldsymbol{\mathcal{M}}
), similar to
[
23
]
for the SE kernel. An alternative direction for future work would be applying our method in the context of hierarchical matrices by using our method as a sub-routine to compute hierarchical parametric low-rank approximations.

Appendix A
TT-cross Approximation

We aim to obtain an approximate tensor train decomposition of
\boldsymbol{\mathcal{X}}\in\mathbb{R}^{n_{1}\times\dots n_{N}}
without explicitly forming
\boldsymbol{\mathcal{X}}
first. To this end, we introduce the TT-cross Approximation method, first proposed in
[
29
]
, which serves as a multidimensional analog to matrix cross approximation. Our description is heavily influenced by
[
40
, Section 2.3]
.

Cross Approximation

We now describe the Cross Approximation method for an arbitrary matrix
\boldsymbol{A}\in\mathbb{R}^{m\times n}
. We first suppose that
\boldsymbol{A}
is exactly rank
r_{s}
, then for the correct choice of the index sets
\mathcal{I},\mathcal{J}
there exists a skeleton decomposition of
\boldsymbol{A}
where

\boldsymbol{A}=\boldsymbol{A}(:,\mathcal{J})[\boldsymbol{A}(\mathcal{I},\mathcal{J})]^{-1}\boldsymbol{A}(\mathcal{I},:),

where
\mathcal{I},\mathcal{J}
are ordered index sets such that the two matrices
\boldsymbol{A}(:,\mathcal{J})\in\mathbb{R}^{m\times r_{s}}
and
\boldsymbol{A}(\mathcal{I},:)\in\mathbb{R}^{r_{s}\times n}
contain columns and rows of
\boldsymbol{A}
corresponding to the index sets
\mathcal{J}
and
\mathcal{I}
respectively. Similarly,
\boldsymbol{A}(\mathcal{I},\mathcal{J})
is the submatrix of
\boldsymbol{A}
. Now, the task is to find an appropriate choice of
\mathcal{I}
and
\mathcal{J}
when
\boldsymbol{A}
is approximately rank
r_{s}
, a good choice is index sets
\mathcal{I},\mathcal{J}
such that
\boldsymbol{A}(\mathcal{I},\mathcal{J})
is the sub-matrix of maximum volume in
\boldsymbol{A}
as stated in
[
17
,
16
]
. However, finding a sub-matrix of maximum volume is NP-hard, as mentioned in
[
9
]
. Thus, in order to compute
\mathcal{I}
and
\mathcal{J}
, we use a heuristic, specifically Algorithm 2 in
[
12
]
to incrementally construct the index sets that define the cross approximation. In our implementation, we modified this slightly and present this as Algorithm
6
.

Nested index sets

We define two index sets
\mathcal{I}^{\leq k}
and
\mathcal{I}^{>k}
that satisfy

\displaystyle\mathcal{I}^{\leq k}\subset

\displaystyle\>\{(i_{1},i_{2},\dots,i_{k}):1\leq i_{j}\leq n_{j},1\leq j\leq k\},

(27)

\displaystyle\mathcal{I}^{>k}\subset

\displaystyle\>\{(i_{k+1},\dots,i_{N}):1\leq i_{j}\leq n_{j},k\leq j\leq N\}

(28)

for
1\leq k\leq N-1
, and then we define the corresponding border index sets
\mathcal{I}^{\leq 0}=\mathcal{I}^{>N}=\emptyset
.
As in the two-dimensional (matrix) case, the index sets are also given a consistent ordering, determined by the TT greedy-cross algorithm; hence, we denote the ordered multi-indices of the index sets with
\mathcal{I}^{\leq k}_{s}
and
\mathcal{I}^{>k}_{t}
where
1\leq s\leq|\mathcal{I}^{\leq k}|,1\leq t\leq|\mathcal{I}^{>k}|
. We also require the index sets
\mathcal{I}^{\leq 1},\dots,\mathcal{I}^{\leq N-1}
and
\mathcal{I}^{>1},\dots,\mathcal{I}^{>N-1}
to be nested, which means for
1\leq k\leq N-1
, the following holds

\displaystyle(i_{1},i_{2},\dots,i_{k})\in\mathcal{I}^{\leq k}\implies(i_{1},i_{2},\dots,i_{k-1})\in\mathcal{I}^{\leq k-1},

\displaystyle(i_{k+1},\dots,i_{N})\in\mathcal{I}^{>k}\implies(i_{k+2},i_{k+3},\dots,i_{N})\in\mathcal{I}^{>k+1}.

With the index sets, we can define the cross intersection matrix
\boldsymbol{X}(\mathcal{I}^{\leq k},\mathcal{I}^{>k})\in\mathbb{R}^{|\mathcal{I}^{\leq k}|\times|\mathcal{I}^{>k}|}

:

[\boldsymbol{X}(\mathcal{I}^{\leq k},\mathcal{I}^{>k})]_{i,j}=[\boldsymbol{X}^{\{k\}}]_{\overline{\mathcal{I}^{\leq k}_{i}},\overline{\mathcal{I}^{>k}_{j}}},\quad 1\leq i,j\leq r_{k}.

Overview of TT greedy-cross

We present an overview of the TT greedy-cross algorithm introduced in
[
37
]
, a specific TT-cross Approximation method. The TT greedy-cross algorithm must be initialized with index sets and in our implementation, it is initialized with index sets of cardinality
2
; for details, see Appendix
B
. The TT-ranks of the TT-cross interpolation constructed by the TT greedy-cross algorithm are related to the cardinalities of the index sets with the relationship

r_{k}=|\mathcal{I}^{\leq k}|=|\mathcal{I}^{>k}|,\quad 1\leq k\leq N-1.

We first define the three-dimensional tensor
\boldsymbol{\mathcal{X}}(\mathcal{I}^{\leq k-1},:,\mathcal{I}^{>k})\in\mathbb{R}^{r_{k-1}\times n_{k}\times r_{k}}
for
2\leq k\leq N-1
as follows:

[\boldsymbol{\mathcal{X}}(\mathcal{I}^{\leq k-1},:,\mathcal{I}^{>k})]_{s,l,t}=x_{\mathcal{I}^{\leq k-1}_{s},l,\mathcal{I}^{>k}_{t}},\quad 1\leq s\leq r_{k-1},1\leq l\leq n_{k},1\leq t\leq r_{k}.

The edge case tensors

of the TT-cross approximation of
\boldsymbol{\mathcal{X}}
at each sequential iteration

,

in order to obtain the TT approximation to
\boldsymbol{\mathcal{X}}

Appendix B
TT greedy-cross initialization

We introduce a heuristic for initializing the index sets that will be used in the TT greedy-cross algorithm since searching over all possible index sets
\mathcal{I}^{\leq k},\mathcal{I}^{>k}
for
1\leq k\leq N-1
of cardinality two in order to minimize
\max_{1\leq k\leq N-1}\textrm{cond}_{2}(\boldsymbol{X}(\mathcal{I}^{\leq k},\mathcal{I}^{>k}))
, where
\textrm{cond}_{2}(\cdot)
is the 2-norm condition number of the matrix, would be computationally infeasible. Numerical simulations indicate that initialization with index sets of cardinality two, rather than one, is needed to apply TT greedy-cross in our method to the squared-exponential kernel in the non-parametric case; otherwise, the TT greedy-cross algorithm quits before a good solution is found. For the parametric case, it is not needed, but does allow the TT greedy-cross algorithm to converge faster. As for the other kernels listed in Table
1
, one can initialize the greedy-cross algorithm with randomized index sets of cardinality 1 for the problem setup described in the numerical experiments section which would take
\mathcal{O}(N)
time.

Our heuristic method begins by initializing the index sets
\mathcal{I}^{>k}
for
1\leq k\leq N-1
with uniformly randomly chosen indices such that
|\mathcal{I}^{>k}|=2
. We start with
k=1
and then construct an index set
\mathcal{I}^{\leq 1}
that minimizes the 2-norm condition number of the cross intersection matrix
\boldsymbol{X}(\mathcal{I}^{\leq 1},\mathcal{I}^{>1})
such that
\mathcal{I}^{\leq 1}_{1}\neq\mathcal{I}^{\leq 1}_{2}
. Now we are given a index set
\mathcal{I}^{\leq k}
where
1\leq k\leq N-2

\mathcal{I}^{\leq k}_{2}=(b_{1},b_{2},\dots,b_{k})
