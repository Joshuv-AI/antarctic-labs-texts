Abstract
In this work, we are concerned with the decentralized optimization problem: min x ∈ Ω ⁡ f ⁡ ( x ) = 1 n ​ ∑ i = 1 n f i ​ ( x ) , \min_{x\in\Omega}~f(x)=\frac{1}{n}\sum_{i=1}^{n}f_{i}(x), where Ω ⊂ ℝ d \Omega\subset\mathbb{R}^{d} is a convex domain and each f i : Ω → ℝ f_{i}:\Omega\rightarrow\mathbb{R} is a local cost function only known to agent i i . A fundamental algorithm is the decentralized projected gradient method (DPG) given by x i ( t + 1 ) = 𝒫 Ω [ ∑ j = 1 n w i ​ j x j ( t ) − α ( t ) ∇ f i ( x i ( t ) ) ] x_{i}(t+1)=\mathcal{P}_{\Omega}\Big[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}(x_{i}(t))\Big] where 𝒫 Ω \mathcal{P}_{\Omega} is the projection operator to Ω \Omega and { w i ​ j } 1 ≤ i , j ≤ n \{w_{ij}\}_{1\leq i,j\leq n} are communication weight among the agents. While this method has been widely used in the literature, its convergence property has not been established so far, except for the special case Ω = ℝ n \Omega=\mathbb{R}^{n} . This work establishes new convergence estimates of DPG when the aggregate cost f f is strongly convex and each function f i f_{i} is smooth. If the stepsize is given by constant α ⁡ ( t ) ≡ α > 0 \alpha(t)\equiv\alpha>0 and suitably small, we prove that each x i ​ ( t ) x_{i}(t) converges to an O ⁡ ( α ) O(\sqrt{\alpha}) -neighborhood of the optimal point. In addition, we further improve the convergence result by showing that the point x i ​ ( t ) x_{i}(t) converges to an O ⁡ ( α ) O(\alpha) -neighborhood of the optimal point if the domain is given the half-space ℝ d − 1 × ℝ + \mathbb{R}^{d-1}\times\mathbb{R}_{+} for any dimension d ∈ ℕ d\in\mathbb{N} . Also, we obtain new convergence results for decreasing stepsizes. Numerical experiments are provided to support the convergence results.

Introduction

Let us consider a multi-agent system with
n
agents that form a connected network and cooperatively solve the following constrained optimization problem:

\min_{x\in\Omega}f(x)=\frac{1}{n}\sum^{n}_{i=1}f_{i}(x),

(1)

where
f_{i}:\Omega\rightarrow\mathbb{R}
is a local cost function only known to agent
i\in\mathcal{V}=\{1,2,\cdots,n\}
, and
\Omega\subset\mathbb{R}^{d}
denotes a common convex closed set. This problem arises in many applications like engineering problems
[
7
,
9
]
, signal processing
[
5
,
22
]
and machine learning problems
[
4
,
16
,
30
]
. The works
[
27
,
34
]
introduced the Decentralized Projected Gradient (DPG) algorithm for solving the problem (
1
), and various other algorithms have appeared for the problem (
1
) such as the double averaging algorithm
[
33
]
, the frank-wolfe type algorithm
[
35
]
, the primal-dual algorithm
[
21
]
, and gradient-tracking type algorithm
[
14
]
. We also refer to
[
31
]
where the projected gradient method is utilized to solve the problem (
1
) in a different way.

In this work, we are concerned with the convergence property of the DPG algorithm described as follows:

x_{i}(t+1)=\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg],

(2)

where
x_{i}(t)
is the variable of agent
i
at time instant
t\in\mathbb{N}\cup\{0\}
and
\mathcal{P}_{\Omega}
represents the projection of a vector
y
onto the set
\Omega
, defined as:

\mathcal{P}_{\Omega}[y]=\arg\min_{x\in\Omega}\|x-y\|.

(3)

The nonnegative weight scalars
w_{ij}
are related to the communication pattern among agents in (
1
) (see Section
2
for the details). This algorithm is studied for various settings containing stochastic distributed optimization
[
2
,
20
,
25
,
34
]
, event-triggered communication
[
19
,
23
]
, and online problems
[
1
,
8
,
17
]
. In addition, the algorithm has been widely used as a backbone for developing various algorithms such as the decentralized TD learning for the multi-agent reinforcement learning
[
13
]
and distributed model predictive control
[
18
]
. Despite its wide applicability, the convergence properties of the algorithm (
2
) have not been established well due to the difficulty of handling the projection operator
P_{\Omega}
in the convergence analysis. To explain the difficulty in the convergence analysis of (
2
) compared to the case
\Omega=\mathbb{R}^{d}
, we note that averaging (
2
) without projection operator gives

\bar{x}(t+1)=\bar{x}(t)-\frac{\alpha(t)}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{i}(t)),

(4)

where
\bar{x}(t)=\frac{1}{n}\sum_{i=1}^{n}x_{i}(t)
. Then, if the stepsize is set to
\alpha\leq\frac{2}{\mu+L}
, one can obtain the following inequality:

\begin{split}\|\bar{x}(t+1)-x_{*}\|&\leq\Big(1-\frac{\mu L}{\mu+L}\alpha\Big)\|\bar{x}(t)-x_{*}\|+\frac{L\alpha}{n}\sum_{i=1}^{n}\|x_{i}(t)-\bar{x}(t)\|,\end{split}

when
f
is
\mu
-strongly convex and each
f_{i}
is
L
-smooth. This inequality is a major ingredient in the convergence estimate of (
5
) in the work
[
38
,
11
]
, but the identity (
4
) no longer holds for (
2
) due to the projection. Instead, we proceed to obtain a sequential estimate of the quantity

\|{\mathbf{x}}(t)-{\mathbf{x}}_{*}\|^{2}=\sum_{i=1}^{n}\|x_{i}(t)-x_{*}\|^{2},

which enables us to offset the projection operator efficiently using the contraction property of the projection operator. As a result, we obtain a convergence result up to an error
O(\sqrt{\alpha})
.

1.1
Related works and contributions of this work

When
\Omega=\mathbb{R}^{n}
, the algorithm (
2
) becomes the unconstrained decentralized gradient descent as given by

x_{i}(t+1)=\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t)).

(5)

The convergence estimates of (
5
) have been established well in the previous works
[
27
,
38
,
11
]
. In the earlier work
[
27
]
, for a constant stepsize, Nedić-Ozdaglar
[
27
]
showed that the sequence converges to an
O(\alpha)
-neighborhood of the optimal set. In this work, the authors assume that the gradient
\nabla f_{i}
has a uniform bound for
1\leq i\leq n
and convexity assumption on each function
f_{i}
. In the recent work
[
38
]
, the convergence result was established for local convex cost functions with
L
-smoothness instead of the uniform boundedness assumption on the gradient. In
[
38
]
, the authors obtain the uniform boundedness by
L
-smoothness of a local convex function and strongly convex total cost function. They show that the sequence with constant stepsize
O(1/(\mu+L))>\alpha(t)\equiv\alpha>0
converges to an
O(\alpha)
-neighborhood of the optimal point exponentially fast. This result was extended by the work
[
11
]
to the case with decreasing stepsize of the form
\alpha(t)=c/(t+w)^{p}
for
0<p\leq 1
.

As we mentioned earlier, if
\Omega\neq\mathbb{R}^{n}
, the convergence analysis for (
2
) becomes more challenging due to the projection operator. In the original works
[
34
,
10
,
24
]
, the convergence results of (
2
) were established under the assumption that the gradient
\nabla f_{i}
has a uniform bound for
1\leq i\leq n
. The work
[
24
]
obtained the convergence rate
O(1/\sqrt{t})
when the stepsize is chosen as
\alpha(t)=c/t
for a suitable range of
c>0
.

The uniform boundedness of the gradient assumption was replaced by the
L
-smoothness property in the work
[
23
]
. For the algorithm (
2
) with
L
-smooth and convex cost functions
f_{i}
, the authors showed that there exists a uniform bound
M>0
of the gradients
\|\nabla f_{i}(x_{i}(t))\|
for all
t\geq 0
and
1\leq i\leq n
if the stepsize is given by a constant
\alpha>0
satisfying
\alpha<\frac{1+\lambda_{n}(W)}{L}
where
\lambda_{n}(W)
denotes the smallest eigenvalue of the mixing matrix
W=\{w_{ij}\}_{1\leq i,j\leq n}
(refer to Section 2). For this, the DPG is interpreted as a projected gradient descent (PGD) of a cost defined on the product space
\Omega^{n}=\Omega\times\cdots\Omega
and a classical argument for the PGD was applied. In addition, assuming also that the aggregate cost
f
is
\mu
-strongly convex, the work
[
23

\begin{split}\|x_{i}(t+1)-x_{*}\|&\leq(1-\mu\alpha)^{t+1}\|\bar{x}(0)-x_{*}\|+\beta^{t+1}\|{\mathbf{x}}(0)\|+\frac{2\alpha M}{1-\beta}\\
&\quad+\sum_{s=0}^{t}(1-\mu\alpha)^{t-s}\Big(\alpha L\gamma_{s}+\frac{\alpha M}{\sqrt{n}}\Big),\end{split}

(6)

.

2
Assumptions and main results

In this section, we state the assumptions on the total and local cost functions in (
1
) and communication patterns among agents. We are interested in (
1
) when the local cost functions and the total cost functions satisfy the following strong convexity and smoothness assumption.

Assumption 1
.

For each
i\in\{1,\cdots n\}
, the local cost function
f_{i}
is
L
-smooth for some
L>0
, i.e., for any
x,y\in\Omega
we have

\|\nabla f_{i}(x)-\nabla f_{i}(y)\|\leq L\|x-y\|\quad\forall~x,y\in\Omega.

Assumption
1
implies that the total cost function
f(\cdot)=\frac{1}{n}\sum^{n}_{i=1}f_{i}(\cdot)
is also
L
-smooth.

Assumption 2
.

The total cost function
f(\cdot)=\frac{1}{n}\sum^{n}_{i=1}f_{i}(\cdot)
is
\mu
-strongly convex for some
\mu>0
, i.e., for any
x,y\in\Omega
, we have

f(y)\geq f(x)+(y-x)\nabla f(x)+\frac{\mu}{2}\|y-x\|^{2}.

Under this assumption, the function
f
has a unique optimizier
x_{*}\in\Omega
(see Theorem 5.25 in
[
3
]
).

In decentralized optimization, local agents share information through a communication network characterized by an undirected graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
. Here, each node in
\mathcal{V}
represents an agent, and an edge
{i,j}\in\mathcal{E}
indicates that agent
i
can send messages to agent
j
. The graph
\mathcal{G}
is assumed to satisfy the following assumption.

Assumption 3
.

The communication graph
\mathcal{G}
is fixed and connected. By ‘fixed’, we mean that the graph
\mathcal{G}
does not depend on the time
t
, and by ‘connected’, we mean that for any
i
and
j
in
\mathcal{E}
, there always exists a sequence of edges connecting them.

We define the mixing matrix
W=[w_{ij}]_{1\leq i,j\leq n}
as follows. The nonnegative weight
w_{ij}
is given for each communication link
\{i,j\}\in\mathcal{E},
where
w_{ij}\neq 0
if
\{i,j\}\in\mathcal{E}
and
w_{ij}=0
if
\{i,j\}\notin\mathcal{E}
. In this paper, we make the following assumption on the mixing matrix
W
.

Assumption 4
.

The mixing matrix
W=\{w_{ij}\}_{1\leq i,j\leq n}
is symmetric and doubly stochastic. In addition
w_{ii}>0
. The network is connected and the weight matrix
W
satisfies
\textrm{null}(I-W)=\textrm{span}\{1_{n}\}
.

Without loss of generality, we arrange the eigenvalues of
W
to satisfy

1=|\lambda_{1}(W)|>|\lambda_{2}(W)|\geq\cdots\geq|\lambda_{n}(W)|\geq 0,

and it is well-known that we have
\beta:=|\lambda_{2}(W)|<1
under Assumption
4
(see Section II.B in
[
29
]
).

In this section, we present the results: consensus achievement, and convergence rate and error of the decentralized projected gradient descent scheme (
2
). Before presenting the main results, we establish the conditions for uniform boundedness of the sequence
\{x_{i}(t)\}_{t\geq 0}
in the sense that
\|\mathbf{x}(t)-\mathbf{x}_{*}\|^{2}
is uniformly bounded for all
t\geq 0
. This uniform boundedness property is crucial to obtain our main results.

Theorem 5
(Conditions for uniform bounedness).

There exists a constant
R_{s}>0
such that

\|\mathbf{x}(t)-{\mathbf{x}}_{*}\|^{2}\leq R_{s}

holds for all
t\geq 0
if at least one of the following statements holds true:

1.

\Omega
is bounded (no restriction on the stepsize).

2.

Each local cost function
f_{i}
is convex and satisfies Assumption
1
. In addition, the stepsize is constant, i.e.,
\alpha(t)\equiv\alpha
, satisfying
\alpha\leq\frac{1+\lambda_{n}(W)}{L}
.

3.

Each local cost function
f_{i}
satisfies Assumption
1
and the total cost function
f
satisfies Assumption
2
. In addition, the stepsize
\{\alpha(t)\}_{t\geq 0}
is non-increasing and satisfies

\alpha(t)<\min\bigg\{Z,\frac{\mu}{4c_{1}},\frac{2}{L+\mu}\bigg\}.

Here we have set the positive constant
Z
by

Z:=\frac{1}{2c_{3}}\Big[-\Big(c_{4}+\frac{\mu}{4}\Big)+\sqrt{\Big(c_{4}+\frac{\mu}{4}\Big)^{2}+4c_{3}(1-\beta)}\Big]\leq 1-\beta,

where the constants
c_{1},c_{2},c_{3},c_{4}
are defined as follows:

c_{1}:=\frac{3L^{2}}{1-\beta},\ c_{2}:=\frac{3nR_{D}^{*}}{1-\beta},\ c_{3}:=c_{1}+L^{2},\ c_{4}:=\frac{4L^{2}}{\mu}.

While Theorem
5
provides conditions for ensuring uniform boundedness, we introduce the following uniform boundedness assumption because it may hold for larger ranges of
\alpha(t)
than that guaranteed by Theorem
5
. Proving a sharper range of
\alpha(t)
for the uniform boundedness property would be an interesting future work.

Assumption 6
.

There exists a constant
R_{s}>0
such that

\|\mathbf{x}(t)-{\mathbf{x}_{*}}\|^{2}\leq R_{s}

holds for all
t\geq 0
.

2.1
Consensus results

In centralized optimization, it suffices to demonstrate that the sequence generated by (
4
) converges to the optimal solution of (
1
) because the central coordinate controls all agents simultaneously. In contrast, decentralized optimization involves each agent generating its own sequence and only sharing its information with neighboring agents. Therefore, we also need to show that each sequence generated by (
2
) converges to the same point, in which case we say the consensus is achieved. The following theorem states the consensus results based on the estimates for the consensus error
\|\mathbf{x}(t)-\mathbf{\bar{x}}(t)\|^{2}
.

Theorem 7
(Consensus).

Suppose that Assumptions
1
,
2
,
3
and
6
hold. If a non-increasing stepsize
\{\alpha(t)\}_{t\geq 0}
satisfies
\alpha(t)\leq\frac{2}{L+\mu}
, then we have the following consensus estimates.

Case 1.

For a decreasing stepsize, we have

\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}\leq\beta^{t}\|\mathbf{x}(0)-\bar{\mathbf{x}}(0)\|^{2}+\frac{R_{c}\alpha(t)^{2}}{(1-\beta)^{2}},

where

R_{c}:=3(L^{2}R_{s}+nR_{D}^{*})\cdot\sup_{s\geq 0}\frac{\alpha(0)^{2}\beta^{s}+\alpha([s/2])^{2}}{\alpha(s)^{2}}.

(7)

Case 2.

For a constant stepsize, i.e.
\alpha(t)\equiv\alpha
, we have

\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}\leq\beta^{t}\|\mathbf{x}(0)-\bar{\mathbf{x}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}.

Theorem
7
demonstrates that the consensus is reached exponentially fast up to an
O(\alpha(t))
error.

2.2
Convergence results: Constant stepsize

According to Theorem
7
, demonstrating the convergence of the consensus point
\bar{x}(t)
to the optimal point
x_{*}
is sufficient to establish our convergence results. The following convergence result holds when the stepsize is given by a constant.

Theorem 8
(Convergence for constant stepsize).

Suppose that Assumptions
1
,
2
,
3
and
6
hold. If the stepsize is given by a constant
\alpha>0
such that
\alpha\leq\frac{2}{L+\mu}
, then
we have

\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}\leq\Big(1-\frac{\mu\alpha}{2}\Big)^{t}\|\bar{\mathbf{x}}(0)-\mathbf{x}_{*}\|^{2}+G_{1}\left(\left(1-\frac{\mu\alpha}{2}\right)^{t-1}+\beta^{\frac{t-1}{2}}\right)+G_{2}\alpha.

Here the constant
G_{1}
and
G_{2}
are defined as

\begin{split}G_{1}&=\frac{2\left(c_{3}\alpha^{2}+c_{4}\alpha+\beta\right)R_{s}}{\mu\alpha}\\
G_{2}&=\frac{2}{\mu}\left(\left(c_{3}\alpha^{2}+c_{4}\alpha+\beta\right)\frac{3(L^{2}R_{s}+nR_{D}^{*})}{\left(1-\beta\right)^{2}}+c_{1}R_{s}+c_{2}\right)\end{split}

where the constants
c_{1}
,
c_{2}
,
c_{3}
and
c_{4}
are defined in Theorem
5
.

Remark 9
.

Note that using
\sum^{n}_{i=1}\|a_{i}+b\|^{2}=\sum^{n}_{i=1}\|a_{i}\|^{2}+\|b\|^{2}
if
\sum^{n}_{i=1}a_{i}=0
for any
a_{i},b\in\mathbb{R}^{d}
, it follows that

\|{\mathbf{x}}(t)-{\mathbf{x}}_{*}\|^{2}=\|{\mathbf{x}}(t)-{\bar{\mathbf{x}}}(t)\|^{2}+\|{\bar{\mathbf{x}}}(t)-{\mathbf{x}}_{*}\|^{2}.

(8)

In view of this formula, the results of Theorem
8
and Theorem
7
together gives the convergence of
\|{\mathbf{x}}(t)-{\mathbf{x}}_{*}\|^{2}
. Consequently, the sequence generated by (
2
) converges exponentially fast to an
O(\sqrt{\alpha})
-neighborhood of the optimal point.

We recall from
[
38
]
that the sequence of the algorithm (
2
) on the whole space
\mathbb{R}^{d}
converges to an
O(\alpha)
-neighborhood of
x_{*}
. This naturally leads us to pose the following question.

Question
: Is the convergence error
O(\sqrt{\alpha})
in Theorem
8
optimal? or can we improve the convergence error to
O(\alpha)
?

We give a partial answer to this question. Namely, we will establish the convergence result up to an
O(\alpha)
-neighborhood when the domain is given as the half-space
\Omega=\{(\tilde{x},x[d])\,|\,\tilde{x}\in\mathbb{R}^{d-1},x[d]\geq 0\}\subseteq\mathbb{R}^{d}
. Here
x[k]\in\mathbb{R}
denotes the
k
-
th
component of the vector
x\in\mathbb{R}^{d}
.

Let
x_{*}=(\tilde{x}_{*},x_{*}[d])\in\mathbb{R}^{d}
be a solution of (
1
), i.e.
x_{*}=\arg\min_{x\in\Omega}f(x)
. If the optimal point
x_{*}
is an interior point of
\Omega
, then the projection of the DPG (
2
) becomes negligible if the point
\{x_{i}(t)\}_{i=1}^{n}
are close enough to the point
x_{*}
and
\alpha>0
is chosen reasonably small, and so the DPG is reduced to the decentralized gradient descent (
5
). Thus the results of
[
38
,
11
]
on the algorithm (
5
) can be applied to obtain the convergence result up to an
O(\alpha)
-neighborhood. Therefore, we focus only on the more intricate case that
x_{*}
is on the boundary of
\Omega
. Namely, we impose the following assumption.

Assumption 10
.

The minimizer of
f
is on the boundary of
\Omega
, specifically,
x_{*}=(\tilde{x}_{*},0)
with some
\tilde{x}_{*}\in\mathbb{R}^{d-1}
. In addition each local cost function
f_{i}
is
L
-smooth, and the minimizer
x_{*}=(\tilde{x}_{*},0)
satisfies
\partial_{d}f(x_{*})=\frac{1}{n}\sum^{n}_{i=1}\partial_{d}f_{i}(x_{*})\geq\omega>0
. Here
\partial_{k}f
denotes the
k
-
th
component of the gradient
\nabla f
.

Theorem 11
.

Suppose that the domain
\Omega
is the half space
\mathbb{R}^{d-1}\times\mathbb{R}_{+}
with any dimension
d\geq 1
and Assumption
10
holds. Suppose also that Assumptions
1
,
2
,
3
and
6
hold. If the stepsize is given by a constant
\alpha>0
such that
\alpha\leq\frac{2}{L+\mu}
, we have

\underset{t\rightarrow\infty}{\textrm{limsup}}\,\|x_{k}(t)-x_{*}\|=O(\alpha)\quad\forall~1\leq k\leq n.

To achieve this result, we develop a new framework to handle the projection operator in an explicit way. The framework will be also useful to obtain the same result for more general domains
\Omega
such as
\mathbb{R}^{d-k}\times\mathbb{R}_{+}^{k}
and smooth convex domains. In
Section
4
we will also bring a one-dimensional for which we show that the algorithm (
2
) converges to an
O(\alpha)
neighborhood of the optimal point by using the explicit formula of the DPG. This simple example represents the difficulty of handling the projection operator and supports the novelty of the proof of Theorem
11
obtained for general cost functions.

2.3
Convergence results: Diminishing stepsize

In this section, we consider the DPG with the decreasing stepsize of the form
v/(t+w)^{p}
for some values
v>0
,
w\geq 0
and
p\in(0,1]
, generalizing the stepsize considered in the previous works
[
34
,
10
]
. The aim of this section is to obtain new convergence results of the DPG with the stepsize
\alpha(t)=v/(t+w)^{p}
.

Before stating the results, we introduce the following constants
G_{3}
and
G_{4}
:

\begin{split}G_{3}&=\Big(c_{3}\alpha(0)^{2}+c_{4}\alpha(0)+\beta\Big)R_{s}\\
G_{4}&=(c_{3}\alpha(0)^{2}+c_{4}\alpha(0)+\beta)\frac{2R_{c}}{(1-\beta)^{2}}+c_{1}R_{s}+c_{2},\end{split}

(9)

where
c_{1},\ c_{2},\ c_{3},\ c_{4}
are defined in Theorem
8
and
R_{c}
is defined in Theorem
7
.

Based on this observation, we consider a diminishing stepsize and provide the exact convergence results. Specifically, we use
\alpha(t)=v/(t+w)^{p}
as the stepsize.

Theorem 12
(Convergence for diminishing stepsize).

Suppose that Assumptions
1
,
2
,
3
and
6
hold. Let
p\in(0,1]
and assume that
\alpha(t)=\frac{v}{(t+w)^{p}}
with
v,w>0
satisfying

\alpha(0)=\frac{v}{w^{p}}\leq\frac{2}{L+\mu}.

Let
\rho_{1}
and
\rho_{2}
be defined by

{\rho_{1}=\Big(\frac{w+1}{w}\Big)^{2p}~\text{and}~\rho_{2}=\sup_{t\geq 0}\beta^{t}/\alpha(t)^{2}}

(10)

Then we have the following results.

1.

Assume that
p\in(0,1)
. Then we have

\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}\leq\frac{2e\rho_{1}\Big(\rho_{2}G_{3}+G_{4}\Big)v}{\mu}([t/2]+w-1)^{-p}+\mathcal{R}_{1}(t)+\mathcal{R}_{2}(t),

where

\begin{split}\mathcal{R}_{1}(t)&=e^{-\sum^{t-1}_{s=0}\frac{\mu v}{2(s+w)^{p}}}\|\bar{\mathbf{x}}(0)-\mathbf{x}_{*}\|^{2},\\
\mathcal{R}_{2}(t)&=\rho_{1}\Big(\rho_{2}G_{3}+G_{4}\Big)v^{2}e^{-\frac{\mu vt}{4(t+w)^{p}}}\sum^{[t/2]-1}_{s=1}\frac{1}{(s+w)^{2p}}.\end{split}

2.

Assume that
p=1
and choose
v>0
such that
\mu v/2>1
. Then we have

\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}\leq\left(\frac{w}{t+w}\right)^{\mu v/2}\|\bar{\mathbf{x}}(0)-\mathbf{x}_{*}\|^{2}+\mathcal{R}_{3}(t),

(11)

where

\mathcal{R}_{3}(t)=\frac{\rho_{1}}{(\mu v/2)-1}\Big(\frac{w+1}{w}\Big)^{\mu v/2}\frac{\Big(\rho_{2}G_{3}+G_{4}\Big)v^{2}}{(t+w-1)}.

Remark 13
.

The constant
\rho_{2}>0
defined in the above result is used in the convergence analysis. Namely, we shall obtain an intermediate inequality whose bound involves a term of the form
d_{1}\beta^{t}+d_{2}\alpha(t)^{2}
for some constants
d_{1}>0
and
d_{2}>0
, and we will bound the terms by
(\rho_{2}d_{1}+d_{2})\alpha(t)^{2}
.

Remark 14
.

Similarly as in the constant stepsize case (see Remark
9
), the results of Theorem
12
implies the convergence of
\|{\mathbf{x}}(t)-{\mathbf{x}}_{*}\|^{2}
. Specifically, for the case
p\in(0,1)
, we easily see that for any fixed
N>0
, there exists a constant
C_{N}>0
independent of
t\geq 0
such that

\mathcal{R}_{1}(t)+\mathcal{R}_{2}(t)\leq C_{N}t^{-N}.

Therefore, the DPG algorithm (
2
) converges to the optimal point with a rate of
O(t^{-p/2})
. For the case
p=1
, we observe that the convergence rate of the first term on the right-hand side of (
11
) is
O(t^{-\mu v/2})
, while that of
\mathcal{R}_{3}(t)
is
O(t^{-1})
. Since
\mu v/2>1
as chosen in Theorem
12
, we conclude that the sequence converges to the optimal point with a rate of
O(t^{-1/2})
.

Remark 15
.

From Theorem
8
and Theorem
11
, we know that the DPG with constant stepsize
\alpha>0
converges exponentially fast to a neighborhood of the optimizer
x_{*}
whose size is comparable to a power of
\alpha
. Based on this result, if we want the DPG to converge to the optimizer
x_{*}
without error, then one strategy is to repeat decreasing the stepsize after suitable numbers of iterations. Optimizing this strategy and comparing its performance with the decreasing case would be interesting work.

2.4
The main ideas of this work

Here we explain the main ideas of this paper, mainly for achieving the
O(\sqrt{\alpha})
-convergence result of
Theorem
8
and its improvement by Theorem
11
on the
O(\alpha)
-convergence result for the half-space. Before the explanation, we also recall the argument in the previous work
[
23
]
which attains an
O(1)
-convergence result.

2.4.1
The argument of [23]

One may see that the proof in the work
[
23
]
begins with writing the DPG in the following way

x_{k}(t+1)=\sum_{j=1}^{n}w_{kj}x_{j}(t)-\alpha\nabla f_{k}(x_{k}(t))+\phi_{k}(t)

(12)

where
\phi_{i}(t)
is the difference between DGD and DPG defined as follows:

\phi_{i}(t)=\underbrace{{\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))}}_{\text{DGD}}-\underbrace{\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg]}_{\text{DPG}}.

Averaging (
12
) for
1\leq k\leq n
one has

\bar{x}(t+1)=\bar{x}(t)-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{k}(x_{i}(t))+\frac{1}{n}\sum_{i=1}^{n}\phi_{i}(t).

(13)

The work
[
23
]
treated the last term of (
13
) as an additional error term and bound it as

\Big\|\frac{1}{n}\sum_{i=1}^{n}\phi_{i}(t)\Big\|=O(\alpha).

(14)

Then, the contraction property of the projection operator (refer to Lemma
28
) is applied to achieve the following estimate

\begin{split}&\|\bar{x}(t+1)-x_{*}\|\\
&=\left\|\mathcal{P}_{\Omega}[\bar{x}(t+1)]-\mathcal{P}_{\Omega}\left[x_{*}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{*})\right]\right\|\\
&\leq\Big\|\bar{x}(t+1)-\Big(x_{*}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{*})\Big)\Big\|\\
&=\Big\|\bar{x}(t)-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{i}(t))-\Big(x_{*}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{*})\Big)+\frac{1}{n}\sum_{i=1}^{n}\phi_{i}(t)\Big\|.\end{split}

(15)

Using the
L
-smooth property of the costs and the triangle inequality, one may estimate the last part of (
15
) as follows:

\begin{split}&\|\bar{x}(t+1)-x_{*}\|\\
&\leq\Big\|\bar{x}(t)-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(\bar{x}(t))-\Big(x_{*}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{*})\Big)\Big\|+\Big\|\frac{1}{n}\sum_{i=1}^{n}\phi_{i}(t)\Big\|\\
&\quad+\frac{L\alpha}{n}\sum_{i=1}^{n}\|\bar{x}(t)-x_{i}(t)\|.\end{split}

(16)

Now we use the strongly convexity of
f
and (
14
) to estimate the right hand side of (
16
) as follows:

\begin{split}&\|\bar{x}(t+1)-x_{*}\|\leq(1-c\alpha)\|\bar{x}(t)-x_{*}\|+O(\alpha)+\frac{L\alpha}{n}\sum_{i=1}^{n}\|\bar{x}(t)-x_{i}(t)\|,\end{split}

(17)

provided that
\alpha>0
is chosen less than a threshold value and
c>0
is a constant related to the strongly convexity of
f
. We may observe that the estimate (
17
) is less effective due to the fact that there is a
O(\alpha)
term in the bound while the coefficient for the contraction of
\|\bar{x}(t)-x_{*}\|
is
(1-c\alpha)
. More precisely, even if we neglect the consensus error
\frac{L\alpha}{n}\sum_{i=1}^{n}\|\bar{x}(t)-x_{i}(t)\|
in (
17
) and consider a positive sequence
\{z_{t}\}_{t\geq 0}
satisfying for
t\geq 0
:

z_{t+1}\leq(1-c\alpha)z_{t}+C\alpha

(18)

for some
c>0
and
C>0
, then the tight bound of
z_{t}
using (
18
) is given as

\begin{split}z_{t}&\leq(1-c\alpha)^{t}z_{0}+\sum_{s=0}^{t-1}(1-c\alpha)^{s}C\alpha=(1-c\alpha)^{t}z_{0}+\frac{C}{c}\Big(1-(1-c\alpha)^{t}\Big).\end{split}

Taking the limit
t\rightarrow\infty
in the above estimate gives
\lim_{t\rightarrow\infty}z_{t}\leq\frac{C}{c}
, which is independent of
\alpha>0
.

2.4.2
The idea for the
O(\sqrt{\alpha})
-convergence

To obtain an improvement beyond the
O(1)
-convergence result of
[
23
]
, one needs a new way to estimate the sequence of the PDG involving the projection operator not using the absolute error bound (
14
) for the difference
\phi_{i}(t)
related to the projection.

As a key part for proving the
O(\sqrt{\alpha})
-convergence result of Theorem
8
, we shall use the contraction property of the projection operator (refer to Lemma
28
) in the following way:

\begin{split}&\|x_{i}(t+1)-x_{*}\|^{2}\\
&=\bigg\|\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg]-\mathcal{P}_{\Omega}\left[x_{*}-\alpha(t)\nabla f(x_{*})\right]\bigg\|^{2}\\
&\leq\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-x_{*}-\alpha(t)\left(\nabla f_{i}({x}_{i}(t))-\nabla f(x_{*})\right)\bigg\|^{2}.\end{split}

(19)

We will then sum this inequality over
1\leq i\leq n
and derive a gain from the right hand side, using the strong convexity and the smoothness property of the costs as well as the property of the mixing matrix
W
and some manipulations relying on the identity

\sum^{n}_{i=1}\|a+b_{i}\|^{2}=n\|a\|^{2}+\sum^{n}_{i=1}b_{i}
which holds when
\sum^{n}_{i=1}b_{i}=0
. Then, roughly we will get the following type of inequality

\|\mathbf{x}(t+1)-\mathbf{x}_{*}\|^{2}\leq(1-c\alpha)\|\mathbf{x}(t)-\mathbf{x}_{*}\|^{2}+C\alpha^{2}

(20)

for some constants
c>0
and
C>0
. Using this estimate recursively, one has

\begin{split}\|\mathbf{x}(t)-\mathbf{x}_{*}\|^{2}&\leq(1-c\alpha)^{t}\|\mathbf{x}(0)-\mathbf{x}_{*}\|^{2}+C\alpha^{2}\sum_{s=0}^{t-1}(1-c\alpha)^{s}\\
&\leq(1-c\alpha)^{t}\|\mathbf{x}(0)-\mathbf{x}_{*}\|^{2}+\frac{C\alpha}{c},\end{split}

(21)

which justifies the
O(\sqrt{\alpha})
-convergence of the sequence
\mathbf{x}(t+1)
towards the optimal point
\mathbf{x}_{*}
.

2.4.3
The idea for the
O({\alpha})
-convergence

Before introducing the idea on the
O(\alpha)
-convergence result behind Theorem
11
, let us try to describe briefly a reason why the above argument for Theorem
8
has a limitation in comparison with the arguments used in
[
38
,
11
]
which achieves the
O(\alpha)
-convergence result of the decentralized gradient descent for the case
\Omega=\mathbb{R}^{d}
. Following arguments
[
38
,
11
]
, it turns out that the DGD enjoys the following types of sequential estimates

\begin{split}\|\bar{\mathbf{x}}(t+1)-\mathbf{x}_{*}\|^{2}&\leq(1-c\alpha)\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+C_{1}\alpha^{3}\\
\|{\mathbf{x}}(t+1)-\bar{\mathbf{x}}(t+1)\|^{2}&\leq\gamma\|{\mathbf{x}}(t+1)-\bar{\mathbf{x}}(t+1)\|^{2}+C_{1}\alpha^{2}.\end{split}

(22)

Here
c>0
,
C_{1}>0
and
C_{2}>0
are suitable constants and
\gamma<1
is a value related to the mixing matrix
W
. Then, similarly to (
21
), we may deduce from each of these two estimates the following estimates

\begin{split}\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}&\leq(1-c\alpha)^{t}\|\bar{\mathbf{x}}(0)-\mathbf{x}_{*}\|^{2}+\frac{C_{1}\alpha^{2}}{c}\\
\|{\mathbf{x}}(t)-\bar{\mathbf{x}}(t)\|^{2}&\leq\beta^{t}\|{\mathbf{x}}(0)-\bar{\mathbf{x}}(0)\|^{2}+\frac{C_{2}\alpha^{2}}{1-\beta}.\end{split}

Combining these two estimates then gives the
O(\alpha)
-convergence result of the DGD. In contrast to this argument using the two estimates of (
22
) separately, the argument of subsection 3.4.2 is based on the sequential estimate (
20
) which can be interpreted as a sum of the two estimates of (
22
). This makes a limitation to obtain sharp estimates for
\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}
and
\|{\mathbf{x}}(t)-\bar{\mathbf{x}}(t)\|^{2}
.
This limitation seems difficult to overcome if the proof begins with the estimate (
19
) to deal with the projection operator.

To get around the mentioned difficulty, we develop a new argument which analyzes the convergence of the sequence
x_{k}(t)
after separating the coordinates into two parts, namely the one which is influenced by the projection operator and the other one for which the projection is ignored. We refer to Subsection
4.2
for the details. Although we limit our case to the domain
\Omega=\mathbb{R}^{d-1}\times\mathbb{R}_{+}
in the current work, we believe that the main idea of the argument can be extended to more general domains such as
\mathbb{R}^{q}\times\mathbb{R}_{+}^{d-q}
and any smooth convex domain for any
0\leq q\leq d
.

\alpha\leq\frac{1+\lambda_{n}(W)}{L}

Proof of Theorem
5
for case 2.

We first recall Consider the following functional
E_{\alpha}:(\mathbb{R}^{d})^{n}\rightarrow\mathbb{R}
defined as

E_{\alpha}(x)=\frac{1}{2}\Big(\sum_{i=1}^{n}\|x_{i}\|^{2}-\sum_{i=1}^{n}\sum_{j=1}^{n}w_{ij}\langle x_{i},x_{j}\rangle\Big)+\alpha\sum_{i=1}^{n}f_{i}(x_{i}).

Next, we consider Case 3 in Theorem

Lemma 19
.

Suppose that Assumptions

-

hold and the stepsize

Then the sequence

1.

We have

(30)

2.

\|{\mathbf{x}}(t)-{\mathbf{x}}_{*}\|^{2}\leq R,\ \text{for all $t\in\mathbb{N}$.}

In fact, we may set
R=\max\left\{\frac{4c_{2}}{\mu}\sup_{t\geq 0}\alpha(t),~\|{\mathbf{x}}(0)-{\mathbf{x}}_{*}\|^{2}\right\}

Proof.

We first prove (

17

\begin{split}&\|{\mathbf{x}}(t+1)-{\mathbf{x}}_{*}\|^{2}\\

4
Improved convergence estimate

In this section, we provide the proof of Theorem
11
which establishes the
O(\alpha)
-convergence result for the half-space. Before this, we exhibit a simple example in dimension one for which we show the

-convergence result based on a direct computation of the algorithm. This example suggests that obtaining the

-convergence result for the DPG becomes more intricate than that of the DGD due to the projection operator.

4.1
One-dimensional example

We consider the functions
g_{1},g_{2}:[0,\infty)\rightarrow\mathbb{R}
defined by

g_{1}(x)=5x^{2}\quad\textrm{and}\quad g_{2}(x)=-3x^{2},\quad x\in[1,\infty]

(36)

and the mixing matrix
\tilde{W}
defined by

\tilde{W}=\begin{pmatrix}2/3&1/3\\
1/3&2/3\end{pmatrix}

(37)

satisfying Assumption
4
. We note that the total cost function
g=(g_{1}+g_{2})/2
has the optimal point at
x_{*}=1
. Then we can represent the projected decentralized gradient descent algorithm with a constant stepsize
\alpha
explicitly as follows:

\begin{split}x_{1}(t+1)&=\max\Big[\frac{2}{3}x_{1}(t)+\frac{1}{3}x_{2}(t)-10\alpha x_{1}(t),~1\Big],\\
x_{2}(t+1)&=\max\Big[\frac{1}{3}x_{1}(t)+\frac{2}{3}x_{2}(t)+6\alpha x_{2}(t),~1\Big].\end{split}

(38)

We first establish that the state
(x_{1}(t),x_{2}(t))
generated by the algorithm (
38
) will be confined to a certain region after a finite number of iterations.

Lemma 21
.

Let
g_{1}(x)
,
g_{2}(x)
and the mixing matrix
\tilde{W}
be defined by (
36
) and (
37
) and let
\mathbf{x}(t)=(x_{1}(t),x_{2}(t))
be the state at
t\geq 0
generated by (
38
). Then for any initial state
\mathbf{x}(0)=(x_{1}(0),x_{2}(0))\in[0,1\infty)^{2}
and
\alpha\in(0,1/45)
, there exists
t_{0}\leq\log_{\lambda+}(1/\|\mathbf{x}(0)\|_{2})
such that
x_{1}(t_{0}+1)=1
and
x_{2}(t_{0}+1)\leq 1+30\alpha
, where
\lambda_{+}\in(0,1)
is defined as

\lambda_{+}=\frac{2}{3}-2\alpha+\sqrt{\frac{1}{9}+64\alpha^{2}},

which is less than
1
for
\alpha<1/45
.

Proof.

We divide the proof into three steps.

Step 1
: There is an integer
t_{0}\leq\log\|\mathbf{x}(0)\|_{2}/\log(1/\lambda_{+})
such that
x_{1}(t_{0}+1)=1
.

To show this, we assume that

x_{1}(s)>1\quad\forall~0\leq s\leq\|\mathbf{x}(0)\|_{2}/\log(1/\lambda_{+})+1.

(39)

Then it follows from (
38
) that

\begin{pmatrix}x_{1}(s+1)\\
x_{2}(s+1)\end{pmatrix}=\begin{pmatrix}\frac{2}{3}-10\alpha&\frac{1}{3}\\
\frac{1}{3}&\frac{2}{3}+6\alpha\end{pmatrix}\begin{pmatrix}x_{1}(s)\\
x_{2}(s)\end{pmatrix},

(40)

where we also used that
x_{2}(s+1)>1
since
x_{1}(s)\geq 1
and
x_{2}(s)\geq 1
for all
s\geq 0
.
The eigenvalues of the matrix on the right hand side of (
40
) are

\lambda_{\pm}=\frac{2}{3}-2\alpha\pm\sqrt{\frac{1}{9}+64\alpha^{2}}

which are positive and less than
1
for
\alpha\in(0,1/45)
. Therefore

\|(x_{1}(s+1),x_{2}(s+1))\|_{2}\leq\lambda_{+}\|(x_{1}(s),x_{2}(s))\|_{2},

and so

\|(x_{1}(s),x_{2}(s))\|_{2}\leq\lambda_{+}^{s}\|(x_{1}(0),x_{2}(0))\|_{2}\quad\forall~0\leq s\leq\|\mathbf{x}(0)\|_{2}/\log(1/\lambda_{+})+1.

Let
s_{0}
be the maximal integer
\leq\|\mathbf{x}(0)\|_{2}/\log(1/\lambda_{+})+1
. Then it follows from the above inequality that

\|(x_{1}(s_{0}),x_{2}(s_{0}))\|_{2}\leq\lambda_{+}^{s_{0}}\|(x_{1}(0),x_{2}(0))\|_{2}\leq 1.

This yields that
x_{1}(s_{0})\leq 1
, which contradicts to the fact that
x_{1}(s_{0})>1
from the assumption (
39
). Therefore (
39
) is not true, and so there exists an integer
t_{0}\leq\log_{\lambda+}(1/\|\mathbf{x}(0)\|_{2})
such that
x_{1}(t_{0}+1)\leq 1
.

Step 2
: It holds that

x_{1}(t_{0})\leq(3-x_{2}(t_{0}))/(2-30\alpha)\quad\textrm{and}\quad x_{2}(t_{0})\leq 1+30\alpha.

(41)

In order to find these estimates, we combine
x_{1}(t_{0}+1)=1
and (
38
) to see that

\frac{2}{3}x_{1}(t_{0})+\frac{1}{3}x_{2}(t_{0})-10\alpha x_{1}(t_{0})\leq 1.

This leads to
x_{1}(t_{0})\leq(3-x_{2}(t_{0}))/(2-30\alpha)
and

\begin{split}\frac{1}{3}x_{2}(t_{0})&\leq 1-\Big(\frac{2}{3}-10\alpha\Big)x_{1}(t_{0})\\
&\leq 1-\Big(\frac{2}{3}-10\alpha\Big)=\frac{1}{3}+10\alpha,\end{split}

which implies that
x_{2}(t_{0})\leq 1+30\alpha
.

Step 3
: We have
x_{2}(t_{0}+1)\leq 1+30\alpha
.

Using (
41
) we deduce

\begin{split}\frac{1}{3}x_{1}(t_{0})+\Big(\frac{2}{3}+6\alpha\Big)x_{2}(t_{0})&\leq\frac{1}{3}\Big(\frac{3-x_{2}(t_{0})}{2-30\alpha}\Big)+\Big(\frac{2}{3}+6\alpha\Big)x_{2}(t_{0})\\
&=\frac{1}{2-30\alpha}+\Big(\frac{2}{3}+6\alpha-\frac{1}{6-90\alpha}\Big)x_{2}(t_{0}).\end{split}

Inserting this into (
38
) we find

\begin{split}x_{2}(t_{0}+1)&=\max\left[\frac{1}{3}x_{1}(t_{0})+\Big(\frac{2}{3}+6\alpha\Big)x_{2}(t_{0}),1\right]\\
&=\max\left[\frac{1}{2-30\alpha}+\Big(\frac{2}{3}+6\alpha-\frac{1}{6-90\alpha}\Big)x_{2}(t_{0}),1\right].\end{split}

Combining this with
x_{2}(t_{0})\leq 1+30\alpha
, we get

\begin{split}x_{2}(t_{0}+1)&\leq\max\left[\frac{1}{2-30\alpha}+\Big(\frac{2}{3}+6\alpha-\frac{1}{6-90\alpha}\Big)(1+30\alpha),1\right]\\
&\leq 1+30\alpha.\end{split}

Here the second inequality follows by observing the first component in the max operator equivalent form

1\leq(1-22\alpha+180\alpha^{2})(1+30\alpha).

This can be rewritten as

0\leq\alpha(1-45\alpha)(1-15\alpha),

which holds true for
\alpha\in(0,1/45)
.

Now, we verify that the state
(x_{1}(t),x_{2}(t))
generated by the algorithm (
38
) converges to an
O(\alpha)
neighborhood of the optimal point
(1,1)
.

Theorem 22
.

Let
g_{1}(x)
,
g_{2}(x)
and the mixing matrix
\tilde{W}
be defined by (
36
) and (
37
) and let
\mathbf{x}(t)=(x_{1}(t),x_{2}(t))
be the state at
t\geq 0
generated by (
38

\mathbf{x}(0)=(x_{1}(0),x_{2}(0))
and
\alpha\in(0,1/45)
, the state
\mathbf{x}(t)
converges exponentially fast to the point
(1,1/(1-18\alpha))
.

Proof.

By Lemma
21
, we can choose
t_{0}
satisfying
x_{1}(t_{0}+1)=1
and
x_{2}(t_{0}+1)\leq 1+30\alpha
. Note that if
\alpha<1/45
then
1/(1-18\alpha)<1+30\alpha
. First it follows from (
38
) that

x_{1}(t+1)=\max\Big[\frac{2}{3}x_{1}(t)+\frac{1}{3}x_{2}(t)-10\alpha x_{1}(t),~1\Big]=1

(42)

using the following inequality

\frac{2}{3}x_{1}(t_{0}+1)+\frac{1}{3}x_{2}(t_{0}+1)-10\alpha<1,

owing to the fact that
x_{1}(t_{0}+1)=1
and
x_{2}(t_{0}+1)<1+30\alpha
. Next, we use the fact
\frac{1}{3}x_{1}(t_{0}+1)+\frac{2}{3}x_{2}(t_{0}+1)\geq 1
and the formula (
38
) to find the following identity

\begin{split}x_{2}(t_{0}+2)&=\frac{1}{3}x_{1}(t_{0}+1)+\frac{2}{3}x_{2}(t_{0}+1)+6\alpha x_{2}(t_{0}+1)\\
&=\frac{1}{3}x_{1}(t_{0}+1)+\frac{2+18\alpha}{3}x_{2}(t_{0}+1).\end{split}

Using this and
x_{1}(t_{0}+1)=1
, we get

x_{2}(t_{0}+2)-\frac{1}{1-18\alpha}=\frac{2+18\alpha}{3}\left[x_{2}(t_{0}+1)-\frac{1}{1-18\alpha}\right].

(43)

Since
(2+18\alpha)/3<1
, it follows that
x_{2}(t_{0}+2)<x_{2}(t_{0}+1)<1+30\alpha
for
x_{2}(t_{0}+1)>\frac{1}{1-18\alpha}
, and
1\leq x_{2}(t_{0}+2)\leq\frac{1}{1-18\alpha}
for
1\leq x_{2}(t_{0}+1)\leq\frac{1}{1-18\alpha}
. We can conclude that
x_{1}(t)=1
and
x_{2}(t)<1+30\alpha
for all
t\geq t_{0}+1
. In addition, (
43
) implies that
x_{2}(t)
converges to
1/(1-18\alpha)
exponentially fast.

In the above result, we note that for

\Big|\frac{1}{1-18\alpha}-1\Big|=\frac{18\alpha}{1-18\alpha}\leq 30\alpha.

Therefore the above result shows that
x_{2}(t)
converges to a point within

, implying that the sequence
\{(x_{1}(t),x_{2}(t))\}_{t\geq 0}
converges to an
O(\alpha)
-neighborhood of the optimal point
x_{*}=1
. This result is sharper than the convergence to an
O(\sqrt{\alpha})
-neighborhood obtained in Theorem
8
.

Lemma 23
.

Let
\{x_{i}(t)\}_{t\geq 0}
be the sequence generated by (
2
) with constant stepsize
\alpha>0
. Then there is a positive value
J\leq\frac{2}{L+\mu}
such that for any
\alpha\in(0,J]
we have a time instant
T_{\alpha}\in\mathbb{N}
satisfying the following estimate

\|x_{i}(t)-x_{*}\|\leq\frac{w}{2L}

and

\frac{1}{n}\sum_{i=1}^{n}\partial_{d}f_{i}(x_{i}(t))\geq\frac{w}{2}

(44)

for any
t\geq T_{\alpha}
.

Proof.

By Theorem
8
, there exist a time
T_{\alpha}\in\mathbb{N}
such that

\|x_{i}(t)-x_{*}\|=O(\sqrt{\alpha})
for
t\geq T_{\alpha}
if the stepsize
\alpha>0
satisfies
\alpha\leq\frac{2}{L+\mu}
. Therefore, there exists a suitable value
J>0
such that
\|x_{i}(t)-x_{*}\|\leq\frac{w}{2L}
for
\alpha\in(0,J)
.

Since a local cost function
f_{i}
is
L
-smooth and
x_{i}(t)\in\mathbb{R}^{d}
satisfies
\|x_{i}(t)-x_{*}\|\leq\frac{w}{2L}
for
1\leq i\leq n
and
t\geq T_{\alpha}
, we have

\begin{split}\frac{1}{n}\sum_{k=1}^{n}\partial_{d}f_{i}(x_{i}(t))&=\frac{1}{n}\sum_{i=1}^{n}\partial_{d}f_{i}(x_{*})+\frac{1}{n}\sum_{k=1}^{n}\Big(\partial_{d}f_{i}(x_{i}(t))-\partial f_{i}(x_{*})\Big)\\
&\geq w-L\Big(\frac{w}{2L}\Big)=\frac{\omega}{2}.\end{split}

The proof is done.

To verify that a sequence
x_{k}(t)
converges to an

-neighborhood of the optimal point, we first show that there exists a time

such that for all

\bar{x}(t)[d]\leq O(\alpha).
For this aim, we introduce the following lemma.

Lemma 24
.

Take any
\alpha\in(0,J]
and all
t\geq T_{\alpha}
. Then we have the following results.

Case 1.

Assume that
\sum_{j=1}^{n}w_{ij}x_{j}(t)-\eta\nabla f_{i}(x_{i}(t))
belongs to
\Omega
for all
1\leq i\leq n
. Then we have

\bar{x}(t+1)[d]\leq\bar{x}(t)[d]-\frac{\omega\alpha}{2}.

(45)

Case 2.

Assume that
\sum_{j=1}^{n}w_{ij}x_{j}(t)-\eta\nabla f_{i}(x_{i}(t))
does not belong to
\Omega
for some
1\leq i\leq n
. Then we have

\bar{x}(t+1)[d]\leq\left(\beta^{t+1}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}\right)^{1/2}.

(46)

Proof.

We begin by proving the first case, where the projection operator becomes negligible in (
2
) so that

x_{i}(t+1)=\sum_{j=1}^{n}w_{ij}x_{j}(t)-\alpha\nabla f_{i}(x_{i}(t))\quad\forall~1\leq i\leq n.

Averaging this for
1\leq i\leq n
gives

\bar{x}(t+1)=\bar{x}(t)-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}(x_{i}(t)).

Considering the
d
-th coordinate of the above formula and using (
44
), it follows that

\begin{split}\bar{x}(t+1)[d]&=\bar{x}(t)[d]-\frac{\alpha}{n}\sum_{i=1}^{n}\partial_{d}f_{i}(x_{i}(t))\leq\bar{x}(t)[d]-\frac{\omega\alpha}{2}.\end{split}

Next, we prove the second case. In this case, we have some
1\leq i\leq n
such that

\Big(\sum_{j=1}^{n}w_{ij}x_{j}(t)-\eta\nabla f_{i}(x_{i}(t))\Big)[d]\leq 0,

and consequently,

x_{i}(t+1)[d]=P_{\Omega}\left[\sum_{j=1}^{n}w_{ij}x_{j}(t)-\eta\nabla f_{i}(x_{i}(t))\right][d]=0.

Therefore

\begin{split}(\bar{x}(t+1)[d])^{2}&=|\bar{x}(t+1)[d]-x_{i}(t+1)[d]|^{2}\\
&\leq\|\bar{x}(t+1)-x_{i}(t+1)\|^{2}\\
&\leq\beta^{t+1}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}},\end{split}

where we used Theorem
7
for the last inequality.

In the following, we show that there exists a time
T
such that for all

\bar{x}(t)[d]\leq O(\alpha).

Proposition 25
.

Let
t_{0}\in\mathbb{N}
be the smallest number such that
\frac{\omega\alpha}{2}t_{0}>K
with
K>0
defined as

K=\Big\{\bar{x}(T_{\alpha})[d],~\Big(\beta\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}\Big)^{1/2}\Big\},

\bar{x}(t+1)[d]\leq\frac{\sqrt{6(L^{2}R_{s}+nR_{D}^{*})}\alpha}{1-\beta}.

For each

\bar{x}(t+1)

\max\Big\{\bar{x}(t)[d]-\frac{w\alpha}{2},~\Big(\beta^{t+1}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}\Big)^{1/2}\Big\}.

(47)

From this we find that for
t\geq T_{\alpha}

\bar{x}(t)[d]\leq\max\Big\{\bar{x}(T_{\alpha})[d],~\Big(\beta\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}\Big)^{1/2}\Big\}=K.

Therefore we have

\bar{x}\Big(\max\{T_{\alpha},t_{1}\}\Big)[d]\leq K.

(48)

Also, the estimate (
47

\bar{x}(t+1)[d]\leq\max\Big\{\bar{x}(t)[d]-\frac{w\alpha}{2},~\frac{\sqrt{6(L^{2}R_{s}+nR_{D}^{*})}\alpha}{1-\beta}\Big\}.

Combining this with (

\bar{x}(t+1)[d]\leq\frac{\sqrt{6(L^{2}R_{s}+nR_{D}^{*})}\alpha}{1-\beta}\quad\textrm{for}~t\geq t_{0}+\max\{T_{\alpha},t_{1}\}.

(49)

It completes the proof.

\tilde{x}_{*}

1\leq k\leq n

Lemma 26

Let
T\in\mathbb{N}

d-1

\begin{split}&\Big\langle y(t)-\tilde{x}_{*},~\tilde{\nabla}f(\bar{x}(t))-\tilde{\nabla}f(x_{*})\Big\rangle\\

&\qquad\qquad\qquad\qquad\qquad\qquad\qquad-\frac{2(L+\mu)}{\mu}\cdot\frac{9L(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}}.\end{split}

Proof.

Using the fact that
f

L

25

\begin{split}&\Big|\Big\langle\bar{x}(t)[d]-x_{*}[d],~(\partial_{d}f(\bar{x}(t))-\partial_{d}f(x_{*}))\Big\rangle\Big|\\

\begin{split}&\Big\langle\bar{x}(t)-x_{*},~\nabla f(\bar{x}(t))-\nabla f(x_{*})\Big\rangle\\

\begin{split}&\Big\langle y(t)-\tilde{x}_{*},~\tilde{\nabla}f(\bar{x}(t))-\tilde{\nabla}f(x_{*})\Big\rangle\\
&\geq\frac{L\mu}{2(L+\mu)}\|\bar{x}(t)-x_{*}\|^{2}+\frac{1}{L+\mu}\|\nabla f(\bar{x}(t))-\nabla f(x_{*})\|^{2}\\
&\qquad\qquad\qquad\qquad\qquad\qquad\qquad-\frac{(L+\mu)}{\mu}\cdot\frac{3L(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{(1-\beta)^{2}},\end{split}

which proves the lemma.

Proposition 27
.

Let

\alpha\in(0,J]

\nu_{1}>0

\big\|y(t)-\tilde{x}_{*}\big\|^{2}\leq(1-\nu_{1}\alpha)^{t}\big\|y(0)-\tilde{x}_{*}\big\|^{2}+\frac{\nu_{2}}{\nu_{1}}\alpha^{2}.

Proof.

We express the first
d-1

\tilde{x}_{i}(t+1)=\sum_{j=1}^{n}w_{ij}\tilde{x}_{j}(t)-\alpha\tilde{\nabla}f_{i}(x_{i}(t)).

(51)

Averaging this for
1\leq i\leq n
, we get the following formula
(
51

y(t+1)=y(t)-\alpha\tilde{\nabla}f(\bar{x}(t))+\alpha\left(\tilde{\nabla}f(\bar{x}(t))-\frac{1}{n}\sum^{n}_{i=1}\tilde{\nabla}f_{i}(x_{i}(t))\right).

(52)

Using the fact that
f_{i}
is
L
-smooth and Theorem
7
, we have

\begin{split}\left\|\tilde{\nabla}f(\bar{x}(t))-\frac{1}{n}\sum^{n}_{i=1}\tilde{\nabla}f_{i}(x_{i}(t))\right\|^{2}&\leq\frac{1}{n}\sum^{n}_{i=1}\left\|\tilde{\nabla}f_{i}(\bar{x}(t)-\tilde{\nabla}f_{i}(x_{i}(t))\right\|^{2}\\

&\leq L^{2}\beta^{t}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{3L^{2}(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{1-\beta}\\
&\leq\frac{6L^{2}(L^{2}R_{s}+nR_{D}^{*})\alpha^{2}}{1-\beta},\end{split}

(53)

where we used the fact that
T>t_{1}
with
t_{1}
defined in Proposition
25
for the last inequality. Using (
52
), Young’s inequality and (
53

\begin{split}&\|y(t+1)-\tilde{x}_{*}\|^{2}\\
=&\left\|y(t)-\alpha f(\bar{x}(t))+\alpha\left(\tilde{\nabla}f(\bar{x}(t))-\frac{1}{n}\sum^{n}_{i=1}\tilde{\nabla}f_{i}(x_{i}(t))\right)\right\|^{2}\\
\leq&(1+c\alpha)\left\|y(t)-\alpha\tilde{f}(\bar{x}(t))-\tilde{x}_{*}\right\|^{2}+\left(1+\frac{1}{c\alpha}\right)\frac{6L^{2}(L^{2}R_{s}+nR_{D}^{*})}{(1-\beta)^{2}}\alpha^{4},\end{split}

(54)

where we have let

Next, we estimate the first term in the last inequality in (

\tilde{\nabla}f(x_{*})=0

\begin{split}&\|y(t)-\alpha\tilde{\nabla}f(\bar{x}(t))-\tilde{x}_{*}\|^{2}\\

Applying Lemma
26

\begin{split}&\|y(t)-\alpha\tilde{\nabla}f(\bar{x}(t))-\tilde{x}_{*}\|^{2}\\
&\geq\Big(1-\frac{L\mu}{L+\mu}\alpha\Big)\big\|y(t)-\tilde{x}_{*}\big\|^{2}+\Big(\alpha^{2}-\frac{2\alpha}{L+\mu}\Big)\Big\|\Big(\tilde{\nabla}f(\bar{x}(t))-\tilde{\nabla}f(x_{*})\Big)\Big\|^{2}\\
&\quad+\frac{2(L+\mu)}{\mu}\cdot\frac{3L(L^{2}R_{s}+nR_{D}^{*})\alpha^{3}}{(1-\beta)^{2}}.\end{split}

This inequality with the condition

\begin{split}&\|y(t)-\eta\tilde{\nabla}f(\bar{x}(t))-\tilde{x}_{*}\|^{2}\\

(55)

Putting (
55

\begin{split}&\|y(t+1)-\tilde{x}_{*}\|^{2}\\

&\leq\Big(1-\frac{L\mu}{2(L+\mu)}\alpha\Big)\big\|y(t)-\tilde{x}_{*}\big\|^{2}+(1+c)\frac{2(L+\mu)}{\mu}\cdot\frac{3L(L^{2}R_{s}+nR_{D}^{*})\alpha^{3}}{(1-\beta)^{2}}\\
&\qquad\qquad\qquad\qquad\qquad+\left(1+\frac{1}{c}\right)\frac{6L^{2}(L^{2}R_{s}+nR_{D}^{*})}{(1-\beta)^{2}}\alpha^{3},\end{split}

where the second inequality follows using that

\|y(t+1)-\tilde{x}_{*}\|^{2}\leq(1-\nu_{1}\alpha)\big\|y(t)-\tilde{x}_{*}\big\|^{2}+\nu_{2}\alpha^{3},

Using this iteratively, we get

\begin{split}\big\|y(t)-\tilde{x}_{*}\big\|^{2}&\leq(1-\nu_{1}\alpha)^{t}\big\|y(0)-\tilde{x}_{*}\big\|^{2}+\nu_{2}\alpha^{3}\sum_{s=0}^{t-1}(1-\nu_{1}\alpha)^{s}\\
&\leq(1-\nu_{1}\alpha)^{t}\big\|\tilde{x}(0)-\tilde{x}_{*}\big\|^{2}+\frac{\nu_{2}}{\nu_{1}}\alpha^{2},\end{split}

which completes the proof.

.

First we consider the case that
\alpha\in(0,J)
since

\begin{split}&\|\tilde{x}_{i}(t)-\tilde{x}_{*}\|^{2}\\

&\leq 2\beta^{t}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+2(1-\nu_{1}\alpha)^{t}\|y(0)-\tilde{x}_{*}\|^{2}+\left(\frac{6(L^{2}R_{s}+nR_{D}^{*})}{(1-\beta)^{2}}+\frac{2\nu_{2}}{\nu_{1}}\right)\alpha^{2},\end{split}

By Proposition

\begin{split}\|x_{i}(t)[d]\|^{2}&\leq 2\|x_{i}(t)[d]-\bar{x}(t)\|^{2}+2\|\bar{x}(t)\|^{2}\\
&\leq 2\beta^{t}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+\frac{12(L^{2}R_{s}+nR_{D}^{*})}{(1-\beta)^{2}}\alpha^{2}.\end{split}

Inserting the above two estimates in (

\begin{split}&\|x_{i}(t)-x_{*}\|^{2}\leq 4\beta^{t}\|{\mathbf{x}}(0)-{\bar{\mathbf{x}}}(0)\|^{2}+2(1-\nu_{1}\alpha)^{t}\|y(0)-\tilde{x}_{*}\|^{2}+\\
&\qquad\qquad\qquad+\left(\frac{18(L^{2}R_{s}+nR_{D}^{*})}{(1-\beta)^{2}}+\frac{2\nu_{2}}{\nu_{1}}\right)\alpha^{2}.\end{split}

This gives for

\underset{t\rightarrow\infty}{\textrm{limsup}}\,\|x_{i}(t)-x_{*}\|^{2}=O(\alpha^{2}).

For
J\leq\alpha\leq\frac{2}{L+\mu}
, we may use the result of Theorem
8
to derive

\underset{t\rightarrow\infty}{\textrm{limsup}}\,\|x_{i}(t)-x_{*}\|^{2}\leq C\alpha\leq\frac{C}{J}\alpha^{2}.

Combining the above two estimates completes the proof.

6
Conclusion

In this paper, we have introduced new convergence estimates for the decentralized projected gradient method. Our findings guarantee that when the algorithm employs a fixed step size
\alpha
(where
\alpha
is a positive constant) below a certain threshold, it converges to an

neighborhood of the optimal solution exponentially fast. Furthermore, we have established exact convergence results for the case with diminishing stepsize

for

\Omega=\mathbb{R}^{d-1}\times\mathbb{R}_{+}
with any
d\geq 1

Lemma 30

Proof.

By

, we have

\sum^{n}_{i=1}\|\nabla f_{i}({x}_{i})-\nabla f_{i}(\bar{x})\|^{2}\leq L^{2}\sum^{n}_{i=1}\|{x}_{i}-\bar{x}\|^{2},

which directly implies (

Next, we prove (

\begin{split}\sum^{n}_{i=1}\left\|a_{i}-\frac{1}{n}\sum^{n}_{l=1}a_{l}\right\|^{2}&=\sum^{n}_{i=1}\left(\|a_{i}\|^{2}-2\left\langle a_{i},\frac{1}{n}\sum^{n}_{l=1}a_{l}\right\rangle+\frac{1}{n^{2}}\left\|\sum^{n}_{l=1}a_{l}\right\|^{2}\right)\\

Using this, it follows that

\begin{split}\sum_{i=1}^{n}\left\|\nabla f_{i}({x}_{i})-\frac{1}{n}\sum_{l=1}^{n}\nabla f_{l}({x}_{l})\right\|^{2}&\leq\sum^{n}_{i=1}\|\nabla f_{i}({x}_{i}(t))\|^{2}.\end{split}

(63)

\begin{split}\|\nabla f_{i}({x}_{i})\|^{2}&\leq 3\|\nabla f_{i}({x}_{i})-\nabla f_{i}(\bar{x})\|^{2}+3\|\nabla f_{i}(\bar{x})-\nabla f_{i}(x_{*})\|^{2}+3\|\nabla f_{i}(x_{*})\|^{2}.\end{split}

\sum^{n}_{i=1}\|\nabla f_{i}({x}_{i})\|^{2}\leq 3L^{2}\|\mathbf{x}-\bar{\mathbf{x}}\|^{2}+3L^{2}\|\bar{\mathbf{x}}-\mathbf{x}_{*}\|^{2}+3nD^{2}.

Combining this with (

\begin{split}\sum_{i=1}^{n}\left\|\nabla f_{i}({x}_{i})-\frac{1}{n}\sum_{l=1}^{n}\nabla f_{l}({x}_{l})\right\|^{2}&\leq\sum^{n}_{i=1}\|\nabla f_{i}({x}_{i}(t))\|^{2}.\\
&\leq 3L^{2}\|\mathbf{x}-\bar{\mathbf{x}}\|^{2}+3L^{2}\|\bar{\mathbf{x}}-\mathbf{x}_{*}\|^{2}+3nD^{2}.\end{split}

Lemma 32
.

Suppose that Assumptions
1
and
2

\{\alpha(t)\}_{t\geq 0}

By Young’s inequality, for any

\begin{split}n\left(1+\frac{4}{\mu\alpha(t)}\right)\alpha(t)^{2}\|Y(t)\|^{2}&\leq\left(1+\frac{4}{\mu\alpha(t)}\right)L^{2}\alpha(t)^{2}\sum_{i=1}^{n}\|x_{i}(t)-\bar{x}(t)\|^{2}\\

Proof of Proposition
16
.

We recall Young’s inequality, which is useful for our derivations: For any vectors
u
and
v
in
\mathbb{R}^{d}
, we have

\|u+v\|^{2}\leq(1+\delta)\|u\|^{2}+\left(1+\frac{1}{\delta}\right)\|v\|^{2}

Using the DPG algorithm in (
2
), we can write
\|x_{i}(t+1)-\bar{x}(t+1)\|^{2}
as

\left\|\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg]-\frac{1}{n}\sum^{n}_{k=1}\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{kj}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{k}(t))\bigg]\right\|^{2}.

Summing this
i=1
to
n
and applying Lemma
29
, it follows that

\begin{split}&\sum^{n}_{i=1}\|x_{i}(t+1)-\bar{x}(t+1)\|^{2}\\
&\leq\sum^{n}_{i=1}\left\|\sum^{n}_{j=1}w_{ij}\left(x_{j}(t)-\bar{x}(t)\right)-\alpha(t)\nabla f_{i}({x}_{i}(t))+\frac{\alpha(t)}{n}\sum^{n}_{l=1}\nabla f_{l}({x}_{l}(t))\right\|^{2}.\end{split}

(68)

where Applying Young’s inequality with

u=\sum^{n}_{j=1}w_{ij}\left(x_{j}(t)-\bar{x}(t)\right),\ v=\alpha(t)\left(\nabla f_{i}({x}_{i}(t))+\frac{1}{n}\sum^{n}_{l=1}\nabla f_{l}({x}_{l}(t))\right),

the last term is bounded as

(1+\delta)\left\|W(\mathbf{x}(t)-\bar{\mathbf{x}}(t))\right\|^{2}+\sum^{n}_{i=1}\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}\left\|\nabla f_{i}({x}_{i}(t))+\frac{1}{n}\sum^{n}_{l=1}\nabla f_{l}({x}_{l}(t))\right\|^{2}.

Here we used the fact that
\sum^{n}_{i=1}\|x_{i}(t)-\bar{x}(t)\|^{2}=\|{\mathbf{x}}(t)-{\bar{\mathbf{x}}}(t)\|^{2}
. Now, applying Lemma
33
, we bound the first term as:

(1+\delta)\beta^{2}\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2},

Using Lemma
31
, the second term is bounded as

\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}\left(3L^{2}\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}+3L^{2}\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+3nD^{2}\right).

Putting all together, we obtain the desired estimate:

\begin{split}&\sum^{n}_{i=1}\|x_{i}(t+1)-\bar{x}(t+1)\|^{2}\\
\leq&(1+\delta)\left\|W(\mathbf{x}(t)-\bar{\mathbf{x}}(t))\right\|^{2}+\sum^{n}_{i=1}\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}\left\|\nabla f_{i}({x}_{i}(t))+\frac{1}{n}\sum^{n}_{l=1}\nabla f_{l}({x}_{l}(t))\right\|^{2}\\
\leq&\left(3L^{2}\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}+(1+\delta)\beta^{2}\right)\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}\\
&\qquad\qquad\qquad\qquad\qquad+3L^{2}\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+3nD^{2}\left(1+\frac{1}{\delta}\right)\alpha(t)^{2}\\
=&(c_{1}\alpha(t)^{2}+(1+\delta)\beta^{2})\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}+c_{1}\alpha(t)^{2}\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+c_{2}\alpha(t)^{2},\end{split}

which completes the proof.

Proof of Proposition
17
.

By the DPG algorithm and using the contraction property of the projection operator in Lemma
28
, we deduce

\begin{split}\|x_{i}(t+1)-x_{*}\|^{2}&=\bigg\|\mathcal{P}_{\Omega}\bigg[\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg]-\mathcal{P}_{\Omega}\left[x_{*}-\alpha(t)\nabla f(x_{*})\right]\bigg\|^{2}\\
&\leq\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-x_{*}-\alpha(t)\left(\nabla f_{i}({x}_{i}(t))-\nabla f(x_{*})\right)\bigg\|^{2}.\end{split}

For the first equality, we used the fact that
x_{*}=\mathcal{P}_{\Omega}\left[x_{*}-\alpha(t)\nabla f(x_{*})\right]
, which follows from
x_{*}=\arg\min_{x\in\Omega}f(x)
.
Summing up the above inequality from
i=1
to
n
, we have

\sum^{n}_{i=1}\|x_{i}(t+1)-x_{*}\|^{2}\leq\sum^{n}_{i=1}\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-x_{*}-\alpha(t)\left(\nabla f_{i}({x}_{i}(t))-\nabla f(x_{*})\right)\bigg\|^{2}.

(69)

Denoting
P(t)
as

P(t)=\bar{x}(t)-\frac{\alpha(t)}{n}\sum^{n}_{l=1}\nabla f_{l}(x_{l}(t)),

we find the following identity of the right-hand side of (
69
):

\begin{split}&\sum^{n}_{i=1}\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-x_{*}-\alpha(t)\left(\nabla f_{i}({x}_{i}(t))-\nabla f(x_{*})\right)\bigg\|^{2}\\
&=\sum^{n}_{i=1}\bigg\|P(t)-(x_{*}-\alpha(t)\nabla f(x_{*}))-P(t)+\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))\bigg\|^{2}\\
&=n\bigg\|P(t)-\left(x_{*}-\alpha(t)\nabla f(x_{*})\right)\bigg\|^{2}+\sum^{n}_{i=1}\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))-P(t)\bigg\|^{2}.\end{split}

(70)

For the last equality, we used

\begin{split}&\sum^{n}_{i=1}\Big(\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))-P(t)\Big)\\
&=\sum^{n}_{j=1}x_{j}(t)-\alpha(t)\sum^{n}_{i=1}\nabla f_{i}(x_{i}(t))-nP(t)=0,\end{split}

and the fact that
\sum^{n}_{i=1}\|a+b_{i}\|^{2}=n\|a\|^{2}+\sum^{n}_{i=1}b_{i}
if
\sum^{n}_{i=1}b_{i}=0
.
Now we estimate the first term on the right-hand side of the last equality in (
70
) as follows:

\begin{split}&n\bigg\|P(t)-\left(x_{*}-\alpha(t)\nabla f(x_{*})\right)\bigg\|^{2}\\
&=n\left\|\bar{x}(t)-x_{*}-\alpha(t)\left(\frac{1}{n}\sum^{n}_{i=1}\nabla f_{i}({x}_{i}(t))-\nabla f(x_{*})\right)\right\|^{2}\\
&\leq\bigg(1-\frac{\mu\alpha(t)}{2}\bigg)\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+\bigg(L^{2}\alpha(t)^{2}+\frac{4L^{2}\alpha(t)}{\mu}\bigg)\|\bar{\mathbf{x}}(t)-\mathbf{x}(t)\|^{2},\end{split}

where we applied Lemma
32
for the last inequality.

Now we estimate the second term on the right-hand side of the last equality in (
70
), which is equal to the right-hand side of (
68
). Therefore, we can apply the estimate for (
68
) to the second term in the last equality of (
70
) and obtain

\begin{split}&\sum^{n}_{i=1}\bigg\|\sum^{n}_{j=1}w_{ij}x_{j}(t)-\alpha(t)\nabla f_{i}({x}_{i}(t))-P(t)\bigg\|^{2}\\
&=\sum^{n}_{i=1}\bigg\|\sum^{n}_{j=1}w_{ij}\Big(x_{j}(t)-\bar{x}(t)\Big)-\alpha(t)\Big(\nabla f_{i}({x}_{i}(t))-\frac{1}{n}\sum^{n}_{l=1}\nabla f_{l}(x_{l}(t))\Big)\bigg\|^{2}\\
&\leq(c_{1}\alpha(t)^{2}+(1+\delta)\beta^{2})\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}+c_{1}\alpha(t)^{2}\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+c_{2}\alpha(t)^{2}.\end{split}

Putting the above two estimates in the last term of (

), we get

\begin{split}\sum^{n}_{i=1}\|x_{i}(t+1)-x_{*}\|^{2}&=\|\mathbf{x}(t+1)-\bar{\mathbf{x}}(t+1)\|^{2}+\|\bar{\mathbf{x}}(t+1)-\mathbf{x}_{*}\|^{2}.\\
&\leq\bigg(\Big(c_{1}+L^{2}\Big)\alpha(t)^{2}+\frac{4L^{2}\alpha(t)}{\mu}+\tilde{\beta}\bigg)\|\mathbf{x}(t)-\bar{\mathbf{x}}(t)\|^{2}\\
&\qquad\qquad+\bigg(1-\frac{\mu\alpha(t)}{2}+c_{1}\alpha(t)^{2}\bigg)\|\bar{\mathbf{x}}(t)-\mathbf{x}_{*}\|^{2}+c_{2}\alpha(t)^{2},\end{split}

which completes the proof.
