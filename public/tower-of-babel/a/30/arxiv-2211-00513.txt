E2E Refined Dataset
Keisuke Toyama, Katsuhito Sudoh, Satoshi Nakamura

Abstract
Although the well-known MR-to-text E2E dataset has been used by many researchers, its MR-text pairs include many deletion/insertion/substitution errors. Since such errors affect the quality of MR-to-text systems, they must be fixed as much as possible. Therefore, we developed a refined dataset and some python programs that convert the original E2E dataset into a refined dataset.

2
Text Refinement

2.1
Error Correction

We corrected the following types of errors in the original E2E dataset.
Some examples are shown in
Table 4
.
Note that although our corrections may not be exhaustive, they will support future studies.

Irregular MR Values:

Each attribute of an MR should have only one value or be empty.
However, some MR data have two values for the
name
and
near
attributes.
We removed such irrelevant data from the dataset.

Overlaps:

We removed a phrase that appears twice in a sentence.

Indefinite Articles:

We corrected usage mistakes in the indefinite articles of “a” and “an.”

Typos:

We corrected over 3,700 typos in the MR values and sentences.

2.2
Normalization

British English:

Since the E2E dataset is based on British English, we replaced such words with American spellings as “center”, “flavor”, “organize”, and “traveling” with “centre”, “flavour”, “organise”, and “travelling.”

Prices:

priceRange
is categorized into “cheap”, “moderate”, “expensive”, “lower than £20”, “£20-25”, and “more than £30” (
Table 6
).
In that case, “£23” should be labelled as “£20-25”.
However, the value of such prices as “£23”, “£22”, “£24”, and “from £20 to £25” in the sentences cannot be determined uniquely from the label “£20-25”.
To avoid this issue, we replaced all of the price values that should be labelled as “£20-25” with “£20-25”.
The same idea was also applied to “lower than £20” and “more than £30” labels.

Currency Expressions:

To simplify the expressions of currency units, we use “£20” instead of “20 pounds”, “20gbp”, “20lb”, “20 quid” and so on.

Symbols:

We normalized such symbols as periods, commas, white spaces, etc.

Quotation Marks:

We use single quotation marks instead of double quotations in the refined dataset.

Capital Letters:

We fixed the capitalization errors in proper nouns and words that begin sentences.

3
MR Refinement

3.1
Label Names

We replaced “high” with “expensive” for the
priceRange
attribute.
For the
food
attribute, we defined additional labels: “American”, “Canadian”, “Indian”, and “Thai”.
The refined labels are listed in
Table 6
.

3.2
Labelling Errors

We manually corrected the MR labelling errors throughout the E2E dataset.

3.3
MR Order

We annotated the order of the mentions of the MR values in the corresponding sentences in
Table 6
.
If the MR value is empty, the order is represented by “0”.

3.4
Number of Sentences

We put the number of sentences in the text part, as shown in
Table 6
.
We simply found the number of sentences using periods (“.”) and question marks (“?”).
Since the example in
Table 6
shows that the text part includes three periods, we set its number of sentences to “3”.

3.5
Sentence Indexes

We also annotated each MR value with its appearance in the text by sentence-level indexes (
Table 6
).
The example in
Table 6
shows that the values of
eatType
,
area
, and
familyFriendly
appear in the first, second, and third sentences, respectively.
The index is set to “0” when an MR value is empty.

4
Others

Delexicalization:

Because all of the
name
and
near
values appear as-is in the sentences, we replaced such values in the text and MR values with “NAME” and “NEAR” to standardize the data.
The original values are stored to keep the original information, although the standardized forms are still useful for training MR-to-text models.

Deduplication:

We conducted deduplication of the MR-text pairs and excluded about 1,500 pairs from the dataset.

5
Limitations

Although we modified the E2E dataset for the development of MR-to-text models, the following limitations remain:

•

As mentioned in Section
2.1
, we removed the data that had irregular MR values. However, multiple values may be allowed under different formulations of MR-to-text problems for more complex situations.

•

We currently ignored referring expressions, although generally they should be allowed.

•

We regard attributes other than
name
as modifiers of a
name
. However, an attribute sometimes modifies
near
. Our current formulation ignores such relationships.

6
Conclusion

We described our E2E refined dataset.
We reduced the deletion/insertion/substitution errors in the original E2E dataset and refined it by correcting errors and normalizing some expressions to simplify the sentences.
We also refined the annotation of the MR values and annotated the MR order, the number of sentences, and the sentence indexes as additional information.
The dataset and the data conversion programs in Python are publicly available at
https://github.com/KSKTYM/E2E-refined-dataset
.
We believe that this dataset will support future studies in related research fields.
