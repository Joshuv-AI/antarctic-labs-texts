Extracting Error Thresholds through the Framework of Approximate Quantum Error Correction Condition
Yuanchen Zhao, Dong E. Liu

Abstract
The robustness of quantum memory against physical noises is measured by two methods: the exact and approximate quantum error correction (QEC) conditions for error recoverability, and the decoder-dependent error threshold which assesses if the logical error rate diminishes with system size. Here we unravel their relations and propose a unified framework to extract an intrinsic error threshold from the approximate QEC condition, which could upper bound other decoder-dependent error thresholds. Our proof establishes that relative entropy, effectively measuring deviations from exact QEC conditions, serves as the order parameter delineating the transition from asymptotic recoverability to unrecoverability. Consequently, we establish a unified framework for determining the error threshold across both exact and approximate QEC codes, addressing errors originating from noise channels as well as those from code space imperfections. This result sharpens our comprehension of error thresholds across diverse QEC codes and error models.

II
AQEC relative entropy

We conjecture that exploring the asymptotic behaviors of AQEC conditions with increasing code size

To prove this statement, we examine a series of QEC codes,

The subtlety arises in quantifying the magnitude of

\bra{q_{1}}B_{uv}\ket{q_{2}}

\bra{q_{1}}B_{uv}\ket{q_{2}}

Considering a surface code

\mathcal{N}_{i}(\rho)=(1-p)\rho+pX\rho X

This phenomenon relates to the degeneracy of the code.
Therefore, we consider an entropic measure for a more precise threshold estimation. The parameters

(2)

Here,

Furthermore, we can always assume

absorbed into the definition of
\Lambda

S(\Lambda+B||\Lambda)=\tr\left\{(\Lambda+B)\left[\log(\Lambda+B)-\log\Lambda\right]\right\},

(3)

which can be shown to satisfy (see Appendix
A

0\leq S(\Lambda+B||\Lambda)\leq 2\log K.

(4)

It measures the magnitude of
B

\Lambda

Notice that in a finite system, the lower bound in Eq. (
4

B=0

S(\Lambda+B||\Lambda)=0

With the help of AQEC relative entropy, we define the
intrinsic error threshold
as follows.
If the AQEC relative entropy vanishes in the large size limit
\lim_{n\rightarrow\infty}S(\Lambda+B||\Lambda)=0
, we say that the QEC system is
below the intrinsic error threshold
. Otherwise, the QEC system is
above the intrinsic error threshold
. This intrinsic threshold demarcates different behaviors of AQEC relative entropy at large
n
, independent of decoder choice.

At the end of this section, we point out that there could be other quantities that measure the magnitude of
B

Ng and Mandayam 2010
;
Mandayam and Ng 2012
or other distance measures

We might alternatively extract the intrinsic error threshold from the asymptotic behavior of these measures since most AQEC measures can bound each other and become asymptotically equivalent in the large size limit.
The central idea is that the large
n
asymptotic behavior of AQEC measures determines the intrinsic error threshold.
We choose AQEC relative entropy since it is more tractable analytically, and the technical advantages are discussed in the following sections.

Refs.

The two phases of the QEC system have just been discussed. However, the critical examination of an intrinsic threshold, or a phase transition, remains. Subsequent sections address this through specific examples using our framework.
In general two mechanisms could result in the extra

For example, suppose that a many-body system is in a topologically ordered phase, but there is a perturbation in Hamiltonian such that it does not stay at the stable fix point, then the local error operator will lead to an exponentially small extra term

;

From now on we consider only

IV.2
threshold of maximum likelihood decoder

We assume that the data qudits suffer from stochastic weyl errors,

\mathcal{N}(\rho_{0})=\sum_{\eta\in\mathcal{V}}\Pr(\eta)T(\eta)\rho_{0}T(\eta)^{\dagger}.

(23)

;

can be decomposed as

Note that

Each sydrome

while each logical class contains

An error equivalent class is specified by syndrome

We denote the corresponding random variables as

(25)

Without losing generality, we redefine the representative configuration of syndrome

The success rate of MLD is commonly measured by the probability of

\Pr(l)=\sum_{s\in\mathcal{S}}\Pr(s,l),

(26)

\Pr(\text{MLD success})=\Pr(l=0).

\displaystyle H(L|S)

\displaystyle=-\sum_{s\in\mathcal{S}}\sum_{l\in\mathcal{L}}\Pr(s,l)\log\Pr(l|s)

A standard approach to the MLD threshold problem is mapping the error class probability to a statistical mechanical (SM) partition function

;
Gross 2006
, The stabilizer code words and Weyl noise operators both acquire phase space descriptions, thus the noise probability distributions on the classical phase space can be mapped to the Boltzmann weights of the classical SM model.

Following this spirit, we can write the probability of error equivalent classes

into classical partition functions,

\displaystyle Z(\eta)=\Pr([\eta])=\Pr(s,l)=

(30)

\displaystyle\sum_{m\in\mathcal{M}}\Pr(\eta+m)=\sum_{c\in\mathbb{Z}_{d}^{r}}\exp\left(-H_{\eta}(c)\right),

serves as the SM d.o.f. and

inherits a quenched disorder configuration from error probability

\displaystyle H_{\eta}(c)=-\sum_{i=1}^{n}\sum_{v_{i}\in\mathbb{Z}_{d}^{2}}J_{i}(v_{i})\omega^{[v_{i},\eta_{i}+M_{i}c]},

(31)

\displaystyle J_{i}(v_{i})=\frac{1}{d^{2}}\sum_{u_{i}\in\mathbb{Z}_{d}^{2}}\omega^{-[v_{i},u_{i}]}\log p_{i}(u_{i}),

Where

\displaystyle H_{\eta}(c)=-\sum_{R}\sum_{v_{R}\in\mathbb{Z}_{d}^{2}}J_{R}(v_{R})\omega^{[v_{R},\eta_{R}+M_{R}c]},

(33)

\displaystyle J_{R}(v_{R})=\frac{1}{d^{2|R|}}\sum_{u_{R}\in\mathbb{Z}_{d}^{2}}\omega^{-[v_{R},u_{R}]}\log p_{R}(u_{R}),

where

Suppose that the error rate of

IV.3
main results on stabilizer codes

A key result of ours for stabilizer codes is the following.

Lemma 2
.

For a qudit stabilizer code in prime
d
and a stochastic Weyl noise channel, the AQEC relative entropy, probability of logical classes and order parameter of the SM model are related by

\displaystyle S(\Lambda+B||\Lambda)

\displaystyle=H(L|S)

(35)

\displaystyle=\sum_{\eta\in\mathcal{V}}\Pr(\eta)\log\left\{\sum_{l\in\mathcal{L}}\exp\left[-\Delta(\eta,l)\right]\right\},

where

is the Shannon conditional entropy of logical class
l
given syndrome

, and the last quantity is a generalized version of the homological difference
Kovalev et al. 2018

Remark
.

We applied the replica method in the derivation of Eq. (

Boas 1973
;
Witten 2019
;
D’Hoker et al. 2021
. We calculate the AQEC relative entropy through the limit

S(\Lambda+B||\Lambda)=\lim_{R\rightarrow 1}\frac{1}{R-1}\log\frac{\tr((\Lambda+B)^{R})}{\tr(\Lambda^{R})}.

(36)

The r.h.s. is evaluated by fixing
R
as integers

\displaystyle\tr(\Lambda^{R})=\frac{1}{d^{k(R-1)}}\sum_{\eta\in\mathcal{V}}\Pr(\eta)Z(\eta)^{R-1},

(37)

\displaystyle\tr((\Lambda+B)^{R})=\frac{1}{d^{k(R-1)}}\sum_{\eta\in\mathcal{V}}\Pr(\eta)\left[\sum_{l\in\mathcal{L}}Z(\eta+l)\right]^{R-1},

and then taking the

limit after analytical continuation. A detailed proof is in Appendix
B
. Note that the generalized homological difference serves as a better-behaved order parameter compared to the simple disorder averaged
\overline{\Delta_{l}}

could possibly diverge even above the threshold when a single unlikely syndrome can be perfectly decoded and all others provide a logical error, and thus fail to determine the threshold position

or Shannon conditional entropy

since they are always nonzero above the threshold, even in the above extreme case.

Notice that the r.h.s. of Eq. (

Nishimori 2001
of the quenched disordered SM model
Z(\eta)
(inserted with domain wall configurations

in the second line).
In classical spin glass theories, in order to compute the disorder averaged free energy

in an accessible way, one often averages the

-th power of partition function first and then take the

(38)

The replica partition function is defined as
Z^{(R-1)}=\sum_{\eta}\Pr(\eta)Z(\eta)^{R-1}
.
It suggests that the SM mapping can be derived from the intrinsic properties of the code and noise, following the spirit of Fan et al.’s example
Fan et al. 2023
.
Note that we considered a different SM mapping to avoid the potentially complex Boltzmann weights in their original SM models when applied to
d\geq 3
qudit systems.
For stabilizer codes and Weyl noises, the SM mapping should always valid which is guaranteed by the Gottesman-Knill theorem
Nielsen and Chuang 2010
;
Gross 2006

Therefore,
\tr(\Lambda^{R})
(or

) is a more suitable choice for the partition function to circumvent complex weights. Additionally, it enables us to directly take the replica limit

on the SM model side, which was not achieved in Ref.

.

Eq.(
35

Theorem 2
.

For a family of qudit stabilizer codes in prime

and stochastic Weyl noise channels, in the large size limit

(1)

below the intrinsic error threshold, i.e.

\lim_{n\rightarrow\infty}\Pr(l=0)=1.

(39)

(2)

(3)

Proof of Theorem
2
.

Assume
\lim_{n\rightarrow\infty}S(\Lambda+B||\Lambda)=0

\displaystyle 1\geq\Pr(l=0)=\sum_{s\in\mathcal{S}}\Pr(s)\Pr(l=0|s)

(40)

\displaystyle\geq\exp\left[\sum_{s\in\mathcal{S}}\Pr(s)\log\Pr(l=0|s)\right]

\displaystyle=\exp\left[\sum_{s\in\mathcal{S}}\sum_{l\in\mathcal{L}}\Pr(s,l)\log\Pr(0|s)\right]

\displaystyle\geq\exp\left[\sum_{s\in\mathcal{S}}\sum_{l\in\mathcal{L}}\Pr(s,l)\log\Pr(l|s)\right]=\exp\left[-H(L|S)\right].

Note that we have used
\Pr(0|s)\geq\Pr(l|s)
,
\forall l\in\mathcal{L}
. So

.

The second and third propositions follow that conditioning reduces entropy,

0\leq H(L|S)\leq H(L),

(41)

where

Fixing the success probability

\displaystyle 0\leq H(L|S)\leq H(L)

(42)

\displaystyle\leq-\Pr(l=0)\log\Pr(l=0)

\displaystyle-(K^{2}-1)\frac{1-\Pr(l=0)}{K^{2}-1}\log\frac{1-\Pr(l=0)}{K^{2}-1}

\displaystyle=f(1-\Pr(l=0)).

The theorem demonstrates that applying our decoder-independent method to stabilizer codes with Weyl noise yields a threshold equivalent to that obtained from the maximum likelihood decoder used in other methods. Also, the intrinsic threshold of QEC systems, as indicated by the second equality of Eq.(

For example, let us assume geometric locality for both stabilizer generators and the error channel. In the ordered phase, nontrivial logical operators must span at least the code distance

In the disordered phase, some logical classes

from reaching zero. For example, if

, then

At a critical error threshold, the divergence of

VI
Discussion

Note that the last example confirmed that our framework could be applied on general AQEC codes, which possess nonzero
B_{uv,q_{1}q_{2}}
for local error operators
E_{u}^{\dagger}E_{v}
. Although the intrinsic threshold in this example vanishes due to the non-vanishing
B_{uv,q_{1}q_{2}}
in the
n\rightarrow\infty
limit, it may remain finite for certain AQEC codes with
B_{uv,q_{1}q_{2}}
suppressed by size (potentially e.g. topological ordered states
Bravyi et al. 2010
, approximate quantum LDPC code
Bohdanowicz et al. 2019
, ETH and Heisenberg chain codes
Brandão et al. 2019
).
Our framework holds potential for application to codes and noises that are beyond Gottesman-Knill theorem, including above AQEC codes and amplitude damping noises
Darmawan and Poulin 2017
.

For a QEC code
\mathcal{C}

Proof.

Since

(58)

\displaystyle\rho_{E}

\displaystyle=\tr_{AQ}\ket{\Psi_{AQE}^{\prime}}\bra{\Psi_{AQE}^{\prime}}

\displaystyle=\sum_{uv}\tr_{AQ}\left(E_{u}\ket{\Psi_{AQ}}\bra{\Psi_{AQ}}E_{v}^{\dagger}\right)\ket{u}_{E}\bra{v}_{E}

\displaystyle=\frac{1}{K}\sum_{uv}\tr_{Q}\left(E_{u}PE_{v}^{\dagger}\right)\ket{u}_{E}\bra{v}_{E}

\displaystyle=\frac{1}{K}\sum_{uv}\tr_{Q}\left(PE_{v}^{\dagger}E_{u}P\right)\ket{u}_{E}\bra{v}_{E}

\displaystyle=\frac{1}{K}\sum_{uv}\tr_{Q}\left(\lambda_{vu}P+PB_{vu}P\right)\ket{u}_{E}\bra{v}_{E}

\displaystyle=\sum_{uv}\lambda_{vu}\ket{u}_{E}\bra{v}_{E}.

\displaystyle\rho_{AE}

\displaystyle=\tr_{Q}\ket{\Psi_{AQE}^{\prime}}\bra{\Psi_{AQE}^{\prime}}

\displaystyle=\sum_{uv}\left[\tr_{Q}\left(E_{u}\ket{\Psi_{AQ}}\bra{\Psi_{AQ}}E_{v}^{\dagger}\right)\right]\ket{u}_{E}\bra{v}_{E}

\displaystyle=\frac{1}{K}\sum_{uv,q_{1}q_{2}}\left[\tr_{Q}\left(E_{u}\ket{q_{1}}_{\mathcal{C}}\bra{q_{2}}_{\mathcal{C}}E_{v}^{\dagger}\right)\right]

\displaystyle\times\ket{u}_{E}\bra{v}_{E}\otimes\ket{q_{1}}_{A}\bra{q_{2}}_{A}

\displaystyle=\frac{1}{K}\sum_{uv,q_{1}q_{2}}\bra{q_{2}}_{\mathcal{C}}E_{v}^{\dagger}E_{u}\ket{q_{1}}_{\mathcal{C}}\ket{u}_{E}\bra{v}_{E}\otimes\ket{q_{1}}_{A}\bra{q_{2}}_{A}

\displaystyle=\sum_{uv}(\Lambda_{vu,q_{2}q_{1}}+B_{vu,q_{2}q_{1}})\ket{u}_{E}\bra{v}_{E}\otimes\ket{q_{1}}_{A}\bra{q_{2}}_{A}.

(60)

\Lambda=(\rho_{E}\otimes\rho_{A})^{T},\quad\Lambda+B=\rho_{AE}^{T}.

\displaystyle=\tr(\Lambda+B)\log(\Lambda+B)-\tr\Lambda\log\Lambda
