For any

\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)\frac{{t}^{n}}{n!}=\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{{x{t}}+y(e^{t}-1)}\,\,\,\,\,\,\,(|{t}|<2\pi).

(3.1)

If x=0 and y=1 in (

\alpha

\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}\frac{{t}^{n}}{n!}=\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{(e^{t}-1)}\,\,\,\,\,\,\,(|{t}|<2\pi).

(3.2)

Theorem 3.1
.

The following relation hold true for
\alpha\in\mathbb{C}
and
n\in\mathbb{N}
;

{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)=\sum\limits_{k=0}^{n}\binom{n}{k}{{\mathcal{E}}_{k}^{(\alpha)}}(x){\mathcal{B}}_{n-k}(y).

(3.3)

Proof.

By using relation (
3.1
), we have

\displaystyle\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)\frac{{t}^{n}}{n!}=

\displaystyle\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{{x{t}}+y(e^{t}-1)}

\displaystyle=

\displaystyle\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{x{t}}\right\}\left\{e^{y(e^{t}-1)}\right\}

\displaystyle=

\displaystyle\left\{\sum_{k\geq 0}{\mathcal{E}_{k}^{(\alpha)}}(x)\frac{{t}^{k}}{k!}\right\}\left\{\sum_{n\geq 0}{\mathcal{B}_{n}}(y)\frac{{t}^{n}}{n!}\right\}.

Now, using series rearrangement method, we get

\displaystyle\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)\frac{{t}^{n}}{n!}=

\displaystyle\sum_{n\geq 0}\left\{\sum\limits_{k=0}^{n}\binom{n}{k}{{\mathcal{E}}_{k}^{(\alpha)}}(x){\mathcal{B}}_{n-k}(y)\right\}\frac{{t}^{n}}{n!}.

By equating same power of t both side, we get desired result (
3.3
).
∎

Theorem 3.2
.

Bell based Euler polynomials of order
\alpha
satisfy following relation for any
\alpha\in\mathbb{C}
and

{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)=\sum\limits_{k=0}^{n}\binom{n}{k}{{\mathcal{E}}_{k}^{(\alpha)}}{\mathcal{B}}_{n-k}(x;y).

(3.4)

Proof.

By using generating function (
3.1
), we have

\displaystyle\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)\frac{{t}^{n}}{n!}=

\displaystyle\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{{x{t}}+y(e^{t}-1)}

\displaystyle=

\displaystyle\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}\right\}\left\{e^{x{t}+y(e^{t}-1)}\right\}

\displaystyle=

\displaystyle\left\{\sum_{k\geq 0}{\mathcal{E}_{k}^{(\alpha)}}\frac{{t}^{k}}{k!}\right\}\left\{\sum_{n\geq 0}{\mathcal{B}_{n}}(x;y)\frac{{t}^{n}}{n!}\right\}

After applying series rearrangement technique and compare same power of t, we get desired result (

∎

Theorem 3.3
.

If
\alpha\in\mathbb{C}
and
n\in\mathbb{N}
, following relation hold true;

{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)=\sum\limits_{k=0}^{n}\binom{n}{k}{{\mathcal{E}}_{k}^{(\alpha)}}(y)\,\,x^{n-k}.

Using relation (
3.1

\displaystyle\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha)}}(x;y)\frac{{t}^{n}}{n!}=

\displaystyle\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha}e^{y(e^{{t}}-1)}\right\}\left\{e^{x{t}}\right\}

\displaystyle=

4.
Implicit summation formulae

In this section, we discus some useful implicit summation formulae for Bell Based Euler polynomials of order
\alpha
, which is defined in following theorem as follows:

Theorem 4.1
.

If
\alpha_{1},\alpha_{2}\in\mathbb{C}
and
n\in\mathbb{N}
, following relation hold true;

{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha_{1}+\alpha_{2})}}(x_{1}+x_{2};y_{1}+y_{2})=\sum\limits_{k=0}^{n}\binom{n}{k}{{}_{\mathcal{B}}{\mathcal{E}}_{k}^{(\alpha_{1})}}(x_{1};y_{1})\,\,{{}_{\mathcal{B}}}{\mathcal{E}}^{(\alpha_{2})}_{n-k}(x_{2};y_{2}).

(4.1)

Proof.

Using the following identity

\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{1}+\alpha_{2}}e^{{(x_{1}+x_{2})t}+(y_{1}+y_{2})(e^{t}-1)}

=\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{1}}e^{x_{1}{t}}+y_{1}(e^{t}-1)\right\}\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{2}}e^{x_{2}{t}}+y_{2}(e^{t}-1)\right\}.

By using generating function (
3.1
), we have

\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha_{1}+\alpha_{2})}}(x_{1}+x_{2};y_{1}+y_{y})\frac{{t}^{n}}{n!}

\displaystyle=

\displaystyle\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{1}+\alpha_{2}}e^{{(x_{1}+x_{2}){t}}+(y_{1}+y_{2})(e^{t}-1)}

\displaystyle=

\displaystyle\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{1}}e^{x_{1}{t}}+y_{1}(e^{t}-1)\right\}\left\{\left(\frac{2}{e^{{t}}+1}\right)^{\alpha_{2}}e^{x_{2}{t}}+y_{2}(e^{t}-1)\right\}

\displaystyle=

\displaystyle\left\{\sum_{k\geq 0}{{}_{\mathcal{B}}}{\mathcal{E}_{k}^{(\alpha_{1})}}(x_{1};y_{1})\frac{{t}^{k}}{k!}\right\}\left\{\sum_{n\geq 0}{{}_{\mathcal{B}}}{\mathcal{E}_{n}^{(\alpha_{2})}}(x_{2};y_{2})\frac{{t}^{n}}{n!}\right\}

\displaystyle=

\displaystyle\left\{\sum_{n\geq 0}\sum_{k\geq 0}{{}_{\mathcal{B}}}{\mathcal{E}_{k}^{(\alpha_{1})}}(x_{1};y_{1})\,\,{{}_{\mathcal{B}}}{\mathcal{E}_{n}^{(\alpha_{2})}}(x_{2};y_{2})\,\,\frac{{t}^{n+k}}{n!k!}\right\}

Using series rearrangement technique, we obtain

\sum_{n\geq 0}{{}_{\mathcal{B}}\mathcal{E}_{n}^{(\alpha_{1}+\alpha_{2})}}(x_{1}+x_{2};y_{1}+y_{y})\frac{{t}^{n}}{n!}=\sum_{n\geq 0}\left\{\sum_{k=0}^{n}\binom{n}{k}{{}_{\mathcal{B}}}{\mathcal{E}_{k}^{(\alpha_{1})}}(x_{1};y_{1})\,\,{{}_{\mathcal{B}}}{\mathcal{E}_{n-k}^{(\alpha_{2})}}(x_{2};y_{2})\,\,\right\}\frac{{t}^{n}}{n!}

Now, equating same power of
{t}
both side, we get desired result (
4.1
).
∎

and

, Bell bassed Euler polynomials of order

Let

with

\mathcal{G}=\left\{\mathfrak{g}|\mathfrak{g}(t)=\sum_{k\geq 0}\frac{c_{k}}{k!}{t}^{k}\,\,s.t.\,\,c_{k}\in\mathbb{C}\right\}.

(6.1)

Let
\mathcal{P}
be set of polynomials in the single vriable

and
\mathcal{P}^{*}
be set of vector space of all linear functional on
\mathcal{P}
. In the umbral calculus, we denote
\left<\mathcal{T}|~\mathfrak{q}(x)\right>
be linear functional
\mathcal{T}
on the polynomials
\mathfrak{q}(x)
. Now, we defined the vector space operations on
\mathcal{P}^{*}
as follows:

\left<\mathcal{T}_{1}+\mathcal{T}_{2}|\,\mathfrak{q}(x)\right>=\left<\mathcal{T}_{1}|\,\mathfrak{q}(x)\right>+\left<\mathcal{T}_{2}|\,\mathfrak{q}(x)\right>

and

\left<\beta\mathcal{T}|~\mathfrak{q}(x)\right>=\beta\left<\mathcal{T}|~\mathfrak{q}(x)\right>

for any constant
\beta
in
\mathbb{C}
.

The formal power series

\mathfrak{g}(t)=\sum_{k\geq 0}\frac{c_{k}}{k!}{t}^{k}\,\,\in\mathcal{G}

(6.2)

defined a linear functional on
\mathcal{P}
as

\left<\mathfrak{g}(t)|~x^{n}\right>=c_{n}

(6.3)

for all
n\in\mathbb{N}\cup\{0\}
.

If we choose
\mathfrak{g}(t)={t}^{k}
in (
6.2
) and (
6.3
), we get

\left<{t}^{k}|~x^{n}\right>=n!\delta_{n,k},

(6.4)

for all

and

\delta_{n,k}=\left\{\begin{array}[]{ll}0&if\,\,n\neq k\\
1,&if\,\,n=k\end{array}.\right.

Since any linear functional
\mathcal{T}
in
\mathcal{P}^{*}
has in the form of (
6.2
) i.e.,

\mathfrak{g}_{\mathcal{T}}({t})=\sum_{k\geq 0}\left<\mathcal{T}|~x^{k}\right>\frac{{t}^{k}}{k!}

and

\left<\mathfrak{g}_{\mathcal{T}}({t})|~x^{n}\right>=\left<\mathcal{T}|~x^{n}\right>.

So, the linear functional
\mathcal{T}=\mathfrak{g}_{\mathcal{T}}({t})
. We know that, the map
\mathcal{T}\rightarrow\mathfrak{g}_{\mathcal{T}}({t})
is a vector space isomorphism from set of vector space of all linear functional on
\mathcal{P}
onto set of formal series
\mathcal{G}
. Therefore, set of formal series
\mathcal{G}
have vector space of all linear functionals on
\mathcal{P}
, also
\mathcal{G}
have algebra of formal power series and so for

Theorem 6.2
