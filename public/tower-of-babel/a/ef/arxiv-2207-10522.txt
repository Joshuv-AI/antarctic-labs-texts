1.2.
Lenstra’s conjecture

Hendrik Lenstra partitioned the set of isomorphism classes of orders in degree
n
number fields in a different way into a finite set of subsets and conjectured which inequalities
\lambda_{i+j}\ll\lambda_{i}\lambda_{j}
hold for each subset. Although the conjecture turns out to be false, as we will show in this paper (
1.16
), it contains valuable insight.

Definition 1.7
.

A
tower type
is a
t
-tuple of integers
(n_{1},\dots,n_{t})\in\mathbb{Z}_{>1}^{t}
for some
t\geq 1
. We say
t
is the
length
of the tower type and
\prod_{i=1}^{t}n_{i}
is the
degree
of the tower type.

Throughout this article, the variable
\mathfrak{T}
will refer to a tower type of length
t
and degree
n
.

We now canonically associate a tower type to a tower of field extensions. Suppose we have a tower of fields

\mathbb{Q}=K_{0}\subset K_{1}\subset\dots\subset K_{t}=K

with no trivial extensions and
t\geq 1
. The
tower type of
K_{0}\subset K_{1}\subset\dots\subset K_{t}
is

\big([K_{1}\colon K_{0}],[K_{2}\colon K_{1}],\dots,[K_{t}\colon K_{t-1}]\big).

To an order
\mathcal{O}
in a number field
K
, we canonically associate a tower of subfields

\mathbb{Q}=K_{0}\subset K_{1}\subset\dots\subset K_{t}=K

with no trivial extensions and
t\geq 1
as follows; a field
L
belongs to the tower if and only if there exists a positive real number
r
such that
L
is obtained from
\mathbb{Q}
by adjoining all
x\in\mathcal{O}
for which
\lvert x\rvert\leq r
. We say the
tower type
of
\mathcal{O}
is the tower type of
K_{0}\subset K_{1}\subset\dots\subset K_{t}
.

Definition 1.8
.

Let
\mathcal{S}(\mathfrak{T})
be the set of isomorphism classes of orders
\mathcal{O}
with tower type
\mathfrak{T}
.

Write
\mathfrak{T}=(n_{1},\dots,n_{t})
. The set
\mathcal{S}(\mathfrak{T})
is infinite (see
Example

1.11
for a construction of infinitely many elements of
\mathcal{S}(\mathfrak{T})
).

Mixed radix notation will be useful to concisely state arithmetic conditions throughout this paper.

Definition 1.9
.

Choose a tower type
\mathfrak{T}=(n_{1},\dots,n_{t})
and
i\in[n]
. Writing
i
in
mixed radix notation with respect to
\mathfrak{T}
means writing

i=i_{1}+i_{2}n_{1}+i_{3}(n_{1}n_{2})+\dots+i_{t}(n_{1}\dots n_{t-1})

where

is an integer such that
0\leq i_{s}<n_{s}
for
1\leq s\leq t
. Note that the integers
i_{s}
are uniquely determined.

Definition 1.10
.

Fix a tower type
\mathfrak{T}=(n_{1},\dots,n_{t})
and integers

. We say the addition
i+j

does not overflow modulo

if we write

,

Note that condition

Hendrik Lenstra suggested the following infinite set of isomorphism classes of orders as a model for the extremal case when determining when inequalities
\lambda_{i+j}\ll\lambda_{i}\lambda_{j}
should hold.

Example 1.11

For a tower type
\mathfrak{T}=(n_{1},\dots,n_{t})
of degree

p
.

We present a counterexample to

when

and
\mathfrak{T}=(8)
.

Counterexample 1.16
.

The addition
3+3
does not overflow modulo
\mathfrak{T}=(8)
. We will produce an infinite set of isomorphism classes of orders in degree
8
fields with tower type
\mathfrak{T}=(8)
such that
\lambda_{3}=o(\lambda_{6})
. Let
\alpha\in\overline{\mathbb{Q}}
be quadratic and let
\beta\in\overline{\mathbb{Q}}
be such that
[\mathbb{Q}(\beta)\colon\mathbb{Q}]=8
and
[\mathbb{Q}(\alpha,\beta)\colon\mathbb{Q}(\alpha)]=4

, there exists an infinite set of positive integers

such that for all

Because

1.3.
Restating Lenstra’s conjecture using logarithms and polytopes

1.16
demonstrates that Lenstra’s conjecture is false. We instead ask if some variant of
1.12
is true; in order to state this variant, we first rephrase

be the absolute value of the discriminant of the order
\mathcal{O}

Definition 1.17
.

Let
\mathcal{S}
be an infinite set of isomorphism classes of orders in degree

of

and denote it by

Definition 1.18
.

Let
\mathcal{S}
be an infinite set of isomorphism classes of orders in degree
n
number fields. The
successive minima spectrum
of
\mathcal{F}
is

For the infinite set
\mathcal{S}(\mathfrak{T})
, the set

captures which inequalities
\lambda_{k}\ll\lambda_{i}\lambda_{j}
hold. We prove the following two theorems in

.

Theorem 1.19
.

For any tower type
\mathfrak{T}
, any integers

, and any set
\mathcal{C}
of isomorphism classes of degree

number fields, we have

\Spe\Big(\bigcup_{K\in\mathcal{C}}\mathcal{S}(\mathfrak{T},K)\Big)\subseteq\{\mathbf{x}\in\mathbb{R}^{n-1}\;\;|\;\;x_{k}\leq x_{i}+x_{j}\}

if and only if there exists a constant

dependent only on
\mathfrak{T}
and

such that
\lambda_{k}(\mathcal{O})\leq c_{\mathfrak{T},\mathcal{C}}\lambda_{i}(\mathcal{O})\lambda_{j}(\mathcal{O})
for all
\mathcal{O}\in\cup_{K\in\mathcal{C}}\mathcal{S}(\mathfrak{T},K))

For example, one could let
\mathcal{C}
be the set of isomorphism classes of degree
n
number fields with Galois group

.

Definition 1.20
.

For a number field
K
, let
\mathcal{S}(K)
be the set of isomorphism classes of orders in
K
.

Theorem 1.21
.

For any number field
K
and any integers

, the following are equivalent:

(1)

we have
\Spe(\mathcal{S}(K))\subseteq\{\mathbf{x}\in\mathbb{R}^{n-1}\;\;|\;\;x_{k}\leq x_{i}+x_{j}\}

(2)

there exists a constant

\mathcal{O}\in\mathcal{S}(K)

(4)

and

has no subfield of degree

Therefore, our primary goal is to determine the sets
\Spe(\mathcal{S}(\mathfrak{T}))
and
\Spe(\mathcal{S}(K))

Conjecture 1.22

For any integers

1.19
shows that

such that

does not overflow modulo

encoding all linear half spaces

such that

does not overflow modulo
\mathfrak{T}

Definition 1.23
.

The

of a tower type

is the set of
\mathbf{x}=(x_{1},\dots,x_{n-1})\in\mathbb{R}^{n-1}
satisfying the following conditions:

(1)

(2)

(3)

for any infinite set
\mathcal{S}
of isomorphism classes of orders in degree

arises from the fact that

arises from the fact that Lenstra’s conjecture hypothesizes

for

.

Theorem

1.19
shows that

Theorem 1.24
.

For a tower type
\mathfrak{T}
and a number field

such that

is nonempty, we have
\Len(\mathfrak{T})\subseteq\Spe(\mathcal{S}(\mathfrak{T},K))
.

We may thus rephrase

as follows.

Conjecture 1.25

For a tower type
\mathfrak{T}
, we have
\Spe(\mathcal{S}(\mathfrak{T}))=\Len(\mathfrak{T})
.

We have discussed how

and

are equivalent, and both false.
Theorem

shows that

is also equivalent to

and
1.22
. The statement of

will inspire a modified conjecture.

1.5.
Expressing

as a union of polytopes

We will prove that the set

is a finite union of polytopes. These polytopes are governed by the multiplicative structure of number fields; to keep track of the key datum, we make the following definition.

Definition 1.29
.

A
flag type
is a function
T\colon[n]\times[n]\rightarrow[n]
such that for any
i,j\in[n]
, we have:

(1)

T(i,j)=T(j,i)
;

(2)

T(i,0)=i
;

(3)

and
T(i,j)\leq T(i+1,j)
for
i<n-1
.

Let
L/K
be a degree
n
field extension.

Definition 1.30
.

A
flag of
L/K
is an indexed set
\mathcal{F}=\{F_{i}\}_{i\in[n]}
of
K
-vector spaces contained in
L
such that

K=F_{0}\subset F_{1}\subset\dots\subset F_{n-1}=L

and
\dim_{K}F_{i}=i+1
for all
i\in[n]
.
A
flag over
K
is a flag of some degree
n
field extension of
K
. When
K
is implicit, we say
\mathcal{F}
is a
flag of
L
.

Let
\mathcal{F}=\{F_{i}\}_{i\in[n]}
be a flag. Associate to
\mathcal{F}
the flag type

\displaystyle T_{\mathcal{F}}\colon[n]\times[n]

\displaystyle\longrightarrow[n]

\displaystyle(i\;\;,\;\;j)\;

\displaystyle\longmapsto\min\{k\in[n]\mid F_{i}F_{j}\subseteq F_{k}\}.

Say
T_{\mathcal{F}}
is the
flag type
of
\mathcal{F}
. Analogously to the Lenstra polytope
\Len(\mathfrak{T})
, we define a polytope encoding the data of a flag type.

Definition 1.31
.

The polytope
P_{T}
of a flag type
T
is the set of
\mathbf{x}=(x_{1},\dots,x_{n-1})\in\mathbb{R}^{n-1}
satisfying the following conditions:

(1)

\sum_{i=1}^{n-1}x_{i}=1/2
;

(2)

0\leq x_{1}\leq\dots\leq x_{n-1}
;

(3)

and
x_{T(i,j)}\leq x_{i}+x_{j}
for
1\leq i,j<n
.

The polytopes
P_{T}
are a generalization of the Lenstra polytopes. For example, fix a tower type
\mathfrak{T}=(n_{1},\dots,n_{t})
and choose elements
\alpha_{1},\dots,\alpha_{t}\in\overline{\mathbb{Q}}
such that
[\mathbb{Q}(\alpha_{1},\dots,\alpha_{t})\colon\mathbb{Q}]=n
and
\deg(\alpha_{i})=n_{i}
for all
1\leq i\leq t
. Define a basis
\mathcal{B}=\{1=v_{0},\dots,v_{n-1}\}
of
\mathbb{Q}(\alpha_{1},\dots,\alpha_{t})
as follows: for
0\leq i<n
, write

i=i_{1}+i_{2}(n_{1})+i_{3}(n_{1}n_{2})+\dots+i_{t}(n_{1}\dots n_{t-1})

where
0\leq i_{s}<n_{s}
for
1\leq s\leq t
, and then set
v_{i}=\alpha_{1}^{i_{1}}\dots\alpha_{t}^{i_{t}}
. Then
P_{T}=\Len(\mathfrak{T})
. See
Example

1.11
for more details.

To a flag
\mathcal{F}=\{F_{i}\}_{i\in[n]}
of a number field
K
, we canonically associate a tower of subfields

\mathbb{Q}=K_{0}\subset K_{1}\subset\dots\subset K_{t}=K

with no trivial extensions as follows and

; a field

belongs to the tower if and only if

for

. We say the

of

is the tower type of
\mathbb{Q}=K_{0}\subset K_{1}\subset\dots\subset K_{t}=K
. We prove the following in
Section

.

Theorem 1.32
.

For a tower type
\mathfrak{T}
and a set of isomorphism classes of degree

\Spe\bigg(\bigcup_{K\in\mathcal{C}}\mathcal{S}(\mathfrak{T},K)\bigg)=\bigcup_{\mathcal{F}}P_{T_{\mathcal{F}}}

where
\mathcal{F}
ranges across all flags with tower type
\mathfrak{T}
of number fields in
\mathcal{C}
.

Corollary 1.33
.

We have:

(1)

\Spe(\mathcal{S}_{n})=\cup_{\mathcal{F}}P_{T_{\mathcal{F}}}

where
\mathcal{F}
ranges across all flags of degree
n
number fields;

(2)

\Spe(\mathcal{S}(K))=\cup_{\mathcal{F}}P_{T_{\mathcal{F}}}
where
\mathcal{F}
ranges across all flags of

(3)

\Spe(\mathcal{S}(\mathfrak{T}))=\cup_{\mathcal{F}}P_{T_{\mathcal{F}}}
where
\mathcal{F}
ranges across all flags of tower type
\mathfrak{T}
;

(4)

and for any set of isomorphism classes of degree
n
number fields

1.7.
The function field case

Let
C
be a geometrically integral smooth projective curve of genus
g
over a field
k
equipped with a finite morphism
\pi\colon C\rightarrow\mathbb{P}^{1}
of degree
n\geq 2
. Let
\mathcal{L}
be a line bundle on
C
.

Definition 1.40
.

For
i\in[n]
, the
i
-th logarithmic successive minimum of
\mathcal{L}
with respect to
\pi
is

a_{i}(\mathcal{L},\pi)\coloneqq\min_{j\in\mathbb{Z}_{\geq 0}}\Big\{h^{0}\big(C,\mathcal{L}\otimes\pi^{*}\mathcal{O}_{\mathbb{P}^{1}}(j+1)\big)-h^{0}\big(C,\mathcal{L}\otimes\pi^{*}\mathcal{O}_{\mathbb{P}^{1}}(j)\big)\geq i+1\Big\}.

When
\pi
is implicit, we will refer to the
i
-th logarithmic successive minimum by
a_{i}(\mathcal{L})
.

By abuse of notation, let
a_{0}\leq a_{1}\leq a_{2}\leq\dots\leq a_{n-1}
be the unique integers such that

\pi_{*}\mathcal{L}\simeq\mathcal{O}_{\mathbb{P}^{1}}(-a_{0})\oplus\mathcal{O}_{\mathbb{P}^{1}}(-a_{1})\oplus\dots\oplus\mathcal{O}_{\mathbb{P}^{1}}(-a_{n-1}).

For any integer
j
, we have

\displaystyle h^{0}(X,\mathcal{L}\otimes\pi^{*}\mathcal{O}_{\mathbb{P}^{1}}(j))

\displaystyle=h^{0}(\mathbb{P}^{1},\pi_{*}\mathcal{L}\otimes\mathcal{O}_{\mathbb{P}^{1}}(j))

\displaystyle=\sum_{i\in[n]}h^{0}(\mathbb{P}^{1},\mathcal{O}_{\mathbb{P}^{1}}(j-a_{i}))

\displaystyle=\sum_{i\in[n]}\max\{0,j+1-a_{i}\},

so
a_{i}=a_{i}(\mathcal{L},\pi)
. Therefore, one may equivalently define the logarithmic successive minima of
\mathcal{L}
with respect to
\pi
as the unique integers
a_{0}\leq a_{1}\leq a_{2}\leq\dots\leq a_{n-1}
such that

\pi_{*}\mathcal{L}\simeq\mathcal{O}_{\mathbb{P}^{1}}(-a_{0})\oplus\mathcal{O}_{\mathbb{P}^{1}}(-a_{1})\oplus\dots\oplus\mathcal{O}_{\mathbb{P}^{1}}(-a_{n-1}).

The logarithmic successive minima
a_{0}(\mathcal{O}_{C}),\dots,a_{n-1}(\mathcal{O}_{C})
of the structure sheaf are are analogous to
\log\lambda_{i}
for an order
\mathcal{O}
in a degree
n
number field, and the genus
g
is analogous to
\log\Delta^{1/2}
; see
[
5
]
for a detailed discussion. This analogy is the reason behing the name logarithmic successive minima.

An application of Riemann–Roch, written explicitly in
Lemma

7.2
, shows that:

(1)

a_{1}(\mathcal{L})+\dots+a_{n-1}(\mathcal{L})=g+n-1-\deg(\mathcal{L})
for any line bundle
\mathcal{L}
;

(2)

and
a_{0}(\mathcal{O}_{C})=0
and
a_{i}(\mathcal{O}_{C})>0
for any
1\leq i<n
.

For an order
\mathcal{O}
in a degree
n
number field with fractional ideal
I
, statement
(1)
is analogous to the fact that
\prod_{i=1}^{n}\lambda_{i}(I)\asymp_{n}\Delta^{1/2}N(I)
, and statement
(2)
is analogous the fact that
\log_{\Delta}\lambda_{0}(\mathcal{O})=0
.
Theorem

1.2
implies that
\lambda_{n-1}\ll\Delta^{1/n}
; the function field analogue is called the
Maroni bound
and it states that
a_{n-1}\leq(2g-2)/n+2
.

In the literature, the numbers
a_{i}(\mathcal{O}_{C})-2
are often denoted by
e_{n-i}
and are called the
scrollar invariants
of
\pi
. The bundle
\big(\pi_{*}O_{C}/\mathcal{O}_{\mathbb{P}^{1}}\big)^{\vee}
is called the
Tschirnhausen bundle
; the question of which
(n-1)
-tuples
(e_{1},\dots,e_{n-1})
(equivalently, which Tschirnhausen bundles) can arise as the scrollar invariants of a curve is an old and important problem. In this paper, we will prove strong constraints on the scrollar invariants.

There are a number of classical results regarding the logarithmic successive minima of the structure sheaf, which we will generalize.

Theorem 1.41

(Ohbuchi
[
7
]
, Theorem 3)
.

If
\pi^{*}(\mathcal{O}_{\mathbb{P}^{1}}(a_{1}(\mathcal{O}_{C})))
is birationally very ample, then

a_{i+j}(\mathcal{O}_{C})\leq a_{i}(\mathcal{O}_{C})+a_{j}(\mathcal{O}_{C})

for any integers
1\leq i<n
and
1\leq j\leq n-3i
.

Theorem 1.42

(Deopurkar, Patel
[
4
]
, Proposition 2.6)
.

If
\pi\colon C\rightarrow\mathbb{P}^{1}
does not factor nontrivially, then

\frac{g+n-1}{\binom{n}{2}}\leq a_{1}(\mathcal{O}_{C})\leq\frac{g+n+1}{n-1}.

The above theorem is analogous to the statement that
\Delta_{\mathcal{O}}^{1/(2\binom{n}{2})}\ll_{n}\lambda_{1}(\mathcal{O})\ll_{n}\Delta_{\mathcal{O}}^{1/2(n-1)}
in the case when

is a primitive field; this is a corollary of

1.4
(see

7.6
).

Let
C

\pi
, and
\mathcal{L}
be as above. The action map
\psi\colon\mathcal{O}_{C}\otimes\mathcal{L}\rightarrow\mathcal{L}
induces an action map

\widehat{\psi}\colon\pi_{*}\mathcal{O}_{C}\otimes\pi_{*}\mathcal{L}\rightarrow\pi_{*}\mathcal{L}

via the pushforward. Let

denote the generic point of

be the function field of

, let

denote the generic point of
\mathbb{P}^{1}
, and let

be the function field of

. The map

\phi_{1}\colon(\mathcal{O}_{C})_{\mid\eta}\simeq(\pi_{*}\mathcal{O}_{C})_{\mid\nu}

\phi_{2}\colon\mathcal{L}_{\mid\eta}\simeq(\pi_{*}\mathcal{L})_{\mid\nu}

of

i=i_{1}+i_{2}(n_{1})+i_{3}(n_{1}n_{2})+\dots+i_{t}(n_{1}\dots n_{t-1})

in mixed radix notation with respect to
\mathfrak{T}
, and then set
v_{i}\coloneqq\alpha_{1}^{i_{1}}\dots\alpha_{t}^{i_{t}}
. Let
\mathcal{F}
be the flag corresponding to the basis
\mathcal{B}
. Define
\mathbf{x}=(x_{1},\dots,x_{n-1})
as follows: let
x_{i}=\frac{i}{2(n-1)}
; then
\mathbf{x}\in P_{T_{\mathcal{F}}}=\Len(\mathfrak{T})
. Apply
Proposition

3.2
to obtain an infinite set
\mathcal{M}\subseteq\mathbb{Z}_{\geq 1}
such that

\{\mathcal{O}_{M}=\mathbb{Z}\langle 1,M^{x_{1}}v_{1},\dots,M^{x_{n-1}}v_{n-1}\rangle\}_{M\in\mathcal{M}}

is a set of orders with tower type
\mathfrak{T}
. Let
M_{i}
be the
i
–th largest element of
\mathcal{M}
. Letting
\alpha_{i,\ell}=M_{i}^{x_{i}}\alpha_{i}
completes the proof.
∎

Lemma 7.4
.

Suppose we have
x,y\in K
for some number field
K
of degree
n
. Then
\lv xy\rv\leq\sqrt{n}\lv x\rv\lv y\rv
.

Proof.

We have

\displaystyle\lv xy\rv^{2}

\displaystyle=\frac{1}{n}\sum_{i=1}^{n}\lv\sigma_{i}(xy)\rv^{2}

\displaystyle=\frac{1}{n}\sum_{i=1}^{n}\lv\sigma_{i}(x)\rv^{2}\lv\sigma_{i}(y)\rv^{2}

\displaystyle\leq\frac{1}{n}\Big(\sum_{i=1}^{n}\lv\sigma_{i}(x)\rv^{2}\Big)\Big(\sum_{i=1}^{n}\lv\sigma_{i}(y)\rv^{2}\Big)

\displaystyle=n\Big(\frac{1}{n}\sum_{i=1}^{n}\lv\sigma_{i}(x)\rv^{2}\Big)\Big(\frac{1}{n}\sum_{i=1}^{n}\lv\sigma_{i}(y)\rv^{2}\Big)

\displaystyle=n\lv x\rv^{2}\lv y\rv^{2}.

∎

Lemma 7.5
.

For a tower type
\mathfrak{T}
, the set
\mathcal{S}(\mathfrak{T},K)
is either empty or infinite.

Proof.

Suppose there exists an element
\mathcal{O}\in\mathcal{S}(\mathfrak{T},K)
. Then, there exists a basis
\mathcal{B}=\{1=v_{0},\dots,v_{n-1}\}
of
K
with tower type
\mathfrak{T}
, and let
\mathcal{F}
be the corresponding flag. Choose a relative interior point
\mathbf{x}\in P_{T_{\mathcal{F}}}
.
Proposition

3.2
constructs an infinite family
\mathcal{S}(\mathcal{B},\mathcal{M},\mathbf{x})
of orders in
K
such that all but finitely many have tower type
\mathfrak{T}
.
∎

Lemma 7.6
.

For an order
\mathcal{O}
in a primitive degree
n
number field, we have

\Delta_{\mathcal{O}}^{1/(2\binom{n}{2})}\ll_{n}\lambda_{1}(\mathcal{O})\ll_{n}\Delta_{\mathcal{O}}^{1/2(n-1)}.

Proof.

We have

\lambda_{1}(\mathcal{O})^{n-1}\leq\prod_{i=1}^{n-1}\lambda_{i}(\mathcal{O})\asymp_{n}\Delta_{\mathcal{O}}^{1/2},

so
\lambda_{1}(\mathcal{O})\ll_{n}\Delta_{\mathcal{O}}^{1/2(n-1)}
.

On the other hand, by
Theorem

1.4
, we have
\lambda_{i+j}(\mathcal{O})\leq\sqrt{n}\lambda_{i}(\mathcal{O})\lambda_{j}(\mathcal{O})
for all
0\leq i,j,i+j<n
. So,
\lambda_{i}\leq n^{(i-1)/2}\lambda_{1}^{i}
. So,

\Delta_{\mathcal{O}}^{1/2}\asymp_{n}\prod_{i=1}^{n-1}\lambda_{i}(\mathcal{O})\ll_{n}\prod_{i=1}^{n-1}\lambda_{1}(\mathcal{O})^{i}\ll_{n}\lambda_{1}(\mathcal{O})^{\binom{n}{2}}

so
\Delta_{\mathcal{O}}^{1/(2\binom{n}{2})}\ll_{n}\lambda_{1}(\mathcal{O})
.
∎
