EM-Type Algorithms for DOA Estimation in Unknown Nonuniform Noise
Ming-yan Gong and Bin Lyu

Abstract




Abstract:
The expectation–maximization (EM) algorithm updates all of the parameter estimates simultaneously, which is not applicable to direction of arrival (DOA) estimation in unknown nonuniform noise. In this work, we present several efficient EM-type algorithms, which update the parameter estimates sequentially, for solving both the deterministic and stochastic maximum–likelihood (ML) direction finding problems in unknown nonuniform noise. Specifically, we design a generalized EM (GEM) algorithm and a space-alternating generalized EM (SAGE) algorithm for computing the deterministic ML estimator. Simulation results show that the SAGE algorithm outperforms the GEM algorithm. Moreover, we design two SAGE algorithms for computing the stochastic ML estimator, in which the first updates the DOA estimates simultaneously while the second updates the DOA estimates sequentially. Simulation results show that the second SAGE algorithm outperforms the first one.

Keywords:
DOA estimation; EM algorithm; Maximum likelihood estimation; Nonuniform noise

However, these EM and SAGE algorithms are usually derived under the known or unknown uniform noise model, i.e., the sensor noise variances must be equal, which may be impractical in certain applications. Hence, the two algorithms should be developed for DOA estimation in the presence of other noise models.

As a general case of the uniform noise model, nonuniform noise has attracted increasing attention. Nonuniform noise is with an arbitrary diagonal covariance matrix, i.e., the sensor noise variances can be unequal. Obviously, classical eigenstructure based subspace methods, e.g., the MUSIC algorithm, cannot be

[
13

while in

14

15

[
16

[
17

[

The ML method can enjoy excellent statistical properties
[
4
]
,
[
5
]
. But, the analyses in
[
19
]
and
[
20
]
suggest that both the deterministic and stochastic ML direction finding problems in unknown nonuniform noise cannot be reduced to two problems with respect to only the DOAs because of the noise parameters and generally involve high-dimensional search algorithms. For efficiently computing both the deterministic and stochastic ML estimators, two alternating maximization (AM) algorithms are presented in
[
19
]
and
[
20
]
, respectively. Unfortunately, the two AM algorithms include high-dimensional numerical search at every iteration and are thus computationally intensive, which motivates this work.

In this work, we first try to apply the EM algorithm, each iteration of which consists of an expectation step (E-step) and a maximization step (M-step). At the M-step, however, the EM algorithm updates all of the parameter estimates simultaneously, which requires high-dimensional numerical search due to the unknown noise parameters. Hence, we present several efficient EM-type algorithms, which update the parameter estimates sequentially and only require low-dimensional numerical search at every iteration, for solving both the deterministic and stochastic ML direction finding problems in unknown nonuniform noise. Specifically, we design a generalized EM (GEM) algorithm based on the expectation-conditional maximization (ECM) algorithm
[
21

and an SAGE algorithm, which updates the DOA estimates sequentially, for computing the deterministic ML estimator. Simulation results show that the SAGE algorithm outperforms the GEM algorithm, i.e., the SAGE algorithm converges faster and can avoid the convergence to an unwanted stationary point of the LLF more efficiently. Moreover, we design two SAGE algorithms for computing the stochastic ML estimator, in which the first updates the DOA estimates simultaneously while the second updates the DOA estimates sequentially. Simulation results show that the second SAGE algorithm outperforms the first one.

\displaystyle\mathbf{d}\big(\theta^{(b,i-1)}_{i}\big)f^{(b,i-1)}_{i}(t)+\big[\mathbf{v}(t)-\mathbf{D}\big(\bm{\theta}^{(b,i-1)}\big)\mathbf{f}^{(b,i-1)}(t)\big],\forall t,

(18a)

\displaystyle\mathbb{D}\left\{\mathbf{g}_{i}(t)\big|\mathbf{V};\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b,i-1)}\right\}=\mathbf{0}_{N},\forall t.

(18b)

3.2.2
CM-steps

The SAGE algorithm tries to estimate
\theta_{i}
,
\textbf{f}_{i}
, and
\bm{\sigma}
by maximizing (
3.2.1
), i.e.,

\displaystyle\min_{\theta_{i}\in(0,\pi),\mathbf{f}_{i},\bm{\sigma}>\mathbf{0}}\sum_{n=1}^{N}\ln(\sigma_{n})+\frac{1}{T}\sum_{t=1}^{T}\big[\mathbf{g}^{(b)}_{i}(t)-\mathbf{d}(\theta_{i})f_{i}(t)\big]^{H}\bm{\Sigma}^{-1}\big[\mathbf{g}^{(b)}_{i}(t)-\mathbf{d}(\theta_{i})f_{i}(t)\big].

(19)

However, problem (
19
) is hard to be reduced to a one-dimensional search problem with respect to only
\theta_{i}
, we use two CM-steps based on the ECM algorithm
[
21
]
.

At the first CM-step, the SAGE algorithm estimates
\theta_{i}
and
\mathbf{f}_{i}
but holds
\bm{\sigma}=\bm{\sigma}^{(b,i-1)}
fixed. Then, problem (
19
) is reduced to

\displaystyle\min_{\theta_{i}\in(0,\pi),\mathbf{f}_{i}}\frac{1}{T}\sum_{t=1}^{T}\big\|\tilde{\mathbf{g}}^{(b)}_{i}(t)-\tilde{\mathbf{d}}(\theta_{i})f_{i}(t)\big\|^{2},

(20)

where
\tilde{\mathbf{g}}^{(b)}_{i}(t)=\big[\bm{\Sigma}^{(b,i-1)}\big]^{-1/2}\mathbf{g}^{(b)}_{i}(t)
and

\tilde{\mathbf{d}}(\theta_{i})=\big[\bm{\Sigma}^{(b,i-1)}\big]^{-1/2}\mathbf{d}(\theta_{i})
.
Following (
11a
) and (
11b
), the estimates of
\theta_{i}
and
\mathbf{f}_{i}
are updated by

\displaystyle\theta^{(b)}_{i}=\theta^{(b,i)}_{i}=\arg\max_{\theta_{i}\in(0,\pi)}\tilde{\mathbf{d}}^{H}(\theta_{i})\widetilde{\mathbf{R}}^{(b)}_{i}\tilde{\mathbf{d}}(\theta_{i}),

(21a)

\displaystyle f^{(b)}_{i}(t)=f^{(b,i)}_{i}(t)=\tilde{\mathbf{d}}^{H}\big(\theta^{(b)}_{i}\big)\tilde{\mathbf{g}}^{(b)}_{i}(t)/q^{(b,i)},\forall t,

(21b)

where
\widetilde{\mathbf{R}}^{(b)}_{i}=(1/T)\sum_{t=1}^{T}\tilde{\mathbf{g}}^{(b)}_{i}(t)\big[\tilde{\mathbf{g}}^{(b)}_{i}(t)\big]^{H}
and

q^{(b,i)}=\tilde{\mathbf{d}}^{H}\big(\theta^{(b)}_{i}\big)\tilde{\mathbf{d}}\big(\theta^{(b)}_{i}\big)=\sum_{n=1}^{N}\big[\sigma^{(b,i-1)}_{n}\big]^{-1}
.

At the second CM-step, the SAGE algorithm estimates
\bm{\sigma}
but holds
\theta_{i}=\theta^{(b)}_{i}
and
\mathbf{f}_{i}=\mathbf{f}^{(b)}_{i}
fixed. Then, problem (
19
) is reduced to

\displaystyle\min_{\bm{\sigma}>\mathbf{0}}\sum_{n=1}^{N}\big[\ln(\sigma_{n})+\frac{d^{(b,i)}_{n}}{\sigma_{n}}\big],

(22)

where

d^{(b,i)}_{n}=(1/T)\sum_{t=1}^{T}\big|\big[\mathbf{g}^{(b)}_{i}(t)-\mathbf{d}\big(\theta^{(b)}_{i}\big)f^{(b)}_{i}(t)\big]_{n}\big|^{2}\geq 0,\forall n.

Thus, the estimate of
\bm{\sigma}
is updated by

\displaystyle\sigma^{(b,i)}_{n}=d^{(b,i)}_{n},\forall n.

(23)

Unfortunately, the operation of the algorithm always is unstable in simulation when the estimate of
\bm{\sigma}
is updated by (
23
). Like (
14
), we modify (
23
) as

\displaystyle\sigma^{(b,i)}_{n}=\gamma\sigma^{(b,i-1)}_{n}+(1-\gamma)d^{(b,i)}_{n},\forall n,

(24)

where
\gamma\in(0,1]
is adjusted in simulation and tends to be larger than
\beta
. Note that in (
24
),
\sigma^{(b,i)}_{n}\geq\gamma\sigma^{(b,i-1)}_{n}>0
if
\sigma^{(b,i-1)}_{n}>0
, which ensures that if
\bm{\sigma}^{(b,i-1)}>\mathbf{0}
, we have

\bm{\sigma}^{(b,i)}>\mathbf{0}.

The other parameter estimates in
(\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b,i-1)})
are not updated at this cycle and their iterative values are denoted by

\displaystyle\theta^{(b,i)}_{m}=\theta^{(b,i-1)}_{m},\forall m\neq i,

(25a)

\displaystyle f^{(b,i)}_{m}(t)=f^{(b,i-1)}_{m}(t),\forall m\neq i,t.

(25b)

After this cycle, we have
[
9
]

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b,i)},\bm{\sigma}^{(b,i)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b,i-1)}\big).

(26)

Thus, after the
b
th iteration, the monotonicity of the SAGE algorithm can be proved by

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b)}\big)=\mathcal{L}\big(\bm{\Phi}^{(b,M)},\bm{\sigma}^{(b,M)}\big)\geq\cdots\geq\mathcal{L}\big(\bm{\Phi}^{(b,0)},\bm{\sigma}^{(b,0)}\big)=\mathcal{L}\big(\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big).

(27)

4
Stochastic Signal Model

In this section, we present two SAGE algorithms for solving problem (
6
).

4.1
First SAGE Algorithm

The first SAGE algorithm simultaneously updates the DOA estimates based on the EM algorithm. To this end, we first try to use the EM algorithm and the E- and M-steps at the
b
th iteration are introduced below.

4.1.1
E-step

The EM algorithm calculates the conditional expectation of the complete-data LLF in (
5b
)
[
7
]
, i.e.,

\displaystyle\mathbb{E}\left\{\mathcal{U}(\bm{\Phi},\bm{\sigma})\big|\mathbf{V};\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\right\}=-TMN\ln(\pi)-T\sum_{m=1}^{M}\big[\ln\big(\mathrm{Det}(\mathbf{H}_{m})\big)+\mathrm{Tr}\big(\mathbf{H}^{-1}_{m}\hat{\mathbf{R}}^{(b)}_{m}\big)\big]

(28)

with
\bm{\Phi}=(\bm{\theta},\mathbf{P})
and

\displaystyle\hat{\mathbf{R}}^{(b)}_{m}=

\displaystyle\mathbb{E}\big\{\hat{\mathbf{R}}_{m}\big|\mathbf{V};\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big\}

\displaystyle=

\displaystyle\mathbf{H}^{(b-1)}_{m}\big[\mathbf{H}^{(b-1)}_{v}\big]^{-1}\hat{\mathbf{R}}_{v}\big[\mathbf{H}^{(b-1)}_{v}\big]^{-1}\mathbf{H}^{(b-1)}_{m}+\mathbf{H}^{(b-1)}_{m}-\mathbf{H}^{(b-1)}_{m}\big[\mathbf{H}^{(b-1)}_{v}\big]^{-1}\mathbf{H}^{(b-1)}_{m},\forall m,

(29)

where the conditional probability density function of
\mathbf{g}_{m}(t)
can be derived from
[
23
]
and

\displaystyle\mathbb{E}\left\{\mathbf{g}_{m}(t)\big|\mathbf{V};\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\right\}=\mathbf{H}^{(b-1)}_{m}\big[\mathbf{H}^{(b-1)}_{v}\big]^{-1}\mathbf{v}(t),\forall m,t,

(30a)

\displaystyle\mathbb{D}\left\{\mathbf{g}_{m}(t)\big|\mathbf{V};\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\right\}=\mathbf{H}^{(b-1)}_{m}-\mathbf{H}^{(b-1)}_{m}\big[\mathbf{H}^{(b-1)}_{v}\big]^{-1}\mathbf{H}^{(b-1)}_{m}\geq\mathbf{0}_{N},\forall m,t.

(30b)

4.1.2
M-step

The EM algorithm estimates
\bm{\Phi}
and
\bm{\sigma}
by maximizing (
28
), i.e.,

\displaystyle\begin{aligned} \min_{\bm{\theta}\in\bm{\Psi},\mathbf{P}\geq\mathbf{0},\bm{\sigma}>\mathbf{0}}\sum_{m=1}^{M}\big[\ln\big(\mathrm{Det}(\mathbf{H}_{m})\big)+\mathrm{Tr}\big(\mathbf{H}^{-1}_{m}\hat{\mathbf{R}}^{(b)}_{m}\big)\big],\end{aligned}

(31)

which is hard to be reduced to parallel subproblems since all the
\mathbf{H}_{m}
’s are related to
\bm{\sigma}
.

To proceed, we hold
\bm{\sigma}=\bm{\sigma}^{(b-1)}
fixed and reduce problem (
31
) to the
M
parallel subproblems:

\displaystyle\min_{\theta_{m}\in(0,\pi),P_{m}\geq 0}\ln\big(\mathrm{Det}(\mathbf{K}_{m})\big)+\mathrm{Tr}\big(\mathbf{K}^{-1}_{m}\widetilde{\mathbf{R}}^{(b)}_{m}\big),\forall m,

(32)

where

\mathbf{H}_{m}=\big[\bm{\Sigma}^{(b-1)}\big]^{1/2}\mathbf{K}_{m}\big[\bm{\Sigma}^{(b-1)}\big]^{1/2}
,

\mathbf{K}_{m}=P_{m}\tilde{\mathbf{d}}(\theta_{m})\tilde{\mathbf{d}}^{H}(\theta_{m})+\alpha_{m}\mathbf{I}_{N}
,

\tilde{\mathbf{d}}(\theta_{m})=\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}\mathbf{d}(\theta_{m})
,

\widetilde{\mathbf{R}}^{(b)}_{m}=\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}\hat{\mathbf{R}}^{(b)}_{m}\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}
.
Utilizing
\mathrm{Det}(\mathbf{K}_{m})=\big(P_{m}q^{(b)}+\alpha_{m}\big)\alpha_{m}^{N-1}
with
q^{(b)}=\|\tilde{\mathbf{d}}(\theta_{m})\|^{2}=\sum_{n=1}^{M}\big[\sigma_{n}^{(b-1)}\big]^{-1}
and

\displaystyle\mathbf{K}_{m}^{-1}=\frac{1}{\alpha_{m}}\Big(\mathbf{I}_{N}-\frac{P_{m}\tilde{\mathbf{d}}(\theta_{m})\tilde{\mathbf{d}}^{H}(\theta_{m})}{P_{m}q^{(b)}+\alpha_{m}}\Big),

we further reduce subproblems (
32
) to

\displaystyle\min_{\theta_{m}\in(0,\pi),P_{m}\geq 0}\ln\big(P_{m}q^{(b)}+\alpha_{m}\big)-\frac{P_{m}\tilde{\mathbf{d}}^{H}(\theta_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta_{m})}{\alpha_{m}\big(P_{m}q^{(b)}+\alpha_{m}\big)},\forall m,

(33)

which can be solved in a separable manner and reduced to
M
parallel one-dimensional search subproblems each with respect to only one exclusive DOA
[
8
]
. Accordingly, the estimate of
\bm{\Phi}
is updated by

\displaystyle\theta^{(b)}_{m}=\arg\max_{\theta_{m}\in(0,\pi)}\tilde{\mathbf{d}}^{H}(\theta_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta_{m}),\forall m,

(34a)

\displaystyle P^{(b)}_{m}=\max\bigg\{\frac{1}{q^{(b)}}\Big(\frac{\tilde{\mathbf{d}}^{H}(\theta^{(b)}_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta^{(b)}_{m})}{q^{(b)}}-\alpha_{m}\Big),0\bigg\},\forall m,

(34b)

where
\theta^{(b)}_{m}
is indeterminate if
P^{(b)}_{m}=0
. Then, we have

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big).

(35)

4.1.3
Additional E- and M-steps

The above M-step does not update the estimate of
\bm{\sigma}
due to the complexity in problem (
31
), we thus add novel E- and M-steps to obtain
\bm{\sigma}^{(b)}
easily, which leads to that the EM algorithm becomes the SAGE algorithm
[
9
]
. To this end, we use
\mathbf{F}
and
\mathbf{Z}=[\mathbf{z}(1)\penalty\ \cdots\penalty\ \mathbf{z}(T)]
as the complete data. The corresponding complete-data LLF is written as

\displaystyle\mathcal{U}(\mathbf{P},\bm{\sigma})=\sum_{t=1}^{T}\big[\ln\mathnormal{p}(\mathbf{f}(t);\mathbf{P})+\ln\mathnormal{p}(\mathbf{z}(t);\bm{\sigma})\big]=-TM\ln(\pi)-T\sum_{m=1}^{M}\big[\ln(P_{m})+\hat{P}_{m}/P_{m}\big]

\displaystyle-TN\ln(\pi)-T\big[\ln\big(\mathrm{Det}(\bm{\Sigma})\big)+\mathrm{Tr}\big(\bm{\Sigma}^{-1}\hat{\mathbf{R}}_{z}\big)\big],

(36)

where
\hat{P}_{m}=(1/T)\sum_{t=1}^{T}|f_{m}(t)|^{2}
and
\hat{\mathbf{R}}_{z}=(1/T)\sum_{t=1}^{T}\mathbf{z}(t)\mathbf{z}^{H}(t)
are two complete-data sufficient statistics for
P_{m}
and
\bm{\Sigma}
, respectively. Based on (
4.1.3
), the additional E- and M-steps are introduced below.

At the additional E-step, the algorithm calculates the conditional expectation of
\mathcal{U}(\mathbf{P},\bm{\sigma})
, i.e.,

\displaystyle\mathbb{E}\big\{\mathcal{U}(\mathbf{P},\bm{\sigma})\big|\mathbf{V};\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big\}=-TM\ln(\pi)-T\sum_{m=1}^{M}\big[\ln(P_{m})+\hat{P}^{(b)}_{m}/P_{m}\big]

\displaystyle-TN\ln(\pi)-T\big[\ln\big(\mathrm{Det}(\bm{\Sigma})\big)+\mathrm{Tr}\big(\bm{\Sigma}^{-1}\hat{\mathbf{R}}^{(b)}_{z}\big)\big]

(37)

with

\displaystyle\hat{P}^{(b)}_{m}=\mathbb{E}\big\{\hat{P}_{m}\big|\mathbf{V};\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big\}=\big[\bar{\mathbf{q}}^{(b)}_{m}\big]^{H}\hat{\mathbf{R}}_{v}\bar{\mathbf{q}}^{(b)}_{m}+P^{(b)}_{m}\big[1-\mathbf{d}^{H}\big(\theta_{m}^{(b)}\big)\bar{\mathbf{q}}^{(b)}_{m}\big]\geq 0,\forall m,

(38a)

\displaystyle\hat{\mathbf{R}}^{(b)}_{z}=

\displaystyle\mathbb{E}\big\{\hat{\mathbf{R}}_{z}\big|\mathbf{V};\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big\}

\displaystyle=

\displaystyle\bm{\Sigma}^{(b-1)}\big[\bar{\mathbf{H}}^{(b)}_{v}\big]^{-1}\hat{\mathbf{R}}_{v}\big[\bar{\mathbf{H}}^{(b)}_{v}\big]^{-1}\bm{\Sigma}^{(b-1)}+\bm{\Sigma}^{(b-1)}-\bm{\Sigma}^{(b-1)}\big[\bar{\mathbf{H}}^{(b)}_{v}\big]^{-1}\bm{\Sigma}^{(b-1)}\geq\mathbf{0}_{N},

(38b)

where
\bar{\mathbf{H}}^{(b)}_{v}=\sum_{m=1}^{M}P^{(b)}_{m}\mathbf{d}\big(\theta^{(b)}_{m}\big)\mathbf{d}^{H}\big(\theta^{(b)}_{m}\big)+\bm{\Sigma}^{(b-1)}
,
\bar{\mathbf{q}}^{(b)}_{m}=\big[\bar{\mathbf{H}}^{(b)}_{v}\big]^{-1}\mathbf{d}\big(\theta_{m}^{(b)}\big)P^{(b)}_{m}
, and the conditional probability density functions of
f_{m}(t)
and
\mathbf{z}(t)
can be derived from
[
23
]
.

At the additional M-step, the algorithm estimates
\mathbf{P}
and
\bm{\sigma}
by maximizing (
4.1.3
), which results in the
M+N
parallel subproblems:

\displaystyle\min_{P_{m}\geq 0}\ln(P_{m})+\hat{P}^{(b)}_{m}/P_{m},\forall m,

(39a)

\displaystyle\min_{\sigma_{n}>0}\ln(\sigma_{n})+\big[\hat{\mathbf{R}}^{(b)}_{z}\big]_{n,n}/\sigma_{n},\forall n.

(39b)

Thus, the estimates of
\mathbf{P}
and
\bm{\sigma}
are updated by

\displaystyle P^{(b)}_{m}=\hat{P}^{(b)}_{m},\forall m,

(40a)

\displaystyle\sigma^{(b)}_{n}=\big[\hat{\mathbf{R}}^{(b)}_{z}\big]_{n,n}\geq 0,\forall n,

(40b)

which indicate that the estimate of
\mathbf{P}
is updated again at this iteration and
\sigma^{(b)}_{n}=0
is possible although its probability is very low. For example, if
M=1
,
T=1
, and
P^{(1)}_{1}=0
in (
34b
), we will have

\bar{\mathbf{H}}^{(1)}_{v}=\bm{\Sigma}^{(0)}>\mathbf{0}_{N}

and
\hat{\mathbf{R}}^{(1)}_{z}=\mathbf{v}(1)\mathbf{v}^{H}(1)
in (
38
). Furthermore, if
\big[\mathbf{v}(1)\big]_{n}=0
, we will obtain
\sigma^{(1)}_{n}=0
by (
40b
). To avoid
\sigma^{(b)}_{n}=0
, we require that if
\sigma^{(b)}_{n}=0
in (
40b
),
\sigma^{(b)}_{n}
will be updated by

\displaystyle\sigma^{(b)}_{n}=\zeta\sigma^{(b-1)}_{n}+(1-\zeta)\big[\hat{\mathbf{R}}^{(b)}_{z}\big]_{n,n},

where
\zeta\in(0,1]
and
\sigma^{(b)}_{n}\geq\zeta\sigma^{(b-1)}_{n}>0
if
\sigma^{(b-1)}_{n}>0
, i.e.,
\bm{\sigma}^{(b)}>\mathbf{0}
if
\bm{\sigma}^{(b-1)}>\mathbf{0}
.

After the additional M-step, this iteration finishes and following (
35
), we can verify the monotonicity of the first SAGE algorithm by

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big).

(41)

4.2
Second SAGE Algorithm

The first SAGE algorithm updates the DOA estimates simultaneously in (
34a
), which leads to slow convergence. In order to speed up the convergence, we present the second SAGE algorithm, which updates the DOA estimates sequentially from
\theta_{1}
to
\theta_{M}
like the SAGE algorithm in Subsection
3.2
.

When the second SAGE algorithm updates the estimate of
\theta_{i}
at the
i
th cycle of the
b
th iteration, all of the noise is also allocated to the
i
th source signal component. According to (
15
),
\mathbf{g}_{i}(t)\sim\mathcal{CN}(\textbf{0},\mathbf{H}_{i})
with
\mathbf{H}_{i}=P_{i}\mathbf{d}(\theta_{i})\mathbf{d}^{H}(\theta_{i})+\bm{\Sigma}
but for
m\neq i
, the statistical distribution of
\mathbf{g}_{m}(t)
depends only on
f_{m}(t)
. The corresponding complete-data LLF is written as

\displaystyle\mathcal{U}(\theta_{i},\mathbf{P},\bm{\sigma})=\sum_{t=1}^{T}\big[\sum_{m\neq i}\ln\mathnormal{p}(f_{m}(t);P_{m})+\ln\mathnormal{p}(\mathbf{g}_{i}(t);\theta_{i},P_{i},\bm{\sigma})\big]

\displaystyle=-T(M-1)\ln(\pi)-T\sum_{m\neq i}\big[\ln(P_{m})+\hat{P}_{m}/P_{m}\big]-TN\ln(\pi)-T\big[\ln\big(\mathrm{Det}(\mathbf{H}_{i})\big)+\mathrm{Tr}\big(\mathbf{H}_{i}^{-1}\hat{\mathbf{R}}_{i}\big)\big],

(42)

which is unsuitable for updating the estimate of
\bm{\sigma}
due to the complexity of
\ln\big(\mathrm{Det}(\mathbf{H}_{i})\big)+\mathrm{Tr}\big(\mathbf{H}_{i}^{-1}\hat{\mathbf{R}}_{i}\big)
. To proceed, we hold
\bm{\sigma}=\bm{\sigma}^{(b-1)}
fixed and let the algorithm only update the estimates of
\theta_{i}
and
\mathbf{P}
by the following E- and M-steps.

4.2.1
E-step

The algorithm calculates the conditional expectation of
\mathcal{U}(\theta_{i},\mathbf{P},\bm{\sigma})
, i.e.,

\displaystyle\mathbb{E}\left\{\mathcal{U}(\theta_{i},\mathbf{P},\bm{\sigma})\big|\mathbf{V};\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b-1)}\right\}=-T(M-1)\ln(\pi)-TN\ln(\pi)

\displaystyle-T\sum_{m\neq i}\big[\ln(P_{m})+\hat{P}^{(b,i)}_{m}/P_{m}\big]-T\big[\ln\big(\mathrm{Det}(\mathbf{H}_{i})\big)+\mathrm{Tr}\big(\mathbf{H}_{i}^{-1}\hat{\mathbf{R}}^{(b)}_{i}\big)\big],

(43)

where

\displaystyle\hat{P}^{(b,i)}_{m}=

\displaystyle\mathbb{E}\big\{\hat{P}_{m}\big|\mathbf{V};\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b-1)}\big\}

\displaystyle=

\displaystyle P^{(b,i-1)}_{m}\big[1-\mathbf{d}^{H}(\theta^{(b,i-1)}_{m})\bar{\mathbf{q}}^{(b,i-1)}_{m}\big]+[\bar{\mathbf{q}}^{(b,i-1)}_{m}]^{H}\hat{\mathbf{R}}_{v}\bar{\mathbf{q}}^{(b,i-1)}_{m}\geq 0

(44)

with
\bar{\mathbf{H}}^{(b,i-1)}_{v}=\sum_{m=1}^{M}P_{m}^{(b,i-1)}\mathbf{d}(\theta^{(b,i-1)}_{m})\mathbf{d}^{H}(\theta^{(b,i-1)}_{i})+\bm{\Sigma}^{(b-1)}
and

\bar{\mathbf{q}}^{(b,i-1)}_{m}=\big[\bar{\mathbf{H}}^{(b,i-1)}_{v}\big]^{-1}\mathbf{d}\big(\theta^{(b,i-1)}_{m}\big)P^{(b,i-1)}_{m}
,

\displaystyle\hat{\mathbf{R}}^{(b)}_{i}=

\displaystyle\hat{\mathbf{R}}^{(b,i)}_{i}=\mathbb{E}\big\{\hat{\mathbf{R}}_{i}\big|\mathbf{V};\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b-1)}\big\}

\displaystyle=

\displaystyle\bar{\mathbf{H}}^{(b,i-1)}_{i}[\bar{\mathbf{H}}^{(b,i-1)}_{v}]^{-1}\hat{\mathbf{R}}_{v}[\bar{\mathbf{H}}^{(b,i-1)}_{v}]^{-1}\bar{\mathbf{H}}^{(b,i-1)}_{i}+\bar{\mathbf{H}}^{(b,i-1)}_{i}-\bar{\mathbf{H}}^{(b,i-1)}_{i}[\bar{\mathbf{H}}^{(b,i-1)}_{v}]^{-1}\bar{\mathbf{H}}^{(b,i-1)}_{i}\geq\mathbf{0}_{N}

(45)

with
\bar{\mathbf{H}}^{(b,i-1)}_{i}=P_{i}^{(b,i-1)}\mathbf{d}(\theta^{(b,i-1)}_{i})\mathbf{d}^{H}(\theta^{(b,i-1)}_{i})+\bm{\Sigma}^{(b-1)}
.

4.2.2
M-step

The algorithm estimates
\theta_{i}
and
\mathbf{P}
by maximizing (
4.2.1
), i.e.,

\displaystyle\min_{\theta_{i}\in(0,\pi),\mathbf{P}\geq 0}\sum_{m\neq i}\big[\ln(P_{m})+\hat{P}^{(b,i)}_{m}/P_{m}\big]+\big[\ln\big(\mathrm{Det}(\mathbf{H}_{i})\big)+\mathrm{Tr}\big(\mathbf{H}_{i}^{-1}\hat{\mathbf{R}}^{(b)}_{i}\big)\big],

(46)

which leads to that

\displaystyle P^{(b,i)}_{m}=\hat{P}^{(b,i)}_{m},\forall m\neq i,

(47)

while the estimates of
\theta_{i}
and
P_{i}
are updated by

\displaystyle\min_{\theta_{i}\in(0,\pi),P_{i}\geq 0}\ln\big(\mathrm{Det}(\mathbf{K}_{i})\big)+\mathrm{Tr}\big(\mathbf{K}_{i}^{-1}\widetilde{\mathbf{R}}^{(b)}_{i}\big),

(48)

where
\mathbf{H}_{i}=\big[\bm{\Sigma}^{(b-1)}\big]^{1/2}\mathbf{K}_{i}\big[\bm{\Sigma}^{(b-1)}\big]^{1/2}
,

\mathbf{K}_{i}=P_{i}\tilde{\mathbf{d}}(\theta_{i})\tilde{\mathbf{d}}^{H}(\theta_{i})+\mathbf{I}_{N}
,

\tilde{\mathbf{d}}(\theta_{i})=\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}\mathbf{d}(\theta_{i})
,

\widetilde{\mathbf{R}}^{(b)}_{i}=\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}\hat{\mathbf{R}}^{(b)}_{i}\big[\bm{\Sigma}^{(b-1)}\big]^{-1/2}
.
Following (
34a
)–(
34b
), the estimates of
\theta_{i}
and
P_{i}
can be updated by

\displaystyle\theta^{(b)}_{i}=\theta^{(b,i)}_{i}=\arg\max_{\theta_{i}\in(0,\pi)}\tilde{\mathbf{d}}^{H}(\theta_{i})\widetilde{\mathbf{R}}^{(b)}_{i}\tilde{\mathbf{d}}(\theta_{i}),

(49a)

\displaystyle P^{(b,i)}_{i}=\max\bigg\{\frac{1}{q^{(b)}}\Big(\frac{\tilde{\mathbf{d}}^{H}(\theta^{(b)}_{i})\widetilde{\mathbf{R}}^{(b)}_{i}\tilde{\mathbf{d}}(\theta^{(b)}_{i})}{q^{(b)}}-1\Big),0\bigg\}.

(49b)

The other signal parameter estimate(s) in
\bm{\Phi}^{(b,i-1)}=(\bm{\theta}^{(b,i-1)},\mathbf{P}^{(b,i-1)})
is(are) not updated at this cycle and the iterative value(s) is(are) denoted by

\displaystyle\theta^{(b,i)}_{m}=\theta^{(b,i-1)}_{m},\forall m\neq i.

(50)

After this cycle, we have

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b,i)},\bm{\sigma}^{(b-1)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b,i-1)},\bm{\sigma}^{(b-1)}\big).

(51)

The above E- and M-steps (or cycle) are repeated until the estimate of
\theta_{M}
is updated and we further have

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big)=\mathcal{L}\big(\bm{\Phi}^{(b,M)},\bm{\sigma}^{(b-1)}\big)\geq\cdots\geq\mathcal{L}\big(\bm{\Phi}^{(b,0)},\bm{\sigma}^{(b-1)}\big)=\mathcal{L}\big(\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big).

(52)

4.2.3
Additional E- and M-steps

The above procedure does not update the estimate of
\bm{\sigma}
, so we also use the additional E- and M-steps
4.1.3
of the first SAGE algorithm to obtain
\bm{\sigma}^{(b)}
easily. After the additional E- and M-steps, the
b
th iteration finishes and following (
52
), we can verify the monotonicity of the second SAGE algorithm by

\displaystyle\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b)},\bm{\sigma}^{(b-1)}\big)\geq\mathcal{L}\big(\bm{\Phi}^{(b-1)},\bm{\sigma}^{(b-1)}\big).

(53)

5
Convergence Properties of the EM-Type Algorithms

5.1
Convergence Point

It is easy to verify that the above EM-type algorithms satisfy standard regularity conditions and the two algorithms for the same signal model always converge to different stationary points or the same stationary point of
\mathcal{L}(\bm{\Phi},\bm{\sigma})

[
6
]
,
[
9
]
,
[
24
]
.

It is well known that these algorithms, as “hill climbing” algorithms, require accurate initial points for obtaining their global maximum points. Moreover, note that processing the same samples, the two algorithms for the same signal model may converge to different stationary points of
\mathcal{L}(\bm{\Phi},\bm{\sigma})
given the same initial point, which indicates that one of the two algorithm may be more efficient for avoiding the convergence to an unwanted stationary point of
\mathcal{L}(\bm{\Phi},\bm{\sigma})
than the other. Hence, we compare convergence points of the EM-type algorithms given poor initial points in the next section.

5.2
Complexity and Stability

The computational complexities of the EM-type algorithms at the
b
th iteration mainly lie in the
M
one-dimensional search problems:

\displaystyle\theta^{(b)}_{m}=\arg\max_{\theta_{m}\in(0,\pi)}\tilde{\mathbf{d}}^{H}(\theta_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta_{m}),\forall m.

(54)

However, we find that when the powers of sources are unequal, the DOA estimates of multiple sources, updated by (
54
), tend to be consistent with the true DOA of the source with the largest power. As a consequence, the EM-type algorithms are unstable.

To address this issue, we reduce the difference between
\theta_{m}^{(b)}
and
\theta_{m}^{(b-1)}
and still use the method in our previous works
[
12
]
,
[
22
]
, i.e., choosing
\theta_{m}^{(b-1)}
as the initial point of some gradient algorithm and then applying this gradient algorithm to search a local maximum point of
\tilde{\mathbf{d}}^{H}(\theta_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta_{m})
as
\theta_{m}^{(b)}
, which leads to
Algorithm 1
in the next section. Using this method, we still have

\displaystyle\tilde{\mathbf{d}}^{H}(\theta^{(b)}_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta^{(b)}_{m})\geq\tilde{\mathbf{d}}^{H}(\theta^{(b-1)}_{m})\widetilde{\mathbf{R}}^{(b)}_{m}\tilde{\mathbf{d}}(\theta^{(b-1)}_{m}),\forall m,

(55)

which guarantees the monotonicity of the EM-type algorithms.

7
Conclusion

We have presented several EM-type algorithms for efficiently computing both the deterministic and stochastic ML estimators in unknown nonuniform noise. Specifically, we design a GEM algorithm and an SAGE algorithm for computing the deterministic ML estimator. Simulation results show that the SAGE algorithm converges faster and is more efficient for avoiding the convergence to an unwanted stationary point of the LLF. Moreover, we design two SAGE algorithms for computing the stochastic ML estimator, in which the first updates the DOA estimates simultaneously while the second updates the DOA estimates sequentially. Simulation results show that the second SAGE algorithm converges faster and is more efficient for avoiding the convergence to an unwanted stationary point of the LLF.
