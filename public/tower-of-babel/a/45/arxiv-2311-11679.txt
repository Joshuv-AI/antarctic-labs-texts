Perfect Simulation of Las Vegas Algorithms via Local Computation
Xinyu Fu, Yonggang Jiang, Yitong Yin

Abstract
The notion of Las Vegas algorithms was introduced by Babai (1979) and can be defined in two ways: • In Babai’s original definition, a randomized algorithm is called Las Vegas if it has a finitely bounded running time and certifiable random failure. • Another definition widely accepted today is that Las Vegas algorithms refer to zero-error randomized algorithms with random running times. The equivalence between the two definitions is straightforward. Specifically, for randomized algorithms with certifiable failures, repeatedly running the algorithm until no failure is encountered allows for faithful simulation of the correct output when it executes successfully. We show that a similar perfect simulation can also be achieved in distributed local computation. Specifically, in the 𝖫𝖮𝖢𝖠𝖫 \mathsf{LOCAL} model, with polylogarithmic overhead in time complexity, any Las Vegas algorithm with finitely bounded running time and locally certifiable failures can be converted to a zero-error Las Vegas algorithm. This transformed algorithm faithfully reproduces the correct output of the original algorithm in successful executions.

Introduction

The Las Vegas algorithm, introduced by Babai
[
2
]
, stands as a cornerstone in the theory of computing,
defining the
ZPP
class for decision problems efficiently solvable by Las Vegas algorithms.
Beyond decision problems, Las Vegas algorithms are pivotal in tackling optimization
[
21
,
4
]
, searching
[
27
,
28
]
, or sampling
[
32
,
13
]
problems.

Las Vegas algorithms can indeed be defined in two distinct yet related ways.
In Babai’s original work
[
2
]
, Las Vegas algorithms are defined as randomized algorithms whose failures are
certifiable
:

•

A Las Vegas algorithm produces the correct output or reports failure within a finite bounded time.

An alternative definition of the Las Vegas algorithm, widely accepted today and utilized in various contexts, e.g. in
[
24
,
26
,
29
]
,
defines Las Vegas algorithms as
zero-error
randomized algorithms:

•

A Las Vegas algorithm may exhibit random running time but always produces the correct output.

The equivalence between these two definitions is evident.
Through truncation, we can transform a zero-error Las Vegas algorithm with random running time into a Las Vegas algorithm with bounded running time and certifiable failure.
Conversely, restarting the algorithm upon failure allows us to convert a Las Vegas algorithm with certifiable failure into a zero-error Las Vegas algorithm.
This strategy, retrying with independent random choice until success, defines a
rejection sampling
procedure that faithfully simulates the random output of the Las Vegas algorithms, provided they return successfully without failure.

This strategy for perfectly simulating the Las Vegas algorithm relies on a global coordination machinery:
every part of the algorithm must be notified if a failure occurs anywhere.
However, our focus is on exploring how this could be accomplished through local computations, without the need for global coordination.

The
\mathsf{LOCAL}
model.

Local computations are formally characterized by the
\mathsf{LOCAL}
model
[
22
,
31
]
.
An instance consists of a network
G=(V,E)
, which is an undirected graph,
and a vector
\bm{{x}}=(x_{v})_{v\in V}
of local inputs.
Each node
v\in V
receives
x_{v}
and
n=|V|
as its input and can access to private random bits.
Communications are synchronized and proceed in rounds.
In each round, each node may perform arbitrary local computation based on all information collected so far
and send messages of arbitrary sizes to all its neighbors.
This gives a
\mathsf{LOCAL}
algorithm. The time complexity is measured by the number of rounds spent by the algorithm until all nodes terminate.
A
\mathsf{LOCAL}
algorithm is said to be a
t(n)
-round
\mathsf{LOCAL}
algorithm on a class of instances,
if it always terminates within
t(n)
rounds on every instance from that class, where
n
represents the number of nodes of the instance.

The (Babai’s) Las Vegas algorithm can be defined in the
\mathsf{LOCAL}
mode with
locally certifiable failures
.
A
t(n)
-round
\mathsf{LOCAL}
algorithm is called
Las Vegas

if each node
v\in V
returns a pair
(Y_{v},F_{v})
, where
Y_{v}
stands for the local output at
v
,
and
F_{v}\in\{0,1\}
indicates whether the algorithm failed locally at
v
.
The algorithm successfully returns if none of the nodes fails.
Furthermore, it is guaranteed that
\sum_{v\in V}\mathbb{E}[F_{v}]<1
.
This notion of Las Vegas
\mathsf{LOCAL}
algorithm was formulated in
[
12
]
.

In this paper, we try to answer the following fundamental question:

Can we faithfully simulate the correct output avoiding all local failures via local computation?

Specifically,
we wonder whether a fixed-round Las Vegas
\mathsf{LOCAL}
algorithm with locally certifiable failures,
can be converted into a zero-error Las Vegas
\mathsf{LOCAL}
algorithm that produces the correct output
(Y_{v})_{v\in V}
conditioned on
\sum_{v\in V}F_{v}=0
,
where the distribution of the correct output is faithfully preserved.
This asks for what used to be achieved by the rejection sampling in the absence of global coordination.

In this paper, for the first time, we answer this question affirmatively.
We prove the following result for the perfect simulation of Las Vegas algorithms via local computation.

Theorem 1.1

(main theorem, informal)
.

Any
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm can be converted to a zero-error Las Vegas
\mathsf{LOCAL}
algorithm,
which terminates within
t(n)\cdot\mathrm{polylog}(n)
rounds with probability
1-n^{-O(1)}
,
and returns the output of the
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm conditioned on no failure.

In the above theorem, the output of the zero-error Las Vegas
\mathsf{LOCAL}
algorithm is identically distributed as the output of the
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm conditioned on that none of the nodes fails,
i.e. the zero-error algorithm perfectly simulates a successful running of the algorithm that may locally fail.

To see how nontrivial this is,
consider a weakened task:
to generate an assignment of random bits so that under this random choice the algorithm terminates without failure.
One may think of this as “solving” the random bits under which the algorithm successfully returns,
which is weaker than our goal,
where the generated random bits are further required to follow the correct distribution.
However, for local computation, just solving the feasible random bits without bothering their distribution is already highly nontrivial.

In a seminal work
[
12
]
, Ghaffari, Harris and Kuhn
gave a systematic approach for solving the good random bits under which a Las Vegas
\mathsf{LOCAL}
algorithm successfully returns.
Their derandomization based approach preserves the
support
of distribution, hence was more suitable for the
distributed graph problems
for constructing feasible solutions on graphs.
Specifically,
\mathrm{polylog}(n)
-round reductions were established between the two types of the Las Vegas
\mathsf{LOCAL}
algorithms for such problems.

In contrast,
the perfect simulation is guaranteed in

Theorem

1.1
preserves the distribution,
therefore, the result can apply to the problems beyond constructing feasible solutions, for example, the sampling problems.

Consider the
Gibbs distributions
defined on the network
G=(V,E)
.
Each node
v
corresponds to a variable with finite domain
\Sigma
.
Let
\mathcal{F}
be a class of
constraints
, where each
f\in\mathcal{F}
is a nonnegative-valued function
f:\Sigma^{\mathsf{vbl}(f)}\to\mathbb{R}_{\geq 0}
defined on the variables in
\mathsf{vbl}(f)\subseteq V
.
This defines a Gibbs distribution

over all assignments
\sigma\in\Sigma^{V}
by:

\mu(\sigma)\propto\prod_{f\in\mathcal{F}}f\left(\sigma_{\mathsf{vbl}(f)}\right).

Such Gibbs distribution
\mu
is said to be
local

, the diameter of
\mathsf{vbl}(f)

and (2) for any partial assignment

\Lambda\subseteq V

with
\mathsf{vbl}(f)\subseteq\Lambda

then
\sigma
is (globally) feasible, which means that
\sigma
can be extended to a feasible full assignment
\tau\in\Sigma^{V}
such that
\tau_{\Lambda}=\sigma

\mu(\tau)>0
.

In

A Gibbs distribution

strong spatial mixing with exponential decay

if the discrepancy (measured in total variation distance)

\mu_{v}^{\sigma},\mu_{v}^{\tau}

The strong spatial mixing is a key property for sampling algorithms.
Its implication for efficient sampling from general Gibbs distributions is a major open problem.
In
[
10

,
a
\mathrm{polylog}(n)
-round Las Vegas
\mathsf{LOCAL}

By

, this immediately implies the following result for perfect simulation of Gibbs distributions via local computation.

Corollary 1.2
.

For any class of local Gibbs distributions that have strong spatial mixing with exponential decay,
there is a
\mathsf{LOCAL}
algorithm for perfect sampling from the Gibbs distribution, which terminates within
\mathrm{polylog}(n)
rounds with probability
1-n^{-O(1)}
.

Remark 1.1
.

The computational tractability of sampling from general Gibbs distributions with strong spatial mixing remains unresolved, even in the sequential and centralized setting.

Corollary

1.2
certainly does not resolve the computational complexity of sampling.
This is because the
\mathsf{LOCAL}
model does not impose any bounds on the computational costs,
and generic reductions such as the one stated in
Theorem

1.1
must apply to all
\mathsf{LOCAL}
algorithms,
including those that run in super-polynomial time.
Such lack of limitation on computational power was indeed common in general (black-box) reductions in the
\mathsf{LOCAL}
model and may be necessary.
For instance, the derandomization of general
\mathsf{LOCAL}
algorithms in
[
12
]
also relied on local exhaustive search of random bits.
Here, our objective is even more ambitious: to preserve the distribution of the random bits of a sucessive running.

On a positive note, if it is known that the correct output has strong spatial mixing, as in the case of
Corollary

1.2
, then the perfect simulation in
Theorem

1.1
can be simplified (using
Algorithm

3
instead of
Algorithm

4
), avoiding exhaustive enumerations.
Consequently, the computational cost of the algorithm in
Corollary

1.2
is dominated by approximately sampling from the marginal distributions
\mu_{v}^{\sigma}
and estimating the marginal probabilities within an inverse-polynomial accuracy.
Indeed, the non-trivial computation costs in both the sampling algorithm in
[
10
]
and our perfect simulation algorithm when there is a strong spatial mixing, are dominated by these tasks which are computationally equivalent to sampling.

In summary, the focus of
Corollary

1.2
is the locality of Gibbs sampling.
Our proof of it may also imply:
locality of computation imposes no additional significant barrier to the task of Gibbs sampling with strong spatial mixing, provided the sampling problem is computationally tractable.

1.1
A sampling Lovász local lemma in the
\mathsf{LOCAL}
model

The perfect simulation of Las Vegas
\mathsf{LOCAL}
algorithms stated in
Theorem

1.1
is achieved by resolving a more general problem,
namely, generating a random sample avoiding all bad events.
This problem is formulated as a natural sampling problem in the variable-framework of the Lovász local lemma.

An instance for the variable-framework Lovász local lemma (LLL) is given by
I=\left(\{X_{i}\}_{i\in U},\{A_{v}\}_{v\in V}\right)
,
where
\{X_{i}\}_{i\in U}
is a set of mutually independent random variables,
such that each
X_{i}
follows a distribution
\nu_{i}
over a finite domain
\Sigma_{i}
;
and
\{A_{v}\}_{v\in V}
is a set of
bad events
, such that for each
v\in V
, the occurrence of
A_{v}
is determined by the evaluation of
X_{\mathsf{vbl}(v)}=(X_{i})_{i\in\mathsf{vbl}(v)}
, where
\mathsf{vbl}(v)\subseteq U
denotes the subset of variables on which
A_{v}
is defined.
The LLL instance
I
defines a
dependency graph

D=D_{I}=(V,E)
, such that each vertex
v\in V
represents a bad event
A_{v}
and each
\{u,v\}\in E
iff
\mathsf{vbl}(v)\cap\mathsf{vbl}(u)\neq\emptyset
.

An LLL instance
I
is said to be
\gamma
-satisfiable
, if the probability avoiding all bad events is bounded as:

\displaystyle\Pr\left(\,\bigcap_{v\in V}\overline{A_{v}}\,\right)\geq\gamma.

(1)

The Lovász local lemma
[
5
]
states a sufficient condition on the dependency graph for
\gamma
to be positive.

A satisfiable LLL instance
I
gives rise to a natural probability distribution over satisfying assignments.
Let
\mu=\mu_{I}
denote the distribution of the random vector
\bm{X}=(X_{i})_{i\in U}
conditioning on that none of the bad events
\{A_{v}\}_{v\in V}
occur.
Formally, denote by
\Omega=\Omega_{I}\triangleq\{\sigma\in\bigotimes_{i\in U}\Sigma_{i}\mid\sigma\text{ avoids }A_{v}\text{ for all }v\in V\}
the space of all satisfying assignments,
and
\nu=\nu_{I}\triangleq\prod_{i\in U}\nu_{i}
the product measure. Then

\displaystyle\forall\sigma\in\Omega,\quad\mu({\sigma})\triangleq\Pr(\bm{X}=\sigma\mid\bm{X}\in\Omega)=\frac{\nu({\sigma})}{\nu(\Omega)}.

(2)

This distribution
\mu=\mu_{I}
of random satisfying assignment was referred to as the
LLL distribution
in
[
16
,
15
]
. It is a Gibbs distribution defined by hard constraints.

The following defines a computational problem for generating a sample according to the distribution
\mu
.

Sampling Satisfying Solution of Lovász Local Lemma

Input :

a
\gamma
-satisfiable LLL instance
I
with dependency graph
D_{I}=(V,E)
;

Output:

a random satisfying assignment
\bm{{X}}^{*}=(X^{*}_{i})_{i\in U}
distributed as
\mu_{I}
.

When the problem is solved in the
\mathsf{LOCAL}
model, the input is presented to the algorithm as follows:

1.

The network
G
of the
\mathsf{LOCAL}
model is just the dependency graph
D_{I}
.

2.

Each node
v\in V
receives as input the values of
n=|V|
and
\gamma
, along with the definition of the bad event
A_{v}
, and the distributions
\nu_{i}
of the random variables
\{X_{i}\mid i\in\mathsf{vbl}(v)\}
on which
A_{v}
is defined
so that it can locally draw independent evaluations of the random variables
\{X_{i}\mid i\in\mathsf{vbl}(v)\}
or check the occurrence of
A_{v}
on such evaluation.

Our main technical result is an efficient
\mathsf{LOCAL}
algorithm for sampling satisfying solution according to the LLL distribution, for any LLL instance that is not prohibitively scarce to satisfy.
We call this result a “
\mathsf{LOCAL}
sampling lemma” since it uses the local lemma framework to give a
\mathsf{LOCAL}
sampling algorithm.

Theorem 1.3

(
\mathsf{LOCAL}
sampling lemma)
.

There is a randomized
\mathsf{LOCAL}
algorithm such that for any LLL instance
I
with
n
bad events,
if
I
is
\gamma
-satisfiable, then the algorithm returns a random satisfying assignment drawn from
\mu_{I}
,
within
\widetilde{O}\left(\log^{6}n\cdot\log^{4}\frac{1}{\gamma}\right)
rounds in expectation,
and within
\widetilde{O}\left(\log^{6}n\cdot\log^{4}\frac{1}{\gamma}\cdot\log^{6}\frac{1}{\epsilon}\right)
rounds with probability at least
1-\epsilon
for any
0<\epsilon<1
.

While the classical algorithmic Lovász Local Lemma (LLL) aims to construct a satisfying assignment,
our objective is more ambitious:
to generate a random satisfying assignment according to the LLL distribution
\mu
.
This sampling problem has been shown to require polynomially stronger conditions than the conventional algorithmic LLL
[
3
,
13
,
15
]
.
Recently, polynomial-time centralized algorithms have been discovered for sampling uniform satisfying assignments for general LLL instances
[
18
,
19
,
8
,
25
]
.
However, in our context of perfectly simulating Las Vegas
\mathsf{LOCAL}
algorithms,
we do not impose any local lemma type of condition on the dependency graph.
Instead, we show that the sampling problem is tractable via local computation,
as long as the chance for a random assignment to be satisfying is non-negligible.
To the best of our knowledge, this marks the first result of its kind.

As a byproduct, the algorithm in
Theorem

1.3
gives a uniform sampler for LCLs in the
\mathsf{LOCAL}
model.
The
locally checkable labelings
(
LCLs
) (see
[
30
]
for formal definitions) are vertex labelings satisfying local constraints in the network.
Suppose that each label is drawn uniformly and independently at random,
and violating the locally checkable constraint at each node
v\in V
defines a bad event
A_{v}
.
Then the LLL distribution corresponds to the uniform distribution over LCLs, and
Theorem

1.3
has the following corollary.

Corollary 1.4
.

For any locally checkable labeling (LCL) problem, if uniform random labeling can always generate a correct LCL with probability at least
2^{-\mathrm{polylog(n)}}
, then there is a randomized
\mathsf{LOCAL}
algorithm that outputs a uniform random LCL within
\mathrm{polylog}(n)
rounds with high probability.

1.2
Perfect simulation via
\mathsf{LOCAL}
sampling lemma

Recall that for
\mathsf{LOCAL}
algorithms, an instance
\mathcal{{I}}=(G,\bm{{x}})
consists of a network
G=(V,E)
and a vector
\bm{{x}}=(x_{v})_{v\in V}
specifying the local input
x_{v}
to each node
v\in V
.
Let
\mathfrak{{C}}
be a class of instances.
A
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm with success probability
\gamma(n)
on instance class
\mathfrak{{C}}
,
is a randomized
\mathsf{LOCAL}
algorithm such that on every instance
\mathcal{{I}}=(G,\bm{{x}})\in\mathfrak{{C}}
, where
G
is a network with
n=|V|
nodes,
at every node
v\in V
the algorithm terminates within
t(n)
rounds and outputs a pair
(Y_{v},F_{v})
where
F_{v}\in\{0,1\}
indicates whether the algorithm failed locally at
v
, and the probability that the algorithm succeeds is

\Pr\left(\forall v\in V:\bm{{F}}_{v}={0}\right)\geq\gamma(n).

Denote by
(\bm{{Y}}_{\mathcal{{I}}},\bm{{F}}_{\mathcal{{I}}})=\left\langle(Y_{v})_{v\in V},(F_{v})_{v\in V}\right\rangle
the output of the Las Vegas
\mathsf{LOCAL}
algorithm on instance
\mathcal{{I}}=(G,\bm{{x}})
with network
G=(V,E)
.
The following theorem is a formal restatement of
Theorem

1.1
, which gives a zero-error Las Vegas
\mathsf{LOCAL}
algorithm that perfectly simulates the good output
(\bm{{Y}}_{\mathcal{{I}}}\mid\bm{{F}}_{\mathcal{{I}}}=\bm{{0}})
when there is no failure everywhere in the network.

Theorem 1.5

(formal restatement of
Theorem

1.1
)
.

Let
t:\mathbb{N}\to\mathbb{N}
and
\gamma:\mathbb{N}\to[0,1]
be two functions.
Let
\mathcal{{A}}
be a
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm with success probability
\gamma(n)
on instance class
\mathfrak{{C}}
.
There is a
\mathsf{LOCAL}
algorithm
\mathcal{{B}}
such that on every instance
\mathcal{{I}}\in\mathfrak{{C}}
of
n
nodes, for any
0<\epsilon<1
,

•

\mathcal{{B}}
terminates within
t(n)\cdot\widetilde{O}\left(\log^{6}n\cdot\log^{4}\frac{1}{\gamma(n)}\cdot\log^{6}\frac{1}{\epsilon}\right)
rounds with probability at least
1-\epsilon
;

•

upon termination,
\mathcal{{B}}
returns an output
\bm{{Y}}_{\mathcal{{I}}}^{\mathcal{{B}}}
that is identically distributed as
(\bm{{Y}}_{\mathcal{{I}}}^{\mathcal{{A}}}\mid\bm{{F}}_{\mathcal{{I}}}^{\mathcal{{A}}}=\bm{{0}})
,
which stands for the output of
\mathcal{{A}}
on the same instance
\mathcal{{I}}
conditioned on that none of the nodes fails.

Proof.

Let
\mathcal{{I}}=(G,\bm{{x}})\in\mathfrak{{C}}
be the instance of the
\mathsf{LOCAL}
algorithm, where
G=(V,E)
is a network with
n=|V|
nodes and the vector
\bm{{x}}=(x_{v})_{v\in V}
specifies the local inputs.
For each
v\in V
, let
X_{v}
denote the local random bits at node
v
used by algorithm
\mathcal{{A}}
.

Since
\mathcal{{A}}
is a
t(n)
-round Las Vegas
\mathsf{LOCAL}
algorithm,
at any
v\in V
, the algorithm
\mathcal{{A}}
deterministically maps the inputs
\bm{{x}}_{B}=(x_{v})_{v\in B}
and the random bits
\bm{{X}}_{B}=(X_{v})_{v\in B}
within the
t(n)
-ball
B=B_{t(n)}(v)
, to the local output
\left(Y_{v}^{\mathcal{{A}}},F_{v}^{\mathcal{{A}}}\right)
, where
F_{v}^{\mathcal{{A}}}\in\{0,1\}
indicates the failure at
v
.
This defines a bad event
A_{v}
for every
v\in V
, on the random variables
X_{u}
for
u\in B_{t(n)}(v)
, i.e.
\mathsf{vbl}(v)=B_{t(n)}(v)
, by

A_{v}:F_{v}^{\mathcal{{A}}}(\bm{{X}}_{\mathsf{vbl}(v)})=1.

Together, this defines an LLL instance
I=(\{X_{v}\}_{v\in V},\{A_{v}\}_{v\in V})
, which is
\gamma(n)
-satisfiable because the probability that
\mathcal{{A}}
has no failure everywhere is at least
\gamma(n)
.

We simulate the sampling algorithm in Theorem
1.3
(which we call the
LLL sampler
) on this LLL instance
I
.
Rather than executing it on the dependency graph
D_{I}
as in Theorem
1.3
, here we simulate the LLL sampler on the network
G=(V,E)
, where each node
v\in V
holds an independent random variable
X_{v}
and a bad event
A_{v}
.
Note that any 1-round communication in the dependency graph
D_{I}

can be simulated by
O(t(n))
-round communications in this network
G=(V,E)
.
Also note that at each
v\in V
, the values of
t(n)
and
\gamma(n)
can be computed locally by knowing
n=|V|
and enumerating all network instances
\mathcal{{I}}\in\mathfrak{{C}}
with
n
nodes.
The LLL sampler can thus be simulated with
O(t(n))
-multiplicative overhead.
In the end it outputs an
\bm{{X}}^{*}=(X_{v}^{*})_{v\in V}\sim\mu_{I}
, which is identically distributed as
\left(\bm{{X}}\mid\bm{{F}}^{\mathcal{{A}}}_{\mathcal{{I}}}=\bm{{0}}\right)
, i.e. the random bits used in the algorithm
\mathcal{{A}}
conditioned on no failure.
The final output
\bm{{Y}}^{*}=(Y_{v}^{*})_{v\in V}
is computed by simulating
\mathcal{{A}}
within
t(n)
locality deterministically using
\bm{{X}}^{*}=(X_{v}^{*})_{v\in V}
as random bits.

The LLL sampler in Theorem
1.3
is a Las Vegas algorithm with random terminations.
Each node
v\in V
can continue updating
Y_{v}^{*}
using the current random bits
\bm{{X}}^{*}_{B}
it has collected within its
t(n)
-local neighborhood
B=B_{t(n)}(v)
.
Once the LLL sampler for generating
\bm{{X}}^{*}
terminates at all nodes,
the updating of
\bm{{Y}}^{*}
will stabilize within additional
t(n)
rounds.
And this final
\bm{{Y}}^{*}
is identically distributed as
\left(\bm{{Y}}_{\mathcal{{I}}}^{\mathcal{{A}}}\mid\bm{{F}}^{\mathcal{{A}}}_{\mathcal{{I}}}=\bm{{0}}\right)
.
This gives us the zero-error Las Vegas
\mathsf{LOCAL}
algorithm
\mathcal{{B}}
as claimed in Theorem
1.5
.

Graph and LLL notations

Let

•

:

:

The following defines a notion of rings of variables that enclose a nonempty subset

2.4
Las Vegas
\mathsf{SLOCAL}
algorithm

Our main sampling algorithm is described in a sequential local (
\mathsf{SLOCAL}
) paradigm.
The
\mathsf{SLOCAL}
model introduced by Ghaffari, Kuhn, and Maus
[
14
]
captures the local computations where symmetry breaking is not concerned.
We extend this notion to the algorithms with random locality of computation.

\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithms

An
N
-scan
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm runs on a network
G=(V,E)
with a subset
A\subseteq V
of
active
nodes.
Each node
v\in V
maintains a local memory state
M_{v}
,
initially storing
v
’s local input, random bits, its ID, and neighbors’ IDs.
An arbitrary total order is assumed over
V
,
such that the relative order between any
u,v\in V
can be deduced from the contents of
M_{u}
and
M_{v}
.

The algorithm operates in
N\geq 1
scans.
Within each scan, the active nodes in
A
are processed one after another in the ordering.
Upon each node
v\in A
being processed, for
\ell=0,1,2,\ldots
,
the node
v
tries to grow an
\ell
-ball
B_{\ell}(v)
and update the memory states
M_{u}
for all
u\in B_{\ell}(v)
based on the information observed so far by
v
,
until some stopping condition has been met by the information within the current ball
B_{\ell}(v)
.
Finally, each
v\in V
outputs a value based on its memory state
M_{v}
.

Compared to the standard (Monte Carlo)
\mathsf{SLOCAL}
algorithm, whose locality is upper bounded by a fixed value,
in
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm, the local neighborhoods are randomly constructed in a sequential and local fashion.
The next theorem gives a simulation of
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithms in the
\mathsf{LOCAL}
model.

Proposition 2.1

(simulation of
\mathsf{SLOCAL}\text{-}\mathsf{LV}
in
\mathsf{LOCAL}
)
.

Let
\mathcal{{A}}
be an
N
-scan
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm that assumes an arbitrary ordering of nodes.
Then there is a randomized
\mathsf{LOCAL}
algorithm
\mathcal{{B}}
,
such that starting from the same initial memory states
\bm{M}=(M_{v})_{v\in V}
,
the algorithm
\mathcal{{B}}
terminates and returns the same output as
\mathcal{{A}}
within
O\left(|A|\cdot\max_{v\in A,j\in[N]}\ell_{v,j}\right)
rounds, where
A
is the set of active nodes and
\ell_{v,j}
is the radius of the ball accessed by the active node
v
in the
j
th scan of algorithm
\mathcal{{A}}
, both fully determined by
\bm{M}
.

Compared to the simulation of
\mathsf{SLOCAL}
Monte Carlo algorithm in the
\mathsf{LOCAL}
model proved in
[
14
]
, which relies on the network decomposition to parallelize the
\mathsf{SLOCAL}
procedure,

Proposition

2.1
provides a rather straightforward simulation that does not parallelize the local computations.
An advantage of such an easy simulation is that it does not require a worst-case complexity upper bound for all scan orders of nodes.
This translation from
\mathsf{SLOCAL}\text{-}\mathsf{LV}
to
\mathsf{LOCAL}
algorithm makes it more convenient to describe
\mathsf{LOCAL}
algorithms where there are multiple randomly growing local neighborhoods interfering with each other.

A formal proof of
Proposition

2.1
is given in
Appendix

A
for completeness.

As stated in

Our sampling algorithm follows a natural two-step framework:

.

There is only one node

such that its corresponding bad event

occurs on

.

Next, we will expose the main idea of our sampling algorithm

The rest of this section is organized as follows:

1.

We begin by approaching the sampling problem with modest objectives.

,
while also assuming a

With these assumptions, we present a sampling algorithm. (

)

2.

The correlation decay assumed above may not always hold.
To address this, we introduce an

of the LLL instance, inducing desirable correlation decay by properly augmenting the LLL instance.

)

3.

Finally, we introduce a

The reliance on the idealized assumption

In this section, we formally present the main sampling algorithm in
Theorem

1.3
.
Recall that the input instance is a
\gamma
-satisfiable LLL instance
I=\left(\{X_{i}\}_{i\in U},\{A_{v}\}_{v\in V}\right)
with
n=|V|
bad events.
The network
G=D_{I}
is its dependency graph.
Our goal is to draw a sample according to the LLL distribution
\mu_{I}
.

As discussed in
Section

3
:
the sampling algorithm initially generates a random assignment
\bm{{Y}}
according to the product distribution
\nu
;
and if there are some bad events occurring on
\bm{{Y}}
,
the algorithm then tries to locally fix this prudctly generated
\bm{{Y}}
to follow the the correct joint distribution
\mu_{I}
.

Through a series of expositions in the last section, the aforementioned problem was partially resolved in
Section

3.3
under an idealized assumption (
3.1
),
which posits that there is only one bad event
A_{v}
that may occur on
\bm{{Y}}
drawn from the product distribution
\nu
initially.

To remove the dependency on
3.1
,
the algorithm for the general case additionally clusters the erred bad events into local balls that are suitably far apart from each other.
These erred balls are then fixed one-by-one using
Algorithm

4
presented in the last section,
using the sequential local paradigm (
\mathsf{SLOCAL}\text{-}\mathsf{LV}
) described in
Section

2.4
.
Finally, according to
Proposition

2.1
, this sequential local procedure is converted into a
\mathsf{LOCAL}
algorithm.
Compared to
Section

3
, the new elements introduced in this section, namely clustering and
\mathsf{SLOCAL}
paradigm, are technically more conventional to local computation,
while their inclusion does indeed introduce additional complexity to the presentation of the algorithm.

The algorithm for the general case consists of three phases:
initialization
,
clustering
, and
resampling
.
The first phase runs in the
\mathsf{LOCAL}
model and terminates within fixed
\tilde{O}(\log^{3}n)
rounds.

•

Initialization
: produce a random assignment
\bm{{Y}}=(Y_{i})_{i\in U}
distributed as the product distribution
\nu
,
and a random set
\bm{\mathcal{{R}}}\subseteq V
of clustering centers used by the next phase. (
Section

4.1
)

Then this random
(\bm{{Y}},\bm{\mathcal{{R}}})
is then passed to a
2
-scan
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm that runs on the same network,
where the two scans correspond to the next two phases of the algorithm, respectively.

•

Clustering
: cluster the bad events that occur on
\bm{{Y}}
into sufficiently far apart balls, ensuring that
3.6
(indeed, a slightly stronger condition,
4.4
) is satisfied invariantly. (
Section

4.2
)

•

Resampling
: properly fix the assignments on the balls to make
\bm{{Y}}
follow the correct distribution
\mu_{I}
, which utilizes the
RecursiveSampling
described in
Algorithm

4
as a black box. (
Section

4.3
)

Finally, by
Proposition

2.1
, the
2
-scan
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm can be transformed to a
\mathsf{LOCAL}
algorithm, which altogether with the initialization phase,
gives us the
\mathsf{LOCAL}
algorithm claimed in
Theorem

1.3
.

At last, we wrap up the proof of
Theorem

1.3
in
Section

4.4
.

4.1
The
Initialization
phase

The goal of this phase is to generate a random assignment
\bm{{Y}}=(Y_{i})_{i\in U}
and a random set
\bm{\mathcal{{R}}}\subseteq V
satisfying:

Condition 4.1
.

The followings hold for
\bm{{Y}}=(Y_{i})_{i\in U}
and
\bm{\mathcal{{R}}}\subseteq V
:

1.

\bm{{Y}}
follows the product distribution
\nu
.

2.

For any
v\in V
, if
\bm{{Y}}
does not avoid
A_{v}
,
then
\mathrm{dist}(u,v)\leq{d\cdot\log n\cdot\log\log\log n}
for some
u\in\bm{\mathcal{{R}}}
, where
d
is a large enough universal constant to be specified later.

3.

For any
0<\epsilon<1
, we have
|\bm{\mathcal{{R}}}|=O\left(\log n\cdot\log\log n\cdot\log\frac{1}{\gamma}\cdot\log\frac{1}{\epsilon}\right)
with probability at least
1-\epsilon
.

Intuitively, this asks for generating a random vector
\bm{{Y}}=(Y_{i})_{i\in U}
obeying the marginal distributions
\nu_{i}
,
and a small set
\bm{\mathcal{{R}}}\subseteq V
of “centers”,
such that all bad events that are made occur by
\bm{{Y}}
are not far away from some center.
In the
\mathsf{LOCAL}
model, this can be achieved rather straightforwardly with the help of network decomposition,
which is a major building block for distributed algorithms.

Definition 4.1

(network decomposition)
.

A weak
(c,d)
-network decomposition of
G=(V,E)
is a pair
(\mathcal{S},\mathcal{C})
, where
\mathcal{S}=\{S_{1},S_{2},\ldots\}
is a partition of
V
into vertex subsets, each with diameter at most
d
;
and
\mathcal{C}:\mathcal{S}\to[c]
is a proper coloring of
\mathcal{S}
such that
\mathcal{C}(S_{1})\neq\mathcal{C}(S_{2})
for any
S_{1},S_{2}\in\mathcal{S}
with
\mathrm{dist}_{G}(S_{1},S_{2})=1
.

We adopt the recent bound for deterministic network decomposition from
[
11
]
.

Lemma 4.2

(
[
11
]
)
.

There is a deterministic
\mathsf{LOCAL}
algorithm that, on any network
G
with
n
nodes, computes a weak
(O(\log n),O(\log n\cdot\log\log\log n))
-network decomposition of
G
in
\tilde{O}(\log^{3}n)
rounds.

Note that each node
v\in V
corresponds to a bad event
A_{v}
defined on the variables in
\mathsf{vbl}(v)
,
and one variable may appear in the
\mathsf{vbl}(v)
for multiple
v
’s.
Alternatively, one can assign each variable to a unique node through the following partition:

\forall v\in V,\quad U_{v}\triangleq\{i\in\mathsf{vbl}(v)\mid v\text{ has the smallest ID among all $v^{\prime}\in V$ with }i\in\mathsf{vbl}(v^{\prime})\}.

It is obvious that
\{U_{v}\mid v\in V\}
is a partition of
U
, assuming that
U=\mathsf{vbl}(V)
is the set of variables ever appearing in any bad events.
Also, each node
v\in V
can compute
U_{v}
within one round.

The algorithm for producing the desirable
(\bm{{Y}},\bm{\mathcal{{R}}})
is as follows.
At first, each node
v\in V
locally draws
Y_{i}\sim\nu_{i}
independently for all
i\in U_{v}
.
This gives the random assignment
\bm{{Y}}=(Y_{i})_{i\in U}
, which obviously follows the marginal distributions
\nu_{i}
.
Next, we compute the
\bm{\mathcal{{R}}}\subseteq V
.
First, each node
v\in V
checks if
A_{v}
is avoided by
\bm{{Y}}
, which costs one round since
\mathsf{vbl}(v)\subseteq\bigcup_{w\in N^{+}(v)}U_{w}
.
Then, we construct a weak
(c\cdot\log n,d\cdot\log n\cdot\log\log\log n)
-network decomposition
(\mathcal{S},\mathcal{C})

for some suitable constant
c,d\in\mathbb{N}
,
which according to
Lemma

4.2
, can be done within
\widetilde{O}(\log^{3}n)
rounds.
After that, within each cluster
S\in\mathcal{S}
,
each node
v\in S
checks whether the union bad event
A_{S}\triangleq\bigcup_{v\in S}A_{v}
is avoided by
\bm{{Y}}
,
and marks
v
in
\bm{\mathcal{{R}}}
iff
A_{S}
occurs and
v
has the smallest ID within the cluster
S
.
This guarantees that for any bad event
A_{v}
that occurs on
\bm{{Y}}
, the node
v\in V
must be
d\cdot\log n\cdot\log\log\log n
-close to a node in
\bm{\mathcal{{R}}}
,
and the construction of such
\bm{\mathcal{{R}}}
takes
\widetilde{O}(\log n)
rounds given the network decomposition
(\mathcal{S},\mathcal{C})
, because the diameter of each cluster
S\in\mathcal{S}
is at most
d\cdot\log n\cdot\log\log\log n
.
Together, the following is achieved.

Lemma 4.3
.

The initialization phase outputs
(\bm{{Y}},\bm{\mathcal{{R}}})
satisfying
4.1
within
\tilde{O}(\log^{3}n)
rounds.

It only remains to verify that
|\bm{\mathcal{{R}}}|=O\left(\log n\cdot\log\log n\cdot\log\frac{1}{\gamma}\cdot\log\frac{1}{\epsilon}\right)
with probability at least
1-\epsilon
, which follows from the Chernoff bound.
A formal proof is included in
Section

7.1
for completeness.

4.2
The
Clustering
phase

The random assignment
\bm{{Y}}
and node set
\bm{\mathcal{{R}}}\subseteq V
constructed in the initialization phase, is passed to a
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm,
which runs on the same network
G=D_{I}
and takes
\bm{\mathcal{{R}}}
as the set of active nodes.
The
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm runs in two scans, where the first scan is the
Clustering
phase.

Each node
v\in V
maintains a local memory
M_{v}
, which initially stores its UID
\mathrm{id}(v)
, the private random bits,
the part of the random assignment
(Y_{i})_{i\in U_{v}}
and the indicator of whether
v\in\bm{\mathcal{{R}}}
.
The total order assumed on
V
is a natural one:
u<v
iff
\mathrm{id}(u)<\mathrm{id}(v)
for any
u,v\in V
.

The
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm scans the active nodes
v\in\bm{\mathcal{{R}}}
in order,
and computes two parameters
p_{v}\in V\cup\{\perp\}
and
r_{v}\in\mathbb{N}\cup\{\perp\}
for each
v\in\bm{\mathcal{{R}}}
,
which defines a collection of balls in the network
G

\displaystyle\bm{\mathcal{{B}}}\triangleq\left\{B_{r_{v}}(p_{v})\mid v\in\bm{\mathcal{{R}}}\land p_{v}\neq\perp\land r_{v}\neq\perp\right\}.

(15)

The goal is to construct a collection
\bm{\mathcal{{B}}}
of far-apart and reasonably small balls,
which together with the random assignment
\bm{{Y}}
,
satisfy a clustered version of the augmented conditional Gibbs property.

The following notion of
clustered conditional Gibbs property
is a refined variant of the augmented conditional Gibbs property defined in
Definition

3.3

for

All the above balls

4.3
The
Resampling
phase

The second scan of the
\mathsf{SLOCAL}\text{-}\mathsf{LV}
algorithm comprises the
Resampling
phase.
The algorithm scans the active nodes
v\in\bm{\mathcal{{R}}}
sequentially in the order of their IDs,
and properly resamples part of the random assignment
\bm{{Y}}
generated in the
Initialization
phase,
over the balls in
\bm{\mathcal{{B}}}
constructed in the
Clustering
phase,
to finally obtain the random satisfying assignment distributed correctly as the LLL distribution
\mu_{I}
.

According to
Lemma

3.8
, the task of resampling mentioned above can be resolved by
Algorithm

4
as long as
3.6
is satisfied invariantly during the sequential and local execution of
Algorithm

4
.

To adapt
Algorithm

4
, designed for resampling a single local neighborhood, to the more general scenario where multiple balls need to be fixed one by one,
we introduce the
Substituting
trick.
This abstraction is formally described in the following technical lemma, the proof of which can be found in
Section

8.4
.

Lemma 4.7
.

Let
\epsilon,\gamma\in(0,1)
,
\alpha\in(0,\gamma]
,
\delta\in\left(0,\frac{\gamma}{2}\right)
, and
\ell=\ell_{0}(\epsilon,\gamma,\delta)
which is defined as in (
18
).
Let
I=\left(\{X_{i}\}_{i\in U},\{A_{v}\}_{v\in V}\right)
be a LLL instance.
For any nonempty set
\Lambda\subseteq V
of bad events,
any
\sigma\in\Sigma_{\mathsf{vbl}(\Lambda)}
,
if
I
is
\alpha
-satisfiable and
I(B_{\ell}(\Lambda)\setminus\Lambda)
is
\gamma
-satisfiable,
then we can construct a new random variable
X_{\beta}
(with domain
\Sigma_{\beta}
and distribution
\nu_{\beta}
) with
\beta\notin U
and a new bad event
A_{\kappa}
with
\kappa\notin V
satisfying the followings:

1.

The constructions of
X_{\beta}
and
A_{\kappa}
depend only on the specifications of
\Lambda
,
\sigma
,
(\epsilon,\gamma,\delta)
and
I(B_{\ell+1}(\Lambda))
.
The event
A_{\kappa}
is defined on the random variables in
\mathsf{vbl}(\kappa)=\mathsf{vbl}(B_{\ell+1}(\Lambda))\setminus\mathsf{vbl}(B_{\ell}(\Lambda))\cup\{\beta\}
.

2.

Let
T=U\setminus\mathsf{vbl}(B_{\ell}(\Lambda))
.
For any
W\subseteq T
, any
\omega\in\Sigma_{W}
and
\overline{\omega}\in\Sigma_{\overline{W}}
, where
\overline{W}=T\setminus W
, we have

\mu^{\omega\wedge\sigma}_{\hat{I},\overline{W}}(\overline{\omega})=\mu^{\omega}_{I_{\sigma},\overline{W}}(\overline{\omega}),

where
\hat{I}
stands for the LLL instance defined by
\hat{I}=\left(\{X_{i}\}_{i\in U},\{A_{v}\}_{v\in V}\cup\left\{A^{{I}}_{\bm{\lambda}({\Lambda},{\epsilon,\gamma,\delta})}\right\}\right)
, where
A^{{I}}_{\bm{\lambda}({\Lambda},{\epsilon,\gamma,\delta})}
represents the bad event constructed in

,
and

stands for the LLL instance defined by
I_{\sigma}=\left(\{X_{i}\}_{i\in(U\setminus\mathsf{vbl}(B_{\ell}(\Lambda)))\cup\{\beta\}},\{A_{v}\}_{v\in(V\setminus B_{\ell+1}(\Lambda))\cup\{\kappa\}}\right)
.

3.

The LLL instance
I_{\sigma}
is
(1-\epsilon)\cdot(\alpha-\delta)
-satisfiable.

All balls
B_{\cdot}(\cdot)
above are defined in the dependency graph
D_{I}
of the original LLL instance

.

The core idea behind the above abstraction is to simulate each ball using a single variable.
This allows us to translate the multi-ball invariant
4.4
into
3.6
,
thus enabling us to reuse
Algorithm

4
to tackle the challenge of multi-ball resampling.
It is worth noting that this step is introduced primarily for the convenience of reusing
Algorithm

4
with the current formulation.
However, even without this step, the sampling problem can still be resolved, albeit with a more intricate formulation in
Algorithm

4
.

5
Related Work and Discussions

The perfect simulation of Las Vegas algorithms is a fundamental problem.
In the celebrated work of Luby, Sinclaire, and Zuckerman
[
24
]
, an optimal strategy was given for speeding up Las Vegas algorithms.
Their approach was based on stochastic resetting, which requires global coordination and works for the Las Vegas algorithms with deterministic outputs,
or the interruptible random outputs.

The distribution of satisfying solutions of the Lovász local lemma (LLL) has drawn much attention, e.g. in
[
13
,
15
]
.
Its perfect simulation was studied in
[
13
,
18
,
17
,
6
]
,
where several key approaches for perfect sampling were applied, including partial rejection sampling (PRS)
[
13
]
, “lazy depth-first” method of Anand and Jerrum (
a.k.a.
the AJ algorithm)
[
1
]
, coupling from the past (CFTP)
[
32
]
, and coupling towards the past (CTTP)
[
6
]
.

In the
\mathsf{LOCAL}
model,
Ghaffari, Harris and Kuhn
[
12
]
showed that for distributed graph problems,
where the goal is to construct feasible graph configurations,
the fixed-round Las Vegas algorithms and the zero-error Las Vegas algorithms are equivalent to polylogarithmic rounds.
Their approach was based on a derandomization by conditional expectations,
and hence was especially suitable for the tasks where the support of the output distribution, instead of the output distribution itself, is concerned,
such as the searching problems for constructing feasible solutions.

The
\mathsf{LOCAL}
algorithms and Gibbs distributions are intrinsically related.
For example, the distributions of the random bits on which a fixed-round Las Vegas
\mathsf{LOCAL}
algorithm successfully returns are Gibbs distributions,
where the certifiers of local failures are the local constraints defining the Gibbs distribution.
In
[
10
]
, Feng and Yin gave a
\mathsf{LOCAL}
sampler with local failures for the Gibbs distributions with strong spatial mixing by
parallelizing the JVV sampler
[
20
]
using the network decomposition
[
23
]
.

Discussion of the current result.

In this paper, we show that for local computation,
the successful output of any fixed-round Las Vegas computation, where failures are reported locally,
can be perfectly simulated with polylogarithmic overheads.

As by-products, this gives perfect simulations, via efficient (polylogarithmic-round) local computation,
for several fundamental classes of high-dimensional joint distributions, including:

•

random satisfying solutions of Lovász local lemma with non-negligible satisfiability;

•

uniform locally checkable labelings (LCLs) with non-negligible feasibility;

•

Gibbs distributions satisfying the strong spatial mixing with exponential decay.

We develop a novel approach for augmenting Lovász local lemma (LLL) instances
by introducing locally-defined new bad events, to create the desirable decay of correlation.
We also give a recursive local sampling procedure,
which utilizes the correlation decay to accelerate the sampling process,
and meanwhile still keeps the sampling result correct, without being biased by the change to the LLL instance.

At first glance,
it almost looks like we are creating mixing conditions out of nothing.
In particular, the approach seems to bypass the local-lemma-type conditions for sampling (e.g. the one assumed in
[
18
]
).
But indeed, our augmentation of LLL instances relies on that the LLL instances are fairly satisfiable
(or at least the separator between the regions that we want to de-correlate should be enough satisfiable).
Sampling in such instances might already be tractable in conventional computation models, e.g. in polynomial-time Turing machine,
but the problem remains highly nontrivial for local computation.

This new approach for perfect simulation works especially well in the models where the locality is the sole concern.
A fundamental question is how this could be extended to the models where the computation and/or communication costs are also concerned, e.g.
\mathsf{CONGEST}
model or
\mathsf{PRAM}
model.

\displaystyle\Pr_{\bm{{X}}\sim\nu}(A_{\lambda})

\displaystyle=\Pr_{\bm{{X}}\sim\nu}\left(\left(\bigcap_{v\in V^{{I}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}\right)\cap\left(\bigcup_{1\leq i\leq\ell}A_{\lambda_{i}}\right)\right)

\displaystyle=\sum_{k\geq 1}\Pr_{\bm{{X}}\sim\nu}\left(\left(\bigcap_{v\in V^{{I}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}\right)\cap\left(\forall 1\leq j<k:X_{R^{{J}}_{{i_{j}}}({\Lambda})}\neq\tau^{(j)}\right)\cap\left(X_{R^{{J}}_{{i_{k}}}({\Lambda})}=\tau^{(k)}\right)\right)

\displaystyle=\sum_{k\geq 1}\Pr_{\bm{{X}}\sim\nu}\left(\left(\bigcap_{v\in V^{{I}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}\right)\cap\left(\bigcap_{1\leq i\leq\ell}\overline{A_{\lambda_{i}}^{(k-1)}}\right)\cap\left(X_{R^{{J}}_{{i_{k}}}({\Lambda})}=\tau^{(k)}\right)\right)

Due to the definition of

, we have

\left(\bigcap_{v\in V^{{I}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}\right)\cap\left(\bigcap_{1\leq i\leq\ell}\overline{A_{\lambda_{i}}^{(k-1)}}\right)=\bigcap_{v\in V^{{J^{(k-1)}}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}.

And in

7
, for each iteration

, there exists a

with

such that

•

•

Thus, we have

\displaystyle\Pr_{\bm{{X}}\sim\nu}(A_{\lambda})=

\displaystyle\sum_{k\geq 1}\Pr_{\bm{{X}}\sim\nu}\left(\left(\bigcap_{v\in V^{{J^{(k-1)}}}_{({1},{\ell})}({\Lambda})}\overline{A_{v}}\right)\cap\left(X_{R^{{J}}_{{i_{k}}}({\Lambda})}=\tau^{(k)}\right)\right)

\displaystyle=

We extend the definition of probability

In particular, we observe that

\displaystyle P\left({\sigma},{\Sigma_{R_{{j}}}}\right)=\mathop{\mathbb{E}}_{\tau\sim\nu_{R_{{j}}}}\left[P\left({\sigma},{\tau}\right)\right]=\Pr_{\bm{{X}}\sim\nu}\left(\bm{{X}}\text{ avoids $A_{v}$ for all }v\in V_{[{i+1},{j-1}]}\mid X_{R_{{i}}}=\sigma\right),

and

Definition 6.3
.

Let
1\leq i<j\leq\ell
.
For any
\tau\in\Sigma_{R_{{j}}}
, we say that

is

(j,\tau)

.

And symmetrically, for any
\sigma\in\Sigma_{R_{{i}}}
we say that

is

(i,\sigma)

if
\sigma
avoids
A_{\lambda_{i}}
and for any

,

\frac{P\left({\sigma},{C}\right)}{P\left({\sigma},{\Sigma_{R_{{j}}}}\right)}>\frac{\nu_{R_{{j}}}(C)}{2}
.

The following lemma states the good properties for being well-distributed and holds generally.

Lemma 6.9
.

Let
1<i<j\leq\ell
. For any
\tau\in\Sigma_{R_{{j}}}
, if
R_{{i}}
is well-distributed based on
(j,\tau)

R_{{i}}
is a good ring, then the followings hold:

1.

R_{{i-1}}
is well-distributed based on
(j,\tau)

2.

for any

P\left({\sigma},{\tau}\right)\leq 3\nu_{R_{{i-1}}}(\sigma)\cdot P\left({\Sigma_{R_{{i-1}}}},{\tau}\right)
;

3.

\nu_{R_{{i}}}(S)\geq\frac{3}{4}
for

.

And the symmetric holds for the good ring
R_{{j}}
that is well-distributed based on
(i,\sigma)
for any

:

1.

R_{{j+1}}
is well-distributed based on
(i,\sigma)
;

2.

for any
\tau\in\Sigma_{R_{{j+1}}}

P\left({\sigma},{\tau}\right)\leq 3\nu_{R_{{j+1}}}(\tau)\cdot P\left({\sigma},{\Sigma_{R_{{j+1}}}}\right)

\nu_{R_{{j}}}(S)\geq\frac{3}{4}

Proof.

We prove these properties one by one.

1.

Note that for any
v\in V_{[{i},{i}]}\setminus V_{[{i+1},{i+1}]}

\mathsf{vbl}(v)\subseteq R_{{i-1}}\cup R_{{i}}
.
For any
\sigma\in\Sigma_{R_{{i-1}}}
, define

For any
C\subseteq\Sigma_{R_{{i-1}}}
with
\nu_{R_{{i-1}}}(C)>\frac{1}{4}
, we define
C^{\prime}\triangleq\{\sigma\in C\mid\nu_{R_{{i}}}(K_{\sigma})>1-\frac{1}{9}\}
.
Then, for any
\sigma^{\prime}\in C\setminus C^{\prime}
, and
\bm{{X}}
drawn from product distribution
{\nu}
, we have

\Pr\left(\text{$\bm{{X}}$ avoids all bad events $A_{v}$ for $v\in V_{[{i},{i}]}\setminus V_{[{i+1},{i+1}]}$}\mid X_{R_{{i-1}}}=\sigma^{\prime}\right)\leq\frac{8}{9}.

Since
R_{{i}}
is a good ring,
\bigcup_{v\in V_{[{i},{i}]}\setminus V_{[{i+1},{i+1}]}}A_{v}
occurs with probability at most
\varepsilon_{0}
.
We have
\nu_{R_{{i-1}}}(C\setminus C^{\prime})\leq 9\varepsilon_{0}
, which means
\nu_{R_{{i-1}}}(C^{\prime})\geq\nu_{R_{{i-1}}}(C)-9\varepsilon_{0}
.
Since
R_{{i}}
is well-distributed based on
(j,\tau)
, for any
\sigma\in\Sigma_{R_{{i-1}}}
with
\nu_{R_{{i}}}(K_{\sigma})\geq\frac{8}{9}
, we have

P\left({K_{\sigma}},{\tau}\right)=\frac{P\left({K_{\sigma}},{\tau}\right)}{P\left({\Sigma_{R_{{i}}}},{\tau}\right)}\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right)>\frac{\nu_{R_{{i}}}(K_{\sigma})}{2}\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right)\geq\frac{4}{9}\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right).

Thus, for any
C\subseteq\Sigma_{R_{{i-1}}}
with
\nu_{R_{{i-1}}}(C)>\frac{1}{4}
, we have

P\left({C},{\tau}\right)\geq\sum_{\sigma\in C^{\prime}}\nu_{R_{{i-1}}}(\sigma)P\left({K_{\sigma}},{\tau}\right)>\frac{4}{9}\left(\nu_{R_{{i-1}}}(S)-9\varepsilon_{0}\right)P\left({\Sigma_{R_{{i}}}},{\tau}\right).

P\left({\Sigma_{R_{i-1}}\setminus C},{\tau}\right)\leq(1-\nu_{R_{{i-1}}}(C))\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right)=(1-\nu_{R_{{i-1}}}(C))\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right)

\frac{P\left({C},{\tau}\right)}{P\left({\Sigma_{R_{{i-1}}}\setminus C},{\tau}\right)}>\frac{4}{9}\cdot\frac{\nu_{R_{{i-1}}}(C)-9\varepsilon_{0}}{1-\nu_{R_{{i-1}}}(C)}\geq\frac{\nu_{R_{{i-1}}}(C)/2}{1-\nu_{R_{{i-1}}}(C)/2}.

and sufficiently small
\varepsilon_{0}
. Thus, we obtain that

\frac{P\left({C},{\tau}\right)}{P\left({*},{\tau}\right)}=\frac{P\left({C},{\tau}\right)}{P\left({\Sigma_{R_{{i-1}}}\setminus C},{\tau}\right)+P\left({C},{\tau}\right)}>\frac{\nu_{R_{{i-1}}}(C)}{2}.

2.

We define
C^{\prime\prime}\triangleq\{\sigma\in\Sigma_{R_{{i-1}}}\mid\nu_{R_{{i}}}(K_{\sigma})\geq 1-\frac{1}{4}\}
.
By the same argument as before, we have

Since
P\left({\sigma},{\tau}\right)\leq\nu_{R_{{i-1}}}(\sigma)\cdot P\left({\Sigma_{R_{{i}}}},{\tau}\right)
for any
\sigma\in\Sigma_{R_{{i-1}}}
. For sufficient small

3.

Sort

is well-distributed based on
(j,\tau)
.
Therefore, we have
\{\sigma_{k},\sigma_{k+1},...,\sigma_{|\Sigma_{R_{{i}}}|}\}\subseteq S
and

\nu_{R_{{i}}}(S)\geq\nu_{R_{{i}}}(\{\sigma_{k},\sigma_{k+1},...,\sigma_{|\Sigma_{R_{{i}}}|}\})\geq\frac{3}{4}.

The symmetric case that
R_{{j}}
is well-distributed based on
(i,\sigma)
follows by symmetry.
