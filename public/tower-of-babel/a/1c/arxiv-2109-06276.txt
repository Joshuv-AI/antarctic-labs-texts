The generalized Ermakov conservative system: A discussion
Antonios Mitsopoulos, Michael Tsamparlis

Abstract
Using older and recent results on the integrability of two-dimensional (2d) dynamical systems, we prove that the results obtained in a recent publication concerning the 2d generalized Ermakov system can be obtained as special cases of a more general approach. This approach is geometric and can be used to study efficiently similar dynamical systems.

2
The 2d generalized Ermakov system

The 2d generalized Ermakov system is defined by the equations

\displaystyle\ddot{x}

\displaystyle=

\displaystyle-\omega^{2}(t)x+\frac{1}{x^{2}y}f\left(\frac{y}{x}\right)

(1)

\displaystyle\ddot{y}

\displaystyle=

\displaystyle-\omega^{2}(t)y+\frac{1}{xy^{2}}g\left(\frac{x}{y}\right)

(2)

where
f,g
are arbitrary functions. This system admits the Ermakov first
integral (FI)

I_{0}=\frac{1}{2}(x\dot{y}-y\dot{x})^{2}+\int^{y/x}f(u)du+\int^{x/y}g(v)dv

(3)

where
u=v^{-1}=\frac{y}{x}
. It is well-known that the 2d generalized Ermakov system generalizes the one-dimensional (1d)
time-dependent oscillator.

Introducing the functions
F,G
by the relations

f\left(\frac{y}{x}\right)=\frac{y}{x}F\left(\frac{y}{x}\right),\enskip g\left(\frac{x}{y}\right)=\frac{x}{y}G\left(\frac{y}{x}\right)

equations (
1
), (
2
) take the
equivalent form

\displaystyle\ddot{x}

\displaystyle=

\displaystyle-\omega^{2}(t)x+\frac{1}{x^{3}}F\left(\frac{y}{x}\right)

(4)

\displaystyle\ddot{y}

\displaystyle=

\displaystyle-\omega^{2}(t)y+\frac{1}{y^{3}}G\left(\frac{y}{x}\right)

(5)

while the Ermakov FI (
3
) becomes

I_{0}=\frac{1}{2}(x\dot{y}-y\dot{x})^{2}+\int^{y/x}\left[uF(u)-u^{-3}G(u)\right]du.

(6)

If one introduces the variables
[
4
]

T=\int\rho^{-2}dt,\enskip X=\rho^{-1}x,\enskip Y=\rho^{-1}y

(7)

where
\rho(t)
is a solution of the 1d time-dependent oscillator

\ddot{\rho}+\omega^{2}(t)\rho=0

(8)

then equations (
4
), (
5
) become
the autonomous system

\displaystyle X^{\prime\prime}

\displaystyle=

\displaystyle\frac{1}{X^{3}}F\left(\frac{Y}{X}\right)

(9)

\displaystyle Y^{\prime\prime}

\displaystyle=

\displaystyle\frac{1}{Y^{3}}G\left(\frac{Y}{X}\right)

(10)

and the Ermakov FI

I_{0}=\frac{1}{2}\left(XY^{\prime}-YX^{\prime}\right)^{2}+\int^{Y/X}\left[uF(u)-u^{-3}G(u)\right]du

(11)

where we use the notation
f^{\prime}\equiv\frac{df(T)}{dT}
and
\dot{f}\equiv\frac{df(t)}{dt}
. For general functions
F,G
the autonomous dynamical system (
9
) - (
10
) is not conservative. In the following we determine the
family of conservative Ermakov systems together with their FIs using collineations of the metric defined by these equations.

Integrability of the 2d generalized Ermakov system

Since the system (

If we consider

\displaystyle X^{\prime\prime}

\displaystyle=

\displaystyle\frac{2N+u\frac{dN}{du}}{X^{3}}

(14)

\displaystyle Y^{\prime\prime}

\displaystyle=

\displaystyle-\frac{1}{X^{3}}\frac{dN}{du}.

(15)

Therefore, if we define the functions

then equations (

We conclude that the family of the conservative 2d Ermakov systems is
defined by the potential

where
N(u)
is an arbitrary
function while the Hamiltonian is given by the expression

H=\frac{1}{2}\left(X^{\prime 2}+Y^{\prime 2}\right)+\frac{N(u)}{X^{2}}.

(17)

In the original coordinates the system (
14
) - (
15
) becomes

\displaystyle\ddot{x}

\displaystyle=

\displaystyle-\omega^{2}(t)x+\frac{2N(u)+u\frac{dN}{du}}{x^{3}}

(18)

\displaystyle\ddot{y}

\displaystyle=

\displaystyle-\omega^{2}(t)y-\frac{1}{x^{3}}\frac{dN}{du}

(19)

For

\displaystyle\ddot{x}

\displaystyle=

\displaystyle-\omega^{2}(t)x

(20)

\displaystyle\ddot{y}

\displaystyle=

\displaystyle-\omega^{2}(t)y+\frac{1}{y^{3}}

(21)

while the Ermakov FI becomes the well-known Lewis invariant

(22)

Equation (

The FIs of the conservative Ermakov system

There are two ways to find the FIs of the Ermakov system. One way is to use the
results of
[
9
]
,
[

[

where it is stated that the generators of the
Noether point symmetries of autonomous conservative systems are the elements
of the homothetic algebra of the metric defined by the kinetic energy
(kinetic metric). In the Ermakov case, this metric is the Euclidean 2d metric
\gamma_{ab}=diag(1,1)

For the convenience of the reader we state Theorem 2 of
[

Theorem 1

Autonomous conservative
dynamical systems of the form

\ddot{q}^{a}=-\Gamma^{a}_{bc}\dot{q}^{b}\dot{q}^{c}-V^{,a}(q)

(23)

where
\Gamma_{bc}^{a}
are the Riemannian connection coefficients
determined from the kinetic metric
\gamma_{ab}
(kinetic energy) and
V(q)

the potential of the system, admit the following point Noether symmetries.

Case 1. The point Noether symmetry

\mathbf{A}_{1}=\partial_{t},\enskip f_{1}=const\equiv 0

(24)

which produces the Noether FI (Hamiltonian)

H=\frac{1}{2}\gamma_{ab}\dot{q}^{a}\dot{q}^{b}+V(q).

(25)

Case 2. The point Noether symmetry

\mathbf{A}_{2}=2\psi_{B}t\partial_{t}+B^{a}\partial_{q^{a}},\enskip f_{2}=c_{1}t

(26)

where
c_{1}
is an arbitrary constant and
B^{a}
is a KV (
\psi_{B}=0
) or
the HV (
\psi_{B}=1
) such that

B_{a}V^{,a}+2\psi_{B}V+c_{1}=0.

(27)

The associated Noether FI is

I_{2}=2\psi_{B}tH-B_{a}\dot{q}^{a}+c_{1}t.

(28)

Case 3. The point Noether symmetry

\mathbf{A}_{3}=2\psi\int C(t)dt\partial_{t}+C(t)\Phi^{,a}\partial_{q^{a}},\enskip f_{3}=C_{,t}\Phi(q)+D(t)

(29)

where
\Phi^{,a}(q)
is a gradient KV (
\psi=0
) or a gradient HV (
\psi=1
)
such that (

are arbitrary constants)

\Phi_{,a}V^{,a}+2\psi V=c_{2}\Phi+c_{3}

(30)

and the functions

are determined by the relations (
C_{,t}\neq 0

C_{,tt}=-c_{2}C,\enskip D_{,t}=-c_{3}C.

(31)

The associated Noether FI is

I_{3}=2\psi H\int C(t)dt-C(t)\Phi_{,a}\dot{q}^{a}+C_{,t}\Phi-c_{3}\int C(t)dt.

5
Conclusions

Using recent results on the integrability of 2d conservative dynamical systems, we proved that the generalized Ermakov system is superintegrable and determined all the quadratic FIs. We showed that the recent results of
[
8
]
can be obtained from the more general method outlined in
[
10
]
and
[
12
]
. Obviously, the methods discussed in the present work can be used by other authors in the study of similar dynamical systems. As a final remark, we note that an extension of this method, where one computes the time-dependent and autonomous quadratic FIs without the use of Noether symmetries, has appeared recently in
[
13
]
.
