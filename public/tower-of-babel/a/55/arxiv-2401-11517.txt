Computation of the Schläfli function
Andrey A. Shoom

Abstract
In this work a method for numerical computation of the Schläfli function f n ​ ( x ) f_{n}(x) , for x ∈ [ n − 1 , n + 1 ] x\in[n-1,n+1] and n ≥ 4 n\geq 4 is presented. The computation is based on the Chebyshev approximation of the function q n ​ ( x ) q_{n}(x) , which is related to the Schläfli function and regular in the interval.

Properties of the Schläfli function

To make this paper self-consistent, this Section is to present some properties of the Schläfli function
f_{n}(x)
. This function can be derived recursively from the remarkable relation discovered by Schläfli
[
19
]
,
4
4

4

This relation is a particular case of the relation derived by Schläfli for an arbitrary (not regular)
(n-1)
-dimensional spherical simplex.

f^{\prime}_{n}(x)=f_{n-2}(x-2)f^{\prime}_{2}(x)\,,

(10)

where the prime stands for the derivative with respect to
x
and according to (
4
),

f^{\prime}_{2}(x)=\frac{1}{\pi|x|\sqrt{x^{2}-1}}\,,\hskip 14.22636pt|x|\geq 1\,.

(11)

According to (
4

n=2
the recurrence relation (
10

it should be an equality. Thus, it is defined

f_{0}(x)\equiv 1\,,\hskip 14.22636ptf_{1}(x)\equiv 1\,.

(12)

By a geometric consideration one can find that the function
f_{n}(x)
takes the following values (for details see
[
1
]
):

f_{n}(-2)=\frac{2^{n}}{(n+1)!}\,,\hskip 14.22636ptf_{n}(-1)=\frac{2^{n-1}}{n!}\,,\hskip 14.22636ptf_{n}(n-1)=0\,,

(13)

corresponding to the dihedral angles
2\pi/3
,
\pi

\text{arcsec}(n-1)
, respectively, and the limiting value

\lim_{x\to\pm\infty}f_{n}(x)=\frac{1}{n!}\,,

(14)

corresponding to the dihedral angle
2\alpha=\pi/2
.

Integrating the recurrence relation (
10
) and using (
11
), (
13
), and (
14
) we derive

f_{n}(x)=\frac{1}{\pi}\int^{x}_{n-1}\frac{f_{n-2}(z-2)}{z\sqrt{z^{2}-1}}dz=f_{n}(n)+\frac{1}{\pi}\int^{x}_{n}\frac{f_{n-2}(z-2)}{z\sqrt{z^{2}-1}}dz\,,

(15)

where
x\in[n-1,+\infty)
, and

f_{n}(x)=\frac{2^{n-1}}{n!}-\frac{1}{\pi}\int^{-1}_{x}\frac{f_{n-2}(z-2)}{|z|\sqrt{z^{2}-1}}dz=\frac{1}{n!}+\frac{1}{\pi}\int^{x}_{-\infty}\frac{f_{n-2}(z-2)}{|z|\sqrt{z^{2}-1}}dz\,,

(16)

where
x\in(-\infty,-1]

Functions

with odd

n

f_{n}(x)=f_{n-1}(x)-\tfrac{1}{3}f_{n-3}(x)+\tfrac{2}{15}f_{n-5}(x)-\tfrac{17}{315}f_{n-7}(x)+\cdots

(17)

and values

with even
n

f_{n}(n)=\tfrac{1}{3}f_{n-2}(n)-\tfrac{2}{15}f_{n-4}(n)+\tfrac{17}{315}f_{n-6}(n)-\tfrac{62}{2835}f_{n-8}(n)+\cdots

The coefficients in the expansion (

Computation of
f_{n}(x)
via the expressions (
15
) and (
16

f_{n}(x)
for arbitrary values of
n
with a required accuracy.

3
Evaluation of
f_{n}(x)
in the interval
x\in[n-1,n+1]

Often in the literature it is required to compute the Schläfli function only at certain points. For instance, to compute the Rogers bound (

We begin with a brief review of relevant properties of

4

If function

f(z)=\sum_{k=-\infty}^{+\infty}c_{k}(z-a)^{k/p}\,,

where the series converges in

We apply this theorem first to the function

(19)

We define the function

3

|a^{(n)}_{N}|\sim\frac{n|a^{(n-2)}_{N}|}{2N+n-3}\sim|a^{(n-2)}_{N}|\sim|a^{(p)}_{N}|\sim\epsilon\,.

(44)

Thus, one can achieve a required accuracy by means of high-precision numerical computations.
