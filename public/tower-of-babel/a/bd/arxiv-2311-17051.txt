Long time asymptotic series for the Painlevé II equation: Riemann–Hilbert approach
N Iorgov, Yu Zhuravlev

Abstract
We elaborate a systematic way to obtain higher order contributions in the nonlinear steepest descent method for Riemann–Hilbert problem associated with homogeneous Painlevé II equation. The problem is reformulated as a matrix factorization problem on two circles and can be solved perturbatively reducing it to finite systems of algebraic linear equations. The method is applied to find explicitly long-time asymptotic behaviour for tau function of Painlevé II equation.

2
Painlevé II equation and related linear problem

2.1
Painlevé II equation and its Hamiltonian formulation

In this paper we will study the homogeneous Painlevé II equation defined by

\frac{d^{2}q}{dt^{2}}=2q^{3}+tq.

(1)

It is the equation of motion of a Hamiltonain system with the time dependent Hamiltonian

H(p,q,t)=\frac{p^{2}}{4}-q^{4}-tq^{2}.

(2)

In what follows we will use expression for the Hamiltonian on trajectories

H(t)=q_{t}^{2}-q^{4}-tq^{2}.

(3)

The central object of our study is the isomonodromic tau function
\tau(t)
defined by

\partial_{t}\log\tau(t)=H(t).

(4)

2.2
Isomonodromic reformulation of Painlevé II equation

There is another way to obtain the Painlevé II equation. Consider the following system of differential equations, called the linear problem

\partial_{z}\Phi=A(z)\Phi,\qquad\partial_{t}\Phi=B(z)\Phi,

(5)

with
2\times 2
traceless matrices
A(z)
and
B(z)
defined by

A(z)=\begin{pmatrix}-4iz^{2}-it-2iq^{2}&4izq-2q_{t}\\
-4izq-2q_{t}&4iz^{2}+it+2iq^{2}\end{pmatrix},\quad B(z)=\begin{pmatrix}-iz&iq\\
-iq&iz\end{pmatrix}.

(6)

Imposing zero curvature condition we get the Painlevé II equation

\partial_{t}A-\partial_{z}B+[A,B]=-2\left(\frac{d^{2}q}{dt^{2}}-2q^{3}-tq\right)\sigma_{1}=0,

(7)

where we use standard Pauli matrices

\sigma_{1}=\begin{pmatrix}0&1\\
1&0\end{pmatrix},\quad\sigma_{2}=\begin{pmatrix}0&-i\\
i&0\end{pmatrix},\quad\sigma_{3}=\begin{pmatrix}1&0\\
0&-1\end{pmatrix}.

(8)

The linear problem (
5
) has irregular singular point at
z=\infty
and can be solved formally for large
z
using the following anzats

\Phi(z)=\Psi(z)e^{\Theta(z)},\quad\Theta(z)=-i\left(\frac{4z^{3}}{3}+tz\right)\sigma_{3},

(9)

with formal matrix series

\Psi(z)=I+\sum_{k=1}^{\infty}g_{k}z^{-k}.

(10)

The form of the exponent
\Theta(z)
follows from the approximation of the integral

\int^{z}dz\sqrt{\frac{1}{2}\Tr A(z)^{2}}\,\sigma_{3}=\Theta(z)+O\left(z^{-1}\right),

(11)

where we used the fact that
z
is a large parameter and

\frac{1}{2}\Tr A(z)^{2}=-16z^{4}-8tz^{2}-t^{2}+4H(t).

(12)

The coefficients
g_{k}
of the expansion (
10
) can be found from the linear problem (
5
) recursively. We present here first two of them

g_{1}=\frac{q}{2}\sigma_{1}-\frac{iH}{2}\sigma_{3},\quad g_{2}=\frac{1}{8}(q^{2}-H^{2})I-\frac{1}{4}(q_{t}+qH)\sigma_{2}.

(13)

The matrix structure of these coefficients can be guessed even from the symmetry of the problem

A(-z)=-\sigma_{2}A(z)\sigma_{2},\quad\Theta(-z)=\sigma_{2}\Theta(z)\sigma_{2}

(14)

without direct computations.
These two symmetry relations imply that the formal matrix series
\Psi(z)
given by (
10
) should satisfy
Z_{2}
-symmetry termwise

\Psi(-z)=\sigma_{2}\Psi(z)\sigma_{2}.

(15)

2.3
Jimbo–Miwa–Ueno tau function and its large time (
t\to-\infty
) asymptotics

The formal asymptotic series (
9
) can be used to define Jimbo–Miwa–Ueno (JMU) tau function by the following integral

\partial_{t}\log\tau_{\mathrm{JMU}}(t)=\oint_{C}\frac{dz}{2\pi i}\mathrm{Tr}\,\Psi(z)^{-1}\partial_{z}\Psi(z)\partial_{t}\Theta(z)=H(t),

(16)

where the contour
C
is a counterclockwise oriented circle of large radius. We see that the tau function defined in (
4
) coincides with JMU tau function.
There is a conjecture
[
11
,
12
]
about asymptotic behaviour of tau function (
16
) for large negative
t

\tau(t)=\sum_{n=-\infty}^{\infty}e^{in\rho}Z(\nu+n,t),

(17)

where the function
Z(\nu,t)
is defined by

Z(\nu,t)=C(\nu)e^{i\nu s}s^{-\nu^{2}}\left(1+\sum_{k=1}^{\infty}\frac{B_{k}(\nu)}{s^{k}}\right),\quad s=\frac{4}{3}(-t)^{\frac{3}{2}},

(18)

with the coefficient
C(\nu)
independent of
t

C(\nu)=6^{-\nu^{2}}e^{\frac{i\pi\nu^{2}}{2}}G(1+\nu)^{2},

(19)

where
G(x)
is the Barnes
G
-function.
The coefficients
B_{k}(\nu)
are polynomials in
\nu

B_{1}(\nu)=-\frac{i\nu(34\nu^{2}+1)}{18},\quad B_{2}(\nu)=-\frac{\nu^{2}(1156\nu^{4}+2318\nu^{2}+271)}{648},\quad\ldots

(20)

There are two parameters
\nu
and
\rho
in this formula related to the monodromy data of the problem (
5
) which will be described in the next section, see (
26
) and (
27
).

3
Reformulation as a Riemann–Hilbert problem

3.1
Stokes graph, canonical solutions in Stokes sectors, Stokes matrices

The linear problem (
5
) can be reformulated as a Riemann–Hilbert (RH) problem
[
10
]
.
Solutions
\Phi(z)
of (
5
)
exhibit Stokes phenomenon near irregular singular point
z=\infty
. To describe the phenomenon we plot Stokes graph which follows from the leading term of
\Theta(z)
, namely, the Stokes rays (see Figure
1
) are fixed by the relation

\mathrm{Im}\left(-iz^{3}\right)=0\qquad\Rightarrow\qquad\mathrm{Arg}\,z=-\frac{\pi}{6}+\frac{\pi k}{3},\quad k\in\mathbb{Z}.

(21)

Figure 1:
Stokes graph for the original RH problem (centered at
z=0
)

It is known that in each Stokes sector
\Omega_{k}
, enclosed by Stokes rays, there is unique solution, so called canonical solution,
\Phi_{k}(z)

of (
5
) having asymptotic behavior (
9
) as
z\to\infty
and
z\in\Omega_{k}
.
Any two solutions of the linear problem (
5
) are related by right multiplication on a constant non-degenerate matrix.
In particular, the canonical solution
\Phi_{k}(z)
, analytically continued to the neighbor Stokes sector
\Omega_{k+1}
, is related to

\Phi_{k+1}(z)
by a Stokes matrix
S_{k}
:

\Phi_{k+1}(z)=\Phi_{k}(z)S_{k},

(22)

where
S_{k}
are Stokes matrices having the following form

S_{2j+1}=\begin{pmatrix}1&0\\
s_{2j+1}&1\end{pmatrix},\qquad S_{2j}=\begin{pmatrix}1&s_{2j}\\
0&1\end{pmatrix}.

(23)

The symmetry relation (
14
) implies that

S_{k+3}=\sigma_{2}S_{k}\sigma_{2}\qquad\Rightarrow\qquad s_{k+3}=-s_{k}.

(24)

Since
A(z)
has no singularity at
z=0
, we obtain that analytically continued solution
\Phi(z)
of (
5
) has no monodromy around
z=0
(and
z=\infty
):

\Phi(e^{2\pi i}z)=\Phi(z)
. Adding the fact that the exponent
\Theta(z)
does not have a formal monodromy (i.e.
\Theta(z)
is a single-valued function near
z=\infty
),
we obtain the cyclic relation on Stokes matrices

S_{1}S_{2}S_{3}S_{4}S_{5}S_{6}=1\qquad\Rightarrow\qquad s_{1}-s_{2}+s_{3}+s_{1}s_{2}s_{3}=0.

(25)

This shows that there are only two independent Stokes parameters. It is convenient to define parameter
\nu
by

e^{2\pi i\nu}=1-s_{1}s_{3},\qquad|\mathrm{Re}\,\nu|<\frac{1}{2},

(26)

and parameter
\rho

e^{i\rho}=\frac{s_{3}^{2}}{2\pi(1-s_{1}s_{3})}.

(27)

The monodromy parameters
\nu
and
\rho
enter the asymptotic expansion of tau function (
17
).
Instead of
\rho
we will also use
Q
defined by

e^{i\rho}=\frac{Q^{2}e^{-4i\pi\nu}}{\Gamma^{2}(\nu)}.

(28)

In order to formulate a RH problem associated with (
5
) we use matrix functions

\Psi_{k}(z)=\Phi_{k}(z)e^{-\Theta(z)},\qquad z\in\bar{\Omega}_{k},\quad k=1,2,\ldots,6,

(29)

which are related by the jump matrices
G_{k}(z)
on the Stokes rays:

\Psi_{k+1}(z)=\Psi_{k}(z)G_{k}(z),\qquad G_{k}(z)=e^{\Theta(z)}S_{k}e^{-\Theta(z)},\qquad z\in\ell_{k}.

(30)

Let us introduce
piecewise
holomorphic matrix function
\Psi(z)
defined by

\Psi(z)=\Psi_{k}(z),\qquad z\in\Omega_{k},\quad k=1,2,\ldots,6.

(31)

Then
\Psi(z)
solves RH problem on the Riemann sphere with RH graph coinciding with Stokes graph and with jump on the graph given by

\Psi_{+}(z)=\Psi_{-}(z)G_{k}(z),\qquad z\in\ell_{k},

(32)

where
\Psi_{+}(z)
(resp.
\Psi_{-}(z)
) are limiting boundary value of
\Psi(z)
on RH graph from left (resp. right) with respect to the direction of
graph edge
\ell_{k}
.
Finally, the associated RH problem is given by the jump condition (
32
), which, together with the normalization condition

\Psi(z)=I+O(z^{-1}),\qquad z\to\infty,

(33)

fixes the solution uniquely.

Note,
G_{k}(z)\to I
exponentially fast as
z\to\infty
along
z\in\ell_{k}
. This observation will play an important role in the nonlinear steepest descent method
for large time asymptotic analysis. In the next subsection we reformulate RH problem by deforming RH graph in order to apply the method.

3.2
Transformation of Stokes graph for nonlinear steepest descent method

The main idea of the nonlinear steepest descent method
[
9
]
is to solve RH problem near critical points and then try to glue all parts. Thus we need to find these critical points. To do this we make rescaling of variables

z=(-t)^{1/2}\lambda,\qquad x=(-t)^{3/2},

(34)

then the exponent
\Theta
becomes

\Theta(z,t)=-i\left(\frac{4z^{3}}{3}+tz\right)\sigma_{3}=x\theta(\lambda)\sigma_{3},\qquad\theta(\lambda)=-i\left(\frac{4\lambda^{3}}{3}-\lambda\right).

(35)

The critical points are defined by
\theta^{\prime}(\lambda)=0
giving
\lambda_{\pm}=\pm 1/2
.

Figure 2:
Deformation of the original RH problem.

On the next step we deform the Stokes graph, see Figure
2
. The first deformation allows to go from
\Omega_{3}
to
\Omega_{6}
with jump on the bridge
(S_{3}S_{4}S_{5})^{-1}
. The second deformation based on the observation that jump matrix on the bridge can be LDU-decomposed

(S_{3}S_{4}S_{5})^{-1}=\begin{pmatrix}1-s_{1}s_{3}&s_{1}\\
s_{1}&1+s_{1}s_{2}\end{pmatrix}=S_{L}S_{D}S_{U},

(36)

where we used

S_{L}=\begin{pmatrix}1&0\\
\frac{s_{1}}{1-s_{1}s_{3}}&1\end{pmatrix},\quad S_{D}=\begin{pmatrix}1-s_{1}s_{3}&0\\
0&(1-s_{1}s_{3})^{-1}\end{pmatrix},\quad S_{U}=\begin{pmatrix}1&\frac{s_{1}}{1-s_{1}s_{3}}\\
0&1\end{pmatrix}.

(37)

New Stokes matrices
S_{U}
,
S_{2}(S_{U})^{-1}
,
S_{L}^{-1}
, and
S_{5}S_{L}
are related by
Z_{2}
-symmetry (
24
)

S_{U}=\sigma_{2}S_{L}^{-1}\sigma_{2}=\begin{pmatrix}1&\frac{s_{1}}{1-s_{1}s_{3}}\\
0&1\end{pmatrix},\quad S_{2}(S_{U})^{-1}=\sigma_{2}S_{5}S_{L}\sigma_{2}=\begin{pmatrix}1&\frac{s_{3}}{1-s_{1}s_{3}}\\
0&1\end{pmatrix}.

(38)

3.3
External local parametrix

Before we find local solutions near the critical points we build an external parametrix, which is defined as a solution to the RH problem with only one jump
S_{D}
on the interval
(\lambda_{-},\lambda_{+})
, which we will call
bridge
. It will help us to glue local solutions.
The jump matrix
S_{D}
on the bridge can be written as

S_{D}=e^{2\pi i\nu\sigma_{3}},

(39)

where
\nu
is defined in (
26
).
A solution of this auxiliary RH problem is

Y_{D}(\lambda)=\left(\frac{\lambda-\lambda_{+}}{\lambda-\lambda_{-}}\right)^{\nu\sigma_{3}}.

(40)

It is normalized, i.e.
Y_{D}(\lambda)\to I
as
\lambda\to\infty
.

3.4
Local parametrices near saddle points

In this subsection we will build local solutions of the RH problem in disks
D_{\pm}
of fixed radius
0<r_{0}<1/2
centered at critical points
\lambda_{\pm}
.
We start from the building conformal maps of these disks to the complex plane straightening the Stokes graph restricted to these disks.
They will be given in terms of the functions
w_{\pm}(\lambda)
defined by

w_{\pm}^{2}(\lambda)=\frac{\theta(\lambda)-\theta(\lambda_{\pm})}{\frac{1}{2}\theta^{\prime\prime}(\lambda_{\pm})}.

(41)

The functions
w_{\pm}(\lambda)
near
\lambda_{\pm}
, respectively, have the following leading expansion terms

w_{\pm}(\lambda)=(\lambda-\lambda_{\pm})+O((\lambda-\lambda_{\pm})^{2}).

(42)

The conformal map of disk
D_{r}
is given by

\zeta(\lambda)=c_{+}x^{\frac{1}{2}}w_{+}(\lambda),\qquad c_{+}=\sqrt{2\theta^{\prime\prime}(\lambda_{+})}=\sqrt{8}e^{3\pi i/4},

(43)

where the multiplier
c_{+}
is chosen to have

\frac{\zeta^{2}(\lambda)}{4}=x\left(\theta(\lambda)-\theta(\lambda_{+})\right).

(44)

Similarly, the conformal map of disk
D_{l}
is given by
\xi(\lambda)=\zeta(-\lambda)
:

\xi(\lambda)=c_{-}x^{1/2}w_{-}(\lambda),\qquad c_{-}=\sqrt{-2\theta^{\prime\prime}(\lambda_{-})}=\sqrt{8}e^{-i\pi/4}.

(45)

The function
\xi(\lambda)
satisfies

\frac{\xi^{2}(\lambda)}{4}=-x(\theta(\lambda)-\theta(\lambda_{-})).

(46)

To build local solution of the RH problem in
D_{\pm}
we consider a model RH problem associated with a linear problem for Weber–Hermite functions

\partial_{\zeta}Y_{\rm WH}(\zeta)=A_{\rm WH}(\zeta)Y_{\rm WH}(\zeta),\qquad A_{\rm WH}(\zeta)=\begin{pmatrix}\zeta/2&\nu\\
1&-\zeta/2\end{pmatrix}.

(47)

Asymptotic behavior of its solutions near the irregular singular point
\zeta=\infty
is given by

Y_{\rm WH}(\zeta)\simeq G_{0}(\zeta)e^{\Theta_{\mathrm{WH}}(\zeta)},\qquad\Theta_{\mathrm{WH}}(\zeta)=\left(\frac{\zeta^{2}}{4}+\nu\log\zeta\right)\sigma_{3},

(48)

up to a constant matrix multiplier from the right.
The formal series
G_{0}(\zeta)
has the form

G_{0}(\zeta)=I+\sum_{j=1}^{\infty}\frac{\rho_{j}}{\zeta^{j}}

(49)

with the matrices
\rho_{j}
defined by

\rho_{2k+1}=\frac{1}{2^{k}k!}\begin{pmatrix}0&(-1)^{k-1}(\nu)_{2k+1}\\
(1-\nu)_{2k}&0\end{pmatrix},

(50)

\rho_{2k}=\frac{1}{2^{k}k!}\begin{pmatrix}(-\nu)_{2k}&0\\
0&(-1)^{k}(\nu)_{2k}\end{pmatrix},

(51)

where
(x)_{j}
is the Pochhammer symbol.

Using the exponent
\Theta_{\mathrm{WH}}
we can build the Stokes graph of the linear problem, see Figure
3
. It has four Stokes rays.
In each sector
\Omega_{j}
,
j=0,1,\ldots,4
, there is unique solution
Y_{j}(\zeta)
of (
47
), so called
the canonical solution
in the sector
\Omega_{j}
,
which has the asymptotic expansion of form (
48
).
We combine all these canonical solutions to
piecewise
holomorphic matrix function
Y(\zeta)

Y(\zeta)=Y_{j}(\zeta),\qquad\zeta\in\Omega_{j},\quad j=0,1,\ldots,4,

(52)

having constant jumps on each of Stokes rays:

Y_{j+1}(\zeta)=Y_{j}(\zeta)H_{j}.

(53)

Figure 3:
Model RH problem for the local solution near
\lambda_{+}
.

From the symmetry of the problem (
47
) and regularity of
A(\zeta)
at
\zeta=0
we can deduce the form of the Stokes matrices

H_{2k}=\begin{pmatrix}1&0\\
h_{2k}&1\end{pmatrix},\quad H_{2k+1}=\begin{pmatrix}1&h_{2k+1}\\
0&1\end{pmatrix}.

(54)

They satisfy the relations

H_{k+2}=\sigma_{3}e^{-i\pi\nu\sigma_{3}}H_{k}e^{i\pi\nu\sigma_{3}}\sigma_{3},\quad H_{0}H_{1}H_{2}H_{3}=e^{2\pi i\nu\sigma_{3}}

(55)

implying the relation for the Stokes parameters

1+h_{0}h_{1}=e^{-2\pi i\nu}.

(56)

Explicit formulas for
h_{0}
and
h_{1}
can be derived from the canonical solutions
Y_{j}(\zeta)
written in terms of Weber–Hermite functions:

h_{0}=-\frac{i\sqrt{2\pi}}{\Gamma(1-\nu)},\qquad h_{1}=\frac{\sqrt{2\pi}}{\Gamma(\nu)}\,e^{-i\pi\nu}.

(57)

In order to construct a local parametrix near
\lambda_{+}
and fit Stokes matrices, we
introduce new
piecewise
holomorphic function
\tilde{Y}(\zeta)
by

\tilde{Y}(\zeta)=Y(\zeta)Q^{-\sigma_{3}/2},

(58)

where
Q
is defined by two equivalent (due to (
26
) and (
56
)) relations (see also (
28
))

Q^{-1}=\frac{-h_{1}}{s_{3}}=-\frac{s_{1}e^{-2\pi i\nu}}{h_{0}}.

(59)

Then the jump matrices
\tilde{H}_{j}
of
\tilde{Y}(\zeta)
defined by
\tilde{Y}_{j+1}(\zeta)=\tilde{Y}_{j}(\zeta)\tilde{H}_{j}
, or explicitly

\tilde{H}_{j}=Q^{\sigma_{3}/2}H_{j}Q^{-\sigma_{3}/2}
, are exactly jump matrices on Stokes curves attached to the critical points
\lambda_{+}
, see Figure
2
(b):

\tilde{H}_{0}=(S_{L})^{-1},\quad\tilde{H}_{1}=S_{6},

(60)

\tilde{H}_{2}=S_{1},\quad\tilde{H}_{3}=S_{2}(S_{U})^{-1},\quad\tilde{H}_{D}=(S_{D})^{-1}.

(61)

The constructed function
\tilde{Y}(\zeta)
solves RH problem in
D_{r}
with constant jump matrices. In order to describe local solutions in
D_{r}
with
“dressed” jump matrices
G_{k}
given by (
30
), it is convenient to use the local parametrix

\psi_{r}(\lambda)=\tilde{Q}^{\sigma_{3}/2}Y(\zeta(\lambda))Q^{-\sigma_{3}/2}e^{-\Theta(\lambda)},\qquad\lambda\in D_{r},

(62)

where

\tilde{Q}=Qe^{\frac{2ix}{3}}\left(c_{+}x^{\frac{1}{2}}\right)^{-2\nu}.

(63)

We will use slightly different form of
\psi_{r}(\lambda)
rewritten as

\psi_{r}(\lambda)=G_{r}(\lambda)\beta_{r}(\lambda)^{-1}Y_{D}(\lambda),\quad\psi_{l}(\lambda)=\sigma_{2}\psi_{r}(-\lambda)\sigma_{2},

(64)

where we used the definition (
43
) of
\zeta(\lambda)
and introduced the functions

\beta_{r}(\lambda)=\left(\frac{\lambda-\lambda_{+}}{\lambda-\lambda_{-}}\cdot\frac{1}{w_{+}(\lambda)}\right)^{\nu\sigma_{3}},\quad G_{r}(\lambda)=\tilde{Q}^{\sigma_{3}/2}G_{0}(\zeta(\lambda))\tilde{Q}^{-\sigma_{3}/2}.

(65)

Also, we will use the following form of series expansion for
G_{r}

G_{r}(\lambda)=I+\sum_{j=1}^{\infty}\frac{\varepsilon_{j}}{w_{+}^{j}(\lambda)},\qquad\varepsilon_{j}=\tilde{Q}^{\sigma_{3}/2}\rho_{j}\tilde{Q}^{-\sigma_{3}/2}\left(c_{+}x^{1/2}\right)^{-j}.

(66)

3.5
Global RH solution and gauge transformations of local parametrices

We have constructed local parametrices (
40
) and (
62
) together with conformal map (
43
)
solving RH problem locally on
D_{0}:=\mathbb{CP}^{1}\setminus D_{r}\cup D_{l}
and
D_{r}
, respectively. However, there is a freedom, called gauge transformation, to multiply them from the left by functions from
\mathcal{H}(U)
—
the space of holomorphic invertible matrix functions on
U
, where
U
in these cases are domains where these local parametrices are defined. Thus, in general, the local parametrices have the form

\Psi_{D}(\lambda)=B_{D}(\lambda)Y_{D}(\lambda),\quad\lambda\in D_{0},

(67)

\Psi_{r}(\lambda)=B_{r}(\lambda)\psi_{r}(\lambda),\quad\lambda\in D_{r},\qquad\Psi_{l}(\lambda)=\sigma_{2}\Psi_{r}(-\lambda)\sigma_{2},\quad\lambda\in D_{l}.

(68)

The last relation follows from
Z_{2}
-symmetry (
15
), which we want to preserve. The precise form of gauge transformation

B_{r}(\lambda)\in\mathcal{H}(D_{r})
and
B_{D}(\lambda)\in\mathcal{H}(D_{0})

will follow from the factorization procedure for jumps between
\Psi_{r}
,
\Psi_{l}
, and
\Psi_{D}
described in the next section.
Note, that normalization condition (
33
) requires
B_{D}(\infty)=I
.

4
Approximated RH problem on two circles

4.1
General idea

In this section we will show how to approximate the solution of initial RH problem by the solution of RH problem on two circles.
We start from the definition of approximated solution
\hat{\Psi}(\lambda)
for RH problem using parametrices (
67
) and (
68
)

\hat{\Psi}(\lambda)=\begin{cases}\Psi_{D}(\lambda),&\lambda\in D_{0},\\
\Psi_{r}(\lambda),&\lambda\in D_{r},\\
\Psi_{l}(\lambda),&\lambda\in D_{l}.\end{cases}

(69)

Note that parametrices
\Psi_{r}
and
\Psi_{l}
can be analytically continued to larger regions but for now it is sufficient to define them inside discs. We formulate new RH problem for
\varphi(z)
defined by

\varphi(z)=\Psi(z)\hat{\Psi}(\lambda)^{-1},\qquad\lambda=z/(-t)^{1/2}.

(70)

This new function has jumps on boundary circles of
D_{\pm}
and tails of Stokes curves, see Figure
4
.

The RH problem for function
\varphi(z)
.

Let us assume that we found parametrices (
67
) and (
68
) satisfying

\Psi_{D}(\lambda)\Psi_{r}(\lambda)^{-1}=I,\qquad\Psi_{D}(\lambda)\Psi_{l}(\lambda)^{-1}=I

(71)

These relations define factorization problems, which allow us to find appropriate gauge transformations

, and
B_{l}
.
For example, for the right circle
\mathcal{C}_{r}
, we have

J_{r}(\lambda):=Y_{D}(\lambda)\psi_{r}(\lambda)^{-1}=B_{D}(\lambda)^{-1}B_{r}(\lambda),

(72)

where
J_{r}(\lambda)
can be rewritten using (
64
) as

J_{r}(\lambda)=\beta_{r}(\lambda)G_{r}(\lambda)^{-1}.

(73)

Thus, the function
\varphi(z)
defined in (
70
) has jumps only on tails of the Stokes curves

J^{(\mathrm{tail})}_{k}=\varphi_{-}(z)^{-1}\varphi_{+}(z)=\Psi_{D}(\lambda)e^{\Theta(z)}S_{k}e^{-\Theta(z)}\Psi_{D}(\lambda)^{-1}=I+O(e^{-2x|\theta(r_{0})|}).

(74)

In this way, the solution
\Psi(z)
for the initial RH problem can be approximated for large parameter
x
by
\hat{\Psi}(\lambda)
up to exponentially small terms.

In what follows, it is convenient to define another formula for the Hamiltonian

\hat{H}=\partial_{s}\log\tau=\frac{dt}{ds}\cdot\partial_{t}\log\tau=-\frac{H}{2(-t)^{1/2}},

(75)

where we used the definition of parameter
s
from (
18
). Using the fact that
\Psi(z)
and
\hat{\Psi}(z)
are equal up to exponentially small terms, we can relate
\hat{H}
with the first coefficient of expansion of
\hat{\Psi}
for large
\lambda
, see also (
13
),

\hat{H}=-\frac{i}{2}\Tr\hat{g}_{1}\sigma_{3},\qquad\hat{\Psi}(\lambda)=I+\sum_{k=1}^{\infty}\frac{\hat{g}_{k}}{\lambda^{k}}.

(76)

The strategy of finding large
t
expansion of tau function using RH approach is to find
B_{D}(\lambda)
by factorization of left-hand side of (
72
) in some order of approximation
(see the precise definition below)
and then using (
67
) to obtain an approximation for the global solution
\Psi(\lambda)\approx\hat{\Psi}(\lambda)
of RH problem,
which, in turn, can be used to recover the Hamiltonian
\hat{H}
and the tau function
\tau(t)
in the same order of approximation by means of relations (
76
) and (
75
).

4.2
Gluing of local solutions of RH problem

In order to glue local solutions of RH problem we need to solve the factorization problem (
72
) and its left circle counterpart.
This problem will be solved in two steps. The first step is factorization of jumps on both circles. If such factorizations exist, on the second step we use a freedom of choosing these factorizations to fix the external parametrix.
Let a solution of factorization problem on the right circle is given by

J_{r}(\lambda)=\left(J_{r,-}(\lambda)\right)^{-1}J_{r,+}(\lambda),

(77)

where
J_{r,-}(\lambda)\in\mathcal{H}(D_{0})
and
J_{r,+}(\lambda)\in\mathcal{H}(D_{r})
, respectively.
This factorization is not unique.
Namely, both functions
J_{r,\pm}
can be multiplied by a function
R_{r}(\lambda)\in\mathcal{H}(\mathbb{CP}^{1}\setminus D_{l})
from the left without spoiling the relation.
For the left circle the story is similar and we have a freedom in choosing factorization describing by
R_{l}(\lambda)\in\mathcal{H}(\mathbb{CP}^{1}\setminus D_{r})
. Thus the gauge transformations
{B}_{r}(\lambda)
,
{B}_{l}(\lambda)
are

{B}_{r}(\lambda)=R_{r}(\lambda)J_{r,+}(\lambda),\qquad{B}_{l}(\lambda)=R_{l}(\lambda)J_{l,+}(\lambda),

(78)

and for
{B}_{D}
we have two formulas

{B}_{D}(\lambda)=R_{r}(\lambda)J_{r,-}(\lambda)=R_{l}(\lambda)J_{l,-}(\lambda).

(79)

The last equation defines a factorization problem

G_{\mathcal{C}}(\lambda)=J_{l,-}(\lambda)\left(J_{r,-}(\lambda)\right)^{-1}=\left(R_{l}(\lambda)\right)^{-1}R_{r}(\lambda).

(80)

Solutions for this factorization problem
R_{r}
and
R_{l}
can be multiplied only by a constant matrix from the left, which can be fixed using asymptotics near
\lambda=\infty
.

4.3
Notion of degree of approximation

To develop the perturbation theory systematically, we need a notion of degree of approximation.
It is related directly to the number of terms in
G_{0}(\zeta)
defined in (
49
) which we use,
namely for
n
-th order of approximation we use the approximation

G_{0}(\zeta)\approx I+\sum_{j=1}^{n}\frac{\rho_{j}}{\zeta^{j}}.

(81)

The related function
G_{r}(\zeta)
defined in (
65
) and its series (
66
) motivate the following definition of degree of approximation

\mathrm{deg}\left(x^{-\frac{k}{2}}\right)=k,\quad\mathrm{deg}\left(x^{-\frac{k}{2}}\tilde{Q}^{\pm s}\right)=k-s+1,\quad s>0.

(82)

In particular,

\mathrm{deg}\,\varepsilon_{k}=k,\qquad\mathrm{deg}\,(\varepsilon_{j}\varepsilon_{k})=j+k.

(83)

Then the
n
-th order of approximation can be defined as one for which we neglect the terms of degree greater than
n
.
The degree of matrix-valued function is defined as the lowest degree of its matrix elements.
Note that two terms having the same degree can be distinguished by their asymptotic behavior for a fixed
\nu
and large
x
.
However, we want to collect all such terms in order not to choose any specific value of parameter
\nu
.

4.4
0
-order of approximation of gauge transformations

It is hard to tackle the factorization problem (
72
) in general, thus we will find a solution perturbatively for large parameter
x
.
We start with
0
-order approximation of
G_{r}(\lambda)
which corresponds to the leading term of (
66
) for large
x
:

G_{r}(\lambda)\approx I.

(84)

In this case, the jump for factorization problem (
77
) is rather simple

J_{r}=\beta_{r}(\lambda)G_{r}(\lambda)^{-1}\approx\beta_{r}(\lambda),

(85)

where we used (
73
).
Since this function is already belongs to
\mathcal{H}(D_{r})
, we immediately read off
0
-order approximation for gauge transformations

B_{D}^{(0)}(\lambda)=I,\qquad B_{r}^{(0)}(\lambda)=\beta_{r}(\lambda).

(86)

Due to
Z_{2}
-symmetry relations

Y_{D}(\lambda)=\sigma_{2}Y_{D}(-\lambda)\sigma_{2},\qquad\Psi_{l}(\lambda)=\sigma_{2}\Psi_{r}(-\lambda)\sigma_{2},

(87)

the factorization of the jump on the right circle leads to factorization of the jump on the left circle in the same order of approximation. Therefore we obtained a
0
-order approximation for the global solution of RH problem
having the expansion for large
\lambda

\Psi_{D}^{(0)}=Y_{D}(\lambda)=I+\frac{(\lambda_{-}-\lambda_{+})\nu\sigma_{3}}{\lambda}+O(\lambda^{-2}).

(88)

It allows us to find the corresponding approximation for the Hamiltonian using (
76
)

\hat{H}^{(0)}=-\frac{i}{2}\Tr\hat{g}^{(0)}_{1}\sigma_{3}=i\nu.

(89)

Integrating the Hamiltonian
\hat{H}^{(0)}
, we get leading asymptotic term for the tau function

\tau^{(0)}=e^{i\nu s}.

(90)

\mathcal{C}_{r}
and

-th order of approximation

5.1
General construction

As a first step, we want to solve the factorization problem (
77
) on
\mathcal{C}_{r}
in
n
-th order of approximation with respect the degree defined above. We can rewrite it as

J_{r,-}(\lambda)J_{r}(\lambda)=J_{r,+}(\lambda).

(91)

Since
J_{r,+}(\lambda)\in\mathcal{H}(D_{r})
, we have

\left[J_{r,-}(\lambda)J_{r}(\lambda)\right]_{-}=0,

(92)

where we denote by
[...]_{-}
the projection onto the space of holomorphic functions outside
D_{r}
which vanish at
\lambda=\infty
.
This projection acts on each matrix elements.
The equation (
92
) rewritten in basis
(\lambda-\lambda_{+})^{k}
,
k\in\mathbb{Z}
, becomes a system of linear equation for unknown
Fourier components of
J_{r,-}(\lambda)
with respect to the basis. Let us describe it explicitly.

In
n
-th order of approximation, the jump matrix
J_{r}(\lambda)
on
\mathcal{C}_{r}
is given by

J_{r}(\lambda)=\beta_{r}(\lambda)G_{r}(\lambda)^{-1},\qquad G_{r}(\lambda)^{-1}=I-\sum_{j=1}^{n}\frac{\eta_{j}}{w_{+}^{j}(\lambda)},

(93)

where
G_{r}(\lambda)^{-1}
is obtained by inversion of

G_{r}(\lambda)=I+\sum_{j=1}^{n}\frac{\varepsilon_{j}}{w_{+}^{j}(\lambda)}

(94)

neglecting terms of degree higher than
n
.
Explicit expressions for the first coefficients of
G_{r}(\lambda)^{-1}
are

\eta_{1}=\varepsilon_{1},\qquad\eta_{2}=\varepsilon_{2}-\varepsilon_{1}^{2},\qquad\ldots.

(95)

Using the definition of
w_{+}(\lambda)
given by (
41
), we see that the most singular term of expansion of
J_{r}(\lambda)
at
\lambda=\lambda_{+}

is
(\lambda-\lambda_{+})^{-n}
.
Therefore the Fourier series for
J_{r}(\lambda)
on
\mathcal{C}_{r}
has the form

J_{r}(\lambda)=I-\sum_{k=-n}^{\infty}q_{k}(\lambda-\lambda_{+})^{k},

(96)

where

q_{k}=\oint_{\mathcal{C}_{r}}\frac{d\lambda}{2\pi i}(\lambda-\lambda_{+})^{-k-1}\left(I-J_{r}(\lambda)\right).

(97)

Also we expect that a proper anzats for
J_{r,-}
is

J_{r,-}(\lambda)=I+\sum_{j=1}^{n}\frac{E_{j}}{(\lambda-\lambda_{+})^{j}}.

(98)

Now equation (
92
), describing factorization of
J_{r}
, can be rewritten as a system of
2n
matrix linear equations
for unknown matrices
E_{k}

\sum_{k=j}^{n}E_{k}q_{k-j-n}=0,\qquad j=1,2,\ldots,n,

(99)

(E_{n},\ldots,E_{1})\begin{pmatrix}I-q_{0}&-q_{1}&\cdots&-q_{n-1}\\
-q_{-1}&I-q_{0}&\cdots&-q_{n-2}\\
\vdots&\ddots&\ddots&\vdots\\
-q_{-n+1}&\cdots&-q_{-1}&I-q_{0}\end{pmatrix}=(q_{-n},\ldots,q_{-1}).

(100)

It is shown in
A
how to solve (
100
) effectively and that
n
matrix equations (
99
) are satisfied for the solution of equations (
100
).

Factorization of the jump
J_{l}
on
\mathcal{C}_{l}
can be done similarly. Since our construction of

uses

-symmetry we can use it to
find
J_{l,-}(\lambda)
by

J_{l,-}(\lambda)=I+\sum_{j=1}^{n}\frac{\tilde{E}_{j}}{(\lambda-\lambda_{-})^{j}},\qquad\tilde{E}_{j}=(-1)^{j}\sigma_{2}E_{j}\sigma_{2}.

(101)

5.2
An example: the factorization in

In this subsection, we apply the described procedure to

Using (

) we get the first order of approximation for

J_{r}(\lambda)=\beta_{r}(\lambda)\left(I-\frac{\varepsilon_{1}}{w_{+}(\lambda)}\right),

(102)

where we took into account
\varepsilon_{1}^{2}=0
in this order of approximation to find the inverse of

G_{r}(\lambda)=I+\frac{\varepsilon_{1}}{w_{+}(\lambda)}.

(103)

To find a solution
J_{r,-}(\lambda)
of (
92
), we assume that in the first order of approximation

J_{r,-}(\lambda)=I+\frac{E_{1}}{\lambda-\lambda_{+}}.

(104)

The equations (

) and (

E_{1}

(105)

where

q_{-1}=\varepsilon_{1},\qquad q_{0}=(\alpha_{r,1}\cdot I+\beta_{r,1})\varepsilon_{1}

(106)

with the coefficients
\alpha_{r,1}

(107)

Since the function

defined in (

) is a diagonal matrix function we have

Therefore (all the equalities are up to terms of

(108)

Note that the equation
E_{1}q_{-1}=0
for

is satisfied automatically.

The factorization problem for
J_{l}
can be solved similarly

We finish the computation in subsection

General construction

The second step is to solve the factorization problem (

R_{l}(\lambda)G_{\mathcal{C}}(\lambda)=R_{r}(\lambda).

(110)

Since the function
R_{r}(\lambda)\in\mathcal{H}(D_{r})

\left[R_{l}(\lambda)G_{\mathcal{C}}(\lambda)\right]_{-}=0,

(111)

where as before
we denote by

Using (

),
\mathrm{deg}\,E_{j}=j
, and

n

The equation (

linear matrix equations for uknown matrices
r_{j}

\sum_{k=j}^{n}r_{k}f_{k-j-n}=0,\qquad j=1,2,\ldots,n,

(116)

(r_{n},\ldots,r_{1})\begin{pmatrix}I-f_{0}&-f_{1}&\cdots&-f_{n-1}\\

6.2
The final step of the factorization in

In this subsection, we finish computations for
n=1
case started in subsection
5.2
.
Assuming that in the first order of approximation the function
R_{l}(\lambda)
has the form

R_{l}(\lambda)=I+\frac{r_{1}}{\lambda-\lambda_{+}},

(120)

the equation (
111
) leads to equations

r_{1}f_{-1}=0,\qquad r_{1}(I-f_{0})=f_{-1}.

(121)

Using (
114
) we get

f_{-1}=(I+\tilde{\varepsilon}_{1})\varepsilon_{1},\qquad f_{0}=-\tilde{\varepsilon}_{1}(I+\varepsilon_{1}).

(122)

The solution of the system (
121
) is

r_{1}=f_{-1}(I-f_{0})^{-1}.

(123)

The first equation of (
121
) is satisfied automatically due to

(I-f_{0})^{-1}f_{-1}=(I+(I+\tilde{\varepsilon}_{1})^{-1}\tilde{\varepsilon}_{1}\varepsilon_{1})\varepsilon_{1}=\varepsilon_{1},\qquad f_{-1}\varepsilon_{1}=0.

(124)

Here we used only that
\varepsilon_{1}^{2}=0
in this approximation. Using also
\tilde{\varepsilon}_{1}^{2}=0
we can present
r_{1}
in more convenient form

r_{1}=\tilde{\varepsilon}_{1}\varepsilon_{1}\Delta^{-1}-\varepsilon_{1}\tilde{\varepsilon}_{1}\tilde{\Delta}^{-1}+\varepsilon_{1}\Delta^{-1}-\tilde{\varepsilon}_{1}\varepsilon_{1}\Delta^{-1}\tilde{\varepsilon}_{1},

(125)

where we introduced matrices

\Delta=I+\tilde{\varepsilon}_{1}\varepsilon_{1},\qquad\tilde{\Delta}^{-1}=I+\varepsilon_{1}\tilde{\varepsilon}_{1}.

(126)

Note that the first two matrices in formula (
125
) are diagonal and the last two are off-diagonal. Let us introduce the following notations

V_{1}=\frac{\tilde{Q}^{2}\nu^{2}}{c_{+}^{2}x},\qquad V_{-1}=\frac{1}{\tilde{Q}^{2}c_{+}^{2}x},

(127)

then, using
\varepsilon_{1}
given by (
66
) and
\tilde{\varepsilon}_{1}=-\sigma_{2}\varepsilon_{1}\sigma_{2}
, we have

\tilde{\varepsilon}_{1}\varepsilon_{1}=\begin{pmatrix}V_{-1}&0\\
0&V_{1}\end{pmatrix},\qquad\varepsilon_{1}\tilde{\varepsilon}_{1}=\begin{pmatrix}V_{1}&0\\
0&V_{-1}\end{pmatrix},

(128)

and the diagonal part of

is

r_{1}^{(\mathrm{diag})}=-\left(\frac{V_{1}}{1+V_{1}}-\frac{V_{-1}}{1+V_{-1}}\right)\sigma_{3}.

(129)

Using
\Psi_{D}
and

given by (

) and (

(130)

Thus, in the first-order approximation, using (

), we get

\hat{H}^{(1)}=i\nu+i\left(\frac{V_{1}}{1+V_{1}}-\frac{V_{-1}}{1+V_{-1}}\right).

(131)

This Hamiltonian can be integrated using the fact that up to terms of second degree we have the relation

\partial_{s}\log(1+V_{1}+V_{-1})=\frac{i(V_{1}-V_{-1})}{1+V_{1}+V_{-1}}=i\left(\frac{V_{1}}{1+V_{1}}-\frac{V_{-1}}{1+V_{-1}}\right).

Therefore the first-order approximated tau function is

\tau^{(1)}=e^{i\nu s}(1+V_{1}+V_{-1}).

(133)

\hat{H}^{(2)}=i\nu+i\left(\frac{V_{1}}{1+V_{1}}-\frac{V_{-1}}{1+V_{-1}}\right)-\frac{\nu^{2}}{s}.

This expression coincides with the second order of approximation of (

V_{k}=\frac{C(\nu+k)}{C(\nu)}\frac{e^{i(\nu+k)s}s^{-(\nu+k)^{2}}}{e^{i\nu s}s^{-\nu^{2}}}e^{ik\rho}.

(136)

7
Discussion

In this paper we elaborated a systematic way to calculate higher orders of asymptotic expansion series
for the Hamiltonian of Painlevé II equation in the long-time limit
t\to-\infty
.
We believe that our approach can be applied to asymptotic analysis of different RH problems and, in particular,
RH problems associated with the other Painlevé equations. In a forthcoming paper, the described method with minor changes will be applied
for higher order asymptotic analysis of Painlevé I equation.

Also this method gives asymptotic series for the isomonodromic tau function by integration of the Hamiltonian.
However this approach looks a bit indirect and it is interesting to develop a method of obtaining tau function directly.
Such a direct way is known for tau function of Painlevé VI equation where this tau function is presented
as a Fredholm determinant related to the Widom constant
[
16
,
17
]
.
We plan to transfer this idea to tau function of Painlevé II equation and present it in the form of a generalization of Widom constant on two circles
\mathcal{C}_{r}
and
\mathcal{C}_{l}
. Also we would like to mention recent paper
[
18
]
, where the author
found a Fredholm determinant presentation for Painlevé II tau function, but it seems that this construction is not related
apparently to Widom constant.

Recently a new approach to construct solutions of Painlevé equations were developed on the base of topological recursion
on elliptic curves
[
19
,
20
]
. This approach is closely related to holomorphic anomaly equation approach

[
21
]
allowing to compute effectively Painlevé II tau function.

One more direction of research is motivated by the relation of Painlevé equations with conformal field theory

[
22
,
23
,
24
]
. In this direction, the most challenging problem is to
build irregular counterparts of conformal blocks together with their relation to Painlevé equations

[
25
,
26
,
27
]
.

Appendix A
Details of factorization on

In this appendix we present an effective way to invert the block Toeplitz matrix

\hat{q}=\begin{pmatrix}I-q_{0}&-q_{1}&\cdots&-q_{n-1}\\
-q_{-1}&I-q_{0}&\cdots&-q_{n-2}\\
\vdots&\ddots&\ddots&\vdots\\
-q_{-n+1}&\cdots&-q_{-1}&I-q_{0}\end{pmatrix}

(137)

defining the coefficients of the linear system (
100
). Also we show that
the equations (
99
) are satisfied automatically on the base of degree reasoning.

To invert
\hat{q}
, it is convenient to present it as

\hat{q}=\delta+\hat{q}^{(1)},

(138)

where
\delta
is its part of degree
0
and by
\hat{q}^{(1)}
the remaining part.
The matrix
\delta
can be expressed in terms of Fourier coefficients (
107
)
of the matrix
\beta_{r}(\lambda)
defined in (
65
) as

\delta=\begin{pmatrix}I&\beta_{r,1}&\cdots&\beta_{r,n-1}\\
0&I&\cdots&\beta_{r,n-2}\\
\vdots&\ddots&\ddots&\vdots\\
0&\cdots&0&I\end{pmatrix}.

(139)

This matrix can be easily inverted even for generic
n
giving an effective formula for
\hat{q}^{-1}

\hat{q}^{-1}=\delta^{-1}\left(I+\hat{q}^{(1)}\delta^{-1}\right)^{-1}=\delta^{-1}\sum_{j=0}^{n}\left(-\hat{q}^{(1)}\delta^{-1}\right)^{j}

(140)

valid in the
n
-th order of approximation.
Using this formula and equation (
100
) we obtain

\mathrm{deg}\,E_{k}=\mathrm{deg}\,q_{-k}=k,\qquad k>0.

(141)

Taking into account

\mathrm{deg}\,E_{j}q_{-k}=j+k,

(142)

we obtain that the equations (
99
) are satisfied automatically for the solution of equations (
100
).

Appendix B
Details of factorization needed for gluing local parametrices

In this appendix we show how to solve the system (

) and (
117
).

) automatically satisfies
(

B.1
Some properties of Fourier coefficients
f_{k}

First, we give some information on the Fourier coefficients
f_{k}
entering the equations (
116
) and (
117
).
Using explicit form of matrices
f_{k}
we can obtain an estimation on their degrees. For the negative coefficients we have

\mathrm{deg}\,f_{-k}=k,\qquad k>0,

(143)

and for the non-negative coefficients we have

\mathrm{deg}\,f_{k}=1,\qquad k\geq 0.

(144)

There is an inequality for degrees having the form

\mathrm{deg}\,AB\geq\mathrm{deg}\,A+\mathrm{deg}\,B-1,

(145)

which can be proven using monomials, namely, the worst case is the case of two monomials having the same signs of exponents of
\tilde{Q}
, for example

\mathrm{deg}\,x^{-\frac{k_{1}}{2}}\tilde{Q}^{s_{1}}\cdot x^{-\frac{k_{2}}{2}}\tilde{Q}^{s_{2}}=k_{1}+k_{2}-(s_{1}+s_{2})+1=\mathrm{deg}\,x^{-\frac{k_{1}}{2}}\tilde{Q}^{s_{1}}+\mathrm{deg}\,x^{-\frac{k_{2}}{2}}\tilde{Q}^{s_{2}}-1.

(146)

We can find degree of matrix
r_{n}
from the first equation of the system (
117
)

r_{n}(1-f_{0})=\left(r_{n-1}f_{-1}+\ldots+r_{1}f_{-n+1}\right)+f_{-n}\qquad\Rightarrow\qquad\mathrm{deg}\,r_{n}=n.

(147)

The last implication is true because
\mathrm{deg}\,f_{-n}=n
and an expression in brackets has also degree
n
by induction. We also need to fulfil (
116
). Using the inequality (
145
) we can get

\mathrm{deg}\left(\sum_{k=j}^{n}r_{k}f_{k-j-n}\right)\geq n+j-1.

(148)

Thus, for
j>1
, the equations (
116
) are satisfied automatically. The only equation which we need to
prove is

M_{n+1}:=r_{n}f_{-1}+r_{n-1}f_{-2}+\cdots+r_{1}f_{-n}=0

(149)

in
n
-order of approximation.

We will prove that

\mathrm{deg}\,M_{n+1}=n+1,

(150)

where matrices
r_{k}
are satisfied the system of equation (
117
)

\begin{cases}r_{n}(1-f_{0})-M_{n}=f_{-n},\\
-r_{n}f_{1}+r_{n-1}(1-f_{0})-M_{n-1}=f_{-n+1},\\
\vdots\\
-r_{n}f_{n-1}-\cdots-r_{2}f_{1}+r_{1}(1-f_{0})=f_{-1}.\end{cases}

(151)

We already have seen that
\mathrm{deg}\,M_{2}=2
for the
n=1
case, see (
124
), therefore we will assume that
\mathrm{deg}\,M_{k}=k
for
k<n+1
.

B.2
Main tricks

We want to present some properties of matrices
f_{k}
following from their definition (
114
).
Let we define the matrices
H_{j}
as

J_{r,-}^{-1}=\left(1+\sum_{j=1}\frac{E_{j}}{(\lambda-\lambda_{+})^{j}}\right)^{-1}=1-\sum_{j=1}^{\infty}\frac{H_{j}}{(\lambda-\lambda_{+})^{j}}.

(152)

These matrices
H_{j}
have the same dependence on
\tilde{Q}
as
E_{j}
(and
\varepsilon_{j}
), namely

E_{j}=\tilde{Q}^{\sigma_{3}/2}e_{j}\tilde{Q}^{-\sigma_{3}/2},\qquad H_{j}=\tilde{Q}^{\sigma_{3}/2}h_{j}\tilde{Q}^{-\sigma_{3}/2},

(153)

where matrices
e_{j},h_{j}
are independent of
\tilde{Q}
. Therefore, we can easily find the degree of a product of
H_{j}
’s

\mathrm{deg}\left(H_{j_{1}}\ldots H_{j_{k}}\right)=j_{1}+\cdots+j_{k}.

(154)

It is convenient to introduce a vector space
\boldsymbol{H}_{l}
generated by the following monomials

\boldsymbol{H}_{l}=\mathrm{Span}\,(H_{j_{1}}\ldots H_{j_{k}},\ j_{1}+\cdots+j_{k}=l).

(155)

Let we discuss the leading form of
f_{-k}

f_{-k}=f_{-k}^{(k)}+\delta f_{-k},\qquad f_{-k}^{(k)}=(1+\tilde{\varepsilon}_{1})H_{k},

(156)

where
\delta f_{-k}
is some matrix having degree
k+1
. Also, we will need the leading behavior of
f_{0}

f_{0}=f_{0}^{(1)}+\delta f_{0},\qquad f_{0}^{(1)}=-\tilde{\varepsilon}_{1}(1+\varepsilon_{1}),

(157)

where
\delta f_{0}
is a matrix of degree 2. The precise form of
f_{-k}
and
f_{0}
allow us to prove a useful relation

(1-f_{0})^{-1}f_{-k}\boldsymbol{H}_{n-k}=H_{k}\boldsymbol{H}_{n-k},

(158)

where we droped terms of degree higher than
n
. Using the inequality for degrees (
145
) we can drop
\delta f_{0}
and
\delta f_{-k}
to get

(1-f_{0})^{-1}f_{-k}\boldsymbol{H}_{n-k}=(1+\tilde{\varepsilon}_{1}+\tilde{\varepsilon}_{1}\varepsilon_{1})^{-1}(1+\tilde{\varepsilon}_{1})H_{k}\boldsymbol{H}_{n-k}\\
=(1+(1+\tilde{\varepsilon}_{1})^{-1}\tilde{\varepsilon}_{1}\varepsilon_{1})^{-1}H_{k}\boldsymbol{H}_{n-k}.

(159)

Using the fact that

\mathrm{deg}\,\varepsilon_{1}H_{k}\boldsymbol{H}_{n-k}=n+1,

(160)

we obtain the relation (
158
).

B.3
Proof of (
149
)

Let we show that

\mathrm{deg}\,r_{1}f_{-n}=n+1.

(161)

We can find
r_{1}
from the system (
151
) in the form

r_{1}=(f_{-1}+r_{2}f_{1}+\cdots+r_{n}f_{n-1})(1-f_{0})^{-1}.

(162)

Due to the fact that
f_{-n}
has degree
n
we can drop terms having degree higher than 1

r_{1}f_{-n}=f_{-1}(1-f_{0})^{-1}f_{-n}=f_{-1}H_{n}=0,

(163)

where we used the identity (
158
) for
k=n
and the last equality follows from the leading behavior of
f_{-1}
given by (
156
). Let we show that

\mathrm{deg}\,r_{2}f_{-n+1}=n+1.

(164)

We can find
r_{2}
from the system (
151
) in the form

r_{2}=(f_{-2}+M_{2}+r_{3}f_{1}+\cdots+r_{n}f_{n-2})(1-f_{0})^{-1}.

(165)

Due to the fact that
f_{-n+1}
has degree
n-1
we can drop terms having degree higher than 2

r_{2}f_{-n+1}=(f_{-2}+M_{2})(1-f_{0})^{-1}f_{-n+1}.

(166)

In the last expression, only leading terms of
f_{k}
contribute

(f_{-2}+M_{2})(1-f_{0}^{(1)})^{-1}f_{-n+1}^{(n-1)}=(f_{-2}+M_{2})H_{n-1}=M_{2}H_{n-1}.

(167)

On this step, we need to use expression for
r_{1}
given by (
162
)

M_{2}H_{n-1}=r_{1}f_{-1}H_{n-1}=f_{-1}(1-f_{0})^{-1}f_{-1}H_{n-1}.

(168)

Using the identity (
158
) for
k=1
, we get

M_{2}H_{n-1}=f_{-1}H_{1}H_{n-1}=0,

(169)

where we used the leading behavior of
f_{-1}
given by (
156
). We can repeat this logic for
r_{k}
. We want to show that

\mathrm{deg}\,r_{k}f_{-n+k-1}=n+1.

(170)

We can find
r_{k}
from the system (
151
) in the form

r_{k}=(f_{-k}+M_{k}+r_{k+1}f_{1}+\cdots+r_{n}f_{n-k})(1-f_{0})^{-1}.

(171)

Due to the fact that
f_{-n+k-1}
has degree
n-k+1
we can drop terms having degree higher than
k
, therefore we have

r_{k}f_{-n+k-1}=(f_{-k}+M_{k})(1-f_{0})^{-1}f_{-n+k-1}.

(172)

In the last expression, only leading terms of
f_{j}
contribute

(f_{-k}+M_{k})(1-f_{0}^{(1)})^{-1}f_{-n+k-1}^{(n-k+1)}=(f_{-k}+M_{k})H_{n-k+1}=M_{k}H_{n-k+1}.

(173)

In this way, we reduced the problem to a statement that if we have

\mathrm{deg}\,M_{k}\boldsymbol{H}_{n-k+1}=n+1,\qquad k<n+1,

(174)

then we can prove the statement (
171
).
The proof uses induction. Let we consider the
k=2
case

M_{2}\boldsymbol{H}_{n-1}=r_{1}f_{-1}\boldsymbol{H}_{n-1}.

(175)

Using expression for
r_{1}
given by (
162
) we have

r_{1}f_{-1}\boldsymbol{H}_{n-1}=f_{-1}(1-f_{0})^{-1}f_{-1}\boldsymbol{H}_{n-1}=f_{-1}H_{1}\boldsymbol{H}_{n-1}=0.

(176)

Thus, we proved the base of induction. By similar arguments, we can prove that

\mathrm{deg}\,r_{1}f_{-k+1}\boldsymbol{H}_{n-k+1}=n+1.

(177)

Indeed, we have

r_{1}f_{-k+1}\boldsymbol{H}_{n-k+1}=f_{-1}(1-f_{0})^{-1}f_{-k+1}\boldsymbol{H}_{n-k+1}=f_{-1}H_{k-1}\boldsymbol{H}_{n-k+1}=0.

(178)

For the other terms of
M_{k}
we can formulate a similar statement

\mathrm{deg}\,r_{m}f_{-k+m}\boldsymbol{H}_{n-k+m}=n+1,\qquad m<k.

(179)

Using expression (
171
) for
k=m
, we get

r_{m}f_{-k+m}\boldsymbol{H}_{n-k+1}=(f_{-m}+M_{m})(1-f_{0})^{-1}f_{-k+m}\boldsymbol{H}_{n-k+1}.

(180)

Then, using the identity (
158
), we have

r_{m}f_{-k+m}\boldsymbol{H}_{n-k+1}=(f_{-m}+M_{m})H_{k-m}\boldsymbol{H}_{n-k+1}=0,

(181)

where the first term is zero due to the structure of leading behavior of
f_{-m}
and the second term is zero by induction. This completes the proof of (
174
), (
172
), and finally (
149
).
