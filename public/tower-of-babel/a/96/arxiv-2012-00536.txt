Nichols algebras over classical Weyl groups(II)
Weicai Wu

Abstract
It is shown that except in three cases conjugacy classes of classical Weyl groups W ⁡ ( B n ) W(B_{n}) and W ⁡ ( D n ) W(D_{n}) are of type D {\rm D} . This proves that Nichols algebras of irreducible Yetter-Drinfeld modules over the classical Weyl groups 𝕎 n \mathbb{W}_{n} (i.e. H n ⋊ 𝕊 n H_{n}\rtimes\mathbb{S}_{n} ) are infinite dimensional, except the class of type ( 2 , 3 ) , ( 1 2 , 3 ) (2,3),(1^{2},3) in 𝕊 5 \mathbb{S}_{5} , and ( 1 n − 2 , 2 ) (1^{n-2},2) in 𝕊 n \mathbb{S}_{n} for n > 5 n>5 . 2020 Mathematics Subject Classification : 16W50, 16T05 Keywords : Rack; classical Weyl groups; Nichols algebras.

Introduction

This work contributes to the classification of finite-dimensional pointed Hopf algebras over an algebraically closed field of characteristic
0

[
4

Let

We briefly recall the definition and main properties of racks;
see
[
3
]
for details, more information and bibliographical references.

A rack
is a pair
(X,\rhd)
, where
X

is a non-empty set and
\rhd:X\times X\rightarrow X
is an operation such that

x\rhd x=x
,

and
\phi_{x}

is a map from
X

X

x\rhd y

For example,

is a rack with
x\rhd y:=xyx^{-1}.

If

and

are two subracks of

with

is called a

of

. Furthermore, if there exist

,

such that
{\rm sq}(a,b):=a\rhd(b\rhd(a\rhd b))\not=b
, then

is called to be of
type D
. Notice that if a rack

contains a subrack

of type
{\rm D}
, then

is also of type
{\rm D}
(see
[
1
]
).
