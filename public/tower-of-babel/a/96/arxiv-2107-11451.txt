A Double-Pivot Degenerate-Robust Simplex Algorithm for Linear Programming


Abstract
A double pivot simplex algorithm that combines features of two recently published papers by these authors is proposed. The proposed algorithm is implemented in MATLAB. The MATLAB implementation is tested, along with a MATLAB implemention of Dantzig’s algorithm, for several test sets, including a set of cycling linear programming problems, Klee-Minty’s problems, randomly generated linear programs, and Netlib benchmark problems. The test results show that the proposed algorithm, with a careful implementation, is (a) degenerate-robust as expected, and (b) more efficient than Dantzig’s algorithm for large size randomly generated linear programming problems, but less efficient for Netlib benchmark problems and small size randomly generated problems in terms of CPU time.

1
Introduction

It has been more than 70 years since Dantzig formulated
a linear programming (LP) problem and proposed the simplex
method
(
Dantzig 1949
)
. The main idea of this algorithm
is to search for an optimizer from a vertex to the next vertex in
the polyhedron formed by the linear constraints using
Dantzig’s pivoting rule. Since then, linear programming
has been one of the mostly studied problems in operations research
(
Borgwardt and Viss 2020
;
Bowly et al. 2020
;
Dadush and Huiberts 2020
;
Cavaleiro and Alizadeh 2021
;
Suriyanarayana et al. 2022
)
.
The simplex method remained to be a mainstream technique
for LP until
Klee and Minty 1972
found an example showing that, in the worst case scenario, Dantzig’s pivoting rule
needs exponentially many iterations to find an optimal
solution of the LP problem. Klee and Minty’s work inspired
researchers to find different ways to solve LP problems.

Interior-point methods emerged as a computationally
feasible alternative technique, which admits algorithms
that find an optimal solution in finite iterations bounded
by a polynomial of the problem size. In the last three
decades, most researches in linear programming
focused on finding novel interior-point methods

(
Wright 1997
;
Gondzio 2012
;
Santos et al. 2019
;
Yang 2021
;
Vitor and Easton 2022
)
. However, the simplex method
never faded away. Motivated by enhancing
the computational performance of the simplex method,
Vitor and Easton 2018
proposed a double pivoting algorithm,
which updates two pivot variables at a time using
Dantzig’s pivoting rule. Motivated by improving the bound of iteration number
of the simplex method,
Yang 2020
independently
proposed a different double pivoting rule that uses
a combined criteria to select two pivot variables.

Realizing the merits of the pivoting rule proposed by
Yang 2020
and
the slope algorithm created by
Vitor and Easton 2018
, this paper proposes and implements a new double pivoting algorithm that combines the pivoting rule of Yang and
the slope algorithm designed to find an optimal solution and an optimal basis of two-dimensional linear programming problems. The proposed algorithm selects two entering variables based on three criteria. The first entering variable is selected based on Dantzig’s pivoting rule, the second entering variable is selected based on the longest step size rule, the combination
of the coefficients of these two variables are determined by the criterion that optimizes the cost reduction, which is equivalent to solving a linear programming
problem of two variables. Notice that the slope algorithm was developed specifically to solve this type of problem.

The intuitions behind the pivoting criteria of Yang are
as follows: first, Dantzig’s pivoting rule is selected because
the computational experience in decades shows that
it is a cheap pivoting rule compared to other
popular pivoting rules
(
Ploskas and Samaras 2014
)
; second, specially
designed examples show that none of the popular
pivoting rules is better than others
(
Paparrizos et al. 2008
)
in the
worst case, hence, using a combination of different rules in a
random way can be beneficial and has been proved that the
strategy results in some polynomial simplex algorithms in the
sense of statistics
(
Gartner et al. 1998
;
Kelner and Spielman 2006
)
; third, using the longest
step size rule will decrease the chance to enter a degenerate
basic feasible solution and increase the chances to get
out of a degenerate solution
(
Yang 2021
)
; fourth, the
longest step rule may be beneficial to reduce the
iteration numbers
(
Yang 2020
)
; finally, using deterministic
pivoting rules may give some hope to find a strongly
polynomial algorithm to solve LP problems, which is not possible for
randomized methods such as the ones proposed by
Gartner et al. 1998
and
Kelner and Spielman 2006
.

Observe that another popular pivoting rule is Harris steepest-edge rule
(
Forrest and Goldfarb 1992
)
, which is similar to the longest step rule in the sense that it needs to compute the step size for all possible pivoting candidates corresponding to a negative reduced cost. Several computational experiments showed that the steepest-edge rule needs fewer simplex iterations than the most negative reduced cost rule
(
Goldfarb and Reid 1977
;
Ploskas and Samaras 2014
)
as one would expect. However, computational experience shows that finding all step sizes for possible pivoting candidates corresponding to the negative coefficients in the revised cost function can be extremely expensive if the cardinality of the negative reduced costs is large. For more complete surveys on pivoting rules, see
Terlaky and Zhang 1993
,
Pan 2014
, and
Ploskas and Samaras 2017
.

Throughout the paper, capitalized bold font is used for matrices, small case bold font is used for vectors, and normal font is used for scalars. To save space, stacked vectors
\left[{\bf x}^{{\rm T}},{\bf y}^{{\rm T}}\right]^{{\rm T}}
are represented as
({\bf x},{\bf y})
. The remainder of the paper is organized as follows. Section
2
presents the proposed algorithm. Section
3
discusses some implementation details. Numerical test problems and test results are provided in Section
4
. Conclusion remarks are summarized in Section
5
.

2
Proposed Algorithm

Consider the primal linear programming problem in standard form:

\displaystyle\begin{array}[]{ll}\min&\ \ {\bf c}^{{\rm T}}{\bf x},\\
\mbox{\rm subject to}&\ \ {\bf A}{\bf x}={\bf b},\hskip 7.22743pt{\bf x}\geq{\bf 0},\end{array}

where
{\bf A}\in{\mathbb{R}}^{m\times n}
,
{\bf b}\in{\mathbb{R}}^{m}
,
{\bf c}\in{\mathbb{R}}^{n}
are given, and
{\bf x}\in{\mathbb{R}}^{n}
is the vector to be optimized. For the following discussion, two primary assumptions are made:

1.

\mbox{rank}({\bf A})=m
;

2.

primal LP problem (
2
) has an optimal solution.

These assumptions are standard. A feasible solution of the linear program satisfies
the conditions of
{\bf A}{\bf x}={\bf b}
and
{\bf x}\geq{\bf 0}
, which exists because of Assumption
2
. Among all feasible solutions, this paper considers only basic feasible solutions, which corresponds to the vertices of the convex polytope
described by the constraints of (
2
). Denote by
B\subset\{1,2,\ldots,n\}
the index set with cardinality
|B|=m
and
N=\{1,2,\ldots,n\}\setminus B
the complementary set of
B
with cardinality
|N|=n-m
such that
matrix
{\bf A}
and vector
{\bf x}
can be partitioned as
{\bf A}=[{\bf A}_{B},{\bf A}_{N}]
and
{\bf x}=({\bf x}_{B},{\bf x}_{N})
with
{\bf x}_{B}\geq 0
and
{\bf x}_{N}=0
. Moreover, if
{\bf A}_{B}{\bf x}_{B}={\bf b}
, then
{\bf x}=({\bf x}_{B},{\bf 0})
is a basic feasible solution. Because some components of
{\bf x}_{B}
may be zeros, and/or even worse,
{\bf A}_{B}
may not be full rank, this partition admits a degenerate basic feasible solution, which are seen in many real-world applications and also in many Netlib benchmark problems
(
Browne et al. 1995
)
. Denote by
\mathcal{B}
the set of all bases
B
and by
\mathcal{N}
the set of all non-bases
N
. Therefore, the linear programming problem (
2
) can be written as:

\displaystyle\begin{array}[]{ll}\min&\ \ {\bf c}_{B}^{{\rm T}}{\bf x}_{B}+{\bf c}_{N}^{{\rm T}}{\bf x}_{N},\\
\mbox{\rm subject to}&\ \ {\bf A}_{B}{\bf x}_{B}+{\bf A}_{N}{\bf x}_{N}={\bf b},\hskip 7.22743pt{\bf x}_{B}\geq{\bf 0},\hskip 7.22743pt{\bf x}_{N}\geq{\bf 0}.\end{array}

Let superscript
k
represent the
k
th iteration. Thus, the matrices and vectors in the
k
th iteration are denoted by
{\bf A}_{B^{k}}
,
{\bf A}_{N^{k}}
,
{\bf c}_{B^{k}}
,
{\bf c}_{N^{k}}
,
{\bf x}_{B^{k}}
, and
{\bf x}_{N^{k}}
where
{\bf x}^{k}=({\bf x}_{B^{k}},{\bf x}_{N^{k}})
is a basic feasible solution of (
2
) with
{\bf x}_{B^{k}}\geq{\bf 0}
and
{\bf x}_{N^{k}}={\bf 0}
. Similarly, define
{\bf x}^{*}=({\bf x}_{B^{*}},{\bf x}_{N^{*}})
as an optimal basic feasible solution of (
2
) with
{\bf A}_{B^{*}}{\bf x}_{B^{*}}={\bf b}
,
{\bf x}_{B^{*}}\geq{\bf 0}
,
{\bf x}_{N^{*}}={\bf 0}
, and
z^{*}={\bf c}^{{\rm T}}{\bf x}^{*}
as the optimal objective function value. Observe that the
partition of
(B^{k},N^{k})
keeps updating and it is different from the partition
(B^{*},N^{*})
before an optimizer is found. If
{\bf A}_{B^{k}}
is full rank, the
reduced cost vector can be calculated as

\bar{{\bf c}}_{N^{k}}^{{\rm T}}=({\bf c}_{N^{k}}-{\bf A}_{N^{k}}^{{\rm T}}{\bf A}_{B^{k}}^{-{\rm T}}{\bf c}_{B^{k}})^{{\rm T}},

(7)

and the iterate of
{\bf x}^{k}={\bf A}_{B^{k}}^{-1}{\bf b}
.

2.1
LU Decomposition versus Pseudo Inverse Solution

Avoiding the calculation of the inverse is not only useful to reduce the computational cost, but also imperative to make sure that the algorithm works when

{\bf A}_{B}
is singular. Notice that the selection of the entering variable in the simplex method does not consider if the new
{\bf A}_{B}
is full rank or not. As a matter of fact, the authors noticed that for Netlib benchmark problems, it is not unusual that
{\bf A}_{B}
is not full rank. For this paper’s implementation, LU decomposition is used to achieve this. Let

{\bf A}_{B^{k}}={\bf L}{\bf U},

(8)

where
{\bf L}
is a full rank permuted lower triangular matrix and
{\bf U}
is an upper triangular matrix with the same rank of
{\bf A}_{B^{k}}
. Therefore, if

{\bf A}_{B^{k}}
is not full rank,
{\bf U}
is not full rank, i.e., some diagonal elements of
{\bf U}
are zeros. Given the LU decomposition (
8
), the reduced cost vector can be calculated as follows. Let
\bar{{\bf p}}={\bf A}_{B^{k}}^{-{\rm T}}{\bf c}_{B^{k}}
, i.e.,

{\bf A}_{B^{k}}^{{\rm T}}\bar{{\bf p}}={\bf c}_{B^{k}}
. Thus,
\bar{{\bf p}}
is obtained by sequentially
solving two systems of linear equations

{\bf U}^{{\rm T}}{\bf p}={\bf c}_{B^{k}}\hskip 7.22743pt\text{and}\hskip 7.22743pt{\bf L}^{{\rm T}}\bar{{\bf p}}={\bf p}.

(9)

Hence, the reduced cost vector is obtained by computing

\bar{{\bf c}}_{N^{k}}={\bf c}_{N^{k}}-{\bf A}_{N^{k}}^{{\rm T}}\bar{{\bf p}}.

(10)

The iterate
{\bf x}^{k}={\bf A}_{B^{k}}^{-1}{\bf b}
can be obtained by sequentially solving two systems of linear equations as follows:

{\bf L}{\bf q}={\bf b}\hskip 7.22743pt\text{and}\hskip 7.22743pt{\bf U}{\bf x}^{k}={\bf q}.

(11)

When
{\bf A}_{B^{k}}
is not full rank, and some diagonal elements of
{\bf U}
are zeros, one may consider the use of the pseudo inverse of
{\bf A}_{B^{k}}
. A simple and careful
analysis shows that this would not work in some cases. The pseudo inverse is equivalent to the following process. Let
\bar{{\bf U}}
be the matrix that removes
rows with zero diagonal elements from
{\bf U}
and
\bar{{\bf q}}
be the vector that removes the corresponding elements in
{\bf q}
; then Equation (
11
) becomes
\bar{{\bf U}}{\bf x}^{k}=\bar{{\bf q}}
and the solution is given by

{\bf x}^{k}=\begin{cases}\bar{{\bf U}}^{{\rm T}}(\bar{{\bf U}}\bar{{\bf U}}^{{\rm T}})^{-1}\bar{{\bf q}}&\ \ {\mbox{if}}~~\bar{{\bf q}}\neq 0,\\
{\bf x}^{k}\in\bar{{\bf U}}^{\perp}&\ \ {\mbox{otherwise.}}\end{cases}

(12)

The matrix
\bar{{\bf U}}^{\perp}
can be obtained by using QR decomposition for
\bar{{\bf U}}
. One can easily see that the least squared solution
(
Ben-Isreael and Greville 2003
)
of (
12
) may not meet the equations corresponding to the deleted rows of
{\bf U}
.
Testing on some Netlib problems verified the analysis. The strategy used in this paper is to add a small
\epsilon
to the zero diagonal elements of
{\bf U}
when it is singular. This will avoid the difficulty in solving (
9
) and (
11
).

2.2
A Double Pivot Algorithm

The double pivot algorithm in this paper is based on
Yang 2020
. First, how the entering variables are selected is briefly describe. Let
C^{k}
be the index set defined as follows:

C^{k}\in\{j^{k}~|~\bar{c}_{j^{k}}<0\},

(13)

and the cardinality
|C^{k}|=p
. Clearly, if
\bar{{\bf c}}_{N^{k}}\geq{\bf 0}
, then
C^{k}=\emptyset
, and an optimizer is found. If
\bar{c}_{j^{k}}<0
for some

j^{k}\in C^{k}
, then an entering variable
x_{\jmath^{k}}
in the next vertex is chosen from the set of
\{j^{k}~|~\bar{c}_{j^{k}}<0\}
because by increasing
x_{\jmath^{k}}
, the objective function
{\bf c}^{{\rm T}}{\bf x}={\bf c}_{B^{k}}^{{\rm T}}{\bf x}_{B^{k}}+\bar{c}_{\jmath^{k}}x_{\jmath^{k}}
will be reduced. The first entering variable
x_{\jmath_{1}^{k}}
is selected by using Dantzig’s pivoting rule:

{\jmath_{1}^{k}}:=\{{\jmath_{1}^{k}}~|~\bar{c}_{\jmath_{1}^{k}}=\min_{j^{k}\in C^{k}}\bar{{\bf c}}_{j^{k}}\}.

(14)

If there is a tie, the minimum index of
{\jmath_{1}^{k}}
will be used to break the tie. Denote
\bar{{\bf b}}={\bf A}_{B^{k}}^{-1}{\bf b}
and
\bar{{\bf a}}_{\jmath^{k}}={\bf A}_{B^{k}}^{-1}{\bf A}_{\jmath^{k}}
, where
\jmath^{k}
is in
C^{k}
and determined by (
14
). Also, denote by
\bar{b}_{i}
the
i
th element of
\bar{b}
and by
\bar{a}_{j^{k},i}
the
i
th element of
\bar{{\bf a}}_{\jmath^{k}}
. Thus, the leaving variable for Dantzig’s pivoting rule is to select
x_{\imath_{1}^{k}}
that satisfies

x_{\imath_{1}^{k}}=\min_{i\in\{1,\ldots,m\}}\bar{b}_{i}/\bar{a}_{{\jmath_{1}^{k}},i},\hskip 7.22743pt\mbox{subject to}\hskip 7.22743pt\bar{a}_{{\jmath_{1}^{k}},i}>0.

(15)

If there is a tie, the minimum index of
{\imath_{1}^{k}}
will
be used to break the tie. The reduced cost value is given by
\bar{c}_{\imath_{1}^{k}}x_{\imath_{1}^{k}}
.

If the cardinality
|C^{k}|\geq 2
, the second entering variable
whose index is
\jmath_{2}^{k}
will maximize the step-size, i.e.,

x_{\jmath_{2}^{k}}=\max_{\bar{c}_{j^{k}}<0,\bar{c}_{j^{k}}\neq\bar{c}_{\jmath_{1}^{k}}}\Big\{\min_{i\in\{1,\ldots,m\}}\bar{b}_{i}/\bar{a}_{j^{k},i},\hskip 7.22743pt\mbox{subject to}\hskip 7.22743pt\bar{a}_{j^{k},i}>0\Big\}.

(16)

The leaving variable
x_{\imath_{2}^{k}}
is determined by the index that achieves the max-min value in (
16
). Given the entering and leaving variables determined by the longest step size rule, one can determine the next iterate
{\bf x}^{k+1}
and the reduced cost
\bar{c}_{\imath_{2}^{k}}x_{\imath_{2}^{k}}
.

This paper discusses two special cases of the double pivot algorithm. For the general case, given the two entering variables
x_{\jmath_{1}^{k}}
and
x_{\jmath_{2}^{k}}
, one needs to determine the two leaving variables which is equivalent to solving a linear programming problem with constraints in a two-dimensional space. Let
{\bf A}_{(\jmath_{1},\jmath_{2})}
be composed of the

\jmath_{1}
and
\jmath_{2}
columns of
{\bf A}_{N}
, and
\jmath_{1}
and
\jmath_{2}
be determined by (
14
) and (
16
). Let
\bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}={\bf A}_{B}^{-1}{\bf A}_{(\jmath_{1},\jmath_{2})}
and
\bar{{\bf c}}_{(\jmath_{1},\jmath_{2})}<{\bf 0}
be the two corresponding elements in
\bar{{\bf c}}_{N}
. For the two entering indexes
(\jmath_{1},\jmath_{2})\in C^{k}
satisfying

{\bf x}_{(\jmath_{1},\jmath_{2})}=(x_{\jmath_{1}},x_{\jmath_{2}})\geq{\bf 0}
, one needs

{\bf x}_{B^{k}}^{k+1}={\bf A}_{B^{k}}^{-1}{\bf b}-{\bf A}_{B^{k}}^{-1}{\bf A}_{N^{k}}{\bf x}_{N^{k}}=\bar{{\bf b}}-\bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}{\bf x}_{(\jmath_{1},\jmath_{2})}\geq{\bf 0}.

(17)

Observe that instead of using matrix inverse,
\bar{{\bf b}}
and
\bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}
are obtained by using LU decomposition and then solving the systems of linear equations discussed in Section
2.1
. Therefore, the problem of finding a new vertex is reduced to minimizing the following linear programming problem:

\displaystyle\begin{array}[]{ll}\min&\ \ \bar{{\bf c}}_{(\jmath_{1},\jmath_{2})}^{{\rm T}}{\bf x}_{(\jmath_{1},\jmath_{2})},\\
\mbox{\rm subject to}&\ \ \bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}{\bf x}_{(\jmath_{1},\jmath_{2})}\leq\bar{{\bf b}},\hskip 7.22743pt{\bf x}_{(\jmath_{1},\jmath_{2})}\geq{\bf 0}.\end{array}

Again, the vector
\bar{{\bf c}}_{(\jmath_{1},\jmath_{2})}
is obtained by using LU decomposition and solving the systems of linear equations discussed in Section
2.1
. The third merit criterion is then introduced, which is to
determine the values of the two entering variables to minimize the objective function under the constraints of (
2.2
). Remarks
1
and
2
formalize the pivoting strategy of the proposed algorithm.

Remark 1

Using multiple merit criteria to select entering variables has been proved to be an effective strategy to solve LP problems and has been used in randomized pivoting algorithms
(
Gartner et al. 1998
;
Kelner and Spielman 2006
)
. Since almost all popular deterministic simplex pivoting rules are proved not polynomial
(
Friedmann 2011
;
Goldfarb and Sit 1979
;
Jeroslow 1973
;
Paparrizos et al. 2008
)
, using a combined deterministic merit criteria to select entering variables may give some fresh ideas to find a strongly polynomial algorithm (defined in
Smale 1999
) to solve linear programming problems.

Remark 2

Using the longest step size rule to select an entering parameter will increase the chance to have a non-degenerate basic feasible solution because the entering variable is more likely to be greater than zero than any other criteria. Since the double pivoting rule will optimize the cost function, the step-sizes for the two pivot variables will not be all zeros if the longest step size is not zero. Therefore, the authors claim that the double pivot algorithm is degenerate-robust. This claim has been observed in numerical experiments to be discussed later.

Even though problem (
2.2
) can be solved using standard simplex algorithms or interior-point methods, there is a much more efficient technique
(
Vitor and Easton 2018
;
Vitor 2018
;
Vitor 2019
;
Vitor 2022
)
for this special LP problem, which is discussed in the next section.

2.3
The Slope Algorithm to Solve Two-Variable Linear Programs

The slope algorithm is a fast technique that runs in O
(m\log m)
time and can find both an optimal solution and an optimal basis of two-variable linear programs. The slope algorithm was first proposed by
Vitor and Easton 2018
and later improved by
Vitor 2018
;
Vitor 2019
;
Vitor 2022
. Observe that the slope algorithm can quickly solve problem (
2.2
). Formally, define a two-variable linear program (2VLP) as:

\displaystyle\begin{array}[]{ll}\max&{\bf c}^{\prime{\rm T}}{\bf x}^{\prime},\\
\mbox{\rm subject to}&{\bf A}^{\prime}{\bf x}^{\prime}\leq{\bf b}^{\prime},~~~~{\bf x}^{\prime}\geq{\bf 0},\end{array}

where
{\bf A}^{\prime}\in{\mathbb{R}}^{(m+2)\times 2}
,
{\bf b}^{\prime}\in{\mathbb{R}}^{m+2}
,

{\bf c}^{\prime}\in{\mathbb{R}}^{2}
are given, and
{\bf x}^{\prime}\in{\mathbb{R}}^{2}
is the
vector of decision variables. For a 2VLP,
A^{\prime}_{m+1,1}=A^{\prime}_{m+2,2}=-1
,

A^{\prime}_{m+1,2}=A^{\prime}_{m+2,1}=0
, and
b^{\prime}_{m+1}=b^{\prime}_{m+2}=0
.
Observe that these two constraints are exactly the nonnegative conditions of
(
2.2
). For simplicity, the slope algorithm assumes that
c^{\prime}_{1}>0
,

c^{\prime}_{2}>0
, and
{\bf b}^{\prime}_{i}\geq 0
for each
i\in\{1,2,...,m,m+1,m+2\}
.
One can easily see that problem (
2.2
) satisfies these assumptions.

Overall, the slope algorithm contrasts the ‘‘slope’’ formed by the objective
function coefficients of the 2VLP,
c^{\prime}_{1}
and
c^{\prime}_{2}
, with the ‘‘slope’’ of
every constraint in the problem. The slope of each constraint

i\in\{1,2,...,m,m+1,m+2\}
is defined by
\alpha_{i}
and can be computed as:

\alpha_{i}=\begin{cases}-2M&\text{if $A^{\prime}_{i,1}=0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}<0$}\\
-M+\frac{A^{\prime}_{i,2}}{A^{\prime}_{i,1}}&\text{if $A^{\prime}_{i,1}>0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}<0$}\\
-M&\text{if $A^{\prime}_{i,1}>0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}=0$}\\
\frac{A^{\prime}_{i,2}}{A^{\prime}_{i,1}}&\text{if $A^{\prime}_{i,1}>0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}>0$}\\
M&\text{if $A^{\prime}_{i,1}=0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}>0$}\\
M-\frac{A^{\prime}_{i,1}}{A^{\prime}_{i,2}}&\text{if $A^{\prime}_{i,1}<0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}>0$}\\
2M&\text{if $A^{\prime}_{i,1}<0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}=0$}\\
3M&\text{if $A^{\prime}_{i,1}=0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}=0$}\\
3M&\text{if $A^{\prime}_{i,1}<0\ \ \ \mbox{and}\ \ \ A^{\prime}_{i,2}<0$}\\
\end{cases}

(24)

where

M>\max{\Bigg\{M^{\prime},M^{\prime\prime},\frac{c^{\prime}_{2}}{c^{\prime}_{1}}\Bigg\}}

(25)

is a sufficiently large positive number and

M^{\prime}=\max\Bigg\{\Bigg|\frac{A^{\prime}_{i,1}}{A^{\prime}_{i,2}}\Bigg|:A^{\prime}_{i,2}\neq 0\ \ \forall i\in\{1,2,...,m,m+1,m+2\}\Bigg\}

(26)

M^{\prime\prime}=\max\Bigg\{\Bigg|\frac{A^{\prime}_{i,2}}{A^{\prime}_{i,1}}\Bigg|:A^{\prime}_{i,1}\neq 0\ \ \forall i\in\{1,2,...,m,m+1,m+2\}\Bigg\}.

(27)

Notice that
M
is used to determine some not well-defined slopes
and differentiate the order of constraints. Figure
1
shows
eight out of the nine types of constraints in a 2VLP (except
constraints where
A^{\prime}_{i,1}=0
and
A^{\prime}_{i,2}=0
since those
define the entire two-dimensional space) and their corresponding

\alpha
values. Furthermore, the reader may observe that viewing
the constraints in ascending order of the
\alpha
values defines a
counterclockwise orientation of the constraints.

Figure 1:
Eight out of Nine Types of Constraints in a 2VLP and their Corresponding
\alpha
Values

Algorithm
1
depicts the slope algorithm step by step.
The input to Algorithm
1
is a 2VLP and the method begins
by computing a sufficiently large positive number
M
, calculating the
‘‘slope’’
\alpha_{i}
of each constraint, and sorting the constraints in
ascending order according to
\alpha_{i}
. From there, the slope algorithm
finds two constraints,
\eta_{j^{\prime}}
and
\eta_{k^{\prime}}
, which slope falls in
between the slope of the cost coefficients
c^{\prime}_{1}
and
c^{\prime}_{2}
based on
the sorted order. The method then checks whether the given 2VLP is
unbounded or not. This can be done by the checking the presence/absence
of some specific constraints that define a ray of unboundedness. That is,
2VLP is unbounded if:

\begin{gathered}\alpha_{\eta_{j^{\prime}}}=-2M\ \ \text{and}\ \ \alpha_{\eta_{k^{\prime}}}\geq M,\ \ \text{or}\\
-2M<\alpha_{\eta_{j^{\prime}}}<-M\ \ \text{and}\ \ \alpha_{\eta_{k^{\prime}}}=2M,\ \ \text{or}\\
\alpha_{\eta_{j^{\prime}}}=-M\ \ \text{and}\ \ \alpha_{\eta_{k^{\prime}}}=2M,\ \ \text{or}\\
-2M<\alpha_{\eta_{j^{\prime}}}<-M\ \ \text{and}\ \ M<\alpha_{\eta_{k^{\prime}}}<2M,\ \ \text{and}\ \ \frac{A^{\prime}_{\eta_{j^{\prime}},2}}{A^{\prime}_{\eta_{j^{\prime}},1}}\leq\frac{A^{\prime}_{\eta_{k^{\prime}},2}}{A^{\prime}_{\eta_{k^{\prime}},1}}.\\
\end{gathered}

(28)

If the given 2VLP is bounded, the slope algorithm continues and finds
whether the intersection of constraints
\eta_{j^{\prime}}
and
\eta_{k^{\prime}}
is
feasible on every other constraint. If not feasible, the algorithm replaces
one of the two constraints with the constraint that violates the feasibility
check, and repeat the process until a pair of feasible constraints is found.
When this process is completed, the slope algorithm returns the optimal
solution and also the two constraints that intersect at the optimal basis.
That is, an optimal simplex basic feasible solution from where there does
not exist a feasible improving search direction. This is possible because
the slope algorithm finds a pair of constraints such that

\alpha_{\eta_{j^{\prime}}}<\frac{c^{\prime}_{2}}{c^{\prime}_{1}}\leq\alpha_{\eta_{k^{\prime}}}
and

\alpha_{\eta_{k^{\prime}}}-\alpha_{\eta_{j^{\prime}}}
is minimized. The reader is
encouraged to see
Vitor and Easton 2018
and
Vitor 2018
;
Vitor 2019
;
Vitor 2022
for additional theoretical results.

Implementation Details

Some implementation details, which are important for improving the efficiency and robustness of Algorithm
2
, are discussed in this section.

3.1
Pre-Process and Post-Process

Pre-process or pre-solver is a major factor that can significantly affect the numerical stability and computational efficiency of optimization algorithms. Many researchers have focused on this topic; for example,
Andersen and Andersen 1993
,
Brearley et al. 1975
,
Mahajan 2010
, and
Yang 2017
. In this paper, the pre-process of
Yang 2017
is used. With the implementation described in the pre-process, the post-process is simple. The MATLAB code of the pre-process and post-process is available in the Netlib benchmark library (
http://www.netlib.org/numeralgo/
) as part of the
na43
package
(
Yang 2017
)
.

3.2
Update
{\bf x}_{B}^{k}

Once the updated base and
{\bf A}_{B^{k+1}}
are available, one can update the basic feasible solution as
{\bf x}_{B^{k+1}}:={\bf A}_{B^{k+1}}^{-1}{\bf b}
. However, for many Netlib benchmark problems, singular or nearly singular
{\bf A}_{B^{k+1}}
are present. Thus, the computation of
{\bf x}_{B^{k+1}}
using this formula may result in some negative components due to numerical errors. A better implementation is as follows. From (
2
),

{\bf x}_{B^{k}}^{k+1}={\bf A}_{B^{k}}^{-1}{\bf b}-{\bf A}_{B^{k}}^{-1}{\bf A}_{N^{k}}{\bf x}_{N^{k}}=\bar{{\bf b}}-\bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}{\bf x}_{(\jmath_{1},\jmath_{2})}\geq{\bf 0}.

(29)

If there is only one negative element in
\bar{{\bf c}}_{N^{k}}
, then

{\bf x}_{B^{k}}^{k+1}={\bf A}_{B^{k}}^{-1}{\bf b}-{\bf A}_{B^{k}}^{-1}{\bf A}_{N^{k}}{\bf x}_{N^{k}}=\bar{{\bf b}}-\bar{{\bf A}}_{\jmath_{1}}x_{\jmath_{1}}\geq{\bf 0}.

(30)

Observe that
\bar{{\bf b}}
,
\bar{{\bf A}}_{\jmath_{1}}
, and
\bar{{\bf A}}_{(\jmath_{1},\jmath_{2})}
are computed by using LU decomposition for efficiency and robustness, and the details are discussed in Section
2.1
. To obtain
{\bf x}_{B^{k+1}}^{k+1}
from
{\bf x}_{B^{k}}^{k+1}
, one needs to remove the component of the leaving variable from
{\bf x}_{B^{k}}^{k+1}
and insert the entering
variable into
{\bf x}_{B^{k}}^{k+1}
.

3.3
Degenerate Solutions

Even though the double pivoting rule solves all cycling problems of small size listed in Section
4.3
, there are some Netlib benchmark problems which stays in degenerate solutions for a long time. This is a sign that the double pivoting rule may still have difficult to handle all cycling problems. During the process of the code development, if a degenerate basic feasible solution moves to another degenerate basic feasible solution and the objective function is not improved after an iteration, then Bland’s rule is applied
(
Bland 1977
)
. Still,
this implementation (using Bland’s rule) has difficult to solve the Netlib
benchmark problem QAP8 due to numerical errors. Inspired by Wolfe’s perturbation
method
(
Wolfe 1963
)
, the following perturbation is implemented: for a zero component in
{\bf x}_{B^{k}}
, a small positive perturbation to replace
the zero component is introduced. This strategy clearly improves the stability of the code even when Bland’s rule is not applied.

3.4
LU Decomposition

Normally for the simplex method, one would update the LU factorization with a rank-1 update (e.g., Forrest-Tomlin update
(
Forrest and Tomlin 1972
)
), which saves substantial time. But MATLAB does not have such an implementation yet. For the purpose of comparing the computational efficiency of Dantzig’s implementation and the double pivot algorithm, the general LU decomposition is implemented. This is not an optimal implementation, but it has the same effect on both algorithms; therefore, the efficiency comparison is still reasonable. However, the Forrest-Tomlin update will be considered in a future implementation.

The LU factorization can also be numerically unstable. This paper’s implementation uses a dynamical permutation for improving the stability. Besides, when the diagonal elements of
{\bf U}
become extremely small (close to zero), a positive perturbation is added to these elements. Computational experiments show the satisfactory numerical stability of the implementation.

4.1
Test on the Klee-Minty Cube Problems

The Klee-Minty cube and its variants have been used to show a serious drawback of popular simplex algorithms, such as steepest-edge pivoting rule, Dantzig’s pivoting rule, most improvement pivoting rule, etc. i.e., all these algorithms need an exponential number of iterations, in the worst case, to find an optimal solution for specially designed Klee-Minty cube problems. This section provides the test results of the double pivot algorithm for three variants
of the Klee-Minty cube
(
Greenberg 1997
;
Ibrahima 2013
;
Kitahara and Mizuno 2011
)
.

The first variant of the Klee-Minty cube is given by
Greenberg 1997
:

\displaystyle\begin{array}[]{ll}\min&\ \ -\sum_{i=1}^{m}2^{m-i}x_{i}\\
\mbox{subject to}&\ \ \left[\begin{array}[]{cccccc}1&0&0&\ldots&0&0\\
2^{2}&1&0&\ldots&0&0\\
2^{3}&2^{2}&1&\ldots&0&0\\
\vdots&\vdots&\vdots&\ddots&0&0\\
2^{m-1}&2^{m-2}&2^{m-3}&\ldots&1&0\\
2^{m}&2^{m-1}&2^{m-2}&\ldots&2^{2}&1\\
\end{array}\right]\left[\begin{array}[]{c}x_{1}\\
x_{2}\\
\vdots\\
\vdots\\
x_{m-1}\\
x_{m}\end{array}\right]\leq\left[\begin{array}[]{c}5\\
25\\
\vdots\\
\vdots\\
5^{m-1}\\
5^{m}\end{array}\right]\\
&\ \ x_{i}\geq 0\hskip 7.22743pti=1,\ldots,m.\end{array}

The optimizer is
[0,\ldots,0,5^{m}]
with an optimal objective function value of
-5^{m}
. The second variant of the Klee-Minty cube is given by
Ibrahima 2013

\displaystyle\begin{array}[]{ll}\min&\ \ -\sum_{i=1}^{m}10^{m-i}x_{i}\\
\mbox{subject to}&\ \ \sum_{j=1}^{i-1}10^{i-j}x_{j}+x_{i}\leq 100^{i-1}\hskip 7.22743pti=1,\ldots,m,\\

. Therefore, the double pivot algorithm is able to solve these problems with size as large as

Conclusions

This paper proposed a double pivot algorithm that combines the pivoting rule of
Yang 2020
and the slope algorithm of
Vitor and Easton 2018
and
Vitor 2018
;
Vitor 2019
;
Vitor 2022
. This paper’s research implemented the algorithm as a MATLAB code. Computational experiments tested the MATLAB code using a small set of cycling problems, three variants of the Klee-Minty problems, randomly generated LP problems, and Netlib benchmark test problems. A computational study compared the performances of the double pivot algorithm and the code that implemented Dantzig’s pivoting algorithm. The test results show that the double pivot algorithm performs better than Dantzig’s pivoting algorithm for large size randomly generated problems, while the latter performs better for small size randomly generated problems and
Netlib benchmark test problems.
