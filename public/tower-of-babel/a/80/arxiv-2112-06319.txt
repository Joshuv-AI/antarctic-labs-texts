On sketching approximations for symmetric Boolean CSPs
Joanna Boyland, Michael Hwang, Tarun Prasad, Noah Singer, Santhoshini Velusamy

Abstract
A Boolean maximum constraint satisfaction problem, Max-CSP ​ ( f ) \textsf{Max-CSP}(f) , is specified by a predicate f : { − 1 , 1 } k → { 0 , 1 } f:\{-1,1\}^{k}\to\{0,1\} . An n n -variable instance of Max-CSP ​ ( f ) \textsf{Max-CSP}(f) consists of a list of constraints, each of which applies f f to k k distinct literals drawn from the n n variables. For k = 2 k=2 , Chou, Golovnev, and Velusamy [ CGV20 ] obtained explicit ratios characterizing the n \sqrt{n} -space streaming approximability of every predicate. For k ≥ 3 k\geq 3 , Chou, Golovnev, Sudan, and Velusamy [ CGSV21 ] proved a general dichotomy theorem for n \sqrt{n} -space sketching algorithms: For every f f , there exists α ⁡ ( f ) ∈ ( 0 , 1 ] \alpha(f)\in(0,1] such that for every ϵ > 0 \epsilon>0 , Max-CSP ​ ( f ) \textsf{Max-CSP}(f) is ( α ⁡ ( f ) − ϵ ) (\alpha(f)-\epsilon) -approximable by an O ⁡ ( log ⁡ n ) O(\log n) -space linear sketching algorithm, but ( α ⁡ ( f ) + ϵ ) (\alpha(f)+\epsilon) -approximation sketching algorithms require Ω ⁡ ( n ) \Omega(\sqrt{n}) space. In this work, we give closed-form expressions for the sketching approximation ratios of multiple families of symmetric Boolean functions. Letting α k ′ = 2 − ( k − 1 ) ​ ( 1 − k − 2 ) ( k − 1 ) / 2 \alpha^{\prime}_{k}=2^{-(k-1)}(1-k^{-2})^{(k-1)/2} , we show that for odd k ≥ 3 k\geq 3 , α ⁡ ( k ​ AND ) = α k ′ \alpha(k\textsf{AND})=\alpha^{\prime}_{k} , and for even k ≥ 2 k\geq 2 , α ⁡ ( k ​ AND ) = 2 ​ α k + 1 ′ \alpha(k\textsf{AND})=2\alpha^{\prime}_{k+1} . Thus, for every k k , k ​ AND k\textsf{AND} can be ( 2 − o ⁡ ( 1 ) ) ​ 2 − k (2-o(1))2^{-k} -approximated by O ⁡ ( log ⁡ n ) O(\log n) -space sketching algorithms; we contrast this with a lower bound of Chou, Golovnev, Sudan, Velingker, and Velusamy [ CGS+22 ] implying that streaming ( 2 + ϵ ) ⋅ 2 − k (2+\epsilon)\cdot 2^{-k} -approximations require Ω ⁡ ( n ) \Omega(n) space! We also resolve the ratio for the “at-least- ( k − 1 ) (k-1) - 1 1 ’s” function for all even k k ; the “exactly- k + 1 2 \frac{k+1}{2} - 1 1 ’s” function for odd k ∈ { 3 , … , 51 } k\in\{3,\ldots,51\} ; and fifteen other functions. We stress here that for general f f , the dichotomy theorem in [ CGSV21 ] only implies that α ⁡ ( f ) \alpha(f) can be computed to arbitrary precision in 𝖯𝖲𝖯𝖠𝖢𝖤 \mathsf{PSPACE} , and thus closed-form expressions need not have existed a priori . Our analyses involve identifying and exploiting structural “saddle-point” properties of this dichotomy. Introduction

In this work, we consider the
streaming approximability
of various
Boolean constraint satisfaction problems
, and we begin by defining these terms. See
[
CGSV21
, §1.1-2]
for more details on the definitions.

1.1
Setup: The streaming approximability of Boolean CSPs

1.1.1
Boolean CSPs

Let
f:\{-1,1\}^{k}\to\{0,1\}
be a Boolean function. In an
n
-variable instance of the problem
\textsf{Max-CSP}(f)
, a
constraint
is a pair
C=(\mathbf{b},\mathbf{j})
, where
\mathbf{j}=(j_{1},\ldots,j_{k})\in[n]^{k}
is a
k
-tuple of distinct
indices
, and
\mathbf{b}=(b_{1},\ldots,b_{k})\in\{-1,1\}^{k}
is a
negation pattern
.

For Boolean vectors
\mathbf{a}=(a_{1},\ldots,a_{n}),\mathbf{b}=(b_{1},\ldots,b_{n})\in\{-1,1\}^{n}
, let
\mathbf{a}\odot\mathbf{b}
denote their
coordinate-wise product

(a_{1}b_{1},\ldots,a_{n}b_{n})
. An
assignment

\bm{\sigma}=(\sigma_{1},\ldots,\sigma_{n})\in\{-1,1\}^{n}
satisfies
C
iff
f(\mathbf{b}\odot\bm{\sigma}|_{\mathbf{j}})=1
, where
\bm{\sigma}|_{\mathbf{j}}
is the
k
-tuple
(\sigma_{j_{1}},\ldots,\sigma_{j_{k}})
(i.e.,
\bm{\sigma}
satisfies
C
iff
f(b_{1}\sigma_{j_{1}},\ldots,b_{k}\sigma_{j_{k}})=1
). An
instance

\Psi
of
\textsf{Max-CSP}(f)
consists of constraints
C_{1},\dots,C_{m}
with non-negative weights
w_{1},\ldots,w_{m}
where
C_{i}=(\mathbf{j}(i),\mathbf{b}(i))
and
w_{i}\in\mathbb{R}
for each
i\in[m]
; the
value

\textsf{val}_{\Psi}(\bm{\sigma})
of an assignment
\bm{\sigma}
to
\Psi
is the (weighted) fraction of constraints in
\Psi
satisfied by
\bm{\sigma}
, i.e.,
\textsf{val}_{\Psi}(\bm{\sigma})\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\tfrac{1}{W}\sum_{i\in[m]}w_{i}\cdot f(\mathbf{b}(i)\odot\bm{\sigma}|_{\mathbf{j}(i)})
, where
W=\sum_{i=1}^{m}w_{i}
. The
value

\textsf{val}_{\Psi}
of an instance
\Psi
is the maximum value of any assignment
\bm{\sigma}\in\{-1,1\}^{n}
, i.e.,
\textsf{val}_{\Psi}\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\max_{\bm{\sigma}\in\{-1,1\}^{n}}\textsf{val}_{\Psi}(\bm{\sigma})
.

1.1.2
Approximations to CSPs

For
\alpha\in[0,1]
, we consider the problem of
\alpha
-approximating
\textsf{Max-CSP}(f)
. In this problem, the goal of an algorithm
\mathcal{A}
is to, on input an instance
\Psi
, output an estimate
\mathcal{A}(\Psi)
such that with probability at least
\frac{2}{3}
,
\alpha\cdot\textsf{val}_{\Psi}\leq\mathcal{A}(\Psi)\leq\textsf{val}_{\Psi}
. For
\beta<\gamma\in[0,1]
, we also consider the closely related
(\beta,\gamma)\textsf{-Max-CSP}(f)
. In this problem, the input instance
\Psi
is promised to either satisfy
\textsf{val}_{\Psi}\leq\beta
or
\textsf{val}_{\Psi}\geq\gamma
, and the goal is to decide which is the case with probability at least
\frac{2}{3}
.

1.1.3
Streaming and sketching algorithms for CSPs

For various Boolean functions
f
, we consider algorithms which attempt to approximate
\textsf{Max-CSP}(f)
instances in the
(single-pass, insertion-only) space-
s
streaming setting
. Such algorithms can only use space
s
(which is ideally small, such as
O(\log n)
, where
n
is the number of variables in an input instance), and, when given as input a CSP instance
\Psi
, can only read the list of constraints in a single, left-to-right pass.

We also consider a (seemingly) weak class of streaming algorithms called
sketching algorithms
, where the algorithm’s output is determined by an length-
s
string called a “sketch” produced from the input stream, and the sketch itself has the property that the sketch of the concatenation of two streams can be computed from the sketches of the two component streams. (See
[
CGSV21
, §3.3]
for a formal definition.) A special case of sketching algorithms are
linear sketches
, where each sketch (i.e., element of
\{0,1\}^{s}
) encodes an element of a vector space and we perform vector addition to combine two sketches.

1.2
Prior work and motivations

1.2.1
Prior results on streaming and sketching
\textsf{Max-CSP}(f)

We first give a brief review of what is already known about the streaming and sketching approximability of
\textsf{Max-CSP}(f)
. For
f:\{-1,1\}^{k}\to\{0,1\}
, let
\rho(f)\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\Pr_{\mathbf{b}\sim\mathsf{Unif}(\{-1,1\}^{k})}[f(\mathbf{b})=1]
, where
\mathsf{Unif}(\{-1,1\}^{k})
denotes the uniform distribution on
\{-1,1\}^{k}
. For every
f
, the
\textsf{Max-CSP}(f)
problem has a trivial
\rho(f)
-approximation algorithm given by simply outputting
\rho(f)
since

. We refer to a function
f
as

for some class of algorithms (e.g., streaming or sketching algorithms with some space bound) if it cannot be
(\rho(f)+\epsilon)
-approximated for any constant
\epsilon>0
. Otherwise, we refer to

as
approximable
for the class of algorithms.

The first two CSPs whose

-space streaming approximabilities were resolved were

2
XOR
and
Max-
2

[

2

In two recent works

1.1.1

2.1
The Chou, Golovnev, Sudan, and Velusamy
[
CGSV21
]
framework for symmetric functions

In this section, we describe the Chou, Golovnev, Sudan, and Velusamy
[
CGSV21
]
framework for finding the optimal sketching approximation ratio of a symmetric Boolean function
f_{S,k}
.

Let
\Delta(\{-1,1\}^{k})
denote the space of all distributions on
\{-1,1\}^{k}
. For a distribution
\mathcal{D}\in\Delta(\{-1,1\}^{k})
and
\mathbf{x}\in\{-1,1\}^{k}
, we use
\mathcal{D}(\mathbf{x})
to denote the probability of sampling
\mathbf{x}
in
\mathcal{D}
. To a distribution
\mathcal{D}\in\Delta(\{-1,1\}^{k})
we associate a
canonical instance

\Psi_{\mathcal{D}}
of
\textsf{Max-CSP}(f_{S,k})
on
k
variables as follows. Let
\mathbf{j}=(1,\ldots,k)
. For every negation pattern
\mathbf{b}\in\{-1,1\}^{k}
,
\Psi_{\mathcal{D}}
contains the constraint
(\mathbf{b},\mathbf{j})
with weight
\mathcal{D}(\mathbf{b})
.

We say a distribution
\mathcal{D}\in\Delta(\{-1,1\}^{k})
is
symmetric
if all vectors of equal Hamming weight are equiprobable, i.e., for every
\mathbf{x},\mathbf{y}\in\{-1,1\}^{k}
such that
\operatorname{wt}(\mathbf{x})=\operatorname{wt}(\mathbf{y})
,
\mathcal{D}(\mathbf{x})=\mathcal{D}(\mathbf{y})
. Let
\Delta_{k}\subseteq\Delta(\{-1,1\}^{k})
denote the set of all symmetric distributions on
\{-1,1\}^{k}
. Given
\mathcal{D}\in\Delta_{k}
, let
\mathcal{D}\langle i\rangle\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\sum_{\mathbf{x}\in\{-1,1\}^{k}:\operatorname{wt}(\mathbf{x})=i}\mathcal{D}(\mathbf{x})
denote the total probability mass on vectors of Hamming weight
i
. Note that any vector
(\mathcal{D}\langle 0\rangle,\ldots,\mathcal{D}\langle k\rangle)
of nonnegative values summing to
1
uniquely determines a distribution
\mathcal{D}\in\Delta_{k}
; we write
\mathcal{D}=(\mathcal{D}\langle 0\rangle,\ldots,\mathcal{D}\langle k\rangle)
for notational convenience.

Let
\mathsf{Bern}(p)
represent a random variable which is
1
with probability
p
and
-1
with probability
1-p
. For
\mathcal{D}\in\Delta(\{-1,1\})^{k}
and
p\in[0,1]
, let

\lambda_{S}(\mathcal{D},p)\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathcal{D},\mathbf{b}\sim\mathsf{Bern}(p)^{k}}[f_{S,k}(\mathbf{a}\odot\mathbf{b})]=\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathsf{Bern}(p)^{k}}[\textsf{val}_{\Psi_{\mathcal{D}}}(\mathbf{b})]

(2.1)

denote the expected value of a “
p
-biased symmetric assignment” on
\mathcal{D}
’s canonical instance.
Also, for a symmetric distribution
\mathcal{D}\in\Delta_{k}
, we define its (scalar)
marginal

\mu(\mathcal{D})\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathcal{D}}[b_{1}]=\cdots=\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathcal{D}}[b_{k}].

(2.2)

In general,
\lambda_{S}
is linear in
\mathcal{D}
and degree-
k
in
p
, and
\mu
is linear in
\mathcal{D}
. For
\mathcal{D}\in\Delta_{k}
, we provide explicit formulas for
\lambda_{S}
and
\mu
in
Section

3
.

Roughly,
[
CGSV21
]
states that
\textsf{Max-CSP}(f_{S,k})
is hard to approximate in the sketching setting if there exist distributions
\mathcal{D}_{N},\mathcal{D}_{Y}\in\Delta_{k}
such that (1)
\mu(\mathcal{D}_{N})=\mu(\mathcal{D}_{Y})
and (2)
\mathcal{D}_{Y}
’s canonical instance is highly satisfied by the trivial (all-ones) assignment but (3)
\mathcal{D}_{N}
’s canonical instance is not well-satisfied by any “biased symmetric assignment”. To be precise, for
\mathcal{D}\in\Delta(\{-1,1\}^{k})
, let

\beta_{S}(\mathcal{D})\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\sup_{p\in[0,1]}\lambda_{S}(\mathcal{D},p)\text{ and }\gamma_{S}(\mathcal{D})\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\lambda_{S}(\mathcal{D},1),

(2.3)

and define

\alpha(f_{S,k})\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}\inf_{\mathcal{D}_{N},\mathcal{D}_{Y}\in\Delta_{k}:~\mu(\mathcal{D}_{N})=\mu(\mathcal{D}_{Y})}\left(\frac{\beta_{S}(\mathcal{D}_{N})}{\gamma_{S}(\mathcal{D}_{Y})}\right).

(2.4)

For every symmetric function
f_{S,k}
,
[
CGSV21
]
proves that
\alpha(f_{S,k})
is the optimal sketching approximation ratio for
\textsf{Max-CSP}(f_{S,k})
:

2.5
Combines
[
CGSV21
, Theorem 2.10 and Lemma 2.14]
.

Let
f_{S,k}:\{-1,1\}^{k}\to\{0,1\}
be a symmetric function. Then for every
\epsilon>0
, there is an linear sketching
(\alpha(f_{S,k})-\epsilon)
-approximation to
\textsf{Max-CSP}(f_{S,k})
in
O(\log n)
space, but any sketching
(\alpha(f_{S,k})+\epsilon)
-approximation to
\textsf{Max-CSP}(f_{S,k})
requires
\Omega(\sqrt{n})
space.

Remark
.

In the general case where
f:\{-1,1\}^{k}\to\{0,1\}
is not symmetric, the approximability of
f
is no longer characterized by
Eq.

2.4
. Instead,
[
CGSV21
]
requires taking an infimum over
all
(not necessarily symmetric) distributions
\mathcal{D}_{N},\mathcal{D}_{Y}\in\Delta(\{-1,1\})^{k}
. Moreover, a general distribution
\mathcal{D}\in\Delta(\{-1,1\})^{k}
no longer has a single scalar marginal (as in
Eq.

2.2
). Instead, we must consider a
vector
marginal
\bm{\mu}(\mathcal{D})=(\mu_{1},\ldots,\mu_{k})
with
i
-th component
\mu_{i}=\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathcal{D}}[b_{i}]
; correspondingly,
\mathcal{D}_{N}
and
\mathcal{D}_{Y}
are required to satisfy the constraint
\bm{\mu}(\mathcal{D}_{N})=\bm{\mu}(\mathcal{D}_{Y})
. These issues motivate our focus on
symmetric
functions in this paper. Since we need to consider only symmetric distributions in
Eq.

2.4
,
\mathcal{D}_{Y}
and
\mathcal{D}_{N}
are each parameterized by
k+1
variables (as opposed to
2^{k}
variables), and there is a single linear equality constraint (as opposed to
k
constraints).

2.2
Formulations of the optimization problem

In order to show that
\alpha(\textsf{$2$AND})=\frac{4}{9}
, Chou, Golovnev, Sudan, and Velusamy
[
CGSV21
, Example 1]
use the following reformulation of the optimization problem on the right hand side of
Eq.

2.4
. For a symmetric function
f_{S,k}
and
\mu\in[-1,1]
, let

\beta_{S,k}(\mu)=\inf_{\mathcal{D}_{N}\in\Delta_{k}:~\mu(\mathcal{D}_{N})=\mu}\beta_{S}(\mathcal{D}_{N})\text{ and }\gamma_{S,k}(\mu)=\sup_{\mathcal{D}_{Y}\in\Delta_{k}:~\mu(\mathcal{D}_{Y})=\mu}\gamma_{S}(\mathcal{D}_{Y});

(2.6)

then

\alpha(f_{S,k})=\inf_{\mu\in[-1,1]}\left(\frac{\beta_{S,k}(\mu)}{\gamma_{S,k}(\mu)}\right).

(2.7)

The optimization problem on the right-hand side of
Eq.

2.7
appears simpler than that of
Eq.

2.4
because it is univariate, but there is a hidden difficulty: Finding an explicit solution requires giving explicit formulas for
\beta_{S,k}(\mu)
and
\gamma_{S,k}(\mu)
. In the case of
\textsf{$2$AND}=f_{\{2\},2}
, Chou, Golovnev, Sudan, and Velusamy
[
CGSV21
]
show that
\gamma_{\{2\},2}(\mu)
is an explicit linear function of
\mu
; maximize the quadratic
\lambda_{\{2\}}(\mathcal{D}_{N},p)
over
p\in[0,1]
to find
\beta_{\{2\}}(\mathcal{D}_{N})
; and then minimize
\beta_{\{2\}}(\mathcal{D}_{N})
given
\mu(\mathcal{D}_{N})=\mu
to find
\beta_{\{2\},2}(\mu)
. However, while for general symmetric functions
f_{S,k}
we can describe
\gamma_{S,k}(\mu)
as an explicit piecewise linear function of
\mu
(see
Lemma

3.3
below), we do not know how to find closed forms for
\beta_{S,k}(\mu)
even for
3
AND
. Thus, in this work we introduce a different formulation of the optimization problem:

\alpha(f_{S,k})=\inf_{\mathcal{D}_{N}\in\Delta_{k}}\left(\frac{\beta_{S}(\mathcal{D}_{N})}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right).

(2.8)

This reformulation is valid because

\alpha(f_{S,k})=\inf_{\mu\in[-1,1],\mathcal{D}_{N}\in\Delta_{k}:~\mu(\mathcal{D}_{N})=\mu}\left(\frac{\beta_{S}(\mathcal{D}_{N})}{\gamma_{S,k}(\mu)}\right)=\inf_{\mathcal{D}_{N}\in\Delta_{k}}\left(\frac{\beta_{S}(\mathcal{D}_{N})}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right).

We view optimizing directly over
\mathcal{D}_{N}\in\Delta_{k}
as an important conceptual switch. In particular, our formulation emphasizes the calculation of
\beta_{S}(\mathcal{D}_{N})
as the centrally difficult feature, yet we can still take advantage of the relative simplicity of calculating
\gamma_{S,k}(\mu)
.

2.3
Our contribution: The max-min method

A priori
, solving the optimization problem on the right-hand side of
Eq.

2.8
still requires calculating
\beta_{S}(\mathcal{D}_{N})
, which involves maximizing a degree-
k
polynomial. To get around this difficulty, we have made a key discovery, which was not noticed by Chou, Golovnev, Sudan, and Velusamy
[
CGSV21
]
even in the
2
AND
case. Let
\mathcal{D}_{N}^{*}
minimize the right-hand side of
Eq.

2.8
, and
p^{*}
maximize
\lambda_{S}(\mathcal{D}_{N}^{*},\cdot)
. After substituting
\beta_{S}(\mathcal{D})=\sup_{p\in[0,1]}\lambda_{S}(\mathcal{D},p)
in
Eq.

2.8
, and applying the max-min inequality, we get

\displaystyle\alpha(f_{S,k})=\inf_{\mathcal{D}_{N}\in\Delta_{k}}\sup_{p\in[0,1]}\left(\frac{\lambda_{S}(\mathcal{D}_{N},p)}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right)

\displaystyle\geq\sup_{p\in[0,1]}\inf_{\mathcal{D}_{N}\in\Delta_{k}}\left(\frac{\lambda_{S}(\mathcal{D}_{N},p)}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right)

(2.9)

\displaystyle\geq\inf_{\mathcal{D}_{N}\in\Delta_{k}}\left(\frac{\lambda_{S}(\mathcal{D}_{N},p^{*})}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right)\,.

Given
p^{*}
, the right-hand side of
Eq.

2.9
is relatively easy to calculate, being a ratio of a linear and piecewise linear function of
\mathcal{D}_{N}
. Our discovery is that, in a wide variety of cases, the quantity on the right-hand side of
Eq.

2.9

equals

\alpha(f_{S,k})
; that is,
(\mathcal{D}_{N}^{*},p^{*})
is a
saddle point
of
\frac{\lambda_{S}(\mathcal{D}_{N},p)}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}
.
5
5

5

This term comes from the optimization literature; such points are also said to satisfy the “strong max-min property” (see, e.g.,
[
BV04
, pp. 115, 238]
). The saddle-point property is guaranteed by von Neumann’s minimax theorem for functions which are concave and convex in the first and second arguments, respectively, but this theorem and the generalizations we are aware of do not apply even to
3
AND
.

This yields a novel technique, which we call the “max-min method”, for finding a closed form for
\alpha(f_{S,k})
. First, we guess
\mathcal{D}_{N}^{*}
and
p^{*}
, and then, we show analytically that
\frac{\lambda_{S}(\mathcal{D}_{N},p)}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}
has a saddle point at
(\mathcal{D}_{N}^{*},p^{*})
and that
\lambda_{S}(\mathcal{D}_{N},p)
is maximized at
p^{*}
. These imply that
\frac{\lambda_{S}(\mathcal{D}_{N}^{*},p^{*})}{\gamma_{S,k}(\mu(\mathcal{D}_{N}^{*}))}
is a lower and upper bound on
\alpha(f_{S,k})
, respectively. For instance, in
Section

4
, in order to give a closed form for
\alpha(k\textsf{AND})
for odd
k
(i.e., the odd case of
Theorem

1.2
), we guess
\mathcal{D}_{N}^{*}\langle\frac{k+1}{2}\rangle=1
and
p^{*}=\frac{k+1}{2k}
(by using Mathematica for small cases), and then check the saddle-point and maximization conditions in two separate lemmas (
Lemmas

4.2
and
4.1
, respectively). Then, we show that
\alpha(k\textsf{AND})=\alpha^{\prime}_{k}
by analyzing the right hand side of the appropriate instantiation of
Eq.

2.9
. We use similar techniques for
k\textsf{AND}
for even
k
(also
Theorem

1.2
) and for various other cases in
Sections

5.3
,
5.1
and
5.2
.

In all of these cases, the
\mathcal{D}_{N}^{*}
we construct is supported on at most two distinct Hamming weights, which is the property which makes finding
\mathcal{D}_{N}^{*}
tractable (using computer assistance). However, this technique is not a “silver bullet”: it is not the case that the sketching approximability of every symmetric Boolean CSP can be exactly calculated by finding the optimal
\mathcal{D}_{N}^{*}
supported on two elements and using the max-min method. Indeed, (as mentioned in
Section

5.3
) we verify using computer assistance that this is not the case for
f_{\{3\},4}
.

Finally, we remark that the saddle-point property is precisely what defines the value
p^{*}
required for our simple classical algorithm for outputting approximately optimal assignments for
\textsf{Max-CSP}(f_{S,k})
where
f_{S,k}=\mathsf{Th}^{i}_{k}
is a threshold function (see
Theorem

7.7
).

Formulas for
\mu
,
\lambda_{S}
, and

In this section, we give explicit formulas for the quantities
\mu(\mathcal{D})
,
\lambda_{S}(\mathcal{D},p)
, and
\gamma_{S,k}(\mu)
(defined in
Eqs.

2.2
,

and
2.6
, respectively) which will be used throughout the rest of the paper. For
i\in[k]
, let
\epsilon_{i,k}\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}-1+\frac{2i}{k}
.

3.1
.

For any
\mathcal{D}\in\Delta_{k}
,

\mu(\mathcal{D})=\sum_{i=0}^{k}\epsilon_{i,k}\,\mathcal{D}\langle i\rangle.

Proof of
Lemma

3.1
.

By definition (
Eq.

2.2
),
\mu(\mathcal{D})=\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathcal{D}}[b_{1}]
. We use linearity of expectation; the contribution of weight-
i
vectors to
\mu(\mathcal{D})
is
\mathcal{D}\langle i\rangle\cdot\frac{1}{k}(i\cdot 1+(k-i)\cdot(-1))=\epsilon_{i,k}\,\mathcal{D}\langle i\rangle
.
∎

3.2
.

For any
\mathcal{D}\in\Delta_{k}
and
p\in[0,1]
, we have

\lambda_{S}(\mathcal{D},p)=\sum_{s\in S}\sum_{i=0}^{k}\left(\sum_{j=\max\{0,s-(k-i)\}}^{\min\{i,s\}}{i\choose j}{k-i\choose s-j}q^{s+i-2j}p^{k-s-i+2j}\right)\mathcal{D}\langle i\rangle

where
q\stackrel{{\scriptstyle\mathrm{\small def}}}{{=}}1-p
.

Proof.

By linearity of expectation and symmetry, it suffices to fix
s
and
i
and calculate, given a fixed string
\mathbf{a}=(a_{1},\ldots,a_{k})
of Hamming weight
i
and a random string
\mathbf{b}=(b_{1},\ldots,b_{k})\sim\mathsf{Bern}(p)^{k}
, the probability of the event
\operatorname{wt}(\mathbf{a}\odot\mathbf{b})=s
.

Let
A=\textsf{supp}(\mathbf{a})=\{t\in[k]:a_{t}=1\}
and similarly
B=\textsf{supp}(\mathbf{b})
. We have
|A|=i
and

s=\operatorname{wt}(\mathbf{a}\odot\mathbf{b})=|A\cap B|+|([k]\setminus A)\cap([k]\setminus B)|.

Let
j=|A\cap B|
, and consider cases based on
j
.

Given fixed
j
, we must have
|A\cap B|=j
and
|([k]\setminus A)\cap([k]\setminus B)|=s-j
. Thus if
j
satisfies
j\leq i,s-j\leq k-i,j\geq 0,j\leq s
, we have
\binom{i}{j}
choices for
A\cap B
and
\binom{k-i}{s-j}
choices for
([k]\setminus A)\cap([k]\setminus B)
; together, these completely determine
B
. Moreover
\operatorname{wt}(\mathbf{b})=|B|=|B\cap A|+|B\cap([k]\setminus A)|=j+(k-i)-(s-j)=k-s-i+2j
, yielding the desired formula.
∎

3.3
.

Let
S\subseteq[k]
, and let

\gamma_{S,k}(\mu)=\begin{cases}\frac{1+\mu}{1+\epsilon_{s,k}}&\mu\in[-1,\epsilon_{s,k})\\
1&\mu\in[\epsilon_{s,k},\epsilon_{t,k}]\\
\frac{1-\mu}{1-\epsilon_{t,k}}&\mu\in(\epsilon_{t,k},1]\end{cases}

(which also equals
\min\left\{\frac{1+\mu}{1+\epsilon_{s,k}},1,\frac{1-\mu}{1-\epsilon_{t,k}}\right\}
).

Proof.

For
\mu\in[-1,1]

\gamma_{S,k}(\mu)=\sup_{\mathcal{D}_{Y}\in\Delta_{k}:\mu(\mathcal{D}_{Y})=\mu}\gamma_{S}(\mathcal{D}_{Y}),

where by

2.3

\gamma_{S}(\mathcal{D}_{Y})=\sum_{i\in S}\mathcal{D}_{Y}\langle i\rangle
. For
\mathcal{D}_{Y}\in\Delta_{k}
, let
\textsf{supp}(\mathcal{D}_{Y})=\{i\in[k]:\mathcal{D}_{Y}\langle i\rangle>0\}
. We handle cases based on
\mu
.

Case 1:
\mu\in[-1,\epsilon_{s,k}]
.

Our strategy is to reduce to the case
\textsf{supp}(\mathcal{D}_{Y})\subseteq\{0,s\}
while preserving the marginal
\mu
and (non-strictly) increasing the value of
\gamma_{S}
.

Consider the following operation on a distribution
\mathcal{D}_{Y}\in\Delta_{k}
: For
u<v<w\in[k]
, increase
\mathcal{D}_{Y}\langle u\rangle
by
\mathcal{D}_{Y}\langle v\rangle\,\frac{w-v}{w-u}
, increase
\mathcal{D}_{Y}\langle w\rangle
by
\mathcal{D}_{Y}\langle v\rangle\,\frac{v-u}{w-u}
, and set
\mathcal{D}_{Y}\langle v\rangle
to zero. Note that this results in a new distribution with the same marginal, since

\mathcal{D}_{Y}\langle v\rangle\frac{w-v}{w-u}\epsilon_{u,k}+\mathcal{D}_{Y}\langle v\rangle\frac{v-u}{w-u}\epsilon_{w,k}=\mathcal{D}_{Y}\langle v\rangle\,\epsilon_{v,k}.

Given an initial distribution
\mathcal{D}_{Y}
, we can apply this operation to zero out
\mathcal{D}_{Y}\langle v\rangle
for
v\in\{1,\ldots,s-1\}
by redistributing to
\mathcal{D}_{Y}\langle 0\rangle
and
\mathcal{D}_{Y}\langle s\rangle
, preserving the marginal and only increasing the value of
\gamma_{S}
(since
v\not\in S
while
s\in S
). Similarly, we can redistribute
\mathcal{D}_{Y}\langle v\rangle
to
\mathcal{D}_{Y}\langle t\rangle
and
\mathcal{D}_{Y}\langle k\rangle
when
v\in\{t+1,\ldots,k-1\}
, and to
\mathcal{D}_{Y}\langle s\rangle
and
\mathcal{D}_{Y}\langle t\rangle
when
v\in\{s+1,\ldots,t-1\}
. Thus, we need only consider the case
\textsf{supp}(\mathcal{D})\subseteq\{0,s,t,k\}
. We assume for simplicity that
0,s,t,k
are distinct.

By definition of
\epsilon_{i,k}
we have

\mu(\mathcal{D})=-\mathcal{D}_{Y}\langle 0\rangle+\mathcal{D}_{Y}\langle s\rangle\left(-1+\frac{2s}{k}\right)+\mathcal{D}_{Y}\langle t\rangle\left(-1+\frac{2t}{k}\right)+\mathcal{D}_{Y}\langle k\rangle\leq-1+\frac{2s}{k}

(by assumption for this case). Substituting
\mathcal{D}_{Y}\langle s\rangle=1-\mathcal{D}_{Y}\langle 0\rangle-\mathcal{D}_{Y}\langle t\rangle-\mathcal{D}_{Y}\langle k\rangle
and multiplying through by
\frac{k}{2}
, we have

k\mathcal{D}_{Y}\langle k\rangle-s\mathcal{D}_{Y}\langle 0\rangle-s\mathcal{D}_{Y}\langle t\rangle-s\mathcal{D}_{Y}\langle k\rangle+t\mathcal{D}_{Y}\langle t\rangle\leq 0;

defining
\delta=\mathcal{D}_{Y}\langle t\rangle(\frac{t}{s}-1)+\mathcal{D}_{Y}\langle k\rangle(\frac{k}{s}-1)
, we can rearrange to get
\mathcal{D}_{Y}\langle 0\rangle\geq\delta
. Then given
\mathcal{D}_{Y}
, we can zero out
\mathcal{D}_{Y}\langle t\rangle
and
\mathcal{D}_{Y}\langle k\rangle
, decrease
\mathcal{D}_{Y}\langle 0\rangle
by
\delta
, and correspondingly increase
\mathcal{D}_{Y}\langle s\rangle
by
\mathcal{D}_{Y}\langle t\rangle+\mathcal{D}_{Y}\langle k\rangle+\delta
. This preserves the marginal since

(\delta+\mathcal{D}_{Y}\langle t\rangle+\mathcal{D}_{Y}\langle k\rangle)\,\epsilon_{s,k}=-\delta+\mathcal{D}_{Y}\langle t\rangle\,\epsilon_{t,k}+\mathcal{D}_{Y}\langle k\rangle

and can only increase
\gamma_{S}
.

Thus, it suffices to only consider the case
\textsf{supp}(\mathcal{D}_{Y})\subseteq\{0,s\}
. This uniquely determines
\mathcal{D}_{Y}
(because
\mu
is fixed); we have
\mathcal{D}_{Y}\langle 0\rangle=\frac{\epsilon_{s,k}-\mu}{\epsilon_{s,k}+1}
and
\mathcal{D}_{Y}\langle s\rangle=\frac{1+\mu}{\epsilon_{s,k}+1}
, yielding the desired value of
\gamma_{S}
.

Case 2:
\mu\in[\epsilon_{s,k},\epsilon_{t,k}]
.

We simply construct
\mathcal{D}_{Y}
with
\mathcal{D}_{Y}\langle s\rangle=\frac{\epsilon_{t,k}-\mu}{\epsilon_{s,k}-\epsilon_{t,k}}
and
\mathcal{D}_{Y}\langle t\rangle=\frac{\mu-\epsilon_{s,k}}{\epsilon_{s,k}-\epsilon_{t,k}}
; we have
\mu(\mathcal{D}_{Y})=\mu
and
\gamma_{S}(\mathcal{D}_{Y})=1
.

Case 3:
\mu\in[\epsilon_{t,k},1]
.

Following the symmetric logic to Case 1, we consider
\mathcal{D}_{Y}
supported on
\{t,k\}
and set
\mathcal{D}_{Y}\langle t\rangle=\frac{1-\mu}{1-\epsilon_{t,k}}
and
\mathcal{D}_{Y}\langle k\rangle=\frac{\mu-\epsilon_{t,k}}{1-\epsilon_{t,k}}
, yielding
\mu(\mathcal{D}_{Y})=\mu
and
\gamma_{S}(\mathcal{D}_{Y})=\mathcal{D}_{Y}\langle t\rangle
.
∎

We prove

using the max-min method. We rely on the following proposition which is a simple inequality for optimizing ratios of linear functions, which we prove in

:

4.5
.

Let
f:\mathbb{R}^{n}\to\mathbb{R}
be defined by the equation
f(\mathbf{x})=\frac{\mathbf{a}\cdot\mathbf{x}}{\mathbf{b}\cdot\mathbf{x}}
for some
\mathbf{a},\mathbf{b}\in\mathbb{R}_{\geq 0}^{n}
. For every
\mathbf{y}(1),\ldots,\mathbf{y}(r)\in\mathbb{R}_{\geq 0}^{n}
, and every
\mathbf{x}=\sum_{i=1}^{r}\alpha_{i}\mathbf{y}(i)
with each

. In particular, taking

and
\mathbf{y}(1),\ldots,\mathbf{y}(n)
as the standard basis for
\mathbb{R}^{n}
, for every
\mathbf{x}\in\mathbb{R}_{\geq 0}^{n}

.

Proof of
Lemma

.

First, suppose

is odd. Set
p^{*}=\frac{1}{2}+\frac{1}{2k}=\frac{k+1}{2k}
. We want to show that

\displaystyle\leq\inf_{\mathcal{D}_{N}\in\Delta_{k}}\frac{\lambda_{\{k\}}(\mathcal{D}_{N},p^{*})}{\gamma_{\{k\},k}(\mu(\mathcal{D}_{N}))}

and
4.4

By definition of

4.6

Similarly, in the case where

To prove
Lemmas

7.2
and
7.1
, we require a bit more setup. Adapting notation from
[
CGSV21
, §4.2]
, given an instance
\Psi
of
\textsf{Max-CSP}(\mathsf{Th}^{i}_{k})
and a “negation pattern”
\mathbf{a}=(a_{1},\ldots,a_{n})\in\{-1,1\}^{n}
for the variables, let
\Psi^{\mathbf{a}}
be the instance which results from
\Psi
by “flipping” the variables according to
\mathbf{a}
(formally, each constraint
(\mathbf{b},\mathbf{j})
is replaced with
(\mathbf{b}\odot\mathbf{a}|_{\mathbf{j}},\mathbf{j})
). We summarize the useful properties of this operation in the following claim:

7.5
.

Let
\Psi
be an instance of
\textsf{Max-CSP}(\mathsf{Th}^{i}_{k})
and
\mathbf{a}=(a_{1},\ldots,a_{n})\in\{-1,1\}^{n}
. Then:

i.

For each
i\in[n]
,
\mathsf{diff}_{i}(\Psi^{\mathbf{a}})=a_{i}\mathsf{diff}_{i}(\Psi)
.

ii.

\textsf{bias}(\Psi)=\textsf{bias}(\Psi^{\mathbf{a}})
.

iii.

For any
\bm{\sigma}\in\{-1,1\}^{n}
,
\textsf{val}_{\Psi^{\mathbf{a}}}(\bm{\sigma})=\textsf{val}_{\Psi}(\mathbf{a}\odot\bm{\sigma})
.

iv.

\textsf{val}_{\Psi^{\mathbf{a}}}=\textsf{val}_{\Psi}
.

Proof.

For
Item

i
, we have

\displaystyle\mathsf{diff}_{i}(\Psi^{\mathbf{a}})

\displaystyle=\sum_{\ell\in[m]\text{ s.t. }j(\ell)_{t}=i\text{ for some }t\in[k]}a_{j(\ell)_{t}}b(\ell)_{t}w_{\ell}

(definition of
\mathsf{diff}_{i}
)

\displaystyle=a_{i}\;\sum_{\ell\in[m]\text{ s.t. }j(\ell)_{t}=i\text{ for some }t\in[k]}b(\ell)_{t}w_{\ell}

\displaystyle=a_{i}\mathsf{diff}_{i}(\Psi).

(definition of
\mathsf{diff}_{i}
)

Item

ii
follows immediately from
Item

i
and the definition
\textsf{bias}(\Psi)=\frac{1}{kW}\sum_{i=1}^{n}|\mathsf{diff}_{i}(\Psi)|
. For
Item

iii
, we have

\displaystyle\textsf{val}_{\Psi^{\mathbf{a}}}(\bm{\sigma})

\displaystyle=\frac{1}{W}\sum_{i\in[m]}w_{i}\mathsf{Th}^{i}_{k}((\mathbf{b}(i)\odot\mathbf{a}|_{\mathbf{j}(i)})\odot\bm{\sigma}|_{\mathbf{j}(i)})

(definitions of
\Psi^{\mathbf{a}}
and
val
)

\displaystyle=\frac{1}{W}\sum_{i\in[m]}w_{i}\mathsf{Th}^{i}_{k}(\mathbf{b}(i)\odot(\bm{\sigma}\odot\mathbf{a})|_{\mathbf{j}(i)})

\displaystyle=\textsf{val}_{\Psi}(\bm{\sigma}\odot\mathbf{a}).

(definition of
val
)

Finally,
Item

iv
follows from
Item

iii
and the fact that
\{\bm{\sigma}:\bm{\sigma}\in\{-1,1\}^{n}\}=\{\bm{\sigma}\odot\mathbf{a}:\bm{\sigma}\in\{-1,1\}^{n}\}
:

\textsf{val}_{\Psi^{\mathbf{a}}}=\max_{\bm{\sigma}\in\{-1,1\}^{n}}\textsf{val}_{\Psi^{\mathbf{a}}}(\bm{\sigma})=\max_{\bm{\sigma}\in\{-1,1\}^{n}}\textsf{val}_{\Psi}(\bm{\sigma}\odot\mathbf{a})=\max_{\bm{\sigma}\in\{-1,1\}^{n}}\textsf{val}_{\Psi}(\bm{\sigma})=\textsf{val}_{\Psi}.

∎

Also, given an instance
\Psi
, we define its “symmetrized canonical distribution”
\mathcal{D}^{\mathrm{sym}}_{\Psi}\in\Delta_{k}
to be the distribution obtained by sampling a constraint at random from
\Psi
and outputting its “randomly permuted negation pattern”. Formally, let
\mathsf{S}_{k}
denote the set of permutations
[k]\to[k]
. For a vector
\mathbf{b}=(b_{1},\ldots,b_{k})\in\{-1,1\}^{k}
and a permutation
\bm{\pi}\in\mathsf{S}_{k}
, let
\bm{\pi}(\mathbf{b})=(b_{\bm{\pi}(1)},\ldots,b_{\bm{\pi}(k)})
. Let
C(i)=(\mathbf{b}(i),\mathbf{j}(i))
denote the
i
-th constraint of
\Psi
, with weight
w_{i}
, and let
W=\sum_{i=1}^{m}w_{i}
be the total weight. To sample a random vector from
\mathcal{D}^{\mathrm{sym}}_{\Psi}
, we sample
i\in[m]
with probability
w_{i}/W
, sample a permutation
\bm{\pi}\sim\mathsf{Unif}(\mathsf{S}_{k})
, and output
\bm{\pi}(\mathbf{b}(i))
. The useful properties of
\mathcal{D}^{\mathrm{sym}}_{\Psi}
are summarized in the following claim:

7.6
.

Let
\Psi
be an instance of
\textsf{Max-CSP}(\mathsf{Th}^{i}_{k})
. Then:

i.

For any
p\in[0,1]
,
\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{n}}[\textsf{val}_{\Psi}(\mathbf{a})]=\lambda_{S}(\mathcal{D}^{\mathrm{sym}}_{\Psi},p)
.

ii.

\mu(\mathcal{D}^{\mathrm{sym}}_{\Psi})=\frac{1}{kW}\sum_{i=1}^{n}\mathsf{diff}_{i}(\Psi)\leq\textsf{bias}(\Psi)
.

iii.

If
\mathsf{diff}_{i}(\Psi)\geq 0
for all
i\in[n]
, then
\mu(\mathcal{D}^{\mathrm{sym}}_{\Psi})=\textsf{bias}(\Psi)
.

Proof.

We begin with
Item

i
. Fix a constraint
(\mathbf{b},\mathbf{j})
. We make two observations. Firstly, if we sample
\mathbf{a}\sim\mathsf{Bern}(p)^{n}
, the distribution of
\mathbf{a}|_{\mathbf{j}}
is identical to
\mathsf{Bern}(p)^{k}
. Secondly, for a fixed vector
\mathbf{b}\in\{-1,1\}^{k}
, if we sample
\mathbf{a}\sim\mathsf{Bern}(p)^{k}
and
\bm{\pi}\sim\mathsf{Unif}(\mathsf{S}_{k})
, the distributions of
\bm{\pi}(\mathbf{b})\odot\mathbf{a}
and
\bm{\pi}(\mathbf{b}\odot\mathbf{a})
are identical. Thus, we have

\displaystyle\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{n}}[\mathsf{Th}^{i}_{k}(\mathbf{b}(i)\odot\mathbf{a}|_{\mathbf{j}})]

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{k}}[\mathsf{Th}^{i}_{k}(\mathbf{b}\odot\mathbf{a})]

(first observation)

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{k},\bm{\pi}\sim\mathsf{Unif}(\mathsf{S}_{k})}[\mathsf{Th}^{i}_{k}(\bm{\pi}(\mathbf{b}\odot\mathbf{a}))]

(symmetry of
\mathsf{Th}^{i}_{k}
)

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{k},\bm{\pi}\sim\mathsf{Unif}(\mathsf{S}_{k})}[\mathsf{Th}^{i}_{k}(\bm{\pi}(\mathbf{b})\odot\mathbf{a})].

(second observation)

Thus, by linearity of expectation, we have
\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{n}}[\textsf{val}_{\Psi}(\mathbf{a})]=\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p)^{k},\mathbf{b}\sim\mathcal{D}^{\mathrm{sym}}_{\Psi}}[\mathsf{Th}^{i}_{k}(\mathbf{b}\odot\mathbf{a})]=\lambda_{S}(\mathcal{D}^{\mathrm{sym}}_{\Psi},p)
, as desired.

For
Item

ii
, we have

\displaystyle\frac{1}{kW}\sum_{i=1}^{n}\mathsf{diff}_{i}(\Psi)

\displaystyle=\frac{1}{kW}\sum_{\ell=1}^{m}w_{\ell}\sum_{t=1}^{k}b(\ell)_{t}

(definition of
\mathsf{diff}_{i}(\Psi)
)

\displaystyle=\frac{1}{W}\sum_{\ell=1}^{m}w_{\ell}\mathop{\mathbb{E}}_{\bm{\pi}\sim\mathsf{S}_{k}}[\pi(\mathbf{b})_{1}]

(where
\bm{\pi}(\mathbf{b})=(\pi(\mathbf{b})_{1},\ldots,\pi(\mathbf{b})_{k})
)

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{b}\sim\mathcal{D}^{\mathrm{sym}}_{\Psi}}[b_{1}]

(definition of
\mathcal{D}^{\mathrm{sym}}_{\Psi}
)

\displaystyle=\mu(\mathcal{D}^{\mathrm{sym}}_{\Psi}).

(definition of
\mu
)

Finally,
Item

iii
follows immediately from
Item

ii
and the definition
\textsf{bias}(\Psi)=\frac{1}{kW}\sum_{i=1}^{n}|\mathsf{diff}_{i}(\Psi)|
.
∎

Finally, we state another consequence of
Lemma

7.1
— a simple randomized,
O(n)
-time-and-space streaming algorithm for
outputting
approximately-optimal assignments when the max-min method applies.

7.7
.

Let
\mathsf{Th}^{i}_{k}
be a threshold function and
p^{*}\in[0,1]
be such that the max-min method applies, i.e.,

\alpha(\mathsf{Th}^{i}_{k})=\inf_{\mathcal{D}_{N}\in\Delta_{k}}\left(\frac{\lambda_{S}(\mathcal{D}_{N},p^{*})}{\gamma_{S,k}(\mu(\mathcal{D}_{N}))}\right).

Then the following algorithm, on input
\Psi
, outputs an assignment with expected value at least
\alpha(\mathsf{Th}^{i}_{k})\cdot\textsf{val}_{\Psi}
: Assign every variable to
1
if
\mathsf{diff}_{i}(\Psi)\geq 0
, and
-1
otherwise, and then flip each variable’s assignment independently with probability
p^{*}
.

Proof.

Let
p^{*}
be as in the theorem statement, and define
\mathbf{maj}
as in the proof of
Lemma

7.2
. We output the assignment
\mathbf{maj}\odot\mathbf{a}
for
\mathbf{a}\sim\mathsf{Bern}(p^{*})^{n}
, and our goal is to show that its expected value is at least
\alpha(\mathsf{Th}^{i}_{k})\textsf{val}_{\Psi}
.

Our assumption that the max-min method applies asserts in particular that

\lambda_{S}(\mathcal{D}^{\mathrm{sym}}_{\Psi^{\mathbf{maj}}},p^{*})\geq\alpha(\mathsf{Th}^{i}_{k})\gamma_{S,k}(\mu(\mathcal{D}^{\mathrm{sym}}_{\Psi^{\mathbf{maj}}})).

(7.8)

Thus our expected output value is

\displaystyle\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p^{*})}[\textsf{val}_{\Psi}(\mathbf{maj}\odot\mathbf{a})]

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{a}\sim\mathsf{Bern}(p^{*})}[\textsf{val}_{\Psi^{\mathbf{maj}}}(\mathbf{a})]

(
Item

iii
of
Proposition

7.5
)

\displaystyle=\lambda_{S}(\mathcal{D}^{\mathrm{sym}}_{\Psi^{\mathbf{maj}}},p^{*})

(
Item

i
of
Proposition

7.6
)

\displaystyle\geq\alpha(\mathsf{Th}^{i}_{k})\gamma_{S,k}(\mu(\mathcal{D}^{\mathrm{sym}}_{\Psi^{\mathbf{maj}}}))

(
Eq.

7.8
)

\displaystyle=\alpha(\mathsf{Th}^{i}_{k})\gamma_{S,k}(\textsf{bias}(\Psi))

(

\displaystyle\geq\alpha(\mathsf{Th}^{i}_{k})\textsf{val}_{\Psi},

Discussion

In this paper, we introduce the max-min method and use it to resolve the streaming approximability of a wide variety of symmetric Boolean CSPs (including infinite families such as
\textsf{Max-}k\textsf{AND}
for all
k
, and
\mathsf{Th}_{k}^{k-1}
for all even
k
). However, these techniques are in a sense “ad hoc” since we use computer assistance to guess the optimal solution for our optimization problem. We leave the question of whether the max-min method can be applied to determine the sketching approximability for all symmetric Boolean CSPs as an interesting open problem.

Separately, we also establish that the techniques developed in
[
CGSV21
]
are not sufficient to characterize the
streaming
approximability of all CSPs. Indeed, we show that their streaming lower bound based on “padded one-wise pairs” cannot match the approximation ratio of their optimal sketching algorithm for
Max-
3
AND
. While we believe that no
o(\sqrt{n})
-space streaming algorithm can beat their sketching algorithm for
Max-
3
AND
, proving this will require new techniques.

Proof of
Proposition

4.5
.

Firstly, we show that it suffices WLOG to take the special case where
r=n
and
\mathbf{y}(1),\ldots,\mathbf{y}(n)
is the standard basis for
\mathbb{R}^{n}
. Indeed, assume the special case and note that for a general case, we can let
\mathbf{a}^{\prime}=(\mathbf{a}\cdot\mathbf{y}(1),\ldots,\mathbf{a}\cdot\mathbf{y}(r))
,
\mathbf{b}^{\prime}=(\mathbf{b}\cdot\mathbf{y}(1),\ldots,\mathbf{b}\cdot\mathbf{y}(r))
,
\mathbf{x}^{\prime}=(x_{1},\ldots,x_{r})
, and let
\mathbf{y}^{\prime}(1),\ldots,\mathbf{y}^{\prime}(r)
be the standard basis for
\mathbb{R}^{r}
. Then
\mathbf{x}^{\prime}=\sum_{i=1}^{r}\alpha_{i}\mathbf{y}^{\prime}(i)
and

f(\mathbf{x})=\frac{\sum_{i=1}^{r}(\mathbf{a}\cdot\mathbf{y}(i))\alpha_{i}}{\sum_{i=1}^{r}(\mathbf{b}\cdot\mathbf{y}(i))\alpha_{i}}=\frac{\mathbf{a}^{\prime}\cdot\mathbf{x}^{\prime}}{\mathbf{b}^{\prime}\cdot\mathbf{x}^{\prime}}\geq\min_{i\in[r]}\frac{\mathbf{a}^{\prime}\cdot\mathbf{y}^{\prime}(i)}{\mathbf{b}^{\prime}\cdot\mathbf{y}^{\prime}(i)}=\min_{i\in[r]}\frac{\mathbf{a}\cdot\mathbf{y}(i)}{\mathbf{b}\cdot\mathbf{y}(i)}.

Now we prove the special case: Assume
r=n
and
\mathbf{y}(1),\ldots,\mathbf{y}(n)
is the standard basis for
\mathbb{R}^{n}
. We have
f(\mathbf{y}(i))=\frac{a_{i}}{b_{i}}
. Assume WLOG that
f(\mathbf{y}(1))=\min\{f(\mathbf{y}(i)):i\in[n]\}
, i.e.,
\frac{a_{1}}{b_{1}}\leq\frac{a_{i}}{b_{i}}
for all
i\in[n]
. Then
a_{i}\geq\frac{a_{1}b_{i}}{b_{1}}
for all
i\in[n]
, so

\mathbf{a}\cdot\mathbf{x}\geq\sum_{i=1}^{n}\frac{a_{1}b_{i}}{b_{1}}\alpha_{i}=\frac{a_{1}}{b_{1}}(\mathbf{b}\cdot\mathbf{x}).

Hence

f(\mathbf{x})=\frac{\mathbf{a}\cdot\mathbf{x}}{\mathbf{b}\cdot\mathbf{x}}\geq\frac{a_{1}}{b_{1}}=f(\mathbf{y}(1)),

as desired.
∎

Proof of
Theorem

1.7
.

To get an
(\alpha-\epsilon)
-approximation to
\textsf{val}_{\Psi}
, let
\delta>0
be small enough such that
\frac{1-\delta}{1+\delta}\alpha(\mathsf{Th}^{i}_{k})\geq\alpha(\mathsf{Th}^{i}_{k})-\epsilon
. We claim that calculating an estimate
\widehat{b}
for
\textsf{bias}(\Psi)
(using
Corollary

7.4
) up to a multiplicative
\delta
factor and outputting
\widehat{v}=\alpha(\mathsf{Th}^{i}_{k})\gamma_{S,k}(\frac{\widehat{b}}{1+\delta})
is sufficient.

Indeed, suppose
\widehat{b}\in[(1-\delta)\textsf{bias}(\Psi),(1+\delta)\textsf{bias}(\Psi)]
; then
\frac{\widehat{b}}{1+\delta}\in[\frac{1-\delta}{1+\delta}\textsf{bias}(\Psi),\textsf{bias}(\Psi)]
. Now we observe

\displaystyle\gamma_{S,k}\left(\frac{\widehat{b}}{1+\delta}\right)

\displaystyle\geq\gamma_{S,k}\left(\frac{1-\delta}{1+\delta}\textsf{bias}(\Psi)\right)

(monotonicity of
\gamma_{S,k}
)

\displaystyle=\min\left\{\frac{1+\frac{1-\delta}{1+\delta}\textsf{bias}(\Psi)}{1+\epsilon_{s,k}},1\right\}

(
Lemma

3.3
)

\displaystyle\geq\frac{1-\delta}{1+\delta}\min\left\{\frac{1+\textsf{bias}(\Psi)}{1+\epsilon_{s,k}},1\right\}

(
\delta>0
)

\displaystyle=\frac{1-\delta}{1+\delta}\gamma_{S,k}(\textsf{bias}(\Psi)).

(
Lemma

3.3
)

Then we conclude

\displaystyle(\alpha(\mathsf{Th}^{i}_{k})-\epsilon)\textsf{val}_{\Psi}

\displaystyle\leq(\alpha(\mathsf{Th}^{i}_{k})-\epsilon)\gamma_{S,k}(\textsf{bias}(\Psi))

(
Lemma

7.1
)

\displaystyle\leq\alpha(\mathsf{Th}^{i}_{k})\cdot\frac{1-\delta}{1+\delta}\gamma_{S,k}(\textsf{bias}(\Psi))

(assumption on
\delta
)

\displaystyle\leq\widehat{v}

(our observation)

\displaystyle\leq\alpha(\mathsf{Th}^{i}_{k})\gamma_{S,k}(\textsf{bias}(\Psi))

(monotonicity of
\gamma_{S,k}
)

\displaystyle\leq\beta_{S,k}(\textsf{bias}(\Psi))

(
Eq.

2.7
)

\displaystyle\leq\textsf{val}_{\Psi},

(
Lemma

7.2
)

as desired.
∎
