A model reduction method for large-scale linear multidimensional dynamical systems
M.A. Hamadi, K. Jbilou, A. Ratnani

Abstract
In this work, we explore the application of multilinear algebra in reducing the order of multidimentional linear time invariant (MLTI) systems. We use tensor Krylov subspace methods as key tools, which involve approximating the system solution within a low-dimensional subspace. We introduce the tensor extended block and global Krylov subspaces and the corresponding Arnoldi based processes. Using these methods, we develop a model reduction using projection techniques. We also show how these methods could be used to solve large-scale Lyapunov tensor equations that are needed in the balanced truncation method which is a technique for order reduction. We demonstrate how to extract approximate solutions via the Einstein product using the tensor extended block Arnoldi and the extended global Arnoldi processes.



keywords

Einstein product, Model recuction, Multi-linear dynamical systems, Tensor Krylov subspaces.

In model reduction for high multi-linear time invariant (MLTI) systems, multilinear algebra can be used to simplify the system representation and reduce the computational complexity. This is achieved by decomposing the system tensor into smaller, lower-dimensional tensors, which can be more efficiently processed. One can use tensor decomposition techniques, such as the Tucker, the higher-order singular value decomposition (HOSVD) or tensor train decomposition (TTD) to decompose the system into simpler components, which can then be used to identify and reduce the number of parameters needed to describe the system.

Tensors are multi-dimensional arrays that can be used to represent higher-order relationships between variables in a system, making them a powerful tool for system analysis and reduction. The goal of model reduction in Multi-Linear Time Invariant (MLTI) systems is to find a reduced-order representation that accurately captures the behavior of the original system, while reducing the computational cost. The resulting reduced-order model retains the essential features of the original system and can be used for tasks such as simulation, optimization and control. The use of multilinear algebra in this context can significantly improve the efficiency and accuracy of the model reduction process. In a various scientific and engineering applications, the dynamical model over space and time can be described by a systems of PDEs,
e.g.,
Navies-Stokes equations in fluid dynamic, Schrodinguer equations in quantum mechanics and heat equations in thermal transfer. Naturally, a spatial/temporal discretization to such equations yields to tensors that evolve in time. [

and the references therein. However the transformation from tensors to vectors leads to a computational challenge due to high number of states/model parameters of the original system that scales exponentially with the number of dimensions. The use of tensors has become increasingly significant in many control applications, such as state-space representation, system identification and optimal control, where tensors can be used to represent the state of a control system in a compact and efficient manner, making it easier to analyse the system and design control strategies. The main idea is to use multilinear algebra to tensorize the vector-based dynamic system representation into an equivalent tensor representation. This strategy of guarding the compact tensor based representations/computations have been established in many applications, such as linear parameters varying models

In this paper we are interested in projecting the MLTI system onto some Krylov subspaces of a finite dimension using Einstein product. This technique of projection helps to reduce the complexity of the original system while preserving its essential features, and what we end up with is a lower-dimensional reduced MLTI system that has the same structure as the original one. The MLTI systems have been introduced in

One of them is the use of the transfer function that describes the input-output behaviour of the MLTI system, and to quantify the efficiency of the projected reduced MLTI system. Many properties in the theory of LTI systems such as, reachibility, controllability and stability, have been generalized in the case of MLTI systems based via the Einstein product

Recently, tensor Krylov subspace methods have gained interest beyond scientific community. These methods are based on the idea of approximating the solution of the system within a low-dimensional subspace, known as the Krylov subspace, generated by applying a few tensor-tensor products. 4
Tensor Balanced Truncation

Besides Krylov subspace model reduction methods for large scale LTI systems, another class of methods is the known Balanced Truncation method (BT) introduced by Moore
[
31
]
. The main challenge in the BT is to solve large-scale discrete-time Lyapunov equations in order to obtain the system Gramians that will be used to generate a reduced model. In this section, we provide with a tensor Balanced Truncation method. The process of this method is as follows. First, we need to solve two discrete Lyapunov equations

\mathcal{P}-{\cal A}\ast\mathcal{P}\ast{\cal A}^{T}={\cal B}\ast{\cal B}^{T},\qquad{\cal Q}-{\cal A}^{T}\ast{\cal Q}\ast{\cal A}={\cal C}^{T}\ast{\cal C},

(45)

where
{\cal A}\in\mathbb{R}^{J_{1}\times J_{2}\times J_{1}\times J_{2}}
and
{\cal B},{\cal C}^{T}\in\mathbb{R}^{J_{1}\times J_{2}\times K_{1}\times K_{2}}
. As mentioned before,
\mathcal{P}
and
{\cal Q}
are known as the reachability and the observability Gramians. It is mentioned previously, that
\mathcal{P}
and
{\cal Q}
are weakly symmetric positive-definite square tensor, then we can obtain the Cholesky-like factors of the two gramians described as follows

\mathcal{P}={\cal Z}\ast{\cal Z}^{T},\qquad{\cal Q}=\mathcal{W}\ast\mathcal{W}^{T}.

(46)

Where the tensors
{\cal Z}
and
\mathcal{W}
are of appropriate dimension presented in low-rank form. The next step consists in computing the singular value decomposition (SVD) of
\Psi(\mathcal{W}^{T}\ast{\cal Z})=U\Sigma V^{T}
, where
\Psi
is the isomorphism defined in (
4
). A reasonable computation is required behind this step since tensor
\mathcal{W}
and
{\cal Z}
are not of large dimensions. The matrix
\Sigma
is a diagonal matrix that contains the singular values known also as the
Hankel singular values
of the associated MLTI system
[
12
]
. This decomposition could be expressed as follows

\begin{split}\Psi(\mathcal{W}^{T}\ast{\cal Z})&=U\Sigma V^{T}\\
&=\begin{bmatrix}U^{1}\,\,U^{2}\end{bmatrix}\begin{bmatrix}\Sigma^{1}&\\
&\Sigma^{2}\end{bmatrix}\begin{bmatrix}(V^{1})^{T}\\
(V^{2})^{T}\end{bmatrix},\end{split}

(47)

where
\Sigma_{1}\in\mathbb{R}^{r^{2}\times r^{2}}
and
\Sigma_{2}\in\mathbb{R}^{(N^{2}-r^{2})\times(N^{2}-r^{2})}
. As described in
[
16
,
30
,
31
]
, a truncation step could be established, and by truncating the states that correspond to small Hankel singular values in
\Sigma_{2}
. The tensorial structure of the reduced MLTI system is given as follows

{\cal A}_{r}=\mathcal{Y}_{r}^{T}\ast({\cal A}\ast\mathcal{X}_{r}),\quad{\cal B}_{r}=\mathcal{Y}_{r}^{T}\ast{\cal B},\quad{\cal C}_{r}={\cal C}\ast\mathcal{X}_{r},

(48)

with

\mathcal{Y}_{r}=\mathcal{W}_{2}\ast\Psi^{-1}(U^{1})\ast\Psi^{-1}(\Sigma_{1})^{(-1/2)},\qquad\mathcal{X}_{r}={\cal Z}_{1}\ast\Psi^{-1}(V^{1})\ast\Psi^{-1}(\Sigma_{1})^{(-1/2)},

(49)

where
\Psi^{(-1)}
is the inverse of the isomorphism defined in (
4
). Regarding the solutions
\mathcal{P}
and
{\cal Q}
of the two Lyapunov equations (
45
), we suggest a solution in a factored form via the tensor extended block and global Krylov subspace projection methods. These two methods are the focus of the upcoming section.

in a efficient way. We start by employing a Singular Value Decomposition (SVD) to
Y_{2m}
, i.e.,
Y_{2m}=P\Sigma Q
, then we consider some tolerance
dtol
and define
P_{r}
,
Q_{r}
as the first
r
columns of
P
and
Q
corresponding respectively to the
r
singular values of magnitude greater than
dtol
. By setting
\Sigma_{r}=\text{diag}(\sigma_{1}\ldots,\sigma_{r})
, we get
Y_{2m}\approx P_{r}\Sigma_{r}Q_{r}^{T}
and the factorization goes as

\mathcal{X}_{m}\approx\widetilde{\mathcal{V}}_{2m}\ast(P_{r}\Sigma_{r}Q_{r}^{T}\circledast{\cal I}_{K})\ast\widetilde{\mathcal{V}}_{2m}^{T}\approx{\cal Z}_{1}\ast{\cal Z}_{2}^{T},

(57)

where
{\cal Z}_{1}=\widetilde{\mathcal{V}}_{2m}\ast(P_{r}(\Sigma_{r})^{1/2}\circledast{\cal I}_{K})
and
{\cal Z}_{2}=((\Sigma_{r})^{1/2}Q_{r}^{T}\circledast{\cal I}_{K})\ast\widetilde{\mathcal{V}}_{2m}^{T}
.
The same process could be followed to get the approximation in a factored form using the global extended tensor Krylov subspace, in this case
{\cal Z}_{1}=\widetilde{\mathcal{V}}_{2m}\ast(P_{r}(\Sigma_{r})^{1/2}\circledast{\cal I}_{K})
and
{\cal Z}_{2}=((\Sigma_{r})^{1/2}Q_{r}^{T}\circledast{\cal I}_{K})\ast\widetilde{\mathcal{V}}_{2m}^{T}
.

.

4.

5.2
Tensor extended block Arnoldi process for Lyapunov equations

In this section, we define a tensor extended block Krylov subspace via Einstein product that will be used to solve the tensor discrete Lyapunov equation (
50
). A description of the classic block Krylov subspace methods via Einstein product has been performed in
[
17
]
. For
{\cal A}\in\mathbb{R}^{J_{1}\times\ldots\times J_{N}\times J_{1}\times\ldots\times J_{N}}
and
{\cal B}\in\mathbb{R}^{J_{1}\times\ldots\times J_{N}\times K_{1}\times\ldots\times K_{M}}
, the
2m
-th block extended tensor Krylov subspace associated to the pair
({\cal A},{\cal B})
is defined by

{\cal K}_{m}^{b-ext}({\cal A},{\cal B})=\text{Range}\left\{{\cal A}^{-\star m}\ast{\cal B},\ldots,{\cal A}^{-1}\ast{\cal B},{\cal B},\ldots,{\cal A}^{\star\,m-1}\ast{\cal B}\right\},

(58)

where
{\cal A}^{\star k}=\underbrace{{\cal A}\ast\ldots\ast{\cal A}}_{k}
,

{\cal A}^{\star-k}=\underbrace{{\cal A}^{-1}\ast\ldots\ast{\cal A}^{-1}}_{k}
and
{\cal A}^{0}={\cal I}
is the identity tensor. Next, we define the notion of upper/lower triangular tensors which will be used later on.

Definition 11
.

Let
{\cal U}
and
{\cal L}
be two tensors in the space
\mathbb{R}^{J_{1}\times\ldots\times J_{N}\times I_{1}\times\ldots\times I_{N}}

-

{\cal U}
si an upper triangular tensor if the entries
u_{j_{1},\ldots,j_{N},i_{1},\ldots,i_{N}}=0
when
i\text{vec}(j,J)\geq i\text{vec}(j,J)
.

-

{\cal L}
si a lower triangular tensor if the entries
r_{j_{1},\ldots,j_{N},i_{1},\ldots,i_{N}}=0
when
i\text{vec}(j,J)\leq i\text{vec}(j,J)
,

where
i\text{vec}(\cdot,\cdot)
is the mapping index mentioned in Definition
4
.

Analogously to the
QR decomposition
in the matrix case
[
15
]
, a similar definition to such decomposition of a tensor
\mathcal{P}
in the space
\mathbb{R}^{J_{1}\times\ldots\times J_{N}\times K_{1}\times\ldots\times K_{M}}
is defined as follows

\mathcal{P}={\cal Q}\ast\mathcal{R},

(59)

where
{\cal Q}\in\mathbb{R}^{J_{1}\times\ldots\times J_{N}\times K_{1}\times\ldots\times K_{M}}
is orthogonal
i.e.,

{\cal Q}^{T}\ast{\cal Q}={\cal I}_{K}
and
\mathcal{R}\in\mathbb{R}^{K_{1}\times\ldots\times K_{M}\times K_{1}\times\ldots\times K_{M}}
is an upper triangular tensor (Definition
11
).
Similarly to the matrix extended block Krylov Arnoldi algorithm
[
38
]
, an analogous algorithm in a tensor format, particularly for the
4th
-order tensor which is the main subject of this paper as mentioned previously, could be generated as follows

Algorithm 4

Tensor extended block Arnoldi algorithm

1.

Input :
{\cal A}\in\mathbb{R}^{J_{1}\times J_{2}\times J_{1}\times J_{2}}
,
{\cal B}\in\mathbb{R}^{J_{1}\times J_{2}\times K_{1}\times K_{2}}
and a fixed integer
m
.

2.

Output :
\widetilde{\mathcal{V}}_{2(m+1)}\in\mathbb{R}^{J_{1}\times J_{2}\times K_{1}\times 2(m+1)K_{2}}
and
\overline{H}_{m}\in\mathbb{R}^{K_{1}\times 2(m+1)K_{2}\times K_{1}\times 2mK_{2}}
.

3.

Compute
QR
-decomp. to
|{\cal B},\,{\cal A}^{-1}\ast{\cal B}|_{2}\in\mathbb{R}^{J_{1}\times J_{2}\times K_{1}\times 2K_{2}}

i.e.,

|{\cal B},\,{\cal A}^{-1}\ast{\cal B}|_{2}=\mathcal{V}_{1}\ast\mathcal{R}_{0}
.
(
MATLAB notation
\widetilde{\mathcal{V}}_{2(m+1)}(:,:,:,1:2K_{2})=\mathcal{V}_{1}
)

4.

for
j=1\cdots m

5.

Set
\mathcal{W}=|{\cal A}\ast\mathcal{V}_{j}^{1},{\cal A}^{-1}\ast\mathcal{V}_{j}^{2}|_{2}
, where
\left\{\begin{array}[]{lll}\mathcal{V}_{j}^{1}&=&\mathcal{V}_{j}(:,:,:,(j-1)K_{2}+1:jK_{2}),\\
\mathcal{V}_{j}^{2}&=&\mathcal{V}_{j}(:,:,:,jK_{2}+1:(j+1)K_{2}),\end{array}\right.

6.

for
i=1,\ldots,j
.

7.

{\cal H}_{i,j}=\mathcal{V}_{i}\ast\mathcal{W}
.

8.

\mathcal{W}=\mathcal{W}-\mathcal{V}_{i}\ast{\cal H}_{i,j}
.

9.

end for.

10.

Compute
QR
-decomp. to
\mathcal{W}
,
i.e.,

\mathcal{W}=[\mathcal{V}_{j+1},{\cal H}_{j+1,j}].

11.

end for.

We start our process by applying Algorithm
4
defined above to the pair
({\cal A},{\cal B})
. After
m
iterations, the following decomposition could be obtained

\begin{array}[]{lll}{\cal A}\ast\widetilde{\mathcal{V}}_{2m}&=\widetilde{\mathcal{V}}_{2(m+1)}\ast\overline{{\cal T}}_{m}\\
&=\widetilde{\mathcal{V}}_{2m}\ast{\cal T}_{m}+\mathcal{V}_{2(m+1)}\ast({\cal T}_{m+1,m}\ast{\cal E}_{2m}^{T}),\end{array}

(60)

where
\widetilde{\mathcal{V}}_{2m}
is the tensor basis associated with
{\cal K}_{m}^{b-ext}({\cal A},{\cal B})
. Tensors
\overline{{\cal T}}_{m}
and
{\cal T}_{m}
are defined as follows

\overline{{\cal T}}_{m}=\widetilde{\mathcal{V}}_{2(m+1)}^{T}\ast({\cal A}\ast\widetilde{\mathcal{V}}_{2m})\in\mathbb{R}^{K_{1}\times 2(m+1)K_{2}\times K_{1}\times 2mK_{2}},\quad{\cal T}_{m}=\widetilde{\mathcal{V}}_{2m}^{T}\ast({\cal A}\ast\widetilde{\mathcal{V}}_{2m})\in\mathbb{R}^{K_{1}\times 2mK_{2}\times K_{1}\times 2mK_{2}}.

Finally the tensor
{\cal E}_{2m}
is get it from the identity tensor
{\cal I}_{2m}\in\mathbb{R}^{K_{1}\times 2mK_{2}\times K_{1}\times 2mK_{2}}
as
{\cal E}_{2m}={\cal I}_{2m}(:,:,:,2(m-1)K_{2}+1:2mK_{2})
. Analogously to the matrix case, the tensor
{\cal T}_{m}
can be defined as the restriction of the tensor
{\cal A}
in the extended block tensor Krylov subspace
{\cal K}_{m}^{b-ext}({\cal A},{\cal B})
. Notice that the tensor
\overline{{\cal T}}_{m}
can be expressed as

\overline{{\cal T}}_{m}=\begin{vmatrix}{\cal T}_{1,1}&{\cal T}_{1,2}&\ldots&{\cal T}_{1,m}\\
{\cal T}_{2,1}&{\cal T}_{2,2}&\ldots&{\cal T}_{2,m}\\

where the notation

. The tensor

is obtained from

by deleting the last row block tensor

.

Remark 4
.

Generally, the tensor
\overline{{\cal H}}_{m}\in\mathbb{R}^{K_{1}\times 2(m+1)K_{2}\times K_{1}\times 2mK_{2}}
is of small dimension, then the computation of the matricization of such tensor denoted by
mat(\overline{{\cal H}}_{m})=\overline{H}_{m}
is feasible. We denote by
\overline{T}_{m}
the matrix that we get from the matricization of tensor
\overline{{\cal T}}_{m}
. We recall that
\overline{T}_{m}
could be computed efficiently and directly using
\overline{H}_{m}
as mentioned in
[
37
]
without requiring any extra product. The purpose behind this process is to build
{\cal T}_{m}
needed afterwards without requiring any extra tensor product with the large scale tensor
{\cal A}
.

We seek for an approximate solution
\mathcal{X}_{m}
to
\mathcal{X}
fulfilling the discrete Lyapunov equation (
51
). Consider the following form of the approximation

\mathcal{X}_{m}=\widetilde{\mathcal{V}}_{2m}\ast\mathcal{Y}_{2m}\ast\widetilde{\mathcal{V}}_{2m}^{T},

(62)

where
\widetilde{\mathcal{V}}_{2m}
is the tensor basis associated with the tensor Krylov subspace obtained by using Algorithm
4
to the pair
({\cal A},{\cal B})
. We obtain the tensor
\mathcal{Y}_{2m}\in\mathbb{R}^{K_{1}\times 2mK_{2}\times K_{1}\times 2mK_{2}}
via the following condition

\widetilde{\mathcal{V}}_{2m}^{T}\ast(\mathcal{R}_{m}\ast\widetilde{\mathcal{V}}_{2m})=0,

(63)

and
\mathcal{R}_{m}
is the residual tensor given by
\mathcal{R}_{m}=\mathcal{X}_{m}-{\cal A}\ast\mathcal{X}_{m}\ast{\cal A}^{T}-{\cal B}\ast{\cal B}^{T}

\mathcal{Y}_{m}-{\cal T}_{m}\ast\mathcal{Y}_{m}\ast{\cal T}_{m}^{T}={\cal B}_{m}\ast{\cal B}_{m}^{T}.

(64)

The right hand side could be simplified to the following
{\cal B}_{m}\ast{\cal B}_{m}^{T}
. We know from Algorithm
4

\begin{split}|{\cal B},\,{\cal A}^{-1}\ast{\cal B}|_{2}&=\mathcal{V}_{1}\ast\mathcal{R}_{0}\\
&=|\mathcal{V}_{1}^{1},\mathcal{V}_{1}^{2}|_{2}\ast\begin{vmatrix}\mathcal{R}_{0}^{(1,1)}&\mathcal{R}_{0}^{(1,2)}\\
\mathcal{O}&\mathcal{R}_{0}^{(2,2)}\end{vmatrix},\end{split}

where
\mathcal{V}_{1}^{i}=\mathcal{V}_{1}(:,:,:,(i-1)K_{2}+1:iK_{2})\in\mathbb{R}^{K_{1}\times K_{2}\times K_{1}\times K_{2}}
,

|\cdot|_{2}

6

defined in Definition
11

3

{\cal B}=\mathcal{V}_{1}^{1}\ast\mathcal{R}_{0}^{(1,1)},

\begin{split}{\cal B}_{m}&=\widetilde{\mathcal{V}}_{2m}^{T}\ast{\cal B}\\
&={\cal E}_{2m}^{1}\ast\mathcal{R}_{0}^{(1,1)},\end{split}

(65)

where

Theorem 2
.

Assume that

and
\|\cdot\|

3

Proof.

We plug
\mathcal{X}_{m}
in the expression of
\mathcal{R}_{m}
and by using decomposition (
60
) and the fact that
\mathcal{Y}_{2m}-{\cal T}_{m}\ast\mathcal{Y}_{2m}\ast{\cal T}_{m}^{T}-{\cal E}_{2m}^{1}\ast\mathcal{R}_{0}^{(1,1)}\ast({\cal E}_{2m}^{1}\ast\mathcal{R}_{0}^{(1,1)})^{T}=0
(
i.e.,
(

)), we get

\mathcal{R}_{m}=\widetilde{\mathcal{V}}_{2(m+1)}\ast\left[\begin{vmatrix}0&-{\cal T}_{m}\ast\mathcal{Y}_{2m}\ast{\cal E}_{2m}\ast{\cal T}_{m+1,m}^{T}\\
-({\cal T}_{m}\ast\mathcal{Y}_{m}\ast{\cal E}_{2m}\ast{\cal T}_{m+1,m}^{T})^{T}&{\cal T}_{m+1,m}\ast{\cal E}_{2m}^{T}\ast\mathcal{Y}_{2m}\ast{\cal E}_{2m}\ast{\cal T}_{m+1,m}^{T}\end{vmatrix}\right]\ast\widetilde{\mathcal{V}}_{2(m+1)}^{T}.

Then we obtain the desired result

\|\mathcal{R}_{m}\|=\sqrt{2*\|{\cal T}_{m}\ast\mathcal{Y}_{2m}\ast{\cal E}_{2m}\ast{\cal T}_{m+1,m}^{T}\|^{2}+\|{\cal T}_{m+1,m}\ast{\cal E}_{2m}^{T}\ast\mathcal{Y}_{2m}\ast{\cal E}_{2m}\ast{\cal T}_{m+1,m}^{T}\|^{2}}.

Conclusion

In this paper, we explored the application of multilinear algebra in reducing the order of multidimentional linear time invariant (MLTI) systems. We used tensor Krylov subspace methods as key tools, which involve approximating the system solution within a low-dimensional subspace. We introduced the tensor extended block and global Krylov subspaces and the corresponding Arnoldi based processes. Using these methods, we developed a model reduction using projection techniques. We have also shown how these methods could be used to solve large-scale Lyapunov tensor equations that are required in the balanced truncation method which is a technique for order reduction. We demonstrated how to extract approximate solutions via the Einstein product using the tensor extended block Arnoldi and the extended global Arnoldi processes.
