Distance Estimation Between Unknown Matrices Using Sublinear Projections on Hamming Cube
Arijit Bishnu, Arijit Ghosh, Gopinath Mishra

Abstract
Using geometric techniques like projection and dimensionality reduction, we show that there exists a randomized sub-linear time algorithm that can estimate the Hamming distance between two matrices. Consider two matrices 𝐀 {\bf A} and 𝐁 {\bf B} of size n × n n\times n whose dimensions are known to the algorithm but the entries are not. The entries of the matrix are real numbers. The access to any matrix is through an oracle that computes the projection of a row (or a column) of the matrix on a vector in { 0 , 1 } n \{0,1\}^{n} . We call this query oracle to be an Inner Product oracle (shortened as IP ). We show that our algorithm returns a ( 1 ± ϵ ) (1\pm\epsilon) approximation to 𝐃 𝐌 ​ ( 𝐀 , 𝐁 ) {{\bf D}}_{\bf M}({\bf A},{\bf B}) with high probability by making 𝒪 ⁡ ( n 𝐃 𝐌 ​ ( 𝐀 , 𝐁 ) ​ poly ​ ( log ⁡ n , 1 ϵ ) ) {\cal O}\left(\frac{n}{\sqrt{{{\bf D}}_{\bf M}({\bf A},{\bf B})}}\mbox{poly}\left(\log n,\frac{1}{\epsilon}\right)\right) oracle queries, where 𝐃 𝐌 ​ ( 𝐀 , 𝐁 ) {{\bf D}}_{\bf M}({\bf A},{\bf B}) denotes the Hamming distance (the number of corresponding entries in which 𝐀 {\bf A} and 𝐁 {\bf B} differ) between two matrices 𝐀 {\bf A} and 𝐁 {\bf B} of size n × n n\times n . We also show a matching lower bound on the number of such IP queries needed. Though our main result is on estimating 𝐃 𝐌 ​ ( 𝐀 , 𝐁 ) {{\bf D}}_{\bf M}({\bf A},{\bf B}) using IP , we also compare our results with other query models.



Key words
: distance estimation, property testing, dimensionality reduction, sub-linear algorithms

[
25

studied property testing algorithms in the sparse binary image model (the number of 1-pixels is

[

,
24
]
, Berman et al. in
[

To the best of our knowledge, computing distances between binary images has not been dealt with in the sub-linear time framework.

Communication complexity

In two-party communication complexity there are two parties, Alice and Bob, that wish to compute a function
\Pi:\{0,1\}^{N}\times\{0,1\}^{N}\to\{0,1\}
. Alice is given
{\bf x}\in\{0,1\}^{N}
and Bob is given
{\bf y}\in\{0,1\}^{N}

i

{\bf x}~({\bf y})

\Pi

{\bf y}

{\bf x}

\mathcal{P}

\Pi({\bf x},{\bf y})

As noted in Section

Emptiness Query Oracle and subset size estimation.

Let us first define the emptiness query oracle.

Definition B.2
.

Let
U
be a known universe and
X\subseteq U
be unknown. Emptiness Query Oracle takes a query set
Q\subseteq U
as input and lets us know whether
Q\cap X=\emptyset
.

The following proposition mentions the query complexity of subset size estimation using emptiness queries.

Proposition B.3

(Estimation of size of an unknown subset using emptyness queries (Lemma 2.9 in
[
6
]
))
.

Let
U
be a universe of size
n
. There exists an algorithm that has an emptiness query oracle access to an unknown subset
X\subseteq U
, takes parameters
\alpha,\delta\in(0,1)
, returns a
(1\pm\alpha)
-approximation to
\left|X\right|
with probability at least
1-\delta

\mathcal{O}\left(\frac{\log n}{\alpha^{2}}\log\frac{1}{\delta}\right)
emptiness queries.

Now, we come back to the proof of Lemma
2.10
by simulating the emptiness query oracle by
IP
.

Proof of Lemma
2.10
.

We will set up the framework of Proposition
B.3
. Let

U=[n]
and
X\subseteq[n]
is the unknown set defined as,
X=\{k\in S:{\bf A}(i,k)\neq{\bf B}(i,k)\}
. Observe that

\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)~|_{S},{\bf B}(i,*)~|_{S}\right)=\left|X\right|.
By Proposition
B.3
, we can estimate
\left|X\right|=\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)~|_{S},{\bf B}(i,*)~|_{S}\right)
by using
\mathcal{O}\left(\frac{\log n}{\alpha^{2}}\log\frac{1}{\delta}\right)
emptiness queries with probability at least
1-\frac{\delta}{2}
. Hence, we will be done by showing how to answer all the emptiness queries by using
IP
queries with probability
1-\frac{\delta}{2}
. Let
Q\subseteq[n]
be (an emptiness query) such that we want to know whether
Q\cap X=\emptyset
. Observe that
Q\cap X=\emptyset
if and only if
\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)~|_{Q},{\bf B}(i,*)~|_{Q}\right)=0
. Also, we can know whether
\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)~|_{Q},{\bf B}(i,*)~|_{Q}\right)=0
or not with probability
1-\frac{\delta}{2n}
by calling
\mbox{{\sc Identity}}\left(S,i,\delta/2n\right)
(the algorithm corresponding to Observation
2.9

\mathcal{O}\left(\log\frac{n}{\delta}\right)

IP

. As there is no need to make more than
\mathcal{O}(n)
many emptiness queries (irrespective of input parameters
\alpha
and
\delta

.

As we are making
\mathcal{O}\left(\frac{\log n}{\alpha^{2}}\log\frac{1}{\delta}\right)

\mbox{{\sc Restrict-Dist-Bet-Rows}}(S,i,\alpha,\delta)
follows.

(1\pm 2\alpha^{\prime})
-approximation to
\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j-1}^{k^{*}}},{\bf B}(i,*)|_{S_{j-1}^{k^{*}}}\right)
. Hence,
\mathbb{P}(k_{j}=2k^{*}-1)=\frac{d_{1}^{j}}{d_{1}^{j}+d_{2}^{j}}
can be bounded as

\displaystyle\left(\frac{1-\alpha^{\prime}}{1+2\alpha^{\prime}}\right)\frac{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j}^{k^{\#}}},{\bf B}(i,*)|_{S_{j}^{k^{\#}}}\right)}{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j-1}^{k^{*}}},{\bf B}(i,*)|_{S_{j-1}^{k^{*}}}\right)}\leq\mathbb{P}(k_{j}=2k^{*}-1)\leq\left(\frac{1+\alpha^{\prime}}{1-2\alpha^{\prime}}\right)\frac{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j}^{k^{\#}}},{\bf B}(i,*)|_{S_{j}^{k^{\#}}}\right)}{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j-1}^{k^{*}}},{\bf B}(i,*)|_{S_{j-1}^{k^{*}}}\right)}

Note that we are done with the desired bound for
\mathbb{P}(k_{j}=2k^{*}-1)
.
∎

For
\mathbb{P}(E_{j}~|~E_{j-1})
, take
k^{*}=I(j-1,\ell)
and
k^{\#}=I(j,\ell)
in the above Observation. Then we get

\mathbb{P}(E_{j}~|~E_{j-1})=\mathbb{P}\left(k_{j}=I(j,\ell)~|~k_{j-1}=I(j-1,\ell)\right)\\
\leq(1+4\alpha^{\prime})\frac{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j}^{I(j,\ell)}},{\bf B}(i,*)|_{S_{j}^{I(j,\ell)}}\right)}{\mbox{{\bf d}}_{{{\bf H}}}\left({\bf A}(i,*)|_{S_{j-1}^{I(j-1,\ell)}},{\bf B}(i,*)|_{S_{-1j}^{I(j-1,\ell)}}\right)}.

Putting the above for each

in Equation
9

The proof of
