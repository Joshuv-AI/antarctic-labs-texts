Diagonally-Addressed Matrix Nicknack: How to improve SpMV performance
Jens Saak, Jonas Schulze

Abstract
We suggest a technique to reduce the storage size of sparse matrices at no loss of information. We call this technique DA storage. It exploits the typically low matrix bandwidth of matrices arising in applications. For memory-bound algorithms, this traffic reduction has direct benefits for both uni-precision and multi-precision algorithms. In particular, we demonstrate how to apply DA storage to the CSR ( CSR ) format and compare the performance in computing the SpMV product, which is a basic building block of many iterative algorithms. We investigate 1367 matrices from the SuiteSparse Matrix Collection [ 4 ] fitting into the CSR format using signed 32 bit 32\text{\,}\mathrm{bit} indices. More than 95 % 95\text{\,}\% of these matrices fit into the DA - CSR format using 16 bit 16\text{\,}\mathrm{bit} column indices, potentially after RCM ( RCM ) reordering [ 2 ] . Using IEEE 754 double precision scalars, we observe a performance uplift of 11 % 11\text{\,}\% (single-threaded) or 17.5 % 17.5\text{\,}\% (multithreaded) on average when the traffic exceeds the size of the last-level CPU cache. The predicted uplift in this scenario is 20 % 20\text{\,}\% . For traffic within the CPU’s combined level 2 and level 3 caches, the multithreaded performance uplift is over 40 % 40\text{\,}\% for a few test matrices.

The
