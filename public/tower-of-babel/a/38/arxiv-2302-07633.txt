Stacking-Induced Symmetry-Protected Topological Phase Transitions
Sang-Jun Choi, Björn Trauzettel

Abstract
We study symmetry-protected topological (SPT) phase transitions induced by stacking two gapped one-dimensional subsystems in BDI symmetry class. The topological invariant of the entire system is a sum of three topological invariants: two from each subsystem and an emerging topological invariant from the stacking. We find that any symmetry-preserving stacking of topologically trivial subsystems can drive the entire system into a topologically nontrivial phase for a certain coupling strength. We explain this intriguing SPT phase transitions by conditions set by orbital degrees of freedom and time-reversal symmetry. To exemplify the SPT transition, we provide a concrete model which consists of an atomic chain and a spinful nanowire with spin-orbit interaction and s s -wave superconducting order. The stacking-induced SPT transition drives this heterostructure into a zero-field topological superconducting phase.

Using the eigenstates of the chiral operator for each block, we can transform the Hamiltonian into

\mathcal{H}(k)=\left(\begin{array}[]{cc|cc}\mathbf{0}_{N_{u}}&h_{u}^{\dagger}(k)&V^{\dagger}&Y^{\dagger}\\

\hline\cr V&X&\mathbf{0}_{N_{d}}&h_{d}^{\dagger}(k)\\

The matrix elements of the coupling term

Since the entire system shall respect the chiral symmetry, we can reduce matrix elements further. The chiral symmetry operator

The matrix size of

We calculate the winding number
\mathcal{W}
of the entire system to study SPT phase transitions. Note that

can be continuously deformed except for singular points

We find that

We emphasize that if we stack two topologically trivial subsystems,

We elaborate on the physical mechanism of the zero-field TSC as imitating the one-dimensional helical state using ODF instead of magnetic fields. It is known that the helical state stabilizes a TSC phase with an
s
-wave superconducting order

k=0

;

;

;

so that
[\hat{T},\hat{H}+\hat{V}^{\prime}]\neq 0

[\hat{T},\hat{H}]=0
but with
\hat{T}^{2}=\hat{1}

To illustrate that the heterostructure mimics helical states, we provide a low-energy effective Hamiltonian of the electron band for weak coupling strength,

\mathcal{T}_{u}=i\sigma_{y}\mathcal{K}

. This is an advantage with respect to the formation of quasi-helical states in spin-orbit nanowires employing Zeeman interaction.

Conclusion.
—Nontrivial SPT phases can be induced by any symmetry-preserving stacking of two subsystems in the one-dimensional BDI symmetry class. We demonstrate that the only requirement for SPT phase transitions is set on ODF of each subsystem without particular types of stacking or interactions. We illustrate the general result on the stacking-induced SPT phase transitions with a concrete example of zero-field TSC. It consists of an atomic wire coupled to a spin-orbit nanowire with
s
-wave superconducting order. Stacking two systems induces a SPT transition so that the stacked systems becomes a TSC in absence of a magnetic field. Since zero-field TSC does not require a large
g
-factor, it can stimulate experimental searches for implementing TSC in a different range of materials.
