Extending the definition of single and set tolerances
Gerold Jäger, Marcel Turkensteen

Abstract
Optimal solutions of combinatorial optimization problems can be sensitive to changes in the cost of one or more elements of the ground set ℰ {\cal E} . Single and set tolerances measure the supremum / infimum possible change such that the current solution remains optimal for cost changes in one or more elements. The current definition does not apply to all elements of ℰ {\cal E} or to all subsets of ℰ {\cal E} . In this work, we broaden the definition to all elements for single tolerances and to all subsets of elements for set tolerances, while proving that key theoretical and computational properties still apply.



keywords

Sensitivity analysis, single tolerance, set tolerance

1
Introduction

Many studies consider the effect of parameter changes
on the optimality of solutions. Greenberg
Gre94
performed sensitivity analysis
(there it is called postoptimal analysis) on linear programming problems.
Andersen et al.
AKR23
developed a computational approach for determining
under which parameter values Mixed Integer Linear Programming solutions remain optimal,
but if multiple parameters change, it is necessary to solve a number of problems
which is exponential in the number of changing parameter values.

In this work, we consider combinatorial optimization problems (COPs), in which
one selects a combination of elements from the ground set to minimize (maximize)
some objective function based on the costs of the individual elements.
Examples of COPs are given in
CCPS97
and include decision problems in Binary Programming.
The objective is often to minimize (maximize) the sum of the costs of elements in a solution,
but one can also minimize the maximum (bottleneck) cost, as in
KZ13
, or the product of
the costs (see
JT24
for applications).
Further relevant studies on sensitivity analysis for COPs can be found in
FV18
;
MWMS22
.

In previous studies
GJM06b
;
JT18
;
JT24
, we developed a theoretical framework
called
theory of tolerances
, in which we determined the limits to the changes
in the costs of elements or sets of elements such current solutions remain optimal and thus other solutions become
optimal. These limits are called
tolerances
.

In case of parameter changes of single elements,
so-called
single tolerances
provide the supremum increase and decrease, respectively, in
which optimal solutions remain optimal.
In case of multiple simultaneous parameter changes, solutions remain optimal within some region
formed by combinations of individual cost changes. However, determining this region is a laborious
task
AKR23
. The theoretical framework
includes measures of the size of the area, called
set tolerances
, which are also
independent of the optimal solution.
In fact, the theoretical framework shows that
the introduced single and set tolerances are independent
of the choice of the optimal solution. This is beneficial, because cost changes could
make some but not all optimal solutions non-optimal.

The current definitions of single and set tolerances have the drawback that they
only apply to specific elements or specific subsets of elements of the ground set. As a consequence, if there is a
set of elements in which all costs either increase or decrease, we first have to check whether the
tolerance is defined, and we may discover that this is not the case.

In this work we generalize the definitions and extend the theory of single and set
tolerances in such a way that this drawback no longer holds. We show that all
extended / new definitions are consistent
with the corresponding current ones.
We further prove that several previous results, in particular exact values and upper and lower
bounds, can be generalized for the new definitions so that the main part of the previous
theory can be kept.

In this work, we aim to provide new definitions of single and
set tolerances, which

•

are consistent with the current definitions on their
respective domains,

•

can be computed conveniently (i.e., previous computational
results should be applicable to all
elements/subsets).

2.1
Combinatorial minimization problems

Formally, a
c
ombinatorial minimization problem (CMP)
{\cal P}

is given by a tuple

({\cal E},D,c,f_{c})
where

{\cal E}
is a finite
ground set of elements
,

D\subseteq 2^{\cal E}\setminus\{\emptyset\}
is
the set of
feasible solutions
,

c:\,{\cal E}\to\mathbb{R}
is the
cost function

which assigns costs to each single element
of
{\cal E}
,

f_{c}:\,D\to\mathbb{R}
is
a function which depends on the function
c
and assigns
costs to each feasible solution
D
.

S^{\ast}\subseteq{\cal E}
is called an
optimal solution
of

{\cal P}
if
S^{\ast}
is a feasible solution and the costs

f_{c}(S^{\ast})
of
S^{\ast}
are infimum.
We denote the cost of an optimal solution

S^{\ast}
of
{\cal P}
by
f_{c}({\cal P})

and the set of optimal solutions by
D^{\ast}
.
Moreover, we require that there is at least one optimal solution of
{\cal P}
, i. e.,
D^{\ast}\not=\emptyset
.

We consider CMPs
{\cal P}=({\cal E},D,c,f_{c})

where

f_{c}:\,D\to\mathbb{R}
is of type

sum
, i.e., the sum of all costs is minimized and which we call
a
combinatorial sum problem (CSP)
,
where it is of type
product
, i.e., the product of all (positive) costs is minimized
and which we call
a
combinatorial product problem (CPP)
, and where it is of type
bottleneck
,
i.e., the maximum of all costs is minimized, and which we call
a
combinatorial bottleneck problem (CBP)
.

Define

\delta(e):=\left\{\begin{array}[]{ll}\infty,&\mbox{if $f_{c}$ is of type sum or bottleneck}\\
c(e),&\mbox{if $f_{c}$ is of type product}\end{array}\right.

as the supremum by which element
e
can be
decreased such that
f_{c}
remains of type
sum, product, or bottleneck, respectively.
For a CBP, let
c^{\ast}
denote
the objective value of an optimal
solution, so
c^{\ast}=f_{c}({\cal P})
.

Let a CMP
{\cal P}=({\cal E},D,c,f_{c})

and
E=\{e_{1},e_{2},\dots,e_{k}\}\subseteq{\cal E}
be given.
If for all
l\in\mathbb{N}
with

1\leq l\leq k
we add
\alpha_{l}\in\mathbb{R}
to the cost of
e_{l}
,
we denote a new CMP instance by

{\cal P}_{c_{{\vec{\alpha}},{E}}}=({\cal E},D,c_{\vec{\alpha},E},{f_{c_{\vec{\alpha},E}}})
,
with costs

c_{\vec{\alpha},e}\bar{e})=\left\{\begin{array}[]{cl}c(\bar{e}),&\mbox{if}\ \bar{e}\in{\cal E}\setminus E\\
c(\bar{e})+\alpha_{l},&\mbox{if}\ \bar{e}=e_{l}\ \mbox{for}\ l=1,2,\dots,k\end{array}\right.
.

Note that

{f_{c_{\vec{\alpha},E}}}
is of the same type as

f_{c}
,
unless
f_{c}
is of type product and
\alpha_{l}\leq-c(e_{l})
for at least one
l\in\{1,2,\dots,k\}
.
When
|E|=1
with
E=\{e\}
, we write

{\cal P}_{c_{{\alpha},{e}}}=({\cal E},D,c_{\alpha,e},{f_{c_{\alpha,e}}})
,
for the sake of simplicity, instead of the formally correct notation with
\{e\}
.

For
M\subseteq D
, we denote the costs of the
best solution included in
M
by
f_{c}(M)
.
Furthermore, the cost
f_{c}(\emptyset)
is defined as infinite, i. e.,
\infty
.

Let
e\in{\cal E}
. We define the subsets of solutions

D_{+}(e)=\{\,S\in D\mid e\in S\}
and
D_{-}(e)=\{\,S\in D\mid e\in{\cal E}\setminus S\}
.

In Sections
2.2
–
2.5
, the current
definitions of upper/lower single tolerances
GJM06b
,
of regular upper/lower set tolerances
JT18
,
of reverse upper/lower set tolerances
JT24
are given. All these definitions depend on a given optimal solution
S^{\ast}
, where

e\in S^{\ast}
for single upper tolerances,

e\in{\cal E}\setminus S^{\ast}
for single lower tolerances,

E\subseteq S^{\ast}
for set upper tolerances,

E\subseteq{\cal E}\setminus S^{\ast}
for set lower tolerances.
However, they are shown to be independent of
S^{\ast}
in these references.
The following observation is the basis for a convenient reformulation
of these definitions.

Observation 1
.

Let
{\cal P}=({\cal E},D,c,f_{c})

be a CMP instance and
E=\{e_{1},e_{2},\dots,e_{k}\}\subseteq{\cal E}
.
Furthermore, let
\vec{\alpha}=(\alpha_{1},\alpha_{2},\dots,\alpha_{k})
,
where
\alpha_{l}\geq 0
for all
l=1,2,\dots,k
.

(a)

Let
S_{1}^{\ast}
and
S_{2}^{\ast}
be optimal solutions of
{\cal P}
with

E\subseteq S_{1}^{\ast}
and
E\nsubseteq S_{2}^{\ast}
.
Then it holds that

{f_{c_{\vec{\alpha},E}}}(S_{2}^{\ast})\leq{f_{c_{\vec{\alpha},E}}}(S_{1}^{\ast})
.

(b)

Let
S_{1}^{\ast}
and
S_{2}^{\ast}
be optimal solutions of
{\cal P}
with

E\subseteq{\cal E}\setminus S_{1}^{\ast}
and
E\nsubseteq{\cal E}\setminus S_{2}^{\ast}
.
Then it holds that

{f_{c_{-\vec{\alpha},E}}}(S_{2}^{\ast})\leq{f_{c_{-\vec{\alpha},E}}}(S_{1}^{\ast})
.

2.2
Single upper tolerances

Let
{\cal P}=({\cal E},D,c,f_{c})

be a CMP instance and let
UTE_{{\cal P}}:=\bigcup_{S^{\ast}\in D^{\ast}}S^{\ast}
.
We define the
(single) upper tolerance

u_{{\cal P}}({e})

of each
e\in UTE_{{\cal P}}
as follows:

\displaystyle u_{{\cal P}}({e})

(1)

\displaystyle:=

\displaystyle\sup\;\{\alpha\in\mathbb{R}_{0}^{+}\mid\mbox{each opt.\ $S^{\ast}$ for}\ {\cal P}\ \mbox{is opt.\ for}\ {\cal P}_{c_{{\alpha},{e}}}\}

\displaystyle:=

\displaystyle\inf\;\{\alpha\in\mathbb{R}_{0}^{+}\mid\mbox{some opt.\ $S^{\ast}$ for}\ {\cal P}\ \mbox{is not opt.\ for}\ {\cal P}_{c_{{-\alpha},{e}}}\}.

In the case of
u_{{\cal P}}({e})<\infty
, “sup” can be replaced by “max”.

This definition is a slight modification from the one provided in
GJM06b
.
As optimal solutions
S^{\ast}
with
e\in{\cal E}\setminus S^{\ast}
remain automatically
optimal when increasing
c(e)
, both definitions are equivalent.

We can determine the set
UTE_{{\cal P}}
from all single lower tolerances if
f_{c}

is of type sum or product
(
GJM06b
, Theorem 12)
and from all so-called

smallest includes
if
f_{c}
is of type bottleneck
(
TJ22
, Algorithm
1)
.

2.3
Single lower tolerances

Let
{\cal P}=({\cal E},D,c,f_{c})

be a CMP instance and let
LTE_{{\cal P}}:={\cal E}\setminus\bigcap_{S^{\ast}\in D^{\ast}}S^{\ast}
.
We define the
(single) lower tolerance

of each
e\in LTE_{{\cal P}}
as follows:

\displaystyle l_{{\cal P}}({e})

\displaystyle:=

\displaystyle\sup\;\{\alpha\in\mathbb{R}_{0}^{+}\mid\mbox{each opt.\ $S^{\ast}$ for}\ {\cal P}\ \mbox{is opt.\ for}\ {\cal P}_{c_{{-\alpha},{e}}}\}

\displaystyle:=

\displaystyle\inf\;\{\alpha\in\mathbb{R}_{0}^{+}\mid\mbox{some opt.\ $S^{\ast}$ for}\ {\cal P}\ \mbox{is not opt.\ for}\ {\cal P}_{c_{{-\alpha},{e}}}\}.

In the case of
l_{{\cal P}}({e})<\infty
, “sup” can be replaced by “max”.

This definition is a slight modification from the one provided in
GJM06b
.
By Observation
1
(b), applied to sets of cardinality one, it holds
for a decrease of
c(e)
by
\alpha\geq 0
that
if any optimal solution
S^{\ast}
with
e\in{\cal E}\setminus S^{\ast}
remains

S^{\ast}
with
e\in S^{\ast}
remains

Thus, both definitions are equivalent.

We can determine the set
LTE_{{\cal P}}
from all single upper tolerances if

is of type sum or product
(
GJM06b
, Theorem 6)
, but we need both all upper

is of type bottleneck

TJ22

Regular and reverse set upper tolerances

Let
{\cal P}=({\cal E},D,c,f_{c})

be a CMP instance and let

UTS_{{\cal P}}:=\{E\subseteq{\cal E}\mid\exists\,S^{\ast}\in D^{\ast}:\,E\subseteq S^{\ast}\}
.
We define the

for each

\displaystyle u_{{\cal P}}({E})

(2)

\displaystyle:=

\displaystyle\sup\;\Big\{\alpha\in\mathbb{R}\mathrel{\Big|}\mbox{for each optimal $S^{\ast}$ for}\ {\cal P}\

\displaystyle\exists\,\vec{\alpha}=(\alpha_{1},\alpha_{2},\dots,\alpha_{k}),\alpha_{1},\alpha_{2},\dots,\alpha_{k}\geq 0,\

\displaystyle\alpha=\sum_{l=1}^{k}\alpha_{l},\;S^{\ast}\ \mbox{is optimal for}\ {\cal P}_{c_{{\vec{\alpha}},{E}}}\Big\}.

In the case of
u_{{\cal P}}({E})<\infty
, “sup” can be replaced by “max”,

This definition is a slight modification from the one provided in
JT18
.
By Observation

(a) it holds
for an increase of

with

with

Thus, both definitions are equivalent.

We define the
reverse set upper tolerance

for each

\displaystyle\bar{u}_{{\cal P}}({E})

(3)

\displaystyle:=

\displaystyle\inf\;\Big\{\alpha\in\mathbb{R}\mathrel{\Big|}\exists\,\mbox{optimal $S^{\ast}$ for}\ {\cal P}\

\displaystyle\exists\,\vec{\alpha}=(\alpha_{1},\alpha_{2},\dots,\alpha_{k}),\;\alpha_{1},\alpha_{2},\dots,\alpha_{k}\geq 0,\

2.6
Interpretation of regular and reverse set tolerances

Consider a set of elements
E
for which all element costs can either increase (set upper tolerances)
or decrease (set lower tolerances).
There are certain combinations of cost changes for which all optimal solutions
S^{\ast}
remain optimal,
the optimality region (illustrated graphically for
|E|=2
in
JT24
). Note that the region in which
all solutions remain optimal is the intersection of the optimality regions of all optimal solutions.
The regular set tolerance is the
1
-norm distance to any point in this region farthest away from the origin,
whereas the reverse set lower tolerance is the (limit of the)
1
-norm distance to any closest point
outside the region.

4
Generalized definitions of upper and lower tolerances

4.1
New and extended definitions of tolerances

In this section, we wish to provide definitions of single and set tolerances to all
elements of
{\cal E}
and to all subsets of
{\cal E}
, respectively.
These definitions should be
consistent
with the current definition for the
domains on which single and set tolerances are defined. Moreover,
tolerances computations should be as
convenient
as possible.

Upper tolerances

For upper tolerances, we choose to extend the current definition
of single upper tolerances (
1
) to any
e\in{\cal E}

and the current definitions of
regular set upper tolerances (
2
)
and reverse set upper tolerances (
3
)
to any
E\subseteq{\cal E}
, which
we call
extended definitions
.
We use the prime to distinguish the extended definitions
and use the notation
u^{\prime}_{{\cal P}}({e})
for single upper tolerances
applied to the element
e

and the notation
u^{\prime}_{{\cal P}}({E})
/
\bar{u}^{\prime}_{{\cal P}}({E})

for regular / reverse set upper tolerances
applied to the subset
E
.

Lower tolerances

For lower tolerances, we introduce
new definitions
,
which for regular / reverse lower tolerances are as follows:

\displaystyle l^{\prime}_{{\cal P}}({E})

\displaystyle:=

\displaystyle\sup\;\Big\{\alpha\in\mathbb{R}\mathrel{\Big|}\exists\,\vec{\alpha}=(\alpha_{1},\alpha_{2},\dots,\alpha_{k}),

(4)

\displaystyle 0\leq\alpha_{1}<\delta(e_{1}),0\leq\alpha_{2}<\delta(e_{2}),\dots,0\leq\alpha_{k}

\displaystyle<\delta(e_{k}),\ \alpha=\sum_{l=1}^{k}\alpha_{l},\;{f_{c_{-\vec{\alpha},E}}}({\cal P}_{c_{{-\vec{\alpha}},{E}}})=f_{c}({\cal P})\}.

In the case of

, “sup” can be replaced by “max”.

\displaystyle\bar{l}^{\prime}_{{\cal P}}({E})

(5)

\displaystyle:=

\displaystyle\inf\;\Big\{\alpha\in\mathbb{R}\mathrel{\Big|}\exists\,\vec{\alpha}=(\alpha_{1},\alpha_{2},\dots,\alpha_{k}),

\displaystyle\;0\leq\alpha_{1}<\delta(e_{1}),0\leq\alpha_{2}<\delta(e_{2}),\dots,0\leq\alpha_{k}

\displaystyle l^{\prime}_{{\cal P}}({e})

(6)

\displaystyle:=

4.2
Concepts and motivation

Now, we explain why our definitions of upper tolerances are simply extensions
to the current definitions, whereas our definitions of lower tolerances are new concepts. Moreover,
we explain why one should not adopt new definitions for upper tolerances or use
extended definitions for lower tolerances.
Our new definitions of upper tolerances are extensions of the current definitions, whereas
for the new lower tolerance definitions we consider the change in the objective value.

Upper tolerances

We choose the extended definitions for upper tolerances,
because they are consistent with the current definitions,
while the new definitions are not.
For example, the upper tolerances of
v
,
w
,
x
,
y
in Example
2
are
0
under the current and the
extended definition, whereas the upper tolerances of
all
elements
v
,
w
,
x
,
y
,
z

in Example
2
would be infinite
under the new definition, as the objective value remains the same if the costs of each of these elements
increased by any positive amount.
This also illustrates that the interpretation of the resulting values can become problematic.

Lower tolerances

We show that the lower tolerances under the new definitions are consistent with those
according to the current definitions for single lower tolerances of any
e\in LTE_{{\cal P}}
and for set tolerances
of any
E\subseteq LTS_{{\cal P}}
.
Moreover, we show that computation formulas and bounds can be extended to any element in or any subset of
{\cal E}
without the need for

LTE_{{\cal P}}
or
LTS_{{\cal P}}
.

A further benefit of the new definition of single lower tolerances is that it is consistent with the
computation of lower tolerances of all elements both for the
1
-Tree Problem in
Hel00

(called
nearness values
) and for the Linear Assignment Problem
kindervater85

(called
hard dual values
).

In contrast, applying the extended definitions of lower tolerances reduces the computational
convenience, in particular for CBPs. For some
e\in{\cal E}\setminus LTE_{{\cal P}}
,
the single lower tolerance of

Conclusions and future work

In this work, we have addressed the challenge that current definitions of tolerances do not
apply to all elements or subsets of elements in combinatorial optimization problems. We
need to distinguish between upper tolerances, which concern cost increases of elements,
and lower tolerances, which concern cost decreases of elements.

The direct way to resolve this challenge is by extending the current definitions
to all elements. We use these extended definitions for upper tolerances,
in which the supremum
cost increases (of subsets) of elements are measured, but we find that current
computation formulas and bounds cannot be extended. In practice, it means that one first
has to determine whether elements belong to or are outside a given optimal solution
to compute upper tolerances.

For lower tolerances, on the other hand, we propose new definitions
based on the optimal objective value. We find that these new definitions are
consistent with the current definitions on its domain, and we find that the
computation formulas and bounds apply to all (subsets of) elements, meaning that we
no longer have to determine which elements belong to or are outside an optimal
solution for lower tolerances. Unfortunately, this approach cannot be applied to upper tolerances
in a meaningful way.

We hope that using this extended theory of set tolerances, heuristical
and exact algorithms will become more effective and easier to create.
