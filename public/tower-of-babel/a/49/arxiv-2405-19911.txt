Full weight spectrum one-orbit cyclic subspace codes
Chiara Castello, Olga Polverino, Ferdinando Zullo

Abstract
For a linear Hamming metric code of length n n over a finite field, the number of distinct weights of its codewords is at most n n . The codes achieving the equality in the above bound were called full weight spectrum codes. In this paper we will focus on the analogous class of codes within the framework of cyclic subspace codes. Cyclic subspace codes have garnered significant attention, particularly for their applications in random network coding to correct errors and erasures. We investigate one-orbit cyclic subspace codes that are full weight spectrum in this context. Utilizing number theoretical results and combinatorial arguments, we provide a complete classification of full weight spectrum one-orbit cyclic subspace codes.



Keywords
: Cyclic subspace code; Full spectrum weight code; Critical pair.

Introduction

Let
k
be a non-negative integer with
k\leq n
, the set of all
k
-dimensional
{\mathbb{F}}_{q}
-subspaces of
{\mathbb{F}}_{q^{n}}
, viewed as an
{\mathbb{F}}_{q}
-vector space, forms a
Grassmannian space
over
{\mathbb{F}}_{q}
, which is denoted by
\mathcal{G}_{q}(n,k)\subseteq\mathcal{P}_{q}(n)
, where
\mathcal{P}_{q}(n)
is the set of all the
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q^{n}}
. A
constant dimension subspace code
is a subset
\mathcal{C}
of
\mathcal{G}_{q}(n,k)
endowed with the metric defined as follows

d(U,V)=2k-2\dim_{{\mathbb{F}}_{q}}(U\cap V),

where
U,V\in\mathcal{C}
. This metric is also known as
subspace metric
.
As usual, we define the
minimum distance
of
\mathcal{C}
as

d(\mathcal{C})=\min\{d(U,V)\colon U,V\in\mathcal{C},U\neq V\}.

Subspace codes have been recently used for the error correction in random
network coding, see
[
14
]
.
The first class of subspace codes studied was the one introduced in
[
8
]
, which is known as
cyclic subspace codes
.
A subspace code
\mathcal{C}\subseteq\mathcal{G}_{q}(n,k)
is said to be
cyclic
if for every
\alpha\in{\mathbb{F}}_{q^{n}}^{*}
and every
V\in\mathcal{C}
then
\alpha V\in\mathcal{C}
.
If
\mathcal{C}
coincides with
\mathrm{Orb}(S)
, for some subspace
S
of
\mathbb{F}_{q^{n}}
, we say that
\mathcal{C}
is a
one-orbit
cyclic subspace code and
S
is said to be an its
representative
.

Similarly to the classical Hamming case, in
[
9
]
the following definition is given.

Definition 1.1
.

[
9
, Definition 2.4]

Let
S\in\mathcal{G}_{q}(n,k)
and let
{\mathcal{C}}=\mathrm{Orb}(S)
. Define

\omega_{2i}({\mathcal{C}})=\mid\{\alpha S\in\mathrm{Orb}(S)\colon\alpha\in\mathbb{F}_{q^{n}}^{*},d(S,\alpha S)=2i\}\mid

for
i\in\{1,\dots,k\}
. We call
(\omega_{2}({\mathcal{C}}),\dots,\omega_{2k}({\mathcal{C}}))

distance/weight distribution
of
{\mathcal{C}}
.

Gluesing-Luerssen and Lehmann in
[
9
]
studied the weight distribution of cyclic subspace codes. In particular, they highlighted how the weight distribution may be used as a tool for a finer classification of cyclic orbit codes. Indeed, since

d(\alpha S,\beta S)=d(S,\alpha^{-1}\beta S)
for any
\alpha,\beta\in\mathbb{F}_{q^{n}}^{*}
, the weight distribution provides the number of codeword pairs at a given distance.

In the classical framework of Hamming-metric codes, Delsarte in
[
6
]
studied the number of distinct distances for a code
\mathcal{C}
. When the code is linear this corresponds to investigate the distinct weights of the codewords in
\C
.
Denote by
L(k,q)
the maximum number of distinct non-zero weights a linear code of dimension
k
over
\mathbb{F}_{q}
may have.
In
[
17
]
, the authors proved that

L(k,q)\leq\frac{q^{k}-1}{q-1}.

As proved in
[
17
]
and
[
2
]
, codes with the equality in the above bound exist for any
q
and
k
and the codes with such a number of weights are called
maximum weight spectrum
codes.
If we also fix the length of the code and we denote by
L(n,k,q)
the maximum number of distinct non-zero weights a linear code of dimension
k
and length
n
over
\mathbb{F}_{q}
may have. Again in
[
17
]
it has been proved that

L(n,k,q)\leq n,

and the parameters of the codes reaching the equality have been completely determined in
[
1
]
. Such codes have been named
Full Weight Spectrum
codes.
In this paper we investigate the subspace analog of full weight spectrum codes in the context of cyclic subspace codes.

As before, denote by
\mathcal{L}(n,k,q)
the maximum number of distinct non-zero weights (in the sense of Definition
1.1
) that a one-orbit cyclic subspace code can have. Note that such a number corresponds to the maximum number of possible distinct distances that a one-orbit cyclic subspace code can have. For a code
\mathcal{C}=\mathrm{Orb}(S)
of
\mathcal{G}_{q}(n,k)
, the possible weights are determined by the intersection of
S
with its cyclic shifts
\alpha S
. Indeed, we have that

2\leq d(S,\alpha S)\leq 2k,

for any
\alpha\in\mathbb{F}_{q^{n}}
such that
S\neq\alpha S
, and since such a value is always even, then

\mathcal{L}(n,k,q)\leq k.

Similarly to the Hamming metric case, the one-orbit cyclic subspace codes having exactly
k
non-zero distinct weights are named
full weight spectrum (FWS)
codes.

In this paper, first we will show a classification result for one-orbit cyclic subspace codes with minimum distance equals to two, for which we will be able to give information on the weight distribution.
These results will yield a classification of FWS one-orbit cyclic subspace codes, precisely we will prove the following main theorem.

Theorem 1.2
.

Let
\C
be a one-orbit cyclic orbit code in
\mathcal{G}_{q}(n,k)
. Then
\C
is a full weight spectrum code if and only if
\C=\mathrm{Orb}(S)
, where
S
is one of the following

(1)

S=\langle 1,\lambda,\ldots,\lambda^{k-1}\rangle_{\mathbb{F}_{q}}
for some
\lambda\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q}
, where

k\leq\begin{cases}\frac{[\mathbb{F}_{q}(\lambda)\colon\mathbb{F}_{q}]+1}{2}&\mbox{if}\,\,\,\dim_{\mathbb{F}_{q}}(\mathbb{F}_{q}(\lambda))<n,\\
\frac{n}{2}&\mbox{if}\,\,\,\dim_{\mathbb{F}_{q}}(\mathbb{F}_{q}(\lambda))=n,\end{cases}

(2)

S=\langle 1,\lambda,\ldots,\lambda^{l-1}\rangle_{{\mathbb{F}}_{q^{2}}}\oplus\lambda^{l}\mathbb{F}_{q}
for some
\lambda\in\mathbb{F}_{q^{n}}\setminus{\mathbb{F}}_{q^{2}}
, where
k=2l+1
,
n
is even and

l<\frac{[{\mathbb{F}}_{q^{2}}(\lambda)\colon{\mathbb{F}}_{q^{2}}]}{2}
.

The proof of this result relies on some steps. First, using the classification of critical pairs of the Cauchy-Davenport inequality for extension fields, we obtain a classification result for one-orbit cyclic subspace codes having minimum distance two. Since all FWS codes have all the possible weights, the above classification result can be used as a starting point for the proof of Theorem
1.2
.
Indeed, the one-orbit cyclic subspace codes having minimum distance two can be divided into two families of codes: for the first one, using some geometric arguments, we can characterize those codes that are FWS codes. For the latter family we need a deep analysis of their intersection properties and we prove that, apart from the family (2), all the other codes of this family have at least one zero in their weight distribution, and so they cannot be FWS codes.

Structure of the paper.
In Section
2
we recall the notion of equivalence among cyclic subspace codes and we study some invariants.
Section
3
is dedicated to some technical results and to recall properties of the dual in extension fields. In Section
4
, we start the study of FWS cyclic subspace codes, we first point out some bounds on the parameters of an FWS code and then we prove that the families (1) and (2) described in Theorem
1.2
are FWS codes. For the Family (1) we completely determine the weight distribution.
Section
5
is devoted to the classification of one-orbit cyclic subspace codes with minimum distance two as a consequence of the classification of critical pairs of the linear analog of the Cauchy-Davenport inequality. In Section
6
we provide the proof of Theorem
1.2
. To this aim, we study the weight distribution of the codes having minimum distance two and we show that, apart from those in (2) of Theorem
1.2
, there is always a zero in the weight distribution. The last section provides some consequences of our results for linear sets and rank-metric codes.

2
Equivalence and invariants

The study of the equivalence for subspace codes was initiated by Trautmann in
[
18
]
and the case of cyclic subspace codes has been investigated in
[
10
]
by Gluesing-Luerssen and Lehmann. In particular, in the latter the authors focused on the case of cyclic orbit codes, which are by definition orbits of an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q}^{n}
under the action of a Singer subgroup
G
of
\mathrm{GL}(n,q)
, that is a cyclic subgroup of order
q^{n}-1
of the group of invertible matrices of order
n
over
\mathbb{F}_{q}
.
By identifying
\mathbb{F}_{q}^{n}
with the field extension
\mathbb{F}_{q^{n}}
as an
\mathbb{F}_{q}
-vector space, we can identify the action of
\mathrm{GL}(n,q)
on the set of
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q}^{n}
with the action of
\mathrm{GL}_{n}(q)
on the set of
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q^{n}}
, where
\mathrm{GL}_{n}(q)
is the group of
\mathbb{F}_{q}
-vector space automorphisms of
\mathbb{F}_{q^{n}}
. In this way, the subgroup of
\mathrm{GL}_{n}(q)
given by the multiplicative maps
x\mapsto ax
for any
a\in\mathbb{F}_{q^{n}}^{*}
is isomorphic to
\mathbb{F}_{q^{n}}^{*}
and so it turns out to be a Singer subgroup of
\mathrm{GL}_{n}(q)
. In this case, the orbits take the following explicit form

\mathrm{Orb}_{\mathbb{F}_{q^{n}}^{*}}(S)=\{\alpha S\mid\alpha\in\mathbb{F}_{q^{n}}^{*}\},

where
S
is an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q^{n}}
and
\alpha S=\{\alpha\cdot s\,:\,s\in S\}
is said to be a
cyclic shift
of
S
.
Since any Singer subgroup of
\mathrm{GL}_{n}(q)
is conjugate to
\mathbb{F}_{q^{n}}^{*}
(see
[
12
, II.7, pp.187]
), we will only consider orbit codes under the action of
G=\mathbb{F}_{q^{n}}^{*}
and we will denote by
\mathrm{Orb}(S):=\mathrm{Orb}_{\mathbb{F}_{q^{n}}^{*}}(S)
. Note that the normalizer
\mathrm{N}_{\mathrm{GL}_{n}(q)}(\mathbb{F}_{q^{n}}^{*})
of
\mathbb{F}_{q^{n}}^{*}
in
\mathrm{GL}_{n}(q)
is isomorphic to
\mathrm{Gal}(\mathbb{F}_{q^{n}}|\mathbb{F}_{q})\rtimes\mathbb{F}_{q^{n}}^{*}
(see
[
10
, Theorem 2.4]
).

By
[
10
, Definition 3.5 and Theorem 2.4]
, we can give the following definitions.

Definition 2.1
.

Let
\mathcal{C}_{1},\mathcal{C}_{2}\subseteq\mathcal{G}_{q}(n,k)
. Then
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are called
(linearly) isometric
if there exists an isomorphism
\psi\in\mathrm{GL}_{n}(q)
such that
\psi(\mathcal{C}_{1})=\mathcal{C}_{2}
, where

\psi(\mathcal{C}_{1})=\{\psi(V)\colon V\in\mathcal{C}_{1}\}.

In this case
\psi
is called a
(linear) isometry
between
\mathcal{C}_{1}
and
\mathcal{C}_{2}
. In the special case, where
\mathcal{C}_{1}=\mathrm{Orb}(S_{1})
,
\mathcal{C}_{2}=\mathrm{Orb}(S_{2})
and
\psi(\mathcal{C}_{1})=\mathcal{C}_{2}
for some
\psi\in\mathrm{N}_{\mathrm{GL}_{n}(q)}(\mathbb{F}_{q^{n}}^{*})
, we call the cyclic orbit codes
\mathrm{Orb}(S_{1})
and
\mathrm{Orb}(S_{2})

Frobenius-isometric
and
\psi
a
Frobenius isometry
. Also, if
\mathcal{C}\subseteq\mathcal{G}_{q}(n,k)
, the
automorphism group
of
{\mathcal{C}}
is the group of linear isometries that fix
{\mathcal{C}}
, that is
Aut({\mathcal{C}}):=\{\psi\in\mathrm{GL}_{n}(q)\,:\;\psi({\mathcal{C}})={\mathcal{C}}\}
.

In the next we will introduce some integers associated with an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q^{n}}
that are invariant under the action of
\mathrm{N}_{\mathrm{GL}_{n}(q)}(\mathbb{F}_{q^{n}}^{*})
.

Definition 2.2
.

For any divisor
t
of
n
and for any
\mathbb{F}_{q}
-subspace
S
of
\mathbb{F}_{q^{n}}
, we denote by

\delta_{t}(S):=\dim_{\mathbb{F}_{q^{t}}}(\langle S\rangle_{{\mathbb{F}}_{q^{t}}}),

h_{t}(S):=\max\{\dim_{\mathbb{F}_{q^{t}}}(\bar{S})\colon\bar{S}\text{ is an }\mathbb{F}_{q}\text{-subspace of }S\text{ and }\bar{S}\text{ is an }\mathbb{F}_{q^{t}}\text{-subspace of }\mathbb{F}_{q^{n}}\}

and

m(S)=\min\{t\colon t\,|\,n\,\,\mbox{and}\,\,\delta_{t}(S)=1\}.

Moreover, if
m=m(S)
, then
{\mathbb{F}}_{q^{m}}
is the smallest subfield of
\mathbb{F}_{q^{n}}
containing a cyclic shift of
S
. If
m(S)=n
, then we will say that the subspace
S
is
generic
in
\mathbb{F}_{q^{n}}
.

Gluesing-Luerseen and Lehmann in
[
10
]
study the automorphisms group of one-orbit cyclic subspace codes and completely classify one-orbit cyclic subspace codes generated by generic subspaces.

Theorem 2.3
.

[
10
, Theorem 6.2(a)]

Let
{\mathcal{C}}=\mathrm{Orb}(S)
and
{\mathcal{C}}^{\prime}=\mathrm{Orb}(S^{\prime})

Clearly,

Definition 2.4

Let
{\mathcal{C}}
be a one-orbit cyclic subspace code in
\mathcal{G}_{q}(n,k)

. For any divisor

Remark 2.5

Note that the integers
\delta_{t}(\cdot)

and

In the next corollary, as a consequence of

Corollary 2.6
.

Let
{\mathcal{C}}_{1}
and
{\mathcal{C}}_{2}
be one-orbit cyclic subspace codes in

. If
{\mathcal{C}}_{1}
and
{\mathcal{C}}_{2}

m({\mathcal{C}}_{1})=m({\mathcal{C}}_{2})
.

Proof.

Let
m_{i}:=m({\mathcal{C}}_{i})
for

. By

\mathrm{GL}_{n/m_{i}}(q^{m_{i}})\unlhd\mathrm{Aut}({\mathcal{C}}_{i})\leq\mathrm{N}_{\mathrm{GL}_{n}(q)}(\mathrm{GL}_{n/m_{i}}(q^{m_{i}})),

(1)

for

, where
\mathrm{GL}_{n/m_{i}}(q^{m_{i}})=\{\psi\in\mathrm{GL}_{n}(q)\,:\,\psi\,\mbox{is}\,\,\mathbb{F}_{q^{m_{i}}}\,\,\mbox{-linear}\}
.
Since by
[

\mathrm{N}_{\mathrm{GL}_{n}(q)}(\mathrm{GL}_{n/m_{i}}(q^{m_{i}}))\cong\mathrm{Gal}(\mathbb{F}_{q^{m_{i}}}|\mathbb{F}_{q})\rtimes\mathrm{GL}_{n/m_{i}}(q^{m_{i}}),

from (

|\mathrm{GL}_{n/m_{i}}(q^{m_{i}})|\leq|\mathrm{Aut}({\mathcal{C}}_{i})|\leq m_{i}|\mathrm{GL}_{n/m_{i}}(q^{m_{i}})|,

(2)

for
i\in\{1,2\}
. If
{\mathcal{C}}_{1}
and
{\mathcal{C}}_{2}
are linearly isometric, then
\mathrm{Aut}({\mathcal{C}}_{1})
and
\mathrm{Aut}({\mathcal{C}}_{2})
are isomorphic groups and hence they have the same size. Now, by contradiction assume that

m_{2}>m_{1}

m_{i}=n/t_{i}

\prod_{i=0}^{t_{1}-1}(q^{n}-q^{m_{1}i})\leq|\mathrm{Aut}({\mathcal{C}}_{1})|=|\mathrm{Aut}({\mathcal{C}}_{2})|\leq m_{2}\prod_{i=0}^{t_{2}-1}(q^{n}-q^{m_{2}i}),

(3)

and hence, since

(4)

By (

3
Auxiliary results

In order to prove Theorem
1.2
, pur main result, we need to recall some definitions and properties, and to prove some preliminary results that will be used later.

As first, we recall that, given an
\mathbb{F}_{q}
-subspace
S
of
\mathbb{F}_{q^{n}}
, the
stabilizer of
S
is

H(S)=\{x\in\mathbb{F}_{q^{n}}^{*}\colon xS=S\}\cup\{0\}.

Note that
H(S)
is a subfield of
\mathbb{F}_{q^{n}}
and
S
is linear over
H(S)
. This implies that also
S\cap\alpha S
is linear over
H(S)
for any
\alpha\in\mathbb{F}_{q^{n}}
. The following lemma gives us information on the weight distribution of a one-orbit cyclic subspace code in relation with the stabilizer of one of its representatives.

Lemma 3.1
.

Let
\C=\mathrm{Orb}(S)\subseteq\mathcal{G}_{q}(n,k)
and let
(\omega_{2}(\C),\dots,\omega_{2k}(\C))
be its weight distribution. If
\omega_{2i}(\C)>0
for some
i\in\{1,\dots,k\}
, then
k\equiv i\pmod{[H(S)\colon\mathbb{F}_{q}]}
.

Proof.

If
\omega_{2i}(\C)>0
then there exists
\alpha\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q}
such that
d(S,\alpha S)=2k-2\cdot\dim_{\mathbb{F}_{q}}(S\cap\alpha S)=2i
, i.e.
\dim_{\mathbb{F}_{q}}(S\cap\alpha S)=k-i
. Since
S\cap\alpha S
is an
H(S)
-subspace of
\mathbb{F}_{q^{n}}
, we have the desired congruence.
∎

To prove our main result, we will investigate some properties on the weight distribution of the codes of the families given in Theorem
1.2
. To this aim, we will need the orthogonal complement of a subspace defined by the trace function.

Remark 3.2
.

The trace function
\mathrm{Tr}_{\mathbb{F}_{q^{n}}/\mathbb{F}_{q}}\colon a\in\mathbb{F}_{q^{n}}\mapsto\displaystyle\sum_{i=0}^{n-1}a^{q^{i}}\in\mathbb{F}_{q}

is an
\mathbb{F}_{q}
-linear map of
\mathbb{F}_{q^{n}}
and it also defines a nondegenerate, symmetric, bilinear form as follows:

(a,b)\in\mathbb{F}_{q^{n}}\times\mathbb{F}_{q^{n}}\mapsto\mathrm{Tr}_{\mathbb{F}_{q^{n}}/\mathbb{F}_{q}}(ab)\in\mathbb{F}_{q}.

Therefore, for any subset
S\subseteq\mathbb{F}_{q^{n}}
we may define the orthogonal complement
(or dual subspace)
S^{\perp}
of
S
in the following way:

S^{\perp}=\{a\in\mathbb{F}_{q^{n}}\colon\mathrm{Tr}_{\mathbb{F}_{q^{n}}/\mathbb{F}_{q}}(ab)=0\text{ for any b}\in S\}.

Note that if
\mathbb{F}_{q^{t}}
is a subfield of
\mathbb{F}_{q^{n}}
and
W
is an
\mathbb{F}_{q^{t}}
-subspace of
\mathbb{F}_{q^{n}}
, then
W^{\perp}
is an
\mathbb{F}_{q^{t}}
-subspace of
\mathbb{F}_{q^{n}}
as well, i.e. the orthogonal complement
\perp
preserves the field of linearity of the
\mathbb{F}_{q}
-subspaces.

As we will see in the next section, the
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q^{n}}
that admit a basis defined by consecutive powers of the same element, define cyclic subspace codes for which it is possible to determine the weight distribution. Also, in some cases there is no zero in the weight distribution. In what follows, we will say that an
\mathbb{F}_{q}
-subspace
S
of
\mathbb{F}_{q^{n}}
of dimension
k
admits a

, if there exist
\rho,\lambda\in\mathbb{F}_{q^{n}}^{*}
such that
S=\rho\langle 1,\lambda,.....\lambda^{k-1}\rangle
. In
[
15
, Proposition 2.9]
it has been proved that the orthogonal complement of a subspace which has a polynomial basis, has a polynomial basis as well.

Proposition 3.3
.

[
15
, Proposition 2.9]

Let
\lambda\in\mathbb{F}_{q^{n}}
such that
\mathbb{F}_{q}(\lambda)=\mathbb{F}_{q^{n}}
. Let
f(x)=a_{0}+a_{1}x+\dots+a_{n-1}x^{n-1}+x^{n}
be the minimal polynomial of
\lambda
over
\mathbb{F}_{q}
. Let
W=\langle 1,\lambda,\dots,\lambda^{l-1}\rangle_{\mathbb{F}_{q}}
with
l\in\{1,\dots,n-1\}
. Then
W^{\perp}=\delta^{-1}\langle 1,\lambda,\dots,\lambda^{n-l-1}\rangle_{\mathbb{F}_{q}}
, where
\delta=f^{\prime}(\lambda)
.

The following proposition gives some properties of
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q^{n}}
contained in an
\mathbb{F}_{q^{t}}
-subspace of
\mathbb{F}_{q^{n}}
.

Proposition 3.4
.

Let
t\mid n
and let
U
be an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q^{n}}
contained in an
\mathbb{F}_{q^{t}}
-subspace
W
of
\mathbb{F}_{q^{n}}
of dimension
l
. Suppose that
\dim_{\mathbb{F}_{q}}(U)=lt-1=\dim_{\mathbb{F}_{q}}(W)-1
. Then there exists an
\mathbb{F}_{q^{t}}
-subspace

of
\mathbb{F}_{q^{n}}
such that

\dim_{\mathbb{F}_{q^{t}}}(T)=l-1\,\,\text{ and }\,\,T\subseteq U.

Also, if
\xi\mathbb{F}_{q^{t}}\subseteq W
, then either
\xi\mathbb{F}_{q^{t}}\subseteq U
or
\dim_{\mathbb{F}_{q}}(U\cap\xi\mathbb{F}_{q^{t}})=t-1
.

Proof.

Let
n=st
and note that
\dim_{\mathbb{F}_{q}}(U^{\perp})=(s-l)t+1
and
\dim_{\mathbb{F}_{q}}(W^{\perp})=(s-l)t
. Since
U\subseteq W
, it results
W^{\perp}\subseteq U^{\perp}
i.e.

U^{\perp}=W^{\perp}\oplus\langle v\rangle_{\mathbb{F}_{q}}\subset W^{\perp}\oplus\langle v\rangle_{\mathbb{F}_{q^{t}}}

for some
v\in U^{\perp}\setminus W^{\perp}
. Let
V=W^{\perp}\oplus\langle v\rangle_{\mathbb{F}_{q^{t}}}
, then by Remark
3.2
,
V
is an
\mathbb{F}_{q^{t}}
-subspace of dimension
s-l+1
over
\mathbb{F}_{q^{t}}
and hence
V^{\perp}=T
is an
\mathbb{F}_{q^{t}}
-subspace of dimension
l-1
and clearly,
T\subseteq U
. Finally, the last part of the assertion follows from the fact that
U
is an hyperplane of
W
seen as an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q^{n}}
.
∎

4
Existence and constructions of FWS codes

This section analyzes the existence of FWS codes and we will deal with two families of such codes. First we will derive some necessary conditions on the parameters of an FWS code, then we will present a first family of FWS codes for each possible choice of admissible parameters. Finally, we will present another non-equivalent family of FWS codes, which relies on some algebraic properties of the extension of
\mathbb{F}_{q}
-subspaces of
\mathbb{F}_{q^{n}}
over the quadratic extension
{\mathbb{F}}_{q^{2}}
when
n
is even.

4.1
Bounds on the parameters of an FWS code

In this section, we will see that not all potential parameter values permit the existence of
an FWS code. In fact, the following proposition will establish necessary conditions for the existence of such codes in
\mathcal{G}_{q}(n,k)
. These conditions will involve the parameters
n
,
k
, and
m({\mathcal{C}})
of the code.

Proposition 4.1
.

Let
{\mathcal{C}}=\mathrm{Orb}(S)
with
S\in\mathcal{G}_{q}(n,k)
and let
m:=m({\mathcal{C}})
. If
m<n
and
\omega_{2k-2}(\C)\neq 0
then
k\leq\frac{m+1}{2}
; if
m=n
and
\omega_{2k}(\C)\neq 0
then
k\leq n/2
.

Proof.

Let
m<n
and
\omega_{2k-2}(\C)\neq 0
. Note that, up to a cyclic shift, we may suppose that
S
is an
{\mathbb{F}}_{q}
-subspace of the subfield
{\mathbb{F}}_{q^{m}}
of
\mathbb{F}_{q^{n}}
. Since
\omega_{2k-2}(\C)\neq 0
, then
there exists
\alpha\in\mathbb{F}_{q^{n}}^{*}
such that
d(S,\alpha S)=2k-2
. This means that
\dim_{\mathbb{F}_{q}}(S\cap\alpha S)=1
and so
there exist
s,s^{\prime}\in S\setminus\{0\}
such that
s=\alpha s^{\prime}
, and hence

\alpha=ss^{\prime-1}\in{\mathbb{F}}_{q^{m}}.

Thus we have

m\geq\dim_{\mathbb{F}_{q}}(S+\alpha S)=2k-\dim_{\mathbb{F}_{q}}(S\cap\alpha S)=2k-1

and so
k\leq\frac{m+1}{2}
.
Let
m=n
and
\omega_{2k}(\C)\neq 0
. Then there exists
\alpha\in\mathbb{F}_{q^{n}}
such that
d(S,\alpha S)=2k
, i.e.

n\geq\dim_{\mathbb{F}_{q}}(S+\alpha S)=2k-\dim_{\mathbb{F}_{q}}(S\cap\alpha S)=2k

and so

k\leq n/2
.

∎

As an immediate consequence we get the following corollary.

Corollary 4.2
.

Let
\C=\mathrm{Orb}(S)\subseteq\mathcal{G}_{q}(n,k)
be an FWS code and let
m=m(\C)
. If
m<n
, then
k\leq\frac{m+1}{2}
; if
m=n
, then
k\leq n/2
.

In the next section we will show that these bounds are tight.

4.2
A family of FWS code

Now we exhibit some examples of FWS codes obtained by subspaces that have a polynomial basis, and so belonging to Family (1) of Theorem
1.2
. To this aim, we start from a technical lemma, which follows the arguments of
[
13
, Lemma 2.5]
.

We will adopt the following notation:
{\mathbb{F}_{q}}[x]_{\leq k-1}
denotes the set of the polynomials in the variable
x
with coefficients in
\mathbb{F}_{q}
and degree at most
k-1
.

Lemma 4.3
.

Let
\mathbb{F}_{q^{n}}=\mathbb{F}_{q}(\lambda)
and let
S=\langle 1,\lambda,\dots,\lambda^{k-1}\rangle_{\mathbb{F}_{q}}\in\mathcal{G}_{q}(n,k)
with
1<k<n-1
.

If
k\leq n/2
, then for any
j\in\{1,\dots,k\}
,

\dim_{\mathbb{F}_{q}}(S\cap\mu S)=j\,\text{ if and only if }\,\mu=\frac{p(\lambda)}{q(\lambda)}

with
p(x),q(x)\in\mathbb{F}_{q}[x]_{\leq k-1}
such that
\gcd(p(x),q(x))=1
and
k-j=\max\{\deg(p(x)),\deg(q(x))\}
.

In particular,

S\cap\mu S=\{p(\lambda)a(\lambda)\colon a(x)\in\mathbb{F}_{q}[x]_{\leq j-1}\}=\mu\{q(\lambda)a(\lambda)\colon a(x)\in\mathbb{F}_{q}[x]_{\leq j-1}\}.

If
n/2<k<n-1
, then for any
i\in\{2k+1-n,\dots,k\}

\dim_{\mathbb{F}_{q}}(S\cap\mu S)=i\text{ if and only if }\mu=\frac{p(\lambda)}{q(\lambda)}

with
p(x),q(x)\in\mathbb{F}_{q}[x]_{\leq k-1}
such that
\gcd(p(x),q(x))=1
and
k-i=\max\{\deg(p(x)),\deg(q(x)\}
.

Proof.

Let
1<k\leq n/2
and suppose
\mu=\frac{p(\lambda)}{q(\lambda)}
where
p(x),q(x)\in\mathbb{F}_{q}[x]_{\leq k-1}
such that
\gcd(p(x),q(x))=1
and
k-j=\max\{\deg(p(x)),\deg(q(x))\}
for
j\in\{1,\dots,k\}
.

For any
a(x)\in\mathbb{F}_{q}[x]_{\leq j-1}
we have that

p(\lambda)a(\lambda)\in S\text{ and }q(\lambda)a(\lambda)\in S,

thus

H=\{p(\lambda)a(\lambda)\colon a(\lambda)\in\mathbb{F}_{q}[\lambda]_{\leq j-1}\}=\mu\{q(\lambda)a(\lambda)\colon a(\lambda)\in\mathbb{F}_{q}[\lambda]_{\leq j-1}\}\subseteq S\cap\mu S.

Using
[
13
, Lemma 2.5]
, one can show that
H=S\cap\mu S
and hence

\dim_{\mathbb{F}_{q}}(S\cap\mu S)=j
.

Conversely, suppose that
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=j
for some
j\in\{1,\dots,k\}
. Then there exist
p(\lambda),q(\lambda)\in S
such that

\mu=\frac{p(\lambda)}{q(\lambda)}.

Of course we may suppose
\gcd(p(x),q(x))=1
and, since
k\leq n/2
, the pair of coprime polynomials
(p(x),q(x))
such that
\mu=\frac{p(\lambda)}{q(\lambda)}
is uniquely determined (up to scalars in
\mathbb{F}_{q}
). Moreover, by the first implication, we get that
S\cap\mu S=H
and hence

k-j=\max\{\deg(p(x)),\deg(q(x))\}.

Let
n/2<k<n-1
, then by Proposition
3.3
we know that

S^{\perp}=\rho\langle 1,\lambda,\dots,\lambda^{n-k-1}\rangle_{\mathbb{F}_{q}}

for some
\rho\in\mathbb{F}_{q^{n}}^{*}
. In particular
1<n-k<n/2
and hence we may apply the first case to
S^{\perp}
. Then we get that

\dim_{\mathbb{F}_{q}}(S^{\perp}\cap\mu S^{\perp})=j\text{ if and only if }\mu=\frac{p(\lambda)}{q(\lambda)},

with
p(x),q(x)\in\mathbb{F}_{q}[x]_{\leq n-k-1}
such that
\gcd(p(x),q(x))=1
and

n-k-j=\max\{\deg(p(x)),\deg(q(x))\}\mbox{ for }j\in\{1,\dots,n-k\}.

Moreover, since
(\mu S)^{\perp}=\mu^{-1}S^{\perp}
,

j=\dim_{\mathbb{F}_{q}}(S^{\perp}\cap\mu S^{\perp})=\dim_{\mathbb{F}_{q}}(S+\mu^{-1}S)^{\perp}=n-\dim_{\mathbb{F}_{q}}(S+\mu^{-1}S)=n-2k+\dim_{\mathbb{F}_{q}}(S\cap\mu^{-1}S).

Thus, since
\dim_{\mathbb{F}_{q}}(S\cap\mu^{-1}S)=\dim_{\mathbb{F}_{q}}(S\cap\mu S)
, we have that for
j\in\{1,\dots,n-k\}
,

\dim_{\mathbb{F}_{q}}(S^{\perp}\cap\mu S^{\perp})=j\text{ if and only if }\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2k+j-n.

The statement follows setting
i=2k+j-n
.
∎

We can now use the above lemma to determine the weight distribution of one-orbit cyclic subspace codes defined by subspaces admitting a polynomial basis. The determination of the weight distribution is related to the problem of determining the weight distribution of certain type of linear sets on the projective line (see
[
13
, Theorem 2.7]
) and to the problem of counting the number of coprime polynomials over finite fields (see
[
5
]
).

Theorem 4.4
.

Let
\lambda\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q}
and let
t:=[\mathbb{F}_{q}(\lambda):\mathbb{F}_{q}]
. Let
S=\langle 1,\lambda,\ldots,\lambda^{k-1}\rangle_{\mathbb{F}_{q}}
with
1<k<t
. Then for the code
{\mathcal{C}}=\mathrm{Orb}(S)
we have the following.

If
k\leq t/2
, then

\omega_{2i}(\C)=\begin{cases}(q+1)q^{2i-1}&\text{if}\,\,i\in\{1,\ldots,k-1\},\\
&\\
\frac{q^{n}-q^{2k-1}}{q-1}&\text{if}\,\,i=k.\end{cases}

If
k>t/2
, then

\omega_{2i}(\C)=\begin{cases}(q+1)q^{2i-1}&\text{if}\,\,i\in\{1,\ldots,t-k-1\},\\
&\\
\frac{q^{t}-q^{2(t-k)-1}}{q-1}&\text{if}\,\,i=t-k\\
&\\
0&\text{if}\,\,i\in\{t-k+1,\ldots,k-1\}\text{ and }t-k+1\neq k,\\
&\\
\frac{q^{n}-q^{t}}{q-1}&\text{if}\,\,i=k.\end{cases}

Proof.

We start by noting that

\omega_{2i}(\C)=\mid\{\mu S\in{\mathcal{C}}\colon\mu\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q}\,\text{ and }\,\dim_{\mathbb{F}_{q}}(S\cap\mu S)=k-i\}\mid

for any
i\in\{1,\ldots,k\}
.
Suppose that
k\leq t/2
. By Lemma
4.3
,
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=j
if and only if
\mu=\frac{p(\lambda)}{q(\lambda)}

with
p(x),q(x)\in\mathbb{F}_{q}[x]_{\leq k-1}
such that
\gcd(p(x),q(x))=1
and
k-j=\max\{\deg(p(x)),\deg(q(x))\}
.
Note that if
\mu\notin\mathbb{F}_{q}(\lambda)={\mathbb{F}}_{q^{t}}
then
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=0
. Hence, assume that
\mu\in{\mathbb{F}}_{q^{t}}
.
Therefore, we have a one-to-one correspondence between those
\mu\in{\mathbb{F}}_{q^{t}}
such that
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=k-i
for some
i\in\{1,\dots,k-1\}
and pairs of coprime polynomials in
(\mathbb{F}_{q}[x]_{\leq k-1})^{2}
(up to scalars of
\mathbb{F}_{q}
).
In order to find the
\omega_{2i}
’s we need to determine the number of such a pairs for which the maximum degree among the two polynomials is
i
.
These values have been computed in the proof of
[
13
, Lemma 2.6]
,
obtaining that
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=k-i
for
q^{2i+1}-q^{2i-1}
different values of
\mu
in
{\mathbb{F}}_{q^{t}}
for any
i\in\{1,\ldots,k-1\}
and
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=0
for
q^{t}-q^{2k-1}
different values of
\mu
in
{\mathbb{F}}_{q^{t}}
, as this corresponds to those
\mu
which cannot be written as the ratio of two polynomials over
\mathbb{F}_{q}
in
\lambda
of degree less than
k
. Taking into account that for any
\mu\in\mathbb{F}_{q^{n}}\setminus{\mathbb{F}}_{q^{t}}
we have
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=0
, the number of non-zero
\mu\in\mathbb{F}_{q^{n}}
such that
d(S,\mu S)=2k
is
(q^{n}-q^{t})+(q^{t}-q^{2k-1})
.
In particular,
\omega_{2(k-1)}(\C)>0
and hence by Lemma
3.1
we get
H(S)=\mathbb{F}_{q}
and hence
\mu S=S
if and only if
\alpha\in\mathbb{F}_{q}^{*}
. So

\omega_{2i}(\C)=\frac{q^{2i+1}-q^{2i-1}}{q-1}\,\,\text{ for }i\in\{1,\ldots,k-1\}\,\text{ and }\,\omega_{2k}(\C)=\frac{q^{n}-q^{2k-1}}{q-1}.

Suppose now that
k>t/2
and consider
S^{\perp}
the dual of
S
in
{\mathbb{F}}_{q^{t}}
as in Remark
3.2
.
By Proposition
3.3
, we have that

S^{\perp}=\delta\langle 1,\lambda,\ldots,\lambda^{t-k-1}\rangle_{\mathbb{F}_{q}},

for some
\delta\in{\mathbb{F}}_{q^{t}}^{*}
. Since
\dim_{\mathbb{F}_{q}}(S^{\perp})=t-k<t/2
and

\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2k-t+\dim_{\mathbb{F}_{q}}(S^{\perp}\cap\mu S^{\perp}),

for any
\mu\in\mathbb{F}_{q^{t}}
, we get

d(S,\mu S)=d(S^{\perp},\mu S^{\perp})\quad\forall\mu\in\mathbb{F}_{q^{t}}^{*},

so for any
\mu\in\mathbb{F}_{q^{t}}^{*}
, we can use the above arguments to get the second part of the assert. In particular, there exist
q^{t}-q^{2(t-k)-1}
elements
\mu\in{\mathbb{F}}_{q^{t}}
such that
d(S,\mu S)=2(t-k)
, whereas there are no elements
\mu
in
\mathbb{F}_{q^{t}}
such that
d(S,\mu S)=2i
for
i\in\{t-k+1,\dots,k-1\}
if
t-k+1<k
. Finally, if
\mu\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q^{t}}
we have
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=0
and hence
d(S,\mu S)=2k
.

∎

Remark 4.5
.

Note that the weight distribution depends on the value
\lambda
only for the degree extension
\mathbb{F}_{q}(\lambda)/\mathbb{F}_{q}
.

As a consequence we can determine under which conditions on the parameters a subspace with a polynomial basis gives an FWS code.

Corollary 4.6
.

For any
\lambda\in\mathbb{F}_{q^{n}}\setminus\mathbb{F}_{q}
, let
t=\dim_{\mathbb{F}_{q}}(\mathbb{F}_{q}(\lambda))
and
S=\langle 1,\lambda,\ldots,\lambda^{k-1}\rangle_{\mathbb{F}_{q}}
with
1<k<t
. Then
{\mathcal{C}}=\mathrm{Orb}(S)
is an FWS code in
\mathcal{G}_{q}(n,k)
in the following cases:

1.

t<n
and
k\leq\frac{t+1}{2}
;

2.

t=n
and
k\leq\frac{n}{2}
.

Also, in both cases
m({\mathcal{C}})=t
and the weight distribution of
{\mathcal{C}}
is

\omega(\C)=\left((q+1)q,(q+1)q^{3},\dots,(q+1)q^{2i-1},\dots,(q+1)q^{2(k-1)-1},\frac{q^{n}-q^{2k-1}}{q-1}\right)

if
k\leq\frac{t}{2}
; whereas the weight distribution of
{\mathcal{C}}
is

\omega(\C)=\left((q+1)q,(q+1)q^{3},\dots,(q+1)q^{2i-1},\dots,,(q+1)q^{2(t-k-1)-1},\frac{q^{t}-q^{2k-3}}{q-1},\frac{q^{n}-q^{2k-1}}{q-1}\right)

if
k=\frac{t+1}{2}
and
t<n
.

Proof.

If
k\leq t/2
, then
by Theorem
4.4
we have
\omega_{2i}(\C)>0
for any
i\in\{1,\dots,k\}
, so
{\mathcal{C}}
has exactly
k
non-zero distinct weights, i.e.
{\mathcal{C}}
is an FWS code.
If
k=\frac{t+1}{2}
and
t<n
, then by Theorem
4.4
we have that
\omega_{2j}(\C)>0
for any
j\in\{1,\dots,\frac{t-3}{2}\}
. Also,
\omega_{t-1}(\C)=\frac{q^{t}-q^{t-2}}{q-1}>0
and
\omega_{t+1}(\C)=\frac{q^{n}-q^{t}}{q-1}>0
. Therefore
{\mathcal{C}}
has
k
non-zero distinct weights, i.e.
{\mathcal{C}}
is an FWS code. Finally, since
\mathbb{F}_{q^{t}}=\mathbb{F}_{q}(\lambda)=\mathbb{F}_{q}(S)
, we have that
m({\mathcal{C}})=t
and the weight distributions comes from Theorem
4.4
.
∎

Therefore, for any admissible values of
k,t,n
and
q
(that is, satisfying the bound in Corollary
4.2
) there exists an FWS one-orbit cyclic subspace code
{\mathcal{C}}
in
\mathcal{G}_{q}(n,k)
. Precisely, we get the following result.

Corollary 4.7
.

For any positive integer
n
, for any divisor
t
of
n
, with either
1<t<n
and
k\leq(t+1)/2
or
t=n
and
k\leq n/2
, and any prime power
q
, there exists
\C=\mathrm{Orb}(S)
in
\mathcal{G}_{q}(n,k)
with
m(\C)=t
which is an FWS code.

Proof.

The proof follows by Corollaries
4.2
and
4.6
.

∎

4.3
Other examples of FWS codes

In this section, another family of FWS codes will be described. We will see that these examples arise from subspaces belonging to Family (2) of Theorem
1.2
. To achieve this goal, we need the following proposition, that will allow us to get some bounds on the parameters of these codes, and then a technical proposition to get information on the weight distribution of such codes.

Proposition 4.8
.

Let
n
be an even positive integer and let

S=\bar{S}\oplus b\mathbb{F}_{q},

(6)

where
\bar{S}
is an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
of dimension
l
over
{\mathbb{F}}_{q^{2}}
and
b\in\mathbb{F}_{q^{n}}\setminus\bar{S}
. Denoted by
Y=\langle S\rangle_{{\mathbb{F}}_{q^{2}}}=\bar{S}\oplus b{\mathbb{F}}_{q^{2}}
, for any
\mu\in\mathbb{F}_{q^{n}}
one of the following occurs:

I)

\bar{S}\cap\mu\bar{S}=S\cap\mu S=Y\cap\mu Y
and
S\cap\mu S
is an
{\mathbb{F}}_{q^{2}}
-subspace;

II)

\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})=\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)-2
,
\dim_{\mathbb{F}_{q}}(S\cap\mu S)\in\{\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S}),\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})+1\}
and
S\cap\mu S
is an
{\mathbb{F}}_{q^{2}}
-subspace if and only if
S\cap\mu S=\bar{S}\cap\mu\bar{S}
;

III)

\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2+\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})=\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)-2
and
S\cap\mu S
is not an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
.

In particular, if
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2l
, then either
\mu\in H(Y)
or
\mu\in H(\bar{S})
.

Proof.

Note that
\bar{S}\subset S\subset Y
, then we easily get

\bar{S}\cap\mu\bar{S}\subseteq S\cap\mu S\subseteq Y\cap\mu Y

(7)

and

\bar{S}+\mu\bar{S}\subseteq S+\mu S\subseteq Y+\mu Y.

(8)

Moreover,
\bar{S}\cap\mu\bar{S}
and
Y\cap\mu Y
are
{\mathbb{F}}_{q^{2}}
-subspaces of
\mathbb{F}_{q^{n}}
. Let
\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})=2h^{\prime}
and
\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)=2h
. Then by (
7
) we have
h^{\prime}\leq h
. Moreover, using the Grassmann formula we get
\dim_{\mathbb{F}_{q}}(S+\mu S)=4l+2-\dim_{\mathbb{F}_{q}}(S\cap\mu S)
and by (
8
) we obtain that

4l-\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})\leq\dim_{\mathbb{F}_{q}}(S+\mu S)\leq 4l+4-\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)

(9)

and so

2h-2\leq\dim_{\mathbb{F}_{q}}(S\cap\mu S)\leq 2h^{\prime}+2.

(10)

Therefore, we get that
h\in\{h^{\prime},h^{\prime}+1,h^{\prime}+2\}
. We will analyze these cases separately.

Case 1:
If
h^{\prime}=h
, by (
7
) we have that
\bar{S}\cap\mu\bar{S}=S\cap\mu S=Y\cap\mu Y
and so
S\cap\mu S
is an
{\mathbb{F}}_{q^{2}}
-subspace. This corresponds to I) of the statement.

Case 2:
If
h=h^{\prime}+1
, by (
10
) we have that
2h^{\prime}\leq\dim_{\mathbb{F}_{q}}(S\cap\mu S)\leq 2h^{\prime}+2
.

If
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2h^{\prime}=\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})
, then by (
7
) we get
\bar{S}\cap\mu\bar{S}=S\cap\mu S\subset Y\cap\mu Y
and so
S\cap\mu S
is an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
.

If
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2h^{\prime}+2=\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)
, then
S\cap\mu S=Y\cap\mu Y
is an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
of dimension
h^{\prime}+1
. Since
\bar{S}
is the maximal
{\mathbb{F}}_{q^{2}}
-subspace contained in
S
, and
\mu\bar{S}
is the maximal
{\mathbb{F}}_{q^{2}}
-subspace contained
\mu S
, then
S\cap\mu S\subseteq\bar{S}\cap\mu\bar{S}
, a contradiction to their dimensions. . This corresponds to II) of the statement.

Case 3:
If
h=h^{\prime}+2
, then by (
10
) we get
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2h^{\prime}+2
. Moreover, if
S\cap\mu S
is an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
, then
S\cap\mu S\subseteq\bar{S}\cap\mu\bar{S}
, a contradiction. Therefore
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2h^{\prime}+2
and
S\cap\mu S
is not an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
. . This corresponds to III) of the statement.

Finally, if
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=2l
, then in Case III) we have that
Y\cap\mu Y=Y
and so
\mu\in H(Y)
. In Cases I and II we get
\mu\in H(\bar{S})
.
∎

From the previous proposition, we derive a necessary condition for obtaining an FWS code starting from a subspace
S
as in (
6
). This condition will be used in Section 6 to prove Theorem 6.2.

Corollary 4.9
.

Let
S=\bar{S}\oplus b\mathbb{F}_{q}
be an
\mathbb{F}_{q}
-subspace of
\mathbb{F}_{q^{n}}
where
\bar{S}
is an
{\mathbb{F}}_{q^{2}}
-subspace of
\mathbb{F}_{q^{n}}
of dimension
2l
over

5
Critical pairs and a classification of cyclic subspace codes with minimum distance two

In the study the weight distribution of a cyclic subspace code, it is crucial to understand the intersections of a subspace with its shifts and hence to evaluate its multiplicative behavior within the field. Such behavior is examined in certain problems that serve as linear analogues to some additive combinatorial questions. Indeed, critical pairs are classically studied in theory of combinatorial number theory and are defined as a pair of sets of a group
(G,\cdot)
with the property that their product set has size smaller than the sum of their sizes. This is connected with Kneser’s Addition Theorem and the Cauchy-Davenport inequality. Recently, linear analogues of these results have been investigated. The linear analogue of Kneser’s Addition Theorem has been proved by Hou, Leung and Xiang in
[
11
]
for separable extensions fields, motivated by a problem on different sets.

In the next we will use the following notation: let
S,T\subseteq{\mathbb{L}}
, where
{\mathbb{L}}
is any field and
{\mathbb{F}}
is a subfield of
{\mathbb{L}}
, then

ST=\{s\cdot t\colon s\in S,t\in T\},

and

denotes the
{\mathbb{F}}
-span in
{\mathbb{L}}
of
ST
.

Theorem 5.1
.

[
11
, Theorem 2.4]

Let

be a separable field extension and let

and
T
be

-subspaces of

In
[
11
]

Then Bachoc, Serra and Zémor in

Bachoc, Serra and Zémor in

\dim_{\mathbb{F}_{q}}(S)=4h+3
. Let
\bar{S}=\langle 1,\lambda,\dots,\lambda^{h-1}\rangle_{{\mathbb{F}}_{q^{4}}}\oplus\lambda^{h}{\mathbb{F}}_{q^{2}}
and suppose that

\mathrm{Orb}(\bar{S})\in\mathcal{G}_{q^{2}}(\frac{n}{2},2h+1)
is an FWS code.
Then
\omega_{4}(\mathrm{Orb}(S))=0
, and so
\mathrm{Orb}(S)
is not an FWS code in
\mathcal{G}_{q}(n,4h+3)
.

Proof.

Suppose by contradiction that
\omega_{4}(\mathrm{Orb}(S))\neq 0
and so there exists
\mu\in\mathbb{F}_{q^{n}}
such that
\dim_{\mathbb{F}_{q}}(S\cap\mu S)=4h+1
. Let
Y=\langle S\rangle_{{\mathbb{F}}_{q^{2}}}=\langle 1,\lambda,\dots,\lambda^{h-1}\rangle_{{\mathbb{F}}_{q^{4}}}\oplus\lambda^{h}{\mathbb{F}}_{q^{2}}\oplus b{\mathbb{F}}_{q^{2}}=\bar{S}\oplus b{\mathbb{F}}_{q^{2}}
. Then by Proposition
4.8
, it follows that

\dim_{\mathbb{F}_{q}}(\bar{S}\cap\mu\bar{S})=4h\text{ and }\dim_{\mathbb{F}_{q}}(Y\cap\mu Y)=4h+2.

Note that
\bar{S}=\bar{\bar{S}}\oplus\lambda^{h}{\mathbb{F}}_{q^{2}}
where
\bar{\bar{S}}=\langle 1,\lambda,\dots,\lambda^{h-1}\rangle_{{\mathbb{F}}_{q^{4}}}
and
\dim_{{\mathbb{F}}_{q^{2}}}(\bar{S}\cap\mu\bar{S})=2h=\dim_{{\mathbb{F}}_{q^{2}}}(\bar{S})-1
. Then by applying again Proposition
4.8
we have that

\,\mbox{either}\,\,\,\mu\in H(\bar{\bar{S}})={\mathbb{F}}_{q^{4}}\,\,\,\mbox{or}\,\,\mu\in H(\langle\bar{S}\rangle_{{\mathbb{F}}_{q^{4}}}).

Since
\mathrm{Orb}(\bar{S})
is an FWS code, by (iii) of Theorem
6.3
, it follows that
H(\langle\bar{S}\rangle_{{\mathbb{F}}_{q^{4}}})={\mathbb{F}}_{q^{4}}
.
Therefore, we get
\mu\in{\mathbb{F}}_{q^{4}}\setminus{\mathbb{F}}_{q^{2}}
and
\bar{S}\cap\mu\bar{S}=\bar{\bar{S}}
. Moreover, there exists
\xi\in(S\cap\mu S)\setminus(\bar{S}\cap\mu\bar{S})
, i.e. there exist
p(x),q(x)\in{\mathbb{F}}_{q^{4}}[x]_{\leq h-1},w^{\prime},w\in{\mathbb{F}}_{q^{2}}^{*}
and
\beta,\beta^{\prime}\in\mathbb{F}_{q}^{*}
such that

\xi=p(\lambda)+\lambda^{h}w+b\beta=\mu(q(\lambda)+\lambda^{h}w^{\prime}+b\beta^{\prime}).

This implies that

(p(\lambda)-\mu q(\lambda))=\lambda^{h}(\mu w^{\prime}-w)+b(\mu\beta^{\prime}-\beta).

Note that
\mu\beta^{\prime}-\beta\neq 0
and
\mu w^{\prime}-w\neq 0
, since
\mu\in{\mathbb{F}}_{q^{4}}\setminus{\mathbb{F}}_{q^{2}}
. So that

b=\frac{p(\lambda)-\mu q(\lambda)}{\mu\beta^{\prime}-\beta}-\lambda^{h}\frac{\mu w^{\prime}-w}{\mu\beta^{\prime}-\beta}\in\langle 1,\lambda,\lambda^{2},....\lambda^{h}\rangle_{{\mathbb{F}}_{q^{4}}}

because
\frac{p(\lambda)-\mu q(\lambda)}{\mu\beta^{\prime}-\beta}\in\bar{\bar{S}}
and
\rho=\frac{\mu w^{\prime}-w}{\mu\beta^{\prime}-\beta}\in{\mathbb{F}}_{q^{4}}^{*}
. This implies that

S=\langle 1,\lambda,\dots,\lambda^{h-1}\rangle_{{\mathbb{F}}_{q^{4}}}\oplus\lambda^{h}{\mathbb{F}}_{q^{2}}\oplus\lambda^{h}\rho\mathbb{F}_{q}

and
\rho\notin{\mathbb{F}}_{q^{2}}
because otherwise
\dim_{\mathbb{F}_{q}}(S)<4h+3
.
Denote by
U={\mathbb{F}}_{q^{2}}\oplus\rho\mathbb{F}_{q}
, we have

S=\bar{\bar{S}}\oplus\lambda^{h}U\text{ and }\mu S=\bar{\bar{S}}\oplus\mu\lambda^{h}U.

Since
\dim_{\mathbb{F}_{q}}(U)=3
and
U\subset{\mathbb{F}}_{q^{4}}
, we get
\dim_{\mathbb{F}_{q}}(U\cap\mu U)\geq 2
and hence
\dim_{\mathbb{F}_{q}}(S\cap\mu S)\geq 4h+2
, a contradiction.
This means that
\dim_{\mathbb{F}_{q}}(S\cap\mu S)\neq 4h+1
for any
\mu\in\mathbb{F}_{q^{n}}
and hence
d(S,\mu S)\neq 4
for any
\mu\in\mathbb{F}_{q^{n}}
.
∎

6.2
.

4.9

7
Concluding remarks

In this paper we have provided a characterization result for one-orbit cyclic subspace codes without zeroes in their weight distribution, which we called
full weight spectrum codes
. This result may be also stated in a purely geometric way. Indeed, our classification result allows us to determine the orbits, under the action of a Singer group, of projective subspaces intersecting the orbit’s elements in all possible dimensions. Precisely, we have the following result.

Theorem 7.1
.

Let
\Sigma_{n-1}=\mathrm{PG}(n-1,q)
be the
(n-1)
-dimensional projective space over
\mathbb{F}_{q}
, let
G
be a Singer cycle of
\Sigma_{n-1}
and let
\mathcal{G}_{q}(n-1,k-1)
be the Grassmaniann of the
(k-1)
-dimensional subspaces
of
\Sigma_{n-1}
. Let
\Sigma_{k-1}
be a
(k-1)
-dimensional subspace of
\Sigma_{n-1}
and let
\mathcal{I}_{\mathrm{Orb}_{G}(\Sigma_{k-1})}=\{\Sigma_{k-1}\cap\varphi(\Sigma_{k-1})\,:\,\varphi\in G\}
be the set of all subspaces obtained intersecting two distinct elements of
\mathrm{Orb}_{G}(\Sigma_{k-1})
.
Then

\mathcal{I}_{\mathrm{Orb}_{G}(\Sigma_{k-1})}\cap\mathcal{G}_{q}(n-1,d-1)\neq\emptyset

for every
d\in\{0,\dots,k-1\}
if, and only if,
\Sigma_{k-1}
, up to the action of
\mathrm{PGL}(n,q)
, is defined by one of the vector subspaces defined in Theorem
1.2
.

Theorem
1.2
may be also used in other contexts such as in the theory of rank-metric codes.
Let
\C
be a rank-metric code in
{\mathbb{F}}_{q^{n}}^{2k}
with
\dim_{{\mathbb{F}}_{q^{n}}}(\C)=2
and having a generator matrix
G
whose column span (over
\mathbb{F}_{q}
) is of the form
S\times S
, for some
\mathbb{F}_{q}
-subspace
S
of
\mathbb{F}_{q^{n}}
with dimension
k
. Then, using
[
16
, Theorem 2]
, we have that

w(xG)=n-\dim_{\mathbb{F}_{q}}((S\times S)\cap x^{\perp}).

Therefore,
\C
has no zeroes in its weight distribution (
FWS
rank-metric code) if and only if
\mathrm{Orb}(S)
is an FWS cyclic subspace code.
Therefore, Theorem
1.2
provides a classification result for FWS rank-metric codes with the above assumptions.
There are still some problems that naturally arise in this paper:

•

It would be nice to determine the weight distribution of the codes in (2) of Theorem
1.2
.
We already know that the weight distributions of the codes in (1) and those in (2) of Theorem
1.2
are different.
Computational results show that the weight distribution does not depend on
\lambda
.

•

Is it possible to determine the equivalence classes of the codes in Theorem
1.2
under the action of linear isometries?

•

A natural generalization of FWS codes can be the following: let
r
be a natural number. We say that a code is
r
-FWS code if the last
r
entries of the weight distributions are zero and all the others are nonzero. In particular,
0
-FWS codes correspond to FWS codes. Is it possible to characterize
r
-FWS codes similarly to what has been done for FWS codes?
