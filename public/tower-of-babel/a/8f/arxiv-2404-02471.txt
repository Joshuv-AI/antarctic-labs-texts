Some bounds on the cardinality of the b b -symbol weight spectrum of codes
Hongwei Zhu, Shitao Li, Minjia Shi, Shu-Tao Xia, Patrick Solé

Abstract
The size of the Hamming distance spectrum of a code has received great attention in recent research. The main objective of this paper is to extend these significant theories to the b b -symbol distance spectrum. We examine this question for various types of codes, including unrestricted codes, additive codes, linear codes, and cyclic codes, successively. For the first three cases, we determine the maximum size of the b b -symbol distance spectra of these codes smoothly. For the case of cyclic codes, we introduce three approaches to characterize the upper bound for the cardinality of the b b -symbol weight spectrum of cyclic codes, namely the period distribution approach, the primitive idempotent approach, and the b b -symbol weight formula approach. As two by-products of this paper, the maximum number of symplectic weights of linear codes is determined, and a basic inequality among the parameters [ n , k , d H ​ ( 𝒞 ) ] q [n,k,d_{H}({\mathcal{C}})]_{q} of cyclic codes is provided.

Introduction

One of the most important topics in coding theory is to characterize the parameters of codes with a given structure. The parameters of a code include its length, size, minimum distance, cover radius, and so on. In 1973, Delsarte
[
16
]
introduced four fundamental parameters of an unrestricted code
C
: minimum distance
d(C)
, the number
s(C)
of distinct distances of
C
,
d(C^{\prime})
, and
s(C^{\prime})
, where
C^{\prime}
is the MacWilliams transform of
C
. In the linear case, these four fundamental parameters are reduced to the minimum weight and the weight spectrum of the given code and of its dual code. Delsarte
[
16
]
pointed out the combinatorial significance of these four fundamental parameters and showed that they have close connection with orthogonal arrays and combinatorial designs. He also showed that
s(C)
is intimately related to other parameters of the given
C
. For instance, it can estimate the size
M
of a code
C
as follows:

q^{n}\Bigg/\sum_{j=0}^{s^{\prime}(C)}{n\choose j}(q-1)^{j}\leq M\leq\sum_{j=0}^{s(C)}{n\choose j}(q-1)^{j},

(1)

where

denotes the length of
C
and

denotes the size of the alphabet. It was also shown in the same paper
[
16
]
that the covering radius of
C
is less than or equal to
s(C^{\prime})
.

Based on these properties, it is always an interesting topic to study the four fundamental parameters of a code. Since the beginning of coding theory, most scholars tended to focus on the minimum distance of a code, but often ignored the other two parameters due to their difficulty. Recently, there has been an increasing interest in these two parameters of codes. Ezerman
et al.

[
23
]
determined the weight spectrum of linear maximum distance separable (MDS) codes with parameters given by the MDS conjecture. Alderson
[
1
]
developed this result to general MDS codes including non-linear MDS codes.
However, it is very hard to determine the exact value of

for a general code

.
For this topic, Shi
et al.

[

showed the maximum value of

is

If the linear code

The research objects in this paper fall into four categories:

•

The

Let

be a positive integer with

The

In this section, our focus is on determining the maximum number of

Proposition 5

Let

M\leq\sum_{j=0}^{|\mathbf{D}_{b}(C)|}{n\choose j}(|\Sigma|^{b}-1)^{j}.

Proof.

Following the approach of the proof in

16

Let

•

•

Theorem 6

For all integers

Proof.

Assume that

Definition 19

at least

6.1

For a polynomial

For a vector

for all integers

6.2
The primitive idempotent approach

An element

of
\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}

\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}

n
over
\mathbb{F}_{q}
is a direct sum of some irreducible cyclic codes. The polynomial

, i.e.,

x^{n}-1=\prod_{i=1}^{s}f_{i}(x),

(9)

where

is irreducible over
\mathbb{F}_{q}
for
1\leq i\leq s
. Set
\hat{f_{i}}(x)=\frac{x^{n}-1}{f_{i}(x)}

\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}
. Every irreducible cyclic code of length
n
over
\mathbb{F}_{q}
is generated by a primitive idempotent of
\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}
. The irreducible cyclic codes can also be described using the trace function.

Let

over
\mathbb{F}_{q}
. Suppose

has degree

be a root of

. Then the set

(10)

represents the
[n,m]_{q}
irreducible cyclic code with non-zeroes
\{\gamma^{-q^{i}}|0\leq i<m\}
. Moreover, if we set

, where

is an integer dividing
Q-1
, and recall that
\alpha
is a primitive element of
\mathbb{F}_{Q}
, letting

, then the set

{\mathcal{C}}(Q,\theta)=\{{\mathbf{c}}(\beta)=({\rm Tr}_{Q/q}(\beta),{\rm Tr}_{Q/q}(\beta\theta),\ldots,{\rm Tr}_{Q/q}(\beta)\theta^{n-1})|\beta\in\mathbb{F}_{Q}\}

also represents an irreducible cyclic code with parameters
[n,m_{0}]_{q}
, where

is the multiplicative order of
q
modulo
n
, and
m_{0}
divides

.

Definition 28
.

The
q
-cyclotomic coset of

\mathbb{F}_{Q}

The set

partitions the ring

of integers into disjoint sets. There is a one-to-one correspondence between the primitive idempotents of

Lemma 29

For any cyclic code

Theorem 30

Let
{\mathcal{C}}

6.3
The

-symbol weight formula approach

In this subsection, we introduce how to calculate the
b
-symbol weight of an irreducible cyclic code. This will significantly contribute to improving the upper bound of
w_{b}({\mathcal{C}})
, where
{\mathcal{C}}
refers to an irreducible cyclic code

in the form of (

Definition 32
.

An additive character of
\mathbb{F}_{q}
is a nonzero function
\chi
from
\mathbb{F}_{q}
to the set of complex numbers such that
\chi(x+y)=\chi(x)\chi(y)
for any

For each

\chi_{b}(c)=e^{2\pi\sqrt{-1}{\rm Tr}_{q/p}(bc)/p},~~{\hbox{for all $c\in\mathbb{F}_{q}$}}

defines an additive character of
\mathbb{F}_{q}.

\chi_{1}
is called the canonical additive character of
\mathbb{F}_{q}
. The Gaussian periods are defined by

\eta_{i}^{(k,Q)}=\sum_{x\in C_{i}^{(k,Q)}}\chi_{1}(x),~~~i\in\{0,1,\ldots,k-1\}.

We adopt the definition of (
11
) instead of (
10
) to describe irreducible cyclic codes, as Ding and Yang
[
21
]
used the definition of (
11
) to provide the Hamming weight calculation formula for the codewords of irreducible cyclic codes, which depends on the values of some Gaussian periods. Zhu et al.
[
54
]
further provided a formula for calculating the

-symbol weight of the codewords of irreducible cyclic codes based on
[
21
]
. Before introducing this calculation formula, we need to provide a definition of the set

Definition 33
.

Let
N_{1}=\gcd\left(\frac{Q-1}{q-1},N\right)
. Define

be the set

According to the definition of
{\mathcal{C}}(Q,\theta)
, it is an irreducible cyclic code with parameters

Theorem 34

[

6.4
Performance analysis of three approaches

The above three approaches have the following characteristics:

•

The period distributions approach: (1) There are existing results on the period distribution of cyclic codes that can be leveraged to reduce computational complexity; (2) Suitable for reducible cyclic codes; (3) The results obtained by the period distributions approach and the primitive idempotent approach are equivalent.

•

The primitive idempotent approach: The proposed upper bound can be applied to reducible cyclic codes.

•

The
b
-symbol weight formula approach: It is more accurate than the period distributions approach and the primitive idempotent approach, but it is difficult to apply to the case of reducible cyclic codes.

Proposition 36
.

The upper bounds provided by the period distributions approach and the primitive idempotent approach are identical.

Proof.

Both approaches rely on determining the number of orbits of the group
\left\langle\tau,\{\sigma_{a}|a\in\mathbb{F}_{q}^{*}\}\right\rangle
on
{\mathcal{C}}^{*}
. Therefore, the upper bounds obtained by the two approaches are equivalent, although they may be expressed differently due to the use of different mathematical symbols.

Considering that reducible cyclic codes can always be decomposed into a series of irreducible cyclic codes, we only need to verify that the results given by Corollary
27
and Theorem
30
are the same. This is equivalent to proving that the equation

\frac{q^{k}-1}{{\rm lcm}({\rm per}(h(x)),q-1)}=\frac{\gcd(n,(q-1)i_{t})(q^{k}-1)}{n(q-1)}

holds. Since
{\rm per}(h(x))=\frac{n}{\gcd(n,i_{t})}
, we have

\frac{q^{k}-1}{{\rm lcm}({\rm per}(h(x)),q-1)}=\frac{q^{k}-1}{{\rm lcm}\left(\frac{n}{\gcd(n,i_{t})},q-1\right)}=\frac{q^{k}-1}{n(q-1)\cdot\frac{1}{\gcd(n,(q-1)i_{t})}}.

This completes the proof.
∎

The reasons for the significant difference on the result forms between Theorem
26
and Theorem

are twofold:

(i)

The parameters selection for the two approaches are different. The period distributions approach needs to determine the period of each
h_{i}(x)
; while the primitive idempotent approach selects the corresponding

. At this point, the correspondence between

and

is
{\rm per}(h(x))=\frac{q^{k_{t_{j}}}-1}{\gcd(q^{k_{t_{j}}}-1,i_{t_{j}})}
.

(ii)

The second reason for the differences is the different selection of auxiliary functions. in Theorem
26
, we can see that the M
\ddot{o}
bius function
\mu(x)
was selected as an auxiliary function in its results; In Theorem
31
, we can find that the Euler’s totient function
\phi(x)
was selected as an auxiliary function in its result (we can see the Euler’s totient function as an auxiliary function in the mathematical derivation of
[
15
]
). The Euler’s totient function and the M
\ddot{o}
bius function have the following relationship:

\phi(n)=\sum_{i|n}\mu(i)\frac{n}{i}.

We note that Chen
et al.

[
12
]
further improved the upper bound given in
[
15
]
by expanding subgroup
\left\langle\tau,\{\sigma_{a}|a\in\mathbb{F}_{q}^{*}\}\right\rangle
to
\left\langle\tau,\{\sigma_{a}|a\in\mathbb{F}_{q}^{*}\},\mu_{q}\right\rangle
, where
\mu_{a}
is a ring automorphism of
\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}
, which is defined as follows:

\displaystyle\mu_{q}:\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}

\displaystyle\longrightarrow

\displaystyle\frac{\mathbb{F}_{q}[x]}{(x^{n}-1)}

\displaystyle\sum_{i=0}^{n-1}a_{i}x^{i}

\displaystyle\longmapsto

\displaystyle\mu_{q}\left(\sum_{i=0}^{n-1}a_{i}x^{i}\right)=\sum_{i=0}^{n-1}a_{i}x^{qi}({\rm mod}~x^{n}-1).

However, the subgroup
\left\langle\tau,\{\sigma_{a}|a\in\mathbb{F}_{q}^{*}\},\mu_{q}\right\rangle
proposed in
[
12
]
is not suitable for studying the
b
-symbol weight spectrum. This is because for a nonzero vector
{\mathbf{c}}
,
\mu_{q}
may alter the
\mathbf{0}
’s run distribution of
{\mathbf{c}}
.

Appendix

We further give some upper bounds on the size of
W_{b}({\mathcal{C}})
of some cyclic codes by using these known (or easily computed) period distributions.

The cyclic codes with prime length
n

If
{\mathcal{C}}
is a cyclic code with prime length
n
, then a nice upper bound of
W_{b}({\mathcal{C}})
is given in the following.

Corollary 37
.

Assume that
n
is prime. Let
{\mathcal{C}}
be a cyclic code with parameters
[n,k]_{q}
and
h(x)
be the parity-check polynomial of
{\mathcal{C}}
. Assume that
per(h(x))>b
. Then we have

|W_{b}({\mathcal{C}})|\leq\left\{\begin{array}[]{ll}\Delta,&\hbox{$n|q-1$;}\\
\min\left\{\Delta,1+\frac{q^{k}-q}{n(q-1)}\right\},&\hbox{$x-1|h(x)$ and $n\not|~q-1$;}\\
\min\left\{\Delta,\frac{q^{k}-1}{n(q-1)}\right\},&\hbox{$x-1\not|~h(x)$ and $n\not|~q-1$.}\end{array}\right.

Proof.

When
n
is prime, the period distribution of
{\mathcal{C}}
is

\left\{\begin{array}[]{ll}B_{1}=q-1,B_{i}=0,2\leq i\leq n-1,B_{n}=q^{k}-q&\hbox{if $x-1|h(x)$;}\\
B_{i}=0,1\leq i\leq n-1,B_{n}=q^{k}-1&\hbox{if $x-1\not|~h(x)$.}\end{array}\right.

If
n|q-1
, we have
|W_{b}({\mathcal{C}})|\leq\min\{\Delta,\frac{q^{k}-1}{q-1}\}=\Delta
since
\Gamma(k,q,b)\leq L(k,q,b)=\frac{q^{k}-1}{q-1}.

According to Inequality (
8
), we obtain the desired result.
∎

The dual of cyclic codes with two zeroes

Recall that
h(x)
denotes the parity-check polynomial of
{\mathcal{C}}
.
If
h(x)
has only two irreducible factors, the period distribution of
{\mathcal{C}}
is easy to compute after a brief discussion. So we omit the proof of the following result.

Corollary 38
.

Assume
\gcd(n,q)=1
. Let
{\mathcal{C}}
be a cyclic code with parameters
[n,k]_{q}
. Let
h(x)=h_{1}(x)h_{2}(x)
where
h_{1}(x)
and
h_{2}(x)
are irreducible over
\mathbb{F}_{q}
,
\deg(h_{i}(x))=s_{i}
and
per(h_{i}(x))=t_{i}
with
1\leq i\leq 2.

If
\min\{t_{1},t_{2}\}>b
, then

|W_{b}({\mathcal{C}})|\leq\left\{\begin{array}[]{ll}\min\left\{\Delta,\frac{q^{k}-1}{lcm(t_{1},q-1)}\right\},&\hbox{if $t_{1}=t_{2}$;}\\
\min\left\{\Delta,\frac{q^{s_{1}}-1}{lcm(t_{1},q-1)}+\frac{q^{s_{2}}-1}{lcm(t_{2},q-1)}+\frac{q^{k}-q^{s_{1}}-q^{s_{2}}+1}{lcm(lcm(t_{1},t_{2}),q-1)}\right\},&\hbox{if
$\gcd(t_{1},t_{2})\in\{t_{1},t_{2}\}$;}\\
\min\left\{\Delta,\frac{q^{s_{1}}-1}{lcm(t_{1},q-1)}+\frac{q^{k}-q^{s_{1}}}{lcm(t_{2},q-1)}\right\},&\hbox{if $t_{1}|t_{2}$.}\end{array}\right.

BCH codes

Let
\delta
be an integer with
2\leq\delta\leq n.
A BCH code
{\mathcal{C}}
over
\mathbb{F}_{q}
of length
n
and designed distance
\delta
is a cyclic code with defining set

T=C_{b}\cup C_{b+1}\cup\cdots\cup C_{b+\delta-2},

where
C_{i}
denotes the
q
-cyclotomic coset modulo
n
containing
i
. The period distribution of BCH codes is given in
[
34
]
in some cases. Combining the results in
[
34
]
, we get the following result directly.

Corollary 39
.

Let
{\mathcal{C}}
be a narrow-sense BCH code with length
n=q^{m}-1
and designed distance
\delta
.
We have the following.

|W_{b}({\mathcal{C}})|\leq\min\left\{\Delta,\sum\limits_{b<t|n}\frac{\sum\limits_{j|t}\mu\left(\frac{t}{j}\right)A_{i}}{lcm(t,q-1)}\right\},

where the value of
A_{i}
is as follows:

(1)

If
2\leq\delta<q+1
, then

A_{i}=\left\{\begin{array}[]{ll}q^{n-(\delta-1)m},&\hbox{$i=n$;}\\
q^{\frac{n}{2}-\lfloor\frac{\delta-1}{2}\rfloor m},&\hbox{$i=\frac{n}{2}$;}\\
A_{\frac{sn}{j}}=q^{\frac{n}{j}-\lfloor\frac{\delta-1}{j}\rfloor m},&\hbox{$i=\frac{n}{j}$ for some $j\in[\delta-1]\backslash\{1,2\}$}\\
&\hbox{where $1\leq s\leq j-1$ and $\gcd(s,j)=1$;}\\
q^{\gcd(n,i)},&\hbox{otherwise.}\end{array}\right.

(2)

If

q+1\leq\delta\leq\left\{\begin{array}[]{ll}q^{\frac{m+1}{2}},&{\rm{if}~~}m\equiv 1({\rm mod~~2});\\
q^{\frac{m}{2}}+2,&{\rm{if}~~}m\equiv 0({\rm mod~~2}),\\
\end{array}\right.

then

A_{i}=\left\{\begin{array}[]{ll}q^{n-((\delta-1)-\lfloor\frac{\delta-1}{q}\rfloor)m},&\hbox{if $i=n$;}\\
A_{\frac{sn}{j}}=q^{\frac{n}{j}}-\left(\left\lfloor\frac{\delta-1}{j}\right\rfloor-\left\lfloor\frac{\delta-1}{qj}\right\rfloor\right)m,&\hbox{$i=\frac{n}{j}$ for some $j\in[\delta-1]$,}\\
&\hbox{where $1\leq s\leq j-1$ and $\gcd(s,j)=1$;}\\
q^{\gcd(n,i)},&\hbox{otherwise.}\end{array}\right.

(3)

If
q^{\frac{m}{2}}+2\leq\delta\leq 2q^{\frac{m}{2}},
then

A_{i}=\left\{\begin{array}[]{ll}q^{n-\left(\delta-\frac{3}{2}-\left\lfloor\frac{\delta-1}{q}\right\rfloor\right)m},&\hbox{$i=n$;}\\
A_{\frac{sn}{j}}=q^{\frac{j}{n}-\left(\left\lfloor\frac{\delta-1}{j}\right\rfloor-\left\lfloor\frac{\delta-1}{qj}\right\rfloor\right)m},&\hbox{$i=n$, $j\in[\delta-1]\backslash\{1\}$, $\gcd(s,j)=1$,}\\
&1\leq s\leq j-1,\left(q^{\frac{r}{2}}+1\right)\not|j;\\
A_{\frac{sn}{j^{\prime}}}=q^{\frac{n}{j^{\prime}}-\frac{m}{2}},&\hbox{$r=\frac{n}{j^{\prime}},j^{\prime}\in[\delta-1],\gcd(s,j^{\prime})=1$,}\\
&{1\leq s\leq j^{\prime}-1,\left(q^{\frac{m}{2}}+1\right)|j^{\prime};}\\
q^{\gcd(n,i)},&\hbox{otherwise.}\end{array}\right.

Reed-Solomon codes

A Reed-Solomon code, abbreviated RS code, is a BCH code of length
n=q-1
. By virtue of the period distribution of the RS code, we obtain the following result.

Corollary 40
.

Let
{\mathcal{C}}
be a Reed-Solomon code with parameters
[q-1,k]_{q}
. Then

|W_{b}({\mathcal{C}})|\leq\min\left\{\Delta,1+\sum_{b<t|q-1}\frac{\sum\limits_{j|t}\mu\left(\frac{t}{j}\right)q^{1+\frac{(k-1)\gcd(q-1,j)}{q-1}}}{q-1}\right\}.

Proof.

The period distribution of Reed-Solomon code is

B_{t}=\sum_{j|t}\mu\left(\frac{t}{j}\right)q^{1+\frac{(k-1)\gcd(q-1,j)}{q-1}},

which is given in
[
25
]
,
and
lcm(t,q-1)=q-1
, then we obtain the desired result.
∎

From Corollary
37
to Corollary
40
, we can see that the period distributions approach has significant advantages over the primitive idempotent approach, thanks to the existing results on the period distribution of cyclic codes.
