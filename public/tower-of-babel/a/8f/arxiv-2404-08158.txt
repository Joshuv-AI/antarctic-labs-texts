Abstract
We continue the study of doubly-efficient proof systems for verifying agnostic PAC learning, for which we obtain the following results. • We construct an interactive protocol for learning the t t largest Fourier characters of a given function f : { 0 , 1 } n → { 0 , 1 } f\colon\{0,1\}^{n}\to\{0,1\} up to an arbitrarily small error, wherein the verifier uses 𝗉𝗈𝗅𝗒 ⁡ ( t ) {\mathsf{poly}}(t) random examples. This improves upon the Interactive Goldreich-Levin protocol of [ GRSY21 ] , whose sample complexity is 𝗉𝗈𝗅𝗒 ⁡ ( t , n ) {\mathsf{poly}}(t,n) . • For agnostically learning the class 𝖠𝖢 0 ​ [ 2 ] \mathsf{AC}^{0}[2] under the uniform distribution, we build on the work of [ CIKK17 ] and design an interactive protocol, where given a function f : { 0 , 1 } n → { 0 , 1 } f\colon\{0,1\}^{n}\to\{0,1\} , the verifier learns the closest hypothesis up to 𝗉𝗈𝗅𝗒𝗅𝗈𝗀 ⁡ ( n ) {\mathsf{polylog}}(n) multiplicative factor, using quasi-polynomially many random examples . In contrast, this class has been notoriously resistant even for constructing realisable learners (without a prover) using random examples. • For agnostically learning k k -juntas under the uniform distribution, we obtain an interactive protocol, where the verifier uses O ⁡ ( 2 k ) O(2^{k}) random examples to a given function f : { 0 , 1 } n → { 0 , 1 } f\colon\{0,1\}^{n}\to\{0,1\} . Crucially, the sample complexity of the verifier is independent of n n . We also show that if we do not insist on doubly-efficient proof systems, then the model becomes trivial. Specifically, we show a protocol for an arbitrary class 𝒞 \mathcal{C} of Boolean functions in the distribution-free setting, where the verifier uses O ⁡ ( 1 ) O(1) labeled examples to learn f f .

Introduction

Can we verify the results of a supervised learner much cheaper than running the learning algorithm from scratch? This presents a fundamental question at a time where training modern machine learning models demands vast amounts of data, meticulously collected and labeled, coupled with substantial computational resources. The infeasibility of repeating this process multiple times, raises the criticality of verifying the results of the learning algorithm.

Recently, Goldwasser, Rothblum, Shafer and Yehudayoff
[
GRSY21
]
formalised the question of verifying the results of supervised machine learning tasks in the context of PAC Learning
[
Val84
]
. They initiated the study of
PAC-verification
, with the aim of developing interactive proof systems that enable a verifier to check the results of an untrusted learner (or a prover). The goal is to achieve this verification while conserving computational resources and reducing data access, either quantitatively or qualitatively. This notion of utilising
interactive proofs
to verify learning algorithms, is rooted in the understanding that interaction with a prover can be remarkably helpful for many computational tasks, evidenced by major results like
\mathsf{IP}=\mathsf{PSPACE}
or
\mathsf{MIP}^{*}=\mathsf{RE}
.

In more detail,
[
GRSY21
]
focus on
agnostic learning
. In the setting of agnostic learning over the
uniform distribution
for a class of Boolean functions
\mathcal{C}
, for an arbitrary
f:\{0,1\}^{n}\rightarrow\{0,1\}
, the learning algorithm has access to a
random example oracle
that provides labeled examples of the form
(x,f(x))
, where each
x
is drawn uniformly at random from
\{0,1\}^{n}
. A learner
(\alpha,\epsilon,\delta)
-agnostically learns a class
\mathcal{C}
over the uniform distribution using random examples, for some
\alpha\geq 1
, if it outputs a hypothesis
h
with error at most
\alpha\cdot\mathsf{opt}_{\mathcal{C}}(f)+\varepsilon
with probability at least
1-\delta
, where
\mathsf{opt}_{\mathcal{C}}(f)=\min_{c\in\mathcal{C}}\{\mathsf{dist}(f,c)\}
is the best possible approximation of
f
by any function in
\mathcal{C}
. Another well-studied variant is one where the learner is required to meet the requirements of
(\alpha,\epsilon,\delta)
-agnostic learning, but is given a stronger form of access to
f
via
membership queries
, and not just random examples. Agnostic learning goes beyond “realisable” PAC learning, which assumes that
f
always comes from
\mathcal{C}
; instead, it represents a more realistic scenario where there is no “ground truth” about the labeling function (see
Section

2.1
for a formal definition).

In the
(\alpha,\epsilon,\delta)
-PAC-verification model over the uniform distribution, a verifier, which accesses
f
using a random example oracle over the uniform distribution, interacts with an untrusted prover (or learner) that has query access to
f
, to output a hypothesis
h
with error at most
\alpha\cdot\mathsf{opt}_{\mathcal{C}}(f)+\varepsilon
, with probability at least
1-\delta
. For the
completeness requirement
of the proof system, the honest prover should be able to convince the verifier to output a “good” hypothesis with high probability (this could also include scenarios where the prover sends a purported hypothesis first and then tries to convince the verifier about its accuracy). For the
soundness requirement
, a malicious prover, even if computationally unbounded, should not be able to convince the verifier to accept a hypothesis that deviates significantly from
\alpha\cdot\mathsf{opt}_{\mathcal{C}}(f)
, with high probability. This represents a PAC-verification task with the goal of achieving a
qualitative
difference between the verifier and the prover, as queries are considered to be a more powerful form of access.

Another equally appealing setting of PAC-verification is one where both verifier and prover have the query access (or random example access) to
f
, and the goal is for the verifier to output a good hypothesis with high probability, making much fewer queries (or samples) than the prover, providing a
quantitative
difference. We refer to
Section

2.2
for a formal definition of the model.

Following the works of
[
GRSY21
]
and its follow-ups
[
MS23
,
CHI+23
]
, we are mainly interested in proof systems that are
doubly efficient
, where the honest prover is also an efficient algorithm. The notion of doubly efficient proof systems is intimately connected to the notion of
delegating
a computational task to an efficient, yet untrusted prover
[
GKR15
]
. While such proof systems have found widespread use theoretically and in practice, their study in the setting of delegating learning tasks is nascent.

In this work, we establish a set of general tools for PAC-verification and illustrate their utility by constructing PAC-verification protocols for certain classes of Boolean functions, whose study is foundational in the field of computational learning theory. Our constructions showcase the power of interacting with a prover, by achieving quantitative and/or qualitative improvements for verifying the results of an agnostic learner, than actually performing the learning task without a prover.

1.1
Our Results

To begin with, we construct a sample-efficient
interactive Goldreich-Levin protocol
, for the problem of learning heavy Fourier coefficients, which improves upon an analogous result by
[
GRSY21
]
. Following this, we construct the first PAC-verifier for classes of functions computable by
constant-depth circuits
like
\mathsf{AC}^{0}[2]
, as well as for functions that are
k
-juntas
. Finally, we illustrate the power of such proof systems with
unbounded honest provers
, with PAC-verifiers for any arbitrary class of Boolean functions, using very few samples, even in the distribution-free setting. We elaborate on these results next.

Learning Heavy Fourier Characters

1.1.2
Learning
\mathsf{AC}^{0}[2]
Circuits

Let
\mathsf{AC}^{0}[2]
be the class of functions computable by constant-depth circuits of polynomial-size with
\mathsf{AND,OR,NOT,XOR}

Suppose the random example oracle over the uniform distribution is such that
\mathsf{opt}(f,\mathsf{AC}^{0}[2])

1/n^{\log(n)}

\mathsf{AC}^{0}[2]
can be
{\mathsf{polylog}}(n)
-PAC-verified using quasi-polynomially many random examples.

3

3

\mathsf{AC}^{0}

Moreover, we can easily extend this to get PAC-verification for

The class

[

In contrast, we show the power of PAC-verification protocols for

Our techniques crucially use the structure of the agnostic learner with membership queries by

\mathsf{opt}(f,\mathsf{AC}^{0}[2])

A tolerant tester for

1.1.4
The Power of PAC-Verification with Unbounded Provers

Finally, we study the power of PAC-verification if we allow the honest prover to have unbounded computational power. For this section, we extend PAC-verification model from
Definition

2.2
to the
distribution-free
agnostic learning setting, where for any unknown, yet fixed distribution
\mathcal{D}
over the examples, the verifier is now given access to the random example oracle with respect to
\mathcal{D}
.
The completeness and soundness requirements are stronger; for every fixed, but unknown underlying distribution
\mathcal{D}
, the hypothesis output by the interaction should have error at most
\mathsf{opt}_{\mathcal{D}}(f,\mathcal{C})+\epsilon
, where the distance is now measured over
\mathcal{D}
.

Let
{\mathsf{P}}/{\mathsf{poly}}
be the class of functions computable by general Boolean circuits of polynomial size, that captures efficient non-uniform computation. We show the following PAC-verification protocol.

Theorem 1.4

(PAC-verification for
{\mathsf{P}}/{\mathsf{poly}}
(see
Corollary

7.11
for a formal statement))
.

For any
\varepsilon>0
,
{\mathsf{P}}/{\mathsf{poly}}
is distribution-free, proper,
(\epsilon,1/10)
-PAC-verifiable, where the verifier uses at most
O(1/\epsilon)
many random labeled examples and runs in
{\mathsf{poly}}(n/\epsilon)
time. Moreover, the honest prover is computationally unbounded.

For contrast, assuming the existence of standard cryptographic primitives (like one-way functions), we know that
{\mathsf{P}}/{\mathsf{poly}}
cannot be learnt in polynomial-time over the uniform distribution using membership queries, even in the realisable setting
[
GGM86
]
. Thus, providing access to an unbounded prover, can help a verifier learn
{\mathsf{P}}/{\mathsf{poly}}
even in the significantly stronger distribution-free, proper, agnostic learning setting.

Theorem

1.4
is proved using a more general result that shows that any arbitrary class of functions
\mathcal{C}
is distribution-free PAC-verifiable using
O(1/\epsilon)
random examples, where the verifier runs in
{\mathsf{poly}}(\log(|\mathcal{C}|)/\epsilon)
. The interactive proof is constructed by viewing agnostic learning as a suitable
Empirical Risk Minimisation
task (ERM) (which does an exhaustive search) and delegating this computational task to the prover using
[
GKR15
]
. More details can be found in
Section

7
.

\gamma^{2}/4

The Fourier weight of a subspace is the sum of squared Fourier coefficients of all vectors in the subspace. This can be estimated using standard techniques from Fourier analysis of Boolean functions
[
O’D14
]
.

GL

\Lambda_{t}

Query-based PAC-verification of
\Lambda_{t}
.

Suppose we could stop this process at depth
O(\log(1/\gamma))
instead of going all the way to
n
, with the hope of getting the query complexity down to
{\mathsf{poly}}(1/\gamma)

\gamma
-heavy vectors. Furthermore,

To resolve this, we consider a partitioning scheme based on

, that also appears in
[
GOS+11
]
. In more detail, we take a set
\{r_{1},\dots,r_{s}\}
of uniformly random vectors from
\mathbb{F}_{2}^{n}
, where

as
\mathsf{span}(r_{1},\dots,r_{s})
of dimension

2^{s}
possible affine shifts of

(the subspace orthogonal to

) form a partition of
\mathbb{F}_{2}^{n}
such that each of these subspaces contains
at most one

\gamma
-heavy vector.

7

For comparison,
[

]

While they work with the decision task of testing, in our learning/Goldreich-Levin setting, we get an arbitrary Boolean function without the nice structure provided by sparsity, that could render any such subspace to contain a large number of non-zero Fourier coefficients. It is unclear how estimating the
L_{2}
-norm of the entire subspace would help the learner identify the heaviest character (up to some error).

Following this, we prove a new method of estimating the heaviest vector from each of these affine subspaces based on the following lemma: for any affine subspace
\Gamma
which is “rare” for
\gamma
-heavy vectors, the

-Fourier norm is an additive approximation to the

-Fourier norm, i.e.,

is roughly equal to
\argmax_{a\in\Gamma}|\hat{f}(a)|
with a small additive error. Using the

-Fourier norm, as opposed to the

-Fourier norm utilized in

]

and
computes the coefficients
for all the
\gamma
-heavy vectors, without identifying the corresponding characters.

8

8

One can view this as a full binary tree, where the nodes in layer

2^{i}

As a solution to this, we just ask the prover (which runs

\gamma
-heavy vectors! The honest prover sends the

-heavy vectors to the verifier, and completeness is ensured since we can easily estimate the Fourier coefficient of a vector using

many random queries (up to an error, say

{\mathsf{poly}}(1/\gamma)

, obtaining a significant

For the sake of exposition, we ignore the effect of the additive errors on various estimates made by the verifier as well as the honest prover that runs

\gamma

and
4.2
for details.

Query-to-sample reductions.

In order to obtain a qualitative improvement as well, we need the verifier in the aforementioned PAC-verification protocol to run using only random examples over the uniform distribution, without having a large blow-up on the sample complexity. Our main challenge is that query access is typically a more powerful resource than just random labeled examples to
f
(formalised by
[
Fel09
]
for agnostic learning over uniform distribution). We prove that for a PAC-verification protocol where the verifier has query access to
f
, the verifier can use
only random examples
and a prover to answer them, when the queries have suitable structure.

To understand this framework, we make the following observations about the queries made by the verifier in the aforementioned PAC-verification protocol for
\Lambda_{t}
. Firstly, we observe that the
marginal
distribution of every query is uniform. In more detail, to estimate the
L_{4}
-norm of an affine subspace using
Lemma

4.4
, the verifier queries on uniformly random
x,y,z\sim\{0,1\}^{n}
, and on
w
which is the sum of these vectors with a uniformly drawn vector from the random subspace
S
. Next, we see that the queries are non-adaptively generated by the verifier, i.e., there exists a query construction algorithm
V_{\mathsf{query}}
that uses its internal randomness to generate all the queries before they are made. Further, the queries are independent of the proof sent by the prover.

Suppose that the verifier makes
Q
queries to
f
. Now, a verifier picks a query index
j\sim[Q]
uniformly at random and “hides” a random example
(w,f(w))
from the uniform distribution as the
j^{\text{th}}
query. The important thing here is that
V_{\mathsf{query}}
can generate the rest of
Q-1
queries,
conditioned
on the
j^{\text{th}}
query being
w
. Indeed, the non-trivial case here is if this query corresponds to one that uses a random vector from the subspace
S
, that is constructed beforehand by
V_{\mathsf{query}}
using
s
random vectors; we prove in
Lemma

6.2
that
V_{\mathsf{query}}
can still generate the rest of the queries conditioned on this query being
w
.

For the reduction, the verifier sends the entire
embedded query set
to the prover and asks for the query answers back. The honest prover answers correctly and the completeness follows from that of the query-based protocol. On the other hand, since the marginal distribution of each query is uniform, which is the same as the underlying distribution, a malicious prover
P
can’t distinguish between the “embedded” query
w
and any other query which is generated by
V_{\mathsf{query}}
. Thus, the best
P
can do is pick a query at random and answer it incorrectly hoping that it is not
w
, while providing correct answers everywhere else (note that
V
has
f(w)
and will catch a prover if it lies on
w
). A malicious prover can get away with cheating on a single query with probability
(1-1/Q)
; repeating this process
O(Q)
number of times ensures that we catch the prover with high probability. Finally, we get a PAC-verification protocol for learning
\Lambda_{t}
where the verifier makes just
O(Q^{2})
samples.

Discussion.

More generally, if the query construction algorithm of the verifier satisfies
embeddability
, i.e., the query set can be generated, conditioned on a random query index being fixed to a given query
w
, as well as the marginal distribution of each query being the same as the underlying distribution, then we get a PAC-verification protocol where the verifier only uses random examples, with sample complexity having a quadratic blow-up. We refer to
Section

3.2
for more details.

While embeddability seems necessary for the hiding process,
Section

1.2.2
extends this framework towards handling more general query marginal distributions. Moreover, we use non-adaptivity to embed the random example in the query set, and we leave the study of extending this framework to handle adaptive queries, which may or may not depend on the interaction with the prover, as an interesting direction for future work.

Overview of the
[
CIKK17
]
agnostic learner.

We start by recalling the
Nisan-Wigderson (NW)
generator. A family of sets
S_{1},\dots,S_{L}
over a universe of size
m
is called an NW-set design, if each
S_{i}
has size
n
and for every
i\neq j
, the overlap between
S_{i}
and
S_{j}
is very small, i.e., is at most
\log(L)
. Given this, for any
f:\{0,1\}^{n}\rightarrow\{0,1\}
, we define the NW-generator
G^{f}:\{0,1\}^{m}\rightarrow\{0,1\}^{L}
, with seed length
m
and stretch
L
, as
G^{f}(z)=f(z\mid_{S_{1}}),\dots,f(z\mid_{S_{L}})
, where
z|_{S_{i}}
is the restriction of the seed
z
to the indices in
S_{i}
.

Next, let
D:\{0,1\}^{L}\rightarrow\{0,1\}
be an efficient algorithm that can distinguish between the outputs of
G^{f}
and uniformly random strings in
\{0,1\}^{L}
, i.e,
\big|\Pr_{z\sim\{0,1\}^{m}}[D(G_{m}(z))=1]-\Pr_{y\sim\{0,1\}^{L}}[D(y)=1]\big|\geq 1/10
.
[
NW94
,
IW01
]
show that for any
f
, given a circuit
D
that distinguishes between the outputs of
G^{f}
and uniformly random strings in
\{0,1\}^{L}
, there exists a uniform
reconstruction algorithm
\mathcal{A}
that makes membership queries to
f
and outputs a circuit that computes
f
on a
(1/2+1/L)
-fraction of the inputs from
\{0,1\}^{n}
. Alternatively,
\mathcal{A}
can be viewed as
weak learner
for
f
, given membership
query access
to it and
D
’s description.

Their algorithm is obtained by a “play-to-lose” argument. Let
f
be the underlying
n
-variate Boolean function, such that
\mathsf{opt}(f,\mathsf{AC}^{0}[2])=\beta^{*}(n)
, for a non-negligible
\beta^{*}
.
[
CIKK17
]
show an efficient algorithm
\mathcal{R}
that takes as input truth tables of length
L
, and rejects every function
g
over
\ell
inputs that has distance at most
1/\ell^{3}
from
\mathsf{AC}^{0}[2]
-circuits of size
2^{\ell^{\gamma}}
(for a fixed
\gamma
), while accepting a random truth table with constant probability. This is nothing but a
(1/\ell^{3})
-tolerant natural property.

The main idea is that with high probability over its seeds
z
and stretch
L
set to
2^{{\mathsf{polylog}}(n)}
,
G^{f}
produces the truth table of a function
g_{z}:\{0,1\}^{\ell}\rightarrow\{0,1\}
, where
\ell=\log(L)={\mathsf{polylog}}(n)
, such that the distance between
g_{z}
and
\mathsf{AC}^{0}[2]
-circuits of size
2^{\ell^{\gamma}}
is at most
4\beta^{*}(n)
. As long as
\beta^{*}(n)
is less than
1/4\ell^{3}
, the tolerant natural property acts as a distinguisher to
G^{f}
; indeed, by definition, it rejects almost all every truth table that could be output by
G^{f}
, whereas it accepts a constant fraction of strings from
\{0,1\}^{L}
. Thus, we can directly use the natural property as a distinguisher in the NW-reconstruction algorithm to get a circuit that computes
f
on a
(1/2+1/L)
-fraction of the input in
\{0,1\}^{n}
. This gives a weak agnostic learner for
\mathsf{AC}^{0}[2]
over the uniform distribution using membership queries.

Query-to-sample reductions for NW-reconstruction algorithms.

Our main technical idea for this section is to show that the verifier can run the NW-reconstruction algorithm
\mathcal{A}
using random examples over the uniform distribution, by interacting with a prover to answer the queries. For this, we extend the query-to-sample reduction to the NW-reconstruction algorithm.

To do this, we need to understand the query pattern of
\mathcal{A}
. Define a random
subcube

\mathcal{E}
as one obtained by setting a fixed set
S
of coordinates in
[n]
with a uniformly random string
\rho\in\{0,1\}^{|S|}
, and considering the set of all Boolean strings in
\{0,1\}^{n}
that are consistent with
\rho
. Further, we define a
subcube membership query
over
\mathcal{E}
as one which queries
f
over all the
2^{n-|S|}
many strings in
\mathcal{E}
.

Our first insight is that
\mathcal{A}
only makes a set of random (possibly non-disjoint) subcube queries, where each subcube is of size at most
2^{\ell}
(apart from a few uniformly random queries for making empirical estimates). The reconstruction algorithm is based on the hybrid argument, which informally implies that, if
D
can distinguish between
f(z|_{S_{1}}),\dots,f(z|_{S_{L}})
and a uniformly random string
(y_{1},\dots,y_{L})
, then for a random
i\in[L]
,
D
also distinguishes between
(f(z|_{S_{1}}),\dots,f(z|_{S_{i-1}}),y_{i},\dots y_{L})
and
(f(z|_{S_{1}}),\dots,f(z|_{S_{i-1}}),f(z|_{S_{i}}),y_{i+1}\dots y_{L})
reasonably well. As such, the subcubes
\mathcal{E}_{1},\dots,\mathcal{E}_{i-1}
are generated by projecting the random seed
z
over the sets
S_{1}\setminus S_{i},\dots,S_{i-1}\setminus S_{i}
. Of additional interest to us, is the fact that these queries are non-adaptively generated.

To hide a random example
w
in the query set, our next idea is that the query construction based on the hybrid argument allows us to embed
w
in the seed
z
. Indeed, we pick a subcube
\mathcal{E}_{j}
at random and embed
w
in the seed
z
at a location that corresponds to
\mathcal{E}_{j}
(i.e.,
z
projected onto
S_{j}\setminus S_{i}
). Following this, we prove the NW-marginal query distribution lemma, in which we show that for any query index
q
that falls in a subcube
\mathcal{E}_{j}
, the probability that the
q^{\text{th}}
-query is a fixed string is equal to
1/2^{n-\log(|\mathcal{E}_{j}|)}
. This is the most technical lemma for this section, and the main challenge here is to account for the effect of all the overlapping sets coming from the set design on the
q^{\text{th}}
marginal distribution. We refer to
Lemma

5.12
for more details.

The query-to-sample reduction follows a similar strategy as described earlier. While completeness holds for the same reasons, for soundness, for any query
q
that lies in a subcube
\mathcal{E}_{j}
, no malicious prover can distinguish between the distribution of
w|_{S_{j}\setminus S_{i}}
, where
w
is the uniformly random example embedded in the query set, and the
q^{\text{th}}
query marginal distribution, since they are identical. The rest of the analysis follows from ideas similar to
Section

1.2.1
.

In order to boost the error of the hypothesis to
{\mathsf{polylog}}(n)\cdot\beta^{*}
, the
[
CIKK17
]
learns the amplified function
\mathsf{Amp}^{f}_{k}:\{0,1\}^{nk+k}\rightarrow\{0,1\}
, defined as
\mathsf{Amp}^{f}_{k}(x_{1},\dots,x_{k},b_{1},\dots,b_{k})=\sum_{j=1}^{k}f(x_{j})b_{j}\pmod{2}
, where
k
is set to
\frac{1}{4\ell^{3}\beta^{*}}
. While dealing with the final CIKK-learner, it is worth highlighting a subtlety which becomes a
critical
issue for the PAC-verification model. In order to get a hypothesis with low error, the learner learns
\mathsf{Amp}^{f}_{k}
, for which it needs to know the value of
\beta^{*}
to set
k=\frac{1}{4\ell^{3}\beta^{*}}
. However, the main challenge for PAC-verification is that the verifier does not know
\beta^{*}

\beta^{*}

finer analysis
of the CIKK-learner to find the right hypothesis. Details on how we extend the ideas highlighted above to the NW-reconstruction algorithm for
G^{\mathsf{Amp}^{f}_{k}}

Related Work

Following
[
GRSY21
]
,
[
MS23
]
extend PAC-verification to statistical query learning algorithms, and
[
CHI+23
]
extend it for classical verification of quantum agnostic learners. A related model is that of covert learning by
[
CK21
]
, where the goal is to ensure that no untrusted intermediary who monitors the interaction, gains any information about the function or the learner.

Of particular interest,
[
MS23
]
show a verifier sample complexity lower bound of
\Omega(\sqrt{d})
, where
d
is the
VC
-dimension of the underlying hypothesis class, in the
distributional
agnostic learning setting, where the learner gets samples from an unknown joint distribution
\mathcal{D}
over
\{0,1\}^{n}\times\{0,1\}
. Our results on PAC-verifying
{\mathsf{P}}/{\mathsf{poly}}
(Theorem
1.4
) indicate that we can beat this verifier sample complexity lower bound in the setting of
functional
agnostic learning with an unbounded prover, i.e., the labels come from an arbitrary Boolean function (over arbitrary example marginal distributions), or in the case of
k
-juntas (Theorem
1.3
), by additionally also considering distributions with restricted marginals over the examples like the uniform distribution.

The study of interactive proofs for testing properties of distributions, initiated by
[
CG18
]
(see also
[
HR22
]
), is also relevant here. In particular,
[
GRSY21
]
note that any PAC-verification task can be formulated as a property of distributions that can be tested using an interactive proof. While a direct application of
[
CG18
]
shows that any property over distributions supported on
\{0,1\}^{n}
can be tested using
O(2^{n/2}/\epsilon^{2})
many samples given an
unbounded prover
,
Theorem

1.4
gives a much stronger sample complexity of
O(1/\epsilon)
for the specific case of PAC-verification in this scenario.

Another related model is that of delegating a property testing task to an untrusted prover (interactive proofs of proximity or IPPs), where the verifier has query access to the input
[
RVW13
]
. In particular,
[
GR22
]
show query-to-sample reductions for IPPs. However, it is unclear whether such techniques for IPPs can be extended to PAC-verification. Moreover, extending our framework to IPPs incurs a quadratic blow-up for the sample complexity, which could render interesting query complexity regimes for IPPs trivial.

[
GK23
]
show that easiness of certain
meta-complexity problems
implies agnostic learnability of
{\mathsf{P}}/{\mathsf{poly}}
in polynomial time using random examples over polynomially-samplable distributions. It remains open whether this can be extended for typical circuit class restrictions.

1.4
Future Directions

Our work establishes PAC-verification protocols for learning some fundamental classes in learning theory like heavy Fourier coefficients, constant-depth circuits, or
k
-juntas, with techniques that could have more general applicability. We state some directions for possible future exploration.

•

We show a general procedure of embedding a random example into specific query construction algorithms and further, prove that this gives a PAC-verification protocol, for query distributions where each marginal is identical to the underlying distribution (
Section

1.2.1
), or for a set of uniformly random subcube queries (
Section

1.2.2
). An interesting direction is to explore the full generality of this framework and obtain a full distributional characterisation of the query-to-sample reduction. Along these lines, it is worth studying whether the property of embeddability can be extended to adaptive query construction algorithms.

•

Another question is whether we can use the algebraic structure of
\mathsf{AC}^{0}[2]
arising from
[
Raz87
,
Smo87
]
to get better PAC-verification protocols that output a hypothesis with just an additive error, i.e., an error of
\mathsf{opt}(f,\mathsf{AC}^{0}[2])+\epsilon
.

•

The role of round complexity in PAC-verification is not well-understood. Is there a hypothesis class that requires more than
2
rounds of interaction? Is there a round-hierarchy for hypothesis classes that have doubly efficient PAC-verification protocols?

We say the learning algorithm is efficient if the running time is

Similarly, we say that

(\alpha,\varepsilon,\delta)
-agnostically learnable with

Agnostic learning goes beyond standard PAC learning (also called

\mathcal{C}
; instead, it represents a more realistic scenario where there is no ‘‘ground truth” about the labeling function.
9
9

9

Indeed, agnostic learning when

Moreover, when

We also define

(\alpha,\epsilon,\delta)
-agnostic learning using membership queries (or just random examples), where for any unknown, yet fixed distribution

Note that we focus on the

2.3
Fourier Analysis of Boolean Functions

We recall a few facts about Boolean functions.
Any function
f:\{0,1\}^{n}\to\mathbb{R}
can be uniquely written as

f(x)=\sum_{\gamma\in\{0,1\}^{n}}\hat{f}(\gamma)\chi_{\gamma}(x),

which is denoted as the Fourier expansion of
f
where
\chi_{\gamma}=(-1)^{\sum_{i\in\gamma}x_{i}}
and is called a
character
. It is easy to see that
\chi_{\gamma}(x+y)=\chi_{\gamma}(x)\chi_{\gamma}(y)
when we view the domain as
\mathbb{F}_{2}^{n}
. The real number
\hat{f}(\gamma)
is called the
Fourier coefficient
of
f
on
\chi_{\gamma}
and the set of all coefficients is called the
Fourier spectrum
of
f
.

The set of all functions
f:\{0,1\}\to\mathbb{R}
forms a vector space over
\mathbb{R}
, and by defining the inner product
{\langle f,g\rangle}=\mathop{\mathbf{E}}_{x\sim\{0,1\}^{n}}[f(x)g(x)]
the set of all characters
\{\chi_{\gamma}:\gamma\in\{0,1\}^{n}\}
forms an orthonormal basis for this linear space, since
{\langle f,\chi_{\gamma}\rangle}=\hat{f}(\gamma)
. The following well-known fact is used in
Section

4
.

Fact 2.3

(Parseval’s identity)
.

For any Boolean function
f:\{0,1\}^{n}\to\mathbb{R}
we have
{\langle f,f\rangle}=\sum_{\gamma\in\{0,1\}^{n}}\hat{f}(\gamma)^{2}
. In particular, if
f
is a function with codomain
\{-1,1\}
, then
{\langle f,f\rangle}=1
.

In
Section

4
we also use
\hat{f}^{>\epsilon}
to denote the set of characters
\{\gamma\in\{0,1\}^{n}:|\hat{f}(\gamma)|>\epsilon\}
.

2.4
Distance Estimators

Agnostic PAC-verification in the realizable setting is much easier than in the agnostic setting. Indeed, it is the arbitrary distance of the input function to the hypothesis class that poses a hurdle in agnostic learning. In the agnostic verification setting, even if a prover provides the closest hypothesis, the task of verifying is non-trivial as the verifier does not know the true distance of the input function from the class. Thus, a natural algorithmic device to provide this utility is the notion of distance estimator which we will define. It must be mentioned that
[
PRR06
]
introduced distance approximation, a notion almost identical to ours. However, for our purposes, we redefine it slightly differently.

Definition 2.4

(
(\epsilon,\delta)
-distance estimator)
.

For parameters
\epsilon,\delta>0

and a class
C
of functions, an
(\epsilon,\delta)
-distance estimator for
C

is an algorithm which is given oracle access to a function
f\colon\{0,1\}^{n}\to\{0,1\}

and outputs
\tilde{d}\in[0,1]
satisfying the guarantee

\Pr\left[\left|\mathsf{dist}(f,C)-\tilde{d}\right|>\epsilon\right]<\delta\kern 5.0pt.

The
query complexity
of the estimator is the maximal number of queries made by the algorithm to
f
.

A natural way of obtaining distance estimators is via tolerant testers. As we will show, noise tolerant testers and distance estimators are similar, and in some sense equivalent objects as the existence of one implies the existence of the other.

Definition 2.5

(
(c_{u},c_{\ell})
-noise tolerant tester)
.

For a class of Boolean functions
C
and parameters
1>c_{u}>c_{\ell}\geq 0
, a
(c_{u},c_{\ell})
-noise tolerant tester for
C

is an algorithm which given oracle access to a function
f\colon\{0,1\}^{n}\to\{0,1\}
.

1.

If
\min_{g\in C}\mathsf{dist}(f,g)\leq c_{\ell}
, then the tester
accepts
with probability at least
\frac{2}{3}
.

2.

If
\min_{g\in C}\mathsf{dist}(f,g)\geq c_{u}
, then the tester
rejects
with probability at least
\frac{2}{3}
.

The
query complexity
of the tester is the maximal number of queries made by the algorithm to
f
.

Similar to
[
PRR06
]
, by a simple binary search argument we show that a noise tolerant tester for a class of functions implies a distance estimator.

Claim 2.6
.

Let
C
be a class of functions, and suppose that for every
\epsilon>0
and every
d\in[0,1]

the class
C
has a
(d+\epsilon,d-\epsilon)
-noise tolerant tester with query complexity
q_{\epsilon}
.
Then
C
has an
(\epsilon,\delta)
-distance estimator
with query complexity
O(q_{\frac{\epsilon}{2}}\cdot\log(\frac{1}{\epsilon})\cdot(\log(\frac{1}{\delta})+\log\log(\frac{1}{\epsilon})))
.

Proof.

Given
\epsilon,\delta>0
and query access to a function
f
, our goal is to find an estimation
\widetilde{d}
of
d^{\star}=\mathsf{dist}(f,C)
such that
\Pr[|d^{\star}-\widetilde{d}|\leq\epsilon]\geq 1-\delta
. We run a binary search on the interval
[0,1]
, each time deleting half of the search space until the length of the remaining interval becomes sufficiently small.

Let
d_{m}
denote the middle of our active interval
[\ell,r]
where at the beginning this interval is
[0,1]
. We run the
(d_{m}+\frac{\epsilon}{2},d_{m}-\frac{\epsilon}{2})
-noise tolerant test for
O(\log\log(1/\epsilon)+\log(1/\delta))
times and take the majority output. If the result is accept we keep
[\ell,d_{m}]
as our active interval, and otherwise we keep
[d_{m},r]
. We stop when the length of the interval becomes
\leq\epsilon
in which case we output the midpoint
\widetilde{d}=d_{m}
as our estimation of
d^{\star}
.
In the case that
d^{\star}
is in our final interval, clearly our answer is
\epsilon
-close to it. In the case that
d^{\star}
is not in our last interval, with high probability it must be
\frac{\epsilon}{2}
-close to the interval, and therefore
\epsilon
-close to it’s midpoint.

To see why consider a noise tolerant test which always outputs the correct answer. Suppose
d^{\star}\in[\ell,r]
. Then, if
d^{\star}\notin[d_{m}-\frac{\epsilon}{2},d_{m}+\frac{\epsilon}{2}]
, we will still have
d^{\star}
in our active interval of the next step. If
d^{\star}\in[d_{m}-\frac{\epsilon}{2},d_{m}+\frac{\epsilon}{2}]
, we may lose
d^{\star}
from our active interval due to lack of guarantee from the test; however it will be
\frac{\epsilon}{2}
-close to the active interval. And it will remain
\frac{\epsilon}{2}
-close to it in the future steps as our tolerant test will always give us the correct half now that
d^{\star}
is not in the interval.

We can easily extend the above argument to the case that the noise tolerant is probabilistic (
Definition

2.5
). Clearly, our binary search only needs
\log(1/\epsilon)
steps. At each step by running our test for
O(\log\log(1/\epsilon)+\log(1/\delta))
steps and taking the majority, we make sure that by Chernoff bound the output is correct with probability at least
1-\delta/\log(1/\epsilon)
. Finally, by union bound over all
\log(1/\epsilon)
steps, all the executions of the noise tolerant test are correct with probability at least
1-\delta
.
∎

3.2
Transformation From Membership Queries to Random Examples

In this section we show under certain conditions one can transform an interactive protocol for learning that uses membership queries to one that only uses random examples.

If each query has the same marginal distribution as the random examples of the verifier, we can reduce the PAC-verification protocol where the verifier uses membership queries, into one where the verifier takes random examples and prover has membership query access. The idea is as follows: the verifier selects one of the queries uniformly at random and fixes its value to a labeled random example. Note that the answer to this query is already known to her. Then she has to sample the rest of queries conditioned on the one fixed query; assuming this conditional sampling can be done computationally efficiently the verifier then sends these queries to the prover and asks him to label them. The verifier can finally check the label of the one query that is known to her to verify that prover did not cheat on the queries. They can repeat this interaction several times to increase the soundness as desired.

. Let

. Then, consider the following process.

1.

Sample a random index

2.

Take a random example

.

3.

Construct a valid query set

. Here, being valid means that

Our query-to-sample reduction assumes that the last step of the above construction is feasible. Since the marginal distribution of all the queries is the same and since

.

In the rest of this proof,
V
denotes the verifier and
P
denotes the prover, and we assume

. For each

, let
f(Q_{i})=\{(x,f(x)):x\in Q_{i}\}
denote the correct labeling of the

to be the number of dishonest query sets provided by the prover.

Completeness:

While interacting with an honest prover we have
t_{\mathsf{bad}}=0
. Note that even though an honest prover provides a valid proof
\pi
and faithful query sets, the verifier may still reject some iterations, but with probability no more than
\delta
individually. Thus the expected number of non-rejecting executions for any
\delta<1/3
is at least
(1-\delta)t>2t/3
. By Chernoff bound, since
t>36\log(2/\delta)
then the number of non-rejecting executions is within
\pm t/6
of its expectation with probability at least
1-\delta
. Thus with the same probability, the number of non-rejecting iterations is at least
(1-\delta)t-t/6>t/2
. Therefore, the verifier does not reject, and outputs a hypothesis that is guaranteed to be
\epsilon
-close to optimal, with probability at least
1-2\delta
.

Soundness:

Let
R_{1}
denote the event that verifier rejects due to rejecting a query set, and let
R_{2}
denote the event that verifier rejects due to rejecting more than half of the iterations. Note that
R_{1}
and

are mutually exclusive, and therefore
\Pr[{\langle P,V\rangle}=\bot]=\Pr[R_{1}]+\Pr[R_{2}]
. Assuming the prover sends an invalid proof
\pi
we show at least one of

or
R_{2}
happens with high probability. Let
q=q(\epsilon,\delta)
. We have two cases.

Case
t_{\mathsf{bad}}\geq q\cdot\ln(\frac{1}{\delta})
:

Then

\Pr[\neg R_{1}]\leq\left(1-\frac{1}{q}\right)^{t_{\mathsf{bad}}}\leq e^{-t_{\mathsf{bad}}/q}\leq e^{-\frac{\ln(1/\delta)q}{q}}\leq\delta.

Hence the verifier rejects with high probability, i.e.
\Pr[{\langle P,V\rangle}=\bot]\geq 1-\delta
.

Case
t_{\mathsf{bad}}<q\cdot\ln(\frac{1}{\delta})
:

We show in this case with overwhelming probability at least half the executions will reject, thus
P_{R}
rejects.

Let
t_{\mathsf{good}}=t-t_{\mathsf{bad}}
, and notice that

. We show among the

faithful query sets more than

of them reject with overwhelming probability. Note that with probability no more than
\delta
a faithful query set

fails to catch a wrong proof, rendering it ineffective. Define the random variable

to be the number of faithful query sets for which

rejects.

Each faithful query set rejects with probability at least

. Let
\alpha=1-\frac{100}{199(1-\delta)}
,
\beta=1-\frac{3\cdot 100}{2\cdot 199}
, and

. Notice that

\displaystyle\Pr[\neg R_{2}]

\displaystyle\leq\Pr[X\leq t/2]

\displaystyle\leq\Pr[X\leq(1-\alpha)\mu]

\displaystyle\leq\Pr[X\leq(1-\beta)\mu]

\displaystyle\stackrel{{\scriptstyle(*)}}{{\leq}}\exp\left(-\frac{\beta^{2}}{2}\mu\right)

\displaystyle\stackrel{{\scriptstyle(**)}}{{\leq}}\exp\left(-\frac{\beta^{2}}{2}(1-\delta)199q\ln(1/\delta)\right)

\displaystyle\stackrel{{\scriptstyle(***)}}{{\leq}}\exp\left(-\frac{\beta^{2}}{3}199\ln(1/\delta)\right)

\displaystyle=\delta^{199\beta^{2}/3}\leq\delta.

The inequality

. Finally
(*\!*\!*)
holds because

\Pr[{\langle V,P\rangle}=\bot]\geq\Pr[R_{2}]\geq 1-\delta
.

∎

4
Sample-Efficient Interactive Goldreich-Levin Protocol

We view any Boolean function

instead. Recall from Section

. The terms “large” or “heavy” will obtain a more precise meaning in our detailed description.

In

we provide an algorithm that outputs the value of the top
t
Fourier coefficients of a given function. We remark that we find this result of independent interest. Then using the idea of this algorithm, in
Section

4.2
we design an interactive protocol for learning the top
t
characters associated with the top

Fourier coefficients. The output of this protocol is a “top” set in the sense of the following definition.

Definition 4.1

(

-Top Set)
.

A set

is called

-top
with respect to a Boolean function

if for any
\alpha\in\mathbb{F}_{2}^{n}\setminus\Gamma
and any

we have

.

Finally, we apply our general query-to-sample reduction to get the following result:

Theorem 4.1

(Formal version of
Theorem

)
.

There exists an interactive protocol with verifier

and prover

where, given

and a number

, and verifier has random example access to a function

) to

and outputs

, which is either a size-

“top” subset of

or

{\left[{\small\begin{array}[]{r l}\textsf{input access type:}&\kern 4.62497pt{\textsf{random examples}}\\
\textsf{sample/query complexity:}&\kern 4.62497pt{{\mathsf{poly}}(t,1/\epsilon,\log(1/\delta))}\\

4.1
Algorithm for Computing the Top Fourier Coefficients

Fix a Boolean function
f:\mathbb{F}_{2}^{n}\to\{-1,1\}
. We follow a similar strategy as the Kushilevitz-Mansour
[
KM93
]
algorithm (based on Goldreich-Levin
[
GL89
]
) for learning heavy Fourier coefficients of a Boolean function
f
, given membership query access to it. However, unlike the KM algorithm, where the bucketing algorithm iteratively splits with respect to a fixed enumeration over the input variables to
f
, we instead split over
random linear functions
.
11
11

11

This splitting idea is also used by
[
GOS+11
]
, but for the case of testing sparse Boolean functions.
This helps us get a much stronger query complexity (independent of
n
.)

Algorithm Overview:

The goal is to find the
t
largest Fourier coefficients of
f
, for a given
t\in\mathbb{N}
. Our key idea for this algorithm is that by partitioning
\mathbb{F}_{2}^{n}
into a few (but at least
t
) randomly constructed, low dimensional affine subspaces, we are likely to
separate
all the heavy vectors (which are not too many by Parseval’s theorem) into different subspaces. In other words, with high probability, each subspace in such a random partitioning contains at most one heavy vector. Therefore, a natural approach to accomplish our goal, would be to estimate the largest associated coefficient in from each subspace in the partition, and output the
t
top ones. Moreover, the extra structure offered by affine nature of partition, enables us to develop tools from Fourier analysis for estimating the largest corresponding coefficient in it. It is worth stressing that while this algorithm only returns the Fourier coefficients, at the end of this, the vectors corresponding to these coefficients are still unknown.

Detailed Description:

Let
\Lambda_{t}=\{\gamma_{1},\dots,\gamma_{t}\}
be the set of vectors in
\mathbb{F}_{2}^{n}
corresponding to the
t
largest Fourier coefficients of
f
. We want to estimate the value of
|\hat{f}(\gamma_{i})|
. To start with, we construct our random partition of
\mathbb{F}_{2}^{n}
as follows. Pick
s
random vectors
r_{1},\dots,r_{s}
from
\mathbb{F}_{2}^{n}
, for
s
to be defined later. These random vectors, assuming they are linearly independent, partition
\mathbb{F}_{2}^{n}
into
2^{s}
affine subspaces (or
cosets
), each of which is described by a vector in
\mathbb{F}_{2}^{s}
. More precisely, we partition
\mathbb{F}_{2}^{n}
into the following sets, each characterized by a vector
a\in\mathbb{F}_{2}^{s}

\displaystyle V_{a}=\{\gamma\in\mathbb{F}_{2}^{n}\ :\ \langle\gamma,r_{i}\rangle=a_{i}\ \text{for each }i\in[s]\}.

(2)

Amongst all these subsets of
\mathbb{F}_{2}^{n}
, an important observation here is that the subspace characterized by the all zeroes vector,
V_{0}
, is the subspace orthogonal to the span of the vectors
r_{1},\dots,r_{s}
, while the rest are affine subspaces defined as its cosets. Indeed, for every
a\in\mathbb{F}_{2}^{s}
, we see that each
V_{a}=V_{0}+h_{a}
where
h_{a}
is any vector in
V_{a}
. Following this, we use
V_{0}+h
to refer to an arbitrary coset of
V_{0}
.

Now suppose we had an algorithm, given a coset
V_{0}+h
, could output
\max_{\gamma\in V_{0}+h}|\hat{f}(\gamma)|
. Then, we attain our goal of computing the top coefficients easily: for suitably picked
s
, find
r_{1},\dots,r_{s}
such that each
V_{a}
contains at most one of the vectors
\Lambda_{t}=\{\gamma_{1},\dots,\gamma_{t}\}
(i.e. vectors of
\Lambda_{t}
are separated across the different cosets of
V_{0}
), and output the
t
largest values from the coefficients estimated by this algorithm, over each coset of
V_{0}
. This motivates us to examine the probability that such a random partition separates
\Lambda_{t}
. Before that, it would be convenient for us to introduce the following notation.

Definition 4.2

(
X
-Rare Set)
.

Let
X
and
Y
be any subsets of
\mathbb{F}_{2}^{n}
. Then
Y
is called
X
-rare
if
|X\cap Y|\leq 1
.

Moreover, for any Boolean function
f
, (abusing notation) we say that
Y
is an
\epsilon
-rare set as a shorthand for a set that is
(\hat{f}^{>\epsilon})
-rare, i.e.,
Y
has at most one vector whose corresponding Fourier coefficient has absolute value at least
\epsilon
.

Claim 4.3
.

For any set
X\subseteq\mathbb{F}_{2}^{n}
and
any
0<\delta<1
, if we draw
s\geq 2\log_{2}(|X|)+\log_{2}(1/\delta)
random vectors
r_{1},\dots,r_{s}
then all cosets of
V_{0}
will be
X
-rare with probability at least
1-\delta
.

Proof.

For
any

\alpha,\beta\in\mathbb{F}_{2}^{n}
such that
\alpha\neq\beta
the probability that they end up in the same coset of
V_{0}
is at most
2^{-s}
. Thus, using the union bound, for any
X\subseteq\mathbb{F}_{2}^{n}
the probability that a coset of
V_{0}
contains two vectors from
X
is at most
\binom{|X|}{2}\cdot 2^{-s}
, and consequently at most
|X|^{2}\cdot 2^{-s}
. Hence choosing
s\geq 2\log_{2}(|X|)+\log_{2}(1/\delta)
bounds this probability by
\delta
.
∎

Claim

4.3
shows that we need not many random vectors to separate any set (and in particular
\Lambda_{t}
) with high probability. Therefore, it only remains to estimate the maximum corresponding coefficient in each coset of
V_{0}
to finish our algorithm. The following lemma paves the path to achieving this by offering a way to estimate the sum of fourth power of the Fourier coefficients corresponding to the vectors in an affine subspace.

Lemma 4.4
.

Let
V+h
be an affine subspace of
\mathbb{F}_{2}^{n}
. For any
f:\mathbb{F}_{2}^{n}\to\{-1,1\}
the following holds

\sum_{s\in V+h}\hat{f}(s)^{4}=\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\sim V^{\perp}\end{subarray}}[\chi_{h}(w)\cdot f(x)\cdot f(y)\cdot f(z)\cdot f(x+y+z+w)].\\

Proof.

Let
A
denote the right-hand side of the equation. We start by substituting each term for its Fourier expansion

\displaystyle A=\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\in V^{\perp}\end{subarray}}[\chi_{h}(w)\cdot f(x)\cdot f(y)\cdot f(z)\cdot f(x+y+z+w)]

\displaystyle=\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\sim V^{\perp}\\
r:=x+y+z+w\end{subarray}}\left[\chi_{h}(w)\left(\sum_{s\in\mathbb{F}_{2}^{n}}\hat{f}(s)\chi_{s}(x)\right)\left(\sum_{t\in\mathbb{F}_{2}^{n}}\hat{f}(t)\chi_{t}(y)\right)\left(\sum_{u\in\mathbb{F}_{2}^{n}}\hat{f}(u)\chi_{u}(z)\right)\left(\sum_{v\in\mathbb{F}_{2}^{n}}\hat{f}(v)\chi_{v}(r)\right)\right]

\displaystyle=\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\sim V^{\perp}\end{subarray}}\left[\chi_{h}(w)\sum_{s,t,u,v\in\mathbb{F}_{2}^{n}}\hat{f}(s)\hat{f}(t)\hat{f}(u)\hat{f}(v)\chi_{s}(x)\chi_{t}(y)\chi_{u}(z)\chi_{v}(x+y+z+w)\right].

By linearity of expectation

\displaystyle A

\displaystyle=\sum_{s,t,u,v\in\mathbb{F}_{2}^{n}}\hat{f}(s)\hat{f}(t)\hat{f}(u)\hat{f}(v)\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\sim V^{\perp}\end{subarray}}\left[\chi_{h}(w)\chi_{s}(x)\chi_{t}(y)\chi_{u}(z)\chi_{v}(x+y+z+w)\right]

\displaystyle=\sum_{s,t,u,v\in\mathbb{F}_{2}^{n}}\hat{f}(s)\hat{f}(t)\hat{f}(u)\hat{f}(v)\mathop{\mathbf{E}}_{\begin{subarray}{c}x,y,z\sim\mathbb{F}_{2}^{n}\\
w\sim V^{\perp}\end{subarray}}\left[\chi_{h}(w)\chi_{s}(x)\chi_{t}(y)\chi_{u}(z)\chi_{v}(x)\chi_{v}(y)\chi_{v}(z)\chi_{v}(w)\right].

Since the random variables
x,y,z,w
are all independent

\displaystyle A

\displaystyle=\sum_{s,t,u,v\in\mathbb{F}_{2}^{n}}\hat{f}(s)\hat{f}(t)\hat{f}(u)\hat{f}(v)\mathop{\mathop{\mathbf{E}}}_{w\sim V^{\perp}}[\chi_{h}(w)\chi_{v}(w)]\mathop{\mathop{\mathbf{E}}}_{x\sim\mathbb{F}_{2}^{n}}[\chi_{s}(x)\chi_{v}(x)]\mathop{\mathop{\mathbf{E}}}_{y\sim\mathbb{F}_{2}^{n}}[\chi_{t}(y)\chi_{v}(y)]\mathop{\mathop{\mathbf{E}}}_{z\sim\mathbb{F}_{2}^{n}}[\chi_{u}(z)\chi_{v}(z)].

The expectation
\mathop{\mathbf{E}}_{x\sim\mathbb{F}_{2}^{n}}[\chi_{s}(x)\chi_{v}(x)]
is
1
only when
s=v
and is
0
otherwise. This is also true for the expectations over
y
and
z
. Therefore the terms in the above summation in which
s=t=u=v
does not hold cancel to
0
. So we simplify the summation to the following

\displaystyle A

\displaystyle=\sum_{s\in\mathbb{F}_{2}^{n}}\hat{f}(s)^{4}\mathop{\mathbf{E}}_{w\sim V^{\perp}}[\chi_{h}(w)\chi_{s}(w)]=\sum_{s\in\mathbb{F}_{2}^{n}}\hat{f}(s)^{4}\mathop{\mathbf{E}}_{w\sim V^{\perp}}[\chi_{h+s}(w)]=\sum_{s\in V+h}\hat{f}(s)^{4}.

The last equality uses the fact that
\mathop{\mathbf{E}}_{w\sim V^{\perp}}[\chi_{h+s}(w)]=\mathds{1}(s\in V+h)
. To see why, consider the following two cases:

(i)

s\in V+h
: In this case
{\langle h+s,w\rangle}=0
for all
w
in
V^{\perp}
, yielding
\mathop{\mathbf{E}}_{w\sim V^{\perp}}[\chi_{h+s}(w)]=\mathop{\mathbf{E}}_{w\sim V^{\perp}}[(-1)^{{\langle h+s,w\rangle}=0}]=1
.

(ii)

s\notin V+h
: Let
\beta=\{b_{1},\dots,b_{k}\}
be a basis for
V^{\perp}
. From
s+h\notin V
it follows that the set
M_{s+h}=\{b\in\beta:{\langle b,h+s\rangle}=1\}
is non-empty. Consequently

\displaystyle\Pr_{w\sim V^{\perp}}[{\langle w,s+h\rangle}=1]=\Pr_{w\sim\mathsf{span}(M_{s+h})}[{\langle w,s+h\rangle}=1]=\frac{1}{2}.

From this we conclude
\mathop{\mathbf{E}}_{w\sim V^{\perp}}[\chi_{h+s}(w)]=0.\qed

Next, we show if the set
V_{0}+h
contains at most one heavy vector, then the fourth root of sum of fourth power is close to the maximum corresponding coefficient in
V_{0}+h
. Recall that for two real numbers
r_{1},r_{2}\in\mathbb{R}
we say they are
\epsilon
-close if
|r_{1}-r_{2}|\leq\epsilon
.

Claim 4.5
.

Let
\Gamma\subseteq\mathbb{F}_{2}^{n}
be
\epsilon
-rare for some
0<\epsilon<1
. Then
\sqrt[4]{\sum_{\gamma\in\Gamma}\hat{f}(\gamma)^{4}}
is
\sqrt{\epsilon}
-close to
|\hat{f}(\gamma^{\star})|
where
\gamma^{\star}=\argmax_{\gamma\in\Gamma}|\hat{f}(\gamma)|
.

Proof.

We have
\hat{f}(\gamma^{\star})^{4}\leq\sum_{\gamma\in\Gamma}\hat{f}(\gamma)^{4}
as a trivial lower bound for the sum. On the other hand

\displaystyle\sum_{\gamma\in\Gamma}\hat{f}(\gamma)^{4}=\hat{f}(\gamma^{\star})^{4}+\sum_{\begin{subarray}{c}\gamma\in\Gamma\\
\gamma\neq\gamma^{\star}\end{subarray}}\hat{f}(\gamma)^{4}\stackrel{{\scriptstyle(*)}}{{\leq}}\hat{f}(\gamma^{\star})^{4}+\epsilon^{2}\sum_{\begin{subarray}{c}\gamma\in\Gamma\\
\gamma\neq\gamma^{\star}\end{subarray}}\hat{f}(\gamma)^{2}\stackrel{{\scriptstyle(**)}}{{\leq}}\hat{f}(\gamma^{\star})^{4}+\epsilon^{2},

Here, in the inequality given by
(*)
, we use the fact that when
\gamma\neq\gamma^{\star}
we have
\hat{f}(\gamma)\leq\epsilon
, and in
(**)
, we use Parseval’s identity (
Fact

2.3
). Putting the lower and the upper bounds together, combined with the fact that the function
\sqrt[4]{\cdot}
is monotonically increasing and sub-additive, we get

\displaystyle|\hat{f}(\gamma^{\star})|\leq\sqrt[4]{\sum\nolimits_{\gamma\in\Gamma}\hat{f}(\gamma)^{4}}\leq\sqrt[4]{\hat{f}(\gamma^{\star})^{4}+\epsilon^{2}}\leq\sqrt[4]{\hat{f}(\gamma^{\star})^{4}}+\sqrt[4]{\epsilon^{2}}=|\hat{f}(\gamma^{\star})|+\sqrt{\epsilon}.

In other words,
|\hat{f}(\gamma^{\star})|
is
\sqrt{\epsilon}
-close to
\sqrt[4]{\sum_{\gamma\in\Gamma}\hat{f}(\gamma)^{4}}
.
∎

Since we do not have the exact value of
\sum_{V_{0}+h}\hat{f}(\gamma)^{4}
, we next provide a way to estimate this value and thus, estimate the maximum coefficient in
V_{0}+h
.

Claim 4.6
.

For
a\in\{0,1\}^{s}
, let
V_{a}=V_{0}+h
be an
\epsilon
-rare coset of
\mathbb{F}_{2}^{n}
. There exists a randomized algorithm that, given
\epsilon,\delta>0
and query access to a function

, makes
O(\log(1/\delta)/\epsilon^{4})
queries to

and outputs an estimate of
|\hat{f}(\gamma^{\star})|
up to error
\pm 2\sqrt{\epsilon}
with probability at least
1-\delta
, where
\gamma^{\star}=\argmax_{\gamma\in V_{0}+h}|\hat{f}(\gamma)|
.

Proof.

We describe the randomized process for estimating
|\hat{f}(\gamma^{\star})|
. Denote by
\omega
the sum
\sum_{\gamma\in V_{0}+h}\hat{f}(\gamma)^{4}
. Notice that the vector
h
is found by finding a solution to the following in
{\mathsf{poly}}(n)

\begin{bmatrix}\text{--- }r_{1}^{T}\text{ ---}\\
\vdots\\
\text{--- }r_{s}^{T}\text{ ---}\end{bmatrix}\cdot h=a.

We start by estimating
\omega
using Lemma
4.4
. To evaluate the expression
\chi_{h}(w)\cdot f(x)\cdot f(y)\cdot f(z)\cdot f(x+y+z+w)
, we construct the following “small” query set. Pick
x,y,z
uniformly at random, and sample

by picking a uniformly random linear combination of

. Then we query

Repeating this procedure for
O(q_{\mathsf{CB}}(\epsilon^{2},\delta))=O(\log(1/\delta)/\epsilon^{4})

\sqrt[4]{\widetilde{\omega}}
is

, and as a result of

(2\sqrt{\epsilon})
-close to
|\hat{f}(\gamma^{\star})|
.
∎

Observe that now not only do we want cosets of

Theorem 4.2
.

and number

, there exists a randomized algorithm that, given membership query access to a Boolean function

Our statement of the agnostic learner is slightly different from that of
[
CIKK17
]
, as they assume that the learner gets the correct value of
\beta^{*}
as input, whereas we extend their analysis to remove this assumption by giving any
\beta\geq\beta^{*}
as input. In fact, as we shall in the agnostic IP, doing this ensures that we can search for the right value of
\beta^{*}
up to constant factors.

The algorithm is obtained by a “play-to-lose” argument. The main idea is that with high probability on the seeds,
G^{f}:\{0,1\}^{{\mathsf{poly}}(n)}\rightarrow\{0,1\}^{L}
produces a truth table of a function over inputs of length
\log L
, which is
(1-4\beta^{*}(n))
-close to some function in
\mathsf{AC}^{0}[2]
. As long as
\beta^{*}(n)
is less than
\tau(\log L)
/4, the tolerant natural property acts as a distinguisher to
G^{f}
; indeed, by definition, it rejects almost all of the truth tables output by
G^{f}
, whereas it accepts a dense fraction of the uniformly random strings from
\{0,1\}^{L}
. Thus, we can directly use the natural property as a distinguisher in the NW-reconstruction algorithm from Lemma
5.3
to get a circuit that computes
f
on a
(1/2+1/L)
-fraction of the
n
-length inputs.

To get a stronger learner, the NW generator is instantiated with the concatenated encoding of
f
by the Direct Product and Hadamard codes, i.e.,
\mathsf{Had}\circ\mathsf{DP}(f)
. The learner now runs the local list-decoding algorithms for Hadamard and Direct Product codes
[
IJKW10
]
in sequence using the circuit output by the reconstruction algorithm (that is a weak learner), to get stronger guarantees on the error of the hypothesis.

In more detail, for any given
f\in\mathcal{F}_{n}
and
k\in\mathbb{N}
, define the amplified function
\mathsf{Amp}^{f}_{k}:\{0,1\}^{nk+k}\rightarrow\{0,1\}
as the Hadamard code encoding of the
k

f
. In other words, for inputs
x_{1},\dots,x_{k}\in\{0,1\}^{n}
and
y_{1},\dots,y_{k}\in\{0,1\}^{k}
,

\mathsf{Amp}^{f}_{k}(x_{1},\dots,x_{k},y_{1},\dots,y_{k})=\sum_{i=1}^{k}f(x_{i})\cdot y_{i}\pmod{2}

Let
G^{\mathsf{Amp}^{f}_{k}}
be the NW-generator instantiated using
\mathsf{Amp}^{f}_{k}
having seed length
m={\mathsf{poly}}(n,k)
and stretch
L(n)
.

We next state the following result that establishes the complexity of any output of an NW-generator, when treated as a truth table of a function over
\ell=\log L
inputs.

Lemma 5.9

(Tolerant natural properties imply agnostic learners)

(1/2-1/{\mathsf{poly}}(n))

-query came from a subcube induced by a restriction obtained from
\mathcal{A}_{\mathsf{query}}
’s internal randomness, or came from a subcube induced by a restriction obtained by embedding

. Thus, the prover has no advantage in picking a particular query with respect to which it cheats.
16
16

16

By cheating, we mean that the malicious prover answers correctly only on the query it believes to be as the embedded random example and lies on any other query which the verifier does not check.
In other words, the best the malicious prover can do is pick a subcube
\mathcal{E}_{u,v}
at random with probability
|\mathcal{E}_{u,v}|/|\mathcal{Q}_{rj}|
.

Furthermore, any point in
\mathcal{E}_{u,v}
has equal likelihood of being the embedded random example and thus, the malicious prover has no advantage over randomly guessing an element of
\mathcal{E}_{u,v}
. Put together, the malicious prover gains no advantage over picking a query uniformly at random from
[|\mathcal{Q}_{rj}|]
and cheating with respect to it.

For any
r\leq M
, define
\mathcal{W}_{r}
as the number of query sets
\mathcal{Q}_{r,j}
over which the prover responds dishonestly on at least one query in the set, i.e., let

\mathcal{W}_{r}=\{j\in[t]\mid\exists w\in\mathcal{Q}_{rj}\text{ such that }\tilde{f}(w)\neq f(w)\}

We finish our analysis by considering the following 2 cases based on the value of
\mathcal{W}_{r}
.

•

Case 1:
There exists
r
such that
|\mathcal{W}_{r}|>\ln(M/\delta)q_{\max}
. Then, for the
r^{\text{th}}
round, we have

\begin{split}\Pr\left[\forall\mathcal{Q}_{r,j}\in\mathcal{W}_{r},\text{verifier accepts }\tilde{f}(\mathcal{Q}_{r,j})\right]&=\Pi_{j\in\mathcal{W}_{r}}\left(1-\frac{1}{|\mathcal{Q}_{rj}|}\right)\\
&\leq\left(1-\frac{1}{q_{\max}}\right)^{|\mathcal{W}_{r}|}\leq e^{-|\mathcal{W}_{r}|/q_{\max}}\leq\delta/M\\
\end{split}

The first inequality follows from Corollary
5.7
as
|\mathcal{Q}_{rj}|\leq q_{\max}
, for all
r\leq M
and
j\in[t]
. Using a union bound over the
M

1-\delta
, any prover gets caught by the verifier if it lies on at least
\ln(M/\delta)q_{\max}
of the query sets in some round.

•

Case 2:
For every
r\leq M
,
|\mathcal{W}_{r}|\leq\ln(M/\delta)q_{\max}
. Again, let
\mathcal{T}
be the value such that
\beta^{*}
lies in the interval
\left(1/2^{\mathcal{T}+1},1/2^{\mathcal{T}}\right]
. In particular,
|\mathcal{W}_{\mathcal{T}}|\leq\ln(M/\delta)q_{\max}
and the fraction of query sets over which the prover cheats is at most
|\mathcal{W}_{\mathcal{T}}|/t\leq\delta/40
.

For each query set
\mathcal{Q}_{\mathcal{T}j}
such that
j\in[t]\setminus\mathcal{W}_{\mathcal{T}}

that errs on at most
\ell^{4}\beta_{\mathcal{T}}
fraction of the inputs, with probability at least
1-\delta/20
over its internal randomness. Let
\mathcal{Y}
be the number of hypotheses in

.

In such a case, the probability that a uniformly randomly chosen hypothesis

from the set

\begin{split}\Pr_{\stackrel{{\scriptstyle j^{*}\sim[t]}}{{V}}}[h_{\mathcal{T}j^{*}}\text{ is bad}]\leq&\Pr_{V}[h_{\mathcal{T}j^{*}}\text{ is bad}\mid j^{*}\in\mathcal{W}_{\mathcal{T}}]\cdot\Pr_{j^{*}\sim[t]}[j^{*}\in\mathcal{W}_{\mathcal{T}}]+\Pr_{V}[h_{\mathcal{T}j^{*}}\text{ is bad}\mid j^{*}\notin\mathcal{W}_{\mathcal{T}}]\\

&+\Pr_{V}[h_{\mathcal{T}j^{*}}\text{ is bad}\mid j^{*}\notin\mathcal{W}_{\mathcal{T}}\land\mathcal{Y}\leq(1-\delta/5)(t-|\mathcal{W}_{r}|)]\cdot\Pr_{V}[\mathcal{Y}\leq(1-\delta/5)(t-|\mathcal{W}_{r}|)]\\
\leq&\delta/40+\delta/5+\delta/4\\

The third inequality comes from the fact that if

Combined with the fact that

Complexity of the interactive proof.

6.2
PAC-Verification of Juntas with Random Examples

Our IP construction for agnostically verifying class of juntas uses the tolerant test for this class introduced in

DMN19
]

In this section we define two types of query patterns for which it is possible to construct membership query sets, and we further argue that all the queries of the junta’s tolerant test are of these form.

Definition 6.1

(Linear Query Pattern)
.

Let
A\sim\mathbb{F}_{2}^{n\times k}
be a uniformly random matrix, and let
B\in\mathbb{F}_{2}^{n\times t}
. Then, we say query set
Q=\{q_{1},\dots,q_{m}\}
is
linear
if for each
i\in[m]
there exists
\alpha_{i}\neq 0\in\mathbb{F}_{2}^{k}
and
\beta_{i}\in\mathbb{F}_{2}^{t}
such that
q_{i}=A\alpha_{i}+B\beta_{i}
.

It is easy to see that individual queries in a linear query pattern are uniformly distributed. Next, we want to show that we can hide a known sample inside a linear query pattern while preserving the linear dependence between the queries. Note that union of such query patterns also maintains this hiding property.

Lemma 6.2
.

For any linear query pattern, it is possible to construct a query set around a random query.

Proof.

Let
Q=\{q_{1},\dots,q_{m}\}
be a linear query pattern such that
q_{i}=A\alpha_{i}+B\beta_{i}

for all
i
where
\alpha_{i}\in\mathbb{F}_{2}^{k}
,
\beta_{i}\in\mathbb{F}_{2}^{t}
are the corresponding values as in
Definition

6.1
.
We follow our general template (described in
Theorem

3.2
) for constructing such a query set. Pick a uniformly random
j\sim[m]
and a uniformly random vector
r\sim\mathbb{F}_{2}^{n}
which corresponds to the
j
-th query; that is
q_{j}=r
.

Let
L\subseteq[k]
be the coordinates of
\alpha_{j}
that are non-zero.
L
must be non-empty since
\alpha_{j}\neq 0
. Choose an arbitrary element
\ell\in L
. To construct
A
, sample all of its columns uniformly at random except the
\ell
-th column. Set the
\ell
-th column of
A
as the following

a_{\ell}=r+B\beta_{j}+\sum_{i\in L\setminus\{\ell\}}a_{i}.

It is easy to check that
q_{j}=r=A\alpha_{j}+B\beta_{j}
. Notice that
a_{\ell}
is a uniformly random vector. Hence
A
is a uniformly random matrix and the query set
Q
is valid.
∎

We define one more query pattern used for dictator testing (Chapter 7 of
[
O’D14
]

Definition 6.3

(NAE Query Pattern)
.

The query set consisting of three vectors

is called NAE if for all
i\in[n]
the bits
(x_{i},y_{i},z_{i})
are drawn uniformly at random from

Lemma 6.4
.

It is possible to construct a membership query set for a NAE query pattern.

Proof.

First, notice that each of the three query points is uniformly distributed. To construct a membership query set, pick one of the
x,y
or
z
at random (w.l.o.g. assume it is
z
) and assign a uniformly random string to it; in our constructions this will be the point we will hide in the query set. Then assign a uniformly random string to

Then for each
i\in[n]
assign

or
x_{i}=1-z_{i}
each with probability

. This set of values for

In this section we obtain a general framework for learning hypothesis classes with few random examples, given the honest prover is unbounded. First we show any hypothesis class

As applications of this general framework, we consider hypothesis classes widely explored in learning theory, like

Regarding the notation for this section, the hypothesis (or the target) class
\mathcal{H}

Let
f:\{0,1\}^{n}\to\{0,1\}

\mathsf{opt}_{S}(\mathcal{H})=\min_{h\in\mathcal{H}}\mathsf{err}_{S}(h)
and
\mathsf{dist}_{\mathcal{D}}(\mathcal{H},f)=\min_{h\in\mathcal{H}}\mathsf{dist}_{\mathcal{D}}(h,f)
.

Empirical Risk Minimization (ERM):

An ERM algorithm finds a hypothesis with minimal empirical error. The main idea of ERM is that minimizing empirical error leads to minimizing true error. The learner does not know the underlying distribution, but it can measure the performance of a given hypothesis on random examples. Thus, instead of minimizing the true error, the learner tries to minimize the empirical error. It is well-known that for any hypothesis class that is not too complicated (i.e. has finite VC dimension), an ERM learner over large enough samples outputs a hypothesis with small true error as well (with high probability).

We start with the following definitions on representative samples from
\mathcal{D}
.

Definition 7.1

(
\epsilon
-Representative Samples
[
SSBD14
]
)
.

A set of samples
S
is
\epsilon
-representative
w.r.t. hypothesis class
\mathcal{H}
, distribution
\mathcal{D}
, and function
f
if for all
h\in\mathcal{H}
it holds that
|\mathsf{err}_{S}(h)-\mathsf{dist}_{\mathcal{D}}(h,f)|\leq\epsilon
.

Learning via uniform convergence says that if
|S|
is sufficiently large then a hypothesis
h
with the minimum empirical error also has a small true error with high probability. In fact, it states something stronger: the empirical error of all hypotheses is close to their true error with high probability. We recall the following well-known fact from learning theory.

Fact 7.2

(ERM for Hypothesis Classes of Finite VC Dimension
[
SSBD14
]
)
.

For any
n
, let
\mathcal{H}=\mathcal{H}_{n}
be any hypothesis class of finite VC-dimension, and let
S
be a set of
\mathsf{m}_{\mathcal{H}}(\epsilon,\delta)=\frac{C}{\epsilon^{2}}\cdot\left(\mathsf{VC}(\mathcal{H})+\log\frac{1}{\delta}\right)
i.i.d. labeled samples from some unknown distribution
\mathsf{Ex}(\mathcal{D},f)
, where
C
is a universal constant. Then
S
is
\frac{\epsilon}{2}
-representative with probability at least
1-\delta
. Moreover, an ERM algorithm minimizing
\mathsf{err}_{S}
achieves agnostic
(\epsilon,\delta)
-PAC learning.

We will show for an ERM algorithm to be a successful agnostic PAC learner, an
almost
empirically optimal hypothesis suffices, hence the following definition.

Definition 7.3
.

For a fixed
n
, let
\mathcal{H}=\mathcal{H}_{n}
be a hypothesis class of finite size, and
S
a finite set of labeled samples. We define the language
L^{\epsilon}_{S}\subseteq\mathcal{H}
as the set of empirically optimal hypotheses with respect to
S
up to
\epsilon
error. That is
L_{S}^{\epsilon}=\{h\in\mathcal{H}:\mathsf{err}_{S}(h)\leq\mathsf{opt}_{S}(\mathcal{H})+\epsilon\}
. We informally refer to elements of
L_{S}^{\epsilon}
as almost empirically optimal.

In
Section

7.1
, we present the main idea of using ERM for distribution free PAC-verification of general circuit classes, where the verifier has only random example access. In
Section

7.2
we further improve the query complexity of the verifier and apply the resulting generic protocol to polynomial sized circuits and juntas.

7.1
PAC-Verification for
\mathcal{H}_{n}
Using
O(\mathsf{VC}(\mathcal{H}_{n}))
Random Examples

The high level idea is that verifier and prover agree on a sample set
S
with i.i.d. samples. The prover provides an almost empirically optimal hypothesis
h
with respect to the samples (
Definition

7.3
). Then it only remains for the verifier to check that
h
is, in fact, almost empirically optimal; i.e.,
h\in L_{S}^{\epsilon}
for some error parameter
\epsilon
. Next we show that this statement reduces to an instance of Circuit Value Problem (CVP), and that we can apply an existing interactive proof for this statement. Alas, the prover is not efficient, and the resulting protocol is not doubly-efficient.

We start by observing that an almost empirically optimal hypothesis can be verified by a low-depth parallelised computation, in the following lemma.

Lemma 7.4

(Reducing
h\in L_{S}^{\epsilon}
to an Instance of CVP)
.

Fix a hypothesis class
\mathcal{H}=\mathcal{H}_{n}
, a sample set
S=\{(x_{i},y_{i})\}_{i=1}^{m}\subseteq\{0,1\}^{n}\times\{0,1\}
, and a parameter
\epsilon>0
. Then, there exists a log-space uniform circuit
C_{\mathsf{ERM}}^{h}:\{0,1\}^{mn+m}\to\{0,1\}
of size
{\mathsf{poly}}(m,|\mathcal{H}|)
and depth
{\mathsf{poly}}(\log(m),\log(|\mathcal{H}|))
such that
h\in L_{S}^{\epsilon}
if and only if
C_{\mathsf{ERM}}^{h}(x_{1},y_{1},\dots,x_{m},y_{m})=1
.

Proof.

The inputs to
C_{\mathsf{ERM}}^{h}
are the samples
x_{i}\in\{0,1\}^{n}
along with
y_{i}\in\{0,1\}
. Give as input each
x_{i}
to each circuit in
\mathcal{H}_{n}
. In other words, test all samples on all hypotheses in parallel. For any
h^{\prime}\in\mathcal{H}
, define its agreement with samples to be
\mathsf{agr}(h^{\prime})=|\{i\in[m]:h^{\prime}(x_{i})=y_{i}\}|
. Then, take the outputs of the circuit
h^{\star}\in\mathcal{H}
that maximizes the agreement and compare this number to the number of accepting samples from
h
and output
1
if and only if
\mathsf{agr}(h)+\epsilon m\geq\mathsf{agr}(h^{\star})
. Observe that the circuit outputs
1
if and only if
h\in L^{\epsilon}_{S}
. Therefore, the statement
h\in L^{\epsilon}_{S}
reduces to an instance of Circuit Value Problem, namely the value of
C_{\mathsf{ERM}}^{h}
on input
S
.

The circuit as described above needs
{\mathsf{poly}}(m,|\mathcal{H}|)
size as we run
m
samples on each hypothesis in
\mathcal{H}
. Note that the rest of the circuit is not any larger. The depth of the circuit is bounded by
{\mathsf{poly}}(\log(m),\log(|\mathcal{H}|))
; each circuit in
\mathcal{H}
can be implemented in depth
\log(|\mathcal{H}|)
, and we need no more than
{\mathsf{poly}}(\log m,\log|\mathcal{H}|)
to compute the agreement and find the maximum.

We can argue the circuit is log-space uniform since each level of the circuit is tasked with the same computation; in other words, this circuit has a highly regular wiring pattern.
∎

Following this, we state the following doubly-efficient interactive proof that verifies the result of the computation of any language computable by a low-depth circuit by an untrusted prover. In our case, the largeness of the circuit
C_{\mathsf{ERM}}
leads to inefficient prover time.

Lemma 7.5

(GKR Protocol
[

]
)

Let

be a language that can be computed by a family of

Remark 7.6
.

The round complexity of the GKR protocol is

.

Remark 7.7

We can set the soundness of the GKR protocol to any

Appendix A
Embeddability

In this section we present a general definition of the notion of
embeddability
of a random query in a query sets obtained from membership samples, described in
Section

3.2
. Recall, when transforming a protocol with membership queries into a protocol that works with random examples, we try to hide a
single
random example in
non-adaptively
generated query sets for the following definition.

Definition A.1

(Embeddable non-adaptive query set)
.

Let
\mathcal{D}
be a distribution over
\{0,1\}^{n}
, and let
V_{\mathsf{query}}
be an algorithm that given randomness
r
returns a sequence of
Q
queries,
y_{1},\dots,y_{Q}\in\{0,1\}^{n}
.

We say that a random query from
\mathcal{D}
can be embedded into the distribution defined by
V_{\mathsf{query}}
, if there exists an algorithm
\hat{V}_{\mathsf{query}}
that takes as input
w\sim\mathcal{D}
and randomness
r^{\prime}
, and outputs a query set
\hat{y}_{1},\dots,\hat{y}_{Q}\in\{0,1\}^{n}
such that the following hold.

1.

There exists
i\in[Q]
such that
\hat{y}_{i}=w
, i.e.,
w
is in the output of
\hat{V}_{\mathsf{query}}
.

2.

For every
\hat{y}_{1},\dots,\hat{y}_{Q}
that is generated by
V_{\mathsf{query}}
with non-zero probability it holds that

\Pr_{r^{\prime}}\left[\hat{y}_{i}=w\mid\hat{V}_{\mathsf{query}}(w;r^{\prime})\text{ outputs }\hat{y}_{1},\dots,\hat{y}_{Q}\right]=\frac{1}{Q}.

In other words, the query index into which
w
is embedded has a uniform distribution, where the probability is over the randomness
r^{\prime}
and the sample access to
\mathcal{D}
.

3.

For all
\hat{y}_{1},\dots,\hat{y}_{Q}
it holds that

\Pr_{r^{\prime}}\left[\hat{V}_{\mathsf{query}}(w;r^{\prime})\text{ outputs }\hat{y}_{1},\dots,\hat{y}_{Q}\right]=\Pr_{r}\left[V_{\mathsf{query}}(r)\text{ outputs }\hat{y}_{1},\dots,\hat{y}_{Q}\right].

In other words, the joint distribution of the queries generated by
\hat{V}_{\mathsf{query}}
and
V_{\mathsf{query}}
coincide.

In particular, the third condition implies that any (possibly unbounded) prover
P
can gain no information about the location of the embedded query
w
by looking at the joint query distributions of the output of
\hat{V}_{\mathsf{query}}
, and the second condition implies that
P
can guess the location of
w
with probability no more than
1/Q
.

(Embeddability is closed under independent unions
