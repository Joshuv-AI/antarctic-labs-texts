Exponential Hardness of Reinforcement Learning with Linear Function Approximation
Daniel Kane, Sihan Liu, Shachar Lovett, Gaurav Mahajan, Csaba Szepesvári, Gellért Weisz

Abstract
A fundamental question in reinforcement learning theory is: suppose the optimal value functions are linear in given features, can we learn them efficiently? This problem’s counterpart in supervised learning, linear regression, can be solved both statistically and computationally efficiently. Therefore, it was quite surprising when a recent work [ 18 ] showed a computational-statistical gap for linear reinforcement learning: even though there are polynomial sample-complexity algorithms, unless NP = RP, there are no polynomial time algorithms for this setting. In this work, we build on their result to show a computational lower bound, which is exponential in feature dimension and horizon, for linear reinforcement learning under the Randomized Exponential Time Hypothesis. To prove this we build a round-based game where in each round the learner is searching for an unknown vector in a unit hypercube. The rewards in this game are chosen such that if the learner achieves large reward, then the learner’s actions can be used to simulate solving a variant of 3-SAT, where (a) each variable shows up in a bounded number of clauses (b) if an instance has no solutions then it also has no solutions that satisfy more than (1- ϵ \epsilon )-fraction of clauses. We use standard reductions to show this 3-SAT variant is approximately as hard as 3-SAT. Finally, we also show a lower bound optimized for horizon dependence that almost matches the best known upper bound of exp ⁡ ( H ) \exp(\sqrt{H}) .

Proof Overview

The high-level idea of the previous lower bound of
[
18
]
was the following. The authors design an MDP that forces the learner to search for an unknown vector
w^{*}
in
\{0,1\}^{v}
which constitutes a satisfying solution of a given SAT formula
\phi
.
In particular, each state in the MDP corresponds to an assignment and the learner at the state can flip one variable appearing in the first unsatisfying clause of the formula (assuming some canonical ordering of the clauses). Rewards are given when the learner either reaches a satisfying assignment or the end of the horizon.
The rewards are designed in such a way that (i) the learner is incentivized for finding
w^{*}
quickly but (ii) unable to exploit much information from the rewards to accelerate the searching process. As a result, the task becomes as hard as solving the original SAT problem.

One bottleneck of the above approach is that the reward is only uninformative if the algorithm plays the game for fewer than
quasi-polynomially
many times. After that, there is a decent chance that the algorithm could obtain extra information from the reward structure which may significantly simplify the task. We follow the same high level idea of embedding hard (variants of) SAT instances into a linear-RL problem. Yet, we make significant modifications to the transition and reward structure of the MDP such that the algorithm can hardly obtain any useful information from the rewards unless it plays the game for
exponentially
many times.

In essence, we ensure the rewards given at the end of the horizon are uninformative by making it a Bernoulli variable with exponentially small mean. If so, the learner with high probability sees only
0
in the end unless it plays the game for a large number of times.
As a warm-up, one could imagine an MDP with actions and transitions identical to that from
[
18
]
.
Yet, we modify the reward to be
\exp(-
number of steps thus far
-\textrm{dist}(w,w^{*}))
at any terminal state
w
.
This makes sure the (expected) reward given at the end of the horizon is always exponentially small.
Unfortunately, the value function induced will be of the same exponential function, and hence cannot be written as a linear function of some low-dimensional features depending only on the state.

Round Based Game.

One way to fix this is by turning the game into a round based game. We divide the search into rounds and in each round, the variables are shown sequentially for the learner to decide whether to flip a variable it or not.
Then, if the learner terminates at the
n
-th round, we make the reward function roughly
\prod_{i=1}^{n}g_{i}(
number of flips taken in round
i)\cdot g_{n+1}(\textrm{dist}(w,w^{*}))
for some carefully chosen low-degree and monotonically decreasing polynomials
g_{i}
.
Now, consider the greedy policy which tries to decrease the distance to
w^{*}
whenever possible.
Since the greedy policy can always reach
w^{*}
within one (entire) round, the value function of such strategy at the beginning of round

\prod_{j<i}g_{j}(
number of flips in round
j)*g_{i}(\textrm{dist}(w,w^{*}))
.
Since only the last term depends on

and

, we get that the value function is essentially a

and

4.5

However, in order to ensure that this is the optimal strategy, we will need to define the

very precisely so that making a flip in the current round is always better than deferring it to future rounds. Essentially this means that the logarithmic derivative of

should be smaller than the logarithmic derivative of

for

.
Ideally, we would like to make

for some increasing sequence of

, which would then make the above property trivially true.
However, since

must be a polynomial, we will instead make it a Taylor approximation to this exponential function around

As long as we can make the error in this Taylor approximation small relative to the difference in logarithmic derivatives of

See

Flips Enforcement.

While the round-based game does ensure the linearity of the value function, the reward given at the end of the horizon is not necessarily small. Since

A caveat of doing so is that we want at least one variable to be indeed erroneous so that flipping it results in the correct truth assignment to it and hence the greedy policy is still well-defined and optimal.
Fortunately, this is guaranteed if

is a small enough absolute constant to be determined later. In particular, the hard instance for the first result is obtained by setting
p=2,q=4
and the hard instance for the second result is obtained by setting

p=2\log v,q=2
.

State Action Transition.

The time steps are divided into
h:=H/v
rounds where each round consists of
v
steps.
In each round, the MDP maintains a set of “used variables”, initialized to be the empty set at the beginning of each round. We will call unused variables as “free variables”. One round is further divided into two stages as follows:

1.

In each step of the first stage, the agent is given one unsatisfied
3-Sat
clause with only
free variables
and asked which of the three variables should be flipped.
Then, the variable chosen by the algorithm will be added to the set of used variables.
The first stage ends (and the second stage starts) when we run out of unsatisfied clauses with only free variables.

2.

In the second stage, the MDP presents each of the remaining free variables sequentially to the agent and asks whether the variable should be flipped. After each step, regardless of whether the algorithm decides to flip the variable or not, the variable presented will be added to the set of used variables.

Note that each round has exactly
v
steps since there are
v
variables in the formula and each step marks one of them as used.

Termination Condition.

The MDP terminates if it reaches the last level, or if more than a
(1-\epsilon)
-fraction of the clauses are satisfied. We make a couple of observations related to the termination conditions. First, if the MDP terminates before reaching the last level, the algorithm has essentially solved the underlying
Gap-
3
-Sat
problem since this means there exists an assignment that satisfies more than
(1-\epsilon)
-fraction of the clauses. Secondly, the termination condition ensures that, at the beginning of each round, there are at least an
\epsilon
-fraction of unsatisfied clauses. Since each variable appears in at most
b
clauses, we will never run out of unsatisfied clauses with only free variables in the first
\epsilon\cdot(
total number of clauses
/b)
steps.

Size of state space.

The number of states necessary for a round and an assignment is at most
O(3^{v})
: the transitions within a round form a tree of branching factor at most
3
and height at most
v
(see
fig.

1
).
There are
h=H/v
rounds,
the whole transition structure is a tree,
hence the total number of states is at most
O((3^{v})^{h})=\exp(\text{poly}(v,H))
.

Rewards.

Rewards are given only when the MDP terminates and are different depending on whether the formula is satisfiable or not. When the formula is not satisfiable, the reward is
0
everywhere.
In the rest of the discussion, we will think of assignments as vectors in
\{-1,1\}^{v}
. When the formula is satisfiable, we need to keep track of the assignment at the beginning of each round and denote them as
w^{(1)},w^{(2)}\ldots,w^{(n)}
(note that the algorithm starts at the first state with the assignment
w^{(1)}
), on which the final reward depends. The reward depends only on the history
w^{(1)},w^{(2)}\ldots,w^{(n)}
, the current assignment

w
and the optimal assignment
w^{*}
and is given by
Ber(r(w^{(1)},w^{(2)}\ldots,w^{(n)},w))
where
r(\cdot)
is the expected reward function and the Bernoulli distribution
Ber(\rho)
is
1
with probability
\rho
and
0
with probability
1-\rho
. Before specifying the expected reward function
r(\cdot)
,
we introduce the concept of an
extended assignment
.

Definition 4.2

(Extended Assignment)
.

Let
S
be the set of free variables. Then, the extended assignment of
w
under
S
, denoted as
\ext(w,S)
is given by
\ext(w,S)_{i}=w^{*}_{i}
for
i\in S
and
\ext(w,S)_{i}=w_{i}
for
i\not\in S
.

In plain language, the extended assignment is the assignment derived from
w
after correcting all the free variables to agree with
w^{*}
.
We note that dependence of the reward function on the extended assignment is crucial to ensure that the value functions associated to the greedy policy are linear functions, which will become relevant later. Now we are ready to define expected reward function
r(\cdot)
in terms of the historic assignments
w^{(1)},\cdots,w^{(n)}
reached by the agent at the end of past rounds, the current assignment
w
reached by the agent and the set of free variables
S
when the MDP terminates.

Definition 4.3

(Expected Reward)
.

Let
p,q\in\mathbb{Z}^{+}
be the two degree parameters.
Let
T_{p}:\mathbb{R}\mapsto\mathbb{R}^{+}
be the degree-
p
Taylor approximation of the exponential function
\exp(\cdot)
at zero:

T_{p}(x)=\sum_{i=0}^{p}\frac{x^{i}}{i!}.

Then, we define expected reward function
r(w^{(1)},w^{(2)}\ldots,w^{(n)},w,S)
as

\displaystyle\left(\prod_{i=1}^{n-1}g_{i}(\textrm{dist}(w^{(i)},w^{(i+1)}))\right)\cdot g_{n}(\textrm{dist}(w^{(n)},\ext(w,S)))\cdot g_{n+1}(\textrm{dist}(\ext(w,S),w^{*})),

(1)

where the polynomial
g_{i}:\mathbb{R}\mapsto\mathbb{R}
for round
i

is defined as

\displaystyle g_{i}(x)=T_{p}\left(-\frac{x}{v^{q-1}\cdot(3-i/h)}\right)\,.

(2)

As noted in the proof overview, the polynomials
g_{i}
are chosen to ensure that the optimal policy prefers going towards
w^{*}
as fast as possible and using a low degree Taylor approximation ensures the value function for the optimal policy can be written as a linear function of low dimensional features.

4.2
Linear Value Function

When the underlying formula is unsatisfiable, any policy is optimal since the reward is constantly
0
. When the formula is satisfiable, we will show that the “greedy policy” is optimal.

Definition 4.4

(Greedy Policy)
.

We say a policy is greedy if at every state it chooses any action that decreases the distance to
w^{*}
whenever possible. If not, it tries to not increase the distance to
w^{*}
.

Notice that based on our setup of the MDP greedy policies exist:
in the first stage of a round, the algorithm is given an unsatisfied clause so there is at least one variable in the clause that can be flipped to decrease the distance from the current assignment to
w^{*}
; in the second stage, the algorithm is given variables one at a time and it can always choose to not flip the variable if the current assignment already agrees with
w^{*}
on the variable.

We first discuss the value function
V^{\pi}
associated to a greedy policy
\pi
. Given a state with current assignment
w
and a set
S
of free variables, we define the following concepts that will be useful in the discussion. Let
m(S)\in\{0,1\}^{v}
be the masking vector such that
m(S)_{i}=1
if the
i
-th variable is in
S
and
m(S)_{i}=0
otherwise. Moreover, let
\mathbf{1}
denote the all-one vector and
\circ
the point-wise multiplication operator. Then, we define

\displaystyle\textrm{dist}_{S,\text{free}}(w,w^{*})

\displaystyle=\textrm{dist}(w\circ m(S),w^{*}\circ m(S))

\displaystyle\textrm{dist}_{S,\text{used}}(w,w^{*})

\displaystyle=\textrm{dist}(w\circ(\mathbf{1}-m(S)),w^{*}\circ(\mathbf{1}-m(S)))

In other words,
\textrm{dist}_{S,\text{used}}(w,w^{*})
and
\textrm{dist}_{S,\text{free}}(w,w^{*})
are the number of used and free variables respectively where the current assignment differs from
w^{*}
. Note that
\textrm{dist}_{S,\text{used}}(w,w^{*})+\textrm{dist}_{S,\text{free}}(w,w^{*})=\textrm{dist}(w,w^{*})
.

Moreover, since the Hamming distance
\textrm{dist}(a,b)
for two vectors
a,b\in\{-1,1\}^{v}

is linear in both
a
and
b
(as
\textrm{dist}(a,b)=(v-\langle a,b\rangle)/2
), this implies
\textrm{dist}_{S,\text{free}}({w,w^{*}})
and
\textrm{dist}_{S,\text{used}}({w,w^{*}})
can be written as a linear function of
w^{*}
and some state specific parameters depending on the current assignment
w
and the set of free variables
S
only. This allows us to show that the value functions for the greedy policy can also be written as linear functions of
w^{*}
and some state specific parameters.

Lemma 4.5
.

When
\varphi
is satisfiable, the greedy policy’s value at state
s
with round history
w^{(1)},\ldots,w^{(n)}
, current assignment
w
and the set of free variables
S
, is given by

\displaystyle V^{\pi}(s)=\prod_{i=1}^{n-1}g_{i}(\textrm{dist}(w^{(i)},w^{(i+1)}))\cdot g_{n}(\textrm{dist}(w^{(n)},w)+\textrm{dist}_{S,\text{free}}({w,w^{*}}))\cdot g_{n+1}(\textrm{dist}_{S,\text{used}}({w,w^{*}})).

(3)

As a result, there exists features
\psi(s),\psi(s,a)\in\mathbb{R}^{d}
with feature dimension
d\leq 2v^{2p}
depending only on state
s
and action
a
; and
\theta\in\mathbb{R}^{d}
depending only on
w^{*}
such that
V^{\pi}
and
Q^{\pi}
can be written as a linear function of features
\psi
i.e.
V^{\pi}(s)=\langle\theta,\psi(s)\rangle
and
Q^{\pi}(s,a)=\langle\theta,\psi(s,a)\rangle
.

Proof.

The first claim follows from the fact that the greedy policy will choose an action that will decrease the distance between the current assignment and the optimal assignment
w^{*}
used by the MDP whenever there is such an action. As a result, starting from a state
s
, it will flip all the free variables where
w
and
w^{*}
differ in the current round,
and then flip all the used variables where
w
and
w^{*}
differ in the next round. Upon reaching
w^{*}
, the final reward received will be exactly Equation (
3
) with no intermediate rewards.

Following the greedy policy may fail to reach
w^{*}
. The only way this can happen is when the MDP terminates early: when more than
(1-\epsilon)
-fraction of the clauses is satisfied, or when we reached a final state in the last round. In such cases,
the reward received depends on the extended assignment of the terminal state.
From Definitions
4.2
and
4.3
it follows that the reward received is the same than the reward would have been if the MDP were not to terminate at that point. Hence, the reward received is still consistent with Equation (
3
).

To prove the second claim, we follow a similar approach as in the proof of Proposition 10 in
[
18
]
.
In particular, we will show that
V^{\pi}(s)
can be written as a polynomial of degree at most
2p
in
w^{*}
.
To see why this is enough, we set
\theta
to be all monomials in
w^{*}
of degree at most
2p
. That is, each coordinate of
\theta
corresponds to a multiset
S\subset[v]
of size
|S|\leq 2p
, and its value is
\theta_{S}=\prod_{i\in S}w^{*}_{i}
.
We set
\psi(s)
to be the corresponding coefficients in the polynomial
V^{\pi}
. Then, we can write
V^{\pi}(s)=\langle\theta,\psi(s)\rangle
.
Since, there are at most
\sum_{i=0}^{2p}v^{i}\leq 2v^{2p}
many coefficients we can set the feature dimension as
d=2v^{2p}
.

Finally, we prove that
V^{\pi}(s)
can be written as a polynomial of degree at most
2p
in
w^{*}
. First recall that
\textrm{dist}_{S,\text{free}}({w,w^{*}})
and
\textrm{dist}_{S,\text{used}}({w,w^{*}})
can be written as a linear function of
w^{*}
and some state specific parameters
w^{(n)},w
and
S
. Moreover,
\textrm{dist}(w^{(n)},w)
is independent of
w^{*}
and only depends on
w^{(n)}
and
w
. Then the fact is proven by noting for each
g_{i}(\cdot)
in the expression that: (i) for
i<n
it is independent of
w^{*}
; and (ii) for
i\in\{n,n+1\}
, it is a degree-
p
polynomial in
\textrm{dist}(w^{(n)},w)
,
\textrm{dist}_{S,\text{free}}({w,w^{*}})
and
\textrm{dist}_{S,\text{used}}({w,w^{*}})
.

Finally, note that linear
V^{\pi}
implies linear
Q^{\pi}
in deterministic MDPs for
\psi(s,a)=\psi(P(s,a))
, since by definition, in MDPs with deterministic transition,
Q^{\pi}(s,a)=r(s,a)+V^{\pi}(P(s,a))

and the rewards in our MDPs are zero, except for the last stage where the rewards do not depend on the action.
∎

We now prove some structural properties of the polynomials
g_{i}
. First, we will show that if a policy makes a “reasonable” number of flips in a round, then the value function decreases by a multiplicative factor. This follows from
g_{i}
being (an appropriate degree) Taylor approximation of
\exp(\cdot)
function around zero.

Claim 4.6
.

The polynomials
g_{i}
defined in Equation (
2
) are bounded:

\frac{1}{4}\leq g_{i}(x)\leq 1-\frac{\epsilon}{6bv^{q-2}}

for all
\frac{\epsilon}{b}\cdot v\leq x\leq v
and
i\in\{1,\ldots,h\}
.
Moreover,
g_{i}
is monotonically decreasing.

Proof.

For simplicity let

z=\frac{x}{v^{q-1}\cdot(3-i/h)}.

For the range of values of
x
we are interested in and since
q\geq 2
, it follows that

z\leq 1/2
. Then, using the fact that
g_{i}
is a Taylor approximation, we can upper bound
g_{i}
by

\displaystyle g_{i}(x)=T_{p}\left(-z\right)=\sum_{j=0}^{p}\frac{(-z)^{j}}{j!}

\displaystyle\leq 1-\frac{z}{2}

(as
p\geq 2
and
z\leq 1/2
)

\displaystyle\leq 1-\frac{\epsilon}{6bv^{q-2}}\,.

(as
x\geq\frac{\epsilon}{b}\cdot v
)

On the other hand, we can lower bound
g_{i}(x)
as follows:

\displaystyle g_{i}(x)=\exp\left(-z\right)-\sum_{j=p+1}^{\infty}\frac{\left(-z\right)^{j}}{j!}

\displaystyle\geq\exp\left(-\frac{1}{2}\right)-\frac{1}{2^{p}(p+1)!}\geq\frac{1}{4}\,,

(4)

where the first inequality again follows from
z\leq 1/2
and summation of geometric series and the last inequality holds as long as
p\geq 1
.

Next, we argue
g_{i}(x)
is monotonically decreasing. We do so by showing the derivative of
g_{i}(x)
is negative. For this, we calculate

\displaystyle\frac{d}{dx}g_{i}(x)=\left(\frac{d}{dx}z\right)\cdot\left(\frac{d}{dz}T_{p}(-z)\right)=-\sum_{j=0}^{p-1}\left(\frac{(-z)^{j}}{j!}\right).

Similar to Equation (
4
), we have

\sum_{j=0}^{p-1}\left(\frac{(-z)^{j}}{j!}\right)\geq\exp\left(-\frac{1}{2}\right)-\frac{1}{2^{p-1}p!}>0

whenever
p\geq 2
.
Therefore,
\frac{d}{dx}g_{i}(x)<0
which implies that
g_{i}(x)
is monotonically decreasing.
∎

Next, we will show that the polynomials are designed such that correcting variables (where
w
and
w^{*}
differ) in round

is always better than correcting variables in round
i+1
.
In particular, suppose we have flipped

bits in the
i
-th round and

bits in the
(i+1)
-th round. We then want to show that

g_{i}(c)\cdot g_{i+1}(d)\geq g_{i}(c-1)\cdot g_{i+1}(d+1)
for any
1\leq c\leq v
and
0\leq d\leq v
.
To prove this, we need to show that the error from Taylor approximation which depends on the choice of

is relatively small.

Claim 4.7
.

For any two polynomials
g_{i},g_{i+1}
defined in Equation (
2
), let

f_{i,c,d}(x)=g_{i}(c+x)\cdot g_{i+1}(d-x).

where

,

and

.
Then, for large enough

f_{i,c,d}(x)\geq f_{i,c,d}(x-1).

Proof.

Consider the function
\hat{f}_{i,c,d}(\cdot)
defined as

\displaystyle\hat{f}_{i,c,d}(x)=\exp\left(-\frac{c+x}{v^{q-1}\cdot(3-i/h)}\right)\cdot\exp\left(-\frac{d-x}{v^{q-1}\cdot(3-(i+1)/h)}\right).

(5)

To prove our claim, we will show that

\displaystyle\hat{f}_{i,c,d}(x)-\hat{f}_{i,c,d}(x-1)

\displaystyle\geq\Omega\left(\frac{1}{\alpha\cdot v^{2q-2}}\right)\,,

(6)

\displaystyle\lvert f_{i,c,d}(x)-\hat{f}_{i,c,d}(x)\rvert

\displaystyle=O\left(\frac{1}{v^{2q-2}}\right)\ \,,

(7)

where to recall
\alpha
in Equation (

) is the parameter in the time horizon factor, i.e.
H=\alpha\cdot v^{q}
and
h=H/v
.
Then, our claim follows from the inequalities above as long as
\alpha
is set to be a sufficiently small constant.
We first prove
Equation

. For this, we will show that the derivative of
\hat{f}_{i,c,d}(x)
is not only positive but lower bounded by
\Omega(1/\alpha\cdot v^{2q-2})
.
The derivative of
\hat{f}(\cdot)
is given by

\displaystyle\hat{f}^{\prime}_{i,c,d}(x)=\hat{f}_{i,c,d}(x)\cdot\frac{h}{v^{q-1}\cdot\left(3h-i\right)\cdot\left(3h-i-1\right)}.

(8)

Notice that
we always have

\hat{f}_{i,c,d}(x)\geq\exp\left(-\frac{2v}{v^{q-1}}\right)\cdot\exp\left(-\frac{v}{v^{q-1}}\right)=\exp\left(-\frac{3}{v^{q-2}}\right)\geq\Omega(1),

and last step from

. We hence have
\hat{f}_{i,c,d}(x)\geq\Omega(1)
.
Combining this with

\hat{f}^{\prime}_{i,c,d}(x)\geq\Omega\left(\frac{1}{\alpha\cdot v^{2q-2}}\right).

Since

Next, we prove

. Recall that

g_{i}(y)=T_{p}\left(\frac{-y}{v^{q-1}\cdot(3-i/h)}\right)

Then, for

\displaystyle\left|g_{i}(y)-\exp\left(-\frac{y}{v^{q-1}\cdot(3-i/h)}\right)\right|\leq O\left(\left(\frac{y}{v^{q-1}\cdot(3-i/h)}\right)^{p+1}\right)\leq O\left(\frac{1}{v^{(q-2)\cdot(p+1)}\cdot 2^{p+1}}\right).

\displaystyle f_{i,c,d}(x)

\displaystyle\left(\exp\left(-\frac{d-x}{v^{q-1}\cdot(3-(i+1)/h)}\right)\pm O\left(\frac{1}{v^{(q-2)\cdot(p+1)}\cdot 2^{p+1}}\right)\right)

Lemma 4.8
.

Any greedy policy as defined in

Proof.

Let
\pi

Suppose

with round history

.
4
4

4

Notice it could be that the terminal state

\displaystyle V^{\tilde{\pi}}(s_{\text{curr}})=G\cdot\prod_{i={n}}^{n+l}g_{i}\left(\textrm{dist}(\tilde{w}^{(i)},\tilde{w}^{(i+1)})\right)\cdot g_{n+l+1}\left(\textrm{dist}\left(\tilde{w}^{(n+l+1)},w^{*}\right)\right).

\displaystyle\prod_{i={n}}^{n+l}g_{i}(\textrm{dist}(\tilde{w}^{(i)},\tilde{w}^{(i+1)}))\cdot g_{n+l+1}(\textrm{dist}(\tilde{w}^{(n+l+1)},w^{*}))\leq g_{n}\left(\tilde{w}^{(n)},\tilde{w}^{(n+1)}\right)\cdot g_{n+1}\left(\tilde{w}^{(n+1)},w^{*}\right).

\displaystyle g_{n+l}\bigg(\textrm{dist}(\tilde{w}^{(n+l)},\tilde{w}^{(n+l+1)})\bigg)\cdot g_{n+l+1}\bigg(\textrm{dist}(\tilde{w}^{(n+l+1)},w^{*})\bigg)

\displaystyle V^{\tilde{\pi}}(s)\leq G\cdot g_{n}\left(\textrm{dist}\left(w^{(n)},\tilde{w}^{(n+1)}\right)\right)\cdot g_{n+1}\left(\textrm{dist}\left(\tilde{w}^{(n+1)},w^{*}\right)\right).

Notice that by the triangle inequality, for any
\tilde{w}^{(n+1)}

\displaystyle\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})+\textrm{dist}(\tilde{w}^{(n+1)},w^{*})-\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})\geq\textrm{dist}_{S_{\text{curr}},\text{used}}({w_{\text{curr}},w^{*}})

Now, we will use case analysis based on the relative sizes of
\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})

\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})

We first consider the case
\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})\leq\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})
.
In this case we have

\displaystyle g_{n}\Big(\textrm{dist}(w^{(n)},\tilde{w}^{(n+1)})\Big)\cdot g_{n+1}\Big(\textrm{dist}(\tilde{w}^{(n+1)},w^{*})\Big)

\displaystyle=g_{n}\Big(\textrm{dist}(w^{(n)},w_{\text{curr}})+\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})\Big)\cdot g_{n+1}\Big(\textrm{dist}(\tilde{w}^{(n+1)},w^{*})\Big)

\displaystyle\leq g_{n}\Big(\textrm{dist}(w^{(n)},w_{\text{curr}})+\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})\Big)

\displaystyle\cdot g_{n+1}\Big(\textrm{dist}(\tilde{w}^{(n+1)},w^{*})+\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})-\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})\Big)

\displaystyle\leq g_{n}\Big(\textrm{dist}(w^{(n)},w_{\text{curr}})+\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})\Big)\cdot g_{n+1}\Big(\textrm{dist}_{S_{\text{curr}},\text{used}}({w_{\text{curr}},w^{*}})\Big)\,,

where the first inequality follows from Claim
4.7
and the second inequality follows from
g_{n}
is a monotonically decreasing function (
4.6
) and Equation (
14
).

Now, we consider the other remaining case when
\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)})>\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})
.
Denote
M
as the set of free variables on which
w_{\text{curr}}
and
w^{*}
agree but
w_{\text{curr}}
and
\tilde{w}^{(n+1)}
disagree.
In other words, these are the variables mistakenly flipped by the policy
\tilde{\pi}
on the path from
w_{\text{curr}}
to
\tilde{w}^{(n+1)}
.
Since
\tilde{w}^{(n+1)},w^{*}
disagree on these variables, these variables must be flipped again on the path from
\tilde{w}^{(n+1)}
to
w^{*}
.
We can then consider the alternative path
w_{\text{curr}}\rightarrow\bar{w}\rightarrow w^{*}
for
\bar{w}
satisfying

\bar{w}_{i}\neq\tilde{w}^{(n+1)}_{i}
for
i\in M
and
\bar{w}_{i}=\tilde{w}^{(n+1)}_{i}
for
i\not\in M
.
Then, it is easy to see that

\displaystyle g_{n}(\textrm{dist}(w^{(n)},w_{\text{curr}})+\textrm{dist}(w_{\text{curr}},\tilde{w}^{(n+1)}))\cdot g_{n+1}(\textrm{dist}(\tilde{w}^{(n+1)},w^{*}))

\displaystyle\leq g_{n}(\textrm{dist}(w^{(n)},w_{\text{curr}})+\textrm{dist}(w_{\text{curr}},\bar{w}))\cdot g_{n+1}(\textrm{dist}(\bar{w},w^{*}))

since
g_{n}(\cdot)
is monotonically decreasing.
Moreover, now we have
\textrm{dist}(w_{\text{curr}},\bar{w})\leq\textrm{dist}_{S_{\text{curr}},\text{free}}({w_{\text{curr}},w^{*}})
since the variables flipped are restricted to be the ones on which
w_{\text{curr}}
and
w^{*}
do not agree. Hence, the proof is reduced to the first case.

∎

4.3
RL algorithm to SAT algorithm

Following the approach taken in previous lower bound
[

(1-\epsilon)

Correctness.

To complete our reduction, we will show the following:

(i)

outputs a policy

, then

with respect to

with error probability
1/8
(namely, even though

is interacting with the simulator

, the returned policy is guaranteed to do well on the true MDP
M_{\varphi}
).

Recalling that if
\phi
is not satisfiable, any policy is optimal, the above two claims establish
that
\mathcal{A}_{SAT}
solves
Gap-
3
-Sat
with error probability
\leq 1/8
. We start by proving that if
\mathcal{A}_{RL}
succeeds on MDP
M_{\varphi}
, then
\mathcal{A}_{SAT}
succeeds on
3-CNF
formula
\varphi
. This follows from the fact that any good policy in the MDP

, the satisfying assignment which is arbitrarily chosen to construct

.

Proposition 4.9
.

Assume that
\alpha,b,\epsilon
are constants and that
v
is large enough. Then,
if
\varphi
is satisfiable and

\mathcal{A}_{RL}
running on
M_{\varphi}
returns a policy
\pi
satisfying
V^{\pi}>V^{*}-1/8

then
\pi
ends on an assignment that satisfies at least a
(1-\epsilon)
-fraction of clauses.

Proof.

Take a satisfiable formula
\varphi
.
The optimal value in this case is at least
1/4
. Indeed, by
Lemma
4.8
, the greedy policy is optimal, its value is
g_{1}(\textrm{dist}(w,w^{*}))

and thus by Claim
4.6
,

\displaystyle V^{*}=g_{1}(\textrm{dist}(w,w^{*}))\geq\frac{1}{4}\,.

We now argue by contraposition: Assume that
\pi
does not end on an assignment that satisfies at least a
(1-\epsilon)
-fraction of clauses.
Let
w^{(1)}
,
\dots
,
w^{(h)}
,
\bar{w}
denote the sequence of assignments obtained by
\pi
:

w^{(1)}=w
, and
w^{(i+1)}
is the assignment at the end of round

and
\bar{w}
is the final assignment.
Recall in each round the MDP has two stages.
In the first stage, the agent is presented unsatisfied clauses made up of only free variables.
By our construction, the first stage is of length at least
\epsilon v/b
.
It follows that

since the policies are not allowed to undo any flips.
We can then upper bound the reward obtained at the end by

\displaystyle\prod_{i=1}^{h}g_{i}(\textrm{dist}(w^{(i)},w^{(i+1)}))\cdot g_{h+1}(\textrm{dist}(\bar{w},w^{*}))\leq\prod_{i=1}^{h}g_{i}(\epsilon v/b)\leq\left(1-\frac{\epsilon}{6bv^{q-2}}\right)^{h}\leq\exp(-cv),

where

, the second from Claim

, and the third follows from

that holds for all

and our choice of

. Therefore, if

, and

is large enough so that

, then the policy

has to end on a state
which satisfied at least a
(1-\epsilon)
-fraction of clauses.
∎

Next, we show that the behavior of
\mathcal{A}_{RL}
is about the same even if it is run on the simulator
\bar{M}_{\varphi}
. In particular, given
\mathcal{A}_{RL}
runs in sub-exponential time and succeeds on

\mathcal{A}_{RL}
will be provided about the same information when it is executed on

and on
M_{\varphi}

Proposition 4.10
.

Suppose
\mathcal{A}_{RL}
with access to MDP oracle
M_{\varphi}
runs in time

and outputs a policy

such that
V^{\pi}>V^{*}-1/8
with error probability
1/10
.
Further, assume that the expected reward at the last layer of
M_{\varphi}
is upper bounded by

Then
\mathcal{A}_{RL}
with access to simulator
\bar{M}_{\varphi}

such that

with respect to

with error probability

.

Proof.

Let
\Pr_{M_{\varphi}}
and
\Pr_{\bar{M}_{\varphi}}
denote the distribution on the observed rewards and output policies induced by the algorithm
\mathcal{A}_{RL}
when running on access to MDP oracle
M_{\varphi}
and simulator
\bar{M}_{\varphi}
respectively.
Let

denote the reward received on the last layer at the end of

when running on access to MDP oracle

We remark that if the algorithm

will terminate the simulation immediately, returning YES.
Before reaching a satisfying assignment,

may only receive rewards from the last layer.
Since the expected reward at the last layer in the MDP

is upper bounded by

by our assumption,
and the algorithm only visits at most

\displaystyle\Pr_{M_{\varphi}}\left[R_{i}=0\penalty\ \forall i\in[N]\right]\geq 1-T/(5T)\geq\frac{4}{5}.

We say that

(or

Note that the

and simulator

may only differ on last layer rewards before

reaches a satisfying assignment. This implies

\displaystyle\Pr_{\bar{M}_{\varphi}}\left[\mathcal{A}_{RL}\penalty\ \text{succeeds with access to}\penalty\ \bar{M}_{\varphi}\mid R_{i}=0\penalty\ \forall i\in[N]\right]

\displaystyle=\Pr_{M_{\varphi}}\left[\mathcal{A}_{RL}\penalty\ \text{succeeds with access to}\penalty\ M_{\varphi}\mid R_{i}=0\penalty\ \forall i\in[N]\right]

Since,
\Pr_{\bar{M}_{\varphi}}\left[R_{i}=0\penalty\ \forall i\in[N]\right]=1
, we conclude that

\displaystyle\Pr_{\bar{M}_{\varphi}}\left[\mathcal{A}_{RL}\penalty\ \text{succeeds with access to}\penalty\ \bar{M}_{\varphi}\right]

Hardness of Approximate SAT with gap and few clauses

In this section, we prove the following:

Proposition A.1
.

Under
rETH
, there exists constants
b,\epsilon,c>0
such that no randomized algorithm can solve
(b,\epsilon)
-
Gap-
3
-Sat
with
v

\exp(cv/\polylog(v))
with error probability
1/8
.

To prove this, we will look at another problem:
\epsilon

Gap-
3
-Sat
. This is similar to
(b,\epsilon)
-
Gap-
3
-Sat
except it does not put any constraints on how many clauses a variable can be in. Through standard technique, one can show that
\epsilon
-
Gap-
3
-Sat
is also hard. In particular, its hardness is shown in
[
23
]
and relies on a certain version of the Probabilistic Checkable Proof (PCP) theorem.

Complexity problem

\epsilon
-
Gap-
3
-Sat

Input:

A gap parameter
\epsilon>0
and a
3-CNF
formula
\varphi
with
v
variables and
O(v)
clauses such that the either (i)
\varphi
is satisfiable or (ii) any assignment leaves at least an
\epsilon
-fraction of the clauses unsatisfied where
\epsilon>0
.

Goal:

Decide whether the formula is satisfiable.

.

Theorem A.2

(Reduction from
3-Sat
to
Gap-
3
-Sat
)
.

Solving
3-Sat
on inputs of size
n
can be reduced to distinguishing
between the case that a
3-CNF

is satisfiable and the case that only

For completeness, we provide a proof for the above theorem. We first review some basic concepts about the PCP theorem. Given a statement (for example, whether a SAT instance is satisfiable), a PCP verifier is granted query access to a proof constructed for the statement over an alphabet
\Sigma
and asked to decide whether the statement is true. A PCP verifier has several important parameters.

•

Completeness

c
: The minimal probability that the verifier accepts a correct proof.

•

Soundness

\epsilon
: The maximal probability that the verifier accepts a proof for an incorrect theorem.

•

Queries

q
: The number of queries made by the verifier to the proof.

•

Size

m
: The length of the proof.

•

Randomness

r
: The number of random bits used by the verifier.

•

Alphabet

\Sigma
: The alphabet used by the proof.

We denote by
\text{PCP}_{c,\epsilon}[r,q]_{\Sigma}
the class of languages that have a PCP verifier with completeness
c
, soundness
s
, randomness
r
, and
q
queries to a proof over alphabet
\Sigma
. Moreover, the PCP verifier is only allowed to do a two query projection test. In a two query-projection test, the verifier is only allowed to make two queries. Upon seeing the answer to the first query, the verifier either immediately rejects, or it has uniquely determined answer to the second query on which it accepts. Our starting point is the following theorem from
[
23
]
.

Theorem A.3

(Theorem 7 from
[
23
]
)
.

There exists a constant
\epsilon>0
and an alphabet
\Sigma
of constant size, such that
\textsc{3-Sat}\penalty\ \in PCP_{1,1-\epsilon}[\log n+O(\log\log n),2]_{\Sigma}
.

Proof of
Theorem

A.2
.

Given a
3-CNF
formula
\psi
with size
n
, the goal is to use the verifier in the above theorem to construct a different
3-Sat
instance
\phi
with size
O(n\polylog n)
such that
(i)
\phi
is satisfiable if
\psi
is satisfiable; and
(ii) at least an
\epsilon
fraction of the clauses in
\phi
are not satisfiable under any assignment if
\psi
is not satisfiable.

Notice that we can without loss of generality assume the verifier is deterministic if we assume it also takes
r:=\log n+O(\log\log n)
random bits as input. Fix a random bit string, the verifier reads at most
2
characters from the proof. Since there are at most
2^{r}=n\polylog n
different random bit strings, we can without loss of generality assume the proof is of size at most
T:=2n\polylog n
.
The first step of the construction is to create
T
variables
\{x_{1},x_{2},\cdots,x_{T}\}
where
x_{i}\in\Sigma
represent the queries responses given to the verifier.
We will create a SAT formula for each of the
2^{r}
random bit strings and the final construction will be simply the concatenation of all the SAT formulas with the
“AND”
logical operator.
Fix an arbitrary random string
q\in\{0,1\}^{r}
. We can then compute the first position the verifier will read. We can denote it as
l_{1}(q)
. There will be a subset of values
R(q)\subseteq\Sigma
that the verifier will reject immediately

.
If the verifier does not reject immediately, the verifier could branch off to do different things based on the value of

. Suppose,

. We can then compute the second position the verifier will read, which we denote as

, and the “right” character the verifier is expecting, which we denote as

. Then, we know that the verifier will accept if and only if the proof, represented by

Since

In addition, there are at most

. Hence, the overall

\phi
is of size

. We know that the verifier would reject with probability at least
\epsilon

\psi
is not satisfiable.
Hence, at least an
\epsilon

\phi
will not be satisfied under any assignment (which can be interpreted as the binary encoding of the given proof).
On the other hand, if
\psi
is satisfiable, it then holds every sub-formula of
\phi
is satisfiable since the verifier always accepts under the “correct” proof.

If one has an algorithm which can distinguish between the cases that
\epsilon

\phi
cannot be satisfied under any assignment versus
\phi
is satisfiable, one can then decide the satisfiability of
\psi
.
∎

-Sat
for some constant
\epsilon_{1}\in(0,1)
, there is no sub-exponential algorithm for
(b,\epsilon_{2})
-
Gap-
3
-Sat
either for some constant
b
and
\epsilon_{2}\in(0,\epsilon_{1})

Combining Theorem

Appendix B
Upper Bounds

In both of the upper bounds, the final policy computed by our algorithms is of the following form: at the state
s
, we have some estimations
\tilde{Q}(s,a)
for each
a\in\mathcal{A}
such that

\lvert\tilde{Q}(s,a)-Q^{*}(s,a)\rvert\leq\epsilon
and the policy always chooses the action
a=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
. We claim the policy induced is nearly optimal as long as
\epsilon
is sufficiently small. The formal statement is given below.

Lemma B.1
.

For any state action pair
(s,a)
,
let
\tilde{Q}(s,a)
be an approximation of
Q^{*}(s,a)
satisfying

\lvert\tilde{Q}(s,a)-Q^{*}(s,a)\rvert\leq\epsilon/(2H)
. Then, consider the policy
\pi
such that at the state
s
, it always chooses the action
a=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
.
Then, it holds

V^{\pi}(s)\geq V^{*}(s)-\epsilon
for any state.

Proof.

We claim
\pi
is a policy satisfying that

V^{\pi}(s)\geq V^{*}(s)-\epsilon\cdot h/H
for any state
s
in the MDP such that there are still
h
steps remaining.
We show this via induction on the number of steps remaining.
Suppose
s
is a state right before the last step.
Then,
V^{*}(s)=Q^{*}(s,a^{*})
for
a^{*}=\mathop{{}\textrm{argmax}}_{a}Q^{*}(s,a^{*})

and

V^{\pi}(s)=Q^{*}(s,a^{\prime})
for
a^{\prime}=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
.
By our assumption, we have

V^{\pi}(s)\geq\tilde{Q}(s,a^{\prime})-\epsilon/(2H)
and since
a^{\prime}=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
, we then further have

V^{\pi}(s)\geq\tilde{Q}(s,a^{*})-\epsilon/(2H)\geq Q^{*}(s,a^{*})-\epsilon/H=V^{*}(s)-\epsilon/H.

Now, consider a state
s
such that there are
(h+1)
steps remaining.
Still, let
a^{\prime}=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
and
a^{*}=\mathop{{}\textrm{argmax}}_{a}Q^{*}(s,a^{*})
.
Furthermore, let
s^{\prime}=P(s,a^{\prime})
be the next state after applying
a^{\prime}
.
We then have
V^{*}(s)=Q^{*}(s,a^{*})
and

V^{\pi}(s)=\mathbb{E}\left[R(s,a^{\prime})\right]+V^{\pi}(s^{\prime})
.
We then have

\displaystyle V^{\pi}(s)

\displaystyle=\mathbb{E}\left[R(s,a^{\prime})\right]+V^{\pi}(s^{\prime})

(Definition of the policy
\pi
)

\displaystyle\geq\mathbb{E}\left[R(s,a^{\prime})\right]+V^{*}(s^{\prime})-\epsilon h/H

(Inductive Hypothesis)

\displaystyle=Q^{*}(s,a^{\prime})-\epsilon h/H

(Definition of
Q^{*},V^{*}
)

\displaystyle\geq\tilde{Q}(s,a^{\prime})-\epsilon h/H-\epsilon/(2H)

(Assumption about
\tilde{Q}
)

\displaystyle\geq\tilde{Q}(s,a^{*})-\epsilon h/H-\epsilon/(2H)

(Choice of
a^{\prime}=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
)

\displaystyle\geq Q^{*}(s,a^{*})-\epsilon h/H-\epsilon/H

(Assumption about
\tilde{Q}
)

\displaystyle=V^{*}(s)-\epsilon(h+1)/H

\displaystyle\text{(The choice of $a^{*}=\mathop{{}\textrm{argmax}}_{a}Q^{*}(s,a)$ and the definition of $Q^{*},V^{*}$)}.

This then gives us
V^{\pi}(s)\geq V^{*}(s)-\epsilon
for any state since there are in total
H
steps in the MDP.
∎

We first prove a computational upper bound which is exponential in the feature dimension
d
.
On a high level, we discretize the parameter space that
\theta^{*}
may lie in to create a policy cover which allows us to search for the best in class by estimating the value of each policy.

Proposition B.2
.

Assume the Linear MDP has a constant number of actions, feature dimension
d
and time Horizon
H
.
Furthermore, assume the featuer vectors satisfy
\left\|\psi(s,a)\right\|_{2}\leq 1
for all state action pairs and
\left\|\theta^{*}\right\|_{2}\leq 1
for the optimal parameter
\theta^{*}
.
Let
\epsilon\in(0,1)
.
There is an algorithm which takes
\exp\left(c\cdot d\cdot\log\left(Hd/\epsilon\right)\right)

time for some sufficiently large constant
c
and finds a policy
\pi
such that
V^{\pi}(s)\geq V^{*}(s)-\varepsilon
with probability
9/10
.

Proof.

Let
\theta^{*}
denote the unknown parameters of the optimal
Q^{*}
function, i.e.

Q^{*}(s,a)=\langle\theta^{*},\psi(s,a)\rangle
.
Suppose we can find such a
\theta\in\mathbb{R}^{d}
satisfying

\left\|\theta-\theta^{*}\right\|_{2}\leq\varepsilon/(2H\cdot\sqrt{d})
.
We note that this implies

\displaystyle\lvert\langle\theta,\psi(s,a)\rangle-Q^{*}(s,a)\rvert\leq\varepsilon/(2H).

(15)

Then, consider the policy
\pi(\theta)
such that at state
s
it always chooses the action

a=\mathop{{}\textrm{argmax}}_{a}\langle\theta,\psi(s,a)\rangle.

By
Lemma

B.1
, it holds

V^{\pi(\theta)}(s)\geq V^{*}(s)-\epsilon
for any state
s
.

Now, let
S\in\mathbb{R}^{d}
be the set of vectors that form an
\epsilon/(2H\sqrt{d})
-cover of the
d
-dimensional unit sphere, i.e.
\min_{\theta\in S}\left\|\theta-\theta^{*}\right\|_{2}\leq\epsilon/(2H\sqrt{d})
for any
\theta^{*}
satisfying
\left\|\theta^{*}\right\|_{2}\leq 1
. Through a standard combinatorial construction, there exists such a cover
S
with size
\lvert S\rvert\leq\exp\left(c\cdot d\cdot\log\left(Hd/\epsilon\right)\right)
for some sufficiently large constant
c
.
From the argument above, we know there must be some
\theta\in S
such that
\pi(\theta)
is nearly optimal, i.e.

V^{\pi(\theta)}(s)\geq V^{*}(s)-\epsilon
for any state
s
.

Our strategy is simple: we will try
\pi(\theta)
for all
\theta\in S
in a brute-force manner and estimate the expected reward of the induced trajectory up to accuracy
\epsilon
.
Notice that the maximum reward collected by any trajectory is at most
H
.
Hence, if we visit the same trajectory with
\textrm{poly}(H,1/\epsilon)\cdot\log(1/\delta)
many times, we can then compute an estimation of its expected reward up to accuracy
\epsilon
with probability at least
1-\delta
. We can take
\delta=\frac{1}{|S|}
so that by union bound our estimation for
V^{\pi(\theta)}(s_{0})
is accurate up to error
\epsilon
for all
\theta\in S
with probability at least
9/10
.
Condition on that, we can then choose
\theta
such that it maximizes our empirical estimations of
V^{\pi(\theta)}(s_{0})
. Then, it is easy to see that such a
\pi(\theta)
must satisfy
V^{\pi(\theta)}(s_{0})\geq V^{*}(s_{0})-2\epsilon
.
Now, since to simulating the interaction of one trajectory takes time at most
\textrm{poly}(d,H)
, the total runtime is bounded by

\textrm{poly}(d,H)\cdot\textrm{poly}(H,1/\epsilon)\cdot\log(1/|S|)\cdot\lvert S\rvert\leq\exp\left(c\cdot d\cdot\log\left(Hd/\epsilon\right)\right)

for some sufficiently large constant
c
.
∎

To prove a horizon upper bound, we build on results of previous work
[
8
]
. This upper bound was originally personally communicated to the authors by Ruosong Wang. We only add it here for completeness. We first give a high level overview of the differences. The proof is almost exactly the same except we now divide the steps of the MDP into
\sqrt{H}
“rounds”.
We will brute force search in the rounds for the optimal policy and use the basis constructed in previous work
[
8
]
to ensure error only grows by a factor of
\sqrt{d}
.
We next prove this in more detail.

Proposition B.3

(Ruosong Wang, personal communication)
.

Assume the Linear MDP has a constant number of actions, feature dimension
d
and time Horizon
H
.
Furthermore, assume the featuer vectors satisfy
\left\|\psi(s,a)\right\|_{2}\leq 1
for all state action pairs and
\left\|\theta^{*}\right\|_{2}\leq 1
for the optimal parameter
\theta^{*}
.
Let
\epsilon\in(0,1)
.
There is an algorithm which takes
\exp\left(c\cdot\sqrt{H}\log d\right)/\epsilon^{-2}
time for some sufficiently large constant
c
and finds a policy
\pi
such that
V^{\pi}(s)\geq V^{*}(s)-\varepsilon
.

Proof.

Given an arbitrary state
s
,
suppose there is a procedure that runs in time

T:=\exp\left(c\cdot\sqrt{H}\log d\right)/\epsilon^{-2}\cdot\log(1/\delta)

and computes
an estimation of
\tilde{Q}(s,a)
for each action
a\in\mathcal{A}
such that

\lvert\tilde{Q}(s,a)-Q^{*}(s,a)\rvert\leq\epsilon/(2H)
with probability at least
1-\delta
.
Then, we claim we can design an algorithm which outputs a policy
\pi

such that
V^{\pi}(s_{0})\geq V^{*}(s_{0})-\epsilon
for the initial state
s_{0}
with probability at least
9/10
.
Starting at the state
s=s_{0}
, we will perform the following steps iteratively:

1.

For the current state
s
, compute the estimations
\tilde{Q}(s,a)
.

2.

Choose
a=\mathop{{}\textrm{argmax}}_{a}\tilde{Q}(s,a)
and then updates
s
to be the next state after applying action
a
.

The above process goes on for at most
H
iterations. Hence, our estimations
\tilde{Q}(s,a)
are accurate in all iterations with probability at least
9/10
if we set
\delta=1/(10H)
.
By
Lemma

B.1
, it then holds the resulting policy is nearly-optimal starting from the initial state
s_{0}
.
Moreover, the algorithm runs in time
H\cdot O(T)
, which is within the desired runtime.

To finish the proof, we then describe our procedure for computing the estimations
\{\tilde{Q}(s,a)|a\in\mathcal{A}\}
for a state
s
.
We will describe the procedure for just the initial state
s_{0}
as computing the estimations for other states can be done similarly.
To do so, we divide the time steps of the MDP into
\sqrt{H}
rounds.
For each round
h\in\sqrt{H}
, we build a set of vectors
B_{h}
that correspond to the “basis” of some larger set of feature vectors
\psi(s,a)
where
s
is a state on the
h\cdot\sqrt{H}
level, i.e. there is a trajectory going from
s_{0}
to
s
in
h\cdot\sqrt{H}
steps.
The step is similar to previous work
[
8
]
and proceeds as follows.
Let
B_{0}=\{\psi(s_{0},a):a\in A\}
where
a
is the set of all actions. Then, we construct
B_{h}
recursively from
B_{h-1}=\{\psi(s_{i},a_{i})\}
: Let
\bar{B}_{h}=\{\psi(P(s_{i},a_{i}),a):a\in A\penalty\ \text{and}\penalty\ \psi(s_{i},a_{i})\in B_{h-1}\}
. Note that
|\bar{B}_{h}|\leq|\mathcal{A}|\cdot|B_{h-1}|
. Next, we set
B_{h}\subset\bar{B}_{h}
as any maximal subset of independent vectors of
\bar{B}_{h}
. Note here
|B_{h}|\leq d
. Moreover, since
\left\|\psi(s,a)\right\|_{2}\leq 1
by assumption, any
\psi(s,a)\in\bar{B}_{h}
can then be written as
\sum_{i=1}^{|B_{h}|}\alpha_{i}\cdot\psi(s_{i},a_{i})
satisfying
\left\|\alpha\right\|_{2}\leq\sqrt{d}
where
\psi(s_{i},a_{i})
are the base vectors in
B_{h}
.

We claim that for any
h\in[\sqrt{H}]
, we can learn
Q^{*}
on the basis
B_{h}
to accuracy
(2d)^{-h}\epsilon
using at most
O\left(\exp(\sqrt{H}\cdot\log d)\cdot\epsilon^{-2}\right)
time.
We show this via induction on
h
.
Notice that for any state
s
on the last level (which are
1
step from termination) and action
a\in\mathcal{A}
, the function
Q^{*}(s,a)
is simply the expected reward
\mathbb{E}\left[R(s,a)\right]
since the MDP terminates immediately afterwards. Hence, we can follow the same trajectory and sample from
R(s,a)
for multiple times and compute an empirical mean
\bar{R}(s,a)
. Suppose we take
C\cdot\varepsilon^{-2}\log(H\cdot|B_{H}|/\delta)\cdot(2d)^{\sqrt{H}}
samples from
R(s,a)
for a sufficiently large constant
C
. It then follows from standard concentration inequalities that

\lvert\bar{R}(s,a)-\mathbb{E}[R(s,a)]\rvert\leq(2d)^{-\sqrt{H}}\epsilon
with probability at least
1-\delta/\left(H\cdot|B_{H}|\right)
.
By the union bound, this holds for all
\phi(s,a)\in B_{H}
with probability at least
1-\delta/H
.
Therefore, for all
\phi(s,a)\in B_{\sqrt{H}}
, we can compute an estimator for for
Q^{*}(s,a)
with accuracy
(2d)^{-\sqrt{H}}
in time at most

\left(C\cdot\varepsilon^{-2}\log(H\cdot|B_{H}|/\delta)\cdot(2d)^{\sqrt{H}}\right)\cdot|B_{H}|\cdot\textrm{poly}(d,H)\leq\exp\left(c\cdot\sqrt{H}\cdot\log d\right)\epsilon^{-2}\log(1/\delta)

for some large enough constant
c
.

Assume we have already learned
Q^{*}
on the basis
B_{h}
to accuracy
d^{-h}\epsilon
.
We will see how we can use the information to estimate
Q^{*}
on the basis
B_{h-1}
to accuracy
d^{-h+1}\epsilon
.
Still, consider a single state-action pair
(s,a)
such that
\phi(s,a)\in B_{h-1}
.
Let
\mathcal{R}_{s,a,\sqrt{H}}
be the set of states reachable from
s
within
\sqrt{H}
many steps condition on that the first step is
a
(notice that
\mathcal{R}_{s,a,\sqrt{H}}
is a subset of

\bar{B}_{h}
by our construction). In other words, each state
s^{\prime}
in
\mathcal{R}_{s,a,\sqrt{H}}
is a state in the
(h\cdot\sqrt{H})
-th level such that there is a trajectory going from
s
to
s^{\prime}
beginning with the action
a
.
We will without loss of generality assume that each state
s^{\prime}
has a unique trajectory starting from
s
: If there are two different trajectories leading to the same state
s^{\prime}
, we can create two copies of
s^{\prime}
and index them by the unique trajectory that leads to them.

We know there must exist some state
s^{*}\in\mathcal{R}_{s,a,\sqrt{H}}
and
a^{*}\in\mathcal{A}
such that
Q^{*}(s,a)
is equal to the sum of the expected rewards collected from the trajectory from
s
to
s^{*}
and
Q(s^{*},a^{*})
.
We will denote by
\kappa(s,s^{\prime})
the expected reward collected from the path going from
s
to
s^{\prime}
for
s^{\prime}\in\mathcal{R}_{s,a,\sqrt{H}}
.
Our goal is then to compute
(i) an estimation for each
\kappa(s,s^{\prime})
where
s^{\prime}\in\mathcal{R}_{s,a,\sqrt{H}}

and (ii) an estimation for each
Q^{*}(s^{\prime},a^{\prime})
where
s^{\prime}\in\mathcal{R}_{s,a,\sqrt{H}}
and
a^{\prime}\in A
.
It is easy to see if we can compute both (i) and (ii) up to accuracy
d^{-h+1}\cdot 2^{-h}
, we can then take the optimal combination of
s^{\prime},a^{\prime}
to get an estimation of
Q^{*}(s,a)
up to accuracy
(2d)^{-h+1}
.

To get an estimation of
\kappa(s,s^{\prime})
, the expected reward collected from a trajectory, we can just visit the trajectory for multiple times. Since
\kappa(s,s^{\prime})\leq\sqrt{H}
, it then follow from standard concentration that if we visit the trajectory for

C\cdot H\cdot\varepsilon^{-2}\log(H\cdot|\mathcal{R}_{s,a,\sqrt{H}}|/\delta)\cdot(2d)^{h}

many times where
C
is a sufficiently large constant, then we can estimate all
\kappa(s,s^{\prime})
up to the desired accuracy
with high probability.
There are at most
|\mathcal{A}|^{\sqrt{H}}=\exp(\log|\mathcal{A}|\cdot\sqrt{H})
many states in
\mathcal{R}_{s,a,\sqrt{H}}
. Since we visit a trajectory

C\cdot H\cdot\varepsilon^{-2}\log(H\cdot|\mathcal{R}_{s,a,\sqrt{H}}|/\delta)\cdot(2d)^{h}
times, estimating each
\kappa(s,s^{\prime})
takes time at most

\displaystyle\exp(\log|\mathcal{A}|\cdot\sqrt{H})\cdot\left(C\cdot H\cdot\varepsilon^{-2}\log(H\cdot|\mathcal{R}_{s,a,\sqrt{H}}|/\delta)\cdot(2d)^{h}\right)\cdot\textrm{poly}(d,H)

\displaystyle\leq\exp\left(c\cdot\sqrt{H}\cdot\log d\right)\epsilon^{-2}\log(1/\delta)

for some sufficiently large constant
c
.

To get an estimation of
Q^{*}(s^{\prime},a^{\prime})
where
s^{\prime}\in\mathcal{R}_{s,a,\sqrt{H}}
and
a^{\prime}\in A
, we will take advantage of the fact that we already have estimations of
Q^{*}
on the basis in
B_{h}
.
In particular, we can express
\psi(s^{\prime},a^{\prime})=\sum_{i=1}^{|B_{h}|}\alpha_{i}\cdot\psi(s_{i},a_{i})
for
\psi(s_{i},a_{i})
being the basis in
B_{h}
. By linearity, we then have

\displaystyle Q^{*}(s^{\prime},a^{\prime})=\sum_{i=1}^{|B_{h}|}\alpha_{i}\cdot Q^{*}(s_{i},a_{i}).

(16)

On one hand, we have
\left\|\alpha\right\|_{2}\leq\sqrt{d}
.
On the other hand, by the inductive hypothesis, we have an estimation
of each
Q^{*}(s_{i},a_{i})
up to accuracy
(2d)^{-h}\cdot\epsilon
.
If we simply plugin our estimation for
Q^{*}(s_{i},a_{i})
into Equation (
16
) to compute our estimation for
Q^{*}(s^{\prime},a^{\prime})
, we then have the error is at most

d\cdot(2d)^{-h}\cdot\epsilon\leq 2^{-h}\cdot d^{-h+1}\cdot\epsilon
by the Cauchy Schwarz’s Inequality, which is the desired bound. Computing the estimation for one
Q^{*}(s^{\prime},a^{\prime})
takes
\textrm{poly}(d)
time. Since there are at most
\exp(\log|\mathcal{A}|\cdot\sqrt{H})\cdot|\mathcal{A}|
many pairs of
(s^{\prime},a^{\prime})
, this part takes time at most
\exp\left(c\cdot\left(\sqrt{H}+\log d\right)\right)
for some sufficiently large constant
c
.

By induction, this then gives us a way to approximate
Q^{*}
on
B_{0}=\{\phi(s_{0},a):a\in A\}
up to accuracy
\epsilon
with high probability. Moreover, the entire process runs in time
\exp\left(c\cdot\sqrt{H}\cdot\log d\right)\epsilon^{-2}\log(1/\delta)
for some sufficiently large constant
c
.

∎
