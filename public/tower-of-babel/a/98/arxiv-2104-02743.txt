Approximate Robust NMPC using Reinforcement Learning
Hossein Nejatbakhsh Esfahani, Arash Bahari Kordabad, Sébastien Gros

Abstract
We present a Reinforcement Learning-based Robust Nonlinear Model Predictive Control (RL-RNMPC) framework for controlling nonlinear systems in the presence of disturbances and uncertainties. An approximate Robust Nonlinear Model Predictive Control (RNMPC) of low computational complexity is used in which the state trajectory uncertainty is modelled via ellipsoids. Reinforcement Learning is then used in order to handle the ellipsoidal approximation and improve the closed-loop performance of the scheme by adjusting the MPC parameters generating the ellipsoids. The approach is tested on a simulated Wheeled Mobile Robot (WMR) tracking a desired trajectory while avoiding static obstacles.

Reinforcement Learning (RL) is a powerful tool for tackling Markov Decision Processes (MDP) without depending on a model of the probability distributions underlying the state transitions of the real system

As a result, MPC delivers a reasonable but suboptimal approximation of the optimal policy. Choosing the MPC parameters that maximises the closed-loop performance for the selected MPC formulation is a difficult problem. II
Ellipsoidal-based Robust NMPC

We consider a model based on the nonlinear dynamics

\displaystyle\boldsymbol{\mathrm{x}}_{+}=\boldsymbol{\mathrm{f}}\left(\boldsymbol{\mathrm{x}},\boldsymbol{\mathrm{u}},\boldsymbol{\mathrm{d}}\right)

(1)

where
\boldsymbol{\mathrm{d}}
is a stochastic variables affecting the state evolution. We assume that the real system is unknown and imperfectly represented by (
1
). A nominal NMPC scheme based on (
1
) reads e.g. as:

\displaystyle\min_{\bar{\boldsymbol{\mathrm{x}}},\bar{\boldsymbol{\mathrm{u}}}}

\displaystyle\quad T\left(\bar{\boldsymbol{\mathrm{x}}}_{N}\right)+\sum_{k=0}^{N-1}L\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)

(2a)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\bar{\boldsymbol{\mathrm{x}}}_{k+1}=\boldsymbol{\mathrm{f}}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k},\boldsymbol{\mathrm{d}}_{k}\right),\quad\boldsymbol{\mathrm{x}}_{0}=\boldsymbol{\mathrm{s}}

(2b)

\displaystyle\quad\boldsymbol{\mathrm{h}}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)\leq 0,\quad\boldsymbol{\mathrm{h}}_{\mathrm{f}}\left(\bar{\boldsymbol{\mathrm{x}}}_{N}\right)\leq 0

(2c)

where
L\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)
and
T\left(\bar{\boldsymbol{\mathrm{x}}}_{N}\right)
are the stage and terminal costs, respectively.
\boldsymbol{\mathrm{s}}
is the current system state while the nominal NMPC predicted trajectories are
\bar{\boldsymbol{\mathrm{x}}}
and
\bar{\boldsymbol{\mathrm{u}}}
. We label
\boldsymbol{\mathrm{h}}
and
\boldsymbol{\mathrm{h}}_{f}
as the nominal stage and terminal inequality constraints, respectively. We will model the model error and real system stochasticity via the uncertain sequence
{\boldsymbol{\mathrm{d}}}_{k}
of disturbances, and we will approximate its effect on the state dynamics in a computationally effective way. More specifically, we will model the sequence
{\boldsymbol{\mathrm{d}}}_{k}
via an i.i.d Gaussian model with mean
\bar{\boldsymbol{\mathrm{d}}}_{k}
and covariance
\Lambda
i.e.

\displaystyle\boldsymbol{\mathrm{d}}_{k}\sim\mathcal{N}\left(\bar{\boldsymbol{\mathrm{d}}}_{k},\Lambda\right)

(3)

The first-order deviation of the model state
\boldsymbol{\mathrm{x}}_{k}
from its nominal trajectory
\bar{\boldsymbol{\mathrm{x}}}_{k}
is then given by:

\displaystyle\Delta\boldsymbol{\mathrm{x}}_{k+1}=

\displaystyle\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{x}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}\Delta\boldsymbol{\mathrm{x}}_{k}+\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{u}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}\Delta\boldsymbol{\mathrm{u}}_{k}

(4)

\displaystyle\qquad+\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{d}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}\Delta\boldsymbol{\mathrm{d}}_{k}

where
\Delta\boldsymbol{\mathrm{x}}_{0}
is a given deviation of the initial state and
\Delta\boldsymbol{\mathrm{d}}_{k}=\boldsymbol{\mathrm{d}}_{k}-\bar{\boldsymbol{\mathrm{d}}}_{k}
. We observe that for
\mathbb{E}\left[\Delta\boldsymbol{\mathrm{x}}_{0}\right]=0
,
\bar{\boldsymbol{\mathrm{d}}}_{k}=\mathbb{E}\left[\boldsymbol{\mathrm{d}}_{k}\right]
and
\boldsymbol{\mathrm{\Delta}}\boldsymbol{\mathrm{u}}_{k}=0
. The expected value of the state deviation is
\mathbb{E}\left[\Delta\boldsymbol{\mathrm{x}}_{k}\right]=0
. We consider a linear feedback over the state deviations for the input deviation
\Delta\boldsymbol{\mathrm{u}}_{k}
as:

\displaystyle\Delta\boldsymbol{\mathrm{u}}_{k}=-K_{k}\Delta\boldsymbol{\mathrm{x}}_{k}

(5)

where
K_{k}
is a control gain matrix typically based on Linear Quadratic Regulator (LQR) techniques.
Then the state deviation dynamics read as:

\displaystyle\Delta\boldsymbol{\mathrm{x}}_{k+1}=

\displaystyle\left.\left(\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{x}}}-\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{u}}}K_{k}\right)\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}\Delta\boldsymbol{\mathrm{x}}_{k}+\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{d}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}\Delta\boldsymbol{\mathrm{d}}_{k}

Let us define the time-varying matrices as follows:

\displaystyle A_{k}=\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{x}}}-K_{k}\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{u}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}},\quad B_{k}=\left.\frac{\partial\boldsymbol{\mathrm{f}}}{\partial\boldsymbol{\mathrm{d}}}\right|_{\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k}}

Then, the covariance of the state deviation reads as:

\displaystyle\Sigma_{k+1}

\displaystyle=\mathbb{E}\left[\Delta\boldsymbol{\mathrm{x}}_{k+1}\Delta\boldsymbol{\mathrm{x}}_{k+1}^{\top}\right]

\displaystyle=\mathbb{E}\left[\left(A_{k}\Delta\boldsymbol{\mathrm{x}}_{k}+B_{k}\Delta\boldsymbol{\mathrm{d}}_{k}\right)\left(A_{k}\Delta\boldsymbol{\mathrm{x}}_{k}+B_{k}\Delta\boldsymbol{\mathrm{d}}_{k}\right)^{\top}\right]

\displaystyle=\mathbb{E}\left[A_{k}\Delta\boldsymbol{\mathrm{x}}_{k}\Delta\boldsymbol{\mathrm{x}}_{k}^{\top}A_{k}^{\top}+B_{k}\Delta\boldsymbol{\mathrm{d}}_{k}\Delta\boldsymbol{\mathrm{d}}_{k}^{\top}B_{k}^{\top}\right]

\displaystyle=A_{k}\Sigma_{k}A_{k}^{\top}+B_{k}\Lambda B_{k}^{\top}

where
\Lambda
is the covariance of the process noise. We observe that the matrices
\Sigma_{k}
describe ellipsoids of state uncertainty propagations defined by the confidence regions:

\displaystyle R_{k}:=\left\{\,\Delta\boldsymbol{\mathrm{x}}_{k}\,\left|\,\frac{1}{2}\Delta\boldsymbol{\mathrm{x}}_{k}^{\top}\Sigma_{k}^{-1}\Delta\boldsymbol{\mathrm{x}}_{k}\leq\sigma_{k}\right.\right\}

(6)

where
\sigma_{k}
is a Mahalanobis distance (the radius of the ellipsoids as the confidence regions). More specifically, we observe that for a Gaussian disturbance
\boldsymbol{\mathrm{d}}_{k}
as in (
3
) with
n
-dimensional mean vector
\bar{\boldsymbol{\mathrm{d}}}_{k}
, the state deviation approximation
\Delta x_{k}
is also Gaussian, given by the following density:

\displaystyle\rho\left(\Delta x_{k}\right)=\left(2\pi\right)^{-\frac{n}{2}}\left(\mathrm{det}\left(\Sigma_{k}\right)\right)^{-\frac{1}{2}}e^{-\frac{1}{2}\Delta\boldsymbol{\mathrm{x}}_{k}^{\top}\Sigma_{k}^{-1}\Delta\boldsymbol{\mathrm{x}}_{k}}

(7)

such that at time
k
, a state deviations
\Delta x_{k}
has a probability density larger or equal to
\left(2\pi\right)^{-\frac{n}{2}}\left(\mathrm{det}\left(\Sigma_{k}\right)\right)^{-\frac{1}{2}}e^{-\sigma_{k}}
to belong to
R_{k}
in (
6
).

The probability of the state deviation to belong to the ellipsoid described by (
6
) is given by:

\displaystyle\mathbb{P}[\Delta x_{k}\in R_{k}]=\int_{R_{k}}\rho\left(\Delta x_{k}\right)\mathrm{d}\Delta x_{k}=\frac{\gamma_{k}\left(\frac{n}{2},\frac{\sigma^{2}_{k}}{2}\right)}{\Gamma_{k}\left(\frac{n}{2}\right)}

(8)

where,
\Gamma_{k}
is the Gamma function and
\gamma_{k}
is the lower incomplete Gamma function describing the probability content for a n-dimensional multinormal distribution
[
21
]
.
Imposing that the ellipsoids described by (
6
) are contained within the MPC feasible set for some sequence
\sigma_{k}
then becomes a way to approximately satisfy the MPC constraints with probability (
8
). In the next section, we detail how to build an inexpensive Robust MPC scheme that ensures the ellipsoids described by (
6
) are contained within the MPC feasible set.

II-A

Inclusion constraint

Consider the constraint

\displaystyle\boldsymbol{\mathrm{h}}_{i}\left({\boldsymbol{\mathrm{x}}}_{k},{\boldsymbol{\mathrm{u}}}_{k}\right)\leq 0

(9)

for some index
i
and suppose that we want to formulate a computationally tractable constraint requiring that (
9
) is satisfied for all state deviations in the ellipsoid (
6
). For nonlinear constraints, this is unfortunately very difficult. As a result, in line with the philosophy above, we will consider the approximation resulting from linearizing the constraint on the nominal trajectory
\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}
of the MPC scheme. More specifically, we will consider imposing the constraint:

\displaystyle\boldsymbol{\mathrm{h}}_{i}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)+

\displaystyle\left.\left(\frac{\partial\boldsymbol{\mathrm{h}}_{i}}{\partial\boldsymbol{\mathrm{x}}}-\frac{\partial\boldsymbol{\mathrm{h}}_{i}}{\partial\boldsymbol{\mathrm{u}}}K_{k}\right)\right|_{\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}}\Delta\boldsymbol{\mathrm{x}}_{k}\leq 0,

(10)

\displaystyle\forall\,\Delta\boldsymbol{\mathrm{x}}_{k}\in R_{k}

Fortunately, this requirement takes a closed form. Indeed, we can simply seek the
\Delta\boldsymbol{\mathrm{x}}_{k}\in\eqref{eq:Ellipsoid}
that gives the worst (highest) value to
\boldsymbol{\mathrm{h}}_{i}
. Let us label

\displaystyle\boldsymbol{\mathrm{b}}_{i}=\left(\frac{\partial\boldsymbol{\mathrm{h}}_{i}}{\partial\boldsymbol{\mathrm{x}}}-\frac{\partial\boldsymbol{\mathrm{h}}_{i}}{\partial\boldsymbol{\mathrm{u}}}K_{k}\right)^{\top}

Then (
10
) can be (tightly) enforced by imposing that:

\displaystyle\boldsymbol{\mathrm{h}}_{i}+\sqrt{2\sigma_{k}}\left(\boldsymbol{\mathrm{b}}_{i}^{\top}\Sigma_{k}\boldsymbol{\mathrm{b}}_{i}\right)^{\frac{1}{2}}\leq 0

(11)

which is a constraint mixing
\boldsymbol{\mathrm{h}}
and its derivative, the dynamics of
\Sigma_{k}
and the given
\sigma_{k}
.

II-B

Robust MPC formulation

We can now formulate an approximate robust NMPC scheme:

\displaystyle V_{\theta}(\boldsymbol{\mathrm{s}})=

\displaystyle\min_{\bar{\boldsymbol{\mathrm{x}}},\bar{\boldsymbol{\mathrm{u}}},\boldsymbol{\mathrm{\zeta}},\Sigma}\quad\gamma^{N}\left(T_{\theta}\left(\bar{\boldsymbol{\mathrm{x}}}_{N}\right)+\boldsymbol{\mathrm{w}}_{f}^{\top}\boldsymbol{\mathrm{\zeta}}_{N}\right)

\displaystyle+\sum_{k=0}^{N-1}\gamma^{k}\left(l_{\theta}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)+\boldsymbol{\mathrm{w}}^{\top}\boldsymbol{\mathrm{\zeta}}_{k}\right)

(12a)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\bar{\boldsymbol{\mathrm{x}}}_{k+1}=\boldsymbol{\mathrm{f}}_{\theta}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k},\boldsymbol{\mathrm{d}}_{k}\right),\quad\bar{\boldsymbol{\mathrm{x}}}_{0}=\boldsymbol{\mathrm{s}}

(12b)

\displaystyle\quad\Sigma_{k+1}=A_{k}\Sigma_{k}A_{k}^{\top}+B_{k}\Lambda B_{k}^{\top},\quad\Sigma_{0}=S_{0}

(12c)

\displaystyle\quad\boldsymbol{\mathrm{h}}_{i}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)+\sqrt{2\sigma_{k}}\left.\left(\boldsymbol{\mathrm{b}}_{i}^{\top}\Sigma_{k}\boldsymbol{\mathrm{b}}_{i}\right)^{\frac{1}{2}}\right|_{\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}}\leq\boldsymbol{\mathrm{\zeta}}_{k}

(12d)

\displaystyle\quad\boldsymbol{\mathrm{h}}_{i}^{\mathrm{f}}\left(\bar{\boldsymbol{\mathrm{x}}}_{N}\right)+\sqrt{2\sigma_{N}}\left.\left(\boldsymbol{\mathrm{b}}_{i}^{\top}\Sigma_{N}\boldsymbol{\mathrm{b}}_{i}\right)^{\frac{1}{2}}\right|_{\bar{\boldsymbol{\mathrm{x}}}_{N}}\leq\boldsymbol{\mathrm{\zeta}}_{N}

(12e)

\displaystyle\quad\boldsymbol{\mathrm{\zeta}}_{0,\ldots,N}\geq 0

(12f)

where,
0<\gamma\leq 1
is a discount factor and
T_{\theta}
is an adjustable terminal cost function. The slack variables and initial guess for the covariance matrix of the state deviation are labeled by
\boldsymbol{\mathrm{\zeta}}
and
S_{0}
, respectively. Although we initialize
S_{0}
at zero in this paper, One can use an observer scheme to estimate this initial matrix.
The adjustable stage cost function in the above RNMPC scheme is defined as follows:

\displaystyle l_{\theta}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)=L\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k}\right)+\varphi_{\theta}\left(\bar{\boldsymbol{\mathrm{x}}}_{k},\bar{\boldsymbol{\mathrm{u}}}_{k},\Sigma_{k}\right),

(13)

of the RNMPC scheme. This term is considered to deliver the impact of the uncertainty on the adopted stage cost. We propose to use a quadratic form for this term, which includes the adjustable matrix
M
as an RL parameter.
\boldsymbol{\mathrm{f}}_{\theta}
is the nonlinear dynamics, which could be adjusted by RL through the model bias parameters. Because the robust NMPC scheme (
12

\ell_{1}

12f

\boldsymbol{\mathrm{w}},\boldsymbol{\mathrm{w}}_{f}
are chosen large enough, then the solution of the RNMPC scheme (

III
RL-based Robust NMPC

In this section, we propose to use RL to tune the approximate robust NMPC scheme. Indeed, the proposed robust NMPC scheme is based on coarse approximations of the state uncertainty propagation, which are likely to yield suboptimality and even constraints violations in practice. Finding the parameters that yield the best closed-loop performance for the real system in terms of cost and constraints violations is a difficult problem. We propose to use RL to find these parameters. More specifically, RL is used to tune the sequences of
\sigma_{k}
and the expected value of the noise
\bar{\boldsymbol{\mathrm{d}}}_{k}
, the process noise
\Lambda
and the matrix
M
in the cost modification
\varphi_{\theta}
in order to improve the Robust NMPC scheme. RL allows one to perform this tuning based on observed state transition, and without any knowledge of the real system stochasticity.

In this section, we first present the algorithmic details needed to implement a second order LSTDQ-learning algorithm on the ellipsoidal RNMPC scheme. Then the sensitivity analysis needed in the reinforcement learning scheme is described.

III-A

Second-Order LSTDQ Learning

LSTDQ-based reinforcement learning methods make an efficient use of data and tend to converge faster than more basic temporal-difference learning methods. Let us form the least squares of Bellman residual error w.r.t
\theta
as:

\displaystyle\min_{\theta}\mathbb{E}\left[\|Q_{\star}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}})-{Q}_{\theta}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}})\|^{2}\right]

(16)

where,
{Q}_{\theta}
obtained from the RNMPC scheme in (
15
) is an approximation of the true action-value function
Q_{\star}
.
Let us consider the following approximation of the Bellman optimality equation, which is used in the Temporal Difference (TD)-based learning approaches.

\displaystyle Q_{\star}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}})\approx L(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}})+\gamma Q_{\theta}(\boldsymbol{\mathrm{s}}_{+},\pi(\boldsymbol{\mathrm{s}}_{+}))

(17)

where,
L(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}})
is the baseline cost in the RL scheme. Substituting (
17
) into (
16
), the least square problem (
16
) for the first-order LSTDQ-learning can be solved for some data acquired from the transitions
\boldsymbol{\mathrm{s}}_{i},\boldsymbol{\mathrm{a}}_{i}\rightarrow\boldsymbol{\mathrm{s}}_{i+1}
as:

\displaystyle\mathbb{E}\left[\delta\nabla_{\theta}Q_{\theta}(\boldsymbol{\mathrm{s}}_{i},\boldsymbol{\mathrm{a}}_{i})\right]=0,

(18a)

\displaystyle\delta=L(\boldsymbol{\mathrm{s}}_{i},\boldsymbol{\mathrm{a}}_{i})+\gamma V_{\theta}(\boldsymbol{\mathrm{s}}_{i+1})-Q_{\theta}(\boldsymbol{\mathrm{s}}_{i},\boldsymbol{\mathrm{a}}_{i})

(18b)

where,
\delta
is the temporal difference error. Both value and action-value functions, respectively,
V_{\theta}(\boldsymbol{\mathrm{s}}_{i+1})=Q_{\theta}(\boldsymbol{\mathrm{s}}_{i+1},\pi(\boldsymbol{\mathrm{s}}_{i+1}))
and
Q_{\theta}(\boldsymbol{\mathrm{s}}_{i},\boldsymbol{\mathrm{a}}_{i})
are obtained from the RNMPC schemes detailed in the last section. In this paper, we adopt a Newton method to solve (
18
) and extract the newton step for the second-order LSTDQ scheme as follows:

\displaystyle\theta\leftarrow\theta-\alpha A^{-1}b,

(19a)

\displaystyle A=\mathbb{E}\left[\delta\nabla^{2}_{\theta}Q_{\theta}+\nabla_{\theta}Q_{\theta}\nabla_{\theta}^{\top}\delta\right],\quad b=\mathbb{E}\left[\delta\frac{\partial Q_{\theta}}{\partial\theta}\right]

(19b)

where, the scalar
\alpha>0
is the step size.

III-B

Sensitivity Analysis

The gradient and Hessian of the function
Q_{\theta}
needed in (
19
) require one to compute the sensitivities of the optimal value of NLP (
15
).
Let us define the Lagrange function
\mathcal{L}_{\theta}
associated to the RNMPC problem (
15
) as follows:

\displaystyle\mathcal{L}_{\theta}=\Phi_{\theta}+\boldsymbol{\mathrm{\lambda}}^{\top}G_{\theta}+\boldsymbol{\mathrm{\mu}}^{\top}H_{\theta}

(20)

where
H_{\theta}
gathers the inequality constraints of (
15
) and
\Phi_{\theta}
is the cost of the RNMPC optimization problem. Variable
\boldsymbol{\mathrm{\lambda}}
is the Lagrange multiplier vector associated to the equality constraints
G_{\theta}
of the RNMPC. Variable
\boldsymbol{\mathrm{\mu}}
is the Lagrange multiplier vector associated to the inequality constraints of the RNMPC scheme. Let us label the primal variables for the RNMPC scheme as
\boldsymbol{\mathrm{p}}=\left\{\boldsymbol{\mathrm{X}},\boldsymbol{\mathrm{U}}\right\}
, where
\boldsymbol{\mathrm{X}},\boldsymbol{\mathrm{U}}
are the state and control input trajectories predicted by (
15
). Then, the primal-dual variables read as
\boldsymbol{\mathrm{z}}=\left\{\boldsymbol{\mathrm{p}},\boldsymbol{\mathrm{\lambda}},\boldsymbol{\mathrm{\mu}}\right\}
.

The sensitivity analysis of optimization problems detailed in
[
22
]
delivers the Gradient
\nabla_{\theta}Q_{\theta}
and Hessian
\nabla^{2}_{\theta}Q_{\theta}
(
H(Q_{\theta})
) terms needed in (
19
) as follows:

\displaystyle\frac{\partial Q_{\theta}}{\partial\theta}=\frac{\partial\mathcal{L}_{\theta}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}},\boldsymbol{\mathrm{z}}^{\star})}{\partial\theta},

(21a)

\displaystyle H(Q_{\theta})=\frac{D}{D\theta}\left(\frac{\partial\mathcal{L}_{\theta}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}},\boldsymbol{\mathrm{z}}^{\star})}{\partial\theta}\right)\approx\frac{\partial^{2}\mathcal{L}_{\theta}(\boldsymbol{\mathrm{s}},\boldsymbol{\mathrm{a}},\boldsymbol{\mathrm{z}}^{\star})}{\partial\theta^{2}}

(21b)

where
\boldsymbol{\mathrm{z}}^{\star}
is the primal-dual solution of (
15
) and
D
is the total derivative. The Hessian term
H(Q_{\theta})
can improve the search direction using the curvature information and thus make more progress per step in comparison with the
first-order LSTDQ learning relying only on the gradient calculation.

III-C

Constrained RL steps

In the proposed RL-RNMPC scheme, there is a matrix
\Lambda
in the dynamics (
12c
), which is adjusted using the reinforcement learning method. As a requirement, this disturbance covariance matrix must be positive semidefinite. However, the RL steps delivered by second-order LSTDQ learning do not necessarily respect this requirement, and we need to enforce it via constraints on the RL steps throughout the learning process. To address this requirement, we formulate a Semi-Definite Program (SDP) as a least squares optimization problem:

\displaystyle\min_{\Delta\theta}

\displaystyle\quad\frac{1}{2}\left\|\Delta\theta\right\|^{2}-F^{\top}\Delta\theta

(22a)

\displaystyle\mathrm{s.t.}

\displaystyle\quad\Lambda({\theta+\Delta\theta})\geq 0

(22b)

where we assume that the above matrix is linear function of
\theta
and the gradient term
F=-\alpha A^{-1}b
is delivered by the second-order LSTDQ-learning algorithm (
19
).

IV
Numerical Example

To illustrate proposed RL-RNMPC, we consider a simulated Wheeled Mobile Robot (WMR) tracking trajectories while avoiding static obstacles avoidance, and affected by model uncertainties and disturbances. Let us define the WMR model as:

\displaystyle\boldsymbol{\mathrm{f}}(\boldsymbol{\mathrm{x}},\boldsymbol{\mathrm{u}})=\begin{bmatrix}\cos(\psi)&0\\
\sin(\psi)&0\\
0&1\end{bmatrix}\boldsymbol{\mathrm{u}}

(23)

where
\boldsymbol{\mathrm{x}}=\left[x,y,\psi\right]^{\top}
and
\boldsymbol{\mathrm{u}}=\left[v,\omega\right]^{\top}
are the state and control input vectors, respectively. The position coordinates of the WMR are labeled
x,y
and
\psi
is the robot orientation angle. The initial position of the mobile robot is
\boldsymbol{\mathrm{x}}_{0}=\left[-1,2,0\right]^{\top}
. The control inputs
v
and
\omega
are the linear and angular velocities, respectively. To discretize the above continuous model, we adopt a fourth-order Runge-Kutta (RK4) integrator providing discretized function
\boldsymbol{\mathrm{f}}_{d}
of the WMR model. We will consider that the real system evolves according to the dynamics:

\displaystyle\boldsymbol{\mathrm{x}}(k+1)=\boldsymbol{\mathrm{f}}_{d}\left(\boldsymbol{\mathrm{x}}(k),\boldsymbol{\mathrm{u}}(k)+\boldsymbol{\mathrm{\Gamma}}_{1}(k)\right)+\boldsymbol{\mathrm{\Gamma}}_{2}(k)

(24)

where the two variables
\boldsymbol{\mathrm{\Gamma}}_{1},\boldsymbol{\mathrm{\Gamma}}_{2}
in the above equations model the uncertainties as:

\displaystyle\boldsymbol{\mathrm{\Gamma}}_{1}(k)=v(k)\begin{bmatrix}d_{1}(k)\\
d_{2}(k)\\
\end{bmatrix},\quad\boldsymbol{\mathrm{\Gamma}}_{2}(k)=T_{s}v(k)\begin{bmatrix}0\\
0\\
d_{2}(k)\end{bmatrix}

(25)

where
d_{1}(k)\sim\mathcal{N}\left(0,\Sigma_{1}^{2}\right)
and
d_{2}(k)\sim\mathcal{N}\left(0,\Sigma_{2}^{2}\right)
. The sampling time is
T_{s}
= 0.2
s
and disturbance variances
\Sigma_{1}
and
\Sigma_{2}
are set as 0.2 and 0.4, respectively. We initialize the adjustable process noise covariance matrix (
3\times 3
) as
\Lambda=diag(\Sigma_{1}^{2},\Sigma_{2}^{2},\Sigma_{2}^{2})
. The expected value of the process noise
\bar{d}
and the matrix
M
as an RL parameter in the cost modification term
\varphi_{\theta}
are initialized at zero. According to (
8
), the probability of the uncertainties in the ellipsoids can be obtained from the Gamma functions. Since the simulated mobile robot has three states, there is a 3-dimensional multinormal distribution
n=3
. To ensure a large enough probability of the uncertainty propagation in the ellipsoids (confidence regions), we set
\sigma_{k}=2.65
. Therefore, with pair
n=3,\quad\sigma_{k}=2.65
we will have the probability of the state deviations to belong to the ellipsoids
\mathbb{P}[\Delta x_{k}\in R_{k}]\approx 93\%
.

The RMPC model will be based on the real system dynamics, assuming that we know them perfectly. More specifically, the nominal model used in the RNMPC scheme is based on the expected value of the exact distribution of the disturbances
d_{1},d_{2}
, and the structure according to which the disturbances enter the system is assumed known. We further observe that by assuming the disturbances are Gaussian, we are considering an ideal setup for the approximate robust MPC to perform well. Hence any gain of performance achieved by RL in this simulation setup is done through handling the approximations introduced in the robust MPC scheme. As it is proposed to adopt the RL approach in order to adjust the RNMPC parameters, we formulate a second-order LSTDQ scheme with a batch size equal to 100 data samples and let RL to update the parameters based on the collected data in the batch. In this simulation, the number of transitions (iterations) is 8000 and thus the number of RL steps is 80. The step size is set as
\alpha=10^{-6}
. We adopt a baseline stage cost used in the LSTDQ scheme as:

\displaystyle L(\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k})=l(\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k})+\boldsymbol{\mathrm{w}}^{\top}\max(0,\boldsymbol{\mathrm{h}}(\boldsymbol{\mathrm{x}}_{k}))

(26)

where
l(\boldsymbol{\mathrm{x}}_{k},\boldsymbol{\mathrm{u}}_{k})
can be expressed as a quadratic function of the state and action deviations from their desired values. The second term in the above baseline is considered to cope with the violations, where
\boldsymbol{\mathrm{h}}\geq 0
is pure inequality vector of constraints induced by the obstacles. The penalty weights are
\boldsymbol{\mathrm{w}}=[30,30,30]
.

The obstacles are represented as ellipsoids (see Fig.
1
). The reference trajectory shown in Fig.
1
is an eight-shaped path, which intersects the obstacles or comes very close to them.

In Fig.

V
Conclusion

In the context of the Robust Nonlinear Model Predictive Control (RNMPC), the formal RNMPC techniques are difficult to implement on nonlinear systems, and thus it is common to use approximate RNMPC methods instead. In this paper we proposed to describe the propagation of the uncertainties using the ellipsoidal tubes in which the disturbances and state deviations are modeled as a Gaussian noise. However, the approximated models and constraints used in this kind of RNMPC can affect the closed-loop performance and thus we adopted an LSTDQ learning as a fast RL algorithm to adjust some crucial parameters of the approximate RNMPC. In this paper, we used the proposed RNMPC as a value function approximator for the LSTDQ algorithm. AS a future work, we will propose to embed a Linear Quadratic Regulator (LQR) in the proposed RNMPC in order to deliver the first guess of the control gain matrix for the adopted linear feedback over the state deviation. Furthermore, we will investigate the proposed RL-RNMPC for a large-scale application.
