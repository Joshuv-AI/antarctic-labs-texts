On a result concerning algebraic curves passing through n n -independent nodes
H. A. Hakopian

Abstract
Let a set of nodes 𝒳 \mathcal{X} in the plane be n n -independent, i.e., each node has a fundamental polynomial of degree n . n. Assume that # ​ 𝒳 = d ⁡ ( n , n − 3 ) + 3 = ( n + 1 ) + n + ⋯ + 5 + 3 . \#\mathcal{X}=d(n,n-3)+3=(n+1)+n+\cdots+5+3. In this paper we prove that there are at most three linearly independent curves of degree less than or equal to n − 1 n-1 that pass through all the nodes of 𝒳 . \mathcal{X}. We provide a characterization of the case when there are exactly three such curves. Namely, we prove that then the set 𝒳 \mathcal{X} has a very special construction: either all its nodes belong to a curve of degree n − 2 , n-2, or all its nodes but three belong to a (maximal) curve of degree n − 3 . n-3. This result complements a result established recently by H. Kloyan, D. Voskanyan, and H. H. Note that the proofs of the two results are completely different. MSC2010: 41A05, 41A63, 14H50. Keywords : algebraic curve, maximal curve, fundamental polynomial, n n -independent nodes.

Introduction

Denote the space of all bivariate polynomials of total degree
\leq n
by

\Pi_{n}=\left\{\sum_{i+j\leq n}a_{ij}x^{i}y^{j}\right\}.

We have that

N:=N_{n}:=\dim\Pi_{n}=(1/2)(n+1)(n+2).

Denote by
\Pi

A
plane algebraic curve

\geq 1.
To simplify notation, we shall use the same letter, say
p
,

.
In particular, by

Consider a set of
s

The problem of finding a polynomial

p(x_{i},y_{i})=c_{i},\quad i=1,\ldots,s,

(1)

is called interpolation problem.

Denote by

on
\mathcal{X}.

A polynomial

is called a fundamental polynomial for a node
A\in{\mathcal{X}}

p(A)=1\ \ \text{and}\ \ p\big|_{{\mathcal{X}}\setminus\{A\}}=0.

We denote this
n
-fundamental polynomial
by
p_{A}^{\star}:=p_{A,\mathcal{X}}^{\star}.

Definition 1.1
.

The interpolation problem with a set of nodes
{\mathcal{X}}_{s}
is called
n
-poised if for any data
(c_{1},\ldots,c_{s})

there is a unique polynomial

satisfying the interpolation conditions (
1

A necessary condition of

Now, let us consider the concept of
n
-independence (see
[
1
,
3
]
).

Definition 1.2
.

A set of nodes

is called

n
-fundamental polynomials. Otherwise, it is called
n
-dependent.

Fundamental polynomials are linearly independent. Therefore a necessary condition of
n
-independence for

is

.

In this paper we consider

-independence more generally. Namely, we admit possibility

n
-independent set

a

We have that

For a node

The set

-independent means that
\mathcal{X}
is
n
-independent and the node

-fundamental polynomial

We say that a node

q:=s_{1}\ell\in\Pi_{n},
where the line
\ell
passes through
B_{1}
and does not pass through
B.
We have that
q(B_{1})=q(B_{2})=0.
In view of Assumption 2 we get that

0=D_{\bf a}^{(k)}[s_{1}\ell](B)=D^{(k)}_{\bf a}s_{1}(B)\ell(B)+kD_{\bf a}^{(k-1)}s_{1}(B)D_{\bf a}\ell(B)=D^{(k)}_{\bf a}s_{1}(B)\ell(B).

Since
\ell(B)\neq 0
we conclude that
D^{(k)}_{\bf a}s_{1}(B)=0.

Now we are in a position to show that

D^{(i)}_{\bf a}\sigma_{1}(B)=D^{(i)}_{\bf a}\sigma_{2}(B)=D^{(i)}_{\bf a}\sigma_{3}(B)=0,\ i=0,1,\ldots,k.

(6)

Let us prove say equalities with
\sigma_{1}.

Consider the polynomial

p=\sigma_{1}-c_{1}s_{1}-c_{2}s_{2},\ \hbox{where}\ c_{i}=\sigma_{1}(B_{i}).

(7)

We get readily that
p(B_{1})=p(B_{2})=0.
Hence, in view of Assumption 2, as above, we get that
p(B)=D_{\bf a}p(B)=\ldots=D^{(k)}_{\bf a}p(B)=0.
It remains to use the relations (
5
) and (
7
).

Hence except the two intersection points
B_{1},B_{2}\in\mathcal{I}:=\ell_{12}\cap,s
all other
n-3
points, counting also the multiplicities, are common for the three curves
\sigma_{1},\sigma_{2},
and
\sigma_{3}.

From this, in view of the condition
(iv)
(page 5), we conclude that the above three polynomials
\sigma_{1},\sigma_{2},
and
\sigma_{3},
have a common divisor
q\in\Pi_{n-3}:

\sigma_{1}=\beta_{1}q,\quad\sigma_{2}=\beta_{2}q,\quad\sigma_{3}=\beta_{3}q,\ \hbox{where}\ \beta_{i}\in\Pi_{2}.

Therefore we have that

\mathcal{X}\subset\sigma_{1}\cap\sigma_{2}\cap\sigma_{3}\subset q\cup[\beta_{1}\cap\beta_{2}\cap\beta_{3}].

(8)

Now consider two cases for
\mathcal{B}:=\beta_{1}\cap\beta_{2}\cap\beta_{3}:

Case (a)
,
\#\mathcal{B}\geq 4.

According to Proposition
1.6
any subset
\mathcal{A}\subset\mathcal{B}
with
\#\mathcal{A}=4
is
2
-dependent. From here we obtain readily that the points of
\mathcal{A}
are collinear. Hence all the points of
\mathcal{B}
are collinear:
\mathcal{B}\subset\ell\in\Pi_{1}.

Now we readily get that
\ell
is a common divisor of
\beta_{1},\beta_{2},
and
\beta_{3},
i.e.,

\beta_{1}=\ell_{1}\ell,\quad\beta_{2}=\ell_{2}\ell,\quad\beta_{3}=\ell_{3}\ell,

where
\ell_{i}\in\Pi_{1}.

Thus, as above, we get that

\mathcal{B}\subset\ell\cup[\ell_{1}\cap\ell_{2}\cap\ell_{3}]\subset\ell.

(9)

The last relation here we get from the fact that the polynomials
\sigma_{1},\sigma_{2},\sigma_{3},
and hence the polynomials
\ell_{1},\ell_{2}\,\ell_{3},
are linearly independent and hence
\ell_{1}\cap\ell_{2}\cap\ell_{3}=\emptyset.

Finally, we get from (
8
) and (
9
) that

\mathcal{X}\subset q\cup\ell,

or, in other words, all the nodes of
{\mathcal{X}}
lie in a curve of degree
n-2,
namely in the curve
q\ell\in\Pi_{n-2}.

Case (b)
,
\#\mathcal{B}\leq 3.

In this case we obtain from (
8
) that
all the nodes of
{\mathcal{X}}
but
\leq 3
lie in a curve
q
of degree
n-3.
From here we readily conclude that
q
is a maximal curve and exactly
3
nodes of
\mathcal{X}
are outside of it.

Thus Proposition
2.2
is proved.

Finally note that in view of Theorem
2.1
and Proposition
2.2
one can formulate the following

Theorem 3.2
.

Assume that
{\mathcal{X}}
is an
n
-independent set of
d(n,k-2)+3
nodes with
3\leq k\leq n-1.
Then at most three linearly independent curves of degree

\leq k
may pass through all the nodes of
{\mathcal{X}}.
Moreover, there are such three curves for the set
{\mathcal{X}}
if and only if all the nodes of
{\mathcal{X}}
lie in a curve of degree
k-1,
or all the nodes of
{\mathcal{X}}
but three lie in a (maximal) curve of degree
k-2.
