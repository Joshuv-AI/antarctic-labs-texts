Let us recall the main definition of the paper:

Let

For each fixed prime number

The

It has the following properties:

1)
|x|_{p}\geq 0

3.1) if

]

The completion of

-adic field which is denoted by

[

The algebraic completion of

-adic numbers

For any

and

U_{r}(a)=\{x\in\mathbb{C}_{p}:|x-a|_{p}<r\},\ \ V_{r}(a)=\{x\in\mathbb{C}_{p}:|x-a|_{p}\leq r\},

S_{r}(a)=\{x\in\mathbb{C}_{p}:|x-a|_{p}=r\}.

Dynamical systems in
\mathbb{C}_{p}
.

To define a dynamical system we consider a function
f:x\in U\to f(x)\in U

\mathbb{C}_{p}
) (see for example
[
6

For

f^{n}(x)=\underbrace{f(f(f\dots(f}_{n\,{\rm times}}(x)))\dots).

For arbitrary given

is the sequence of points

x_{0},x_{1}=f(x_{0}),x_{2}=f^{2}(x_{0}),x_{3}=f^{3}(x_{0}),\dots

(1.1)

The main problem:
Given a function
f
and initial point

what ultimately happens with the sequence (

Does the limit
\lim_{n\to\infty}x_{n}
exist? If not what is the set of limit points of the sequence?

A point

A fixed point

is called

of

such that
|f(x)-x_{0}|_{p}>|x-x_{0}|_{p}

for

,

.

Let

be a fixed point of a

The ball

(contained in

is an

The function

Consider the dynamical system associated with the function
f:\mathbb{C}_{p}\to\mathbb{C}_{p}

f(x)=\frac{a}{x^{2}},\ \ a\neq 0,\ \ a\in\mathbb{C}_{p},

(2.1)

Denote by

\theta_{1,n}=1

This function has three fixed point

in
\mathbb{C}_{p}

For these fixed points we have

x^{3}_{k}=a\ \ \Rightarrow\ \ x_{k}=\theta_{k,3}a^{1\over 3}\ \ \Rightarrow\ \ |x^{3}_{k}|_{p}=|a|_{p}\ \ \Rightarrow\ \ |x_{k}|_{p}=\alpha\equiv(|a|_{p})^{1/3}.

(2.2)

Thus
x_{k}\in S_{\alpha}(0)
,
k=1,2,3
.

We have

f^{\prime}(x)={-2a\over x^{3}}={-2\over x}\cdot f(x).

Therefore at a fixed point we get

f^{\prime}(x_{k})={-2\over x_{k}}\cdot f(x_{k})=-2.

|f^{\prime}(x_{k})|_{p}=\left\{\begin{array}[]{ll}1/2,\ \ \mbox{if}\ \ p=2\\[5.69054pt]
1,\ \ \mbox{if}\ \ p\geq 3\end{array}\right.

Hence the fixed point
x_{k}
is an attractive for
p=2
and an indifferent for
p\geq 3
. Therefore the fixed point is never repeller.

We can explicitly calculate

Lemma 1
.

For any

we have

f^{n}(x)=a^{{1\over 3}(1-(-2)^{n})}\cdot x^{(-2)^{n}},\ \ n\geq 1.

Proof.

We use induction over

.
For
n=1,2
the formula is clear. Assume it is true for
n
and show it for

f^{n+1}(x)=f^{n}(f(x))=a^{{1\over 3}(1-(-2)^{n})}\cdot(f(x))^{(-2)^{n}}

=a^{{1\over 3}(1-(-2)^{n})}\cdot({a\over x^{2}})^{(-2)^{n}}=a^{{1\over 3}(1-(-2)^{n+1})}\cdot x^{(-2)^{n+1}}.

This completes the proof.
∎

|f^{n}(x)|_{p}=\left|a^{{1\over 3}(1-(-2)^{n})}\cdot x^{(-2)^{n}}\right|_{p}=\alpha^{1-(-2)^{n}}\cdot r^{(-2)^{n}},\ \ n\geq 1.

(2.3)
