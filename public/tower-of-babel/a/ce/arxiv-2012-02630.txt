Upper and Lower Bounds for Competitive Group Testing
Robert Scheidweiler, Eberhard Triesch

Abstract
We consider competitive algorithms for adaptive group testing problems. In the first part of the paper, we develop an algorithm with competitive constant c < 1.452 c<1.452 thus improving the up to now best known algorithms with constants 1.5 + ϵ 1.5+\epsilon from 2003. In the second part, we prove the first nontrivial lower bound for competitive constants, namely that c c is always larger than 1.31 1.31 .

Introduction

Assume that we are given some finite set
S
,
|S|=n
, of
items
which can be

good
or
defective
. Our task is to identify the set
D
of defectives by
(successively) choosing subsets
W_{1},W_{2},\ldots
of
S
and testing whether
D
is disjoint from
W_{i}
or not. In choosing
W_{i}
, we may assume that the results of the first
i-1
tests are already known (
adaptive
search). We want to
minimize the number of tests needed to identify the set
D
in the worst case.

This problem is called the
adaptive group testing
problem and dates back to 1943 when Dorfman
[
1
]
in his seminal paper discussed possibilities to
reduce the number of blood tests for syphilitic antigene of American inductees.
Although group testing was not used in this context, many applications in different areas such as quality control, information theory, computer networks and clone library were found in the following years. The most complete account on
group testing can be found in
[
2
]
. The books
[
3
]
and

[
4
]
treat search problems in more generality but also cover the subject while

[
5
]
focusses on nonadaptive group testing with applications in the life sciences. In this paper, we deal with adaptive group
testing only.

Most papers on this subject considered the case that the number
d
of defectives is known in advance, the so-called
(d,n)
-group testing problem.
We write
M_{A}(d,n)
for the maximum number of tests required by a group testing algorithm
A
to identify all items and denote by
M(d,n):=\min_{A}M_{A}(d,n)
the worst case number of tests for the problem.
By general
considerations, we have the
information theoretic lower bound

M(d,n)\geq\left\lceil\log{n\choose d}\right\rceil\geq d\log\frac{n}{d},

where the base of
\log
is two throughout this paper.

There is a famous and beautiful conjecture on the so-called cutoff point for adaptive group testing due to Hu, Hwang and Wang:
If the ratio
r:=n/d
is at most
3
, it is optimal to test each item individually.

Conjecture 1.1
.

[
6
]

For
0<d<n
and
r\leq 3
,

\displaystyle M(d,n)=n-1.

The equation
M(d,n)=n-1
was proved if
r\leq\frac{21}{8}=2.625
by Du and Hwang
[
7
]
.
Leu, Lin and Weng extended this to
r\leq\frac{43}{16}=2.6875
for
d\geq 193

[
8
]

and Riccio and Colbourn to
r<\log_{\frac{3}{2}}3\approx 2.709
for sufficiently large
d

depending on
r

[
9
]
.
Wegener, Fischer and Klasner proved the conjecture if the cardinality of the test sets is
at most 2
[
10
]
. For later use, we record the result of Leu, Lin and Weng

Theorem 1.2
.

[
8
]

For
\frac{16}{43}n\leq d<n
,
d\geq 193
,

\displaystyle M(d,n)=n-1.

For
r>\frac{43}{16}
, the best group testing algorithms we know about are due to A. Allemann
[
11
]
:

Theorem 1.3
.

[
11
]

There is an algorithm which, for all
0<d\leq\frac{n}{2}
,
finds

defectives by at most

\log{n\choose d}+0.255d+\frac{1}{2}\log d+6.5

tests.

In practice, the prior knowledge of
d
is often an unrealistic assumption.
However, if nothing is known about
d
, the worst case number of tests is clearly
n
and can be realized by testing all elements
individually. Suppose the number of defectives turns out to be one. Then those
n
singleton tests are very many as compared to the
\lceil\log n\rceil

tests needed if

is known in advance. Du and Hwang thus asked for an algorithm
A
with the following property:
Algorithm
A
successfully identifies

without prior knowledge of
d
for all

. Denote by
M_{A}(d\,|\,n)
the worst case number of tests used by

if
the number of defectives turns out to be

M_{A}(d\,|\,n)/M(d,n)
should be bounded by some constant c.
More precisely:

Definition 1.4
.

[

Let

be some real number,

. Algorithm

for all

Du and Hwang gave the first competitive algorithm with

in 1993
[

]
. Several improvements were given by Bar-Noy,
Hwang, Kessler and Kutten
(c=2)
in 1994
[

, by Du, Xue, Sun and Cheng

in 1994
[

and by Schlaghoff

in 2005
[

In
[

we read the following remark:

“However, it certainly requires a new technique in order to push the competitive ratio down under

No nontrivial

3
A lower bound

To prove a lower bound for competitive constants
c
, we assume familiarity with the definition of the worst case search length as a game between two players
as developed, e.g., in
[
3
, section 1.10]
: The first player (Algy) chooses a test set
W
and the second (the Strategist, his adversary) answers
good
or
defective
.
Of course, his answers have to be consistent and his goal is to force Algy to ask as many questions as possible whereas Algy
wants to minimize that number. Moreover, we can assume that Algy’s test sets do not contain any classified elements.
The worst case number of tests is just the number of tests in the game if both players play optimally from their point of view.
In particular, if the adversary player follows some specific strategy and Algy plays optimally against this strategy, the number of tests needed is a lower bound
for the general worst case number of tests. We are going to define and analyze such a strategy
{\cal S}
.

In order to precisely define the answers of the Strategist in the
t
-th round, we have to keep track of the results of the preceding tests.
This is done by some hypergraph
H_{t}=(S_{t},E_{t})
, where
S_{t}
is the set of all items which have not been identified as good or defective after
t
tests, and
E_{t}
consists of all inclusion-minimal
sets which are known to contain a defective element after
t
tests.
H_{t}
is defined inductively as follows:

•

H_{0}:=(S,\emptyset)

•

If the hypergraph
H_{t-1}
is defined (after
t-1
tests and answers), assume that Algy chooses some test set
W,
w.l.o.g.
\emptyset\neq W\subset S_{t-1}
.

–

If the adversary answers
good
, all elements of
W
are removed from
S_{t-1}
. Furthermore, let
U
denote the set of items
x\in S_{t-1}

such that
\{x\}=Y\setminus W
for some
Y\in E_{t-1},
i.e., all vertices which lie in edges of size one after the removal of
W.
The elements of
U
are identified as
defective
and are removed from
S_{t-1}
as well. Thus

S_{t}:=S_{t-1}\setminus(U\cup W)
. Now let
E_{t}^{\prime}:=\{Y\setminus W|Y\in E_{t-1}\text{ and }Y\cap U=\emptyset\}
.
E_{t}
is defined as the set of all inclusion-minimal sets in
E_{t}^{\prime}
.

–

If the adversary answers
defective
, we distinguish two cases:
If
|W|>1
, we let
S_{t}:=S_{t-1}
and
E_{t}
consists of all inclusion-minmal sets in
E_{t-1}\cup\{W\}
.
Otherwise, if
|W|=1,
set
S_{t}:=S_{t-1}\setminus W
and
E_{t}^{\prime}:=\{Y|Y\in E_{t-1}\text{ and }Y\cap W=\emptyset\}
.
E_{t}
is defined as the set of all inclusion-minimal sets in
E_{t}^{\prime}
.

Recall that a
vertex cover
of
H_{t}
is a set
X
with
X\cap Y\neq\emptyset
for all
Y\in E_{t}
.
After
t
tests, the possible sets of defectives are just the unions of the defective elements in
S\setminus S_{t}
with the vertex covers of
H_{t}
and with elements which are not covered by any edge in
H_{t}
. For
|S_{t}|\geq 2
all sets in
E_{t}
have cardinality at least two. Hence, subsets of
S_{t}
with
|S_{t}|-1
elements are vertex covers. Therefore, the set of defectives is not determined yet.
The case
|S_{t}|=1
arises only if
E_{t}=\emptyset
. It follows that the set of defectives is determined iff
S_{t}=\emptyset
.

We can now define our strategy
{\cal S}
:

-

If a set
W
of at least two elements is tested, the answer is “defective”.

-

If a singleton is tested which is not contained in some
Y\in E_{t}
, the answer is “good”.

-

If a singleton is tested which is contained in some
Y\in E_{t}
, the answer is “defective”.

Theorem 3.1
.

If answers are given according to strategy
{\cal S}
, the following assertions hold for each group testing algorithm
A
:

i)

All elements will never be declared defective.

ii)

If the number of defectives in the game is
d
, then
A
used at least
n+d
tests.

iii)

If
A
is
c
-competitive, we have for
n\to\infty

\displaystyle c\geq\frac{M_{A}(d\,|\,n)}{M(d,n)}-o(1)\geq\min\left\{\left.\frac{n+d}{M(d,n)}\right|0\leq d<n\right\}-o(1).

Proof:

i)
Assume to the contrary that all elements are declared defective. Then the Strategist always answers
defective
. As long as
|S_{t}|\geq 2
, a new defective can only be identified if
Algy chooses a singleton as test set. Hence, for some
t
, we have
|S_{t}|=1
and
E_{t}=\emptyset
. But then the next test has to be
W=S_{t}
and the answer is
good
,
a contradiction.

ii)
It is clear that the
(n-d)
good items are identified by testing
(n-d)
singletons. If some item
x
is declared defective in the
(t+1)
-th test, the corresponding test has to be
W=\{x\}
and there has to be some prior test of a set

Y=Y(x)
such that
x\in Y\in E_{t}
. Since
Y\notin E_{t+1}
,
Y(x)\neq Y(x^{\prime})
for all other defective elements
x^{\prime}\neq x
. It follows that
A
needs at least two tests for each defective element.
The total number of tests is thus at least
2d+(n-d)=n+d
.

iii)
Obvious, by
i)
and
ii)
.
