Measurable multiresolution systems, endomorphisms, and representations of Cuntz relations
Sergey Bezuglyi and Palle E.T. Jorgensen

Abstract
. The purpose of this paper is to present new classes of function systems as part of multiresolution analyses. Our approach is representation theoretic, and it makes use of generalized multiresolution function systems (MRSs). It further entails new ideas from measurable endomorphisms-dynamics. Our results yield applications that are not amenable to more traditional techniques used on metric spaces. As the main tool in our approach, we make precise new classes of generalized MRSs which arise directly from a dynamical theory approach to the study of surjective endomorphisms on measure spaces. In particular, we give the necessary and sufficient conditions for a family of functions to define generators of Cuntz relations. We find an explicit description of the set of generalized wavelet filters. Our results are motivated in part by analyses of sub-band filters in signal/image processing. But our paper goes further, and it applies to such wider contexts as measurable dynamical systems, and complex dynamics. A unifying theme in our results is a new analysis of endomorphisms in general measure space, and its connection to multi-resolutions, to representation theory, and generalized wavelet systems.

2.3.
Radon-Nikodym derivatives and Markovian
functions

Suppose
\sigma\in End(X,\mathcal{B},\mu)
. Recall that
\mu\circ\sigma^{-1}\sim\mu

in this case. Then we can define the

Radon-Nikodym derivative

\rho_{\mu}(x):=\frac{d\mu\circ\sigma^{-1}}{d\mu}(x)
, which is a Borel
function such that

(2.5)

\int_{X}f(\sigma x)\;d\mu=\int_{X}f(x)\rho_{\mu}(x)\;d\mu,\quad f\in L^{1}(\mu).

Setting
\rho_{n}(x)=\frac{d\mu\circ\sigma^{-n}}{d\mu}(x)
,
we obtain the Radon-Nikodym
cocycle
satisfying the
equation
\rho_{n+m}(x)=\rho_{m}(\sigma^{n}(x))\rho_{n}(x)
.

Remark 2.7
.

Suppose that
\sigma\in End(X,\mathcal{B},\mu)
and
\nu
is a measure
equivalent to
\mu
, i.e., there exists a Borel function

\xi
such that
d\nu(x)=h(x)d\mu(x)
. Then
\sigma

is also non-singular with respect to
\nu
, and

\rho_{\nu}(x)=h(\sigma x)\rho_{\mu}(x)h^{-1}(x)
.

Every
\sigma\in End(X,\mathcal{B})
defines a linear operator

S_{\sigma}
called a composition operator on the space
of bounded Borel functions:

S_{\sigma}(f)=f\circ\sigma,\qquad f\in\mathcal{F}(X,\mathcal{B}).

This operator is also known by the name of a
Koopman
operator

when it is considered in a
L^{2}
space.

The map
A\mapsto\mu(\sigma(A)),A\in\mathcal{B},

defines a measure on the subalgebra
\sigma^{-1}(\mathcal{B})
. If

\mu
is a
forward quasi-invariant
measure, then
there exists a unique
\sigma^{-1}(\mathcal{B})
-measurable function

\omega_{\mu}(x)=\frac{d\mu\circ\sigma}{d\mu}(x)
such that

(2.6)

\int_{X}f(\sigma x)\omega_{\mu}(x)\;d\mu=\int_{X}f(x)\;d\mu,\quad f\in L^{1}(\mu).

It can be deduced from the uniqueness of the Radon-Nikodym
derivative that

\omega_{\mu}(x)=\rho_{\mu}(\sigma(x))^{-1}

when these functions are
considered as functions measurable with respect to

\sigma^{-1}(\mathcal{B})
.

The following statement is well-known and we omit its
proof.

Lemma 2.8
.

(1) The composition operator
S_{\sigma}:L^{2}(X,\mathcal{B},\mu)\to L^{2}(X,{\sigma^{-1}(\mathcal{B})},\mu)
is an isometry if and only if
\mu\circ\sigma^{-1}=\mu
.

(2) The operator
S_{\sigma}
on
L^{2}(\mu)
is bounded if
and only if there exists a constant
k>0
such that

\frac{\mu(\sigma^{-1}(A))}{\mu(A)}\leq k,\quad A\in\mathcal{B}.

(3) If
\mu
is a forward quasi-invariant measure, then

T_{\sigma}:f\longmapsto\sqrt{\omega_{\mu}}(f\circ\sigma)

is an isometry from
L^{2}(X,\mathcal{B},\mu)
onto
L^{2}(X,{\sigma^{-1}(\mathcal{B})},\mu)
.

2.4.
Properties of endomorphisms

In this subsection, we collected the properties of endomorphisms
of a measure space for the reader’s convenience. Here and
below we implicitly use the

\mathrm{mod}\ 0
-convention which means that a property
(formula, relation, etc) holds almost everywhere with
respect to a fixed measure.

Definition 2.9
.

Let
\sigma
be a surjective endomorphism of
(X,\mathcal{B},\mu)
with
quasi-invariant measure
\mu
.

(i) The endomorphism
\sigma
is called

conservative
if for any set
A
of positive measure
there exists
n>0

such that
\mu(\sigma^{n}(A)\cap A)>0
.

(ii) The endomorphism
\sigma
is called
ergodic

if whenever
A
is
\sigma
-invariant, i.e.,
\sigma^{-1}(A)=A
, then either
A
or
X\setminus A
is
of measure zero. Equivalently,
\sigma
is ergodic if, for
a bounded Borel function
f
, the condition

f\circ\sigma=f
implies that
f
is a constant
\textrm{mod}\ 0
.

(iii) Any endomorphism
\sigma\in End(X,\mathcal{B},\mu)
generates the
sequence of sub-algebras:

\mathcal{B}\supset\sigma^{-1}(\mathcal{B})\ \cdots\ \supset\sigma^{-i}(\mathcal{B})\supset\ \cdots

Then
\sigma\in End(X,\mathcal{B},\mu)
is called
exact
if

\mathcal{B}_{\infty}:=\bigcap_{k\in\mathbb{N}}\sigma^{-k}(\mathcal{B})=\{\emptyset,X\}\ \mod 0.

(iv) A non-singular endomorphism
\sigma
of
(X,\mathcal{B},\mu)

is said to be
\mu
-
recurrent
if for every non-
negative Borel function
f
, the function

\Sigma(f)=\sum_{n\geq 0}f(\sigma^{n}(x))\omega_{n}(x)

takes only the values 0 and
\infty

\mu
-a.e. where

\omega_{n}(x)=\dfrac{d\mu\circ\sigma^{n}}{d\mu}(x)
.

In the next remark, we include several results illustrating the
properties of endomorphisms given in Definition
(
2.9
). We use some results from

[
Sil88
]
,
[
HS91
]
,
[
Haw94
]
.

Remark 2.10
.

(1) Every exact endomorphism is ergodic. There are
examples of
ergodic endomorphisms which are not exact. As it is
customary in ergodic theory, we can always assume, without
loss of generality, that an endomorphism is ergodic.

(2) There are examples of one-sided shifts (
n
-to-one
endomorphisms) which are not exact.

(3) We note that there are ergodic endomorphisms that are
not conservative.

(4) An endomorphism
\sigma
is recurrent with respect to a
finite measure
\mu
if and only if
\sum_{n\geq 0}\omega_{n}(x)=\infty
.

(5) A
\mu
-recurrent endomorphism is conservative.

Since every surjective endomorphism defines an isometry

S_{\sigma}
(or
T_{\sigma}
), see Lemma
2.8
, then
we can apply Wold’s theorem to these objects.

Theorem 2.11

(Wold’s theorem)
.

Let
S
be an isometric operator in a Hilbert space

\mathcal{H}
. Define

\mathcal{H}_{\infty}=\bigcap_{n}S^{n}\mathcal{H},

and

\mathcal{H}_{shift}=N_{S^{*}}\oplus SN_{S^{*}}\oplus\cdots\oplus S^{k}N_{S^{*}}\oplus\cdots.

Then the following statements hold.

(1) The space
\mathcal{H}
is decomposed into the orthogonal
direct sum

\mathcal{H}=\mathcal{H}_{\infty}\oplus\mathcal{H}_{shift}.

(2)

\mathcal{H}_{\infty}=\{x\in\mathcal{H}:\|(S^{*})^{n}x\|=\|x\|,\ \forall n\in\mathbb{N}\}.

(3) The operator
S
restricted on
\mathcal{H}_{\infty}
is a
unitary operator, and
S
is a unilateral shift
in the space
\mathcal{H}_{shift}
.

For
\sigma\in End(X,\mathcal{B},\mu)
, define

\mathcal{B}_{\infty}=\bigcap_{n=0}^{\infty}\sigma^{-n}(\mathcal{B}),

and let
\mathcal{A}_{\sigma}=\{A\in\mathcal{B}:\sigma^{-1}(A)=A\}

be the subalgebra of
\sigma
-invariant subsets of
X
.

Let
\zeta
be a partition of
(X,\mathcal{B},\mu)
into orbits of

\sigma
(recall that
x\stackrel{{\scriptstyle\zeta}}{{\sim}}y
if there are

n,m
such that
\sigma^{n}(x)=\sigma^{m}(y)
). Let
\eta
be
the partition of
(X,\mathcal{B},\mu)
such that

x\stackrel{{\scriptstyle\eta}}{{\sim}}y
if there is

n
such that
\sigma^{n}(x)=\sigma^{n}(y)
. By
\zeta^{\prime}
and

\eta^{\prime}
we denote the measurable halls of
\zeta
and

\eta
, respectively.

If
\epsilon
denotes the partition of
X
into points,
then we have the sequence of decreasing measurable
partitions
\{\sigma^{-i}(\epsilon)\}_{i=0}^{\infty}
:

\epsilon\succeq\sigma^{-1}(\epsilon)\succeq\sigma^{-2}(\epsilon)\cdots.

As shown in
[
Roh61
]
, the following results hold

\zeta^{\prime}\preceq\eta^{\prime},\qquad\ \ \ \eta^{\prime}=\bigwedge_{n}\sigma^{-n}(\epsilon)

and

\mathcal{A}(\zeta^{\prime})=\mathcal{A}_{\sigma},\qquad\ \ \ \mathcal{A}(\eta^{\prime})=\mathcal{B}_{\infty}.

In particular,
\sigma
is ergodic if the partition

\zeta^{\prime}
is trivial, and
\sigma
is exact if the

\eta^{\prime}
is trivial.

Since

is a measurable partition, we can define
the quotient measure space
(Y,\nu)=(X/\eta^{\prime},\mathcal{B}/\eta^{\prime},\mu_{\eta^{\prime}})

(1) Let

Example 2.13

Let

Define the set

Define the map

2.5.
Markovian functions

In this subsection, we consider a class of functions defined
by an endomorphism
\sigma\in End(X,\mathcal{B},\mu)
. The following
definition is motivated by relation (
2.6
).

Definition 2.15
.

Let
\sigma
be an
onto endomorphism of
(X,\mathcal{B},\mu)
.
A function
\varphi\in{\mathcal{F}(X,\mathcal{B})}
satisfying

(2.7)

\int_{X}(f\circ\sigma)\varphi\;d\mu=\int_{X}f\;d\mu

for all
f
in
L^{1}(\mu)
is called a
Markovian

function. The set of all Markovian functions is denoted by

M(\sigma,\mu)
. We denote
M_{2}(\sigma,\mu)=M(\sigma,\mu)\cap L^{2}(\mu)
.

The Markovian functions were considered in a series of
papers
[
Haw94
]
,
[
HS91
]
,

[
DH94
]
, and others.

Remark 2.16
.

(1) The set
M(\sigma,\mu)
is convex.

(2) Suppose that
\mu
is a forward quasi-invariant
measure for

\sigma\in End(X,\mathcal{B},\mu)
. Then the set of Markovian functions

M(\sigma,\mu)
is not empty because

\omega_{\mu}\in M(\sigma,\mu)
due to relation
(
2.6
).

(3) For two equivalent measures
\mu
and
\nu
, we
discuss
relation between the functions
\omega_{\mu}
and
\omega_{\nu}

in Theorem
3.15
. As above, the function

\omega_{\mu}
generates a cocycle by setting

\omega_{n}(x)=\frac{d\mu\circ\sigma^{n}}{d\mu}(x)
(where
\omega_{1}=\omega_{\mu}
).

(4) Let
g
be a function from
L^{1}(\mu)
. It was shown
in
[
Haw94
]
that, for the measure
d\nu=gd\mu
,
the following holds:

\int_{X}f(\sigma x)\dfrac{g\omega_{\nu}}{g\circ\sigma}(x)\;d\mu=\int_{X}f(x)\;d\mu,\quad f\in L^{1}(\mu).

This means that the function
\dfrac{g\omega_{\nu}}{g\circ\sigma}

is Markovian with respect to
(\sigma,\mu)
.

Based on the facts from Remark
2.16
, we prove the
following result.

Proposition 2.17
.

Let
\sigma\in End(X,\mathcal{B},\mu)
. Suppose a measure

\nu
is equivalent to
\mu
and
g=\frac{d\nu}{d\mu}
. Then

M(\sigma,\nu)=g^{-1}M(\sigma,\mu)(g\circ\sigma).

Proof.

For a function
\varphi\in M(\sigma,\mu)
, show that

h=g^{-1}\varphi(g\circ\sigma)\in M(\sigma,\nu)
. For any

f\in L^{1}(\nu)
, we have

\displaystyle\int_{X}(f\circ\sigma)g^{-1}\varphi(g\circ\sigma)\;d\nu=

\displaystyle\int_{X}(fg)\circ\sigma\varphi\;d\mu

\displaystyle=

\displaystyle\int_{X}fg\;d\mu

\displaystyle=

\displaystyle\int_{X}f\;d\nu.

This shows that the function
h
is in
M(\sigma,\nu)
.

Conversely, let
\varphi
be a Markovian function from

M(\sigma,\nu)
. Since
d\nu=gd\mu
,

\displaystyle\int_{X}fg\;d\mu=

\displaystyle\int_{X}(f\circ\sigma)\varphi g\;d\mu

\displaystyle=

\displaystyle\int_{X}(f\circ\sigma)(g\circ\sigma)[(g\circ\sigma)^{-1}\varphi g]\;d\mu.

The latter means that
(g\circ\sigma)^{-1}\varphi g\in M(\sigma,\mu)
.
∎

Lemma 2.18
.

Let
\varphi_{1},...,\varphi_{k}
be Markovian functions from

M(\sigma,\mu)
. Then the function
\psi=(\varphi_{k}\circ\sigma^{k-1})\cdots(\varphi_{2}\circ\sigma)\varphi_{1}
belongs to
M(\sigma^{k},\mu)
.

Proof.

We compute

\displaystyle\int_{X}(f\circ\sigma^{k})\psi\;d\mu=

\displaystyle\int_{X}[(f\circ\sigma^{k-1})\circ\sigma(\varphi_{k}\circ\sigma^{k-2})\circ\sigma\cdots(\varphi_{2}\circ\sigma)]\varphi_{1}\;d\mu

\displaystyle=

\displaystyle\int_{X}(f\circ\sigma^{k-1})(\varphi_{k}\circ\sigma^{k-2})\cdots(\varphi_{3}\circ\sigma)\varphi_{2}\;d\mu

\displaystyle\cdots\cdots

\displaystyle=

\displaystyle\int_{X}f\;d\mu.

∎

3.1.
Transfer operators and endomorphisms

We define a transfer operator in general settings using
only the Borel structure of the space
(X,\mathcal{B})
. Transfer
operators are extensively studied for various dynamical
systems applying the properties of phase spaces.

Definition 3.1
.

Let
{\mathcal{F}(X,\mathcal{B})}
be the set of all bounded
Borel functions
1
1

1

In this section, we will consider
real-valued functions for definiteness; the case of
complex-valued functions can be done similarly.

and let
R:{\mathcal{F}(X,\mathcal{B})}\to{\mathcal{F}(X,\mathcal{B})}
be a linear operator.
Then

is called a

if it
satisfies the following properties:

(i)
f\geq 0\ \Longrightarrow\ R(f)\geq 0
(i.e.,
R
is
a positive operator);

(ii) for any Borel functions
f,g\in\mathcal{F}(X,\mathcal{B})

the

holds

R((f\circ\sigma)g)=fR(g).

To emphasize that a transfer operator
R
is defined by an

\sigma

(R,\sigma)
.

Let
\mathbbm{1}
be a function on
(X,\mathcal{B})
that takes the
only value 1. If
R(\mathbbm{1})(x)>0
for all

,
then we say that
R
is a
strict transfer operator
.
If
R(\mathbbm{1})=\mathbbm{1}
, then the transfer operator

Every transfer operator

defines an action on the
set of probability measures
M_{1}(X)

\mu\in M_{1}(X)

(\mu R)(f)=\int_{X}R(f)\;d\mu,\quad f\in{\mathcal{F}(X,\mathcal{B})}.

If
\mu=\mu R

\mu
is called

A measure
\mu\in M_{1}(X)
is called

(R,\sigma)
if
\mu

\sigma
-invariant and
\mu R=\mu
.

Restrictions of transfer operators on Banach or Hilbert
spaces give more possibilities to study their properties.

Lemma 3.2
.

Let
(X,\mathcal{B},\mu)
be a
probability standard measure space.
Suppose that
(R,\sigma)
is a normalized transfer operator
acting in

where

is strongly

if and only if

R^{*}(\mathbbm{1})=\mathbbm{1}
.

Proof.

Here and below we denote by
\langle\cdot,\cdot\rangle_{\mu}
the inner product in
L^{2}(\mu)
.
Since
R
is normalized, we can write

\langle f,\mathbbm{1}\rangle_{\mu\circ\sigma^{-1}}=\langle f\circ\sigma,R^{*}(\mathbbm{1})\rangle_{\mu}=\langle R(f\circ\sigma),\mathbbm{1}\rangle_{\mu}=\langle fR(\mathbbm{1}),\mathbbm{1}\rangle_{\mu}=\langle f,\mathbbm{1}\rangle_{\mu},

that is
\mu
is
\sigma
-invariant if

R^{*}(\mathbbm{1})=\mathbbm{1}
.

Similarly, we see that the condition
R^{*}(\mathbbm{1})=1
is
equivalent to
\mu=\mu R

\langle f,\mathbbm{1}\rangle_{\mu R}=\langle R(f),\mathbbm{1}\rangle_{\mu}=\langle f,R^{*}(\mathbbm{1})\rangle_{\mu}=\langle f,\mathbbm{1}\rangle_{\mu}.

∎

Example 3.3
.

Let
\sigma\in End(X,\mathcal{B},\mu)

Theorem 3.7
.

(1) For
\sigma\in End(X,\mathcal{B},\mu)
as above, consider the
composition

in the Hilbert space

acts by the

(2) The adjoint operator
S_{\sigma}^{*}
is a transfer operator

S_{\sigma}^{*}(g(f\circ\sigma))=fS_{\sigma}^{*}(g).

The transfer operator
S_{\sigma}^{*}
is normalized if and
only if
\mu
is
\sigma
-invariant.

(3) For a function
t\in\mathcal{F}(X,\mathcal{B})
, the adjoint
operator
P_{t}^{*}
is a non-normalized transfer operator.

Proof.

(1) For functions
f,g\in L^{2}(\mu)
, we have

\displaystyle\langle S_{\sigma}f,g\rangle_{\mu}=

\displaystyle\int_{X}(f\circ\sigma)g\;d\mu

\displaystyle=

\displaystyle\int f\;(gd\mu)\circ\sigma^{-1}

\displaystyle=

\displaystyle\int f\frac{(gd\mu)\circ\sigma^{-1}}{d\mu}\;d\mu

\displaystyle=

\displaystyle\langle f,S_{\sigma}^{*}g\rangle_{\mu}

which proves (
3.4
).

(2) To prove the pull-out property, we compute, for
arbitrary functions

\displaystyle\int_{X}hS_{\sigma}^{*}((f\circ\sigma)g)\;d\mu=

\displaystyle\int_{X}S_{\sigma}(h)(f\circ\sigma)g\;d\mu

\displaystyle=

\displaystyle\int_{X}((hf)\circ\sigma)\;g\;d\mu

\displaystyle=

\displaystyle\int_{X}hfS_{\sigma}^{*}(g)\;d\mu.

Finally, we see that

\int_{X}f\;d\mu\circ\sigma^{-1}=\int_{X}(f\circ\sigma)\mathbbm{1}\;d\mu=\int_{X}fS_{\sigma}^{*}(\mathbbm{1})\;d\mu,

and
S_{\sigma}^{*}(\mathbbm{1})=\mathbbm{1}\ \Longleftrightarrow\ \mu\circ\sigma^{-1}=\mu
.

(3) The same proof as in (1) gives the formula

P_{t}^{*}(g)=\frac{(tgd\mu)\circ\sigma^{-1}}{d\mu},\quad g\in L^{2}(\mu_{\mathcal{A}}).

This shows that
P^{*}_{t}
is not normalized.

To prove that
P_{t}^{*}
satisfies the pull-out property,
we write

\displaystyle\langle h,P_{t}^{*}(g(f\circ\sigma))\rangle_{\mu}=

\displaystyle\langle P_{t}(h),g(f\circ\sigma)\rangle_{\mu}

\displaystyle=

\displaystyle\langle t(h\circ\sigma),g(f\circ\sigma)\rangle_{\mu}

\displaystyle=

\displaystyle\langle P_{t}(hf),g\rangle_{\mu}

\displaystyle=

\displaystyle\langle h,fP_{t}^{*}(g)\rangle_{\mu}.

∎

4.
Cuntz relations for invariant and
quasi-invariant measures

Starting with the measurable category, and disintegration of
the appropriate measures, we showed above that careful
choice of Hilbert spaces allows for a powerful tool in the
analysis of endomorphisms and branching systems (in the
measurable setting). In more detail, the steps from
transformations in measure space to
L^{2}
spaces and
operators are often called “passing to the Koopman
operators”. In our context,
the non-commutativity for the operators under consideration
is captured well with the Cuntz relations, or rather their
representations; see
[
Cun77
]
,

[
JT20
]
,
[
BJ15
]
.
Recall that, following J. Cuntz, for every
n
, one
introduces a
C^{*}
-algebra
\mathcal{O}_{|\Lambda|}
defined by a
system of
|\Lambda|
generators
T_{i}
. These generators may be
realized as operators in Hilbert space, say
H
as follows:
The relations (Cuntz-relations) state that the
T_{i}
system
is represented by isometries with orthogonal ranges in

H
such that the sum of these ranges is
H
. (Think of the
subspaces as sub-bands.) In other words, via the isometries,

H
arises as an orthogonal sum of copies of itself.
As a
C^{*}
-algebra,
\mathcal{O}_{|\Lambda|}
is simple. Its
representations are important, and they play a crucial role
in the study of self-similar dynamics and self-similar
geometries.

4.1.

Let

is Markovian, we have

\displaystyle\langle S_{\varphi}(f),S_{\varphi}(g)\rangle_{\mu}=

\displaystyle\int_{X}\sqrt{\varphi}(f\circ\sigma)\sqrt{\varphi}(\overline{g}\circ\sigma)\;d\mu

\displaystyle=

\displaystyle\int_{X}(f\overline{g}\circ\sigma)\varphi\;d\mu

\displaystyle=

\displaystyle\int_{X}f\overline{g}\;d\mu,\qquad f,g\in L^{2}(\mu).

∎

Theorem 4.3
.

(1) For
\sigma\in End(X,\mathcal{B},\mu)
as above and the operator
S_{\varphi}
,
the adjoint operator
S_{\sigma}^{*}
acts by the formula:

(4.2)

S_{\varphi}^{*}(g)=\frac{(g\sqrt{\varphi}d\mu)\circ\sigma^{-1}}{d\mu},\quad g\in L^{2}(\mu).

(2) The adjoint operator
S_{\varphi}^{*}
is a transfer operator
satisfying the pull-out property:

(4.3)

S_{\varphi}^{*}(g(f\circ\sigma))=fS_{\varphi}^{*}(g).

The operator
S_{\varphi}^{*}
is normalized if and only if
\mu
is

\sigma
-invariant.

Proof.

(1) For functions
f,g\in L^{2}(\mu)
, we have

\int_{X}\sqrt{\varphi}(f\circ\sigma)g\;d\mu=\int f\;(\sqrt{\varphi}gd\mu)\circ\sigma^{-1}=\int f\frac{(gd\mu)\circ\sigma^{-1}}{d\mu}\;d\mu

which proves (
4.2
).

(2) The operator
S^{*}_{\varphi}
is obviously positive.
To prove the pull-out property, we compute, for arbitrary
functions
f,g,h\in L^{2}(\mu)
,

\displaystyle\int_{X}hS_{\varphi}^{*}((f\circ\sigma)g)\;d\mu=

\displaystyle\int_{X}S_{\varphi}(h)(f\circ\sigma)g\;d\mu

\displaystyle=

\displaystyle\int_{X}\sqrt{\varphi}(hf)\circ\sigma\;g\;d\mu

\displaystyle=

\displaystyle\int_{X}S_{\varphi}(hf)g\;d\mu

\displaystyle=

\displaystyle\int_{X}hfS^{*}_{\varphi}(g)\;d\mu.

This proves that (
4.3
) holds.

We see that

S_{\varphi}^{*}(\mathbbm{1})=\frac{(\sqrt{\varphi}d\mu)\circ\sigma^{-1}}{d\mu}.

Hence,
S_{\varphi}^{*}
is normalized if and only if
\mu=\mu\circ\sigma^{-1}

and
\varphi=\mathbbm{1}
. This can be proved as follows

\int_{X}f\;d\mu\circ\sigma^{-1}=\int_{X}(f\circ\sigma)\mathbbm{1}\;d\mu=\int_{X}fS_{\sigma}^{*}(\mathbbm{1})\;d\mu,

and
S_{\sigma}^{*}(\mathbbm{1})=\mathbbm{1}\ \Longleftrightarrow\ \mu\circ\sigma^{-1}=\mu
.
∎

Remark 4.4
.

One can easily check that, for

We recall that

Proposition 4.5
.

Let
\sigma,\varphi,
and
S_{\varphi}
be as above. Then

(1)
\mathbb{E}_{\varphi}:=S_{\varphi}S^{*}_{\varphi}
is
an orthogonal projection from
L^{2}(\mu)
onto
\mathcal{H}_{\varphi}
;

(2)
\mathbb{E}_{\varphi}((f\circ\sigma)g)=(f\circ\sigma)\mathbb{E}_{\varphi}(g)

(3)
S^{*}_{\varphi}(f\mathbb{E}_{\varphi}(g))=S^{*}_{\varphi}(g)S^{*}_{\varphi}(f\sqrt{\varphi})
.

Proof.

(1) Let
f,g\in L^{2}(\mu)
. Then we write

\displaystyle\langle S_{\varphi}S^{*}_{\varphi}f,\sqrt{\varphi}(g\circ\sigma)\rangle_{\mu}=

\displaystyle\langle S_{\varphi}S^{*}_{\varphi}f,S_{\varphi}g\rangle_{\mu}

\displaystyle=

\displaystyle\langle S^{*}_{\varphi}f,g\rangle_{\mu}

\displaystyle=

\displaystyle\langle f,S_{\varphi}g\rangle_{\mu}

\displaystyle=

\displaystyle\langle f,\sqrt{\varphi}(g\circ\sigma)\rangle_{\mu}.

Hence,
(f-S_{\varphi}S^{*}_{\varphi}f)\perp\mathcal{H}_{\varphi}
.

For (2), we first note that
S_{\varphi}(fg)=\sqrt{\varphi}(g\circ\sigma)(f\circ\sigma)=S_{\varphi}(g)S_{\sigma}(f)
, and then

\displaystyle\mathbb{E}_{\varphi}((f\circ\sigma)g)=

\displaystyle S_{\varphi}S^{*}_{\varphi}((f\circ\sigma)g)

\displaystyle=

\displaystyle S_{\varphi}(S^{*}_{\varphi}(g)f)

\displaystyle=

\displaystyle(S_{\varphi}S^{*}_{\varphi})(g)S_{\sigma}(f)

\displaystyle=

\displaystyle(f\circ\sigma)\mathbb{E}_{\varphi}(g).

For (3), we use the pull-out property of
S^{*}_{\varphi}
:

\displaystyle S^{*}_{\varphi}(f\mathbb{E}_{\varphi}(g))=

\displaystyle S^{*}_{\varphi}(fS_{\varphi}S^{*}_{\varphi}(g))

\displaystyle=

\displaystyle S^{*}_{\varphi}(f\sqrt{\varphi}(S^{*}_{\varphi}(g)\circ\sigma))

\displaystyle=

\displaystyle S^{*}_{\varphi}(g)S^{*}_{\varphi}(f\sqrt{\varphi}).

∎

Let
\{m_{i}:i\in\Lambda\}
be a collection of complex-valued
functions from

. We fix a Markovian function

.
For every

(4.4)

T_{m_{i}}(f)=m_{i}\sqrt{\varphi}(f\circ\sigma)=M_{m_{i}}S_{\varphi}(f)

where

Then

Lemma 4.6
.

The operator
T_{m}(f)=m\sqrt{\varphi}(f\circ\sigma)
is bounded on
L^{2}(\mu)

if and only if
|m|^{2}\in L^{\infty}(\mu)
.

Proof.

For

, we have

\displaystyle||T_{m}(f)||^{2}=

\displaystyle\int_{X}(m\sqrt{\varphi}(f\circ\sigma))(\overline{m}\sqrt{\varphi}(\overline{f}\circ\sigma)\;d\mu

\displaystyle=

\displaystyle\int_{X}|m|^{2}(|f|^{2}\circ\sigma)\varphi\;d\mu

\displaystyle\leq

\displaystyle\sup|m|^{2}\int_{X}(|f|^{2}\circ\sigma)\varphi\;d\mu

\displaystyle=

\displaystyle\sup|m|^{2}||f||^{2}.

∎

Lemma 4.7
.

The operator
T_{m}
is an isometry in

if and only if

∎

Remark 4.8

Lemma 4.9
.

The operators

and

Theorem 4.11
.

Let
\sigma
be an onto
endomorphism of
(X,\mathcal{B},\mu)
where
\mu
is quasi-invariant with
respect to
\sigma
.
Let
\{m_{i}:i\in\Lambda\}
be a family of
complex-valued functions.
The operators
\{T_{m_{i}},i\in\Lambda
}
generate a
representation of the Cuntz algebra
\mathcal{O}_{|\Lambda|}

if and only if

(i)\ \ S^{*}_{\varphi}(\sqrt{\varphi}\;\overline{m}_{j}m_{i})=\delta_{ij}\mathbbm{1},

(ii)\ \ \sum_{i\in\Lambda}m_{i}\mathbb{E}_{\varphi}(\overline{m}_{i}f)=f,\ \ \ f\in L^{2}(\mu).

Proof.

We first note that condition (i) of the
theorem
implies that the operators
T_{m_{i}}
are isometries because
of Lemma
4.7
.
The Cuntz relations for isometries
\{T_{m_{i}}\}_{i\in\Lambda}
mean that

\sum_{i\in\Lambda}T_{m_{i}}T_{m_{i}}^{*}=\mathbb{I}

and the projections
T_{m_{i}}T_{m_{i}}^{*}
are mutually
orthogonal.

We will show that, for
f,g\in L^{2}(\mu)
and
i\neq j
,
the vectors
T_{m_{i}}T_{m_{i}}^{*}(f)
and
T_{m_{j}}T_{m_{j}}^{*}(g)

are orthogonal if and only if condition (i) of the theorem
holds. In the following computation, we use (
4.5
).

\displaystyle\langle T_{m_{i}}T_{m_{i}}^{*}(f),T_{m_{j}}T_{m_{j}}^{*}(g)\rangle_{\mu}=

\displaystyle\langle(T_{m_{j}}^{*}T_{m_{i}})T_{m_{i}}^{*}(f)),T_{m_{j}}^{*}(g)\rangle_{\mu}

\displaystyle=

\displaystyle\langle S^{*}_{\varphi}(\sqrt{\varphi}\;\overline{m}_{j}m_{i})(\xi),\eta\rangle_{\mu}

where
\xi=T_{m_{i}}^{*}(f)
and
\eta=T_{m_{j}}^{*}(g)
. Since

f,g
are arbitrary functions, the left-hand side is zero
if and only if
S^{*}_{\varphi}(\sqrt{\varphi}\;\overline{m}_{j}m_{i})=\delta_{ij}\mathbb{I}
.

Next, we use (
4.6
) to see when the identity
operator
is decomposed in the sum of orthogonal projections

T_{m_{i}}T_{m_{i}}^{*}
. It follows from Lemma
4.9
that,
for any
f\in L^{2}(\mu)
,

\sum_{i\in\Lambda}T_{m_{i}}T_{m_{i}}^{*}(f)=\sum_{i\in\Lambda}m_{i}\mathbb{E}_{\varphi}(\overline{m}_{i}f)

Hence, the property
\sum_{i\in\Lambda}T_{m_{i}}T_{m_{i}}^{*}=\mathbb{I}
is equivalent to condition (ii) of the theorem.
∎

Corollary 4.12
.

It follows from Theorem
4.11
that

L^{2}(\mu)=\bigoplus_{i\in\Lambda}\ m_{i}\mathcal{H}_{\varphi}.

In other words,

is an orthogonal

over

where
\mathcal{A}=\sigma^{-1}(\mathcal{B})
.

Lemma 4.13
.

Let
\sigma\in End(X,\mathcal{B},\mu)
be an onto endomorphism. Then if

-invariant probability measure, then the only

{\sigma^{-1}(\mathcal{B})}

\int_{X}(f\circ\sigma)\varphi\;d\mu=\int_{X}f\;d\mu=\int_{X}f\;d(\mu\circ\sigma)^{-1}=\int_{X}(f\circ\sigma)\;d\mu.

Since

is arbitrary, we get
\varphi=\mathbbm{1}
on
{\sigma^{-1}(\mathcal{B})}
.
∎

We will apply the constructions of
Subsection
4.1
to the case when

\varphi=\mathbbm{1}

4.1
are proved in more general settings,

Let
\underline{m}=\{m_{i}:i\in\Lambda\}
be a collection

Proposition 4.16
.

The following formulas hold: for

(1)\ \ S^{*}_{\varphi}(g)=S^{*}_{\sigma}(\sqrt{\varphi}\;g),\quad(2)\ \ \mathbb{E}_{\varphi}(g)=\sqrt{\varphi}\;\mathbb{E}_{\sigma}(\sqrt{\varphi}\;g).

5.
The set of wavelet filters

In this section, we
answer the question about the structure of the set of

wavelet filters
, i.e., we describe the set
of functions satisfying the conditions of
Theorem
4.11
.
We consider two different approaches: (i) it will be shown
that there the set
\mathfrak{M}
is isomorphic to the so
called loop group
\mathcal{G}
;
(ii) using the decomposition into cyclic representations,
we describe elements
\underline{m}\in\mathfrak{M}
as the
collection of cyclic vectors for the representation of

L^{\infty}(\mathcal{A})
in
L^{2}(X,\mathcal{B},\mu)
.

5.1.
Actions of loop groups on wavelet filters

Consider bounded operators
B(l^{2}(\Lambda))
in the Hilbert
space
l^{2}(\Lambda)
where
\Lambda
is a countably infinite
set. If
\{e_{i}:i\in\Lambda\}
is the canonical
orthonormal basis in
l^{2}(\Lambda)
, then we define the
infinite
|\Lambda|\times|\Lambda|
matrix
\widehat{A}=(a_{ij})
by setting
a_{ij}=\langle e_{i},Ae_{j}\rangle
.
This observation will allow us to work with matrix notation
in the computations below.

Let
\mathcal{U}
be the group of all unitary operators in

B(l^{2}(\Lambda))
. Denote by
\mathcal{G}
the group of Borel
functions on
(X,\mathcal{B})
with values in
\mathcal{U}
(we recall
that
\mathcal{U}
is a Polish group). We use the notation

G=(g_{ij}(x))
for elements of
\mathcal{G}
. Then every
entry
g_{ij}(x)
is a Borel complex-valued matrix.
The group
\mathcal{G}
is called the
loop group
.
We remark that for
G\in\mathcal{G}
,
G^{*}G=\mathbb{I}
where
the matrix
G^{*}=\overline{G}^{T}
. We will use the relation

(5.1)

\sum_{l\in\Lambda}\overline{g}_{li}g_{lj}=\delta_{ij}

where
G=(g_{ij})\in\mathcal{G}
.

Let
\varphi
be a Markovian function. We recall that, in this
case, the operator
S_{\varphi}
is isometric.
We denote the set of generalized wavelet filters by

(5.2)

\mathfrak{M}_{\varphi}:=\{\underline{m}=(m_{i})_{i\in\Lambda}:S_{\varphi}^{*}(\sqrt{\varphi}\;m_{i}\overline{m}_{j})=\delta_{ij}\mathbbm{1},\ \ \ \sum_{i\in\Lambda}m_{i}\mathbb{E}_{\varphi}(\overline{m}_{j}f)=f\}.

We consider simultaneously the case of
\sigma
-invariant
measure
\mu
and the corresponding operators
S_{\sigma}
and

\mathbb{E}_{\sigma}
, see Section
4
for
properties of these operators. In this case, we use the set

(5.3)

\mathfrak{M}_{\sigma}:=\{\underline{m}=(m_{i})_{i\in\Lambda}:S_{\sigma}^{*}(m_{i}\overline{m}_{j})=\delta_{ij}\mathbbm{1},\ \ \ \sum_{i\in\Lambda}m_{i}\mathbb{E}_{\sigma}(\overline{m}_{j}f)=f\}.

It turns out that the group
\mathcal{G}
acts on the sets

\mathfrak{M}_{\varphi}
and
\mathfrak{M}_{\sigma}
. Indeed,
for a fixed
\underline{m}\in\mathfrak{M}_{\varphi}
(or

\underline{m}\in\mathfrak{M}_{\sigma}
) and
G\in\mathcal{G}
, we define

\underline{m}^{G}:=(m^{G}_{i}(x):i\in\Lambda)
by the
formula

(5.4)

m^{G}_{i}(x)=\sum_{j\in\Lambda}(\overline{g}_{ji}\circ\sigma)(x)m_{j}(x)

or
\underline{m}^{G}=(G^{*}\circ\sigma)\underline{m}
in a short form.

In the next statements, we will study the properties of
this action of
\mathcal{G}
on the sets of wavelet filters.
For definiteness, we formulate these results for the
set
\mathfrak{M}_{\varphi}
. The same proofs work for the
action of
\mathcal{G}
on
\mathfrak{M}_{\sigma}
, we will omit them.
We will show in the next lemmas that: (i) the set

\mathfrak{M}_{\varphi}
is invariant with respect to the action
of group
\mathcal{G}
; (ii) formula
(
5.4
) defines a group action on

\mathfrak{M}_{\varphi}
; (iii) this action of
\mathcal{G}
is free and
transitive.

Lemma 5.1
.

If
\underline{m}\in\mathfrak{M}_{\varphi}
, then
\underline{m}^{G}\in\mathfrak{M}_{\varphi}
.

Proof.

We will verify that the family of functions
\underline{m}^{G}=(m_{i}^{G}(x):i\in\Lambda)
satisfies
conditions (i) and (ii) of Theorem
4.11
.
For (i), we use (
5.1
) and the fact that

S^{*}_{\varphi}
is a transfer operator satisfying the pull-out
property:

\displaystyle S^{*}_{\varphi}(\sqrt{\varphi}\;m^{G}_{i}\overline{m}^{G}_{j})=

\displaystyle S^{*}_{\varphi}\left(\sqrt{\varphi}\sum_{k\in\Lambda}(\overline{g}_{ki}\circ\sigma)m_{k}\cdot\sum_{l\in\Lambda}\overline{(\overline{g}_{jl}\circ\sigma)m_{l}}\right)

\displaystyle=

\displaystyle\sum_{k\in\Lambda}\sum_{l\in\Lambda}\overline{g}_{ki}g_{lj}S^{*}_{\varphi}(\sqrt{\varphi}\overline{m}_{l}m_{k})

\displaystyle=

\displaystyle\sum_{k\in\Lambda}\sum_{l\in\Lambda}\overline{g}_{ki}g_{lj}\delta_{kl}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}\overline{g}_{ki}g_{kj}

\displaystyle=

\displaystyle\delta_{ij}.

For (ii), let
f\in L^{2}(\mu)
, then

\displaystyle\sum_{i\in\Lambda}m_{i}^{G}\mathbb{E}_{\varphi}(\overline{m}^{G}_{i}f)=

\displaystyle\sum_{i\in\Lambda}\sum_{k\in\Lambda}(\overline{g}_{ki}\circ\sigma)m_{k}\mathbb{E}_{\varphi}\left(\sum_{l\in\Lambda}(g_{li}\circ\sigma)\overline{m}_{l}f\right)

\displaystyle=

\displaystyle\sum_{i\in\Lambda}\sum_{k\in\Lambda}\sum_{l\in\Lambda}(\overline{g}_{ki}\circ\sigma)(g_{li}\circ\sigma)m_{k}\mathbb{E}_{\varphi}(\overline{m}_{l}f)

\displaystyle=

\displaystyle\sum_{i\in\Lambda}\sum_{k\in\Lambda}\sum_{l\in\Lambda}((\overline{g}_{ki}g_{li})\circ\sigma)m_{k}\mathbb{E}_{\varphi}(\overline{m}_{l}f)

\displaystyle=

\displaystyle\sum_{i\in\Lambda}\sum_{k\in\Lambda}\delta_{kl}m_{k}\mathbb{E}_{\varphi}(\overline{m}_{l}f)

\displaystyle=

\displaystyle\sum_{k\in\Lambda}m_{k}\mathbb{E}_{\varphi}(\overline{m}_{l}f)

\displaystyle=

\displaystyle f.

We used here the equality
GG^{*}=\mathbb{I}
or

\sum_{i}\overline{g}_{ki}g_{li}=\delta_{kl}
.
∎

In the next lemma, we show that (
5.4
) defines
an action of the group
\mathcal{G}
on
\mathfrak{M}
.

Lemma 5.2
.

For every
\underline{m}\in\mathfrak{M}_{\varphi}
and every

G,H\in\mathcal{G}
,

(5.5)

(\underline{m}^{G})^{H}=\underline{m}^{GH},\quad\underline{m}^{\mathbb{I}}=\underline{m}.

Proof.

Indeed, if
\mathbb{I}
is the identity matrix, then

\underline{m}^{\mathbb{I}}=\underline{m}
for every

\underline{m}\in\mathfrak{M}_{\varphi}
.

Let
G,H\in\mathfrak{M}_{\varphi}
. Show that (
5.5
)
holds:

\displaystyle(m^{G})^{H}_{i}=

\displaystyle\sum_{j\in\Lambda}(\overline{h}_{ji}\circ\sigma)m_{j}^{G}

\displaystyle=

\displaystyle\sum_{j\in\Lambda}(\overline{h}_{ji}\circ\sigma)\sum_{k\in\Lambda}(\overline{g}_{kj}\circ\sigma)m_{k}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}\sum_{j\in\Lambda}((\overline{g}_{ij}\overline{h}_{jk})\circ\sigma)m_{k}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}(\overline{f}_{ik}\circ\sigma)m_{k}

\displaystyle=

\displaystyle m^{GH}_{i},

where the entries of
GH
are denoted by
(f_{ik})
.
∎

Lemma 5.3
.

Let
\varphi
be a positive Markovian function.

(1) The map
\Phi:\underline{m}\mapsto\sqrt{\varphi}\;\underline{m}

defines an isomorphism between the sets
\mathfrak{M}_{\varphi}

and
\mathfrak{M}_{\sigma}
.

(2) The map
\Phi
implements the conjugation of actions
of
\mathcal{G}
on the sets
\mathfrak{M}_{\sigma}
and

\mathfrak{M}_{\varphi}
.

Proof.

(1) We will show that if
\underline{m}
satisfies
(
5.2
), then
\sqrt{\varphi}\underline{m}
belongs to

\mathfrak{M}_{\sigma}
, i.e., (
5.3
) holds.
For this, we check that

S^{*}_{\sigma}(\sqrt{\varphi}m_{i}\;\sqrt{\varphi}\overline{m}_{j})=S^{*}_{\varphi}(\sqrt{\varphi}\;m_{i}\overline{m}_{j})=\delta_{ij},\ \ i,j\in\Lambda,

and, using Proposition
4.16
,

\displaystyle\sum_{i\in\Lambda}\sqrt{\varphi}m_{i}\mathbb{E}_{\sigma}(\sqrt{\varphi}\overline{m}_{i}f)=

\displaystyle\sum_{i\in\Lambda}\sqrt{\varphi}m_{i}S_{\sigma}S^{*}_{\sigma}(\sqrt{\varphi}\overline{m}_{i}f)

\displaystyle=

\displaystyle\sum_{i\in\Lambda}m_{i}S_{\varphi}S^{*}_{\varphi}(\overline{m}_{i}f)

\displaystyle=

\displaystyle f.

(2) It can be checked directly that, for every
G\in\mathcal{G}

and
\underline{m}\in\mathfrak{M}_{\varphi}
,

\Phi\underline{m}^{G}=(\Phi\underline{m})^{G}.

∎

Lemma 5.4
.

Let
\varphi
be a positive Markovian function.
The action of
\mathcal{G}
on
\mathfrak{M}_{\varphi}
defined in
(
5.4
) is free and transitive.

Proof.

It follows from Lemma
5.3

that it suffices to show that the action of
\mathcal{G}

on
\mathfrak{M}_{\sigma}
is free and transitive.

Let
\underline{m}=(m_{i})
and

\underline{n}=(n_{j})
be two elements of
the set
\mathfrak{M}_{\sigma}
. Define an infinite matrix
G
by
setting

g_{ij}=S^{*}_{\varphi}(m_{i}\overline{n}_{j}),\quad i,j\in\Lambda.

We show that
\underline{m}^{G}=\underline{n}
to prove that
the action is transitive. Indeed,

\displaystyle m_{i}^{G}=

\displaystyle\sum_{k\in\Lambda}(\overline{g}_{k,i}\circ\sigma)m_{k}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}(S^{*}_{\sigma}(\overline{m}_{k}n_{i})\circ\sigma)m_{k}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}S_{\sigma}S^{*}_{\sigma}(\overline{m}_{k}n_{i})m_{k}

\displaystyle=

\displaystyle\sum_{k\in\Lambda}\mathbb{E}_{\sigma}(\overline{m}_{k}n_{i})m_{k}

\displaystyle=

\displaystyle n_{i}.

We used here relation (
5.3
).

To see that this action is free, we assume that

\underline{m}^{G}=\underline{m}
for some

\underline{m}\in\mathfrak{M}_{\sigma}
and
G\in\mathcal{G}
. Then

\sum_{k\in\Lambda}(\overline{g}_{ki}\circ\sigma)m_{k}=m_{i},\quad i\in\Lambda.

Multiply both sides by
\overline{m}_{j}
and apply the operator

S^{*}_{\sigma}
:

\sum_{k\in\Lambda}S^{*}_{\sigma}((\overline{g}_{ki}\circ\sigma)m_{k}\overline{m}_{j})=S^{*}_{\sigma}(m_{i}\overline{m}_{j})

Use the pull-out property and (
5.3
):

\sum_{k\in\Lambda}\overline{g}_{ki}S^{*}_{\sigma}(m_{k}\overline{m}_{j})=\delta_{ij}.

Hence,

\sum_{k\in\Lambda}\overline{g}_{ki}\delta_{kj}=\delta_{ij}

and
\overline{g}_{li}=\delta_{ij}
. This proves that

G=\mathbb{I}
and the action is free.

∎

The following theorem gives a complete description of the
set
\mathfrak{M}_{\varphi}
. This result immediately
follows from the proven Lemmas
5.1
-
5.4
.

Theorem 5.5
.

(1) The set
\mathfrak{M}_{\varphi}
is isomorphic (as a set) to the
loop group
\mathcal{G}
.

(2) For every element
G=(g_{ij})
of the loop group,
there exists a wavelet filter
\underline{m}
such that

g_{ij}=S^{*}_{\varphi}(\sqrt{\varphi}\;m_{i}\overline{m}_{j})
.

5.2.
Endomorphisms, wavelet filters and cyclic
representations

In this subsection, we will use another approach to describe the
set
\mathfrak{M}
of wavelet filters associated with an
endomorphism
\sigma
of
(X,\mathcal{B},\mu)
. We will assume here that
\sigma

is measure-preserving.

Let
\mathcal{A}={\sigma^{-1}(\mathcal{B})}
and
\mu_{\mathcal{A}}
is the restriction of
\mu

onto the sigma-subalgebra
\mathcal{A}
. Denote by
\mathfrak{A}
the
set
L^{\infty}(\mu_{\mathcal{A}})
of bounded
{\sigma^{-1}(\mathcal{B})}
-measurable
functions. The
*
-algebra
\mathfrak{A}
acts on
L^{2}(\mu)
by
multiplication operators: for every
f\in L^{2}(\mu)
and

\gamma\in\mathfrak{A}

f\longmapsto\gamma f=M_{\gamma}(f).

This formula defines a representation
\pi
of
\mathfrak{A}

in
L^{2}(\mu)
. Using the theorem about the decomposition of
non-degenerate representations into orthogonal cyclic
representations, we can write

(5.6)

L^{2}(\mu)=\bigoplus_{i\in\Lambda}\mathcal{H}_{i},\quad\pi=\bigoplus_{i\in\Lambda}\pi_{i}

where
\pi_{i}
is a cyclic representation and
\mathcal{H}_{i}
is
the closure of
\{\pi_{i}(\gamma)h_{i}:\gamma\in\mathfrak{A}\}
. The vectors
h_{i},i\in\Lambda
, are called cyclic.
The set of indexes
\Lambda
is countably infinite.

We will use the cyclic vectors
(h_{i})
to construct a
wavelet filter
\underline{m}=(m_{i})
satisfying the
conditions of Theorem
4.15
.

Lemma 5.6
.

There are functions
(g_{i})
such that the cyclic vectors

(m_{i}=h_{i}(g_{i}\circ\sigma))
for representations
of
\mathfrak{A}
have the property

(5.7)

S_{\sigma}^{*}(|m_{i}|^{2})=\mathbbm{1}.

Proof.

We note that for every function
\gamma\in\mathfrak{A}
there exists a function
g\in L^{\infty}(\mu)

such that
\gamma=g\circ\sigma
. Hence, if
h_{i}
is a cyclic vector
for a representation of
\mathfrak{A}
, then
m_{i}
is cyclic,
too.

We will determine the function
g_{i}
such that
m_{i}=h_{i}(g_{i}\circ\sigma)
satisfies the statement of the lemma. For this, we
compute

S^{*}_{\sigma}(|m_{i}|^{2})=S^{*}_{\sigma}(|h_{i}(g_{i}\circ\sigma)|^{2})=|g_{i}|^{2}S^{*}_{\sigma}(|h_{i}|^{2}),

and take
g_{i}
such that the above expression equals 1 a.e.
∎

For functions
f\in L^{2}(\mu)
, we define the operators

(5.8)

S_{i}(f)=m_{i}(f\circ\sigma)=M_{m_{i}}S_{\sigma}(f).

Lemma 5.7
.

Let the functions
(m_{i})
satisfy (
5.7
). Then the
operators
S_{i},i\in\Lambda
, are isometries satisfying
the property

(5.9)

S_{\sigma}^{*}(m_{i}\overline{m}_{j})=\delta_{ij},\quad i,j\in\Lambda.

Proof.

We first note that
S^{*}_{i}=S^{*}_{\sigma}M_{\overline{m}_{i}}
, and

S^{*}_{i}S_{i}=\mathbb{I}\ \ \Longleftrightarrow\ \ S_{\sigma}^{*}(|m_{i}|^{2})=\mathbbm{1}.

Next, we use the fact that cyclic representations, which are
defined by the distinct vectors
m_{i}
and
m_{j}
, are
mutually
orthogonal. Applying the fact that the transfer operator

S^{*}_{\sigma}
has the pull-out property, we compute, for any

\gamma_{1},\gamma_{2}\in\mathfrak{A}
,

\displaystyle\langle\gamma_{1}m_{i},\gamma_{2}m_{j}\rangle_{\mu}=

\displaystyle\langle(g_{1}\circ\sigma)\;m_{i},(g_{2}\circ\sigma)\;m_{j}\rangle_{\mu}

\displaystyle=

\displaystyle\langle(g_{1}\circ\sigma)m_{i}\overline{m}_{j},S_{\sigma}(g_{2})\rangle_{\mu}

\displaystyle=

\displaystyle\langle S^{*}_{\sigma}((g_{1}\circ\sigma)m_{i}\overline{m}_{j}),g_{2}\rangle_{\mu}

\displaystyle=

\displaystyle\langle g_{1}S^{*}_{\sigma}(m_{i}\overline{m}_{j}),g_{2}\rangle_{\mu}.

Hence, the inner product is zero if and only if
(
5.9
) holds.
∎

Theorem 5.8
.

Let
(m_{i}:i\in\Lambda)
be a set of cyclic vectors
satisfying
(
5.7
). Then
\underline{m}=(m_{i})
is a wavelet
filter if and only if
\sum_{i\in\Lambda}S^{*}_{i}S_{i}=\mathbb{I}
. In other words,
\underline{m}\in\mathfrak{M}
if
and only if the operators
S_{i}
are the generators of a
representation of the Cuntz algebra
\mathcal{O}_{|\Lambda|}
.

Proof.

To prove the theorem, we use the result of
Theorem (
4.15
). For this, we should check that

\{S_{i}:i\in\Lambda\}
are the operators satisfying conditions
(i) and (ii) of Theorem (
4.15
). Condition (i) is
proved in Lemma (
5.7
). To verify (ii), we
observe that, for any
f\in L^{2}(\mu)
and
i\in\Lambda
,

\mathbb{E}_{\sigma}(f\overline{m}_{i})m_{i}=S_{i}S_{i}^{*}(f).

Indeed,

\displaystyle\mathbb{E}_{\sigma}(f\overline{m}_{i})m_{i}=S_{i}S_{i}^{*}(f)=

\displaystyle S_{\sigma}S_{\sigma}^{*}(f\overline{m}_{i})m_{i}=S_{i}S_{i}^{*}(f)

\displaystyle=

\displaystyle S_{i}(S_{\sigma}^{*}M_{\overline{m}_{i}}(f))

\displaystyle=

\displaystyle S_{i}S_{i}^{*}(f).

It follows that
\sum_{i\in\Lambda}S^{*}_{i}S_{i}=\mathbb{I}
if and only if condition (ii) holds. This proves
the theorem.
∎

Corollary 5.9
.

Let
\sigma\in End(X,\mathcal{B},\mu)
where
\mu
is a
probability measure.
Let
(m_{i}:i\in\Lambda)
be a set of cyclic vectors
satisfying (
5.6
) and (
5.7
).
Then, for a.e.
x\in X
,

\sum_{i\in\Lambda}|m_{i}(x)|^{2}<\infty.

Proof.

The result follows from the fact that

\sum_{i\in\Lambda}||m_{i}||_{\mu}^{2}=1.

Indeed, this relation is obtained when the function

\mathbbm{1}(x)
is substituted into the cyclic
decomposition (
5.6
).
∎
