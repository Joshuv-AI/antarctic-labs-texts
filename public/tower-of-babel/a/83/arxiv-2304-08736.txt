Sparse sets that satisfy the Prime Number Theorem
Olivier Bordellès, Randell Heyman, Dion Nikolic

Abstract
For arbitrary real t > 1 t>1 we examine the set { ⌊ x / n t ⌋ : n ≤ x } \{\left\lfloor x/n^{t}\right\rfloor:n\leq x\} . Asymptotic formulas for the cardinality of this set and the number of primes in this set are given. The prime counting result uses an alternate Vaughan’s decomposition for the von Mangoldt function, with triple exponential sums instead of double exponential sums. These sets are the sparsest known sets that satisfy the prime number theorem, in the sense that the number of primes is asymptotically given by the cardinality of the set divided by the natural logarithm of the cardinality of the set.

Introduction

Let
x
and
n
be strictly positive integers throughout. The prime number theorem states that
\pi(x)\sim x/\log x
, where
\pi(x)
is the number of primes less than or equal to
x
. We can apply the prime number theorem to sets in the following way:
Let

S_{f,x}:=\{f(n):n\leq x\},

where we restrict
S_{f,x}
to those sets where
f
is positive integer valued and not piecewise defined. We will count the number of primes in these sets using

\pi\left(S_{f,x}\right):=\left|\{s\in S_{f,x}:s\text{ is prime}\}\right|.

Using this notation the prime number theorem can be restated as

\pi\left(S_{\mathrm{id},x}\right)\sim\frac{|S_{\mathrm{id},x}|}{\log|S_{\mathrm{id},x}|},

where
|*|
represents set cardinality and
\mathrm{id}
is the identity function.
We say a set
S_{f,x}

satisfies the prime number theorem
if

\pi\left(S_{f,x}\right)\sim\frac{|S_{f,x}|}{\log|S_{f,x}|}.

The authors are not aware of literature that focuses on sets that satisfy the prime number theorem. As prime numbers are an essential component of many cryptography protocols, it is conceivable that sets that satisfy the prime number theorem (particularly those less dense) may have applications.

To explore this further, define the

D_{f,x}:=\frac{|S_{f,x}|}{\max{S_{f,x}}-\min{S_{f,x}}}.

\lim_{x\rightarrow\infty}D_{f,x}/D_{g,x}=0

As mentioned above, the set

satisfies the prime number theorem. But it is not sparse.
In contrast, as implied from above,
D_{\left\lfloor x/n\right\rfloor,x}\sim 2x^{-1/2}
and is an example of a sparse set that satisfies the prime number theorem. This paper investigates other sparse sets that satisfy the prime number theorem.

Lemma 7
.

Let

Proof of Corollary
1

For the sets based on the Piatestski-Shapiro sequences we infer from
[
12
]
that

\pi(S_{\left\lfloor n^{c}\right\rfloor,x})\sim\frac{(x^{c})^{1/c}}{\log x^{c}}=\frac{x}{c\log x}.

Since
\alpha\geq 1
it follows that
\left\lfloor n^{c}\right\rfloor\neq\left\lfloor m^{c}\right\rfloor
for any
n\neq m
. Therefore

\frac{|S_{\left\lfloor n^{c}\right\rfloor,x}|}{\log|S_{\left\lfloor n^{c}\right\rfloor,x}|}\sim\frac{x}{\log x}\not\sim\pi(S_{\left\lfloor n^{c}\right\rfloor,x}).

For the sets based on the Beatty sequence we infer from
[
12
]
that

\pi(S_{\left\lfloor\alpha n+\beta\right\rfloor,x})\sim\frac{\alpha x+\beta}{\alpha\log(\alpha x+\beta)}\sim\frac{x}{\log x}.

Since
\alpha\geq 1
it follows that
\left\lfloor\alpha n+\beta\right\rfloor\neq\left\lfloor\alpha m+\beta\right\rfloor
for any
n\neq m
. Therefore

\frac{|S_{\left\lfloor\alpha n+\beta\right\rfloor,x}|}{\log|S_{\left\lfloor\alpha n+\beta\right\rfloor,x}|}\sim\frac{x}{\log x}\sim\pi\left(S_{\left\lfloor\alpha n+\beta\right\rfloor,x}\right).

The density is given by

\frac{|S_{\left\lfloor\alpha n+\beta\right\rfloor,x}|}{\max{S_{\left\lfloor\alpha n+\beta\right\rfloor,x}}-\min{S_{S_{\left\lfloor\alpha n+\beta\right\rfloor,x}}}}=\frac{x}{\left\lfloor\alpha x+\beta\right\rfloor-\left\lfloor\alpha+\beta\right\rfloor},

which is asymptotically
\frac{1}{\alpha}
,
concluding the proof.
