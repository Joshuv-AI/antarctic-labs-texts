On minimal representations of shallow ReLU networks
Steffen Dereich, Sebastian Kassing

Abstract
. The realization function of a shallow ReLU network is a continuous and piecewise affine function f : ℝ d → ℝ f:{\mathbb{R}}^{d}\to{\mathbb{R}} , where the domain ℝ d {\mathbb{R}}^{d} is partitioned by a set of n n hyperplanes into cells on which f f is affine. We show that the minimal representation for f f uses either n n , n + 1 n+1 or n + 2 n+2 neurons and we characterize each of the three cases. In the particular case, where the input layer is one-dimensional, minimal representations always use at most n + 1 n+1 neurons but in all higher dimensional settings there are functions for which n + 2 n+2 neurons are needed. Then we show that the set of minimal networks representing f f forms a C ∞ C^{\infty} -submanifold M M and we derive the dimension and the number of connected components of M M . Additionally, we give a criterion for the hyperplanes that guarantees that all continuous, piecewise affine functions are realization functions of appropriate ReLU networks.

1.
Introduction

Standard convergence results for Stochastic Gradient Descent schemes often use strong convexity of the loss function around an isolated minimum. However, a common loss function in neural network applications depends exclusively on the realization function generated by the weights and biases and there exists a non-trivial set of parametrizations generating the same realization function. In practice, the most frequently used activation function is the ReLU function
\sigma(x)=\max(x,0)
. The positive homogeneity of ReLU leads to many redundancies in the loss landscape (
[
PTS20
]
). As is well known (see for instance
[
QZX20
]
) one can restrict attention to networks where the vector of weights associated to each hidden neuron have uniform norm without reducing the set of representable functions. Additionally,
[
Coo18
]
showed that in the overparameterized regime (more parameters in the network architecture than data points to fit), under the assumption that the network is able to fit the data points and the activation function
\sigma
is smooth, the set of parameters
P\subset{\mathbb{R}}^{n}
achieving zero training loss forms a
(n-p)
-dimensional smooth submanifold for almost all input data
S=((x_{i},y_{i}))_{1=1,\dots,p}\subset{\mathbb{R}}^{(d+1)\times p}
with fixed
p\in{\mathbb{N}}
. Moreover, for every point
x
in the manifold the Hessian of the loss function
\text{Hess}\,F(x)
has
p
positive eigenvalues and
n-p
eigenvalues equal to
0
.

[
FGJ20
]
and
[
DK19
]
established convergence rates for SGD and
[
MR20
]
for the Langevin diffusion under these assumptions for the critical locus. See also
[
Woj21
]
for results on SGD in continuous time in the case where the perturbation scales with the value of the loss function.

Nonetheless, general networks do not meet this assumption. For an easy counterexample, we try to approximate the zero function
f:{\mathbb{R}}\to{\mathbb{R}};x\mapsto 0
with a neural network using one hidden-layer with one neuron.
Such a network
\mathbb{W}
with weights
w_{1,1}^{1},w_{1,1}^{2}
and biases
b_{1}^{1},b_{1}^{2}
responds to an input
x
via

\mathfrak{N}^{\mathbb{W}}(x)=w_{1,1}^{2}\max(w_{1,1}^{1}x+b_{1}^{1},0)+b_{1}^{2}.

Now, the equation
\mathfrak{N}^{\mathbb{W}}(x)\equiv 0
is solved by the set

\bigl\{(w_{1,1}^{1},w_{1,1}^{2},b_{1}^{1},b_{1}^{2})\in{\mathbb{R}}^{4}:\bigl(w_{1,1}^{1}=0\vee w_{1,1}^{2}=0\bigr),b_{1}^{2}=-w_{1,1}^{2}b_{1}^{1}\bigr\}

which around
(0,0,0,0)
forms not even locally a submanifold of
{\mathbb{R}}^{4}
.

One key to solving this problem is minimality. We classify the set of parametrizations leading to the same realization function in shallow ReLU networks under the assumption that the network is minimal, meaning that there exists no neural network with less neurons in the hidden-layer which admits the same realization function, and show that the set of minimal parametrizations forms a smooth submanifold. We distinguish between three different scenarios and derive the dimension and the number of connected components in each of the situations.

The idea of minimal networks has been used by
[
Sus92
]
to describe the set of configurations with the same structure and realization function for real-valued neural networks with one hidden-layer and activation function
\sigma=\tanh
. Therein, the point-symmetry of the activation function is used to state that the set of minimal networks with the same input-output map is the union of discrete points generated by a finite group of transformations. This result has been generalized in
[
Nit03
]
for complex-valued neural networks without bias and in
[
Kob10
]
for general complex-valued networks with hyperbolic tangent activation. In the present work the transformation group is not countable, due to the positive-homogeneity of the ReLU function, leading to a rich set of configurations.

In a similar but independent approach,
[
CJR21
]
characterized the critical points of the loss function in the task of approaching affine functions on an interval with respect to the
L^{2}
-norm. However, we consider all functions that are representable by neural networks, i.e. piecewise affine functions admitting some additional properties, and allow the input dimension to be arbitrarily large.

The second main result of this article concerns the class of affine functions that are representable by shallow ReLU nets. We show that all continuous and piecewise affine functions can be constructed by a neural network if the hyperplanes which partition the space into cells on which the function acts affine (the
breaklines
) do not intersect in an artificial way (see further Theorem
4.3
). Moreover, we show that for a fixed number of hidden neurons, the set of weights and biases that lead to those piecewise affine realizations not covered by Theorem
4.3
are a nullset with respect to the Lebesgue-measure. Therefore, the set of piecewise affine functions satisfying the assumptions of Theorem
4.3
have universal approximation properties (
[
LLPS93
]
,
[
Hor93
]
).

There are a lot of results concerning the approximation power of shallow nets (e.g.
[
Cyb89
]
,
[
HSW89
]
,
[
LLPS93
]
and
[
Hor93
]
).
[
Han19
]
shows that neural nets with arbitrary depths are able to approximate every continuous function
f:[0,1]^{d}\to{\mathbb{R}}
, if there are at least
d+2
neurons on each hidden layer. Further,
[
ABMM18
]
showed that every piecewise linear function
f:{\mathbb{R}}^{d}\to{\mathbb{R}}
can be represented by a ReLU neural network with at most
\lceil\log_{2}(n+1)\rceil+1
depth and for every piecewise linear, univariate function
f:{\mathbb{R}}\to{\mathbb{R}}
with
n
breakpoints there exists a net having one hidden-layer with
n+1
neurons that represents
f
. We give sufficient conditions on the piecewise affine function in order to be representable by a shallow neural net and generalize their second result for multivariate functions
f:{\mathbb{R}}^{d}\to{\mathbb{R}}
. We show that if
f
has
n
breaklines and is representable by a shallow neural net there exists a net with
n+2
neurons on the hidden layer that represents
f
. Further, we give algebraic conditions on
f
that are equivalent to the fact that
f
is representable by a neural net with
n
hidden neurons (resp.
n+1
hidden neurons) and characterize the manifold of minimal representations for
f
depending on the minimal number of neurons.

2.
Shallow ReLU networks

In this section we give the basic definitions and notions of a ReLU network with one hidden layer. We denote by
d_{0}\in{\mathbb{N}}
the input dimension, by
d_{1}\in{\mathbb{N}}
the numbers of neurons in the hidden layer and by
(\cdot)_{+}:{\mathbb{R}}\to{\mathbb{R}}
the ReLU activation function, i.e.
(x)_{+}=\max(x,0)
, for all
x\in{\mathbb{R}}
. For simplicity we let the output dimension
d_{2}=1
.
The configuration of such a neural network is described by a tuple

\mathbb{W}=(W^{1},b^{1},W^{2},b^{2})\in{\mathbb{R}}^{d_{1}\times d_{0}}\times{\mathbb{R}}^{d_{1}}\times{\mathbb{R}}^{1\times d_{1}}\times{\mathbb{R}}=:\mathcal{W}^{d_{0},d_{1},1},

where, for
i=1,2
, we always write

W^{i}=(w_{j,k}^{i})_{\begin{subarray}{c}j=1,\dots,d_{i}\\
k=1,\dots,d_{i-1}\end{subarray}}\quad\text{ and }\quad b^{i}=(b_{1}^{i},\dots,b_{d_{i}}^{i})^{\dagger},

where
†
denotes the transpose of a matrix or a vector.
Moreover, for
j=1,\dots,d_{1}
, we write
w_{j}^{1}=(w_{j,1}^{1},\dots,w_{j,d_{0}}^{1})^{\dagger}
and
w_{j}^{2}=w_{1,j}^{2}
.

We often refer to a configuration of a neural network as the (
neural
)
network

\mathbb{W}
. A configuration
\mathbb{W}\in\mathcal{W}^{d_{0},d_{1},1}
describes a function
\mathfrak{N}^{\mathbb{W}}:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}}
via

(1)

\displaystyle\mathfrak{N}^{\mathbb{W}}(x)=b^{2}+\sum_{j=1}^{d_{1}}w_{j}^{2}\max\Bigl(\sum_{i=1}^{d_{0}}w_{j,i}^{1}x_{i}+b_{j}^{1},0\Bigr).

We call
\mathfrak{N}^{\mathbb{W}}

realization function
or
response
. Further, we call
f\in\mathcal{F}=\bigcup_{d_{1}\in{\mathbb{N}}}\{\mathfrak{N}^{\mathbb{W}}:\mathbb{W}\in\mathcal{W}^{d_{0},d_{1},1}\}
a
representable function
.

The above network representation has a lot of redundancies. Moreover, there are more intuitive geometric descriptions of the response function. To understand this we first introduce an orientation on
{\mathbb{R}}^{d_{0}}
. The explicit choice will have no relevance.

We fix a convex cone
\mathcal{O}_{+}\subset{\mathbb{R}}^{d_{0}}\backslash\{0\}
such that for
\mathcal{O}_{-}=-\mathcal{O}_{+}
one has
{\mathbb{R}}^{d_{0}}\backslash\{0\}=\mathcal{O}_{+}\dot{\cup}\,\mathcal{O}_{-}
and we call the vectors in
\mathcal{O}_{+}
positively oriented and the vectors in
\mathcal{O}_{-}
negatively oriented.
\mathrm{orient}:{\mathbb{R}}^{d_{0}}\backslash\{0\}\to\{\pm 1\}
denotes the mapping that assigns
x
its orientation
\mathrm{orient}(x)
.

We call a network
\mathbb{W}=\mathcal{W}^{d_{0},d_{1},1}

non-degenerate
iff for all
j=1,\dots,d_{1}
,
w_{j}^{2}w_{j}^{1}\not=0
. Now we will give a different description of the response of a non-degenerate network
\mathbb{W}
:
we say that the neuron
j\in\{1,\dots,d_{1}\}
has

•

positive normal
{\displaystyle\mathfrak{n}_{j}=\frac{\mathrm{orient}(w_{j}^{1})}{|w_{j}^{1}|}w_{j}^{1}\in\mathcal{O}_{+}^{1}:=\{x\in\mathcal{O}_{+}:|x|=1\}}
,

•

offset
o_{j}=-\frac{\mathrm{orient}(w_{j}^{1})}{|w_{j}^{1}|}b_{j}^{1}\in{\mathbb{R}}
,

•

kink
\Delta_{j}=|w_{j}^{1}|w_{j}^{2}\in{\mathbb{R}}\backslash\{0\}
and

•

orientation
\sigma_{j}=\mathrm{orient}(w_{j}^{1})\in\{\pm 1\}
.

For
d_{1}\in{\mathbb{N}}
we call
(\mathfrak{n},o,\Delta,\sigma,b^{2})
with
\mathfrak{n}=(\mathfrak{n}_{1},\dots,\mathfrak{n}_{d_{1}})
, etc. the
effective tuple for the neurons
1,\dots d_{1}
and write
\mathcal{E}_{d_{1}}
for the set of all effective tuples using
d_{1}
neurons.

First we note that the response of a network can be represented in terms of the previous quantities:

\displaystyle\mathfrak{N}^{\mathbb{W}}(x)

\displaystyle=b^{2}+\sum_{j=1}^{d_{1}}w^{2}_{j}(w^{1}_{j}\cdot x+b_{j}^{1})_{+}=b^{2}+\sum_{j=1}^{d_{1}}\Delta_{j}\Bigl(\frac{1}{|w_{j}^{1}|}w^{1}_{j}\cdot x+\frac{1}{|w_{j}^{1}|}b_{j}^{1}\Bigr)_{+}

\displaystyle=b^{2}+\sum_{j=1}^{d_{1}}\Delta_{j}\bigl(\sigma_{j}(\mathfrak{n}_{j}\cdot x-o_{j})\bigr)_{+},

where
\cdot
denotes the scalar product.
Conversely, for arbitrary positive normals
\mathfrak{n}_{1},\dots,\mathfrak{n}_{d_{1}}\in\mathcal{O}_{+}^{1}
, offsets
o_{1},\dots,o_{d_{1}}\in{\mathbb{R}}
, kinks
\Delta_{1},\dots,\Delta_{d_{1}}\in{\mathbb{R}}\backslash\{0\}
, orientations
\sigma_{1},\dots,\sigma_{d_{1}}\in\{\pm 1\}
and
b^{2}\in{\mathbb{R}}
the following mapping is a
C^{\infty}
-bijection onto all networks
\mathbb{W}
having the latter features:

(2)

\displaystyle\psi:(0,\infty)^{d_{1}}\to\mathcal{W}^{d_{0},d_{1},1}\;;\;a\mapsto(\tilde{W}^{1},\tilde{b}^{1},\tilde{W}^{2},b^{2}),

where

\tilde{W}^{1}=(\sigma_{1}a_{1}\mathfrak{n}_{1},\dots,\sigma_{d_{1}}a_{d_{1}}\mathfrak{n}_{d_{1}})^{\dagger}\;,\;\tilde{b}^{1}=(-\sigma_{1}a_{1}o_{1},\dots,-\sigma_{d_{1}}a_{d_{1}}o_{d_{1}})

and

\tilde{W}^{2}=\Bigl(\frac{\Delta_{1}}{a_{1}},\dots,\frac{\Delta_{d_{1}}}{a_{d_{1}}}\Bigr).

Thus, for
d_{1}\in{\mathbb{N}}
and an effective tuple
(\mathfrak{n},o,\Delta,\sigma,b^{2})
the set of neural networks
\mathbb{W}\in\mathcal{W}^{d_{0},d_{1},1}
having the effective tuple
(\mathfrak{n},o,\Delta,\sigma,b^{2})
forms a
d_{1}
-dimensional
C^{\infty}
-manifold with one connected component.

With slight misuse of notation we write

\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,b^{2}}:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}},\,x\mapsto b^{2}+\sum_{j=1}^{d_{1}}\Delta_{j}\bigl(\sigma_{j}(\mathfrak{n}_{j}\cdot x-o_{j})\bigr)_{+}

and briefly write
\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma}=\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,0}
and
\mathfrak{N}^{\mathfrak{n},o,\Delta}=\mathfrak{N}^{\mathfrak{n},o,\Delta,(1,\dots,1)}
. Although, the tuple
(\mathfrak{n},\Delta,\sigma,o,b^{2})
does not uniquely describe a neural network, it describes a response function uniquely and thus we will speak of the neural network with
effective
tuple
(\mathfrak{n},o,\Delta,\sigma,b^{2})
.
We note that each summand of
\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,b^{2}}
has the breakline

P_{j}=\bigl\{x\in{\mathbb{R}}^{d_{0}}:\mathfrak{n}_{j}\cdot x=o_{j}\bigr\}

and we call

A_{j}=\{x:\sigma_{j}(\mathfrak{n}_{j}\cdot x-o_{j})>0\}

the domain of activity of the
j
th neuron. With slight misuse of notation we also call
(\mathfrak{n}_{j},o_{j})

breakline
of the
j
th neuron. Note that in the case where
\sigma_{j}=1
,
A_{j}
is the part on the positive side of the hyperplane
P_{j}
and in the case where
\sigma_{j}=-1
,
A_{j}
is the negative side of the hyperplane.
By construction, we have

\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,b^{2}}(x)=b^{2}+\sum_{j=1}^{d_{1}}1\hskip-2.78857pt\mathrm{l}_{A_{j}}(x)\bigl(\sigma_{j}\Delta_{j}(\mathfrak{n}_{j}\cdot x-o_{j})\bigr).

Outside the breaklines the function
\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,b^{2}}
is differentiable with

D\mathfrak{N}^{\mathfrak{n},o,\Delta,\sigma,b^{2}}(x)=\sum_{j=1}^{d_{1}}1\hskip-2.78857pt\mathrm{l}_{A_{j}}(x)\sigma_{j}\Delta_{j}\mathfrak{n}_{j}.

Note that for each summand along a breakline the difference of the differential on the positive and negative side equals
\Delta_{j}\mathfrak{n}_{j}
.

3.
Minimal representations of shallow ReLU nets

In this section, we fix a representable function
f\in\mathcal{F}
and derive the necessary number of neurons in the hidden layer in order to find a neural network having response
f
. Moreover, we classify the set of minimal networks with realization function
f
.
We start with the following auxiliary result on representable functions.

Lemma 3.1
.

Let
f\in\mathcal{F}=\bigcup_{d_{1}\in{\mathbb{N}}}\{\mathfrak{N}^{\mathbb{W}}:\mathbb{W}\in\mathcal{W}^{d_{0},d_{1},1}\}
.

(i)

The function
f
is affine or there exist (up to reordering) unique pairwise different breaklines

in the sense that there exist unique

and

with

f(x)=\mathfrak{N}^{(\mathfrak{n},o,\Delta)}(x)+a\cdot x+b,\text{ \ for all }x\in{\mathbb{R}}^{d_{0}}.

(ii)

If
f
is non-affine, then for every
(\sigma_{j})\in\{\pm 1\}^{n}
, one has

(3)

\displaystyle f(x)=\mathfrak{N}^{(\mathfrak{n},o,\Delta,\sigma)}(x)+a_{\sigma}\cdot x+b_{\sigma},

where

a_{\sigma}=a+\sum_{j:\sigma_{j}=-1}\Delta_{j}\mathfrak{n}_{j}\text{ \ and \ }b_{\sigma}=b-\sum_{j:\sigma_{j}=-1}\Delta_{j}o_{j}.

(iii)

Let
d_{1}\in{\mathbb{N}}
and
\mathbb{W}\in\mathcal{W}^{d_{0},d_{1},1}
be a network with breaklines

The response
\mathfrak{N}^{\mathbb{W}}
agrees with

iff for every breakline

of

(4)

\displaystyle\sum_{j:(\tilde{\mathfrak{n}}_{j},\tilde{o}_{j})=S}\tilde{\Delta}_{j}=\begin{cases}\Delta_{j},&\text{ if $S$ is a breakline of $f$},\\

In particular, a representation

(i): Let

Theorem 3.2
.

Let

be non-affine and denote by

(ii)

If the set
J
is empty and for a
\mathfrak{m}\in{\mathcal{N}}
the set
J(\mathfrak{m})
is not empty, then the set of all networks
\mathbb{W}\in\mathcal{W}^{d_{0},n+1,1}
with response
f
forms a
n+1
-dimensional
C^{\infty}
-manifold having

(n+1)!\cdot\Bigl(\sum\limits_{n\in{\mathcal{N}}:J(\mathfrak{n})\neq\emptyset}\bigl|\bigl\{(\sigma,j)\in J(\mathfrak{n})\times\mathbb{I}(\mathfrak{n}):\sigma_{j}=1\bigr\}\bigr|\Bigr)

connected components.

(iii)

If for every
\mathfrak{n},\mathfrak{n}^{\prime}\in{\mathcal{N}}
,
J(\mathfrak{n},\mathfrak{n}^{\prime})=\emptyset
, then the set of all networks
\mathbb{W}\in\mathcal{W}^{d_{0},n+2,1}
with response
f
forms a
n+3
-dimensional
C^{\infty}
-manifold having
(n+2)!2^{n}
connected components.

If, however, for every
\mathfrak{n}\in{\mathcal{N}}
,
J(\mathfrak{n})=\emptyset
, but there exist
\mathfrak{n},\mathfrak{n}^{\prime}\in{\mathcal{N}}
with
J(\mathfrak{n},\mathfrak{n}^{\prime})\neq\emptyset
then the set of all networks
\mathbb{W}\in\mathcal{W}^{d_{0},n+2,1}
with response
f
forms a disjoint union of two different
C^{\infty}
-manifolds: One of dimension
n+3
having
(n+2)!\cdot 2^{n}
connected components and one of dimension
n+2
having

(n+2)!\cdot\Bigl(\sum\limits_{\mathfrak{n},\mathfrak{n}^{\prime}\in{\mathcal{N}}:J(\mathfrak{n},\mathfrak{n}^{\prime})\not=\emptyset,\mathfrak{n}<\mathfrak{n}^{\prime}}\bigl|\bigl\{(\sigma,j_{1},j_{2})\in J(\mathfrak{n},\mathfrak{n}^{\prime})\times\mathbb{I}(\mathfrak{n})\times\mathbb{I}(\mathfrak{n}^{\prime}):\sigma_{j_{1}}=\sigma_{j_{2}}=1\bigr\}\bigr|\Bigr)

connected components.

4.
Representability of piecewise affine functions via shallow ReLU networks

In this section, we discuss which continuous, piecewise affine functions

f:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}}
can be represented as response of a neural network.

Definition 4.1
.

Let
f:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}}
be a continuous function,
n\in{\mathbb{N}}
and
S_{1},\dots,S_{n}
be distinct hyperplanes in
{\mathbb{R}}^{d_{0}}
. We call
f

piecewise affine with breaklines
S_{1},\dots,S_{n}
if
f
is affine on each connected component of
{\mathbb{R}}^{d_{0}}\setminus(S_{1}\cup\ldots\cup S_{n})
.
We call the connected components of
{\mathbb{R}}^{d_{0}}\setminus(S_{1}\cup\ldots\cup S_{n})

cells
of the breaklines
S_{1},\dots,S_{n}
.

As a first result, we note that for
d_{0}>1
there are hyperplanes
S_{1},\dots,S_{n}
and piecewise affine functions
f
with breaklines
S_{1},\dots,S_{n}
that cannot be represented as realization function of a shallow network.

Example 4.2

(A piecewise affine function that is not representable by a shallow network)
.

Consider the piecewise affine function

f(x,y)=\begin{cases}0,&\text{ if }|x|\geq|y|\text{ and }\mathrm{sign}(x)=-\mathrm{sign}(y)\text{ or }y=0,\\
y,&\text{ if }\mathrm{sign}(x)=\mathrm{sign}(y),\\
x+y,&\text{ else.}\end{cases}

Assume that there exist
d_{1}\in{\mathbb{N}}
and
\mathbb{W}\in\mathcal{W}^{2,d_{1},1}
with
\mathfrak{N}^{\mathbb{W}}=f
.
As consequence, see (
1
), the function

{\mathbb{R}}\setminus\{0\}\ni x\mapsto\lim\limits_{y\searrow 0}\nabla f(x,y)-\lim\limits_{y\nearrow 0}\nabla f(x,y)

needs to be constant. But

\lim\limits_{y\searrow 0}\nabla f(-1,y)-\lim\limits_{y\nearrow 0}\nabla f(-1,y)=\begin{pmatrix}0\\
-1\end{pmatrix}\neq\begin{pmatrix}0\\
1\end{pmatrix}=\lim\limits_{y\searrow 0}\nabla f(1,y)-\lim\limits_{y\nearrow 0}\nabla f(1,y)

yields a contradiction and
f
cannot be represented as response of a network.

We note that in the example the function has three breaklines that all meet in zero. As the following lemma shows a function is representable, if all breaklines having an arbitrarily fixed point in common have linear independent normals.
Obviously, this property does not hold in the counterexample. In particular, we note that for the next lemma to hold one at least needs that there are at most
d_{0}
breaklines that have an arbitrarily fixed point in common.

Theorem 4.3
.

Let
f:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}}
be a continuous and piecewise affine function with breaklines
S_{1},\dots S_{n}
. If
for all
x\in{\mathbb{R}}^{d_{0}}
with
\#\rho(x)\neq 0
we have

(8)

\displaystyle\dim\Bigl(\bigcap\limits_{j\in\rho(x)}S_{j}\Bigr)=d_{0}-\#\rho(x),

where
\rho(x):=\{j\in\{1,\dots,n\}:x\in S_{j}\}
,
then there exists a network
\mathbb{W}\in\mathcal{W}^{d_{0},n+2,1}
with

\mathfrak{N}^{\mathbb{W}}=f.

Remark 4.4
.

Let
S_{1},\dots,S_{n}
be hyperplanes in
{\mathbb{R}}^{d_{0}}
. We note that the hyperplanes
S_{1},\dots,S_{n}
do not satisfy assumption (
8
) of the latter theorem iff there are indices
1\leq j_{1}<\ldots<j_{k}\leq n
with
\emptyset\not=S_{j_{1}}\cap\ldots\cap S_{j_{k-1}}\subset S_{j_{k}}
.

We note that in the case where
S_{1},\dots,S_{n}
denote the breaklines of the hidden neurons of a network
\mathbb{W}\in\mathcal{W}^{d_{0},n,1}
we get that for Lebesgue almost-every choice of the network
\mathbb{W}
the breaklines satisfy assumption (
8
) of the latter theorem. (Indeed, one even has that for Lebesgue almost-every
\mathbb{W}
, the function
\#\rho
is bounded by two.)

Recalling that the the mapping
\mathbb{W}\mapsto\mathfrak{N}^{\mathbb{W}}
maps continuously into the space of continuous functions on a compact set endowed with uniform convergence we conclude that the universal approximation property (
[
LLPS93
]
,
[
Hor93
]
) remains true when restricting to shallow networks for which the breaklines of the hidden neurons satisfy assumption (
8
).

Proof.

Let
f:{\mathbb{R}}^{d_{0}}\to{\mathbb{R}}
be a piecewise affine function with breaklines
S_{1},\dots,S_{n}
satisfying (
8
). Again we use the standard representation for the hyperplanes
S_{1},\dots,S_{n}
and denote by
\mathfrak{n}_{1},\dots,\mathfrak{n}_{n}
positively oriented normal vectors and by
o_{1},\dots,o_{n}\in{\mathbb{R}}
offsets such that for every
k=1,\dots,n

S_{k}=\{x\in{\mathbb{R}}^{d_{0}}:\mathfrak{n}_{k}\cdot x=o_{k}\}.

Further, for
\sigma=(\sigma_{i})_{1\leq i\leq n}\in\{-1,1\}^{n}
we let

\mathcal{C}(\sigma)=\{x\in{\mathbb{R}}^{d_{0}}:\sigma_{k}(\mathfrak{n}_{k}\cdot x)>\sigma_{k}o_{k}\text{ for all }k=1,\dots,n\}.

Note that whenever
\mathcal{C}(\sigma)
is not empty it is a cell. Moreover, every cell admits such a representation. On a cell
\mathcal{C}(\sigma)
the gradient of
f
is constant and we denote this constant by
\nabla f_{\sigma}
.

First, we show that for a cell
\mathcal{C}(\sigma)
,
x\in\overline{\mathcal{C}(\sigma)}
and
\bar{\sigma}\in\{\pm 1\}^{n}
with
\bar{\sigma}_{k}=\sigma_{k}
for all
k\in\rho(x)^{c}
one has that
\mathcal{C}(\bar{\sigma})
is a cell with
x\in\overline{\mathcal{C}(\bar{\sigma})}
. If
\rho(x)=\emptyset
there is nothing to show and if
\rho(x)\neq\emptyset
we get with assumption (
8
) that

\dim\Bigl(\bigcap\limits_{j\in\rho(x)}S_{j}\Bigr)=d_{0}-\#\rho(x)

so that the family
(\mathfrak{n}_{j}:j\in\rho(x))
is linearly independent. Therefore, the matrix

M=(\mathfrak{n}_{j})_{j\in\rho(x)}\in{\mathbb{R}}^{n\times\rho(x)}

has full rank and its adjoint
M^{\dagger}
is surjective. Now let
\bar{\sigma}\in\{\pm 1\}^{n}
with
\bar{\sigma}_{k}=\sigma_{k}
for all
k\in\rho(x)^{c}
and pick
y\in{\mathbb{R}}^{n}
with

M^{\dagger}y=(\bar{\sigma}_{j})_{j\in\rho(x)}.

We show that for all sufficiently small
\varepsilon>0
,
z_{\varepsilon}=x+\varepsilon y
lies in
\mathcal{C}(\bar{\sigma})
. Indeed, for
k\in\rho(x)^{c}
one has

\bar{\sigma}_{k}(\mathfrak{n}_{k}\cdot x)>\bar{\sigma}_{k}o_{k}

and by continuity, the inequality remains true for
z_{\varepsilon}
in place of
x
as long as
\varepsilon
is sufficiently small. Moreover, for
k\in\rho(x)
one has

\bar{\sigma}_{k}(\mathfrak{n}_{k}\cdot z_{\varepsilon})=\bar{\sigma}_{k}\bigl(\underbrace{(\mathfrak{n}_{k}\cdot x)}_{=o_{k}}+\varepsilon\underbrace{(\mathfrak{n}_{k}\cdot y)}_{(M^{\dagger}y)_{k}=\bar{\sigma}_{k}}\bigr)>\bar{\sigma}_{k}o_{k}.

Hence, for small
\varepsilon>0
, one has
z_{\varepsilon}\in\mathcal{C}(\bar{\sigma})
.

We will also consider the reduced system, where we omit the last constraint and set for
\tau\in\{\pm 1\}^{n-1}

\mathcal{C}^{\prime}(\tau)=\{x\in{\mathbb{R}}^{d_{0}}:\tau_{k}(\mathfrak{n}_{k}\cdot x)>\tau_{k}o_{k}\text{ for all }k=1,\dots,n-1\}.

We call
\mathcal{C}^{\prime}(\tau)
a cell of the reduced system, if it is non-empty.

Suppose that
\mathcal{C}^{\prime}(\tau)
is a cell that intersects
S_{n}
. Since
\mathcal{C}^{\prime}(\tau)
is an open set there exists an
x\in S_{n}
which is also an element of
\overline{\mathcal{C}(\tau,1)}
and
\overline{\mathcal{C}(\tau,-1)}
. In particular, both are cells and we set

Df_{\tau}=\nabla f_{(\tau,1)}-\nabla f_{(\tau,-1)}.

We show that for a cell
\mathcal{C}^{\prime}(\tau)
of the reduced system,
x\in\overline{\mathcal{C}^{\prime}(\tau)}\cap S_{k}\cap S_{n}
with
k\in\{1,\dots,n-1\}
and
\bar{\tau}=(1-21\hskip-2.78857pt\mathrm{l}_{\{k\}})\tau
(the orientations one obtains when flipping the
k
th orientation) one has

Df_{\bar{\tau}}=Df_{\tau}.

First, we note that for every vector
w
in the tangent space of
S_{n}
we have

\nabla f_{\tau,1}(w)=\nabla f_{\tau,-1}(w)\text{ \ and \ }\nabla f_{\bar{\tau},1}(w)=\nabla f_{\bar{\tau},-1}(w),

since
f
is differentiable in the
w
-direction on
S_{n}\cap\mathcal{C}^{\prime}(b)
(resp.
S_{n}\cap\mathcal{C}^{\prime}(\bar{b}))
and the differential agrees in that direction with the one on the positive and negative side of
S_{n}
. This entails that

Df_{\tau}(w)=0=Df_{\bar{\tau}}(w).

For the same reason we have for every
w^{\prime}
in the tangential direction of
S_{k}
that

\nabla f_{\bar{\tau},1}(w^{\prime})=\nabla f_{\tau,1}(w^{\prime})\text{ \ and \ }\nabla f_{\bar{\tau},-1}(w^{\prime})=\nabla f_{\tau,-1}(w^{\prime})

and again we get that

Df_{\bar{\tau}}(w^{\prime})=\nabla f_{\bar{\tau},1}(w^{\prime})-\nabla f_{\bar{\tau},-1}(w^{\prime})=\nabla f_{\tau,1}(w^{\prime})-\nabla f_{\tau,-1}(w^{\prime})=Df_{\tau}(w^{\prime}).

By assumption,
S_{k}
and
S_{n}
are not parallel hyperplanes so that we obtain with linearity that
Df_{\bar{\tau}}=Df_{\tau}
.

In the next step we deduce that for every cell
\mathcal{C}^{\prime}(\tau)
that intersects
S_{n}
one has that
Df_{\tau}
does not depend on the choice of
\tau
. To see this we let
\mathcal{C}^{\prime}(\tau_{1})
and
\mathcal{C}^{\prime}(\tau_{2})
be two cells of the reduced system that intersect
S_{n}
, pick
x_{1}\in\mathcal{C}^{\prime}(\tau_{1})\cap S_{n}
and
x_{2}\in\mathcal{C}^{\prime}(\tau_{2})\cap S_{n}
and consider the path
\gamma:[0,1]\to S_{n}
given by

\gamma(t)=tx_{2}+(1-t)x_{1}.

By definition the path does not lie in one of the hyperplanes
S_{1},\dots,S_{n-1}
and there are finitely many times
0<t_{1}<\ldots<t_{\ell}<1
at which the path switches cells of the reduced system. For
k=0,\dots,\ell
, we denote by
\mathcal{C}^{\prime}(\tilde{\tau}_{k})
the cell that is visited by the path on the time interval
(t_{k},t_{k+1})
where
t_{0}=0
and
t_{\ell+1}=1
. We note that in
\tilde{\tau}_{k-1}
and
\tilde{\tau}_{k}
all components in
\rho(\gamma(t_{k}))^{c}
agree for
k=1,\dots,\ell
and it suffices to show that for each
k=1,\dots,\ell
,
Df_{\tilde{\tau}_{k}}=Df_{\tilde{\tau}_{k-1}}
.
This is obtained by applying the property that
\tilde{\tau}_{k}
can be obtained from
\tilde{\tau}_{k-1}
by finitely many flips of single orientations as analyzed in the previous step. This yields that indeed
Df_{\tau_{2}}=Df_{\tau_{1}}
.

It remains to represent
f
as a neural network. As we observed for every cell
\mathcal{C}^{\prime}(\tau)
of the reduced system that intersects
S_{n}
, the value
\Delta_{n}:=Df_{\tau}
is the same. Note that

f^{n-1}(x)=f(x)-\Delta_{n}(\mathfrak{n}_{n}\cdot x-o_{n})_{+}

has breaklines
S_{1},\dots,S_{n}
and for every cell
\mathcal{C}^{\prime}(\tau)
of the reduced system that intersects
S_{n}
one has

Df^{n-1}_{\tau}=0.

Consequently,
f^{n-1}
is affine on the cells of the reduced equation and, in particular, it has
breaklines
S_{1},\dots,S_{n-1}
. Iteration of the argument yields
\Delta_{1},\dots,\Delta_{n}\in{\mathbb{R}}
such that

f(x)-\sum_{k=1}^{n}\Delta_{k}(\mathfrak{n}_{k}\cdot x-o_{k})_{+}

has no breaklines meaning that it is affine. Since every affine function can be represented with two neurons there exists a normal vector
\mathfrak{n}_{n+1}=\mathfrak{n}_{n+2}
, kinks
\Delta_{n+1}=-\Delta_{n+2}
and
b^{2}\in{\mathbb{R}}
such that for
o_{n+1}=o_{n+2}=0
, one has

f={\mathcal{N}}^{\mathfrak{n},o,\Delta,(1,\dots,1,-1),b^{2}}.

Thus we constructed an effective network with
n+2
neurons that represents
f
.
