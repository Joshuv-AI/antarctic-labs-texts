Multiplicity distribution of dipoles in QCD from Le, Mueller and Munier equation
Eugene Levin

Abstract
In this paper we derived in QCD the BFKL linear, inhomogeneous equation for the factorial moments of multiplicity distribution ( M k M_{k} ) from LMM equation. In particular, the equation for the average multiplicity of the color-singlet dipoles ( N N ) turns out to be the homogeneous BFKL while M k ∝ N k M_{k}\,\,\propto\,\,N^{k} at small x x . Second, using the diffusion approximation for the BFKL kernel we show that the factorial moments are equal to: M k = k ! ​ N ​ ( N − 1 ) k − 1 M_{k}\,\,=\,\,k!\ N\,\left(N\,\,-\,\,1\right)^{k-1} which leads to the multiplicity distribution: σ n σ in = 1 N ​ ( N − 1 N ) n − 1 \frac{\sigma_{n}}{\sigma_{\rm in}}\,\,=\,\,\frac{1}{N}\,\left(\frac{N\,-\,1}{N}\right)^{n-1} . We also suggest a procedure for finding corrections to this multiplicity distribution which will be useful for descriptions of the experimental data.

from both part of Eq. (
36
) we obtain:

\frac{\partial\,\widetilde{m}_{2}\left(\gamma,y,y_{0}\right)}{\partial\,y}\,\,=\,\,\chi\left(\gamma\right)\widetilde{m}_{2}\left(\gamma,y,y_{0}\right)\,\,+\,\,\,2\,\widetilde{n^{2}}

(38)

where
\chi\left(\gamma\right)
is given by Eq. (
8b
) and
\widetilde{n^{2}}
denotes the Mellin image of
N^{2}\left(\boldsymbol{k}_{T},\boldsymbol{b},y,y_{0}\right)
.

Eq. (

) has the following solution which satisfies the initial condition of Eq. (

):

\widetilde{m}_{2}\left(\gamma,y,y_{0}\right)\,\,=\,\,e^{\,\chi\left(\gamma\right)\,y}\int^{y}_{0}\!\!\!dy^{\prime}\,2\,\widetilde{n^{2}}e^{\,-\,\chi\left(\gamma\right)\,y^{\prime}}+\,\,\widetilde{m}^{\rm BFKL}_{2}\left(\gamma,y,y_{0}\right)

(39)

where
\widetilde{m}^{\rm BFKL}_{2}\left(\gamma,y,y_{0}\right)
is a solution to the homogeneous linear BFKL equation with the initial condition of Eq. (
33
). In the following, we neglect the contribution of this term.

V.1.3
Semi-classical solution

For large
y
and
\xi
we can use the semi-classical approximation( SCA, see Refs.
KOLEB
;
BKL
and references therein) to take the integral over
y^{\prime}
in Eq. (
39
). In this approximation we are searching for

N=e^{S_{N}}\,=\,e^{\omega\left(\xi^{\prime},y\right)\,y+\gamma\left(y,\xi^{\prime}\right)\xi^{\prime}}

(40)

where
\omega\left(\xi^{\prime},y\right)
and

\gamma\left(y,\xi^{\prime}\right)
are smooth functions of
y
and
\xi^{\prime}
:
\partial\,\omega^{\prime}\left(\xi^{\prime},y\right)/\partial\,y\,\ll\,\omega^{2}\left(\xi^{\prime},y\right),\,\partial\,\omega\left(\xi^{\prime},y\right)/\partial\,\xi^{\prime}\,\ll\,\omega\left(\xi^{\prime},y\right)\,\gamma\left(y,\xi^{\prime}\right),\partial\,\gamma\left(\xi^{\prime},y\right)/\partial\,\xi^{\prime}\,\ll\,\gamma^{2}\left(\xi^{\prime},y\right),\,\partial\,\gamma\left(\xi^{\prime},y\right)/\partial\,\xi^{\prime}\,\ll\,\omega\left(\xi^{\prime},y\right)\,\gamma\left(y,\xi^{\prime}\right)
. Such form of
N
stems from Eq. (
21
) if we use the method of steepest descent for calculating the integral over
\gamma
. Indeed, using this method one can see that

\omega\left(\xi^{\prime},y\right)\,\,=\,\,\chi\left(\gamma_{\rm SP}\right);~~~~~\gamma\left(\xi^{\prime},y\right)\,\,=\,\,\gamma_{\rm SP};~~~~\mbox{equation for $\gamma_{\rm SP}$:}~~\frac{d\chi\left(\gamma\right)}{d\gamma}\Bigg|_{\gamma=\gamma_{\rm SP}}\!\!\!\!\!\!\!\!\!\!\!\!y\,\,=\,\,\xi^{\prime};

(41)

In the SCA the Mellin image of
N^{2}
can be written as follows:

N^{2}\left(\xi^{\prime},y,y_{0}\right)\,\,=\,\,e^{2\,S_{N}}\,=\,e^{2\,\omega\left(\xi^{\prime},y\right)\,y+2\,\gamma\left(y,\xi^{\prime}\right)\xi^{\prime}}\,\,=\,\,\int\limits^{\epsilon+i\infty}_{\epsilon-i\infty}\!\!\!\!\frac{d\gamma}{2\,\pi\,i}e^{\,\,2\chi\left(\frac{1}{2}\gamma\right)\,y\,\,+\,\,\gamma\,\xi^{\prime}}H\left(\gamma\right)

(42)

Indeed, taking the integral by the method of steepest descent we obtain the following equation for the saddle point (
\gamma^{(2)}_{SP}
):

2\frac{d\,\chi\left(\frac{1}{2}\gamma\right)}{d\gamma}\Bigg|_{\gamma=\gamma^{(2)}_{\rm SP}}y\,\,=\,\,\xi^{\prime};

(43)

with the solution
\gamma^{(2)}_{\rm SP}\,=\,2\,\gamma_{SP}
, where
\gamma_{SP}
is given by Eq. (
41
). Plugging this solution into Eq. (
42
) we see that

\displaystyle N^{2}\left(\xi^{\prime},y,y_{0}\right)\,\,

\displaystyle=

\displaystyle\,\,e^{\,\,2\chi\left(\frac{1}{2}\gamma^{(2)}_{SP}\right)\,y\,\,+\,\,\gamma^{(2)}_{SP}\,\xi^{\prime}}\int\limits^{\epsilon+i\infty}_{\epsilon-i\infty}\!\!\!\!\frac{d\Delta\gamma}{2\,\pi\,i}e^{\,\,\frac{d^{2}\chi\left(\frac{1}{2}\gamma^{(2)}_{SP}\right)}{d\gamma}\,y(\Delta\gamma)^{2}}H\left(\gamma^{(2)}_{SP}\right)

(44)

\displaystyle=

\displaystyle e^{\,\,2\chi\left(\gamma_{SP}\right)\,y\,\,+\,\,2\,\gamma_{SP}\,\xi^{\prime}}\int\limits^{\epsilon+i\infty}_{\epsilon-i\infty}\!\!\!\!\frac{d\Delta\gamma}{2\,\pi\,i}e^{\,\,\frac{d^{2}\chi\left(\gamma_{SP}\right)}{d\gamma}\,y(\Delta\gamma)^{2}}H\left(2\gamma_{SP}\right)

The integral over
\Delta\gamma
leads to a smooth function, which in the SCA can be considered as a constant. Therefore, comparing Eq. (
42
) and Eq. (
44
) one can see that Eq. (
42
) is correct.
We can derive Eq. (
42
) using a more general consideration.
Actually, the expression for the Mellin transform of
N^{2}\left(\xi^{\prime},y,y_{0}\right)
is the convolution in
\gamma
of Mellin images of
N
, which has the following form:

\widetilde{n^{2}}\,\,=\,\,\,\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\!\!\frac{d\,\gamma^{\prime}}{2\,\pi\,i}n_{in}\left(\gamma^{\prime}\right)\,n_{in}\left(\gamma\,-\,\gamma^{\prime}\right)e^{\left(\chi\left(\gamma^{\prime}\right)\,\,+\,\,\chi\left(\gamma\,-\,\gamma^{\prime}\right)\right)\,y}

(45)

Taking the integral over
\gamma^{\prime}
using the method of steepest descent one can see that the equation for the saddle point has the following form:

\frac{d\,\chi\left(\gamma-\gamma^{\prime}\right)}{d\,\gamma^{\prime}}\,\,+\,\,\frac{d\,\chi\left(\gamma^{\prime}\right)}{d\,\gamma^{\prime}}\,\,=\,\,0

(46)

with the solution
\gamma^{\prime}_{SP}=\frac{1}{2}\gamma
. Plugging this solution in Eq. (
45
) we reduce it to:

\widetilde{n^{2}}\,\,=\,\,\,e^{2\chi\left(\frac{1}{2}\gamma\right)\,y}\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\!\!\frac{d\,\Delta\gamma^{\prime}}{2\,\pi\,i}\,\,n^{2}_{in}\left(\frac{1}{2}\gamma\right)e^{\frac{d^{2}\chi\left(\gamma^{\prime}_{SP}\right)}{d\gamma^{\prime 2}_{SP}}\,y\,\left(\Delta\gamma^{\prime}\right)^{2}}

(47)

which reproduces the Mellin transform of Eq. (
42
).

Plugging in Eq. (
39
)
\widetilde{n^{2}}\,\,=\,\,e^{2\chi\left(\frac{1}{2}\gamma\right)\,y}H\left(\gamma\right)

we can take the integral over
y^{\prime}
and the solution has the form:

\tilde{m}_{2}\left(\gamma,y,y_{0}\right)\,\,=\,\,\,e^{\,\,\chi\left(\gamma\right)\,y}H\left(\gamma\right)\int^{y}_{0}\!\!\!dy^{\prime}\,2\,\widetilde{n^{2}}\,\,e^{\,-\,\chi\left(\gamma\right)\,y^{\prime}}=\,\,\frac{2}{2\chi\left(\frac{1}{2}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\Bigg\{e^{2\chi\left(\frac{1}{2}\gamma\right)\,y}H\left(\gamma\right)\,\,-\,\,e^{\chi\left(\gamma\right)\,y}H\left(\gamma\right)\Bigg\}

(48)

Note, that in Eq. (
48
) we neglected the contribution of
\widetilde{m}^{\rm BFKL}_{2}\left(\gamma,y,y_{0}\right)
in Eq. (
39
).

Before fixing
H\left(\gamma\right)

we need to go back to coordinate representation. Indeed, in this representation we have simple initial conditions for
M_{2}
of Eq. (
33
). Since all solutions are solutions of the linear equations and
\gamma_{SP}\,\ll\,1
, we can replace
\xi^{\prime}=\ln k^{2}_{T}
by
\xi\,=\,\ln\frac{1}{r^{2}}
.
Bearing this in mind, we can reduce the solution to the form:

M_{2}\left(\xi,y,y_{0}\right)\,\,=\,\,\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\!\!\!\frac{d\,\gamma}{2\,\pi\,i}\,\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{2}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\Bigg\{e^{2\chi\left(\frac{1}{2}\gamma\right)\,y}\,\,-\,\,e^{\chi\left(\gamma\right)\,y}\Bigg\}\,\frac{1}{\gamma}\,e^{\gamma\,\,\xi}

First, we note, that taking the integral over
\gamma
using the method of steepest descent, we reproduce Eq. (
48
) with the particular choice of
H\left(\gamma\right)=\chi\left(\gamma\right)/\gamma
, which has been discussed in Eq. (
30

this solution coincides with Eq. (
34

In DLA this solution takes the form (see Eq. (
IV

\displaystyle M^{\rm DLA}_{2}\left(\xi^{\prime},y,y_{0}\right)\,\,

\displaystyle=

\displaystyle\,\,\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\!\!\frac{d\,\gamma}{2\,\pi\,i}\,\,\frac{2}{3}\Bigg\{e^{\frac{4}{\gamma}\,y}\,\,-\,\,e^{\frac{1}{\gamma}\,y}\Bigg\}\,\frac{1}{\gamma}\,e^{\gamma\,\,\xi^{\prime}}

(50a)

\displaystyle=

\displaystyle\frac{2}{3}\Bigg\{N_{\rm SCA}^{2}\left(r,y,y_{0}\right)\,\,-\,\,N_{\rm SCA}\left(r,y,y_{0}\right)\Bigg\}\,\,\leftarrow\mbox{with semiclassical accuracy}

However, it turns out that Eq. (

M_{2}\left({Eq.~(\ref{SOLMLN31})}\right)\,\,=\,\,2\Bigg(N^{2}\left(r,y,y_{0}\right)\,\,-\,\,N\left(r,y,y_{0}\right)\Bigg)\,\,=\,\,\,\,2\,y\xi\,\,+\,\,\frac{3}{2}\left(y\,\xi\right)^{2}\,+\,{\cal O}\left(\left(y\,\xi\right)^{3}\right)

V.1.4
Diffusion approximation

Actually, the most adequate approach at high energies is the diffusion one (see Eq. (
IV

Plugging in Eq. (

V.2
The third moment

The third moment can be found from the generating function
\tilde{w}_{\lambda}\left(\boldsymbol{r},\boldsymbol{b},y,y_{0}\right)
in the following way:

M_{3}\left(\boldsymbol{r},y,y_{0}\right)\,\,=\,\,\,\langle|n(n\,-\,1)\,(n\,-\,2)|\rangle=\sum^{\infty}_{n=1}n\,(n-1)\,(n-2)w_{n}\left(r,y,y_{0}\right)\,=\,\frac{\partial^{3}\,\,w_{\lambda}\left(\boldsymbol{r},y,y_{0}\right)}{\partial\,\,\lambda^{3}}\Big|_{\lambda\,=\,1}

(58)

Using Eq. (
58
) we obtain the equation for
M_{3}\left(\boldsymbol{r},y,y_{0}\right)
from Eq. (
18
):

\displaystyle\frac{\partial\,M_{3}\left(\boldsymbol{r},y,y_{0}\right)}{\partial\,y}\,\,

\displaystyle=

\displaystyle\,\,\int d^{2}r^{\prime}K\left(\boldsymbol{r}^{\prime},\boldsymbol{r}-\boldsymbol{r^{\prime}}|\boldsymbol{r}\right)\Bigg\{M_{3}\left(\boldsymbol{r}^{\prime},y,y_{0}\right)\,+\,M_{3}\left(\boldsymbol{r}\,-\,\boldsymbol{r}^{\prime},y,y_{0}\right)

\displaystyle\,\,+

\displaystyle\,\,6\,M_{2}\left(\boldsymbol{r}^{\prime},y,y_{0}\right)\,N\left(\boldsymbol{r}\,-\,\boldsymbol{r}^{\prime},y,y_{0}\right)-\,\,M_{3}\left(\boldsymbol{r},y,y_{0}\right)\Bigg\}

Rewriting Eq. (
V.2
) in momentum representation(see Eq. (
35

\frac{\partial\,m_{3}\left(\boldsymbol{k}_{T},y,y_{0}\right)}{\partial\,y}\,\,=\,\,\int\frac{d^{2}k^{\prime}_{T}}{(2\pi)^{2}}K\left(\boldsymbol{k}_{T},\boldsymbol{k}^{\prime}_{T}\right)\,\,m_{3}\left(\boldsymbol{k}^{\prime}_{T},y,y_{0}\right)\,\,+\,\,6\,m_{2}\left(\boldsymbol{k}_{T},y,y_{0}\right)\,n\left(\boldsymbol{k}_{T},y,y_{0}\right)

\frac{\partial\,\widetilde{m}_{3}\left(\gamma,y,y_{0}\right)}{\partial\,y}\,\,=\,\,\chi\left(\gamma\right)\widetilde{m}_{3}\left(\gamma,y,y_{0}\right)\,\,+\,\,\,6\,\widetilde{n^{2}\,n}

where

is the Mellin image of

\widetilde{n^{2}\,n}\left(\gamma,y\right)\,\,=\,\,\,\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\frac{d\,\gamma^{\prime}}{2\,\pi\,i}\,\widetilde{n^{2}}\left(\gamma^{\prime},y\right)\,\widetilde{n}\left(\gamma-\gamma^{\prime},y\right)

where
\widetilde{n^{2}}\left(\gamma,y\right)
is determined by (see Eq. (
49

\widetilde{n^{2}}\,\,=\,\,\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{2}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\Bigg\{e^{2\chi\left(\frac{1}{2}\gamma\right)\,y}\,\,-\,\,e^{\chi\left(\gamma\right)\,y}\Bigg\}\,\frac{1}{\gamma}

(62)

Plugging Eq. (
21
) and Eq. (
62
) into Eq. (
61
) one can see that
\widetilde{n^{2}\,n}\left(\gamma,y\right)
is a sun of two terms.
Taking the integral over
\gamma^{\prime}
in each of them in the saddle point approximation (see Eq. (
45

2\frac{d\,\chi\left(\frac{1}{2}\gamma^{\prime}\right)}{d\gamma^{\prime}}+\frac{d\,\chi\left(\gamma-\gamma^{\prime}\right)}{d\gamma^{\prime}}=0~~~\mbox{with}~~~\gamma^{\prime}_{SP}=\frac{2}{3}\gamma;~~~~~\frac{d\,\chi\left(\gamma-\gamma^{\prime}\right)}{d\,\gamma^{\prime}}\,\,+\,\,\frac{d\,\chi\left(\gamma^{\prime}\right)}{d\,\gamma^{\prime}}\,\,=\,\,0;~~~\mbox{with}\,\gamma^{\prime}_{SP}=\frac{1}{2}\gamma;

Hence,
\widetilde{n^{2}\,n}\left(\gamma,y\right)
takes the form:

\widetilde{n^{2}\,n}\left(\gamma,y\right)\,\,=\,\,\,\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\frac{1}{2}\gamma\right)}\Bigg\{e^{3\chi\left(\frac{1}{3}\gamma\right)\,y}\,\,-\,\,e^{\chi\left(\frac{1}{2}\gamma\right)\,y}\Bigg\}\,H_{2}\left(\gamma\right)

H_{2}\left(\gamma\right)
, which we will specify below.

Plugging this equation in Eq. (
60
) we obtain the solution:

\displaystyle\widetilde{m}_{3}\left(\gamma,y,y_{0}\right)\,\,

\displaystyle=

\displaystyle\,\,6\left(\frac{1}{3\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\right)\,\left(\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\frac{1}{2}\gamma\right)}\right)\Bigg\{e^{3\,\chi\left(\frac{1}{3}\gamma\right)\,y}\,\,-\,\,e^{\,\chi\left(\gamma\right)\,y}\Bigg\}\,\,

(65)

\displaystyle-

\displaystyle\,\,\left(\frac{1}{2\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\frac{1}{2}\gamma\right)}\right)\left(\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{2}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\right)\Bigg\{e^{2\,\chi\left(\frac{1}{2}\gamma\right)\,y}\,\,-\,\,e^{\,\chi\left(\gamma\right)\,y}\Bigg\}\,H_{2}\left(\gamma\right)

\displaystyle M_{3}\left(\xi,y,y_{0}\right)\,\,

\displaystyle=

\displaystyle\,\,6\,\int\limits^{\epsilon+i\,\infty}_{\epsilon-i\,\infty}\frac{d\,\gamma}{2\,\pi\,i},\left(\frac{\chi\left(\gamma\right)}{3\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\right)\,\left(\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\frac{1}{2}\gamma\right)}\right)\Bigg\{e^{3\,\chi\left(\frac{1}{3}\gamma\right)\,y}\,\,-\,\,e^{\,\chi\left(\gamma\right)\,y}\Bigg\}\,\,

(66)

\displaystyle-

\displaystyle\,\,\left(\frac{\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{3}\gamma\right)\,\,-\,\,\chi\left(\frac{1}{2}\gamma\right)}\right)\left(\frac{2\,\chi\left(\gamma\right)}{2\,\chi\left(\frac{1}{2}\gamma\right)\,\,-\,\,\chi\left(\gamma\right)}\right)\Bigg\{e^{2\,\chi\left(\frac{1}{2}\gamma\right)\,y}\,\,-\,\,e^{\,\chi\left(\gamma\right)\,y}\Bigg\}\,\frac{1}{\gamma}e^{\gamma\,\,\xi}

(67)

which is the same as for the multiplicity distribution of Eq. (

V.3
General approach

The equation for a general moment

M_{k}\left(r,y,y_{0}\right)=\langle|n(n\,-\,1)\dots(n-k+1)|\rangle=\sum^{\infty}_{n=1}\left(n\,(n\,-\,1)\dots(n-k+1)\right)\,w_{n}\left(r,y,y_{0}\right)\,=\,\frac{\partial^{k}\,\,w_{\lambda}\left(\boldsymbol{r},y,y_{0}\right)}{\partial\,\,\lambda^{k}}\Big|_{\lambda\,=\,1}

(68)

we can obtain by differentiating Eq. (
18
) with respect to
\lambda
. It has the simple form in the momentum representation (see Eq. (
35
)):

\frac{\partial}{\partial\,y}m_{k}\left(k_{T},y,y_{0}\right)\,\,=\,\,\int\frac{d^{2}k_{T}}{(2\pi)^{2}}K\left(\boldsymbol{k}_{T},\boldsymbol{k}^{\prime}_{T}\right)\,\,m_{k}\left(\boldsymbol{k}^{\prime}_{T},y,y_{0}\right)\,\,+\,\,\sum^{k-1}_{i=1}\,\frac{k!}{(k-i)!\,i!}m_{k-i}\left(\boldsymbol{k}_{T},\ y,y_{0}\right)\,m_{i}\left(\boldsymbol{k}_{T},y,y_{0}\right)

As we have discussed, we can go back to coordinate representation in Eq. (
69
), since
m_{k}
are solution to the linear equations, and, therefore, have the Mellin image

m_{k}\left(\boldsymbol{k}_{T},y\right)\,\,\,=\,\,\,\int\limits^{\epsilon\,+\,i\,\infty}_{\epsilon\,-\,i\,\infty}\!\!\frac{d\gamma}{2\,\pi\,i}\,e^{\omega\left(\gamma\right)\,y\,\,+\,\,\gamma\,\xi^{\prime}}\,m_{k0}\left(\gamma\right)~~~~\mbox{with}~~~\xi^{\prime}\,\,=\,\,\ln k^{2}_{T}

Finding corrections and comparison with experiments

Eq. (
73
) generates the multiplicity distribution of Eq. (

). However, several questions arise, when we wish to compare this distribution with the experimental data, let say with DIS. The average multiplicity of the color-singlet dipoles is equal to the sea quark structure function
x\Sigma_{\rm sea}\left(x,Q^{2}\right)
KHLE1
. On the other hand, in Eq. (
73

\ln k^{2}_{T}\,\to-\ln r^{2}
. Therefore, my suggestion is to use Eq. (
1
) with
N\,=x\Sigma_{\rm sea}\left(x,Q^{2}\right)
but to calculate the corrections to this distribution. The multiplicity distribution can generally be written, using the cumulant generating function
f\left(\lambda\right)
as follows
MUMULT
;
MGF
:

\frac{\sigma_{n}}{\sigma_{\rm in}}\,\,=\,\,\oint\frac{d\lambda}{2\,\pi\,i}\frac{e^{f\left(\lambda\right)}}{\lambda^{n+1}}

(78)

where the contour of integration is the circle around the point
\lambda=0
and
f\left(\lambda\right)
is the cumulant generating function, which is defined as

f\left(\lambda\right)\,\,=\,\,\sum^{\infty}_{n=1}\frac{\kappa_{n}}{n!}\left(\lambda-1\right)^{n}

(79)

where
\kappa_{n}
are cumulants. Generally speaking, we have the following definition for the cumulants:

\kappa_{1}\,=\,N;~~~\kappa_{2}\,=\,M_{2}\,-\,N^{2};~~~\kappa_{3}\,=\,M_{3}\,-\,3\,M_{2}\,N\,+\,2\,N^{2};~~~\kappa_{4}\,=\,M_{4}\,-\,4\,M_{3}\,N\,-\,3\,M^{2}_{2}\,+\,12\,M_{2}\,N^{2}\,-\,6\,N^{4};

(80)

M_{k}

73

In our case we can view

.

generates the multiplicity distributions of Eq. (
1

(81)

with

\Delta\kappa_{1}\,=\,0;~~\Delta\kappa_{2}\,\,=\,\,M_{2}\left(k_{T},y\right)\,-\,2\,N\,\left(N\,-\,1\right);~~~~\Delta\kappa_{3}\,=\,M_{3}\left(k_{T},y\right)\,-6\,N\left(N\,-\,1\right)^{2}\,-\,3\,\Delta\kappa_{2}\,N\,;
