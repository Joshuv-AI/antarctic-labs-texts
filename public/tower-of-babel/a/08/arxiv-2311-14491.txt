Introduction

0.1
Formulation of the result

Consider the equation

-\Delta u+Vu=0,

(0.1)

where
V
is a bounded measurable function.
Landis has proposed the question about the fastest speed at which a solution
u

can decrease at infinity if we consider the equation (
0.1
) in the entire space
\mathbb{R}^{n}

or outside a ball in
\mathbb{R}^{n}
.
There are two settings of the question: the real case and the complex case.
A complex-valued function
u
satisfies the equation (
0.1
) for a certain bounded
complex
potential
V
if and only if

\left|\Delta u\right|\leqslant C|u|.

(0.2)

If the potential
V
is real, the equation (
0.1
) is true for the real part
\operatorname{Re}u
and
for the imaginary part
\operatorname{Im}u
.
It means that the condition that a function
u
satisfies the equation (
0.1
)
for a certain bounded
real
potential
V
is equivalent to the estimate (
0.2
)
with a real-valued function
u.

For
n=1
it is easy to see that any solution which decreases superexponentially fast

u(x)=O\big(e^{-N|x|}\big)\quad\forall\ N,

is
u\equiv 0
.
On the other hand, there exist nontrivial solutions which decrease exponentially.
For example, the function
u(x)=\exp(-\sqrt{x^{2}+1})
satisfies the estimate (
0.2
).
Therefore, for
n=1
the answer is clear both in the real and in the complex cases.

The question in the multidimensional complex case was solved by Meshkov
[
7
]
.
He showed that any function
u
saisfying (
0.2
) and

u(x)=O\big(e^{-N|x|^{4/3}}\big)\quad\forall\ N,

is
u\equiv 0
.
Also for
n=2
he constructed a nontrivial function
u
satisfying the estimate (
0.2
)
and the estimate

u(x)=O\big(e^{-c|x|^{4/3}}\big)

for a certain
c>0
.

The real multidimensional case remains an open problem.
Recently in
[
6
]
it has been shown that for
n=2
,
any real function
u
satisfying (
0.2
) and

u(x)=O\big(e^{-N|x|\sqrt{\ln|x|}}\big),\quad\text{for}\ |x|\to\infty,\quad\forall\ N

is
u\equiv 0
.

We consider an analogous question in a cylinder

\Pi:=\mathbb{R}\times\mathbb{T}^{d},\qquad\mathbb{T}^{d}=\mathbb{R}^{d}/(2\pi\mathbb{Z})^{d}.

Our main result is the following

Theorem 0.1
.

Let
d\geqslant 3
,
N>0
.
There exists a real-valued function
F\in C^{\infty}\left(\mathbb{R}\times\mathbb{T}^{d}\right),

F\not\equiv 0,
such that

|\Delta F(x)|\leqslant C|F(x)|,

(0.3)

|F(x)|\leqslant Ce^{-N|w|^{4/3}}

(0.4)

for all
x=(w,y)\in\mathbb{R}\times\mathbb{T}^{d}
.

Remark 0.2
.

If one constructs such function
F(w,y_{1},y_{2},y_{3})
for
d=3
,
then the same function works also as an example for
d>3
.

Assume that the function
F_{1}(w,y)
satisfies (
0.3
), (
0.4
)
with
N=1
.
Consider the function
\tilde{F}(w,y)=F_{1}(nw,ny)
with some natural
n
.
Then
\tilde{F}
is also
(2\pi)
-periodic in each variable
y_{j}
,

\left|\Delta\tilde{F}(w,y)\right|=n^{2}\left|\Delta F_{1}(nw,ny)\right|\leqslant n^{2}C\left|F_{1}(w,y)\right|,

\left|\tilde{F}(w,y)\right|\leqslant Ce^{-n^{4/3}|w|^{4/3}}.

So, if there is a function for
N=1
then there is a such function for any
N
.

Thus, Theorem
0.1
follows from its particular case
d=3
and
N=1
.
In the sequel we construct an example just for
d=3
and
N=1
.

Bourgain and Kenig proved the following estimate.

Theorem 0.3

(
[
1
]
, Lemma 3.10)

Assume that a function

Then

what can be said about the quantity

Theorem

Our example shows that for

\displaystyle+\frac{1}{4\pi^{2}r^{2}}\int_{\Omega\cap\partial B_{r}(x_{0})}\frac{\partial u(x)}{\partial\nu}\,dS(x)+\frac{1}{2\pi^{2}r^{3}}\int_{\Omega\cap\partial B_{r}(x_{0})}u(x)\,dS(x),

(4.8)

\displaystyle+\int_{\partial\Omega\cap B_{r}(x_{0})}\frac{\partial u(x)}{\partial\nu}\frac{1}{4\pi^{2}}\left(\frac{1}{|x-x_{0}|^{2}}-\frac{1}{r^{2}}\right)dS(x)+\frac{1}{2\pi^{2}r^{3}}\int_{\Omega\cap\partial B_{r}(x_{0})}u(x)\,dS(x).

Lemma 6.6
