Network Coding for 3 3 s / n /n t Sum-Networks
Wentu Song 1 , Chau Yuen 1 , Kai Cai 2 , and Rongquan Feng 3

Abstract
A sum-network is a directed acyclic network where each source independently generates one symbol from a given field 𝔽 \mathbb{F} and each terminal wants to receive the sum ( ( over OPEN 𝔽 ) \mathbb{F}) of the source symbols. For sum-networks with two sources or two terminals, the solvability is characterized by the connection condition of each source-terminal pair [ 3 ] . A necessary and sufficient condition for the solvability of the 3 3 -source 3 3 -terminal ( 3 CLOSE (3 s / 3 /3 t ) ) sum-networks was given by Shenvi and Dey [ 6 ] . However, the general case of arbitrary sources/sinks is still open. In this paper, we investigate the sum-network with three sources and n n sinks using a region decomposition method. A sufficient and necessary condition is established for a class of 3 3 s / n /n t sum-networks. As a direct application of this result, a necessary and sufficient condition of solvability is obtained for the special case of 3 3 s / 3 /3 t sum-networks.

(Linear Network Code)

/n

.

III-A

Region Decomposition and Region Graph

Definition III.1
(Region and Region Decomposition)

Let

be a non-empty subset of

R

such that for any

and

,

contains an incoming link of
e
. If

is
partitioned into mutually disjoint regions, say

, then we call

D=\{R_{1},R_{2},\cdots,R_{N}\}

The edge
e_{l}
in Definition
III.1
is called the leader of

and is denoted as

. A region

is
called the
X_{i}

source region
(or a

for short) if
\text{lead}(R)
is the
X_{i}
source link;

is
called a

If

Since the source links have no incoming link, then each source

k

n
terminal
regions for any
k
s
/n
t sum-network. We will always denote the

k

and the

Definition III.2
(Region Graph)

Let

be a region decomposition of
G
. The region graph of

about

\mathcal{E}_{D}
, where

is the set of all ordered

(R^{\prime},R)

contains an incoming link of

\text{lead}(R)
.

Consider the example network
G_{1}
in Fig.
1

of two region graphs are shown in Fig.

We use

. If

. For

, we use

to denote the set of parents of

For

. If there is a path

Lemma C.7

Suppose

proof C.8

IV.7

III.7
