A Fixed Version of Quadratic Program in Gradient Episodic Memory
Wei Zhou, Yiying Li

Abstract
Gradient Episodic Memory (GEM) ( Lopez-Paz and Ranzato 2017 ) is indeed a novel method for continual learning, which solves new problems quickly without forgetting previously acquired knowledge. However, in the process of studying the paper, we found there were some problems in the proof of the dual problem of Quadratic Program, so here we give our fixed version for this problem.



1
The dual problem of quadratic program

The main feature of GEM
(
Lopez-Paz and Ranzato 2017
)
is an episodic memory
M_{t}
, which stores a subset of the observed examples from task
t
. In the contribution of GEM, it makes two key observations to solve positive backward transfer efficiently. First, it is unnecessary to store old predictors
f^{t-1}_{\theta}
, as long as we guarantee that the loss at previous tasks does not increase after each parameter update
g
. Second, assuming that the function is locally linear (as it happens around small optimization steps) and that the memory is representative of the examples from past tasks, we can diagnose increases in the loss of previous tasks by computing the angle between their loss gradient vector and the proposed update.
Mathematically, we solve the constraints as:

\left\langle g,g_{k}\right\rangle:=\left\langle\frac{\partial\ell(f_{\theta}(x,t),y)}{\partial\theta},\frac{\partial\ell(f_{\theta},\mathcal{M}_{k})}{\partial\theta}\right\rangle\geq 0,\mbox{ for all }k<t.

(1)

If all the inequality constraints (
1
) are satisfied, then
the proposed parameter update
g
is unlikely to increase the loss at previous
tasks. On the other hand, if one or more of the inequality
constraints (
1
) are violated, then there is at least one
previous task that would experience an increase in loss after the parameter
update. If violations occur, we propose to project the proposed gradient
g

to the closest gradient
\tilde{g}
(in squared
\ell_{2}
norm) satisfying all
the constraints (
1
). Therefore, we are interested in:

\displaystyle\text{minimize}_{\tilde{g}}\frac{1}{2}\quad

\displaystyle\|g-\tilde{g}\|_{2}^{2}

subject to

\displaystyle\langle\tilde{g},g_{k}\rangle\geq 0\text{ for all }k<t.

(2)

To solve (
2
) efficiently, recall the primal of a Quadratic
Program (QP)
(
Nocedal and Wright 2006
;
Bot et al. 2009
)
with inequality constraints:

\displaystyle\text{minimize}_{z}\quad

\displaystyle\frac{1}{2}z^{\top}Cz+w^{\top}z

subject to

\displaystyle Az\leq b,

(3)

where
C\in\mathbb{R}^{p\times p}
,
w\in\mathbb{R}^{p}
,
A\in\mathbb{R}^{(t-1)\times p}
, and
b\in\mathbb{R}^{t-1}
,
p
is the dimension of gradient vector.

The Lagrangian dual of a QP is also a QP. We write the Lagrangian function as

L(z,v)=\frac{1}{2}z^{\top}Cz+p^{\top}z+v^{\top}(Az-b)

(4)

Defining the (Lagrangian) dual function as
g(v)=\inf_{z}L(z,v)
, we find an infimum of
L
, using
\nabla_{z}L(z,v)=0
and positive-definiteness of Q:

z^{*}=-C^{-1}(A^{\top}v+w)

(5)

So, the dual problem of (
3
)
is:

\displaystyle\text{minimize}_{v}\quad

\displaystyle\frac{1}{2}v^{\top}AC^{-1}A^{\top}v+(w^{\top}C^{-1}A^{\top}+b^{\top})v

subject to

\displaystyle v\geq 0.

(6)

With these notations in hand, we write the primal GEM QP (
2
) as:

\displaystyle\text{minimize}_{z}\quad

\displaystyle\frac{1}{2}z^{\top}z-g^{\top}z+\frac{1}{2}g^{\top}g

subject to

\displaystyle Gz\leq 0,

where
G=-(g_{1},\ldots,g_{t-1})
, and we discard the constant term
g^{\top}g
.
This is a QP on
p
variables (the number of parameters of the neural
network), which could be measured in the millions. However, we can pose the
dual of the GEM QP as:

\displaystyle\text{minimize}_{v}\quad

\displaystyle\frac{1}{2}v^{\top}GG^{\top}v-g^{\top}G^{\top}v

subject to

\displaystyle v\geq 0,

(7)

since
z=-G^{\top}v+g
and the term
g^{\top}g
is constant. This is a QP on

t-1\ll p
variables, the number of observed tasks so far. Once we solve the
dual problem (
7
) for
v^{\star}
, we can recover the projected
gradient update as
\tilde{g}=-G^{\top}v^{\star}+g
.
