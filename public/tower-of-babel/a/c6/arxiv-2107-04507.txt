Learning-Based Nonlinear H ∞ H^{\infty} Control via Game-Theoretic Differential Dynamic Programming
Wei Sun Theodore B. Trafalis University of Oklahoma, Norman, OK 73019

Abstract
In this work, we present a learning-based nonlinear H ∞ H^{\infty} control algorithm that guarantee system performance under learned dynamics and disturbance estimate. The Gaussian Process (GP) regression is utilized to update the nominal dynamics of the system and provide disturbance estimate based on data gathered through interaction with the system. A soft-constrained differential game associated with the disturbance attenuation problem in nonlinear H ∞ H^{\infty} control is then formulated to obtain the nonlinear H ∞ H^{\infty} controller. The differential game is solved through the min-max Game-Theoretic Differential Dynamic Programming (GT-DDP) algorithm in continuous time. Simulation results on a quadcopter system demonstrate the efficiency of the learning-based control algorithm in handling external disturbances.

2
Learned Dynamics

2.1
Problem Formulation

Consider a dynamical system whose dynamics can be denoted by the summation of two components, a known function obtained from system modeling and an unknown function that represents the model error induced by the disturbance and noise that are not captured by the original model. The continuous-time system dynamics is given by

\displaystyle\frac{\textrm{d}{\bf x}(t)}{\textrm{d}t}=\bar{f}({\bf x}(t),{\bf u}(t))+\delta f({\bf x}(t),{\bf u}(t)),\quad{\bf x}(t_{0})={\bf x}_{0},\quad t\geq 0,

(1)

where

{\bf x}(t)\in\mathbb{R}^{n}
is the state of the dynamic system at
t\in[t_{0},{t_{f}}]
,
{\bf u}(t)\in U_{1}\subset\mathbb{R}^{m}
denotes the control of the system where
U_{1}
is a convex constraint sets of the control
{\bf u}
,
\bar{f}({\bf x}(t),{\bf u}(t))
denotes the nominal nonlinear system model that is known
a priori
and
\delta f({\bf x}(t),{\bf u}(t))
denotes the unknown error dynamics.

The goal of this paper is to find an estimate of the function
\delta f({\bf x}(t),{\bf u}(t))
and an associated confidence range of the estimation, which will then be used to design a nonlinear
H^{\infty}
controller that drives the system to its desired state despite the uncertainty in the dynamics.

2.2
Model Learning

The unknown error dynamics
\delta f({\bf x}(t),{\bf u}(t))
can be modeled through a machine learning process. In this subsection, we introduce the Gaussian processes (GP) approach to achieve this task.

A GP is a stochastic process such that every finite collection of its random variables have a joint Gaussian distribution. It is widely used in nonparametric regression in machine learning to find an approximation of a nonlinear map from an input vector to a function value. Given state-control pairs
\chi=({\bf x},{\bf u})\in\mathbb{R}^{m+n}
at different time instants, and the corresponding function values
\delta f(\chi)=\delta f({\bf x},{\bf u})
, the error function
\delta f
can be approximated by a GP defined by a mean function and a covariance function. The latter is also known as the kernel, which serves as a similarity measure of random variables. In this paper, we consider the Gaussian kernel
[
7
]

\displaystyle k(\chi_{i},\chi_{j})=\sigma_{s}^{2}\exp(-\dfrac{1}{2}(\chi_{i}-\chi_{j})^{{\mbox{\tiny\sf T}}}M(\chi_{i}-\chi_{j}))

(2)

as the covariance between two data points,
\delta f(\chi_{i})
and
\delta f(\chi_{j})
, where
\chi_{i}=\chi(t_{i})
,
\chi_{j}=\chi(t_{j})
,
i,j\in\mathbb{N}
. In (
2
), the process variance
\sigma_{s}^{2}
and the scaling matrix
M
are hyperparameters.

Let
X=[\chi_{1},\dots,\chi_{N}]^{{\mbox{\tiny\sf T}}}
denote a vector of
N
state-control pairs and the vector of their corresponding observed error function values is denoted by
\delta f(X)=[\delta f(\chi_{1}),\dots,\delta f(\chi_{N})]^{{\mbox{\tiny\sf T}}}
, where
\delta f(\chi_{i})=\dot{{\bf x}}(t_{i})-\bar{f}(\chi_{i})
, and let
\chi^{*}
be a test input, then the joint probability distribution of the observed output and the predicted function value
\delta f(\chi^{*})
is given by

\displaystyle\begin{bmatrix}\delta f(X)\\
\delta f(\chi^{*})\end{bmatrix}\sim\mathcal{N}\left(0,\begin{bmatrix}K(X,X)+\sigma_{w}^{2}I&{\bf k}(X,\chi^{*})\\
{\bf k}(\chi^{*},X)&k(\chi^{*},\chi^{*})\end{bmatrix}\right),

(3)

where
K(X,X)
has entries
K(X,X)_{(i,j)}=k(\chi_{i},\chi_{j})
,
i,j\in\{1,\dots,N\}
, and
{\bf k}(X,\chi^{*})
has row entries
{\bf k}(X,\chi^{*})_{(i)}=k(\chi_{i},\chi^{*})
,
i\in\{1,\dots,N\}
,
{\bf k}(\chi^{*},X)={\bf k}(X,\chi^{*})^{{\mbox{\tiny\sf T}}}
,
I
is the identity matrix, and the noise variation
\sigma_{w}^{2}
is another hyperparameter of the GP. The mean of the joint distribution is assumed to be zero here, since the GP is used to approximate the error dynamics
\delta f
for which no prior knowledge is available. The hyperparameters
\Theta=(\sigma_{w},\sigma_{s}.M)
can be learned by solving a maximum log-likelihood problem

\displaystyle\Theta^{*}=\operatornamewithlimits{argmax}_{\Theta}\left\{\log\left(p(\delta f(X)|X,\Theta)\right)\right\}

(4)

through gradient ascent methods
[
7
]
.

Given the joint probability distribution (
3
), the predictive mean and variance of the error function can be specified as

\displaystyle\mathbb{E}\left[\delta f(\chi^{*})\right]

\displaystyle={\bf k}(\chi^{*},X)(K(X,X)+\sigma_{w}^{2}I)^{-1}\delta f(X),

(5)

\displaystyle\mathrm{Var}\left[\delta f(\chi^{*})\right]

\displaystyle=k(\chi^{*},\chi^{*})-{\bf k}(\chi^{*},X)(K(X,X)+\sigma_{w}^{2}I)^{-1}{\bf k}(X,\chi^{*}).

(6)

Using the property of GP that the derivative of a GP is still a GP, the joint probability distribution of the observed output and the derivative of the predicted error function can be obtained as

\displaystyle\begin{bmatrix}\delta f(X)\\
\nabla_{\chi}\delta f(\chi^{*})\end{bmatrix}\sim\mathcal{N}\left(0_{N},\begin{bmatrix}K(X,X)+\sigma_{w}^{2}I&\nabla_{\chi}{\bf k}(X,\chi^{*})\\
\nabla_{\chi}{\bf k}(\chi^{*},X)&\nabla_{\chi\chi}k(\chi^{*},\chi^{*})\end{bmatrix}\right).

(7)

The derivatives in (
7
) can be expressed analytically as follows

\displaystyle\nabla_{\chi}{\bf k}(X,\chi^{*})_{(i)}

\displaystyle=\nabla_{\chi}{\bf k}(\chi^{*},X)_{(i)}=Mk(\chi_{i},\chi^{*})(\chi_{i}-\chi^{*}),\quad i\in\{1,\dots,N\},

(8)

\displaystyle\nabla_{\chi\chi}k(\chi^{*},\chi^{*})

\displaystyle=\sigma_{s}^{2}M.

(9)

Similar to the prediction process in error function
\delta f
, the predictive mean and variance of its state derivative is given by

\displaystyle\mathbb{E}\left[\nabla_{\chi}\delta f(\chi^{*})\right]

\displaystyle=\nabla_{\chi}{\bf k}(\chi^{*},X)(K(X,X)+\sigma_{w}^{2}I)^{-1}\delta f(X),

(10)

\displaystyle\mathrm{Var}\left[\nabla_{\chi}\delta f(\chi^{*})\right]

\displaystyle=\nabla_{\chi\chi}{\bf k}(\chi^{*},\chi^{*})-\nabla_{\chi}{\bf k}(\chi^{*},X)(K(X,X)+\sigma_{w}^{2}I)^{-1}\nabla_{\chi}{\bf k}(X,\chi^{*}).

(11)

The analytical expression of the state derivative obtained here can be useful in speeding up the computation process later on.

3
Nonlinear
H^{\infty}
Control

In this section, we set up a nonlinear
H^{\infty}
control problem to synthesize controllers that stabilize the system with guaranteed performance.

To this end, consider the general structure of the soft-constrained differential game associated with the disturbance attenuation problem in nonlinear
H^{\infty}
control. A detailed explanation of the relationship between the
H^{\infty}
control and the zero-sum differential game can be found in
[
21
]
.

The dynamics of the differential game is described by

\displaystyle\frac{\textrm{d}{\bf x}(t)}{\textrm{d}t}=F({\bf x}(t),{\bf u}(t),{\bf w}(t)),\quad{\bf x}(t_{0})={\bf x}_{0},\quad t\geq 0,

(12)

where
{\bf w}(t)\in U_{2}\subset\mathbb{R}^{q}
denote the disturbance of the system and
U_{2}
is a constraint set of the disturbance
{\bf w}
,
and the right-hand side of the dynamics in our problem is given by

\displaystyle F({\bf x},{\bf u},{\bf w})=\bar{f}({\bf x},{\bf u})+\mu({\bf x},{\bf u})+W({\bf x},{\bf u})C({\bf x},{\bf u}){\bf w},

(13)

where the time arguments are omitted for brevity,
\bar{f}({\bf x},{\bf u})
is the known nominal dynamics in (
1
), and
\mu({\bf x},{\bf u})
is the mean of the GP-learned multivariate Gaussian distribution that approximates the unknown error dynamics
\delta f({\bf x},{\bf u})
such that
\delta f({\bf x},{\bf u})\sim\mathcal{N}(\mu({\bf x},{\bf u}),\Sigma({\bf x},{\bf u}))
. Given the data set
\{X,\delta f(X)\}
, the mean and variance of the Gaussian distribution can be calculated as in (
5
) and (
6
) respectively. In particular,
\mu({\bf x},{\bf u})=\mathbb{E}\left[\delta f(\chi)\right]
and
\Sigma({\bf x},{\bf u})=\mathrm{Var}\left[\delta f(\chi)\right]
, where
\chi=({\bf x},{\bf u})
.
The matrix
C({\bf x},{\bf u})\in\mathbb{R}^{n\times q}
encodes the information of the structure of the noise that is known a priori. For instance, in many applications the noise comes in the same channel as the control, so for a control-affine system where
\bar{f}({\bf x},{\bf u})=f_{1}({\bf x})+f_{2}({\bf x}){\bf u}
, one can set
C({\bf x},{\bf u})=f_{2}({\bf x})
. If no prior structural information of the noise is assumed, then one can set
q=n
and
C({\bf x},{\bf u})=I
. The matrix

W({\bf x},{\bf u})=\Sigma({\bf x},{\bf u})^{\frac{1}{2}}
encodes the standard deviation information of the disturbance and this information is gained from the learning process.

The cost of the differential game is defined as

J_{\gamma}({\bf u}(\cdot),{\bf w}(\cdot))=\phi({\bf x}(t_{f}),t_{f})+\int_{t_{0}}^{t_{f}}\mathcal{L}_{\gamma}({\bf x}(t),{\bf u}(t),{\bf w}(t))\,\text{d}t,

(14)

where
t_{0}
and
t_{f}
are fixed initial and terminal time,
\phi:\mathbb{R}^{n}\times[t_{0},{t_{f}}]\to\mathbb{R}_{+}
denotes the terminal cost, and

\mathcal{L}_{\gamma}({\bf x}(t),{\bf u}(t),{\bf w}(t))=\mathcal{L}({\bf x}(t),{\bf u}(t),{\bf w}(t))-\gamma^{2}{\bf w}(t)^{{\mbox{\tiny\sf T}}}{\bf w}(t),

(15)

where
\mathcal{L}:\mathbb{R}^{n}\times\mathbb{R}^{m}\times\mathbb{R}^{q}\to\mathbb{R}_{+}
denotes the running cost of the performance index associated with the system (
12
), specified as

J({\bf u}(\cdot),{\bf w}(\cdot))=\phi({\bf x}(t_{f}),t_{f})+\int_{t_{0}}^{t_{f}}\mathcal{L}({\bf x}(t),{\bf u}(t),{\bf w}(t))\,\text{d}t.

(16)

In the differential game described by (
12
) and (
14
), we wish to find non-anticipative feedback strategy
\mu_{{\bf u}}:[t_{0},{t_{f}}]\times\mathbb{R}^{n}\rightarrow U_{1}
for the control and
\mu_{{\bf w}}:[t_{0},{t_{f}}]\times\mathbb{R}^{n}\rightarrow U_{2}
for the disturbance such that the corresponding cost function

J_{\gamma}(\mu_{{\bf u}},\mu_{{\bf w}})=\phi({\bf x}(t_{f}),t_{f})+\int_{t_{0}}^{t_{f}}\mathcal{L}_{\gamma}({\bf x}(t),\mu_{{\bf u}}(t,{\bf x}(t)),\mu_{{\bf w}}(t,{\bf x}(t)))\,\text{d}t

(17)

is minimized by the control while maximized by the disturbance.
The function describing the minimax value of the cost function at
t_{0}
and
{\bf x}_{0}
is given by

\displaystyle V({\bf x}_{0},t_{0})=\min_{\mu_{{\bf u}}}\max_{\mu_{{\bf w}}}J_{\gamma}(\mu_{{\bf u}},\mu_{{\bf w}}),

(18)

which is known as the value function.

Standard regularity assumptions on the functions
F
,
\mathcal{L}
, and
\phi
will be assumed throughout the paper to ensure existence and uniqueness of solutions of the differential equation (
12
).
Accordingly, it will be assumed that
\mu_{{\bf u}}(t,{\bf x})
and
\mu_{{\bf w}}(t,{\bf x})
are piecewise continuous functions in
t
and Lipschitz continuous functions in
{\bf x}
.

It is further assumed that
both the control and disturbance have perfect knowledge of the dynamics of the system given by (
12
), the constraint sets
U_{1}
and
U_{2}
, the cost function, and the state
{\bf x}
at each current time. This is a standard assumption for differential games with complete information
[
35
]
.
The Isaacs condition

\hskip-8.53581pt\min\limits_{{\bf u}}\max\limits_{{\bf w}}\{\mathcal{L}({\bf x},{\bf u},{\bf w})+\nabla_{{\bf x}}V^{{\mbox{\tiny\sf T}}}F({\bf x},{\bf u},{\bf w})\}=\max\limits_{{\bf w}}\min\limits_{{\bf u}}\{\mathcal{L}({\bf x},{\bf u},{\bf w})+\nabla_{{\bf x}}V^{{\mbox{\tiny\sf T}}}F({\bf x},{\bf u},{\bf w})\},

(19)

is assumed to hold for all
{\bf x},{\bf u},{\bf w}
and
t\geq 0
, which ensures that the
\min
and
\max
operators can be interchanged without affecting the outcome
and thus ensures that the value of the game exists.
In (
19
),
\nabla_{{\bf x}}V({\bf x},t)
denotes the partial derivative of the value function
V({\bf x},t)
with respect to the state
{\bf x}
.
Notice that the Isaacs’ condition holds when the controls are separable in both dynamics and cost
[
35
]
, which is the case for many problems in practice.

Under the assumption that the value of the game exists, and applying Theorem 4.14 in
[
21
]
, it can be shown that there exists some positive definite function
q_{0}({\bf x})
, such that
\forall{\bf w}:[t_{0},{t_{f}}]\to\mathbb{R}^{q}
where
{\bf w}(t)\in U_{2}\subset\mathbb{R}^{q},t\in[t_{0},{t_{f}}]
, and
\forall{\bf x}_{0}\in\mathbb{R}^{n}
,

\displaystyle J(\mu_{{\bf u}}^{*},{\bf w})\leq\gamma^{2}(\int_{t_{0}}^{{t_{f}}}{\bf w}^{{\mbox{\tiny\sf T}}}{\bf w}\text{d}t+q_{0}({\bf x}_{0})),

(20)

that is, the optimal state feedback controller
\mu_{{\bf u}}^{*}
ensures a disturbance attenuation bound
\gamma
.
For simplicity of the presentation, we henceforth use
{\bf u}
and
{\bf w}
to denote
\mu_{{\bf u}},\mu_{{\bf w}}
, respectively. For instance,
V({\bf x}_{0},t_{0})=\min\limits_{{{\bf u}}}\max\limits_{{{\bf w}}}J_{\gamma}({{\bf u}},{{\bf w}})
.

4
Game-Theoretic Differential Dynamic Programming

Game-Theoretic Differential Dynamic Programming (GT-DDT)
[
34
]
solves a differential game problem by
utilizing the dynamic programming method and attempting to find a locally optimal control policy through the iterative improvement of a nominal control and state trajectory.
The control update within each iteration of GT-DDT consists of two main steps. The first step is the optimal policy update, which can be shown to be a function of the zero, first and second order of terms of the value function expansion along the nominal trajectory.
The second step consists of the backward propagation of the local model of the value function.

4.1
Optimal Policy Update

The derivation of GT-DDP starts from the Hamilton-Jacobi-Isaacs (HJI) partial differential equation satisfied by the value function, which is derived from the dynamic programming principle
[
36
,
35
]
.
In particular, the value of the game in (
18
) satisfies

\displaystyle-\frac{\partial V({\bf x},t)}{\partial t}

\displaystyle=\min_{{\bf u}}\max_{{\bf w}}Q({\bf x},{\bf u},{\bf w},t),

(21)

where

\displaystyle Q({\bf x},{\bf u},{\bf w},t)

\displaystyle=\mathcal{L}_{\gamma}({\bf x},{\bf u},{\bf w})+\nabla_{{\bf x}}V({\bf x},t)^{{\mbox{\tiny\sf T}}}F({\bf x},{\bf u},{\bf w}),

(22)

with the boundary condition at time
t={t_{f}}

V({\bf x}({t_{f}}),{t_{f}})=\phi({\bf x}({t_{f}}),{t_{f}}).

(23)

The optimal control and disturbance update laws
\delta{\bf u}^{*}
,
\delta{\bf w}^{*}
can be derived from second order expansion of the terms in both sides of equation (
21
) about the nominal state, control and disturbance trajectories
({\bar{{\bf x}}},{\bar{{\bf u}}},{\bar{{\bf w}}})
.
Specifically,

\displaystyle-\frac{\text{d}V}{\text{d}t}-\delta{\bf x}^{{\mbox{\tiny\sf T}}}\frac{\text{d}(\nabla_{{\bf x}}V)}{\text{d}t}-\frac{1}{2}\delta{\bf x}^{{\mbox{\tiny\sf T}}}\frac{\text{d}(\nabla_{{\bf x}{\bf x}}V)}{\text{d}t}\delta{\bf x}

\displaystyle=\min_{\delta{\bf u}}\max_{\delta{\bf w}}Q(\bar{{\bf x}}+\delta{\bf x},\bar{{\bf u}}+\delta{\bf u},\bar{{\bf w}}+\delta{\bf w},t)

\displaystyle=\min_{\delta{\bf u}}\max_{\delta{\bf w}}\left\{\mathcal{L}+\delta{\bf x}^{{\mbox{\tiny\sf T}}}{Q_{{\bf x}}}+\delta{\bf u}^{{\mbox{\tiny\sf T}}}{Q_{{\bf u}}}+\delta{\bf w}^{{\mbox{\tiny\sf T}}}{Q_{{\bf w}}}+\frac{1}{2}\left[\begin{array}[]{c}\delta{\bf x}\\
\delta{\bf u}\\
\delta{\bf w}\end{array}\right]^{{\mbox{\tiny\sf T}}}\left[\begin{array}[]{ccc}Q_{{\bf x}{\bf x}}&Q_{{\bf x}{\bf u}}&Q_{{\bf x}{\bf w}}\\
Q_{{\bf u}{\bf x}}&Q_{{\bf u}{\bf u}}&Q_{{\bf u}{\bf w}}\\
Q_{{\bf w}{\bf x}}&Q_{{\bf w}{\bf u}}&Q_{{\bf w}{\bf w}}\end{array}\right]\left[\begin{array}[]{c}\delta{\bf x}\\
\delta{\bf u}\\
\delta{\bf w}\end{array}\right]\right\},

where

\displaystyle Q_{{\bf x}}=\nabla_{{\bf x}}F^{{\mbox{\tiny\sf T}}}\nabla_{{\bf x}}V+\nabla_{{\bf x}}\mathcal{L},

(33a)

\displaystyle Q_{{\bf u}}=\nabla_{{\bf u}}F^{{\mbox{\tiny\sf T}}}\nabla_{{\bf x}}V+\nabla_{{\bf u}}\mathcal{L},

(33b)

\displaystyle Q_{{\bf w}}=\nabla_{{\bf w}}F^{{\mbox{\tiny\sf T}}}\nabla_{{\bf x}}V+\nabla_{{\bf w}}\mathcal{L},

(33c)

\displaystyle Q_{{\bf x}{\bf x}}=\nabla_{{\bf x}{\bf x}}\mathcal{L}+2\nabla_{{\bf x}{\bf x}}V\nabla_{{\bf x}}F,

(33d)

\displaystyle Q_{{\bf u}{\bf u}}=\nabla_{{\bf u}{\bf u}}\mathcal{L},

(33e)

\displaystyle Q_{{\bf w}{\bf w}}=\nabla_{{\bf w}{\bf w}}\mathcal{L},

(33f)

\displaystyle Q_{{\bf u}{\bf x}}=\nabla_{{\bf u}}F^{{\mbox{\tiny\sf T}}}\nabla_{{\bf x}{\bf x}}V+\nabla_{{\bf u}{\bf x}}\mathcal{L},

(33g)

\displaystyle Q_{{\bf w}{\bf x}}=\nabla_{{\bf w}}F^{{\mbox{\tiny\sf T}}}\nabla_{{\bf x}{\bf x}}V+\nabla_{{\bf w}{\bf x}}\mathcal{L},

(33h)

\displaystyle Q_{{\bf u}{\bf w}}=\nabla_{{\bf u}{\bf w}}\mathcal{L}.

(33i)

\displaystyle Q_{{\bf x}{\bf u}}=Q_{{\bf u}{\bf x}}^{{\mbox{\tiny\sf T}}},\quad Q_{{\bf x}{\bf w}}=Q_{{\bf w}{\bf x}}^{{\mbox{\tiny\sf T}}},\quad Q_{{\bf w}{\bf u}}=Q_{{\bf u}{\bf w}}^{{\mbox{\tiny\sf T}}}.

(33j)

The arguments of the functions
Q,V,F
, etc, are omitted for brevity, and the equations in (
33
) are evaluated along the nominal trajectory
(\bar{{\bf x}},\bar{{\bf u}},\bar{{\bf w}})
.

The optimal control
\delta{\bf u}^{*}
and disturbance
\delta{\bf w}^{*}
must be chosen to minimize and maximize the right-hand side of (
4.1
) respectively. By computing the gradients of (
4.1
) with respect to
\delta{\bf u}
and
\delta{\bf w}
, respectively, and set them equal to zero, one obtain

\displaystyle\delta{\bf u}^{*}

\displaystyle=-Q_{{\bf u}{\bf u}}^{-1}\bigg(Q_{{\bf u}{\bf x}}\delta{\bf x}+Q_{{\bf u}{\bf w}}\delta{\bf w}^{*}+Q_{{\bf u}}\bigg),

(34a)

\displaystyle\delta{\bf w}^{*}

\displaystyle=-Q_{{\bf w}{\bf w}}^{-1}\bigg(Q_{{\bf w}{\bf x}}\delta{\bf x}+Q_{{\bf w}{\bf u}}\delta{\bf u}^{*}+Q_{{\bf w}}\bigg),

(34b)

where
Q_{{\bf w}{\bf u}}=Q_{{\bf u}{\bf w}}^{{\mbox{\tiny\sf T}}}
.

Notice that
\delta{\bf u}^{*}
and
\delta{\bf w}^{*}
show up in the right-hand side of (
34
), and this can be further derived to obtain the
explicit expressions for
\delta{\bf u}^{*}
and
\delta{\bf w}^{*}
as

\displaystyle\delta{\bf u}^{*}

\displaystyle={\bf l}_{{\bf u}}+{\bf K}_{{\bf u}}\delta{\bf x}

(35a)

\displaystyle\delta{\bf w}^{*}

\displaystyle={\bf l}_{{\bf w}}+{\bf K}_{{\bf w}}\delta{\bf x},

(35b)

where the feed-forward gains
{\bf l}_{{\bf w}},{\bf l}_{{\bf u}}
and feedback gains
{\bf K}_{{\bf w}},{\bf K}_{{\bf u}}
are given by

{\bf l}_{{\bf u}}=-\bigg(Q_{{\bf u}{\bf u}}-Q_{{\bf u}{\bf w}}Q_{{\bf w}{\bf w}}^{-1}Q_{{\bf w}{\bf u}}\bigg)^{-1}\bigg(Q_{{\bf u}}-Q_{{\bf u}{\bf w}}Q_{{\bf w}{\bf w}}^{-1}Q_{{\bf w}}\bigg),\\

(36)

{\bf l}_{{\bf w}}=-\bigg(Q_{{\bf w}{\bf w}}-Q_{{\bf w}{\bf u}}Q_{{\bf u}{\bf u}}^{-1}Q_{{\bf u}{\bf w}}\bigg)^{-1}\bigg(Q_{{\bf w}}-Q_{{\bf w}{\bf u}}Q_{{\bf u}{\bf u}}^{-1}Q_{{\bf u}}\bigg),

(37)

{\bf K}_{{\bf u}}=-\bigg(Q_{{\bf u}{\bf u}}-Q_{{\bf u}{\bf w}}Q_{{\bf w}{\bf w}}^{-1}Q_{{\bf w}{\bf u}}\bigg)^{-1}\bigg(Q_{{\bf u}{\bf x}}-Q_{{\bf u}{\bf w}}Q_{{\bf w}{\bf w}}^{-1}Q_{{\bf w}{\bf x}}\bigg),

(38)

{\bf K}_{{\bf w}}=-\bigg(Q_{{\bf w}{\bf w}}-Q_{{\bf w}{\bf u}}Q_{{\bf u}{\bf u}}^{-1}Q_{{\bf u}{\bf w}}\bigg)^{-1}\bigg(Q_{{\bf w}{\bf x}}-Q_{{\bf w}{\bf u}}Q_{{\bf u}{\bf u}}^{-1}Q_{{\bf u}{\bf x}}\bigg).

(39)

4.2
Value Function Propagation

The update law for the second order local model of the value function

(V,\nabla_{{\bf x}}V,\nabla_{{\bf x}{\bf x}}V)
can be derived by substituting the optimal control (
34a
) and disturbance (
34b
) to the HJI equation (
21

6
Conclusion

In this paper, we have introduced an approach that combines machine learning with nonlinear
H^{\infty}
control to design a learning-based controller that takes into account the learned model dynamics and disturbance estimate while achieving performance guarantee of the system. The error dynamics and disturbance estimate are learned through the utilization of the Gaussian Process (GP) in order to formulate the soft-constrained differential game associated with the disturbance attenuation nonlinear
H^{\infty}
control problem. The differential game is then solved through the Game-Theoretic Differential Dynamic Programming (GT-DDP) method to obtain the optimal state-feedback control that guarantees performance despite model uncertainties.
The GT-DDP method is derived by taking the Taylor series expansion of the Hamilton-Jacobi-Isaacs (HJI) equation associated with the differential game around a nominal trajectory to obtain the update law of the control and disturbance, as well as the backward propagation equations of the approximation terms of the value function.
The approach we presented is tested on a nonlinear control problem, namely, a quadcopter flight steering.
The example showcases the ability of our controller to handle relatively high degree-of-freedom systems and system disturbances. Future possible extension of this research includes applying this method to problems with stochastic dynamics and state/control constraints, which will be suitable for a variety of applications including bio-mechanical systems and stochastic models in finance.
