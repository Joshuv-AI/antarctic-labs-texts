Abstract
We have find the diagonal K K matrix solutions of the reflection equations for a class of vertex models. These models have ( n + 1 ) ​ ( 2 ​ n + 1 ) (n+1)(2n+1) vertices and are defined as two set of (n + 1) R R matrices, solutions of the equations of Yang-Baxter equations. For a given value of n we find n!- 1 2 ​ ( n − 2 ) ​ ( n − 1 ) \frac{1}{2}(n-2)(n-1) K K diagonal matrices.
