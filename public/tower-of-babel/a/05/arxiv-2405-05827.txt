Efficient designs for threshold group testing without gap
Thach V. Bui, Yeow Meng Chee, Van Khu Vu

Abstract
Given d d defective items in a population of n n items with d ≪ n d\ll n , in threshold group testing without gap, the outcome of a test on a subset of items is positive if the subset has at least u u defective items and negative otherwise, where 1 ≤ u ≤ d 1\leq u\leq d . The basic goal of threshold group testing is to quickly identify the defective items via a small number of tests. In non-adaptive design, all tests are designed independently and can be performed in parallel. The decoding time in the non-adaptive state-of-the-art work is a polynomial of ( d / u ) u ​ ( d / ( d − u ) ) d − u , d (d/u)^{u}(d/(d-u))^{d-u},d , and log ⁡ n \log{n} . In this work, we present a novel design that significantly reduces the number of tests and the decoding time to polynomials of min ⁡ { u u , ( d − u ) d − u } , d \min\{u^{u},(d-u)^{d-u}\},d , and log ⁡ n \log{n} . In particular, when u u is a constant, the number of tests and the decoding time are O ⁡ ( d 3 ​ ( log 2 ⁡ n ) ​ log ⁡ ( n / d ) ) O(d^{3}(\log^{2}{n})\log{(n/d)}) and O ⁡ ( d 3 ​ ( log 2 ⁡ n ) ​ log ⁡ ( n / d ) + d 2 ​ ( log ⁡ n ) ​ log 3 ⁡ ( n / d ) ) O\big(d^{3}(\log^{2}{n})\log{(n/d)}+d^{2}(\log{n})\log^{3}{(n/d)}\big) , respectively. For a special case when u = 2 u=2 , with non-adaptive design, the number of tests and the decoding time are O ⁡ ( d 3 ​ ( log ⁡ n ) ​ log ⁡ ( n / d ) ) O(d^{3}(\log{n})\log{(n/d)}) and O ⁡ ( d 2 ​ ( log ⁡ n + log 2 ⁡ ( n / d ) ) ) O(d^{2}(\log{n}+\log^{2}{(n/d)})) , respectively. Moreover, with 2-stage design, the number of tests and the decoding time are O ⁡ ( d 2 ​ log 2 ⁡ ( n / d ) ) O(d^{2}\log^{2}{(n/d)}) .

Introduction

The main objective of group testing is to find a small number of defective items in a large population of items
[
1
]
. Defective items and non-defective items are defined by context. For example, in Covid-19 scenario, defective (respectively, non-defective) items are people who are positive (respectively, negative) to Coronavirus. In standard group testing (SGT), a pool of items is positive if there exists at least one defective item in the pool and negative otherwise. In some problems
[
2
,
3
]
, there is a need for cooperation of at least two defective items in an effort to achieve a certain goal. A test on a set of items is positive if the certain goal is attained and negative otherwise. This means the SGT model does not fit to these problems. Damaschke
[
4

proposes a threshold group testing (TGT) model in which the outcome of a test on a subset of items is positive if the subset has at least
u

\ell
defective items, where
0\leq\ell<u
, and arbitrary otherwise. The parameter
g=u-\ell-1
is called the gap. It is obvious that when

, TGT is called
TGT without gap
.

There are many criteria in tackling group testing. Here we only mention four main criteria. The first criterion is the number of stages. When the number of stages is one, i.e., non-adaptive design, all tests are designed in priori and independently. Since the tests in this design can be performed simultaneously, it saves times, and therefore gives a significant advantage for some applications with a fast response demand such as identifying infected persons during pandemic
[
5
]
. Non-adaptive design has also been applied in other areas such as computational and molecular biology
[
6
]
, networking
[
7
]
. However, the number of tests in non-adaptive design normally does not meet the information-theoretic bound that multi-stage designs can obtain. In multi-stage design, the design of tests in a stage depends on the design of the tests in the previous designs and therefore time consuming is essentially unavoidable. The second criterion is between deterministic and randomized design. Given the same input, a deterministic design produces the same result while a randomized one might not produce the same result because it includes a degree of randomness in it. The third criterion is the setting of the defective set. The combinatorial setting applies any configuration on the defective set under the predefined constrains while the probabilistic setting applies some distribution on the input items. Finally, both exact recovery and approximate recovery are also an important criterion studied in group testing.

In this work, we consider non-adaptive and 2-stage designs, deterministic design, combinatorial setting, and exact recovery. The formal problem definition is presented in the subsequent section.

Disjunct and list-disjunct matrices

Disjunct matrices are a powerful tool to tackle the standard and threshold group testing problem
[

,
9
,
11
]
. They were first introduced by Kautz and Singleton
[

]
and then generalized by Stinson and Wei
[

Definition 1
.

An

binary matrix

is called a

such that
|S_{1}|=k
and
|S_{2}|=1

have 0’s, i.e.,
\left|\bigcap_{j\in S_{2}}\mathsf{supp}\left(\mathcal{M}(:,j)\right)\big\backslash\bigcup_{j\in S_{1}}\mathsf{supp}\left(\mathcal{M}(:,j)\right)\right|\geq 1
.

When
\mathcal{M}
is a
d

, there exists an efficient procedure to recover
\mathsf{supp}(\mathbf{x})
from

as follows.

Theorem 3
.

[
18

\mathcal{M}\in\{0,1\}^{m\times n}
with
m=O(k^{2}\min\{\log{n},(\log_{k}{n})^{2}\})

III
Non-adaptive design

In this section, we present an algorithm with up to
O(u^{u}d^{3}\log^{3}{n})
decoding time to find the defective set.

III-A

Comments on the technique using auxiliary subset

In the seminal work of threshold group testing, Damaschke
[
4
]
proposed an idea of using a set
U
of
u-1
defective items as auxiliary pool in the standard group testing strategy. Then the number of tests and the decoding time for identifying the defective set are the same as the standard group testing strategy. This cannot be applied to non-adaptive setting because the defective items in the set of
u-1
defective items
U
can not be identified by this way. Indeed, let
x\in U
and
\mathcal{M}
be a
d
-disjunct matrix. Because of the disjunctiveness property of
\mathcal{M}
, there exists a test in which it contains
x
and none of
P\setminus\{x\}
. By adding the
u-1
items in
U
into this test, the number of defective items in this test is
u-1
because
x\in U
. Consequently, the outcome of this test is negative. Thus, the defective item
x
is identified as negative. We reiterate that any work using the auxiliary subset proposed by Damaschke for the non-adaptive setting may encounter the same mistake. There is a simple way to remedy this. Given a known
u
defective items, we use
u
distinct auxiliary pools of
u-1
defective items in the standard group testing strategy. Then the defective set is the union set of
u
defective sets obtained from the decoding procedures in the standard group testing strategy.

III-B

Single selectors

To attain a design with an efficient encoding and decoding algorithm, we propose a notation called
single selector
.

Definition 2
.

Given integers
m,d
, and
n
, with
1\leq m\leq d\leq n
. A Boolean matrix is called
an
(m,d,n)
-single selector
if for any arbitrary set
D\subseteq[n]
with
|D|=d
, there exists a row in
\mathcal{M}
such that it contains exactly
m
items in
D
.

The following lemma presents the existence of single selectors by probabilistic construction (proved in the appendix).

Lemma 1
.

Given integers
m,d
, and
n
, with
1\leq m<d\leq n
, there exists an
(m,d,n)
-single selector with
O\big(\min\left\{m^{m},(d-m)^{d-m}\right\}d\log{\frac{n}{d}}\big)
rows. When
m=d
,
t=O\big(d\log{\frac{n}{d}}\big)
.

Proof.

Consider a binary Bernoulli matrix
\mathcal{M}=(m_{ij})
of size
t\times n
in which
\Pr[m_{ij}=1]=p
and
\Pr[m_{ij}=0]=1-p
. Consider a set
D
of
d
columns in
\mathcal{M}
. Let the event that a row does not contain exactly
m
ones in
D
be
the bad event
. The probability that the bad event happens is:

1-\binom{d}{m}p^{m}(1-p)^{d-m}.

By setting
p=1/d
, we get

\displaystyle\binom{d}{m}p^{m}(1-p)^{d-m}=\binom{d}{m}\left(\frac{1}{d}\right)^{m}\left(1-\frac{1}{d}\right)^{d-m}

\displaystyle\geq\left(\frac{d}{m}\right)^{m}\left(\frac{1}{d}\right)^{m}\left(1-\frac{1}{d}\right)^{d-m}=\frac{1}{m^{m}}\left(1-\frac{1}{d}\right)^{d}\left(1+\frac{1}{d-1}\right)^{m}

(1)

\displaystyle\geq\frac{1}{m^{m}}\times\mathrm{e}\left(1-\frac{1}{d}\right)\left(1+\frac{1}{d-1}\right)^{m}=\frac{\mathrm{e}}{m^{m}}\left(1+\frac{1}{d-1}\right)^{m-1}

(2)

\displaystyle\geq\frac{\mathrm{e}}{m^{m}},

where
\mathrm{e}
is base of the natural logarithm. Equation (
1
) is obtained because
\left(\frac{a}{b}\right)^{b}\leq\binom{a}{b}
for
0<a\leq b
. We get (
2
) because
\mathrm{e}\big(1-\frac{1}{d}\big)\leq\big(1-\frac{1}{d}\big)^{d}
. Consequently, the probability that the bad event happens for the
t
rows with respect to
D
is

\left(1-\binom{d}{m}p^{m}(1-p)^{d-m}\right)^{t}\leq\left(1-\frac{\mathrm{e}}{m^{m}}\right)^{t}\leq\exp\left(-\frac{\mathrm{e}t}{m^{m}}\right),

because
1-x\leq e^{-x}
for any
x>0
. Therefore, the probability that
\mathcal{M}
is not an
(m,d,n)
-single selector, i.e., there exists at least one subset
D\subseteq[n]
with
|D|=d
such that the bad event happens for the
t
rows, is up to:

\binom{n}{d}\left(1-\binom{d}{m}p^{m}(1-p)^{d-m}\right)^{t}\leq\left(\frac{\mathrm{e}n}{d}\right)^{d}\exp\left(-\frac{\mathrm{e}t}{m^{m}}\right),

(3)

where the last equation is obtained because
\binom{a}{b}\leq\left(\frac{\mathrm{e}a}{b}\right)^{b}
for
0<a\leq b
.
To ensure that there exists an
(m,d,n)
-single selector
\mathcal{M}
, one needs

\left(\frac{\mathrm{e}n}{d}\right)^{d}\exp\left(-\frac{\mathrm{e}t}{m^{m}}\right)<1\Longleftrightarrow\frac{m^{m}d}{\mathrm{e}}\left(1+\log{\frac{n}{d}}\right)<t.

(4)

Thus, we can choose
t=\lceil\frac{m^{m}d}{\mathrm{e}}\big(1+\log{\frac{n}{d}}\big)\rceil+1=O\big(m^{m}d\log{\frac{n}{d}}\big)
to satisfy (
4
).

We can easily create a
(d-m,d,n)
-single selector
\bar{\mathcal{M}}=(\bar{m}_{ij})
from a
t\times n

(m,d,n)
-single selector
\mathcal{M}=(m_{ij})
by inverting all entries in
\mathcal{M}
, i.e.,
\bar{m}_{ij}=1-m_{ij}
for
i\in[t]
and
j\in[n]
.

When
m=d
, we choose
p=d/(d+1)
then (
3
) becomes

\displaystyle\binom{n}{d}\left(1-\binom{d}{m}p^{m}(1-p)^{d-m}\right)^{t}

\displaystyle=\binom{n}{d}\left(1-\left(\frac{d}{d+1}\right)^{d}\right)^{t}\leq\left(\frac{\mathrm{e}n}{d}\right)^{d}\exp\left(-t\left(\frac{d}{d+1}\right)^{d}\right).

This inequality holds if we choose
t=\lceil\mathrm{e}d\left(1+\log{\frac{n}{d}}\right)\rceil+1=O\big(d\log{\frac{n}{d}}\big)
because:

\displaystyle t>\mathrm{e}d\left(1+\log{\frac{n}{d}}\right)\geq\left(1+\frac{1}{d}\right)^{d}\log{\left(\frac{\mathrm{e}n}{d}\right)^{d}}

\displaystyle\Longrightarrow\left(\frac{\mathrm{e}n}{d}\right)^{d}\exp\left(-\frac{\mathrm{e}t}{m^{m}}\right)<1.

This completes our proof.

∎

III-C

Non-adaptive design

Here we present a non-adaptive design to tackle TGT without gap and summarize it in Theorem
1
. When
u=d
, it has been known that the
d
defective items can be found by using a
d
-disjunct matrix and its complementary matrix
[
11
, Lemma 1]
. Because of Theorem
3
, it takes
O(d^{2}\min(d,n))
tests to identify all
d
defective items in
O(d^{2}\min(d,n)+d\log^{2}{(n/d)})
time. This satisfies the claims in Theorem
1
. Therefore, we only consider the case
u<d
to prove Theorem
1
.

III-C
1
Main idea

Our objective is first creating a test that contains exactly
u
defective items. From these
u
defective items, we create
u
sets
S_{1},\ldots,S_{u}\subseteq[n]
of items such that each set contains exactly
u-1
defective items and the sets of the defective items in these
u
tests are distinct, i.e.,
S_{i}\cap P\neq S_{i^{\prime}}\cap P
for any
i\neq i^{\prime}
. The by augmenting
S_{i}
to a
(d-u)
-disjunct matrix
\mathcal{M}
for testing and decoding, we can recover set
P\setminus S_{i}
. Therefore, the defective set
P
can be recover by setting
P=\bigvee_{i=1}^{u}(P\setminus S_{i})
.

We define some notations as follows. The exclusion-wise operator between two vectors of same size
\mathbf{z}=(z_{1},\ldots,z_{n})
and
\mathbf{z}^{\prime}=(z_{1}^{\prime},\ldots,z_{n}^{\prime})
is
\mathbf{z}\circ\mathbf{z}^{\prime}=(z_{1}^{\prime}\oplus(z_{1}^{\prime}\wedge z_{1}),\ldots,z_{n}^{\prime}\oplus(z_{n}^{\prime}\wedge z_{n}))
, where

\mathsf{supp}(\mathbf{z}\circ\mathbf{z}^{\prime})=\mathsf{supp}(\mathbf{z}^{\prime})\setminus\mathsf{supp}(\mathbf{z})
. Then the exclusion operator between two matrices
\mathcal{A}
and
\mathcal{B}

\mathcal{B}\circ\mathcal{A}:=\begin{bmatrix}\mathcal{B}\circ\mathcal{A}(1,:)\\
\vdots\\
\mathcal{B}\circ\mathcal{A}(a,:)\end{bmatrix}
, where
\mathcal{B}\circ\mathcal{A}(i,:):=\begin{bmatrix}\mathcal{B}(1,:)\circ\mathcal{A}(i,:)\\
\vdots\\
\mathcal{B}(b,:)\circ\mathcal{A}(i,:)\end{bmatrix}
for
i=1,\ldots,a
.

Similarly, the OR-wise operator between two vectors of same size
\mathbf{z}=(z_{1},\ldots,z_{n})
and
\mathbf{z}^{\prime}=(z_{1}^{\prime},\ldots,z_{n}^{\prime})

\mathbf{z}\vee\mathbf{z}^{\prime}=(z_{1}\vee z_{1}^{\prime},\ldots,z_{n}\vee z_{n}^{\prime})
. In other words,
\mathsf{supp}(\mathbf{z}\vee\mathbf{z}^{\prime})=\mathsf{supp}(\mathbf{z})\cup\mathsf{supp}(\mathbf{z}^{\prime})
. The OR operator between two matrices

\mathcal{B}\vee\mathcal{A}:=\begin{bmatrix}\mathcal{B}\vee\mathcal{A}(1,:)\\

.

III-C
4
Correctness

We first state a useful lemma in utilizing disjunct matrices to identify defective items with auxiliary set. The full proof and complexity are presented in the full version.

Lemma 2
.

Consider
(n,\bar{p},u)
-TGT, i.e., TGT without gap and the number of defective items is at most
p
. Let
P
and
\mathcal{M}
be a defective set and a
t\times n

p
-disjunct matrix, where
|P|\leq p
. Let
\mathbf{x}\in\{0,1\}^{n}
be an input vector and
\mathbf{y}=\mathsf{test}(\mathcal{M}\vee\mathbf{x})
. Then if
\mathsf{test}(\mathbf{x})=0
, for any decoding procedure with the exact recovery in standard group testing with the measurement matrix
\mathcal{M}
and the outcome vector
\mathbf{y}
, the returned defective set is
P\setminus\mathsf{supp}(\mathbf{x})
if
|\mathsf{supp}(\mathbf{x})\cap P|=u-1
and an empty set if
|\mathsf{supp}(\mathbf{x})\cap P|<u-1
.

As described in Section
III-C1
, we need to prove that there exist
u
sets
S_{1},\ldots,S_{u}\subseteq[n]
such that each set contains exactly
u-1
defective items and
S_{i}\cap P\neq S_{i^{\prime}}\cap P
for any
i\neq i^{\prime}
. Indeed, since
\mathcal{A}
is a
(d,u,n)
-single selector and
|P|=d
, there exists a row
r^{*}
such that
|\mathsf{supp}(\mathcal{A}(r^{*},:))\cap P|=u
. Let
Q=\mathsf{supp}(\mathcal{A}(r^{*},:))\cap P
. Because
\mathcal{B}
is a
u
-disjunct matrix, for any
q\in Q
, there exists a row, denoted as
r_{q}
, such that
\mathsf{supp}(\mathcal{B}(r_{q},:))\cap Q=\{q\}
. On the other hand,
\mathsf{supp}(\mathcal{B}(r_{q},:)\circ\mathcal{A}(r^{*},:))=(\mathsf{supp}(\mathcal{A}(r^{*},:))\setminus\mathsf{supp}(\mathcal{B}(r_{q},:))\cup(\mathsf{supp}(\mathcal{B}(r_{q},:)\setminus\mathsf{supp}(\mathcal{A}(r^{*},:)))
. Therefore,
\mathsf{supp}(\mathcal{B}(r_{q},:)\circ\mathcal{A}(r^{*},:))\cap P=(\mathsf{supp}(\mathcal{A}(r^{*},:))\cap P)\setminus(\mathsf{supp}(\mathcal{B}(r_{q},:)\cap P)=Q\setminus\{q\}
. Since
|Q|=u
, there thus exist
u
sets
S_{1},\ldots,S_{u}\subseteq[n]
such that each set contains exactly
u-1
defective items and
S_{i}\cap P\neq S_{i^{\prime}}\cap P
for any
i\neq i^{\prime}
. On the other hand,
\mathsf{test}(\mathcal{A}(r^{*},:))
is positive and
\mathsf{test}(\mathcal{B}(r_{q},:)\circ\mathcal{A}(r^{*},:))
is negative, by using Lemma
2

\mathcal{M}
is a
(d-u+1)
-disjunct matrix, we get
\mathsf{test}(\mathcal{M}\vee(\mathcal{B}(r_{q},:)\circ\mathcal{A}(r^{*},:)))=\mathsf{test}(\mathcal{M},Q\setminus\{q\})
. Therefore, set
S_{r^{*},r_{q}}=\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee(\mathcal{B}(r_{q},:)\circ\mathcal{A}(r^{*},:))),\mathcal{M})

. This implies the set

To complete our proof, we need to show that the decoding procedure never adds false defective items to the defective set. Consider
i\in[a]

then
\mathsf{test}(\mathcal{A}(i,:))
is negative. Therefore, no items are added to

. If
\mathsf{test}(\mathcal{A}(i,:))
is positive and
\mathsf{test}(\mathcal{B}(i^{\prime},:)\circ\mathcal{A}(i,:))

\mathsf{test}(\mathcal{A}(i,:))
is positive and
\mathsf{test}(\mathcal{B}(i^{\prime},:)\circ\mathcal{A}(i,:))

•

|\mathcal{A}(i,:)\cap P|=u
and
|\mathsf{supp}(\mathcal{B}(i^{\prime},:)\circ\mathcal{A}(i,:))\cap P|<u
.

•

|\mathcal{A}(i,:)\cap P|>u
and
|\mathsf{supp}(\mathcal{B}(i^{\prime},:)\circ\mathcal{A}(i,:))\cap P|<u
.

In both cases, by Lemma
2

By using Lemma

a=O\left(\min\left\{u^{u},(d-u)^{d-u}\right\}d\log{\frac{n}{d}}\right)

IV
Non-adaptive and 2-stage designs for
u=2

In this section, we present designs with decoding time of
O(d^{2}\log^{2}{(n/d)})
to find the defective set for
(n,d,\ell=1,u=2)
-TGT. When
u=2
, we only need two rows in which each row contains exactly one defective item and the two defective items in the two rows are distinct. This idea was proposed in
[
29
]
for a randomized and non-adaptive design. Since our designs are deterministic, the technical details are different from theirs. We first present the notion of selectors which will be used for our designs later.

IV-A

Selectors

To have an efficient decoding procedure, we recall a tool named
selectors
which were introduced by De Bonis et al.
[
13
]
.

Definition 3
.

[
13
]

Given integers
k
,
m
, and
n
, with
1\leq m\leq k\leq n
, we say that a Boolean matrix M with
t
rows and
n
columns is a
(k,m,n)
-selector if any submatrix of
\mathcal{M}
obtained by choosing
k
out of
n
arbitrary columns of
\mathcal{M}
contains at least
m
distinct rows of the identity matrix
\mathcal{I}_{k}
. The integer
t
is the size of the
(k,m,n)
-selector.

Theorem 5
.

[
13
, Theorem 1]

Given integers
1\leq m\leq k\leq n
, there exists a
(k,m,n)
-selector of size
t
, with

t<\frac{\mathrm{e}k^{2}}{k-m+1}\log{\frac{n}{k}}+\frac{\mathrm{e}k(2k-1)}{k-m+1}.

IV-B

Main idea

Our main idea consists of two parts:

•

Use a
(2d,d+2,n)
-selector to obtain at least two indicating subsets in which each contains only one defective item and non-defective items.

•

For each indicating subset, add it to every test in SGT to find the defective items. In particular, a test is positive if at least one more defective item is present and negative otherwise. Hence, the standard group testing techniques can be applied to find the defective items.

We present the results of non-adaptive and 2-stage designs in Theorem
2
and their details in the subsequent sections. Note that the proofs of their complexities are presented in the full version.

IV-C

Non-adaptive design

Encoding:
We first initialize a
(2d,d+2,n)
-selector
\mathcal{A}
of size
a\times n
and an
m\times n

d
-disjunct matrix
\mathcal{M}
. Then we generate three types of vectors: indicator vector
\mathbf{y}:=\mathsf{test}(\mathcal{A})
, reference vector
\mathbf{r}:=\mathsf{test}(\mathcal{A}\vee\mathcal{A})
, and identification vector
\mathbf{f}:=\mathsf{test}(\mathcal{M}\vee\mathcal{A})
. The indicator and reference vectors are used to locate two tests such that they contain two distinct defective items and each contains only one defective item. The identification vector is then to recover the defective set based on these two tests.

Decoding:
We first find two indices
i_{1}\neq i_{2}\in[a]
by scanning the indicator vector
\mathbf{y}
and the reference vector
\mathbf{r}
such that
\mathsf{test}(\mathcal{A}(i_{1},:))=\mathsf{test}(\mathcal{A}(i_{2},:))=0
and
\mathsf{test}(\mathcal{A}(i_{1},:)\vee\mathcal{A}(i_{2},:))=1
. Then the defective set is
P=\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{1},:)),\mathcal{M})\cup\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{2},:)),\mathcal{M})
.

Correctness:
Consider an arbitrary set
C\subset[n]
with
C\cap P=P
and
|C|=2d
. From Definition
3
, since
\mathcal{A}
is a
(2d,d+2,n)
-selector, there exists at least
d+2
distinct rows of the identity matrix
\mathcal{I}_{2d}
. Because
|P|=d\geq 2
, there must exist two rows
i_{1}
and
i_{2}
in
\mathcal{A}
such that two distinct defective items belong to them and each row contains a single defective item. In other words,
\mathsf{supp}(\mathcal{A}(i_{1},:))\cap P=\{p_{1}\}
and
\mathsf{supp}(\mathcal{A}(i_{2},:))\cap P=\{p_{2}\}
for
p_{1}\neq p_{2}\in P
. Because
\mathsf{test}(\mathcal{A}(i_{1},:))=\mathsf{test}(\mathcal{A}(i_{2},:))=0
, by Lemma
2
, we get
\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{1},:)),\mathcal{M})=P\setminus\{p_{1}\}
and
\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{2},:)),\mathcal{M})=P\setminus\{p_{2}\}
. Therefore, we always get
P\subseteq S
.

Now we prove that
S
never contains false defective items. Indeed, because we only process row
i
with
\mathsf{test}(\mathcal{A}(i,:))=0
, row
\mathcal{A}(i,:)
satisfies
|\mathsf{supp}(\mathcal{A}(i,:))\cap P|\leq u-1=1
. Therefore, by Lemma
2
, the procedure
\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i,:)),\mathcal{M})
either return to a set of defective items or an empty set. Set
S
thus never contains false defective items.

Complexity:
By using the result in Theorem
5
, the number of tests in
\mathcal{A}
is
a=O\big(d\log{\frac{n}{d}}\big)
. By Theorem
3
, an
m\times n

d
-disjunct matrix
\mathcal{M}
can be efficiently decoded in
O\big(m+d\log^{2}{(n/d)}\big)
time with
m=O\big(d^{2}\min(n,d)\big)
. Therefore, the number of tests the non-adaptive design is:

\displaystyle a+a^{2}+am=O\left(d^{3}\log{\frac{n}{d}}\cdot\min(n,d)\right).

To identify
i_{1}
and
i_{2}
, it takes
O(a^{2})=O\big(d^{2}\log^{2}{\frac{n}{d}}\big)
time. Because of the construction of
\mathcal{M}
, it takes
2O\big(d^{2}\min\{\log{n},(\log_{d}{n})^{2}\}+d\log^{2}{(n/d)}\big)
time to run
\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{1},:)),\mathcal{M})
and
\mathrm{dec}(\mathsf{test}(\mathcal{M}\vee\mathcal{A}(i_{2},:)),\mathcal{M})
. Therefore, it takes
O\left(d^{2}\left(\log^{2}{\frac{n}{d}}+\min(n,d)\right)\right)
time to run the non-adaptive design.

IV-D

2-stage design

Encoding and decoding:
In the first stage, we utilize matrices
\mathcal{A},\mathcal{M}
, the indicator vector
\mathbf{y}
, the reference vector
\mathbf{r}
in Section
IV-C
. However, we amend vector
\mathbf{f}
as follows. We initialize a
(d,d,n)
-list disjunct matrix
\mathcal{H}
of size
h\times n
as in Theorem
4
which can be decoded in
O\big(d\log^{2}{(n/d)}\big)
time with
h=O\big(d\log{(n/d)}\big)
. Then we set
\mathbf{f}=\mathsf{test}(\mathcal{H}\vee\mathcal{A})
.

In the second stage, we first find two indices
i_{1}\neq i_{2}\in[a]
by scanning the indicator vector
\mathbf{y}
and
\mathbf{r}
such that
\mathsf{test}(\mathcal{A}(i_{1},:))=\mathsf{test}(\mathcal{A}(i_{2},:))=0
and
\mathsf{test}(\mathcal{A}(i_{1},:)\vee\mathcal{A}(i_{2},:))=1
. Then the approximate defective set is
R=\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{1},:)),\mathcal{H})\cup\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{2},:)),\mathcal{H})
. Finally, we test every two items in
R
. If a test on two items is positive then we add them to the defective set.

Correctness:
Similar to the analysis in Section
IV-C
, when
\mathsf{test}(\mathcal{A}(i_{1},:))=\mathsf{test}(\mathcal{A}(i_{2},:))=0
and
\mathsf{test}(\mathcal{A}(i_{1},:)\vee\mathcal{A}(i_{2},:))=1
, we get
|\mathcal{A}(i_{1},:)\cap P|=1
and
|\mathcal{A}(i_{2},:)\cap P|=1
. Let
\{p_{1}\}=\mathcal{A}(i_{1},:)\cap P
and
\{p_{2}\}=\mathcal{A}(i_{2},:)\cap P
. It is straightforward that
p_{1}\neq p_{2}
.

When
|\mathsf{supp}(\mathbf{x})\cap P|=u-1
, it is easy to confirm that
\mathcal{T}\otimes\mathbf{x}=\mathcal{T}\odot\mathsf{vecc}(P\setminus(\mathsf{supp}(\mathbf{x})\cap P))
for any matrix
\mathcal{T}
. Therefore, we have
\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{1},:))=\mathcal{H}\odot\mathsf{vecc}(P\setminus(\mathcal{A}(i_{1},:)\cap P))=\mathcal{H}\odot\mathsf{vecc}(P\setminus\{p_{1}\})
and
\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{2},:))=\mathcal{H}\odot\mathsf{vecc}(P\setminus(\mathcal{A}(i_{2},:)\cap P))=\mathcal{H}\odot\mathsf{vecc}(P\setminus\{p_{2}\})
. Since
\mathcal{H}
is a
(d,d)
-list disjunct matrix, we get
\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{k},:)),\mathcal{H})=P\setminus\{p_{k}\}
and
|\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{k},:)),\mathcal{H})|\leq 2d-1
for
k=1,2
. Therefore,
|R|\leq 3d-2
. Since we are considering the case without gap with
u=2
, if a test on two items is positive, the two items must be defective. On the other hand, since
R\cap P=P
, all pairs of the defective items will be tested, and therefore, by adding every two items in a test that yields a positive outcome will recover the defective set.

Complexity:
The number of tests is:

\displaystyle a+a^{2}+ah+{|R|\choose 2}=O\left(d^{2}\log^{2}{\frac{n}{d}}\right).

In the second stage, to identify
i_{1}
and
i_{2}
, it takes
O(a^{2})=O\big(d^{2}\log^{2}{\frac{n}{d}}\big)
time. Because of the construction of
\mathcal{H}
, it takes
O\big(d\log^{2}{(n/d)}\big)
time to decode
\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{1},:)),\mathcal{H})
and
\mathrm{dec}(\mathsf{test}(\mathcal{H}\vee\mathcal{A}(i_{2},:)),\mathcal{H})
. Finally, it takes
O\big({|R|\choose 2}\big)=O({3d-2\choose 2})=O(d^{2})
time to get the defective set
P
. In summary, it takes
O\big(d^{2}\log^{2}{\frac{n}{d}}\big)+O\big(d\log^{2}{(n/d)}\big)+O(d^{2})=O\big(d^{2}\log^{2}{\frac{n}{d}}\big)
time to run the 2-stage design.

V
Conclusion

In this paper, we first present efficient decoding designs with a polynomial time of
\min\{u^{u},(d-u)^{d-u}\},d
, and
\log{n}
for TGT without gap under the deterministic design, the combinatorial setting, and the exact recovery criterion. It is inciting to extend this work for the case TGT with a gap. Another interesting question is whether the designs here are applicable to find hidden graphs in learning theory.

Appendix A
Proof of Lemma
2

Consider
y_{i}=\mathsf{test}(\mathcal{M}(i,:)\vee\mathbf{x})=\mathsf{test}(\mathsf{supp}(\mathcal{M}(i,:))\cup\mathsf{supp}(\mathbf{x}))
for
i=1,\ldots,t
. Since
\mathcal{M}
is a
p
-disjunct matrix, For every defective item
r\in P
, there exists a row
i_{r}
, called
a private row
, such that that row contains
r
and does not contain the remaining items in
P\setminus\{r\}
. Therefore, if
|\mathsf{supp}(\mathbf{x})\cap P|<u-1
,
y_{i_{r}}=0
. Consequently, any decoding procedure with the exact recovery in standard group testing with the measurement matrix
\mathcal{M}
must declare item
r
as non-defective. Therefore, the decoding procedure returns an empty set.

When
|\mathsf{supp}(\mathbf{x})\cap P|=u-1
, for any
r\in\mathsf{supp}(\mathbf{x})\cap P
, we get
y_{i_{r}}=0
because row
i_{r}
contains only
u-1
defective items in
\mathsf{supp}(\mathbf{x})\cap P
. Therefore, any item in
\mathsf{supp}(\mathbf{x})\cap P
will not be included in the returned defective set by any decoding procedure with the exact recovery in standard group testing. On the other hand, for any
r^{\prime}\in P\setminus\mathsf{supp}(\mathbf{x})
, every test that includes
r^{\prime}
is positive. Because
\mathcal{M}
is a
p
-disjunct matrix, item
i^{\prime}
will be included in the returned defective set by any decoding procedure with the exact recovery in standard group testing. In other words, the returned defective set is
P\setminus\mathsf{supp}(\mathbf{x})
if
|\mathsf{supp}(\mathbf{x})\cap P|=u-1
.
