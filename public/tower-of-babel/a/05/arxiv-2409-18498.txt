Improved Approximation Algorithms for Relational Clustering
Aryan Esmailpour, Stavros Sintos

Abstract
. Clustering plays a crucial role in computer science, facilitating data analysis and problem-solving across numerous fields. By partitioning large datasets into meaningful groups, clustering reveals hidden structures and relationships within the data, aiding tasks such as unsupervised learning, classification, anomaly detection, and recommendation systems. Particularly in relational databases, where data is distributed across multiple tables, efficient clustering is essential yet challenging due to the computational complexity of joining tables. This paper addresses this challenge by introducing efficient algorithms for k k -median and k k -means clustering on relational data without the need for pre-computing the join query results. For the relational k k -median clustering, we propose the first efficient relative approximation algorithm. For the relational k k -means clustering, our algorithm significantly improves both the approximation factor and the running time of the known relational k k -means clustering algorithms, which suffer either from large constant approximation factors, or expensive running time. 1.
Introduction

Clustering is a fundamental process in computer science, serving as a vital tool for data analysis, pattern recognition, and problem-solving across various domains. Through clustering, large datasets are partitioned into meaningful groups, unveiling hidden structures and relationships within the data. In machine learning, clustering algorithms are used to enable tasks such as classification, anomaly detection, and recommendation systems.
Its significance lies in its ability to transform raw data into useful knowledge, empowering researchers, and businesses to make informed decisions.

In relational databases, data is gathered and stored across various tables.
Each table consists of a set of tuples and two tuples stored in different tables might refer to the same entity.
Relational data is decoupled into different relational tables, and we cannot obtain the full data unless all the tables are joined.
This setting is quite common in real database management systems (DBMS).
As shown in the DB-engines study
(
1
)
the vast majority of database systems are relational DBMS.
Kaggle surveys
(
2
)
demonstrate that most of the learning tasks encountered by data scientists involve relational data. More specifically, 70% of database systems are relational DBMS and 65% of the data sets in learning tasks are relational data.
As mentioned in
(
20
)
, relational data is expected to reach $122.38 billion by 2027
(
50
)
in investments.

In order to explore and process relational data, usually two steps are required: data preparation, and data processing. In the data preparation step, tuples from different tables are joined to construct useful data, while in data processing, an algorithm (for example a clustering algorithm) is performed on the join results to analyze the data. This two-step approach is usually too expensive because the size of the join results can be polynomially larger than the total size of the input tables
(
47
,
48
)
.

In this paper, given a (full) conjunctive query and a database instance, we study efficient
k
-median and
k
-means clustering on the results of the query without first computing the query results.
While there are recent papers
(
20
,
23
,
45
)
on designing clustering algorithms on relational data, they usually suffer from i) large additive approximation error, ii) large constant relative approximation error, and iii) expensive running time.

Despite recent attention to relational clustering, the problem of efficiently solving relational
k
-median clustering without additive approximation error remained unsolved.
In this paper, we propose the first efficient relative approximation algorithm for the
k
-median clustering on relational data. Furthermore, by extending our methods, we design an algorithm for the
k
-means clustering on relational data that dominates (with respect to both the running time and the approximation ratio) all the known relative approximation algorithms.

Let

over any database instance. More formally, for every database instance

(

For every acyclic join query

Given a cyclic join query

[Relational

\mathbf{D}
, a join query

, and a positive integer parameter

Definition 1.2.

[Relational

\mathbf{D}
, a join query
\bm{q}
, and a positive integer parameter

\mathcal{S}\subseteq\mathbb{R}^{d}

\mu_{\mathcal{S}}(\bm{q}(\mathbf{D}))

k

By relational

We note that the clustering problem on relational data is defined over the unweighted set
\bm{q}(\mathbf{D})
.
In order to propose efficient algorithms we will need to construct weighted subset of tuples (

Approximation

We say that an algorithm is a relative
\beta
-approximation algorithm for the relational
k
-median clustering if it returns a set
\mathcal{S}
of size
k
such that
\textbf{v}_{\mathcal{S}}(\bm{q}(\mathbf{D}))\leq\beta\cdot\textbf{v}_{\mathsf{OPT}(\bm{q}(\mathbf{D}))}\bm{q}(\mathbf{D})
. Next, we say that an algorithm is an additive
\beta
-approximation algorithm for the relational
k
-median clustering if it returns a set
\mathcal{S}
of size
k
such that
\textbf{v}_{\mathcal{S}}(\bm{q}(\mathbf{D}))\leq\textbf{v}_{\mathsf{OPT}(\bm{q}(\mathbf{D}))}\bm{q}(\mathbf{D})+\beta
. In this paper, we focus on relative approximation algorithms, so when we refer to a
\beta
-approximation algorithm we always mean relative
\beta
-approximation.
Equivalently, we define relative and additive approximation algorithms for the relational
k
-means clustering.

Coreset

We give the definition of coresets for both the relational

A weighted set

(1)

(1-\varepsilon)\textbf{v}_{Y}(\bm{q}(\mathbf{D}))\leq\textbf{v}_{Y}(\mathcal{C})\leq(1+\varepsilon)\textbf{v}_{Y}(\bm{q}(\mathbf{D})).

Similarly, a weighted set

(2)

2.2.
Data structures for aggregation queries

In this subsection, we show how we can combine known results in database theory to answer aggregation queries in linear time with respect to the size of the database.

Let
\mathcal{R}
be an axis-parallel hyper-rectangle in
\mathbb{R}^{d}
.The goal is i) count the number of tuples
|\bm{q}(\mathbf{D})\cap\mathcal{R}|
, and ii) sample uniformly at random from
\bm{q}(\mathbf{D})\cap\mathcal{R}
.
The axis-parallel hyper-rectangle
\mathcal{R}
is defined as the product of
d
intervals over the attributes, i.e.,
\mathcal{R}=\{I_{1}\times\ldots\times I_{d})
, where
I_{i}=[a_{i},b_{i}]
for
a_{i},b_{i}\in\mathbb{R}
.
Hence,
\mathcal{R}
defines a set of
d
linear inequalities over the attributes, i.e., a tuple
t
lies in
\mathcal{R}
if and only if
a_{j}\leq\pi_{A_{j}}(t)\leq b_{j}
for every
A_{j}\in{\mathbf{A}}
.
Let
p
be a tuple in a relation
R_{i}
.
If
a_{j}\leq\pi_{A_{j}}(p)\leq b_{j}
for every
A_{j}\in{\mathbf{A}}_{i}
, then we keep
p
in
R_{i}
. Otherwise, we remove it. The set of surviving tuples is exactly the set of tuples that might lead to join results in
\mathcal{R}
. Let
\mathbf{D}^{\prime}\subseteq\mathbf{D}
be the new database instance such that
\bm{q}(\mathbf{D}^{\prime})=\bm{q}(\mathbf{D})\cap\mathcal{R}
. The set
\mathbf{D}^{\prime}
is found in
O(N)
time.
Using Yannakakis algorithm
(
58
)
we can count
|\bm{q}(\mathbf{D}^{\prime})|
in
O(N\log N)
time and using
(
59
)
we can sample
z
tuples from
\bm{q}(\mathbf{D}^{\prime})
in
O((N+z)\log N)
time. Using hashing, we can improve the running time of the algorithms to
O(N)
and
O(N+z\log N)
, respectively.

Lemma 2.1.

Let
\mathcal{R}
be a rectangle in
\mathbb{R}^{d}
. There exists an algorithm

to count

in
O(N\log N)
time or
O(N)
time with high probability. Furtheremore, there exists an algorithm

to sample
z

\bm{q}(\mathbf{D})\cap\mathcal{R}
in
O((N+z)\log N)
time or
O(N+z\log N)
time with high probability.

Let
B\subseteq{\mathbf{A}}
be a subset of the attributes. The result in Lemma
2.1
can also be used (straightforwardly) to compute
|\widebar{\pi}_{B}(\bm{q}(\mathbf{D}))\cap\mathcal{R}|
or sample
z
samples from
\widebar{\pi}_{B}(\bm{q}(\mathbf{D}))\cap\mathcal{R}
in the same running time, since

.

2.3.
High level ideas

Before we start with the technical sections of the paper, we give high level ideas of our methods.

In Section
3
, we assume that a set of centers
X
for the relational
k
-median clustering is given such that
\textbf{v}_{X}(\bm{q}(\mathbf{D}))
is within a constant factor from the optimum
k
-median error with
|X|>k
.
Using
X
, we construct a coreset
\mathcal{C}
for the relational
k
-median problem.
Then we run
\mathsf{GkMedianAlg}_{\gamma}
(or
\mathsf{DkMeansAlg}_{\gamma}
for the discrete version) on
\mathcal{C}
to obtain the final solution
\mathcal{S}
. While all previous papers on relational clustering
(
20
,
23
,
45
)
construct weighted coresets, the coresets that were used are sub-optimal. Instead, we use and modify the coreset construction from
(
34
)
, which is a more optimized coreset for the
k
-median (and
k
-means) clustering under the Euclidean metric, in the standard computational setting. Of course, using such a coreset comes at a cost.
First, it is not clear how to construct a set
X
with the desired properties on relational data, efficiently. In Section
4
we show how to construct
X
designing a hierarchical method over the attributes
{\mathbf{A}}
.
Second, it is not straightforward to construct the coreset in
(
34
)
on relational data, given
X
. In fact, the coreset construction in
(
34
)
cannot be applied (efficiently) in the relational setting. Hence, inspired by
(
34
)
, we design a novel small coreset based on
X
and show that it can be applied to relational data.

More specifically, for any center
x_{i}\in X
, in
(
34
)
, the authors first compute all points in the dataset that have
x_{i}
as the closest center in
X
. Let
P_{i}
be this set of points. Then, they construct a grid around
x_{i}
, and from every cell
\square
in the grid, they add one representative point from
P_{i}\cap\square
with weight
|P_{i}\cap\square|
.
Unfortunately, in our setting we cannot compute
P_{i}
and/or
|P_{i}\cap\square|
efficiently.

We resolve the two issues as follows.
First, we construct a grid around
x_{i}
, but instead of computing all tuples that have
x_{i}
as the closest center and process all cells, we check whether a cell
\square
is close enough to the center
x_{i}
(Equation (
3
) in the next section). If not then we skip the cell. If yes, then we take a representative tuple from
\square
and we set its weight to be the number of tuples in
\square
that do not lie in a different cell that has been already processed by our algorithm. Of course, the weight of a representative tuple now is not the same as in
(
34
)
and we might count tuples even outside of
P_{i}
, however with a careful analysis we make sure that the overall error is still bounded.
The second problem though, still remains; we need to count the number of tuples in
\square
excluding the cells we have already visited from previous centers in
X
(notice that the grid cells of two different centers in
X
might intersect). We propose two methods to achieve it. In Section
3.1
we give a deterministic method that constructs the arrangement of the complement of the visited cells and we use Lemma
2.1
to count the number of tuples, exactly. However, this algorithm requires
\Omega(|X|^{d}N)
time. In Section
3.2
we give a more involved and faster randomized approximation algorithm to count the number of tuples based on sampling.

3.
From many centers to exactly
k
centers

We describe an algorithm that constructs a coreset for the relational
k
-median clustering over the (multi-set) projection of
\bm{q}(\mathbf{D})
on an arbitrary subset of attributes.
Let
{\mathbf{A}}_{u}\subseteq{\mathbf{A}}
be a subset of the attributes. Let

Assume that

We also assume that

In this section we propose two algorithms that take as input

-median problem in
\bm{q}_{u}(\mathbf{D})

We also note that if

approximation solution for the relational
k
-median clustering problem on

\displaystyle\mathcal{E}

5.
Conclusion

In this paper we propose improved approximation algorithms for the relational
k
-median and
k
-means clustering.
There are multiple interesting open problems derived from this work. It is interesting to check whether our geometric algorithms can be extended other clustering objective functions such as the sum of radii clustering. It is also interesting to use the ideas proposed in this paper to design clustering algorithms on the results of more complex queries such as conjunctive queries with inequalities or conjunctive queries with negation. Finally, someone can study relational clustering under different distance functions such as the Hamming, Jaccard or the cosine distance.

\mu_{X}(\bm{q}_{u}(\mathbf{D}))=\sum_{t\in\bm{q}(\mathbf{D})}\phi^{2}(\pi_{{\mathbf{A}}_{u}}(t),X).

We also assume that
r
is a real number such that
\mu_{X}(\bm{q}_{u}(\mathbf{D}))\leq r\leq\alpha\cdot\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))
.
In fact, we can also assume that
\frac{r}{1+\varepsilon}\leq\mu_{X}(\bm{q}_{u}(\mathbf{D}))
.
Note that again we do not assume anything about the size of

, and in the next section, we show that we can always consider
|X|=O(k^{2})
. Again, we assume that at first, the set
X
and the number
r
are given as input, and later we describe the algorithm to efficiently construct
X
and
r
. Similarly to the relational
k
-median clustering, we propose two algorithms, one slower deterministic and one faster randomized. The running times of the algorithms are the same as the running times of the algorithms for the relational
k
-median clustering.

A.2.
Deterministic algorithm for k-means

We set
\Phi=\sqrt{\frac{r}{\alpha n}}
to be a lower bound estimate of the average mean radius
\sqrt{\frac{\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))}{n}}
, and keep all other parameters as described for the
k
-median coreset in section
3.1
. Then we construct the same exponential grids and follow the exact same algorithms to get the coreset
\mathcal{C}
. Then, we run the standard algorithm for the weighted
k
-means problem on
\mathcal{C}
,
\mathsf{GkMeansAlg}_{\gamma}(\mathcal{C})
, to get a set of
k
centers
\mathcal{S}
. We return the set of centers
\mathcal{S}
. Furthermore, we set and return
r_{u}=\frac{1}{1-\varepsilon}\mu_{\mathcal{S}}(\mathcal{C})
.

Correctness

We conduct a correctness analysis by proving analogous versions of the lemmas established for the
k
-median clustering, but this time for the
k
-means clustering.

For any tuple
t\in\bm{q}_{u}(\mathbf{D})
, let
x_{i}\in X
be the center that is closest to
t
. We have that
\phi(t,x_{i})\leq\alpha n\Phi
. So,
the following lemma is correct by the same argument as in lemma
3.1
.

Lemma A.1.

Every tuple
t\in\bm{q}_{u}(\mathbf{D})
is assigned to one point in
\mathcal{C}
. Furthermore, the number of tuples in
\bm{q}_{u}(\mathbf{D})
that are assigned to a point
s\in\mathcal{C}
is
w(s)
.

Any point
t\in\bm{q}_{u}(\mathbf{D})
is assigned to one point in
\mathcal{C}
, so we can define
x_{i(t)}
and
\sigma(t)
as before.

Lemma A.2.

\mathcal{C}
is a
k
-means
\varepsilon
-coreset for
\bm{q}_{u}(\mathbf{D})
.

Proof.

Let
Y
be an arbitrary set of
k
points in
\mathbb{R}^{d_{u}}
. The error is defined as

\displaystyle\mathcal{E}=|\mu_{Y}(\bm{q}(\mathbf{D}))-\mu_{Y}(\mathcal{C})|

\displaystyle\leq\sum_{t\in\bm{q}_{u}(\mathbf{D})}|\phi^{2}(t,Y)-\phi^{2}(\sigma(t),Y)|

\displaystyle=\sum_{t\in\bm{q}_{u}(\mathbf{D})}|(\phi(t,Y)-\phi(\sigma(t),Y))(\phi(t,Y)+\phi(\sigma(t),Y))|.

By the triangle inequality,
\phi(t,Y)\leq\phi(\sigma(t),Y)+\phi(t,\sigma(t))
and
\phi(\sigma(t),Y)\leq\phi(t,Y)+\phi(t,\sigma(t))
. Hence,
|\phi(t,Y)-\phi(\sigma(t),Y)|\leq\phi(t,\sigma(t))
.
We have,

\displaystyle\mathcal{E}\leq\sum_{t\in\bm{q}_{u}(\mathbf{D})}|(\phi(t,Y)-\phi(\sigma(t),Y))(\phi(t,Y)+\phi(\sigma(t),Y))|\leq\sum_{t\in\bm{q}_{u}(\mathbf{D})}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t)).

Now we divide the points of
\bm{q}_{u}(\mathbf{D})
into three cases. Let
P_{R}=\{t\in\bm{q}_{u}(\mathbf{D})|\phi(t,x_{i(t)})\leq\Phi\land\phi(t,Y)\leq\Phi\}
, and
P_{X}=\{t\in\bm{q}_{u}(\mathbf{D})\setminus P_{R}|\phi(t,Y)\leq\phi(t,x_{i(t)})\}
, and
P_{Y}=\{t\in\bm{q}_{u}(\mathbf{D})\setminus P_{R}|\phi(t,x_{i(t)})<\phi(t,Y)\}
. Note that we do not actually construct these sets, instead we only analyze the error induced by these three types of points separately. It is straightforward to see that
P_{R}\cup P_{X}\cup P_{Y}=\bm{q}_{u}(\mathbf{D})
and
P_{R}\cap P_{X}=\emptyset
,
P_{R}\cap P_{Y}=\emptyset
,
P_{X}\cap P_{Y}=\emptyset
.

For a point
t\in P_{R}
, since
\phi(t,x_{i(t)})\leq\Phi
, by the construction of the exponential grid, we have that
\phi(t,\sigma(t))\leq\textsf{diam}(\square_{t})\leq\frac{\varepsilon}{10\alpha}\Phi
, hence

\displaystyle\sum_{t\in P_{R}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))\leq\sum_{t\in P_{R}}\frac{\varepsilon}{10\alpha}\Phi(2\Phi+\frac{\varepsilon}{10\alpha}\Phi)\leq\frac{3\varepsilon}{10\alpha}n\Phi^{2}\leq\frac{3\varepsilon}{10}\mu_{OPT(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D})).

By the definition of the set
P_{X}
, we have
\phi(t,x_{i(t)})>\Phi
, hence, as shown in the proof of lemma
3.2
,
\phi(t,\sigma(t))\leq\frac{\varepsilon}{10\alpha}\phi(t,x_{i(t)})
, and
\phi(t,x_{i(t)})\leq(1+\frac{4\varepsilon}{10\alpha})\phi(t,X)
. Therefore,

\displaystyle\sum_{t\in P_{X}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))\leq\sum_{t\in P_{X}}\frac{\varepsilon}{10\alpha}\phi(t,x_{i(t)})(2\phi(t,x_{i(t)})+\frac{\varepsilon}{10\alpha}\phi(t,x_{i(t)}))

\displaystyle\leq\frac{3\varepsilon}{10\alpha}\sum_{t\in P_{X}}\phi^{2}(t,x_{i(t)})\leq\frac{3\varepsilon}{10\alpha}\sum_{t\in P_{X}}((1+\frac{4\varepsilon}{10\alpha})\phi^{2}(t,X))\leq\frac{12\varepsilon}{10\alpha}\mu_{X}(\bm{q}_{u}(\mathbf{D}))\leq\frac{12\varepsilon}{10}\mu_{OPT(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D})).

For the last case we have
\phi(t,\sigma(t))\leq\frac{\varepsilon}{10\alpha}\phi(t,Y)
.
It holds because: If
\phi(t,x_{i(t)})\leq\Phi
, then
\phi(t,\sigma(t))\leq\frac{\varepsilon}{10\alpha}\Phi\leq\frac{\varepsilon}{10\alpha}\phi(t,Y)
. If
\phi(t,x_{i(t)})>\Phi
then
\phi(t,\sigma(t))\leq\frac{\varepsilon}{10\alpha}\phi(t,x_{i(t)})\leq\frac{\varepsilon}{10\alpha}\phi(t,Y)
.
Hence, we have,

\displaystyle\sum_{t\in P_{Y}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))

\displaystyle\leq\sum_{t\in P_{Y}}\frac{\varepsilon}{10\alpha}\phi(t,Y)(2\phi(t,Y)+\frac{\varepsilon}{10\alpha}\phi(t,Y))\leq\frac{3\varepsilon}{10\alpha}\sum_{t\in P_{Y}}\phi^{2}(t,Y)

\displaystyle\leq\frac{3\varepsilon}{10\alpha}\mu_{Y}(\bm{q}_{u}(\mathbf{D})).

Finally, we bound the error,

\displaystyle\mathcal{E}

\displaystyle\leq\sum_{t\in\bm{q}_{u}(\mathbf{D})}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))

\displaystyle\leq\sum_{t\in P_{R}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))+\sum_{t\in P_{X}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))

\displaystyle\hskip 155.00023pt+\sum_{t\in P_{Y}}\phi(t,\sigma(t))(2\phi(t,Y)+\phi(t,\sigma(t))

\displaystyle\leq\frac{3\varepsilon}{10}\mu_{OPT(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))+\frac{12\varepsilon}{10}\mu_{OPT(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))+\frac{3\varepsilon}{10\alpha}\mu_{Y}(\bm{q}_{u}(\mathbf{D}))\leq\frac{18\varepsilon}{10}\mu_{Y}(\bm{q}_{u}(\mathbf{D})).

Thus, if we set
\varepsilon\leftarrow\varepsilon/18
, the result follows.
∎

Lemma A.3.

\mu_{\mathcal{S}}(\bm{q}_{u}(\mathbf{D}))\leq r_{u}\leq(1+\varepsilon)\gamma\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))

A.3.
Randomized Algorithm for k-means Clustering

The algorithm for the
k
-means problem is exactly the same as the one we described in section
3.2
for the
k
-median problem. Hence, in this section, we use the same notation and prove the additional lemmas required to show that the algorithm works also for
k
-means clustering. Note that this algorithm builds the
k
-means version of the exponential grid as described in
A.2
, and then continues with the randomized counting algorithm described in section
3.2
.

Correctness

Notice that Lemmas
3.6
and
3.7
are independent of the objective function of the problem and we can directly assume they are true without proving them again in this section.

We prove the following lemma using the same notation as in Lemma
3.8
.

Lemma A.5.

Let
Y
be an arbitrary set of
k
points in
\mathbb{R}^{d_{u}}
. It holds that
\mu_{Y}(\bar{P}_{u})\leq\varepsilon\mu_{Y}(P_{u})+\varepsilon\mu_{Y}(\bm{q}(\mathbf{D}))
and
\mu_{Y}(\bm{q}_{u}(\mathbf{D}))\leq(1+\varepsilon)\mu_{Y}(P_{u})
with probability at least
1-\frac{1}{N^{O(1)}}
.

Proof.

We first start showing the first inequality.
For a point
p\in\bar{P}_{u}
and each
h\leq\frac{1}{\varepsilon}
, by triangle inequality, we have

\phi(p,Y)\leq\phi(t_{j_{h}(p)},Y)+\phi(p,t_{j_{h}(p)}).

By squaring the above inequality we get,

\phi^{2}(p,Y)\leq 2\phi^{2}(t_{j_{h}(p)},Y)+2\phi^{2}(p,t_{j_{h}(p)}).

Taking the sum of these
\frac{1}{\varepsilon}
inequalities, we have,

\phi^{2}(p,Y)\leq 2\varepsilon\sum_{h=1}^{1/\varepsilon}\phi^{2}(t_{j_{h}(p)},Y)+2\varepsilon\sum_{h=1}^{1/\varepsilon}\phi^{2}(p,t_{j_{h}(p)}).

So, we have

\mu_{Y}(\bar{P}_{u})\leq 2\varepsilon\sum_{p\in\bar{P}_{u}}\sum_{h=1}^{1/\varepsilon}\phi^{2}(t_{j_{h}(p)},Y)+2\varepsilon\sum_{p\in\bar{P}_{u}}\sum_{h=1}^{1/\varepsilon}\phi^{2}(p,t_{j_{h}(p)}).

From Lemma
3.7
, we proved that any
t\in P_{u}
is assigned by at most one point in
\bar{P}_{u}
, so the first term in the sum can be bounded as

2\varepsilon\sum_{p\in\bar{P}_{u}}\sum_{h=1}^{1/\varepsilon}\phi^{2}(t_{j_{h}(p)},Y)\leq 2\varepsilon\sum_{t\in P_{u}}\phi^{2}(t,Y)=2\varepsilon\mu_{Y}(P_{u}).

Next, we bound the second term in the sum.

We define a new assignment function
\sigma^{\prime}
as we did in the proof of Lemma
3.8
, and with the same argument we get,

\displaystyle 2\varepsilon\sum_{p\in\bar{P}_{u}}\sum_{h=1}^{1/\varepsilon}\phi^{2}(p,t_{j_{h}(p)})\leq 2\varepsilon\sum_{t\in P_{u}}\phi^{2}(t,\sigma^{\prime}(t))\leq 2\varepsilon\sum_{t\in\bm{q}_{u}(\mathbf{D})}\phi^{2}(t,\sigma^{\prime}(t))\leq\frac{36\varepsilon}{10}\mu_{Y}(\bm{q}_{u}(\mathbf{D})).

The last inequality holds using the arguments in the proof of Lemma
A.2
.
Finally, by summing up the two terms and setting
\varepsilon\leftarrow\frac{\varepsilon}{6}
, the first inequality follows.

Then we prove the second inequality.

\mu_{Y}(P_{u})=\mu_{Y}(\bm{q}_{u}(\mathbf{D}))-\mu_{Y}(\bar{P}_{u})\geq\mu_{Y}(\bm{q}_{u}(\mathbf{D}))-\varepsilon\mu_{Y}(P_{u})-\varepsilon\mu_{Y}(\bm{q}_{u}(\mathbf{D}))\Leftrightarrow\mu_{Y}(\bm{q}_{u}(\mathbf{D}))\leq\frac{1+\varepsilon}{1-\varepsilon}\mu_{Y}(P_{u}).

If we set
\varepsilon\leftarrow\varepsilon/3
, the result follows.
∎

Lemma A.6.

\mathcal{C}
is a
k
-means
\varepsilon
-coreset of
P_{u}
with probability at least
1-\frac{1}{N^{O(1)}}
.

Proof.

Let
Y
be an arbitrary set of
k
points in
\mathbb{R}^{d_{u}}
.
With probability at least
1-\frac{1}{N^{O(1)}}
, we have,

\displaystyle\mathcal{E}

\displaystyle\!=\!|\mu_{Y}(P_{u})-\mu_{Y}(\mathcal{C})|\!=\!|\sum_{t\in P_{u}}\phi^{2}(t,Y)-\sum_{p\in\mathcal{C}}w(p)\phi^{2}(p,Y)|\!=\!|\sum_{t\in P_{u}}\phi^{2}(t,Y)-\sum_{p\in\mathcal{C}}(1+\varepsilon_{p})n_{p}\phi^{2}(p,Y)|

\displaystyle=|\sum_{t\in P_{u}}\phi^{2}(t,Y)-\sum_{t\in P_{u}}(1+\varepsilon_{\hat{\sigma}(t)})\phi^{2}(\hat{\sigma}(t),Y)|\leq\sum_{t\in P_{u}}|\phi^{2}(t,Y)-(1+\varepsilon_{\hat{\sigma}(t)})\phi^{2}(\hat{\sigma}(t),Y)|.

This inequality also follows from Lemma
3.6
. We have,

\displaystyle\mathcal{E}

\displaystyle\leq\sum_{t\in P_{u}}|\phi^{2}(t,Y)-(1+\varepsilon_{\hat{\sigma}(t)})\phi^{2}(\hat{\sigma}(t),Y)|\leq\sum_{t\in P_{u}}|\phi^{2}(t,Y)-\phi^{2}(\hat{\sigma}(t),Y)|+\varepsilon\sum_{t\in P_{u}}\phi^{2}(\hat{\sigma}(t),Y)

\displaystyle\leq\sum_{t\in P_{u}}|\phi^{2}(t,Y)-\phi^{2}(\hat{\sigma}(t),Y)|+2\varepsilon\sum_{t\in P_{u}}\left(\phi^{2}(t,\hat{\sigma}(t))+\phi^{2}(t,Y)\right).

Using the proofs of Lemma
A.2
and Lemma

, we have
\sum_{t\in P_{u}}|\phi^{2}(t,Y)-\phi^{2}(\hat{\sigma}(t),Y)|\leq(1+\varepsilon)\frac{18\varepsilon}{10}\mu_{Y}(P_{u})
, and

\displaystyle\mathcal{E}

\displaystyle\leq(1+\varepsilon)\frac{18\varepsilon}{10}\mu_{Y}(P_{u})+(1+\varepsilon)\frac{36\varepsilon^{2}}{10}\mu_{Y}(P_{u})+2\varepsilon\mu_{Y}(P_{u})\leq\frac{130}{10}\varepsilon\mu_{Y}(P_{u}).

So, if we set

, the result follows.
∎

Correctness

Recall that for any set

,

\mu_{Y}(\bm{q}_{u}(\mathbf{D}))=\sum_{t\in\bm{q}(\mathbf{D})}\phi^{2}(\pi_{{\mathbf{A}}_{u}}(t),Y)=\sum_{t\in\bm{q}(\mathbf{D})}\sum_{A_{j}\in{\mathbf{A}}_{u}}(\pi_{A_{j}}(t)-\pi_{A_{j}}(\mathcal{N}(Y,\pi_{{\mathbf{A}}_{u}}(t)))^{2}.

Assuming that
\mathcal{S}_{v},r_{v}
and

satisfy Equation
8
, we show how to compute
\mathcal{S}_{u}
and
r_{u}
that satisfy Equation

.

If we prove that
X
is a constant
\alpha
-approximation of the
k
-means problem on
\bm{q}_{u}(\mathbf{D})
and
\mu_{X}(\bm{q}_{u}(\mathbf{D}))\leq r_{u}\leq\alpha\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))
, then the correctness follows from Theorem

(or Theorem

Lemma A.9.

\mu_{X}(\bm{q}_{u}(\mathbf{D}))\leq r_{u}\leq\alpha\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))
.

Proof.

Let
\mathcal{O}_{v}=\pi_{{\mathbf{A}}_{v}}(\mathsf{OPT}(\bm{q}_{u}(\mathbf{D})))
, and
\mathcal{O}_{z}=\pi_{{\mathbf{A}}_{z}}(\mathsf{OPT}(\bm{q}_{u}(\mathbf{D})))
. We define
\mathcal{O}=\mathcal{O}_{v}\times\mathcal{O}_{z}
. Notice that
\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))\subseteq\mathcal{O}
so
\mu_{\mathcal{O}}(\bm{q}_{u}(\mathbf{D}))\leq\mu_{\mathsf{OPT}(\bm{q}_{u}(\mathbf{D}))}(\bm{q}_{u}(\mathbf{D}))
.
We have,

\displaystyle\mu_{X}

\displaystyle(\bm{q}_{u}(\mathbf{D}))=\sum_{t\in\bm{q}(\mathbf{D})}||\pi_{{\mathbf{A}}_{u}}(t)-\mathcal{N}(X,\pi_{{\mathbf{A}}_{u}}(t))||^{2}

\displaystyle=\sum_{t\in\bm{q}(\mathbf{D})}||\pi_{{\mathbf{A}}_{v}}(t)-\pi_{{\mathbf{A}}_{v}}(\mathcal{N}(X,\pi_{{\mathbf{A}}_{u}}(t)))||^{2}+\sum_{t\in\bm{q}(\mathbf{D})}||\pi_{{\mathbf{A}}_{z}}(t)-\pi_{{\mathbf{A}}_{z}}(\mathcal{N}(X,\pi_{{\mathbf{A}}_{u}}(t)))||^{2}

\displaystyle=\sum_{t\in\bm{q}(\mathbf{D})}||\pi_{{\mathbf{A}}_{v}}(t)-\mathcal{N}(\mathcal{S}_{v},\pi_{{\mathbf{A}}_{v}}(t))||^{2}+\sum_{t\in\bm{q}(\mathbf{D})}||\pi_{{\mathbf{A}}_{z}}(t)-\mathcal{N}(\mathcal{S}_{z},\pi_{{\mathbf{A}}_{z}}(t))||^{2}

We first start with some definitions.
Let
\bm{q}
be a query over a set of
d
attributes
{\mathbf{A}}
and a set of
m
relations
{\mathbf{R}}
.

A fractional edge cover of join query
\bm{q}
is a point
x=\{x_{R}\mid R\in{\mathbf{R}}\}\in\mathbb{R}^{m}
such that for any attribute
A\in{\mathbf{A}}
,
\sum_{R\in{\mathbf{R}}_{A}}x_{R}\geq 1
, where
{\mathbf{R}}_{A}
are all the relations in
{\mathbf{A}}
that contain the attribute
A
.
As proved in
(
13
)
, the maximum output size of a join query
\bm{q}
is
O(N^{\lVert x\rVert_{1}})
. Since the above bound holds for any fractional edge cover, we define
\rho=\rho(\bm{q})
to be the fractional cover with the smallest
\ell_{1}
-norm, i.e.,
\rho(\bm{q})
is the value of the objective function of the optimal solution of linear programming (LP):

(9)

\min\sum_{R\in{\mathbf{R}}}x_{R},\;\text{s.t.}\;\forall R\in{\mathbf{R}}:x_{R}\geq 0\;\text{and}\;\forall A\in{\mathbf{A}}:\sum_{R\in{\mathbf{A}}_{R}}x_{R}\geq 1.

Next, we give the definition of the Generalized Hypetree Decomposition (GHD).
A GHD of
\bm{q}
is a pair
(\mathcal{T},\lambda)
, where

\mathcal{T}
is a tree as an ordered set of nodes and
\lambda:\mathcal{T}\to 2^{{\mathbf{A}}}
is a labeling function which associates to each vertex
u\in\mathcal{T}
a subset of attributes in
{\mathbf{A}}
, called
\lambda_{u}
, such that the following conditions are satisfied:

•

(coverage) For each
R\in{\mathbf{R}}
, there is a node
u\in\mathcal{T}
such that
{\mathbf{A}}_{R}\subseteq\lambda_{u}
, where
{\mathbf{A}}_{R}
is the set of attributes contained in
R
;

•

(connectivity) For each
A\in{\mathbf{A}}
, the set of nodes
\{u\in\mathcal{T}:A\in\lambda_{u}\}
forms a connected subtree of
\mathcal{T}
.

Given a join query
\bm{q}
, one of its GHD
(\mathcal{T},\lambda)
and a node
u\in\mathcal{T}
, the width of
u
is defined as the optimal fractional edge covering number of its derived hypergraph
(\lambda_{u},\mathcal{E}_{u})
, where
\mathcal{E}_{u}=\{{\mathbf{A}}_{R}\cap\lambda_{u}:R\in{\mathbf{R}}\}
. Given a join query and a GHD
(\mathcal{T},\lambda)
, the width of
(\mathcal{T},\lambda)
is defined as the maximum width over all nodes in
\mathcal{T}
. Then, the fractional hypertree width of a join query follows:
The fractional hypertree width of a join query
\bm{q}
, denoted as
\mathsf{fhw}(\bm{q})
, is

\mathsf{fhw}(\bm{q})=\min_{(\mathcal{T},\lambda)}\max_{u\in\mathcal{T}}\rho(\lambda_{u},\mathcal{E}_{u}),

i.e., the minimum width over all GHDs.

Overall,
O(N^{\mathsf{fhw}})
is an upper bound on the number of join results materialized for each node in
\mathcal{T}
. It is also the time complexity to compute the join results for each node in
\mathcal{T}

(
13
)
. Hence, we converted our original cyclic query into an acyclic join query (with join tree
\mathcal{T}
) where each relation has
O(N^{\mathsf{fhw}})
tuples. We execute all our algorithms to the new acyclic join query replacing the

factor in the running time.
