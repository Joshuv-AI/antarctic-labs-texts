A Note on the Games-Chan Algorithm
Graham H. Norton

Abstract
The Games-Chan algorithm finds the minimal period of a periodic binary sequence of period 2 n 2^{n} , in n n iterations. We generalise this to periodic q q -ary sequences (where q q is a prime power) using generating functions and polynomials. We apply this to find the multiplicity of x − 1 x-1 in a q q -ary polynomial f f in log q ⁡ deg ⁡ ( f ) \log_{\,q}\deg(f) iterations.



Keywords:
Finite field, minimal polynomial, minimal period, periodic sequence.

1
Introduction

In
[
1
]
, the authors gave a
\log_{\,2}N
algorithm to find the minimal period of a periodic binary sequence with period
N=2^{n}
. Their proof used binomial coefficients
\bmod\ 2
and combinatorial identities. We generalise
[
1
, Theorem]
to periodic
q
-ary sequences of length
N=q^{n}
(where
q
is a prime power) using generating functions and
\mathrm{GF}(q)[x]
. We apply this to finding the multiplicity of
x-1
in
f\in\mathrm{GF}(q)[x]
in
\log_{\,q}\deg(f)
iterations.

We conclude with the corresponding recursive, division-free algorithm.

1.1
Notation

Let
q=p^{e}
for some prime
p
, put
\mathcal{F}=\mathrm{GF}(q)
and for
f\in\mathcal{F}
, write
|f|
for
\deg(f)
. We have
x^{p^{r}}-1=(x-1)^{p^{r}}
. Throughout the paper,
N=q^{n}
for some
n>0
.

1.2
Sequences

We write
s=(s_{0},s_{1},\ldots)
for a sequence with
s_{i}\in\mathcal{F}
. The
generating function
of
s
is
\mathrm{G}(s)(x)=\sum_{i=0}^{\infty}\ s_{i}\ x^{i}\in\mathcal{F}[[x]]
. It is well-known that if
s
has period
N
, we can write

\mathrm{G}(s)(x)=\frac{\overline{s}(x)}{x^{N}-1}

where
\overline{s}(x)=s_{0}+\cdots+s_{N-1}x^{N-1}\in\mathcal{F}[x]
and
|\overline{s}|<N
. The sequence
s
has a unique monic
minimal polynomial

\mu(s)=(x^{N}-1)/\gcd(\overline{s},x^{N}-1)=(x-1)^{\mathrm{mp}(s)}=x^{\mathrm{mp}(s)}-1
; here
\mathrm{mp}(s)
is called the
minimal period
of
s
. We have
\mathrm{mp}(s)=N-|\gcd(\overline{s},x^{N}-1)|
. The zero sequence has
\mathrm{G}(0)=0/1
and
\gcd(0,1)=1=(x-1)^{0}
so
\mathrm{mp}(0)=0
. If
t
is another sequence, then

\mu(s+t)=\mathrm{lcm}\{\mu(s),\mu(t)\})
,
[
2
, Theorem 8.59]
.

The following notion of ’
q
-folding’ of a sequence plays a key role; it generalises the use of left and right halves of a sequence in
[
1
]
.

Definition 1.1

Let
s
be a sequence with initial period
(s_{0},\ldots,s_{N-1})\in\mathcal{F}^{N}
. Put
s^{(i)}=(s_{iN^{\prime}},\ldots,s_{(i+1)N^{\prime}-1})\in\mathcal{F}^{N^{\prime}}
for
0\leq i\leq q-1
, so that
(s_{0},\ldots,s_{N-1})=(s^{(0)},\ldots,s^{(q-1)})
.
Also, define
s^{\bullet}=s^{(0)}+\cdots+s^{(q-1)}\in\mathcal{F}^{N^{\prime}}
and
(s^{(0)})^{\bullet}=s^{(0)})
.

The main idea of the proof is to relate
\overline{s}
and
\overline{s^{\bullet}}
.

Theorem 1.2

Let
s
be a non-zero sequence over
\mathcal{F}
of period
N
. Then

(i)\ \ \mathrm{G}(s)=-\frac{\overline{s^{(0)}}}{x^{N^{\prime}}-1}-\cdots-\frac{x^{(q-2)N^{\prime}}\ \overline{s^{(q-2)}}}{x^{(q-1)N^{\prime}}-1}+\frac{x^{(q-1)N^{\prime}}\overline{s^{\bullet}}}{x^{N}-1}

\displaystyle(ii)\ \mathrm{mp}(s)=\left\{\begin{array}[]{ll}\max\{\mathrm{mp}(s^{(0)}),\ldots,\mathrm{mp}(s^{(q-2)})\}&\mbox{if }s^{\bullet}=0\\
\\
\mathrm{mp}(s^{\bullet})+(q-1)N^{\prime}&\mbox{otherwise.}\end{array}\right.

Proof.
We put
\sigma=s^{\bullet}
to simplify the notation. Firstly,
\sigma=0
if and only if
\overline{\sigma}=0
, and if
\overline{\sigma}\neq 0
then
0\leq|\overline{\sigma}|<N^{\prime}
. By definition

\overline{s^{(i)}}(x)=s_{iN^{\prime}}+\cdots+s_{(i+1)N^{\prime}-1}x^{(i+1)N^{\prime}-1}
and

\overline{s}(x)=\overline{s^{(0)}}(x)+\cdots+x^{(q-1)N^{\prime}}\overline{s^{(q-1)}}(x)=g_{0}(x)+\cdots+g_{q-1}(x)\ \mathrm{say,}

where
g_{i}(x)=x^{iN^{\prime}}\ \overline{s^{(i)}}(x)
for
0\leq i\leq q-1
. Thus

x^{iN^{\prime}}|g_{i}(x)
,

\overline{\sigma}(x)=g_{0}(x)+x^{-N^{\prime}}g_{1}(x)+\cdots+x^{-(q-2)N^{\prime}}g_{q-2}(x)+x^{-(q-1)N^{\prime}}g_{q-1}(x)\,\ \mathrm{and}

\displaystyle\overline{s}

\displaystyle=

\displaystyle(g_{0}-x^{(q-1)N^{\prime}}g_{0})+\cdots+(g_{q-2}-x^{N^{\prime}}g_{q-2})+(x^{(q-1)N^{\prime}}g_{0}+\cdots+x^{N^{\prime}}g_{q-2}+g_{q-1})

\displaystyle=

\displaystyle(1-x^{(q-1)N^{\prime}})g_{0}+\cdots+(1-x^{N^{\prime}})g_{q-2}+x^{(q-1)N^{\prime}}(g_{0}+\cdots+x^{-(q-1)N^{\prime}}g_{q-1})

\displaystyle=

\displaystyle(1-x^{(q-1)N^{\prime}})g_{0}+\cdots+(1-x^{N^{\prime}})g_{q-2}+x^{(q-1)N^{\prime}}\overline{\sigma}

so

\mathrm{G}(s)=-\frac{\overline{s^{(0)}}}{x^{N^{\prime}}-1}-\cdots-\frac{x^{(q-2)N^{\prime}}\ \overline{s^{(q-2)}}}{x^{(q-1)N^{\prime}}-1}+\frac{x^{(q-1)N^{\prime}}\ \overline{\sigma}}{x^{N}-1}

and (i) is proved. Now
\mu(\frac{x^{iN^{\prime}}\ \overline{s^{(i)}}}{x^{(i+1)N^{\prime}}-1})=\mu(s^{(i)})
and so

\mu(s)=\mathrm{lcm}\{\mu(s^{(0)}),\ldots,\mu(s^{(q-2)}),\mu\left(\frac{x^{(q-1)N^{\prime}}\ \overline{\sigma}}{x^{N}-1}\right)\}.

So if
\sigma=0
then
\mathrm{mp}(s)=\max\{\mathrm{mp}(s^{(0)}),\ldots,\mathrm{mp}(s^{(q-2)})\}.

Now let
\sigma\neq 0
. For
0\leq i\leq q-2
,
\mathrm{mp}(s^{(i)})\leq|s^{(i)}|\leq{(i+1)N^{\prime}-1}<(q-1)N^{\prime}
, so
\max\{\mathrm{mp}(s^{(0)},\ldots,\mathrm{mp}(s^{(q-2)})\}

<(q-1)N^{\prime}
. Also, since
|\overline{\sigma}|<N^{\prime}
,

N-|\gcd(x^{(q-1)N^{\prime}}\overline{\sigma},x^{N}-1)|=qN^{\prime}-|\gcd(\overline{\sigma},x^{N^{\prime}}-1)|=(q-1)N^{\prime}+\mathrm{mp}(\sigma)\geq(q-1)N^{\prime}.

We conclude that if
s^{\bullet}\neq 0
then
\mathrm{mp}(s)=\mathrm{mp}(s^{\bullet})+(q-1)N^{\prime}
.

\square

Corollary 1.3

(
[
1
, Theorem]
) Let
s
be a non-zero sequence over
\mathrm{GF}(2)
of period
N=2^{n}
. Then

\displaystyle\mathrm{mp}(s)=\left\{\begin{array}[]{ll}\mathrm{mp}(s^{(0)})&\mbox{if }s^{\bullet}=0\\
\\
\mathrm{mp}(s^{\bullet})+N/2&\mbox{otherwise.}\end{array}\right.

2
The multiplicity of
x-1
in
f\in\mathcal{F}[x]

We next show how Theorem
1.2
yields a
\log_{\,q}
division-free algorithm to find the multiplicty of
x-1
in
f\in\mathcal{F}[x]
.

Definition 2.1

For
f\in\mathcal{F}[x]^{\times}
,
\pi(f)
denotes the multiplicity of
x-1
in
f
.

Suppose
|f|<N
. Since
\gcd(f,x^{N}-1)=(x-1)^{\pi(f)}
, we can relate
\pi(f)
and
\mathrm{mp}(f/(x^{N}-1)
: we have
\mu(f/(x^{N}-1))=(x^{N}-1)/\gcd(f,x^{N}-1)
, so
\mathrm{mp}(f/(x^{N}-1))=N-\pi(f)
or
\pi(f)=N-\mathrm{mp}(f/(x^{N}-1))
.

To apply Theorem
1.2
, we first adapt the definition of
q
-folding to
\mathrm{GF}(q)[x]
.

Definition 2.2

Let
f\in\mathcal{F}[x]^{\times}
,
N
be the smallest power of
q
greater than
|f|
and put
f=f^{(0)}+\cdots+f^{(q-1)}
where
|f^{(i)}|<(i+1)N^{\prime}
and
x^{iN^{\prime}}|f^{(i)}
for
0\leq i\leq q-1
. We also put
f^{\bullet}=f^{(0)}+\cdots+x^{-(q-1)N^{\prime}}f^{(q-1)}
(so that
|f^{\bullet}|<N^{\prime}
) and
(f^{(0)})^{\bullet}=f^{(0)}
.

Corollary 2.3

Let
f\in\mathcal{F}[x]^{\times}
and
N
be the smallest power of
q
greater than
|f|
. Then

\displaystyle\pi(f)=\left\{\begin{array}[]{ll}\min\{\pi(f^{(0)})+(q-1)N^{\prime},\ldots,\pi(f^{(q-2)})+N^{\prime}\}&\mbox{if }f^{\bullet}=0\\
\\
\pi(f^{\bullet})&\mbox{otherwise.}\end{array}\right.

Proof.
Put
s=f/(x^{N}-1)
. Then
\overline{s^{(i)}}=f^{(i)}
for
0\leq i\leq q-1
and
\overline{s^{\bullet}}=f^{\bullet}
, so from Theorem
1.2
,

(i)\ \ \mathrm{G}(s)=-\frac{f^{(0)}}{x^{N^{\prime}}-1}-\cdots-\frac{x^{(q-2)N^{\prime}}\ f^{(q-2)}}{x^{(q-1)N^{\prime}}-1}+\frac{x^{(q-1)N^{\prime}}\ f^{\bullet}}{x^{N}-1}\ \ \mathrm{and}

\displaystyle(ii)\ \mathrm{mp}(s)=\left\{\begin{array}[]{ll}\max\{\mathrm{mp}(s^{(0)}),\ldots,\mathrm{mp}(s^{(q-2)})\}&\mbox{if }s^{\bullet}=0\\
\\
\mathrm{mp}(s^{\bullet})+(q-1)N^{\prime}&\mbox{otherwise.}\end{array}\right.

If
f^{\bullet}=0
then

\displaystyle\pi(f)

\displaystyle=

\displaystyle N-\max\{\mathrm{mp}(s^{(0)}),\ldots,\mathrm{mp}(s^{(q-2)})\}

\displaystyle=

\displaystyle\min\{N-\mathrm{mp}(s^{(0)}),\ldots,N-\mathrm{mp}(s^{(q-2)})\}

\displaystyle=

\displaystyle\min\{N+\pi(f^{(0)})-N^{\prime},\ldots,N+\pi(f^{(q-2)})-(q-1)N^{\prime}\}

\displaystyle=

\displaystyle\min\{\pi(f^{(0)})+(q-1)N^{\prime},\ldots,\pi(f^{(q-2)})+N^{\prime}\}

and

\pi(f)=N-\mathrm{mp}(f^{\bullet}/(x^{N}-1))=N+(\pi(f^{\bullet})-N)
otherwise.

\square

2.1
The Binary Case

We give a direct proof of Corollary
2.3
when
q=2
. This requires high school algebra and
x^{2^{r}}+1=(x+1)^{2^{r}}
in
\mathrm{GF}(2)[x]
only.

Proposition 2.4

Let
f\in\mathrm{GF}(2)[x]^{\times}
, let
N
be the smallest power of 2 greater than
|f|
and
N^{\prime}=N/2
. Then

\displaystyle\pi(f)=\left\{\begin{array}[]{ll}\pi(f^{(0)})+N^{\prime}&\mbox{if }f^{\bullet}=0\\
\\
\pi(f^{\bullet})&\mbox{otherwise.}\end{array}\right.

Proof.
Put
g=f^{(0)}
and
h=f^{(1)}
to simplify the notation. We have

f=(g+x^{N^{\prime}}g)+(h+x^{N^{\prime}}g)=(x+1)^{N^{\prime}}g+x^{N^{\prime}}(g+x^{-N^{\prime}}h)=(x+1)^{N^{\prime}}g+x^{N^{\prime}}f^{\bullet}

so that if
f^{\bullet}=0
then
\pi(f)=\pi(f^{(0)})+N^{\prime}
. Now let
f^{\bullet}\neq 0
.
Firstly,
\pi(f^{\bullet})\leq\pi(f)
and
\pi(f^{\bullet})\leq|f^{\bullet}|<N^{\prime}
, so that

\displaystyle\frac{f}{(x+1)^{\pi(f^{\bullet})}}=(x+1)^{N^{\prime}-\pi(f^{\bullet})}g+\frac{x^{N^{\prime}}\cdot f^{\bullet}}{(x+1)^{\pi(f^{\bullet})}}.

(6)

If
\pi(f^{\bullet})<\pi(f)
then
x+1
divides the left-hand side of Equation (
6
). As
N^{\prime}-\pi(f^{\bullet})>0
,
(x+1)|(x+1)^{N^{\prime}-\pi(f^{\bullet})}g
. This implies that
(x+1)|x^{N^{\prime}}
, which is a contradiction and therefore
\pi(f)=\pi(f^{\bullet})
.

\square

We can also deduce
[
1
, Theorem]
from Proposition
2.4
using the method of Corollary
2.3
. The details are elementary and left to the reader.

3
The
\mathrm{mp}
Algorithm

The corresponding
\log_{\,q}N
algorithm is division-free.

If
\overline{s}(1)=\sum_{i=0}^{|\overline{s}|}s_{i}\neq 0
then
\mathrm{mp}(s)=N
, so we can include this in the corresponding algorithm, which requires
\log_{2}N
iterations.

procedure

\mathrm{mp}(s;N
):
return

\mathrm{mp}(s)
;

{

if

(s=0)
then
\mathrm{mp}:=0
;
exit
;

if

(\overline{s}(1)\neq 0)
then
\mathrm{mp}:=N
;
exit
;

if
(
N\geq 2
)
then if
(
s^{\bullet}=0
)

then

\mathrm{mp}:=\max\{\mathrm{mp}(s^{(0)};N^{\prime}),\ldots,\mathrm{mp}(s^{(q-2)};N^{\prime});q-1\}
;

else

\mathrm{mp}:=\mathrm{mp}(s^{\bullet};N^{\prime})+(q-1)N^{\prime}
;

}

procedure

\max(n_{1},\ldots,n_{k};k):m
;

{

if
k=1

then

m:=n_{1}

else

m:=\max\{n_{1},\max\{n_{2},\ldots,n_{k};k-1\};2\}
;

}

There is a corresponding multiplicity algorithm which is similar and left to the reader.
