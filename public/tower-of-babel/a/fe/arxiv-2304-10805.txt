RPLKG: Robust Prompt Learning with Knowledge Graph
Yewon Kim ∗, Yongtaek Lim ∗, Dokyung Yoon, Kyungwoo Song

Abstract
Large-scale pre-trained models have been known that they are transferable, and they generalize well on the unseen dataset. Recently, multimodal pre-trained models such as CLIP show significant performance improvement in diverse experiments. However, when the labeled dataset is limited, the generalization of a new dataset or domain is still challenging. To improve the generalization performance on few-shot learning, there have been diverse efforts, such as prompt learning and adapter. However, the current few-shot adaptation methods are not interpretable, and they require a high computation cost for adaptation. In this study, we propose a new method, robust prompt learning with knowledge graph (RPLKG). Based on the knowledge graph, we automatically design diverse interpretable and meaningful prompt sets. Our model obtains cached embeddings of prompt sets after one forwarding from a large pre-trained model. After that, model optimizes the prompt selection processes with Gumbel-Softmax. In this way, our model is trained using relatively little memory and learning time. Also, RPLKG selects the optimal interpretable prompt automatically, depending on the dataset. In summary, RPLKG is i) interpretable, ii) requires small computation resources, and iii) easy to incorporate prior human knowledge. To validate the RPLKG, we provide comprehensive experimental results on few-shot learning, domain generalization and new class generalization setting. RPLKG shows a significant performance improvement compared to zero-shot learning and competitive performance against several prompt learning methods using much lower resources.

It has been known that the pre-trained model has high transferability, and it induces competitive performance on diverse downstream tasks with a small dataset. Because of its successes, there have been many research works of the pre-trained large-scale model on the individual domain, such as computer vision

CLIP classifies the given image with the text embedding module instead of the classifier. Therefore, CLIP is capable of zero-shot classification, and it also shows competitive performance on few-shot learning tasks.

However, the few-shot learning performance of CLIP is still challenging, and there is still a large performance gap between the CLIP few-shot learning and the full training data learning. Therefore, there have been several efforts to increase the few-shot learning performance of CLIP
[

To alleviates the problem, there have been efforts to train a small number of parameters instead of full fine-tuning. The promising approach is the prompt tuning that introduces the learnable parameter into the input layer

In this paper, we propose a new method, robust prompt learning with knowledge graph (RPLKG) to enhance the few-shot learning performance of the large-scale pre-trained model, such as CLIP. As shown in Figure
2
, RPLKG constructs the text prompt based on the knowledge graph, and it automatically selects the optimal prompt for the given image. We construct relatively large-scale prompt text, and the choice of optimal prompt for each dataset is a combinatorial problem. In other words, the naive approach requires exponential time complexity. To solve the problem efficiently, we propose a Gumbel-Softmax based
[

,

RPLKG improves the previous prompt learning methods in three ways. First, RPLKG is possible to incorporate human knowledge. We establish the minimal rule, and we convert the knowledge graph into plain text to utilize the prompt. Second, RPLKG is interpretable because RPLKG uses plain text as a prompt, which is different from the previous continuous prompt optimization works. Lastly, RPLKG only requires a small amount of computation resources. As shown in Figure
1
, the learnable component of RPLKG is located at the top of CLIP layer; therefore, RPLKG does not require backpropagation through the CLIP, large-scale model. It is noted that the previous prompt learning works introduce the learnable parameter at the bottom of CLIP; therefore, backpropagation through the CLIP is required. Besides, RPLKG only introduces tiny learnable parameters, 0.79M parameters, and it is only about 0.5% of CLIP parameters. We summarize the contributions of this paper as follows:

•

We provide a new framework to construct the plain text prompt based on the knowledge graph. With minimal rules, we efficiently convert the knowledge graph into plain interpretable text.

•

We propose a new optimal prompt selection module based on the attention and Gumbel-Softmax. The selection module introduces a tiny learnable parameter at the top of CLIP; therefore, it only requires tiny computation costs additionally.

•

We validate RPLKG extensively. For the few-shot learning, we conduct experiments on 11 datasets with {1,2,4,8,16}-shot experimental environments. Besides, RPLKG shows superior performance in domain generalization experiments.

2.2
Knowledge Graph

The knowledge graph is essential to incorporate the human prior knowledge into the machine learning model. Therefore, there have been several efforts to construct the knowledge graph or infer the relationship between two entities in the knowledge graph. The representative knowledge graph for the entity is the ConceptNet
[
17

18

. ConceptNet is based on the Wiktionary, and it provides a multi-lingual knowledge graph and it contains 8M nodes and 21M edges. For the English language, it still contains 1.5M nodes. Besides, there are diverse knowledge graphs such as DBPedia
[

[

There have been several approaches to injecting the knowledge graph into the machine learning algorithm for inductive bias.
For the computer vision domain, Fact VQA utilizes the knowledge graph to provide the factual answer even though the ground-truth answer is not seen in the training phase.
For the natural language and recommendation domain, the conversational recommender system adopts ConceptNet and DBpedia knowledge base and extracts the information from the graph embedding
[
21
]
. Next, they maximize the mutual information between two knowledge graph representations to merge the knowledge efficiently. The merged information contributes to the model performing well on the recommendation system through the dialogue.
Our RPLKG is different from the previous knowledge graph application research works. First, we transform the knowledge graph into interpretable plain text to extract the information. Second, we only introduce a tiny component to select the optimal knowledge depending on the dataset. Besides, we provide a minimal rule for utilizing the knowledge base in the image classification tasks.

2.3
Prompt Learning

Prompt learning is a proposed methodology in the NLP field which allows efficient learning in large language models. Various downstream tasks can be efficiently learned by utilizing the pre-trained model as based knowledge. In prompt learning, the model learns to find the matching answer of provided a "fill-in-the-blank" cloze test form of textual prompt. Early prompts were handcrafted using human-based knowledge manually. Since the template of the prompt has a crucial impact on performance, it is important to search out which template is optimal for the downstream task. However, manually finding a good prompt is a very time-consuming task. Therefore, Autoprompt
[
22
]
proposed an automatic prompt search. Subsequently, a soft prompt emerges, which maps prompt to learnable embeddings. Different from conventional word formats, allowing end-to-end learning in continuous space
[

[

added continuous prompts to the pre-trained vision language model, significantly improving few-shot visual recognition and generalization performance. PLOT
[
25

has previously achieved fine-grained vision language tasks by proposing a method of learning multiple prompts with an image’s local features rather than one prompt per image. In addition, Menon et al.
[
26

offered interpretable prompts by constructing descriptions of detailed image features of the class using GPT-3
[

. Our methodology, RPLKG, builds a knowledge graph-based prompt database that is interpretable and does not update the VLM directly, suggesting a lightweight and efficient method.

3.1
Prompt with Knowledge Graph

It has been known that the quality of the prompt influences the model performance largely

To enhance the performance of a large-scale pre-trained model, high-quality, prompt design is necessary that describes the given instance or label information. Besides, the prompt design needs to be completed automatically by minimizing human efforts or intervention. To satisfy the condition, we design the prompt based on the knowledge graph, ConceptNet, and our prompt design is simple, scalable, and easy to incorporate human knowledge. ConceptNet provides the entity and multiple relations between entities. For the given label name, we search the given label name,
entity_{i}
, on a ConceptNet, and it returns the triplet, (
entity_{i}
,
relation_{ij}
,
entity_{j}
). Next, we convert the triplet as a sentence,
entity_{i}
is
relation_{ij}

entity_{j}
.
However, each dataset has a different rule to set the label name, and ConceptNet does not contain several label names. To alleviate the problem, we devise a minimal rule.

Most datasets utilize the "/", "( )", and "or" symbol to denote the synonym, such as "baluster / handrail" Therefore, we split the label name with "/", "()" and "or" symbol, and we search the spllited label name individually, such as "baluster" and "handrail". It is noted that "/" symbol in FGVC-Aircraft and StanfordCars represents a label name itself instead of a synonym, such as "Ram C/V Cargo Van Minivan 2012". Therefore, we do not split the label name with the "/" symbol on FGVC-Aircraft and StanfordCars dataset.

The first rule is not sufficient to find a large-scale, high-quality prompt. As a second step, we convert the capital letters to lowercase. For example, we convert the "Forest" as a "forest" if the ConceptNet does not contain the "Forest" in the database.
However, there are several cases that ConceptNet still does not contain the splitted label name in their database. For the failure cases, we adopt the additional rule, merging the word without space. For example, we split the "ice cream" into "icecream".
Even though we adopt the above rules, there are still several labels that are not matched to the ConceptNet database. Finally, we split the class name with spacing. For example, we convert "conference room" to "conference" and "room". It is noted that we also regard the symbol "-" and "_" as a space. Figure

Baselines

We propose several additional simple baselines that utilize the ConceptNet-based prompt
[
18
,
17
]
. This is the first paper that utilizes the ConceptNet-based prompt for multi-modal learning; therefore, we devise diverse simple approaches for utilizing the ConceptNet. We outline the simple baselines as below. It is noted that these methods do not have a learnable component.

Random prompt: For the
i
-th given data instance, we randomly select the prompt
T_{ic}
among
M_{c}
for each class
c
.

Average prompt: We utilize the average prompt embedding for each class. In other words, we utilize
\frac{1}{M_{c}}\sum_{i=1}^{M_{c}}{T_{ic}}
as a prompt for each class and dataset, where
T_{ic}
denote the text prompt embedding for instance
i
and class
c
.

Attentive prompt: We calculate the similarity between image embedding and prompt embedding for each class and normalize it as a sum-to-one. Then, we utilize the weight
w_{ic}
to calculate the weight average of prompt embedding,
\sum_{i=1}^{N_{c}}{w_{ic}T_{ic}}
. It is noted that the attentive prompt is a weighted average of prompts, and the weight is determined by the data instance.

5
Conclusion

Transfer learning of large-scale pre-trained models is essential for machine learning deployment in the real world.
In this study, we provide a new framework, RPLKG, that constructs prompts and select the prompt automatically to enhance transfer learning. RPLKG constructs scalable and meaningful prompts that incorporate human knowledge easily based on the ConceptNet. Besides, RPLKG adopts a learnable module that incorporates Gumbel-Softmax to choose the optimal prompt in a data-dependent manner. We validate that RPLKG significantly increases the performance in diverse experimental settings. In summary, RPLKG shows competitive performance using interpretable prompts and requiring much less training time and memory.
