Biasymptotics of the Möbius- and Liouville-signed partition numbers
Taylor Daniels

Abstract
. For n ∈ ℕ n\in\mathbb{N} let Π ⁡ [ n ] \Pi[n] denote the set of partitions of n n , i.e., the set of positive integer tuples ( x 1 , x 2 , … , x k ) (x_{1},x_{2},\ldots,x_{k}) such that x 1 ≥ x 2 ≥ ⋯ ≥ x k x_{1}\geq x_{2}\geq\cdots\geq x_{k} and x 1 + x 2 + ⋯ + x k = n x_{1}+x_{2}+\cdots+x_{k}=n . Fixing f : ℕ → { 0 , ± 1 } f:\mathbb{N}\to\{0,\pm 1\} , for π = ( x 1 , x 2 , … , x k ) ∈ Π ⁡ [ n ] \pi=(x_{1},x_{2},\ldots,x_{k})\in\Pi[n] let f ( π ) := f ( x 1 ) f ( x 2 ) ⋯ f ( x k ) f(\pi):=f(x_{1})f(x_{2})\cdots f(x_{k}) . In this way we define the signed partition numbers p ⁡ ( n , f ) = ∑ π ∈ Π ⁡ [ n ] f ⁡ ( π ) . p(n,f)=\sum_{\pi\in\Pi[n]}f(\pi). Building on the author’s previous work on the quantities p ⁡ ( n , μ ) p(n,\mu) and p ⁡ ( n , λ ) p(n,\lambda) , where μ \mu and λ \lambda are the Möbius and Liouville functions of prime number theory, respectively, on assumptions about the zeros of the Riemann zeta function we establish an alternation of the terms p ⁡ ( n , μ ) p(n,\mu) between two asymptotic behaviors as n → ∞ n\to\infty . Similar results for the quantities p ⁡ ( n , λ ) p(n,\lambda) are established. However, it is also demonstrated that if the Riemann Hypothesis (RH) holds, then it is possible that the quantities p ⁡ ( n , λ ) p(n,\lambda) maintain a single asymptotic behavior as n → ∞ n\to\infty . In particular, this stable asymptotic behavior occurs if, in addition to RH, it holds that all zeros of ζ ⁡ ( s ) \zeta(s) in the critical strip { 0 < Re ( s ) < 1 } \{0<\operatorname{Re}(s)<1\} are simple and the residues of 1 / ζ ⁡ ( s ) 1/\zeta(s) at these zeros are not too large. To formally describe these stable and alternating behaviors, the notions of asymptotic and biasymptotic sequences are introduced using a modification of the real logarithm.

1.
Introduction

For
n\in\mathbb{N}
let
\Pi[n]
denote the set of
partitions
of
n
, i.e., the set of positive integer tuples
(x_{1},x_{2},\ldots,x_{k})
such that
x_{1}\geq x_{2}\geq\ldots\geq x_{k}
and
x_{1}+x_{2}+\cdots+x_{k}=n
.
For fixed
f:\mathbb{N}\to\{0,\pm 1\}
, for
n\in\mathbb{N}
and
\pi=(x_{1},x_{2},\ldots,x_{k})\in\Pi[n]
let

(1.1)

f(\pi):=f(x_{1})f(x_{2})\cdots f(x_{k}).

With this we define for
n\in\mathbb{N}
the
signed partition numbers

p(n,f)
via

(1.2)

p(n,f)=\sum_{\pi\in\Pi[n]}f(\pi).

If
n\in\mathbb{N}
has prime factorization
p_{1}^{a_{1}}p_{2}^{a_{2}}\cdots p_{r}^{a_{r}}
with distinct primes
p_{i}
and all
a_{i}\geq 1
, then the Möbius
\mu
and Liouville
\lambda
functions are defined via

\lambda(n)=(-1)^{a_{1}+\cdots+a_{r}}\qquad\text{and}\qquad\mu(n)=\begin{cases}(-1)^{r}&\text{if all $a_{i}=1$,}\\
0&\text{otherwise.}\end{cases}

In
[
2
]
, the following asymptotic results on the sequences
(p(n,\mu))_{\mathbb{N}}
and
(p(n,\lambda))_{\mathbb{N}}
are established: For all
\varepsilon>0
, as
n\to\infty
one has

(1.3)

\displaystyle p(n,\mu)=O\big(e^{(1+\varepsilon)\sqrt{n}}\big)\qquad\text{and}\qquad p(n,\lambda)=O\big(e^{(1+\varepsilon)\sqrt{\zeta(2)n}}\big),

where
\zeta(2)=\pi^{2}/6
. In addition, for
n=2k
with
k\in\mathbb{N}
, as
k\to\infty
one has

(1.4)

\log p(2k,\mu)\sim\sqrt{2k}\qquad\text{and}\qquad\log p(2k,\lambda)\sim\sqrt{\zeta(2)2k},

where the relation
a_{m}\sim b_{m}
indicates that
\lim_{m\to\infty}a_{m}/b_{m}=1
.

This paper builds on the results of
[
2
]
to consider, in essence, the extent to which the relations (
1.4
) hold when the input
n
is odd. The statements of our main results require additional vocabulary, so for the sake of exposition we first state approximate versions of these results and then formalize them in section
2
. Here we use
\approx
to mean “behaves like, within reasonable error.”

Let
\zeta(s)
denote the Riemann zeta function and let

(1.5)

\Theta:=\sup\{\operatorname{Re}(\rho):\zeta(\rho)=0\}.

It is well known that
1/2\leq\Theta\leq 1
; the assertion that
\Theta=1/2
is the Riemann Hypothesis. Our three primary results extending the relations (
1.4
) are then roughly described in the following approximate statements:

(1
\approx
)

If
\Theta<1
, then for all
L\in\mathbb{N}
there exist arbitrarily large
N,N_{*}\in\mathbb{N}
such that

\displaystyle\log p(n,\mu)

\displaystyle\approx\sqrt{n}\qquad\text{for $N\leq n\leq N+L-1$},

\displaystyle\log\!\big((-1)^{n}p(n,\mu)\big)

\displaystyle\approx\sqrt{n}\qquad\text{for $N_{*}\leq n\leq N_{*}+L-1$.}

(2
\approx
)

If
\Theta<1
but
\Theta>1/2
as well, then for all
L\in\mathbb{N}
there exist arbitrarily large
N,N_{*}\in\mathbb{N}
such that

\displaystyle\log p(n,\lambda)

\displaystyle\approx\sqrt{\zeta(2)n}\qquad\text{for $N\leq n\leq N+L-1$},

\displaystyle\log\!\big((-1)^{n}p(n,\lambda)\big)

\displaystyle\approx\sqrt{\zeta(2)n}\qquad\text{for $N_{*}\leq n\leq N_{*}+L-1$.}

(3
\approx
)

If
\Theta=1/2
, then the long-term behavior of
(p(n,\lambda))_{\mathbb{N}}
is uncertain. In fact, it is possible that for some
N_{0}\in\mathbb{N}
one has

(1.6)

\log\!\big((-1)^{n}p(n,\lambda)\big)\approx\sqrt{\zeta(2)n}\qquad\text{for \emph{all} $n>N_{0}$.}

Considering items
(1

≈

)
,
(2

≈

)
, and
(3

≈

)
above we see, informally speaking, that on some strings
N,N+1,\ldots,N+L-1
the relations (
1.4
) can be “directly” extended to include odd
n
, but that on different strings
N_{*},N_{*}+1,\ldots,N_{*}+L_{*}-1
the extension requires the inclusion of a factor
(-1)^{n}
.

2.
Asymptotic and biasymptotic sequences

To motivate precise versions of statements
(1

≈

)
,
(2

≈

)
, and
(3

≈

)
we recall three classical results on certain sequences
(p(n,1_{A}))_{\mathbb{N}}
, where
1_{A}
is the indicator function for
A\subset\mathbb{N}
. For brevity let
p(n,A):=p(n,1_{A})
. The most well known of these three is the relation

(2.1)

\log p(n,\mathbb{N})\sim\kappa\sqrt{n},

where

\kappa:=\pi\sqrt{2/3},

which is an immediate corollary of Hardy and Ramanujan’s main results in
[
4
]
.

To state the second result we recall that
A\subset\mathbb{N}
is said to have
density

\delta_{A}
if the ratio
|A\cap\{1,2,\ldots,N\}|N^{-1}
tends to
\delta_{A}
as
N\to\infty
. It is evident that
\delta_{\mathbb{N}}=1
, and it is well known that the set of squarefree numbers has density
6/\pi^{2}\approx 0.601
. The prime number theorem implies that
\delta_{\mathbb{P}}=0
. A remarkable theorem of Erdős
[
3
]
states that: if
A\subset\mathbb{N}
and
\mathrm{gcd}(A)=1
, then
A
has density
\delta_{A}>0
if and only if

(2.2)

\log p(n,A)\sim\kappa\sqrt{\delta_{A}n}.

We remark that the proof of the “only if” statement in Erdős’ theorem is omitted in
[
3
]
since the proof of a similar result is given there. Complete proofs of both statements are given in
[
8
]
*Ch. 16.

The third result, due to Roth and Szekeres
[
10
]
, states that as
n\to\infty
one has

(2.3)

\log p(n,\mathbb{P})\sim\kappa\sqrt{\frac{2n}{\log n}},

where
\mathbb{P}
is the set of prime numbers. Finally we note that we may rewrite relations (
1.3
) and (
1.4
) and statements
(2

≈

)
and
(3

≈

)
with
\sqrt{\zeta(2)}=\tfrac{1}{2}\kappa=\tfrac{1}{2}\pi\sqrt{2/3}
.

Computing
p(n,\mu)
and
p(n,\lambda)
for
n\leq 10^{5}
we notice the following:

(i)

Except for very small
n
, say
n\leq 50
, we have

(2.4)

p(n,\mu)\approx(-1)^{n}e^{\sqrt{n}}\qquad\text{and}\qquad p(n,\lambda)\approx(-1)^{n}e^{\frac{1}{2}\kappa\sqrt{n}}.

(ii)

here are some
n
for which
p(n,\mu)
or
p(n,\lambda)
are 0, but all such
n
are
\leq 25
.

Thus, because these
p(n,f)
may be positive, negative, or zero we cannot simply speak of
\log p(n,f)
, and instead employ the following modification of the logarithm.

For real
x
we define the
logarithmic scale
function
\logsc(x)
via

(2.5)

\logsc(x)=\sgn(x)\log(|x|+1),

where
\sgn(0)=0
and
\sgn(x)=x/|x|
otherwise.
One may easily check that
\logsc x
is continuously differentiable and invertible with inverse

\expsc(x):=\sgn(x)(\exp|x|-1),

and additionally that
\logsc{x}\sim\log x
as
x\to\infty
. Using
\logsc(x)
we may characterize sequences that behave like
(-1)^{n}\exp\mathopen{}\mathclose{{\left(x_{n}+o(x_{n})}}\right)
for some sequence
(x_{n})
that grows to
+\infty
, as seen in the following lemma.

Lemma 2.1
.

Let
(a_{n})
and
(x_{n})
be real sequences with
x_{n}>0
for all
n
, and suppose that
x_{n}\to\infty
as
n\to\infty
. The relation
(-1)^{n}\logsc a_{n}\sim x_{n}
holds if and only if

(2.6)

a_{n}=(-1)^{n}\mathopen{}\mathclose{{\left(e^{x_{n}+y_{n}}-1}}\right)

for some sequence
(y_{n})
satisfying the relation
y_{n}=o(x_{n})
.

Proof.

Let
b_{n}:=\logsc{a_{n}}
. If
(-1)^{n}b_{n}\sim x_{n}
, then there exists a sequence
(y_{n})
with
y_{n}=o(x_{n})
for which
b_{n}=(-1)^{n}x_{n}+y_{n}
for all
n
. By restricting to sufficiently large values of
n
if necessary, there is no loss of generality in assuming that
y_{n}<x_{n}
for all
n
. It follows that
\sgn(b_{n})=(-1)^{n}
, that
|b_{n}|=(-1)^{n}b_{n}=x_{n}+(-1)^{n}y_{n}
, and that

a_{n}=\expsc{b_{n}}=(-1)^{n}\mathopen{}\mathclose{{\left(e^{x_{n}+(-1)^{n}y_{n}}-1}}\right).

Formula (
2.6
) then follows by simply relabeling
(-1)^{n}y_{n}
as
y_{n}
. The reverse implication in the lemma is immediate.
∎

Strings
are tuples
(N,N+1,\ldots,N+L-1)
where
N,L\in\mathbb{N}
; the string’s
length
is
L
. Length
L=1
and length
L>1
strings are trivial and nontrivial, respectively.

Although computations for small
n
suggest that
p(n,\mu)\approx(-1)^{n}\exp(\sqrt{n})
as
n\to\infty
, our approximate result
(1

≈

)
above states that if all zeros of
\zeta(s)
have real part
\leq 1-\varepsilon
for some
\varepsilon>0
, then there exist arbitrarily long strings on which
p(n,\mu)\approx\exp(\sqrt{n})
and arbitrarily long strings on which
p(n,\mu)\approx(-1)^{n}\exp(\sqrt{n})
, and that
p(n,\mu)
alternates between these two approximate behaviors indefinitely. To formally describe this alternation, for sequences
(x_{n})
and
(y_{n})
we say that

(2.7)

x_{n}\raisebox{-1.72218pt}{ $\overset{\raisebox{-0.60275pt}{\scalebox{0.7}{$*$}}}{\sim}$ }y_{n}

if: for all
\varepsilon>0
there exist arbitrarily long strings on which
|x_{n}/y_{n}-1|<\varepsilon
. It is equivalent to say that
x_{n}\raisebox{-1.72218pt}{ $\overset{\raisebox{-0.60275pt}{\scalebox{0.7}{$*$}}}{\sim}$ }y_{n}
if, for all
\varepsilon>0
and
L\in\mathbb{N}
, there exist arbitrarily large
N
such that

(2.8)

\mathopen{}\mathclose{{\left|x_{n}/y_{n}-1}}\right|<\varepsilon\qquad\text{for $N\leq n\leq N+L-1$.}

Definition 2.2
.

For fixed
\alpha\in(0,1]
, we say a sequence
(p(n,f))_{\mathbb{N}}
is
biasymptotic with factor
\alpha
if both

(2.9)

\displaystyle\logsc p(n,f)\raisebox{-1.72218pt}{ $\overset{\raisebox{-0.60275pt}{\scalebox{0.7}{$*$}}}{\sim}$ }\alpha\kappa\sqrt{n}\qquad\text{and}\qquad(-1)^{n}\logsc p(n,f)\raisebox{-1.72218pt}{ $\overset{\raisebox{-0.60275pt}{\scalebox{0.7}{$*$}}}{\sim}$ }\alpha\kappa\sqrt{n},

where
\kappa=\pi\sqrt{2/3}
is the “asymptotic factor” for
\log p(n,\mathbb{N})
in (
2.1
).

We note that, by Lemma
2.1
, the latter relation here is only possible if on arbitrarily long strings one has
p(n,f)=(-1)^{n}e^{\alpha\kappa\sqrt{n}+y_{n}}
for some terms
y_{n}
dominated by
\sqrt{n}
.
Recalling that
\Theta:=\sup\{\operatorname{Re}(\rho):\zeta(\rho)=0\}
, we now formalize statements
(1

≈

)
and
(2

≈

)
.

Theorem 2.3

(cf.
(1

≈

)
)
.

If
\Theta<1
, then
(p(n,\mu))_{\mathbb{N}}
is biasymptotic with factor
\kappa^{-1}
.

Theorem 2.4

(cf.
(2

≈

)
)
.

If
\frac{1}{2}<\Theta<1
, then
(p(n,\lambda))_{\mathbb{N}}
is biasymptotic with factor
\frac{1}{2}
.

As mentioned in statement
(3

≈

)
, the behavior of
(p(n,\lambda))_{\mathbb{N}}
on assumption of the Riemann Hypothesis (RH) is less certain than that of
(p(n,\mu))_{\mathbb{N}}
. In particular, additional information regarding the nontrivial zeros of
\zeta(s)
is required to draw conclusions. The Simplicity Hypothesis (SH) asserts that zeros
\rho
of
\zeta(s)
in the strip
\{0<\operatorname{Re}(s)<1\}
are simple, and we have the following other scenario in which
(p(n,\lambda))_{\mathbb{N}}
is biasymptotic.

Theorem 2.5
.

Suppose that RH holds but SH does not, i.e., that some zero
\tfrac{1}{2}+i\gamma
of
\zeta(s)
has order
m>1
. Then
(p(n,\lambda))_{\mathbb{N}}
is biasymptotic with factor
\frac{1}{2}
.

For the sake of consistency between the formal versions of
(1

≈

)
,
(2

≈

)
, and
(3

≈

)
, for fixed
\alpha\in(0,1]
we say a sequence
(p(n,f))_{\mathbb{N}}
is
asymptotic with factor
\alpha
if one has

(2.10)

\logsc p(n,f)\sim\alpha\kappa\sqrt{n}\qquad(\kappa=\pi\sqrt{2/3}).

Recalling that
\mu^{2}
is the indicator function for the set of squarefree integers, it is immediate from (
2.1
) and (

) that
(p(n,1))_{\mathbb{N}}
and
(p(n,\mu^{2}))_{\mathbb{N}}
are asymptotic with factors
1
and
\sqrt{6}/\pi\approx 0.7797
, respectively. In light of relation (
2.3
), the sequence
(p(n,\mathbb{P}))_{\mathbb{N}}
is not described by this definition because we require that
\alpha
be constant. On the other hand, one may easily use a different “normalization” in (
2.10
), e.g., specify that

\logsc p(n,f)\sim\alpha\kappa\sqrt{\frac{2n}{\log n}}.

If RH and SH hold and there exists some
C>0
such that

(2.11)

|1/\zeta^{\prime}(\rho)|\leq C|\rho|

for all zeros
\rho=1/2+i\gamma
of
\zeta(s)
on the critical line, we say that the Effective Simplicity Hypothesis (ES) holds with constant

, etc. when the

4.
A review of results on
p(x,\mu)
and
p(n,\lambda)

Our analyses of the potential (bi-)asymptotic behaviors of
(p(n,\mu))_{\mathbb{N}}
and
(p(n,\lambda))_{\mathbb{N}}
require detailed analyses of the generating functions of these sequences and how they affect the asymptotic formulae for
p(n,\mu)
and
p(n,\lambda)
established in
[
2
]
*Thms. 1.2–1.5. We briefly recall these formulae and the necessary tools from sections 1 and 2 of
[
2
]
.

The functions
\Phi(z)=\Phi(z,f)
and
\Psi(z)=\Psi(z,f)
associated to the sequence
(p(n,f))_{\mathbb{N}}
are defined for
|z|<1
via

(4.1)

\Phi(z)=\prod_{n=1}^{\infty}\mathopen{}\mathclose{{\left(\frac{1}{1-f(n)z^{n}}}}\right)\qquad\text{and}\qquad\Psi(z)=\sum_{k,n=1}^{\infty}\frac{f^{k}(n)}{k}z^{nk}

(4.2)

\Phi(z)=\exp\Psi(z).

By comparison to the functions
\Phi(z,1)
and
\Psi(z,1)
one sees that
\Phi(z,f)
and
\Psi(z,f)
are analytic for
|z|<1
, so by Cauchy’s theorem one has

(4.3)

p(n,f)=\frac{1}{2\pi i}\int_{|z|=\rho}\Phi(z)z^{-n-1}\,dz=\rho^{-n}\int_{0}^{1}\Phi(\rho e(\alpha))e(-n\alpha)\,d\alpha

for all
0<\rho<1
. The integrals (
4.3
) provide a natural definition for the quantities
p(x,f)
for a general

by simply using
x
in place of
n
therein.

To obtain asymptotic results on
p(x,f)
for a given
x>0
using (
4.3
), we select
\rho=\rho(x)
and
\rho_{*}=\rho_{*}(x)
so as to minimize the quantities
\Psi(\rho)-x\log\rho

10.
The Riemann Hypothesis and
(p(n,\lambda))_{\mathbb{N}}

As mentioned in statement
(3

≈

)
and section
2
, the Riemann Hypothesis (RH), i.e., the assertion that
\Theta=1/2
, presents a delicate scenario vis-à-vis the (bi-)asymptotic type of
(p(n,\lambda))_{\mathbb{N}}
. In contrast to our results on
(p(n,\mu))_{\mathbb{N}}
, on RH it is possible that

(10.1)

p(n,\lambda)=(-1)^{n}\exp\mathopen{}\mathclose{{\left(\tfrac{1}{2}\kappa\sqrt{n}+o(\sqrt{n})}}\right)\qquad(\kappa=\pi\sqrt{2/3},\,\,n\to\infty),

that is, the sequence
((-1)^{n}p(n,\lambda))_{\mathbb{N}}
is asymptotic with factor
1/2
. This behavior is not guaranteed by RH alone though; rather, several conditions must be satisfied.

One such condition is the Simplicity Hypothesis (SH), i.e., the hypothesis that all zeros of
\zeta(s)
are simple. Should SH hold, the residues of
1/\zeta(s)
at the zeros of
\zeta(s)
on the
critical line

\sigma=1/2
must also be considered. In particular, one requires an assumption of effective simplicity (ES), namely that for some
C>0
one has

(ES)

\mathopen{}\mathclose{{\left|1/\zeta^{\prime}(\rho)}}\right|\leq C|\rho|

for all zeros
\rho=1/2+i\gamma
of
\zeta(s)
. In addition we discuss a condition of linear independence of the imaginary parts
\gamma
of these zeros in section
11
.

Considering the result of Theorem
2.4
, going forward we assume RH unless stated otherwise, and we write the zeros
\rho
of
\zeta(s)
on the critical line as
\rho=1/2+i\gamma
; the trivial zeros
-2,-4,-6,\ldots
of
\zeta(s)
are not referenced. The quantities
\gamma
are the
ordinates
of the zeros
\rho
, and
\rho
and
\gamma
always denote such zeros and ordinates, respectively. In particular, for sums
\sum_{\rho}
one lets
\rho
run over the zeros
\rho=1/2+i\gamma
, and similarly for sums
\sum_{\gamma}
over the ordinates
\gamma
. We note that although
\rho
is used in previous sections to denote a solution of (
sp
) and (
sp

∗

), this does not cause confusion.

We now present informal arguments to motivate our later discussions, assuming SH for the remainder of this section. As
\tfrac{\Theta}{2}=\tfrac{1}{4}
and
\vartheta=\tfrac{1}{2}(1-\Theta)=\tfrac{1}{4}
on RH, Proposition
8.2
implies that

(10.2)

\phi_{*}(x)=\phi_{0}(x)+O(x^{\varepsilon})

with

(10.3)

\phi_{0}(x)=\mathchoice{{\vbox{\hbox{$\textstyle-$}}\kern-4.86108pt}}{{\vbox{\hbox{$\scriptstyle-$}}\kern-3.43057pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.908pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.76045pt}}\!\int_{\mathopen{}\mathclose{{\left<\sigma}}\right>}H(s)x^{s/2}\,ds=\mathchoice{{\vbox{\hbox{$\textstyle-$}}\kern-4.86108pt}}{{\vbox{\hbox{$\scriptstyle-$}}\kern-3.43057pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.908pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.76045pt}}\!\int_{\mathopen{}\mathclose{{\left<\sigma}}\right>}\eta(s)\frac{\zeta(2s)}{\zeta(s)}\Gamma(s)x^{s/2}\,ds\qquad(\sigma>\tfrac{1}{2}),

where we recall that

\mathfrak{z}=\pi^{2}/6,\quad\kappa=\pi\sqrt{2/3},\quad\text{and}\quad\eta(s)=(\kappa/\mathfrak{z})^{s}(1-2^{-s-1})\zeta(s+1).

For all zeros
\rho=1/2+i\gamma
of
\zeta(s)
we define
\mathfrak{c}_{\rho}
via

\mathfrak{c}_{\rho}=\Res_{s=\rho}H(s)=\eta(\rho)\frac{\zeta(2\rho)}{\zeta^{\prime}(\rho)}\Gamma(\rho),

where the last equality is valid by SH. Observing that the simple pole of
H(s)
at
s=\tfrac{1}{2}
is due to
\zeta(2s)
rather than
1/\zeta(s)
, we similarly define
\mathfrak{c}_{0}
via

(10.4)

\mathfrak{c}_{0}=-\Res_{s=\frac{1}{2}}H(s)=-\tfrac{1}{2}\cdot\frac{\eta(\frac{1}{2})}{\zeta(\frac{1}{2})}\Gamma(\tfrac{1}{2}),

noting the negative sign, and numerically compute that
\mathfrak{c}_{0}\approx 1.28
.

Formally shifting left (
10.3
) left to the line
\operatorname{Re}(s)=u
for some
\tfrac{1}{4}<u<\tfrac{1}{2}
, one has

(10.5)

\phi_{0}(x,\lambda)=-\mathfrak{c}_{0}x^{1/4}+\sum_{\rho}\mathfrak{c}_{\rho}x^{\rho/2}+\mathchoice{{\vbox{\hbox{$\textstyle-$}}\kern-4.86108pt}}{{\vbox{\hbox{$\scriptstyle-$}}\kern-3.43057pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.908pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.76045pt}}\!\int_{\mathopen{}\mathclose{{\left<u}}\right>}\eta(s)\frac{\zeta(2s)}{\zeta(s)}\Gamma(\rho)x^{s/2}\,ds.

As
x^{\rho/2}=x^{1/4}e^{i\gamma\log(x)/2}
, the sum
\sum_{\rho}\mathfrak{c}_{\rho}x^{\rho/2}
is a sum of oscillatory (in
x
) terms, while the term
-\mathfrak{c}_{0}x^{1/4}
is strictly decreasing in
x
. Considering the first zero
\rho_{1}\approx 1/2+14.13i
on the critical line, we find that
|\mathfrak{c}_{\rho_{1}}|\approx 1.27\hskip-1.00006pt\cdot\hskip-1.60004pt10^{-9}
, which is far smaller than
\mathfrak{c}_{0}\approx 1.28
; this vast difference is due to the exponential decay of
|\Gamma(s)|
on vertical lines. It is conceivable then that the series
\sum_{\rho}|\mathfrak{c}_{\rho}|
may converge, and may even satisfy the inequality
\sum_{\rho}|\mathfrak{c}_{\rho}|<\mathfrak{c}_{0}
. Should this inequality hold, it follows that

(10.6)

-\phi_{0}(x)\gg x^{1/4}

and, from formulae (
4.6
) and (
8.1
), that

p(n,\lambda)=(-1)^{n}\frac{\rho_{*}^{-n}\Phi(-\rho_{*})}{\sqrt{2\pi\Psi_{(2)}(-\rho_{*})}}\mathopen{}\mathclose{{\left[1+O(n^{-1/5})}}\right]=(-1)^{n}\exp\mathopen{}\mathclose{{\left(\tfrac{1}{2}\kappa\sqrt{n}+o(\sqrt{n})}}\right),

as mentioned in (
10.1
). Thus, on assumptions of RH and SH we require detailed information about the quantities
\mathfrak{c}_{\rho}
.

11.
The cases of nonsimplicity and large residues

Prior to a rigorous treatment of equation (
10.5
), we consider the scenario in which RH holds but SH fails. If a zero
\rho=1/2+i\gamma
has multiplicity
m>1
, then

\Res_{s=\rho}\mathopen{}\mathclose{{\left[H(s)x^{s/2}}}\right]=\sum_{k=1}^{m}\mathfrak{c}_{\rho,k}\frac{\log^{k-1}(x)}{(k-1)!}x^{\rho/2}

for some complex constants
\mathfrak{c}_{\rho,1},\ldots,\mathfrak{c}_{\rho,m}
with
\mathfrak{c}_{\rho,m}\neq 0
. In this case, the oscillatory sum in (
10.5
) has terms of order larger than
x^{1/4}
, making the quantity
-\mathfrak{c}_{0}x^{1/4}
in equation (
10.5
) negligible as
x\to\infty
. This is made precise in the following lemma.

Lemma 11.1
.

Assume RH and suppose that some nontrivial zero
\rho
of
\zeta(s)
has multiplicity
m>1
. As
x\to\infty
one has

\phi_{0}(x,\lambda)=\Omega_{\pm}(x^{1/4}\log^{m-1}x).

Proof.

The result follows from a minor modification of the proof of Lemma
7.3
, which is itself based on the proof of Theorem 15.3 in Montgomery and Vaughan
[
7
]
, specifically following the discussions on page 467 therein.
∎

Considering Lemmata
5.2
,
5.3
, and
9.1
and Proposition
5.4
, it is evident that their results remain valid if expressions

(where
A=\Theta/2
for us) are changed to
x^{1/4}\log^{m-1}x
. As such, using the same arguments as in proving Theorem
2.4
we at once establish the biasymptotic result in Theorem
2.5
, namely:
If RH holds but SH fails, then
(p(n,\lambda))_{\mathbb{N}}
is biasymptotic with factor
\tfrac{1}{2}
.

We now introduce another hypothesis. We say that the Linear Independence Hypothesis (LI) holds if the set
\{|\gamma|:\zeta(1/2+i\gamma)=0\}
is linearly independent over the set
\{0,\pm 1\}
. It is believed by some that said set of ordinates is even linearly independent over
\mathbb{Q}
, but this is more than needed here. The following arguments are taken from
[
7
]
*Thm. 15.5, our arguments only require this weaker independence condition.

Lemma 11.2
.

Assume RH, SH, and LI, and suppose that there exist zeros
\rho_{1},\rho_{2},\ldots,\rho_{K}
with ordinates
0<\gamma_{1}<\gamma_{2}<\cdots<\gamma_{K}
such that

(11.1)

\sum_{k=1}^{K}|\mathfrak{c}_{\rho_{k}}|>\mathfrak{c}_{0}.

Then writing
\phi_{0}(x,\lambda)=\phi_{0}(x)
one has

(11.2)

\limsup_{x\to\infty}\frac{\phi_{0}(x)}{x^{1/4}}\geq\tfrac{1}{2}\sum_{k=1}^{K}|\mathfrak{c}_{\rho_{k}}|-\tfrac{1}{2}\mathfrak{c}_{0}

and

(11.3)

\liminf_{x\to\infty}\frac{\phi_{0}(x)}{x^{1/4}}\leq-\tfrac{1}{2}\sum_{k=1}^{K}|\mathfrak{c}_{\rho_{k}}|-\tfrac{1}{2}\mathfrak{c}_{0},

and in particular one has

\phi_{0}(x)=\Omega_{\pm}(x^{1/4}).

Proof.

Let
c>0
. Recalling that
\mathcal{M}^{0}\mathopen{}\mathclose{{\left[\phi_{0}(x);s}}\right]=\int_{0}^{1}\phi_{0}(x)x^{-s-1}\,ds
and noting that

\int_{1}^{\infty}\frac{cx^{1/4}-\phi_{0}(x)}{x^{s/2+1}}\,dx=\frac{2c}{s-1/2}-2H(s)+\mathcal{M}^{0}\mathopen{}\mathclose{{\left[\phi_{0}(x);-s/2}}\right]\qquad(\sigma>\tfrac{1}{2}),

we define

(11.4)

\displaystyle W\hskip-0.80002pt(s)

\displaystyle=\int_{1}^{\infty}\frac{cx^{1/4}-\phi_{0}(x)}{x^{s/2+1}}\,dx,

(11.5)

\displaystyle\mathscr{W}\hskip-0.80002pt(s;\varphi)

\displaystyle=\tfrac{1}{2}e^{i\varphi}W(s)+\tfrac{1}{2}e^{-i\varphi}W(\bar{s}),

and

(11.6)

I(s)=\int_{1}^{\infty}\frac{cx^{1/4}-\phi_{0}(x)}{x^{s/2+1}}\prod_{k=1}^{K}\mathopen{}\mathclose{{\left\{1+\cos(\varphi_{k}-\gamma_{k}\log x)}}\right\}\,dx,

where
\varphi_{1},\varphi_{2},\ldots,\varphi_{K}
are real numbers to be determined below. Note that
W\hskip-0.80002pt(s)
has a simple pole at
s=1/2
with residue
2c+\mathfrak{c}_{0}
, where
\mathfrak{c}_{0}=-\Res_{s=1/2}[H(s)x^{s/2}]
. Multiplying out the product in (
11.6
) we have

(11.7)

I(s)=W\hskip-0.80002pt(s)+\sum_{k=1}^{K}\mathscr{W}\hskip-0.80002pt(s+i\gamma_{k};\varphi_{k})+J(s),

where
J(s)
is a linear combinations of terms of the form

\mathscr{W}\hskip-0.80002pt\mathopen{}\mathclose{{\left(s+i{\textstyle\sum}_{k}\varepsilon_{k}\gamma_{k};\,\,{\textstyle\sum}_{k}\varepsilon_{k}\varphi_{k}}}\right)

with all
\varepsilon_{k}\in\{0,\pm 1\}
and at least two of the
\varepsilon_{k}
nonzero.

We now suppose that
\phi_{0}(x)\leq cx^{1/4}
for all
x>0
, noting that, by the statement of Landau’s theorem (Lemma
7.2
), no generality is lost by assuming the inequality to hold for all
x
. Applying Landau’s theorem we see that
I(s)
converges for
\sigma>1/2
, and the linear independence assumption implies that
J(s)
is analytic at the point
s=1/2
. Thus, the function
I(s)
has a simple pole at
s=1/2
with residue

2c+\mathfrak{c}_{0}+\sum_{k=1}^{K}\operatorname{Re}\mathopen{}\mathclose{{\left[e^{i\varphi_{k}}\mathfrak{c}_{\rho_{k}}}}\right].

Select the
\varphi_{k}
so that
e^{i\varphi_{k}}\mathfrak{c}_{k}=-|\mathfrak{c}_{k}|
. As
I(s)
is uniformly bounded below for
s>1/2
, by letting
s
tend to
1/2
from above (on the real axis) in equation (
11.7
) we find that

2c\geq\sum_{k=1}^{K}|\mathfrak{c}_{\rho_{k}}|-\mathfrak{c}_{0},

establishing inequality (
11.2
). The proof of inequality (
11.3
) is similar, and the assertion that
\phi_{0}(x)=\Omega_{\pm}(x^{1/4})
follows at once from inequalities (
11.2
) and (
11.3
).
∎

Since Lemma
11.2
provides an
\Omega
–result for
\phi_{0}(x)
in place of, e.g., Lemma
9.1
, we argue as in the proof of Theorem
2.4
to conclude the following similar result.

Theorem 11.3
.

If the hypotheses of Lemma
11.2
hold, then
(p(n,\lambda))_{\mathbb{N}}
is biasymptotic with factor
\tfrac{1}{2}
.

When

Proof.

As the ordinates

We conclude our analyses with an informal discussion of an interesting problem concerning the sequence

As seen in sections
5
and
7
, the locations of such strings are determined by
\phi_{*}(x,\mu)
. By Proposition
6.5
, on RH (recall that
\tfrac{\Theta}{2}=\vartheta=\tfrac{1}{4}
in this case) we have

(13.1)

where

\phi_{0}(x,\mu)=\mathchoice{{\vbox{\hbox{$\textstyle-$}}\kern-4.86108pt}}{{\vbox{\hbox{$\scriptstyle-$}}\kern-3.43057pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.908pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.76045pt}}\!\int_{\mathopen{}\mathclose{{\left<\sigma}}\right>}F(s)x^{s/2}\,ds=\mathchoice{{\vbox{\hbox{$\textstyle-$}}\kern-4.86108pt}}{{\vbox{\hbox{$\scriptstyle-$}}\kern-3.43057pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.908pt}}{{\vbox{\hbox{$\scriptscriptstyle-$}}\kern-2.76045pt}}\!\int_{\mathopen{}\mathclose{{\left<\sigma}}\right>}2^{s}\mathopen{}\mathclose{{\left(\frac{1-2^{-s-1}}{1-2^{-s}}}}\right)\frac{\zeta(s+1)}{\zeta(s)}\Gamma(s)x^{s/2}\,ds\qquad(\sigma>\tfrac{1}{2}).

We first note that

\displaystyle\Res_{s=0}[F(s)x^{s/2}]

\displaystyle=-\frac{\log^{2}x}{8\ell_{2}}-\mathopen{}\mathclose{{\left(\frac{3\ell_{2}-2\ell_{\pi}}{4\ell_{2}}}}\right)\log x-\frac{\pi^{2}+2(\ell_{2}^{2}-18\ell_{2}\ell_{\pi}+6\ell_{\pi}^{2})}{24\ell_{2}}

\ell_{2}=\log 2
and
\ell_{\pi}=\log\pi

12.3

Let
\rho_{1}
and
