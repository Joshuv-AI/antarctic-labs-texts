On the matrix function R q p ​ ( A , B , z ) {}_{p}R_{q}(A,B;z) and its fractional calculus properties
Ravi Dwivedi and Reshma Sanjhira

Abstract
The main objective of the present paper is to introduce and study the function R q p ​ ( A , B , z ) {}_{p}R_{q}(A,B;z) with matrix parameters and investigate the convergence of this matrix function. The contiguous matrix function relations, differential formulas and the integral representation for the matrix function R q p ​ ( A , B , z ) {}_{p}R_{q}(A,B;z) are derived. Certain properties of the matrix function R q p ​ ( A , B , z ) {}_{p}R_{q}(A,B;z) have also been studied from fractional calculus point of view. Finally, we emphasize on the special cases namely the generalized matrix M M -series, the Mittag-Leffler matrix function and its generalizations and some matrix polynomials.

2
Preliminaries

Let the spectrum of a matrix
A
in
\mathbb{C}^{r\times r}
, denoted by
\sigma(A)
, be the set of all eigenvalues of
A
.
Recall that a matrix
A\in\mathbb{C}^{r\times r}
is said to be positive stable when

\beta(A)=\min\{\,\Re(z)\mid z\in\sigma(A)\,\}>0.

For a positive stable matrix
A\in\mathbb{C}^{r\times r}
, the gamma matrix function is defined by
[
jjc98a
]

\Gamma(A)=\int_{0}^{\infty}e^{-t}\,t^{A-I}\,dt

and the reciprocal gamma matrix function is defined as
[
jjc98a
]

\Gamma^{-1}(A)=A(A+I)\dots(A+(n-1)I)\Gamma^{-1}(A+nI),\ n\geq 1.

(1)

The Pochhammer symbol for
A\in\mathbb{C}^{r\times r}
is given by
[
jjc98b
]

(A)_{n}=\begin{cases}I,&\text{if $n=0$,}\\
A(A+I)\dots(A+(n-1)I),&\text{if $n\geq 1$}.\end{cases}

(2)

This gives

(A)_{n}=\Gamma^{-1}(A)\ \Gamma(A+nI),\qquad n\geq 1.

(3)

If
A\in\mathbb{C}^{r\times r}
is a positive stable matrix and
n\geq 1
is an integer, then the gamma matrix function can also be defined in the form of a limit as
[
jjc98a
]

\Gamma(A)=\lim_{n\to\infty}(n-1)!\,(A)_{n}^{-1}\,n^{A}.

(4)

If
A
and
B
are positive stable matrices in
\mathbb{C}^{r\times r}
, then the beta matrix function is defined as
[
jjc98a
]

\mathfrak{B}(A,B)=\int_{0}^{1}t^{A-I}\,(1-t)^{B-I}dt.

(5)

Furthermore, if
A
,
B
and
A+B
are positive stable matrices in
\mathbb{C}^{r\times r}
such that
AB=BA
, then the beta matrix function is defined as
[
jjc98a
]

\mathfrak{B}(A,B)=\Gamma(A)\,\Gamma(B)\,\Gamma^{-1}(A+B).

(6)

Using the Schur decomposition of
A
, it follows that
[
gl
]
,
[
vl
]

\|e^{tA}\|\leq e^{t\alpha(A)}\sum_{k=0}^{r-1}\frac{(\|A\|r^{1/2}t)^{k}}{k!},\ \ t\geq 0.

(7)

We shall use the notation
\Gamma\left(\begin{array}[]{c}A_{1},\dots,A_{p}\\
B_{1},\dots,B_{q}\end{array}\right)
for
\Gamma(A_{1})\cdots\Gamma(A_{p})\,\Gamma^{-1}(B_{1})\cdots\Gamma^{-1}(B_{q})
.

3
The matrix function
{}_{p}R_{q}(A,B;z)

Jódar and Cortés
[
jjc98b
]
defined the Gauss hypergeometric function with matrix parameters denoted by
{}_{2}F_{1}(A,B;C;z)
, where
A
,
B
,
C
are matrices in
\mathbb{C}^{r\times r}
, and determined its region of convergence and integral representation. A natural generalization of the Gauss hypergeometric matrix function is obtained in
[
ds1
]
by introducing an arbitrary number of matrices as parameters in the numerator and denominator and referring to this generalization as the generalized hypergeometric matrix function,
{}_{p}F_{q}(A_{1},\dots,A_{p};B_{1},\dots,B_{q};z)
. We now give an extension of the generalized hypergeometric matrix function. Let
A
,
B
,
C_{i}
and
D_{j}
,
1\leq i\leq p
,
1\leq j\leq q
, be matrices in
\mathbb{C}^{r\times r}
such that
D_{j}+kI
are invertible for all integers
k\geq 0
. Then, we define the matrix function
{}_{p}R_{q}(A,B;z)
as

{}_{p}R_{q}(A,B;z)

\displaystyle={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B;z\right)

\displaystyle=\sum_{n\geq 0}\Gamma^{-1}(nA+B)\,(C_{1})_{n}\dots(C_{p})_{n}\,(D_{1})_{n}^{-1}\dots(D_{q})_{n}^{-1}\,\frac{z^{n}}{n!}.

(10)

In the following theorem, we find the regions in which the matrix function
{}_{p}R_{q}(A,B;z)
either converges or diverges.

Theorem 3.1
.

Let
A,B,C_{1},\dots,C_{p},D_{1},\dots,D_{q}
be positive stable matrices in
\mathbb{C}^{r\times r}
. Then the matrix function
{}_{p}R_{q}(A,B;z)
defined in (
10
) converges or diverges in one of the following regions:

1.

If
p\leq q+1
, the matrix function converges absolutely for all finite
z
.

2.

If
p=q+2
, function converges for
|z|<1
and diverges for
|z|>1
.

3.

If
p=q+2
and
|z|=1
, the function converges absolutely for

\beta(D_{1})+\cdots+\beta(D_{q})>\alpha(C_{1})+\cdots+\alpha(C_{p}).

4.

If
p>q+2
, the function diverges for all
z\neq 0
.

Proof 3.2
.

Let
U_{n}(z)
denote the general term of the series (
10
). Then, we have

\displaystyle\|U_{n}(z)\|

\displaystyle\leq\|\Gamma^{-1}(nA+B)\|\,\prod_{i=1}^{p}\|(C_{i})_{n}\|\,\prod_{j=1}^{q}\|(D_{j})_{n}^{-1}\|\,\frac{|z|^{n}}{n!}

\displaystyle\leq\|\Gamma^{-1}(nA+B)\|\,\prod_{i=1}^{p}\left\|\frac{(C_{i})_{n}n^{C_{i}}n^{-C_{i}}(n-1)!}{(n-1)!}\right\|\,

\displaystyle\quad\times\prod_{j=1}^{q}\left\|\frac{(D_{j})_{n}^{-1}n^{D_{j}}n^{-D_{j}}(n-1)!}{(n-1)!}\right\|\,\frac{|z|^{n}}{n!}.

(11)

The limit definition of gamma matrix function (
4
) and Schur decomposition (
7
) yield

\displaystyle\|U_{n}(z)\|

\displaystyle\leq N\ S\ ((n-1)!)^{p-q-2}\ n^{\sum_{i=1}^{p}\alpha(C_{i})-\sum_{j=1}^{q}\beta(D_{j})-1}\,|z|^{n},

(12)

where
N=\|\Gamma^{-1}(C_{1})\|\cdots\|\Gamma^{-1}(C_{p})\|\|\Gamma(D_{1})\|\cdots\|\Gamma(D_{q})\|
and

\displaystyle S=\left(\sum_{k=0}^{r-1}\frac{(\max\{\|C_{1}\|,\dots,\|C_{p}\|,\|D_{1}\|,\dots,\|D_{q}\|\}\,r^{\frac{1}{2}}\,\ln n)^{k}}{k!}\right)^{p+q}.

(13)

Thus, it can be easily calculated from (
12
) and comparison theorem of numerical series that the matrix series (
10
) converges or diverges in one of the region listed in Theorem 3.1.

4
Contiguous matrix function relations

In this section, we shall obtain contiguous matrix function relations and differential formulas satisfied by the matrix function
{}_{p}R_{q}(A,B;z)
. The following abbreviated notations will be used throughout the subsequent sections:

\displaystyle R={}_{p}R_{q}(A,B;z)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B;z\right),

\displaystyle R(C_{i}+)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{i-1},C_{i}+I,C_{i+1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B;z\right),

\displaystyle R(C_{i}-)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{i-1},C_{i}-I,C_{i+1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B;z\right),

\displaystyle R(D_{j}-)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{j-1},D_{j}-I,D_{j+1},\dots,D_{q}\end{array}\mid A,B;z\right),

\displaystyle{}_{p}R_{q}(A,B+I;z)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B+I;z\right),

\displaystyle{}_{p}R_{q}(A,B-I;z)={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{q}\end{array}\mid A,B-I;z\right).

Following Desai and Shukla
[
ds
]
, we can find
(p+q-1)
contiguous matrix function relations of bilateral type that connect either
R
,
R(C_{1}+)
and
R(C_{i}+)
,
1\leq i\leq p
or
R
,
R(C_{1}+)
and
R(D_{j}-)
,
1\leq j\leq q
. Let
C_{i},1\leq i\leq p
be positive stable matrices in
\mathbb{C}^{r\times r}
such that
C_{i}C_{k}=C_{k}C_{i},1\leq k\leq p,k<i
,
C_{i}A=AC_{i}
and
C_{i}B=BC_{i}
. Then, we have

\displaystyle R(C_{i}+)=\sum_{n\geq 0}C_{i}^{-1}(C_{i}+nI)\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q})_{n}^{-1}\,\frac{z^{n}}{n!}.

(26)

If
\theta=z\frac{d}{dz}
is a differential operator, then we get

\displaystyle(\theta+C_{i})R=\sum_{n\geq 1}(C_{i}+nI)\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q})_{n}^{-1}\,\frac{z^{n}}{n!}.

(27)

Equations (
26
) and (
27
) together yield

(\theta+C_{i})R=C_{i}\,R(C_{i}+),\quad i=1,\dots,p.

(28)

In particular, for
i=1
, we write

(\theta+C_{1})R=C_{1}\,R(C_{1}+).

(29)

Similarly for matrices
D_{j}\in\mathbb{C}^{r\times r},1\leq j\leq q
such that
D_{j}D_{k}=D_{k}D_{j},1\leq k\leq q,k>j
, we obtain a set of
q
equations, given by

\theta\,R+R\,(D_{j}-I)=R(D_{j}-)(D_{j}-I).

(30)

Now, eliminating
\theta
from (
28
) and (
30
) gives rise to
(p+q-1)
contiguous matrix function relations of bilateral type

C_{i}\,R-R\,(D_{j}-I)=C_{i}\,R(C_{i}+)-R(D_{j}-)(D_{j}-I),\ 1\leq i\leq p,1\leq j\leq q.

(31)

Equations (
28
) and (
29
) produce
(p-1)
contiguous matrix function relations

(C_{1}-C_{i})R=C_{1}R(C_{1}+)-C_{i}\,R(C_{i}+),\quad i=2,\dots,p.

(32)

Furthermore, Equations (
29
) and (
30
) leads to
q
contiguous matrix function relations

C_{1}\,R-R\,(D_{j}-I)=C_{1}\,R(C_{1}+)-R(D_{j}-)(D_{j}-I),\ 1\leq j\leq q.

(33)

The set of matrix function relations given in (
32
) and (
33
) are simple contiguous matrix function relations.
Next, we give matrix differential formulas satisfied by the matrix function
{}_{p}R_{q}(A,B;z)

5
Integral representation

We now find an integral representation of the matrix function
{}_{p}R_{q}(A,B;z)
using the integral of the beta matrix function.

Theorem 5.1
.

Let
A
,
B
,
C_{1}
,
\dots,C_{p}
,
D_{1},\dots,D_{q}
be matrices in
\mathbb{C}^{r\times r}
such that:
C_{p}
,
D_{q}
,
D_{q}-C_{p}
are positive stable and
C_{p}D_{j}=D_{j}C_{p}
for all
1\leq j\leq q
. Then, for
|z|<1
, the matrix function
{}_{p}R_{q}(A,B;z)
defined in (
10
) can be presented in integral form as

\displaystyle{}_{p}R_{q}(A,B;z)

\displaystyle=\int_{0}^{1}{}_{p-1}R_{q-1}\left(\begin{array}[]{c}C_{1},\dots,C_{p-1}\\
D_{1},\dots,D_{q-1}\end{array}\mid A,B;t\,z\right)t^{C_{p}-I}(1-t)^{D_{q}-C_{p}-I}dt

\displaystyle\quad\times\Gamma\left(\begin{array}[]{c}D_{q}\\
C_{p},D_{q}-C_{p}\end{array}\right).

Proof 5.2
.

Since
C_{p},D_{q},D_{q}-C_{p}
are positive stable and
C_{p}D_{q}=D_{q}C_{p}
, we have
[
jjc98b
]

\displaystyle(C_{p})_{n}(D_{q})_{n}^{-1}=\left(\int_{0}^{1}t^{C_{p}+(n-1)I}(1-t)^{D_{q}-C_{p}-I}dt\right)\Gamma\left(\begin{array}[]{c}D_{q}\\
C_{p},D_{q}-C_{p}\end{array}\right).

Using (
5.2
) in (
10
), we get

\displaystyle{}_{p}R_{q}(A,B;z)

\displaystyle=\sum_{n\geq 0}\int_{0}^{1}\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p-1})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q-1})_{n}^{-1}

\displaystyle\quad\times\frac{z^{n}}{n!}\,t^{C_{p}+(n-1)I}\,(1-t)^{D_{q}-C_{p}-I}dt\ \Gamma\left(\begin{array}[]{c}D_{q}\\
C_{p},D_{q}-C_{p}\end{array}\right).

To interchange the integral and summation, consider the product of matrix functions

\displaystyle S_{n}(z,t)

\displaystyle=\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p-1})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q-1})_{n}^{-1}\,\frac{z^{n}}{n!}\,t^{C_{p}+(n-1)I}

\displaystyle\quad\times(1-t)^{D_{q}-C_{p}-I}\ \Gamma\left(\begin{array}[]{c}D_{q}\\
C_{p},D_{q}-C_{p}\end{array}\right).

For

and

, we get

\displaystyle\|S_{n}(z,t)\|

\displaystyle\leq\left\|\Gamma\left(\begin{array}[]{c}D_{q}\\
C_{p},D_{q}-C_{p}\end{array}\right)\right\|\,\left\|\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p-1})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q-1})_{n}^{-1}\,\frac{z^{n}}{n!}\right\|\,

\displaystyle\quad\times\|t^{C_{p}-I}\|\|(1-t)^{D_{q}-C_{p}-I}\|.

(60)

The Schur decomposition (
7
) yields

\displaystyle\|t^{C_{p}-I}\|\ \|(1-t)^{D_{q}-C_{p}-I}\|

\displaystyle\leq t^{\alpha(C_{p})-1}(1-t)^{{\alpha(D_{q}-C_{p})}-1}\left(\sum_{k=0}^{r-1}\frac{(\|C_{p}-I\|\ r^{1/2}\ \ln t)^{k}}{k!}\right)

\displaystyle\quad\times\left(\sum_{k=0}^{r-1}\frac{(\|{D_{q}-C_{p}-I}\|\ r^{1/2}\ \ln{(1-t)})^{k}}{k!}\right).

(61)

Since

\displaystyle\|t^{C_{p}-I}\|\ \|(1-t)^{D_{q}-C_{p}-I}\|\leq\mathcal{A}\ t^{\alpha(C_{p})-1}(1-t)^{{\alpha(D_{q}-C_{p})}-1},

(62)

\displaystyle\mathcal{A}=\left(\sum_{k=0}^{r-1}\frac{(\max\{\|C_{p}-I\|,\|D_{q}-C_{p}-I\|\}\ r^{1/2})^{k}}{k!}\right)^{2}.

(63)

The matrix series
\Gamma^{-1}(nA+B)\,(C_{1})_{n}\cdots(C_{p-1})_{n}\,(D_{1})_{n}^{-1}\cdots(D_{q-1})_{n}^{-1}\,\frac{z^{n}}{n!}
converges absolutely for

S^{\prime}
. Thus, we get

\displaystyle\sum_{n\geq 0}\|S_{n}(z,t)\|\leq f(t)=NS^{\prime}\mathcal{A}\,t^{\alpha(C_{p})-1}\,(1-t)^{\alpha(D_{q}-C_{p})-1}.

(64)

Since
\alpha(C_{p}),\alpha(D_{q}-C_{p})>0
, the function
f(t)
is integrable and by the dominated convergence theorem
[
gf
]
, the summation and the integral can be interchanged in (
5.2
). Using
C_{p}D_{j}=D_{j}C_{p},\ 1\leq j\leq q
, we get (
5.1
).

6
Fractional calculus of the matrix function
{}_{p}R_{q}(A,B;z)

Let
x>0
and
\mu\in\mathbb{C}
such that
\Re(\mu)>0
. Then the Riemann-Liouville type fractional order integral and derivatives of order
\mu
are given by
[
kst
]
,
[
skm
]

({\bf I}^{\mu}_{a}f)(x)=\frac{1}{\Gamma(\mu)}\int_{a}^{x}(x-t)^{\mu-1}f(t)dt

(65)

and

{\bf D}_{a}^{\mu}f(x)=({\bf I}^{n-\mu}_{a}{\bf D}^{n}f(x)),\quad{\bf D}=\frac{d}{dx}.

(66)

Bakhet and his co-workers,
[
ab
]
, studied the fractional order integrals and derivatives of Wright hypergeometric and incomplete Wright hypergeometric matrix functions using the operators (
65
) and (
66
). To obtain such they used the following lemma:

Lemma 6.1
.

Let
A
be a positive stable matrix in
\mathbb{C}^{r\times r}
and
\mu\in\mathbb{C}
such that
\Re(\mu)>0
. Then the fractional integral operator (
65
) yields

\displaystyle{\bf I}^{\mu}(x^{A-I})=\Gamma(A)\Gamma^{-1}(A+\mu I)x^{A+(\mu-1)I}.

(67)

In the next two theorems, we find the fractional order integral and derivative of matrix function
{}_{p}R_{q}(A,B;z)
.

Theorem 6.2
.

Let
A
,
B
,
C_{1}
,
\dots,C_{p}
,
D_{1},\dots,D_{q}
be matrices in
\mathbb{C}^{r\times r}
and
\mu\in\mathbb{C}
such that
D_{i}D_{j}=D_{j}D_{i},1\leq i,j\leq q
and
\Re(\mu)>0
. Then the fractional integral of the matrix function
{}_{p}R_{q}(A,B;z)
is given by

\displaystyle{\bf I}^{\mu}[{}_{p}R_{q}(A,B;z)z^{D_{j}-I}]

\displaystyle={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{j-1},D_{j}+\mu I,D_{j+1},\dots,D_{q}\end{array}\mid A,B;z\right)z^{D_{j}+(\mu-1)I}

\displaystyle\quad\times\Gamma(D_{j})\Gamma^{-1}(D_{j}+\mu I).

(70)

Proof 6.3
.

From Equation (
65
), we have

\displaystyle{\bf I}^{\mu}[{}_{p}R_{q}(A,B;z)z^{D_{j}-I}]

\displaystyle=\frac{1}{\Gamma(\mu)}\int_{0}^{z}(z-t)^{\mu-1}{}_{p}R_{q}(A,B;t)t^{D_{j}-I}dt

\displaystyle=\frac{1}{\Gamma(\mu)}\sum_{n\geq 0}\,(C_{1})_{n}\dots(C_{p})_{n}\left(\int_{0}^{z}(z-t)^{\mu-1}t^{D_{j}+(n-1)I}dt\right)(D_{1})_{n}^{-1}\dots(D_{q})_{n}^{-1}\,\frac{1}{n!}

\displaystyle=\sum_{n\geq 0}\,(C_{1})_{n}\dots(C_{p})_{n}\left({\bf I}^{\mu}\,z^{D_{j}+(n-1)I}\right)(D_{1})_{n}^{-1}\dots(D_{q})_{n}^{-1}\,\frac{1}{n!}.

(71)

Using the Lemma
6.1
, we get

\displaystyle{\bf I}^{\mu}[{}_{p}R_{q}(A,B;z)z^{D_{j}-I}]

\displaystyle=\frac{1}{\Gamma(\mu)}\sum_{n\geq 0}\,(C_{1})_{n}\dots(C_{p})_{n}\Gamma(D_{j}+nI)\Gamma^{-1}(D_{j}+nI+\mu I)

\displaystyle\quad\times z^{D_{j}+(n+\mu-1)I}(D_{1})_{n}^{-1}\dots(D_{q})_{n}^{-1}\,\frac{1}{n!}

\displaystyle={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{j-1},D_{j}+\mu I,D_{j+1},\dots,D_{q}\end{array}\mid A,B;z\right)

\displaystyle\quad\times z^{D_{j}+(\mu-1)I}\,\Gamma(D_{j})\Gamma^{-1}(D_{j}+\mu I).

(74)

This completes the proof.

Theorem 6.4
.

Let
A
,
B
,
C_{1}
,
\dots,C_{p}
,
D_{1},\dots,D_{q}
be matrices in
\mathbb{C}^{r\times r}
and
\mu\in\mathbb{C}
such that
D_{i}D_{j}=D_{j}D_{i},1\leq i,j\leq q
and
\Re(\mu)>0
. Then the fractional integral of the matrix function
{}_{p}R_{q}(A,B;z)
is given by

\displaystyle{\bf D}^{\mu}[{}_{p}R_{q}(A,B;z)z^{D_{j}-I}]

\displaystyle={}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{j-1},D_{j}-\mu I,D_{j+1},\dots,D_{q}\end{array}\mid A,B;z\right)z^{D_{j}-(\mu-1)I}

\displaystyle\quad\times\Gamma(D_{j})\Gamma^{-1}(D_{j}-\mu I).

(77)

Proof 6.5
.

The fractional derivative operator (
66
) and Theorem
6.2
together yield

\displaystyle{\bf D}^{\mu}[{}_{p}R_{q}(A,B;z)z^{D_{j}-I}]

\displaystyle=\left(\frac{d}{dz}\right)^{r}{}_{p}R_{q}\left(\begin{array}[]{c}C_{1},\dots,C_{p}\\
D_{1},\dots,D_{j-1},D_{j}+(r-\mu)I,D_{j+1},\dots,D_{q}\end{array}\mid A,B;z\right)z^{D_{j}+(r-\mu-1)I}

\displaystyle\quad\times\Gamma(D_{j})\Gamma^{-1}(D_{j}+(r-\mu)I).

(80)

Now, proceeding exactly in the same manner as in Theorem
4.1
, we get (
77
).

7
Special Cases

The matrix function
{}_{p}R_{q}(A,B;z)
reduces to several special matrix functions. These matrix functions are considered as matrix generalizations of respective classical matrix functions such as the generalized hypergeometric matrix function, the Gauss hypergeometric matrix function, the confluent hypergeometric matrix function, the matrix M-series, the Wright matrix function and the Mittag-Leffler matrix function and its generalizations. We also discuss some matrix polynomials as particular cases.
We start with the special case
A=B=I
and

. The matrix function

reduces to

\displaystyle=\sum_{n\geq 0}\,(C_{1})_{n}\dots(C_{p-1})_{n}\,(D_{1})_{n}^{-1}\dots(D_{q})_{n}^{-1}\,\frac{z^{n}}{n!}

\displaystyle={}_{p-1}F_{q}(C_{1},\dots,C_{p-1},D_{1},\dots,D_{q};z),

(83)

which is known as generalized hypergeometric matrix function with
p-1
matrix parameters in the numerator and
q
in the denominator
[
ds1
]
. For
C_{1}=A_{1},C_{2}=B_{1},C_{3}=I,D_{1}=C
and
A=B=I
, the matrix function

reduces to the Gauss hypergeometric matrix function

A=B=I
