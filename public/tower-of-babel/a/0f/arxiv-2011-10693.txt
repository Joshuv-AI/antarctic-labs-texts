Templates, Arrays, and Overlays
Jordan Broussard

Abstract




An
array
is a function
A:\mathbb{Z}^{2}\rightarrow\mathbb{F}
, where
\mathbb{F}
is a field. We adopt the matrix notation
A_{r,c}
instead of
A(r,c)
. An array can be thought of as an extention of Riordan arrays (removing the condition that the array is lower-triangular) with indices from
\mathbb{Z}
rather than indices from
\mathbb{N}
. Instead of using the rows of the array to store powers of the coefficients of the generating function
[
2
]
, we store the coefficients of a generating function in two variables (
x
and
y
) where the degree of
x
denotes the row and the degree of
y
denotes the column. ***Add comment about how to actually use it as a Riordan array *** Since the array allows negative indices, then the corresponding generating function is a formal Laurent series rather than a formal power series. That is, we can define the generating function
a(x,y)
as

a(x,y)=\sum_{(r,c)\text{ }\in\text{ }\mathbb{Z}^{2}}A_{r,c}\text{ }x^{r}y^{c}.

Observation 1
.

The set of arrays is a vector space under entry-wise addition and scalar multiplication.

Let
X
and
Y
be shift operators such that
(XA)_{r,c}=A_{r,c-1}
and
(YA)_{r,c}=A_{r-1,c}
. Notice that
X
and
Y
are invertible linear operators and they commute.

Definition 1
.

A
template
T
is a polynomial in
X
and
Y
, where
X^{0}=Y^{0}=I
, the identity operator.

Since
T
is a polynomial of linear operators, then
T
is also linear.

Definition 2
.

A
is
annihilated by
the operator
\Psi
if
\Psi A=0
, where 0 denotes the zero array.

Definition 3
.

We also say that
A
is a
template array with template
T
if
A
is annihilated by a template
T
.

As an example, let
A
be a template array with template
T
, where
T=I-Y(I+X)
. Then we can recover the two-dimensional recurrence by considering the
(r,c)
entry of
T
applied to
A
. Since
A
is a template array, then we have

\displaystyle(TA)_{r,c}

\displaystyle=0\Leftrightarrow

\displaystyle((I-Y(I+X))A)_{r,c}

\displaystyle=0\Leftrightarrow

\displaystyle((I-Y-XY)A)_{r,c}

\displaystyle=0\Leftrightarrow

\displaystyle A_{r,c}-A_{r-1,c}-A_{r-1,c-1}

\displaystyle=0\Leftrightarrow

\displaystyle A_{r,c}=A_{r-1,c}+A_{r-1,c-1}

.

Definition 4
.

An
overlay for a template T
is an array with finite support that contains the coefficients of
T
.

We typically draw overlays with only their nonzero entries visible. We can define the
overlay product
of two arrays by the Hadamard product (or the sum of entry-wise products). We define the dimensions of an overlay to be (number of rows containing non-zero entries)
\times
(number of columns containing non-zero entries). Let the array

Theorem 2
.

If we have an overlay
B=\left(b_{i,j}\right)
such that the top row of the overlay is
u+1
units wide, the bottom row is
l+1
units wide, the furthest column to the right containing a nonzero entry in the overlay is indexed zero, the furthest column to the left containing a nonzero entry in the overlay is indexed
n
, and the bottom-most row containing a nonzero entry in the overlay is indexed
0
while the top-most row containing a nonzero entry in the overlay is indexed
m
, then
m
consecutive rows of initial conditions, along with
u
consecutive columns coming out of the top and
l
consecutive columns coming out of the bottom of these rows is sufficient to populate the rest of the array.

Proof.

Observe that if
n=0
and
m=0
then
b_{0,0}\neq 0
(otherwise we would not have a valid overlay). Then the overlay corresponds to the recurrence

0=\sum_{i=0}^{0}\sum_{j=0}^{0}b_{i,j}A_{r-i,c-j}=b_{0,0}A_{r,c}.

Since
b_{0,0}\neq 0
, then
A_{r,c}=0
, so the only valid array is the zero array. Suppose that
n
and
m
are not both simultaneously zero.

If
m=0
and
n\neq 0
, then the initial conditions we claim to be sufficient to populate the entire array is
n
columns that are pre-populated and no rows that are pre-populated. Without loss of generality, let the pre-populated columns be indexed 0 through
n-1
. Then we have

\sum_{j=0}^{n}b_{0,j}A_{r,c-j}=0.

If trying to populate a column one unit to the right of the previously constructed columns, say column
c\geq n
, then by our assumptions, the columns indexed 0 through
c-1
have already been populated. Thus for our summation, we have

\sum_{j=0}^{n}b_{0,j}A_{r,c-j}=0.

Since
j
ranges between 0 and
n
, then
c-1-j\leq c-1
and
0\leq c-n\leq c-j
. Thus each
A_{r,c-j}
is already determined except for
A_{r,c}
, and since
b_{0,0}\neq 0
,
A_{r,c}
is uniquely determined by the recurrence. Since
r
is arbitrary, then the entire column can be populated this way.

Similarly, relying on the fact that
b_{0,n}\neq 0
, we can constrcut a column
c<0

For the remaining cases, it suffices to show that we can construct a row above the
m
consecutive rows and a row below the
m
consecutive rows in order to populate the array because if we do one, then we can build the next row above by placing the overlay in the starting position from the previous row, move the overlay up one row, and repeat the process outlined below. The same holds for rows below, we just move the overlay down instead of up.

Given the overlay described above, the overlay corresponds to the recurrence

\sum_{i=0}^{m}\sum_{j=0}^{n}b_{i,j}A_{r-i,c-j}=0

where
b_{i,j}
are the coefficients in the overlay with at least one nonzero entry in the
0^{\text{th}}
row, in the
0^{\text{th}}

row and in the

Without loss of generality, let the
m

m-1
.

Case 1 (

\displaystyle 0

Definition 5
.

A
valid initial conditions layout
is the set of elements in
\mathbb{Z}^{2}
(coordinates) that define the location of the initial conditions.

In order to be an initial conditions layout, the initial conditions must construct a unique array when the overlay is applied. In other words, a layout is the locations on the array that must be filled in with initial values in order to construct a unique array for a given overlay. We do assume here that the overlay contains at least one nonzero entry.
