The non-GRS properties for the twisted generalized Reed-Solomon code and its extended code
Canze Zhu, Qunying Liao

Abstract
In 2017, Beelen et al. firstly introduced twisted generalized Reed-Solomon (in short, TGRS) codes, and constructed a large subclass of MDS TGRS codes. Later, they proved that TGRS code is non-GRS when the code rate is less than one half. In this letter, basing on the dual code of the TGRS code or the extended TGRS code, by using the Schur product, we prove that almost all of TGRS codes and extended TGRS codes are non-GRS when the code rate more than one half.

is maximum distance separable (in short, MDS). Especially, generalized Reed-Solomon (in short, GRS) codes are a well known class of MDS codes, it is very important in coding theory and applications

,

,

,

,

,

,

,

,

,

,

,

,

,

]
. Other known MDS codes have been constructed from

-arcs in projective geometry
[

]
, circulant matrices
[

]
, Hankel matrices
[

]
, or twisted Reed-Solomon (in short, TGRS) codes

.

In 2017, inspired by the construction for twisted Gabidulin codes
[
23
]
, Beelen et al. firstly introduced TGRS codes, which is a generalization for GRS codes, they also showed that TGRS codes could be well decoded. Different from GRS codes, they showed that a TGRS code is not necessarily MDS and presented a sufficient and necessary condition for a TGRS code to be MDS
[

,

,

. Especially, the authors showed that TGRS codes are not GRS when the code rate is less than one half

[

. TGRS codes are also used to construct LCD MDS codes by their applications in cryptography

,

In this letter, we focus on the non-GRS properties for the TGRS code and its extended code. Let
\mathcal{C}
be the TGRS code or extended TGRS (in short, ETGRS) code with code rate more than one half, by calculating the dimension and the minimun Hamming distance of the Schur square for

\mathcal{C}^{\perp}
is non-GRS, and then
\mathcal{C}
is non-GRS. The rest of this letter is organized as follows. In section 2, some basic notations and results about linear codes are given. In section 3, we show that almost all of the TGRS code and ETGRS code are non-GRS. In section 4, we conclude the whole paper.

Preliminaries

In this section, we review some basic knowledge.

II-A

The dual codes, the Schur product and equivalence for linear codes

The nonation of the dual code is given in the following.

For
\mathbf{a}=(a_{1},\ldots,a_{n})
,
\mathbf{b}=(b_{1},\ldots,b_{n})

\in\mathbb{F}_{q}^{n}
, the inner product is defined as
\langle\mathbf{a},\mathbf{b}\rangle=\sum\limits_{i=1}^{n}a_{i}b_{i}.
And then
the dual code of
\mathcal{C}
is defined as

\mathcal{C}^{\perp}=\{\mathbf{c}^{{}^{\prime}}\in\mathbb{F}_{q}^{n}~|~\langle\mathbf{c}^{{}^{\prime}},\mathbf{c}\rangle=0~~\text{for any}~\mathbf{c}\in\mathcal{C}\}.

The Schur product is defined as follows.

Definition 1
(
[
5
]
)

For
\mathbf{x}=(x_{1},\ldots,x_{n}),\mathbf{y}=(y_{1},\dots,y_{n})\in\mathbb{F}_{q}^{n}
, the Schur product between
\mathbf{x}
and
\mathbf{y}
is
defined as
\mathbf{x}\star\mathbf{y}:=(x_{1}y_{1},\ldots,x_{n}y_{n}).
The Schur product of two
q
-ary codes
\mathcal{C}_{1}
and
\mathcal{C}_{2}
with length
n
is
defined as

\displaystyle\mathcal{C}_{1}\star\mathcal{C}_{2}=\langle\mathbf{c}_{1}\star\mathbf{c}_{2}~|~\mathbf{c}_{1}\in\mathcal{C}_{1},\mathbf{c}_{2}\in\mathcal{C}_{2}\rangle.

Especially, for a code
\mathcal{C}
, we call
\mathcal{C}^{2}:=\mathcal{C}\star\mathcal{C}
the Schur square of
\mathcal{C}
.

Remark 1

For any linear code
\mathcal{C}=\langle\boldsymbol{v}_{1},\ldots,\boldsymbol{v}_{k}\rangle
with
\boldsymbol{v}_{i}\in\mathbb{F}_{q}^{n}~(i=1,\ldots,k)
, we have

\displaystyle\mathcal{C}^{2}=\langle\boldsymbol{v}_{i}\star\boldsymbol{v}_{j}~(i,j\in\{1,\ldots,k\})\rangle.

(1)

The definition of the equivalence for linear codes is given in the following.

Definition 2

(
[
16
]
)
Let
\mathcal{C}_{1}
and
\mathcal{C}_{2}
be
q
-ary linear codes with length
n
. We say that
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are equivalent if
there is a permutation
\pi
in the permutation group with order
n
and
\boldsymbol{v}=(v_{1},\dots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}
such that
\mathcal{C}_{2}=\Phi_{\pi,\boldsymbol{v}}(\mathcal{C}_{1})
, where

\displaystyle\Phi_{\pi,\boldsymbol{v}}:\mathbb{F}_{q}^{n}\to\mathbb{F}_{q}^{n},\quad(c_{1},\ldots,c_{n})\mapsto(v_{1}c_{\pi(1)},\ldots,v_{n}c_{\pi(n)}).

Remark 2

By Definition
2
, if
\mathcal{C}_{1}
and
\mathcal{C}_{2}
are equivalent, then

\bullet

\mathcal{C}_{1}^{2}
and
\mathcal{C}_{2}^{2}
are equivalent;

\bullet

\mathcal{C}_{1}^{\perp}
and
\mathcal{C}_{2}^{\perp}
are equivalent.

II-B

The GRS, TGRS and ETGRS code

The definition of the GRS code is given in the following.

Definition 3
(
[
16
]
)

Let
\boldsymbol{\alpha}=(\alpha_{1},\ldots,\alpha_{n})\in\mathbb{F}_{q}^{n}
with
\alpha_{i}\neq\alpha_{j}

(i\neq j)
and

\boldsymbol{v}=(v_{1},\ldots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}
. Then
the GRS code is defined as

\displaystyle\mathcal{GRS}_{k,n}(\boldsymbol{\alpha},\boldsymbol{v})

\displaystyle=

\displaystyle\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}))|f(x)\in\mathbb{F}_{q}[x],\deg f(x)\leq k-1\}.

The dual code of the GRS code is given in the following.

Lemma 1
(
[
18
]
)

Let
\boldsymbol{u}=(u_{1},\ldots,u_{n})
with
u_{j}=\prod\limits_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})^{-1}

(j=1,\ldots,n)
, then

\big(\mathcal{GRS}_{k,n}(\boldsymbol{\alpha},\boldsymbol{1})\big)^{\perp}=\mathcal{GRS}_{n-k,n}(\boldsymbol{\alpha},\boldsymbol{u}).

By the definition of the GRS code, Lemma
1
and Remark
1
, we have

Proposition 1

For
\frac{n}{2}\leq k<n
, let
\boldsymbol{u}=(u_{1},\ldots,u_{n})
with
u_{j}=-\prod\limits_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})~(j=1,\ldots,n),
then
\big(\mathcal{GRS}_{k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{1})\big)^{2}=\mathcal{GRS}_{2(n-k)-2,n}(\boldsymbol{\alpha},\boldsymbol{u}^{2})
with dimension
2(n-k)-1
and minimun Hamming distance
2k-n+2
.

The definition of the twisted polynomials linear space
\mathcal{V}_{k,t,h,\eta}
is given in the following.

Definition 4
(
[
2
]
)

Let
\eta\in\mathbb{F}_{q}^{*}
, and
t
,
h
,
k

\in\mathbb{N}
with
0\leq h<k\leq q
. Then the set of
(k,t,h,\eta)
-twisted polynomials is defined as

\displaystyle\mathcal{V}_{k,t,h,\eta}

\displaystyle=

\displaystyle\big\{f(x)=\sum\limits_{i=0}^{k-1}a_{i}x^{i}+\eta a_{h}x^{k-1+t}|a_{i}\in\mathbb{F}_{q}~(i=0,\ldots,k-1)\big\},

which is a
k
-dimensional
\mathbb{F}_{q}
-linear subspace.
h
and
t
are the hook and the twist, respectively.

From the twisted polynomials linear space
\mathcal{V}_{k,t,h,\eta}
, the definitions of the TGRS code and the ETGRS code are given in the following, respectively.

Definition 5
(
[
2
]
)

For any
t
,
h
,
k
,
n

\in\mathbb{N}
with
0\leq h\leq k-1<k-1+t<n\leq q
, let
\eta\in\mathbb{F}_{q}^{*}
,
\boldsymbol{\alpha}=(\alpha_{1},\ldots,\alpha_{n})\!\in\!\mathbb{F}_{q}^{n}
with
\alpha_{i}\neq\alpha_{j}

(i\neq j)
and

\boldsymbol{v}=(v_{1},\ldots,v_{n})\in(\mathbb{F}_{q}^{*})^{n}
. Then
the TGRS code is defined as

\displaystyle\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)=\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}))~|~f(x)\in\mathcal{V}_{k,t,h,\eta}\}.

For
h>0
, the ETGRS code is defined as

\displaystyle\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)

\displaystyle=

\displaystyle\{(v_{1}f({\alpha_{1}}),\ldots,v_{n}f(\alpha_{n}),f_{h})~|~f(x)\in\mathcal{V}_{k,t,h,\eta}\},

where
f_{h}
is the coefficient of
x^{h}
in
f(x)
. Especially,
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{1},\eta)
and
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{1},\eta,\infty)
are called the TRS code and the ETRS code, respectively.

Remark 3

\bullet
Note that
f(0)=f_{0}
, thus it is not necessary to define the ETGRS code when hook
h=0
.

\bullet
In
[
2
]
,
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
and
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
are called TGRS codes without difference. But it is not different from Definition
5
.

Beelen et al. gave the non-GRS property for the TGRS code as the following.

Lemma 2
(Theorem
30

[
3
]
)

If
3<k<\frac{n}{2}
, then
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
is non-GRS.

Note that any punctured code of the GRS code is a GRS code and
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
is a punctured code of
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
. By Lemma
2
, we have

Lemma 3

If
3<k<\frac{n+1}{2}
, then
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS.

The authors gave the parity check matrix for
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
, which is useful to show that
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
is non-GRS when
2k\geq n
.

Lemma 4
(Theorem
3.1

[
27
]
)

For any
m\in\mathbb{N}
, let

u_{j}=\prod_{i=1,i\neq j}^{n}(\alpha_{j}-\alpha_{i})^{-1}~(i=1,\ldots,n),~~L_{m}=\sum\limits_{l=1}^{n}u_{l}\alpha_{l}^{n-1+m}

\text{and}~~~\tilde{L}=\sum\limits_{m=1}^{k-h-1}L_{m}L_{k+t-h-1-m}-\eta^{-1}(1+\eta L_{k+t-h-1}).

Then
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
has the parity check matrix

\tilde{H}_{n-k}(\boldsymbol{v})=\left(\begin{matrix}\tilde{\boldsymbol{\beta}}_{1},\tilde{\boldsymbol{\beta}}_{2},\ldots,\tilde{\boldsymbol{\beta}}_{n}\end{matrix}\right),

where

\displaystyle\tilde{\boldsymbol{\beta}}_{j}=\left(\begin{matrix}&\!\!\!\!\frac{u_{j}}{v_{j}}\\
&\!\!\!\!\vdots\\
&\!\!\!\!\frac{u_{j}}{v_{j}}\alpha_{j}^{n-(k+t+1)}\\
&\!\!\!\!\frac{u_{j}}{v_{j}}\big(\tilde{L}\alpha_{j}^{n-k-t}+\alpha_{j}^{n-(h+1)}-\sum\limits_{m=1}^{k-h-1}L_{m}\alpha_{j}^{n-(h+1)-m}\big)\\
&\!\!\!\!\frac{u_{j}}{v_{j}}\big(\alpha_{j}^{n-(k+t-1)}-L_{1}\alpha_{j}^{n-k-t}\big)\\
&\!\!\!\!\vdots\\
&\!\!\!\!\frac{u_{j}}{v_{j}}\big(\alpha_{j}^{n-(k+1)}-L_{t-1}\alpha_{j}^{n-k-t}\big)\\
\end{matrix}\right)_{(n-k)\times n}.

Remark 4

Under the assumption in Lemma
4
, let

\displaystyle\mathcal{V}_{k,t,h,\eta}^{\perp}

\displaystyle=

\displaystyle\Big\{f(x)=\sum\limits_{i=0}^{n-(k+t+1)}a_{i}x^{i}+\sum_{j=0}^{t-1}a_{n-k-t+j}h_{n-k-t+j}(x)~\Big|

\displaystyle\qquad\quad a_{i}\in\mathbb{F}_{q}~(i=0,\ldots,n-k-1)\Big\}

with

\displaystyle h_{n-k-t+j}(x)

\displaystyle=

\displaystyle\begin{cases}x^{n-(h+1)}+\tilde{L}x^{n-k-t}-\sum\limits_{m=1}^{k-h-1}L_{m}x^{n-(h+1)-m},&\text{if~}j=0;\\
x^{n-k-t+j}-L_{j}x^{n-k-t},&\!\!\!\!\!\!\!\!\!\!\text{if~}~1\leq j\leq t-1.\end{cases}

Then

\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{1},\eta)=\Big\{\big(u_{1}g({\alpha_{1}}),\ldots,{u_{n}}g(\alpha_{n})\big)|g(x)\in\mathcal{V}^{\perp}_{k,t,h,\eta}\Big\}.

III
Non-GRS properties for the TGRS code and ETGRS code

In this section, by using the Schur product, we prove that almost all of TGRS codes and ETGRS codes are non-GRS when the code rate more than one half.

Theorem 1

Let

,
h
,
k
,
n

\in\mathbb{N}
with
0\leq h\leq k-1
and

\frac{n}{2}\leq k\leq n-3

(1.1)
-
(1.6)

\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)

(1.1)

n=k+t
,
2k\geq n+2
, and
3\leq h\leq k-3
;

(1.2)

n=k+t+1
,
2k\geq n+2
, and
2\leq h\leq k-3

(1.3)

n\geq k+t+2
,
2k\geq n
,

(1.4)

n\geq k+t+2
,
2k\geq n+1

t=2

(1.5)

n\geq k+t+2

Proof
. We show that
\dim\big(\big(\mathcal{C}^{\perp}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{1},\eta)\big)^{2}\big)\geq 2(n-k)
as follows.

By Remark
4

\displaystyle\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{1},\eta)\!\!=\big\{\big(u_{1}f({\alpha_{1}}),\ldots,u_{n}f(\alpha_{n})\big)\big|f(x)\in\mathcal{V}^{\perp}_{k,t,h,\eta}\big\},\!\!

where

\displaystyle\mathcal{V}_{k,t,h,\eta}^{\perp}=

\displaystyle\Big\{f(x)=\sum\limits_{i=0}^{n-(k+t+1)}a_{i}x^{i}+\sum_{j=0}^{t-1}a_{n-k-t+j}h_{n-k-t+j}(x)|

\displaystyle\hskip 18.49988pt\hskip 18.49988pta_{i}\in\mathbb{F}_{q}~(i=0,\ldots,n-k-1)\Big\}

with

\displaystyle\begin{aligned} &h_{n-k-t+i}(x)\\
=&\begin{cases}x^{n-(h+1)}+\tilde{L}x^{n-k-t}-\sum\limits_{m=1}^{k-h-1}L_{m}x^{n-(h+1)-m},&\!\!\!\!\!\!\!\text{~if~}i=0;\\
x^{n-k-t+i}-L_{i}x^{n-k-t},&\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\!\text{~if~}1\leq i\leq t-1.\end{cases}\end{aligned}

(2)

Thus

\displaystyle\big(\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{1},\eta)\big)^{2}\!\!=\!\!\Big\{\big(g({\alpha_{1}}),\ldots,g(\alpha_{n})\big)\big|g(x)\in(\mathcal{V}_{k,t,h,\eta}^{\perp})^{2}\Big\}

\displaystyle(\mathcal{V}_{k,t,h,\eta}^{\perp})^{2}=\big\langle g(x)=f_{1}(x)f_{2}(x)\big|~f_{1}(x),f_{2}(x)\in\mathcal{V}_{k,t,h,\eta}^{\perp}\big\rangle.

x^{l}h_{0}(x)

(14)

If

h-1\leq n-2k+h-2<n-2k+h\leq n-k-3,

thus

-

(1.5)

\displaystyle\big(s,s_{1},s_{2}\in\{0,\ldots,n-k-t-1\},l,l_{1},l_{2}\in\{0,1,\ldots,t-1\}\big)\Big\rangle,

and

\displaystyle\begin{aligned} &\deg\big(x^{l+s}\big)=l+s\leq n-1~(l,s\in\{0,1,\ldots,n-k-t-1\}),\\
&\deg(x^{n-k-t-2}h_{n-k-t+l}(x))=2(n-k)-2t-2+l\\
&~(l=1,2,\ldots,t-1),\\
&\deg\big(h_{n-k-3}(x)h_{n-k-t+l_{1}}(x)\big)=2(n-k)-t-3+l_{1}\\
&~(l_{1}=1,\ldots,t-1),~\\
&\deg\big(h_{n-k-2}(x)h_{n-k-1}(x)\big)=2(n-k)-3,\\
&\deg\big(h_{n-k-1}^{2}(x)\big)=2(n-k)-2.\end{aligned}

(16)

Furthermore, for
x^{l}h_{0}(x)

Lemma 5

For any
m\in\mathbb{N}
and
A\subseteq\mathbb{F}_{q}
with
|A|>2
, let
L_{A}(m)=\sum\limits_{\alpha\in A}\alpha^{m}\prod_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta),
then

\displaystyle L_{A}(m)=\begin{cases}0,\hskip 9.24994pt&\text{if}~m\leq|A|-2;\\
-1,\hskip 9.24994pt&\text{if}~m=|A|-1;\\
-\sum\limits_{\alpha\in A}\alpha,&\text{if}~m=|A|.\end{cases}

(20)

Proof.
For any
l\in\mathbb{Z}^{+}
, it is well-known that

\displaystyle\sum\limits_{\beta\in\mathbb{F}_{q}}\beta^{l}=\begin{cases}-1,\hskip 9.24994pt&\text{if}~q-1\mid l;\\
0,\hskip 9.24994pt&\text{otherwise}.\end{cases}

(21)

Note that

\displaystyle\prod_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta)

\displaystyle=

\displaystyle\alpha^{q-|A|}-\sum\limits_{\beta\in\mathbb{F}_{q}\backslash A}\beta\alpha^{q-|A|-1}+\cdots+(-1)^{q-|A|}\prod_{\beta\in\mathbb{F}_{q}\backslash A}\beta

\displaystyle=

\displaystyle\alpha^{q-|A|}+\sum\limits_{\gamma\in A}\gamma\alpha^{q-|A|-1}+\cdots+(-1)^{q-|A|}\prod_{\beta\in\mathbb{F}_{q}\backslash A}\beta,

thus we have

\displaystyle\begin{aligned} L_{A}(m)=&\sum\limits_{\alpha\in A}\alpha^{m}\prod_{\beta\in\mathbb{F}_{q}\backslash A}(\alpha-\beta)\\
=&\sum\limits_{\alpha\in\mathbb{F}_{q}}\Big(\alpha^{q-|A|+m}+\sum\limits_{\gamma\in A}\gamma\alpha^{q-|A|-1+m}+\\
&\hskip 18.49988pt\hskip 18.49988pt\hskip 18.49988pt\cdots+(-1)^{q-|A|+m}\prod_{\beta\in\mathbb{F}_{q}\backslash A}\beta\alpha^{m}\Big).\end{aligned}

(22)

Now by
(\ref{lq1})
-
(\ref{lq2})
, we obtain
(\ref{lq})
.
\hfill\Box

Theorem 2

For
t\geq 2
,
3\leq k\leq n-2
and
n\geq k+t+1
,
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS.

Proof
. By Lemma
3
, if
3\leq k<\frac{n+1}{2}
, then
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS. Thus it is enought to prove that the theorem is true for
2k\geq n+1
.

In the following, we prove that
\boldsymbol{c}_{i}\in\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)

(i=1,2,3)
, where

\displaystyle\boldsymbol{c}_{1}=\Big(~\frac{u_{1}}{v_{1}}\alpha_{1}^{n-k-t-1}~,\ldots,\frac{u_{n}}{v_{n}}\alpha_{n}^{n-k-t-1},0~\Big),

\displaystyle\boldsymbol{c}_{2}=\Big(~\frac{u_{1}}{v_{1}}\alpha_{1}^{n-k-t}~,\ldots,\frac{u_{n}}{v_{n}}\alpha_{n}^{n-k-t},-\eta~\Big),

\displaystyle\boldsymbol{c}_{3}=\Big(~\frac{u_{1}}{v_{1}}\alpha_{1}^{n-k-t+1}~,\ldots,\frac{u_{n}}{v_{n}}\alpha_{n}^{n-k-t+1},-\eta\sum_{i=1}^{n}\alpha_{i}~\Big).

Denote
A_{\boldsymbol{\alpha}}=\{\alpha_{1},\ldots,\alpha_{n}\}
, for
s\in\{n-k-t-1,n-k-t,n-k-t+1\}
and
l\in\{0,\ldots,k-1,k-1+t\}
, by the assumption
t\geq 2
and Lemma
5
, we have

\displaystyle\begin{aligned} &\sum\limits_{i=0}^{n}u_{i}\alpha_{i}^{s}\alpha_{i}^{l}\\
=&-\sum\limits_{\alpha\in A_{\boldsymbol{\alpha}}}\alpha^{s+l}\prod_{\beta\in\mathbb{F}_{q}\backslash A_{\boldsymbol{\alpha}}}(\alpha-\beta)\\
=&\begin{cases}1,&\text{if}~s=n-k-t\text{~and~}l=k-1+t;\\
\sum_{i=1}^{n}\alpha_{i},&\text{if}~s=n-k-t+1\text{~and~}l=k-1+t;\\
0,&\text{otherwise}.\end{cases}\end{aligned}

By above equation, we can verify that

\boldsymbol{c}_{i}\in\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)~(i=1,2,3)

directly. Thus

\displaystyle\boldsymbol{c}

\displaystyle=\boldsymbol{c}_{1}\star\boldsymbol{c}_{3}-\boldsymbol{c}_{2}\star\boldsymbol{c}_{2}

\displaystyle=\big(0,0,\ldots,0,\eta^{2}~\big)\in(\mathcal{C}_{k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty))^{2}.

By Proposition
1
, for an
[n+1,k]
GRS code
\mathcal{C}
,
(\mathcal{C}^{\perp})^{2}
is with minimun Hamming distance

\displaystyle d=2k-(n+1)+2\geq 2.

Thus
\boldsymbol{c}\notin(\mathcal{C}^{\perp})^{2}
, and then
\mathcal{C}_{t,h,k,n}^{\perp}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS, it implies that
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS.

\hfill\Box

Remark 5

\bullet
Note that any punctured code of the GRS code is a GRS code and
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta)
is a punctured code of
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
. Thus, if one of conditions
(1.1)
-
(1.6)
in Theorem
1
holds, then
\mathcal{C}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{v},\eta,\infty)
is non-GRS.

\bullet
The assumption in Theorem
2
is weaker than that in Theorem
1
when
t\geq 2
and
n\geq k+t+1
.

IV
Conclusion

In this letter, by using the Schur product, we prove that almost all of TGRS codes and ETGRS codes are non-GRS when the code rate more than one half. However, if
n,k,t,h
do not satisfy one of the conditions in Theorem
1
, we can not obtain the non-GRS property for the TGRS code by the method given in the proof for Theorem
1
. The main reason is that we can not obtain
\dim\big(\big(\mathcal{C}^{\perp}_{t,h,k,n}(\boldsymbol{\alpha},\boldsymbol{1},\eta)\big)^{2}\big)\geq 2k
without the conditions in Theorem
1
.
