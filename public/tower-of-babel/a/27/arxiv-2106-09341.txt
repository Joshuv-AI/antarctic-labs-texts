Positivity for the clamped plate equation under high tension
Sascha Eichmann,

Abstract




8.8.2026

Abstract:

In this article we consider positivity issues for the clamped plate equation with high tension
\gamma>0
. This equation is given by
\Delta^{2}u-\gamma\Delta u=f
under clamped boundary conditions. Here we show, that given a positive
f
, i.e. upwards pushing, we find a
\gamma_{0}>0
such that for all
\gamma\geq\gamma_{0}
the bending
u
is indeed positive. This
\gamma_{0}
only depends on the domain and the ratio of the
L^{1}
and
L^{\infty}
norm of
f
.

In contrast to a recent result by Cassani and Tarsia, our approach is valid in all dimensions.

Keywords:
Bi-laplace equation, maximum principle, high tension.

AMS Subject Classification:
35B09, 35B30, 35B50, 35J40.

1
Introduction

The Boggio-Hadamard conjecture states, that for a given convex, open, bounded set
\Omega\subseteq{\mathbb{R}}^{n}
, an
f\geq 0
and outer normal
\nu
of
\Omega
, a solution
u
to

\left\{\begin{array}[]{cc}\Delta^{2}u=f&\mbox{ in }\Omega,\\
u=\partial_{\nu}u=0&\mbox{ on }\partial\Omega.\end{array}\right.

(
1.1
)

is nonnegative, i.e.
u\geq 0
(cf.
[
H1908a
]
,
[
H1908b
]
). Problem (
1.1
) models the bending
u
of a clamped plate
\Omega
under a force
f
. Hence the problem can be restated as:

Does upward pushing yield upward bending?

The conjecture was substantiated by Boggio’s explicit formula
[
Bo05
]
(see also
[
GazGrSw
, Lemma 2.27]
or
[
Hi19
]
) for the Greens function of problem (
1.1
) on the unit disc, because this function is positive, and furthermore by Almansi’s result to calculate the Greens function for certain domains by the Greens function of the unit ball (see
[
Al1899
]
).

Several other domains than the disc have been found on which such a positivity preserving property holds (see the references below). Hadamard himself claimed in
[
H1908b
]
that such a property for all limaçons is true, which turned out to be wrong in general, though some of them still possess this property (see
[
GazGrSw
, Fig. 1.2]
). Remarkable is that such limaçons are not convex.
In
[
GrRo10
]
Grunau and Robert showed, that positivity preserving is preserved under small regular perturbations of the domain in dimensions
n\geq 3
.
The conformal invariance of the problem was also successfully used to construct domains with a positivity preserving property by e.g. Dall’Acqua and Sweers in
[
DaSw04
]
(see also the references therein for more informations on such domains).

On the other hand several counterexamples have been found by now. The first one was by Duffin on an infinite strip
[
Du48
]
and shortly after Garabedian
[
Gar51
]
showed, that on an elongated ellipse the Greens function changes sign. By now even for uniform forces, i.e.
f\equiv 1
, counterexamples have been found by Grunau and Sweers in
[
GrSw14a
]
and
[
GrSw14b
]
. We refer to
[
GazGrSw
, §1.2]
for a comprehensive historical overview to this problem.

Instead of examining (
1.1
) for positivity, Cassani and Tarsia in
[
CaTa20
]
examined positivity issues for

\left\{\begin{array}[]{cc}\Delta^{2}u-\gamma\Delta u=f&\mbox{ in }\Omega,\\
u=\partial_{\nu}u=0&\mbox{ on }\partial\Omega.\end{array}\right.

(
1.2
)

with
\gamma>0
big enough. The basic motivation is that for
\gamma
big enough, the influence of
\Delta u
(
-\Delta u=f
satisfies positivity preserving via the maximum principle) becomes stronger than that of
\Delta^{2}u
. In more technical detail Cassani and Tarsia conjectured the existence of a
\gamma_{0}=\gamma_{0}(f,\Omega)\geq 0
, such that
u\geq 0
for all
\gamma\geq\gamma_{0}
and provided a proof for dimensions
n=2,3
, smooth, bounded
\Omega
and positive
f\in L^{2}(\Omega)
.
In this article we provide a different approach, which is valid for all dimensions, see Theorem
1.1
.

In dimension
n=1
this positivity preserving property is true for all
\gamma>0
independent of
f
. This was shown by Grunau in
[
Gr02
]
Proposition 1.

The parameter
\gamma
is usually called tension, if it is positive. Several results concerning (
1.2
) have been achieved, which are usually concerned with vibrations of the plate, i.e. eigenvalue problems. Bickley gave some explicit caculations for the spectrum in the unit disc in
[
Bi1933
]
already in 1933. Hence the existing literature for these eigenvalue problems is quite vast and is still developing, see e.g.
[
BuoKe21
]
,
[
AnBuoFr19
]
and the references therein.

Other modifications for (
1.1
) concerning positivity issues are e.g. changing the boundary conditions to so called Steklov-conditions. This has been examined by e.g. Bucur and Gazzola in
[
BucGaz11
]
.

Different elliptic differential operators of higher order, their respective fundamental solutions and their sign close to a singularity have also been examined by Grunau, Romani and Sweers in
[
GrRomSw20
]
in a more systematic approach to understand better the loss of positivity preserving.

Instead of (
1.2
) we examine the following boundary value problem for positivity preserving. This is obviously equivalent, but (
1.3
) yields the advantage, that the singularity of the equation is more prominent and hence yields easier access to necessary estimates.

\left\{\begin{array}[]{cc}\varepsilon^{2}\Delta^{2}u_{\varepsilon}-\Delta u_{\varepsilon}=f&\mbox{ in }\Omega,\\
u_{\varepsilon}=\partial_{\nu}u_{\varepsilon}=0&\mbox{ on }\partial\Omega.\end{array}\right.

(
1.3
)

Here
\Omega\subset\subset{\mathbb{R}}^{n}
,
\partial\Omega\in C^{4}
,
f\in L^{\infty}(\Omega)
and
\varepsilon>0
,
and the solution
u_{\varepsilon}\in W^{4,p}(\Omega)\mbox{ for all }1<p<\infty
(see e.g.
[
GazGrSw
, Corollary 2.21]
and the references therein for existence, regularity and uniqueness to (
1.3
)).

Theorem 1.1

For connected
\Omega\subset\subset{\mathbb{R}}^{n}
,
\partial\Omega\in C^{4}
,
f\in L^{\infty}(\Omega)
,
\tau>0,f\geq 0
with

\int f{\ {\rm d}}{{\cal L}^{n}}\geq\tau\parallel f\parallel_{L^{\infty}(\Omega)}>0,

(
1.4
)

there exists
\varepsilon_{0}=\varepsilon_{0}(\Omega,\tau)>0
such that

u_{\varepsilon}>0\quad\mbox{in }\Omega\mbox{ for all }0<\varepsilon\leq\varepsilon_{0}.

(
1.5
)

Please note, that we do not have any restrictions on the dimension, i.e.
n\in{\mathbb{N}}
arbitrary. Furthermore our method yields, that
\varepsilon_{0}
does not depend on
f
directly, only on
\tau
.

The strategy of the proof is as follows:
The limiting problem of (
1.3
) is

\left\{\begin{array}[]{cc}-\Delta u=f\geq 0,\not\equiv 0&\mbox{ in }\Omega,\\
u=0&\mbox{ on }\partial\Omega,\end{array}\right.

which admits a maximum principle,
and establishes positivity of
u_{\varepsilon}\mbox{ on any }\Omega^{\prime}\subset\subset\Omega\mbox{ for }\varepsilon
small.

We proceed by contradiction and assume Theorem
1.1
is false. Hence for every
\varepsilon>0
we find a nonnegative
f_{\varepsilon}\in L^{\infty}(\Omega)
satisfying (
1.4
), such that
u_{\varepsilon}
is not positive in
\Omega
.

Then we examine a blow up of our solutions
u_{\varepsilon}
, which is weighted by the supremum of the modulus of the laplacian at the boundary, i.e.
\sup_{\partial\Omega}\varepsilon^{2}|\Delta u_{\varepsilon}|
.
After a careful analysis (see sections §
2
and §
3
), we can show that this blow up converges in a suitable sense to a solution of
\Delta^{2}u-\Delta u=0
on the half-space with Dirichlet boundary conditions (see section §
4
).
With a uniqueness result shown in appendix
A
, we explicitly calculate this limit
and obtain positivity of the laplacian of
u_{\varepsilon}
on the boundary for
\varepsilon
small.
This is crucial, as in the presence of Dirichlet boundary conditions in (
1.3
)
the laplacian is the second normal derivative of
u_{\varepsilon}
on the boundary,
and therefore positivity of the laplacian on the boundary gives positivity of
u_{\varepsilon}

close to the boundary, see section §
4
.

Similar strategies of examining a blow up to the half space and using explicit formulas have been employed by Grunau and Robert in
[
GrRo10
]
and Grunau, Robert and Sweers in
[
GrRoSw11
]
to show lower bounds for the Greens function of a polyharmonic operator. This method was later refined by Pulst in his PhD-thesis
[
Pu15
]
to also obtain such estimates, if non-constant lower order terms are present. If variable coefficients in the principal part of the operator are given by a power of a second order elliptic linear operator, such estimates were found by the same method by Grunau in
[
Gr21
]
.

Our blow-up strategy needs careful estimates for the singular problem (
1.3
). Estimates for these kinds of problems have a long history, see e.g.
[
Fr79
]
,
[
Gre68
]
,
[
Gue81
]
, and
[
Naj88
]
. We are not aware of any specific estimates, which would help in our specific situation. For this reason and for the sake of completeness we derive them here.

2
Preliminary estimates

We proceed by contradiction and assume we find nonnegative
f_{\varepsilon}\in L^{\infty}(\Omega)
for
\varepsilon\downarrow 0
satisfying (
1.4
), such that the solution
u_{\varepsilon}
of (
1.3
) is sign-changing.
As (
1.3
) is homogeneous of degree one,
we may assume by scaling

0\leq f_{\varepsilon}\leq 1\quad\mbox{ and }\quad\int f_{\varepsilon}{\ {\rm d}}{{\cal L}^{n}}\geq\tau>0.\\

(
2.1
)

By the Banach-Alaoglu Theorem we get after passing to subsequence and relabeling
f_{\varepsilon}\rightarrow f\mbox{ weakly}^{*}\mbox{ in }L^{\infty}(\Omega)
with

0\leq f\leq 1\quad\mbox{ and }\quad\int f{\ {\rm d}}{{\cal L}^{n}}\geq\tau>0.

(
2.2
)

In particular we have
f\not\equiv 0
.

The limiting problem of (
1.3
) is thought to be the second-order boundary-value problem

\begin{array}[]{c}-\Delta u=f\quad\mbox{in }\Omega,\\
u=0\quad\mbox{on }\partial\Omega.\end{array}

(
2.3
)

We also consider

\begin{array}[]{c}-\Delta u_{0,\varepsilon}=f_{\varepsilon}\quad\mbox{in }\Omega,\\
u_{0,\varepsilon}=0\quad\mbox{on }\partial\Omega.\end{array}

(
2.4
)

These two problems admit some important estimates:

Proposition 2.1

For
u
and
u_{0,\varepsilon}
in (
2.3
) rsp. (
2.4
) we find a constant
c_{0}=c_{0}(\Omega,\tau)>0
, such that

-\partial_{\nu}u,-\partial_{\nu}u_{0,\varepsilon}\geq c_{0}>0\quad\mbox{on }\partial\Omega

(
2.5
)

and

u,u_{0,\varepsilon}\geq c_{0}d(.,\partial\Omega)\quad\mbox{on }\Omega

(
2.6
)

for
\varepsilon>0
small enough.

Proof:

Both problems admit by standard elliptic theory, see
[
GT
]
Theorem 9.15,
unique solutions
u\mbox{ respectively }u_{0,\varepsilon}\in W^{2,p}(\Omega)\hookrightarrow C^{1,\alpha}(\Omega)\mbox{ for all }1<p<\infty\mbox{ and }1-(n/p)>\alpha>0
with

\parallel u,u_{0,\varepsilon}\parallel_{W^{2,p}(\Omega)\cap C^{1,\alpha}(\Omega)}\leq C(\Omega,p,\alpha)<\infty\quad\forall 1<p<\infty,0<\alpha<1.

(
2.7
)

In particular the set of all
u,u_{0,\varepsilon}\mbox{ for any }f,f_{\varepsilon}
with (
2.2
) and (
2.1
)
is compact in
C^{1}(\overline{\Omega})
, and in particular

u_{0,\varepsilon}\rightarrow u\quad\mbox{strongly in }C^{1,\alpha}(\Omega),\forall 0<\alpha<1,

(
2.8
)

and weakly in
W^{2,p}(\Omega)\mbox{ for all }1<p<\infty
.

As
f,f_{\varepsilon}\geq 0,f,f_{\varepsilon}\not\equiv 0\mbox{ and }\Omega
is connected,
we get by the strong maximum principle, see
[
GT
]
Theorem 8.19, that

u,u_{0,\varepsilon}>0\mbox{ in }\Omega.

(
2.9
)

By Hopf’s maximum principle,
see
[
GT
]
Lemma 3.4, and by compactness of the
u,u_{0,\varepsilon}\mbox{ in }C^{1}(\overline{\Omega})
we find a constant
c_{0}=c_{0}(\Omega,\tau)>0
such that (
2.5
) and (
2.6
) both hold for
\varepsilon>0
small enough.

\Box

We put
v_{\varepsilon}:=u_{\varepsilon}-u_{0,\varepsilon}\in W^{2,p}(\Omega)\cap C^{1,\alpha}(\Omega)\mbox{ with }v_{\varepsilon}=0\mbox{ on }\partial\Omega
.
Subtracting in (
1.3
), we see

\Delta(\varepsilon^{2}\Delta u_{\varepsilon}-v_{\varepsilon})=0\quad\mbox{in }\Omega,

(
2.10
)

that is
\varepsilon^{2}\Delta u_{\varepsilon}-v_{\varepsilon}

is harmonic in
\Omega
.

Equation (
2.3
) is indeed the limiting problem of (
1.3
)
in the sense of the following proposition.

Proposition 2.2

For
u_{\varepsilon},u,v_{\varepsilon}=u_{\varepsilon}-u_{0,\varepsilon}

as in (
1.3
), (
2.1
), (
2.4
),
we have

\begin{array}[]{c}u_{\varepsilon}\rightarrow u,v_{\varepsilon}\rightarrow 0\mbox{ strongly in }W^{1,2}_{0}(\Omega),\\
\varepsilon\Delta u_{\varepsilon}\rightarrow 0\mbox{ strongly in }L^{2}(\Omega).\end{array}

(
2.11
)

Proof:

Multiplying (
2.10
) by
v_{\varepsilon}
and integrating by parts, we get

0=\int\limits_{\Omega}\Delta(\varepsilon^{2}\Delta u_{\varepsilon}-v_{\varepsilon})v_{\varepsilon}{\ {\rm d}}{{\cal L}^{n}}=

=\int\limits_{\Omega}\varepsilon^{2}(\Delta^{2}u_{\varepsilon})u_{\varepsilon}{\ {\rm d}}{{\cal L}^{n}}-\int\limits_{\Omega}\varepsilon^{2}(\Delta^{2}u_{\varepsilon})u_{0,\varepsilon}{\ {\rm d}}{{\cal L}^{n}}+\int\limits_{\Omega}|\nabla v_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}.

Replacing
\varepsilon^{2}\Delta^{2}u_{\varepsilon}\mbox{ by }\Delta v_{\varepsilon}

in the second term with (
2.10
), we continue

\int\limits_{\Omega}\varepsilon^{2}|\Delta u_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}+\int\limits_{\Omega}|\nabla v_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}=\int\limits_{\Omega}(\Delta v_{\varepsilon})u_{0,\varepsilon}{\ {\rm d}}{{\cal L}^{n}}=

=-\int\limits_{\Omega}\nabla v_{\varepsilon}\nabla u_{0,\varepsilon}{\ {\rm d}}{{\cal L}^{n}}\leq\parallel\nabla v_{\varepsilon}\parallel_{L^{2}(\Omega)}\ \parallel\nabla u_{0,\varepsilon}\parallel_{L^{2}(\Omega)},

(
2.12
)

in particular
\parallel\nabla v_{\varepsilon}\parallel_{L^{2}(\Omega)}\leq\parallel\nabla u_{0,\varepsilon}\parallel_{L^{2}(\Omega)}\leq C(\Omega)
by (
2.7
), hence

\int\limits_{\Omega}\varepsilon^{2}|\Delta u_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}+\int\limits_{\Omega}|\nabla v_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}\leq\int\limits_{\Omega}|\nabla u_{0,\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}\leq C(\Omega).

Passing to a subsequence, we get

\begin{array}[]{c}v_{\varepsilon}\rightarrow v\mbox{ weakly in }W^{1,2}_{0}(\Omega),\\
\varepsilon^{2}\Delta u_{\varepsilon}\rightarrow 0\mbox{ strongly in }L^{2}(\Omega).\end{array}

Multiplying (
2.10
) by some
\eta\in C^{\infty}_{0}(\Omega)

and passing to a subsequence, we get

0=\int\limits_{\Omega}(\varepsilon^{2}\Delta^{2}u_{\varepsilon}-\Delta v_{\varepsilon})\eta{\ {\rm d}}{{\cal L}^{n}}=\int\limits_{\Omega}\varepsilon^{2}\Delta u_{\varepsilon}\cdot\Delta\eta{\ {\rm d}}{{\cal L}^{n}}+\int\limits_{\Omega}\nabla v_{\varepsilon}\nabla\eta{\ {\rm d}}{{\cal L}^{n}}\rightarrow\int\limits_{\Omega}\nabla v\nabla\eta{\ {\rm d}}{{\cal L}^{n}},

and
v\in W^{1,2}_{0}(\Omega)
is harmonic in
\Omega
,
hence
v=0\mbox{ and }u_{\varepsilon}\rightarrow u\mbox{ weakly in }W^{1,2}_{0}(\Omega)
.
Returning to (
2.12
), we improve now to

\int\limits_{\Omega}\varepsilon^{2}|\Delta u_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}+\int\limits_{\Omega}|\nabla v_{\varepsilon}|^{2}{\ {\rm d}}{{\cal L}^{n}}=-\int\limits_{\Omega}\nabla v_{\varepsilon}\nabla u_{0,\varepsilon}{\ {\rm d}}{{\cal L}^{n}}\rightarrow 0,

which is (
2.11
).

\Box

The following proposition shows that the laplacian cannot be bounded throughout
\Omega
.

Proposition 2.3

For
u_{\varepsilon},\tau

as in (
1.3
), (
2.1
), (
2.2
),
we have for any
\Omega^{\prime}\subset\subset\Omega
that

\liminf\limits_{\varepsilon\rightarrow 0}\int\limits_{\Omega\setminus\Omega^{\prime}}(\Delta u_{\varepsilon})_{+}{\ {\rm d}}{{\cal L}^{n}}\geq\tau>0.

Proof:

We see for any
\eta\in C^{\infty}_{0}(\Omega)

with the previous Proposition
2.2

\int(\Delta u_{\varepsilon})\eta{\ {\rm d}}{{\cal L}^{n}}=\int u_{\varepsilon}\Delta\eta{\ {\rm d}}{{\cal L}^{n}}\rightarrow\int u\Delta\eta{\ {\rm d}}{{\cal L}^{n}}=\int(\Delta u)\eta{\ {\rm d}}{{\cal L}^{n}}=-\int f\eta{\ {\rm d}}{{\cal L}^{n}}

and the homogeneous boundary conditions in (
1.3
) that

\int\Delta u_{\varepsilon}(1-\eta){\ {\rm d}}{{\cal L}^{n}}=\int\Delta u_{\varepsilon}{\ {\rm d}}{{\cal L}^{n}}-\int(\Delta u_{\varepsilon})\eta{\ {\rm d}}{{\cal L}^{n}}=

=\int\limits_{\partial\Omega}\partial_{\nu}u_{\varepsilon}{\ {\rm d}}area_{\partial\Omega}-\int(\Delta u_{\varepsilon})\eta{\ {\rm d}}{{\cal L}^{n}}\rightarrow\int f\eta{\ {\rm d}}{{\cal L}^{n}}.

Choosing
\eta\in C^{\infty}_{0}(\Omega)\mbox{ with }0\leq\eta\leq 1\mbox{ and }\eta\equiv 1\mbox{ in }\Omega^{\prime}
, we get

\int\limits_{\Omega\setminus\Omega^{\prime}}(\Delta u_{\varepsilon})_{+}{\ {\rm d}}{{\cal L}^{n}}\geq\int(\Delta u_{\varepsilon})(1-\eta){\ {\rm d}}{{\cal L}^{n}}\rightarrow\int f\eta{\ {\rm d}}{{\cal L}^{n}}.

Letting
\eta\nearrow\chi_{\Omega}
, we get from (
2.2
) that

\int f\eta{\ {\rm d}}{{\cal L}^{n}}\rightarrow\int f{\ {\rm d}}{{\cal L}^{n}}\geq\tau>0,

and the proposition follows.

\Box

3
The laplacian on the boundary

In this section, we investigate the values of the laplacian on the boundary and put

{\ell^{-}_{\varepsilon}}:=\min\limits_{\partial\Omega}\varepsilon^{2}\Delta u_{\varepsilon}\leq\max\limits_{\partial\Omega}\varepsilon^{2}\Delta u_{\varepsilon}=:{\ell^{+}_{\varepsilon}}.

(
3.1
)

With subscripts
\pm
we denote the positive respectively negative part, i.e.

{\ell^{\pm}_{\varepsilon}}_{,+}:=\max\left(0,{\ell^{\pm}_{\varepsilon}}\right),\ {\ell^{\pm}_{\varepsilon}}_{,-}:=\max\left(0,-{\ell^{\pm}_{\varepsilon}}\right).

(
3.2
)

Furthermore we set

{M_{\varepsilon}}:=\parallel\varepsilon^{2}\Delta u_{\varepsilon}\parallel_{L^{\infty}(\partial\Omega)}=\max({\ell^{+}_{\varepsilon}}_{,+},{\ell^{-}_{\varepsilon}}_{,-}).

(
3.3
)

The quantity
M_{\varepsilon}
will be crucial throughout the exposition. Our goal is to show, that it has the same asymptotic as
\varepsilon
itself, i.e. we find constants
c_{0},C>0
such that

c_{0}\varepsilon\leq M_{\varepsilon}\leq C\varepsilon.

for
\varepsilon>0
small.
A first step in this direction is Proposition
3.3
, which will later be improved to our desired result in Proposition
4.2
and (
4.19
).

With the maximum principle, we get the following estimates.

Proposition 3.1

For
u_{\varepsilon},f_{\varepsilon},u_{0,\varepsilon},v_{\varepsilon}=u_{\varepsilon}-u_{0,\varepsilon},{\ell^{\pm}_{\varepsilon}}

as in (
1.3
), (
2.1
), (
2.4
),
(
3.1
),
we have

{\ell^{-}_{\varepsilon}}\leq\varepsilon^{2}\Delta u_{\varepsilon}-v_{\varepsilon}\leq{\ell^{+}_{\varepsilon}}\quad\mbox{in }\Omega,

(
3.4
)

-{\ell^{+}_{\varepsilon}}_{,+}-\varepsilon^{2}\parallel f_{\varepsilon}\parallel_{L^{\infty}(\Omega)}\leq v_{\varepsilon}\leq{\ell^{-}_{\varepsilon}}_{,-}\quad\mbox{in }\Omega,

(
3.5
)

u_{\varepsilon}>-{\ell^{+}_{\varepsilon}}_{,+}\quad\mbox{in }\Omega.

(
3.6
)

Proof:

As
v_{\varepsilon}=u_{\varepsilon}-u_{0,\varepsilon}=0\mbox{ on }\partial\Omega

by (
1.3
) and (
2.4
),
we get (
3.4
) from (
2.10
).

Adding (
2.4
), we see

\varepsilon^{2}\Delta v_{\varepsilon}-v_{\varepsilon}=-\varepsilon^{2}\Delta u_{0,\varepsilon}+\varepsilon^{2}\Delta u_{\varepsilon}-v_{\varepsilon}\leq\varepsilon^{2}f_{\varepsilon}+{\ell^{+}_{\varepsilon}}\quad\mbox{in }\Omega,

in particular

\varepsilon^{2}\Delta v_{\varepsilon}<0\quad\mbox{in }[v_{\varepsilon}<-\varepsilon^{2}f_{\varepsilon}-{\ell^{+}_{\varepsilon}}_{,+}]=:\Omega_{0}.

Since
v_{\varepsilon}\geq-\varepsilon^{2}f_{\varepsilon}-{\ell^{+}_{\varepsilon}}_{,+}\mbox{ on }\partial\Omega_{0}
,
as
v_{\varepsilon}=0\mbox{ on }\partial\Omega
by above,
we get from the mean-value estimate for superharmonic functions
or by Alexandroff’s maximum principle, as
v_{\varepsilon}\in W^{2,n}(\Omega)
,
see
[
GT
]
Theorem 9.1,
that
v_{\varepsilon}\geq-\varepsilon^{2}f_{\varepsilon}-{\ell^{+}_{\varepsilon}}_{,+}\mbox{ in }\Omega_{0}
,
hence
\Omega_{0}=\emptyset
,
and the left estimate in (
3.5
) follows.
The right estimate is obtained by symmetry observing that
f_{\varepsilon}\geq 0
.

Next for
x\in\overline{\Omega}\mbox{ with }u_{\varepsilon}(x)=\min_{\overline{\Omega}}u_{\varepsilon}
and assuming that this minimum is negative,
we see
x\in\Omega
, as
u_{\varepsilon}=0\mbox{ on }\partial\Omega
by (
1.3
),
hence
\Delta u_{\varepsilon}(x)\geq 0
,
as
u_{\varepsilon}\in W^{4,p}(\Omega)\hookrightarrow C^{2}(\Omega)\mbox{ for }2-(n/p)>0
.
Then we get with (
3.4
) and (
2.9
) that

-u_{\varepsilon}(x)\leq\varepsilon^{2}\Delta u_{\varepsilon}(x)-v_{\varepsilon}(x)-u_{0,\varepsilon}(x)<{\ell^{+}_{\varepsilon}},

which is (
3.6
).

\Box

Using the fourth order equation, we get estimates for the laplacian.

Proposition 3.2

For
u_{\varepsilon},f_{\varepsilon},u_{0,\varepsilon},v_{\varepsilon}=u_{\varepsilon}-u_{0,\varepsilon},{\ell^{\pm}_{\varepsilon}}

as in (
1.3
), (
2.1
), (
2.4
),
(
3.1
),
we have

-{\ell^{-}_{\varepsilon}}_{,-}-\varepsilon^{2}\parallel f_{\varepsilon}\parallel_{L^{\infty}(\Omega)}\leq\varepsilon^{2}\Delta u_{\varepsilon}\leq{\ell^{+}_{\varepsilon}}_{,+}\quad\mbox{in }\Omega.

(
3.7
)

Proof:

We have with (
1.3
) that

\varepsilon^{2}\Delta^{2}u_{\varepsilon}-\Delta u_{\varepsilon}=f_{\varepsilon}\quad\mbox{in }\Omega

and get

\varepsilon^{2}\Delta(\Delta u_{\varepsilon})<0\quad\mbox{in }[\Delta u_{\varepsilon}<-\parallel f_{\varepsilon,+}\parallel_{L^{\infty}(\Omega)}-\varepsilon^{-2}{\ell^{-}_{\varepsilon}}_{,-}]=:\Omega_{0}.

Since
\Delta u_{\varepsilon}\geq-\parallel f_{\varepsilon,+}\parallel_{L^{\infty}(\Omega)}-\varepsilon^{-2}{\ell^{-}_{\varepsilon}}_{,-}\mbox{ on }\partial\Omega_{0}
,
as
\Delta u_{\varepsilon}\geq\varepsilon^{-2}{\ell^{-}_{\varepsilon}}\geq-\varepsilon^{-2}{\ell^{-}_{\varepsilon}}_{,-}\mbox{ on }\partial\Omega
with (
3.1
),
we get from the mean-value estimate for superharmonic functions
or by Alexandroff’s maximum principle, as
\Delta u_{\varepsilon}\in W^{2,n}(\Omega)
,
see
[
GT
]
Theorem 9.1,
that
\Delta u_{\varepsilon}\geq-\parallel f_{\varepsilon,+}\parallel_{L^{\infty}(\Omega)}-\varepsilon^{-2}{\ell^{-}_{\varepsilon}}_{,-}\mbox{ in }\Omega_{0}
,
hence
\Omega_{0}=\emptyset
,
and the left estimate in (
3.7
) follows.
The right estimate is obtained by symmetry observing that
f_{\varepsilon}\geq 0
.

\Box

Here we can give a preliminary asymptotic estimate for
{M_{\varepsilon}}
.
Actually we will improve this asymptotic later
in Proposition
4.2
and (
4.19
).
Anyway we present this estimate at this stage
to get more compact bounds already now.

Proposition 3.3

For
u_{\varepsilon},{M_{\varepsilon}},{\ell^{\pm}_{\varepsilon}}

as in (
1.3
), (
2.1
),
(
3.1
), (
3.3
),
we have

\varepsilon^{-2}{M_{\varepsilon}}\geq\varepsilon^{-2}{\ell^{+}_{\varepsilon}}_{,+}\rightarrow\infty.

in particular
{M_{\varepsilon}}\geq{\ell^{+}_{\varepsilon}}={\ell^{+}_{\varepsilon}}_{,+}>0\mbox{ for }\varepsilon

\Omega\mbox{ and }\tau
.

Proof:

Combining Proposition
3.2

3.7
) and Proposition
2.3
,
we get for any
\Omega^{\prime}\subset\subset\Omega
that

{{\cal L}^{n}}(\Omega\setminus\Omega^{\prime})\liminf\limits_{\varepsilon\rightarrow 0}\varepsilon^{-2}{\ell^{+}_{\varepsilon}}_{,+}\geq\liminf\limits_{\varepsilon\rightarrow 0}\int\limits_{\Omega\setminus\Omega^{\prime}}(\Delta u_{\varepsilon})_{+}{\ {\rm d}}{{\cal L}^{n}}\geq\tau>0,

hence, as

Appendix A
Uniqueness of a bi-laplace equation on the half space

In this section we show the following uniqueness theorem.

Theorem A.1

Let
v:\overline{{\mathbb{R}}^{n}_{+}}\rightarrow{\mathbb{R}}
be a smooth solution to

\left\{\begin{array}[]{c}\Delta^{2}v-\Delta v=0\mbox{ on }{\mathbb{R}}^{n}_{+},\\
v=\partial_{n}v=0\mbox{ on }{\mathbb{R}}^{n-1}\times\{0\},\\
v\in L^{\infty}({\mathbb{R}}^{n}_{+}).\end{array}\right.

Then
v=0
.

The proof is based on an energy type estimate and on the one-dimensional case.
We start with the one dimensional case and show the following lemma:

Lemma A.1

Let
v\in C^{4}_{loc}([0,\infty[)
satisfy

\displaystyle\frac{d^{4}v}{dt^{4}}-\frac{d^{2}v}{dt^{2}}=0

\displaystyle\mbox{ on }]0,\infty[,

\displaystyle v(0)=\frac{dv}{dt}(0)=0,

\displaystyle v\in L^{\infty}(]0,\infty[).

Then
v=0
.

Proof:

Since the differential equation is ordinary and linear, the solution space of the equation itself is of dimension
4
. By inserting the following functions, we see that they constitute a basis of the solution space

t\mapsto\cosh(t),\ \sinh(t),\ 1,\ t.

The following functions are therefore a basis of the solution space including the initial conditions at
t=0
:

v_{1}(t)=\cosh(t)-1,\ v_{2}(t)=\sinh(t)-t.

Hence
v
has to be of the form

v(t)=Av_{1}(t)+Bv_{2}(t)=A(\cosh(t)-1)+B(\sinh(t)-t).

Inserting the exponential function for
\cosh
and
\sinh
yields

\displaystyle v(t)=

\displaystyle A\left(\frac{e^{t}+e^{-t}}{2}-1\right)+B\left(\frac{e^{t}-e^{-t}}{2}-t\right)

\displaystyle=

\displaystyle\frac{1}{2}(A+B)e^{t}+\frac{1}{2}(A-B)e^{-t}-A-Bt.

Since the solution is bounded, we have
A=-B
. Again the boundedness then yields
B=0
, to rule out linear growth. Hence
v=0
.

\Box

For our next step we introduce a bit of notation for half spaces

B_{R}^{+}:=B_{R}(0)\cap{\mathbb{R}}^{n}_{+}\subseteq{\mathbb{R}}^{n},\ R>0.

Next we show an energy type estimate.

Lemma A.2

Let
v
satisfy

\left\{\begin{array}[]{c}\Delta^{2}v-\Delta v=0\mbox{ on }{\mathbb{R}}^{n}_{+},\\
v=\partial_{n}v=0\mbox{ on }{\mathbb{R}}^{n-1}\times\{0\}.\end{array}\right.

Then there exists a constant
C=C(n)>0
, such that for all
R>1
we have

\int_{B_{R}^{+}}\left(|\Delta v|^{2}+|\nabla v|^{2}\right)\,d{{\cal L}^{n}}\leq\frac{C}{R^{2}}\int_{B_{2R}^{+}}\left(|\nabla v|^{2}+v^{2}\right)\,d{{\cal L}^{n}}.

Proof:

Let
\eta\in C^{\infty}_{0}(B_{2R}(0))
with
0\leq\eta\leq 1
,
\eta=1
on
B_{R}(0)
and for any
k\geq 1

|D^{k}\eta|\leq\frac{C_{k}}{R^{k}}\chi_{B_{2R}(0)\setminus B_{R}(0)},

(
A.1
)

i.e.
\eta
is a cutoff function for the ball
B_{R}(0)
. Then
v\eta^{4}
and its first derivative are zero on
\partial B_{2R}^{+}
. Therefore partial integration and the differential equation itself yield

\displaystyle 0=

\displaystyle\int_{B_{2R}^{+}}v\eta^{4}(\Delta v-\Delta^{2}v)\,d{{\cal L}^{n}}=-\int_{B_{2R}^{+}}\Delta(v\eta^{4})\Delta v\,d{{\cal L}^{n}}-\int_{B_{2R}^{+}}\nabla(v\eta^{4})\nabla v\,d{{\cal L}^{n}}

\displaystyle=

\displaystyle-\int_{B_{2R}^{+}}\left(|\Delta v|^{2}\eta^{4}+|\nabla v|^{2}\eta^{4}\right)\,d{{\cal L}^{n}}

\displaystyle-\int_{B_{2R}^{+}}2\left(\nabla v\nabla(\eta^{4})\Delta v+v\Delta(\eta^{4})\Delta v+v\nabla v\nabla(\eta^{4})\right)\,d{{\cal L}^{n}}

\displaystyle=

\displaystyle-\int_{B_{2R}^{+}}\left(|\Delta v|^{2}\eta^{4}+|\nabla v|^{2}\eta^{4}\right)\,d{{\cal L}^{n}}

\displaystyle-\int_{B_{2R}^{+}}\big(8\nabla v\nabla\eta\eta^{3}\Delta v+4v\Delta v\Delta\eta\eta^{3}+12v\Delta v|\nabla\eta|^{2}\eta^{2}+4v\nabla v\nabla\eta\eta^{3}\big)\,d{{\cal L}^{n}}.

By the previous identity and Young’s inequality with an
\varepsilon>0
we get

\displaystyle\int_{B_{2R}^{+}}

\displaystyle\left(|\Delta v|^{2}\eta^{4}+|\nabla v|^{2}\eta^{4}\right)\,d{{\cal L}^{n}}

\displaystyle\leq\int_{B_{2R}^{+}}

\displaystyle\big(\varepsilon|\Delta v|^{2}\eta^{4}+C_{\varepsilon}|\nabla v|^{2}|\nabla\eta|^{2}\eta^{2}

\displaystyle+\varepsilon|\Delta v|^{2}\eta^{4}+C_{\varepsilon}v^{2}|\Delta\eta|^{2}\eta^{2}

\displaystyle+\varepsilon|\Delta v|^{2}\eta^{4}+C_{\varepsilon}v^{2}|\nabla\eta|^{4}

\displaystyle+\varepsilon|\nabla v|^{2}\eta^{4}+C_{\varepsilon}v^{2}|\nabla\eta|^{2}\eta^{2}\big)\,d{{\cal L}^{n}}.

Now choosing
\varepsilon
small enough, we can absorb the terms with
\varepsilon
as a prefactor into the left hand side

\frac{1}{2}\int_{B_{2R}^{+}}\left(|\Delta v|^{2}\eta^{4}+|\nabla v|^{2}\eta^{4}\right)\,d{{\cal L}^{n}}

\leq C\int_{B_{2R}^{+}}\left(|\nabla v|^{2}|\nabla\eta|^{2}\eta^{2}+v^{2}|\Delta\eta|^{2}\eta^{2}+v^{2}|\nabla\eta|^{4}+v^{2}|\nabla\eta|^{2}\eta^{2}\right)\,d{{\cal L}^{n}}.

Together with
0\leq\eta\leq 1
the estimates on the derivatives of the cutoff function (
A.1
) yield

\int_{B_{R}^{+}}\left(|\Delta v|^{2}+|\nabla v|^{2}\right)\,d{{\cal L}^{n}}\leq C\int_{B_{2R}^{+}}\left(|\nabla v|^{2}\frac{1}{R^{2}}+v^{2}\frac{1}{R^{4}}+v^{2}\frac{1}{R^{4}}+v^{2}\frac{1}{R^{2}}\right)\,d{{\cal L}^{n}}.

Since we have choosen
R>1
, we obtain

\int_{B_{R}^{+}}\left(|\Delta v|^{2}+|\nabla v|^{2}\right)\,d{{\cal L}^{n}}\leq\frac{C}{R^{2}}\int_{B_{2R}^{+}}\left(|\nabla v|^{2}+v^{2}\right)\,d{{\cal L}^{n}}.

\Box

Now we can show our main result Theorem
A.1
, by iterating Lemma
A.2
:

Proof of Theorem
A.1
:

Since
v
is bounded and the differential equation is linear and elliptic, we can employ Schauder-type estimates (see
[
ADN59
, Thm. 6.2]
and
[
DN55
, Sec. 4]
) to obtain

\|v\|_{C^{k}(\overline{{\mathbb{R}}^{n}_{+}})}\leq C_{k}\|v\|_{L^{\infty}(\overline{{\mathbb{R}}^{n}_{+}})}<\infty.

(
A.2
)

Let
x=(y,t)\in\overline{{\mathbb{R}}^{n}_{+}}
, such that
y\in{\mathbb{R}}^{n-1}
and
t\geq 0
. By
\partial_{y}^{k}v
we denote any partial derivative of
v
of order
k
only after horizontal directions, i.e. indices in
\{1,\ldots,n-1\}
. Then for every
k\in{\mathbb{N}}
the function
\partial^{k}_{y}v:\overline{{\mathbb{R}}^{n}_{+}}\rightarrow{\mathbb{R}}
still solves the differential equation, satisfies the Dirichlet boundary conditions and by (
A.2
) is again bounded. Now we can iteratively apply Lemma
A.2
for
k\geq\ell\in{\mathbb{N}}
and obtain

\int_{B_{R}^{+}}|\partial^{k}_{y}v|^{2}\,d{{\cal L}^{n}}\leq\int_{B_{R}^{+}}|\nabla\partial^{k-1}_{y}v|^{2}\,d{{\cal L}^{n}}

\leq\frac{C}{R^{2}}\int_{B_{2R}^{+}}\left(|\nabla\partial^{k-1}_{y}v|^{2}+|\partial^{k-1}_{y}v|^{2}\right)\,d{{\cal L}^{n}}

\leq\frac{C}{R^{2}}\int_{B_{2R}^{+}}\left(|\nabla\partial^{k-1}_{y}v|^{2}+|\nabla\partial^{k-2}_{y}v|^{2}\right)\,d{{\cal L}^{n}}

\leq\frac{C}{R^{4}}\int_{B_{4R}^{+}}\left(|\nabla\partial_{y}^{k-1}v|^{2}+|\partial_{y}^{k-1}v|^{2}+|\nabla\partial_{y}^{k-2}v|^{2}+|\partial_{y}^{k-2}v|^{2}\right)\,d{{\cal L}^{n}}

\leq\ldots\leq\frac{C_{\ell,k}}{R^{2\ell}}\sum_{j=1}^{\ell}\int_{B_{2^{\ell}R}^{+}}\left(|\nabla\partial_{y}^{k-j}v|^{2}+|\partial_{y}^{k-j}v|^{2}\right)\,d{{\cal L}^{n}}.

By choosing
k=\ell
, (
A.2
) yields

\int_{B_{R}^{+}}|\partial^{k}_{y}v|^{2}\,d{{\cal L}^{n}}\leq\frac{C_{k}}{R^{2k}}{{\cal L}^{n}}\left(B_{2^{k}R}^{+}\right)\leq C_{k}R^{n-2k}.

If
k>2n
, this yields for
R\rightarrow\infty
:

\int_{{\mathbb{R}}^{n}_{+}}|\partial^{k}_{y}v|^{2}\,d{{\cal L}^{n}}=0.

Hence
\partial^{k}_{y}v=0
. This implies

\partial_{y_{i}}\partial^{k-1}_{y}v=0,\mbox{ for }i=1,\ldots,i-1.

Therefore
\partial^{k-1}_{y}v(y,t)
is independent of
y\in{\mathbb{R}}^{n-1}
and
t\mapsto\partial^{k-1}_{y}v(y,t)
satisfies the assumptions of Lemma
A.1
. Hence we also have

\partial^{k-1}_{y}v=0.

Especially we have

\partial_{y_{i}}\partial^{k-2}_{y}v=0.

for all
i=1,\ldots,n-1
.
Hence again
\partial^{k-2}_{y}v(y,t)
is independent of
y
and therefore again satisfies the assumptions of Lemma
A.1
.
Iterating this final process yields

v=0,

which is the desired conclusion.

\Box

Remark:

The proof above works, because both
\Delta^{2}
and
-\Delta
are monotone operators which are added correctly. If we would destroy this monotonicity by e.g. examining
\Delta^{2}+\Delta
, Theorem
A.1
is not true anymore. For example a bounded nontrivial solution to

\Delta^{2}v+\Delta v=0
,
is
(y,t)\mapsto 1-\cos t
.

\Box

Proposition A.3

Let
u:\overline{{\mathbb{R}}^{n}_{+}}\rightarrow{\mathbb{R}}

be a smooth solution of the fourth order boundary-value problem

\begin{array}[]{c}\Delta^{2}u-\Delta u=0\quad\mbox{in }{\mathbb{R}}^{n}_{+},\\
u,\partial_{n}u=0\quad\mbox{on }{\mathbb{R}}^{n-1}\times\{0\}.\\
\end{array}

(
A.3
)

Furthermore let
u
for some
\beta\in{\mathbb{R}}
and the corresponding
linear function
u_{0}:(y,t)\mapsto\beta t
satisfy

u-u_{0}\in L^{\infty}({\mathbb{R}}^{n}_{+}).

Then
u
is one dimensional, that is

u(y,t)=\beta(e^{-t}-1+t)\quad\mbox{for }y\in{\mathbb{R}}^{n-1},t\geq 0,

(
A.4
)

in particular

\Delta u\equiv\beta\quad\mbox{in }{\mathbb{R}}^{n-1}\times\{0\}

(
A.5
)

and

u>0\quad\mbox{in }{\mathbb{R}}^{n}_{+},\quad\mbox{if }\beta>0.

(
A.6
)

Proof:

We put

v(y,t):=u(y,t)-\beta(e^{-t}-1+t)\quad\mbox{for }y\in{\mathbb{R}}^{n-1},t\geq 0,

and see
v\in C^{\infty}_{loc}(\overline{{\mathbb{R}}^{n}_{+}})
and

\begin{array}[]{c}\Delta^{2}v-\Delta v=0\quad\mbox{in }{\mathbb{R}}^{n}_{+},\\
v,\partial_{n}v=0\quad\mbox{on }{\mathbb{R}}^{n-1}\times\{0\},\\
v=u-u_{0}-\beta(\exp(-.)-1)\in L^{\infty}({\mathbb{R}}^{n}_{+}).\\
\end{array}

Then the uniqueness in Proposition
A.1
gives
v\equiv 0
,
which is (
A.4
),
and by direct calculation

\Delta u(y,0)=\partial_{tt}(\beta(e^{-t}-1+t))|_{t=0}=\beta\quad\mbox{for }y\in{\mathbb{R}}^{n-1},

which is (
A.5
).
For
\beta>0
, we get by the strict convexity of the exponential function

u(y,t)=\beta(e^{-t}-1+t)>0\quad\mbox{for }y\in{\mathbb{R}}^{n-1},t>0,

which is (
A.6
).

\Box
