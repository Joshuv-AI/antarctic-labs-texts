Coding Reliability with Aclus – Did I correctly characterize my observations?
Marcus Weber, Oğuzhan Yürük

Abstract
Describing observations or objects in non-mathematical disciplines can often be accomplished by answering a list of questions. These questions can be formulated in such a way that the only possible answers always are “yes” or “no”. This article is about automatically checking such given binary data sets for inconsistencies and about finding possible logical rules valid for the analyzed objects.

1
Introduction

This article presents a method (Algebraic clustering,
Aclus
) to check for possible inconsistencies in a given binary data table. A binary data table represents an incidence relation between a set of observations and a list of characteristics. Such data structures are used by many disciplines to store various information such as the data collected in a social studies survey, or the data collected in a controlled experiment. There are several ways of cross-checking the correctness of coded observations
[
17
]
: Colleagues can be consulted to check the assignments (intercoder reliability, intercoder consistency). The coder can also carry out the coding again at a later point in time and examine deviations (intracoder reliability). In this article, we propose a new approach, namely to check whether certain classifications “destroy” simple rules about the observed objects.

The data stored in a binary table can be represented as a set of polynomials in a Boolean polynomial ring. Boolean rings and algebras are classically studied by George Boole in mid 1800s
[
5
]
, but they are quite fundamental objects in various research areas outside mathematics such as computer science
[
20
,
6
]
, biology
[
22
]
, or data analysis
[
9
,
1
,
3
]
. Due to their practicality in various applications, the Boolean polynomial rings and their algebraic aspects are intensively studied in mathematics.

The method
Aclus
which we introduce in this article relies on a well-established theory in the field of computational algebra, called the theory of Gröbner bases. Computing a Gröbner basis is usually not an easy task for a general input, but there are highly efficient computation methods for Boolean polynomials. A Gröbner basis of a Boolean ideal can be computed efficiently by using zero suppressed binary decision diagrams (ZDDs) which exploit the extra structure of Boolean polynomial rings and can handle a few hundred variables
[
7
]
. Throughout this work, we use the Gröbner basis implementation available in the computer algebra system OSCAR
[
18
]
, which is based on the software
Singular

[
12
]
. For even larger scale problems, one possibility is to get help from modern SAT solving techniques
[
4
]
. The performance of modern SAT-solvers are constantly thanks to the International SAT Competition organized annually, see
[
2
]
. However, the scale of our computations in this work are relatively small, and we will not need such heavy tools.

Aclus
is based on an existing theory in mathematics, however, this article adds novel concepts to data analysis in two different ways:

•

The presented framework allows for representing “objects” as well as “properties” in the same space, namely by Boolean polynomials. This is in the spirit of the “Mathematics of Comparing Objects”
[
23
]
. Objects are represented by polynomials which combine properties. To extract the properties from the polynomials, one has to compare objects (i.e., adding and multiplying the according polynomials) which again leads to new polynomials.

•

From a statistical point of view (like in machine learning) “rules” about properties of objects become visible by finding repeating patterns or significant regularities in data. In this article we think of “logical rules”. From this point of view, a “rule” becomes visible by objects (or observations) that do
not
exist, i.e. by the “holes” in our binary data tables expressed by an ideal
\cal I
.

1.2
Mathematical Problem

Given a binary data table whose entries are not random, but contain (hidden) logical rules which have led to the special combination of assigned and not-assigned characteristics of the observations. How can I check whether this table includes assignment errors contradicting the unknown rules?

When analyzing a binary data table, checking how often a certain pattern occurs is a crucial step. Consider the pattern given in the line No. 5, which is “001101”. If the same pattern occurs in many other lines in the data table, then it would make sense to trust this particular entry since it is not an exception in the data. However, this is not the criterion of correctness in this article. In fact,
Aclus
will first collect the set of all pairwise different patterns in the table and then only work on these different patterns. From this point of view, two observations are not distinguishable if they share the same pattern. In Table
1
every pattern only occurs once. Thus, the step of clustering lines sharing the same pattern is obsolete in this special example. If a logical rule concerning the properties of the given objects applies, then the negation of this rule provides a not satisfiable statement. For example, take the logical rule: If it rains, then the soil becomes wet. Its negation – it rains and the soil stays dry – provides a situation that will not be observed. The set of all patterns which can not be found among our observations is therefore the basis for finding logical rules about our reported object properties. In order to formulate this approach algebraically, we represent these logic and set operations in Boolean rings.

A ring with unity
1\in\textbf{B}
is called a
Boolean ring
if every element
a\in\textbf{B}
is idempotent, i.e.,
a^{2}=a
. It follows from the the idempotency assumption that any Boolean ring
B
has characteristic 2, i.e.
a+a=0
for any
a\in\textbf{B}
. Moreover, for any
a,b\in\textbf{B}
we have
a+b=(a+b)^{2}=a+a\cdot b+b\cdot a+b
, and since
\characteristic(\textbf{B})=2
it follows that
B
is commutative.

Operations in Boolean rings can be seen as logical statements. Given any Boolean ring
(\textbf{B},+,\cdot)
, one can define new set of Boolean operations
\lor,\land,\lnot
(i.e., “or”, “and”, “not”) where

\displaystyle a\lor b=a+b+a\cdot b,\quad a\land b=a\cdot b\quad\text{and}\quad\lnot a=a+1,

for
a,b\in\textbf{B}
. The set
B
together with these 3 new Boolean operations defines a Boolean algebra. Conversely, if
(\textbf{B},\lor,\land,\lnot)
is a Boolean algebra then we can recover the ring addition
a+b=\left(\lnot a\land b\right)\lor\left(a\land\lnot b\right)
and multiplication
a\cdot b=a\land b
for any
a,b\in\textbf{B}
.

The operations of Boolean algebras are also understandable as operations on sets. Given an arbitrary set
S
, its power set
\mathcal{P}(S)
has a natural Boolean algebra structure.
If two subsets
A,B\in\mathcal{P}(S)
, then their union and intersection correspond to binary Boolean operations
\lor
and
\land
, respectively, and the complement
A^{c}:=S\setminus A
is the unary operation
(1+A)
associated to the Boolean algebra
\mathcal{P}(S)
. The set
S
does not necessarily have to be finite, but in the scope of our application this set will always be finite.
The empty set and
S
are distinguished elements of the Boolean algebra
\mathcal{P}(S)
, because they are the identity of the intersection and the union operations. The ring operations induced by the Boolean algebra structure is then as follows:

P+Q=(P\cap Q^{c})\cup(P^{c}\cap Q)\text{ and }P\cdot Q=P\cap Q.

For more details about the Boolean rings and algebras, we refer the reader to
[
13
]
.

Example 1.2
.

The algebraic approach presented in this article works out for each row of a binary table in which way this row is “special”. It creates an algebraic expression, which names the special feature of the corresponding pattern. To anticipate the presented method and the evaluations: In our example in line No. 4 it provides
cg+c+g+1
, which is equivalent to
\lnot(c\vee g)
. From the algebraic expression one can read which additional rule about the relationships between the columns would hold, if the corresponding pattern would be deleted from the table. In our example this rule would be
cg+c+g+1=0
, which is equivalent to
cg+c+g=1
, to
\lnot{c}\Rightarrow g
, or to
\lnot{g}\Rightarrow c
.

This Boolean algebraic approach will further turn into an algebraic clustering method which provides a way to not only find single, conspicuous rows in the table, but also how to combine some rows to get a conspicuous cluster of observations together with its peculiarity. In our guiding example, a combination of line No. 3 and line No. 6 forms one cluster. In every other row, “very cold (
v
)” and “well-growing (
g
)” do not appear together. Without these entries:
v\Rightarrow\lnot{g}
, equivalently
g\Rightarrow\lnot{v}
.

2
The Algebraic Framework

In this section we present the algebraic framework behind our method
Aclus
.

Let
B
be a Boolean ring, and
\textbf{B}[\boldsymbol{X}]:=\textbf{B}[X_{1},\dots,X_{n}]
denote the ring of polynomials over
B
. Every polynomial in
\textbf{B}[\boldsymbol{X}]
is a finite sum of monomials, and a
monomial
in
\textbf{B}[\boldsymbol{X}]
is an expression of the form

f_{i}X_{1}^{\alpha_{1}}\dots X_{n}^{\alpha_{n}},

where
f_{i}\in\textbf{B}
and
\boldsymbol{\alpha}=(\alpha_{1},\dots,\alpha_{n})\in\mathbb{Z}_{\geq 0}^{n}
are called as the coefficient and the exponent of this particular monomial.
\textbf{B}[\boldsymbol{X}]
is not a Boolean ring, as the polynomial variable
X_{i}
’s are not necessarily idempotent. However, if the idempotency is enforced on the variables by considering the quotient ring

\textbf{B}(\boldsymbol{X})={{}^{\textstyle\textbf{B}[\boldsymbol{X}]}\big/_{\textstyle\left\langle X_{1}^{2}-X_{1},\dots,X_{n}^{2}-X_{n}\right\rangle}},

then the resulting quotient is a Boolean ring, and consequently every finitely generated ideal in
\textbf{B}(\boldsymbol{X})
is principal. An element from the quotient
\textbf{B}(\boldsymbol{X})
is called a Boolean polynomial, and it has an unique representative in
B[X_{1},\dots,X_{n}]
with degree at most 1 in each variable
X_{i}
.

Let
\mathcal{O}
be a set of observations,
\mathcal{P}
be a set of characteristics associated to the elements in
\mathcal{O}
. Each observation in
\mathcal{O}
either posses or lacks each characteristic in
\mathcal{P}
, and the incidence information between the observations and the characteristics can be represented in terms of a Boolean data table as in
Definition

1.1
. Each characteristic in
\mathcal{P}
is assigned a Boolean function (variable)
X_{i}
from
\mathcal{O}
to
\textbf{B}=\{0,1\}
. For a given observation
o\in\mathcal{O}
, the Boolean function
X_{i}
is evaluated to 1 if and only if the observation
o
admits the characteristic represented by
X_{i}
.

Algebraically, the Boolean polynomial ring
\textbf{B}(X_{1},\dots,X_{n})
contains every Boolean polynomial that can be written using the variables
X_{1},\dots,X_{n}
. In terms of the Boolean data,
\textbf{B}(X_{1},\dots,X_{n})
represents all possible descriptions that can be given using the characteristics represented by
X_{1},\dots,X_{n}
. For example,
X_{i}\cdot X_{j}
is a description which holds for any observation that admits both of the characteristics
X_{i}
and
X_{j}
, and similarly,
X_{i}+X_{j}
describes those observations that admit the characteristics
X_{i}
or
X_{j}
but not both.

Given a Boolean polynomial
f(\boldsymbol{X})\in\textbf{B}(\boldsymbol{X})
and a vector
\boldsymbol{b_{o}}\in\textbf{B}^{n}
, one can
evaluate
the polynomial
f
at
\boldsymbol{b_{o}}
. Note that fixing a vector
\boldsymbol{b_{o}}\in\textbf{B}^{n}
corresponds to considering a particular observation in
\mathcal{O}
. In algebraic terms, this corresponds to substituting each variable
X_{i}
with the
i
-th entry of
\boldsymbol{b_{o}}
, and then computing the resulting Boolean algebraic expression.

Example 2.1
.

Consider the Table
1
again. Every row of this table can be mapped to a Boolean polynomial. Line No. 5 turns into
(w+1)(a+1)nc(v+1)(g+1)
. If we insert logical values “0” and “1” into this expression (in terms of Boolean ring elements), then
(w+1)(a+1)nc(v+1)(g+1)=1
only for line No. 5. This algebraic expression is like a “select statement” for this special row.

There are expressions in
\textbf{B}(\boldsymbol{X})
which are evaluated to “0” for all row patterns of Table
1
, e.g.,
wan(c+1)vg=0
for all lines in
Table

1
. If we have such an expression that is always evaluated to zero for all rows in the table, then every multiple of this expression (multiplication with Boolean polynomials) is also always zero. Similarly, this accounts for sums of such expressions, too. In fact, this defines an ideal
\cal I
of
\textbf{B}(\boldsymbol{X})
, which we will refer as the
Aclus ideal
associated to the given Boolean data table. In general, the Aclus ideal
\cal I
includes all select-statements which would provide an empty set when applied to the data of the binary table.

Example 2.2
.

The Boolean polynomial

is element of the Aclus ideal
\cal I
in case of Table

cv+v=0
is equivalent to
v=cv
. The logical rule is: If it is very cold, then it is cold and very cold. The expression
(g+1)w(c+1)
is another element of this ideal, which means that whenever it is wet and not cold the copper beech grows, because
w(c+1)=1
implies
g+1=0
in order to cancel the algebraic expression. A generator of the Aclus ideal
\cal I
can be found by computing the union of all rows of Table

and then by taking the complement of this expression. If we only consider the distinct patterns of Table
1
, then computing the union is like taking the sum of all related polynomial expressions.

Given a Boolean polynomial ring
\textbf{B}(\boldsymbol{X})
and any ideal
{\cal I}
of
\textbf{B}(\boldsymbol{X})
, the set

V({\cal I}):=\left\{\boldsymbol{X}\in\textbf{B}^{n}\ \mid\ \forall f\in{\cal I},\ f(\boldsymbol{X})=0\right\}

is called the variety of
\cal I
. Recall that an ideal is a collection of polynomials from
\textbf{B}(\boldsymbol{X})
, and each of these polynomials represents a rule given in terms of the Boolean variables
X_{1},\dots,X_{n}
. Then,
V({\cal I})
is the set of objects in
\textbf{B}^{n}
that do not satisfy any rule represented by the polynomials in
\cal I
.

Various fundamental results from classical algebraic geometry, such as
Theorem

2.3
, can be carried over to the Boolean setting.

Theorem 2.3

(Boolean Nullstellensätze
[
19
]
)
.

Let
\cal I
be a finitely generated ideal in
\textbf{B}(\boldsymbol{X})
, then
V({\cal I})\neq\emptyset
if and only if
\cal I
contains a constant polynomial that is not equal to
0
. Moreover, given any
\cal I
with
V({\cal I})\neq\emptyset
and
f\in\textbf{B}(\boldsymbol{X})
, then

f\in{\cal I}\quad\Longleftrightarrow\quad f(\boldsymbol{\tilde{X}})=0\quad\text{for all}\quad\boldsymbol{\tilde{X}}\in V({\cal I}).

In terms of Boolean tables,
Theorem

2.3
can be summarized by the following two statements: First, any rule generated from the polynomials in the ideal
\cal I
is not satisfied by any element of
V({\cal I})
. Second, if a rule is not satisfied by any element of
V({\cal I})
, then this rule exists as a polynomial in
\cal I
.

Given an ideal
{\cal I}
of the Boolean polynomial ring
\textbf{B}(\boldsymbol{X})
, a natural way to obtain a new polynomial ring is to consider the quotient ring
{{}^{\textstyle\textbf{B}(\boldsymbol{X})}\big/_{\textstyle\cal I}}
. This quotient ring is also a Boolean ring, and its elements are not Boolean polynomials, but equivalence classes of Boolean polynomials in
\textbf{B}(\boldsymbol{X})
. If we fix a suitable order on the monomials of
\textbf{B}(\boldsymbol{X})
, then there is a way to pick a unique representative Boolean polynomial from each equivalence class. Therefore, one can associate the ring
{{}^{\textstyle\textbf{B}(\boldsymbol{X})}\big/_{\textstyle\cal I}}
with a new set of representative polynomials, which obviously depend on the fixed monomial order and this dependence will be carefully discussed in
Section

2.1
. The elements of the ring
{{}^{\textstyle\textbf{B}(\boldsymbol{X})}\big/_{\textstyle\cal I}}
can be perceived as the reduced versions of the polynomials in
\textbf{B}(\boldsymbol{X})
such that each polynomial that lies in
\cal I
is set to be equal to zero. For general polynomial rings, computing these representatives may be a challenging task. However, for Boolean polynomial rings, the theory of Gröbner bases allows us to do this efficiently. In
Section

2.1
, we cover the basic notions about Boolean Gröbner basis which will be required to understand our approach.

2.1
Simplifying Rules via Boolean Gröbner Basis

Although in the ring of Boolean polynomials every finitely generated ideal is principal, there may be an alternative set of algebraic expressions which generate
\cal I
.
One possible way to find a basis for the ideal
\cal I
is to use the theory of Gröbner bases. Before we give a definition of Gröbner basis, we first have to introduce the notion of monomial orderings.

Recall that the set of monomials in
\textbf{B}({\boldsymbol{X}})
can be represented with the set
\mathbb{Z}^{n}_{\geq 0}
by considering the exponent vector of each monomial in
\textbf{B}({\boldsymbol{X}})
.

Definition 2.4
.

A monomial ordering on
\textbf{B}(\boldsymbol{X})
is a relation
>
on the set of exponent vectors
\mathbb{Z}^{n}_{\geq 0}
which is a total and well ordering such that for any
\boldsymbol{\alpha},\boldsymbol{\beta},\boldsymbol{\gamma}\in\mathbb{Z}^{n}_{\geq 0}
with
\boldsymbol{\alpha}>\boldsymbol{\beta}
, it holds that
\boldsymbol{\alpha}+\boldsymbol{\gamma}>\boldsymbol{\beta}+\boldsymbol{\gamma}
.

There are various ways to define a monomial order on
\textbf{B}({\boldsymbol{X}})
, and here we present two standard examples.

Definition 2.5

(Lexicographic order)
.

Given two exponent vectors

\boldsymbol{\alpha}=(\alpha_{1},\dots,\alpha_{n}),\boldsymbol{\beta}=(\beta_{1},\dots,\beta_{n})\in\mathbb{Z}^{n}_{\geq 0},

we write
\boldsymbol{\alpha}>_{\text{lex}}\boldsymbol{\beta}
, or equivalently
\boldsymbol{X}^{\boldsymbol{\alpha}}>_{\text{lex}}\boldsymbol{X}^{\boldsymbol{\beta}}
, if the leftmost nonzero entry of the vector
\boldsymbol{\alpha}-\boldsymbol{\beta}=(\alpha_{1}-\beta_{1},\dots,\alpha_{n}-\beta_{n})
is positive.

Example 2.6
.

Consider the monomials
X_{1}
,
X_{2}X_{3}
,
X_{2}X_{4}
and
X_{2}
in the polynomial ring
\textbf{B}(X_{1},X_{2},X_{3},X_{4})
, whose exponent vectors are
(1,0,0,0)
,
(0,1,1,0)
,
(0,1,0,1)
and
(0,1,0,0)
, respectively. First, consider the lexicographic monomial order on
\textbf{B}(X_{1},X_{2},X_{3},X_{4})
: The difference of the first two exponent vectors is

(1,0,0,0)-(0,1,1,0)=(1,-1,-1,0),

and therefore
X_{1}>_{\text{lex}}X_{2}X_{3}
. The differences of other exponent vectors similarly yield that
X_{1}>_{\text{lex}}X_{2}X_{3}>_{\text{lex}}X_{2}X_{4}>_{\text{lex}}X_{2}
. Furthermore, the lexicographic order on
\textbf{B}(X_{1},X_{2},X_{3},X_{4})
induces the following order on the variables:

X_{1}>_{\text{lex}}X_{2}>_{\text{lex}}X_{3}>_{\text{lex}}X_{4}.

(1)

The natural way to represent the exponent vector of a monomial is to write the exponent of
i
-th variable in the
i
-th entry of the vector. We make this assumption without exactly saying it in
Definition

2.4
, and this assumption induces the order of variables given in (
1
). By changing in which order we write the variables into a vector, one can obtain the other possible ways to order variables. In fact, the variables are not necessarily given with a natural order in our applications. In
Algorithm

1
, we propose a methodology to obtain an variable order which makes sense from a data perspective. Also, it is possible to equip the variables with a preferred order by using the weighted lexicographic order, which we define next.

Definition 2.7

(Weighted lexicographic order)
.

Let
\boldsymbol{w}=\left(w_{1},\dots,w_{n}\right)\in\mathbb{Z}^{n}
be a weight vector, and let
>_{\text{lex}}
denote the lexicographic order on
\mathbb{Z}^{n}_{\geq 0}
. Then, the weighted lexicographic order given by
\boldsymbol{w}
, which is denoted by
>_{\boldsymbol{w}}
, is defined as follows: for
\boldsymbol{\alpha}=\left(\alpha_{1},\dots,\alpha_{n}\right),\boldsymbol{\beta}=\left(\beta_{1},\dots,\beta_{n}\right)\in\mathbb{Z}^{n}_{\geq 0}
, we write
\boldsymbol{X}^{\alpha}>_{\boldsymbol{w}}\boldsymbol{X}^{\boldsymbol{\beta}}
if and only if

\sum w_{i}\alpha_{i}>\sum w_{i}\beta_{i}\qquad\text{or}\qquad\sum w_{i}\alpha_{i}=\sum w_{i}\beta_{i}\ \ \text{and}\ \ \boldsymbol{X}^{\alpha}>_{\text{lex}}\boldsymbol{X}^{\boldsymbol{\beta}}.

Example 2.8
.

Consider the Boolean ring
\textbf{B}(X_{1},X_{2},X_{3},X_{4})
, the weight vector
\boldsymbol{w}=(4,3,2,1)
, and let
>_{\boldsymbol{w}}
denote the weighted lexicographic order given by the weight vector
\boldsymbol{w}
. The monomial order
>_{\boldsymbol{w}}
induces the following order on the polynomial variables:

X_{1}>_{\boldsymbol{w}}X_{2}>_{\boldsymbol{w}}X_{3}>_{\boldsymbol{w}}X_{4},

which is the same variable order induced by
>_{\text{lex}}
in
Example

2.6
. Although the order of the polynomial variables is the same, the monomial order
>_{\boldsymbol{w}}
is not the lexicographic order. For example, the four monomials given in

2.6

:

X_{2}X_{3}>_{\boldsymbol{w}}X_{1}>_{\boldsymbol{w}}X_{2}X_{4}>_{\boldsymbol{w}}X_{4}.

Remark 2.9
.

By changing the weight vector
\boldsymbol{w}

and

\boldsymbol{w^{\prime}}=(1,2,3,4)
. The induced variable order in this case is

X_{4}>_{\boldsymbol{w^{\prime}}}X_{3}>_{\boldsymbol{w^{\prime}}}X_{2}>_{\boldsymbol{w^{\prime}}}X_{1},

Let
f\in\textbf{B}({\boldsymbol{X}})
be a nonzero polynomial,
f_{\boldsymbol{\alpha}}
denote the coefficient of the monomial
\boldsymbol{X}^{\boldsymbol{\alpha}}
in
f
for
\boldsymbol{\alpha}\in\mathbb{Z}^{n}_{\geq 0}
, and

A_{f}:=\left\{\boldsymbol{\alpha}\in\mathbb{Z}^{n}_{\geq 0}\ \mid\ f_{\boldsymbol{\alpha}}\neq 0\right\}

denote
the support of f
.
If
>
is a monomial order on
\textbf{B}({\boldsymbol{X}})
, then
the multidegree of f
is

\deg(f):=\underset{\boldsymbol{\alpha}\in A_{f}}{\arg\max}\left\{\boldsymbol{X}^{\boldsymbol{\alpha}}\right\},

where the maximization is taken with respect to the monomial order
>
. Moreover,
the leading monomial of
f
is
\text{LM}(f):=\boldsymbol{X}^{\deg(f)}
, the
the leading coefficient of
f
is
\text{LC}(f):=f_{\deg(f)}
, and the
the leading term of
f
is
\text{LT}(f):=\text{LC}(f)\cdot\text{LM}(f)
.
If
G
is a finite set of polynomials in
\textbf{B}({\boldsymbol{X}})
, then
\text{LM}(G)
denotes the set containing the leading monomials of the polynomials in
G
.

Definition 2.10
.

Let
\cal I
be an ideal of the Boolean polynomial ring
\textbf{B}(\boldsymbol{X})
, a finite subset
G\subset\cal I
is called a
Boolean Gröbner basis
of
\cal I
if
\left\langle\text{LM}(G)\right\rangle=\left\langle\text{LM}(\cal I)\right\rangle
.

Recall that we represent each observation with a Boolean polynomial in
\textbf{B}(\boldsymbol{X})
. We utilize Gröbner basis of an ideal
\cal I
to simplify these polynomials, and hence simplify the rows encoded by the Boolean data that we started with.

Proposition 2.11

(
[
11
]
)
.

Let
\cal I
be an ideal of
\textbf{B}(\boldsymbol{X})
,
G=\{g_{1},\dots,g_{k}\}
be a Gröbner basis of
\cal I
, and

be polynomial in
\textbf{B}(\boldsymbol{X})
. Then there exists a unique
r\in\textbf{B}(\boldsymbol{X})
such that:

1.

f=g+r
for some
g\in\cal I
,

2.

Non of the polynomials
\text{LT}(g_{1}),\dots,\text{LT}(g_{k})
divide any term of
r
.

Definition 2.12
.

Given an ideal
\cal I
of
\textbf{B}(\boldsymbol{X})
, a Gröbner basis
G
of
\cal I
, and a polynomial
f\in\textbf{B}(\boldsymbol{X})
, then
the polynomial
r
given by the
Proposition

2.11
is called as the
normal form of
f
with respect to the Gröbner basis
G
. Note that
G
, and consequently the normal form
r
, depend on the choice of monomial ordering on
\textbf{B}(\boldsymbol{X})
.

One can think of the normal form
r
as a reduction of the original polynomial
f
obtained by setting each polynomial in the ideal
\cal I
equal to zero. In order to compute the
r
, one needs to perform a series of polynomial divisions with remainder; first divide
f
by
g_{1}
to obtain the remainder
r_{1}
, and then at each next step divide the remainder
r_{i-1}
by
g_{i}
successively.

Remark 2.13
.

If the set
G=\{g_{1},\dots,g_{k}\}
is not a Gröbner basis of the ideal
\cal I
, then the result of taking successive remainders depend on the order of polynomials in
G
. However, if
G
is a Gröbner basis of the ideal that it generates, then the result do not depend on
g_{i}
’s order.

Now, we algorithmically describe the process we apply in order to obtain a reduction scheme from a given Boolean data table. We start with a Boolean data table given as in
Definition

1.1
, and we associate the Boolean variables
X_{1},\dots,X_{n}
to each of its columns from left to right, respectively. In order to compute normal forms we have to fix a monomial order as discussed in
Remark

2.13
. We exclusively use the weighted lexicographical order defined in
Definition

2.7
, where the weight of the variables are computed as in
Algorithm

1
. This algorithm computes the weights of each variable
X_{i}
by considering the relation between occurrences of
true
and
false
for this variable in the Boolean data table
M
. The weight is

w[i]=n_{true}\cdot n_{false}.

In our perspective,
X_{i}
is more likely to be a distinctive property either if it occurs in only some of the observations, or if it occurs in most of the observations. In this case the weight in Algorithm 1 would be small.

In terms of the algebraic reduction, variables
X_{i}
with higher weight are less likely to appear in the normal forms we compute than the variables with lower weights. In terms of the data, a high
w[i]
shows that nearly half of our observations admit the characteristic
X_{i}
, and indicates that the characteristic
X_{i}
is not biased towards a minority in the set of observations. Therefore, the variables that correspond to a less biased characteristics are less likely to appear in the reduced expression obtained by taking the normal form.

.

2.2
Finding Peculiarities

The problem which motivated this article is not finding logical rules by trusting the data set, but to find possible inconsistencies in the data set. Imagine there are “simple” (yet unknown) logical rules represented by the reported observations (of a large data set). We describe a process in
Algorithm

2
to find an alternative reduced formulation of the polynomials corresponding to the objects.

We note that the method given in
Algorithm

2
can be implemented in many modern computer algebra systems. We require two key functionalities from the computer algebra system, which are to compute a Gröbner basis and to compute the normal form with respect to a Gröbner basis.

4
Conclusion

Our method
Aclus
helped researchers from Egyptology to refine their coding scheme for classifying ancient statues. The proposed method extracts all possible logical rules about the properties of observed objects in terms of an ideal of Boolean Polynomials. The Gröbner Basis of this ideal depends on the monomial ordering. In this article, we decided for using monomial orderings based on the number of occurrences of characteristics. One particular order called the
elimination order
would be another good candidate which offers various functionalities, which we plan to discuss in a follow up work.

By using the rules given by the ideal, we can reduce the information, i.e., the polynomial which represents the characteristics of one object – included in one row of the binary data table – to a shorter algebraic expression. This expression provides the peculiarity of the corresponding object in terms of a new rule which would apply if that object would be deleted from the data table.

Only as a remark about the illustrative example of this article: Table
1
has been created to represent the properties of the copper beech according to the decision tree in
[
16
]
. However, it is obvious that this decision tree is not correct. The author based decisions on a difference between the German word “basisch” and the German word “alkalisch” which actually means the same (namely high pH). Thus, we can expect that corrections in Table
1
lead to more simple rules about copper beeches (like in “Rotbuchen”,
[
21
]
). Maybe one rule about copper beeches is even as simple as
\overline{c}\Rightarrow g
(“If it is not cold, then the copper beech grows well.”). In this case only line No. 4 would be a wrongly reported observation found by
Aclus
and would have to be deleted from the table in order to correct it.

Conceptual aspects.

Based on the algorithm
Aclus
, the consequences of removing and adding observations to an existing binary data set can be distinguished. There are the following situations:

1a

Adding an observation with a new pattern.
In this case, elements of
\cal I
are removed. There are now less possible logical rules about the relations between the properties of the objects (in terms of a subset relation).

1b

Adding an observation with a pattern that already exists.
In this case, the logical rules do not change, but the importance of certain properties can change their weighting. Therefore, the representation of rules and residues are possibly changing due to a possibly new Gröbner basis.

2a

Removing an observation with a unique pattern.
In this case, the removed pattern is added to
\cal I
. There are now more possible logical rules about the relations between the properties of the objects (superset relation).

2b

Removing an observation with a pattern that is repeated.
Same as 1b.
