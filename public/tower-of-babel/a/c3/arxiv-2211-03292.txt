Approximate Trace Reconstruction from a Single Trace
Xi Chen, Anindya De, Chin Ho Lee, Rocco A. Servedio, Sandip Sinha

Abstract
The well-known trace reconstruction problem is the problem of inferring an unknown source string x ∈ { 0 , 1 } n x\in\{0,1\}^{n} from independent “traces”, i.e. copies of x x that have been corrupted by a δ \delta -deletion channel which independently deletes each bit of x x with probability δ \delta and concatenates the surviving bits. The current paper considers the extreme data-limited regime in which only a single trace is provided to the reconstruction algorithm. In this setting exact reconstruction is of course impossible, and the question is to what accuracy the source string x x can be approximately reconstructed. We give a detailed study of this question, providing algorithms and lower bounds for the high, intermediate, and low deletion rate regimes in both the worst-case ( x x is arbitrary) and average-case ( x x is drawn uniformly from { 0 , 1 } n \{0,1\}^{n} ) models. In several cases the lower bounds we establish are matched by computationally efficient algorithms that we provide. We highlight our results for the high deletion rate regime: roughly speaking, they show that • Having access to a single trace is already quite useful for worst-case trace reconstruction: an efficient algorithm can perform much more accurate reconstruction, given one trace that is even only a few bits long, than it could given no traces at all. But in contrast, • in the average-case setting, having access to a single trace is provably not very useful: no algorithm, computationally efficient or otherwise, can achieve significantly higher accuracy given one trace that is o ⁡ ( n ) o(n) bits long than it could with no traces.

This work: Approximate reconstruction from a single trace.
We consider the problem of recovering an unknown
n
-bit source string
x
as accurately as possible given only
a single trace
from
\mathrm{Del}_{\delta}(x)
. Despite the simplicity and naturalness of this problem, it does not seem to have been considered in prior work.

We give a detailed study of this problem, analyzing both the worst-case setting of an arbitrary unknown source string
x
as well as the average-case setting of a uniform random
\boldsymbol{x}\sim\{0,1\}^{n}
. In each of these settings we consider both the low (
\delta=o_{n}(1)
), medium (
\delta=\Theta(1)
), and high (
\delta=1-o_{n}(1)
) deletion rate regimes.
In a number of cases we give upper bounds on the approximate reconstruction accuracy that any one-trace algorithm can achieve, which are essentially matched by corresponding one-trace algorithms that we provide. (All of the algorithms we give are computationally efficient.)
For some problem variants our upper bounds on the best achievable accuracy extend beyond one-trace algorithms to algorithms that receive multiple traces.

We view our results as a first investigation of one-trace reconstruction, and reiterate that very little was previously known for any of the problem variants that we consider. We describe the state of prior knowledge in the context of different specific problem variants when describe our results in

1.1.1
Worst-case one-trace reconstruction

We first consider the high deletion rate regime. It is convenient to let
\rho:=1-\delta
denote the
retention rate
, so in the high deletion rate regime we have
\rho=o(1)
.

If
\rho
is too small (as a function of
n
) then it is easy to see that no nontrivial performance is possible. In particular, if
\rho=o(1/n)
, then by Markov’s inequality with probability
1-o(1)
a trace
\boldsymbol{y}\sim\mathrm{Del}_{\delta}(x)
is zero bits long, and in this case a reconstrution algorithm cannot even distinguish between the two possibilities
x=0^{n}
and
x=1^{n}
. Consequently, if
\rho=o(1/n)
then the largest expected LCS achievable by a one-trace algorithm is at most
(1/2+o_{n}(1))n
(and
n/2
is trivially achieved by outputting any string with an equal number of 0’s and 1’s).

Our first positive result shows that — perhaps surprisingly — if
\rho
is only slightly larger, then it is already possible to do much better than the above trivial bound:

Theorem 1

(Worst-case algorithm, small retention rate, informal statement)
.

For any
\rho=\omega(\log(n)/n)
, there is a worst-case one-trace algorithm that achieves expected LCS at least
(2/3-o(1))n
.
Moreover, for any retention rate
\rho\geq\omega(1/n^{1/3})
, there is a worst-case one-trace algorithm that achieves expected LCS at least
(2/3+c\rho)n
, where
c>0
is an absolute constant.

The key to
Theorem

1
is a (to the best of our knowledge novel) notion of an
LCS-cover
, and a simple construction of an extremely small LCS-cover consisting of just two strings. This already suffices to give the first sentence of
Theorem

1
; the second sentence, improving the LCS bound to
(2/3+c\rho)
, is obtained via a win-win analysis which considers whether or not the single received trace has many “long runs”. Roughly speaking, if the trace has many long runs then this indicates that the source string
x
is highly structured in a way (containing many long segments that are almost all-0 or almost all-1) that makes it easy to achieve a large LCS, and if the trace has few long runs then the source string
x
must have many 01 alternations, which can be leveraged to get an LCS larger than
2n/3
.

Theorem

1
can be viewed as saying that having a
\log n
-bit trace already makes it possible to achieve an LCS of at least
(2/3-o(1))n.
Complementing
Theorem

1

n^{0.999}
-bit trace does not make it possible to achieve an LCS of
(2/3+c)n
for any
c>0

Theorem 2

(Worst-case upper bound on any algorithm, small retention rate, informal statement)
.

Fix any
\varepsilon>0

For retention rate
\rho=1/n^{\varepsilon}
, no one-trace algorithm can achieve expected LCS greater than
(2/3+o(1))n
in the worst-case setting.

See

Theorem

1.1.2
Average-case one-trace reconstruction

The average-case setting of one-trace reconstruction turns out to present some unexpected challenges due to connections with difficult unresolved problems in the combinatorics of words. To see this, let us first consider the problem of average-case trace reconstruction from
zero
traces; so the reconstruction algorithm receives no input at all, and simply aims to output the
n
-bit string
\widehat{x}
which maximizes the expected value of
|\mathsf{LCS}(\widehat{x},\boldsymbol{x})|
across uniform random
\boldsymbol{x}\sim\{0,1\}^{n}
. In contrast with the worst-case setting (where no zero-trace algorithm can achieve expected LCS better than 1/2 because the source string
x
could be chosen uniformly at random from
\{0^{n},1^{n}\}
), in the average-case setting the hypothesis string
\widehat{x}=(01)^{n/2}
already achieves
\operatorname{{\bf E}}[|\mathsf{LCS}(\widehat{x},\boldsymbol{x})|]\geq(3/4-o(1))n
: first greedily match the 0’s in
\widehat{x}
with the 0’s in
\boldsymbol{x}
from left to right, and then opportunistically augment these
\approx n/2
matching edges with edges matching pairs of 1’s where possible. So nontrivial performance is possible, even with zero traces, in the average-case setting.

Can we do better with a smarter choice of the hypothesis string
\widehat{x}
? A natural idea is to select
\widehat{\boldsymbol{x}}
uniformly at random from
\{0,1\}^{n}
. The performance of this zero-trace algorithm is captured by the
Chvátal–Sankoff constant

\gamma_{2}:=\lim_{n\to\infty}{\frac{\operatorname{{\bf E}}_{\boldsymbol{x},\widehat{\boldsymbol{x}}\sim\{0,1\}^{n}}[|\mathsf{LCS}(\boldsymbol{x},\widehat{\boldsymbol{x}})|]}{n}}

(the “2” is because we are working with the binary alphabet); the existence of this limit is an easy consequence of the superadditivity of LCS between random strings (using Fekete’s Lemma
[
Wik22b
]
). Despite much investigation over more than 40 years, the value of
\gamma_{2}
is not known: in 1975 Chvátal and Sankoff showed that
0.727273\leq\gamma_{2}\leq 0.866595,
and the current state of the art bounds, due to Lueker
[
Lue09
]
, are that
0.788071\leq\gamma_{2}\leq 0.826280

[
Wik22a
]
.

A superadditivity argument similarly establishes the existence of the limit

c_{2}:=\lim_{n\to\infty}\max_{\widehat{x}\in\{0,1\}^{n}}{\frac{\operatorname{{\bf E}}_{\boldsymbol{x}\sim\{0,1\}^{n}}[|\mathsf{LCS}(\boldsymbol{x},\widehat{x})|]}{n}},

(1)

which corresponds to the performance of the information-theoretic optimal zero-trace algorithm for the average-case setting. Even less is known about
c_{2}
than
\gamma_{2}
; Bukh and Cox
[
BC22
]
have shown (via an involved argument and an automated search) that
c_{2}\geq 0.82118
, and we show in
Appendix

that
c_{2}\leq 0.88999
, but more detailed bounds on the value of
c_{2}
do not seem to be known, nor is it known what strings might achieve this optimal bound
[
Buk22

.

Given these challenges in understanding zero-trace reconstruction in the average-case setting, the prospects of analyzing one-trace average-case reconstruction may appear dim.
Perhaps surprisingly, for the low deletion rate regime and medium deletion rate regime it turns out that the difficulty of analyzing zero-trace reconstruction is the only barrier to showing an upper bound on average-case one-trace reconstruction. This is shown in the following theorem, which gives an upper bound on average-case one-trace reconstruction in terms of the quantity
c_{2}
from
Equation

1

Theorem 4

(Average-case upper bound on any algorithm, small retention rate, informal statement)
.

Let
L_{1,\mathop{\mathrm{avg}}}(\delta,n)
denote the best expected LCS achievable by any one-trace algorithm at deletion rate
\delta
in the average-case setting. Then we have
c_{2}\leq\lim_{n\to\infty}{\frac{L_{1,\mathop{\mathrm{avg}}}(\delta,n)}{n}}\leq c_{2}+\rho.

Theorem

4
tells us that for any
\rho=o_{n}(1)
retention rate, it is not possible to asymptotically improve on the performance of the best zero-trace algorithm.
In fact, in
Theorem

29
we give a generalization of
Theorem

4
which gives an upper bound on the performance of algorithms that receive more than one trace. The proof is based on a careful analysis, using a coupling argument, of the
a posteriori

\boldsymbol{x}
given the received collection of traces.

Finally, we consider upper and lower bounds which are applicable for the medium and small deletion rate regime. In the average-case setting, the algorithm of
Theorem

3
can be shown to have better performance than was established in
Theorem

for the worst-case setting:

Theorem 5

(Average-case algorithm, small deletion rate, informal statement)
.

There is an average-case one-trace algorithm that achieves expected LCS at least

\left(1-\delta+\frac{1}{2}\delta^{2}+\frac{17}{8}\delta^{4}+\frac{55}{8}\delta^{5}-o(1)\right)n
for deletion rate
\delta.

Given

, it is natural to investigate the best possible performance of any one-trace algorithm in the average-case setting for small

For any deletion rate

3.1.1
A useful structural result and a
(2/3-o(1))
-LCS algorithm for

It is helpful for us to consider the following preliminary problem: we are not given any traces, and the goal is to output

has large LCS with one of the candidate strings in our list.
This motivates the following definition:

Definition 11

Let

We say a set

\big\lvert\mathsf{LCS}(S,x)\big\rvert:=\max_{s\in S}\hskip 1.13791pt\big\lvert\mathsf{LCS}(s,x)\big\rvert\geq h.

The following simple claim shows that when

is within a factor of two of

Claim 12

For every

((n+m)/3)
-LCS-cover of size at most

.

Proof.

We first consider the extreme settings of
m=2n
and
m=n/2
.
When
m=2n
, we have
\lvert\mathsf{LCS}((01)^{n},x)\rvert=n
for every

, and thus
\{(01)^{n}\}
is an
n
-LCS cover (of size

When
m=n/2
, every

either contains

many 1s or this many 0s, and so either
\lvert\mathsf{LCS}(0^{n/2},x)\rvert\geq n/2
or
\lvert\mathsf{LCS}(1^{n/2},x)\rvert\geq n/2
, and hence the set
\{0^{n/2},1^{n/2}\}
is a
(n/2)
-LCS cover of size
2
.

We interpolate between these two cases to handle general

Write
m=2a+b
and
n=a+2b
for some

and

(so
a=m-(n+m)/3
and
b=n-(n+m)/3
).
Consider

S:=\bigl\{(01)^{a}0^{b},(01)^{a}1^{b}\bigr\}\subseteq\{0,1\}^{m}.

(6)

Given

, we can write

where

and

\big\lvert\mathsf{LCS}(S,x)\big\rvert\geq\Big\lvert\mathsf{LCS}\bigl((01)^{a},x_{1}\bigr)\Big\rvert+\Big\lvert\mathsf{LCS}\bigl(\{0^{b},1^{b}\},x_{2}\bigr)\Big\rvert\geq a+b=(n+m)/3.\qed

We observe that taking

-LCS cover consisting of the two strings

that achieves

to determine which one of the two

3.3.1
Proof of

Fact 25

(
[

)

We now choose

Recall that
m=\frac{1}{2}\log_{1/\varepsilon^{4}}\ell

For

4
Worst-case one-trace reconstruction, medium and small deletion rate

In this section we consider the medium and small deletion rate regime. In particular, throughout this section we suppose that
\delta\leq 1/2
. (Note that if
\delta>1/2
, then the quantity
1-\delta+\delta^{2}/2-\delta^{3}/2+\delta^{4}/2-\delta^{5}/2
is less than
2/3
, so the performance guarantee given by

/

4.1
An efficient algorithm achieving expected LCS
(1-\delta+\delta^{2}/2-\delta^{3}/2+\delta^{4}/2-\delta^{5}/2-o(1))n

As mentioned in the introduction, it is very easy for a one-trace algorithm to achieve expected LCS at least
(1-\delta)n
: this can be accomplished simply by having the hypothesis string
\widehat{x}
be any string that contains the input trace
\boldsymbol{y}
as a subsequence. The expected LCS of such a hypothesis string is clearly at least
\operatorname{{\bf E}}[|\boldsymbol{y}|]
, which is
(1-\delta)n
by linearity of expectation.

The following theorem shows how to improve on this naive bound:

Theorem 26

(Worst-case algorithm, small deletion rate)
.

Let
\delta=\delta(n)\leq 1/2
be the deletion rate. There is an
O(n)
-time (randomized) algorithm
Small-rate-reconstruct
which is given as input the values
n
and
\delta
and a single trace
\boldsymbol{y}\sim\mathrm{Del}_{\delta}(x)
, where
x\in\{0,1\}^{n}
is an unknown and arbitrary source string.
For any
\gamma\leq 1
,
Small-rate-reconstruct
outputs a hypothesis string
\widehat{\boldsymbol{x}}\in\{0,1\}^{n}
which satisfies

\operatorname{{\bf E}}\big[|\mathsf{LCS}(\widehat{\boldsymbol{x}},x)|\big]\geq\Bigl(1-e^{-\Omega(\gamma^{2}n)}\Bigr)\left(1-\delta+\frac{\delta^{2}}{2}-\frac{\delta^{3}}{2}+\frac{\delta^{4}}{2}-\frac{\delta^{5}}{2}\right)n-3\gamma n

(so in particular, taking
\omega(1/\sqrt{n})\leq\gamma\leq o(1)
, we get that the expected value of
|\mathsf{LCS}(\widehat{\boldsymbol{x}},x)|
is at least
(1-\delta+\delta^{2}/2-\delta^{3}/2+\delta^{4}/2-\delta^{5}/2-o(1))n
).

1:

Set
j=1
and
p_{y}=1.

2:

While
p_{y}\leq|\boldsymbol{y}|
do:

3:

With probability
1-\delta
set
\widehat{\boldsymbol{x}}_{j}:=\boldsymbol{y}_{p_{y}}
and increment
p_{y}
;

4:

with the remaining
\delta
probability set
\widehat{\boldsymbol{x}}_{j}
to a uniform bit from
\{0,1\}
.

5:

Set
j:=j+1.

6:

If
|\widehat{\boldsymbol{x}}|<n
then append
0^{n-|\widehat{\boldsymbol{x}}|}
to
\widehat{\boldsymbol{x}}
, and if
|\widehat{\boldsymbol{x}}|>n
then delete bits
\widehat{\boldsymbol{x}}_{n+1},\dots
from
\widehat{\boldsymbol{x}}.

7:

Output the
n
-bit string
\widehat{\boldsymbol{x}}.

Algorithm 1

Small-rate-reconstruct

Intuition.

The algorithm
Small-rate-reconstruct
is given as
Algorithm

1
.
To analyze the algorithm it is convenient to consider the string
\widehat{\boldsymbol{x}}^{\prime}
which is
\widehat{\boldsymbol{x}}
immediately before Step 5 is performed (i.e. with no padding with 0s or deletion applied). We will show later that
\widehat{\boldsymbol{x}}^{\prime}
is with high probability “very close to
\widehat{\boldsymbol{x}}

\widehat{\boldsymbol{x}}^{\prime}
and take care of the minor difference between
\widehat{\boldsymbol{x}}^{\prime}
and
\widehat{\boldsymbol{x}}
at the end of the argument.

We first observe that
\widehat{\boldsymbol{x}}^{\prime}
clearly contains
\boldsymbol{y}
as a subsequence.
The main idea of the proof is that a non-negligible fraction of the times that Step 3 is performed, one or more uniform random bits from
\{0,1\}
will be placed in between consecutive bits
\boldsymbol{y}_{p_{y}}
and
\boldsymbol{y}_{p_{y}+1}
in creating the hypothesis string
\widehat{\boldsymbol{x}}^{\prime}
exactly when one or more bits of
x
were deleted in between
\boldsymbol{y}_{p_{y}}
and
\boldsymbol{y}_{p_{y}+1}
in the creation of the trace
\boldsymbol{y}
. Each time this happens there is a 1/2 chance that at least one “additional bit” beyond the subsequence
\boldsymbol{y}
of
\widehat{\boldsymbol{x}}^{\prime}
can be incorporated into a matching between
x
and
\widehat{\boldsymbol{x}}^{\prime}
.
This is the source of the extra
(\delta^{2}/2-\delta^{3}/2+\delta^{4}/2-\delta^{5}/2)n
in the LCS bound. Intuitively, the number of additional bits between every
\boldsymbol{y}_{p_{y}}
and
\boldsymbol{y}_{p_{y}+1}
in each of
x
and
\widehat{\boldsymbol{x}}^{\prime}
is distributed according to
\mathsf{Geometric}(1-\delta)-1
, so there are at least
\min\{\mathsf{Geometric}(1-\delta)-1,\mathsf{Geometric}(1-\delta)-1\}=\mathsf{Geometric}(1-\delta^{2})-1
many additional bits between
\boldsymbol{y}_{p_{y}}
and
\boldsymbol{y}_{p_{y}+1}
in
both
of
x
and
\widehat{\boldsymbol{x}}^{\prime}
, and there is a 1/2 chance each uniform additional
\{0,1\}
bit in
\widehat{\boldsymbol{x}}^{\prime}
matches an additional bit in
x
.

We now provide formal details.

Proof of
Theorem

26
.

Let
x\in\{0,1\}^{n}
be the unknown source string.
Consider appending infinitely many copies of a special symbol
\ast
to
x
to form an infinite string
x_{\infty}
.
We sample an infinite subsequence
\boldsymbol{y}_{\infty}
of
x_{\infty}
by the following infinite process:
For each
j=1,2,\dots
, we sample a prefix
\boldsymbol{x}^{j}
of
x_{\infty}
of length
\lvert\boldsymbol{x}^{j}\rvert\sim\mathsf{Geometric}(1-\delta)
, then output the last bit of
\boldsymbol{x}^{j}
as the
j
-th bit of
\boldsymbol{y}_{\infty}
and delete the prefix
\boldsymbol{x}^{j}
from
x_{\infty}
before moving on to the next value of
j
.

Note that the longest prefix of
\boldsymbol{y}_{\infty}
that does not contain any
x_{i}:i>n
is identically distributed as the trace
\boldsymbol{y}\sim\mathrm{Del}_{\delta}(x)
.
Equivalently, the concatenation of the last bit in each of
\boldsymbol{x}^{1},\ldots,\boldsymbol{x}^{\lvert\boldsymbol{y}\rvert}
is identically distributed as
\boldsymbol{y}\sim\mathrm{Del}_{\delta}(x)
.

Let
\mathbf{T}=\{t_{1}<\cdots<t_{|\boldsymbol{y}|}\}
be the set of
|\boldsymbol{y}|
many locations
j\in\{1,2,\dots,\}
such that
\widehat{\boldsymbol{x}}^{\prime}_{j}
was set to
\boldsymbol{y}_{p_{y}}
in some execution of Step 3 of
Small-rate-reconstruct
.
Note that the elements of
\mathbf{T}
are the indices of the
\mathbf{T}
race bits in
\widehat{\boldsymbol{x}}^{\prime}
and that
t_{i}
is the index such that
\widehat{\boldsymbol{x}}^{\prime}_{t_{i}}
was set to
\boldsymbol{y}_{i}
in Step 3 of the execution of
Small-rate-reconstruct
.
Let

\widehat{\boldsymbol{x}}^{\prime 1}:=\widehat{\boldsymbol{x}}^{\prime}_{[1:t_{1}]},\widehat{\boldsymbol{x}}^{\prime 2}:=\widehat{\boldsymbol{x}}^{\prime}_{[t_{1}+1:t_{2}]},\ldots,\widehat{\boldsymbol{x}}^{\prime\lvert\boldsymbol{y}\rvert}:=\widehat{\boldsymbol{x}}^{\prime}_{[t_{\lvert\boldsymbol{y}\rvert-1}+1:t_{\lvert\boldsymbol{y}\rvert}]}.

Observe that for each
i\in[\lvert\boldsymbol{y}\rvert]
, both
\boldsymbol{x}^{i}
and
\widehat{\boldsymbol{x}}^{\prime i}
are identically distributed.
In particular, their lengths
\lvert\boldsymbol{x}^{i}\rvert
and
\lvert\widehat{\boldsymbol{x}}^{\prime i}\rvert
are distributed according to
\mathsf{Geometric}(1-\delta)
, and so the minimum of both lengths, i.e.
\boldsymbol{d}_{i}:=\min\{\lvert\boldsymbol{x}^{i}\rvert,\lvert\widehat{\boldsymbol{x}}^{\prime i}\rvert\}
, is distributed according to
\mathsf{Geometric}(1-\delta^{2})
.
Moreover, the last bits in
\boldsymbol{x}^{i}
and
\widehat{\boldsymbol{x}}^{\prime i}
are equal to
\boldsymbol{y}_{i}
, and the rest of the bits in
\widehat{\boldsymbol{x}}^{i}
are uniform.

For each
i\in[\lvert\boldsymbol{y}\rvert]
, since the length-
(\boldsymbol{d}_{i}-1)
prefix of
\widehat{\boldsymbol{x}}^{\prime i}
is random, in expectation (over the randomness of
\widehat{\boldsymbol{x}}^{\prime i}
) it agrees with the length-
(\boldsymbol{d}_{i}-1)
prefix of
\boldsymbol{x}^{i}
on
(\boldsymbol{d}_{i}-1)/2
of the bits.
Also, the last bit of both
\boldsymbol{x}^{i}
and
\widehat{\boldsymbol{x}}^{\prime i}
are the same.
Hence, we have

\operatorname{{\bf E}}_{\widehat{\boldsymbol{x}}^{\prime i}}\Bigl[\lvert\mathsf{LCS}(\boldsymbol{x}^{i},\widehat{\boldsymbol{x}}^{i})\rvert\Bigr]\geq(\boldsymbol{d}_{i}-1)/2+1.

Observe that the concatenation of
\boldsymbol{x}^{i}:i\in[\lvert\boldsymbol{y}\rvert]
is a prefix of
x
, because the last bit of
\boldsymbol{x}^{\lvert\boldsymbol{y}\rvert}
is the last bit of
\boldsymbol{y}\sim\mathrm{Del}_{\delta}(x)
, and the concatenation of
\widehat{\boldsymbol{x}}^{\prime i}:i\in[\lvert\boldsymbol{y}\rvert]
is exactly
\widehat{\boldsymbol{x}}^{\prime}
.
Thus,

\operatorname{{\bf E}}_{\widehat{\boldsymbol{x}}^{\prime}}\Bigl[\lvert\mathsf{LCS}(x,\widehat{\boldsymbol{x}}^{\prime})\rvert\Bigr]\geq\sum_{i=1}^{\lvert\boldsymbol{y}\rvert}\Bigl[\operatorname{{\bf E}}_{\boldsymbol{x}^{i},\widehat{\boldsymbol{x}}^{\prime i}}\lvert\mathsf{LCS}(\boldsymbol{x}^{i},\widehat{\boldsymbol{x}}^{\prime i})\rvert\Bigr]\\
\geq\sum_{i=1}^{\lvert\boldsymbol{y}\rvert}\Bigl((\boldsymbol{d}_{i}-1)/2+1\Bigr)=\lvert\boldsymbol{y}\rvert+\sum_{i=1}^{\lvert\boldsymbol{y}\rvert}(\boldsymbol{d}_{i}-1)/2.

Since
\boldsymbol{d}_{i}\sim\mathsf{Geometric}(1-\delta^{2})
, we have
\operatorname{{\bf E}}[\boldsymbol{d}_{i}-1]=\frac{1}{1-\delta^{2}}-1=\frac{\delta^{2}}{1-\delta^{2}}
.
So taking expectation over
\lvert\boldsymbol{y}\rvert
, we obtain

\displaystyle\operatorname{{\bf E}}\Bigl[\lvert\mathsf{LCS}(x,\widehat{\boldsymbol{x}}^{\prime})\rvert\Bigr]

\displaystyle\geq\operatorname{{\bf E}}\bigl[\lvert\boldsymbol{y}\rvert\bigr]+\operatorname{{\bf E}}\bigl[\lvert\boldsymbol{y}\rvert\bigr]\frac{\delta^{2}}{2(1-\delta^{2})}

\displaystyle=(1-\delta)n\cdot\left(1+\frac{\delta^{2}}{2(1-\delta^{2})}\right)

\displaystyle=\left(1-\delta+\frac{\delta^{2}}{2(1-\delta^{2})}-\frac{\delta^{3}}{2(1-\delta^{2})}\right)n

\displaystyle\geq\left(1-\delta+\frac{\delta^{2}}{2}-\frac{\delta^{3}}{2}+\frac{\delta^{4}}{2}-\frac{\delta^{5}}{2}\right)n.

To finish the proof, we relate
\operatorname{{\bf E}}[\lvert\mathsf{LCS}(\widehat{\boldsymbol{x}},x)\rvert]
to
\operatorname{{\bf E}}[\lvert\mathsf{LCS}(\widehat{\boldsymbol{x}}^{\prime},x)\rvert]
.
We observe that

|\mathsf{LCS}(\widehat{\boldsymbol{x}},x)|\geq\max\{0,|\mathsf{LCS}(\widehat{\boldsymbol{x}}^{\prime},x)|-\boldsymbol{k}\},

where
\boldsymbol{k}
is the number of bits
\widehat{\boldsymbol{x}}_{n+1},\dots
deleted from
\widehat{\boldsymbol{x}}
in Step 5 of
Small-rate-reconstruct
if bits are deleted in that step (and
\boldsymbol{k}=0
otherwise). So it remains only to show that with high probability
\boldsymbol{k}
is small.

Recall that the value of
|\boldsymbol{y}|
is distributed as
\mathrm{Bin}(n,1-\delta)
, and given a particular outcome of the value of
|\boldsymbol{y}|
, the number of bits deleted in Step 5 is distributed as
\min\{0,\mathbf{G}_{1}+\cdots+\mathbf{G}_{|\boldsymbol{y}|}-n\}
where the
\mathbf{G}_{i}
’s are independent geometric random variables with each
\mathbf{G}_{i}\sim\mathsf{Geometric}(\rho)
(recall that
\rho=1-\delta
).
We will use two tail bounds: first, by a multiplicative
Chernoff bound, we have

Claim 27
.

For
\gamma\leq 1
, we have

\operatorname{{\bf Pr}}[|\boldsymbol{y}|\geq(1+\gamma)(1-\delta)n]\leq e^{-\Omega(\gamma^{2}n)}.

The second tail bound shows that
\mathbf{G}_{1}+\cdots+\mathbf{G}_{|\boldsymbol{y}|}
is unlikely to be much larger than
n
:

Claim 28
.

Fix an outcome of
|\boldsymbol{y}|
such that
|\boldsymbol{y}|\leq(1+\gamma)(1-\delta)n
,
where
\gamma\leq 1.

Then
\operatorname{{\bf Pr}}[\mathbf{G}_{1}+\cdots+\mathbf{G}_{|\boldsymbol{y}|}\geq(1+3\gamma)n]\leq e^{-\Omega(\gamma^{2}n)}.

Proof.

Recall that
7
upper bounds the probability that
\mathbf{G}_{1}+\cdots+\mathbf{G}_{(1+\gamma)(1-\delta)n}\geq\frac{1+\gamma}{1-\delta}\cdot(1+\gamma)(1-\delta)n=(1+\gamma)^{2}n
.
As
\gamma\leq 1
, we get that

\displaystyle\operatorname{{\bf Pr}}[\mathbf{G}_{1}+\cdots+\mathbf{G}_{|\boldsymbol{y}|}\geq(1+3\gamma)n]\leq e^{-\Omega(\gamma^{2}|\boldsymbol{y}|)}=e^{-\Omega(\gamma^{2}n)},

where the final inequality is by
7
.
∎

Combining
27
and
28
, we get that
\boldsymbol{k}\leq 3\gamma n
except with probability
e^{-\Omega(\gamma^{2}n)}
. Consequently, we have that

\displaystyle\operatorname{{\bf E}}[|\mathsf{LCS}(\widehat{\boldsymbol{x}},x)]

\displaystyle\geq\Bigl(1-e^{-\Omega(\gamma^{2}n)}\Bigr)\Bigl(\operatorname{{\bf E}}[|\mathsf{LCS}(\widehat{\boldsymbol{x}}^{\prime},x)]-3\gamma n\Bigr)

\displaystyle\geq\Bigl(1-e^{-\Omega(\gamma^{2}n)}\Bigr)\left(1-\delta+\frac{\delta^{2}}{2}-\frac{\delta^{3}}{2}+\frac{\delta^{4}}{2}-\frac{\delta^{5}}{2}\right)n-3\gamma n,

and the theorem is proved.
∎

4.2
Bounds on the performance of one-trace algorithms in the low deletion rate regime

As noted in the Introduction, it is natural to try to complement

by proving an upper bound on the best expected LCS that can be achieved by any one-trace algorithm in the low deletion rate regime. An average-case bound is of course stronger than a worst-case bound of this sort; in

1.1.2
we will show that even in the average-case setting, the best achievable LCS given a single trace is at most
(1-\Theta(\delta))n
.

5

In this section we bound the performance of any average-case few-trace algorithm when the retention rate is low.

6.2

Finally, in this section we establish an upper bound on the best possible performance that any one-trace algorithm can achieve in the small-deletion-rate regime.

{\frac{{n-5\sqrt{\delta^{\prime}}n\choose 3\delta^{\prime}n/4}}{{n\choose\delta^{\prime}n}}}\leq{\frac{{n\choose 3\delta^{\prime}n/4}}{{n\choose\delta^{\prime}n}}}=\frac{(n-\delta^{\prime}n)!\cdot(\delta^{\prime}n)!}{(n-3\delta^{\prime}n/4)!\cdot(3\delta^{\prime}n/4)!}\leq\left(\frac{\delta^{\prime}n}{n-\delta^{\prime}n}\right)^{\delta^{\prime}n/4}\leq(2\delta^{\prime})^{\delta^{\prime}n/4}.

As a result, the probability is at most

\left(\frac{3\delta^{\prime}n}{4}+1\right)\cdot\left(120\sqrt{\delta^{\prime}}\right)^{\delta^{\prime}n/4}=2^{-\Omega(\delta^{\prime}\log(1/\delta^{\prime})n)}

since
\delta^{\prime}
is at most some sufficiently small constant. This finishes the proof of
42
.
∎

Appendix A
An upper bound on average-case zero-trace reconstruction

We recall from

that in the asymptotic limit, the best possible performance of any zero-trace average-case reconstruction algorithm is given by

5

Via an involved analysis, Bukh and Cox show that
\operatorname{{\bf E}}_{\boldsymbol{x}\sim\{0,1\}^{n}}[|\mathsf{LCS}(\boldsymbol{x},w)|]\geq 0.82118

is the
n
-bit string
(0110111010010110010001011010)^{n/28},
and hence

We give an upper bound on

:

Claim 43
.

c_{2}\leq 0.88999.

Proof.

Fix

to be the optimal string that maximizes
\operatorname{{\bf E}}_{\boldsymbol{x}\sim\{0,1\}^{n}}[|\mathsf{LCS}(\boldsymbol{x},\boldsymbol{z})|]

follows from

\mathop{{\bf Pr}\/}_{\boldsymbol{x}\sim\{0,1\}^{n}}[z\text{~has a matching of size $0.88999n$ with $\boldsymbol{x}$}]\leq o(1),

(34)

which we establish below by showing that

\sum_{S\subseteq[n],|S|=0.88999n}\mathop{{\bf Pr}\/}_{\boldsymbol{x}\sim\{0,1\}^{n}}[z_{S}\text{~matches entirely into $\boldsymbol{x}$}]\leq o(1).

(35)

Via a union bound,
Equation

35
in turn follows from showing that for any
t
-bit string
y
, where
t:=0.88999n
, we have

\mathop{{\bf Pr}\/}_{\boldsymbol{x}\sim\{0,1\}^{n}}[y\text{~matches entirely into $\boldsymbol{x}$}]={\frac{o(1)}{{n\choose 0.88999n}}}.

(36)

Fix any
t
-bit string
y
and any
n
-bit string
x
.
The “greedy strategy” for (attempting to) entirely match
y
into
x
is the approach which maintains two pointers
p_{y}
(into the coordinates of
y
) and
p_{x}
and scans across
x
by successively incrementing
p_{x}
, matching each coordinate of
y
and incrementing
p_{y}
whenever it is possible to do so.
We recall the following well-known fact:

Claim 44

(Greedy matching is optimal for entirely matching one string into another)
.

There is some matching that entirely matches
y
into
x
if and only if the greedy strategy succeeds in entirely matching
y
into
x
.

We return to establishing
Equation

36
.
By
44
,
y
matches entirely into
\boldsymbol{x}
if and only if the greedy strategy matches
y
entirely into
\boldsymbol{x}
.

\boldsymbol{x}\sim\{0,1\}^{n}

Appendix B
A simple upper bound on average-case one-trace reconstruction in the small deletion rate regime

In this section we give a simple upper bound on the best possible expected LCS that any one-trace algorithm can achieve in the average-case small-deletion-rate regime.
The argument, which is based on a union bound over all possible matchings of a given size, is significantly simpler than the proof of
Theorem

35
, but it yields a result that is quantitatively weaker by a
\Theta(\log(1/\delta))
factor.

Theorem 45

(Weak average-case upper bound on any algorithm, small deletion rate)
.

Let
\delta=\delta(n)
be any
\omega(1/n)
deletion rate.
There is an absolute constant
c>0
such that for sufficiently large
n
we have

L_{1,\mathop{\mathrm{avg}}}(\delta,n)\leq(1-c\delta/\log(1/\delta))n.

Proof.

As in the beginning of the proof of
Theorem

35
, by recalling the well-known fact
[
KB80
]
that the median of the
\mathrm{Bin}(n,\delta)
distribution belongs to
\{\lfloor n\delta\rfloor,\lceil n\delta\rceil\}
, since
\delta=\omega(1/n)
we have that with probability
\Omega(1)
the length
|\boldsymbol{y}|
of a random trace
\boldsymbol{y}
drawn from the
\delta
-deletion channel is at least
(1-\Omega(\delta))n=:(1-\delta^{\prime})n
.
Hence to upper bound
L_{1,\mathop{\mathrm{avg}}}(\delta,n)
as claimed, it suffices to show the following: for any one-trace algorithm
A
that is given as input a uniform random trace
\boldsymbol{y}
, of length exactly
(1-\delta^{\prime})n
, from a uniform random source string
\boldsymbol{x}\sim\{0,1\}^{n}
, we have

\mathop{{\bf Pr}\/}_{\boldsymbol{x}\sim\{0,1\}^{n}}\left[A\text{~outputs a hypothesis string $z$ with~}|\mathsf{LCS}(\boldsymbol{x},z)|\geq\left(1-{\frac{c\delta^{\prime}}{\log(1/\delta^{\prime}}}\right)n\right]\leq 0.9.

(38)

We first recall from
Corollary

10
that given a trace
\boldsymbol{y}
of length
(1-\delta^{\prime})n
from a uniform
\boldsymbol{x}\sim\{0,1\}^{n}
, the
\delta^{\prime}n
bits of
\boldsymbol{x}_{\mathbf{D}}
that are missing from
\boldsymbol{y}
are independent and uniform random.
Next, we note that any candidate matching
\mu
of size
(1-\tau)n
between a source string
x\in\{0,1\}^{n}
and a hypothesis string
z\in\{0,1\}^{n}
is completely specified by two subsets
S=\{i_{1}<\cdots<i_{\tau n}\}\subset[n]
and
S^{\prime}=\{j_{1}<\cdots<j_{\tau n}\}\subset[n]
of size
\tau n
, where
S
(
S^{\prime}
, respectively) is the set of positions in
x
(positions in
z
, respectively) that do not participate in the matching.

Fix any hypothesis string
z\in\{0,1\}^{n}
(here
z
may depend on the trace
\boldsymbol{y}\sim\{0,1\}^{(1-\delta^{\prime})n}
that algorithm
A
receives as input).
Consider a fixed candidate matching
\mu
of size
(1-\tau)n
between
z
and
\boldsymbol{x}
, defined by two fixed sets
S,S^{\prime}
as described above.
For
\tau<\delta^{\prime}/2
(which will be the case given our final parameter setting for
\tau
), even if all
\tau n
positions in
S
are contained in the deleted locations
\mathbf{D}
, there are at least
(\delta-\tau)n\geq(\delta^{\prime}/2)n
bits in
\boldsymbol{x}_{\mathbf{D}}
that are not present in
\boldsymbol{y}
but are matched to some bits of
z
by the candidate matching
\mu
.
As mentioned above, these bits are independently uniform random, and so the probability that
\mu
successfully matches all of those (at least)
(\delta^{\prime}/2)n
bits with the right outcomes of their partners in
z
is at most
2^{-(\delta^{\prime}/2)n}.

It follows that
\operatorname{{\bf Pr}}_{\boldsymbol{x}}[
the candidate matching
\mu
is a valid matching between
z
and
\boldsymbol{x}]\leq 2^{-(\delta^{\prime}/2)n}
.
Hence we have

\displaystyle\mathop{{\bf Pr}\/}_{\boldsymbol{x}\sim\{0,1\}^{n}}[\text{there exists some matching of size $(1-\tau)n$ between $\boldsymbol{x}$ and $z$}]

\displaystyle\leq{n\choose\tau n}^{2}\cdot 2^{-(\delta^{\prime}/2)n}\leq 2^{(2H(\tau)-\delta^{\prime}/2)n}\leq 2^{-(\delta^{\prime}/4)n}\leq 0.9,

where the first inequality is by a union bound over all
{n\choose\tau n}^{2}
many candidate matchings of size
(1-\tau)n
, the second is
8
, the
third holds by choosing
\tau=c\delta^{\prime}/\log(1/\delta^{\prime})
for a suitable absolute constant
c
, and the fourth (with room to spare) is because
\delta^{\prime}
, like
\delta
, is
\omega(1/n).

∎
