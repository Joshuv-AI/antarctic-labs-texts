Abstract
Cache-aided MIMO communications aims to jointly exploit both coded caching (CC) and spatial multiplexing gains to enhance communication efficiency. In this paper, we first analyze the achievable degrees of freedom (DoF) in a MIMO-CC system with CC gain t t , where a server with L L transmit antennas communicates with K K users, each equipped with G G receive antennas. We demonstrate that the enhanced achievable DoF is max β , Ω ⁡ Ω ​ β \max_{\beta,\Omega}\Omega\beta , where the number of users Ω \Omega served in each transmission is fine-tuned to maximize DoF, and β ≤ min ⁡ ( G , L ​ ( Ω − 1 t ) / 1 + ( Ω − t − 1 ) ​ ( Ω − 1 t ) ) \beta\leq\min\big(G,\nicefrac{{L\binom{\Omega-1}{t}}}{{1+(\Omega-t-1)\binom{\Omega-1}{t}}}\big) represents the number of parallel streams decoded by each user. Second, we introduce an effective transmit covariance matrix design aimed at maximizing the symmetric rate, solved iteratively via successive convex approximation. Third, we propose a new class of MIMO-CC schemes using a novel scheduling mechanism leveraging maximal multicasting opportunities to maximize delivery rates at given SNR levels while adhering to linear processing constraints. Lastly, we devise linear multicast beamforming strategies tailored for the flexible scheduling schemes in MIMO-CC systems and present an iterative solution for the efficient design of beamformers. Extensive numerical simulations are used to verify the results of the paper.

Introduction

Mobile data traffic is continuously growing due to exponentially increasing volumes of multimedia content and the rising popularity of emerging applications such as mobile immersive viewing and extended reality

The existing wireless network infrastructure is under considerable strain due to the particularly demanding requirements of these applications, ranging from high throughput to ultra-low latency data delivery.

To enable this new gain,

The codewords are built such that each user can eliminate undesired parts of the message using its cache contents.
Later, the original CC scheme of

MISO-CC with bit- and signal-level designs

The original MISO-CC scheme relied on bit-level processing by multicasting carefully created XOR codewords to multiple user groups while suppressing the remaining inter-stream interference through spatial processing

The main motivation behind the signal-level CC schemes was the subpacketization bottleneck, which reflects the division of each fine into smaller parts for the CC operation

While the original SISO- and MISO-CC schemes of

Nevertheless, the flexibility provided by signal-level CC by use of dedicated (unicast) beamformers for each data term, has motivated continued research on signal-level schemes.

I-B

Main Contributions

The main contributions of this work are four-fold:

1) We improve upon the delivery scheme proposed by the authors in
[
20
]
to enhance the achievable single-shot DoF. Instead of serving a fixed number of users in each transmission, we judiciously select the number of users and the spatial multiplexing order per user in order to maximize the DoF. This eliminates the integer constraint on
\frac{L}{G}
imposed by
[
20
]
, resulting in an improved DoF of
\max_{\Omega,\beta}{\Omega\times\beta}
, where
\Omega
represents the number of users served in each transmission, and
{\beta\leq\mathrm{min}\big(G,\nicefrac{{L\binom{\Omega-1}{t}}}{{1+(\Omega-t-1)\binom{\Omega-1}{t}}}\big)}
denotes the total number of parallel data streams received by each user.

2) For any given delivery scheme (bit- or signal-level) in the considered MIMO-CC setup, we formulate a symmetric rate maximization problem w.r.t the general transmission covariance matrices of the intended messages. In this formulation, the user-specific rate is aggregated from all messages intended for the given user. Successive convex approximation (SCA) is used to solve the resulting non-convex optimization problem. This approach offers an upper bound on the symmetric rate performance of the selected transmission strategy.

3)
We propose a new class of MIMO-CC schemes based on a novel scheduling mechanism that allows maximizing the delivery rate in a given SNR level constrained by the linear processing condition at each receiver. The new class of schemes takes advantage of the maximal multicasting opportunity by transmitting multiple codewords of size
t+1
, and is symmetric in the sense that each target user receives the same number of parallel streams with each transmission.

4)
We discuss the optimized beamformer design for the proposed class of linear MIMO-CC schemes. The design is based on alternating optimization between the receiver and transmit beamformers and is coupled by an iterative algorithm based on Lagrangian duality for the transmitter side optimization problem,
providing a more practical and scalable Tx-Rx beamforming approach.

Parts of this work are included in our conference papers in
[
1
,
2
]
. Specifically, the preliminary idea of covariance-based multi-group multicasting was first introduced in

, and the achievability of the enhanced DoF bound for MIMO-CC systems was disclosed in

. This work includes the contributions of

and expands them significantly by introducing a new class of symmetric schemes with maximal multicasting gains to improve the finite-SNR performance of MIMO-CC schemes (where maximizing DoF is not necessarily desirable), and by proposing a high-performance, linear beamforming solution (w.r.t the covariance-based design) for the new class of symmetric schemes. The result is a simple yet efficient solution for enabling the gain boost of CC in practical MIMO systems. Numerical simulations are used to validate the results of the paper and to compare the performance of the new solutions with
[
1
,
2
]
and other baseline schemes.

{\mathcal{P}}
. As a result, as we transmit
\beta
subpackets with each transmission and there exist
S
distinct packet index sets
{\mathcal{P}}
, the maximum number of subpackets with the same packet index is
\big\lceil\frac{\beta}{S}\big\rceil
. On the other hand, by definition, the beamformer vector
{\mathbf{w}}_{{\mathcal{P}},k}^{q}
has to null out the inter-stream interference caused by
W_{{\mathcal{P}},k}^{q}
to every stream decoded by user
k^{\prime}
in
{\mathcal{K}}\backslash({\mathcal{P}}\cup\{k\})
(the interference caused to other users is removed by their cache contents).
Let us use
{\mathbf{U}}_{k}\in\mathbb{C}^{G\times\beta}
to denote the receive beamforming matrix at user
k
for decoding its
\beta
parallel streams. For the given transmission
s
, let us define the
equivalent interference channel
of a subpacket
W_{{\mathcal{P}},k}^{q}
included in
{\mathbf{x}}(s)
as

\begin{array}[]{l}\bar{{\mathbf{H}}}_{\mathcal{P},k}=[{\mathbf{H}}_{k^{\prime}}^{\mbox{\scriptsize H}}{\mathbf{U}}_{k^{\prime}}]^{\mbox{\scriptsize H}},\quad\forall k^{\prime}\in{\mathcal{K}}\backslash(\mathcal{P}\cup\{k\}),\end{array}

(6)

where
[\;\cdot\;]
represents the horizontal concatenation of matrices inside the brackets. Then, for each subpacket
W_{{\mathcal{P}},k}^{q}
transmitted by
{\mathbf{x}}(s)
, the interference nulling condition of its respective beamformer
{\mathbf{w}}_{{\mathcal{P}},k}^{q}

{\mathbf{w}}_{{\mathcal{P}},k}^{q}\in\mathrm{Null}(\bar{{\mathbf{H}}}_{{\mathcal{P}},k}).

(7)

Note that for given user index
k
and packet index
{\mathcal{P}}
, the definition in (

W_{{\mathcal{P}},k}^{q}
transmitted by
{\mathbf{x}}(s)
, irrespective of its subpacket index
q
.
Now, to ensure that each user

can decode all
\beta\leq G
parallel streams

sent to it with
{\mathbf{x}}(s)
, it is essential that transmit beamformers
{\mathbf{w}}_{{\mathcal{P}},k}^{q}
are linearly independent. For parallel streams with a different packet index
{\mathcal{P}}
, this condition is automatically met since the beamformers are chosen from different null spaces corresponding to non-overlapping or partially overlapping user sets.
However, for successfully decoding subpackets with the same packet index
{\mathcal{P}}
, the number of such subpackets (i.e.,
\big\lceil\frac{\beta}{S}\big\rceil
) should be limited by the dimensions of the
\mathrm{Null}(\bar{{\mathbf{H}}}_{{\mathcal{P}},k})

6

\bar{{\mathbf{H}}}_{{\mathcal{P}},k}
is formed by concatenation of
\Omega-t-1

, each with dimensions

, and hence,
\bar{{\mathbf{H}}}_{{\mathcal{P}},k}\in\mathbb{C}^{(\Omega-t-1)\beta\times L}

\mathrm{nullity(\cdot)}
to denote the dimensions of the null space, we can use the rank-nullity theorem
[
28
]
to write

\mathrm{nullity}(\bar{{\mathbf{H}}}_{\mathcal{P},k})=L-\mathrm{rank}(\bar{{\mathbf{H}}}_{\mathcal{P},k})=L-({\Omega-t-1})\beta.

So, for successful decoding of subpackets with the same packet index, we should have

\begin{array}[]{l}\left\lceil\frac{\beta}{S}\right\rceil\leq L-(\Omega-t-1)\beta.\end{array}

(8)

Recalling that
S=\binom{\Omega-1}{t}
and noting that the right-hand-side of (
8

) as

\begin{array}[]{l}\beta\leq\left(L-(\Omega-t-1)\beta\right)\binom{\Omega-1}{t},\end{array}

(9)

which, together with the basic decoding criteria of
\beta\leq G
, results in (
4
).
∎

The DoF of

General Multicast Transmit Covariance Matrix Design for MIMO CC

In this section, a general multicast transmit covariance matrix design is devised to maximize the symmetric rate across users in a MIMO-CC system.
Following the system model in Section
II
, let us assume a separate transmission vector
{\mathbf{x}}
is built for every subset
{\mathcal{K}}
of users with
|{\mathcal{K}}|=\Omega
. As a result of the proposed cache placement strategy,
any missing part of data requested by each user is available in the cache memories of exactly
t
other users in the network.
This facilitates the generation of data elements for subsets
{\mathcal{T}}
of users with size
|{\mathcal{T}}|=t+1
, such that the data sent to every user in the target group is available in the cache memories of all the other users in the group.
Defining
{\mathsf{S}}^{{\mathcal{K}}}=\{{\mathcal{T}}\subseteq{\mathcal{K}},|{\mathcal{T}}|=t+1\}
as the superset of all intended data element indices, the transmission vector
{\mathbf{x}}
is constructed as

\begin{array}[]{l}{\mathbf{x}}=\sum\nolimits_{\mathcal{T}\in{\mathsf{S}}^{{\mathcal{K}}}}{{\mathbf{x}}}_{\mathcal{T}},\end{array}

(12)

where
{{\mathbf{x}}}_{\mathcal{T}}\sim\mathcal{CN}(\mathbf{0},{\mathbf{K}}_{{{\mathbf{x}}}_{\mathcal{T}}})
is the transmit signal vector corresponding to bit-wise XOR data delivered to users
k\in{\mathcal{T}}
, chosen from a
complex Gaussian codebook with a multicast
covariance matrix
{\mathbf{K}}_{{{\mathbf{x}}}_{\mathcal{T}}}
.
Let us define
{\mathsf{S}}_{k}^{{\mathcal{K}}}=\{{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}\mid k\in{\mathcal{T}}\}
as the superset of data element indices containing useful data for user
k
, and
\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}=\mathsf{S}^{{\mathcal{K}}}\backslash{\mathsf{S}}_{k}^{{\mathcal{K}}}
.
Then, plugging (
12
) into (
1
) results in

\begin{array}[]{l}{\mathbf{y}}_{k}={\mathbf{H}}_{k}\sum_{{\mathcal{T}}\in{\mathsf{S}}_{k}^{{\mathcal{K}}}}{{\mathbf{x}}}_{{\mathcal{T}}}+{\mathbf{H}}_{k}\sum_{{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}}{{\mathbf{x}}}_{\mathcal{T}}+{\mathbf{z}}_{k}\end{array}

(13)

where the first and second summation terms correspond to the intended and interference terms for user
k
, respectively.
Here, the design objective is to maximize the worst-case delivery rate at which the system can serve all requests for files from the library.
It can be easily shown that
|{\mathsf{S}}_{k}^{{\mathcal{K}}}|=\binom{\Omega-1}{t}
and
|\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}|=\binom{\Omega-1}{t+1}
. As a result, if
\Omega>t+1
, every user
k\in{\mathcal{K}}
should decode multiple codewords received in parallel and the codeword-specific rates are constrained by the equivalent user-specific multiple access channel (MAC) rate regions of size
m_{k}=\binom{\Omega-1}{t}

[
7
,
8
]
.
The user-specific rate at a particular user
k
is obtained by aggregating all the messages that form an equivalent MAC channel, i.e.,
R_{MAC}^{k}=\min_{\mathsf{B}\subseteq{\mathsf{S}}_{k}^{{\mathcal{K}}}}[\frac{1}{|\mathsf{B}|}\sum_{{{\mathcal{T}}}\in\mathsf{B}}R_{{\mathcal{T}}}]
, where
\mathsf{B}\neq\varnothing
could represent any superset of codeword indices with sizes
|\mathsf{B}|=i,i\in\{1,\dots,{m_{k}}\}
, and
\sum_{{{\mathcal{T}}}\in\mathsf{B}}R_{{\mathcal{T}}}
limits the individual and sum rate of any combination of two or more transmitted multicast signals determined by
|\mathsf{B}|

[
18
]
. Assuming ideal (non-linear) receiver processing, the max-min rate maximization problem is formulated for the
proposed general multicast transmission design
as follows:

\hskip 0.0pt\begin{array}[]{l}\max_{{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}}\min_{k\in{\mathcal{K}}}{\min}_{{\mathsf{B}}\subseteq{\mathsf{S}}_{k}^{{\mathcal{K}}}}\big[\frac{1}{|{\mathsf{B}}|}\sum_{{{\mathcal{T}}}\in{\mathsf{B}}}R_{{\mathcal{T}}}\big]\\[8.61108pt]
\mathrm{s.t.}\sum_{{{\mathcal{T}}}\in\mathsf{B}}R_{{\mathcal{T}}}\leq\log\big|{\mathbf{I}}+{\mathbf{H}}_{k}\sum_{{{\mathcal{T}}}\in\mathsf{B}}{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}{\mathbf{H}}_{k}^{H}{\mathbf{Q}}_{k}^{-1}\big|,\\[8.61108pt]
\qquad\qquad\qquad\qquad\qquad\qquad\qquad\forall k\in{\mathcal{K}},\mathsf{B}\subseteq{\mathsf{S}}_{k}^{{\mathcal{K}}},\\[8.61108pt]
\qquad\sum\nolimits_{{{\mathcal{T}}}\in{\mathsf{S}}^{{\mathcal{K}}}}\text{Tr}({\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}})\leq P_{T},\end{array}

(14)

where the first constraint covers the rate region among all intended messages received by user
k
, and
{\mathbf{Q}}_{k}=(N_{0}{\mathbf{I}}+{\mathbf{H}}_{k}\sum_{{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}}{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}{\mathbf{H}}_{k}^{H})
.
The optimization problem (
14
) is NP-hard and non-convex due to the interference terms
{\mathbf{Q}}_{k}
. By applying SCA, a sub-optimal but efficient solution can be found iteratively. For this purpose, the constraints can be first written as a difference of two convex functions

\begin{array}[]{l}\hskip 0.0pt\sum_{{{\mathcal{T}}}\in\mathsf{B}}R_{{\mathcal{T}}}\leq\log\Big|{\mathbf{Q}}_{k}\!+\!{\mathbf{H}}_{k}\sum_{{{\mathcal{T}}}\in\mathsf{B}}\!{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}{\mathbf{H}}_{k}^{\mbox{\scriptsize H}}\Big|\!-\log\big|{\mathbf{Q}}_{k}\big|,\end{array}

for all
k\in{\mathcal{K}},\mathsf{B}\subseteq\mathsf{S}_{k}^{{\mathcal{K}}}
.
Then, applying the first-order Taylor series approximation to the negative
\log\det
term, a lower bound approximation can be found as

\begin{array}[]{l}\hskip 0.0pt\mathrm{Tr}\Big(\bar{{\mathbf{Q}}}_{k}^{-1}{\mathbf{H}}_{k}\sum_{{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}}(\bar{{\mathbf{K}}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}-{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}){\mathbf{H}}_{k}^{\mbox{\scriptsize H}}\Big)-\log|\bar{{\mathbf{Q}}}_{k}|,\end{array}

where the constant valued
\bar{{\mathbf{Q}}}_{k}
and
\bar{{\mathbf{K}}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}
represent the current approximation points acquired from the previous SCA iteration, and
\bar{R}
contains the previous SCA approximation point.
Finally, the approximated convex optimization problem can be written as

\begin{array}[]{l}\hskip 0.0pt\max_{{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}}R\\[8.61108pt]
\hskip 0.0pt\mathrm{s.t.}\sum\nolimits_{{{\mathcal{T}}}\in{\mathsf{S}}^{{\mathcal{K}}}}\text{Tr}({\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}})\leq P_{T},\\[8.61108pt]
R\!\leq\!\big(\!\log\big|N_{0}{\mathbf{I}}+{\mathbf{H}}_{k}(\sum_{{{\mathcal{T}}}\in\mathsf{B}}{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}\!\!+\!\!\sum_{{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}}{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}){\mathbf{H}}_{k}^{H}\big|\\[8.61108pt]
\;+\mathrm{Tr}(\bar{{\mathbf{Q}}}_{k}^{-1}{\mathbf{H}}_{k}\!\sum_{{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}}(\bar{{\mathbf{K}}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}\!\!-\!\!{\mathbf{K}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}\!){\mathbf{H}}_{k}^{H})\!\!-\!\log|\bar{{\mathbf{Q}}}_{k}|\big)\frac{1}{|\mathsf{B}|},\\[8.61108pt]
\qquad\qquad\qquad\qquad\qquad\qquad\forall k\in{\mathcal{K}},\mathsf{B}\subseteq{\mathsf{S}}_{k}^{{\mathcal{K}}}.\end{array}

(15)

Starting with a randomly chosen feasible initial point
\bar{{\mathbf{K}}}_{{{\mathbf{x}}}_{{\mathcal{T}}}}
,
{\mathcal{T}}\in\bar{\mathsf{S}}_{k}^{{\mathcal{K}}}
, and iterating (
15
) until convergence, a local solution of (
14
) can be achieved.

V
Linear Multicast Transmission Schemes for MIMO-CC

The placement and delivery strategies proposed in the proof of Theorem
1
can be implemented using any linear transmitter and receiver structures (as the number of unicast streams per user is explicitly limited by

\beta\leq G
).
However, as discussed in Remark
1
,
relying fully on unicast beamforming and signal domain processing may severely degrade the finite-SNR performance. Also, maximizing the DoF may not even be desirable for rate optimization in finite-SNR
[
7
,
26
]
.
On the other hand, the alternative design in Section
IV
based on optimizing the covariance matrices of the transmitted multicast signals improves the finite-SNR rate, but
requires non-linear receiver processing in general, and the rate optimization problem may also be too complex for practical implementation as
the number of the rate constraints of the MAC region in (
15
) increases exponentially w.r.t the total number of parallel streams in each transmission.

In this section, we introduce a new class of generalized linear multicast transmission strategies that may not necessarily achieve the enhanced DoF value in Theorem
1
but are designed to maximize the delivery rate at a given SNR level constrained by linear processing condition at each receiver. All the proposed strategies in this section are based on the original multi-server (MS) scheme in
[
8
]
, take advantage of maximal multicasting opportunities (i.e., XOR codewords of size
t+1
), and are symmetric in the sense that each target user receives an equal number of streams per each transmission.

Remark 2
.

The proposed class of linear multicast transmission schemes is a subset of all possible schemes for a given network. The symmetric rate achieved through these schemes may not be
globally
optimal, and, for example, non-linear or non-symmetric schemes with better performance may be found. However, as it is practically impossible to consider all feasible transmission strategies, we focus only on a subset of strategies with a well-defined structure and realistic practical implementability.

We start by reviewing the original MS scheme in
[
8
]
and assuming that the number of users in each transmission is set to
\Omega
. With this scheme,
in the delivery phase, each requested packet
W_{{\mathcal{P}},k}
is further divided into
\binom{K-t-1}{\Omega-t-1}
subpackets denoted as
W_{{\mathcal{P}},k}^{q}
, and for each subset
{\mathcal{K}}
of users with
|{\mathcal{K}}|=\Omega
, a particular transmission vector
{\mathbf{x}}_{\mathrm{MS}}
is constructed as:

\begin{array}[]{l}{\mathbf{x}}_{\mathrm{MS}}=\sum_{{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}}{\mathbf{w}}_{{\mathcal{T}}}X_{{\mathcal{T}}},\end{array}

(16)

where
{{\mathsf{S}}}^{{\mathcal{K}}}=\{{\mathcal{T}}\subseteq{\mathcal{K}},|{\mathcal{T}}|=t+1\}
denotes the superset of requested codeword indices,

X_{{\mathcal{T}}}=\bigoplus_{k\in{\mathcal{T}}}^{q}W_{{\mathcal{T}}\backslash\{k\},k}

represents the
codeword
generated for the user subset
{\mathcal{T}}
, and
{\mathbf{w}}_{{\mathcal{T}}}
is the multicast beamformer vector associated with
X_{{\mathcal{T}}}
. The super index
q
increases sequentially and is used to avoid the repetition of subpackets.

The first option for a cache-enabled MIMO system is to apply this MS scheme directly, i.e., to build the transmission vectors
similarly as (
16
) but to use spatial multiplexing at each receiver to separate the parallel streams. It can be easily verified that the number of parallel streams per user with (
16
) is
\binom{\Omega-1}{t}
. However, as the number of antennas
at each receiver is
G
, such a direct application of the MS strategy to the MIMO case could pose two challenges. First, if
G<\binom{\Omega-1}{t}
, linear receiver processing is not possible, and the complex successive interference cancellation (SIC) structure is needed to decode the parallel streams. Second, if
G\gg\binom{\Omega-1}{t}
, the solution is very inefficient as the number of streams decoded by each user is much smaller than the maximum possible value (i.e.,
G
). To address both scenarios, our proposed schemes introduce an underlying scheduling mechanism that enables setting the number of parallel streams sent to each target user, indicated by
\beta
, to any number from a predefined set while maintaining the linear decodability of streams.

Let us define
{\mathcal{B}}_{\Omega}
to contain a set of possible
\beta
values for a given
\Omega
. For every
\Omega
and
\beta\in{\mathcal{B}}_{\Omega}
, we can build a symmetric linear transmission strategy that transmits
\beta
parallel streams to each of the
\Omega
users in
{\mathcal{K}}
in each transmission using codewords of size
t+1
while also ensuring linear decodability.
Then, for a given
\mathrm{SNR}
value, we pick
\Omega
and
\beta\in{\mathcal{B}}_{\Omega}
values that maximize the symmetric rate as:

\begin{array}[]{l}\max\nolimits_{\Omega,\beta\in{\mathcal{B}}_{\Omega}}R_{\mathrm{sym}}(\Omega,\beta,\mathrm{SNR}).\end{array}

(17)

Enhanced Multicast Scheduling for MIMO-CC

Let us define

\begin{array}[]{l}\beta_{0}=\frac{t+1}{\mathrm{gcd}(t+1,\Omega)},\quad B_{0}=\frac{\Omega}{\mathrm{gcd}(t+1,\Omega)},\\[4.30554pt]
\end{array}

(18)

where
\mathrm{gcd}(\cdot)
denotes the greatest common divisor.
We first introduce a
base scheduling
where each target user receives exactly
\beta_{0}
codewords in each transmission. This is done in Theorem
2
using an appropriate partitioning of the codeword index superset
{{\mathsf{S}}}^{{\mathcal{K}}}=\{{\mathcal{T}}\subseteq{\mathcal{K}},|{\mathcal{T}}|=t+1\}
. Then, in Theorem
3
, we extend the base scheduling to suggest a more general set of possible
\beta
values.

Lemma 1
.

For any given
t
and
\Omega
,
|{\mathsf{S}}^{{\mathcal{K}}}|=\binom{\Omega}{t+1}
and
\binom{\Omega-1}{t}
are divisible by
B_{0}
and
\beta_{0}
, respectively.

Proof.

The proof follows the

Bézout’s identity
(or
Bézout’s lemma
) in number theory
[
29
]
, which asserts that the gcd of two integers can be expressed as a linear combination of them
with integer coefficients.
Using this lemma, we can write
\gcd(\Omega,t+1)=a\Omega+b(t+1)
for two integers
a
and
b
, and as a result

\begin{array}[]{l}\nicefrac{{\binom{\Omega}{t+1}}}{{B_{0}}}=\frac{a\Omega+b(t+1)}{\Omega}\binom{\Omega}{t+1}=a\binom{\Omega}{t+1}+b\binom{\Omega-1}{t},\\[8.61108pt]
\nicefrac{{\binom{\Omega-1}{t}}}{{\beta_{0}}}=\frac{a\Omega+b(t+1)}{t+1}\binom{\Omega-1}{t}=a\binom{\Omega}{t+1}+b\binom{\Omega-1}{t},\end{array}

and the divisibility constraints are met.
∎

Theorem 2
.

For the considered MIMO-CC system,
one can partition
{\mathsf{S}}^{{\mathcal{K}}}
into
S_{0}=\nicefrac{{\binom{\Omega}{t+1}}}{{B_{0}}}
supersets
{\mathsf{S}}^{{\mathcal{K}}}(s)
,
s\in[S_{0}]
,
such that for every
s\in[S_{0}]
,
\bigcup_{{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}(s)}{\mathcal{T}}={\mathcal{K}}
and for each user
k\in{\mathcal{K}}
,

|\{{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}(s)|k\in{\mathcal{T}}\}|=\beta_{0}
, i.e., user
k
appears in exactly
\beta_{0}
distinct
sets
{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}(s)
.

Proof.

The proof is based on two existing theorems on hypergraph factorization in
[
30
,
31
]
. By definition, a hypergraph
({\mathcal{V}},{\mathsf{E}})
consists of a finite set of vertices
{\mathcal{V}}
and an edge multi-superset
{\mathsf{E}}
, where every edge
{\mathcal{E}}\in{\mathsf{E}}
is itself a multi-subset of
{\mathcal{V}}
. For a positive integer
r
, an
r
-
factor
in a hypergraph
({\mathcal{V}},{\mathsf{E}})
is a spanning
r
-regular sub-hypergraph of
({\mathcal{V}},{\mathsf{E}})
, i.e., a hypergraph with the same vertex set
{\mathcal{V}}
but with an edge superset
\hat{{\mathsf{E}}}\subseteq{\mathsf{E}}
such that every vertex in
{\mathcal{V}}
is included in exactly
r
edges
{\mathcal{E}}\in\hat{{\mathsf{E}}}
. The
r
-
factorization
of
({\mathcal{V}},{\mathsf{E}})
is then defined as the partitioning of
{\mathsf{E}}
into multiple equal-sized sub-supersets
\hat{{\mathsf{E}}}_{i}
,
i\in\{1,\cdots,\nicefrac{{|{\mathsf{E}}|}}{{|\hat{{\mathsf{E}}}_{i}|}}\}
, such that every hypergraph
({\mathcal{V}},\hat{{\mathsf{E}}}_{i})
is an
r
-factor of
({\mathcal{V}},{\mathsf{E}})
.

For a positive integer
h
, the hypergraph
({\mathcal{V}},{\mathsf{E}})
is said to be
h
-uniform if
|{\mathcal{E}}|=h
for each
{\mathcal{E}}\in{\mathsf{E}}
. A complete
h
-uniform hypergraph
K_{n}^{h}
is defined as a hypergraph where
|{\mathcal{V}}|=n
and
{\mathsf{E}}
includes every subset of
{\mathcal{V}}
with size
h
. The well-known Baranyai theorem in
[
30
]
states that “
if
\nicefrac{{n}}{{h}}
is an integer,
1
-factorization of
K_{n}^{h}
is indeed possible
”. The Baranyai theorem was later extended in numerous works
[
31
,
32
]
, among which, in
[
31
]
it was shown that “
K_{n}^{h}
has a connected
\frac{h}{\mathrm{gcd}(n,h)}
-factorization
.”

Now, to prove Theorem
2
, let us first consider the case
\beta_{0}=1
, i.e.,
\mathrm{gcd}(\Omega,t+1)=t+1
. Consider the complete
(t+1)
-uniform hypergraph
K_{\Omega}^{t+1}
, where the set of vertices is the same as the target user set
{\mathcal{K}}
and the set of edges includes every selection of users from
{\mathcal{K}}
with size
t+1
. Clearly, for this hypergraph, the superset of edges
{\mathsf{E}}
is the same as
{\mathsf{S}}^{{\mathcal{K}}}
. The original Baranyai theorem
[
30
]
states that
K_{\Omega}^{t+1}
has a 1-factorization, and as each 1-factor should span the vertex set and each edge has a size of
t+1
, the number of edges in each 1-factor is
\nicefrac{{\Omega}}{{t+1}}=B_{0}
. As a result, the total number of 1-factors is
\nicefrac{{|{\mathsf{E}}|}}{{B_{0}}}=\nicefrac{{|{\mathsf{S}}^{{\mathcal{K}}}|}}{{B_{0}}}=\nicefrac{{\binom{\Omega}{t+1}}}{{B_{0}}}
.

Next, we consider the general case when
\mathrm{gcd}(\Omega,t+1)\neq t+1
. Again, starting from the complete
(t+1)
-uniform hypergraph
K_{\Omega}^{t+1}
, we can use the extension of the Baranyai’s theorem in
[
31
]
to ensure that
K_{\Omega}^{t+1}
has a
\nicefrac{{t+1}}{{\gcd(\Omega,t+1)}}=\beta_{0}
-factorization. Clearly, as each
\beta_{0}
-factor spans the whole vertex set and each vertex appears exactly
\beta_{0}
times, each
\beta_{0}
-factor provides us with one desired superset
{\mathsf{S}}^{{\mathcal{K}}}(s)
. Moreover, as the number of vertices is
\Omega
, each vertex appears
\beta_{0}
times, and the size of each edge is
t+1
, the number of edges in a
\beta_{0}
-factor is
\nicefrac{{\Omega\beta_{0}}}{{t+1}}=\nicefrac{{\Omega}}{{\gcd(\Omega,t+1)}}=B_{0}
. As a result, the total number of
\beta_{0}
-factors is
\nicefrac{{|{\mathsf{E}}|}}{{B_{0}}}=\nicefrac{{\binom{\Omega}{t+1}}}{{B_{0}}}
, and the proof is complete.
∎

Remark 3
.

The proof of Theorem
2
only shows the

of the intended partitioning of codeword indices. In order to build such a partitioning, one may use exhaustive search, heuristic solutions, or existing algorithms that are applicable under particular constraints. For example, if

and
\Omega

scheduling which has been thoroughly studied in the literature
[
33
]
. Also, for the slightly more general case where

can take any value but
\gcd(\Omega,t+1)=t+1
, the proof of the original Baranyai theorem
[
30
,
34
]
can be used to design an efficient partitioning algorithm. A detailed description of this solution is provided in
[
35
]
.

{\mathsf{S}}^{{\mathcal{K}}}(s)

Theorem 3

For given
\beta_{0}
and

and for two general integers

In other words, for each
\beta\in{\mathcal{B}}_{\Omega}
,
one could build a linear CC scheme comprising only XOR codewords of size

, such that with each transmission, each user in the target user set

Proof.

According to Theorem

,
one could partition
{\mathsf{S}}^{{\mathcal{K}}}
into
S_{0}
supersets
{\mathsf{S}}^{{\mathcal{K}}}(s)
such that for every

is selected such that
\nicefrac{{\delta S_{0}}}{{\eta}}
is also an integer. This concatenation and partitioning process is shown in Fig.

.

By definition, each user

appears exactly
\eta\beta_{0}
times in each resulting small table. Let us use
\hat{{\mathsf{S}}}^{{\mathcal{K}}}(\hat{s})
,
\hat{s}\in[\nicefrac{{\delta S_{0}}}{{\eta}}]
to denote the multi-superset including all the codeword indices in the
\hat{s}
-th small table (we need a multi-superset as there could be repetition in codeword indices if
\eta>S_{0}

\begin{array}[]{l}{\mathbf{x}}(\hat{s})=\sum_{{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}}(\hat{s})}{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}X_{{\mathcal{T}}}^{\hat{q}},\end{array}

{\mathcal{T}}
. Each transmission vector

\eta\beta_{0}

.

Clearly, a necessary condition for linear decodability of the transmission vectors

.
However, as discussed in the proof of Theorem

, one should also ensure that the number of subpackets

received by each user

\bar{{\mathbf{H}}}_{{\mathcal{P}},k}

\begin{array}[]{l}\lceil\frac{\eta}{{S_{0}}}\rceil{\leq}L-(\Omega-t-1)\eta\beta_{0}\Leftrightarrow{}\eta\leq\lfloor\frac{LS_{0}}{1+(\Omega-t-1)\beta_{0}S_{0}}\rfloor,\end{array}

∎

Remark 4
.

In practice, we may not even need to explicitly enforce extra subpacketization in the bit-domain when
\delta>1
. Instead, we could rely on splitting the encoded version of the codeword into arbitrary sizes, determined by their allocated rates in the symmetric rate optimization problem (as outlined in Section
VI
). Such an approach not only avoids extra subpacketization in the bit domain but could also improve the achievable rate by allowing more flexibility in the size of sub-streams
[
36
]
.

VI
Linear Beamforming for MIMO-CC

In this section, we discuss how linear transmit and receive beamformers can be designed for the MIMO-CC multicast transmission schemes introduced in Section
V
.
The goal is to enable multicast transmission to multiple groups of users with partially overlapping user sets and to use receiver-side processing to separate different group-specific streams.
We also propose an iterative solution, adapting the solution in
[
24
]
for non-overlapping multicast groups, for the fast and efficient computation of the transmit beamformers.

Let us start with the general transmission vector design in (
20
) and ignore the
\hat{s}
index (the same process is repeated for each transmission).
Let us define
{\mathcal{D}}^{{\mathcal{K}}}
to include all the codewords (i.e., every
X_{{\mathcal{T}}}^{\hat{q}}
) in transmit signal
{\mathbf{x}}
. We also define
\hat{{\mathsf{S}}}^{{\mathcal{K}}}_{k}=\{{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}}\mid k\in{\mathcal{T}}\}
,
{\mathcal{D}}^{{\mathcal{K}}}_{k}=\{X_{{\mathcal{T}}}^{\hat{q}}\in{\mathcal{D}}^{{\mathcal{K}}}\mid{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}}_{k}\}
and
\bar{{\mathcal{D}}}^{{\mathcal{K}}}_{k}={\mathcal{D}}^{{\mathcal{K}}}\backslash{\mathcal{D}}^{{\mathcal{K}}}_{k}
.
Then, the signal received by user
k\in{\mathcal{K}}
in (
1
) can be written as

\begin{array}[]{l}{\mathbf{y}}_{k}={\mathbf{H}}_{k}\Big({\sum_{{\mathcal{T}},\hat{q}:X_{\mathcal{T}}^{\hat{q}}\in{\mathcal{D}}^{{\mathcal{K}}}_{k}}{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}X_{{\mathcal{T}}}^{\hat{q}}}\\
\qquad\qquad+{\sum_{{\mathcal{T}},\hat{q}:X_{\mathcal{T}}^{\hat{q}}\in\bar{{\mathcal{D}}}^{{\mathcal{K}}}_{k}}{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}X_{{\mathcal{T}}}^{\hat{q}}}\Big)+{\mathbf{z}}_{k},\end{array}

(22)

where the first and second summations represent the intended and interference signals, respectively.
Denoting
{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}
as the receiver beamforming vector for decoding the intended stream
X_{{\mathcal{T}}}^{\hat{q}}\in{\mathcal{D}}_{k}^{{\mathcal{K}}}
at user
k\in{\mathcal{K}}
, the corresponding SINR term

\gamma_{k,{\mathcal{T}}}^{\hat{q}}
is given as:

\begin{array}[]{l}\gamma_{k,{\mathcal{T}}}^{\hat{q}}=\frac{|{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}^{\mbox{\scriptsize H}}{\mathbf{H}}_{k}{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}|^{2}}{\hskip-28.45274pt{\sum\limits_{{\bar{{\mathcal{T}}},\bar{q}:X_{\bar{{\mathcal{T}}}}^{\bar{q}}\in{\mathcal{D}}^{{\mathcal{K}}}\backslash\{X_{{\mathcal{T}}}^{\hat{q}}\}}}}|{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}^{\mbox{\scriptsize H}}{\mathbf{H}}_{k}{\mathbf{w}}_{\bar{{\mathcal{T}}}}^{\bar{{{q}}}}|^{2}+N_{0}\|{\mathbf{u}}_{k,{{\mathcal{T}}}}^{\hat{q}}\|^{2}}.\end{array}

Similarly to Section
IV
, we aim to minimize the worst-case delivery time among all users in
{\mathcal{K}}
. This is realized by maximizing the minimum achievable rate
across all partially overlapping groups of
{\mathcal{T}}\in\hat{{\mathsf{S}}}_{k}^{{\mathcal{K}}}
, formulated as

\begin{array}[]{l}\hskip-8.53581pt\max_{{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}},{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}\!\!\min_{{\mathcal{T}}\in{\mathsf{S}}^{{\mathcal{K}}}}\sum_{{\hat{q}}\in{\mathcal{Q}}_{{\mathcal{T}}}}\min_{k\in{\mathcal{T}}}\log(1+\gamma_{k,{\mathcal{T}}}^{\hat{q}}),\\[8.61108pt]
\qquad s.t.~~\sum\nolimits_{{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}},\hat{q}\in{\mathcal{Q}}_{\mathcal{T}}}\|{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}\|^{2}\leq P_{T},\end{array}

(23)

where
{\mathcal{Q}}_{\mathcal{T}}=\{{\hat{q}}\mid X_{{\mathcal{T}}}^{\hat{q}}\in{{\mathcal{D}}}^{{\mathcal{K}}}\}
and

P_{T}
is the transmission power.

The rate-optimal
\{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}\}
, maximizing the objective of (
23
) and employed to separate the
\beta
data terms intended for user
k
, correspond to (scaled) MMSE receivers
[
37
]
:

\begin{array}[]{l}{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}=\Big({\mathbf{H}}_{k}{\mathbf{W}}{\mathbf{W}}^{\mbox{\scriptsize H}}{\mathbf{H}}_{k}^{\mbox{\scriptsize H}}+N_{0}{\mathbf{I}}\Big)^{-1}{\mathbf{H}}_{k}{{\mathbf{w}}}_{{\mathcal{T}}}^{\hat{q}},\\
\qquad\qquad\qquad\forall{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}},k\in{\mathcal{T}},{\hat{q}}\in{\mathcal{Q}}_{\mathcal{T}}.\end{array}

(24)

where
{\mathbf{W}}=[{{\mathbf{w}}}_{{\mathcal{T}}}^{\hat{q}}]
is formed by concatenation of all transmit beamforming vectors
{{\mathbf{w}}}_{{\mathcal{T}}}^{\hat{q}}
(for every transmitted stream
X_{{\mathcal{T}}}^{\hat{q}}\in{\mathcal{D}}^{{\mathcal{K}}}
). Similarly, for each intended stream
X_{{\mathcal{T}}}^{\hat{q}}\in{\mathcal{D}}_{k}^{{\mathcal{K}}}
at user
k
,
the MSE
\epsilon_{k,{\mathcal{T}}}^{\hat{q}}

is defined as

\begin{array}[]{l}\epsilon_{k,{\mathcal{T}}}^{\hat{q}}=\mathbb{E}[{|{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}^{\mbox{\scriptsize H}}{\mathbf{y}}_{k}-X_{\mathcal{T}}^{\hat{q}}|^{2}}]={|1-{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}^{\mbox{\scriptsize H}}{\mathbf{H}}_{k}{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}|^{2}}\\
\hskip 19.91692pt+{\hskip-28.45274pt{\sum\limits_{{\bar{{\mathcal{T}}},\bar{q}:X_{\bar{{\mathcal{T}}}}^{\bar{q}}\in{\mathcal{D}}^{{\mathcal{K}}}\backslash\{X_{{\mathcal{T}}}^{\hat{q}}\}}}}\hskip-28.45274pt|{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}^{\mbox{\scriptsize H}}{\mathbf{H}}_{k}{\mathbf{w}}_{\bar{{\mathcal{T}}}}^{\bar{{{q}}}}|^{2}+N_{0}\|{\mathbf{u}}_{k,{{\mathcal{T}}}}^{\hat{q}}\|^{2}}.\end{array}

(25)

For fixed receive beamforming vector
{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}
,
\epsilon_{k,{\mathcal{T}}}^{\hat{q}}
is a convex function of transmit beamformers
{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}
(for
every transmitted stream
X_{{\mathcal{T}}}^{\hat{q}}\in{\mathcal{D}}^{{\mathcal{K}}}
), and vice versa.
Applying (
24
) in (
25
), the minimum MSE can be written as
{\epsilon_{k,{\mathcal{T}}}^{\hat{q}}}=(1+\gamma_{k,{\mathcal{T}}}^{\hat{q}})^{-1}
.
Utilizing this relation, (
23
) can be formulated equivalently in terms of MSE, for which the optimal
{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}
(for fixed
{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}
) is given by (
24
).
However, solving for
{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}
(given fixed
{{\mathbf{u}}_{k,{\mathcal{T}}}^{\hat{q}}}
) is a non-convex optimization problem, which can be reformulated as a difference of convex functions program (DCP) by introducing an auxiliary function
f(x)=2^{x}
and solved sub-optimally using SCA similarly to
[
37
]
.
As a result, adapting (
23
) for transmitter optimization, we solve the following convex problem iteratively until convergence:

\begin{array}[]{l}\max_{{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}},r_{c},r_{{\mathcal{T}}}^{\hat{q}},t_{k,{\mathcal{T}}}^{\hat{q}}}~r_{c}\\[8.61108pt]
s.t.\>\>\>r_{c}\leq\sum_{{\hat{q}}\in{\mathcal{Q}}_{\mathcal{T}}}r_{{\mathcal{T}}}^{\hat{q}},\quad r_{{\mathcal{T}}}^{\hat{q}}\leq t_{k,{\mathcal{T}}}^{\hat{q}}\>,\\[8.61108pt]
\qquad\epsilon_{k,{\mathcal{T}}}^{\hat{q}}\leq\bar{\alpha}_{k,{\mathcal{T}}}^{\hat{q}}t_{k,{\mathcal{T}}}^{\hat{q}}+\bar{\psi}_{k,{\mathcal{T}}},\\[8.61108pt]
\qquad\qquad\qquad\qquad\forall{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}},{\hat{q}}\in{\mathcal{Q}}_{\mathcal{T}},k\in{\mathcal{T}},\\[8.61108pt]
\qquad\sum\nolimits_{{\mathcal{T}}\in\hat{{\mathsf{S}}}^{{\mathcal{K}}},{\hat{q}}\in{{\mathcal{Q}}}_{{\mathcal{T}}}}\|{\mathbf{w}}_{{\mathcal{T}}}^{\hat{q}}\|^{2}\leq P_{T},\end{array}

(26)

where, given
\bar{t}_{k,{\mathcal{T}}}^{\hat{q}}
representing the optimal value of
{t}_{k,{\mathcal{T}}}^{\hat{q}}
from the previous iteration, the auxiliary function
f(\bar{t}_{k,{\mathcal{T}}}^{\hat{q}})^{-1}

VIII
Conclusion

The application of coded caching (CC) to enhance communication efficiency and performance in MIMO systems was thoroughly investigated in this paper. First, the number of users per transmission and the spatial multiplexing order per user were optimized to improve the achievable single-shot degrees of freedom (DoF) during the delivery. Then, the symmetric rate optimization problem for a given delivery scheme was formulated using general transmission covariance matrices to provide an upper bound on the rate performance, and the resulting non-convex problem was solved by successive convex approximation (SCA). Then, a new class of MIMO-CC schemes with maximal multicasting gain for enhanced finite-SNR performance and adhering to linear decodability was introduced. Finally, linear transmit and receiver beamformer designs were provided for the new class of MIMO-CC schemes, along with an iterative algorithm based on Lagrangian duality to reduce computational overhead. Numerical simulations confirmed the enhanced DoF and improved finite-SNR performance of the new schemes.
