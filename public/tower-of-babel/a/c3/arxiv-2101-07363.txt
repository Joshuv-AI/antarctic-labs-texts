Some results on higher order isosymmetries in Semi-Hilbertian Spaces
Rchid RABAOUI

Abstract
. In this paper, we introduce the class of ( A , ( m , n ) ) (A,(m,n)) -isosymmetric operators and we study some of their properties, for a positive semi-definite operator A A and m , n ∈ ℕ m,n\in\mathbb{N} , which extend, by changing the initial inner product with the semi-inner product induced by A A , the well-known class of ( m , n ) (m,n) -isosymmetric operators introduced by Mark Stankus ( [ 18 ] , [ 19 ] ). In particular, we characterize a family of A A -isosymmetric ( 2 × 2 ) (2\times 2) upper triangular operator matrices. Moreover, we show that that if T T is ( A , ( m , n ) ) (A,(m,n)) -isosymmetric and if Q Q is a nilpotent operator of order r r doubly commuting with T T , then T p T^{p} is ( A , ( m , n ) ) (A,(m,n)) -isosymmetric symmetric for any p ∈ ℕ p\in\mathbb{N} and ( T + Q ) (T+Q) is ( A , ( m + 2 ​ r − 2 , n + 2 ​ r − 1 ) ) \big(A,(m+2r-2,n+2r-1)\big) -isosymmetric. Some properties of the spectrum are also investigated.

Remark 1.1
.

(1)

Recall by definition

T\in(A;(m,n))\Longleftrightarrow\mathcal{S}^{n}_{A}(T)\in(I;(m,0))\Longleftrightarrow\mathcal{I}^{m}_{A}(T)\in(I;(0,n)).

Note that:

(a)

If
\mathcal{S}^{n}_{A}(T)\geq 0
, then
T\in(A;(m,n))

if and only if
T\in(\mathcal{S}^{n}_{A}(T);(m,0))
.

(b)

If
\mathcal{I}^{m}_{A}(T)\geq 0
, then
T\in(A;(m,n))

if and only if
T\in(\mathcal{I}^{m}_{A}(T);(0,n))
.

(2)

An
(A;(1,1))
-isosymmetry is an
A
-isosymmetry, and if
A=I
then an
(A;(m,n))
-isosymmetry is an
(m,n)
-isosymmetry.

(3)

If
T\in(A;(m,0))
, then
T\in(A;(m,n^{\prime}))
for all integer
n^{\prime}\geq 0
.

(4)

If
T\in(A;(0,n))
, then
T\in(A;(m^{\prime},n))
for all integer
m^{\prime}\geq 0
.

(5)

If
S\in\mathcal{B}(H)
is unitarly equivalent to
T
, then
S\in(A;(m,n))
if and only if
T\in(VAV^{*};(m,n))
, with

is unitary. Indeed, since
T
and
S
are unitary equivalent, there exists
V\in B(H)
unitary with
\mathcal{S}^{n}_{A}(S)=V^{*}\mathcal{S}^{n}_{VAV^{*}}(T)V.

It holds

\displaystyle\Omega_{A}^{m,n}(S)

\displaystyle=

\displaystyle V^{*}\big(\Omega_{VAV^{*}}^{m,n}(T)\big)V.

(6)

From the following identity

\big(\big\{(x+y)^{n}\big\}_{\mathbf{a}}\big)(T,A)=i^{n}\big(\big\{(x-y)^{n}\big\}_{\mathbf{a}}\big)(iT,A)

it can be seen that

(A;(m,n))
-isosymmetric if and only if

. So, several parallel results on skew
(A;(m,n))
-isosymmetries follow from the results of
(A;(m,n))
-isosymmetries.

(7)

The class of
(A;(m,n))
-isosymmetric (resp. skew
(A;(m,n))
-isosymmetric) operators is closed in norm, that is: let
T\in\mathcal{B}(H)
and
A\in\mathcal{B}(H)^{+}
, if

is a sequence of

-isosymmetric

-isosymmetric

-isosymmetric
(

.

Let

Example 1.2
.

(1)

The identity operator and the orthogonal projection on

.

(2)

Let

and

(3)

Generally, an

-isosymmetry is not necessarily an
(m,n)
-isosymmetry. Let

with norm

(4)

An operator

, without being in

or in
(A;(0,n))
. In fact, Let

Proposition 2.1
.

Let
T\in\mathcal{B}(H)
and
A\in\mathcal{B}(H)^{+}
. Then, the following assertions hold.

(1)

T
is
(A;(m,n))
-isosymmetric if and only if

(2.1)

\displaystyle\langle\Omega_{A}^{m,n}(T)x\,|\,x\rangle

\displaystyle=

\displaystyle\sum_{k=0}^{m}(-1)^{m-k}\;{m\choose k}\;\langle\mathcal{S}^{n}_{A}(T)T^{k}x\,|\,T^{k}x\rangle

\displaystyle=

\displaystyle\sum_{k=0}^{n}(-1)^{n-k}\;{n\choose k}\;\langle\mathcal{I}^{m}_{A}(T)T^{n-k}x\,|\,T^{k}x\rangle=0,\quad\forall\,x\in H.

(2)

If
T
is
(A;(m,n))
-isosymmetric, then
T
is
(A;(m^{\prime},n^{\prime}))
-isosymmetric
(m^{\prime}\geq m,n^{\prime}\geq n).

(3)

If
T
is
(A,n)
-symmetric
(
resp. skew
A
-symmetric
)
, then
(T-s)
is
(A;(m,n))
-isosymmetric
(
resp. skew
(A;(m,n))
-isosymmetric
)
for

.

Proof.

(1)

A simple computation shows that

\big(\Omega_{A}^{m,n}(T)\big)^{*}=\left\{\begin{array}[]{ll}\Omega_{A}^{m,n}(T),&\hbox{if n is even;}\\
-\Omega_{A}^{m,n}(T),&\hbox{if n is odd.}\end{array}\right.

If
n
is odd then
\big(i\Omega_{A}^{m,n}(T)\big)^{*}=i\Omega_{A}^{m,n}(T)
and, consequently,
\mathcal{K}:=i\Omega_{A}^{m,n}(T)
is a symmetric operator, which allows to conclude.

(2)

Since the following identities hold

\displaystyle\mathcal{I}^{m+1}_{A}(T)

\displaystyle=

\displaystyle\big(y\big\{(yx-1)^{m}\big\}_{\mathbf{a}}x-\big\{(yx-1)^{m}\big\}_{\mathbf{a}}\big)(T,A)=T^{*}\mathcal{I}^{m}_{A}(T)-\mathcal{I}^{m}_{A}(T)T,

\displaystyle\mathcal{S}^{n+1}_{A}(T)

\displaystyle=

\displaystyle\big(y\big\{(y-x)^{n}\big\}_{\mathbf{a}}-\big\{(y-x)^{n}\big\}_{\mathbf{a}}x\big)(T,A)=T^{*}\mathcal{S}^{n}_{A}(T)T-\mathcal{S}^{n}_{A}(T),

we obtain immediately

\displaystyle\Omega_{A}^{m+1,n}(T)

\displaystyle=

\displaystyle T^{*}\Omega_{A}^{m,n}(T)-\Omega_{A}^{m,n}(T)T,

\displaystyle\Omega_{A}^{m,n+1}(T)

\displaystyle=

\displaystyle T^{*}\Omega_{A}^{m,n}(T)T-\Omega_{A}^{m,n}(T).

The above two equalities completes the proof.

(3)

The following identity follows from the multinomial theorem

\displaystyle\big((y-s)(x-s)-1\big)^{m}\big\{\big((y-s)-(x-s)\big)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\big((yx-1)+(y-s)(-s)+(-sx)\big)^{m}\big\{(y-x)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\bigg(\sum_{\alpha_{1}+\alpha_{2}+\alpha_{3}=m}{m\choose\alpha_{1},\alpha_{2},\alpha_{3}}(y-s)^{\alpha_{2}}(-s)^{\alpha_{3}+\alpha_{2}}(yx-1)^{\alpha_{1}}x^{\alpha_{3}}\bigg)\big\{(y-x)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\sum_{\alpha_{1}+\alpha_{2}+\alpha_{3}=m}{m\choose\alpha_{1},\alpha_{2},\alpha_{3}}(y-s)^{\alpha_{2}}(-s)^{\alpha_{3}+\alpha_{2}}(yx-1)^{\alpha_{1}}\big\{(y-x)^{n}\big\}_{\mathbf{a}}x^{\alpha_{3}}

\displaystyle=

\displaystyle\sum_{k=0}^{m}\sum_{j=0}^{m-k}\;{m\choose k}{m-k\choose j}\;(y-s)^{k}(-s)^{k+j}(yx-1)^{m-k-j}\big\{(y-x)^{n}\big\}_{\mathbf{a}}x^{j}.

Moreover, we have

\displaystyle\big((y-s)(x-s)-1\big)^{m}\big\{\big((y-s)+(x-s)\big)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\sum_{k=0}^{m}\sum_{j=0}^{m-k}\sum_{i=0}^{n-i}\;{m\choose k}{m-k\choose j}{n\choose i}\;(y-s)^{k}(-s)^{k+j}(yx-1)^{m-k-j}\big\{(y+x)^{i}\big\}_{\mathbf{a}}(-2s)^{n-i}x^{j}.

By using these identities with
x
replaced by
T
,
y
replaced by
T^{*}
and
a
replaced by
A
, we obtain

(2.2)

\Omega_{A}^{m,n}(T-s)=\sum_{k=0}^{m}\sum_{j=0}^{m-k}\;{m\choose k}{m-k\choose j}\;(T^{*}-s)^{k}(-s)^{k+j}\Omega_{A}^{m-k-j,n}(T)T^{j},

(2.3)

\Lambda_{A}^{m,n}(T-s)=\sum_{k=0}^{m}\sum_{j=0}^{m-k}\sum_{i=0}^{n-i}\;{m\choose k}{m-k\choose j}{n\choose i}\;(T^{*}-s)^{k}(-s)^{k+j}\Lambda_{A}^{m-k-j,t}(T)(-2s)^{n-i}T^{j}.

This completes the proof.

Proposition 2.2
.

Let

(1)

If

(2)

\Big(\frac{(-i)^{n-1}}{(n-1)!}\mathcal{S}_{A}^{(n-1)}(T),m\Big)

Proof.

(1)

Let consider the following identity

\Omega_{A}^{m,n}(T)=\sum_{k=0}^{n}(-1)^{n-k}\;{n\choose k}\;T^{*k}\mathcal{I}^{m}_{A}(T)T^{n-k}.

Since
T

(A,m)
-isometric,
\frac{1}{(m-1)!}\mathcal{I}^{m-1}_{A}(T)

\displaystyle\sum_{k=0}^{m}(-1)^{m-k}\;{m\choose k}\;|\lambda|^{2k}\big\langle\mathcal{S}^{n}_{A}(T)f(\lambda)\,\big|\,f(\lambda)\big\rangle

\displaystyle\big(1-|\lambda|^{2}\big)^{m}\sum_{j=0}^{n}(-1)^{n-j}\;{n\choose j}\;\big\langle A^{\frac{1}{2}}T^{n-j}f(\lambda)\,\big|\,A^{\frac{1}{2}}T^{j}f(\lambda)\big\rangle

\displaystyle=

\displaystyle\big(1-|\lambda|^{2}\big)^{m}\sum_{j=0}^{n}(-1)^{n-j}\;{n\choose j}\;\lambda^{n-j}\overline{\lambda}^{j}\big\langle A^{\frac{1}{2}}f(\lambda)\,\big|\,A^{\frac{1}{2}}f(\lambda)\big\rangle

\displaystyle=

\displaystyle\big(1-|\lambda|^{2}\big)^{m}\big(2\Im m\,\lambda\big)^{n}\big\|A^{\frac{1}{2}}f(\lambda)\|^{2}.

This completes the proof.

∎

3.
Sum with a nilpotent operator

The paper
[
7
]
proves that, for positive integers
m,n
,
(T+Q)
is
(m+2r-2,n+2r-1)
-isosymmetric if
T
is an
(m,n)
-isosymmetry,
Q
is a nilpotent operator with order
r
, and
Q
doubly commutes with
T
(i.e
TQ=QT
and
TQ^{*}=Q^{*}T
). The authors, in
[
7
]
, shows this property for
(m,n,C)
-isosymmetric operators, with
C
a conjugation on a Hilbert space and
T
and
S
are
C
-doubly commuting (i.e
TQ=QT
and
CTCQ^{*}=Q^{*}CTC
). Theorem
3.2
extend this result to the sum of an
(A,(m,n))
-isosymmetry and a nilpotent operator.

Lemma 3.1
.

Let
T,S\in\mathcal{B}(H)
and
A\in\mathcal{B}(H)^{+}
. If
T
and
S
are doubly commuting, then the following two operator identities hold

(3.1)

\Omega_{A}^{m,n}(T+S)=\sum_{k=0}^{n}\sum_{j=0}^{n-k}\sum_{i+l+h=m}(-1)^{k}{n\choose k}\;{n-k\choose j}{m\choose i,l,h}\;(T^{*}+S^{*})^{i}S^{*l+j}\Omega_{A}^{h,n-k-j}(T)T^{l}S^{i+k}.

(3.2)

\Lambda_{A}^{m,n}(T+S)=\sum_{k=0}^{n}\sum_{j=0}^{n-k}\sum_{i+l+h=m}{n\choose k}\;{n-k\choose j}{m\choose i,l,h}\;(T^{*}+S^{*})^{i}S^{*l+j}\Lambda_{A}^{h,n-k-j}(T)T^{l}S^{i+k}.

Proof.

The multinomial theorem gives

\displaystyle\big((y_{1}+y_{2})(x_{1}+x_{2})-1\big)^{m}\big\{\big((y_{1}+y_{2})-(x_{1}+x_{2})\big)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\big((y_{1}x_{1}-1)+(y_{1}+y_{2})x_{2}+y_{2}x_{1}\big)^{m}\big\{((y_{1}-x_{1})+(y_{2}-x_{2}))^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\bigg(\sum_{i+l+h=m}{m\choose i,l,h}(y_{1}+y_{2})^{i}y^{l}_{2}(y_{1}x_{1}-1)^{h}x^{l}_{1}x^{i}_{2}\bigg)

\displaystyle\cdot\bigg\{\sum_{k=0}^{n}\sum_{j=0}^{n-k}(-1)^{k}{n\choose k}\;{n-k\choose j}\;y_{2}^{j}(y_{1}-x_{1})^{(n-k-j)}x_{2}^{k}\bigg\}_{\mathbf{a}}

\displaystyle=

\displaystyle\bigg(\sum_{i+l+h=m}(y_{1}+y_{2})^{i}y^{l}_{2}(y_{1}x_{1}-1)^{h}x^{l}_{1}x^{i}_{2}\bigg)

\displaystyle\cdot\bigg(\sum_{k=0}^{n}\sum_{j=0}^{n-k}(-1)^{k}{n\choose k}\;{n-k\choose j}\;y_{2}^{j}\Big\{(y_{1}-x_{1})^{(n-k-j)}\Big\}_{\mathbf{a}}x_{2}^{k}\bigg)

\displaystyle=

\displaystyle\sum_{k=0}^{n}\sum_{j=0}^{n-k}\sum_{i+l+h=m}(-1)^{k}{n\choose k}\;{n-k\choose j}{m\choose i,l,h}\;(y_{1}+y_{2})^{i}y^{l+j}_{2}(y_{1}x_{1}-1)^{h}\Big\{(y_{1}-x_{1})^{(n-k-j)}\Big\}_{\mathbf{a}}x^{l}_{1}x^{i+k}_{2}.

On the other hand, we have

\displaystyle\big((y_{1}+y_{2})(x_{1}+x_{2})-1\big)^{m}\big\{\big((y_{1}+y_{2})-(x_{1}+x_{2})\big)^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\big((y_{1}x_{1}-1)+(y_{1}+y_{2})x_{2}+y_{2}x_{1}\big)^{m}\big\{((y_{1}+x_{1})+y_{2}+x_{2})^{n}\big\}_{\mathbf{a}}

\displaystyle=

\displaystyle\sum_{k=0}^{n}\sum_{j=0}^{n-k}\sum_{i+l+h=m}{n\choose k}\;{n-k\choose j}{m\choose i,l,h}\;(y_{1}+y_{2})^{i}y^{l+j}_{2}(y_{1}x_{1}-1)^{h}\Big\{(y_{1}+x_{1})^{(n-k-j)}\Big\}_{\mathbf{a}}x^{l}_{1}x^{i+k}_{2}.

If
T
and
S
are doubly commuting, then replacing
x_{1}
by
T
,
x_{2}
by
S
,
y_{1}
by
T^{*}
,
y_{2}
by
S^{*}
and
a
by
A
, we obtain (
3.1
) and (
3.2
).

∎

Theorem 3.2
.

Let
A\in\mathcal{B}(H)^{+}
,
T\in\mathcal{B}(H)
and
Q
is a nilpotent operator of
order
r.
If
T
and
Q
are doubly commuting, then the following statements hold.

(1)

If
T
is
(A,(m,n))
-isosymmetric, then
(T+Q)
is
(A,(m+2r-2,n+2r-1))
-isosymmetric.

(2)

If
T
is skew
(A,(m,n))
-isosymmetric, then
(T+Q)
is skew
(A,(m+2r-2,n+2r-1))
-isosymmetric.

Proof.

(1)

By (
3.1
),

\displaystyle\Omega_{A}^{m+2r-2,n+2r-1}(T+Q)

\displaystyle=

\displaystyle\sum_{k=0}^{n+2r-1}\sum_{j=0}^{n+2r-1-k}\sum_{i+l+h=m+2r-2}(-1)^{k}{n+2r-1\choose k}\;{n+2r-1-k\choose j}

\displaystyle{m+2r-2\choose i,l,h}(T^{*}+Q^{*})^{i}Q^{*l+j}\Omega_{A}^{h,n+2r-1-k-j}(T)T^{l}Q^{i+k},

Note that if
(k+j)\geq 2r
or
i\geq r
or
l\geq r
, then
(T^{*}+Q^{*})^{i}Q^{*l+j}\Omega_{A}^{h,n+2r-1-k-j}(T)T^{l}Q^{i+k}=0
since either
Q^{*l+j}=0
or
Q^{i+k}=0
. On the other hand, if
(k+j)\leq 2r-1
, then

n+2r-1-(k+j)\geq n+2r-1-(2r-1)=n,

and, if

and
l\leq r-1
, then

Hence,
T
is an
(A,(h,n+2r-1-k-j))
-isosymmetry and
\Omega_{A}^{h,n+2r-1-k-j}(T)=0
. Therefore,
\Omega_{A}^{m+2r-2,n+2r-1}(T+Q)=0
and
(T+Q)
is
(A,(m+2r-2,n+2r-1))
-isosymmetric.

(2)

By (
3.2
),

\displaystyle\Lambda_{A}^{m+2r-2,n+2r-1}(T+Q)

\displaystyle=

\displaystyle\sum_{k=0}^{n+2r-1}\sum_{j=0}^{n+2r-1-k}\sum_{i+l+h=m+2r-2}{n+2r-1\choose k}\;{n+2r-1-k\choose j}

\displaystyle{m+2r-2\choose i,l,h}(T^{*}+Q^{*})^{i}Q^{*l+j}\Lambda_{A}^{h,n+2r-1-k-j}(T)T^{l}Q^{i+k}.

By using this identity and arguing in the same way as in the first statement we complete the proof.

∎

4.

For

\Omega_{A}^{1,1}(T)=T^{*}\mathcal{I}^{1}_{A}(T)-\mathcal{I}^{1}_{A}(T)T=T^{*2}AT-T^{*}AT^{2}-T^{*}A+AT,

(4.2)

\Lambda_{A}^{1,1}(T)=\mathcal{I}^{1}_{A}(T)T+T^{*}\mathcal{I}^{1}_{A}(T)T=T^{*2}AT+T^{*}AT^{2}-T^{*}A-AT.

) and (

,

Theorem 4.3
.

Let
A\in\mathcal{B}(H)^{+}
,
N,E,X\in\mathcal{B}(H)
and
\textbf{T}=\left(\begin{array}[]{cc}N&E\\
0&X\\
\end{array}\right)
on
\textbf{H}=H\oplus H
. Then, the following statements hold.

(1)

Assume that
E=NEX
,
N^{*}AE=AEX
and
N
is
A
-isometric. Then,
T
is
A
-isosymmetric if and only if
X
is
A
-isosymmetric.

(2)

Assume that
N
is
A
-symmetric and
NE=EX
. Then,
T
is
A
-isosymmetric if and only if
X
is
A
-isosymmetric and
AE=ANEX
holds.

Proof.

(1)

Since
A\in\mathcal{B}(H)^{+}
, we have
\textbf{A}=A\oplus A\in\mathcal{B}\big(H\oplus H\big)^{+}.
On the other hand,

\mathcal{I}^{1}_{A}(\textbf{T})=\left(\begin{array}[]{cc}\mathcal{I}^{1}_{A}(N)&N^{*}AE\\
E^{*}AN&E^{*}AE+\mathcal{I}^{1}_{A}(X)\\
\end{array}\right).

It holds from that

\displaystyle\textbf{T}^{*}\mathcal{I}^{1}_{A}(\textbf{T})

\displaystyle=

\displaystyle\left(\begin{array}[]{cc}N^{*}\mathcal{I}^{1}_{A}(N)&N^{*2}AE\\
E^{*}\mathcal{I}^{1}_{A}(N)+X^{*}E^{*}AN&E^{*}N^{*}AE+X^{*}E^{*}AE+X^{*}\mathcal{I}^{1}_{A}(X)\\
\end{array}\right),

\displaystyle\mathcal{I}^{1}_{A}(\textbf{T})\textbf{T}

\displaystyle=

\displaystyle\left(\begin{array}[]{cc}\mathcal{I}^{1}_{A}(N)N&\mathcal{I}^{1}_{A}(N)E+N^{*}AEX\\
E^{*}AN^{2}&E^{*}ANE+E^{*}AEX+\mathcal{I}^{1}_{A}(X)X\\
\end{array}\right).

By equations (
1
) and (
1
),
T
is
A
-isosymmetric if and only if

(4.14)

\left\{\begin{array}[]{ll}N^{*}\mathcal{I}^{1}_{A}(N)=\mathcal{I}^{1}_{A}(N)N,&\hbox{ }\\
E^{*}\mathcal{I}^{1}_{A}(N)+X^{*}E^{*}AN=E^{*}AN^{2},&\hbox{ }\\
N^{*2}AE=\mathcal{I}^{1}_{A}(N)E+N^{*}AEX,&\hbox{}\\
\big(E^{*}N^{*}AE+X^{*}E^{*}AE\big)+X^{*}\mathcal{I}^{1}_{A}(X)=\big(E^{*}ANE+E^{*}AEX\big)+\mathcal{I}^{1}_{A}(X)X.&\hbox{}\end{array}\right.

Assume that
N
is
A
-isometric, that is
\mathcal{I}^{1}_{A}(N)=N^{*}AN-A=0
. It holds from that

(4.15)

\left\{\begin{array}[]{ll}X^{*}E^{*}AN=E^{*}AN^{2},&\hbox{ }\\
N^{*2}AE=N^{*}AEX,&\hbox{}\\
\big(E^{*}N^{*}AE+X^{*}E^{*}AE\big)+X^{*}\mathcal{I}^{1}_{A}(X)=\big(E^{*}ANE+E^{*}AEX\big)+\mathcal{I}^{1}_{A}(X)X.&\hbox{}\end{array}\right.

If
E=NEX
and
N^{*}AE=AEX
, then the first and the second equation of (
4.15
) hold. Moreover, we have

\displaystyle E^{*}ANE+E^{*}AEX

\displaystyle=

\displaystyle X^{*}E^{*}\underbrace{N^{*}AN}E+E^{*}N^{*}AE

\displaystyle=

\displaystyle X^{*}E^{*}AE+E^{*}N^{*}AE.

The above equation gives

X^{*}\mathcal{I}^{1}_{A}(X)=\mathcal{I}^{1}_{A}(X)X.

Hence,
X
is
A
-isosymmetric. Arguing as above, we can show the converse of the claim.

(2)

Assume that
N
is
A
-symmetric, that is
\mathcal{S}^{1}_{A}(N)=N^{*}A-AN=0
and
T
is
A
-isosymmetric. From the assumptions, it holds
X^{*}E^{*}A=E^{*}N^{*}A=E^{*}AN,
and so
N^{*}AE=AEX.
Hence, it follows

(4.16)

\left\{\begin{array}[]{ll}X^{*}E^{*}AE=E^{*}ANE,&\hbox{}\\
E^{*}N^{*}AE=E^{*}AEX.&\hbox{}\end{array}\right.

From (
4.14
) and (
4.16
), we obtain

E^{*}N^{*}AE+X^{*}E^{*}AE=E^{*}ANE+E^{*}AEX.

So,
X^{*}\mathcal{I}^{1}_{A}(X)=\mathcal{I}^{1}_{A}(X)X.
Hence,
X
is
A
-isosymmetric. On the other hand, (
4.14
) becomes

\left\{\begin{array}[]{ll}E^{*}(N^{*2}-I)A+X^{*}E^{*}N^{*}A=E^{*}N^{*2}A,&\hbox{}\\
AN^{2}E=A(N^{2}-I)E+ANEX.&\hbox{}\end{array}\right.

This gives that

\left\{\begin{array}[]{ll}E^{*}A=X^{*}E^{*}N^{*}A,&\hbox{}\\
AE=ANEX.&\hbox{}\end{array}\right.

By similar arguments, we can show the other implication.

∎

Corollary 4.4
.

Let
A\in\mathcal{B}(H)^{+}
,
N,E,X\in\mathcal{B}(H)
and
\textbf{T}=\left(\begin{array}[]{cc}N&E\\

\end{array}\right)
on

with

an

-isometry. If

, then

is

-isosymmetric.

Proof.

Since
N
is an

-isometry and

, it holds from (

) that

On the other hand,

\hbox{\big($T$ is $A$-isosymmetric\big)}\Longleftrightarrow\big(X^{*}(E^{*}AE+X^{*}AX-A)=(E^{*}AE+X^{*}AX-A)X\big).

This completes the proof.

∎

.

\mathcal{M}
is invariant for

\mathcal{M}^{\perp}

, we have

∎
