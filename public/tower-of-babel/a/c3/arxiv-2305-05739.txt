Graph-Based Reductions for Parametric and Weighted MDPs
Kasper Engelen, Guillermo A. Pérez, Shrisha Rao

Abstract
We study the complexity of reductions for weighted reachability in parametric Markov decision processes. That is, we say a state p p is never worse than q q if for all valuations of the polynomial indeterminates it is the case that the maximal expected weight that can be reached from p p is greater than the same value from q q . In terms of computational complexity, we establish that determining whether p p is never worse than q q is 𝐜𝐨 \mathbf{co} 𝐄𝐓𝐑 \mathbf{ETR} -complete. On the positive side, we give a polynomial-time algorithm to compute the equivalence classes of the order we study for Markov chains. Additionally, we describe and implement two inference rules to under-approximate the never-worse relation and empirically show that it can be used as an efficient preprocessing step for the analysis of large Markov decision processes.



1
Introduction

Markov decision processes (MDPs, for short) are useful mathematical models to
capture the behaviour of systems involving some random components and discrete
(non-deterministic) choices. In the field of verification, they are studied as
formal models of randomised algorithms, protocols,
etc.
[
1
,
6
]
In artificial intelligence, MDPs
provide the theoretical foundations upon which reinforcement learning
algorithms are based
[
16
,
19
]
.

From the verification side, efficient tools have been implemented for the analysis
of MDPs. These include, for instance, PRISM
[
14
]
,
Storm
[
12
]
, and
Modest
[
9
]
. While those
tools can handle ever larger and complexer MDPs, as confirmed by the most
recent Comparison of Tools for the Analysis of Quantitative Formal
Models
[
4
]
,
they still suffer from the state-explosion problem and the worst-case
exponential complexity of value iteration. While most tools can check the MDP
against a rich class of specifications (linear temporal logic, probabilistic
computation-tree logic, etc.), they often reduce the task to reachability
analysis and solve the latter using some version of value
iteration
[
10
]
.

In this work we focus on reduction techniques to improve the runtime of MDP
analysis algorithms as implemented in the aforementioned verification tools.
We are particularly interested in reductions based on the graph underlying the
MDP which do not make use of the concrete probability distributions. This,
because such reductions can also be applied to partially known MDPs that arise
in the context of reinforcement learning
[
2
]
. Several graph
and automata-theoretic reduction techniques with these properties already
exist. They focus on the computation of states with specific properties, for
instance: extremal-value states (i.e. states whose probability of reaching the
target set of states is
0
or
1
), maximal end components (i.e. sets of
states which can almost-surely reach each other), and essential
states
[
7
,
5
]
(i.e.
sets of states which form a graph-theoretic separator between some given state
and the target set), to name a few. In
[
15
]
, Le Roux and Pérez
have introduced a partial order among states, called the
never-worse
relation
(NWR, for short), that subsumes all of the notions listed above.
Their main results in that work were establishing that the NWR the natural
decision problem of comparing two states is
\mathbf{coNP}
-complete, and giving a few
inference rules to under-approximate the full NWR.

Our contribution.

In this paper, we have extended the NWR to weighted reachability in parametric MDPs.
Formally, we have assigned weights to the target set of states and allow for transitions to be labelled with polynomials instead of just concrete
probability values. Then, we say a state
p
is never worse than
q
if for
all valuations of the indeterminates, it is the case that the maximal expected
weight that can be reached from
p
is at least the same value from
q
.
We have shown that determining whether
p
is NWR than
q
is
\mathbf{co}
\mathbf{ETR}
-complete, so it
is polynomial-time interreducible with determining the truth value of a
statement in the existential theory of the reals. Along the way, we prove that
the NWR for weighted reachability reduces in polynomial time to the NWR for
(Boolean) reachability. Regarding theoretical results, we further establish
that the equivalence classes of the NWR can be computed in polynomial time for a special class of
parametric Markov chains, while this is just as hard as the NWR decision
problem for parametric MDPs. Finally, we have significantly improved (and corrected small errors in) the inference
rules from Le Roux and Pérez and provided a concrete algorithm to use them in
order to reduce the size of a given MDP. We have implemented our algorithm and
evaluated its performance on a number of benchmarks from the Quantitative
Verification Benchmark Set
[
11
]
.

2.1
Stochastic models

A distribution on a finite set
S
is a function
f:S\rightarrow\mathbb{R}_{\geq 0}
, with
\sum_{s\in S}f(s)=1
.

Definition 1
(Markov chains)

A (weighted) Markov chain is a tuple
\mathcal{C}=(S,\mu,T,\rho)
with
a finite set of states
S
, a set of target states
T\subseteq S
, a
probabilistic transition function
\mu:(S\setminus T)\times S\rightarrow\mathbb{R}_{\geq 0}
with
\forall s\in S\setminus T:\sum_{s^{\prime}\in S}\mu(s,s^{\prime})=1
(i.e.
\mu
maps non-target states onto probability
distributions over states), and a weight function

\rho:T\rightarrow\mathbb{Q}
that assigns weights to the target states.

Note that all states in
T
are sinks:
\mu(t,s)
is
undefined for all
t\in T,s\in S
.

A
run
of
\mathcal{C}
is a finite non-empty word
\pi=s_{0}\dots s_{n}

over
S
such that
0<\mu(s_{i},s_{i+1})
for all
0\leq i<n
. The run
\pi

reaches

s^{\prime}\in S
if
s^{\prime}=s_{n}
. The probability associated with a run
is defined as
\mathbb{P}_{\mu}(\pi)=\prod_{0\leq i<n}\mu(s_{i},s_{i+1})
.

We also define the probability of reaching a set of states.
Below, we write
\{\!\{x_{1},\dots,x_{n}\}\!\}
to denote the
multiset
consisting of the elements
x_{1},\dots,x_{n}
.

Definition 2
(Reachability)

Given a Markov chain
\mathcal{C}=(S,\mu,T,\rho)
, an initial state
s_{0}\in S

and a set of states
B\subseteq S
, we denote by

\mathbb{P}^{s_{0}}_{\mathcal{\mathcal{C}}}[\Diamond B]
the probability of reaching
B

from
s_{0}
. If
s_{0}\in B
then
\mathbb{P}^{s_{0}}_{\mathcal{C}}[\Diamond B]=1
,
otherwise:

\mathbb{P}^{s_{0}}_{\mathcal{C}}[\Diamond B]=\sum\{\!\{\mathbb{P}_{\mu}(\pi)\mid\pi=s_{0}\dots s_{n}\in(S\setminus B)^{+}B\}\!\}.

For brevity, when
B=\{a\}
, we write
\mathbb{P}^{s_{0}}_{\mathcal{\mathcal{C}}}[\Diamond a]
instead of
\mathbb{P}^{s_{0}}_{\mathcal{\mathcal{C}}}[\Diamond\{a\}]
.

Now, we use the weights of targets states to define a weighted reachability value.

Definition 3
(Value of a state)

Given a Markov chain
\mathcal{C}=(S,\mu,T,\rho)
and a state
s_{0}\in S
, the (expected reward) value of
s_{0}
is

\mathrm{Rew}^{s_{0}}_{\mathcal{C}}=\sum_{t\in T}\mathbb{P}^{s_{0}}_{\mathcal{\mathcal{C}}}[\Diamond t]\cdot\rho(t).

Definition 4
(Markov decision processes)

A weighted and parametric Markov decision process (wpMDP) is a tuple

\mathcal{M}=(S,A,X,\delta,T,\rho)
with finite sets

of states;
A

of actions;

We assume, without loss of generality, that there is an extra state

\rho(\mathit{fail})=0

\mathit{fail}
with probability

In this paper, we will work with the following subclasses of wpMDPs.

from the

wp̃MDPs

or weighted
trivially parametric

each transition, a unique variable as polynomial. That is,

probabilistic transition function is
such that

\delta(s,a,s^{\prime})\equiv 0

Since all parameters are trivial in such

(S,A,\Delta,T,\rho)
where

represents all transitions that do not have probability
0
.

p̃MDPs

or (non-weighted) trivially parametric MDPs are both
non-weighted and trivially parametric. We thus omit

and

For the rest of this section, let us fix a wpMDP
\mathcal{M}=(S,A,X,\delta,T,\rho)
.

Definition 5
(Graph preserving valuation, from
[
13
]
)

A valuation
\mathsf{val}:X\rightarrow\mathbb{R}
is graph preserving if the following hold for all

s\in(S\setminus T),s^{\prime}\in S,a\in A
:

•

probabilities are non-negative:
\delta(s,a,s^{\prime})[\mathsf{val}]\geq 0
,

•

outgoing probabilities induce a distribution:
\sum_{s^{\prime\prime}\in S}\delta(s,a,s^{\prime\prime})[\mathsf{val}]=1
,

•

\delta(s,a,s^{\prime})\not\equiv 0\implies\delta(s,a,s^{\prime})[\mathsf{val}]\neq 0
.

The set of all such graph-preserving valuations is written as
\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}}
.

A graph-preserving valuation of any wpMDP
\mathcal{M}
gives an MDP (with real
probabilities!) that we call
\mathcal{M}[\mathsf{val}]
by substituting each parameter with the corresponding real number and computing the value of the polynomials on each transition. Such an MDP is equivalent to the ones that appear in the literature
[
1
,
15
,
13
]
.

Definition 6
(Strategies)

A (memoryless deterministic) strategy
\sigma
is a function
\sigma:(S\setminus T)\rightarrow A
that maps states to actions. The set of all such deterministic memoryless strategies is written as
\Sigma^{\mathcal{M}}
.

The wpMDP
\mathcal{M}
with a valuation
\mathsf{val}

and strategy
\sigma
induce a Markov chain
\mathcal{M}^{\sigma}_{\mathsf{val}}=(S,\mu,T,\rho)
where
\mu(s,s^{\prime})=\delta(s,\sigma(s),s^{\prime})[\mathsf{val}]
for all
s\in(S\setminus T),s^{\prime}\in S
.

Remark 1

Note that we only consider memoryless deterministic strategies. This is because we are interested in strategies that maximise the
expected reward value for a given valuation. Since all targets
are trapping, one can prove, e.g., by reduction to
quantitative reachability or expected mean payoff
[
1
]
, that
for all valuations, there is an optimal memoryless and deterministic strategy.

2.2
The graph of a wpMDP

It is convenient to work with a graph representation of a
wpMDP. In that regard, we consider states
s
(depicted as circles
\bigcirc
)
and state-action pairs
(s,a)
(depicted as squares
\square
) to be vertices.
We call the vertices in
S_{N}=(S\setminus T)\times A

nature vertices
and we will
use these to denote state-action pairs throughout the paper. We use
V=S\cup S_{N}
to denote the set of vertices of a wpMDP. The graph

\mathcal{G}(\mathcal{M})=(V,E)
of a wpMDP is thus a bipartite graph with
S
and

S_{N}
being the two partitions. We define the set of edges as follows.

\displaystyle E={}

\displaystyle\{(s,(s,a))\in S\times S_{N}\mid\exists s^{\prime}\in S\setminus\{\mathit{fail}\}:\delta(s,a,s^{\prime})\not\equiv 0\}

\displaystyle{}\cup\{((s,a),s^{\prime})\in S_{N}\times S\mid\delta(s,a,s^{\prime})\not\equiv 0\}

That is, there is an edge from a state to a nature vertex if the nature vertex has that state as the first component of the tuple and if it can reach some state other than
\mathit{fail}
with non-zero probability; there is one from a nature vertex to a state if the polynomial on the corresponding transition is not syntactically zero.

Let

\mathsf{val}\in\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}}
be a graph-preserving valuation
and
\sigma\in\Sigma^{\mathcal{M}}
a strategy.
We now define the
(reward) value
of a vertex in

\mathcal{G}(\mathcal{M})
with respect to
\mathsf{val}
and
\sigma
.

\mathrm{Rew}^{\sigma}_{\mathcal{M}[\mathsf{val}]}(v)=\begin{cases}\sum_{s^{\prime}\in vE}\delta(s,a,s^{\prime})[\mathsf{val}]\cdot\mathrm{Rew}^{\sigma}_{\mathcal{M}[\mathsf{val}]}(s^{\prime})&\text{if }v=(s,a)\in S_{N}\\
\mathrm{Rew}^{v}_{\mathcal{M}_{\mathsf{val}}^{\sigma}}&\text{otherwise}\end{cases}

Further, we write
\mathrm{Rew}^{*}_{\mathcal{M}[\mathsf{val}]}(v)
for the value
\max_{\sigma\in\Sigma^{\mathcal{M}}}\mathrm{Rew}^{\sigma}_{\mathcal{M}[\mathsf{val}]}(v)
, i.e. when the strategy is chosen to
maximise the value of the vertex. We use
\mathrm{Rew}^{\sigma}_{\mathsf{val}}
and
\mathrm{Rew}^{*}_{\mathsf{val}}
when the wpMDP being referred to is clear from context.

Remark 2

In the case of pMDPs and p̃MDPs,
\mathrm{Rew}^{\sigma}_{\mathcal{M}[\mathsf{val}]}(v)=\mathbb{P}^{v}_{\mathcal{\mathcal{M}_{\mathsf{val}}^{\sigma}}}[\Diamond\mathit{fin}]
. The reader can easily verify this by looking at the definition of reward.

In
Fig.

2a

\mathsf{val}=\{x=0.6,y=0.28\}

is a graph-preserving one. We then get
\mathrm{Rew}^{*}_{\mathsf{val}}(q,a)=1-0.28=0.72
and

\mathrm{Rew}^{*}_{\mathsf{val}}(q,b)=0.6(4)=2.4
. Hence, the optimal strategy for state

will
be to choose action

\mathrm{Rew}^{*}_{\mathsf{val}}(q)=2.4

\mathrm{Rew}^{*}_{\mathsf{val}}(p)=\mathrm{Rew}^{*}_{\mathsf{val}}(p,a)=2(0.28)+(2(0.6)^{2}-0.28)\mathrm{Rew}^{*}_{\mathsf{val}}(q)=1.616

2.3
The never-worse relation

Let
\mathcal{M}=(S,A,X,\delta,T,\rho)
be a wpMDP and

\mathcal{G}(\mathcal{M})=(V,E)
. We will
now take the never-worse relation (NWR)
[
15
]
and generalise it to take
into account polynomials on transitions and weighted target
states.

Definition 7
(Never-worse relation for wpMDPs)

A subset
W\subseteq V
of vertices is
never worse
than a vertex
v\in V
, written
v\trianglelefteq W
, if and only if:

\forall\,\mathsf{val}\in\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}},\exists\,w\in W:\mathrm{Rew}^{*}_{\mathsf{val}}(v)\leq\mathrm{Rew}^{*}_{\mathsf{val}}(w).

We write
v\sim w
if
v\trianglelefteq\{w\}
and
w\trianglelefteq\{v\}
, and
\tilde{v}
for the equivalence class of
v
.

For brevity, we write
v\trianglelefteq w
instead of
v\trianglelefteq\{w\}
.
For two subsets
U,W\subseteq V
, we write
U\trianglelefteq W
if and only if

U\neq\emptyset
and
u\trianglelefteq W
for all
u\in U
.

Example 2

In
Fig.

2a
, we have
p\trianglelefteq q
. This is because the constraints
2x^{2}-y+2y=1
and
0<2y<1
on any graph preserving valuation ensure that
\frac{1}{2}<x
. Thus,
\mathrm{Rew}^{*}_{\mathsf{val}}(q)=\mathrm{Rew}^{*}_{\mathsf{val}}(q,a)>2
. Now, the value of
p
will be a convex combination of
1
and
\mathrm{Rew}^{*}_{\mathsf{val}}(q)
. Hence, it’s value will be at most the value of
q
.

3
From Weighted to Non-Weighted MDPs

In this section, we show that we can efficiently transform any wpMDP
into a non-weighted one with a superset of states and such that the NWR is preserved.
Technically, we have two reductions: one to transform wpMDPs into pMDPs and one to transform wp̃MDPs into p̃MDPs. The former is easier but makes use of the non-trivial polynomials labelling transitions while the latter is more involved.
It follows that algorithms and complexity upper-bounds for the NWR as studied in
[
15
]
can be applied to the trivially parametric weighted case.

Remark 3

Below, we will make the assumption that the target states all have distinct weights. That is
T=\{t_{0},\dots,t_{n}\}
with
0=\rho(t_{0})<\rho(t_{1})<\dots<\rho(t_{n})
. This is no loss of generality. Indeed, if
t_{i}
and
t_{j}

\rho(t_{i})=\rho(t_{j})
then, because all target states are trapping, we can add (on any action
a\in A
) a transition such that
\delta(t_{i},a,t_{j})=1
and remove remove
t_{i}
from
T
. This can be realised using logarithmic space, does not add new states, and it clearly preserves the NWR.

Experiments

In this section, we show the results of the experiments that we have conducted to
assess the effectiveness of the techniques described in the previous sections.
We first motivate the research questions that we wish to answer using the
experiments. Then, we describe the models that we have used during the experiments,
including the pre-processing steps that were performed. Next, we describe the
different setups in which our techniques have been applied to the selected and
pre-processed models. Finally, we discuss the results that we have obtained during
the experiments. Everything needed to re-run our experiments is in
[
8
]
.

We approach our experiments with the following research questions in mind.

Q1.

Is the NWR really useful in practice?

Q2.

Does our under-approximation give us significant reductions in the size of some models? How do these reductions compare to the known reductions?

Q3.

Does the under-approximation yield reductions in early iterations?

Note that the first question is (intentionally) vague. To approach it, we thus focus on the more concrete two that follow. Namely, for the under-approximation, we want to know whether we can reduce the size of common benchmarks and, moreover, whether such reduction in size is obtained through a small number of applications of our inference rules. On the one hand, a positive answer to Q2 would mean the NWR is indeed useful as a preprocessing step to reduce the size of an MDP. On the other hand, a positive answer to Q3 would imply that a small number of applications of our inference rules is always worth trying.

7
Conclusions

We have extended the never-worse relation to the quantitative reachability
setting on parametric Markov decision processes. While the complexity of
deciding the relation is relatively high (
\mathbf{co}
\mathbf{ETR}
-complete), efficient
under-approximations seem promising. We believe that the relation could be
made more applicable by exploring the computation of such under-approximations
in an on-the-fly fashion such as, for instance, on-the-fly MEC algorithms
[
3
]
. The following questions also warrant futher (empirical) study: What kind of MDPs have large reductions under the NWR? What do the reduced MDPs look like? What kinds of states are detected and removed by the NWR under-approximations?

As additional future work,
we think it is worthwhile to study approximations that are (more)
efficient when the MDP is encoded as a reduced ordered binary decision diagram
(BDD) or in a particular modelling language such as the PRISM language. For the latter, an initial work in this direction is
[
20
]
.

We give an alternate equivalent definition of
\mathrm{Rew}^{*}_{\mathsf{val}}(v)
by using Bellman equations which will be useful in proofs:

Lemma 5

Consider a wpMDP
\mathcal{M}=(S,A,X,\delta,T,\rho)
. Let
\boldsymbol{Z}
denote the set of all vertices that cannot reach
T
. The vector
(x_{v})_{v\in V}
with
x_{p}=\mathrm{Rew}^{*}_{\mathcal{M}[\mathsf{val}]}(v)
is the unique solution of the following system of equations:

•

If
v\in T
then
x_{v}=\rho(v)
;

•

If
v\in\boldsymbol{Z}
then
x_{v}=0
;

•

If
v\in S_{N}\setminus(T\cup\boldsymbol{Z})
then
x_{v}=\sum_{s\in vE}\delta(v,s)[\mathsf{val}]\cdot x_{s}
;

•

If
v\in S\setminus(T\cup\boldsymbol{Z})
then
x_{v}=\max_{a\in vE}x_{a}
.

The following lemma observes the relation between the optimal rewards of states and state-action pairs to their (immediate) successors.

Lemma 6

For a wpMDP
\mathcal{M}=(S,A,X,\delta,T,\rho)
and a valuation
\mathsf{val}\in\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}}
, for all
u\in S
we have

\mathrm{Rew}^{*}_{\mathsf{val}}(u)=\max_{a\in A}\mathrm{Rew}^{*}_{\mathsf{val}}(u,a),

and for all
u\in S_{N}

\min_{(u,a)\in uE}\mathrm{Rew}^{*}_{\mathsf{val}}(u,a)\leq\mathrm{Rew}^{*}_{\mathsf{val}}(u)\leq\max_{(u,a^{\prime})\in uE}\mathrm{Rew}^{*}_{\mathsf{val}}(u,a^{\prime}),

where the equality holds iff all the vertices in
uE
have the same value.

The proof directly follows from the equivalent definition of reward values.

\displaystyle\mathbb{P}^{e}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]

\displaystyle=\sum_{u\in U}\mathbb{P}^{e}_{\mathcal{M}}[(S\setminus U)\,\mathsf{U}\,u]\cdot\mathbb{P}^{u}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]

\displaystyle=\sum_{u\in U}\mathbb{P}^{e}_{\mathcal{M}}[(S\setminus U)\,\mathsf{U}\,u]\cdot\mathbb{P}^{e}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]

\displaystyle=\mathbb{P}^{e}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]\cdot\sum_{u\in U}\mathbb{P}^{e}_{\mathcal{M}}[(S\setminus U)\,\mathsf{U}\,u]

\mathit{fail}

\mathit{fail}

Since we have shown that each equivalence class has exactly one exit, it immediately follows that each state in the equivalence class must almost surely reach the unique exit.

The proof of the upper bound is the same as the proof of

Lemma 18

For any equivalence partition
\{S_{0},\dots,S_{m}\}

\mathsf{val}\in\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}}

\mathsf{val}(s,s^{\prime})=\begin{cases}0.5&\text{if $s,s^{\prime}\in S_{i}$ for some $0<i<m$};\\

\varepsilon_{i}&\text{if $s\in S_{i}$ and $s^{\prime}\in S_{i-}$ for some $0<i<m$}.\\

That is, all the edges within the same layer get probability

be defined as above. Then for any

Both bounds are proved by induction. First, we will prove the lower bound by inducting starting from the top layer

. Any exit in this layer has an edge to
\mathit{fin}
with probability

(and the other edge might be to
\mathit{fail}
). Thus, the bound for all vertices in
S_{m-1}
holds by

17
. Now, assume that the bound

with

. Let

be an exit in

\displaystyle\mathbb{P}^{s}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]

\displaystyle\geq(1-\varepsilon_{i})\min_{j>i}\{\mathbb{P}^{s^{\prime}}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]|s^{\prime}\in S_{j}\}

\displaystyle\geq(1-\varepsilon_{i})\min_{j>i}\{(1-\varepsilon_{m-1})\cdot\dots\cdot(1-\varepsilon_{j})\}

\displaystyle=(1-\varepsilon_{i})(1-\varepsilon_{m-1})\cdot\dots\cdot(1-\varepsilon_{i+1}).

Thus, the lower bound holds for all exits in the layer and by
Lemma

17
, it holds for all vertices in the layer.

Now, to show the upper bound, we induct starting from the lowest layer
S_{1}
. Any exit in this layer goes to
\mathit{fail}
with probability
\varepsilon_{1}
and thus its value can be at most
1-\varepsilon_{1}
. By
Lemma

17
this bound holds for all vertices in
S_{1}
. Now, assume the bound
\mathbb{P}^{s^{\prime}}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]\leq 1-\varepsilon_{1}\cdot\dots\cdot\varepsilon_{j}
holds for any

with

. Let
s
be an exit in
S_{i}
. In the best case scenario, it can have an edge to
\mathit{fin}
with probability

and the “best” vertex in

with probability

\displaystyle\mathbb{P}^{s}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]

\displaystyle\leq 1-\varepsilon_{i}+\varepsilon_{i}\cdot\max_{j<i}\{\mathbb{P}^{s^{\prime}}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]|s^{\prime}\in S_{j}\}

\displaystyle\leq 1-\varepsilon_{i}+\varepsilon_{i}\cdot\max_{j<i}\{1-\varepsilon_{1}\cdot\dots\cdot\varepsilon_{j}\}

\displaystyle=1-\varepsilon_{i}+\varepsilon_{i}\cdot(1-\varepsilon_{1}\cdot\dots\cdot\varepsilon_{i-1})

\displaystyle=1-\varepsilon_{1}\cdot\dots\cdot\varepsilon_{i}.

Thus, the upper bound for all the exists and hence it also holds for all states in

by

Back to the proof of the Lemma, it suffices to show the existence of

is greater than the upper bound of the layer

\displaystyle(1-\varepsilon_{m-1})\cdot\dots\cdot(1-\varepsilon_{i})

\displaystyle>(1-\varepsilon_{i})^{m-i}

\displaystyle\varepsilon_{i}>\varepsilon_{j}\text{ for }j>i

\displaystyle>(1-\varepsilon_{i})^{n}

\displaystyle 1-\varepsilon_{1}\cdot\dots\cdot\varepsilon_{i-1}

\displaystyle<1-\varepsilon_{i-1}^{i-1}

\displaystyle\varepsilon_{i-1}<\varepsilon_{j}\text{ for }j<i

Now, we can easily choose

Lemma 19

Any valuation
\mathsf{val}\in\mathsf{Val}^{\mathrm{gp}}_{\mathcal{M}}
induces an equivalence partition
\{S_{0},\dots,S_{m}\}
such that two states

are in the same layer iff
\mathbb{P}^{s}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]=\mathbb{P}^{s^{\prime}}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]
.

We define the partition by grouping all the vertices with the same reward into the same layer and then ordering the layers by the rewards of the states in them. That is, layers with higher rewards are above the layers with lower rewards. One can easily check that this is indeed an equivalence partition.

Definition 13
(Finest valuation)

A graph preserving valuation
\mathsf{val}
is a finest valuation if for all
u,v\in S
,
\mathbb{P}^{u}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]=\mathbb{P}^{v}_{\mathcal{M}^{\mathsf{val}}}[\Diamond\mathit{fin}]
iff

.

Definition 14
(Finest partition)

A finest partition is an equivalence partition such that the number of layers in the partition is exactly the number of equivalence classes.

Lemma 20

A finest valuation always exists for a Markov chain.

Proof

Suppose, that a finest valuation does not exist. Let
\mathsf{val}
be a valuation such that there does not exist any other valuation such that the induced equivalence partition (
Lemma

19
) has more layers than the one induced by
\mathsf{val}
. Let
\{S_{0},\dots,S_{m}\}
be the equivalence partition induced by
\mathsf{val}
. Since
\mathsf{val}
is not a finest valuation, there exists a layer, say
S_{i}
, with at least two equivalence classes. Now, we observe that at least two of these equivalence classes must have states that exit
S_{i}
(otherwise, if there was only one equivalence class with exits, all other equivalence classes on that layer would almost surely reach this equivalence class, and by
Lemma

14
, all of these equivalence classes would be equivalent to the one with the exits, which is not possible). We now move one of these equivalence classes with exits to a new layer
S_{i^{\prime}}
which is placed in between
S_{i}
and
S_{i+1}
. We call the layer obtained by removing
S_{i^{\prime}}
as
S_{i^{\prime\prime}}
. Note that each exit has one edge in an equivalence partition has an going up and one edge going down. This along with the fact that any state can almost surely reach the set of all exits, ensures that if a state
u
is on a layer above
v
in some equivalence partition, then there are state-disjoint paths from
u
to
\mathit{fin}
and
v
to
\mathit{fail}
. Consider the new partition
\{S_{0},\dots,S_{i^{\prime\prime}},S_{i^{\prime}},S_{i+1},\dots,S_{m}\}
(which is not necessarily an equivalence partition). Let
s
be an exit in
S_{i^{\prime}}
which was also an exit in
S_{i}
in the original partition. That is,
s
has an edge to
S_{i^{\prime}+}
and one to
S_{i^{\prime\prime}-}
. We claim that
s
is the unique vertex with outgoing edges from
S_{i^{\prime}}
(i.e. its equivalence class). Suppose there is another vertex
s^{\prime}
that exits
S_{i^{\prime}}
, then it must have an edge to
S_{i^{\prime\prime}}
or lower. Thus, there are disjoint paths from
s
to
\mathit{fin}
and
s^{\prime}
to fail. By making the probabilities on these paths close to
1
, we can make the reward of

close to
1
and
s^{\prime}
close to
0

is a “valid” layer of an equivalence partition. We can use a similar argument to show that any equivalence class in

which has an exit from

must have a unique vertex with edges outside the equivalence class. But there might be states in the original

that had an edge to a state in

are still valid layers in each step. Let

be one of the equivalence classes which had an edge to
S_{i^{\prime}}
. We move

between
S_{i^{\prime\prime}}
and
S_{i^{\prime}}
. Using the argument from above, this state going up to
S_{i^{\prime}}
and down to

is the unique exit of this layer. We continue doing this until there are no more new exits (apart from the exits originally in
S_{i}
) in

. This gives us an equivalence partition which is finer than the original one. Now, using

, we can get a valuation
\mathsf{val}^{\prime}
finer than

which is a contradiction to the assumption.∎

Now, we use this finest valuation to get a finest partition and use this to show that each equivalence class has a unique state with edges going out of the equivalence class.

Lemma 21

For any equivalence class
U\subset S\backslash T
, there exists a unique state
s\in S
such that
sE\not\subseteq U
.

Proof

Let
\mathsf{val}
be a finest valuation. Let
\{S_{0},\dots,S_{n}\}
be a finest partition. Thus, each equivalence class has its own layer. Let

for some

has two exits

Now, using

One can easily give a polynomial time algorithm for this by checking almost-sure reachability between pairs of vertices.

Computing and collapsing the NWR equivalence classes of a Markov chain can be done in polynomial time.
