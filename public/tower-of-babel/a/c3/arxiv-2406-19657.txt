LLMEasyQuant: Scalable Quantization for Parallel and Distributed LLM Inference
Dong Liu, Yanxuan Yu

Abstract
As large language models (LLMs) grow in size and deployment scale, quantization has become an essential technique for reducing memory footprint and improving inference efficiency. However, existing quantization toolkits often lack transparency, flexibility, and system-level scalability across GPUs and distributed environments. We present LLMEasyQuant , a modular, system-aware quantization framework designed for efficient, low-bit inference of LLMs on single-node multi-GPU, multi-node, and edge hardware. LLMEasyQuant supports a wide range of quantization methods—including Symmetric Quantization, ZeroQuant, SmoothQuant, and SimQuant—with unified interfaces for per-layer calibration, bitwidth assignment, and runtime adaptation. It integrates fused CUDA kernels with NCCL-based distributed synchronization and supports both static and online quantization. Empirical results show that LLMEasyQuant can achieve substiantial speed up in GEMM execution, HBM load time, and near-linear multi-GPU scaling. Ablation studies further validate its ability to balance latency, memory, and accuracy under diverse deployment conditions. LLMEasyQuant offers a practical quantization serving system for scalable, hardware-optimized LLM inference.

ZeroQuant: Zero-Point Quantization

ZeroQuant
[
YYAZ+22
]
leverages asymmetric linear mapping to preserve the exact representation of sparse zero values, which are frequent in KV cache and attention structures of LLMs. This method computes the quantization step as

\Delta=\frac{\max(X)-\min(X)}{2^{b}-1+\epsilon},\quad z=\text{round}\left(-\frac{\min(X)}{\Delta}\right)

and encodes values via

Q(x)=\text{clip}\left(\left\lfloor\frac{x}{\Delta}+z\right\rfloor,-128,127\right),\quad\hat{x}=\Delta(Q(x)-z)

This approach is implemented using a fused CUDA kernel where scale and zero-point computation, clamping, and quantization are performed in a single device pass. Communication across devices is optimized using NCCL’s ring-reduce collectives over RDMA, enabling distributed quantized model loading and serving.

Symmetric 8-bit and Layer-by-Layer Quantization

We now present a system-level design of symmetric 8-bit quantization combined with layer-by-layer scheduling. This design is critical in enabling accurate and hardware-friendly quantization for large-scale Transformer models such as LLaMA, Qwen, and DeepSeek. Our implementation targets Tensor Core acceleration with device-aware memory allocation and multi-GPU synchronization.

For a given transformer layer
\ell
, we compute the symmetric quantization scale based on the channel-wise maximum absolute weight value. Specifically, we define:

s_{\ell}=\frac{\max(|W_{\ell}|)}{2^{b-1}-1+\epsilon}

(16)

Q(W_{\ell})=\text{clip}\left(\left\lfloor\frac{W_{\ell}}{s_{\ell}}\right\rceil,-2^{b-1},2^{b-1}-1\right)

(17)

\hat{W}_{\ell}=s_{\ell}\cdot Q(W_{\ell})

(18)

This transformation ensures that the quantized tensor lies within a symmetric integer range and aligns with NVIDIA Tensor Core INT8 GEMM pipelines.

To quantify the quantization error, we define the loss between the full-precision and quantized layer output as:

\mathcal{L}_{\text{quant}}^{(\ell)}=\left\|f_{\ell}(x;W_{\ell})-f_{\ell}(x;\hat{W}_{\ell})\right\|_{2}^{2}

(19)

where
f_{\ell}
denotes the forward function of the
\ell
-th layer, which may include layer normalization, attention, and MLP operations. The quantization schedule aims to minimize this loss jointly with a hardware-aware cost proxy:

\min_{s_{\ell},b_{\ell}}\quad\mathcal{L}_{\text{quant}}^{(\ell)}+\lambda\cdot\Phi(b_{\ell})

(20)

where
\Phi(b_{\ell})
represents quantization cost such as latency, HBM transfer bandwidth, or energy, and
\lambda
balances accuracy and efficiency.

In our system implementation, each transformer layer is quantized independently in a distributed pipeline. We utilize per-GPU quantization kernels that operate on local weight shards. The scale factors
s_{\ell}
are stored in constant memory to reduce redundant global memory access. Quantized weights are first placed in HBM and are then loaded into shared SRAM using cooperative warp-tiling during kernel launch.

The kernel launch uses a persistent thread model where each thread block operates on a fixed tile of the weight matrix. During quantized inference, inputs are fetched as FP16 tensors, and weights are dequantized from INT8 using the preloaded
s_{\ell}
via fused multiply-add (FMA) instructions. This enables direct integration with CUTLASS-backed MMA884 kernels on Ampere or Hopper architectures.

To support multi-GPU quantization, LLMEasyQuant uses NCCL-based collectives. Each worker independently computes
s_{\ell}
for its assigned layers, followed by an
all_gather
communication to share scale factors across nodes. Quantized weight shards are optionally reduced or synchronized depending on whether model parallelism or pipeline parallelism is used. Inter-node communication leverages RDMA-backed links when available, reducing latency for synchronizing quantization metadata.

To further reduce numerical variance, we adopt percentile-based clipping during
s_{\ell}
estimation:

s_{\ell}=\frac{\max(\text{Percentile}(|W_{\ell}|,p))}{2^{b-1}-1+\epsilon}

(21)

where

is typically chosen in the range of 99.9 to 99.99 to mitigate outlier influence. This clipping is applied per layer and per channel and fused into the quantization kernel at compile time.

SimQuant: A Hardware-Aware Dynamic Quantization Framework

SimQuant
[
HKM+24
]
is a recent quantization strategy proposed in the context of KV cache compression for large language models with extremely long sequence lengths. Unlike fixed-point quantization schemes that statically compute quantization parameters based on global or per-layer statistics, SimQuant dynamically tailors the quantization interval to the per-batch distribution of intermediate tensors. This enables precise alignment with activation sparsity and facilitates near-lossless INT8 approximation of high-variance KV cache tensors.

Let
X\in\mathbb{R}^{B\times D}
be the matrix to be quantized (e.g., Key or Value block in the KV cache), where
B
is the number of tokens and
D
is the feature dimension. SimQuant first computes channel-wise min/max bounds:

v_{\min}^{(d)}=\min_{i}X_{i,d},\quad v_{\max}^{(d)}=\max_{i}X_{i,d},\quad\forall d\in\{1,\dots,D\}

(22)

From this, the scale factor
s_{d}
and zero-point
z_{d}
per channel are computed as:

s_{d}=\frac{2^{b}-1}{v_{\max}^{(d)}-v_{\min}^{(d)}+\epsilon},\quad z_{d}=\left\lfloor-v_{\min}^{(d)}\cdot s_{d}\right\rceil

(23)

where
b
is the target bitwidth (typically
b=8
), and
\epsilon
is a small constant for numerical stability. The quantized tensor is given by:

X^{(\text{quant})}_{i,d}=\text{clip}\left(\left\lfloor X_{i,d}\cdot s_{d}+z_{d}+0.5\right\rfloor,0,2^{b}-1\right)

(24)

To reconstruct the original float32 values during inference, a dequantization kernel performs:

X^{(\text{dequant})}_{i,d}=\frac{X^{(\text{quant})}_{i,d}-z_{d}}{s_{d}}

(25)

SimQuant is designed for deployment on memory-hierarchical hardware. Quantized KV tensors are stored in HBM using INT8 layout, while the min/max metadata vectors
\{v_{\min},v_{\max}\}
and scale/zero-point vectors
\{s_{d},z_{d}\}
are stored in shared memory or constant memory depending on CUDA kernel design. For inference, the dequantization is performed in real time in SRAM via fused CUDA kernel using a persistent-thread strategy that minimizes redundant memory fetch.

SimQuant also supports optional vector-wise or group-wise quantization granularity. For instance, a vector can be divided into blocks of size
g
, and each block
(d_{0}:d_{0}+g)
shares the same
(s_{g},z_{g})
parameters:

s^{(g)}=\frac{2^{b}-1}{\max X^{(g)}-\min X^{(g)}+\epsilon}

(26)

This coarser quantization layout reduces metadata overhead while preserving quantization fidelity for dense tokens. In distributed inference scenarios, SimQuant scales across multiple GPUs via partitioned quantization of each layer’s KV cache, followed by AllReduce or AllGather of scale vectors across ranks using NCCL or InfiniBand.

SmoothQuant: Smoothing-Aware Quantization with Weight-Attenuated Rescaling

SmoothQuant
[
XLS+23
]
is a post-training quantization (PTQ) technique specifically designed to address the challenge of activation outliers in transformer-based large language models. Unlike traditional methods that directly quantize both weights and activations independently, SmoothQuant redistributes the quantization burden from activations—which often exhibit heavy-tailed distributions—to weights, which are generally more compressible and robust under scaling transformations.

Let
X\in\mathbb{R}^{B\times D}
denote the activation tensor and
W\in\mathbb{R}^{D\times D^{\prime}}
the associated weight matrix in a linear or attention projection layer. SmoothQuant performs a linear transformation that preserves the output of the original matrix multiplication while reshaping the distributions to facilitate quantization. Given a smoothing parameter
\alpha\in[0,1]
, the transformation is defined per-channel as:

s_{j}=\left(\frac{\text{max}(|X_{j}|)^{\alpha}}{\text{max}(|W_{j}|)^{1-\alpha}}+\epsilon\right)

(27)

\tilde{X}_{j}=\frac{X_{j}}{s_{j}},\quad\tilde{W}_{j}=W_{j}\cdot s_{j}

(28)

Y=\tilde{X}\cdot\tilde{W}=X\cdot W

(29)

where
j
indexes the feature/channel dimension and
\epsilon
is a small constant to prevent division by zero. This transformation is algebraically equivalent to the original operation but results in a smoother distribution for the input
X
, which significantly reduces dynamic range and improves quantization robustness.

During inference, both
\tilde{X}
and
\tilde{W}
are quantized to INT8 using symmetric or asymmetric quantization operators. On hardware such as NVIDIA A100/H100, quantized weights are prepacked into 4x4 MMA tiles and stored in HBM in fused FP16-INT8 layouts. The transformation and quantization are performed in a fused CUDA kernel where:
-
s_{j}
is precomputed and stored in constant memory,
- activation tiles are scaled on-the-fly before INT8 conversion,
- weight tiles are pre-scaled and quantized offline,
- INT8 tensor cores are used for GEMM, with optional dequantization in shared SRAM.

SmoothQuant is natively parallelizable across layers and channels, and integrates seamlessly with ONNXRuntime-Quant or TVM-based deployment backends. It also supports distributed training quantization via per-rank activation rescaling, using NCCL or RDMA to broadcast
s_{j}
across devices in model parallel inference.

VII
Conclusion

We present
LLMEasyQuant
, a modular and system-efficient quantization toolkit tailored for distributed and GPU-accelerated LLM inference. LLMEasyQuant supports multi-level quantization strategies—including SimQuant, SmoothQuant, and ZeroQuant—with native integration of per-channel scaling, mixed-precision assignment, and fused CUDA kernels optimized for Tensor Core execution. It enables low-bitweight computation across GPU memory hierarchies, leveraging shared SRAM for dequantization, HBM for tile-pipelined matrix operations, and NCCL-based collective communication for cross-device consistency. Evaluated under GPT-style LLMs, LLMEasyQuant reduces quantization-induced perplexity while sustaining throughput across 8-GPU distributed environments. Compared to static INT8 baselines, it achieves nference memory reduction and improves latency in decode-heavy regimes—without requiring retraining or model restructuring.
