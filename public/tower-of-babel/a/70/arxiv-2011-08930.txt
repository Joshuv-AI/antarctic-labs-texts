Distributed Online Learning with Multiple Kernels
Jeongmin Chae, and Songnam Hong

Abstract
In the Internet-of-Things (IoT) systems, there are plenty of informative data provided by a massive number of IoT devices (e.g., sensors). Learning a function from such data is of great interest in machine learning tasks for IoT systems. Focusing on streaming (or sequential) data, we present a privacy-preserving distributed online learning framework with multiple kernels (named DOMKL). The proposed DOMKL is devised by leveraging the principles of an online alternating direction of multipliers (OADMM) and a distributed Hedge algorithm. We theoretically prove that DOMKL over T T time slots can achieve an optimal sublinear regret 𝒪 ⁡ ( T ) {\cal O}(\sqrt{T}) , implying that every learned function achieves the performance of the best function in hindsight as in the state-of-the-art centralized online learning method. Moreover, it is ensured that the learned functions of any two neighboring learners have a negligible difference as T T grows, i.e., the so-called consensus constraints hold. Via experimental tests with various real datasets, we verify the effectiveness of the proposed DOMKL on regression and time-series prediction tasks.

Introduction

The Internet-of-Things (IoT) systems consist of a massive number of machine-type devices (e.g., sensors) which can be employed to monitor and analyze various cyber-physical systems such as smart cities, smart grids, connected cars, mobile healthcare, intelligent energy management, traffic management, and so on
[
1
,
2
,
3
]
. In order to accomplish sophisticated tasks, the IoT systems are expected to sense, learn, and adapt to sequentially arriving measurements. These can be efficiently performed via machine learning techniques
[
4
,
5
,
6
]
, where a large and complex data can be efficiently analyzed in a timely fashion. In particular, this paper focuses on learning a function as it is of great interest in various machine learning tasks such as classification, regression, clustering, dimensionality reduction, and reinforcement learning
[
7
,
8
,
9
,
10
]
. In the most of existing works, function learning tasks are performed in a centralized fashion with the assumption that all the data (possibly acquired by distributed IoT devices) are gathered in the cloud (or central processor). This assumption, however, is not applicable for the IoT systems due to the limitations of communication bandwidth, power consumption, latency, and privacy concern. Also, data privacy has become a growing concern in IoT systems. Multiple cases of data leakage and misuse have demonstrated that the centralized processing of learning a function comes at high risk for the end users privacy. As IoT devices usually collect data in privacy environments, these concerns hold particularly strong. Thus, a privacy-preserving distributed function learning, where training data is stored locally in every distributed device (or learner) without revealing the local data to a cloud, has been investigated
[
11
,
12
,
13
,
14
]
. Moreover, in many real-world applications, function learning tasks are expected to be performed in an online fashion. For instance, online learning is required when data arrive sequentially such as solar power prediction
[
15
]
, time series prediction
[
16
]
, energy-saving in smart home
[
17
]
, and when the large number of data makes it impossible to carry out data analytic in batch form
[
18
]
. Motivated by this, we investigate a distributed function learning framework suitable for streaming (or sequential) data.

Supervised function learning tasks, which are closely related to the subject of this paper, are formulated as follows. Given the training data
\{({\bf x}_{t},y_{t}):t=1,...,T\}
with features
{\bf x}_{t}\in\mbox{\bb R}^{d}
and labels
y_{t}\in\mbox{\bb R}
, the primary goal of these tasks is to learn (or estimate) a function
f:\mbox{\bb R}^{d}\rightarrow\mbox{\bb R}
which minimizes the accumulate loss
\frac{1}{T}\sum_{t=1}^{T}{\cal L}(f({\bf x}_{t}),y_{t})
,
where
f({\bf x}_{t})=\hat{y}_{t}
and
{\cal L}(\cdot,\cdot)
represent an estimated label and a loss function, respectively. This challenging problem can be tractable with the restriction that
f(\cdot)
belongs to a well-structured function space such as reproducing kernel Hilbert space (RKHS)
[
19
]
. Such function learning is called kernel-based learning. Definitely the accuracy of a kernel-based learning fully relies on a preselected kernel, which is determined manually either by a task-specific priori knowledge or by some intensive cross-validation process.
Multiple kernel learning (MKL), using a predetermined set of kernels (called a kernel dictionary), is more powerful as it can enable a data-driven kernel selection from a given dictionary. That is, a linear (or non-linear) combination of multiple kernels is optimized as the consequence of a function learning process
[
20
]
.

Recently,
online
MKL (OMKL) has been proposed, which seeks the optimal combination of multiple kernel functions in an online fashion. Two popular approaches to learn the best kernel combination are the Hedge algorithm and online gradient descent (OGD) algorithm
[
21
,
22
]
. It was shown in
[
18
,
21
,
23
,
24
]
that OMKL can yield an attractive accuracy performance and enjoy a great flexibility compared with single-kernel online learning. Whereas, OMKL generally suffers from a high computational complexity as the dimension of optimization variables grow with time (i.e., the number of data
T
)
[
7
,
25
]
. Recently in
[
23
]
, this problem has been addressed by applying a random feature (RF) approximation
[
26
]
to OMKL. In the the resulting method, named RF-based OMKL, the dimension of the optimization variables can be determined irrespective of the number of data
T
. Another advantage of RF-based OMKL is that learning a function can be solved using the powerful toolboxes from online convex optimization and online learning developed under vector spaces
[
23
]
. Furthermore, an extension to active learning framework has been investigated in
[
24
]
. Despite the success of kernel-based learning, the above methods cannot be applicable to distributed learning tasks caused in various IoT systems, which is the primary motivation of this work.

Contributions:
We consider the distributed learning setting, where measurements are made locally at each learner (e.g., IoT device) and the communication only occurs among neighboring learners. For this system, inspired by the success of kernel-based learning, we propose a distributed online learning framework with multiple kernels. The proposed method is named DOMKL. In the proposed DOMKL, each learner estimates its own function collaboratively with neighboring learners subject to the so-called consensus constraints. That is, neighboring learners aim at estimating an identical function by sharing their local information, while due to preserving a privacy, it is prohibitive to exchange local data directly. We contribute to this subject in the following ways:

•

We extend the principles of the centralized OMKL
[
23
,
24
]
into a distributed online learning framework. Thus, the proposed DOMKL also has the
scalability
in terms of the number of data, differently from the other multiple kernel learning methods, which makes it suitable for streaming data.

•

In DOMKL, each kernel function at every learner is learned via online alternating direction method of multipliers (OADMM), by only exchanging the latest estimate with neighboring learners. Also, the weight for combining kernel functions is updated using the principle of hedge algorithm in a distributed way. We remark that by sharing gradients only,
privacy
at every learner is certainly ensured.

•

We theoretically prove that DOMKL can guarantee a sublinear regret
{\cal O}(\sqrt{T})
with respect to both learning accuracy and constraint violation (i.e., discrepancy). We notice that the learning accuracy of DOMKL is in the same order at that of the centralized OMKL in
[
23
,
24
]
. Specifically, our analysis reveals that a learned function at every learner almost achieves the performance of the best kernel function in the kernel dictionary, and has a negligible difference from those of its neighboring learners.

•

Via numerical tests with real datasets, we verify the effectiveness of the proposed DOMKL on regression and time-series prediction tasks, by showing that it achieves the almost same performance of the centralized OMKL.

The remaining part of this paper is organized as follows. In Section
II

In Section

IV
to verify the asymptotic optimality of the proposed methods. In Section
V
, beyond the asymptotic analysis, we demonstrate the effectiveness of the proposed DOMKL via numerical tests with real datasets. Some concluding remarks are provided in Section
VI
.

II
Preliminaries

We briefly review online multiple kernel learning based on random feature (RF) approximation (termed RF-based MKL), which will be used as the foundation of the proposed distributed online learning. Given the training data
\{({\bf x}_{1},y_{1}),...,({\bf x}_{T},y_{T})\}
, where
{\bf x}_{t}\in{\cal X}\subseteq\mbox{\bb R}^{d}
and
y_{t}\in{\cal Y}\subseteq\mbox{\bb R}
, the objective of MKL is to learn a (non-linear) function
f:{\cal X}\rightarrow{\cal Y}
that minimizes the accumulate loss

\frac{1}{T}\sum_{t=1}^{T}{\cal L}(f({\bf x}_{t}),y_{t}),

(1)

where
f({\bf x}_{t})
and
{\cal L}(\cdot,\cdot)
represent an estimated label and a loss function, respectively. In a kernel-based learning
[
20
,
27
,
28
]
, it is assumed that a target function
f({\bf x})
belongs to a reproducing Hilbert kernel space (RKHS) (denoted by
{\cal H}
), namely,
f({\bf x})
can be represented as

f({\bf x})=\sum_{t=1}^{\infty}\alpha_{t}\kappa({\bf x},{\bf x}_{t}),

(2)

where
\kappa({\bf x},{\bf x}_{t}):{\cal X}\times{\cal X}\rightarrow{\cal Y}
is a symmetric positive semidefinite basis function (called kernel), which measures the similarity between
{\bf x}
and
{\bf x}_{t}
. Among various kernels, one representative example is the Gaussian kernel with a parameter
\sigma^{2}
, given as

\kappa({\bf x},{\bf x}_{t})=\exp\left(\frac{-\|{\bf x}-{\bf x}_{t}\|^{2}}{2\sigma^{2}}\right).

(3)

Also, a kernel is said to be
reproducing
if

\langle\kappa({\bf x},{\bf x}_{t_{1}}),\kappa({\bf x},{\bf x}_{t_{2}})\rangle_{{\cal H}}=\kappa({\bf x}_{t_{1}},{\bf x}_{t_{2}}),

(4)

where
\langle\cdot,\cdot\rangle_{{\cal H}}
denotes an inner product defined in the Hilbert space
{\cal H}
. The associated RKHS norm is defined as

\|f\|_{{\cal H}}^{2}\stackrel{{\scriptstyle\Delta}}{{=}}\sum_{t_{1}}\sum_{t_{2}}\alpha_{t_{1}}\alpha_{t_{2}}\kappa({\bf x}_{t_{1}},{\bf x}_{t_{2}}).

(5)

The function learning problem over RKHS can be formulated:

\min_{f\in{\cal H}}\;\frac{1}{T}\sum_{t=1}^{T}{\cal L}(f({\bf x}_{t}),y_{t}).

(6)

We remark that a loss function can be chosen in a task-specific way, e.g., least-square cost for regression and logistic cost for classification. Especially when the number of data is finite (e.g.,
T
training data), the representer theorem in
[
25
]
shows that the optimal solution of (
6
) is represented as

\hat{f}({\bf x})=\sum_{t=1}^{T}\alpha_{t}\kappa({\bf x},{\bf x}_{t}).

(7)

The major drawback of this approach is the curse of dimensionality as the number of parameters
\alpha_{t}
’s (to be optimized) grows with the number of data
T
.

In
[
26
]
, it has been addressed by introducing RF approximation for kernels. As in
[
26
]
, the kernel
\kappa
is assumed to be shift-invariant, i.e.,
\kappa({\bf x}_{t_{1}},{\bf x}_{t_{2}})=\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})
for any
t_{1},t_{2}\in[T]
. Note that Gaussian, Laplacian, and Cauchy kernels satisfy the shift-invariance
[
26
]
. For
\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})
absolutely integrable, its Fourier transform
\pi_{k}({\bf v})
exists and represents the power spectral density. Also, when
\kappa({\bf 0})=1
it can also be viewed as a probability density function (PDF). For a Gaussian kernel in (
3
), we have
\pi_{\kappa}({\bf v})={\cal N}(0,\sigma^{-2}{\bf I})
. Then, the kernel function can be rewritten as

\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})=\mbox{\bb E}\left[\exp\left(j{\bf v}^{{\sf T}}\left({\bf x}_{t_{1}}-{\bf x}_{t_{2}}\right)\right)\right].

(8)

Having a sufficient number of independent and identically distributed (i.i.d.) samples
{\bf v}_{i},\;i\in[D]
from
\pi_{\kappa}({\bf v})
,
\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})
can be well-approximated by the sample mean such as

\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})\approx\frac{1}{D}\sum_{i=1}^{D}\mbox{Re}\left(\exp\left(j{\bf v}_{i}^{{\sf T}}\left({\bf x}_{t_{1}}-{\bf x}_{t_{2}}\right)\right)\right),

(9)

where
\mbox{Re}(a)
denotes the real part of a complex value
a
. Clearly, the accuracy of this approximation grows as the number of samples
D
increases. In numerical tests, a proper
D
will be chosen by considering the accuracy-complexity tradeoff. The approximation in (
9
) can be rewritten as a vector form
\kappa({\bf x}_{t_{1}}-{\bf x}_{t_{2}})={\bf z}^{{\sf T}}({\bf x}_{t_{1}}){\bf z}({\bf x}_{t_{2}})
,
where

{\bf z}({\bf x})=\frac{1}{\sqrt{D}}\left[\sin{{\bf v}_{1}^{{\sf T}}{\bf x}},...,\sin{{\bf v}_{D}^{{\sf T}}({\bf x}),\cos{{\bf v}_{1}^{{\sf T}}{\bf x}},...,\cos{{\bf v}_{D}^{{\sf T}}{\bf x}}}\right]^{{\sf T}}.

(10)

Based on this, the optimal solution
\hat{f}({\bf x})
in (
7
) can be well-approximated as

\hat{f}({\bf x})=\sum_{t=1}^{T}\alpha_{t}{\bf z}^{{\sf T}}({\bf x}_{t}){\bf z}({\bf x})\stackrel{{\scriptstyle\Delta}}{{=}}\hat{\hbox{\boldmath$\theta$}}^{{\sf T}}{\bf z}({\bf x}),

(11)

where the optimization variable
\hat{\hbox{\boldmath$\theta$}}
is a
2D
-vector. Note that its dimension
2D
can be determined irrespective of the number of data
T
.

RF-based kernel learning can be naturally extended into MKL framework, where a target function is formed as a linear (or convex) combination of multiple preselected kernels
\{\kappa_{p}:p\in[P]\}
. From
[
29
]
, the estimated function can be represented as

\hat{f}({\bf x})=\sum_{p=1}^{P}\hat{q}_{p}\hat{f}_{p}({\bf x})\in\bar{{\cal H}},

(12)

where
\bar{{\cal H}}\stackrel{{\scriptstyle\Delta}}{{=}}{\cal H}_{1}\bigotimes{\cal H}_{2}\bigotimes\cdots\bigotimes{\cal H}_{P}
and

\hat{f}_{p}({\bf x})\in{\cal H}_{p}
which is a RKHS induced by the kernel
\kappa_{p}
, and
\hat{q}_{p}\in[0,1]
denotes the combination weight of the associated kernel function
\hat{f}_{p}
. Also, under RF approximation, the kernel functions in (
12
) can be further simplified as

\hat{f}_{p}({\bf x})=\hat{\hbox{\boldmath$\theta$}}_{p}^{{\sf T}}{\bf z}_{p}({\bf x}),

(13)

for
p\in[P]
, where
{\bf z}_{p}({\bf x})
is defined in (
26
) with
D
number of i.i.d. samples from
\pi_{\kappa_{p}}({\bf v})
.
Assuming RF-based MKL, the function in (
13
), which is defined by the parameter
\hat{\hbox{\boldmath$\theta$}}_{p}
, will be assumed as the form of a learned (or estimated) function in the subsequent sections.

III
Methods

Consider a distributed online learning task in a network with the set of learners (e.g., IoT devices)
{\cal V}=\{1,2,...,J\}
interacting with each other over communication links. In particular, each learner aims at estimating a function in a sequential fashion, by leveraging its local streaming data and some information provided by neighboring learners. The connectivity of the
J
learners is described by the set of unordered pairs of the learners (called edges), given as

{\cal E}=\{\{i,j\}:\mbox{the learners }i\mbox{ and }j\mbox{ are connected}\}.

(14)

Specifically, the learner
i
can communicate with the learner
j
only if
\{i,j\}\in{\cal E}
. Given the learner
j
, the index set of its neighboring learners is denoted as

{\cal N}_{j}=\{i:\{i,j\}\in{\cal E}\}\subseteq{\cal V}.

(15)

Also, our
communication model
is assumed as follows: Due to the privacy concerns, it is prohibitive to share local data with neighboring learners. Whereas, each learner
j
can only transmit its latest estimated function (e.g.,
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}
) at time
t
to the neighboring learners
i\in{\cal N}_{j}
. Clearly, private local data should not be recovered from the estimated function
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}
. For the example of Fig.
1
, we have that
{\cal V}=\{1,2,3,4\}
and
{\cal E}=\{\{1,2\},\{1,3\},\{1,4\},\{2,5\},\{3,4\}\}
. Accordingly, we can obtain the set of neighbors as
{\cal N}_{1}=\{2,3,4\}
,
{\cal N}_{2}=\{1,5\}
,
{\cal N}_{3}=\{1,4\}
,
{\cal N}_{4}=\{1,3\}
, and
{\cal N}_{5}=\{2\}
. In this example, at time
t
, the learner
2
transmits the estimated parameter
\hat{\hbox{\boldmath$\theta$}}_{2,t+1}
to the learners 1 and 5, and receives the
\hat{\hbox{\boldmath$\theta$}}_{1,t+1}
and
\hat{\hbox{\boldmath$\theta$}}_{5,t+1}
from them, respectively.

Focusing on the above model, we propose a distributed online learning algorithm with the RF-based kernel in Section
III-A
, and extend it into a multiple kernel framework in Section
III-B
.

III-A

The Proposed DOKL (Single Kernel)

We first define the problem setting of a distributed kernel learning (DKL) and then extend it into an online framework. In the DKL, each learner
j
has its own local data
\{({\bf x}_{j,1},y_{j,1}),...,({\bf x}_{j,T},y_{j,T})\}
. Leveraging them and some information from neighboring learners, the learner
j
estimates a (non-linear) function
\hat{f}_{j}({\bf x})
. Following the RF approximation in (
11
), it is fully characterized by a
2D
-vector
\hat{\hbox{\boldmath$\theta$}}_{j}
as

\hat{f}_{j}({\bf x})=\hat{\hbox{\boldmath$\theta$}}_{j}^{{\sf T}}{\bf z}({\bf x}),

(16)

where
{\bf z}({\bf x})
is defined in (
26
). Given the connectivity (or communication model)
{\cal E}
, the objective of DKL is to solve the following optimization problem in a distributed way:

\displaystyle\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}}\sum_{t=1}^{T}\sum_{j=1}^{|{\cal V}|}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)

\displaystyle\mbox{ subject to }\hbox{\boldmath$\theta$}_{i}=\hbox{\boldmath$\theta$}_{j},\;\;\forall\{i,j\}\in{\cal E},

(17)

where
\hbox{\boldmath$\theta$}=[\hbox{\boldmath$\theta$}_{1};\hbox{\boldmath$\theta$}_{2};\cdots;\hbox{\boldmath$\theta$}_{|{\cal V}|}]
with
\hbox{\boldmath$\theta$}_{j}\in\mbox{\bb R}^{2D\times 1}
. In
[
30
]
, it was shown that the above problem can be efficiently solved via ADMM. Toward this, the optimization problem in (
17
) can be reformulated as

\displaystyle\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}}\sum_{t=1}^{T}\sum_{j=1}^{|{\cal V}|}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)

(18)

\displaystyle\mbox{ subject to }{\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hbox{\boldmath$\gamma$}={\bf 0},

(19)

for some matrices
{\bf A}\in\mbox{\bb R}^{4D|{\cal E}|\times 2D|{\cal V}|}
and
{\bf B}\in\mbox{\bb R}^{4D|{\cal E}|\times 2D|{\cal E}|}
, where each component of an auxiliary vector
\gamma
is assigned to an edge such as

\hbox{\boldmath$\gamma$}=\left[\hbox{\boldmath$\gamma$}_{\{i,j\}}:\{i,j\}\in{\cal E}\right]\in\mbox{\bb R}^{2D|{\cal E}|\times 1}.

(20)

Using the connectivity
{\cal E}
, the matrices
{\bf A}
and
{\bf B}
can be obtained straightforwardly. Consider the example of
{\cal V}=\{1,2,3\}
and
{\cal E}=\{\{1,2\},\{1,3\}\}
. In this case, the matrices of
{\bf A}
an
{\bf B}
are determined as

\displaystyle{\bf A}

\displaystyle=\left[\begin{matrix}{\bf I}&{\bf 0}&{\bf 0}\\
{\bf I}&{\bf 0}&{\bf 0}\\
{\bf 0}&{\bf I}&{\bf 0}\\
{\bf 0}&{\bf 0}&{\bf I}\end{matrix}\right]\mbox{ and }{\bf B}=\left[\begin{matrix}-{\bf I}&{\bf 0}\\
{\bf 0}&-{\bf I}\\
-{\bf I}&{\bf 0}\\
{\bf 0}&-{\bf I}\end{matrix}\right],

(21)

where
{\bf I}
and
{\bf 0}
represent the
2D\times 2D
identify and zero matrices, respectively. It is easily verified that the constraint in (
19
) is equivalent to that in (
17
), i.e.

{\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hbox{\boldmath$\gamma$}=\left[\begin{matrix}\hbox{\boldmath$\theta$}_{1}-\hbox{\boldmath$\gamma$}_{\{1,2\}}\\
\hbox{\boldmath$\theta$}_{1}-\hbox{\boldmath$\gamma$}_{\{1,3\}}\\
\hbox{\boldmath$\theta$}_{2}-\hbox{\boldmath$\gamma$}_{\{1,2\}}\\
\hbox{\boldmath$\theta$}_{3}-\hbox{\boldmath$\gamma$}_{\{1,3\}}\end{matrix}\right]={\bf 0}.

(22)

We are now ready to explain the proposed
distributed online kernel learning
(DOKL). The primary goal of DOKL is to solve the optimization problem (
19
) in an online fashion. For the centralized setting
[
24
]
, the online kernel learning problem has been efficiently solved via online gradient descent (OGD). Furthermore, it was shown that this approach can achieve the optimal sublinear regret
{\cal O}(\sqrt{T})

[
24
]
. For the distributed setting, we will solve it using online ADMM (OADMM) proposed in
[
31
]
and show that the optimal sublinear regret is also achieved.

At every time
t
, each learner
j
observes the incoming data
({\bf x}_{j,t},y_{j,t})
and optimizes the local function
\hat{f}_{j,t+1}
(defined by a parameter
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}
) via OADMM. Specifically, at every time
t
, OADMM solves the following regularized optimization problem:

\displaystyle\hat{\hbox{\boldmath$\theta$}}_{t+1}

\displaystyle=\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}}\sum_{j=1}^{|{\cal V}|}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)+\frac{\eta}{2}\left\|\hbox{\boldmath$\theta$}-\hat{\hbox{\boldmath$\theta$}}_{t}\right\|^{2}

\displaystyle\mbox{subject to }{\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hbox{\boldmath$\gamma$}=0,

(23)

where
\hbox{\boldmath$\theta$}=[\hbox{\boldmath$\theta$}_{1};\hbox{\boldmath$\theta$}_{2};\cdots;\hbox{\boldmath$\theta$}_{|{\cal V}|}]
with
\hbox{\boldmath$\theta$}_{j}\in\mbox{\bb R}^{2D\times 1}
. Accordingly, the augmented Lagrangian of (
23
) at time
t
is given as

\displaystyle L_{\rho}^{t}(\hbox{\boldmath$\theta$},\hbox{\boldmath$\gamma$},\hbox{\boldmath$\lambda$})

\displaystyle\stackrel{{\scriptstyle\Delta}}{{=}}\sum_{j=1}^{|{\cal V}|}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)+\hbox{\boldmath$\lambda$}^{{\sf T}}\left({\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hbox{\boldmath$\gamma$}\right)

\displaystyle\;\;\;+\frac{\eta}{2}\left\|\hbox{\boldmath$\theta$}-\hat{\hbox{\boldmath$\theta$}}_{t}\right\|^{2}+\frac{\rho}{2}\left\|{\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hbox{\boldmath$\gamma$}_{t}\right\|^{2}.

(24)

Thus, at time
t
, OADMM has the following update steps:

\displaystyle\hat{\hbox{\boldmath$\theta$}}_{t+1}

\displaystyle=\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}}\sum_{j=1}^{|{\cal V}|}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)+\hat{\hbox{\boldmath$\lambda$}}_{t}^{{\sf T}}\left({\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hat{\hbox{\boldmath$\gamma$}}_{t}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;+\frac{\rho}{2}\left\|{\bf A}\hbox{\boldmath$\theta$}+{\bf B}\hat{\hbox{\boldmath$\gamma$}}_{t}\right\|^{2}+\frac{\eta}{2}\left\|\hbox{\boldmath$\theta$}-\hat{\hbox{\boldmath$\theta$}}_{t}\right\|^{2},

(25)

\displaystyle\hat{\hbox{\boldmath$\gamma$}}_{t+1}

\displaystyle=\operatornamewithlimits{argmin}_{\hbox{\boldmath$\gamma$}}\;\;\hat{\hbox{\boldmath$\lambda$}}_{t}^{{\sf T}}\left({\bf A}\hat{\hbox{\boldmath$\theta$}}_{t+1}+{\bf B}\hbox{\boldmath$\gamma$}\right)+\frac{\rho}{2}\left\|{\bf A}\hat{\hbox{\boldmath$\theta$}}_{t+1}+{\bf B}\hbox{\boldmath$\gamma$}\right\|^{2},

(26)

\displaystyle\hat{\hbox{\boldmath$\lambda$}}_{t+1}

\displaystyle=\hat{\hbox{\boldmath$\lambda$}}_{t}+\rho\left({\bf A}\hat{\hbox{\boldmath$\theta$}}_{t+1}+{\bf B}\hat{\hbox{\boldmath$\gamma$}}_{t+1}\right).

(27)

Leveraging the structures of
{\bf A}
and
{\bf B}
, we will show that the above update steps can be performed in a distributed way, by only exchanging the latest estimates
\hat{\hbox{\boldmath$\theta$}}_{j,t}
’s among neighboring learners. The corresponding key lemma is given in the below.

Lemma 1

The optimization problems in (
25
)-(
27
) can be solved in a distributed way, where each learner
j
only exchanges the estimate
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}
with the neighboring learners
i\in{\cal N}_{j}
. The corresponding updates at the learner
j
are derived as follows:

\displaystyle\hat{\hbox{\boldmath$\theta$}}_{j,t+1}=\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}_{j}}{\cal L}\left(\hbox{\boldmath$\theta$}_{j}^{{\sf T}}{\bf z}({\bf x}_{j,t}),y_{j,t}\right)+\hat{\hbox{\boldmath$\lambda$}}_{j,t}^{{\sf T}}\hbox{\boldmath$\theta$}_{j}

III-B

The Proposed DOMKL (Multiple Kernels)

As an extension of the previous section, we will present a distributed online learning with
multiple kernels
(termed DOMKL). This approach can address the challenging problem of choosing a proper kernel in DOKL. Throughout the paper, it is assumed that there are
P
kernels in a kernel dictionary, each of which is defined by
\kappa_{p}
for
p\in[P]
. In the proposed DOMKL, every learner follows the same procedures separately. Focusing on the operations of the learner
j
, thus, DOMKL consists of the following two steps:

i) Local step:
This step learns a set of single kernel functions
\hat{f}_{j,t+1}^{p}({\bf x})\in{\cal H}_{p}
for
p\in[P]
. The learner
j
observes the incoming data
({\bf x}_{j,t},y_{j,t})
and optimizes the local functions
\hat{f}_{j,t+1}^{p}({\bf x})
for
p\in[P]
, via online optimization. Following the RF approximation in (
11
), each kernel function is determined by the
2D
-vector
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}^{p}
such as

\hat{f}_{j,t+1}^{p}({\bf x})=\left(\hat{\hbox{\boldmath$\theta$}}_{j,t+1}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}),

(32)

where
{\bf z}_{p}({\bf x})
is defined in (
26
). As in Section
III-A
, the parameter vector
\hat{\hbox{\boldmath$\theta$}}_{j,t+1}^{p}
is optimized in an online fashion via OADMM. The corresponding update rules are provided in (
28
) and (
29
). We remark that each kernel function
\hat{f}_{j,t+1}^{p}
is optimized independently from the other kernel functions. Namely, ADMM is performed for each kernel separately. During this step, the learner
j
obtained the
P
kernel functions defined by the parameters

\{\hat{\hbox{\boldmath$\theta$}}_{j,t+1}^{p}:p\in[P]\}
.

ii) Global step:
In this step, every learner
j
seeks the best function approximation
\hat{f}_{j,t+1}({\bf x})
by combining its local kernel functions
\{\hat{f}_{j,t+1}^{p}({\bf x}),p\in[P]\}
with proper weights
\{\hat{q}_{j,t+1}^{p},p\in[P]\}
:

\hat{f}_{j,t+1}({\bf x})=\sum_{p=1}^{P}\hat{q}_{j,t+1}^{p}\hat{f}_{j,t+1}^{p}({\bf x}),

(33)

where
\sum_{p=1}^{P}\hat{q}_{j,t+1}^{p}=1
with
\hat{q}_{j,t+1}^{p}\in[0,1]
. Here, the weights can capture the reliabilities (or accuracy) of the corresponding kernel functions. Following the online learning framework
[
22
]
, the weights are determined by the so-called
exponential strategy
(EXP strategy) in which they are determined on the basis of the past losses (i.e., the reliabilities of
P
kernels) as follows.
We first define the
local
accumulated losses:

\hat{w}_{j,t+1}^{p}=\exp\left(-\frac{1}{\eta_{g}}\sum_{\tau=1}^{t}{\cal L}\left(\hat{f}_{j,\tau}^{p}({\bf x}_{j,\tau}),y_{j,\tau}\right)\right),

(34)

for
p\in P
. Then, using
\{\hat{w}_{i,t+1}^{p}:i\in{\cal N}_{j}\}
(obtained from the neighboring learners), the weights are defined as

\hat{q}_{j,t+1}^{p}=\frac{\hat{w}_{j,t+1}^{p}\cdot\prod_{i\in{\cal N}_{j}}\hat{w}_{i,t+1}^{p}}{\sum_{p=1}^{P}\Big(\hat{w}_{j,t+1}^{p}\cdot\prod_{i\in{\cal N}_{j}}\hat{w}_{i,t+1}^{p}\Big)},

(35)

for some parameter
\eta_{g}>0
. Notice that from the above update rule, the weights of the learner
j
are determined by the local data of the neighboring learners as well as its own local data, i.e.,

\displaystyle\hat{w}_{j,t+1}^{p}\cdot\prod_{i\in{\cal N}_{j}}\hat{w}_{i,t+1}^{p}=\exp\left(-\frac{1}{\eta_{g}}L_{j,t+1}\right),

where the accumulated losses are obtained as

\displaystyle L_{j,t+1}

\displaystyle=\sum_{\tau=1}^{t}{\cal L}\left(\hat{f}_{j,\tau}^{p}({\bf x}_{j,\tau}),y_{j,\tau}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;+\sum_{i\in{\cal N}_{j}}\sum_{\tau=1}^{t}{\cal L}\left(\hat{f}_{i,\tau}^{p}({\bf x}_{i,\tau}),y_{i,\tau}\right).

Here, the second term can capture the reliability of the kernel function
p
obtained from the data of neighboring learners.

Remark 2

In particular when a network forms an acyclic graph, the weights can be further elaborated using the principle of message-passing
[
32
]
. In this case, the weights (i.e., the reliabilities of
P
kernels) can be updated using the local data of connected learners, in addition to that of neighboring learners. Here, we say that two learners are connected with a length
\zeta
if there exists a path of length
\zeta
between the two learners. Also, we let
{\cal N}_{j}^{(\zeta)}
denote the index set containing all the length-
\zeta
connected learners from the learner
j
, i.e.,
{\cal N}_{j}^{(\zeta)}=\{i\in{\cal V}:\mbox{there exists a length-$\zeta$ path}\mbox{between the learners $j$ and $i$}\}

with
{\cal N}_{j}^{(1)}={\cal N}_{j}
. Based on the principle of message-passing, the message transmitted from the learner
j
to the neighboring learner
i\in{\cal N}_{j}
is determined as

m_{j\rightarrow i,t+1}=\hat{w}_{j,t+1}^{p}\cdot\prod_{\ell\in{\cal N}_{j}:\ell\neq i}m_{\ell\rightarrow j,t}

(36)

with initial values
m_{\ell\rightarrow j,1}=1
for all
\{\ell,j\}\in{\cal E}
. Accordingly, the weights of the learner
j
are updated from the incoming messages
\{m_{\ell\rightarrow j,t}:\ell\in{\cal N}_{j}\}
such as

\hat{q}_{j,t+1}^{p}=\frac{\hat{w}_{j,t+1}^{p}\cdot\prod_{\ell\in{\cal N}_{j}}m_{\ell\rightarrow j,t}}{\sum_{p=1}^{P}\left(\hat{w}_{j,t+1}^{p}\cdot\prod_{\ell\in{\cal N}_{j}}m_{\ell\rightarrow j,t}\right)},

(37)

for some parameter
\eta_{g}>0
. This update rule can ensure that local information for weights (i.e., the reliabilities of the
P
kernels) can be propagated over the network as a time (or iteration)
t
grows, which is shown in the below:

\hat{w}_{j,t+1}^{p}\cdot\prod_{\ell\in{\cal N}_{j}}m_{\ell\rightarrow j,t}=\exp\left(-\frac{1}{\eta_{g}}L_{j,t+1}\right),

(38)

where the accumulated losses are given as

\displaystyle L_{j,t+1}

\displaystyle=\sum_{\tau=1}^{t}{\cal L}\left(\hat{f}_{j,\tau}^{p}({\bf x}_{j,\tau}),y_{j,\tau}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;+\sum_{\zeta=1}^{t-1}\sum_{i\in{\cal N}_{j}^{(\zeta)}}\sum_{\tau=1}^{t-\zeta}{\cal L}\left(\hat{f}_{i,\tau}^{p}({\bf x}_{i,\tau}),y_{i,\tau}\right).

(39)

The above update philosophy can be maintained even for cyclic graphs, as long as the girth of a network graph is larger than the overall number of iterations
T
. Otherwise, some losses can be reflected due to the duplication.

Note that the learned function in (
33
) will be used to estimate the label
\hat{y}_{j,t+1}
of an incoming local data
\hat{{\bf x}}_{j,t+1}
. The detailed procedures of DOMKL are provided in

IV
Theoretical Analysis

We analyze the performances of the proposed DOKL and DOMKL in terms of the cumulative regrets for both learning accuracy and constraint violation (i.e., discrepancy). We let
\hat{f}_{j,t}
denote the estimated function of the learner
j
. Let
f_{j}^{\star}
denote the optimal function for the data of the learner
j
, i.e.,

f_{j}^{\star}=\operatornamewithlimits{argmin}_{f}\sum_{t=1}^{T}{\cal L}\left(f({\bf x}_{j,t}),y_{j,t}\right).

(40)

Then, the cumulative regrets for learning accuracy and discrepancy at the leaner
j
are formally defined as

\displaystyle{\rm regret}_{\rm a}^{j}(T)

\displaystyle=\sum_{t=1}^{T}{\cal L}\left(\hat{f}_{j}^{t}({\bf x}_{j,t}),y_{j,t}\right)-{\cal L}(f_{j}^{\star}\left({\bf x}_{j,t}),y_{j,t}\right)

\displaystyle{\rm regret}_{\rm d}^{j}(T)

\displaystyle=\sum_{t=1}^{T}\left|\sum_{i\in{\cal N}_{j}}\left(\hat{f}_{j,t}({\bf x}_{j,t})-\hat{f}_{i,t}({\bf x}_{j,t})\right)\right|^{2}.

From now on, we will prove that the proposed DOMKL and DOMKL can achieve the sublinear regrets
{\cal O}(\sqrt{T})
for both learning accuracy and discrepancy. When
T\rightarrow\infty
, thus, the regret per time will be disappeared. Recall that under the RF approximation, each kernel function
\hat{f}_{j,t}^{p}
has the form of

\hat{f}_{j,t}^{p}({\bf x})=\left(\hat{\hbox{\boldmath$\theta$}}_{j,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}).

(41)

For ease of exposition, given the data
({\bf x}_{j,t},y_{j,t})
, the loss function with respect to
\theta
is represented as

{\cal L}\left(\hbox{\boldmath$\theta$}^{{\sf T}}{\bf z}_{p}({\bf x}_{j,t}),y_{j,t}\right)\stackrel{{\scriptstyle\Delta}}{{=}}{\cal L}_{j,t}^{p}(\hbox{\boldmath$\theta$}).

(42)

Throughout the paper, the above two notations will be used interchangeably. Also, we let
\hbox{\boldmath$\theta$}_{j,p}^{\star}
denote the optimal RF approximation function at the kernel
p
, i.e.,

\hbox{\boldmath$\theta$}_{j}^{\star}=\operatornamewithlimits{argmin}_{\hbox{\boldmath$\theta$}}\sum_{t=1}^{T}{\cal L}\left(\hbox{\boldmath$\theta$}^{{\sf T}}{\bf z}_{p}({\bf x}_{j,t}),y_{j,t}\right),\;\forall j\in{\cal V},

(43)

with the consensus constraint in (
23
).
For the analysis, the following conditions are assumed:

•

(a1)
For any fixed
{\bf z}_{p}({\bf x}_{j,t})
and
y_{j,t}
, the loss function
{\cal L}_{j,t}^{p}(\hbox{\boldmath$\theta$})
is convex with respect to
\theta
, differentiable, and bounded as
{\cal L}_{j,t}^{p}(\hbox{\boldmath$\theta$})\in[0,L_{u}]
. Also, its gradient is bounded, i.e.,
\|\nabla{\cal L}_{j,t}^{p}(\hbox{\boldmath$\theta$})\|^{2}\leq G
for some positive constant
G
.

•

(a2)
For any kernel
\kappa_{p}
,
\hat{\hbox{\boldmath$\theta$}}_{j,t}^{p}
belongs to a bounded set
\Theta_{p}\subseteq\mbox{\bb R}^{2D\times 1}
, i.e.,
\|\hat{\hbox{\boldmath$\theta$}}_{j,t}^{p}\|^{2}\leq C
for some positive constant
C
.

•

(a3)
For any
t\in T
,
{\cal L}_{j,t}^{p}(\hat{\hbox{\boldmath$\theta$}}_{j,t}^{p})-{\cal L}_{j,t}^{p}(\hbox{\boldmath$\theta$}_{j}^{\star})\geq-B

for some positive constant
B
.

The assumptions
(a1)
and
(a2)
are in general required in the online learning setting
[
23
,
33
,
31
,
24
]
. Also, the assumption
(a3)
is required to prove the sublinear regret of constraint violation (i.e., discrepancy), which is true if convex functions are bounded from below or Lipschitz continuous
[
31
]
.
Additionally, for the proof of Theorem
2
, the following assumption is required:

•

(a4)
For any fixed
j\in{\cal V}
and
p\in[P]
, there exists a sequence of
\epsilon_{t}
’s such that
|\hat{q}_{j,t}^{p}-\hat{q}_{i,t}^{p}|\leq\epsilon_{t}
and
\sum_{t=1}^{T}\epsilon_{t}^{2}\leq{\cal O}(\sqrt{T})
for
\forall i\in{\cal N}_{j}
, where
\hat{q}_{j,t}^{p}
is defined in (
35
).

In fact, the upper-bound
\epsilon_{t}
is determined on the basis of network structure (i.e., the connectivity of learners in the network). For example, when the network is a complete graph, we can easily obtain the
\epsilon_{t}=0
for all
t\in[T]
. Obviously, as the connectivity of a network becomes sparse,
\epsilon_{t}
tends to increase. Via numerical tests, we have confirmed that the assumption
(a4)
might not be tight, i.e., it can be easily satisfied in practical network structures.

and
2
below, and the proofs will be provided in Sections
IV-A
and
IV-B
.

V
Experiments

We provide the experimental tests to verify the effectiveness of the proposed DOMKL. In particular, we consider the online regression and time-series prediction tasks with various real-world datasets. A regularized least-square loss function (with respect to
\theta
) is considered, which is defined as

{\cal L}\left(\hbox{\boldmath$\theta$}^{{\sf T}}{\bf z}_{p}({\bf x}_{t}),y_{t}\right)=\left[y_{t}-\hbox{\boldmath$\theta$}^{{\sf T}}{\bf z}_{p}({\bf x}_{t})\right]^{2}+\lambda\|\hbox{\boldmath$\theta$}\|^{2},

for some regularization parameter
\lambda>0
.
Regarding the distributed settings, the various network structures (i.e., the various network connectivity among learners) are considered, which are described in Fig.
2
. Also, to verify the superiority of the proposed algorithms, we compare the performances with the state-of-the-art centralized counterpart (named online multiple kernel learning (OMKL)) proposed in
[
23
,
24
]
. Especially, we will demonstrate the effectiveness of the proposed DOMKL into two-fold: 1) it can achieve the performance of the best kernel function (under the distributed setting) in hindsight; 2) it can achieve the performance of OMKL without sharing local data directly. To accomplish this, the following methods are used in our experiments:

•

OMKL
: The
centralized
online
multiple
kernel learning algorithm using online gradient decent (OGD) method
[
23
,
24
]
.

•

DOKL1
: The proposed
decentralized
online
single
kernel learning in Algorithm 1 having the Gaussian kernel with
\sigma^{2}=10^{-2}
.

•

DOKL2
: The proposed
decentralized
online
single
kernel learning algorithm in Algorithm 1 having the Gaussian kernel with
\sigma^{2}=10^{2}
.

•

DOMKL
: The proposed
decentralized
online
multiple
kernel learning in Algorithm 2, where we use the kernel dictionary consisting of the 17 Gaussian kernels whose parameters are given as

\sigma_{p}^{2}=10^{\frac{i-9}{2}},~p=1,\dots,17.

(57)

Additionally, the hyper-parameters of the proposed DOKL and DOMKL are set by

\rho=\eta=\eta_{g}=\sqrt{T}~\text{and}~D=50.

(58)

Obviously these hyper-parameters can control the tradeoff between learning accuracy and consensus constraint. Unfortunately, the optimization of such hyper-parameters are not straightforward as in the centralized OMKL
[
23
,
24
]
, which is left of a future work. Instead, we have chosen the hyper-parameters on the basis of analytical results in Section
IV
, where it was proved that DOMKL can yield an optimal performance asymptotically with
\rho=\eta=\eta_{g}=\sqrt{T}
.

To show the effectiveness of using multiple kernels, DOMKL is compared with the best single kernel, where it is obtained via an exhaustive search by assuming that all data is known in advance. In detail, the exhaustive search among 17 Gaussian kernels in (
57
) is conducted on Wave energy data to find the best single kernel. This reveals that in this dataset, the Gaussian kernel with
\sigma^{2}=10^{-2}
(i.e., DOKL1) is the optimal. Accordingly, DOKL shows the best performance for Wave energy data (see Tables II and III). It is remarkable that this process to find the optimal single kernel is not applicable, since at every time
t
, the optimization of a function learning should be performed only with the partial datasets

\{({\bf x}_{\tau},y_{\tau}):\tau\in[t]\}
. Thus, it is not possible to find the best kernel function over the entire dataset. From this comparison, we can confirm that the proposed DOMKL achieves the optimal performance on top of its practical usefulness.

In the following subsections, the performances of DOMKL are investigated into two aspects:
node-wise
and
network-wise
, which are respectively evaluated by learning accuracy and consensus violation.

i) Learning accuracy:
For every learner
j\in\mathcal{V}
, the accuracy of a function learning is evaluated by the standard mean-square-error (MSE) as

\mbox{MSE}=\frac{1}{T}\sum_{t=1}^{T}\left(\hat{y}_{j,t}-y_{j,t}\right)^{2}~\;\;\text{for}~j\in\mathcal{V},

(59)

where
\hat{y}_{j,t}=\hat{f}({\bf x}_{j,t})
and
y_{j,t}
denote an estimated label and a true label of the learner
j
at time
t
, respectively. Clearly, a smaller value of MSE indicates a more precise learned function. However, this metric cannot capture the consensus among neighboring learners, which is evaluated from the metric in the below.

ii) Consensus violation:
The network-wise consensus is evaluated by measuring the differences of the learning functions of neighboring learners. For the consistency with the theoretical analysis in Section
IV
, we take the following metric:

\mbox{CV}=\frac{1}{T}\sum_{t=1}^{T}\left|\sum_{i\in{\cal N}_{j}}\left(\hat{f}_{j,t}({\bf x}_{j,t})-\hat{f}_{i,t}({\bf x}_{j,t})\right)\right|^{2}.

(60)

Clearly, a smaller value of the above metric can ensure that neighboring learners in a network generate a more similar estimated functions. Note that due to the randomness caused by the above algorithms (e.g.,
{\bf z}({\bf x})
in (
26
)), the averaged MSE and CV performances over 10 trials are evaluated.

Time-series Prediction Tasks

The proposed DOMKL can be naturally extended into time-series prediction tasks which predict the future values in an online distributed fashion. Toward this, we take the popular time-series prediction method called
Autoregressive (AR) model
[
39
]
. An AR(
p
) model predicts the future value
y_{t}
with the assumption of the linear dependency on its past
p
values, which is mathematically represented as

y_{t}=c+\sum_{i=1}^{p}\alpha_{i}y_{t-i}+\epsilon_{t},

(61)

where
c
is a constant,
\alpha_{i}
denotes the weight associated with

y_{t-i}
, and
\epsilon_{t}
denotes a Gaussian noise at time
t
. Based on this, the RF-based kernelized AR(
p
) model, which can explore a nonlinear dependency, has been introduced in
[
24
]
, where it is formulated as

\displaystyle y_{t}

\displaystyle=c+f(y_{t-1},y_{t-2},\dots,y_{t-p})+\epsilon_{t}

\displaystyle=c+f({\bf x}_{t})+\epsilon_{t}

\displaystyle=c+\hbox{\boldmath$\theta$}^{{\sf T}}{\bf z}({\bf x}_{t})+\epsilon_{t},

(62)

where
{\bf x}_{t}\triangleq\left[y_{t-1},y_{t-2},\dots,y_{t-p}\right]^{{\sf T}}
and
f({\bf x}_{t})
belongs to kernel space, which is well-approximated as in (
11
). Then, this can be directly plugged into DOMKL framework to solve time-series prediction tasks. The proposed algorithms are tested with the following univariate time-series datasets from UCI Machine Learning Repository:

[

]
:
This dataset contains
T

Temperature
[
41
]
:
This dataset consists
T
= 5500 time-series temperature data obtained from Minneapolis Department of Transportation in US. Data is collected from hourly interstate 94 Westbound temperature for MN DoT ATR station 301, roughly midway between Minneapolis and St Paul, MN.

This certifies that the benefit of using multiple kernels in DOMKL actually contributes on the performance improvements, by enlarging a function class. As in online regression tasks, the proposed DOMKL also achieves the almost same performance with OMKL on time-series prediction tasks. This ensures its advantages on data privacy and practicability. From the perspective of network-wise performances, the low values of consensus violation of DOMKL are notable. VI
Concluding Remarks

In this paper, we proposed a novel distributed online learning framework with multiple kernels. The proposed method is referred to as DOMKL. It was devised by appropriately incorporating an online alternating direction method of multipliers (OADMM) and a distributed Hedge algorithm. To be specific, the former is to optimize kernel functions and the latter is to update the weights for combining the kernel functions collaboratively with neighboring learners in a distributed fashion. The key advantages of the proposed DOMKL are the
scalability
(with respect to the number of incoming data) and
privacy-preserving
. These merits enable it to be applicable for various function learning tasks arising from IoT systems. Furthermore, we theoretically proved that DOMKL can achieve an optimal sublinear regret, i.e., it yields the same order with a centralized counterpart (called online multiple kernel learning (OMKL)). This shows that distributed learners (e.g., IoT devices) can achieve the almost same accuracy of the centralized OMKL, without sharing local data directly.
Beyond the asymptotic analysis, we demonstrated the effectiveness of the proposed DOMKL on online regression and time-series prediction tasks via experimental results with real datasets.

An important future work is to extend the proposed DOMKL into wireless distributed settings, in which the amount of information to be transmitted should be carefully designed according to communication constraints (e.g., channel capacity). Active learning could be a promising solution because in this case, unnecessary information cannot be transmitted by activating useful learners only at every time. Thus, it can reduce the communication cost. Furthermore, this active learning approach can reduce the labeling cost in that each learner only queries some useful incoming data to an oracle. Another promising solution is to employ a quantized OADMM having dynamic quantization levels which are chosen according to the qualities of wireless channels.
