Towards Tractability of the Diversity of Query Answers: Ultrametrics to the Rescue
Marcelo Arenas, Timo Camillo Merkl, Reinhard Pichler, Cristian Riveros

Abstract
The set of answers to a query may be very large, potentially overwhelming users when presented with the entire set. In such cases, presenting only a small subset of the answers to the user may be preferable. A natural requirement for this subset is that it should be as diverse as possible to reflect the variety of the entire population. To achieve this, the diversity of a subset is measured using a metric that determines how different two solutions are and a diversity function that extends this metric from pairs to sets. In the past, several studies have shown that finding a diverse subset from an explicitly given set is intractable even for simple metrics (like Hamming distance) and simple diversity functions (like summing all pairwise distances). This complexity barrier becomes even more challenging when trying to output a diverse subset from a set that is only implicitly given (such as the query answers for a given query and a database). Until now, tractable cases have been found only for restricted problems and particular diversity functions. To overcome these limitations, we focus in this work on the notion of ultrametrics, which have been widely studied and used in many applications. Starting from any ultrametric d d and a diversity function δ \delta extending d d , we provide sufficient conditions over δ \delta for having polynomial-time algorithms to construct diverse answers. To the best of our knowledge, these conditions are satisfied by all the diversity functions considered in the literature. Moreover, we complement these results with lower bounds that show specific cases when these conditions are not satisfied and finding diverse subsets becomes intractable. We conclude by applying these results to the evaluation of conjunctive queries, demonstrating efficient algorithms for finding a diverse subset of solutions for acyclic conjunctive queries when the attribute order is used to measure diversity.

Introduction

The set of answers to a query may be very large, potentially
overwhelming users when presented with the entire set.
In such cases,
presenting only a small subset of the answers to the user may be
preferable.
Ideally, the selected answers should give the user
a good overview of the variety present in the complete set of answers.
As was argued in
[
33
]
, determining such a small subset
by sampling will, in general,
not constitute a satisfactory solution to this problem,
since it would most probably miss interesting but rarely occurring answers.
Instead, the goal should be to present to the user a
diverse
subset of the answer space
to reflect its variety.

This raises the question of how to define diversity among query results.
The natural way of defining the diversity of a set of elements (see, e.g.,

[
16
]
for a whole framework on dealing with diversity)
is to first define the
diversity of 2 elements by a metric (the “distance” function) and then to appropriately
generalize it to arbitrary (finite) sets.
Both, for the metric and for the generalization to arbitrary sets, many choices exist and,
as was mentioned in
[
35
]
,
it ultimately depends on the application context which distance and diversity function
is best suited.

We restrict ourselves here to the relational model. Hence, the answer to a query is a set of tuples and we are interested in outputting
a subset with a given size
k
so as to maximize the diversity.
A natural and simple choice for the distance between two tuples is the Hamming distance
(i.e., the number of positions in which the two tuples differ), which was used e.g.,
in the analysis of the diversity of query answers in
[
21
]
. A more nuanced point of view was taken
in
[
33
,
32
]
, where an ordering of the attributes is assumed and
tuples are considered as more distant if they differ on an attribute that comes
earlier in the ordering. This
idea was exemplified by a car-relation with attributes
make-model-color-year-description in this order. Hence, for instance, the query engine
would preferably output a subset of cars with different models rather than with different colors. Actually, this distance function is an ultrametric, i.e., a metric
\mathbf{d}
, that
satisfies the strong triangle inequality

\mathbf{d}(a,c)\leq\max\{\mathbf{d}(a,b),\mathbf{d}(b,c)\}
for any three elements.

For the generalization of the distance to a diversity
\delta
of sets,
one can aggregate the pairwise distances, for instance,
by taking their sum or minimum
(see, e.g.,
[
33
,
32
,
21
,
16
]
). In this work, we also want to look at a more sophisticated
diversity measure proposed by Weitzman
in
[
35
]
, which we will refer to as
\delta_{\operatorname{W}}
.
It is motivated by the
goal of capturing the increase of diversity (measured as the minimum
distance from the already chosen elements) when yet another element is added.
Detailed formal definitions of all concepts mentioned here will be given in
Section
2
.

Aiming at a diverse subset of the answers to a query raises several
computational problems. The most basic problem is to actually evaluate the
diversity function
\delta
for a given set
S
of tuples. Clearly,
this problem is easy to solve, if
\delta
is defined by taking
one
of the standard aggregate functions sum or min
over some efficiently computable metric (such as the Hamming distance).
However, if we take the more sophisticated
diversity measure
\delta_{\operatorname{W}}
proposed by Weitzman,
this is not clear any more. In fact, only an exponential algorithm was proposed in

[
35
]
for this task and it was left open, if a polynomial-time
algorithm exists. We will settle this open question by proving NP-hardness.

Our ultimate goal is to select a
small subset (say, of size
k
for given
k>1
)
of the query answers so as to maximize the diversity.
When considering data complexity and restricting ourselves to FO-queries,
query evaluation is tractable and we may
assume the entire set
S
of query answers as
explicitly
given.
Now the goal is to find a subset
S^{\prime}\subseteq S
of size
k
such
that
\delta(S^{\prime})
is maximal. In
[
21
]
, it was shown that this task
is NP-hard even for the simple setting where
\delta
is defined as the sum or as the
minimum over the pairwise Hamming distances of the tuples.
Taking the Weitzman diversity clearly makes this task yet more complex.
It is here that ultrametrics come to the rescue. Indeed, we show tractability of the following problem: given a set
S
of elements and integer
k>1
,
find a subset
S^{\prime}
of
S
such that
\delta(S^{\prime})
is maximal, where
\delta

is a diversity function extending an ultrametric and
\delta
satisfies a certain
monotonicity property we call
weak subset-monotonicity
.
Moreover, we show that even slightly
relaxing the monotonicity property immediately leads to NP-hardness.

Things get yet more complex if we consider combined complexity.
Since the set
S
of query answers can be exponentially big, we cannot afford to compute it upfront.
In other words,

S
is only given
implicitly
by the database
D
and query
Q
.
But the goal remains the same: we want to find a subset
S^{\prime}
of
S
with
|S^{\prime}|=k

that maximizes the diversity
\delta(S^{\prime})
. Since query evaluation is intractable
for conjunctive queries even without worrying about diversity,
we now restrict the query language to acyclic conjunctive queries.
We then manage again to prove tractability for the task of finding a subset
S^{\prime}
with
maximal diversity, provided that
\delta
is
subset-monotone
– a restriction slightly stronger than weak subset-monotonicity but which is satisfied by

\delta_{\operatorname{W}}
, for example. Again we show tightness of this tractability result by proving that
without this stronger notion of monotonicity, the problem is NP-hard.
Finally, we also identify a kind of middle ground in terms of monotonicity of

\delta
that ensures fixed-parameter tractability when considering
k

as parameter.

Diversity setting

Let
\mathcal{U}
be an infinite set.
We see
\mathcal{U}
as a
universe
of possible solutions and
S\in\operatorname{finite}(\mathcal{U})
as a candidate finite set of solutions that cannot be empty. To determine the diversity of
S
, we first determine how different the pairs of elements are in
S
, which is done through a metric. A
metric

over
\mathcal{U}
is a function
\textbf{d}:\mathcal{U}\times\mathcal{U}\rightarrow\mathbb{Q}_{\geq 0}
such that
\textbf{d}(a,b)=0
iff
a=b
,
d
is symmetric (i.e.,
\textbf{d}(a,b)=\textbf{d}(b,a)
), and

satisfies the triangle inequality (i.e.,
\textbf{d}(a,c)\leq\textbf{d}(a,b)+\textbf{d}(b,c)
). We define the distance of an element

to a set

as
\textbf{d}(a,S):=\min_{b\in S}\textbf{d}(a,b)
.

Given a metric
d
, a

\delta
of

is a function
\delta:\operatorname{finite}(\mathcal{U})\rightarrow\mathbb{Q}_{\geq 0}
such that
\delta(S)=0
iff

, and
\delta(\{a,b\})=\textbf{d}(a,b)
. Note that we see
\delta
as a function that extends

from pairs to sets, and that is

when the set has a single element (i.e., no diversity). Moreover, we impose the
restriction that
\delta
should be closed under isomorphism. That is, if
f:\mathcal{U}\rightarrow\mathcal{U}
is
a bijective function such that
\textbf{d}(a,b)=\textbf{d}(f(a),f(b))
for every
a,b\in\mathcal{U}
, then
\delta(S)=\delta(f(S))
for every
S\in\operatorname{finite}(\mathcal{U})
.

As proposed in
[
16
]
,
one way of defining a diversity function
\delta
for a given

d
over
\mathcal{U}
is to define an aggregator
f
that combines the pairwise distances. That is,
we set

\delta(S):=f(\textbf{d}(a,b)_{a,b\in S})
.
Common aggregators are sum and min, which give rise to the following diversity functions
of an arbitrary metric
d

Diversity problems

When confronted with the task of selecting a
diverse
set of elements from an (explicitly or implicitly) given
set, we are mainly concerned with three problems – each of them depending on a concrete

diversity
function
\delta
, which in turn is defined over some universe
\mathcal{U}
of elements.
The most basic problem consists in
computing the diversity for a given
S\in\operatorname{finite}(\mathcal{U})
:

Problem:

\mathtt{DiversityComputation}[\delta]

Input:

A finite set
S\subseteq\mathcal{U}

Output:

\delta(S)

An additional source of complexity is introduced if the task is to find a subset of
S

with a certain diversity.

Problem:

\mathtt{DiversityExplicit}[\delta]

Input:

A finite set
S\subseteq\mathcal{U}
and
k>1

Output:

\argmax_{S^{\prime}\subseteq S\,:\,|S^{\prime}|=k}\delta(S^{\prime})

In light of the previous problem, it is convenient to introduce the following notation:
we call
S^{\prime}
with
S^{\prime}\subseteq S

a “
k
-diverse subset of
S
”, if
S^{\prime}=\argmax_{A\subseteq S\,:\,|A|=k}\delta(A)
.
In other words, the goal of the
\mathtt{DiversityExplicit}[\delta]
problem is to find a

k
-diverse subset of
S
.

Things may get yet more complex, if the set
S\subseteq\mathcal{U}
from which we want to select a subset with
maximal diversity is only “implicitly” given.
For us, the most important example of such a setting is when
S
is the set of answer tuples
to a given query
Q
(in particular, an acyclic CQ) over database
D
and we consider combined complexity. Further settings will be introduced in
Section
6
. All these settings have in common that

S
might be
exponentially big and one cannot afford to turn the implicit representation into an explicit one upfront.

Problem:

\mathtt{DiversityImplicit}[\delta]

Input:

An implicit representation of a finite set
S\subseteq\mathcal{U}
and
k>1

Output:

\argmax_{S^{\prime}\subseteq S\,:\,|S^{\prime}|=k}\delta(S^{\prime})

By slight abuse of notation, we will formulate intractability results on the
three functional problems introduced above in the form of “
\mathsf{NP}
-hardness” results.
Strictly speaking, we thus mean the decision variants of the diversity problems,
i.e., deciding if the diversity
\delta(S)
is above a given threshold

or if a set
S^{\prime}\subseteq S
with
\delta(S^{\prime})\geq th
exists.

Complexity analysis of algorithms

For the implementation of our algorithms, we assume the computational model of
Random Access Machines (RAM) with uniform cost measure and addition and subtraction
as basic operations
[
1
]
.
Further, in all the scenarios considered in this paper, a metric
d
is defined
over a countably infinite set
\mathcal{U}
, and the value
\textbf{d}(a,b)
is a
non-negative rational number for every
a,b\in\mathcal{U}
. Thus, we assume
that the codomain of every metric

is the set
\mathbb{Q}_{\geq 0}
, which in
particular implies that we have a finite representation for each
possible value of a metric that can be stored in a fixed number of RAM registers. Moreover, although
d
is defined over an
infinite set, we will only need its values for a finite set, and we
assume that
\textbf{d}(a,b)
can be computed in constant time for any pair

a
,
b
of elements in this set. Alternatively, one could multiply
the complexity of our algorithms by a parameter

that encapsulates
the cost of computing
\textbf{d}(a,b)
or consider the metric as given by a
look-up table at the expense of a quadratic blow-up of the
input. Neither of these alternatives would provide any additional
insights while complicating the notation or blurring the setting. We
have therefore refrained from adopting one of them.

Computing diversity is hard

The most basic computational problem considered here is
\mathtt{DiversityComputation}[\delta_{\operatorname{W}}]

Clearly, for
\delta_{\operatorname{sum}}
and
\delta_{\operatorname{min}}

Then we set

It is straightforward to verify that

.
∎

4
Ultrametrics to the rescue

In this section, we recall the definition of an ultrametric and present some of its structural properties. The results presented here are well-known in the literature of ultrametric spaces.
Nevertheless, they are crucial to understand the algorithms for diversity measures shown in the following sections.
To make the paper self-contained, we provide proofs of these properties in the appendix.

Ultrametrics

Let
\mathcal{U}
be a possibly infinite set. An
ultrametric

u
over
\mathcal{U}
is a metric over
\mathcal{U}
that additionally satisfies the
strong triangle inequality
:

\textbf{u}(a,c)\leq\max\{\textbf{u}(a,b),\textbf{u}(b,c)\}.

We use
d
to denote a metric and
u
to denote an ultrametric, thereby making it explicit that we are using an ultrametric.

As an example, consider the following ultrametric for tuples in a relational database with schema
\sigma
. Let
\mathcal{U}
be the set of all tuples of
\sigma
.
Define the metric
\textbf{u}_{\operatorname{rel}}
such that

\textbf{u}_{\operatorname{rel}}(R(\bar{a}),R(\bar{a}))=0
,
\textbf{u}_{\operatorname{rel}}(R(\bar{a}),S(\bar{b}))=1
, and
\textbf{u}_{\operatorname{rel}}(R(\bar{a}),R(\bar{a}^{\prime}))=2^{-i}
with
i=\min\{j\mid\bar{a}[j]\neq\bar{a}^{\prime}[j]\}
, for arbitrary tuples
R(\bar{a})
,
R(\bar{a}^{\prime})
, and
S(\bar{b})
of
\sigma
with
R\neq S,\bar{a}\neq\bar{a}^{\prime}
. In other words, the distance is
1
if tuples comes from different relations, and otherwise
2^{-i}
such that
i
is the first position where (the arguments of) the tuples differ. One can check that
\textbf{u}_{\operatorname{rel}}

is an ultrametric since, for arbitrary tuples
R(\bar{a})
,

R(\bar{b})
,
R(\bar{c})
such that
i
is the first position where

R(\bar{a})
and
R(\bar{c})
differ, it holds that
R(\bar{a})
and
R(\bar{b})
differ at position
i
or

R(\bar{b})
and
R(\bar{c})
differ at position
i
, so that

\textbf{u}_{\operatorname{rel}}(R(\bar{a}),R(\bar{c}))\leq\max\{\textbf{u}_{\operatorname{rel}}(R(\bar{a}),R(\bar{b})),\textbf{u}_{\operatorname{rel}}(R(\bar{b}),R(\bar{c}))\}.

Similarly, the strong triangle inequality holds for tuples of different relations.

Structure of ultrametric spaces over finite sets

Ultrametrics form a class of well-studied metric spaces, which have
useful structural properties.
For instance, if
d
in
Equation (
2
) from Section
2

is an ultrametric, then that equation holds for every

a\in S
.
Moreover, every three elements form
an isosceles triangle, namely, for every
a,b,c\in\mathcal{U}
it holds
that
\textbf{u}(a,b)=\textbf{u}(a,c)
, or
\textbf{u}(a,b)=\textbf{u}(b,c)
, or
\textbf{u}(a,c)=\textbf{u}(b,c)
. In particular, this implies some well-structured hierarchy
on all balls centered at elements of a finite set, that we introduce
next.
Fix an ultrametric
\textbf{u}:\mathcal{U}\times\mathcal{U}\rightarrow\mathbb{Q}_{\geq 0}
and fix a finite set
S\subseteq\mathcal{U}
. For every
a\in S
and
r\in\mathbb{Q}_{\geq 0}
, let:

\mathcal{B}_{S}(a,r):=\{b\in S\mid\textbf{u}(a,b)\leq r\}.

That is,
\mathcal{B}_{S}(a,r)
is the (closed)
ball
centered at
a

with radius
r
. Let
\mathcal{B}_{S}=\{\mathcal{B}_{S}(a,r)\mid a\in S\wedge r\in\mathbb{Q}_{\geq 0}\}
be the
set of all balls
of
u
over
S
.
Given that
S
is finite,
\mathcal{B}_{S}
is finite as
well. Moreover, the set
\mathcal{B}_{S}
follows a nested structure given
by the following standard properties of ultrametrics.

Property 1
.

(a) For every
B_{1},B_{2}\in\mathcal{B}_{S}
, it holds that
B_{1}\cap B_{2}=\emptyset
or
B_{1}\subseteq B_{2}
or
B_{2}\subseteq B_{1}
.

(b) If
\textbf{u}(a_{1},a_{2})\leq r
, then
\mathcal{B}_{S}(a_{1},r)=\mathcal{B}_{S}(a_{2},r)
.

Property
1
(a) implies a nested structure among balls in
\mathcal{B}_{S}
that we
can represent as a tree structure as follows. First, for every
B\in\mathcal{B}_{S}
, define the set:

\operatorname{parent}(B):=\{B^{\prime}\in\mathcal{B}_{S}\mid B\subsetneq B^{\prime}\wedge\neg\exists B^{\prime\prime}\in\mathcal{B}_{S}\,:\,B\subsetneq B^{\prime\prime}\subsetneq B^{\prime}\}.

Since
(\mathcal{B}_{S},\subseteq)
is a partial order over a finite set,
\operatorname{parent}(B)
is non-empty for every
B\neq S
. Moreover, by Property
1
(a), we have that
\operatorname{parent}(B)
has at most one element. Then, for every
B\in\mathcal{B}_{S}\setminus\{S\}
we can write
\operatorname{parent}(B)
to denote this single element.

We define the
ultrametric tree of
u
over
S
as the graph
\mathcal{T}_{S}=(V_{S},E_{S})
such that
V_{S}:=\mathcal{B}_{S}
and

E_{S}\ :=\ \{(\operatorname{parent}(B),B)\mid B\in\mathcal{B}_{S}\setminus\{S\}\}.

Given that
(\mathcal{B}_{S},\subseteq)
is a partial order and every
B
has at most one incoming edge, we have that
\mathcal{T}_{S}
is a (directed) tree and
S
is the root of this tree.
Therefore, we can write
\operatorname{children}(B)=\{B^{\prime}\mid(B,B^{\prime})\in E_{S}\}
to denote the children of
B
in
\mathcal{T}_{S}
. Note that
B
is a leaf in the tree
\mathcal{T}_{S}
iff
B=\{a\}
for some
a\in S
. Further, if
|B|\geq 2
, then
\operatorname{children}(B)
forms a partition of
B
by Property
1
(a).

Example 4.2
.

Let
S
be the set of all tuples in the relation
CARS
of Example
4.1
. In Figure
1(b)
, we display the ultrametric tree of
\textbf{u}_{\operatorname{rel}}
over
S
. One can check in this figure that each leaf contains a single tuple, and the children of each ball form a partition. ∎

It will be also convenient to relate the distance between elements in
S
with the radius of the balls in
\mathcal{B}_{S}
. For this purpose, for every
B\in\mathcal{B}_{S}
we define its
radius
as:

\operatorname{r}_{S}(B)\ :=\ \max\{\textbf{u}(a,b)\mid a,b\in B\}.

Notice that
\operatorname{r}_{S}(B)
is well defined since
B
is a finite set.
By Property
1
(b), we have that
B=\mathcal{B}_{S}(a,\operatorname{r}_{S}(B))
for every ball
B\in\mathcal{B}_{S}
and point
a\in B
.
Hence, in what follows, we can use any
a\in B
as the center of the ball
B
.

Another crucial property of the radius of
B
is that it determines the distance between elements of different children of
B
in
\mathcal{T}_{S}
as follows.

Property 2
.

Let
B_{1},B_{2}\in\operatorname{children}(B)
with
B_{1}\neq B_{2}
. Then
\textbf{u}(a_{1},a_{2})=\operatorname{r}_{S}(B)
for every
a_{1}\in B_{1},a_{2}\in B_{2}
.

Example 4.3
.

In the ultrametric tree of Figure
1(b)
we display the radius of each ball. One can check that the root node
S=\{t_{1},\ldots,t_{6}\}
satisfies that
\operatorname{r}_{S}(S)=\nicefrac{{1}}{{2}}
and
\textbf{u}_{\operatorname{rel}}(t,t^{\prime})=\nicefrac{{1}}{{2}}
for every
t\in\{t_{1},\ldots,t_{4}\}
and
t^{\prime}\in\{t_{5},t_{6}\}
. Hence, Property
2
holds in this case. ∎

By Properties
1
and
2
, the ultrametric tree
\mathcal{T}_{S}
and the radius function
\operatorname{r}_{S}
completely determine the ultrametric over a finite set
S
and they will be the starting point for our algorithms. By the following property, we can always construct both in quadratic time over the size of
|S|
.

Property 3
.

Given an ultrametric
u
and a finite set
S
, we can construct
\mathcal{T}_{S}
and
\operatorname{r}_{S}
in
O(|S|^{2})
.

Property
3
above
can be easily seen by making use of the classical result that
a minimum-weight spanning tree
\mathcal{T}
of a graph
G=(S,S\times S)
, where
u
expresses the edge weight,
can be computed in time
O(|S|^{2})
and the fact that
\mathcal{T}_{S}
and
\operatorname{r}_{S}
can be
easily computed from
\mathcal{T}
. On the other hand, it is also easy to see that, in general, one cannot compute the ultrametric tree
\mathcal{T}_{S}
in time
o(|S|^{2})
. Indeed, we just have to consider an ultrametric on
a set
S=\{a_{1},\dots,a_{n}\}
where only one pair
(a_{i},a_{j})
of elements has distance 1 and all other pairs have distance 2. Then one cannot compute

\mathcal{T}_{S}
and
\operatorname{r}_{S}
without finding this pair
(a_{i},a_{j})
.

5
Ultrametrics for explicit representation

In this section, we present our first algorithmic results for the
\mathtt{DiversityExplicit}[\delta]

problem, i.e., the problem of finding a
k
-diverse subset of a finite set
S
given a diversity function
\delta
of an ultrametric
u
. Here, we assume that
S
is represented explicitly, namely,
S
is given as a finite list
a_{1},\ldots,a_{n}
.

In order to find tractable scenarios for the explicit case, we
introduce the notion of subset-monotonicity for diversity functions.
A diversity function
\delta
of a metric
d
is said to
be
subset-monotone
if and only if for every
A\subseteq\mathcal{U}

and every pair
B,B^{\prime}\subseteq\mathcal{U}
such that
B=\{b_{1},\ldots,b_{\ell}\}
,
B^{\prime}=\{b_{1}^{\prime},\ldots,b_{\ell}^{\prime}\}
,
A\cap B=A\cap B^{\prime}=\emptyset
,
\delta(B)\leq\delta(B^{\prime})
, and
\textbf{d}(a,b_{i})\leq\textbf{d}(a,b_{i}^{\prime})
for every
a\in A
and
i\in\{1,\ldots,\ell\}
, it holds
that
\delta(A\cup B)\leq\delta(A\cup B^{\prime})
. Subset-monotonicity
captures the natural intuition that, if we replace
B
with
B^{\prime}
such
that
B^{\prime}
is at least as diverse as
B
and
B^{\prime}
is farther from
A
than
B
,
then
A\cup B^{\prime}
is at least as diverse as
A\cup B
.

We observe that, for ultrametrics, all diversity functions from Section
2
are subset-monotone. The diversity functions
\delta_{\operatorname{sum}}
and
\delta_{\operatorname{min}}
have this property even for arbitrary metrics.

Proposition 5.1
.

The diversity functions
\delta_{\operatorname{sum}}
and
\delta_{\operatorname{min}}
are subset-monotone for every metric.
If
\delta_{\operatorname{W}}
extends an ultrametric, then it is also subset-monotone.
If
\delta_{\operatorname{W}}
extends an arbitrary metric, then it is, in general, not subset-monotone.

Interestingly, if
\delta
is a subset-monotone diversity function
over an ultrametric
u
, then we can always find a
k
-diverse
subset of a finite set
S
efficiently. In fact, it is possible to
prove this result even if we consider a weaker notion of
subset-monotonicity. A diversity function
\delta
over a metric
d
is said to
be
weakly subset-monotone
if and only if for every
A\subseteq\mathcal{U}
and
every pair
B,B^{\prime}\subseteq\mathcal{U}
such that
B=\{b_{1},\ldots,b_{\ell}\}
,
B^{\prime}=\{b_{1}^{\prime},\ldots,b_{\ell}^{\prime}\}
,
A\cap B=A\cap B^{\prime}=\emptyset
,
\delta(B)\leq\delta(B^{\prime})
and
\textbf{d}(a,b_{i})=\textbf{d}(a,b_{i}^{\prime})

for every
a\in A
and
i\in\{1,\ldots,\ell\}
, it holds that

\delta(A\cup B)\leq\delta(A\cup B^{\prime})
.
In other words, if we replace
B
with
B^{\prime}
such that
B^{\prime}
is
at least as diverse as
B
and both have the
same pairwise distance

to
A
,
then
A\cup B^{\prime}
is at least as diverse as
A\cup B
. Note that this
weaker version is almost verbatim from subset monotonicity, but with
the condition
\textbf{d}(a,b_{i})\leq\textbf{d}(a,b_{i}^{\prime})
replaced by
\textbf{d}(a,b_{i})=\textbf{d}(a,b_{i}^{\prime})
. Clearly, subset-monotonicity implies weak
subset-monotonicity but not vice versa.

Theorem 5.2
.

Let
\delta
be a weakly subset-monotone diversity function of an ultrametric
u
. Then the problem
\mathtt{DiversityExplicit}[\delta]
can be solved in time
O(k^{2}\cdot f_{\delta}(k)\cdot|S|+|S|^{2})
where
O(f_{\delta}(k))
is the time required to compute
\delta
over a set of size
k
.

Note that
f_{\delta}(k)\leq k^{2}
for
\delta_{\operatorname{sum}}
,
\delta_{\operatorname{min}}
, and
\delta_{\operatorname{W}}
, so
we conclude from Theorem
5.2
that the problem

\mathtt{DiversityExplicit}[\delta]
can be solved in polynomial time for
these fundamental diversity functions.

Proof Sketch of Theorem
5.2
.

The main ideas of the algorithm for Theorem
5.2
are the following.
Let
S
be a finite subset of the universe
\mathcal{U}
,
u
an ultrametric over
\mathcal{U}
, and
\delta
a weakly subset-monotone diversity function of
u
. By Proposition
3
, we can construct an ultrametric tree
\mathcal{T}_{S}
of
S
in time
O(|S|^{2})
. For the sake of simplification, assume that
\mathcal{T}_{S}
is a binary tree. Otherwise, one can easily extend the following ideas to the non-binary case. For each vertex
B
(i.e., a ball) of
\mathcal{T}_{S}
, we maintain a function
\mathsf{C}_{B}\colon\{0,\dots,\min\{k,|B|\}\}\rightarrow 2^{B}
where
\mathsf{C}_{B}(i)
is an

i
-diverse subset of
B
. That is, for every
i\in\{0,\dots,\min\{k,|B|\}\}
we have

\mathsf{C}_{B}(i)\ :=\ \argmax_{A\subseteq B:|A|=i}\delta(A).

Clearly, if we can compute
\mathsf{C}_{S}
for the root
S
of
\mathcal{T}_{S}
, then
\mathsf{C}_{S}(k)
is a
k
-diverse subset for
S
.

The algorithm follows a dynamic programming approach, computing
\mathsf{C}_{B}
for each
B\in\mathcal{B}_{S}
in a bottom-up fashion over
\mathcal{T}_{S}
. For every ball
B
, we can easily check that
\mathsf{C}_{B}(0)=\emptyset
and
\mathsf{C}_{B}(1)=\{a\}
for some
a\in B
. In particular,
\mathsf{C}_{\{a\}}=\big\{0\mapsto\emptyset,1\mapsto\{a\}\big\}
is our base case for every leaf
\{a\}
of
\mathcal{T}_{S}
.
For an inner vertex
B
of
\mathcal{T}_{S}
, the process is a bit more involved. Let
B_{1}
and
B_{2}
be the two children of
B
in
\mathcal{T}_{S}
and assume that we have already computed
\mathsf{C}_{B_{1}}
and
\mathsf{C}_{B_{2}}
.
We claim that, for every
i\in\{0,\dots,\min\{k,|B|\}\}
, we can calculate
\mathsf{C}_{B}(i)
as
\mathsf{C}_{B}(i)=\mathsf{C}_{B_{1}}(i_{1})\cup\mathsf{C}_{B_{2}}(i_{2})
, where
i_{1},i_{2}
are obtained as follows:

(i_{1},i_{2})=\argmax_{(j_{1},j_{2}):j_{1}+j_{2}=i}\delta(\mathsf{C}_{B_{1}}(j_{1})\cup\mathsf{C}_{B_{2}}(j_{2})).

Intuitively, when maximizing diversity with
i
elements of
B
, one must try all combinations
of a
j_{1}
-diverse subset from
B_{1}
and a
j_{2}
-diverse subset from
B_{2}
,
such that
i=j_{1}+j_{2}
holds.
That is, the best elements to pick from
B_{1}
and
B_{2}
are found in
\mathsf{C}_{B_{1}}
and
\mathsf{C}_{B_{2}}
, respectively.

To see that the claim holds, let
A
be a subset of
B
with
i
-elements maximizing
\delta(A)
. Define
A_{1}:=A\cap B_{1}
and
A_{2}:=A\cap B_{2}
, and their sizes
i_{1}:=|A_{1}|
and
i_{2}:=|A_{2}|
, respectively. Due to the optimality of
\mathsf{C}_{B_{1}}
, we know that
\delta(A_{1})\leq\delta(\mathsf{C}_{B_{1}}(i_{1}))
. Further,
\textbf{u}(a_{1},a_{2})=\textbf{u}(a_{1}^{\prime},a_{2})=\operatorname{r}_{S}(B)
for every
a_{1}\in A_{1},a_{1}^{\prime}\in\mathsf{C}_{B_{1}}(i_{1}),a_{2}\in A_{2}
by Property
2
. Then the conditions of weak subset-monotonicity are satisfied and
\delta(A_{1}\cup A_{2})\leq\delta(\mathsf{C}_{B_{1}}(i_{1})\cup A_{2})
. Following the same argument, we can conclude that
\delta(\mathsf{C}_{B_{1}}(i_{1})\cup A_{2})\leq\delta(\mathsf{C}_{B_{1}}(i_{1})\cup\mathsf{C}_{B_{2}}(i_{2}))
, proving that
\mathsf{C}_{B_{1}}(i_{1})\cup\mathsf{C}_{B_{2}}(i_{2})
is optimal.

By the previous ideas, the desired algorithm
with time complexity
O(k^{2}\cdot f_{\delta}(k)\cdot|S|+|S|^{2})

for solving the
\mathtt{DiversityExplicit}[\delta]
problem follows.
∎

By Theorem
5.2
, we get the following result for finding
k
-diverse outputs of CQ query evaluation, where

f_{Q}(D)\leq|D|^{|Q|}
.

Corollary 5.3
.

Let
u
be an ultrametric over tuples,
\delta
be a weakly subset-monotone diverse function of
u
, and
Q
be a fixed CQ (i.e., data complexity). Given a relational database
D
, and a value
k
(in unary), we can compute a
k
-diverse subset of
{\lsem{}{Q}\rsem}(D)
with respect to
\delta
in time
O(k^{2}\cdot f_{\delta}(k)\cdot|{\lsem{}{Q}\rsem}(D)|+|{\lsem{}{Q}\rsem}(D)|^{2}+f_{Q}(D))
where
f_{Q}(D)
is the time required to evaluate
Q
over
D
.

An open question is whether we can extend
Theorem
5.2
beyond weakly subset-monotone diversity
functions (extending ultrametrics). We provide here a partial answer by
focusing on monotone diversity functions. A diversity function

\delta
of a metric
d
is said to be
monotone
if and only if for every
A,A^{\prime}\subseteq\mathcal{U}
such that
A=\{a_{1},\ldots,a_{\ell}\}
,
A^{\prime}=\{a_{1}^{\prime},\ldots,a_{\ell}^{\prime}\}
, and
\textbf{d}(a_{i},a_{j})\leq\textbf{d}(a_{i}^{\prime},a_{j}^{\prime})
for
every
i,j\in\{1,\ldots,\ell\}
, it holds that

\delta(A)\leq\delta(A^{\prime})
. Monotone diversity functions were
considered in
[
21
]
as a general class of natural diversity
functions.
In the next result, we show that monotonicity of the
diversity function
\delta
over some ultrametric is, in general,
not enough to make the
\mathtt{DiversityExplicit}[\delta]
problem tractable.

Theorem 5.4
.

The
\mathtt{DiversityExplicit}[\delta]
problem is
\mathsf{NP}
-hard even for a monotone, efficiently computable diversity function
\delta
based on an ultrametric.

That is, the previous result implies that there are monotone diversity functions beyond the weakly subset-monotone class where the algorithmic strategy of Theorem
5.2
cannot be used.

6
Ultrametrics for implicit representations

We move now to study the case when
S
is represented implicitly. Our motivation for implicit representations is to model the query evaluation setting: we receive as input a query
Q
and a database
D
, and we want to compute a
k
-diverse subset of
S={\lsem{}{Q}\rsem}(D)
. The main challenge is that
S
could be of exponential size concerning
|Q|
and
|D|
; namely,
S
is implicitly encoded by
Q
and
D
, and it is not efficient first to compute
S
to find a
k
-diverse subset of
S
. To formalize this setting in general, given a universe
\mathcal{U}
, we say that an
implicit schema over
\mathcal{U}
is a tuple
(\mathcal{I},{\lsem{}{\cdot}\rsem})
where
\mathcal{I}
is a set of objects called implicit representations, and
{\lsem{}{\cdot}\rsem}
is a function that maps every implicit representation
I\in\mathcal{I}
to a finite subset of
\mathcal{U}
. Further, we assume the existence of a size function
|\cdot|:\mathcal{I}\rightarrow\mathbb{N}
that represents the size
|I|
of each implicit representation
I\in\mathcal{I}
. For example,
\mathcal{I}
can be all pairs
(Q,D)
where
Q
is a CQ and
D
is a relational database,
{\lsem{}{\cdot}\rsem}
maps each pair
(Q,D)
to
{\lsem{}{Q}\rsem}(D)
, and
|(Q,D)|=|Q|+|D|
. Note that we do not impose any restriction on the number of elements of
{\lsem{}{I}\rsem}
, so it can be arbitrarily large with respect to
|I|
. Our goal in this section is to compute efficiently, given an implicit representation
I\in\mathcal{I}
and
k>1
, a
k
-diverse subset of
{\lsem{}{I}\rsem}
with respect to a diversity function
\delta
of an ultrametric
u
.

Given this general scenario, we need a way to navigate through the
elements of
{\lsem{}{I}\rsem}
. In particular, we need a way to navigate the
ultrametric tree
\mathcal{T}_{{\lsem{}{I}\rsem}}
of
u
over
{\lsem{}{I}\rsem}
.
Like
{\lsem{}{I}\rsem}
,
\mathcal{T}_{{\lsem{}{I}\rsem}}
could be arbitrarily
large with respect to
|I|
, so it could be unfeasible to construct

\mathcal{T}_{{\lsem{}{I}\rsem}}
explicitly. For this reason, we will assume that our
implicit schemas admit some efficient algorithms for
traversing ultrametric trees. Formally,
an
implicit ultrametric tree
for an implicit schema

(\mathcal{I},{\lsem{}{\cdot}\rsem})
consists of three algorithms

(\texttt{Root},\texttt{Children},\texttt{Member})
such that, given an implicit representation

I\in\mathcal{I}
and a ball
B\in\mathcal{B}_{{\lsem{}{I}\rsem}}
:

1.

\texttt{Root}(I)
computes the root of
\mathcal{T}_{{\lsem{}{I}\rsem}}
in polynomial time with respect to
|I|
;

2.

\texttt{Children}(I,B)
enumerates all children of
B
in
\mathcal{T}_{{\lsem{}{I}\rsem}}
with polynomial delay w.r.t.
|I|
; and

3.

\texttt{Member}(I,B)
outputs one solution in
B
in polynomial time with respect to
|I|
.

Further, when we say that a method receives a ball
B
as input or enumerates
B
as output, it means an ID representing the ball
B
.
Recall that
B\subseteq{\lsem{}{I}\rsem}
and then
B
could be large with respect to
|I|
. For this reason, methods
\texttt{Root}(I)
and
\texttt{Children}(I,B)
output IDs representing balls in
\mathcal{B}_{{\lsem{}{I}\rsem}}
, that one later uses to call
Children
and
Member
. Here, we assume that each ID has the size of one register of the RAM or a small number of registers that one can bound by some parameter on
I
(e.g., the arity of query answers if
(\mathcal{I},{\lsem{}{\cdot}\rsem})
models the query evaluation setting).
For example, in the next section we show that such a representation exists in the case of acyclic CQs.
Regarding performance, we say that we can compute an implicit ultrametric tree in time
O(f_{\mathcal{T}}(I))
, for some function
f_{\mathcal{T}}
, if the running time of
Root
and
Member
, and the delay of
Children
are in
O(f_{\mathcal{T}}(I))
.
Note that we can always assume that
f_{\mathcal{T}}(I)\leq|I|^{\ell}
for some constant
\ell
.

Unlike the results presented in Section
5
, there
is a difference in the complexity of the problem
\mathtt{DiversityImplicit}[\delta]

depending on whether a diversity function is subset-monotone or weakly
subset-monotone. First, it is possible to show that

\mathtt{DiversityImplicit}[\delta]
is tractable when restricted to the class of subset-monotone diversity functions.

Theorem 6.1
.

Let
(\mathcal{I},{\lsem{}{\cdot}\rsem})
be an implicit schema and
u
an ultrametric over a common universe
\mathcal{U}
that admit an implicit
ultrametric tree, and
\delta
be a subset-monotone diversity
function of
u
.
Further, assume that the running time of computing
\delta
over a
k
-subset of
\mathcal{U}
is bounded by
O(f_{\delta}(k))
, and we can compute the implicit ultrametric tree in time
O(f_{\mathcal{T}}(I))
. Then, the problem
\mathtt{DiversityImplicit}[\delta]
can
be solved in time
O(k\cdot f_{\mathcal{T}}(I)+k^{2}\cdot f_{\delta}(k))
.

Proof sketch.

The algorithm of Theorem
6.1
follows a different approach than
the algorithm for explicit representation
in Theorem
5.2
. Instead of processing the
ultrametric tree in a bottom-up fashion, it proceeds top-down by using
the interface of the implicit representation of the ultrametric tree
and following a greedy approach:
we maintain a set of solutions
S
and a set of candidates
L
.
At each step we add a
l\in L
to
S
that maximizes the “incremental” diversity, i.e., crucially

\delta(S\cup\{l\})=\max_{l^{\prime}\in L}\delta(S\cup\{l^{\prime}\})=\max_{l^{\prime\prime}\in{\lsem{}{I}\rsem}}\delta(S\cup\{l^{\prime\prime}\}).

Due to subset-monotonicity, proceeding greedily is correct and due to the implicit ultrametric tree, we can maintain
L
efficiently, i.e., it requires time
O(f_{\mathcal{T}}(I))
at each step.
∎

Unfortunately, and in contrast with Theorem
5.2
in Section
5
, the tractability of the problem
\mathtt{DiversityImplicit}[\delta]
no longer holds if we consider weakly subset-monotone diversity functions.
To prove this, let
d
be any metric over a universe
\mathcal{U}
, and define the
sum-min diversity function

\delta_{\operatorname{sum-min}}
as follows. For every set
S\in\operatorname{finite}(\mathcal{U})
:
\delta(S)=0
if
|S|=1
, and
\delta(S)
is given by the following expression if
|S|>1
:

\delta_{\operatorname{sum-min}}(S)\ :=\ \sum_{a\in S}\textbf{d}(a,S\setminus\{a\})\ =\ \sum_{a\in S}\,\min_{b\in S\,:\,b\neq a}\textbf{d}(a,b).

Intuitively,
\delta_{\operatorname{sum-min}}
is summing the contribution of each element
a\in S
to the diversity of
S
, namely, how far is
a
from the other elements in
S
. One can see
\delta_{\operatorname{sum-min}}
as a non-recursive version of the Weitzman diversity function. Like the other diversity functions used before, we can prove that
\delta_{\operatorname{sum-min}}
is also a weakly subset-monotone diversity function.

Proposition 6.2
.

\delta_{\operatorname{sum-min}}
is weakly subset-monotone if it extends an ultrametric.

As we show next,
\delta_{\operatorname{sum-min}}
serves as an example of a
weakly subset-monotone diversity function of an ultrametric
u
for which
one can find an implicit representation that admits an implicit
ultrametric tree, but where it is hard to find a
k
-diverse subset.

Theorem 6.3
.

There exists an implicit schema
(\mathcal{I},{\lsem{}{\cdot}\rsem})
and an ultrametric
u
over a common universe
\mathcal{U}
which admit an implicit ultrametric tree but for which
\mathtt{DiversityImplicit}[\delta_{\operatorname{sum-min}}]
is
\mathsf{NP}
-hard.

A natural question is whether subset-monotonicity can be relaxed in
other ways to allow for the tractability of the problem

\mathtt{DiversityImplicit}[\delta]
. We conclude this section by providing an
answer to this question when considering the notion of
fixed-parameter tractable (FPT) algorithms.
More precisely, we say that a diversity function
\delta
of a metric

d
over
\mathcal{U}
is
weakly monotone
if, and only if, for every set

A\subseteq\mathcal{U}
and every
b,b^{\prime}\in\mathcal{U}
such that
A\cap\{b,b^{\prime}\}=\emptyset
and
\textbf{d}(a,b)\leq\textbf{d}(a,b^{\prime})
for every
a\in A
, it holds that

\delta(A\cup\{b\})\leq\delta(A\cup\{b^{\prime}\})
. In other words, if
we extend
A
with
b
or
b^{\prime}
, then
A\cup\{b^{\prime}\}
will be at least as diverse as

A\cup\{b\}
given that
b^{\prime}
is farther from
A
than
b
.

Every subset-monotone function is also weakly monotone, but weak
subset-monotonicity does not necessarily imply weak
monotonicity. However, one can check that all diversity functions
used in this paper are weakly monotone, in particular,
\delta_{\operatorname{sum-min}}
.

Theorem 6.4
.

For every implicit schema
(\mathcal{I},{\lsem{}{\cdot}\rsem})
and
ultrametric
u
over a common universe
\mathcal{U}
which admits an implicit ultrametric
tree, and for every computable weakly monotone diversity function
\delta
of

u
, the problem
\mathtt{DiversityImplicit}[\delta]
is fixed-parameter
tractable in
k
.

Proof sketch.

Our FPT algorithm navigates the ultrametric tree top-down by using its implicit representation, but this time it considers balls up to distance
k
from the root.
In the worst case, the ultrametric tree is binary and we have to consider all balls up to depth
k
.
We then iterate over these balls (up to
2^{k}
many), obtaining a set
S
by selecting one solution form each ball. We show that if
\delta
is weakly monotone, a
k
-diverse subset of
S
is a
k
-diverse subset of
{\lsem{}{I}\rsem}
.
∎

7
Efficient computation of diverse answers to ACQs

In this section, we use the results for implicit representations from the previous section to obtain efficient algorithms for finding
k
-diverse subsets of the answers to acyclic CQ (ACQ) with respect to the ultrametric
\textbf{u}_{\operatorname{rel}}
over tuples presented in Section
4
.
Note that here we study algorithms for ACQ in combined complexity (i.e., the query
Q
is not fixed), in contrast to Corollary
5.3
whose analysis is in data complexity (i.e.,
Q
is fixed).
In the following, we start by recalling the definition of ACQ and discussing the ultrametric
\textbf{u}_{\operatorname{rel}}
. Then, we show our main results concerning computing diverse query answers for ACQ.

Acyclic CQ is the prototypical subclass of conjunctive queries that allow for tractable query evaluation
(combined complexity)
[
38
,
4
]
. We therefore also take ACQ as the
natural starting point in our effort to develop efficient algorithms for finding
k
-diverse sets. Let
Q
be a CQ like in (
2
). A
join tree
for
Q
is a labeled tree
T=(V,E,\lambda)
where
(V,E)
is a undirected tree and
\lambda
is a bijective function from
V
to the atoms
\{R_{1}(\bar{x}_{1}),\ldots,R_{m}(\bar{x}_{m})\}
. Further, a join tree
T
must satisfy that each variable
x\in\mathcal{X}
forms a connected component in
T
, namely, the set
\{v\in V\mid\text{$x$ appears in the atom $\lambda(v)$}\}
is connected in
T
. Then
Q
is
acyclic
iff there exists a join tree for
Q
.
Also, we say that
Q
is a
free-connex ACQ
iff
Q
is acyclic and the body together with the head of
Q
is acyclic (i.e., admits a join tree).

For our algorithmic results over ACQ, we restrict to the ultrametric
\textbf{u}_{\operatorname{rel}}
over tuples of a schema
\sigma
, previously defined in Section
4
.
Arguably,
\textbf{u}_{\operatorname{rel}}
is a natural ultrametric for comparing tuples of relations that has been used for computing diverse subsets in previous work
[
32
,
33
]
.
Let
Q
be a CQ with head
Q(\bar{x})
.
Note that the variable order
\bar{x}
in
Q(\bar{x})
is important for measuring the diversity of subsets of
{\lsem{}{Q}\rsem}(D)
for some database
D
. Concretely, if we have two CQ
Q
and
Q^{\prime}
with the same body but with different orders in their heads, then diversity of the subsets of
{\lsem{}{Q}\rsem}(D)
and
{\lsem{}{Q^{\prime}}\rsem}(D)
could be totally different.

By using Theorem
6.1
over ACQ and the ultrametric
\textbf{u}_{\operatorname{rel}}
, we can find quasilinear time algorithms with respect to
|D|
for finding
k
-diverse sets of query answers.

Theorem 7.1
.

Let
\delta
be a subset-monotone diversity function of the ultrametric
\textbf{u}_{\operatorname{rel}}
such that the running time of computing
\delta
over a set of size
k
is bounded by
O(f_{\delta}(k))
. Given an ACQ
Q
, a relational database
D
, and a value
k
(in unary), a
k
-diverse subset of
{\lsem{}{Q}\rsem}(D)
with respect to
\delta
can be computed in time
O(k\cdot|Q|\cdot|D|\cdot\log(|D|)+k^{2}\cdot f_{\delta}(k))
.

Proof Sketch.

To apply Theorem
6.1
, we need to describe an implicit ultrametric tree for tuples in
{\lsem{}{Q}\rsem}(D)
. A helpful property of ultrametric
\textbf{u}_{\operatorname{rel}}
is that balls in
\mathcal{B}_{{\lsem{}{Q}\rsem}(D)}
can be represented by the common prefix of their tuples. More specifically, for every ball
B\in\mathcal{B}_{{\lsem{}{Q}\rsem}(D)}
there exist values
c_{1},\ldots,c_{i}
such that
B=\{Q(\bar{a})\in{\lsem{}{Q}\rsem}(D)\mid\forall j\leq i.\,\bar{a}[j]=c_{j}\}
.
Then, we can traverse the ultrametric tree of
\textbf{u}_{\operatorname{rel}}
over
{\lsem{}{Q}\rsem}(D)
, by managing partial outputs (i.e., prefixes) of
{\lsem{}{Q}\rsem}(D)
.

Let
Q
be an ACQ like (
2
). To arrive at the methods
Root
,
Children
, and
Member
, we modify Yannakakis algorithm
[
38
]
to find the following data values that extend a given prefix.
Concretely, given values
c_{1},\ldots,c_{i}
that represent a ball
B
, we want to find all values
c
such that
c_{1},\ldots,c_{i},c
is the prefix of a tuple in
{\lsem{}{Q}\rsem}(D)
. For this, we can consider the subquery
Q^{\prime}(\bar{x}[i+1]))\leftarrow R_{1}(h(\bar{x}_{1})),\ldots,R_{m}(h(\bar{x}_{m}))
where
h
is a partial assignment that maps
h(\bar{x}[j])=c_{j}
for every
j\leq i
and
h(x)=x
for any other variable
x\in\mathcal{X}
. The subquery
Q^{\prime}
is also acyclic and returns all the desired values
c
, such that
c_{1}\ldots,c_{i},c
represents a child of
B
. Thus, running Yannakakis algorithm over
Q^{\prime}
and
D
, we can compute
Children
in time
O(|Q|\cdot|D|\cdot\log(|D|))
and similarly for the methods
Root
or
Member
.
∎

A natural next step to improve the running time of Theorem
7.1
is to break the dependency between
k
and
|Q|\cdot|D|\cdot\log(|D|)
. Towards this goal, we take inspiration from the work of Carmeli et al.
[
6
]
, which studied direct access to ranked answers of conjunctive queries. In this work, the algorithmic results also depend on the attribute order, characterizing which CQs and orders admit direct access to the results.
For this characterization, the presence of a disruptive trio in the query is crucial. Let
Q
be a CQ like (
2
). We say that two variables
x
and
y
in
Q
are neighbors if they appear together in
Q
in some atom. Then we say that three positions
i,j,k
(i.e., variables
\bar{x}[i]
,
\bar{x}[j]
, and
\bar{x}[k]
) in the head of
Q
form a
disruptive trio
iff
\bar{x}[i]
and
\bar{x}[j]
are not neighbors in
Q
, and
\bar{x}[k]
is a neighbor of
\bar{x}[i]
and
\bar{x}[j]
in
Q
, but
i<k
and
j<k
(i.e.,
\bar{x}[k]
appears after
\bar{x}[i]
and
\bar{x}[j]
). For example, for the query
Q(x_{1},x_{2},x_{3},x_{4})\leftarrow R(x_{1},x_{2}),S(x_{2},x_{4}),T(x_{4},x_{3})
, the positions
2,3,4
form a disruptive trio, but
1,2,3
do not.

In the following result, we show that free-connex ACQ and the absence of a disruptive trio are what we need to get better algorithms for computing
k
-diverse subsets.

Theorem 7.2
.

Let
\delta
be a subset-monotone diversity function of the ultrametric
\textbf{u}_{\operatorname{rel}}
such that the running time of computing
\delta
over a set of size
k
is bounded by
O(f_{\delta}(k))
. Given a free-connex ACQ
Q
without a disruptive trio, a relational database
D
, and a value
k
(in unary), a
k
-diverse subset of
{\lsem{}{Q}\rsem}(D)
with respect to
\delta
can be computed in time
O(|Q|\cdot|D|\cdot\log(|D|)+k\cdot|Q|+k^{2}\cdot f_{\delta}(k))
.

Proof Sketch.

Similar to Theorem
7.1
, we use the prefix of tuples to represent balls and take advantage of the structure of a join tree and the absence of disruptive trios to implement an index over
D
. By
[
6
]
, the absence of disruptive trios ensures the existence of a
layered join tree
whose layers follow the order of the variables in the head of
Q
. Then, by using the layered join tree, we can compute an index in time
O(|Q|\cdot|D|\cdot\log(|D|))
that we can use to calculate the next data value in a prefix, like in Theorem
7.1
, but now in time
O(|Q|)
.
Thus, after a common preprocessing phase,
\texttt{Root},\texttt{Children}
and
Member
run in time
O(|Q|)
.
∎

Note that in data complexity, the only remaining non-(quasi)linear term in Theorem
7.2
is
k^{2}\cdot f_{\delta}(k)
which arises since we have to reevaluate
\delta
at each step to find the next greedily best pick.
For some specific diversity function this may not be necessary.
As an example, for the Weitzman diversity function
\delta_{\operatorname{W}}
we can get rid of this term
k^{2}\cdot f_{\delta}(k)
by smartly keeping track of which answer maximizes the diversity next.

Theorem 7.3
.

Let
\delta_{\operatorname{W}}
be the Weitzman diversity function over the ultrametric
\textbf{u}_{\operatorname{rel}}
.
Given a free-connex ACQ
Q
without a disruptive trio, a relational database
D
, and a value
k
(in unary), a
k
-diverse subset of
{\lsem{}{Q}\rsem}(D)
with respect to
\delta_{\operatorname{W}}
can be computed in time
O(|Q|\cdot|D|\cdot\log(|D|)+k\cdot|Q|)
.

Related work

Diversification

Aiming for a small,
diverse
subset of the solutions has been adopted in many areas
as a viable strategy of dealing
with a solution space that might possibly be overwhelmingly big.
This is, in particular, the case in data mining, information retrieval, and web science, where
the term
“diversification of search results”
is commonly used for the process of
extracting a small diverse subset from a huge set of solutions, see e.g.,

[
30
,
7
,
27
,
11
,
26
]
and the surveys

[
39
,
36
]
.
The diversity of solutions has also been intensively studied by the Artificial Intelligence (AI) community.
Notably, this is the case in subfields of AI which are most closely related to
database research, namely constraint satisfaction (recall that, from a logical point of view,
solving constraint satisfaction problems and evaluating
conjunctive queries are equivalent tasks)

[
16
,
13
,
14
,
25
]

and answer set programming (which corresponds to datalog with unrestricted negation under stable model semantics)
[
9
]
.
In the database community, the diversification of query answers has been on the agenda for over a
decade: the computation of diverse query results was studied in
[
32
,
33
]
for relational data and in

[
20
]
for XML data.
In
[
34
]
, a system was presented
with an extension of SQL to allow for requesting diverse answers.
In
[
8
]
, query result diversification is studied as
a “bi-criteria” optimization problem that aims at finding
k
query answers that maximize both, the diversity and the relevance of the answers.
Recent publications witness the renewed interest in the diversity of query answers
by the database systems community
[
24
,
17
]
and the database theory community
[
3
,
21
]
.

Measuring diversity

In
[
16
]
, a whole framework for dealing with the
diversity of subsets of the solutions
has been proposed. There, diversity is defined by first defining the distance between two solutions and then
combining the pairwise distances via an aggregate function such as, for instance,
sum, min, or max.
In
[
35
]
,
a more sophisticated way of aggregating pairwise distances has
led to the definition of the diversity function
\delta_{\operatorname{W}}
,
which we have had a closer look at in our work.
Yet more complexity was introduced in

[
28
]
, where the diversity of a subset of solutions not only takes the
relationships between the chosen solutions into account but also their relationship with the solutions
excluded from the subset.

For the distance between two solutions, any metric can be used. As is argued in
[
35
]
,
it ultimately depends on the application context which distance function (and, consequently, which diversity function)
is appropriate. Note that
diversity and similarity can be seen as two sides of the same medal. Hence, all
kinds of similarity measures studied in the
data mining and
information retrieval communities are, in principle, also candidates for the distance function;
e.g., the Minkowski distance with Manhattan and Euclidean
distance as important special cases as well as Cosine distance when solutions are represented as vectors, the edit
distance for solutions as strings, or the Jaccard Index for solutions as sets, etc.,
see e.g.,
[
10
,
37
]
.

Ultrametrics

The study of ultrametrics started in various areas of mathematics (such as real analysis, number theory, and
general topology – see
[
19
]
)
in the early 20th century. Ultrametrics are particularly well suited for hierarchical clustering and, as such,
they have many applications in various sciences such as
psychology, physics, and biology
(see, e.g.,
[
23
,
18
,
35
]
) and, of course,
also in data mining,
see e.g.,
[
29
]
.
Ultrametrics have also been used in database research and
related areas:
in
[
15
]
,
several convergence criteria for the fixed-point iteration of datalog programs (or, more generally, logic programs) with negation are defined. To this end, the set of possible ground atoms is divided into
levels
and
two sets of ground atoms are considered as more diverse if they differ on an earlier level. Clearly, this is
an ultrametric.
In
[
32
,
33
]
,
the distance between tuples is defined by imposing an order on the attributes and considering two
tuples as more diverse if they differ on an earlier attribute in this ordering
(see also Example
4.1
in the current paper). Again, this is clearly an ultrametric, even though it was not
explicitly named as such in
[
32
,
33
]
.

Computing diversity

It should be noted that searching for diverse sets
is, in general, an intractable problem.
For instance, in
[
21
]
, NP-completeness of the

\mathtt{DiversityExplicit}[\delta]
problem
3
3

3

Strictly speaking, in
[
21
]
,
S
was defined as the result set of an FO-query.
However,
since data complexity was considered, we can of course compute
S
upfront in polynomial time and may,
therefore, assume
S
to be explicitly given.

was proved even for the simple setting
where
S
is a set of tuples of arity five and defining the
diversity via the sum or min of the pairwise Hamming distances.
Consequently,
approximations or heuristics are typically proposed
to compute diverse sets (see
[
36
]
for a very recent survey on
diversification methods).
In
[
5
]
, the parameterized version of the
\mathtt{DiversityExplicit}[\delta]
problem was studied for cases where
the problem of
deciding the existence of a solution is fixed-parameter tractable (FPT)
w.r.t. the treewidth.
As a
prototypical problem, the Vertex Cover problem was studied and it was shown that, when defining the
diversity as the sum of the pairwise Hamming distances, then the
\mathtt{DiversityExplicit}[\delta]

problem is FPT w.r.t. the treewidth
w
and the size
k
of the desired diversity set.
Moreover, it was argued in

[
5
]

that analogous FPT-results for the
\mathtt{DiversityExplicit}[\delta]
problem apply to
virtually any problem where the decision of the existence of a solution
is FPT w.r.t. the treewidth.
In
[
21
]
, the
\mathtt{DiversityExplicit}[\delta]
problem was shown FPT
w.r.t. the size
k
of the desired diversity set, when considering
S
as a set of tuples and defining
the diversity via a monotone aggregate function
over the pairwise Hamming distances of the tuples.

However,
tractable
,
exact
methods for computing diverse sets
are largely missing with one notable exception:
in
[
33
]
,
an efficient method for solving the
\mathtt{DiversityExplicit}[\delta]
problem
in a very specific setting is presented, where the diversity
\delta
is defined as the sum over the ultrametric defined via an ordering of the attributes as recalled in Example
4.1
.
Assuming the existence of a tree representation of the relation
S

in the style of a Dewey tree known from
XML query processing
[
31
]
,
the algorithm in
[
33
]
finds a
k
-diverse set in
O(k)
time.
Other than that, the field of tractable diversity computation is wide open and the main goal of this work is to fill this gap.

9
Conclusions

In this work, we have studied the complexity of 3 levels of
diversity
problems.
For the most basic problem
\mathtt{DiversityComputation}[\delta]
of computing the diversity
\delta(S)
for a given set
S
of elements, we have closed a problem left open in
[
35
]
by
proving intractability of this problem in case of the Weitzman diversity measure
\delta_{\operatorname{W}}
.
We have then pinpointed the boundary between tractability and intractability for
both, the
\mathtt{DiversityExplicit}[\delta]
and the
\mathtt{DiversityImplicit}[\delta]
problems
(i.e., the problems of maximizing the diversity of an explicitly or implicitly given
set
S
, respectively)
in terms of monotonicity properties of the diversity function
\delta
extending
an ultrametric.
In particular, this has allowed us to identify tractable cases of
the
\mathtt{DiversityImplicit}[\delta]
problem when considering acyclic conjunctive queries.

There are several natural directions of generalizing our results: clearly, they are naturally extended to more general query classes than
acyclic CQs such as
CQs with bounded (generalized or fractional)
hypertree-width

\begin{array}[]{rcl}\delta_{\operatorname{sum}}(A\cup B)&=&\sum_{a,a^{\prime}\in A}\textbf{d}(a,a^{\prime})+\sum_{a\in A,b\in B}\textbf{d}(a,b)+\sum_{b,b^{\prime}\in B}\textbf{d}(b,b^{\prime})\\

&=&\delta_{\operatorname{min}}(A\cup B^{\prime}).\end{array}

\begin{array}[]{rcl}\delta_{\operatorname{W}}(A\cup B)&=&\sum_{i=1}^{t}\min\{\textbf{u}(a_{i},a_{j}),\textbf{u}(a_{i},b)\mid i<j,b\in B\}+\sum_{i=1}^{l-1}\min\{\textbf{u}(b_{i},b_{j})\mid i<j\}\\

\texttt{Member}(I,B_{\text{fc}})
where
B_{\text{fc}}
is the first-child of
B
in the implicit ultrametric tree. In other words, if we call
\texttt{Children}(I,B).\texttt{init}
, then it always holds that:

\texttt{Member}(I,B)=\texttt{Member}(I,\texttt{Children}(I,B).\texttt{current}).

This assumption simplifies the presentation of the algorithm considerably, and we can assume it without loss of generality. Indeed, if it does not hold, the algorithm will require an extra check, increasing the whole running time only by a constant.

Intuitively, Algorithm
1
keeps a set
S
of solutions, and its primary goal is to maximize the “incremental” diversity of adding a new element to
S
. This new element is chosen from the current balls of the ultrametric tree that have not been visited yet. For this purpose, the algorithm maintains a set
L
of balls such that, for each
B\in L
, the algorithm is iterating through the children of
B
by using the iteration interface
\texttt{Children}(I,B)
. The algorithm picks the new element that maximizes the incremental diversity of
S
greedily from
L
by computing (line 7):

B\leftarrow\argmax_{B\in L}\delta(S\cup\{\texttt{Member}(I,\texttt{Children}(I,B).\texttt{current})\}.

Then the algorithm adds
\texttt{Member}(I,\texttt{Children}(I,B).\texttt{current})
to
S
(line 8) and moves to the next children of
B
(line 9) until
S
has size
k
or
L
is empty (line 6).

Following the above strategy, Algorithm
1
starts by picking the root ball
B_{\texttt{root}}=\texttt{Root}(I)
and adds a first solution to
S
(line 2). Then, it adds
B_{\texttt{root}}
to
L
for iterating through its children (lines 3 and 4). By assumption
(\ddagger)
, the solution in
B_{\texttt{root}}
added to
S
is the same as the first children of
B_{\texttt{root}}
. For this reason, the algorithm skips the first children of
B_{\texttt{root}}
by calling
\texttt{Children}(I,B_{\texttt{root}}).\texttt{next}
.

When Algorithm
1
reaches the end of the children of a ball
B\in L
(line 9), it removes
B
from
L
(line 10). After this, it iterates over all the children
B^{\prime}
of
B
(line 11), adding
B^{\prime}
to
L
whenever
B^{\prime}
is not a leaf node in the ultrametric tree, namely,
|B^{\prime}|>1
(lines 12 and 13). Similar to the initial case, by assumption
(\ddagger)
we can skip the first sibling
B_{\text{fc}}
of
B^{\prime}
, given that the solution that
B_{\text{fc}}
can contribute to
S
is already in
S
(lines 14 and 15).

Correctness

We prove the correctness of Algorithm
1
in three steps.

For the first step, we prove that, at the beginning of each iteration (line 6),
S
and
L
cover all solutions
{\lsem{}{I}\rsem}
, i.e.,
S\cup\bigcup_{B\in L}B={\lsem{}{I}\rsem}
.
We show this by induction on the number of iterations.
This is certainly true before the first iteration, since
B_{\texttt{root}}
is the root of the ultrametric tree and
B_{\texttt{root}}={\lsem{}{I}\rsem}
.
For any iteration,
S
only grows while
L
only changes if
\texttt{Children}(I,B).\texttt{next}=\texttt{false}
(line 9).
Then, the algorithm removes
B
from
L
and adds all
B^{\prime}\in\texttt{Children}(I,B)
to
L
for which
|B^{\prime}|>1
.
Note that, if
|B^{\prime}|=1
, then
B^{\prime}\subseteq S
as at least one element
a\in B^{\prime}
of each child
B^{\prime}
of
B
was added to
S
.
Given that
\texttt{Children}(I,B)
forms a partition of
B
, we can assert that
B\subseteq S\cup\bigcup_{B^{\prime}\in\texttt{Children}(I,B),|B^{\prime}|>1}B^{\prime}
.
We conclude that
S\cup\bigcup_{B\in L}B={\lsem{}{I}\rsem}
still holds.

For the second step, we show that, at the beginning of each iteration, for any
a\in{\lsem{}{I}\rsem}\setminus S
, there exists
B\in L
such that
\delta(S\cup\{a\})\leq\delta(S\cup\{b\})
for
b=\texttt{Member}(I,\texttt{Children}(I,B).\texttt{current})
. In other words, in steps 7 and 8 the algorithm chooses an element that maximizes the incremental diversity of
S
.
To prove this, take any
a\in{\lsem{}{I}\rsem}\setminus S
.
By the first step, there must exists
B\in L
such that
a\in B
. Let
B^{\prime}=\texttt{Children}(I,B).\texttt{current}
and
b=\texttt{Member}(I,B^{\prime})
.
On the one hand, for every
s\in S\cap B
, it holds that
\textbf{u}(s,a)\leq r(B)
. Given that
S\cap B^{\prime}=\emptyset
(i.e.,
B^{\prime}
has not been considered yet),
\textbf{u}(s,b)=r(B)
(by Property
2
). In particular,
\textbf{u}(s,a)\leq\textbf{u}(s,b)
.
On the other hand, for every
s\in S\setminus B
, it holds that
\textbf{u}(s,a)=\textbf{u}(s,b)
given that
a,b\in B
. Combining both cases, we have that
\textbf{u}(s,a)\leq\textbf{u}(s,b)
for every
s\in S
.
Now, if we choose
A=S
,
B=\{a\}
, and
B^{\prime}=\{b\}
, we conclude by subset-monotonicity that
\delta(S\cup\{a\})\leq\delta(S\cup\{b\})
.

For the last step, we prove that the algorithm always outputs a
k
-diverse set with respect to
\delta
.
Let
S=\{s_{1},\ldots,s_{k}\}
be the output of the algorithm where
s_{1},\ldots,s_{k}
is the order how the algorithm added the elements to
S
.
Towards a contradiction, assume that there exists
S^{\prime}\subseteq{\lsem{}{I}\rsem}
of size
k
such that
\delta(S)<\delta(S^{\prime})
. Let
M
be the set of all
S^{\prime}
such that
\delta(S)<\delta(S^{\prime})
and
|S^{\prime}|=k
. Pick one
S^{*}\in M
that contains the longest prefix of
s_{1},\ldots,s_{k}
, namely,
S^{*}=\argmax_{S^{\prime}\in M}\{m\mid s_{1},\ldots,s_{m}\in S^{\prime}\}
. Then
s_{1},\ldots,s_{m}\in S^{*}
but
s_{m+1}\notin S^{*}
.
Also, let
s^{*}\in S^{*}
be such that
\textbf{u}(s_{m+1},S^{*}\setminus\{s_{1},\ldots,s_{m}\})=\textbf{u}(s_{m+1},s^{*})
(i.e.,
s^{*}
is one of the closest elements to
s_{m+1}
in
S^{*}\setminus\{s_{1},\ldots,s_{m}\}
). Define
A=S^{*}\setminus\{s_{1},\ldots,s_{m},s^{*}\}
,
B=\{s_{1},\ldots,s_{m},s^{*}\}
, and
B^{\prime}=\{s_{1},\ldots,s_{m},s_{m+1}\}
.
By the second step, we know that
\delta(B)\leq\delta(B^{\prime})
. Furthermore, for every
a\in A
we have that:

\textbf{u}(a,s^{*})\leq\max\{\textbf{u}(a,s_{m+1}),\textbf{u}(s_{m+1},s^{*})\}=\max\{\textbf{u}(a,s_{m+1}),\textbf{u}(s_{m+1},S^{*}\setminus\{s_{1},\ldots,s_{m}\})\}=\textbf{u}(a,s_{m+1}).

The remaining elements
B\setminus\{s^{*}\}
are the same as
B^{\prime}\setminus\{s_{m+1}\}
and
\textbf{u}(a,s_{i})=\textbf{u}(a,s_{i})
.
Then, applying subset-monotonicity, we get that:

\delta(S^{*})=\delta(A\cup B)\leq\delta(A\cup B^{\prime})

This means that
A\cup B^{\prime}\in M
but
A\cup B^{\prime}
has a longer prefix of
s_{1},\ldots,s_{k}
than
S^{*}
, which is a contradiction. We conclude that the output
S
of Algorithm
1
is a
k
-diverse set of
{\lsem{}{I}\rsem}
with respect to
\delta
.

Running time

By inspecting Algorithm
1
, one can check that the number of balls of the ultrametric tree that are used is at most
O(k)
. By caching the result of the functions
Children
and
Member
, we can bound the running time of these methods in the algorithm by
O(k\cdot f_{\mathcal{T}}(I))
.

Now, let
f_{\delta}(n)
be a function such that the running time of computing
\delta(A)
over a set
A
of size
n
is bounded asymptotically by
f_{\delta}(n)
. One can check that
|L|\in O(k)
and, for each iteration, we compute
B
by calling
\delta
exactly
|L|
-times over a set of size at most
k
. Then, the running time of line 7 takes at most
O(k\cdot f_{\delta}(k))
. Overall, we can bound the running time of Algorithm
1
by:

O(k\cdot f_{\mathcal{T}}(I)+k^{2}\cdot f_{\delta}(k)).

∎

Proof of Proposition

Proof.

We show that
\delta_{\operatorname{sum-min}}
is subset monotone.
Let
A\subseteq\mathcal{U},B=\{b_{1},\dots,b_{l}\},B^{\prime}=\{b^{\prime}_{1},\dots,b^{\prime}_{l}\}
with
\emptyset=A\cap B=A\cap B^{\prime}

\delta_{\operatorname{sum-min}}(B)\leq\delta_{\operatorname{sum-min}}(B^{\prime})

\textbf{u}(a,b_{i})=\textbf{u}(a,b^{\prime}_{i})
for any

and

We need to show that
\delta_{\operatorname{sum-min}}(A\cup B)\leq\delta_{\operatorname{sum-min}}(A\cup B^{\prime})
.
To that end, we start by computing the contributions of
a\in A
, i.e.,

\displaystyle\textbf{u}(a,A\cup B\setminus\{a\})

\displaystyle=\min\{\min_{a^{\prime}\in A:a^{\prime}\neq a}\textbf{u}(a,a^{\prime}),\min_{b_{i}\in B}\textbf{u}(a,b_{i})\}

\displaystyle=\min\{\min_{a^{\prime}\in A:a^{\prime}\neq a}\textbf{u}(a,a^{\prime}),\min_{b^{\prime}_{i}\in B^{\prime}}\textbf{u}(a,b^{\prime}_{i})\}

\displaystyle=\textbf{u}(a,A\cup B^{\prime}\setminus\{a\}).

For the elements
b_{i}\in B
the argument is more involved.
For that, let

\displaystyle B(b_{i})

\displaystyle:=\{b_{j}\in B\mid\textbf{u}(b_{i},b_{j})\leq\min\{\textbf{u}(b_{i},A),\textbf{u}(b_{j},A)\}\}\subseteq B

\displaystyle B^{\prime}(b^{\prime}_{i})

\displaystyle:=\{b^{\prime}_{j}\in B^{\prime}\mid\textbf{u}(b^{\prime}_{i},b^{\prime}_{j})\leq\min\{\textbf{u}(b^{\prime}_{i},A),\textbf{u}(b^{\prime}_{j},A)\}\}\subseteq B^{\prime}.

Of course,
B(b_{i})=B(b_{j})
for
b_{j}\in B(b_{i})
.
Furthermore, for
b_{i},b_{j}\in B(b_{i})
there is a
a(b_{i},b_{j})\in A
such that
\textbf{u}(b_{i},b_{j})\leq\min\{\textbf{u}(b_{i},A),\textbf{u}(b_{j},A)\}=\min\{\textbf{u}(b_{i},a(b_{i},b_{j})),\textbf{u}(b_{j},a(b_{i},b_{j}))\}
.
Thus, also
\textbf{u}(b_{i},a(b_{i},b_{j}))=\textbf{u}(b_{j},a(b_{i},b_{j}))
.
Then, also

\displaystyle\textbf{u}(b^{\prime}_{i},b^{\prime}_{j})

\displaystyle\leq\max\{\textbf{u}(b^{\prime}_{i},a(b_{i},b_{j})),\textbf{u}(b^{\prime}_{j},a(b_{i},b_{j}))\}

\displaystyle=\max\{\textbf{u}(b_{i},a(b_{i},b_{j})),\textbf{u}(b_{j},a(b_{i},b_{j}))\}

\displaystyle=\textbf{u}(b_{i},a(b_{i},b_{j}))=\textbf{u}(b_{j},a(b_{i},b_{j}))

\displaystyle=\min\{\textbf{u}(b_{i},A),\textbf{u}(b_{j},A)\}

\displaystyle=\min\{\textbf{u}(b^{\prime}_{i},A),\textbf{u}(b^{\prime}_{j},A)\}.

Thus,
\{b^{\prime}_{j}\mid b_{j}\in B(b_{i})\}\subseteq B^{\prime}(b^{\prime}_{i})
for any
i\in\{1,\dots,l\}
.
Analogously, we can argue that
\{b_{j}\mid b^{\prime}_{j}\in B^{\prime}(b^{\prime}_{i})\}\subseteq B(b_{i})
.
Therefore,
B^{\prime}(b^{\prime}_{i})=\{b^{\prime}_{j}\mid b_{j}\in B(b_{i})\}
and
B(b_{i})=\{b_{j}\mid b^{\prime}_{j}\in B^{\prime}(b^{\prime}_{i})\}
.

Furthermore, we show that
\textbf{u}(b_{i},b_{j})=\textbf{u}(b^{\prime}_{i},b^{\prime}_{j})
if
b_{j}\not\in B(b_{i})
(equally, if
b_{i}\not\in B(b_{j})

b^{\prime}_{i}\not\in B^{\prime}(b^{\prime}_{j})

To that end, let
b_{j}\not\in B(b_{i})

W.l.o.g.,
\textbf{u}(b_{i},A)\leq\textbf{u}(b_{j},A)
and, thus,
\textbf{u}(b_{i},b_{j})>\textbf{u}(b_{i},A)=\textbf{u}(b_{i},a)
for some

.
Then,
\textbf{u}(b_{i},b_{j})=\textbf{u}(b_{j},a)
(recall for an ultrametric
\textbf{u}(\alpha,\beta)<\textbf{u}(\beta,\gamma)
implies
\textbf{u}(\alpha,\gamma)=\textbf{u}(\beta,\gamma)
).
Furthermore,
b^{\prime}_{j}\not\in B^{\prime}(b^{\prime}_{i})
and thus,

\textbf{u}(b^{\prime}_{i},b^{\prime}_{j})>\min\{\textbf{u}(b^{\prime}_{i},A),\textbf{u}(b^{\prime}_{j},A)\}=\min\{\textbf{u}(b_{i},A),\textbf{u}(b_{j},A)\}=\textbf{u}(b_{i},A)=\textbf{u}(b_{i},a)=\textbf{u}(b^{\prime}_{i},a)\}.

Therefore, also
\textbf{u}(b^{\prime}_{i},b^{\prime}_{j})=\textbf{u}(b^{\prime}_{j},a)=\textbf{u}(b_{j},s)=\textbf{u}(b_{i},b_{j})
.

Moreover, if
|B(b_{i})|=|B^{\prime}(b^{\prime}_{i})|=1
, then
\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})=\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})\leq\textbf{u}(t^{\prime}_{i},T^{\prime}-t^{\prime}_{i})

\displaystyle\sum_{i=1}^{l}

\displaystyle\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})

\displaystyle=\sum_{|B(b_{i})|=1}(\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})+\textbf{u}(b_{i},B\setminus\{b_{i}\})-\textbf{u}(b_{i},B\setminus\{b_{i}\}))+\sum_{|B(b_{i})|>1}\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})

\displaystyle=\sum_{|B(b_{i})|=1}(\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})+\textbf{u}(b_{i},B\setminus\{b_{i}\})-\textbf{u}(b_{i},B\setminus\{b_{i}\}))+\sum_{|B(t_{i})|>1}\textbf{u}(b_{i},B\setminus\{b_{i}\})

\displaystyle=\sum_{|B(b_{i})|=1}(\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})-\textbf{u}(b_{i},B\setminus\{b_{i}\}))+\sum_{i=1}^{l}\textbf{u}(b_{i},B\setminus\{b_{i}\})

\displaystyle=\sum_{|B(b_{i})|=1}(\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})-\textbf{u}(b_{i},B\setminus\{b_{i}\}))+\delta_{\operatorname{sum-min}}(B)

\displaystyle\leq\sum_{|B^{\prime}(b^{\prime}_{i})|=1}(\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})-\textbf{u}(b^{\prime}_{i},B^{\prime}\setminus\{b^{\prime}_{i}\}))+\delta_{\operatorname{sum-min}}(B^{\prime})

\displaystyle=\sum_{|B^{\prime}(b^{\prime}_{i})|=1}(\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})-\textbf{u}(b^{\prime}_{i},B^{\prime}\setminus\{b^{\prime}_{i}\}))+\sum_{i=1}^{l}\textbf{u}(b^{\prime}_{i},B^{\prime}\setminus\{b^{\prime}_{i}\})

\displaystyle=\sum_{|B^{\prime}(b^{\prime}_{i})|=1}(\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})+\textbf{u}(b^{\prime}_{i},B^{\prime}\setminus\{b^{\prime}_{i}\})-\textbf{u}(b^{\prime}_{i},B^{\prime}\setminus\{b^{\prime}_{i}\}))+\sum_{|B^{\prime}(b^{\prime}_{i})|>1}\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})

\displaystyle=\sum_{i}\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\}).

In total,

\displaystyle\delta_{\operatorname{sum-min}}(A\cup B)

\displaystyle=\sum_{a\in A}\textbf{u}(a,A\cup B\setminus\{a\})+\sum_{i=1}^{l}\textbf{u}(b_{i},A\cup B\setminus\{b_{i}\})

\displaystyle\leq\sum_{a\in A}\textbf{u}(a,A\cup B^{\prime}\setminus\{a\})+\sum_{i=1}^{l}\textbf{u}(b^{\prime}_{i},A\cup B^{\prime}\setminus\{b^{\prime}_{i}\})=\delta_{\operatorname{sum-min}}(A\cup B^{\prime}).

This concludes the proof.
