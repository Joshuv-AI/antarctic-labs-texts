Abstract
A novel search method for large polarization kernels is proposed. The algorithm produces a kernel with given partial distances by employing the depth-first search combined with the computation of coset leaders weight tables and sufficient conditions of code non-equivalence. Using the proposed method, we improved all existing lower bounds on the maximum error exponent for kernels of size from 17 to 29. We also obtained kernels which admit low complexity processing by the recently proposed recursive trellis algorithm. Numerical results demonstrate the advantage of polar codes with the obtained kernels compared with shortened polar codes and polar codes with small kernels.

Polar codes proposed by Arıkan
[
1

achieve the symmetric capacity of a binary-input memoryless channel

. They have low complexity construction, encoding, and decoding algorithms. However, their finite-length performance turns out to be quite poor.

One way to address this problem is to replace the Arıkan matrix by a larger matrix referred to as
polarization kernel

[
2

having better polarization properties. Moreover, polar codes with large kernels were shown to provide an asymptotically optimal scaling exponent
[

Several fundamental bounds on the error exponent together with various kernel constructions have recently been derived
[

]
,
[
4
]
,
[

]
,
[

]
. Unfortunately, the construction of a polarization kernel of an arbitrary length with the best polarization properties remains an intractable problem. In this paper we are focusing on finding the kernels with as large error exponent as possible. To do this, we propose the search algorithm for polarization kernels with given

. This algorithm is based on depth-first search combined with the computation of coset leaders weight tables and sufficient conditions of code non-equivalence. This allows us to find polarization kernels of sizes

[

]
,
[

.

We also demonstrate the application of the proposed approach to the construction of polarization kernels which admit low complexity processing by the recently proposed recursive trellis algorithm
[

III
Basic search algorithm

III-A

Motivations of the proposed approach

Finite length performance of polar codes can be improved by improving the polarization parameters of the constituent kernels. In this work we are focusing on the error exponent, since it is independent of a channel and can be explicitly computed.

Problem 1
.

Find an
l\times l
polarization kernel with the maximal error exponent, i.e. obtain

K^{\star}=\arg\max_{K\in\mathbf{K}_{l}}E(K),

(4)

where
\mathbf{K}_{l}
is a set of all
l\times l
binary polarization kernels. By
E_{l}^{\star}
we denote
E(K^{\star})

Problem
1
was solved for kernels of length from
2
to
16

[
5
]
. For kernels of greater size there are only various upper bounds on the error exponent
[
2
,
4
,
5
]
. Obviously, the direct solution of Problem
1
is infeasible. Hence, in this work our goal is to improve the lower bound
E_{l}^{\star}
by finding
l\times l
kernels with error exponent as large as possible.

Let us denote a length

PDP
\mathcal{D}
as

if there exists an
l\times l
kernel with PDP
\mathcal{D}
. Hence, the set
\mathbf{K}_{l}
can be represented as the following disjoint union of sets

\mathbf{K}_{l}=\bigcup_{\mathcal{D}\in\mathbf{D}_{l}}\mathbf{K}_{l}(\mathcal{D}),

(5)

where
\mathbf{D}_{l}
is a set of all valid
l
-length PDPs, and
\mathbf{K}_{l}(\mathcal{D})
is a set of
l\times l
kernels with PDP
\mathcal{D}
. Such a representation of
\mathbf{K}_{l}
implies the following
approach for the approximate solution of problem
1
. Let
\widehat{E}_{l}
be the maximal error exponent among known

kernels. For instance, we can combine the results from

]
and

]
. Then

1.

Generate the set

\widetilde{\mathbf{D}}_{l}
of possibly valid PDPs

with

\frac{1}{l}\sum^{l-1}_{i=0}\log_{l}\mathcal{D}_{i}>\ \widehat{E}_{l};

2.

For each
\mathcal{D}\in\widetilde{\mathbf{D}}_{l}
try to construct at least one kernel
K
with PDP
\mathcal{D}.

The description of the proposed solution for the second task starts in Section
III-B
and continues in Section
IV
. We used the statement “possibly valid” in the sense that only necessary conditions
to check whether a PDP

is valid are known, which is described in detail in Section

.

Computing equivalence invariants on codes

Definition 3
.

Let
K
and
\widehat{K}
be
l\times l
polarization kernels. We say that
\widehat{K}
is
equivalent
to
K
, if
\widehat{K}=XKP
for matrices
X
and
P
defined as in Proposition
1
.

Since the polarization properties of the equivalent kernels are the same, it is enough to consider only one kernel from each equivalence class.

The equivalence of two polarization kernels implies the equivalence of its kernel codes. That is, we propose to prune the equivalent kernel codes
\mathcal{C}_{K}^{(\phi)}
from the search tree, which can be done by solving the code equivalence problem. In our case we need only to check whether two codes are equivalent, the corresponding column permutation is not used.

Unfortunately, to the best of our knowledge, there are no simple solutions of the above task, and below we provide a short review of the known methods. It was shown in
[
22
]
that the code equivalence problem can be reduced to the graph isomorphism problem in polynomial time. There is a deterministic reduction running in
O(n^{\omega})
if
\text{hull}(\mathcal{C})=\mathcal{C}\cap\mathcal{C}^{\perp}
of a code
\mathcal{C}
is trivial (i.e. contains only zero codeword), where
\omega
is a matrix multiplication exponent
[
23
]
. The support splitting algorithm
[
24
]
can be used to find a permutation between two equivalent codes. Algorithm
[
25
]
computes the automorphism group using a set of minimal and next to minimal weight codewords. The code equivalence test based on the canonical augmentation is proposed in
[
26
,
27
]
.

That is, the code equivalence problem is hard to decide.
Hence, to keep the complexity of the polarization kernel search algorithm relatively simple, we consider the following approach.

Definition 4

(
[
24
]
)
.

Let
\mathcal{L}
denote the set of all codes. An
invariant

\mathcal{I}
over a set
E
is defined as a mapping
\mathcal{L}\rightarrow E
such that any two permutation equivalent codes take the same value.

Observe that by definition, in the general case the code invariant provides only sufficient condition of code non-equivalence.

Definition 5
.

Let
\mathcal{L}^{\star}
be a set of all non-equivalent
(n,k,d)
linear codes. We say that an invariant
\mathcal{I}
has
accuracy

\Delta_{\mathcal{I}}={|\left\{{\mathcal{I}(\mathcal{C})|\mathcal{C}\in\mathcal{L}^{\star}}\right\}|}/{|\mathcal{L}^{\star}|}.

Given an
(n,k)
linear code
\mathcal{C}
with the parity-check matrix
H
, we propose to compute the following several invariants.
Let
A(\mathcal{C})
be the weight distribution of a
\mathcal{C}
, i.e.

A(\mathcal{C})=(a_{0},a_{1},\dots,a_{n}),

where

a_{i}=|\left\{{c|c\in\mathcal{C},\wt(c)=i}\right\}|.

The first invariant we suggest to employ is

\mathcal{I}_{A}(\mathcal{C})=\begin{cases}A(\mathcal{C}),&\text{if }k\leq n/2,\\
A(\mathcal{C}^{\perp}),&\text{otherwise.}\end{cases}

Since
A(\mathcal{C}^{\perp})
can be obtained from
A(\mathcal{C})
by using the MacWilliams identities, the accuracy of both invariants is the same, but
A(\mathcal{C}^{\perp})
is easier to compute for
k>n/2
.

The second invariant we consider is
\mathcal{I}_{W}(\mathcal{C})=\mathcal{W}(\mathcal{C})
. It was proven
[
28
]
that the weight distribution of coset leaders
\mathcal{W}(\mathcal{C})
is not determined by
A(\mathcal{C})
, therefore, it may distinguish codes with the same weight distribution.

Following the support splitting algorithm
[
24
]
, we introduce the third invariant

\mathcal{I}_{S}(\mathcal{C})=\begin{cases}\left\{{A(s(\mathcal{C},i))|i\in[n]}\right\},&\text{if }k\leq n/2,\\
\left\{{A(s(\mathcal{C}^{\perp},i))|i\in[n]}\right\},&\text{otherwise,}\end{cases}

where
s(\mathcal{C},i)
is a code obtained by shortening of
\mathcal{C}
on a coordinate
i
. The weight distribution
A(s(\mathcal{C}^{\perp},i))
can be obtained from
A(s(\mathcal{C},i))
and
A(\mathcal{C})
(see Lemma 18 in
[
24
]
), hence the invariants
A(s(\mathcal{C},i))
and
A(s(\mathcal{C}^{\perp},i))
have the same accuracy, but the latter is easier to compute for
k>n/2
.

Since we consider short codes, all proposed invariants can be efficiently computed, stored, hashed, and compared. Moreover, given two invariants
\mathcal{I}_{F},\mathcal{I}_{G}
we can construct a new invariant

\mathcal{I}_{F,G}(\mathcal{C})=(\mathcal{I}_{F}(\mathcal{C}),\mathcal{I}_{G}(\mathcal{C}))

which may have higher accuracy. To investigate this, we generated sets
\widetilde{\mathcal{L}}^{\star}\subset\mathcal{L}^{\star}
of some

(n,k,d)
non-equivalent codes using software package
QextNewEdition

[
27
]
, and estimated accuracy of the considered invariants for the obtained sets
\widetilde{\mathcal{L}}^{\star}
.

Table
I
presents an estimation

\widetilde{\Delta}_{\mathcal{I}}={\left|\left\{{\mathcal{I}(\mathcal{C})|\mathcal{C}\in\widetilde{\mathcal{L}}^{\star}}\right\}\right|}/{\left|\widetilde{\mathcal{L}}^{\star}\right|}

of the accuracy
\Delta_{\mathcal{I}}
of the proposed invariants. It can be seen that the invariants
\mathcal{I}_{A}
and
\mathcal{I}_{\mathcal{W}}
distinguish non-equivalent codes quite weakly on their own, whereas combined in a pair, the accuracy significantly improves. At the same time, the invariant
\mathcal{I}_{S}(\mathcal{C})
is good enough, but the addition of
\mathcal{I}_{A}
and
\mathcal{I}_{\mathcal{W}}
to
\mathcal{I}_{S}(\mathcal{C})
still improves the overall accuracy.

Strictly speaking, all considered invariants do not provide the complete distinction of inequivalent codes, and consequently, if we use this modification, the algorithm is not guaranteed to find a kernel with given PDP even if it exists. Nevertheless, this approach provides significant search complexity reduction and still allows us to obtain polarization kernels, as it is demonstrated in the next sections.

In this section we assemble the methods described in Sections

Suppose we are in the search tree node with an

VIII
Conclusion and open problems

In this paper a novel search method for large polarization kernels with given partial distance profile was proposed. This algorithm is based on depth-first search over sets of candidate rows. The proposed algorithm was used to improve the lower bounds on the maximal error exponent of sizes
17\leq l\leq 29
.

We also demonstrated application of the proposed method for finding kernels which admit low complexity processing by the recursive trellis processing algorithm. Numerical results show the advantage of the polar codes with the obtained kernels compared with shortened polar codes with the Arıkan kernel and polar codes with small kernels.

In the following, we outline multiple open problems with large kernels:

•

Tight bounds on partial distances.
There is a significant gap between the lower and upper bounds of the maximum error exponent of
l\times l
kernels for large
l
. Moreover, we have almost no bounds for non-monotonic partial distances, except the LP bound.

•

The problem of
scaling exponent minimization
remains unsolved. It is unknown whether the proposed method can be extended to explicitly solve it.

•

Processing complexity.
For some PDP the proposed algorithm can produce kernels which admit low complexity processing by RTPA. However, it is unknown how to obtain kernel with given PDP and minimum processing complexity.
