The Polynomial Hierarchy does not collapse
Reiner Czerwinski

Abstract
The arithmetical hierarchy ( 𝐀𝐇 {\mathbf{AH}} ) is similar to the polynomial hierarchy ( 𝐏𝐇 {\mathbf{PH}} ). Unlike the 𝐏𝐇 {\mathbf{PH}} , the 𝐀𝐇 {\mathbf{AH}} does not collapse relative to any oracle. A language in the ( k + 1 ) (k+1) -st level of the 𝐀𝐇 {\mathbf{AH}} is computable enumerable (c.e.) relative to the k k th level. So, given an oracle in the k k th level of the 𝐀𝐇 {\mathbf{AH}} , we could use a black-box search to decide whether the input word is in the language. With very large padding arguments, i.e. the paddings grow faster than any relative to the level k k of the 𝐀𝐇 {\mathbf{AH}} computable function, we would construct a language contained in the k + 1 k+1 level of 𝐏𝐇 {\mathbf{PH}} , if we use only a finite set of input words. From the oracle in 𝐀𝐇 {\mathbf{AH}} , we would construct an analogue oracle at the k k th level of 𝐏𝐇 {\mathbf{PH}} . For the input words of the finite set, a word is in the language of 𝐀𝐇 {\mathbf{AH}} , if and only if it is in the language of 𝐏𝐇 {\mathbf{PH}} . And the input word is in the oracle set of 𝐀𝐇 {\mathbf{AH}} , if and only if it is in the oracle of 𝐏𝐇 {\mathbf{PH}} . As in the language of 𝐀𝐇 {\mathbf{AH}} , we must apply a black-box search in the language of 𝐏𝐇 {\mathbf{PH}} . So, we would also have exponentially many oracle queries in the language of 𝐏𝐇 {\mathbf{PH}} . The 𝐏𝐇 {\mathbf{PH}} does not collapse.



1
Introduction

The polynomial hierarchy (
\mathbf{PH}
) is similar to the arithmetical hierarchy (
\mathbf{AH}
).
A language
in the
{\mathbf{AH}}
is defined by additional variables, which are bounded by alternating existential and
universal quantifiers. These variables are connected with a computational relation.
The number of alternating quantifiers denotes the level in the hierarchy.
In the
{\mathbf{PH}}
the runtime and the lengths of the quantified variables are bounded
by a polynomial of the input length.

The
{\mathbf{AH}}
does not collapse. According to the
jump theorem
[
13
, page 53, Th. 2.3.]
, the
{\mathbf{AH}}
does not collapse relative to any oracle.
A proof for the
{\mathbf{PH}}
must circumvent the relativization barrier.
There are oracles where the
{\mathbf{PH}}
does not collapse relative to them
[
16
]
. The
{\mathbf{PH}}
does not collapse relative to random oracles
[
3
]
.
A good overview can be found in
[
11
]
.
On the other hand,
for every
k\in\bbbn
, there is an oracle
for which the polynomial hierarchy collapses on exactly the
k
th level relative to it
[
6
]
.

In Section
2
, we recall the definition of the
{\mathbf{AH}}
and the
{\mathbf{PH}}

and some properties of the
{\mathbf{PH}}
.

If we had an oracle
A
with
\Sigma_{1}\leq_{T}A
, and a language c.e. in
A
, then
we could analyze the number of oracle queries with black-box complexity.
We prove this in Section
3
when the oracle is in
\Pi_{k}.

In Section
4
, we obtain a connection from the
{\mathbf{AH}}
to the
{\mathbf{PH}}

via very large padding arguments.

In Section
5
, we combine the padding technique
of Section
4
with the black-box complexity results
of Section
3
.
We conclude that the
{\mathbf{PH}}
does not collapse.

In section
6
we argue why the proof method does not relativize.

2
Notations and Prerequisites

2.1
Languages

A language is a set of words. A word is a finite sequence of symbols.
Without loss of generality we can choose
\{0,1\}
as the set of symbols. So, the words are in
\{0,1\}^{*}
.
The complement of a language
L
is
\overline{L}=\bigl(\{0,1\}^{*}\setminus L\bigr)
.

2.2
Relations

If
A_{1},\dots,A_{n}
are sets,
then
R\subseteq A_{1}\times\cdots\times A_{n}
is an
n
-ary relation.
If the tuple
(a_{1},\dots,a_{n})\in A_{1}\times\cdots\times A_{n}

is in
R
, we denote
R(a_{1},\dots,a_{n})
.
We denote
\lnot R(a_{1},\dots,a_{n})
, if the tuple is not in the relation
R
.

A relation is computable if it is decidable with a Turing machine, whether
a tuple is in the relation or not.
An
n
-ary relation
R
is c.e., if there exists a sequence
(R_{t})
of
n
-ary computable relations with

R(x_{1},\dots,x_{n})\iff\exists t_{0}\;\forall t\geq t_{0}:R_{t}(x_{1},\dots,x_{n})

and

\lnot R(x_{1},\dots,x_{n})\iff\forall t:\lnot R_{t}(x_{1},\dots,x_{n}).

A relation
R
is co-c.e. if
\lnot R
is c.e.

Computable relations are more difficult to handle than c.e. relations.
A relation is c.e., if there exists a Turing machine which accepts the coding
of the tuple if and only if the tuple is in the relation. Finding a computable
TM is much harder.

2.3
Arithmetical Hierarchy

A language
L
is in
\Sigma_{k}
, if there exists a computable relation

R_{L}
with

\begin{split}x\in L\iff\exists y_{1}\in\{0,1\}^{*}\;\forall y_{2}\in\{0,1\}^{*}\dots Q_{k}y_{k}\in\{0,1\}^{*}:\\
R_{L}(x,y_{1},y_{2},\dots,y_{k})\end{split}

(1)

\text{where }Q_{i}=\begin{cases}\exists\text{ if }i\text{ is odd}\\
\forall\text{ if }i\text{ is even.}\end{cases}

The class
\Pi_{k}
is defined similarly to
\Sigma_{k}
, except, that
the first of the alternating quantifiers is universal and not existential.
A language
L
is in
\Pi_{k}
, if
\overline{L}\in\Sigma_{k}
.

The Arithmetical Hierarchy is defined as

{\mathbf{AH}}=\bigcup_{k\in\bbbn}\Sigma_{k}=\bigcup_{k\in\bbbn}\Pi_{k}.

Remark 1

In the literature, the variables in the definition are often natural numbers.
This definition of
{\mathbf{AH}}
is equivalent, since
there is a bijective computable function from
\bbbn
to
\{0,1\}^{*}
:

\rho(n)=b_{k-1}b_{k-2}\dots b_{0}\text{ where }n+1=\sum_{j=0}^{k}b_{j}*2^{j}\text{ and }b_{k}=1.

(2)

Lemma 1

Let the language
L
be defined with a c.e. or co-c.e. relation
R
, such that

L=\{x\mid Q_{1}y_{1}\in\{0,1\}^{\ast}\;Q_{2}y_{2}\in\{0,1\}^{\ast}\dots Q_{k}y_{k}\in\{0,1\}^{\ast}\;R(x,y_{1},y_{2},\dots,y_{k})\},

where
Q_{1},Q_{2},\dots,Q_{k}

Q_{K}=\begin{cases}\exists&\text{ if }R\text{ is c.e.}\\
\forall&\text{ if }R\text{ is co-c.e.}\\
\end{cases}

If

Q_{1}
is existential (universal), then

is in
\Sigma_{k}
(
\Pi_{k}
).

Proof

(i)

If

is a c.e. relation and
Q_{k}
is existential, then there exists a sequence of computable
relations

with

R(x,y_{1},\dots,y_{k})\iff\exists t:R_{t}(x,y_{1},\dots,y_{k}).

So,

\displaystyle L

\displaystyle=

\displaystyle\{x\mid Q_{1}y_{1}\in\{0,1\}^{\ast}\;Q_{2}y_{2}\in\{0,1\}^{\ast}\;\dots\exists y_{k}\in\{0,1\}^{\ast}\;\exists t\in\bbbn:

\displaystyle R_{t}(x,y_{1},y_{2},\dots,y_{k})\}

\displaystyle=

\displaystyle\{x\mid Q_{1}y_{1}\in\{0,1\}^{\ast}\;Q_{2}y_{2}\in\{0,1\}^{*}\;\dots\exists(y_{k},\rho(t))\in(\{0,1\}^{*})^{2}:

\displaystyle R_{t}(x,y_{1},y_{2},\dots,y_{k})\}.

If the quantifier
Q_{1}
is existential, then

L
fulfils the property in Equation (
1
).
In this case
L\in\Sigma_{k}
.
If the quantifier
Q_{1}
is universal, then
L_{R}\in\Pi_{k}
.

(ii)

If
R
is co-c.e. and
Q_{k}
is universal, then

\overline{L}=\{x\mid\overline{Q}_{1}y_{1}\in\{0,1\}^{\ast}\;\overline{Q}_{2}y_{2}\in\{0,1\}^{\ast}\dots\overline{Q}_{k}y_{k}\in\{0,1\}^{\ast}\;\lnot R(x,y_{1},y_{2},\dots,y_{k})\}

with

\overline{Q}:=\begin{cases}\forall&\text{ if }Q=\exists\\
\exists&\text{ if }Q=\forall\text{.}\end{cases}

As proven in (i),
\overline{L}
is in
\Pi_{k}
(
\Sigma_{k}
),
which implies, that
L
is in
\Sigma_{k}
(
\Pi_{k}
).

If
L\in\Sigma_{k}
with a computable relation
R_{L}
, that satisfies property
(
1
), we define the relation for
k\geq 1
:

\tilde{R}_{(L,k)}(x,y)\overset{\mathrm{def}}{\iff}\forall y_{2}\{0,1\}^{*}\dots Q_{k}y_{k}\in\{0,1\}^{*}:R_{L}(x,y,y_{2},\dots,y_{k})\text{.}

(3)

The set
\{(x,y)\in(\{0,1\}^{*})^{2}\mid\tilde{R}_{(L,k)}(x,y)\}
is in
\Pi_{k-1}
.
So the set is computable in
\Sigma_{k-1}
.

Theorem 2.1

Let
k
be a positive integer, and let
L
be a language in
\Sigma_{k}
.
If
\tilde{R}_{(L,k)}
is the binary relation in
\Pi_{k-1}

with
L=\{x\mid\exists y\in\{0,1\}^{*}\tilde{R}_{(L,k)}(x,y)\}

as
defined in Equation
3
,
and
X
is a finite set of words,
then there exists an
M

with

\text{ for all }x\in X:x\in L\iff\exists y\in\{0,1\}^{M}\tilde{R}_{(L,k)}(x,y)\text{.}

We denote
M=\eta(X,k,L)
.

Proof

Let
X=\{x_{1},\dots,x_{n}\}
be a finite set of words.
If
L
is in
\Sigma_{k}
, and
\tilde{R}_{(L,k)}
is a relation in
\Pi_{k-1}

that satisfies the property in Equation

,
then for every

there exists an

with

m\geq m_{x}\Rightarrow[x\in L\iff\exists y\in\{0,1\}^{\leq m}\tilde{R}_{(L,k)}(x,y)]\text{.}

Now we define

So,

\text{ for all }x\in X:x\in L\iff\exists y\in\{0,1\}^{\leq M}\tilde{R}_{(L,k)}(x,y)\text{.}

Properties of

[

]

A language is in

A language

2.4
Polynomial Hierarchy

Definition 1

If
A
is a set and
n>0
, then

A^{\leq n}\overset{\mathrm{def}}{=}\bigcup_{k\leq n}A^{k}\text{.}

The length of a word
x\in A^{*}
is
|x|=\min\{n\mid x\in A^{\leq n}\}
.
The word
1^{n}
is the unary coding of
n
.

The polynomial hierarchy is
{\mathbf{PH}}=\bigcup_{k\geq 0}\Sigma_{k}^{p}=\bigcup_{k\geq 0}\Pi_{k}^{p}
.

A language
L
is in
\Sigma_{k}^{p}
or
\Pi_{k}^{p}
if there exists a relation
R_{L}
computable in polynomial time, and polynomial
p
, such that

\begin{split}x\in L\Leftrightarrow Q_{1}y_{1}\in\{0,1\}^{\leq p(|x|)}\;\dots Q_{k}y_{k}\in\{0,1\}^{\leq p(|x|)}\;:\\
R_{L}(x,y_{1},\dots,y_{k})\text{.}\end{split}

There are alternating existential and universal quantifiers,

\text{i.e.\ }Q_{i}=\begin{cases}\exists\text{ if }i\text{ is odd}\\
\forall\text{ if }i\text{ is even}\end{cases}\text{ for }L\in\Sigma^{p}_{k}\text{ and}

Q_{i}=\begin{cases}\forall\text{ if }i\text{ is odd}\\
\exists\text{ if }i\text{ is even}\end{cases}\text{ for }L\in\Pi^{p}_{k}\text{.}

If
M
is a TM, then the language of
M
is
L(M)=\{x\mid M\text{ accepts }x\}
.
A set is c.e. if it is the language of a TM.

The following theorem is an exercise in some books, e.g. Homework 7.11 in
[
4
, p. 166]
.

Theorem 2.2

The set

\begin{split}S_{k}=\{\langle R,x,1^{m},1^{t}\rangle\mid\\
\exists y_{1}\in\{0,1\}^{\leq m}\forall y_{2}\{0,1\}^{\leq m}\dots Q_{k}y_{k}\in\{0,1\}^{\leq m}:\\
R(x,y_{1},y_{2},\dots,y_{k})\text{ and }R\text{ is computable within }t\text{ steps }\}\end{split}

is
\Sigma^{p}_{k}
-complete.

Proof

Obviously,
S_{k}
is in
\Sigma_{k}^{p}
.
If the language
L
is in
\Sigma_{k}^{p}
, then there exist polynomials
p
,
q
, and an
(n+1)
-ary relation
R
with

\begin{split}L=\bigl\{x\mid\exists y_{1}\in\{0,1\}^{\leq p(|x|)}\forall y_{2}\{0,1\}^{\leq p(|x|)}\dots Q_{k}y_{k}\in\{0,1\}^{\leq p(|x|)}:\\
R(x,y_{1},y_{2},\dots,y_{k})\text{ and }R\text{ is computable within }q(|x|)\text{ steps }\bigr\}.\end{split}

So, for all
x
,
\langle R,x,1^{p(|x|)},1^{q(|x|)}\rangle\in S_{k}
.
This implies
L\leq^{p}_{m}S_{k}
.

3
Black-Box Search and the
{\mathbf{AH}}

3.1
Oracles and computable Permutations

A computable permutation is a computable bijective function from
\bbbn
to
\bbbn
,
or from
\{0,1\}^{*}
to
\{0,1\}^{*}
.
The set of computable permutations is a group
[
10
, page 73, Th. I]
.
So, the inverse of a computable permutation is also a computable permutation.

If
A\subseteq\{0,1\}^{*}
and
f
is a computable permutation of
\{0,1\}^{*}
, then

A_{f}:=\{x\in\{0,1\}^{*}\mid f(x)\in A\}.

It is obvious, that
A_{f}\equiv_{T}A
.

Lemma 2

Let
A
be a language.
For every
x,y\in\{0,1\}^{*}
there exists a computable permutation
f

with
y=f(x)
.
Thus

x\in A\iff y\in A_{f}.

Proof

The permutation, that swaps
x
and
y
, i.e.

f(w)=\begin{cases}y&\text{if }w=x\\
x&\text{if }w=y\\
w&\text{otherwise,}\end{cases}

is computable.

3.2
Black-Box Complexity with Oracles

Theorem 3.1

Let
k
and
m
be positive integers,
k\geq 1
.
Let
\tilde{R_{L}}
be a
\Pi_{k}
-complete
2
-ary relation. An oracle
Turing mashine (OTM)
with an oracle for
\tilde{R}_{L}
, that decides whether

x\in L_{m}=\{x\mid\exists y\in\{0,1\}^{\leq m}\tilde{R}_{L}(x,y)\}

needs an oracle query for every
y\in\{0,1\}^{\leq m}
in the worst case.

Proof

The relation
\tilde{R}_{L}
is not computable.
We assume that we would have an
\tilde{R}_{L}
-oracle to search for
a
y
with
\tilde{R}_{L}(x,y)
.
In this case, we should use black-box search.
If there is a
\hat{y}\in\{0,1\}^{\leq m}
with
\tilde{R}_{L}(x,\hat{y})
, then
by Lemma
2

we can construct for each
\overline{y}\in\{0,1\}^{\leq m}
a computable permutation

f_{\overline{y}}
with
f_{\overline{y}}(\overline{y})=\hat{y}
. The language

L_{m,f_{\overline{y}}}=\{x\mid\exists y\in\{0,1\}^{\leq m}\;(\tilde{R}_{L}\circ f_{\overline{y}})(x,y)\}:=\{x\mid\exists y\in\{0,1\}^{\leq m}\;\tilde{R}_{L}(x,f_{\overline{y}}(y))\}

is
(\tilde{R}_{L}\circ f_{\overline{y}})
-computable, because
(\tilde{R}_{L}\circ f_{\overline{y}})\equiv_{T}\tilde{R}_{L}
. The search result is now at
(x,\overline{y})
.
So, we have to use the oracle
\tilde{R_{L}}
on any

y
with a length less than
m
in the worst case.

We need a black-box search to decide with the oracle
\tilde{R}_{L}

whether an input word is in

L_{m}=\{x\mid\exists y\in\{0,1\}^{\leq m}\;\tilde{R}_{L}(x,y)\}
.

The cardinality of
\bigl(\{0,1\}^{\leq m}\bigr)
is
N=2^{m+1}-1
.
If there is only one
y\in\{0,1\}^{\leq m}
with
\tilde{R}_{L}(x,y)
, then the black-box complexity,
i.e. the expected number of oracle queries,
is
N/2+1/2=2^{m}

[
15
, Th. 9.3.1]
.

4
The Relationship between
{\mathbf{PH}}
and
{\mathbf{AH}}

A set of
{\mathbf{AH}}
can be transformed into a problem of
{\mathbf{PH}}
by considering only a finite set of input words.
For a language
L
in
\Sigma_{k}
we use very large padding arguments to
construct a language
L^{\prime}
in
\Sigma_{k}^{p}
. For the finite set of input,s
a word is in

,if and only if the word is in

.

Lemma 3

Let
k
be a non-negative integer.
Let
L
be a language in
{\mathbf{AH}}
with c.e. or co-c.e.
k
-ary

We prove this lemma by induction over

.

]

is computable within
t

The set

In the induction step, we define the language

\begin{split}L:=\{x\mid Q_{1}y_{1}\in\{0,1\}^{*}Q_{2}y_{2}\in\{0,1\}^{*}\dots Q_{k+1}y_{k+1}\in\{0,1\}^{*}\\

W.l.o.g. the quantifier

If we choose

\begin{split}\bigl[x\in L\iff Q_{1}y_{1}\in\{0,1\}^{\leq M}Q_{2}y_{2}\in\{0,1\}^{\leq M}\dots Q_{k+1}y_{k+1}\in\{0,1\}^{\leq M}\\

The set

\begin{split}(x,y_{1},y_{2},\dots,y_{k+1})\in S\times(\{0,1\}^{\leq M})^{k}\Longrightarrow\\
\bigl[R_{L}(x,y_{1},y_{2},\dots,y_{k+1})\iff R_{L,T}(x,y_{1},y_{2},\dots,y_{k+1})\bigr]\end{split}

with
\lim_{t}R_{L,t}=R_{L}

The arithmetical hierarchy does not collapse

]
,
[

]

5
The
{\mathbf{PH}}
does not collapse

To show that the
{\mathbf{PH}}
does not collapse,
we prove
that for a language in
\Sigma_{k+1}^{P}
the runtime
is exponential relative to
\Sigma_{k}^{P}
.

Lemma 4

Let
k
be a positive integer.
If one computes a language in
\Sigma^{p}_{k+1}
with a
\Pi^{p}_{k}
-oracle,
then in the worst case one needs exponentially many oracle queries.

Proof

Let
