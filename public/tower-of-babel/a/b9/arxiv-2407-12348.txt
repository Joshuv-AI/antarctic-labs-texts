MM Algorithms for Statistical Estimation in Quantile Regression
Yifan CHENG, Anthony KUK Yung Cheung

Abstract
Quantile regression ( Koenker & Bassett, 1978 ) is a robust and practically useful way to efficiently model quantile varying correlation and predict varied response quantiles of interest. This article constructs and tests MM algorithms, which are simple to code and have been suggested superior to some other prominent quantile regression methods in nonregularized problems ( Pietrosanu et al., 2021 ) , in an array of linear quantile regression settings. Simulation studies comparing MM to existing tested methods and applications to various real data sets have corroborated our algorithms’ effectiveness.



1
Introduction

Predicting varied quantiles of the response variable is desirable in diverse domains (e.g.,
Buchinsky, 1995
,
Taylor & Bunn, 1998
;
Yu et al., 2003
;
Koenker, 2004
), as quantiles closer to the tails are of more interest than
q=0.5
in some applications. Various quantile estimation approaches (e.g.,
Cole, 1988
;
Efron, 1991
;
He, 1997
) have been proposed to model non-constant correlation patterns between the dependent and independent variables across different outcome quantiles, among which
Koenker & Bassett, 1978
’s method remains foremost. Quantile regression introduced by
Koenker & Bassett (1978)
not only excels in efficiently portraying a comprehensive picture of the regressor-regressand’s dependency structure but also stays more robust against outliers than ordinary regression of the mean.
Denote
n
and
p
as the sample size and covariate dimension (including the intercept), respectively. Suppose we have observed a sample (
\bm{x}_{i},y_{i}),\,i=1,2,\dots,n
. For any given quantile level
q\in(0,1)
and any specified regression function
f(\bm{X},\bm{\theta})
,
let
f_{i}(\bm{\theta}):\mathbb{R}^{p}\rightarrow\mathbb{R}=f(\bm{x}_{i},\bm{\theta})\text{ and }r_{i}(\bm{\theta})=y_{i}-f_{i}(\bm{\theta})
,
i=1,2,\dots,n
.
Koenker & Bassett (1978)
defined the regression quantile at
q
as the
p
-dimensional vector
\bm{\hat{\theta}}
that minimizes the asymmetric
L_{1}
loss function

L(\bm{\theta})=\sum_{i=1}^{n}\rho_{q}(r_{i}(\bm{\theta})),

(1.1)

where

\rho_{q}(r_{i})=|r_{i}|\left[q\mathbbm{1}_{\{r_{i}\geq 0\}}+(1-q)\mathbbm{1}_{\{r_{i}<0\}}\right]=qr_{i}-r_{i}\mathbbm{1}_{\{r_{i}<0\}},\quad i=1,2,\dots,n.

(1.2)

Compared to traditional least-squares estimators, the minimizers of
Equation

1.1
are much more robust to an array of non-normal error distributions while performing similarly well for Gaussian linear models
(
Koenker & Bassett, 1978
)
.

The prevailing most well-adopted quantile regression package in R is probably still
quantreg
developed by
Koenker (2010)
, which estimates empirical regression coefficients for specified quantile orders via a default simplex algorithm
(
Koenker & D’Orey, 1987
)
and an interior point method
(
Portnoy & Koenker, 1997
)
triggering the Frisch-Newton algorithm for huge data sets.
Pietrosanu et al. (2021)
advanced in questing robust accelerated quantile regression methods
(
Portnoy & Koenker, 1997
)
by conducting simulation studies on four prominent approaches – Alternating Direction Method of Multipliers (ADMM) algorithms, Coordinate Descent (CD) algorithms, MM algorithms, and algorithms adopted by
quantreg
. They found out that MM produced comparably accurate parameter estimates markedly faster than the other three methods in non-regularized quantile and composite quantile regression.

Although termed “algorithm”, MM, which stands for Majorize-Minimize for minimization problems and Minorize-Maximize for maximization problems, is in fact a strategy for creating an easy-to-minimize/maximize surrogate function that majorizes/minorizes the objective function. Given an objective function
L(\bm{\theta}):\mathbb{R}^{p}\rightarrow\mathbb{R}
that is difficult to be minimized directly and a current iteration’s parameter estimate
\bm{\theta}^{(t)}
(
t\in\mathbb{N}
), a surrogate function
Q\left(\bm{\theta|\theta}^{(t)}\right):\mathbb{R}^{p}\rightarrow\mathbb{R}
is called a majorizer of
L(\bm{\theta})
at
\bm{\theta}^{(t)}
if it satisfies

Q\big(\bm{\theta|\theta}^{(t)}\big)\geq L\left(\bm{\theta}\right)\text{ for all }\bm{\theta}

(1.3)

and in particular

Q\big(\bm{\theta}^{(t)}|\bm{\theta}^{(t)}\big)=L\big(\bm{\theta}^{(t)}\big).

(1.4)

If the value
\bm{\theta}^{(t+1)}
at which
Q\big(\bm{\theta|\theta}^{(t)}\big)
is minimized can be conveniently calculated, then
Q\big(\bm{\theta|\theta}^{(t)}\big)
yields a successful MM algorithm which drives the objective function
L(\bm{\theta})
further downhill each iteration thanks to the descent property

L\big(\bm{\theta}^{(t+1)}\big)\leq Q\big(\bm{\theta}^{(t+1)}|\bm{\theta}^{(t)}\big)\leq Q\big(\bm{\theta}^{(t)}|\bm{\theta}^{(t)}\big)=L\big(\bm{\theta}^{(t)}\big).

(1.5)

To construct suitable majorizing/minorizing surrogate functions and thus significantly simplify difficult optimization problems, MM typically exploits convexity/concavity and miscellaneous inequalities
(
Hunter & Lange, 2004
)
such as Jensen’s Inequality (which brings about the well-known EM algorithm, a special case of MM), Supporting Hyperplanes, Quadratic Upper Bound
(
B“”ohning & Lindsay, 1988
)
, the Arithmetic-Geometric Mean Inequality, and the Cauchy-Schwartz Inequality. The MM algorithm enjoys implementation simplicity and remarkable stability guaranteed by
Equation

1.5
while possessing complementary computation speed merits
(
Hunter & Lange, 2004
)
compared to the widely-adopted Newton-Raphson algorithm, and has hence gained application attention in diversified fields (e.g.,
Sabatti & Lange, 2002
;
Hunter & Lange, 2002
;
Hunter, 2004
;
Hunter & Li, 2005
).

2
MM Algorithms in Linear Quantile Regression

2.1
An MM Algorithm in Quantile Regression

For any given quantile level
q\in(0,1)
, the loss function
L(\bm{\theta})
in
Equation

1.1
is hard to directly minimize since it may accommodate multiple minima and its components (
1.2
) are non-differentiable when
r_{i}=0

(
Hunter & Lange, 2000
)
. An MM algorithm may be constructed to bypass the non-differentiability problem by setting (
Hunter & Lange, 2000
;
Hunter & Lange, 2004
)

Q\left(\bm{\theta}|\bm{\theta}^{(t)}\right)=\sum_{i=1}^{n}\zeta_{q}\left(y_{i}-f_{i}(\bm{\theta})|y_{i}-f_{i}\big(\bm{\theta}^{(t)}\big)\right)=\sum_{i=1}^{n}\zeta_{q}\left(r_{i}(\bm{\theta})|r_{i}\big(\bm{\theta}^{(t)}\big)\right),

(2.1)

where

\zeta_{q}\left(r_{i}(\bm{\theta})|r_{i}\big(\bm{\theta}^{(t)}\big)\right)=\frac{1}{4}\left\{\frac{r_{i}^{2}(\bm{\theta})}{\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|}+(4q-2)r_{i}(\bm{\theta})+\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|\right\}.

(2.2)

It can be shown that the surrogate function in
Equation

2.1
is a majorizer of
L(\bm{\theta})
at
\bm{\theta}^{(t)}
(We leave the proof to
Proposition A.1.
in
Appendix

A
), yet this MM method suffers from the vexing drawback that
Q\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
is not defined when one
r_{i}\big(\bm{\theta}^{(t)}\big)=0
,
i\in\{1,2,\dots,n\}
. This is a realistic concern that should be settled, as some
f_{i}\big(\bm{\theta}^{(t)}\big)
may well converge to
y_{i}
as
t\rightarrow\infty.
For example, in the simplest case when all
f_{i}\big(\bm{\theta}^{(t)}\big)
,
i=1,2,...,n
denote the sample mean
\mu^{(t)}
,
\mu^{(t)}\text{ should }\rightarrow\text{ one }y_{i}\text{ as }t\rightarrow\infty
if
nq\not\in\mathbb{N}

(
Hunter & Lange, 2000
)
.

Hunter & Lange (2000)
addressed this issue by introducing a close-approximate function
L_{\epsilon}(\bm{\theta})
, where
\epsilon>0
is a small real number that denotes a perturbation, of the actual loss function
Equation

1.1

L_{\epsilon}(\bm{\theta})=\sum_{i=1}^{n}\rho_{q}^{\epsilon}(r_{i}(\bm{\theta}))=\sum_{i=1}^{n}\left\{\rho_{q}(r_{i}(\bm{\theta}))-\frac{\epsilon}{2}\ln(\epsilon+|r_{i}(\bm{\theta})|)\right\}

(2.3)

and inventing a corresponding majorizer

Q_{\epsilon}\left(\bm{\theta}|\bm{\theta}^{(t)}\right)=\sum_{i=1}^{n}\zeta_{q}^{\epsilon}\left(r_{i}(\bm{\theta})|r_{i}\big(\bm{\theta}^{(t)}\big)\right)=\frac{1}{4}\sum_{i=1}^{n}\left\{\frac{r_{i}^{2}(\bm{\theta})}{\epsilon+\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|}+(4q-2)r_{i}(\bm{\theta})+{\const}_{i}\right\},

(2.4)

where
{\const}_{i},\>i=1,2,\ldots,n
are chosen to ensure that

\zeta_{q}^{\epsilon}\left(r_{i}\big(\bm{\theta}^{(t)}\big)|r_{i}\big(\bm{\theta}^{(t)}\big)\right)=\frac{1}{4}\left\{\frac{r_{i}^{2}\big(\bm{\theta}^{(t)}\big)}{\epsilon+\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|}+(4q-2)r_{i}\big(\bm{\theta}^{(t)}\big)+{\const}_{i}\right\}=\rho_{q}^{\epsilon}\left(r_{i}\big(\bm{\theta}^{(t)}\big)\right).

(2.5)

By definition,
Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
satisfies
Equation

1.4
as
\zeta_{q}^{\epsilon}\big(r_{i}\big(\bm{\theta}^{(t)}\big)|r_{i}\big(\bm{\theta}^{(t)}\big)\big)=\rho_{q}^{\epsilon}\big(r_{i}\big(\bm{\theta}^{(t)}\big)\big)
for all
i\in\{1,2,\dots,n\}
. Given current residual value
r^{(t)}=r\big(\bm{\theta}^{(t)}\big)
at iteration t, we let

h(r)=\zeta_{q}^{\epsilon}\big(r|r^{(t)}\big)-\rho_{q}^{\epsilon}(r)=\frac{1}{4}\left\{\frac{r^{2}}{\epsilon+\big|r^{(t)}\big|}-2r+{\const}+2\epsilon\cdot\ln(\epsilon+|r|)\right\}+r\mathbbm{1}_{\{r<0\}}.

Then

\displaystyle\text{For }r\geq 0,\;h^{\prime}(r)=\frac{1}{2}\left(\frac{r}{\epsilon+|r^{(t)}|}-1+\frac{\epsilon}{\epsilon+r}\right)=\frac{1}{2}\cdot\frac{r\big(r-\big|r^{(t)}\big|\big)}{\big(\epsilon+\big|r^{(t)}\big|\big)(\epsilon+r)};

(2.6)

\displaystyle\text{For }r<0,\;h^{\prime}(r)=\frac{1}{2}\left(\frac{r}{\epsilon+\big|r^{(t)}\big|}+1-\frac{\epsilon}{\epsilon-r}\right)=-\frac{1}{2}\cdot\frac{r\big(r+\big|r^{(t)}\big|\big)}{\big(\epsilon+\big|r^{(t)}\big|\big)(\epsilon-r)}.

(2.7)

Hence
h^{\prime}(r)=0\iff r=0\text{ or }r=\pm\>\big|r^{(t)}\big|\iff r=0\text{ or }r=\pm\>r^{(t)}
since the sets
\left\{\big|r^{(t)}\big|,-\big|r^{(t)}\big|\right\}
and
\left\{r^{(t)},-r^{(t)}\right\}
are the same. We can see from
Equations

2.6
and
2.7
that
h^{\prime}(r)\leq 0\text{ for }r\in\big(-\infty,-\big|r^{(t)}\big|\big]\cup\big[0,\big|r^{(t)}\big|\big]\text{ and }\geq 0\text{ for }r\in\big[-\big|r^{(t)}\big|,0\big]\cup\big[\big|r^{(t)}\big|,\infty\big),
i.e.,
h(r)
is non-increasing for
r\in\big(-\infty,-\big|r^{(t)}\big|\big]\cup\big[0,\big|r^{(t)}\big|\big]\text{ and non-decreasing for }r\in\big[-\big|r^{(t)}\big|,0\big]\cup\big[\big|r^{(t)}\big|,\infty\big).

Observe that
h(r)
is an even function and thus by
Equation

2.5
,

h\big(-r^{(t)}\big)=h\big(r^{(t)}\big)=0\iff h\big(-\big|r^{(t)}\big|\big)=h\big(\big|r^{(t)}\big|\big)=0\Rightarrow h(r)\geq 0\text{ for all }r.\qquad

Hence,

\zeta_{q}^{\epsilon}\big(r|r^{(t)}\big)\geq\rho_{q}^{\epsilon}(r)\text{ for all }r\Rightarrow Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)\geq L_{\epsilon}(\bm{\theta})\text{ for all }\bm{\theta}.

By the above reasoning,
Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
satisfies
Equation

1.3
as well and thus indeed majorizes
L_{\epsilon}(\bm{\theta})
at
\bm{\theta}^{(t)}
.

2.2
Estimating Different Quantile Coefficients Separately

For linear quantile regression,
f_{i}(\bm{\theta})=\bm{x}_{i}^{T}\bm{\theta}\text{ for }i=1,2,\dots,n
and
\bm{r}(\bm{\theta})_{n\times 1}=\left(r_{1}(\bm{\theta}),\ldots,r_{n}(\bm{\theta})\right)^{T}=\bm{y}_{n\times 1}-\bm{X}_{n\times p}\bm{\theta}_{p\times 1}
for any given quantile level
q\in(0,1)
.
Q_{\epsilon}(\bm{\theta}|\bm{\theta}^{(t)})
is quadratic in
\bm{\theta}
and the MM algorithm can proceed in simplicity by explicitly solving for
\bm{\theta}^{(t+1)}
that minimizes
Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
and updating the current parameter estimate
\bm{\theta}^{(t)}
to
\bm{\theta}^{(t+1)}
.

Given
q\in(0,1)
and current parameter estimate
\bm{\theta}^{(t)}
, let

\bm{W}^{(t)}=\begin{pmatrix}\frac{1}{\epsilon+\big|r_{1}\big(\bm{\theta}^{(t)}\big)\big|}&&&\\
&\frac{1}{\epsilon+\big|r_{2}\big(\bm{\theta}^{(t)}\big)\big|}&&\\
&&\ddots&\\
&&&\frac{1}{\epsilon+\big|r_{n}\big(\bm{\theta}^{(t)}\big)\big|}\end{pmatrix},\;\bm{c}_{n\times 1}=\begin{pmatrix}4q-2\\
4q-2\\
\vdots\\
4q-2\end{pmatrix}.

(2.8)

Then
Equation

2.4
becomes

\displaystyle Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=

\displaystyle\frac{1}{4}\left(\bm{r}(\bm{\theta})^{T}\bm{W}^{(t)}\bm{r}(\bm{\theta})+\bm{c}^{T}\bm{r}(\bm{\theta})\right)+\const

\displaystyle=

\displaystyle\frac{1}{4}\left(\bm{(y-X\theta)}^{T}\bm{W}^{(t)}\bm{(y-X\theta)}+\bm{c}^{T}\bm{(y-X\theta)}\right)+\const.

(2.9)

Thus minimizing
Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
is equivalent to minimizing

g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=\bm{(y-X\theta)}^{T}\bm{W}^{(t)}\bm{(y-X\theta)}+\bm{c}^{T}\bm{(y-X\theta)},

(2.10)

which can be done directly as
g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
is quadratic in
\bm{\theta}
. Setting

\frac{\partial}{\partial\bm{\theta}}g(\bm{\theta}|\bm{\theta}^{(t)})\bigg|_{\bm{\theta}=\bm{\theta}^{(t+1)}}=\left(2\bm{X}^{T}\bm{W}^{(t)}\bm{X\theta}-2\bm{X}^{T}\bm{W}^{(t)}\bm{y}-\bm{X}^{T}\bm{c}\right)_{\bm{\theta}=\bm{\theta}^{(t+1)}}=\bm{0}\,\text{ yields}

\bm{\theta}^{(t+1)}=(\bm{X}^{T}\bm{W}^{(t)}\bm{X})^{-1}\left(\bm{X}^{T}\bm{W}^{(t)}\bm{y}+\frac{1}{2}\bm{X}^{T}\bm{c}\right).

(2.11)

Suppose that
\bm{X}_{n\times p}
(
n>p
) is of full column rank. Then for all
p\times 1
vector
\bm{v}\neq\bm{0}_{p\times 1}
,
\bm{Xv}\neq\bm{0}_{n\times 1}
and thus
\bm{v}^{T}\bm{X}^{T}\bm{W}^{(t)}\bm{Xv}=\bm{(Xv)}^{T}\bm{W}^{(t)}\bm{(Xv)}>0
, as
\bm{W}^{(t)}
is a diagonal matrix whose diagonal entries are all strictly positive. This shows that
\bm{X}^{T}\bm{W}^{(t)}\bm{X}
is positive definite and thus invertible. Hence,
\bm{\theta}^{(t+1)}
given in
Equation

2.11
is indeed well-defined and minimizes
Equations

2.10
and
2.9
, as the Hessian matrix

\frac{\partial^{2}}{\partial\bm{\theta}\partial\bm{\theta}^{T}}g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=2\bm{X}^{T}\bm{W}^{(t)}\bm{X}

is positive definite for all
\bm{\theta}
and in particular
\bm{\theta}^{(t+1)}
.

2.3
Estimating Different Quantile Coefficients Simultaneously

It is of tremendous interest as well as utmost importance to efficiently discern informative signals from and discard unwanted noises in the empirical sample quantile functions. To date, most relevant efforts either resort to varied smoothing techniques on the empirical quantile functions (e.g.,
Cheng, 1995
;
Cheng & Parzen, 1997
) or adjust nonparametric fitting techniques to quantile regression (e.g.,
Yu & Jones, 1998
), which more or less suffer from interpretation simplicity and prediction efficiency.
Frumento & Bottai (2016)
addressed these concerns by bringing forward a parsimonious parametric approach that directly models the linear regression coefficients as smooth functions of
q
, which succeeds in effectively pooling information across quantile levels. The method was later built into R via the
qrcm
package
(
Frumento, 2020
)
.

Rather than estimating the regression coefficients directly but only one
q
a time as in the previous subsection,
Frumento & Bottai (2016)
introduced a basis of
h\in\mathbb{N}
known functions of the quantile order –
\bm{b}(q)=(b_{1}(q),b_{2}(q),\dots,b_{h}(q))^{T}
, where
h
is usually less than 10 and
\bm{b}(q)
is required to induce a monotonically non-decreasing
Q(q|\bm{x,\theta})
for some
\bm{\theta}
, wrote the regression coefficient as
\bm{\beta}_{q}=\bm{A}_{p\times h}\bm{b}(q)
for all
q
, and estimated instead the
p\times h
parameter matrix
\bm{A}=\big(\theta_{jl}\big)_{j=1,\ldots,p,\>l=1,\ldots,h}
.
The residual vector can now be expressed as a function of
q
–
\bm{r}(q)=(r_{1}(q),r_{2}(q),\dots,r_{n}(q))^{T}=\bm{y}-\bm{XAb}(q)
. This way, entries of
\bm{\beta}_{q}
are represented as linear combinations of basis functions of
q
and are no longer estimated separately.

The MM algorithm described in
Section

2.2
for linear quantile regression can be conveniently generalized to fit the model in this section by rewriting the parameter matrix
\bm{A}_{p\times h}
as

\bm{\theta}_{hp\times 1}=(\theta_{11},\theta_{21},\dots,\theta_{p1},\dots\dots,\theta_{1h},\theta_{2h},\dots,\theta_{ph})^{T}

(2.12)

to form the parameter vector to be estimated and replacing the
\bm{X}_{n\times p}
in
Section

2.2
by new design matrices
\bm{D}(q)_{n\times hp}
for any
q\in(0,1)
:

\displaystyle\bm{D}(q)_{n\times hp}

\displaystyle=\bm{b}(q)^{T}_{1\times h}\otimes\bm{X}_{n\times p}

(2.13)

\displaystyle=\begin{pmatrix}x_{11}b_{1}(q)&x_{12}b_{1}(q)&\dots&x_{1p}b_{1}(q)&\dots\dots&x_{11}b_{h}(q)&x_{12}b_{h}(q)&\dots&x_{1p}b_{h}(q)\\
x_{21}b_{1}(q)&x_{22}b_{1}(q)&\dots&x_{2p}b_{1}(q)&\dots\dots&x_{21}b_{h}(q)&x_{22}b_{h}(q)&\dots&x_{2p}b_{h}(q)\\
\vdots&\vdots&\ddots&\vdots&\ddots&\vdots&\vdots&\ddots&\vdots\\
\vdots&\vdots&\ddots&\vdots&\ddots&\vdots&\vdots&\ddots&\vdots\\
x_{n1}b_{1}(q)&x_{n2}b_{1}(q)&\dots&x_{np}b_{1}(q)&\dots\dots&x_{n1}b_{h}(q)&x_{n2}b_{h}(q)&\dots&x_{np}b_{h}(q)\end{pmatrix}.

Then
\bm{r}(q,\bm{\theta})=(r_{1}(q,\bm{\theta}),r_{2}(q,\bm{\theta}),\dots,r_{n}(q,\bm{\theta}))^{T}=\bm{y}-\bm{XAb}(q)=\bm{y}-\bm{D}(q)\bm{\theta}
. Given
k\in\mathbb{N}
quantile orders
q_{1},q_{2},\dots,q_{k}
that we wish to simultaneously model, where
k
is typically set large (e.g., 100, 1000) for better performances, the surrogate function with perturbation becomes

\displaystyle Q_{\epsilon}\left(\bm{\theta}|\bm{\theta}^{(t)}\right)=

\displaystyle\sum_{a=1}^{k}\sum_{i=1}^{n}\zeta_{q_{a}}^{\epsilon}\left(r_{i}(q_{a},\bm{\theta})|r_{i}\big(q_{a},\bm{\theta}^{(t)}\big)\right)

\displaystyle=

\displaystyle\frac{1}{4}\sum_{a=1}^{k}\sum_{i=1}^{n}\left\{\frac{r_{i}^{2}(q_{a},\bm{\theta})}{\epsilon+\big|r_{i}\big(q_{a},\bm{\theta}^{(t)}\big)\big|}+(4q_{a}-2)r_{i}(q_{a},\bm{\theta})+{\const}_{ia}\right\}.

(2.14)

Given current parameter estimate
\bm{\theta}^{(t)},\text{ for all }a\in\{1,2,\dots,k\}
, let

(\bm{W}_{a})_{n\times n}^{(t)}=\begin{pmatrix}\frac{1}{\epsilon+\big|r_{1}\big(q_{a},\bm{\theta}^{(t)}\big)\big|}&&&\\
&\frac{1}{\epsilon+\big|r_{2}\big(q_{a},\bm{\theta}^{(t)}\big)\big|}&&\\
&&\ddots&\\
&&&\frac{1}{\epsilon+\big|r_{n}\big(q_{a},\bm{\theta}^{(t)}\big)\big|}\end{pmatrix},\;(\bm{c}_{a})_{n\times 1}=\begin{pmatrix}4q_{a}-2\\
4q_{a}-2\\
\vdots\\
4q_{a}-2\end{pmatrix}.

Then
2.14
can be written as

\displaystyle Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=

\displaystyle\frac{1}{4}\sum_{a=1}^{k}\left\{\bm{r}(q_{a},\bm{\theta})^{T}\bm{W}_{a}^{(t)}\bm{r}(q_{a},\bm{\theta})+\bm{c}_{a}^{T}\bm{r}(q_{a},\bm{\theta})+{\const}_{a}\right\}

\displaystyle=

\displaystyle\frac{1}{4}\sum_{a=1}^{k}\left\{(\bm{y}-\bm{D}(q_{a})\bm{\theta})^{T}\bm{W}_{a}^{(t)}(\bm{y}-\bm{D}(q_{a})\bm{\theta})+\bm{c}_{a}^{T}(\bm{y}-\bm{D}(q_{a})\bm{\theta})+{\const}_{a}\right\},

(2.15)

which is again quadratic in
\bm{\theta}
and thus can be solved directly for
\bm{\theta}^{(t+1)}
. Let

g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=\sum_{a=1}^{k}\left\{\bm{(y-D}(q_{a})\bm{\theta)}^{T}\bm{W}_{a}^{(t)}\bm{(y-D}(q_{a})\bm{\theta)}+\bm{c}_{a}^{T}\bm{(y-D}(q_{a})\bm{\theta)}\right\}.

(2.16)

Then minimizing
g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
is equivalent to minimizing
Q_{\epsilon}\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
.

\displaystyle\frac{\partial}{\partial\bm{\theta}}g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)\bigg|_{\bm{\theta}=\bm{\theta}^{(t+1)}}=\left(\sum_{a=1}^{k}\left\{2\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{D}(q_{a})\bm{\theta}-2\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{y}-\bm{D}^{T}(q_{a})\bm{c}_{a}\right\}\right)_{\bm{\theta}=\bm{\theta}^{(t+1)}}=\bm{0}

\displaystyle\qquad\Rightarrow\bm{\theta}^{(t+1)}=\left[\sum_{a=1}^{k}\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{D}(q_{a})\right]^{-1}\left[\sum_{a=1}^{k}\left(\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{y}+\frac{1}{2}\bm{D}^{T}(q_{a})\bm{c}_{a}\right)\right],

(2.17)

which is well-defined for a full rank
\bm{X}_{n\times p}
(
n>p
), a small
h\in\mathbb{N}
, and a big
k\in\mathbb{N}
. To see this, we note that
\sum_{a=1}^{k}\bm{D}^{T}(q_{a})_{hp\times n}(\bm{W}_{a})^{(t)}_{n\times n}\bm{D}(q_{a})_{n\times hp}=\bm{D}^{T}_{hp\times nk}\bm{W}_{nk\times nk}^{(t)}\bm{D}_{nk\times hp}
, where

\displaystyle\bm{D}_{nk\times hp}=\begin{pmatrix}\bm{D}(q_{1})_{n\times hp}\\
\bm{D}(q_{2})_{n\times hp}\\
\vdots\\
\bm{D}(q_{k})_{n\times hp}\end{pmatrix}=\begin{pmatrix}\bm{b}(q_{1})^{T}_{1\times h}\otimes\bm{X}_{n\times p}\\
\bm{b}(q_{2})^{T}_{1\times h}\otimes\bm{X}_{n\times p}\\
\vdots\\
\bm{b}(q_{k})^{T}_{1\times h}\otimes\bm{X}_{n\times p}\end{pmatrix}=\begin{pmatrix}\bm{b}(q_{1})^{T}\\
\bm{b}(q_{2})^{T}\\
\vdots\\
\bm{b}(q_{k})^{T}\end{pmatrix}_{k\times h}\otimes\bm{X}_{n\times p}

(2.18)

and

\displaystyle\bm{W}_{nk\times nk}^{(t)}=\begin{pmatrix}(\bm{W}_{1})^{(t)}_{n\times n}&&&\\
&(\bm{W}_{2})^{(t)}_{n\times n}&&\\
&&\ddots&\\
&&&(\bm{W}_{k})^{(t)}_{n\times n}\end{pmatrix}.

(2.19)

\displaystyle\rank(\bm{D})=\rank\left(\begin{pmatrix}\bm{b}(q_{1})^{T}\\
\bm{b}(q_{2})^{T}\\
\vdots\\
\bm{b}(q_{k})^{T}\end{pmatrix}\right)\times\rank(\bm{X})=h\times p=hp\text{ implies that }\bm{D}_{nk\times hp}\text{ is full-rank}.

Since
\bm{W}_{nk\times nk}^{(t)}
is a diagonal matrix whose diagonal entries are all strictly positive and
\bm{D}_{nk\times hp}
(
nk>hp
) is of full column rank,
\bm{D}^{T}\bm{W}^{(t)}\bm{D}
is positive definite and thus invertible.

\bm{\theta}^{(t+1)}
given in
2.17
indeed minimizes
Equations

2.16
and
2.14
, as
\frac{\partial^{2}}{\partial\bm{\theta}\partial\bm{\theta}^{T}}g\big(\bm{\theta}|\bm{\theta}^{(t)}\big)=2\sum_{a=1}^{k}\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{D}(q_{a})=2\bm{D}^{T}\bm{W}^{(t)}\bm{D}
is positive definite for all
\bm{\theta}
including
\bm{\theta}^{(t+1)}
.

With no additional assumptions, the parametric logistic basis

\bm{b}(q)=(1,\ln(q),\ln(1-q))^{T}

(2.20)

has been suggested to perform well generally by
Frumento & Bottai (2016)
and was thus adopted by us. Since there are situations, though not frequent, when linear combinations of
Equation

2.20
drastically deviate from the actual coefficient functions (see
Section

3
when the errors follow a shifted rescaled
\Beta(0.5,0.5)
distribution, for instance), we also resorted to flexible nonparametric bases. Natural splines (cubic splines that restrict both tails to be linear, abbreviated as “ns”), which encompass both flexibility retained from ordinary cubic splines and stability achieved by imposing the tail linearity restriction
(
Perperoglou et al., 2019
)
and have thus been extensively utilized in regression analysis, were considered. We followed the truncated power basis form presented by
Hess (1994)
and defined

\displaystyle\bm{b}(q)_{h\times 1}=\big(1,q,S_{1}(q),S_{2}(q),\dots,S_{h-2}(q)\big)^{T},\text{ where for all }l\in\{1,2,\dots,h-2\},

\displaystyle S_{l}(q)=(q-q_{l})_{+}^{3}-\frac{(q-q_{h-1})_{+}^{3}(q_{h}-q_{l})}{q_{h}-q_{h-1}}+\frac{(q-q_{h})_{+}^{3}(q_{h-1}-q_{l})}{q_{h}-q_{h-1}}

(2.21)

for ns bases with
h>2\>(h\in\mathbb{N})
knots
q_{1},q_{2},\dots,q_{h}\in(0,1)
.

We can conveniently extend the linear quantile regression MM algorithm constructed in this subsection to parametrically model quantile regression problems with manifest complex nonlinear patterns by first flexibly transforming the original explanatory variables via for instance natural spline transformations
(
Perperoglou et al., 2019
)
again. More details are in
Appendix

C
.

(3.1)

1.

2.

3.

e_{i}

\displaystyle Q_{q}(Y|x)=F_{y}^{-1}(q|x)

\displaystyle=1+3x+(1+2x)Q_{q}(e)=[1+Q_{q}(e)]+[3+2Q_{q}(e)]x,\>q\in(0,1).

(3.2)

4
Discussion

This article explores MM algorithms in various linear quantile regression settings. Simulation studies comparing MM with existing tested methods and applications of MM to several real data sets showcase the effectiveness of our MM algorithms. MM’s computation speed edge over some other prominent algorithms when estimating coefficients at different quantiles separately
(
Pietrosanu et al., 2021
)
has also been supported by our simulation study in
Section

3
.

One major flaw of our MM is that it gets relatively slow compared to
qrcm
when estimating different quantile coefficients simultaneously, which should result from having to invert an
hp\times hp
matrix
\sum_{a=1}^{k}\bm{D}^{T}(q_{a})\bm{W}_{a}^{(t)}\bm{D}(q_{a})
(in
2.17
) at each iteration. It is, however, quite promising to address this current weakness, as some authors have successfully invented fast MM algorithms that bypass large matrix inversion problems (
Lange et al., 2000
;
Erdogan & Fessler, 1999
). In situations where super fast algorithms are needed, a finite smoothing algorithm raised by
Chen (2007)
, which operates by directly minimizing a nice smooth approximate function of
L_{q}(\bm{\theta})=\sum_{i=1}^{n}\rho_{q}(r_{i}(\bm{\theta}))
, may also come to the rescue.

Proposition A.1.

\displaystyle Q\left(\bm{\theta}|\bm{\theta}^{(t)}\right)=\sum_{i=1}^{n}\zeta_{q}\left(r_{i}(\bm{\theta})|r_{i}\big(\bm{\theta}^{(t)}\big)\right)=\sum_{i=1}^{n}\frac{1}{4}\left\{\frac{r_{i}^{2}(\bm{\theta})}{\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|}+(4q-2)r_{i}(\bm{\theta})+\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|\right\}\text{ majorizes }

\displaystyle L(\bm{\theta})=\sum_{i=1}^{n}\rho_{q}(r_{i}(\bm{\theta}))=\sum_{i=1}^{n}\left[qr_{i}(\bm{\theta})-r_{i}(\bm{\theta})\mathbbm{1}_{\{r_{i}(\bm{\theta})<0\}}\right]\text{ at }\bm{\theta}=\bm{\theta}^{(t)}.

Proof.

\displaystyle Q\left(\bm{\theta}^{(t)}\big|\bm{\theta}^{(t)}\right)-L\big(\bm{\theta}^{(t)}\big)=\sum_{i=1}^{n}\left[\zeta_{q}\left(r_{i}\big(\bm{\theta}^{(t)}\big)\big|r_{i}\big(\bm{\theta}^{(t)}\big)\right)-\rho_{q}\left(r_{i}\big(\bm{\theta}^{(t)}\big)\right)\right]

\displaystyle=

\displaystyle\sum_{i=1}^{n}\left(\frac{1}{4}\left[\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|-2r_{i}\big(\bm{\theta}^{(t)}\big)+\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|\right]+r_{i}\big(\bm{\theta}^{(t)}\big)\mathbbm{1}_{\left\{r_{i}\big(\bm{\theta}^{(t)}\big)<0\right\}}\right)

\displaystyle=

\displaystyle\sum_{i=1}^{n}\left\{r_{i}\big(\bm{\theta}^{(t)}\big)\left(-\frac{1}{2}+\mathbbm{1}_{\left\{r_{i}\big(\bm{\theta}^{(t)}\big)<0\right\}}\right)+\frac{1}{2}\big|r_{i}\big(\bm{\theta}^{(t)}\big)\big|\right\}=0.

It remains to show
Q\big(\bm{\theta}|\bm{\theta}^{(t)}\big)
satisfies
Equation

1.3
.
\forall\text{ residual }r,
letting

\displaystyle h(r)=\,

\displaystyle\zeta_{q}\big(r|r^{(t)}\big)-\rho_{q}(r)=\frac{1}{4}\left(\frac{r^{2}}{\big|r^{(t)}\big|}-2r+\big|r^{(t)}\big|\right)+r\mathbbm{1}_{\{r<0\}},\text{ we have }

\displaystyle h^{\prime}(r)=\,

\displaystyle\frac{1}{2}\left(\frac{r}{\big|r^{(t)}\big|}-1\right)+\mathbbm{1}_{\{r<0\}}=\begin{cases}\frac{1}{2}\cdot\frac{r-\big|r^{(t)}\big|}{\big|r^{(t)}\big|}\;\text{ if }r\geq 0\\
\frac{1}{2}\cdot\frac{r+\big|r^{(t)}\big|}{\big|r^{(t)}\big|}\;\text{ if }r<0\end{cases}.

(A.1)

Observe from
A.1
that
h\big(\pm r^{(t)}\big)=h^{\prime}\big(\pm r^{(t)}\big)=0
and

\displaystyle h^{\prime}(r)\leq 0\>\text{ if }r\in\big(-\infty,-\big|r^{(t)}\big|\big]\cup\big[0,\big|r^{(t)}\big|\big]\text{ and }\geq 0\>\text{ if }r\in\big[-\big|r^{(t)}\big|,0\big]\cup\big[\big|r^{(t)}\big|,\infty\big)

\displaystyle\iff

\displaystyle h(r)\>\text{ is non-increasing for }r\in\big(-\infty,-\big|r^{(t)}\big|\big]\cup\big[0,\big|r^{(t)}\big|\big]

\displaystyle\text{ and is non-decreasing for }r\in\big[-\big|r^{(t)}\big|,0\big]\cup\big[\big|r^{(t)}\big|,\infty\big)

\displaystyle\Rightarrow\>

\displaystyle h(r)\geq\min\left\{h\big(r^{(t)}\big),h\big(-r^{(t)}\big)\right\}=0\;\forall\>r\quad\iff\quad\zeta_{q}\big(r|r^{(t)}\big)\geq\rho_{q}(r)\;\forall\>r.

Hence
Q\big(\bm{\theta|\theta}^{(t)}\big)\geq L(\bm{\theta})\;\forall\;\bm{\theta}
and
Equation

1.3
is satisfied. ∎

Appendix B
Adaptive Lasso for Heterogeneous Variable Selection in Regularized Quantile Regression

In diverse sparse modeling settings requiring efficient predictor selection, the adaptive lasso has been proven highly competent in consistent variable selection by imposing an adequately weighted
\mathit{l}_{1}
penalty
\lambda\sum_{j=1}^{p}w_{j}|\beta_{j}|,\lambda\geq 0

(
Zou, 2006
)
. Several authors (e.g.,
Wu & Liu, 2009
,
Peng et al., 2014
) have extended this powerful technique to account for possible quantile-varying covariate effects by defining a penalized quantile regression problem at any quantile level
q\in(0,1)
as follows. We write
\bm{\beta}=(\beta_{1},\beta_{2},\dots,\beta_{p})^{T}
, where
\beta_{1}
denotes the coefficient for the intercept term, and let the parameter estimate

\displaystyle\hat{\bm{\beta}}_{\lambda}(q)_{p\times 1}=

\displaystyle\underset{\bm{\beta}}{\text{ argmin}}\;L_{q}(\bm{\beta}),\text{ where}

\displaystyle L_{q}(\bm{\beta})=

\displaystyle\sum_{i=1}^{n}\rho_{q}(r_{i}(\bm{\beta}))+\lambda\sum_{j=2}^{p}\frac{|\beta_{j}|}{\big|\tilde{\beta}_{j}(q)\big|}\text{ and}

(B.1)

\displaystyle\tilde{\bm{\beta}}(q)_{p\times 1}=

\displaystyle\underset{\bm{\beta}}{\text{ argmin}}\;\sum_{i=1}^{n}\rho_{q}(r_{i}(\bm{\beta}))\text{ (the nonregularized quantile regression estimator).}

Thanks to the AM-GM Inequality,

Q_{q,\lasso}\left(\bm{\beta}\bigg|\bm{\beta}^{(t)}\right)=\sum_{i=1}^{n}\zeta_{q}\left(r_{i}\bigg|r_{i}^{(t)}\right)+\lambda\sum_{j=2}^{p}\frac{1}{\left|\tilde{\beta}_{j}(q)\right|}\left[\frac{1}{2}\left|\beta_{j}^{(t)}\right|+\frac{\beta_{j}^{2}}{2\left|\beta_{j}^{(t)}\right|}\right]

(B.2)

is a majorizer of
B.1
at
\bm{\beta}^{(t)}
. To mend the flaw that
Equation

B.2
is undefined when
r_{i}^{(t)}=0
for any
i\in\{1,2,\ldots,n\}
or
\beta_{j}^{(t)}=0
for any
j\in\{2,3,\dots,p\}
, a realistic concern as
r_{i}\big(\bm{\beta}^{(t)}\big)
for some
f_{i}\big(\bm{\beta}^{(t)}\big)
,
i\in\{1,2,\ldots,n\}
and
\beta_{j}^{(t)}
,
j\in\{2,3,\dots,p\}
for penalized quantile regression may well converge to 0 as
t\rightarrow\infty
, we can adopt

\displaystyle Q^{\epsilon,\epsilon_{l}}_{q,\lasso}\left(\bm{\beta}\bigg|\bm{\beta}^{(t)}\right)=\sum_{i=1}^{n}\zeta_{q}^{\epsilon}\left(r_{i}\bigg|r_{i}^{(t)}\right)+\lambda\sum_{j=2}^{p}\frac{1}{\big|\tilde{\beta}_{j}(q)\big|}\left[\frac{1}{2}\left(\big|\beta_{j}^{(t)}\big|+\epsilon_{l}\right)+\frac{\beta_{j}^{2}}{2\left(\big|\beta_{j}^{(t)}\big|+\epsilon_{l}\right)}\right],

(B.3)

an approximate majorizer at
\bm{\beta}^{(t)}
of

L_{q}^{\epsilon}(\bm{\beta})=\sum_{i=1}^{n}\rho_{q}^{\epsilon}(r_{i}(\bm{\beta}))+\lambda\sum_{j=2}^{p}\frac{|\beta_{j}|}{\big|\tilde{\beta}_{j}(q)\big|}=\sum_{i=1}^{n}\left\{\rho_{q}(r_{i}(\bm{\beta}))-\frac{\epsilon}{2}\ln(\epsilon+|r_{i}(\bm{\beta})|)\right\}+\lambda\sum_{j=2}^{p}\frac{|\beta_{j}|}{\big|\tilde{\beta}_{j}(q)\big|},

(B.4)

which closely approximates
L_{q}(\bm{\beta})
in
B.1
. While it is still ensured that
L_{q}^{\epsilon}(\bm{\beta})\leq Q^{\epsilon,\epsilon_{l}}_{q,\lasso}\big(\bm{\beta}|\bm{\beta}^{(t)}\big)\;\forall\;\bm{\beta}
, introducing a perturbation
\epsilon_{l}>0
makes
L_{q}^{\epsilon}\big(\bm{\beta}^{(t)}\big)\neq Q^{\epsilon,\epsilon_{l}}_{q,\lasso}\big(\bm{\beta}^{(t)}|\bm{\beta}^{(t)}\big)
.
Let

\displaystyle\bm{V}^{(t)}_{p\times p}

\displaystyle=\begin{pmatrix}0&&&\\
&\frac{1}{\big|\tilde{\beta}_{2}(q)\big|\cdot\big(\big|\beta_{2}^{(t)}\big|+\epsilon_{l}\big)}&&\\
&&\ddots&\\
&&&\frac{1}{\big|\tilde{\beta}_{p}(q)\big|\cdot\big(\big|\beta_{p}^{(t)}\big|+\epsilon_{l}\big)}\end{pmatrix},

(B.5)

\displaystyle\bm{W}^{(t)}_{n\times n}

\displaystyle=\begin{pmatrix}\frac{1}{\epsilon+\big|r_{1}\big(\bm{\beta}^{(t)}\big)\big|}&&&\\
&\frac{1}{\epsilon+\big|r_{2}\big(\bm{\beta}^{(t)}\big)\big|}&&\\
&&\ddots&\\
&&&\frac{1}{\epsilon+\big|r_{n}\big(\bm{\beta}^{(t)}\big)\big|}\end{pmatrix},\text{ and }

\displaystyle\bm{c}_{n\times 1}

\displaystyle=(4q-2,4q-2,\dots,4q-2)^{T}.

Then

Q^{\epsilon,\epsilon_{l}}_{q,\lasso}\big(\bm{\beta}|\bm{\beta}^{(t)}\big)=\frac{1}{4}\left((\bm{y}-\bm{X\beta})^{T}\bm{W}^{(t)}(\bm{y}-\bm{X\beta})+\bm{c}^{T}(\bm{y}-\bm{X\beta})\right)+\frac{\lambda}{2}\bm{\beta}^{T}\bm{V}^{(t)}\bm{\beta}+\const.

(B.6)

Hence, minimizing
Q^{\epsilon,\epsilon_{l}}_{q,\lasso}\big(\bm{\beta}|\bm{\beta}^{(t)}\big)
is equivalent to minimizing

\displaystyle h\big(\bm{\beta}|\bm{\beta}^{(t)}\big)

\displaystyle=g\big(\bm{\beta}|\bm{\beta}^{(t)}\big)+2\lambda\bm{\beta}^{T}\bm{V}^{(t)}\bm{\beta},\text{ where }

(B.7)

\displaystyle g\big(\bm{\beta}|\bm{\beta}^{(t)}\big)

\displaystyle=(\bm{y}-\bm{X\beta})^{T}\bm{W}^{(t)}(\bm{y}-\bm{X\beta})+\bm{c}^{T}(\bm{y}-\bm{X\beta}).

We have shown in
Section

2.2
that
\bm{X}^{T}\bm{W}^{(t)}\bm{X}
is positive definite and thus invertible for a full rank
\bm{X}_{n\times p}
. It is also clear that
\bm{V}^{(t)}
is positive semi-definite, as it is a diagonal matrix whose entries are all non-negative. Hence, for a full rank
\bm{X}_{n\times p}
, the Hessian

\displaystyle\frac{\partial^{2}}{\partial\bm{\beta}\partial\bm{\beta}^{T}}h\big(\bm{\beta}|\bm{\beta}^{(t)}\big)=2\bm{X}^{T}\bm{W}^{(t)}\bm{X}+4\lambda\bm{V}^{(t)}\;\text{ is positive definite since }\lambda\geq 0.

(B.8)

We can thus proceed to solve for
\bm{\beta}^{(t+1)}
by directly minimizing
Equation

B.7
:

\displaystyle\frac{\partial}{\partial\bm{\beta}}h\big(\bm{\beta}|\bm{\beta}^{(t)}\big)\bigg\rvert_{\bm{\beta}=\bm{\beta}^{(t+1)}}

\displaystyle=\left(2\bm{X}^{T}\bm{W}^{(t)}\bm{X\beta}-2\bm{X}^{T}\bm{W}^{(t)}\bm{y}-\bm{X}^{T}\bm{c}+4\lambda\bm{V}^{(t)}\bm{\beta}\right)\bigg\rvert_{\bm{\beta}=\bm{\beta}^{(t+1)}}

\displaystyle=2\left(\bm{X}^{T}\bm{W}^{(t)}\bm{X}+2\lambda\bm{V}^{(t)}\right)\bm{\beta}^{(t+1)}-2\bm{X}^{T}\bm{W}^{(t)}\bm{y}-\bm{X}^{T}\bm{c}=\bm{0}

\displaystyle\Rightarrow\bm{\beta}^{(t+1)}=\frac{1}{2}

\displaystyle\left(\bm{X}^{T}\bm{W}^{(t)}\bm{X}+2\lambda\bm{V}^{(t)}\right)^{-1}\bm{X}^{T}\left[2\bm{W}^{(t)}\bm{y}+\bm{c}\right].

(B.9)

\left(\bm{X}^{T}\bm{W}^{(t)}\bm{X}+2\lambda\bm{V}^{(t)}\right)^{-1}
indeed exists for a full rank
\bm{X}
as
Equation

B.8

\Rightarrow 2\bm{X}^{T}\bm{W}^{(t)}\bm{X}+4\lambda\bm{V}^{(t)}=2\big(\bm{X}^{T}\bm{W}^{(t)}\bm{X}+2\lambda\bm{V}^{(t)}\big)\text{ is invertible }\iff\bm{X}^{T}\bm{W}^{(t)}\bm{X}+2\lambda\bm{V}^{(t)}
is invertible.

It remains to find suitable choices of
\lambda>0
for each
q\in(0,1)
of interest. We followed
Peng et al., 2014
’s idea and used a quantile regression BIC metric put forward by
Lee et al. (2014)
:

{\BIC}_{q}(\lambda)={\BIC}_{q}\left(\hat{\bm{\beta}}_{\lambda}(q)\right)=\ln\left(\sum_{i=1}^{n}\rho_{q}\left(r_{i}\left(\hat{\bm{\beta}}_{\lambda}(q)\right)\right)\right)+\big|\mathit{S}_{q}^{\lambda}\big|\frac{\ln(n)}{2n},

(B.10)

where
\big|\mathit{S}_{q}^{\lambda}\big|
represents the size of
\mathit{S}_{q}^{\lambda}=\left\{2\leq j\leq p:\big|(\hat{\beta}_{\lambda})_{j}\big|>0\right\}
.

Proposition B.1.

Consider the linear quantile regression model

Y_{i}=\bm{X}_{i}^{T}\bm{\beta}_{q}+U_{i},\>i=1,2,\dots,n,\>q\in(0,1)

(B.11)

with loss
\rho_{q}(u)=|u|\big[q\mathbbm{1}_{\{u\geq 0\}}+(1-q)\mathbbm{1}_{\{u<0\}}\big]=qu-u\mathbbm{1}_{\{u<0\}}
and error distribution

U_{1},\dots,U_{n}\overset{\iid}{\sim}\text{ an asymmetric Laplace distribution with PDF }f_{U}(u)=\frac{q(1-q)}{\sigma}e^{-\frac{\rho_{q}(u)}{\sigma}}.

(B.12)

Given a fixed
\lambda\geq 0
and an obtained (penalized) coefficient estimator
\hat{\bm{\beta}}_{q}=\hat{\bm{\beta}}_{\lambda}(q)
that attempts to minimize
L_{q}^{\epsilon}(\bm{\beta})
in
Equation

B.4
, a BIC is given by

{\BIC}_{q}\left(\hat{\bm{\beta}}_{q}\right)=\ln\left(\sum_{i=1}^{n}\rho_{q}\left(r_{i}\left(\hat{\bm{\beta}}_{q}\right)\right)\right)+|\mathit{S}_{q}|\frac{\ln(n)}{2n}

(B.13)

if we approximate
\sigma
by
\hat{\sigma}_{\mle}
.

Proof.

Given sample observations
\{(\bm{x}_{i},y_{i}):1\leq i\leq n\}
, the log-likelihood is

l(\bm{\beta}_{q},\sigma)=\ln\left[\prod_{i=1}^{n}f_{U}(y_{i}-\bm{x}_{i}^{T}\bm{\beta}_{q})\right]=-n\ln(\sigma)-\sum_{i=1}^{n}\frac{\rho_{q}(y_{i}-\bm{x}_{i}^{T}\bm{\beta}_{q})}{\sigma}+\const.

(B.14)

For any given
\hat{\bm{\beta}}_{q}
, we let
g(\sigma)=l\big(\hat{\bm{\beta}}_{q},\sigma\big),\>\sigma\in(0,\infty)
. Since
g
is differentiable everywhere on
(0,\infty)
and

\displaystyle g^{\prime}(\sigma)

\displaystyle=\frac{\partial l\left(\bm{\beta}_{q},\sigma\right)}{\partial\sigma}\bigg|_{\bm{\beta}_{q}=\hat{\bm{\beta}}_{q}}=-\frac{n}{\sigma}+\sum_{i=1}^{n}\frac{\rho_{q}\left(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\right)}{\sigma^{2}}=\frac{-n\sigma+\sum_{i=1}^{n}\rho_{q}\left(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\right)}{\sigma^{2}}

has a unique zero (and hence the unique critical point by Fermat’s Theorem) at

\displaystyle\sigma

\displaystyle=\hat{\sigma}\big(\hat{\bm{\beta}_{q}}\big)=\frac{\sum_{i=1}^{n}\rho_{q}\left(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\right)}{n}

(B.15)

with
g^{\prime}(\sigma)>0
for
\sigma<\hat{\sigma}\big(\hat{\bm{\beta}}_{q}\big)
and
g^{\prime}(\sigma)<0
for
\sigma>\hat{\sigma}\big(\hat{\bm{\beta}_{q}}\big)
,
\sigma=\hat{\sigma}\big(\hat{\bm{\beta}}_{q}\big)
given in
B.15
is the unique local maxima. Since
g(\sigma)\rightarrow-\infty
as
\sigma\rightarrow\infty
or as
\sigma\rightarrow 0_{+}
,

\hat{\sigma}_{\mle}\left(\hat{\bm{\beta}}_{q}\right)=\frac{\sum_{i=1}^{n}\rho_{q}\left(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\right)}{n}\in(0,\infty)\text{ satisfies }g\left(\hat{\sigma}_{\mle}\left(\hat{\bm{\beta}}_{q}\right)\right)=\underset{\sigma\in(0,\infty)}{\max}\,g(\sigma)=\underset{\sigma\in(0,\infty)}{\max}\,l\left(\hat{\bm{\beta}}_{q},\sigma\right)

and is the unique MLE of
\sigma
given
\hat{\bm{\beta}}_{q}
. Setting
\sigma=\hat{\sigma}_{\mle}\left(\hat{\bm{\beta}}_{q}\right)=\frac{\sum_{i=1}^{n}\rho_{q}\left(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\right)}{n}
, we get

\displaystyle{\BIC}_{q}\big(\hat{\bm{\beta}}_{q}\big)

\displaystyle=-2l\left(\hat{\bm{\beta}}_{q},\hat{\sigma}_{\mle}\big(\hat{\bm{\beta}}_{q}\big)\right)+|\mathit{S}_{q}|\ln(n)=2n\ln\left[\hat{\sigma}_{\mle}\big(\hat{\bm{\beta}}_{q}\big)\right]+2n-2\const+|\mathit{S}_{q}|\ln(n)

\displaystyle=2n\left(\ln\left[\frac{\sum_{i=1}^{n}\rho_{q}\big(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\big)}{n}\right]+|\mathit{S}_{q}|\frac{\ln(n)}{2n}\right)+2n-2\const

\displaystyle=2n\left(\ln\left[\sum_{i=1}^{n}\rho_{q}\big(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\big)\right]+|\mathit{S}_{q}|\frac{\ln(n)}{2n}\right)+2n-2\const-2n\ln(n)

\displaystyle={\const}_{1}\left(\ln\left[\sum_{i=1}^{n}\rho_{q}\big(y_{i}-\bm{x}_{i}^{T}\hat{\bm{\beta}}_{q}\big)\right]+|\mathit{S}_{q}|\frac{\ln(n)}{2n}\right)+{\const}_{2},\text{ where }{\const}_{1}=2n>0.

(B.16)

Hence,
B.16
is equivalent to
Equation

B.13
as a BIC metric.

Appendix C
Nonparametric Quantile Regression

Despite its popularity and general competence, the typical linear quantile regression is inappropriate for data sets exhibiting manifest complex nonlinear patterns. Quantile regression for universal nonlinear data, however, has rarely been discussed. The handful of existing approaches in current literature (e.g.,
Yu & Jones, 1998
) rely on broader nonparametric methods like Kernel Estimation adapted to quantile regression instead of parametric methods convenient for interpretation and prediction. We attempt to bridge this gap by extending our MM algorithm constructed in
Section

2.3
to parametrically model this type of quantile regression problem.

C.2
Double Kernel and Likelihood Cross Validation

To see how well our MM algorithms perform compared to existing nonparametric methods, we adopted widely-used Kernel Estimation techniques on the two bivariate real data sets to predict
\hat{y}(x|q)
at
q=0.05,0.1,0.25,0.5,0.75,0.9,0.95.
Given a finite sample with observed points
(x_{i},y_{i})
,
i=1,2,\dots,n
and a new point with known
x
, the estimated conditional CDF of this point’s
y
coordinate is of the form

\displaystyle\hat{F}(y|x)

\displaystyle=\sum_{i=1}^{n}w_{i}(x,h_{1})\cdot I(y_{i}\leq y),\text{ where}

(C.3)

\displaystyle w_{i}(x,h_{1})

\displaystyle=\frac{K\left(\frac{x_{i}-x}{h_{1}}\right)}{\sum_{j=1}^{n}K\left(\frac{x_{j}-x}{h_{1}}\right)}.

To smooth our estimation in the
y
direction, we replaced the deterministic form
I(y_{i}\leq y)
in
Equation

C.3
by a standard normal CDF
N(y_{i},h_{2})=\Phi\left(\frac{y-y_{i}}{h_{2}}\right)
and formed a double kernel conditional CDF estimate

\hat{\hat{F}}(y|x)=\sum_{i=1}^{n}w_{i}(x,h_{1})\cdot\Phi\left(\frac{y-y_{i}}{h_{2}}\right)=\sum_{i=1}^{n}\left[\frac{K\left(\frac{x_{i}-x}{h_{1}}\right)}{\sum_{j=1}^{n}K\left(\frac{x_{j}-x}{h_{1}}\right)}\cdot\Phi\left(\frac{y-y_{i}}{h_{2}}\right)\right].

(C.4)

The estimated conditional quantile function is thus

\hat{\hat{Q}}_{q}(y|x)=\hat{\hat{F}}^{-1}(q|x),\>q\in(0,1).

(C.5)

We adopted the normal kernel
\phi
as the kernel function
K
in
Equation

C.4
in light of the normal kernel’s various favorable mathematical properties and proceeded to produce quantile curves of
\hat{y}(x|q)
against
x
at each
q\in\{0.05,0.1,0.25,0.5,0.75,0.9,0.95\}
after specifying a set of sensible choices for the bandwidths
h_{1},h_{2}
. We discovered and confirmed by Likelihood cross-validation (LCV) that different
h_{2}
values generated estimates that are extremely alike, if not identical. As such, we present quantile curves with a set of
h_{1}
choices and a fixed adequate
h_{2}=10^{-4}
in
Figures

22
and
23
. The figures suggest that
h_{1}=10,12.5
for “triceps” and
h_{1}=0.15,0.2
for “WTD” most effectively and smoothly capture the scatters’ trends.

To decide optimal bandwidth choices for Double Kernel Estimation, we carried out leave-one-out likelihood cross-validation to quantitatively judge different bandwidths’ out-of-sample prediction capabilities.
As the estimated conditional PDF is given by

\hat{\hat{f}}(y|x)=\sum_{i=1}^{n}w_{i}(x,h_{1})\cdot\phi\left(\frac{y-y_{i}}{h_{2}}\right),

(C.6)

a leave-one-out LCV likelihood can be expressed as

\mathcal{L}_{\text{LCV}}=\prod_{j=1}^{n}\hat{\hat{f}}^{(-j)}(y_{j}|x_{j}),

(C.7)

where
\hat{\hat{f}}^{(-j)}(y_{j}|x_{j})
denotes the estimated PDF for a new observation with
x=x_{j}
derived using the entire sample except the point
(x_{j},y_{j})
. The larger
\mathcal{L}_{\text{LCV}}
, the better the method.

C.3
Simulation Studies

The quantile curves produced by Double Kernel seem to appear “rougher” than those obtained from MM. To more convincingly and objectively compare the two approaches, we resort to simulation studies again. We considered the three-parameter generalized gamma (GG) distribution, as it incorporates many common fewer-parameter distributions (e.g., Gamma, Weibull, Exponential distributions).

A generalized gamma random variable Y with parameters
\theta,\beta,k
, or
\mu,\sigma,k
, where

\begin{cases}\mu=\ln(\theta)+\frac{\ln(k)}{\beta},\qquad\sigma=\frac{1}{\beta\sqrt{k}}\\
\theta=\frac{e^{\mu}}{k^{\sigma\sqrt{k}}},\qquad\qquad\beta=\frac{1}{\sigma\sqrt{k}}\end{cases},

(C.8)

has probability density function

f(y;\theta,\beta,k)=\frac{\beta}{\theta^{k\beta}\Gamma(k)}y^{k\beta-1}\exp\left\{-\left(\frac{y}{\theta}\right)^{\beta}\right\},\qquad y>0

(C.9)

and quantile function

Q(q;\mu,\sigma,k)=e^{\mu}\left\{\frac{r(q;k)}{k}\right\}^{\sigma\sqrt{k}},\qquad q\in(0,1),

(C.10)

where
r(q;k)
is the quantile function of the
\Ga(\theta=1,k)
, or
\GG(\theta=1,\beta=1,k)
distribution. It is virtually the
\frac{1}{\beta}^{\text{th}}
power of a
\Ga\left(\theta^{\beta},k\right)
random variable and can be generated either by substituting a
\unif(0,1)
random variable as
q
into
Equation

C.10
or by generating a
\Ga\left(\theta^{\beta},k\right)
random variable and taking the
\frac{1}{\beta}^{\text{th}}
power of it. For implementation in software like R, the first method is preferred, as the second may fail for some parameter choices causing extreme values.

We modeled the parameters
\mu,\sigma,k
as suggested by
Noufaily & Jones (2013)
– assume
\mu(x)=a+bx
,
\sigma(x)=e^{c+dx}
,
k(x)=e^{f+gx}
, where
\{a,b,c,d,f,g\}
is the new set of parameters.
For each chosen parameter set
\{a,b,c,d,f,g\}
, we formed
N
bivariate samples of size
n
by

1.

Sample
x_{1},x_{2},\dots,x_{n}
independently from a uniform distribution;

2.

for all
i\in\{1,2,\dots,n\},
generate
y_{i}
from
\GG(\mu(x_{i}),\sigma(x_{i}),k(x_{i}))
using one of the two methods described in the previous paragraph.

We then applied to each sample MM/Double Kernel with a variety of covariate knots and quantile order bases/bandwidths choices. Integrated Mean Squared Error (IMSE), given in
Equation

3.3
, was calculated using the theoretical quantile function
Equation

C.10
at
q=0.1,0.25,0.5,0.75,0.9
for each approach. Estimated quantile curves based on the mean conditional predictions
\hat{y}(x|q)=\hat{Q}_{q}(y|x)
were also made to compare with the theoretical ones.

Figure 24
:
Theoretical quantile curves at
q=0.1,0.25,0.5,0.75,0.9
for generalized gamma distributions with parameters specified in
Item

1
(
A
) and
Item

2
(
B
).

We tried out two sets of parameter choices for
