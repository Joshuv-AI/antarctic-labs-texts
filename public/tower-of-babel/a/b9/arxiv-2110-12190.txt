PROMPT: Parallel Iterative Algorithm for ℓ p \ell_{p} norm linear regression via Majorization Minimization with an application to semi-supervised graph learning
R. Jyothi, P. Babu

Abstract
In this paper, we consider the problem of ℓ p \ell_{p} norm linear regression, which has several applications such as in sparse recovery, data clustering, and semi-supervised learning. The problem, even though convex, does not enjoy a closed-form solution. The state-of-the-art algorithms are iterative but suffer from convergence issues, i.e., they either diverge for p > 3 p>3 or the convergence to the optimal solution is sensitive to the initialization of the algorithm. Also, these algorithms are not generalizable to every possible value of p p . In this paper, we propose an iterative algorithm : P arallel Ite R ative Alg O rith M for ℓ P \ell_{\textbf{P}} norm regression via Majoriza T ion Minimization ( PROMPT ) based on the principle of Majorization Minimization and prove that the proposed algorithm is monotonic and converges to the optimal solution of the problem for any value of p p . The proposed algorithm can also parallelly update each element of the regression variable, which helps to handle large scale data efficiently, a common scenario in this era of data explosion. Subsequently, we show that the proposed algorithm can also be applied for the graph based semi-supervised learning problem. We show through numerical simulations that the proposed algorithm converges to the optimal solution for any random initialization and also performs better than the state-of-the-art algorithms in terms of speed of convergence. We also evaluate the performance of the proposed algorithm using simulated and real data for the graph based semi-supervised learning problem.



I
Introduction and Problem Formulation

Linear regression is a statistical model which is used to estimate the relationship between a dependent variable and one or more independent variables
[
1
]
. This technique is commonly used in data forecasting
[
2
]
, time series analysis
[
3
]
and for risk assessment
[
4
]
. In linear regression, the dependent variable
y
is related to the unknown independent variables
{\boldsymbol{x}}=[x_{1},x_{2},\ldots,x_{n}]^{T}\in\mathbb{R}^{n}
using a linear model as follows:

\begin{array}[]{ll}y=a_{1}x_{1}+a_{2}x_{2}+\cdots+a_{n}x_{n}+e={\boldsymbol{a}}^{T}{\boldsymbol{x}}+e\end{array}

(1)

where
a_{i}
’s are the known regression parameters and
e
is the unknown noise usually modeled as a Gaussian random variable. Suppose we have
m
such observations, then the model in (
1
) can be re-written compactly as:

\begin{array}[]{ll}{\mathbf{y}}={\mathbf{A}}{\boldsymbol{x}}+{\boldsymbol{e}}\end{array}

(2)

where
{\mathbf{y}}\in\mathbb{R}^{m}
is obtained by stacking the observations
\{y_{i}\}_{i=1}^{m}
,
{\mathbf{A}}=[{\boldsymbol{a}}_{1},{\boldsymbol{a}}_{2},\ldots,{\boldsymbol{a}}_{m}]^{T}\in\mathbb{R}^{m\times n}
and
{\boldsymbol{e}}=[e_{1},e_{2},\ldots,e_{m}]^{T}\in\mathbb{R}^{m}
is the unknown error vector.
Usually,
m>n
i.e., there are more equations than unknowns and hence the linear system of equations in (
2
) does not have any solution. In such a case, a classical approach adopted to solve the set of equations in (
2
) is to find an
{\boldsymbol{x}}
such that the sum of the squares of the error i.e., the
\ell_{2}
norm of the error vector is minimum:

\begin{array}[]{ll}\underset{{\boldsymbol{x}}}{\rm arg\>min}\>\{f({\boldsymbol{x}})=\|{\mathbf{y}}-{\mathbf{A}}{\boldsymbol{x}}\|^{2}_{2}\}\end{array}

(3)

where
\|\cdot\|_{2}
is the Euclidean norm. The estimate
{\boldsymbol{x}}
obtained by solving the above problem is known as the least-squares estimator and is given by
{\boldsymbol{x}}=\left({\mathbf{A}}^{T}{\mathbf{A}}\right)^{-1}\left({\mathbf{A}}^{T}{\mathbf{y}}\right)
. However, it has been observed that the performance of the least-squares estimator is degraded when the underlying noise is not Gaussian distributed
[
5
]
. To overcome this issue, the authors in
[
6
]
and
[
7
]
show that the estimate
{\boldsymbol{x}}
obtained by minimizing the
\ell_{p}
norm of the error vector, for
p\neq 2
, is less sensitive to the noise distribution. In practice, the noise distribution may be non-Gaussian and hence in this paper we focus on solving the
\ell_{p}
norm linear regression problem which is defined as:

\begin{array}[]{ll}\textrm{LR:}\quad\underset{{\boldsymbol{x}}}{\rm arg\>min}\>\{f_{{}_{LR}}({\boldsymbol{x}})=\|{\mathbf{y}}-{\mathbf{A}}{\boldsymbol{x}}\|_{p}\}\end{array}

(4)

Even though the problem in (
4
) is convex and differentiable, one cannot obtain a closed-form solution for it using the KKT conditions. Hence, the state-of-the art methods used to solve the problem in (
4
) are iterative in nature. The benchmarking algorithm used to solve the
\ell_{p}
norm problem for
p\in[1,\infty)
is the Iterative Reweighted Least Squares (IRLS) algorithm (
[
8
,
9
,
10
,
11
]
). It is a simple iterative algorithm which replaces the objective function in (
4
) with a weighted
\ell_{2}
norm function at every iteration, which when minimized admits a closed-form solution. However, it was found that this method diverges for
p>3
(
[
10
]
,
[
12
]
). Since then, many algorithms have been proposed to overcome the issue of convergence faced by IRLS algorithm (
[
13
,
14
,
15
]
). We review these methods briefly in the next section. Apart from being a robust regressor, the
\ell_{p}
norm linear regression for
p>2
has applications in semi-supervised learning commonly used in classification problems (
[
16
,
17
,
18
]
), which we discuss next.

In today’s world, classification problems are becoming pervasive wherein the goal is to categorize the given data into its corresponding class using a mapping function
[
1
]
. In the supervised learning setting, the training data set (which consists of data points and its corresponding class labels) are used to learn the mapping function which can be used later to predict the class label of an unknown test data point. However, one setback of this approach is that it requires large amount of labeled data points to learn the mapping function. Data labeling is a laborious task (e.g. writing a transcript for speech recognition) and also requires expert input (deciding whether a brain scan is healthy or not). However, one can easily obtain large amounts of unlabeled data. Semi-supervised learning utilizes both the labeled and unlabeled data points to learn the mapping function. By doing so, semi-supervised learning learns a better mapping function when compared to the supervised learning which uses only the labeled data points
[
12
]
.

Under the semi-supervised learning approach, graph based semi-supervised learning is commonly used, wherein the labels of the unknown data points are learned by propagating the known label information using graphs. Suppose we are given
n
data points
{\boldsymbol{v}}_{i}\in\mathbb{R}^{d}
out of which
u
are unlabeled data points and
l
are labeled points with labels
h_{i}=f({\boldsymbol{v}}_{i})
(where
f
is an unknown real-valued function). Generally, the number of labeled points are much smaller than the number of unlabeled points i.e.,
l<<u
.
An undirected graph
{\boldsymbol{G}}=(V,E)
with vertex set
V=\{v_{1},v_{2},\ldots v_{n}\}
are used to represent the
n
data points. The subset
{L}\subset V
of the vertex set are used to represent the labeled points and the remaining vertices
V\setminus L
represents the unlabeled points. The edges
E
of the graph are equipped with non-negative edge weights
{W}=\{w_{xy}\}_{x,y\in{E}}
, which are chosen such that
w_{xy}\approx 1
when
x
is similar to
y
and
w_{xy}\approx 0
when
x
and
y
are dissimilar. The task of graph based semi-supervised learning is to assign labels to the remaining vertices without changing the labels at the vertex subset
L
. Since, this problem has infinitely many solutions, one usually makes the
semi-supervised smoothness assumption
which states that if two data points
{\boldsymbol{v}}_{1}
,
{\boldsymbol{v}}_{2}
in a high density region are close then so should be their corresponding outputs
h_{1}
,
h_{2}
; hence the function
f
is required to be smooth in the high density regions
[
19
]
. A common approach used to label the data points at remaining vertices such that the mapping function does not change rapidly in the high density regions and also agrees with the labels at the vertices

\ell_{2}
-based Laplacian regularizer, which is given as:

\begin{array}[]{ll}\hat{f}(v)=\underset{f}{\rm arg\>min}\>\displaystyle\sum_{i,j\in E}w_{ij}\left(f(v_{i})-f(v_{j})\right)^{2}\\
\hskip 28.45274pt{\rm{subject\>to}}\>f(v_{i})=h_{i},i\in{L}\end{array}

(5)

The above model was first introduced by
[
20
]
. From an intuitive perspective, minimizing the objective function in (
5

similar points (for which

is larger) will have similar labels, making
\left(f(v_{i})-f(v_{j})\right)^{2}

smaller, while for dissimilar points (
w_{ij}
is small) and hence are allowed to have dissimilar labels. However, it was found that when the number of unlabeled data points

is much greater than the number of labeled data points

becomes constant everywhere, with sharp spikes near the labeled data. We illustrate the same in Fig.

From Fig.

The above problem can be cast as an

II
Related Work and Contributions

The conventional IRLS algorithm used to solve the
\ell_{p}
norm problem was first developed by Karlovitz
[
8
]
and also independently by several other researchers (
[
9
,
10
,
11
]
). A brief history of IRLS algorithm can be found in
[
22
]
. To compute the value of the next iterate
{\boldsymbol{x}}^{k+1}
, the IRLS algorithm solves the following weighted least-squares problem:

\begin{array}[]{ll}{\boldsymbol{x}}^{k+1}=\quad\underset{{\boldsymbol{x}}}{\rm arg\>min}\>({\mathbf{A}}{\boldsymbol{x}}-{\mathbf{y}})^{T}{\boldsymbol{W}}^{k}({\mathbf{A}}{\boldsymbol{x}}-{\mathbf{y}})\end{array}

(7)

where
{\boldsymbol{W}}
is a diagonal matrix with diagonal elements
\{w_{1},w_{2}\cdots w_{m}\}
and
{\boldsymbol{W}}^{k}
is the value taken by
{\boldsymbol{W}}
at the
k^{th}
iteration. The IRLS algorithm starts with
{\boldsymbol{W}}^{0}={\mathbf{I}}
and solves the problem in (
7
) whose solution is the least-squares estimator
{\boldsymbol{x}}^{0}=\left({\mathbf{A}}^{T}{\mathbf{A}}\right)^{-1}\left({\mathbf{A}}^{T}{\mathbf{y}}\right)
. It then updates the weights matrix
{\boldsymbol{W}}^{k}=\textrm{diag}(|{\mathbf{A}}{\boldsymbol{x}}^{k}-{\mathbf{y}}|^{p-2})
and solves the weighted least-squares problem in (
7
) whose solution is
{\boldsymbol{x}}^{k}=({\mathbf{A}}^{T}{\boldsymbol{W}}^{k}{\mathbf{A}})^{-1}{\mathbf{A}}^{T}{\boldsymbol{W}}^{k}{\mathbf{y}}
and this is repeated until convergence. The pseudocode of IRLS algorithm is shown in Table 1.

: Noisy observed data
{\mathbf{y}}
, data matrix
{\mathbf{A}}
and
p

Initialize
: Set
k
= 0. Initialize
{{\boldsymbol{x}}^{0}}=\left({\mathbf{A}}^{T}{\mathbf{A}}\right)^{-1}\left({\mathbf{A}}^{T}{\mathbf{y}}\right)
.

Repeat
:

1) Update
{\boldsymbol{W}}^{k}=\textrm{diag}(|{\mathbf{A}}{\boldsymbol{x}}^{k}-{\mathbf{y}}|^{p-2})

2)
{\boldsymbol{x}}^{k+1}=({\mathbf{A}}^{T}{\boldsymbol{W}}^{k}{\mathbf{A}})^{-1}{\mathbf{A}}^{T}{\boldsymbol{W}}^{k}{\mathbf{y}}

k\leftarrow k+1

until

\left|\dfrac{{f_{{}_{\textrm{LR}}}({{{{\boldsymbol{x}}}^{k}}})}-{f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{k-1}})}}{{f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{k-1}})}}\right|\leq 10^{-3}

The IRLS algorithm has several drawbacks. Firstly, the IRLS algorithm involves computing the inverse of a square matrix of size
n
at every iteration - making the algorithm computationally expensive for large
n
. Also, at any iteration, if
{\mathbf{y}}
becomes equal to
{\mathbf{A}}{\boldsymbol{x}}^{k}
, the matrix
({\mathbf{A}}^{T}{\boldsymbol{W}}^{k}{\mathbf{A}})
becomes ill-conditioned and the algorithm will run into numerical issues. Another drawback of IRLS algorithm is that it fails to converge for

(
[

]
,
[

[

and the IRLS iterate

with the updated weights:

\begin{array}[]{ll}{\boldsymbol{x}}^{k+1}=q\tilde{{\boldsymbol{x}}}^{k}+(1-q){\boldsymbol{x}}^{k-1}\end{array}

(8)

However, this method is very slow because one has to choose an optimal value for

at every iteration. The authors in
[

proposed a modified IRLS algorithm wherein to avoid ill-conditioned matrix, they systematically added non-zero values to the diagonal elements of the matrix

is calculated by doing a line search along the line joining the previous iterate
{\boldsymbol{x}}^{k-1}
and the standard IRLS iterate with the modified weights. Homotopy based approaches have also been proposed to solve the
\ell_{p}
norm regression problem
[
13
]
, wherein first a simpler optimization problem is solved i.e., the
\ell_{p}
norm problem for
p=2
is solved and then

[
23
]
used interior point methods to solve the
\ell_{p}

[
15
]

III
Majorization Minimization

In this section, we give an overview of MM procedure which has been applied to develop
PROMPT
. To explain the MM framework, we consider the following optimization problem:

\begin{array}[]{ll}\underset{{\boldsymbol{x}}\in\chi}{\rm minimize}\>f({\boldsymbol{x}})\end{array}

(9)

where
f({\boldsymbol{x}})
could be either a convex or non-convex function and
\chi
is the constraint set. Under the MM framework, at every iteration, a surrogate function
g({\boldsymbol{x}}|{\boldsymbol{x}}^{k})
which majorizes the function
f({\boldsymbol{x}})
is constructed and minimized i.e.

{\boldsymbol{x}}^{k+1}\in\underset{{\boldsymbol{x}}\in\chi}{\rm arg\>min}\quad g\left({\boldsymbol{x}}|{\boldsymbol{x}}^{k}\right)

(10)

where
{\boldsymbol{x}}^{k+1}
is the value taken by
{\boldsymbol{x}}
at the
(k+1)^{th}
iteration. A surrogate function
g({\boldsymbol{x}}|{\boldsymbol{x}}^{k})
is said to majorize a function
f({\boldsymbol{x}})
if it satisfies the following properties:

g\left({\boldsymbol{x}}^{k}|{\boldsymbol{x}}^{k}\right)=f\left({\boldsymbol{x}}^{k}\right)

(11)

g\left({\boldsymbol{x}}|{\boldsymbol{x}}^{k}\right)\geq f\left({\boldsymbol{x}}\right)

(12)

Using (
10
), (
11
) and (
12
) it can be shown that the sequence of points
\{{\boldsymbol{x}}^{k}\}
generated by the MM procedure monotonically decrease the objective function:

\begin{array}[]{ll}f({\boldsymbol{x}}^{k+1})\leq g({\boldsymbol{x}}^{k+1}|{\boldsymbol{x}}^{k})\leq g({\boldsymbol{x}}^{k}|{\boldsymbol{x}}^{k})=f({\boldsymbol{x}}^{k})\end{array}

(13)

where the first inequality and the last equality are obtained by using (
11
) and (
12
). The second inequality is by (
10
). The computational complexity and the convergence speed of the algorithm depends on the choice of the surrogate function. For instance, in the case of a multivariate optimization problem, a surrogate function could make the parameters separable and hence each of them could be updated parallely - which is particularly useful for a large scale problem. An overview of the various surrogate functions used can be found in (
[
24
]
,
[
25
]
).

The objective function

, which can be observed by first rewriting

\begin{array}[]{ll}f_{{}_{LR}}({\boldsymbol{x}})=\|{\mathbf{y}}-{\mathbf{A}}{\boldsymbol{x}}\|_{p}=\displaystyle\sum_{i=1}^{m}|y_{i}-{\boldsymbol{a}}_{i}^{T}{\boldsymbol{x}}|^{p}\end{array}

where

g(x_{j}|{\boldsymbol{x}}^{k})
which majorizes

Lemma IV.1

Given any
\tilde{{\boldsymbol{x}}}={\tilde{{\boldsymbol{x}}}^{k}}
, the function
\left|{{\boldsymbol{c}}^{T}}\tilde{{\boldsymbol{x}}}\right|^{p}
(
p\geq 1
), where
{\boldsymbol{c}}\>\rm{and}\>\tilde{{\boldsymbol{x}}}\in\mathbf{R}^{n+1}
, can be upper bounded as:

\begin{array}[]{ll}\left|\left({{\boldsymbol{c}}^{T}}\tilde{{\boldsymbol{x}}}\right)\right|^{p}\leq\displaystyle\sum_{j=1}^{n+1}\dfrac{1}{n+1}\left|\left(n+1\right)c_{j}\left(\tilde{x}_{j}-\tilde{x}_{j}^{k}\right)+{\boldsymbol{c}}^{T}{\tilde{{\boldsymbol{x}}}^{k}}\right|^{p}\end{array}

(15)

Proof:

We replicate the proof from
[
24
]
for the sake of clarity. Note that the function
\left|\left(\cdot\right)\right|^{p}
(
p\geq 1
) is convex and hence by using the Jensen’s inequality we get:

\begin{array}[]{ll}\left|\left(\displaystyle\sum_{j=1}^{n+1}\dfrac{s_{j}}{n+1}\right)\right|^{p}\leq\displaystyle\sum_{j=1}^{n+1}\dfrac{|\left(s_{j}\right)|^{p}}{n+1}\end{array}

(16)

Letting
s_{j}=(n+1)c_{j}\left(\tilde{x}_{j}-\tilde{x}_{j}^{k}\right)+{\boldsymbol{c}}^{T}(\tilde{{\boldsymbol{x}}}^{k})
and substituting it in (
16
), the inequality in (
15
) is achieved.
∎Let
{\boldsymbol{c}}_{i}=[c_{i,1}\cdots c_{i,n+1}]^{T}=[-{\boldsymbol{a}}_{i}\>\>y_{i}]^{T}
and let
\tilde{{\boldsymbol{x}}}=[{\boldsymbol{x}},1]^{T}
. Then the objective function
f_{{}_{LR}}({\boldsymbol{x}})
in (
14
) can be rewritten as:

\begin{array}[]{ll}f_{{}_{LR}}({\boldsymbol{x}})=\displaystyle\sum_{i=1}^{m}|y_{i}-{\boldsymbol{a}}_{i}^{T}{\boldsymbol{x}}|^{p}=\displaystyle\sum_{i=1}^{m}|{\boldsymbol{c}}_{i}^{T}\tilde{{\boldsymbol{x}}}|^{p}\end{array}

(17)

Using lemma
IV.1
, we majorize the term
|{\boldsymbol{c}}_{i}^{T}\tilde{{\boldsymbol{x}}}|^{p}
and hence majorize the objective function
f_{{}_{LR}}({\boldsymbol{x}})
. At any given
{\boldsymbol{x}}^{k}
, the majorization function

is given by:

\begin{array}[]{ll}g(x_{j}|{\boldsymbol{x}}^{k})=\displaystyle\sum_{i=1}^{m}\displaystyle\sum_{j=1}^{n+1}\dfrac{1}{n+1}\left|\left(n+1\right)c_{ij}\left(\tilde{x}_{j}-\tilde{x}_{j}^{k}\right)+{\boldsymbol{c}}_{i}^{T}{\tilde{{\boldsymbol{x}}}^{k}}\right|^{p}\end{array}

(18)

where

represents the
j^{th}
element of the
{i}^{th}
vector
{\boldsymbol{c}}_{i}
. The above surrogate function can be rewritten as:

\begin{array}[]{ll}g(x_{j}|{\boldsymbol{x}}^{k})=\displaystyle\sum_{i=1}^{m}\displaystyle\sum_{j=1}^{n}\left|c_{ij}\tilde{x}_{j}+d^{k}_{ij}\right|^{p}+\\
\displaystyle\sum_{i=1}^{m}\left|c_{i,n+1}\tilde{x}_{n+1}+d^{k}_{i,n+1}\right|^{p}=\displaystyle\sum_{i=1}^{m}\displaystyle\sum_{j=1}^{n}\left|-a_{ij}{x}_{j}+d^{k}_{ij}\right|^{p}+\\
\hskip 42.67912pt\displaystyle\sum_{i=1}^{m}\left|y_{i}+d^{k}_{i,n+1}\right|^{p}\end{array}

(19)

where
d^{k}_{ij}=-c_{ij}\tilde{x}^{k}_{j}+\dfrac{1}{n+1}{\boldsymbol{c}}_{i}^{T}{\boldsymbol{x}}^{k}
. From above, it can be observed that if
a_{ij}
is zero then the product
a_{ij}x_{j}
becomes equal to zero, hence the first term of
g(x_{j}|{\boldsymbol{x}}^{k})
has to be computed only over the non-zero elements of

i.e.,

\begin{array}[]{ll}g(x_{j}|{\boldsymbol{x}}^{k})=\displaystyle\mathop{\sum_{i=1}^{m}\sum_{j=1}^{n}}_{a_{ij}\neq 0}\left|-a_{ij}{x}_{j}+d^{k}_{ij}\right|^{p}+\displaystyle\sum_{i=1}^{m}\left|y_{i}+d^{k}_{i,n+1}\right|^{p}\end{array}

(20)

Ignoring the constant terms in
g(x_{j}|{\boldsymbol{x}}^{k})
, the surrogate minimization problem at any iteration, given
{\boldsymbol{x}}^{k}
becomes:

\begin{array}[]{ll}\underset{{\boldsymbol{x}}}{\rm arg\>min}\displaystyle\mathop{\sum_{i=1}^{m}\sum_{j=1}^{n}}_{a_{ij}\neq 0}w_{ij}\left|{x}_{j}-\dfrac{d^{k}_{ij}}{a_{ij}}\right|^{p}\end{array}

(21)

where
w_{ij}=|a_{ij}|^{p}
. The above problem is separable in each element of
{\boldsymbol{x}}
. Hence, at every iteration we solve the following surrogate minimization problem parallely over each element of
{\boldsymbol{x}}
:

\begin{array}[]{ll}\underset{x_{j}}{\rm arg\>min}\displaystyle\mathop{\sum_{i=1}^{m}}_{a_{ij}\neq 0}w_{ij}\left|{x}_{j}-\dfrac{d^{k}_{ij}}{a_{ij}}\right|^{p}\end{array}

(22)

Therefore, each element of
{\boldsymbol{x}}
can be updated parallely. The problem in (
22
) does not have a closed-form solution. However, we can employ a parameter free bisection method to solve the above problem. The initial interval
[a,b]
of the bisection method for the problem in (
22
) is found using the following lemma:

Lemma IV.2

Consider the following problem wherein given the positive weights
(w_{1},w_{2}\cdots w_{N})
and the data points
(a_{1},a_{2}\cdots a_{N})
, the problem is to estimate
x
such that it minimizes the weighted sum of absolute deviations raised to the
p^{th}
power, i.e.

\begin{array}[]{ll}\underset{x}{\rm arg\>min}\>f(x)=\displaystyle\sum_{j=1}^{N}w_{j}|x-a_{j}|^{p}\end{array}

(23)

The solution
x
of the above problem will always lie in-between
\rm{min}({\boldsymbol{a}})
and
\rm{max}({\boldsymbol{a}})
where
{\boldsymbol{a}}=[a_{1},a_{2}\cdots a_{N}]^{T}
.

Proof:

The gradient of the problem in (
23
) is given as:

\begin{array}[]{ll}f^{\prime}(x)=\displaystyle\sum_{j=1}^{N}p\>w_{j}|x-a_{j}|^{p-2}(x-a_{j})=\displaystyle\sum_{j=1}^{N}v_{j}(x-a_{j})\end{array}

(24)

where
v_{j}=p\>w_{j}|x-a_{j}|^{p-2}
and is always positive. Note that for
x=\rm{min}({\boldsymbol{a}})
and
x=\rm{max}({\boldsymbol{a}})
, the gradient
f^{\prime}(x)
will always be lesser than and greater than zero, respectively. Then, according to the Intermediate Value Theorem
[
26
]
, the gradient will be equal to zero for
x
in the interval [
\rm{min}({\boldsymbol{a}})
,
\rm{max}({\boldsymbol{a}})
].
∎Using lemma
IV.2
, the initial interval
[a,b]
for the bisection search approach to solve the problem in (
22
) is
[\rm{min}({\boldsymbol{s}}_{j})\>\>\rm{max}({\boldsymbol{s}}_{j})]^{T}
where the
i^{th}
element of
{\boldsymbol{s}}_{j}
is given as
s_{ij}=\dfrac{d^{k}_{ij}}{a_{ij}}
. Further, by the principle of MM, it is sufficient that the bisection search approach finds a value
{\boldsymbol{x}}^{k}
at the
k^{th}
iteration such that
f_{{}_{\textrm{LR}}}({{\boldsymbol{x}}}^{k})<f_{{}_{\textrm{LR}}}({{\boldsymbol{x}}}^{k-1})
and not find the exact minimum of the surrogate minimization problem in (
22
).

IV-B

Special Cases

When compared to the
\ell_{p}
norm regression problem for
p\in(1,\infty)
, the
\ell_{1}
and
\ell_{\infty}
norm regression problems are non-differentiable - thereby one cannot use the bisection search algorithm developed in the previous subsection to solve the
\ell_{1}
and
\ell_{\infty}
norm regression problem. Hence, in this subsection, we discuss an alternate approach to solve the surrogate minimization problem and extend PROMPT algorithm to solve the
\ell_{1}
and
\ell_{\infty}
norm regression problems.

1.
\ell_{1}
norm linear regression - Consider the following
\ell_{1}
norm linear regression problem:

\begin{array}[]{ll}f_{{}_{LR}}({\boldsymbol{x}})=\|{\mathbf{y}}-{\mathbf{A}}{\boldsymbol{x}}\|_{1}=\displaystyle\sum_{i=1}^{m}|y_{i}-{\boldsymbol{a}}_{i}^{T}{\boldsymbol{x}}|\end{array}

(25)

Similar to the
\ell_{p}
norm regression problem (
p>2
) in (
14
), we rewrite the above problem as:

\begin{array}[]{ll}f_{{}_{LR}}({\boldsymbol{x}})=\displaystyle\sum_{i=1}^{m}|{\boldsymbol{c}}_{i}^{T}\tilde{{\boldsymbol{x}}}|\end{array}

(26)

where
{\boldsymbol{c}}_{i}=[c_{i,1}\cdots c_{i,n+1}]^{T}=[-{\boldsymbol{a}}_{i}\>\>y_{i}]^{T}
and let
\tilde{{\boldsymbol{x}}}=[{\boldsymbol{x}},1]^{T}
. Then by using lemma
IV.1
, we majorize the term
|{\boldsymbol{c}}_{i}^{T}\tilde{{\boldsymbol{x}}}|
and obtain the following surrogate minimization problem:

\begin{array}[]{ll}\underset{x_{j}}{\rm arg\>min}\displaystyle\mathop{\sum_{i=1}^{m}\sum_{j=1}^{n}}w_{ij}\left|{x}_{j}-s_{ij}\right|\end{array}

(27)

where
w_{ij}=|a_{ij}|
,
s_{ij}=\dfrac{d^{k}_{ij}}{a_{ij}}
and
d^{k}_{ij}=-c_{ij}\tilde{x}^{k}_{j}+\dfrac{1}{n+1}{\boldsymbol{c}}_{i}^{T}{\boldsymbol{x}}^{k}
. Similar to the surrogate mimization problem in (
22
), the above problem is separable in each element of
{\boldsymbol{x}}
and hence can be updated parallely. In addition, unlike the surrogate minimization problem in (
22
), the above surrogate minimization problem has a closed-form solution and is given by the weighted median of the points
s_{ij}

[
27
]
. Given the points
s_{1j},s_{2j},\cdots,s_{mj}
and its associated weights
w_{ij}
, the weighted median
x_{j}
is calculated as

a. Sort the points
s_{ij}
in ascending order.

b. Normalize the weights
w_{ij}
associated with the data points
s_{ij}
such that the sum of the weights is equal to one.

c. The weighted median
x_{j}
is one of the points
s_{qj}
satisfying
\displaystyle\sum_{i=1}^{q-1}w_{ij}\leq\dfrac{1}{2}
and
\displaystyle\sum_{i=q+1}^{m}w_{ij}\leq\dfrac{1}{2}
.

{\boldsymbol{x}}

Minimizing the Lagrange function with respect to

\begin{array}[]{ll}x_{j}=\dfrac{\displaystyle\sum_{i=1}^{m}\lambda_{i}w_{ij}^{2}s_{ij}}{\displaystyle\sum_{i=1}^{m}\lambda_{i}w_{ij}^{2}}\end{array}

(33)

\begin{array}[]{ll}\lambda_{i}\left(z-w_{ij}^{2}|x_{j}-s_{ij}|^{2}\right)=0\end{array}

(34)

4.

Each dual variable
\lambda_{i}
must be non-negative.

30

IV-C

Proof of convergence

Given that the proposed algorithm is based on MM procedure, it is guaranteed that the sequence of points
\{{{\boldsymbol{x}}}^{k}\}
generated by MM algorithm will monotonically decrease the problem in (
4
). Moreover, since
f_{{}_{\textrm{LR}}}({{\boldsymbol{x}}})
in (
4
) is bounded below by zero, it is ensured that the sequence
f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}})
will converge to a finite value.

We now show that the sequence
\{{{\boldsymbol{x}}}^{k}\}
converges to the stationary point of the problem in (
4
). From the monotonic property of MM we have:

\begin{array}[]{ll}f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{0}})\geq f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{1}})\geq f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{2}})\end{array}

(35)

Assume that there is a subsequence
{{\boldsymbol{x}}}^{r_{j}}
converging to a limit point
\tilde{{\boldsymbol{q}}}
. Then from (
11
), (
12
) and (
35
) we get:

\begin{array}[]{ll}g({{\boldsymbol{x}}}^{r_{j+1}}|{{\boldsymbol{x}}}^{r_{j+1}})=f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{r_{j+1}}})\leq f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}^{r_{j}+1}})\leq g({{\boldsymbol{x}}}^{r_{j}+1}|{{\boldsymbol{x}}}^{r_{j}})\\
\hskip 71.13188pt\leq g({{\boldsymbol{x}}}|{{\boldsymbol{x}}}^{r_{j}})\end{array}

(36)

where
g(\cdot)
is the surrogate function as defined in (
20
). Then, letting
j\rightarrow\infty
, we get:

\begin{array}[]{ll}g(\tilde{{\boldsymbol{q}}}|\tilde{{\boldsymbol{q}}})\leq g({{\boldsymbol{x}}}|\tilde{{\boldsymbol{q}}})\end{array}

(37)

which implies
g^{\prime}(\tilde{{\boldsymbol{q}}}|\tilde{{\boldsymbol{q}}})\geq 0
. Since the first order behavior of surrogate function is same as function
f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}})
(
[
12
]
),
g^{\prime}(\tilde{{\boldsymbol{q}}}|\tilde{{\boldsymbol{q}}})\geq 0
implies
f^{\prime}_{{}_{\textrm{LR}}}({\tilde{{\boldsymbol{q}}}})\geq 0
. Hence,
\tilde{{\boldsymbol{q}}}
is the stationary point of
f_{{}_{\textrm{LR}}}({{{\boldsymbol{x}}}})
and therefore the proposed algorithm converges to the stationary point of the problem in (
4
).

IV-D

Graph Based semi-supervised learning

In this subsection we discuss the application of proposed algorithm for the graph based semi-supervised learning problem. Graph based semi-supervised learning consists of two steps:

1.

Construction of graph
G=(V,E)
from the given data.

2.

Using the constructed graph estimating the labels of the unlabeled data points using an appropriate algorithm.

We now discuss each step in detail. In the case of first step, as suggested in
[
12
]
, one can construct a symmetric
K
-nearest neighbour (K-NN) graph from the given data. In K-NN graph, each vertex are used to represent a data point. An edge between the data points
{\boldsymbol{v}}_{i}
and
{\boldsymbol{v}}_{j}
exists if and only if
{\boldsymbol{v}}_{i}\in{\textrm{KNN}}({\boldsymbol{v}}_{j})
or
{\boldsymbol{v}}_{j}\in{\textrm{KNN}}({\boldsymbol{v}}_{i})
, where
{\textrm{KNN}}({\boldsymbol{v}}_{j})
stands for the
K
-nearest neighbours of the
{\boldsymbol{v}}_{j}
among the data points
{\boldsymbol{v}}_{1},\cdots,{\boldsymbol{v}}_{j-1},{\boldsymbol{v}}_{j+1},\cdots,{\boldsymbol{v}}_{n}
. The
K
-nearest neighbours of
{\boldsymbol{v}}_{j}
are found by measuring the Euclidean distance between
{\boldsymbol{v}}_{j}
and each of the remaining data points
{\boldsymbol{v}}_{1},\cdots,{\boldsymbol{v}}_{j-1},{\boldsymbol{v}}_{j+1},\cdots,{\boldsymbol{v}}_{n}
and choosing the data points corresponding to the
K
smallest distance. Each edge is associated with a non-negative edge weight which is defined as:

\displaystyle w_{ij}

\displaystyle=

\displaystyle\begin{cases}\textrm{exp}\left(-\dfrac{\|{\boldsymbol{v}}_{i}-{\boldsymbol{v}}_{j}\|_{2}^{2}}{\sigma^{2}}\right)&;{\boldsymbol{v}}_{i}\in{\textrm{KNN}}({\boldsymbol{v}}_{j})\\
\textrm{exp}\left(-\dfrac{\|{\boldsymbol{v}}_{j}-{\boldsymbol{v}}_{i}\|_{2}^{2}}{\sigma^{2}}\right)&;{\boldsymbol{v}}_{j}\in{\textrm{KNN}}({\boldsymbol{v}}_{i})\\
0&;\textrm{otherwise}\end{cases}

(38)

where
\sigma=\dfrac{1}{2}{\rm{max}}\{\|{\boldsymbol{v}}_{i}-{\boldsymbol{v}}_{j}\|_{2}^{2}:w_{ij}>0\}
.

From the constructed graph
G
, we now estimate the labels of the unlabeled points by solving the problem in (
6
). For the ease of readability, we re-write the problem once again here:

\begin{array}[]{ll}\underset{f}{\rm arg\>min}\>\displaystyle\sum_{i,j\in E}w_{ij}\left|f(v_{i})-f(v_{j})\right|^{p}\\
\hskip 8.53581pt{\rm{subject\>to}}\>f(v_{i})=h_{i},i\in L\end{array}

(39)

Let
f_{i}=f(v_{i})
and
{\boldsymbol{f}}=[f_{1},f_{2}\cdots f_{n}]\in\mathbf{R}^{n}
and
{\boldsymbol{h}}=[h_{1},h_{2},\cdots,h_{l}]\in\mathbf{R}^{l}
. Then the constrained problem in (
39
) can be re-written as:

\begin{array}[]{ll}\underset{{\boldsymbol{f}}}{\rm arg\>min}\>\displaystyle\sum_{i=1}^{u}\displaystyle\sum_{j=1}^{u}w_{ij}\left|f_{i}-f_{j}\right|^{p}+\displaystyle\sum_{i=1}^{u}\displaystyle\sum_{j=1}^{l}w_{i,j+u}|f_{i}-h_{j}|^{p}\end{array}

(40)

We now convert the above problem to
\ell_{p}
norm regression problem. To do so, we first define the edge vertex incidence matrix
{\boldsymbol{B}}
. Each row of the edge incidence matrix
{\boldsymbol{B}}
corresponds to an edge and each column corresponds to a vertex and its entries are given as:

\displaystyle{\boldsymbol{B}}_{ev}

\displaystyle=

\displaystyle\begin{cases}1&;{\textrm{if v is the head of e}}\\
-1&;{\textrm{if v is the tail of e}}\\
0&;\textrm{otherwise}\end{cases}

(41)

Let
{\boldsymbol{G}}={\boldsymbol{W}}^{1/p}{\boldsymbol{B}}
, where
{\boldsymbol{W}}
is a diagonal matrix with the weights of the edges and
{\boldsymbol{z}}=-[{\boldsymbol{B}}]_{:,u+1:u+l}{\boldsymbol{h}}
, where the notation
[{\boldsymbol{B}}]_{:,u+1:u+l}
is used to represent all the rows of
u+1
to
u+l
columns of the matrix
{\boldsymbol{B}}
. Then the problem in (
40
) can be re-written as:

\begin{array}[]{ll}\underset{{\boldsymbol{f}}}{\rm arg\>min}\|{\boldsymbol{G}}{\boldsymbol{f}}-{\boldsymbol{z}}\|_{p}\end{array}

(42)

which is an
\ell_{p}
-norm regression problem and the proposed algorithm can be used to solve it.

VI
Conclusion

In this paper, we proposed an iterative algorithm
PROMPT
based on the MM procedure to solve the
\ell_{p}
norm regression problem for any value of
p
.
PROMPT
can parallely update each element of
{\boldsymbol{x}}
which is helpful to handle the large scale data efficiently. Also, unlike the state-of-the-art algorithm, the proposed algorithm converges to to the optimal point irrespective of the initialization scheme. We show through computer simulations that the proposed algorithm has faster speed of convergence when compared to the state-of-the-art algorithms and in the end we also evaluate the performance of the proposed algorithm for the graph based semi-supervised problem using real and simulated data.
