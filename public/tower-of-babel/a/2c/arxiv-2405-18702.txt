Two classes of Majorana neutrinos in the seesaw model


Abstract
The commonly used pseudo-C symmetry ( ν L ) c = C ​ ν L ¯ T (\nu_{L})^{c}=C\overline{\nu_{L}}^{T} is not defined in Lagrangian field theory. In general, there exist two classes of Majorana fermions; the first is associated with the Dirac-type fermion with the conventional C and P symmetries, and the second is associated with the Weyl-type fermion defined by CP symmetry only and formally characterised by the pseudo-C symmetry. Taking the seesaw model as an example, it is shown that a generalized Pauli–Gürsey (or Bogoliubov-type) canonical transformation converts the neutrino defined by the Weyl-type fermion to the neutrino defined by the Dirac-type fermion and thus to the conventional Majorana fermion, while preserving the canonical anti-commutation relations. The mixing angles in the weak lepton sector are not modified by this generalized Pauli–Gürsey transformation.

We first summarize the conceptual complications in the case of Majorana neutrinos. One defines the customarily used

]

\displaystyle\nu_{L}(x)\to\nu_{L}(x)^{\tilde{C}}=C\overline{\nu_{L}(x)}^{T}.

(1)

Our notational conventions follow those in

\displaystyle\psi(x)\equiv\nu_{L}(x)+C\overline{\nu_{L}}^{T}(x),

Suppose we construct a Lagrangian, comprising kinetic and mass terms, invariant under the pseudo-C symmetry by using (

\displaystyle=

\displaystyle\int d^{4}x(1/2)\{\bar{\psi}i\gamma^{\mu}\partial_{\mu}\psi(x)-\bar{\psi}(x)M_{\nu}\psi(x)\}

\displaystyle\int d^{4}x\{\overline{\nu_{L}}(x)i\gamma^{\mu}\partial_{\mu}\nu_{L}(x)-(1/2)[\nu_{L}^{T}(x)CM_{\nu}\nu_{L}(x)+h.c.]\}

where

1
]

\displaystyle\int d^{4}x{\cal L}_{\nu}

\displaystyle=

\displaystyle\int d^{4}x\Big\{\overline{\nu_{L}}(x)i\gamma^{\mu}\partial_{\mu}\left(\frac{1-\gamma_{5}}{2}\right)\nu_{L}(x)

(5)

\displaystyle-

\displaystyle(1/2)\left[\nu_{L}^{T}(x)CM_{\nu}\left(\frac{1-\gamma_{5}}{2}\right)\nu_{L}(x)+h.c.\right]\Big\}.

In the last formula, we apply the pseudo-C operation (

\nu_{L}(x)\rightarrow C\overline{\nu_{L}(x)}^{T}

Noting that

This shows that the operation

\nu_{L}(x)\ \to\nu_{L}(x)^{\tilde{C}}=C\overline{\nu_{L}(x)}^{T}

Practically, Weinberg’s model

5

6

Technically, we distinguish the Weyl fermion from the chiral fermion as much as possible in the following. Only CP operation is allowed for the free Weyl fermion, while C and P are separately defined for the free chiral fermion which arises from a massive Dirac-type fermion. Thus, we define CP for the Weyl fermion

\displaystyle\nu_{L}(x^{0},\vec{x})\rightarrow i\gamma^{0}C\overline{\nu_{L}}^{T}(x^{0},-\vec{x}),

(6)

but no separate C nor P. The “Majorana” fermion in the sense

\displaystyle\psi(x)\equiv\nu_{L}(x)+C\overline{\nu_{L}}^{T}(x)

(7)

is defined only for CP-symmetry as it is based on the Weyl fermion in the present case. Noting that CP conjugation is given by (
6

we have the CP transformation for
\psi(x)

3
]

\displaystyle\psi(x^{0},\vec{x})\rightarrow i\gamma^{0}\psi(x^{0},-\vec{x}).

(8)

However, no separate C nor P are defined for
\psi(x^{0},\vec{x})
in (

On the other hand, the chiral fermion arising from a generic Dirac-type massive fermion is defined both with the charge conjugation and parity separately by

\displaystyle C:\ \ \ \nu_{L}(x)\rightarrow C\overline{\nu_{R}}^{T}(x)=\left(C\overline{\nu}^{T}(x)\right)_{L},

\displaystyle\ \ \ \ \ \ \ \ \nu_{R}(x)\rightarrow C\overline{\nu_{L}}^{T}(x)=\left(C\overline{\nu}^{T}(x)\right)_{R},

\displaystyle P:\ \ \ \nu_{L,R}(x^{0},\vec{x})\rightarrow i\gamma^{0}\nu_{R,L}(x^{0},-\vec{x}),

(9)

and thus the combined CP is formally the same as for the Weyl fermion (
