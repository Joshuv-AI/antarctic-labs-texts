Blow-up problem for nonlinear nonlocal parabolic equation with absorption under nonlinear nonlocal boundary condition
Alexander Gladkov

Abstract
. In this paper we consider initial boundary value problem for nonlinear nonlocal parabolic equation with absorption under nonlinear nonlocal boundary condition and nonnegative initial datum. We prove comparison principle, global existence and blow-up of solutions.

1.
Introduction

In this paper we consider the initial boundary value problem for
nonlinear nonlocal parabolic equation

u_{t}=\Delta u+au^{p}\int_{\Omega}u^{q}(y,t)\,dy-bu^{m},\;x\in\Omega,\;t>0,

(1.1)

with nonlinear nonlocal boundary condition

\frac{\partial u(x,t)}{\partial\nu}=\int_{\Omega}{k(x,y,t)u^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;t>0,

(1.2)

and initial datum

u(x,0)=u_{0}(x),\;x\in\Omega,

(1.3)

where
a,\,b,\,p,\,q,\,m,\,l
are positive numbers,
\Omega
is a bounded domain in
\mathbb{R}^{N}

for
N\geq 1
with smooth boundary
\partial\Omega
,
\nu
is unit
outward normal on
\partial\Omega.

Throughout this paper we suppose that the functions

k(x,y,t)
and
u_{0}(x)
satisfy the following conditions:

k(x,y,t)\in C(\partial\Omega\times\overline{\Omega}\times[0,+\infty)),\;k(x,y,t)\geq 0;

u_{0}(x)\in C^{1}(\overline{\Omega}),\;u_{0}(x)\geq 0\textrm{ in
}\Omega,\;\frac{\partial u_{0}(x)}{\partial\nu}=\int_{\Omega}{k(x,y,0)u_{0}^{l}(y)}\,dy\textrm{ on }\partial\Omega.

2.
Comparison principle

In this section a comparison principle
for (
1.1
)–(
1.3
) will be proved. We begin with
definitions of a supersolution, a subsolution and a maximal
solution of (
1.1
)–(
1.3
). Let

Q_{T}=\Omega\times(0,T),\;S_{T}=\partial\Omega\times(0,T)
,

\Gamma_{T}=S_{T}\cup\overline{\Omega}\times\{0\}
,
T>0
.

Definition 2.1
.

We say that a nonnegative function
u(x,t)\in C^{2,1}(Q_{T})\cap C^{1,0}(Q_{T}\cup\Gamma_{T})
is a supersolution
of (
1.1
)–(
1.3
) in
Q_{T}
if

u_{t}\geq\Delta u+au^{p}\int_{\Omega}u^{q}(y,t)\,dy-bu^{m},\;(x,t)\in Q_{T},

(2.1)

\frac{\partial u(x,t)}{\partial\nu}\geq\int_{\Omega}{k(x,y,t)u^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;0<t<T,

(2.2)

u(x,0)\geq u_{0}(x),\;x\in\Omega,

(2.3)

and
u(x,t)\in C^{2,1}(Q_{T})\cap C^{1,0}(Q_{T}\cup\Gamma_{T})
is a
subsolution of (
1.1
)–(
1.3
) in
Q_{T}
if
u\geq 0
and
it satisfies (
2.1
)–(
2.3
) in the reverse
order. We say that
u(x,t)
is a solution of
problem (
1.1
)–(
1.3
) in
Q_{T}
if
u(x,t)
is both a
subsolution and a supersolution of (
1.1
)–(
1.3
) in

Q_{T}
.

Definition 2.2
.

We say that a solution
u(x,t)
of (
1.1
)–(
1.3
) in

Q_{T}
is a maximal solution if for any other solution
v(x,t)

of (
1.1
)–(
1.3
) in
Q_{T}
the inequality
v(x,t)\leq u(x,t)
is satisfied for
(x,t)\in Q_{T}\cup\Gamma_{T}
.

Theorem 2.3
.

Let
\overline{u}
and
\underline{u}
be a
supersolution and a subsolution of problem
(
1.1
)–(
1.3
) in
Q_{T},
respectively. Suppose that

\underline{u}(x,t)>0
or
\overline{u}(x,t)>0
in
{Q}_{T}\cup\Gamma_{T}
if
\min(p,q,l)<1.
Then
\overline{u}(x,t)\geq\underline{u}(x,t)
in
{Q}_{T}\cup\Gamma_{T}.

Proof.

Suppose that
\min\{p,q,l\}\geq 1.
Let
T_{0}\in(0,T)
and
\{\varepsilon_{n}\}
be decreasing to
0
a sequence such that

0<\varepsilon_{n}<1.
For
\varepsilon=\varepsilon_{n}
let

u_{0\varepsilon}(x)
be the functions with the following
properties:
u_{0\varepsilon}(x)\in C^{1}(\overline{\Omega}),\,

u_{0\varepsilon}(x)\geq\varepsilon,\,

u_{0\varepsilon_{i}}(x)\geq u_{0\varepsilon_{j}}(x)
for
\varepsilon_{i}>\varepsilon_{j},\,

u_{0\varepsilon}(x)\to u_{0}(x)
as
\varepsilon\to 0
and

\frac{\partial u_{0\varepsilon}(x)}{\partial\nu}=\int_{\Omega}k(x,y,0)u^{l}_{0\varepsilon}(y)\,dy

for
x\in\partial\Omega.
Let
u_{\varepsilon}
be the solution of the following auxiliary
problem:

\displaystyle\left\{\begin{array}[]{ll}u_{t}=\Delta u+au^{p}\int_{\Omega}u^{q}(y,t)\,dy-bu^{m}+b\varepsilon^{m}&\textrm{for}\,\,\,x\in\Omega,\,\,\,\,\,t>0,\\
\frac{\partial u(x,t)}{\partial\nu}=\int_{\Omega}k(x,y,t)u^{l}(y,t)dy&\textrm{for}\,\,\,x\in\partial\Omega,\,\,t>0,\\
u(x,0)=u_{0\varepsilon}(x)&\textrm{for}\,\,\,x\in\Omega,\end{array}\right.

where
\varepsilon=\varepsilon_{n}.
It was proved in
[
33
]
(see also
[
11
]
for similar problem) that

u_{m}(x,t)=\lim_{\varepsilon\to 0}u_{\varepsilon}(x,t)
is a maximal solution of
(
1.1
)–(
1.3
). To establish theorem we will show that

\underline{u}(x,t)\leq u_{m}(x,t)\leq\overline{u}(x,t)\,\,\,\textrm{in}\,\,\,\overline{Q}_{T_{0}}\,\,\,\textrm{for any}\,\,\,T_{0}\in(0,T).

(2.8)

We prove the second inequality in (
2.8
) only, since the
proof of the first one is similar. Let
\varphi(x,t)\in C^{2,1}(\overline{Q}_{T_{0}})
be a nonnegative function such that

\frac{\partial\varphi(x,t)}{\partial\nu}=0,\;(x,t)\in S_{T_{0}}.

If we multiply the first equation in (
2
) by
\varphi(x,t)
and then integrate over
Q_{t}
for
0<t<T_{0},
we get

\displaystyle\hskip-19.91684pt\int_{\Omega}u_{\varepsilon}(x,t)\varphi(x,t)\,dx

\displaystyle\leq

\displaystyle\int_{\Omega}u_{\varepsilon}(x,0)\varphi(x,0)\,dx+\varepsilon^{m}b\int_{0}^{t}\int_{\Omega}\varphi(x,\tau)\,dxd\tau

(2.9)

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\Omega}\left[u_{\varepsilon}(x,\tau)\varphi_{\tau}(x,\tau)+u_{\varepsilon}(x,\tau)\Delta\varphi(x,\tau)\right.

\displaystyle+

\displaystyle\left.au_{\varepsilon}^{p}(x,\tau)\int_{\Omega}u_{\varepsilon}^{q}(y,\tau)\,dy-bu_{\varepsilon}^{m}\varphi(x,\tau)\right]\,dxd\tau

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\partial\Omega}\varphi(x,\tau)\int_{\Omega}k(x,y,\tau)u_{\varepsilon}^{l}(y,\tau)\,dy\,dS_{x}d\tau.

On the other hand,
\overline{u}
satisfies (
2.9
) with
reversed inequality and with
\varepsilon=0.
Set

w(x,t)=u_{\varepsilon}(x,t)-\overline{u}(x,t).
Then
w(x,t)

satisfies

\displaystyle\hskip-25.6073pt\int_{\Omega}w(x,t)\varphi(x,t)\,dx

\displaystyle\leq

\displaystyle\int_{\Omega}w(x,0)\varphi(x,0)\,dx+\varepsilon^{m}b\int_{0}^{t}\int_{\Omega}\varphi\,dxd\tau

(2.10)

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\Omega}(\varphi_{\tau}+\Delta\varphi-bm\theta_{1}^{m-1}(x,\tau)\varphi)w\,dxd\tau

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\Omega}ap\theta_{2}^{p-1}(x,\tau)w(x,\tau)\int_{\Omega}u_{\varepsilon}^{q}(y,\tau)\,dydxd\tau

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\Omega}a\overline{u}^{p}(x,\tau)\int_{\Omega}q\theta_{3}^{q-1}(y,\tau)w(y,\tau)\,dydxd\tau

\displaystyle+

\displaystyle\int_{0}^{t}\int_{\partial\Omega}\varphi(x,\tau)\int_{\Omega}k(x,y,\tau)l\theta_{4}^{l-1}w(y,\tau)\,dydS_{x}d\tau,

where
\theta_{i},\,i=\overline{1,4}
are some continuous functions
between
u_{\varepsilon}
and
\overline{u}.
Note here that by
hypotheses for
k(x,y,t)
,
u_{\varepsilon}(x,t)
and

\overline{u}(x,t)
, we have

\displaystyle 0\leq\overline{u}(x,t)\leq M,\,\,\varepsilon\leq u_{\varepsilon}(x,t)\leq M\,\,\textrm{in}\,\,\overline{Q}_{T_{0}}

\displaystyle\textrm{and}\,\,\,0\leq k(x,y,t)\leq M\,\,\,\textrm{in}\,\,\partial\Omega\times\overline{Q}_{T_{0}},

(2.11)

where
M
is some positive constant. Then it is easy to see from
(
2
) that
\theta_{1}^{m-1},\,

\theta_{2}^{p-1},\,

\theta_{3}^{q-1}
and
\theta_{4}^{l-1}
are
positive and bounded functions in
\overline{Q}_{T_{0}}
and,
moreover,
\theta_{2}^{p-1}\leq M^{p-1},\,

\theta_{3}^{q-1}\leq M^{q-1},\,

\theta_{4}^{l-1}\leq M^{l-1}.

Define a sequence
\{a_{k}\}
in the following way:
\,a_{k}\in C^{\infty}(\overline{Q}_{T_{0}}),\,

a_{k}\geq 0\,
and
\,a_{k}\to bm\theta_{1}^{m-1}\,
as
\,k\to\infty\,
in
L^{1}({Q}_{T_{0}}).

Now consider a backward problem given by

\displaystyle\left\{\begin{array}[]{ll}\varphi_{\tau}+\Delta\varphi-a_{k}\varphi=0&\textrm{for}\,\,\,x\in\Omega,\,\,\,0<\tau<t,\\
\frac{\partial\varphi(x,\tau)}{\partial\nu}=0&\textrm{for}\,\,\,x\in\partial\Omega,\,\,\,0<\tau<t,\\
\varphi(x,t)=\psi(x)&\textrm{for}\,\,\,x\in\Omega,\end{array}\right.

where
\psi(x)\in C_{0}^{\infty}(\Omega)
and
0\leq\psi(x)\leq 1.
Denote a solution of (
2
) as
\varphi_{k}(x,\tau).

Then by the standard theory for linear parabolic equations (see

[
24
]
, for example), we find that
\varphi_{k}\in C^{2,1}(\overline{Q}_{t}),

0\leq\varphi_{k}(x,\tau)\leq 1
in

\overline{Q}_{t}.
Putting
\varphi=\varphi_{k}
in
(
2.10
) and passing then to the limit as
k\to\infty,
we
infer

\displaystyle\int_{\Omega}w(x,t)\psi(x)\,dx

\displaystyle\leq

\displaystyle\int_{\Omega}w(x,0)_{+}\,dx+\varepsilon^{m}bT_{0}|\Omega|

(2.16)

\displaystyle+

\displaystyle[a(p+q)|\Omega|M^{p+q-1}+l|\partial\Omega|M^{l}]\int_{0}^{t}\int_{\Omega}w(y,\tau)_{+}\,dyd\tau,

where
w_{+}=\max\{w,0\},

|\partial\Omega|
and
|\Omega|
are
the Lebesgue measures of
\partial\Omega
in
\mathbb{R}^{N-1}
and

\Omega
in
\mathbb{R}^{N},
respectively. Since (
2.16
) holds
for every
\psi(x),
we can choose a sequence
\{\psi_{k}\}

converging in
L^{1}(\Omega)
to
\psi(x)=1
if
w(x,t)>0
and
\psi(x)=0
otherwise. Hence, from (
2.16
) we get

\displaystyle\int_{\Omega}w(x,t)_{+}\,dx

\displaystyle\leq

\displaystyle\int_{\Omega}w(x,0)_{+}\,dx+\varepsilon^{m}bT_{0}|\Omega|

\displaystyle+

\displaystyle[a(p+q)|\Omega|M^{p+q-1}+l|\partial\Omega|M^{l}]\int_{0}^{t}\int_{\Omega}w(y,\tau)_{+}\,dyd\tau.

Applying now Gronwall’s inequality and passing to the limit

\varepsilon\to 0,
the conclusion of the theorem follows for
\min(p,q,l)\geq 1.

For the case
\min(p,q,l)<1
we can consider

w(x,t)=\underline{u}(x,t)-\overline{u}(x,t)
and prove the
theorem in a similar way using the positiveness of a subsolution
or a supersolution.
∎

Remark 2.5
.

We improve a comparison principle in
[
33
]
. The authors of
[
33
]
supposed that

\underline{u}(x,t)>0
or
\overline{u}(x,t)>0
in
{Q}_{T}\cup\Gamma_{T}
if
\min(m,p,q,l)<1.

Next lemma shows the positiveness for
t>0
of solutions of (
1.1
)–(
1.3
) with
m\geq 1
and
u_{0}\not\equiv 0.

Lemma 2.6
.

Let
u_{0}\not\equiv 0
in
\Omega,

m\geq 1.
Suppose
u
is a solution of
(
1.1
)–(
1.3
) in
Q_{T}.
Then
u>0
in
{Q}_{T}\cup S_{T}.

Proof.

We take any
\tau\in(0,T).

As
u(x,t)
is continuous in
\overline{Q}_{\tau}
function, then we have

u(x,t)\leq M,\,\,(x,t)\in\overline{Q}_{\tau}

(2.17)

with some positive constant
M.
Now we put
v=u\exp(\lambda t),

where
\lambda\geq bM^{m-1}.
It is easy to verify that
v_{t}-\Delta v\geq 0.
Since
v(x,0)=u_{0}(x)\not\equiv 0
in
\Omega
and
v(x,t)\geq 0
in
Q_{\tau},
by the strong maximum principle
v(x,t)>0

in
Q_{\tau}.
Let
v(x_{0},t_{0})=0
in some point
(x_{0},t_{0})\in S_{T}.

Then according to Theorem 3.6 of
[
19
]
it yields
\partial v(x_{0},t_{0})/\partial\nu<0,
which contradicts (
1.2
).
∎

3.
Global existence

Theorem 3.1
.

Let
\max(p+q,l)\leq 1
or
1<\max(p+q,l)<m.
Then every solution
of (
1.1
)–(
1.3
) is global.

Proof.

In order to prove global existence of solutions we construct a
suitable explicit supersolution of (
1.1
)–(
1.3
) in

Q_{T}
for any positive
T.
Suppose at first that
\max(p+q,l)\leq 1.

Since
k(x,y,t)
is a continuous function, there exists a constant

K>0
such that

k(x,y,t)\leq K

(3.1)

in
\partial\Omega\times Q_{T}.
Let
\lambda_{1}
be the first
eigenvalue of the following problem

\begin{cases}\Delta\varphi+\lambda\varphi=0,\;x\in\Omega,\\
\varphi(x)=0,\;x\in\partial\Omega,\end{cases}

(3.2)

and
\varphi(x)
be the corresponding eigenfunction with

\sup\limits_{\Omega}\varphi(x)=1
. It is well known,

\varphi(x)>0
in
\Omega
and
\max\limits_{\partial\Omega}\partial\varphi(x)/\partial\nu<0.

We now construct a supersolution of (
1.1
)–(
1.3
) in
Q_{T}
as follows

\overline{u}(x,t)=\frac{C\exp(\mu t)}{c\varphi(x)+1},

where constants
C,\mu
and
c
are chosen to satisfy the
inequalities:

c\geq\max\left\{K\int_{\Omega}\frac{dy}{(\varphi(y)+1)^{l}}\max_{\partial\Omega}\left(-\frac{\partial\varphi}{\partial\nu}\right)^{-1},1\right\},

C\geq\max\{\sup_{\Omega}(c\varphi(x)+1)u_{0}(x),1\},\quad\mu\geq\lambda_{1}+2c^{2}\sup_{\Omega}\frac{|\nabla\varphi|^{2}}{(c\varphi(x)+1)^{2}}+a|\Omega|.

It is easy to obtain

\displaystyle\overline{u}_{t}-\Delta\overline{u}

\displaystyle-a\overline{u}^{p}\int_{\Omega}\overline{u}^{q}(y,t)\,dy+b\overline{u}^{m}

\displaystyle\geq\left(\mu-\frac{c\lambda_{1}\varphi}{c\varphi(x)+1}-2c^{2}\sup_{\Omega}\frac{|\nabla\varphi|^{2}}{(c\varphi(x)+1)^{2}}-a|\Omega|\right)\overline{u}\geq 0

(3.3)

for
(x,t)\in Q_{T},

\displaystyle\frac{\partial\overline{u}}{\partial\nu}=

\displaystyle cC\exp(\mu t)\left(-\frac{\partial\varphi}{\partial\nu}\right)\geq KC^{l}\exp(l\mu t)\int_{\Omega}\frac{dy}{(\varphi(y)+1)^{l}}

\displaystyle\geq

\displaystyle\int_{\Omega}k(x,y,t)\overline{u}^{l}(y,t)\,dy

(3.4)

for
(x,t)\in S_{T}
and

\overline{u}(x,0)\geq u_{0}(x)

(3.5)

for
x\in\Omega.
By virtue of (
3.3
)–(
3.5
) and Theorem
2.3
,
the solution of (
1.1
)–(
1.3
) exists globally.

Suppose now that
1<\max(p+q,l)<m.
Let
v_{0}(x)
be the function with the following properties:

v_{0}(x)\in C^{1}(\overline{\Omega}),\;v_{0}(x)>u_{0}(x)\textrm{ in
}\overline{\Omega},\;\frac{\partial v_{0}(x)}{\partial\nu}=\int_{\Omega}{Kv_{0}^{l}(y)}\,dy\textrm{ on }\partial\Omega,

where
K
was defined in (
3.1
). Let
v(x,t)
be the solution of (
1.1
) in
Q_{T}
with
boundary and initial data

\frac{\partial u(x,t)}{\partial\nu}=\int_{\Omega}{Ku^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;0<t<T,

(3.6)

u(x,0)=v_{0}(x),\;x\in\Omega.

(3.7)

We prove that
v(x,t)
exists in
Q_{T}
for any
T>0.

By Lemma
2.6
and Theorem
2.3

u(x,t)\leq v(x,t)\textrm{ in }Q_{T}.

Integrating (
1.1
) for
v(x,t)
over
Q_{t}
and using Green’s identity and H
\ddot{o}
lder’s inequality, we have

\displaystyle\int_{\Omega}v(x,t)\,dx=\int_{\Omega}v_{0}(x)\,dx+\int_{0}^{t}\int_{\partial\Omega}\int_{\Omega}Kv^{l}(y,\tau)\,dy\,dS_{x}\,d\tau

\displaystyle+a\int_{0}^{t}\int_{\Omega}v^{p}(y,\tau)\,dy\int_{\Omega}v^{q}(y,\tau)\,dy\,d\tau-b\int_{0}^{t}\int_{\Omega}v^{m}(y,\tau)\,dy\,d\tau

\displaystyle\leq\int_{\Omega}v_{0}(x)\,dx+K|\partial\Omega|(t|\Omega|)^{\frac{m-l}{m}}\left(\int_{0}^{t}\int_{\Omega}v^{m}(y,\tau)\,dy\,d\tau\right)^{\frac{l}{m}}

\displaystyle+at^{\frac{m-p-q}{m}}|\Omega|^{\frac{2m-p-q}{m}}\left(\int_{0}^{t}\int_{\Omega}v^{m}(y,\tau)\,dy\,d\tau\right)^{\frac{p+q}{m}}-b\int_{0}^{t}\int_{\Omega}v^{m}(y,\tau)\,dy\,d\tau.

(3.8)

Since
v(x,t)>0,
we obtain from (
3.8
) that

\int_{0}^{t}\int_{\Omega}v^{m}(y,\tau)\,dy\,d\tau\leq C(T),\;t\leq T.

(3.9)

Now we prove that
v(x,t)
can not blow up in
\Omega.

Let
G_{N}(x,y;t-\tau)
be the Green function of
the heat equation with homogeneous Neumann boundary condition.
Then we have the representation formula:

\displaystyle v(x,t)

\displaystyle=\int_{\Omega}{G_{N}(x,y;t)v_{0}(y)}dy+K\int_{0}^{t}{\int_{\partial\Omega}G_{N}(x,\xi;t-\tau)\int_{\Omega}v^{l}(y,\tau)}dydS_{\xi}d\tau

\displaystyle+a\int_{0}^{t}{\int_{\Omega}G_{N}(x,y;t-\tau)v^{p}(y,\tau)\int_{\Omega}v^{q}(z,\tau)}\,dz\,dyd\tau

\displaystyle-b\int_{0}^{t}{\int_{\Omega}}G_{N}(x,y;t-\tau)v^{m}(y,\tau)\,dyd\tau

(3.10)

for
(x,t)\in Q_{T}.
We now take a sequence of sets
\{\Omega_{k}\}
such that

\Omega_{k}\subset\subset\Omega,\,

\Omega_{k}\subset\Omega_{k+1},\,

\Omega=\cup_{k=1}^{\infty}\Omega_{k},\,

\partial\Omega_{k}\in C^{2}.

It is well known (see, for example,
[
19
]
,
[
20
]
) that

G_{N}(x,y;t-\tau)\geq 0,\;x,y\in\Omega,\;0\leq\tau<t<T,

(3.11)

\int_{\Omega}{G_{N}(x,y;t-\tau)}\,dy=1,\;x\in\Omega,\;0\leq\tau<t<T,

(3.12)

0\leq G_{N}(x,y;t-\tau)\leq c_{0},\;x\in\Omega_{k},\;y\in\partial\Omega,\;0<\tau<t<T,

(3.13)

c_{1}\leq G_{N}(x,y;t-\tau)\leq c_{2},\;x\in\overline{\Omega},\;y\in\overline{\Omega},\;t-\tau\geq\varepsilon_{0},

(3.14)

\frac{c_{3}}{\sqrt{t-\tau}}\leq\int_{\partial\Omega}G_{N}(x,\xi;t-\tau)dS_{\xi}\leq\frac{c_{4}}{\sqrt{t-\tau}},\;x\in\partial\Omega,\;0<t-\tau\leq\varepsilon_{0},

(3.15)

where
\varepsilon_{0}>0,\,

c_{0}
is a positive constant depending on

k.
Here and below
c_{i},\,i\in\mathbb{N}
are positive constants.
We note that

v^{p}(y,t)\int_{\Omega}v^{q}(z,t)\,dz\leq v^{p+q}(y,t)+\left(\int_{\Omega}v^{q}(z,t)\,dz\right)^{\frac{p+q}{q}}\,\textrm{for}\,\,\,(y,t)\in Q_{T}.

(3.16)

Indeed, if

\int_{\Omega}v^{q}(z,t)\,dz\leq v^{q}(y,t),

then

v^{p}(y,t)\int_{\Omega}v^{q}(z,t)\,dz\leq v^{p+q}(y,t).

Otherwise, we have

v^{p}(y,t)\leq\left(\int_{\Omega}v^{q}(z,t)\,dz\right)^{\frac{p}{q}}

and

v^{p}(y,t)\int_{\Omega}v^{q}(z,t)\,dz\leq\left(\int_{\Omega}v^{q}(z,t)\,dz\right)^{\frac{p+q}{q}}.

Now using (
3.12
), (
3.16
) and H
\ddot{o}
lder’s inequality, we estimate the third integral in the right hand side of (
