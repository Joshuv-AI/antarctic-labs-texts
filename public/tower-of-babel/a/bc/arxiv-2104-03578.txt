Abstract
. We consider a system of two singularly perturbed Boundary Value Problems (BVPs) of convection-diffusion type with discontinuous source terms and a small positive parameter multiplying the highest derivatives. Then their solutions exhibit boundary layers as well as weak interior layers. A numerical method based on finite element method (Shishkin and Bakhvalov-Shishkin meshes) is presented. We derive an error estimate of order O ⁡ ( N − 1 ​ ln 3 / 2 ​ N ) O(N^{-1}\ln^{3/2}{N}) in the energy norm with respect to the perturbation parameter. Numerical experiments are also presented to support our theoritical results. AMS Mathematics Subject Classification: 65L10, CR G1.7 Key words:Singularly perturbed problem, Discontinuous source term, Weakly coupled system, Finite element method, Energy norm, Convection-diffusion, Boundary value problem.

(.,.)

\quad f(\bar{v}):=f_{1}(v_{1})+f_{2}(v_{2}).

B(.,.)

|||\bar{u}|||_{H_{0}^{1}}=[\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\sigma(\|u_{1}\|_{0}^{2}+\|u_{2}\|_{0}^{2})]^{1/2},

Lemma 2.1
.

A bilinear functional

Proof.

Let
\bar{u}=(u_{1},u_{2})\in(H_{0}^{1}(\Omega))^{2}.
Then

\displaystyle B(\bar{u},\bar{u})

\displaystyle=

\displaystyle\varepsilon(u_{1}^{\prime},u_{1}^{\prime})+(b_{1}u_{1}^{\prime},u_{1})+(a_{11}u_{1}+a_{12}u_{2},u_{1})+\varepsilon(u_{2}^{\prime},u_{2}^{\prime})+(b_{2}u_{2}^{\prime},u_{2})

\displaystyle+(a_{21}u_{1}+a_{22}u_{2},u_{2})

\displaystyle\geq

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\int_{0}^{1}b_{1}(x)u_{1}^{\prime}u_{1}dx+\int_{0}^{1}b_{2}(x)u_{2}^{\prime}u_{2}dx+(\alpha u_{1},u_{1})

\displaystyle+(\alpha u_{2},u_{2})

\displaystyle=

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\int_{0}^{1}\frac{b_{1}(x)}{2}\frac{d}{dx}(u_{1}^{2})+\int_{0}^{1}\alpha u_{1}^{2}dx+\int_{0}^{1}\frac{b_{2}(x)}{2}\frac{d}{dx}(u_{2}^{2})

\displaystyle+\int_{0}^{1}\alpha u_{2}^{2}dx

\displaystyle=

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})-\frac{1}{2}\int_{0}^{1}u_{1}^{2}d(b_{1}(x))+\int_{0}^{1}\alpha u_{1}^{2}dx-\frac{1}{2}\int_{0}^{1}u_{2}^{2}d(b_{2}(x))

\displaystyle+\int_{0}^{1}\alpha u_{2}^{2}dx

\displaystyle=

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\int_{0}^{1}(\alpha-\frac{1}{2}b_{1}^{\prime}(x))u_{1}^{2}dx+\int_{0}^{1}(\alpha-\frac{1}{2}b_{2}^{\prime}(x))u_{2}^{2}dx

\displaystyle\geq

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\min\{\sigma_{1},\sigma_{2}\}[\int_{0}^{1}u_{1}^{2}dx+\int_{0}^{1}u_{1}^{2}dx]

\displaystyle\varepsilon(|u_{1}|_{1}^{2}+|u_{2}|_{1}^{2})+\sigma(\|u_{1}\|_{0}^{2}+\|u_{2}\|_{0}^{2})

Therefore we have

is coercive with respect to
|||.|||.

\displaystyle=

\displaystyle[\varepsilon(|u_{1h}|_{1}^{2}+|u_{2h}|_{1}^{2})+\sigma(\|u_{1h}\|_{0}^{2}+\|u_{2h}\|_{0}^{2})+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}b_{1}^{2}(x_{i})(u_{1h}^{\prime}(x))^{2}dx

Lemma 2.2

If
\quad\delta_{1,i}=\delta_{2,i}=0\,\,\quad

\quad B_{h}(\bar{u}_{h},\bar{u}_{h})\geq|||\bar{u}_{h}|||_{V_{h}}^{2}

satisfies the coercive property with respect to
|||.|||_{V_{h}}.

Proof.

Let
\bar{u}_{h}=(u_{1h},u_{2h})\in V_{h}^{2}.
If

\displaystyle B_{h}(\bar{u}_{h},\bar{u}_{h})

\displaystyle=

\displaystyle\varepsilon(u_{1h}^{\prime},u_{1h}^{\prime})+(b_{1}u_{1h}^{\prime},u_{1h})+(a_{11}u_{1h}+a_{12}u_{2h},u_{1h})+\varepsilon(u_{2h}^{\prime},u_{2h}^{\prime})+(b_{2}u_{2h}^{\prime},u_{2h})

\displaystyle B_{h}(\bar{u}_{h},\bar{u}_{h})

\displaystyle\geq

\displaystyle\varepsilon(|u_{1h}|_{1}^{2}+|u_{2h}|_{1}^{2})+\sigma(\|u_{1h}\|_{0}^{2}+\|u_{2h}\|_{0}^{2})

Then the corresponding difference scheme is

\begin{split}L^{N}\bar{U}_{i}&:=\begin{cases}-\varepsilon[(\frac{U_{1,i+1}-U_{1,i}}{h_{i+1}}-\frac{U_{1,i}-U_{1,i-1}}{h_{i}})+(\frac{U_{2,i+1}-U_{2,i}}{h_{i+1}}-\frac{U_{2,i}-U_{2,i-1}}{h_{i}})]\\
+\alpha_{1,i}(\frac{U_{1,i+1}-U_{1,i}}{h_{i+1}})+\alpha_{2,i}(\frac{U_{2,i+1}-U_{2,i}}{h_{i+1}})\\
+\beta_{1,i}(\frac{U_{1,i}-U_{1,i-1}}{h_{i}})+\beta_{2,i}(\frac{U_{2,i}-U_{2,i-1}}{h_{i}})\\
+\gamma_{1,i}U_{1,i}+\gamma_{2,i}U_{2,i}=f_{h}(\bar{\phi}_{i}),\end{cases}\\
&U_{1,0}=U_{1,N}=U_{2,0}=U_{2,N}=0,\end{split}

(2.5)

where
\bar{U}_{i}=(U_{1,i},U_{2,i}),\,

U_{1,i}=U_{1}(x_{i}),\,U_{2,i}=U_{2}(x_{i}),\,\bar{\phi}_{i}=(\phi_{i},\phi_{i}),\quad i=1,2,...,N-1
and

\displaystyle\alpha_{1,i}

\displaystyle=h_{i+1}\int_{x_{i}}^{x_{i+1}}(b_{1}\phi_{i+1}^{\prime}\phi_{i}+\delta_{1,i+1}b_{1}^{2}\phi_{i+1}^{\prime}\phi_{i}^{\prime}+\delta_{1,i+1}b_{1}a_{11}\phi_{i+1}\phi_{i}^{\prime}+\delta_{2,i+1}b_{2}a_{21}\phi_{i+1}\phi_{i}^{\prime})dx

\displaystyle\beta_{1,i}

\displaystyle=-h_{i}\int_{x_{i-1}}^{x_{i}}(b_{1}\phi_{i-1}^{\prime}\phi_{i}+\delta_{1,i}b_{1}^{2}\phi_{i-1}^{\prime}\phi_{i}^{\prime}+\delta_{1,i}b_{1}a_{11}\phi_{i-1}\phi_{i}^{\prime}+\delta_{2,i}b_{2}a_{21}\phi_{i-1}\phi_{i}^{\prime})dx

\displaystyle\gamma_{1,i}

\displaystyle=\bar{h}_{i}(\widehat{a_{11}}+\widehat{a_{21}})(x_{i})+\int_{x_{i-1}}^{x_{i}}(\delta_{1,i}b_{1}a_{11}+\delta_{2,i}b_{2}a_{21})\phi_{i}^{\prime}dx+\int_{x_{i}}^{x_{i+1}}(\delta_{1,i+1}b_{1}a_{11}+\delta_{2,i+1}b_{2}a_{21})\phi_{i}^{\prime}dx

\displaystyle\alpha_{2,i}

\displaystyle=h_{i+1}\int_{x_{i}}^{x_{i+1}}(b_{2}\phi_{i+1}^{\prime}\phi_{i}+\delta_{2,i+1}b_{2}^{2}\phi_{i+1}^{\prime}\phi_{i}^{\prime}+\delta_{1,i+1}b_{1}a_{12}\phi_{i+1}\phi_{i}^{\prime}+\delta_{2,i+1}b_{2}a_{22}\phi_{i+1}\phi_{i}^{\prime})dx

\displaystyle\beta_{2,i}

\displaystyle=-h_{i}\int_{x_{i}}^{x_{i+1}}(b_{2}\phi_{i-1}^{\prime}\phi_{i}+\delta_{2,i}b_{2}^{2}\phi_{i-1}^{\prime}\phi_{i}^{\prime}+\delta_{1,i}b_{1}a_{12}\phi_{i-1}\phi_{i}^{\prime}+\delta_{2,i}b_{2}a_{22}\phi_{i-1}\phi_{i}^{\prime})dx

\displaystyle\gamma_{2,i}

\displaystyle=\bar{h}_{i}(\widehat{a_{12}}+\widehat{a_{22}})(x_{i})+\int_{x_{i-1}}^{x_{i}}(\delta_{1,i}b_{1}a_{12}+\delta_{2,i}b_{2}a_{22})\phi_{i}^{\prime}dx+\int_{x_{i}}^{x_{i+1}}(\delta_{1,i+1}b_{1}a_{12}+\delta_{2,i+1}b_{2}a_{22})\phi_{i}^{\prime}dx.

Remark 2.4
.

If the local mesh step is small enough, then it is possible to choose
\delta_{k,i}=0,k=1,2.
In other case, we shall choose
\delta_{k,i}
from the condition,

of the difference scheme (

\displaystyle\delta_{1,i}=\begin{cases}0,\quad\quad\quad\quad\quad\quad\quad h_{i}\leq\frac{2\varepsilon}{\parallel b_{1}\parallel_{\infty}},\\
\frac{b_{1}h_{i}(2b_{2}^{2}+h_{i}b_{2}a_{22})-h_{i}^{2}b_{2}^{2}a_{21}}{(2b_{1}^{2}+h_{i}b_{1}a_{11})(2b_{2}^{2}+h_{i}b_{2}a_{22})-h_{i}^{2}b_{1}b_{2}a_{12}a_{21}},h_{i}>\frac{2\varepsilon}{\parallel b_{1}\parallel_{\infty}}\end{cases}

and also

\displaystyle\delta_{2,i}=\begin{cases}0,\quad\quad\quad\quad\quad\quad\quad h_{i}\leq\frac{2\varepsilon}{\parallel b_{2}\parallel_{\infty}},\\
\frac{b_{2}h_{i}(2b_{1}^{2}+h_{i}b_{1}a_{11})-h_{i}^{2}b_{1}^{2}a_{12}}{(2b_{1}^{2}+h_{i}b_{1}a_{11})(2b_{2}^{2}+h_{i}b_{2}a_{22})-h_{i}^{2}b_{1}b_{2}a_{12}a_{21}},h_{i}>\frac{2\varepsilon}{\parallel b_{2}\parallel_{\infty}}.\end{cases}

We derive the following estimates of
\delta_{1,i}
and
\delta_{2,i}

\displaystyle\delta_{k,i}\leq\begin{cases}CN^{-1}\quad\text{for}\quad i=1,...,N/4\quad\text{and}\quad i=(N/2)+1,...,3N/4,\\
0\quad\quad\quad\text{for}\quad i=(N/4)+1,...,N/2\quad\text{and}\quad i=(3N/4)+1,...,N-1,\end{cases}

where
k=1,2.

The above system contains
N-1

unknowns. To solve the system we split it into two algebraic systems as follows:

For

\displaystyle P_{1}^{N}U_{1,i}^{*}:=\begin{cases}-\varepsilon(\frac{U_{1,i+1}^{*}-U_{1,i}^{*}}{h_{i+1}}-\frac{U_{1,i}^{*}-U_{1,i-1}^{*}}{h_{i}})+\alpha_{1,i}(\frac{U_{1,i+1}^{*}-U_{1,i}^{*}}{h_{i+1}})+\beta_{1,i}(\frac{U_{1,i}^{*}-U_{1,i-1}^{*}}{h_{i}})\\
+\gamma_{1,i}U_{1,i}^{*}=\int_{x_{i-1}}^{x_{i+1}}f_{1}\phi_{i}+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}f_{1}b_{1}\phi_{i}^{\prime},\quad U_{1,0}^{*}=U_{1,N}^{*}=0,\end{cases}

(2.6)

\displaystyle P_{2}^{N}U_{2,i}^{*}:=\begin{cases}-\varepsilon(\frac{U_{2,i+1}^{*}-U_{2,i}^{*}}{h_{i+1}}-\frac{U_{2,i}^{*}-U_{2,i-1}^{*}}{h_{i}})+\alpha_{2,i}(\frac{U_{2,i+1}^{*}-U_{2,i}^{*}}{h_{i+1}})+\beta_{2,i}(\frac{U_{2,i}^{*}-U_{2,i-1}^{*}}{h_{i}})\\

(2.7)

3.
Error analysis

The convergence analysis of the numerical scheme starts at the triangle inequality

|||\bar{u}-\bar{u}_{h}|||_{V_{h}}\leq|||\bar{u}-\bar{u}^{I}|||_{V_{h}}+|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}},

(3.1)

where
\bar{u}^{I}
denotes the piecewise linear interpolant to
\bar{u}
on
\Omega
.

Now we estimate the second term of equation (
3.1
).

Lemma 3.1
.

The following estimate holds true

|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}\leq C\|\bar{u}^{I}-\bar{u}\|_{0}.

Proof.

Because of the Galerkin orthogonality relation between
\bar{u}
and
\bar{u}_{h}
,
we have

B_{h}(\bar{u}_{h}-\bar{u},\bar{u}^{I}-\bar{u}_{h})=0.

Then from the coercive property (
2.2
) of
B_{h}(.,.),
we have

\displaystyle|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}^{2}

\displaystyle\leq

\displaystyle 2B_{h}(\bar{u}^{I}-\bar{u}_{h},\bar{u}^{I}-\bar{u}_{h})

\displaystyle=

\displaystyle 2B_{h}(\bar{u}^{I}-\bar{u},\bar{u}^{I}-\bar{u}_{h})

\displaystyle=

\displaystyle 2[(b_{1}(u_{1}^{I}-u_{1})^{\prime},u_{1}^{I}-u_{1h})+(a_{11}(u_{1}^{I}-u_{1}),u_{1}^{I}-u_{1h})+(a_{12}(u_{2}^{I}-u_{2}),u_{1}^{I}-u_{1h})

\displaystyle+(b_{2}(u_{2}^{I}-u_{2})^{\prime},u_{2}^{I}-u_{2h})+(a_{21}(u_{1}^{I}-u_{1}),u_{2}^{I}-u_{2h})+(a_{22}(u_{2}^{I}-u_{2}),u_{2}^{I}-u_{2h})

\displaystyle+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}(-\varepsilon(u_{1}^{I}-u_{1})^{\prime\prime}+b_{1}(u_{1}^{I}-u_{1})^{\prime}+a_{11}(u_{1}^{I}-u_{1})

\displaystyle+a_{12}(x)(u_{2}^{I}-u_{2}))b_{1}(u_{1}^{I}-u_{1h})^{\prime}dx

\displaystyle+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{2,i}(-\varepsilon(u_{2}^{I}-u_{2})^{\prime\prime}+b_{2}(u_{2}^{I}-u_{2})^{\prime}+a_{21}(u_{1}^{I}-u_{1})

\displaystyle+a_{22}(u_{2}^{I}-u_{2}))b_{2}(u_{2}^{I}-u_{2h})^{\prime}dx].

That is,

\displaystyle|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}^{2}

\displaystyle\leq

\displaystyle C\int_{0}^{1}(u_{1}^{I}-u_{1})[(u_{1}^{I}-u_{1h})+(u_{2}^{I}-u_{2h})]+C\int_{0}^{1}(u_{2}^{I}-u_{2})[(u_{1}^{I}-u_{1h})+(u_{2}^{I}-u_{2h})]

\displaystyle\leq

\displaystyle C\int_{0}^{1}[(u_{1}^{I}-u_{1})+(u_{2}^{I}-u_{2})][(u_{1}^{I}-u_{1h})+(u_{2}^{I}-u_{2h})].

Therefore we have

\displaystyle|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}^{2}

\displaystyle\leq

\displaystyle C\|\bar{u}^{I}-\bar{u}\|_{0}\quad\|\bar{u}^{I}-\bar{u}_{h}\|_{0}

\displaystyle|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}^{2}

\displaystyle\leq

\displaystyle C\|\bar{u}^{I}-\bar{u}\|_{0}\quad|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}

\displaystyle|||\bar{u}^{I}-\bar{u}_{h}|||_{V_{h}}

\displaystyle\leq

\displaystyle C\|\bar{u}^{I}-\bar{u}\|_{0}.

∎

Error analysis on Shishkin and Bakhvalov-Shishkin meshes

For the discretization described above we shall use a mesh of the general type introduced in

, but here adapted for the layers at

Let

\sigma_{1}=\min\{\frac{d}{2},{\frac{\varepsilon}{\beta}}\tau_{0}\ln N\},\quad\sigma_{2}=\min\{\frac{1-d}{2},{\frac{\varepsilon}{\beta}}\tau_{0}\ln N\},\quad\quad\tau_{0}\geq 2.

Our mesh will be equidistant on

,
where

\Omega_{S}=(0,d-\sigma_{1})\cup(d,1-\sigma_{2})

First we shall assume

We choose the transition points to be

x_{N/4}=d-\sigma_{1},\quad x_{N/2}=d,\quad x_{3N/4}=1-\sigma_{2}.

Because of the specific layers, here we have to use two mesh generating

\varphi_{1}

\varphi_{2}

\displaystyle\varphi_{1}(1/4)=\ln N,

\displaystyle\varphi_{1}(1/2)=0

\displaystyle\varphi_{2}(3/4)=\ln N,

\displaystyle\varphi_{2}(1)=0.

The mesh points are

x_{i}=\begin{cases}\frac{4i}{N}(d-\sigma_{1}),\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad i=0,...,N/4\\
d-\frac{\tau_{0}}{\beta}\varepsilon\varphi_{1}(t_{i}),\quad\quad\quad\quad\quad\quad\quad\quad\quad i=N/4+1,...,N/2\\
d+\frac{4}{N}(1-d-\sigma_{2})(i-N/2),\quad\quad\quad i=N/2+1,...,3N/4\\
1-\frac{\tau_{0}}{\beta}\varepsilon\varphi_{2}(t_{i}),\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad i=3N/4+1,...,N,\end{cases}

where

We define new functions
\psi_{1}
and
\psi_{2}

by

\varphi_{i}=-\ln\psi_{i},\quad i=1,2.

There are several mesh-characterizing functions

in the literature, but we shall
use only those which correspond to Shishkin mesh and
Bakhvalov-Shishkin mesh with the following properties

\displaystyle\max|\psi^{\prime}|

\displaystyle=

\displaystyle C\ln N\quad\text{for Shishkin meshes}

\displaystyle\max|\psi^{\prime}|

\displaystyle=

\displaystyle C\quad\text{for Bakhvalov-Shishkin meshes}

\bullet
Shishkin mesh

\psi_{1}(t)=e^{-2(1-2t)lnN},\quad\,\ \psi_{2}(t)=e^{-4(1-t)lnN},

\bullet

\psi_{1}(t)=1-2(1-N^{-1})(1-2t),\quad\psi_{2}(t)=1-4(1-N^{-1})(1-t).

The set of interior mesh points is denoted by

It is well known that on the layer part of the Shishkin mesh

\frac{\tau_{0}}{\beta}\varepsilon N^{-1}\max{\mid\psi_{2}^{\prime}\mid}\exp{(\frac{\beta}{\tau_{0}\varepsilon}(1-x_{i-1}))},\quad i=3N/4+1,...,N\end{cases}

and

\frac{h_{i}}{\varepsilon}\leq CN^{-1}\max{\mid\varphi^{\prime}\mid}\leq C.

Interpolation Error

Initially we consider the interpolation error in the maximum norm.

be arbitrary and

Lemma 4.1
.

For the Shishkin mesh we have

We now give a proof for the case

) will be

\displaystyle 2C\int_{x_{i-1}}^{x_{i}}(t-x_{i-1})dt

\displaystyle\leq

\displaystyle 2C\frac{h_{i}^{2}}{2}

\displaystyle|(v_{1}-v_{1}^{I})(x)|

\displaystyle|(w_{11}-w_{11}^{I})(x)|

\displaystyle\leq

To compute the last term of (

Lemma 4.3

and

therefore, by Lemma

\displaystyle\int_{0}^{1}|(u_{1}-u_{1}^{I})^{\prime}(x)|^{2}dx

\displaystyle\leq

\displaystyle\leq

\displaystyle CN^{-2}\ln^{2}N\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}(v_{1}^{{}^{\prime\prime}}(x)+w_{11}^{{}^{\prime\prime}}(x)+w_{21}^{{}^{\prime\prime}}(x))dx.

\displaystyle|\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}w_{11}^{{}^{\prime\prime}}(x)|

\displaystyle C\varepsilon^{-2}\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}e^{-\frac{\beta(1-x)}{\varepsilon}}dx

\displaystyle\leq

\displaystyle C\varepsilon^{-1}[\sum_{i=\frac{N}{4}+1}^{\frac{N}{2}}[e^{-\frac{\beta(1-x)}{\varepsilon}}]_{x_{i-1}}^{x_{i}}+\sum_{i=\frac{3N}{4}+1}^{N}[e^{-\frac{\beta(1-x)}{\varepsilon}}]_{x_{i-1}}^{x_{i}}]+C\varepsilon^{-1}N^{1-\tau_{0}}

\displaystyle C\varepsilon^{-1}\ln N.

\displaystyle|\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}w_{21}^{{}^{\prime\prime}}(x)|

\displaystyle\leq

\displaystyle C\varepsilon^{-1}[\sum_{i=1}^{\frac{N}{2}}\int_{x_{i-1}}^{x_{i}}e^{-\frac{\beta(d-x)}{\varepsilon}}dx+\sum_{i=\frac{N}{2}+1}^{N}\int_{x_{i-1}}^{x_{i}}e^{-\frac{\beta(1-x)}{\varepsilon}}dx]

\displaystyle CN^{1-\tau_{0}}

We have

\displaystyle|||\bar{u}-\bar{u}^{I}|||_{V_{h}}

\displaystyle=[\varepsilon(|u_{1}-u_{1}^{I}|_{1}^{2}+|u_{2}-u_{2}^{I}|_{1}^{2})+\sigma(\|u_{1}-u_{1}^{I}\|_{0}^{2}+\|u_{2}-u_{2}^{I}\|_{0}^{2})

\displaystyle+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}b_{1}^{2}(x_{i})((u_{1}-u_{1}^{I})^{\prime}(x))^{2}dx

\displaystyle+\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{2,i}b_{2}^{2}(x_{i})((u_{2}-u_{2}^{I})^{\prime}(x))^{2}dx]^{1/2}.

Now we have to estimate the following terms

\displaystyle|\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}b_{1}^{2}(x_{i})((u_{1}-u_{1}^{I})^{\prime}(x))^{2}dx|

\displaystyle\leq C\mid\delta_{1,i}\mid\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\mid(u_{1}-u_{1}^{I})^{\prime}(x)^{2}\mid dx

\displaystyle\leq CN^{-1}(\varepsilon^{-1}N^{-2}\ln^{3}N)

\displaystyle|\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{1,i}b_{1}^{2}(x_{i})((u_{1}-u_{1}^{I})^{\prime}(x))^{2}dx|

\displaystyle\leq CN^{-2}\ln^{3}N

and also

\displaystyle|\sum_{i=1}^{N}\int_{x_{i-1}}^{x_{i}}\delta_{2,i}b_{2}^{2}(x_{i})((u_{2}-u_{2}^{I})^{\prime}(x))^{2}dx|\leq CN^{-2}\ln^{3}N.

Substituting these estimates, we have

\displaystyle|||\bar{u}-\bar{u}^{I}|||_{V_{h}}

\displaystyle\leq[\varepsilon(C\varepsilon^{-1}N^{-2}\ln^{3}N)+\sigma(CN^{-5/2}\ln^{5/2}N)^{2}+CN^{-3}\ln^{4}N+CN^{-2}\ln^{3}N]^{1/2}

\displaystyle\leq[\varepsilon(C\varepsilon^{-1}N^{-2}\ln^{3}N)+\sigma(CN^{-5/2}\ln^{5/2}N)^{2}+CN^{-2}\ln^{3}N]^{1/2}

\displaystyle\leq CN^{-1}\ln^{3/2}N[1+N^{-3}\ln^{2}N+1]^{1/2}

\displaystyle|||\bar{u}-\bar{u}^{I}|||_{V_{h}}

\displaystyle\leq CN^{-1}\ln^{3/2}N.

∎

5.
Error Estimate

Now we state the main theorem of this paper.

Theorem 5.1
.

Let
\bar{u}
and
\bar{u}_{h}
be solution of (
1.1
-
1.3
) and (
2.4
) respectively. Then we have

|||\bar{u}-\bar{u}_{h}|||_{V_{h}}\leq\begin{cases}CN^{-1}\ln^{3/2}N,\quad\text{for Shishkin mesh,}\\
CN^{-1},\quad\text{for Bakhvalov-Shishkin mesh}.\end{cases}

Proof.

From the inequality (
3.1
), Lemmas (
3.1
), (
4.2
) and (
4.3
), for Shishkin meshes we have

\displaystyle|||\bar{u}-\bar{u}_{h}|||_{V_{h}}

\displaystyle\leq

\displaystyle CN^{-1}\ln^{3/2}N+CN^{-\frac{5}{2}}\ln^{\frac{5}{2}}N

\displaystyle\leq

\displaystyle CN^{-1}\ln^{3/2}N.

Similarly we prove the error estimates for Bakhvalov-Shishkin meshes.
∎
