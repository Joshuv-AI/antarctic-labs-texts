merging the N N -hyperideals and J J -hyperideals in one frame
M. Anbarloei

Abstract
. The notions of N N -hyperideals and J J -hyperideals as two new classes of hyperideals were recently defined in the context of Krasner ( m , n ) (m,n) -hyperrings. These concepts are created on the basis of the intersection of all n n -ary prime hyperideals and the intersection of all maximal hyperideals, respectively. Despite being vastly different in many aspects, they share numerous similar properties. The aim of this research work is to merge them under one frame called n n -ary δ ⁡ ( 0 ) \delta(0) -hyperideals where the function δ \delta assigns to each hyperideal of a Krasner ( m , n ) (m,n) -hyperring a hyperideal of the same hyperring. We give various properties of n n -ary δ ⁡ ( 0 ) \delta(0) -hyperideals and use them to characterize certain classes of hyperrings such as hyperintegral domains and local hyperrings. Moreover, we introduce the notions of ( s , n ) (s,n) -absorbing δ ⁡ ( 0 ) \delta(0) -hypereideals and weakly ( s , n ) (s,n) -absorbing δ ⁡ ( 0 ) \delta(0) -hypereideals.
