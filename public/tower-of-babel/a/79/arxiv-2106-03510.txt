Cooling down stochastic differential equations: almost sure convergence
Steffen Dereich, Sebastian Kassing

Abstract
. We consider almost sure convergence of the SDE d ​ X t = α t ​ d ​ t + β t ​ d ​ W t dX_{t}=\alpha_{t}\,dt+\beta_{t}\,dW_{t} under the existence of a C 2 C^{2} -Lyapunov function F : ℝ d → ℝ F:{\mathbb{R}}^{d}\to{\mathbb{R}} . More explicitly, we show that on the event that the process stays local we have almost sure convergence in the Lyapunov function ( F ⁡ ( X t ) ) t ≥ 0 (F(X_{t}))_{t\geq 0} as well as ∇ F ​ ( X t ) → 0 \nabla F(X_{t})\to 0 , if | β t | = 𝒪 ⁡ ( t − β ) |\beta_{t}|=\mathcal{O}(t^{-\beta}) for a β > 1 / 2 \beta>1/2 . In this article, we analyse convergence of

\displaystyle\quad\int_{0}^{\infty}|\beta_{s}|_{F}^{2}\,ds<\infty\,\text{ and}\ \limsup\limits_{t\to\infty}|\beta_{t}|<\infty\Bigr\},

However, the current framework allows more flexibility in the drift term. We will restrict attention to certain events: set

\mathbb{B}:=\Biggl\{\liminf_{t\to\infty}F(X_{t})>-\infty,\,\limsup_{t\to\infty}|\alpha_{t}|<\infty\text{ and }\limsup_{\varepsilon\to 0}\limsup_{\begin{subarray}{c}t\to\infty\\

On

Remark 1.2

Note that as

Remark 1.3
.

A standard approach for proving convergence statements similar to those given in Theorem
1.1

[

]

In the case where the set of critical points of

\displaystyle\dot{x}_{t}=-\nabla F(x_{t})

[

Łoj65

]
or
[

In this article, we device a probabilistic counterpart to the classical analytic approach. We will derive moment estimates of

for Łojasiewicz-functions

on

We call the function

\sup\limits_{t\geq t_{k}}|\tilde{M}_{t}(\omega)-\tilde{M}_{t_{k}}(\omega)|<\varepsilon/2.

For
k\in{\mathbb{N}}
and

one has

\displaystyle|X_{t}(\omega)-X_{t_{k}}(\omega)|

\displaystyle\leq\int_{t_{k}}^{t}|\alpha_{s}(\omega)|\,ds+|\tilde{M}_{t}(\omega)-\tilde{M}_{t_{k}}(\omega)|

\displaystyle\leq C_{1}(t-t_{k})+\varepsilon/2\leq\varepsilon

Moreover, since
\varepsilon<C_{2}
we conclude for

and

that

\displaystyle|f(y)-f(x)|\leq|H(\xi)|\,|y-x|\leq C_{1}|y-x|,

Hence,

This entails that
\int_{t_{0}}^{\infty}|f(X_{t})|^{2}\,dt=\infty
and, hence,

-B_{t}(\omega)=\int_{t_{0}}^{t}\langle f(X_{s}(\omega)),-\alpha_{s}(\omega)\rangle\,ds\geq C_{2}\int_{t_{0}}^{t}|f(X_{s}(\omega)|^{2}\,ds\to\infty.

This contradicts that
(B_{t}(\omega))_{t\geq t_{0}}
converges to a finite value, by choice of
\omega
.

It remains to prove almost sure convergence of
(X_{t})_{t\geq 0}
on
{\mathbb{C}}_{3}
in the case where the set
\mathcal{C}:=\{x\in{\mathbb{R}}^{d}:f(x)=0\}
is at most countable.
Take

for which

and set

. We show by contradiction that
(X_{t}(\omega))_{t\geq 0}
converges. Suppose that
(X_{t}(\omega))_{t\geq 0}
would not converge. Then there would exist a coordinate

and reals

such that the set of accumulation points

\mathcal{K}:=\bigcap_{n\in{\mathbb{N}}}\bigl\{X^{(i)}_{t}(\omega):t\geq n,X_{t}(\omega)\in\overline{B(0,r+1)}\bigr\}

is a compact set containing

. By applying the principle of nested intervals we can produce for every

of

with

so that

∎

Proof of Theorem

The proof of Theorem

3.2.
Bounding the drift term in the case where no dropout occurs

Proposition 3.3
.

Suppose that
T
is such that on
\{T\geq t\}
,
\langle f(X_{t}),-\alpha_{t}\rangle\geq 0
and
(F(X_{t}))_{t\geq 0}
converges on
\{T=\infty\}
, almost surely. Let
\Phi:[0,\infty)\to[0,\infty)
be a decreasing, continuously differentiable function so that
t\mapsto-\dot{\Phi}_{t}
is decreasing and

\lim_{t\to\infty}\frac{\Phi_{t}}{\sqrt{-\dot{\Phi}_{t}}}=0.

If for every
t\geq 0
,

{\mathbb{E}}[1\hskip-2.78857pt\mathrm{l}_{\{T>t\}}(F(X_{t})-F(X_{T}))]+\frac{1}{2}{\mathbb{E}}\Bigl[\int_{t}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{s\leq T\}}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\,ds\Bigr]\leq\Phi_{t}

and
(M_{t})_{t\geq 0}
given by

M_{t}:=\int_{0}^{t\wedge T}\langle f(X_{s}),\beta_{s}\,dW_{s}\rangle

is a regular martingale, then

{\mathbb{E}}\Bigl[\int_{0}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\sqrt{\langle f(X_{s}),-\alpha_{s}\rangle}\,ds\Bigr]\leq\int_{0}^{\infty}\sqrt{-\dot{\Phi}_{s}}\,ds.

Proof.

Since
(M_{t})_{t\geq 0}
is a regular martingale we get with Itô’s formula, see (
9
), that

\displaystyle\Psi(t):=

\displaystyle\ {\mathbb{E}}\Bigl[\int_{t}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\langle f(X_{s}),-\alpha_{s}\rangle\,ds\Bigr]

\displaystyle=

\displaystyle\ {\mathbb{E}}\bigl[1\hskip-2.78857pt\mathrm{l}_{\{T>t\}}(F(X_{t})-F(X_{T}))\bigr]+\frac{1}{2}{\mathbb{E}}\Bigl[\int_{t}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{T>s\}}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\,ds\Bigr]\leq\Phi_{t}.

The function
\Psi
is right-continuous and monotonically decreasing and, hence, càdlàg.
We let
\varphi_{s}:=(-\dot{\Phi}_{s})^{-1/2}
and note that by Cauchy-Schwarz

\displaystyle{\mathbb{E}}\Bigl[\int_{0}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\sqrt{\langle f(X_{s}),-\alpha_{s}\rangle}\,ds\Bigr]\leq\Bigl(\int_{0}^{\infty}\varphi_{s}{\mathbb{E}}\bigl[1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\langle f(X_{s}),-\alpha_{s}\rangle\bigr]\,ds\Bigr)^{1/2}\Bigl(\int_{0}^{\infty}\varphi_{s}^{-1}\,ds\Bigr)^{1/2}.

Moreover, using partial integration we get that

\displaystyle\int_{0}^{\infty}\varphi_{s}{\mathbb{E}}\bigl[1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\langle f(X_{s}),-\alpha_{s}\rangle\bigr]\,ds

\displaystyle=-\int_{0}^{\infty}\varphi_{s}\,d\Psi_{s}

\displaystyle={-}[\varphi\Psi]_{0}^{\infty}+\int_{0}^{\infty}\Psi_{s}\,d\varphi_{s}.

(\varphi_{s})_{s\geq 0}
is increasing by assumption and
\varphi_{s}\Phi_{s}\to 0
as

so that

\displaystyle{-}[\varphi\Psi]_{0}^{\infty}+\int_{0}^{\infty}\Psi_{s}\,d\varphi_{s}

\displaystyle\leq{-}\varphi_{0}(\Phi_{0}-\Psi_{0}){-}[\varphi\Phi]_{0}^{\infty}+\int_{0}^{\infty}\Phi_{s}\,d\varphi_{s}

\displaystyle={-}\varphi_{0}(\Phi_{0}-\Psi_{0})+\int_{0}^{\infty}\underbrace{\varphi_{s}(-\dot{\Phi}_{s})}_{=\sqrt{-\dot{\Phi}_{s}}}\,ds.

Altogether we get that

{\mathbb{E}}\Bigl[\int_{0}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{s<T\}}\sqrt{\langle f(X_{s}),-\alpha_{s}\rangle}\,ds\Bigr]\leq\int_{0}^{\infty}\sqrt{-\dot{\Phi}_{s}}\,ds.

∎

3.3.
Technical analysis of lower dropouts

Roughly speaking, the following two lemmas will later be used to show that for a certain critical level of the target function, a lower dropout (in the sense of the previous two propositions) entails that the Lyapunov function converges to a value strictly below the respective critical level with high probability.

Lemma 3.4
.

Let
(M_{t})_{t\geq 0}
be a continuous local martingale started in zero. Then for every
\kappa>0

{\mathbb{P}}\Bigl(\sup_{t\geq 0}(M_{t}-\langle M\rangle_{t})\geq\kappa\Bigr)\leq\frac{1}{\kappa^{2}}+\sum_{n\in{\mathbb{N}}_{0}}\frac{2^{n+1}}{(2^{n}+\kappa)^{2}}=:\phi(\kappa).

In particular, for every
\varepsilon>0
there exists a
\kappa>0
such that the above right-hand side is smaller than
\varepsilon
.

Proof.

For
n\in{\mathbb{N}}_{0}
, let
T_{n}:=\inf\{t\geq 0:\langle M\rangle_{t}>2^{n}\}
. Then we have

\displaystyle\sup_{t\in[T_{n},T_{n+1})}(M_{t}-\langle M\rangle_{t})\leq\sup_{t\in[0,T_{n+1})}M_{t}-2^{n}

and

\sup_{t\in[0,T_{0})}(M_{t}-\langle M\rangle_{t})\leq\sup_{t\in[0,T_{0})}M_{t}.

We use Doob’s
L^{2}
-inequality to deduce that

{\mathbb{P}}\Bigl(\sup_{t\in[0,T_{n+1})}M_{t}\geq 2^{n}+\kappa\Bigr)\leq(2^{n}+\kappa)^{-2}{\mathbb{E}}[M_{T_{n+1}}^{2}]\leq\frac{2^{n+1}}{(2^{n}+\kappa)^{2}}

and

{\mathbb{P}}\Bigl(\sup_{t\in[0,T_{0})}M_{t}\geq\kappa\Bigr)\leq\frac{1}{\kappa^{2}}.

Therefore,

{\mathbb{P}}\Bigl(\sup_{t\geq 0}(M_{t}-\langle M\rangle_{t})\geq\kappa\Bigr)\leq\frac{1}{\kappa^{2}}+\sum_{n\in{\mathbb{N}}_{0}}\frac{2^{n+1}}{(2^{n}+\kappa)^{2}}.

∎

Lemma 3.5
.

Let
t_{0}\geq 0
,
\rho,\kappa:[t_{0},\infty)\to(0,\infty)
be functions and
t_{0}\leq T^{\prime}\leq T
be two stopping times such that, for every
t\geq t_{0}
, on
\{T^{\prime}\leq t\leq T\}
,

|\beta_{t}^{\dagger}f(X_{t})|^{2}\leq\rho_{T^{\prime}}\langle f(X_{t}),-\alpha_{t}\rangle\text{ \ and \ }\frac{1}{2}\int_{T^{\prime}}^{t}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\,ds\leq\kappa_{T^{\prime}}.

Then,

\displaystyle{\mathbb{P}}\Bigl(\sup_{t\in[T^{\prime},T]}

\displaystyle F(X_{t})-F(X_{T^{\prime}})\geq 2\kappa_{T^{\prime}}\Bigr)\leq\phi\Bigl(\inf\limits_{t\geq t_{0}}\frac{\kappa_{t}}{\rho_{t}}\Bigr).

Proof.

We use again representation (
5
):

\displaystyle dF(X_{t})

\displaystyle=\langle f(X_{t}),\alpha_{t}\rangle\,dt+\langle f(X_{t}),\beta_{t}\,dW_{t}\rangle+\frac{1}{2}\mathrm{tr}(\beta_{t}^{\dagger}H(X_{t})\beta_{t})\,dt.

Consider the local martingale

(M_{t})_{t\geq t_{0}}:=\Bigl(\int_{0}^{t}1\hskip-2.78857pt\mathrm{l}_{\{T^{\prime}\leq s\leq T\}}\langle f(X_{s}),\beta_{s}\,dW_{s}\rangle\Bigr)_{t\geq t_{0}}

and note that

\langle M\rangle_{t}=\int_{0}^{t}1\hskip-2.78857pt\mathrm{l}_{\{T^{\prime}\leq s\leq T\}}|\beta_{s}^{\dagger}f(X_{s})|^{2}\,ds\leq\rho_{T^{\prime}}\int_{0}^{t}1\hskip-2.78857pt\mathrm{l}_{\{T^{\prime}\leq s\leq T\}}\langle f(X_{s}),-\alpha_{s}\rangle\,ds.

Hence,

\displaystyle\int_{0}^{t}1\hskip-2.78857pt\mathrm{l}_{\{T^{\prime}\leq s\leq T\}}\langle f(X_{s}),\alpha_{s}\rangle\,ds

\displaystyle+\int_{0}^{t}1\hskip-2.78857pt\mathrm{l}_{\{T^{\prime}\leq s\leq T\}}\langle f(X_{s}),\beta_{s}\,dW_{s}\rangle

\displaystyle\leq M_{t}-\frac{1}{\rho_{T^{\prime}}}\langle M\rangle_{t}=:\Xi_{t}.

Note that
\Xi_{t}=\rho_{T^{\prime}}(\frac{1}{\rho_{T^{\prime}}}M_{t}-\langle\frac{1}{\rho_{T^{\prime}}}M\rangle_{t})
with
(\frac{1}{\rho_{T^{\prime}}}M_{t})_{t\geq t_{0}}
being a continuous local martingale started in zero so that with Lemma
3.4

\displaystyle{\mathbb{P}}\Bigl(\sup_{t\geq t_{0}}\Xi_{t}\geq\kappa_{T^{\prime}}\Bigr)

\displaystyle={\mathbb{P}}\Bigl(\sup_{t\geq t_{0}}\frac{1}{\rho_{T^{\prime}}}M_{t}-\langle\frac{1}{\rho_{T^{\prime}}}M\rangle_{t}\geq\frac{\kappa_{T^{\prime}}}{\rho_{T^{\prime}}}\Bigr)

\displaystyle\leq{\mathbb{P}}\Bigl(\sup_{t\geq t_{0}}\frac{1}{\rho_{T^{\prime}}}M_{t}-\langle\frac{1}{\rho_{T^{\prime}}}M\rangle_{t}\geq\inf\limits_{t\geq t_{0}}\frac{\kappa_{t}}{\rho_{t}}\Bigr)\leq\phi\Bigl(\inf\limits_{t\geq t_{0}}\frac{\kappa_{t}}{\rho_{t}}\Bigr).

Altogether, using

\displaystyle\sup_{T^{\prime}\leq t\leq T}F(X_{t})-F(X_{T^{\prime}})\leq\sup_{T^{\prime}\leq t\leq T}\Xi_{t}+\underbrace{\sup_{T^{\prime}\leq t\leq T}\frac{1}{2}\int_{T^{\prime}}^{t}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\,ds}_{\leq\kappa_{T^{\prime}}}

we get that

\displaystyle{\mathbb{P}}\Bigl(\sup_{T^{\prime}\leq t\leq T}F(X_{t})-F(X_{T^{\prime}})\geq 2\kappa_{T^{\prime}}\Bigr)

\displaystyle\leq{\mathbb{P}}\Bigl(\sup_{t\geq t_{0}}\Xi_{t}\geq\kappa_{T^{\prime}}\Bigr)\leq\phi\Bigl(\inf\limits_{t\geq t_{0}}\frac{\kappa_{t}}{\rho_{t}}\Bigr).

∎

3.4.
Proof of Theorem
1.6

\displaystyle\leq\int_{0}^{\ell}e^{-4u}g_{u}\,du\leq\int_{0}^{\ell}\frac{1}{(u+1)^{2}}\,du\leq 1.

Hence, as a consequence of the Chebyshev inequality one gets that

\int_{t}^{\infty}e^{-2s}|\bar{B}_{s}|\,ds=\lim_{u\to\infty}\int_{t}^{u}e^{-2s}|\bar{B}_{s}|\,ds=\infty,\quad\text{almost surely.}

∎

Proof of Theorem
4.1
.

(i): We first verify that
F
is a Łojasiewicz-function.
We need to analyse the critical points only. One has

\text{Hess}\,F(0)=\begin{pmatrix}-6&0\\
0&-6\end{pmatrix}

so that the Hessian has full rank at
0
which implies validity of a Łojasiewicz-inequality with
\theta=\frac{1}{2}
on an appropriate neighbourhood of
0
. Next, let
x\in{\mathbb{R}}^{2}
with
|x|=1
. Since
\psi^{\prime\prime}(1)=2
,
\psi
satisfies a Łojasiewicz-inequality

|\psi^{\prime}(r)|\geq\L|\psi(r)-\psi(1)|^{\frac{1}{2}}

for all
r\in[1-\varepsilon,1+\varepsilon)
and appropriately fixed
\varepsilon\in(0,\frac{1}{2}]
and
\L>0
. Consequently, for
y\in B(0,1+\varepsilon)\backslash B(0,1-\varepsilon)
one has

|f(y)|=|\psi^{\prime}(|y|)|\geq\L\,|\psi(|y|)-\psi(1)|^{1/2}=\L\,|F(y)-F(x)|^{1/2}.

(ii): has been shown in Prop.
4.2
.

(iii): We conceive
(X_{t})_{t\geq 0}
as complex-valued process by letting

Y_{t}:=X^{(1)}_{t}+iX^{(2)}_{t}

and note that (since
(Y_{t})_{t\geq 0}
does not hit
0
) there is a continuous adapted process
(\Phi_{s})_{s\geq 0}
satisfying

Y_{s}=|X_{s}|e^{i\Phi_{s}}.

Now on
[t,T_{t}]

\displaystyle d\Phi_{s}=||X_{s}|-1|\,ds+\frac{1}{|X_{s}|^{2}}\frac{1}{s+1}\langle\mathrm{ort}(X_{s}),dW_{s}\rangle

so that

d\langle\Psi\rangle_{s}=\frac{1}{|X_{s}|^{2}}\frac{1}{(s+1)^{2}}\,ds.

We thus get that

\int_{t}^{T_{t}}d\langle\Psi\rangle_{s}=\int_{t}^{T_{t}}\frac{1}{|X_{s}|^{2}}\frac{1}{(s+1)^{2}}\,ds\leq\mbox{$\frac{9}{4}$}\int_{t}^{\infty}\frac{1}{(s+1)^{2}}\,ds<\infty

so that
\int_{t}^{T_{t}\wedge s}\frac{1}{|X_{u}|^{2}}\frac{1}{u+1}\langle\mathrm{ort}(X_{u}),dW_{u}\rangle
converges almost surely as
s\to\infty
, say to
\bar{\Psi}^{(t)}
. Consequently, on
\{T_{t}=\infty\}
one has as
s\to\infty

\Phi_{s}=\int_{t}^{s}||X_{u}|-1|\,du+\bar{\Phi}^{(t)}+o(1),

where
o(1)
stands for a term converging to zero as
s\to\infty
. By Proposition
4.2
(iii) and Lemma
4.3
,
\int_{t}^{s}||X_{u}|-1|\,du\to\infty
as
s\to\infty
which shows that
(X_{t})_{t\geq 0}
does not converge on
\{T_{t}=\infty\}
. The result follows by noticing that
\bigcup_{t\in{\mathbb{N}}}\{T_{t}=\infty\}
is an almost sure set by Proposition
4.2
(i).
∎

Appendix A
Criterion for staying local

Assume that
F
satisfies
\lim_{|x|\to\infty}F(x)=\infty
and consider the set

{\mathbb{L}}_{1}:=\Bigl\{\sup\limits_{t\geq 0}\int_{0}^{t}\bigl(\langle f(X_{s}),\alpha_{s}\rangle+\frac{1}{2}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\bigr)\,ds<\infty\Bigr\}.

We will show that
\limsup_{t\to\infty}|X_{t}|<\infty
, almost surely, on
{\mathbb{L}}_{1}
. By Itô’s formula

dF(X_{t})=\langle f(X_{t}),\alpha_{t}\rangle\,dt+\langle f(X_{t}),\beta_{t}\,dW_{t}\rangle+\frac{1}{2}\mathrm{tr}(\beta_{t}^{\dagger}H(X_{t})\beta_{t})\,dt.

Now, let
n\in{\mathbb{N}}
and consider the stopping time

T_{n}:=\inf\Bigl\{t\geq 0:\int_{0}^{t}\bigl(\langle f(X_{s}),\alpha_{s}\rangle+\frac{1}{2}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\bigr)\,ds\geq n\Bigr\}.

and
(Y_{t})_{t\geq 0}
given by

Y_{t}:=F(X_{t})-\int_{0}^{t}\bigl(\langle f(X_{s}),\alpha_{s}\rangle+\frac{1}{2}\mathrm{tr}(\beta_{s}^{\dagger}H(X_{s})\beta_{s})\bigr)\,ds.

Then,
(Y_{t}^{T_{n}})_{t\geq 0}
is a local martingale that is bounded from below and, thus, a supermartingale. With the martingale convergence theorem we get almost sure convergence of
(Y_{t}^{T_{n}})_{t\geq 0}
and, thus, on
\{T_{n}=\infty\}
we have that
\sup_{t\geq 0}F(X_{t})
is finite, almost surely. Finally, note that

{\mathbb{L}}_{1}=\bigcup\limits_{n\in{\mathbb{N}}}\{T_{n}=\infty\},

so that
\limsup_{t\to\infty}|X_{t}|<\infty
, almost surely, on
{\mathbb{L}}_{1}
. Note that for the choice
(\alpha_{t})_{t\geq 0}=(-f(X_{t}))_{t\geq 0}
we have

\Bigl\{\sup\limits_{t\geq 0}|H(X_{t})|<\infty\text{ and }\int_{0}^{\infty}|\beta_{s}|_{F}^{2}\,ds<\infty\Bigr\}\subset{\mathbb{L}}_{1}

as well as for a compact set
K\subset{\mathbb{R}}^{d}

\displaystyle\Bigl\{

\displaystyle 1\hskip-2.78857pt\mathrm{l}_{\{X_{t}\notin K\}}(-|f(X_{t})|^{2}+\frac{1}{2}\mathrm{tr}((\beta_{t})^{\dagger}H(X_{t})\beta_{t}))\leq 0\text{ for all large }t

\displaystyle\text{ and }\int_{0}^{\infty}1\hskip-2.78857pt\mathrm{l}_{\{X_{s}\in K\}}|\beta_{s}|_{F}^{2}\,ds<\infty\Bigr\}\subset{\mathbb{L}}_{1}.
