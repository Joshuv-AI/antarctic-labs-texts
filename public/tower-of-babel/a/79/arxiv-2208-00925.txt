Cluster Statistics in Expansive Combinatorial Structures
Konstantinos Panagiotou, Leon Ramzews

Abstract
We develop a simple and unified approach to investigate several aspects of the cluster statistics of random expansive (multi-)sets. In particular, we determine the limiting distribution of the size of the smallest and largest clusters, we establish all moments of the distribution of the number of clusters, and we prove a local limit theorem for that distribution. Our proofs combine effectively two simple ingredients: an application of the saddle-point method through the well-known framework of H H -admissibility, and an ingenious idea by Erdős and Lehner that utilizes the elementary inclusion/exclusion principle.

Introduction & Main Results

Sets and Multisets

In a particular setting of the models that we consider we are given a set
{\mathcal{C}}
– the so-called
clusters
or
components
– whose elements have each a specific size, that is, we are given in addition a mapping
|\cdot|:{\mathcal{C}}\to\mathbb{N}
that assigns to each cluster its size.
Then we study objects that are composed out of elements in
{\mathcal{C}}
and whose structure can be described in terms of elements in the set

\displaystyle\Omega_{n}:=\Big\{(N_{1},\dots,N_{n})\in\mathbb{N}_{0}^{n}:\sum_{1\leq k\leq n}kN_{k}=n\Big\}.

Using this notation, we say that a (compound) object
O
has cluster structure
(N_{1},\dots,N_{n})\in\Omega_{n}
, if there are
N_{k}
clusters of size
k
in
O
for
1\leq k\leq n
. Naturally, in that case we say that
O
has (total) size
n
and we write
|O|=n
.

The first broad class of models that admit such a description are
sets
or
assemblies
on the label set

[n]:=\{1,2,\dots,n\}
. This class includes the prominent examples of permutations (where the clusters are cycles), graphs that have some appropriate property (where the clusters are the connected graphs with that property) and the Maxwell-Boltzmann model
of ideal gas from statistical physics (where the clusters are particles at some energy level).
Let us write
C_{k}
for the number of objects of size
k
in
{\mathcal{C}}
,
k\in\mathbb{N}
.
Then, in this class of models the number of compound objects (that is, sets) with cluster structure
(N_{1},\dots,N_{n})\in\Omega_{n}
equals

\frac{n!}{\prod_{1\leq i\leq n}i!^{N_{i}}}\cdot\prod_{1\leq i\leq n}\frac{C_{i}^{N_{i}}}{N_{i}!}=n!\prod_{1\leq i\leq n}\frac{(C_{i}/i!)^{N_{i}}}{N_{i}!};

(1.1)

the first term is a multinomial coefficient that partitions the
n
labels to the
N_{i}
objects of size
i
, and the second term selects
a set of
N_{i}
objects from the objects of size
i
in
{\mathcal{C}}
, for all
1\leq i\leq n
. Actually, this formula can also be used if we replace
C_{i}
with an arbitrary non-negative real number (with no combinatorial interpretation); this is the case, for example, in coagulation-fragmentation processes, where (
1.1
) is related to the equilibrium state of the system.
We refer to
[
13
]
for an excellent overview and many detailed examples, and to the extensive work
[
17
]
and the excellent books
[
9
,
4
]
that treat the combinatorial settings.

From now on we assume that the
C_{k}
’s are non-negative real numbers.
If we sum up (
1.1
) over all elements in
\Omega_{n}
, we obtain the
partition function
of the model, which in the combinatorial setting is just the number of
{\mathcal{C}}
-sets of total size
n
. Then, a fundamental fact is, see
[
9
,
4
]
, that if we set
c_{k}=C_{k}/k!
, the partition function equals
n!
times the
n
-th coefficient in a power series
S
that satisfies the beautiful and simple identity

\displaystyle C(x):=\sum_{k\geq 1}c_{k}x^{k}=\sum_{k\geq 1}\frac{C_{k}}{k!}x^{k}\quad\text{and}\quad S(x):=e^{C(x)}.

(1.2)

A further important class of models are
multisets
, where we may add each cluster several times. This class includes – most prominently – partitions of an integer (where the clusters are the natural numbers) and unlabeled objects, for example graphs (where the clusters are unlabeled connected graphs) as well as the Bose-Einstein model of ideal gas. In this class of models the number of compound objects (that is, multisets) with cluster structure
(N_{1},\dots,N_{n})\in\Omega_{n}
equals

\prod_{1\leq i\leq n}\binom{C_{i}+N_{i}-1}{N_{i}},

(1.3)

where the binomial coefficient accounts for the number of ways to choose with repetition
N_{i}
elements from
{\mathcal{C}}_{i},1\leq i\leq n
. As before, (
1.3
) makes also sense if the
C_{k}
’s are arbitrary non-negative reals, which happens for example in another model of coagulation-fragmentation processes. Again
[
14
]
is a great source of examples for that matter. Moreover, summing up (
1.3
) over all elements in
\Omega_{n}
, we obtain the partition function of that model, which in the combinatorial setting equals the number of
{\mathcal{C}}
-multisets of total size
n
. Then, if we set
c_{k}=C_{k}
, the partition function equals the
n
-th coefficient of a power series
G
that satisfies the (again, beautiful) identity

\displaystyle C(x):=\sum_{k\geq 1}c_{k}x^{k},\quad\textasciiacute\text{and}\quad G(x):=\exp\left\{\sum_{j\geq 1}C(x^{j})/j\right\}.

(1.4)

If we consider structures as the ones just described, then two questions immediately pop up. First, there is the counting problem: how do the coefficients of
C
relate to the coefficients of
S
resp.
G
, in other words, how many
{\mathcal{C}}
-(multi-)sets of a given size are there? This question alone is mathematically challenging and interesting, but further it is essential to investigate a second question: what can we say about the “typical” cluster structure in a (multi-)set? More specifically, let
\mathsf{S}^{(n)}=(\mathsf{S}^{(n)}_{1},\dots,\mathsf{S}^{(n)}_{n})\in\Omega_{n}
and
\mathsf{G}^{(n)}=(\mathsf{G}^{(n)}_{1},\dots,\mathsf{G}^{(n)}_{n})\in\Omega_{n}
denote the cluster structures of an element drawn uniformly at random from all
{\mathcal{C}}
-sets and
{\mathcal{C}}
-multisets of (total) size
n
.
Denote by
[x^{n}]F(x)
the coefficient of
x^{n}
in a power series
F
.
By definition and using (
1.1
) and (
1.3
) we readily obtain

\displaystyle\mathrm{Pr}\left[\mathsf{S}^{(n)}=(N_{1},\dots,N_{n})\right]

\displaystyle=\frac{1}{[x^{n}]S(x)}\cdot\prod_{1\leq i\leq n}\frac{c_{i}^{N_{i}}}{N_{i}!}\cdot\mathbbm{1}_{(N_{1},\dots,N_{n})\in\Omega_{n}},

(1.5)

\displaystyle\mathrm{Pr}\left[\mathsf{G}^{(n)}=(N_{1},\dots,N_{n})\right]

\displaystyle=\frac{1}{[x^{n}]G(x)}\cdot\prod_{1\leq i\leq n}\binom{c_{i}+N_{i}-1}{N_{i}}\cdot\mathbbm{1}_{(N_{1},\dots,N_{n})\in\Omega_{n}}.

(1.6)

Let
\mathsf{F}^{(n)}=(\mathsf{F}^{(n)}_{1},\dots,\mathsf{F}^{(n)}_{n})
be either
\mathsf{S}^{(n)}
or
\mathsf{G}^{(n)}
.
Central objects of interest are the distribution of the
total
number of clusters

\kappa(\mathsf{F}^{(n)}):=\sum_{1\leq k\leq n}\mathsf{F}_{k}^{(n)}

and the distribution of the size of the smallest and largest clusters

\displaystyle{\mathcal{M}}(\mathsf{F}^{(n)}):=\min\left\{1\leq k\leq n:\mathsf{F}^{(n)}_{k}>0\right\}\quad\text{and}\quad\mathcal{L}(\mathsf{F}^{(n)}):=\max\left\{1\leq k\leq n:\mathsf{F}^{(n)}_{k}>0\right\}.

State of the art

Let
h:[1,\infty)\to[0,\infty)
be an eventually positive, continuous and slowly varying function, which means that

\lim_{x\to\infty}\frac{h(\lambda x)}{h(x)}=1,\quad\text{for }\lambda>0.

Then a quite common and rather general assumption in the study of (multi-)sets is that the counting sequence for
{\mathcal{C}}
fulfils

c_{n}=h(n)\cdot n^{\alpha-1}\cdot\rho^{-n},\quad\alpha\in\mathbb{R},\penalty\ 0<\rho\leq 1.

(1.7)

Under this assumption the prominent problem of determining
[x^{n}]S(x)
and
[x^{n}]G(x)
is treated in several papers. The state of the art is:
[
26
,
25
]
treat the
convergent
case
\alpha<0
,
[
1
]
the
logarithmic
case
\alpha=0
,
[
14
,
10
]
the
expansive
case
\alpha>0
and
[
15
]
a specific “quasi-expansive” class of sequences that satisfy an analytical set of conditions implying
\alpha>0
and
\rho=1
, the
Meinardus scheme of conditions
. We see that from today’s viewpoint the partition functions are pretty well understood.

Regarding the statistical properties of (multi-)sets the picture in the convergent case (
\alpha<0
) is also rather complete. It is known that the number
\kappa(\mathsf{F}^{(n)})
of components converges (without scaling) in distribution, see
[
3
]
, and the tails are determined completely in
[
22
]
. In this case, removing a – the – largest cluster from
\mathsf{F}^{(n)}
leaves an object that converges in distribution to a limit given by the Boltzmann model, cf.
[
26
,
25
,
2
]
, implying that
n-\mathcal{L}(\mathsf{F}^{(n)})
has a limiting distribution.

The expansive case, on the other side, is quite different from that. In general,
\kappa(\mathsf{F}^{(n)})
is unbounded with high probability in this case.
This is already reflected in the special case of integer partitions, which are multisets of natural numbers; the classical work by
Erdös and Lehner 1941
determines the proper normalization so that the number of parts in a random integer partition converges in distribution.
However, in the general expansive setting, the precise picture is not completely understood and rather fragmented.
More specifically, the number of
{\mathcal{C}}
-multisets of size
n
and
N
clusters, which is obviously related to
\Pr[\kappa(\mathsf{G}^{(n)})=N]
, was studied in
[
23
]
when
\rho<1
.
The distribution of
\kappa(\mathsf{G}^{(n)})
was studied in the quasi-expansive case:
[
24
]
describes parts of the distribution, and
[
20
]
finds the proper normalization leading to a central limit theorem, which is Gaussian only for parts of the parameter range. Determining the proper scaling for
\kappa(\mathsf{G}^{(n)})
in the expansive case is still an open problem.
Regarding sets, the proper normalization that yields a local and central Gaussian limit theorem for
\kappa(\mathsf{S}^{(n)})
is established in
[
7
]
in the expansive case and when
h(n)
is constant; treating general
h
has not been achieved so far.

There are also many results about the smallest and largest clusters of
\mathsf{F}^{(n)}
. Here integer partitions are also well-understood, as the representation of integer partitions into Ferres diagrams shows that the distribution of the number of clusters and of the largest clusters are identical.
In the case of multisets,
Mutafchiev 2013
establishes that after appropriate normalization
\mathcal{L}(\mathsf{G}^{(n)})
converges to an extreme value distribution in the quasi-expansive case. Regarding the expansive case we are not aware of any detailed results concerning
\mathcal{M}(\mathsf{G}^{(n)})
and
\mathcal{L}(\mathsf{G}^{(n)})
.
For the case of
{\mathcal{C}}
-sets,
[
11
]
proved that there is a threshold
n^{1/(\alpha+1)}
for
\mathcal{L}(\mathsf{S}^{(n)})
, meaning that the probability of the event
\{\mathcal{L}(\mathsf{S}^{(n)})\leq n^{\beta}\}
tends to
0
if
\beta<1/(\alpha+1)
and to
1
if
\beta>1/(\alpha+1)
. In their work also the limiting distribution of the minimal cluster size is determined. still unknown.

Our contribution

In this paper we perform a thorough study of the expansive case, that is, we make an assumption that is at least as general as (
1.7
) with
\alpha>0
– see below – and we derive a rather complete picture: we determine the limiting distribution of the size of the smallest and largest clusters, we establish all moments of the distribution of the number of clusters, and we prove a local limit theorem for that distribution for both
{\mathcal{C}}
-sets and
{\mathcal{C}}
-multisets.

On the methodological side, our findings are based on a simple, yet far-reaching observation, that somehow has escaped notice so far. The proofs in the state of the art works, for example
[
10
,
14
]
, are conducted by studying the partition functions
[x^{n}]S(x)
and
[x^{n}]G(x)
with the help of the powerful
Khinchin’s probabilistic method
, see
[
11
]
for a great overview and some historical perspective, to reduce the analytical problem to a probabilistic one; but
in heart
the authors apply the well-known saddle-point method to the Cauchy integral representing the coefficients of the series at hand.
For that they basically prove that
S(x)
and
G(x)
possess a property called
H
-admissibility
, see Section
2.1
, but without calling it that way. Now, the great advantage in realising that a series
F
is
H
-admissible is that by existing results one is able to compute/estimate
[x^{n}]F(x)
and
[x^{n-k}]F(x)/[x^{n}]F(x)
systematically for virtually
any

0<k\leq n
as
n\to\infty
.
This has powerful consequences, as the studies of the cluster statistics always rely at some point on determining such a fraction. So, knowing that
S
,
G
– and for that effect, many related series that we construct explicitly – are
H
-admissible opens us the path for obtaining incredibly detailed results. In particular, by combining our observation with the elementary methods developed in
[
6
]
in the context of integer partitions, we are able to find the proper scaling under which
\mathcal{L}(\mathsf{S}^{(n)})
,
\mathcal{L}(\mathsf{G}^{(n)})
and
\mathcal{M}(\mathsf{S}^{(n)})
,
\mathcal{M}(\mathsf{G}^{(n)})
,
converge and we identify the limit.

As we already remarked, our upcoming results all hold for arbitrary non-negative real-valued sequences

Coefficient Extraction and Counting

In our first main result we determine asymptotically the coefficients of
S,G
and a wide class of related power series in the oscillating expansive setting.

Theorem 1.1
.

For
\alpha>0
,
0<\rho\leq 1
and
0<\varepsilon<\alpha/3
let
(c_{k})_{k\in\mathbb{N}}\in{\mathcal{F}}(2\alpha/3+\varepsilon,\alpha,\rho)
. Let
z_{n}
be the solution to
z_{n}C^{\prime}(z_{n})=n
. Then, for
\ell\in\mathbb{N}_{0}
and as
n\to\infty
,

\displaystyle[x^{n}]S(x)\cdot C(x)^{\ell}\sim\frac{S(z_{n})C(z_{n})^{\ell}}{\sqrt{2\pi C^{\prime\prime}(z_{n})}}\cdot z_{n}^{-n-1}.

(1.9)

Let
\ell\in\mathbb{N}_{0},(p_{1},\dots,p_{\ell})\in\mathbb{N}_{0}^{\ell}
. If
0<\rho<1
, then as
n\to\infty
,

\displaystyle[x^{n}]G(x)\prod_{1\leq i\leq\ell}\sum\nolimits_{j\geq 1}j^{p_{i}}C(x^{j})\sim\exp\left\{\sum\nolimits_{j\geq 2}C(\rho^{j})/j\right\}\cdot\frac{S(z_{n})C(z_{n})^{\ell}}{\sqrt{2\pi C^{\prime\prime}(z_{n})}}\cdot z_{n}^{-n-1}.

(1.10)

If
\rho=1
, let
q_{n}
be the solution to
\sum_{j\geq 1}q_{n}^{j}C^{\prime}(q_{n}^{j})=n
. Then, as
n\to\infty
,

\displaystyle[x^{n}]G(x)\prod_{1\leq i\leq\ell}\sum\nolimits_{j\geq 1}j^{p_{i}}C(x^{j})\sim\frac{G(q_{n})\prod_{1\leq i\leq\ell}\sum\nolimits_{j\geq 1}j^{p_{i}}C(q_{n}^{j})}{\sqrt{2\pi\sum\nolimits_{j\geq 1}jq_{n}^{2j}C^{\prime\prime}(q_{n}^{j})}}\cdot q_{n}^{-n}.

(1.11)

The proof is in Section
3.2.1
.
A natural application of Theorem
1.1
is solving the counting problem, that is, determining the numbers
s_{n}/n!:=[x^{n}]S(x)
and
g_{n}:=[x^{n}]G(x)
of
{\mathcal{C}}
-sets and
{\mathcal{C}}
-multisets of size
n
asymptotically. That is, if
(c_{k})_{k\in\mathbb{N}}\in{\mathcal{F}}(2\alpha/3+\varepsilon,\alpha,\rho)
for
\alpha>0,0<\varepsilon<\alpha/3
and
0<\rho\leq 1
we recover (though, due to the notational discrepancy this is not immediately obvious) streamlined versions of the results in
[
10
,
14
]

s_{n}\sim\frac{S(z_{n})}{\sqrt{2\pi z_{n}^{2}C^{\prime\prime}(z_{n})}}\cdot z_{n}^{-n}\cdot n!,\quad z_{n}\text{ solves }z_{n}C^{\prime}(z_{n})=n

and

\displaystyle g_{n}\sim\begin{cases}\exp\bigg\{\sum_{j\geq 2}C(\rho^{j})/j\bigg\}\frac{\exp\left\{C(z_{n})\right\}}{\sqrt{2\pi z_{n}^{2}C^{\prime\prime}(z_{n})}}\cdot z_{n}^{-n},&$0<\rho<1$ and $z_{n}$ solves $z_{n}C^{\prime}(z_{n})=n$\\

The Distribution of the Largest and Smallest Clusters

Theorem
1.1
is not only helpful to obtain counting results, but it can also be applied to get fine grained information about the cluster statistics of random (multi-)sets. Let
\mathsf{S}^{(n)}
and
\mathsf{G}^{(n)}
be the random cluster structures from (
1.5
) and (
1.6
), respectively.
The next statements are concerned with the distribution of the extreme (in both directions of the spectrum) cluster sizes in
\mathsf{S}^{(n)}
and
\mathsf{G}^{(n)}
. Recall that for
\mathsf{F}^{(n)}\in\{\mathsf{S}^{(n)},\mathsf{G}^{(n)}\}

{\mathcal{M}}(\mathsf{F}^{(n)}):=\min\left\{1\leq k\leq n:\mathsf{F}^{(n)}_{k}>0\right\}\quad\text{and}\quad\mathcal{L}(\mathsf{F}^{(n)}):=\max\left\{1\leq k\leq n:\mathsf{F}^{(n)}_{k}>0\right\}.

First we treat the largest clusters.
Freiman and Granovsky 2005
show that if
(c_{k})_{k\in\mathbb{N}}
is expansive, then the coarse threshold for the size of the largest cluster in the
{\mathcal{C}}
-set
\mathsf{S}^{(n)}
is given by
n^{1/(\alpha+1)}
, in the sense that

\displaystyle\lim_{n\to\infty}\mathrm{Pr}\left[\mathcal{L}(\mathsf{S}^{(n)})\leq n^{\beta}\right]=\begin{cases}0,&$\beta<1/(\alpha+1)$\\
1,&$\beta>1/(\alpha+1)$\end{cases}.

However, the question about the actual order of magnitude, and even more, the limiting distribution, remained an open problem.
Mutafchiev 2013
treated the
{\mathcal{C}}
-multiset
\mathsf{G}^{(n)}
in a specific setting – under the aforementioned Meinardus scheme of conditions – that in addition to several assumptions requires
\rho=1
. He established that for specific functions functions
f(n),g(n)

\lim_{n\to\infty}\mathrm{Pr}\left[\mathcal{L}(\mathsf{G}^{(n)})\leq g(n)+tf(n)\right]=\mathrm{e}^{-\mathrm{e}^{-t}},\quad t\in\mathbb{R},

a fact that was known for integer partitions from the classical work
[
6
]
. In our next result we show that, after appropriate normalization, this behavior is universal for expansive (multi-)sets.

Theorem 1.2
.

Let
(c_{k})_{k\in\mathbb{N}}
be expansive. For
t\in\mathbb{R}
and
\beta>0
set

s(t,\beta):=\beta^{-1}\big(\ln X+t\big),\quad\text{where}\quad X=\Gamma(\alpha)^{-1}C(\rho\mathrm{e}^{-\beta})(\ln C(\rho\mathrm{e}^{-\beta}))^{\alpha-1}\frac{h(\beta^{-1}\ln C(\rho\mathrm{e}^{-\beta}))}{h(\beta^{-1})}.

Let
z_{n}=\rho\mathrm{e}^{-\eta_{n}}
be the solution to
z_{n}C^{\prime}(z_{n})=n
and
q_{n}=\rho\mathrm{e}^{-\xi_{n}}
the solution to
\sum_{j\geq 1}q_{n}^{j}C^{\prime}(q_{n}^{j})=n
.
Then

\displaystyle\lim_{n\to\infty}\mathrm{Pr}\left[\mathcal{L}(\mathsf{F}^{(n)})\leq s(t,\beta_{n})\right]=\mathrm{e}^{-\mathrm{e}^{-t}},\text{ where }\beta_{n}=\begin{cases}\eta_{n},&$\mathsf{F}^{(n)}=\mathsf{S}^{(n)}\text{ or }\mathsf{F}^{(n)}=\mathsf{G}^{(n)},0<\rho<1$\\
\xi_{n},&$\mathsf{F}^{(n)}=\mathsf{G}^{(n)},\rho=1$\end{cases},\quad t\in\mathbb{R}.

The proof, which is in Section
3.2
, is based on a combination of
H
-admissibility together with the inclusion/exclusion principle as exploited in
[
6
]
.
For an application of Theorem
1.2
we have to determine
C(\rho\mathrm{e}^{-\beta})
and
\rho\mathrm{e}^{-\beta}C^{\prime}(\rho\mathrm{e}^{-\beta})
accurately enough as
\beta\to 0
. Here is a particular example where this works out nicely, the proof of which is performed after the proof of Theorem
1.2
.

Example 1.3
.

Let
c_{n}=n^{\alpha-1}\rho^{-n}
for
\alpha>0,0<\rho\leq 1
and
n\in\mathbb{N}
. Define

f(n):=\left(\frac{n}{\Gamma(\alpha+1)}\right)^{1/(\alpha+1)}\quad\text{and}\quad\tilde{f}(n):=\left(\frac{n}{\Gamma(\alpha+1)\zeta(\alpha+1)}\right)^{1/(\alpha+1)}.

Then, if
z_{n}=\rho\mathrm{e}^{-\eta_{n}}
is the solution to
z_{n}C^{\prime}(z_{n})=n
,

\displaystyle\eta_{n}=f(n)^{-1}+o(n^{-1})\quad\text{and}\quad\ln X=\alpha\ln f(n)+(\alpha-1)\ln\ln f(n)+(\alpha-1)\ln\alpha+o(1)

and, if
q_{n}=\rho\mathrm{e}^{-\xi_{n}}
is the solution to
\sum_{j\geq 1}q_{n}^{j}C^{\prime}(q_{n}^{j})=n
,

\xi_{n}=\tilde{f}(n)^{-1}+o(n^{-1})\quad\text{and}\quad\ln X=\alpha\ln\tilde{f}(n)+(\alpha-1)\ln\ln\tilde{f}(n)+(\alpha-1)\ln\alpha+o(1).

This delivers the exact scaling for the distribution of the largest cluster in
\mathsf{S}^{(n)}
and
\mathsf{G}^{(n)}
for all
0<\rho\leq 1
.

Next we consider the smallest clusters. In the next result we determine the distribution of
\mathcal{M}(\mathsf{S}^{(n)})
,
\mathcal{M}(\mathsf{G}^{(n)})
. The authors of
[
11
]
determine the limiting distribution of
\mathcal{M}(\mathsf{S}^{(n)})
in the expansive case. We extend their result to the oscillating expansive case and further to
\mathcal{M}(\mathsf{G}^{(n)})
.

Corollary 1.4
.

For
\alpha>0
,
0<\rho\leq 1
and
0<\varepsilon<\alpha/3
let
(c_{k})_{k\in\mathbb{N}}\in{\mathcal{F}}(2\alpha/3+\varepsilon,\alpha,\rho)
. Then, for
s\in\mathbb{N}
,

\lim_{n\to\infty}\mathrm{Pr}\left[\mathcal{M}(\mathsf{F}^{(n)})>s\right]=\begin{cases}\exp\bigg\{-\sum_{1\leq k\leq s}c_{k}\rho^{k}\bigg\},&$\mathsf{F}^{(n)}=\mathsf{S}^{(n)}$\\
\exp\bigg\{-\sum_{j\geq 1}\sum_{1\leq k\leq s}c_{k}\rho^{jk}/j\bigg\},&$\mathsf{F}^{(n)}=\mathsf{G}^{(n)}$\end{cases}.

Moreover,
\lim_{n\to\infty}\mathrm{Pr}\left[\mathcal{M}(\mathsf{F}^{(n)})>s_{n}\right]=0
for any
s_{n}\to\infty
and
\mathsf{F}^{(n)}\in\{\mathsf{S}^{(n)},\mathsf{G}^{(n)}\}
.

The Cluster Distribution

In this section we study the distribution of the number of clusters in
\mathsf{S}^{(n)}
and
\mathsf{G}^{(n)}
. Recall that for
\mathsf{F}^{(n)}\in\{\mathsf{S}^{(n)},\mathsf{G}^{(n)}\}
the number of components is defined by

\kappa(\mathsf{F}^{(n)}):=\sum_{1\leq k\leq n}\mathsf{F}^{(n)}_{k}.

Extending the generating series
S(x)
and
G(x)
to the bivariate version where the additional variable
y
tags the number of clusters in a (multi-)set yields, see
[
9
,
4
]
,

S(x,y)=\exp\left\{yC(x)\right\}\quad\text{and}\quad G(x,y)=\exp\left\{\sum_{j\geq 1}\frac{C(x^{j})y^{j}}{j}\right\}.

Then for
k\in\mathbb{N}

\displaystyle\mathrm{Pr}\left[\kappa(\mathsf{S}^{(n)})=k\right]=\frac{[x^{n}y^{k}]S(x,y)}{[x^{n}]S(x)}\quad\text{and}\quad\mathrm{Pr}\left[\kappa(\mathsf{G}^{(n)})=k\right]=\frac{[x^{n}y^{k}]G(x,y)}{[x^{n}]G(x)}.

For
n,\ell\in\mathbb{N}
let
(n)_{\ell}
denote the falling factorial
(n)_{\ell}:=n(n-1)\cdots(n-\ell+1)
.
By a straightforward computation we obtain the well-known relations

\displaystyle\mathbb{E}\left[(\kappa(\mathsf{S}^{(n)}))_{\ell}\right]=\frac{[x^{n}]d^{\ell}/(dy^{\ell})S(x,y)\big|_{y=1}}{[x^{n}]S(x)}\quad\text{and}\quad\mathbb{E}\left[(\kappa(\mathsf{G}^{(n)}))_{\ell}\right]=\frac{[x^{n}]d^{\ell}/(dy^{\ell})G(x,y)\big|_{y=1}}{[x^{n}]G(x)},\quad\ell\in\mathbb{N}.

(1.12)

For the specific case
c_{n}\sim cn^{\alpha-1}\rho^{-n}
and
c,\alpha>0,0<\rho\leq 1
the results in
Erlihson and Granovsky 2008
can be used to obtain the moments of
\kappa(\mathsf{S}^{(n)})
; the following result completes the picture for both sets and multisets in the oscillating expansive case.

Corollary 1.5
.

For
\alpha>0
,
0<\rho\leq 1
and
0<\varepsilon<\alpha/3
let
(c_{k})_{k\in\mathbb{N}}\in{\mathcal{F}}(2\alpha/3+\varepsilon,\alpha,\rho)
. Let
z_{n}
be the solution to
z_{n}C^{\prime}(z_{n})=n
. Then

\displaystyle\mathbb{E}\left[\kappa(\mathsf{F}^{(n)})^{\ell}\right]\sim C(z_{n})^{\ell}\quad\text{for}\quad\mathsf{F}^{(n)}=\begin{cases}\mathsf{S}^{(n)},&$0<\rho\leq 1$\\
\mathsf{G}^{(n)},&$0<\rho<1$\end{cases}.

If
\rho=1
, let
q_{n}
be the solution to
\sum_{j\geq 1}q_{n}^{j}C^{\prime}(q_{n}^{j})=n
. Then

\mathbb{E}\left[\kappa(\mathsf{G}^{(n)})\right]\sim\sum_{j\geq 1}C(q_{n}^{j})\quad\text{and}\quad\mathbb{E}\left[\kappa(\mathsf{G}^{(n)})^{2}\right]\sim\Big(\sum_{j\geq 1}C(q_{n}^{j})\Big)^{2}+\sum_{j\geq 1}jC(q_{n}^{j}).

The proof is in Section
3.2
. Some further comments are in place.
First, note that in Corollary
1.5
we consider only the first and second moment of
\kappa(\mathsf{G}^{(n)})
in the case
\rho=1
. We actually may compute
any
moment also in that case by determining carefully the derivatives in (
1.12
) and then making use of Theorem
1.1
.
However, already for the case
\ell=2
the second term in the asymptotic formula for
\mathbb{E}\left[\kappa(\mathsf{G}^{(n)})^{2}\right]
can be of the same order as the first term. To see this, consider following example. Let
c_{n}\sim n^{\alpha-1}
for some
0<\alpha<1
. Set
q_{n}=\mathrm{e}^{-\xi_{n}}
. Then, as we will show later in Lemma
2.2
, we have that
\sum_{j\geq 1}C(q_{n}^{j})=\Theta(\xi_{n}^{-1})
and
\sum_{j\geq 1}jC(q_{n}^{j})=\Theta(\xi_{n}^{-2})
. For this reason it seems out of reach to get a “nice” formula for
\mathbb{E}\left[\kappa(\mathsf{G}^{(n)})^{\ell}\right]
for general
\ell
. So, we are content with only presenting the cases
\ell=1,2
.
As a second remark, we want to mention that in general we cannot compute the variance in any of the cases that we consider, as we do not know (and in the generality considered here, cannot obtain) the second asymptotic order of the expressions at hand.

Under the stronger assumption that
(c_{k})_{k\in\mathbb{N}}
is expansive we can actually say much more. In this direction,
Erlihson and Granovsky 2004
derived a local and a central limit theorem for
\kappa(\mathsf{S}^{(n)})
under the condition
c_{n}=cn^{\alpha-1}\rho^{-n}
for
c,\alpha>0,0<\rho\leq 1
and
n\in\mathbb{N}
; note the “=” sign. Here we establish the validity of a local limit theorem in the expansive case for sets and multisets.

Theorem 1.6
.

Let
(c_{k})_{k\in\mathbb{N}}
be expansive. Then for any
K>0
, as
n\to\infty

\displaystyle\mathrm{Pr}\left[\kappa(\mathsf{S}^{(n)})=\lfloor C(z_{n})+t\sqrt{C(z_{n})/(\alpha+1)}\rfloor\right]\sim\mathrm{e}^{-t^{2}/2}\cdot\frac{1}{\sqrt{2\pi C(z_{n})/(\alpha+1)}},\quad t\in[-K,K].

If
0<\rho<1
we further get that for any
t\in\mathbb{R}
, as
n\to\infty
,

\displaystyle\mathrm{Pr}\left[\kappa(\mathsf{G}^{(n)})=\lfloor C(z_{n})+t\sqrt{C(z_{n})/(\alpha+1)}\rfloor\right]\sim\mathrm{e}^{-t^{2}/2}\cdot\frac{1}{\sqrt{2\pi C(z_{n})/(\alpha+1)}}.

The proof can be found in Section
3.2
. Let us make two more remarks. First, this theorem of course
strongly suggests
that the variance of
\kappa(\mathsf{S}^{(n)})
and
\kappa(\mathsf{G}^{(n)})
is
\sim C(z_{n})/(\alpha+1)
; we leave it as an open problem to establish that. Moreover, note that in Theorem
1.6
the statement about
\kappa(\mathsf{S}^{(n)})
implies a central limit theorem, whereas the statement about
\kappa(\mathsf{G}^{(n)})
is weaker and in general not sufficient to obtain a central limit theorem.

In the proof we will, among other ingredients, exploit knowledge about the (asymptotic) number of
{\mathcal{C}}
-(multi-)sets of total size
n
and with
N
clusters. In the paper
[
23
]
we determined the asymptotic number of such multisets, which is nothing else than the coefficient
[x^{n}y^{N}]G(x,y)
, for a wide range (but not all) of
N
. Here we solve, again by using tools from
[
23
]
, the analogous problem for the set case; the proof is in Section
3.2
.

Theorem 1.7
.

Let
(c_{k})_{k\in\mathbb{N}}
be expansive. Let
N=N_{n}
be such that
N,n/N\to\infty
as
n\to\infty
. Set
r_{n}
to be the solution to
r_{n}C^{\prime}(r_{n})/C(r_{n})=n/N
.
Then, as
n\to\infty
,

[x^{n}y^{N}]S(x,y)\sim\frac{1}{N!}\cdot\frac{C(r_{n})^{N}}{\sqrt{2\pi Nr_{n}^{2}C^{\prime\prime}(r_{n})/((\alpha+1)C(r_{n}))}}\cdot r_{n}^{-n}.

Preliminaries

In this section we first introduce the concept of
H
-admissibility and state Lemma
2.1
, which is a central result about coefficient extraction. Subsequently, we collect various estimates for power series that are needed in the forthcoming proofs in Section
2.2
.

2.1
H
-admissibility

We start by reviewing the concept of
H
-admissibility, which is a general set of conditions on a function
F(x)
with radius of convergence
0<\rho\leq\infty
under which
[x^{n}]F(x)
can be computed asymptotically. This theory was initiated in the seminal paper
[
16
]
and has seen numerous extensions and applications. As a general reference we recommend
[
9
, Ch. VIII.5]
.

Set
F(x)=\mathrm{e}^{f(x)}
.
By applying Cauchy’s coefficient formula and switching to polar coordinates we obtain for some
0<r<\rho

\displaystyle[x^{n}]F(x)=\frac{r^{-n}}{2\pi}\int_{-\pi}^{\pi}F(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\mathrm{e}^{-n\mathrm{i}\mkern 1.0mu\theta}d\theta.

(2.1)

To get a grip on this expression we expand
F(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})
at
\theta=0
, so that for some
\lvert\xi\rvert\leq\lvert\theta\rvert\leq\pi

\displaystyle F(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\mathrm{e}^{-n\mathrm{i}\mkern 1.0mu\theta}=F(r)\cdot\exp\left\{\mathrm{i}\mkern 1.0mu\theta(a(r)-n)-\frac{\theta^{2}}{2}b(r)+\frac{(\mathrm{i}\mkern 1.0mu\theta)^{3}}{6}c(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\xi})\right\}

(2.2)

for functions
a,b
and
c
given by

\displaystyle\mathrm{i}\mkern 1.0mua(x):=\frac{\partial}{\partial\theta}f(x\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\bigg|_{\theta=0},\quad-b(x):=\frac{\partial^{2}}{\partial\theta^{2}}f(x\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\bigg|_{\theta=0}\quad\text{and}\quad\mathrm{i}\mkern 1.0mu^{3}c(x):=\frac{\partial^{3}}{\partial\theta^{3}}f(x\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\bigg|_{\theta=0}.

In particular,

\displaystyle a(x)=xf^{\prime}(x),\quad b(x)=x^{2}f^{\prime\prime}(x)+xf^{\prime}(x)\quad\text{and}\quad c(x)=x^{3}f^{\prime\prime\prime}(x)+3x^{2}f^{\prime\prime}(x)+xf^{\prime}(x).

(2.3)

With these definitions at hand we (informally) say that
F(x)
is
H
-admissible, if it is possible to split up (
2.1
) into a dominant part, where
f(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})-n\mathrm{i}\mkern 1.0mu\theta=f(r)+\mathrm{i}\mkern 1.0mu\theta(a(r)-n)-\theta^{2}b(r)/2+o(1)
, and another integral that is negligible. Then by choosing
a(r)
to be (close to)
n
the asymptotic value of the dominant integral can be retrieved, as it is of “Gaussian” type. The following three conditions formalize this idea, where
F
is assumed to be a function with radius of convergence
0<\rho\leq\infty
which is positive on some interval
(R_{0},\rho)\subseteq(0,\rho)
.

(
H_{1}
)

[Capture Condition]
a(r)
and
b(r)
tend to infinity as
r\to\rho
.

(
H_{2}
)

[Locality Condition] For some function
\theta_{0}:(R_{0},\rho)\to\mathbb{R}^{+}
we have as
r\to\rho
uniformly in
\lvert\theta\rvert\leq\theta_{0}(r)

F(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})\sim F(r)\cdot\exp\left\{\mathrm{i}\mkern 1.0mu\theta a(r)-{\theta^{2}}b(r)/2\right\}.

(
H_{3}
)

[Decay Condition] As
r\to\rho
uniformly in
\theta_{0}(r)\leq\lvert\theta\rvert<\pi

F(r\mathrm{e}^{\mathrm{i}\mkern 1.0mu\theta})=o\big(b(r)^{-1/2}{F(r)}\big).

We call
F(x)

H
-admissible if it has the three proprties
(

H
1

)
–
(

H
3

)
.
The following statement, which originates in
[
16
, Thm. 1]
, provides a useful tool for determining the
n
-th coefficient of a
H
-admissible function, see also
[
9
, Prop. VIII.5]
.

Lemma 2.1
.

Suppose that
F(x)
is
H
-admissible. Then as
r\to\rho

[x^{n}]F(x)=\frac{F(r)}{\sqrt{2\pi b(r)}}\cdot r^{-n}\cdot\left(\exp\left\{-\frac{(a(r)-n)^{2}}{2b(r)}\right\}+\varepsilon_{n}\right),

where
\lim_{r\to\rho}\sup_{n\in\mathbb{N}}\lvert\varepsilon_{n}\rvert=0
.

In particular, by choosing any
r
such that
(a(r)-n)^{2}/b(r)=\mathcal{O}\left(1\right)
we get the first asymptotic order of
[x^{n}]F(x)
. This allows us to compare
different
coefficients
[x^{n-k}]F(x)
and
[x^{n}]F(x)
using the
identical
saddle-point
r
, a simple yet impactful fact we will use numerous times later.

2.2
Asymptotics and Estimates for Power Series

First we state the following auxiliary lemma which will help us to compute asymptotic bounds for the sum
\sum_{j\geq 1}j^{\beta-1}r^{\gamma j}C^{(\gamma)}((\mathrm{e}^{-\chi})^{j})
for
\beta\in\mathbb{N},\gamma\in\mathbb{N}_{0}
and as
\chi\to 0
. In the proof we use the Euler-MacLaurin summation formula (and the computations are inspired by
[
19
, Appendix A]
).

Lemma 2.2
.

Let
\beta,\gamma\in\mathbb{R}_{0}^{+}
. Then, as
\chi\to 0
,

\displaystyle\sum_{k\geq 1}\frac{k^{\gamma}\mathrm{e}^{-\chi k}}{(1-\mathrm{e}^{-\chi k})^{\beta}}\sim\begin{cases}d_{1}\cdot\chi^{-(\gamma+1)},&$\beta<1+\gamma$\\
\chi^{-(\gamma+1)}\ln(\chi^{-1}),&$\beta=1+\gamma$\\
d_{2}\cdot\chi^{-\beta},&$\beta>1+\gamma$\end{cases},

where, letting
\zeta
denote the Zeta-function,

\displaystyle d_{1}=\int_{0}^{\infty}\frac{t^{\gamma}\mathrm{e}^{-t}}{(1-\mathrm{e}^{-t})^{\beta}}dt\quad\text{and}\quad d_{2}=\zeta(\beta-\gamma).

Proof.

Define
g(t):=t^{\gamma}\mathrm{e}^{-\chi t}/(1-\mathrm{e}^{-\chi t})^{\beta}
.
For
\beta-\gamma<1
the integral
\int_{0}^{\infty}t^{\gamma}\mathrm{e}^{-t}/(1-\mathrm{e}^{-t})^{\beta}dt
exists (since the integrand is asymptotically
t^{-(\beta-\gamma)}
as
t\to 0
) so that by convergence of the Riemann sum to the corresponding integral we obtain

\sum_{k\geq 1}g(k)=\chi^{-(\gamma+1)}\cdot\chi\cdot\sum_{k\geq 1}\frac{(\chi k)^{\gamma}\mathrm{e}^{-\chi k}}{(1-\mathrm{e}^{-\chi k})^{\beta}}\sim\chi^{-(\gamma+1)}\int_{0}^{\infty}\frac{t^{\gamma}\mathrm{e}^{-t}}{(1-\mathrm{e}^{-t})^{\beta}}dt.

Next we consider the case
\beta-\gamma>1
. Let
P_{1}(x)=x-\lfloor x\rfloor-1/2
. Then the Euler-Maclaurin formula, see for example
[
12
, Ch. 9.5]
, gives us

\displaystyle\sum_{k\geq 1}g(k)=\int_{1}^{\infty}g(t)dt+\frac{g(1)}{2}+\int_{1}^{\infty}g^{\prime}(x)P_{1}(x)dx.

(2.4)

We will determine the first integral by using dominated convergence.
Note that for
t\geq 1

\chi^{\beta}g(t)t^{\beta-\gamma}=(\chi t)^{\beta}\mathrm{e}^{-\chi t}/(1-\mathrm{e}^{-\chi t})^{\beta}.

Thus

\displaystyle\lim_{\chi\to 0}\chi^{\beta}g(t)=t^{\gamma-\beta},\quad t\geq 1.

(2.5)

Further, the continuous function
z^{\beta}\mathrm{e}^{-z}/(1-\mathrm{e}^{-z})^{\beta}
tends to
1
as
z\to 0
and to
0
as
z\to\infty
. Hence there is some
A>0
such that

\displaystyle\chi^{\beta}g(t)\leq{A}t^{\gamma-\beta},\quad t\geq 1.

(2.6)

Thus, by dominated convergence, (
2.5
), and the fact that
\int_{1}^{\infty}t^{-(\beta-\gamma)}dt
exists

\displaystyle\int_{1}^{\infty}g(t)dt=\chi^{-\beta}\int_{1}^{\infty}\chi^{\beta}g(t)dt\sim\chi^{-\beta}\int_{1}^{\infty}t^{-(\beta-\gamma)}dt=\chi^{-\beta}\frac{1}{\beta-\gamma-1}.

(2.7)

The next term in (
2.4
) is
g(1)/2\sim\chi^{-\beta}/2
. Moreover,

\displaystyle\int_{1}^{\infty}g^{\prime}(t)P_{1}(t)dt=\int_{1}^{\infty}\left(\gamma\frac{t^{\gamma-1}\mathrm{e}^{-\chi t}}{(1-\mathrm{e}^{-\chi t})^{\beta}}-\chi\frac{t^{\gamma}\mathrm{e}^{-\chi t}}{(1-\mathrm{e}^{-\chi t})^{\beta}}-\chi\beta\frac{t^{\gamma}\mathrm{e}^{-2\chi t}}{(1-\mathrm{e}^{-\chi t})^{\beta+1}}\right)P_{1}(t)dt.

(2.8)

Note that
\beta-\gamma>1
implies that
\beta-(\gamma-1)>1
and
(\beta+1)-\gamma>1
so that as before

\int_{1}^{\infty}g^{\prime}(t)P_{1}(t)dt\sim\chi^{-\beta}(\gamma-\beta)\int_{1}^{\infty}t^{-(\beta-\gamma+1)}P_{1}(t)dt-\chi^{-\beta+1}\int_{1}^{\infty}t^{-(\beta-\gamma)}P_{1}(t)dt.

As
\beta-\gamma>1
, the last term is
\mathcal{O}\left(\chi^{-\beta+1}\right)=o(\chi^{-\beta})
. Moreover, by using again Euler-Maclaurin summation

\sum_{k\geq 1}\frac{k^{-(\beta-\gamma)}}{\gamma-\beta}=\int_{1}^{\infty}\frac{t^{-(\beta-\gamma)}}{\gamma-\beta}dt+\frac{1}{2(\gamma-\beta)}+\int_{1}^{\infty}t^{-(\beta-\gamma+1)}P_{1}(t)dt.

Computing the integral and rearranging the terms yields

\int_{1}^{\infty}t^{-(\beta-\gamma+1)}P_{1}(t)dt=\frac{\zeta(\beta-\gamma)}{\gamma-\beta}+\frac{1}{(\gamma-\beta)(\gamma-\beta+1)}-\frac{1}{2(\gamma-\beta)}.

The claim follows for
\beta-\gamma>1
.
Finally, let us consider the case
\beta=\gamma+1
. Set
a=\ln(\chi^{-1})^{-1/(2(\gamma+1))}=o(1)
. We have that

\chi^{\gamma+1}\int_{1}^{\infty}g(t)dt=\int_{\chi}^{\infty}\frac{t^{\gamma}\mathrm{e}^{-t}}{(1-\mathrm{e}^{-t})^{\gamma+1}}dt=\left(\int_{\chi}^{a}+\int_{a}^{1}+\int_{1}^{\infty}\right)\frac{t^{\gamma}\mathrm{e}^{-t}}{(1-\mathrm{e}^{-t})^{\gamma+1}}dt=:I_{1}+I_{2}+\mathcal{O}\left(1\right).

In
I_{1}
we use that
t=o(1)
to obtain that
I_{1}\sim\int_{\chi}^{a}t^{-1}dt=\ln a-\ln\chi\sim\ln(\chi^{-1})
. In
I_{2}
we estimate
I_{2}\leq(1-\mathrm{e}^{-a})^{-(\gamma+1)}\int_{a}^{1}t^{\gamma}\mathrm{e}^{-t}=\Theta(\ln(\chi^{-1})^{1/2})=o(\ln(\chi^{-1}))
.
Hence

\displaystyle\int_{1}^{\infty}g(t)dt\sim\chi^{-(\gamma+1)}\ln(\chi^{-1}).

(2.9)

Further
g(1)\sim\chi^{-\beta}=\chi^{-(\gamma+1)}
and by estimating
\lvert P_{1}(x)\rvert\leq 1
in (
2.8
) we get

\bigg\lvert\int_{1}^{\infty}g^{\prime}(t)P_{1}(t)dt\bigg\rvert\leq\int_{1}^{\infty}\left(\gamma\frac{t^{\gamma-1}\mathrm{e}^{-\chi t}}{(1-\mathrm{e}^{-\chi})^{\beta}}+\chi\frac{t^{\gamma}\mathrm{e}^{-\chi t}}{(1-\mathrm{e}^{-\chi t})^{\beta}}+\chi\beta\frac{t^{\gamma}\mathrm{e}^{-2\chi t}}{(1-\mathrm{e}^{-\chi t})^{\beta+1}}\right)dt=:J_{1}+J_{2}+J_{3}.

Since
\beta=\gamma+1
we have that
\gamma-1-\beta=-2
and the integral
\int_{1}^{\infty}t^{-2}dt
exists. Hence, analogous to (
2.5
)–(
2.7
) we obtain by dominated convergence that
J_{i}=\mathcal{O}\left(\chi^{-(\gamma+1)}\right)=o(\chi^{-(\gamma+1)}\ln(\chi^{-1}))
for
i=1,3
. Analogous to (
2.9
) we obtain that

\chi^{-1}J_{2}=\int_{1}^{\infty}g(t)dt\sim\chi^{-(\gamma+1)}\ln(\chi^{-1})

implying that
J_{2}=o(\chi^{-(\gamma+1)}\ln(\chi^{-1})).

This finishes the proof.
∎

\displaystyle\Omega_{n,\leq s}=\Omega_{n}\setminus\bigcup_{k>s}\Omega_{n,k}.

(3.24)

Define

I_{\ell}=I_{\ell}(n):=\sum_{s<k_{1}<\cdots<k_{\ell}\atop k_{1}+\cdots+k_{\ell}\leq n}\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,\mathrm{k}}\right],\qquad\ell\in\mathbb{N}.

Here comes the inclusion/exclusion principle into play. In light of (
3.23
) and (
3.24
) we obtain that

\displaystyle\mathrm{Pr}\left[\mathcal{L}(\mathsf{F}^{(n)})\leq s\right]

\displaystyle=\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n}\setminus\bigcup_{k>s}\Omega_{n,k}\right]=\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n}\right]+\sum_{\ell\geq 1}(-1)^{\ell}I_{\ell}=1+\sum_{\ell\geq 1}(-1)^{\ell}I_{\ell}.

Computing the union of events by the inclusion/exclusion principle entails the helpful “sandwich-property” that for any
M>1

\displaystyle 1+\sum_{1\leq\ell\leq 2M-1}(-1)^{\ell}I_{\ell}\leq\mathrm{Pr}\left[\mathcal{L}(\mathsf{F}^{(n)})\leq s\right]\leq 1+\sum_{1\leq\ell\leq 2M}(-1)^{\ell}I_{\ell}.

(3.25)

This has the great advantage that we can take a large but fixed
M
when analysing
\mathcal{L}(\mathsf{F}^{(n)})
; investigating
I_{\ell}=I_{\ell}(n)
for fixed
\ell
is much easier, as we only need to let one parameter (namely
n
) tend to infinity.
Recall that for
t\in\mathbb{R}
we defined

s_{n}=s(t,\beta_{n}):=\beta_{n}^{-1}\big(\ln X(\beta_{n})+t\big),\quad X(\beta_{n}):=\frac{1}{\Gamma(\alpha)}C(w_{n})(\ln C(w_{n}))^{\alpha-1}\frac{h(\beta_{n}^{-1}\ln C(w_{n}))}{h(\beta_{n}^{-1})}.

Since
h(\beta_{n}^{-1}\ln C(w_{n}))/h(\beta_{n}^{-1})=\mathcal{O}\left(\ln C(w_{n})\right)
due to (
2.10
) we obtain

\displaystyle s_{n}\sim\beta_{n}^{-1}\ln C(w_{n}),\quad n\to\infty.

(3.26)

In order to get a grip on (
3.25
) we claim that

\displaystyle\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\sim\prod_{1\leq i\leq\ell}c_{k_{i}}w_{n}^{k_{i}},\quad\ell\in\mathbb{N},\,s_{n}<k_{1}<\cdots<k_{\ell}<s_{n}+o(s_{n})

(3.27)

and for any
\varepsilon>0
when
n
sufficiently large

\displaystyle\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\leq(1+\varepsilon)\cdot\prod_{1\leq i\leq\ell}c_{k_{i}}w_{n}^{k_{i}},\quad\ell\in\mathbb{N},\,k_{1},\dots,k_{\ell}>0.

(3.28)

The proof of (
3.27
) and (
3.28
), which is rather lengthy and relies heavily upon the underlying generating series to be
H
-admissible, is deferred to the end of this section for better readability.
We continue by showing

\displaystyle I_{\ell}\sim\frac{1}{\ell!}(\mathrm{e}^{-t})^{\ell},\quad\ell\in\mathbb{N}.

(3.29)

Then, by choosing
M\in\mathbb{N}
sufficiently large in (
3.25
), we get that
\mathrm{Pr}\left[\mathcal{L}(\mathsf{F}^{(n)})\leq s_{n}\right]
gets arbitrarily close to
1+\sum_{\ell\geq 1}(-1)^{\ell}(\mathrm{e}^{-t})^{\ell}/\ell!=\mathrm{e}^{-\mathrm{e}^{-t}}
and the claim of Theorem
1.2
follows.
We first treat the case
\ell=1
in (
3.29
), which is instructive for the remaining cases
\ell\geq 2
.
Let
\nu\equiv\nu(\beta_{n})
be in
\omega(\beta_{n}^{-1})\cap o(s_{n})
, which is possible due to (
3.26
). Note further that
\nu=o(\beta_{n}^{-1}\ln C(w_{n}))=o(n)
as
n\to\infty
according to (
3.22
). Then

I_{1}=\bigg(\sum_{s_{n}<k\leq s_{n}+\nu}+\sum_{k>s_{n}+\nu}\bigg)\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,k}\right]=:I_{1,1}+I_{1,2}.

We are first going to show that
I_{1,1}\sim\mathrm{e}^{-t}
. Due to (
3.27
) we obtain

\displaystyle I_{1,1}\sim\sum_{s_{n}<k\leq s_{n}+\nu}c_{k}w_{n}^{k}=\sum_{s_{n}<k\leq s_{n}+\nu}h(k)k^{\alpha-1}\mathrm{e}^{-\beta_{n}k}\sim h(s_{n})s_{n}^{\alpha-1}\mathrm{e}^{-\beta_{n}s_{n}}\sum_{0<k\leq\nu}\mathrm{e}^{-\beta_{n}k}\sim h(s_{n})s_{n}^{\alpha-1}\mathrm{e}^{-\beta_{n}s_{n}}\beta_{n}^{-1}.

(3.30)

Recalling
s_{n}\sim\beta_{n}^{-1}\ln C(w_{n})
from (
3.26
) and plugging in
s_{n}
into the expression in the previous display gives by Lemma
2.3

\displaystyle I_{1,1}\sim\frac{\Gamma(\alpha)h(\beta_{n}^{-1})\beta_{n}^{-\alpha}}{C(w_{n})}\cdot\mathrm{e}^{-t}\sim\mathrm{e}^{-t}.

(3.31)

For
k>s_{n}+\nu
we use the estimate (
3.28
) and obtain

\displaystyle\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,k}\right]=\mathcal{O}\left(c_{k}w_{n}^{k}\right).

With this at hand and since
\nu=\omega(\beta_{n}^{-1}
) Lemma
2.4
reveals for
k>s_{n}+\nu
that

\displaystyle I_{1,2}=\mathcal{O}\left(\sum_{k>s_{n}+\nu}c_{k}w_{n}^{k}\right)=\mathcal{O}\left(h(s_{n})s_{n}^{\alpha-1}\mathrm{e}^{-\beta_{n}(s_{n}+\nu)}\beta_{n}^{-1}\right)=\mathcal{O}\left(\mathrm{e}^{-t}\mathrm{e}^{-\beta_{n}\nu}\right)=o(1).

(3.32)

It follows that
I_{1}\sim\mathrm{e}^{-t}
, as claimed. Next, we treat the remaining
\ell\geq 2
in (
3.29
). Define

{B}:=\{\mathrm{k}\in\mathbb{N}^{\ell}:\forall 1\leq i\leq\ell:k_{i}>s_{n},k_{1}+\cdots+k_{\ell}\leq n\},

and

{B}_{=}:=\{\mathrm{k}\in{B}:\exists 1\leq i<j\leq\ell:k_{i}=k_{j}\}.

In addition we need the sets

\displaystyle{B}_{\leq}:=\{\mathrm{k}\in{B}:\forall 1\leq i\leq\ell:k_{i}\leq s_{n}+\nu\},\quad{B}_{>}:=\{\mathrm{k}\in{B}:\exists 1\leq i\leq\ell:k_{i}>s_{n}+\nu\}.

Further set

f(\mathrm{k}):=\prod_{1\leq i\leq k}c_{k_{i}}w_{n}^{k_{i}},\quad\mathrm{k}\in{B}.

With these definitions at hand and since
\nu=o(s_{n})
we obtain by applying (
3.27
) and (
3.28
)

\displaystyle I_{\ell}

\displaystyle=\bigg(\sum_{\mathrm{k}\in{B}_{\leq},\atop k_{1}<\cdots<k_{\ell}}+\sum_{\mathrm{k}\in{B}_{>},\atop k_{1}<\cdots<k_{\ell}}\bigg)\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,k_{1},\dots,k_{\ell}}\right]\sim\frac{1}{\ell!}\bigg(\sum_{{B}_{\leq}}-\sum_{{B}_{=}}\bigg)f(\mathrm{k})+\mathcal{O}\bigg(\sum_{{B}_{>}}f(\mathrm{k})\bigg).

where we slightly abuse the notation and write
\sum_{\mathcal{X}}=\sum_{x\in\mathcal{X}}
for any set
\mathcal{X}
.
We will prove

\displaystyle\frac{1}{\ell!}\sum_{{B}_{\leq}}f(\mathrm{k})\sim\frac{1}{\ell!}(\mathrm{e}^{-t})^{\ell},\quad\sum_{{B}_{>}}f(\mathrm{k})=o(1)\quad\text{and}\quad\sum_{{B}_{=}}f(\mathrm{k})=o(1),

(3.33)

from which (
3.29
) follows immediately.
We start with the first asymptotic identity in (
3.33
).
The estimate
k_{i}\leq s_{n}+\nu
for all
1\leq i\leq\ell
implies that
k_{1}+\cdots+k_{\ell}\leq\ell(s_{n}+\nu)=o(n)
so that with (
3.31
)

\sum_{{B}_{\leq}}f(\mathrm{k})=\sum_{{B}_{\leq}}\prod_{1\leq i\leq\ell}c_{k_{i}}w_{n}^{k_{i}}=I_{1,1}^{\ell}\sim(\mathrm{e}^{-t})^{\ell}.

Next we show the second claim in (
3.33
). By applying (
3.32
) we obtain

\sum_{{B}_{>}}f(\mathrm{k})=\sum_{{B}_{>}}\prod_{1\leq i\leq\ell}c_{k_{i}}w_{n}^{k_{i}}\leq I_{1,2}\cdot I_{1}^{\ell-1}=o(\mathrm{e}^{-t(\ell-1)})=o(1).

Finally, we show the third asymptotic identity in (
3.33
).
We get

\sum_{{B}_{=}}f(\mathrm{k})\leq\binom{\ell}{2}\sum_{s_{n}<k_{1},\dots,k_{\ell-1}\leq n}f(k_{1},k_{1},k_{2},\dots,k_{\ell})\leq\binom{\ell}{2}\sum_{s_{n}<k\leq n}c_{k}^{2}w_{n}^{2k}\cdot I_{1}^{\ell-2}.

According to Lemma
2.4
and analogous to (
3.32
) we find that

\sum_{k>s_{n}+\nu}c_{k}^{2}w_{n}^{2k}=\mathcal{O}\left(h(s_{n})^{2}s_{n}^{2(\alpha-1)}\mathrm{e}^{-2\beta_{n}(s_{n}+\nu)}\beta_{n}^{-1}\right)=o(1).

Additionally, just as in (
3.30
) and (
3.31
) we compute that

\sum_{s_{n}<k\leq s_{n}+\nu}c_{k}^{2}w_{n}^{2k}\sim h(s_{n})^{2}s_{n}^{2(\alpha-1)}\mathrm{e}^{-2\beta_{n}s_{n}}\sum_{1\leq k\leq\nu}\mathrm{e}^{-2\beta_{n}k}=\mathcal{O}\left((h(s_{n})s_{n}^{\alpha-1}\mathrm{e}^{-\beta_{n}s_{n}}\beta_{n}^{-1})^{2}\beta_{n}\right)=\mathcal{O}\left(\mathrm{e}^{-2t}\beta_{n}\right)=o(1).

Since
I_{1}^{\ell-2}\sim\mathrm{e}^{-t(\ell-2)}
this shows that
\sum_{{B}_{=}}f(\mathrm{k})=o(1)
and we haven proven (
3.33
) and we are done.

Proof of (
3.27
) and (
3.28
).

Let
\ell\in\mathbb{N}
,
\mathrm{k}:=(k_{1},\dots,k_{\ell})\in\mathbb{N}^{\ell}
and recall that

\Omega_{n,\mathrm{k}}:=\{(N_{1},\dots,N_{n})\in\Omega_{n}:\forall 1\leq i\leq\ell:N_{k_{i}}\geq 1\}.

We further abbreviate

\sum_{\Omega_{n,\mathrm{k}}}=\sum_{(N_{1},\dots,N_{n})\in\Omega_{n,\mathrm{k}}},\qquad\Sigma_{\mathrm{k}}:=k_{1}+\cdots+k_{\ell}\qquad\text{and}\qquad[n]_{\neq\mathrm{k}}:=\{1,\dots,n\}\setminus\{k_{1},\dots,k_{\ell}\}.

From here on we treat the two cases “set” and “multiset” seperately.

The set case.

From (
1.5
) we obtain

\displaystyle\mathrm{Pr}\left[\mathsf{S}^{(n)}\in\Omega_{n,\mathrm{k}}\right]

\displaystyle=\frac{1}{[x^{n}]S(x)}\sum_{\Omega_{n,\mathrm{k}}}\prod_{1\leq i\leq n}\frac{c_{i}^{N_{i}}}{N_{i}!}=\frac{1}{[x^{n}]S(x)}\cdot\prod_{1\leq i\leq\ell}c_{k_{i}}\cdot\sum_{\Omega_{n,\mathrm{k}}}\prod_{i\in[n]_{\neq\mathrm{k}}}\frac{c_{i}^{N_{i}}}{N_{i}!}\cdot\prod_{1\leq i\leq\ell}\frac{c_{k_{i}}^{N_{k_{i}}-1}}{N_{k_{i}}!}.

(3.34)

First observe that if
(N_{1},\dots,N_{n})\in\Omega_{n,\mathrm{k}}
we necessarily have that
N_{i}=0
for
i>n-\Sigma_{\mathrm{k}}
. Since further for
N_{k_{i}}\geq 1
the estimate
c_{k_{i}}^{N_{k_{i}}-1}/N_{k_{i}}!\leq c_{k_{i}}^{N_{k_{i}}-1}/(N_{k_{i}}-1)!
holds for
1\leq i\leq\ell
we get that

\displaystyle\sum_{\Omega_{n,\mathrm{k}}}\prod_{i\in[n]_{\neq\mathrm{k}}}\frac{c_{i}^{N_{i}}}{N_{i}!}\cdot\prod_{1\leq i\leq\ell}\frac{c_{k_{i}}^{N_{k_{i}}-1}}{N_{i}!}

\displaystyle\leq\sum_{\Omega_{n-\Sigma_{\mathrm{k}}}}\prod_{i=1}^{n-\Sigma_{\mathrm{k}}}\frac{c_{i}^{N_{i}}}{N_{i}!}=[x^{n-\Sigma_{\mathrm{k}}}]S(x).

All in all, we have shown that

\displaystyle\mathrm{Pr}\left[\mathsf{F}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\leq\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}\cdot\prod_{1\leq i\leq k}c_{k_{i}}.

(3.35)

Lemma
3.1
asserts that
S(x)
is
H
-admissible. Recall the definition of
A_{s}(x)
from (
3.2
) and note that the functions
a(x),b(x)
from (
2.3
) for
f(x)=\ln S(x)
are exactly
A_{1}(x),A_{2}(x)
, compare to (
3.3
) with
\ell=0
. We chose
z_{n}
such that
A_{1}(z_{n})=z_{n}C^{\prime}(z_{n})=n
. Let
\varepsilon>0
. Then Lemma
2.1
reveals that there is some (potentially large but fixed)
K=K(\varepsilon)>0
such that for
n
sufficiently large

\displaystyle\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}\leq(1+\varepsilon)\cdot z_{n}^{\Sigma_{\mathrm{k}}},\quad\text{uniformly in }\mathrm{k}\in\mathbb{N}^{\ell}\text{ with }0<\Sigma_{\mathrm{k}}\leq n-K.

(3.36)

For all
\mathrm{k}\in\mathbb{N}^{\ell}
such that
n-K<\Sigma_{\mathrm{k}}\leq n
we have that
[x^{n-\Sigma_{\mathrm{k}}}]S(x)=\mathcal{O}\left(1\right)
and hence with Lemma
2.1
, noting that
z_{n}\leq\rho\leq 1
,

\displaystyle\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}=\mathcal{O}\left(z_{n}^{n}\sqrt{b(z_{n})}/S(z_{n})\right)=o\big(z_{n}^{\Sigma_{\mathrm{k}}}\big),\quad\text{uniformly in }n-K<\Sigma_{\mathrm{k}}\leq n.

(3.37)

In any case, by combining (
3.35
)–(
3.37
), and since
\ell
is fixed, we obtain for
n
sufficiently large

\displaystyle\mathrm{Pr}\left[\mathsf{S}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\leq(1+\varepsilon)\cdot\prod_{1\leq i\leq\ell}c_{k_{i}}z_{n}^{k_{i}},\quad\text{uniformly in }\mathrm{k}\in\mathbb{N}^{\ell}\text{ with }0<\Sigma_{\mathrm{k}}\leq n.

(3.38)

This shows (
3.28
). Let us next demonstrate that (
3.27
) is valid. In light of (
3.38
) it is left to show that

\displaystyle\mathrm{Pr}\left[\mathsf{S}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\geq(1+o(1))\cdot\prod_{1\leq i\leq\ell}c_{k_{i}}z_{n}^{k_{i}}\quad\text{for }s_{n}<k_{1}<\cdots<k_{\ell}<s_{n}+o(s_{n})\text{ and as }n\to\infty.

(3.39)

For that let
S_{\neq\mathrm{k}}(x)
be the generating series of elements such that there are no clusters of sizes
k_{1},\dots,k_{\ell}
, that is,

\displaystyle S_{\neq\mathrm{k}}(x)=S(x)\cdot T_{1}(x),\quad\text{where}\quad T_{1}(x)=\exp\bigg\{-\sum_{1\leq i\leq\ell}c_{k_{i}}x^{k_{i}}\bigg\}.

(3.40)

Note that for any
s_{n}<k<s_{n}+o(s_{n})
and by plugging in
s_{n}
we get analogous to (
3.30
) (where
\beta_{n}=\eta_{n}
for

c_{k}z_{n}^{k}=h(k)k^{\alpha-1}\mathrm{e}^{-\eta_{n}k}\leq h(s_{n})s_{n}^{\alpha-1}\mathrm{e}^{-\eta_{n}s_{n}}(1+o(1))\sim\eta_{n}=o(1)
. Hence

\displaystyle T_{1}(z_{n})\sim 1.

(3.41)

Writing
\mathsf{S}^{(n)}=(\mathsf{S}_{1}^{(n)},\dots,\mathsf{S}_{n}^{(n)})
, we conclude

\displaystyle\mathrm{Pr}\left[\mathsf{S}^{(n)}\in\Omega_{n,\mathrm{k}}\right]\geq\mathrm{Pr}\left[\forall 1\leq i\leq\ell:\mathsf{S}^{(n)}_{k_{i}}=1\right]=\frac{[x^{n-\Sigma_{\mathrm{k}}}]S_{\neq\mathrm{k}}(x)}{[x^{n}]S(x)}\cdot\prod_{1\leq i\leq\ell}c_{k_{i}}.

(3.42)

We compute

\displaystyle\frac{[x^{n-\Sigma_{\mathrm{k}}}]S_{\neq\mathrm{k}}(x)}{[x^{n}]S(x)}=\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}+\sum_{1\leq u\leq n}\frac{[x^{n-\Sigma_{\mathrm{k}}-u}]S(x)}{[x^{n}]S(x)}[x^{u}]T_{1}(x).

(3.43)

Analogous to (
3.36
) and (
3.37
) we obtain due to (
3.41
)

\displaystyle\sum_{1\leq u\leq n}\frac{[x^{n-\Sigma_{\mathrm{k}}-u}]S(x)}{[x^{n}]S(x)}[x^{u}]T_{1}(x)=\mathcal{O}\bigg(z_{n}^{\Sigma_{\mathrm{k}}}\sum_{u\geq 1}[x^{u}]T_{1}(x)z_{n}^{u}\bigg)=\mathcal{O}\big(z_{n}^{\Sigma_{\mathrm{k}}}T_{1}(z_{n})\big)=o\big(z_{n}^{\Sigma_{\mathrm{k}}}\big).

(3.44)

Next we show that the first term on the right-hand side of (
3.43
) is asymtotically equal to
z_{n}^{\Sigma_{\mathrm{k}}}
.
Since
\Sigma_{\mathrm{k}}=\mathcal{O}(\eta_{n}^{-1}\ln C(z_{n}))=o(n)
for
s_{n}<k_{1}<\cdots<k_{\ell}<s_{n}+o(s_{n})
due to (
3.22
) and (
3.26
) we obtain by Lemma
2.1
as

\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}=z_{n}^{\Sigma_{\mathrm{k}}}\bigg(\exp\bigg\{-\frac{\big(A_{1}(z_{n})-(n-\Sigma_{\mathrm{k}})\big)^{2}}{2A_{2}(z_{n})}\bigg\}+o(1)\bigg).

Since
A_{1}(z_{n})=n
we just need to show that
\Sigma_{\mathrm{k}}^{2}/b(z_{n})=o(1)
. We compute, noting that
A_{2}(z_{n})=\Theta(h(\eta_{n}^{-1})\eta_{n}^{-(\alpha+2)})
according to Lemma
2.3
,

\displaystyle\frac{\Sigma_{\mathrm{k}}^{2}}{A_{2}(z_{n})}=\mathcal{O}\left(\eta_{n}^{\alpha}\cdot\ln^{2}C(z_{n})\cdot h(\eta_{n}^{-1})\right)=o(1).

(3.45)

Concluding, we obtain by plugging in (
3.44
) into (
3.43
) that

\frac{[x^{n-\Sigma_{\mathrm{k}}}]S_{\neq\mathrm{k}}(x)}{[x^{n}]S(x)}=(1+o(1))\cdot z_{n}^{\Sigma_{\mathrm{k}}},\quad\text{for }s_{n}<k_{1}<\cdots<k_{\ell}<s_{n}+o(s_{n})\text{ and as }n\to\infty,

which in turn brings with (
3.42
) that (
3.39
) is true. This concludes the proof of (
3.27
). The set case is completed and we move on to the multiset case.

The multiset case.

). Replacing

(3.48)

,

) with

\displaystyle\frac{[x^{n-\Sigma_{\mathrm{k}}}]S(x)}{[x^{n}]S(x)}=w_{n}^{\Sigma_{\mathrm{k}}}\bigg(\exp\bigg\{-\frac{\big(A_{1,1}(w_{n})-(n-\Sigma_{\mathrm{k}})\big)^{2}}{2A_{2,2}(w_{n})}\bigg\}+o(1)\bigg)

(3.49)

Start with

(3.50)

Now consider

C(z_{n})\sim\Gamma(\alpha)h(\eta_{n}^{-1})\eta_{n}^{-\alpha}\sim\alpha^{-1}\Gamma(\alpha+1)^{1/(\alpha+1)}\cdot g(n)\cdot n^{\alpha/(\alpha+1)}.

Consequently
\limsup N^{\prime}/N_{n}^{*}<1
and
N^{\prime}/N_{n}^{*}=\Theta(1)
. Let
(x_{n},y_{n})=(x_{n,N^{\prime}},y_{n,N^{\prime}})
be the solution to (
3.57
). Then
[
23
, Thm. 1(I)]
together with Theorem
1.1
reveal that

\displaystyle\frac{g_{n,N^{\prime}}}{g_{n}}\sim\frac{\exp\left\{\sum_{j\geq 2}C(\rho^{j})y_{n}^{j}/j\right\}}{\exp\left\{\sum_{j\geq 2}C(\rho^{j})/j\right\}}\cdot\frac{\exp\left\{y_{n}C(x_{n})-C(z_{n})\right\}}{\sqrt{2\pi N^{\prime}y_{n}x_{n}^{2}C^{\prime\prime}(x_{n})/((\alpha+1)z_{n}^{2}C^{\prime\prime}(z_{n}))}}\cdot\left(\frac{z_{n}}{x_{n}}\right)^{n}\cdot y_{n}^{-N^{\prime}}.

(3.60)

In the remaining proof we show that
z_{n}/x_{n}
and
y_{n}
are so close to
1
that the right-hand side of (
3.60
) is asymptotically
(2\pi N^{\prime}/(\alpha+1))^{-1/2}\mathrm{e}^{-t^{2}/2}
. For that we first repeat some important properties of
(x_{n},y_{n})
from
[
23
, Lem. 4.1]
, that is,

\displaystyle x_{n}\sim\rho,\quad\limsup_{n\to\infty}y_{n}<\rho^{-m}\quad\text{and}\quad S_{n}:=\frac{x_{n}^{m}y_{n}}{1-x_{n}^{m}y_{n}}=\Theta(1).

(3.61)

Parametrize
x_{n}=z_{n}\mathrm{e}^{\delta_{n}}
for an appropriate
\delta_{n}
. We first show that

\displaystyle\delta_{n}=o(\eta_{n}).

(3.62)

By (
3.57
) and (
3.61
) we have that
y_{n}C(x_{n})\sim C(z_{n})+L\sim C(z_{n})
and
x_{n}y_{n}C^{\prime}(x_{n})\sim n=z_{n}C^{\prime}(z_{n})
. Plugging in
x_{n}=z_{n}\mathrm{e}^{\delta_{n}}=\rho\mathrm{e}^{-(\eta_{n}-\delta_{n})}
we obtain by Lemma
2.3

C(z_{n})\sim y_{n}C(x_{n})\sim y_{n}\Gamma(\alpha)h(\eta_{n}-\delta_{n})(\eta_{n}-\delta_{n})^{-\alpha}\sim y_{n}C(z_{n})\frac{h(\eta_{n}-\delta_{n})}{h(\eta_{n})}\frac{(\eta_{n}-\delta_{n})^{-\alpha}}{\eta_{n}^{-\alpha}}

implying that

\displaystyle y_{n}\frac{h(\eta_{n}-\delta_{n})}{h(\eta_{n})}\frac{(\eta_{n}-\delta_{n})^{-\alpha}}{\eta_{n}^{-\alpha}}\sim 1.

(3.63)

Analogously

n\sim x_{n}y_{n}C^{\prime}(x_{n})\sim y_{n}z_{n}C^{\prime}(z_{n})\frac{h(\eta_{n}-\delta_{n})}{h(\eta_{n})}\frac{(\eta_{n}-\delta_{n})^{-(\alpha+1)}}{\eta_{n}^{-(\alpha+1)}}

implying that

\displaystyle y_{n}\frac{h(\eta_{n}-\delta_{n})}{h(\eta_{n})}\frac{(\eta_{n}-\delta_{n})^{-(\alpha+1)}}{\eta_{n}^{-(\alpha+1)}}\sim 1.

(3.64)

Combining (
3.63
) and (
3.64
) we obtain that
(\eta_{n}-\delta_{n})/\eta_{n}\sim 1
implying (
3.62
).

In what follows we use, without mentioning it every time, that
\delta_{n}=o(\eta_{n})
and Lemma
2.3
imply

z_{n}^{k}C^{(k)}(z_{n})\delta_{n}=\Theta(h(\eta_{n}^{-1})\eta_{n}^{-(\alpha+k)}\delta_{n})=o(h(\eta_{n}^{-1})\eta_{n}^{-(\alpha+k-1)})=o(C^{(k-1)}(z_{n})),\quad k\in\mathbb{N}.

Next we expand
C(z_{n}\mathrm{e}^{\delta})
at
\delta=0
. Since
\delta_{n}=o(\eta_{n})
and
y_{n}=\mathcal{O}\left(1\right)
we obtain that

\displaystyle y_{n}C(x_{n})

\displaystyle=y_{n}C(z_{n})+y_{n}z_{n}C^{\prime}(z_{n})\delta_{n}+y_{n}z_{n}^{2}C^{\prime\prime}(z_{n})\delta_{n}^{2}/2+o(C^{\prime\prime}(z_{n})\delta_{n}^{2})

(3.65)

\displaystyle=y_{n}C(z_{n})+y_{n}z_{n}C^{\prime}(z_{n})\delta_{n}+o(y_{n}C^{\prime}(z_{n})\delta_{n}).

Then the second identity in (
3.57
) gives

N^{\prime}=y_{n}C(z_{n})+y_{n}z_{n}C^{\prime}(z_{n})\delta_{n}+c_{m}S_{n}+o(C^{\prime}(z_{n})\delta_{n}).

Recalling that
N^{\prime}=C(z_{n})+L
and dividing both sides by
C(z_{n})
entails that
y_{n}\sim 1
and

\displaystyle y_{n}=1+\frac{L-c_{m}S}{C(z_{n})}-\frac{z_{n}C^{\prime}(z_{n})}{C(z_{n})}\delta_{n}+o\bigg(\frac{C^{\prime}(z_{n})}{C(z_{n})}\delta_{n}\bigg).

(3.66)

We proceed similarly with the second identity in (
3.57
). Expanding
z_{n}\mathrm{e}^{\delta}y_{n}C^{\prime}(z_{n}\mathrm{e}^{\delta})
around
\delta=0
and using (
3.62
) yields

\displaystyle x_{n}y_{n}C^{\prime}(x_{n})

\displaystyle=y_{n}z_{n}C^{\prime}(z_{n})+y_{n}(z_{n}C^{\prime}(z_{n})+z_{n}^{2}C^{\prime\prime}(z_{n}))\delta_{n}+\mathcal{O}\left(C^{\prime\prime\prime}(z_{n})\delta_{n}^{2}\right)

\displaystyle=y_{n}n+y_{n}z_{n}C^{\prime\prime}(z_{n})\delta_{n}+o(C^{\prime\prime}(z_{n})\delta_{n}).

(3.67)

Note that Lemma
2.3
implies that
C^{\prime\prime}(z_{n})=\Theta(C^{\prime}(z_{n})^{2}/C(z_{n}))=\Theta(nC^{\prime}(z_{n})/C(z_{n}))
. Keeping this in mind, we plug in
(
3.67
) and
y_{n}
from (
3.66
) into the first equation of (
3.57
) to obtain

\displaystyle n

\displaystyle=y_{n}n+y_{n}z_{n}^{2}C^{\prime\prime}(z_{n})\delta_{n}+o(C^{\prime\prime}(z_{n})\delta_{n})+mc_{m}S_{n}

\displaystyle=n+n\frac{L-c_{m}S}{C(z_{n})}+\delta_{n}\bigg(z_{n}^{2}C^{\prime\prime}(z_{n})-n\frac{z_{n}C^{\prime}(z_{n})}{C(z_{n})}\bigg)+o(C^{\prime\prime}(z_{n})\delta_{n})+mc_{m}S_{n}.

Since
S_{n}=\Theta(1)
due to (
3.61
) this implies together with Lemma
2.3
that

\delta_{n}\sim-n\frac{L-c_{m}S}{C(z_{n})}\bigg(z_{n}^{2}C^{\prime\prime}(z_{n})-n\frac{z_{n}C^{\prime}(z_{n})}{C(z_{n})}\bigg)^{-1}\sim-\alpha\frac{L-c_{m}S}{n}.

This, in turn, implies with (
3.66
) that

y_{n}=1+(\alpha+1)\frac{L-c_{m}S_{n}}{C(z_{n})}+o\bigg(\frac{L-c_{m}S_{n}}{C(z_{n})}\bigg).

It follows that there are
\alpha_{n}=o(L/n)
and
\beta_{n}=o(L/C(z_{n}))
such that

\displaystyle\delta_{n}=-\alpha\frac{L-c_{m}S_{n}}{n}+\alpha_{n}\quad\text{and}\quad y_{n}=1+(\alpha+1)\frac{L-c_{m}S_{n}}{C(z_{n})}+\beta_{n}.

(3.68)

Recall that
L\sim t\sqrt{C(z_{n})/(\alpha+1)}
and
S_{n}=\Theta(1)
due to (
3.61
). Plugging this and the expressions for
\delta_{n},y_{n}
into (
3.65
) as well as using Lemma
2.3
for
C(z_{n}),z_{n}C^{\prime}(z_{n})=n,z_{n}^{2}C^{\prime\prime}(z_{n})
yields

\displaystyle y_{n}C(x_{n})

\displaystyle=y_{n}C(z_{n})+y_{n}z_{n}C^{\prime}(z_{n})\delta_{n}+y_{n}z_{n}^{2}C^{\prime\prime}(z_{n})\delta_{n}^{2}/2+o(C^{\prime\prime}(z_{n})\delta_{n}^{2})

\displaystyle=C(z_{n})+(\alpha+1)(L-c_{m}S_{n})+\beta_{n}C(z_{n})+-\alpha(L-c_{m}S)+\alpha_{n}n

\displaystyle\quad-\alpha(\alpha+1)\frac{L^{2}}{C(z_{n})}+z_{n}^{2}C^{\prime\prime}(z_{n})\frac{\alpha^{2}}{2}\frac{L^{2}}{n^{2}}+o(1)

\displaystyle=C(z_{n})+L-c_{m}S_{n}+\beta_{n}C(z_{n})+\alpha_{n}n-\frac{\alpha}{2}t^{2}+o(1).

Plugging this into the second identity of (
3.57
) entails

\displaystyle N^{\prime}=y_{n}C(x_{n})+c_{m}S_{n}\Rightarrow\beta_{n}C(z_{n})+\alpha_{n}n=\frac{\alpha}{2}t^{2}+o(1).

(3.69)

With (
3.68
) at hand we obtain that

\bigg(\frac{z_{n}}{x_{n}}\bigg)^{n}=\mathrm{e}^{-\delta_{n}n}=\mathrm{e}^{\alpha(L-c_{m}S_{n})-\alpha_{n}n}

and

y_{n}^{-N^{\prime}}\sim\bigg(1+(\alpha+1)\frac{L-c_{m}S_{n}}{C(z_{n})}+\beta_{n}\bigg)^{-C(z_{n})+t\sqrt{C(z_{n})/(\alpha+1)}}\sim\mathrm{e}^{-(\alpha+1)(L-c_{m}S_{n})-t^{2}-\beta_{n}C(z_{n})+(\alpha+1)t^{2}/2}.

Combining the previous two displays with (
3.69
) delivers

\bigg(\frac{z_{n}}{x_{n}}\bigg)^{n}y_{n}^{-N^{\prime}}=\mathrm{e}^{\alpha(L-c_{m}S_{n})-\alpha_{n}n-(\alpha+1)(L-c_{m}S_{n})-t^{2}-\beta_{n}C(z_{n})+(\alpha+1)t^{2}/2}\sim\mathrm{e}^{L-c_{m}S_{n}-t^{2}/2}.

From
N^{\prime}=y_{n}C(x_{n})+c_{m}S_{n}
we directly get
y_{n}C(x_{n})-C(z_{n})=L-c_{m}S_{n}
so that

\exp\left\{y_{n}C(x_{n})-C(z_{n})\right\}\cdot\bigg(\frac{z_{n}}{x_{n}}\bigg)^{n}\cdot y_{n}^{-N^{\prime}}\sim\mathrm{e}^{-t^{2}/2}.

Since
\delta_{n}=o(\eta_{n})
as showed in (
3.62
) we obtain that
z_{n}^{2}C^{\prime\prime}(z_{n})\sim x_{n}^{2}C^{\prime\prime}(x_{n})
. Concluding, and plugging in
y_{n}\sim 1
, we obtain in (
3.60
)

\frac{g_{n,N^{\prime}}}{g_{n}}\sim\frac{1}{\sqrt{2\pi N^{\prime}/(\alpha+1)}}\mathrm{e}^{-t^{2}/2}\sim\frac{1}{\sqrt{2\pi C(z_{n})/(\alpha+1)}}\mathrm{e}^{-t^{2}/2}

as claimed.
∎
