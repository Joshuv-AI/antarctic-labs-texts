Deterministic Distributed algorithms and Descriptive Combinatorics on Δ \Delta -regular trees This paper is an extension of some parts of the conference paper “Local Problems on Trees from the Perspectives of Distributed Algorithms, Finitary Factors, and Descriptive Combinatorics (arXiv:2106.02066)” presented at the 13th Innovations in Theoretical Computer Science Conference (ITCS 2022).
Sebastian Brandt, Yi-Jun Chang, Jan Grebík, Christoph Grunau, Václav Rozhoň, Zoltán Vidnyánszky

Abstract
We study complexity classes of local problems on regular trees from the perspective of distributed local algorithms and descriptive combinatorics. We show that, surprisingly, some deterministic local complexity classes from the hierarchy of distributed computing exactly coincide with well studied classes of problems in descriptive combinatorics. Namely, we show that a local problem admits a continuous solution if and only if it admits a local algorithm with local complexity O ⁡ ( log ∗ ⁡ n ) O(\log^{*}n) , and a Baire measurable solution if and only if it admits a local algorithm with local complexity O ⁡ ( log ⁡ n ) O(\log n) .

2.1
Local Problems on
\Delta

The problems we study in this work are locally checkable labeling (LCL) problems, which, roughly speaking, are problems that can be described via local constraints that have to be satisfied in a neighborhood of each vertex.
In the context of distributed algorithms, these problems were introduced in the seminal work by Naor and Stockmeyer
[
NS95

In the modern formulation introduced in
[

This formulation is very general in that it not only captures vertex and edge labeling problems, but also others such as orientation problems, or combinations of all of these types.
Before we can provide this general definition of an LCL, we need to introduce some definitions.
We start by formalizing the notion of a half-edge.

We illustrate the difference between our setting and the “standard setting” without virtual half-edges on the perfect matching problem.
A standard definition of the perfect matching problem is that some edges are picked in such a way that each vertex is covered by exactly one edge.
It is easy to see that there is no local algorithm to solve this problem on the class of finite trees (without virtual half-edges), this is a simple parity argument.
However, in our setting, every vertex needs to pick exactly one half-edge (real or virtual) in such a way that both endpoints of each edge are either picked or not picked.
We remark that in our setting it is not difficult to see that (if

2.2
The
\mathsf{LOCAL}
model

In this section, we define local algorithms and local complexity.
In this work we focus exclusively on
deterministic
local algorithms.
Recall that our setup is informally the following. We are given a graph
G
, where each vertex is a computer, which knows the size of the graph
n
, and perhaps some other parameters like the maximum degree
\Delta
. In the case of randomized algorithms, each vertex has access to a private random bit string, while in the case of deterministic algorithms, each vertex is equipped with a unique identifier from a range polynomial in the size
n
of the network. Every vertex must run the same algorithm. In one round, each vertex can exchange any message with its neighbors and can perform an arbitrary computation. The goal is to find a solution to a given LCL in as few communication rounds as possible. An algorithm is correct if and only if the collection of outputs at all vertices constitutes a correct solution to the problem. As the allowed message size is unbounded, a
t
-round
\mathsf{LOCAL}
algorithm can be equivalently described as a function that maps
t
-neighborhoods to outputs—the output of a vertex is then simply the output of this function applied to the
t
-neighborhood of this vertex. Hence, we arrive to the following definition.

Definition 2.4

(Local algorithm)
.

Let
\Sigma
be a set of labels.
A
distributed local algorithm

\mathcal{A}
of local complexity
t(n)
is a function that takes as an input the (isomorphism type as a rooted graph)
t(n)
-neighborhood of a vertex
u
together with the identifiers of each vertex in the neighborhood and the size of the graph
n
, and outputs a label
\in\Sigma
for each half-edge adjacent to
u
.

Applying an algorithm
\mathcal{A}
on an input graph
G
of size
n
means that the function is applied to a
t(n)
-neighborhood
B_{G}(u,t(n))
of each vertex
u
of
G
. The output of the function is a labeling of the half-edges around the vertices.

Definition 2.5

(Local complexity)
.

We say that an LCL problem
\Pi
has a
deterministic local complexity

t(n)
if there is a local algorithm
\mathcal{A}
of local complexity
t(n)
such that when run on an input graph
G
, with each of its vertices having a unique identifier from
[n^{C}]
for some absolute constant
C>0
,
\mathcal{A}
always returns a correct solution to
\Pi
.
We write
\Pi\in\mathsf{LOCAL}(O(t(n))
.

We note for completeness that
randomized local complexity
is defined similarly, the difference is that the unique identifiers at each vertex are replaced with sequences of independent random strings, and we allow the algorithm to fail with probability at most
1/n
.

Recall that
\log^{*}n
stands for the iterated logarithm of
n
, that is,
\log^{*}n
is the number of times the logarithm function must be iteratively applied to
n
before the result is
\leq 1
. The threshold
\log^{*}n
plays a crucial role in distributed computing, as it is a classical result that graphs with degrees bounded by
\Delta
can be
\Delta+1
-colored in
O(\log^{*}n)
-many rounds, or in our terminology,
\Delta+1
-coloring is in
\mathsf{LOCAL}(O(\log^{*}n)).

For functions
f,g:\mathbb{N}\to\mathbb{N}
we use the notation
f(n)=\Omega(g(n))
if
\liminf_{n\to\infty}\frac{f(n)}{g(n)}>0
and
f(n)=\Theta(g(n))
if
f(n)=O(g(n))
and
f(n)=\Omega(g(n)).

Classification of Local Problems on
\Delta
-regular Trees

There has been a lot of work done aiming to classify all possible local complexities of LCL problems on bounded degree trees. This classification was recently finished (see the citations in

2.6

Even though the results in the literature are stated for the classical notion of trees with a degree bounded by constant, we note that one can check that the same picture emerges if we restrict ourselves even further to

[

]
.
For our purposes, we only need to recall the classification in the deterministic setting.

Theorem 2.6

(Classification of deterministic local complexities of LCLs on

2.3
Rake and Compress

Although the classification of LCLs on (
\Delta
-regular) trees is fully understood (see
Theorem

2.6
), and we use it as a black box, there is a particular technique, called rake-and-compress decomposition, that is useful for us.
We define the two operations
Rake
and
Compress
as follows, where the operation
Compress
is parameterized by a positive integer
\ell
.

Rake
:

Remove all leaves and isolated vertices.

Compress
:

Remove all vertices that belong to some path
P
such that (i) all vertices in
P
have degree at most
2
and (ii) the number of vertices in
P
is at least
\ell
.

The rake-and-compress process was first defined in
[
MR89
]
. It was later generalized and applied in the study of the
\mathsf{LOCAL}
model
[
CP19
,
CHL+20
,
Cha20
,
BBO+21
]
. We consider the following version of rake-and-compress.

Definition 2.7

(Rake-and-compress process)
.

Given two positive integers
\gamma
and
\ell
, the rake-and-compress process on a tree
T
is defined as follows. For
i=1,2,3,\ldots
, until all vertices are removed, perform
\gamma
number of
Rake
and then perform one
Compress
.
We write
{V}_{i}^{\textsf{R}}
to denote the set of vertices removed during the
Rake
operations in the
i
-th iteration and we write
{V}_{i}^{\textsf{C}}
to denote the set of vertices removed during the
Compress
operation in the
i
-th iteration.

It is clear that
V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup\cdots
in
Definition

2.7
, and this is called a rake-and-compress decomposition. We define the
depth
of the decomposition as the smallest number
d
such that
V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup\cdots\cup{V}_{d}^{\textsf{R}}
. That is,
d
is the smallest iteration number such that by the time we finish all the
Rake
operations in the
d
-th iteration, all vertices have been removed. The following lemma gives an upper bound
L
on the depth
d
of the decomposition.

Lemma 2.8

(
[
CP19
]
)
.

In the rake-and-compress decomposition of an
n
-vertex tree
T
with
\ell=O(1)
and
\gamma=1
, we have
V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup\cdots\cup{V}_{L}^{\textsf{R}}
for some
L=O(\log n)
.

Local Complexity

Once we have an upper bound
L\geq d
on the depth
d
of the decomposition, it is clear that the rake-and-compress decomposition of
Definition

2.7
can be computed in
O((\ell+\gamma)L)
rounds. For example, if
\ell=O(1)
and
\gamma=1
, then
Lemma

2.8
implies that

, so the decomposition algorithm finishes in
O((\ell+\gamma)L)=O(\log n)
rounds.

Post-processing

Now we focus on the case of
\gamma=1
and
\ell=O(1)
.
As
\gamma=1
, each connected component in the subgraph induced by
{V}_{i}^{\textsf{R}}
is either a single vertex or an edge. Each connected component in the subgraph induced by
{V}_{i}^{\textsf{C}}
is a path of at least
\ell
vertices.

For some applications, it is desirable that each
{V}_{i}^{\textsf{R}}
is an independent set and each
{V}_{i}^{\textsf{C}}
is a collection of paths of
O(1)
vertices. By doing a post-processing step to modify the given rake-and-compress decomposition

, it is possible to attain these properties. Specifically, we have the following lemma.

Lemma 2.9

(Rake-and-compress decomposition with post-processing
[
CP19
]
)
.

Given any constant integer
\ell^{\prime}\geq 1
, there is an
O(\log n)
-round
\mathsf{LOCAL}
algorithm that decomposes the vertices of an
n
-vertex tree
T
into
2L-1
layers

V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup{V}_{3}^{\textsf{R}}\cup{V}_{3}^{\textsf{C}}\cup\cdots\cup{V}_{L}^{\textsf{R}},

with
L=O(\log n)
satisfying the following requirements.

•

For each
1\leq i\leq L
,
{V}_{i}^{\textsf{R}}
is an independent set, and each
v\in{V}_{i}^{\textsf{R}}
has at most one neighbor in
{V}_{L}^{\textsf{R}}\cup{V}_{L-1}^{\textsf{C}}\cup{V}_{L-1}^{\textsf{R}}\cup\cdots\cup{V}_{i}^{\textsf{C}}
.

•

For each
1\leq i\leq L-1
,
{V}_{i}^{\textsf{C}}
is a collection of disjoint paths
P_{1},P_{2},\ldots,P_{k}
, where each
P_{j}=(v_{1},v_{2},\ldots,v_{s})
satisfies the following requirements.

–

The number
s
of vertices in

satisfies
\ell^{\prime}\leq s\leq 2\ell^{\prime}
.

–

There are two vertices

and
w
in

is adjacent to

, and

and

.

Proof.

We first compute a rake-and-compress decomposition
V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup{V}_{3}^{\textsf{R}}\cup{V}_{3}^{\textsf{C}}\cup\cdots
of
Definition

2.7
with parameters
\ell=\ell^{\prime}
and
\gamma=1
. By
Lemma

2.8
, the decomposition can be computed in

rounds in the
\mathsf{LOCAL}
model.

To satisfy all the requirements, we consider the following post-processing step, which takes

rounds to perform. For each

, the vertex set

is a collection of non-adjacent vertices and edges. For each edge
\{u,v\}
with
u\in{V}_{i}^{\textsf{R}}
and

u
and

to

.
For each

is a collection of disjoint paths of at least

satisfying the following conditions.

•

is an independent set that does not contain either endpoint of

.

•

Each connected component of the subgraph induced by

has at least
\ell^{\prime}
vertices and at most

Then we promote all the vertices in
I
to
{V}_{i+1}^{\textsf{R}}
. As
\ell^{\prime}=O(1)
, such an independent set

can be computed in
O(\log^{\ast}n)

,
CV86
]
.
It is straightforward to verify that the new decomposition

after the modification satisfies all the requirements. By
Lemma

2.8
, there is
L=O(\log n)
such that
V(T)={V}_{1}^{\textsf{R}}\cup{V}_{1}^{\textsf{C}}\cup{V}_{2}^{\textsf{R}}\cup{V}_{2}^{\textsf{C}}\cup{V}_{3}^{\textsf{R}}\cup{V}_{3}^{\textsf{C}}\cup\cdots\cup{V}_{L}^{\textsf{R}}
.
∎

2.4
Descriptive combinatorics

Before we define formally the descriptive combinatorics complexity classes, we give a high-level overview on their connection to distributing computing for the readers more familiar with the latter.

The complexity class that partially captures deterministic local complexity classes and hints the additional computation power that one can gets in the infinite setting is called
\mathsf{BOREL}
.
First, by a result of Kechris, Solecki and Todorčević
[
KST99
]
the
maximal independent set problem
is in this class for any bounded degree graph.
5
5

5

That is, it is possible to find a Borel maximal independent set, i.e., a maximal independent set which is, moreover, a Borel subset of the vertex set.

In particular, this yields that
\mathsf{BOREL}
contains the class
\mathsf{LOCAL}(O(\log^{*}n))
by the characterization of
[
CKP19
]
, see
[
Ber20a
]
.
Moreover, (see the definition below)
\mathsf{BOREL}
is closed under countably many iterations of the operations of finding a maximal independent set in some power of the graph, and of applying a constant local rule that takes into account what has been constructed previously.
Therefore, the constructions in the class
\mathsf{BOREL}
can use some unbounded, global, information.

The “truly” local class in descriptive combinatorics is the class
\mathsf{CONTINUOUS}
.
As above the inclusion
\mathsf{LOCAL}(O(\log^{*}n))\subseteq\mathsf{CONTINUOUS}
holds in most reasonable classes of bounded degree graphs since it is possible to solve the maximal independent set problem in a continuous manner, see
[
Ber20a
]
.
In the paper
[
Ber21
]
, Bernshteyn showed that, in the context of
Cayley graphs
of countable groups, this class admits various equivalent definitions and the inclusion is in fact equality.

Another complexity class that we consider in this paper is the class
\mathsf{BAIRE}
.
This is a topological relaxation of the class
\mathsf{BOREL}
, namely, a LCL is in the class
\mathsf{BAIRE}
if there is a Borel solution that can be incorrect on a topologically negligible set.
The main advantage of the class
\mathsf{BAIRE}
is that it admits a hierarchical decomposition that is called
toast
.
The independence of colorings on a tree together with this structure allows for a combinatorial characterization of the class
\mathsf{BAIRE}
, which was proven by Bernshteyn
[
Ber
]
, see also
Section

4
.

Basic definitions

A
Polish space
is a separable, completely metrizable topological space. A prime example of a Polish space is the real numbers. A Polish space is called
zero-dimensional
if it admits a basis consisting of clopen sets. The two most important examples of zero-dimensional Polish spaces are the collection of irrational numbers (as a subspace of
\mathbb{R}
) and the Cantor set. In fact, the former captures the structure of general zero-dimensional Polish spaces, while the latter captures the structure of compact ones; essentially, one can always imagine that we are working on one of these spaces.
Recall that the collection of
Borel subsets
of a topological space is the minimal family of sets which contains all open sets and closed under taking complements and countable unions. The family of Borel sets has sufficient closure properties so that most of the simply defined sets are contained in them. On the other hand, Borel sets still behave intuitively, that is, their category does not exhibit the paradoxes arising from the Axiom of Choice (e.g., Banach-Tarski). Since a graph on a space
X
can be identified with a subset of
X^{2}
, we can talk about a graph being closed or Borel etc.

Recall that in a topological space
(X,\tau)
, a set
C\subseteq X
is
\tau
-meager
(or meager if the topology is clear) if it can be covered by countably many
\tau
-closed sets with empty interior.
In Polish spaces, the collection of meager sets form a
\sigma
-ideal,
[
Kec95
, Section 8]
.
This provides the notion of small sets in the same way as does the
\sigma
-ideal of null sets in measure spaces.
A set
C\subseteq X
is
comeager
if
X\setminus C
is meager.
Let
X
be a standard Borel space, we say that a Polish topology
\tau
on
X
is
compatible
if the fixed original
\sigma
-algebra on
X
and the
\tau
-Borel
\sigma
-algebra are the same.

We refer the reader to
[
Pik21
,
KM20
,
Ber20a
,
Kec95
]
, or to
[
GR21a
, Introduction, Section 4.1]
and
[
GR21b
, Section 7.1, 7.2]
for intuitive examples and standard facts of descriptive set theory.

2.4.1
\mathsf{CONTINUOUS}

Let
X
be a zero-dimensional Polish space. We follow Bernshteyn
[
Ber21
, Section 2]
and say that a graph
\mathcal{G}\subseteq X\times X
is a
continuous graph
, if the neighborhood
N_{\mathcal{G}}(U)
of any clopen set
U
is clopen.

Definition 2.10

(Continuous Tree)
.

A
continuous (
\Delta
-regular) tree
6
6

6

Note that here we abuse the terminology, as these objects are typically called forests; however, we believe that this fits nicer into the general picture, which we are presenting.

\mathcal{T}
on
X
is an acyclic
\Delta
-regular continuous graph.
We define
\mathcal{H}(\mathcal{T})
to be the set of all half-edges of
\mathcal{T}
.

The set
\mathcal{H}(\mathcal{T})
carries a canonical zero-dimensional Polish topology inherited from

, namely, every pair of clopen sets

determines a clopen set
(U\times V)\cap\mathcal{T}
in the space

, where
\mathcal{H}(\mathcal{T})
can be thought of as a set of ordered edges.
Another concrete way how to describe the topology is as follows.
By
[

such that vertices at distance at most

.
Then

can be defined as a disjoint union of clopen sets of the form

, where

and

are half-edges adjacent to

\mathsf{CONTINUOUS}

.

Let

We say that

is different than the one given in the introduction (intuitive description of the

The space of labelings

Recall that
T_{\Delta}
is the
\Delta
-regular tree and we pick a distinguished vertex
\mathfrak{r}
which we call
the root
.
We write
\operatorname{Aut}(T_{\Delta})
for the group of all automorphisms of
T_{\Delta}
and
\operatorname{Aut}^{o}(T_{\Delta})
for the subgroup that fixes
\mathfrak{r}
.
Endowed with pointwise-convergence, or equivalently, subspace topology form
{T_{\Delta}}^{T_{\Delta}}
,
\operatorname{Aut}(T_{\Delta})
is a Polish group and
\operatorname{Aut}^{o}(T_{\Delta})
is a compact subgroup with countable index (see,
[
Gao08
, Theorem 2.4.4]
).
We write
\operatorname{id}_{T_{\Delta}}
for the identity in
\operatorname{Aut}(T_{\Delta})
.

For a set
b
, we define
b^{T_{\Delta}}
to be the space of all
b
-labelings of vertices of
T_{\Delta}
.
We endow
b^{T_{\Delta}}
with the product topology, where
b
is viewed as a discrete space.
The shift action
\operatorname{Aut}(T_{\Delta})\curvearrowright b^{T_{\Delta}}
is defined as

g\cdot x(v)=x(g^{-1}(v)),

where
g\in\operatorname{Aut}(T_{\Delta})
,
x\in b^{T_{\Delta}}
and
v\in T_{\Delta}
.

Definition 2.12
.

Write
b^{T_{\Delta}}/\sim
for the quotient space of the action
\operatorname{Aut}^{o}(T_{\Delta})\curvearrowright b^{T_{\Delta}}
.
That is,
x\sim y
if and only if there is
g\in\operatorname{Aut}^{o}(T_{\Delta})
so that
g\cdot x=y
.
Given
x\in b^{T_{\Delta}}
, we let
[x]\in b^{T_{\Delta}}/\sim
to be the
\sim
-equivalence class of
x
.

The graph
\mathcal{G}_{b,\Delta}
on
b^{T_{\Delta}}/\sim
is defined as follows:
[x]
and
[y]
form an edge in
\mathcal{G}_{b,\Delta}
if and only if for every
z\in[x]
there is a
g\in\operatorname{Aut}(T_{\Delta})
that moves the root to one of its neighbors so that
g\cdot z\in[y]
.

It is easy to see that
\mathcal{G}_{b,\Delta}
is not a continuous tree, as it contains cycles and even loops.
For convenience, we extend the notion of a continuous graph to this setting.

Proposition 2.13
.

The quotient space
b^{T_{\Delta}}/\sim
is a compact zero-dimensional Polish space and the graph
\mathcal{G}_{b,\Delta}
is a continuous graph of degree at most
\Delta
.

Proof.

The space
b^{T_{\Delta}}
is a compact metric space.
Write
d
for the standard compatible metric, that is,
d(x,y)=2^{-k-1}
if the first vertex where
x
and
y
differ is at a distance
k
from the root
\mathfrak{r}
.
It is a standard fact that the action
\operatorname{Aut}^{o}(T_{\Delta})\curvearrowright b^{T_{\Delta}}
is continuous.
Define the metric
d/\sim
on
b^{T_{\Delta}}/\sim
as

d/\sim([x],[y])=\inf\{d(x^{\prime},y^{\prime}):x^{\prime}\in[x],\ y^{\prime}\in[y]\}

where
x,y\in b^{T_{\Delta}}
.
Equivalently,
d/\sim([x],[y])=2^{-k-1}
is the minimal
k\in\mathbb{N}
so that
x
and
y
do not have isomorphic labeled
k
-neighborhood of
\mathfrak{r}
.
As
\operatorname{Aut}^{o}(T_{\Delta})
is compact, we have that
d/\sim([x],[y])=0
if and only if
[x]=[y]
.
It is routine to verify that
d/\sim
is a compatible metric for the quotient topology and that a clopen basis is given by labeled
k
-neighborhoods of
\mathfrak{r}
considered up to isomorphism.
This shows that
b^{T_{\Delta}}/\sim
is a compact zero-dimensional Polish space.

The root
\mathfrak{r}
of
T_{\Delta}
has exactly
\Delta
-many neighbours.
Let
g_{1},\dots,g_{\Delta}\in\operatorname{Aut}(T_{\Delta})
be such that
g_{i}
moves
\mathfrak{r}
to its
i
-th neighbour.
Then for every other
h\in\operatorname{Aut}(T_{\Delta})
that moves
\mathfrak{r}
to one of the neighbors, there is an
h^{\prime}\in\operatorname{Aut}^{o}(T_{\Delta})
so that
h^{\prime}\cdot h=g_{i}
for some
i\leq\Delta
.
Consequently, the degree of
\mathcal{G}_{b,\Delta}
is at most
\Delta
.

It is routine to verify that if
U
is a basic clopen set, that is, a set defined by some
b
-labeling of a
k
-neighborhood of
\mathfrak{r}
for some
k\in\mathbb{N}
, then
N_{\mathcal{G}_{b,\Delta}}(U)
, the neighborhood of

in
\mathcal{G}_{b,\Delta}
, is a union of some
b
-labeled
(k+1)
-neighborhoods of
\mathfrak{r}
, thus a clopen set.
∎

The compact continuous tree
\mathcal{T}^{\operatorname{dist}}_{\Delta}

First, we restrict our attention to labelings that satisfy local constraints.
This way, we define a continuous tree that provides a bridge between local algorithms and the class
\mathsf{CONTINUOUS}

[
Ber21

.
Let
k\in\mathbb{N}

\ell_{k}=|B(\mathfrak{r},k)|=1+\Delta\sum_{i=0}^{k-1}(\Delta-1)^{i}
.

\mathsf{TOAST}
algorithm

The idea to use a toast structure to solve LCLs appears in
[
CM16
]
and has many applications since then
[
GJKS15
,
MU17
]
.
This approach has been formalized in
[
GR21b
]
, where the authors introduce
\mathsf{TOAST}

As we use this notion in
Section

4
, we discuss here briefly the definition and refer the reader to
[

, Section 4]
for more details.

An LCL
\Pi
admits a

algorithm if there is
q\in\mathbb{N}
and a partial extending function that has the property that whenever it is applied inductively to a

-toast, then it produces a
\Pi
-coloring.
Recall that a

gets a finite subset of some underlying set that is partially colored as an input and outputs an extension of this coloring on the whole finite subset.
An advantage of this approach is that once we know that a given Borel graph admits a Borel or Baire toast structure, and a given LCL
\Pi
admits a
\mathsf{TOAST}
algorithm, then we may conclude that
\Pi
is in the class
\mathsf{BOREL}
or
\mathsf{BAIRE}
, respectively.

-regular continuous tree. Then

admits a continuous solution on
\mathcal{T}
.

Our strategy follows closely Bernshteyn’s argument
[
Ber21
]
.
Namely, given a continuous tree
\mathcal{T}
on
X
, we construct a continuous
\{0,1\}
-labeling of

in such a way that the
\{0,1\}
-labeled tree rooted at any given vertex

, i.e., the vertex labeled connected component of

in
\mathcal{T}
, is “close” to
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)
.
Here “close” means that the continuous function on
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)
that solves
\Pi
can be extended to these elements.
Before we give a formal proof, we need to introduce some technical notation and recall the continuous Lovász Local Lemma of Bernshteyn
[
Ber21
]
.

3.1.1
Hyperaperiodic elements

An element
[\alpha]\in\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)/\sim
is called
hyperaperiodic
if the closure of the connectivity component of
[\alpha]
in
\mathcal{T}^{\{0,1\}}_{\Delta}
in the space
\{0,1\}^{T_{\Delta}}/\sim
is a subset of
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)/\sim
.
Equivalently, the closure is a compact subset of
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)/\sim
, or every element that can be approximated by a sequence from
\operatorname{Aut}(T_{\Delta})\cdot\alpha
is in the space
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)
.
We also abuse the notation and say that
\alpha\in\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)
is hyperaperiodic if
[\alpha]
is such.

This notion is well studied in the context of countable groups
[
GJS09
,
STD16
,
GJKS18
,
Ber21
]
.
Namely, every countable group
\Gamma
admits such a
\{0,1\}
-labeling, in particular, every Cayley graph of finitely generated group
\Gamma
admits such a coloring with respect to the shift action of
\Gamma
.
As a byproduct of our main result, we show that these elements indeed exist even in our setting, where the automorphism group is much larger.
It is an exciting open problem to understand for which other classes of (structured) graphs hyperaperiodic elements exist.

Theorem 3.5
.

There are hyperaperiodic elements in
\operatorname{Free}\left(\{0,1\}^{T_{\Delta}}\right)/\sim
.

The statement follows from the last part of the proof of
Theorem

3.4
.
The following is the main definition that we use to approximate hyperaperiodic elements.

Definition 3.6
.

Let

,

,

,

and

(\alpha,K)

n

\alpha\upharpoonright B(v,K)=\alpha^{\prime}\upharpoonright B(v,K).

for every
K,n\in\mathbb{N}
.

Proposition 3.7
.

Let

,
K\in\mathbb{N}
and suppose that

is non-empty.
The sets

and

are compact,

-invariant and we have

for every

and

for some

In particular,

has girth at least

Proof.

It is easy to see from the definition that

is
\operatorname{Aut}(T_{\Delta})
-invariant.
Suppose that
\alpha_{\ell}\to\alpha
in
\{0,1\}^{T_{\Delta}}
, where
\alpha_{\ell}\in X_{K,n}
for every

.
Let
v\in T_{\Delta}
and
g\in\operatorname{Aut}(T_{\Delta})
.
We need to show that
(\alpha,K)

n
-breaks

at
v

If not, then

and we find

such that

and

Taking

large so that

does not

This shows that

Let

be such that

for some

.
It is easy to see that if there is a

From the definition of

n
-breaks

at

But that contradicts the fact that

or

The additional part follows by the same argument as in

∎

3.1.2
Continuous Lovász Local Lemma

In order to construct/approximate hyperaperiodic elements, Bernshteyn
[
Ber21
]
developed a continuous version of the Lovász Local Lemma (LLL).
Namely, he found a sufficient LLL-style condition for the existence of a continuous solution to a continuous constraint satisfaction problem (CSP) defined on a zero-dimensional Polish space, see the definitions below.
Rather surprisingly, a similar but incomparable sufficient condition for the existence of
O(\log^{*}n)
deterministic algorithms was studied in the distributed computing literature
[
BGR20
]
.
We note that both conditions are tight, see the discussion in
[
Ber21
, Section 1.A.2]
.

Let
X
be a set and
k\in\mathbb{N}
. For a finite set
D\subseteq X
, an
(X,k)
-
bad event with domain
D
is an element of
k^{D}
. A
constraint
\mathscr{B}
with domain
D
is a collection of
(X,k)
-bad events with domain
D
; we will use the notation
\operatorname{dom}(\mathscr{B})=D
, and omit
X
and
k
if it is clear from the context. A
CSP

\mathfrak{B}
(on
X
with range
k
)
is a set of
(X,k)
-constraints.
Define the
maximal probability of
\mathfrak{B}
as

p(\mathfrak{B})=\sup_{\mathscr{B}\in\mathfrak{B}}\frac{|\mathscr{B}|}{k^{|dom(\mathscr{B})|}},

the
vertex degree of
\mathfrak{B}
as

vdeg(\mathfrak{B})=\sup_{x\in X}|\{\mathscr{B}\in\mathfrak{B}:x\in dom(\mathscr{B})\}|,

and the
order of
\mathfrak{B}
by

ord(\mathfrak{B})=\sup_{\mathscr{B}\in\mathfrak{B}}|\operatorname{dom}(\mathscr{B})|.

If
X
is a zero-dimensional Polish space, a CSP
\mathfrak{B}
on
X
is
continuous
if for every
set
S
of functions
\{1,\dots,n\}\to k
and
U_{2},\dots,U_{n}\subseteq X
clopen the set

\{x_{1}:\text{there are $x_{2}\in U_{2},\dots,x_{n}\in U_{n}$ such that }x_{1},\dots,x_{n}\text{ are distinct and }S(x_{1},\dots,x_{n})\in\mathfrak{B}\}

is clopen, where
S(x_{1},\dots,x_{n})
stands for the collection of functions determined by the elements of
S
, i.e.,
f\in S(x_{1},\dots,x_{n})
if for some
\varphi\in S
we have
f(x_{i})=j\iff\varphi(i)=j
.

A
k
-coloring
f:X\to k

satisfies (or solves) the CSP
\mathfrak{B}
if
f
has no restriction that is a bad event. The following theorem has been proven in
[
Ber21
]
:

Theorem 3.8

(
[
Ber21
]
)
.

Let
X
be a zero-dimensional Polish space,
k\in\mathbb{N}
, and
\mathfrak{B}
be a continuous CSP on
X
with range
k
such that

p(\mathfrak{B})\cdot vdeg(\mathfrak{B})^{ord(\mathfrak{B})}<1.

Then
\mathfrak{B}
admits a continuous solution.

3.1.3
The continuous tree
\mathcal{T}

The aim of this section is to show that every continuous
\{0,1\}
-labeling of vertices of a continuous tree

naturally induces a continuous homomorphism from
\mathcal{T}
to
\mathcal{G}_{\{0,1\},\Delta}
.
The main technical difficulty is that there is no unified way how vertices of
\mathcal{T}
“view” their connected component and its automorphism group.
To overcome this difficulty we first break local symmetry by a proper edge coloring.

Proposition 3.9
.

Let
\mathcal{T}

\Theta_{\mathcal{T}}:\mathcal{H}(\mathcal{T})\to(2\Delta-1)

Proof.

This is a direct consequence of
[
KST99
]

3.2
combined with
[
Lin92
]
, applied to the line graph of

Recall that a line graph of
\mathcal{T}
is a graph with a vertex set equal to the edge set of
\mathcal{T}
, where two edges of
\mathcal{T}
form an edge in the line graph if they share a vertex in
\mathcal{T}
.
∎

Let
\mathcal{T}
be a continuous tree on
Z
,
\Theta_{\mathcal{T}}
as above and
x\in Z
.
Moreover, fix the canonical linear ordering on the set

and some ordering of vertices of

Write

for the isomorphism between the connectivity component of

in
\mathcal{T}
and

that is defined inductively along
k=dist_{\mathcal{T}}(x,{-})
as follows:

1.

sends

to the root
\mathfrak{r}
of
T_{\Delta}
,

2.

Suppose that
I_{x}
is defined on
B_{\mathcal{T}}(x,k)
and
dist_{\mathcal{T}}(x,y)=k
for some

Consider the linear ordering on

induced by

if

Extend

Similarly, we define the action of

on the connectivity component of

That is, we define

Proposition 3.10
.

Let
\mathcal{T}
be a continuous tree on

Then the map

to

Proof.

It follows directly from the definitions that the map is well-defined.
As
\Theta_{\mathcal{T}}
and

are continuous, it follows that

is continuous as well.
To see this note that the values of

and

fully determine

on
B_{\mathcal{T}}(x,\ell)

The moreover part easily follows.
∎

Let us remark that

remains the same for any continuous assignment

, where

is an enumeration of the connected component of

.

3.1.4
Key Lemma

\mathsf{BAIRE}=\mathsf{LOCAL}(O(\log n))

In this section, we show that on

-regular trees the classes

and

are the same.
At first glance, this result looks rather counter-intuitive.
This is because in finite

-regular tree.
However, there is an intuitive reasons why these classes are the same: in both setups there is a technique to decompose an input graph into a hierarchy of subsets, see

and

. Furthermore, the existence of a solution that is defined inductively with respect to these decompositions can be characterized by the same combinatorial condition of Bernshteyn
[

]

Combinatorial Condition –
\ell
-full Set

In both structural decompositions we need to extend a partial coloring along paths that have their endpoints colored from the inductive step.
The precise formulation of the combinatorial condition that captures this demand was extracted by Bernshteyn
[

]

He proved that it characterizes the class

for Cayley graphs of virtually free groups.
Note that this class contains, e.g.,

Definition 4.1

(Combinatorial condition – an

Let

A set

and

Then there is a way to label the half-edges around the remaining

vertices with configurations from

such that all the

edges on the path have valid edge configuration on them.

Now we are ready to formulate the result that combines Bernshteyn’s result
[

]
(equivalence between (1.) and (3.)) with the main results of this section.

To finish the proof of

\mathsf{LOCAL}(n^{o(1)})=\mathsf{LOCAL}(O(\log n))

Theorem 4.6
.

Let
\Pi=(\Sigma,\mathcal{V},\mathcal{E})

Then there exists an
\ell

for some

The rest of the section is devoted to the proof of

. We start with the high-level idea of the proof.
A natural attempt for showing
\mathsf{LOCAL}(n^{o(1)})

\Rightarrow

\ell
-full is to simply take any
\mathsf{LOCAL}(n^{o(1)})
algorithm
\mathcal{A}
solving
\Pi
, and then take
\mathcal{V}^{\prime}
to be all vertex configurations that can possibly occur in an output of
\mathcal{A}
. It is not hard to see that this approach does not work in general, because the algorithm might use a special strategy to label vertices with degree smaller than
\Delta
. Specifically, there might be some vertex configuration
c
used by
\mathcal{A}
so that some
\mathtt{a}\in c
will only be used to label
virtual
half-edges. It will be problematic to include

in
\mathcal{V}^{\prime}
.

To cope with this issue, we do not deal with general bounded-degree trees. Instead, we construct recursively a sequence
(W^{\ast}_{1},W^{\ast}_{2},\ldots,W^{\ast}_{L})
of sets of rooted, layered, and
partially labeled
tree in a special manner. A tree
T
is included in
W^{\ast}_{i}
if it can be constructed by gluing a multiset of rooted trees in
W^{\ast}_{i-1}
and a new root vertex
r
in a certain fixed manner. A vertex is said to be in layer

if it is introduced during the
i

during the construction of
W^{\ast}_{i}
from

. All remaining vertices are said to be in layer 0.

We show that each
T\in W^{\ast}_{L}
admits a correct labeling that extends the given partial labeling, as these partial labelings are computed by a simulation of
\mathcal{A}
.
Moreover, in these correct labelings, the variety of possible configurations of half-edge labels around vertices in different non-zero layers is the same for each layer.
This includes vertices of non-zero layer whose half-edges are labeled by the given partial labeling.
We simply pick
\mathcal{V}^{\prime}
to be the set of all configurations of half-edge labels around vertices that can appear in a non-zero layer in a correct labeling of a tree
T\in W^{\ast}_{L}
.
Our construction ensures that each
c\in\mathcal{V}^{\prime}
appears as the labeling of some degree-
\Delta
vertex in some tree that we consider.

The proof that
\mathcal{V}^{\prime}
is an
\ell
-full set is based on finding paths using vertices of non-zero layers connecting two vertices with any two vertex configurations in
\mathcal{V}^{\prime}
in different lengths. These paths exist because the way rooted trees in
W^{\ast}_{i-1}
are glued together in the construction of

is sufficiently flexible.
The reason that we need
\mathcal{A}
to have complexity
\mathsf{LOCAL}(n^{o(1)})
is that the construction of the trees can be parameterized by a number
w
so that all the trees have size polynomial in
w
and the vertices needed to be assigned labeling are at least distance
w
apart from each other. Since the number of rounds of
\mathcal{A}
executed on trees of size

is much less than

, each labeling assignment can be calculated locally and independently.
The construction of the trees as well as the analysis are based on a machinery developed in
[
CP19
]
.
Specifically, we will consider the equivalence relation
\overset{\star}{\sim}
defined in
[
CP19
]
and prove some of its properties, including a pumping lemma for bipolar trees. The exact definition of
\overset{\star}{\sim}
in this paper is different from the one in
[
CP19
]
because the mathematical formalism describing LCL problems in this paper is different from the one in
[
CP19
]
.
After that, we will consider a procedure for gluing trees parameterized by a labeling function

similar to the one used in
[
CP19
]
.
We will apply this procedure iteratively to generate a set of trees. We will show that the desired
\ell
-full set

can be constructed by considering the set of all possible correct labeling of these trees.

The Equivalence Relation
\overset{\star}{\sim}

We consider trees with a list of designated vertices
v_{1},v_{2},\ldots,v_{k}
called

. A

is a tree with one pole

, and a

is a tree with two poles

and
t
.
For a tree
T
with its poles
S=(v_{1},v_{2},\ldots,v_{k})
with
\operatorname{deg}(v_{i})=d_{i}<\Delta
, we denote by

the function that maps each choice of the
virtual
half-edge labeling surrounding the poles of
T
to
YES
or
NO
, indicating whether such a partial labeling can be completed into a correct complete labeling of
T
.
More specifically, consider

X=(\mathcal{I}_{1},\mathcal{I}_{2},\ldots,\mathcal{I}_{k}),

where
\mathcal{I}_{i}
is a size-
(\Delta-d_{i})
multiset of labels in
\Sigma
, for each

. Then

if there is a correct labeling of
T
such that the
\Delta-d_{i}
virtual half-edge labels surrounding

are labeled by
\mathcal{I}_{i}
, for each

. This definition can be generalized to the case

is already partially labeled in the sense that some of the half-edge labels have been fixed. In this case,

whenever

is incompatible with the given partial labeling.

Let
T
be a tree with poles
S=(v_{1},v_{2},\ldots,v_{k})
and let

be another tree with poles

Then we write

if

Given an LCL problem

, it is clear that the number of equivalence classes of rooted trees and bipolar trees w.r.t.

is finite.
For a rooted tree

Subtree Replacement

The following lemma provides a sufficient condition that the equivalence class of a tree
T
is invariant of the equivalence class of its subtree
T^{\prime}
.
We note that a real half-edge in
T
might become virtual in its subtree
T^{\prime}
.
Consider a vertex
v
in
T^{\prime}
and its neighbor

that is in

but not in

. Then the half-edge

is real in

.

Lemma 4.7

(Replacing subtrees)
.

Let

be a tree with poles

.
Let

be a connected subtree of

induced by

, where

is the set of vertices in
T
.
We identify a list of designated vertices

in

.

•

S\cap U\subseteq S^{\prime}
.

•

Each edge
e=\{u,v\}
connecting
u\in U
and
v\in V\setminus U
must satisfy

.

Let

be another tree with poles

that is in the same equivalence class as

.
Let

be the result of replacing

by

in

by identifying

for each

.

is in the same equivalence class as

.

Proof.

To prove the lemma, by symmetry, it suffices to show that starting from any correct labeling
\mathcal{L}
of

, it is possible to find a correct labeling

of

in such a way that the multiset of the virtual half-edge labels surrounding each pole in

Such a correct labeling

of

is constructed as follows. If

, then we simply adopt the given labeling

of

in

.
Next, consider the vertices in

.
Set

to be the one compatible with the labeling

of

restricted to the subtree

in the sense that

is the multiset of the virtual half-edge labels surrounding the pole

of

, for each

. We must have

.
Since

and

are in the same equivalence class, we have

, and so we can find a correct labeling

of

that is also compatible with

. Combining this labeling

of the vertices

in

of the vertices

in

of

.

We verify that

gives a correct labeling of

. Clearly, the size-

multiset that labels each vertex

is in

, by the correctness of

and
\mathcal{L}^{\prime\prime}
. Consider any edge

in

. Similarly, if

or

, then the size-

multiset that labels

is in

, by the correctness of

and
\mathcal{L}^{\prime\prime}
. For the case that

connects a vertex

, we must have

by the lemma statement. Therefore, the label of the half-edge

is the same in both

and

by our choice of

. Thus, the size-

, by the correctness of

.

We verify that the

and

. Consider a pole

is clearly the same in both

and

.
If

in the statement implies that

A Pumping Lemma

We will prove a pumping lemma of bipolar trees using
Lemma

4.7
.
Suppose
T_{i}
is a tree with a root
r_{i}
for each
1\leq i\leq k
, then
H=(T_{1},T_{2},\ldots,T_{k})
denotes the bipolar tree resulting from concatenating the roots
r_{1},r_{2},\ldots,r_{k}
into a path
(r_{1},r_{2},\ldots,r_{k})
and setting the two poles of
H
by

and

.
A simple consequence of
Lemma

4.7
is that
\textsf{Class}_{2}(H)
is determined by
\textsf{Class}_{1}(T_{1}),\textsf{Class}_{1}(T_{2}),\ldots,\textsf{Class}_{1}(T_{k})
.
We have the following pumping lemma.

Lemma 4.8

(Pumping lemma)
.

There exists a finite number
{\ell_{\operatorname{pump}}}>0
such that as long as
k\geq{\ell_{\operatorname{pump}}}
, any bipolar tree
H=(T_{1},T_{2},\ldots,T_{k})
can be decomposed into
H=X\circ Y\circ Z
with
0<|Y|<k
so that
X\circ Y^{i}\circ Z
is in the same equivalence class as
H
for each
i\geq 0
.

Proof.

Set
{\ell_{\operatorname{pump}}}
to be the number of equivalence classes for bipolar trees plus one. By the pigeon hole principle, there exist
1\leq a<b\leq k
such that
(T_{1},T_{2},\ldots,T_{a})
and
(T_{1},T_{2},\ldots,T_{b})
are in the same equivalence class. Set
X=(T_{1},T_{2},\ldots,T_{a})
,
Y=(T_{a+1},T_{a+2},\ldots,T_{b})
, and
Z=(T_{b+1},T_{b+2},\ldots,T_{k})
. As we already know that
\textsf{Class}_{2}(X)=\textsf{Class}_{2}(X\circ Y)
,
Lemma

4.7
implies that

\textsf{Class}_{2}(X\circ Y)=\textsf{Class}_{2}(X^{2}\circ Y)
by replacing
X
by
X\circ Y
in the bipolar tree
X\circ Y
.
Similarly,
\textsf{Class}_{2}(X\circ Y^{i})
is the same for for each
i\geq 0
. Applying
Lemma

4.7
again to replace
X\circ Y
by
X\circ Y^{i}
in
H=X\circ Y\circ Z
, we conclude that
X\circ Y^{i}\circ Z
is in the same equivalence class as
H
for each
i\geq 0
.
∎

A Fixed Point

Given a fixed labeling function

,
we want to find a set of rooted trees

that is a

for the procedure

in the sense that

\textsf{Class}_{1}(Z_{f}(W^{\ast}))=\textsf{Class}_{1}(W^{\ast}).

To find such a set

•

For the base case,

•

Given that
W_{i,j}

•

Given that

for all positive integers

We show that the sequence

Lemma 4.11

For any

j\geq a_{i}
, we have
\textsf{Class}_{1}(W_{i,j})=\textsf{Class}_{1}(W_{i,j+c_{i}})
, where
c_{i}=b_{i}-a_{i}
.

Proof.

By
Lemma

4.10
,
\textsf{Class}_{1}(W_{i,j})
depends only on
\textsf{Class}_{1}(W_{i,j-1})
. Hence the lemma follows from the fact that
\textsf{Class}_{1}(W_{i,b_{i}})=\textsf{Class}_{1}(W_{i,a_{i}})
.
∎

Next, we show that
\textsf{Class}_{1}(W_{2,1})\subseteq\textsf{Class}_{1}(W_{3,1})\subseteq\textsf{Class}_{1}(W_{4,1})\subseteq\cdots
.

Lemma 4.12
.

For any
i\geq 2
, we have
\textsf{Class}_{1}(W_{i,1})\subseteq\textsf{Class}_{1}(W_{i,j})
for each
j>1
, and so
\textsf{Class}_{1}(W_{i,1})\subseteq\textsf{Class}_{1}(W_{i+1,1})
.

Proof.

Since
W_{i,1}=\bigcup_{a_{i-1}\leq l\leq b_{i-1}-1}W_{i-1,l}
, we have

\bigcup_{a_{i-1}+j-1\leq l\leq b_{i-1}+j}W_{i-1,l}\subseteq W_{i,j}

according to the procedure of constructing
W_{i,j}
. By
Lemma

4.11
,

\textsf{Class}_{1}\left(\bigcup_{a_{i-1}\leq l\leq b_{i-1}-1}W_{i-1,l}\right)=\textsf{Class}_{1}\left(\bigcup_{a_{i-1}+j-1\leq l\leq b_{i-1}+j}W_{i-1,l}\right)

for all
j\geq 1
, and so we have
\textsf{Class}_{1}(W_{i,1})\subseteq\textsf{Class}_{1}(W_{i,j})
for each
j>1
. The claim
\textsf{Class}_{1}(W_{i,1})\subseteq\textsf{Class}_{1}(W_{i+1,1})
follows from the fact that
W_{i+1,1}=\bigcup_{a_{i}\leq l\leq b_{i}-1}W_{i,l}
.
∎

Set
i^{\ast}
to be the smallest index
i\geq 2
such that
\textsf{Class}_{1}(W_{i,1})=\textsf{Class}_{1}(W_{i+1,1})
. By the pigeon hole principle and
Lemma

4.12
, the index
i^{\ast}
exists, and it is upper bounded by
C
, the number of equivalence classes for rooted trees. We set

W^{\ast}=W_{i^{\ast},1}.

The following lemma shows that
\textsf{Class}_{1}(Z_{f}(W^{\ast}))=\textsf{Class}_{1}(W^{\ast})
, as needed.

Lemma 4.13
.

For any
i\geq 2
, if
\textsf{Class}_{1}(W_{i,1})=\textsf{Class}_{1}(W_{i+1,1})
, then
\textsf{Class}_{1}(W_{i,j})
is the same for all
j\geq 1
.

Proof.

By
Lemma

4.11
and the way we construct
W_{i+1,1}
, we have

\textsf{Class}_{1}(W_{i,j})\subseteq\textsf{Class}_{1}(W_{i+1,1})\ \ \text{for each}\ \ j\geq a_{i}.

By
Lemma

4.12
, we have

\textsf{Class}_{1}(W_{i,1})\subseteq\textsf{Class}_{1}(W_{i,j})\ \ \text{for each}\ \ j>1.

Therefore,
\textsf{Class}_{1}(W_{i,1})=\textsf{Class}_{1}(W_{i+1,1})
implies that
\textsf{Class}_{1}(W_{i,j})=\textsf{Class}_{1}(W_{i,1})
for each
j\geq a_{i}
. Hence we must have
\textsf{Class}_{1}(Z_{f}(W_{i,1}))=\textsf{Class}_{1}(W_{i,1})
, and so
\textsf{Class}_{1}(W_{i,j})
is the same for all
j\geq 1
.
∎

We remark that simply selecting

to be any set such that
\textsf{Class}_{1}(Z_{f}(W^{\ast}))=\textsf{Class}_{1}(W^{\ast})
is not enough for our purpose. As we will later see, it is crucial that the set

is constructed by iteratively applying the function

and taking the union of previously constructed sets.

A Sequence of Sets of Trees

We define

and

for each

The way we choose

guarantees that

for all

For convenience, we write

Similarly,

Our analysis will rely on the assumption that all rooted trees in

, which depends only on the labeling function

The assumption that

, and

Lemma 4.15

A Feasible Labeling Function
f
exists

We show that a feasible labeling function
f
exists given that
\Pi
can be solved in
\mathsf{LOCAL}(n^{o(1)})
rounds. We will construct a labeling function
f
in such a way each equivalence class in
\textsf{Class}_{1}(W^{\ast})
contains only rooted trees that admit legal labeling. That is, for each
c\in\textsf{Class}_{1}(W^{\ast})
, the mapping
h
associated with
c
satisfies
h(X)=\textsf{YES}
for some
X
.

We will consider a series of modifications in the construction

W\rightarrow X_{f}(W)\rightarrow Y_{f}(W)\rightarrow Z_{f}(W)

that do not alter the sets of equivalence classes in these sets, conditioning on the assumption that all trees that we have processed admit correct labelings. That is, whether
f
is feasible is invariant of the modifications.

Applying the Pumping Lemma

Let
w>0
be some target length for the pumping lemma. In the construction of
Y_{f}(W)
, when we process a bipolar tree

H=(T_{1}^{l},T_{2}^{l},\ldots,T_{{\ell_{\operatorname{pump}}}}^{l},T^{m},T_{1}^{r},T_{2}^{r},\ldots,T_{{\ell_{\operatorname{pump}}}}^{r}),

we apply
Lemma

4.8
to the two subtrees
H^{l}=(T_{1}^{l},T_{2}^{l},\ldots,T_{{\ell_{\operatorname{pump}}}}^{l})
and
H^{r}=(T_{1}^{r},T_{2}^{r},\ldots,T_{{\ell_{\operatorname{pump}}}}^{r})
to obtain two new bipolar trees
H_{+}^{l}
and
H_{+}^{r}
.
The
s
-
t
path in the new trees
H_{+}^{l}
and
H_{+}^{r}
contains
w+x
vertices, for some
0\leq x<{\ell_{\operatorname{pump}}}
. The equivalence classes do not change, that is,
\textsf{Class}_{2}(H^{l})=\textsf{Class}_{2}(H_{+}^{l})
and
\textsf{Class}_{2}(H^{r})=\textsf{Class}_{2}(H_{+}^{r})
.

We replace
H^{l}
by
H_{+}^{l}
and replace
H^{r}
by
H_{+}^{r}
in the bipolar tree
H
.
Recall that the outcome of applying the labeling function
f
to the root
r
of the rooted tree
T_{{\ell_{\operatorname{pump}}}+1}
depends only on

\textsf{Class}_{2}(H^{l}),\textsf{Class}_{1}(T_{1}^{m}),\textsf{Class}_{1}(T_{2}^{m}),\ldots,\textsf{Class}_{1}(T_{\Delta-2}^{m}),\textsf{Class}_{2}(H^{r}),

so applying the pumping lemma to
H^{l}
and
H^{r}
during the construction of
Y_{f}(W)
does not alter
\textsf{Class}_{1}(T_{\ast}^{m})
and
\textsf{Class}_{2}(H^{\ast})
for the resulting bipolar tree
H^{\ast}
and its middle rooted tree
T_{\ast}^{m}
, by
Lemma

4.9
.

Reusing Previous Trees

During the construction of the fixed point
W^{\ast}
, we remember all bipolar trees to which we have applied the feasible function
f
.

During the construction of
Y_{f}(W)
. Suppose that we are about to process a bipolar tree
H
, and there is already some other bipolar tree
\tilde{H}
to which we have applied
f
before so that

\textsf{Class}_{2}(H^{l})=\textsf{Class}_{2}(\tilde{H}^{l})
,
\textsf{Class}_{1}(T_{i}^{m})=\textsf{Class}_{1}(\tilde{T}_{i}^{m})
for each
1\leq i\leq\Delta-2
, and
\textsf{Class}_{2}(H^{r})=\textsf{Class}_{2}(\tilde{H}^{r})
.
Then we replace
H
by
\tilde{H}
, and then we process
\tilde{H}
instead.

By
Lemma

4.9
, this modification does not alter
\textsf{Class}_{1}(T_{\ast}^{m})
and
\textsf{Class}_{2}(H^{\ast})
for the resulting bipolar tree
H^{\ast}
.

Not Cutting Bipolar Trees

We consider the following different construction of
Z_{f}(W)
from
Y_{f}(W)
. For each
H^{\ast}\in Y_{f}(W)
, we simply add two copies of
H^{\ast}
to
Z_{f}(W)
, one of them has
r=s
and the other one has
r=t
.
That is, we do not cut the bipolar tree
H^{\ast}
, as in the original construction of
Z_{f}(W)
.

In general, this modification might alter
\textsf{Class}_{1}(Z_{f}(W))
.
However, it is not hard to see that if all trees in
Y_{f}(W)
already admit correct labelings, then
\textsf{Class}_{1}(Z_{f}(W))
does not alter after the modification.

Specifically, let
T
be a rooted tree in
Z_{f}(W)
with the above modification.
Then
T
is identical to a bipolar tree
H^{\ast}=(T_{1},T_{2},\ldots,T_{k})\in Y_{f}(W)
, where there exists some
1<i<k
such that the root
r_{i}
of
T_{i}
has its half-edge labels fixed by
f
.
Suppose that the root of
T
is the root
r_{1}
of
T_{1}
.
If we do not have the above modification, then the rooted tree
T^{\prime}
added to
Z_{f}(W)
corresponding to
T
is
(T_{1},T_{2},\ldots,T_{i})
, where the root of
T^{\prime}
is also
r_{1}
.

Given the assumption that all bipolar trees in
Y_{f}(W)
admit correct labelings, it is not hard to see that
\textsf{Class}_{1}(T^{\prime})=\textsf{Class}_{1}(T)
. For any correct labeling
\mathcal{L}^{\prime}
of
T^{\prime}
, we can extend the labeling to a correct labeling
\mathcal{L}
of
T
by labeling the remaining vertices according to any arbitrary correct labeling of
H^{\ast}
. This is possible because the labeling of
r_{i}
has been fixed. For any correct labeling
\mathcal{L}
of
T
, we can obtain a correct labeling
\mathcal{L}^{\prime}
of
T^{\prime}
by restricting
\mathcal{L}
to
T^{\prime}
.

Simulating a
\mathsf{LOCAL}
Algorithm

We will show that there is a labeling function
f
that makes all the rooted trees in
W^{\ast}
to admit correct solutions, where we apply the above three modifications in the construction of
W^{\ast}
. In view of the above discussion, such a function
f
is feasible.

The construction of
W^{\ast}
involves only a finite number
k
of iterations of
Z_{f}
applied to some previously constructed rooted trees. If we view the target length
w
of the pumping lemma as a variable, then the size of a tree in
W^{\ast}
can be upper bounded by
O(w^{k})
.

Suppose that we are given an arbitrary
n^{o(1)}
-round
\mathsf{LOCAL}
algorithm
\mathcal{A}
that solves
\Pi
. It is known
[
CP19
,
Cha20
]
that randomness does not help for LCL problems on bounded-degree trees with lound complexity
\Omega(\log n)
, so we assume that

\mathcal{A}
is deterministic.

The runtime of
\mathcal{A}
on a tree of size

O(w^{k})
can be made to be at most
t=w/10
if
w
is chosen to be sufficiently large.

We pick the labeling function
f
as follows.
Whenever we encounter a new bipolar tree
H
to which we need to apply
f
, we simulate
\mathcal{A}
locally at the root
r^{m}
of the middle rooted tree
T^{m}
in
H
. Here we assume that the pumping lemma was applied before simulating
\mathcal{A}
. Moreover, when we do the simulation, we assume that the number of vertices is
n=O(w^{k})
.

To make the simulation possible, we just locally generate arbitrary distinct identifiers in the radius-
t
neighborhood
S
of
r^{m}
. This is possible because
t=w/10
is so small that for any vertex
v
in any tree
T
constructed by recursively applying
Z_{f}
for at most
k
iterations, the radius-
(t+1)
neighborhood of
v
intersects at most one such
S
-set. Therefore, it is possible to complete the identifier assignment to the rest of the vertices in
T
so that for any edge
\{u,v\}
, the set of identifiers seen by
u
and
v
are distinct in an execution of a
t
-round algorithm.

Thus, by the correctness of
\mathcal{A}
, the labeling of all edges
\{u,v\}
are configurations in
\mathcal{E}
and the labeling of all vertices
v
are configurations in
\mathcal{V}
.
Our choice of
f
implies that all trees in
W^{\ast}
admit correct labeling, and so
f
is feasible. Combined with
Lemma

4.19
, we have proved that
\mathsf{LOCAL}(n^{o(1)})

\Rightarrow

\ell
-full.
