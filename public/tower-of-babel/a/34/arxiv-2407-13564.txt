Convergence result for the gradient-push algorithm and its application to boost up the Push-DIging algorithm
Hyogi Choi, Woocheol Choi, Gwangil Kim

Abstract
. The gradient-push algorithm is a fundamental algorithm for the distributed optimization problem min x ∈ ℝ d ⁡ f ⁡ ( x ) = ∑ j = 1 n f j ​ ( x ) , \min_{x\in\mathbb{R}^{d}}f(x)=\sum_{j=1}^{n}f_{j}(x), (0.1) where each local cost f j f_{j} is only known to agent a i a_{i} for 1 ≤ i ≤ n 1\leq i\leq n and the agents are connected by a directed graph. In this paper, we obtain convergence results for the gradient-push algorithm with constant stepsize whose range is sharp in terms the order of the smoothness constant L > 0 L>0 . Precisely, under the two settings: 1) Each local cost f i f_{i} is strongly convex and L L -smooth, 2) Each local cost f i f_{i} is convex quadratic and L L -smooth while the aggregate cost f f is strongly convex, we show that the gradient-push algorithm with stepsize α > 0 \alpha>0 converges to an O ⁡ ( α ) O(\alpha) -neighborhood of the minimizer of f f for a range α ∈ ( 0 , c / L ] \alpha\in(0,c/L] with a value c > 0 c>0 independent of L > 0 L>0 . As a benefit of the result, we suggest a hybrid algorithm that performs the gradient-push algorithm with a relatively large stepsize α > 0 \alpha>0 for a number of iterations and then go over to perform the Push-DIGing algorithm. It is verified by a numerical test that the hybrid algorithm enhances the performance of the Push-DIGing algorithm significantly. The convergence results of the gradient-push algorithm are also supported by numerical tests.

Introduction

In this paper, we consider the distributed optimization problem:

\min_{x\in\mathbb{R}^{d}}f(x)=\sum_{j=1}^{n}f_{j}(x),

(1.1)

is stronlgy convex, and so there exists a unique minimizer

of the problem (
1.1
).

Frequently in real-world scenarios, the communication between agents is described as a directed network because the communication powers of agents are different, leading to one-way interactions between agents.
In the fundamental work, Nedic and Olshevsky
[
19
,
21
]
introduced the gradient-push algorithm for the distributed optimization on the directed graph making use of the gradient-push protocol
[
16
,
31
]
. The gradient-push algorithm is formulated as follows:

\begin{split}&w_{i}(t+1)=\sum_{j=1}^{n}W_{ij}x_{j}(t)\\
&y_{i}(t+1)=\sum_{j=1}^{n}W_{ij}y_{j}(t)\\
&z_{i}(t+1)=\frac{w_{i}(t+1)}{y_{i}(t+1)}\\
&x_{i}(t+1)=w_{i}(t+1)-\alpha(t)\nabla f_{i}\big(z_{i}(t+1)\big),\end{split}

(1.2)

endowed with initial data
x_{i}(0)\in\mathbb{R}^{d}
and
y_{i}(0)=1
for each
1\leq i\leq n
and
t\geq 0
. Here
W_{ij}\geq 0
is a communication weight and
\alpha(t)>0
is stepsize. We define a directed graph
G=(V,E)
with the vertex set
V={1,2,\cdots,n}
and the edge set
E\subset V\times V
, where
(i,j)\in E
means that there exist a directed edge from agent
j
toward
i
. We assume that
W_{ij}>0
if
(i,j)\in E
or
i=j
and
W_{ij}=0
otherwise. A popular choice is given by
W_{ij}=1/(|N_{j}|+1)
for
i\in N_{j}\cup\{j\}
where
N_{j}=\{i|(i,j)\in E\}
. Throughout this paper, we will focus on the constant stepsize
\alpha(t)=\alpha
and the graph
G
is assumed to satisfy the following assumptions.

Assumption 1
.

Graph
G
is strongly connected.
When
G
is strongly connected, then it contains directed edge
(i,j)\in V\times V
for all
i,j

Assumption 2
.

the matrix
W=\{W_{ij}\}_{1\leq i,j\leq n}
is column stochastic, which means

\sum_{k=1}^{n}W_{kj}=1.

Assumption 3
.

Each local funcition
f_{i}
satisfies
L_{i}
-smoothness for some
L_{i}>0
, i.e.,

\|\nabla f_{i}(x)-\nabla f_{i}(y)\|\leq L_{i}\|x-y\|\quad\forall~x,y\in\mathbb{R}^{d}.

1.1.
New results for the gradient-push algorithm with constant stepsize

Despite its wide applications, the convergence property of the gradient-push algorithm has not been fully understood.
The works
[
19
,
20
,
21
,
29
]
studied the convergence property of the gradient-push algorithm after assuming the boundedness of either the state variable or the gradient for the convergence analysis.
The work
[
21
]
established the convergence result for convex cost functions when the stepsize
\alpha(t)
is given as
\alpha(t)=1/\sqrt{t}
or satisfies the condition
\sum_{t=1}^{\infty}\alpha(t)=\infty
and
\sum_{t=1}^{\infty}\alpha(t)^{2}<\infty
. The work
[
20
]
obtained the convergence result when the cost function is strongly convex, and
\alpha(t)=c/t
for some
c>0
. We also refer to the work
[
29
]
where the authors obtained a convergence result for non-convex cost functions. We would like to mention that the convergence results in the previous works
[
19
,
21
,
29
]
rely on
a priori
assumption that the gradients of the cost functions are uniformly bounded.

In the recent work
[
10
]
, the authors proved that for each
1\leq i\leq n
, the sequence
\{z_{i}(t)\}_{t\geq 0}
of the gradient-push algorithm (
1.2
) with constant stepsize
\alpha>0
converges linearly to an
O(\alpha)
-neighborhood of the
minimizer
x_{*}
when each cost
f_{j}
is
L
-smooth and
f
is
\beta
-strongly convex, if the stepsize satisfies
\alpha\leq\frac{c}{L^{2}}
where the value
c>0
is deterimined by
\beta
and
W
. We refer to Theorem
2.1
below for the full detail. Having this result, one may wonder the full range of
\alpha>0
for which this kind of convergence result holds for the gradient-push algorithm (
1.2
).
To discuss this issue, we introduce the following definition.

Definition 1.1
.

We denote by
\alpha_{GP}>0
the largest constant such that for
\alpha\in(0,\alpha_{GP}]
the sequence
\{z_{i}(t)\}_{t\geq 0}
of the gradient-push algorithm converges linearly up to an
O(\alpha)
-neighborhood of the minimizer for each
1\leq i\leq n
.

It is worth to mention that if the matrix
W
is symmetric and doubly stochastic, then the gradient-push becomes the diffusion algorithm
[
8
]
which closely resembles the distributed gradient descent algorithm. The result
[
37
]
showed that the DGD algorithm converges to an
O(\alpha)
-neighborhood of the minimizer linearly if each local cost is convex and
L
-smooth and the aggregate cost is strongly convex when the stepsize satisfies
\alpha\leq\frac{c}{L}
with a specific value
c>0
independent of
L>0
. A similar result was obtained in
[
3
]
for the diffusion algorithm. These results leads one to consider the following problem for the gradient-push algorithm.

Open problem.
Is there a class of cost functions such that
\alpha_{GP}\geq\frac{c}{L}
holds with a constant
c>0
independent of
L>0
?

We mention that the proof of the result of
[
37
]
heavily relies on a reformulation of the DGD by a gradient descent method of a cost defined on the product space
(\mathbb{R}^{d})^{n}
.
This approach is no longer applicable for the gradient-push algorithm, which makes the problem difficult.

In this work, we introduce an essential framework for analyzing the gradient-push algorithm. Consequently, we settle down the above problem for two popular classes of the cost functions. To state the result, we recall a well-known result (see
[
9
]
) that under Assumptions
1
and
2
, the matrix W =
\{W_{ij}\}_{1\leq i,j\leq n}
has a right eigenvector
\pi
=
(\pi_{1}\cdots\pi_{n})^{\top}
associated with the eigenvalue 1 satisfying
\sum_{j=1}^{n}\pi_{j}=1
and

\sum_{j=1}^{n}W_{kj}\pi_{j}=\pi_{k}\quad\forall~1\leq k\leq n.

The following is the main result of this paper answering the above open problem.

Theorem 1.2
.

Suppose one of the following conditions holds true:

Case 1:

Each cost
f_{k}
is
\mu_{k}
-strongly convex and
L_{k}
-smooth for
1\leq k\leq n
. The stepsize is assumed to satisfy
\alpha\in(0,\alpha_{0}]
with
\alpha_{0}=\min_{1\leq k\leq n}\frac{2n\pi_{k}}{L_{k}+\mu_{k}}
.

Case 2:

Each cost
f_{j}
is given by convex quadratic form as
f_{j}(x)=\frac{1}{2}x^{\top}A_{j}x+B_{j}x
for a symmetric positive semi-definite matrix
A_{j}\geq
0 and
B_{j}\in\mathbb{R}^{1\times d}
and the aggregate cost
f
=
\frac{1}{n}\sum_{k=1}^{n}f_{k}
is
\mu
-strongly convex.
The stepsize is assumed to satisfy
\alpha\in(0,\alpha_{0}]
with
\alpha_{0}=\min_{1\leq k\leq n}\frac{2n\pi_{k}}{L_{k}+\epsilon}
for any fixed
\epsilon>0
. Here the smoothness constant
L_{k}
of cost
f_{k}
is given by the largest eigenvalue of
A_{k}.

Then for each
1\leq k\leq n
, the sequence
\{z_{k}(t)\}_{t\geq 0}
of the gradient-push algorithm (
1.2
) with stepsize
\alpha\in(0,\alpha_{0}]
converges linearly to an
O(\alpha)
-neighborhood of the
minimizer of
f
.

1.2.
Combining the gradient-push with the Push-DIging

Here we briefly discuss how the new understanding of the gradient-push algorithm with a large constant stepsize can be used effectively in combination with the Push-DIGing algorithm
[
9
,
22
]
. Determining a sharp lower bound of
\alpha_{GP}
is a theoretically interesting problem. It is also important for practical scenarios since the choice of the stepsize
\alpha
affects the performance of the algorithm. More precisely, choosing larger value
\alpha>0
within the range
(0,\alpha_{GP}]
usually makes the gradient-push algorithm converge faster to an
O(\alpha)
-neighborhood of the minimizer since the convergence rate is lower bounded by
(1-c\alpha)
for a value
c>0
independent of
\alpha\in(0,\alpha_{GP}]
. Over the convergence result up to an
O(\alpha)
-neighborhood, one can achieve the exact convergence algorithm to the minimizer by reducing the stepsize
\alpha
repeatedly after suitable number of iterations. As an alternative way, we suggest to combine the gradient-push and the Push-DIGing algorithm
[
9
,
22
]
which converges to the minimizer exactly even for a constant stepsize by communicating also the gradient informations of the agents. The Push-DIGing algorithm is stated as follows:

\begin{split}\mathbf{x}_{i}(t+1)&=\sum_{j=1}^{n}W_{ij}\mathbf{x}_{j}(t)-\alpha\mathbf{v}_{i}(t)\\
\mathbf{y}_{i}(t+1)&=\sum_{j=1}^{n}W_{ij}\mathbf{y}_{j}(t)\\
\mathbf{z}_{i}(t+1)&=\frac{\mathbf{x}_{i}(t+1)}{\mathbf{y}_{i}(t+1)}\\
\mathbf{v}_{i}(t+1)&=\sum_{j=1}^{n}W_{ij}\mathbf{v}_{j}(t)+\nabla f_{i}(\mathbf{z}_{i}(t+1))-\nabla f_{i}(\mathbf{z}_{i}(t)),\end{split}

(1.3)

where
\mathbf{v}_{i}(0)=\nabla f_{i}(\mathbf{z}_{i}(0))
. It was shown in the works
[
9
,
22
]
that the Push-DIGing algorithm converges linearly to the minimizer when the constant stepsize
\alpha>0
is less than a specific value. Precisely, there are a value
M>0
and a value
\bar{\alpha}>0
such that for
\alpha\in(0,\bar{\alpha})
we have

\sum_{k=1}^{n}\|z_{k}(t+1)-x_{*}\|\leq M(1-\gamma\alpha)^{t},

where
\gamma>0
is a value determined by the properties of the cost functions and the
matrix
W
. Similarly to the gradient-push algorithm, we consider the following definition.

Definition 1.3
.

We denote by
\alpha_{PD}>0
the largest constant such that for
\alpha\in(0,\alpha_{PD}]
the Push-DIGing algorithm converges linearly to the minimizer.

Although some lower bound of
\alpha_{PD}
is achieved in
[
9
,
22
]
, the exact value of
\alpha_{PD}>0
has not been attained theoretically. We performed a numerical test to check that
\alpha_{PD}\ll\alpha_{GP}
holds for a linear regression problem (refer to Figure
2
for the detail). Consequently, the Push-DIGing is much slower than the gradient-push algorithm up to a certain number of iterations although the Push-DIGing converges to the minimizer exactly. Figure

shows the convergence result with respect to the iteration

where

and

are random matrices whose elements are selected uniformly randomly in the interval

with dimensions

and

and the numbers of agents is

with the mixing matrix

2.
Convergence results

In this section, we state preliminary main results for showing the convergence result of Theorem
1.2
.
To recall the result of
[
11
]
, we define the following constant

\delta=\max_{t\in\mathbb{N}_{0}}\max_{1\leq i\leq n}\frac{1}{y_{i}(t)}

and consider the following value

\rho:=|||W-W^{\infty}|||_{\pi}.

(2.1)

It was proved in
[
34
]
that we have
\rho\in(0,1)
when Assumption 1 holds true.

Theorem 2.1

(
[
11
]
)
.

Suppose that each cost is
L
-smooth and the aggregate cost
f
is
\beta
-strongly convex for some
\beta>0
. Let
\gamma=\frac{\beta L}{\beta+L}
,
q=\frac{n\gamma}{4L\delta}
and assume that
\alpha>0
satisfies
\alpha\leq\frac{2}{L+\beta}
and
\alpha<Q
with
Q>0
defined as

Q=\frac{q(1-\rho)}{L\rho(\delta q+\delta{\|1_{n}-n\pi\|_{\pi\otimes 1_{d}}}+\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}})}.

(2.2)

Then for each
1\leq i\leq n
, the sequence
\{z_{i}(t)\}_{t\geq 0}
converges to an
O(\alpha)
-neighborhood of the optimal point
x_{*}
exponentially fast.

Remark 2.2
.

Note that
\gamma<\beta
and
q<\frac{n\beta}{4L\delta}
. Using this we find

Q<\frac{q(1-\rho)}{L\rho(\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}})}<\frac{n\beta(1-\rho)}{4L^{2}\rho\delta\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}}}.

(2.3)

From this we find that
Q=O(1/L^{2})
and so the range
(0,Q)
for the stepsize of the convergence result of Theorem
2.1
is quite restrictive when the smoothness constant
L>0
is large.

The result of Theorem
1.2
improves the range of the stepsize given in Theorem
2.1
from
\alpha=O(1/L^{2})
to
\alpha=O(1/L)
when each local cost is convex. To obtain this result, we begin by writing the gradient-push algorithm as follows:

w_{i}(t+1)=\sum_{j=1}^{n}W_{ij}\Big(w_{j}(t)-\alpha\nabla f_{j}\Big(\frac{w_{j}(t)}{y_{j}(t)}\Big)\Big),

(2.4)

and recall from
[
10
]
that there exist
a>0
such that

\Big\|\frac{1}{y_{j}(t)}-\frac{1}{n\pi_{j}}\Big\|\leq a\rho^{t}

(2.5)

for all
1\leq j\leq n
. Now we introduce the mapping
T_{\alpha}
:
\mathbb{R}^{nd}

\rightarrow

\mathbb{R}^{nd}
defined as

T_{\alpha}(w)=\Big(\sum_{j=1}^{n}W_{1j}\Big(w_{j}-\alpha\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)\Big)^{\top},\cdots,\sum_{j=1}^{n}W_{nj}\Big(w_{j}-\alpha\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)\Big)^{\top}\Big)^{\top}

(2.6)

and write the algorithm (
2.4

w(t+1)=T_{\alpha}\big(w(t)\big)+\alpha P_{t}(w(t)),

(2.7)

where
P_{t}
:
\mathbb{R}^{nd}

\rightarrow

\mathbb{R}^{nd}

P_{t}(w)=\Big(\sum_{j=1}^{n}W_{1j}\Big(\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)-\nabla f_{j}\Big(\frac{w_{j}}{y_{j}(t)}\Big)\Big)^{\top},\cdots,\sum_{j=1}^{n}W_{nj}\Big(\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)-\nabla f_{j}\Big(\frac{w_{j}}{y_{j}(t)}\Big)\Big)^{\top}\Big)^{\top}

(2.8)

for

Using the convergence property (

. This motivates us to study the contraction property of the mapping
T_{\alpha}
in the following theorem.

Theorem 2.3
.

Case 1:

Each cost
f_{k}
is
\mu_{k}
-strongly convex and
L_{k}
-smooth for

. The stepsize is assumed to satisfy
\alpha\in(0,\alpha_{0}]

\alpha_{0}=\min_{1\leq k\leq n}\frac{2n\pi_{k}}{L_{k}+\mu_{k}}

Case 2:

Each cost

is given by convex quadratic form as

for a symmetric positive semi-definite matrix

and

and the aggregate cost

The stepsize is assumed to satisfy

For the above two cases, the mapping

The proof of this result will be given in Section

In this section, we investigate the contraction property of the mapping

We begin with recalling the following Lemma.

Lemma 3.1
.

Suppose g:
\mathbb{R}^{nd}

\rightarrow

\mathbb{R}
is
\mu
-strongly convex and
L
-smooth for some
L
>
0 and
\mu
>
0. Then

\langle x-y,\nabla g(x)-\nabla g(y)\rangle\geq\frac{\mu L}{\mu+L}\|x-y\|^{2}+\frac{1}{\mu+L}\|\nabla g(x)-\nabla g(y)\|^{2}.

holds for all
x
,
y

\in

\mathbb{R}^{nd}

Proof.

We refer to
[
5
]
for a proof of this Lemma.
∎

Using this Lemma, one may prove the following well-known result.

Lemma 3.2
.

Suppose g:
\mathbb{R}^{d}

\rightarrow

\mathbb{R}
is
\mu
-strongly convex and
L
-smooth for some
L>0
and
\mu>0
. Then for any
\alpha\in\big(0,\frac{2}{\mu+L}\big]
, the following estimate holds.

\|x-y-\alpha(\nabla g(x)-\nabla g(y))\|\leq(1-\gamma\alpha)\|x-y\|\quad\forall~x,y\in\mathbb{R}^{d},

where
\gamma=\frac{\mu L}{\mu+L}
.

Proof.

We give a proof for the reader’s convenience. Using Lemma
3.1
, we get

\begin{split}&\|x-y-\alpha(\nabla g(x)-\nabla g(y))\|^{2}\\
&=\|x-y\|^{2}-2\alpha\langle x-y,\nabla g(x)-\nabla g(y)\rangle+\alpha^{2}\|\nabla g(x)-\nabla g(y)\|^{2}\\
&\leq\Big(1-\frac{2\alpha\mu L}{\mu+L}\Big)\|x-y\|^{2}+\Big(\alpha^{2}-\frac{2\alpha}{\mu+L}\Big)\|\nabla g(x)-\nabla g(y)\|^{2}.\end{split}

This inequality for
\alpha\leq\frac{2}{\mu+L}
yields

\begin{split}\|x-y-\alpha(\nabla g(x)-\nabla g(y))\|^{2}&\leq\Big(1-\frac{2\mu L}{\mu+L}\alpha\Big)\|x-y\|^{2}\\
&\leq\Big(1-\frac{\mu L}{\mu+L}\alpha\Big)^{2}\|x-y\|^{2}.\end{split}

The proof is done.
∎

Based on this lemma, we derive the following result.

Lemma 3.3
.

Suppose that for
1\leq k\leq n
, the local cost
f_{k}
is
L_{k}
-smooth and
\mu_{k}
-strongly convex. Then, for
{\alpha}\leq\Big(0,~\min_{1\leq k\leq n}\frac{2{n\pi_{k}}}{\mu_{k}+L_{k}}\Big]
we have

\Big\|w-v-\alpha\Big(\nabla F\Big(\frac{w}{n\pi}\Big)-\nabla F\Big(\frac{v}{n\pi}\Big)\Big)\Big\|_{\pi\otimes 1_{d}}\leq(1-C\alpha)\|w-v\|_{\pi\otimes 1_{d}},

where
C=\min_{1\leq k\leq n}\frac{\mu_{k}L_{k}}{n\pi_{k}(\mu_{k}+L_{k})}
.

Proof.

If the stepsize satisfies
\frac{\alpha}{n\pi_{k}}\leq\frac{2}{\mu_{k}+L_{k}}
for each
1\leq k\leq n
, we have

\Big\|\frac{w_{k}}{n\pi_{k}}-\frac{v_{k}}{n\pi_{k}}-\frac{\alpha}{n\pi_{k}}\Big(\nabla f_{k}\Big(\frac{w_{k}}{n\pi_{k}}\Big)-\nabla f_{k}\Big(\frac{v_{k}}{n\pi_{k}}\Big)\Big)\Big\|\leq\Big(1-\frac{\mu_{k}L_{k}}{\mu_{k}+L_{k}}\cdot\frac{\alpha}{n\pi_{k}}\Big)\Big\|\frac{w_{k}}{n\pi_{k}}-\frac{v_{k}}{n\pi_{k}}\Big\|,

which gives

\Big\|w_{k}-v_{k}-\alpha\Big(\nabla f_{k}\Big(\frac{w_{k}}{n\pi_{k}}\Big)-\nabla f_{k}\Big(\frac{v_{k}}{n\pi_{k}}\Big)\Big)\Big\|\leq\Big(1-\frac{\mu_{k}L_{k}}{\mu_{k}+L_{k}}\cdot\frac{\alpha}{n\pi_{k}}\Big)\|{w_{k}}-{v_{k}}\|.

This directly yields

\begin{split}\Big\|w-v-\alpha\Big(\nabla F\Big(\frac{w}{n\pi}\Big)-\nabla F\Big(\frac{v}{n\pi}\Big)\Big)\Big\|_{\pi\otimes 1_{d}}&\leq\max_{1\leq k\leq n}\Big(1-\frac{\mu_{k}L_{k}\alpha}{n\pi_{k}(\mu_{k}+L_{k})}\Big)\|w-v\|_{\pi\otimes 1_{d}}\\
&\leq\Big(1-\Big[\min_{1\leq k\leq n}\frac{\mu_{k}L_{k}}{n\pi_{k}(\mu_{k}+L_{k})}\Big]\alpha\Big)\|w-v\|_{\pi\otimes 1_{d}}.\end{split}

The proof is done.
∎

Define a function
J(w):\mathbb{R}^{nd}\rightarrow\mathbb{R}^{nd}
as

J(w)=\Big(\sum_{j=1}^{n}W_{1j}w_{j}^{\top},\cdots,\sum_{j=1}^{n}W_{nj}w_{j}^{\top}\Big)^{\top}\quad\textrm{for}~w=(w_{1}^{\top},\cdots,w_{n}^{\top})^{\top}\in\mathbb{R}^{nd}.

(3.1)

We have the following result.

Lemma 3.4
.

We have

\|J(x)\|_{\pi\otimes 1_{d}}\leq\|x\|_{\pi\otimes 1_{d}}\quad\forall~x\in\mathbb{R}^{nd}.

(3.2)

In addition, the equality holds if and only if there exists a vector
\zeta\in\mathbb{R}^{d}
such that

x_{j}=\pi_{j}\zeta\quad\textrm{for}~1\leq j\leq n.

(3.3)

Proof.

By the triangle inequality, for any
x\in\mathbb{R}^{nd}

\begin{split}\|J(x)\|_{\pi\otimes 1_{d}}&=\Big[\sum_{k=1}^{n}\frac{1}{\pi_{k}}\|\sum_{j=1}^{n}W_{kj}x_{j}\|^{2}\Big]^{\frac{1}{2}}\\
&\leq\Big[\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big(\sum_{j=1}^{n}W_{kj}\|x_{j}\|\Big)^{2}\Big]^{\frac{1}{2}}\\
&=\Big[\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big(\sum_{j=1}^{n}\sqrt{W_{kj}\pi_{j}}\frac{\sqrt{W_{kj}}}{\sqrt{\pi_{j}}}\|x_{j}\|\Big)^{2}\Big]^{\frac{1}{2}}.\end{split}

(3.4)

We use the Cauchy-Schwartz inequality to get

\begin{split}\|J(x)\|_{\pi\otimes 1_{d}}&\leq\Big[\sum_{k=1}^{n}\frac{1}{\pi_{k}}\sum_{j=1}^{n}W_{kj}\pi_{j}\sum_{j=1}^{n}\frac{W_{kj}}{\pi_{j}}\|x_{j}\|^{2}\Big]^{\frac{1}{2}}\\
&=\Big[\sum_{k=1}^{n}\sum_{j=1}^{n}\frac{W_{kj}}{\pi_{j}}\|x_{j}\|^{2}\Big]^{\frac{1}{2}}\\
&=\Big[\sum_{j=1}^{n}\frac{1}{\pi_{j}}\|x_{j}\|^{2}\Big]^{\frac{1}{2}}=\|x\|_{\pi\otimes 1_{d}},\end{split}

(3.5)

where we used (
1.1
) in the first equality and (
2
) in the second equality.

Next we assume that
x\in\mathbb{R}^{nd}
satisfies the equality of the inequality (
3.2
). Then the two inequalities in (
3.4
) and (
3.5
) should hold equality. For each
1\leq k\leq n
, we set
I_{k}=\{j\in\{1,2,3\cdots,n\}~|~W_{kj}\neq 0\}
.
By the equality condition of the Cauchy-Schwarz inequality of (
3.5
), the following ratios

\frac{\sqrt{W_{kj}}}{\sqrt{\pi_{j}}}\|x_{j}\|\Big/\sqrt{W_{kj}\pi_{j}}=\frac{\|x_{j}\|}{\pi_{j}}

are same for all
j\in I_{k}
. Combining this with the fact that the graph induced by
\{W_{kj}\}
is connected, we see that

\frac{\|x_{1}\|}{\pi_{1}}=\frac{\|x_{2}\|}{\pi_{2}}=\cdots=\frac{\|x_{n}\|}{\pi_{n}}.

(3.6)

As the inequality (
3.4
) holds equality, we find that equalities hold in the following inequalities.

\|\sum_{j=1}^{n}W_{kj}x_{j}\|\leq\sum_{j=1}^{n}W_{kj}\|x_{j}\|\quad\forall 1\leq k\leq n.

(3.7)

Using this and the equality condition of the triangle inequality, for each
1\leq k\leq n
there are nonnegative constants
c_{jk}
for
j\in I_{k}
such that
x_{j}=c_{jk}x_{k}
. Combining this with the fact that the network induced by
\{W_{kj}\}
is connected, we find that for any
1\leq j,k\leq n
, there are values
c_{jk}\geq 0
such that
x_{j}=c_{jk}x_{k}
. This, together with (
3.6
), yields that there exists a vector
\zeta\in\mathbb{R}^{d}
such that
x_{j}=\pi_{j}\zeta
for
1\leq j\leq n
. It finishes the proof.
∎

Now we give the proof of Theorem
2.3
for Case 1.

Proof of Theorem
2.3
for Case 1.

Using the definition (
2.6
) of
T_{\alpha}
we find

\begin{split}&\|T_{\alpha}(w)-T_{\alpha}(v)\|_{\pi\otimes 1_{d}}\\
&=\Big(\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big\|\sum_{j=1}^{n}W_{kj}\Big(w_{j}-v_{j}-\alpha\Big(\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)-\nabla f_{j}\Big(\frac{v_{j}}{n\pi_{j}}\Big)\Big)\Big)\Big\|^{2}\Big)^{\frac{1}{2}}\\
&=\Big\|J\Big(w-v-\alpha\Big(\nabla F\Big(\frac{w}{n\pi}\Big)-\nabla F\Big(\frac{v}{n\pi}\Big)\Big)\Big)\Big\|_{\pi\otimes 1_{d}},\end{split}

where we have set
\nabla F\Big(\frac{w}{n\pi}\Big)=\Big(\nabla f_{1}\Big(\frac{w_{1}}{n\pi_{1}}\Big)^{\top},\cdots,\nabla f_{n}\Big(\frac{w_{n}}{n\pi_{n}}\Big)^{\top}\Big)^{\top}
. Now we apply Lemma
3.4
and Lemma
3.3
to derive the following estimate

\begin{split}\|T_{\alpha}(w)-T_{\alpha}(v)\|_{\pi\otimes 1_{d}}&\leq\|w-v-\alpha\Big(\nabla F\Big(\frac{w}{n\pi}\Big)-\nabla F\Big(\frac{v}{n\pi}\Big)\Big)\|_{\pi\otimes 1_{d}}\\
&\leq(1-C\alpha)\|w-v\|_{\pi\otimes 1_{d}},\end{split}

The proof is done.
∎

In order to prove Theorem
2.3
for Case 2, we prepare the following Lemma.

Lemma 3.5
.

Let
A

\in

\mathbb{R}^{d\times d}
be a symmetric and positive semidefinite matrix. Then, for any
\alpha

\in

(0,\frac{2}{\max\lambda(A)})
, the following inequality holds

\|\big(I_{d}-\alpha A\big)x\|\leq\|x\|.\quad\forall x\in\mathbb{R}^{d}.

The equality in the above inequality holds if and only if

Ax=0.

Proof.

Since
A
is symmetric, it is diagonalizable in the sense that

A=UDU^{\top},

where
D\in\mathbb{R}^{d\times d}=\textrm{diag}(\lambda_{1},\cdots,\lambda_{d})
is a diagonoal matrix whose entries are eigenvalues of
A
and
U\in\mathbb{R}^{d\times d}
satisfies
UU^{\top}=U^{\top}U=I_{d}
. Using this decomposition, we find the following equality

\begin{split}\|\big(I_{d}-\alpha A\big)x\|&=\|\big(I_{d}-\alpha UDU^{\top}\big)x\|\\
&=\|\big(UU^{\top}-\alpha UDU^{\top}\big)x\|\\
&=\|\big(U^{\top}-\alpha DU^{\top}\big)x\|\\
&=\|\big(I_{d}-\alpha D\big)U^{\top}x\|.\end{split}

Letting
w=U^{\top}x\in\mathbb{R}^{d}
in the above equality gives

\begin{split}\|\big(I_{d}-\alpha A\big)x\|&=\|\big(I_{d}-\alpha D\big)w\|\\
&=\Big(\sum_{k=1}^{d}(1-\alpha\lambda_{k})^{2}w_{k}^{2}\Big)^{\frac{1}{2}}.\end{split}

(3.8)

Since
A
is positive semi-definite, we have
\lambda_{j}\geq 0
for
1\leq j\leq d
. Combining this with the assumption
\alpha\in(0,\frac{2}{\max\lambda(A)})
, it follows that
-1<1-\alpha\lambda_{k}\leq 1
. Therefore we have

(1-\alpha\lambda_{k})^{2}w_{k}^{2}\leq w_{k}^{2}\quad

(3.9)

for any
1\leq k\leq d
. Inserting this inequality in (
3.8
) we get

\begin{split}\|\big(I_{d}-\alpha A\big)x\|&\leq\Big(\sum_{k=1}^{d}w_{k}^{2}\Big)^{\frac{1}{2}}=\|w\|=\|x\|,\end{split}

(3.10)

which is the desired inequality.

Now we proceed to prove the equality condition of the inequality. If
Ax=0
, then it is trivial that
\|\big(I_{d}-\alpha A\big)x\|=\|x\|
.

Conversely, we suppose that
\|\big(I_{d}-\alpha A\big)x\|=\|x\|
. Then for all
1\leq k\leq d
, the inequality (
3.9
) should hold equality, i.e.,

(1-\alpha\lambda_{k})^{2}w_{k}^{2}=w_{k}^{2},

which leads to

\alpha(2-\alpha\lambda_{k})\lambda_{k}w_{k}^{2}=0.

Combining this with the fact that
(2-\alpha\lambda_{k})>0
for
\alpha\in\Big(0,\frac{2}{\max\lambda(A)}\Big)
, it follows that

\lambda_{k}w_{k}=0

for all
1\leq k\leq d
. This implies that
Dw=0
, and so we have
Ax=UDU^{\top}x=UDw=0.

The proof is done.

∎

Using the above lemma, we proceed to prove Theorem
2.3
for Case 2.

Proof of Theorem
2.3
for Case 2.

For each
\alpha\in\Big(0,\min_{1\leq k\leq n}\frac{2n\pi_{k}}{L_{k}}\Big)
, we aim to show that

\sup_{w\neq v}\frac{\|T_{\alpha}(w)-T_{\alpha}(v)\|_{\pi\otimes 1_{d}}}{\|w-v\|_{\pi\otimes 1_{d}}}<1.

We define
L_{\alpha}

:

\mathbb{R}^{nd}

\rightarrow

\mathbb{R}^{nd}
as
L_{\alpha}(x)=\Big(L_{\alpha}(x)_{1}^{\top},\cdots,L_{\alpha}(x)_{n}^{\top}\Big)^{\top}
with

\big(L_{\alpha}(x)\big)_{k}=\sum_{j=1}^{n}W_{kj}\Big(I_{d}-\frac{\alpha A_{j}}{n\pi_{j}}\Big)x_{j}\in\mathbb{R}^{d}

for
1\leq k\leq n
. Using
\nabla f_{j}(x)=A_{j}x+B_{j}^{\top}
we find

\Big(T_{\alpha}(w)-T_{\alpha}(v)\Big)=L_{\alpha}(w-v).

Therefore, the desired inequality (
3
) is equivalent to

\sup_{x\neq 0}\frac{\|L_{\alpha}(x)\|_{\pi\otimes 1_{d}}}{\|x\|_{\pi\otimes 1_{d}}}<1.

(3.11)

In order to show this inequality, we first show that the term in the left hand side is less or equal to
1
.

For any
w=(w_{1}^{\top},\cdots,w_{n}^{\top})^{\top}\in\mathbb{R}^{nd}
, we notice that

\begin{split}\|L_{\alpha}(w)\|_{\pi\otimes 1_{d}}&=\Big[\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big\|\sum_{j=1}^{n}W_{kj}\Big(w_{j}-\alpha A_{j}\frac{w_{j}}{n\pi_{j}}\Big)\Big\|^{2}\Big]^{\frac{1}{2}}\\
&=\|J\Big(w-\alpha\Big(A\Big(\frac{w}{n\pi}\Big)\Big)\Big)\|_{\pi\otimes 1_{d}},\end{split}

(3.12)

where we have let
A\Big(\frac{w}{n\pi}\Big)=\Big(\Big(A_{1}\frac{w_{1}}{n\pi_{1}}\Big)^{\top},\cdots,\Big(A_{n}\frac{w_{n}}{n\pi_{n}}\Big)^{\top}\Big)^{\top}
.

Using Lemma
3.4
and Lemma
3.5
with the fact that
\alpha\in(0,\frac{2n\pi_{j}}{\max\lambda(A_{j})}]
for all
1\leq j\leq n
, we have

\displaystyle\|L_{\alpha}(w)\|_{\pi\otimes 1_{d}}

\displaystyle\leq\|w-\alpha\Big(A\Big(\frac{w}{n\pi}\Big)\Big)\|_{\pi\otimes 1_{d}}

(3.13)

\displaystyle\leq\|w\|_{\pi\otimes 1_{d}}.

(3.14)

Therefore we have

\sup_{w\neq 0}\frac{\|L_{\alpha}(w)\|_{\pi\otimes 1_{d}}}{\|w\|_{\pi\otimes 1_{d}}}\leq 1.

(3.15)

Now we aim to show that the above inequality is strict. For this we note that, since
L_{\alpha}
is linear,

\sup_{x\neq 0}\frac{\|L_{\alpha}(x)\|_{\pi\otimes 1_{d}}}{\|x\|_{\pi\otimes 1_{d}}}=\sup_{x\in\mathbb{S}^{nd-1}}\frac{\|L_{\alpha}(x)\|_{\pi\otimes 1_{d}}}{\|x\|_{\pi\otimes 1_{d}}},

where
\mathbb{S}^{nd-1}=\{x\in\mathbb{R}^{nd}:\|x\|=1\}
.

In order to show that the inequality (
3.15
) is strict, we assume the contrary that there exists a vector
x=(x_{1}^{\top},\cdots,x_{n}^{\top})^{\top}\in\mathbb{S}^{nd-1}
such that

\frac{\|L_{\alpha}(x)\|_{\pi\otimes 1_{d}}}{\|x\|_{\pi\otimes 1_{d}}}=1.

Then the inequalities of (
3.13
) and (
3.14
) with
w=x
should hold equality. As for the equality condition of (
3.14
), it follows from Lemma
3.5
the following identities

A_{j}x_{j}=0\quad\forall 1\leq j\leq n.

(3.16)

Then the equality condition of (
3.13
) is written as

\|J(x)\|_{\pi\otimes 1_{d}}=\|x\|_{\pi\otimes 1_{d}}.

By the equality condition of Lemma
3.4
, there exists a vector
\zeta\in\mathbb{R}^{d}
such that for all
1\leq j\leq n
,

x_{j}=\pi_{j}\zeta.

(3.17)

Inserting this form into (
3.16
), we find
A_{j}(\pi_{j}\zeta)=0
, and so
A_{j}\zeta=0
. Summing this over
1\leq j\leq n
, we get

\big(\sum_{j=1}^{n}A_{j}\big)\zeta=0.

(3.18)

Since the aggregate cost
f
is assumed to be
\mu
-strongly convex, the matrix
\big(\sum_{j=1}^{n}A_{j}\big)
is positive definite.
Thus, the equality (
3.18
) implies that
\zeta=0
. From this and (
3.17
) we have
x=0
. This is a contradiction to the prior assumption that
x\in\mathbb{S}^{nd-1}
. Therefore the equality (
3
) cannot hold and so (
3.11
) holds true, and (
3
) is verified.

Let
\alpha_{0}=\min_{1\leq j\leq n}\Big(\frac{2n\pi_{j}}{\{\max\lambda(A_{j})\}+\epsilon}\Big)
for a fixed value
\epsilon>0
. By (
3
) there exists a value
\eta_{\epsilon}\in(0,1)
such that

\|T_{\alpha_{0}}(w)-T_{\alpha_{0}}(v)\|_{\pi\otimes 1_{d}}\leq\eta_{\epsilon}\|w-v\|_{\pi\otimes 1_{d}}.

For any
\alpha\in(0,\alpha_{0}]
, we find from (
2.6
) and (
3.1
) the following identity

T_{\alpha}(w)=\frac{\alpha}{\alpha_{0}}T_{\alpha_{0}}(w)+\Big(1-\frac{\alpha}{\alpha_{0}}\Big)J(w).

By the triangle inequality and Lemma
3.4
, we obtain an upper bound of
\|T_{\alpha}(w)-T_{\alpha}(v)\|_{\pi\otimes 1_{d}}
as follows

\begin{split}\|T_{\alpha}(w)-T_{\alpha}(v)\|_{\pi\otimes 1_{d}}&\leq\frac{\alpha}{\alpha_{0}}\|T_{\alpha_{0}}(w)-T_{\alpha_{0}}(v)\|_{\pi\otimes 1_{d}}+\Big(1-\frac{\alpha}{\alpha_{0}}\Big)\|J(w-v)\|_{\pi\otimes 1_{d}}\\
&\leq\frac{\alpha}{\alpha_{0}}\|T_{\alpha_{0}}(w)-T_{\alpha_{0}}(v)\|_{\pi\otimes 1_{d}}+\Big(1-\frac{\alpha}{\alpha_{0}}\Big)\|w-v\|_{\pi\otimes 1_{d}}\\
&\leq\frac{\alpha}{\alpha_{0}}\eta_{\epsilon}\|w-v\|_{\pi\otimes 1_{d}}+\Big(1-\frac{\alpha}{\alpha_{0}}\Big)\|w-v\|_{\pi\otimes 1_{d}}\\
&=\Big(1-\frac{1-\eta_{\epsilon}}{\alpha_{0}}\alpha\Big)\|w-v\|_{\pi\otimes 1_{d}}.\end{split}

The proof is done.
∎

Proof of Theorem
2.4
.

By Theorem
2.3
, the mapping
T_{\alpha}
is contractive for any
\alpha\in(0,\alpha_{0}]
, and so there exist a unique fixed point
w^{\alpha}\in\mathbb{R}^{nd}
of the mapping
T_{\alpha}
.

In order to prove the uniform bound of
\{w^{\alpha}\}_{\alpha\in(0,\alpha_{0}]}
, we construct a sequence converging to
w^{\alpha}
. Namely, for a fixed value
\alpha\in(0,\alpha_{0}]
, we consider the sequence
\{u(t)\}_{t\geq 0}\subset\mathbb{R}^{nd}
such that
u(0)=0\in\mathbb{R}^{nd}
and
u(t+1)=T_{\alpha}(u(t))
for
t\geq 0
.
We use the contraction property (
2.9
) of
T_{\alpha}
to find

\begin{split}\|u(t+1)-u(t)\|_{\pi\otimes 1_{d}}&=\|T_{\alpha}^{t}(u(1))-T_{\alpha}^{t}(u(0))\|_{\pi\otimes 1_{d}}\\
&\leq(1-C\alpha)^{t}\|u(1)-u(0)\|_{\pi\otimes 1_{d}}.\end{split}

(3.19)

Next we use
w^{\alpha}=T_{\alpha}(w^{\alpha})
and (
2.9
) to deduce

\begin{split}\|u(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}&=\|T_{\alpha}(u(t))-T_{\alpha}(w^{\alpha})\|_{\pi\otimes 1_{d}}\\
&\leq(1-C\alpha)\|u(t)-w^{\alpha}\|_{\pi\otimes 1_{d}},\end{split}

and so
u(t)
converges to
w^{\alpha}
as
t\rightarrow\infty
. Combining this with (
3.19
), we get

\begin{split}\|w^{\alpha}-u(0)\|_{\pi\otimes 1_{d}}&\leq\sum_{t=0}^{\infty}\|u(t+1)-u(t)\|_{\pi\otimes 1_{d}}\\
&\leq\sum_{t=0}^{\infty}(1-C\alpha)^{t}\|u(1)-u(0)\|_{\pi\otimes 1_{d}}\\
&=\frac{1}{C\alpha}\|u(1)-u(0)\|_{\pi\otimes 1_{d}}.\end{split}

Now we use
u(0)=0\in\mathbb{R}^{nd}
and
u(1)=\alpha J(\nabla F(0))
to find

\|w^{\alpha}\|_{\pi\otimes 1_{d}}\leq\frac{1}{C}\|J(\nabla F(0))\|_{\pi\otimes 1_{d}}.

Therefore the set of the fixed points
\{w^{\alpha}\}_{\alpha\in(0,\alpha_{0}]}
is bounded.
The proof is done.
∎

4.
Convergence of the gradient-push algorithm to the fixed point of
T_{\alpha}

In this section, we give the proof of Theorem
2.5
regarding the convergence property of the gradient-push algorithm (
2.7
) towards the fixed point
w^{\alpha}
of the mapping
T_{\alpha}
. For this, we make use of the contraction property of the mapping
T_{\alpha}
obtained in Theorem
2.3
along with a bound of mapping
P_{t}(w)
of (
2.8
) attained in the following lemma.

Lemma 4.1
.

The mapping
P_{t}(w)
defined in (
2.8
) satisfies the following inequality

\|P_{t}(w)\|_{\pi\otimes 1_{d}}\leq b\rho^{t}\|w\|_{\pi\otimes 1_{d}}\quad\forall~w\in\mathbb{R}^{nd}\quad\textrm{and}\quad t\geq 0,

where we have set
b=aL
with constant
a>0
defined in (
2.5
).

Proof.

Using Lemma
3.4
and the
L
-smooth property of
f_{j}
, we deduce

\begin{split}\|P_{t}(w)\|_{\pi\otimes 1_{d}}^{2}&=\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big\|\sum_{j=1}^{n}W_{kj}\Big(\nabla f_{j}\Big(\frac{w_{j}}{n\pi_{j}}\Big)-\nabla f_{j}\Big(\frac{w_{j}}{y_{j}(t)}\Big)\Big)\Big\|^{2}\\
&\leq\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big\|\nabla f_{k}\Big(\frac{w_{k}}{n\pi_{k}}\Big)-\nabla f_{k}\Big(\frac{w_{k}}{y_{k}(t)}\Big)\Big\|^{2}\\
&\leq L^{2}\sum_{k=1}^{n}\frac{1}{\pi_{k}}\Big(\frac{1}{y_{k}(t)}-\frac{1}{n\pi_{k}}\Big)^{2}\big\|w_{k}\big\|^{2}\\
&\leq a^{2}L^{2}\rho^{2t}\sum_{k=1}^{n}\frac{1}{\pi_{k}}\big\|w_{k}\big\|^{2}=b^{2}\rho^{2t}\|w\|_{\pi\otimes 1_{d}}^{2}.\end{split}

The proof is done.
∎

In the following lemma, we give a bound of
V_{\alpha}
defined in (
2.11
).

Lemma 4.2
.

For
\alpha\in(0,\alpha_{0}]
, we have

V_{\alpha}\leq\exp\Big(\frac{\alpha_{0}b}{1-C\alpha_{0}}\frac{1}{1-\rho}\Big).

Proof.

For any
\alpha\in(0,\alpha_{0}]
, the following inequality holds

V_{\alpha}=\prod_{k=0}^{\infty}\Big(1+\frac{\alpha b\rho^{k}}{1-C\alpha}\Big)\leq\prod_{k=0}^{\infty}\Big(1+\frac{\alpha_{0}b\rho^{k}}{1-C\alpha_{0}}\Big).

Taking logarithm and using the fact that
\log(1+x)\leq x
, we get

\begin{split}\log\Big[\prod_{k=0}^{\infty}\Big(1+\frac{\alpha_{0}b\rho^{k}}{1-C\alpha_{0}}\Big)\Big]&=\sum_{k=0}^{\infty}\log\Big(1+\frac{\alpha_{0}b\rho^{k}}{1-C\alpha_{0}}\Big)\\
&\leq\sum_{k=0}^{\infty}\frac{\alpha_{0}b}{1-C\alpha_{0}}\rho^{k}\\
&=\frac{\alpha_{0}b}{(1-C\alpha_{0})(1-\rho)}.\end{split}

The proof is done.
∎

Now we are ready to prove Theorem
2.5
.

Proof of Theorem
2.5
.

Using the triangle inequality and (
2.7
) with the fact that
w^{\alpha}
is the fixed point of the mapping
T_{\alpha}
, we get

\begin{split}\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}&=\|T_{\alpha}(w(t))-T_{\alpha}(w^{\alpha})+\alpha P(w(t))\|_{\pi\otimes 1_{d}}\\
&\leq\|T_{\alpha}(w(t))-T_{\alpha}(w^{\alpha})\|_{\pi\otimes 1_{d}}+\alpha\|P(w(t))\|_{\pi\otimes 1_{d}}.\end{split}

(4.1)

Applying the contraction property of
T_{\alpha}
established in Theorem
2.3
and using
Lemma
4.1
, we obtain

\begin{split}\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}&\leq(1-C\alpha)\|w(t)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha b\rho^{t}\|w(t)\|_{\pi\otimes 1_{d}}\\
&=(1-C\alpha)\|w(t)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha b\rho^{t}\|w(t)-w^{\alpha}+w^{\alpha}\|_{\pi\otimes 1_{d}}.\end{split}

(4.2)

We use the triangle inequality and the bound of
\|w^{\alpha}\|_{\pi\otimes 1_{d}}
obtained in Theorem
2.4
to find

\begin{split}\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}&\leq(1-C\alpha+\alpha b\rho^{t})\|w(t)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha b\rho^{t}\|w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&\leq(1-C\alpha+\alpha b\rho^{t})\|w(t)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha bR\rho^{t}.\end{split}

Using the above inequality recursively, we get

\begin{split}\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}&\leq\big[\underbrace{\prod_{i=0}^{t}(1-C\alpha+\alpha b\rho^{i})}_{T_{1}}\big]\|w(0)-w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&\quad+\alpha bR\underbrace{\sum_{i=0}^{t-1}\big[\rho^{i}\prod_{k=i+1}^{t}(1-C\alpha+\alpha b\rho^{k})}_{T_{2}}\big]+\alpha bR\rho^{t}.\end{split}

(4.3)

In view of the definition (
2.11
) of
V_{\alpha}
, we have

T_{1}=(1-C\alpha)^{t+1}\prod_{i=0}^{t}\Big(1+\frac{\alpha b\rho^{i}}{1-C\alpha}\Big)\leq(1-C\alpha)^{t+1}V_{\alpha}.

(4.4)

Next we estimate
T_{2}
. Notice that

\begin{split}\prod_{k=i+1}^{t}(1-C\alpha+\alpha b\rho^{k})&=(1-C\alpha)^{t-i}\prod_{k=i+1}^{t}\Big(1+\frac{\alpha b\rho^{k}}{1-C\alpha}\Big)\\
&\leq(1-C\alpha)^{t-i}\prod_{k=0}^{\infty}\Big(1+\frac{\alpha b\rho^{k}}{1-C\alpha}\Big)\\
&=V_{\alpha}(1-C\alpha)^{t-i}.\end{split}

Using this inequality, we estimate
T_{2}
as follows:

\begin{split}T_{2}&\leq V_{\alpha}\sum_{i=0}^{t-1}\rho^{i}(1-C\alpha)^{t-i}=\left\{\begin{array}[]{ll}tV_{\alpha}\rho^{t}&~\textrm{if}~1-C\alpha=\rho\\
\frac{V_{\alpha}(1-C\alpha)}{1-C\alpha-\rho}\Big[(1-C\alpha)^{t}-\rho^{t}\Big]&~\textrm{if}~1-C\alpha\neq\rho.\end{array}\right.\end{split}

(4.5)

Putting (
4.4
) and (
4.5
) in (
4.3
), we get

\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}\leq V_{\alpha}(1-C\alpha)^{t+1}\|w(0)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\mathcal{R}(t),

where

\mathcal{R}(t)=\bigg\{\begin{array}[]{ll}tV_{\alpha}\alpha bR\rho^{t}+\alpha bR\rho^{t}&\textrm{if}~1-C\alpha=\rho\\
\frac{\alpha bRV_{\alpha}(1-C\alpha)}{1-C\alpha-\rho}\Big[(1-C\alpha)^{t}-\rho^{t}\Big]+\alpha bR\rho^{t}&\textrm{if}~1-C\alpha\neq\rho.\end{array}

The proof is completed.
∎

5.
Estimate for the distance between
w^{\alpha}
and
x_{*}

In the previous section, we studied the convergence property of the sequence
w(t)
of the algorithm (
2.4
) towards the unique fixed point
w^{\alpha}
of
T_{\alpha}
.
This section is devoted to estimate the distance between the fixed point
w^{\alpha}
and the minimizer
x_{*}
of the aggregate cost
f
. Namely, we prove the result of Theorem
2.6
. Also we give the proof of Theorem
1.2
at the end of this section.

For our purpose, we consider the average
\bar{w}^{\alpha}
of
w^{\alpha}=((w^{\alpha}_{1})^{\top},\cdots,(w^{\alpha}_{n})^{\top})^{\top}\in\mathbb{R}^{nd}
defined by

\bar{w}^{\alpha}=\frac{1}{n}\sum_{k=1}^{n}w_{k}^{\alpha},

and note that

W^{\infty}=\pi 1_{n}^{\top}

which leads to

(W^{\infty}\otimes I_{d})w^{\alpha}=(\pi 1_{n}^{\top}\otimes I_{d})w^{\alpha}=n\pi\otimes\bar{w}^{\alpha}.

(5.1)

We will find several estimates regarding the two quantities
\|w^{\alpha}-n\pi\otimes\bar{w}^{\alpha}\|_{\pi\otimes 1_{d}}
and
\|\bar{w}^{\alpha}-x_{*}\|
to prove Theorem
2.6
. In what follows, we consider the two cases and the value
\alpha_{0}
defined in Theorem
2.3
.

Lemma 5.1
.

For
\alpha\in(0,\alpha_{0}]
, the fixed point
w^{\alpha}
of
T_{\alpha}
satisfies

\|w^{\alpha}-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq\|w^{\alpha}-n\pi\otimes\bar{w}^{\alpha}\|_{\pi\otimes 1_{d}}+n\|\bar{w}^{\alpha}-x_{*}\|.

(5.2)

Proof.

We apply the triangle inequality to find

\|w^{\alpha}-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq\|w^{\alpha}-n\pi\otimes\bar{w}^{\alpha}\|_{\pi\otimes 1_{d}}+\|n\pi\otimes(\bar{w}^{\alpha}-x_{*})\|_{\pi\otimes 1_{d}}.

(5.3)

Using the stochastic property of
\pi
, we get

\|n\pi\otimes(\bar{w}^{\alpha}-x_{*})\|_{\pi\otimes 1_{d}}^{2}=\sum_{j=1}^{n}\frac{1}{\pi_{j}}(n\pi_{j})^{2}\|\bar{w}^{\alpha}-x_{*}\|^{2}=n^{2}\|\bar{w}^{\alpha}-x_{*}\|^{2}.

Combining this with (
5.3
) gives

\|w^{\alpha}-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq\|w^{\alpha}-n\pi\otimes\bar{w}^{\alpha}\|_{\pi\otimes 1_{d}}+n\|\bar{w}^{\alpha}-x_{*}\|.

The proof is done.
∎

We state a basic lemma.

Lemma 5.2
.

For any
n\times n
matrix
A
, we have

|||A\otimes I_{d}|||_{\pi\otimes 1_{d}}=|||A|||_{\pi}.

In the following lemma, we obtain an estimate of
\|\bar{w}^{\alpha}-x_{*}\|
using the strong convexity of the aggregate cost
f
.

Lemma 5.3
.

For
\alpha\in(0,\alpha_{0}]
, the fixed point
w^{\alpha}
of
T_{\alpha}
satisfies

\|\bar{w}^{\alpha}-x_{*}\|\leq\frac{L}{\gamma}\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|

(5.4)

where
\gamma=\frac{\mu\bar{L}}{\mu+\bar{L}}
with
\bar{L}=\frac{1}{n}\sum_{k=1}^{n}L_{k}
.

Proof.

The fixed point equation
w^{\alpha}=T_{\alpha}(w^{\alpha})
can be written as

w_{k}^{\alpha}=\sum_{j=1}^{n}W_{kj}\Big(w_{j}^{\alpha}-\alpha\nabla f_{j}\Big(\frac{w_{j}^{\alpha}}{n\pi_{j}}\Big)\Big).

Averaging this with the fact that
W
is column-stochastic, we get

\bar{w}^{\alpha}=\bar{w}^{\alpha}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}\Big(\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big).

We manipulate this as follows

\bar{w}^{\alpha}-x_{*}=\bar{w}^{\alpha}-x_{*}-\frac{\alpha}{n}\sum_{i=1}^{n}\nabla f_{i}\big(\bar{w}^{\alpha}\big)+\frac{\alpha}{n}\sum_{i=1}^{n}\Big(\nabla f_{i}\big(\bar{w}^{\alpha}\big)-\nabla f_{i}\Big(\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big)\Big).

Using the triangle inequality with Lemma
3.3
, we have

\|\bar{w}^{\alpha}-x_{*}\|\leq\Big(1-\frac{\gamma\alpha}{n}\Big)\|\bar{w}^{\alpha}-x_{*}\|+\frac{L\alpha}{n}\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|,

which gives

\|\bar{w}^{\alpha}-x_{*}\|\leq\frac{L}{\gamma}\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|.

The proof is done.
∎

We further estimate the right hand side of the inequality (
5.4
) in the following lemma.

Lemma 5.4
.

For
\alpha\in(0,\alpha_{0}]
, the fixed point
w^{\alpha}
of
T_{\alpha}
satisfies

\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|\leq\frac{\sqrt{\sum_{k=1}^{n}\frac{1}{\pi_{k}}}}{n}\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}.

Proof.

Using the Cauchy-Schwartz inequality, we estimate

\begin{split}\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|&=\frac{1}{n}\sum_{i=1}^{n}\frac{1}{\pi_{i}}\Big\|w_{i}^{\alpha}-n\pi_{i}\bar{w}^{\alpha}\Big\|\\
&\leq\frac{1}{n}\Big(\sum_{i=1}^{n}\frac{1}{\pi_{i}}\Big)^{\frac{1}{2}}\Big(\sum_{i=1}^{n}\frac{1}{\pi_{i}}\Big\|w_{i}^{\alpha}-n\pi_{i}\bar{w}^{\alpha}\Big\|^{2}\Big)^{\frac{1}{2}}.\end{split}

By the definition of weighted (
\pi\otimes 1_{d}
)-norm and (
5.1
), we get

\begin{split}\sum_{i=1}^{n}\Big\|\bar{w}^{\alpha}-\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|&\leq\frac{\sqrt{\sum_{k=1}^{n}\frac{1}{\pi_{k}}}}{n}\|w^{\alpha}-n\pi\otimes\bar{w}^{\alpha}\|_{\pi\otimes 1_{d}}\\
&=\frac{\sqrt{\sum_{k=1}^{n}\frac{1}{\pi_{k}}}}{n}\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}.\end{split}

The proof is done.
∎

Recall that we denote
\nabla F(\frac{w}{n\pi})=(\nabla f_{1}(\frac{w_{1}}{n\pi_{1}})^{\top},\cdots,\nabla f_{n}(\frac{w_{n}}{n\pi_{n}})^{\top})^{\top}
. In the following we will find a bound of the weighted consensus error
\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}
.

Proposition 5.5
.

For
\alpha\in(0,\alpha_{0}]
, the fixed point
w^{\alpha}
of
T_{\alpha}
satisfies

\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\leq\frac{\alpha\rho}{1-\rho}\Big[\frac{LR}{n\pi_{min}}+Q\Big]

where
\pi_{min}=\min_{1\leq j\leq n}\pi_{j}
and
Q=\|\nabla F(0)\|_{\pi\otimes 1_{d}}
.

Proof.

Using the fact that
w_{\alpha}
is the fixed point of
T_{\alpha}
, we proceed as follows:

\begin{split}&\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&=\|((I_{n}-W^{\infty})\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&=\Big\|[((I_{n}-W^{\infty})W)\otimes I_{d}]\Big(w^{\alpha}-\alpha\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big)\Big\|_{\pi\otimes 1_{d}}\\
&=\Big\|[(W-W^{\infty})\otimes I_{d}]\Big[((I_{n}-W^{\infty})\otimes I_{d})w^{\alpha}-\alpha\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big]\Big\|_{\pi\otimes 1_{d}},\end{split}

(5.5)

where we have used
W^{\infty}W=WW^{\infty}=(W^{\infty})^{2}=W^{\infty}
in the second and the third equalities. By the triangle inequality and Lemma
5.2
, we estimate (
5.5
) as follows:

\begin{split}&\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&\leq|||(W-W^{\infty})\otimes I_{d}|||_{\pi\otimes 1_{d}}\Big[\|((I_{n}-W^{\infty})\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha\Big\|\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}\Big]\\
&=|||W-W^{\infty}|||_{\pi}\Big[\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha\Big\|\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}\Big]\\
&=\rho\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}+\alpha\rho\Big\|\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}\end{split}

which leads to

\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\leq\frac{\alpha\rho}{1-\rho}\Big\|\nabla F\Big(\frac{w^{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}.

(5.6)

Considering the
L
-smoothness of
f_{i}
we find

\begin{split}\Big\|\nabla f_{i}\Big(\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big)\Big\|&\leq\Big\|\nabla f_{i}\Big(\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big)-\nabla f_{i}(0)\Big\|+\|\nabla f_{i}(0)\|\\
&\leq L\Big\|\frac{w_{i}^{\alpha}}{n\pi_{i}}\Big\|+\|\nabla f_{i}(0)\|.\end{split}

Using this we have

\begin{split}\Big\|\nabla F\Big(\frac{w_{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}&=\Big(\sum_{j=1}^{n}\frac{1}{\pi_{j}}\Big\|\nabla f_{j}\Big(\frac{w_{j}^{\alpha}}{n\pi_{j}}\Big)\Big\|^{2}\Big)^{\frac{1}{2}}\\
&\leq\Big(\sum_{j=1}^{n}\frac{1}{\pi_{j}}\Big(L^{2}\frac{\|w_{j}^{\alpha}\|^{2}}{(n\pi_{j})^{2}}\Big)\Big)^{\frac{1}{2}}+\Big(\sum_{j=1}^{n}\frac{1}{\pi_{j}}\|\nabla f_{j}(0)\|^{2}\Big)^{\frac{1}{2}}\end{split}

Applying Theorem
2.4
we get

\begin{split}\Big\|\nabla F\Big(\frac{w_{\alpha}}{n\pi}\Big)\Big\|_{\pi\otimes 1_{d}}&\leq\frac{L}{n\pi_{min}}\Big(\sum_{j=1}^{n}\frac{1}{\pi_{j}}\|w_{j}^{\alpha}\|^{2}\Big)^{\frac{1}{2}}+Q\\
&=\frac{L}{n\pi_{min}}\|w^{\alpha}\|_{\pi\otimes 1_{d}}+Q\\
&\leq\frac{L}{n\pi_{min}}R+Q\end{split}

where
Q=\Big(\sum_{j=1}^{n}\frac{1}{\pi_{j}}\|\nabla f_{j}(0)\|^{2}\Big)^{\frac{1}{2}}
.
Putting this estimate in (
5.6
), we have

\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\leq\frac{\alpha\rho}{1-\rho}\Big(\frac{LR}{n\pi_{min}}+Q\Big).

(5.7)

The proof is done.
∎

Combining the above lemmas, we proceed to prove the result of Theorem
2.6
.

Proof of Theorem
2.6
.

Applying Lemma
5.4
to Lemma
5.3
, we have

\|\bar{w}^{\alpha}-x_{*}\|\leq\frac{L}{n\gamma}\sqrt{\sum_{k=1}^{n}\frac{1}{\pi_{k}}}\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}.

(5.8)

Using the relation (
5.1
) in the inequality (
5.2
) we find

\|w^{\alpha}-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}+n\|\bar{w}^{\alpha}-x_{*}\|.

Inserting (
5.8
) and Proposition
5.5
to the above inequality, we get

\begin{split}\|w^{\alpha}-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}&\leq\Big(1+\frac{L}{\gamma}\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}}\Big)\|w^{\alpha}-(W^{\infty}\otimes I_{d})w^{\alpha}\|_{\pi\otimes 1_{d}}\\
&\leq\frac{\alpha\rho}{1-\rho}\Big(1+\frac{L}{\gamma}\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}}\Big)\Big(\frac{LR}{n\pi_{min}}+Q\Big).\end{split}

The proof is done.
∎

Now we are ready to prove Theorem
1.2
.

Proof of Theorem
1.2
.

Consider the two cases and the value
\alpha_{0}>0
of Theorem
2.3
.
Consider the sequence
w(t)\in\mathbb{R}^{nd}
of the algorithm (
2.4
) with stepsize
\alpha>0
with initial point
w(0)
. Then, the result of Theorem
2.5
gives

\|w(t+1)-w^{\alpha}\|_{\pi\otimes 1_{d}}\leq V_{\alpha}(1-C\alpha)^{t+1}\|w(0)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\mathcal{R}(t).

Combining this with the result of Theorem
2.6
and the triangle inequality gives

\begin{split}\|w(t+1)-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq&V_{\alpha}(1-C\alpha)^{t+1}\|w(0)-w^{\alpha}\|_{\pi\otimes 1_{d}}+\mathcal{R}(t)\\
&\quad+\frac{\alpha\rho}{1-\rho}\Big(1+\frac{L}{\gamma}\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}}\Big)\Big(\frac{LR}{n\pi_{min}}+Q\Big).\end{split}

Therefore we have

\lim_{t\rightarrow\infty}\|w(t+1)-n\pi\otimes x_{*}\|_{\pi\otimes 1_{d}}\leq\frac{\alpha\rho}{1-\rho}\Big(1+\frac{L}{\gamma}\sqrt{\sum_{j=1}^{n}\frac{1}{\pi_{j}}}\Big)\Big(\frac{LR}{n\pi_{min}}+Q\Big),

which implies that for each
1\leq k\leq n
, the sequence
\{w_{k}(t)\}_{t\geq 0}
converges to an
O(\alpha)
-neighborhood of
n\pi_{k}x_{*}
exponentially fast. We recall from (
1.2
) and (
2.5
) that
z_{k}(t)=w_{k}(t)/y_{k}(t)
and
y_{k}(t)
converges to
n\pi_{k}
exponentially fast. Therefore, the sequence
\{z_{k}(t)\}_{t\geq 0}
converges to an
O(\alpha)
-neighborhood of
x_{*}
linearly as
t\rightarrow\infty
. The proof is done.
∎

6.1.
Contraction property of the mapping

First we validate numerically the contraction property of

for
\alpha\in(0,\alpha_{0}]
proved in Theorem
2.3
. We mention that for both Case 1 and Case 2, the local costs are given by the form
f_{j}(x)=\frac{1}{2}x^{\top}P_{j}x+q_{j}x
(ignore the constant part) for

(P_{j},q_{j})=\bigg\{\begin{array}[]{ll}(A_{j}^{\top}A_{j}+\delta I_{d},-2A_{j}^{\top}b_{j})&\textrm{for Case 1}\\
(A_{j},b_{j})&\textrm{for Case 2}.\end{array}

and so the operator
T_{\alpha}
satisfies

\begin{split}&T_{\alpha}(x)-T_{\alpha}(y)\\
&=\Big(\sum_{j=1}^{n}W_{1j}(I-\alpha P_{j})(x_{j}-y_{j})^{\top},\cdots,\sum_{j=1}^{n}W_{nj}(I-\alpha P_{j})(x_{j}-y_{j})^{\top}\Big)^{\top}\\
&=:M_{\alpha}(x-y),\end{split}

where

is an
nd\times nd
matrix whose

-matrix

for
1\leq i,j\leq n

of

\begin{split}\mathcal{L}_{\alpha}&=\sup_{x\neq y}\frac{\|T_{\alpha}(x)-T_{\alpha}(y)\|_{\pi\otimes 1_{d}}}{\|x-y\|_{\pi\otimes 1_{d}}}=\sup_{x\neq y}\frac{\|M_{\alpha}(x-y)\|_{\pi\otimes 1_{d}}}{\|x-y\|_{\pi\otimes 1_{d}}}\\
&=\sup_{x\in\mathbb{R}^{nd}\setminus\{0\}}\frac{\|D^{-1}M_{\alpha}x\|_{L^{2}(\mathbb{R}^{nd})}}{\|D^{-1}x\|_{L^{2}(\mathbb{R}^{nd})}},\end{split}

where

nd\times nd
matrix given by
\textrm{Diag}(\sqrt{\pi_{1}},\cdots,\sqrt{\pi_{n}})\otimes I_{d}
.
Letting

, we estimate

\begin{split}\mathcal{L}_{\alpha}&=\sup_{y\in\mathbb{R}^{nd}\setminus\{0\}}\frac{\|D^{-1}M_{\alpha}Dy\|_{L^{2}(\mathbb{R}^{nd})}}{\|y\|_{L^{2}(\mathbb{R}^{nd})}}\\
&=|||D^{-1}M_{\alpha}D|||_{L^{2}\rightarrow L^{2}},\end{split}

We compute the value
