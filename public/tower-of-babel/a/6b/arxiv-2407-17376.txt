Distance reconstruction of sparse random graphs
Paul Bastide

Abstract
In the distance query model, we are given access to the vertex set of a n n -vertex graph G G , and an oracle that takes as input two vertices and returns the distance between these two vertices in G G . We study how many queries are needed to reconstruct the edge set of G G when G G is sampled according to the G ⁡ ( n , p ) G(n,p) Erdős-Renyi-Gilbert distribution. Our approach applies to a large spectrum of values for p p starting slightly above the connectivity threshold: p ⩾ 2000 ​ log ⁡ n n p\geqslant\frac{2000\log n}{n} . We show that there exists an algorithm that reconstructs G ∼ G ⁡ ( n , p ) G\sim G(n,p) using O ⁡ ( Δ 2 ​ n ​ log ⁡ n ) O(\Delta^{2}n\log n) queries in expectation, where Δ \Delta is the expected average degree of G G . In particular, for p ∈ [ 2000 ​ log ⁡ n n , log 2 ⁡ n n ] p\in[\frac{2000\log n}{n},\frac{\log^{2}n}{n}] the algorithm uses O ⁡ ( n ​ log 5 ​ n ) O(n\log^{5}n) queries.

2.1
A Simple Algorithm

We sketch here the algorithm we are using, which has been introduced in
[
MZ23
]
and also used in
[
KZ24
]
. Consider a random set
S\subseteq V(G)
of fixed size
|S|=s
. First, the algorithm asks
\textsc{Query}(S,V(G))
. From these queries, it computes the
pseudo-edges
of
G
define as

\tilde{E}:=\{\{u,v\}\subseteq V(G)\mid\forall s\in S,|d(s,u)-d(s,v)|\leqslant 1\}.

The algorithm asks
\textsc{Query}(\tilde{E})
and finishes. Note that this algorithm always completely reconstructs the graph. If there exists
s
such that
|d(s,u)-d(s,v)|\geqslant 2
then
uv\notin E(G)
, therefore
\tilde{E}
is a superset of
E(G)
. The number of queries asked is at most
ns+|\tilde{E}|
.
Therefore the challenge in proving precise upper bound lies in showing that even for small values of
s
,
|\tilde{E}|
does not become excessively large.

Lemma 2.1

Given

Also for any

\mathbb{P}\left(\sum_{i=1}^{n}X_{i}\geqslant(1+\delta)\mu\right)\leqslant e^{-\delta^{2}\mu/(2+\delta)}.

Lemma 2.2

For every

Fix a vertex

\displaystyle\mathbb{P}\left(\left|\sum_{v\in V(G)\setminus\{u\}}X_{v}-p(n-1)\right|\geqslant\frac{1}{2}p(n-1)\right)\leqslant 2e^{-p(n-1)/12}\leqslant n^{-2},

Lemma 2.3
.

For

, for any
