Abstract
Streaming codes are packet-level codes that recover dropped packets within a strict decoding-delay constraint. We study streaming codes over a sliding-window (SW) channel model which admits only those erasure patterns which allow either a single burst erasure of ≤ b \leq b packets along with ≤ e \leq e random packet erasures, or else, ≤ a \leq a random packet erasures, in any sliding-window of w w time slots. We determine the optimal rate of a streaming code constructed via the popular diagonal embedding (DE) technique over such a SW channel under delay constraint τ = ( w − 1 ) \tau=(w-1) and provide an O ⁡ ( w ) O(w) field size code construction. For the case e > 1 e>1 , we show that it is not possible to significantly reduce this field size requirement, assuming the well-known MDS conjecture. We then provide a block code construction whose DE yields a streaming code achieving the rate derived above, over a field of size sub-linear in w , w, for a family of parameters having e = 1 . e=1. We show the field size optimality of this construction for some parameters, and near-optimality for others under a sparsity constraint. Additionally, we derive an upper-bound on the d min d_{\text{min}} of a cyclic code and characterize cyclic codes which achieve this bound via their ability to simultaneously recover from burst and random erasures.

Our Contributions:
We determine the optimal rate of an

Framework

We borrow the framework from
[
1
]
. At each time instant
t\in\mathbb{N}\bigcup\{0\},
the encoder receives a message packet
\underline{u}(t)=[u_{1}(t),u_{2}(t),\dots,u_{k}(t)]^{T}\in\mathbb{F}^{k}_{q},
and produces a coded packet
\underline{x}(t)=[x_{1}(t),x_{2}(t),\dots,x_{n}(t)]^{T}\in\mathbb{F}^{n}_{q}.
We will assume that
\underline{u}(t)=\underline{0}_{k}
for
t<0.
The encoder is causal, i.e.,
\underline{x}(t)
is a function of prior message packets
\underline{u}(0),\underline{u}(1),\dots,\underline{u}(t)
only. The coded packet
\underline{x}(t)
is then transmitted over a packet erasure channel, so that at time
t,
the receiver receives

\underline{y}(t)=\begin{cases}\underline{x}(t),~\text{if}~\underline{x}(t)\text{~is not erased,}\\
\wedge,~\text{if}~\underline{x}(t)\text{~is erased.}\end{cases}

Here, we use the symbol
\wedge
to denote an erased packet.
A delay-constrained decoder at the receiver must recover
\underline{u}(t)
using
\{\underline{y}(0),\underline{y}(1),\dots,\underline{y}(t+\tau)\}
only, where
\tau
denotes the decoding-delay constraint, for all
t\geq 0
. Packet-level codes satisfying this requirement are called streaming codes.
The rate of the streaming code is defined to be
\frac{k}{n}
.

We will use the following straightforward lemma.

Lemma 1
.

Let
\mathcal{C}
be an
[n,k]

An

\mathcal{C}

[

is an
[n,k,d]

then

unless

and

or
k=(q-1),

n\leq(q+2).
If
k>q,
then

An
[n,k]
code
\mathcal{C}
is said to be cyclic if
\forall\underline{c}^{T}=[c_{0},c_{1},\dots,c_{n-1}]\in\mathcal{C},
the vector
[c_{n-1},c_{0},\dots,c_{n-2}]\in\mathcal{C}

[
25
, Chapter 7]

\mathcal{C}
be an

and let

\displaystyle H=\begin{bmatrix}h_{0}&h_{1}&\cdots&h_{k-1}&h_{k}&0&\cdots&0\\

III
Optimal Rate of
(a,(b,e),w,\tau=w-1)
Streaming Codes Constructed via DE

The following theorem characterizes the optimal rate of an
(a,(b,e),w,\tau=w-1)
streaming code constructed via DE.

Theorem 1
.

The optimal rate of an
(a,(b,e),w,\tau=w-1)
streaming code constructed via DE is given by

\displaystyle R_{\textnormal{opt}}=\frac{w-(b+e)}{w}.

(2)

Proof.

The argument presented here is similar to one presented in
[
26
]
. Suppose that
\mathcal{C}
is a systematic
[n,k]
code, such that DE of
\mathcal{C}
results in an
(a,(b,e),w,\tau=w-1)
streaming code. Since the code
\mathcal{C}
recovers from
(b+e)
erasures, it follows that
(n-k)\geq(b+e)
.

We will first consider the case
n<w
. Let
n=(w-\delta_{1})
and
k=(n-(b+e)-\delta_{2})
, where
\delta_{1}>0
and
\delta_{2}\geq 0.
It is easy to verify that in this case
\frac{k}{n}<\frac{w-(b+e)}{w}
.
Now consider the case
n\geq w
, and consider the erasure pattern that erases the packet at time slot
0
along with that last
(b+e-1)
packets in the window
[0:w-1]
, i.e., the packets at time slots
t\in J=\{0\}\bigcup[w-(b+e)+1:w-1]
. Note that this erasure pattern is admissible in the
(a,(b,e),w)
-SW channel. Now consider the diagonally-embedded codeword
\underline{c}=[c_{0},c_{1},\dots,c_{n-1}]=[x_{1}(0),x_{2}(1),\dots,x_{n}(n-1)]\in\mathcal{C}.
Since
\mathcal{C}
is a systematic code, the first
k
code symbols
c_{0},c_{1},\dots,c_{k-1}
correspond to message symbols. In order to recover the message symbol
m_{0}=c_{0}
which has been erased, we must have that at least one of the code symbols in
\{c_{i}\mid i\in[0:w-1]\setminus J\}
is a parity symbol. Thus, we must have
k\leq w-(b+e)
. Combining this with the inequality
(n-k)\geq(b+e),
we get

\frac{k}{n}\leq\frac{w-(b+e)}{w}.

Since any SW of length
w
in the
(a,(b,e),w)
-SW channel can contain at most
(b+e)
erasures, and the delay constraint is
(w-1),
DE of a systematic
[w,w-(b+e)]
MDS code yields an
(a,(b,e),w,\tau=w-1)
streaming code of rate
R_{\textnormal{opt}}
.
∎

We remark here that in general, (
2
) is tighter than the upper-bound
\frac{w-a}{w-a+b+e+\frac{e}{m}}
derived in
[
7
]
, where
m=\lceil\frac{w-(b+e)}{b+e-a}\rceil
. Further,
R_{\textnormal{opt}}
is the optimal rate of any
(a,(b,e\geq(b-1)),w,\tau=w-1)
streaming code. To see this, consider the erasure pattern in Fig.
3
. By a direct extension of the argument in
[
7
]
, this erasure pattern is admissible in the
(a,(b,e),w)
-SW channel. Each period of the erasure pattern is of length
w
and has
w-(b+e)
non-erased packets, yielding a rate upper-bound
\frac{w-(b+e)}{w}
, which is achievable from Theorem
1
.

The arguments in the proof of Theorem
1
imply that if DE of a systematic
[n,k]
code yields an
(a,(b,e),w,\tau=w-1)
streaming code achieving rate
R_{\textnormal{opt}},
then
n=w,
and
k=w-(b+e).

The code constructed in Theorem
1
requires a field of size
O(w)
. As we show in the next theorem, if
e>1,
one can not do significantly better.

Theorem 2
.

Let
\mathcal{C}
be an
[n,n-(b+e)]
code over
\mathbb{F}_{q}
such that it can recover from any burst erasure of length
b
along with any
e>1
random erasures, where
n>(b+e+1)
. Then,
q\geq(n-b-2)
.

Proof.

Let
H\in\mathbb{F}_{q}^{(b+e)\times n}
be a parity-check matrix of
\mathcal{C}
. Since
\mathcal{C}
recovers from the burst erasure that erases the first
b
code symbols,
H([0:b+e-1],[0:b-1])
must have full rank from Lemma
1
. Hence, we can perform row operations on
H
to get
H([0:b-1],[0:b-1])=I_{b}
and
H([b:b+e-1],[0:b-1])=\underline{\underline{0}}^{e\times b}
. Now suppose that there exist
e
distinct indices
i_{0},i_{1},\dots,i_{e-1}
in
[b:n-1]
such that the set of sub-columns
S=\{H_{i_{j}}([b:b+e-1])\mid j\in[0:e-1]\}
is a linearly dependent set. Then we can combine
H_{i_{j}},~j\in[0:e-1],
to get a vector
\underline{v}
such that the last
e
coordinates of
\underline{v}
are
0
. Thus,
\underline{v}
can be written as a linear combination of
H_{0},H_{1},\dots,H_{b-1},
which implies that
\{H_{j}\mid j\in[0:b-1]\}\bigcup\{H_{i_{j}}\mid j\in[0:e-1]\}
is a linearly dependent set. This can not be true since from the hypothesis of the theorem,
\mathcal{C}
recovers from any burst erasure of length
b
along with any
e
random erasures. Hence, any
e
columns of
H([b:b+e-1],[b:n-1])
must be linearly independent. In other words,
H([b:b+e-1],[b:n-1])
must be a generator matrix of an
[n-b,e]
MDS code. The claim follows from the MDS conjecture.
∎

Theorem 6
