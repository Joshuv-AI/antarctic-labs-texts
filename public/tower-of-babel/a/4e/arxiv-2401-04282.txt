Efficient Constrained Graph Search for Post-hoc Error Correction in Binary Classifiers
Qinwu Xu qinwu.xu@utexas.edu

Abstract
We introduce a model-agnostic framework for constrained post-hoc error correction in binary classifiers. Given a frozen base classifier, the method discovers interpretable conjunctions of feature–threshold conditions that reduce residual false-positive or false-negative errors while limiting adverse changes to previously correct predictions. The proposed approach combines multi-path graph search with depth-dependent constraint tightening, allowing broad candidate correction regions to be progressively refined toward feasible solutions. A reduced-histogram procedure further accelerates threshold evaluation. Unlike classifier retraining or conventional rule learning, the framework optimizes a single correction path over the residual errors of an existing classifier without modifying its parameters. Experiments on a large binary-classification problem demonstrate substantial error reduction, including a configuration that removes 90% of false positives while sacrificing 5% of true positives. Additional evaluation across eight OpenML classification tasks demonstrates improvements in the targeted error type on seven of eight tasks in each correction mode, while also revealing the importance of held-out constraint validation.

Introduction

Modern classification systems—including support vector machines (SVMs),
tree ensembles, boosting methods, and neural networks—can achieve strong
aggregate predictive performance while retaining systematic residual errors
in operationally important regions of the input space. In many applications,
the costs of different errors are asymmetric: for example, reducing false
positives (FPs) may be desirable only if the resulting loss of true positives
(TPs) remains below an acceptable tolerance. Cost-sensitive learning has long
studied classification under unequal misclassification costs

(
Elkan, 2001
)
, while selective classification studies the related problem
of trading prediction coverage for reduced predictive risk

(
El-Yaniv and Wiener, 2010
;
Geifman and El-Yaniv, 2017
;
Geifman and El-Yaniv, 2019
)
. These approaches establish the
importance of explicitly controlling prediction trade-offs rather than
optimizing aggregate accuracy alone. More broadly, optimization methods range from Newton-type numerical
optimization for continuous physical inverse problems

(
Xu, 2014
;
Xu et al., 2016
)
to discrete search over structured decision spaces,
with the present work addressing the latter setting.

A complementary problem arises when an already-trained classifier performs
well overall but exhibits identifiable residual errors. Retraining or replacing
the underlying model may be undesirable because of computational cost,
deployment constraints, certification requirements, or limited access to model
parameters. Classifier patching provides one related approach: rather than
replacing a strong but fixed black-box classifier, an auxiliary model can
identify regions in which the original classifier is error-prone and modify
its behavior in those regions
(
Kauschke and Fürnkranz, 2018
)
. Recent work on post-hoc
selective classification likewise studies improvements that can be applied
to pretrained classifiers without modifying their underlying parameters

(
Cattelan and Silva, 2024
)
. These developments motivate a broader question: given a
frozen binary classifier, can a compact and interpretable post-hoc rule remove
a targeted subset of residual errors while explicitly limiting adverse changes
to predictions that were already correct?

We formulate this problem as
constrained post-hoc error correction
.
Let the frozen base classifier be

\hat{y}=C_{\theta}(x),

(1)

where
\theta
is fixed. We learn a correction operator

\hat{y}^{\prime}=R_{\phi}(x,\hat{y}),

(2)

where
\phi
specifies a conjunction of feature identities, thresholds,
inequality directions, and their top-down rule path. The base-model parameters

\theta
are never modified; optimization is restricted to the post-hoc rule
parameters
\phi
.

Our formulation is also related to interpretable tree and rule learning.
Decision trees recursively partition the feature space through simple
feature-threshold decisions
(
Quinlan, 1987
)
. Rule-based approaches instead
represent predictions using compact logical conditions or decision lists.
Examples include predictive rule ensembles
(
Friedman and Popescu, 2008
)
, Bayesian rule
lists
(
Letham et al., 2015
)
, and certifiably optimal rule lists

(
Angelino et al., 2018
)
. More recent work has addressed limitations of greedy
tree induction through explicit optimization or alternative interpretable
tree structures, including optimal sparse decision trees

(
Hu et al., 2019
)
and Fast Interpretable Greedy-Tree Sums (FIGS)

(
Tan et al., 2025
)
. These methods demonstrate both the usefulness of compact
rule-based models and the limitations of committing prematurely to locally
greedy splits.

The objective considered here is different from learning a complete
interpretable classifier from scratch. We assume that
C_{\theta}
already
exists and restrict the search to a post-hoc correction of its predictions.
Rather than selecting one locally optimal split and discarding alternatives,
the proposed method retains multiple high-ranked candidate
feature–threshold rules and organizes them into a graph. Candidate paths are
explored using depth-first search (DFS) with top-
K
pruning. A depth-dependent
dynamic optimization schedule permits broader correction at upper levels while
progressively enforcing the final FP or TP constraint. A reduced-histogram
procedure further reduces the cost of searching candidate thresholds.

Contributions.

Our main contributions are:
(1) a model-agnostic formulation of constrained post-hoc error correction for
frozen binary classifiers, explicitly separating the base-model parameters

\theta
from the learned correction-rule parameters
\phi
;
(2) a graph-search procedure that retains and explores multiple candidate rule
paths rather than committing to a single greedy split;
(3) a depth-dependent dynamic optimization strategy that progressively enforces
the desired FP–TP trade-off as search depth increases; and
(4) a reduced-histogram threshold-search procedure designed to reduce
computational cost while retaining greater resolution around informative
thresholds.

Related Work and Motivation

2.1
Decision Trees and Interpretable Rule Learning

Decision trees are among the most established interpretable classification
models. Starting from a root node, they recursively partition the input space
using feature-dependent decisions until a terminal prediction is reached

(
Quinlan, 1987
)
. Their hierarchical structure provides a direct
representation of the conditions leading to a prediction, but standard tree
induction is generally greedy: a locally selected split can restrict the
quality of subsequent paths.

A substantial literature has therefore explored alternative forms of
interpretable rule learning. RuleFit constructs predictive models from linear
combinations of simple rules, where individual rules are conjunctions of a
small number of feature conditions
(
Friedman and Popescu, 2008
)
. Bayesian Rule Lists
learn sparse ordered decision lists intended to remain understandable to human
users
(
Letham et al., 2015
)
. CORELS uses discrete optimization and algorithmic
bounds to construct sparse rule lists with certificates of optimality

(
Angelino et al., 2018
)
. Similarly, Optimal Sparse Decision Trees (OSDT) addresses
the myopic nature of conventional greedy tree induction by explicitly searching
for optimal sparse trees
(
Hu et al., 2019
)
. FIGS extends greedy tree learning by
simultaneously growing a flexible collection of trees, allowing compact
interpretable models to capture additive structure that can be inefficient for
a single tree to represent
(
Tan et al., 2025
)
.

A closely related perspective arises from subgroup discovery and contrast-set mining, which identify interpretable feature-defined regions exhibiting distinctive target distributions
(
novak2009
)
. Such methods commonly construct increasingly specific rules by adding feature conditions, balancing subgroup coverage against selectivity. This provides a useful foundation for understanding hierarchical rule refinement, although the present work targets a different problem: constrained correction of residual prediction errors from a frozen classifier rather than discovery of descriptive subgroups.

The proposed method shares with this literature the use of simple,
interpretable feature-threshold rules, but differs in both objective and
deployment setting. It does not attempt to replace the original classifier
with an interpretable model. Instead, the original classifier remains frozen,
and the rule search operates only as a post-hoc correction mechanism. Moreover,
the graph search retains several candidate children at each level so that
alternative correction paths can be evaluated before a final path is selected.

2.2
Post-hoc Classifier Correction and Patching

The most closely related setting is classifier patching. Kauschke and
Fürnkranz
(
Kauschke and Fürnkranz, 2018
)
consider adaptation of a strong but
unchangeable black-box classifier by identifying regions of the input space in
which the original classifier is error-prone and learning a patch for those
regions. This shares an important motivation with our formulation: useful
corrections can be learned without retraining the underlying classifier.

Our setting differs in the structure and objective of the correction.
Rather than training an auxiliary classifier to model error regions, we search
for a compact conjunction of feature–threshold rules under an explicit
constraint on the adverse class-wise effect of the correction. Thus, the
search can directly target objectives such as removing FPs while limiting TP
loss, or recovering TPs while limiting additional FPs. The resulting
correction is a compact rule path that can be inspected independently of the
base classifier.

More broadly, recent post-hoc methods have investigated how pretrained
classifiers can be modified or supplemented without retraining their underlying
parameters. For example, post-hoc selective-classification methods modify the
confidence estimator associated with an existing classifier to improve its
risk–coverage behavior
(
Cattelan and Silva, 2024
)
. While these methods do not
perform the same form of label correction considered here, they reinforce the
practical motivation for improving the operational behavior of frozen
predictors through lightweight post-hoc mechanisms.

2.3
Selective and Cost-Sensitive Classification

Selective classification, also known as classification with a reject option,
allows a predictor to abstain on uncertain inputs and thereby trades coverage
against predictive risk
(
El-Yaniv and Wiener, 2010
)
. This idea has been extended to
deep neural networks, including post-hoc selective classifiers constructed
from already-trained networks
(
Geifman and El-Yaniv, 2017
)
and models such as
SelectiveNet that jointly optimize prediction and rejection

(
Geifman and El-Yaniv, 2019
)
. The connection to our problem is the explicit control of
an undesirable outcome: both settings seek more useful operating points than
those obtained by optimizing aggregate classification accuracy alone.

There is nevertheless an important distinction. Selective classification
typically changes whether a prediction is issued, whereas our method changes
selected binary predictions through interpretable feature-dependent correction
rules. Consequently, our constraint is expressed directly in terms of changes
to FP and TP counts rather than through the conventional risk–coverage
trade-off.

Cost-sensitive classification provides another related perspective.
When false positives and false negatives have different consequences, the
optimal decision rule should account explicitly for those asymmetric costs

(
Elkan, 2001
)
. Our formulation similarly recognizes asymmetric error
preferences, but expresses them as constrained post-hoc optimization. For
example, one operating mode searches for the largest reduction in FPs subject
to an upper bound on TP loss. This formulation is useful when the acceptable
degradation can be specified directly as an operational constraint rather than
as a single scalar misclassification cost.

2.4
Motivation for Graph-based Correction Search

These lines of research suggest three desirable properties for a post-hoc
correction mechanism: it should preserve the already-deployed base classifier,
produce a compact and inspectable correction, and explicitly control the
trade-off between corrected and newly introduced errors. Greedy tree induction
provides interpretability but can commit early to a locally attractive split;
optimal tree and rule-list methods address this limitation but generally seek
to learn an entire classifier. Selective and cost-sensitive methods explicitly
model prediction trade-offs but do not directly produce the feature-dependent
post-hoc correction path considered here.

Our graph-search formulation occupies the intersection of these settings. It
keeps the base classifier fixed, searches multiple alternative conjunctions of
feature–threshold conditions, and evaluates them according to a constrained
FP–TP objective. The dynamic optimization and reduced-histogram components
are introduced to make this multi-path search computationally practical.

The path defines a correction region

\mathcal{R}(\phi_{d})=\bigcap_{k=1}^{d}\left\{x:x_{j_{k}}\;s_{k}\;\tau_{k}\right\}.

(4)

Depending on the optimization mode, predictions satisfying

The correction is applied only to samples having the

The rule is learned from training features, ground-truth

(X,y,\hat{y})
.
Once selected, the correction path is frozen and applied
to unseen samples without retraining
C_{\theta}

3.2
Graph Search over Correction Rules

The proposed graph search explores alternative correction
paths through successive feature-threshold conditions.
Each node represents a candidate path
\phi_{d}
, and
its children are generated by appending one additional
feature-threshold condition.

For a fixed path, successive correction regions are nested:

\mathcal{R}(\phi_{d+1})\subseteq\mathcal{R}(\phi_{d}).

(5)

Thus, each refinement restricts the samples eligible for
correction. This structure permits broad initial correction
regions to be progressively refined to reduce adverse
prediction changes.

At each node, candidate feature-threshold conditions are
evaluated using the correction objective defined below.
The top-
K
candidates are retained as children, and
depth-first search (DFS) recursively explores the resulting
paths up to maximum depth
D
.

Unlike a conventional greedy decision tree, which commits
to a single locally preferred split at each node, the
proposed search retains multiple candidate refinements.
A rule that is not locally optimal may therefore lead to
a better complete correction path after further refinement.

The score of each node is evaluated over its complete
top-down rule path. After exploring the retained candidates,
the highest-scoring feasible path is selected:

\phi^{*}=\arg\max_{\phi\in\mathcal{P}_{\mathrm{search}}}J(\phi)\quad\text{subject to the correction constraint},

(6)

where
\mathcal{P}_{\mathrm{search}}
denotes the candidate
paths explored by the search procedure.

Only one correction path is selected during training and
applied to all eligible inference samples, rather than
using object-dependent paths as in a decision tree.

3.3
Constrained Objective

The objective is to maximize beneficial prediction
corrections while limiting adverse changes to predictions
that were originally correct.

For a candidate path
\phi_{d}
, define

G(\phi_{d})
as the number of beneficial corrections
and
C(\phi_{d})
as the number of adverse corrections.

For TP recovery,

G(\phi_{d})=\Delta TP(\phi_{d}),\qquad C(\phi_{d})=\Delta FP(\phi_{d}),

(7)

where
\Delta TP
counts recovered false negatives and

\Delta FP
counts newly introduced false positives.

For FP reduction,

G(\phi_{d})=\Delta FP_{\mathrm{removed}}(\phi_{d}),\qquad C(\phi_{d})=\Delta TP_{\mathrm{lost}}(\phi_{d}).

(8)

Both modes can therefore be expressed using the
unified constrained objective

\max_{\phi}G(\phi)\quad\text{subject to}\quad C(\phi)\leq\epsilon,

(9)

where
\epsilon
is the maximum allowable adverse
correction cost for the selected mode.

To rank candidate paths during graph search, we use
the weighted objective

J(\phi)=\alpha^{\prime}G(\phi)-C(\phi),

(10)

where
\alpha^{\prime}
controls the relative importance of
beneficial and adverse corrections.
Candidate paths are ranked by
J(\phi)
, while feasibility
is determined by the corresponding correction constraint.

Objective improvement under rule refinement.

For a fixed search path, let

G_{d}=G(\phi_{d})
and
C_{d}=C(\phi_{d})
.
The nested-region property in
Eq.
5
implies

G_{d+1}\leq G_{d},\qquad C_{d+1}\leq C_{d}.

(11)

For a fixed weight
\alpha^{\prime}
, the change in the
weighted objective after adding a feature-threshold
condition is

J(\phi_{d+1})-J(\phi_{d})=(C_{d}-C_{d+1})-\alpha^{\prime}(G_{d}-G_{d+1}).

(12)

Consequently, a refinement improves the objective if

C_{d}-C_{d+1}>\alpha^{\prime}(G_{d}-G_{d+1}).

(13)

This condition characterizes the trade-off underlying
progressive rule refinement: a new condition is beneficial
when the reduction in adverse corrections outweighs
the weighted loss of beneficial corrections.
Although deeper rules necessarily reduce correction
coverage, they may improve the overall objective by
eliminating adverse corrections more efficiently.

3.4
Dynamic Optimization

The nested structure of correction regions motivates
a depth-dependent constraint schedule. Rather than
enforcing the final adverse-correction budget at every
search depth, the proposed method permits broader
candidate regions at upper levels and progressively
tightens the constraint during refinement.

Let
\epsilon
denote the final admissible adverse
correction budget. At depth
d
, the search uses

C(\phi_{d})<\epsilon_{d},\qquad\epsilon_{d}=\epsilon\left(\frac{D}{d+1}\right)^{2},

(14)

where
D
is the maximum search depth and
d
is
the current depth.

For TP recovery,
C(\phi_{d})
represents additional
false positives; for FP reduction, it represents
lost true positives. Thus, the same depth-dependent
schedule applies to both correction modes.

At shallow depths, the relaxed constraint allows
the search to retain regions with substantial
target-error coverage, even when their adverse
correction cost exceeds the final admissible budget.
As additional conditions restrict the correction
region, the allowable adverse correction cost
decreases.

The refinement condition in
Eq.
13
explains when
such specialization improves the weighted objective.
Together, multi-path exploration and dynamic
constraint tightening allow the algorithm to examine
promising intermediate candidates that might otherwise
be discarded under a fixed final constraint.

In the large example in Section
4.3
,
TP loss decreases from 14.20% at depth 1 to
2.80% at depth 3, while retaining a 17.52%
FP reduction.

3.5
Reduced Histogram Algorithm for Threshold Search

At each node, features are ranked according to their optimal objective-function scores. The optimal score for each feature depends on its discrimination threshold. A direct threshold search can loop over all data points. The proposed histogram-and-bin algorithm instead searches over histogram bins. A finer bin size gives higher resolution but greater computational cost. To improve accuracy while reducing search cost, the method constructs a reduced histogram with variable bin sizes: coarse bins are used in regions dominated by either TP or FP, while fine bins are used in mixed regions where the discrimination threshold is likely to occur.

5
Discussion

The method is intended for settings in which a deployed or otherwise fixed classifier exhibits structured residual errors that can be characterized by interpretable input features. Its principal advantage is that it does not require modifying or retraining the base model: the correction path is learned separately and can be inspected before deployment. The constrained formulation also exposes the operational trade-off between errors corrected and new errors introduced.

The method has corresponding limitations. Because the correction path is based on feature thresholds, it is most appropriate when meaningful structured features are available and residual errors contain repeatable structure. A compact rule cannot be expected to correct errors that are effectively random with respect to the available features. Search depth, branch factor, histogram resolution, and the constraint schedule also affect the search space and computational cost. Appendix
B
is designed to test whether gains persist across datasets and frozen base classifiers rather than only on the original SVM example.

6
Conclusion

We presented a model-agnostic framework for constrained post-hoc error correction in binary classifiers. The method leaves the base classifier frozen and searches for a compact feature–threshold rule path that either removes false positives subject to a bound on true-positive loss or recovers true positives subject to a bound on false-positive gain. Graph search retains multiple candidate paths, dynamic optimization progressively enforces the target constraint with depth, and reduced-histogram threshold search improves computational efficiency. The current examples demonstrate both correction modes, including 90% FP removal at 5% TP loss in the small case and 17.52% FP reduction at 2.80% TP loss in the large case. A public multi-dataset benchmark is specified in Appendix
B
to evaluate generalization, constrained error trade-offs, and computational efficiency across stronger frozen baselines.

Appendix A
Software Architecture and Reproducibility

We provide a public Python implementation of the proposed graph-search
framework.
2
2

2

https://github.com/qinwuxutexas/class_discrimination_graph_search_dynamic_optimization

The released code separates data processing, correction objectives,
rule representation, reduced-histogram threshold search, and graph search
into modular components.

Given feature vectors
X
, ground-truth labels
y
, and predictions

\hat{y}
from a frozen base classifier, the implementation first loads
and preprocesses the input data. Candidate feature–threshold rules are
then evaluated using reduced-histogram threshold search. At each graph
depth, candidate rules are ranked according to the correction
objective, and the top candidates are retained as child nodes. Dynamic
optimization adjusts the admissible TP/FP constraint as the search
progresses. The resulting top-down paths are ranked, and the
highest-scoring feasible path is selected.

In the reported large case, the implementation generated 39 discrimination rules in 9 seconds for 300,700 negative and 27,764 positive input objects on a dual-core 2.59 GHz laptop, with maximum process memory of 122 MB.

The learned path is fitted using the training data and is subsequently
frozen and applied unchanged to the held-out test predictions. The
repository includes configuration files, executable scripts, the core
search implementation, data utilities, and unit tests. Instructions for
installation and reproduction are provided in the repository README.

Appendix B
Proposed OpenML Benchmark Evaluation

To further evaluate the generality of the proposed graph-search method,
we plan a large-scale benchmark using public binary-classification tasks
from OpenML. The purpose of this experiment is to evaluate whether the
proposed method can improve already-trained classifiers on datasets for
which substantial classification errors remain, rather than selecting
datasets based on the observed improvement of our method.

B.1
Dataset Selection

We use the OpenML-CC18 benchmark suite as the initial candidate pool.
The suite contains 72 curated classification tasks covering datasets
with different sample sizes, feature dimensions, class distributions,
and levels of classification difficulty.

The benchmark datasets will be selected
before
applying the
proposed graph-search algorithm according to the following procedure:

1.

Retrieve binary-classification tasks from the OpenML-CC18
benchmark suite.

2.

Retrieve existing OpenML runs for standard classifiers,
primarily SVM and tree-based classifiers such as XGBoost or
gradient-boosted trees.

3.

Extract the reported test performance, model configuration,
preprocessing pipeline, and hyperparameters for reproducible runs.

4.

Rank candidate datasets according to the performance of the
existing base classifiers.

5.

Retain approximately eight datasets for which strong
conventional classifiers still exhibit substantial residual
classification error.

6.

Fix this dataset set before evaluating the proposed
graph-search correction method.

This screening procedure deliberately uses only the performance of the

base classifier
. No result from the proposed graph-search method
is used for dataset selection. This prevents selecting datasets
specifically because they favor the proposed method.

B.2
Reproduction of Base Classifiers

For each selected dataset, we first identify a strong and reproducible
OpenML run. OpenML runs provide the model flow, hyperparameters,
evaluation results, and, when available, prediction outputs. These
artifacts are used to reproduce the base classifier as closely as
possible.

The following hierarchy is used:

1.

If a suitable OpenML run provides the required predictions,
dataset split information, and model configuration, its predictions
are used directly as the frozen base-classifier output.

2.

If predictions are unavailable but the model architecture,
preprocessing procedure, and hyperparameters are available, the
corresponding classifier is retrained using the reported
configuration and the OpenML task splits.

3.

If an existing run cannot be reliably reproduced, a strong
SVM or XGBoost baseline is trained and tuned using a predefined
hyperparameter search procedure.

The fitted weights of the original OpenML model are therefore not
required. What is required is either the original predictions or
sufficient information to reproduce a comparable base classifier.

B.3
Post-hoc Graph-Search Evaluation

Let the reproduced base classifier be denoted by

C_{\theta}
, where
\theta
remains fixed during the proposed
post-hoc optimization.

For each benchmark dataset, the experiment proceeds as follows:

1.

Train or reproduce the base classifier
C_{\theta}
.

2.

Obtain its predictions on the training data and identify the
residual false-positive and false-negative samples.

3.

Apply the proposed graph-search algorithm to

(X_{\mathrm{train}},y_{\mathrm{train}},\hat{y}_{\mathrm{train}})
.

4.

Search feature–threshold correction rules using the
reduced-histogram procedure.

5.

Construct candidate top-down paths using graph search with
dynamic optimization.

6.

Select the highest-scoring feasible path according to the
specified TP/FP constraint.

7.

Freeze the resulting discrimination path.

8.

Apply exactly the same path, without further optimization,
to the held-out test predictions of
C_{\theta}
.

9.

Compare the original classifier
C_{\theta}
against

C_{\theta}+\mathrm{GraphSearch}
on exactly the same test samples.

Thus, the proposed method does not retrain or modify the parameters of
the underlying classifier. It learns a constrained post-hoc correction
rule from residual classification errors and subsequently applies the
frozen rule to unseen samples.

B.4
Candidate Dataset Screening

The initial screening will focus on binary datasets satisfying the
following criteria:

•

sufficient sample size to support separate training and
held-out evaluation;

•

nontrivial residual error for strong SVM or boosted-tree
classifiers;

•

numerical or consistently encoded tabular features suitable
for threshold-based discrimination rules;

•

reproducible OpenML tasks and model runs; and

•

sufficient false-positive and/or false-negative samples to
evaluate constrained error correction.

Candidate datasets will first be ranked using existing OpenML
performance records. Approximately eight difficult datasets will then
be frozen as the benchmark set before graph-search experiments are
performed.

B.5
Evaluation Protocol

For every dataset, the principal comparison is

C_{\theta}\quad\mathrm{vs.}\quad C_{\theta}+\mathrm{GraphSearch},

where both methods use the same base model, data split, preprocessing,
and test samples. We report accuracy, precision, recall, F1 score,
false-positive rate, false-negative rate, and the absolute numbers of
corrected and newly introduced errors.

Because the method is designed for constrained error correction, we
additionally report the trade-off between recovered errors and the
errors introduced by the correction path. For example, in the
false-positive-reduction setting, the primary quantities are the
percentage of false positives removed and the associated loss of true
positives.

Runtime, number of evaluated candidate rules, selected path depth, and
the final rule path are also reported for each dataset. These
measurements evaluate both the effectiveness and computational
efficiency of the proposed search procedure.
