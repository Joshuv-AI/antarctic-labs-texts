Solvable limit of ETH matrix model for double-scaled SYK
Kazumi Okuyama, and Takao Suyama

Abstract
We study the two-matrix model for double-scaled SYK model, called ETH matrix model introduced by Jafferis et al [arXiv:2209.02131]. If we set the parameters q A , q B q_{A},q_{B} of this model to zero, the potential of this two-matrix model is given by the Gaussian terms and the q q -commutator squared interaction. We find that this model is solvable in the large N N limit and we explicitly construct the planar one- and two-point function of resolvents in terms of elliptic functions.

2.1
Review of DSSYK

SYK model is defined by the Hamiltonian for

\{\psi_{i},\psi_{j}\}=2\delta_{i,j}

\displaystyle H=\mathrm{i}^{p/2}\sum_{1\leq i_{1}<\cdots<i_{p}\leq M}J_{i_{1}\cdots i_{p}}\psi_{i_{1}}\cdots\psi_{i_{p}},

(2)

\displaystyle\langle J_{i_{1}\cdots i_{p}}\rangle_{J}=0,\quad\langle J_{i_{1}\cdots i_{p}}^{2}\rangle_{J}=\binom{M}{p}^{-1}.

(3)

DSSYK is defined by the scaling limit

\displaystyle M,p\to\infty\quad\text{with}\quad q_{A}=e^{-\frac{2p^{2}}{M}}:\text{fixed}.

(4)

As shown in
Berkooz:2018jqr

\tr H^{k}

\displaystyle\langle\tr H^{k}\rangle_{J}=\sum_{\text{chord diagrams}}q_{A}^{\#(\text{intersections})}.

(5)

Here,

Using the technique of the transfer matrix,

\displaystyle\langle\tr e^{-\beta H}\rangle_{J}=\int_{0}^{\pi}\frac{d\theta}{2\pi}\mu(\theta)e^{-\beta E(\theta)},

are given by

\displaystyle\mu(\theta)=(q_{A},e^{\pm 2\mathrm{i}\theta};q_{A})_{\infty},\qquad E(\theta)=\frac{2\cos\theta}{\sqrt{1-q_{A}}}.

(7)

The

-Pochhammer symbol is defined by

\displaystyle(a;q)_{\infty}=\prod_{k=0}^{\infty}(1-aq^{k}),

(8)

and the measure factor in (

\displaystyle(q_{A},e^{\pm 2\mathrm{i}\theta};q_{A})_{\infty}

\displaystyle=(q_{A};q_{A})_{\infty}(e^{2\mathrm{i}\theta};q_{A})_{\infty}(e^{-2\mathrm{i}\theta};q_{A})_{\infty}.

(9)

One can also introduce

operator in DSSYK. One simple example

\displaystyle\mathcal{O}=\mathrm{i}^{s/2}\sum_{1\leq i_{1}<\cdots<i_{s}\leq M}K_{i_{1}\cdots i_{s}}\psi_{i_{1}}\cdots\psi_{i_{s}}

\displaystyle\vartheta_{1}(u)=-\mathrm{i}\sum_{n\in\mathbb{Z}}(-1)^{n}q^{\frac{1}{2}(n+\frac{1}{2})^{2}}e^{2\pi\mathrm{i}u(n+\frac{1}{2})}

(49)

with
q=e^{2\pi\mathrm{i}\tau}
. Note that

\vartheta_{1}(u)
has the properties

\displaystyle\vartheta_{1}(u+1)=\vartheta_{1}(-u)=-\vartheta_{1}(u),\quad\vartheta_{1}(u+\tau)=-e^{-\pi\mathrm{i}\tau-2\pi\mathrm{i}u}\vartheta_{1}(u).

(50)

Note also that
X^{2}(u)
in (
48
)
has a zero at
u=u_{0}
and a pole at
u=-u_{0}
.
Using (
50
), one can show that
the last condition in (
47
) is
satisfied by setting
u_{0}
as

\displaystyle e^{2\pi\mathrm{i}u_{0}}=\tilde{q}.

(51)

One can easily evaluate the value of
X^{2}(u)
at several special points

\displaystyle X^{2}(0)=1,\quad X^{2}(\pm 1/2)=-1,\quad X^{2}(\pm\tau/2)=-\tilde{q}^{\pm 1},\quad X^{2}(\pm\tau/2\pm 1/2)=-\tilde{q}^{\pm 1}.

(52)

From the definition of
G(X)
in (
37
),

G(X)
obeys the boundary condition

G(X)\sim\left\{\begin{aligned} &\tilde{q}X^{2}+\mathcal{O}(X^{-2}),&\quad&(X\to\infty),\\
&\tilde{q}X^{-2}+\mathcal{O}(X^{2}),&\quad&(X\to 0).\end{aligned}\right.

(53)

Also, from (
42
)
G(u)=G(X(u))
should satisfy

\displaystyle G(u+1)=G(-u)=G(u+\tau).

(54)

One can show that these conditions
(
53
) and (
54
)
are satisfied by
the following elliptic function

\displaystyle G(X)

\displaystyle=-\frac{\tilde{q}\vartheta_{1}(2u_{0})}{\vartheta^{\prime}_{1}(0)}\Biggl[\partial_{u}\log X^{2}(u)+\frac{2\vartheta_{1}^{\prime}(2u_{0})}{\vartheta_{1}(2u_{0})}\Biggr].

(55)

This is our final result of the one-point function,
which implicitly determines
\omega(X)
via the relation
(
37
).
Note that our result
guarantees that
G(X)
is an even function of
X

since both
G(X)
in (
48
) and
X^{2}(u)

in (
48
) are expanded around
u=\pm u_{0}

in the integer powers of
u\mp u_{0}
.

\displaystyle\Pi_{A}

(67)

\displaystyle=\frac{1}{2\pi\mathrm{i}}\frac{\partial}{\partial\tau}\frac{1}{2}\tilde{q}\int_{-\frac{1}{2}}^{\frac{1}{2}}du\Bigl[X^{2}(u-\tau/2)-X^{2}(u+\tau/2)-X^{-2}(u-\tau/2)+X^{-2}(u+\tau/2)\Bigr].

As discussed in
Dorey:2002pq
, this integral is evaluated by taking the
residue at
u=\pm u_{0}

\displaystyle\Pi_{A}

\displaystyle=\frac{1}{2}\tilde{q}\frac{\partial}{\partial\tau}\Biggl[\underset{u=-u_{0}}{\text{Res}}X^{2}(u)-\underset{u=u_{0}}{\text{Res}}X^{-2}(u)\Biggr]

(68)

\displaystyle=\tilde{q}\frac{\partial}{\partial\tau}\frac{\vartheta_{1}(2u_{0})}{\vartheta_{1}^{\prime}(0)}.

This is our final result of the
A
-period
\Pi_{A}
.
The condition
\Pi_{A}=S

(
60
) determines
q=e^{2\pi\mathrm{i}\tau}

as a function of
\tilde{q}
and
S
.
One can easily show that
\Pi_{A}
in (
68
)
has the following small
q
expansion

\displaystyle\Pi_{A}=q(-3+\tilde{q}^{-2}+3\tilde{q}^{2}-\tilde{q}^{4})+q^{2}(-18+6\tilde{q}^{-2}+18\tilde{q}^{2}-6\tilde{q}^{4})+\mathcal{O}(q^{3}).

(69)

From (
69
) one can see that
the small
q
regime corresponds to small
\tilde{q}
.
Thus we can compute
q
as a small
\tilde{q}
expansion with fixed
S

\displaystyle q

\displaystyle=S\tilde{q}^{2}+3S(S-1)^{2}\tilde{q}^{4}+3S(S-1)^{2}(9S^{2}-8S+2)\tilde{q}^{6}+\mathcal{O}(\tilde{q}^{8}).

(70)

From (
70
) and
(
51
),
\tau
and
u_{0}
are related as

\displaystyle\tau\approx 2u_{0}\qquad(\tilde{q}\to 0).

(71)

Note also that
\tau
and
u_{0}
are pure imaginary when
0<\tilde{q}<1,0<S<1
.

We can also compute
u_{b}
in the small
\tilde{q}
expansion
by solving the equation for the branch-point (
58
)

\displaystyle e^{2\pi\mathrm{i}u_{b}}

\displaystyle=\sqrt{S}(\sqrt{S}-\sqrt{S-1})\tilde{q}\left[1+\frac{1}{2}(S-1)^{3/2}(3\sqrt{S-1}-5\sqrt{S})\tilde{q}^{2}+\mathcal{O}(\tilde{q}^{4})\right].

(72)

If we set
S=\cos^{2}\phi
,

u_{b}
in (
72
) is expanded as

\displaystyle u_{b}

\displaystyle=\frac{\tau}{2}+\text{Re}(u_{b}),

(73)

\displaystyle\text{Re}(u_{b})

\displaystyle=\frac{1}{4\pi}\bigl[2\phi-5\tilde{q}^{2}\cos\phi\sin^{3}\phi+\mathcal{O}(\tilde{q}^{4})\bigr].

It is also convenient to define

\displaystyle X_{b}=X(u_{b})\tilde{q}^{-\frac{1}{2}},\quad\tilde{S}=\left(\frac{X_{b}+X_{b}^{-1}}{2}\right)^{2}.

(74)

Then we find that
\tilde{S}
is expanded as

\displaystyle\tilde{S}=S+S(S-1)^{2}\tilde{q}^{2}+S(S-1)^{2}(1-6S+8S^{2})\tilde{q}^{4}+\mathcal{O}(\tilde{q}^{6}).

(75)

3.5
Moment of
\omega(X)

Let us consider the small
X
expansion of
\omega(X)

in (
38
)

\displaystyle\omega(X)=-\sum_{n=0}^{\infty}\mu_{n}X^{n}.

(76)

From the generating function of the Chebyshev polynomials
T_{n}(t)

\frac{1-X^{2}}{1-2tX+X^{2}}=1+\sum_{n=1}^{\infty}2T_{n}(t)X^{n},

(77)

one can see that the coefficient
\mu_{n}
of this expansion (
76
)
is the expectation value of the moment

\displaystyle\mu_{n}=\frac{1}{N}\Bigl\langle\Tr\bigl(2T_{n}(A/2)\bigr)\Bigr\rangle,\quad(n\geq 1).

(78)

Plugging (
76
) into the definition of
G(X)
in (
37
),

G(X)
is expanded as

\displaystyle G(X)=\tilde{q}(X^{2}+X^{-2})+S\sum_{n=1}^{\infty}\mu_{n}(\tilde{q}^{\frac{n}{2}}-\tilde{q}^{-\frac{n}{2}})X^{n}.

(79)

We can easily extract the moment
\mu_{n}

from the expansion of our solution of
G(X)
(
55
)
around
u=u_{0}
.
Our solution (
55
)
guarantees that the odd moments vanish

\displaystyle\mu_{2k+1}=0,\quad(k\in\mathbb{Z}_{\geq 0}),

(80)

since
G(X)
in (
55
) is an even function of
X
by construction.
Thus
G(X)
is expanded as

\displaystyle G(X)=\tilde{q}(X^{2}+X^{-2})+S\sum_{n=1}^{\infty}\mu_{2n}(\tilde{q}^{n}-\tilde{q}^{-n})X^{2n}.

(81)

For instance,
\mu_{2}
and
\mu_{4}
are obtained from (
55
) as

\displaystyle\mu_{2}

\displaystyle=\frac{\tilde{q}}{S(\tilde{q}-\tilde{q}^{-1})}\left[\frac{\vartheta_{1}^{\prime\prime\prime}(0)\vartheta_{1}(2u_{0})^{2}}{2\vartheta_{1}^{\prime}(0)^{3}}+\frac{\vartheta_{1}^{\prime}(2u_{0})^{2}}{\vartheta_{1}^{\prime}(0)^{2}}-\frac{3\vartheta_{1}(2u_{0})\vartheta_{1}^{\prime\prime}(2u_{0})}{2\vartheta_{1}^{\prime}(0)^{2}}-1\right],

(82)

\displaystyle\mu_{4}

\displaystyle=\frac{2\tilde{q}\vartheta_{1}(2u_{0})^{2}}{3S(\tilde{q}^{2}-\tilde{q}^{-2})}\left[\frac{\vartheta_{1}^{\prime\prime\prime}(2u_{0})}{\vartheta_{1}^{\prime}(0)^{3}}-\frac{\vartheta_{1}^{\prime\prime\prime}(0)\vartheta_{1}^{\prime}(2u_{0})}{\vartheta_{1}^{\prime}(0)^{4}}\right].

Using the small
\tilde{q}
expansion of
q
in (
70
),
we can compute the small
\tilde{q}
expansion of the moments

\mu_{2n}

\displaystyle\mu_{2}

\displaystyle=S-2+S(S-1)^{2}\tilde{q}^{2}+S(S-1)^{2}(6S^{2}-6S+1)\tilde{q}^{4}+\mathcal{O}(\tilde{q}^{6}),

(83)

\displaystyle\mu_{4}

\displaystyle=2(S-1)^{2}+4(S-1)^{3}S\tilde{q}^{2}+2S(S-1)^{2}(14S^{3}-26S^{2}+15S-2)\tilde{q}^{4}+\mathcal{O}(\tilde{q}^{6}),

\displaystyle\mu_{6}

\displaystyle=(-1+S)^{2}(-2+5S)+3(-1+S)^{3}S(-3+5S)\tilde{q}^{2}

\displaystyle+9(-1+S)^{3}S\left(-1+9S-19S^{2}+13S^{3}\right)\tilde{q}^{4}+\mathcal{O}(\tilde{q}^{6}).

One can check that the
\mathcal{O}(\tilde{q}^{0})
term of
\mu_{2n}
is equal to

\displaystyle\lim_{\tilde{q}\to 0}\mu_{2n}=\int_{-2\sqrt{S}}^{2\sqrt{S}}d\lambda\rho(\lambda)2T_{2n}(\lambda/2),

(84)

where
\rho(\lambda)
is the eigenvalue density of Gaussian one-matrix model
with the potential
V(A)=\frac{A^{2}}{2S}

\displaystyle\rho(\lambda)=\frac{\sqrt{4S-\lambda^{2}}}{2\pi S}.

(85)

This is expected since in the limit
\tilde{q}\to 0

the two-matrix model in (
24
) reduces
to two decoupled Gaussian one-matrix models
for
A
and
B

\displaystyle\lim_{\tilde{q}\to 0}\Tr V(A,B)=\Tr\left(\frac{A^{2}}{2S}+\frac{B^{2}}{2}\right).

(86)

It turns out that the higher order correction in (
83
)
can be expressed as a deformation of the eigenvalue density

\displaystyle\rho(\lambda)=\frac{\sqrt{4\tilde{S}-\lambda^{2}}}{2\pi\tilde{S}}\frac{1+c\lambda^{2}+\mathcal{O}(\lambda^{4})}{1+c\tilde{S}+\cdots},

(87)

where
\tilde{S}
is defined in (
75
) and
c
is
given by

\displaystyle c=-2S(S-1)^{2}\tilde{q}^{4}+\mathcal{O}(\tilde{q}^{6}).

(88)

3.6
One-point function at
S=1

We observe from (
83
)
that the
S\to 1
limit of the moments is given by

\displaystyle\lim_{S\to 1}\mu_{n}=-\delta_{n,2},

(89)

which is independent of
\tilde{q}
.
This is consistent with the result of
Jafferis:2022wez

that the planar one-point function of the two-matrix
model at
S=1
remains the same as that of the one-matrix model
with the potential
V_{0}(A)
in (
18
), which reduces to the Gaussian one-matrix model when
q_{A}=0

\displaystyle\lim_{q_{A}\to 0}V_{0}(A)=T_{2}(A/2)=\frac{A^{2}}{2}-1.

(90)

We can explicitly show that the saddle-point condition (
42
)
for
S=1
is solved by the resolvent of Gaussian one-matrix model with the eigenvalue
density

\displaystyle\rho(\lambda)=\frac{\sqrt{4-\lambda^{2}}}{2\pi}.

(91)

The resolvent (
23
) for this eigenvalue density is given by

\displaystyle R(\lambda)=\int_{-2}^{2}d\lambda^{\prime}\rho(\lambda^{\prime})\frac{1}{\lambda-\lambda^{\prime}}=\frac{1}{2}\bigl(\lambda\pm\sqrt{\lambda^{2}-4}\bigr)=X^{\pm 1},

(92)

where we used the relation between
\lambda
and
X
in (
36
).

X
and
X^{-1}
in (
92
) correspond to
different branches of the resolvent.
From (
92
) and the definition of
\omega(X)
in (
38
),
we find the
expansion of
\omega(X)
around
X=0
and
X=\infty

\omega(X)=\left\{\begin{aligned} \omega_{0}(X)&=X(X-X^{-1})=X^{2}-1,&\quad&(X\to 0),\\
\omega_{\infty}(X)&=X^{-1}(X-X^{-1})=1-X^{-2},&\quad&(X\to\infty).\end{aligned}\right.

(93)

Then we find

\displaystyle T_{X}\omega(X)

\displaystyle=\omega_{0}(\tilde{q}^{\frac{1}{2}}X)-\omega_{\infty}(\tilde{q}^{-\frac{1}{2}}X)

(94)

\displaystyle=\tilde{q}(X^{2}+X^{-2})-2,

where we assumed

\displaystyle\tilde{q}^{\frac{1}{2}}\ll\min\bigl\{|X|,|X^{-1}|\bigr\}.

(95)

Finally, we find that
G(X)
in (
44
)
for
S=1
is constant

\displaystyle G(X)=\tilde{q}(X^{2}+X^{-2})-T_{X}\omega(X)=2,

(96)

which trivially satisfies the saddle-point condition (
42
).

We should stress that the two-matrix model with the potential
(
20
) itself
is not equal to the Gaussian matrix model when
\tilde{q}\neq 0
.
We are only claiming
that the planar
resolvent
\omega(X)

in (
93
) for
S=1

is equal to that of the Gaussian one-matrix model (
90
),
which is expected from the construction of the counter term (
17
).

4
Two-point function of resolvents

In this section, we study the two-point function of resolvents in our two-matrix
model (
24
).
In a similar manner as
the one-point function
\omega(X)
in (
38
), we define the
connected two-point function
\omega(X,Y)
by

\displaystyle\omega(X,Y)

\displaystyle=\left\langle\Tr\frac{X-X^{-1}}{X+X^{-1}-A}\Tr\frac{Y-Y^{-1}}{Y+Y^{-1}-A}\right\rangle_{\rm conn}

(101)

\displaystyle=\left\langle\sum_{a=1}^{N}\frac{X-X^{-1}}{X+X^{-1}-\lambda_{a}}\sum_{b=1}^{N}\frac{Y-Y^{-1}}{Y+Y^{-1}-\lambda_{b}}\right\rangle_{\rm conn}.

Our definition of
\omega(X,Y)
in (
101
)
implies the following symmetry properties:

\omega(X,Y)=\omega(Y,X)=-\omega(X^{-1},Y)=\omega(-X,-Y).

(102)

Note that
\omega(-X,Y)
is not equal to
\omega(X,Y)
in general.
Naively, we expect that the structure of cuts of
\omega(X,Y)

is inherited from that of the one-point function
\omega(X)
.
However, this is not the case due to the fact that

\omega(-X,Y)\neq\omega(X,Y)
. We find that
only the even part of
\omega(X,Y)
can be expressed in a simple way
for general
S<1
.
Interestingly, we find that
S=1
is special for the two-point function as well.
It turns out that when
S=1
the entire
\omega(X,Y)

can be constructed in terms of the Bergman kernel on a torus.

4.1
Equation for
\omega(X,Y)

In this subsection,
we derive an equation satisfied by
\omega(X,Y)
.
A similar equation is discussed, for example, in
Zakany:2018dio
.

For this purpose, we need to extend the saddle-point equation (
30
)
to the matrix model with a generic potential for
A

V(X;t)=\sum_{n\in\mathbb{Z}}t_{n}X^{n}.

(103)

Here the ’t Hooft parameter
S
is absorbed into the definition of
the parameters
t_{n}
in the potential
V(X;t)
.
The one-point function of this model is
given by

\omega_{t}(X)=\frac{1}{N}\left\langle\sum_{a=1}^{N}\frac{X-X^{-1}}{X+X^{-1}-X_{a}-X_{a}^{-1}}\right\rangle_{t},

(104)

where
X_{a}
is related to the eigenvalue
\lambda_{a}
of
A
by

\lambda_{a}\ =\ X_{a}+X_{a}^{-1},

(105)

and the average
\langle\cdots\rangle_{t}
is taken with respect to
V(X;t)

\displaystyle\langle\cdots\rangle_{t}=\frac{1}{\mathcal{Z}_{t}}\int\prod_{a=1}^{N}dz_{a}e^{-NV(e^{z_{a}};t)}(\cdots)\prod_{a<b}\frac{(\cosh z_{a}-\cosh z_{b})^{2}}{\bigl(\cosh(z_{a}+\Delta)-\cosh z_{b}\bigr)\bigl(\cosh(z_{a}-\Delta)-\cosh z_{b}\bigr)},

(106)

where
\mathcal{Z}_{t}
is determined by the condition
\langle 1\rangle_{t}=1
.
The saddle-point equation for
\omega_{t}(X)
turns out to be

\sum_{n\in\mathbb{Z}}nt_{n}X^{n}=2\omega_{t}(X)-\omega_{t}(\tilde{q}X)-\omega_{t}(\tilde{q}^{-1}X).

(107)

From (
77
), one can show the following identity

\frac{Y-Y^{-1}}{Y+Y^{-1}-X-X^{-1}}=-\sum_{n\in\mathbb{Z}}X^{n}Y^{|n|}.

(108)

Introducing
the so-called
loop-insertion operator
D(Y)
by

\displaystyle D(Y)=\sum_{n\in\mathbb{Z}}Y^{|n|}\frac{\partial}{\partial t_{n}},

(109)

(
108
) is written as

\displaystyle\frac{Y-Y^{-1}}{Y+Y^{-1}-X-X^{-1}}=-D(Y)V(X;t).

(110)

Then, acting
D(Y)
on
\omega_{t}(X)
in (
104
) we find

D(Y)\omega_{t}(X)=\omega_{t}(X,Y),

(111)

where
\omega_{t}(X,Y)
is the two-point function defined with respect to
V(X;t)
.
Our model of interest
corresponds to
t_{n}=t_{n}^{*}
such that

V(X;t^{*})\ =\ \frac{1}{2S}(1-\tilde{q}^{2})(X+X^{-1})^{2},

(112)

and we denote
\omega(X)=\omega_{t^{*}}(X)
and
\omega(X,Y)=\omega_{t^{*}}(X,Y)
.
Using the relation (
111
),
one can obtain an equation for
\omega(X,Y)

by acting the loop-insertion operator
D(Y)
on both sides of (
107
)
and setting
t_{n}=t_{n}^{*}
.
Acting
D(Y)
on the left-hand side of (
107
), we find

D(Y)\sum_{n\in\mathbb{Z}}nt_{n}X^{n}=-K(X,Y)+K(X,Y^{-1}),

(113)

where

K(X,Y)=\frac{XY}{(X-Y)^{2}},

(114)

and the right-hand side of (
107
) becomes

\displaystyle D(Y)\bigl[2\omega_{t}(X)-\omega_{t}(\tilde{q}X)-\omega_{t}(\tilde{q}^{-1}X)\bigr]=2\omega_{t}(X,Y)-\omega_{t}(\tilde{q}X,Y)-\omega_{t}(\tilde{q}^{-1}X,Y).

(115)

Finally we find the equation for
\omega(X,Y)

\displaystyle-K(X,Y)+K(X,Y^{-1})

\displaystyle=2\omega(X,Y)-\omega(\tilde{q}X,Y)-\omega(\tilde{q}^{-1}X,Y)

(116)

\displaystyle=-T_{X}^{2}\omega(X,Y),

where we define
T_{X}
and
T_{Y}

as
q
-difference operators
generalizing (
43
) to the two-variable case

\displaystyle T_{X}f(X,Y)

\displaystyle=f(\tilde{q}^{\frac{1}{2}}X,Y)-f(\tilde{q}^{-\frac{1}{2}}X,Y),

(117)

\displaystyle T_{Y}f(X,Y)

\displaystyle=f(X,\tilde{q}^{\frac{1}{2}}Y)-f(X,\tilde{q}^{-\frac{1}{2}}Y).

Note that the left-hand side
of (
116
)
is compatible with the symmetry (
102
) of
\omega(X,Y)
.

As in the case of one-point function
\omega(X)
, this equation
(
116
) can be simplified by introducing another function
G(X,Y)
defined by

G(X,Y)=T_{X}T_{Y}\omega(X,Y)+K(X,Y)+K(X,Y^{-1}).

(118)

From the symmetries of

\omega(X,Y)
in (
102
), it follows that

5
Conclusion and outlook

In this paper we have studied the
one- and two-point function of resolvents
\Tr\frac{1}{\lambda-A}

in the two-matrix model for DSSYK in the limit
q_{A},q_{B}\to 0
.
In this limit, the matrix model potential
is given by the Gaussian terms plus the
q
-commutator squared interaction
(
20
).
After integrating out the matter matrix
B
, the partition function
of two-matrix model is written as the eigenvalue integral for the matrix
A

and the large
N
saddle-point equation can be
solved in terms of an elliptic function.
To study this model,
it is convenient to introduce
the ’t Hooft parameter
S
in the potential
(
24
).
It turned out that the solution of planar resolvent behaves
differently for
S<1
and
S=1
.
When
S=1
, we confirmed that the moments of two-point function
in
Jafferis:2022wez
are correctly reproduced from
our planar solution
of
G(X,Y)
in (
133
).

There are many interesting open questions.
We would like to understand the bulk Hilbert space of
quantum gravity coupled to matter fields.
One can show that the moments

c_{n,m}
(
137
) of the two-point function at
S=1
is written as
(see e.g. appendix B of
Zhou:2023eus
)

\displaystyle c_{n,m}=\frac{\Tr(\tilde{q}^{L_{0}}\alpha_{n}\alpha_{-m})}{\Tr\tilde{q}^{L_{0}}}=\frac{n}{1-\tilde{q}^{n}}\delta_{n,m},

(154)

where
\alpha_{n}
is the free boson with the commutator

[\alpha_{n},\alpha_{m}]=n\delta_{n+m,0}
and

L_{0}
is the Virasoro generator

\displaystyle L_{0}=\frac{1}{2}\alpha_{0}^{2}+\sum_{n=1}^{\infty}\alpha_{-n}\alpha_{n}.

(155)

This expression (
154
) suggests that
the bulk Hilbert space of
the wormhole geometry is isomorphic to the Fock space of
free boson.
This is not so surprising since it is known that
the matrix model correlators admit a CFT representation
Kostov:2009nj
;
Kostov:2010nw
.
In this computation (
154
), the zero mode
\alpha_{0}
is decoupled
and it does not contribute to the two-point function.
It is tempting to identify the zero mode
\alpha_{0}
as the

\mathcal{L}^{2}(\mathbb{R})
factor of the Hilbert space
for the wormhole geometry discussed in
Chen:2023hra
.
Note that the eigenvalue of
L_{0}
corresponds
to the discrete length of the bulk geodesic loop
running around the neck of the wormhole

Jafferis:2022wez
;
Okuyama:2023byh
;
Okuyama:2023kdo
.
The
L_{0}=0
state corresponds to a thin wormhole,
but such a state is decoupled in the computation of
two-point function (i.e. there is no
n=0
term in
(
139
)).
Thus the two-point function in our two-matrix model
is UV finite.
It would be interesting to understand the bulk Hilbert space
of our model better.

It would also be interesting to study the ETH matrix model of DSSYK
when
q_{A},q_{B}\neq 0

and compute the two-point function of resolvents.
Perhaps, the Virasoro generator
L_{0}

in (
154
) might be replaced by the
q
-Virasoro generator

Shiraishi:1995rp
when
q_{A},q_{B}\neq 0
.
We leave this generalization as an interesting future problem.
