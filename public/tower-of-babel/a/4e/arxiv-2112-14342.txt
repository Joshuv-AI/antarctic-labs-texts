An algebraic form of the Marchenko inversion. Partial waves with orbital momentum l ≥ 0 l\geq 0
N. A. Khokhlov

Abstract
We present a generalization of the algebraic method for solving the Marchenko equation (fixed- l l inversion) for any values of the orbital angular momentum l l . We expand the Marchenko equation kernel in a separable form using a triangular wave set. The separable kernel allows a reduction of the equation to a system of linear equations. We obtained a linear expression of the kernel expansion coefficients in terms of the Fourier series coefficients of q ⁡ ( 1 − S ⁡ ( q ) ) q(1-S(q)) function ( S ⁡ ( q ) S(q) is the scattering matrix) depending on the momentum q q . The linear expression is valid for any orbital angular momentum l l . The kernel expansion coefficients are determined by the scattering data in the finite range 0 ≤ q ≤ π / h 0\leq q\leq\pi/h . In turn, the thus defined Marchenko kernel of the equation allows one to find the potential function of the radial Schrödinger equation with h h -step accuracy.
