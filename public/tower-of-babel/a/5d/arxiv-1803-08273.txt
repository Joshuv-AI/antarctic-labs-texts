A quantum algorithm for simulating non-sparse Hamiltonians
Chunhao Wang, Leonard Wossnig

Abstract
We present a quantum algorithm for simulating the dynamics of Hamiltonians that are not necessarily sparse. Our algorithm is based on the input model where the entries of the Hamiltonian are stored in a data structure in a quantum random access memory (qRAM) which allows for the efficient preparation of states that encode the rows of the Hamiltonian. We use a linear combination of quantum walks to achieve poly-logarithmic dependence on precision. The time complexity of our algorithm, measured in terms of the circuit depth, is O ⁡ ( t ​ N ​ ∥ H ∥ ​ polylog ​ ( N , t ⁡ ∥ H ∥ , 1 / ϵ ) ) O(t\sqrt{N}\lVert H\rVert\,\mathrm{polylog}(N,t\lVert H\rVert,1/\epsilon)) , where t t is the evolution time, N N is the dimension of the system, and ϵ \epsilon is the error in the final state, which we call precision. Our algorithm can be directly applied as a subroutine for unitary implementation and quantum linear systems solvers, achieving O ~ ​ ( N ) \widetilde{O}(\sqrt{N}) dependence for both applications.

Introduction

1.1
Background and main results

Hamiltonian simulation is the problem of simulating the dynamics of quantum systems, which is the original motivation for quantum computers
[
19
,
20
]
. It has been shown to be BQP-hard and is hence conjectured not to be classically solvable in polynomial time, since such an algorithm would imply an efficient classical algorithm for any problem with an efficient quantum algorithm, including integer factorization
[
38
]
.

Different input models have been considered in previous quantum algorithms for simulating Hamiltonian evolution. The
local Hamiltonian
model is specified by the local terms of a Hamiltonian. The
sparse-access
model for a sparse Hamiltonian
H
is specified by the following two oracles:

\displaystyle O_{S}\ket{i,j}\ket{z}

\displaystyle\mapsto\ket{i,j}\ket{z\oplus S_{i,j}},\text{ and}

(1)

\displaystyle O_{H}\ket{i,j}\ket{z}

\displaystyle\mapsto\ket{i,j}\ket{z\oplus H_{i,j}},

(2)

where

is the
j
-th nonzero entry of the
i
-th row and
\oplus
denotes the bit-wise XOR. The
linear combination of unitaries
(
LCU
) model is specified by a decomposition of a Hamiltonian as a linear combination of unitaries and we are given the coefficients and access to each unitary.
Following the first proposal by Lloyd
[
28
]
for local Hamiltonians, Aharonov and Ta-Shma gave an efficient algorithm for sparse Hamiltonians
[
4

While the above-mentioned input models arise naturally in many physics applications and matrix arithmetic applications (i.e., we have access to the local terms of a Hamiltonian or each entry of a Hamiltonian can be efficiently computed), in many machine learning applications, it is more convenient to work with a different input model, namely, the

As we receive and process the input data, with little overhead, they can be stored in the data structure, and then the qRAM will facilitate preparing quantum states corresponding to the input data. The use of the qRAM model has been successfully demonstrated in many applications such as quantum principal component analysis
[
29
]
, quantum support vector machines
[

]

[

In this work, we consider the qRAM model for obtaining information about the Hamiltonian that is not necessarily sparse. Quantum access to this data structure allows us to efficiently prepare states that encode the rows of the Hamiltonian. Using the ability to prepare these states in combination with a quantum walk

1.2
Related work

Hamiltonian simulation with
\lVert H\rVert
dependence.

For non-sparse Hamiltonians, a suitable model is the black-box model (a special case of the sparse-access model): querying the oracle with an index-pair
\ket{i,j}
returns the corresponding entry of the Hamiltonian
H
, i.e.,
O_{H}
defined in Eq. (
2
).
With access to a black-box Hamiltonian, simulation with error
\epsilon
can then be provably performed with query complexity

O((\lVert H\rVert t)^{3/2}N^{3/4}/\sqrt{\epsilon})
for dense Hamiltonians
[
7
]
,
and it was also empirically observed in
[
7
]
that for several classes of Hamiltonians,
O(\sqrt{N}\log(N))
queries suffice.
Whether this
\widetilde{O}(\sqrt{N})
dependence holds for all Hamiltonians was left as an open problem. After the first version of this work was made public, this open problem was almost resolved by Low
[
30
]
, where he proposed a quantum algorithm for simulating black-box Hamiltonians with time complexity
O((t\sqrt{N}\lVert H\rVert)^{1+o(1)}/\epsilon^{o(1)})
. Although our input model is stronger than the black-box model, our work distinguishes itself since the two models are still comparable in many quantum machine learning applications and our work gives a better complexity.

Hamiltonian simulation with
\left\|H\right\|_{\mathrm{max}}
dependence.

Since the qRAM model is stronger than the black-box model and the sparse-access model, previous quantum algorithms such as
[
7
,
9
]
can be directly used to simulate Hamiltonians in the qRAM model. For a
d
-sparse Hamiltonian, the circuit depth of the black-box Hamiltonian simulation is given by
\widetilde{O}(td\left\|H\right\|_{\mathrm{max}})
as shown in
[
7
,
9
]
. When
H
is non-sparse, their results imply the scaling
\widetilde{O}(tN\left\|H\right\|_{\mathrm{max}})
. In applications where
\left\|H\right\|_{\mathrm{max}}
is a measure of cost, our result has no advantage against theirs, as the inequality
\lVert H\rVert\leq\sqrt{N}\left\|H\right\|_{\mathrm{max}}
implies
\widetilde{O}(t\sqrt{H}\lVert H\rVert)=\widetilde{O}(tN\left\|H\right\|_{\mathrm{max}})
. However, in the case where
\lVert H\rVert
is a measure of cost, such as solving linear systems
[
23
,
16
]
, and black-box unitary implementation
[
7
]
, our result has a quadratic improvement in the dimensionality dependence, as the inequality
\left\|H\right\|_{\mathrm{max}}\leq\lVert H\rVert
implies
\widetilde{O}(tN\left\|H\right\|_{\mathrm{max}})=\widetilde{O}(tN\lVert H\rVert)
.

Hamiltonian simulation in the qRAM model.

Shortly after the first version of this paper was made public, Chakraborty, Gilyén, and Jeffery
[
12
]
independently proposed a quantum algorithm for simulating non-sparse Hamiltonians based on the similar qRAM input model which achieved the same time complexity as our method. Their work is based on a very general input model, namely, the block-encoding model, which was originally proposed in
[
33
]
. The block-encoding model assumes we are given a unitary
\bigl(\begin{smallmatrix}H/\alpha&\cdot\\
\cdot&\cdot\end{smallmatrix}\bigr)
that contains
H/\alpha
in its upper-left block. Then the evolution
e^{-iHt}
can be simulated in
\widetilde{O}(\alpha\lVert H\rVert t)
time. It was shown in
[
33
]
that working with the sparse-access model of a
d
-sparse Hamiltonian
H
, a block-encoding of
H
with
\alpha=d
can be efficiently implemented, and it hence implies a simulation algorithm with time complexity
\widetilde{O}(d\lVert H\rVert t)
. One of the main results in
[
12
]
is that working with the qRAM model of a
d
-sparse Hamiltonian
H
, a block-encoding with
\alpha=\sqrt{d}
can be efficiently implemented, which yields a simulation algorithm with time complexity
\widetilde{O}(\sqrt{d}\lVert H\rVert t)
. This result has the same complexity as ours, but their techniques are more general. In fact, the techniques of
[
12
]
has been generalized in
[
21
]
to a quantum framework for implementing singular value transformation of matrices. Another merit of
[
12
]
is that they gave detailed analysis for application to a quantum linear systems solvers in the qRAM model.

Quantum-inspired classical algorithms for Hamiltonian simulation.

1.3
Applications

Unitary implementation.

One immediate application of simulating non-sparse Hamiltonians is the unitary implementation problem: given access to the entries of a unitary
U
, the objective is to construct a quantum circuit to approximate
U
with precision
\epsilon
. As proposed in
[
7
,
25
]
, unitary implementation can be reduced to Hamiltonian simulation by considering the Hamiltonian

\displaystyle H=\begin{pmatrix}0&U\\
U^{{\dagger}}&0\end{pmatrix},

(6)

and the fact that
e^{-iH\pi/2}\ket{1}\ket{\psi}=-i\ket{0}U\ket{\psi}
.
If the entries of a unitary matrix can be accessed by a black-box query oracle, it is shown in
[
7
]
that this unitary operator can be implemented with
O(N^{2/3}\mathrm{polylog}(N)\mathrm{poly}(1/\epsilon))
queries to the black box.
Assume now that the entries of
U
are stored in a data structure such as in Definition
1
.
Using the same reduction to Hamiltonian simulation, our Hamiltonian simulating algorithm implies an implementation of
U
with time complexity (circuit depth)
O(\sqrt{N}\,\mathrm{polylog}(N,1/\epsilon))
.

Quantum linear systems solver.

Simulating non-sparse Hamiltonians can also be used as a subroutine for solving linear systems of equations for non-sparse matrices.
The essence for solving a linear system
A\ket{x}=\ket{b}
is to apply
A^{-1}
on
\ket{b}
, assuming here for simplicity that
\ket{b}
is entirely in the column-space of
A
.
When
A
is
d
-sparse, it is shown in
[
16
]
that
A^{-1}
can be approximated as a linear combination of unitaries of the form
e^{-iAt}
.
An efficient quantum algorithm for Hamiltonian simulation such as
[
9
]
can then be used as a subroutine, so that this linear system can be solved with gate complexity
O(d\kappa^{2}\mathrm{polylog}(N,\kappa/\epsilon))
.
If
A
is non-sparse, the time complexity of their algorithm scales as
\widetilde{O}(N)
. Based on the data structure in
[
26
]
, a quantum algorithm for solving linear systems for non-sparse matrices was described in
[
41
]
, with time complexity (circuit depth)
O(\kappa^{2}\sqrt{N}\mathrm{polylog}(N)/\epsilon)
.
If we assume a similar input model as in
[
26
,
41
]
, using our Hamiltonian simulation algorithm, together with the linear combinations of unitaries (LCU) decompositions in
[
16
]
, we have a quantum algorithm for solving linear systems for non-sparse matrices with time complexity (circuit depth)
O(\kappa^{2}\sqrt{N}\mathrm{polylog}(\kappa/\epsilon))
, which is an exponential improvement in error dependence compared to
[
41
]
.

In the remainder of this paper, we first define our data structure, then describe the algorithm in detail and finally prove the main results. We then finish with a summary of this work and a discussion of the benefits and possible drawbacks of our algorithm.

Data structure and quantum walk

We first give the precise definition of the data structure that stores the entries of the Hamiltonian, and then show how this data structure can be used to prepare states that will allow us to perform fast Hamiltonian simulation even for dense matrices.
The data structure was introduced in in

Definition 1

(Data Structure)

Let

The leaf node

2

Using this data structure, we can efficiently perform the mapping described in the following technical lemma for efficient state preparation.

Lemma 1

(State Preparation)
.

Let
H\in\mathbb{C}^{N\times N}
be a Hermitian matrix (where
N=2^{n}
) stored in the data structure as specified in Definition
1
. Each entry
H_{jk}
is represented with
b

1.

Let
\left\|H\right\|_{1}
be defined as above. A quantum computer that has access to the data structure can perform the following mapping for
j\in\{0,\ldots,N-1\}
,

\displaystyle\ket{j}\ket{0^{\log N}}\ket{0}\mapsto\frac{1}{\sqrt{\left\|H\right\|_{1}}}\ket{j}\sum_{k=0}^{N-1}\ket{k}\left(\sqrt{H_{jk}^{*}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{N}}\ket{1}\right),

(7)

with time complexity (circuit depth)
O(n^{2}b^{5/2}\log b)
, where
\sigma_{j}=\sum_{k}|H_{jk}|
, and the square-root satisfies
\sqrt{H_{jk}}\bigl(\sqrt{H_{jk}^{*}}\bigr)^{*}=H_{jk}
.

2.

The size of the data structure containing all
N^{2}
complex entries is
O(N^{2}\log^{2}(N))
.

In order to perform the mapping we will need the following Lemma, which enables us to efficiently implement the conditional rotations with complex numbers.

Lemma 2

Let
\theta,\phi_{0},\phi_{1}\in\mathbb{R}

\widetilde{\theta},\widetilde{\phi_{0}},\widetilde{\phi_{1}}

\theta,\phi_{0}

\displaystyle U:\ket{\widetilde{\phi_{0}}}\ket{\widetilde{\phi_{1}}}\ket{\widetilde{\theta}}\ket{0}\mapsto\ket{\widetilde{\phi_{0}}}\ket{\widetilde{\phi_{1}}}\ket{\widetilde{\theta}}\left(e^{i\widetilde{\phi_{0}}}\cos(\widetilde{\theta})\ket{0}+e^{i\widetilde{\phi_{1}}}\sin(\widetilde{\theta})\ket{1}\right).

(8)

Moreover,

can be implemented with

Proof.

Define

\displaystyle U=\left(\sum_{\widetilde{\phi_{0}}\in\{0,1\}^{b}}\ket{\widetilde{\phi_{0}}}\!\bra{\widetilde{\phi_{0}}}\otimes e^{i\ket{0}\!\bra{0}\widetilde{\phi_{0}}}\right)\left(\sum_{\widetilde{\phi_{1}}\in\{0,1\}^{b}}\ket{\widetilde{\phi_{1}}}\!\bra{\widetilde{\phi_{1}}}\otimes e^{i\ket{1}\!\bra{1}\widetilde{\phi_{1}}}\right)\left(\sum_{\widetilde{\theta}\in\{0,1\}^{b}}\ket{\widetilde{\theta}}\!\bra{\widetilde{\theta}}\otimes e^{-iY\widetilde{\theta}}\right),

). Then the rotation angles will be determined by calculating the square root and trigonometric functions on the output of the query: this can be implemented with
O(b^{5/2})
1- and 2-qubit gates using simple techniques based on Taylor series and long multiplication as in
[
9
]
, where the error is smaller than that caused by truncating to
b
bits. Then the conditional rotation is applied by the circuit described in Lemma
2
, and the cost for the conditional rotation is
O(b)
. There are
n=\log(N)
levels, so the cost excluding the implementation of the oracle is
O(nb^{5/2})
. To obtain quantum access to the classical data structure, a quantum addressing scheme is required. One addressing scheme described in
[
22
]
can be used. Although the circuit size of this addressing scheme is
\widetilde{O}(N)
for each
D_{j}
, its circuit depth is
O(n)
. Therefore, the time complexity (circuit depth) for preparing the state in Eq. (
7
) is
O(n^{2}b^{5/2}\log n)
.

We use the following rules to determine the sign of the square-root of a complex number: if
H_{jk}
is not a negative real number, we write
H_{jk}=re^{i\varphi}
(for
r\geq 0
and
-\pi\leq\varphi\leq\pi
) and take
\sqrt{H_{jk}^{*}}=\sqrt{r}e^{-i\varphi/2}
; when
H_{jk}
is a negative real number, we take
\sqrt{H_{jk}^{*}}=\mathrm{sign}(j-k)i\sqrt{|H_{jk}|}
to avoid the sign ambiguity. With this recipe, we have
\sqrt{H_{jk}}\bigl(\sqrt{H_{jk}^{*}}\bigr)^{*}=H_{jk}
.
∎

In the following, we demonstration a state preparation procedure based on the data structure in Fig.

.
In this example, the initial state (omitting the first register) is
\ket{00}\ket{0}
. Let
\sigma_{j}=|c_{0}|+|c_{1}|+|c_{2}|+|c_{3}|
. Apply the first rotation, we obtain the state

\displaystyle\frac{1}{\sqrt{\left\|H\right\|_{1}}}\ket{00}\left(\sqrt{|c_{0}|+|c_{1}|+|c_{2}|+|c_{3}|}\ket{0}+\sqrt{\left\|H\right\|_{1}-\sigma_{j}}\ket{1}\right)=

\displaystyle\frac{1}{\sqrt{\left\|H\right\|_{1}}}\left(\sqrt{|c_{0}|+|c_{1}|+|c_{2}|+|c_{3}|}\ket{00}\ket{0}+\sqrt{\left\|H\right\|_{1}-\sigma_{j}}\ket{00}\ket{1}\right).

(11)

Then, apply a rotation on the first qubit of the first register conditioned on the last register, we obtain the state

\displaystyle\frac{1}{\sqrt{\left\|H\right\|_{1}}}\left(\left(\sqrt{|c_{0}|+|c_{1}|}\ket{00}+\sqrt{|c_{2}|+|c_{3}|}\ket{10}\right)\ket{0}+\left(\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{2}}(\ket{00}+\ket{10})\right)\ket{1}\right).

(12)

Next, apply a rotation on the second qubit of the first register conditioned on the first qubit of the first register and last register, we obtain the desired state:

\displaystyle\frac{1}{\sqrt{\left\|H\right\|_{1}}}\left(\sqrt{c_{0}}\ket{00}\ket{0}+\sqrt{c_{1}}\ket{01}\ket{0}+\sqrt{c_{2}}\ket{10}\ket{0}+\sqrt{c_{3}}\ket{11}\ket{0}+\right.

\displaystyle\left.\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{00}\ket{1}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{01}\ket{1}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{10}\ket{1}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{11}\ket{1}\right)=

\displaystyle\frac{1}{\sqrt{\left\|H\right\|_{1}}}\left(\ket{00}\left(\sqrt{c_{0}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{1}\right)+\ket{01}\left(\sqrt{c_{1}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{1}\right)+\right.

\displaystyle\left.\ket{10}\left(\sqrt{c_{2}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{1}\right)+\ket{11}\left(\sqrt{c_{3}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{4}}\ket{1}\right)\right).

(13)

Based on the data structure specified in Definition
1
and the efficient state preparation in Lemma
1
, we construct a quantum walk operator for
H
as follows. First define the isometry
T
as

\displaystyle T=\sum_{j=0}^{N-1}\sum_{b\in\{0,1\}}(\ket{j}\!\bra{j}\otimes\ket{b}\!\bra{b})\otimes\ket{\varphi_{jb}},

(14)

with
\ket{\varphi_{j1}}=\ket{0}\ket{1}
and

\displaystyle\ket{\varphi_{j0}}=\frac{1}{\sqrt{\left\|H\right\|_{1}}}\sum_{k=0}^{N-1}\ket{k}\left(\sqrt{H_{jk}^{*}}\ket{0}+\sqrt{\frac{\left\|H\right\|_{1}-\sigma_{j}}{N}}\ket{1}\right),

(15)

where
\sigma_{j}=\sum_{k=0}^{N-1}|H_{jk}|
.
Let
S
be the swap operator that maps
\ket{j_{0}}\ket{b_{0}}\ket{j_{1}}\ket{b_{1}}
to
\ket{j_{1}}\ket{b_{1}}\ket{j_{0}}\ket{b_{0}}
, for all
j_{0},j_{1}\in\{0,\ldots,N-1\}
and
b_{0},b_{1}\in\{0,1\}
. We observe that

\displaystyle\bra{j}\bra{0}T^{{\dagger}}ST\ket{k}\ket{0}=\frac{\sqrt{H_{jk}}\left(\sqrt{H_{jk}^{*}}\right)^{*}}{\left\|H\right\|_{1}}=\frac{H_{jk}}{\left\|H\right\|_{1}},

(16)

where the second equality is ensured by the choice of the square-root as in the proof of Lemma
1
.
This implies that

\displaystyle(I\otimes\bra{0})T^{{\dagger}}ST(I\otimes\ket{0})=\frac{H}{\left\|H\right\|_{1}}.

(17)

The quantum walk operator
U
is defined as

\displaystyle U=iS(2TT^{{\dagger}}-I).

(18)

A more general characterization of the eigenvalues of quantum walks is presented in
[
39
]
. Here
we give a specific proof on the relationship between the eigenvalues of
U
and
H
as follows.

Lemma 3
.

Let the unitary operator
U
be defined as in Eq. (
18
), and let
\lambda
be an eigenvalue of
H
with eigenstate
\ket{\lambda}
. It holds that

\displaystyle U\ket{\mu_{\pm}}=\mu_{\pm}\ket{\mu_{\pm}},

(19)

where

\displaystyle\ket{\mu_{\pm}}=

\displaystyle(T+i\mu_{\pm}ST)\ket{\lambda}\ket{0},\mbox{ and}

(20)

\displaystyle\mu_{\pm}=

\displaystyle\pm e^{\pm i\arcsin(\lambda/\left\|H\right\|_{1})}.

(21)

Proof.

By the fact that
T^{{\dagger}}T=I
and

(I\otimes\bra{0})T^{{\dagger}}ST(I\otimes\ket{0})=H/\left\|H\right\|_{1}
, and
(I\otimes\bra{1})T^{{\dagger}}ST(I\otimes\ket{0})=0
, we have

\displaystyle U\ket{\mu_{\pm}}=\mu_{\pm}T\ket{\lambda}\ket{0}+i\left(1+\frac{2\lambda i}{\left\|H\right\|_{1}}\mu_{\pm}\right)ST\ket{\lambda}\ket{0}.

(22)

In order for this state being an eigenstate, it must hold that

\displaystyle 1+\frac{2\lambda i}{\left\|H\right\|_{1}}\mu_{\pm}=\mu_{\pm}^{2},

(23)

and the solution is

\displaystyle\mu_{\pm}=\frac{\lambda i}{\left\|H\right\|_{1}}\pm\sqrt{1-\frac{\lambda^{2}}{\left\|H\right\|_{1}^{2}}}=\pm e^{\pm i\arcsin(\lambda/\left\|H\right\|_{1})}.

(24)

∎

3
Linear combination of unitaries and Hamiltonian simulation

To see how to convert the quantum walk operator
U
to Hamiltonian simulation, we first consider the generating function for the Bessel function, denoted by
J_{m}(\cdot)
. According to
[
2
, (9.1.41)]
, we have

\displaystyle\sum_{m=-\infty}^{\infty}J_{m}(z)\mu_{\pm}^{m}=\exp\left(\frac{z}{2}\left(\mu_{\pm}-\frac{1}{\mu_{\pm}}\right)\right)=e^{iz\lambda/\left\|H\right\|_{1}},

(25)

where the second equality follows from Eq. (
21
) and the fact that
\sin(x)=(e^{ix}-e^{-ix})/2i
. This leads to the following linear combination of unitaries:

\displaystyle V_{\infty}=\sum_{m=-\infty}^{\infty}\frac{J_{m}(z)}{\sum_{j={-\infty}}^{\infty}J_{j}(z)}U^{m}=\sum_{m=-\infty}^{\infty}J_{m}(z)U^{m}=e^{izH/\left\|H\right\|_{1}},

(26)

where the second equality follows from the fact that
\sum_{j={-\infty}}^{\infty}J_{j}(z)=1
.

Now we consider an approximation to
e^{-izH/\left\|H\right\|_{1}}
in terms of Eq. (
26
):

\displaystyle V_{k}=\sum_{m=-k}^{k}\frac{J_{m}(z)}{\sum_{j=-k}^{k}J_{j}(z)}U^{m}.

(27)

Here the coefficients are normalized by
\sum_{j=-k}^{k}J_{j}(z)
so that they sum to 1. This will minimize the approximation error (see the proof of Lemma
4
in Appendix
B
, and the normalization trick was originated in
[
9
]
). The eigenvalues of
V_{k}
are

\displaystyle\sum_{m=-k}^{k}\frac{J_{m}(z)}{\sum_{j=-k}^{k}J_{j}(z)}\mu_{\pm}^{m}.

(28)

Note that each eigenvalue of
V_{k}
does not depend on
\pm
as
J_{-m}(z)=(-1)^{m}J_{m}(z)
.

To bound the error in this approximation, we have the technical lemma, and the proof is shown in Appendix
B
.

Lemma 4
.

Let
V_{k}
and
V_{\infty}
be defined as above. There exists a positive integer
k
satisfying
k\geq|z|
and

\displaystyle k=O\left(\frac{\log(\lVert H\rVert/(\left\|H\right\|_{1}\epsilon))}{\log\log(\lVert H\rVert/(\left\|H\right\|_{1}\epsilon))}\right),

(29)

such that

\displaystyle\lVert V_{k}-V_{\infty}\rVert\leq\epsilon.

(30)

In the following, we provide technical lemmas for implementing linear combination of unitaries.
Suppose we are given the implementations of unitaries
U_{0}
,
U_{1}
, …,
U_{m-1}
, and coefficients
\alpha_{0},\alpha_{1},\ldots,\alpha_{m-1}
. Then the unitary

\displaystyle V=\sum_{j=0}^{m-1}\alpha_{j}U_{j}

(31)

can be implemented probabilistically by the technique called linear combination of unitaries (LCU)
[
27
]
. Provided
\sum_{j=0}^{m-1}|\alpha_{j}|\leq 2
,
V
can be implemented with success probability
1/4
. To achieve this, we define the multiplexed-
U
operation, which is denoted by
\text{multi-}U
, as

\displaystyle\text{multi-}U\ket{j}\ket{\psi}=\ket{j}U_{j}\ket{\psi}.

(32)

We summarize the probabilistic implementation of
V
in the following lemma, whose proof is shown in Appendix
B
.

Lemma 5
.

Let
\mathrm{multi}
-
U
be defined as above. If
\sum_{j=0}^{m-1}|\alpha_{j}|\leq 2
, then there exists a quantum circuit that maps
\ket{0}\ket{0}\ket{\psi}
to the state

\displaystyle\frac{1}{2}\ket{0}\ket{0}\left(\sum_{j=0}^{m-1}\alpha_{j}U_{j}\ket{\psi}\right)+\frac{\sqrt{3}}{2}\ket{\Phi^{\bot}},

(33)

where
(\ket{0}\!\bra{0}\otimes\ket{0}\!\bra{0}\otimes I)\ket{\Phi^{\bot}}=0
.
Moreover, this quantum circuit uses
O(1)
applications of
\mathrm{multi}
-
U
and
O(m)
1- and 2-qubit gates.

Let
W
be the quantum circuit in Lemma
5
, and let
P
be the projector defined as
P=\ket{0}\!\bra{0}\otimes\ket{0}\!\bra{0}\otimes I
. We have

\displaystyle PW\ket{0}\ket{0}\ket{\psi}=\frac{1}{2}\ket{0}\ket{0}\sum_{j=0}^{m-1}\alpha_{j}U_{j}\ket{\psi}.

(34)

If
\sum_{j=0}^{m-1}\alpha_{j}U_{j}
is a unitary operator, one application of the oblivious amplitude amplification operator
-W(1-2P)W^{{\dagger}}(1-2P)W
implements
\sum_{j=0}^{m-1}U_{j}
with certainty
[
8
]
. However, in our application, the unitary operator
\widetilde{W}
implements an approximation of
V_{\infty}
in the sense that

\displaystyle P\widetilde{W}\ket{0}\ket{0}\ket{\psi}=\frac{1}{2}\ket{0}\ket{0}V_{k}\ket{\psi},

(35)

with
\lVert V_{k}-V_{\infty}\rVert\leq\epsilon
. The following lemma shows that the error caused by the oblivious amplitude amplification is bounded by
O(\epsilon)
, and the proof is given in Appendix
B
.

Lemma 6
.

Let the projector
P
be defined as above. If a unitary operator
\widetilde{W}
satisfies
P\widetilde{W}\ket{0}\ket{0}\ket{\psi}=\frac{1}{2}\ket{0}\ket{0}\widetilde{V}\ket{\psi}
where
\lVert\widetilde{V}-V\rVert\leq\epsilon
. Then
\lVert-\widetilde{W}(I-2P)\widetilde{W}^{{\dagger}}(I-2P)\widetilde{W}\ket{0}\ket{0}\ket{\psi}-\ket{0}\ket{0}V\ket{\psi}\rVert=O(\epsilon)
.

Now we are ready to prove Theorem
1
.

Proof of Theorem
1
.

The proof we outline here follows closely the proof given in
[
9
]
. The intuition of this algorithm is to divide the simulation into
O(t\left\|H\right\|_{1})
segments, with each segment simulating
e^{-iH/2}
. To implement each segment, we use the LCU technique to implement
V_{k}
defined in Eq. (
27
), with coefficients
\alpha_{m}=J_{m}(z)/\sum_{j=-k}^{k}J_{j}(z)
.
When
z=-1/2
, we have
\sum_{j=-k}^{k}|\alpha_{j}|<2
. Actually, this holds for all
|z|\leq 1/2
because

\displaystyle\sum_{j=-k}^{k}|\alpha_{j}|

\displaystyle\leq\sum_{j=-k}^{k}\frac{\lvert J_{j}(z)\rvert}{1-4\frac{|z/2|^{k+1}}{(k+1)!}}\leq\sum_{j=-k}^{k}\frac{\left\lvert z/2\right\rvert^{|j|}}{|j|!}\left(1-\frac{4|z/2|^{k+1}}{(k+1)!}\right)^{-1}

\displaystyle<\frac{8}{7}+\frac{16}{7}\sum_{j=1}^{\infty}\frac{1}{4^{j}j!}=\frac{8}{7}+\frac{16}{7}\left(\sqrt[4]{e}-1\right)<2,

(36)

where the first inequality follows from the fact that
\sum_{j=-k}^{k}J_{j}(z)\geq 1-4|z/2|^{k+1}/(k+1)!
(see
[
9
]
), the second inequality follows from the fact that
|J_{m}(z)|\leq|z/2|^{|m|}/|m|!
(see
[
2
, (9.1.5)]
), and the third inequality uses the assumption that
|z|\leq 1/2
.
Now, Lemmas
5
and
6
can be applied. By Eq. (
25
) and using Lemma
4
, set

\displaystyle k=O\left(\frac{\log(\lVert H\rVert/(\left\|H\right\|_{1}\epsilon^{\prime}))}{\log\log(\lVert H\rVert/(\left\|H\right\|_{1}\epsilon^{\prime}))}\right),

(37)

and we obtain a segment that simulates
e^{-iH/(2\left\|H\right\|_{1})}
with error bounded by
O(\epsilon^{\prime})
. Repeat the segment
O(t\left\|H\right\|_{1})
times with error
\epsilon^{\prime}=\epsilon/(t\left\|H\right\|_{1})
, and we obtain a simulation of
e^{-iHt}
with error bounded by
\epsilon
. It suffices to take

\displaystyle k=O\left(\frac{\log(t\lVert H\rVert/\epsilon)}{\log\log(t\lVert H\rVert/\epsilon)}\right).

(38)

By Lemma
5
, each segment can be implemented by
O(1)
application of
\text{multi-}U
and
O(k)
1- and 2-qubit gates, as well as the cost for computing the coefficients
\alpha_{m}
for
m\in\{-k,\ldots,k\}
. The cost for each
\text{multi-}U
is
k
times the cost for implementing the quantum walk
U
. By Lemma
1
, the state in Eq. (
15
) can be prepared with time complexity (circuit depth)
O(n^{2}b^{5/2})
, where
b
is the number of bit of precision. To achieve the overall error bound
\epsilon
, we choose
b=O(\log(t\left\|H\right\|_{1}/\epsilon))
. Hence the time complexity for the state preparation is
O(n^{2}\log^{5/2}(t\left\|H\right\|_{1}/\epsilon))
, which is also the time complexity for applying the quantum walk
U
. Therefore, the time complexity for one segment is

\displaystyle O\left(n^{2}\log^{5/2}(t\left\|H\right\|_{1}/\epsilon)\frac{\log(t\lVert H\rVert/\epsilon)}{\log\log(t\lVert H\rVert/\epsilon)}\right).

(39)

Considering
O(t\left\|H\right\|_{1})
segments, the time complexity is as claimed.
∎

Note that the coefficients
\alpha_{-k},\ldots,\alpha_{k}
(for
k
defined in Eq. (
37
)) in Lemma
5
can be classically computed using the methods in
[
11
,
34
]
, and the cost is
O(k)
times the number of bits of precision, which is
O(\log(t\lVert H\rVert/\epsilon)
. This is no larger than the quantum time complexity.

4
Discussion

We presented a quantum Hamiltonian simulation algorithm whose time complexity has
\widetilde{O}(\sqrt{N})
dependence for non-sparse Hamiltonians with access to a seemingly more powerful input model.
Our technique for Hamiltonian simulation combines ideas from linear combination of quantum walks and an efficient memory model which prepares a special states to provide the improved performance. Our algorithm can be directly applied as a subroutine for the unitary implementation problem and for a quantum linear systems solver. Especially for the latter application, many quantum machine learning algorithms are based on solving linear systems in the same input model, and our algorithm implies exponentially improved error dependence over
[
41
]
for this application.

We note that the data structure in qRAM may require a large overhead in practice, if the data were not already stored in it.
Furthermore it might be hard to implement such a data structure physically due to the exponential amount of quantum resources
[
1
,
3
,
18
]
.
However, if the Hamiltonian is highly structured (i.e., the entries repeat in some pattern), the memory model could be efficiently implemented.
Another potential point of criticism is the required error rate of such a device, as some computations will require an error rate per gate of
O(1/\mathrm{poly}(N))
to retain a feasible error rate for applications
[
5
]
.
Whereas, not all computations might need such low error rates
[
5
]
and hence the feasibility of our algorithm as a subroutine in an explicit algorithm must be further validated experimentally. To summarize, our algorithm inherits many problems of Grover’s search algorithm for unordered classical data, as well as many qRAM-based quantum machine learning algorithms.

However, if the above mentioned caveats can be overcome, our algorithm still supplies a polynomial speedup over known quantum algorithms for Hamiltonian simulation and furthermore allows for a polynomial speedup in comparison with the best known classical algorithms for several practical problems, such as linear regression or linear systems.
