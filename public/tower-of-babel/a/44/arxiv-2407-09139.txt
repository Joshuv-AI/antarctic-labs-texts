Abstract
We report measurements of time-dependent CP asymmetries in B 0 → K S 0 ​ π 0 ​ γ B^{0}\rightarrow K^{0}_{\scriptscriptstyle S}\pi^{0}\gamma decays based on a data sample of ( 388 ± 6 ) × 10 6 (388\pm 6)\times 10^{6} B ​ B ¯ B\kern 1.79993pt\overline{\kern-1.79993ptB}{} events collected at the Υ ⁡ ( 4 ​ S ) \Upsilon(4S) resonance with the Belle II detector. The Belle II experiment operates at the SuperKEKB asymmetric-energy e + ​ e − e^{+}e^{-} collider. We measure decay-time distributions to determine CP -violating parameters S S and C C . We determine these parameters for two ranges of K S 0 ​ π 0 K^{0}_{\scriptscriptstyle S}\pi^{0} invariant mass: m ⁡ ( K S 0 ​ π 0 ) ∈ ( 0.8 , 1.0 ) ​ Ge ​ V / c 2 m(K^{0}_{\scriptscriptstyle S}\pi^{0})\in(0.8,1.0){\mathrm{\penalty\ Ge\kern-1.00006ptV\!/}c^{2}} , which is dominated by B 0 → K ∗ 0 ( → K S 0 π 0 ) γ B^{0}\rightarrow K^{*0}(\rightarrow K^{0}_{\scriptscriptstyle S}\pi^{0})\gamma decays, and a complementary region m ⁡ ( K S 0 ​ π 0 ) ∈ ( 0.6 , 0.8 ) ∪ ( 1.0 , 1.8 ) ​ Ge ​ V / c 2 m(K^{0}_{\scriptscriptstyle S}\pi^{0})\in(0.6,0.8)\cup(1.0,1.8){\mathrm{\penalty\ Ge\kern-1.00006ptV\!/}c^{2}} . Our results have improved precision as compared to previous measurements and are consistent with theory predictions.
