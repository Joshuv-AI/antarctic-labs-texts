pGMM Kernel Regression and Comparisons with Boosted Trees


Abstract
In this work, we demonstrate the advantage of the pGMM (“powered generalized min-max”) kernel in the context of (ridge) regression. In recent prior studies, the pGMM kernel has been extensively evaluated for classification tasks ( Li 2017b ; Li 2018 ; Li and Zhao 2022b ) , for logistic regression, support vector machines, as well as deep neural networks. In this paper, we provide an experimental study on ridge regression, to compare the pGMM kernel regression with the ordinary ridge linear regression as well as the RBF kernel ridge regression. Perhaps surprisingly, even without a tuning parameter (i.e., p = 1 p=1 for the power parameter of the pGMM kernel), the pGMM kernel already performs well. Furthermore, by tuning the parameter p p , this (deceptively simple) pGMM kernel even performs quite comparably to boosted trees. Boosting and boosted trees are very popular in machine learning practice. For regression tasks, typically, practitioners use L 2 L_{2} boost, i.e., for minimizing the L 2 L_{2} loss. Sometimes for the purpose of robustness, the L 1 L_{1} boost might be a choice. In this study, we implement L p L_{p} boost for p ≥ 1 p\geq 1 and include it in the package of “Fast ABC-Boost” ( Li 2009 ; Li 2010 ; Li and Zhao 2022a ) . Perhaps also surprisingly, the best performance (in terms of L 2 L_{2} regression loss) is often attained at p > 2 p>2 , in some cases at p ≫ 2 p\gg 2 . This phenomenon has already been demonstrated by Li et al. 2010 in the context of k-nearest neighbor classification using L p L_{p} distances. In summary, the implementation of L p L_{p} boost provides practitioners the additional flexibility of tuning boosting algorithms for potentially achieving better accuracy in regression applications.



1
Introduction

Kernels, which can be either linear or nonlinear, are classical tools in machine learning
(
Vapnik 1999
;
Schölkopf and Smola 2002
;
Bishop and Nasrabadi 2006
;
Hastie et al. 2009
)
. In general, machine learning researchers and practitioners are often familiar with the Gaussian (a.k.a. RBF, radial basis function) kernels, the polynomial kernels, etc. In this paper, we introduce the “pGMM” (
p
-powered generalized min-max) kernel for regression tasks.

The idea of the pGMM kernel has been developed in a series of works over the recent years by
Li 2017b
;
Li 2018
;
Li and Zhao 2022b
. To explain the pGMM kernel, we would need to first introduce the GMM (“generalized min-max”) kernel
(
Li 2017a
;
Li and Zhang 2017
)
. The original “min-max” similarity (kernel) was defined on non-negative data
(
Kleinberg and Tardos 1999
;
Charikar 2002
;
Manasse et al. 2010
;
Ioffe 2010
)
. Thus, in order to define the GMM kernel for general data types, the first step is to apply a transformation on the original data to remove negative entries via a simple dimensionality expansion.

Specifically, consider the original data vector
u_{i}
,
i=1
to
d
. The following transformation, depending on whether an entry
u_{i}
is positive or negative,

\displaystyle\left\{\begin{array}[]{cc}\hskip-7.94974pt\tilde{u}_{2i-1}=u_{i},\hskip 7.22743pt\tilde{u}_{2i}=0&\text{if }\ u_{i}>0\\
\tilde{u}_{2i-1}=0,\hskip 7.22743pt\tilde{u}_{2i}=-u_{i}&\text{if }\ u_{i}\leq 0\end{array}\right.

converts general data types to non-negative data. Take a concrete example here. When
d=3
and
u=[-3\ \ 17\ \ -0.8]
, the transformed data vector becomes
\tilde{u}=[0\ \ 3\ \ 17\ \ 0\ \ 0\ \ 0.8]
. The GMM kernel is then defined as the following form:

\displaystyle{\text{GMM}}(u,v)=\frac{\sum_{i=1}^{2d}\min\{\tilde{u}_{i},\tilde{v}_{i}\}}{\sum_{i=1}^{2d}\max\{\tilde{u}_{i},\tilde{v}_{i}\}}.

(3)

Note that, unlike the popular Gaussian (RBF) kernel, the GMM kernel (
3
) has no tuning parameter. To introduce tuning parameters, the following pGMM kernel is one (deceptively) simple strategy:

\displaystyle{\text{pGMM}}(u,v;p)=\frac{\sum_{i=1}^{2d}\left(\min\{\tilde{u}_{i},\tilde{v}_{i}\}\right)^{p}}{\sum_{i=1}^{2d}\left(\max\{\tilde{u}_{i},\tilde{v}_{i}\}\right)^{p}},

(4)

where
p\in\mathbb{R}
is a tuning parameter. Readers have probably realized that this operation is mathematically equivalent to applying a
p
-power transformation on the data before computing the GMM kernel. However, directly applying power transformations on the original data is typically not a good idea due to numerical issues. As demonstrated in
Li 2017b
;
Li 2018
;
Li and Zhao 2022b
, the pGMM kernel can be conveniently “hashed” using for example consistent weighted sampling (CWS)
(
Manasse et al. 2010
;
Ioffe 2010
)
or extremal process
(
Li et al. 2021
)
. Those hashing methods provide a numerically stable framework for applying the power transformation.

As one can see, this pGMM kernel (and the related hashing algorithms) are constructed from the original data without knowing the subsequent tasks, which can be clustering, regression, or classification. As demonstrated in the previous papers or unpublished technical reports
(
Li 2017b
;
Li 2018
;
Li and Zhao 2022b
)
, the pGMM kernel (with merely one tuning parameter) performs surprisingly well in many classification tasks. It is expected that pGMM kernel should also work well for other tasks such as regression. Nevertheless, readers might be still interested in seeing those experiments. This motivates us to report the regression experiments using pGMM kernels.

Summary of contributions.
In this paper, we collect a set of regression datasets to compare pGMM kernel (ridge) regression with linear (ridge) regression and RBF kernel regression. Since the authors have been working on boosting and trees
(
Li 2009
;
Li 2010
;
Li and Zhao 2022a
)
, we also provide the
L_{p}
regression results on those datasets using boosted trees. The experimental results confirm the following:

•

The pGMM kernel performs (perhaps surprisingly) well on regression tasks.

•

Boosted trees typically outperform the pGMM kernel, but usually not by too much.

•

L_{p}
boost with
p>2
in many cases outperforms the standard
L_{2}
(or
L_{1}
) boost.

2
pGMM Kernel Ridge Regression

Consider a training dataset:
X\in\mathbb{R}^{n\times d}
and
Y\in\mathbb{R}^{n}
, where
n
is the number of training examples and
d
is the number of dimensions. Given a testing set
X_{t}
, the classical ridge linear regression (LR) outputs the prediction
\hat{Y}_{t}
as

\displaystyle\hat{Y}_{t}=X_{t}\left(X^{T}X+\lambda I_{d}\right)^{-1}X^{T}Y,

(5)

where
I_{d}
is the identity matrix of size
d\times d
and
\lambda\geq 0
is the regularization coefficient.

To help readers understand (pGMM) kernel regression, we make use of the following standard linear algebra trick (i.e., the “push-through identity”):

\displaystyle\left(X^{T}X+\lambda I_{d}\right)^{-1}X^{T}=X^{T}\left(XX^{T}+\lambda I_{n}\right)^{-1}

(6)

to re-write ridge regression into a mathematically equivalent form:

\displaystyle\hat{Y}_{t}=X_{t}X^{T}\left(XX^{T}+\lambda I_{n}\right)^{-1}Y,

(7)

or in a “kernel” form:

\displaystyle\hat{Y}_{t}=K_{t}\left(K+\lambda I_{n}\right)^{-1}Y,\hskip 14.45377ptK_{t}=X_{t}X^{T},\hskip 14.45377ptK=XX^{T}

(8)

The kernels
K=XX^{T}
and
K_{t}=X_{t}X^{T}
are simple linear kernels. One can of course also use nonlinear kernels, for example, the well-known Gaussian kernel or polynomial kernel. In this paper, we focus on the pGMM kernel

\displaystyle K(u,v;p)={\text{pGMM}}(u,v;p)=\frac{\sum_{i=1}^{2d}\left(\min\{\tilde{u}_{i},\tilde{v}_{i}\}\right)^{p}}{\sum_{i=1}^{2d}\left(\max\{\tilde{u}_{i},\tilde{v}_{i}\}\right)^{p}}.

(9)

where
u
and
v
are two data vectors in the training set
X
or testing set
X_{t}
.

Thus, in a most naive format, conducting kernel (ridge) regression can be extremely simple if the dataset size is small, e.g., with fewer than
30,000
training examples, so that we can store the kernel matrix. This is of course not realistic (and not necessary) for larger datasets. The prior studies
(
Li 2017b
;
Li 2017a
;
Li and Zhang 2017
;
Li 2018
;
Li et al. 2021
;
Li and Zhao 2022b
)
have already provided very extensive experiments to demonstrate how to effectively linearize the min-max kernel and variants via hashing, for classification tasks. In this paper, for the sake of easy reproducibility, we just provide experiments directly using kernels, on relatively small datasets.

;
Schapire and Singer 1999
;
Friedman et al. 2000

3.1
L_{p}
Boosting for Regression Using Second-Order Information

We denote a training dataset by
\{y_{i},\mathbf{x}_{i}\}_{i=1}^{n}
, where
n
is the number of training samples,
\mathbf{x}_{i}
is the
i
-th feature vector, and
y_{i}
is the
i
-th observation value. Our goal is to build a model
F(\mathbf{x})
to minimize the
L_{p}
loss as follows:

\displaystyle L_{p}=\frac{1}{n}\sum_{i=1}^{n}L_{p,i}=\frac{1}{n}\sum_{i=1}^{n}|y_{i}-F_{i}|^{p},\hskip 14.45377pt\text{where }F_{i}=F(\mathbf{x}_{i}).

(10)

Following the “additive model” paradigm
(
Friedman et al. 2000
;
Friedman 2001
)
, we let
F
be a function of
M
terms:

\displaystyle F^{(M)}(\mathbf{x})=\sum_{m=1}^{M}f_{m}(\mathbf{x}),

(11)

where
f_{m}(\mathbf{x})
, the base learner, is a regression tree and learned from the data in a stagewise greedy fashion. Following the idea from
Friedman et al. 2000
, at each boosting iteration, we fit
f_{m}
by weighted least squares, with responses
\{z_{i}\}
and weights
\{w_{i}\}
:

\displaystyle z_{i}=\frac{-L_{p,i}^{\prime}}{L_{p,i}^{\prime\prime}},\hskip 14.45377ptw_{i}=L_{p,i}^{\prime\prime},\hskip 14.45377pt

(12)

\displaystyle\text{where}\ \ L_{p,i}^{\prime}=\frac{\partial{L_{p,i}}}{\partial F_{i}}\ \ \text{and }\ L_{p,i}^{\prime\prime}=\frac{\partial^{2}{L_{p,i}}}{\partial F_{i}^{2}}.

We adopt the derivation from
Li 2010
to obtain the corresponding
gain
formula needed for deciding the split location in building regression trees using responses
\{z_{i}\}
and weights
\{w_{i}\}
. Historically, boosting based on the weighted least square procedure was believed to have numerical issues
(
Friedman et al. 2000
;
Friedman et al. 2008
)
, and hence later
Friedman 2001
proposed using only the first derivatives to fit the trees, i.e.,

\displaystyle z_{i}=-L_{p,i}^{\prime},\hskip 14.45377ptw_{i}=1.

(13)

Of course, it is now clear that, as shown in
Li 2010
, one can derive the explicit and numerically stable/robust formula for computing the gains using second-order information.

Specifically, for the
L_{p}
loss (
10
), we can write down its first derive, for
p\geq 1
:

\displaystyle\frac{\partial L_{p,i}}{\partial F_{i}}=-p|y_{i}-F_{i}|^{p-1}\text{sign}\left(y_{i}-F_{i}\right),

(14)

and the second derivative, for
p\geq 2
:

\displaystyle\frac{\partial^{2}L_{p,i}}{\partial F_{i}^{2}}=p(p-1)|y_{i}-F_{i}|^{p-2}.

(15)

Note that
\frac{\partial^{2}L_{p,i}}{\partial F_{i}^{2}}=2
when
p=2
.

3.2
Tree-Splitting Criterion Using Second-Order Information

Here we repeat derivations in
Li 2010
. Consider a tree node with
N
data points and consider one particular feature. We have the weights
w_{i}
and the response values
z_{i}
,
i=1
to
N
. The data points are already sorted according to the feature values. The tree-splitting procedure is to find the index
s
,
1\leq s<N
, such that the weighted square error (SE) is reduced the most if split at
s
.

That is, we seek the
s
to maximize

\displaystyle Gain(s)=

\displaystyle SE_{total}-(SE_{left}+SE_{right})

\displaystyle=

\displaystyle\sum_{i=1}^{N}(z_{i}-\bar{z})^{2}w_{i}-\left[\sum_{i=1}^{s}(z_{i}-\bar{z}_{L})^{2}w_{i}+\sum_{i=s+1}^{N}(z_{i}-\bar{z}_{R})^{2}w_{i}\right],

where
\bar{z}=\frac{\sum_{i=1}^{N}z_{i}w_{i}}{\sum_{i=1}^{N}w_{i}}
,

\bar{z}_{left}=\frac{\sum_{i=1}^{s}z_{i}w_{i}}{\sum_{i=1}^{s}w_{i}}
,

\bar{z}_{right}=\frac{\sum_{i=s+1}^{N}z_{i}w_{i}}{\sum_{i=s+1}^{N}w_{i}}
.

With some algebra, one can obtain

\displaystyle\sum_{i=1}^{N}(z_{i}-\bar{z})^{2}w_{i}=

\displaystyle\sum_{i=1}^{N}z_{i}^{2}w_{i}+\bar{z}^{2}w_{i}-2z_{i}\bar{z}w_{i}

\displaystyle=

\displaystyle\sum_{i=1}^{N}z_{i}^{2}w_{i}+\left(\frac{\sum_{i=1}^{N}z_{i}w_{i}}{\sum_{i=1}^{N}w_{i}}\right)^{2}\sum_{i=1}^{N}w_{i}-2\frac{\sum_{i=1}^{N}z_{i}w_{i}}{\sum_{i=1}^{N}w_{i}}\sum_{i=1}^{N}z_{i}w_{i}

\displaystyle=

\displaystyle\sum_{i=1}^{N}z_{i}^{2}w_{i}-\frac{\left(\sum_{i=1}^{N}z_{i}w_{i}\right)^{2}}{\sum_{i=1}^{N}w_{i}}

\displaystyle\sum_{i=1}^{s}(z_{i}-\bar{z}_{left})^{2}w_{i}=

\displaystyle\sum_{i=1}^{s}z_{i}^{2}w_{i}-\frac{\left(\sum_{i=1}^{s}z_{i}w_{i}\right)^{2}}{\sum_{i=1}^{t}w_{i}}

\displaystyle\sum_{i=s+1}^{N}(z_{i}-\bar{z}_{right})^{2}w_{i}=

\displaystyle\sum_{i=s+1}^{N}z_{i}^{2}w_{i}-\frac{\left(\sum_{i=s+1}^{N}z_{i}w_{i}\right)^{2}}{\sum_{i=s+1}^{N}w_{i}}

Therefore, after simplification, we obtain

\displaystyle Gain(s)=

\displaystyle\frac{\left[\sum_{i=1}^{s}z_{i}w_{i}\right]^{2}}{\sum_{i=1}^{s}w_{i}}+\frac{\left[\sum_{i=s+1}^{N}z_{i}w_{i}\right]^{2}}{\sum_{i=s+1}^{N}w_{i}}-\frac{\left[\sum_{i=1}^{N}z_{i}w_{i}\right]^{2}}{\sum_{i=1}^{N}w_{i}}

Plugging in
z_{i}=-L_{i}^{\prime}/L_{i}^{\prime\prime}
,
w_{i}=L_{i}^{\prime\prime}
yields,

\displaystyle Gain(s)=

\displaystyle\frac{\left[\sum_{i=1}^{s}L_{i}^{\prime}\right]^{2}}{\sum_{i=1}^{s}L_{i}^{\prime\prime}}+\frac{\left[\sum_{i=s+1}^{N}L_{i}^{\prime}\right]^{2}}{\sum_{i=s+1}^{N}L_{i}^{\prime\prime}}-\frac{\left[\sum_{i=1}^{N}L_{i}^{\prime}\right]^{2}}{\sum_{i=1}^{N}L_{i}^{\prime\prime}}.

(16)

This procedure is numerically robust/stable because we never need to directly compute the response values
z_{i}=-L_{i}^{\prime}/L_{i}^{\prime\prime}
, which can (and should) approach infinity easily. Because the original LogitBoost
(
Friedman et al. 2000
)
directly used the individual response values
z_{i}=-L_{i}^{\prime}/L_{i}^{\prime\prime}
, the procedure was believed to have numerical issues, which was one motivation for
Friedman 2001
to use only the first derivatives to build tress i.e.,
z_{i}=L_{i}^{\prime}

w_{i}=1
. Thus the gain formula becomes:

\displaystyle UGain(s)=

\displaystyle\frac{1}{s}\left[\sum_{i=1}^{s}L_{i}^{\prime}\right]^{2}+\frac{1}{N-s}\left[\sum_{i=s+1}^{N}L_{i}^{\prime}\right]^{2}-\frac{1}{N}\left[\sum_{i=1}^{N}L_{i}^{\prime}\right]^{2}.

(17)

Note that in the above derivations, we simply use
L_{i}
,
L_{i}^{\prime}
, and
L_{i}^{\prime\prime}
by dropping the subscript
p
(e.g.,
L_{p,i}
) because the formulas are really applicable to general loss functions, not just the
L_{p}
loss.

3.3
L_{p}
Boosting Algorithm

Algorithm
1
describes Robust LogitBoost using the tree split gain formula (
16
) (for
p\geq 2
) or the tree split gain formula (
17
) (for
1\leq p<2
). Note that after trees are constructed, the values of the terminal nodes are computed by

\displaystyle\frac{\sum_{node}z_{i,k}w_{i,k}}{\sum_{node}w_{i,k}}=\frac{\sum_{node}-L_{i}^{\prime}}{\sum_{node}L_{i}^{\prime\prime}},

which explains Line 5 of Algorithm
1
. When
1\leq p<2
, because the second derivative
L^{\prime\prime}_{i}
does not exist, we follow
Friedman 2001
by only using the first derivatives to build the trees using the tree split gain formula (
17
), and we update the note values by

\displaystyle\frac{\sum_{node}z_{i,k}w_{i,k}}{\sum_{node}w_{i,k}}=\frac{\sum_{node}-L_{i}^{\prime}}{p\times\#|node|},

which explains Line 9 of Algorithm
1
. Note that we use
p\times\#|node|
instead of just
\times\#|node|
to avoid potential ambiguity at
p=2
.

In retrospect, deriving Eq. (
16
), the explicit tree split gain formula using second-order information, is straightforward. Nevertheless, until the formula was first presented by
Li 2010
, the original LogitBoost was believed to have numerical issues and the more robust MART algorithm was a popular alternative
(
Friedman et al. 2000
;
Friedman et al. 2008
)
. As shown in
Li 2010
, in many datasets, because MART used only the first derivative information for tree split, MART typically did not achieve as good accuracy as Robust LogitBoost. Nowadays, the split gain formula in Eq. (
16
) is the standard implementation in popular tree platforms. On the other hand, we should emphasize that it is not guaranteed that boosting using second derivatives would always improve over boosting using only first derivatives. It might be good to maintain the implementations of both approaches for practitioners to choose from
(
Li and Zhao 2022c
)
.

4
Conclusion

In the context of regression, this paper combines two contributions: 1) kernel ridge regression using the pGMM kernel; and 2)
L_{p}
boosting for regression. The simple (one-parameter only) pGMM kernel is surprisingly effective for regression. The parameter
p
in the pGMM kernel is mathematically equivalent to applying a
p
-powered transformation on the original data before computing the GMM kernel. In practice, the pGMM kernel can be effectively hashed via consistent weighted sampling or extremal process sampling
(
Li et al. 2021
)
, which are numerically stable regardless of the
p
values. If instead we directly apply the power transformation on the original data, numerical problems can easily occur. We hope the presented experiments on pGMM kernel for regression would help encourage the use of the pGMM kernel and variants in machine learning research and practice.

L_{p}
boosting is also effective for regression. Different from the
p
in the pGMM kernel, the parameter
p
in
L_{p}
boosting is for tuning the loss function used for training. While
L_{2}
boosting is popular and standard in practice, using
L_{p}
boosting is as convenient as
L_{2}
when boosting is equipped with the explicit gain formula using second derivatives of the loss function. Practitioners can simply treat the
p
as an additional tuning parameter which might help achieve lower regression errors.
L_{p}
boost has been implemented and included in the “Fast ABC-Boost” package
(
Li and Zhao 2022c
)
. Typically,
L_{p}
boosting could achieve lower regression errors than the pGMM kernel, but the gap in performance is often quite small especially if the original data are reasonably preprocessed.
