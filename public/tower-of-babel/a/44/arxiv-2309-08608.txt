On Egorov’s Theorem for Infinite Measure
Semyon Litvinov

Abstract
. A simple proof of Egorov’s theorem for infinite measure is given.



2020 Mathematics Subject Classification
28A20

1.
Introduction

Let
\Omega=(\Omega,\Sigma,\mu)
be a measure space, and let
\mathcal{L}^{0}(\Omega)
be the space of real-valued measurable functions on
\Omega
. Let
\|\cdot\|_{\infty}
stand for the uniform norm in the space
\mathcal{L}^{\infty}(\Omega)\subset\mathcal{L}^{0}(\Omega)
of essentially bounded functions, that is, given
f\in\mathcal{L}^{\infty}(\Omega)
,

\|f\|_{\infty}=\esssup_{\omega\in\Omega}|f(\omega)|.

Denote by
\chi_{E}
the characteristic function of a set
E\in\Sigma
.

Definition 1.1
.

Let
\{f_{n}\}_{n=1}^{\infty}\subset\mathcal{L}^{0}(\Omega)
.

(A.E.) The sequence
\{f_{n}\}
is said to converge to a function
f\in\mathcal{L}^{0}(\Omega)

almost everywhere
(a.e.) if there exists a set
E\in\Sigma
such that

\mu(\Omega\setminus E)=0\text{ \ and \ }f_{n}(\omega)\to f(\omega)\ \ \forall\ \omega\in E.

(A.U.) The sequence
\{f_{n}\}
is said to converge to a function
f\in\mathcal{L}^{0}(\Omega)

almost uniformly
(a.u.) if for every
\varepsilon>0
there exists a set
E\in\Sigma
such that

\mu(\Omega\setminus E)<\varepsilon\text{ \ and \ }\|(f_{n}-f)\chi_{E}\|_{\infty}\to 0.

The classical Egorov’s theorem can be stated as follows - see, for example,
[
1
]
:

Theorem 1.1
.

Assume that
\mu(\Omega)<\infty
.
If
\{f_{n}\}\subset\mathcal{L}^{0}(\Omega)
is such that
f_{n}\to f
a.e., then
f_{n}\to f
a.u.

It is easy to see that if
\mu(\Omega)=\infty
, Theorem
1.1
is no longer valid: consider the space
\Omega=(0,\infty)
equipped with Lebesgue measure and let
f_{n}=\chi_{(n-1,n]}
, or
f_{n}=\chi_{[n,\infty)}
.

In
[
2
]
, the author, among other results, found a necessary and sufficient condition - which is in essence condition (
1
) below - under which an a.e. convergent sequence in an infinite measure space converges a.u. Note that the argument in
[
2
]
does not employ Theorem
1.1
- it rather follows ”the steps ordinarily employed in measure theory to prove Egorov’s and related theorems.” The goal of this note is to provide a simple argument - based on an application of Egorov’s theorem - to prove its infinite-measure extension:

Theorem 1.2
.

Assume that
\mu(\Omega)=\infty
. If
\{f_{n}\}\subset\mathcal{L}^{0}(\Omega)
is such that
f_{n}\to f
a.e., then
f_{n}\to f
a.u. if and only if

(1)

\forall\ \lambda>0\ \ \exists\ n_{\lambda}\text{ \ such that \ }\mu\Big\{\sup_{n\geq n_{\lambda}}|f_{n}-f|\geq\lambda\Big\}<\infty.

2.
Proof of Theorem
1.2

Without loss of generality, assume that
f=0
a.e.

If there exists
\lambda>0
such that
\mu\big\{\sup_{n\geq m}|f_{n}|\geq\lambda\big\}=\infty
for all
m\in\mathbb{N}
, then
f_{n}\to 0
a.u. clearly fails, so the ”only if” part follows.

Next, assuming that (
1
) holds with
f=0
a.e., we need to show that
f_{n}\to 0
a.u. Fix
\varepsilon>0
and, given
m\in\mathbb{N}
, let
n_{1}(m)
be such that
\mu(F_{m})<\infty
, where

F_{m}=\Big\{\sup_{n\geq n_{m}}|f_{n}|\geq\frac{1}{m}\Big\},\text{\ so that \ }\big\||f_{n}|\chi_{\Omega\setminus F_{m}}\big\|_{\infty}\leq\frac{1}{m}\ \ \forall\ n\geq n_{1}(m).

Then Theorem
1.1
implies that there exists
\Sigma\ni E_{m}\subset F_{m}
such that

\mu(F_{m}\setminus E_{m})\leq\frac{\varepsilon}{2^{m}}\text{\, \ and\, \ }\|f_{n}\chi_{E_{m}}\|_{\infty}\to 0\text{ \ as\ }n\to\infty.

As the sequence
\{f_{n}\chi_{E_{m}}\}
is Cauchy in
\mathcal{L}^{\infty}(\Omega)
for each
m
, it follows that

\forall\,m\ \ \exists\ n_{2}(m)\in\mathbb{N}\text{ \ such that \ }\|(f_{n^{\prime}}-f_{n^{\prime\prime}})\chi_{E_{m}}\|_{\infty}\leq\frac{1}{m}\ \ \forall\ n^{\prime},n^{\prime\prime}\geq n_{2}(m).

Now, setting
G_{m}=E_{m}\cup(\Omega\setminus F_{m})
and
n(m)=\max\{n_{1}(m),n_{2}(m)\}
, we have
\mu(\Omega\setminus G_{m})\leq\displaystyle\frac{\varepsilon}{2^{m}}
and

\begin{split}\|(f_{n^{\prime}}-f_{n^{\prime\prime}})\chi_{G_{m}}\|_{\infty}&=\|(f_{n^{\prime}}-f_{n^{\prime\prime}})\chi_{E_{m}}\|_{\infty}+\|(f_{n^{\prime}}-f_{n^{\prime\prime}})\chi_{\Omega\setminus F_{m}}\|_{\infty}\\
&\leq\frac{1}{m}+\big\||f_{n^{\prime}}|\chi_{\Omega\setminus F_{m}}\big\|_{\infty}+\big\||f_{n^{\prime\prime}}|\chi_{\Omega\setminus F_{m}}\big\|_{\infty}\leq\frac{3}{m}\end{split}

for each
m
and
n^{\prime},n^{\prime\prime}\geq n(m)
.

Furthermore, letting
G=\bigcap_{m}G_{m}
yields

\mu(\Omega\setminus G)\leq\varepsilon\text{\,\ \ and\,\ \ }\|(f_{n^{\prime}}-f_{n^{\prime\prime}})\chi_{G}\|_{\infty}\leq\frac{3}{m}\ \ \forall\ n^{\prime},n^{\prime\prime}\geq n(m),

implying that the sequence
\{f_{n}\chi_{G}\}
is also Cauchy in
\mathcal{L}^{\infty}(\Omega)
.

Therefore, there exists
f\in\mathcal{L}^{\infty}(\Omega)
such that
\|f_{n}\chi_{G}-f\|_{\infty}\to 0
, so we have

\forall\ \varepsilon>0\ \ \exists\ G\in\Sigma\text{ \ such that\,\ }\mu(\Omega\setminus G)\leq\varepsilon\text{ \ and \ }\|(f_{n}-f)\chi_{G}\|_{\infty}\to 0.

Thus
f_{n}\to f
a.u., so
f_{n}\to f
a.e., which, due to
f_{n}\to 0
a.e., entails
f=0
a.e.

Summarizing, we conclude that

\forall\ \varepsilon>0\ \ \exists\ G\in\Sigma\text{ \ such that\,\ }\mu(\Omega\setminus G)\leq\varepsilon\text{ \ and \ }\|f_{n}\chi_{G}\|_{\infty}\to 0,

that is,
f_{n}\to 0
a.u., thus completing the argument.
