Abstract
We study the CP -averaged branching fractions and the CP -violating asymmetries in the pure annihilation decays of B s 0 → a 0 + ​ a 0 − B_{s}^{0}\to a_{0}^{+}a_{0}^{-} and B d 0 → K 0 ∗ ⁣ + ​ K 0 ∗ ⁣ − B_{d}^{0}\to K_{0}^{*+}K_{0}^{*-} , where a 0 ​ [ K 0 ∗ ] a_{0}\;[K_{0}^{*}] denotes the scalar a 0 ​ ( 980 ) a_{0}(980) and a 0 ​ ( 1450 ) a_{0}(1450) [ K 0 ∗ ​ ( 800 ) ​ ( or ​ κ ) K_{0}^{*}(800)({\rm or}\;\kappa) and K 0 ∗ ​ ( 1430 ) K_{0}^{*}(1430) ], with the perturbative QCD factorization approach under the assumption of two-quark structure for the a 0 a_{0} and K 0 ∗ K_{0}^{*} states. The numerical results show that the branching ratios of the B d 0 → K 0 ∗ ⁣ + ​ K 0 ∗ ⁣ − B_{d}^{0}\to K_{0}^{*+}K_{0}^{*-} decays are in the order of 10 − 6 10^{-6} , while the decay rates of the B s 0 → a 0 + ​ a 0 − B_{s}^{0}\to a_{0}^{+}a_{0}^{-} modes are in the order of 10 − 5 10^{-5} . In light of the measured modes with the same quark components in the pseudoscalar sector, namely, B d 0 → K + ​ K − B_{d}^{0}\to K^{+}K^{-} and B s 0 → π + ​ π − B_{s}^{0}\to\pi^{+}\pi^{-} , the predictions for the considered decay modes in this work are expected to be measured at the Large Hadron Collider beauty and/or Belle-II experiments in the (near) future. Meanwhile, it is of great interest to find that the twist-3 distribution amplitudes ϕ S \phi^{S} and ϕ T \phi^{T} with inclusion of the Gegenbauer polynomials for the scalar a 0 ​ ( 1450 ) a_{0}(1450) and K 0 ∗ ​ ( 1430 ) K_{0}^{*}(1430) states in scenario 2 contribute slightly to the branching ratios while significantly to the CP violations in the B d 0 → K 0 ∗ ​ ( 1430 ) + ​ K 0 ∗ ​ ( 1430 ) − B_{d}^{0}\to{K_{0}^{*}}(1430)^{+}{K_{0}^{*}}(1430)^{-} and B s 0 → a 0 ​ ( 1450 ) + ​ a 0 ​ ( 1450 ) − B_{s}^{0}\to a_{0}(1450)^{+}a_{0}(1450)^{-} decays, which indicates that, compared to the asymptotic ϕ S \phi^{S} and ϕ T \phi^{T} , these Gegenbauer polynomials could change the strong phases evidently in these pure annihilation decay channels. These predictions await for the future confirmation experimentally, which could further provide useful information to help explore the inner structure of the scalars and shed light on the annihilation decay mechanism.

are power suppressed and with currently unknown mechanism,

B
and
D

has the advantages in computing the annihilation contributions. Therefore,
by assuming the scalar

and

B_{d}^{0}\to K^{+}K^{-}
