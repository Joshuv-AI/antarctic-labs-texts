Ncorpi 𝒪 \mathcal{O} N : A 𝒪 ⁡ ( N ) \mathcal{O}(N) software for N-body integration in collisional and fragmenting systems. Journal: New Astronomy
Jérémy COUTURIER, Alice C. QUILLEN, Miki NAKAJIMA

Abstract
Ncorpi 𝒪 \mathcal{O} N is a N-body software developed for the time-efficient integration of collisional and fragmenting systems of planetesimals or moonlets orbiting a central mass. It features a fragmentation model, based on crater scaling and ejecta models, able to realistically simulate a violent impact. The user of Ncorpi 𝒪 \mathcal{O} N can choose between four different built-in modules to compute self-gravity and detect collisions. One of these makes use of a mesh-based algorithm to treat mutual interactions in 𝒪 ⁡ ( N ) \mathcal{O}(N) time. Another module, much more efficient than the standard Barnes-Hut tree code, is a 𝒪 ⁡ ( N ) \mathcal{O}(N) tree-based algorithm called FalcON. It relies on fast multipole expansion for gravity computation and we adapted it to collision detection as well. Computation time is reduced by building the tree structure using a three-dimensional Hilbert curve. For the same precision in mutual gravity computation, Ncorpi 𝒪 \mathcal{O} N is found to be up to 25 25 times faster than the famous software REBOUND. Ncorpi 𝒪 \mathcal{O} N is written entirely in the C language and only needs a C compiler to run. A python add-on, that requires only basic python libraries, produces animations of the simulations from the output files. The name Ncorpi 𝒪 \mathcal{O} N, reminding of a scorpion, comes from the French N-corps , meaning N-body, and from the mathematical notation 𝒪 ⁡ ( N ) \mathcal{O}(N) , due to the running time of the software being almost linear in the total number N N of moonlets. Ncorpi 𝒪 \mathcal{O} N is designed for the study of accreting or fragmenting disks of planetesimal or moonlets. It detects collisions and computes mutual gravity faster than REBOUND, and unlike other N-body integrators, it can resolve a collision by fragmentation. The fast mutipole expansions are implemented up to order six to allow for a high precision in mutual gravity computation.

Mutual interactions between the moonlets

We consider in this section mutual interactions between the moonlets. The general aspects of orbital dynamics, those not related to moonlet
-
moonlet mutual interactions, are treated in
B

\mathcal{O}(N)
time. However, the moonlets can interact through collisions and mutual gravity, and managing these interactions in a naive way results in a very slow integrator. Hereafter, a mutual interaction denotes either a collision or a gravitational mutual interaction. We review in this section the four modules implemented in Ncorpi
\mathcal{O}
N that can deal with mutual interactions between the moonlets, namely

1.

\mathcal{O}(N^{2})
brute-force method.

2.

\mathcal{O}(N\ln N)
standard tree code.

3.

\mathcal{O}(N)
falcON fast multipole method.

4.

\mathcal{O}(N)
mesh-grid algorithm.

Each of the four modules is able to treat both the detection of collision and the computation of self gravity (Ncorpi
\mathcal{O}
N adapts Dehnen’s falcON algorithm so it can also detect collisions).

3.1
Detectiong a collision between a pair of moonlet

Before delving into the presentation of the four mutual interaction modules, we describe how Ncorpi
\mathcal{O}
N decides if two given moonlets will collide in the upcoming timestep. Note that apart from the brute-force method, these modules rarely treat mutual interactions in a pair-wise way.

Given two moonlets with positions
\mathbf{\boldsymbol{r}}_{1}
and
\mathbf{\boldsymbol{r}}_{2}
and masses
m_{1}
and
m_{2}
, all four modules rely on the following procedure to determine if the moonlets will be colliding during the upcoming timestep.

Let
\mathbf{\boldsymbol{v}}_{1}
and
\mathbf{\boldsymbol{v}}_{2}
be the velocities of the moonlets and
R_{1}
and
R_{2}
their radii. Let us denote
\Delta\mathbf{\boldsymbol{v}}=\mathbf{\boldsymbol{v}}_{1}-\mathbf{\boldsymbol{v}}_{2}
and
\Delta\mathbf{\boldsymbol{r}}=\mathbf{\boldsymbol{r}}_{1}-\mathbf{\boldsymbol{r}}_{2}
. Approximating the trajectories by straight lines, we decide according to the following procedure if the moonlets will collide during the upcoming timestep. We first compute the discriminant

\Delta=\left(\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}\right)^{2}+\Delta v^{2}\left[\left(R_{1}+R_{2}\right)^{2}-\Delta r^{2}\right].

(1)

Then, the time
\Delta t
until the collision is given by

\Delta t=-\frac{\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}+\sqrt{\Delta}}{\Delta v^{2}}.

(2)

A collision will occur between the moonlets in the upcoming timestep if, and only if,
\Delta t\in\mathbb{R}
and
0\leq\Delta t\leq dt
, where
dt
is the size of the timestep. If that is the case, the collision is resolved using results from Sect.
5
.

3.2
Brute-force
\mathcal{O}(N^{2})
algorithm

The most straightforward way of treating mutual interactions is through a brute-force algorithm where all
N(N-1)/2
pairs of moonlets are considered. At each timestep, the mutual gravity between all pairs is computed, and the algorithm decides if a collision will occur between the two considered moonlets in the upcoming timestep. However, this greedy procedure yields a
\mathcal{O}(N^{2})
time complexity, limiting the total number of moonlets to a few thousands at best on a single-core implementation (
e.g.

1000\leq N\leq 2700
in
Salmon and Canup 2012
).

3.3
The mesh
\mathcal{O}(N)

Khuller and Matias 1995

Their algorithm is not completely straightforward to implement and only allows for the closest pair of moonlets to be identified. Here, we describe a mesh-based three-dimensional simplified version of their algorithm able to detect collisions in

For a real number

\mathcal{O}

In practise in Ncorpi

3.4
Tree-based algorithms

In this section, we present the two remaining modules of Ncorpi
\mathcal{O}
N that can search for collisions or compute mutual gravity using a three-dimensional tree, or octree. The first algorithm, hereafter referred as standard tree code, was published in 1986 by
Barnes and Hut 1986
for mutual gravity computation, and adapted in 2012 by
Rein and Liu 2012
for collision detection in REBOUND. The second algorithm, called falcON, was published in 2002 by
Dehnen 2002
for mutual gravity computation. We show in this section that it can be adapted to collision search as well.

Both the standard tree code and falcON use a fast multipole Taylor expansion for mutual gravity computation, and take advantage of the fact that collisions are short-range only for collision search. FalcON is significantly faster than the standard tree code at both mutual gravity computation (for the same precision) and collision detection.

3.4.2
Tree climbing

The tree climbing procedure consists in computing several quantities for all cells of the tree, recursively from the children nodes. The tree climbing procedure differs slightly for collision search or mutual gravity computation.

3.4.6
Peano-Hilbert order and cache efficiency

The practical construction of a tree generally involves a structure containing relevant informations for the current cell (number of children, mass, multipole moments, etc
\cdots
), and pointers towards the children nodes, that can be either NULL or contain the address in memory of a child. Such a construction is easy to implement but yields poor memory locality (children have no reason to be next to each other in memory) and travelling in the tree requires multiple pointer dereferences. These issues are responsible for many cache misses and the processor wastes a lot of clock cycles waiting for data in memory.

Figure 5:
Hilbert order of all the cells of the tree of Fig.

A much better implementation can be achieved by storing the tree in a regular array, in such a way that children are contiguous in memory, and such that cells close in space are likely to be close in memory. To this aim, we use the space filling curve discovered by David Hilbert. At a given generation (or level) in the tree, cells are ordered according to a three-dimensional version of Hilbert’s 1891 space filling curve, skipping non-existing cells. For illustration purposes, we show this order in two dimensions in Fig.

If

\text{order}(A)>\text{order}(B)

a

A

b

However, when building the tree, its final structure as well as the number of cells it contains are still unknown and it is not possible to build the tree in a regular array. Therefore, we use the general representation based on pointers to build the tree. Then, the final tree is copied in an array indexed by Hilbert order, hereafter called the flat tree, and the tree is freed. FalcON algorithm (climbing, walk and descent) and the standard tree code (climbing and standard tree) are performed on the flat tree.

Instead of putting the moonlets in the tree in a random order, an impressive speed-up for the tree building can be achieved by putting the moonlets in the Hilbert order of the previous timestep. We define the Hilbert order of a moonlet as the Hilbert order of its parent leaf. When the moonlets are put in the tree in the Hilbert order of the previous timestep, a spacial coherence is maintained during the tree construction, increasing the probability that the data needed by the processor are already loaded in the cache, and reducing cache misses. 4.1
Numerical integration

In the parameter file of Ncorpi
\mathcal{O}

If the mesh-algorithm is used, then only mutual gravity with the neighbouring moonlets and with the three largest moonlets are taken into account. (28)

5.1
Elastic collisions

We say that a collision is elastic if it conserves both energy and momentum.
Let
\mathbf{\boldsymbol{v}}^{\prime}_{1}
and
\mathbf{\boldsymbol{v}}^{\prime}_{2}
be the moonlets velocities after the impact. If we write

\mathbf{\boldsymbol{v}}^{\prime}_{1}-\mathbf{\boldsymbol{v}}_{1}=-\frac{\mathbf{\boldsymbol{J}}}{m_{1}}\quad\text{ and }\quad\mathbf{\boldsymbol{v}}^{\prime}_{2}-\mathbf{\boldsymbol{v}}_{2}=\frac{\mathbf{\boldsymbol{J}}}{m_{2}},

(30)

then it is immediate to verify that the total momentum is conserved, whatever the vector
\mathbf{\boldsymbol{J}}
. Let us write

\mathbf{\boldsymbol{J}}=\alpha_{\text{el}}\left(\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}\right)\Delta\mathbf{\boldsymbol{r}},

(31)

where
\alpha_{\text{el}}
is a real number. The scalar product
\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}
traduces the violence of the impact, in the sense that, for a grazing collision,
\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}=0
, while for a frontal collision, it reaches an extremum
\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}=-\Delta r\Delta v
. The variation of kinetic energy
\Delta E
at the impact reads

\Delta E=\alpha_{\text{el}}\left(\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}\right)^{2}\left(\frac{m_{1}+m_{2}}{2m_{1}m_{2}}\alpha_{\text{el}}\Delta r^{2}-1\right).

(32)

At the impact, we have
\Delta r=R_{1}+R_{2}
and the elasticity of the collision reads

\alpha_{\text{el}}=\frac{2m_{1}m_{2}}{\left(m_{1}+m_{2}\right)\left(R_{1}+R_{2}\right)^{2}}.

(33)

5.2
Inelastic collisions

The results of Sect.
5.1
suggest a very straightforward model for non-elastic collisions. We simply write
\mathbf{\boldsymbol{J}}=\alpha\left(\Delta\mathbf{\boldsymbol{r}}\cdot\Delta\mathbf{\boldsymbol{v}}\right)\Delta\mathbf{\boldsymbol{r}}
, and if we choose for
\alpha
a non-zero value different from
\alpha_{\text{el}}
, then the collision in inelastic. Let us write

\alpha=\frac{fm_{1}m_{2}}{\left(m_{1}+m_{2}\right)\left(R_{1}+R_{2}\right)^{2}}=\frac{f}{2}\alpha_{\text{el}},

(34)

where
f\in\mathbb{R}
. Then the variation in kinetic energy due to the impact reads

\Delta E=2f\left(f-2\right)\frac{m_{1}m_{2}}{m_{1}+m_{2}}\cos^{2}\theta\Delta v^{2}.

(35)

To prevent an energy increase, we must consider
0\leq f\leq 2
. The condition that the two moonlets gets farther away from each other after the impact reads
\Delta\mathbf{\boldsymbol{v}}^{\prime}\cdot\Delta\mathbf{\boldsymbol{r}}\geq 0
. We have

\Delta\mathbf{\boldsymbol{v}}^{\prime}\cdot\Delta\mathbf{\boldsymbol{r}}=\left(1-f\right)\left(\Delta\mathbf{\boldsymbol{v}}\cdot\Delta\mathbf{\boldsymbol{r}}\right),

(36)

and so we take
f\geq 1
to prevent the moonlets from getting closer after the collision.
Ncorpi
\mathcal{O}
N’s model for non-merging and non-fragmenting collisions thus relies on the parameter
f
(indicated by the user in the parameter file of Ncorpi
\mathcal{O}
N), bounded by
1\leq f\leq 2
, such that values of
f
close to
2
correspond to almost elastic collisions, whereas values close to
1
correspond to very inelastic collisions.

(59)

be the velocity and position of the center of mass of the colliding pair. We define

\mathbf{\boldsymbol{G}}=m_{1}\mathbf{\boldsymbol{r}}_{1}\times\mathbf{\boldsymbol{v}}_{1}+m_{2}\mathbf{\boldsymbol{r}}_{2}\times\mathbf{\boldsymbol{v}}_{2}

(60)

the angular momentum of the pair at the collision. For a merger, the conservation of the angular momentum (
resp
. the momentum) reads
M\tilde{\mathbf{\boldsymbol{r}}}\times\tilde{\mathbf{\boldsymbol{v}}}=\mathbf{\boldsymbol{G}}
(
resp
.
\tilde{\mathbf{\boldsymbol{v}}}=\mathbf{\boldsymbol{v}}_{\text{cm}}
). It is interesting to notice that it is impossible to preserve both the momentum and the angular momentum at the collision without considering the spin. Indeed, the conservation of the angular momentum implies that
\tilde{\mathbf{\boldsymbol{v}}}
is orthogonal to
\mathbf{\boldsymbol{G}}
. However, from

M\tilde{\mathbf{\boldsymbol{v}}}\cdot\mathbf{\boldsymbol{G}}=M\mathbf{\boldsymbol{v}}_{\text{cm}}\cdot\mathbf{\boldsymbol{G}}=m_{1}m_{2}\mathbf{\boldsymbol{v}}_{2}\cdot\Delta\mathbf{\boldsymbol{r}}\times\Delta\mathbf{\boldsymbol{v}},

(61)

we conclude that it is possible to conserve both the momentum and the angular momentum only if
\Delta\mathbf{\boldsymbol{r}}\times\Delta\mathbf{\boldsymbol{v}}=\mathbf{\boldsymbol{0}}
, or equivalently, only if the collision is frontal (
\text{\textqoppa{} }\!\!=0
). For oblique collisions, the only way to conserve both is to take into account the spin of the moonlets. However, taking into account the spin complexifies the treatment of collisions as well as the numerical implementation and slows down the code. Therefore, NcorpiON does not implement the spin and if the user chooses to use the fragmentation model or to resolve all collisions by merging, then it must be decided if the momentum or the angular momentum should be preserved upon impact. If falcON is used to treat mutual interactions, then it makes more sense to preserve the momentum upon collision, since by construction, falcON preserves the total momentum when computing mutual gravity, but does not preserve the total angular momentum.

When the colliding moonlets merge, the momentum is conserved simply by taking
\tilde{\mathbf{\boldsymbol{v}}}=\mathbf{\boldsymbol{v}}_{\text{cm}}
, whereas we achieve the conservation of the momentum with
\tilde{\mathbf{\boldsymbol{v}}}=\mathbf{\boldsymbol{v}}_{\text{cm}}-\check{m}\check{\mathbf{\boldsymbol{v}}}^{\prime}/M
when the tail is reunited into one unique moonlet. Finally, when a full fragmentation occurs, we conserve the total momentum with

\tilde{\mathbf{\boldsymbol{v}}}=\mathbf{\boldsymbol{v}}_{\text{cm}}-\sum_{j=1}^{\tilde{N}}\frac{\tilde{m}_{2}}{M}\tilde{\mathbf{\boldsymbol{v}}}_{k}^{\prime}.

(62)

Conserving the angular momentum is not as straightforward and we present our model for doing so in
D
. Requiring the conservation of the momentum is not enough to constrain
\tilde{\mathbf{\boldsymbol{r}}}
, and we use the value of
\tilde{\mathbf{\boldsymbol{r}}}
determined in
D
even when the user decides to conserve the momentum, in order to be as close as possible from the conservation of the total angular momentum.

6
Conclusions

We have presented with this paper a novel
N
-body software, faster than existing
N
-body integrators on a single core implementation. Unlike other similar softwares, Ncorpi
\mathcal{O}
N is able to treat a fragmentation subsequent to a violent collision. Mutual interactions (collisions and self-gravity) can be treated with four different modules, whose time complexities range from
\mathcal{O}(N)
to
\mathcal{O}(N^{2})
. Using falcON module for mutual interactions, Ncorpi
\mathcal{O}
N is found to be
25
times faster than the software REBOUND when
N=2^{23}
, for the same precision in mutual gravity computation.

Ncorpi
\mathcal{O}
N is very adapted to simulations of satellites or planet formation, and we are currently using it to better understand the formation of the Moon from a protolunar disk around the Earth, following the giant impact between the proto-Earth and Theia. The results of this study will constitute another paper, that will be published afterwards.

Ncorpi
\mathcal{O}
N has its own
website
1
and is distributed freely on the following
github repository
2
. Both these resources provide extensive documentation and the website also provides with a detailed overview of the structure of Ncorpi
\mathcal{O}
N’s code.

This software was written with time efficiency in mind and aims to be as CPU-efficient and cache-friendly as possible. As such, we believe it is among the fastest single-core
N
-body codes for large
N
, if not the fastest
26
26

26

GyrfalcON
on NEMO could be faster, since it also uses falcON. However, it does not handle collisions or fragmentations.
. However, unlike other softwares, Ncorpi
\mathcal{O}
N lacks a parallelized version. Even though REBOUND is found to be significantly slower than Ncorpi
\mathcal{O}
N on a single-core run, it would outperform Ncorpi
\mathcal{O}
N if heavily parallelized. Therefore, we plan to upgrade Ncorpi
\mathcal{O}
N to a parallelized version in the future, as well as to make it a multi-purpose
N
-body integrator (by removing the need for a massive central mass).

Ncorpi
\mathcal{O}
N has its own fragmentation module that relies on crater scaling and ejecta models to come up with a realistic outcome for violent collisions between moonlets. However, this model makes assumptions (
e.g.
impactor much smaller than target) that can be hard to reconcile with the reality of a simulation. Furthermore, the direction of the fragments is chosen arbitrarily after a fragmentation, and these issues could reduce the actual degree of realism of Ncorpi
\mathcal{O}
N’s fragmentation model.

Beyond planetary or satellite formation, disks of debris are also observed by stellar occultation around some trans-Neptunian object like the dwarf planet Haumea (
Ortiz et al. 2017
), or a smaller-sized body called Quaoar (
Morgado et al. 2023
). Both these objects feature rings located outside of their Roche radius, and Ncorpi
\mathcal{O}
N could be a relevant tool to understand what mechanisms prevent the rings’ material from accreting.

Appendix B
General orbital dynamics

This appendix focuses on aspects of orbital dynamics that are not moonlet
-
moonlet interactions (treated in Sect.
3
).

B.1
Interactions with the center of mass of the Earth

We consider here the gravitational interactions between the moonlets and the center of mass of the Earth. Let
\mathbf{\boldsymbol{r}}
be the position of a moonlet in the geocentric reference frame. Its gravitational potential per unit mass reads

V=-\frac{\mathcal{G}M_{\oplus}}{r},

(63)

where
\mathcal{G}
is the gravitational constant. The moonlet’s acceleration is given by

\ddot{\mathbf{\boldsymbol{r}}}=-\nabla_{\mathbf{\boldsymbol{r}}}V,

(64)

that is,

\ddot{\mathbf{\boldsymbol{r}}}=-\frac{\mathcal{G}M_{\oplus}}{r^{3}}\mathbf{\boldsymbol{r}}.

(65)

Ncorpi
\mathcal{O}
N uses dimensionless units such that
R_{\oplus}=M_{\oplus}=1
and
\mathcal{G}=4\pi^{2}
. The choice
\mathcal{G}=4\pi^{2}
, instead of the more common
\mathcal{G}=1
, ensures that the unit of time is the orbital period at Earth surface. The user can change this in the parameter file.

B.2
Earth flattening and interactions with the equatorial bulge

The Earth is not exactly a sphere, and under its own rotation, it tends to take an ellipsoidal shape. The subsequent redistribution of mass modifies its gravitational field, affecting the moonlets. Let
\zeta(\theta,\varphi)
be the altitude of the geoid of the Earth, where

\begin{split}&X=r\sin\theta\cos\varphi,\\
&Y=r\sin\theta\sin\varphi,\\
&Z=r\cos\theta,\end{split}

(66)

is the relation between the cartesian and spherical coordinates of
\left(\mathcal{O},\mathbf{\boldsymbol{I}},\mathbf{\boldsymbol{J}},\mathbf{\boldsymbol{K}}\right)
. If
R_{\oplus}
denotes the mean radius of the Earth, then the geoid is generally defined as the only equipotential surface such that

\int_{0}^{2\pi}\int_{0}^{\pi}\zeta(\theta,\varphi)\sin\theta d\theta d\varphi=R_{\oplus},

(67)

that is, as the only equipotential surface whose average height is the mean radius. Expanding the geoid over the spherical harmonics as

\begin{split}&\zeta(\theta,\varphi)=R_{\oplus}\left[1+h(\theta,\varphi)\right],\text{ and}\\
&h(\theta,\varphi)=\sum_{l=2}^{+\infty}\sum_{m=-l}^{l}\epsilon_{lm}Y_{lm}(\theta,\varphi)\\
\end{split}

(68)

satisfies Eq. (
67
). For reference, the definition of the spherical harmonics used here is given in Appendix A of
Couturier 2022
. If the Earth is spherical, then its potential is radial and we take
\zeta(\theta,\varphi)=R_{\oplus}
, that is,
\epsilon_{lm}=0
for all
l
and
m
.

Similarly as for the geoid, we write the potential raised by the redistribution of mass within the Earth as (
e.g.

Boué et al. 2019
)

\begin{split}&V(r,\theta,\varphi)=-\frac{\mathcal{G}M_{\oplus}}{r}\left[1+\hat{v}(r,\theta,\varphi)\right]+V_{\Omega}(r,\theta),\\
&\hat{v}(r,\theta,\varphi)=\sum_{l=2}^{+\infty}\sum_{m=-l}^{l}\left(\frac{R_{\oplus}}{r}\right)^{l}\hat{V}_{lm}Y_{lm}(\theta,\varphi),\end{split}

(69)

where
V_{\Omega}(r,\theta)=\Omega^{2}r^{2}\left(P_{2}(\cos\theta)-1\right)/3
is the potential raised by the rotation itself. We denote
\Omega_{\text{c}}=

\left(\mathcal{G}M_{\oplus}/R_{\oplus}^{3}\right)^{1/2}
the Keplerian frequency at Earth’s surface. With this notation, the potential raised by the Earth deformed under its own rotation can be rewritten

\begin{split}&V(r,\theta,\varphi)=-\frac{\mathcal{G}M_{\oplus}}{r}\left[1+v(r,\theta,\varphi)\right]-\frac{1}{3}\Omega^{2}r^{2},\\
&v(r,\theta,\varphi)=\sum_{l=2}^{+\infty}\sum_{m=-l}^{l}\left(\frac{R_{\oplus}}{r}\right)^{l}V_{lm}Y_{lm}(\theta,\varphi),\end{split}

(70)

where
V_{lm}=\hat{V}_{lm}
if
\left(l,m\right)\neq\left(2,0\right)
and

V_{20}=\hat{V}_{20}-\frac{1}{3}\frac{\Omega^{2}}{\Omega_{\text{c}}^{2}}\frac{r^{5}}{R_{\oplus}^{5}}.

(71)

If we assume
h\ll 1
and
v\ll 1
(this is equivalent to
\Omega^{2}\ll\Omega_{\text{c}}^{2}
), then it is easy to verify from the definition of the geoid that (
Wahr 1996
, Sect. 4.3.1)

\epsilon_{lm}=V_{lm}\bigr|_{r=R_{\oplus}}.

(72)

This gives a relation between the figure of the Earth (the geoid) and the potential raised by the redistribution of mass. If we limit ourselves to the quadrupolar order and if we assume that the problem does not to depend on
\varphi
(axisymmetry), then all the
V_{lm}
and
\epsilon_{lm}
vanish for
\left(l,m\right)\neq\left(2,0\right)
. For the fluid Earth, it can be shown that (
Couturier 2022
, Sect. 5.2.1;
Wahr 1996
, Eq. (4.24))

\epsilon_{20}=-\frac{5}{6}\frac{\Omega^{2}}{\Omega_{\text{c}}^{2}}.

(73)

The
J_{2}
coefficient is defined as
J_{2}=-\hat{V}_{20}
(with the convention of Appendix A of
Couturier 2022
for the spherical harmonics). For the fluid Earth, Eqs. (
71
), (
72
) and (
73
) yield

J_{2}=\frac{1}{2}\frac{\Omega^{2}}{\Omega_{\text{c}}^{2}}.

(74)

According to Eq. (
69
), a moonlet orbiting the Earth at position
\mathbf{\boldsymbol{r}}
in the geocentric reference frame, feels, from the equatorial bulge, the potential per unit mass
27
27

27

Due to the axisymmetry, we can go to the geocentric reference frame by simply removing
V_{\Omega}
in Eq. (
69
).

\begin{split}V_{J_{2}}=&\frac{\mathcal{G}M_{\oplus}R_{\oplus}^{2}}{r^{3}}J_{2}P_{2}(\cos\theta)\\
=-&\frac{\mathcal{G}M_{\oplus}R_{\oplus}^{2}}{2r^{5}}J_{2}\left(r^{2}-3\left(\mathbf{\boldsymbol{k}}\cdot\mathbf{\boldsymbol{r}}\right)^{2}\right).\end{split}

(75)

Writing
\mathbf{\boldsymbol{r}}=x\mathbf{\boldsymbol{i}}+y\mathbf{\boldsymbol{j}}+z\mathbf{\boldsymbol{k}}
, we have
\mathbf{\boldsymbol{k}}\cdot\mathbf{\boldsymbol{r}}=z

64

\ddot{\mathbf{\boldsymbol{r}}}=\frac{\mathcal{G}M_{\oplus}R_{\oplus}^{2}J_{2}}{r^{5}}\left[\frac{15z^{2}-3r^{2}}{2r^{2}}\mathbf{\boldsymbol{r}}-3z\mathbf{\boldsymbol{k}}\right].

(76)

The user chooses the sideral rotation period of the Earth (or central body) in the parameter file of Ncorpi
\mathcal{O}
N. Then, Eq. (

) and the fluid approximation are used to determine the

of the central body.

B.3
Interaction with the Sun

The interaction between a moonlet, located at
\mathbf{\boldsymbol{r}}
, and the Sun, located at
\mathbf{\boldsymbol{r}}_{\odot}
in the geocentric reference frame can be taken into account in the model by adding to the moonlet the potential per unit mass

V_{\odot}=-\mathcal{G}M_{\odot}\left(\frac{1}{\left|\mathbf{\boldsymbol{r}}-\mathbf{\boldsymbol{r}}_{\odot}\right|}-\frac{\mathbf{\boldsymbol{r}}\cdot\mathbf{\boldsymbol{r}}_{\odot}}{r_{\odot}^{3}}\right).

(77)

To the quadrupolar order, this gives

V_{\odot}=-\frac{\mathcal{G}M_{\odot}}{2r_{\odot}^{3}}\left(3\frac{\left(\mathbf{\boldsymbol{r}}\cdot\mathbf{\boldsymbol{r}}_{\odot}\right)^{2}}{r_{\odot}^{2}}-r^{2}\right).

(78)

Equation (
64
) yields, for the acceleration of the moonlet

\ddot{\mathbf{\boldsymbol{r}}}=-\frac{\mathcal{G}M_{\odot}}{r_{\odot}^{3}}\left(\mathbf{\boldsymbol{r}}-3\frac{\mathbf{\boldsymbol{r}}\cdot\mathbf{\boldsymbol{r}}_{\odot}}{r_{\odot}^{2}}\mathbf{\boldsymbol{r}}_{\odot}\right).

(79)

For simplification, we assume that the Earth orbits the Sun on a circular trajectory. Without restraining the generality, we can assume that the Earth’s longitude of the ascending node is
0
(this can be achieved by simply putting the unit vector
\mathbf{\boldsymbol{i}}
of the geocentric frame towards the ascending node). Similarly, for a circular orbit, we can arbitrarily choose
\omega_{\odot}=0
. We denote
a_{\odot}
the semi-major axis of the Earth orbit and
\epsilon
the obliquity of the Earth. With these notations, the vector
\mathbf{\boldsymbol{r}}_{\odot}
reads

\begin{split}&\mathbf{\boldsymbol{r}}_{\odot}=\begin{pmatrix}x_{\odot}\\
y_{\odot}\\
z_{\odot}\end{pmatrix}=\begin{pmatrix}1&0&0\\
0&\cos\epsilon&-\sin\epsilon\\
0&\sin\epsilon&\cos\epsilon\end{pmatrix}\begin{pmatrix}a_{\odot}\cos\lambda_{\odot}\\
a_{\odot}\sin\lambda_{\odot}\\
0\end{pmatrix}\!\!\!\\
&=\begin{pmatrix}a_{\odot}\cos\lambda_{\odot}\\
a_{\odot}\sin\lambda_{\odot}\cos\epsilon\\
a_{\odot}\sin\lambda_{\odot}\sin\epsilon\end{pmatrix},\end{split}

(80)

where
\lambda_{\odot}=n_{\odot}t=t\sqrt{\mathcal{G}M_{\odot}/a_{\odot}^{3}}
.

Appendix D
Conservation of the angular momentum upon fragmenting or merging impact

We present here the method that Ncorpi
\mathcal{O}
N uses to preserve the angular momentum up to machine precision, when the user requires so. We recall that

\mathbf{\boldsymbol{v}}_{\text{cm}}=\frac{m_{1}}{M}\mathbf{\boldsymbol{v_{1}}}+\frac{m_{2}}{M}\mathbf{\boldsymbol{v_{2}}}\quad\text{and}\quad\mathbf{\boldsymbol{r}}_{\text{cm}}=\frac{m_{1}}{M}\mathbf{\boldsymbol{r_{1}}}+\frac{m_{2}}{M}\mathbf{\boldsymbol{r_{2}}},

(87)

are the velocity and position of the center of mass of the colliding pair, whereas

\mathbf{\boldsymbol{G}}=m_{1}\mathbf{\boldsymbol{r}}_{1}\times\mathbf{\boldsymbol{v}}_{1}+m_{2}\mathbf{\boldsymbol{r}}_{2}\times\mathbf{\boldsymbol{v}}_{2},

(88)

is the angular momentum to be conserved.

D.1
Case of a merger

If the collision results in a merger, then the outcome is a single moonlet of mass
M=m_{1}+m_{2}
.
The conservation of the total angular momentum reads

\mathbf{\boldsymbol{G}}=M\tilde{\mathbf{\boldsymbol{r}}}\times\tilde{\mathbf{\boldsymbol{v}}}.

(89)

Equation (
89
) only has solutions if
\tilde{\mathbf{\boldsymbol{r}}}
is perpendicular to
\mathbf{\boldsymbol{G}}
. Therefore, we write

\tilde{\mathbf{\boldsymbol{r}}}=\mathbf{\boldsymbol{r}}_{\text{cm}}+\delta\tilde{\mathbf{\boldsymbol{r}}},

(90)

and we choose the smallest possible value of
\delta\tilde{\mathbf{\boldsymbol{r}}}
that verifies

\mathbf{\boldsymbol{G}}\cdot\tilde{\mathbf{\boldsymbol{r}}}=\mathbf{\boldsymbol{G}}\cdot\delta\tilde{\mathbf{\boldsymbol{r}}}+\frac{m_{1}m_{2}}{M}\mathbf{\boldsymbol{r}}_{2}\cdot\Delta\mathbf{\boldsymbol{r}}\times\Delta\mathbf{\boldsymbol{v}}=0.

(91)

Equation (
91
) is of the form
\mathbf{\boldsymbol{\mathfrak{a}}}\cdot\mathbf{\boldsymbol{w}}=\mathfrak{b}
with unknown
\mathbf{\boldsymbol{w}}=\delta\tilde{\mathbf{\boldsymbol{r}}}
. We are lead to minimize
\left|\mathbf{\boldsymbol{w}}\right|^{2}
under the constraint
\mathbf{\boldsymbol{\mathfrak{a}}}\cdot\mathbf{\boldsymbol{w}}=\mathfrak{b}
. We write

\mathcal{L}(\lambda,\mathbf{\boldsymbol{w}})=\left|\mathbf{\boldsymbol{w}}\right|^{2}+\lambda\left(\mathbf{\boldsymbol{\mathfrak{a}}}\cdot\mathbf{\boldsymbol{w}}-\mathfrak{b}\right),

(92)

where
\lambda
is a Lagrange multiplier. The gradient of
\mathcal{L}
vanishes when
\mathbf{\boldsymbol{w}}=\mathfrak{b}\mathbf{\boldsymbol{\mathfrak{a}}}/\mathfrak{a}^{2}
, and therefore we take

\delta\tilde{\mathbf{\boldsymbol{r}}}=\frac{m_{1}m_{2}}{M}\mathbf{\boldsymbol{r}}_{2}\cdot\left(\Delta\mathbf{\boldsymbol{v}}\times\Delta\mathbf{\boldsymbol{r}}\right)\frac{\mathbf{\boldsymbol{G}}}{G^{2}}.

(93)

\mathbf{\boldsymbol{a}}\times\mathbf{\boldsymbol{w}}=\mathbf{\boldsymbol{b}}
with unknown
\mathbf{\boldsymbol{w}}=\tilde{\mathbf{\boldsymbol{v}}}
. Since
\mathbf{\boldsymbol{a}}\cdot\mathbf{\boldsymbol{b}}=0
, this equation has solutions given by

This comes from
\mathbf{\boldsymbol{a}}\times\left(\mathbf{\boldsymbol{b}}\times\mathbf{\boldsymbol{a}}\right)=a^{2}\mathbf{\boldsymbol{b}}-\left(\mathbf{\boldsymbol{a}}\cdot\mathbf{\boldsymbol{b}}\right)\mathbf{\boldsymbol{a}}
.

\mathbf{\boldsymbol{w}}=\left(\mathbf{\boldsymbol{b}}\times\mathbf{\boldsymbol{a}}\right)/a^{2}+\alpha\mathbf{\boldsymbol{a}}
for any
\alpha\in\mathbb{R}
. Therefore, we take

\tilde{\mathbf{\boldsymbol{v}}}=\frac{1}{M\tilde{r}^{2}}\mathbf{\boldsymbol{G}}\times\tilde{\mathbf{\boldsymbol{r}}}+\alpha\tilde{\mathbf{\boldsymbol{r}}},

(94)

where we choose the real number
\alpha
in order to minimize
\left|\tilde{\mathbf{\boldsymbol{v}}}-\mathbf{\boldsymbol{v}}_{\text{cm}}\right|
. We have

\left|\tilde{\mathbf{\boldsymbol{v}}}-\mathbf{\boldsymbol{v}}_{\text{cm}}\right|^{2}=\alpha^{2}\tilde{r}^{2}-2\alpha\tilde{\mathbf{\boldsymbol{r}}}\cdot\mathbf{\boldsymbol{v}}_{\text{cm}}+K,

(95)

where
K
does not depend on
\alpha
, and the minimal value of

. Finally, we achieve the conservation of the total angular momentum by giving to the unique moonlet resulting from the merger the position and velocity

(96)

D.2
Case of a fragmentation

If the collision results in a full fragmentation (
\tilde{m}_{2}\geq m^{(0)}
), then the conservation of the total angular momentum reads

\mathbf{\boldsymbol{G}}=\tilde{m}\tilde{\mathbf{\boldsymbol{r}}}\times\tilde{\mathbf{\boldsymbol{v}}}+\tilde{m}_{2}\sum_{k=1}^{\tilde{N}}\left(\tilde{\mathbf{\boldsymbol{r}}}+\tilde{\mathbf{\boldsymbol{r}}}_{k}^{\prime}\right)\times\left(\tilde{\mathbf{\boldsymbol{v}}}+\tilde{\mathbf{\boldsymbol{v}}}_{k}^{\prime}\right).

(97)

In the case of a partial fragmentation (
\tilde{m}_{2}<m^{(0)}\leq\check{m}
), the tail is reunited into a single moonlet and the sum in Eq. (
97
) has only one term. We define

For a partial fragmentation, the sums are reduced to one term and

\begin{split}&\tilde{\mathbf{\boldsymbol{g}}}=\tilde{m}_{2}\sum_{k=1}^{\tilde{N}}\tilde{\mathbf{\boldsymbol{r}}}_{k}^{\prime}\times\tilde{\mathbf{\boldsymbol{v}}}_{k}^{\prime},\\

(98)

and Eq. (

\mathbf{\boldsymbol{G}}=M\tilde{\mathbf{\boldsymbol{r}}}\times\tilde{\mathbf{\boldsymbol{v}}}+\tilde{\mathbf{\boldsymbol{r}}}\times\tilde{\mathbf{\boldsymbol{u}}}+\tilde{\mathbf{\boldsymbol{s}}}\times\tilde{\mathbf{\boldsymbol{v}}}+\tilde{\mathbf{\boldsymbol{g}}},

\tilde{\mathbf{\boldsymbol{r}}}

\tilde{\mathbf{\boldsymbol{v}}}

Equation (

\mathbf{\boldsymbol{a}}\cdot\mathbf{\boldsymbol{b}}=0

with the equation

\tilde{\mathbf{\boldsymbol{v}}}
from Eq. (

\tilde{\mathbf{\boldsymbol{r}}}
and
\tilde{\mathbf{\boldsymbol{v}}}

\begin{split}&\tilde{m}\tilde{\mathbf{\boldsymbol{r}}}+\tilde{m}_{2}\sum_{k=1}^{\tilde{N}}\left(\tilde{\mathbf{\boldsymbol{r}}}+\tilde{\mathbf{\boldsymbol{r}}}_{k}^{\prime}\right)=M\tilde{\mathbf{\boldsymbol{r}}}+\tilde{\mathbf{\boldsymbol{s}}}=M\mathbf{\boldsymbol{r}}_{\text{cm}},\\

(101)

In order to determine
\tilde{\mathbf{\boldsymbol{r}}}
, we thus write
M\tilde{\mathbf{\boldsymbol{r}}}+\tilde{\mathbf{\boldsymbol{s}}}=M\left(\mathbf{\boldsymbol{r}}_{\text{cm}}+\delta\tilde{\mathbf{\boldsymbol{r}}}\right)
and we choose the smallest
\delta\tilde{\mathbf{\boldsymbol{r}}}
that verifies
\mathbf{\boldsymbol{a}}\cdot\mathbf{\boldsymbol{b}}=0

\begin{split}\mathbf{\boldsymbol{a}}\cdot\mathbf{\boldsymbol{b}}&=\left(M\tilde{\mathbf{\boldsymbol{r}}}+\tilde{\mathbf{\boldsymbol{s}}}\right)\cdot\left(\mathbf{\boldsymbol{G}}-\tilde{\mathbf{\boldsymbol{g}}}\right)+\tilde{\mathbf{\boldsymbol{r}}}\cdot\left(\tilde{\mathbf{\boldsymbol{s}}}\times\tilde{\mathbf{\boldsymbol{u}}}\right)\\
&=\left(\mathbf{\boldsymbol{r}}_{\text{cm}}+\delta\tilde{\mathbf{\boldsymbol{r}}}\right)\cdot\left(M\mathbf{\boldsymbol{G}}-M\tilde{\mathbf{\boldsymbol{g}}}+\tilde{\mathbf{\boldsymbol{s}}}\times\tilde{\mathbf{\boldsymbol{u}}}\right)=0.\end{split}

(102)

We are left to minimize
\left|\delta\tilde{\mathbf{\boldsymbol{r}}}\right|
under a constraint of the form
\mathbf{\boldsymbol{\mathfrak{a}}}\cdot\delta\tilde{\mathbf{\boldsymbol{r}}}=\mathfrak{b}
. This was already done in the merger case with the theory of Lagrange multiplier and we have

\begin{split}&\delta\tilde{\mathbf{\boldsymbol{r}}}=\frac{\mathfrak{b}\mathbf{\boldsymbol{\mathfrak{a}}}}{\mathfrak{a}^{2}}=-\frac{\left(\mathbf{\boldsymbol{r}}_{\text{cm}}\cdot\mathbf{\boldsymbol{\mathfrak{a}}}\right)\mathbf{\boldsymbol{\mathfrak{a}}}}{\mathfrak{a}^{2}},\quad\text{where}\\
&\mathbf{\boldsymbol{\mathfrak{a}}}=M\left(\mathbf{\boldsymbol{G}}-\tilde{\mathbf{\boldsymbol{g}}}\right)+\tilde{\mathbf{\boldsymbol{s}}}\times\tilde{\mathbf{\boldsymbol{u}}}.\end{split}

(103)

Now that
\tilde{\mathbf{\boldsymbol{r}}}
is known, we can obtain
\tilde{\mathbf{\boldsymbol{v}}}
from Eq. (
100
). The solutions of Eq. (
100
) are given by
28

\tilde{\mathbf{\boldsymbol{v}}}=\frac{\mathbf{\boldsymbol{b}}\times\mathbf{\boldsymbol{a}}}{a^{2}}+\alpha\mathbf{\boldsymbol{a}},

(104)

where
\alpha\in\mathbb{R}
. We choose for the real number
\alpha
the value that is closest from preserving the total momentum, that is, we choose the value of
\alpha
that minimizes
\left|M\left(\tilde{\mathbf{\boldsymbol{v}}}-\mathbf{\boldsymbol{v}}_{\text{cm}}\right)+\tilde{\mathbf{\boldsymbol{u}}}\right|

\begin{split}&\frac{1}{M^{2}}\left|M\left(\tilde{\mathbf{\boldsymbol{v}}}-\mathbf{\boldsymbol{v}}_{\text{cm}}\right)+\tilde{\mathbf{\boldsymbol{u}}}\right|^{2}\\
=\;&a^{2}\alpha^{2}-2\alpha\left(\mathbf{\boldsymbol{v}}_{\text{cm}}-\frac{\tilde{\mathbf{\boldsymbol{u}}}}{M}\right)\cdot\mathbf{\boldsymbol{a}}+K,\end{split}

(105)

where
K
does not depend on
\alpha
and therefore, we choose

\alpha=\frac{\left(\mathbf{\boldsymbol{v}}_{\text{cm}}-\tilde{\mathbf{\boldsymbol{u}}}/M\right)\cdot\mathbf{\boldsymbol{a}}}{a^{2}}.

(106)

We uniquely determined
\tilde{\mathbf{\boldsymbol{r}}}
and
\tilde{\mathbf{\boldsymbol{v}}}
in such a way that the total angular momentum is conserved upon impact up to machine precision, whether the collision results in a merger or in a fragmentation.
