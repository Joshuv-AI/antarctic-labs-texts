Recurrent Memory Decision Transformer
Arkadii Bessonov, Alexey Staroverov, Huzhenyu Zhang, Alexey K. Kovalev, Dmitry Yudin, Aleksandr I. Panov

Abstract
Originally developed for natural language problems, transformer models have recently been widely used in offline reinforcement learning tasks. This is because the agent’s history can be represented as a sequence, and the whole task can be reduced to the sequence modeling task. However, the quadratic complexity of the transformer operation limits the potential increase in context. Therefore, different versions of the memory mechanism are used to work with long sequences in a natural language. This paper proposes the Recurrent Memory Decision Transformer (RMDT), a model that uses a recurrent memory mechanism for reinforcement learning problems. We conduct thorough experiments on Atari games and MuJoCo control problems and show that our proposed model is significantly superior to its counterparts without the recurrent memory mechanism on Atari games. We also carefully study the effect of memory on the performance of the proposed model. These findings shed light on the potential of incorporating recurrent memory mechanisms to improve the performance of large-scale transformer models in offline reinforcement learning tasks. The Recurrent Memory Decision Transformer code is publicly available in the repository https://anonymous.4open.science/r/RMDT-4FE4 .

Introduction

Learning long-term dependencies is a critical requirement in numerous applications. In natural language processing (NLP), the ability to analyze and generate large textual content while preserving the long contextual information of user prompts in chatbots has received considerable attention. Originally developed for NLP, transformers have proven to be a valuable component in reinforcement learning (RL) and decision making
[
23
,
26
]
. There is significant progress in developing transformer neural network models for decision-making by intelligent agents in various games, simulations, and real-world environments. One of the directions in this area is to apply pre-trained large language models
[
38
]
and simultaneously solve many practical problems on multimodal data
[
36
]
. Another direction is the improvement of specialized neural network models working with action sequences, e.g., Decision Transformer
[
23
]
, VIMA
[
32
]
. Several works explore memory mechanisms to improve the efficiency of solving natural language processing problems, such as Transformer-XL
[
8
]
, and RMT
[
31
]
, which allow taking into account a long context for the formation of the model prediction. It is evident that tasks involving robotics, such as self-driving cars and manipulator-related activities, require a similar long context understanding as observed in NLP. Consequently, this realization has motivated us to extend and investigate NLP methods
[
8
,
31
]
in the domain of RL tasks where contextual information plays a central role.

Since the publication of the Decision Transformer paper
[
23
]
, several successful and promising outcomes have been reported
[
34
,
33
,
39
]
. These discoveries have catalyzed our exploration and improvement of transformer architectures in RL tasks. Although the incorporation of memory is rational in scenarios where agents operate in simulated environments, it remains unclear whether the agents effectively use this memory in an intended manner. We have adopted an approach using recurrent memory tokens described in the RMT paper
[
31
]
to address this issue. While this approach provides simplicity and flexibility for downstream RL tasks, it requires a slightly more complicated training procedure.

This paper introduces the Recurrent Memory Decision Transformer (RMDT), a model that uses a recurrent memory mechanism for RL tasks. We elucidate the training and evaluation processes for such models. Furthermore, we empirically demonstrate that these tokens effectively retain information from previous contexts, allowing the model to use past information when making decisions in the present. We conduct thorough experiments on Atari games and MuJoCo control problems, showing that our proposed model is significantly superior to its counterparts without the recurrent memory mechanism. We also carefully study the effect of memory on the performance of the proposed model. These results provide a compelling rationale for considering the proposed approach as valuable for downstream applications characterized by complex data structures. In addition, they motivate further exploration of alternative strategies for integrating memory into transformers for RL.

Background

Offline Reinforcement Learning.
In reinforcement learning
[
7
]
, we assume that the task can be described by a Markov decision process as a tuple
(S,A,P,R)
. The process consists of states
s\in S
, actions
a\in A
, a state transition function
P(s^{\prime}|s,a)
, and an immediate reward function
r=R(s,a)
. Given a timestep
t
, we use
r_{t}=R(s_{t},a_{t})
to denote the immediate reward that the agent receives at state
s_{t}
performing action
a_{t}
at that timestep. We describe trajectory
\tau
of length
T
as a sequence of states
s_{i}
, actions
a_{i}
, and immediate rewards
r_{i}
:
\tau=(s_{0},a_{0},r_{0},s_{1},a_{1},r_{1},\dots,s_{T},a_{T},r_{T})
. We denote return
R_{t}
of trajectory
\tau
at the timestep
t
as a sum of future rewards from he timestep
t
to the end of trajectory:
R_{t}=\sum^{T}_{t^{\prime}=t}r_{t^{\prime}}
. The goal of a reinforcement learning agent is to learn policy
\pi
that maximizes the expected return. In online reinforcement learning, the trajectories used to train an agent are obtained iteratively during the interaction between the agent and the environment. In offline reinforcement learning, the agent does not interact with the environment during training. A fixed set of trajectories collected by an arbitrary policy is used to train the policy. Although such a setting is more difficult because it does not allow additional exploration of the environment or generation of new trajectories, it is preferable for tasks where interaction with the environment is costly or risky, such as in robotics.

Transformers.
Transformers
[
6
]
were originally proposed to solve natural language processing tasks and developed the idea of an attention mechanism
[
2
]
. Generally, the model is a stack of self-attention layers with residual connections
[
4
]
. Each layer receives embedding tokens
x_{i}
as input and outputs the same number of tokens
z_{i}
while maintaining the dimension of the tokens themselves.
The
i
-th input token
x_{i}
is mapped via linear transformations to a key
k_{i}
, value
v_{i}
, and query
q_{i}
embeddings. The
i
-th output embedding
z_{i}
of the self-attention layer is obtained as a weighted sum of
v_{j}
embeddings. The weights are the normalized dot products between the query
q_{i}
and other keys
k_{j}
embedding:

z_{i}=\sum^{n}_{j=1}softmax(\{\langle q_{i},k_{j^{\prime}}\}\rangle\}^{n}_{j^{\prime}=1})_{j}\cdot v_{j}.

(1)

This mechanism allows the layer to consider only tokens from the required positions when generating the output token
z_{i}
.

4
Recurrent Memory Decision Transformer

We used the methodology outlined in the Decision Transformer (DT) paper to represent the modeled trajectory. In our Recurrent Memory Decision Transformer (RMDT) approach, we employed both recurrently trained memory tokens and the preservation of previous hidden states, as elucidated in the Transformer-XL paper. We predict actions in an autoregressive manner. The memory vectors, which have undergone training, can be positioned either solely at the beginning of the sequence or at both the beginning and end. Empirical findings indicate that using memory tokens on both sides leads to enhanced performance.

The architecture of RMDT is depicted in
Figure 2
. The trajectory is represented as a sequence of triplets
(R,O,A)
, where R denotes the target reward,
O
represents the observation, and
A
signifies the action. Each component is encoded using the appropriate encoder. The linear projection was utilized for encoding
R
and
A
, while for Atari states, a two-layer CNN was employed, and for MuJoCo states, a linear projection layer was used. The memory embeddings, which are model parameters, are inserted at the beginning and end of the first segment in the input sequence. This embedded sequence serves as the input for the transformer. The resulting embeddings, obtained in the transformer’s output, correspond to observation vectors that are further employed with linear projection to predict the agent’s action in the respective frame. The resulting input sequence for the model is also shown in
Figure 2
at the bottom. Memory embedding is a subsequence of
M
vectors, where
M
is a hyperparameter. These memory-embedding subsequences are the same at the beginning and the end of the sequence in the current segment.

During training, we used the teacher forcing procedure with
N
segments, each consisting of
K
context frames. This entails randomly sampling a uniform subsequence of length
NK
frames from the initial training sequence as shown in
Figure 3
. Subsequently, the model is trained on each
NK
full segment in
N
steps. We initialize the memory subsequence with trainable memory vectors. Following a forward pass, we retrieve a new subsequence from the end of the memory subsequence, which is then used for padding in the next subsequence segment. To avoid computational instability, we detach the new memory subsequence. However, the gradient from the next segment can flow to the previous segment through this memory subsequence. The entire training procedure is illustrated in
Figure 4
. We used lower triangular attention masks to attend to tokens within the trajectory sequence. In the case of memory segments, a full attention mask was utilized. Subsequent segments entail updating the memory vectors based on the extracted representations of the suffix memory vectors at the top layer of the transformer.

Figure 3:
Formation of segments during RMDT training.

Figure 4:
The training procedure of the Recurrent Memory Decision Transformer (RMDT)

To train these memory vectors effectively, modifying the standard DT training procedure is essential. The subsequent context segment must leverage the information stored in the memory segment of the input sequence from the preceding context. This allows us to regulate the overall length of the context available to the model during the inference phase by manipulating the number of sections employed during training. While environments with relatively simplistic dynamics, such as Atari and MuJoCo, do not necessitate exceedingly protracted contexts, our experiments demonstrate a saturation in agent reward with a moderate number of sections employed (around five). However, in real-world applications, a greater number of sections may confer greater value, as evidenced by the ability of memory tokens to retain significant information across segments.
At the same time, while the DT paper ascertained a saturation point in model performance when the context length reached a 30-frame history, our investigations indicate that the incorporation of memory facilitates improved agent performance when the extension of the history length is up to 150 frames via the application of memory vectors and segment training (
section 6
).

Environments

The training dataset employed was identical to that of DT, namely the DQN replay dataset with grayscale state images

Due to limited computation resources, we used four different Atari environments – Seaquest, Qbert, Breakout, and Pong.

As for the continuous control tasks, we take a standard MuJoCo locomotion environment (HalfCheetah,

[

– 1 million timesteps generated by a “medium” policy that achieves approximately

– the replay buffer of an agent trained to the performance of a medium policy (approximately 200k-400k timesteps in our environments); 3)

– 1 million timesteps generated by the medium policy concatenated with 1 million timesteps generated by an expert policy.

6
Ablation Study

In this section, we examine how the various memory hyperparameters of our model affect its performance. We conducted experiments on the same Atari environments as the main results. We used the same evaluation protocol: we reported non-normalized averaged scores for three model runs, with ten trajectories in each run.

Number of segments.
We first looked at the effect of the number of segments used in RMDT (
Figure 5
). Increasing the number of segments from one to three leads to a significant increase for all Atari environments except Pong. However, increasing the number further does not lead to significant changes and even worse results on Seaquest. Thus, our findings indicate that using three segments, corresponding to a context of 90 frames, is sufficient for the environments considered. We, therefore, use three segments as the default configuration in our experimental results.

Figure 5:
RMDT results for Atari environments depending on the number of segments.

While the performance of DT plateaus at approximately 30 frames of context (see supplementary materials in
[
23
]
), RMDT shows improved results by extending the effective context to 150 frames in three out of four environments (
Figure 5
). It should be noted, however, that this effect only manifests itself when scaling the number of segments (i.e., using memory tokens for a larger number of segments). Simply scaling the context length without a concomitant increase in the observed number of segments in a given sequence (and thus the length of the subsequences where memory is used) does not yield a corresponding improvement.

Memory size.
Next, we examined how the number of memory embeddings affects model performance (
Figure 6
). We have experimented with 1, 15, and 30 memory embeddings and found that increasing the length of the memory subsequence did not improve the results for three out of four environments. This observation may be due to the use of relatively simple environments where a small context window is sufficient. In such scenarios, it is more important to use memory efficiently and ensure adequate segments rather than focusing solely on increasing the memory subsequence length. We used 15 memory embeddings for the main experiments based on these results.

Figure 6:
RMDT results for Atari environments depending on the number of memory embeddings.

Use of memory tokens.
We also investigated whether the presence of memory tokens affects the results or whether it is sufficient to increase the context used for prediction simply. To do this, we trained the model with the same parameters and methodology as the RMDT, the only difference being the absence of memory tokens. We designated this model as DT-XL and report its results in the
Table 1
. In the absence of memory tokens within the segment training procedure, we observed a decrease in agent performance. This is evidence that using memory tokens improves the results of the proposed model.

Overlay of segments.
In dynamic environments such as MuJoCo, it is important for the trajectory to be smooth and consistent. If we were to start forming each new segment from the beginning with only previous memory tokens, the model could behave differently at the start compared to the end of the last segment, potentially leading to failure. Memory tokens may not help in this situation because they tend to store global information about the environment rather than local context. Our solution is to take a few steps from the end of the previous segment and use them to start forming the new segment, resulting in an overlap between the previous and current segments. To deal with token memory updates, we ablate their fixation after the first segment. Our MuJoCo experiments show that this benefits performance significantly. It should be noted that our Atari experiments show no dependence on these parameter changes.

Memory survey

Previous studies have highlighted incorporating memory segments’ effectiveness in improving agent performance. This section provides empirical evidence to support the claim that memory subsequences effectively capture contextual information from preceding segments. To illustrate this, we present a visual representation as an attention map for a representative segment. Notably, this attention map shows a consistent pattern across multiple heads and layers. An interesting observation is that including 15 memory vectors at the beginning and end of each segment sequence results in discernible patterns in the left and bottom regions distinct from the central square.

For a more detailed visualization, we present the distinct regions individually in
Figure 7
. The attention patterns depicted strikingly demonstrate the model’s recurrent use of memory subsequences for frame-by-frame action prediction. This is evident from the prominent bright stripes aligning with state embeddings within the input sequence (although some memory vectors rely predominantly on previous actions). This observation further supports that the model effectively leverages the information stored within the corresponding memory segment. Furthermore, when constructing a new memory subsequence for the subsequent context segment, the model considers the entire state sequence, including the existing memory segments. This is indicated by the presence of radiant and frequent stripes in the figure.

In
Figure 7
(b), we show the attention map of the write-memory subsequence for each layer within a single segment, revealing a consistent pattern across different segments. Notably, it becomes evident that during the memory update process for the subsequent segment, the model successfully exploits information originating from both the current segment and the read-memory subsequence.

Moreover, as depicted in
Figure 8
, we provide evidence that the model consistently incorporates the read-memory subsequence throughout various layers for each segment. This observation substantiates the compelling hypothesis that the memory effectively encodes information from preceding segments, thereby preserving it for use in subsequent segments. The attention map presented in this analysis corresponds to a randomly selected attention head, although it is important to note that similar patterns were observed across multiple heads.
We provide examples of attention maps for the MuJoCo environment in
Appendix B
.

8
Conclusion

In this paper, we propose the Recurrent Memory Decision Transformer (RMDT), an autoregressive transformer model for offline reinforcement learning problems that exploit the mechanisms of recurrent memory. In extensive experiments on Atari and MuJoCo environments, we have shown that our proposed model significantly outperforms the models without recurrent memory, such as DT, Transformer-XL, and TAP. We have considered the aspects of memory embedding formation in detail and have shown their interpretability using attention maps. The proposed approach is promising for further research in problems with long sequences, including robotic environments, where training intelligent agents on pre-collected data is advisable.

Limitations.
The proposed Recurrent Memory Decision Transformer is limited for application when modeling short sequences, i.e., when all the data can be accommodated within a single segment. In such cases, the efficiency of the memory mechanism is limited because we don’t need to store long dependencies and since we can use a common transformer.

In order to substantiate our findings, we have made the code of Recurrent Memory Decision Transformer publicly available in the repository
https://anonymous.4open.science/r/RMDT-4FE4
.
The code includes both the model implementation and the code used to run the experiments.

Appendix B

While the main body of the paper primarily presented results obtained from the Atari environment, we now extend the same analysis to the MuJoCo environment, thereby providing comprehensive findings across both domains.
