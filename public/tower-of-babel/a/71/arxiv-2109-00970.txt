Construction of Inter-Group Complementary Code Set and 2-D Z-Complementary Array Code Set Based on Multivariable Functions
Abhishek Roy, and Sudhan Majhi

Abstract
The need of two dimensional (2-D) arrays with good 2-D correlation properties have been found of great interest in research because of the rapid development of the modern technologies in the field of wireless communications. 2-D arrays have found various applications wireless communication technologies such as ultra-wide band (UWB), 2-D synchronization, phased array antenna etc. In this paper, we propose a direct construction of 2-D Z-complementary array code set (ZCACS) by using multivariable function. For this purpose, we first proposed a construction of inter-group complementary (IGC) code set using multivariable function and use this construction to produce our desired 2-D ZCACS. The use of multivariable function enables us to set the size of the 2-D ZCACS to be L 1 × L 2 L_{1}\times L_{2} , where L 1 = 2 m L_{1}=2^{m} , L 2 = 2 ​ p 1 m 1 ​ p 2 m 2 ​ … ​ p k m k L_{2}=2p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}} , m ≥ 1 m\geq 1 and m α ≥ 2 m_{\alpha}\geq 2 for all α = 1 , 2 , … , k \alpha=1,2,\dots,k , which is an improvement over the traditional generalized Boolean function that produces sequences of length of the form 2 m 2^{m} .

Introduction

In the field of sequence design, the introduction of Golay complementary pair (GCP) by Marcel J. E. Golay in 1951 marks a milestone
[
1
]
. It is a pair of sequences whose aperiodic auto-correlation sum (AACS) is zero for all time shifts except the zero shift. Due to its ideal auto-correlation properties, it has been widely used in wireless communication engineering such as reducing the peak-to-mean envelope power ratio (PMEPR) of orthogonal frequency division multiplexing (OFDM)
[
2
,
3
,
4
]
, channel estimation
[
5
]
, radar
[
6
]
etc. In 1972, Tseng and Liu in
[
7
]
extended the concept of GCP to complementary set (CS), which refers to a set of sequences of same lengths having zero AACS for all non-zero time shifts. Although there are many constructions of CSs in the literature, the first direct construction was given by Paterson
[
8
]
by using generalized Boolean function (GBF). Later, CS was extended to the concept of mutually orthogonal Golay complementary set (MOGCS) which is a collection of multiple CSs with the property that aperiodic cross-correlation sum (ACCS) of the CSs is zero for all shifts. Complete complementary code (CCC) is the special case of MOGCS when the set size achieves its upper bound and it was introduced by Suehiro and Hatori in
[
9
]
. In the literature, there are many constructions of CCCs
[
10
,
11
,
12
,
13
,
14
,
15
,
16
]
.

There has been some drawbacks in CCCs regarding the set size, which is bounded by the number of sequences in each constituting CS. To ovecome this drawbak, later the concept of the Z-complementary code set (ZCCS) was introduced. A ZCCS consists of codes which display zero ACCS wihin a range around the zero shift, which is called the zero-correlation zone (ZCZ). Several direct and indirect constructions of ZCCS can be found in the literature
[
17
,
18
,
19
,
20
]
using GBF method or other recursive tools. A special case of ZCCS is inter-group complementary (IGC) code set where the codes are divided into some groups and ACCS of codes from two different groups is zero for all time shifts and within the same group it follows ZCCS properties. Several constructions of IGC code sets can be found in the literture
[
21
,
22
,
23
]
.

The discussed above are known as one dimensional (1-D) sequences. However, these 1-D sequences can be generealized to two-dimensional (2-D) arrays. The 1-D GCP can be extended to 2-D and called 2-D Golay complementary array pair (GCAP). Some constructions of 2-D GCAP are provided in
[
24
,
25
,
26
]
. Similarly 2-D MOGCS is a generalization of 1-D MOGCS. It was first introduced by Lüke in 1985
[
27

[
28
]
. When the set size of a 2-D MOGCS is equal to the number of constituent arrays, then it is called 2-D CCC
[
29
]
. Till date many constructions of 2-D MOGCS have appered in the literature
[
30
,
31
,
32
]
.

As the set size is limited in 2-D MOGCS, the 2-D generalization of 1-D ZCCS is introduced by Xeng
et al.
in 2004, called 2-D Z-complementary array code set (ZCACS)
[
33
]
. The applications of 2-D ZCACS include the high bandwidth spectral efficient implementaion of UWB MC-CDMA in one dimension and reduction of PMEPR in other dimension, multiple access system etc.

There has been some construction of 2-D ZCACS in the literature. Recently, Das
et al.

[
34
]
proposed a construction of 2-D ZCACS by using 2-D Z-paraunitary (ZPU) matrices. But the construnctions in the literature including this does not follow a direct appraoch. Motivated by this, we have developed a direct construction method of 2-D ZCACS by using multivariable funcions. Recenty, the concept of multivariable functions is introduced by Sarkar
et al.
in
[
16
]
.

Motivated by this, in this paper, we propose a construction of IGC code set of length of the form
p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}

p_{\alpha}
’s are prime numbers and

II
Preliminaries

II-A

One dimensional sequences

Definition 1
(ACCF (
[
19
]
))

For two complex-valued sequences
\mathbf{a}=(a_{0},a_{1},\dots,a_{L_{1}})
and
\mathbf{b}=(b_{0},b_{1},\dots,b_{L_{1}})
of length
L
, the ACCF at the time shift
\tau
is defined by

C(\mathbf{a},\mathbf{b})(\tau)=\begin{cases}\sum\limits_{i=0}^{L-\tau-1}a_{i}b_{i+\tau}^{*},&0\leq\tau<L;\\
\sum\limits_{i=0}^{L+\tau-1}a_{i-\tau}b_{i}^{*},&-L<\tau\leq-1;\\
0,&\mid\tau\mid\geq L,\end{cases}

(1)

where
(\cdot)^{*}
denotes the complex conjugate. If
\mathbf{a}=\mathbf{b}
, then the function is called AACF and is denoted by
A(\mathbf{a})(\tau)
.

Definition 2
(ZCP
[
19
]
)

A pair of length-
L
sequences
(\mathbf{a},\mathbf{b})
is called a ZCP if they satisfy the following:

A(\mathbf{a})(\tau)+A(\mathbf{b})(\tau)=0~~\text{for}~~0<\mid\tau\mid<Z,

(2)

where
Z\leq L
. Here
Z
is called the ZCZ width. If
Z=L
, then
(\mathbf{a},\mathbf{b})
is called a GCP.

Definition 3
(Code (
[
18
]
))

An ordered set of sequences
\{\mathbf{a}_{0},\mathbf{a}_{1},\dots,\mathbf{a}_{M-1}\}
of same length
L
, is called a code. A code can be written in matrix form as follows:

\mathcal{C}=\begin{bmatrix}\mathbf{a}_{0}\\[2.0pt]
\mathbf{a}_{1}\\
\vdots\\
\mathbf{a}_{M-1}\end{bmatrix}_{M\times L}

(3)

Definition 4
(ACCF of code (
[
18
]
))

Let
\mathcal{C}_{1}=\{\mathbf{a}_{0}^{1},\mathbf{a}_{1}^{1},\dots,\mathbf{a}_{M-1}^{1}\}
,
\mathcal{C}_{2}=\{\mathbf{a}_{0}^{2},\mathbf{a}_{1}^{2},\dots,\mathbf{a}_{M-1}^{2}\}
be two
M\times L
matrices or codes, then ACCF of
\mathcal{C}_{1}
and
\mathcal{C}_{2}
is defined by

C(\mathcal{C}_{1},\mathcal{C}_{2})(\tau)=\displaystyle\sum_{\lambda=0}^{M-1}C(\mathbf{a}_{\lambda}^{1},\mathbf{a}_{\lambda}^{2})(\tau).

(4)

Definition 5
(MOGCS(
[
11
]
))

A collection
\mathcal{C}=\{\mathcal{C}_{0},\mathcal{C}_{1},\cdots,\mathcal{C}_{K-1}\}
of codes is called MOGCS if it satisfies

C(\mathcal{C}_{\nu_{1}},\mathcal{C}_{\nu_{2}})(\tau)=\begin{cases}ML,&\tau=0,\quad\nu_{1}=\nu_{2};\\
0,&0<|\tau|<L,\quad\nu_{1}=\nu_{2};\\
0,&|\tau|<L,\quad\nu_{1}\neq\nu_{2}.\end{cases}

(5)

When
K=M
, then
\mathcal{C}
is called CCC.

Definition 6
(ZCCS (
[
18
]
))

A collection
\mathcal{C}=\{\mathcal{C}_{0},\mathcal{C}_{1},\cdots,\mathcal{C}_{K-1}\}
is called ZCCS if it satisfies

C(\mathcal{C}_{\nu_{1}},\mathcal{C}_{\nu_{2}})(\tau)=\begin{cases}ML,&\tau=0,\quad\nu_{1}=\nu_{2};\\
0,&0<|\tau|<Z,\quad\nu_{1}=\nu_{2};\\
0,&|\tau|<Z,\quad\nu_{1}\neq\nu_{2},\end{cases}

(6)

where
Z\leq L
. Here,
Z
is called the ZCZ width. It is detnoted by
(K,Z)
-
\text{ZCCS}_{M}^{L}
.

Lemma 1
(
[
18
]
)

For any
(K,Z)
-
\text{ZCCS}_{M}^{L}
, the following inequality holds

K\leq M\left\lfloor\frac{L}{Z}\right\rfloor,

(7)

where
\left\lfloor\cdot\right\rfloor
is the floor function. If equality holds, then the ZCCS is said to be an optimal.

Definition 7
(IGC code set (
[
21
]
))

Let
I(K,M,L,Z)=\{\mathcal{C}^{i}:i=0,1,\dots,K-1\}
be an optimal
(K,Z)
-
\text{ZCCS}_{M}^{L}
.
Then, it follows the bound
K=M\left\lfloor L/Z\right\rfloor
. Let also be that the
K
codes can be divided into
M
number of code groups
I^{g}(g=0,1,\dots,M-1)
. Each group contains
K/M=\left\lfloor L/Z\right\rfloor
codes and the code set
I(K,M,L,Z)
follows the following properties:

C({\mathcal{C}^{i},\mathcal{C}^{j}})({\tau})=\begin{cases}ML,&i=j,\quad\tau=0,\\
0,&i=j,\quad 0<|\tau|<Z,\\
0,&i\neq j,\quad\mathcal{C}^{i},\mathcal{C}^{j}\in I^{g},~|\tau|<Z,\\
0,&\mathcal{C}^{i}\in I^{g_{1}},\quad\mathcal{C}^{j}\in I^{g_{2}},~g_{1}\neq g_{2},|\tau|<L.\end{cases}\\

(8)

Then, the code set
I(K,M,L,Z)
is called an IGC code set.

II-B

Two Dimensional Array

Definition 8
(2-D Array (
[
34
]
))

A 2-D array is a two dimensional matrix
\mathbf{X}
, an element denoted by
X_{i,j}
, where
0\leq i<L_{1}
,

0\leq j<L_{2}
and the size of the array is
L_{1}\times L_{2}
.

Definition 9
(2-D ACCF (
[
34
]
))

The 2-D ACCF of two arrays
\mathbf{X}
and
\mathbf{Y}
both of size
(L_{1},L_{2})
at time shift
(\tau_{1},\tau_{2})
is defined by

C(\mathbf{X},\mathbf{Y})(\tau_{1},\tau_{2})=\!\begin{cases}\sum\limits_{i=0}^{L_{1}-\tau_{1}-1}\sum\limits_{j=0}^{L_{2}-\tau_{2}-1}X_{i,j}Y^{*}_{i+\tau_{1},j+\tau_{2}},&\text{if}~0\leq\tau_{1}<L_{1},0\leq\tau_{2}<L_{2};\\
\sum\limits_{i=0}^{L_{1}+\tau_{1}-1}\sum\limits_{j=0}^{L_{2}-\tau_{2}-1}X_{i-\tau_{1},j}Y^{*}_{i,j+\tau_{2}},&\text{if}~-L_{1}<\tau_{1}\leq-1,0\leq\tau_{2}<L_{2};\\
\sum\limits_{i=0}^{L_{1}-\tau_{1}-1}\sum\limits_{j=0}^{L_{2}+\tau_{2}-1}X_{i,j-\tau_{2}}Y^{*}_{i+\tau_{1},j},&\text{if}~0\leq\tau_{1}\leq L_{1},-L_{2}<\tau_{2}\leq-1;\\
\sum\limits_{i=0}^{L_{1}+\tau_{1}-1}\sum\limits_{j=0}^{L_{2}+\tau_{2}-1}X_{i-\tau_{1},j-\tau_{2}}Y^{*}_{i,j},&\text{if}~-L_{1}\!\!<\!\tau_{1}\!\leq\!\!-1,-L_{2}\!\!<\!\tau_{2}\!\leq\!\!-1.\end{cases}

(9)

Here
(\cdot)^{*}
denotes the complex conjugate. When
\mathbf{X}=\mathbf{Y}
, then it is called 2-D AACF and is denoted by
A(\mathbf{X})(\tau_{1},\tau_{2})
.

Definition 10
(2-D ZCAC (
[
34
,
35
]
))

A set
\mathcal{X}=\{\mathbf{X}_{0},\mathbf{X}_{1},\dots,\mathbf{X}_{M-1}\}
of 2-D arrays with equal size
L_{1}\times L_{2}
is called a 2-D Z-complementary array code (ZCAC) if they satisfy:

\sum_{i=0}^{M-1}A(\mathbf{X}_{i})(\tau_{1},\tau_{2})=\begin{cases}ML_{1}L_{2},&(\tau_{1},\tau_{2})=(0,0);\\
0,&0\leq\mid\tau_{1}\mid<Z_{1},0\leq\mid\tau_{2}\mid<Z_{2},(\tau_{1},\tau_{2})\neq(0,0).\end{cases}

(10)

where
Z_{1}\leq L_{1}
,
Z_{2}\leq L_{2}
. When
M=2
, then it is called a 2-D Z-complementary array pair (ZCAP).

Definition 11
(2-D ZCACS (
[
34
]
))

A collection of 2-D ZCAC
\{\mathcal{X}_{0},\mathcal{X}_{1},\dots,\mathcal{X}_{K-1}\}
where
\mathcal{X}_{\lambda}=\{\mathbf{X}_{0}^{\lambda},\mathbf{X}_{1}^{\lambda},\dots,\mathbf{X}_{M-1}^{\lambda}\}
and
each
\mathbf{X}_{i}^{\lambda}
has equal size of
L_{1}\times L_{2}
, is called a 2-D ZCACS if they satisfy:

\sum_{i=0}^{M-1}C(\mathbf{X}_{i}^{\lambda_{1}},\mathbf{X}_{i}^{\lambda_{2}})(\tau_{1},\tau_{2})=\begin{cases}ML_{1}L_{2},&\lambda_{1}=\lambda_{2},(\tau_{1},\tau_{2})=(0,0);\\
0,&\lambda_{1}=\lambda_{2},0\leq\mid\tau_{1}\mid<Z_{1},0\leq\mid\tau_{2}\mid<Z_{2};(\tau_{1},\tau_{2})\neq(0,0);\\
0,&\lambda_{1}\neq\lambda_{2},\mid\tau_{1}\mid<Z_{1},\mid\tau_{2}\mid<Z_{2},\\
\end{cases}

(11)

where
Z_{1}\leq L_{1}
,
Z_{2}\leq L_{2}
.

II-C

Multivariable Function

A multivariable function can be defined as

f:\mathbb{Z}_{p_{1}}^{m_{1}}\times\mathbb{Z}_{p_{2}}^{m_{2}}\times\dots\times\mathbb{Z}_{p_{k}}^{m_{k}}\rightarrow\mathbb{Z}_{\lambda}

where
p_{1},p_{2},\dots,p_{k}
are prime numbers and
\lambda
is a positive integer. For ease of understanding we define the following notations

•

v_{p_{\alpha},1},v_{p_{\alpha},2},\dots,v_{p_{\alpha},m_{\alpha}}
are the
m_{\alpha}
variables which take values from
\mathbb{Z}_{p_{\alpha}}
for
\alpha=1,2\dots,k
.

•

u_{p_{\alpha},i_{\alpha}}
is the vector representation of
i_{\alpha}
with base
p_{\alpha}
, i.e.,
u_{p_{\alpha},i_{\alpha}}=(i_{\alpha,1},i_{\alpha,2},\dots,i_{\alpha,m_{\alpha}})
where
i_{\alpha}=\sum_{\gamma=1}^{m_{\alpha}}p_{\alpha}^{\gamma-1}i_{\alpha,\gamma}
.

•

The set
M^{r}
of monomials of degree at most
r
is given by

M^{r}=\left\{\prod_{\alpha=1}^{k}\prod_{\beta=1}^{m_{\alpha}}v_{p_{\alpha},\beta}^{j_{\beta}^{\alpha}}:0\leq\sum_{\alpha=1}^{k}\sum_{\beta=1}^{m_{\alpha}}j_{\beta}^{\alpha}\leq r\right\},

where
j_{\beta}^{\alpha}\in\{0,1,\dots,p_{\alpha}-1\}
and
0\leq r\leq\sum_{\alpha=1}^{k}m_{\alpha}
.

A multivariable function
f
is a linear combination of the monomials from the sets
M^{r}
with coefficients from
\mathbb{Z}_{\lambda}
. The order of the multi-varible function is the degree of the highest degree monomial which has non-zero co-efficient.

A multivariable function
f:\mathbb{Z}_{p_{1}}^{m_{1}}\times\mathbb{Z}_{p_{2}}^{m_{2}}\times\dots\times\mathbb{Z}_{p_{k}}^{m_{k}}\rightarrow\mathbb{Z}_{\lambda}
can be associated with a
\mathbb{Z}_{\lambda}
-valued sequence of length
p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}
. For this, we define the ordered set

\begin{split}U=\bigg((u_{p_{1},i_{1}},u_{p_{2},i_{2}},\dots,u_{p_{k},i_{k}}):i_{1}=0,1,\dots,p_{1}^{m_{1}}-1;&i_{2}=0,1,\dots,p_{2}^{m_{2}}-1;\dots;\\
&\qquad i_{k}=0,1,\dots,p_{k}^{m_{k}}-1\bigg).\end{split}

(12)

The
\mathbb{Z}_{\lambda}
-valued sequence corresponding to the multivariable function
f
is given by

\begin{split}\mathbf{f}=\bigg(f(u_{p_{1},i_{1}},u_{p_{2},i_{2}},\dots,u_{p_{k},i_{k}}):i_{1}=0,1,\dots,p_{1}^{m_{1}}-1;&i_{2}=0,1,\dots,p_{2}^{m_{2}}-1;\dots;\\
&\qquad i_{k}=0,1,\dots,p_{k}^{m_{k}}-1\bigg).\end{split}

(13)

One can also associate a complex-valued sequence corresponding to a multivariable function
f
, which is given by

\begin{split}\psi(\mathbf{f})=\bigg(\omega_{\lambda}^{f(u_{p_{1},i_{1}},u_{p_{2},i_{2}},\dots,u_{p_{k},i_{k}})}:i_{1}=0,1,\dots,p_{1}^{m_{1}}-1;&i_{2}=0,1,\dots,p_{2}^{m_{2}}-1;\dots;\\
&\qquad i_{k}=0,1,\dots,p_{k}^{m_{k}}-1\bigg),\end{split}

(14)

where
\omega_{\lambda}=\exp(\frac{2\pi\sqrt{-1}}{\lambda})
.

Remark 1

When
k=1
and
p_{1}=2
, then the multivariable function reduces to
f:\mathbb{Z}_{2}^{m}\rightarrow\mathbb{Z}_{\lambda}
which is the form of the generalized Boolean function (GBF). Hence, multivariable
function is the generalization of the GBF.

We further introduce some notations to produce 2-D matrices by using multivariable functions. Let
F_{\mathbf{d}}:\mathbb{Z}_{p_{1}}^{m_{1}}\times\mathbb{Z}_{p_{1}}^{m_{2}}\times\dots\times\mathbb{Z}_{p_{\alpha}}^{m_{\alpha}}\rightarrow\mathbb{Z}_{\lambda}
be a set of multivariable functions for
\mathbf{d}=(d_{p^{\prime}_{1}},d_{p^{\prime}_{2}},\dots,d_{p^{\prime}_{w}})\in\prod_{\alpha=1}^{w}\mathbb{Z}_{p^{\prime}_{\alpha}}
, where
p^{\prime}_{\alpha}
are some prime numbers. Let
K=\{F_{\mathbf{d}}:\mathbf{d}\in\prod_{\alpha=1}^{w}\mathbb{Z}_{p^{\prime}_{\alpha}}\}
be an ordered set, which can be written as a
\mathbb{Z}_{\lambda}
-valued matrix or array of size
L_{1}\times L_{2}
, where
L_{1}=p^{\prime}_{1}p^{\prime}_{2}\dots p^{\prime}_{w}
and
L_{2}=p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}
. The
i
-th row of
K
is determined by the multivariable function
F_{\vec{i}}
, where
\vec{i}
is the vector representation of
i
in
\mathbb{Z}_{p^{\prime}_{1}}\times\mathbb{Z}_{p^{\prime}_{2}}\times\dots\times\mathbb{Z}_{p^{\prime}_{w}}
. So, the
(i,j)
-th component of the matrix
K
is defined by
K_{i,j}=F_{\vec{i}}(\vec{j})
, where
\vec{j}
is the vector representation of
j
in
\prod_{\alpha=1}^{k}\mathbb{Z}_{p_{\alpha}}^{m_{\alpha}}
. We can also associate a complex-valued matrix
\Psi(K)
with
K
, where
\left(\Psi(K)\right)_{i,j}=\omega_{\lambda}^{K_{i,j}}
for all
i,j
.

III
Construction of IGC Code Set

In this section, a construction of IGC code set for lengths of the form
p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}
, (
m_{\alpha}\geq 2
, for all
\alpha
) is presented by using multivariable function. We take the multivariable functions

f_{\alpha}:\mathbb{Z}_{p_{\alpha}}^{m_{\alpha}-1}\rightarrow\mathbb{Z}_{\lambda},

for
\alpha=1,2,\dots,k
. Each
f_{\alpha}
is defined by

\begin{split}f_{\alpha}(v_{p_{\alpha},1},v_{p_{\alpha},2},\dots,v_{p_{\alpha},m_{\alpha}-1})=&\frac{\lambda}{p_{\alpha}}\sum_{\beta=1}^{m_{\alpha}-2}v_{p_{\alpha},\pi_{\alpha}(\beta)}v_{p_{\alpha},\pi_{\alpha}(\beta+1)}+\sum_{\beta=1}^{m_{\alpha}-1}c_{\alpha,\beta}v_{p_{\alpha},\beta}+c_{\alpha},\end{split}

(15)

where
c_{\alpha,\beta},c_{\alpha}\in\mathbb{Z}_{\lambda}
for
\beta=1,2,\dots,m_{\alpha}-1
;
m_{\alpha}\geq 2
for all
\alpha
,
\pi_{\alpha}
is a permutation of the set
\{1,2,\dots,m_{\alpha}-1\}
and
\lambda
is taken
in such a way that
p_{\alpha}\mid\lambda
for all
\alpha=1,2,\dots,k
.
Let the function
f:\mathbb{Z}_{p_{1}}^{m_{1}-1}\times\mathbb{Z}_{p_{2}}^{m_{2}-1}\times\dots\times\mathbb{Z}_{p_{k}}^{m_{k}-1}\rightarrow\mathbb{Z}_{\lambda}
be defined by

f=f_{1}+f_{2}+\dots+f_{k}.

(16)

Now, for
\mathbf{\gamma}=(\gamma_{1},\gamma_{2},\dots,\gamma_{k}),\mathbf{s}=(s_{1},s_{2},\dots,s_{k}),\mathbf{t}=(t_{1},t_{2},\dots,t_{k})\in\mathbb{Z}_{p_{1}}\times\mathbb{Z}_{p_{2}}\times\dots\times\mathbb{Z}_{p_{k}}
, we define the set of functions

a_{\mathbf{s},\mathbf{t}}^{\mathbf{\gamma}}:\mathbb{Z}_{p_{1}}^{m_{1}-1}\times\dots\times\mathbb{Z}_{p_{k}}^{m_{k}-1}\times\mathbb{Z}_{p_{1}}\times\dots\times\mathbb{Z}_{p_{k}}\rightarrow\mathbb{Z}_{\lambda},

given by

\begin{split}a_{\mathbf{s},\mathbf{t}}^{\mathbf{\gamma}}=&f+\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v_{p_{\alpha},\pi_{\alpha}(1)}\gamma_{\alpha}+\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v_{p_{\alpha},\pi_{\alpha}(m_{\alpha}-1)}t_{\alpha}+\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v^{\prime}_{p_{\alpha}}s_{\alpha}\\
=&R_{\mathbf{t}}^{\mathbf{\gamma}}+T_{\mathbf{s}},\end{split}

(17)

where
R_{\mathbf{t}}^{\mathbf{\gamma}}:\mathbb{Z}_{p_{1}}^{m_{1}-1}\times\dots\times\mathbb{Z}_{p_{k}}^{m_{k}-1}\rightarrow\mathbb{Z}_{\lambda}
is defined by

R_{\mathbf{t}}^{\mathbf{\gamma}}=f+\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v_{p_{\alpha},\pi_{\alpha}(1)}\gamma_{\alpha}+\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v_{p_{\alpha},\pi_{\alpha}(m_{\alpha}-1)}t_{\alpha},

(18)

and
T_{\mathbf{s}}:\mathbb{Z}_{p_{1}}\times\dots\times\mathbb{Z}_{p_{k}}\rightarrow\mathbb{Z}_{\lambda}
is defined by

T_{\mathbf{s}}=\sum_{\alpha=1}^{k}\frac{\lambda}{p_{\alpha}}v^{\prime}_{p_{\alpha}}s_{\alpha}.

(19)

Next, we define the code
\mathcal{C}_{\mathbf{s},\mathbf{t}}
which is given by

\mathcal{C}_{\mathbf{s},\mathbf{t}}=[\psi(a_{\mathbf{s},\mathbf{t}}^{\mathbf{\gamma}})]_{\gamma\in\mathbb{Z}_{p_{1}}\times\mathbb{Z}_{p_{2}}\times\dots\times\mathbb{Z}_{p_{k}}}=\begin{bmatrix}\psi(a_{\mathbf{s},\mathbf{t}}^{(0)_{\gamma}})\\[2.0pt]
\psi(a_{\mathbf{s},\mathbf{t}}^{(1)_{\gamma}})\\
\vdots\\
\psi(a_{\mathbf{s},\mathbf{t}}^{(p_{1}p_{2}\dots p_{k}-1)_{\gamma}})\end{bmatrix},

(20)

where
(i)_{\gamma}
is the vector representation of
i
in
\mathbb{Z}_{p_{1}}\times\mathbb{Z}_{p_{2}}\times\dots\times\mathbb{Z}_{p_{k}}
.

It can be noted that
\psi(a_{\mathbf{s},\mathbf{t}}^{\mathbf{\gamma}})
can be written as

\psi(a_{\mathbf{s},\mathbf{t}}^{\mathbf{\gamma}})=\psi(T_{\mathbf{s}})\otimes\psi(R_{\mathbf{t}}^{\mathbf{\gamma}}),

(21)

where
\otimes
denotes the Kronecker product.

Also, for two pairs of sequences

V
Conclusion

In this paper, we have investigated IGC code set and 2-D ZCACS. We have used multivariable function to construct these sequences and arrays, so that the length and array sizes could be flexible. We first proposed a class of multivariables functions to generate the IGC code set of length of the form
p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}
where
m_{\alpha}\geq 2
for all
\alpha
. Using
Theorem
1
, we have developed the construction of 2-D ZCAC of array size
L_{1}\times L_{2}
where
L_{1}=2^{m}
and
L_{2}=2p_{1}^{m_{1}}p_{2}^{m_{2}}\dots p_{k}^{m_{k}}
. And finally in
Theorem
3
, we have proposed our main construction of 2-D ZCACS of the same array sizes using multi-varaible functions. Although our constructions cover a majority of evern lengths for the array sizes of 2-D ZCACS, the construction for all remaining lengths including the odd lengths are still an open problem.
