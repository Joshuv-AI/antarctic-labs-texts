A new class of solvable nonlinear difference equation systems
DURHASAN TURGUT TOLLU

Abstract
The paper deals with the following system of nonlinear difference equations x n + 1 = a ​ x n 2 ​ y n + b ​ x n ​ y n 2 , y n + 1 = c ​ x n 2 ​ y n + d ​ x n ​ y n 2 , n ∈ ℕ 0 , x_{n+1}=ax_{n}^{2}y_{n}+bx_{n}y_{n}^{2},\ y_{n+1}=cx_{n}^{2}y_{n}+dx_{n}y_{n}^{2},\ n\in\mathbb{N}_{0}, where the initial values x 0 , y 0 x_{0},y_{0} and the parameters a a , b b , c c , d d are arbitrary real numbers, which is a new class of solvable systems of nonlinear difference equations. The general solution of the system is here obtained in closed form via a practical method. Keywords: Closed form formula, general solution, system of difference equations, zero set, trivial solution. AMS Classification (2010): 39A05, 39A10, 39A20.



1  Introduction

As in the theory of differential equations, a fundamental problem in the
theory of difference equations is the solvability of these equations or
their systems. If the considered equation or system can be solved, a
detailed analysis of behavior of the solutions can be obtained via its
general solution. Theoretically, the linear difference equations and systems
are always solvable. But, a nonlinear difference equation or a system of
nonlinear difference equations is not always solvable. Because finding the
solution of a nonlinear equation or system requires special methods. These
methods are generally to transform the equations or the system into linear
ones by suitable changes of variables. Accordingly, it is quite interesting
and valuable to find the general solution of a nonlinear difference equation
or system of difference equations.

In this paper, we define the following system of nonlinear difference
equations

x_{n+1}=ax_{n}^{2}y_{n}+bx_{n}y_{n}^{2},\ y_{n+1}=cx_{n}^{2}y_{n}+dx_{n}y_{n}^{2},\ n\in\mathbb{N}_{0},

(1)

where the initial values
x_{0}
,
y_{0}
and the parameters
a
,
b
,
c
,
d
are arbitrary real numbers. We obtain the closed form formulas of
nontrivial solutions of system (
1
) via a practical method. The
method was used for the first time in the reference
[
32
]
to
solve another system. The method in this study is a slight modification of
the first. See also
[
33
]
for another solvable nonlinear
system and another modification.

System (
1
) belongs to the following class of systems of difference
equations of order one

x_{n+1}=f\left(x_{n},y_{n}\right),\ y_{n+1}=g\left(x_{n},y_{n}\right),\ n\in\mathbb{N}_{0}.

(2)

By the solvability of a system in form (
2
), we would like to say
that there are sequences of the general terms

\left\{\begin{array}[]{c}x_{kn+i}=\phi_{n}^{\left(i\right)}\left(x_{0},y_{0}\right),\\
y_{ln+j}=\psi_{n}^{\left(j\right)}\left(x_{0},y_{0}\right),\end{array}\ 0\leq i\leq k-1,\ 0\leq j\leq l-1,\right.

(3)

that provide the system for
i,j,n\in\mathbb{N}_{0}
and
k,l\in\mathbb{N}
. If there are
n_{0}\in\mathbb{N}_{0}
such that the identities

\phi_{n}^{\left(i\right)}\left(x_{0},y_{0}\right)=0\text{ and }\psi_{n}^{\left(j\right)}\left(x_{0},y_{0}\right)=0

hold for every
n\geq n_{0}
, then we say that the solution represented by (
3
) is eventually trivial. If
n_{0}=0
, then we say that the
solution is trivial. The set of initial values that produce such solutions
is called zero set of system (
2
). See
[
21
]
for the zero
set definition of a difference equation.

2  Some preliminary results

This section serves us to achieve our main results.

If we take
a=c
,
b=d

x_{n+1}=\left(a+b\right)x_{n}^{3}

(4)

from its solutions for all

. This equation is a special

x_{n+1}=a_{n}x_{n}^{3},

(5)

where

is a sequence with real-terms. If
a_{n}\neq 0

for all

, then Equation (

x_{n}=x_{0}^{3^{n}}\prod\limits_{k=0}^{n-1}a_{k}^{3^{n-k-1}}.

Several equations in the form of (
5

study. If we allow to become
a_{n}=a+b
for every
n\in\mathbb{N}_{0}
,
then we have the following solution

x_{n}=x_{0}^{3^{n}}\prod\limits_{k=0}^{n-1}\left(a+b\right)^{3^{n-k-1}}=x_{0}^{3^{n}}\left(a+b\right)^{\left(\sum\limits_{k=0}^{n-1}3^{n-k-1}\right)}=x_{0}^{3^{n}}\left(a+b\right)^{\frac{3^{n}-1}{3-1}}

\sum\limits_{k=m}^{m-l}s_{k}=0\text{ and }\prod\limits_{k=m}^{m-l}s_{k}=1,\ l\in\mathbb{N}.

Hence, the above formulas are also valid for
n=0

In this study, we use the general solutions of the two-dimensional system of

Lemma 1

Consider system (
6

ad-bc=0
, then the general
solution of system (

\left[\begin{array}[]{c}u_{n}\\
v_{n}\end{array}\right]=\left(a+d\right)^{n-1}\left[\begin{array}[]{c}au_{0}+bv_{0}\\
cu_{0}+dv_{0}\end{array}\right].

Proof.
Suppose that
ad-bc=0

A^{2}=\left(a+d\right)A
. By using this identity, we have

A^{n}=A^{2}A^{n-2}=\left(a+d\right)AA^{n-2}=\left(a+d\right)A^{n-1}

for
n\geq 2
. Since the last equality is a first-order difference equation,
we can write

\displaystyle A^{n}

\displaystyle=

\displaystyle\left(a+d\right)A^{n-1}

\displaystyle\left(a+d\right)A^{n-1}

\displaystyle=

\displaystyle\left(a+d\right)^{2}A^{n-2}

\displaystyle\left(a+d\right)^{2}A^{n-2}

\displaystyle=

\displaystyle\left(a+d\right)^{3}A^{n-3}

\displaystyle\left(a+d\right)^{n-2}A^{2}

\displaystyle=

\displaystyle\left(a+d\right)^{n-1}A.

By summing the above equalities, we find the
n
th power of
A
as follows

A^{n}=\left(a+d\right)^{n-1}\left[\begin{array}[]{cc}a&b\\
c&d\end{array}\right].

(10)

Finally, by using (
10

8

).

That is, apart from these cases, there are still initial values that

determine such solutions of (
