Exotic states in the π ​ D \pi D system
Thomas Luu

Abstract
In this proceedings we consider several states, namely the D s ​ 0 ∗ ​ ( 2317 ) D^{*}_{s0}(2317) , D s ​ 1 ​ ( 2460 ) D_{s1}(2460) , D 0 ∗ ​ ( 2300 ) D^{*}_{0}(2300) and D 1 ​ ( 2430 ) D_{1}(2430) , which appear to defy description as simple quark-antiquark pairs. Theoretical input from unitarized chiral perturbation theory suggests they can be understood as emerging from Goldstone-Boson– D D -meson scattering. We present results from an S ​ U ​ ( 3 ) SU(3) flavor-symmetric lattice QCD simulation at large pion masses suggesting that there exists a π ​ D \pi D bound state in the flavor-sextet representation that cannot emerge for quark-antiquark states, but that appears naturally from the multiquark states. Moreover, we find repulsion in the [15] representation, which establishes the pattern predicted for the interactions of Goldstone bosons with D D mesons. This suggests these states may have the structure of hadronic molecules.
