Interior continuity, continuity up to the boundary and Harnack’s inequality for double-phase elliptic equations with non-logarithmic conditions
Oleksandr V. Hadzhy, Igor I. Skrypnik, Mykhailo V. Voitovych

Abstract
We prove continuity and Harnack’s inequality for bounded solutions to elliptic equations of the type div ( | ∇ u | p − 2 ∇ u + a ( x ) | ∇ u | q − 2 ∇ u ) = 0 , \displaystyle{\rm div}\big(|\nabla u|^{p-2}\,\nabla u+a(x)|\nabla u|^{q-2}\,\nabla u\big)=0, a ⁡ ( x ) ⩾ 0 , \displaystyle a(x)\geqslant 0, | a ⁡ ( x ) − a ⁡ ( y ) | ⩽ A ​ | x − y | α ​ μ ​ ( | x − y | ) , \displaystyle|a(x)-a(y)|\leqslant A|x-y|^{\alpha}\mu(|x-y|), x ≠ y , \displaystyle x\neq y, div ( | ∇ u | p − 2 ∇ u [ 1 + ln ( 1 + b ( x ) | ∇ u | ) ] ) = 0 , \displaystyle{\rm div}\Big(|\nabla u|^{p-2}\,\nabla u\big[1+\ln(1+b(x)\,|\nabla u|)\big]\Big)=0, b ⁡ ( x ) ⩾ 0 , \displaystyle b(x)\geqslant 0, | b ⁡ ( x ) − b ⁡ ( y ) | ⩽ B | x − y | μ ⁡ ( | x − y | ) , \displaystyle|b(x)-b(y)|\leqslant B|x-y|\,\mu(|x-y|), x ≠ y , \displaystyle x\neq y, div ( | ∇ u | p − 2 ∇ u + c ( x ) | ∇ u | q − 2 ∇ u [ 1 + ln ( 1 + | ∇ u | ) ] β ) = 0 , \displaystyle{\rm div}\Big(|\nabla u|^{p-2}\,\nabla u+c(x)|\nabla u|^{q-2}\,\nabla u\big[1+\ln(1+|\nabla u|)\big]^{\beta}\Big)=0, c ( x ) ⩾ 0 , β ⩾ 0 , \displaystyle c(x)\geqslant 0,\,\beta\geqslant 0,\phantom{=0=0} | c ⁡ ( x ) − c ⁡ ( y ) | ⩽ C ​ | x − y | q − p ​ μ ​ ( | x − y | ) , \displaystyle|c(x)-c(y)|\leqslant C|x-y|^{q-p}\,\mu(|x-y|), x ≠ y , \displaystyle x\neq y, under the precise choice of μ \mu . Keywords: double-phase elliptic equations, non-logarithmic conditions, continuity of solutions, regularity of a boundary point, Harnack’s inequality. MSC (2010) : 35B65, 35D30, 35J60, 49N60.

i_{1}\geqslant 2
be the maximal number satisfying the above condition,
in this case we set
\widetilde{r}_{1}=\widetilde{r}_{0}/2^{i_{1}}
, then
inequality (
4.5
) can be rewritten in the form

M_{k}(\widetilde{r}_{0})-M_{k}(\widetilde{r}_{1})\geqslant\eta\,\tau(\widetilde{r}_{0},M_{k}(\widetilde{r}_{0})\lambda(\widetilde{r}_{0})).

Further we define the sequence
\widetilde{r}_{j}
by induction.
Suppose we have chosen
\widetilde{r}_{0}
,
\widetilde{r}_{1}
,
…,
\widetilde{r}_{j}
such that

\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i}))\geqslant C_{4}\widetilde{r}_{i},\quad i=0,1,\ldots,j,

(4.6)

M_{k}(\widetilde{r}_{i+1})\leqslant M_{k}(\widetilde{r}_{i})-\eta\,\tau(\widetilde{r}_{i},M_{k}(\widetilde{r}_{i})\lambda(\widetilde{r}_{i})),\quad i=0,1,\ldots,j-1.

(4.7)

Let us show how to choose
\widetilde{r}_{j+1}
.
By (
4.6
) similarly to (
4.4
) we obtain

\tau(\widetilde{r}_{j},M_{k}(\widetilde{r}_{j})\lambda(\widetilde{r}_{j}))\geqslant\gamma(a)g(x_{0},C_{4})\geqslant\gamma(a)\,C_{4}^{\,p-1}.

(4.8)

Let us construct an auxiliary solution
v=v(x,M_{k}(\widetilde{r}_{j})\lambda(\widetilde{r}_{j}))

of the problem (
1.12
), (
1.13
) in

\mathcal{D}_{j}=B_{\widetilde{r}_{j}}(x_{0})\setminus E_{j}
,

E_{j}=B_{\widetilde{r}_{j}/4}(x_{0})\setminus\Omega
.
Consider the function

\widetilde{u}_{k,j}=M_{k}(\widetilde{r}_{j})-u_{k}^{+}
,
since
\widetilde{u}_{k,j}\geqslant v
on
\partial\mathcal{D}_{j}
,
by Lemma
4.1
we obtain
\widetilde{u}_{k,j}\geqslant v
in
\mathcal{D}_{j}
.
If
\gamma(a)\,C_{4}^{\,p-1}\geqslant C_{3}
, then condition (
1.14
) is violated and by
Theorem
1.4
we have

M_{k}(\widetilde{r}_{j})-M_{k}(\widetilde{r}_{j}/2)\geqslant\eta\,\tau(\widetilde{r}_{j},M_{k}(\widetilde{r}_{j})\lambda(\widetilde{r}_{j})).

(4.9)

If

\tau(\widetilde{r}_{j}/2,\lambda(\widetilde{r}_{j}/2))\geqslant C_{4}\widetilde{r}_{j}/2
we set
\widetilde{r}_{j+1}=\widetilde{r}_{j}/2
.
And if

\tau(\widetilde{r}_{j}/2,\lambda(\widetilde{r}_{j}/2))\leqslant C_{4}r_{j}/2
,
similarly to (
4.3
) we find a number
i\geqslant 2
such that

\tau(\widetilde{r}_{j}/2^{i},\lambda(\widetilde{r}_{j}/2^{i}))\geqslant C_{4}\widetilde{r}_{j}/2^{i}
, let
i_{j+1}\geqslant 2
be the maximal number
satisfying the above condition, in this case we set

\widetilde{r}_{j+1}=\widetilde{r}_{j}/2^{i_{j+1}}
.
Then inequality (
4.9
) can be rewritten as

M_{k}(\widetilde{r}_{j})-M_{k}(\widetilde{r}_{j+1})\geqslant\eta\,\tau(\widetilde{r}_{j},M_{k}(\widetilde{r}_{j})\lambda(\widetilde{r}_{j})).

(4.10)

We have

\sum_{i\in\mathbb{N}}\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i}))=+\infty.

(4.11)

Indeed, by our choices

\displaystyle\sum_{i\in\mathbb{N}}\tau(r_{i},\lambda(r_{i}))

\displaystyle=\sum_{\begin{subarray}{c}i\in\mathbb{N}\\
r_{i}\neq\widetilde{r}_{i}\end{subarray}}\tau(r_{i},\lambda(r_{i}))+\sum_{i\in\mathbb{N}}\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i}))

\displaystyle\leqslant\gamma\sum_{i\in\mathbb{N}}\frac{\rho}{2^{i}}+\sum_{i\in\mathbb{N}}\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i}))\leqslant\gamma\rho+\sum_{i\in\mathbb{N}}\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i})),

from which the required (
4.11
) follows.

To complete the proof of Theorem
1.2
we sum up inequality (
4.10
)
for
j=0,1,2,\ldots,l
.
By (
4.2
) and (
{\rm g}_{1}
) we obtain that

\eta\,\gamma(a)\sum\limits_{j=0}^{l}\tau(\widetilde{r}_{j},\lambda(\widetilde{r}_{j}))\leqslant\sum\limits_{j=0}^{l}(M_{k}(\widetilde{r}_{j})-M_{k}(\widetilde{r}_{j+1}))\leqslant M_{k}(r_{0})\leqslant 2M.

This implies that

\sum\limits_{i\in\mathbb{N}}\tau(\widetilde{r}_{i},\lambda(\widetilde{r}_{i}))\leqslant\gamma(a,M)<+\infty
,
which contradicts (
4.11
).
This completes the proof of Theorem
1.2
.

4.2
Harnack’s inequality for double-phase elliptic equations,
proof of Theorem
1.3

To prove Theorem
1.3
we need the following version of De Giorgi type lemma,
which was proved in
[
39
]
.

Let
u
be a bounded weak solution to Eq. (
1.1
). Let
\overline{x}\in\Omega
be
an arbitrary point. Consider a ball
B_{8r}(\overline{x})\subset\Omega
and denote by

\mu_{\pm}
and
\omega
non-negative numbers such that

\mu_{+}\geqslant\esssup_{B_{r}(\overline{x})}u,\quad\mu_{-}\leqslant\essinf_{B_{r}(\overline{x})}u,\quad\omega=\mu_{+}-\mu_{-}.

Lemma 4.3
.

Let conditions
(
{\rm g}_{1}
)
and

(
{\rm g}_{3}
)
be fulfilled. Fix
\xi
,
a\in(0,1)
, then there exists
number
\nu\in(0,1)
depending only on the data and
a
such that if

\left|\left\{x\in B_{r}(\overline{x}):u(x)\geqslant\mu_{+}-\xi\,\omega\right\}\right|\leqslant\nu\,\theta^{-2n}(r)\,|B_{r}(\overline{x})|,

(4.12)

then either

\xi\,\omega\leqslant r

(4.13)

or

u(x)\leqslant\mu_{+}-a\,\xi\,\omega\quad\text{for a.a.}\ x\in B_{r/2}(\overline{x}).

(4.14)

Likewise, if

\left|\left\{x\in B_{r}(\overline{x}):u(x)\leqslant\mu_{-}+\xi\,\omega\right\}\right|\leqslant\nu\,[\theta(r)]^{-2n}\,|B_{r}(\overline{x})|,

(4.15)

then either (
4.13
) holds, or

u(x)\geqslant\mu_{-}+a\,\xi\,\omega\quad\text{for a.a.}\ x\in B_{r/2}(\overline{x}).

(4.16)

Fix
x_{0}\in\Omega
and for
0<8\rho<R
construct the ball

B_{\rho\tau}(x_{0})
,
\tau\in(0,1)
and set
u_{0}:=u(x_{0})
.
Following Krylov and Safonov
[
25
]
consider the equation

\max\limits_{B_{\rho\tau}(x_{0})}u=\frac{u_{0}}{2(1-\tau)^{l_{1}}}\left(\frac{\theta\big((1-\tau)\rho\big)}{\theta(\rho)}\right)^{l_{2}},

where
l_{1}
,
l_{2}>0
will be chosen later depending only on the known data.

Further we will assume that

u_{0}\geqslant C_{2}\rho\,\frac{\theta^{\frac{2n}{p-1}}(\rho)}{\lambda(\rho)}.

(4.17)

Let
\tau_{0}\in(0,1)
be the maximal root of the above equation.
Fix
\overline{x}
by the condition

u(\overline{x})=\max\limits_{B_{\rho\tau_{0}}(x_{0})}u=\frac{u_{0}}{2(1-\tau_{0})^{l_{1}}}\left(\frac{\theta\big((1-\tau_{0})\rho\big)}{\theta(\rho)}\right)^{l_{2}}.

Since
B_{\frac{\rho(1-\tau_{0})}{2}}(\overline{x})\subset B_{\frac{\rho(1+\tau_{0})}{2}}(x_{0})
, by our choice of
\theta(\rho)

we have

\max_{B_{\frac{\rho(1-\tau_{0})}{2}}(\overline{x})}u\leqslant\frac{2^{\,l_{1}-1}u_{0}}{(1-\tau_{0})^{l_{1}}}\left(\frac{\theta\big(\frac{1-\tau_{0}}{2}\rho\big)}{\theta(\rho)}\right)^{l_{2}}=2^{\,l_{1}}u(\overline{x})\left(\frac{\theta\big(\frac{1-\tau_{0}}{2}\rho\big)}{\theta\big((1-\tau_{0})\rho\big)}\right)^{l_{2}}\leqslant 2^{\,l_{1}+l_{2}}u(\overline{x}).

Claim.

There exists a positive number
\nu\in(0,1)
depending only on the known data
such that

\left|\left\{x\in B_{\frac{\rho(1-\tau_{0})}{2}}(\overline{x}):u(x)\geqslant\frac{u(\overline{x})}{2}\right\}\right|\geqslant\nu\,\theta^{-2n}\bigg(\frac{1-\tau_{0}}{2}\rho\bigg)|B_{\frac{\rho(1-\tau_{0})}{2}}(\overline{x})|.

(4.18)

Indeed, in the opposite case we apply (
4.12
)–(
4.14
) with the choices

\mu_{+}=2^{\,l_{1}+l_{2}}u(\overline{x}),\quad\xi\,\omega=\left(2^{\,l_{1}+l_{2}}-\frac{1}{2}\right)u(\overline{x}),\quad a=\frac{2^{\,l_{1}+l_{2}}-\frac{3}{4}}{2^{\,l_{1}+l_{2}}-\frac{1}{2}}\in(0,1).

The condition (
4.17
) obviously implies

\xi\,\omega\geqslant(1-\tau_{0})\rho/2
. Therefore we can conclude that

u(\overline{x})\leqslant\max\limits_{B_{\frac{\rho(1-\tau_{0})}{4}}(\overline{x})}u\leqslant\frac{3}{4}\,u(\overline{x}),

reaching a contradiction, which proves the claim.

Set
r=\dfrac{1-\tau_{0}}{2}\rho
,

E:=B_{r}(\overline{x})\cap\left\{u\geqslant\dfrac{u(\overline{x})\lambda(\rho)}{2}\right\}
,
then inequality (
4.18
) translates into

|E|\geqslant\nu\,\theta^{-2n}(r)\,|B_{r}(\overline{x})|.

(4.19)

We will apply Theorem
1.4
, for this we consider an auxiliary solution

v(x):=v(x,m)
,
m=\frac{1}{2}u(\overline{x})\lambda(\rho)
of the problem
(
1.12
), (
1.13
) in
\mathcal{D}=B_{4\rho}(\overline{x})\setminus E
.

First, we need to check the inequality

C(E,B_{4\rho}(\overline{x});m)\geqslant C_{3}\,\rho^{n-1}.

(4.20)

Set
\Phi(x,{\rm v}):=\int\limits_{0}^{{\rm v}}g(x,s)\,ds
,
by (
{\rm g}_{1}
)
\Phi(x,{\rm v})\asymp G(x,{\rm v})
,
x\in\Omega
,
{\rm v}>0
.
Using the Poincaré inequality and conditions (
{\rm g}_{1}
), (
{\rm g}_{2}
),
for any
\varphi\in W_{0}(B_{4\rho}(\overline{x}))
such that
\varphi\geqslant 1
on
E
,
we obtain

\displaystyle\frac{1}{\rho}\int\limits_{B_{4\rho}(\overline{x})}g(\overline{x},m\varphi/\rho)\,\varphi\,dx\leqslant\frac{\gamma}{m}\int\limits_{B_{4\rho}(\overline{x})}\Phi(\overline{x},m\varphi/\rho)\,dx

\displaystyle\leqslant\gamma\int\limits_{B_{4\rho}(\overline{x})}g(\overline{x},m\varphi/\rho)\,|\nabla\varphi|\,dx\leqslant\gamma\int\limits_{B_{4\rho}(\overline{x})}g(x,m\varphi/\rho)\,|\nabla\varphi|\,dx

\displaystyle\leqslant\frac{1}{2\gamma\rho}\int\limits_{B_{4\rho}(\overline{x})}g(x,m\varphi/\rho)\,\varphi\,dx+\gamma\int\limits_{B_{4\rho}(\overline{x})}g(x,m|\nabla\varphi|)\,|\nabla\varphi|\,dx

\displaystyle\leqslant\frac{1}{2\rho}\int\limits_{B_{4\rho}(\overline{x})}g(\overline{x},m\varphi/\rho)\,\varphi\,dx+\gamma\int\limits_{B_{4\rho}(\overline{x})}g(x,m|\nabla\varphi|)\,|\nabla\varphi|\,dx,

which implies that

\displaystyle\int\limits_{B_{4\rho}(\overline{x})}g(x,m|\nabla\varphi|)\,|\nabla\varphi|\,dx\geqslant\frac{\gamma^{-1}}{\rho}\int\limits_{B_{4\rho}(\overline{x})}g(\overline{x},m\varphi/\rho)\,\varphi\,dx

\displaystyle\geqslant\gamma^{-1}g(\overline{x},m/\rho)\,\frac{|E|}{\rho}\geqslant\gamma^{-1}\nu\,\theta^{-2n}(r)\,g(\overline{x},m/\rho)\,\left(\frac{r}{\rho}\right)^{n}\rho^{n-1}.

And hence

C(E,B_{4\rho}(\overline{x});m)\geqslant\gamma^{-1}\nu\,\theta^{-2n}(r)\,g(\overline{x},m/\rho)\,\left(\frac{r}{\rho}\right)^{n}\rho^{n-1}.

(4.21)

By (
{\rm g}_{1}
), (
4.17
) and our choice of
u(\overline{x})
we have

\displaystyle g(\overline{x},m/\rho)

\displaystyle=g\bigg(\overline{x},\left(\frac{\theta(r)}{\theta(\rho)}\right)^{l_{2}}\left(\frac{\rho}{r}\right)^{l_{1}}\frac{u_{0}\lambda(\rho)}{2\rho}\bigg)

\displaystyle\geqslant g\bigg(\overline{x},\frac{C_{2}}{2}\left(\frac{\rho}{r}\right)^{l_{1}}\theta^{\,l_{2}}(r)\,\theta^{\frac{2n}{p-1}-l_{2}}(\rho)\bigg)

\displaystyle\geqslant\gamma^{-1}C_{2}^{\,p-1}\,\theta^{\,l_{2}(p-1)}(r)\left(\frac{\rho}{r}\right)^{l_{1}(p-1)}g\left(\overline{x},\theta^{\frac{2n}{p-1}-l_{2}}(\rho)\right).

Choosing
l_{1}
and
l_{2}
from the conditions
l_{1}=\dfrac{n}{p-1}
,

l_{2}=\dfrac{2n}{p-1}
, from the last inequality we obtain

g(\overline{x},m/\rho)\geqslant\gamma^{-1}C_{2}^{\,p-1}\,\theta^{2n}(r)\left(\frac{\rho}{r}\right)^{n}g(\overline{x},1)\geqslant\gamma^{-1}C_{2}^{\,p-1}\,\theta^{2n}(r)\left(\frac{\rho}{r}\right)^{n}.

Therefore, by (
4.21
), choosing
C_{2}
so that

\gamma^{-1}\nu\,C_{2}^{\,p-1}\geqslant C_{3}
, we arrive at the required (
4.20
).

Using (
4.20
) and Theorem
1.4
, we conclude that

v(x)\geqslant\gamma^{-1}\rho\,g_{\overline{x}}^{-1}\left(\frac{C(E,B_{4\rho}(\overline{x});m)}{\rho^{\,n-1}}\right)\quad\text{for a.a.}\ x\in B_{2\rho}(\overline{x})\setminus B_{\rho}(\overline{x}).

Inequality (
4.21
) and condition (
{\rm g}_{1}
) imply that

g^{-1}_{\overline{x}}\left(\frac{C(E,B_{4\rho}(\overline{x});m)}{\rho^{n-1}}\right)\geqslant\gamma^{-1}\nu^{-\frac{1}{p-1}}\,\theta^{-\frac{2n}{p-1}}(r)\left(\frac{r}{\rho}\right)^{\frac{n}{p-1}}\frac{m}{\rho}.

And using our choices of
m
and
u(\overline{x})
, from the previous we obtain

v(x)\geqslant\gamma^{-1}\,\theta^{-\frac{2n}{p-1}}(\rho)\,\lambda(\rho)\,u_{0},\quad x\in B_{2\rho}(\overline{x})\setminus B_{\rho}(\overline{x}).

(4.22)

By our construction
u\geqslant v
on
\partial\mathcal{D}
, and therefore,
by Lemma
4.1
and (
4.22
) we have

\inf\limits_{B_{\rho}(x_{0})}u\geqslant\inf\limits_{B_{2\rho}(\overline{x})}u\geqslant\inf\limits_{\partial B_{2\rho}(\overline{x})}u\geqslant\inf\limits_{\partial B_{2\rho}(\overline{x})}v\geqslant\gamma^{-1}\,\theta^{-\frac{2n}{p-1}}(\rho)\,\lambda(\rho)\,u_{0},

which completes the proof of Theorem
1.3
.
