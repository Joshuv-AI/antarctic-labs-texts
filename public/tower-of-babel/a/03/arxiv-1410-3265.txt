Improved statistical fluctuation analysis for measurement-device-independent quantum key distribution with three-intensity decoy-state method
Zong-Wen Yu 1,2 , Yi-Heng Zhou 1,3 , and Xiang-Bin Wang 1,3,4

Abstract
We present an improved statistical fluctuation analysis for measurement device independent quantum key distribution with three-intensity decoy-state method. Taking the statistical fluctuations for different sources jointly, we present more tightened formulas for some key quantities used in calculating the secure final key. Numerical simulation shows that, given the total number of pulses 10 12 10^{12} , our method improves the key rate by about 97% for a distance of 50kms compared with the result given by Xu., et al. (Phys. Rev. A 89, 052333); and improves the key rate by 146 % 146\% for a distance of 100kms compared with the result from full optimization of all parameters but treating the statistical fluctuations traditionally, i.e., treating the fluctuations for different sources separately.

Three-intensity decoy-state method for MDI-QKD

The UTP will announce whether the pulse-pair has caused a successful event. Those bits corresponding to successful events will be post-selected and further processed for the final key. Since in practice only imperfect single-photon sources are available, we need the decoy-state method for security in practice.

III.1
Relations among the fluctuations of different sources

When we do the statistical fluctuation analysis, we need to choose a proper security bound first. With a given definite security bound, we can bound
\delta_{lr}
and
\tau_{lr}
by Eq.(
19
) and Eq.(
27
) respectively. In order to obtain the relations among these quantities, we need to reconsider the grouping of the successful events announced by UTP.

For clarity, we consider the relation between
\tau_{ox}
and
\tau_{xo}
first. As defined above, we know that
\tau_{ox}
and
\tau_{xo}
are the relative fluctuations for the observed error yields
{T}_{ox}
and
{T}_{xo}
respectively. These two observable are corresponding to the successful events with different two-pulse sources
ox
and
xo
. If we group all those successful events of these two sources together, and denote
J=\{ox,xo\}
, the relation between the error yield
T_{J}
and its mean value
\langle T_{J}\rangle
is

\langle{T}_{J}\rangle=T_{J}(1+\tau_{J}),

(31)

where
\tau_{J}
is the relative fluctuation for the observable
T_{J}
. Similarly,
\tau_{J}
has the following property with given security bound

|\tau_{J}|\leq\frac{n_{\tau}}{\sqrt{N_{ox}S_{ox}+N_{xo}S_{xo}}}\triangleq\bar{\tau}_{J}.

(32)

In this relation,
N_{ox}S_{ox}+N_{xo}S_{xo}
is the number of error counts when Alice and Bob use two-pulse sources
ox
and
xo
. Reconsidering the definition of
T_{J}
, we know that

N_{ox}T_{ox}+N_{xo}T_{xo}=(N_{ox}+N_{xo})T_{J}.

Now we take into account the mean values. The above relation can be written into

\displaystyle N_{ox}\langle{T}_{ox}\rangle+N_{xo}\langle{T}_{xo}\rangle

\displaystyle=

\displaystyle N_{ox}T_{ox}(1+\tau_{ox})+N_{xo}T_{xo}(1+\tau_{xo})

\displaystyle=

\displaystyle(N_{ox}T_{ox}+N_{xo}T_{xo})(1+\tau_{J}).

Then we have the relation between these two quantities
\tau_{ox}
and
\tau_{xo}

\displaystyle|N_{ox}{T}_{ox}\tau_{ox}+N_{xo}{T}_{xo}\tau_{xo}|\leq n_{\tau}\sqrt{N_{ox}{T}_{ox}+N_{xo}{T}_{xo}}.

(33)

Here we have used Eq.(
32
). Similarly, the relation between any two different quantities
\tau_{l_{1}r_{1}}
and
\tau_{l_{2}r_{2}}
can be written into

\displaystyle|N_{l_{1}r_{1}}{T}_{l_{1}r_{1}}\tau_{l_{1}r_{1}}+N_{l_{2}r_{2}}{T}_{l_{2}r_{2}}\tau_{l_{2}r_{2}}|

\displaystyle\leq n_{\tau}\sqrt{N_{l_{1}r_{1}}{T}_{l_{1}r_{1}}+N_{l_{2}r_{2}}{T}_{l_{2}r_{2}}},

(34)

with
l_{1},r_{1},l_{2},r_{2}
each can be any one of
o,x
or
y
and
l_{1}r_{1}\neq l_{2}r_{2}
.

Generally, we can group the successful events of a number of two-pulse sources together. To see it more clearly, we define the set

{\bf J}=\{lr|l,r=o,x,y\}

(35)

as the whole set of all possible two-pulse sources (in a certain basis) used by Alice and Bob in the protocol. Explicitly,

{\bf J}=\{oo,ox,xo,oy,yo,xx,xy,yx,yy\}
in any basis.
With this notation, we can write all the relations among
\tau_{lr}
into

\left|\sum_{lr\in\mathcal{J}}N_{lr}T_{lr}\tau_{lr}\right|\leq n_{\tau}\sqrt{\sum_{lr\in\mathcal{J}}N_{lr}T_{lr}},

(36)

for all nonempty
\mathcal{J}\subseteq{\bf J}
and

\sum_{lr\in{\bf J}}N_{lr}T_{lr}\tau_{lr}=0.

(37)

The last equation is deduced from the fact that

\sum_{lr\in{\bf J}}N_{lr}\langle{T}_{lr}\rangle=\sum_{lr\in{\bf J}}N_{lr}T_{lr}.

Specifically, if set
\mathcal{J}
contains only one element
lr
, then the relations presented in Eq.(
36
) is just the bound for
\tau_{lr}
shown in Eq.(
27
). If set
\mathcal{J}
contains two elements, say
\mathcal{J}=\{l_{1}r_{1},l_{2}r_{2}\}
, then the relations presented in Eq.(
36
) is just the relation between two quantities
\tau_{l_{1}r_{1}}
and
\tau_{l_{2}r_{2}}
given by Eq.(
III.1
).

It should be noted that there are nine different
\tau_{lr}
in Eq.(
26
) for this three-intensity protocol in each basis, if we consider all possible
lr
. Furthermore, in Eq.(
36
) and Eq.(
37
), there are
\sum_{k=2}^{9}\mathcal{C}_{9}^{k}=2^{9}-9-1=502
joint constraints and
\mathcal{C}_{9}^{1}=9
boundary constraints for these nine quantities. It is a hard work to obtain an explicit formula to estimate the lower bound of
\langle{t}_{11}\rangle=\langle{s}_{11}\rangle\langle{e}_{11}\rangle
from Eq.(
25
) with all these constraints. In the next subsection, we will present some explicit formulas to upper bound
\langle{e}_{11}\rangle
and lower bound
\langle{s}_{11}\rangle
.

Similarly, all the relations among quantities
\delta_{lr}
for all possible
lr
can be written into

\left|\sum_{lr\in\mathcal{J}}N_{lr}S_{lr}\delta_{lr}\right|\leq n_{\delta}\sqrt{\sum_{lr\in\mathcal{J}}N_{lr}S_{lr}},

(38)

for all nonempty
\mathcal{J}\subseteq{\bf{J}}
and

\sum_{lr\in{\bf J}}N_{lr}S_{lr}\delta_{lr}=0.

(39)

Specifically, if set
\mathcal{J}
contains only one element
lr
, then the relations presented in Eq.(
38
) is just the bounds for each quantities
\delta_{lr}
shown in Eq.(
19

e_{11}^{f}=(T_{+}^{f}-T_{-}^{f})/(a_{1}b_{1}\underline{s}_{11}^{f}),

where

\displaystyle T_{+}^{f}

\displaystyle=

\displaystyle\hat{T}_{+}+T_{xx}\tau_{xx}+a_{0}b_{0}T_{oo}\tau_{oo},

\displaystyle T_{-}^{f}

\displaystyle=

\displaystyle\hat{T}_{-}+a_{0}T_{ox}\tau_{ox}+b_{0}T_{xo}\tau_{xo},

with
\hat{T}_{\pm}
being the constant factors given by Eq.(

In order to obtain a proper estimation of the upper bound of

from the function

\tau_{lr}
. That is to say, we need maximize the function
e_{11}^{f}
of variables
\tau_{lr}
under the constraints shown in Eqs.(
36
,
37

\tau_{lr}
in each basis for this protocol. In principle, one can solve this optimization problem by the linear programming (LP) method with all those 502 constraints being listed in Eqs.(
36
,
37
). However, this will cost huge computation power in making full optimization of all parameters. Note that if we only use part of the constraints, the final key will be still secure but the key rate could be not the optimized result. Naturally, one may ask the question whether we can still obtain the optimized or almost optimized result if we only use a few of 502 constraints. The answer is yes. Actually, as shown below, most of the constrains take no effect to the key rate and they can be abandoned. Luckily, as we show below, we can greatly reduce the number of joint constraints to 11 or even fewer. Moreover, we can even obtain explicit formulas for the optimization problem.

Reconsidering the function
e_{11}^{f}
, we know that the signs in front of

and
T_{-}^{f}

and

T_{-}^{f}

T_{+}^{f}

\tau_{xx}
and
\tau_{oo}
. Similarly, in minimizing
T_{-}^{f}
, we only need to consider the sole joint constraint between variables
\tau_{ox}
and
\tau_{xo}
. These optimization problems can be solved by using the LP method. Furthermore, we can solve the problem analytically with explicit formulas.
We consider the maximization of
T_{+}^{f}
first. In this function, there are two variables
\tau_{xx}
and
\tau_{oo}
. So we only need to consider the joint constraint
N_{xx}T_{xx}\tau_{xx}+N_{oo}T_{oo}\tau_{oo}\leq n_{\tau}\sqrt{N_{xx}T_{xx}+N_{oo}T_{oo}}
and the bounds of
\tau_{xx}
,
\tau_{oo}
shown in Eq.(
27
). Explicitly, we have

\displaystyle T_{+}^{f}

\displaystyle\leq

\displaystyle\hat{T}_{+}+\frac{n_{\tau}a_{0}b_{0}}{N_{oo}}\sqrt{N_{xx}T_{xx}+N_{oo}T_{oo}}

(41)

\displaystyle\hskip-14.22636pt+n_{\tau}\left(\frac{1}{N_{xx}}-\frac{a_{0}b_{0}}{N_{oo}}\right)\sqrt{N_{xx}T_{xx}}\triangleq\overline{T}_{+}^{f_{1}},

when
a_{0}b_{0}N_{xx}\leq N_{oo}
, and

\displaystyle T_{+}^{f}

\displaystyle\leq

\displaystyle\hat{T}_{+}+\frac{n_{\tau}}{N_{xx}}\sqrt{N_{xx}T_{xx}+N_{oo}T_{oo}}

(42)

\displaystyle\hskip-14.22636pt+n_{\tau}\left(\frac{a_{0}b_{0}}{N_{oo}}-\frac{1}{N_{xx}}\right)\sqrt{N_{oo}T_{oo}}\triangleq\overline{T}_{+}^{f_{2}},

V
Conclusion

Through studying the statistical fluctuations of different sources jointly, we obtain the improved statistical analysis with explicit formulas. Numerical simulation shows that the results obtained from our improved methods are significantly better than the results obtained with the traditional methods treating statistical fluctuations of each sources separately. In our study, we have taken the same intensities in both bases. The result can be further improved by taking different intensities in different bases and taking the decoy-state method in only one basis as pointed out in
Wang3improve
. This will be reported elsewhere.
