Crossing number of graphs and Δ ​ 𝖸 \mathsf{\Delta Y} -move
Youngsik Huh, Ryo Nikkuni

Abstract
. The crossing number of a graph is the minimum number of double points over all generic immersions of the graph into the plane. In this paper we investigate the behavior of crossing number under a graph transformation, called Δ ​ 𝖸 \mathsf{\Delta Y} -move, on the complete graph K n K_{n} . Concretely it is shown that for any k ∈ ℕ k\in\mathbb{N} , there exist a natural number n n and a sequence of Δ ​ 𝖸 \mathsf{\Delta Y} -moves K n → G ( 1 ) → ⋯ → G ( k ) K_{n}\rightarrow G^{(1)}\rightarrow\cdots\rightarrow G^{(k)} which is decreasing with respect to the crossing number. We also discuss the decrease of crossing number for relatively small n n .

2.
Crossing-reducible trigons

For a drawing of a graph, an
n
-gon
will imply the image of an
n
-cycle of the graph on the drawing.
A drawing of a graph is said to be

(G1)

No edge intersects itself, that is, there is no self-crossing.

(G2)

There is no crossing between any two adjacent edges.

(G3)

No two edges intersect each other more than once.

Note that if a drawing
D

\mathrm{cr}(D)=\mathrm{cr}(G)
