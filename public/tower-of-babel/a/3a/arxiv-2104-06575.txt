Five Degree-of-Freedom Property Interpolation of Arbitrary Grain Boundaries via Voronoi Fundamental Zone Octonion Framework
Sterling G. Baird, Eric R. Homer, David T. Fullwood, Oliver K. Johnson

Abstract
In this work we introduce the Voronoi fundamental zone octonioninterpolation framework for grain boundarystructure-property models and surrogates. The Voronoi fundamental zone octonionframework offers an advantage over other five degree-of-freedombased property interpolation methods because it is constructed as a point set in a manifold. This means that directly computed Euclidean distances approximate the original octonion distance with significantly reduced computation runtime ( ∼ \sim 7 CPU minutes vs. 153 CPU days for a 50 000 × 50 000 $50\,000$\times$50\,000$ pairwise-distance matrix). This increased efficiency facilitates lower interpolation error through the use of significantly more input data. We demonstrate grain boundary energyinterpolation results for a non-smooth validation function and simulated bi-crystal datasets for Fe and Ni using four interpolation methods: barycentric interpolation, Gaussian process regressionor Kriging, inverse-distance weighting, and nearest neighborinterpolation. These are evaluated for 50 000 50\,000 random input grain boundariesand 10 000 10\,000 random prediction grain boundaries. The best performance was achieved with Gaussian process regression, which resulted in a reduction of the root mean square errorby 83.008 57 83.008\,57 % relative to root mean square errorof a constant, average model. Likewise, interpolation on a large, noisy, molecular staticsFe simulation dataset improves performance by 34.4 % 34.4\text{\,}\mathrm{\%} compared to 21.2 % 21.2\text{\,}\mathrm{\%} in prior work. Interpolation on a small, low-noise molecular staticsNi simulation dataset is similar to interpolation results for the original octonion metric ( 57.6 % 57.6\text{\,}\mathrm{\%} vs. 56.4 % 56.4\text{\,}\mathrm{\%} ). A vectorized, parallelized, MATLAB interpolation function ( interp5DOF . m ) and related routines are available in our Voronoi fundamental zone octonionrepository ( github.com/sgbaird-5dof/interp ) which can be applied to other crystallographic point groups. The Voronoi fundamental zone octonionframework offers advantages for computing distances between grain boundaries, estimating property values for arbitrary grain boundaries, and modeling surrogates of computationally expensive five degree-of-freedomfunctions and simulations.

2.3

Conclusion

In this work, we presented the Voronoi fundamental zone octonionframework for (i) computing distances between GBs and (ii) predicting the properties of GBs from existing measurements. We found that distance calculations in the Voronoi fundamental zone octonionframework are dramatically more computationally efficient than traditional methods at the expense of infrequent, large distance overestimation which can be addressed through ensemble techniques at a small computational cost as discussed in
Section

2.1.3
.

We also developed and tested a barycentric interpolation method, and adapted three other interpolation methods for use in the Voronoi fundamental zone octonionframework. We provide an easy-to-use, versatile implementation of our methods through an interpolation function

github.com/ichesser/GB_octonion_code

Of the interpolation methods that we present in this work, Gaussian process regressionprovided the highest accuracy predictions. It also provided higher accuracy predictions than any of the methods in the literature. The Gaussian process regressioninterpolation errors (
50\,000

For example, barycentric interpolation enables rapid and accurate predictions when the function to be evaluated changes, but the input and prediction grain boundariesremain fixed.

We anticipate that the Voronoi fundamental zone octonionframework and corresponding implementation will benefit numerous applications related to grain boundarystructure and properties, including facilitating grain boundarystructure-property model development, enabling efficient surrogate modeling of grain boundaryproperties, and larger scale iterative simulations that require repetitive evaluation of computationally expensive structure-property models.
