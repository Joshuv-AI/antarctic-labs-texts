On the rigidity of the Sasakian structure and characterization of cosymplectic manifolds
Dhriti Sundar Patra, Vladimir Rovenski

Abstract
We introduce new metric structures on a smooth manifold (called “weak” structures) that generalize the almost contact, Sasakian, cosymplectic, etc. metric structures ( φ , ξ , η , g ) (\varphi,\xi,\eta,g) and allow us to take a fresh look at the classical theory. We demonstrate this statement by generalizing several well-known results. We prove that any Sasakian structure is rigid, i.e., our weak Sasakian structure is homothetically equivalent to a Sasakian structure. We show that a weak almost contact structure with parallel tensor φ \varphi is a weak cosymplectic structure and give an example of such a structure on the product of manifolds. We find conditions for a vector field to be a weak contact infinitesimal transformation. Keywords : Almost contact metric structure, Sasakian structure, cosymplectic structure, contact vector field Mathematics Subject Classifications (2010) 53C15, 53C25, 53D15

(\varphi,Q,\xi,\eta,g)
be a weak cosymplectic structure. Then

\displaystyle 2\,g((\nabla_{X}\,\varphi)Y,Z)

\displaystyle=N^{(5)}(X,Y,Z),

(72)

\displaystyle 6\,d\Phi

\displaystyle=N^{(5)}(X,Y,Z)+N^{(5)}(Y,Z,X)+N^{(5)}(Z,X,Y),

(73)

\displaystyle 2\,g([\varphi,\varphi](X,Y),Z)

\displaystyle=N^{(5)}(\varphi X,Y,Z)+N^{(5)}(\varphi Y,Z,X)+N^{(5)}(\varphi Z,X,Y).

(74)

Proof.

For a weak almost cosymplectic structure

(75)

From (

Using (

Remark 5.1
.

For a weak cosymplectic structure, using (
72
), we obtain (compare with (

))

\displaystyle 2\,g(Q(\nabla_{X}\,\xi),\,Z)=-N^{(5)}(X,\xi,\varphi Z).

Recall that an almost contact metric structure
(\varphi,\xi,\eta,g)
is cosymplectic if and only if
\varphi
is parallel, e.g.,
[

, Theorem 6.8]
.
The following our theorem completes this result.

Theorem 5.2
.

Any weak almost contact structure
(\varphi,Q,\xi,\eta,g)
with the property
\nabla\varphi=0

is a weak cosymplectic structure with vanishing tensor
N^{(5)}
.

Proof.

Using condition
\nabla\varphi=0
, from (
14
) we obtain
[\varphi,\varphi]=0
.
Hence, from (
11
) we get
N^{(1)}(X,Y)=2\,d\eta(X,Y)Q\xi
, and from (

) we obtain

\displaystyle\nabla_{\varphi X}\,\xi-\varphi\,\nabla_{X}\,\xi=0,\quad X\in\mathfrak{X}_{M}.

(76)

From (
2
), we calculate

3\,d\Phi(X,Y,Z)=g((\nabla_{X}\,\varphi)Z,Y)+g((\nabla_{Y}\,\varphi)X,Z)+g((\nabla_{Z}\,\varphi)Y,X);

hence, using condition
\nabla\varphi=0
again, we get
d\Phi=0
. Next,

\displaystyle N^{(2)}(Y,\xi)=-\eta([\varphi Y,\xi])=g(\xi,\varphi\nabla_{\xi}Y)=0.

Thus, setting
Z=\xi
in Lemma
2.1
and using the condition
\nabla\varphi=0
and the properties

d\Phi=0
,
N^{(2)}(Y,\xi)=0
and
N^{(1)}(X,Y)=2\,d\eta(X,Y)Q\xi
, we find

.
By (

Thus,

Finally, from (

∎

6
Weak contact vector fields

Contact vector fields (and contact infinitesimal transformations) is a fruitful tool in contact manifold geometry.
Here, we are based on some classical results, e.g.,
[
1
, Section 5.2]
.

Definition 6.1
.

A vector field
X
on a weak contact metric manifold
M^{2n+1}(\varphi,Q,\xi,\eta)
is called
a
weak contact vector field

(or, a
weak contact infinitesimal transformation
), if
the flow of
X
preserves
\xi
, i.e., there exists a smooth function
\sigma:M\rightarrow\mathbb{R}
such that

\displaystyle\pounds_{X}\,\eta=\sigma\,\eta,

(77)

and if
\sigma=0
, then the vector field
X
is said to be
strict weak contact vector field
.

The following our result generalizes
[
1
, Theorem 5.7]
.

Theorem 6.1
.

A vector field
X
on a weak contact metric manifold
M^{2n+1}(\varphi,Q,\xi,\eta,g)
is a weak contact infinitesimal transformation
if and only if there exists a function
f
on
M
such that

\displaystyle QX=-\frac{1}{2}\,\varphi\,\nabla f+\nu\,f\,\xi.

(78)

Moreover, a weak contact vector field
X
is strict if and only if
\,\xi(f)
.

Proof.

One can explicitly write
(\pounds_{X}\,\eta)(Y)=X(\eta(Y))-\eta([X,Y])
. Using (
8
), we rewrite (
77
) as

\displaystyle 2\,d\eta(X,Y)+Y(f)=\sigma\,\eta(Y),

(79)

where
f=\eta(X)
. Using (
7
) in (
79
), we get

-2\,g(\varphi X,Y)+Y(f)=\sigma\,\eta(Y)
,
which provides

\displaystyle-2\,\varphi X+\nabla f=\sigma\,\xi.

(80)

Applying
\varphi
and using (
1
), we obtain (
78
).
Multiplying (
80
) by
\xi
gives
\sigma=\xi(f)
.

Conversely, assume the condition (
78
).
The scalar product of (
78
) with
\xi
gives

\nu\,\eta(X)=g(Q\,\xi,X)=\nu\,f;

therefore,
f=\eta(X)
.
Multiplying (
78
) by
\varphi
and using (
1
), gives

Q\,\varphi X=-\frac{1}{2}\,\varphi^{2}(\nabla f)=\frac{1}{2}\,Q\,\nabla f-\frac{1}{2}\,\eta(\nabla f)\,Q\,\xi,

then, using non-degeneracy of
Q
, we get

\displaystyle\nabla f-2\,\varphi X=\eta(\nabla f)\,\xi=\xi(f)\,\xi.

Thus, using (
4
), (
7
) and (
8
), one can calculate

\displaystyle(\pounds_{X}\,\eta)(Y)

\displaystyle=2\,d\eta(X,Y)+Y(\eta(X))=2\,d\eta(QX-\tilde{Q}X,Y)+Y(f)

\displaystyle=2\,g(-\frac{1}{2}\,\varphi\nabla f+f\,\nu\,\xi,\varphi Y)+Y(f)-2\,g(\tilde{Q}X,\varphi Y)

\displaystyle=-g(\varphi\nabla f,\varphi Y)+Y(f)-2\,g(\tilde{Q}X,\varphi Y)

\displaystyle=-(QY)(f)+\nu\,\xi(f)\,\eta(Y)+Y(f)-2\,g(\tilde{Q}X,\varphi Y)

\displaystyle=\nu\,\xi(f)\,\eta(Y)-g(\tilde{Q}(\nabla f-2\,\varphi X),Y)

\displaystyle=\nu\,\xi(f)\,\eta(Y)-(\nu-1)\,\xi(f)\,\eta(Y)=\xi(f)\,\eta(Y).

By this, (
77
) with
\sigma=\xi(f)
is valid.
∎
