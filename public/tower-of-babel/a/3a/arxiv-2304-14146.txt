Introduction

Let
S
be a semigroup. Let
\mathbb{C}
be a field of complex numbers. The sine addition law for unknown functions
f,g:S\longrightarrow\mathbb{C}
is the functional equation

f(xy)=f(x)g(y)+f(y)g(x),\hskip 11.38092ptx,y\in S,

(1.1)

The functional equation (
1.1

[
2
]
,
[
6
]
and
[

The solutions of the functional equation (

[
4

[

and
[

For additional discussions of this functional equation and their history, see
[

In this paper we consider the following Kannappan-sine addition law (

f(xyz_{0})=f(x)g(y)+f(y)g(x),\;x,y\in S,

(1.2)

On a monoid with identity element

[
3

4

2\bigl[\dfrac{f}{\beta}+\dfrac{g}{\alpha}](xy)=[\dfrac{f}{\beta}+\dfrac{g}{\alpha}](x)[\dfrac{f}{\beta}+\dfrac{g}{\alpha}](y)-[\dfrac{-f}{\beta}+\dfrac{g}{\alpha}](x)[\dfrac{-f}{\beta}+\dfrac{g}{\alpha}](y)

[

It should be noted that the traitement above on monoids are used in

We notice also that, when

is in the centre of

, and then the

and as mentioned above their solutions are known, so the contributions
of the present paper to the theory of trigonometric functional equations
in the non-abelian case.

The special case of (
1.2

where
\chi
is exponential function on

The result by Kannappan

and its generalization (see for example
[

]
,
[
10
]
), has been an inspiration
by its treatment of similar functional equations on groups.

Our main goal is to extend

Our main contributions to the knowledge about (

Set up, notations and terminology

Throughout this paper we enforce the set up below.

S
is a semigroup (a set with an associative composition rule) and
z_{0}
is a fixed element in
S
.

If
X
is a
topological space we denote by
C(X)
the algebra of continuous functions
from
X
to the field of complex numbers
\mathbb{C}
. Let
\mathbb{C}^{*}=\setminus\{0\}
.

A map
A:S\longrightarrow\mathbb{C}
is said to be additive if

A(xy)=A(x)+A(y)
for all
x,y\in S
,

and a function
\chi:S\longrightarrow\mathbb{C}
is multiplicative if

\chi(xy)=\chi(x)\chi(y)
for all
x,y\in S.

If
\chi
is multiplicative and
\chi\neq 0

then we call
\chi
an
exponential
. For a multiplicative function
\chi:S\longrightarrow\mathbb{C}
, we define the
null space

I_{\chi}
by

I_{\chi}:=\{x\in S\hskip 2.84544pt|\hskip 2.84544pt\chi(x)=0\}
.

Then
I_{\chi}
is either empty or a proper subset of
S
and
I_{\chi}
is a
two sided ideal in S if not empty and
S\setminus I_{\chi}
is a subsemigroup of
S
.

A function
f:S\longrightarrow\mathbb{C}
is said to be central if
f(xy)=f(yx)
for all
x,y\in S
.
A function
f
is said to be abelian if

f(x_{1}x_{2},...,x_{n})=f(x_{\sigma(1)}x_{\sigma(2)},...,x_{\sigma(n)})

for all

x_{1},x_{2},...,x_{n}\in S
, all permutations
\sigma
of
n
elements and all
n\in\mathbb{N}
.

Note that additive and multiplicative functions are abelian.

For any subset
T\subseteq S
let
T^{2}:=\{xy\hskip 2.84544pt|\hskip 2.84544ptx,y\in T\}
and for any fixed element
z_{0}
in S we let

T^{2}z_{0}:=\{xyz_{0}\hskip 2.84544pt|\hskip 2.84544ptx,y\in T\}
.

To characterize and describe some solutions of our functional equations, we use the partition of the null space
I_{\chi}
into the disjoint union
I_{\chi}=P_{\chi}\cup(I_{\chi}\setminus P_{\chi})
, with

P_{\chi}:=\{p\in I_{\chi}\setminus I_{\chi}^{2}\hskip 2.84544pt|\hskip 2.84544ptup,pv,upv\in I_{\chi}\setminus I_{\chi}^{2}\hskip 2.84544pt\text{for}\hskip 2.84544pt\text{all}\hskip 2.84544ptu,v\in S\setminus I_{\chi}\}.

For more discussions about the partition of the null space
I_{\chi}
we refer to
[
4
]
,
[
5
]
and
[
3
]
. The following lemma will be used later.

Lemma 2.1
.

p\in P_{\chi}\implies up,pv,upv\in P_{\chi}
for all
u,v\in S\setminus I_{\chi}\
.

Proof.

Follows directly from the definition of

To obtain some of the solutions of the functional equation (
1.2
)
we need the solutions of the following functional equation

f(xyz_{0})=f(x)+f(y),\hskip 8.5359ptx,y\in S.

(3.1)

Lemma

) on semigroups.

Lemma 3.2
.

Let
S
be a semigroup. The solutions of the functional equation (
3.1
) are the function
of the form
f=A+A(z_{0})
, where
A:S\longmapsto\mathbb{C}
is additive.

Proof.

Let
x,y,z\in S
be arbitrary. Using (
3.1
) we find that

f((xy)z_{0}^{2}z_{0})=f(xy)+f(z_{0}^{2}).

Similarly we find that

f((xyz_{0})z_{0}z_{0})=f(xyz_{0})+f(z_{0})=f(x)+f(y)+f(z_{0}).

Comparing the previous equations we get that

f(xy)=f(x)+f(y)+[f(z_{0})-f(z_{0}^{2})].

Therefore, we see that
A:=f+[f(z_{0})-f(z_{0}^{2})]
is additive.
Now, using (
3.1
) and the fact that
A
is additive we obtain that

\begin{split}0&=f(xyz_{0})-f(x)-f(y)\\
&=A(xyz_{0})-[f(z_{0})-f(z_{0}^{2})]-(A(x)-[f(z_{0})-f(z_{0}^{2})])\\
&\quad-(A(y)-[f(z_{0})-f(z_{0}^{2})])\\
&=A(z_{0})+[f(z_{0})-f(z_{0}^{2})].\end{split}

Thus
A(z_{0})=-[f(z_{0})-f(z_{0}^{2})]
, and
hence

f=A+A(z_{0})
.
The converse statement is trivial.
This completes the proof of Lemma
3.2

Lemma 4.1
.

Let
S
be a semigroup, and let
f,g:S\longmapsto\mathbb{C}
be a solution of the functional equation (
1.2
). Then we have the following.

(i) If
f(z_{0})=0
then

g(z_{0}^{2})f(xy)=g(z_{0})[f(x)g(y)+f(y)g(x)]-f(z_{0}^{2})g(xy),\hskip 8.5359ptx,y\in S.

(4.1)

(ii) If
f(z_{0})\neq 0
then there exists
\gamma\in\mathbb{C}
such that

g(xyz_{0})=g(x)g(y)+\gamma^{2}f(x)f(y),\hskip 8.5359ptx,y\in S.

(4.2)

Proof.

(i) Let
x,y,z\in

S
be arbitrary. Using (
1.2
) and the fact that
f(z_{0})=0
we have

f((xyz_{0})z_{0}z_{0})=f(xyz_{0})g(z_{0})+f(z_{0})g(xyz_{0})=g(z_{0})[f(x)g(y)+f(y)g(x)]

and

f((xyz_{0})z_{0}z_{0})=f((xy)z_{0}^{2}z_{0})=f(xy)g(z_{0}^{2})+f(z_{0}^{2})g(xy).

Then we deduce that

f(xy)g(z_{0}^{2})+f(z_{0}^{2})g(xy)=g(z_{0})[f(x)g(y)+f(y)g(x)],\hskip 8.5359ptx,y\in S.

This proves (i).

(ii) Let
x,y\in S
be arbitrary. By using (
1.2
) we get

\begin{split}f((xyz_{0})z_{0}z_{0})&=f(xyz_{0})g(z_{0})+f(z_{0})g(xyz_{0})\\
&=g(z_{0})[f(x)g(y)+f(y)g(x)]+f(z_{0})g(xyz_{0})\\
&=g(z_{0})f(x)g(y)+g(z_{0})f(y)g(x)+f(z_{0})g(xyz_{0}).\end{split}

Similarly, we find

\begin{split}f(x(yz_{0}^{2})z_{0})&=f(x)g(yz_{0}^{2})+f(yz_{0}^{2})g(x)\\
&=f(x)g(yz_{0}^{2})+g(x)[f(y)g(z_{0})+f(z_{0})g(y)]\\
&=f(x)g(yz_{0}^{2})+g(z_{0})g(x)f(y)+f(z_{0})g(x)g(y).\end{split}

Then the associativity of the operation in
S
implies

f(z_{0})[g(xyz_{0})-g(x)g(y)]=f(x)[g(yz_{0}^{2})-g(y)g(z_{0})].

(4.3)

Since
f(z_{0})\neq 0
, dividing equation (
4.3
) by
f(z_{0})
we get that

g(xyz_{0})=g(x)g(y)+f(x)\phi(y),

(4.4)

where

\phi(y):=\dfrac{g(yz_{0}^{2})-g(y)g(z_{0})}{f(z_{0})},\hskip 5.69046pty\in S.

Now, substituting (
4.4
) come back into (
4.3
) we get

f(z_{0})[f(x)\phi(y)]=f(x)[f(y)\phi(z_{0})].

By putting
x=z_{0}
in the last equation, we deduce that

\phi(y):=cf(y),
where
c:=\dfrac{\phi(z_{0})}{f(z_{0})}
.

Choosing
\gamma\in\mathbb{C}
such that
\gamma^{2}=c
, equation (
4.4
) becomes

g(xyz_{0})=g(x)g(y)+\gamma^{2}f(x)f(y).

This proves part (ii) and completes the proof of Lemma
4.1
.
∎
