On Topological Bihyperbolic Modules
Soumen Mondal, Chinmay Ghosh, Sanjib Kumar Datta

Abstract
In this paper we introduce topological modules over the ring of bihyperbolic numbers. We discuss bihyperbolic convexity, bihyperbolic-valued seminorms and bihyperbolic-valued Minkowski functionals in topological bihyperbolic modules. Finally we introduce locally bihyperbolic convex modules. AMS Subject Classification (2010) : 30G35, 46A03, 46A19, 52A07. Keywords and phrases : Bihyperbolic modules, Topological bihyperbolic modules, Bihyperbolic convexity, Bihyperbolic-valued seminorms, Bihyperbolic-valued Minkowski functionals, Locally bihyperbolic convex modules.

2
A Review of Bihyperbolic Numbers

In this section we state some basic facts about bihyperbolic numbers.

Bihyperbolic numbers (also called canonical hyperbolic quaternions
or hyperbolic four complex numbers) set is defined by

H_{2}:=\{\zeta=x+y\mathbf{j}_{1}+z\mathbf{j}_{2}+w\mathbf{j}_{3}:x,y,z,w\in\mathbb{R};\mathbf{j}_{1}\mathbf{,j}_{2},\mathbf{j}_{3}\notin\mathbb{R}\}

where the multiplication is given by the following rules

\mathbf{j}_{1}^{2}=\mathbf{j}_{2}^{2}=\mathbf{j}_{3}^{2}=1,\text{ }\mathbf{j}_{1}\mathbf{j}_{2}=\mathbf{j}_{2}\mathbf{j}_{1}=\mathbf{j}_{3},\text{ }\mathbf{j}_{2}\mathbf{j}_{3}=\mathbf{j}_{3}\mathbf{j}_{2}=\mathbf{j}_{1},\text{ }\mathbf{j}_{3}\mathbf{j}_{1}=\mathbf{j}_{1}\mathbf{j}_{3}=\mathbf{j}_{2}.

The canonical form of
\zeta=x+yi+zj+wk

\in H_{2}
is

\zeta=\lambda_{1}(\zeta)\mathbf{e}_{1}+\lambda_{2}(\zeta)\mathbf{e}_{2}+\lambda_{3}(\zeta)\mathbf{e}_{3}+\lambda_{4}(\zeta)\mathbf{e}_{4}

where

\lambda_{1}(\zeta)=(x+y+z+w),\text{ }\lambda_{2}(\zeta)=(x-y+z-w),\text{
}\lambda_{3}(\zeta)=(x+y-z-w),\text{ }\lambda_{4}(\zeta)=(x-y-z+w)

and

\mathbf{e}_{1}=\frac{(1+\mathbf{j}_{1}+\mathbf{j}_{2}+\mathbf{j}_{3})}{4},\text{ }\mathbf{e}_{2}=\frac{(1-\mathbf{j}_{1}+\mathbf{j}_{2}-\mathbf{j}_{3})}{4},\text{ }\mathbf{e}_{3}=\frac{(1+\mathbf{j}_{1}-\mathbf{j}_{2}-\mathbf{j}_{3})}{4},\text{ }\mathbf{e}_{4}=\frac{(1-\mathbf{j}_{1}-\mathbf{j}_{2}+\mathbf{j}_{3})}{4}.

The bihyperbolic numbers
\mathbf{e}_{1},\mathbf{e}_{2},\mathbf{e}_{3},\mathbf{e}_{4}
have the following properties

\mathbf{e}_{i}\mathbf{e}_{j}=\left\{\begin{array}[]{c}0,i\neq j\text{ }\\
\mathbf{e}_{i},i=j\end{array}\right.i,j\in\{1,2,3,4\}

and

\sum\limits_{i=1}^{4}\mathbf{e}_{i}=1.

The ring of bihyperbolic numbers
(H_{2},+,.)
is a commutative ring. The
inverse of a bihyperbolic number
\zeta=x+y\mathbf{j}_{1}+z\mathbf{j}_{2}+w\mathbf{j}_{3}
exist if
\lambda_{k}(\zeta)\neq 0,\forall k=1,2,3,4.
The
set of non-invertible bihyperbolic numbers is called null cone as

NC=\{\zeta:\lambda_{1}(\zeta)\lambda_{2}(\zeta)\lambda_{3}(\zeta)\text{ }\lambda_{4}(\zeta)=0\}.

A non zero bihyperbolic number
\zeta=x+y\mathbf{j}_{1}+z\mathbf{j}_{2}+w\mathbf{j}_{3}
is called zero divisor if there exist a non zero
bihyperbolic number
\zeta^{\prime}=x^{\prime}+y^{\prime}\mathbf{j}_{1}+z^{\prime}\mathbf{j}_{2}+w^{\prime}\mathbf{j}_{3}
such that
\zeta\zeta^{\prime}=0.
Thus zero divisors exist if
\zeta,\zeta^{\prime}

satisfy the following equations

\displaystyle x+y+z+w

\displaystyle=

\displaystyle 0\text{ and }x^{\prime}=y^{\prime}=z^{\prime}=w^{\prime}

or

\displaystyle x-y+z-w

\displaystyle=

\displaystyle 0\text{ and }x^{\prime}=-y^{\prime}=z^{\prime}=-w^{\prime}

or

\displaystyle x+y-z-w

\displaystyle=

\displaystyle 0\text{ and }x^{\prime}=y^{\prime}=-z^{\prime}=-w^{\prime}

or

\displaystyle x-y-z+w

\displaystyle=

\displaystyle 0\text{ and }x^{\prime}=-y^{\prime}=-z^{\prime}=w^{\prime}.

It is easy to verify that the set of zero divisors of the ring
H_{2}
=
NC-\{0\}=NC^{\ast}
(say), where
0=0+0\mathbf{j}_{1}+0\mathbf{j}_{2}+0\mathbf{j}_{3}\in H_{2}.

It is clear that
\mathbf{e}_{i}

(i\in\{1,2,3,4\})
are zero divisors of
the ring
H_{2}.

Thus the sets

H_{2}(\mathbf{e}_{i}):=\mathbf{e}_{i}.H_{2}\text{ ,}i\in\{1,2,3,4\}

are (principal) ideals in the ring
H_{2}
such that

H_{2}(\mathbf{e}_{i})\cap H_{2}(\mathbf{e}_{j})=\phi,\text{ }i\neq j;i,j\in\{1,2,3,4\}.

and
H_{2}
can be decomposed into the following direct sum

H_{2}=H_{2}(\mathbf{e}_{1})\oplus H_{2}(\mathbf{e}_{2})\oplus H_{2}(\mathbf{e}_{3})\oplus H_{2}(\mathbf{e}_{4}).

Observe that

H_{2}(\mathbf{e}_{i})=\{r\mathbf{e}_{i}:r\in\mathbb{R}\}=\mathbb{R}\mathbf{e}_{i},\text{ }i\in\{1,2,3,4\}.

Remark 1

We have the following useful property

(1)

\zeta\in H_{2}(\mathbf{e}_{i})
if and only if
\zeta\mathbf{e}_{i}=\zeta
, for
i\in\{1,2,3,4\}.

(2)

\zeta\in H_{2}(\mathbf{e}_{i})\oplus H_{2}(\mathbf{e}_{j})
if and
only if
\zeta(\mathbf{e}_{i}+\mathbf{e}_{j})=\zeta,
for
i\neq j;

i,j\in\{1,2,3,4\}.

(3)

\zeta\in H_{2}(\mathbf{e}_{i})\oplus H_{2}(\mathbf{e}_{j})\oplus H_{2}(\mathbf{e}_{k})
if and only if
\zeta(\mathbf{e}_{i}+\mathbf{e}_{j}+\mathbf{e}_{k})=\zeta,
for
i\neq j\neq k;

i,j,k\in\{1,2,3,4\}.

The set of non-negative bihyperbolic number is

H_{2}^{+}:=\{\zeta=w_{1}\mathbf{e}_{1}+w_{2}\mathbf{e}_{2}+w_{3}\mathbf{e}_{3}+w_{4}\mathbf{e}_{4}:w_{1},w_{2},w_{3},w_{4}\geq 0\}.

The binary relation on
H_{2}
defined by:

\zeta\preceq\varphi\text{ if and only if }\lambda_{k}(\zeta)\leq\lambda_{k}(\varphi)\text{ for all }k\in\{1,2,3,4\}

is a partial order on
H_{2}.
If we take
\alpha,\beta\in\mathbb{R},
then
\alpha\preceq\beta
if and only if
\alpha\leq\beta.

For
\zeta,\eta,\xi,\vartheta\in H_{2},
it is easy to verify that

(1) If
\zeta\preceq\eta
and
\xi\in H_{2}^{+},
then
\zeta\xi\preceq\eta\xi.

(2) If
\zeta\preceq\eta
and
\xi\preceq\vartheta,
then
\zeta+\xi\preceq\eta+\vartheta.

(3) If
\zeta\preceq\eta,
then
-\eta\preceq-\zeta.

The bihyperbolic-valued modulus of a number
\zeta
is defined by

\left|\zeta\right|=\left|\lambda_{1}(\zeta)\right|\mathbf{e}_{1}+\left|\lambda_{2}(\zeta)\right|\mathbf{e}_{2}+\left|\lambda_{3}(\zeta)\right|\mathbf{e}_{3}+\left|\lambda_{4}(\zeta)\right|\mathbf{e}_{4}.

This satisfies the following properties:

(1)
\left|\zeta\right|=0
if and only if
\zeta=0.

(2)
\left|\zeta\varphi\right|=\left|\zeta\right|.\left|\varphi\right|.

(3)
\left|\zeta+\varphi\right|\preceq\left|\zeta\right|+\left|\varphi\right|
for any
\zeta,\varphi\in H_{2}.

Let
A\subset H_{2},
if there exists
M\in H_{2}^{+}
such that
\left|x\right|\preceq M

\forall x\in A,
we say that
A
is
H_{2}-
bounded set.

If
A\subset H_{2}
is
H_{2}-
bounded from above, then the
H_{2}-
supremum
of
A
is defined as

\sup_{H_{2}}A=\sum\limits_{i=1}^{4}\sup A_{i}\mathbf{e}_{i},

where
A_{i}=\{a_{i}:\sum\limits_{i=1}^{4}a_{i}\mathbf{e}_{i}\in A\}.

Similarly
H_{2}-
infimum of a
H_{2}-
bounded below set
A
is defined as

\inf_{H_{2}}A=\sum\limits_{i=1}^{4}\inf A_{i}\mathbf{e}_{i},

where
A_{i}
are defined as above.

Topological Bihyperbolic Modules

Topological bicomplex modules have been introduced in
[
3
]
. In this
section, we introduce topological bihyperbolic modules, the concept of
balancedness, convexity and absorbedness in bihyperbolic modules and discuss
some of their properties.

Definition 2

Let
X
be a
H_{2}
module and
\tau
be a Hausdorff topology on
X
such
that the operations

(i)

+:X\times X\longrightarrow X
and

(ii)\,

.:H_{2}\times X\longrightarrow X

are continuous. Then the pair
(X,\tau)
is called a topological
bihyperbolic module or topological
H_{2}-
module.

Example 3

Every
H_{2}-
module with
H_{2}-
valued norm is a topological
H_{2}-
module.

Remark 4

Let
(X,\tau)
be a topological
H_{2}-
module. Write

X=\sum\limits_{i=1}^{4}\mathbf{e}_{i}X

where
X_{i}=\mathbf{e}_{i}X
are
\mathbb{R}-
vector spaces. Then
\tau_{l}=\{\mathbf{e}_{l}G:G\in\tau\}
is a
Hausdorff topology on

and so
(X_{l},\tau_{l})
is a topological

Definition 5

Let
X
be a
H_{2}
module and a function
\left\|.\right\|_{H_{2}}:X\longrightarrow H_{2}^{+}
such that

1.\left\|x\right\|_{H_{2}}=0\Leftrightarrow x=0,

2.\left\|\lambda.x\right\|_{H_{2}}=\left|\lambda\right|\left\|x\right\|_{H_{2}}

\forall x\in X,

\forall\lambda\in H_{2},

3.\left\|x+y\right\|_{H_{2}}\preceq\left\|x\right\|_{H_{2}}+\left\|y\right\|_{H_{2}},

is called bihyperbolic-valued or

valued norm on

If
\left\|.\right\|_{i}
are
\mathbb{R}-
valued norm on

for

then

can be endowed

valued norm given by the formula

\left\|x\right\|_{H_{2}}=\left\|\sum\limits_{i=1}^{4}\mathbf{e}_{i}x_{i}\right\|_{H_{2}}=\sum\limits_{i=1}^{4}\left\|x_{i}\right\|_{i}\mathbf{e}_{i}.

Definition 8

Let
B
be a subset of a
H_{2}-
module
X.
Then
B
is called a
H_{2}-
balanced set if for any
x\in B
and
\lambda\in H_{2}
with
\left|\lambda\right|\preceq 1,

\lambda x\in B.

In other words,
\lambda B\subseteq B
for any
\lambda\in H_{2},

\left|\lambda\right|\preceq 1.
It is obvious that if
\ B
is
H_{2}-
balanced set, then
0\in H_{2}.

Theorem 9

Let
B
be a
H_{2}-
balanced subset of a
H_{2}-
module
X.
Then

(i)

\lambda B=B
whenever
\lambda\in H_{2}
with
\left|\lambda\right|=1.

(ii)

\lambda B=\left|\lambda\right|B
for each
\lambda\in H_{2}\backslash NC^{\ast}.

Proof.

(i)
Let
\lambda\in H_{2}
with
\left|\lambda\right|=1.

Since
B
is
H_{2}-
balanced,
\lambda B\subseteq B.
Writing
\lambda=\sum\limits_{i=1}^{4}\lambda_{i}\mathbf{e}_{i},
we have
\left|\lambda_{i}\right|=1
for each
i\in\{1,2,3,4\}.

Therefore

\left|\frac{1}{\lambda}\right|=\frac{1}{\left|\lambda\right|}=\left|\lambda\right|^{-1}=\sum\limits_{i=1}^{4}\left|\lambda_{i}\right|^{-1}\mathbf{e}_{i}=1.

So,

\frac{1}{\lambda}B\subseteq B\Longrightarrow B\subseteq\lambda B.

(ii)
Let
\lambda\in H_{2}\backslash NC^{\ast}.
If
\lambda=0,
then
\lambda B=\left|\lambda\right|B.
Now let
\lambda\neq 0.

Writing
\lambda=\sum\limits_{i=1}^{4}\lambda_{i}\mathbf{e}_{i},
we obtain

\frac{\lambda}{\left|\lambda\right|}=\sum\limits_{i=1}^{4}\frac{\lambda_{i}}{\left|\lambda_{i}\right|}\mathbf{e}_{i}.

Hence

\left|\frac{\lambda}{\left|\lambda\right|}\right|=1.

So by
(i),
we have

\frac{\lambda}{\left|\lambda\right|}B=B\Longrightarrow\lambda B=\left|\lambda\right|B.

Theorem 10

Let
B
be a
H_{2}-
balanced subset of
H_{2}-
module
X.
Then

(i)

\mathbf{e}_{i}B
are balanced sets in
\mathbb{R}-

\mathbf{e}_{i}X

(ii)

\mathbf{e}_{i}B\subset B
for all

Proof.

(i)
Let
x\in\mathbf{e}_{i}B
and
a\in\mathbb{R}
such that
\left|a\right|\leq 1.
Then there exists
x^{\prime}

and
a^{\prime}\in H_{2}
with
\left|a^{\prime}\right|\preceq 1

such that

and

Since
B
is
H_{2}-
balanced,
a^{\prime}x^{\prime}

\in B.
Thus

x^{\prime}\in\mathbf{e}_{i}B,
showing that
\mathbf{e}_{i}B
is balanced set in
\mathbb{R}-
vector space
\mathbf{e}_{i}X.

(ii)
Let
x\in\mathbf{e}_{i}B.
Then there is an
x^{\prime}\in B
such

x=

\mathbf{e}_{i}x^{\prime}.
Since

\lambda x^{\prime}\in B

\left|\lambda\right|\preceq 1.

In particular, taking

we get

Thus
\mathbf{e}_{i}B\subset B.

Definition 11

Let
B
be a subset of a
H_{2}-
module
X.
Then
B
is called a
H_{2}-
convex set if
x,y\in X
and
\lambda\in H_{2}^{+}
satisfying

implies that
\lambda x+(1-\lambda)y\in B.

Definition 12

Let
\{x_{1},x_{2},...,x_{n}\}
be a subset of a
H_{2}-
module
X.
Then
the linear combinations
\sum\limits_{i=1}^{n}a_{i}x_{i}
in which

and
\sum\limits_{i=1}^{n}a_{i}=1
are called

convex
combinations of the

In this terminology, a
H_{2}-
convex is one that contains all its
H_{2}-
convex combinations.

Let
B
be a
H_{2}-

H_{2}-
module
X.
Then

(i)

\mathbf{e}_{i}B
are convex sets in
\mathbb{R}-
vector spaces
\mathbf{e}_{i}X,
for
i\in\{1,2,3,4\}.

(ii)

\mathbf{e}_{i}B\subset B

Take

, then there exist

Theorem 15

Let
B

\mathbf{e}_{i}x_{i},

Hyperbolic-valued Minkowski functionals in hyperbolic modules have been

Definition 33

Let
B
be a
H_{2}-
convex,
H_{2}-
absorbing subset of a
H_{2}-
module
X.
Then the mapping
q_{B}:X\longrightarrow

H_{2}^{+}
defined by

q_{B}(x)=\inf_{H_{2}}\{\alpha\succ 0:x\in\alpha B\},\text{ \ for each }x\in X

is called bihyperbolic-valued gauge or bihyperbolic-valued Minkowski
functional on
B.

Since
B
is
H_{2}-
convex, then by Theorem
15
, we have
B=\sum\limits_{i=1}^{4}\mathbf{e}_{i}B.
Then for
x=\sum\limits_{i=1}^{4}\mathbf{e}_{i}x_{i},

\alpha=\sum\limits_{i=1}^{4}\mathbf{e}_{i}\alpha_{i},

q_{B}
can be written as

q_{B}(x)=\sum\limits_{i=1}^{4}\mathbf{e}_{i}q_{Bi}(x),

where

q_{Bi}(x)=\inf\{\alpha_{i}>0:x_{i}\in\alpha_{i}\mathbf{e}_{i}B\}.

Theorem 34

Let
B
be a
H_{2}-
convex,
H_{2}-
balanced,
H_{2}-
absorbing
subset of a
H_{2}-
module
X.
Then the
H_{2}-
valued gauge
q_{B}
is a
H_{2}-
valued seminorm on
X.

Proof.
Let
x,y\in X
such that
q_{B}(x)=\alpha
and
q_{B}(y)=\gamma.
Then for
any
\epsilon\succ 0,
we have
x\in(\alpha+\epsilon)B
and
y\in(\gamma+\epsilon)B.
Therefore we can find
u,v\in B
such that
x=(\alpha+\epsilon)u
and
y=(\gamma+\epsilon)v.
Observe that
0\prec\frac{(\alpha+\epsilon)}{(\alpha+\gamma+2\epsilon)}\prec 1
and
0\prec\frac{(\gamma+\epsilon)}{(\alpha+\gamma+2\epsilon)}\prec 1.
Therefore, by
H_{2}-
convexity of
B,
we have

\frac{(\alpha+\epsilon)u+(\gamma+\epsilon)v}{(\alpha+\gamma+2\epsilon)}\in B\Longrightarrow(\alpha+\epsilon)u+(\gamma+\epsilon)v\in(\alpha+\gamma+2\epsilon)B

which implies that

x+y\in(\alpha+\gamma+2\epsilon)B.

Letting
\epsilon\longrightarrow 0,
we obtain

q_{B}(x+y)\preceq\alpha+\gamma=q_{B}(x)+q_{B}(y).

We now show that
q_{B}(\lambda x)=\left|\lambda\right|

q_{B}(x)
for each
x\in X
and
\lambda\in H_{2}.

Clearly,
q_{B}(0)=0.
So we assume that
\lambda\in H_{2}\backslash NC.

Since
B
is
H_{2}-
balanced, by Theorem
9
, we have

\displaystyle q_{B}(\lambda x)

\displaystyle=

\displaystyle\inf_{H_{2}}\{\alpha\succ 0:\lambda x\in\alpha B\}

\displaystyle=

\displaystyle\inf_{H_{2}}\left\{\alpha\succ 0:x\in\alpha\left(\frac{1}{\lambda}B\right)\right\}

\displaystyle=

\displaystyle\inf_{H_{2}}\left\{\alpha\succ 0:x\in\alpha\left(\frac{1}{\left|\lambda\right|}B\right)\right\}

\displaystyle=

\displaystyle\left|\lambda\right|\inf_{H_{2}}\left\{\frac{\alpha}{\left|\lambda\right|}\succ 0:x\in\frac{\alpha}{\left|\lambda\right|}B\right\}

\displaystyle=

\displaystyle\left|\lambda\right|q_{B}(x).

Now suppose
\lambda\in NC^{\ast}
such that
\lambda=\lambda_{i}\mathbf{e}_{i}
for
i\in\{1,2,3,4\}.
Since
B
is
H_{2}-
balanced set in
X,
it
follows that
\mathbf{e}_{i}B
is balanced set in
\mathbb{R}-
vector space
\mathbf{e}_{i}X.
Hence

\displaystyle q_{B}(\lambda x)

\displaystyle=

\displaystyle\sum\limits_{l=1}^{4}\mathbf{e}_{l}q_{Bl}(\lambda x)

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\{\alpha_{i}>0:\lambda_{i}x_{i}\in\alpha_{i}\mathbf{e}_{i}B\}

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\left\{\alpha_{i}>0:x_{i}\in\alpha_{i}\left(\frac{1}{\lambda_{i}}\mathbf{e}_{i}B\right)\right\}

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\left\{\alpha_{i}>0:x_{i}\in\alpha_{i}\left(\frac{1}{\left|\lambda_{i}\right|}\mathbf{e}_{i}B\right)\right\}

\displaystyle=

\displaystyle\left|\lambda_{i}\right|\mathbf{e}_{i}\inf\left\{\frac{\alpha_{i}}{\left|\lambda_{i}\right|}>0:x_{i}\in\frac{\alpha_{i}}{\left|\lambda_{i}\right|}\mathbf{e}_{i}B\right\}

\displaystyle=

\displaystyle\left|\lambda_{i}\right|\mathbf{e}_{i}q_{Bi}(x)=\left|\lambda\right|q_{B}(x).

Now suppose
\lambda\in NC^{\ast}
such that
\lambda=\lambda_{i}\mathbf{e}_{i}+\lambda_{j}\mathbf{e}_{j}
for
i\neq j,

i,j\in\{1,2,3,4\}.

Since
B
is
H_{2}-
balanced set in
X,
it follows that
\mathbf{e}_{i}B
,
\mathbf{e}_{j}B
are balanced set in
\mathbb{R}-
vector spaces
\mathbf{e}_{i}X,\mathbf{e}_{j}X
respectively. Hence

\displaystyle q_{B}(\lambda x)

\displaystyle=

\displaystyle\sum\limits_{l=1}^{4}\mathbf{e}_{l}q_{Bl}(\lambda x)

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\{\alpha_{i}>0:\lambda_{i}x_{i}\in\alpha_{i}\mathbf{e}_{i}B\}+\mathbf{e}_{j}\inf\{\alpha_{j}>0:\lambda_{j}x_{j}\in\alpha_{j}\mathbf{e}_{j}B\}

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\left\{\alpha_{i}>0:x_{i}\in\alpha_{i}\left(\frac{1}{\lambda_{i}}\mathbf{e}_{i}B\right)\right\}+\mathbf{e}_{j}\inf\left\{\alpha_{j}>0:x_{j}\in\alpha_{j}\left(\frac{1}{\lambda_{j}}\mathbf{e}_{j}B\right)\right\}

\displaystyle=

\displaystyle\mathbf{e}_{i}\inf\left\{\alpha_{i}>0:x_{i}\in\alpha_{i}\left(\frac{1}{\left|\lambda_{i}\right|}\mathbf{e}_{i}B\right)\right\}+\mathbf{e}_{j}\inf\left\{\alpha_{j}>0:x_{j}\in\alpha_{j}\left(\frac{1}{\left|\lambda_{j}\right|}\mathbf{e}_{j}B\right)\right\}

\displaystyle=

\displaystyle\left|\lambda_{i}\right|\mathbf{e}_{i}\inf\left\{\frac{\alpha_{i}}{\left|\lambda_{i}\right|}>0:x_{i}\in\frac{\alpha_{i}}{\left|\lambda_{i}\right|}\mathbf{e}_{i}B\right\}+\left|\lambda_{j}\right|\mathbf{e}_{j}\inf\left\{\frac{\alpha_{j}}{\left|\lambda_{j}\right|}>0:x_{j}\in\frac{\alpha_{j}}{\left|\lambda_{j}\right|}\mathbf{e}_{j}B\right\}

\displaystyle=

\displaystyle\left|\lambda_{i}\right|\mathbf{e}_{i}q_{Bi}(x)+\left|\lambda_{j}\right|\mathbf{e}_{j}q_{Bj}(x)=\left|\lambda\right|q_{B}(x).

Now suppose
\lambda\in NC^{\ast}
such that
\lambda=\lambda_{i}\mathbf{e}_{i}+\lambda_{j}\mathbf{e}_{j}+\lambda_{k}\mathbf{e}_{k}
for
i\neq j\neq k,

i,j,k\in\{1,2,3,4\}.
Since
B
is
H_{2}-
balanced set in
X,

it follows that
\mathbf{e}_{i}B
,
\mathbf{e}_{j}B,\mathbf{e}_{k}B
are
balanced set in
\mathbb{R}-
vector spaces
\mathbf{e}_{i}X,\mathbf{e}_{j}X
,
\mathbf{e}_{k}X

respectively. Hence by similar technique used as above, we can prove in this
case also

q_{B}(\lambda x)=\left|\lambda\right|q_{B}(x).

This completes the proof.

Definition 39

We define a topology on a
H_{2}-

\mathcal{P}

H_{2}-

For
x\in X
,
\epsilon\succ 0
