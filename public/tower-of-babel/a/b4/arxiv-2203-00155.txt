Performance of Distribution Regression with Doubling Measure under the seek of Closest Point
Ilqar Ramazanli

Abstract
We study the distribution regression problem assuming the distribution of distributions has a doubling measure larger than one. First, we explore the geometry of any distributions that has doubling measure larger than one and build a small theory around it. Then, we show how to utilize this theory to find one of the nearest distributions adaptively and compute the regression value based on these distributions. Finally, we provide the accuracy of the suggested method here and provide the theoretical analysis for it.

Introduction

Distribution regression has been discussed with details in the paper by Barnabas et al
[
1
]
.
Standard regression stands for the problem where
X_{i}
is a vector from
\mathbb{R}^{d}
and it is sampled from a distribution
\mathcal{P}

\displaystyle X_{i}\sim\mathcal{P}

and we are given values

those are corresponding to the value of the regression function in points

:

\displaystyle f(X_{1})\rightarrow Y_{1}

\displaystyle f(X_{2})\rightarrow Y_{2}

\displaystyle f(X_{k})\rightarrow Y_{k}

and we are trying to find the estimation of the value of regression function
f
, for a new value
X
: i.e.
f(X)
.

In distribution regression we are assuming the input argument
P_{i}
itself is probability distribution coming from a distribution of distributions - meta distribution-
\Psi
.

\displaystyle P_{i}\sim\Psi

and we are trying to find the value of the regression function
f
for a new distribution
P
: i.e.
f(P)
.
The main conceptual difference here from the distribution regression is that, we never actually get aware of the underlying distribution
P
or any of
P_{i}
’s.
We only can estimate these distributions from a set of points that are sampled from them.

An example application of this problem would be in a medical setting when we try to detect underlying medical conditions based on parameters we measured in lab tests.
For instance, heart rate, blood pressure, and chemical concentrations in our body changes over time.
Using standard machine learning methods these values would be perceived as fixed vectors, therefore it would follow a natural loss of information.
Hence, approaching these values as distributions reflects the underlying process better than taking them as vectors.

One of the earliest pioneering jobs in this problem has been done by Barnabas et al on
[
1
]
.
The proposed solution in the work is called the Kernel-Kernel method.
The first Kernel keyword stands for the Kernel method that has been used to estimate the underlying distributions.
The second Kernel keyword stands for the Kernel method that has been used to estimate the regression function.

The distribution estimation part has been done with the Kernel method mentioned below:

\displaystyle p_{i}(x)=\frac{1}{n_{i}}\sum_{j=1}^{n_{i}}\frac{1}{b^{k}_{i}}B\Big(\frac{\|x-X_{ij}\|}{b_{i}}\Big)

(1)

where B is an appropriate Kernel function described in the work done by Tsybakov
[
3
]
.
Moreover, the second estimation - regression estimation is done by

\hat{f}(p)=\begin{cases}\frac{\sum_{i}Y_{i}K(\frac{D(P_{i},P)}{h})}{\sum_{i}K(\frac{D(P_{i},P)}{h})},&\text{if }\sum_{i}K(\frac{D(P_{i},P)}{h})>0\\
0,&\text{otherwise}\end{cases}

for a given bandwidth
h
and a kernel function
K
.
The solution has been proposed is statically sampling
m
distributions from the meta distribution:
\Psi
and call them
P_{1},P_{2},\ldots,P_{m}
and oracle their value
f(P_{i})\rightarrow Y_{i}
.
Moreover, to sample
n
many points from each of these distributions and estimate them according to these points.

Moreover, authors had made several assumptions regarding underlying distributions and regression function to prove the results rigorously:

•

f
is Holder continuous

•

The kernel
K
is assymetric boxed and Lipschitz

•

Distribution class is Holder

•

Y
is bounded

In this work, we are only assuming distribution class is holder, with doubling measure and the regression function is Lipschitz.

In this paper, we are taking a slightly different approach to this problem.
For an allowed error bound
\epsilon
, using the theory we build, we are finding how many distributions is enough to guarantee that one of them is close enough to the underlying one.
Then, until the point we find a close enough distribution, we re-sample a new distribution, and sample set of points from each of them to ensure the distance.
Finally, just return the
Y_{i}
that we consider that is close enough to the underlying distribution.

\displaystyle\sum_{j=0}^{i}\frac{1}{2^{i+1}}\mathbb{P}\Big(\frac{1}{2^{j}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{j+1}}\Big)

\displaystyle\leq\sum_{j=0}^{i}\frac{1}{2^{i+1}}\Big(\big[1-\frac{1}{2^{(j+1)d}}\big]^{m}-\big[1-\frac{1}{2^{jd}}\big]^{m}\Big)

Summing both side of the equation with respect to results with the following inequality:

\displaystyle\sum_{i=0}^{\infty}\sum_{j=0}^{i}\frac{1}{2^{i+1}}\mathbb{P}\Big(\frac{1}{2^{j}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{j+1}}\Big)

\displaystyle\leq\sum_{i=0}^{\infty}\sum_{j=0}^{i}\frac{1}{2^{i+1}}\Big(\big[1-\frac{1}{2^{(j+1)d}}\big]^{m}-\big[1-\frac{1}{2^{jd}}\big]^{m}\Big)

Reversing the order of the variables in the sum we get:

\displaystyle\sum_{j=0}^{\infty}\sum_{i=j}^{\infty}\frac{1}{2^{i+1}}\mathbb{P}\Big(\frac{1}{2^{j}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{j+1}}\Big)

\displaystyle\leq\sum_{i=0}^{\infty}\sum_{i=j}^{\infty}\frac{1}{2^{i+1}}\Big(\big[1-\frac{1}{2^{(j+1)d}}\big]^{m}-\big[1-\frac{1}{2^{jd}}\big]^{m}\Big)

We can see the right multiplication for each side of the inequality is constant with respect to
j
which allows us to write summation in the form of:

\displaystyle\sum_{j=0}^{\infty}\mathbb{P}\Big(\frac{1}{2^{j}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{j+1}}\Big)\sum_{i=j}^{\infty}\frac{1}{2^{i+1}}

\displaystyle\leq\sum_{j=0}^{\infty}\Big(\big[1-\frac{1}{2^{(j+1)d}}\big]^{m}-\big[1-\frac{1}{2^{jd}}\big]^{m}\Big)\sum_{i=j}^{\infty}\frac{1}{2^{i+1}}

by replacing
\sum_{i=j}^{\infty}\frac{1}{2^{i+1}}
with
\frac{1}{2^{i}}
we get:

\displaystyle\sum_{j=0}^{\infty}\mathbb{P}\Big(\frac{1}{2^{j}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{j+1}}\Big)\frac{1}{2^{j+1}}

\displaystyle\leq\sum_{i=0}^{\infty}\Big(\big[1-\frac{1}{2^{(j+1)d}}\big]^{m}-\big[1-\frac{1}{2^{jd}}\big]^{m}\Big)\frac{1}{2^{j}}

which is equivalent to lemma statement:

\displaystyle\sum_{i=0}^{\infty}\frac{1}{2^{i}}\mathbb{P}\Big(\frac{1}{2^{i}}>\mathrm{min}\{\|s-\omega\||\omega\in\Omega\}>\frac{1}{2^{i+1}}\Big)

\displaystyle\leq\sum_{i=0}^{\infty}\frac{1}{2^{i}}\Big(\big[1-\frac{1}{2^{(i+1)d}}\big]^{m}-\big[1-\frac{1}{2^{id}}\big]^{m}\Big)

∎

V
Conclusion

Distribution Regression is a generalization of the regression problem of vectors in
\mathbb{R}^{d}
.
The problem has been well studied previously using Kernel-Kernel methods or with kNN algorithm.
In this paper, we mix kNN with the Kernel method and derive algorithm and theoretical analysis, which demonstrates the performance of the algorithm.
It is an interesting open problem how to optimize sample count in the algorithm here even further, and the authors of this paper have ongoing work regarding this optimization.
