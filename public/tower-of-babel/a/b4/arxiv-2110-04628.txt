1.
Introduction

This paper is devoted to the following question arising in Quantum Hydro-Dynamics (QHD): assume that
(\sqrt{\rho},\Lambda)\in H^{1}(\mathbb{R}^{d})\times L^{2}(\mathbb{R}^{d},\mathbb{R}^{d})
are such that
\Lambda=0
when
\rho=0
. The question is under which conditions there exists a wave function
\psi\in H^{1}(\mathbb{R}^{d},\mathbb{C})
such that

(1.1)

\sqrt{\rho}=|\psi|,\quad J=\sqrt{\rho}\Lambda=\Im\big(\bar{\psi}\nabla\psi).

The second equation gives for
\psi=\sqrt{\rho}w
smooth,
|w|=1
, that
i\Lambda=\sqrt{\rho}\bar{w}\nabla w
. The interest for the above question arises because
\rho,J
are obtained as solutions to the QHD system

(1.2)

\begin{cases}\partial_{t}\rho+\dive J=0,\\
{\displaystyle\partial_{t}J+\dive\big(\Lambda\otimes\Lambda+p(\rho)\mathrm{id}\big)=\dive\bigg(\frac{\nabla^{2}\rho}{4}-\nabla\sqrt{\rho}\otimes\nabla\sqrt{\rho}\bigg),}\end{cases}

which is the system of PDE satisfied by the hydrodynamics quantities in (
1.1
) if
\psi\in C(\mathbb{R},H^{1}(\mathbb{R}^{d},\mathbb{C}))
solves the Schrödinger equation

(1.3)

i\partial_{t}\psi=-\frac{1}{2}\Delta\psi+f^{\prime}(|\psi|^{2})\psi,

where

f(\rho)=\rho\int_{\rho*}^{\rho}\frac{p(s)-p(\rho*)}{s^{2}}ds,\quad\rho^{*}\text{ reference density}.

Apart from the 1d case, where a weak solution to (
1.2
) can be constructed and then the wave function
\psi
is recovered (see
[
AMZ21
]
), in the general case one first obtains the solution to (
1.3
) and then shows that the associated hydrodynamics quantities (
1.1
) satisfy (
1.2
); for an overview of the mathematical theory for QHD we refer to
[
AM
]
.

An implication that
(\rho,J)
are derived from a wave function
\psi
is that

(1.4)

\mathrm{curl}\,J=2\nabla\sqrt{\rho}\wedge\Lambda,

which mimics the fact that
\mathrm{curl}\,\nabla\theta=0
. Being this condition a local condition, it is not sufficient for the existence of a wave function
\psi
, as one can see with the elementary example in
\mathbb{R}^{2}

(1.5)

\rho(x)\in C^{1}_{c}(\mathbb{R}^{2}),\rho(0)=0,\qquad J(x)=\rho(x)\frac{\alpha x^{\perp}}{|x|^{2}},\ \alpha\notin\mathbb{Z}.

Indeed (
1.4
) is verified and being
v=\alpha x^{\perp}/|x|^{2}
,
\mathrm{curl}\,v=2\pi\alpha\delta_{0}
, for
\alpha\notin\mathbb{N}
it is impossible to solve

Dw=iwv,

where
Dw
is the differential of the function
w
.

In
[
AMZ
]
the authors present some results which extend the 1d case recontruction of the wave function
\psi
to the case when
x\in\mathbb{R}^{d}
and
\rho,J
are radially symmetric, and more interestingly when
x\in\mathbb{R}^{2}
, the mass
\rho
is continuous and the vacuum set
\{\rho=0\}
is given by isolated points
\{x_{1},x_{2},\dots\}
, and the velocity field
v=J/\rho
is a distribution such that

(1.6)

\mathrm{curl}\,v=2\pi\sum_{j}k_{j}\delta_{x_{j}},\qquad k_{j}\in\mathbb{Z}.

In this case the local function
w(x)
given by
Dw=ivw
(which is obtained by the above curl-free condition) can be extended to a global one because of the
integer circuitation condition
(
1.6
): indeed, considering a single singular point
x_{1}=0

\mathrm{curl}\,v=2\pi k\delta_{0},

one deduce that for all test function
\phi

-\int\nabla^{\perp}\phi\cdot v\mathcal{L}^{2}=2\pi k\phi(0).

In particular (by considering radial function
\psi
, for example) one deduce that for
\mathcal{L}^{1}
-a.e.
r
it holds

(1.7)

\int_{0}^{1}v(\gamma_{r}(t))\cdot\dot{\gamma}_{r}(t)dt=2\pi k,\quad\gamma_{r}(t)=r(\cos(2\pi t),\sin(2\pi t)).

Hence, the local functions
w
can be extended globally, since after a rotation around
x_{1}
the value

(1.8)

w(\gamma_{r}(1))=w(\gamma_{r}(0))e^{i\int_{0}^{1}v(\gamma_{r}(t))\cdot\dot{\gamma}_{r}(t)dt}=w(\gamma_{r}(0))

is the same, and indeed the counterexample (
1.5
) does not satisfy exactly (
1.6
) about the point
x=0
.

With more generality, one can see that the condition (
1.6
) is equivalent to the following. Let
\Gamma(\mathbb{R}^{2})
be the metric space of Lipschitz curves
\gamma:[0,1]\mapsto\mathbb{R}^{2}
with the uniform topology
C_{0}
, and define a
test plan
\pi
as a probability measure such that its evaluation
e(t)_{\sharp}\pi
at time
t
satisfies

\int\phi(x)(e(t)_{\sharp}\pi)(dx)=\int\phi(\gamma(t))\pi(d\gamma)\leq C\int\phi(x)dx,

for all
\phi\geq 0
continuous function. The formula (
1.8
) is then rewritten as follows: for
\pi
-a.e.
\gamma
such that
\gamma(0)=\gamma(1)
(i.e. it is a closed path) it holds

(1.9)

\int_{0}^{1}v(\gamma(t))\cdot\dot{\gamma}(t)dt=2\pi\sum_{j}k_{j}\mathrm{Wi}(\gamma,x_{j})\in 2\pi\mathbb{Z},

where
\mathrm{Wi}(\gamma,x)
is the
winding number
of
\gamma
around
z\notin\gamma([0,1])
. Being the set
\{\rho=0\}
locally finite (or more generally of
\mathcal{H}^{1}
-measure
0
), one can prove that
\pi
-a.e.
\gamma
is not passing through
\{\rho=0\}
, so that for
\pi
-a.e.
\gamma
the winding number
\mathrm{Wi}(\gamma,x_{i})
is defined for all
x_{i}
. The above formula is actually equivalent to the weak formulation (
1.7
) because for sufficiently regular functions the boundary of almost all level sets is the union of closed curves.

Formula (
1.9
) is meaningful in any dimension, and actually even in metric measure spaces, and gives rise to the following questions.

Problem
.

Let
(X,d,\mu)
be a metric measure space (a Polish space with
\mu\in\mathcal{P}(X)
Borel probability measure) and let
v\in L^{2}(T^{*}X)
be a cotangent vector field such that, if
\pi
is a test plan supported on the set of closed curves, then

(1.10)

\int_{0}^{1}v(\gamma(t))\cdot\dot{\gamma}(t)dt\in 2\pi\mathbb{Z}\qquad\text{for $\pi$-a.e. $\gamma$.}

(1)

Is there a function
w\in L^{\infty}(X,\mathbb{S}^{1})
such that its differential satisfies

(1.11)

Dw=iwv\,?

(2)

Assuming moreover that
m
is the ambient measure in
(X,d)
and

(1.12)

\mu=\frac{|f|^{2}m}{\|f\|_{2}^{2}}\quad\text{with}\ f\in W^{1,2}(X,\mathbb{R}),

does the function
fw
belong to
W^{1,2}(X,\mathbb{C})
?

Above and in the following we will use the identification
\{z\in\mathbb{C},|z|=1\}=\mathbb{S}^{1}
, this should not generate confusion. In the case
X=\mathbb{R}^{d}
(or a differentiable manifold) the objects considered in the previous statement are standard, while in Section
3
we recall their definitions for generic metric measure spaces following
[
GP20
]
.

The assumption that
v\in L^{2}(T^{*}X)
is the analog of the requirement
\Lambda=\sqrt{\rho}v\in L^{2}(\mathbb{R}^{d})
in the Euclidean setting. We will call the condition (
1.10
) the
integer circuitation condition
. It is obvious that the opposite is trivial, i.e.
v=-iDw/w
has integer circuitation.

It turns out that in general metric spaces the answer is no, simple because the space may have too few curves and the measure
\mu
may be too singular (Example
6.3
). But in more regular spaces the answer is positive:

Theorem 1.1
.

Assume that
(X,d,m)
has the measure contraction property
MCP(K,N)
(and if branching the ambient measure
m
is the Hausdorff measure
\mathcal{H}^{N}
). Then, for every
f\in W^{1,2}(X,\mathbb{R})
and cotangent vector field
v\in L^{2}(T^{*}X)
w.r.t. the measure
\mu=|f|^{2}m/\|f\|_{2}^{2}
, there exists
w\in L^{\infty}(X,\mathbb{S}^{1})
such that

(1.13)

Dw=iwv\quad\text{and}\quad fw\in W^{1,2}(X,\mathbb{C}).

Moreover, there exists a partition of
\{|f|>0\}
into at most countably many sets
\Omega_{i}
,
m(\Omega_{i})>0
,

\{|f|>0\}=\bigcup_{i\in\mathbb{N}}\Omega_{i},

such that for every function
w^{\prime}
satisfying
Dw=iwv
it holds

\frac{w^{\prime}(x)}{w(x)}=c_{i}\in\mathbb{S}^{1}\quad\text{constant for $m$-a.e. $x\in\Omega_{i}$}.

The second part of the statement is the same as the 1d case, where in every interval such that
\{|f|>0\}
the function
w
is determined up to a constant. Moreover, every Riemann manifold satisfies the assumptions of the theorem.

Before giving an overview of the proof, some comments are in order.

The actual result proved here is more general: the idea is to decompose the space
X
into regions
\{\Omega_{\alpha}\}_{\alpha}
in which a.e. points
x,y\in\Omega_{\alpha}
can be connected by test plans, and in these regions to construct the function
w
by integrating along curves. The technical part is to remove curves
\gamma
which are not ”good” for
v
: either the integral along
\gamma
is not defined or the circuitation (
1.13
) is not integer if
\gamma
is closed. The non technical part is that such a decomposition does not need to be sufficiently regular to decompose the metric measure space
(X,d,m)
into metric measure spaces
(\Omega_{\alpha},d,m_{\alpha})
. Example
6.3
indeed uses the well known construction of the Vitali set to show that the decomposition above does not exist in general. From a measure theoretical point of view, one needs to assume that the partition
\{\Omega_{\alpha}\}_{\alpha}
admits a
strongly consistent disintegration
, i.e. one can write

(1.14)

\mu=\int\mu_{\alpha}\omega(d\alpha)\quad\text{with}\quad\mu_{\alpha}\in\mathcal{P}(\Omega_{\alpha}).

This condition is certainly fullfilled if the partition
\{\Omega_{\alpha}\}_{\alpha}
is countable, and this countability property is true under the assumptions of Theorem
1.1
. It is not clear to us if such a decomposition into these measure-theoretic indecomposable components
\Omega_{\alpha}
has some interests on its own.

Within these setting, the function
v
is not locally integrable, so
\mathrm{curl}\,v
is meaningless even distributionally. On the other hand, as in the example of (
1.5
), the study of
\mathrm{curl}\,\Lambda
does not yield any condition into the existence of the function
w
. It is not clear if there exists some
\mathrm{curl}
-like functional which allows to write the integer circuitation condition in a more PDE point of view, for example identifying the quantum vortex structure on which the rotational part of
v
is concentrated and has
2\pi\mathbb{Z}
-density, as in (
1.6
).

Another question is whether the integer circuitation assumption (
1.10
) is preserved by the flow of (
1.2
). A tautological argument is that since a solution to the QHD system is constructed by means of a wave function
\psi
solving Shcrödinger equation, a posteriori the integer circuitation condition must be compatible with the QHD formulation. Similarly for the study of the identity (
1.4
), it can be shown that the integer circuitation condition is compatible for smooth solutions of (
1.2
). Indeed one rewrites the system (
1.2
) as

(1.15)

\begin{cases}\partial_{t}\rho+v\cdot\nabla\rho=0,\\
{\displaystyle\partial_{t}v+v\cdot\nabla v=\nabla\bigg(\frac{\Delta\sqrt{\rho}}{2\sqrt{\rho}}-f^{\prime}(\rho)\bigg),}\end{cases}

so that both
\rho
and
v
are transported by the same vector field
v
. Hence any curve
\gamma
at time
t
is transported back to a curve
\gamma^{\prime}
at time
0
(being the flow
\dot{X}=v(t,X)
locally smooth), and defining

\gamma_{t}(\alpha)=X(t,\gamma(\alpha))

one has

\begin{split}\frac{d}{dt}\int v(t,\gamma_{t}(\alpha))\cdot\dot{\gamma}_{t}(\alpha)d\alpha\bigg|_{t=0}&=\int\nabla\bigg(-\frac{|v_{0}|^{2}}{2}+\frac{\Delta\sqrt{\rho_{0}}}{2\sqrt{\rho_{0}}}-f^{\prime}(\rho_{0})\bigg)\cdot\dot{\gamma}(\alpha)d\alpha\\
&\quad+\int v_{0}(\gamma(\alpha))\cdot\nabla v_{0}(\gamma(\alpha))\dot{\gamma}(\alpha)d\alpha\\
&=\int\nabla\bigg(\frac{\Delta\sqrt{\rho_{0}}}{2\sqrt{\rho_{0}}}-f^{\prime}(\rho_{0})\bigg)\cdot\dot{\gamma}(\alpha)d\alpha=0.\end{split}

Hence the fact that the l.h.s. of the equation for
v
in (
1.15
) is a gradient yields that the integer circuitation condition is preserved.

The last two remarks (i.e. if one can give a meaning to
\mathrm{curl}\,v
and if the computation above can be performed for nonsmooth solutions) are related to the fundamental question of regularity of the QHD solution, which is echoed by the regularity of the flow of the transport equation with vector field
v
. As far as we know, these questions are completely open in the general case and they are deeply connected to the proof of existence of a solution by purely fluid dynamics techniques.

As a last observation, a completely similar analysis can be done for the question:

given
v\in L^{1}(T^{*}X)
, there exists a function
w
such that
Dw=v
, i.e. the form is exact?

The results and the proof are exactly the same, by replacing the integer circuitation condition with the
circuitation free condition
: if
\pi
is a test plan supported on the set of closed curves, then

(1.16)

\int_{0}^{1}v(\gamma(t))\cdot\dot{\gamma}(t)dt=0\qquad\text{for $\pi$-a.e. $\gamma$.}

1.1.
Sketch of the proof and structure of the paper

In a nutshell, the idea of constructing
w
is the same as for the smooth case: given a value
w(\bar{x})
as some point
\bar{x}
, find
w(x)
by solving the ODE

(1.17)

\frac{d}{dt}w(\gamma(t))=iw(\gamma(t))v(\gamma(t))\cdot\dot{\gamma}(t),\qquad w(\gamma(0))=w(\bar{x}),\ \gamma(0)=\bar{x},\gamma(1)=x.

The integer circuitation condition should take care of the possibility of having multiple curves connecting
\bar{x}
to
x
.

The problem is that all definitions are given in terms of measures, and then one has to consider only the good path, i.e. the ones for which the circuitation condition holds. This difficulty occurs also for
X=\mathbb{R}^{d}
, because of the density
f\in W^{1,2}
. Given a closed curve
\gamma
such that
\gamma(t)=\gamma(s)
for some
0<s<t<1
, it is not even true in general that the restricted closed curve
R_{s,t}\gamma=\gamma\llcorner_{[s,t]}
is of integer circuitation, even if
\gamma
is. The first results (Proposition
3.10
and Theorem
3.12
) state that under the integer circuitation condition (
1.10
) every test plan is concentrated on a set of curves
A_{\pi}
such that every closed curve obtained by patching pieces of finitely many curves of
A_{\pi}
has integer circuitation. In particular, restrictions of curves satisfy (
1.10
). We call the curves obtained by piecing together parts of other curves
subcurve
or
subloops
if closed.

The argument in
\mathbb{R}^{d}
(and in differentiable manifolds) is much easier than the general case in MMS: the case
X=\mathbb{R}^{2}
is particularly straightforward (Section
4
). Indeed, one can use test plans to move mass along the
i
-axis,
i=1,2
, and then construct a finite dimensional map from
\mathbb{R}^{4}
into the set of curves
\Gamma
such that every point in some Cantor-like neighborhood is connected with another one by a specific curve moving first along the
1
-direction and then along the
2
-direction (Lemma
4.1
). The integer circuitation condition and the result of the previous part imply that we can remove a set of measure
0
in
\mathbb{R}^{4}
and the remaining curves have integer circuitation together with the subcurves (Corollary
4.2
). Since by
W^{1,2}
-regularity of the function
f
one can locally assume that
f>1/2
on sufficiently many of these segments, the function
w
can be constructed on this set (which is of positive
\mathcal{L}^{2}
-measure, Lemma
4.3
). This procedure can be repeated in every Lebesgue point of
f
and
Df
, and the different
w
(which are defined up to a constant) can be related with each other by a test plan (if it exists) concentrated on curves with initial points in one set and end points in the other set, making them compatible (Lemma
4.5
). The same analysis can be done in
\mathbb{R}^{d}
,
d\geq 3
, at the expense of a more complicated selection procedure for the curves. Since we will address the problem in general spaces, we will leave this extension to the reader which wants to avoid some measure theoretic arguments used in the remaining parts.

The observation above is that locally one can construct suitable paths which have integer circuitation, where
f>0
. In particular these sets cannot be further divided by just removing a set of measure
0
trajectories of the above plan. The idea is then to find this minimal partition (see Section
5
for the abstract theory, and Section
5.1
for the application to out case).

Given a set of curves
\{\gamma_{\alpha}\}_{\alpha}
, define the minimal (by set inclusion) equivalence relation
E
by requiring that
\gamma_{\alpha}(t)E\gamma_{\alpha}(s)
for all
s,t\in[0,1]
,
\gamma_{\alpha}
(Definition
5.7
). If we have a test plan
\pi
, for every set of curves
A_{\pi}
,
\pi(A_{\pi})=1
, one has clearly different equivalence relations
E^{A_{\pi}}
. However the space
X
is separable, and we use this fact to deduce that there is a set
\bar{A}_{\pi}
such that the equivalence relation
E^{\bar{A}_{\pi}}
is minimal: this means that if
\mathcal{M}^{\bar{A}_{\pi}}
is the family of
\mu
-measurable sets which are saturated w.r.t.
E^{\bar{A}_{\pi}}
, then for all other sets
A_{\pi}
where
\pi
is concentrated there exists a
\mu
-conegligible set where the
\sigma
-algebra generated by
E^{A_{\pi}}
is a subalgebra of
\mathcal{M}^{E^{\bar{A}_{\pi}}}
(Proposition
5.8
). This does not means that every atom of
\mathcal{M}^{\bar{A}_{\pi}}
coincides with an equivalence class of
E^{\bar{A}_{\pi}}
: the situation is completely equivalent to the Vitali set of
[0,1]
, where
E=[0,1]/\mathbb{Q}
and then the
E
-saturated
\mathcal{L}^{1}
-measurable sets have Lebesgue measure
0
or
1
(see Example
6.3
).

Notwithstanding the counterexample right above, the next step we perform is to find a test plan
\bar{\pi}
such that the maximal measure algebra
\mathcal{M}^{\bar{\pi}}
is the minimal among all measure algebras
\mathcal{M}^{\pi}
(Proposition
5.9
). The reason for this analysis is the following: first, being
\mathcal{M}^{\bar{\pi}}
maximal, up to a negligible set the space
X
cannot be further divided into smaller atoms, i.e. the atoms of
\mathcal{M}^{\bar{\pi}}
are the minimal components used by the test plan
\bar{\pi}
. Being
\mathcal{M}^{\bar{\pi}}
minimal among the maximal measure algebras, we deduce that the all others test plans use curves which are contained into atoms of
\mathcal{M}^{\bar{\pi}}
(up to a negligible set as usual, see Corollary
5.11
). These components are in some sense the minimal connected-by-curves components of
(X,\mu)
, in the sense that one cannot find a further decomposition such that all test plans have trajectories concentrated on the atoms of this new refined decomposition.

Unfortunately finding the minimal-maximal
\sigma
-algebra is not sufficient: indeed the problem is that in general the components of the minimal-maximal decomposition do not coincide with the equivalence classes of the generating relation (as observed above, and as Example
6.3
shows). This condition seems essential and it is assumed in the construction of
w
(Assumption
6.1
). In the case of sufficiently regular MMS (in particular
MCP(K,N)
-spaces where the ambient measure is
f\mathcal{H}^{N}
with
f\in W^{1,2}(X,\mathcal{H}^{N})
), it is satisfied (Example
7.2
). Under the assumption that the equivalence classes coincide with the atoms of the measure algebra
\mathcal{M}^{\bar{\pi}}
, the construction is now fairly simple, and follows the line for the
\mathbb{R}^{2}
case: for the test plan
\bar{\pi}
take the set
A^{\bar{\pi}}
such that every subloop is of integer circuitation, choose a Borel section and a Borel function
\omega
on the quotient space and for every

compute
w
by solving the ODE (
1.17
) with initial data
\omega(y)
along a path connecting
y
to
x
, where
y
is the point in Borel section in the equivalence class of
x
(Proposition
6.4
). It is important to note that the existence of such a path follows because we assume that the atoms of the measure algebra coincide with the equivalence classes, or equivalently that the disintegration is strongly consistent (
1.14
). The fact that
\bar{A}^{\bar{\pi}}
is of free circuitation gives that the value
w(x)
is independent of the particular path chosen. The same argument yields that any other solution

is such that
w^{\prime}/w
is constant on the equivalence class (Theorem
6.6
).

The final analysis of the case when
\mu=fm
, with
f\in W^{1,2}(X,m)
is at this point a corollary, once it is assumed that the space
(X,d,m)
has a test plan connecting all points at lest locally (a

, as defined in
[
LV07
]
, see Assumption
7.1
): indeed in this case the equivalence classes have positive measure, and then the disintegration is strongly consistent. Metric measure spaces enough regular satisfy this assumption (Example

). For the existence of

solving (
1.11
), the only thing to verify is that there exists a test plan
\bar{\pi}
satisfying the assumptions of the previous sections, and this is true in these spaces (Lemma

). Finally, to check that

it is enough to prove that that it holds along test plans for

, and this is fairly easy once one have a Borel way of passing from test plans for

to test plans for

and Proposition

).

Notation

d
. A point in
X
will be denoted by
x
. The balls of radius
r
centered at

is denoted as
B^{X}_{r}(x)
, and more generally the

B^{X}_{r}(A)
. The family of compact subsets of a metric space

is denoted by
\mathcal{K}(X)
, and we will use the Hausdorff distance
d_{H}(K_{1},K_{2})
. Countable intersection of open sets are
G_{\delta}
-sets, while countable union of closed sets are
F_{\sigma}
-sets. The projection onto
X
is written as
\mathtt{p}_{X}
, or sometimes
\mathtt{p}_{i}

\mathcal{B}(X)

\sigma

\sigma(\Sigma^{1}_{1})

In case there is no ambiguity, the geodesic connecting
x
to

is

→

[
x

]

: this notation will be used mainly in
\mathbb{R}^{d}
.

A generic function from
X

\lx@glossaries@gls@link{main}{genfunc}{{{}}{\color[rgb]{0,0,1}f}}:X\to Y

\lx@glossaries@gls@link{main}{Graphf}{{{}}{\color[rgb]{0,0,1}\Graph(f)}}=\big\{(x,f(x)),x\in X\big\}\subset X\times Y,

and its range by

\lx@glossaries@gls@link{main}{Rangef}{{{}}{\color[rgb]{0,0,1}f(X)}}=\big\{f(x),x\in X\big\}.

For a (multi-valued) function

we will denote
f(x)
both as the image of

or as the section

. In general this will not generate confusion.

The space of Lipschitz functions
\mathrm{Lip}([0,1];X)
from

into

is denoted by

: we will refer to it as the set of Lipschitz curves on

. Its subset of closed Lipschitz curves (or closed loops or loops for shortness) will be written as

. An element of both sets will be written as

. Explicitly

\Gamma=\Lip([0,1];X),\quad\Gamma_{c}=\Big\{\gamma\in\Lip([0,1];X),\gamma(0)=\gamma(1)\Big\}.

It is known that

is a separable metric space with the

-topology
[

, Theorem 2.4.3]
.

The evaluation map
\lx@glossaries@gls@link{main}{evaluation}{{{}}{\color[rgb]{0,0,1}e(t)}}=e(t,\gamma)
is the map

\Gamma\ni\gamma\mapsto e(t,\gamma)=\gamma(t)\in X.

The restriction operator
R_{s,t}(\gamma)
is defined as the restriction of the curve
\gamma
to the interval
[s,t]\subset[0,1]
,

R_{s,t}(\gamma)(\tau)=\gamma\big((1-\tau)s+\tau t\big),\quad 0\leq s\leq t\leq 1.

The time inversion of a curve is denoted by
R(\gamma)(t)=\gamma(1-t)
.

The metric derivative of
\gamma
is denoted by
\dot{|\gamma|}
. The length of a curve
\gamma\in\Gamma
is defined as

\lx@glossaries@gls@link{main}{Lengthgam}{{{}}{\color[rgb]{0,0,1}L(\gamma)}}=\int_{0}^{1}\dot{|\gamma|}(t)dt.

Given a set
A\subset\Gamma
, we say that
\gamma\in\Gamma
is a sub-curve of

if there are finitely many curves
\gamma_{i}\in A
such that

\Graph\gamma\subset\bigcup_{i}\Graph\gamma_{i}.

The set of all sub-curves of
A
is denoted by
\Gamma_{A}
.

The Lebesgue measure in
\mathbb{R}^{d}
is denoted with
\mathcal{L}^{d}
and the
d
-dimensional Hausdorff measure by
\mathcal{H}^{d}
. Let
\mathcal{P}(X)
be the space of probability measures over
X
and
m
,
\mu
elements of
\mathcal{P}(X)
: in the second part of our analysis
\mu=fm
(and

will be used as ambient probability for the space

), but in the first part we will consider
(X,d,\mu)
as a given metric measure space. The topology on
\mathcal{P}(X)
is the narrow topology. We denote the standard integral spaces by
L^{p}(\mu)
. The push forward of a measure
\mu
by a map
f
is written by
f_{\sharp}\mu
. The disintegration of a probability according to a map
f:X\to Y
will be denoted as

\mu=\int\lx@glossaries@gls@link{main}{muy}{{{}}{\color[rgb]{0,0,1}\mu_{y}}}\varpi,\quad\lx@glossaries@gls@link{main}{varpi}{{{}}{\color[rgb]{0,0,1}\varpi}}=f_{\sharp}\mu.

We will also write
\varpi=\mu\llcorner\mathcal{M}
, where
\mathcal{M}
is the
\sigma
-algebra made of
\mu
-measurable sets saturated w.r.t. the equivalence relation
Ex=f^{-1}(f(x))
.

If

is an equivalence relation, we will write

if

are equivalent, and the equivalence class for

as
Ex
or

. We will not distinguish between

and its graph in the product space. We will often use the letters

for the elements of the quotient space

. The quotient map is considered either as a section of

(i.e. a set

containing a single point for every equivalence class) or as a map
\lx@glossaries@gls@link{main}{quotinetmap}{{{}}{\color[rgb]{0,0,1}\mathtt{e}}}:X\to[0,1]

3.
Settings and basic computations

In this section we introduce the setting for our problem: it is based on the analysis on metric measure space of
[
Gig
,
GP20
]
, with elementary slight variations.

3.1.
Test plans

Definition 3.1
.

A measure
\lx@glossaries@gls@link{main}{pi}{{{}}{\color[rgb]{0,0,1}\pi}}\in\mathcal{P}(\Gamma)
is a
\mu
-admissible test plan
(or
test plan
when the reference measure
\mu
is clear from the context) if for some constant
C
it holds

(3.1)

\int_{0}^{1}e(t)_{\sharp}(\dot{|\gamma|}\eta)dt\leq C\mu.

The set of
\mu
-admissible test plans is denoted by
\mathrm{Adm(\mu)}
, and
C
is called the
compressibility constant
of
\pi
.

The above formula (
3.1
) is equivalent to

\int\bigg[\int_{0}^{1}1\!\!\mathrm{I}_{\gamma(t)\in A}(t,\gamma)\dot{|\gamma|}(t)dt\bigg]\eta(d\gamma)\leq C\mu(A).

It is clear that the above definition is invariant if we reparameterize the curves
\gamma
. In the following we will often consider the parametrization of
\gamma
by length, so that
\dot{|\gamma|}=1
: this is to avoid to write the factor
\dot{|\gamma|}
in many equations. In that case the interval of integration is
[0,L(\gamma)]
, and we will often not specify the interval of integration if clear from the context.

Remark 3.2
.

For the analysis in this work we do not require the conditions

(3.2)

\int\bigg[\int_{0}^{1}\big(\dot{|\gamma|}(t)\big)^{2}dt\bigg]\pi(d\gamma)<\infty,\quad e(t)_{\sharp}\pi\leq C\mu,

see for example
[
GP20
, Definition 2.1.1]
. These assumptions will be analyzed in Proposition
3.9
: here we can just say that since the integer circuitation condition (
1.10
) is required for
\pi
-a.e.
\gamma
and is independent on the parametrization of
\gamma
, it is natural to consider test plans as in Definition
3.1
.

Remark 3.3
.

An admissible test plan
\pi
is given by the constant curves: define the map

X\ni x\mapsto\gamma_{x}\in\Gamma_{c},\qquad\gamma_{x}(t)=x\quad\forall t\in[0,1],

and set

(3.3)

\pi=(\gamma_{x})_{\sharp}(f(x)\mu(dx))

for every
f\in L^{\infty}(\mu)
,
\|f\|_{1}=1
. It is immediate from the definition to see that

\pi(\Gamma)=1,\quad e(t)_{\sharp}\pi=f\mu,

so that it is admissible. In particular the measure defined in (
3.3
) when
f\equiv 1
is denoted with
\hat{\pi}
.

It may happens that these are the only test plans: for example, if
(X,d)
is totally disconnected (or zero dimensional
[
Sri98
, Section 2.2]
), the only Lipschitz curves
\gamma:[0,1]\to X
are the constant ones.

It is immediate to see that if
\pi\in\text{{Adm}}(\mu)
and
\gamma\mapsto(s(\gamma),t(\gamma))
is a Borel function, then
(R_{s,t})_{\sharp}\pi,R_{\sharp}\pi\in\text{{Adm}}(\mu)
because

e(\tau)_{\sharp}\big((R_{s,t})_{\sharp}\pi\big)=\gamma((1-\tau)s(\gamma)+\tau t(\gamma))_{\sharp}\pi,\quad e(\tau)_{\sharp}\big(R_{\sharp}\pi\big)=e(1-\tau)_{\sharp}\pi.

3.2.
Tangent and cotangent bundles

Here we recall the definition of tangent and cotangent bundles in a metric measure space
X
, following the approach of
[
Gig
,
GP20
]
.

Let
S^{1}(X)
be the set of functions
f:X\to\mathbb{R}
with the following property: there exists
g\in L^{1}(X)
such that for all test plan
\pi

f\circ\gamma\ \text{is a.c. $\pi$-a.e. $\gamma$}\quad\wedge\quad e_{\sharp}\bigg(\bigg|\frac{d}{dt}f(\gamma(t))\bigg|\mathcal{L}^{1}\llcorner_{[0,1]}\times\pi\bigg)\leq Cg\mu,

where
C
is the compressibility constant of
\pi
(see (
3.1
)) and
e:[0,1]\times\Gamma\to X
is the evaluation map. The essential infimum of all
g
’s is called the minimal upper gradient
|Df|
.

Let
v
be an element of the cotangent bundle
L^{1}(T^{*}X)
, which can be defined as the
L^{1}(\mu)
-normed
L^{\infty}(\mu)
-modulus closure of the set

\bigcup_{n\in\mathbb{N}}\Big\{\{(\Omega_{i},f_{i})\}_{i=1}^{n},\{\Omega_{i}\}_{i=1}^{n}\ \text{partition of}\ X,\{f_{i}\}_{i=1}^{n}\subset S^{1}(X)\Big\}/\sim

w.r.t. the norm

\big\|\{(\Omega_{i},f_{i})\}_{i=1}^{n}\big\|=\sum_{i}\int_{\Omega_{i}}|Df_{i}|\mu,

where the equivalence relation
\sim
is w.r.t. the above norm, and
|Df|
is the minimal upper gradient (see
[
GP20
, Theorem 4.1.1]
). We can associate to a function
f\in S^{1}(X)
the cotangent vector field
\lx@glossaries@gls@link{main}{df}{{{}}{\color[rgb]{0,0,1}Df}}=(X,f)
, so that

(3.4)

\{(\Omega_{i},f_{i})\}_{i=1}^{n}=\sum_{i=1}^{n}1\!\!\mathrm{I}_{\Omega_{i}}Df_{i}.

The tangent bundle
L^{\infty}(TX)
is defined as the dual
L^{\infty}(\mu)
-normed
L^{\infty}(\mu)
-modulus, i.e. the space of linear functional
L:L^{1}(T^{*}X)\to L^{1}(\mu)
such that for
f\in L^{\infty}(\mu)
,
v\in L^{1}(T^{*}X)

L(fv)=fL(v),\quad\|L\|=\sup_{\|v\|\leq 1}\int|L(v)|\mu<\infty.

The above norm definition gives that the pointwise norm is

|L|=\mathrm{ess\text{-}sup}\big\{L(v),\|v\|\leq 1\big\}\in L^{\infty}(\mu).

If
\pi
is a test plan, then for every simple element
v=\sum_{i}1\!\!\mathrm{I}_{\Omega_{i}}Df_{i}
we can define

(3.5)

\Lambda_{\gamma}(t,v)=\sum_{i}1\!\!\mathrm{I}_{\Omega_{i}}(\gamma(t))\frac{d}{dt}f_{i}(\gamma)(t)\quad(\dot{|\gamma|}=1),

which satisfies by (
3.1
)

\int\bigg[\int_{0}^{L(\gamma)}|\Lambda_{\gamma}(t,v)|dt\bigg]\eta(d\gamma)\leq\sum_{i}C\int_{\Omega_{i}}|Df_{i}|\mu=C\|v\|_{L^{1}(T^{*}X)}.

Hence, being the elements of the form (
3.4
) dense in
L^{1}(T^{*}X)
and
v\mapsto\Lambda_{\gamma}(t,v)
linear, passing to the limit we obtain that for every
v\in L^{1}(T^{*}X)
there exists a unique
L^{1}(\mathcal{L}^{1}\times\pi)
-function
\Lambda_{\gamma}(t,v)
such that

(3.6)

\lx@glossaries@gls@link{main}{Lambda}{{{}}{\color[rgb]{0,0,1}\Lambda_{\gamma}(t,v)}}=\lim_{v_{n}\to v}\Lambda_{\gamma}(t,v_{n}),

where
v_{n}=\sum_{i}1\!\!\mathrm{I}_{\Omega_{i}}Df_{i}
is converging to
v
in
L^{1}(T^{*}X)
, and it satisfies

(3.7)

\|\Lambda_{\cdot}(\cdot,v)\|_{L^{1}(\mathcal{L}^{1}\otimes\pi)}\leq C\|v\|_{L^{1}(T^{*}(X))},\quad\text{$C$ compressibility constant}.

Hence
L^{1}(T^{*}X)\ni v\mapsto\Lambda_{\gamma}(t,v)\in L^{1}(\mathcal{L}^{1}\times\pi)
is linear and continuous.

Remark 3.4
.

The function
\Lambda_{\gamma}(\cdot,v)
depends on
\pi
. Since we are using it only with a test plan which is clear from the context, we will not add the dependence w.r.t.
\pi
in what follows.

We will need the following property of
\Lambda_{\gamma}(t,v)
: we write the proof for completeness.

Lemma 3.5
.

There exists a
\mathcal{L}^{1}\times\pi
-negligble set
N
such that

\gamma(t)=\gamma(s)\quad\Rightarrow\quad\Lambda_{\gamma}(t,v)=\Lambda_{\gamma}(s,v)

for all
s,t\in[0,L(\gamma)]\setminus N(\gamma)
.

In particular, the function
\Lambda_{\gamma}
can be defined as an
L^{1}
-function of
\mathcal{H}^{1}\llcorner_{\gamma(0,L(\gamma))}
.

Proof.

By (
3.7
) we have that if
v_{n}\to v
in
L^{1}(T^{*}X)
then
\Lambda_{\gamma}(t,v_{n})\to\Lambda_{\gamma}(t,v)
in
L^{1}(\mathcal{L}^{1}\times\pi)
, so that up to subsequences it converges
\mathcal{L}^{1}\times\pi
-a.e.. In particular, let
v_{n}\to v
be a sequence of cotangent vector fields in
L^{1}(T^{*}X)
such that the statement is true for each
v_{n}
, and let
N_{n}\subset[0,1]\times\Gamma
be the corresponding
\mathcal{L}^{1}\times\pi
-negligible set such that

\forall s,t\notin N_{n}(\gamma)\ \Big(\gamma(t)=\gamma(s)\ \Rightarrow\ \Lambda_{\gamma}(s,v_{n})=\Lambda_{\gamma}(t,v_{n})\Big).

Clearly the set
N=\cup_{n}N_{n}
is negligible. Since
\Lambda_{\gamma}(t,v_{n})\to\Lambda_{\gamma}(t,v)
up to a subsequence in a
\mathcal{L}^{1}\times\pi
-conegligble set
A\subset\mathbb{R}\times\Gamma
, we obtain that for all
(t,\gamma),(s,\gamma)\in A\setminus N
it holds

\gamma(t)=\gamma(s)\ \Rightarrow\ \Lambda_{\gamma}(s,v)=\Lambda_{\gamma}(t,v).

It is thus sufficient to prove the statement is true for
v
of the form (
3.4
), and in particular for a single
f
.

Define the set of transversal self-intersections

\begin{split}N^{\prime}&=\bigcup_{n}N^{\prime}_{n}\\
&=\bigcup_{n\in\mathbb{N}}\bigg\{(s,\gamma):\exists t\in[0,L(\gamma)]\,\Big(\gamma(s+2^{-n}(-1,1))\cap\gamma(t+2^{-n}(-1,1))=\{\gamma(s)\}=\{\gamma(t)\}\Big)\bigg\}.\end{split}

It is fairly easy to see that for every
\gamma

N^{\prime}_{n}(\gamma)
is finite for every
\gamma
: indeed if
s_{n},t_{n}\in[0,L(\gamma)]
are a sequence of points in the definition of
N^{\prime}_{n}(\gamma)
, then it is clear that
|s_{n}-s_{m}|\vee|t_{n}-t_{m}|\geq 2^{-n}
. Hence
N^{\prime}(\gamma)
is countable and
N^{\prime}
is
\mathcal{L}^{1}\times\pi
-negligible.

For a given
f\in S^{1}(X)
, consider the conegligible set

M=\Big\{(t,\gamma)\notin N^{\prime}:\dot{|\gamma|}(t)\ \text{exists and }f\circ\gamma\ \text{differentiable in $t$}\Big\}.

Note that if
\gamma(s)=\gamma(t)
,
s,t\in M(\gamma)
, then there are sequences
s_{n}\to s,t_{n}\to t
,
s_{n},t_{n}\not=s,t
respectively such that
\gamma(s_{n})=\gamma(t_{n})
: hence by the formula (
3.5
) we deduce that

\frac{d}{dt}f\circ\gamma(t)=\frac{d}{dt}f\circ\gamma(s).

The complement
N=M^{c}
satisfies the statement.
∎

In particular we deduce that

Corollary 3.6
.

For
\pi
-a.e.
\gamma
the function
\Lambda_{\gamma}
depends only on
\gamma(t)
for
\mathcal{L}^{1}
-a.e.
t
, i.e. can be written as a function on
\gamma([0,1])
defined
\mathcal{H}^{1}
-a.e. or equivalently it is a measurable function for the pull-back
\sigma
-algebra
e^{-1}(\gamma)(\mathcal{B}(X))
.

3.3.
The integer circuitation condition

Let
v\in L^{1}(T^{*}X)
and
\Lambda_{\gamma}(t)=\Lambda(t,v)\in L^{1}(\mathcal{L}^{1}\times\pi)
be the corresponding
L^{1}
-function given by (
3.5
): being
v
fixed from now on, for shortness we will not write the dependence w.r.t.
v
. We restate the assumption of integer circuitation (
1.10
) here below.

Assumption 3.7
.

For all test plans
\pi
concentrated on
\Gamma_{c}
it holds

(3.8)

\int_{0}^{1}\Lambda_{\gamma}(t)\dot{|\gamma|}(t)dt\in 2\pi\mathbb{Z}\quad\pi\text{-a.e.}\ \gamma,

i.e.
v
(or
\Lambda
) has
integer circuitation
.

We define

\lx@glossaries@gls@link{main}{InteCirc}{{{}}{\color[rgb]{0,0,1}\mathcal{I}_{c}}}=\bigg\{\gamma\in\Gamma_{c},\int_{0}^{1}\Lambda_{\gamma}(t)\dot{|\gamma|}(t)dt\in 2\pi\mathbb{Z}\bigg\},

so that we can rephrase the above assumption as
\mathcal{I}_{c}
has full
\pi
-measure. Note that as far as we know
\mathcal{I}_{c}
depends on
\pi
, but this should not create confusion being
\pi
fixed in the construction of the function
w
satisfying (
1.11
) (see Section
6
).

An elementary example of an integer circuitation cotangent vector field is given by

v=-i\frac{Df}{f},

where
f\in L^{0}(\mu,\mathbb{S}^{1})
with
|Df|\in L^{1}
: in this case

\Lambda_{\gamma}(t)=-\frac{i}{f}\frac{d}{dt}f\circ\gamma(t)\quad(\dot{|\gamma|}=1),

with
\pi
-a.e.
\gamma
, with
\pi
test plan.

Remark 3.8
.

Another possible condition is to ask that

\int_{0}^{1}\Lambda_{\gamma}(t)\dot{|\gamma|}(t)dt=0\quad\pi\text{-a.e.}\ \gamma.

In this case we are looking for functions whose differential along
\gamma
is
\Lambda_{\gamma}
, i.e.
v=Df
is exact: we will say that every admissible
\pi
has
0
circuitation
or it is
circuitation free
. The analysis of this situation is completely similar to the case we are considering in the following, so the same constructions apply.

For completeness we show that we can restrict the set of test plans to a more tame one.

Proposition 3.9
.

Assume that Assumption
3.7
holds only for test plans which satisfy

L(\gamma)\in L^{\infty}(\pi),\quad e(t)_{\sharp}\pi\leq C\mu,

Then Assumption
3.7
holds for all test plans.

Proof.

Let
\pi\in\text{{Adm}}(\mu)
be a test plan supported on
\Gamma_{c}
as in Definition
3.1
.

Since Assumption
3.7
is invariant for countable unions of test plans, we can assume that
\pi
is concentrated on curves with length
L(\gamma)\in(\bar{L},\bar{L}+1)
,
\bar{L}
fixed, and we thus consider the pameterization

L(\gamma\llcorner_{[0,t]})=L(\gamma)t.

In this case Condition (
3.1
) implies

\int_{0}^{1}e(t)_{\sharp}\pi\leq\frac{C}{\bar{L}}\mu=C^{\prime}\mu.

Hence for all
\delta t>0
the measure
\pi^{\prime}
defined by

\pi^{\prime}=\fint_{0}^{\delta}\big[(\gamma^{\epsilon})_{\sharp}\pi\big]d\epsilon,\quad\gamma^{\epsilon}(t)=\gamma(\epsilon+t\mod L(\gamma)),

is supported on
\Gamma_{c}
and satisfies
\bar{L}\leq L(\gamma)\leq\bar{L}+1
and

e(t)_{\sharp}\pi^{\prime}=\fint_{t}^{\delta+t}\big[e(s)_{\sharp}\pi\big]ds\leq\frac{C^{\prime}}{\delta}\mu,

where for simplicity we assume that
0\leq t\leq\bar{L}-\delta
. The assumptions on the proposition thus imply that Assumption
3.7
holds for
\pi^{\prime}
-a.e.
\gamma
, and by Corollary
3.6

\Lambda_{\gamma^{\epsilon}}(t)=\Lambda_{\gamma}(t+\epsilon\mod L(\gamma)),

so that we conclude that
\pi
satisfies Assumption
3.7
.
∎

3.4.
Intersection properties of curves

By definition, any test plan
\pi
supported on
\Gamma_{c}
is concentrated on the set of curves such that

\int_{0}^{L(\gamma)}\Lambda_{\gamma}(t)dt\in 2\pi\mathbb{Z}.

However a priori nothing is said about properties of intersecting curve: for example, given two curves
\gamma,\gamma^{\prime}
such that

(3.9)

\gamma(s)=\gamma^{\prime}(s^{\prime}),\ \gamma(t)=\gamma^{\prime}(t^{\prime}),\quad s\leq t,s^{\prime}\leq t^{\prime},

one can construct a closed curve
\gamma^{\prime\prime}
by setting

(3.10)

\gamma^{\prime\prime}(\tau)=\begin{cases}R_{s,t}(\gamma)(2\tau)&\tau\in[0,1/2],\\
R_{1-t^{\prime},1-s^{\prime}}(R(\gamma^{\prime}))(2\tau-1)&\tau\in(1/2,1],\end{cases}

i.e. moving from
\gamma(s)
to
\gamma(t)=\gamma^{\prime}(t^{\prime})
along
\gamma(\tau)
and then returning to
\gamma^{\prime}(s^{\prime})=\gamma(s)
along
\gamma(-\tau)
. We will use the above construction (i.e. a new closed curve obtained by piecing together parts of other curves) to show that we can also require

\int_{0}^{1}\Lambda(\gamma^{\prime\prime})(\tau)\dot{|\gamma^{\prime\prime}|}(\tau)d\tau\in 2\pi\mathbb{Z}

by removing a
\pi
-negligible set of trajectories, where
\gamma^{\prime\prime}
is the curve constructed above.

We first start with self-intersecting curves.

Proposition 3.10
.

Let
\Lambda
be of integer circuitation. Every
\pi\in\text{{Adm}}(\mu)
supported on
\Gamma_{c}
is concentrated on a set of closed curves
A_{\pi}
such that if
\gamma(s)=\gamma(t)
then
R_{s,t}(\gamma)
has integer circuitation.

Proof.

The proof is given in 3 steps.

Step 1: construction of a countable Borel set of loops.

The following argument is the same as in
[
Sri98
, Proposition 5.2.7]
: we give it for completeness. The set

F=\big\{(\gamma,s,t):\gamma(s)=\gamma(t)\big\}\subset\Gamma_{c}\times[0,1]^{2}

is closed, and moreover

\Big\{\gamma:\gamma(s)=\gamma(t)\ \text{for some}\ (s,t)\in\bar{B}^{2}_{r}((\bar{s},\bar{t}))\Big\}

is closed in
\Gamma
. Hence
F:\Gamma_{c}\to[0,1]^{2}
is a Borel measurable multifunction with
F(\gamma)
closed. For every
\bar{B}^{2}_{2^{-k}}((\bar{s}_{m},\bar{t}_{m}))
,
s_{m},t_{m}\in\mathbb{Q}
and
k\in\mathbb{N}
, there is a Borel selection
[
Sri98
, Theorem 5.2.1]

L_{k,m}:A_{k,m}=F^{-1}(\bar{B}^{2}_{2^{-k}}((\bar{s}_{m},\bar{t}_{m})))\to[0,1]^{2},\quad L_{k,m}(\gamma)=(s_{k,m},t_{k,m})\in F(\gamma)\cap\bar{B}^{2}_{2^{-k}}((\bar{s}_{m},\bar{t}_{m})),

By construction, the graphs of the functions
L_{k,m}
are dense in
F(\gamma)
for each
\gamma
, i.e.

F(\gamma)=\clos\big\{L_{k,m}(\gamma),\gamma\in A_{k,m}\big\}.

By reordering, we will denote the functions

Step 2: negligibility of the set of bad loops.

The previous point gives that

Theorem 3.12

Let

The proof is given in two steps. The first one illustrates the procedure in a simple case, while the second is the general case.

Step 1: the case of two curves.

Consider the set

and its closed subset

\mathcal{C}(2)=\Big\{(\gamma_{1},\gamma_{2})\in(\Gamma_{c})^{2}:\gamma_{1}([0,1])\cap\gamma_{2}([0,1])\not=\emptyset\Big\}.

In particular the multifunction

with graph

[
Sri98

\gamma^{\prime}(\gamma_{1},\gamma_{2};t)=\begin{cases}\gamma_{1}(2t)&t\in[0,t_{1}/2]\\
\gamma_{2}(t_{2}+2t-t_{1}\mod 1)&t\in(t_{1}/2,t_{1}/2+1/2),\\
\gamma_{1}(2t-1)&t\in[t_{1}/2+1/2,1].\end{cases}

Clearly the map

Assumption 7.1

Example 7.2

The above condition holds for example for

More generally, it holds in non-branching metric measure space under the Measure Contraction Property

[

LV07

In the case of branching spaces, the same condition holds if (locally, being all computations done in a small ball)

To prove this fact, consider any ball
