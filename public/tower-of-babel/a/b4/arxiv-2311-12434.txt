Abstract
. In this paper we improve and complement a result by Móricz and Siddiqi [ 8 ] . In particular, we prove that their inequality of the Nörlund means with respect to the Walsh system holds also without their additional condition. Moreover, we prove some new approximation results and inequalities in Lebesgue spaces for any 1 ≤ p < ∞ 1\leq p<\infty .

42C10, 42B30.

Walsh group, Walsh system, Fejér means, Nörlund means, approximation, inequalities.

Introduction

Concerning some definitions and notations used in this introduction we refer to Section 2.
Fejér’s theorem shows that (see e.g.
[
2
]
and
[
6
]
) if one replaces ordinary summation by Fejér means
\sigma_{n},
defined by

\sigma_{n}f:=\frac{1}{n}\sum_{k=1}^{n}S_{k}f,

then, for any
1\leq p\leq\infty,
there exists an absolute constant
C_{p},
depending only on
p
such that the inequality

\left\|\sigma_{n}f\right\|_{p}\leq C_{p}\left\|f\right\|_{p}

holds.
Moreover, (see e.g.
[
12
]
) let
1\leq p\leq\infty
,
2^{N}\leq n<2^{N+1}
,
f\in L^{p}(G)
and
n\in\mathbb{N}.
Then the following inequality holds:

(1)

\displaystyle\left\|\sigma_{n}f-f\right\|_{p}\leq 3\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right).

It follows that if
f\in lip\left(\alpha,p\right),
i.e.

\omega_{p}\left(1/2^{n},f\right)=O\left(1/2^{n\alpha}\right),\ \text{as}\ n\rightarrow\infty,

then

\left\|\sigma_{n}f-f\right\|_{p}=\left\{\begin{array}[]{c}O\left(1/2^{N}\right),\text{ \ \ \ if \ \ \ }\alpha>1,\\
O\left(N/2^{N}\right),\text{ \ \ \ if \ \ \ }\alpha=1,\\
O\left(1/2^{N\alpha}\right),\text{ \ \ \ \ \ \ \ if }\alpha<1.\end{array}\right.

Moreover, (see
[
12
]
) if
1\leq p<\infty,

f\in L^{p}(G)
and

\left\|\sigma_{2^{n}}f-f\right\|_{p}=o\left(1/2^{n}\right),\ \text{as}\ n\rightarrow\infty,

then
f
is a constant function.

Boundedness of maximal operators of Vilenkin-Fejer means and weak-
(1,1)
type inequality

\mu\left(\sigma^{*}f>\lambda\right)\leq\frac{c}{\lambda}\left\|f\right\|_{1},\text{ \qquad}\left(f\in L_{1}(G),\ \ \lambda>0\right)

can be found in Zygmund
[
17
]
for trigonometric series, in Schipp

[
13
]
for Walsh series and in Pál, Simon
[
10
]
and Weisz
[
15
,

]
for bounded Vilenkin
series.

n=2^{j}+k,

and

(q_{k},k\in\mathbb{N})
is non-increasing.

2.
Preliminaries

Let
\mathbb{N}_{+}
denote the set of the positive integers,
\mathbb{N}:=\mathbb{N}_{+}\cup\{0\}.
Denote by

Z_{2}:=\{0,1\}

the additive group of integers modulo
2.

Define the group
G
as the complete direct product of the group
Z_{2}
with the product of the discrete topologies of
Z_{2}\textrm{'s}
.
The direct product
\mu
of the measures

\mu^{*}(\left(\{j\}\right):=1/2\text{ \ }(j\in Z_{2})

is the Haar measure on
G
with
\mu\left(G\right)=1.

The elements of
G
are represented by the sequences

x:=(x_{0},x_{1},\dots,x_{k},\dots)\qquad\left(\text{ }x_{k}\in Z_{2}\right).

It is easy to give a base for the neighborhood of
G
, namely

\displaystyle I_{0}\left(x\right):=G,\ \ \ I_{n}(x):=\{y\in G\mid y_{0}=x_{0},\dots,y_{n-1}=x_{n-1}\}\text{ }(x\in G,\text{ }n\in\mathbb{N}).

Denote
I_{n}(0)
by
I_{n}
i.e
I_{n}:=I_{n}(0).
It is well-known that every
n\in\mathbb{N}
can be uniquely expressed as

n=\sum_{k=0}^{\infty}n_{j}2^{j},\ \ \ \text{where }\ \ \ n_{j}\in Z_{2}\ \ \ (j\in\mathbb{N})

and only a finite number of
n_{j}`
s differ from zero.

First define the Rademacher functions as

r_{k}\left(x\right):={(-1)}^{x_{k}},\text{ \ \ }\left(k\in\mathbb{N}\right).

Now we define the Walsh system
w:=(w_{n}:n\in\mathbb{N})
on
G
as

w_{n}\left(x\right):=\prod_{k=0}^{\infty}r_{k}^{n_{k}}\left(x\right)\text{ \quad}\left(n\in\mathbb{N}\right).

The Walsh system is orthonormal and complete in
L^{2}\left(G\right)\,
(see e.g.
[
14
]
).

If
f\in L^{1}\left(G\right)
, then we can define the Fourier
coefficients, the partial sums of the Fourier series, the Fejér means, the Dirichlet and Fejér kernels
with respect to the Walsh system in
the usual manner:

\displaystyle\widehat{f}\left(k\right)

\displaystyle:

\displaystyle=\int_{G}fw_{k}d\mu,\,\text{\quad}\left(k\in\mathbb{N}\right),

\displaystyle S_{n}f

\displaystyle:

\displaystyle=\sum_{k=0}^{n-1}\widehat{f}\left(k\right)w_{k},\text{
\quad}\left(n\in\mathbb{N}_{+},\text{ }S_{0}f:=0\right),

\displaystyle\sigma_{n}f

\displaystyle:

\displaystyle=\frac{1}{n}\sum_{k=1}^{n}S_{k}f,\text{ \quad\ \ }\left(n\in\mathbb{N}_{+}\right).

\displaystyle D_{n}

\displaystyle:

\displaystyle=\sum_{k=0}^{n-1}\psi_{k},\text{ \quad\ \ }\left(n\in\mathbb{N}_{+}\right).

\displaystyle K_{n}

\displaystyle:

\displaystyle=\frac{1}{n}\sum_{k=1}^{n}D_{k},\text{ \quad\ \ }\left(n\in\mathbb{N}_{+}\right).\

Recall that for Dirichlet and Fejér kernels
D_{n}
and
K_{n}
we have that (see e.g.
[
2
]
)

(4)

\quad\hskip 0.0ptD_{2^{n}}\left(x\right)=\left\{\begin{array}[]{l}\text{ }2^{n},\text{\thinspace\thinspace\thinspace if\thinspace\thinspace}x\in I_{n},\\
\text{ }0,\text{\thinspace\thinspace\thinspace\thinspace\thinspace\thinspace\thinspace\thinspace if
\thinspace\thinspace}x\notin I_{n},\end{array}\right.

(5)

D_{2^{n}-m}\left(x\right)=D_{2^{n}}\left(x\right)-w_{2^{n}-1}\left(x\right){{D}_{m}}\left(x\right),\,\,\,0\leq m<{2^{n}}

(6)

n\left|K_{n}\right|\leq 3\sum_{l=0}^{|n|}2^{l}\left|K_{2^{l}}\right|,

where
|n|=:\max\{j\in\mathbb{N},n_{j}\neq 0\}
and

(7)

\displaystyle\int_{G}K_{n}(x)d\mu(x)=1,\ \ \ \ \ \sup_{n\in\mathbb{N}}\int_{G}\left|K_{n}(x)\right|d\mu(x)\leq 2.

Moreover, if
n>t,

t,n\in\mathbb{N},
then

(8)

K_{2^{n}}\left(x\right)=\left\{\begin{array}[]{ll}2^{t-1},&x\in I_{t}\backslash I_{t+1},\quad x-e_{t}\in I_{n},\\
\frac{2^{n}+1}{2},&x\in I_{n},\\
0,&\text{otherwise.}\end{array}\right.

The
n
-th Nörlund mean
t_{n}
of the Fourier series of
f
is defined by

(9)

t_{n}f:=\frac{1}{Q_{n}}\overset{n}{\underset{k=1}{\sum}}q_{n-k}S_{k}f,\ \ \ \text{where }\ \ \ Q_{n}:=\sum_{k=0}^{n-1}q_{k}.

Here
\{q_{k}:k\geq 0\}
is a sequence of nonnegative numbers, where
q_{0}>0
and

\lim_{n\rightarrow\infty}Q_{n}=\infty.

Then the summability method (
9
) generated by
\{q_{k}:k\geq 0\}
is regular if and only if (see
[
7
]
)

\underset{n\rightarrow\infty}{\lim}\frac{q_{n-1}}{Q_{n}}=0.

The representation

t_{n}f\left(x\right)=\underset{G}{\int}f\left(t\right)F_{n}\left(x-t\right)d\mu\left(t\right)

play central roles in the sequel, where

(10)

F_{n}=:\frac{1}{Q_{n}}\overset{n}{\underset{k=1}{\sum}}q_{n-k}D_{k}

is called the kernels of the Nörlund means.

It is well-known (see e.g.
[
12
]
) that every Nörlund summability method generated by non-increasing sequence
(q_{k},k\in\mathbb{N})
is regular, but Nörlund means generated by non-decreasing sequence
(q_{k},k\in\mathbb{N})
is not always regular. In this paper we investigate regular Nörlund means only.

If we invoke Abel transformation we get the following identities:

(11)

\displaystyle Q_{n}:=\overset{n-1}{\underset{j=0}{\sum}}q_{j}=\overset{n}{\underset{j=1}{\sum}}q_{n-j}\cdot 1=\overset{n-1}{\underset{j=1}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j+q_{0}n

and

(12)

t_{n}f=\frac{1}{Q_{n}}\left(\overset{n-1}{\underset{j=1}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\sigma_{j}f+q_{0}n\sigma_{n}f\right).

3.
Main Results

Based on estimate (
1
) we can prove our first main results:

Theorem 1
.

Let
2^{N}\leq n<2^{N+1}
and
{{t}_{n}}
be a regular Nörlund mean generated by non-decreasing sequence
\{q_{k}:k\in\mathbb{N}\},
in sign
q_{k}\uparrow.
Then, for any
f\in L^{p}(G),
where
1\leq p<\infty,
the following inequality holds:

\|t_{n}f-f\|_{p}\leq\frac{18}{Q_{n}}\sum_{i=0}^{N-1}2^{i}q_{n-2^{i}}\omega_{p}\left(\frac{1}{2^{i}},f\right)+12\omega_{p}\left(\frac{1}{2^{N}},f\right).

Proof.

Let
2^{N}\leq n<2^{N+1}.
Since
t_{n}
are regular Nörlund means, generated by sequences of non-decreasing numbers
\{q_{k}:k\in\mathbb{N}\}
by combining (
11
) and (
12
), we can conclude that

\displaystyle\|t_{n}f(x)-f(x)\|_{p}

\displaystyle\leq

\displaystyle\frac{1}{Q_{n}}\left(\overset{n-1}{\underset{j=1}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}+q_{0}n\|\sigma_{n}f(x)-f(x)\|_{p}\right)

\displaystyle:=

\displaystyle I+II,

Furthermore,

\displaystyle I

\displaystyle=

\displaystyle\frac{1}{Q_{n}}\overset{2^{N}-1}{\underset{j=1}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}

\displaystyle+

\displaystyle\frac{1}{Q_{n}}\overset{n-1}{\underset{j=2^{N}}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}:=I_{1}+I_{2}.

Now we estimate each terms separately. By using (
1
) for
I_{1}
we obtain that

(13)

\displaystyle I_{1}

\displaystyle\leq

\displaystyle\frac{3}{Q_{n}}\overset{N-1}{\underset{k=0}{\sum}}\overset{2^{k+1}-1}{\underset{j=2^{k}}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\sum_{s=0}^{k}\frac{2^{s}}{2^{k}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{3}{Q_{n}}\overset{N-1}{\underset{k=0}{\sum}}2^{k+1}\overset{2^{k+1}-1}{\underset{j=2^{k}}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)\sum_{s=0}^{k}\frac{2^{s}}{2^{k}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{6}{Q_{n}}\overset{N-1}{\underset{k=0}{\sum}}\left(q_{n-2^{k}}-q_{n-2^{k+1}}\right)\sum_{s=0}^{k}2^{s}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{6}{Q_{n}}\overset{N-1}{\underset{s=0}{\sum}}2^{s}\omega_{p}\left(1/2^{s},f\right)\sum_{k=s}^{N-1}\left(q_{n-2^{k}}-q_{n-2^{k+1}}\right)

\displaystyle\leq

\displaystyle\frac{6}{Q_{n}}\overset{N-1}{\underset{s=0}{\sum}}2^{s}q_{n-2^{s}}\omega_{p}\left(1/2^{s},f\right).

It is evident that

(14)

\displaystyle I_{2}

\displaystyle\leq

\displaystyle\frac{3}{Q_{n}}\overset{n-1}{\underset{j=2^{N}}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)j\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{3\cdot 2^{N+1}}{Q_{n}}\overset{n-1}{\underset{j=2^{N}}{\sum}}\left(q_{n-j}-q_{n-j-1}\right)\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{6q_{n-2^{N}}}{Q_{n}}\sum_{s=0}^{N}2^{s}\omega_{p}\left(1/2^{s},f\right)\leq\frac{6}{Q_{n}}\overset{N}{\underset{s=0}{\sum}}2^{s}q_{n-2^{s}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{6}{Q_{n}}\overset{N-1}{\underset{s=0}{\sum}}2^{s}q_{n-2^{s}}\omega_{p}\left(1/2^{s},f\right)+6\omega_{p}\left(1/2^{N},f\right).

For
II
we have that

\displaystyle II\leq\frac{3q_{0}2^{N+1}}{Q_{n}}\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)\leq\frac{6}{Q_{n}}\sum_{s=0}^{N-1}2^{s}q_{n-2^{s}}\omega_{p}\left(1/2^{s},f\right)+6\omega_{p}\left(1/2^{N},f\right).

The proof is complete.
∎

Our next main result reads:

Theorem 2
.

Let
{{t}_{n}}
be Nörlund mean generated by a non-increasing sequence
\{q_{k}:k\in\mathbb{N}\}
, in sign
q_{k}\downarrow
.
Then, for any
f\in L^{p}(G),
where
1\leq p<\infty,
the inequality

\displaystyle\|t_{2^{n}}f-f\|_{p}\leq\sum_{s=0}^{n-1}\frac{2^{s}}{2^{n}}\omega_{p}\left(1/2^{s},f\right)+3\overset{n-1}{\underset{s=0}{\sum}}\frac{n-s}{2^{n-s}}\frac{q_{2^{s}}}{q_{2^{n}}}\omega_{p}\left(1/2^{s},f\right)+3\omega_{p}\left(1/2^{n},f\right)

holds.

Proof.

By using (
5
) we find that

(15)

\displaystyle t_{2^{n}}f=D_{2^{n}}\ast f-\frac{1}{Q_{2^{n}}}\overset{2^{n}-1}{\underset{k=0}{\sum}}q_{k}\left(\left(w_{2^{n}-1}D_{k}\right)\ast f\right).

By using Abel transformation we get that

(16)

\displaystyle t_{2^{n}}f

\displaystyle=

\displaystyle D_{2^{n}}\ast f-\frac{1}{Q_{2^{n}}}\overset{2^{n}-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j((w_{2^{n}-1}K_{j})\ast f)

\displaystyle-

\displaystyle\frac{1}{Q_{2^{n}}}q_{2^{n}-1}(2^{n}-1)(w_{2^{n}-1}K_{2^{n}-1}\ast f)

\displaystyle=

\displaystyle D_{2^{n}}\ast f-\frac{1}{Q_{2^{n}}}\overset{2^{n}-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j((w_{2^{n}-1}K_{j})\ast f)

\displaystyle-

\displaystyle\frac{1}{Q_{2^{n}}}q_{2^{n}-1}2^{n}(w_{2^{n}-1}K_{2^{n}}\ast f)

\displaystyle+

\displaystyle\frac{q_{2^{n}-1}}{Q_{2^{n}}}(w_{2^{n}-1}D_{2^{n}}\ast f)

and

(17)

\displaystyle t_{2^{n}}f(x)-f(x)=\int_{G}(f(x+t)-f(x))D_{2^{n}}(t)dt

\displaystyle-

\displaystyle\frac{1}{Q_{2^{n}}}\overset{2^{n}-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\int_{G}\left(f(x+t)-f(x)\right)w_{2^{n}-1}(t)K_{j}(t)dt

\displaystyle-

\displaystyle\frac{1}{Q_{2^{n}}}q_{2^{n}-1}2^{n}\int_{G}(f(x+t)-f(x))w_{2^{n}-1}(t)K_{2^{n}}(t)dt

\displaystyle+

\displaystyle\frac{q_{2^{n}-1}}{Q_{2^{n}}}\int_{G}(f(x+t)-f(x))w_{2^{n}-1}(t)D_{2^{n}}(t)dt

\displaystyle:=

\displaystyle I+II+III+IV.

4
) we find that

\|I\|_{p}\leq\int_{I_{n}}\|f(x+t)-f(x))\|_{p}D_{2^{n}}(t)dt\leq\omega_{p}\left(1/2^{n},f\right).

and

\|IV\|_{p}\leq\int_{I_{n}}\|f(x+t)-f(x))\|_{p}D_{2^{n}}(t)dt\leq\omega_{p}\left(1/2^{n},f\right).

Since

(18)

2^{n}q_{2^{n}-1}\leq Q_{2^{n}},\ n\in\mathbb{N},

If we combine (
8
), (
18
) and generalized Minkowski’s inequality, then we get that

\displaystyle\|III\|_{p}

\displaystyle\leq

\displaystyle\int_{G}\left\|f\left(x+t\right)-f\left(x\right)\right\|_{p}K_{2^{n}}\left(t\right)d\mu(t)

\displaystyle=

\displaystyle\int_{I_{n}}\left\|f\left(x+t\right)-f\left(x\right)\right\|_{p}K_{2^{n}}\left(t\right)d\mu(t)

\displaystyle+

\displaystyle\sum_{s=0}^{n-1}\int_{I_{n}\left(e_{s}\right)}\left\|f\left(x+t\right)-f\left(x\right)\right\|_{p}K_{2^{n}}\left(t\right)d\mu(t)

\displaystyle\leq

\displaystyle+

\displaystyle\leq

\displaystyle\leq

\displaystyle\frac{3}{Q_{2^{n}}}\overset{n-1}{\underset{l=0}{\sum}}\sum_{k=l}^{n-1}\left(q_{2^{k}}-q_{2^{k+1}}\right)\sum_{s=0}^{l}2^{s}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{3}{Q_{2^{n}}}\overset{n-1}{\underset{l=0}{\sum}}q_{2^{l}}\sum_{s=0}^{l}2^{s}\omega_{p}\left(1/2^{s},f\right)\leq\frac{3}{Q_{2^{n}}}\overset{n-1}{\underset{s=0}{\sum}}2^{s}\omega_{p}\left(1/2^{s},f\right)\sum_{l=s}^{n-1}q_{2^{l}}

\displaystyle\leq

\displaystyle\frac{3}{Q_{2^{n}}}\overset{n-1}{\underset{s=0}{\sum}}2^{s}\omega_{p}\left(1/2^{s},f\right)q_{2^{s}}(n-s)\leq 3\overset{n-1}{\underset{s=0}{\sum}}\frac{n-s}{2^{n-s}}\frac{q_{2^{s}}}{q_{2^{n}}}\omega_{p}\left(1/2^{s},f\right).

The proof is complete. ∎

Finally, we state and prove the third main result.

Theorem 3
.

Let
2^{N}\leq n<2^{N+1}
and
{{t}_{n}}
be Nörlund mean generated by non-increasing sequence
\{q_{k}:k\in\mathbb{N}\}
(in sign
q_{k}\downarrow
) satisfying the condition

(22)

\frac{1}{Q_{n}}=O\left(\frac{1}{n}\right),\text{\ \ as \ \ }n\rightarrow\infty

Then, for any
f\in L^{p}(G),
where
1\leq p<\infty,
we have the following inequality

\displaystyle\|t_{n}f-f\|_{p}\leq C\sum_{j=0}^{N}\frac{2^{j}}{2^{N}}\omega_{p}\left(1/2^{j},f\right),

where
C
is a constant only depending on
p.

Proof.

Let
2^{N}\leq n<2^{N+1}.
Since
t_{n}
is a regular Nörlund means, generated by a sequence of non-increasing numbers
\{q_{k}:k\in\mathbb{N}\}
by combining (
11
) and (
12
), we can conclude that

\displaystyle\|t_{n}f(x)-f(x)\|_{p}

\displaystyle\leq

\displaystyle\frac{1}{Q_{n}}\left(\overset{n-1}{\underset{j=1}{\sum}}\left(q_{n-j-1}-q_{n-j}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}+q_{0}n\|\sigma_{n}f(x)-f(x)\|_{p}\right)

\displaystyle:=

\displaystyle I+II.

Furthermore,

\displaystyle I

\displaystyle=

\displaystyle\frac{1}{Q_{n}}\overset{2^{N}-1}{\underset{j=1}{\sum}}\left(q_{n-j-1}-q_{n-j}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}

\displaystyle+

\displaystyle\frac{1}{Q_{n}}\overset{n-1}{\underset{j=2^{N}}{\sum}}\left(q_{n-j-1}-q_{n-j}\right)j\|\sigma_{j}f(x)-f(x)\|_{p}:=I_{1}+I_{2}.

Analogously to (
13
) we get that

\displaystyle I_{1}

\displaystyle\leq

\displaystyle\frac{2}{Q_{n}}\overset{N-1}{\underset{k=0}{\sum}}\left(q_{n-2^{k+1}}-q_{n-2^{k}}\right)\sum_{s=0}^{k}2^{s}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{2}{Q_{n}}\sum_{s=0}^{N-1}2^{s}\omega_{p}\left(1/2^{s},f\right)\overset{N-1}{\underset{k=s}{\sum}}\left(q_{n-2^{k+1}}-q_{n-2^{k}}\right)

\displaystyle=

\displaystyle\frac{2}{Q_{n}}\sum_{s=0}^{N-1}2^{s}\omega_{p}\left(1/2^{s},f\right)(q_{n-2^{N}}-q_{n-2^{s}})

\displaystyle\leq

\displaystyle\frac{2q_{n-2^{N}}}{Q_{n}}\sum_{s=0}^{N-1}2^{s}\omega_{p}\left(1/2^{s},f\right)\leq\frac{2q_{0}}{Q_{n}}\sum_{s=0}^{N-1}2^{s}\omega_{p}\left(1/2^{s},f\right).

Moreover, analogously to (
14
) we find that

\displaystyle I_{2}

\displaystyle\leq

\displaystyle\frac{2}{Q_{n}}\overset{n-1}{\underset{j=1}{\sum}}\left(q_{n-j-1}-q_{n-j}\right)j\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle=

\displaystyle\frac{2}{Q_{n}}\left(nq_{0}-Q_{n}\right)\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{2nq_{0}}{Q_{n}2^{N}}\sum_{s=0}^{N}2^{s}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{2q_{0}}{Q_{n}}\sum_{s=0}^{N}2^{s}\omega_{p}\left(1/2^{s},f\right).

For
II
we have that

\displaystyle II

\displaystyle\leq

\displaystyle\frac{q_{0}2^{N+1}}{Q_{n}}\sum_{s=0}^{N}\frac{2^{s}}{2^{N}}\omega_{p}\left(1/2^{s},f\right)

\displaystyle\leq

\displaystyle\frac{2q_{0}}{Q_{n}}\sum_{s=0}^{N}2^{s}\omega_{p}\left(1/2^{s},f\right)

Hence, by using (
22
) we obtain the required inequality above so the proof is complete.
