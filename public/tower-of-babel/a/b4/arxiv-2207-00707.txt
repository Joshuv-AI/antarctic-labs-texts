Inverse spherical Bessel functions generalize Lambert W W and solve similar equations containing trigonometric or hyperbolic subexpressions or their inverses
David R. Stoutemyer

Abstract
A strict integer Laurent polynomial in a variable x x is 0 or a sum of one or more terms having integer coefficients times x x raised to a negative integer exponent. Equations that can be transformed to certain such polynomials times exp ⁡ ( − x ) = 𝑐𝑜𝑛𝑠𝑡𝑎𝑛𝑡 \exp(-x)=\mathit{constant} are exactly solvable by inverses of modified spherical Bessel functions of the second kind k n ​ ( x ) k_{n}(x) where n n is the order, generalizing the Lambert W W function when n > 0 . n>0. Equations that can be converted to certain such polynomials times cos ⁡ ( x ) \cos(x) or such polynomials times sin ⁡ ( x ) \sin(x) or a sum thereof = 𝑐𝑜𝑛𝑠𝑡𝑎𝑛𝑡 =\mathit{constant} are exactly solvable by inverses of spherical Bessel functions y n ​ ( x ) y_{n}(x) or j n ​ ( x ) j_{n}(x) . Such equations include cos ⁡ ( x ) / x = 𝑐𝑜𝑛𝑠𝑡𝑎𝑛𝑡 \cos(x)/x=\mathit{constant} , for which the solution inverse 1 ​ ( y 0 ) ​ ( − c ​ o ​ n ​ s ​ t ​ a ​ n ​ t ) \mathrm{inverse}\,_{1}(y_{0})(-constant) is the Dottie number when 𝑐𝑜𝑛𝑠𝑡𝑎𝑛𝑡 = 1 \mathit{constant}=1 , where subscript 1 1 is the branch number. Equations that can be converted to certain strict integer Laurent polynomials times sinh ⁡ ( x ) \sinh(x) and possibly also plus such a polynomial times cosh ⁡ ( x ) \cosh(x) are exactly solvable by inverses of modified spherical Bessel functions of the first kind i n ​ ( x ) i_{n}(x) .
