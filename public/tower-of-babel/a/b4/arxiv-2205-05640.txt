Abstract
High-rank line-of-sight (LOS) MIMO systems have attracted considerable attention for millimeter wave and THz communications. The small wavelengths in these frequencies enable spatial multiplexing with massive data rates at long distances. Such systems are also being considered for multi-path non-LOS (NLOS) environments. In these scenarios, standard channel models based on plane waves cannot capture the curvature of each wave front necessary to model spatial multiplexing. This work presents a novel and simple multi-path wireless channel parametrization where each path is replaced by a LOS path with a reflected image source. The model is fully valid for all paths with specular planar reflections, and captures the spherical nature of each wave front. Importantly, it is shown that the model uses only two additional parameters relative to the standard plane wave model. Moreover, the parameters can be easily captured in standard ray tracing. The accuracy of the approach is demonstrated on detailed ray tracing simulations at 28 GHz 28\text{\,}\mathrm{G}\mathrm{H}\mathrm{z} and 140 GHz 140\text{\,}\mathrm{G}\mathrm{H}\mathrm{z} in a dense urban area.

The main concept is that,

Our main contribution here

In addition, we show how these parameters can be

Analyzing wide aperture systems with

In addition, the ray tracing must be repeated for different antenna geometries or orientations,

In contrast, we show how

As an illustration, we show an example application of using the RM model

II
Plane Wave Approximations for Multi-Path Channels

We begin by reviewing the standard
plane wave multi-path channel models
using the perspective in
[
16
]
.
Consider a wireless channel from a
TX locations
{\boldsymbol{x}}^{t}\in{\mathcal{A}}^{t}

to RX locations
{\boldsymbol{x}}^{r}\in{\mathcal{A}}^{r}
,
where
{\mathcal{A}}^{t}
and
{\mathcal{A}}^{r}\subset{\mathbb{R}}^{p}

are some regions that can contain
the elements in the TX and RX arrays.
We focus on
so-called 3D models with
p=3
,
although similar results can be derived
for
p=2
.
We assume the channel is described by a set of
L
discrete
paths representing the routes of propagation from
the TX to RX locations.
In this case, the channel frequency response
at a frequency
f
from a transmit
location
{\boldsymbol{x}}^{t}
to a receive location

{\boldsymbol{x}}^{r}
is given by:

H(f)=\sum_{\ell=1}^{L}g_{\ell}\exp\left(-\frac{j2\pi f}{c}d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})\right),

(2)

where, for each path
\ell=1,\ldots,L
,

g_{\ell}
is a complex nominal channel gain
(assumed to be approximately constant over the region),
d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})
is the propagation distance
along the path from
{\boldsymbol{x}}^{t}
to
{\boldsymbol{x}}^{r}
,
and
c
is the speed of light

[
15
]
.
We will call
d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})
the
path
distance function
for path
\ell
.

Describing the gain
g_{\ell}
and path distance function
d_{\ell}(\cdot)

for each path is sufficient to compute the response
for arbitrary TX and RX arrays in multi-path
environments. For example,
suppose that the TX array has
N_{\rm tx}

elements at locations
x^{t}_{n}\in{\mathcal{A}}^{t}
,

n=1,\ldots,N_{\rm tx}
and the RX array
has elements at locations
x^{r}_{m}\in{\mathcal{A}}^{r}
,

m=1,\ldots,N_{\rm rx}
.
Then, the MIMO frequency response
is the matrix with coefficients

H_{mn}(f)=\sum_{\ell=1}^{L}g_{\ell}\exp\left(-\frac{j2\pi f}{c}d_{\ell}({\boldsymbol{x}}^{r}_{m},{\boldsymbol{x}}^{t}_{n})\right).

(3)

Hence, if we can find the gain
g_{\ell}
and path distance function
d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})
for each
path, we can compute the wideband MIMO channel response.

The main challenge is how to model the
path distance function
d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})

as a function of the RX and TX positions
{\boldsymbol{x}}^{r}
and
{\boldsymbol{x}}^{t}
.
If path
\ell
is LOS,
the path distance function
is simply the Euclidean distance

d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})=\|{\boldsymbol{x}}^{r}-{\boldsymbol{x}}^{t}\|.

(4)

For NLOS paths, the distance function is usually
approximated under the assumption that
the propagation in each path are plane waves.
Specifically, suppose that

{\boldsymbol{x}}^{r}_{0}
and
{\boldsymbol{x}}^{t}_{0}
are some reference locations
for the RX and TX. For example, these points
could be the
centroids of the arrays.
Now, for small displacements

{\boldsymbol{x}}^{t}-{\boldsymbol{x}}^{t}_{0}

and
{\boldsymbol{x}}^{r}-{\boldsymbol{x}}^{r}_{0}
, one often
assumes a plane wave approximation (PWA)

\displaystyle d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})\approx\widehat{d}_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})

\displaystyle=c\tau_{\ell}+({\boldsymbol{u}}^{r}_{\ell})^{\intercal}({\boldsymbol{x}}^{r}_{0}-{\boldsymbol{x}}^{r})+({\boldsymbol{u}}^{t}_{\ell})^{\intercal}({\boldsymbol{x}}^{t}_{0}-{\boldsymbol{x}}^{t}),

(5)

where
c
is the speed of light,

\tau_{\ell}
is the time of flight between the nominal points
{\boldsymbol{x}}^{r}_{0}
and
{\boldsymbol{x}}^{t}_{0}

along the path,

c\tau_{\ell}=d_{\ell}({\boldsymbol{x}}^{r}_{0},{\boldsymbol{x}}^{t}_{0}),

(6)

and
{\boldsymbol{u}}^{r}_{\ell}
and
{\boldsymbol{u}}^{t}_{\ell}
are unit vectors in
{\mathbb{R}}^{p}
representing the directions of arrival
and departure of the path.
We will call (
II
)
the
PWA model
.

When path
\ell
is a LOS path, so that

d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})
is given by
(
4
), the parameters for the
PWA model (
II
) are

\displaystyle\tau_{\ell}

\displaystyle=\frac{1}{c}\|{\boldsymbol{x}}^{r}_{0}-{\boldsymbol{x}}^{t}_{0}\|

(7a)

\displaystyle{\boldsymbol{u}}^{r}

\displaystyle=\frac{{\boldsymbol{x}}^{t}_{0}-{\boldsymbol{x}}^{r}_{0}}{c\tau},\quad{\boldsymbol{u}}^{t}=\frac{{\boldsymbol{x}}^{r}_{0}-{\boldsymbol{x}}^{t}_{0}}{c\tau}.

(7b)

The direction vectors
{\boldsymbol{u}}^{r}_{\ell}
and
{\boldsymbol{u}}^{t}_{\ell}

are also the negative derivatives of the distance
function at
({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})=({\boldsymbol{x}}^{r}_{0},{\boldsymbol{x}}^{t}_{0})
, meaning:

({\boldsymbol{u}}^{r})^{\intercal}=-\frac{\partial d_{\ell}({\boldsymbol{x}}^{r}_{0},{\boldsymbol{x}}^{t}_{0})}{\partial{\boldsymbol{x}}^{r}},\quad({\boldsymbol{u}}^{t})^{\intercal}=-\frac{\partial d_{\ell}({\boldsymbol{x}}^{r}_{0},{\boldsymbol{x}}^{t}_{0})}{\partial{\boldsymbol{x}}^{t}}.

(8)

Hence, the PWA model is valid to a second-order error
approximation in that

\displaystyle d_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})-\widehat{d}_{\ell}({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})

\displaystyle=O(\|{\boldsymbol{x}}^{r}_{0}-{\boldsymbol{x}}^{r}\|^{2})+O(\|{\boldsymbol{x}}^{t}_{0}-{\boldsymbol{x}}^{t}\|^{2}).

(9)

Typically, we express the directions
{\boldsymbol{u}}^{r}_{\ell}
and
{\boldsymbol{u}}^{t}_{\ell}

in spherical coordinates. For
p=3
, we can write
these unit vectors as

\displaystyle{\boldsymbol{u}}^{r}_{\ell}

\displaystyle=(\cos(\phi^{r}_{\ell})\cos(\theta^{r}_{\ell}),\sin(\phi^{r}_{\ell})\cos(\theta^{r}_{\ell}),\sin(\theta^{r}_{\ell}))

(10a)

\displaystyle{\boldsymbol{u}}^{t}_{\ell}

\displaystyle=(\cos(\phi^{t}_{\ell})\cos(\theta^{t}_{\ell}),\sin(\phi^{t}_{\ell})\cos(\theta^{t}_{\ell}),\sin(\theta^{t}_{\ell})),

(10b)

where
\phi^{r}_{\ell},\phi^{t}_{\ell}
are the azimuth
AoA and AoD for path
\ell
,
and
\theta^{r}_{\ell},\theta^{t}_{\ell}
are
the elevation AoA and AoD.
Thus, the channel can be described by six parameters
per path with a total of
6L
parameters:

(g_{\ell},\tau_{\ell},\phi^{r}_{\ell},\theta^{r}_{\ell},\phi^{t}_{\ell},\theta^{t}_{\ell}),\quad\ell=1,\ldots,L.

(11)

The PWA model (
II
)
thus has clear benefits:
it is geometrically interpretable and accurate when
the total array aperture is small. The main disadvantage is that
it becomes inaccurate when the array aperture is large and higher-order terms of the displacements

{\boldsymbol{x}}^{r}-{\boldsymbol{x}}^{r}_{0}
and
{\boldsymbol{x}}^{t}-{\boldsymbol{x}}^{t}_{0}
become
significant. In particular, the PWA
model always predicts that each path contributes
at most one spatial rank.
But, for wide aperture
arrays, the spherical nature of the wavefront
can result in a higher rank channel even for a single path
[
1
,
2
,
3
,
4
]
.
In particular, a channel with only a LOS path
can have a higher spatial rank, but the PWA model
will not be able to predict this feature.

In contrast, the path distance function
(
4
) is exact for arbitrary displacements.
However, this model is only valid for LOS paths.
The question is whether there is a model
for the path distance function that is exact
for arbitrary array sizes and applies in NLOS
settings.

III
Modeling the Distance Function under Planar, Specular Reflections

III-A

The Reflection Model

Our first result provides a
geometric characterization
of the path distance function for paths
with arbitrary numbers of specular reflections
from flat planes.
Specifically, we show that the path distance of the reflected path
is identical to a LOS distance to a rotated and translated image point.
Moreover, the parameters for the rotation and reflection can be derived from
the path route. The result does not apply to
curved surfaces, diffractions, or scattering.
However, we will show in the simulations below
that, even in a realistic environment with these properties, as well as
losses such as foliage, the model
performs well.

To state the result, let
{\mathcal{A}}^{t}
and
{\mathcal{A}}^{r}\subset{\mathbb{R}}^{p}
be regions of space. Suppose that
for every TX location
{\boldsymbol{x}}^{t}\in{\mathcal{A}}^{t}

and RX location
{\boldsymbol{x}}^{r}\in{\mathcal{A}}^{r}
there is a path that has a constant
set of reflecting surfaces where each surface is a plane.
In this case, we will say the path
has
constant planar reflections
over the regions

{\mathcal{A}}^{t}
and
{\mathcal{A}}^{r}
. With this definition,
our first result is as follows:

Theorem 1

Suppose a path has constant planar
reflections from regions

{\mathcal{A}}^{t}
to
{\mathcal{A}}^{r}\subset{\mathbb{R}}^{p}
.
Let
{\boldsymbol{x}}^{t}_{0}\in{\mathcal{A}}^{t}

and
{\boldsymbol{x}}^{r}_{0}\in{\mathcal{A}}^{r}
be arbitrary points
in these regions. Then,
there exists an orthogonal matrix
{\boldsymbol{U}}\in{\mathbb{R}}^{p\times p}

and vector
{\boldsymbol{g}}\in{\mathbb{R}}^{p}
such that

d({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})=\left\|{\boldsymbol{x}}^{r}-{\boldsymbol{U}}{\boldsymbol{x}}^{t}-{\boldsymbol{g}}\right\|.

(12)

Proof:

of the reflections on the surfaces denoted
S_{1}

Write the path’s route
as a sequence of
K-1

{\boldsymbol{x}}^{t}={\boldsymbol{x}}^{0}\rightarrow{\boldsymbol{x}}^{1}\rightarrow\cdots\rightarrow{\boldsymbol{x}}^{K}={\boldsymbol{x}}^{r},

(13)

where,
{\boldsymbol{x}}^{i}
represents the location of the
i
-the reflection.
The initial point,
{\boldsymbol{x}}^{0}={\boldsymbol{x}}^{t}
, is the TX location
and the final point,
{\boldsymbol{x}}^{K}={\boldsymbol{x}}^{r}
, is the RX location.
An example path with two reflections (i.e.,
K=3
)
is shown in Fig.

.
Let

denote the

For example, in Fig.

,
there are two surfaces,

and
S_{2}
.

The key idea in the proof is to trace the

Simple geometry shows that, after

We note that the distance function
(
12
) has a simple geometric interpretation:
The distance of any reflected path
is identical to the distance on a LOS path
but with the TX in a rotated
and shifted the reference frame.
The rotation is represented by the
orthogonal matrix
{\boldsymbol{U}}
and the
shift by the vector
{\boldsymbol{g}}
.
Returning to Fig.
1
,
this rotated and shifted point is simply the mirror
image of the original transmitter.

It is important to recognize that,
in a multi-path channel, there will be
separate parameters,
{\boldsymbol{U}}_{\ell}
and
{\boldsymbol{g}}_{\ell}
,
for each path
\ell
. Thus, if we are computing a
MIMO channel matrix component,
H_{mn}(f)

in (

), each path distance function
must be computed from an expression of the form:

d_{\ell}({\boldsymbol{x}}^{r}_{m},{\boldsymbol{x}}^{t}_{n})=\left\|{\boldsymbol{x}}^{r}_{m}-{\boldsymbol{U}}_{\ell}{\boldsymbol{x}}^{t}_{n}-{\boldsymbol{g}}_{\ell}\right\|.

We will discuss how to estimate the parameters

({\boldsymbol{U}}_{\ell},g_{\ell})
for each path
in Section

III-B

Relation to the PWA Model

The description (
12
) can also be
easily connected to the parameters in the PWA.
Let
R_{z}(\phi)
,
R_{y}(\theta)

and
R_{x}(\gamma)
be the rotation matrices
around the
z
,
y
and
x
axes:

\displaystyle{\boldsymbol{R}}_{z}(\phi)

\displaystyle:=\begin{bmatrix}\cos(\phi)&-\sin(\phi)&0\\
\sin(\phi)&\cos(\phi)&0\\
0&0&1\end{bmatrix},

(14a)

\displaystyle{\boldsymbol{R}}_{y}(\theta)

\displaystyle:=\begin{bmatrix}\cos(\theta)&0&\sin(\theta)\\
0&1&0\\
-\sin(\theta)&0&\cos(\theta)\end{bmatrix}

(14b)

\displaystyle{\boldsymbol{R}}_{x}(\gamma)

\displaystyle:=\begin{bmatrix}1&0&0\\
0&\cos(\gamma)&-\sin(\gamma)\\
0&\sin(\gamma)&\cos(\gamma)\end{bmatrix}

(14c)

Also, for
s=\pm 1
, let

{\boldsymbol{Q}}_{z}(s)
be the reflection in the

-axis:

{\boldsymbol{Q}}_{z}(s):=\begin{bmatrix}1&0&0\\
0&1&0\\
0&0&s\end{bmatrix}.

With these definitions, we have the following result.

Theorem 2

Suppose a path has

constant planar reflections from regions

{\mathcal{A}}^{t}
to
{\mathcal{A}}^{r}\subset{\mathbb{R}}^{p}
.
Let
{\boldsymbol{x}}^{t}_{0}\in{\mathcal{A}}^{t}

and
{\boldsymbol{x}}^{r}_{0}\in{\mathcal{A}}^{r}

, there exists parameters

(\tau,\phi^{r},\theta^{r},\phi^{t},\theta^{t},\gamma^{t},s)

where

1&\mbox{if $K$ is odd},\end{cases}

(17)

such that for all
{\boldsymbol{x}}^{r}\in{\mathcal{A}}^{r}
and
{\boldsymbol{x}}^{t}\in{\mathcal{A}}^{t}
, the total path distance is

\displaystyle d({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})=\Bigl\|c\tau{\boldsymbol{e}}_{x}+{\boldsymbol{R}}_{y}(\theta^{r}){\boldsymbol{R}}_{z}(-\phi^{r})({\boldsymbol{x}}^{r}_{0}-{\boldsymbol{x}}^{r})

\displaystyle+{\boldsymbol{Q}}_{z}(s){\boldsymbol{R}}_{x}(\gamma^{t}){\boldsymbol{R}}_{y}(\theta^{t}){\boldsymbol{R}}_{z}(-\phi^{t})({\boldsymbol{x}}^{t}_{0}-{\boldsymbol{x}}^{t})\Bigr\|.

(18)

Moreover the parameters
(\tau,\phi^{r},\theta^{r},\phi^{t},\theta^{t})

(
II
).

B
and
Appendix

The importance
of the result is that, in
p=3
,
the path distance function can be explicitly
written as a set of rotation angles:
Specifically, there are
elevation and azimuth angles,

\theta^{r}
and
\phi^{r}
at the RX,
and roll, elevation, and azimuth angles

\gamma^{t}
,
\theta^{t}
and
\phi^{t}

at the TX. There is an additional

.

In a multi-path channel, there will
be one set of such parameters
for each path along with a path gain.
Thus, if there are
L
paths, the

where we have added the complex gain

and delay

for each path

.
In comparison to the PWA model (

),
there is one additional binary parameter

and one additional angle
\gamma^{t}_{\ell}

per path.
We have thus found a concise parametrization

(RM).

IV
Fitting the RM
Parameters from Ray Tracing Data

A benefit of the PWA model is that
computing the terms of MIMO channel matrix
(
3
) is computationally simple.
Specifically, one typically only needs
to run ray tracing once
between any reference TX and
RX locations
{\boldsymbol{x}}_{0}^{t}
and
{\boldsymbol{x}}^{r}_{0}

near the array elements. If the PWA parameters for the paths
(
11
) can be extracted from those simulations, then
for any elements close to the reference locations,
the path distance and phase offset of
the path can be computed from (
II
).

Unfortunately, this approach is not valid for wide
aperture arrays where the displacements

{\boldsymbol{x}}^{t}-{\boldsymbol{x}}^{t}_{0}
and
{\boldsymbol{x}}^{r}-{\boldsymbol{x}}^{r}_{0}

are large. In ray tracing, the conventional approach is to
perform a simulation for each pair of TX and RX elements to
capture the full MIMO response accurately.
Hence, if there are
N_{\rm tx}
and
N_{\rm rx}
elements on the
TX and RX arrays, the computational complexity
grows by
N_{\rm rx}N_{\rm tx}
. Moreover, if the arrays are
moved or changed, the simulations need to be performed again. As ray tracing is computationally costly,
performing ray tracing
N_{\rm rx}N_{\rm tx}
times
for each possible array configuration or orientation
can be computationally prohibitive.

In contrast, if one has the full
RM model parameters (
19
)
for each path, the MIMO channel matrix
coefficients (
3
) can
be computed for arbitrary array
geometries without re-running the ray tracing.

In this section, we show how the model parameters
(
19
)
can be extrapolated
from a limited number of ray tracing simulations.
We describe two potential methods:

•

RM via Route Tracing (RM-RT)
: In this method, we assume that we can obtain
the full route (
13
)
for each path. This route is provided by most ray tracers,
such as the commercial Wireless Insite
ray tracer
[
22
]
that we use below.
Given the route information, we show that the complete set of
RM model parameters (
19
) can be found directly from
the channel from a single pair of reference
locations
({\boldsymbol{x}}^{t}_{0},{\boldsymbol{x}}^{r}_{0})
.

•

RM via Displaced Pairs (RM-DP)
: In this case,
we assume the ray tracing provides only the PWA parameters
(
11
) for any TX-RX pair. However,
the path route (
13
) is not provided.
In this case, we show that the RM model
parameters can be found from the PWA model parameters at
M+1

TX-RX pairs with one pair being a reference pair, and
M
additional pairs at locations displaced from the reference. The number of required additional pairs
is
M\geq 2
.

IV-A

Parameter Estimation via Route Tracing

In the first method,
reflection model via route tracing (RM-RT)
, ray tracing
is performed between some reference TX and RX pair locations,
{\boldsymbol{x}}_{0}^{t}
and
{\boldsymbol{x}}_{0}^{r}
.
We assume that, in addition to the PWA parameters (
11
),
the ray tracing provides the physical

route
of each multi-path component.
Specifically, for each path, we assume the ray tracer provides
sequence of points as in (
13
).
Under this assumption, we can obtain the parameters
{\boldsymbol{U}}
and
{\boldsymbol{g}}
in
(
12
) following the proof of Theorem
1
.

VI-B

Capacity Estimation via Exhaustive Ray Tracing

We first consider estimating the capacity via exhaustive
ray tracing. This method is the most exact, but also the most computationally
intensive.
For exhaustive ray tracing, we must run ray tracing between each TX and RX element in the arrays at each orientation at some reference frequency

f_{0}
. That is, between each TX element
n
and RX element
m
,
we use ray tracing at the RF center frequency
f_{0}
to find parameters

(g_{\ell mn},\tau_{\ell mn},\phi_{\ell mn}^{r},\theta_{\ell mn}^{r},\phi_{\ell mn}^{t},\theta_{\ell mn}^{t}),\quad\ell=1,\ldots,L_{mn},

(27)

where
L_{mn}
is the number of paths between the TX element
n

and RX element
n
and the items in the vector in (
27
)
are the gain, delays, and angles of the path
\ell
in that link.
Then, similar to the previous section, the MIMO channel matrix
at a frequency
f
, can be estimated by

{\boldsymbol{H}}(f)=\begin{bmatrix}H_{11}(f)&\dots&H_{1N_{\rm tx}}(f)\\
\vdots&\ddots&\vdots\\
H_{N_{\rm rx}1}(f)&\dots&H_{N_{\rm rx}N_{\rm tx}}(f)\end{bmatrix},

(28)

where

H_{mn}(f)=\sum_{\ell=1}^{L_{mn}}g_{\ell mn}e^{-j2\pi(f-f_{0})\tau_{\ell mn}}.

(29)

The capacity can then be estimated from the MIMO channel
matrix from standard MIMO communication theory
[
15
]
,
depending on the MIMO assumptions.
For example, suppose that the transmit power is
P_{\rm tx}
,
the bandwidth is
B
, and the TX must transmit a constant
PSD,
S_{\rm tx}=P_{\rm tx}/B
.
Suppose, in addition, that the TX and RX know the MIMO
channel matrix,
{\boldsymbol{H}}(f)
, at all frequencies
f
in the band
and perform optimal pre-coding at the TX and linear processing at the RX. That is, the system has full CSI-T and CSI-R.
Let

{\boldsymbol{s}}(f)=(s_{1}(f),\ldots,s_{r}(f)),

(30)

denote the singular values of
{\boldsymbol{H}}(f)
at frequency
f
,
where
r
is the channel rank.
Then, we can estimate the rate by

R:=\int_{f_{0}-B/2}^{f_{0}+B/2}\mathrm{SE}(f)\,df

(31)

where
\mathrm{SE}(f)
is the spectral efficiency (i.e.,
rate per unit bandwidth):

\mathrm{SE}(f)=\max_{k=1,\ldots,r}\sum_{i=1}^{k}\rho\left(\frac{s_{i}^{2}(f)P_{\rm tx}}{N_{0}Bk}\right),

(32)

where
N_{0}
is the noise PSD,
\rho(\gamma)
is the spectral
efficiency per stream for an SNR
\gamma
, and
the maximization over
k
is to select the number of streams to use.
The formula (
32
) assumes that we allocate a fraction
1/k

of the power to each stream and optimize over
k
. This allocation
is an approximation of water-filling.
The resulting average spectral efficiency is

\overline{\mathrm{SE}}:=R/B.

(33)

For the theoretical Shannon capacity, in (
32
),
we would use the formula:

\rho(\gamma)=\log_{2}(1+\gamma).

(34)

However, to account for losses with practical codes and overhead,
we assume a widely-used
model in 3GPP simulations
[
28
]
:

\rho(\gamma):=\min\left\{\alpha\log_{2}(1+\gamma),\rho_{\rm max}\right\}

(35)

where
\alpha=0.6
and
\rho_{\rm max}=4.8

\mathrm{b}\mathrm{p}\mathrm{s}\mathrm{/}\mathrm{H}\mathrm{z}
.

The key computational challenge in the exhaustive capacity estimation is the ray tracing.
Since the arrays have
N_{\rm rx}=N_{\rm tx}=64

elements each, and there are
N_{\rm ang}=24

angular steps, we must run ray tracing
N
times with

N=N_{\rm rx}N_{\rm tx}N_{\rm ang}=(64)(64)(24)\approx 98000,

(36)

to extract the parameters (

all the angular steps.
While the exhaustive procedure is the most accurate, the large number of ray tracing simulations required can be computationally extremely expensive.

VII
Conclusions

Near-field communication
is a promising technology for systems in the
mmWave and THz bands. However, accurate assessment
of near-field communications requires
channel models that can capture the spherical
nature of the wavefront of each path, a feature
not accounted for in most models today that
use planar approximations of waves. This paper has presented a simple parametrization for
multi-path wireless channels that correctly describes
the spherical nature of each wavefront.
Interestingly, the parametrization
requires only two additional parameters relative
to standard plane wave models. Moreover,
we have provided a computationally simple
algorithm to extract the parameters
from ray tracing.

The model is based on image theory and is
fully accurate under the assumption
of planar, infinite surface reflections.
Moreover, our simulations show that the proposed reflection model delivers a high accuracy
over wide apertures, even when these exact conditions are not met. In particular, the models are significantly more accurate than models
based on plane wave approximations. The technique is precise while substantially decreasing
the simulation duration in contrast to the comprehensive ray tracing approach.

Going forward, the method can greatly enhance
the evaluation of near-field communications in site-specific settings. In this paper, we have
demonstrated the method for evaluation of
mmWave and sub-THz wide-aperture MIMO backhaul links in a site-specific setting.

A natural
next step is to develop statistical channel
models, such as those used by 3GPP
[
14
]
,
or machine learning methods
[
24
,
29
]
,
that describe the distribution of these parameters
in common environments.

Appendix A
Proof of

Write the path’s route
as a sequence of
K-1
interactions as in (
13
). Let

denote the
k

The initial transmitter point

can be reflected

to obtain an image that we will denote

{\boldsymbol{z}}^{1}

create a second image
{\boldsymbol{z}}^{2}

K-1
reflections,
we obtain a final image point
{\boldsymbol{z}}^{K-1}

The method of images states that the total distance of the reflected path is equal to
the LOS distance from the final reflected
image point
{\boldsymbol{z}}^{K-1}
to the receiver
{\boldsymbol{x}}^{r}
.
Hence,

d({\boldsymbol{x}}^{r},{\boldsymbol{x}}^{t})=\|{\boldsymbol{x}}^{r}-{\boldsymbol{z}}^{K-1}\|.

(37)

Therefore, (

{\boldsymbol{z}}^{K-1}={\boldsymbol{U}}{\boldsymbol{x}}^{t}+{\boldsymbol{g}},

(38)

for some orthogonal matrix
{\boldsymbol{U}}
and vector
{\boldsymbol{g}}
.
That is, the image point is a rotation and translation of the
original transmitted point.

Finding the matrix
{\boldsymbol{U}}
and vector
{\boldsymbol{g}}
in (

is a matter of simple geometry.
We will walk through the details since this process will also
show how to numerically compute the parameters from the
route sequence (
13

First, since each surface is a plane, the surface can be represented as:

S_{k}=\left\{{\boldsymbol{x}}~|~({\boldsymbol{u}}^{k})^{\intercal}{\boldsymbol{x}}=b^{k}\right\},

for some unit vector
{\boldsymbol{u}}^{k}

To compute the normal vector, let

(40)

Then, the normal vector for
S_{k}
is given by:

{\boldsymbol{u}}^{k}:=\frac{{\boldsymbol{v}}^{k+1}-{\boldsymbol{v}}^{k}}{\|{\boldsymbol{v}}^{k+1}-{\boldsymbol{v}}^{k}\|},\quad k=1,\ldots,K-1.

(41)

Also, since we know
{\boldsymbol{x}}^{k}
is in the plane
S_{k}
in (
39

the intercept must be given by:

b^{k}=({\boldsymbol{u}}^{k})^{\intercal}{\boldsymbol{x}}^{k}.

(42)

Since the image point
{\boldsymbol{z}}^{k}
is the reflection of
{\boldsymbol{z}}^{k-1}
around
S_{k}
,
the two points are related by:

\displaystyle{\boldsymbol{z}}^{k}

\displaystyle={\boldsymbol{x}}^{k-1}-2{\boldsymbol{u}}^{k}(({\boldsymbol{u}}^{k})^{\intercal}{\boldsymbol{z}}^{k-1}-b^{k})

\displaystyle={\boldsymbol{V}}_{k}{\boldsymbol{z}}^{k-1}+{\boldsymbol{c}}_{k}

(43)

where

(44)

The recursion (

{\boldsymbol{z}}^{0}={\boldsymbol{x}}^{t}

Solving (

(45)

{\boldsymbol{U}}_{k}=\prod_{i=1}^{k}{\boldsymbol{V}}_{i},

(46)

and
{\boldsymbol{g}}^{k}

{\boldsymbol{g}}^{k}={\boldsymbol{c}}^{k}+{\boldsymbol{V}}_{k}{\boldsymbol{g}}^{k-1},\quad k=1,\ldots,K-1,

Iterating through (
43

{\boldsymbol{U}}=\prod_{k=1}^{K-1}{\boldsymbol{V}}_{k},\quad{\boldsymbol{g}}={\boldsymbol{g}}^{K-1}.

(48)

Also, each matrix
{\boldsymbol{V}}_{k}
in (
44

matrix. Since
{\boldsymbol{U}}
in (
46

{\boldsymbol{U}}
is also orthogonal. This completes the proof.
