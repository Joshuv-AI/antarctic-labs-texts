Maximum Principle and Asymptotic Properties of Hermite–Padé Polynomials
Sergey P. Suetin

Abstract
. In the paper, we discuss how it would be possible to succeed in Stahl’s novel approach, 1987–1988, to explore Hermite–Padé polynomials based on Riemann surface properties. In particular, we explore the limit zero distribution of type I Hermite–Padé polynomials Q n , 0 , Q n , 1 , Q n , 2 Q_{n,0},Q_{n,1},Q_{n,2} , deg ⁡ Q n , j ⩽ n \operatorname{deg}{Q_{n,j}}\leqslant{n} , for a collection of three analytic elements [ 1 , f ∞ , f ∞ 2 ] [1,f_{\infty},f^{2}_{\infty}] . The element f ∞ f_{\infty} is an element of a function f f from the class ℂ ⁡ ( z , w ) \mathbb{C}(z,w) where w w is supposed to be from the class Z ± 1 / 2 ( [ − 1 , 1 ] ) Z_{\pm 1/2}([-1,1]) of multivalued analytic functions generated by the inverse Zhukovskii function with the exponents from the set { ± 1 / 2 } \{\pm 1/2\} . The Riemann surface corresponding to f ∈ ℂ ⁡ ( z , w ) f\in\mathbb{C}(z,w) is a four-sheeted Riemann surface ℜ 4 ​ ( w ) \mathfrak{R}_{4}(w) and all branch points of f f are of the first order (i.e., all branch points are of square root type). It is proved that there exits the similar limit zero distribution for all three polynomials Q n , j Q_{n,j} . The answer is done in terms of Nuttall’s condenser which was introduced by E. Rakhmanov and the author in 2013. The corresponding limit measure is supported on the second plate of Nuttall’s condenser which coincides with the projection of the boundary between the first and the second sheets of the three-sheeted Riemann surface ℜ 3 ​ ( w ∞ ) \mathfrak{R}_{3}(w_{\infty}) associated by Nuttall with the element w ∞ w_{\infty} . The limit measure is a unique solution of a mixed Green-logarithmic theoretical-potential equilibrium problem. In general the surface ℜ 3 ​ ( w ∞ ) \mathfrak{R}_{3}(w_{\infty}) can be of any genus. Since the algebraic function f ∈ ℂ ⁡ ( z , w ) f\in\mathbb{C}(z,w) is of fourth order and we consider the triple of the analytic elements [ 1 , f ∞ , f ∞ 2 ] [1,f_{\infty},f^{2}_{\infty}] but not the quadruple [ 1 , f ∞ , f ∞ 2 , f ∞ 3 ] [1,f_{\infty},f^{2}_{\infty},f^{3}_{\infty}] ones, the result is new and does not follow from the known results. As in previous paper arXiv: 2108.00339 and following to Stahl’s ideas, 1987–1988, we do not use the orthogonality relations at all. The proof is based on the maximum principle only. \displaystyle\max_{z\in\Gamma_{\rho}}\left|\left[Q_{n,1}(z)+Q_{n,2}(z)\bigl(f(z^{(0)})+f(z^{(1)})\bigr)\right]e^{(n-s+1)V^{\lambda_{E}}(z)}\right|

(23)

\displaystyle\asymp\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(1)})e^{(n-s+1)V^{\lambda_{E}}(z)}\right|.

In the same way as above (i.e., based on the maximum principle applied to the function
u_{n}(\mathbf{z})
) we obtain the following relations as
n\to\infty

\displaystyle\max_{z\in\Gamma_{\rho}}

\displaystyle\left|\bigl[Q_{n,1}(z)+Q_{n,2}(z)(f(z^{(0)})+f(z^{(1)})\bigr]e^{(n+1-s)V^{\lambda_{E}}(z)}\right|

(24)

\displaystyle\qquad\asymp\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(1)})e^{(n+1-s)V^{\lambda_{E}}(z)}\right|,

\displaystyle\max_{z\in\Gamma_{\rho}}

\displaystyle\left|\bigl[Q_{n,1}(z)+Q_{n,2}(z)(f(z^{(0)})+f(z^{(2)})\bigr]e^{(n+1-s)V^{\lambda_{E}}(z)}\right|

(25)

\displaystyle\qquad\asymp\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(2)})e^{(n+1-s)V^{\lambda_{E}}(z)}\right|.

From (
17
), (
24
), (
25
) and the identity

\displaystyle Q_{n,1}(z)

\displaystyle+Q_{n,2}(z)(f(z^{(0)})+f(z^{(2)}))

\displaystyle=Q_{n,1}(z)+Q_{n,2}(z)\bigl(f(z^{(0)})+f(z^{(1)})\bigr)+Q_{n,2}(z)(f(z^{(2)})-f(z^{(1)}))

it follows that

(26)

\max_{z\in\Gamma_{\rho}}\left|Q_{n,2}(z)e^{(n+1-s)V^{\lambda_{E}}(z)}\right|\asymp\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(2)})e^{(n+1-s)V^{\lambda_{E}}(z)}\right|.

2.4.

Since
\lambda_{F}
is the balayage of the measure
\lambda_{E}\in M_{1}(E)
from the domain
\Omega
to the compact set
F
, we have the identity

(27)

V^{\lambda_{F}}(z)=V^{\lambda_{E}}(z)-G^{\lambda_{E}}_{F}(z)+\operatorname{const},\quad z\in\widehat{\mathbb{C}},

with some constant. Note now that the function
q_{s}(z)(f(z^{(0)})+f(z^{(1)}))
is a holomorphic function in the domain
\Omega
.
From this fact and (
27
) it follows that the function

(28)

v_{n}(z):=\log\left|q_{s}(z)\bigl[Q_{n,1}(z)+Q_{n,2}(z)(f(z^{(0)})+f(z^{(1)}))\bigr]\right|+(n+s)V^{\lambda_{F}}(z)

is a subharmonic function in
\Omega
. Therefore by the maximum principle and taking into account that
\Gamma_{\rho}
is a level curve for the Green potential
G_{F}^{\lambda_{E}}(z)
, we obtain that for
1<\rho<\rho_{2}<R

\displaystyle\max_{z\in\Gamma_{\rho_{2}}}\left|\bigl[Q_{n,1}(z)+Q_{n,2}(z)(f(z^{(0)})+f(z^{(1)}))\bigr]e^{nV^{\lambda_{E}}(z)}\right|

(29)

\displaystyle\leqslant\left(\frac{\rho_{2}}{\rho}\right)^{n}\max_{z\in\Gamma_{\rho}}\left|\bigl[Q_{n,1}(z)+Q_{n,2}(z)(f(z^{(0)})+f(z^{(1)}))\bigr]e^{nV^{\lambda_{E}}(z)}\right|.

Since the function

\log|Q_{n,2}(z)|+n\bigl(V^{\lambda_{E}}(z)-G_{F}^{\lambda_{E}}(z)\bigr)

is a subharmonic function in
\Omega
, then the following inequality holds

(30)

\max_{z\in\Gamma_{\rho_{2}}}\left|Q_{n,2}(z)e^{nV^{\lambda_{E}}(z)}\right|\leqslant\left(\frac{\rho_{2}}{\rho}\right)^{n}\max_{z\in\Gamma_{\rho}}\left|Q_{n,2}(z)e^{nV^{\lambda_{E}}(z)}\right|.

Note that the inequality (
30
) is an analog of the Bernshtein–Walsh Theorem but for the level curves of the Green potential
G_{F}^{\lambda_{E}}(z)
instead of the Green function
g_{S}(z,\infty)
(see
[
45
]
).

Combining (
18
), (
26
) and (
30
), we obtain finally that for any admissible
\rho_{2},\rho\in(1,R)
and as
n\to\infty
the following asymptotic relations valid

(31)

\displaystyle\max_{z\in\Gamma_{\rho_{2}}}\left|Q_{n,2}(z)e^{nV^{\lambda_{E}}(z)}\right|\asymp\left(\frac{\rho_{2}}{\rho}\right)^{n}\max_{z\in\Gamma_{\rho}}\left|Q_{n,2}(z)e^{nV^{\lambda_{E}}(z)}\right|,

(32)

\displaystyle\max_{z\in\Gamma_{\rho_{2}}}\left|R_{n}(z^{(2)})e^{nV^{\lambda_{E}}(z)}\right|\asymp\left(\frac{\rho_{2}}{\rho}\right)^{n}\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(2)})e^{nV^{\lambda_{E}}(z)}\right|.

From (
31
) it follows (cf.
[
45
]
) that
the sequence
\{n-\operatorname{deg}{Q_{n,2}}\}
is bounded and

(33)

\frac{1}{n}\chi(Q_{n,2})\overset{*}{\longrightarrow}\lambda_{F},\quad n\to\infty.

Based on these results it easy to check that
the sequences
\{n-\operatorname{deg}{Q_{n,0}}\},\{n-\operatorname{deg}{Q_{n,1}}\}
are also bounded and

\frac{1}{n}\chi(Q_{n,j})\overset{*}{\longrightarrow}\lambda_{F},\quad j=0,1,\quad n\to\infty.

Finally from (
17
) and (
26
) we obtain the estimate

(34)

\varlimsup_{n\to\infty}\left|R_{n}(z^{(1)})e^{nV^{\lambda_{E}}(z)}\right|^{1/n}\leqslant\frac{1}{\rho^{2}},\quad z\in\Gamma_{\rho}.

Now let consider the function
u_{n}(\mathbf{z})
(see (
13
)) in the open set
V^{(1,2)}(R)
, where
\pi_{3}(\partial V^{(1,2)}(R))=\Gamma_{R}
. Function
u_{n}(\mathbf{z})
is a (pice-wise) subharmonic function in
V^{(1,2)}(R)
. Ultimately from (
32
), (
33
), (
34
) and by the three constants theorem applied to
u_{n}
and for any component of
V^{(1,2)}(R)
we obtain that as
n\to\infty

(35)

\max_{z\in\Gamma_{\rho}}\left|R_{n}(z^{(1)})e^{nV^{\lambda_{E}}(z)}\right|\asymp\frac{1}{\rho^{2}}.

From this relation, (
24
) and (
33
) it finally follows that

(36)

\biggl|\frac{Q_{n,1}(z)}{Q_{n,2}(z)}+\bigl(f(z^{(0)})+f(z^{(1)})\bigr)\biggr|^{1/n}\overset{\operatorname{cap}}{\longrightarrow}e^{-2G_{F}^{\lambda_{E}}(z)}<1,\quad z\in\Omega\setminus{E}.

Theorem
1
is proven.

3.2.

Traditionally the problem of asymptotics of Padé and Hermite–Padé polynomials consists of two components. Namely, geometrical component and analytical one.
