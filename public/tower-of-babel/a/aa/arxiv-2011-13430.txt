Stability for UMAP
J.F. Jardine

Abstract
This paper displays the Healy-McInnes UMAP construction V(X,N) as an iterated ushout of Vietoirs-Rips objects V ⁡ ( X , D x ) V(X,D_{x}) , which are associated to extended pseudo metric spaces (ep-metric spaces) defined by a system N N of neighbourhoods of the elements of a finite set X X . An inclusion of finite sets X ⊂ Y X\subset Y defines a map of UMAP systems V ⁡ ( X , N ) → V ⁡ ( Y , N ′ ) V(X,N)\to V(Y,N^{\prime}) in the presence of a compatible system of neighbourhoods N ′ N^{\prime} for Y Y . There is also an induced map of ep-metric spaces ( X , D ) → ( Y , D ′ ) (X,D)\to(Y,D^{\prime}) , where D D and D ′ D^{\prime} are colimits (global averages) of the metrics defined by the respective neighbourhood systems. We prove a stablity result for the restriction of this ep-metric space map to global components. This stability result translates, via excision for path components, to a stability result for global components of the UMAP systems.

General constructions

Suppose that we have a set
X
with a finite list of ep-metric space structures
(X,d_{i})
,
i=1,\dots,k
. We can also endow
X
with a discrete ep-metric space structure, so that
d_{\infty}(x,y)=\infty
for all
x,y\in X
. Suppose that

has a total ordering.

There are canonical ep-metric space morphisms
(X,d_{\infty})\to(X,d_{i})
, all of which are the identity on

(X,D)
for the colimit in

\textstyle{(X,d_{\infty})\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\textstyle{(X,d_{i})\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\tau_{i}}
\textstyle{(X,d_{j})\ignorespaces\ignorespaces\ignorespaces\ignorespaces}
\scriptstyle{\tau_{j}}

The maps

1

is formed by taking the colimit of the underlying functions, and endowing it with a metric, in this case

We also write

along the underlying set

Formally,

D(x,y)=\inf_{P}\ (\sum\ d_{i_{j}}(x_{j},x_{j+1})),

indexed over all polygonal paths

and choices of metrics

in the list

. The pair

forms a polygonal path, so that

for all
i
. In this sense, the ep-metric

optimizes the metrics

.

There may not be a polygonal path

and metrics

such that all

are finite. In that case, we have

.

If
X
is a finite set, then the collection of polygonal paths from

to

in

is finite, and so

D(x,y)=\sum\ d_{i_{j}}(x_{j},x_{j+1})

for some choice of polygonal path
P
and metrics

. In that case,
d_{i_{j}}(x_{j},x_{j+1})
must be minimal among all
d_{k}(x_{j},x_{j+1})
.

The maps
(X,d_{\infty})\to(X,d_{i})
induce maps

into Vietoris-Rips systems, and we form the iterated pushout

V(X,D):=\vee_{i}\ V(X,d_{i})

(3)

in the category of systems. This means that the object (
3
) is the colimit of all maps

(4)

over the discrete system

. The maps (

is a type of homotopy colimit.

Remark 1
.

In practice and in general, although one tends to be notationally lazy, it is better to replace the Vietoris-Rips system

with the homotopy equivalent system

, and

is the nerve of

can be described explicitly as the collection of subsets

The ep-metric space maps

\textstyle{BP(X,d_{i})\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces\ignorespaces}

From this perspective, we can write

The UMAP algorithm of

For each point

The set

In much of what follows, the choices of the sets

In all applications, one assigns distances

Examples

Remark 3

Suppose that

Global connectedness has the following general properties:

1)

Every ep-metric space
(X,d)
is a disjoint union of its set
\pi_{\infty}(X,d)
of global components.

2)

An ep-metric space morphism
f:(X,d_{X})\to(Y,d_{Y})
preserves global connected components: if
d_{X}(x,y)<\infty
then

d_{Y}(f(x),f(y))\leq d_{X}(x,y)<\infty,

so that
f(y)
is in the connected component of
f(x)
. We therefore have an induced function
f_{\ast}:\pi_{\infty}(X,d_{X})\to\pi_{\infty}(Y,d_{Y})
.

3)

Every metric space is globally connected.
