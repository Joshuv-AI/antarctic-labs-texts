Abstract
The independent set polynomial is important in many areas of combinatorics, computer science, and statistical physics. For every integer Δ ≥ 2 \Delta\geq 2 , the Shearer threshold is the value λ ∗ ​ ( Δ ) = ( Δ − 1 ) Δ − 1 / Δ Δ \lambda^{*}(\Delta)=(\Delta-1)^{\Delta-1}/\Delta^{\Delta} . It is known that for λ < − λ ∗ ​ ( Δ ) \lambda<-\lambda^{*}(\Delta) , there are graphs G G with maximum degree Δ \Delta whose independent set polynomial, evaluated at λ \lambda , is at most 0 0 . Also, there are no such graphs for any λ > − λ ∗ ​ ( Δ ) \lambda>-\lambda^{*}(\Delta) . This paper is motivated by the computational problem of approximating the independent set polynomial when λ < − λ ∗ ​ ( Δ ) \lambda<-\lambda^{*}(\Delta) . The key issue in complexity bounds for this problem is “implementation”. Informally, an implementation of a real number λ ′ \lambda^{\prime} is a graph whose hard-core partition function, evaluated at λ \lambda , simulates a vertex-weight of λ ′ \lambda^{\prime} in the sense that λ ′ \lambda^{\prime} is the ratio between the contribution to the partition function from independent sets containing a certain vertex and the contribution from independent sets that do not contain that vertex. Implementations are the cornerstone of intractability results for the problem of approximately evaluating the independent set polynomial. Our main result is that, for any λ < − λ ∗ ​ ( Δ ) \lambda<-\lambda^{*}(\Delta) , it is possible to implement a set of values that is dense over the reals. The result is tight in the sense that it is not possible to implement a set of values that is dense over the reals for any λ > λ ∗ ​ ( Δ ) \lambda>\lambda^{*}(\Delta) . Our result has already been used in a paper with Bezáková (STOC 2018) to show that it is #P-hard to approximate the evaluation of the independent set polynomial on graphs of degree at most Δ \Delta at any value λ < − λ ∗ ​ ( Δ ) \lambda<-\lambda^{*}(\Delta) . In the appendix, we give an additional incomparable inapproximability result (strengthening the inapproximability bound to an exponential factor, but weakening the hardness to NP-hardness).

Introduction

The independent set polynomial is a fundamental object in computer science which has been studied with various motivations. From an algorithmic viewpoint, the evaluation of this polynomial is crucial for determining the applicability of the Lovász Local Lemma and thus obtaining efficient algorithms for
both
finding
[
9
]
and approximately counting
[
5
,
8
]
combinatorial objects with specific properties.

The independent set polynomial also arises in statistical physics, where it is
called the
hard-core partition function
.
Given a graph
G
,
the value of the independent set polynomial
of
G

at a point
\lambda

is equal to the value of the partition function of the hard-core model
where the so-called “activity parameter” is equal to
\lambda
.
We use the following notation.
Given a graph
G
, let
\mathcal{I}_{G}
denote the set of independent sets in
G
.
The weight of an independent set
I\in\mathcal{I}_{G}
is given by
\lambda^{|I|}
.
The hard-core partition function with parameter
\lambda
is defined as

Z_{G}(\lambda):=\sum_{I\in\mathcal{I}_{G}}\lambda^{|I|}.

(1)

The evaluation of the hard-core partition function for
\lambda<0
has significant algorithmic interest due to its connection with the Lovász Local Lemma (LLL) and, more precisely, to the problem of checking when the LLL applies.
Shearer, as part of his work
[
12
]
on the LLL, implicitly established that for every
\Delta\geq 2
, there is a threshold
\lambda^{*}(\Delta)
, given by
\lambda^{*}(\Delta)=(\Delta-1)^{\Delta-1}/\Delta^{\Delta}
, such that

1.

for all
\lambda\geq-\lambda^{*}(\Delta)
, for all graphs
G
of maximum degree
\Delta
, it holds that
Z_{G}(\lambda)>0
.

2.

for all
\lambda<-\lambda^{*}(\Delta)
, there exists a graph
G
of maximum degree
\Delta
such that
Z_{G}(\lambda)\leq 0
.

We refer to the point
-\lambda^{*}(\Delta)
as the
Shearer threshold
.
Scott and Sokal
[
11
]
were the first to realise the relevance of Shearer’s work to the phase transitions of the hard-core model, and to make explicit Shearer’s contribution in this context.
From an algorithmic viewpoint, the Shearer threshold is tacitly present in most, if not all, applications of the (symmetric) LLL. In particular, Shearer
[
12
]
proved that
\lambda^{*}(\Delta)
is the maximum value

such that
in a probability space where each event occurs with probability
at most
p

and each event is independent of all except at most
\Delta
other events,
there is a positive probability that no events occur.

A key concept in the hard-core model is that of “implementation”.
A formal definition follows shortly.
Informally, an
implementation
of a real number
\lambda^{\prime}
is a graph whose hard-core partition function
Z_{G}(\lambda)

simulates a vertex-weight of
\lambda^{\prime}
in the sense that

\lambda^{\prime}
is the ratio between the contribution to
Z_{G}(\lambda)
from independent sets containing a certain vertex and the contribution from independent sets that do not contain that vertex.
Implementation is the cornerstone of all inapproximability results for the independence polynomial/hard-core partition function.

The main result of this paper (Theorem
1
) is that
if
\lambda<-\lambda^{*}(\Delta)
then, for any real number
\lambda^{\prime}

and any desired error, there is a bipartite graph
G
of maximum degree at most
\Delta
that
implements the activity
\lambda^{\prime}
within the desired error.

We first give the necessary definitions, in order to state the result formally. We then describe the algorithmic consequences.

1.1
Implementations

Let

Definition 1
.

[Implementing an activity
\lambda^{\prime}
]

We refer to the vertex

.

Suppose that

implements
\lambda^{\prime}
with error

and that

It is clear from the definition

In particular, in the regime

2.1
Overview of the proof

In this section, we give an overview of the proof of Theorem
1
. We also
state the main lemmas that we need, and use them to prove
the theorem. The remaining sections contain a proof of the main lemmas.

Consider a degree bound
\Delta\geq 3
.
In order to prove Theorem
1
, we will show that for any fixed
\lambda<-\lambda^{*}(\Delta)
, we can implement a dense set of activities using bipartite graphs of maximum degree
\Delta
. At a very rough level, the proof of Theorem
1
splits into two regimes:

1.

when
\lambda<-\lambda^{*}(2)=-1/4
,

2.

when
-1/4\leq\lambda<-\lambda^{*}(\Delta)
.

Roughly, in regime
1
, we will be able to use
paths
to implement a dense set of activities. In regime
2
, we will first use a
(\Delta-1)
-ary tree to implement an activity
\lambda^{\prime}<-1/4
. Then, using the activity
\lambda^{\prime}
, we will be able to use the path construction of the first regime to implement a dense set of activities.

Unfortunately, the actual proof is more intricate, since as it turns out there is a set
\mathcal{B}\subset\mathbb{R}
, dense
in
(-\infty,-1/4)
, such that, if
\lambda\in\mathcal{B}
, paths exhibit a periodic behaviour in terms of implementing activities (and thus can only be used to implement a finite set of activities). The following lemma will be important in specifying the set
\mathcal{B}
and understanding this periodic behaviour. The proof is given in Section
2.2
.

Lemma 1
.

Let
\lambda<-1/4
and
\theta\in(0,\pi/2)
be such that
\lambda=-1/(2\cos\theta)^{2}
. Then, the partition function of the path
P_{n}
with
n
vertices is given by

Z_{P_{n}}(\lambda)=\frac{\sin((n+2)\theta)}{2^{n}(\cos\theta)^{n}\sin(2\theta)}.

The “bad” set
\mathcal{B}
of activities (for which paths exhibit a periodic behaviour) can be read off from Lemma
1
. To make this precise, let

\mathcal{B}:=\Big\{\lambda\in\mathbb{R}\mid\lambda=-\frac{1}{4(\cos\theta)^{2}}\mbox{ for some }\theta\in(0,\pi/2)\mbox{ which is a \emph{rational multiple} of }\pi\Big\}.

(2)

Note, for example, that
-1,-1/2,-1/3\in\mathcal{B}
(set
\theta=\pi/3,\pi/4,\pi/6
, respectively). For
\lambda<-1/4
, it is not hard to infer from Lemma

that the ratio
\frac{Z^{\mathsf{in}}_{P_{n},v}(\lambda)}{Z^{\mathsf{out}}_{P_{n},v}(\lambda)}
is equal to
-\frac{1}{2\cos\theta}\frac{\sin(n\theta)}{\sin((n+1)\theta)}
(cf. the upcoming equation (
9

\lambda\in\mathcal{B}
or equivalently
\theta
is a rational multiple of
\pi

in the path. On the other hand, when
\lambda<-1/4
and
\lambda\notin\mathcal{B}
, then we can show that the ratio is dense in

as
n
varies (this follows essentially from the fact that

is dense on the circle when
\theta
is irrational) and hence we can use paths to implement a dense set of activities. This is the scope of the next lemma, which is proved in Section
2.2
.

Lemma 2
.

Let
\lambda<-1/4
be such that
\lambda\notin\mathcal{B}
. Let
P_{n}
denote a path with
n
vertices and let
v
be one of the endpoints of
P_{n}
. Then, for every
\lambda^{\prime}\in\mathbb{R}
, for every
\epsilon>0
, there exists
n
such that

\Big|\frac{Z^{\mathsf{in}}_{P_{n},v}(\lambda)}{Z^{\mathsf{out}}_{P_{n},v}(\lambda)}-\lambda^{\prime}\Big|\leq\epsilon.

When
\lambda\in\mathcal{B}
, we can no longer use paths to implement a dense set of activities, as we explained earlier, and we need to use a more elaborate argument. A key observation is that, for
\lambda\in\mathcal{B}
, the partition function of a path of appropriate length is equal to 0. In particular, we have the following simple corollary of Lemma
1
.

Corollary 1
.

Let
\lambda<-1/4
be such that
\lambda\in\mathcal{B}
. Denote by
P_{n}
the path with
n
vertices. Then, there is an integer

such that the partition function of the path
P_{n}
is zero, i.e.,
Z_{P_{n}}(\lambda)=0
.

Proof.

Since
\lambda\in\mathcal{B}
, there exists
\theta\in(0,\pi/2)
which is a rational multiple of
\pi
such that
\lambda=-1/(2\cos\theta)^{2}
. Write
\theta=\frac{p}{q}\pi
for positive integers

\gcd(p,q)=1
. Note that

. By Lemma

∎

Having a path

whose partition function equals 0 allows us to implement the activity
-1

Z^{\mathsf{in}}_{P,v}(\lambda)+Z^{\mathsf{out}}_{P,v}(\lambda)=Z_{P}(\lambda)=0
,

(3)

2.3
The ratio
R_{\lambda}(G,v)
and a simple way to implement activities

Let
\lambda\in\mathbb{R}_{\neq 0}
. To prove Lemmas
3

5

\frac{Z^{\mathsf{out}}_{G,v}(\lambda)}{Z_{G}(\lambda)}
(rather than
\frac{Z^{\mathsf{in}}_{G,v}(\lambda)}{Z^{\mathsf{out}}_{G,v}(\lambda)}

defined as

The following simple lemma shows how to implement activities using the quantities

Lemma 8
.

Let
\lambda\in\mathbb{R}_{\neq 0}
and

. Let
G^{\prime}
be a graph and
u
be a vertex of
G^{\prime}
such that

. Consider the graph
G
obtained from

by adding a new vertex
v
whose single neighbour is the vertex

. Then,

Z^{\mathsf{out}}_{G,v}(\lambda)\neq 0\mbox{ and }\frac{Z^{\mathsf{in}}_{G,v}(\lambda)}{Z^{\mathsf{out}}_{G,v}(\lambda)}=\lambda r.

Proof.

Note that
Z^{\mathsf{out}}_{G,v}(\lambda)=Z_{G^{\prime}}(\lambda)\neq 0
, where the disequality follows from the fact that the quantity

\frac{Z^{\mathsf{in}}_{G,v}(\lambda)}{Z^{\mathsf{out}}_{G,v}(\lambda)}=\frac{\lambda Z^{\mathsf{out}}_{G^{\prime},u}(\lambda)}{Z_{G^{\prime}}(\lambda)}=\lambda\cdot R_{\lambda}(G^{\prime},u)=\lambda r.\qed

The following functions

and

will be important in what follows:

\begin{gathered}f_{+}:\mathbb{R}\backslash\{-1\}\mapsto\mathbb{R}\backslash\{0\},\mbox{ given by }f_{+}(x)=\frac{1}{1+x}\mbox{ for all }x\neq-1,\\
f_{-}:\mathbb{R}\backslash\{+1\}\mapsto\mathbb{R}\backslash\{0\},\mbox{ given by }f_{-}(x)=\frac{1}{1-x}\mbox{ for all }x\neq+1.\end{gathered}

Definition 3
.

Let
S\subseteq\mathbb{R}
be the set of real numbers defined as follows:
z\in S
iff for some integer

, there exists a sequence
x_{0},\ldots,x_{n}
such that
x_{0}=0
,
x_{n}=z
and for all
i=0,\ldots,n-1
it holds that

\mbox{ either }x_{i+1}=f_{+}(x_{i})\mbox{ or }x_{i+1}=f_{-}(x_{i}).

In other words, the set
S
in Definition
3
can be obtained by the following recursive procedure. Initialise
S_{0}=\{0\}
. For

, define

by first letting
S^{+}_{h+1}=f_{+}(S_{h})
and
S^{-}_{h+1}=f_{-}(S_{h})
and then setting

. The set
S
can then be recovered by taking the union of the sets
S_{h}
, i.e.,
S=\cup^{\infty}_{h=0}S_{h}
.

Our interest in the set

is justified by the following lemma.

Lemma 11
.

Let
\Delta\geq 3
and
\lambda<0
. Suppose that
(\Delta,\lambda)
implements the activities

and

also implements the set of activities

, where

is given in Definition

Proof.

For simplicity, we drop the
\lambda
’s from notation, i.e., we will just write

instead of
Z_{G}(\lambda),Z^{\mathsf{out}}_{G,v}(\lambda),Z^{\mathsf{in}}_{G,v}(\lambda)
.

Since
(\Delta,\lambda)
implements the activities
-1
and
+1
, we have that there exist bipartite graphs
G_{+},G_{-}
of maximum degree at most
\Delta
with terminals
v_{+},v_{-}
, respectively, such that

\displaystyle Z^{\mathsf{out}}_{G_{+},v_{+}}\neq 0\mbox{ and }\frac{Z^{\mathsf{in}}_{G_{+},v_{+}}}{Z^{\mathsf{out}}_{G_{+},v_{+}}}=+1,\quad Z^{\mathsf{out}}_{G_{-},v_{-}}\neq 0\mbox{ and }\frac{Z^{\mathsf{in}}_{G_{-},v_{-}}}{Z^{\mathsf{out}}_{G_{-},v_{-}}}=-1.

Recall also (from Definitions
1
and
2
) that
v_{+},v_{-}
have degree 1 in
G_{+}
and
G_{-}
, respectively.

Consider an arbitrary
z\in S
. Then, there exists a sequence
x_{0},\ldots,x_{n}
such that
x_{0}=0
,
x_{n}=z
and for all

it holds that

\mbox{ either }x_{i+1}=f_{+}(x_{i})\mbox{ or }x_{i+1}=f_{-}(x_{i}).

For

, we will construct inductively a bipartite graph
G_{i}
of maximum degree
\Delta
and specify a vertex

in

with degree at most

such that

. Using this for

in conjuction with Lemma

(\Delta,\lambda)
implements

, as wanted.

We begin with the base case
i=0
. Consider the graph

obtained by adding a new vertex
u
to the graph
G_{-}
and connecting

and
v_{-}
with an edge. Note that

is bipartite and has maximum degree at most
\Delta
; also,

has degree 1 in

. Further, we have

\displaystyle Z^{\mathsf{out}}_{G,u}=Z_{G_{-}}=Z^{\mathsf{in}}_{G_{-},v_{-}}+Z^{\mathsf{out}}_{G_{-},v_{-}}=0,

\displaystyle Z_{G}=Z^{\mathsf{in}}_{G,u}+Z^{\mathsf{out}}_{G,u}=Z^{\mathsf{in}}_{G,u}=\lambda\cdot Z^{\mathsf{out}}_{G_{-},v_{-}}\neq 0.

It follows that
R(G,u)=Z^{\mathsf{out}}_{G,u}/Z_{G}=0
, which completes the proof for

by setting
G_{0}=G
and
u_{0}=u
.

For the induction step, let
i
be an integer satisfying
0\leq i\leq n-1
and assume that
G_{i}
is a bipartite graph of maximum degree at most
\Delta
such that

for some vertex

It is simple to see that all numbers in the set

is in fact the set

of all rational numbers.

Lemma 12

Let
S\subseteq\mathbb{R}
be the set in Definition
3
. Then,
S=\mathbb{Q}
, i.e.,

is the set of all rational numbers.

Proof.

As noted earlier, it is simple to see that

. Thus, we only need to argue that
\mathbb{Q}\subseteq S
.

Since
0\in S
(by taking
n=0
in Definition
3
) and

, we have that

. Note that

f_{-}(f_{-}(f_{+}(x)))=-x\mbox{ for }x\neq-1,0.

(16)

It follows that
-1\in S
. Observe also that
\frac{1}{2},2\in S
since

and

.

We will show that, for some integer

\rho_{0}=\rho
,
\rho_{n}=-1
.

(ii)

\rho_{i}\notin\{0,1/2,1\}
for

.

(iii)

\rho_{i+1}=f_{+}(\rho_{i})
or
\rho_{i+1}=f_{-}(\rho_{i})
for

.

Before proving the existence of such a sequence, we first show how to conclude that
\rho\in S
. To do this, let
x_{i}:=\rho_{n-i}
for

. Properties
(i)
–
(iii)
of the sequence

translate into the following properties of the sequence

(a)

x_{0}=-1
,
x_{n}=\rho
.

(b)

x_{i}\notin\{0,1/2,1\}
for
i=1,2,\ldots,n
.

(c)

x_{i}=f^{-1}_{+}(x_{i-1})
or
x_{i}=f^{-1}_{-}(x_{i-1})

(since by Item

). For the base case

. For the induction step, assume that

for some integer

, our goal is to show that

. The main observation is that the inverses of the functions
f_{-}
and

can be obtained by composing appropriately the functions
f_{-}
and
f_{+}
. Namely, we have that

\displaystyle f^{-1}_{-}(x)=\frac{x-1}{x}=f_{-}(f_{-}(x))\mbox{ for $x\neq 0,1$},

(17)

\displaystyle f^{-1}_{+}(x)=\frac{1-x}{x}=f_{-}(f_{-}(f_{+}(f_{-}(f_{-}(x))))))\mbox{ for $x\neq 0,\frac{1}{2},1$}.

(18)

(
17
) is proved by just making the substitutions. (

) and (
17

equals

and

and

we have that

and

and (

(i)
–
(iii)
. Consider the following set

, which is defined analogously to the set

with the only difference that the starting point for

is the point

(instead of

). Formally,

iff for some integer

\rho_{0}=\rho
,
\rho_{n}=z
and for all

\rho_{i+1}=f_{+}(\rho_{i})

\rho\in\mathbb{Q}

\rho\notin T=\{-1,0,1/2,1,2\}

, consider one with the smallest possible length, which we will denote by

In this section, we give the proof of Lemma

Recall from Section
2.3
that the ratio
R_{\lambda}(G,v)
is defined as
Z^{\mathsf{out}}_{G,v}(\lambda)/Z_{G}(\lambda)
, whenever
Z_{G}(\lambda)\neq 0
. The following standard lemma gives a recursive procedure to compute
R_{\lambda}(G,v)
and will thus be useful in studying the activities that
(\Delta,\lambda)
implements.

Lemma 13
.

Let
\lambda\in\mathbb{R}_{\neq 0}
. Let
G
be a connected graph and let
v
be a vertex all of whose neighbours are in different components of
G\backslash v
. Denote by
G_{1},\ldots,G_{d}
the connected components of
G\backslash v
and by
v_{1},\ldots,v_{d}
the neighbours of
v
in
G_{1},\ldots,G_{d}
. Assume that
Z_{G_{1}}(\lambda),\ldots,Z_{G_{d}}(\lambda)\neq 0
.

Then,
Z_{G}(\lambda)=0
iff
\prod^{d}_{i=1}R_{\lambda}(G_{i},v_{i})=-1/\lambda
. Further, if
Z_{G}(\lambda)\neq 0
, it holds that

R_{\lambda}(G,v)=f\big(R_{\lambda}(G_{1},v_{1}),\ldots,R_{\lambda}(G_{d},v_{d})\big),\mbox{ where }f(x_{1},\ldots,x_{d}):=\frac{1}{1+\lambda\prod^{d}_{i=1}x_{i}}.

Proof.

For convenience, we drop the
\lambda
’s from notation. Using that
Z_{G_{1}},\ldots,Z_{G_{d}}\neq 0
, we have that

Z_{G}=Z^{\mathsf{in}}_{G,v}+Z^{\mathsf{out}}_{G,v}=\lambda\prod^{d}_{i=1}Z^{\mathsf{out}}_{G_{i},v_{i}}+\prod^{d}_{i=1}Z_{G_{i}}=\Big(\prod^{d}_{i=1}Z_{G_{i}}\Big)\Big(\lambda\prod^{d}_{i=1}R(G_{i},v_{i})+1\Big),

and thus
Z_{G}=0
iff
\prod^{d}_{i=1}R(G_{i},v_{i})=-1/\lambda

3.1
Preliminaries on antiferromagnetic 2-spin systems on
\Delta
-regular graphs

In our setting, where every vertex has degree at most
\Delta
, an implementation consumes one of the
\Delta
slots that a vertex has available to connect to other vertices. This is particularly problematic for the case where
\Delta=3
. In the following we circumvent this problem by constructing suitable binary gadgets, so that we can use inapproximability results for computing the partition function of antiferromagnetic 2-spin systems on
\Delta
-regular graphs.

An antiferromagnetic 2-spin system (without an external field) is specified by two parameters
\beta,\gamma>0
such that
\beta\gamma<1
. Let
\mathbf{M}=\{M_{ij}\}_{i,j\in\{0,1\}}
be the matrix
\big[\begin{smallmatrix}\beta&1\\
1&\gamma\end{smallmatrix}\big]
. For a graph
H=(V,E)
, configurations of the 2-spin system are assignments
\sigma:V\rightarrow\{0,1\}
and the weight of a configuration
\sigma
is given by
w_{H,\beta,\gamma}(\sigma)=\prod_{\{u,v\}\in E}M_{\sigma(u),\sigma(v)}
. The partition function of
H
is then given by

Z_{H,\beta,\gamma}=\sum_{\sigma:V\rightarrow\{0,1\}}w_{H,\beta,\gamma}(\sigma)=\sum_{\sigma:V\rightarrow\{0,1\}}\prod_{\{u,v\}\in E}M_{\sigma(u),\sigma(v)}.

For positive parameters
\beta,\gamma
and
c>1
, we consider the following computational problem, where the input is a 3-regular graph
H
.

Name

\#\mathsf{2Spin}(\beta,\gamma,c)
.

Instance

An
n
-vertex graph
H
which is
3
-regular.

Output

A number
\hat{Z}
such that
c^{-n}Z_{H,\beta,\gamma}\leq\hat{Z}\leq c^{n}Z_{H,\beta,\gamma}
.

The case
\beta=\gamma<1
corresponds to the well-known (antiferromagnetic) Ising model. As a corollary of results of Sly and Sun
[
13
]
(see also
[
4
]
), it is known that, for
0<\beta=\gamma<1/3
, there exists
c>1
such that
\#\mathsf{2Spin}(\beta,\beta,c)
is
\mathsf{NP}
-hard, i.e., approximating the partition function
Z_{G,\beta,\beta}
of the Ising model on
3
-regular graphs
H
is
\mathsf{NP}
-hard, even within an exponential factor.
6
6

6

The inapproximability result for the Ising model holds for general degrees
\Delta\geq 3
in the regime
0<\beta=\gamma<(\Delta-2)/\Delta
. While we do not prove it here (since we only need the result for
\Delta=3
), Lemma
15
also holds for general degrees
\Delta\geq 3
in the square

.

Lemma 15
.

Let
\Delta=3
and
\beta,\gamma
be such that

Proof.

Sly and Sun

give a sufficient condition on the range of

The condition in

\lambda_{1}^{\prime}(\lambda_{1}^{\prime}+2)>0

\lambda_{1}^{\prime}\in I_{1}
) and
\lambda_{2}^{\prime}+1>0
(from
\lambda_{2}^{\prime}\in I_{2}
). Finally, for (

\lambda_{2}^{\prime}+1<-\frac{\lambda_{1}^{\prime}(\lambda_{1}^{\prime}+2+\frac{1}{3}|\lambda|^{1/3})}{1+\frac{1}{3}|\lambda|^{1/3}}

1+\lambda_{1}^{\prime}+\lambda_{2}^{\prime}<\lambda_{1}^{\prime}\Big(1-\frac{\lambda_{1}^{\prime}+2+\frac{1}{3}|\lambda|^{1/3}}{1+\frac{1}{3}|\lambda|^{1/3}}\Big)=-\frac{\lambda_{1}^{\prime}(\lambda_{1}^{\prime}+1)}{1+\frac{1}{3}|\lambda|^{1/3}}<0,

Next, we show that
\beta,\gamma<1/3
. To show that
\beta<1/3
, using (
37
), we only need to show that

(\lambda_{1}^{\prime}+1)^{2}+\lambda_{2}^{\prime}<-\frac{1}{3}|\lambda|^{1/3}(1+\lambda_{1}^{\prime}+\lambda_{2}^{\prime}),\mbox{ or equivalently }(\lambda_{2}^{\prime}+1)(1+\frac{1}{3}|\lambda|^{1/3})<-\lambda_{1}^{\prime}(\lambda_{1}^{\prime}+2+\frac{1}{3}|\lambda|^{1/3}),

which is true since
\lambda_{2}^{\prime}\in I_{2}
. To show that
\gamma<1/3
, using (
37
) again, we see that the inequality
\gamma<1/3
is equivalent to

-3|\lambda|^{1/3}(1+\lambda_{2}^{\prime})>1+\lambda_{1}^{\prime}+\lambda_{2}^{\prime},\mbox{ or equivalently }\lambda_{2}^{\prime}<-1-\frac{\lambda_{1}^{\prime}}{1+3|\lambda|^{1/3}},

Since
\lambda_{1}^{\prime}<0
and
\lambda_{2}^{\prime}<-1-\frac{\lambda_{1}^{\prime}(\lambda_{1}^{\prime}+2+\frac{1}{3}|\lambda|^{1/3})}{1+\frac{1}{3}|\lambda|^{1/3}}
, we only need to show that

\frac{\lambda_{1}^{\prime}+2+\frac{1}{3}|\lambda|^{1/3}}{1+\frac{1}{3}|\lambda|^{1/3}}<\frac{1}{1+3|\lambda|^{1/3}},\mbox{ or }(\lambda_{1}^{\prime}+2)(1+3|\lambda|^{1/3})+\frac{1}{3}|\lambda|^{1/3}(1+3|\lambda|^{1/3})<1+\frac{1}{3}|\lambda|^{1/3},

which is true since, from
\lambda_{1}^{\prime}\in I_{1}
, we have
(\lambda_{1}^{\prime}+2)(1+3|\lambda|^{1/3})<-(|\lambda|^{2/3}-1)
.

Thus, we have shown that
0<\beta,\gamma<1/3
, thus completing the proof of Lemma
16
.
∎
