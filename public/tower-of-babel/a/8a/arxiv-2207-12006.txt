Stabilization of a Multi-Dimensional System of Hyperbolic Balance Laws
Michael Herty, Ferdinand Thein

Abstract
We are interested in the feedback stabilization of systems described by Hamilton-Jacobi type equations in ℝ n \mathbb{R}^{n} . A reformulation leads to a stabilization problem for a multi-dimensional system of n n hyperbolic partial differential equations. Using a novel Lyapunov function taking into account the multi-dimensional geometry we show stabilization in L 2 L^{2} for the arising system using a suitable feedback control. We further present examples of such systems partially based on a forming process.

2
Stabilization of Multi-Dimensional Linear Hyperbolic Balance Laws

We are interested in the following initial boundary value problem (IBVP) for the given system of PDEs

\displaystyle\begin{cases}\frac{\partial}{\partial t}\mathbf{w}+\sum_{k=1}^{d}\mathbf{A}^{(k)}(\mathbf{x})\frac{\partial}{\partial x_{k}}\mathbf{w}(t,\mathbf{x})+\mathbf{B}(\mathbf{x})\mathbf{w}(t,\mathbf{x})&=0,\;(t,\mathbf{x})\in[0,T)\times\Omega\\
\mathbf{w}(0,\mathbf{x})&=\mathbf{w}_{0}(\mathbf{x}),\;\mathbf{x}\in\Omega,\\
\mathbf{w}(t,\mathbf{x})&=\mathbf{w}_{BC}(t,\mathbf{x}),\;(t,\mathbf{x})\in[0,T)\times\partial\Omega\end{cases}

(2.1)

Here
\mathbf{w}\equiv(w_{1}(t,\mathbf{x}),\dots,w_{n}(t,\mathbf{x}))^{T}
is the vector of unknowns
and
\Omega\subset\mathbb{R}^{d}
a bounded domain with sufficiently smooth boundary
\partial\Omega
.
Moreover,
\mathbf{A}^{(k)}
and
\mathbf{B}
are sufficiently smooth and bounded
n\times n
real matrices.

Additionally, the matrices
\mathbf{A}^{(k)}(\mathbf{x})=(a_{ii}^{(k)}(\mathbf{x}))_{i=1,\dots,n}
are assumed to be diagonal matrices and hence have a full set of eigenvectors. The system is hyperbolic.
With the convention
t\equiv x_{0}
and
\mathbf{A}_{0}:=\mathbf{Id}
a compressed form of system (
2.1
) is

\displaystyle\sum_{k=0}^{d}\mathbf{A}^{(k)}(\mathbf{x})\frac{\partial}{\partial x_{k}}\mathbf{w}+\mathbf{B}(\mathbf{x})\mathbf{w}=0.

(2.2)

This system is symmetric hyperbolic in the sense of Friedrichs, i.e., all matrices
\mathbf{A}^{(k)}
are symmetric and
\mathbf{A}_{0}=\mathbf{Id}>0
, see
[
24
]
.
The boundary condition will be made more precise later on.
According to the references
[
32
,
36
,
40
,
18
]
there exists a solution
\mathbf{w}\in C^{1}((0,T),H^{s}(\Omega))^{n}

,s\geq 1+\frac{d}{2}

if the initial and boundary data are sufficiently smooth.
In order to study the Lyapunov function it is beneficial to rewrite the equation for each unknown
w_{i}
as follows

\displaystyle\frac{\partial}{\partial t}w_{i}(t,\mathbf{x})+\mathbf{a}_{i}(\mathbf{x})\cdot\nabla w_{i}(t,\mathbf{x})+\mathbf{b}_{i}(\mathbf{x})\cdot\mathbf{w}(t,\mathbf{x})=0,

with

\displaystyle\mathbf{a}_{i}:=(a_{ii}^{(1)},\dots,a_{ii}^{(d)}),\;\text{and}\hskip 10.00002pt\mathbf{b}_{i}:=(b_{i1},\dots,b_{in}).

We assume the following non-characteristic condition

\displaystyle\mathbf{a}_{i}(\mathbf{x})\neq\mathbf{0},\,i=1,\dots n.

(2.3)

In the case
\mathbf{a}_{i}(\mathbf{x})=\mathbf{0}
the PDE for
w_{i}
would degenerate to an ODE and thus this case is of no interest in the present work.
For later use, let

\displaystyle\mathcal{E}(\mu(\mathbf{x}))

\displaystyle:=\textup{diag}(\exp(\mu_{1}(\mathbf{x})),\dots,\exp(\mu_{n}(\mathbf{x}))),

\displaystyle\mathcal{A}(t,\mathbf{x})

\displaystyle:=\left(\mathbf{w}^{T}\mathbf{A}^{(1)}\mathcal{E}\mathbf{w},\dots,\mathbf{w}^{T}\mathbf{A}^{(d)}\mathcal{E}\mathbf{w}\right)^{T},

\displaystyle\mathcal{M}^{(k)}(\mathbf{x})

\displaystyle:=\textup{diag}\left(\frac{\partial}{\partial x_{k}}\mu_{1}(\mathbf{x}),\dots,\frac{\partial}{\partial x_{k}}\mu_{n}(\mathbf{x})\right),\,k=1,\dots,d.

The functions
\mu_{1}(\mathbf{x}),\dots,\mu_{n}(\mathbf{x})
will be defined in the subsequent theorem by (
2.7
).
Further, we assume that there exists a diagonal matrix
\mathcal{D}
such that we have

\displaystyle-\mathbf{v}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{v}\leq\mathbf{v}^{T}\mathcal{D}\mathcal{E}\mathbf{v},\;\forall\mathbf{v}\in\mathbb{R}^{n}.

(2.4)

This kind of dissipativity condition for the linear source term ensures together with (
2.3
) that we find suited weights
\mu_{i}
using (
2.7
).
There are different possible choices for
\mathcal{D}
depending on the problem under consideration.
We will comment on this later on, see Remark
3.4
and in Section
4
for some examples.
The boundary
\partial\Omega
will be separated in the controllable and uncontrollable part, i.e. for
i=1,\dots,n

\displaystyle\Gamma_{i}^{+}

\displaystyle:=\left\{\left.\mathbf{x}\in\partial\Omega\,\right|\,\mathbf{a}_{i}\cdot\mathbf{n}\geq 0\right\},

\displaystyle\Gamma_{i}^{-}

\displaystyle:=\left\{\left.\mathbf{x}\in\partial\Omega\,\right|\,\mathbf{a}_{i}\cdot\mathbf{n}<0\right\}.

The part
\Gamma_{i}^{-}
is then split disjointly into the part
\mathcal{C}_{i}
where we apply a feedback control
u_{i}
and a part
\mathcal{Z}_{i}
where we prescribe
w_{i}=0
.

Finally we want to specify the notion of exponential stability. We call a solution
\mathbf{w}\in C^{1}(0,T;H^{s}(\Omega))^{n}
for
s\geq 1+\frac{d}{2}
of the system
(
2.1
) exponentially stable in the
L^{2}-
sense, iff

\displaystyle\|\mathbf{w}(t,.)\|_{L^{2}(\Omega)}\leq\exp(-Ct)\|\mathbf{w}(0,.)\|_{L^{2}(\Omega)},\,C\in\mathbb{R}_{>0}.

(2.5)

The Lyapunov function we will introduce in Theorem
2.1
is equivalent to the
L^{2}(\Omega)
norm.
Now, we state the main result of this paper.

Theorem 2.1
.

Assume (
2.4
) and let
\mathbf{w}(t,\mathbf{x})\in C^{1}\left((0,T),H^{s}(\Omega)\right)^{n}
,
s\geq 1+d/2,

be a solution to the IBVP (
2.1
). Define the Lyapunov function by

\displaystyle L(t)=\int_{\Omega}\mathbf{w}(t,\mathbf{x})^{T}\mathcal{E}(\mu(\mathbf{x}))\mathbf{w}(t,\mathbf{x})\,\textup{d}\mathbf{x}

(2.6)

and assume that there exists
\mu_{i}(\mathbf{x})\in H^{s}(\Omega)
such that

\displaystyle\begin{split}\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)+\mathcal{D}&=-\textup{diag}\left(C^{(i)}_{L}\right)\\
\text{or written rowwise}\quad\mathbf{a}_{i}\cdot\nabla\mu_{i}(\mathbf{x})+\nabla\cdot\mathbf{a}_{i}+\mathcal{D}_{ii}&=-C_{L}^{(i)},\;C^{(i)}_{L}\geq C_{L}>0\end{split}

(2.7)

holds true for some value
C_{L}\in\mathbb{R}_{>0}
.
The boundary condition for (
2.1
) is given by

\displaystyle\mathbf{w}_{BC,i}(t,\mathbf{x})=\begin{cases}0&,\,\mathbf{x}\in\mathcal{Z}_{i}\\
u_{i}(t,\mathbf{x})&,\,\mathbf{x}\in\mathcal{C}_{i}\end{cases}\;t\in[0,T),\;i=1,\dots,n

where we assume that for
i\in\{1,\dots,n\}
the feedback controls
u_{i}
satisfy

\displaystyle-\sum_{i=1}^{n}\int_{\mathcal{C}_{i}}u_{i}(t,\mathbf{x})^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\leq\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

(2.8)

Then, the Lyapunov function satisfies

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)\leq-C_{L}L(t).

Further, the solution
\mathbf{w}
of the IBVP (
2.1
) is exponentially stable in the
L^{2}-
sense (
2.5
).

The proof is given in the following section for better readability. We refer to Remark
3.3
for conditions under which
u_{i}
exists. In Remark
3.6
we comment on the
solvability of the equation (
2.7
) and in Remark
3.4
for conditions on the existence of
\mathcal{D}
in assumption (
2.4
). Note that the choice of
s
in the
space
H^{s}
guarantees that
\mu
and
\mathbf{w}
are differentiable in
\mathbf{x}
by Sobolev embedding.

3
Proof of Theorem
2.1

Proof.

We want to show that the Lyapunov function (
2.6
) decays exponentially fast under the given conditions.
We obtain for the time derivative of the Lyapunov function

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)

\displaystyle=\frac{\textup{d}}{\textup{d}t}\int_{\Omega}\mathbf{w}^{T}\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}=\int_{\Omega}\frac{\partial}{\partial t}\mathbf{w}^{T}\mathcal{E}\mathbf{w}+\mathbf{w}^{T}\mathcal{E}\frac{\partial}{\partial t}\mathbf{w}\,\textup{d}\mathbf{x}.

Replacing the time derivative of
\mathbf{w}
using the PDE system (
2.1
) gives

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)

\displaystyle=\int_{\Omega}\left[-\sum_{k=1}^{d}\mathbf{A}^{(k)}\frac{\partial}{\partial x_{k}}\mathbf{w}-\mathbf{B}\mathbf{w}\right]^{T}\mathcal{E}\mathbf{w}+\mathbf{w}^{T}\mathcal{E}\left[-\sum_{k=1}^{d}\mathbf{A}^{(k)}\frac{\partial}{\partial x_{k}}\mathbf{w}-\mathbf{B}\mathbf{w}\right]\,\textup{d}\mathbf{x}

\displaystyle=-\int_{\Omega}\sum_{k=1}^{d}\left[\left(\frac{\partial}{\partial x_{k}}\mathbf{w}\right)^{T}\mathbf{A}^{(k)}\mathcal{E}\mathbf{w}+\mathbf{w}^{T}\mathcal{E}\mathbf{A}^{(k)}\left(\frac{\partial}{\partial x_{k}}\mathbf{w}\right)\right]

\displaystyle+\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\,\textup{d}\mathbf{x}

Now with using the product rule and introducing the abbreviation
\mathcal{A}
we obtain

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)

\displaystyle=-\int_{\Omega}\sum_{k=1}^{d}\left[\frac{\partial}{\partial x_{k}}\left(\mathbf{w}^{T}\mathbf{A}^{(k)}\mathcal{E}\mathbf{w}\right)-\mathbf{w}^{T}\left(\frac{\partial}{\partial x_{k}}\left(\mathcal{E}\mathbf{A}^{(k)}\right)\right)\mathbf{w}\right]

\displaystyle+\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\,\textup{d}\mathbf{x}

\displaystyle=-\int_{\Omega}\nabla\cdot\mathcal{A}\,\textup{d}\mathbf{x}+\int_{\Omega}\mathbf{w}^{T}\left(\sum_{k=1}^{d}\frac{\partial}{\partial x_{k}}\left(\mathcal{E}\mathbf{A}^{(k)}\right)\right)\mathbf{w}-\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\,\textup{d}\mathbf{x}

\displaystyle=-\underbrace{\int_{\partial\Omega}\mathcal{A}\cdot\mathbf{n}\,\textup{d}\mathbf{x}}_{=:\mathcal{B}(t)}

\displaystyle+\underbrace{\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}-\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\right]\mathbf{w}\,\textup{d}\mathbf{x}}_{=:\mathcal{I}(t)}.

In the following we split the proof into two parts. First we show that the boundary term
\mathcal{B}(t)
is non-negative under the given conditions.
In the second part we estimate
\mathcal{I}(t)
such that we can use Gronwalls Lemma to show the decay of the Lyapunov function.

3.1
Estimating the Boundary Integral

In the following we want to discuss the boundary term. We have

\displaystyle\mathcal{A}\cdot\mathbf{n}

\displaystyle=\sum_{k=1}^{d}\mathbf{w}^{T}\mathbf{A}^{(k)}\mathcal{E}\mathbf{w}n_{k}=\sum_{k=1}^{d}\sum_{i=1}^{n}w_{i}a_{ii}^{(k)}\exp(\mu_{i}(\mathbf{x}))w_{i}n_{k}

\displaystyle=\sum_{i=1}^{n}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\sum_{k=1}^{d}a_{ii}^{(k)}n_{k}=\sum_{i=1}^{n}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)

and thus

\displaystyle\mathcal{B}(t)=\int_{\partial\Omega}\mathcal{A}\cdot\mathbf{n}\,\textup{d}\mathbf{x}=\sum_{i=1}^{n}\int_{\partial\Omega}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\,\textup{d}\mathbf{x}.

Using the partitioning of the boundary introduced before we rewrite the boundary term and obtain

\displaystyle\mathcal{B}(t)

\displaystyle=\int_{\partial\Omega}\mathcal{A}\cdot\mathbf{n}\,\textup{d}\mathbf{x}

\displaystyle=\sum_{i=1}^{n}\left[\int_{\Gamma_{i}^{+}}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\,\textup{d}\mathbf{x}+\int_{\Gamma_{i}^{-}}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\,\textup{d}\mathbf{x}\right]

\displaystyle=\sum_{i=1}^{n}\left[\int_{\Gamma_{i}^{+}}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\,\textup{d}\mathbf{x}+\int_{\mathcal{C}_{i}}u_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\,\textup{d}\mathbf{x}\right]

\displaystyle\geq 0.

3.2
Estimating the Volume Integral

We now want to study the expression

\displaystyle\mathcal{I}(t):=\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}-\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\right]\mathbf{w}\,\textup{d}\mathbf{x}.

Since
\mathcal{M}^{(k)}
and
\mathbf{A}^{(k)}
are diagonal matrices we need to discuss the second term, i.e.

\displaystyle\mathcal{S}(t)

\displaystyle:=-\int_{\Omega}\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\,\textup{d}\mathbf{x}

where the integrand is a symmetric quadratic form. By assumption (
2.4
) there exists a diagonal matrix
\mathcal{D}
such that

\displaystyle-\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\leq\mathbf{w}^{T}\mathcal{D}\mathcal{E}\mathbf{w}

holds and thus we have

\displaystyle\mathcal{S}(t)

\displaystyle=-\int_{\Omega}\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}\,\textup{d}\mathbf{x}\leq\int_{\Omega}\mathbf{w}^{T}\mathcal{D}\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}.

Altogether we hence obtain

\displaystyle\mathcal{I}(t)

\displaystyle=\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}\right]\mathbf{w}+\mathcal{S}(t)

\displaystyle\leq\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}\right]\mathbf{w}+\int_{\Omega}\mathbf{w}^{T}\mathcal{D}\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}.

Since the
\mu_{i}
satisfy (
2.7
) we further yield

\displaystyle\mathcal{I}(t)

\displaystyle\leq\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)+\mathcal{D}\right]\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}

\displaystyle=-\int_{\Omega}\mathbf{w}^{T}\textup{diag}\left(C_{L}^{(i)}\right)\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}=-\sum_{i=1}^{n}C_{L}^{(i)}\int_{\Omega}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

Altogether we yield for the Lyapunov function

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)=-\mathcal{B}(t)+\mathcal{I}(t)\leq\mathcal{I}(t)\leq-\sum_{i=1}^{n}C_{L}^{(i)}\int_{\Omega}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\leq-C_{L}L(t).

Applying Gronwalls Lemma gives the claimed exponential decay and thus the proof is complete.
∎

Remark 3.1
.

It is a question of interest whether the obtained result can be extended to the exponential stability in the corresponding
H^{s}
-norm.
The basic strategy is outlined in
[
5
]
(Chap. 4, pp. 153).
The Lyapunov function can be defined by

\displaystyle L(t):=\sum_{|\alpha|\leq s}\left\|\mathcal{E}\left(\mu^{(\alpha)}\right)^{\frac{1}{2}}\partial^{\alpha}\mathbf{u}\right\|^{2}_{2}.

(3.1)

Note that by introducing the
\mathcal{E}\left(\mu^{(\alpha)}\right)
we want to highlight that in principal it is possible to choose suited weight functions for every occurring multi-index
|\alpha|\leq s
.
Once the Lyapunov function is introduced the strategy is the same since due to the governing PDE (
2.1
) the new system obtained by differentiation has the same structure.
However, one has to make sure that the new terms fulfill the desired assumptions made for the main theorem. Once this verified the arguments are similar.

Remark 3.2
.

Theorem
2.1
is formulated for solutions being in
H^{s}
and thus providing enough smoothness for the steps thorughout the proof.
However, it is pointed out in
[
5
]
(Chap. 2, p. 64) and
[

]
(Lem. 4.2) that due to the density of

functions in

it is possible to transfer the obtained results to more

In the following we want to discuss different special cases which lead to mathematical simplifications or situations of particular interest.

Remark 3.3
.

The inequality for the control
u_{i}
can be simplified under additional assumptions.

(i)

A possible simplifying assumption on the controls is that they are uniform in space, i.e.
u_{i}=u_{i}(t)
.
This leads to the following condition for the controls

\displaystyle-\sum_{i=1}^{n}u_{i}(t)^{2}\int_{\mathcal{C}_{i}}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\leq\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

(ii)

Further the same control may be applied to all components which leads to
u_{i}\equiv u(t,\mathbf{x}),\,i=1,\dots,n
.
This leads to the following condition for the controls

\displaystyle-\sum_{i=1}^{n}\int_{\mathcal{C}_{i}}u(t,\mathbf{x})^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\leq\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

(iii)

Assume that both previous assumptions hold, i.e.
u_{i}\equiv u(t),\,i=1,\dots,n
. Then we can explicitly give a condition for the feedback control as

\displaystyle u(t)^{2}\leq-\left(\sum_{i=1}^{n}\int_{\mathcal{C}_{i}}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\right)^{-1}\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

(3.2)

Remark 3.4
.

We comment on the choice of the matrix
\mathcal{D}
.

(i)

In the general case the following estimate always holds

\displaystyle-\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}

\displaystyle=-2\mathbf{w}^{T}\mathbf{B}^{T}\underbrace{\mathcal{E}}_{>0}\mathbf{w}=-2\underbrace{\mathbf{w}^{T}\mathcal{E}^{\frac{1}{2}}}_{:=\mathbf{y}^{T}}\underbrace{\mathcal{E}^{-\frac{1}{2}}\mathbf{B}^{T}\mathcal{E}^{\frac{1}{2}}}_{=:\mathbf{Q}}\underbrace{\mathcal{E}^{\frac{1}{2}}\mathbf{w}}_{=:\mathbf{y}}

\displaystyle\leq C(\mathbf{Q})\mathbf{y}^{T}\mathbf{y}=C(\mathbf{Q})\mathbf{w}^{T}\mathcal{E}\mathbf{w}.

The constant
C(\mathbf{Q})
depends on the minimal eigenvalue of
\mathbf{Q}+\mathbf{Q}^{T}
.

(ii)

If
\mathbf{B}
is symmetric we can improve the estimate using the minimal eigenvalue
\lambda_{min}\in Spec(\mathbf{B})\subset\mathbb{R}

\displaystyle-\mathbf{w}^{T}\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\mathbf{w}=-2\mathbf{w}^{T}\mathbf{B}^{T}\mathcal{E}\mathbf{w}\leq-2\lambda_{min}\mathbf{w}^{T}\mathcal{E}\mathbf{w}.

This corresponds to the matrix
\mathcal{D}=-2\lambda_{min}\textup{{Id}}
.

(iii)

In the case that
\mathbf{B}
is a diagonal matrix itself we simply have
\mathcal{D}=-2\mathbf{B}
without any assumption.

(iv)

If the quadratic form is positive definite, the source term is estimated by
\mathcal{S}(t)\leq 0
and thus equation (
2.7
) simplifies accordingly.

Case (iii) of Remark
3.4
is a special case of interest since it leads to the following result.

Corollary 3.5
.

Let the assumption of Theorem (
2.1
) hold true. Additionally assume that
\mathbf{B}
is a diagonal matrix. The Lyapunov function is given as

\displaystyle L(t)=\int_{\Omega}\mathbf{w}(t,\mathbf{x})^{T}\mathcal{E}(\mu(\mathbf{x}))\mathbf{w}(t,\mathbf{x})\,\textup{d}\mathbf{x}

where we assume that there exists
\mu_{i}(\mathbf{x})\in H^{s}(\Omega)
satisfy

\displaystyle\begin{split}\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)-2\mathbf{B}&=-C_{L}\mathbf{Id}\\
\text{or written rowwise}\quad\mathbf{a}_{i}\cdot\nabla\mu_{i}(\mathbf{x})+\nabla\cdot\mathbf{a}_{i}-2\mathbf{B}_{ii}&=-C_{L},\;C_{L}>0\end{split}

(3.3)

for some value
C_{L}\in\mathbb{R}_{>0}
.
The boundary condition for (
2.1
) is given by

\displaystyle\mathbf{w}_{BC,i}(t,\mathbf{x})=\begin{cases}0&,\,\mathbf{x}\in\mathcal{Z}_{i}\\
u_{i}(t,\mathbf{x})&,\,\mathbf{x}\in\mathcal{C}_{i}\end{cases}\;t\in[0,T),\;i=1,\dots,n

where the
u_{i}
satisfies

\displaystyle-\sum_{i=1}^{n}\int_{\mathcal{C}_{i}}u_{i}(t,\mathbf{x})^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}=\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\mathbf{a}_{i}\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

(3.4)

Then the Lyapunov function satisfies

\displaystyle L(t)=L(0)\exp(-C_{L}t).

and thus the solution
\mathbf{w}
of the IBVP (
2.1
) is asymptotically stable in the
L^{2}-
sense.

Proof.

The proof basically follows the same steps as the previous one. With the proposed choice of the control we obtain
\mathcal{B}(t)=0
.
For the volume integral
\mathcal{I}(t)
we have

\displaystyle\mathcal{I}(t)

\displaystyle=\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}-\left(\mathbf{B}^{T}\mathcal{E}+\mathcal{E}\mathbf{B}\right)\right]\mathbf{w}\,\textup{d}\mathbf{x}

\displaystyle=\int_{\Omega}\mathbf{w}^{T}\left[\sum_{k=1}^{d}\left(\mathcal{M}^{(k)}\mathbf{A}^{(k)}+\frac{\partial}{\partial x_{k}}\mathbf{A}^{(k)}\right)\mathcal{E}-2\mathbf{B}\mathcal{E}\right]\mathbf{w}\,\textup{d}\mathbf{x}

\displaystyle=-\int_{\Omega}\mathbf{w}^{T}C_{L}\mathcal{E}\mathbf{w}\,\textup{d}\mathbf{x}=-C_{L}\sum_{i=1}^{n}\int_{\Omega}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

Together this gives

\displaystyle\frac{\textup{d}}{\textup{d}t}L(t)=\mathcal{B}(t)+\mathcal{I}(t)=\mathcal{I}(t)=-C_{L}\sum_{i=1}^{n}\int_{\Omega}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}=-C_{L}L(t).

∎

Remark 3.6
.

An important task that remains is the calculation of the weights
\mu_{i}
which have to satisfy (
2.7
)

\mathbf{a}_{i}\cdot\nabla\mu_{i}(\mathbf{x})+\nabla\cdot\mathbf{a}_{i}+\mathcal{D}_{ii}=-C_{L}^{(i)}.

Note that this PDE is an inhomogeneous linear first order transport PDE in
d
dimensions with variable coefficients.
A classical approach to obtain a solution is the method of characteristics as presented e.g.
[
23
]
.
However, we want to emphasize that although we are considering a control problem on a bounded domain, the weights
\mu_{i}
can be determined from (
2.7
) without any additional restrictions.
Thus it is worth noting that only the PDE has to be satisfied and there is freedom in the choice of further conditions which may be due to constraints from the application.
Moreover further simplifications are possible and will be presented using particular examples in Section
4
.

4
Application to Stabilization of Hamilton–Jacobi Equations

In this section we discuss the application of the stabilization result.
In particular, we show conditions for the solvability of equation (
2.7
) as well as on the particular structure of the matrices
\mathbf{A}^{(k)}.

Theorem (
2.1
) has been motivated by a stabilization problem arising in a forming process leading to the question of stabilization of Hamilton–Jacobi equations.
We start by exploring formally the relation to this class of PDEs.
Hamilton-Jacobi equations for describing the level–set of a deforming process have been used e.g. in
[
1
]
.
Here, a Titanium deformation process needed to be stabilized at a desired level–set by applying an external force at the boundary. The quantity of interest

\phi=\phi(t,\mathbf{x}),\;\phi:\Omega\to\mathbb{R}

for
\Omega\in\mathbb{R}^{n}
has been used to describe the boundary between formed and unformed material. The evolution of this set
\{(t,\mathbf{x}): \phi(t,\mathbf{x})=0\}
is mathematically described by a Hamilton-Jacobi equation

\displaystyle\begin{cases}\frac{\partial\phi}{\partial t}+H(\mathbf{x},\nabla\phi)&=0,\;(t,\mathbf{x})\in(0,T)\times\Omega,\\
\phi(0,\mathbf{x})&=\phi_{0}(\mathbf{x}),\;\mathbf{x}\in\Omega,\\
\nabla\phi(t,\mathbf{x})\cdot\mathbf{n}&=0,\;(t,\mathbf{x})\in[0,T)\times\partial\Omega\end{cases}

(4.1)

for an Hamiltonian
H
that describes the flow field induced by the process. If we introduce the new variable
\mathbf{\Psi}(t,\mathbf{x})=\nabla\phi(t,\mathbf{x}),
i.e.,

\psi_{i}:=\partial_{x_{i}}\phi.

we formally transform the initial equation into a system of (hyperbolic) PDEs. The system (
4.1
) reads then

\displaystyle\begin{cases}\frac{\partial}{\partial t}\mathbf{\Psi}+\nabla(H(\mathbf{x},\mathbf{\Psi}))&=0,\;(t,\mathbf{x})\in(0,T)\times\Omega\\
\mathbf{\Psi}(0,\mathbf{x})&=\nabla\phi_{0}(\mathbf{x}),\;\mathbf{x}\in\Omega,\\
\mathbf{\Psi}(t,\mathbf{x})&=\mathbf{\Psi}_{BC}(t,\mathbf{x}),\;(t,\mathbf{x})\in[0,T)\times\partial\Omega\end{cases}

(4.2)

Note that von-Neumann boundary conditions in (
4.1
) are now Dirichlet boundary condition in (
4.2
) understood e.g. in the sense of
[
4
]
.
In view of the stabilization of the process we then linearize
H
at a desired reference state
\overline{\mathbf{\Psi}}
and obtain

\displaystyle H(\mathbf{x},\mathbf{\Psi})\approx H(\mathbf{x},\overline{\mathbf{\Psi}})+\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}})\cdot\left(\mathbf{\Psi}-\overline{\mathbf{\Psi}}\right).

(4.3)

Denote by
\mathbf{\overline{\Psi}}=\nabla\overline{\phi}
and assume
\overline{\phi}
fulfills (
4.2
).
Deviations of this desired state are considered and hence
\mathbf{\Psi}
is given by

\mathbf{\Psi}=\mathbf{\overline{\Psi}}+\mathbf{w},

for some initial disturbance we assume
w_{i}(0,\mathbf{x})\neq 0
. By the following computation we obtain a linear system using (
4.3
) starting from (
4.2
)

\displaystyle 0

\displaystyle=\frac{\partial}{\partial t}\mathbf{\Psi}+\nabla(H(\mathbf{x},\mathbf{\Psi}))

\displaystyle\approx\frac{\partial}{\partial t}\mathbf{\Psi}+\nabla(H(\mathbf{x},\overline{\mathbf{\Psi}})+\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}})\cdot\left(\mathbf{\Psi}-\overline{\mathbf{\Psi}}\right))

\displaystyle=\frac{\partial}{\partial t}(\mathbf{\overline{\Psi}}+\mathbf{w})+\nabla(H(\mathbf{x},\overline{\mathbf{\Psi}})+\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}})\cdot\mathbf{w})

\displaystyle=\frac{\partial}{\partial t}\mathbf{w}+\nabla\left(\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}})\cdot\mathbf{w}\right).

By definition of
\mathbf{\Psi}
and
\mathbf{\overline{\Psi}}
we have

\displaystyle\frac{\partial}{\partial x_{i}}\Psi_{j}=\frac{\partial^{2}}{\partial x_{i}\partial x_{j}}\phi=\frac{\partial}{\partial x_{j}}\Psi_{i},\hskip 10.00002pt\text{and}\hskip 10.00002pt\frac{\partial}{\partial x_{i}}\overline{\Psi}_{j}=\frac{\partial^{2}}{\partial x_{i}\partial x_{j}}\overline{\phi}=\frac{\partial}{\partial x_{j}}\overline{\Psi}_{i}

which implies

\displaystyle\frac{\partial}{\partial x_{i}}w_{j}=\frac{\partial}{\partial x_{j}}w_{i}.

(4.4)

Furthermore, we denote

H_{k}(\mathbf{x}):=\left.\frac{\partial}{\partial\psi_{k}}H(\mathbf{x},\mathbf{\Psi})\right|_{\mathbf{\Psi}=\overline{\mathbf{\Psi}}}

to obtain the following set of equations for
i=1,\dots,n

\displaystyle 0=\frac{\partial}{\partial t}w_{i}+\frac{\partial}{\partial x_{i}}\left(\sum_{k=1}^{n}H_{k}\cdot w_{k}\right)=\frac{\partial}{\partial t}w_{i}+\sum_{k=1}^{n}\left[\frac{\partial H_{k}}{\partial x_{i}}w_{k}+H_{k}\frac{\partial w_{k}}{\partial x_{i}}\right]

Thus by introducing the source term

S_{i}=-\sum_{k=1}^{n}\frac{\partial H_{k}}{\partial x_{i}}w_{k}

and using (
4.4
) to write

\frac{\partial w_{k}}{\partial x_{i}}=\frac{\partial w_{i}}{\partial x_{k}}

we obtain the following system of
n
(transport) PDEs studied in the Theorem (
2.1
)

\displaystyle\begin{split}\frac{\partial}{\partial t}w_{i}(t,\mathbf{x})+\sum_{k=1}^{n}H_{k}(\mathbf{x})\frac{\partial w_{i}}{\partial x_{k}}(t,\mathbf{x})&=S_{i}\\
\text{or}\quad\frac{\partial}{\partial t}w_{i}(t,\mathbf{x})+\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}})\cdot\nabla w_{i}(t,\mathbf{x})&=S_{i}.\end{split}

(4.5)

Note that the obtained equations (
4.5
) are linear in
w_{i}
since
H
and the reference state
\overline{\mathbf{\Psi}}
are assumed to be known.
Moreover the sources are algebraic for the same reason and are responsible for the coupling of the equations.
Note that the source term vanishes identically for
\nabla_{\mathbf{\Psi}}H(.,\overline{\mathbf{\Psi}})=\nabla_{\mathbf{\Psi}}H(\overline{\mathbf{\Psi}})\in\mathbb{R}^{n}
, i.e. the gradient is constant.
This is in fact the case for the actual forming process, see
[
1
]
. However, the presented result extends this towards more general
S_{i}.

For the proof of the result the compact vector form is suitable. We show here the relation towards
H.
Let the matrices

\mathbf{A}^{(k)}(\mathbf{x}):=H_{k}(\mathbf{x})\mathbf{Id},\;k=1,\dots,n

be given and

\mathbf{B}(\mathbf{x}):=\left(\frac{\partial H_{k}}{\partial x_{i}}\right)_{i,k=1,\dots,n},\;\mathbf{S}=-\mathbf{B}\mathbf{w}.\;

This leads to the system

\displaystyle\frac{\partial}{\partial t}\mathbf{w}+\sum_{k=1}^{n}\mathbf{A}^{(k)}(\mathbf{x})\frac{\partial}{\partial x_{k}}\mathbf{w}+\mathbf{B}(\mathbf{x})\mathbf{w}=0.

The matrices
\mathbf{A}^{(k)}
are diagonal matrices with the multiple eigenvalue
H_{k}(\mathbf{x})
and hence have a full set of eigenvectors.
By equation (
4.5
) we conclude

\mathbf{a}_{i}(\mathbf{x})=\nabla_{\mathbf{\Psi}}H(\mathbf{x},\overline{\mathbf{\Psi}}).

In the following sections we discuss particular cases that may serve as examples and simplifications.

4.1
Potential Gradient Flow

A particular case of interest is a Hamiltonian of the form

\displaystyle H(\mathbf{x},\mathbf{\Psi})=\tilde{\mathbf{H}}(\mathbf{x})\cdot\mathbf{\Psi}.

If additionally
\tilde{\mathbf{H}}(\mathbf{x})
is the gradient of a potential
\varphi(\mathbf{x})
we have

\displaystyle\tilde{\mathbf{H}}(\mathbf{x})

\displaystyle=\nabla_{\mathbf{\Psi}}H(\mathbf{x},\mathbf{\Psi})=\nabla\varphi(\mathbf{x}),

\displaystyle\mathbf{B}(\mathbf{x})

\displaystyle=\left(\frac{\partial H_{j}}{\partial x_{i}}\right)_{i,j=1,\dots,n}=\left(\frac{\partial}{\partial x_{i}}\frac{\partial\varphi}{\partial x_{j}}\right)_{i,j=1,\dots,n}=\mathbf{D}^{2}\varphi(\mathbf{x}).

Thus
\mathbf{B}
is the Hessian of a potential
\varphi
and hence we have the situation of case (ii), Remark
3.4
.

4.2
Vanishing Mixed Source Terms

Consider the situation of
\mathbf{B}
being a diagonal matrix and thus we are in the case (iii) of Remark
3.4
.
In this case the source term is as follows

\displaystyle\mathcal{S}(t)

\displaystyle=\sum_{i=1}^{n}\int_{\Omega}2w_{i}S_{i}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}=-2\sum_{i=1}^{n}\int_{\Omega}\frac{\partial H_{i}}{\partial x_{i}}w_{i}^{2}\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}

Moreover, Corollary
3.5
can be applied.
Thus by choosing each
\mu_{i}
according to

\nabla_{\mathbf{\Psi}}H\cdot\nabla\mu_{i}+\nabla\cdot\nabla_{\mathbf{\Psi}}H-2\frac{\partial H_{i}}{\partial x_{i}}=-C_{L}

we obtain

\mathcal{I}(t)=\sum_{i=1}^{n}\int_{\Omega}w_{i}^{2}\left(\nabla_{\mathbf{\Psi}}H\cdot\nabla\mu_{i}+\nabla\cdot\nabla_{\mathbf{\Psi}}H-2\frac{\partial H_{i}}{\partial x_{i}}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}=-\sum_{i=1}^{n}C_{L}L_{i}(t).

If we now also choose the control
u_{i}
such that

\displaystyle u(t)^{2}=\left(\sum_{i=1}^{n}\int_{\mathcal{C}_{i}}\left(\nabla_{\mathbf{\Psi}}H\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}\right)^{-1}\sum_{i=1}^{n}\int_{\Gamma_{i}^{+}}w_{i}^{2}\left(\nabla_{\mathbf{\Psi}}H\cdot\mathbf{n}\right)\exp(\mu_{i}(\mathbf{x}))\,\textup{d}\mathbf{x}.

we obtain
\mathcal{B}(t)=0
leading altogether to (see Cor.
3.5
)

\frac{\textup{d}}{\textup{d}t}L(t)=-C_{L}L(t)\hskip 10.00002pt\Leftrightarrow\hskip 10.00002ptL(t)=L(0)\exp(-C_{L}t).

In this particular case we computed exactly the decay of the Lyapunov function which may be beneficial for testing numerical methods.
An example of a Hamiltonian
H
leading to this situation is e.g.

H(\mathbf{x},\mathbf{\Psi})=\sum_{i=1}^{n}H_{i}(x_{i})\psi_{i}\hskip 10.00002pt\Rightarrow\hskip 10.00002pt\frac{\partial H_{i}}{\partial x_{j}}=0,\,i\neq j.

In this case, the PDE for
\mu_{i}
simplifies and we can find a solution as

\displaystyle\mu_{i}(\mathbf{x})=\sum_{k=1}^{n}F^{(i)}_{k}(x_{k})

(4.6)

for some functions
F^{(i)}_{k}
as follows. Note that due to the particular structure of
\mu_{i}
we have

\frac{\partial^{2}}{\partial x_{k}\partial x_{l}}\mu_{i}\equiv 0,\;k\neq l.

By differentiating the PDE for
\mu_{i}
w.r.t.
x_{k}
we obtain

\displaystyle 0

\displaystyle=\frac{\partial}{\partial x_{k}}\left[\nabla\cdot\nabla_{\mathbf{\Psi}}H+\nabla_{\mathbf{\Psi}}H\cdot\nabla\mu_{i}-2\frac{\partial H_{i}}{\partial x_{i}}\right]

\displaystyle=\frac{\partial^{2}}{\partial x_{k}^{2}}H_{k}+\frac{\partial}{\partial x_{k}}H_{k}\frac{\partial}{\partial x_{k}}\mu_{i}+H_{k}\frac{\partial^{2}}{\partial x_{k}^{2}}\mu_{i}-2\frac{\partial^{2}}{\partial x_{k}\partial x_{i}}H_{i}\delta_{ki}

\displaystyle=\frac{\partial^{2}}{\partial x_{k}^{2}}H_{k}+\frac{\partial}{\partial x_{k}}H_{k}F_{k}^{\prime(i)}(x_{k})+H_{k}F_{k}^{\prime\prime(i)}(x_{k})-2\frac{\partial^{2}}{\partial x_{k}\partial x_{i}}H_{i}\delta_{ki}

\displaystyle\Leftrightarrow\hskip 10.00002pt

\displaystyle\frac{\textup{d}}{\textup{d}x_{k}}\left(H_{k}(x_{k})F_{k}^{\prime(i)}(x_{k})\right)=2\frac{\partial^{2}}{\partial x_{k}\partial x_{i}}H_{i}\delta_{ki}-\frac{\partial^{2}}{\partial x_{k}^{2}}H_{k}

\displaystyle\Leftrightarrow\hskip 10.00002pt

\displaystyle H_{k}(x_{k})F_{k}^{\prime(i)}(x_{k})=\int^{x_{k}}2\frac{\partial^{2}}{\partial x_{k}\partial x_{i}}H_{i}(s)\delta_{ki}-\frac{\partial^{2}}{\partial x_{k}^{2}}H_{k}(s)\,\textup{d}s.

Hence, the
F_{k}^{(i)}
are determined by integration which in turn define
\mu_{i}.

4.3
Constant Hamiltonian Gradient

Under the assumption that
\nabla_{\mathbf{\Psi}}H=\mathbf{C}\in\mathbb{R}^{n}\setminus\{\mathbf{0}\}
is constant in each component the source terms
S_{i}
vanish identically.
In this case the PDE for
\mu_{i}
reads

\displaystyle-C_{L}^{(i)}=\nabla_{\mathbf{\Psi}}H\cdot\nabla\mu_{i},\;C^{(i)}_{L}\in\mathbb{R}_{>0}.

(4.7)

This PDE is an inhomogeneous linear advection equation. We choose an index
j
with
H_{j}\neq 0
and consider the following problem

\displaystyle\begin{cases}\frac{\partial}{\partial\tau}\mu_{i}(\tau,\mathbf{y})+\mathbf{a}\cdot\nabla_{y}\mu_{i}(\tau,\mathbf{y})=-\frac{C_{L}^{(i)}}{H_{j}},\\
\mu_{i}(0,\mathbf{y})=g_{i}(\mathbf{y})\end{cases}

\displaystyle\text{with}\;\tau:=x_{j},\;\mathbf{y}:=(x_{1},\dots,x_{j-1},x_{j+1},\dots,x_{n}),

\displaystyle\mathbf{a}:=\frac{1}{H_{j}}\overline{\mathbf{H}},\hskip 10.00002pt\overline{\mathbf{H}}:=(H_{1},\dots,H_{j-1},H_{j+1},\dots,H_{n}).

Its general solution is given by

\mu_{i}(\tau,\mathbf{y})=g_{i}(\mathbf{y}-\mathbf{a}\tau)+\int_{0}^{\tau}f(\mathbf{y}+(s-\tau)\mathbf{a},s)\,\textup{d}s

which leads to

\displaystyle\mu_{i}(\mathbf{x})=g_{i}(\mathbf{y}-\mathbf{a}x_{j})-\frac{C_{L}^{(i)}}{H_{j}}x_{j}.

The function
g_{i}
can be chosen arbitrarily. Hence, a full solution to equation (
2.7
) exists. Note that the case
g_{i}\equiv 0
corresponds to the 1D case of stabilizing controls as
introduced e.g. in
[
5
,
10
]
.

Note that the choice for
\mu(x_{1},x_{2})
made in
[
1
]
is a combination of the present case with
\nabla_{\mathbf{\Psi}}H=\mathbf{C}\in\mathbb{R}^{n}\setminus\{\mathbf{0}\}

and the solution ansatz
(
4.6
)
for
\mu
used in the previous part.
The excluded case
\nabla_{\mathbf{\Psi}}H=\mathbf{C}=\mathbf{0}
is of no interest since it implies
H=H(\mathbf{x})
and thus the Hamilton-Jacobi equation becomes the trivial ODE

\frac{\partial}{\partial t}\Phi(t,\mathbf{x})+H(\mathbf{x})=0.

5
Summary

A novel Lyapunov function for
L^{2}-
control of a class of multi–dimensional systems of hyperbolic equations has been presented.
The analysis relies on the fact that this system can be derived from Hamilton–Jacobi equations.
A stabilizing feedback control has been derived and exponential decay of a weighted
L^{2}-
norm has been established.
Several examples have been presented where some are inspired by a model for forming processes. Future extensions could be given towards numerical discretizations as well as stabilization in
H^{s}-
norm.
