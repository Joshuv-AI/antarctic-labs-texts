Ramsey-type results for path covers and path partitions
Shuya Chiba, Michitaka Furuya

Abstract
A family 𝒫 \mathcal{P} of subgraphs of G G is called a path cover (resp. a path partition ) of G G if ⋃ P ∈ 𝒫 V ⁡ ( P ) = V ⁡ ( G ) \bigcup_{P\in\mathcal{P}}V(P)=V(G) (resp. ⋃ ˙ P ∈ 𝒫 ​ V ​ ( P ) = V ⁡ ( G ) \dot{\bigcup}_{P\in\mathcal{P}}V(P)=V(G) ) and every element of 𝒫 \mathcal{P} is a path. The minimum cardinality of a path cover (resp. a path partition) of G G is denoted by pc ⁡ ( G ) {\rm pc}(G) (resp. pp ⁡ ( G ) {\rm pp}(G) ). In this paper, we characterize the forbidden subgraph conditions assuring us that pc ⁡ ( G ) {\rm pc}(G) (or pp ⁡ ( G ) {\rm pp}(G) ) is bounded by a constant. We conclude this section by defining a new Ramsey-type concept concerning the path cover/partition number.
Let
{\mathcal{H}}
be a family of graphs.
The
path cover Ramsey number

R^{\rm pc}({\mathcal{H}})
(resp. the
path partition Ramsey number

R^{\rm pp}({\mathcal{H}})
) is the minimum positive integer
R
such that any connected graph
G
with
{\rm pc}(G)\geq R
(resp.
{\rm pp}(G)\geq R
) contains an induced copy of an element of
{\mathcal{H}}
, where
R^{\rm pc}({\mathcal{H}})=\infty
(resp.
R^{\rm pp}({\mathcal{H}})=\infty
) if such an integer does not exist.
Then it follows from Theorem
1.2
that the following hold:

(P1)

For a finite family
{\mathcal{H}}
of connected graphs,
R^{\rm pc}({\mathcal{H}})
is a finite number if and only if
{\mathcal{H}}\leq\{K_{1,n},K^{*}_{n},F^{(1)}_{n,n},F^{(2)}_{n,n}\}
for an integer
n\geq 2
.

(P2)

For a finite family
{\mathcal{H}}
of connected graphs,
R^{\rm pp}({\mathcal{H}})
is a finite number if and only if
{\mathcal{H}}\leq\{K_{1,n},K^{*}_{n},F^{(1)}_{n,n},F^{(2)}_{n,n},F^{(3)}_{n,n},F^{(4)}_{n,n}\}
for an integer
n\geq 2
.

Note that
R^{\rm pc}({\mathcal{H}})=2
if and only if
R^{\rm pp}({\mathcal{H}})=2
.
As we mentioned above, it is known that
R^{\rm pc}(\{K_{1,3},K^{*}_{3}\})=2
and the study of triples
\{H_{1},H_{2},H_{3}\}
of connected graphs with
R^{\rm pc}(\{H_{1},H_{2},H_{3}\})=2
is completed.
Since the
K_{1,3}
-freeness tends to give an important structure to many Hamiltonian properties, one might be interested in a relationship between such new Ramsey-type values and

-freeness.
Here we focus on the values

and

for the case where

contains

.
Note that for positive integers

and

R^{\rm pp}({\mathcal{H}})=R^{\rm pp}({\mathcal{H}}\setminus\{F^{(1)}_{m,n},F^{(3)}_{m,n},F^{(4)}_{m,n}:m\geq 1,~n\geq 1,~m+n\geq 3\}).
