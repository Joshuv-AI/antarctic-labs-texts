Generalized Euclidean distance matrices
R. Balaji a , R.B. Bapat b and Shivani Goel c

Abstract
Euclidean distance matrices ( EDM \mathop{\rm EDM} ) are symmetric nonnegative matrices with several interesting properties. In this article, we introduce a wider class of matrices called generalized Euclidean distance matrices ( GEDM \mathop{\rm GEDM} s) that include EDM \mathop{\rm EDM} s. Each GEDM \mathop{\rm GEDM} is an entry-wise nonnegative matrix. A GEDM \mathop{\rm GEDM} is not symmetric unless it is an EDM \mathop{\rm EDM} . By some new techniques, we show that many significant results on Euclidean distance matrices can be extended to generalized Euclidean distance matrices. These contain results about eigenvalues, inverse, determinant, spectral radius, Moore-Penrose inverse and some majorization inequalities. We finally give an application by constructing infinitely divisible matrices using generalized Euclidean distance matrices.



keywords

Euclidean distance matrix, Haynsworth inertia formula, Laplacian matrices, Majorization, Infinitely divisible matrices.

Introduction

An
n\times n
real matrix
D=[d_{ij}]
is a
Euclidean distance matrix
(EDM) if there exist vectors

x^{1},x^{2},\dotsc,x^{n}
in a Euclidean space
(V,\langle\cdot,\cdot\rangle)
such that

d_{ij}=\langle x^{i}-x^{j},x^{i}-x^{j}\rangle~~~\mbox{for all}~i,j=1,2,\dotsc,n;

(1)

or equivalently,

d_{ij}=\|x^{i}-x^{j}\|^{2}~~\mbox{for all}~i,j=1,2,\dotsc,n.

Euclidean distance matrices appear in several fields. For instance, in approximation theory, Micchelli
[
9
]
proved the striking
result: If
x^{1},\dotsc,x^{n}
are
n
distinct points in the plane, then

(-1)^{n-1}\det[\sqrt{1+\|x^{i}-x^{j}\|^{2}}]>0.

As a consequence, there exists a unique function

f(x)=\sum_{k=1}^{n}c_{k}\sqrt{1+\|x-x^{k}\|^{2}}

interpolating a given data
y_{1},\dotsc,y_{n}
at
x^{1},\dotsc,x^{n}
.
Euclidean distance matrices have several interesting properties. For example, we have the following basic result.

Theorem 1.1

(Menger, Schoenberg.
[
7
]
)
.

Let
D=[d_{ij}]
be an
n\times n
symmetric matrix with zero diagonal. Then the following are equivalent.

1.

D
is an
\mathop{\rm EDM}
.

2.

If
(x_{1},\dotsc,x_{n})^{\prime}
is such that
\sum_{i=1}^{n}x_{i}=0
, then
\sum_{i,j}d_{ij}x_{i}x_{j}\leq 0
.

3.

Let
\mathbf{1}=(1,1,\dotsc,1)^{\prime}\in\mathbb{R}^{n}
. Then the bordered matrix

\left[\begin{matrix}D&\mathbf{1}\\
\mathbf{1}^{\prime}&0\end{matrix}\right]
has exactly one (simple) positive eigenvalue.

Symmetric matrices with exactly one simple positive eigenvalue are called elliptic matrices. Elliptic matrices play an important role in Alexandrov inequalities for mixed volumes
[
3
, chapter 5]
.
Elliptic matrices are useful in obtaining infinitely divisible matrices. If
[a_{ij}]
is an elliptic matrix with all entries positive, then
[\displaystyle\frac{1}{a_{ij}^{r}}]
is positive semidefinite for all
r>0
, i.e.
[\frac{1}{a_{ij}}]
is a infinitely divisible matrix. The main theme of
[
4
]
is to obtain infinitely divisible matrices via elliptic matrices.

1.1
Objective of the paper

In this paper, we investigate the so-called generalized Euclidean distance matrices (
\mathop{\rm GEDM}
).
All Euclidean distance matrices (
\mathop{\rm EDM}
) are generalized Euclidean distance matrices.
If a generalized Euclidean distance matrix is not an
\mathop{\rm EDM}
, then it is not symmetric.
Despite this fact, we extend many properties of
\mathop{\rm EDM}
s to
\mathop{\rm GEDM}
s.
For example, we show that all eigenvalues of a
\mathop{\rm GEDM}
are real and has at most one positive eigenvalue, null space of a
\mathop{\rm GEDM}

is a subspace of
\mathbf{1}^{\perp}
, the Moore-Penrose inverse of a
\mathop{\rm GEDM}
is negative semidefinite on
\mathbf{1}^{\perp}
and so on.
These results are obtained by using new techniques that circumvent the standard arguments on symmetric matrices.

1.2
Definition of generalized Euclidean distance matrices

We begin with the following observation. Let
D=[d_{ij}]
be an
n\times n
Euclidean distance matrix.
In view of (
1
), if
D=[d_{ij}]
is a EDM, then

d_{ij}=\|x^{i}\|^{2}+\|x^{j}\|^{2}-2\langle x^{i},x^{j}\rangle~~~\forall i,j=1,2,\dotsc,n.

Recall that the Gram matrix of an ordered system of vectors
\{v^{1},\dotsc,v^{n}\}
in a Euclidean space is the matrix

[\langle v^{i},v^{j}\rangle]
.
As every positive semidefinite matrix is a Gram matrix of some system of vectors in some Euclidean space, it follows that

D=[d_{ij}]
is an EDM if and only if there exists an
n\times n
positive semidefinite matrix
F=[f_{ij}]
such that

d_{ij}=f_{ii}+f_{jj}-2f_{ij}.

(2)

Let
\mathbf{1}
be the vector of all ones in
\mathbb{R}^{n}
. Define
J:=\mathbf{1}\mathbf{1}^{\prime}
.
Then (
2
) can be rewritten as

D=\mathop{\rm diag}(F)J+J\mathop{\rm diag}(F)-2F.

(3)

Define

P:=I-\frac{1}{n}J~~\mbox{and}~~Y=[y_{ij}]:=-\frac{1}{2}PDP,

(4)

where
I
is the
n\times n
identity matrix.
As the diagonal entries of
D
are zero,
from equation
(\ref{df11})
, it can be verified that

d_{ij}=y_{ii}+y_{jj}-2y_{ij},

or equivalently,

D=\mathop{\rm diag}(Y)J+J\mathop{\rm diag}(Y)-2Y.

By an easy verification, it follows that
Y
is positive semidefinite and
Y\mathbf{1}=0
. Thus, a symmetric matrix
D=[d_{ij}]
is an EDM if and only if
there exists a positive semidefinite matrix
G=[g_{ij}]
such that
G\mathbf{1}=0
(equivalently, row sums and column sums of
G
are zero) and

d_{ij}=g_{ii}+g_{jj}-2g_{ij}.

Several important properties of Euclidean distance matrices depend on this characterization.

Definition 1.2
.

We say that an
n\times n
real symmetric matrix
L
is a
generalized Laplacian matrix
if
L
is positive semidefinite
and
L\mathbf{1}=0
.

It is easy to note that
L
is a generalized Laplacian if and only if there exists a positive semidefinite matrix
F
such that

L=PFP
, where

P
is the matrix in
(\ref{df1})
.
Laplacian matrices of connected graphs are examples of generalized Laplacian matrices.

Definition 1.3
.

Let
a
and
b
be any two positive numbers and
L
be an
n\times n
generalized Laplacian matrix.
Define

d_{ij}=a^{2}l_{ii}+b^{2}l_{jj}-2abl_{ij}~~~i,j=1,2,\dotsc,n.

We now say that
[d_{ij}]
is a generalized Euclidean distance matrix (
\mathop{\rm GEDM}
).

An easy computation shows that

d_{ji}=b^{2}l_{ii}+a^{2}l_{jj}-2abl_{ij}.

Thus,
D
is symmetric if and only if
a=b
and in this case,
all the diagonal entries of
D
are zero; hence
D
will be a Euclidean distance matrix.
To illustrate the definition, consider the following example.

Example 1.4
.

Let

L:=[l_{ij}]=\left[\begin{array}[]{cccc }~~3&-1&-2\\
-1&~~3&-2\\
-2&-2&~~4\\
\end{array}\right].

Then
L
is a generalized Laplacian matrix. Set
a=1
and
b=3
. For
i,j=1,2,3
, define

\displaystyle d_{ij}:

\displaystyle=a^{2}l_{ii}+b^{2}l_{jj}-2abl_{ij}

\displaystyle=l_{ii}+9l_{jj}-6l_{ij}.

Now,

D:=[d_{ij}]=\left[\begin{array}[]{cccc}12&36&51\\
36&12&51\\
43&43&16\end{array}\right]

is a
\mathop{\rm GEDM}
.

We note the following proposition.

Proposition 1.5
.

An
n\times n
matrix
D
is a
\mathop{\rm GEDM}
if and only if there exist
x^{1},\dotsc,x^{n}
in some Euclidean space
(V,\langle\cdot,\cdot\rangle)
such that

d_{ij}=\langle ax^{i}-bx^{j},ax^{i}-bx^{j}\rangle~~\mbox{and}~~\sum_{j=1}^{n}x^{j}=0.

Proof.

Let
D=[d_{ij}]
be a
\mathop{\rm GEDM}
. Then,

d_{ij}=a^{2}l_{ii}+b^{2}l_{jj}-2abl_{ij},

where
L=[l_{ij}]
is a generalized Laplacian matrix and
a,b
are some positive numbers. Because
L
is positive semidefinite and
L\mathbf{1}=0
, there exist
x^{1},\dotsc,x^{n}
in a Euclidean space
(V,\langle\cdot,\cdot\rangle)
such that

l_{ij}=\langle x^{i},x^{j}\rangle~~\mbox{and}~~\sum_{j=1}^{n}x^{j}=0.

Thus,

\displaystyle d_{ij}=a^{2}\langle x^{i},x^{i}\rangle+b^{2}\langle x^{j},x^{j}\rangle-2ab\langle x^{i},x^{j}\rangle=\langle ax^{i}-bx^{j},ax^{i}-bx^{j}\rangle.

The converse is immediate.
∎

1.3
Preliminaries

We fix the notation and mention a few results/definitions that are needed in the sequel.

(N1)

All matrices considered are real. The transpose of a matrix
A
is written
A^{\prime}
. The notation
\mathbf{1}
will denote the vector of all ones in
\mathbb{R}^{n}
,
J
will be the matrix
\mathbf{1}\mathbf{1}^{\prime}

and
\mathbf{1}^{\perp}
will be the subspace containing all vectors that are orthogonal to
\mathbf{1}
. As usual
e_{1},\dotsc,e_{n}
will denote the standard orthonormal basis vectors in
\mathbb{R}^{n}
; hence the first column of an
n\times n
matrix
A
will be
Ae_{1}
and so on. We use
P
to denote the orthogonal projection
I-\frac{1}{n}J
onto
\mathbf{1}^{\perp}
.

(N2)

The null space of
A
is denoted by
\mathop{\rm null}(A)
and the column space (range) of
A
by
\mathop{\rm col}(A)
.
As usual,
\rho(A)
will be the spectral radius of
A
and the Moore-Penorse inverse of
A
will be written

A^{\dagger}
.

(N3)

Let
x:=(x_{1},\dotsc,x_{n})^{\prime}
and
y:=(y_{1},\dotsc,y_{n})^{\prime}
be any two vectors. Let

\sigma
and
\pi
be permutations on
\{1,\dotsc,n\}
such that

x_{\sigma(1)}\geq\cdots\geq x_{\sigma_{n}}~~\mbox{and}~~y_{\pi_{1}}\geq\cdots\geq y_{\pi_{n}}.

We say that
x
is majorized by
y
if

\sum_{i=1}^{n}x_{i}=\sum_{i=1}^{n}y_{i}~~~\mbox{and}~~\sum_{j=1}^{k}x_{\sigma(j)}\leq\sum_{j=1}^{k}y_{\pi(j)}~~~(k=1,\dotsc,n-1).

To say that
x
is majorized by
y
, we use the notation
x\prec y
.

(N4)

Given an
n\times n
matrix
A=[a_{ij}]
, we use
\mathop{\rm diag}(A)
to denote the
vector
(a_{11},\dotsc,a_{nn})^{\prime}
in
\mathbb{R}^{n}
. If
(p_{1},\dotsc,p_{n})^{\prime}
is a vector in
\mathbb{R}^{n}
, we use

\mathop{\rm Diag}(p_{1},\dotsc,p_{n})
to denote the diagonal matrix with diagonal entries
p_{1},\dotsc,p_{n}
.

(N5)

Let
H
be an
n\times n

symmetric matrix and the eigenvalues are
\lambda_{1}\dotsc,\lambda_{n}
such that

\lambda_{1}\geq\cdots\geq\lambda_{n}.

We now define
\lambda(H)
by

\lambda(H)=(\lambda_{1},\dotsc,\lambda_{n})^{\prime}.

(N6)

By a theorem of Schur, if
H
is an
n\times n
symmetric matrix, then

\mathop{\rm diag}(H)\prec\lambda(H).

If
A
and
B
are
n\times n
symmetric matrices, then a result of Ky Fan states that

\lambda(A+B)\prec\lambda(A)+\lambda(B).

(see e.g.,
[
11
, Theorem 7.14 and 7.15]
)

(N7)

The inertia of a symmetric matrix
A
is denoted by
\mathop{\rm In}(A)=(\nu,\delta,\mu)
where
\nu
is the number of
negative eigenvalues of
A
,
\delta
is the nullity of
A
and
\mu
is the number of positive eigenvalues of
A
.
If
A
is
n\times n
,
p\in\mathbb{R}^{n}
, and if

\widetilde{A}=\left[\begin{array}[]{ccc}A&p\\
p^{\prime}&0\end{array}\right],

then the generalized Schur complement
\widetilde{A}/A
is
-p^{\prime}A^{{\dagger}}p
.
If
p\in\mathop{\rm col}(A)
, then

\mathop{\rm In}(\widetilde{A}/A)+\mathop{\rm In}(A)=\mathop{\rm In}(\widetilde{A}).

(see
[
5
, Theorem 2]
)

(N8)

An
n\times n
matrix
A
is called an
{\bf M}
-matrix, if
A=\rho I-S
,
where
S
is a nonnegative matrix and
\rho\geq\rho(S)
.

(N9)

Let
A
be an
n\times n
symmetric matrix and
p\in\mathbb{R}^{n}
. If
the bordered matrix

\left[\begin{array}[]{ccccccc}A&p\\
p^{\prime}&0\end{array}\right]

has exactly one positive eigenvalue, then

y\in p^{\perp}\implies y^{\prime}Ay\leq 0.

(see
[
6
, Theorem 2.9]
)

In the sequel, we assume that
D
is a non-zero
\mathop{\rm GEDM}
and

L
is the generalized Laplacian such that

D=a^{2}\widetilde{L}J+b^{2}J\widetilde{L}-2abL,

(5)

where
a
and

\widetilde{L}:=\mathop{\rm Diag}(L)

2.1
Eigenvalues of a
\mathop{\rm GEDM}

We shall now show that all eigenvalues of
D
are real and in fact
D
is similar to a symmetric matrix.

Theorem 2.1
.

D
is similar to a symmetric matrix and has exactly one positive eigenvalue.

Proof.

If all the diagonal entries of
D
are zero, then
D
is a Euclidean distance matrix and in this case, the result is known.
Now assume that
D
has at least one positive diagonal entry.
Let the eigenvalues of
L
be arranged

\alpha_{1}\leq\alpha_{2}\leq\cdots\leq\alpha_{n}.

Since
L
is positive semidefinite and
L\mathbf{1}=0
,
\alpha_{1}=0
.
Let
U
be an orthogonal matrix with first column equal to the unit vector
\frac{1}{\sqrt{n}}\mathbf{1}
and such that

U^{\prime}LU=\mathop{\rm Diag}(0,\alpha_{2},\dotsc,\alpha_{n}).

Define

(s_{1},s_{2},\dotsc,s_{n})^{\prime}:=U^{\prime}\widetilde{L}JUe_{1}.

By an easy verification,

s_{1}={\rm trace}(L).

Furthermore,

U^{\prime}\widetilde{L}JUe_{i}=0~~~~i=2,\dotsc,n.

Thus,

\displaystyle U^{\prime}DU

\displaystyle=a^{2}U^{\prime}\widetilde{L}JU+b^{2}U^{\prime}J\widetilde{L}U-2abU^{\prime}LU

(6)

\displaystyle=\left[\begin{array}[]{ccccc}(a^{2}+b^{2})s_{1}&b^{2}s_{2}&\ldots&b^{2}s_{n}\\
a^{2}s_{2}&-2ab\alpha_{2}&\ldots&0\\
\vdots&\vdots&\ddots&\vdots\\
a^{2}s_{n}&0&\ldots&-2ab\alpha_{n}\end{array}\right].

Define

W:=\mbox{Diag}(\frac{\displaystyle b}{\displaystyle a},1,\dotsc,1).

Now,

W^{-1}U^{\prime}DUW=\begin{array}[]{ccccc}\left[\begin{array}[]{ccccc}(a^{2}+b^{2})s_{1}&abs_{2}&\ldots&abs_{n}\\
abs_{2}&-2ab\alpha_{2}&\ldots&0\\
\vdots&\vdots&\ddots&\vdots\\
abs_{n}&0&\ldots&-2ab\alpha_{n}\end{array}\right];\end{array}

(7)

hence
D
is similar to a symmetric matrix.
By interlacing theorem,
W^{-1}U^{\prime}DUW
has
n-1
non-positive eigenvalues. Since
{\rm trace}(D)>0
, we see that

(W^{-1}U^{\prime}DUW)_{11}>0.

Hence,
W^{-1}U^{\prime}DUW
has at least one positive eigenvalue. So,
D
has exactly one positive eigenvalue. The proof is now complete.
∎

In the rest of the paper, we shall use
W
and
U
to denote the matrices defined in Theorem
2.1
.
We have the following corollary now.

Corollary 2.2
.

All the eigenvalues of the bordered matrix

\widetilde{D}:=\left[\begin{array}[]{cccc}D&\mathbf{1}\\
\mathbf{1}^{\prime}&0\end{array}\right]

are real and
\widetilde{D}
has exactly one positive eigenvalue.

Proof.

Setting

K:=\left[\begin{array}[]{cccc}U&0\\
0&1\\
\end{array}\right]\left[\begin{array}[]{cccc}W&0\\
0&1\\
\end{array}\right],

we find that
the bordered matrix

\widetilde{D}:=\left[\begin{array}[]{cccccc}D&\mathbf{1}\\
\mathbf{1}^{\prime}&0\end{array}\right]

is similar to

Q:=K^{-1}\widetilde{D}K=\left[\begin{array}[]{cccccc}W^{-1}U^{\prime}DUW&W^{-1}U^{\prime}\mathbf{1}\\
\mathbf{1}^{\prime}UW&0\end{array}\right].

(8)

Since
U
is an orthogonal matrix with first column equal to
\frac{1}{\displaystyle\sqrt{n}}\mathbf{1}
,

\displaystyle W^{-1}U^{\prime}\mathbf{1}

\displaystyle=\mathop{\rm Diag}(\frac{a}{b},1,\dotsc,1)(\sqrt{n}e_{1})

(9)

\displaystyle=(\sqrt{n}\frac{a}{b},0,\dotsc,0)^{\prime}

\displaystyle=\sqrt{n}\frac{a}{b}e_{1}.

Put

\delta:=\sqrt{n}\dfrac{a}{b}.

By
(\ref{m4})
and
(\ref{m5})
,

\displaystyle Q

\displaystyle=\left[\begin{array}[]{ccccc}W^{-1}U^{\prime}DUW&\delta e_{1}\\
\frac{1}{\delta}e_{1}^{\prime}&0\\
\end{array}\right]

(10)

\displaystyle=\left[\begin{array}[]{ccccc}(a^{2}+b^{2})s_{1}&abs_{2}&\ldots&abs_{n}&\delta\\
abs_{2}&-2ab\alpha_{2}&\ldots&0&0\\
\vdots&\vdots&\ddots&\vdots&\vdots\\
abs_{n}&0&\ldots&-2ab\alpha_{n}&0\\
\frac{1}{\displaystyle\delta}&0&0\ldots&0&0\end{array}\right]

Define

G:=\mbox{Diag}(I,\frac{1}{\delta}),

where
I
is the
n\times n
identity matrix.
Now,

\displaystyle G^{-1}QG

\displaystyle=\left[\begin{array}[]{ccccc}I&0\\
0&\delta\\
\end{array}\right]\left[\begin{array}[]{ccccc}W^{-1}U^{\prime}DUW&\delta e_{1}\\
\frac{1}{\delta}e_{1}^{\prime}&0\\
\end{array}\right]\left[\begin{array}[]{ccccc}I&0\\
0&\frac{1}{\delta}\\
\end{array}\right]

(11)

\displaystyle=\left[\begin{array}[]{ccccc}W^{-1}U^{\prime}DUW&e_{1}\\
e_{1}^{\prime}&0\\
\end{array}\right].

As

is symmetric (see
(\ref{m4})
),

is symmetric. Thus,
\widetilde{D}

is similar to a symmetric matrix.

\widetilde{D}
has only real eigenvalues.

We now claim that
\widetilde{D}
has exactly one positive eigenvalue.
Let
x=(x_{1},\dotsc,x_{n})^{\prime}
be orthogonal to

. Because
x_{1}=0

x^{\prime}W^{-1}U^{\prime}DUWx=-2ab\sum_{i=2}^{n}x_{i}^{2}\alpha_{i}\leq 0.

(12)

The subspace

\nabla:=\{(x,r):x^{\prime}e_{1}=0,~r\in\mathbb{R}\}

2.3
Null space of a
\mathop{\rm GEDM}

The main result about the null space of a
\mathop{\rm GEDM}
is
\mathop{\rm null}(D)\subseteq\mathbf{1}^{\perp}
; so
\mathbf{1}\in\mathop{\rm col}(D)
and this in turn will be useful
to investigate the Moore-Penorse inverse of
D
.

Theorem 2.5
.

If
D
is a
\mathop{\rm GEDM}
, then
\mathbf{1}\in\mathop{\rm null}(D)
.

Proof.

Following same notation as in Theorem
2.1
, we have
by equation
(\ref{pdp})
,

\Delta:=U^{\prime}DU=\left[\begin{array}[]{ccccc}(a^{2}+b^{2})s_{1}&b^{2}s_{2}&\ldots&b^{2}s_{n}\\
a^{2}s_{2}&-2ab\alpha_{2}&\ldots&0\\
\vdots&\vdots&\ddots&\vdots\\
a^{2}s_{n}&0&\ldots&-2ab\alpha_{n}\end{array}\right].

As

\Delta_{11}=(a^{2}+b^{2})s_{1}
and
s_{1}={\rm trace}(L)
,
\Delta_{11}>0
.
Let
Dx=0
. We claim that
\mathbf{1}^{\prime}x=0
.
Since
U\Delta U^{\prime}=D
and
Dx=0
, we have

\Delta U^{\prime}x=0.

(13)

If

v:=(s_{2},s_{3},\dotsc,s_{n})^{\prime}
and

S:=\mathop{\rm Diag}(2ab\lambda_{2},\dotsc,2ab\lambda_{n})
, then

\Delta=\left[\begin{array}[]{cccc}\Delta_{11}&b^{2}v^{\prime}\\
a^{2}v&-S\end{array}\right].

Put
y:=U^{\prime}x
. By writing
y=(y_{1},\bar{y})^{\prime}
, where
y_{1}\in\mathbb{R}
and
\bar{y}^{\prime}\in\mathbb{R}^{n-1}
,

2.5

Suppose

are some vectors in a Euclidean space
(V,\langle\cdot,\cdot\rangle)

v\in V
and

such that

\langle p^{i}-v,p^{i}-v\rangle=\|p^{i}-v\|^{2}=r~~\mbox{for all}~i=1,\dotsc,n,

then we say that
p^{1},\dotsc,p^{n}
lie on the surface of a hypersphere. Now the Euclidean distance matrix
[\|p^{i}-p^{j}\|^{2}]
is called a circum
\mathop{\rm EDM}
.
A well-known result (
[
10
, Theorem
3.4
]
) characterizes all circum
\mathop{\rm EDM}
s.
This says that
E
is a circum
\mathop{\rm EDM}
if and if there exists a vector
s
and a scalar
\beta
such that

Es=\beta\mathbf{1}~~\mbox{and}~~s^{\prime}\mathbf{1}=1.

This is equivalent to saying that
E
is a circum
\mathop{\rm EDM}
if and only if
\mathbf{1}^{\prime}E^{\dagger}\mathbf{1}>0
.
We now introduce the following definition.

Definition 2.16
.

We say that
D=[d_{ij}]
is a circum
\mathop{\rm GEDM}
if there exist
a,b>0
and vectors
x^{1},\dotsc,x^{n}
on the surface of a hypersphere
such that

d_{ij}=\|ax^{i}-bx^{j}\|^{2},

where
\sum_{i=1}^{n}x^{i}=0
.

We now have the following result for
\mathop{\rm GEDM}
s.

Theorem 2.17
.

The following are equivalent.

(1)

D
is a circum
\mathop{\rm GEDM}
.

(2)

\mathbf{1}^{\prime}D^{{\dagger}}\mathbf{1}>0
.

Proof.

As
D=[d_{ij}]
is a
\mathop{\rm GEDM}
,
there exist vectors
x^{1},\dotsc,x^{n}
such that

\sum_{j=1}^{n}x^{i}=0~~\mbox{and}~~d_{ij}=\|ax^{i}-bx^{j}\|^{2}.

Define

e_{ij}:=[\|x^{i}-x^{j}\|^{2}]~~\mbox{and}~~E:=[e_{ij}].

Assume (1).
Then,
x^{1},\dotsc,x^{n}
lie on the surface of a hypersphere. So,
E
is a circum
\mathop{\rm EDM}
and hence
\mathbf{1}^{\prime}E^{\dagger}\mathbf{1}>0
.
By Theorem
2.15
,
\mathbf{1}^{\prime}D^{\dagger}\mathbf{1}>0
.
This proves (2).

Assume (2).
Then by Theorem
2.15
,
\mathbf{1}^{\prime}E^{\dagger}\mathbf{1}>0
.
So,
x^{1},\dotsc,x^{n}
lie on the surface of a hypersphere. Hence
D
is a circum
\mathop{\rm GEDM}
.
∎

a^{2}s&-2ab\mbox{Diag}(\alpha_{2},\dotsc,\alpha_{n})\end{array}\right].

Hence,

U^{\prime}(D+D^{\prime})U=\left[\begin{array}[]{ccccc}2(a^{2}+b^{2}){\rm trace}(L)&(a^{2}+b^{2})s\\
(a^{2}+b^{2})s&-4ab\mbox{Diag}(\alpha_{2},\dotsc,\alpha_{n})\\
\end{array}\right].

By
(\ref{m4})
,

W^{-1}U^{\prime}DUW=\begin{array}[]{ccccc}\left[\begin{array}[]{ccccc}(a^{2}+b^{2}){\rm trace}(L)&abs\\
abs&-2ab\mathop{\rm Diag}(\alpha_{2},\dotsc,\alpha_{n})\\
\end{array}\right].\end{array}

Put

F:=W^{-1}U^{\prime}DUW.

Since

ab\leq\frac{a^{2}+b^{2}}{2},

we can write

U^{\prime}(D+D^{\prime})U=2F+\left[\begin{array}[]{cccc}0&\alpha s\\
\alpha s&0\\
\end{array}\right],

for some
\alpha>0
.
Put

Q:=\left[\begin{array}[]{cccc}0&s\\
s&0\\
\end{array}\right].

We now have

U^{\prime}(D+D^{\prime})U-\alpha Q=2F.

By Ky Fan majorization theorem,

\lambda(U^{\prime}(D+D^{\prime})U-\alpha Q)\prec\lambda(D+D^{\prime})-\alpha\lambda(Q).

As,

\lambda(Q)=(\lambda_{1}(Q),0,\dotsc,0,-\lambda_{1}(Q))~~\mbox{and}~~\lambda_{1}(Q)>0,

we have

\lambda(D+D^{\prime})-\alpha\lambda(Q)\prec\lambda(D+D^{\prime}).

Thus,

\lambda(U^{\prime}(D+D^{\prime})U-\alpha Q)\prec\lambda(D+D^{\prime}),

i.e.

\lambda(2F)\prec\lambda(D+D^{\prime}).

Since

\lambda(2F)=\lambda(2D),

we get

\lambda(D)\prec\lambda(\frac{D+D^{\prime}}{2}).

This completes the proof.
∎

As an immediate corollary of the above result, we have the following.

Corollary 2.22
.

\rho(D)\leq\rho(\frac{D+D^{\prime}}{2})
.

3.1
Constructing infinitely divisible matrices

Generalized distance matrices can be used to construct infinitely divisible matrices. Recall that a symmetric matrix
E=[e_{ij}]
is infinitely divisible if
E
is an entry-wise nonnegative and
[e_{ij}^{r}]
is a positive semidefinite matrix for all
r\geq 0
.

Theorem 3.1
.

Let
S=[s_{ij}]
be an
n\times n
generalized Laplacian matrix. If
a,b>0
, define

d_{ij}:=a^{2}s_{ii}+b^{2}s_{jj}-2abs_{ij},~~f_{ij}:=\max{(d_{ij},d_{ji})};

D:=[d_{ij}]~~\mbox{and}~~F:=[f_{ij}].

If
\mathop{\rm rank}(S)=n-1
, then each
f_{ij}>0
and

[\frac{1}{f_{ij}}]
is an infinitely divisible matrix.

Proof.

We claim that
d_{ij}>0
for all
i,j
. Since
S\mathbf{1}=0
, all cofactors of
S
are equal. Hence all principal minors of
S
are positive. In particular,
every
2\times 2
principal submatrix of
S
is positive definite. So,
d_{ij}>0
and thus
f_{ij}>0
for all
i,j
.

Put
G:=[f_{ij}]:=[\max(d_{ij},d_{ji})]
.
By Theorem 4.2.9 in Bapat
[
2
]
, it suffices to show that
G
has exactly one
(simple) positive eigenvalue. We shall use the following identity: If
\alpha
and
\beta
are positive, then

\max{(\alpha,\beta)}=\frac{1}{2}[(\alpha+\beta)+|\alpha-\beta|].

Hence,

2G=[d_{ij}+d_{ji}]+[|d_{ij}-d_{ji}|]

has exactly one simple positive eigenvalue.
Put

A:=[d_{ij}+d_{ji}]~~\mbox{and}~~B:=[|d_{ij}-d_{ji}|].

If
D=[d_{ij}]
, then for any
x\in\mathbf{1}^{\perp}
,

x^{\prime}Dx=-2ab(x^{\prime}Sx)\leq 0,

and hence
x^{\prime}Ax\leq 0
. We now claim that
B
is negative semidefinite on
\mathbf{1}^{\perp}
as well.
It can be noted easily that

|d_{ij}-d_{ji}|=|a^{2}-b^{2}||s_{ii}-s_{jj}|.

If
\alpha,\beta\geq 0
, then

|\alpha-\beta|=\alpha+\beta-2{\rm min}(\alpha,\beta),

and therefore,

|d_{ij}-d_{ji}|=|a^{2}-b^{2}|(s_{ii}+s_{jj}-2{\rm min}(s_{ii},s_{jj})).

It is well known that
{\rm min}(s_{ii},s_{jj})
is positive semidefinite.
So,

B
is negative semidefinite on
\mathbf{1}^{\perp}
, and consequently,
2G=A+B
is negative semidefinite on
\mathbf{1}^{\perp}
.
Thus,
G
has at least
n-1
non-positive eigenvalues. Since diagonal entries of
G
are positive,
G
has at least
one positive eigenvalue. Thus,
G
has exactly one simple positive eigenvalue. This completes the proof.
∎
