Abstract
. Using combinatorial covering properties, we show that there is no concentrated set of reals of size ω 2 \omega_{2} in the Miller model. The main result refutes a conjecture of Bartoszyński and Halbeisen. We also prove that there are no γ \gamma -set of reals of size ω 2 \omega_{2} in the Miller model.

1.
Introduction

We work in the Cantor space
{\operatorname{P}(\omega)}
.
A set
X\subseteq{\operatorname{P}(\omega)}
is
concentrated on a set

D\subseteq{\operatorname{P}(\omega)}
if the sets
X\setminus U
are countable for all open sets
U\subseteq{\operatorname{P}(\omega)}
containing
D
.
A set
X\subseteq{\operatorname{P}(\omega)}
is
concentrated
if it is uncountable and concentrated on some countable set contained in
X
.
One of the remarkable features of concentrated sets is the following
covering property introduced by Rothberger
[
19
]

as a strengthening and a topological counterpart of strong measure zero sets introduced by Borel.
A set

X\subseteq{\operatorname{P}(\omega)}
is
Rothberger
if for any sequence
\mathcal{U}_{0},\allowbreak\mathcal{U}_{1},\allowbreak\dotsc
of open covers of
X
, there are sets
U_{0}\in\mathcal{U}_{0},U_{1}\in\mathcal{U}_{1},\dotsc
such that the family
\{\,U_{n}:n\in\omega\,\}
covers
X
.

Another motivation behind concentrated sets is their connection
with so-called
K
-Lusin sets, which in their turn are
related to classical works of Banach and Kuratowski
on the existence of non-vanishing
\sigma
-additive measures
defined on all subsets of the real line, see, e.g.,

[
3
]
and references therein.
Let
{[\omega]^{\omega}}
and
\mathrm{Fin}
be the families of all infinite and finite subsets of
\omega
, respectively.
Recall that a set
X\subseteq{[\omega]^{\omega}}
is
K
-Lusin
if it is uncountable and
the sets
X\cap K
are countable for all compact sets
K\subseteq{[\omega]^{\omega}}
.

Observation 1.1
.

There is a concentrated set in
{\operatorname{P}(\omega)}
of cardinality
\kappa
if and only if there is a
K
-Lusin set in
{[\omega]^{\omega}}
of cardinality
\kappa
.

Proof.

(
\Rightarrow
)
Let
X\subseteq{\operatorname{P}(\omega)}
be a concentrated set of cardinality
\kappa
.
Eventually, adding to the set
X
countably many points, we may assume that the set
X
contains a countable dense set
D
in
{\operatorname{P}(\omega)}
such that
X
is concentrated on
D
.
The space
{\operatorname{P}(\omega)}
(homeomorphic with
{2^{\omega}}
) is countable dense homogeneous
(see
[
2
]
and references therein), i.e.,
for any countable dense subsets
D_{0},D_{1}
of
{\operatorname{P}(\omega)}

there exists a homeomorphism
h\colon{\operatorname{P}(\omega)}\to{\operatorname{P}(\omega)}

with
h[D_{0}]=D_{1}
.
It follows that a homeomorphic copy
Y
of
X
in
{\operatorname{P}(\omega)}
is concentrated on
\mathrm{Fin}
.
For any compact set
K\subseteq{[\omega]^{\omega}}
, the open set
{\operatorname{P}(\omega)}\setminus K
contains
\mathrm{Fin}
, and thus the set
Y\cap K
is countable.
It follows that
Y\setminus\mathrm{Fin}
is a
K
-Lusin set of cardinality
\kappa
.

(
\Leftarrow
)
Let
X\subseteq{[\omega]^{\omega}}
be a
K
-Lusin set of cardinality
\kappa
.
For any open set
U\subseteq{\operatorname{P}(\omega)}
containing
\mathrm{Fin}
, the set
{\operatorname{P}(\omega)}\setminus U
is compact in

{\operatorname{P}(\omega)}
, and thus the set

It follows that the set

is concentrated on

and it has cardinality

.
∎

By a

\omega^{<\omega}

consisting of increasing finite sequences such that the following
conditions are satisfied:

•

•

If

has infinitely many immediate successors in
T

The
Miller forcing
is the
collection

of all Miller trees ordered by inclusion,
i.e., smaller trees carry more information about the generic. This
poset was introduced in
[
17
]
.
For a Miller tree

we
shall denote the set of all splitting nodes of

\mathsf{Split}(T)
.
The set

\mathsf{Split}(T)
may be written in the form
\bigcup_{i\in\omega}\mathsf{Split}_{i}(T)
,
where

\mathsf{Split}_{i}(T):=\{t\in\mathsf{Split}(T)\>:\>|\{s\in\mathsf{Split}(T):s\subsetneq t\}|=i\}.

If
T_{0},T_{1}\in\mathbb{M}
, then
T_{1}\leq_{i}T_{0}
means that
T_{1}\leq T_{0}

and
\mathsf{Split}_{i}(T_{1})=\mathsf{Split}_{i}(T_{0})

It is easy to check that for any

.

For a node

We need the following notions and auxiliary results.
For sets

if the set

is finite.
A nonempty set

if for every sets

.
Let

.
For a set

If

is a semifilter, filter or an ultrafilter, then also

A

there is a function

such that the set
S/a
is the Fréchet filter of all cofinite sets in
{[\omega]^{\omega}}
, an ultrafilter or the full semifilter
{[\omega]^{\omega}}

The semifilter trichotomy is equivalent to the inequality
\mathfrak{u}<\mathfrak{g}
(
[

, Theorems 7 and 10]

[
4

The second alternative of this trichotomy implies that for any
two semifilters
S_{0},S_{1}
for which there are

such that

S_{0}/a_{0},S_{1}/a_{1}
are ultrafiltes, there exists

such that

is an ultrafilter, see the proof of

.
