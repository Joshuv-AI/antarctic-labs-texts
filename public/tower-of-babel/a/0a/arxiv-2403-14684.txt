FOCIL: Finetune-and-Freeze for Online Class Incremental Learning by Training Randomly Pruned Sparse Experts
Murat Onur Yildirim, Elif Ceren Gok Yildirim, Decebal Constantin Mocanu, Joaquin Vanschoren

Abstract
Class incremental learning (CIL) in an online continual learning setting strives to acquire knowledge on a series of novel classes from a data stream, using each data point only once for training. This is more realistic compared to offline modes, where it is assumed that all data from novel class(es) is readily available. Current online CIL approaches store a subset of the previous data which creates heavy overhead costs in terms of both memory and computation, as well as privacy issues. In this paper, we propose a new online CIL approach called FOCIL. It fine-tunes the main architecture continually by training a randomly pruned sparse subnetwork for each task. Then, it freezes the trained connections to prevent forgetting. FOCIL also determines the sparsity level and learning rate per task adaptively and ensures (almost) zero forgetting across all tasks without storing any replay data. Experimental results on 10-Task CIFAR100, 20-Task CIFAR100, and 100-Task TinyImagenet, demonstrate that our method outperforms the SOTA by a large margin. The code is publicly available at https://github.com/muratonuryildirim/FOCIL .



1
Introduction

Current artificial intelligence systems are prone to forgetting previously learned information when confronted with new tasks, commonly known as
catastrophic forgetting

(
McCloskey & Cohen 1989
)
. Continual learning (CL) tries to tackle this phenomenon by striving to acquire knowledge from a nonstationary data stream, presenting a potential path for emulating human cognitive abilities.
Class incremental learning (CIL)
(
Van de Ven & Tolias 2019
)
is a challenging scenario of CL where models learn a sequence of tasks and the task identifiers at inference are not accessible.

Traditional CIL involve retaining all training data for the current task, and the model undergoes multiple epochs of training with repeated shuffles. However, constraints such as privacy and memory may limit access to all data.

This study focuses on online CIL
, a more demanding and realistic scenario in which samples from each task can only be used once and access to previous batches is not available. To avoid catastrophic forgetting in online CIL, various methods are proposed, and most of which -except one
(
Guo et al. 2022a
)
- are built on replay-based CL in which a subset of the previous training data is stored to train the model on both the new data and stored data together to adjust the features and decision boundaries for all classes. However, storing a subset of the data (i) brings overhead costs in terms of both memory and computation, (ii) violates privacy concerns, and (iii) complicates data retrieval and training.

In this paper, we aim to learn continually in an online manner without storing any exemplars. To this end, we present Finetune-and-Freeze for Online Class Incremental Learning by Training Randomly Pruned Sparse Experts (FOCIL). It has a very simple working principle: For every task, it prunes an overparameterized neural network to obtain a task-specific sparse subnetwork (or expert), then trains the new connections that belong to this expert only. Once trained, it freezes them to prevent catastrophic forgetting. Our contributions are summarized as follows:

•

To our knowledge, FOCIL is the first approach that utilizes random network pruning and sparse subnetworks trained from scratch in online class incremental learning.

•

FOCIL only fine-tunes the backbone continually without any complicated training procedure while adaptively determining the sparsity level and learning rate per task.

•

FOCIL secures (almost) zero forgetting across all tasks without storing any replay data. This reduces memory and computation expenses, as well as privacy concerns.

•

Experiments show that FOCIL surpasses SOTA methods by a large margin: For example, it remarkably improves upon the top baseline almost 4 times in terms of accuracy on 100-Task TinyImageNet.

During training

Related Work

Continual Learning.

Many approaches proposed for CL require and assume that the whole training data is readily available for the task at hand and train the model multiple times with repeated shuffling. These methods include regularization-based techniques with consolidation
(
Kirkpatrick et al. 2017
;
Zenke et al. 2017
;
Chaudhry et al. 2018
;
Aljundi et al. 2018
;
Lee et al. 2020
)
or knowledge distillation
(
Li & Hoiem 2017
;
Hou et al. 2018
;
Kang et al. 2022b
)
to optimize model stability, replay-based methods with storing
(
Rebuffi et al. 2017
;
Lopez-Paz & Ranzato 2017
;
Wu et al. 2019
;
Zhao et al. 2020
;
Bang et al. 2021
;
Liu et al. 2021b
;
Arani et al. 2022
;
Sarfraz et al. 2023
)
or generating
(
Mocanu et al. 2016b
;
Shin et al. 2017
;
He et al. 2018
;
Hu et al. 2019
;
Petit et al. 2023
)
samples to retain past experiences, architecture expansions
(
Aljundi et al. 2017
;
Liu et al. 2021a
;
Pham et al. 2021
;
Yan et al. 2021
;
Wang et al. 2022a
;
Wang et al. 2023
;
Douillard et al. 2022
;
Zhou et al. 2023
)
to optimize model plasticity, and parameter isolation with mask learning
(
Mallya et al. 2018
)
, iterative pruning
(
Mallya & Lazebnik 2018
;
Golkar et al. 2019
;
Wortsman et al. 2020
;
Dekhovich et al. 2023
)
and dynamic sparse training
(
Sokar et al. 2021
;
Gurbuz & Dovrolis 2022
;
Kang et al. 2022a
;
Wang et al. 2022b
;
Sokar et al. 2023
;
Kang et al. 2023
)
to maintain the key parameters.

However, accessing the whole data at once is not always possible, and performing multiple epochs of training imposes a significant computational expense.

Online Class Incremental Learning.

Online CIL assumes that the data for each task comes gradually in a stream and can only be trained once. AGEM
(
Chaudhry et al. 2019a
)
modifies the loss function of GEM
(
Lopez-Paz & Ranzato 2017
)
to accelerate training with small episodic memory. GSS
(
Aljundi et al. 2019b
)
improves learning by diversifying gradients within the memory buffer, allowing the model to extract a wider range of information from its stored experiences. ER
(
Chaudhry et al. 2019b
)
selects samples for the replay data randomly. MIR
(
Aljundi et al. 2019a
)
chooses replay samples characterized by maximal increases in loss magnitude. GDumb
(
Prabhu et al. 2020
)
employs a greedy sampling strategy and maintains a balanced class representation, utilizing all samples in memory while training the learner. ASER
(
Shim et al. 2021
)
suggests buffer management using Shapley values. SCR
(
Mai et al. 2021
)
employs supervised contrastive loss in the process of representation learning and adopts the nearest class mean classifier. CoPE
(
De Lange & Tuytelaars 2021
)
relies on prototypes with a high momentum-based update strategy for every observed batch. DVC
(
Gu et al. 2022
)
improves online class-incremental learning through gradient-based sample selection and maximization of mutual information between training image views. OCM
(
Guo et al. 2022b
)
prevents forgetting by maximizing mutual information. OnPro
(
Wei et al. 2023
)
introduces an online prototype equilibrium to alleviate bias and class confusion, along with an adaptive prototypical feedback mechanism to improve boundary definitions.

Except for AOP
(
Guo et al. 2022a
)
, which leverages a pre-trained backbone, online CIL approaches rely on replay-based CL which requires storing a subset of seen data in a memory bank. At each time step of the task, the model receives a mini-batch data
X_{t}\cup X_{b}
for training, where
X_{t}
and
X_{b}
are drawn from the i.i.d. distribution streaming data
D_{t}
for task
t
and the memory bank
M
, respectively.

However, storing a subset of the data for a replay may be restricted due to constraints such as privacy, memory, and computation. These factors impose some limitations on current online CIL approaches.

Pruning at Initialization.

In offline supervised learning, pruning at initialization approaches remove some connections before training, and only a subset of parameters undergoes the training process. The naive approach is pruning each layer uniformly with the same pruning ratio, known as uniform pruning or initialization
(
Mariet & Sra 2015
;
He et al. 2017
;
Gale et al. 2019
)
. Instead of uniform pruning, ER
(
Mocanu et al. 2018
)
and ERK
(
Evci et al. 2020
)
introduced a more advanced layer-wise pruning approach from the field of graph theory with strong results.

Instead of a predefined rule-based sparsity ratio, many works proposed to adjust the layerwise sparsity ratios before training. SNIP
(
Lee et al. 2019
)
only keeps the connections with a large weight and gradient which are obtained by a single batch iteration and prunes the rest of the connections. GraSP
(
Wang et al. 2020
)
prunes connections by computing the Hessian gradient product. SynFlow
(
Tanaka et al. 2020
)
proposes a way to iteratively prune the network to avoid layer collapse without ever looking at the data.

From a more theoretical perspective,
Mocanu et al. 2016a
showed that pruning a restricted boltzmann machine randomly at initialization performs as well as its dense counterpart.
Liu et al. 2022
demonstrated that randomly pruned backbones are effective enough as long as the backbone is wide enough and
Gadhikar et al. 2023
proved that randomly pruned random networks are sufficiently expressive.

However, to our knowledge, none of the existing studies have considered pruning at initialization within the context of continual learning or (online) class incremental learning.

FOCIL

Figure

1
illustrates the FOCIL method. In this section, we provide motivation, preliminaries, and optimization objectives, and explain our expert identification approach as well as the learning rate and sparsity level adaptation strategy.

Motivation.

Deep Neural Networks are typically over-parameterized and exhibit the capability of maintaining multiple subnetworks effectively
(
Frankle & Carbin 2019
;
Liu et al. 2020
)
.

This characteristic allows the learning of more than one expert in a single model, akin to the brain where only a few neurons respond to any given stimulus
(
Babadi & Sompolinsky 2014
)
. It underscores that different parts of the brain have distinct responsibilities or functions.

In offline supervised learning,
Liu et al. 2022
demonstrated that randomly pruned sparse networks perform as well as dense counterparts, particularly in the context of wide neural networks. Furthermore,
Gadhikar et al. 2023
showed that randomly pruned networks are sufficiently expressive and can effectively approximate any target network if they are wider by a certain factor.

In offline class incremental learning,
Mirzadeh et al. 2022a
;
Mirzadeh et al. 2022b
proved that increasing the parameter count does not invariably correlate with enhanced performance unless such a parameter increase specifically targets the width of the network.

Notably, many models developed for offline supervised learning such as AlexNet and ResNet tend to be inherently very wide for continual learning tasks. For instance, in a 20-task CIFAR100 scenario, the data for each task is 20 times smaller than the original dataset, which makes many models sufficiently wide.

Drawing inspiration from these intuitions and previous findings, we propose training a
not wide
deep neural network model by performing random pruning at each task initialization to find sparse experts that are responsible for different tasks in online class incremental learning scenarios.

Preliminaries.

Online CIL involves updating a neural network where the training data for each task come gradually as a stream with a sequence of learning tasks
\mathcal{T}_{1:t}=(\mathcal{T}_{1},\mathcal{T}_{2},...,\mathcal{T}_{t})
, each with a corresponding dataset
\mathcal{D}_{t}~=~{(x_{i,t},y_{i,t})^{n_{t}}}
consisting of
n_{t}
instances per task. In a new learning task, a deep network is optimized to map the input instance to the classifier space, denoted as
f_{\theta}:\mathcal{X}_{t}\rightarrow\mathcal{Y}_{t}
, where
\theta
represents the network parameters. Note that the learning tasks are mutually exclusive, i.e.,
\mathcal{Y}_{t-1}\cap\mathcal{Y}_{t}=~\emptyset,~\forall t\in\mathcal{T}
.

During online class-incremental learning, it is necessary to have a unified model that can make accurate predictions for both new and previously encountered classes. To achieve this, we use a single-head classifier that is expanded each time the model is trained with a new task. This is necessary because, during inference, a unified classifier must choose labels from all the classes that have been observed since task identifiers are not available. Note that this is different from task incremental learning which requires task identifiers.

Pruning.

To find an expert for each task, we apply random unstructured pruning to the neural network using Erdős-Rényi Kernel (ERK)
(
Evci et al. 2020
)
that has been proven to perform more effectively in CL
(
Yildirim et al. 2023
)
. While keeping the total sparsity at the level of
s
, ERK scales the sparsity of the layers proportional to

\displaystyle 1-\frac{(n^{l-1}+n^{l}+w^{l}+h^{l})}{n^{l-1}n^{l}w^{l}h^{l}}

(1)

where
n^{l}
denotes the number of neurons or feature maps at layer
l
, and
w^{l}
and
h^{l}
indicate the width and height of the
l^{th}
convolutional kernel. It allocates higher sparsities to layers with more parameters and lower sparsities to layers with fewer parameters to protect the information flow. The sparsity of the fully connected layers scales as in the original Erdős-Rényi
(
Mocanu et al. 2018
)
.

Objective.

FOCIL aims to effectively learn an expert per task in an online manner by solving the optimization problem that minimizes the following function for each task:

\displaystyle\small\theta_{s}^{*}

\displaystyle=\arg\min\sum_{i=1}^{n_{t}}[CE(f_{\theta_{s}}(x_{i,t}),y_{i,t})]

(2)

Here,
CE
is the Cross-Entropy Loss and
\theta_{s}
is the output of random pruning, and the optimal
\theta_{s}^{*}
is determined by solving this optimization problem (Eq.
2
). After finding
\theta_{s}^{*}
, FOCIL freezes these connections to avoid catastrophic forgetting. However, it allows shared connections between experts. Hence, the overall usage of the backbone is task-dependent and highly related to the extent of shared knowledge among tasks, although the sparsity level per task is predetermined.

.

Expert Selection.

Similar to
(
Rajasegaran et al. 2020
;
Wortsman et al. 2020
;
Dekhovich et al. 2023
)
, we posit that the model’s predictive confidence relies on accurate alignment with the corresponding expert. This prompts us to expect that the entropy of the signal within the most relevant expert should demonstrate a lower magnitude compared to alternative experts. By leveraging these nuanced entropy dynamics, we identify the responsible expert with a single batch of streaming data by aiming for the lowest entropy and highest confidence.

Adaptivity.

FOCIL treats the learning rate (
\eta
) and the sparsity level (
s
) as variables to be searched and optimized, given a search space
\eta_{space}
and
s_{space}
with a predefined number of trials
\mathcal{N}_{1:n}=(\mathcal{N}_{1},\mathcal{N}_{2},...,\mathcal{N}_{n})
. Despite the availability of more sophisticated search algorithms like Bayesian Optimization
(
Bergstra et al. 2011
)
, FOCIL opts for a simple Random Search (RS)
(
Bergstra & Bengio 2012
)
along with Asynchronous Successive Halving
(
Li et al. 2018
)
which accelerates the search. These choices are driven by their practicality in an online setup; they are simple, parallelizable, robust to noisy objectives, and have been proven to work well in practice
(
Hutter et al. 2019
)
.

Evaluation Metrics.

We use Average Accuracy and Average Forgetting
(
Shim et al. 2021
;
Gu et al. 2022
)
to measure the performance in online CIL.

Average Accuracy is measured by learning from the data stream of all tasks, and then testing the final model using the test data of all tasks. It can formally defined as:
\frac{1}{T}\sum_{j=1}^{T}a_{T,j}
where
a_{i,j}
is the accuracy on task
j
after the model is trained from task 1 to
i
.

Average Forgetting measures how much the model forgets after being trained on the final task and can be defined as:
\frac{1}{T-1}\sum_{j=1}^{T-1}f_{T,j}
where
f_{i,j}=\max_{k\in(1,2,...,i-1)}a_{k,j}-a_{i,j}
.

5
Conclusion

In this paper, we propose Finetune-and-Freeze for Online Class Incremental Learning by Training Randomly Pruned Sparse Experts (FOCIL) which improves the top baseline almost 4 times in terms of average accuracy while returning nearly zero forgetting. Besides, it trains almost 3 times faster. These achievements signify a substantial leap forward in the landscape of online class incremental learning.

In contrast to existing methods, FOCIL innovatively opts for training a network from scratch without the reliance on storing replay data in online class incremental learning. It creates task-specific sparse experts by training a randomly pruned subnetwork for each task, allowing fine-tuning of the backbone continually while adaptively selecting the learning rate and sparsity level per task, ensuring dynamic adjustments to enhance the performance. Subsequently, the trained connections are frozen in post-training of each task to safeguard against forgetting.

Beyond its immediate application in online scenarios, the versatility of FOCIL suggests potential adaptability to many continual learning scenarios. Our future research will delve into exploring more effective ways for expert identification of a given data or task. In addition, extending FOCIL to an offline setting as well as to other continual learning scenarios such as domain incremental learning would be promising further advancements in the field. Overall, the success of FOCIL sets a new standard in online class incremental learning and opens avenues for refining incremental learning methodologies, with the potential to reshape approaches in both online and offline continual learning scenarios.

Broader Impact

This paper presents work whose goal is to advance the field of Machine Learning, especially on the subject of Online Class Incremental Learning. Besides the advancements in the field, it eliminates the need to store data, thereby improving privacy.

For AGEM and ER, we use SGD optimizer and set the learning rate to 0.1. We uniformly randomly select samples to update the memory buffer and replay.

For GSS, we use SGD optimizer and set the learning rate to 0.1. The number of batches randomly sampled from the memory buffer to estimate the maximal gradients cosine similarity score is set to 64, and the random sampling batch size for calculating the score is set to 64.

For MIR, we use SGD optimizer and set the learning rate to 0.1. The number of subsamples is set as 100.

For GDumb, we use SGD optimizer and set the learning rate to 0.1. The value for gradient clipping is set to 10. The minimal learning rate is set to 0.0005, and the epochs to train for the memory buffer are 70.

For ASER, we use SGD optimizer and set the learning rate to 0.1. The nearest neighbor is set to 3. We use mean values of Adversarial SV and Cooperative SV and set the maximum number of samples per class for random sampling to 1.5. We use the SV-based methods for memory update and retrieval as in the original paper.

For CoPE, we use SGD optimizer and set the learning rate to 0.005. We set the temperature to 0.05. The momentum of the moving average updates for the prototypes is set to 0.9.
