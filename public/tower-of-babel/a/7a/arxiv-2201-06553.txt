Paired compressed cover trees guarantee a near linear parametrized complexity for all k k -nearest neighbors search in an arbitrary metric space
Yury Elkin, Vitaliy Kurlin

Abstract
This paper studies the important problem of finding all k k -nearest neighbors to points of a query set Q Q in another reference set R R within any metric space. Our previous work defined compressed cover trees and corrected the key arguments in several past papers for challenging datasets. In 2009 Ram, Lee, March, and Gray attempted to improve the time complexity by using pairs of cover trees on the query and reference sets. In 2015 Curtin with the above co-authors used extra parameters to finally prove a time complexity for k = 1 k=1 . The current work fills all previous gaps and improves the nearest neighbor search based on pairs of new compressed cover trees. The novel imbalance parameter of paired trees allowed us to prove a better time complexity for any number of neighbors k ≥ 1 k\geq 1 .

All

-nearest neighbors problem and overview of new results

The nearest neighbor search was one of the first data-driven problems
[
7
]
.
Briefly, the problem is to find all
k\geq 1
nearest neighbors in a reference set
R
for all points from a query set
Q
.
Both sets live in an ambient space
X
with a distance
d
satisfying all metric axioms.
For example,
X=\mathbb{R}^{m}
with the Euclidean metric, a query set
Q
can be a single point.

The naive approach to find first nearest neighbors of points from
Q
within
R
is proportional to the product
|Q|\cdot|R|
of the sizes of
Q,R
.
The aim in nearest neighbor search is to reduce the brute-force complexity
O(|Q|\cdot|R|)
to a near linear time in the maximum size of
Q,R
.

The
exact

k
-nearest neighbor problem asks for exact (true)
k
-nearest neighbors of every query point
q
.
The
probabilistic
neighbor problem
[
14
]
aims to find exact
k
-nearest neighbors with a given probability.
The
approximate
neighbor problem
[
2
]
,
[
13
]
,
[
1
]
,
[
17
]
aims to find for every query point
q\in Q
its approximate neighbor
r\in R
satisfying
d(q,r)\leq(1+\epsilon)d(q,\mathrm{NN}(q))
, where
\epsilon>0
is fixed and
\mathrm{NN}(q)
is the exact first nearest neighbor of
q
.

Arguably the first approach to the neighbor search was developed in 1974 by using a
quadtree

[
11
]
, which hierarchically indexed a reference set
R\subset\mathbb{R}^{2}
.
In higher dimensions, a KD-tree
[
3
]
smarter subdivided a subset of
R\subset\mathbb{R}^{m}
at every level into two subsets instead of
2^{m}
subsets.

[
10

described further developments since 1970s in detail.
Section
2
will technically compare the most recent results after formalizing the key concepts below.

We formally define the
k
-nearest neighbor set

\mathrm{NN}_{k}(q)

Definition 1.1

(
k
-nearest neighbor set
\mathrm{NN}_{k}
)
.

Let

be finite subsets of a metric space.
For any points

and

consists of all points that are non-strictly closer to
q
than

is close to
q
.
For any integer

k
-nearest neighbor set

\mathrm{NN}_{k}(q)
consists of all points

such that
|N(q;u)|\geq k
and any other

with

has a larger neighborhood of size
|N(q;v)|>k
.

\blacksquare

For

, the nearest neighbor sets of

\mathrm{NN}_{1}(0)=\{1\}
,
\mathrm{NN}_{2}(0)=\{2\}

\mathrm{NN}_{3}(0)=\{3\}

Due to the neighborhoods

The 3-nearest neighbor set

is a single point.
Because of a potential ambiguity of an exact

In the above example,

Review of past work and challenges in the
k
-nearest neighbor search

First we review the past searches by using a single tree on a reference set
R
.
Then we consider the faster searchers by using a paired trees (a dual tree approach) on both
Q,R
.

Search on a single tree
.
The highly-cited paper
[
5
]
by Beygelzimer, Kakade, Langford in 2006 introduced the first concept of a cover tree to prove a worst-case time complexity for a 1st nearest neighbor search (
k=1
).
This tree was motivated by the earlier navigating nets
[
13
]
and is called an
implicit cover tree
to distinguish other versions in Fig.
1
and
4
.

[
5
, Theorem 6]
implied that an implicit cover tree
T
on a reference set
R
can be built in time
O(c^{6}|R|\log|R|)
, where
|R|
is the size (number of points) of
R
,
c
is an expansion constant depending a structure of
R
, see Definition
3.4
.
Assuming that
T
is already built,
[
5
, Theorem 5]
expressed the time complexity to find a 1st nearest neighbor in
R
for all points
q\in Q
as
O(c^{12}|Q|\log|R|)
.
However, both statements relied on
[
5
, Lemma 4.3]
showing that a depth of a single point in a tree is
O(c^{2}\log|R|)
.
In 2015
[
9
, Section 5.3]
pointed out
[
5
, Lemma 4.3]
cannot be used to estimate the number of internal recursions in
[
5
, Theorem 5]
. In
[
10
, section 3]
it was shown that the original time complexity theorem for the cover tree construction algorithm
[
5
, Theorem 6]
had similar issues.
Otherwise, the past argument guarantees the total complexity
O(c^{12}|R|^{2})
for
Q=R
as for a brute-force search for
k=1
.
In 2021
[
10
, section 3]
described typical sets
R
that indeed require more careful estimates.

The above facts motivated a new concept of a compressed cover tree to clarify the worst-case complexity for all reference sets
R
, see Definition
3.1
, which

[
10
, Theorem 6.5]
showed that, after constructing a compressed cover tree
\mathcal{T}(R)
on
R
, we can find all
k
-nearest neighbors of
q
in
R
in time
O(c^{10}k\log(k)\cdot|H(\mathcal{T}(R))|)
for any
k\geq 1
, where
|H(\mathcal{T}(R))|
is the height of
\mathcal{T}(R)
, see Definition
3.10
.
The new height parameter
|H(\mathcal{T}(R))|
has the upper bound
\log_{2}(\Delta)
, where the aspect ratio
\Delta
is the diameter of
R
divided by the minimum distance between points in
R
.
Another approach uses paired trees on both sets
Q,R
.

Search on paired trees
.
In 2001 Gray and Moore
[
12
]
considered two KD-trees on the reference and query sets
Q,R
.
The approach was often called a dual-tree search.
Since the trees on
Q,R
are independent, there is no real duality between them, so we call such trees
paired
.
In 2006
[
4
]
proposed to consider paired cover trees.

[
4
, Theorem 3.7]
claimed that
[
4
, Algorithm 5]
finds all 1st nearest-neighbors for a query set
Q
in time
O(c^{16}\max\{|Q|,|R|\})
.
In the case
Q=R
,
[
4
, Algorithm 5]

seems to return only the self-neighbor

q\in R
.
A sketched proof of
[
4
, Theorem 3.7]
claimed similarities with the argument in
[
5
, Theorem 5]
without details that could clarify the concerns in the single tree case.

In 2009
[
16

revisited the time complexity for all 1st nearest neighbors and claimed the upper bound
O(c(R)^{12}c(Q)^{4\kappa}\max\{|Q|,|R|\})
, where
c(Q),c(R)
are expansion constants of the query set
Q
and reference set
R
.
The degree of bichromaticity
\kappa
is a parameter of both sets
Q,R
, see
[
16
, Definition 3.1]
.
We have found the following issues.

First, Counterexample
A.4
shows that
[
16
, Algorithm 1]
for
Q=R
returns for any query point
q\in Q
the same point
q
as its first neighbor.
Second, Remark
A.6
explains several possible interpretations of
[
16
, Definition 3.1]
for the parameter
\kappa
.
Third,
[
16
, Theorem 3.1]
similarly to
[
5
, Theorem 5]
relied on the same estimate of recursions in the proof of
[
5
, Lemma 4.3]
.
Counterexample
A.7
explains step-by-step why the time complexity of
[
16
, Algorithm 1]
requires a clearer definition of
\kappa
and more detailed justifications.

In 2015 Curtin with the authors above
[

]
introduced other parameters:
the imbalance
I_{t}
in
[

and

[

These parameters measured extra recursions that occurred due to possible imbalances in trees built on

[

shows that, for constructed cover trees on a query set

The main novelty

The new single imbalance

The height

In practice, we often need to quickly find nearest neighbors for a small number of data objects within a much larger dataset.

A compressed cover tree and other tools for

Definition 3.1

(a compressed cover tree
\mathcal{T}(R)
,
[
10
, Definition 2.1]
)
.

Let
R
be a finite set in an ambient space
X
with a metric
d
.

A compressed cover tree

\mathcal{T}(R)
has the vertex set
R
with a root
r\in R
and a
level
function
l:R\rightarrow\mathbb{Z}
satisfying the conditions below.

(
3.1
a)

Root condition
:
the level of a root node
r
is
l(r)\geq 1+\max_{p\in R-r}l(p)
.

(
3.1
b)

Covering condition
:
every non-root node
q\in R
has a unique
parent

p
and a level
l(q)<l(p)
so that
d(q,p)\leq 2^{l(q)+1}
;
then
p
has a single link to its
child
node
q
in
\mathcal{T}(R)
.

(
3.1
c)

Separation condition
:
for any
i\in\mathbb{Z}
, the
cover set

C_{i}=\{p\in R\mid l(p)\geq i\}
has a minimum separation distance

d_{\min}(C_{i})=\min\limits_{p\in C_{i}}\min\limits_{q\in C_{i}-p}d(p,q)>2^{i}
.

Since there is a 1-1 correspondence between all reference points in
R
and all nodes of the tree
\mathcal{T}(R)
, the same notation
p
can refer to a point of the reference set
R
or to a node of a tree
\mathcal{T}(R)
.
Set
l_{\max}=1+\max\limits_{p\in R-r}l(p)
and
l_{\min}=\min\limits_{p\in R}l(p)
.
For a node
p\in\mathcal{T}(R)
, let
\mathrm{Children}(p)
denote the set of all children of
p
, including
p
itself, which will be convenient later.

For any node
p\in\mathcal{T}(R)
, define the
node-to-root
path as a unique sequence of nodes
w_{0},\dots,w_{m}
such that
w_{0}=p
,
w_{m}
is the root and
w_{j+1}
is the parent of
w_{j}
for all
j=0,...,m-1
.
A node
q\in\mathcal{T}(R)
is called a
descendant
of another node
p
if
p
belongs to the node-to-root path of
q
.
A node
p
is an
ancestor
of
q
if
q
belongs to the node-to-root path of
p
.
The set of all descendants of a node
p
is denoted by
\mathrm{Descendants}(p)
and includes the node
p
itself.

Lemma 5.4
