Connectivity of graphs that do not have the edge-Erdős-Pósa property
Henning Bruhn, Raphael Steck

Abstract
We show that we can assume graphs that do not have the edge-Erdős-Pósa property to be connected. Then we strengthen this result to 2 2 -connectivity under the additional assumptions of a minor-closed property and a generic counterexample.



A class
\mathcal{F}
has the
edge-Erdős-Pósa property
if there exists a function
f:\mathbb{N}\rightarrow\mathbb{R}
such that for every graph
G
and every integer
k

k

G
each isomorphic to some graph in
\mathcal{F}
or there is an edge set

of size at most

meeting all subgraphs in

isomorphic to some graph in
\mathcal{F}

is called the

If we replace vertices with edges in the above definition, that is, we look for a vertex hitting set or vertex-disjoint graphs, then we obtain the
vertex-Erdős-Pósa property
.
The class

that is studied in this paper arises from taking minors: For a fixed graph
H
, we define the set

\mathcal{F}_{H}=\{G\,|\,H\text{ is a minor of }G\}.

In other words,
\mathcal{F}_{H}
is the set of
H
-expansions
. The vertex-Erdős-Pósa property for
\mathcal{F}_{H}
is well understood: Robertson and Seymour
[
1
]
proved that the class
\mathcal{F}_{H}
has the vertex-Erdős-Pósa property if and only if
H
is planar. This implies that the vertex-Erdős-Pósa property is closed under taking minors, which in turn implies that

If for a graph
H
the class
\mathcal{F}_{H}
has the vertex-Erdős-Pósa property, then so does the class
\mathcal{F}_{C}
for every component
C
of
H

(1)

For the edge-Erdős-Pósa property, it is not known whether it is minor-closed or not, and it is not at all clear whether it should be. Thus, we tackle (
1
) for the edge-Erdős-Pósa property. We show that

Theorem 1
.

If for a graph
H
the class
\mathcal{F}_{H}
has the edge-Erdős-Pósa property, then so does
\mathcal{F}_{C}
for every component

of

Interestingly, Robertson and Seymour proved their result about the vertex-Erdős-Pósa property of planar graphs in two steps: First, they proved it for every connected planar graph. In a second step, they lifted the connectivity requirement. Thus Theorem

might also provide some help in verifying for which graphs

the class
\mathcal{F}_{H}
has the edge-Erdős-Pósa property. For example, it might help to prove that
\mathcal{F}_{H}
does not have the edge-Erdős-Pósa property if

has large treewidth (for larger or arbitrary maximum degree of

To this end, we also attempt a strengthening of Theorem

which allows us to not only focus on connected, but
2
-connected graphs

2
2-Connectivity

First, we define a graph property

\mathcal{P}
, no minor of

\mathcal{P}
. An example for a hereditary property would be large treewidth: If a graph
H

Second, for a block

k

-expansions in

. Furthermore, for every

, there is a

, there is an embedding of
A
in
A^{*}
such that for every vertex

contains

Every known construction that shows that some class
