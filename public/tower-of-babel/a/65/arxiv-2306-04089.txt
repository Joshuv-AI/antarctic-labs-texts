Fully Automated Verification of Linear Time-Invariant Systems against Signal Temporal Logic Specifications via Reachability Analysis Journal: Nonlinear Analysis: Hybrid Systems
Niklas Kochdumper, Stanley Bak

Abstract
While reachability analysis is one of the most promising approaches for formal verification of dynamic systems, a major disadvantage preventing a more widespread application is the requirement to manually tune algorithm parameters such as the time step size. Manual tuning is especially problematic if one aims to verify that the system satisfies complicated specifications described by signal temporal logic formulas since the effect the tightness of the reachable set has on the satisfaction of the specification is often non-trivial to see for humans. We address this problem with a fully-automated verifier for linear systems, which automatically refines all parameters for reachability analysis until it can either prove or disprove that the system satisfies a signal temporal logic formula for all initial states and all uncertain inputs. Our verifier combines reachset temporal logic with dependency preservation to obtain a model checking approach whose over-approximation error converges to zero for adequately tuned parameters. While we in this work focus on linear systems for simplicity, the general concept we present can equivalently be applied for nonlinear and hybrid systems.

1.1
State of the Art

Approaches that check if a system satisfies a temporal logic specification can be divided into the two groups runtime verification and static verification. Runtime verification, which is often realized via monitors
[
7
,
6
]
, treats the system as a black box and checks if the observations obtained from the system satisfy the specification. Static verification, on the other hand, considers the case where a model of the system is available and checks if all executions of the model satisfy the temporal logic specification. Since our method falls into the static verification category, we focus on this group from now on.
A standard approach for formal verification against temporal logic specifications is to convert the temporal logic formula into an equivalent acceptance automaton
[
8
, Sec. 2.7]
.
If the system itself can be represented by a finite state automaton, formal verification reduces to checking if there exists an accepting trace for the automaton obtained by taking the automaton product of the system and the acceptance automaton for the negated temporal logic formula
[
9
, Sec. 5.2]
, which can be realized with standard automaton analysis tools
[
10
]
.

Also methods for continuous-time systems apply the acceptance automaton concept

One major disadvantage of these methods is that reachability analysis for hybrid systems, which are obtained from the automaton product of the continuous dynamics with the acceptance automaton, is quite challenging and often provides very conservative results. Apart from the acceptance automaton concept, there also exist other strategies

[

[

1.2
Contribution

In this work we present the first fully-automated verifier for linear systems and signal temporal logic specifications, which is based on the reachset temporal logic approach
[
11
]
. One major drawback of the previous RTL method is demonstrated by the example shown in Fig.
1
: RTL checks if the atomic predicates are satisfied by the whole reachable set, which yields very conservative results, especially if the reachable set becomes large. We solve this problem by keeping track which parts of the initial set and input set satisfy or violate the predicates at specific points in time, as it is visualized in Fig.
2
. In summary, our verifier has the following features:

\bullet

The algorithm is guaranteed to converge to the solution in finite time for decidable problem instances.

\bullet

Our verifier is fully-automated, so no manual parameter tuning is required.

\bullet

In case the system violates the specification we return a counterexample in form of a falsifying trajectory, which might provide valuable insights for a system engineer.

\bullet

Since our verifier naturally divides the initial set and input set into parts that satisfy or violate the temporal logic formula, it can also be used to determine a safe set of states or cut away all states that yield a violation, which is very useful for controller synthesis and set-based prediction.

We will demonstrate all of these features on several interesting benchmarks.

2.3
Reachability Analysis

The reachable set of a dynamic system is defined as follows:

Definition 3

(Reachable Set) We consider a dynamic system whose behavior is described by the differential equation

\dot{x}(t)=f\big(x(t),u(t)\big),

(10)

where
x(t)\in\mathbb{R}^{n}
is the system state and
u(t)\in\mathbb{R}^{m}
is the input. Given an initial set
\mathcal{X}_{0}\subset\mathbb{R}^{n}
and an input set
\mathcal{U}\subset\mathbb{R}^{m}
, the reachable set at time
t\geq 0
is defined as

\mathcal{R}^{\text{e}}(t):=\big\{\xi(t,x_{0},u(\cdot))~\big|~x_{0}\in\mathcal{X}_{0},\forall\theta\in[0,t]:~u(\theta)\in\mathcal{U}\big\},

where
\xi(t,x_{0},u(\cdot))
denotes the solution to (
10
) for the initial state
x_{0}=x(0)
and the input signal
u(\cdot)
.

Since the exact reachable set
\mathcal{R}^{\text{e}}(t)
as defined in Def.
3
cannot be computed in general, the goal of reachability analysis is to calculate a tight enclosure
\mathcal{R}(t)\supseteq\mathcal{R}^{\text{e}}(t)
instead. Moreover, it is common practice to compute the reachable set for consecutive time intervals
\tau_{i}=[t_{i},t_{i+1}]
with
t_{i}=i\cdot\Delta t
,
i\in\{0,\dots,t_{\text{end}}/\Delta t\}
, where
\Delta t
is the time step size and
t_{\text{end}}
is the final time. We assume without loss of generality that time starts at
t_{0}=0
and
t_{\text{end}}
is a multiple of
\Delta t
. Consequently, the reachable set for the whole time horizon
\mathcal{R}([0,t_{\text{end}}])
is given by a sequence

\mathcal{R}(t_{0}),\mathcal{R}(\tau_{0}),\mathcal{R}(t_{1}),\mathcal{R}(\tau_{1}),\dots,\mathcal{R}(\tau_{t_{\text{end}}/\Delta t-1}),\mathcal{R}(t_{\text{end}})

(11)

of time point reachable sets
\mathcal{R}(t_{i})
and time interval reachable sets
\mathcal{R}(\tau_{i})
. For the remainder of the paper, we use the shorthand notation
\forall u(\cdot)\in\mathcal{U}
to refer to the set
\{u(\cdot)\,|\,\forall\theta\in[0,t_{\text{end}}]:\,u(\theta)\in\mathcal{U}\}
of all input signals that are contained in the input set
\mathcal{U}
at all times.

Some reachability algorithms preserve dependencies between initial states and inputs and the corresponding reachable states
[
25
]
. For those algorithms, the computed enclosure of the reachable set can be used to construct a symbolic function that approximates the solution to the differential equation within a guaranteed error bound:

Definition 4

(Dependency Preservation)
Let
\mathcal{R}(t)
be an enclosure of the reachable set for the initial set
\mathcal{X}_{0}
and the set of uncertain inputs
\mathcal{U}
computed with a reachability algorithm
\mathcal{A}
. The reachability algorithm
\mathcal{A}
is dependency preserving if the computed reachable set
\mathcal{R}(t)
can be used to construct a function
\mu(t,x_{0},u(\cdot))
that approximates the solution
\xi(t,x_{0},u(\cdot))
of the differential equation in (
10
) within some time-varying error bound
\mathcal{E}(t)
for all initial states
x_{0}\in\mathcal{X}_{0}
and input signals
u(\cdot)\in\mathcal{U}
:

\forall t\in[0,t_{\text{end}}],\forall x_{0}\in\mathcal{X}_{0},\forall u(\cdot)\in\mathcal{U}:~\xi(t,x_{0},u(\cdot))\in\mu(t,x_{0},u(\cdot))\oplus\mathcal{E}(t)\,\subseteq\,\mathcal{R}(t),

where the trivial solution
\mu(t,x_{0},u(\cdot))=\mathbf{0}
and
\mathcal{E}(t)=\mathcal{R}(t)
is only allowed if the reachable set enclosure
\mathcal{R}(t)
is singleton.

The main advantage of dependency preservation is that with the analytical relation
\mu(t,x_{0},u(\cdot))
between initial states and inputs and the corresponding reachable states enclosures of reachable sets for single initial states and inputs can be computed very efficiently in terms of a simple function evaluation.

2.4
Temporal Logic

We consider specifications in signal temporal logic
[
6
]
:

Definition 5

(Signal Temporal Logic) The syntax of a signal temporal logic formula over a finite set of atomic predicates
\varrho\in\mathcal{AP}
is

\varphi:=\varrho\,|\,\neg\varphi\,|\,\varphi_{1}\vee\varphi_{2}\,|\,\varphi_{1}\wedge\varphi_{2}\,|\,\varphi_{1}\,U_{[a,b]}\,\varphi_{2}\,|\,\varphi_{1}\,R_{[a,b]}\,\varphi_{2}\,|\,\lozenge_{[a,b]}\,\varphi\,|\,\Box_{[a,b]}\,\varphi\,|\,\bigcirc_{a}\,\varphi

with
a,b\in\mathbb{R}_{\geq 0}
and
b\geq a
, where we in addition to the until operator
\varphi_{1}\,U_{[a,b]}\,\varphi_{2}
consider the operators release
\varphi_{1}\,R_{[a,b]}\,\varphi_{2}:=\neg(\neg\varphi_{1}\,U_{[a,b]}\,\neg\varphi_{2})
, finally
\lozenge_{[a,b]}\,\varphi:=\mathrm{true}~U_{[a,b]}\,\varphi
, globally
\Box_{[a,b]}\,\varphi:=\neg\lozenge_{[a,b]}\,\neg\varphi
, and next
\bigcirc_{a}\,\varphi:=\lozenge_{[a,a]}\,\varphi
. For a trace
\xi(t)
, the semantics of a signal temporal logic formula is defined as follows:

\begin{split}\xi\vDash\varrho&~~\Leftrightarrow~~\pi_{\varrho}(\xi(0))=\mathrm{true}\\
\xi\vDash\neg\varphi&~~\Leftrightarrow~~\neg(\xi\vDash\varphi)\\
\xi\vDash\varphi_{1}\vee\varphi_{2}&~~\Leftrightarrow~~(\xi\vDash\varphi_{1})\vee(\xi\vDash\varphi_{2})\\
\xi\vDash\varphi_{1}\,U_{[a,b]}\,\varphi_{2}&~~\Leftrightarrow~~\exists t\in[a,b]:\xi_{t}\vDash\varphi_{2}~\wedge~\forall t^{\prime}\in[0,t):\xi_{t^{\prime}}\vDash\varphi_{1}\end{split}

using a predicate evaluation function
\pi_{\varrho}
and notation
\xi_{a}(t):=\xi(t+a)
. The semantics for the conjunction follows from the equality
\varphi_{1}\wedge\varphi_{2}=\neg(\neg\varphi_{1}\vee\neg\varphi_{2})
.

In this work we consider atomic predicates given by linear inequality constraints such as
2\,x_{1}-3\,x_{2}\leq 1
.
Please note that this also includes polytope containment since
x\in\mathcal{P}
with
\mathcal{P}=\langle C,d\rangle_{P}
can be represented as
C_{(1,\cdot)}x\leq d_{(1)}\wedge\dots\wedge C_{(s,\cdot)}x\leq d_{(s)}
. Reachset temporal logic
[
11
, Def. 2]
is a special type of logic that can be directly evaluated on a reach sequence (
11
):

Definition 6

(Reachset Temporal Logic) The syntax of a reachset temporal logic formula
1
1

1

In contrast to
[
11
, Def. 2]
, we use a shortened definition of RTL that is restricted to the relevant parts.
over a finite set of atomic predicates
\varrho\in\mathcal{AP}
is

\varphi:=A\,\varrho~|~\varphi_{1}\vee\varphi_{2}~|~\varphi_{1}\wedge\varphi_{2}~|~\bigcirc_{a}\,\varphi

with
a=i\cdot\Delta t/2
and
i\in\mathbb{N}_{\geq 0}
, where
\Delta t
is the time step size. The all operator
A\,\varrho
specifies that a predicate is satisfied for all states inside the reachable set, and the next operator
\bigcirc_{a}\,\varphi
refers to a time point reachable set if

is an integer multiple of
\Delta t
and to a time interval reachable set otherwise. For a reachable set
\mathcal{R}(t)
, the semantics of a reachset temporal logic formula is defined as follows:

\begin{split}\mathcal{R}\vDash A\,\varrho&~~\Leftrightarrow~~\forall r\in\mathcal{R}(0):~\pi_{\varrho}(r)=\mathrm{true}\\
\mathcal{R}\vDash\varphi_{1}\vee\varphi_{2}&~~\Leftrightarrow~~(\mathcal{R}\vDash\varphi_{1})\vee(\mathcal{R}\vDash\varphi_{2})\\
\mathcal{R}\vDash\varphi_{1}\wedge\varphi_{2}&~~\Leftrightarrow~~(\mathcal{R}\vDash\varphi_{1})\wedge(\mathcal{R}\vDash\varphi_{2})\\
\mathcal{R}\vDash\bigcirc_{a}\,\varphi&~~\Leftrightarrow~~\begin{cases}\mathcal{R}_{a}\vDash\varphi,&a~\text{mod}~\Delta t=0\\

using a predicate evaluation function
\pi_{\varrho}
and notation
\mathcal{R}_{a}(t):=\mathcal{R}(t+a)
.

The paper
[

]
that introduced RTL also provides an approach for converting a temporal logic formula in STL to RTL. Given an STL formula

, the resulting RTL formula

has according to

\varphi_{\text{rtl}}=\bigwedge_{h=0}^{H}\bigvee_{j=0}^{J}\bigcirc_{j\,\Delta t/2}\bigvee_{k=0}^{K}A\,\varrho_{hjk},

where

,

, and

Since we consider the case where the atomic predicates

are all given by linear inequality constraints, the entailment check

can be equivalently formulated in terms of intersection checks between the reachable set
\mathcal{R}(t)
and polytopes

:

\mathcal{R}\vDash\varphi_{\text{rtl}}~~\Leftrightarrow~~\bigwedge_{h=0}^{H}\bigvee_{j=0}^{J}\bigvee_{k=0}^{K}\bigg(\widetilde{\mathcal{R}}(j\,\Delta t/2)\cap\bigcup_{l=0}^{L}\mathcal{P}_{hjkl}=\emptyset\bigg),

(12)

where

is the number of polytopes required to represent the atomic predicates
\varrho_{hjk}
and the auxiliary variable
\widetilde{\mathcal{R}}(t)
is used to distinguish between time point and time interval reachable sets:

\widetilde{\mathcal{R}}(t)=\begin{cases}\mathcal{R}(t_{j}),&t~\text{mod}~\Delta t=0\\
\mathcal{R}(\tau_{j}),&\text{otherwise}\end{cases}~~~~\text{with}~~~~j=\lfloor t/\Delta t\rfloor.

Since we use the same time step size
\Delta t
for reachability analysis and for the time-discretization of reachset temporal logic, (
12
) can be directly evaluated on a reach sequence (

).
An example demonstrating the conversion from STL to RTL is provided in

.

According to

]
, it holds that if the reachable set satisfies the RTL formula

, then it is guaranteed that all traces contained in the reachable set satisfy the corresponding STL formula

. Due to the conservatism introduced by the time-discretization for RTL with

, the contrary does not hold, meaning that satisfaction of the STL formula does not automatically imply satisfaction of the RTL formula. However, since the conservatism introduced by the time-discretization converges to zero for
\Delta t\to 0

[
11
]
, satisfaction of STL and RTL becomes equivalent in the limit case
\Delta t\to 0
.

Problem Formulation

We consider linear time-invariant systems

\displaystyle\dot{x}(t)

\displaystyle=A\,x(t)+B\,u(t)

The initial state

is uncertain within the input set
\mathcal{U}\subset\mathbb{R}^{m}
. In this work, we assume that
\mathcal{X}_{0}
and
\mathcal{U}
are represented by zonotopes.
While we consider the set of uncertain inputs
\mathcal{U}
to be constant over time for simplicity, the extension to a time-varying set of uncertain inputs
\mathcal{U}(t)
is straightforward. Time-varying sets of uncertain inputs can for example be used to pass external signals such as reference trajectories or a sequence of control commands to the model.

Given an STL formula
\varphi
, our goal is to decide whether the system (
13
) satisfies
\varphi
for all initial states
x_{0}\in\mathcal{X}_{0}
and all input signals
u(\cdot)\in\mathcal{U}
:

\forall t,\forall x_{0}\in\mathcal{X}_{0},\forall u(\cdot)\in\mathcal{U}:~\xi(t,x_{0},u(\cdot))\vDash\varphi,

where
\xi(t,x_{0},u(\cdot))
is the solution to (
13
) for the initial state
x_{0}=x(t_{0})
and the input signal
u(\cdot)
.

4
Reachability Analysis

For the approach presented in this paper we require a reachability algorithm that is dependency preserving according to Def.
4
. To construct such an algorithm, we modify the reachability algorithm in
[
24
, Sec. 3.2]
by using a different enclosure for the reachable set due to uncertain inputs
\mathcal{P}(\Delta t)
. In particular, to preserve dependencies on the inputs, we approximate the reachable set due to time-varying inputs with the reachable set due to constant inputs
\mathcal{P}_{c}(\Delta t)=T\,\mathcal{U}_{0}
in each time step, where

T=A^{-1}(e^{A\Delta t}-I_{n})

(14)

is the propagation matrix for constant inputs and
\mathcal{U}_{0}=B\big(\mathcal{U}\oplus(-c_{u})\big)\subset\mathbb{R}^{n}
is an auxiliary variable defined using the geometric center
c_{u}
of the input set
\mathcal{U}=\langle c_{u},G_{u}\rangle_{Z}
. If the matrix
A
is not invertible,
A^{-1}
in (
14
) can be integrated into the power-series for the exponential matrix
[
26
, Sec. IV]
. Since
\mathcal{P}_{c}(\Delta t)=T\,\mathcal{U}_{0}
is computed using a linear map, it preserves dependencies according to
[
25
, Tab. 1]
. We account for the approximation error with the bloating term

\mathcal{D}=\bigg(\sum_{j=1}^{\kappa}\frac{A^{j}\Delta t^{j+1}}{(j+1)!}\bigg)\mathcal{U}_{0}\oplus\bigoplus_{j=1}^{\kappa}\frac{A^{j}\Delta t^{j+1}}{(j+1)!}\,\mathcal{U}_{0}\oplus 2\,\Delta t\,\boldsymbol{\mathcal{E}}\,\mathcal{U}_{0},

(15)

which according to
[
5
, Prop. 2]
encloses the difference between constant and time-varying inputs. Consequently, we overall obtain the following enclosure for the reachable set due to time-varying inputs:

\mathcal{P}(\Delta t)\subseteq T\,\mathcal{U}_{0}\oplus\mathcal{D}.

(16)

Another essential part of the reachability algorithm in
[
24
, Sec. 3.2]
is the set
\mathcal{C}_{i}
that accounts for the curvature of trajectories and is according to
[
24
, Sec. 3.2]
given as

\mathcal{C}_{i}=(e^{A\Delta t})^{i}\big(\boldsymbol{\mathcal{F}}\,\mathcal{X}_{0}\oplus\boldsymbol{\mathcal{G}}\,\widetilde{u}\big)

(17)

using the auxiliary variable
\widetilde{u}=Bc_{u}\in\mathbb{R}^{n}
and the interval matrices
[
24
, Sec. 3.2]

\boldsymbol{\mathcal{F}}=\boldsymbol{\mathcal{T}}^{(\kappa)}A\oplus\boldsymbol{\mathcal{E}},~\boldsymbol{\mathcal{G}}=\boldsymbol{\mathcal{T}}^{(\kappa+1)}\oplus\boldsymbol{\mathcal{E}}\Delta t,~\boldsymbol{\mathcal{T}}^{(o)}=\bigoplus_{j=2}^{o}\big[\big(j^{\frac{-j}{j-1}}-j^{\frac{-1}{j-1}}\big)\Delta t^{j},0\big]\frac{A^{j-1}}{j!},

(18)

where the parameter
\kappa
and the interval matrix
\boldsymbol{\mathcal{E}}
are the truncation order and the remainder of the Taylor series for the exponential matrix
[
24
, Eq. (3.2)]
:

\boldsymbol{\mathcal{E}}=[-E,E],\quad E=e^{|A|\Delta t}-\sum_{j=0}^{\kappa}\frac{\big(|A|\Delta t\big)^{j}}{j!}.

Using the enclosure of the reachable set due to time-varying inputs
\mathcal{P}(\Delta t)
in (
16
) as well as the curvature enclosure
\mathcal{C}_{i}
in (
17
), the reachability algorithm in
[
24
, Sec. 3.2]
finally computes tight enclosures of the time point reachable set
\mathcal{R}(t_{i})
and the time interval reachable set
\mathcal{R}(\tau_{i})
as follows:

\begin{split}&\mathcal{R}(t_{i})=\mathcal{H}(t_{i})\oplus\mathcal{P}(t_{i}),\\
&\mathcal{R}(\tau_{i})=conv\big(\mathcal{H}(t_{i}),\mathcal{H}(t_{i+1})\big)\oplus\mathcal{P}(t_{i+1})\oplus\mathcal{C}_{i},\end{split}

(19)

where the homogeneous solution
\mathcal{H}(t_{i})
resulting from the propagation of the initial set and constant inputs as well as the particular solution
\mathcal{P}(t_{i})
due to uncertain time-varying inputs are computed using the following propagation scheme:

\begin{split}\mathcal{H}(t_{i+1})&=e^{A\Delta t}\,\mathcal{H}(t_{i})\oplus T\,\widetilde{u},\\
\mathcal{P}(t_{i+1})&=e^{A\Delta t}\,\mathcal{P}(t_{i})\oplus\mathcal{P}(\Delta t),\end{split}

(20)

where the initial values are
\mathcal{H}(0)=\mathcal{X}_{0}
and
\mathcal{P}(0)=\mathbf{0}
. The resulting reachability algorithm is summarized in Alg.
1
, where we enclose
\mathcal{C}_{i}
and
\mathcal{D}
by intervals to reduce the number of generators of the reachable set.

5
Model Checking

The main disadvantage of model checking using RTL is that the intersection checks in (
12
) are evaluated in a pure true/false manner, losing all information about which initial states or inputs result in an intersection. As visualized in Fig.
1
, the model checking procedure therefore also considers so-called spurious traces, which are contained in the reachable set but are not consistent with the system dynamics. In this work we solve this problem by explicitly keeping track which initial states and which inputs result in an intersection.

In particular, we approximate the set of all possible time-varying inputs
u(\cdot)\in\mathcal{U}
with the set of all possible piecewise constant inputs, because our reachability algorithm Alg.
1
is dependency preserving for piecewise constant inputs. This approximation does not negatively affect the completeness of our model checking algorithm, since in the limit case
\Delta t\to 0
piecewise constant inputs approximate time-varying inputs arbitrary well. For our model checking algorithm, we have to consider the set containing all possible combinations of initial states and piecewise constant inputs, which is given as
\mathcal{X}_{0}\times\mathcal{U}\times\dots\times\mathcal{U}
. As shown in (
21
), since both the initial set and the input set are represented by zonotopes, we can equivalently represent every initial state and every piecewise constant input signal by the corresponding zonotope factors
\alpha_{x}
and
\alpha_{u,i}
. Therefore, the set
\mathcal{X}_{0}\times\mathcal{U}\times\dots\times\mathcal{U}
containing all possible combinations of initial states and inputs can equivalently be represented in the space of zonotope factors by the hypercube
\widetilde{\alpha}=[-\mathbf{1},\mathbf{1}]
with
\widetilde{\alpha}
defined as in (
23
). Since the hypercube
\widetilde{\alpha}=[-\mathbf{1},\mathbf{1}]
is computationally much easier to handle than the zonotope
\mathcal{X}_{0}\times\mathcal{U}\times\dots\times\mathcal{U}
, our model checking algorithm represents initial states and inputs in factor space
\widetilde{\alpha}=[-\mathbf{1},\mathbf{1}]
.

and a polytope
\mathcal{P}_{hjkl}
we can divide the domain

into factors that potentially lead to an intersection and factors that are guaranteed to not result in an intersection with the polytope
\mathcal{P}_{hjkl}

. Then, we need to show that there exists a vector of factors
\widetilde{\alpha}\in[-\mathbf{1},\mathbf{1}]
that does not intersect any of the safe sets
\mathcal{K}_{j}=\langle C_{j},d_{j}\rangle_{P}\in\mathbf{L}
(see Line

\begin{split}\min_{\widetilde{\alpha}\in[-\mathbf{1},\mathbf{1}]}\|\widetilde{\alpha}\|_{1}~~\text{subject to}~~&\forall j\in\{1,\dots,|\mathbf{L}|\},~\forall k\in\{1,\dots,s_{j}\}:\\
&C_{j(\cdot,k)}\,\widehat{\alpha}_{jk}>\lambda_{jk}\,d_{j(k)},~-\mathbf{1}\,\lambda_{jk}\leq\widehat{\alpha}_{jk}\leq\mathbf{1}\,\lambda_{jk},\\
&\textstyle\lambda_{jk}\in\{0,1\},~\widetilde{\alpha}=\sum_{k=1}^{s_{j}}\widehat{\alpha}_{jk},~\sum_{k=1}^{s_{j}}\lambda_{jk}=1.\end{split}

(26)

If (
26
) has a feasible solution, the system violates the specification
\varphi
. In addition, the optimal solution
\widetilde{\alpha}=[\alpha_{x};\alpha_{u,1};\dots;\alpha_{u,t_{\text{end}}/\Delta t}]
for (
26
) defines a falsifying trajectory

x(t_{i+1})=e^{A\Delta t}x(t_{i})+T(c_{u}+G_{u}\alpha_{u,i}),\quad\quad i=0,\dots,t_{\text{end}}/\Delta t

with initial state
x(t_{0})=c_{x}+G_{x}\alpha_{x}
.

The verification problem for linear systems against STL specifications is undecidable in general since it is not possible to compute the exact reachable set
[
28
]
. However, undecidable verification problems only occur if the reachable set is located exactly on the decision boundary between safe and unsafe, and are therefore quite rare in practice. Consequently, most verification problem are decidable, and Alg.
3
returns the correct result in finite time in these cases:

Theorem 1

If the verification problem defined by the linear system
\dot{x}=Ax+Bu
, the STL specification
\varphi
, the initial set
\mathcal{X}_{0}
, and the input set
\mathcal{U}
represents a decidable problem instance, Alg.
3
will terminate in finite time.

Proof 3

Our verification approach contains the following three sources of over-approximation errors:

1.

The error from the conservative enclosure of the reachable set.

2.

The error from the time-discretization of the STL formula during the conversion to RTL.

3.

The error through the approximation of time-varying inputs with piecewise constant inputs.

As we show in
B
, the over-approximation error from reachability analysis converges to 0 for
\Delta t\to 0
. Similarly, the error from the time-discretization during conversion to RTL becomes 0 for
\Delta t\to 0

[
11
]
, and the space of piecewise constant inputs contained inside the input set
\mathcal{U}
converges to the space of time-varying input signals contained in
\mathcal{U}
for
\Delta t\to 0
. Consequently, all errors converge to 0 for
\Delta t\to 0
, so that Alg.
3
will always be able to find a
\Delta t
small enough to either verify or falsify the specification.

If the verification problem instance is not decidable, Alg.
3
does not terminate. To accelerate the computation, we additionally implemented two improvements for our basic verification approach presented in this section:

\bullet

We already evaluate all predicates prior to the conversion to RTL and substitute predicates that are either satisfied or violated for the whole reachable set by true/false.

\bullet

We omit the conversion to conjunctive normal form performed during conversion to RTL for cases where it does not bring a benefit. In particular, this is the case if the conversion does not result in a disjunction of atomic predicates.

Finally, Alg.
3
naturally splits the domain
\widetilde{\alpha}\in[-\mathbf{1},\mathbf{1}]
corresponding to the initial set and space of input signals into safe and unsafe subsets. We can therefore directly use the resulting list of unsafe sets
\mathbf{L}
to identify initial states and input signals that are safe or to cut away all reachable states that violate the temporal logic specification.

Prediction of Traffic Participants

In addition to verifying dynamic systems against temporal logic specifications, our approach can also be used to cut away the parts of the reachable set which violate a temporal logic formula.

For set-based prediction of traffic participants, one first computes the space potentially occupied by other cars using reachability analysis, and then cuts away the regions that violate traffic rules. 8
Future Work

While we in this work focused on linear systems for simplicity, the general framework we presented can equivalently be applied for nonlinear and hybrid systems. Therefore, the extension to nonlinear and hybrid systems is our main focus for future work, and we outline some challenges as well as potential solutions in this section.

One key requirement for our automated verification framework is a reachability algorithm that preserves dependencies and converges to the exact reachable set if the algorithm parameters are tuned adequately. While dependency preserving reachability algorithms are readily available for nonlinear systems
[
25
]
, it is more complicated to preserve dependencies for hybrid systems due to the intersections with the guard sets at discrete transitions. One promising strategy to handle those discrete transitions in a dependency-preserving fashion is the guard-mapping approach
[
33
]
, since it circumvents the explicit computation of geometric intersections. Moreover, automated parameter tuning is significantly harder for nonlinear and hybrid systems compared to linear systems due to the increased number of algorithm parameters. A promising approach for automated parameter tuning for those systems has been published recently
[
34
]
, but does not yet guarantee convergence to the exact reachable set.

Another challenge arises from the fact that reachable sets for nonlinear and hybrid systems are in general non-convex, so that non-convex set representations such as polynomial zonotopes
[
35
]
or Taylor models
[
36
]
are required to compute tight enclosures. In our framework, replacing the convex zonotopes we used for linear systems with those non-convex set representations yields polynomial level sets instead of polytopes for the regions of unsafe zonotope factors. With polynomial level sets the checks for empty sets in Line
14
of Alg.
2
are computationally more expensive, and the optimization problem in (
26
) becomes a mixed-integer polynomial program, which is harder to solve. Potential solutions to address these issues are using contractor programming
[
37
, Chapter 4]
to check if a polynomial level set is empty, and applying continuous relaxation
[
38
]

to warm-start the mixed-integer polynomial program.

9
Conclusion

We presented the first fully-automated verifier for linear systems that considers the very general case of specifications defined by signal temporal logic formulas. Our algorithm avoids the conservatism of the previous reachset temporal logic approach by explicitly keeping track of which initial states and which uncertain inputs satisfy or violate single parts of the formula, and is therefore guaranteed to always find the correct solution in finite time for decidable verification problem instances. As we demonstrated with numerical experiments, our automated verifier can even solve high-dimensional benchmarks with up to 1000 states as well as complex temporal logic specifications with nested temporal operators very efficiently. Other advantageous features of our algorithm are that it returns a falsifying trajectory in case of a safety violation and that it naturally divides the initial as well as the input set into parts which satisfy or violate the specification. This is for instance beneficial for set-based prediction of traffic participants, as we demonstrated with an exemplary traffic scenario.

\displaystyle~\,=\lim_{\Delta t\to 0}\boldsymbol{\mathcal{F}}\,\mathcal{X}_{0}\oplus\boldsymbol{\mathcal{G}}\,\widetilde{u}\overset{\eqref{eq:proofC}}{=}\mathbf{0},

which concludes the proof.
