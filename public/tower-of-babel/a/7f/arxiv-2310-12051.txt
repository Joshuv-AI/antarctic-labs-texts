Simpler and Higher Lower Bounds for Shortcut Sets
Virginia Vassilevska Williams, Yinzhan Xu, Zixuan Xu

Abstract
We study the well-known shortcut set problem: how much can one decrease the diameter of a directed graph by adding a small set of shortcuts from the transitive closure of the graph. We provide a variety of lower bounds. First, we vastly simplify the recent construction of Bodwin and Hoppenworth [FOCS 2023] which showed an Ω ~ ​ ( n 1 / 4 ) \widetilde{\Omega}(n^{1/4}) lower bound for the diameter of a directed unweighted n n -node graph after adding O ⁡ ( n ) O(n) shortcut edges. We highlight that our simplification completely removes the use of the convex sets by Bárány and Larman [Math. Ann. 1998] used in all previous lower bound constructions. Our simplification also removes the need for randomness and further removes some log factors. It allows us to generalize the construction to higher dimensions, which in turn can be used to show the following results: • There is an Ω ⁡ ( n 1 / 5 ) \Omega(n^{1/5}) lower bound for the diameter of the graph after adding O ⁡ ( m ) O(m) shortcuts, where m m denotes the number of edges in the input graph. • For all ε > 0 \varepsilon>0 , there exists a δ > 0 \delta>0 such that there are n n -vertex O ⁡ ( n ) O(n) -edge graphs G G where adding any shortcut set of size O ⁡ ( n 2 − ε ) O(n^{2-\varepsilon}) keeps the diameter of G G at Ω ⁡ ( n δ ) \Omega(n^{\delta}) . This improves the sparsity of the constructed graph compared to a known similar result by Hesse [SODA 2003]. • For any integer d ≥ 2 d\geq 2 , there exists a graph G = ( V , E ) G=(V,E) on n n vertices and S ⊆ V S\subseteq V with | S | = Θ ~ ​ ( n 3 / ( d + 3 ) ) |S|=\widetilde{\Theta}(n^{3/(d+3)}) , such that when adding O ⁡ ( n ) O(n) or O ⁡ ( m ) O(m) shortcuts, the sourcewise diameter (the largest distance from some vertex in S S to some reachable vertex in the graph) is Ω ~ ​ ( | S | 1 / 3 ) \widetilde{\Omega}(|S|^{1/3}) . This initiates the study of sourcewise diameter in the setting of the shortcut set problem; previously, the study of the sourcewise variant is popular in a wide variety of related problems such as spanners and distance preservers. Complementing this lower bound result, we also provide an upper bound: we show that, we can reduce the sourcewise diameter to O ~ ​ ( | S | ) \widetilde{O}(\sqrt{|S|}) by adding O ⁡ ( n ) O(n) shortcut edges.

Technical Overview

2.1
Previous Works

Before giving an overview of our construction, we first summarize previous approaches to proving lower bounds for the shortcut set problem using
O(n)
shortcuts. Prior to the work of Bodwin and Hoppenworth
[
BH23
]
, lower bound constructions for the
O(n)
-shortcut set problem including
[
Hes03
]
and
[
HP18
]
are all based on constructing a directed graph
G
on
n
-vertices with a set of
critical paths

\Pi
such that
|\Pi|=C\cdot n
where
C
can be set as an arbitrarily large constant. The critical path set contains paths of length
\ell
that are unique paths between their endpoints, and are
pairwise edge-disjoint
. Then one would need to add at least one shortcut for each critical path in order to decrease the diameter to
o(\ell)
. Using this approach, Hesse
[
Hes03
]
obtained a lower bound of
\Omega(n^{1/17})
, and Huang and Pettie
[
HP18
]
obtained a lower bound of
\Omega(n^{1/6})
.

Recently, Bodwin and Hoppenworth
[
BH23
]
improved the lower bound to
\widetilde{\Omega}(n^{1/4})
by relaxing the property where paths in
\Pi
are pairwise edge-disjoint to allow pairs of paths to overlap on
polynomially many
edges.
In order to better illustrate our improvements, we give more details of their construction. The construction falls under the same geometric construction framework used in earlier works (e.g.
[
Hes03
,
CE06
,
LVWX22
,
BH22
]
) for constructing lower bounds for shortcut sets and related problems. In this framework, every vertex of the graph corresponds to a lattice point in
\mathbb{Z}^{d}
and every edge corresponds to a
d

convex set

B_{d}(r)
of vectors of length
O(r)

centered at the origin. It is known from
[
BL98
]

|B_{d}(r)|=\Theta\left(r^{d\cdot\frac{d-1}{d+1}}\right)
and

has the important property of being

, namely for distinct
\vec{b}_{1},\vec{b}_{2}\in B_{d}(r)

\langle\vec{b}_{1},\vec{b}_{2}\rangle<\langle\vec{b}_{1},\vec{b}_{1}\rangle

The construction in

The
O(m)
-shortcut setting.

As mentioned earliler, aside from the
O(n)
-shortcut set problem, another intensely studied setting is the
O(m)
-shortcut set problem where
m
is the number of edges in the input graph. An immediate question following from the construction in
[
BH23
]
is whether this construction can give an improvement for the
O(m)
-shortcut setting. In particular, notice that in their construction, the graph has constant, and hence
m=\Theta(n)
, so one may think that in this case a shortcut set of size
O(n)
is also a shortcut set of size
O(m)
, and thus their construction should directly imply an
\Omega(n^{1/4})
lower bound in the
O(m)
-shortcut setting. However, this is not the case.

First we highlight the fact that the construction in
[
HP18
]
has
|\Pi|=\Theta(n)
where the constant can be set arbitrarily large, but in
[
BH23
]
the size of
\Pi
is
c_{0}\cdot\frac{n}{\log n}
for some fixed constant
c_{0}
that cannot be set arbitrarily large. This means that the construction in
[
BH23
]
given above would only give a lower bound for shortcut sets of size
\leq c_{0}\cdot\frac{n}{\log n}
, so in order to extend the lower bound to shortcut sets of size
C\cdot n
for arbitrarily large
C
, Bodwin and Hoppenworth
[
BH23
]
use the so-called path subsampling argument: they
consider a smaller graph
G^{\prime}
obtained from
G
by restricting to a random subset of vertices
V^{\prime}\subseteq V
and “merging” paths between these vertices with short lengths. Namely, they added the edges between all
u,v\in V^{\prime}
such that the distance between
u,v
is at most
O(\log n)
. Thus
G^{\prime}
has fewer vertices compared to
G
while having roughly the same diameter up to
\log n
factors. A shortcut
H
on
G^{\prime}
can also be viewed as a shortcut on
G
as
V(G^{\prime})
is a subset of
V(G)
. Furthermore,
n^{\prime}:=|V(G^{\prime})|<n
, so when
|H|=c_{0}\cdot\frac{n}{\log n}
for some,
|H|
can be
C\cdot n^{\prime}
for arbitrarily large
C
, if
n^{\prime}
(which can be adjusted by the parameters in the subsampling argument) is small enough.

Due to the nature of the operation described above, only the number of vertices in the graph is decreased, and the number of edges does not necessarily decrease. This is the underlying barrier in obtaining lower bounds for
O(m)
-shortcut sets using the technique in
[
BH23
]
.

Generalization to higher dimensions

A natural follow-up question on the construction given in
[
BH23
]
is whether it can be generalized to higher dimensions and give better bounds. Previous constructions in
[
HP18
,
LVWX22
]
can both be easily generalized to higher dimensions and one can optimize the dimension to obtain the best bounds. However, it is unclear how the construction in
[
BH23
]
can be generalized to higher dimensions for the following reason: the set of edge vectors
W
is taken to be the set of differences between adjacent vectors in
B
ordered counterclockwise. Although it is easy to define the notion of “adjacent vectors” in
2
dimensions, it is unclear how to define an analogous notion in, say,
3
dimensions.

2.2
Our Construction

The key observation that led to our construction is the following: notice that in the construction of the critical paths in
[
BH23
]
, each path has two choices at each layer, which is to take the edge corresponding to the zero vector
(0,0)
or to take the edge corresponding to the nonzero vector
\vec{w}_{\lambda_{i}}
. Thus, a critical path in fact corresponds to a subset of the set of edge vectors
W
, and the difference between the end point and start point of the path corresponds to sum of the vectors in this subset. The use of the convex set
B
in the construction of the set of edge vectors
W
ensures that critical paths are well-defined in the sense that it has a well-defined choice between the two vectors in
E_{i}=\{\vec{w}_{\lambda_{i}},(0,0)\}
and that the sum of vectors taken in a critical path is the sum of a subset of
W
whose sum is unique among all subsets, since the subset uniquely maximizes the inner product with the corresponding directional vector. Intuitively, this means that we only need a set of edge vectors
W
that have lots of “unique subset sums”.

There is in fact a very simple set that satisfies the above described property, which is the set
W:=\{1\}\times[r]=\{(1,s)\mid 1\leq s\leq r\}
for some integer
r
.
Between layer
i
and layer
i+1
, we put the set of edge vectors as
E_{i}=\{\vec{w},(0,0)\}
for some
\vec{w}\in W
and each vector
\vec{w}\in W
is assigned to a unique
E_{i}
, so we have
\ell=r+1
. Then we define the critical paths as the paths that take the nonzero edge vectors of the form
\{1\}\times[t]
for
t\in[r]
starting in some starting region in the first layer. Notice that given a starting vertex
(0,x_{1},x_{2})
, a critical path taking the vectors
\{1\}\times[t]
will end at the vertex
(r,x_{1}+t,x_{2}+\sum_{j=1}^{t}j)
. It is easy to see that the start vertex and end vertex uniquely determine a path since the second coordinate indicates the number
t
of nonzero vectors taken and the third coordinate indicates that the sum of these
t
distinct numbers is
\sum_{j=1}^{t}j
. The unique subset of
[r]
satisfying these conditions is
[t]
. This construction completely removes the use of the result from
[
BL98
]
that bounds the number of vertices of the convex hull over the integer points contained in a
d
-dimensional ball of radius
r>0
. In addition, we eliminates the use of randomness in
[
BH23
]
and the new construction is easier to analyze.
We further remark that our simplified construction also provides a logarithmic improvement for the lower bound of
O(n)
-shortcut set over
[
BH23
]
.

In addition, this construction can be easily generalized to higher dimensions. For instance, when each grid is
3
-dimensional, we take the set of edge vectors as
W:=\{1\}\times\{0\}\times[r]\cup\{0\}\times\{1\}\times[r]
and let the critical paths correspond to subsets of the form
\{1\}\times\{0\}\times[s]\cup\{0\}\times\{1\}\times[s^{\prime}]
for
s,s^{\prime}\in[r]
. It is not hard to see that given the coordinates of the start vertex and the end vertex of a critical path, there is a unique path between the endpoints. Using such generalizations, we are able to obtain improvements in other settings such as the
O(m)
-shortcut set setting.

We will discuss our constructions in more detail in

Critical paths

.

For any
(x_{1},x_{2})\in\llbracket r\rrbracket\times\llbracket r^{2}\rrbracket
and for any

Properties of

.

By definition of our construction, the graph
G=(V,E)
with the critical path set

has

\displaystyle|V|

\displaystyle=\ell\times(2r)(2r^{2})=4r^{3}(r+1),

\displaystyle|E|

\displaystyle\leq 2(\ell-1)(2r)(2r^{2})=8r^{4},

\displaystyle|P|

\displaystyle=r\cdot r^{2}\cdot|D|=r^{4}.

Next we show that all critical paths are unique paths between their endpoints and they have relatively small pairwise overlaps.

Lemma 4.1

For every critical path
\pi\in P
,
\pi
is the unique path between its endpoints in
G
.

Proof.

Let
v=(1,x_{1},x_{2})
be the start vertex of
\pi
and suppose the subset of nonzero edge vectors used by
\pi
is exactly the set
\{1\}\times\llbracket s\rrbracket
where
s\in[r]
. Then we can compute the endpoint of
\pi
as
u:=(r+1,y_{1},y_{2})
where
y_{1}=x_{1}+s,y_{2}=x_{2}+\sum_{i=0}^{s-1}=x_{2}+s(s-1)/2
.

Suppose for contradiction that there exists another path
\pi^{\prime}\neq\pi
from
v
to
u
in
G
. Let
S
denote the set of nonzero edge vectors in
\pi^{\prime}
, then we know that since
\pi^{\prime}\neq\pi
and each adjacent layer corresponds to a unique nonzero edge vector, we must have
S\neq\{1\}\times\llbracket s\rrbracket
. Since all the nonzero edge vectors have the first coordinate equal to
1
and we know the endpoints of
\pi^{\prime}
correspond to the grid point
(x_{1},x_{2})
and
(x_{1}+s,x_{2}+s(s-1)/2)
, we know that
\pi^{\prime}
must take exactly
s
nonzero edge vectors. Thus we must have
|S|=s
. Then since the second coordinates of all the edge vectors are exactly the set
\llbracket r\rrbracket
, in order for
\pi^{\prime}
to reach
u
, the sum of the second coordinates of the
s
vectors in
S
must be
s(s-1)/2
. It is easy to see that the only solution is to take the values
0,\dots,s-1
for the second coordinates of the vectors in
S
and therefore
S=\{1\}\times\llbracket s\rrbracket
. This gives a contradiction to the assumption that
\pi^{\prime}\neq\pi
.
∎

Lemma 4.2

For any two critical paths
\pi_{1},\pi_{2}\in P
corresponding to the same subset of nonzero edge vectors
\{1\}\times\llbracket s\rrbracket
(and thus having distinct starting vertices), we have that
\pi_{1}
and
\pi_{2}
are vertex-disjoint.

Proof.

As
\pi_{1},\pi_{2}
have different start point, and at each layer, they will pick the same edge vector, they will stay different at each layer.
∎

Lemma 4.3

Given any path
\sigma:u\leadsto w
of length
g
in
G
from layer

to layer

where
a,b\in\llbracket\ell\rrbracket
and
b-a=g
, there are at most
8r/g

\sigma
.

Proof.

Let
k
be the smallest integer such that
g\geq 2\cdot\frac{r}{2^{k}}
, so that
\{a,\ldots,b-1\}
contains an interval
\{i\cdot\frac{r}{2^{k}},i\cdot\frac{r}{2^{k}}+1,\ldots,i\cdot\frac{r}{2^{k}}+\frac{r}{2^{k}}-1\}
for some
i\in\llbracket 2^{k}\rrbracket
. Note that by definition of the permutation
q

\{q_{i\cdot\frac{r}{2^{k}}},\ldots,q_{i\cdot\frac{r}{2^{k}}+\frac{r}{2^{k}}-1}\}=\{i^{\prime},i^{\prime}+2^{k},\ldots,i^{\prime}+r-2^{k}\},

where the
k

i^{\prime}
is the
k
-bit binary representation of
i

Consider the set of nonzero edge vectors
S=\bigcup_{i=a}^{b-1}E_{i}\setminus\{(0,0)\}
. By the above discussion,
S
must contain edge vectors
\{(1,i^{\prime}+t\cdot 2^{k})\mid t\in\llbracket r/2^{k}\rrbracket\}
.

Suppose the path
\sigma
is used by a critical path
\pi
with initial point
(0,x_{1},x_{2})
and with the set of edge vectors
\{1\}\times\llbracket s\rrbracket
. Now we want to bound the number of critical paths
\pi^{\prime}\in P
that can potentially contain
\sigma
as a subpath. By
Lemma

4.2
, it suffices to count the number of
s^{\prime}\in\llbracket r\rrbracket
such that some critical path
\pi^{\prime}
passing through the vertex
u
in layer

associated with the set of nonzero edge vectors
\{1\}\times\llbracket s^{\prime}\rrbracket
can contain
\sigma
as a subpath.

We show that
\pi^{\prime}
cannot contain
\sigma
as a subpath if
|s^{\prime}-s|>2^{k}
. Notice that if
|s^{\prime}-s|>2^{k}
, then
S
must contain an edge vector

that is in the symmetric difference of
\{1\}\times\llbracket s\rrbracket
and
\{1\}\times\llbracket s^{\prime}\rrbracket
since
S
contains the set
\{(1,i^{\prime}+t\cdot 2^{k})\mid t\in\llbracket r/2^{k}\rrbracket\}
. This means that from layer

to layer

and
\pi^{\prime}

\pi
and
\pi^{\prime}
must have taken different paths from layer

It follows that the number of critical paths containing
\sigma
as a subpath is at most the number of

such that

. By definition of

. So

and thus the number of critical paths containing

∎

We summarize the properties of the graph constructed above as follows.

Proposition 4.4

There exists a constant
c_{0}>0
, so that there exists infinitely many
n
-vertex directed unweighted graphs
G=(V,E)
and path sets
P
of size
|P|=c_{0}n
with the following properties:

1.

G
has
\ell=\Theta(n^{1/4})
layers.

2.

Each path in
P
starts in layer
0
and ends in layer
\ell-1
.

3.

Each path in
P
is the unique path between its endpoints in
G
.

4.

For any path
\sigma
of length
g
, there are at most
8\ell/g
paths in
P
that contain
\sigma
as a subpath.

4.2
Application:
O(n)
-Shortcut Lower Bound

From
4.4
, we can prove the following lower bound.

Proposition 4.5

There exists an absolute constant
c_{1}>0
and infinitely many
n
-vertex directed unweighted graph
G=(V,E)
such that for shortcut set
H
of size
|H|\leq c_{1}n
, the graph
G\cup H
must have diameter
\Omega(n^{1/4})
.

Proof.

Take a graph
G=(V,E)
from
4.4
with path set
P
of size
|P|=10c_{1}n
for a suitable constant
c_{1}
. Let
H
be a shortcut set of size
|H|\leq c_{1}n
on
G
.

We define the following potential function over shortcut sets
H
as

\phi(H)=\sum_{\pi\in P}\text{dist}_{G\cup H}(s_{\pi},t_{\pi}),

i.e.,
\phi(H)
is the sum over the distances between pairs of endpoints of the critical paths after adding the shortcut set
H
. Then by
4.4
we have

\phi(\varnothing)=\sum_{\pi\in P}\text{dist}_{G}(s_{\pi},t_{\pi})=10c_{1}n\cdot(\ell-1).

Now for any path
\sigma:u\leadsto v
of length
g
in
G
, adding the shortcut
(u,v)
only affects the critical paths
\pi
that contains
\sigma
as a subpath by
Lemma

4.1
.
For any shortcut set
H^{\prime}
and not including the shortcut
(u,v)
, let
\text{dist}_{1}(\cdot,\cdot)
denote the distance function
\text{dist}_{G\cup H^{\prime}}(\cdot,\cdot)
and
\text{dist}_{2}
denote the distance function
\text{dist}_{G\cup H^{\prime}\cup\{(u,v)\}}
for simplicity. Then we have

\displaystyle\text{dist}_{1}(s_{\pi},t_{\pi})-\text{dist}_{2}(s_{\pi},t_{\pi})

\displaystyle\leq

\displaystyle\text{dist}_{1}(s_{\pi},t_{\pi})-\min\left\{\text{dist}_{1}(s_{\pi},t_{\pi}),\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,v)+\text{dist}_{2}(v,t_{\pi})\right\}

\displaystyle\leq

\displaystyle\max\left\{0,\text{dist}_{1}(s_{\pi},t_{\pi})-\left(\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,v)+\text{dist}_{2}(v,t_{\pi})\right)\right\}

\displaystyle\leq

\displaystyle\max\left\{0,\left(\text{dist}_{1}(s_{\pi},u)+\text{dist}_{1}(u,v)+\text{dist}_{1}(v,t_{\pi})\right)-\left(\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,v)+\text{dist}_{2}(v,t_{\pi})\right)\right\}

\displaystyle\leq

\displaystyle\text{dist}_{1}(u,v)-\text{dist}_{2}(u,v)

\displaystyle\leq

\displaystyle g-1\leq g.

By
Item

4
in
4.4
, adding the edge
(u,v)
only affects the distance of
8\ell/g
pairs of
(s_{\pi},t_{\pi})
for
\pi\in P
, so we have for any shortcut set
H^{\prime}
,

\phi(H^{\prime})-\phi(H^{\prime}\cup\{(u,v)\})\leq g\cdot\frac{8\ell}{g}=8\ell.

Therefore for a shortcut set
H
of size
|H|\leq c_{1}n
, we have

\phi(H)\geq\phi(\varnothing)-8\ell c_{1}n\geq 10(\ell-1)c_{1}n-8\ell c_{1}n=(2\ell-10)c_{1}n.

Over
|P|=10c_{1}n
pairs of critical paths, the average distance is
\Theta(\ell)
, which implies that there must exists a pair with distance
\Theta(\ell)
. Then it follows that the diameter of
G\cup H
is
\Theta(\ell)=\Theta(n^{1/4})
by
Item

1
in
4.4
.
∎

5.1
Construction of

It is easy to generalize our construction to higher dimensions as follows. Let
d\geq 1
be an integer and let
G_{d}=(V_{d},E_{d})
be the graph defined as follows. Note that the dimension of the grid in each layer of the graph will be
d+1
and that the base construction corresponds to the case where
d=1

Vertex set
V_{d}

The graph has
\ell=d\cdot r+1
layers and each layer is the grid
\llbracket 2d\cdot r\rrbracket^{d}\times\llbracket 2d\cdot r^{2}\rrbracket
. We denote a vertex
v
in layer
i
as
(i,\vec{x})
where
i
specifies the layer and
\vec{x}\in\llbracket 2d\cdot r\rrbracket^{d}\times\llbracket 2d\cdot r^{2}\rrbracket
is a grid point.

Edge set
E_{d}

Consider the set of integer vectors
W\subseteq\{0,1\}^{d}\times\llbracket r\rrbracket
, where the first
d
coordinates of every vector in
W
contains exactly a single one and
d-1
zeros. Let
q
be the same permutation on
\llbracket r\rrbracket
as the one defined in
Section

4
. For each
k=1,\dots,d
and
i\in\llbracket r\rrbracket
, let
\vec{w}_{id+k-1}
be the vector
(0,\dots,0,1,0,\dots,0,q_{i})
where the
1
is on the
k
-th coordinate. Note that
\vec{w}_{0},\dots,\vec{w}_{dr-1}
is a permutation of
W
.

We only add edges between adjacent layers as follows: between layer
i
and
i+1
for
i\in\llbracket dr\rrbracket
, define the edge vector set
E_{i}=\{\vec{w}_{i},\vec{0}\}
where
\vec{0}
is the
(d+1)
-dimensional all zero vector. For every vertex
(i,\vec{x})
, we add edge connecting it to the vertex
(i+1,\vec{x}+\vec{e})
for
\vec{e}\in E_{i}
if
\vec{x}+\vec{e}\in\llbracket 2d\cdot r\rrbracket^{d}\times\llbracket 2d\cdot r^{2}\rrbracket
.

Critical Paths
P_{d}

A critical path is defined by a start vertex
(0,\vec{x})
where
\vec{x}\in\llbracket r\rrbracket^{d}\times\llbracket r^{2}\rrbracket
and a set of vectors
\bigcup_{i=1}^{d}\{0\}^{i-1}\times\{1\}\times\{0\}^{d-i}\times\llbracket s_{i}\rrbracket
for
s_{1},\dots,s_{d}\in[r]
. For any layer
i
, the critical path uses the edge corresponding to the nonzero vector
w_{i}
if
w_{i}
belongs to the set; otherwise, it uses the edge corresponding to
\vec{0}
.

Properties of
G_{d}

By definition, the graph
G_{d}=(V_{d},E_{d})
has

\displaystyle|V_{d}|

\displaystyle=(\ell-1)\times(2dr)^{d}\times(2dr^{2})=\Theta(r^{d+3}),

\displaystyle|E_{d}|

\displaystyle\leq 2|V_{d}|=\Theta(r^{d+3}),

\displaystyle|P_{d}|

\displaystyle=r^{d}\cdot r^{2}\cdot r^{d}=\Theta(r^{2d+2}).

It is not hard to check that
G_{d}
also satisfies the following properties.

Proposition 5.1

(Properties of
G_{d}
)

The graph
G_{d}=(V_{d},E_{d})
with critical path set
P_{d}
satisfies the following:

1.

For every critical path
\pi\in P_{d}
,
\pi
is the unique path between its endpoints in
G
.

2.

For any two critical paths
\pi_{1},\pi_{2}\in P_{d}
associated with the same
s_{1},\ldots,s_{d}
(and thus have distinct starting vertices), we have that
\pi_{1}
and
\pi_{2}
are vertex-disjoint.

3.

Given any path
\sigma:u\leadsto v
of length
g
in
G_{d}
from layer
a
to layer
b
where
a,b\in\llbracket\ell\rrbracket
and
b-a=g
, there are at most
O((r/g)^{d})
critical paths containing
\sigma
.

Proof.

1.

Suppose the start vertex for
\pi
is
u=(0,x_{1},\ldots,x_{d},y)
, and
s_{1},\ldots,s_{d}
are the associated values for
\pi
. Then the end point
v
of
\pi
can be computed as

\left(\ell-1,x_{1}+s_{1},x_{2}+s_{2},\ldots,x_{d}+s_{d},y+\sum_{i=1}^{d}\frac{s_{i}(s_{i}-1)}{2}\right).

Thus, for any path travelling from
u
to
v
, it must use
s_{i}
nonzero vectors from
\{0\}^{i-1}\times\{1\}\times\{0\}^{d-i-1}\times\llbracket r\rrbracket
for every
i\in[d]
. Furthermore, the sum of the last coordinate of these vectors must equal
\sum_{i=1}^{d}\frac{s_{i}(s_{i}-1)}{2}
. As a result, for each
i
, it must use
\{0\}^{i-1}\times\{1\}\times\{0\}^{d-i-1}\times\llbracket s_{i}\rrbracket
, because any other choices of vectors would make the sum of the last coordinate larger than desired. Hence, there is a unique path from
u
to
v
.

2.

As
\pi_{1},\pi_{2}
have different start vertices, and at each layer, they will pick the same direction vector because they share the same
s_{1},\ldots,s_{d}
, so they will stay different at each layer.

3.

Suppose the path
\sigma
is used by a critical path
\pi
with initial point
(0,\vec{x})
and with associated values
s_{1},\ldots,s_{d}
. Now we want to bound the number of critical paths
\pi^{\prime}\in P
that can potentially contain
\sigma
as a subpath. By
Item

2
, it suffices to count the number of
s_{1}^{\prime},\ldots,s_{d}^{\prime}\in\llbracket r\rrbracket
such that some critical path
\pi^{\prime}
passing through the vertex
u
in layer
a
associated with
s_{1}^{\prime},\ldots,s_{d}^{\prime}
can contain
\sigma
as a subpath.

For every
k\in[d]
,
E_{a}\setminus\{\vec{0}\},E_{a+1}\setminus\{\vec{0}\},\ldots,E_{b-1}\setminus\{\vec{0}\}
contain
\left\{\{0\}^{k-1}\times\{1\}\times\{0\}^{d-k}\times\{q_{i}\}\mid\alpha\leq i<\beta\right\}
for some
\alpha,\beta
where
\beta-\alpha=\Theta(g/d)=\Theta(g)
. By the same proof as
Lemma

4.3
, if
|s_{k}^{\prime}-s_{k}|>\Omega(r/g)
, then
\pi^{\prime}
cannot contain
\sigma
as a subpath. As this holds for every
k\in[d]
, we get that the number of
\pi^{\prime}
that can contain
\sigma
as a subpath is
O((r/g)^{d})
.

∎

5.2
Application I:
O(m)
-Shortcut Lower Bound

For our
O(m)
-shortcut lower bound, we will use
d=2
in the graphs constructed above. Let us summarize the properties.

Corollary 5.2

For infinitely many
n
, there exists an
n
-vertex directed unweighted graphs
G=(V,E)
and path sets
P
, where
|E|\leq 2n
and
|P|=\Theta(n^{6/5})
, and with the following properties:

1.

G
has
\ell=\Theta(n^{1/5})
layers.

2.

Each path in
P
starts in layer
0
and ends in layer
\ell-1
.

3.

Each path in
P
is the unique path between its endpoints in
G
.

4.

For any path
\sigma
of length
g
, there are at most
O((\ell/g)^{2})
paths in
P
that contain
\sigma
.

From
5.2
, we can prove the following lower bound.

See
1.3

Proof.

Take any graph
G=(V,E)
with the associated critical paths
P
from
5.2
.

Let
c
be a parameter to be chosen later. Let
E^{\prime}
a set of edges that contains
(u,v)
to
E^{\prime}
if
\text{dist}_{G}(u,v)\leq c
.

Let
\Phi(H)
be a potential function defined as

\Phi(H)=\sum_{\pi\in P}\text{dist}_{G\cup E^{\prime}\cup H}(s_{\pi},t_{\pi}).

Initially,

\Phi(\emptyset)=|P|\cdot\frac{\ell}{c}=\Theta\left(\frac{n^{7/5}}{c}\right).

Now, suppose we have a shortcut set
H^{\prime}
, and we add an edge
(u,v)
to
H^{\prime}
, where
u
and
v
are
g
layers apart and
u
can reach
v
in
G
. For any
\pi\in P
, if
\pi
does not have a subpath from
u
to
v
, then adding
(u,v)
will not affect the distance from
s_{\pi}
to
t_{\pi}
, by
Item

3
in
5.2
.

If any critical path
\pi
contains a subpath from
u
to
v
, then there exists a unique path
\sigma
from
u
to
v
in
G
, because otherwise, the critical path
\pi
will not be the unique path from
s_{\pi}
to
t_{\pi}
. By
Item

4
in
5.2
, the number of critical paths that contain
\sigma
is
O((\ell/g)^{2})
, which implies that the number of critical paths that contain a subpath from
u
to
v
is
O((\ell/g)^{2})
.

Therefore, adding the edge
(u,v)
will only affect the distance of
O((\ell/g)^{2})
pairs of
(s_{\pi},t_{\pi})
for
\pi\in P
. For each such
\pi
(for simplicity, we use
\text{dist}_{1}
to denote
\text{dist}_{G\cup E^{\prime}\cup H^{\prime}}
and
\text{dist}_{2}
to denote
\text{dist}_{G\cup E^{\prime}\cup H^{\prime}\cup\{(u,v)\}}
in the following),

\displaystyle\text{dist}_{1}(s_{\pi},t_{\pi})-\text{dist}_{2}(s_{\pi},t_{\pi})

\displaystyle\leq

\displaystyle\text{dist}_{1}(s_{\pi},t_{\pi})-\min\left\{\text{dist}_{1}(s_{\pi},t_{\pi}),\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,w)+\text{dist}_{2}(w,t_{\pi})\right\}

\displaystyle\leq

\displaystyle\max\left\{0,\text{dist}_{1}(s_{\pi},t_{\pi})-\left(\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,w)+\text{dist}_{2}(w,t_{\pi})\right)\right\}

\displaystyle\leq

\displaystyle\max\left\{0,\left(\text{dist}_{1}(s_{\pi},u)+\text{dist}_{1}(u,w)+\text{dist}_{1}(w,t_{\pi})\right)-\left(\text{dist}_{2}(s_{\pi},u)+\text{dist}_{2}(u,w)+\text{dist}_{2}(w,t_{\pi})\right)\right\}

\displaystyle\leq

\displaystyle\text{dist}_{1}(u,w)-\text{dist}_{2}(u,w)

\displaystyle\leq

\displaystyle\lceil g/c\rceil-1.

Therefore, if
g\leq c
,
\Phi(H^{\prime})-\Phi(H^{\prime}\cup\{(u,w)\})=0
; if
g>c
,
\Phi(H^{\prime})-\Phi(H^{\prime}\cup\{(u,w)\})\leq O((\ell/g)^{2})\cdot(\lceil g/c\rceil-1)=O(\frac{\ell^{2}}{gc})=O(\frac{\ell^{2}}{c^{2}})
.

Thus, as
H
contains at most
Cm\leq 2Cn
edges,

\Phi(H)\geq\Phi(\emptyset)-2Cn\cdot O\left(\frac{\ell^{2}}{c^{2}}\right)=\Theta\left(\frac{n^{7/5}}{c}\right)-O\left(\frac{Cn^{7/5}}{c^{2}}\right).

Note that the constant factors hidden in
\Theta
and
O
above are independent of
C
and
c
. Therefore, by setting
c
big enough, we can ensure that
\Phi(H)\geq\Theta\left(\frac{n^{7/5}}{c}\right)
. By averaging, this implies that there exists
\pi\in P
where

\text{dist}_{G\cup E^{\prime}\cup H}(s_{\pi},t_{\pi})\geq\Omega\left(\frac{n^{1/5}}{c}\right).

Also, as
\text{dist}_{G\cup H}(s_{\pi},t_{\pi})\geq\text{dist}_{G\cup E^{\prime}\cup H}(s_{\pi},t_{\pi})
, we get that the diameter of
G\cup H
is
\Omega\left(\frac{n^{1/5}}{c}\right)
. The theorem follows as
c
is a constant only depending on
C
.
∎

5.3
Application II: Near-Quadratic-Shortcut Lower Bound

Using the construction of
G_{d}
(recall
|V_{d}|=\Theta(r^{d+3})
,
|P_{d}|=\Theta(r^{2d+2})
and other properties in
5.1
), we can show the following
Theorem

5.3
that recovers
[
Hes03
, Theorem 4.1]
. One small improvement is that the average degree of our construction is a constant, while the average degree of Hesse’s construction depends on
\varepsilon
.

Theorem 5.3

For all
\varepsilon>0
, there exists some
\delta>0
such that there exist infinitely many
n
-vertex
O(n)
-edge graphs
G
where adding any shortcut set of size
O(n^{2-\varepsilon})
keeps the diameter of
G
at
\Omega(n^{\delta})
.

Proof.

Let
d
be a large enough integer so that
(1-\varepsilon)\cdot\frac{d+3}{d-1}<1-\varepsilon/2
. Similar to the proof of
Theorem

1.3
, we let
E^{\prime}
be a set of edges that contain
(u,v)
if
\text{dist}_{G_{d}}(u,v)\leq c
, for some parameter
c
.

Let
H
be the shortcut set, and let
\Phi(H)
be a potential function defined as

\Phi(H)=\sum_{\pi\in P_{d}}\text{dist}_{G\cup E^{\prime}\cup H}(s_{\pi},t_{\pi}).

Initially,

\Phi(\emptyset)=|P_{d}|\cdot\frac{\ell}{c}=\Theta\left(\frac{r^{2d+3}}{c}\right).

If we add an edge between two vertices that are
g\geq c
layers apart, the potential function is dropped by at most

O\left((r/g)^{d}\cdot\frac{g}{c}\right)=O\left(\frac{r^{d}}{g^{d-1}c}\right)\leq O\left(\frac{r^{d}}{c^{d}}\right).

Thus, if we add
O(r^{d+3}\cdot c^{d-1})
edges, the potential is still
\Omega\left(\frac{r^{2d+3}}{c}\right)
, so the diameter of the graph is still
\Omega(r/c)
. By setting
c=r^{(1-\varepsilon)\cdot\frac{d+3}{d-1}}
, we conclude that after adding

O(r^{d+3}\cdot c^{d-1})=O(r^{d+3}\cdot r^{(1-\varepsilon)\cdot(d+3)})=O(n^{2-\varepsilon})

edges, the diameter is still

\Omega\left(\frac{r}{c}\right)=\Omega\left(\frac{r}{r^{(1-\varepsilon)\cdot\frac{d+3}{d-1}}}\right)=\Omega(r^{\varepsilon/2})=\Omega(n^{\varepsilon/(2(d+3))}).

∎

6
Sourcewise
O(n)
-Shortcut Set

Recall that in the sourcewise
O(n)
-shortcut set problem, we need to add
O(n)
shortcut edges to a directed unweighted graph, so that
\max_{(s,v)\in S\times V,\text{dist}(s,v)<\infty}\text{dist}(s,v)
is minimized. Similar to the
O(n)
-shortcut set problem, we are interested in how small the quantity could be. We provide both an upper and a lower bound for this problem. The upper bound adapts the techniques of Kogan and Parter
[
KP22b
]
, and the lower bound uses our higher dimensional construction in
Section

5
.

6.1
Lower Bound

Theorem 6.1

For any integer
d\geq 2
, there exists a graph
G=(V,E)
on
n
vertices and
S\subseteq V
with
|S|=\widetilde{\Theta}(n^{3/(d+3)})
, such that when adding
O(n)
(or
O(m)
) shortcuts, the sourcewise diameter is
\Omega(n^{1/(d+3)})
.

Proof.

In
G_{d}
, we independently put each vertex in the first layer in
S
with probability
q=\frac{\log^{2}n}{r^{d-1}}
. Recall that the number of vertices in each layer of
G_{d}
is
\Theta(r^{d+2})
,
so with high probability,
|S|=\Theta(r^{d+2}\cdot q)=\Theta(r^{3}\cdot\log^{2}n)=\Theta(n^{3/(d+3)}\cdot\log^{2}n)
.

Similar to the proof of
Theorem

1.3
, let
c
be a parameter to be chosen later. Let
E^{\prime}
be a set of edges that contains
(u,v)
if
\text{dist}_{G}(u,v)\leq c
. Additionally, we add
(u,v)
to
E^{\prime}
if
u
can reach
v
and
v
is in the first
\ell/2
layers.

Let the potential function
\Phi(H)
for a set of shortcut edges
H
be defined as

\Phi(H)=\sum_{\pi\in P_{d},s_{\pi}\in S}\text{dist}_{G_{d}\cup E^{\prime}\cup H}(s_{\pi},t_{\pi}),

where we recall that
P_{d}
is the set of critical paths in
G_{d}
. Because of the way we randomly pick
S
, the number of critical paths
\pi
with
s_{\pi}\in S
is
\Theta(|P_{d}|\cdot q)=\Theta(r^{d+3}\cdot\log^{2}n)
(recall
|P_{d}|=\Theta(r^{2d+2})
). Therefore, initially,
\Phi(\emptyset)=\Theta(r^{d+4}\cdot\log^{2}n/c)
.

Now consider adding an edge
(u,v)
to
H
where
u
can reach
v
in
G
. Since if
\text{dist}_{G_{d}}(u,v)\leq c
, or if
v
is in the first
\ell/2
layers, adding it will not change the value of the potential function, we assume that
\text{dist}_{G_{d}}(u,v)=g>c
and
v
is in the second half of layers. First, by
5.1
, the number of critical paths in
P
using the subpath from
u
to
v
is at most
O((r/g)^{d})
. Furthermore, for each vertex
s
in the first layer, the number of critical paths starting from
s
and at the same time using the subpath from
u
to
v
must be using the
s\leadsto v
subpath in
G_{d}
. As a result, for each fixed
s
, there are
O((r/\text{dist}_{G_{d}}(s,v))^{d})=O(1)
critical paths starting from
s
and using the subpath from
u
to
v
. Then by the random sampling of
S
, with high probability, the number of critical paths
\pi
in
P
using the subpath from
u
to
v
with
s_{\pi}\in S
is

O(\max\{\log n,(r/g)^{d}\cdot q\}).

This implies that, with high probability, the drop of potential caused by adding
(u,v)
is

O(\max\{g/c\cdot\log n,g/c\cdot(r/g)^{d}\cdot q\}).

Because
c\leq g\leq r
, the above can be bounded by

O\left(\max\left\{r\log n/c,\frac{r\log^{2}n}{c^{d}}\right\}\right).

If we add
O(n)
edges to
H
, then the total potential drop can be bounded by

O\left(\max\left\{r^{d+4}\log n/c,\frac{r^{d+4}\log^{2}n}{c^{d}}\right\}\right).

By taking large enough
n
and setting
c
as a large enough constant, we can make it so that the above is less than
\Phi(\emptyset)/2
. Therefore,
\Phi(H)=\Theta(r^{d+4}\log^{2}n/c)
for
H=O(n)
. By averaging, some critical path
\pi
with
s_{\pi}\in S
will have length
\Omega(r/c)
.

The same proof works for the
O(m)
-shortcut case because
G_{d}
has
m=\Theta(n)
.
∎

6.2
Upper Bound

We can assume without loss of generality that the input graph
G
is a directed acyclic graph (DAG) by the following trick used in prior works (e.g., see
[
Ras10
]
):
for each strongly connected component, we add a star connecting every vertex from and to the same vertex, which would reduce the diameter of each strongly connected component to
\leq 2
using only
O(n)
shortcuts in total. Then we only need to keep one representative vertex in each strongly connected component, and the resulting graph would become a DAG.

Lemma 6.2

Given a graph
G=(V,E)
and a subset
S\subseteq V
, one can reduce the sourcewise diameter to
\widetilde{O}(\sqrt{|S|})
using
O(n)
shortcuts.

Proof Sketch.

The proof of this lemma is analogous to the shortcut set construction in
[
KP22b
]
, so we only provide a proof sketch.

Let
D=\sqrt{|S|}
be our desired diameter.
First, given a DAG
G
, let
G^{*}
be its transitive closure. It is known that (e.g., see
[
GIL+21
]
) for every
\ell
, we can decompose the vertices of any DAG to
\ell
chains (a chain is a path), and
2n/\ell
antichains (an antichain is a set of vertices that do not have edges between each other). Thus, we can decompose
G^{*}
into
\ell:=\frac{16n}{D}
chains
\mathcal{P}=\{P_{1},\ldots,P_{\ell}\}
and
2n/\ell
antichains. Then for each
P_{i}
, we use known method
[
Ras10
]
that decreases the diameter of it to
\leq 2
by adding
O(|P_{i}|\log|P_{i}|)
shortcut edges. Next, let
\mathcal{P}^{\prime}
be a set of chains, and we add
P_{i}
to
\mathcal{P}^{\prime}
for every
i\in[\ell]
with probability
\Theta(\log n/D)
. Finally, for every
s\in S
and every
P_{i}\in\mathcal{P}^{\prime}
, we add an edge
(s,u)
to the shortcut set where
u
is the first vertex on
P_{i}
that is reachable from
s
(this step is different from
[
KP22b
]
, since here we add edges from vertices in
S
, while in
[
KP22b
]
, they add edges from a random subset of vertices).

It is not difficult to see that, with high probability, the number of shortcut edges added is
\widetilde{O}(n+\frac{n}{D^{2}}\cdot|S|)=\widetilde{O}(n)
. The correctness follows by the analysis in
[
KP22b
]
.

To decrease the number of shortcut edges added to
O(n)
, we perform the following two modifications:

•

When we add
O(|P_{i}|\log|P_{i}|)
shortcut edges to
P_{i}
to make its diameter
\leq 2
, we instead only add
O(|P_{i}|)
edges to make its diameter
\leq\widetilde{O}(1)
. This can be done by applying the same method to the chain formed by
\frac{|P_{i}|}{\log|P_{i}|}
evenly spaced-out vertices on the original chain
P_{i}
.

•

Slightly increase
D
to
\widetilde{O}(\sqrt{|S|})
so that the
\widetilde{O}(\frac{n}{D^{2}}\cdot|S|)
part of the edge bound becomes
O(n)
.

∎
