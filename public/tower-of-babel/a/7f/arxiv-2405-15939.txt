Diversifying Human Pose in Synthetic Data for Aerial-view Human Detection
Yi-Ting Shen Hyungtae Lee Heesung Kwon Shuvra S. Bhattacharyya

Abstract
We present a framework for diversifying human poses in a synthetic dataset for aerial-view human detection. Our method firstly constructs a set of novel poses using a pose generator and then alters images in the existing synthetic dataset to assume the novel poses while maintaining the original style using an image translator. Since images corresponding to the novel poses are not available in training, the image translator is trained to be applicable only when the input and target poses are similar, thus training does not require the novel poses and their corresponding images. Next, we select a sequence of target novel poses from the novel pose set, using Dijkstra’s algorithm to ensure that poses closer to each other are located adjacently in the sequence. Finally, we repeatedly apply the image translator to each target pose in sequence to produce a group of novel pose images representing a variety of different limited body movements from the source pose. Experiments demonstrate that, regardless of how the synthetic data is used for training or the data size, leveraging the pose-diversified synthetic dataset in training generally presents remarkably better accuracy than using the original synthetic dataset on three aerial-view human detection benchmarks (VisDrone, Okutama-Action, and ICG) in the few-shot regime.

Introduction

Despite the recent explosive use of flying devices, aerial-view detection has not made much progress compared to general detection that has been successful in computer vision, such as R-CNNs
[

,
26
]
, DETRs

One solution to dealing with the data scarcity issue in aerial-view human detection is to use synthetic data generated by controlling the factors closely associated with large variations in human appearances. For example, several attempts have been made to synthesize images of human postures by employing multiple virtual characters with various outfits or external physical characteristics
[
5
,
60
]
, or by capturing humans from various aerial views at densely sampled viewing angles and ranges
[
25
,

. Particularly, human poses, one of the main factors linked to distinctive human appearances, are highly diverse and only partially defined, making them exceptionally difficult to control when constructing a synthetic dataset.

In this paper, we aim to diversify an existing synthetic dataset instead of simply synthesizing more images from scratch. Specifically, we want to transform images in an existing synthetic dataset so that the characters assume poses that do not appear in the original set (‘novel poses’), while maintaining the original style. To make our goal feasible, we need to find appropriate solutions to the following two main questions: i)
how to find a variety of novel yet realistic poses
, and ii)
how to generate human images assuming novel poses
.

To address the first question, we introduce a pose generator based on the diffusion model, an emerging generative model that exhibits remarkable performance
[
52
]
. The pose generator is designed to provide a variety of realistic human poses in the form of 3D keypoint locations. Using the pose generator, we construct a large set of diverse novel poses (‘novel pose set’) while ensuring a certain level of diversity by not allowing highly similar poses in the set.

To address the second question, we use a
source-to-target
image translator to create human images such that virtual characters assume various poses in the novel pose set. Ideally, training the image translator requires pairs of source and target images along with their corresponding poses. However, target images corresponding to poses in the novel pose set are not available in our scenario. To deal with this issue, our strategy is to first train the image translator on image pairs from an existing synthetic dataset with diverse viewpoints and fairly limited types of similar poses. The image translator is then applied in a cascaded manner, transforming input poses only to similar yet distinctive target poses. Specifically, we apply the image translation to sequences of target poses (‘target pose sequences’) that demonstrate a variety of limited body movements, gradually transforming an input pose into a final target pose.

Our strategy requires any two adjacent poses in a target pose sequence to be as close to each other as possible. To ensure this property, we first randomly select a few final target poses from the novel pose set for each pose in the original synthetic dataset that serves as the starting pose of each target pose sequence. Then, finding a target pose sequence can be viewed as a problem of finding the optimal path from a starting pose to a final target pose in a graph built on the novel pose set. We use Dijkstra’s algorithm
[
13
]
to solve this optimal path search problem. Then, for each target pose in a target pose sequence, a corresponding target image is generated by the image translator using the previous target image as the source image for the current image generation.

With the solutions to the two main questions, we present a framework of constructing a pose-diversified synthetic dataset for aerial-view human detection (Fig
1
). We show that leveraging the pose-diversified synthetic dataset in training remarkably enhances the detection performance, especially in the low-shot setup, where the need for additional data is relatively huge. Moreover, regardless of how to leverage synthetic data in training (either ‘pre-training and fine-tuning’ or ‘PTL (Progressive Transformation Learning)
[
47
]
’), using the pose-diversified synthetic dataset generally yields significantly better detection accuracy than using the original synthetic dataset on three aerial-view human detection benchmarks: VisDrone
[
67
]
, Okutama-Action
[
4
]
, and ICG
[
1
]
. The positive impact of using the pose-diversified synthetic dataset continues regardless of the dataset size, supported by a series of scaling behavior analyses of the synthetic dataset from various aspects.

Related Works

Synthesizing human appearances.
Many efforts have been made to manipulate factors that affect human appearances, such as exterior/clothing features
[
5
,
60
]
, viewing angle and direction
[
25
,
48
]
, human-object interaction
[

, to generate diverse synthetic data. The diversity of these factors can be represented by a finite number of parameters respectively. Diverse synthetic data is then created by sampling these parameterized factors.

However, human poses are exceptionally diverse that it is difficult to select representative samples to cover the entire pose space. Therefore, there have been attempts to directly capture human poses from various real human movements. For example, some of these attempts
[
19
,
46
,
39

used commercial body scanners (
e.g

, MoCap
[

e.g

, depth
[

or point clouds
[

).

Similar to our objective, several previous works have altered existing human images to assume diverse poses. For instance, HUSC
[
64
]
and SURREAL
[
55
]
introduced image translators that altered an image to have different poses that did not present in the original dataset. PoseTrans
[
21
]
applied human parsing and affine transformations to existing human images to generate new images with diverse poses. Rogez and Schmid
[
46
]
stitched multiple images showing only part of human body to follow a given novel pose. In this paper, we introduce an image translator that addresses the same problem where no ground-truth images of novel poses exist.

Pose generation.
In previous works, novel poses can be created by completing missing human keypoints using visible joint information or by sampling from a pose prior distribution. For the pose completion task, several attempts have been made to adopt MLE
[
29
]
, mixture density regression models
[
54
]
, or transformers
[
36
,
15
,
62
]
. For the task of sampling from a prior distribution, the pose prior distribution has been captured from human pose datasets in a variety of ways, such as learning multi-task representations
[
11
]
, constructing an over-complete pose dictionary
[
2
]
, fitting into a mixture of Gaussian
[
6
]
, learning a VAE
[
40
]
, and learning a neural distance field
[
53
]
. Also,
[
12
]
used adversarial learning to guide an existing pose generator to generate plausible poses. Extending from the second line of tasks, we designed a pose generator based on the diffusion model.

Generating images of novel poses.
Many efforts have been made to transform human images so that they can present certain target poses. These efforts adopted various forms of generators, including conditional GAN
[
30
,
61
]
, NeRF
[
17
,
20
]
, and neural feature fields
[
10
]
, and continued to present better generation quality than previous work. To obtain better generation quality, patch-level disentanglement
[
30
]
, in contrast to larger-sized part-level disentanglement that inevitably introduced artifacts, and image revision
[
63
]
, which compared adjacent images in a video sequence, have also been introduced. To address the case where pairs of images corresponding to source and target poses were not available for training, DPE
[
38
]
used a bidirectional cyclic training strategy that minimized the distance between two images (including the same character) after transforming them to have the same pose and expression. This strategy was effective only under a strict constraint that required optimal face reconstruction, which is not easily met in our scenario. To address this problem, our strategy is to train an image translator to acquire a limited capability to perform transformation and apply it only when the source and the target poses are close to each other. Specifically, we construct the target pose sequence where adjacent target poses are sufficiently similar and generate the target images in order.

Exploiting various poses in recognition tasks.
There are two categories of approaches that consider various human poses for recognition tasks: learning pose-aware models and learning pose-invariant models. In this section, we cover learning pose-invariant models, the category to which our method belongs.

In the past, attempts have been made to develop pose-invariant features that can be used to represent humans, such as articulation-insensitive features
[
32
]
, bag-of-pose-activation (poselet)
[
8
,
7
,
35
,
27
,
28
]
, and features when taking a standard pose
[
66
]
. After the recent introduction of large-capacity deep neural networks, there have been efforts to learn representations to capture human poses appearing in large-scale human datasets. For example, 3DInvarReID
[
33
]
learned pose-invariant representations to acquire the reconstruction ability between two different poses. In this paper, our objective is to learn a pose-invariant representation using a pose-diversified synthetic dataset.

3
Method

Our approach to constructing a pose-diversified synthetic dataset has three main components (Fig.
1
): pose generator, image translator, and target pose selection. The details of these components are elaborated below:

Pose generator.
The pose generator is designed to generate novel yet realistic poses that do not exist in existing datasets. The generated pose takes the form of 3D locations of
K
human keypoints,
i.e
.
,
{\bf p}\in\mathbb{R}^{K\times 3}
(in our setting,
K=17
). To acquire such a capability, the pose generator adopts the diffusion model, an emerging generative model that exhibits remarkable performance (
e.g.
, image
[
49
]
, human motion
[
52
]
,
etc.
).

Using the pose generator, we construct a novel pose set
\mathcal{P}_{n}
. To ensure the diversity of the set, we do not include pose pairs with high similarity in the set. In practice, a newly generated pose is added to the set only if there are no similar poses in the set. Here, the two poses with pose distance (eq.
4
) less than a certain threshold
T_{\text{sim}}
are considered similar (in our setting,
T_{\text{sim}}=0.24
). This process is repeated until
N_{\text{pos}}
poses are included in the set. Fig.
2
presents some examples of poses in
\mathcal{P}_{n}
.

Image translator.
Training the image translator requires source poses, target poses and their corresponding images. In this work, input poses and novel poses serve as source poses and target poses, respectively. Clearly, target images corresponding to novel poses are not available for training in our scenario. Our strategy to address this issue is to train the image translator to acquire a limited capability that can generate target images only when target poses are similar to source poses. Such limited capability can be achieved by using limited pose pairs from the original synthetic data for training without relying on novel poses in
\mathcal{P}_{n}
. After that, human images assuming novel poses that differ significantly from the input pose can be generated by repeatedly applying the image translator.

The image translator is only applied to human regions segmented from the input synthetic image to prevent non-human regions adversely influencing the generation. The human region segmentation is performed using segmentation masks, which are generally available along with synthetic data. The segmented human region is refilled in the remaining input image using background inpainting (
[
50
]
is used in this work). The generated human images are resized at random ratios and placed at random locations in the background images. The random ratio follows the human-size distribution of the original synthetic dataset.

Target pose selection.
The image translator lacks the ability to generate images with poses that are significantly different from the input pose. To ensure the diversity of generated images while considering the limitation of the image translator, we introduce a
progressive pose search
that finds sequential target poses evolved from the input pose.

The progressive pose search adopts Dijkstra’s algorithm
[
13
]
, which searches for the optimal path from the start node to the destination node in the graph. In our scenario, the novel pose set is treated as a graph, where the input pose and the target pose serve as the start node and the destination node, respectively. The input pose is estimated in the form of 2D human keypoint locations by applying ViTPose
[
59
]
to the input image. The target pose is randomly selected from the novel pose set
\mathcal{P}_{n}
. Then, intermediate target poses
{\bf p}_{1},~{\bf p}_{2},~\cdots,~{\bf p}_{n-1}
between the input pose (
{\bf p}_{0}
) and the final target pose (
{\bf p}_{n}
) are optimally found from the novel pose set
\mathcal{P}_{n}
by minimizing the following objective:

d({\bf p}_{0},{\bf p}_{n})=\sum_{i=1}^{n}\left(d_{\text{pose}}\left({\bf p}_{i-1},{\bf p}_{i}\right)\right)^{k}~~~\text{s.t.},|\mathcal{P}_{t}|\leq N_{\text{max}},

(1)

where
d_{\text{pose}}
is the pose distance (eq.
4
) between the 2D keypoint locations of two poses, and
\mathcal{P}_{t}=\{{\bf p}_{1},~{\bf p}_{2},~\cdots,~{\bf p}_{n}\}
is the target pose set. To attenuate accumulated generation errors, we limit the maximum number of target poses to
N_{\text{max}}
. Note that when
k>1
, the objective is more affected by shorter pose distances (in our setting,
k=2
).

(2)

\displaystyle{\bf p}_{i}=\argmin_{{\bf p}\in\mathcal{P}_{n}}{\left(\left(d_{\text{pose}}\left({\bf p}_{i-1},{\bf p}\right)\right)^{k}+d\left({\bf p},{\bf p}_{n}\right)\right)}.

Post-processing: noisy image filtering, occlusion insertion.
For the first post-processing, we consider filtering out noisy images that provide a negative impact on the performance. Specifically, we conduct a sanity check based on pose estimation to filter out noisy images from all generated images. The generated images are considered to have a high probability of being low-quality if their estimated poses are significantly different from the target poses used during the generation process. Accordingly, the generated images whose pose distances (eq.
4
) between the input target poses and the estimated poses are greater than a threshold
T_{\text{filt}}
are not included in the novel image set (in our setting,
T_{\text{filt}}=0.1
). Samples of noisy generated images are shown in Fig.
4
.

For the second post-processing, we consider occlusions, which account for much variation in human appearances in real-world aerial-view images. Among various situations that cause occlusions, we consider the simple and frequently occurring case where a human is occluded by another human. That is, we place two generated humans that share the same camera position in one image. The locations of both humans in the image are randomly determined, but we ensure that there is an overlap between the two humans. Besides, the occluding human is always positioned lower than the occluded human in the image to follow the natural occlusions in the aerial view. Samples of generated images after post-processing are shown in Fig.
5
.

3.1
Implementation Details

Measuring pose similarity.
Pose distance
d_{\text{pose}}
, used in several ways in our approach, can be measured by comparing the keypoint locations (2D or 3D) of two poses
{\bf p}_{i}
and
{\bf p}_{j}
, as follows:

d_{\text{pose}}({\bf p}_{i},{\bf p}_{j})=\sqrt{2\left(1-{\bar{\bf p}_{i}}^{\top}{\bar{\bf p}_{j}^{\text{tr}}}\right)},

(4)

where
{\bar{\bf p}_{i}}
and
{\bar{\bf p}_{j}^{\text{tr}}}
are
L_{2}
normalized pose vectors.
{\bf p}_{j}^{\text{tr}}
is a transformed
{\bf p}_{j}
such that the both input poses share the same facing direction and are captured from the same camera position. To determine the facing direction of each pose, we use
neck-to-nose
vector’s direction. The camera position for each pose is either provided by the original synthetic dataset as meta-data or can be easily found. Note that novel poses generated by the pose generator are assumed to be captured from the ground view, just like the poses used to train the pose generator. When comparing a 2D pose and a 3D pose (used in ‘target pose selection’), the pose similarity is calculated after the 3D pose is first transformed and then projected into the 2D space.

The pose generator architecture.
Inspired by
[
52
]
, the pose generator adopting a diffusion model (called “Pose Diffusion Model (PDM)”) which is designed to generate human poses in the form of 3D locations of
K
keypoints,
i.e
.
,
{\bf p}^{(0)}\in\mathbb{R}^{K\times 3}
. PDM iterates two processes in reverse order: i) the
diffusion
and ii) the
denoising
processes. The diffusion process at step
t
diffuses the denoised pose
{\bf p}^{(0)}
to the noisy pose
{\bf p}^{(t)}
by repeatedly adding Gaussian noise
z_{t}\sim\mathcal{N}\left({\bf 0},{\bf I}\right)
to the input pose for
t
times. The denoising process at step
t
requires a model
g_{\text{pos}}
that estimates a clean pose
\hat{{\bf p}}^{(0)}
from the noisy pose
{\bf p}^{(t)}
. It takes as input the current iteration step
t
and the noisy pose
{\bf p}^{(t)}
passed from the diffusion process. This alternating process at step
t
can be formally expressed as:

\displaystyle{\bf p}^{(i)}

\displaystyle=

\displaystyle\sqrt{1-\alpha_{i}}{\bf p}^{(i-1)}+\sqrt{\alpha_{i}}z_{i},~~~i=1,2,\cdots,t.

\displaystyle\hat{{\bf p}}^{(0)}

\displaystyle=

\displaystyle g_{\text{pos}}\left({\bf p}^{(t)},t\right)

(5)

The input at the first iteration is drawn from the Gaussian distribution,
i.e
.
,
{\bf p}^{(t)}\sim\mathcal{N}({\bf 0},{\bf I})
.

For the denoising model
g_{\text{pos}}
, we use a 8-layer transformer encoder architecture
[
56
]
. Each keypoint is treated as an input token and converted to a
d
-dimensional embedding via a feed-forward network (
d=512
). The noise time step
t
is also projected to the
d
-dimensional embedding via a separate feed-forward network. Each input embedding is summed with a standard positional embedding and then fed to the encoder. Excluding the first output token corresponding to the noise time step, the remaining output tokens are further passed through an output feed-forward network to predict clean keypoints. The attention module of the transformer is well suited for estimating human structures as human keypoint locations highly depend on each other.

The pose generator training.
The denoising model
g_{\text{pos}}
is the only trainable module in the pose generator. We aim to train
g_{\text{pos}}
to accurately generate keypoint locations fitting the distribution of the training set. To achieve this objective, the training loss is defined as follows such that the generated keypoint locations should be as close to the ground truth as possible given the noisy pose
{\bf p}^{(t)}
regardless of the noise time step
t
:

\mathcal{L}({\bf p}^{(t)})=\mathbb{E}_{{\bf p}^{(0)}\sim q({\bf p}^{(0)}),t\sim[1,T]}||{\bf p}^{(0)}-g_{\text{pos}}({\bf p}^{(t)},t)||_{2}^{2}.

(6)

for training, which provides metadata about the parameters used in synthesis, such as the camera position. We define image pairs that share similar camera positions as having similar poses.

This result demonstrates the impact of using synthetic data in training on improving detection performance.

Moreover, the pose-diversified synthetic dataset is generally more effective than the original synthetic dataset in increasing the detection accuracy, regardless of how the synthetic data is used for training. Interestingly, the improvement is more pronounced for the cross-domain setups evaluated on the Okutama-Action or ICG datasets. Increasing diversity of human appearances in synthetic data generally ensures higher accuracy, and the benefit becomes even greater in cross-domain tasks where the characteristics of the test set are not well captured by the training set without synthetic images. The exceptional cases (PTL & ICG test set) where accuracy is deteriorated despite using the pose-diversified dataset are discussed in a later subsection.

In addition, in most cases, PTL presents better accuracy than PT-FT, demonstrating its superiority in maximizing the impact of synthetic data. However, this superiority of PTL disappears when evaluating on the ICG test set. A subset of synthetic images used in PTL are constructed in a way that images closer (
e.g
.
, having smaller domain gap) to the training set are selected more often. The ICG test set and VisDrone training set are captured from nadir and oblique perspectives, respectively, so the human appearances in images are very different. This degraded accuracy of PTL may occur because the selected synthetic images are not representative of the ICG images. On the other hand, it is clear from the results of PT-FT that using the entire pose-diversified set in training leads to better representation ability on both same-domain and cross-domain tasks. 5
Conclusion and Discussion

We have introduced an image generation framework that alters the original synthetic image to assume a novel pose that is not present in the original set. Using this pose-diversified synthetic dataset for training by adding the generated images to the original synthetic dataset enables machine learning models to acquire the ability to capture more human appearances, resulting in better accuracy for aerial-view human detection.

We have also studied the scaling behaviors of the synthetic dataset. In our study, the benefit of being able to represent diverse human appearances become more distinct. For example, when using more synthetic data via PTL, the detection accuracy of using our pose-diversified set continues to increase while the performance improvement plateaus when using the original set. In this section, we aim to raise some discussion points about our method.

Diversifying human poses in real data?
One might consider applying our method for constructing a pose-diversified dataset to real data instead of synthetic data. However, there are some remaining challenges in applying our work to real data. For example, to create pose-diversified data using our method, some necessary information can be obtained relatively easier using the metadata provided along with the synthetic data (camera position for each input image used in target pose selection, human region masks,
etc
.
). In addition, the image translator in our method normally requires a large-scale dataset for training, which does not align with the prerequisite settings for low-shot or cross-domain tasks that our work focuses on. Therefore, expanding real dataset in a pose-diversified manner is not within our scope but is worth considering as future work.

Broader impacts.
The ‘novel poses’ in this work are in fact learned from the existing human pose dataset that is used to train the pose generator. Therefore, to construct a pose-diversified dataset using the proposed framework, the pose training set has to contain sufficiently diverse poses. In other words, if one intend to extend the proposed framework (
e.g
.
, applying to different object categories), it is crucial to make sure that such diverse pose training set exists.

In addition, aerial-view human detection enables a variety of constructive applications, such as search and rescue in humanitarian assistance and disaster relief, safe operations of UAVs,
etc
. However, it could also raise privacy concerns or invasion of personal spaces. As a result, it is necessary to carefully monitor the purposes for which this task is used.

Pose transformation
The pose distance measurement, which uses pose transformation to align the facing direction and camera position of two input poses, is employed in several aspects within our method. While the main manuscript outlines the general strategy of pose transformation, we provide specific details here regarding the pose transformation implemented in each scenario.

The pose distance measurement is used in the following scenarios:

•

Building the novel pose set (3D pose
vs
.
3D pose).
To ensure pose diversity within the novel pose set, any generated poses are excluded if they closely resemble existing poses in the set in terms of pose distance. Here, the poses within the novel pose set are represented by the 3D locations of human keypoints. When comparing a generated pose to each pose in the set, the generated pose undergoes a transformation to align its facing direction with that of the pose being compared, where the facing direction is defined by a
neck-to-nose
vector. Since the pose generator is trained using poses captured from a ground view, two generated poses being compared are assumed to have the same camera position on the ground. Therefore, no further transformation is required.

•

Selecting target poses (2D pose
vs
.
3D pose).
In the process of target pose selection, we calculate the pose distance between each input pose in the original synthetic data, represented in 2D keypoint positions, and every pose in the novel pose set, represented in 3D keypoint positions. The camera position corresponding to the input pose can be extracted from the metadata of the original synthetic data. Therefore, we first transform poses in the novel pose set to align with the camera positions of the input pose. We then adjust these poses to match the facing direction of the input pose using the
neck-to-nose
vector. After that, the transformed poses are projected onto a 2D plane for the computation of pose distance.

•

Filtering noisy images (2D pose
vs
.
2D pose).
In the process of noisy image filtering, we compute the pose distance for each generated image, measuring the disparity between the target pose used during generation and the estimated pose. As these two poses correspond to the same image, no transformation is needed.

Image generation.
The overview of image generation is shown in Fig.
8
. To minimize potential noise coming from the background during the generation of novel images, we adopt a strategy of processing the human and background regions independently. Segmentation of the human region can be achieved through the utilization of the segmentation mask provided within the Archangel-synthetic dataset
[
48
]
, serving as the original synthetic dataset in our scenario.

Figure 8
:
The overview of image generation.

The human region where the background is excluded is filled with a mono color (in our case, gray) to facilitate the creation of the segmentation mask after image generation. With a given target pose, this human image undergoes alterations to ensure that the human in the image assumes the target pose, using the
source-to-target
image translator (‘image tr.’). The segmentation mask for the human within the generated image is then constructed by capturing pixels that deviate from the pre-defined mono color. To mitigate artifacts in the segmentation mask, we apply a series of morphological operations, including four iterations of dilation followed by two iterations of erosion, using a kernel size of
3\times 3
.

The human region, segmented from the generated image using the segmentation mask, is then resized using a randomly selected resizing factor, while maintaining a fixed aspect ratio. To elaborate, we randomly select a human image from the Archangel-synthetic dataset and determine the resizing factor such that the longer side of the human region in the generated image matches that of the human region in the randomly selected image. Subsequently, the generated and resized human region is reinserted into the background at a random location, and the original human region is inpainted. To introduce occlusion to the generated image, we add two generated human regions onto the image during post-processing.

Training details.
The proposed framework comprises three types of model training: pose generator training, image translator training, and detector training (
i.e
.
, PT-FT and PTL). In this section, we delve into additional training details that were not addressed in the main manuscript. All the models were trained on a server with 4 NVIDIA GeForce RTX 2080 Ti GPUs.

•

Pose generator training.
We built our pose generator based on the official implementation of MDM
[
52
]
. Without further specifications, we maintained all the settings and training strategies as defined in the original implementation. The pose generator was trained on the Human3.6M dataset
[
19
]
, which was preprocessed according to the procedure outlined in VideoPose3D
[
41
]
. We trained the pose generator for 600k iterations with a batch size of 256, a learning rate of 0.0001, and 1k diffusion steps. Other details, including network architecture and loss function, are provided in the main manuscript (Sec. 3.1).

•

Image translator training.
We utilized the official NTED model
[
45
]
as our image translator, which had been pre-trained on the DeepFashion dataset
[
34
]
, with an input human image size of
256\times 176
. We fine-tuned the pre-trained image translator on the Archangel-synthetic dataset for 200 epochs with a batch size of 4. During fine-tuning, we adjusted the learning rate to be 10 times smaller (
i.e
.
, 0.0002) than the default setting used for pre-training. Additionally, the generative adversarial loss was incorporated after 20k training iterations. Default settings were applied if no further specifications were provided.

•

Detector training.
In this work, we utilized two different methods that leverage synthetic data in detector training: PTL and PT-FT. For PTL, we adhered to the official implementation
[
47
]
, which trained a variant of RetinaNet
[
31
]
in a progressive manner, using default hyper-parameters. It’s important to note that the original PTL framework only considers the case when there is only a single virtual character present in each synthetic image. However, in our pose-diversified synthetic dataset, there might be two virtual characters in a single image. To address this issue, when calculating the domain gap (
i.e
.
, Mahalanobis distance) for each synthetic image containing two characters, we computed the domain gaps separately for each character and represented the synthetic image based on the character with the smaller domain gap. Moreover, if a synthetic image with two characters was selected during a PTL iteration, both characters were involved in the syn2real transformation. For PT-FT, we adopted the same detector architecture and training setups as specified in PTL, with the exception of omitting the progressive aspect. The detector was pre-trained on the synthetic dataset for 6k iterations, followed by fine-tuning on the real dataset for 600 iterations.
