joint normality of representations of numbers: an ergodic approach
Vitaly Bergelson, Younghwan Son

Abstract
. We introduce an ergodic approach to the study of joint normality of representations of numbers. For example, we show that for any integer b ≥ 2 b\geq 2 almost every number x ∈ [ 0 , 1 ) x\in[0,1) is jointly normal with respect to the b b -expansion and continued fraction expansion. This fact is a corollary of the following result which deals with pointwise joint ergodicity : Let T b : [ 0 , 1 ] → [ 0 , 1 ] T_{b}:[0,1]\rightarrow[0,1] be the times b b map defined by T b ​ x = b ​ x mod 1 T_{b}x=bx\,\bmod\,1 and let T G : [ 0 , 1 ] → [ 0 , 1 ] T_{G}:[0,1]\rightarrow[0,1] be the Gauss map defined by T G ​ ( x ) = { 1 x } T_{G}(x)=\{\frac{1}{x}\} for x ≠ 0 x\neq 0 and T G ​ ( 0 ) = 0 . T_{G}(0)=0. (Here { ⋅ } \{\cdot\} denotes the fractional part.) For any f , g ∈ L ∞ ​ ( λ ) f,g\in L^{\infty}(\lambda) , lim N → ∞ 1 N ​ ∑ n = 0 N − 1 f ⁡ ( T b n ​ x ) ​ g ​ ( T G n ​ x ) = ∫ f ​ 𝑑 λ ⋅ ∫ g ​ d ​ μ G for almost every ​ x ∈ [ 0 , 1 ] , \lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T_{b}^{n}x)\,g(T_{G}^{n}x)=\int f\,d\lambda\cdot\int g\,d\mu_{G}\quad\text{for almost every }x\in[0,1], where λ \lambda is the Lebesgue measure on [ 0 , 1 ] [0,1] and μ G \mu_{G} is the Gauss measure on [ 0 , 1 ] [0,1] given by μ G ​ ( A ) = 1 log ⁡ 2 ​ ∫ A 1 1 + x ​ 𝑑 x \mu_{G}(A)=\frac{1}{\log 2}\int_{A}\frac{1}{1+x}dx for any measurable set A ⊂ [ 0 , 1 ] A\subset[0,1] . We also establish the equivalence of various forms of normality and joint normality for representations of numbers, hereby providing a general framework for classical normality results.

Definition 2.1

(ii)

Proof.

(i)\Rightarrow(ii)
: Let
\mu=\mu_{1}\times\cdots\times\mu_{k}
.
Denote
C(Y)
by the space of continuous functions on a compact space
Y
.
We will use the classical fact that the functions of the form
f_{1}\otimes\cdots\otimes f_{k}(x_{1},\dots,x_{k})=\prod_{i=1}^{k}f_{i}(x_{i})

Moreover, there is a countable set of functions

such that their tensor product is linearly dense in

.
Thus one can find a countable dense subset

.

Condition (i) implies that for each

, there exists a full measure set

such that if

(2.1)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}F_{m}(T_{1}^{n}x,\cdots,T_{k}^{n}x)=\int F_{m}\,d\mu.

Let

.
It suffices to show that if

is a continuous function on

, then for any

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}F(T_{1}^{n}x,\cdots,T_{k}^{n}x)=\int F\,d\mu.

Let

satisfy

\int|F_{m}-F|\,d\mu<\epsilon

\frac{1}{N}\sum_{n=0}^{N-1}\left|F(T_{1}^{n}x,\cdots,T_{k}^{n}x)-F_{m}(T_{1}^{n}x,\cdots,T_{k}^{n}x)\right|<\epsilon.

\displaystyle\left|\frac{1}{N}\sum_{n=0}^{N-1}F(T_{1}^{n}x,\cdots,T_{k}^{n}x)-\int F\,d\mu\right|

\displaystyle\leq\frac{1}{N}\sum_{n=0}^{N-1}\left|F(T_{1}^{n}x,\cdots,T_{k}^{n}x)-F_{m}(T_{1}^{n}x,\cdots,T_{k}^{n}x)\right|

Since
\epsilon
is arbitrary, the desired result follows.

(ii)\Rightarrow(i)
: Note first that condition (ii) implies that each
T_{i}
is
\mu_{i}
-ergodic. Indeed, it follows from condition (ii) that there exists a set
X_{0}
of full measure such that for any
x\in X_{0}
, for any
f\in C(X)
, and for any
i=1,2\dots,k
,

\frac{1}{N}\sum_{n=1}^{N}f(T_{i}^{n}x)\rightarrow\int f\,d\mu_{i}.

So, by dominated convergence theorem,

(2.2)

\frac{1}{N}\sum_{n=1}^{N}f(T_{i}^{n}x)\rightarrow\int f\,d\mu_{i}\text{ in }L^{2}(\mu_{i}).

It follows by the standard approximation argument that (
2.2
) holds for any
f\in L^{2}(\mu_{i})
, which implies that each
T_{i}
is
\mu_{i}
-ergodic.

We need to prove that for any bounded measurable functions
f_{1},\dots,f_{k}
,

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)=\prod_{i=1}^{k}\int f_{i}\,d\mu_{i}\quad\text{for a.e. }x.

Without loss of generality, we assume that
|f_{i}(x)|\leq 1
for all
x\in X
and for
i=1,2,\dots,k
. For any given
m\in\mathbb{N}
, there are continuous functions
g_{1}^{(m)},\dots,g_{k}^{(m)}
such that
|g_{i}^{(m)}(x)|\leq 1
for all
x\in X
and
\int|f_{i}-g_{i}^{(m)}|d\mu_{i}<\frac{1}{m}
.

By condition (ii), there is a set of full measure
A_{m}^{1}
such that if
x\in A_{m}^{1}
, then

(2.3)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)=\prod_{i=1}^{k}\int g_{i}^{(m)}\,d\mu_{i},

and by pointwise ergodic theorem, there is a set of full measure
A_{m}^{2}
such that if
x\in A_{m}^{2}
, then for any
i=1,2,\dots,k
,

(2.4)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}|f_{i}(T_{i}^{n}x)-g_{i}^{(m)}(T_{i}^{n}x)|=\int|f_{i}-g_{i}^{(m)}|\,d\mu_{i}.

Let
A_{m}=A_{m}^{1}\cap A_{m}^{2}
.
We will show that if
x\in A_{m}
, then

(2.5)

\limsup_{N\rightarrow\infty}\left|\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}\int f_{i}\,d\mu_{i}\right|\leq\frac{2k}{m}.

By triangle inequality,

(2.6)

\displaystyle\left|\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}\int f_{i}\,d\mu_{i}\right|

\displaystyle\leq\frac{1}{N}\sum_{n=0}^{N-1}\left|\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)\right|

\displaystyle+\left|\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)-\prod_{i=1}^{k}\int g_{i}^{(m)}\,d\mu_{i}\right|

\displaystyle+\left|\prod_{i=1}^{k}\int g_{i}^{(m)}\,d\mu_{i}-\prod_{i=1}^{k}\int f_{i}\,d\mu_{i}\right|

Let us estimate each of the three terms on the right hand side of (
2.6
).
To estimate the first term on the right hand side of (
2.6
), we use the following identity

(2.7)

\prod_{i=1}^{k}a_{i}-\prod_{i=1}^{k}b_{i}=(a_{1}-b_{1})b_{2}\cdots b_{k}+a_{1}(a_{2}-b_{2})b_{3}\cdots b_{k}+\cdots+a_{1}\cdots a_{k-1}(a_{k}-b_{k}).

We have

\left|\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)\right|\leq\sum_{i=1}^{k}|f_{i}(T_{i}^{n}x)-g_{i}^{(m)}(T_{i}^{n}x)|,

so

\frac{1}{N}\sum_{n=0}^{N-1}\left|\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)\right|\leq\sum_{i=1}^{k}\frac{1}{N}\sum_{n=0}^{N-1}|f_{i}(T_{i}^{n}x)-g_{i}^{(m)}(T_{i}^{n}x)|.

Thus, if
x\in A_{m}
, by (
2.4
),

\limsup_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\left|\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)-\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)\right|\leq\sum_{i=1}^{k}\int|f_{i}-g_{i}^{(m)}|\,d\mu_{i}\leq\frac{k}{m}.

As for the second term on the right hand side of (
2.6
), we have by (
2.3
) that if
x\in A_{m}
,

\lim_{N\rightarrow\infty}\left|\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}g_{i}^{(m)}(T_{i}^{n}x)-\prod_{i=1}^{k}\int g_{i}^{(m)}\,d\mu_{i}\right|=0.

Finally applying (
2.7
) to the last term on the right hand side of (
2.6
), we have that

\left|\prod_{i=1}^{k}\int g_{i}^{(m)}\,d\mu_{i}-\prod_{i=1}^{k}\int f_{i}\,d\mu_{i}\right|\leq\sum_{i=1}^{k}\int|g_{i}^{(m)}-f_{i}|\,d\mu_{i}\leq\frac{k}{m}.

Putting all the things together, we get (
2.5
).

Let
B=\bigcap_{m=1}^{\infty}A_{m}
.
Clearly
B
is of full measure (with respect to each
\mu_{i}
). It follows from (
2.5
) that for any
x\in B
, we have

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}f_{i}(T_{i}^{n}x)=\prod_{i=1}^{k}\int f_{i}\,d\mu_{i},

which concludes the proof.
∎

3.
Number-theoretic transformations possessing properties E and M

In this section we discuss in detail properties E and M, which appear in the formulation our main theorem (Theorem
4.1
in Section
4
).
We also describe numerous examples of systems which possess properties E and M and belong to the family
\mathcal{T}
, which was introduced in Section
1
. These examples will be used in the subsequent sections to illustrate our results pertaining to pointwise joint ergodicity and joint normality.

3.1.
Entropy and property E

In this short section we formulate, for reader’s convenience, the classical Shannon-McMillan-Breiman theorem as well as a corollary of it which serve as a motivation for introducing property E.

Theorem 3.1

(Shannon-McMillan-Breiman, see for example Section 6.2 in
[
36
]
)
.

Let
(X,\mathcal{B},\mu,T)
be a probability measure preserving system and let
h(T)
denote the Kolmogorov-Sinai entropy of
T
.
Let
\mathcal{A}
be a countable measurable partition of
X
with
-\sum_{A\in\mathcal{A}}\mu(A)\log\mu(A)<\infty
and
\bigvee_{n=0}^{\infty}T^{-n}\sigma(\mathcal{A})=\mathcal{B}\mod\mu
.
For
x\in X
, let
\mathcal{A}(x)
be the element of
\mathcal{A}
which contains
x
. Let
\mathcal{A}^{n}:=\bigvee\limits_{0}^{n-1}T^{-j}\mathcal{A}
. Then

-\frac{1}{n}\log\mu(\mathcal{A}^{n}(x))\rightarrow h(T)\,\,\text{a.e. and in }L^{1}.

The following corollary of Shannon-McMillan-Breiman theorem, which is often referred to as the entropy equipartition property, states roughly that
for most sets
A\in\mathcal{A}^{n}
,
\mu(A)
is approximately
e^{-nh(T)}
.

Corollary 3.2
.

Given
\epsilon>0
, there is
n_{0}
such that for
n\geq n_{0}
the elements of
\mathcal{A}^{n}
can be divided into two classes

\mathfrak{g}^{n}=\mathfrak{g}^{n}(\epsilon)
and
\mathfrak{b}^{n}=\mathfrak{b}^{n}(\epsilon)
(“good” and “bad” atoms) such that

(1)

\mu\left(\bigcup_{B\in\mathfrak{b}^{n}}B\right)<\epsilon

(2)

For
A\in\mathfrak{g}^{n}
,

(3.1)

e^{-n(h(T)+\epsilon)}<\mu(A)<e^{-n(h(T)-\epsilon)}.

Thus we have that for
n\geq n_{0}

(3.2)

\mu\left(\{x\in[0,1):x\in A\text{ for some }A\in\mathcal{A}^{n}\text{ with }e^{-n(h(T)+\epsilon)}\leq\mu(A)\leq e^{-n(h(T)-\epsilon)}\}\right)\geq 1-\epsilon.

Note that, given
(T,\mu,\mathcal{A})\in\mathcal{T}
and
n\in\mathbb{N}
,
\mathcal{A}^{n}=\bigvee\limits_{0}^{n-1}T^{-j}\mathcal{A}
is also a finite or countable partition of
[0,1]
into intervals; we will call these intervals
cylinders of rank
n
.
Since
\frac{1}{c}\mu\leq\lambda\leq c\mu
for some
c\geq 1
, Corollary
3.2
says that if a cylinder
A
of rank
n
belongs to the class
\mathfrak{g}^{n}
of good atoms, then

\frac{1}{c}e^{-n(h(T)+\epsilon)}\leq\lambda(A)\leq ce^{-n(h(T)-\epsilon)}.

The property E which we will recall here for the convenience of the reader can be viewed as a formalization of the requirement that most cylinders of rank
n
belong to the class
\mathfrak{g}^{n}
of good atoms.

Definition 3.3
.

(T,\mu,\mathcal{A})\in\mathcal{T}
has property E if for any
\epsilon>0
, there is a positive real number
c_{0}=c_{0}(\epsilon)
such that, for any
n\in\mathbb{N}
,

(3.3)

\mu\left(\{x\in[0,1):x\in A\text{ for some }A\in\mathcal{A}^{n}\text{ with }e^{-n(h(T)+\epsilon)}\leq\mu(A)\leq e^{-n(h(T)-\epsilon)}\}\right)\geq 1-\frac{c_{0}}{n}.

3.2.
Property M and RU maps

In this subsection, we introduce the notion of a RU map and show that any weakly mixing RU map has property M. We also show that if
(T,\mu,\mathcal{A})\in\mathcal{T}
has property M, then
T
is exact.

We start with recalling the definition of property M.

Definition 3.4
.

(T,\mu,\mathcal{A})\in\mathcal{T}
has property M if there is a sequence
(b_{n})_{n=1}^{\infty}
of non-negative real numbers with
\sum\limits_{n=1}^{\infty}b_{n}<\infty
such that,
for any natural number
l
and for any non-negative integer
n
, if
A\in\sigma(\mathcal{A}^{l})
and
B\in\mathcal{B}
, then

(3.4)

|\lambda(A\cap T^{-(n+l)}B)-\lambda(A)\mu(B)|\leq b_{n}.

Define variation of
f
on
I=[0,1]
by

\text{Var}(f):=\sup\sum_{i}|f(x_{i})-f(x_{i-1})|,

where the supremum ranges over all
0=x_{0}<x_{1}<\cdots<x_{n}=1
.

For every
f\in L^{1}(\lambda)
, set

\|f\|_{BV}:=\|f\|_{\infty}+V(f),\,\text{where}\,V(f)=\inf\{\text{Var}(f^{*}):f^{*}=f\,\,\,\text{a.e. with respect to }\lambda\}.

Let
BV=:\{f\in L^{1}(\lambda):\|f\|_{BV}<\infty\}
.
The space
BV
is a Banach space with the norm
\|\cdot\|_{BV}
.

Definition 3.5

(cf.
[
1
]
, p.19 and
[
2
]
, p.3)
.

A map
T:[0,1]\rightarrow[0,1]
is said to be a RU map
if there exists a partition
\mathcal{A}
of
[0,1]
into (open, closed, or half open on either end) intervals with nonempty and disjoint interiors such that

(1)

T
is uniformly expanding:

\inf\{|T^{\prime}(x)|:x\in\text{int}(A),A\in\mathcal{A}\}>1

(2)

T
satisfies Rychlik’s condition:

\sum_{A\in\mathcal{A}}\|1_{TA}v_{A}^{\prime}\|_{BV}<\infty,

where
v_{A}
,
A\in\mathcal{A}
, denotes the inverse of
T_{|A}:A\rightarrow TA
.

Remark 3.6
.

Notice that RU maps are presumed to be equipped with a partition
\mathcal{A}
of
[0,1]
(so that the properties (1) and (2) in Definition
3.5
are satisfied).
We will find it convenient to denote RU maps belonging to the class
\mathcal{T}
by triples
(T,\mu,\mathcal{A})
with the understanding that the partition
\mathcal{A}
in the triple
(T,\mu,\mathcal{A})
corresponds to the partition which is stipulated in the Definition
3.5
.

The following result is motivated by Theorem 1(a) in the paper by Aaronson and Nakada (
[
2
]
).

Theorem 3.7
.

If
(T,\mu,\mathcal{A})\in\mathcal{T}
is a weakly mixing RU map, then it has property M. More precisely, there is a real number
r
with
0<r<1
such that for any
A\in\sigma(\mathcal{A}^{l})
and
B\in\mathcal{B}
,

|\lambda(A\cap T^{-n-l}B)-\lambda(A)\mu(B)|\leq\mu(B)\,O(r^{n}).

The proof of Theorem
3.7
is the almost same as that of Theorem 1(a) in the cited above paper by Aaronson and Nakada.
We provide the proof for reader’s convenience.
Before embarking on the proof, we introduce some auxiliary facts.
For
(T,\mu,\mathcal{A})\in\mathcal{T}
, let
\hat{T}:L^{1}(\lambda)\rightarrow L^{1}(\lambda)
be the corresponding Frobenius-Perron operator.
Then

\hat{T}^{n}f=\sum_{A\in\mathcal{A}^{n}}1_{T^{n}A}\,v_{A}^{\prime}\,f\circ v_{A},

where
v_{A}:T^{n}A\rightarrow A
is the inverse of the restriction of
T^{n}
to
A
.

We will need the following two results, which were obtained by Rychlik (
[
46
]
) (see also formulas (1) and (2) on p.4 in
[
2
]
):

(1)

If
(T,\mu,\mathcal{A})\in\mathcal{T}
is a RU map, then there is
c_{0}>0
such that for any
f\in BV
,

(3.5)

\sum_{A\in\mathcal{A}^{l}}\|1_{T^{l}A}\,v_{A}^{\prime}\,f\circ v_{A}\|_{BV}\leq c_{0}\|f\|_{BV},\quad l\geq 1.

(2)

If
T
is a weakly mixing RU map, then
there exist
C>0
and
r\in(0,1)
so that for any
f\in BV

(3.6)

\|\hat{T}^{n}f-h\int_{X}f\,d\lambda\|_{BV}\leq Cr^{n}\|f\|_{BV},\quad n\geq 1,

where
h=\frac{d\mu}{d\lambda}.

Proof of Theorem
3.7
.

Let
A\in\sigma(\mathcal{A}^{l})
. Write
A=\bigcup_{i}A_{i}
, where
A_{i}\in\mathcal{A}^{l}
.
Note that

\hat{T}^{l}1_{A}=\sum_{I\in\mathcal{A}^{l}}1_{T^{l}I}\,v_{I}^{\prime}\,1_{A}\circ v_{I}=\sum_{A_{i}}1_{T^{l}A_{i}}\,v_{A_{i}}^{\prime}\,1\circ v_{A_{i}},

where
v_{A_{i}}:T^{l}A_{i}\rightarrow A_{i}
is given by
v_{A_{i}}:=({T^{l}}_{|A_{i}})^{-1}
.
Then, by (
3.5
) we get

\displaystyle\|\hat{T}^{l}1_{A}\|_{BV}

\displaystyle\leq\sum_{A_{i}}\|1_{T^{l}A_{i}}\,v_{A_{i}}^{\prime}\,1\circ v_{A_{i}}\|_{BV}

\displaystyle\leq\sum_{I\in\mathcal{A}^{l}}\|1_{T^{l}I}\,v_{I}^{\prime}\,1\circ v_{I}\|_{BV}\leq c_{0}\|1\|_{BV}=c_{0}

for some
c_{0}>0
.
Notice that

\lambda(A\cap T^{-(n+l)}B)=\int(\hat{T}^{n}(\hat{T}^{l}1_{A}))\,1_{B}\,d\lambda\quad\text{and}\quad\lambda(A)\mu(B)=\int\left(h\int\hat{T}^{l}1_{A}\,d\lambda\right)1_{B}\,d\lambda.

Using (
3.6
) with
f=\hat{T}^{l}1_{A}
, we obtain

\|\hat{T}^{n}(\hat{T}^{l}1_{A})-h\int\hat{T}^{l}1_{A}\,d\lambda\|_{\infty}\leq\|\hat{T}^{n}(\hat{T}^{l}1_{A})-h\int\hat{T}^{l}1_{A}\,d\lambda\|_{BV}\leq Cr^{n}\|\hat{T}^{l}1_{A}\|_{BV}\leq c_{0}Cr^{n}.

Then,

\displaystyle|\lambda(A\cap T^{-(n+l)}B)-\lambda(A)\mu(B)|=\left|\int\left(\hat{T}^{n}(\hat{T}^{l}1_{A})-h\int\hat{T}^{l}1_{A}\,d\lambda\right)1_{B}\,d\lambda\right|

\displaystyle\quad\leq\|\hat{T}^{n}(\hat{T}^{l}1_{A})-h\int\hat{T}^{l}1_{A}\,d\lambda\|_{\infty}\lambda(B)\leq c_{0}Cr^{n}\lambda(B)=\mu(B)O(r^{n}).

∎

We conclude this section by proving that if
(T,\mu,\mathcal{A})\in\mathcal{T}
has property M, then it is exact.

A (non-invertible) measure preserving transformation
T
on a probability space
(X,\mathcal{B},\mu)
is called
exact endomorphism
if

\bigcap_{n=0}^{\infty}T^{-n}\mathcal{B}=\{\emptyset,X\}\,\,(\bmod\,\mu).

Rokhlin (
[
44
]
) showed that if a measure preserving transformation
T
on a probability space
(X,\mathcal{B},\mu)
is exact, then
T
has completely positive entropy (meaning that each of its non-trivial factors has positive entropy).

Theorem 3.8
.

If
(T,\mu,\mathcal{A})\in\mathcal{T}
has property M, then
T
is exact.

Proof.

Assume that
T
is not exact.
Then there is a measurable set
B\in\bigcap_{n=0}^{\infty}T^{-n}\mathcal{B}
with
0<\mu(B)<1
(and so
0<\lambda(B)<1
).
One can find a sequence of measurable sets
B_{n}\in\bigvee_{i=0}^{n-1}\sigma(T^{-i}\mathcal{A})
such that
\lambda(B_{n}\triangle B)\rightarrow 0
and
\lambda(B_{n})\geq\epsilon_{0}
for some
\epsilon_{0}>0
if
n
is sufficiently large.
Since
B\in\bigcap_{n=0}^{\infty}T^{-n}\mathcal{B}
, for each
n\in\mathbb{N}
there exists a measurable set
C_{n}\in\mathcal{B}
such that
T^{-2n}C_{n}=B^{c}
.
Note that

\lambda(B_{n}\cap T^{-2n}C_{n})=\lambda(B_{n}\cap B^{c})\leq\lambda(B_{n}\triangle B)\rightarrow 0.

By (
3.4
), we have that

-b_{n}+\lambda(B_{n}\cap T^{-2n}C_{n})\leq\lambda(B_{n})\mu(C_{n})\leq b_{n}+\lambda(B_{n}\cap T^{-2n}C_{n}).

Since
\lambda(B_{n})\geq\epsilon_{0}
for sufficiently large
n
,
\mu(C_{n})\rightarrow 0
.
Then we have

0=\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=1}^{n}\mu(C_{n})=\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=1}^{n}\mu(T^{-2n}C_{n})=\mu(B^{c}),

so
\mu(B)=1
, which contradicts the assumption that
\mu(B)<1

∎

3.3.
Examples

In this subsection, we discuss some examples of number-theoretic maps which, along with an appropriate partition, belong to the class
\mathcal{T}
and possess properties E and M.

3.3.1.
Times
b
maps:
T_{b}x=bx\mod 1
,
b\geq 2
an integer

Note that the map
T_{b}x=bx\,\bmod\,1
is
\lambda
-preserving and ergodic.
It is well-known that the entropy
h(T_{b})
is
\log b
.

Let

\mathcal{A}_{b}=\left\{\left[0,\frac{1}{b}\right),\cdots,\left[\frac{b-1}{b},1\right)\right\}.

Then clearly
(T_{b},\lambda,\mathcal{A}_{b})\in\mathcal{T}
.

It is also not hard to check that

•

for any
n\in\mathbb{N}
, if
I
is a cylinder of rank
n
, then
\lambda(I)=\frac{1}{b^{n}}
, so the set
\mathfrak{b}^{n}
of bad atoms is empty, which clearly implies that
(T_{b},\lambda,\mathcal{A}_{b})
has property E.

•

if
A\in\sigma(\mathcal{A}_{b}^{l})
,
l\in\mathbb{N},
and
B\in\mathcal{B}
, then

\lambda(A\cap T_{b}^{-(n+l)}B)=\lambda(A)\lambda(B)\,\,\text{for any }n\geq 0,

so
(T_{b},\lambda,\mathcal{A}_{b})
has property M.

3.3.2.
Gauss map:
T_{G}x=\frac{1}{x}\,\bmod 1

It is well-known that Gauss map
T_{G}
is ergodic with respect to Gauss measure
d\mu_{G}=\frac{1}{\log 2}\frac{dx}{1+x}.

Let

(3.7)

\mathcal{A}_{G}=\left\{\left(\frac{1}{n+1},\frac{1}{n}\right]:n\in\mathbb{N}\right\}.

It is not hard to see that
(T_{G},\mu_{G},\mathcal{A}_{G})\in\mathcal{T}
.

To show that
(T_{G},\mu_{G},\mathcal{A}_{G})
has property E, recall first some basic facts about continued fractions.
Let
x\in[0,1)
be an irrational number. Let
x=[x_{1},x_{2},x_{3},\cdots]
be the continued fraction expansion of
x
. Let
p_{n}=p_{n}(x),q_{n}=q_{n}(x)
denote the numerator and denominator of the
n
th convergent:

\frac{p_{n}}{q_{n}}=[x_{1},x_{2},\cdots,x_{n}].

Let
I_{n}(x)
denote the cylinder set of rank
n
containing
x
. The length of
I_{n}(x)
is given by

\lambda(I_{n}(x))=\left|\frac{p_{n}}{q_{n}}-\frac{p_{n}+p_{n+1}}{q_{n}+q_{n+1}}\right|=\frac{1}{q_{n}(q_{n}+q_{n+1})}.

It is known (see, for instance, Section 14 in
[
25
]
or formula (4.18) of Chapter 1 in
[
8
]
) that for a.e.
x
,

(3.8)

\lim_{n\rightarrow\infty}\frac{1}{n}\log q_{n}(x)=\frac{\pi^{2}}{12\log 2}.

Then Shannon-McMillan-Breiman Theorem (Theorem
3.1
) implies that for a.e.
x
,

h(T_{G})=\lim_{n\rightarrow\infty}-\frac{\log\mu_{G}(I_{n}(x))}{n}=\lim_{n\rightarrow\infty}-\frac{\log\lambda(I_{n}(x))}{n}=\lim_{n\rightarrow\infty}\frac{1}{n}\log q_{n}(x)(q_{n}(x)+q_{n-1}(x))=\frac{\pi^{2}}{6\log 2}.

The fact that
(T_{G},\mu_{G},\mathcal{A}_{G})
has property E is a consequence of the following theorem.

Theorem 3.9

(cf. Theorem 2 in
[
14
]
or Theorem B in
[
49
]
)
.

For any
\delta>0
, there exist
N>0,B>0,\alpha>0
such that for all
n\geq N
,

(3.9)

\lambda\left\{x:\left|\frac{1}{n}\log q_{n}(x)-\frac{\pi^{2}}{12\log 2}\right|\geq\delta\right\}\leq B\exp(-\alpha n).

The following result implies that
T_{G}
has property M.

Theorem 3.10

(cf.
[
25
]
,
[
28
]
,
[
29
]
)
.

There is a constant
\gamma
such that for
A\in\sigma(\mathcal{A}_{G}^{l})
,
B\in\mathcal{B}
and for
n\in\mathbb{N}

(3.10)

\left|\lambda(A\cap T_{G}^{-n-l}B)-\lambda(A)\mu_{G}(B)\right|=\lambda(A)\,\mu_{G}(B)\,O(e^{-\gamma n}).

3.3.3.
\beta
-transformations:
T_{\beta}x=\beta x\,\bmod 1
,
\beta>1
a non-integer

Rényi showed that there is a
T_{\beta}
-preserving and ergodic measure
\mu_{\beta}
such that
1-\frac{1}{\beta}\leq\frac{d\mu_{\beta}}{d\lambda}\leq\frac{1}{1-1/\beta}
. (See
[
41
]
and also see
[
35
]
and
[
18
]
.)

Let

\mathcal{A}_{\beta}=\left\{\left[0,\frac{1}{\beta}\right),\cdots,\left[\frac{[\beta]-1}{\beta},\frac{[\beta]}{\beta}\right),\left[\frac{[\beta]}{\beta},1\right)\right\}.

Clearly
(T_{\beta},\mu_{\beta},\mathcal{A}_{\beta})\in\mathcal{T}
.

It is known (
[
34
]
) that
h(T_{\beta})=\log\beta
.
For
x\in[0,1)
, let
I_{n}(x)
denote the cylinder of rank
n
containing
x
.
Then Shanon-McMillan-Breiman theorem implies that for a.e.
x
,

\lim_{n\rightarrow\infty}-\frac{\log\lambda(I_{n}(x))}{n}=\lim_{n\rightarrow\infty}-\frac{\log\mu_{\beta}(I_{n}(x))}{n}=h(T_{\beta})=\log\beta.

The fact that
(T_{\beta},\mu_{\beta},\mathcal{A}_{\beta})
has property E is the consequence of the following theorem.

Theorem 3.11
.

For
\epsilon>0
,

\lambda\left\{x:\left|-\frac{\log\lambda(I_{n}(x))}{n}-\log\beta\right|>\epsilon\right\}\leq\frac{\beta}{\beta-1}e^{-\epsilon n}.

Proof.

It is obvious that if
A
is a cylinder of rank
n
, then
\lambda(A)\leq\frac{1}{\beta^{n}}
. In
[
41
]
, Rényi showed that number of cylinders of rank
n
is less than or equal to
\frac{\beta}{\beta-1}\beta^{n}
. Then,

\lambda\{x:x\in A\text{ for some cylinder }A\text{ of rank }n\text{ such that }\lambda(A)<\beta^{-n}e^{-\epsilon n}\}\leq\frac{\beta}{\beta-1}e^{-\epsilon n}.

∎

It is not hard to check that
(T_{\beta},\mu_{\beta},\mathcal{A}_{\beta})
is a RU map. Also, it is known that
T_{\beta}
is strongly mixing (see Section 4.5 in
[
43
]
or Theorem 1C in
[
37
]
), hence weakly mixing, so
(T_{\beta},\mu_{\beta},\mathcal{A}_{\beta})
has property M by Theorem
3.7
.

3.3.4.
Linear
\bmod\,1
transformations.

Times
b
maps
T_{b}
and
\beta
-transformations
T_{\beta}
belong to a general family of maps
T_{\beta,\gamma}
:

T_{\beta,\gamma}x=\beta x+\gamma\bmod 1,\,\,(\beta>1,0\leq\gamma<1).

It is known that if either
\beta\geq 2,0\leq\gamma<1
or
1<\beta<2,\gamma=0
, then there is a
T_{\beta,\gamma}
-invariant and ergodic measure
\mu_{\beta,\gamma}
such that
1/c\leq\frac{d\mu_{\beta,\gamma}}{d\lambda}\leq c
for some
c\geq 1
. (See
[
20
]
and
[
52
]
.)
Also, it is known (
[
34
]
) that
h(T_{\beta,\gamma})=\log\beta.

On the other hand, Parry showed that if
1<\beta<2
and
\gamma\neq 0
, then
T_{\beta,\gamma}
may not have an invariant measure, which is equivalent to the Lebesgue measure. (See
[
35
]
). In what follows we will assume that either
\beta\geq 2,0\leq\gamma<1
, or
1<\beta<2,\gamma=0
.

Let

\mathcal{A}_{\beta,\gamma}=\left\{\left[0,\frac{1-\gamma}{\beta}\right),\left[\frac{1-\gamma}{\beta},\frac{2-\gamma}{\beta}\right)\cdots,\left[\frac{[\beta+\gamma]-1-\gamma}{\beta},\frac{[\beta+\gamma]-\gamma}{\beta}\right),\left[\frac{[\beta+\gamma]-\gamma}{\beta},1\right)\right\}.

One readily checks that
(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})\in\mathcal{T}
.

Now let us show that
(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})
has properties E and M.
(Note that we only need to consider the case that
\beta\geq 2,0\leq\gamma<1
.)

It is not hard to check that
(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})
is a RU map. Also it is known that
T_{\beta,\gamma}
is strong mixing (indeed, it is exact (
[
52
]
)), hence weakly mixing, so
(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})
has property M by Theorem
3.7
.

One also can check that if
\beta\geq 2
, the number of cylinders of rank
n
for
(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})
is
O(\beta^{n})
; indeed, for
\beta=2
, the number of cylinders of rank
n
is less than or equal to
\sum_{i=1}^{n}(2^{i}+1)=2^{n+1}-1
and for other cases (
\beta>2
), this follows from Lemma 2.1 in
[
52
]
. Then by arguing as in the proof of Theorem
3.11
in Subsection

, one concludes that

(T_{\beta,\gamma},\mu_{\beta,\gamma},\mathcal{A}_{\beta,\gamma})
has property E.

4.
The proof of main theorem

In this section we prove the main theorem of this article, which we formulate again for reader’s convenience.
Note that the properties E and M, which appear in the formulation, were introduced in Section
1
. (See also Section
3
.)

Theorem 4.1

(Theorem
1.10
)
.

Let
T_{i}:[0,1]\rightarrow[0,1],1\leq i\leq k
, be measurable transformations such that for each
i=1,2\dots,k
, there is a partition
\mathcal{A}_{i}
and a
T_{i}
-invariant ergodic measures
\mu_{i}
with
(T_{i},\mu_{i},\mathcal{A}_{i})\in\mathcal{T}
.
Suppose that for each
i=1,2\dots,k
,
(T_{i},\mu_{i},\mathcal{A}_{i})
satisfies properties E and M. If entropy values
h(T_{1}),\cdots,h(T_{k})
are distinct,
then
T_{1},\dots,T_{k}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{k})
.

The following classical lemma will play an instrumental role in the proof of Theorem
4.1
.

Lemma 4.2

(See
[
21
]
, Lemma 1.5 and a historical remark preceding its formulation.)
.

Let
(X,\mathcal{B},\mu)
be a probability space. Let
f_{n}(x)
be a sequence of non-negative measurable functions on
X
. Let
u_{n},v_{n}
be sequences of real numbers such that

0\leq u_{n}\leq v_{n}.

Write
V(N):=\sum\limits_{n=1}^{N}v_{n}
and assume that
V(N)\rightarrow\infty
as
N\rightarrow\infty
.
Suppose that there exists a constant
K
such that for arbitrary large integers
M_{1},M_{2}\,(1\leq M_{1}<M_{2})
,

(4.1)

\int_{X}\left(\sum_{M_{1}\leq n<M_{2}}(f_{n}(x)-u_{n})\right)^{2}\,d\mu\leq K\sum_{M_{1}\leq n<M_{2}}v_{n}.

Then for any
\epsilon>0
and for a.e.
x\in X
,

(4.2)

\sum_{1\leq n\leq N}f_{n}(x)=\sum_{1\leq n\leq N}u_{n}+O\left(V(N)^{1/2}(\log(V(N)+2))^{2/3+\epsilon}+\max_{1\leq n\leq N}u_{n}\right).

Proof of Theorem
4.1
.

Recall that
\mathcal{A}_{i}^{m}
is a finite or countable partition of the unit interval
[0,1]
and the elements of
\mathcal{A}_{i}^{m}
are intervals, which are called cylinders of rank
m
(corresponding to
(T_{i},\mu_{i},\mathcal{A}_{i})
).
It is enough to show that for any
l\in\mathbb{N}
and for any
A_{i}\in\mathcal{A}_{i}^{l}
,
i=1,2,\dots,k
,

(4.3)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{n}x)=\prod_{i=1}^{k}\mu_{i}(A_{i})\quad\text{ for almost every }x.

To see that the validity for (
4.3
) implies the result in question observe first that since the family of cylinders is countably infinite, (
4.3
) implies that for almost every
x
, for any
A_{i}\in\mathcal{A}_{i}^{l}
,
i=1,2,\dots,k
,

(4.4)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{n}x)=\prod_{i=1}^{k}\mu_{i}(A_{i}).

Now, since
\mathcal{B}=\bigvee_{m=1}^{\infty}\sigma(\mathcal{A}_{i}^{m})
for all
i=1,2,\dots,k
,
any interval

can be approximated by cylinders.
Hence, by the standard approximation argument,
the fact that (
4.4
) holds for any
A_{i}\in\mathcal{A}_{i}^{l},i=1,2,\dots,k,l\in\mathbb{N}
implies that it holds for any intervals
J_{1},\dots,J_{k}
:

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}\prod_{i=1}^{k}1_{J_{i}}(T_{i}^{n}x)=\prod_{i=1}^{k}\mu_{i}(J_{i}).

This, in turn, implies that for almost every
x
,
(T_{1}^{n}x,\dots,T_{k}^{n}x)
is equidistributed with respect to
\mu_{1}\times\cdots\times\mu_{k}
. The pointwise joint ergodicity of
T_{1},\dots,T_{k}
follows then from Theorem
2.2
.

We will derive (
4.3
) by applying Lemma
4.2
to

f_{n}(x)=\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{n}x),\quad u_{n}=\prod_{i=1}^{k}\mu_{i}(A_{i}),\quad v_{n}=\max(1,\log n).

(Note that
f_{n}(x)
and
v_{n}
depend on
n
, but
u_{n}
is a constant sequence, so we can ignore the last term
\max\limits_{1\leq n\leq N}u_{n}
in (
4.2

Write
h_{i}=h(T_{i})
for simplicity. Without loss of generality we assume that
h_{1}<h_{2}<\cdots<h_{k}
. Choose
\epsilon,\delta,\gamma>0
small enough so that for

,

(4.5)

h_{i}-(1+\delta)h_{i-1}-(2+\delta)\epsilon\geq\gamma.

Since
(T_{i},\mu_{i},\mathcal{A}_{i})\in\mathcal{T}
for
i=1,2,\dots,k
, there exists
c\geq 1
such that
\frac{1}{c}\mu_{i}\leq\lambda\leq c\mu_{i}
for all
i=1,2,\dots,k
.
For
M_{1},M_{2}\in\mathbb{N}
with
M_{1}<M_{2}\leq(1+\delta)M_{1}
, let

I_{M_{1},M_{2}}=\{(m,n):M_{1}+l\leq m<n\leq M_{2}-l,n-m\geq l\}\subset\mathbb{N}^{2}.

We will show that (
4.3
) is the consequence of the following two claims:

Claim 1. For
(m,n)\in I_{M_{1},M_{2}}
,

(4.6)

\lambda\left(\bigcap_{i=1}^{k}\left(T_{i}^{-m}A_{i}\bigcap T_{i}^{-n}A_{i}\right)\right)=\prod_{i=1}^{k}\mu_{i}(A_{i})^{2}+c_{m,n},

where
\sum\limits_{(m,n)\in I_{M_{1},M_{2}}}|c_{m,n}|=O(M_{2}-M_{1})

Claim 2. For
M_{1}+l\leq m\leq M_{2}-l

(4.7)

\lambda\left(\bigcap_{i=1}^{k}T_{i}^{-m}A_{i}\right)=\prod_{i=1}^{k}\mu_{i}(A_{i})+d_{m},

where
\sum\limits_{m=M_{1}+l}^{M_{2}-l}|d_{m}|=O(1)

) follows from (

4.6
) and (

\displaystyle\int_{0}^{1}\left(\sum_{n=M_{1}}^{M_{2}}\left(\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{n}x)-\prod_{i=1}^{k}\mu_{i}(A_{i})\right)\right)^{2}\,d\lambda

\displaystyle=2\int_{0}^{1}\sum_{(m,n)\in I_{M_{1},M_{2}}}\left(\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{m}x)-\prod_{i=1}^{k}\mu_{i}(A_{i})\right)\left(\prod_{i=1}^{k}1_{A_{i}}(T_{i}^{n}x)-\prod_{i=1}^{k}\mu_{i}(A_{i})\right)\,d\lambda+O(M_{2}-M_{1})

\displaystyle=O\left(\sum_{(m,n)\in I_{M_{1},M_{2}}}|c_{m,n}|\right)+O\left(\sum_{m=M_{1}+l}^{M_{2}-l}|d_{m}|\right)(M_{2}-M_{1})+O(M_{2}-M_{1})

\displaystyle=O(M_{2}-M_{1}).

Given any
M<N

\displaystyle\leq(N-M)\log N=N\log N-M\log N

(1)

By property E,

\lambda\left(\bigcup_{B\in\mathfrak{b}_{q+1}^{M_{1}}}B\right)\leq\frac{a}{M_{1}}.

Putting (
4.11
), (
4.12
), and (
4.13
) together, we get

\lambda(H_{2}(q))\leq\frac{a}{M_{1}}+2c^{2}e^{-M_{1}(h_{q+1}-\epsilon)+M_{2}(h_{q}+\epsilon)}=O\left(\frac{1}{M_{1}}+e^{-\gamma M_{1}}\right).

This completes the proof of Claim 4.

By Claim 4,

\bigcap_{i=1}^{q}(T_{i}^{-m}A_{i}\cap T_{i}^{-n}A_{i})=H_{1}(q)\cup H_{2}(q)\cup I_{2}(q),

where
H_{1}(q)\in\sigma(\mathcal{A}_{q+1}^{M_{1}})
and
\lambda(H_{2}(q)\cup I_{2}(q))=O(\frac{1}{M_{1}}+e^{-\gamma M_{1}})
.

Note that
H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\cap T_{q+1}^{-n}A_{q+1}\in\sigma(\mathcal{A}_{q+1}^{n+l})
, thus one can write

(4.14)

H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\cap T_{q+1}^{-n}A_{q+1}=I_{1}(q+1)\cup R,

where
I_{1}(q+1)=\bigcup_{i=1}^{s(q+1)}J_{i}(q+1)
with

for
1\leq i\leq s(q+1)
and
R
is union of some intervals in
\mathfrak{b}_{q+1}^{n+l}
, so

(4.15)

\lambda(R)\leq\frac{a}{n+l}=O\left(\frac{1}{M_{1}}\right).

Let

I_{2}(q+1)=\bigcap_{i=1}^{q+1}(T_{i}^{-m}A_{i}\cap T_{i}^{-n}A_{i})\setminus I_{1}(q+1),

so
I_{1}(q+1)\bigcup I_{2}(q+1)=\bigcap\limits_{i=1}^{q+1}(T_{i}^{-m}A_{i}\cap T_{i}^{-n}A_{i}).

Note that

I_{2}(q+1)\subset R\cup H_{2}(q)\cup I_{2}(q),

so
\lambda(I_{2}(q+1))=O\left(\frac{1}{M_{1}}+e^{-\gamma M_{1}}\right)
.

Now, utilizing the fact that
(T_{q+1},\mu_{q+1},\mathcal{A}_{q+1})
has property M, we obtain

\displaystyle\lambda\left(H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\cap T_{q+1}^{-n}A_{q+1}\right)

\displaystyle=\lambda\left(H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\right)\mu_{q+1}(A_{q+1})+O(b_{n-m-l})

(4.16)

\displaystyle=\lambda(H_{1}(q))\mu_{q+1}(A_{q+1})^{2}+O(b_{m-M_{1}-l}+b_{n-m-l}).

(We use that
H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\in\mathcal{A}_{q+1}^{m+l}
for the first equality and
H_{1}(q)\in\mathcal{A}_{q+1}^{M_{1}}\subset\mathcal{A}_{q+1}^{M_{1}+l}
for the second equality.)

Then,

\displaystyle\lambda(I_{1}(q+1))

\displaystyle=\lambda\left(H_{1}(q)\cap T_{q+1}^{-m}A_{q+1}\cap T_{q+1}^{-n}A_{q+1}\right)+O(\lambda(R))\quad(\text{by }\eqref{eqn:$I_1(q+1)$})

\displaystyle=\lambda(H_{1}(q))\mu_{q+1}^{2}(A_{q+1})^{2}+O\left(b_{m-M_{1}-l}+b_{n-m-l}+\frac{1}{M_{1}}\right)(\text{by }\eqref{eqn:R},\eqref{eqn:comp})

\displaystyle=\lambda(I_{1}(q))\mu_{q+1}^{2}(A_{q+1})^{2}+O\left(b_{m-M_{1}-l}+b_{n-m-l}+\frac{1}{M_{1}}+e^{-\gamma M_{1}}\right)(\text{by Claim 4})

∎

5.
Disjoint systems and pointwise joint ergodicity

In this section, we deal with an approach to pointwise joint ergodicity which is based on the notion of disjointness of dynamical systems that was introduced by Furstenberg in
[
15
]
. We remark that while in the previous sections we were mostly dealing with the maps of the interval, the main results in this section are quite general.
The reader is referred to the classical literature (
[
17
]
,
[
36
]
,
[
45
]
,
[
51
]
) for definitions of mixing notions which are mentioned in this section.

Definition 5.1
.

Probability measure preserving systems
(X_{i},\mathcal{B}_{i},\mu_{i},T_{i}),1\leq i\leq k,
are mutually disjoint if the only
T_{1}\times\cdots\times T_{k}
-invariant measure on
X_{1}\times\cdots\times X_{k}
, which has the property that the projection of
\mu
onto
X_{i}
is
\mu_{i}
for all
i=1,\dots,k
, is the product measure
\mu_{1}\times\cdots\times\mu_{k}
.

By slight abuse of language, we will say that
T_{1},\dots,T_{k}

are mutually disjoint if it is clear from the context what the systems
(X_{i},\mathcal{B}_{i},\mu_{i})
are.

Here are some examples of disjoint measure preserving systems:

(1)

Translations on compact abelian groups and weakly mixing systems are disjoint (Theorem 6.10 in
[
45
]
).

(2)

Zero entropy systems and K-automorphisms are disjoint (Theorem 6.11 in
[
45
]
).

(3)

Rigid systems and mildly mixing systems are disjoint (Proposition 4.3 in
[
24
]
).

(4)

If
T_{1}
is a translation on a compact abelian group,
T_{2}
is a weakly mixing rigid transformation, and
T_{3}
is a mildly mixing transformation, then it is not hard to show that
T_{1},T_{2},T_{3}
are mutually disjoint.

(5)

If
\mathsf{X}_{i}=(X,\mathcal{B},\mu_{i},T_{i}),1\leq i\leq k,
are ergodic, measurably distal systems and Kronecker factors of
\mathsf{X}_{i}
are mutually disjoint, then
T_{1},\dots,T_{k}
are mutually disjoint (Proposition 8.5 in
[
7
]
).

The following simple theorem establishes a relation between disjointness and pointwise joint ergodicity.

Theorem 5.2
.

Let
X
be a compact metric space and let
\mathcal{B}
be the Borel
\sigma
-algebra of
X
.
Let
\mu_{1},\dots,\mu_{l},\nu_{1},\dots,\nu_{m}
be pairwise equivalent probability measures on
(X,\mathcal{B})
.
Let
\mathsf{X}_{i}^{(1)}=(X,\mathcal{B},\mu_{i},S_{i})
,
1\leq i\leq l
, and
\mathsf{X}_{j}^{(2)}=(X,\mathcal{B},\nu_{j},T_{j})
,
1\leq j\leq m
, be measure preserving systems such that

(1)

S_{1},\dots,S_{l}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{l})
,

(2)

T_{1},\dots,T_{m}
are pointwise jointly ergodic with respect to
(\nu_{1},\dots,\nu_{m})
,

(3)

\mathsf{X}^{(1)}=\mathsf{X}_{1}^{(1)}\times\cdots\times\mathsf{X}_{l}^{(1)}
and
\mathsf{X}^{(2)}=\mathsf{X}_{1}^{(2)}\times\cdots\times\mathsf{X}_{m}^{(2)}
are disjoint.

Then,
S_{1},\dots,S_{l},T_{1},\dots,T_{m}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{l},\nu_{1},\dots,\nu_{m})
.

Proof.

By the assumptions (1) and (2), Theorem
2.2
implies that there exists a full measure set
A\in\mathcal{B}
such that if
x\in A
, then

\frac{1}{N}\sum_{n=0}^{N-1}\delta_{S_{1}^{n}x}\times\cdots\times\delta_{S_{l}^{n}x}\rightarrow\mu_{1}\times\cdots\times\mu_{l}

and

\frac{1}{N}\sum_{n=0}^{N-1}\delta_{T_{1}^{n}x}\times\cdots\times\delta_{T_{m}^{n}x}\rightarrow\nu_{1}\times\cdots\times\nu_{l}.

Now consider the sequence of measures on
X^{l+m}

\rho_{N}:=\frac{1}{N}\sum_{n=0}^{N-1}\delta_{S_{1}^{n}x}\times\cdots\times\delta_{S_{l}^{n}x}\times\delta_{T_{1}^{n}x}\times\cdots\times\delta_{T_{m}^{n}x},\quad N=1,2,\dots.

Let
\rho
be a weak* limit point of
(\rho_{N})
and let us show that
\rho=\mu_{1}\times\cdots\times\mu_{l}\times\nu_{1}\times\cdots\times\nu_{m}
.
Note that
\rho
is
(S_{1}\times\cdots\times S_{l})\times(T_{1}\times\cdots\times T_{m})
-invariant and that the projections of
\rho
on
\mathsf{X}^{(1)}
and
\mathsf{X}^{(2)}
are, correspondingly,
\mu_{1}\times\cdots\times\mu_{l}
and
\nu_{1}\times\cdots\times\nu_{m}
.
So, the desired result follows from the assumption that
\mathsf{X}^{(1)}
and
\mathsf{X}^{(2)}
are disjoint.
∎

The following corollary of Theorem
5.2
provides a convenient criterion of pointwise joint ergodicity.
A special case when
k=2
and
\mu_{1}=\mu_{2}
was obtained by Berend (see Theorem 2.2 in
[
5
]
; cf. also Theorem I.6 in
[
15
]
).

Corollary 5.3
.

Let
X
be a compact metric space and let
\mathcal{B}
be the Borel
\sigma
-algebra of
X
.
Let
\mathsf{X}_{i}=(X,\mathcal{B},\mu_{i},T_{i})
,
1\leq i\leq k
, be ergodic probability measure preserving systems.
Suppose that
\mu_{1},\dots,\mu_{k}
are pairwise equivalent and
\mathsf{X}_{1},\dots,\mathsf{X}_{k}
are mutually disjoint. Then
T_{1},\cdots,T_{k}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{k})
.

Proof.

Take first
k=2
. Since
\mathsf{X}_{1}
and
\mathsf{X}_{2}
are disjoint, by Theorem
5.2
,
T_{1},T_{2}
are pointwise jointly ergodic.
Take now
k=3
.
Since
\mathsf{X}_{1},\mathsf{X}_{2}
and
\mathsf{X}_{3}
are mutually disjoint,
\mathsf{X}_{1}\times\mathsf{X}_{2}
and
\mathsf{X}_{3}
are disjoint and so by Theorem
5.2
,
T_{1},T_{2},T_{3}
are pointwise jointly ergodic. And so on.
∎

Theorem 5.4
.

Let
X
be a compact metric space and let
\mathcal{B}
be the Borel
\sigma
-algebra of
X
.
Let
\mu_{1},\dots,\mu_{l},\nu_{1},\dots,\nu_{m}
be pairwise equivalent probability measures on
(X,\mathcal{B})
.
Let
\mathsf{X}_{i}^{(1)}=(X,\mathcal{B},\mu_{i},S_{i})
,
1\leq i\leq l
, and
\mathsf{X}_{j}^{(2)}=(X,\mathcal{B},\nu_{j},T_{j})
,
1\leq j\leq m
, be measure preserving systems such that

(1)

each
S_{i}
,
1\leq i\leq l
, has zero entropy,

(2)

each
T_{i}
,
1\leq i\leq m
, is exact.

If
S_{1},\dots,S_{l}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{l})
and
T_{1},\dots,T_{m}
are pointwise jointly ergodic with respect to
(\nu_{1},\dots,\nu_{m})
, then
S_{1},\dots,S_{l},T_{1},\dots,T_{m}
are pointwise jointly ergodic with respect to
(\mu_{1},\dots,\mu_{l},\nu_{1},\dots,\nu_{m})
.

Proof.

Since a Cartesian product of zero entropy systems has zero entropy,
S_{1}\times\cdots\times S_{l}
has zero entropy.
It is known (
[
44
]
) that natural extensions of exact transformations are K-automorphisms and a Cartesian product of K-automorphisms is K-automorphism. Thus,
T_{1}\times\cdots\times T_{m}
is a factor of a K-automorphism.
It is also known that K-automorphisms are disjoint from zero entropy systems. Also, if
\mathsf{X}
and
\mathsf{Y}
are disjoint and
\mathsf{Z}
is a factor of
\mathsf{X}
, then
\mathsf{Z}
and
\mathsf{Y}
are disjoint (Proposition I.1 in
[
15
]
). Thus,
S_{1}\times\cdots\times S_{l}
and
T_{1}\times\cdots\times T_{m}
are disjoint, and so Theorem
5.5
follows from
5.2
.
∎

Theorems
4.1
and
5.4
lead to the following result.

.

Let
\mu_{1},\dots,\mu_{k}
be probability measures on

\mathcal{B}
is the Borel

.

(2)

for

Then for any bounded measurable functions

In this section we deal with various equivalent forms of normality and joint normality, which were briefly discussed in the Introduction.
We start with proving Theorem
1.14
from the Introduction, which we formulate here again for reader’s convenience.

(Theorem
1.14
)
.

Let
{\mathbf{T}}=(T,\mu,\mathcal{A})\in\tilde{\mathcal{T}}
such that
T
is totally ergodic. Let
x\in[0,1]
.
The following statements are equivalent.

(i)

x
is
{\mathbf{T}}
-normal.

(ii)

(T^{n}x)
is equidistributed in
[0,1]
with respect to
\mu
, that is, for any continuous function
f:[0,1]\rightarrow\mathbb{R}
,

(6.1)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)=\int f\,d\mu.

(iii)

For any
m\geq 2
,
x
is
{\mathbf{T}}_{m}
-normal.

(iv)

T^{k}x
is simply
{\mathbf{T}}_{m}
-normal for all

and
m\geq 1
.

(v)

x
is simply
{\mathbf{T}}_{m}

.

There exists a sequence
(m_{l})_{l\in\mathbb{N}}
with
m_{1}<m_{2}<\cdots

is simply
{\mathbf{T}}_{m_{l}}
-normal for any

.

The proof of Theorem
6.1
rests on two useful lemmas which are of independent interest. Before formulating and proving these lemmas we need to introduce some additional terminology.

Let
X
be a compact metric space and let
M(X)
denote the space of probability Borel measures on
X
.
For
\mu\in M(X)
, let
\mathcal{R}(X,\mu)
denote the space of Riemann integrable functions on
X
. Note that
f\in\mathcal{R}(X,\mu)
if and only if
\mu(D_{f})=0
, where
D_{f}
is the set of points of discontinuity of
f
.
Also, note that if the sequence
\mu_{1},\mu_{2},\dots\in M(X)
converges to the measure
\mu
in weak* topology, then, by the standard approximation argument, for any
f\in\mathcal{R}(X,\mu)
,

\int f\,d\mu_{n}\rightarrow\int f\,d\mu.

We will say that a measure preserving system
(X,\mathcal{B},\mu,T)
is
admissible
if
X
is a compact metric space,
\mathcal{B}
is the
\sigma
-algebra of Borel sets of
X
,
\mu
is a probability measure on
\mathcal{B}
, and
T:X\rightarrow X
is a
\mu
-preserving transformation with the property that the set
S
of points of discontinuity of
T
satisfies
\mu(S)=0
.
Following
[
19
]
, we will call any such transformation
\mu
-continuous
.
Note that if
(X,\mathcal{B},\mu,T)
is an admissible system, so is
(X,\mathcal{B},\mu,T^{m})
for any
m\geq 2
.

Given an admissible system
(X,\mathcal{B},\mu,T)
and a point
x\in X
we will say that
x
is
(T,\mu)
-generic
if for any continuous function
f
on
X
,

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)=\int f\,d\mu,

or, equivalently,

\frac{1}{N}\sum_{n=0}^{N-1}\delta_{T^{n}x}\rightarrow\mu\,\,\text{ in weak* topology.}

Note that a point
x\in X
is
(T,\mu)
-generic if and only if for any
f\in\mathcal{R}(X,\mu)
,

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)=\int f\,d\mu.

Remark 6.2
.

Let
\mathbf{T}=(T,\mu,\mathcal{A})\in\tilde{\mathcal{T}}
. Then
([0,1],\mathcal{B},\mu,T)
, where
\mathcal{B}
is the Borel
\sigma
-algebra of
[0,1]
, is an admissible system.
Moreover, the following statements are equivalent.

(i)

x\in[0,1]
is
(T,\mu)
-generic (i.e. for any
f\in C([0,1])
,
\lim\limits_{N\rightarrow\infty}\frac{1}{N}\sum\limits_{n=0}^{N-1}f(T^{n}x)=\int f\,d\mu
).

(ii)

For any interval
I\subset[0,1]
,

(6.2)

\lim_{N\rightarrow\infty}\frac{\#\{0\leq n\leq N-1:T^{n}x\in I\}}{N}=\mu(I).

(One has only to justify (ii)
\Rightarrow
(i). It is not hard to see that this implication follows form the fact that linear combinations of characteristic functions of intervals are dense in
\mathcal{R}([0,1],\mu)
.)

The following lemma is a natural dynamical version of a classical result due to Pyatetskii-Shapiro. (See Theorem 2 in
[
40
]
. See also Theorem 3 in
[
39
]
and Lemma 8.1 in Chapter 1 of
[
27
]
.)

Lemma 6.3
.

Let
(X,\mathcal{B},\mu,T)
be an ergodic admissible system.
If
x\in X
has the property that there is a constant
C>0
such that for any non-negative continuous function
f
on
X

(6.3)

\limsup_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)\leq C\int f\,d\mu,

then
x
is
(T,\mu)
-generic.

Proof.

Define a sequence of measures in
M(X)

\nu_{N}:=\frac{1}{N}\sum_{n=0}^{N-1}\delta_{T^{n}x},\quad N\in\mathbb{N}.

It is sufficient to show that
\nu_{N}\rightarrow\mu
in weak* topology.

Let
\nu
be a weak* limit point of the sequence
(\nu_{N})
and let
(\nu_{N_{k}})
be a subsequence of
(\nu_{N})
such that
\nu_{N_{k}}\rightarrow\nu
.
Note that by (
6.3
), for any nonnegative continuous function
f
on
X
,

\int fd\nu=\lim_{k\rightarrow\infty}\int f\,d\nu_{N_{k}}=\lim_{k\rightarrow\infty}\frac{1}{N_{k}}\sum_{n=0}^{N_{k}-1}f(T^{n}x)\leq C\int fd\mu,

so
\nu\ll\mu
and hence
\mathcal{R}(X,\mu)\subset\mathcal{R}(X,\nu)
.

Now let us show that
\int f\,d\nu=\int f\circ T\,d\nu
for any
f\in C(X)
.
Note that since
T
is
\mu
-continuous, for any
f\in C(X)
,
f\circ T\in\mathcal{R}(X,\mu)\subset\mathcal{R}(X,\nu)
, and so

\ \int f\,d\nu_{N_{k}}\rightarrow\int f\,d\nu\quad\text{and}\quad\int f\circ T\,d\nu_{N_{k}}\rightarrow\int f\circ T\,d\nu.

Since

\left|\int f\,d\nu_{N_{k}}-\int f\circ T\,d\nu_{N_{k}}\right|=\left|\frac{1}{N_{k}}\sum_{n=0}^{N_{k}-1}\left(f(T^{n}x)-f(T^{n+1}x)\right)\right|\leq\frac{2}{N_{k}}\|f\|_{u}\rightarrow 0\quad\text{as }k\rightarrow\infty,

we get
\int f\,d\nu=\int f\circ T\,d\nu
for any
f\in C(X)
.
This, in turn, implies that for any
f\in C(X)

(6.4)

\int f\circ T^{n}d\nu=\int fd\nu\,\text{ for any }n\in\mathbb{N}.

Fix a continuous function
f
on
X
. Since
T
is ergodic, the pointwise ergodic theorem implies

(6.5)

\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}y)=\int f\,d\mu

for
\mu-\text{a.e. }y
. Moreover, the fact that
\nu\ll\mu
implies that (
6.5
) also holds for
\nu-\text{a.e. }y
.
Note that

(6.6)

\left|\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}y)\right|\leq\|f\|_{u}\quad\text{for any }y\in X.

Using (
6.4
) and (
6.6
) and the fact that (
6.5
) holds for
\nu-\text{a.e. }y
, we get with the help of the dominated convergence theorem

\displaystyle\int f\,d\nu

\displaystyle=\int\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}y)d\nu(y)=\lim_{N\rightarrow\infty}\int\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}y)d\nu(y)=\int\lim_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}y)d\nu(y)

\displaystyle=\int\int f\,d\mu\,d\nu=\int fd\mu.

Thus
\nu=\mu
, which implies that any limit point of
(\nu_{N})
is
\mu
, and so
\nu_{N}\rightarrow\mu
in weak* topology.
∎

Lemma 6.4
.

Let
(X,\mathcal{B},\mu,T)
be a totally ergodic admissible system.
Let
m\geq 2
.
Then
x\in X
is
(T,\mu)
-generic if and only if
x
is
(T^{m},\mu)
-generic.

Proof.

Suppose that
x
is
(T,\mu)
-generic.
Note that for any non-negative continuous function

on
X
,

\frac{1}{N}\sum_{n=0}^{N-1}f(T^{mn}x)\leq m\frac{1}{mN}\sum_{n=0}^{mN-1}f(T^{n}x),

and hence

\limsup_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{mn}x)\leq m\int f\,d\mu.

By Lemma
6.3
,
x
is
(T^{m},\mu)
-generic.

Now suppose that

is
(T^{m},\mu)
-generic.
Let
f
be a non-negative continuous function on

. Then for any

we have

\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)\leq\frac{[N/m]+1}{N}\sum_{r=0}^{m-1}\frac{1}{[N/m]+1}\sum_{n=0}^{[N/m]}f\circ T^{r}(T^{mn}x).

Since
T
is
\mu
-continuous,

is Riemann integrable for each

.
Therefore

\lim_{N\rightarrow\infty}\frac{1}{[N/m]+1}\sum_{n=0}^{[N/m]}f\circ T^{r}(T^{mn}x)=\int f\circ T^{r}\,d\mu=\int f\,d\mu.

Hence

\limsup_{N\rightarrow\infty}\frac{1}{N}\sum_{n=0}^{N-1}f(T^{n}x)\leq\int f\,d\mu,

which, by Lemma
6.3
, implies

is
(T,\mu)
-generic.
∎

Remark 6.5
.

Let

\displaystyle\quad=\{0\leq n\leq N-1:T_{b}^{mn}(T_{b}^{k}x)\in[v_{1}]\cap T_{b}^{-m}[v_{2}]\cap\cdots\cap T_{b}^{-m(t-1)}[v_{t}]\}.

\displaystyle\lim_{N\rightarrow\infty}\frac{\#\{0\leq n\leq N-1:x_{mn+k}=v_{1},x_{m(n+1)+k}=v_{2},\dots,x_{m(n+t-1)+k}=v_{t}\}}{N}

\displaystyle\quad\quad=\lambda([v_{1}]\cap T_{b}^{-m}[v_{2}]\cap\cdots\cap T_{b}^{-m(t-1)}[v_{t}])

(6.21)

\displaystyle\quad\quad=\lambda([v_{1},v_{2},\dots,v_{t}])

Wall’s theorem leads to the question whether a similar phenomenon of normality-preservation along arithmetic progressions takes place for general
\mathbf{T}
-normal sequences.
This question has, in general, a negative answer. Indeed, while for any

In fact, it was shown (

]

[

]
for more discussion on the failure of normality preservation.)
