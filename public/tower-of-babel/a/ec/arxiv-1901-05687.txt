General fractional Sobolev Space with variable exponent and applications to nonlocal problems
E. Azroul 1 , A. Benkirane 2 and M. Shimi 3

Abstract
. In this paper, we extend the fractional Sobolev spaces with variable exponents W s , p ⁡ ( x , y ) \displaystyle W^{s,p(x,y)} to include the general fractional case W K , p ⁡ ( x , y ) \displaystyle W^{K,p(x,y)} , where p \displaystyle p is a variable exponent, s ∈ ( 0 , 1 ) \displaystyle s\in(0,1) and K \displaystyle K is a suitable kernel. We are concerned with some qualitative properties of the space W K , p ⁡ ( x , y ) \displaystyle W^{K,p(x,y)} (completeness, reflexivity, separability and density). Moreover, we prove a continuous and compact embedding theorem of these spaces into variable exponent Lebesgue spaces. As applications, we discus the existence of a nontrivial solution for a nonlocal p ( x , . ) \displaystyle p(x,.) -Kirchhoff type problem. Further, we establish the existence and uniqueness of a solution for a variational problem involving the integro-differential operator of elliptic type ℒ p ( x , . ) K \displaystyle\mathcal{L}^{p(x,.)}_{K} .

Introduction

Our main goal in this paper is to extend the fractional Sobolev spaces with variable exponents to cover the nonlocal general case with singular kernel. For this,
we begin this work by remembering the definition of fractional Sobolev spaces with variable exponent, see for instance
[
3
,

,

,

Let
\displaystyle\Omega
be a smooth bounded open set in
\displaystyle\mathbb{R}^{N}
. We start by fixing
\displaystyle s\in(0,1)
and let
\displaystyle p:\overline{\Omega}\times\overline{\Omega}\longrightarrow(1,+\infty)
be a continuous bounded function. We assume that

(1.1)

1<p^{-}=\underset{(x,y)\in\overline{\Omega}\times\overline{\Omega}}{\min}p(x,y)\leqslant p(x,y)\leqslant p^{+}=\underset{(x,y)\in\overline{\Omega}\times\overline{\Omega}}{\max}p(x,y)<+\infty

and

(1.2)

p~~~\text{is symmetric, that is,}~~p(x,y)=p(y,x)\hskip 10.00002pt\text{for all}\hskip 10.00002pt(x,y)\in\overline{\Omega}\times\overline{\Omega}.

Let denote by :

\bar{p}(x)=p(x,x)\hskip 10.00002pt\text{ for all }\hskip 10.00002ptx\in\overline{\Omega}.

We define the fractional Sobolev space with variable exponent via the Gagliardo approach as follows,

\hskip-318.67078ptW=W^{s,p(x,y)}(\Omega)

\hskip 19.91684pt=\bigg\{u\in L^{\bar{p}(x)}(\Omega):\int_{\Omega\times\Omega}\frac{|u(x)-u(y)|^{p(x,y)}}{\lambda^{p(x,y)}|x-y|^{sp(x,y)+N}}~dxdy<+\infty,~~\text{for some}~~\lambda>0\bigg\},

where
\displaystyle L^{\bar{p}(x)}(\Omega)
is the Lebesgue space with variable exponent, (see Section

).

The space
\displaystyle W^{s,p(x,y)}(\Omega)
is a Banach space (see
[
11
]
) if it is endowed with the norm,

\|u\|_{W^{s,p(x,y)}(\Omega)}=\|u\|_{W}=\|u\|_{L^{\bar{p}(x)}(\Omega)}+[u]_{s,p(x,y)},

where
\displaystyle[.]_{s,p(x,y)}

The space

is separable and reflexive, see (
[

Let us consider the fractional
\displaystyle p(x,.)
-Laplacian operator given by

(-\Delta_{p(x,.)})^{s}u(x)=p.v.\int_{\Omega}\frac{|u(x)-u(y)|^{p(x,y)-2}(u(x)-u(y))}{|x-y|^{n+sp(x,y)}}~dy~,~~~~~\text{for all }x\in\Omega

One typical feature of this operator is the nonlocality, in the sense that the value of

\displaystyle N
and
\displaystyle s

\displaystyle(-\Delta)^{s}
in the case
\displaystyle p=2
. The interest for this last operator and more generally pseudo-differential operators, has constantly increased over the last few years, although such operators have been a classical topic of functional analysis since long ago. Nonlocal operators such as
\displaystyle(-\Delta)^{s}

,

]
. We refer the reader to
[

,
12
]
and to the references included for a self-contained overview of the basic properties of fractional Sobolev spaces and fractional Laplacian operator.

Now, we introduce the nonlocal integro-differential operator of elliptic type
\displaystyle\mathcal{L}^{p(x,.)}_{K}
that generalizes the operator
\displaystyle(-\Delta_{p(x,.)})^{s}

\mathcal{L}^{p(x,.)}_{K}(u(x))=p.v.\int_{\mathbb{R}^{N}}|u(x)-u(y)|^{p(x,y)-2}(u(x)-u(y))K(x,y)~dy,~~~~~\text{for all }x\in\mathbb{R}^{N}

\hskip 73.97733pt=\lim\limits_{\varepsilon\longrightarrow 0}\int_{\mathbb{R}^{N}\setminus B_{\varepsilon}(x)}|u(x)-u(y)|^{p(x,y)-2}(u(x)-u(y))K(x,y)~dy,~~~~~\text{for all }x\in\mathbb{R}^{N}.

where
\displaystyle p.v.
is a commonly used abbreviation in the principal value sense,
\displaystyle p:\mathbb{R}^{N}\times\mathbb{R}^{N}\longrightarrow(1,+\infty)

1.1

(1.3)

p((x,y)-(z,z))=p(x,y),\hskip 14.22636pt~~~~~\text{for all }(x,y),(z,z)\in\mathbb{R}^{N}\times\mathbb{R}^{N}.

The kernel
\displaystyle K:\mathbb{R}^{N}\times\mathbb{R}^{N}\longrightarrow(0,+\infty)
is a measurable function with the following properties:

(1.4)

K(x,y)=K(y,x)\hskip 8.5359pt\text{for any }(x,y)\in\mathbb{R}^{N}\times\mathbb{R}^{N},

there exists
\displaystyle k_{0}>0

(1.5)

K(x,y)\geqslant k_{0}|x-y|^{-(N+sp(x,y))},~\text{for any }(x,y)\in\mathbb{R}^{N}\times\mathbb{R}^{N}~and~x\neq y,

(1.6)

A typical example for
\displaystyle K

\displaystyle K(x,y)=|x-y|^{-(N+sp(x,y))}

\displaystyle\mathcal{L}^{p(x,.)}_{K}=(-\Delta_{p(x,.)})^{s}

An other example for
\displaystyle K

K_{1}(x,y)=|x-y|^{-(N+sp(x,y))}a(x-y),

where
\displaystyle a:\mathbb{R}^{N}\longrightarrow[1,+\infty)
is a bounded function, that is,
\displaystyle a\in L^{\infty}(\mathbb{R}^{N})
. It is easy to see that
\displaystyle K_{1}

3.
Functional framework

One of the aims of this paper is to study nonlocal problems driven by
\displaystyle\mathcal{L}^{p(x,.)}_{K}
and
\displaystyle(-\Delta_{p(x,.)})^{s}
with Dirichlet boundary data via variational methods. For this purpose, we need to work in a suitable fractional Sobolev space. For this, we consider a functional analytical setting that is inspired by (but not equivalent to) the fractional Sobolev spaces in order to correctly encode the Dirichlet boundary datum in the variational formulation.

This section is devoted to the definition of this space as well as to its properties. Further, we will prove a continuous compact embedding theorem of these spaces into variable exponent Lebesgue spaces. Finally, we establish a convergence property for a bounded sequence in
\displaystyle W^{K,p(x,y)}_{0}(\Omega)
.

Let
\displaystyle\Omega
be a Lipschitz open bounded subset of
\displaystyle\mathbb{R}^{N}
,
\displaystyle s\in(0,1)
be fixed such that
\displaystyle sp^{+}<N
. Denote
by
\displaystyle Q
the set

Q:=\mathbb{R}^{N}\times\mathbb{R}^{N}\setminus(C\Omega\times C\Omega),\hskip 10.00002pt\text{where }~~C\Omega=\mathbb{R}^{N}\setminus\Omega.

Now, due to the non-locality of the operator
\displaystyle\mathcal{L}^{p(x,.)}_{K}
we introduce the general fractional Sobolev space with variable exponent as follows

W^{K,p(x,y)}(\Omega)=~\left\{\begin{array}[]{clcclc}\hskip-14.22636ptu:\mathbb{R}^{N}\longrightarrow\mathbb{R}~\text{measurable, such that}~~u_{|\Omega}\in L^{\bar{p}(x)}(\Omega)~\text{with}\\
\int_{Q}\frac{|u(x)-u(y)|^{p(x,y)}}{\lambda^{p(x,y)}}K(x,y)~dxdy<+\infty,~~\text{for some}~~\lambda>0\\
\end{array}\right\}.

The norm in
\displaystyle W^{K,p(x,y)}(\Omega)
can be defined as follows:

\|u\|_{W^{K,p(x,y)}(\Omega)}=\|u\|_{K,p(x,y)}=\|u\|_{L^{\bar{p}(x)}(\Omega)}+[u]_{K,p(x,y)},

where,
\displaystyle[u]_{K,p(x,y)}=\inf\bigg\{\lambda>0:\int_{Q}\frac{|u(x)-u(y)|^{p(x,y)}}{\lambda^{p(x,y)}}K(x,y)~dxdy\leqslant 1\bigg\}

\displaystyle u\in W^{K,p(x,y)}(\Omega)

\rho_{K,p(.,.)}(u)=\int_{Q}|u(x)-u(y)|^{p(x,y)}K(x,y)~dxdy+\int_{\Omega}|u(x)|^{\bar{p}(x)}dx.

It is easy to see that
\displaystyle\rho_{K,p(.,.)}
is a
convex modular

\displaystyle W^{K,p(x,y)}(\Omega)

\displaystyle\rho_{K,p(.,.)}

\displaystyle u\in W_{0}^{K,p(x,y)}(\Omega)
