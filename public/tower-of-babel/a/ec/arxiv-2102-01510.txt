Abstract
Two new classes of skew codes over a finite field 𝔽 \mathbb{F} are proposed, called skew convolutional codes and skew trellis codes. These two classes are defined by, respectively, left or right sub-modules over the skew fields of fractions of skew polynomials over 𝔽 \mathbb{F} . The skew convolutional codes can be represented as periodic time-varying ordinary convolutional codes. The skew trellis codes are in general nonlinear over 𝔽 \mathbb{F} . Every code from both classes has a code trellis and can be decoded by Viterbi or BCJR algorithms.



I
Introduction

Convolutional codes were introduced by Elias in 1955
[
1
]
. These codes became popular when in 1967 Viterbi invented his decoding algorithm
[
2
]
and Forney
[
3
]
drew a
code trellis
which made understanding the Viterbi algorithm easy and its maximum-likelihood nature obvious.
Convolutional codes are widely used in telecommunications, e.g., in Turbo codes and in the WiFi IEEE 802.11 standard, in cryptography, etc.

The most common versions are
binary
convolutional codes;

non-binary
convolutional codes are used for higher orders of modulation
[
4
]
or data streaming
[
5
]
.
It is known that periodic time-varying convolutional codes improve the free distance and weight distribution over fixed codes, see; e.g., Mooser
[
6
]
and Lee
[
7
]
. This is a motivation to introduce the new class of linear
skew convolutional codes
that can be represented as ordinary periodic non-binary convolutional codes. The new class is defined as a
left
module over a skew field
{\cal Q}
that will be introduced later. A
right
module over
{\cal Q}
defines another interesting class of
nonlinear trellis codes
.

Our goal is to define and to give a first encounter with the introduced skew codes. The proofs and additional results about the skew convolutional codes as well as more examples and references can be found in the journal version
[
8
]
.

II
Skew convolutional codes

II-A

Skew polynomials and fractions

Consider a field
\mathbb{F}
and an automorphism

\theta
of the field.
Later on, we will use the finite field
\mathbb{F}=\mathbb{F}_{q^{m}}
with the Frobenius
automorphism

\theta(a)=a^{q}

(1)

for all
a\in\mathbb{F}
. Denote by
{\cal R}=\mathbb{F}[D;\theta]
the noncommutative
ring of skew polynomials in
D
over
\mathbb{F}
(with zero derivation)

\mathbb{F}[D;\theta]=\{a(D)=a_{0}+a_{1}D+\dots+a_{n}D^{n}\ |\ a_{i}\in\mathbb{F}\mbox{ and }n\in\mathbb{N}\}.

The addition in
{\cal R}
is as usual.
The multiplication is defined by the basic rule

Da=\theta(a)D

and is extended to all elements of
{\cal R}
by
associativity and distributivity.
The ring
{\cal R}
has a unique left skew field of fractions
{\cal Q}
, from which it inherits its linear algebra properties; see, e.g.,
[
9
]
for more details and
[
8
]
for some examples.

II-B

Definition of skew convolutional codes

Much of linear algebra can be generalized from vector spaces over a field to (either left or right) modules over the skew field
{\cal Q}
. Indeed, it is shown in
[
9
, Theorem 1.4]
that any left
{\cal Q}
-module
{\cal C}
is free, i.e., it has a basis,
and any two bases of
{\cal C}
have the same cardinality, which is the dimension of
{\cal C}
.

Definition 1

(Skew convolutional code)
.

A skew convolutional
[n,k]
code
{\cal C}
over the field
\mathbb{F}
is a left sub-module of dimension
k
of the free module
{\cal Q}^{n}
.

The elements of the code
{\cal C}
are called its
codewords
. A codeword is an
n
-tuple over
{\cal Q}
, where every component is a fraction of skew polynomials from
{\cal R}
. The (Hamming) weight of a fraction is the number of nonzero coefficients in its expansion as a left skew Laurent series
\mathbb{F}((D))
in increasing powers of
D
. The code
{\cal C}
is
\mathbb{F}=\mathbb{F}_{q^{m}}
-linear. The
free distance

d_{f}
of a skew convolutional code is defined to be the minimum nonzero weight over all codewords.

II-C

Relations with ordinary convolutional codes

Lemma 1
.

The class of skew convolutional codes includes ordinary time-invariant (fixed) convolutional codes.

Indeed, when
\theta=id
, a skew convolutional code coincides with an ordinary convolutional code.

A
generator matrix
of a skew convolutional
[n,k]
code
{\cal C}
is a
k\times n
matrix
G(D)
over the skew field
{\cal Q}
whose rows form a basis for the code
{\cal C}
. If the matrix
G(D)
is over the ring
{\cal R}
of skew polynomials, then
G(D)
is called a
polynomial generator matrix
for
{\cal C}
. Every skew code
{\cal C}
has a polynomial generator matrix. Indeed, given a generator matrix
G(D)
over the skew field of fractions
{\cal Q}
, a polynomial generator matrix can be obtained by left multiplying each row of
G(D)
by the left least common multiple of the denominators in that row.

There are two important characteristics of a convolutional code: the free

d_{f}
and the slope
\sigma

The weight of a branch labeled by a vector

is defined to be the Hamming weight

of

. The weight of a path is the sum of its branch weights. A path in the trellis that diverges from zero state, that does not use edges of weight
0

\ell

The
\ell

is defined to be the minimum weight of
\ell
-loops in the minimal code trellis. The slope is defined as
\sigma=\lim_{\ell\rightarrow\infty}d_{\ell}^{\text{b}}/\ell
. The free distance is
d_{f}=\min_{\ell}d_{\ell}^{\text{b}}
.

V
Dual codes

Duality for skew convolutional codes can be defined in different ways.

First, consider a skew convolutional code
{\cal C}
over
\mathbb{F}
in scalar form as a set of sequences as in (
15
). For two sequences
v
and
v^{\prime}
, where at least one of them is finite, define the scalar product
(v,v^{\prime})
as the sum of products of corresponding components, where missing components are assumed to be zero. We say that the sequences are orthogonal if
(v,v^{\prime})=0
.

Definition 2
.

The dual code
{\cal C}^{\perp}
to a skew convolutional
[n,k]
code
{\cal C}
is an
[n,n-k]
skew convolutional code
{\cal C}^{\perp}
such that
(v,v^{\perp})=0
for all finite length words
v\in{\cal C}
and
v^{\perp}\in{\cal C}^{\perp}
.

Another way to define orthogonality is, for example, as follows. Consider two
n
-words
v(D)
and
v^{\perp}(D)
over
{\cal Q}^{n}
. We say that
v^{\perp}(D)
is left-orthogonal to
v(D)
if
v^{\perp}(D)v(D)=0
and right-orthogonal if
v(D)v^{\perp}(D)=0
. A left dual code to a skew convolutional code
{\cal C}
can be defined as

{\cal C}^{\perp}_{\text{left}}=\{v^{\perp}\in{\cal Q}^{n}:v^{\perp}(D)v(D)=0\mbox{ for all }v\in{\cal C}\}.

The dual code
{\cal C}^{\perp}_{\text{left}}
is a left submodule of
{\cal Q}^{n}
, hence it is a skew convolutional code.

We consider below dual codes according to Definition
2

{\cal C}
with generator matrix
G

H

GH^{T}=0
.

[n,k]

VII
Conclusion

We defined two new classes of skew codes over a finite field. The first class consists of linear skew convolutional codes, which are equivalent to time-varying periodic convolutional codes but have as compact description as fixed convolutional codes. The second class consists of nonlinear trellis codes.
