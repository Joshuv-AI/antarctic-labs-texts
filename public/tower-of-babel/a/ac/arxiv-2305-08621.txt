The repository contains code related to the dataset on the Danish
National Election 2022, available at
Harvard Dataverse
.
See the directory
Data from Danish Twitter on National Election
2022
in the Harvard repository.

We cluster Twitter users into bins of users that showed exactly the
same liking/retweeting behavior over the period. To investigate whether
any of these bins exhibited
coordinated inauthentic behavior
,
we were interested in whether bin size correlated with

\circ

user account deletion/suspension (we bought some likes at some point,
and saw that the user accounts disappeared rather quickly)

\circ

high bot scores from Botometer / Botometer Lite.

We didn’t find significant correlations. Neither, and somewhat surprisingly,
between Botometer and Botometer Lite scores.

Dates for Data Collection

\circ

November 1, 2022: Election date.

\circ

October 7, 2022 and 30 days forward: we scraped with the query
#dkpol
-is:retweet OR #fv22 -is:retweet OR #fv2022 -is:retweet
. See
Pull-All_fv22/parameters.py
.

\circ

Late January to Mid February 2023: we looked up user account information
and botscores.

Botometer guidelines suggest that we should have looked up botscores
runningly as they are somewhat time sensitive. Checking for correlations
with botscores, however, came as an afterthought to the general data
collection.

Dataset components

The dataset contains the following:

1. /Raw Data/Pull-All_fv22.zip

Tweet IDs, Liking Users and Retweeting Users live scraped from Oct.
7th and 30 days forward

Runningly, we collected the user identities of liking and retweeting
users, with the algorithm described in
[
3
]

using the code from
this repo
.

The dataset contains the collected data, time stamped. I.e., for every
~5 minutes in the scrape period, there is a file of
the last 48 hours’ tweet IDs, and lists of liking and retweeting users.
See the linked-to repo for information on the directory and file structure.

This repo contains code to process these rather raw files. In addition
to this readme, you can also go through the file
analysis/Pull-fv22-treatment.py

for a bit of practical code.

Note:
The dataset does not contain e.g. tweet text, as this
cannot to shared in batch without violating Twitter’s terms and conditions.

Testing for Correlations: Conclusions

Again, we were mostly interested in whether the correlation in liking/retweeting
behavior among users correlated with

\circ

user account deletion/suspension, creation date, and/or

\circ

high bot scores from Botometer / Botometer lite.

We did not find any significant correlations: The size of a user’s
cluster of identically liking/retweeting users did not correlate with
the user’s Botometer scores or Botometer Lite scores, and the size
of a cluster did not correlate with how many of its users had disappeared.
Also, Botometer and Botometer Lite scores did not correlate with one
another.

To replicate:

1. Run
analysis/features-frame.py
: Collects tweet and user
information, including botscores, user cluster sizes, deletions, etc.

In a bit more detail, the feature frames we created to check for correlated
features included the following:

\circ

binsize: size of bin/cluster the user is grouped into

\circ

user-ID

\circ

error_title: result from user look-ups

\circ

error_detail

\circ

name

\circ

created_at: creation date of user account

\circ

protected: whether user account is private

\circ

verified: whether user account is verified

\circ

followers_count: number of followers of user

\circ

following_count: number of accounts the user follows

\circ

tweet_count: number of posted tweets by user

\circ

listed_count: number of public lists that user is a member of

\circ

screenname - Botscores

\circ

All 8 raw, universal Botometer v4 botscores, such as *overall*,
*fake follower*, *astroturf*

\circ

Botometer Lite score

2. Run
analysis/correlation-coeff.py
: Loads the feature frame
and inspects data, e.g.:

\circ

slices dataframe to filter for users in large bins,

\circ

computes the Pearson correlation coefficient across all columns,

\circ

plots histograms comparing users’ different features, e.g. bin size
and bot scores.
