Abstract
MDS codes are elegant constructions in coding theory and have mode important applications in cryptography, network coding, distributed data storage, communication systems et. In this study, a method is given which MDS codes are lifted to a higher finite field. The presented method satisfies the protection of the distance and creating the MDS code over the F q F_{q} by using MDS code over F p . F_{p}. Keywords: Lifted MDS codes, distance preserving

Conclusion

In this paper, we give a method called lifted MDS codes. It satisfies that protection the distance, variation of code components, keep the MDS property in higher finite fields. Moreover, complexity for calculation is less than the previous recursive method which is clear, because there are only matrix multiplications for the generation of new MDS code.
