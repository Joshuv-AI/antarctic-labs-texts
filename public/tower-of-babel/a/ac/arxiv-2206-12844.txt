Theorem 2
.

In T-quasigroup
(Q,\cdot)
of the form
x\cdot y=\varphi x+\psi y
Schröder identity of generalized associativity is true if and only if
\varphi x=\psi^{-2}x
,
\varepsilon=\varphi^{7}
,
\varepsilon=\psi^{14}
,
\varphi\psi z+\psi\varphi z=0
.

Proof.

We rewrite identity (
9
) in the following form:

\varphi^{2}y+\psi^{3}y+\varphi\psi z+\psi\varphi z+\psi^{2}\varphi x=x.

(14)

If we substitute in equality (
14
)
y=z=0
then we have

\varphi x=\psi^{-2}x.

(15)

If we substitute in equality (
14
)
x=z=0
then we have

\varphi^{2}y+\psi^{3}y=0.

(16)

Taking into consideration equality (
15
), we can re-write equality (
16
) in the form

\psi^{-4}y+\psi^{3}y=0,

(17)

or in the form

\psi^{3}=I\psi^{-4},

(18)

where
Ix=-x
for all
x\in Q
. Notice, the permutation
I
is an automorphism of the group
(Q,+)
here.
Therefore, we can rewrite previous equalities in the form

\varepsilon=I\psi^{-7},I=\psi^{-7},\varepsilon=\psi^{-14},\varepsilon=\psi^{14},\varepsilon=\varphi^{7}.

(19)

If we substitute in equality (
14
)
x=y=0
then we have

\varphi\psi z+\psi\varphi z=0.

(20)

Converse. If we substitute in identity (
9
) the expression
x\cdot y=\varphi x+\psi y
, then we obtain equality (
14
), which is true taking into consideration equalities (
15
), (
16
), (
20
). Then we obtain, that identity (
9
) is true in this case.

.

2.2

Theorem 3
.

In T-quasigroup
(Q,\cdot)
of the form

Schröder identity is true if and only if
\varphi^{2}+\psi^{2}=\varepsilon
,
\varphi\psi y+\psi\varphi y=0
.

Proof.

From identity

xy\cdot yx=x

(21)

we have

\varphi(\varphi x+\psi y)+\psi(\varphi y+\psi x)=x.

(22)

If in (
22
)
y=0
, then

\varphi^{2}+\psi^{2}=\varepsilon.

(23)

If in (
22
)
x=0
, then

\varphi\psi y+\psi\varphi y=0.

(24)

Converse. If we substitute in identity (
10
) the expression
x\cdot y=\varphi x+\psi y
, then we obtain equality (
22
), which is true taking into consideration equalities (
23
), (
24
). Then we obtain, that identity (

) is true in this case.
∎
