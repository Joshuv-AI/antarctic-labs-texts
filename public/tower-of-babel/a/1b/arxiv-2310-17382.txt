Formulae for the number of non-negative integer solutions of linear Diophantine equation and inequality
Eteri Samsonadze

Abstract
. New formulae are presented for the number P ⁡ ( b ) P(b) of non-negative integer solutions of a Diophantine equation ∑ i = 1 n a i ​ x i = b \sum_{i=1}^{n}a_{i}x_{i}=b and for the number Q ⁡ ( b ) Q(b) of non-negative integer solutions of the Diophantine inequality ∑ i = 1 n a i ​ x i ≤ b \sum_{i=1}^{n}a_{i}x_{i}\leq b ( a i > 0 , b ≥ 0 CLOSE (a_{i}>0,b\geq 0 ).

Translation from Russian

The methods of finding the number of integer non-negative solutions of a linear Diophantine equation are known (
[
1
]
,
[
2
]
,
[
3
]
,
[
4
]
, etc.). In the present paper, employing a new method based on the properties of the Kronecker symbol, yet another formula for the number of integer non-negative solutions of a linear Diophantine equation with an arbitrary number of unknowns is obtained.

Consider an equation

\sum_{i=1}^{n}a_{i}x_{i}=b,\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (1)

where
a_{i}

(i=1,2,...,n)
are natural numbers;
b
is an integer non-negative number;
n\geq a
.

We will prove that, for the number
P(b)
of integer non-negative solutions of equation (1), the following formula is valid:

P(b)=\sum_{t_{1}=0}^{d_{1}-1}\sum_{t_{2}=0}^{d_{2}-1}...\sum_{t_{n}=0}^{d_{n}-1}C(f(t_{1},t_{2},...,t_{n})+1;n-1),\ \ \ \ \ (2)

where

f(t_{1},t_{2},...,t_{n})=\frac{1}{M}(b-a_{1}t_{1}-a_{2}t_{2}-...-a_{n}t_{n});

d_{i}=\frac{M}{a_{i}}(i=1,2,...,n);

M
is the least common multiple of the numbers
a_{1},a_{2},...,a_{n}
;

C(k,l)=\frac{1}{l!}k(k+1)...(k+l-1)

if
k
is a natural number, and

C(k,l)=0

otherwise.

Proof.

It is not hard to see that

P(b)=\sum_{x_{1}}\sum_{x_{2}}...\sum_{x_{n}}\delta(\sum_{i=1}^{n}a_{i}x_{i};b),\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (3)

where
\delta(x;y)
is the Kronecker symbol, while
x
in the symbol
\sum_{x}
takes all non-negative integer values.

Taking formula (3) and the following equality into account

\sum_{x}\delta(x;a)=\sum_{x}\sum_{t=0}^{d-1}(dx+t;a),

for any
a
and natural
d
, we obtain

P(b)=\sum_{x_{1}}\sum_{x_{2}}...\sum_{x_{n}}\sum_{t_{1}=0}^{d_{1}-1}\sum_{t_{2}=0}^{d_{2}-1}...\sum_{t_{n}=0}^{d_{n}-1}\delta(\sum_{i=1}^{n}a_{i}(d_{i}x_{i}+t_{i});b).

Since
a_{i}d_{i}=M

(i=1,2,...,n)
, this implies:

P(b)=\sum_{x_{1}}\sum_{x_{2}}...\sum_{x_{n}}\sum_{t_{1}=0}^{d_{1}-1}\sum_{t_{2}=0}^{d_{2}-1}...\sum_{t_{n}=0}^{d_{n}-1}\delta(\sum_{i=1}^{n}x_{i};\frac{b-\sum_{i=1}^{n}a_{i}t_{i}}{M}).

This formula and formula (3) imply that

P(b)=\sum_{t_{1}=0}^{d_{1}-1}\sum_{t_{2}}^{d_{2}-1}...\sum_{t_{n}=0}^{d_{n}-1}\sum_{t_{n}=0}^{d_{n}-1}P_{*}(f(t_{1},t_{2},...,t_{n})),\ \ \ \ \ \ \ \ \ \ \ \ \ \ (4)

where
P_{*}(m)
denotes the number of integer non-negative solutions of the equation

x_{1}+x_{2}+...+x_{n}=m.

Applying the well-known formula
[
5
]

\sum_{x=1}^{k}x(x+1)...(x+l)=\frac{1}{l+2}k(k+1)...(k+l+1),

and the principle of the mathematical induction by
n
, it is not hard to prove that

P_{*}(m)=\frac{1}{(n-1)!}(m+1)(m+2)...(m+n-1)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (5)

for
n\geq 2
and integer
m\geq 0
. Formulas (4) and (5) imply (2).
∎

Note that the number of summands in the right-hand part of formula (2) does not depend on
b
. At that, if

b\geq nM-(a_{1}+a_{2}+...+a_{n}),

all
f(t_{1},t_{2},...,t_{n})
are non-negative. Note also that formula (2) is valid also in the case where
M
is an arbitrary common multiple of the numbers
a_{1},a_{2},...,a_{n}
.

Since the number
Q(b)
of integer non-negative solutions of an inequality

\sum_{i=1}^{n}a_{i}x_{i}\leq b,

is equal to the number of integer non-negative solutions of the equation

x_{n+1}+\sum_{i=1}^{n}a_{i}x_{i}=b,

formula (2) implies that, for natural
a_{i}

(i=1,2,...,n)
and integer
b\geq 0
, one has

Q(b)=\sum_{t_{1}=0}^{d_{1}-1}\sum_{t_{2}=0}^{d_{2}-1}...\sum_{t_{n}=0}^{d_{n}-1}\sum_{t_{n+1}=0}^{M-1}C(f(t_{1},t_{2},...,t_{n})+1;n),\ \ \ \ \ \ \ \ \ \ (6)

where

f(t_{1},t_{2},...,t_{n+1})=\frac{1}{M}(b-\sum_{i=1}^{n}a_{i}t_{i}-t_{n+1});

d_{i}=\frac{M}{a_{i}}\ \ \ \ \ \ \ (i=1,2,...,n);

M
is the least common multiple of the numbers
a_{1},a_{2},...,a_{n}
.

As an implication of formula (2), we give the following formula for calculating
P(b)
:

P(b)=\sum_{i=1}^{n}l_{i}C(b^{\prime}+2-i;n-1),\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (7)

where

b^{\prime}=\left[\frac{b}{M}\right]
is the integral part of the number
\frac{b}{M}
;

l_{i}=P^{\prime}(r+(i-1)M)

(i=1,2,...,n)
;

r
is the remainder of
b
modulo
M
;

P^{\prime}(c)
is the number of integer non-negative solutions of the system

\left\{\begin{array}[]{llllllll}\sum_{j=1}^{n}a_{j}t_{j}=c,\\
\\
0\leq t_{j}\leq\frac{M}{a_{j}}-1~(j=1,2,...,n),\end{array}\right.\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (8)

Note that
l_{1}
,
l_{2}
,…,
l_{n}
depend only on the numbers
a_{1}
,
a_{2}
, ….,
a_{n}
and
r
.

Thus, formula (7) enables us to calculate the number
P(b)
of integer non-negative solutions of equation (1) for an arbitrary
b
that is congruent to
r
modulo
M
provided that we know the number
P^{\prime}(c)
of integer non-negative solutions of system (8) for
c=r
,
c=r+M
, …,
c=r+(n-1)M

(0\leq r<M)
.

Note also that
P^{\prime}(c)\leq P(c)
for any
c
and
P^{\prime}(c)=0
for

c>nM-(a_{1}+a_{2}+...+a_{n}).

For finding all
P^{\prime}(c)
’s it suffices to know the values of the expression
\sum_{j=1}^{n}a_{j}t_{j}
for
c\leq t_{j}\leq\frac{M}{a_{j}}-1

(j=1,2,...,n)
.

Example
. Find the number
P(b)
of integer non-negative solutions of the equation

x_{1}+x_{2}+...+x_{n-1}+2x_{n}=b,

for an integer
b\geq 0
.

To calculate
P(b)
, we will apply formula (7), where we set

a_{1}=a_{2}=...=a_{n-1}=1,

a_{n}=2,M=2,t_{n}=0,0\leq t_{i}\leq 1\ \ (i=1,2,...,n-1).

It is not hard to see that if
t_{1}
,
t_{2}
, …,
t_{n-1}
take values
0
and
1
, then the expression

t_{1}+t_{2}+...+t_{n-1}+2t_{n}

takes the value
0
precisely one time; the value
1
– precisely
C^{1}_{n-1}
times, etc., the value
n-1
– precisely
C_{n-1}^{n-1}
times. Moreover,

t_{1}+t_{2}+...+t_{n-1}+2t_{n}\leq n-1.

Therefore,

P^{\prime}(0)=C_{n-1}^{0},P^{\prime}(1)=C^{1}_{n-1},...,P^{\prime}(n-1)=C_{n-1}^{n-1}

and

P^{\prime}(c)=0

for
c>n-1
.

This fact together with formula (7) implies that

P(b)=\sum_{k=0}^{\left[\frac{n-1}{2}\right]}C_{n-1}^{2k}C(b^{\prime}-k+1;n-1)

for an even
b
and

P(b)=\sum_{k=0}^{\left[\frac{n-2}{2}\right]}C_{n-1}^{2k+1}C(b^{\prime}-k+1;n-1)

for an odd
b
, where

C(m;n-1)=\frac{1}{(n-1)!}m(m+1)...(m+n-2)

if
m>0
, and

C(m;n-1)=0

otherwise;
b^{\prime}=\left[\frac{b}{2}\right]
.
