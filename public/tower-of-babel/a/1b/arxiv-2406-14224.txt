Cellular Automata model for period- n n synchronization: A new universality class.
Divya D. Joshi & Prashant M. Gade

Abstract
There are few known universality classes of absorbing phase transitions in one dimension and most models fall in the well-known directed percolation (DP) class. Synchronization is a transition to an absorbing state and this transition is often DP class. With local coupling, the transition is often to a fixed point state. Transitions to a periodic synchronized state are seldom observed. Recently a transition to a synchronized period-3 state that is not in DP class is observed. We model it using a cellular automata model with states 1 to n n . The rules are a) Each site in state i i changes to state i + 1 i+1 for i < n i<n and 1 if i = n i=n . b) After this update, it takes value of either neighbor unless it is in state 1. With these rules, we observe a transition to synchronization with critical exponents different from those of DP for n > 2 n>2 . For n = 2 n=2 , a different exponent is observed.

Introduction

The theory of phase transitions is a major success story in statistical physics in the 70’s. The concepts of renormalization group as well as universality class were introduced in those times. It was fascinating that the second-order phase transition in quark-gluon plasma is in the same universality class as the Ising model

These transitions are in a few different universality classes such as directed percolation, directed Ising, Manna class etc.

Of these different universal classes, the directed percolation universality class is the most observed. The Jannsen-Grassberger conjecture states that “the universality class of DP contains all continuous transitions from a dead or absorbing state to an active one with a single scalar order parameter, provided the dead state is not degenerate and provided some technical points are fulfilled: short-range interactions both in space and time, the nonvanishing probability for any active state to die locally, translational invariance (absence of frozen randomness), and absence of multicritical points”
[
7
,
8
]

and it is observed even in the most unexpected places where the absorbing state has no long-range order in space. The phase space is divided into bands and all sites return to the previous band after a certain period. Thus it could be described as a periodic state with that period only in a coarse-grained sense
[
9
,
10
]
.

Recently, a transition to a period-3 synchronized state has been observed in coupled Gaussian maps. Gaiki
et al
observed that this transition is in a new universality class and report exponents that do not match with previous reports
[
10
]
. We present a stochastic cellular automata model that reproduces the exponents for period-3. In this model, we obtain
exponents close to those obtained in the above work. Now one may wonder if a transition to a synchronized state with a period different from three has a different universality class. We investigate this possibility. However, within our numerical error, except for period-2, the exponents for any period are not very different from those obtained for period-3. In this model, all sites are updated like a clock. Except for sites in a certain preferred state, all other sites are influenced by its neighbors.

The model

We consider a
1D
lattice of length
N
. The state at each site
i
is denoted by
s_{t}(i)
. At
t=0
, we assign each site a spin state
s_{0}(i)
as
l
where
l=1,2,\ldots k
with equal probability. The states of the sites are updated synchronously in two steps.

i) In the first step, we update the sites cyclically
i.e.
, the state 1 changes to 2, 2 changes to 3 and
k
changes to 1. We introduce one more
arbitrary variable
s^{\prime}_{t}(i)
. Thus
s^{\prime}_{t+1}(i)=s_{t}(i)+1
if
s_{t}(i)<k
and

s^{\prime}_{t+1}(i)=1
if
s_{t}(i)=k
.

ii) In the second step, except for sites in a certain preferred state, all other sites mimic the state of randomly chosen neighbor. In other words, if
s^{\prime}_{t+1}(i)\neq 1
,
s_{t+1}(i)=s^{\prime}_{t+1}(i-1)
or
s_{t+1}(i)=s^{\prime}_{t+1}(i+1)
with probability
{\frac{1}{2}}
. If
s^{\prime}_{t+1}(i)=1
, we assign
s_{t+1}(i)=1
. Thus, the site which is in state
1
is not affected by its nearest neighbors. This rule breaks the symmetry between states. In coupled map lattices, different states are not exactly equivalent. Thus all possible transitions are
not equally probable. This rule models the possibility that some states are less affected by neighbours than others.

For synchronization, we define an order parameter
O(t)={\frac{1}{N}}\sum_{i}H(|s_{t}(i)-s_{t}(i-1)|)
where
H(x)=1
iff
x\leq 0
and
H(x)=1
otherwise. In other words, this order parameter is the number of domain walls where the spin values of consecutive sites on the lattice are different. The order parameter is zero for synchronized state and is nonzero otherwise.

First, let us consider the case
k=3
which is the case of transition to synchronized period-3 studied by Gaiki
et al

[
10
]
. In Fig.
1
, we plot
O(t)
as a function of time
t
on a logarithmic scale. We find a power-law behaviour
O(t)\sim t^{-\delta}
with
\delta\sim 0.82
which is similar to the exponent observed in the above paper. In Fig.
2
, we show how defects, (the sites where spins of consecutive sites are different) propagate in time. The defects propagate in a straight line and annihilate after meeting (This is very similar to Fig. 5f of
[
10
]
). This behaviour is unlike the directed percolation universality class where defects propagate in a cone (See Fig.1 of
[
11
]
). We find that the defects take a preferred direction and there is very little random or zig-zag motion over and above this direction. We also study the evolution of the order parameter for different system sizes. In Fig.
3
we show the evolution of the order parameter for different system sizes. There is a power-law behaviour followed by cusp and exponential decay. The decay time scales as
N^{2}
and if we plot
t/N^{z}
versus
O(t)N^{z\delta}
with
z=2

[
10
]

k>3

3
Discussion and Conclusion

We have studied a model of cellular automaton for period-
n
synchronization. We used cellular automaton to model a transition to the synchronized period-
n
state. This model is updated in two steps. In the first step, the states of sites are updated cyclically. In the next step, the sites randomly take the state of their neighbour, except for sites with state 1. Sites with this state remain unaltered. We define the order parameter as the difference between the state values of the neighbouring states. The order parameter is a nonzero quantity when the neighbouring sites have different states. In this work, we have studied three cases,
i.e.,

k=2,3,
and 20 in detail. For
k=2
, it is observed that the defects grow as a power-law with the dynamic exponents
\delta=\frac{1}{2}
and
z=2
. This suggests the model behaves like a random walk model for
k=2
. On the other hand, we get
\delta=0.82
and
z=2
for this model with
k=3
and 20. For
k\geq 3
, the model shows the same behaviour. These values have been recently observed in a transition to period-3 in the coupled Gaussian map. These exponents are novel and have not been seen in any other universality classes. Thus, these findings may suggest the existence of a new universality class.
