Ground state solutions for quasilinear Schrödinger type equation involving anisotropic p-laplacian
Kaushik Bal, Sanjit Biswas

Abstract




Abstract

This paper is concerned with the existence of a nonnegative ground state solution of the following quasilinear Schrödinger equation

\displaystyle\begin{cases}-\Delta_{H,p}u+V(x)|u|^{p-2}u-\Delta_{H,p}(|u|^{2\alpha})|u|^{2\alpha-2}u=\lambda|u|^{q-1}u\text{ in }\mathbb{R}^{n}\\
u\in W^{1,p}(\mathbb{R}^{n})\cap L^{\infty}(\mathbb{R}^{N})\end{cases}

where
N\geq 2
;
(\alpha,p)\in D_{N}=\{(x,y)\in\mathbb{R}^{2}:2xy\geq y+1,\;y\geq 2x,\;y<N\}
and
\lambda>0
is a parameter. The operator
\Delta_{H,p}
is the reversible Finsler p-Laplacian operator with the function
H
being the Minkowski norm on
\mathbb{R}^{N}
. Under certain conditions on
V
, we establish the existence of a non-trivial non-negative bounded ground state solution of the above equation.

In this paper, we are concerned with the following problem

\displaystyle\begin{cases}-\Delta_{H,p}u+V(x)|u|^{p-2}u-\Delta_{H,p}(|u|^{2\alpha})|u|^{2\alpha-2}u=\lambda|u|^{q-1}u\text{ in }\mathbb{R}^{n}\\

(1)

(H4)

(H5)

The variational form of the equation (

\displaystyle I(u)=\frac{1}{p}\intop\nolimits[1+(2\alpha)^{p-1}|u|^{(2\alpha-1)p}]H(Du)^{p}+V(x)|u|^{p}]dx-\frac{\lambda}{q+1}\intop\nolimits|u|^{q+1}dx

\displaystyle\begin{cases}f^{\prime}(t)=[1+(2\alpha)^{p-1}|f(t)|^{(2\alpha-1)p}]^{-\frac{1}{p}},\;t>0\\

(9)

Under the transformation

\displaystyle I(f(v))=\frac{1}{p}\intop\nolimits[H(Dv)^{p}+V(x)|f(v)|^{p}]dx-\frac{\lambda}{q+1}\intop\nolimits|f(v)|^{q+1}dx.

We give some important properties of

Lemma 1.1
.

The function

(i)

(ii)

(v)

for all

(vi)

f(t)\leq 2\alpha tf^{\prime}(t)\leq 2\alpha f(t)
for all

(vii)

such that

C|t|^{\frac{1}{2\alpha}},\;\text{ if }\;|t|\geq 1\end{cases}

(viii)

|f|^{p}

(ix)

(x)

Proof.

The proof of the first seven properties can be found in
[
29
]
. To prove property
(viii)
we define
\phi:\mathbb{R}\to\mathbb{R}
by
\phi(t)=|f(t)|^{p}
. It is easy to check that,

i)

\phi^{\prime}(t)=p|f(t)|^{p-2}f(t)f^{\prime}(t)

ii)

\phi"=p|f|^{p-2}[ff"+(p-1)f^{\prime 2}].

Now,
\phi
is convex if and only if

\displaystyle ff"+(p-1)f^{\prime 2}=\frac{(p-1)+(p-2\alpha)(2\alpha)^{p-1}|f|^{p(2\alpha-1)}}{[1+(2\alpha)^{p-1}|f|^{p(2\alpha-1)}]^{1+\frac{2}{p}}}\geq 0.

(11)

Moreover,
ff"+(p-1)f^{\prime 2}\geq 0
if and only if
(p-1)+(p-2\alpha)(2\alpha)^{p-1}|f|^{p(2\alpha-1)}\geq 0
. Hence, we can conclude that if

then

is convex. Conversely, if

(p-1)+(p-2\alpha)(2\alpha)^{p-1}|f(t)|^{p(2\alpha-1)}\geq 0,\text{ for all }t>0.

Therefore,

\displaystyle\frac{(p-1)+(p-2\alpha)(2\alpha)^{p-1}|f|^{p(2\alpha-1)}}{t^{\frac{p(2\alpha-1)}{2\alpha}}}\geq 0.

Take

\displaystyle\lim_{t\to\infty}[(p-1)t^{-\frac{p(2\alpha-1)}{2\alpha}}+(p-2\alpha)(2\alpha)^{p-1}(|f(t)|{t^{-\frac{1}{2\alpha}}})^{p(2\alpha-1)}]\geq 0

Using the fact

that is,

The definition of
