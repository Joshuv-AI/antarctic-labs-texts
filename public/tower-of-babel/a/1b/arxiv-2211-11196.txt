Hamilton-Jacobi-Bellman equation of nonlinear optimal control problems with fractional discount rate
Gou Nishida, Takamatsu Takahiro, Noboru Sakamoto

Abstract
This paper derives the Hamilton-Jacobi-Bellman equation of nonlinear optimal control problems for cost functions with fractional discount rate from the Bellman’s principle of optimality. The fractional discount rate is described by Mittag-Leffler function that can be considered as a generalized exponential function.



1
Introduction

The Hamilton-Jacobi-Bellman (HJB) equation in optimal control theory yields
a necessary and sufficient condition for the optimality of controls with respect to cost functions
(
Anderson and Moore 1990
)
.
The optimal controls are obtained from the HJB equation as a minimizer of the Hamiltonian included in the equation.
The cost functions can be variously chosen for each control problem.
The discounted cost is defined by multiplying an exponential function to an integrand of a cost function.
The exponential function affects evaluations to increase or decrease weighting as time progresses.

In this paper, the Hamilton-Jacobi-Bellman equation of nonlinear optimal control problems
for an extended discounted cost function using a fractional discount rate described by Mittag-Leffler function
(
Podlubny 1999
;
Gorenflo et al. 2020
)

is derived from the Bellman’s principle of optimality
(
Bellman 2021
)
.

2
Preliminaries

This section summarizes the basic definition and derivation of the infinite horizon optimal control problem with discounted cost.

2.1
Optimal problem with discount rate

Consider the infinite horizon optimal control problem for the system

\displaystyle\dot{x}(t)=f(x(t),u(t),t)

(1)

with the cost function

\displaystyle J=\int_{t}^{\infty}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau

(2)

for some time
t
such that
t_{0}\leq t\leq\infty
, where
\lambda\in{\mathbb{R}}
,
x=x(t)\in{\mathbb{R}}^{n}
is the state,
u=u(t)\in{\mathbb{R}}^{m}
is the control,
f\colon M\to{\mathbb{R}}^{n}
is a smooth mapping, and
M
is an
n
-dimensional manifold.
If
\lambda>0
, then the cost is expanded as time progresses, and designed controls work
in such a way as to suppress states within a short time.
If
\lambda<0
, prospective costs do not so much take into account with distance from an initial time.

This problem can be formulated by dynamic programming as follows:

\displaystyle V(x,t)=\inf_{u[t,\infty]}J

\displaystyle=\inf_{u[t,\infty]}\left(\int_{t}^{t^{\prime}}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\int_{t^{\prime}}^{\infty}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau\right)

\displaystyle=\inf_{u[t,t^{\prime}]}\left\{\int_{t}^{t^{\prime}}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\inf_{u[t^{\prime},\infty]}\left(\int_{t^{\prime}}^{\infty}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau\right)\right\}

\displaystyle=\inf_{u[t,t^{\prime}]}\left(\int_{t}^{t^{\prime}}{e^{\lambda(\tau-t)}}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\,{e^{\lambda dt}}V(x(t^{\prime}),t^{\prime})\right),

(3)

where we have used
t^{\prime}=t+dt
in the last equation.
For an infinitesimal time
dt>0
, the above
V
called a value function can be written as follows:

\displaystyle V(x,t)

\displaystyle\ =\inf_{u[t,t+dt]}\left(L(x,u,t)\,dt+{e^{\lambda dt}}V(x+fdt,t+dt)\right),

(4)

where we have assumed that
V
called a value function is smooth.
From the first order term of the Taylor series expansion of (
4
):

\displaystyle V(x+fdt,t+dt)

\displaystyle\quad=V(x,t)+\dfrac{\partial V}{\partial x}(x,t)fdt+\dfrac{\partial V}{\partial t}(x,t)dt+\mathcal{O}(dt^{2}),

(5)

\displaystyle{e^{\lambda dt}=1+\lambda dt+\mathcal{O}(dt^{2})},

(6)

we obtain

\displaystyle{-\lambda V(x,t)}-\dfrac{\partial V}{\partial t}(x,t)

\displaystyle=\inf_{u}\left(L(x,u,t)+\dfrac{\partial V}{\partial x}(x,t)f\right)

\displaystyle=\inf_{u}H(x,u,p,t),

(7)

where we have defined

\displaystyle H(x,u,p,t)=L(x,u,t)+\dfrac{\partial V}{\partial x}(x,t)f

(8)

for
p=(\partial V/\partial x)^{\top}(x,t)
.
The equation (
7
) is the Hamilton-Jacobi-Bellman equation with discounted cost that is the necessary condition of the optimal problem.
The term
-\lambda V(x,t)
does not appears in the standard optimal control problem setting.

3
Main results

3.1
Motivation and summary of results

In (
3
), the relation
e^{\lambda(\tau-t^{\prime}+dt)}=e^{\lambda(\tau-t^{\prime})}e^{\lambda dt}
has been used.
This relation is called the semigroup property of exponential functions.
In this paper, we attempt to use the Mittag-Leffler function

E_{\alpha}(\lambda(\tau-t^{\prime}+dt)^{\alpha})
instead of the exponential function in the optimal control problem.
The Mittag-Leffler function can be considered as a generalized exponential function.
For instance,
E_{0}(z)=1/(1-z)
for
|z|<1
,
E_{1}(z)=e^{z}
,
E_{2}(z)=\cosh(\sqrt{z})
for
z\in{\mathbb{C}}
,
where
{\mathbb{C}}
is the set of complex numbers, and
\mathrm{erfc}
is the error function.

The Mittag-Leffler function
E_{\alpha}
is defined by

\displaystyle E_{\alpha}(z)=\sum_{n=0}^{\infty}\dfrac{z^{n}}{\Gamma(\alpha n+1)}

(9)

for
z\in{\mathbb{C}}
and
\alpha\geq 0
, where

\Gamma
is the Gamma function defined by

\displaystyle\Gamma(z)=\int_{0}^{\infty}t^{z-1}e^{-t}\,dt\quad(\mathrm{Re}\,z>0)

(10)

for a complex number
z
with positive real part (
\Gamma(n+1)=n!
for a natural number
n
, and

\Gamma(r+1)=r\Gamma(r)
for a positive real
r
).

On the other hand, there is a difficulty that the semigroup property of the Mittag-Leffler function does not hold, i.e.,

E_{\alpha}[\lambda(\tau-t^{\prime}+dt)^{\alpha}]\neq E_{\alpha}[\lambda(\tau-t^{\prime})^{\alpha}]E_{\alpha}(\lambda dt^{\alpha})
.
Then, the following relation holds
(
Guswanto 2016
)
:

\displaystyle E_{\alpha}[\lambda(t+s)^{\alpha}]=E_{\alpha}(\lambda t^{\alpha})E_{\alpha}(\lambda s^{\alpha})-\varDelta E_{\alpha}(t,s),

(11)

\displaystyle\varDelta E_{\alpha}(t,s)=\int_{0}^{t}(\tau)^{\alpha-1}E_{\alpha,\alpha}(\lambda\tau^{\alpha})F(t-\tau)\,d\tau,

(12)

\displaystyle F(t)=\int_{0}^{s}\dfrac{(t+s-\sigma)^{-\alpha}}{\Gamma(1-\alpha)}\dfrac{dE_{\alpha}}{d\sigma}(\lambda\sigma^{\alpha})\,d\sigma,

(13)

and
{dE_{\alpha}}(\lambda\sigma^{\alpha})/{d\sigma}=\lambda\sigma^{\alpha-1}E_{\alpha,\alpha}(\lambda\sigma^{\alpha})
for
\sigma>0
,
where
E_{\alpha,\alpha}
is the generalized Mittag-Leffler function (or Wiman’s function) defined by

\displaystyle E_{\alpha,\beta}(z)=\sum_{n=0}^{\infty}\dfrac{z^{n}}{\Gamma(\alpha n+\beta)}

(14)

for
z\in{\mathbb{C}}
and
\alpha,\beta\in{\mathbb{C}}
such that
\mathrm{Re}(\alpha)>0
and
\mathrm{Re}(\beta)>0
.

3.2
Optimal control problem with generalized discounted cost

In this paper, we assume that the error term
\varDelta E_{\alpha}(t,s)
for a small
s
is sufficiently small.

Let a real number
\alpha
be the fractional order such that
0<\alpha<1
.
Consider the infinite horizon optimal control problem for the system

\displaystyle\dot{x}(t)=f(x(t),u(t),t)

(15)

with the cost function

\displaystyle J=\int_{t}^{\infty}\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]L(x(\tau),u(\tau),\tau)\,d\tau

(16)

\displaystyle\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]=E_{\alpha}[\lambda(\tau-t)^{\alpha}]+\varDelta E_{\alpha}(\tau,-t)

(17)

for some time
t
such that
t_{0}\leq t\leq\infty
, where

\bar{E}_{\alpha}
is the approximated Mittag-Leffler function,

\lambda\in{\mathbb{R}}
,
x=x(t)\in{\mathbb{R}}^{n}
is the state,
u=u(t)\in{\mathbb{R}}^{m}
is the control,
f\colon M\to{\mathbb{R}}^{n}
is a smooth mapping, and
M
is an
n
-dimensional manifold.

Proposition 1
.

The infinite horizon optimal control problem for the system (
15
) with respect to the cost function (
16
)
can be formulated by

\displaystyle V(x,t)

\displaystyle=\inf_{u[t,t+dt]}\left(L(x,u,t)\,dt\right.

\displaystyle\qquad\qquad\left.+{E_{\alpha}(\lambda dt^{\alpha})}V(x+fdt,t+dt)\right),

(18)

where we have assumed that
V
is smooth, and the difference
\varDelta E_{\alpha}(t,s)
between
E_{\alpha}[\lambda(t+s)^{\alpha}]
and
E_{\alpha}(\lambda t^{\alpha})E_{\alpha}(\lambda s^{\alpha})
in (
11
) is sufficiently small.

Proof.

Consider the following direct calculation by dynamic programming:

\displaystyle V(x,t)=\inf_{u[t,\infty]}J

\displaystyle=\inf_{u[t,\infty]}\left(\int_{t}^{t^{\prime}}{\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\int_{t^{\prime}}^{\infty}{\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]}L(x(\tau),u(\tau),\tau)\,d\tau\right)

\displaystyle=\inf_{u[t,t^{\prime}]}\left\{\int_{t}^{t^{\prime}}{\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\inf_{u[t^{\prime},\infty]}\left(\int_{t^{\prime}}^{\infty}{\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]}L(x(\tau),u(\tau),\tau)\,d\tau\right)\right\}

\displaystyle=\inf_{u[t,t^{\prime}]}\left(\int_{t}^{t^{\prime}}{\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]}L(x(\tau),u(\tau),\tau)\,d\tau\right.

\displaystyle\qquad\left.+\,{E_{\alpha}(\lambda dt^{\alpha})}V(x(t^{\prime}),t^{\prime})\right),

(19)

where we have used
t^{\prime}=t+dt
and

\displaystyle\bar{E}_{\alpha}[\lambda(\tau-t)^{\alpha}]\mid_{t=t^{\prime}-dt}

\displaystyle\quad=E_{\alpha}[\lambda(\tau-t^{\prime}+dt)^{\alpha}]+\varDelta E_{\alpha}(\tau-t^{\prime},dt)

\displaystyle\quad=E_{\alpha}[\lambda(\tau-t^{\prime})^{\alpha}]E_{\alpha}(\lambda dt^{\alpha})

(20)

in the last equation.
Then, for an infinitesimal time
dt>0
, the above value function
V
can be written as (
18
). ∎

Lemma 3.1
.

The following relation holds:

\displaystyle{E_{\alpha}(\lambda dt^{\alpha})}V(x+fdt,t+dt)

\displaystyle\quad\approx V+\dfrac{\partial V}{\partial x}fdt+\dfrac{\partial V}{\partial t}dt+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}V

\displaystyle\qquad+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}\dfrac{\partial V}{\partial x}fdt+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}\dfrac{\partial V}{\partial t}dt.

(21)

Proof.

From the first order terms of the Taylor series expansion of (
18
),

\displaystyle V(x+fdt,t+dt)

\displaystyle\ =V(x,t)+\dfrac{\partial V}{\partial x}(x,t)fdt+\dfrac{\partial V}{\partial t}(x,t)dt+\mathcal{O}\left(dt^{2}\right),

(22)

and

\displaystyle E_{\alpha}(\lambda dt^{\alpha})

\displaystyle=1+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}+\mathcal{O}(dt^{2\alpha}),

(23)

we obtain the relation

\displaystyle{E_{\alpha}(\lambda dt^{\alpha})}V(x+fdt,t+dt)

\displaystyle\quad\cong\left(1+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}\right)\left(V+\dfrac{\partial V}{\partial x}fdt+\dfrac{\partial V}{\partial t}dt\right).

(24)

∎

Lemma 3.2
.

(
18
) can be written as

\displaystyle 0

\displaystyle=\inf_{u[t,t^{\prime}]}\left(L(x,u,t)dt+\dfrac{\partial V}{\partial x}fdt+\dfrac{\partial V}{\partial t}dt\right.

\displaystyle\quad+\left.\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}V+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}\dfrac{\partial V}{\partial x}fdt+\dfrac{\lambda dt^{\alpha}}{\Gamma(\alpha+1)}\dfrac{\partial V}{\partial t}dt\right)

\displaystyle=\inf_{u[t,t^{\prime}]}\left(L(x,u,t)+\dfrac{\partial V}{\partial x}f(x,u,t)+\dfrac{\partial V}{\partial t}(x,t)\right.

\displaystyle\qquad\qquad\left.+\lambda A(\alpha)\dfrac{\partial^{1-\alpha}V(x,t)}{\partial t^{1-\alpha}}\right),

(25)

where
t^{\prime}=t+dt
, and
A(\alpha)={(1-\alpha)^{\alpha-1}}/{\alpha^{\alpha}}
.

Proof.

Let us consider the fractional derivative of composite functions
(
Podlubny 1999
, p. 98)

\!\phantom{\ }{}_{a}^{\phantom{1}}D^{\alpha}_{\vphantom{1}t}f(g(t))

\displaystyle=\dfrac{(t-a)^{-\alpha}}{\Gamma(1-\alpha)}f(g(t))

\displaystyle\quad+\sum_{k=1}^{\infty}C^{\alpha}_{k}\dfrac{k!\,(t-a)^{k-\alpha}}{\Gamma(k-\alpha+1)}\sum_{m=1}^{k}\left(\!\phantom{\ }D^{m}_{g}f(g)\right)

\displaystyle\qquad\cdot\sum\prod_{r=1}^{k}\dfrac{1}{a_{r}!}\left(\dfrac{\!\phantom{\ }D^{r}_{t}g(t)}{r!}\right)^{a_{r}},

(26)

where
t>0
,
\sum
extends over all combinations of non-negative integer values of
a_{1},a_{2},\cdots,a_{k}

such that
\sum_{r=1}^{k}ra_{r}=k
, and
\sum_{r}^{k}a_{r}=m
.
By substituting
t^{\prime}=t+dt
to
t
with
a=t
in (
26
), we get

\!\phantom{\ }{}_{t}^{\phantom{1}}D^{\alpha}_{\vphantom{1}t^{\prime}}V(x(t^{\prime}))=\dfrac{dt^{-\alpha}}{\Gamma(1-\alpha)}V(x(t^{\prime}))

\displaystyle\quad+\sum_{k=1}^{\infty}C^{\alpha}_{k}\dfrac{k!\,dt^{k-\alpha}}{\Gamma(k-\alpha+1)}\sum_{m=1}^{k}\left(\!\phantom{\ }{}_{x}^{\phantom{1}}D^{m}_{\vphantom{1}x^{\prime}}V(x^{\prime})\right)

\displaystyle\qquad\cdot\sum\prod_{r=1}^{k}\dfrac{1}{a_{r}!}\left(\dfrac{\!\phantom{\ }{}_{t}^{\phantom{1}}D^{r}_{\vphantom{1}t^{\prime}}x(t^{\prime})}{r!}\right)^{a_{r}},

(27)

where
x^{\prime}=x(t^{\prime})
, and

\displaystyle C^{\alpha}_{k}=\dfrac{\Gamma(\alpha+1)}{\Gamma(k+1)\Gamma(\alpha-k+1)}.

(28)

Consider the approximation up to
k=1
in (
27
) as follows:

\!\phantom{\ }{}_{t}^{\phantom{1}}D^{\alpha}_{\vphantom{1}t^{\prime}}V(x(t^{\prime}))=\dfrac{dt^{-\alpha}}{\Gamma(1-\alpha)}V(x(t^{\prime}))

\displaystyle\ +C^{\alpha}_{1}\dfrac{dt^{1-\alpha}}{\Gamma(2-\alpha)}\left(\!\phantom{\ }{}_{x}^{\phantom{1}}D^{1}_{\vphantom{1}x^{\prime}}V(x^{\prime})\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}x(t^{\prime})\right)+{\mathcal{O}}(dt^{2-\alpha}),

(29)

where
C^{\alpha}_{1}={\Gamma(\alpha+1)}/{\Gamma(\alpha)}=\alpha
, and

a_{1}=1
is obtained from the relation
r\cdot a_{r}=k
with
r=1
and
k=1
.
Next, by substituting
1-\alpha
to
\alpha
in (
29
),
and multiplying
dt
from the right-side, the following relation is given

\!\phantom{\ }{}_{t}^{\phantom{1}}D^{1-\alpha}_{\vphantom{1}t^{\prime}}V(x(t^{\prime}))\,dt=\left[\dfrac{dt^{\alpha-1}}{\Gamma(1-(1-\alpha))}V(x(t^{\prime}))\right.

\displaystyle\quad+(1-\alpha)\dfrac{dt^{1-(1-\alpha)}}{\Gamma(2-(1-\alpha))}\left(\!\phantom{\ }{}_{x}^{\phantom{1}}D^{1}_{\vphantom{1}x^{\prime}}V(x^{\prime})\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}x(t^{\prime})\right)

\displaystyle\quad\left.+{\mathcal{O}}(dt^{2-(1-\alpha)})\right]dt

\displaystyle=\dfrac{dt^{\alpha}}{\Gamma(\alpha)}V(x(t^{\prime}))+(1-\alpha)\dfrac{dt^{\alpha}}{\Gamma(1+\alpha)}\left(\dfrac{\partial V}{\partial x^{\prime}}f\right)\,dt

\displaystyle\quad+{\mathcal{O}}(dt^{2+\alpha}).

(30)

Furthermore, we augmented (
30
) as a multi-variable expression for
x=\left[x_{1},x_{2},\cdots,x_{n},t\right]^{\top}
as follows:

\!\phantom{\ }{}_{t}^{\phantom{1}}D^{1-\alpha}_{\vphantom{1}t^{\prime}}V(x^{\prime},t^{\prime})\,dt

\displaystyle=\left[\dfrac{dt^{\alpha-1}}{\Gamma(\alpha)}V(x^{\prime},t^{\prime})+(1-\alpha)\dfrac{dt^{\alpha}}{\Gamma(1+\alpha))}\right.

\displaystyle\qquad\cdot\left(\!\phantom{\ }{}_{x}^{\phantom{1}}D^{1}_{\vphantom{1}x_{1}^{\prime}}V(x^{\prime},t^{\prime})\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}x_{1}(t^{\prime})+\!\phantom{\ }_{x}^{\phantom{1}}D^{1}_{\vphantom{1}x_{2}^{\prime}}V(x^{\prime},t^{\prime})\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}x_{2}(t^{\prime})\right.

\displaystyle\qquad\left.\left.+\cdots+\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}V(x^{\prime},t^{\prime})\!\phantom{\ }_{t}^{\phantom{1}}D^{1}_{\vphantom{1}t^{\prime}}t^{\prime}\right)\right]dt+{\mathcal{O}}(dt^{2+\alpha})

\displaystyle=\alpha\dfrac{dt^{\alpha}}{\Gamma(\alpha+1)}V(x^{\prime},t^{\prime})+(1-\alpha)\dfrac{dt^{\alpha}}{\Gamma(\alpha+1)}\left(\dfrac{\partial V}{\partial x^{\prime}}f+\dfrac{\partial V}{\partial t^{\prime}}\right)dt

\displaystyle\quad+{\mathcal{O}}(dt^{2+\alpha}).

(31)

Finally, the following first order relation with respect to
dt
has been obtained from (
31
):

\displaystyle\dfrac{1}{\alpha}\!\phantom{\ }_{t-dt}^{\phantom{1}}D^{1-\alpha}_{\vphantom{1}t}V(x,t)dt

\displaystyle=\dfrac{dt^{\alpha}}{\Gamma(\alpha+1)}V(x,t)+\dfrac{1-\alpha}{\alpha}\dfrac{dt^{\alpha}}{\Gamma(\alpha+1)}\left(\dfrac{\partial V}{\partial x}f+\dfrac{\partial V}{\partial t}\right)dt.

(32)

Moreover, we get

\displaystyle\dfrac{\mbox{\boldmath$\varsigma$}^{\alpha-1}}{\alpha}\!\phantom{\ }_{t-dt}^{\phantom{1}}D^{1-\alpha}_{\vphantom{1}t}V(x,t)\mbox{\boldmath$\varsigma$}\,dt

\displaystyle=\dfrac{(\mbox{\boldmath$\varsigma$}dt)^{\alpha}}{\Gamma(\alpha+1)}V(x,t)+\mbox{\boldmath$\varsigma$}\dfrac{(\mbox{\boldmath$\varsigma$}dt)^{\alpha}}{\Gamma(\alpha+1)}\left(\dfrac{\partial V}{\partial x}f+\dfrac{\partial V}{\partial t}\right)dt,

(33)

where we have defined
\mbox{\boldmath$\varsigma$}=(1-\alpha)/\alpha
.
We can substitute
\mbox{\boldmath$\varsigma$}dt
with the scaling parameter
\varsigma
to
dt
in the first equality of (
25
) without loss of generality.
Hence, the second equality of (
25
) is given. ∎

Theorem 3.3
.

From (
25
), the Hamilton-Jacobi-Bellman equation with extended discounted cost

\displaystyle-{\lambda}A(\alpha)\dfrac{\partial^{1-\alpha}V(x,t)}{\partial t^{1-\alpha}}-\dfrac{\partial V}{\partial t}(x,t)

\displaystyle\qquad=\inf_{u}\left(L(x,u,t)+\dfrac{\partial V}{\partial x}(x,t)f(x,u,t)\right)

\displaystyle\qquad=\inf_{u}H(x,u,p,t),

(34)

can be derived, where the pre-Hamiltonian

\displaystyle H(x,u,p,t)=L(x,u,t)+\dfrac{\partial V}{\partial x}(x,t)f(x,u,t)

(35)

with
p=(\partial V/\partial x)^{\top}(x,t)
has been defined.

4
Conclusion

This paper proposed the Hamilton-Jacobi-Bellman equation of nonlinear optimal control problems for cost functions including
a fractional discount rate described by Mittag-Leffler functions.
The authors attempt to integrate this formulation into the stable manifold method
(
Sakamoto and Van der Schaft 2008
)
that is an exact numerical solver of
Hamilton-Jacobi equations in nonlinear optimal control problems.
