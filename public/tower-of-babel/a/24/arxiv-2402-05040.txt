Blow-up of solutions for a semilinear parabolic equation with nonlinear memory and absorption under nonlinear nonlocal boundary condition
Alexander Gladkov

Abstract
. In this paper we consider initial boundary value problem for a parabolic equation with nonlinear memory and absorption under nonlinear nonlocal boundary condition. We prove global existence and blow-up of solutions.

1.
Introduction

In this paper we consider the following parabolic equation
with nonlinear memory and absorption

u_{t}=\Delta u+a\int_{0}^{t}u^{q}(x,\tau)\,d\tau-bu^{m},\;x\in\Omega,\;t>0,

(1.1)

under nonlinear nonlocal boundary condition

\frac{\partial u(x,t)}{\partial\nu}=\int_{\Omega}{k(x,y,t)u^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;t>0,

(1.2)

and initial datum

u(x,0)=u_{0}(x),\;x\in\Omega,

(1.3)

where
a,b,\,q,\,m,\,l
are positive numbers,
\Omega
is a bounded domain in
\mathbb{R}^{N}

for
N\geq 1
with smooth boundary
\partial\Omega
,
\nu
is unit
outward normal on
\partial\Omega.

Throughout this paper we suppose that the functions

k(x,y,t)
and
u_{0}(x)
satisfy the following conditions:

k(x,y,t)\in C(\partial\Omega\times\overline{\Omega}\times[0,+\infty)),\;k(x,y,t)\geq 0;

u_{0}(x)\in C^{1}(\overline{\Omega}),\;u_{0}(x)\geq 0\textrm{ in
}\Omega,\;\frac{\partial u_{0}(x)}{\partial\nu}=\int_{\Omega}{k(x,y,0)u_{0}^{l}(y)}\,dy\textrm{ on }\partial\Omega.

Various phenomena in the natural sciences and engineering lead to the nonclassical mathematical models subject to nonlocal boundary conditions.
For global existence and blow-up of solutions for parabolic equations and systems
with nonlocal boundary conditions we refer to
[
1
]
–
[
10
]
and the references therein.
In particular, the blow-up problem for parabolic equations with nonlocal boundary condition

u(x,t)=\int_{\Omega}k(x,y,t)u^{l}(y,t)\,dy,\;x\in\partial\Omega,\;t>0,

(1.4)

was considered in
[
11
]
–
[
17
]
. Blow-up problem for (
1.1
), (
1.4
), (
1.3
) was studied in
[
14
]
.
Initial boundary value problems for parabolic equations with
nonlocal boundary condition (
1.2
) were studied in
[
18
]
–
[
25
]
.
So, the problem (
1.1
)–(
1.3
) with
a=0
was investigated in
[
20
,
21
]
.
Initial-boundary value problems with nonlinear memory for parabolic equations
were addressed in many papers also (see, for example,
[
26
]
–
[
33
]
).
Local existence of solutions and comparison principle for (
1.1
)–(
1.3
) have been proved in
[
33
]
.

The aim of this paper is to investigate global existence and blow-up of solutions of (
1.1
)–(
1.3
).

This paper is organized as follows. In the next section we present finite time blow-up results for solutions with nontrivial initial data
and with large initial data. In Section 3 we prove the global existence of solutions for any initial data.

2.
Blow-up in finite time

We begin with definition of a supersolution, a subsolution and a solution of (
1.1
)–(
1.3
). Let

Q_{T}=\Omega\times(0,T),\;S_{T}=\partial\Omega\times(0,T)
,

\Gamma_{T}=S_{T}\cup\overline{\Omega}\times\{0\}
,
T>0
.

Definition 2.1
.

We say that a nonnegative function
u(x,t)\in C^{2,1}(Q_{T})\cap C^{1,0}(Q_{T}\cup\Gamma_{T})
is a supersolution
of (
1.1
)–(
1.3
) in
Q_{T}
if

u_{t}\geq\Delta u+a\int_{0}^{t}u^{q}(x,\tau)\,d\tau-bu^{m},\;(x,t)\in Q_{T},

(2.1)

\frac{\partial u(x,t)}{\partial\nu}\geq\int_{\Omega}{k(x,y,t)u^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;0<t<T,

(2.2)

u(x,0)\geq u_{0}(x),\;x\in\Omega,

(2.3)

and
u(x,t)\in C^{2,1}(Q_{T})\cap C^{1,0}(Q_{T}\cup\Gamma_{T})
is a
subsolution of (
1.1
)–(
1.3
) in
Q_{T}
if
u\geq 0
and
it satisfies (
2.1
)–(
2.3
) in the reverse
order. We say that
u(x,t)
is a solution of
problem (
1.1
)–(
1.3
) in
Q_{T}
if
u(x,t)
is both a
subsolution and a supersolution of (
1.1
)–(
1.3
) in

Q_{T}
.

To prove the main results we use the comparison principle and the positiveness of a solution
which have been proved in
[
33
]
.

Theorem 2.2
.

Let
\overline{u}
and
\underline{u}
be a
supersolution and a subsolution of problem
(
1.1
)–(
1.3
) in
Q_{T},
respectively. Suppose that

\underline{u}(x,t)>0
or
\overline{u}(x,t)>0
in
{Q}_{T}\cup\Gamma_{T}
if
\min(q,l)<1.
Then
\overline{u}(x,t)\geq\underline{u}(x,t)
in
{Q}_{T}\cup\Gamma_{T}.

Theorem 2.3
.

Let
{u}
be a solution of problem
(
1.1
)–(
1.3
) in
Q_{T}.
Let
u_{0}(x)\not\equiv 0
in
\Omega
and
m\geq 1.
Then

u(x,t)>0
in
{Q}_{T}\cup S_{T}.
If
u_{0}(x)>0
in
\overline{\Omega}
and
m<1
then
u(x,t)>0
in
{Q}_{T}\cup\Gamma_{T}.

To prove blow-up result we need the following statement.

Lemma 2.4
.

Let
{u}
be a solution of problem (
1.1
)–(
1.3
) in
Q_{T}
with
u_{0}(x)\not\equiv 0.
Then

\int_{\Omega}u(x,t)\,dx\geq c_{1}\;\textrm{ for}\;t\in[0,T],

(2.4)

where positive constant
c_{1}
does not depend on
T.

Proof.

Since
u_{0}(x)\not\equiv 0
there exists
t_{0}>0
such that

\int_{\Omega}u(x,t)\,dx>0\;\textrm{ for }\;t\in[0,t_{0}].

(2.5)

Suppose that
T>t_{0}
and
m\geq 1.
By Theorem
2.3
we have

u(x,t)>0\;\textrm{ in}\;{Q}_{T}\cup S_{T}.

Then there exists
c_{2}>0
such that

u(x,t_{0})\geq c_{2}\;\textrm{and}\;a\int_{0}^{t_{0}}u^{q}(x,t)\,dt\geq c_{2}\;\textrm{ for }\;x\in\overline{\Omega}.

Let us consider the following problem

v_{t}=\Delta v+a\int_{0}^{t_{0}}u^{q}(x,\tau)\,d\tau+a\int_{t_{0}}^{t}v^{q}(x,\tau)\,d\tau-bv^{m},\;(x,t)\in Q_{T}\setminus\overline{Q_{t_{0}}},

(2.6)

\frac{\partial v(x,t)}{\partial\nu}=\int_{\Omega}{k(x,y,t)v^{l}(y,t)}\,dy,\;x\in\partial\Omega,\;t_{0}<t<T,

(2.7)

v(x,t_{0})=u(x,t_{0}),\;x\in\Omega.

(2.8)

Let

c_{3}=\min\left\{c_{2},\left[\frac{c_{2}}{b}\right]^{\frac{1}{m}}\right\}.

It is easy to see that
u(x,t)
and
v(x,t)=c_{3}
are a solution and a subsolution of problem (
2.6
)–(
2.8
) in
Q_{T}\setminus\overline{Q_{t_{0}}},
respectively. By comparison principle for (
2.6
)–(
2.8
) (see Theorem 3 in
[
33
]
for similar problem)

u(x,t)\geq c_{3}\;\textrm{in}\;Q_{T}\setminus\overline{Q_{t_{0}}}.

(2.9)

From (
2.5
), (
2.9
) we obtain (
2.4
).

Now let
m<1.

Integrating (
1.1
) over
\Omega
and using Green’s identity, we obtain

\begin{split}\int_{\Omega}u_{t}(x,t)\,dx&=\int_{\partial\Omega}\int_{\Omega}k(x,y,t)u^{l}(y,t)\,dy\,dS_{x}+a\int_{\Omega}\int_{0}^{t}u^{q}(x,\tau)\,d\tau\,dx\\
&-b\int_{\Omega}u^{m}(x,t)\,dx.\end{split}

(2.10)

Let us introduce auxiliary function

J_{1}(t)=\int_{\Omega}u(x,t)\,dx.

Applying to (
2.10
) Hölder’s inequality, we have

J^{\prime}_{1}(t)>c_{4}-b|\Omega|^{1-m}J^{m}_{1}(t)\;\textrm{for}\;t\geq t_{0},

where

c_{4}=\frac{a}{2}\int_{0}^{t_{0}}\int_{\Omega}u^{q}(x,\tau)\,dx\,d\tau>0.

Let

c_{5}=\min\left\{J_{1}(t_{0}),\left[\frac{c_{4}}{b|\Omega|^{1-m}}\right]^{\frac{1}{m}}\right\}.

Obviously,
J^{\prime}_{1}(t)>0
if
J_{1}(t)\leq\left[\frac{c_{4}}{b|\Omega|^{1-m}}\right]^{1/m}.
Therefore

J_{1}(t)\geq c_{5}\;\textrm{for}\;t\geq t_{0}

and (
2.4
) holds.
∎

To formulate finite time blow-up result we introduce

\underline{k}(t)=\inf_{\Omega}\int_{\partial\Omega}k(x,y,t)\,dS_{x}

and suppose that

\underline{k}(0)>0

(2.11)

and for some
k_{1}>0,\,

t_{1}>0

\int_{\partial\Omega}k(x,y,t)\,dS_{x}\geq k_{1}\;\textrm{ for any}\;y\;\in\Omega\;\textrm{ and}\;t\geq t_{1}.

(2.12)

Theorem 2.5
.

Let
q>\max(m,1)
or
l>\max(m,1)
and (
2.12
) hold. Then solutions of (
1.1
)–(
1.3
) blow up in finite time for any
u_{0}(x)\not\equiv 0.
If
l>\max(m,1)
and (
2.11
) holds then solutions of (
1.1
)–(
1.3
) blow up in finite time for large enough initial data.

Proof.

Suppose that
q>\max(m,1)
and
u_{0}(x)\not\equiv 0.
Let us introduce auxiliary function

J_{2}(t)=\int_{0}^{t}\int_{\Omega}u^{q}(x,\tau)\,dxd\tau.

Applying Hölder’s inequality to the right hand side of (
2.10
), we obtain

J_{1}^{\prime}(t)\geq aJ_{2}(t)-b|\Omega|^{(q-m)/q}\left(J_{2}^{\prime}(t)\right)^{m/q}.

(2.13)

By Hölder’s inequality, we have

J_{2}^{\prime}(t)=\int_{\Omega}u^{q}(x,t)\,dx\geq|\Omega|^{1-q}J_{1}^{q}(t).

(2.14)

Slightly modifying the proof of Lemma 5.3 in
[
34

from (
2.4
), (
2.13
), (
2.14
) we conclude that there exists
T\in(0,\infty)
such that

\lim_{t\to T}(J_{1}(t)+J_{2}(t))=\infty,

which implies that

blows up in a finite time for any nonnegative nontrivial initial datum.

Let
l>\max(m,1)
and (
2.12
) hold now. Applying Hölder’s inequality for
t\geq t_{1}
to the right hand side of (
2.10
), we obtain

J_{1}^{\prime}(t)\geq a\int_{0}^{t}\int_{\Omega}u^{q}(x,\tau)\,dxd\tau+k_{1}J_{3}(t)-b|\Omega|^{(l-m)/l}J_{3}^{m/l},

(2.15)

where

We note that

a\int_{0}^{t}\int_{\Omega}u^{q}(x,\tau)\,dxd\tau+k_{1}J_{3}(t)-b|\Omega|^{(l-m)/l}J_{3}^{m/l}\geq\frac{k_{1}}{2}J_{3}(t)

(2.17)

Then from (
2.15
) – (
2.17

(2.18)

Thus solutions of (
1.1
)–(
1.3

u_{0}(x)\not\equiv 0
if

a\int_{0}^{\infty}\int_{\Omega}u^{q}(x,\tau)\,dxd\tau=\infty.

We suppose now that

\int_{0}^{\infty}\int_{\Omega}u^{q}(x,\tau)\,dxd\tau=M<\infty.

(2.19)

Integrating (
2.10
) by

, we obtain

\begin{split}\int_{\Omega}u(x,t)\,dx&=\int_{\Omega}u_{0}(x)\,dx+\int_{0}^{t}\int_{\partial\Omega}\int_{\Omega}k(x,y,\tau)u^{l}(y,\tau)\,dy\,dS_{x}\,d\tau\\

(2.20)

Using Hölder’s inequality and Lemma

, we have

\int_{t_{1}}^{t}\int_{\Omega}u^{l}(y,\tau)\,dy\,d\tau\geq[(t-t_{1})|\Omega|]^{-(l-1)}\left[\int_{t_{1}}^{t}\int_{\Omega}u(y,\tau)\,dy\,d\tau\right]^{l}\geq c_{1}^{l}|\Omega|^{-(l-1)}(t-t_{1}).

(2.21)

If
m\leq q
then applying Hölder’s inequality, we get

(2.22)

Now from (
2.12
), (
2.20
) – (

as

Then by Hölder’s inequality

Thus solutions of (

)–(
1.3
) blow up in finite time for any
u_{0}(x)\not\equiv 0.

If
m>q
then it is easy to check that

bu^{m}(x,t)\leq b\left[\frac{2b}{k_{1}}\right]^{\frac{m-q}{l-m}}u^{q}(x,t)+\frac{k_{1}}{2}u^{l}(x,t).

(2.23)

Now from (

), (

) – (

)–(

) for any
u_{0}(x)\not\equiv 0.

Let
l>\max(m,1)
and (
2.11
) hold now. Then there exists

such that
\underline{k}(t)>0
for
t\in[0,T_{0}].
Denote

Applying Hölder’s inequality to (

), we obtain for

J_{1}^{\prime}(t)\geq k_{0}J_{3}(t)-b|\Omega|^{(l-m)/l}J_{3}^{m/l}(t)=J_{3}(t)\left[k_{0}-b|\Omega|^{(l-m)/l}J_{3}^{(m-l)/l}(t)\right].

(2.24)

By Hölder’s inequality, we have

J_{3}(t)=\int_{\Omega}u^{l}(x,t)\,dx\geq|\Omega|^{1-l}J_{1}^{l}(t).

(2.25)

Let

Then

J_{3}(0)\geq|\Omega|\left\{\frac{2b}{k_{0}}\right\}^{\frac{l}{l-m}},

3.
Global existence

The proof of a global existence result relies on the continuation principle and the
construction of a supersolution.

Theorem 3.1
.

Let at least one from the following conditions hold:

a).
\max(q,l)\leq 1;

b).
\max(q,l)>1
and
l<m,\,q\leq m.

Then every solution of (
1.1
)–(
1.3
) is global.

Proof.

In order to prove global existence of solutions we construct a
suitable explicit supersolution of (
1.1
)–(
1.3
) in

Q_{T}
for any positive
T.
Suppose at first that
\max(q,l)\leq 1.

Since
k(x,y,t)
is a continuous function, there exists a constant

K>0
such that

k(x,y,t)\leq K

in
\partial\Omega\times Q_{T}.
Let
\lambda_{1}
be the first
eigenvalue of the following problem

\begin{cases}\Delta\varphi+\lambda\varphi=0,\;x\in\Omega,\\
\varphi(x)=0,\;x\in\partial\Omega,\end{cases}

and
\varphi(x)
be the corresponding eigenfunction with

\sup\limits_{\Omega}\varphi(x)=1
. It is well known,

\varphi(x)>0
in
\Omega
and
\max\limits_{\partial\Omega}\partial\varphi(x)/\partial\nu<0.

Now, let
\overline{u}(x,t)
be defined as

\overline{u}(x,t)=\frac{C\exp(\mu t)}{c\varphi(x)+1},

(3.1)

where constants
C,\mu
and
c
are chosen to satisfy the
inequalities:

c\geq\max\left\{K\int_{\Omega}\frac{dy}{(\varphi(y)+1)^{l}}\max_{\partial\Omega}\left(-\frac{\partial\varphi}{\partial\nu}\right)^{-1},1\right\},

(3.2)

C\geq\max\{\sup_{\Omega}(c\varphi(x)+1)u_{0}(x),1\}

(3.3)

and

\mu\geq\lambda_{1}+2c^{2}\sup_{\Omega}\frac{|\nabla\varphi|^{2}}{(c\varphi(x)+1)^{2}}+a(c+1)^{1-q}+\frac{1}{q}.

It is not difficult to check that
\overline{u}(x,t)
is a supersolution of (
1.1
)–(
1.3
) in
Q_{T}.
Then by Theorem
2.2

u(x,t)\leq\overline{u}(x,t)\,\,\,\textrm{in}\,\,\,\overline{Q}_{T}.

For
l\leq 1,\,1<q\leq m
the function
\overline{u}(x,t)
in (
3.1
) is a supersolution of (
1.1
)–(
1.3
) in
Q_{T}
if (
3.2
), (
3.3
) hold and

\mu\geq\lambda_{1}+2c^{2}\sup_{\Omega}\frac{|\nabla\varphi|^{2}}{(c\varphi(x)+1)^{2}}+\frac{a(c+1)^{m-q}}{qb}.

Suppose now that
1<l<m,\,q\leq m.
To construct a supersolution we use the change of variables in a
neighborhood of
\partial\Omega
as in
[
35
]
. Let

\overline{x}\in\partial\Omega
and
\widehat{n}(\overline{x})
be the inner unit normal to
\partial\Omega
at the
point
\overline{x}.
Since
\partial\Omega
is smooth it is well
known that there exists
\delta>0
such that the mapping
\psi:\partial\Omega\times[0,\delta]\to\mathbb{R}^{n}
given by

\psi(\overline{x},s)=\overline{x}+s\widehat{n}(\overline{x})

defines new coordinates (
\overline{x},s)
in a neighborhood of

\partial\Omega
in
\overline{\Omega}.
A straightforward
computation shows that, in these coordinates,
\Delta
applied to
a function
g(\overline{x},s)=g(s),
which is independent of the
variable
\overline{x},
evaluated at a point
(\overline{x},s)
is
given by

\Delta g(\overline{x},s)=\frac{\partial^{2}g}{\partial s^{2}}(\overline{x},s)-\sum_{j=1}^{n-1}\frac{H_{j}(\overline{x})}{1-sH_{j}(\overline{x})}\frac{\partial g}{\partial s}(\overline{x},s),

(3.4)

where
H_{j}(\overline{x})
for
j=1,...,n-1,
denote the principal
curvatures of
\partial\Omega
at
\overline{x}.
For
0\leq s\leq\delta

and small
\delta
we have

\left|\sum_{j=1}^{n-1}\frac{H_{j}(\overline{x})}{1-sH_{j}(\overline{x})}\right|\leq\overline{c}.

(3.5)

Let
0<\varepsilon<\omega<\min(\delta,1),\,

r>a/(bq),\,

\max(1/l,2/(m-1))<\beta<2/(l-1),\,

A\geq\sup_{\Omega}u_{0}(x).

We modify a supersolution in
[
12
]

of coordinates
(\overline{x},s,t)
define

\overline{v}(x,t)=\overline{v}((\overline{x},s),t)=\left(\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta}{\gamma}}+A\right)\exp(rt),

(3.6)

where
s_{+}=\max(s,0).
For points in
\overline{Q_{T}}\setminus Q_{\delta,T}

we set
\overline{v}(x,t)=A\exp(rt).
We prove that
\overline{v}(x,t)

is the supersolution of (
1.1
)–(
1.3
) in
Q_{T}.

It is not difficult to check that

\left|\frac{\partial\overline{v}}{\partial s}\right|\leq\beta\min\left(\left[D(s)\right]^{\frac{\gamma+1}{\gamma}}\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta+1}{\gamma}},\,(s+\varepsilon)^{-(\beta+1)}\right)\exp(rt),

(3.7)

\left|\frac{\partial^{2}\overline{v}}{\partial s^{2}}\right|\leq\beta(\beta+1)\min\left(\left[D(s)\right]^{\frac{2(\gamma+1)}{\gamma}}\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta+2}{\gamma}},\,(s+\varepsilon)^{-(\beta+2)}\right)\exp(rt),

where

Then

\overline{\varepsilon}>0

(3.9)

where
{\overline{s}}=[\overline{\varepsilon}/(1+\overline{\varepsilon})]^{1/\gamma}\omega-\varepsilon,

\varepsilon<[\overline{\varepsilon}/(1+\overline{\varepsilon})]^{1/\gamma}\omega.
We denote

Lv\equiv v_{t}-\Delta v-a\int_{0}^{t}v^{q}(x,\tau)\,d\tau+bv^{m}.

(3.10)

By (
3.4
)–(
3.10
) we can choose

\overline{\varepsilon}
small and
A

Q_{{\overline{s}},T}

\displaystyle L\overline{v}

\displaystyle\geq\left\{r\left(\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta}{\gamma}}+A\right)+b\left(\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta}{\gamma}}+A\right)^{m}\exp[r(m-1)t]\right.

\displaystyle-\beta(\beta+1)\left[D(s)\right]^{\frac{2(\gamma+1)}{\gamma}}\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta+2}{\gamma}}+\beta\overline{c}\left[D(s)\right]^{\frac{\gamma+1}{\gamma}}\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta+1}{\gamma}}

\displaystyle-\left.\frac{a}{rq}\left(\left[(s+\varepsilon)^{-\gamma}-\omega^{-\gamma}\right]_{+}^{\frac{\beta}{\gamma}}+A\right)^{q}\exp[r(q-1)t]\right\}\exp(rt)\geq 0.

Let
s\in[{\overline{s}},\delta].
From (
3.4
)–(
