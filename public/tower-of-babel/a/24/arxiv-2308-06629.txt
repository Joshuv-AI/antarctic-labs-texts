Optimal FIFO grouping in public transit networks
Steil, Patrick

Abstract




1
Introduction

This technical report is about grouping public transit vehicles (
trips
) into a set of routes (or, as they are more commonly known:
lines
) so that two vehicles of the same route do not overtake each other. We say that such a set of routes satisfies the FIFO property. A natural question is: Given a set of trips, find a minimal FIFO grouping into routes. This is especially interesting for certain route planning algorithms since a better (
smaller
) route grouping leads to a better runtime. This contribution is structured as follows: First, all necessary details are formalised and defined, and then the algorithmic complexity of this problem is explained and proven.

2
Definitions

We now introduce notations and definitions.
A timetable consists of a set of stations
\mathcal{S}
, i.e., places where passengers can hop on and off vehicles, and a set of trips
\mathcal{T}
, i.e., vehicles that travel through the network.
A trip
T\in\mathcal{T}
consists of a sequence of (chronological) events, where the
i
’th event
T[i]=\uptau^{i}
represents the arrival and departure of the vehicle at the
i
’th stop
\uptau^{i}_{\mathrm{stop}}\in\mathcal{S}
along its stop sequence
\mathcal{S}\left(T\right)
.
The departure time of
\uptau
is indicated by
\uptau_{\mathrm{dep}}
, the arrival time by
\uptau_{\mathrm{arr}}
.
We require
\uptau^{i}_{\mathrm{arr}}\leq\uptau^{i}_{\mathrm{dep}}\leq\uptau^{i+1}_{\mathrm{arr}}\leq\uptau^{i+1}_{\mathrm{dep}}\;\forall i\in\left[\left|T\right|-1\right]
1
1

1

\left[n\right]\equiv\left[1,n\right]\cap\mathbb{N}
.
Given two trips
A\neq B\in\mathcal{T},\;\mathcal{S}\left(A\right)=\mathcal{S}\left(B\right)
, we define
A\preceq B
as “
A
being earlier than
B
” if the following conditions hold
\forall i\in\left[\left|A\right|\right]
:

\displaystyle A[i]_{\mathrm{stop}}=B[i]_{\mathrm{stop}}

(1)

\displaystyle\left(A[i]_{\mathrm{arr}}\leq B[i]_{\mathrm{arr}}\right)\;\text{and}\;\left(A[i]_{\mathrm{dep}}\leq B[i]_{\mathrm{dep}}\right)

(2)

If
\exists j\in\left[\left|A\right|\right]:\left(A[j]_{\mathrm{arr}}<B[j]_{\mathrm{arr}}\right)\vee\left(A[j]_{\mathrm{dep}}<B[j]_{\mathrm{dep}}\right)
, we write
A\prec B
.
We say
A
and
B
do not “overtake” each other if either
A\preceq B
or vice versa.
A route
R=\left\{T_{1},T_{2},\dots\right\}
is a set of trips, such that one can order all trips
T_{1}\preceq T_{2}\preceq\dots
, i.e., no trip overtakes another trip on this route
R
.
A directed
graph

G=\left(V,E\right)
is a tuple of vertices
V
and edges
E\subseteq V\times V
.
A
comparability
graph is a directed graph
G=\left(V,E\right)
, with a transitive orientation
F\subseteq E
.
An orientation
F
is defined as
\left(v,w\right)\in F\iff\left(w,v\right)\notin F
such that every edge
e\in E
is “oriented” by
F
.
For the following definitions, let
G=\left(V,E\right)
be a graph.
We call a set of vertices
C\subseteq V
a
clique
, if all vertices are pairwise connected.
The
clique cover
problem asks for a partition
\mathcal{C}
of
V
into cliques.
Finding a minimal clique cover for a graph is
{\mathsf{NP}}
-hard
[
2
]
.

3
Problem Statement & Proof

One trivial and valid FIFO grouping is to allow a new route for each trip.
As mentioned in the introduction, it is necessary, from an algorithmic point of view, to minimise the number of FIFO routes.
Nevertheless, how hard is it to find an optimal FIFO grouping?
We prove this problem is solvable in
{\mathsf{P}}
, meaning a polynomial time algorithm exists to find such an optimal FIFO grouping.

Theorem 1
.

Given a set of trips
\mathcal{T}
, finding a minimal FIFO route grouping such that no two trips of the same route overtake each other is solvable in polynomial time.

Proof.

We will find such a FIFO route grouping by transforming the problem into multiple comparability graphs and finding a smallest clique cover
\mathcal{C}
for each of these graphs.
Each clique
C\in\mathcal{C}
corresponds to a route
R
. Since there exists a polynomial time algorithm which computes
\mathcal{C}
given a comparability graph
[
1
]
, Theorem
1
follows.
For every distinct stop sequence
\sigma=\left<s_{1},s_{2},\dots,s_{k}\right>
which occurs in
\mathcal{T}
(meaning
\exists T\in\mathcal{T}:\mathcal{S}\left(T\right)=\sigma
), we create a graph
G_{\sigma}=\left(\left\{T\in\mathcal{T}\;|\;\mathcal{S}\left(T\right)=\sigma\right\},F_{\sigma}\right)
.
F_{\sigma}
is defined by the following (with
T\neq T^{\prime}\in G_{\sigma}
):

\left(T,T^{\prime}\right)\in F_{\sigma}\iff T\preceq T^{\prime}

(3)

We need to show that
F_{\sigma}
is a transitive orientation.
Let
A\neq B\neq C\in G_{\sigma}
and
\left(A,B\right),\left(B,C\right)\in F_{\sigma}
.
We show that
\left(A,C\right)\in F_{\sigma}
, i.e., both equations (
1
) and (
2
) hold.
Note that (
1
) follows by construction of
G_{\sigma}
. As for (2):
We know, that
\forall i\in\left[\left|A\right|\right]

\displaystyle\left(A[i]_{\mathrm{arr}}\leq B[i]_{\mathrm{arr}}\right)\;\text{and}\;\left(A[i]_{\mathrm{dep}}\leq B[i]_{\mathrm{dep}}\right)

\displaystyle\left(B[i]_{\mathrm{arr}}\leq C[i]_{\mathrm{arr}}\right)\;\text{and}\;\left(B[i]_{\mathrm{dep}}\leq C[i]_{\mathrm{dep}}\right)

hold.
It follows:

\displaystyle\Rightarrow

\displaystyle\left(A[i]_{\mathrm{arr}}\leq C[i]_{\mathrm{arr}}\right)\;\text{and}\;\left(A[i]_{\mathrm{dep}}\leq C[i]_{\mathrm{dep}}\right)

\displaystyle\Rightarrow

\displaystyle A\preceq C\iff\left(A,C\right)\in F_{\sigma}

∎

Note

Preliminary results on real-life datasets (GTFS feeds from e.g., Germany, Switzerland, …) show that a greedy approach finds the same number of FIFO routes as the optimal algorithm. Both algorithms are implemented here
https://github.com/TransitRouting/Arc-FlagTB
. This was to be expected since vehicles of the same route do not overtake each other or relatively rarely in reality.
