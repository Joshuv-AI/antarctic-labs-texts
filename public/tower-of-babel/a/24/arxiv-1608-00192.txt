Game Theoretic Control of Multi-Agent Systems footnoteinfo
Ting Liu, Jinhuan Wang, Daizhan Cheng

Abstract
Control of multi-agent systems via game theory is investigated. Assume a system level object is given, the utility functions for individual agents are designed to convert a multi-agent system into a potential game. First, for fixed topology, a necessary and sufficient condition is given to assure the existence of local information based utility functions. Then using local information the system can converge to a maximum point of the system object, which is a Nash equilibrium. It is also proved that a networked evolutionary potential game is a special case of this multi-agent system. Second, for time-varying topology, the state based potential game is utilized to design the optimal control. A strategy based Markov state transition process is proposed to assure the existence of state based potential function. As an extension of the fixed topology case, a necessary and sufficient condition for the existence of state depending utility functions using local information is also presented. It is also proved that using better reply with inertia strategy, the system converges to a maximum strategy of the state based system object, which is called the recurrent state equilibrium.



keywords

Finite game, (state based) potential function, multi-agent systems, designed utility function, semi-tensor product of matrices.

Game Theoretic Approach

Consider a multi-agent system. Assume a system level objective function is given. This paper considers whether the system designer is able to design local information based utility functions for individual agents, such that the multi-agent system becomes a networked potential game with the objective function as the potential function. Then as the agents using their local information to maximize their utility functions the overall system can maximize the (system level) objective function. The paper consists mainly of two parts: First, the fixed topology case is considered. A necessary and sufficient condition is obtained to assure the existence of local information based utility functions. Then we show that the networked evolutionary potential games are special case of this kind of multi-agent systems.

Second, the case of time-varying topology is investigated. The concepts and results about state based potential game proposed by J.R. Marden
[
14
]
have been used and combined with our previous results. Similar to fixed topology case, a necessary and sufficient condition is also obtained. Certain state transition process is proposed as strategy depending Markov process, which assures the non-decreasing requirement of the state based potential function. An illustrative example is presented, which shows that the game theoretic control makes the multi-agent system reach consensus with probability
1
.

The rest of this paper is organized as follows: Section 2 provides some necessary preliminaries, including (i) semi-tensor product of matrices, which is a basic tool in our approach; (ii)the potential equation, which is a key result used in this paper; (iii) networked potential game, which is an important example of the multi-agent systems concerned in this paper. Section 3 considers the game theoretic control for fixed topology multi-agent systems. A necessary and sufficient condition is presented. It is also shown that networked potential games meet the requirement. The game theoretic control for time-varying topology is discussed in Section 4. State based potential game is reviewed first. A necessary and sufficient conditions is also obtained. An illustrative example is presented. Section 5 is a brief conclusion.

Networked Evolutionary Games

Definition 11

[
7
]
A networked evolutionary game (NEG), denoted by
\Gamma=\{(N,E),G,\Pi\}
, consists of

\displaystyle\begin{cases}a_{1}(t+1)=f_{1}(a_{1}(t),\cdots,a_{n}(t))\\

where

,

.

Using vector form expression of the strategies, (

\displaystyle a(t+1)=La(t),

where

\displaystyle c_{i}(t)=\mathop{\sum}\limits_{j\in U(i)\backslash\{i\}}c_{ij},\;i\in N.

Assume the SUR used is MBRA, that is

\displaystyle a_{i}(t+1)\in\argmax_{a_{i}\in S_{i}}(c_{i}(a_{i},a_{-i}(t)):=\BR_{i}(t),

where the elements of

•

If

\begin{array}[]{l}a_{i}(t+1)=a^{i}_{j},~\mbox{with probability}~\frac{1}{\mu_{i}(t)},\\

If only the local information is allowed to use, then (

.

If only the local information is allowed to use, the convergence described in Theorem

is not assured, unless the utilities are themselves local information depending. That is why we need to design the local information depending utilities.

State Based Potential Games

4.1
A Brief Review

The state based potential game is proposed in
[
14
]
. This subsection briefly review some related basic concepts and results.

Definition 17

1.

A finite state based evolutionary game is a tuple
G=\{N,S,C,X,P\}
, where
N=\{1,2,\cdots,n\}
is the set of players;
S=\prod_{i=1}^{n}S_{i}
is the strategy profile;
C=\{c_{1},\cdots,c_{n}\}
is the set of payoff (utility) functions, and
c_{i}:X\times S\rightarrow{\mathbb{R}}
;
X
is the state space;
P:X\times S\rightarrow\triangle(X)
is the the probability distributions over the finite state space
X
.

2.

X=\{x_{1},\cdots,x_{r}\}
, where
r=\left|X\right|
. Similar to
a_{i}\in\Delta_{k_{i}}
, we can also to express states in vector form as

x_{i}\sim\delta_{r}^{i},\quad i=1,\cdots,r.

3.

The state
x(t)
satisfies

\displaystyle x(t+1)\sim P\left(x(t),a(t)\right),

(33)

which can be expressed into its algebraic state space form as

\displaystyle x(t+1)=M_{P}x(t)a(t),

(34)

where
a(t)=\ltimes_{i=1}^{n}a_{i}(t)
.

4.

The strategy dynamics of an evolutionary game is of the following form

\displaystyle\begin{cases}a_{1}(t+1)=f_{1}(x(t+1),a(t),c(t))\\
a_{2}(t+1)=f_{2}(x(t+1),a(t),c(t))\\
\vdots\\
a_{n}(t+1)=f_{n}(x(t+1),a(t),c(t)),\end{cases}

(35)

where
c(t)=(c_{1}(t),c_{2}(t),\cdots,c_{n}(t))
.
The dynamics is determined by an SUR. In this paper we assume
f_{i}
is independent of
c
, hence it can be expressed in algebraic state space form as

\displaystyle a(t+1)=M_{F}x(t+1)a(t).

(36)

Definition 18

The action state pair
[a^{*},x^{*}]
is a recurrent state equilibrium with respect to the state transition process
P(\cdot)
if the following two conditions are satisfied:

•

The state
x^{*}
satisfies
x^{*}\in X(a^{*}|x)
for every state
x\in X(a^{*}|x^{*})
.

•

For every agent
i\in N
and every state
x\in X(a^{*}|x^{*})
,

c_{i}(x,a_{i}^{*},a^{*}_{-i})\geq c_{i}(x,a_{i},a^{*}_{-i}),\ \forall a_{i}\in S_{i}

Definition 19

A state based game
G=\{N,S,C,X,P\}
is a state based potential game if there exists a potential function
\phi:X\times S\rightarrow{\mathbb{R}}
that satisfies the following two properties for every action state pair
[a,x]\in S\times X
:

•

For any agent
i\in N
and action
a_{i}^{\prime}\in S_{i}

\displaystyle c_{i}(x,a_{i}^{\prime},a_{-i})-c_{i}(x,a)=\phi(x,a_{i}^{\prime},a_{-i})-\phi(x,a).

(37)

•

For any state
x^{\prime}
in the support of
P(x,a)

\displaystyle\phi(x^{\prime},a)\geq\phi(x,a).

(38)

The “better reply with inertia” dynamics is important for state based games. Define an agent’s strict better reply set for any action state pair
[a,x]\in S\times X
as

B_{i}(x,a):=\left\{a_{i}^{\prime}\in S_{i}\;\big|\;c_{i}(x,a_{i}^{\prime},a_{-i})>c_{i}(x,a)\right\}.

The better reply with inertia dynamics can be described as follows.

•

If
B_{i}(x(t),a(t-1))=\emptyset
then

\displaystyle p^{a_{i}(t-1)}_{i}=1.

(39)

•

Otherwise, if
B_{i}(x(t),a(t-1))\neq\emptyset
then

\displaystyle\begin{cases}p^{a_{i}}_{i}=\epsilon,\quad a_{i}=a_{i}(t-1)\\
p^{a^{\prime}_{i}}_{i}=\frac{(1-\epsilon)}{\left|B_{i}(x(t),a(t-1))\right|},\quad a^{\prime}_{i}\in B_{i}(x(t),a(t-1))\\
p_{i}^{a^{\prime\prime}_{i}}=0,\quad\mbox{Otherwise},\end{cases}

(40)

where
\epsilon\in(0,1)
is referred to as the agent’s inertia.

Theorem 20
.

Let
G=\left\{N,S,C,X,P\right\}
be a state based potential game with potential function
\phi:X\times S\rightarrow{\mathbb{R}}
. If all agents adhere to the better reply with inertia dynamics then the action state pair converges almost surely to an action invariant set of recurrent state equilibria.

4.2
State-depending Utility Design

Assume a state based multi-agent system is described as
\Gamma=\left\{N,S,c,X,P\right\}
, where
N=\{1,\cdots,n\}
;
S=\prod_{i=1}^{n}S_{i}
and
S_{i}=\{1,\cdots,k_{i}\}
,
i=1,\cdots,n
;
c_{i}:X\times S\rightarrow{\mathbb{R}}
;
P:X\times S\rightarrow\overline{X}
;
X=\{x_{1},\cdots,x_{r}\}
; and the system level object is a state-depending function
\phi=\phi(x,a)
.

The system objective function can be expressed as

\displaystyle\phi(x,a)=V^{\phi}xa,

(41)

where
a=\ltimes_{i=1}^{n}a_{i}
,
V^{\phi}\in{\mathbb{R}}^{rk}
,
k=\prod_{i=1}^{n}k_{i}
.

Split
V^{\phi}
into
r
equal blocks as

V^{\phi}=[V^{\phi}_{1},V^{\phi}_{2},\cdots,V^{\phi}_{r}].

Assume
x=x_{i}
is fixed. Then the structure vector of
\phi(x_{i},\cdot)
is

V^{\phi(x_{i},\cdot)}=V^{\phi}_{i},\quad 1\leq i\leq r.

Corresponding to
\phi(x_{i},\cdot)
, we can construct
B_{i}
as in (
32
), that is

\SpanRow(B_{i})=\bigcap_{j=1}^{n}\SpanRow\begin{bmatrix}\Gamma_{U^{i}(j)}\\
E_{j}^{T}\end{bmatrix},

where
U^{i}(j)
is the neighborhood of player
j
under fixed state
x=x_{i}
.
Define

\displaystyle B:=\diag(B_{1},B_{2},\cdots,B_{r}).

(42)

Next, we need to design the state evolutionary process (SEP). We suggest the following two ways to construct it.

•

SEP-1 (Remaining Priority):

Construct

BR(x(t),a(t)):=\left\{x_{j}\;\big|\;\phi(x_{j},a(t))>\phi(x(t),a(t))\right\}.

Then

–

if
BR(x(t),a(t))=\emptyset
, then

\displaystyle x(t+1)=x(t);

(43)

–

if
BR(x(t),a(t))\neq\emptyset
, then

\displaystyle\begin{array}[]{l}x(t+1)=x_{j},\quad\mbox{with probability }p_{j}=\frac{1}{\left|BR(x(t),a(t))\right|}\\
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~x_{j}\in BR(x(t),a(t)).\end{array}

•

SEP-2 (Equal Probability):

BR(x(t),a(t)):=\left\{x_{j}\;\big|\;\phi(x_{j},a(t))\geq\phi(x(t),a(t))\right\}.

Then

\displaystyle\begin{array}[]{l}x(t+1)=x_{j},\text{with probability }p_{j}=\frac{1}{\left|BR(x(t),a(t))\right|}\\
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~x_{j}\in BR(x(t),a(t)).\end{array}

5
Conclusion

This paper considers the problem of game theoretic control of multi-agent systems. Assume there is a system level objective function, say consensus, then we may design a local information based utility functions such that the multi-agent system becomes a potential game with the system level objective function as the potential function. Then individual agents can use their local information to reach an equilibrium, which maximizes the objective function. Two cases have been investigated. (i) fixed topology, and (ii) time-varying topology. Necessary and sufficient conditions have been obtained for both cases. Some examples are presented to illustrate the theoretical results.

There are several problems remaining for further study. For example,

1.

The state transition process used in this paper for time-varying topology is designable. A challenge problem for further investigation is to relax this.

2.

When the necessary and sufficient condition fails, can we design a near-potential game
[
22
]
to reach the same goal?
