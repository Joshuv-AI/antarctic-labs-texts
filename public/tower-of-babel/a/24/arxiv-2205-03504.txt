Reinforcement Learning Approach to Estimation in Linear Systems
Minyue Fu

Abstract
This paper addresses two important estimation problems for linear systems, namely system identification and model-free state estimation. Our focus is on ARMAX models with unknown parameters. We first provide a reinforcement learning algorithm for system identification with guaranteed consistency. This algorithm is then used to provide a novel solution to model-free state estimation. These results are then applied to solving the model-free LQG control problem in the reinforcement learning setting.



I
Introduction

It is well known that
system identification
and
state estimation
are closely related learning problems for dynamic systems, with a rich history of research and rich set of methodologies; see, e.g., classical monographs
[
1
,
2
]
for the former and
[
3
,
4
]
for the latter. The task of system identification is to estimate the system parameters, whereas that of state estimation is to provide an estimate of the state for a given system model.

The main motivation for this paper is to understand
how to do state estimation without a system model
. A simple approach is, of course, to estimate the system parameters first and then use them to estimate the state. But this approach is not suitable for on-line model-free state estimation where the estimates need to be updated recursively (or iteratively) along with the output measurement samples. That is, an online estimation algorithm is preferred. The second motivation for this paper is to know whether these estimation problems can be studied in the framework of reinforcement learning
[
5
,
6
]
.

The system under study is the classical Auto-Regressive Moving-Average eXogenous (ARMAX) model with known orders but unknown parameters. We first consider the online system identification problem formulated in the reinforcement learning framework, and the objective is to provide a recursive (or iterative) estimate of the system parameters along with the update of the output measurement. By blending the tools of
instrumental variables
and
bootstrapping
, we provide a new recursive learning algorithm that globally optimises a cost function in the reinforcement learning setting and provides a convergent and consistent parameter estimate in the system identification setting at the same time. We then extend this algorithm to solve the model-free state estimation problem under a similar reinforcement learning setting and give an asymptotically optimal state estimate in the Kalman filtering sense. The reinforcement learning algorithms for system identification and state estimation will then be used to solve the classical linear quadratic Gaussian (LQG) control problem for an ARMAX model with unknown parameters. The solution is a reinforcement learning algorithm for model-free LQG control.

The contributions of the paper are summarised below:

•

Reformulation and reinterpretation of the classical system identification tools (least-squares, instrumental variables, bootstrapping…) in the framework of reinforcement learning;

•

New recursive parameter estimation algorithm for system identification with consistency;

•

Reinforcement learning algorithm for model-free state estimation;

•

Application to model-free linear quadratic Gaussian (LQG) control.

II-A

System Model

In this paper, we consider a system with the following stationary ARMAX model

II-B

Reinforcement Learning

Reinforcement learning (RL) is an iconic tool in machine learning with huge success in applications
[
5
]
and has deep connections with the control theory
[
6
]
. Consider a system

\displaystyle x_{k+1}

\displaystyle=f(x_{k},u_{k},w_{k})

\displaystyle z_{k}

\displaystyle=g(x_{k},u_{k},w_{k}),

(16)

where
x_{k}
is the state,
u_{k}
is the control input,
w_{k}
is the process noise,
z_{k}
is the output known as the cost,
f(\cdot)
and
g(\cdot)
are unknown functions. Under the assumption that both the state and output are measurable, the aim of RL is to design an optimal control law
u_{k}=\pi(x_{k})
such that the following total cost
J_{k}
is minimised:

\displaystyle J_{k}

\displaystyle=\mathbb{E}[\sum_{t=0}^{\infty}\gamma^{t}z_{k+t}],

(17)

where
0<\gamma<1
is a forgetting factor. In the standard RL terminology, control is called
action
, control law is called
policy
, forgetting factor is called the
discount factor
,
-z_{k}
is called the
reward
,
-J_{k}
is called the
value function
, and (
17
) is equivalent to
maximise
the value function.

To get around of the difficulty with unknown
f(\cdot)
and
g(\cdot)
and unknown structure of feasible policy
\pi(\cdot)
, total cost and policy are parameterised as
J_{k}^{\theta}
and
\pi^{\theta}(\cdot)
with some (high-dimensional) parameter vector
\theta
. These functions are then approximated using neural networks and an iterative algorithm is applied to tune
\theta
, based on the available
x_{k}
and
z_{k}
sequences (from simulations and/or experiments) such that
J_{k}^{\theta}
is minimised. It is worth noting that apart from some simple cases, RL represents a learning paradigm rather than a guarantee for optimal policies. Important cases where the optimal policy is guaranteed include 1) Markov decision process (MDP) with finite numbers of states and actions
[
5
]
; 2) linear quadratic regulation (LQR) for state feedback control of linear systems
[
7
]
.

Two types of iterative algorithms are most commonly used in RL:
policy iteration
(PI) and
value iteration
(VI). PI aims to improve the policy after each iteration whereas VI focuses on improving the value function. The
key difference
between PI and VI is the following: In PI, a single policy (known as
on-policy
) is used in every time step, whereas in VI, different policies (known as
off-policy
) can be used in different time steps. This is illustrated in Fig.
1
below. This seemingly subtle difference has a profound influence on the efficiency and effectiveness of the algorithm. Namely, in PI, a complete evaluation of a new policy needs to be performed before the next iteration, whereas in VI, past value functions evaluated based on old policies can be used in evaluating the new policy, making VI a much more popular choice in RL.

[formula]
is used throughout
Value Iteration: Current and past policies are mixed

II-C

RL Formulation of System Identification

We now formulate the system identification problem as a reinforcement learning problem. Let

\displaystyle\hat{y}_{k}=\pi(y_{<k},u_{<k}),

(18)

be a (one-step-ahead) predictor of
y_{k}
, where
y_{<k}=[y_{k-1},y_{k-2},\ldots]
and
u_{<k}
is similarly defined. The prediction error is given by

\displaystyle e_{k}=y_{k}-\hat{y}_{k}.

(19)

The total cost is defined to be

\displaystyle J_{k}=\mathbb{E}[\sum_{t=0}^{\infty}\gamma^{t}e_{k-t}^{2}]

(20)

for some discount factor
0<\gamma<1
. Notice that this sequence goes
backwards
in time, and that the initial state is not present because the sequence of
y_{k}
starts from
k=-\infty
. The RL problem is to find the optimal policy (i.e., predictor)
\pi
such that
J_{k}
is minimised. We will show later that this formulation coincides with the classical system identification problem.

II-D

RL Formulation of Optimal State Estimation

State estimation without a system model has a unique difficulty due to infinite choices of state coordinates. Therefore, the state estimation problem not only needs to provide an optimal state estimate, but also to specify the system structure. Mathematically, we need to determine the following model:

\displaystyle\pi:\ \ \ \hat{x}_{k+1}

\displaystyle=\hat{f}(\hat{x}_{k},y_{k},u_{k})

\displaystyle\hat{y}_{k}

\displaystyle=\hat{g}(\hat{x}_{k})

(21)

where
\hat{x}_{k}
represents the estimated state,
\hat{f}(\cdot)
and
\hat{g}
are the unknown functions (i.e., structure and parameters). Collectively,
\hat{f}(\cdot)
and
\hat{g}(\cdot)
constitute the policy to be optimised. A “simple” choice for the estimated state is
\hat{x}_{k}=\mathrm{col}[y_{<k},u_{<k}]
, but this is not desirable because its dimension is infinite. It is natural that we want
\hat{x}_{k}
to have a fixed finite dimension.

The RL formulation for model-free state estimation is to find the optimal
\pi
in (
21
) such that the total cost
J_{k}
in (
20
) is minimised. Again, we will show later that this formulation is consistent with the classical Kalman filtering problem.

III
System Identification

This section solves the RL problem for system identification.

We first make a simple observation that the discount factor does not play any role and that the problem formulation (
20
) can be simplified.

Lemma 2

For any given (stationary) policy
\pi
in (
18
), the total cost
J_{k}
in (
20
) can be simplified to

\displaystyle J_{k}

\displaystyle=\frac{1}{1-\gamma}\mathbb{E}[e_{k}^{2}].

(22)

Proof:

The result follows from the stationarity of the system model (
1
) and that of the policy. That is,

\mathbb{E}[e_{k}^{2}]
is independent of
k
. Hence,
J_{k}=\mathbb{E}[e_{k}^{2}]\sum_{t=0}^{\infty}\gamma^{t}
, giving (
22
).
∎

The result above indicates that we effectively minimise the squared prediction error, for which the following holds.

Lemma 3

Suppose, for any
k
,
w_{k}
is independent of
u_{k-i}
for any
i=1,\ldots,m
. Then, the optimal policy
\pi^{\star}
of (
18
) that minimises
\mathbb{E}[J_{k}]
is given by

\displaystyle\hat{y}_{k}=

\displaystyle-a_{1}y_{k-1}-\ldots-a_{n}y_{k-n}+b_{1}u_{k-1}+\ldots+b_{m}u_{k-m}

\displaystyle+c_{1}e_{k-1}+\ldots+c_{p}e_{k-p}

(23)

with
e_{k-i}=y_{k-i}-\hat{y}_{k-i}
defined recursively. The corresponding minimum is given by

\displaystyle\min_{\pi}\mathbb{E}[J_{k}]

\displaystyle=\frac{1}{1-\gamma}\sigma^{2}.

(24)

Proof:

Firstly, it is obvious from (
1
) and (
18
)-(
19
) that
e_{k}
can be rewritten as

\displaystyle e_{k}=w_{k}+\tilde{e}_{k}

where
\tilde{e}_{k}
a function of
u_{<k},y_{<k}
and
w_{<k}
, hence independent of
w_{k}
. It is clear that
\mathbb{E}[e_{k}^{2}]\geq\mathbb{E}[w_{k}^{2}]=\sigma^{2}
. By taking
\hat{y}_{k}
as in (
23
), we get

\displaystyle e_{k}+c_{1}e_{k-1}+\ldots c_{p}e_{k-p}=w_{k}+c_{1}w_{k-1}+\ldots c_{p}w_{k-p},

i.e.,
e_{k}
and
w_{k}
have the same power spectrum, hence
\mathbb{E}[e_{k}^{2}]=\mathbb{E}[w_{k}^{2}]=\sigma^{2}
, confirming the optimality of (
23
). Finally, (
24
) is obtained by using Lemma
2
. (We note that the result for minimum
\mathbb{E}[e_{k}^{2}]
is consistent with
[
1
]
.)
∎

With Lemma
3
, we can take the policy structure to be

\displaystyle\hat{y}_{k}(\theta)=

\displaystyle-\hat{a}_{1}y_{k-1}-\ldots-\hat{a}_{n}y_{k-n}\hskip-2.84526pt+\hat{b}_{1}u_{k-1}\hskip-2.84526pt+\ldots+\hat{b}_{m}u_{k-m}

\displaystyle+\hat{c}_{1}e_{k-1}(\theta)+\ldots+\hat{c}_{p}e_{k-p}(\theta)

(25)

\displaystyle e_{k}(\theta)

\displaystyle=y_{k}-\hat{y}_{k}(\theta),

(26)

with
\theta=[\hat{a}_{1}\ \ldots\ \hat{a}_{n}\ \hat{b}_{1}\ \ldots\ \hat{b}_{m}\ \hat{c}_{1}\ \ldots\ \hat{c}_{p}]^{T}
.

The most popular method for ARMAX estimation is the so-called
pseudo-linear regression
(PLR) method
[
1
,
2
]
. Defining the pseudo-linear regressor as

\displaystyle\varphi_{k}(\theta)=

\displaystyle[-y_{k-1}\ \ldots\ -y_{k-n}\ u_{k-1}\ \ldots\ u_{k-m}

\displaystyle\ e_{k-1}(\theta)\ \ldots\ e_{k-p}(\theta)]^{T},

(27)

then

\displaystyle\hat{y}_{k}(\theta)

\displaystyle=\varphi_{k}^{T}(\theta)\theta;\ \ e_{k}(\theta)=y_{k}-\varphi_{k}^{T}(\theta)\theta.

(28)

The PRL estimate of
\theta
is computed by solving

\displaystyle\mathbb{E}[\varphi_{k}(\theta)(y_{k}-\varphi_{k}^{T}(\theta)\theta)]=0.

(29)

This is typically done recursively (known as
bootstrapping
method in the system identification literature): Starting from some initial estimate
\theta^{(0)}
, then for each
i=1,2,\ldots
, solve
\theta^{(i)}
using

\displaystyle\mathbb{E}[\varphi_{k}(\theta^{(i-1)})(y_{k}-\varphi_{k}^{T}(\theta^{(i-1)})\theta^{(i)})]=0,

(30)

which is a
repeated least-squares
problem.

The PRL method is also often combined with the
instrumental variable
method, where the first term
\varphi_{k}(\theta)
in (
29
) is replaced with an instrumental variable (vector)
\zeta_{k}(\theta)
which is designed to be uncorrelated with
e_{k}(\theta)
.

The convergence properties of the bootstrapping and the instrumental variable method depend on many factors; see
[
2
,
1
]
for detailed analysis. We emphasise two key observations:

1.

Global convergence to the optimal solution is not always guaranteed;

2.

The bootstrapping method above is a form of policy iteration in the viewpoint of RL.

We will see below that by using a value iteration method in combination with the instrumental variable method, a globally convergent algorithm can be derived for ARMAX estimation. We will first study off-line identification before giving an on-line algorithm.

III-A

Off-line Identification of MA Models

We first consider the case of MA models, as this is the stumbling block in system identification, causing the regressor (
27
) to depend on
\theta
. The MA model is given by

\displaystyle y_{k}

\displaystyle=w_{k}+c_{1}w_{k-1}+\ldots c_{p}w_{k-p}

(31)

with the assumption that
c(z)=1+c_{1}z^{-1}+\ldots+c_{p}z^{-p}
is strictly stable. Also,
\theta=[\hat{c}_{1}\ \ldots\ \hat{c}_{p}]^{T}
in this case.

Identification of MA models can be traced back at least to
[
8
,
9
]
. But earlier methods all require solving difficult nonlinear equations. In
[
1
]
(p. 337), a two-step, non-iterative method is provided: Step 1 estimates a high-order AR model to approximate the MA model; Step 2 uses the prediction errors (known as innovations) from the AR model as an estimate of the past process noise and estimate the MA parameters using the least-squares method. This method requires heavy computation for the first step due to the use of a high-order AR model and gives only an approximate solution. Alternatively, the PRL method can be used to reduce complexity, but there is no theoretical guarantee for an optimal solution.

Here we introduce a new algorithm based on an VI method in RL. That is,
we generalise the bootstrapping method (
30
) by allowing the PLR to depend on multiple past estimates of
\theta
, as illustrated in Fig.
1
. We first consider an
off-line
iterative algorithm before extending it to on-line learning.

We start estimating
\theta
from
k=0
. Denote by
\theta^{(k)},k\geq 0
the
k
-th estimate. We revise (
25
)-(
26
) to the following:

\displaystyle\hat{y}_{k}(\theta)=

\displaystyle\hat{c}_{1}e_{k-1}(\theta^{(k-1)})+\ldots+\hat{c}_{p}e_{k-p}(\theta^{(k-p)})

(32)

\displaystyle e_{k}(\theta)

\displaystyle=y_{k}-\hat{y}_{k}(\theta).

(33)

That is,
e_{k-i}(\theta)
is replaced with
e_{k-i}(\theta^{(k-i)})
. With some abuse of notation, the latter will denoted by
e_{k}
if not confusing.

Suppose
y_{k}
is measured for all
k<0
. Due to the stationarity of (
31
), we can compute all the autocorrelations
r_{y}(i)=\mathbb{E}[y_{k}y_{k-i}]
using the available measurements prior to
k=0
. Our off-line iterative algorithm assumes that
r_{y}(i),i=0,1,\ldots,p
, are available and produces a sequence of
\theta^{(k)},k\geq 0,
such that
\theta^{(k)}\rightarrow\theta^{\star}
as
k\rightarrow\infty
.

Initialise
e_{-1}=\ldots=e_{-p}=0
and
\theta^{(-1)}=\ldots=\theta^{(-p)}=0
. For
k=0,1,\ldots
, solve
\theta^{(k)}
from

\displaystyle\min_{\theta}\mathbb{E}[e_{k}^{2}]=\mathbb{E}[(y_{k}-\hat{c}_{1}e_{k-1}-\ldots-\hat{c}_{p}e_{k-p})^{2}]

(34)

and construct the resulting
e_{k}
using
\theta^{(k)}
. Differentiating the above results in the orthogonality condition:

\displaystyle\mathbb{E}[e_{k}e_{k-i}]=0,i=1,\ldots,p.

(35)

As we will show later that the orthogonality condition holds recursively, i.e.,
\mathbb{E}[e_{k-j}e_{k-j-i}]=0
for all
j>0
and
i>0
as well. This implies that (
35
) can be simplified to

\displaystyle\mathbb{E}[(y_{k}-\hat{c}_{i}e_{k-i})e_{k-i}]=0,

giving the simple solution for
\hat{c}_{i}
as

\displaystyle c_{i}^{(k)}=\left\{\begin{array}[]{ll}\rho_{k}(i)/\mathbb{E}[e_{k-i}^{2}]&\mathrm{if\ }\mathbb{E}[e_{k-i}^{2}]>0\\
0&\mathrm{otherwise}\end{array}\right.,

where
\rho_{k}(i)=\mathbb{E}[y_{k}e_{k-i}]
.

The resulting
\mathbb{E}[e_{k}^{2}]
is given by

\displaystyle\mathbb{E}[e_{k}^{2}]=r_{y}(0)-(c_{1}^{(k)})^{2}\mathbb{E}[e_{k-1}^{2}]-\ldots(c_{p}^{(k)})^{2}\mathbb{E}[e_{k-p}^{2}].

(38)

Note that, by construction,
e_{k}
explicitly depends on
\theta^{(k)}
but implicitly depends on
\theta^{(k-1)},\theta^{(k-2)},\ldots
because of
e_{k-1},\ldots
, hence the method above is an VI method in the RL framework.

The computation of (
III-A
) involves
\rho_{k}(i)
, which can also be easily updated. Indeed, for
i=1,\ldots,p
,

\displaystyle\rho_{k}(i)=

\displaystyle\mathbb{E}[y_{k}e_{k-i}]

\displaystyle=

\displaystyle\mathbb{E}[y_{k}(y_{k-i}-c_{1}^{(k-i)}e_{k-i-1}-\ldots-c_{p}^{(k-i)}e_{k-i-p})]

\displaystyle=

\displaystyle r_{y}(i)-c_{1}^{(k-i)}\rho_{k}(i+1)-\ldots-c_{p}^{(k-i)}\rho_{k}(i+p).

From (
31
),
\rho_{k}(i)=\mathbb{E}[y_{k}e_{k-j}]=0
for
j>p
. Therefore,

\displaystyle\hskip-5.69054pt\left[\hskip-2.84526pt\begin{array}[]{cccc}1&c_{1}^{(k-1)}&\ldots&c_{p-1}^{(k-1)}\\
0&1&c_{1}^{(k-2)}&\vdots\\
\vdots&\ddots&1&c_{1}^{(k-p+1)}\\
0&\ldots&0&1\end{array}\right]\hskip-2.84526pt\left[\begin{array}[]{c}\rho_{k}(1)\\
\rho_{k}(2)\\
\vdots\\
\rho_{k}(p)\end{array}\hskip-2.84526pt\right]\hskip-2.84526pt=\hskip-2.84526pt\left[\hskip-2.84526pt\begin{array}[]{c}r_{y}(1)\\
r_{y}(2)\\
\vdots\\
r_{y}(p)\end{array}\hskip-2.84526pt\right]

which can be easily computed due to the triangular structure.

We have the following result for convergence.

Theorem 1

The VI method above has two properties:

•

(Orthogonality:)
\mathbb{E}[e_{k}e_{k-i}]=0
for all
k\geq i
and
i>0
;

•

(Convergence and Consistency:)
\theta^{(k)}\rightarrow\theta^{\star}
as
k\rightarrow\infty
.

Proof:

Take any
k\geq 0
and
i>0
. The orthogonality condition for
i\leq p
was given in (
35
). Now consider
i=p+1
,

\displaystyle\mathbb{E}[e_{k}e_{k-i}]

\displaystyle=\mathbb{E}[(y_{k}-c_{1}^{(k)}e_{k-1}-\ldots-c_{p}^{(k)}e_{k-p})e_{k-i}]

The first term
\mathbb{E}[y_{k}e_{k-i}]=0
due to
i>p
. Thus,
\mathbb{E}[e_{k}e_{k-i}]=0
because
\mathbb{E}[e_{k-j}e_{k-i}]=0
for all
j=1,\ldots,p
due to
i=p+1
. This process can be repeated for
i=p+2,p+3,\ldots
. Hence, the orthogonality condition holds for all
i>0
.

To show convergence and consistency, we note that the sequences
\{e_{0},e_{1},\ldots e_{k-1}\}
and
\{y_{0},y_{1},\ldots,y_{k-1}\}
form a linear invertible mapping. Let
\pi_{k}^{\star}
be the optimal function in (
18
), linear or nonlinear, such that
\mathbb{E}[(y_{k}-\hat{y}_{k})^{2}]
is minimised. Due to the assumption that
w_{k}
is a Gaussian white noise, it is well-known
[
3
]
that the optimal
\pi_{k}^{\star}
is a linear mapping. Due to the invertibility above, the optimal
\hat{y}_{k}
can be represented as the following linear mapping:

\displaystyle\hat{y}_{k}

\displaystyle=\delta_{1}e_{k-1}+\ldots\delta_{p}e_{k-p}+\delta_{p+1}e_{k-p-1}+\ldots+\delta_{k}e_{0}

and the optimal
\delta_{i}
can be solved by minimising
\mathbb{E}[(y_{k}-\hat{y}_{k})^{2}]
.
Due to the orthogonality peroperty of
e_{k}
and the fact that
y_{k}
is orthogonal to
e_{k-i}
for
i>p
, it is easy to see that
\delta_{i}=0
for any
i>p
and, for any
i=1,2,\ldots,p
,
\delta_{i}
are the same as
\hat{c}_{i}
in (
III-A
). That is, the optimal
\hat{y}_{k}
is given by

\displaystyle\hat{y}_{k}

\displaystyle=\hat{c}_{1}e_{k-1}+\ldots+\hat{c}_{p}e_{k-p}

(51)

with
[\hat{c}_{1}\ \ldots\hat{c}_{p}]=\theta^{(k)}
.

On the other hand, it is also well known
[
3
]
that, as
k\rightarrow\infty
, the stability of
c(z)
and stationarity of (
34
) implies that the optimal
\hat{y}_{k}
is such that

\displaystyle e_{k}=y_{k}-\hat{y}_{k}\rightarrow c^{-1}(z)y_{k}=w_{k}

That is,
c(z)e_{k}\rightarrow y_{k}
, i.e.,

\displaystyle e_{k}

\displaystyle\rightarrow-c_{1}e_{k-1}-\ldots-c_{p}e_{k-p}+y_{k}

\displaystyle\hat{y}_{k}

\displaystyle\rightarrow c_{1}e_{k-1}+\ldots c_{p}e_{k-p}

Comparing this to (
51
), we see that
\theta^{(k)}\rightarrow\theta^{\star}
as
k\rightarrow\infty
.
∎

Now let us return to the ARMAX model (

)-(

IV
Model-based State Estimation

IV-A

Optimal State Estimation for a Known Model

Consider the following state-space model:

\displaystyle x_{k+1}

\displaystyle=Ax_{k}+B_{1}u_{k}+B_{2}w_{k}

\displaystyle y_{k}

\displaystyle=Cx_{k}+v_{k},

(82)

where
x_{k}
is the state,
u_{k}
is the known input,
w_{k}
is the process noise,
v_{k}
is the measurement noise,
\{(w_{k},\ v_{k})\}
is zero-mean Gaussian noise with

\displaystyle\mathbb{E}\left\{\left[\begin{array}[]{c}w_{k}\\
v_{k}\end{array}\right][w_{l}^{T}\ v_{l}^{T}]\right\}

\displaystyle=\left[\begin{array}[]{cc}Q&S\\
S^{T}&R\end{array}\right]\delta_{kl},\ \ k,l\in\mathbb{R}.

When the system model is known, the steady-state Kalman filter of (
82
) is given by
[
3
]

\displaystyle\hat{x}_{k+1}

\displaystyle=A\hat{x}_{k}+B_{1}u_{k}+L(y_{k}-C\hat{x}_{k})

(87)

with the optimal observer gain

given by
[
3
]
(Section 5.4)

\displaystyle L

\displaystyle=(A\Sigma C^{T}+B_{2}S)(C\Sigma C^{T}+R)^{-1}

(88)

\displaystyle\Sigma

\displaystyle=A\Sigma A^{T}-(A\Sigma C^{T}+B_{2}S)(C\Sigma C^{T}+R)^{-1}

\displaystyle\hskip 51.21495pt\cdot(A\Sigma C^{T}+B_{2}S)^{T}+B_{2}QB_{2}^{T}.

(89)

In the above,
\Sigma=\mathbb{E}[(x_{k}-\hat{x}_{k})(x_{k}-\hat{x}_{k})^{T}]
is the steady-state state estimation error covariance, and (

) is an algebraic Riccati equation (ARE).

IV-B

Pitfall for Model-Free State Estimation

Example 1

Consider the scalar sequence
\{y_{k}\}
:

\displaystyle y_{k}

\displaystyle=w_{k-1}+w_{k}+\mu_{k}=(1+z^{-1})w_{k}+\mu_{k}

(90)

which has the following state-space realisation:

\displaystyle x_{k+1}

\displaystyle=w_{k}

\displaystyle y_{k}

\displaystyle=x_{k}+w_{k}+\mu_{k}

(91)

where
w_{k}
and
\mu_{k}
are independent zero-mean Gaussian white noises with variance equal to 1. Comparing with (
82
)-(
IV-A
), we verify that
v_{k}=w_{k}+\mu_{k},A=1,B_{1}=0,B_{2}=1,C=1,Q=1,R=2,S=1
. The state estimator (
87
) becomes

\displaystyle\hat{x}_{k+1}

\displaystyle=L(y_{k}-\hat{x}_{k}).

(92)

Solving (
89
) gives

\displaystyle\Sigma

\displaystyle=\Sigma-(\Sigma+1)^{2}(\Sigma+2)^{-1}+1

resulting in
\Sigma=(\sqrt{5}-1)/2\approx 0.618
and
L\approx 0.618
.

On the other hand, the spectrum of
y_{k}
in (
90
) is

\displaystyle S_{y}

\displaystyle=(1+z^{-1})(1+z)+1=\alpha(1+\alpha^{-1}z^{-1})(1+\alpha^{-1}z)

with
\alpha=0.5(3+\sqrt{5})
.
Now consider an alternative state-space realisation:

\displaystyle\mathbf{x}_{k+1}

\displaystyle=\mathbf{w}_{k}

\displaystyle y_{k}

\displaystyle=\alpha^{-1}\mathbf{x}_{k}+\mathbf{w}_{k}

(93)

with
\mathbf{w}_{k}
being a zero-mean Gaussian white noise with variance of
\alpha
. For (
93
), the counterpart of
(Q,R,S)
is given by
\mathbf{Q}=\mathbf{R}=\mathbf{S}=\alpha
. The optimal state estimator is given by

\displaystyle\hat{\mathbf{x}}_{k+1}

\displaystyle=\mathbf{L}(y_{k}-\hat{\mathbf{x}}_{k}).

(94)

Solving (
89
) for this estimator gives
\mathbf{L}=1
, and the corresponding steady-state state estimation error covariance
\Sigma=0
. That is, in steady state,
\mathbf{x}_{k}
can be perfectly predicted by
y_{<k}
!

Since the noises
w_{k}
and
\mu_{k}
are not directly measurable, the state-space representation (
82
) is indistinguishable from (
93
).

We see from this example that different state-space realisations can result in vastly different state estimation results, which is a unique feature for the state estimation problem when the state-space model is not specified!

IV-C

State-Space Realisation for ARMAX Models

Motivated by Example
1
, we see that different state-space realisations may result in vastly different state estimation errors. Here, we present a state-space realisation that has zero optimal state estimation error in steady state.

Our chosen state-space realisation for (

Comparing the realisation (

VI
Conclusion

Model-free state estimation is a challenging problem due to the fact that both the system model is unknown and the measurement contains partial state and noises. By reformulating the classical system identification as a reinforcement learning problem and incorporating the classical tools of instrumental variables and bootstrapping, we have provided a value-iteration based reinforcement learning algorithm for system identification of an ARMAX system with guaranteed consistency. This algorithm is then used in solving the model-free state estimation problem for an ARMAX system, and a reinforcement learning solution has been obtained. These results have also been applied to solving the model-free LQG problem for an ARMAX system.

The key to our model-free state estimation solution is to use the observable-canonical realisation, which leads to the optimal state estimation by the driving the state estimation error covariance to zero. How to generalise this observation to more general systems, linear or nonlinear, will be crucial to more general solutions to model-free state estimation. This will alleviate a stumbling block to reinforcement learning applications where only measurement of partial state with noise is available.
