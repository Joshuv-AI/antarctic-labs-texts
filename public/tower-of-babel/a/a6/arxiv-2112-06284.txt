Dynamical analysis of a generalized hepatitis B epidemic model and its dynamically consistent discrete model Journal: Mathematical Methods in the Applied Sciences
Manh Tuan Hoang

Abstract
The aim of this work is to study qualitative dynamical properties of a generalized hepatitis B epidemic model and its dynamically consistent discrete model. Positivity, boundedness, the basic reproduction number and asymptotic stability properties of the model are analyzed rigorously. By the Lyapunov stability theory and the Poincare-Bendixson theorem in combination with the Bendixson-Dulac criterion, we show that a disease-free equilibrium point is globally asymptotically stable if the basic reproduction number ℛ 0 ≤ 1 \mathcal{R}_{0}\leq 1 and a disease-endemic equilibrium point is globally asymptotically stable whenever ℛ 0 > 1 \mathcal{R}_{0}>1 . Next, we apply the Mickens’ methodology to propose a dynamically consistent nonstandard finite difference (NSFD) scheme for the continuous model. By rigorously mathematical analyses, it is proved that the constructed NSFD scheme preserves essential mathematical features of the continuous model for all finite step sizes. Finally, numerical experiments are conducted to illustrate the theoretical findings and to demonstrate advantages of the NSFD scheme over standard ones. The obtained results in this work not only improve but also generalize some existing recognized works.

In this section, dynamical qualitative properties of the model (

Proposition 1

(Positivity and boundedness)
.

The set
\mathbb{R}_{+}^{3}
is a positively invariant set of the model (
3
), i.e.,
S(t),I(t),R(t)\geq 0
whenever
S(0),I(0),R(0)\geq 0
. Furthermore, we have

\begin{split}&\limsup_{t\to\infty}S(t)\leq\dfrac{\Lambda}{\mu_{0}+\nu},\quad\dfrac{\Lambda}{p}\leq\limsup_{t\to\infty}\big(S(t)+I(t)\big)\leq\dfrac{\Lambda}{q},\quad\dfrac{r_{1}\Lambda}{p\mu_{0}}\leq\limsup_{t\to\infty}R(t)\leq\dfrac{r_{2}\Lambda}{q\mu_{0}},\\
&p:=\max\{\mu_{0}+\nu,\,\,\mu_{0}+\mu_{1}+\beta\},\quad q:=\min\{\mu_{0}+\nu,\,\,\mu_{0}+\mu_{1}+\beta\},\quad r_{2}:=\max\{\beta,\,\,\nu\},\quad r_{1}:=\min\{\beta,\,\,\nu\}.\end{split}

(4)

Proof.

First, the system (
3
) implies that

\dfrac{dS}{dt}\bigg|_{S=0}=\Lambda>0,\quad\dfrac{dI}{dt}\bigg|_{I=0}=0,\quad\dfrac{dR}{dt}\bigg|_{R=0}=\beta I+\nu S\geq 0.

Thanks to
[
33
, Lemma 10]
, the positivity of the solutions of the model (
3
) is obtained. Hence, the set
\mathbb{R}_{3}^{+}
is a positively invariant set of (
3
).

Next, it follows from the first equation of (
3
) that

\dfrac{dS}{dt}\leq\Lambda-(\mu_{0}+\nu)S.

Using the basic comparison theorem for ODEs
[
47
]
, we obtain

S(t)\leq\bigg(S(0)-\dfrac{\Lambda}{\mu_{0}+\nu}\bigg)e^{-(\mu_{0}+\nu)t}+\dfrac{\Lambda}{\mu_{0}+\nu},

which implies the first estimate of (
4
).

Similarly, it follows from the first and second equation of (
3
) that

\Lambda-p(S+I)\leq\dfrac{d(S+I)}{dt}=\Lambda-(\mu_{0}+\nu)S-(\mu_{0}+\mu_{1}+\beta)I\leq\Lambda-q(S+I).

Hence, the second estimate of (
4
) is obtained.

Lastly, using the third equation of (
3
) we have

\dfrac{r_{1}\Lambda}{p}-\mu_{0}R\leq r_{1}(S+I)-\mu_{0}R\leq\dfrac{dR}{dt}\leq r_{2}(S+I)-\mu_{0}R\leq\dfrac{r_{2}\Lambda}{q}-\mu_{0}R

for
t
large enough. Consequently, the third estimate of (
4
) is proved. This proof is complete.
∎

Proposition 2

(Equilibria and the basic reproduction number)
.

(i)

The HBV model (
3
) always possesses a disease-free equilibrium (DFE) point given by

E^{0}=(S^{0},I^{0},R^{0})=\bigg(\dfrac{\Lambda}{\mu_{0}+\nu},\,\,0\,\,\dfrac{\nu\Lambda}{\mu_{0}(\mu_{0}+\nu)}\bigg)

(5)

for all the values of the parameters.

(ii)

The basic reproduction number of the model (
3
) can be computed as

\mathcal{R}_{0}=\dfrac{1}{\mu_{0}+\mu_{1}+\beta}\dfrac{\partial f\bigg(\dfrac{\Lambda}{\mu_{0}+\nu},\,\,0\bigg)}{\partial I}.

(6)

(iii)

The model (
3
) has a unique disease-endemic equilibrium (DEE) point
E^{*}=(S^{*},I^{*},R^{*})
if and only if
\mathcal{R}_{0}>1
. Moreover, if
E^{*}
exists it is given by

S^{*}\dfrac{\Lambda-(\mu_{0}+\mu_{1}+\beta)I^{*}}{\mu_{0}+\nu},\quad R^{*}=\dfrac{\beta I^{*}+\nu S^{*}}{\mu_{0}},

(7)

where
I^{*}
is a unique positive solution of the equation

{f\bigg(\dfrac{\Lambda-(\mu_{0}+\mu_{1}+\beta)I}{\mu_{0}+\nu},\,\,I\bigg)}-\big(\mu_{0}+\mu_{1}+\beta\big)I=0.

Proof.

Proof of Part (i).
To determine equilibria of the model (
3
), we need to solve the nonlinear system of algebra equations

\Lambda-f(S,I)-\big(\mu_{0}+\nu\big)S=0,\quad f(S,I)-\big(\mu_{0}+\mu_{1}+\beta\big)I=0,\quad\beta I+\nu S-\mu_{0}R=0.

(8)

It follows from the first and second equations of the system (
8
) that

S=\dfrac{\Lambda-(\mu_{0}+\mu_{1}+\beta)I}{\mu_{0}+\nu}.

Combining this with the second equation of (
8
) we obtain

f\bigg(\dfrac{\Lambda-(\mu_{0}+\mu_{1}+\beta)I}{\mu_{0}+\nu},I\bigg)-\big(\mu_{0}+\mu_{1}+\beta\big)I=0.

(9)

Since

for all

, the equation (

. Consequently, the system (

) always possesses a solution
\big(\Lambda/(\mu_{0}+\nu),\,\,0,\,\,{\nu\Lambda}/{[\mu_{0}(\mu_{0}+\nu)]}\big)
. This solution corresponds to a unique DFE point.

Proof of Part (ii).
We apply the method proposed in
[

to compute the basic reproduction number of the model (

\begin{split}&\dfrac{dS(t)}{dt}=\Lambda-f(S(t),I(t))-\big(\mu_{0}+\nu\big)S(t),\\
&\dfrac{dI(t)}{dt}=f(S(t),I(t))-\big(\mu_{0}+\mu_{1}+\beta\big)I(t).\end{split}

(10)

We reorder the variables in (

\mathcal{F}(x)=\begin{pmatrix}f(S,I)\\

Consequently,

D\mathcal{F}(x_{0})=\begin{pmatrix}\dfrac{\partial f}{\partial I}(S_{0},0)&0\\
&\\
0&0\end{pmatrix},\quad D\mathcal{V}(x)=\begin{pmatrix}(\mu_{0}+\mu_{1}+\beta)&0\\
&\\
\dfrac{\partial f}{\partial I}(S_{0},0)&\dfrac{\partial f}{\partial S}(S_{0},0)+(\mu_{0}+\nu).\end{pmatrix}

Then, the basic reproduction number can be computed as

\mathcal{R}_{0}=\rho(FV^{-1})=\dfrac{1}{\mu_{0}+\mu_{1}+\beta}\dfrac{\partial f\bigg(\dfrac{\Lambda}{\mu_{0}+\nu},\,\,0\bigg)}{\partial I}.

Proof of Part (iii)
. Return to the equation (
9

. Indeed, consider the equation

(11)

From the condition (H5), it is easy to verify that

for all

\begin{split}&\lim_{I\to 0}F(I)=\dfrac{\partial f\bigg(\dfrac{\Lambda}{\mu_{0}+\nu},\,\,0\bigg)}{\partial I}-({\mu_{0}+\mu_{1}+\beta})>0,\\
&F\bigg(\dfrac{\Lambda}{\mu_{0}+\mu_{1}+\beta}\bigg)=-({\mu_{0}+\mu_{1}+\beta})<0.\end{split}

Hence, the equation (

I^{*}
and we obtain
(S^{*},I^{*},R^{*})
as in (

Lemma 1

(Local asymptotic stability)
.

(i)

The DFE point
E^{0}
is locally asymptotically stable if
\mathcal{R}_{0}<1
and unstable if
\mathcal{R}_{0}>1
.

(ii)

The DEE point

is locally asymptotically stable if
\mathcal{R}_{0}>1

\mathcal{R}_{0}<1

Proof.

Proof of Part (i).
The Jacobian matrix of the system (

is given by

J(E^{0})=\begin{pmatrix}-(\mu_{0}+\nu)&-\dfrac{\partial f(E^{0})}{\partial I}&0\\
&&\\
0&\dfrac{\partial f(E^{0})}{\partial I}-(\mu_{0}+\mu_{1}+\beta)&0\\
&&\\
\nu&\beta&-\mu_{0}\end{pmatrix}.

Hence, three eigenvalues of
J(E^{0})
are

\lambda_{1}=-(\mu_{0}+\nu),\quad\lambda_{2}=\dfrac{\partial f(E^{0})}{\partial I}-(\mu_{0}+\mu_{1}+\beta),\quad\lambda_{3}=-\mu_{0}.

It is clear that
\lambda_{1}<0
and
\lambda_{3}<0
. Moreover, if
\mathcal{R}_{0}<1
then
\lambda_{3}<0
. By the Lyapunov direct method
[
3
,
44
]
, the DFE point
E^{0}
is locally asymptotically stable. Conversely, if
\mathcal{R}_{0}>1
then
\lambda_{3}>0
and hence,
E^{0}
is unstable. The proof is complete.

Proof of Part (ii).
Note that
E^{*}
exists if and only if
\mathcal{R}_{0}>1
. The Jacobian matrix of the system (
3
) at
E^{*}
is given by

J(E^{*})=\begin{pmatrix}-\dfrac{\partial f(E^{*})}{\partial S}-(\mu_{0}+\nu)&-\dfrac{\partial f(E^{*})}{\partial I}&0\\
&&\\
\dfrac{\partial f(E^{*})}{\partial S}&\dfrac{\partial f(E^{*})}{\partial I}-(\mu_{0}+\mu_{1}+\beta)&0\\
&&\\
\nu&\beta&-\mu_{0}\end{pmatrix}.

Hence, one of three eigenvalues of
J(E^{*})
is
\lambda_{1}=-\mu_{0}<0
and two remaining eigenvalues are the ones of the sub-matrix

\widehat{J}(E^{*})=\begin{pmatrix}-\dfrac{\partial f(E^{*})}{\partial S}-(\mu_{0}+\nu)&-\dfrac{\partial f(E^{*})}{\partial I}\\
&&\\
\dfrac{\partial f(E^{*})}{\partial S}&\dfrac{\partial f(E^{*})}{\partial I}-(\mu_{0}+\mu_{1}+\beta)\end{pmatrix}.

Because
E^{*}
is the positive equilibrium point we have

\dfrac{f(S^{*},I^{*})}{I^{*}}=(\mu_{0}+\mu_{1}+\beta).

Hence, it follows from the hypothesis (H5) that

\dfrac{\partial f(S^{*},I^{*})}{\partial I}<\dfrac{f(S^{*},I^{*})}{I^{*}}=(\mu_{0}+\mu_{1}+\beta).

(12)

From this estimate, we obtain

Thanks to the Lyapunov stability theorem

]
, the local asymptotic stability of

Lemma 2
.

Let
f(S,I)
be a function satisfying the conditions (H1)-(H5). We define

V(S):=S-S_{0}-\int_{S_{0}}^{S}\dfrac{f(S_{0},I)}{f(t,I)}dt,\quad S\geq 0

(14)

and

g(I)=\dfrac{f(S_{0},I)}{I}-(\mu_{0}+\mu_{1}+\nu),\quad I>0.

(15)

Then,

(i)

V(S)\geq 0
for all
S\geq 0
and
V(S)=0
if and only if
S=S_{0}
.

(ii)

If
\mathcal{R}_{0}\leq 1
, then
g(I)<0
for all
I>0

Proof.

Proof of Part (i).
First, it is clear that
V(S_{0})=0
. The derivative of the function
V
is given by

V^{\prime}(S)=1-\dfrac{f(S_{0},I)}{f(S,I)}.

From the condition (H3) we deduce that

\begin{split}&V^{\prime}(S)>0\quad\mbox{for all}\quad S>S_{0},\\
&V^{\prime}(S)<0\quad\mbox{for all}\quad S<S_{0},\\
&V^{\prime}(S)=0\quad\mbox{if and only if}\quad S=S_{0}.\end{split}

Hence,
V(S)>V(S_{0})=0
for all
S\neq S_{0}
. The proof of this part is complete.

Proof of Part (ii).
It follows from the condition (H5) that

g^{\prime}(I)=\dfrac{\partial f(S_{0},I)}{\partial I}<0.

On the other hand,

\lim_{I\to 0}g(I)=\dfrac{\partial f\bigg(\dfrac{\Lambda}{\mu_{0}+\nu},\,\,0\bigg)}{\partial I}-(\mu_{0}+\mu_{1}+\nu)=(\mu_{0}+\mu_{1}+\nu)(\mathcal{R}_{0}-1)\leq 0.

Therefore, we conclude that
g(I)<(\mu_{0}+\mu_{1}+\nu)(\mathcal{R}_{0}-1)\leq 0
. This completes the proof.

Theorem 2

Suppose that

Note that if
I(0)=0
then
\big(S(t),I(t)\big)
will converge to the DFE point
\widehat{E^{0}}
as
t\to\infty
. We first use the Dulac-Bendixson criterion
[

, Theorem 3.6]
to show that the system (

) has no periodic orbits or graphics in
\mathbb{R}_{2}^{+}
. Indeed, let us denote by
F(S,I)

D(S,I)=\dfrac{1}{I}.

We have

\begin{split}\dfrac{\partial(DF)}{\partial S}+\dfrac{\partial(DG)}{\partial I}&=\dfrac{\partial}{\partial S}\bigg[\dfrac{\Lambda}{I}-\dfrac{f(S,I)}{I}-\dfrac{(\mu_{0}+\nu)S}{I}\bigg]+\dfrac{\partial}{\partial I}\bigg[\dfrac{f(S,I)}{I}-(\mu_{0}+\mu_{1}+\beta)\bigg]\\
&=-\dfrac{1}{I}\dfrac{\partial f(S,I)}{S}-\dfrac{\mu_{0}+\nu}{I}+\dfrac{\partial}{\partial I}\bigg(\dfrac{f(S,I)}{I}\bigg).\end{split}

It follows from the conditions (H3) and (H5) that

\dfrac{\partial(DF)}{\partial S}+\dfrac{\partial(DG)}{\partial I}<0.

Hence, the system (
13
) has no periodic orbits or graphics in the open first quadrant.

Since all solutions of the model (
13
) are bounded and the DFE point
\widehat{E^{0}}
is unstable saddle if
\mathcal{R}_{0}>1
, using Poincaré-Bendixson theorem
[
44
, Theorem 3.5]
we obtain the GAS of the DEE point
\widehat{E^{*}}
. The proof is complete.
∎

Construction of dynamically consistent NSFD scheme

In this section, we construct and analyze a dynamically consistent NSFD scheme for the model (
3
). For this purpose, consider the model (
3
) on a finite time interval
[0,T]
and discretize this interval by

0=t_{0}<t_{1}<\ldots<t_{N-1}<t_{N}=T,

where
t_{n+1}-t_{n}=\Delta t
for
0\leq n\leq N-1
. Let us denote by
(S_{n},I_{n},R_{n})
the intended approximation for
\big(S(t_{n}),I(t_{n}),R(t_{n})\big)
for
n=1,2,\ldots,N
. Applying the Mickens’ methodology
[
48
,
49
,
50
,
51
,
52
]
we approximate the first derivatives in the model (
3
) by

\dfrac{dS}{dt}\bigg|_{t=t_{n}}\approx\dfrac{S_{n+1}-S_{n}}{\varphi(\Delta t)},\qquad\dfrac{dI}{dt}\bigg|_{t=t_{n}}\approx\dfrac{I_{n+1}-I_{n}}{\varphi(\Delta t)},\qquad\dfrac{dR}{dt}\bigg|_{t=t_{n}}\approx\dfrac{R_{n+1}-R_{n}}{\varphi(\Delta t)},

(17)

where
\varphi
, called the denominator function, is a positive function satisfying
\varphi(\Delta t)=\Delta t+\mathcal{O}(\Delta t^{2})
as
\Delta t\to 0
. Next, we discretize the right-hand side function of the model (
3
) as follows. Let us denote

f^{*}(S,I)=\begin{cases}&\dfrac{f(S,I)}{S},\quad S>0,\\
&0,\quad S=0.\end{cases}

(18)

Then,
f(S,I)=Sf^{*}(S,I)
. Moreover, it follows from the conditions (H1) and (H5) that
f^{*}(S,I)
is differentiable for
S,I\geq 0
. In particular,

\begin{split}&f^{*}(S^{0},I^{0})=f^{*}(S^{*},I^{*})=0,\\
&\dfrac{\partial f^{*}}{\partial S}(S_{0},0)=0,\quad\dfrac{\partial f^{*}}{\partial I}(S_{0},0)=\dfrac{1}{S_{0}}\dfrac{\partial f}{\partial I}(S_{0},0),\\
&\dfrac{\partial f^{*}}{\partial S}(S^{*},I^{*})=\dfrac{1}{S^{*}}\dfrac{\partial f}{\partial S}(S^{*},I^{*}),\quad\dfrac{\partial f^{*}}{\partial I}(S^{*},I^{*})=\dfrac{1}{S^{*}}\dfrac{\partial f}{\partial I}(S^{*},I^{*}).\end{split}

(19)

We now discretize the right-hand side function of (
3
) by

\begin{split}&\Lambda-f(S(t_{n}),I(t_{n}))-\big(\mu_{0}+\nu\big)S(t_{n})\approx\Lambda-S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\nu\big)S_{n+1}\\
&f(S(t_{n}),I(t_{n}))-\big(\mu_{0}+\mu_{1}+\beta\big)I(t_{n})\approx S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\mu_{1}+\beta\big)I_{n+1},\\
&\beta I(t_{n})+\nu S(t_{n})-\mu_{0}R(t_{n})\approx\beta I_{n+1}+\nu S_{n+1}-\mu_{0}R_{n+1}.\end{split}

(20)

The systems (
17
) and (
20
) lead to the the following NSFD model for the model (
3
)

\begin{split}&\dfrac{S_{n+1}-S_{n}}{\varphi(\Delta t)}=\Lambda-S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\nu\big)S_{n+1},\\
&\dfrac{I_{n+1}-I_{n}}{\varphi(\Delta t)}=S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\mu_{1}+\beta\big)I_{n+1},\\
&\dfrac{R_{n+1}-R_{n}}{\varphi(\Delta t)}=\beta I_{n+1}+\nu S_{n+1}-\mu_{0}R_{n+1}.\end{split}

(21)

Theorem 4
.

The set
\mathbb{R}^{3}_{+}
is a positively invariant set of the NSFD model (
3
), that is,
S_{n},I_{n},R_{n}\geq 0
whenever
S_{0},I_{0},R_{0}\geq 0
. Moreover, we have

\begin{split}&\limsup_{n\to\infty}S_{n}\leq\dfrac{\Lambda}{\mu_{0}+\nu},\quad\quad\dfrac{\Lambda}{p}\leq\limsup_{n\to\infty}\big(S_{n}+I_{n}\big)\leq\dfrac{\Lambda}{q},\quad\dfrac{r_{1}\Lambda}{p\mu_{0}}\leq\limsup_{n\to\infty}R_{n}\leq\dfrac{r_{2}\Lambda}{q\mu_{0}},\end{split}

(22)

where
p,q,r_{1}
and
r_{2}
are given by (
4
).

Proof.

First, we rewrite the system (
21
) in the explicit form

\begin{split}&S_{n+1}=\dfrac{S_{n}+\varphi\Lambda}{1+\varphi f^{*}(S_{n},I_{n})+\varphi(\mu_{0}+\nu)},\\
&I_{n+1}=\dfrac{I_{n}+\varphi S_{n+1}f^{*}(S_{n},I_{n})}{1+\varphi(\mu_{0}+\mu_{1}+\beta)},\\
&R_{n+1}=\dfrac{R_{n}+\varphi\beta I_{n+1}+\varphi\nu S_{n+1}}{1+\varphi\mu_{0}}.\end{split}

(23)

Hence,
S_{n+1},I_{n+1},R_{n+1}\geq 0
if
S_{n},I_{n},R_{n}\geq 0
.

It follows from the first equation of (
21
) that

\dfrac{S_{n+1}-S_{n}}{\varphi}\leq\Lambda-(\mu_{0}+\nu)S_{n+1},

which implies that

\begin{split}S_{n+1}&\leq\dfrac{S_{n}}{1+\varphi(\mu_{0}+\nu)}+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\\
&\leq\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg[\dfrac{S_{n-1}}{1+\varphi(\mu_{0}+\nu)}+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\bigg]+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\\
&=\bigg[\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg]^{2}S_{n-1}+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\bigg[1+\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg]\\
&\leq\ldots\leq\bigg[\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg]^{n+1}S_{0}+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\sum_{j=0}^{n}\bigg(\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg)^{j}\\
&=\bigg[\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg]^{n+1}S_{0}+\dfrac{\varphi\Lambda}{1+\varphi(\mu_{0}+\nu)}\dfrac{1-\bigg(\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\bigg)^{n+1}}{1-\dfrac{1}{1+\varphi(\mu_{0}+\nu)}}.\end{split}

Letting
n\to\infty
, the first estimate of (
22
) is obtained.

Similarly, from the first and second equations of (
21
) we have

\Lambda-p(S_{n+1}+I_{n+1})\leq\dfrac{(S_{n+1}+I_{n+1})-(S_{n}+I_{n})}{\varphi}=\Lambda-(\mu_{0}+\nu)S_{n+1}-(\mu_{0}+\mu_{1}+\beta)I_{n+1}\leq\Lambda-q(S_{n+1}+I_{n+1}),

which implies that

\dfrac{\varphi\Lambda+(S_{n}+I_{n})}{1+\varphi p}\leq(S_{n+1}+I_{n+1})\leq\dfrac{\varphi\Lambda+(S_{n}+I_{n})}{1+\varphi q}.

From this estimate, we obtain the second estimate of (
22
).

Lastly, it follows from the third equation of (
21
) that

r_{1}\dfrac{\Lambda}{p}-\mu_{0}R_{n+1}\leq r_{1}(S_{n+1}+I_{n+1})-\mu_{0}R_{n+1}\leq\dfrac{R_{n+1}-R_{n}}{\varphi}\leq r_{2}(S_{n+1}+I_{n+1})-\mu_{0}R_{n+1}\leq r_{2}\dfrac{\Lambda}{q}-\mu_{0}R_{n+1}

for
n
large enough. Hence,

\dfrac{R_{n}+\varphi r_{1}{\Lambda}/{p}}{1+\varphi\mu_{0}}\leq R_{n+1}\leq\dfrac{R_{n}+\varphi r_{2}{\Lambda}/{q}}{1+\varphi\mu_{0}},

which implies the last estimate of (
22
). The proof is completed.
∎

We now compute the basic reproduction number for the discrete model (

[
4
]
.

It is easy to verify that the model (
21
) always has a unique DFE point
E^{0}=(S_{0},0,R_{0})
for all the values of the parameters. Since the first two equations of (

\begin{split}&\dfrac{S_{n+1}-S_{n}}{\varphi(\Delta t)}=\Lambda-S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\nu\big)S_{n+1},\\
&\dfrac{I_{n+1}-I_{n}}{\varphi(\Delta t)}=S_{n+1}f^{*}(S_{n},I_{n})-\big(\mu_{0}+\mu_{1}+\beta\big)I_{n+1}.\end{split}

(24)

We reorder the variables in (
24
) as
(I_{n},S_{n})
. Then, the DFE point is transformed to
(0,S_{0})
. By using (
19
), the corresponding Jacobian matrix of (

J_{0}=\begin{pmatrix}\dfrac{1+\varphi\dfrac{\partial f}{\partial I}(S_{0},0)}{1+\varphi(\mu_{0}+\mu_{1}+\beta)}&0\\
&\\
-\dfrac{\varphi\dfrac{\partial f}{\partial I}(S_{0},0)}{1+\varphi(\mu_{0}+\nu)}&\dfrac{1}{1+\varphi(\mu_{0}+\nu)}\end{pmatrix}

Following the method in

It is clear that

Hence, the basic reproduction number of the discrete model (

which means that the basic reproduction numbers of the models (

Theorem 5
.

The DEE point
E^{*}
of the NSFD model (
21
) is locally asymptotically stable if
\mathcal{R}_{0}>1
.

Proof.

The Jacobian matrix of the system (
21
) at
E^{*}
is given by

J(E^{*})=\begin{pmatrix}\dfrac{1-\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\nu)}&-\dfrac{\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\nu)}&0\\
&\\
\dfrac{\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\mu_{1}+\beta)}&\dfrac{1+\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\mu_{1}+\beta)}&0\\
&\\
\dfrac{\partial R_{n+1}}{\partial S_{n}}(E^{*})&\dfrac{\partial R_{n+1}}{\partial I_{n}}(E^{*})&\dfrac{1}{1+\varphi\mu_{0}}\end{pmatrix}.

Hence, one of three eigenvalue of
J(E^{*})
is
\lambda_{3}=\dfrac{1}{1+\varphi\mu_{0}}
and two remaining eigenvalues are the ones of the sub-matrix

J^{*}=\begin{pmatrix}\dfrac{1-\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\nu)}&-\dfrac{\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\nu)}\\
&\\
\dfrac{\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\mu_{1}+\beta)}&\dfrac{1+\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})}{1+\varphi(\mu_{0}+\mu_{1}+\beta)}\end{pmatrix}.

It is clear that
|\lambda_{3}|<1
. Denote by
\lambda_{1}
and
\lambda_{2}
the eigenvalues of
J^{*}
. We will show that
|\lambda_{1}|<1
and
|\lambda_{2}|<1
. Thanks to Theorem 2.10 in
[
3
]
, it is sufficient to verify that

|Tr(J^{*})|<1+\det(J^{*})<2.

(25)

Indeed, we first have

\det(J^{*})=\dfrac{1+\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})-\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})}{\big[1+\varphi(\mu_{0}+\mu_{1}+\beta)\big]\big[1+\varphi(\mu_{0}+\nu)\big]}.

So, it follows from (
12
) that
\det(J^{*})<1
. On the other hand,

Tr(J^{*})=\dfrac{\bigg(1-\varphi\dfrac{\partial f}{\partial S}(S^{*},I^{*})\bigg)\big[1+\varphi(\mu_{0}+\mu_{1}+\beta)\big]+\bigg(1+\varphi\dfrac{\partial f}{\partial I}(S^{*},I^{*})\bigg)\big[1+\varphi(\mu_{0}+\nu)\big]}{\big[1+\varphi(\mu_{0}+\mu_{1}+\beta)\big]\big[1+\varphi(\mu_{0}+\nu)\big]}.

Hence, it is easy to verify that

1+\det(J^{*})-Tr(J^{*})>0,\quad 1+\det(J^{*})+Tr(J^{*})>0,

or equivalently,

|Tr(J^{*})|<1+\det(J^{*}).

Therefore, (
25
) is verified. This completes the proof.

Remark 1
.

Summing up the results constructed in this section, we conclude that the NSFD model (

The NSFD scheme (

Proof.

Let
\big(S(0),I(0),R(0)\big)\in\mathbb{R}_{3}^{+}

For each arbitrary but fixed step size
\Delta t^{*}>0
, we denote

) that

\begin{split}e_{n+1}&\leq(1+m\Delta t)e_{n}+\tau\dfrac{\Delta t^{2}}{2}\\
&\leq(1+m\Delta t)\bigg[(1+m\Delta t)e_{n-1}+\tau\dfrac{\Delta t^{2}}{2}\bigg]+\tau\dfrac{\Delta t^{2}}{2}=(1+m\Delta t)^{2}e_{n-1}+\tau\dfrac{\Delta t^{2}}{2}\Big[1+(1+m\Delta t)\Big]\\
&\leq\ldots\leq(1+m\Delta t)^{n}e_{0}+\tau\dfrac{\Delta t^{2}}{2}\sum_{j=0}^{n}(1+m\Delta t)^{j}=\tau\dfrac{\Delta t^{2}}{2}\dfrac{(1+m\Delta t)^{n+1}-1}{(1+m\Delta t)-1}=\dfrac{\tau\Delta t}{2m}\big[(1+m\Delta t)^{n+1}-1\big].\end{split}

(34)

Combining (
34
) and the well-known inequality
e^{x}\geq x+1
for
x\geq 0
we obtain

e_{n+1}\leq\dfrac{\tau\Delta t}{2m}\big[e^{m(n+1)t_{n}}-1\big]=\dfrac{\tau\Delta t}{2m}\big[e^{mt_{n+1}}-1\big].

(35)

This is the desired conclusion. The proof is complete.
∎

By the estimate (
35
) we obtain the following result.

Corollary 2
.

The following estimate holds for the NSFD scheme (
21
)

|S(t_{n})-S_{n}|+|I(t_{n})-I_{n}|+|R(t_{n})-R_{n}|\leq\dfrac{\tau\Delta t}{2m}\big[e^{mt_{n}}-1\big]

for
n=0,1,2,\ldots
.

5
Conclusions and open problems

In this work, we have studied dynamics of a generalized hepatitis B epidemic model and its dynamically consistent NSFD model. The positivity, boundedness, the basic reproduction number and asymptotic stability properties of the model have been analyzed rigorously. It was proved, by the Lyapunov stability theory and the Poincare-Bendixson theorem in combination with the Bendixson-Dulac criterion, that the DFE point is globally asymptotically stable if the basic reproduction number
\mathcal{R}_{0}\leq 1
and the DEE point is globally asymptotically stable whenever
\mathcal{R}_{0}>1
. Besides, the Mickens’ methodology was applied to formulate a dynamically consistent NSFD model for the continuous model. By rigorously mathematical analyses we have shown that the constructed NSFD scheme preserves essential mathematical features of the continuous model for all finite step sizes. Finally, the numerical experiments are conducted to illustrate the theoretical findings and to demonstrate advantages of the NSFD scheme over standard ones. The obtained results provided important improvements for the ones presented in
[
36
]
and
[
59
]
.

Based on the approach in
[
36
]
, we can also use the optimal control strategy for the model (
3
) to eliminate the spreading of the HBV. This is a very interesting and important problem with many useful applications in real-world applications.

Although the constructed NSFD scheme is only convergent of order
1
, its main advantage is that it can preserve the essential properties of the continuous model for all finite step sizes. On the other hand, it can be easily combined with extrapolation techniques or variable step-size strategies to improve the accuracy. The most important thing is that it can be operate well regardless of step sizes.

In the near future, optimal control strategies and high-order NSFD schemes for the model (
3
) and its extensions will be studied. Additionally, the practice applications of the HBV model (
3
) will be also considered.
