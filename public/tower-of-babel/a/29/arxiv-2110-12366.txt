Abstract
. The Lohe sphere model and the Lohe matrix model are prototype continuous aggregation models on the unit sphere and the unitary group, respectively. These models have been extensively investigated in recent literature. In this paper, we propose several discrete counterparts for the continuous Lohe type aggregation models and study their emergent behaviors using the Lyapunov function method. For suitable discretization of the Lohe sphere model, we employ a scheme consisting of two steps. In the first step, we solve the first-order forward Euler scheme, and in the second step, we project the intermediate state onto the unit sphere. For this discrete model, we present a sufficient framework leading to the complete state aggregation in terms of system parameters and initial data. For the discretization of the Lohe matrix model, we use the Lie group integrator method, Lie-Trotter splitting method and Strang splitting method to propose three discrete models. For these models, we also provide several analytical frameworks leading to complete state aggregation and asymptotic state-locking.

To set the stage, we begin with brief two aggregation models, namely the Lohe sphere model and the Lohe matrix model. First, we consider a finite ensemble of particles lying in the unit sphere

{\mbox{\boldmath$x$}}_{i}={\mbox{\boldmath$x$}}_{i}(t)\in\mathbb{S}^{d-1}

i

(1.2)

\dot{\mbox{\boldmath$x$}}_{i}=\Omega_{i}\mbox{\boldmath$x$}_{i}+\frac{\kappa}{N}\sum_{j=1}^{N}(\mbox{\boldmath$x$}_{j}-\left\langle\mbox{\boldmath$x$}_{j},\mbox{\boldmath$x$}_{i}\right\rangle\mbox{\boldmath$x$}_{i}),\quad i\in[N],

Second, we consider the ensemble of unitary matrices, and let
U_{i}=U_{i}(t)\in{\mathbf{U}}(d)
be the state of the
i

(1.3)

\displaystyle\dot{U}_{i}U_{i}^{\dagger}=-\mathrm{i}H_{i}+\frac{\kappa}{2N}\sum_{j=1}^{N}(U_{j}U_{i}^{\dagger}-U_{i}U_{j}^{\dagger}),\quad i\in[N],

where
H_{i}
is a

The goal of this paper is to provide first-order discrete counterparts for the continuous models (
1.2

1.2

First, we use the first-order forward Euler scheme to get the intermediate state and then, we project it to the unit sphere to get the state value at next step: Let
\mbox{\boldmath$x$}_{i}(n)
be a given state of the
i
-th particle at discrete time

is the time-step. Then, the intermediate state
\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)
and the projected state
\mbox{\boldmath$x$}_{i}(n+1)
are determined by the following recursive relations:

(1.4)

\begin{cases}\displaystyle\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+h\Omega_{i}\mbox{\boldmath$x$}_{i}(n)+\frac{\kappa h}{N}\sum_{j=1}^{N}\Big(\mbox{\boldmath$x$}_{j}(n)-\left\langle\mbox{\boldmath$x$}_{j}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle\mbox{\boldmath$x$}_{i}(n)\Big),\quad n\geq 0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(n+1)=\frac{\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)}{\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert},\quad i\in[N].\end{cases}

Note that
\mbox{\boldmath$x$}_{i}(n)
lies in the unit sphere by construction for all
n\geq 0
,
i\in[N]
. From now on, we call system (
1.4

For (
1.4

\Omega_{i}=\Omega
), we provide a sufficient framework leading to complete state aggregation in which all states aggregate to the same state asymptotically. If system parameters and initial data satisfy

0<\kappa h\leq 1,\quad\min\limits_{1\leq i,j\leq N}\left\langle\mbox{\boldmath$x$}_{i}^{0},\mbox{\boldmath$x$}_{j}^{0}\right\rangle>0,

and let

be a solution to (

{\mathcal{X}}^{0}

\lim_{n\to\infty}\max_{1\leq i,j\leq N}\left\lVert\mbox{\boldmath$x$}_{i}(n)-\mbox{\boldmath$x$}_{j}(n)\right\rVert=0.

Second, we provide three discrete Lohe matrix models based on the Lie group integrator method, the Lie-Trotter splitting formula and the Strang splitting formula. More precisely, the first discrete Lohe matrix model is based on the Lie group integrator method, and it reads as follows.

(1.5)

U_{i}(n+1)=\exp\left(-\mathrm{i}H_{i}h+\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n),\quad\text{for all }i\in[N],

where

For the homogeneous zero free flow with

0<\beta:=\kappa h<\beta_{0}\approx 0.437864,\quad\max_{1\leq i,j\leq N}\left\lVert U_{i}^{0}-U_{j}^{0}\right\rVert_{\mathrm{F}}<\sqrt{4-e^{2\beta}-\frac{e^{2\beta}-1}{2\beta}},

5.8

\lim_{n\to\infty}\max_{1\leq i,j\leq N}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}=0.

As a second and third discrete Lohe matrix models, we propose the following models using the Lie-Trotter splitting formula and the Strang splitting formula as follows:

(1.6)

U_{i}(n+1)=\exp\big(-\mathrm{i}H_{i}h\big)\exp\left(\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n),

Note that for zero free flows with

Preliminaries

In this section, we briefly discuss two continuous systems “

2.1.
The Lohe matrix model

Let
U_{i}=U_{i}(t)
be a
d\times d
unitary matrix and
H_{i}
a
d\times d
hermitian matrix whose eigenvalues represent the natural frequencies of the
i
-th Lohe oscillator. We set
U_{i}^{{\dagger}}
to be the hermitian conjugate of
U_{i}
. Then the temporal evolution of
U_{i}
is governed by the Cauchy problem to the Lohe matrix model:

(2.1)

\begin{cases}\displaystyle\dot{U}_{i}U_{i}^{\dagger}=-\mathrm{i}H_{i}+\frac{\kappa}{2N}\sum_{j=1}^{N}(U_{j}U_{i}^{\dagger}-U_{i}U_{j}^{\dagger}),\quad t>0,\\
\displaystyle U_{i}\Big|_{t=0+}=U_{i}^{0}\in\mathbf{U}(d),\quad i\in[N],\end{cases}

where
\kappa
is a nonnegative coupling strength.

In the following proposition, we list several basic properties of (
2.1
) without proofs.

Proposition 2.1
.

[
38
,
39
]
The following assertions hold:

(i)

Let
{\mathcal{U}}
be a solution to the Cauchy problem (
2.1
). Then,
U_{i}U_{i}^{\dagger}
is conserved:

U_{i}(t)U_{i}^{\dagger}(t)=U_{i}^{0}U_{i}^{0\dagger},\quad t>0,~i\in[N].

(ii)

The Cauchy problem
(
2.1
)
is invariant under the right-translation by a unitary matrix in the sense that if
L\in\mathbf{U}(d)
and
V_{i}=U_{i}L
, then
V_{i}
satisfies the same system with translated initial data:

\begin{cases}\displaystyle{\mathrm{i}}\dot{V}_{i}V_{i}^{\dagger}=H_{i}-\frac{{\mathrm{i}}\kappa}{2N}\sum_{j=1}^{N}\left(V_{i}V_{j}^{\dagger}-V_{j}V_{i}^{\dagger}\right),\quad t>0,\\
\displaystyle V_{i}\Big|_{t=0+}=U^{0}_{i}L,\quad i\in[N].\end{cases}

(iii)

(Solution splitting property): Consider the free flow with the same hamiltonian and Lohe flow without the free flow part:

\dot{F}_{i}F_{i}^{\dagger}=-\mathrm{i}H,\quad\dot{L}_{i}L_{i}^{\dagger}=\frac{\kappa}{2N}\sum_{j=1}^{N}(L_{j}L_{i}^{\dagger}-L_{i}L_{j}^{\dagger}).

Then, the solution operator for (
2.1
) can be rewritten as a composition of the solution operator for the free flow and pure Lohe flow:

U_{i}(t)=\Big(F(t)L(t){\mathcal{U}}^{0}\Big)_{i},\quad i\in[N].

Before we discuss the emergent dynamics of (
2.1

2.1

Definition 2.2
.

[
30

(i)

The ensemble

U_{i}(t)U_{j}^{\dagger}(t)=U_{i}^{0}(U_{j}^{0})^{\dagger},\quad t>0,~~i,j\in[N].

(ii)

The ensemble
{\mathcal{U}}
exhibits asymptotic state-locking, if
U_{i}U_{j}^{{\dagger}}
has a limit as
t\to\infty
:

\exists~~\lim\limits_{t\to\infty}U_{i}(t)U_{j}^{\dagger}(t),\quad i,j\in[N].

In the sequel, we again list the emergent dynamics of (
2.1
) without proofs.

Proposition 2.3
.

[
30
]

(i)

(Homogeneous ensemble): Suppose system parameters and initial data satisfy

(2.2)

{\mathcal{D}}({\mathcal{H}})=0,\quad\kappa>0,\quad{\mathcal{U}}^{0}\in\mathcal{B}(\sqrt{2}),

and let
{\mathcal{U}}
be a solution to (
2.1

{\mathcal{D}}({\mathcal{U}})

(ii)

{\mathcal{D}}({\mathcal{H}})>0,\quad\kappa>\kappa_{e}>\frac{54}{17}{\mathcal{D}}({\mathcal{H}}),\quad{\mathcal{U}}^{0}\in\mathcal{B}(\alpha),

(ii)

Let

2.2.
The Lohe sphere model

Let
\mbox{\boldmath$x$}_{i}=\mbox{\boldmath$x$}_{i}(t)
be the position of the
i
-th swarming particle on the unit sphere
\mathbb{S}^{d-1}
, and
\Omega_{i}
is a
d\times d
skew-symmetric matrix. Then the Lohe sphere model reads as follows:

(2.7)

\begin{cases}\displaystyle\dot{\mbox{\boldmath$x$}}_{i}=\Omega_{i}\mbox{\boldmath$x$}_{i}+\frac{\kappa}{N}\sum_{j=1}^{N}\Big(\mbox{\boldmath$x$}_{j}-\left\langle\mbox{\boldmath$x$}_{j},\mbox{\boldmath$x$}_{i}\right\rangle\mbox{\boldmath$x$}_{i}\Big),\quad t>0,\\

Note that for

, a special case for (
2.7

2.1

in terms of Pauli’s matrices

U_{i}:=e^{-{\mathrm{i}}\theta_{i}}\Big({\mathrm{i}}\sum_{k=1}^{3}x_{i}^{k}\sigma_{k}+x_{i}^{4}I_{2}\Big)=e^{-{\mathrm{i}}\theta_{i}}\left(\begin{array}[]{cc}x_{i}^{4}+{\mathrm{i}}x_{i}^{1}&x_{i}^{2}+{\mathrm{i}}x_{i}^{3}\\
-x_{i}^{2}+{\mathrm{i}}x_{i}^{3}&x_{i}^{4}-{\mathrm{i}}x_{i}^{1}\\
\end{array}\right),

where
I_{2}
and
\sigma_{i}
are the identity matrix and Pauli matrices, respectively, defined by

I_{2}:=\left(\begin{array}[]{cc}1&0\\
0&1\\
\end{array}\right),\quad\sigma_{1}:=\left(\begin{array}[]{cc}1&0\\
0&-1\\
\end{array}\right),\quad\sigma_{2}:=\left(\begin{array}[]{cc}0&-{\mathrm{i}}\\
{\mathrm{i}}&0\\
\end{array}\right),\quad\sigma_{3}:=\left(\begin{array}[]{cc}0&1\\
1&0\\
\end{array}\right).

We also expand the hamiltonian matrix
H_{i}

H_{i}=\sum_{k=1}^{3}\omega_{i}^{k}\sigma_{k}+\nu_{i}I_{2},

where
\omega_{i}=(\omega_{i}^{1},\omega_{i}^{2},\omega_{i}^{3})

\Omega_{i}:=\left(\begin{array}[]{cccc}0&-\omega_{i}^{3}&\omega_{i}^{2}&-\omega_{i}^{1}\\

-\omega_{i}^{2}&\omega_{i}^{1}&0&-\omega_{i}^{3}\\
\omega_{i}^{1}&\omega_{i}^{2}&\omega_{i}^{3}&0\\

\Omega_{i}
skew-symmetric matrix. By taking

\lim_{t\to\infty}\max_{1\leq i,j\leq N}\left\lVert\mbox{\boldmath$x$}_{i}-\mbox{\boldmath$x$}_{j}\right\rVert=0.

2. Note that

\left\langle\mbox{\boldmath$x$}^{0}_{i},\mbox{\boldmath$x$}^{0}_{c}\right\rangle=\frac{1}{N}\sum_{j=1}^{N}\left\langle\mbox{\boldmath$x$}^{0}_{i},\mbox{\boldmath$x$}^{0}_{j}\right\rangle\geq\min\limits_{1\leq i,j\leq N}\langle\mbox{\boldmath$x$}^{0}_{i},\mbox{\boldmath$x$}^{0}_{j}\rangle.

This yields

\min\limits_{1\leq i\leq N}\left\langle\mbox{\boldmath$x$}^{0}_{i},\mbox{\boldmath$x$}^{0}_{c}\right\rangle\geq\min\limits_{1\leq i,j\leq N}\langle\mbox{\boldmath$x$}^{0}_{i},\mbox{\boldmath$x$}^{0}_{j}\rangle.

Therefore, the condition in the second statement is more relaxed compared to the condition of the first statement.

3. For a heterogeneous ensemble, we do not have a good theory of asymptotic state-locking up to now.

Thanks to solution splitting property for (
2.7
) similar to Proposition
2.1
(iii), we may assume
\Omega_{i}=O
for a homogeneous ensemble. Like the Lohe matrix model, system (
2.7
) for a homogeneous ensemble can be rewritten as a gradient system:

(2.9)

{\dot{\mbox{\boldmath$x$}}}_{i}=\kappa{\mathbb{P}}_{\mbox{\boldmath$x$}_{i}}^{\perp}\Big(\frac{1}{N}\sum_{k=1}^{N}\mbox{\boldmath$x$}_{k}\Big),\quad i\in[N],

where
{\mathbb{P}}^{\perp}_{\mbox{\boldmath$x$}_{i}}
is the orthogonal projection onto the tangent plane perpendicular to
\mbox{\boldmath$x$}_{i}
:

{\mathbb{P}}^{\perp}_{\mbox{\boldmath$x$}_{i}}\mbox{\boldmath$y$}=\mbox{\boldmath$y$}-\langle\mbox{\boldmath$y$},\mbox{\boldmath$x$}_{i}\rangle\mbox{\boldmath$x$}_{i}.

Now, we introduce a potential function
{\mathcal{V}}_{s}
:

{\mathcal{V}}_{s}({\mathcal{X}}):=-\frac{\kappa}{2N}\sum_{i,j=1}^{N}\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle=-\frac{\kappa}{2}N\rho^{2}.

Proposition 2.8
.

Suppose system parameters satisfy

\Omega_{i}=\Omega,\quad i\in[N]\quad\mbox{and}\quad\kappa>0.

Then, the following assertions hold.

(i)

System (
2.9
) with
\Omega=O
is a gradient flow with the analytical potential
{\mathcal{V}}_{s}
:

{\dot{\mbox{\boldmath$x$}}}_{i}=-\left.\frac{\partial\mathcal{V}_{s}}{\partial\mbox{\boldmath$x$}_{i}}\right|_{T_{\mbox{\boldmath$x$}_{i}}{\mathbb{S}}^{d-1}},\quad t>0,\quad i\in[N].

(ii)

Let
{\mathcal{X}}
be a solution to (
2.9
) with the initial configuration
{\mathcal{X}}^{0}
. Then, the quantities
e^{-\Omega t}\mbox{\boldmath$x$}_{i}(t)
converge as
t\to\infty
for any initial data
{\mathcal{X}}^{0}
.

In the following sections, we study several discrete counterparts for the Lohe sphere model and the Lohe matrix model, respectively.

3.
Discrete Lohe flow on the unit sphere

In this section, we first present the scheme of a discrete Lohe sphere model and then, we study its emergent dynamics under a suitable framework in terms of system parameters and initial data.

3.1.
Euler method with projection

In this subsection, we briefly discuss the Euler method for the first-order ODE model on a general manifold. It consists of the forward first-order Euler scheme and projection onto the underlying manifold. More precisely, let
\mathcal{M}
be a one-particle state space manifold embedded in Euclidean space, and consider the following Cauchy problem:

(3.1)

\begin{cases}\displaystyle\dot{\mbox{\boldmath$x$}}_{i}={\boldmath f}_{i}({\mathcal{X}}),\quad t>0,~~i\in[N],\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in\mathcal{M}.\end{cases}

For the well-posedness of (
3.1
), we require the vector field
F_{i}({\mathcal{X}})\in T_{\mbox{\boldmath$x$}_{i}}{\mathcal{M}}
so that underlying manifold
{\mathcal{M}}
is positively invariant by the flow generated by (
3.1
):

\mbox{\boldmath$x$}_{i}^{0}\in\mathcal{M}\quad\implies\quad\mbox{\boldmath$x$}_{i}(t)\in\mathcal{M},\quad\forall~t\geq 0,~~i\in[N].

Let
{\mathcal{X}}(n)
be given at the
n
-th time step. Then, as a naive discretization of (
3.1
), we first apply the first-order forward Euler method for (
3.1
) to get an intermediate value
{\widetilde{\mathcal{X}}}(n+1)
:

(3.2)

{\widetilde{\mbox{\boldmath$x$}}}_{i}(n+1)={\mbox{\boldmath$x$}}_{i}(n)+h{\boldmath f}_{i}({\mathcal{X}}(t)),\quad i\in[N].

Even if

\mbox{\boldmath$x$}_{i}(n)\in{\mathcal{M}},\quad{\boldmath f}_{i}({\mathcal{X}}(n))\in T_{\mbox{\boldmath$x$}_{i}(n)}\mathcal{M},

\mbox{\boldmath$x$}_{i}(n+1)
given by (
3.2
) may not lie in
\mathcal{M}
. Thus, the naive scheme (
3.2
) is not a dynamical system on
{\mathcal{M}}
in geneal. To recast system (
3.2
) to a dynamical system on
{\mathcal{M}}
, the projecting step is required.

In summary, the proposed discrete model for (
3.1
) reads as follows.

(3.3)

\begin{cases}\displaystyle\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+h{\boldmath f}_{i}({\mathcal{X}}(n)),\quad n\geq 0,~~i\in[N],\\
\displaystyle\mbox{\boldmath$x$}_{i}(n+1)={\mathbb{P}}_{\mathcal{M}}\widetilde{\mbox{\boldmath$x$}}_{i}(n+1),\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in\mathcal{M},\end{cases}

where
{\mathbb{P}}_{\mathcal{M}}
is a projection operator from
{\mathbb{R}}^{d}
to
{\mathcal{M}}
.

By the construction of (
3.3
), as long as the discrete model (
3.3
) admits a solution, one has

\mbox{\boldmath$x$}_{i}(n)\in{\mathcal{M}},\quad n\geq 0,~~i\in[N].

3.2.
Discrete Lohe sphere model

Now, we present a discrete Lohe sphere model using the discrete algorithm discussed in Section
3.1
and study its emergent dynamics.

Note that the Lohe sphere model is the first-order consensus model on the unit sphere
\mathbb{S}^{d-1}
. The projection onto the unit sphere is given by rescaling:

\mathbb{P}_{\mathbb{S}^{d-1}}(\mbox{\boldmath$x$})=\frac{\mbox{\boldmath$x$}}{\left\lVert\mbox{\boldmath$x$}\right\rVert},\quad\mbox{\boldmath$x$}\in{\mathbb{R}}^{d}\setminus\{\mathbf{0}\}.

Then, the discrete Lohe sphere model with Euler’s method reads as follows:

(3.4)

\begin{cases}\displaystyle\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+h\Omega_{i}\mbox{\boldmath$x$}_{i}(n)+\frac{\kappa h}{N}\sum_{j=1}^{N}\Big(\mbox{\boldmath$x$}_{j}(n)-\left\langle\mbox{\boldmath$x$}_{j}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle\mbox{\boldmath$x$}_{i}(n)\Big),\quad n\geq 0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(n+1)=\frac{\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)}{\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert},\quad i\in[N].\end{cases}

Note that
\mbox{\boldmath$x$}_{i}(n)
lies in the unit sphere for all
n\geq 0
,
i\in[N]
.

It is well known that the Lohe sphere model on
{\mathbb{S}}^{1}
can be reduced to the Kuramoto model at the continuous level. In the sequel, we see that this reduction is also valid for the discrete level as well. For this, we set

(3.5)

\mbox{\boldmath$x$}_{i}=\begin{pmatrix}\cos\theta_{i}\\
\sin\theta_{i}\end{pmatrix},\quad\Omega_{i}=\begin{pmatrix}0&-\nu_{i}\\
\nu_{i}&0\end{pmatrix}.

First, it follows from
\eqref{C-3}_{2}
and (
3.5
) that

(3.6)

\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert\mbox{\boldmath$x$}_{i}(n+1)=\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert\begin{pmatrix}\cos\theta_{i}(n+1)\\
\sin\theta_{i}(n+1)\end{pmatrix}.

On the other hand, it follows from
\eqref{C-3}_{1}
that

(3.7)

\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\begin{pmatrix}\cos\theta_{i}(n)\\
\sin\theta_{i}(n)\end{pmatrix}+\left(\nu_{i}h+\frac{\kappa h}{N}\sum_{j=1}^{N}\sin(\theta_{j}(n)-\theta_{i}(n))\right)\begin{pmatrix}-\sin\theta_{i}(n)\\
\cos\theta_{i}(n)\end{pmatrix}.

We introduce
\phi(n)\in(-\frac{\pi}{2},\frac{\pi}{2})
to satisfy

\tan\phi(n)=\nu_{i}h+\frac{\kappa h}{N}\sum_{j=1}^{N}\sin(\theta_{j}(n)-\theta_{i}(n)).

By combining (
3.6
) and (
3.7
), one has

(3.8)

\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert\begin{pmatrix}\cos\theta_{i}(n+1)\\
\sin\theta_{i}(n+1)\end{pmatrix}=\begin{pmatrix}\cos\theta_{i}(n)\\
\sin\theta_{i}(n)\end{pmatrix}+\tan\phi(n)\begin{pmatrix}-\sin\theta_{i}(n)\\
\cos\theta_{i}(n)\end{pmatrix}.

We take squaring the relations in (
3.8
) and use trigonometric identity to find

(3.9)

\begin{cases}\displaystyle\|\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\|=\frac{1}{\cos\phi(n)},\quad n\geq 0,\\
\displaystyle\theta_{i}(n+1)=\theta_{i}(n)+\arctan\Bigg(\nu_{i}h+\frac{\kappa h}{N}\sum_{j=1}^{N}\sin(\theta_{j}(n)-\theta_{i}(n))\Bigg),\quad i\in[N].\end{cases}

Note that for
|x|\ll 1
, one has
\arctan(x)\approx x
. So
\eqref{C-5}_{2}
becomes the discrete Kuramoto model
[
11
,
45
,
55
]
:

(3.10)

\theta_{i}(n+1)=\theta_{i}(n)+\nu_{i}h+\frac{\kappa h}{N}\sum_{j=1}^{N}\sin(\theta_{j}(n)-\theta_{i}(n)).

Emergent dynamics of (
3.10
) and uniform-in-time transition to the continuous dynamics have been discussed in recent literatures, e.g., exponential synchronization
[
11
]
for some restricted initial configuration, complete synchronization
[
45
,
55
]
for a generic initial configuration and uniform-in-time transition from discrete dynamics to continuous dynamics
[
21
]
.

3.3.
Emergent dynamics

Next, we return to the Lohe sphere model (
2.7
) for a homogeneous ensemble:

\Omega_{i}=\Omega,\quad i\in[N].

We set

\mbox{\boldmath$y$}_{i}(t)=e^{-\Omega t}\mbox{\boldmath$x$}_{i}(t),\quad i\in[N].

Then, it satisfies same equation (
2.7
) with every
\Omega_{i}
being the zero matrix. To sum up, without loss of generality, we may assume

\Omega_{i}=O,\quad i\in[N].

To sum up, we consider the discrete Lohe sphere model:

(3.11)

\begin{cases}\displaystyle\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+\frac{\kappa h}{N}\sum_{j=1}^{N}\Big(\mbox{\boldmath$x$}_{j}(n)-\left\langle\mbox{\boldmath$x$}_{j}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle\mbox{\boldmath$x$}_{i}(n)\Big),\quad n\geq 0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(n+1)=\frac{\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)}{\left\lVert\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\right\rVert},\quad i\in[N].\end{cases}

Recursive relation
\eqref{C-6}_{1}
can be rewritten in a handy form using the averaged state
\mbox{\boldmath$x$}_{c}:=\frac{1}{N}\sum_{j=1}^{N}\mbox{\boldmath$x$}_{j}
:

\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+\kappa h\Big(\mbox{\boldmath$x$}_{c}(n)-\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{c}(n)\rangle\mbox{\boldmath$x$}_{i}(n)\Big).

For the emergent dynamics of (
3.11
), we introduce several functionals: for
n\geq 0
and
{\mathcal{X}}(n)=(\mbox{\boldmath$x$}_{1}(n),\cdots,\mbox{\boldmath$x$}_{N}(n))\in\big(\mathbb{S}^{d}\big)^{N}
,

(3.12)

\displaystyle\begin{aligned} &\rho(n)=\left\lVert\mbox{\boldmath$x$}_{c}(n)\right\rVert,\quad\mbox{\boldmath$x$}_{c}(n):=\rho(n){\hat{\mbox{\boldmath$x$}}}_{c}(n),\quad A_{i}(n):=\left\langle\mbox{\boldmath$x$}_{i}(n),{\hat{\mbox{\boldmath$x$}}}_{c}(n)\right\rangle,\\
&B_{ij}(n):=\left\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\right\rangle,\quad\mathcal{A}(n):=\min\limits_{1\leq i\leq N}A_{i}(n),\quad\mathcal{B}(n):=\min\limits_{1\leq i,j\leq N}B_{ij}(n).\end{aligned}

To describe the behavior of the functionals
\mathcal{A}
and
\mathcal{B}
, we first note that

(3.13)

\displaystyle\begin{aligned} &\langle{\widetilde{\mbox{\boldmath$x$}}}_{i}(n+1),{\widetilde{\mbox{\boldmath$x$}}}_{j}(n+1)\rangle\\
&\hskip 14.22636pt=\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle+\kappa h\langle\mbox{\boldmath$x$}_{i}+\mbox{\boldmath$x$}_{j},\mbox{\boldmath$x$}_{c}\rangle(1-\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle)\\
&\hskip 19.91684pt+(\kappa h)^{2}\Big(\|\mbox{\boldmath$x$}_{c}\|^{2}-\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{c}\rangle^{2}-\langle\mbox{\boldmath$x$}_{j},\mbox{\boldmath$x$}_{c}\rangle^{2}+\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{c}\rangle\cdot\langle\mbox{\boldmath$x$}_{j},\mbox{\boldmath$x$}_{c}\rangle\cdot\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle\Big)\\
&\hskip 14.22636pt=\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle+(\kappa h\rho)\langle\mbox{\boldmath$x$}_{i}+\mbox{\boldmath$x$}_{j},{\hat{\mbox{\boldmath$x$}}}_{c}\rangle\Big(1-\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle\Big)\\
&\hskip 19.91684pt+(\kappa h\rho)^{2}\Big(1-\langle\mbox{\boldmath$x$}_{i},{\hat{\mbox{\boldmath$x$}}}_{c}\rangle^{2}-\langle\mbox{\boldmath$x$}_{j},{\hat{\mbox{\boldmath$x$}}}_{c}\rangle^{2}+\langle\mbox{\boldmath$x$}_{i},{\hat{\mbox{\boldmath$x$}}}_{c}\rangle\cdot\langle\mbox{\boldmath$x$}_{j},{\hat{\mbox{\boldmath$x$}}}_{c}\rangle\cdot\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\rangle\Big).\end{aligned}

Then, (
3.13
) and
\|\mbox{\boldmath$x$}_{i}(n)\|^{2}=1
imply

(3.14)

\|\widetilde{\mbox{\boldmath$x$}}_{i}(n+1)\|^{2}=1+(\kappa h\rho(n))^{2}\Big(1-\langle{\hat{\mbox{\boldmath$x$}}}_{c}(n),\mbox{\boldmath$x$}_{i}(n)\rangle^{2}\Big).

Finally,
\eqref{C-6}_{2}
, (
3.13
) and (
3.14
) yield

(3.15)

\displaystyle\begin{split}&\left\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{j}(n+1)\right\rangle\\
&\hskip 14.22636pt=\frac{\begin{multlined}\left\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\right\rangle+(\kappa h\rho)\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{i}+\mbox{\boldmath$x$}_{j}\right\rangle(1-\left\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\right\rangle)\\
\\
+(\kappa h\rho)^{2}\left(1-\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{i}\right\rangle^{2}-\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{j}\right\rangle^{2}+\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{i}\right\rangle\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{j}\right\rangle\left\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{j}\right\rangle\right)\end{multlined}}{\sqrt{1+(\kappa h\rho)^{2}\left(1-\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{i}\right\rangle^{2}\right)}\sqrt{1+(\kappa h\rho)^{2}\left(1-\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{j}\right\rangle^{2}\right)}}\end{split}

for
n\geq 0,~i,j\in[N]
. Here the right hand side of (
3.15
) is evaluated at the
n
-th time step.

Lemma 3.1
.

Suppose system parameters and initial data satisfy

0<\beta:=\kappa h\leq 1,\quad\mathcal{B}(0)=\min\limits_{1\leq i,j\leq N}\langle\mbox{\boldmath$x$}_{i}^{0},\mbox{\boldmath$x$}_{j}^{0}\rangle>0,

and let
{\mathcal{X}}
be a solution to (
3.11
) with the initial data
{\mathcal{X}}^{0}
. Then, the following assertions hold.

(i)

For each
i,j\in[N]
,
B_{ij}(n)
defined in (
3.12
) is monotonically increasing in
n
:

B_{ij}(n+1)\geq B_{ij}(n),\quad n\geq 0.

(ii)

The functionals
\langle\mbox{\boldmath$x$}_{i},\mbox{\boldmath$x$}_{c}\rangle
and
\rho
are monotonically increasing in
n
:

\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{c}(n+1)\rangle\geq\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{c}(n)\rangle,\quad\rho(n+1)\geq\rho(n),\quad n\geq 0.

Proof.

(i) It suffices to show that if
\mathcal{B}(n)>0
,

B_{ij}(n+1)\geq B_{ij}(n).

Since
\mathcal{B}(n)>0
, one has

(3.16)

0<A_{i}(n),B_{ij}(n)\leq 1,\quad i,j\in[N].

For notational simplicity, we set

\gamma(n):=\kappa h\rho(n)\leq 1.

We use (
3.15
) to see that

\displaystyle\begin{aligned} &\left\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{j}(n+1)\right\rangle\geq\left\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\right\rangle=B_{ij}\\
&\hskip 42.67912pt\Longleftrightarrow\quad B_{ij}+\gamma(A_{i}+A_{j})(1-B_{ij})+\gamma^{2}(1-A_{i}^{2}-A_{j}^{2}+A_{i}A_{j}B_{ij})\\
&\hskip 128.0374pt\geq B_{ij}\sqrt{1+\gamma^{2}(1-A_{i}^{2})}\sqrt{1+\gamma^{2}(1-A_{j}^{2})}\\
&\hskip 42.67912pt\Longleftarrow\quad B_{ij}+\gamma(A_{i}+A_{j})(1-B_{ij})+\gamma^{2}(1-A_{i}^{2}-A_{j}^{2}+A_{i}A_{j}B_{ij})\\
&\hskip 128.0374pt\geq B_{ij}+\gamma^{2}\left(1-\frac{A_{i}^{2}+A_{j}^{2}}{2}\right)B_{ij}\\
&\hskip 42.67912pt\Longleftrightarrow\quad(A_{i}+A_{j})(1-B_{ij})\geq\gamma\left(A_{i}^{2}+A_{j}^{2}+B_{ij}-1-\frac{(A_{i}+A_{j})^{2}}{2}B_{ij}\right),\end{aligned}

where we used the inequality:

(3.17)

\sqrt{1+x}\sqrt{1+y}\leq 1+\frac{x+y}{2}\quad\mbox{for $x,y\geq 0$},

and
A_{i},B_{ij}
and
\gamma
are evaluated at the
n
-th time step. On the other hand, by the Cauchy-Schwarz inequality, one has

(3.18)

(A_{i}-A_{j})^{2}=\left\lvert\left\langle{\hat{\mbox{\boldmath$x$}}}_{c},\mbox{\boldmath$x$}_{i}-\mbox{\boldmath$x$}_{j}\right\rangle\right\rvert^{2}\leq\left\lVert\mbox{\boldmath$x$}_{i}-\mbox{\boldmath$x$}_{j}\right\rVert^{2}=2(1-B_{ij}).

Finally, we use
\gamma\leq 1
, (
3.16
) and (
3.18
) to see

\displaystyle\begin{aligned} &\gamma\left(A_{i}^{2}+A_{j}^{2}+B_{ij}-1-\frac{(A_{i}+A_{j})^{2}}{2}B_{ij}\right)\leq\;A_{i}^{2}+A_{j}^{2}-\frac{(A_{i}-A_{j})^{2}}{2}-\frac{(A_{i}+A_{j})^{2}}{2}B_{ij}\\
&\hskip 28.45274pt=\frac{(A_{i}+A_{j})^{2}}{2}(1-B_{ij})\leq(A_{i}+A_{j})(1-B_{ij}).\end{aligned}

(ii) We use the result (i) to find that for a fixed
i\in[N]
,

\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{j}(n+1)\rangle\geq\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\rangle,\quad n\geq 0.

We sum the above relation over
j\in[N]
and then divide the resulting relation by
N
to find

\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{c}(n+1)\rangle\geq\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{c}(n)\rangle,\quad n\geq 0.

On the other hand, by the definition of
\rho
and the result of (i), one has

\displaystyle\begin{aligned} \rho(n+1)^{2}&=\langle\mbox{\boldmath$x$}_{c}(n+1),\mbox{\boldmath$x$}_{c}(n+1)\rangle=\frac{1}{N^{2}}\sum_{i,j\in[N]}\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{j}(n+1)\rangle\\
&\geq\frac{1}{N^{2}}\sum_{i,j\in[N]}\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\rangle=\langle\mbox{\boldmath$x$}_{c}(n),\mbox{\boldmath$x$}_{c}(n)\rangle=\rho(n)^{2},\quad n\geq 0.\end{aligned}

This yields the desired estimate.
∎

Now, we are ready to provide our first main result on the complete state aggregation of (
3.11
).

Theorem 3.2
.

Suppose system parameters and initial data satisfy

0<\beta=\kappa h\leq 1,\quad\mathcal{B}(0)=\min\limits_{1\leq i,j\leq N}\langle\mbox{\boldmath$x$}_{i}^{0},\mbox{\boldmath$x$}_{j}^{0}\rangle>0,

and let
{\mathcal{X}}
be a solution to (
3.11
) with the initial data
{\mathcal{X}}^{0}
. Then, the complete state aggregation emerges:

\lim_{n\to\infty}\max_{1\leq i,j\leq N}\left\lVert\mbox{\boldmath$x$}_{i}(n)-\mbox{\boldmath$x$}_{j}(n)\right\rVert=0.

Proof.

Since

\|\mbox{\boldmath$x$}_{i}(n)-\mbox{\boldmath$x$}_{j}(n)\|^{2}=2(1-\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\rangle)=2(1-B_{ij}(n)),

it suffices to show

(3.19)

\lim_{n\to\infty}B_{ij}(n)=1.

Proof of (
3.19
)
: By Lemma
3.1
, the following quantities

\rho(n),\quad\left\langle\mbox{\boldmath$x$}_{c}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle=\rho(n)\left\langle{\hat{\mbox{\boldmath$x$}}}_{c}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle=\rho(n)A_{i}(n),\quad B_{ij}(n)=\left\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\right\rangle

monotonically increase, as
n
increases and these are bounded above by
1
. Hence, there exist numbers
\rho^{\infty},~A_{i}^{\infty},~B_{ij}^{\infty}\in(0,1)
such that

\lim_{n\to\infty}\rho(n)=\rho^{\infty},\quad\lim_{n\to\infty}\left\langle\mbox{\boldmath$x$}_{c}(n),\mbox{\boldmath$x$}_{i}(n)\right\rangle=A_{i}^{\infty},\quad\lim_{n\to\infty}\left\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\right\rangle=B_{ij}^{\infty},

for all
i,j\in[N]
. Then, one has

\lim_{n\to\infty}\left\langle\mbox{\boldmath$x$}_{i}(n),\mbox{\boldmath$x$}_{j}(n)\right\rangle=\lim_{n\to\infty}\left\langle\mbox{\boldmath$x$}_{i}(n+1),\mbox{\boldmath$x$}_{j}(n+1)\right\rangle=B_{ij}^{\infty},

and we use (
3.17
) to get

(3.20)

\displaystyle\begin{aligned} &B_{ij}^{\infty}+\beta(A_{i}^{\infty}+A_{j}^{\infty})(1-B_{ij}^{\infty})+\beta^{2}\big\{(\rho^{\infty})^{2}-(A_{i}^{\infty})^{2}-(A_{j}^{\infty})^{2}+A_{i}^{\infty}A_{j}^{\infty}B_{ij}^{\infty}\big\}\\
&\hskip 14.22636pt=B_{ij}^{\infty}\sqrt{1+\beta^{2}\big\{(\rho^{\infty})^{2}-(A_{i}^{\infty})^{2}\big\}}\sqrt{1+\beta^{2}\big\{(\rho^{\infty})^{2}-(A_{j}^{\infty})^{2}\big\}}.\end{aligned}

Since

(A_{i}(n)-A_{j}(n))^{2}=\left\lvert\left\langle\mbox{\boldmath$x$}_{c},\mbox{\boldmath$x$}_{i}-\mbox{\boldmath$x$}_{j}\right\rangle\right\rvert^{2}\leq\left\lVert\mbox{\boldmath$x$}_{c}\right\rVert^{2}\left\lVert\mbox{\boldmath$x$}_{i}-\mbox{\boldmath$x$}_{j}\right\rVert^{2}=2\rho(n)^{2}(1-B_{ij}(n)),

we have

(A_{i}^{\infty}-A_{j}^{\infty})^{2}\leq 2(\rho^{\infty})^{2}(1-B_{ij}^{\infty}).

On the other hand, note the following quantity:

\Delta B_{ij}(n)=B_{ij}(n+1)-B_{ij}(n).

We take
n\to\infty
to
\Delta B_{ij}(n)
and use (
3.16
) and (
3.20
) to get

\displaystyle\begin{aligned} 0&\geq B_{ij}^{\infty}+\beta(A_{i}^{\infty}+A_{j}^{\infty})(1-B_{ij}^{\infty})+\beta^{2}\big\{(\rho^{\infty})^{2}-(A_{i}^{\infty})^{2}-(A_{j}^{\infty})^{2}+A_{i}^{\infty}A_{j}^{\infty}B_{ij}^{\infty}\big\}\\
&\hskip 5.69046pt-B_{ij}^{\infty}\left(1+\beta^{2}\left((\rho^{\infty})^{2}-\frac{(A_{i}^{\infty})^{2}+(A_{j}^{\infty})^{2}}{2}\right)\right)\\
&=\beta(A_{i}^{\infty}+A_{j}^{\infty})(1-B_{ij}^{\infty})-\beta^{2}\frac{(A_{i}^{\infty}+A_{j}^{\infty})^{2}}{2}(1-B_{ij}^{\infty})\\
&\hskip 28.45274pt+\beta^{2}\left\{(\rho^{\infty})^{2}(1-B_{ij}^{\infty})-\frac{(A_{i}^{\infty}-A_{j}^{\infty})^{2}}{2}\right\}\\
&\geq\beta(A_{i}^{\infty}+A_{j}^{\infty})(1-B_{ij}^{\infty})\left(1-\beta\frac{A_{i}^{\infty}+A_{j}^{\infty}}{2}\right)\geq 0.\end{aligned}

This yields,

\mbox{either}~B_{ij}^{\infty}=1\quad\mbox{or}\quad\beta(A_{i}^{\infty}+A_{j}^{\infty})=2.

Since
0<\beta\leq 1
and
0<A_{i}\leq 1
, the latter case implies

\beta=A_{i}^{\infty}=A_{j}^{\infty}=1.

This implies
B_{ij}^{\infty}=1
. Therefore, for all cases, we get the desired estimate:

B_{ij}^{\infty}=1,\quad i,j\in[N].

∎

4.
Discrete Lohe matrix flow on the unitary group

In this section, we present several discretization algorithms for the Lohe matrix model (
1.3
) using an exponential map such as the Lie group integrator method and splitting methods, and then we apply the aforementioned discretization algorithms to the Lohe matrix model to derive three different discrete models for the Lohe matrix model. More over, for the three discrete models, we study their emergent properties.

4.1.
Discretization methods

In this subsection, we study two discretization methods, namely “
the Lie group integrator method
” and “
operator splitting method
”. The Euler method discussed in the previous section may not preserve the structure of a state and thus a projection is required. In what follows, we present discretization algorithms without a projection step.

4.1.1.
The Lie group integrator method

Let
({\mathcal{M}},\langle\cdot,\cdot\rangle_{{\mathcal{M}}})
be a Riemannian manifold with metric
\langle\cdot,\cdot\rangle_{\mathcal{M}}
, and we consider the Cauchy problem:

(4.1)

\begin{cases}\displaystyle\dot{\mbox{\boldmath$x$}}_{i}={\boldmath f}_{i}({\mathcal{X}}),\quad t>0,~~i\in[N],\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in\mathcal{M},\end{cases}

where we assumed

(4.2)

{\boldmath f}_{i}({\mathcal{X}})\in T_{\mbox{\boldmath$x$}}\mathcal{M}\quad\mbox{at any point $\mbox{\boldmath$x$}\in M$},~~i\in[N].

As noticed before, the forward Euler scheme does not guarantee
{\mathcal{X}}(n+1)\in\mathcal{M}^{N}
even if
{\mathcal{X}}(n)\in{\mathcal{M}}^{N}
in general. Thus, we take the update of
\mbox{\boldmath$x$}_{i}(n)
to the tangential direction
{\boldmath f}_{i}({\mathcal{X}}(n))
via an
exponential map

[
5
,
17
]
. Before we move on further, we briefly recall the exponential map below. We set the tangent bundle
T{\mathcal{M}}
as

T{\mathcal{M}}:=\{(\mbox{\boldmath$x$},\mbox{\boldmath$v$})\in{\mathcal{M}}\times T_{\mbox{\boldmath$x$}}{\mathcal{M}}:~\mbox{\boldmath$x$}\in{\mathcal{M}},~~\mbox{\boldmath$v$}\in T_{\mbox{\boldmath$x$}}{\mathcal{M}}\},

where
T_{\mbox{\boldmath$x$}}{\mathcal{M}}
is the tangent space of
\mathcal{M}
at
\mbox{\boldmath$x$}\in{\mathcal{M}}
.
Since we are interested in asymptotic behaviors, we only consider that the Riemannian manifold
{\mathcal{M}}
is
geodesically complete
in the sense that for any two points
\mbox{\boldmath$x$},\mbox{\boldmath$y$}\in{\mathcal{M}}
, there exists a unique length minimizing geodesic between
x
and
y
. For a given
(\mbox{\boldmath$x$},\mbox{\boldmath$v$})\in{\mathcal{M}}\times T_{\mbox{\boldmath$x$}}{\mathcal{M}}
, let
\gamma:[0,1]\to{\mathcal{M}}
be a locally length minimizing geodesic such that

(4.3)

\gamma(0)=\mbox{\boldmath$x$},\quad{\dot{\gamma}}(0)=\mbox{\boldmath$v$}.

For
\mbox{\boldmath$x$}\in{\mathcal{M}}
, the exponential map
\mbox{exp}_{\mbox{\boldmath$x$}}:~T_{\mbox{\boldmath$x$}}{\mathcal{M}}\to{\mathcal{M}}
is defined as

\exp_{\mbox{\boldmath$x$}}(\mbox{\boldmath$v$}):=\gamma(1).

Note that for the trivial manifold
{\mathcal{M}}={\mathbb{R}}^{d}
, one has

T_{x}{\mathcal{M}}\simeq{\mathbb{R}}^{d},\quad T{\mathcal{M}}\simeq{\mathbb{R}}^{d}\times{\mathbb{R}}^{d},

and the geodesic
\gamma
satisfying (
4.3
) and the exponential map are just a straight line passing through
x
in the direction of
v
and the sum of
x
and
v
:

\gamma(t)=\mbox{\boldmath$x$}+t\mbox{\boldmath$v$},\quad t\in{\mathbb{R}},\quad\exp_{\mbox{\boldmath$x$}}\mbox{\boldmath$v$}=\gamma(1)=\mbox{\boldmath$x$}+\mbox{\boldmath$v$}.

Now, we propose the discrete model for (
4.1
) via the exponential map update
{\mathcal{X}}(n)
according to the following discrete map:

(4.4)

\begin{cases}\mbox{\boldmath$x$}_{i}(n+1)=\exp_{\mbox{\boldmath$x$}_{i}(n)}\Big(h{\boldmath f}_{i}({\mathcal{X}}(n))\Big),\quad n\geq 0,\\
\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in\mathcal{M},\quad i\in[N].\end{cases}

By (
4.2
), as long as system (
4.4
) admits a solution, one has

{\mathcal{X}}(n)\in\mathcal{M}^{N},\quad n\geq 0.

Note that for
{\mathcal{M}}={\mathbb{R}}^{d}
, discrete system (
4.4
) can cast as the first-order forward Euler discretization of (
4.1
):

{\mbox{\boldmath$x$}}_{i}(n+1)=\mbox{\boldmath$x$}_{i}(n)+h{\boldmath f}_{i}({\mathcal{X}}(n)),\quad n\geq 0,~~i\in[N].

Next, we return to our setting. Let
G
be a Lie group, and consider the following Cauchy problem:

(4.5)

\begin{cases}\displaystyle\dot{\mbox{\boldmath$x$}}_{i}=A_{i}({\mathcal{X}})\mbox{\boldmath$x$}_{i},\quad t>0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in G,\quad i\in[N],\end{cases}

where we assumed

(4.6)

A_{i}({\mathcal{X}})\in\mathfrak{g}:=T_{\text{id}}G\quad\mbox{at any point $\mbox{\boldmath$x$}\in G$}.

Note that a Lie group equipped with a left-invariant metric is geodesically complete. For a Lie group case, discrete scheme (
4.4
) can be rewritten as

(4.7)

\begin{cases}\mbox{\boldmath$x$}_{i}(n+1)=\exp\big(hA_{i}({\mathcal{X}}(n))\big)\mbox{\boldmath$x$}_{i}(n),\quad n\geq 0,\\
\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in G,~~i\in[N].\end{cases}

On a matrix Lie group, the exponential map is equivalent to the matrix exponential. This numerical scheme for system (
4.5
) is often called the discrete model with the
“Lie group integrator method”

[
8
,
31
,
32
]
.

4.1.2.
Operator splitting method

In this part, we consider the case in which the coefficient in front of
\mbox{\boldmath$x$}_{i}
in (
4.5
) can split into two parts, say

(4.8)

\begin{cases}\displaystyle\dot{\mbox{\boldmath$x$}}_{i}=(A_{i}({\mathcal{X}})+B_{i}({\mathcal{X}}))\mbox{\boldmath$x$}_{i},\quad t>0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in G,~~i\in[N],\end{cases}

where we also assume (
4.6
) for
A_{i}
and
B_{i}
for all
i\in[N]
. For constant matrices
A_{i}
and
B_{i}
, the unique solution to (
4.8
) is given by

\mbox{\boldmath$x$}_{i}(t)=\exp(tA_{i}+tB_{i})\mbox{\boldmath$x$}_{i}^{0},\quad t\geq 0,\quad i\in[N].

If
A_{i}
and
B_{i}
are not commutative, it is very difficult to calculate the matrix exponential
e^{tA_{i}+tB_{i}}
. Thus, we propose another discrete model motivated by the Lie-Trotter product formula
[
51
]
:

e^{A_{i}+B_{i}}=\lim_{n\to\infty}\left(e^{A_{i}/n}e^{B_{i}/n}\right)^{n}.

Now, if we apply the Lie-trotter splitting method to (
4.8
), one has

(4.9)

\begin{cases}\displaystyle\mbox{\boldmath$x$}_{i}(n+1)=\exp(hA_{i}({\mathcal{X}}(n)))\exp(hB_{i}({\mathcal{X}}(n)))\mbox{\boldmath$x$}_{i}(n),\quad n\geq 0,\\
\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in G,~~i\in[N].\end{cases}

It is known that the Lie-trotter splitting scheme admits a first order local truncation error:

e^{h(A+B)}=e^{hA}e^{hB}+\mathcal{O}(h).

Our discrete models are the first order approximation of the continuous model, hence the discretization admits second order local truncation error. The first order error from the operator splitting may be relatively large to the local truncation error from the time discretization. To get rid of such issues, we introduce the Strang splitting:

e^{h(A+B)}=e^{hA/2}e^{hB}e^{hA/2}+\mathcal{O}(h^{2}).

See
[
34
,
42
,
46
]
for the detailed description of the Strang splitting and higher order splitting methods. The Strang splitting method applied to (
4.8
) yields

(4.10)

\begin{cases}\displaystyle\mbox{\boldmath$x$}_{i}(n+1)=\exp\left(\frac{h}{2}A_{i}({\mathcal{X}}(n))\right)\exp\Big(hB_{i}({\mathcal{X}}(n))\Big)\exp\left(\frac{h}{2}A_{i}({\mathcal{X}}(n))\right)\mbox{\boldmath$x$}_{i}(n),~~n\geq 0,\\
\displaystyle\mbox{\boldmath$x$}_{i}(0)=\mbox{\boldmath$x$}_{i}^{0}\in G,\quad i\in[N].\end{cases}

4.2.
Discrete Lohe matrix models

In this subsection, we present three explicit discrete models for (
1.3
) using the discretization schemes discussed in the previous subsection. First, we rewrite the system (
1.3
) as in the form of (
4.5
):

(4.11)

\begin{cases}\displaystyle\dot{U}_{i}=A_{i}(\mathcal{U})U_{i},\quad i\in[N],\\
\displaystyle A_{i}(\mathcal{U})=-\mathrm{i}H_{i}+\frac{\kappa}{2}\big(U_{c}U_{i}^{\dagger}-U_{i}U_{c}^{\dagger}\big),\end{cases}

where
U_{c}:=\frac{1}{N}\sum_{j=1}^{N}U_{j}
.

In what follows, we introduce three discretize schemes using Lie group integrator formula (
4.7
), Lie-Trotter splitting formula (
4.9
), and Strang splitting formula (
4.10
). Without these formulas, we might use the projection algorithm(which applied in the Lohe sphere model) to discretize the Lohe matrix model. However, the projection of a general matrix onto the unitary group
\mathbb{U}(d)
is incomparably harder, since we should use the SVD(singular value decomposition) to find the projection. However, the SVD has no explicit formula. This is the priimary reason why we can not find estimates for the discretized system via projection.

For the discretized schemes (
4.7
), (
4.9
), and (
4.10
), we can make sufficient estimates for asymptotic behaviors. In particular, for a homogeneous model, we obtain complete state aggregation as expected, whereas we obtain the orbital stability for a heterogeneous model. It is the main benefit of using the Lie group exponential maps.

4.2.1.
The discrete Lohe matrix model A

If we apply the Lie group integrator method (
4.7
) to the Lohe matrix model (
4.11
), one has the discrete Lohe matrix model A:

(4.12)

\displaystyle\begin{aligned} U_{i}(n+1)&=\exp\Big(hA_{i}(\mathcal{U}(n))\Big)U_{i}(n)\\
&={\exp\left(-\mathrm{i}H_{i}h+\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n)},\quad i\in[N],~~n\geq 0.\end{aligned}

Discrete model (
4.12
) can be reduced to the discrete Kuramoto model (
3.10
) in a special setting:

(4.13)

U_{i}=e^{-\mathrm{i}\theta_{i}},\quad H_{i}=\nu_{i},\quad i\in[N].

It follows from (
4.12
) and (
4.13
) that

(4.14)

\displaystyle\begin{aligned} &\exp(-\mathrm{i}\theta_{i}(n+1))=U_{i}(n+1)=\exp\bigg(-\mathrm{i}H_{i}h+\frac{\kappa h}{2N}\sum_{j=1}^{N}(U_{j}U_{i}^{\dagger}-U_{i}U_{j}^{\dagger})\bigg)U_{i}(n)\\
&\hskip 19.91684pt=\exp\bigg(-\mathrm{i}\nu_{i}h+\frac{\kappa h}{2N}\sum_{j=1}^{N}(e^{-\mathrm{i}(\theta_{j}(n)-\theta_{i}(n))}-e^{-\mathrm{i}(\theta_{i}(n)-\theta_{j}(n))})\bigg)\exp(-\mathrm{i}\theta_{i}(n))\\
&\hskip 19.91684pt=\exp\bigg(-\mathrm{i}\Big[\theta_{i}(n)+\nu_{i}h+\frac{\kappa h}{N}\sum\limits_{j=1}^{N}\sin(\theta_{j}(n)-\theta_{i}(n))\Big]\bigg).\end{aligned}

By comparing the exponents on both sides of (
4.14
), one obtains the discrete Kuramoto model (
3.10
).

4.2.2.
The discrete Lohe matrix model B

If we apply the Lie-Trotter splitting scheme (
4.9
) for system (
4.11
), one obtains the second discrete model:

(4.15)

\displaystyle U_{i}(n+1)=\exp(-\mathrm{i}H_{i}h)\exp\left(\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n),

for

and

-\mathrm{i}H_{i}h
and
\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))
commute in general.

4.2.3.
The discrete Lohe matrix model C

Again, we apply the Strang splitting scheme (
4.10
) for system (
4.11
) to get the third discrete model:

(4.16)

\displaystyle U_{i}(n+1)=\exp\left(-\frac{\mathrm{i}H_{i}h}{2}\right)\exp\left(\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)\exp\left(-\frac{\mathrm{i}H_{i}h}{2}\right)U_{i}(n),

for

and
n\geq 0
.

Note that for zero free flows:

H_{i}=O,\quad i\in[N].

all discrete Lohe matrix models reduced to same form (
5.1

5.
A homogeneous matrix ensemble

In this section, we study emergent behaviors of a homogeneous ensemble with the same hamiltonian
H
. Thanks to the solution splitting property, at the level of continuous system, we can assume the common hamiltonian to be zero. In this case, all three discrete Lohe matrix models coincide and it reads as

(5.1)

\displaystyle U_{i}(n+1)=\exp\left(\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n),\quad i\in[N],~~n\geq 0.

5.1.
Preliminary lemmas

In this subsection, we study several lemmas to be crucially used in the next subsection. First, we study the relations between the Frobenius norm and operator norm for complex valued square matrix.

Lemma 5.1
.

Let
A
and
B
be square matrices in
{\mathbb{C}}^{d\times d}
and
U\in\mathbf{U}(d)
. Then, one has

\left\lVert AB\right\rVert_{\mathrm{F}}\leq\left\lVert A\right\rVert_{\mathrm{op}}\left\lVert B\right\rVert_{\mathrm{F}},\quad\left\lVert AB\right\rVert_{\mathrm{F}}\leq\left\lVert A\right\rVert_{\mathrm{F}}\left\lVert B\right\rVert_{\mathrm{op}},\quad\left\lVert AU\right\rVert_{\mathrm{F}}=\left\lVert UA\right\rVert_{\mathrm{F}}=\left\lVert A\right\rVert_{\mathrm{F}}.

Proof.

Let
B=\left[\begin{array}[]{c|c|c}b_{1}&\cdots&b_{d}\end{array}\right]
for column vectors
b_{1},\cdots,b_{d}
. Then, we have

\displaystyle\left\lVert AB\right\rVert_{\mathrm{F}}^{2}=\sum_{i=1}^{d}\left\lVert Ab_{i}\right\rVert^{2}\leq\left\lVert A\right\rVert_{\mathrm{op}}^{2}\sum_{i=1}^{d}\left\lVert b_{i}\right\rVert^{2}=\left\lVert A\right\rVert_{\mathrm{op}}^{2}\left\lVert B\right\rVert_{\mathrm{F}}^{2},

\displaystyle\left\lVert AB\right\rVert_{\mathrm{F}}=\lVert B^{\dagger}A^{\dagger}\rVert_{\mathrm{F}}\leq\lVert B^{\dagger}\rVert_{\mathrm{op}}\lVert A^{\dagger}\rVert_{\mathrm{F}}=\lVert B\rVert_{\mathrm{op}}\lVert A\rVert_{\mathrm{F}},

\displaystyle\left\lVert AU\right\rVert_{\mathrm{F}}^{2}=\mathrm{tr}\left(AUU^{\dagger}A^{\dagger}\right)=\mathrm{tr}\left(AA^{\dagger}\right)=\left\lVert A\right\rVert_{\mathrm{F}}^{2}.\qed

Lemma 5.2
.

Let
A_{1},\cdots,A_{k}
and
B_{1},\cdots,B_{k}
be square matrices in
{\mathbb{C}}^{d\times d}
. Then, one has the following assertions:

\displaystyle\|A_{1}A_{2}\cdots A_{k}\|_{\mathrm{F}}\leq\|A_{1}\|_{\mathrm{F}}\|A_{2}\|_{\mathrm{F}}\cdots\|A_{k}\|_{\mathrm{F}},

\displaystyle|\mathrm{tr}(A_{1}A_{2}\cdots A_{k})|\leq\left\lVert A_{1}\right\rVert_{\mathrm{F}}\left\lVert A_{2}\right\rVert_{\mathrm{F}}\cdots\left\lVert A_{k}\right\rVert_{\mathrm{F}}.

Proof.

It suffices to show that the both assertions hold for two matrices:

\left\lVert AB\right\rVert_{\mathrm{F}}\leq\left\lVert A\right\rVert_{\mathrm{F}}\cdot\left\lVert B\right\rVert_{\mathrm{F}},\quad|\mathrm{tr}(AB)|\leq\left\lVert A\right\rVert_{\mathrm{F}}\cdot\left\lVert B\right\rVert_{\mathrm{F}}.

The general case can be treated using mathematical induction. We set

A=(a_{ij}),\quad B=(b_{ij}),

where
[A]_{ij}
denotes the
(i,j)
-component of the matrix A.

(i) We use the Cauchy-Schwarz inequality to get

|[AB]_{ij}|=\Big|\sum_{k=1}^{N}a_{ik}b_{kj}\Big|\leq\sum_{k=1}^{N}|a_{ik}|\cdot|b_{kj}|\leq\Big(\sum_{k=1}^{N}|a_{ik}|^{2}\Big)^{\frac{1}{2}}\cdot\Big(\sum_{k=1}^{N}|b_{kj}|^{2}\Big)^{\frac{1}{2}}.

This yields

\displaystyle\begin{aligned} \left\lVert AB\right\rVert_{\mathrm{F}}^{2}&=\sum_{i,j=1}^{N}\Big|[AB]_{ij}\Big|^{2}\leq\sum_{i,j=1}^{N}\Big(\sum_{k=1}^{N}|a_{ik}|^{2}\Big)\cdot\Big(\sum_{k=1}^{N}|b_{ik}|^{2}\Big)\\
&\leq\Big(\sum_{i,k=1}^{N}|a_{ik}|^{2}\Big)\cdot\Big(\sum_{j,k=1}^{N}|b_{ik}|^{2}\Big)=\left\lVert A\right\rVert^{2}_{\mathrm{F}}\cdot\left\lVert B\right\rVert^{2}_{\mathrm{F}}.\end{aligned}

(ii) From simple calculations, we get

\displaystyle|\mathrm{tr}\left(AB\right)|

\displaystyle=\Big|\sum_{i=1}^{d}[AB]_{ii}\Big|\leq\sum_{i,k=1}^{d}|[A]_{ik}|\cdot|[B]_{ki}|

\displaystyle\leq\Big(\sum_{i,k=1}^{d}|[A]_{ik}|^{2}\Big)^{\frac{1}{2}}\cdot\Big(\sum_{i,k=1}^{d}|[B]_{ki}|^{2}\Big)^{\frac{1}{2}}\leq\left\lVert A\right\rVert_{\mathrm{F}}\cdot\left\lVert B\right\rVert_{\mathrm{F}}.\qed

Remark 5.3
.

For
k=1
, Lemma
5.2
can be reduced as follows:

|\mathrm{tr}(A)|=\Big|\sum_{i=1}^{d}a_{ii}\Big|\leq\sum_{i=1}^{d}|a_{ii}|\leq\sqrt{d}\Big(\sum_{i=1}^{d}|a_{ii}|^{2}\Big)^{\frac{1}{2}}\leq\sqrt{d}\left\lVert A\right\rVert_{\mathrm{F}}.

Lemma 5.4
.

Let
A_{1},\cdots,A_{k}
and
B_{1},\cdots,B_{k}
be square matrices in
{\mathbb{C}}^{d\times d}
such that

\left\lVert A_{i}\right\rVert_{\mathrm{op}}\leq 1,\quad\left\lVert B_{i}\right\rVert_{\mathrm{op}}\leq 1,\quad i\in[K].

Then, one has

\left\lVert A_{1}\cdots A_{k}-B_{1}\cdots B_{k}\right\rVert_{\mathrm{F}}\leq\sum_{l=1}^{k}\left\lVert A_{l}-B_{l}\right\rVert_{\mathrm{F}}.

Proof.

As in Lemma
5.2
, it is sufficient to check that the assertion holds for
k=2
. The general case can be made using the mathematical induction and the result of Lemma
5.2
. Suppose that
A_{1},A_{2},B_{1}
and
B_{2}
are square matrices in
\mathbb{C}^{d\times d}
such that

\left\lVert A_{i}\right\rVert_{\mathrm{op}}\leq 1,\quad\left\lVert A_{i}\right\rVert_{\mathrm{op}}\leq 1,\quad i=1,2.

Then, we use Lemma
5.1
and Lemma
5.2
to get

\displaystyle\left\lVert A_{1}A_{2}-B_{1}B_{2}\right\rVert_{\mathrm{F}}

\displaystyle=\left\lVert(A_{1}-B_{1})A_{2}+B_{1}(A_{2}-B_{2})\right\rVert_{\mathrm{F}}

\displaystyle\leq\left\lVert(A_{1}-B_{1})A_{2}\right\rVert_{\mathrm{F}}+\left\lVert B_{1}(A_{2}-B_{2})\right\rVert_{\mathrm{F}}

\displaystyle\leq\left\lVert A_{1}-B_{1}\right\rVert_{\mathrm{F}}\cdot\left\lVert A_{2}\right\rVert_{\mathrm{op}}+\left\lVert B_{1}\right\rVert_{\mathrm{F}}\cdot\left\lVert A_{2}-B_{2}\right\rVert_{\mathrm{F}}

\displaystyle\leq\left\lVert A_{1}-B_{1}\right\rVert_{\mathrm{F}}+\left\lVert A_{2}-B_{2}\right\rVert_{\mathrm{F}}.\qed

For
n\geq 0,~\mathcal{U}(n)=(U_{1}(n),\cdots,U_{N}(n))\in(\mathbf{U}(d))^{N}
and
i\in[N]
, we set

(5.2)

\mathcal{D}(n):=\max\limits_{1\leq i,j\leq N}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}},\quad\Delta_{i}:=\frac{1}{2}(U_{c}U_{i}^{\dagger}-U_{i}U_{c}^{\dagger}).

Note that system
\eqref{D-3}_{1}
can be rewritten as:

U_{i}(n+1)=\exp\left(\frac{\kappa h}{2}(U_{c}(n)U_{i}^{\dagger}(n)-U_{i}(n)U_{c}^{\dagger}(n))\right)U_{i}(n)=e^{\beta\Delta_{i}(n)}U_{i}(n).

Lemma 5.5
.

Let
U_{1},\cdots,U_{N}
be
d\times d
unitary matrices. Then, one has the following estimates: for
i,j\in[N]
,

\displaystyle\begin{aligned} &(i)~\lVert U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger}\rVert_{\mathrm{F}}\leq 2\left\lVert U_{i}-U_{j}\right\rVert_{\mathrm{F}},\quad\left\lVert\Delta_{i}\right\rVert_{\mathrm{F}}\leq\frac{1}{N}\sum\limits_{k=1}^{N}\left\lVert U_{k}-U_{i}\right\rVert_{\mathrm{F}},\\
&(ii)~\left\lVert\Delta_{i}\right\rVert_{\mathrm{op}}\leq\left\lVert U_{c}\right\rVert_{\mathrm{op}}\leq 1,~~\left\lVert\Delta_{i}-\Delta_{j}\right\rVert_{\mathrm{F}}\leq\left\lVert U_{i}-U_{j}\right\rVert_{\mathrm{F}},~~\left\lVert\Delta_{i}-\Delta_{j}\right\rVert_{\mathrm{op}}\leq\left\lVert U_{i}-U_{j}\right\rVert_{\mathrm{op}}.\end{aligned}

Proof.

(i) Note that

U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger}=(U_{i}-U_{j})U_{i}^{\dagger}-U_{i}(U_{i}^{\dagger}-U_{j}^{\dagger}).

This relation and Lemma
5.1
imply

\left\lVert U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger}\right\rVert_{\mathrm{F}}\leq\lVert(U_{i}-U_{j})U_{i}^{\dagger}\rVert_{\mathrm{F}}+\lVert U_{i}(U_{i}^{\dagger}-U_{j}^{\dagger})\rVert_{\mathrm{F}}=2\left\lVert U_{i}-U_{j}\right\rVert_{\mathrm{F}}.

On the other hand, we use the above result and defining relation
\Delta_{i}
in (
5.2
) to get

\lVert\Delta_{i}\rVert_{\mathrm{F}}\leq\frac{1}{2N}\sum_{k=1}^{N}\left\lVert U_{k}U_{i}^{\dagger}-U_{i}U_{k}^{\dagger}\right\rVert_{\mathrm{F}}\leq\frac{1}{N}\sum_{k=1}^{N}\left\lVert U_{k}-U_{i}\right\rVert_{\mathrm{F}}

(iii) Note that

Similarly, we obtain

First, we rewrite

(5.6)

\displaystyle\begin{aligned} \mathcal{A}_{1}&=\mathrm{tr}\left((\Delta_{i}-\Delta_{j})U_{i}U_{j}^{\dagger}+(\Delta_{j}-\Delta_{i})U_{j}U_{i}^{\dagger}\right)=\mathrm{tr}\left((\Delta_{i}-\Delta_{j})(U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger})\right)\\

&\hskip 14.22636pt\left.-\mathrm{tr}\left(\big\{(U_{k}-U_{i})(U_{k}^{\dagger}-U_{i}^{\dagger})+(U_{k}-U_{j})(U_{k}^{\dagger}-U_{j}^{\dagger})\big\}(U_{i}-U_{j})(U_{i}^{\dagger}-U_{j}^{\dagger})\right)\right]\\

&\qquad\qquad\qquad\qquad\qquad\quad\left.+\mathrm{tr}\left((U_{k}-U_{j})(U_{k}^{\dagger}-U_{j}^{\dagger})(U_{i}-U_{j})(U_{i}^{\dagger}-U_{j}^{\dagger})\right)\right],\end{aligned}

where in the fourth equality, we used the following identities for unitary matrices

and

\displaystyle(U_{i}^{\dagger}-U_{j}^{\dagger})(U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger})

\displaystyle(U_{i}U_{j}^{\dagger}-U_{j}U_{i}^{\dagger})(U_{i}-U_{j})

\displaystyle\begin{aligned} \mathcal{B}_{m+1}^{+}&=\mathrm{tr}\left(\sum_{l=0}^{m}\frac{m!}{l!(m-l)!}(-1)^{l}\Delta_{j}^{l}\Delta_{i}^{m+1-l}U_{i}U_{j}^{\dagger}-\sum_{l=0}^{m}\frac{m!}{l!(m-l)!}(-1)^{l}\Delta_{j}^{l+1}\Delta_{i}^{m-l}U_{i}U_{j}^{\dagger}\right)\\

5.1

\displaystyle\begin{aligned} \left\lVert\Delta_{i}^{m}-\Delta_{j}^{m}\right\rVert_{\mathrm{F}}&=\left\lVert\sum_{l=0}^{m-1}\Delta_{i}^{l}(\Delta_{i}-\Delta_{j})\Delta_{j}^{m-1-l}\right\rVert_{\mathrm{F}}\\

Theorem 5.8
.

(Complete state aggregation)

Suppose system parameters and initial data satisfy

H_{i}=O,\quad i\in[N],\quad 0<\beta=\kappa h<\beta_{0}\approx 0.437864,\quad\mathcal{D}(0)<\sqrt{4-e^{2\beta}-\frac{e^{2\beta}-1}{2\beta}},

and let
\{U_{i}(n)\}
be a solution to (
5.1
). Then, complete state aggregation emerges asymptotically:

\lim_{n\to\infty}\max_{1\leq i,j\leq N}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}=0.

Moreover, the convergence rate is exponential.

Proof.

We use the mathematical induction. Suppose that
\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}
is monotonically decreasing up to the
n
-th time step. Then, one has

\mathcal{D}(n)\leq\mathcal{D}(0).

Now we claim:

\mathcal{D}(n+1)\leq(1-C)\mathcal{D}(n),\quad n\geq 0

for a positive constant
C
independent of
n
.

By (
5.5
) and the estimates of
\mathcal{A}_{m}
’s (Lemma
5.6
and Lemma
5.7
), we get

(5.10)

\displaystyle\begin{aligned} &\lVert U_{i}(n+1)-U_{j}(n+1)\rVert_{\mathrm{F}}^{2}-\lVert U_{i}(n)-U_{j}(n)\rVert_{\mathrm{F}}^{2}=-\beta\mathcal{A}_{1}-\sum_{m=2}^{\infty}\frac{\beta^{m}}{m!}\mathcal{A}_{m}\\
&\hskip 14.22636pt\leq-2\beta\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}+\beta\mathcal{D}(n)^{2}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}\\
&\hskip 25.6073pt+\sum_{m=2}^{\infty}\frac{\beta^{m}}{m!}\cdot(m+1)2^{m-1}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}\\
&\hskip 14.22636pt=-\beta\bigg(2-\mathcal{D}(n)^{2}-\sum_{m=2}^{\infty}\frac{(2\beta)^{m-1}}{m!}(m+1)\bigg)\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}\\
&\hskip 14.22636pt\leq-\beta\bigg(4-e^{2\beta}-\frac{e^{2\beta}-1}{2\beta}-(\mathcal{D}(0))^{2}\bigg)\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}\leq 0.\end{aligned}

The above inequatliy implies that there exists a positive constant
C
independent of
i,j,n
such that

\left\lVert U_{i}(n+1)-U_{j}(n+1)\right\rVert_{\mathrm{F}}^{2}\leq(1-C)^{2}\left\lVert U_{i}(n)-U_{j}(n)\right\rVert_{\mathrm{F}}^{2}

for all
i,j\in[N]
and
n\geq 0
.
∎

Lemma 6.1
.

Let

and

\left\lVert e^{\mathrm{i}A}-e^{\mathrm{i}B}\right\rVert_{\mathrm{F}}\leq\left\lVert A-B\right\rVert_{\mathrm{F}}.

Proof.

Let the eigen-decomposition of

and

A=U\begin{pmatrix}\lambda_{1}&&\\
&\ddots&\\
&&\lambda_{d}\end{pmatrix}U^{\dagger},\quad B=V\begin{pmatrix}\mu_{1}&&\\
&\ddots&\\
&&\mu_{d}\end{pmatrix}V^{\dagger},

where
U
,
V
are unitary matices and
\lambda_{1},\cdots,\lambda_{n},\mu_{1},\cdots,\mu_{n}
are real numbers.

Suppose
\Sigma=\text{diag}(\sigma_{1},\cdots,\sigma_{d})
and
\widetilde{\Sigma}=\text{diag}(\widetilde{\sigma}_{1},\cdots,\widetilde{\sigma}_{d})
be arbitary diagonal matrices and

\mathrm{tr}\left(X\widetilde{X}^{\dagger}\right)=\mathrm{tr}\left(U\Sigma U^{\dagger}V\widetilde{\Sigma}^{\dagger}V^{\dagger}\right)=\mathrm{tr}\left(\Sigma W\widetilde{\Sigma}^{\dagger}W^{\dagger}\right)=\sum_{k,l=1}^{d}\sigma_{k}\widetilde{\sigma}_{l}^{\ast}\left\lvert W_{k,l}\right\rvert^{2}.

By the same argument, we have

\displaystyle\mathrm{tr}\left(e^{\mathrm{i}A}e^{-\mathrm{i}B}\right)=\sum_{k,l=1}^{d}e^{\mathrm{i}(\lambda_{k}-\mu_{l})}\left\lvert W_{k,l}\right\rvert^{2},\quad\mathrm{tr}\left(e^{\mathrm{i}B}e^{-\mathrm{i}A}\right)=\sum_{k,l=1}^{d}e^{\mathrm{i}(\mu_{l}-\lambda_{k})}\left\lvert W_{k,l}\right\rvert^{2},

\displaystyle\mathrm{tr}\left(AB^{\dagger}\right)=\mathrm{tr}\left(BA^{\dagger}\right)=\sum_{k,l=1}^{d}\lambda_{k}\mu_{l}\left\lvert W_{k,l}\right\rvert^{2}.

\displaystyle\widetilde{U}_{i}^{\dagger}(n+1)-U_{i}(n)\widetilde{U}_{i}^{\dagger}(n)\rVert_{\mathrm{F}}=\lVert U_{i}(n+1)U_{i}^{\dagger}(n)-\widetilde{U}_{i}(n+1)\widetilde{U}_{i}^{\dagger}(n)\rVert_{\mathrm{F}}

\displaystyle=\lVert\exp(\beta\Delta_{i}(n))-\exp(\beta\widetilde{\Delta}_{i}(n))\rVert_{\mathrm{F}}

\displaystyle\leq\beta\lVert\Delta_{i}(n)-\widetilde{\Delta}_{i}(n)\rVert_{\mathrm{F}}\leq\beta d(\mathcal{U}(n),\widetilde{\mathcal{U}}(n))\leq\beta C^{n}d(\mathcal{U}^{0},\widetilde{\mathcal{U}}^{0})

for all
n\geq 0
. Thus, one has

\lVert U_{i}(n+m)\widetilde{U}_{i}^{\dagger}(n+m)-U_{i}(n)\widetilde{U}_{i}^{\dagger}(n)\rVert_{\mathrm{F}}<\frac{\beta C^{n}}{1-C}d(\mathcal{U}^{0},\widetilde{\mathcal{U}}^{0})

for all
n,m\geq 0
. This implies that
\{U_{i}(n)\widetilde{U}_{i}^{\dagger}(n)\}_{n\geq 0}
is a Cauchy sequence. It follows that the following limit exists.

L_{i}^{\infty}:=\lim_{n\to\infty}U_{i}(n)\widetilde{U}_{i}^{\dagger}(n).

According to (a), we have
d(\mathcal{U}(n),\widetilde{\mathcal{U}}(n))\to 0
as
n\to\infty
. This implies

\lim_{n\to\infty}\lVert U_{i}(n)\widetilde{U}_{i}^{\dagger}(n)-U_{j}(n)\widetilde{U}_{j}^{\dagger}(n)\rVert_{\mathrm{F}}=\lim_{n\to\infty}\lVert U_{i}(n)U_{j}^{\dagger}(n)-\widetilde{U}_{i}(n)\widetilde{U}_{j}^{\dagger}(n)\rVert_{\mathrm{F}}=0

for all
i,j\in[N]
. Therefore,
L^{\infty}_{i}=L^{\infty}_{j}
for all
i,j\in[N]
and thus
the assertion (ii) holds.
∎

Theorem 6.6
.

Suppose system parameters and initial data satisfy

(ii)

Let

be a solution to (
6.1
) with time step

and initial data
\mathcal{U}^{0}
. The uniform-in-time convergence of the discrete solution to the continuous solution occurs:

(6.10)

Proof.

(i) There exists

7.
Conclusion

In this paper, we have provided several discrete models corresponding to the discrete counterparts of the Lohe sphere model and Lohe matrix model on the unitary group. Aforementioned models are the high-dimensional generalizations of the Kuramoto model for synchronization. The Lohe sphere model describes the aggregate modeling on the unit sphere, whereas the Lohe matrix model describes the aggregate modeling on a unitary group. Recently, emergent dynamics and phase transition phenomena for these continuous models have been extensively studied in literature from control theory and statistical physics communities. When one tries to simulate these models, we are forced to discretize these continuous models using suitable discretization algorithms.

For the discretization of the Lohe sphere model, we construct a scheme consisting of two steps. In the first step, we use the first-order forward Euler scheme to get the intermediate state which is not on the unit sphere. In the second step, we project the intermediate state to the unit sphere for the state in next time step. Since projection operator is contractive, all the emergent properties of intermediate states carry over to the projected states.

On the other hand, for the Lohe matrix model, we proposed three discrete models derieved from the Lie group exponential map. The first one is based on the exponential map on the underlying Lie group. This corresponds to the manifold version of the first-order Euler scheme free of projections. The other two discrete models are motivated by operator splitting theory. For a homogeneous flow with the same free flow, we show that complete state aggregation occurs exponentially fast under a suitable framework in terms of system parameters and initial data. On the other hand, for a heterogenous flow with different free flows, we can not prove emergent dynamics yet. The second and third discrete models are motivated by the Lie-Trotter splitting scheme and Strang splitting scheme. For zero free flow, all three discrete models coincide and exhibit exponential aggregation, whereas for the last two discrete models based on operator splitting exhibit the orbital stability and the state-locking states.
