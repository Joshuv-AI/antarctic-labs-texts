The strong coupling g X ​ J / ψ ​ ϕ g_{XJ/\psi\phi} of X ⁡ ( 4700 ) → J / ψ ​ ϕ X(4700)\to J/\psi\phi in the light-cone sum rules
Yiling Xie, Dazhuang He, Xuan Luo, Hao Sun

Abstract
We assign the scalar tetraquark and the D-wave tetraquark state for X ⁡ ( 4700 ) X(4700) and calculate the width of the decay X ⁡ ( 4700 ) X(4700) → J / ψ ​ ϕ \to J/\psi\phi within the framework of light-cone sum rules. The strong coupling g X ​ J / ψ ​ ϕ g_{XJ/\psi\phi} is obtained by considering the technique of soft-meson approximation. We also investigate the mass and the decay constant of X ⁡ ( 4700 ) X(4700) in the framework of SVZ sum rules. Our prediction for the mass is in agreement with the experimental measurement. For the decay width of X ⁡ ( 4700 ) X(4700) → J / ψ ​ ϕ \to J/\psi\phi , if we assigns X X (4700) as a scalar c ​ s ​ c ¯ ​ s ¯ cs\bar{c}\bar{s} tetraquark state, we obtain Γ = ( 109 − 24 + 35 ) \Gamma=(109^{+35}_{-24}) MeV, which indicates that X ⁡ ( 4700 ) X(4700) → J / ψ ​ ϕ \to J/\psi\phi is a predominant decay channel. On the contrary, if X X (4700) is assigned as a D-wave tetraquark state, we obtain Γ = ( 17.1 − 4.0 + 6.2 ) \Gamma=(17.1^{+6.2}_{-4.0}) MeV, so that X X (4700) → \to J / ψ ​ ϕ J/\psi\phi becomes a much smaller decay channel.
