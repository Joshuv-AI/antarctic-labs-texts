Exploring the mass spectrum and the electromagnetic properties of the possible Ξ c ​ c ​ K ( ∗ ) \Xi_{cc}K^{(*)} and Ξ c ​ c ​ K ¯ ( ∗ ) \Xi_{cc}\bar{K}^{(*)} molecules
Li-Cheng Sheng 1, Jin-Yu Huo 1, Rui Chen 1, Fu-Lai Wang 2,3,4,6, Xiang Liu 2,3,4,5,6

Abstract
Using the one-boson-exchange model, we investigate the interactions between the doubly charmed baryon Ξ c ​ c ​ ( 3621 ) \Xi_{cc}(3621) and the S − S- wave (anti-)kaon accounting for the S − D S-D wave mixing and coupled-channel effects. We find the coupled Ξ c ​ c ​ K / Ξ c ​ c ​ K ∗ \Xi_{cc}K/\Xi_{cc}K^{*} state with I ⁡ ( J P ) = 0 ​ ( 1 / 2 − ) I(J^{P})=0(1/2^{-}) , the Ξ c ​ c ​ K ∗ \Xi_{cc}K^{*} state with 0 ​ ( 1 / 2 − ) 0(1/2^{-}) , the Ξ c ​ c ​ K ¯ \Xi_{cc}\bar{K} state with 0 ​ ( 1 / 2 − ) 0(1/2^{-}) , and the Ξ c ​ c ​ K ¯ ∗ \Xi_{cc}\bar{K}^{*} states with 0 ​ ( 1 / 2 − , 3 / 2 − ) 0(1/2^{-},3/2^{-}) can be recommended as good doubly charmed molecular candidates with strangeness | S | = 1 |S|=1 . We further examine their M1 radiative decay behaviors and magnetic moments within the constituent quark model framework. This information can enhance our understanding of their inner structures, including the distribution of electric charge and the orientation of the constituent quarks’ spins.
