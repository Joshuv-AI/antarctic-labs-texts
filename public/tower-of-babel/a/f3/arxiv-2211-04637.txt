Quantum Search Algorithm for Binary Constant Weight Codes
Kein Yukiyoshi, Naoki Ishikawa

Abstract
A binary constant weight code is a type of error-correcting code with a wide range of applications. The problem of finding a binary constant weight code has long been studied as a combinatorial optimization problem in coding theory. In this paper, we propose a quantum search algorithm for binary constant weight codes. Specifically, the search problem is newly formulated as a quadratic unconstrained binary optimization (QUBO) and Grover adaptive search (GAS) is used for providing the quadratic speedup. Focusing on the inherent structure of the problem, we derive an upper bound on the minimum of the objective function value and a lower bound on the exact number of solutions. In our algebraic analysis, it was found that this proposed algorithm is capable of reducing the number of required qubits, thus enhancing the feasibility. Additionally, our simulations demonstrated that it reduces the query complexities by 63 % 63\% in the classical domain and 31 % 31\% in the quantum domain. The proposed approach may be useful for other quantum search algorithms and optimization problems.

Quantum computation has proven to have advantages over classical computation regarding query complexity required for solving specific problems, such as Shor’s algorithm

Grover’s search algorithm finds a solution in an unordered database of

Then, Dürr and Høyer proposed Grover adaptive search (GAS)

GAS can be interpreted as a kind of quantum exhaustive search algorithm, which guarantees the optimality of the solutions obtained.
At the time of writing, it is the only algorithm that provides the quadratic speedup for solving a binary optimization problem.
An efficient construction method for a quantum circuit corresponding to a polynomial objective function has long been unknown.
The breakthrough is Gilliam’s method proposed in

Against this background, we newly formulate the problem of finding a binary constant weight code as a QUBO problem.
This novel formulation enables the use of GAS and provides a quadratic speedup for the search problem.
Additionally, focusing on the inherent structure of the problem, our proposed GAS further accelerates the quadratic speedup, which is a unique attempt in the literature.
The major contributions of this paper are summarized as follows:

1.

The problem of finding an optimal binary constant weight code is newly formulated as a QUBO problem, and the number of qubits required for constructing a quantum circuit is maximally reduced. In this formulation, the Hamming distance between codewords, which is usually represented by exclusive OR (XOR), is attributed to the representation using an inner product. Furthermore, a unique trick using the inner product is incorporated into the objective function to guarantee that the minimum distance of an obtained code is at least a given value
d
.

2.

Two novel mathematical properties are clarified: (1) an upper bound on the minimum of the objective function value and (2) a lower bound on the exact number of solutions. These clarifications help reduce the number of qubits and query complexity, which are supported by our algebraic analysis and numerical simulations.

Finally, in Section V, we conclude this paper.

III
Proposed Quantum Search Algorithm

In this section, we propose a novel objective function that attributes the problem of finding a binary constant weight code to an optimization problem. The problem is defined as finding a code such that the code length
n
, weight
w
, number of codewords
M
, and minimum distance
d
are each equal to the given values
(n,w,M,d)
, which is hereinafter referred to as condition
(n,w,M,d)
.
Additionally, focusing on the inherent properties of the problem, we derive an upper bound on the minimum value of the objective function and a lower bound on the number of solutions.
Using these bounds, we modify GAS and reduce the number of qubits and query complexity.

III-A

Proposed Formulation

To obtain the optimal solution for a binary constant weight code
A(n,d,w)
, we newly formulate the search problem as a QUBO problem, which is supported by GAS.
A challenging task here is that the objective function has to incorporate the Hamming distance between codewords.
In general, the Hamming distance

between codewords
\mathbf{c}_{m}
and
\mathbf{c}_{m^{\prime}}
is expressed using the XOR operation

As long as the Hamming weight is constant, the XOR operation can be expressed by an inner product
\expectationvalue{\c_m, \c_{m'}}=\sum_{i=1}^{n}c_{m,i}c_{m^{\prime},i}

Theorem 1
.

If a code has a constant weight

d(\mathbf{c}_{m},\mathbf{c}_{m^{\prime}})=2\quantity(w - \expval{\c_m, \c_m'}).

Proof.

For any pair of

c_{m,i}\oplus c_{m^{\prime},i}=\quantity(c_{m, i} + c_{m', i})-2c_{m,i}c_{m^{\prime},i}.

Since weights of codewords are constant,

\displaystyle\sum_{i=1}^{n}\quantity(c_{m, i}\oplus c_{m', i})=

\displaystyle d(\mathbf{c}_{m},\mathbf{c}_{m^{\prime}})

\displaystyle\sum_{i=1}^{n}\quantity(c_{m, i} + c_{m', i})-2\sum_{i=1}^{n}c_{m,i}c_{m^{\prime},i}

\displaystyle 2\quantity(w - \expval{\c_m, \c_{m'}})

Reduction of Qubits

Here, we modify the objective function (
27
) so that a single codeword is always selected, leading to a reduction in the number of qubits.

Theorem 3
.

If a code that satisfies the condition
(n,w,M,d)
exits,
then for every possible codeword
\mathbf{c}
in the combinatorial matrix, at least one code exists that satisfies the
condition
(n,w,M,d)
such that the codeword
\mathbf{c}
is included.

Proof.

When we consider a code as a matrix where each row vector is a codeword,
the Hamming distance between codewords does not change even if we swap any two columns of the matrix.
Therefore, by swapping the columns of any code that satisfies the condition
(n,w,M,d)
,
we can construct a code that contains any specific codeword and satisfies the condition
(n,w,M,d)
.
∎

Let
\mathbf{P}^{\prime}(n,w)
be a matrix generated by removing
\mathbf{P}(n,w)
’s row vectors, the Hamming distance of which from a codeword
\mathbf{p}_{0}
is less than
d
, where
\mathbf{p}_{0}
is the first row vector of
\mathbf{P}(n,w)
(
30
).
The objective function with reduced binary variables can be defined as

E^{\prime}(\mathbf{x})=f^{\prime}(\mathbf{x})+\rho^{\prime}\cdot g^{\prime}(\mathbf{x}),

(32)

where

\displaystyle f^{\prime}(\mathbf{x})

\displaystyle=\sum_{0\leq r<r^{\prime}<q_{1}}\expectationvalue{\mathbf{p'}_r, \mathbf{p'}_{r'}}^{l}\cdot x_{r}x_{r^{\prime}},

(33)

\displaystyle g^{\prime}(\mathbf{x})

\displaystyle=\quantity(\sum_{r=0}^{q_{1}-1}x_r - (M - 1))^{2},

(34)

and
\mathbf{p}^{\prime}_{r}
is the
(r+1)
-th row vector of
\mathbf{P}^{\prime}(n,w)
.
The number of binary variables
q_{1}
is equal to the number of rows in
\mathbf{P}^{\prime}(n,w)
and is expressed as

q_{1}=\sum_{i=0}^{w-\frac{d}{2}}\binom{w}{i}\binom{n-w}{w-i}.

(35)

The penalty coefficient
\rho^{\prime}
can be defined as

\displaystyle\rho^{\prime}=\overline{f}^{\prime}+1=\binom{q_{1}}{2}(w-1)^{l}+1

(36)

where
\overline{f}^{\prime}
denotes the upper bound of
f^{\prime}
.
Let
E^{\prime}_{\mathrm{max}}
be the maximum of the objective function value, i.e.,
E^{\prime}_{\mathrm{max}}=\max_{\mathbf{x}}E^{\prime}(\mathbf{x})
.
It is upper bounded by

\displaystyle E^{\prime}_{\mathrm{max}}\leq\overline{E}^{\prime}_{\mathrm{max}}=\overline{f}^{\prime}+\rho^{\prime}\overline{g}^{\prime}

\displaystyle=

\displaystyle\begin{cases}\binom{q_{1}}{2}(w-1)^{l}+\rho^{\prime}\quantity(q_{1} - M + 1)^{2}&(2(M-1)<q_{1})\\
\binom{q_{1}}{2}(w-1)^{l}+\rho^{\prime}(M-1)^{2}&(2(M-1)\geq q_{1})\end{cases}

\displaystyle=

\displaystyle\begin{cases}O\quantity(q_1^2w^l(q_{1} - M)^2)&(2(M-1)<q_{1})\\
O\quantity(q_1^2w^lM^2)&(2(M-1)\geq q_{1}).\end{cases}

(37)

Then, the number of qubits required to encode the objective function value is expressed by

\displaystyle q_{2}^{\prime}=\lceil\log_{2}(\overline{E}^{\prime}_{\mathrm{max}})\rceil+1

\displaystyle=

\displaystyle\begin{cases}O\quantity(\log(q_1) + l\log(w))&(2(M-1)<q_{1})\\
O\quantity(\log(q_1) + l\log(w) + \log(M))&(2(M-1)\geq q_{1}).\end{cases}

(38)

Assuming
w\neq 2d
, the coefficient

is upper bounded by

\displaystyle l

\displaystyle=\left\lfloor\frac{\log\binom{M}{2}}{\log\quantity(1 + \frac{2}{2w - d})}+1\right\rfloor\leq\left\lfloor\frac{\log\binom{M}{2}}{2}+1\right\rfloor

\displaystyle=O(\log(M))

(39)

Using (
III-B
),
q_{2}^{\prime}
of (

) can be simplified to

q_{2}^{\prime}=O\quantity(\log(q_1) + \log(M)\log(w)).

(40)

The total number of qubits is

q_{1}+q_{2}^{\prime}=O\quantity(q_{1} + \log(M)\log(w)).

(41)

The query complexity in the quantum domain is expressed by

O\quantity(\sqrt{\frac{2^{q_{1}}}{t}}),

(42)

where

III-C
1
Novel Initial Threshold

Let
E^{\prime}_{\mathrm{min}}
be the minimum of the objective function value, i.e.,
E^{\prime}_{\mathrm{min}}=\min_{\mathbf{x}}E^{\prime}(\mathbf{x})
.
Similar to (
22
), its upper bound can be derived as

E^{\prime}_{\mathrm{min}}<\overline{E}^{\prime}_{\mathrm{min}}+1=\binom{M-1}{2}\quantity(w - \frac{d}{2})^{l}+1.

(43)

The objective function value
E^{\prime}(\mathbf{x})
may become greater than
\overline{E}^{\prime}_{\mathrm{min}}
.
By contrast, if it is smaller than
\overline{E}^{\prime}_{\mathrm{min}}
, the obtained code has at least the minimum distance
d
.
Therefore, the desired code can be obtained without updating the threshold of GAS.
That is, we set the initial value of the threshold to

y_{0}=\overline{E}^{\prime}_{\mathrm{min}}+1.

(44)

Additionally, if the objective function value is greater than
\overline{E}^{\prime}_{\mathrm{min}}
, the obtained code is not good regarding the minimum distance.
This fact helps to reduce the number of qubits
q_{2}
.
Specifically, the penalty coefficient
\rho^{\prime}
is replaced by

\rho^{\prime\prime}=\overline{E}^{\prime}_{\mathrm{min}}+1.

(45)

and we have an updated objective function

E^{\prime\prime}(\mathbf{x})=f^{\prime}(\mathbf{x})+\rho^{\prime\prime}\cdot g^{\prime}(\mathbf{x})

(46)

where
f^{\prime}
and
g^{\prime}
are defiend by (
33
) and (
34
), respectively. Then, the objective function is upper bounded by

\displaystyle E^{\prime\prime}_{\mathrm{max}}\leq\overline{E}^{\prime\prime}_{\mathrm{max}}

\displaystyle=

\displaystyle\begin{cases}O\quantity(q_1^2w^l + M^2(w - d/2)^l(q_{1} - M)^2)&(2(M-1)<q_{1})\\
O\quantity(q_1^2w^l + M^4(w - d/2)^l)&(2(M-1)\geq q_{1}).\end{cases}

(47)

As with the
E_{\mathrm{max}}^{\prime}
case, the number of qubits required to encode the objective function value can be simplified to

\displaystyle q_{2}^{\prime\prime}

\displaystyle=\lceil\log_{2}(\overline{E}^{\prime\prime}_{\mathrm{max}})\rceil+1

\displaystyle=O\quantity(\log(q_1) + \log(M)\log(w)).

(48)

The number of qubits that can be reduced is bounded by

\displaystyle\lceil\log_{2}(\overline{E}^{\prime}(\mathbf{x}))\rceil-\lceil\log_{2}(\overline{E}^{\prime\prime}(\mathbf{x}))\rceil

\displaystyle>

\displaystyle\log_{2}\quantity(\frac{\overline{E}'(\mathbf{x})}{\overline{E}''(\mathbf{x})})-2=\log_{2}\quantity(\frac{\overline{f}' + \rho'\overline{g}' - 1}{\overline{f}' + \rho''\overline{g}' - 1})-2

\displaystyle>

\displaystyle\log_{2}\quantity(\frac{\overline{f}' + \rho'\overline{g}'}{\overline{f}' + \rho''\overline{g}'})-2=\log_{2}\quantity(\frac{1 + \overline{g}'}{1 + \frac{\rho''}{\rho'}\overline{g}'})-2

\displaystyle=

\displaystyle\log_{2}\quantity(\frac{1 + \overline{g}'}{1 + \frac{(M-1)(M-2)(2w - d)^l + 4}{q_1(q_1 - 1)(2w-2)^l + 4}\overline{g}'})-2,

(49)

which is obviously positive since

when

and

Note that, for constructing a code that satisfies the condition

, it is sufficient to obtain just one code whose objective function is smaller than

.

III-C
2
Novel Limit on the Number of Grover Operators

The BBHT search and GAS algorithms try to find the appropriate number of Grover operators, which increases the query complexity compared to the case where the number of solutions is previously known.
Although, in general, the exact number of solutions
t
is unknown, the possible range of
t
may be obtained from the inherent structure of the problem.
Our proposed algorithm exploits this information.

Theorem 4
.

If
w\leq d
and
A(n-1,d,w)<M-1
, then the exact number of solutions
t
is lower bounded by

\displaystyle t

\displaystyle\geq\underline{t}=\left\{\begin{array}[]{ll}w!&(w-\frac{d}{2}=1)\\
\displaystyle{\min_{2\leq i\leq w-d/2}}\ \binom{w}{i}&(w-\frac{d}{2}\geq 2).\end{array}\right.

The proof is given in the Appendix
A
.

We improve the quantum search algorithm using the obtained lower bound
\underline{t}
of (
4
).
Traditionally, the number of Grover operators
L
is uniformly drawn from the semi-open interval
[0,k)
, where
k
is a parameter that increases in each iteration of GAS.
The probability of success
P_{k}(t)
is known as
[
16
]

P_{k}(t)=\frac{1}{2}-\frac{\sin(4k\theta)}{4k\sin(2\theta)}

(52)

where

\theta=\arcsin\quantity(\sqrt{\frac{t}{2^{q_{1}}}}).

(53)

Then, the optimal value
k_{\mathrm{opt}}
is

\displaystyle k_{\mathrm{opt}}

\displaystyle=\mathop{\mathrm{arg~min}}\limits_{k}\ \frac{k}{P_{k}(t)}

\displaystyle=\mathop{\mathrm{arg~min}}\limits_{k}\ \frac{4k^{2}\sin(2 \theta)}{2k\sin(2\theta)-\sin(4k\theta)}

(54)

and is upper bounded by

k_{\mathrm{opt}}\leq\overline{k}_{\mathrm{opt}}=\mathop{\mathrm{arg~min}}\limits_{k}\ \frac{k}{P_{k}(\underline{t})}.

(55)

Theorem 5
.

If the ratio
t/2^{q_{1}}
is sufficiently small, then

\overline{k}_{\mathrm{opt}}\in\quantity[1, \left\lceil\frac{1+\sqrt{2}}{2} \sqrt{\frac{2^{q_1}}{\underline{t}}}\right\rceil].

(56)

The proof is given in the Appendix
B
.
In general,
t/2^{q_{1}}
is sufficiently small that it can be approximated as
(t/2^{q_{1}})^{2}\sim 0
.
The search range of
\overline{k}_{\mathrm{opt}}
can be limited within the closed interval using Theorem
5
.
Then, we can search for
\overline{k}_{\mathrm{opt}}
with negligible complexity; however,
\overline{k}_{\mathrm{opt}}
itself is not expressed in a closed form.
For example, within the closed interval, root-finding algorithm such as the bisection method
[
27
]
or Newton-Raphson method
[
28
]
is used for the first-order derivative of
k/P_{k}(\underline{t})
, all the
k
that take the extreme values are listed, and
\overline{k}_{\mathrm{opt}}
is one of the listed values or one of both ends of the closed interval. Note that, the lower bound obtained in Theorem
4
requires assumption
w\leq d
and
A(n-1,d,w)<M-1
. Thus, this extra technique cannot be applied to all possible parameters of the problem. Since there has not been much research on the number of solutions for constant weight codes, more general and stronger bounds may be found in the future.
Moreover, Theorem 4 also holds for
k_{\mathrm{opt}}
by replacing
\underline{t}
with
t
. This result suggests that the value of
k
need not be larger than
(1+\sqrt{2})/2\cdot\sqrt{2^{q_{1}}}\sim 1.207\cdot\sqrt{2^{q_{1}}}
, even if the number of solutions is completely unknown. A similar technique was proposed in
[
19
]
to set the upper bound of
k
to
\sqrt{2^{q_{1}}}
. Theorem
5
provides a rough basis for this technique.

The query complexity can be reduced by setting
\overline{k}_{\mathrm{opt}}
as the upper bound on
k
.
Note that, although this paper only focuses on the lower bound, an upper bound on
t
may be obtained for some problems, and a similar approach could speedup the quantum search algorithm more.

The original search space size is calculated as

The conventional GAS (Algorithm

The proposed GAS (Algorithm

Both classical exhaustive search and conventional GAS used the proposed objective function

One major reason is the quadratic speedup of GAS with the aid of quantum superposition, entanglement, and amplitude amplification.

These proposals lead to fewer states of interest and higher probability of success, resulting in faster convergence.

V
Conclusions

Although much work has been done on binary constant weight codes, its parameter-dependent combinatorial explosion is still a problem. In this paper, we proposed a quantum search algorithm for binary constant weight codes as a solution.
The search problem was newly formulated as a QUBO problem, and novel bounds were derived for the minimum of the objective function value and the exact number of solutions.
We proposed a modified algorithm for GAS using the derived bounds and showed that it can further accelerate the quadratic speedup while reducing the number of qubits.
Similar approaches that utilize problem-specific bounds, such as those in this study, have the potential for wide use in applications of quantum search algorithms to other problems, thereby improving the feasibility of quantum speedup.
