Non-Abelian Hodge Correspondence:

The basic principle of the non-Abelian Hodge correspondence is that the correspondence between Higgs bundles and representations of the fundamental group can be formulated as a kind of non-Abelian Hodge theorem, that is, an analogy occurs with the Hodge decomposition of a non-Abelian Keller manifold, but with coefficients in a non-Abelian group
\mathop{GL}(n,\mathbb{C})
, instead of the abelian group
\mathbb{C}
(cf. Main Results: Non-Abelian gauge theory and T Duality is
\Theta^{\pm ell}
NF Hodge Theater).

1. Non-Abelian Hodge theorem:

A representation
{\displaystyle\rho:\pi_{1}(X)\to GL(r,\mathbb{C})}
of the fundamental group is semisimple if and only if the flat vector bundle
{\displaystyle E={\hat{X}}\times_{\rho}\mathbb{C}^{r}}
admits a harmonic metric. Furthermore the representation is irreducible if and only if the flat vector bundle is irreducible.

2. Non-Abelian Hodge theorem:

A Higgs bundle
{\displaystyle(E,\Phi)}
has a Hermitian Yang–Mills metric if and only if it is polystable. This metric is a harmonic metric, and therefore arises from a semisimple representation of the fundamental group, if and only if the Chern classes
{\displaystyle c_{1}(E)}
and
{\displaystyle c_{2}(E)}
vanish. Furthermore, a Higgs bundle is stable if and only if it admits an irreducible Hermitian Yang–Mills connection, and therefore comes from an irreducible representation of the fundamental group.

3. Non-Abelian Hodge theorem:

A Higgs bundle arises from a semisimple representation of the fundamental group if and only if it is polystable. Furthermore it arises from an irreducible representation if and only if it is stable.

4. Non-Abelian Hodge theorem version for module spaces:

There are homeomorphisms
{\displaystyle M_{Dol}^{ss}\cong M_{dR}\cong M_{B}^{+}}
of moduli spaces which restrict to homeomorphisms
{\displaystyle M_{Dol}^{s}\cong M_{dR}^{*}\cong M_{B}^{*}}.
