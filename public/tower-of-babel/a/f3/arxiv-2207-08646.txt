Abstract
This paper presents a factor graph formulation and particle-based spa ( spa ) for robust sequential localization in multipath-prone environments. The proposed algorithm jointly performs data association, sequential estimation of a mobile agent position, and adapts all relevant model parameters. We derive a novel non-uniform fa ( fa ) model that captures the delay and amplitude statistics of the multipath radio channel. This model enables the algorithm to indirectly exploit position-related information contained in the mpc for the estimation of the agent position without using any prior information such as floorplan information or training data. Using simulated and real measurements in different channel conditions, we demonstrate that the algorithm can provide high-accuracy position estimates even in fully obstructed line-of-sight (OLOS) situations and show that the performance of our algorithm constantly attains the pcrlb ( pcrlb ), facilitating the additional information contained in the presented fa model. The algorithm is shown to provide robust estimates in both, dense multipath channels as well as channels showing specular, resolved mpc , significantly outperforming state-of-the-art radio-based localization methods.

Performance for Real Radio Measurements

For further validation of the proposed algorithm, we use real radio measurements collected in a laboratory hall of NXP Semiconductors, Gratkorn, Austria. The hall, shown in Fig.

VIII
Conclusion

We have presented a particle-based
spa
(
spa
) that sequentially estimates the position of a mobile agent using range and amplitude measurements provided by a snapshot-based
ceda
(
ceda
).
We introduced a novel
nlos
(
nlos
) model that is adapted to the
dps
(
dps
) of the multipath radio channel. We analyzed the performance of the proposed algorithm using both numerically simulated and real measurements in different channel conditions and showed that the additional information provided by the
nlos
model can support the estimation of the agent position. Our algorithm significantly outperformed the conventional
pdaai
filter and consistently attained the
pcrlb
in partial
olos
situations (i.e., no lost tracks). While
mpslam
(
mpslam
) can naturally outperform our algorithm in channels showing resolved, specular
mpc
, we demonstrate the proposed algorithm to offer a significantly smaller number of lost tracks at reduced execution time in a geometrically ambiguous scenario.

A possible direction for future research includes extending the model to multiple biases with respect to several
mpc
using joint probabilistic data association and dynamic
mpc
initialization
[
46
,
48
]
or to several
mpc
clusters by using data association with extended objects
[
47
]
.
