The Computational Complexity of Finding Temporal Paths under Waiting Time Constraints
Arnaud Casteigts, Anne-Sophie Himmel, Hendrik Molter, Philipp Zschoche

Abstract
Computing a (short) path between two vertices is one of the most fundamental primitives in graph algorithmics. In recent years, the study of paths in temporal graphs, that is, graphs where the vertex set is fixed but the edge set changes over time, gained more and more attention. A path is time-respecting, or temporal , if it uses edges with non-decreasing time stamps. We investigate a basic constraint for temporal paths, where the time spent at each vertex must not exceed a given duration Δ \Delta , referred to as Δ \Delta - restless temporal paths . This constraint arises naturally in the modeling of real-world processes like packet routing in communication networks and infection transmission routes of diseases where recovery confers lasting resistance. While finding temporal paths without waiting time restrictions is known to be doable in polynomial time, we show that the “restless variant” of this problem becomes computationally hard even in very restrictive settings. For example, it is W[1] -hard when parameterized by the distance to disjoint path of the underlying graph, which implies W[1] -hardness for many other parameters like feedback vertex number and pathwidth. A natural question is thus whether the problem becomes tractable in some natural settings. We explore several natural parameterizations, presenting FPT algorithms for three kinds of parameters: (1) output-related parameters (here, the maximum length of the path), (2) classical parameters applied to the underlying graph (e.g., feedback edge number), and (3) a new parameter called timed feedback vertex number , which captures finer-grained temporal features of the input temporal graph, and which may be of interest beyond this work.

Related work.

Several types of waiting time constraints have been considered in the temporal

Our contributions.

We introduce the problem

Restless Temporal Path
. To get a finer understanding of the computational complexity of this problem,
we turn our attention to its parametrized complexity.
In stark contrast to both restless temporal walks and non-restless temporal paths,
we show that this problem is
NP
-hard even in very restricted settings—in particular, even when the lifetime is restricted to only three time steps—and
W[1]
-hard when parameterized by the
(vertex deletion)
distance to disjoint paths
of the underlying
graph, which implies
W[1]
-hardness with respect to many other parameters like feedback vertex number and pathwidth (
\cref
sec:path:hardness).
This is tight in the sense that the problem can be solved in polynomial time when the underlying graph is a forest.
On the positive side, we explore parameters of three different natures. First,
we show that the problem is fixed-parameter tractable (

length
(in number of hops) of the temporal path (
\cref
sec:fptalg).
We further show that the problem is

of the underlying graph (
\cref

Additionally, we show that the problem presumably does not admit a polynomial kernel
under the previously mentioned parameterizations where the problem is in

Our results provide a fine-grained characterization of the tractability boundary of the
computation of restless temporal paths for parameters of the underlying graph,
as illustrated by the vicinity of the corresponding parameters in

\cref
fig:hierarchy. Then, going beyond parameters related to the output and to the underlying graph,
we define a novel temporal version of the classic

called

We show that finding restless temporal paths is FPT when parameterized by

We believe that the latter is an interesting turn of events compared to our hardness results.

In this paper, we focus mainly on the case of non-strict temporal paths, i.e., the times along a path are required to be non-decreasing. For instance, a similar NP-hardness reduction as for non-strict temporal paths may apply, but requires more than a constant lifetime to be adapted. In fact, the length of a strict temporal path is trivially bounded by the lifetime itself, thus an FPT algorithm for the

Parameterized complexity.

We use standard notation and terminology from parameterized

[

]

and give here a brief overview of the most important concepts that are used in this paper.

is a language

A parameterized problem is

(in the complexity class

if there is an algorithm that solves each instance

in

time,
for some computable function

A decidable parameterized problem

admits a

if there is a polynomial-time algorithm that transforms each instance
(I,r)
into an instance
(I^{\prime},r^{\prime})
such that
(I,r)\in L
if and only if
(I^{\prime},r^{\prime})\in L
and
|(I^{\prime},r^{\prime})|\in r^{O(1)}
.
If a parameterized problem is hard for the parameterized complexity class
W[1]
, then it is (presumably) not in
FPT

The complexity classes
W[1]
is closed under parameterized reductions, which may run in
FPT
-time and additionally set the new parameter to a value that exclusively depends on the old parameter.

If there is a

1.

If
t^{\prime}>t
, then replace
t
with the next layer in
L_{i}
and repeat.

2.

If
t-t^{\prime}\leq\Delta
, then add
t
to
T[v_{i}]
, replace
t
with the next layer in
L_{i}
and repeat.

3.

Else, replace
t^{\prime}
with the next layer in
T[v_{i-1}]
and repeat.

This is done until all elements in one of the lists are processed.

The resulting list
T[v_{i}]
is again sorted.
Due to this and
T[v_{1}](=L_{1})
being sorted, we can assume that
T[v_{i-1}]
is given as a sorted list of layers when computing
T[v_{i}]
.
Hence, we can compute each table entry
T[v_{i}]
in
O(|T[v_{i-1}]|+|L_{i}|)
time.
It further holds that
|T[v_{i}]|\leq|L_{i}|
and
\sum_{i=1}^{n}|L_{i}|=\sum_{i=1}^{\ell}|E_{i}|
.
Hence, the dynamic program runs in
O(|\mathcal{G}|)
time.
∎

Furthermore, it is easy to observe that computational hardness of
Restless Temporal Path
for some fixed value of
\Delta
implies hardness for all larger finite values of
\Delta
.
This allows us to construct hardness reductions for small fixed values of
\Delta
and still obtain general hardness results.

Observation 3
.

Given an instance
I=(\mathcal{G},s,z,k,\Delta)
of
Short Restless Temporal Path
,
we can construct in linear time an instance

of
Short Restless Temporal Path
such that
I
is a
yes
-instance if and only if
I^{\prime}
is a
yes
-instance.

Proof.

The result immediately follows from the observation that a temporal graph
\mathcal{G}
contains a
\Delta
-restless temporal
(s,z)
-path
if and only if
the temporal graph
\mathcal{G}^{\prime}
contains a
(\Delta+1)
-restless temporal
(s,z)
-path, where

\mathcal{G}^{\prime}
is obtained from
\mathcal{G}
by inserting one trivial (edgeless) layer
after every
\Delta
consecutive layers. ∎

However, for some special values of
\Delta
we can solve
Restless Temporal Path
in polynomial time.

Observation 4
.

Restless Temporal Path
on instances
(\mathcal{G},s,z,\Delta)
can be solved in polynomial time,
if
\Delta=0
or
\Delta\geq\ell
.

Proof.

Considering
\Delta=0
implies that the entirety of a path between

and

must be realized in a single layer.
Thus, the problem is equivalent to testing if at least one of the layers
G_{i}

contains a (static) path between
s
and
z
.

If
\Delta\geq\ell
,
then

-restless temporal paths correspond to unrestricted temporal paths, whose computation can be made using any of the (polynomial time) algorithms in Bui-Xuan, Ferreira, and Jarry

.
∎

3
Hardness results for restless temporal paths

In this section we present a thorough analysis of the computational hardness of
Restless Temporal Path
which also transfers to

NP-hardness for few layers.

We start by showing that

-complete even if the lifetime

Theorem 5

W[1]
-hardness for distance to disjoint paths.

In the following, we show that parameterizing
Restless Temporal Path
with structural graph parameters of the underlying graph of the input temporal graph presumably does not yield fixed-parameter tractability for a large number of popular parameters.
In particular, we show that
Restless Temporal Path
parameterized by the distance to disjoint paths of the underlying graph is
W[1]
-hard.
The
distance to disjoint paths
of a graph
G
is the minimum number of vertices we have to remove from
G

such that the reminder of
G
is a set of disjoint paths.
Many well-known graph parameters can be upper-bounded in the distance to disjoint paths, e.g., pathwidth, treewidth, and feedback vertex number
[
57
]
.
Hence, the following theorem also implies that
Restless Temporal Path
is
W[1]
-hard when parameterized by the pathwidth or the feedback vertex number of the underlying graph.

.

Timed feedback vertex number

In this section we introduce a new temporal version of the well-studied “feedback

destroying temporal cycles are unbounded in our reductions. We leave the
parameterized complexity of

2.

V^{\prime\infty}\setminus T^{\prime}=\emptyset
,

3.

I
is a
yes
-instance if and only if
I^{\prime}
is a
yes
-instance.

Proof.

Let
I=(G,V^{\infty},T,k)
be an instance of
Subset Feedback Vertex Set with Undeletable Vertices
.
Since we aim for a running time of
O(k(|V|+|E|))
,
we can assume that
\cref
rr:undeletable-cycle,rr:merge are not applicable on
I
, see
\cref
lem:rr:merge.

The goal now is to duplicate each vertex in
V^{\infty}\setminus T

k+1
times,
such that we cannot delete all of them even if there are not in
V^{\infty}
.
Note that we might create many copies of an edge doing this naïvely.
To avoid this, we observe that it suffices to replace
each maximal connected component in
G[V^{\infty}\setminus T]
with
k+1
vertices.
We partition
V(G[V^{\infty}\setminus T])=Q_{1}\uplus\dots\uplus Q_{c}

such that
Q_{i}
is a maximal connected component of
G[V^{\infty}\setminus T]

and we construct
G^{\prime}:=(V^{\prime},E^{\prime})
, where

\displaystyle V^{\prime}

\displaystyle:=(V\setminus(V^{\infty}\setminus T))\cup\{q_{i}^{j}\mid i\in[c],j\in[k+1]\}\text{ and }

\displaystyle E^{\prime}

\displaystyle:=E(G[V\setminus(V^{\infty}\setminus T)])\cup\{\{q_{i}^{j},w\}\mid\exists v\in Q_{i}\colon\{v,w\}\in E\}.

Since
|\{q_{i}^{j}\mid i\in[c],j\in[k+1]\}|\leq|V|(k+1)
and
we copy each edge at most
k+1
times,
G^{\prime}
is constructed after
O(k(|V|+|E|))
time.

We now claim that
I
is a
yes
-instance
if and only if
I^{\prime}:=(G^{\prime},T^{\prime}:=V^{\infty}\cap V(G^{\prime}),T,k)
is a
yes
-instance
of
Subset Feedback Vertex Set with Undeletable Vertices
.

(\Rightarrow)
: Let
X
be a solution for
I
.
Then
X
is also a solution for
I^{\prime}
,
because
X\cap V^{\infty}=\emptyset
and for each cycle
C^{\prime}
in
G^{\prime}
containing a vertex from
T
,
we can construct a closed walk in
G
by replacing a vertex
q_{i}^{j}
by a path in
G[Q_{i}]
.
This closed walk induces a simple cycle
C
in
G
containing a vertex in
T
.
Hence,
C^{\prime}
also contains a vertex from
X
.

(\Leftarrow)
: Let
X
be a solution for
I^{\prime}
.
We assume without loss of generality that
X\cap\{q_{i}^{j}\mid i\in[c],j\in[k+1]\}=\emptyset
.
Suppose towards a contradiction that
X
is not a solution for
I
.
Let
C
be an cycle in
G
satisfying
V(C)\cap X=\emptyset\not=V(C)\cap T
.
We construct a closed walk
C^{\prime}
in
G^{\prime}
from
C
by replacing each maximal consecutive subpath in
C

containing only vertices from
Q_{i}
with
q_{i}^{1}
, for all
i\in[c]
.
Note that

contains a simple cycle which intersects

but not
X
—a contradiction.
∎

Now we are finally ready to prove
\cref
lem:sfvs-uv.

Proof of
\cref
lem:sfvs-uv.

First, we apply
\cref
lem:remove-non-terminals on
I
and
hence assume that
V^{\infty}\setminus T=\emptyset
.
Furthermore, by
\cref
lem:rr:merge we assume that
\cref
rr:merge,rr:undeletable-cycle are not applicable.
Thus,
G[V^{\infty}\cap T]
is an independent set.
We now create
k+1
copies of each vertex in
V^{\infty}\cap T
such that
we cannot remove all of them, even if there are deletable.
However, we have to be careful what kind of new cycles this creates.
We do the following.
Let
V^{\infty}\cap T=\{v_{1},v_{2},\dots,v_{p}\}
and take a fresh set of
vertices
Q_{i}:=\{q_{i}^{j}\mid j\in[k+1]\}
for each
i\in[p]
.
We construct
G^{\prime}:=(V^{\prime},E^{\prime})
, where

\displaystyle V^{\prime}:=

\displaystyle(V\setminus(V^{\infty}\cap T))\cup\bigcup_{i=1}^{p}Q_{i}\cup\{w_{i}^{\prime},w_{i}\mid\{v_{i},w\}\in E\},\text{ and}

\displaystyle E^{\prime}:=

\displaystyle\{\{v,w\}\in E\mid v,w\in V^{\prime}\}\cup

\displaystyle\{\{w_{i},w\},\{w_{i},w_{i}^{\prime}\},\{w_{i}^{\prime},q_{i}^{j}\}\mid\{v_{i},w\}\in E,i\in[p]\},j\in[k+1]\}.

Output
I^{\prime}=(G^{\prime},T^{\prime},k)
,
where
T^{\prime}:=(T\setminus V^{\infty})\cup\{w_{i}\mid\{v_{i},w\}\in E\}
.
Since
|\{q_{i}^{j}\mid i\in[c],j\in[k+1]\}|\leq|V|(k+1)
and
we create for each edge at most
k+2
new edges,
G^{\prime}
is constructed after
O(k(|V|+|E|))
time.
Together with the preprocessing of
\cref
lem:remove-non-terminals this gives an overall running time of
O(k^{2}(|V|+|E|))
.

We now claim that
I
is a
yes
-instance
if and only if
I^{\prime}
is a
yes
-instance of
Subset Feedback Vertex Set
.

(\Rightarrow)
: Let
X
be a solution for

.
Observe that
X\subseteq V^{\prime}
, because
V\setminus V^{\prime}\subseteq V^{\infty}
.
Assume towards a contradiction that there is a cycle
C^{\prime}
in
G^{\prime}
such that
V(C^{\prime})\cap X=\emptyset
.
Assume without loss of generality that
C^{\prime}
is a shortest of the set of cycles satisfying
V(C^{\prime})\cap X=\emptyset
.
Hence, for each
i\in[p]
we have that
|V(C^{\prime})\cap Q_{i}|\leq 1
,
and since
G[V^{\infty}\cap T]
is an independent set,
a vertex
q_{i}^{j}\in V(C^{\prime})\cap Q_{i}
has two neighbors
w^{\prime}_{i},u^{\prime}_{i}
, where
w,u\in V
.
Thus, we can construct a cycle
C
in
G
by replacing each subpath
w^{\prime}_{i},q_{i}^{j},u^{\prime}_{i}

with the vertex
v_{i}\in T\cap V^{\infty}
, where
q_{i}^{j}\in V(C^{\prime})\cap Q_{i}
and
i\in[p],j\in[k+1]
.
This contradicts

being a solution for
I
.

(\Leftarrow)
: Let
X^{\prime}
be a solution for
I^{\prime}
.
For all
i\in[p]
, we assume without loss of generality that

X^{\prime}\cap Q_{i}=\emptyset
:

This can be assumed, because
|Q_{i}|>k\geq|X^{\prime}|
and all vertices in

have the same neighborhood.

X^{\prime}\cap\{w_{i}\mid\{v_{i},w\}\in E\}=\emptyset
:

This can be assumed, because these vertices are of degree two and thus a vertex

can be replaced by its origin
w
.

X^{\prime}\cap\{w_{i}^{\prime}\mid\{v_{i},w\}\in E\}=\emptyset

Such a vertex

can be replaced by its origin

as well,

in
G^{\prime}
passing through

which does not include

,

for some

Hence

in

Hence there
v_{i}\in V(C)\cap(T\cap V^{\infty})

7
Conclusion

We have analyzed the (parameterized) computational complexity of

Restless Temporal Path
, a canonical variant of the problem of finding temporal
paths, where the waiting time at every vertex is restricted.
Unlike its non-restless counterpart or the “walk-version”, this problem turns out to be computationally hard,
even in quite restricted cases.
On the positive side, we give an efficient algorithm to find short restless temporal paths
and we could identify structural parameters of the underlying graph and of the temporal graph itself
that allow for fixed-parameter algorithms.
