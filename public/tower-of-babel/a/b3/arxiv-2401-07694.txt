Stochastic Optimization with Arbitrary Recurrent Data Sampling
William Powell, Hanbaek Lyu

Abstract
For obtaining optimal first-order convergence guarantees for stochastic optimization, it is necessary to use a recurrent data sampling algorithm that samples every data point with sufficient frequency. Most commonly used data sampling algorithms (e.g., i.i.d., MCMC, random reshuffling) are indeed recurrent under mild assumptions. In this work, we show that for a particular class of stochastic optimization algorithms, we do not need any further property (e.g., independence, exponential mixing, and reshuffling) beyond recurrence in data sampling to guarantee optimal rate of first-order convergence. Namely, using regularized versions of Minimization by Incremental Surrogate Optimization (MISO), we show that for non-convex and possibly non-smooth objective functions with constraints, the expected optimality gap converges at an optimal rate O ( n − 1 / 2 ) O(n^{-1/2}) under general recurrent sampling schemes. Furthermore, the implied constant depends explicitly on the ‘speed of recurrence’, measured by the expected amount of time to visit a data point, either averaged (‘target time’) or supremized (‘hitting time’) over the target locations. We discuss applications of our general framework to decentralized optimization and distributed non-negative matrix factorization.

Introduction

In this paper we consider the minimization of a non-convex weighted finite-sum objective
f:\mathbb{R}^{p}\to\mathbb{R}
:

\displaystyle\boldsymbol{\theta}^{*}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\Big\{f(\boldsymbol{\theta}):=\sum_{v\in\mathcal{V}}f^{v}(\boldsymbol{\theta})\pi(v)\Big\}

(1)

where
\boldsymbol{\Theta}\subseteq\mathbb{R}^{p}
is a convex, but not necessarily compact feasible set and
\boldsymbol{\theta}
represents the parameters of a model to be optimized. Here
\mathcal{V}
is a finite index set where one can view each index
v\in\mathcal{V}
representing (a batch of) data that can be accessed at once. Then
f^{v}(\boldsymbol{\theta})
is the loss incurred using parameter
\boldsymbol{\theta}
with respect to data at
v
, which is weighted by
\pi(v)\geq 0
when forming the overall objective
f
in (
1
). Without loss of generality, we assume the
\pi(v)
s sum to one.
When
\pi(v)\equiv\frac{1}{|\mathcal{V}|}
the problem (
1
) becomes the classical finite sum problem in the optimization literature. Instances of non-uniform
\pi
arise when training a model with imbalanced data as has been studied in
(
Steininger et al. 2021
;
Wang et al. 2022b
;
Sow et al. 2024
)
.

We aim to solve this problem by developing an algorithm which produces iterative parameter updates
\boldsymbol{\theta}_{n}
given only access to an
arbitrary sequence of data samples

(v_{n})_{n\geq 1}
. In order to reach a first-order stationary point of (
1
) for general objectives, it is necessary to use a sampling algorithm that is
recurrent
, meaning that every data point is sampled infinitely often with ‘sufficient frequency’. Note that recurrence is satisfied by many common sampling schemes such as i.i.d. (independently and identically distributed) sampling, (irreducible) Markov Chain Monte-Carlo (MCMC), cyclic sampling
(
Bertsekas 2011
)
, and random-reshuffling
(
Ying et al. 2017
)
. The main question we ask in this work is the following:

\bullet

Is there any class of stochastic optimization algorithms for which recurrent sampling is enough to obtain optimal first-order convergence guarantee for (
1
)?

In this paper, we show that for a class of suitable extensions of stochastic optimization algorithms known as
Minimization by Incremental Surrogate Optimization
(MISO)
(
Mairal 2015
)
, no additional property of a data sampling algorithm (e.g., independence, exponential mixing, reshuffling) other than recurrence is needed in order to guarantee convergence to first-order stationary points. Furthermore, we show that the rate of convergence depends crucially on the worst-case (over the initial locations) amount of times to reach a furthest target and/or an average target.
These correspond to the notion of ‘hitting time’ and ‘random target time’ in Markov chain theory, respectively.

With the original MISO algorithm in
(
Mairal 2013
)
, even under the general recurrent data sampling, we are able to obtain asymptotically optimal iteration complexity if we can use strongly convex surrogate functions. However, there is a significant technical bottleneck in showing asymptotic convergence to stationary points, which was classically established in
(
Mairal 2015
)
in case of the i.i.d. data sampling. We find that using additional regularization helps with improving the convergence rate and allows us to prove asymptotic convergence to stationary points under arbitrary recurrent data sampling. For these reasons, we propose a slight extention of MISO that we call the
Regularized Minimization by Incremental Surrogate Optimization
(RMISO), which takes the following form:

Step 1.

Sample
v_{n}
according to a recurrent sampling algorithm

Step 2.

g_{n}^{v_{n}}\leftarrow
Convex majorizing surrogate of
f^{v_{n}}
at
\boldsymbol{\theta}_{n-1}
;
g_{n}^{v}=g_{n-1}^{v}
for
v\neq v_{n}

Step 3.

\bar{g}_{n}\leftarrow\sum_{v\in\mathcal{V}}g_{n}^{v}\pi(v)
; Compute

\displaystyle\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}

\displaystyle\Big[\bar{g}_{n}(\boldsymbol{\theta})+\Psi(\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert)\Big].

The algorithm maintains a list of majorizing surrogate functions for each data point
v
. At each step, a new data sample
v_{n}
is drawn according to a recurrent data sampling algorithm. We then find a new majorizing convex surrogate
g_{n}^{v_{n}}
that is tight at the current parameter
\boldsymbol{\theta}_{n-1}
. All other surrogates are unchanged. Then the new parameter
\boldsymbol{\theta}_{n}
is found by minimizing the empirical mean of the current surrogates plus a regularization term
\Psi(\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert)
that penalizes large values of
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert
. To handle dependent data, many algorithms use some form of projection or regularization to achieve this property
(
Lyu 2023
;
Bhandari et al. 2018
;
Roy & Balasubramanian 2023
)
. This allows one to control the bias introduced by dependent sampling schemes as well as use the broader class of convex surrogates instead of requiring them to be strongly convex. The original MISO
(
Mairal 2015
)
is recovered by omitting this regularization term. The particular choice of this term is crucial for the success of the analysis under the general recurrent data sampling setting.

Applications of our work include distributed optimization over networks where
\mathcal{V}
forms the vertex set of a connected graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
and each vertex
v
stores some data. Prior work
(
Johansson et al. 2010
;
Johansson et al. 2007
;
Ram et al. 2009
;
Lopes & Sayed 2007
;
Mao et al. 2020
;
Even 2023
;
Sun et al. 2022
)
studies the performance of various optimization algorithms in this setting assuming the sequence
(v_{n})_{n\geq 1}
is a Markov chain
on the graph
\mathcal{G}
. Here
\pi
is typically taken to be uniform and it is frequently assumed that the Markov chain is an MCMC sampling converging to
\pi
, see
(
Sun et al. 2022
;
Johansson et al. 2010
;
Wang et al. 2022a
)
.

In this setting we find both theoretically and empirically that convergence of our algorithm can be accelerated by choosing sampling schemes that guarantee a higher frequency of visits to each
v\in\mathcal{V}
. Such schemes may be non-Markovian or not aperiodic and so not guaranteed to converge to a stationary distribution. Moreover, our analysis does not require
\pi
to agree with the stationary measure of the sampling process if it exists. As remarked in
(
Even 2023
)
, this additional flexibility may be advantageous as it allows one to opt for more efficient sampling schemes who’s stationary measure may not agree with the data-weighting-distribution
\pi
. In our context, these are the schemes which minimize the measures of recurrence we define in the sequel.

1.1
Contribution

Our algorithms and analysis consider three cases which we briefly summarize in the following bullet points.

•

We show convergence rates of
O(n^{-1/2})
for MISO with strongly convex surrogates or constant quadratic proximal regularization, matching the rate shown for SAG in
(
Even 2023
)
. The implied constant depends on the potentially much smaller ’target time’ rather than the hitting time.

•

The same convergence rates hold for MISO with dynamic quadratic proximal regularization where, inspired by the dynamic step size used for SAG in
(
Even 2023
)
, the regularization parameter is adaptive to the state of the sampling process. Asymptotic convergence of stationarity measures in expectation is also proved.

•

Convergence rates of
O(n^{-1/2}\log n)
are shown for MISO with diminishing search radius restriction, where averaged surrogates are minimized within a diminishing radius. We show almost sure convergence to stationarity for this method.

•

We experimentally validate our results for the tasks of non-negative matrix factorization and logistic regression. We find that our method is robust to data heterogeneity as it produces stable iterate trajectories while still maintaining fast convergence (see Sec.
4.2
).

1.2
Related Work

MISO
(
Mairal 2015
)
was originally developed to solve finite sum problems under i.i.d sampling and proceeds by repeatedly minimizing a surrogate of the empirical loss function. In
(
Mairal 2015
)
it is shown that for MISO the expected objective optimality gap
\mathbb{E}[f(\boldsymbol{\theta}_{n})-f(\boldsymbol{\theta}^{*})]
decays at rate
O(1/n)
when the objective function is convex and exponentially fast when it is strongly convex, just as batch gradient descent does
(
Bottou et al. 2018
)
. For non-convex
f
it is shown that the iterates produced by MISO converge to the set of stationary points of
f
over a convex constraint set, but no convergence rate analysis is given. Convergence rates for non-convex objectives were later provided for unconstrained problems in
(
Qian et al. 2019
)
where it was shown that the expected gradient norm
\mathbb{E}[\lVert\nabla f(\boldsymbol{\theta}_{n})\rVert]
decays at rate
O(n^{-1/2})
. This rate was matched for the constrained setting in
(
Karimi et al. 2022
)
. However, both papers only consider i.i.d sampling.

(R)MISO may be compared with
Stochastic Averaged Gradient
(SAG)
(
Schmidt et al. 2017
)
as both store the most recent information computed using the data
v
and output new parameter updates
\boldsymbol{\theta}_{n}
depending on an average of this information over
\mathcal{V}
. Recently in
(
Even 2023
)
, it was shown that for non-convex objectives SAG produces iterates such that the expected gradient norm decays at rate
O(n^{-1/2})
under Markovian sampling. In comparison, the expected gradient norm converges at rate
O(n^{-1/4})
for other stochastic first-order methods such as Stochastic Gradient Descent (SGD)
(
Sun et al. 2018
;
Alacaoglu & Lyu 2023
;
Even 2023
;
Karimi et al. 2019
)
. Other works devoted to the study of first order optimization methods under Markovian sampling include
(
Beznosikov et al. 2023
;
Bhandari et al. 2018
;
Wang et al. 2022a
;
Huo et al. 2023
;
Lyu 2023
)
.

There has also been a recent focus on proving faster convergence for SGD using without-replacement sampling methods such as random-reshuffling
(
Gürbüzbalaban et al. 2021
;
Ying et al. 2017
)
. This has been further extended to variance reduced algorithms
(
Huang et al. 2021
;
Malinovsky et al. 2023
;
Beznosikov & Takáč 2023
)
and distributed optimization
(
Mishchenko et al. 2022
;
Horváth et al. 2022
)
. New sampling algorithms that aim to improve over random reshuffling have been suggested in
(
Rajput et al. 2022
;
Lu et al. 2022a
;
Mohtashami et al. 2022
)
. In particular, in
(
Lu et al. 2022b
)
the authors show that the convergence of SGD can be accelerated provided a certain concentration inequality holds and propose leveraging this using a greedy sample selection strategy.

To obtain our results, we adopt a new analytical approach which is inspired in part by the analysis of SAG in
(
Even 2023
)
. This strategy differs significantly from mixing rate arguments used in the analysis of stochastic optimization methods with Markovian data (e.g
(
Sun et al. 2018
;
Bhandari et al. 2018
;
Nagaraj et al. 2020
;
Lyu et al. 2020
;
Lyu et al. 2022
;
Lyu 2023
;
Alacaoglu & Lyu 2023
)
). We give a short sketch of our proofs in Section
3.4
and a brief overview of mixing rate techniques and the challenges of adapting them to the analysis of MISO in Appendix
B
. We believe that these techniques may be of interest in their own right and may further contribute to analyzing other stochastic optimization methods with recurrent data sampling.

Main Results

3.1
Optimality Conditions

We now introduce the optimality conditions used in this paper and related quantities. Here we denote
f
to be a general objective function
f:\boldsymbol{\Theta}\to\mathbb{R}
, but elsewhere
f
will refer to the objective function in (
1
) unless otherwise stated.

For a given function
f
and
\boldsymbol{\theta}^{*},\boldsymbol{\theta}\in\boldsymbol{\Theta}
, we define its
directional derivative
at
\boldsymbol{\theta}^{*}
in the direction
\boldsymbol{\theta}-\boldsymbol{\theta}^{*}
as

\displaystyle\nabla f(\boldsymbol{\theta}^{*},\boldsymbol{\theta}-\boldsymbol{\theta}^{*}):=\lim_{\alpha\to 0^{+}}\frac{f(\boldsymbol{\theta}^{*}+\alpha(\boldsymbol{\theta}-\boldsymbol{\theta}^{*}))-f(\boldsymbol{\theta}^{*})}{\alpha}

(4)

A necessary first order condition for
\boldsymbol{\theta}^{*}
to be a local minimum of
f
is to require
\nabla f(\boldsymbol{\theta}^{*},\boldsymbol{\theta}-\boldsymbol{\theta}^{*})\geq 0
for all
\boldsymbol{\theta}\in\boldsymbol{\Theta}
(see
(
Mairal 2015
)
). Thus we define the optimality of
f
at
\boldsymbol{\theta}^{*}\in\boldsymbol{\Theta}
as

\displaystyle O_{f}(\boldsymbol{\theta}^{*}):=\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}^{*}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}^{*},\boldsymbol{\theta}-\boldsymbol{\theta}^{*}).

(5)

Note that
O_{f}(\boldsymbol{\theta}^{*})
is non-negative (since we may take
\boldsymbol{\theta}=\boldsymbol{\theta}^{*}
) and only positive if there exists some
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\nabla f(\boldsymbol{\theta}^{*},\boldsymbol{\theta}-\boldsymbol{\theta}^{*})<0
.
Thus we say that
\boldsymbol{\theta}^{*}\in\boldsymbol{\Theta}
is a
stationary point
of
f
over
\boldsymbol{\Theta}
if
O_{f}(\boldsymbol{\theta}^{*})=0
.
If
f
is differentiable and
\boldsymbol{\Theta}
is convex, this is equivalent to
-\nabla f(\boldsymbol{\theta}^{*})
being in the normal cone of
\boldsymbol{\Theta}
at
\boldsymbol{\theta}^{*}
. If
\boldsymbol{\theta}^{*}
is in the interior of
\boldsymbol{\Theta}
then it implies that
\lVert\nabla f(\boldsymbol{\theta}^{*})\rVert=0
.

For iterative algorithms, this stationary point condition may hardly be satisfied in a finite number of iterations. A practically important question is how the worst case number of iterations required to achieve an
\varepsilon
-approximate solution scales with the desired precision
\varepsilon
. We say that
\boldsymbol{\theta}^{*}\in\boldsymbol{\Theta}
is an
\varepsilon
-
approximate stationary point
of
f
over
\boldsymbol{\Theta}
if
O_{f}(\boldsymbol{\theta}^{*})\leq\varepsilon
.
This notion of
\varepsilon
-approximate solution is consistent with the corresponding notion for unconstrained problems. In fact, if
f
is differentiable, and if
\boldsymbol{\theta}^{*}
is distance at least one away from the boundary
\partial\boldsymbol{\Theta}
, then it reduces to
\lVert\nabla f(\boldsymbol{\theta}^{*})\rVert\leq\varepsilon
. For each
\varepsilon>0
, we then define the
worst-case iteration complexity
of an algorithm for solving (
1
) as

\displaystyle N_{\varepsilon}(\boldsymbol{\theta}_{0}):=\inf\{n\geq 1:O_{f}(\boldsymbol{\theta}_{n})\leq\varepsilon\},

(6)

where
(\boldsymbol{\theta}_{n})_{n\geq 0}
is a sequence of iterates produced by the algorithm with initial estimate
\boldsymbol{\theta}_{0}
.

3.2
Assumptions

In this subsection, we state our assumptions for establishing the main results. Throughout this paper, we denote by
\mathcal{F}_{n}
the
\sigma
-algebra generated by the samples
v_{1},\ldots,v_{n}
and the parameters
\boldsymbol{\theta}_{0},\ldots,\boldsymbol{\theta}_{n}
produced by Algorithm
1
or
2
. With this definition,
(\mathcal{F}_{n})_{n\geq 1}
defines a filtration.

In what follows we will also define some important quantities in terms of the measure theoretic definition of the
L_{\infty}
norm for random variables:

\displaystyle\lVert X\rVert_{\infty}=\inf\{t>0:\mathbb{P}(|X|>t)=0\}.

(7)

This is due to the technical consideration that the conditional expectation
\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]
is random and hence so is
\sup_{n\geq 1}\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]
. Our analysis requires this supremum to be bounded by a non-random constant, while in the fully general case
\sup_{n\geq 1}\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]
may be an unbounded.

We first state our main assumption on the sampling scheme.

Assumption 3.1

(Recurrent data sampling)
.

The sequence
(v_{n})_{n\geq 1}
of data samples defines a stochastic process which satisfies the following property: for each
v\in\mathcal{V}
,
\sup_{n\geq 1}\left\lVert\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]\right\rVert_{\infty}<\infty
, i.e., the expected return time conditioned on
\mathcal{F}_{n}
is uniformly bounded.

Assumption
3.1
states that the data
(v_{n})_{n\geq 1}
are sampled in such a way that the expected time between visits to a particular data point is finite and uniformly bounded. Generalizing the notion of positive recurrence in Markov chain theory, we say a sampling algorithm is
recurrent
if Assumption
3.1
is satisfied. We emphasize that recurrence is the
only
requirement we make of the sampling process in order to prove the convergence rate guarantees in Theorem
3.8
and the asymptotic convergence in Theorem
3.9
(We do not assume independence or Markovian dependence, etc.). We include below a list of some commonly used recurrent sampling algorithms.

1.

(
i.i.d. sampling
) Sampling data i.i.d from a fixed distribution is the most common assumption in the literature
(
Mairal 2013
;
Mairal 2015
;
Bottou et al. 2018
;
Schmidt et al. 2017
;
Johnson & Zhang 2013
)
. Suppose we sample
v_{n}
i.i.d from some distribution
\gamma
on
\mathcal{V}
. Then the
\tau_{n,v}
are independent geometric random variables taking values from
\{1,2,\dots,\}
with success probability
\gamma(v)
, so
\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]=1/\gamma(v)
. In particular, if
\gamma
is uniform
\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]=|\mathcal{V}|
for all
n
and
v
.

2.

(
MCMC
) Markov chain Monte Carlo methods (see e.g. Ch.3 of
(
Levin & Peres 2017
)
) produce a Markov chain
(v_{n})
on
\mathcal{V}
. If this chain is irreducible then
\max_{v,w}\mathbb{E}_{w}[\tau_{0,v}]
is finite
(
Levin & Peres 2017
)
. For any
n
,
v
, and initial distribution
\nu
, the Markov property implies
\mathbb{E}_{\nu}[\tau_{n,v}|\mathcal{F}_{n}]=\mathbb{E}_{v_{n}}[\tau_{0,v}]
. So any irreducible Markov chain satisfies
3.1
.

3.

(
Cyclic sampling
) In cyclic sampling one samples data in order according to some enumeration until the dataset is exhausted. This process is then repeated until convergence. The authors of
(
Lu et al. 2022b
)
show that iteration complexity for SGD can be improved from
O(\varepsilon^{-4})
to
O(\varepsilon^{-3})
using such methods.
To see that
3.1
holds in this setting, we simply notice that
\tau_{n,v}\leq|\mathcal{V}|
for all
n
and
v
.

4.

(
Reshuffling
) Reshuffling is similar to cycling sampling except that the dataset is randomly permuted at the beginning of each epoch
(
Lu et al. 2022b
)
. It was observed empirically that random reshuffling performs better that i.i.d sampling in
(
Bottou 2012
)
and further studied in
(
Gürbüzbalaban et al. 2021
;
Lu et al. 2022b
)
. The authors of
(
Lu et al. 2022b
)
show the same improvement in iteration complexity for SGD as for cyclic sampling.
In this case,
3.1
is satisfied since
\tau_{n,v}\leq 2|\mathcal{V}|
.

In Markov chain theory, the quantity
\max_{v,w}\mathbb{E}_{w}[\tau_{0,v}]
is commonly denoted
t_{\text{hit}}
. Adapting this notion, we define

\displaystyle t_{\text{hit}}:=\max_{v\in\mathcal{V}}\,\sup_{n\geq 1}\,\,\left\lVert\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]\right\rVert_{\infty}

(8)

for each
v
when
3.1
holds, for general sampling schemes.

Continuing the connection with Markov chains, we also let

\displaystyle t_{\odot}:=\sup_{n\geq 1}\,\,\left\lVert\sum_{v\in\mathcal{V}}\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]\pi(v)\right\rVert_{\infty}

(9)

where
\pi
is as in (
1
). Note that if
v_{n}
is an irreducible Markov chain then the Markov property implies

\displaystyle t_{\odot}=\max_{w\in\mathcal{V}}\sum_{v\in\mathcal{V}}\mathbb{E}_{w}[\tau_{0,v}]\pi(v).

(10)

This is closely related to the
target time
define by

\displaystyle t_{\odot}^{w}=\sum_{v\in V}\mathbb{E}_{w}[\tau_{v}]\pi(v)

(11)

with the difference being that here
\tau_{v}=\inf\{n\geq 0:v_{n}=v\}
is the first hitting time of
v
rather than the first return time to
v
. The
random target lemma
(Lemma 10.1 in
(
Levin & Peres 2017
)
) states that if
\pi
is the stationary distribution of the Markov chain, then the target time is independent of the starting state
w
. In this case, the quantities (
10
) and (
11
) only differ by one. This can be seen by first noting that
\mathbb{E}_{w}[\tau_{v}]=\mathbb{E}_{w}[\tau_{0,v}]
if
v\neq w
. This leaves only the difference
\mathbb{E}_{w}[\tau_{0,w}]\pi(w)-\mathbb{E}_{w}[\tau_{w}]\pi(w)
. The second term is equal to zero and the first equals one since if
\pi
is the unique stationary distribution for the chain,
\pi(w)=\frac{1}{\mathbb{E}_{w}[\tau_{0,w}]}

(
Levin & Peres 2017
)
.

For transitive irreducible Markov chains,
t_{\text{hit}}
and
t_{\odot}
are comparable
(
Levin & Peres 2017
)
. However, in other situations
t_{\odot}
may be much smaller that
t_{\text{hit}}
. For instance, consider the simple random walk on the graph in Figure
1
, which we call the ‘lonely’ graph, and let
\pi
be its stationary distribution. In the lonely graph,
|\mathcal{V}|-1
vertices form a clique and the remaining vertex has degree one. A random walk on this graph has worst case hitting time
t_{\text{hit}}=O(|\mathcal{V}|^{2})
: its value is tied to the lonely vertex with degree one which has low probability of being visited. On the other hand
t_{\odot}
is only
O(|\mathcal{V}|)
since it only depends on an
average
hitting time instead of the worst case. See Example 10.4 in
(
Levin & Peres 2017
)
for more details.

We again emphasize that in our general setting, we do not require
(v_{n})
to be a Markov chain nor do we require
\pi
to be a stationary measure for the process. The above analysis serves to motivate the definition given in (
9
) and provide an example of where
t_{\odot}
may be much smaller than
t_{\text{hit}}
.

We next list some assumptions of the functions
f^{v}
.

Assumption 3.2

(Lower-bounded objective and directional derivatives)
.

For all
v\in\mathcal{V}
and
\boldsymbol{\theta},\boldsymbol{\theta}^{\prime}\in\boldsymbol{\Theta}
, the function
f^{v}
is bounded below, i.e.
\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}f^{v}(\boldsymbol{\theta})>-\infty
. Moreover, the directional derivative
\nabla f^{v}(\boldsymbol{\theta},\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta})
exists.

Assumption
3.2
implies that the objective
f
is bounded below. For the remainder of this paper we will denote
\Delta_{0}:=\bar{g}_{0}(\boldsymbol{\theta}_{0})-\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}f(\boldsymbol{\theta})
. It is important to note that if the initial surrogates
g_{0}^{v}
are in
\mathcal{S}_{L}(f^{v},\boldsymbol{\theta}_{0})
(as is the case in both Algorithms
1
and
2
) then
g_{0}(\boldsymbol{\theta}_{0})=f(\boldsymbol{\theta}_{0})
so
\Delta_{0}=f(\boldsymbol{\theta}_{0})-\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}f(\boldsymbol{\theta})
. The regularity assumption in
3.2
was used in
(
Mairal 2015
)
and is necessary in analyzing our algorithms using our definition of approximate stationarity. For Algorithm
2
we make the following stronger but common assumption which is crucial to our analysis:

Assumption 3.3
.

For each
v\in\mathcal{V}
, the function
f^{v}
is continuously differentiable and
\nabla f^{v}
is
L
-Lipschitz continuous.

For simplicity, we assume that if Assumption
3.3
holds then the Lipschitz constant of
f^{v}
agrees with that of the corresponding approximation error
h^{v}
.

Finally, Assumption
3.4
states that the radii in Algorithm

decrease slowly, but not too slowly. This is analogous to square summability of step sizes in gradient descent.

Assumption 3.4

(Square-summable and non-summable radii)
.

The sequence
(r_{n})_{n\geq 1}
is non-increasing,
\sum_{n=1}^{\infty}r_{n}=\infty

\sum_{n=1}^{\infty}r_{n}^{2}<\infty

3.4
Sketch of proofs

In this section we provide a short sketch of our analysis in order to convey the main ideas. Let
\bar{h}_{n}=\sum_{v\in V}h_{n}^{v}\pi(v)
be the average surrogate approximation error at step
n
. The key step in our analysis (Lemma
D.1
) is to prove

\displaystyle\sum_{n=1}^{N}c_{n}\mathbb{E}[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert]=O\left(\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\right),

(16)

where
c_{n}
is any non-increasing sequence. For simplicity, assume that the surrogate functions
g_{n}^{v}
and the objective functions
f^{v}
are differentiable and we are in the unconstrained setting, i.e.
\boldsymbol{\Theta}=\mathbb{R}^{p}
. If
\boldsymbol{\theta}_{n}
is a minimizer of
\bar{g}_{n}
then
\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n})=0
. Therefore
\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert=\lVert\nabla f(\boldsymbol{\theta}_{n})\rVert
and (
16
) implies

\displaystyle\sum_{n=1}^{N}c_{n}\mathbb{E}[\lVert\nabla f(\boldsymbol{\theta}_{n})\rVert]=O\left(\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\right).

(17)

If we take
c_{n}=1
, we can then conclude that
\min_{1\leq n\leq N}\mathbb{E}[\lVert\nabla f(\boldsymbol{\theta}_{n})\rVert]=O(N^{-1/2})
. The addition of regularization introduces an added complication because we are no longer directly minimizing
\bar{g}_{n}
on the entire feasible set and so do not have
\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n})=0
. However, as we argue in Section
D
, the added regularization is not too strong asymptotically.

The main idea is to focus in the individual error gradients because each has the property
\nabla h_{n}^{v}(\boldsymbol{\theta}_{k^{v}(n)-1})=0
. By Definition
2.1
, we then have
\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})\rVert\leq L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert
, so to show (
16
) we only need to prove

\displaystyle\sum_{n=1}^{N}c_{n}\mathbb{E}[\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert]=O\left(\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\right)

(18)

The triangle inequality and monotonicity of
(c_{n})
imply

\displaystyle c_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert\leq\sum_{i=k^{v}(n)}^{n}c_{i}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert,

(19)

so we can relate the error
\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})\rVert
to the sequence
(\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2})_{n\geq 1}
. The crucial role played by the regularization or strong convexity is that we can prove the following iterate stability:
\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}<\infty
a.s. This idea was also used in
(
Lyu & Li 2023
;
Lyu et al. 2022
;
Lyu 2023
)
.

Under Assumption
3.1
one can expect
\mathbb{E}[n-k^{v}(n)]\leq M
for some
M
. One can then intuitively view the expectation of the right hand side of (
19
) similarly to
\sum_{i=n-M}^{n}c_{i}\mathbb{E}[\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert]
. Summing this from
n=1
to
N
we conclude that for a positive constant
C
,

\sum_{n=1}^{N}\mathbb{E}[\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})\rVert]\approx C\sum_{n=1}^{N}c_{n}\mathbb{E}[\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert].

(20)

By Cauchy-Schwartz and the iterate stability obtained through regularization, the right hand side is
O\left(\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\right)
. Full details of our analysis are given in Appendices
C
,
D
, and
E
.

4.1
Applications

In this section we give some applications of our general framework. These include applications to matrix factorization as well as a double averaging version of RMISO derived by using prox-linear surrogates.

4.1.1
Distributed Matrix Factorization

Before beginning this section we define some additional notation. For a collection of matrices
\{A_{v}\}_{v\in\mathcal{V}}\subset\mathbb{R}^{n\times m}
we let
[A_{v};v\in\mathcal{V}]
be their concatenation along the horizontal axis. For a set
\boldsymbol{\Theta}\subset\mathbb{R}^{n\times m}
we let
\boldsymbol{\Theta}^{\mathcal{V}}=\{[A_{v};v\in\mathcal{V}]:A_{v}\in\boldsymbol{\Theta}\text{ for all }v\}
.

We consider the matrix factorization loss
f(W,H)=\frac{1}{2}\lVert X-WH\rVert_{F}^{2}+\alpha\lVert H\rVert_{1}
where
X\in\mathbb{R}^{p\times d}
is a given data matrix to be factored into the product of dictionary
W\in\boldsymbol{\Theta}_{W}\subseteq\mathbb{R}^{p\times r}
and code
H\in\boldsymbol{\Theta}_{H}\subseteq\mathbb{R}^{r\times d}
with
\alpha\geq 0
being the
L_{1}
-regularization parameter for
H
. Here
\boldsymbol{\Theta}_{W}
and
\boldsymbol{\Theta}_{H}
are convex constraint sets.

Suppose we have a connected graph
\mathcal{G}=(\mathcal{V},\mathcal{E})
where each vertex stores a matrix
X_{v}\in\mathbb{R}^{p\times d}
. For each
v\in\mathcal{V}
define the loss function

\displaystyle f^{v}(W)=\inf_{H\in\boldsymbol{\Theta}_{H}}\frac{1}{2}\lVert X^{v}-WH\rVert_{F}^{2}+\alpha\lVert H\rVert_{1},

(21)

which is the minimum reconstruction error for factorizing
X_{v}
using the dictionary
W
. In this context, the empirical loss to be minimized is
\frac{1}{|\mathcal{V}|}\sum_{v\in\mathcal{V}}f^{v}(W)
.
Note that this problem is not convex. Indeed, letting
X=[X_{v};v\in V]
it is equivalent to finding
(W^{*},H^{*})\in\boldsymbol{\Theta}_{W}\times\boldsymbol{\Theta}_{H}^{\mathcal{V}}
minimizing
\frac{1}{2}\lVert X-WH\rVert_{F}^{2}+\alpha\lVert H\rVert_{1}
,
which is a constrained non-convex optimization problem with a bi-convex loss function.

In order to apply RMISO let
W_{n-1}\in\boldsymbol{\Theta}_{W}
be the previous dictionary and denote

\displaystyle H_{n}^{v}\in\argmin_{H\in\boldsymbol{\Theta}_{H}^{\mathcal{V}}}\frac{1}{2}\lVert X_{v}-W_{n-1}H\rVert_{F}^{2}+\alpha\lVert H\rVert_{1}

(22)

if
v_{n}=v
and otherwise
H_{n}^{v}=H_{n-1}^{v}
.
Then the function
g_{n}^{v}(W):=\frac{1}{2}\lVert X_{v}-W_{n-1}H_{n}^{v}\rVert_{F}^{2}+\alpha\lVert H_{n}^{v}\rVert_{1}
is a majorizing surrogate of
f^{v}
at
W_{n-1}
and belongs to
\mathcal{S}_{L^{\prime}}(f^{v},W_{n-1})
for some
L^{\prime}>0
(see Ex.
G.5
).
Then Algorithms
1
and
2
can be used with these surrogates.

4.1.2
Prox-Linear Surrogates

Suppose each
f^{v}
is differentiable and has
L
-Lipschitz continuous gradients. Then the functions

\displaystyle\hskip-8.5359ptg^{v}(\boldsymbol{\theta})=f^{v}(\boldsymbol{\theta}^{\prime})+\langle\nabla f^{v}(\boldsymbol{\theta}^{\prime}),\boldsymbol{\theta}-\boldsymbol{\theta}^{\prime}\rangle+\frac{L}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}^{\prime}\rVert

(23)

are in
\mathcal{S}_{2L,L}(f^{v},\boldsymbol{\theta}^{\prime})
(see Example
G.2
) . Further suppose that
\pi
is the uniform distribution. Using these surrogates, the update according to Algorithm
1
is

\begin{cases}\bar{\boldsymbol{\theta}}_{n-1}&\leftarrow\frac{1}{|\mathcal{V}|}\sum_{v\in\mathcal{V}}\boldsymbol{\theta}_{k^{v}(n)-1}\\
\bar{\nabla}_{n-1}&\leftarrow\frac{1}{|\mathcal{V}|}\sum_{v\in\mathcal{V}}\nabla f^{v}(\boldsymbol{\theta}_{k^{v}(n)-1})\\
\tilde{\boldsymbol{\theta}}_{n-1}&\leftarrow\frac{\rho_{n}}{L+\rho_{n}}\boldsymbol{\theta}_{n-1}+\frac{L}{L+\rho_{n}}\bar{\boldsymbol{\theta}}_{n-1}\\
\boldsymbol{\theta}_{n}&\leftarrow\text{Proj}_{\boldsymbol{\Theta}}\left(\tilde{\boldsymbol{\theta}}_{n-1}-\frac{1}{L+\rho_{n}}\bar{\nabla}_{n-1}\right).\end{cases}

(24)

Compared with MISO (obtained by setting
\rho_{n}=0
in (
24
)) we see that the additional proximal regularization has the effect of further averaging the iterates, putting additional weight of
\frac{\rho_{n}}{L+\rho_{n}}
on the most recent parameter
\boldsymbol{\theta}_{n-1}
.

We ran each experiment with ten different seeds. The results plotted in Figure
3
show the average loss against the test dataset for both graph topologies over these ten runs as well as a shaded region with boundaries given by the standard deviation. We see that RMISO-DPR and MCSAG display poorer performance on the lonely graph as
t_{\text{hit}}
increases from
O(|\mathcal{V}|)
to
O(|\mathcal{V}|^{2})
. The performance of RMISO-CPR, RMISO-DR, and MISO are unchanged since each only depends on
t_{\odot}
, with RMISO-DR and MISO performing the best and only narrowly outperforming RMISO-CPR.

Both SGD-HB and AdaGrad converge quickly in both settings but suffer from unstable trajectories compared to RMISO and MCSAG. A more stable algorithm may be advantageous in situations where the value of the objective function cannot easily be computed. See
(
Nesterov & Shikhman 2015
)
for an example of such a situation.

5
Conclusion

In this paper we have established convergence and complexity results for our proposed extensions of MISO under the general assumption of recurrent data sampling. Our results show that convergence speed depends crucially on the average or supremized expected time to reach other data points. In particular, the constant proximal regularization version of our algorithm depends only on the averaged target time, a potentially large improvement over the hitting time. Both our analysis and numerical experiments display the benefit of using possibly non-i.i.d or non-Markovian sampling schemes in order to accelerate convergence.

This paper presents work whose goal is to advance the field of Machine Learning. There are many potential societal consequences of our work, none of which we feel must be specifically highlighted here.

Remark A.5

(Optimal sampling and estimating
t_{\odot}
and
t_{\text{hit}}
)
.

The dependence of the convergence rates on
t_{\odot}
or
t_{\text{hit}}
in Theorem
A.1
suggests one can accelerate convergence by choosing a sampling algorithm with the smallest values of these constants appropriate for the context. In general, an optimal sampling scheme is problem dependent. The best one can hope for, in terms of dependence on
|\mathcal{V}|
, is that both constants are
O(|\mathcal{V}|)
which is achieved by i.i.d sampling. However, this may not be feasible in settings like decentralized optimization where communication can only occur between neighboring vertices in a graph.

Depending on the graph topology, it is likely that for the standard random walk
t_{\text{hit}}
and
t_{\odot}
are much larger than
|\mathcal{V}|
, especially for sparse graphs. If a cycle containing all nodes in the graph exists, our theory suggests using cyclic sampling by traversing such a spanning cycle. In this case, both
t_{\text{hit}}
and
t_{\odot}
have optimal order
O(|\mathcal{V}|)
. If no such cycle exists, a good way to minimized
t_{\text{hit}}
is to find the shortest path in the graph which contains all vertices and then sample the vertices deterministically in order by walking over this path. This idea holds in a more general setting beyond optimization on graphs: a good way to minimize
t_{\text{hit}}
is to sample data as efficiently as possible by covering the dataset with the fewest possible number of repeats.

For many specific instances, these quantities can be estimated analytically. For random walks on graphs, much about the hitting time and target time is known through classical Markov chain theory
(
Levin & Peres 2017
)
. For cyclic sampling and random reshuffling respectively, one has
t_{\text{hit}}=|\mathcal{V}|
and
t_{\text{hit}}\leq 2|\mathcal{V}|
since each data point is visited exactly once every epoch and no re-shuffling occurs in the cyclic case. Under cyclic sampling, for fixed
n
and for each
1\leq k\leq|\mathcal{V}|
there is a
v
with
\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]=k
. So
t_{\odot}
is the largest possible value of
\sum_{v\in\mathcal{V}}\sigma_{v}\pi(v)
where
\sigma
ranges over all permutations of
{1,...,|\mathcal{V}|}.
In particular, if
\pi
is uniform,
t_{\odot}=\frac{|\mathcal{V}|-1}{2}
. For reshuffling with uniform
\pi
,
t_{\odot}
is at least this large by considering a time
n
at the beginning of an epoch. But it still holds
t_{\odot}\leq 2|\mathcal{V}|
since
t_{\odot}\leq t_{\text{hit}}
. If these quantities cannot be easily estimated analytically, they can be approximated using Monte-Carlo.

Remark A.6

(Comparison with i.i.d sampling)
.

If the sequence
(v_{n})
is formed by sampling vertices uniformly at random from
\mathcal{V}
then, as previously mentioned, the return times
\tau_{n,v}
are i.i.d geometric random variables with parameter
\frac{1}{|\mathcal{V}|}
. Then
\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]=|\mathcal{V}|
for each
n
and
v
so
t_{\odot}=|\mathcal{V}|
. Substituting
|\mathcal{V}|
for
t_{\odot}
in the optimal bound in Theorem
3.8

(ii)
we recover the result given for MISO in the i.i.d setting in
(
Karimi et al. 2022

up to a factor of two. This is in-spite of the fact that our analytical approach is necessarily different to handle general recurrent sampling and shows that our results are tight.

Remark A.7

(Iterate stability and regularization)
.

Here we give some remarks on the use of diminishing radius and proximal regularization in Algorithms
1
and
2
.

The diminishing radius restriction in Algorithm
2
is a ‘hard’ regularization technique. It bakes necessary iterate stability directly into the problem by enforcing the stronger condition
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
. In comparison with proximal regularization, diminishing radius bounds the one step iterate difference by a deterministic quantity. Moreover, as is argued in the proof of Theorem
3.9

(ii)
and the preceding propositions, sufficiently often the iterate
\boldsymbol{\theta}_{n}
obtained by minimizing the
\bar{g}_{n}
over the trust region in fact minimizes
\bar{g}_{n}
over the entire feasible set
\boldsymbol{\Theta}
. This allows us to prove that limit points of the iterates produces by Algorithm
2
are stationary even for general recurrent sampling schemes. However, diminishing radius introduces the drawback of needing to compute a projection at each step of the optimization process.

Compared to diminishing radius, proximal regularization is a form of ‘soft’ regularization. It is less restrictive than diminishing radius, but only allows us to derive a weaker form of iterate stability: we only have
\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}<\infty
instead of the stronger
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
which makes some aspects of the analysis slightly more challenging.

As mentioned in Section
3.2
, the use of dynamic proximal regularization in Case
3.6
adapts to the sampling process and increasingly penalizes large values of
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert
as the amount of time any vertex is left un-visited increases. The drawback is that we are unable to prove almost sure asymptotic convergence in Theorem
3.9
for Case
3.6
as we are for Case
3.7
. If we could show
\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\to 0
, then asymptotic convergence would follow. However
\rho_{n}
is not bounded and can take arbitrarily large values, albeit with low probability. But as we show in Lemma
E.1
,
\mathbb{E}[\rho_{n}]
is uniformly bounded, which allows us to deduce
\mathbb{E}[\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert]\to 0
and leads to the
L^{1}
-convergence result in Theorem
3.9
.

For case
3.5
it is relatively straightforward to show
\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\to 0
since
\rho_{n}
is constant. In this case, the difficulty lies in showing
\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\to 0
. We
are
able to prove this for Case
3.6
however because the use of dynamic proximal regularization allows us to show that the sequence
\max_{v\in\mathcal{V}}(n-k^{v}(n))\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert^{2}
is summable. More detail is given in the proofs and discussion in subsection
E.1
.

Appendix B
Convergence analysis using mixing times

In this section, we give an overview of the standard pipeline for analyzing stochastic optimization algorithms with Markovian data and discuss the difficulties of applying these techniques to the analysis of MISO.

The analysis of first order methods such as SGD generally rely on conditionally unbiased gradient estimates. In the context of solving problem (
1
), this is to require

\displaystyle\mathbb{E}[\nabla f^{v_{n}}(\boldsymbol{\theta}_{n-1})|\mathcal{F}_{n-1}]=\nabla f(\boldsymbol{\theta}_{n-1})

(35)

where
\mathcal{F}_{n}
is the filtration of information up to time
n
.
However, in the dependent data setting (
35
) does not hold which complicates the analysis significantly. Previous works (e.g
(
Sun et al. 2018
;
Bhandari et al. 2018
;
Nagaraj et al. 2020
;
Lyu et al. 2020
;
Lyu et al. 2022
;
Lyu 2023
;
Alacaoglu & Lyu 2023
)
) use a ”conditioning on the distant past” argument. Specifically, for SGD, one assumes that
(v_{n})
is a Markov chain on state space
\mathcal{V}
which mixes exponentially fast to its stationary distribution
\pi
with parameter
\lambda
. One then considers the quantity

\displaystyle\mathbb{E}[\nabla f^{v_{n}}(\boldsymbol{\theta}_{n-a_{n}})|\mathcal{F}_{n-a_{n}}]

(36)

where
a_{n}
is a slowly growing sequence satisfying
\sum_{n\geq 1}\lambda^{a_{n}}<\infty
.
By further assuming either uniformly bounded gradients as in
(
Sun et al. 2018
)
or that the conditional expectations
\mathbb{E}[\lVert\nabla f^{v_{n+1}}(\boldsymbol{\theta})\rVert|\mathcal{F}_{n}]
are uniformly bounded as in
(
Alacaoglu & Lyu 2023
)
, one can show that

\displaystyle\left\lVert\nabla f(\boldsymbol{\theta}_{n-a_{n}})-\mathbb{E}[\nabla f^{v_{n}}(\boldsymbol{\theta}_{n-a_{n}})|\mathcal{F}_{n-a_{n}}]\right\rVert=O(\lambda^{a_{n}}).

(37)

Using Lipschitz continuity of gradients, it is then established that

\displaystyle\lVert\nabla f(\boldsymbol{\theta}_{n})-\mathbb{E}[\nabla f^{v_{n}}(\boldsymbol{\theta}_{n})|\mathcal{F}_{n-a_{n}}]\rVert=O(\lambda^{a_{n}})+O(\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-a_{n}}\rVert),

(38)

allowing one to control the bias in the stochastic gradient estimate. Conventional analysis may then be used to prove

\displaystyle\sum_{n=1}^{\infty}\gamma_{n}\mathbb{E}\left[\langle\nabla f(\boldsymbol{\theta}_{n}),\nabla f^{v_{n}}(\boldsymbol{\theta}_{n})\rangle\right]<\infty,

(39)

where
\gamma_{n}
denotes the stepsize at iteration
n
. Combining this with (
38
), it can finally be deduced that

\displaystyle\sum_{n=1}^{\infty}\gamma_{n}\mathbb{E}[\lVert\nabla f(\boldsymbol{\theta}_{n})\rVert^{2}]<\infty

(40)

for an appropriate stepsize
\gamma_{n}
which gives the desired convergence rate.

This technique was further developed to analyze convergence rates of
stochastic majorization minimization
(SMM)
(
Mairal 2013
)
algorithms under Markovian sampling in
(
Lyu 2023
)
. In the context of problem (
1
), SMM proceeds by minimizing a recursively defined majorizing surrogate of the empirical loss function. The algorithm is stated concisely as follows:

\displaystyle(\textbf{SMM}):\begin{cases}&\text{Sample }v_{n}\text{ from the conditional distribution }\pi(\cdot|\mathcal{F}_{n-1})\\
&g_{n}\leftarrow\text{Strongly convex majorizing surrogate of $f^{v_{n}}$}\\
&\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\left(\bar{g}_{n}(\boldsymbol{\theta}):=(1-w_{n})\bar{g}_{n-1}(\boldsymbol{\theta})+w_{n}g_{n}(\boldsymbol{\theta})\right)\end{cases}

(41)

where
(w_{n})_{n\geq 1}
is a non-increasing sequence of weights. A crucial step in the analysis of SMM is to show that

\displaystyle\sum_{n=1}^{\infty}w_{n}\mathbb{E}[|\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{f}_{n}(\boldsymbol{\theta}_{n})|]<\infty

(42)

where
\bar{f}_{n}
is the empirical loss function satisfying the recursion
\bar{f}_{n}(\boldsymbol{\theta}):=(1-w_{n})\bar{f}_{n-1}(\boldsymbol{\theta})+w_{n}f^{v_{n}}(\boldsymbol{\theta})
. To do so, the problem is reduced to showing that

\displaystyle\mathbb{E}\left[\mathbb{E}[f^{v_{n}}(\boldsymbol{\theta}_{n-a_{n}})-\bar{f}_{n}(\boldsymbol{\theta}_{n-a_{n}})|\mathcal{F}_{n-a_{n}}]^{+}\right]=O(w_{n-a_{n}})+O(\lambda^{a_{n}})

(43)

(see Proposition 8.1 in
(
Lyu 2023
)
) which is similar to (
37
). By additionally assuming Lipschitz continuity of the individual loss functions
f^{v}
, it is then shown that

\displaystyle\mathbb{E}\left[\mathbb{E}[f^{v_{n}}(\boldsymbol{\theta}_{n})-\bar{f}_{n}(\boldsymbol{\theta}_{n})|\mathcal{F}_{n-a_{n}}]\right]=O(w_{n-a_{n}})+O(\lambda^{a_{n}})+O(\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-a_{n}}\rVert)

(44)

which may be compared with (
38
). Finally, (
42
) is proved by showing

\displaystyle\sum_{n=1}^{\infty}w_{n}\mathbb{E}[|\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{f}_{n}(\boldsymbol{\theta}_{n})|]\leq\bar{g}_{1}(\boldsymbol{\theta}_{1})+\sum_{n=1}^{\infty}w_{n}\mathbb{E}[f^{v_{n}}(\boldsymbol{\theta}_{n})-\bar{f}_{n}(\boldsymbol{\theta}_{n})]

(45)

and using the bound (
44
) to conclude that the latter sum is finite.

MISO and its extensions proposed in this paper are similar to SMM in their use of the majorization-minimization principle, but contain a few key differences. Put shortly, the original implementation of MISO is

\displaystyle\textbf{(MISO)}:\begin{cases}\text{Sample }v_{n}\text{ from the conditional distribution }\pi(\cdot|\mathcal{F}_{n-1})\\
g_{n}^{v_{n}}\leftarrow\text{Convex surrogate of $f^{v_{n}}$ at $\boldsymbol{\theta}_{n-1}$; $g_{n}^{v}=g_{n-1}^{v}$ for $v\neq v_{n}$}\\
\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\left(\bar{g}_{n}(\boldsymbol{\theta}):=\sum_{v\in\mathcal{V}}g_{n}^{v}\pi(v)\right)\end{cases}

(46)

In contrast with SMM, each surrogate defining
\bar{g}_{n}
is given a constant weight. Consequently, the additional control provided by the decreasing weights
(w_{n})
in SMM is not present, which makes the adaptation of the techniques used in the analysis of SMM non-trivial.

A key step in the original analysis of MISO given in
(
Mairal 2015
)
is to show

\displaystyle\sum_{n=1}^{\infty}\mathbb{E}[\bar{h}_{n}(\boldsymbol{\theta}_{n})]<\infty.

(47)

This is similar to (
42
) and shows that the averaged surrogate is an asymptotically accurate approximation of the true objective at all
\boldsymbol{\theta}_{n}
s. To prove this, one needs to relate the averaged error
\bar{h}_{n}(\boldsymbol{\theta}_{n})
to another quantity proven to be summable through other means. This is, in abstract, the role that mixing rate analysis plays for SGD and SMM. Using techniques from
(
Mairal 2015
)
one can prove

\displaystyle\sum_{n=1}^{\infty}\mathbb{E}[h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})]<\infty.

(48)

If the
(v_{n})
are drawn i.i.d from
\pi
, or more generally if the probability of transitioning between any two vertices is uniformly bounded below by a positive quantity, then
h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})
is a conditionally unbiased estimate of
\bar{h}_{n}(\boldsymbol{\theta}_{n})
up to a constant. Then (
47
) follows by conditioning on the most recent information
\mathcal{F}_{n}
.

To adapt the analysis to a more general setting, one may attempt to use Markov chain mixing to show

\displaystyle|\bar{h}_{n}(\boldsymbol{\theta}_{n-a_{n}})-\mathbb{E}[h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n-a_{n}})|\mathcal{F}_{n-a_{n}}]|=O(\lambda^{a_{n}})

(49)

similar to (
37
) and (
43
). However, an additional complication arises because the function
h_{n}^{v_{n+1}}
conditional on
\mathcal{F}_{n-a_{n}}
depends on both the history of data samples
v_{k}

and
the estimated parameters
\boldsymbol{\theta}_{k}
for
n-a_{n}\leq k\leq n
. In contrast,
f^{v_{n}}
for SGD (in (
37
)) depends only on the last data sample
v_{n}
and
\bar{f}_{n}
for SMM (in (
43
)) depends only on the histrory of data samples
v_{n-a_{n}},\dots,v_{n}
.
So, one cannot use the Markov property to isolate the randomness in
h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n-a_{n}})
due to the Markov chain transition over the interval
[n-a_{n},n+1]
. To alleviate this problem, one may attempt to control the difference

\displaystyle|h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n-a_{n}})-h_{n-a_{n}}^{v_{n+1}}(\boldsymbol{\theta}_{n-a_{n}})|

(50)

but doing so is not straightforward without access to something resembling the weights
(w_{n})
in SMM.

Appendix C
Preliminary Lemmas

In this section we state and prove some preliminary lemmas which will be used to prove in the proofs of both Theorem
3.8
and
3.9
.

We first introduce some additional notation. Throughout this section as well as the remainder of the paper we let

\displaystyle t_{\text{cov}}:=\sup_{n\geq 1}\left\lVert\mathbb{E}\left[\max_{v\in\mathcal{V}}\tau_{n,v}\Big|\mathcal{F}_{n}\right]\right\rVert_{\infty}.

(51)

We recall that the
L_{\infty}
norm here is taken for the conditional expectation viewed as a random variable. This quantity is a generalization of the worst case expected cover time from Markov chain theory
(
Levin & Peres 2017
)
and will be important in the analysis of Algorithm
1
with dynamic proximal regularization.

Our first result, Proposition
C.1
, states that under Assumption
3.1
the return times have finite moments of all orders and gives an upper-bound on
t_{\text{cov}}
in terms of
t_{\text{hit}}
. The first item will is used in Section
E
to prove asymptotic results while the second is used in the proof of iteration complexity for Case
3.6
.

Proposition C.1

(Recurrence implies finite exponential moments of return time)
.

Let Assumption
3.1
hold and let
t_{\text{hit}}
and
t_{\text{cov}}
be as in (
8
) and (
51
) respectively.

(i)

There exists
s_{0}>0
so that for all
0<s<s_{0}
there is a constant
C_{s}>0
with

\displaystyle\max_{v\in\mathcal{V}}\,\sup_{n\geq 1}\,\,\mathbb{E}\left[e^{s\tau_{n,v}}\Big|\mathcal{F}_{n}\right]\leq C_{s}<\infty.

(52)

Consequently, for each
p\geq 1
,
\max_{v\in\mathcal{V}}\sup_{n\geq 1}\mathbb{E}[\tau_{n,v}^{p}|\mathcal{F}_{n}]\leq C<\infty
for some
C>0
.

(ii)

We have the following bound on
t_{\text{cov}}
:

\displaystyle t_{\text{cov}}\leq(2t_{\text{hit}}+1)\log_{2}(4|\mathcal{V}|).

(53)

Proof.

Let
m
be the smallest integer satisfying
m\geq 2t_{\text{hit}}
. For any
n\geq 1
and
v\in\mathcal{V}
notice that if
\tau_{n,v}\geq km
then we must have
\tau_{n+jm,v}\geq m
for each
0\leq j\leq k-1
. Then

\displaystyle\mathbb{P}(\tau_{n,v}\geq km|\mathcal{F}_{n})\leq\mathbb{P}\left(\bigcap_{j=0}^{k-1}\{\tau_{n+jm,v}\geq m\}\Big|\mathcal{F}_{n}\right)=\mathbb{E}\left[\prod_{j=0}^{k-1}\mathds{1}(\tau_{n+jm,v}\geq m)\Big|\mathcal{F}_{n}\right].

(54)

We have

\displaystyle\mathbb{E}\left[\prod_{j=0}^{k-1}\mathds{1}(\tau_{n+jm,v}\geq m)\Big|\mathcal{F}_{n}\right]=\mathbb{E}\left[\mathbb{E}\big[\mathds{1}(\tau_{n+(k-1)m,v}\geq m)|\mathcal{F}_{n+(k-1)m}\big]\prod_{j=0}^{k-2}\mathds{1}(\tau_{n+jm,v}\geq m)\Big|\mathcal{F}_{n}\right]

(55)

where we have used that
\{\tau_{n+jm,v}\geq m\}
is measurable with respect to
\mathcal{F}_{n+(k-1)m}
for each
j\leq k-2
. By Markov’s inequality and Assumption
3.1

\displaystyle\mathbb{E}\big[\mathds{1}(\tau_{n+(k-1)m,v}\geq m)|\mathcal{F}_{n+(k-1)m}\big]=\mathbb{P}\left(\tau_{n+(k-1)m,v}\geq m|\mathcal{F}_{n+(k-1)m}\right)\leq\frac{t_{\text{hit}}}{m}.

(56)

So

\displaystyle\mathbb{E}\left[\prod_{j=0}^{k-1}\mathds{1}(\tau_{n+jm,v}\geq m)\Big|\mathcal{F}_{n}\right]\leq\frac{t_{\text{hit}}}{m}\mathbb{E}\left[\prod_{j=0}^{k-2}\mathds{1}(\tau_{n+jm,v}\geq m)\Big|\mathcal{F}_{n}\right].

(57)

Proceeding by induction it follows that

\displaystyle\mathbb{P}(\tau_{n,v}\geq km|\mathcal{F}_{n})\leq\left(\frac{t_{\text{hit}}}{m}\right)^{k}\leq 2^{-k}

(58)

with the second inequality using our choice of
m
. Now,

\displaystyle\mathbb{E}\left[e^{s\tau_{n,v}}|\mathcal{F}_{n}\right]=\sum_{\ell=1}^{\infty}e^{s\ell}\mathbb{P}(\tau_{n,v}=\ell|\mathcal{F}_{n})\leq\sum_{k=0}^{\infty}e^{s(k+1)m}\mathbb{P}(\tau_{n,v}\geq km|\mathcal{F}_{n})\leq\sum_{k=0}^{\infty}e^{s(k+1)m}2^{-k}.

(59)

The latter sum is finite if
s<\frac{\log 2}{2m}
and does not depend on
n
or
v
which shows
(i)
.

With
n
still fixed let
\tau_{\text{cov}}=\max_{v\in\mathcal{V}}\tau_{n,v}
. We have

\displaystyle\mathbb{E}[\tau_{\text{cov}}|\mathcal{F}_{n}]=\sum_{\ell=1}^{\infty}\mathbb{P}(\tau_{\text{cov}}\geq\ell|\mathcal{F}_{n})\leq\sum_{k=0}^{\infty}m\mathbb{P}(\tau_{\text{cov}}\geq km|\mathcal{F}_{n})\leq(2t_{\text{hit}}+1)\sum_{k=0}^{\infty}\mathbb{P}(\tau_{\text{cov}}\geq km|\mathcal{F}_{n})

(60)

since
\mathbb{P}(\tau_{\text{cov}}\geq\ell|\mathcal{F}_{n})
is a decreasing function of
\ell
and
m\leq 2t_{\text{hit}}+1
. By a union bound

\displaystyle\mathbb{P}(\tau_{\text{cov}}\geq km|\mathcal{F}_{n})\leq 1\wedge\sum_{v\in\mathcal{V}}\mathbb{P}(\tau_{n,v}\geq km|\mathcal{F}_{n})\leq 1\wedge|\mathcal{V}|2^{-k}.

(61)

Summing a geometric series we get

\displaystyle\sum_{k=0}^{\infty}\mathbb{P}(\tau_{\text{cov}}\geq km|\mathcal{F}_{n})\leq\log_{2}|\mathcal{V}|+|\mathcal{V}|\sum_{k>\log_{2}\mathcal{|V|}}2^{-k}\leq\log_{2}|\mathcal{V}|+2.

(62)

Combining (
60
) and (
62
) shows
(ii)
.
∎

The next proposition states some general properties of first order surrogate functions.

Proposition C.2

(Properties of Surrogates)
.

Fix
\bar{\boldsymbol{\theta}}\in\boldsymbol{\Theta}
and
f:\boldsymbol{\Theta}\to\mathbb{R}
. Let
g\in\mathcal{S}_{L}(f,\bar{\boldsymbol{\theta}})
and let
\boldsymbol{\theta}^{\prime}
be a minimizer of
g
over
\boldsymbol{\Theta}
. Then for all
\boldsymbol{\theta}\in\boldsymbol{\Theta}

\displaystyle|h(\boldsymbol{\theta})|\leq\frac{L}{2}\lVert\boldsymbol{\theta}-\bar{\boldsymbol{\theta}}\rVert^{2}

(63)

Proof.

This follows from using the classical upperbound for
L
-smooth functions

\displaystyle h(\boldsymbol{\theta})\leq h(\bar{\boldsymbol{\theta}})+\langle\nabla h(\bar{\boldsymbol{\theta}}),\boldsymbol{\theta}-\bar{\boldsymbol{\theta}}\rangle+\frac{L}{2}\lVert\boldsymbol{\theta}-\bar{\boldsymbol{\theta}}\rVert^{2}

(64)

(see Lemma
F.1
) and noting that
h(\bar{\boldsymbol{\theta}})
and
\nabla h(\bar{\boldsymbol{\theta}})
are both equal to zero according to Definition
2.1
.
∎

Next, we show that the surrogate objective value
\bar{g}_{n}(\boldsymbol{\theta}_{n})
evaluated at
\boldsymbol{\theta}_{n}
is non-increasing.

Lemma C.3

(Surrogate Monotonicity)
.

Let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of either Algorithm
1
or
2
. Then
\bar{g}_{n}(\boldsymbol{\theta}_{n-1})\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})
for all
n\geq 1
. Moreover, the sequence
(\bar{g}_{n}(\boldsymbol{\theta}_{n}))_{n\geq 0}
is non-increasing. As a consequence, by Assumption
3.2
and Definition
2.1
,
(\bar{g}_{n}(\boldsymbol{\theta}_{n}))_{n\geq 0}
is bounded below with probability one and therefore
\lim_{n\to\infty}\bar{g}_{n}(\boldsymbol{\theta}_{n})
exists almost surely.

Proof.

Since
g_{n}^{v_{n}}\in\mathcal{S}_{L}(f^{v_{n}},\boldsymbol{\theta}_{n-1})
, Definition
2.1
implies that
g_{n}^{v_{n}}(\boldsymbol{\theta}_{n-1})=f^{v_{n}}(\boldsymbol{\theta}_{n-1})
. Then

\displaystyle\bar{g}_{n}(\boldsymbol{\theta}_{n-1})

\displaystyle=\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})+\Big[g_{n}^{v_{n}}(\boldsymbol{\theta}_{n-1})-g_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\Big]\pi(v_{n})

(65)

\displaystyle=\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})+\Big[f^{v_{n}}(\boldsymbol{\theta}_{n-1})-g_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\Big]\pi(v_{n})

(66)

\displaystyle\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})

(67)

where the last inequality used
g_{n-1}^{v_{n}}
is a majorizing surrogate of
f^{v_{n}}
.

Suppose now that
(\boldsymbol{\theta}_{n})_{n\geq 0}
is an output of Algorithm
1
. Then by definition of
\boldsymbol{\theta}_{n}
,

\displaystyle\bar{g}_{n}(\boldsymbol{\theta}_{n})

\displaystyle\leq\bar{g}_{n}(\boldsymbol{\theta}_{n})+\frac{\rho_{n}}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

\displaystyle\leq\bar{g}_{n}(\boldsymbol{\theta}_{n-1})+\frac{\rho_{n}}{2}\lVert\boldsymbol{\theta}_{n-1}-\boldsymbol{\theta}_{n-1}\rVert^{2}

\displaystyle=\bar{g}_{n}(\boldsymbol{\theta}_{n-1})

\displaystyle\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}).

If instead
(\boldsymbol{\theta}_{n})_{n\geq 1}
is an output of Algorithm
2
, then we can directly conclude
\bar{g}_{n}(\boldsymbol{\theta}_{n})\leq\bar{g}_{n}(\boldsymbol{\theta}_{n-1})
by definition of
\boldsymbol{\theta}_{n}
. The remainder of the proof is identical to the above.
∎

The next lemma establishes the summability of the sequence
h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})
. This was used in
(
Mairal 2015
)
to prove asymptotic convergence of MISO under i.i.d. sampling. We use it primarily in the analysis of Algorithm
2
.

Lemma C.4
.

Let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of either Algorithm
1
or
2
. Then almost surely

\displaystyle\sum_{n=1}^{\infty}h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})\leq\frac{1}{\pi_{\text{min}}}\Delta_{0}.

(68)

Proof.

By Definition
2.1
, for each
n
the quantity
h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})
is non-negative. Therefore, it suffices to show that the sequence of partial sums,
\sum_{n=1}^{N}h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})
is uniformly bounded.

Recall that

\displaystyle\bar{g}_{n+1}(\boldsymbol{\theta}_{n+1})\leq\bar{g}_{n+1}(\boldsymbol{\theta}_{n})

\displaystyle=\bar{g}_{n}(\boldsymbol{\theta}_{n})+(g_{n+1}^{v_{n+1}}(\boldsymbol{\theta}_{n})-g_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n}))\pi(v_{n+1})

(69)

\displaystyle=\bar{g}_{n}(\boldsymbol{\theta}_{n})+(f^{v_{n+1}}(\boldsymbol{\theta}_{n})-g_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n}))\pi(v_{n+1}).

(70)

We then have

\displaystyle\sum_{n=1}^{N}h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})

\displaystyle=\sum_{n=1}^{N}g_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})-f^{v_{n+1}}(\boldsymbol{\theta}_{n})

\displaystyle\leq\sum_{n=1}^{N}\frac{1}{\pi(v_{n+1})}\left(\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{g}_{n+1}(\boldsymbol{\theta}_{n+1})\right)

\displaystyle\leq\frac{1}{\pi_{\text{min}}}\sum_{n=1}^{N}\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{g}_{n+1}(\boldsymbol{\theta}_{n+1})

\displaystyle\leq\frac{1}{\pi_{\text{min}}}\Delta_{0}

which is what we needed to show.
∎

Proposition C.5
.

Suppose
(\boldsymbol{\theta}_{n})_{n\geq 0}
is an output of Algorithm
2
. The for all
n\geq 1
,
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
.

Proof.

This follows directly from the definition of
\boldsymbol{\theta}_{n}
in Algorithm
2
.
∎

Lemma
C.6
establishes the iterate stability. These results are crucially used to control the surrogate error gradient
\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert
in Lemma
D.1
as well as in the asymptotic analysis of RMISO in Section
E
.

Lemma C.6

(Finite variation of iterate differences)
.

The following hold almost surely:

(i)

For Case
3.7
,

\displaystyle\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\sum_{n=1}^{\infty}r_{n}^{2}<\infty.

(71)

(ii)

In either of the Cases
3.5
or
3.6
,

\displaystyle\sum_{n=1}^{\infty}\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\Delta_{0}<\infty.

(72)

Proof.

The proof of
(i)
can be deduced from Proposition
C.5
and Assumption
3.4
.

Now assume either of the Cases
3.5
or
3.6
. Define
G_{n}(\boldsymbol{\theta})=\bar{g}_{n}(\boldsymbol{\theta})+\frac{\rho_{n}}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert
. Then
G_{n}
is
\rho_{n}+\mu
strongly convex. Since
\theta_{n}
is a minimizer of
G_{n}
over
\boldsymbol{\Theta}
we get

\displaystyle G_{n}(\boldsymbol{\theta}_{n})+\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq G_{n}(\boldsymbol{\theta}_{n-1})=\bar{g}_{n}(\boldsymbol{\theta}_{n-1})\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})

(73)

where the last inequality is due to Lemma
C.3
.
So

\displaystyle\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-G_{n}(\boldsymbol{\theta}_{n})\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n}).

(74)

Hence,

\displaystyle\sum_{n=1}^{N}\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\sum_{n=1}^{N}\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})

\displaystyle=\bar{g}_{0}(\boldsymbol{\theta}_{0})-\bar{g}_{N}(\boldsymbol{\theta}_{N})\leq\Delta_{0}.

(75)

Letting
N\to\infty
shows that

\displaystyle\sum_{n=1}^{\infty}\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\Delta_{0}

(76)

as desired. This shows
(ii)
.
∎

The remaining results in this section concern Algorithm
2
and are used both in the convergence rate analysis in Section
D
as well as the asymptotic analsyis of Section
E
. Recall that in this case we are assuming that
\nabla f^{v}
is
L
-Lipschitz continuous for each
v\in V
. Proposition
C.7
states that this assumption implies
\nabla\bar{g}_{n}
is differentiable and
2L
Lipschitz for each
n
.

Proposition C.7
.

Let
\{\boldsymbol{\theta}_{v}\}_{v\in\mathcal{V}}
be a collection of
|\mathcal{V}|
points in
\boldsymbol{\Theta}
. Suppose that Assumption
3.3
holds and that
g_{n}^{v}\in\mathcal{S}_{L}(f^{v},\boldsymbol{\theta}_{v})
for each
v
. Then

(i)

The gradient of the objective function
\nabla f=\sum_{v\in\mathcal{V}}\nabla f^{v}\pi(v)
is
L
-Lipschitz over
\boldsymbol{\Theta}
.

(ii)

For each
v
,
\nabla g_{n}^{v}
is
2L
-Lipchitz over
\boldsymbol{\Theta}
. In addition,
\nabla\bar{g}_{n}
is
2L
-Lipchitz.

Proof.

Since
\pi
is a probability distribution, (i) follows easily from the triangle inequality.

For (ii) note that
\nabla(g_{n}^{v}-f^{v})=\nabla h_{n}^{v}
is
L
-Lipshitz by Definition
2.1
. Then since
\nabla g_{n}^{v}=\nabla h_{n}^{v}+\nabla f^{v}
it follows from the triangle inequality that
\nabla g_{n}^{v}
is
2L
-Lipschitz. Then recalling that
\nabla\bar{g}_{n}=\sum_{v\in\mathcal{V}}\nabla g_{n}^{v}\pi(v)
another application of the triangle inequality shows that
\nabla\bar{g}_{n}
is
2L
-Lipschitz continuous.
∎

Proposition C.8
.

Assume Case
3.7
and let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of Algorithm
2
. Then

\displaystyle\sum_{n=1}^{N}|\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle|\leq\Delta_{0}+L\sum_{n=1}^{N}r_{n}^{2}

(77)

almost surley.

Proof.

Since
\nabla\bar{g}_{n}
is
2L
-Lipschitz continuous by Proposition
C.7
, by Lemma
F.1

\displaystyle|\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{g}_{n}(\boldsymbol{\theta}_{n-1})-\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle|\leq L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}.

(78)

Under Algorithm
2
we have
\bar{g}_{n}(\boldsymbol{\theta}_{n})\leq\bar{g}_{n}(\boldsymbol{\theta}_{n-1})
by the definition of
\boldsymbol{\theta}_{n}
and
\bar{g}_{n}(\boldsymbol{\theta}_{n-1})\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})
by Lemma
C.3
. These observations together with (
78
) imply

\displaystyle\left|\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle|\right|

\displaystyle\leq|\bar{g}_{n}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})|+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(79)

\displaystyle=\bar{g}_{n}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(80)

\displaystyle\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}.

(81)

We have

\displaystyle\sum_{n=1}^{N}\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})\leq\Delta_{0}

(82)

almost surely. Therefore

\displaystyle\sum_{n=1}^{N}\left|\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle\right|

\displaystyle\leq\sum_{n=1}^{N}\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(83)

\displaystyle\leq\Delta_{0}+L\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(84)

\displaystyle\leq\Delta_{0}+L\sum_{n=1}^{N}r_{n}^{2},

(85)

where the last line uses
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
.
∎

The next lemma is a key to establishing iteration complexity of Algorithm
2
. A similar lemma was used to analyze block majorization-minimization with diminishing radius in
(
Lyu & Li 2023
)
.

Lemma C.9

(Approximate first order optimality)
.

Let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of Algorithm
2
and let
b_{n}=\min\{1,r_{n}\}
. Then

\displaystyle b_{n}\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1}\langle-\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle\leq\langle-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle+r_{n}\lVert\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\rVert+2Lr_{n}^{2}.

(86)

Proof.

Fix
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}
. By definition of
\boldsymbol{\theta}_{n}
we have
\bar{g}_{n}(\boldsymbol{\theta}_{n})\leq\bar{g}_{n}(\boldsymbol{\theta})
. Subtracting
\bar{g}_{n}(\boldsymbol{\theta}_{n-1})
from both sides and using Proposition
C.7
and Lemma
F.1
,

\displaystyle\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle-L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

\displaystyle\leq\bar{g}_{n}(\boldsymbol{\theta}_{n})-\bar{g}_{n}(\boldsymbol{\theta}_{n-1})

(87)

\displaystyle\leq\bar{g}_{n}(\boldsymbol{\theta})-\bar{g}_{n}(\boldsymbol{\theta}_{n-1})

(88)

\displaystyle\leq\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle+L\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert^{2}.

(89)

Notice that

\displaystyle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1})

\displaystyle=\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})+\left[\nabla g_{n}^{v_{n}}(\boldsymbol{\theta}_{n-1})-\nabla g_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\right]\pi(v_{n})

(90)

\displaystyle=\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})+\left[\nabla f^{v_{n}}(\boldsymbol{\theta}_{n-1})-\nabla g_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1}\right]\pi(v_{n})

(91)

\displaystyle=\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\pi(v_{n}).

(92)

where the second line used
g_{n}^{v_{n}}\in\mathcal{S}_{L}(f^{v_{n}},\boldsymbol{\theta}_{n-1})
and item (ii) of Definition
2.1
, and the third line used the definition of
h_{n-1}^{v_{n}}
. Therefore, adding and subtracting
\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle
from the right hand side of (
89
) we get

\displaystyle\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle

\displaystyle\leq\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle-\pi(v_{n})\langle\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle+L\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(93)

\displaystyle\qquad\qquad\qquad\qquad+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(94)

\displaystyle\leq\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle+\lVert\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\rVert\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert+L\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(95)

\displaystyle\qquad\qquad\qquad\qquad+L\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}

(96)

\displaystyle\leq\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle+r_{n}\lVert\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\rVert+2Lr_{n}^{2}

(97)

where the last line used
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
and
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}\leq r_{n}
.
Since the above holds for all
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}
we obtain

\displaystyle\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rangle\leq\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}}\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle+r_{n}\lVert\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\rVert+2Lr_{n}^{2}.

(98)

Finally notice that since
b_{n}\leq 1
, the convexity of
\boldsymbol{\Theta}
implies that
\boldsymbol{\theta}_{n-1}+b_{n}(\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1})\in\boldsymbol{\Theta}
for any
\boldsymbol{\theta}\in\boldsymbol{\Theta}
. Thus, if there exists
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1
there is
\boldsymbol{\theta}^{\prime}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}
such that the direction of
\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}_{n-1}
agrees with that of
\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}
. Therefore

\displaystyle b_{n}\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1}\langle-\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle

\displaystyle=\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1}\langle-\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),b_{n}(\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1})\rangle

(99)

\displaystyle\leq\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq b_{n}}\langle-\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rangle.

(100)

combining this with (
98
) we complete the proof.
∎

Appendix D
Convergence Rate Analysis

In this subsection we prove the convergence rate guarantees of Theorem
3.8
.

D.1
The key lemma

First we state and prove Lemma
D.1
which lies at the heart of our analysis. It allows us to relate the surrogate error gradient
\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert
to the sequence of parameter differences
(\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2})
which is known to be summable by Lemma
C.6
. It is important to note that we only use the recurrence of data sampling Assumption
3.1
and the structure of the algorithm in the proof.

Lemma D.1

(Key lemma)
.

Let
(c_{n})_{n\geq 1}
be a non-increasing sequence of positive numbers. For any of the cases
3.5
-
3.7
and any
v\in V
,

\displaystyle\mathbb{E}\left[\sum_{n=1}^{N}c_{n}\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]\leq Lt_{\odot}\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\mathbb{E}\left[\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right)^{1/2}\right].

(101)

Proof.

Fix some
v\in V
. We recall that
k^{v}(n)
is the last time before
n
that the sampling process visited
v
and therefore the last time the surrogate
g_{n}^{v}
was updated. We then have
g_{n}^{v}\in\mathcal{S}_{L}(f^{v},\boldsymbol{\theta}_{k^{v}(n)-1})
so by the definition of first-order surrogates (Definition
2.1
)
\nabla h_{n}^{v}(\boldsymbol{\theta}_{k^{v}(n)-1})=0
. Combining this with the Lipschitz continuity of
\nabla h_{n}^{v}
we get

\displaystyle c_{n}\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})\rVert=c_{n}\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})-\nabla h_{n}^{v}(\boldsymbol{\theta}_{k^{v}(n)-1})\rVert\leq Lc_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert\leq L\sum_{i=k^{v}(n)}^{n}c_{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert.

(102)

Therefore by the triangle inequality,

\displaystyle c_{n}\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\leq c_{n}\sum_{v\in\mathcal{V}}\lVert\nabla h_{n}^{v}(\boldsymbol{\theta}_{n})\rVert\pi(v)\leq L\sum_{v\in\mathcal{V}}\left(\sum_{i=k^{v}(n)}^{n}c_{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert\right)\pi(v).

(103)

For an integer
n
, let
p^{v}(n)=\inf\{j>n:v_{j}=v\}
be the first time strictly after
n
that the sampling algorithm visits
v
. Denote
a\land b:=\min(a,b)
. We have

\displaystyle\sum_{n=1}^{N}\sum_{v\in\mathcal{V}}\left(\sum_{i=k^{v}(n)}^{n}c_{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert\right)\pi(v)

\displaystyle=\sum_{v\in\mathcal{V}}\left(\sum_{n=1}^{N}\sum_{i=k^{v}(n)}^{n}c_{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert\right)\pi(v)

(104)

\displaystyle=\sum_{v\in\mathcal{V}}\left(\sum_{i=1}^{N}\sum_{n=i}^{N\wedge p^{v}(i)-1}c_{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert\right)\pi(v)

(105)

\displaystyle\leq\sum_{v\in\mathcal{V}}\left(\sum_{i=1}^{N}c_{i}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert(p^{v}(i)-i)\right)\pi(v)

(106)

\displaystyle=\sum_{v\in\mathcal{V}}\left(\sum_{i=1}^{N}c_{i}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert\tau_{i,v}\right)\pi(v),

(107)

where the third line used that
(c_{n})
is non-increasing. So we get

\displaystyle\mathbb{E}\left[\sum_{n=1}^{N}c_{n}\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]

\displaystyle\leq L\mathbb{E}\left[\sum_{v\in\mathcal{V}}\left(\sum_{n=1}^{N}c_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\tau_{n,v}\right)\pi(v)\right]

(108)

\displaystyle=L\mathbb{E}\left[\sum_{n=1}^{N}c_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\left(\sum_{v\in V}\tau_{n,v}\pi(v)\right)\right]

(109)

\displaystyle=L\mathbb{E}\left[\sum_{n=1}^{N}c_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\left(\sum_{v\in\mathcal{V}}\mathbb{E}[\tau_{n,v}|\mathcal{F}_{n}]\pi(v)\right)\right]

(110)

\displaystyle\leq Lt_{\odot}\mathbb{E}\left[\sum_{n=1}^{N}c_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\right]

(111)

\displaystyle\leq Lt_{\odot}\left(\sum_{n=1}^{N}c_{n}^{2}\right)^{1/2}\mathbb{E}\left[\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right)^{1/2}\right]

(112)

with the second to last line using Assumption
3.1
and the last using Cauchy-Schwartz.
∎

D.2
The constant proximal regularization case
3.5

In this section we prove Theorem
A.1
for Case
3.5
.

Proof of Theorem
A.1
for case
3.5
.

We first use the linearity of the limit and the differentiability of the average surrogate error
\bar{h}_{n}
to get

\displaystyle\left|\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right|=\left|\langle\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rangle\right|\leq\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert

(113)

for all
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1
. It the follows from the triangle inequality, taking supremums, and then expectations that

\displaystyle\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]+\mathbb{E}\left[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right].

(114)

Our goal will be to control the sum of right hand side.

We first address the first term on the right hand side of (
114
). Recall that in this case we are using constant proximal regularization, so
\rho_{n}\equiv\rho
for some
\rho\geq 0
. For any
\boldsymbol{\theta}\in\boldsymbol{\Theta}

\displaystyle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})+\rho\langle\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1},\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rangle\geq 0

(115)

since
\boldsymbol{\theta}_{n}
is a minimizer of
\bar{g}_{n}(\boldsymbol{\theta})+\frac{\rho}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert^{2}
over
\boldsymbol{\Theta}
. Then

\displaystyle-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\leq\rho\langle\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1},\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rangle\leq\rho\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq\rho\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert

(116)

for any
\boldsymbol{\theta}\in\boldsymbol{\Theta}
with
\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1
. Therefore,

\displaystyle\mathbb{E}\left[\sum_{n=1}^{N}\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]

\displaystyle\leq\rho\mathbb{E}\left[\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\right]

(117)

\displaystyle\leq\rho\sqrt{N}\mathbb{E}\left[\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right)^{1/2}\right]

(118)

where we used the Cauchy-Schwartz inequality in the last line. By Lemma
C.6

\displaystyle\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right)^{1/2}\leq\sqrt{\frac{2\Delta_{0}}{\rho+\mu}}

(119)

almost surely. Thus,

\displaystyle\mathbb{E}\left[\sum_{n=1}^{N}\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\rho\sqrt{\frac{2N\Delta_{0}}{\rho+\mu}}.

(120)

We now turn to the second term on the right hand side of (
114
).
By Lemma
D.1
with
c_{n}=1
and Lemma
C.6

\displaystyle\mathbb{E}\left[\sum_{n=1}^{N}\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]\leq\sqrt{N}Lt_{\odot}\mathbb{E}\left[\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right)^{1/2}\right]\leq\sqrt{\frac{2N\Delta_{0}}{\rho+\mu}}Lt_{\odot}.

(121)

Now, summing both sides of (
114
) and using (
120
) and (
121
),

\displaystyle\sum_{n=1}^{N}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]

\displaystyle=\mathbb{E}\left[\sum_{n=1}^{N}\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]

(122)

\displaystyle\leq\sqrt{2N\Delta_{0}}\left(\frac{\rho}{\sqrt{\rho+\mu}}+\frac{Lt_{\odot}}{\sqrt{\rho+\mu}}\right).

(123)

This shows

\displaystyle\min_{1\leq n\leq N}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\frac{\sqrt{2\Delta_{0}}\left(\frac{\rho}{\sqrt{\rho+\mu}}+\frac{Lt_{\odot}}{\sqrt{\rho+\mu}}\right)}{\sqrt{N}}.

(124)

∎

D.3
The dynamic proximal regularization case
3.6

In this section we prove Theorem
A.1
for Case
3.6
. Recall the definition of
t_{\text{cov}}
from (
51
). Before proving the theorem we introduce a Lemma adapted from
(
Even 2023
)
Lemma A.5. This is used to bound the expected sum of the first
N
dynamic regularization parameters

in terms of

Lemma D.2
.

Let
a_{n}=\max_{v\in V}(n-k^{v}(n))
. Then

\displaystyle\sum_{n=1}^{N}\mathbb{E}[a_{n}]\leq Nt_{\text{cov}}.

(125)

Proof.

Since
a_{n}\leq n-1
we have

\displaystyle\sum_{n=1}^{N}\mathbb{E}[a_{n}]=\sum_{n=1}^{N}\sum_{i=1}^{n-1}\mathbb{P}(a_{n}\geq i).

(126)

Let
b_{n}=\max_{v\in\mathcal{V}}\tau_{n,v}
. We note that if
a_{n}\geq i
then there is
v\in V
with
v_{j}\neq v
for all
n-i<j\leq n
and so
\tau_{n-i,v}\geq i
. So we have the inclusion
\{a_{n}\geq i\}\subseteq\{b_{n-i}\geq i\}
. Therefore

\displaystyle\sum_{n=1}^{N}\sum_{i=1}^{n-1}\mathbb{P}(a_{n}\geq i)

\displaystyle=\sum_{i=1}^{N}\sum_{n=i+1}^{N}\mathbb{P}(a_{n}\geq i)

(127)

\displaystyle\leq\sum_{i=1}^{N}\sum_{n=i+1}^{N}\mathbb{P}(b_{n-i}\geq i)

(128)

\displaystyle=\sum_{s=1}^{N-1}\sum_{t=1}^{N-s}\mathbb{P}(b_{s}\geq t)

(129)

\displaystyle\leq\sum_{s=1}^{N-1}\sum_{t=1}^{\infty}\mathbb{P}(b_{s}\geq t)

(130)

\displaystyle\leq N\sup_{n\geq 1}\mathbb{E}[b_{n}].

(131)

We have

\displaystyle\mathbb{E}[b_{n}]=\mathbb{E}\left[\mathbb{E}\left[\max_{v\in\mathcal{V}}\tau_{n,v}\Big|\mathcal{F}_{n}\right]\right]\leq t_{\text{cov}}

(132)

so we are done.

Proof of Theorem
A.1
for Case
3.6
.

The proof in this case follows the same strategy as Case
3.5
, but is slightly more complicated due to the randomness of the dynamic proximal regularization parameter.

Define
\delta_{n}:=\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})
. By optimality of
\boldsymbol{\theta}_{n}
and Lemma
C.3
,

\displaystyle\bar{g}_{n}(\boldsymbol{\theta}_{n})+\frac{\rho_{n}}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})

(133)

so
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq\sqrt{2\rho_{n}^{-1}\delta_{n}}
. Using similar reasoning as in the proof for case

\displaystyle-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\leq\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq\sqrt{2\rho_{n}\delta_{n}}.

(134)

We have using Cauchy-Schwartz twice,

\displaystyle\sum_{n=1}^{N}\mathbb{E}[\sqrt{\rho_{n}\delta_{n}}]

\displaystyle\leq\sum_{n=1}^{N}(\mathbb{E}[\rho_{n}])^{1/2}(\mathbb{E}[\delta_{n}])^{1/2}

(135)

\displaystyle\leq\left(\sum_{n=1}^{N}\mathbb{E}[\rho_{n}]\right)^{1/2}\left(\sum_{n=1}^{N}\mathbb{E}[\delta_{n}]\right)^{1/2}

(136)

\displaystyle\leq\sqrt{N(\rho+t_{\text{cov}})\Delta_{0}}.

(137)

The last inequality here uses
\rho_{n}=\rho+\max_{v\in V}(n-k^{v}(n))
and Lemma
D.2
as well as
\sum_{n=1}^{N}\delta_{n}\leq\Delta_{0}
a.s. It follows that

\displaystyle\sum_{n=1}^{N}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\sqrt{2N(\rho+t_{\text{cov}})\Delta_{0}}.

To handle the gradient error

C.6
and
\rho_{n}\geq\rho
to conclude

\displaystyle\sum_{n=1}^{N}\frac{\rho+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\sum_{n=1}^{N}\frac{\rho_{n}+\mu}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\Delta_{0}

(139)

almost surely. It then follows from Lemma
D.1
that

\displaystyle\sum_{n=1}^{N}\mathbb{E}\left[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]\leq\sqrt{N}Lt_{\odot}\mathbb{E}\left[\left(\sum_{n=1}^{N}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\right)^{1/2}\right]\leq\sqrt{\frac{2N\Delta_{0}}{\rho}}Lt_{\odot}.

(140)

Finally, combining (
138
) and (
140
) we get

\displaystyle\sum_{n=1}^{N}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\sqrt{2N\Delta_{0}}\left(\sqrt{\rho+t_{\text{cov}}}+\frac{Lt_{\odot}}{\sqrt{\rho+\mu}}\right)

(141)

and so we deduce

\displaystyle\min_{1\leq n\leq N}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\frac{\sqrt{2\Delta_{0}}\left(\sqrt{\rho+t_{\text{cov}}}+\frac{Lt_{\odot}}{\sqrt{\rho+\mu}}\right)}{\sqrt{N}}.

(142)

We complete the proof by substituting the bound for

in Proposition
C.1
.

Appendix E
Asymptotic Analysis

We use this section to prove Theorem
3.9
. Recall that by Proposition
C.1
, there are constants
C_{1}
and
C_{2}
with
\sup_{n\geq 1}\mathbb{E}[\tau_{n,v}^{2}|\mathcal{F}_{n}]\leq C_{1}

\sup_{n\geq 1}\mathbb{E}[\tau_{n,v}^{4}|\mathcal{F}_{n}]\leq C_{2}
for each

. Accordingly, we let
\mu_{2}=\max_{v\in V}\sup_{n\geq 1}\left\lVert\mathbb{E}[\tau_{n,v}^{2}|\mathcal{F}_{n}]\right\rVert_{\infty}
and
\mu_{4}=\max_{v\in\mathcal{V}}\sup_{n\geq 1}\lVert\mathbb{E}[\tau_{n,v}^{4}|\mathcal{F}_{n}]\rVert_{\infty}
.

The first Lemma of this section states that the first and second moments of the dynamic regularization parameter
\rho_{n}
in Algorithm
1
are uniformly bounded. While
\rho_{n}
only appears in Algorithm
1
, the random variable
\max_{v\in V}(n-k^{v}(n))
is also present in the analysis of Algorithm

Lemma E.1
.

Assume
3.1
. Then there is a constant
C>0
such that

\displaystyle\sup_{n\geq 1}\,\,\mathbb{E}[\rho_{n}]+\sup_{n\geq 1}\mathbb{E}[\rho_{n}^{2}]\leq C.

(160)

Proof.

Fix
v\in\mathcal{V}
. For a positive integer
j
we have

\displaystyle\{n-k^{v}(n)\geq j\}=\{k^{v}(n)\leq n-j\}\subseteq\{\tau_{n-j,v}\geq j\}.

(161)

Therefore, we get

\displaystyle\mathbb{E}[(n-k^{v}(n))]

\displaystyle=\sum_{j=1}^{\infty}\mathbb{P}(n-k^{v}(n)\geq j)

(162)

\displaystyle\leq\sum_{j=1}^{\infty}\mathbb{P}(\tau_{n-j,v}\geq j)

(163)

\displaystyle\leq\sum_{j=1}^{\infty}\frac{\mathbb{E}[\tau_{n-j,v}^{2}]}{j^{2}}

(164)

\displaystyle\leq\mu_{2}\sum_{j=1}^{\infty}j^{-2}

(165)

since
\mathbb{E}[\tau_{n-j,v}^{2}]\leq\mu_{2}
. Finally,

\displaystyle\mathbb{E}[\rho_{n}]=\rho+\mathbb{E}\left[\max_{v\in\mathcal{V}}(n-k^{v}(n))\right]\leq\rho+\sum_{v\in V}\mathbb{E}[n-k^{v}(n)]\leq\rho+|\mathcal{V}|\mu_{2}\sum_{j=1}^{\infty}j^{-2}.

(166)

To bound the second moment we follow the same approach:

\displaystyle\mathbb{E}[(n-k^{v}(n))^{2}]

\displaystyle=\sum_{j=1}^{\infty}\mathbb{P}\left((n-k^{v}(n))^{2}\geq j\right)

(167)

\displaystyle\leq\sum_{j=1}^{\infty}\mathbb{P}(\tau_{n-j,v}^{2}\geq j)

(168)

\displaystyle\leq\sum_{j=1}^{\infty}\frac{\mathbb{E}[\tau_{n-j,v}^{4}]}{j^{2}}

(169)

\displaystyle\leq\mu_{4}\sum_{j=1}^{\infty}j^{-2}.

(170)

The proof is completed by mimicking the last line of the proof bounding the first moment.

∎

The dynamic proximal regularization case

Here we prove Theorem

(i)
. Our first lemma, Lemma

, is similar to
D.1
and key to showing that
\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\to 0
. The difference is that we must deal with
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert^{2}
instead of
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert
. In order to relate this to the sequence of one step iterate differences
(\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2})
we need to use the Cauchy-Schwartz inequality which introduces a dependence on

Lemma E.2
.

Let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of Algorithm
1
. Assume case
3.6
. Then

\displaystyle\sum_{n=1}^{\infty}\mathbb{E}[\bar{h}_{n}(\boldsymbol{\theta}_{n})]<\infty.

(171)

Proof.

Since
\bar{h}_{n}(\boldsymbol{\theta}_{n})=\sum_{v\in V}h_{n}^{v}(\boldsymbol{\theta}_{n})\pi(v)
and
\mathcal{V}
is finite, it is sufficient to show
\sum_{n=1}^{\infty}\mathbb{E}[h_{n}^{v}(\boldsymbol{\theta}_{n})]<\infty
for each
v\in V
. Before starting recall that by Lemma
C.6
, and
\rho_{n}\geq\rho>0

\displaystyle\sum_{n=1}^{\infty}\frac{\rho_{n}}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\Delta_{0}\quad\text{ and }\quad\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\leq\frac{2}{\rho}\Delta_{0}

(172)

almost surely. This implies

\displaystyle\mathbb{E}\left[\sum_{n=1}^{\infty}\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right]+\mathbb{E}\left[\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert^{2}\right]<\infty.

(173)

Fix
v\in V
. For each
n
we have
g_{n}^{v}\in\mathcal{S}_{L}(f^{v},\boldsymbol{\theta}_{k^{v}(n)-1})
. Then using Proposition
C.2
, the triangle inequality and Cauchy Schwartz

\displaystyle|h_{n}^{v}(\boldsymbol{\theta}_{n})|\leq\frac{L}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert^{2}\leq\frac{L}{2}(n-k^{v}(n)+1)\sum_{i=k^{v}(n)}^{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}.

(174)

Let
B_{n}=(n-k^{v}(n)+1)\sum_{i=k^{v}(n)}^{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}
. We claim that
\mathbb{E}\left[\sum_{n=1}^{\infty}B_{n}\right]<\infty
. As in Lemma
D.1
let
p^{v}(n)=\inf\{j>n:v_{j}=v\}
be the next time strictly after time
n
the sampling algorithm visits
v
. Exchanging the order of summation we have

\displaystyle\mathbb{E}\left[\sum_{n=1}^{\infty}(n-k^{v}(n)+1)\sum_{i=k^{v}(n)}^{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]

\displaystyle=\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{p^{v}(i)-1}(n-k^{v}(n)+1)\right]

(175)

\displaystyle=\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{\infty}(n-k^{v}(n)+1)\mathds{1}(p^{v}(i)>n)\right].

(176)

The equality
\{p^{v}(i)>n\}=\{\tau_{i,v}\geq n-i+1\}
holds as both are equal to the event
\{v_{j}\neq v:i<j\leq n+1\}
. Moreover,
k^{v}(n)=k^{v}(i)
on
\{p^{v}(i)>n\}
since there is no visit to
v
between times
i
and
n
. Therefore,

\displaystyle\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{\infty}(n-k^{v}(n)+1)\mathds{1}(p^{v}(i)>n)\right]

(177)

\displaystyle=\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathds{1}(\tau_{i,v}\geq n-i+1)\right]

(178)

\displaystyle=\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})\right]

(179)

where the last line used
\boldsymbol{\theta}_{i},\boldsymbol{\theta}_{i-1}
and
k^{v}(i)
are all measurable with respect to
\mathcal{F}_{i}
. We have

\displaystyle\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})

(180)

\displaystyle=\sum_{n=i}^{\infty}(n-i+1)\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})+(i-k^{v}(i))\sum_{n=i}^{\infty}\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})

(181)

\displaystyle=\mathbb{E}[\tau_{i,v}^{2}|\mathcal{F}_{i}]+(i-k^{v}(i))\mathbb{E}[\tau_{i,v}|\mathcal{F}_{i}]

(182)

\displaystyle\leq\mu_{2}+(i-k^{v}(i))t_{\text{hit}}.

(183)

Finally,

\displaystyle\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})\right]

(184)

\displaystyle\leq\mu_{2}\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]+t_{\text{hit}}\mathbb{E}\left[\sum_{i=1}^{\infty}(i-k^{v}(i))\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]

(185)

\displaystyle\leq\mu_{2}+\mathbb{E}\left[\sum_{i=1}^{\infty}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]+t_{\text{hit}}\mathbb{E}\left[\sum_{i=1}^{\infty}\rho_{i}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]<\infty.

(186)

This shows
\mathbb{E}\left[\sum_{n=1}^{\infty}B_{n}\right]<\infty
. The proof is completed by using Fubini’s Theorem and (
174
) to conclude

\displaystyle\sum_{n=1}^{\infty}\mathbb{E}[h_{n}^{v}(\boldsymbol{\theta}_{n})]=\mathbb{E}\left[\sum_{n=1}^{\infty}h_{n}^{v}(\boldsymbol{\theta}_{n})\right]\leq\frac{L}{2}\mathbb{E}\left[\sum_{n=1}^{\infty}B_{n}\right]<\infty.

(187)

This completes the proof.

Proof of Theorem
3.9

(i)
.

Starting as in the proofs of Theorem
3.8

\displaystyle\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]

\displaystyle\leq\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]+\mathbb{E}\left[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]

(188)

Using the same argument as in the proof of Theorem
3.8
for Case
3.6
,

\displaystyle\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]\leq\mathbb{E}[\rho_{n}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert]\leq\mathbb{E}[\sqrt{2\rho_{n}\delta_{n}}]

(190)

where
\delta_{n}=\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})-\bar{g}_{n}(\boldsymbol{\theta}_{n})
. By Cauchy-Schwartz and Lemma
E.1

\displaystyle\mathbb{E}[\sqrt{2\rho_{n}\delta_{n}}]\leq\sqrt{2\mathbb{E}[\rho_{n}]\mathbb{E}[\delta_{n}]}\leq C\sqrt{\mathbb{E}[\delta_{n}]}

(191)

for some
C>0
independent of
n
.
By Jensen’s inequality and Lemma
F.2

\displaystyle\mathbb{E}[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert]\leq\sqrt{\mathbb{E}[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert^{2}]}\leq\sqrt{2L\mathbb{E}[\bar{h}_{n}(\boldsymbol{\theta}_{n})]}

(192)

We have

\displaystyle\sum_{n=1}^{\infty}\mathbb{E}[\delta_{n}]=\sum_{n=1}^{\infty}\mathbb{E}[\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1})]-\mathbb{E}[\bar{g}_{n}(\boldsymbol{\theta}_{n})]\leq\Delta_{0}<\infty

(193)

so
\mathbb{E}[\delta_{n}]\to 0
as
n\to\infty
. Also,
\sqrt{\mathbb{E}[\bar{h}_{n}(\boldsymbol{\theta}_{n})]}\to 0
by Lemma
E.2
. Therefore

\displaystyle\mathop{\rm lim\,sup}\limits_{n\to\infty}\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]

\displaystyle\leq\mathop{\rm lim\,sup}\limits_{n\to\infty}\left(\mathbb{E}\left[\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right]+\mathbb{E}\left[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert\right]\right)

(194)

\displaystyle\leq\lim_{n\to\infty}\left(C\sqrt{\mathbb{E}[\delta_{n}]}+\sqrt{2L\mathbb{E}[\bar{h}_{n}(\boldsymbol{\theta}_{n})]}\right)=0.

(195)

We follow a similar approach to show that

\displaystyle\mathbb{E}\left[\left(\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right)^{2}\right]\to 0.

(196)

Notice that the sub-optimality measure

. Then from the inequality

\displaystyle\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\leq\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})+\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert

and Cauchy-Schwartz we get

\displaystyle\mathbb{E}\left[\left(\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla f(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right)^{2}\right]\leq 2\mathbb{E}\left[\left(\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rVert\leq 1}-\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n},\boldsymbol{\theta}-\boldsymbol{\theta}_{n})\right)^{2}\right]+2\mathbb{E}\left[\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert^{2}\right].

(200)

\displaystyle\leq C\sqrt{\mathbb{E}[\delta_{n}^{2}]}.

(201)

Since

. Using Lemmas

Remark E.3
.

The proof of Lemma
E.2
demonstrates one of the main difficulties in proving asymptotic convergence for constant proximal regularization. In particular, our techniques require us to show that

\displaystyle\mathbb{E}\left[\sum_{i=1}^{\infty}(i-k^{v}(i))\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]<\infty.

(202)

The term
i-k^{v}(i)
appears as the residual when we swap
n-k^{v}(i)+1
for
n-i+1
in order to show

\displaystyle\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathbb{P}(\tau_{i,v}\geq n-i+1|\mathcal{F}_{i})\leq\mu_{2}+(i-k^{v}(i))t_{\text{hit}}

To avoid this, an idea is to notice that
\tau_{i,v}\geq n-i+1
only if
\tau_{k^{v}(i),v}\geq n-k^{v}(i)+1
and instead compute

\displaystyle\sum_{n=i}^{\infty}(n-k^{v}(i)+1)\mathbb{P}(\tau_{k^{v}(i),v}\geq n-k^{v}(i)+1|\mathcal{F}_{k^{v}(i)}).

The problem here is that
k^{v}(i)
is
not
a stopping time so, among other things, the
\sigma
-algebra
\mathcal{F}_{k^{v}(i)}
may not be well defined. Intuitively,
i-k^{v}(i)
represents a gap in knowledge since we must wait until time
i
to know the last time
v
was visited.

The use of dynamic proximal regularization bakes (
202
) into the algorithm. Lemmas
E.1
and
C.6
suggests that it may be true with constant proximal regularization: if
(i-k^{v}(n))
and
\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}
were independent then

\displaystyle\mathbb{E}\left[\sum_{i=1}^{\infty}(i-k^{v}(i))\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}\right]

\displaystyle=\sum_{i=1}^{\infty}\mathbb{E}[i-k^{v}(i)]\mathbb{E}[\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}]

\displaystyle\leq C\sum_{i=1}^{\infty}\mathbb{E}[\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}]<\infty.

However,
k^{v}(i)
,
\boldsymbol{\theta}_{i}
, and
\boldsymbol{\theta}_{i-1}
are all determined by the behavior of the sampling process so we do not have this independence.

We will see in the next subsection that diminishing radius overcomes this issue by bounding the difference
\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}
by a deterministic quantity.

The diminishing radius case

3.9

(ii)

E.2
for the diminishing radius case. The remaining argument is similar to that used in
(
Lyu & Li 2023
)
and

Lemma E.4
.

Let
(\boldsymbol{\theta}_{n})_{n\geq 0}
be an output of Algorithm
2
. Assume Case
3.7
. Then almost surely

\displaystyle\sum_{n=1}^{\infty}\bar{h}_{n}(\boldsymbol{\theta}_{n})<\infty.

(203)

Proof.

The strategy here is nearly the same as in Lemma
E.2
except that we use
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
.

Again, it is sufficient to show
\sum_{n=1}^{\infty}h_{n}^{v}(\boldsymbol{\theta}_{n})<\infty
almost surely for each
v\in\mathcal{V}
. Fixing
v
we have
g_{n}^{v}\in\mathcal{S}_{L}(f^{v},\boldsymbol{\theta}_{k^{v}(n)-1})
. Then Proposition
C.2
, the triangle inequality, and Cauchy-Schwartz give us

\displaystyle|h_{n}^{v}(\boldsymbol{\theta}_{n})|\leq\frac{L}{2}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{k^{v}(n)-1}\rVert^{2}

\displaystyle\leq\frac{L}{2}(n-k^{v}(n)+1)\sum_{i=k^{v}(n)}^{n}\lVert\boldsymbol{\theta}_{i}-\boldsymbol{\theta}_{i-1}\rVert^{2}

with
r_{i}^{2}
in place of

to conclude

\displaystyle\mathbb{E}\left[\sum_{n=1}^{\infty}B_{n}\right]\leq\mu_{2}\sum_{i=1}^{\infty}r_{i}^{2}+t_{\text{hit}}\mathbb{E}\left[\sum_{i=1}^{\infty}\rho_{i}r_{i}^{2}\right].

Proposition E.5
.

Assume Case
3.7
. Suppose there exists a sequence
(n_{k})_{k\geq 1}
such that almost surely either

\displaystyle\sum_{k=1}^{\infty}\lVert\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}\rVert=\infty\quad\text{ or }\quad\mathop{\rm lim\,inf}\limits_{k\to\infty}\left|\left\langle\nabla\bar{g}_{n_{k}+1}(\boldsymbol{\theta}_{n_{k}}),\frac{\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}}{\lVert\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}\rVert}\right\rangle\right|=0.

Then there exists a further subsequence
(m_{k})_{k\geq 1}
of

exists almost surely and
\boldsymbol{\theta}_{\infty}
is a stationary point of
f
over
\boldsymbol{\Theta}
.

Proof.

By Proposition
C.8
,

\displaystyle\sum_{k=1}^{\infty}\lVert\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}\rVert\left|\left\langle\nabla\bar{g}_{n_{k}+1}(\boldsymbol{\theta}_{n_{k}}),\frac{\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}}{\lVert\boldsymbol{\theta}_{n_{k}+1}-\boldsymbol{\theta}_{n_{k}}\rVert}\right\rangle\right|<\infty\quad\text{ a.s. }

(m_{k})_{k\geq 1}

where

\boldsymbol{\theta}_{\infty}

f
over
\boldsymbol{\Theta}
, then we may find
\boldsymbol{\theta}^{\star}\in\boldsymbol{\Theta}

\varepsilon>0
so that

\displaystyle\langle\nabla f(\boldsymbol{\theta}_{\infty}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{\infty}\rangle\leq-\varepsilon<0.

(213)

On the other hand by the triangle inequality and Cauchy-Schwartz

\displaystyle|\langle\nabla\bar{g}_{m_{k}}(\boldsymbol{\theta}_{m_{k}}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{m_{k}}\rangle-\langle\nabla f(\boldsymbol{\theta}_{\infty}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{\infty}\rangle|

(215)

\displaystyle\leq\lVert\nabla\bar{h}_{m_{k}}(\boldsymbol{\theta}_{m_{k}})\rVert\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{m_{k}}\rVert+\lVert\nabla f(\boldsymbol{\theta}_{m_{k}})-\nabla f(\boldsymbol{\theta}_{\infty})\rVert\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{\infty}\rVert+\lVert\nabla f(\boldsymbol{\theta}_{\infty})\rVert\lVert\boldsymbol{\theta}_{\infty}-\boldsymbol{\theta}_{m_{k}}\rVert

(\boldsymbol{\theta}_{m_{k}})_{k\geq 1}
converges,
\sup_{k}\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{m_{k}}\rVert\leq M
for some
M<\infty
. Furthermore,

\displaystyle\sum_{n=1}^{\infty}\lVert\nabla\bar{h}_{n}(\boldsymbol{\theta}_{n})\rVert^{2}\leq 2L\sum_{n=1}^{\infty}\bar{h}_{n}(\boldsymbol{\theta}_{n})<\infty

(217)

by Lemmas
E.4
and
F.2
so

almost surely as

sufficiently large so that

\displaystyle\langle\nabla\bar{g}_{m_{k}}(\boldsymbol{\theta}_{m_{k}}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{m_{k}}\rangle\leq-\frac{\varepsilon}{2}

(218)

for
k\geq K
.

\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert\leq r_{n}
and

. Applying Lemma
C.9
we get

\frac{\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert}{b_{n}}\left\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n-1}),\frac{\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}}{\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert}\right\rangle\\
\leq\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\rVert\leq 1}\left\langle\nabla\bar{g}_{n-1}(\boldsymbol{\theta}_{n-1}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n-1}\right\rangle+\lVert\nabla h_{n-1}^{v_{n}}(\boldsymbol{\theta}_{n-1})\rVert+Lr_{n}.

(219)

It then follows that for sufficiently large

\displaystyle\frac{\lVert\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}\rVert}{b_{m_{k}+1}}\left\langle\nabla\bar{g}_{m_{k}+1}(\boldsymbol{\theta}_{m_{k}}),\frac{\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}}{\lVert\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}\rVert}\right\rangle

(220)

\displaystyle\leq\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{m_{k}}\rVert\leq 1}\left\langle\nabla\bar{g}_{m_{k}}(\boldsymbol{\theta}_{m_{k}}),\boldsymbol{\theta}-\boldsymbol{\theta}_{m_{k}}\right\rangle+\lVert\nabla h_{m_{k}}^{v_{m_{k}+1}}(\boldsymbol{\theta}_{m_{k}})\rVert+Lr_{m_{k}}

(221)

\displaystyle\leq\left\langle\nabla\bar{g}_{m_{k}}(\boldsymbol{\theta}_{m_{k}}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{m_{k}}\right\rangle+\lVert\nabla h_{m_{k}}^{v_{m_{k}+1}}(\boldsymbol{\theta}_{m_{k}})\rVert+r_{m_{k}}

(222)

\displaystyle\leq-\frac{\varepsilon}{2}+\lVert\nabla h_{m_{k}}^{v_{m_{k}+1}}(\boldsymbol{\theta}_{m_{k}}\rVert+r_{m_{k}}

(223)

Recall Lemma
C.4
which shows

\displaystyle\sum_{n=1}^{\infty}h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})<\infty

(224)

almost surely.
Therefore, since
h_{n}^{v_{n}}
is non-negative,
\sqrt{h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})}\to 0
almost surely as
n\to\infty
. Moreover, by Lemma
F.2
,
\lVert\nabla h_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})\rVert\leq\sqrt{2Lh_{n}^{v_{n+1}}(\boldsymbol{\theta}_{n})}
. So letting
k\to\infty
shows

\displaystyle\mathop{\rm lim\,sup}\limits_{k\to\infty}\frac{\lVert\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}\rVert}{b_{m_{k}+1}}\left\langle\nabla\bar{g}_{m_{k}}(\boldsymbol{\theta}_{m_{k}+1}),\frac{\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}}{\lVert\boldsymbol{\theta}_{m_{k}+1}-\boldsymbol{\theta}_{m_{k}}\rVert}\right\rangle\leq-\frac{\varepsilon}{2}

(225)

contradicting (
212
).
∎

Recall that under Algorithm
2
, the one step parameter difference
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert
is at most
r_{n}
. For each
n\geq 1
we say that
\boldsymbol{\theta}_{n}
is a
long point
if
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert<r_{n}
and a
short point
if
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert=r_{n}
. The next proposition shows that if
\boldsymbol{\theta}_{n}
is a long point, then
\boldsymbol{\theta}_{n}
is obtained by directly minimizing
\bar{g}_{n}
over the full parameter space
\boldsymbol{\Theta}
. It is here the we crucially use the convexity of
\bar{g}_{n}
from Definition
2.1
.

Proposition E.6
.

For
n\geq 1
, suppose that
\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}\cap B_{r_{n}}(\boldsymbol{\theta}_{n-1})}\bar{g}_{n}(\boldsymbol{\theta})
and that
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert<r_{n}
. Then
\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\bar{g}_{n}(\boldsymbol{\theta})
.

Proof.

By Definition
2.1
,
\bar{g}_{n}
is convex. Thus, it suffices to verify the first order stationarity condition

\displaystyle\inf_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n}\rangle\geq 0

(226)

to conclude
\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\bar{g}_{n}(\boldsymbol{\theta})
. To this end, assume the conclusion is false. Then there is
\boldsymbol{\theta}^{\star}\in\boldsymbol{\Theta}
with
\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n}\rangle<0
. Moreover, as
\boldsymbol{\theta}_{n}
is obtained by minimizing
\bar{g}_{n}
over
\boldsymbol{\Theta}\cap B_{r_{n}}(\boldsymbol{\theta}_{n-1})
we must have
\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n-1}\rVert>r_{n}
. As we are assuming
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert<r_{n}
, there is
\alpha\in(0,1)
so that
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert=\alpha r_{n}
. Notice that

\displaystyle\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n}\rVert\geq\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n-1}\rVert-\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert>(1-\alpha)r_{n}.

(227)

Hence if we set
a=\frac{(1-\alpha)r_{n}}{\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n}\rVert}
then
a\in(0,1)
. So, the convexity of
\boldsymbol{\Theta}
implies that
\tilde{\boldsymbol{\theta}}:=a(\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n})+\boldsymbol{\theta}_{n}\in\boldsymbol{\Theta}
. Furthermore,

\displaystyle\lVert\tilde{\boldsymbol{\theta}}-\boldsymbol{\theta}_{n-1}\rVert\leq a\lVert\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n}\rVert+\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert=(1-\alpha)r_{n}+\alpha r_{n}=r_{n}

(228)

and

\displaystyle\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n}),\tilde{\boldsymbol{\theta}}-\boldsymbol{\theta}_{n}\rangle=a\langle\nabla\bar{g}_{n}(\boldsymbol{\theta}_{n}),\boldsymbol{\theta}^{\star}-\boldsymbol{\theta}_{n}\rangle<0.

(229)

This contradicts
\boldsymbol{\theta}_{n}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}\cap B_{r_{n}}(\boldsymbol{\theta}_{n-1})}\bar{g}_{n}(\boldsymbol{\theta})
and completes the proof.
∎

Proposition E.7
.

Assume the Case
3.7
. If
(\boldsymbol{\theta}_{n_{k}})_{k\geq 1}
is a sequence consisting of long points such that
\boldsymbol{\theta}_{\infty}:=\lim_{k\to\infty}\boldsymbol{\theta}_{n_{k}}
exist almost surely, then
\boldsymbol{\theta}_{\infty}
is a stationary point of
f
over
\boldsymbol{\Theta}
.

Proof.

By the assumption that
\boldsymbol{\theta}_{n_{k}}
is a long point and Proposition
E.6
we have
\boldsymbol{\theta}_{n_{k}}\in\argmin_{\boldsymbol{\theta}\in\boldsymbol{\Theta}}\bar{g}_{n_{k}}(\boldsymbol{\theta})
. Therefore, for any
\boldsymbol{\theta}\in\boldsymbol{\Theta}
,

\displaystyle\langle\nabla\bar{g}_{n_{k}}(\boldsymbol{\theta}_{n_{k}}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n_{k}}\rangle\geq 0.

(230)

We then notice that

\displaystyle\langle\nabla f(\boldsymbol{\theta}_{n_{k}}),\boldsymbol{\theta}-\boldsymbol{\theta}_{m_{k}}\rangle=\langle\nabla\bar{g}_{n_{k}}(\boldsymbol{\theta}_{n_{k}}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n_{k}}\rangle-\langle\nabla\bar{h}_{n_{k}}(\boldsymbol{\theta}_{n_{k}}),\boldsymbol{\theta}-\boldsymbol{\theta}_{n_{k}}\rangle.

(231)

By Lemmas
F.2
and
E.4
,
\lVert\nabla\bar{h}_{n_{k}}(\boldsymbol{\theta}_{n_{k}})\rVert^{2}\leq 2L\bar{h}_{n_{k}}(\boldsymbol{\theta}_{n_{k}})\to 0
almost surely as
k\to\infty
. Therefore, by taking limits we get

\displaystyle\langle\nabla f(\boldsymbol{\theta}_{\infty}),\boldsymbol{\theta}-\boldsymbol{\theta}_{\infty}\rangle\geq 0.

(232)

Since this holds for all
\boldsymbol{\theta}\in\boldsymbol{\Theta}
,

\displaystyle\sup_{\boldsymbol{\theta}\in\boldsymbol{\Theta},\lVert\boldsymbol{\theta}-\boldsymbol{\theta}_{\infty}\rVert\leq 1}\langle-\nabla f(\boldsymbol{\theta}_{\infty}),\boldsymbol{\theta}-\boldsymbol{\theta}_{\infty}\rangle\leq 0

(233)

which means that
\boldsymbol{\theta}_{\infty}
is a stationary point of
f
over
\boldsymbol{\Theta}
.
∎

Proposition E.8
.

Suppose there exists a sub-sequence
(\boldsymbol{\theta}_{n_{k}})_{k\geq 1}
such that
\lim_{k\to\infty}\boldsymbol{\theta}_{n_{k}}=\boldsymbol{\theta}_{\infty}
exists almost surely and that
\boldsymbol{\theta}_{\infty}
is not a stationary point of
f
over
\boldsymbol{\Theta}
. Then there is
\varepsilon>0
such that the
\varepsilon
-neighborhood
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
has the following properties:

(a)

B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
does not contain any stationary points of
f
over
\boldsymbol{\Theta}
.

(b)

There are infinitely many
n
for which
\boldsymbol{\theta}_{n}
is outside of
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
.

Proof.

We first show that there exists
\varepsilon>0
so that
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
does not contain any long points. Suppose for contradiction that for each
\varepsilon>0
, there is a long point in
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
. Then one may construct a sequence of long points converging to
\boldsymbol{\theta}_{\infty}
. But then by Proposition
E.7
,
\boldsymbol{\theta}_{\infty}
is a stationary point for
f
over
\boldsymbol{\Theta}
, a contradiction.

Next we show that there exists
\varepsilon
so that
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
satisfies (a). In fact, suppose not. Then we can find a sequence of stationary points
(\boldsymbol{\theta}_{\infty,k})_{k\geq 1}
converging to
\boldsymbol{\theta}_{\infty}
. But then by continuity of
\nabla f
,

\displaystyle\langle\nabla f(\boldsymbol{\theta}_{\infty}),\boldsymbol{\theta}-\boldsymbol{\theta}_{\infty}\rangle=\lim_{k\to\infty}\langle\nabla f(\boldsymbol{\theta}_{k,\infty}),\boldsymbol{\theta}-\boldsymbol{\theta}_{k,\infty}\rangle\geq 0

(234)

for any
\boldsymbol{\theta}\in\boldsymbol{\Theta}
. Then
\boldsymbol{\theta}_{\infty}
is a stationary point of
f
over
\boldsymbol{\Theta}
, contradicting our assumptions.

Now let
\varepsilon>0
be such that
B_{\varepsilon}(\boldsymbol{\theta}_{\infty})
does not contain any long points and satisfies (a). We will show that
B_{\varepsilon/2}(\boldsymbol{\theta}_{\infty})
satisfies (b) and thus
B_{\varepsilon/2}(\boldsymbol{\theta}_{\infty})
satisfies both (a) and (b) as desired. Aiming for a contradiction, suppose there are only finitely many
n
for which
\boldsymbol{\theta}_{n}
is outside
B_{\varepsilon/2}(\boldsymbol{\theta}_{\infty})
. Then there exists

so that
\boldsymbol{\theta}_{n}\in B_{\varepsilon/2}(\boldsymbol{\theta}_{\infty})
for all

. Then
\boldsymbol{\theta}_{n}
is a short point for each

so
\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert=r_{n}
for all
n\geq N
. This, in turn, implies that
\sum_{n=1}^{\infty}\lVert\boldsymbol{\theta}_{n}-\boldsymbol{\theta}_{n-1}\rVert=\infty
. By Proposition
E.5
, there exists a subsequence
(\boldsymbol{\theta}_{n_{k}})_{k\geq 1}
such that
\boldsymbol{\theta}_{\infty}^{\prime}=\lim_{k\to\infty}\boldsymbol{\theta}_{n_{k}}
exists and is stationary for

. But since

, this contradicts (a). The proof is complete.
∎

We now prove Theorem
3.9

(ii)
.

Proof of Theorem
3.9

(ii)
.

Suppose for contradiction that there exists a non-stationary limit point
\boldsymbol{\theta}_{\infty}
of
(\boldsymbol{\theta}_{n})_{n\geq 0}
. By Proposition

, there is
\varepsilon>0
so that

Appendix F
Auxiliary Lemmas

Lemma F.1
.

Let
f:\mathbb{R}^{p}\to\mathbb{R}
be a continuously differentiable function with
L
-Lipschitz continuous gradient. Then for all
\boldsymbol{\theta},\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}
,

\displaystyle|f(\boldsymbol{\theta}^{\prime})-f(\boldsymbol{\theta})-\langle\nabla f(\boldsymbol{\theta}),\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}\rangle|\leq\frac{L}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}^{\prime}\rVert^{2}.

(237)

Proof.

This is a classical lemma. See
(
Nesterov 2003
)
Lemma 1.2.3.
∎

Lemma F.2
.

Let
f:\mathbb{R}^{p}\to[0,\infty)
be a continuously differentiable function with
L
-Lipschitz continuous gradient. Then for all
\boldsymbol{\theta}\in\mathbb{R}^{p}
, it holds
\lVert\nabla f(\boldsymbol{\theta})\rVert^{2}\leq 2Lf(\boldsymbol{\theta})
.

Proof.

Fix
\boldsymbol{\theta}\in\mathbb{R}^{p}
. By Lemma
F.1
we have

\displaystyle\inf_{\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}}f(\boldsymbol{\theta}^{\prime})\leq\inf_{\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}}\left\{f(\boldsymbol{\theta})+\langle\nabla f(\boldsymbol{\theta}),\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}\rangle+\frac{L}{2}\lVert\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}\rVert^{2}\right\}.

(238)

It is easy to compute that

\displaystyle\inf_{\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}}\left\{f(\boldsymbol{\theta})+\langle\nabla f(\boldsymbol{\theta}),\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}\rangle+\frac{L}{2}\lVert\boldsymbol{\theta}^{\prime}-\boldsymbol{\theta}\rVert^{2}\right\}=f(\boldsymbol{\theta})-\frac{1}{2L}\lVert\nabla f(\boldsymbol{\theta})\rVert_{2}^{2}.

(239)

Therefore

\displaystyle\lVert\nabla f(\boldsymbol{\theta})\rVert_{2}^{2}\leq 2L(f(\boldsymbol{\theta})-\inf_{\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}}f(\boldsymbol{\theta}^{\prime}))\leq 2Lf(\boldsymbol{\theta})

(240)

since
\inf_{\boldsymbol{\theta}^{\prime}\in\mathbb{R}^{p}}f(\boldsymbol{\theta}^{\prime})\geq 0
.
∎

Appendix G
Examples of Surrogate Functions

Example G.1

(Proximal surrogates for
L
-smooth functions)
.

Suppose
f
is continuously differentiable with
L
-Lipschitz continuous gradients. Then
f
is
L
-weakly convex, meaning
\boldsymbol{\theta}\mapsto f(\boldsymbol{\theta})+\frac{L}{2}\lVert\boldsymbol{\theta}\rVert^{2}
is convex (see
(
Lyu 2023
)
Lemma C.2). For each

, the following function belongs to

:

\displaystyle g:\boldsymbol{\theta}\mapsto f(\boldsymbol{\theta})+\frac{\gamma}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}^{*}\rVert^{2}

(241)

Indeed,
g\geq f
,
g(\boldsymbol{\theta}^{*})=f(\boldsymbol{\theta}^{*})
,
\nabla h(\boldsymbol{\theta}^{*})=0
, and
\nabla h
is
(L+\rho)
Lipschitz. Minimizing the above function over
\boldsymbol{\Theta}
is equivalent to applying a proximal mapping of
f
where the resulting estimate is denoted
\text{prox}_{f/\rho}(\boldsymbol{\theta}^{*})
(see
(
Parikh & Boyd 2014
;
Davis & Drusvyatskiy 2019
)
).

Example G.2

(Prox-linear surrogates)
.

If
f
is
L
-smooth, then the following quadratic function
g
belongs to
\mathcal{S}_{2L}(f,\boldsymbol{\theta}^{*})

\displaystyle g:\boldsymbol{\theta}\mapsto f(\boldsymbol{\theta}^{*})+\langle\nabla f(\boldsymbol{\theta}^{*}),\boldsymbol{\theta}-\boldsymbol{\theta}^{*}\rangle+\frac{L}{2}\lVert\boldsymbol{\theta}-\boldsymbol{\theta}^{*}\rVert^{2}.

(242)

Indeed,

,

since

-smooth.

Appendix H
Matrix factorization algorithms

Here we formally state the non-negative matrix factorization algorithms derived in Section
4.1.1
. They may be compared to the celebrated online nonnegative matrix factorization algorithm in
(
Mairal et al. 2010
)
which is a special case of SMM.

With surrogates
g_{n}(W)
as defined in Section
4.1.1
, one can show that minimizing the averaged surrogate
\bar{g}_{n}(W)=\frac{1}{|\mathcal{V}|}\sum_{v\in V}g_{n}^{v}(W)
is equivalent to minimizing

\displaystyle\text{tr}(WA_{n}W^{T})-2\text{tr}(WB_{n}),

(247)

with
A_{n}
and
B_{n}
, defined recursively as

\displaystyle A_{n}

\displaystyle:=A_{n-1}+\frac{1}{|\mathcal{V}|}\Big[H_{n}^{v_{n}}(H_{n}^{v_{n}})^{T}-H_{n-1}^{v_{n}}(H_{n-1}^{v_{n}})^{T}\Big]

(248)

\displaystyle B_{n}

\displaystyle:=B_{n-1}+\frac{1}{|\mathcal{V}|}\Big[H_{n}^{v_{n}}X_{v}^{T}-H_{n-1}^{v_{n}}X_{v}^{T}\Big].

(249)

With this, we state the full algorithms below.

Algorithm 3

Distributed Matrix Factorization with Proximal Regularization

Input:

(X^{v})_{v\in\mathcal{V}}
(Data matrices in
\mathbb{R}^{p\times d}
);
W_{0}\in\boldsymbol{\Theta}_{W}
(initial dictionary);
N
(number of iterations);
\rho>0
(regularization parameter)

Option:

Regularization\in\{Dynamic,Constant\}

Compute initial codes
H_{0}^{v}\in\argmin_{H\in\boldsymbol{\Theta}_{H}^{\mathcal{V}}}\frac{1}{2}\lVert X^{v}-W_{0}H\rVert_{F}^{2}+\alpha\lVert H\rVert_{1}
for each
v\in\mathcal{V}

for

n=1

to

N

do

sample an index
v_{n}

update
H_{n}^{v}\in\argmin_{H\in\boldsymbol{\Theta}_{H}^{\mathcal{V}}}\frac{1}{2}\lVert X_{v}-W_{n-1}H\rVert_{F}^{2}+\alpha\lVert H\rVert_{1}
;
H_{n}^{v}=H_{n-1}^{v}
