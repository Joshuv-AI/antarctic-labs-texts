Exact Learning of Multitrees and Almost-Trees Using Path Queries
Ramtin Afshar, Michael T. Goodrich

Abstract
Given a directed graph, G = ( V , E ) G=(V,E) , a path query, path ( u , v ) (u,v) , returns whether there is a directed path from u u to v v in G G , for u , v ∈ V u,v\in V . Given only V V , exactly learning all the edges in G G using path queries is often impossible, since path queries cannot detect transitive edges. In this paper, we study the query complexity of exact learning for cases when learning G G is possible using path queries. In particular, we provide efficient learning algorithms, as well as lower bounds, for multitrees and almost-trees, including butterfly networks.

Definition 1

(arborescence)
An arborescence is a rooted DAG with root

We next introduce multitree, which is a family of DAGs useful in distributed computing

Definition 2

(multitree)
A multitree is a DAG in which the subgraph reachable from any vertex induces a tree, that is, it is a DAG with at most one directed path for any pair of vertices.

Learning Multitrees

In this section, we begin by presenting a deterministic algorithm to learn
a rooted tree (a multitree with a single root) of height

path queries. Then we derive a deterministic algorithm to

These results form building blocks for the main results of this section,
which are an efficient algorithm to learn a multitree
of arbitrary height with
