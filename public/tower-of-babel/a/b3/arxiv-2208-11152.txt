Strong XOR Lemma for Communication with Bounded Rounds
Huacheng Yu

Abstract
In this paper, we prove a strong XOR lemma for bounded-round two-player randomized communication. For a function f : 𝒳 × 𝒴 → { 0 , 1 } f:\mathcal{X}\times\mathcal{Y}\rightarrow\{0,1\} , the n n -fold XOR function f ⊕ n : 𝒳 n × 𝒴 n → { 0 , 1 } f^{\oplus n}:\mathcal{X}^{n}\times\mathcal{Y}^{n}\rightarrow\{0,1\} maps n n input pairs ( X 1 , … , X n , Y 1 , … , Y n ) (X_{1},\ldots,X_{n},Y_{1},\ldots,Y_{n}) to the XOR of the n n output bits f ⁡ ( X 1 , Y 1 ) ⊕ ⋯ ⊕ f ⁡ ( X n , Y n ) f(X_{1},Y_{1})\oplus\cdots\oplus f(X_{n},Y_{n}) . We prove that if every r r -round communication protocols that computes f f with probability 2 / 3 2/3 uses at least C C bits of communication, then any r r -round protocol that computes f ⊕ n f^{\oplus n} with probability 1 / 2 + exp ⁡ ( − O ⁡ ( n ) ) 1/2+\exp(-O(n)) must use n ⋅ ( r − O ⁡ ( r ) ⋅ C − 1 ) n\cdot\left(r^{-O(r)}\cdot C-1\right) bits. When r r is a constant and C C is sufficiently large, this is Ω ⁡ ( n ⋅ C ) \Omega(n\cdot C) bits. It matches the communication cost and the success probability of the trivial protocol that computes the n n bits f ⁡ ( X i , Y i ) f(X_{i},Y_{i}) independently and outputs their XOR, up to a constant factor in n n . A similar XOR lemma has been proved for f f whose communication lower bound can be obtained via bounding the discrepancy [ Sha03 ] . By the equivalence between the discrepancy and the correlation with 2 2 -bit communication protocols [ VW08 ] , our new XOR lemma implies the previous result.

Introduction

In computational complexity, XOR lemmas study the relation between the complexity of a
\{0,1\}
-valued function
f(x)
and the complexity of the
n
-fold XOR function
f^{\oplus n}
where

f^{\oplus n}(x_{1},\ldots,x_{n})=f(x_{1})\oplus\cdots\oplus f(x_{n})

and
\oplus
is the XOR.
A classic example is Yao’s XOR lemma for circuits
[
Yao82
]
, which states if
f
cannot be computed with probability
2/3
on a random input by size-
s
circuits, then
f^{\oplus n}
cannot be computed with probability
1/2+\exp(-\Omega(n))
on a random input by size-
s^{\prime}
circuits for some
s^{\prime}<s
(and small
n
).
Such lemmas can be used to create very hard functions in a blackbox way, which can only be computed barely better than random guessing, from functions that are “just” hard to compute with constant probability.
This approach of hardness amplification has been used in one-way functions
[
Yao82
,
Lev87
]
, pseudorandom generators
[
Imp95
,
IW97
]
, and more recently, streaming lower bounds
[
AN21
,
CKP+21
]
.

In general, suppose computing a function
f
with probability
2/3
requires resource
s
in some model of computation (e.g., circuit size, running time, query complexity, communication cost, etc).
Then the trivial way to compute
f^{\oplus n}
is to compute each
f(x_{i})
using resource
s
independently, and output their XOR.
It uses resource
n\cdot s
in total, and each instance is correct with probability
2/3
, hence, their XOR is correct with probability
1/2+\exp(-\Theta(n))
: For two
independent
random bits
b_{1},b_{2}
, if
\Pr[b_{1}=0]=1/2+\alpha_{1}/2
and
\Pr[b_{2}=0]=1/2+\alpha_{2}/2
, then

\displaystyle\Pr[b_{1}\oplus b_{2}=0]=(1/2+\alpha_{1}/2)(1/2+\alpha_{2}/2)+(1/2-\alpha_{1}/2)(1/2-\alpha_{2}/2)=1/2+\alpha_{1}\alpha_{2}/2;

let
b_{i}=0
if and only if
f(x_{i})
is computed correctly, applying the above calculation inductively gives the claimed probability.
A
strong XOR lemma
asserts that to achieve
1/2+\exp(-O(n))
success probability, one must use
\Omega(n\cdot s)
resource — the trivial solution is essentially optimal.

Now suppose that we are given
n\cdot s/2
resource in total, and we want to compute
f^{\oplus n}
.
If we try to solve the
n
copies independently, then no matter how we distribute the resource among the
n
copies, at least half of them will get no more than
s
.
The function
f^{\oplus}
is computed correctly with probability at most
1/2+\exp(-\Omega(n))
.
Of course, since all
n
inputs
(x_{1},\ldots,x_{n})
are given together, we can potentially process them jointly.
This may correlate the
n
copies, and in particular, it may correlate the correctness of computing each
f(x_{i})
.
Hence, one difficulty in proving the strong XOR lemma from the technical point of view is that in the above calculation of the probability of XOR of two independent bits, the linear terms perfectly cancel only because
b_{1}
and
b_{2}
are independent;
when they are not independent, we may get a linear term remaining, and do not reduce the probability bias as desired.
In computational models where one cannot expect the independence between the copies throughout the computation, a success probability lower bound of
1/2+\exp(-\Omega(n))
(hence, a strong XOR lemma) is generally difficult to prove.

In this paper, we prove a strong XOR lemma for the two-player randomized communication complexity with bounded rounds: Alice and Bob receive
X
and
Y
respectively, they alternatively send a total of
r
messages to each other with the goal of computing
f(X,Y)
.
For
f^{\oplus n}
, Alice receives
(X_{1},\ldots,X_{n})
and Bob receives
(Y_{1},\ldots,Y_{n})
, and they wish to compute
f(X_{1},Y_{1})\oplus\cdots\oplus f(X_{n},Y_{n})
after
r
rounds of communication.
Each player has half of the inputs for all copies, and can send messages that arbitrarily depend on them, which can nontrivially correlate the
n
instances.
Nevertheless, we show that one cannot do much better than simply solving all
n
copies in parallel.

Let
\mathbf{R}^{(r)}_{p}(f)
be the minimum number of bits of communication needed in
r

correctly with probability

We prove the following theorem.

Theorem 1
.

For any
\{0,1\}
-valued function

\mathbf{R}^{(r)}_{1/2+2^{-n}}(f^{\oplus n})\geq n\cdot\left(r^{-O(r)}\cdot\mathbf{R}^{(r)}_{2/3}(f)-1\right).

In particular, when

\mathbf{R}^{(r)}_{1/2+2^{-n}}(f^{\oplus n})\geq\Omega\left(n\cdot\left(\mathbf{R}^{(r)}_{2/3}(f)-O(1)\right)\right)

Our proof of the distributional version is inspired by the

2.2
Obtaining exponentially small advantage

The above decomposition preserves the success probability.
However, if we start from a protocol for

In fact, this is inherent for information complexity, since the strong XOR lemma for

It turns out that the main difficulty in applying the above strategy is to formalize the last bullet point.
Note that the expected advantage of
\pi_{n}

\mathop{\mathbb{E}}\left[\mathrm{adv}(f(X_{n},Y_{n})\mid X_{n},Y_{<n},\mathbf{M})\right]

When we say that the advantage of

\mathrm{adv}(f(X_{n},Y_{n})\mid X_{n},Y_{<n},\mathbf{M})

.

This motivates us to consider the following two extreme cases:

1.

\mathrm{adv}(f^{\oplus n}(X,Y)\mid X_{n},Y_{<n},\mathbf{M})
is roughly uniformly distributed among all
(X_{n},Y_{<n},\mathbf{M})
;

2.

\mathrm{adv}(f^{\oplus n}(X,Y)\mid X_{n},Y_{<n},\mathbf{M})
is concentrated on a tiny fraction of the triples
(X_{n},Y_{<n},\mathbf{M})
.

Basically following what we just argued, the above strategy directly applies in the first case.
The second case is related to the
direct product theorems
, where we also want to analyze protocols that is correct with exponentially small probability.
This is because one possible strategy for the players is to compute all
f(X_{i},Y_{i})
correctly with some probability
\varepsilon
and output a random bit otherwise.
We must at least show that in this case,
\varepsilon\leq\exp(-\Omega(n))
.

2.3
Generalized protocols

For the second case above, we follow one strategy for direct product theorems
[
BRWY13b
]
.
When the advantage
\mathrm{adv}(f^{\oplus n}(X,Y)\mid X_{n},Y_{<n},\mathbf{M})
is concentrated on a small set
U
of triples
(X_{n},Y_{<n},\mathbf{M})
, we restrict our attention to
U
by
conditioning

\pi
on
U
.
However, this immediately creates two issues.

The first issue is that although
\pi\mid U
is a well-defined distribution, it is not necessarily a
protocol
, since conditioning on an arbitrary event may break the independence between a message and the receiver’s input, e.g.,
M_{1}
may no longer be independent of
Y
conditioned on
X
.
5
5

5

Conditioning on an event also distorts the input distribution, which needs to be handled. But for simplicity, we omit it in the overview.

This issue was also encountered in the direct product theorem proofs.
Instead of studying standard protocols, we focus on
generalized protocols
, where we allow each message to depend on both player’s inputs, and we wish to restrict the correlation between the odd
M_{i}
and Bob’s input and the correlation between the even
M_{i}
and Alice’s input.
In the previous work, it bounds

\theta(\pi):=\sum_{\mathrm{odd}\,i}I(M_{i};Y\mid X,M_{<i})+\sum_{\mathrm{even}\,i}I(M_{i};X\mid Y,M_{<i}),

the mutual information between the message and the receiver’s input.

Intuitively, the
\theta
-value measures how close to a standard protocol a generalized protocol is.
It turns out that the
\theta
-value of a standard protocol conditioned on a not-too-small probability event is small; on the other hand, when the
\theta
-value is small, it is statistically close to a standard protocol.
Furthermore, an important feature of
\theta(\pi)
is that the decomposition of
\pi
into
\pi_{<n}
and
\pi_{n}
also satisfies that
\theta(\pi)=\theta(\pi_{<n})+\theta(\pi_{n})
.
Hence, when doing the decomposition, we can hope to obtain a generalized protocol for
f
that is very close to a standard protocol.

The second issue is that conditioning on a small probability event
U
could greatly increase the information cost, from
I
to
\Omega(I/\Pr[U])
.
Since
I
is close to the communication cost, such a multiplicative loss in each step of decomposition is unaffordable.
Such a loss occurs because the mutual information is an average measure (an expectation), which does not provide any concentration (also recall the counterexample in footnote
4
where the communication cost and the advantage are both concentrated on an
\varepsilon
-probability event, when we condition on this event, both the expected communication cost and the advantage increase by a factor of
1/\varepsilon
).
More specifically, consider the first term in the information cost,
I(X;\mathbf{M}\mid Y)
(omit the public random bits for now).
For standard protocols, it is equal to

\sum_{x,y,\mathbf{m}}\pi(x,y,\mathbf{m})\cdot\log\left(\frac{\pi(x\mid\mathbf{m},y)}{\pi(x\mid y)}\right)=\mathop{\mathbb{E}}_{\pi}\left[\log\left(\frac{\pi(X\mid\mathbf{M},Y)}{\pi(X\mid Y)}\right)\right]=\mathop{\mathbb{E}}_{\pi}\left[\log\left(\frac{\pi(X\mid\mathbf{M},Y)}{\mu(X\mid Y)}\right)\right].

If we only have a bound on this expectation, then inevitably its value can greatly increase after conditioning on a small probability event, not to say that the logarithm inside the expectation is
not
nonnegative, so it can get worse than what Markov’s inequality gives.

We also note that the argument in the previous subsections crucially uses the
rectangle property
of the communication protocols, which does not necessarily hold for generalized protocols.
This turns out not to be a real issue, since throughout the argument, we will maintain the rectangle property
at all leaves
, which is sufficient for the argument to go through (see also Section
2.6
).

2.4
\theta
-cost and
\chi^{2}
-costs

Our novel solution to the second issue above is to focus on the “exponential version” of the information cost, i.e., for the first term,

\chi^{2}_{\mu,A}(\pi):=\mathop{\mathbb{E}}_{\pi}\left[\frac{\pi(X\mid\mathbf{M},Y)}{\mu(X\mid Y)}\right],

which we call the
\chi^{2}
-cost by Alice.
The
\chi^{2}
-cost by Bob,
\chi^{2}_{\mu,B}(\pi)
, is defined similarly for the second term in the information cost (see Definition
15
).

This notion of the cost has the following benefits.

•

For a (deterministic) standard protocol with
C
bits of communication,
\chi^{2}_{\mu,A}(\pi)\leq 2^{C}
.
Hence, it corresponds to the exponential of the communication cost.

•

When conditioning on a small probability event
U
, we can essentially ensure that it increases by a factor of
O(1/\pi(U))
(Lemma
37
gives a more generalized statement).
Effectively, this only adds
\log(1/\pi(U))
to the communication cost, which becomes affordable.

Note that the mutual information is the expected KL-divergence, and the
\chi^{2}
-cost is the expected
\chi^{2}
-divergence (plus one).
Similarly, we also define an “exponential version” of
\theta(\pi)
, which we call the
\theta
-cost of
\pi
(see Definition
12
).
It also ensures that the value does not increase significantly when conditioning on a small probability event.

On the other hand, going from mutual information to its “exponential version” loses many of its good properties, most importantly, the chain rule.
The next crucial observation is that the chain rule for mutual information in fact holds
pointwisely
, which enables us to work with the
\chi^{2}
-costs.

More specifically, let
X,Y,Z
be three random variables with joint distribution
\pi
, the chain rules says
I(X;Y,Z)=I(X;Y)+I(X;Z\mid Y)
.
By writing the mutual information as an expectation, this is

\mathop{\mathbb{E}}\left[\log\left(\frac{\pi(Y,Z\mid X)}{\pi(Y,Z)}\right)\right]=\mathop{\mathbb{E}}\left[\log\left(\frac{\pi(Y\mid X)}{\pi(Y)}\right)\right]+\mathop{\mathbb{E}}\left[\log\left(\frac{\pi(Z\mid X,Y)}{\pi(Z\mid Y)}\right)\right].

This equality holds pointwisely in the sense that for any concrete values
(x,y,z)
, the equality holds for the logarithms inside the expectation

\log\left(\frac{\pi(y,z\mid x)}{\pi(y,z)}\right)=\log\left(\frac{\pi(y\mid x)}{\pi(y)}\right)+\log\left(\frac{\pi(z\mid x,y)}{\pi(z\mid y)}\right)

by the definition of conditional probability.

Therefore, the “exponential version” also holds pointwisely:

\frac{\pi(y,z\mid x)}{\pi(y,z)}=\frac{\pi(y\mid x)}{\pi(y)}\cdot\frac{\pi(z\mid x,y)}{\pi(z\mid y)}.

This is what we use in replacement of the chain rule for mutual information.
See the next subsection for more details.

2.5
Proof outline

We now give an outline of the proof of the following statement:
Given an
r
-round standard protocol
\pi
for

with communication cost
o(n\cdot C)
that succeeds with advantage
\alpha^{o(n)}
on the inputs sampled from
\mu^{n}

r
-round generalized protocol
\rho
for

with
\chi^{2}
-costs
\approx 2^{C}
,
\theta
-cost
\approx 1/\alpha
and advantage
\approx\alpha
.
We will then discuss how to convert such a generalized protocol to a standard protocol with low communication cost in the next subsection.

We first show that
\pi
is also a generalized protocol with
\chi^{2}
-cost
2^{o(nC)}
and
\theta
-cost
1
(in the proof of Lemma
25
).
Next, we decompose
\pi
into
\pi_{<n}
for
f^{\oplus n-1}
and
\pi_{n}
for
f
, and prove that the product of the
\theta
-cost [resp.
\chi^{2}
-costs] of
\pi_{<n}
and
\pi_{n}
is that of
\pi
pointwisely (Section
5
).
Now if the advantage of
\pi
is not roughly evenly distributed, we will identify an event
U
such that the advantage conditioned on
U
is much higher than the average advantage, and more importantly, the advantage within
U
becomes roughly evenly distributed (not concentrated on any small probability event in
U
) (Section
6.1
).
Conditioning on
U
increases the advantage while also increases the
\theta
-cost and
\chi^{2}
-costs, it turns out that they all increase by about the same factor.
Next, we partition the sample space of
\pi
into
S_{\textnormal{high-cost}},S_{\textnormal{low-cost}}
and
S_{\textnormal{low-prob}}
such that

•

in
S_{\textnormal{high-cost}}
,
\pi_{n}
has high
\theta
-cost or high
\chi^{2}
-cost (excluding some corner cases), say
\geq 1/\alpha
for
\theta
-cost or
\geq 2^{C}
for
\chi^{2}
-cost,

•

in
S_{\textnormal{low-cost}}
,
\pi_{n}
has low
\theta
-cost and low
\chi^{2}
-cost (also excluding some corner cases),

•

S_{\textnormal{low-prob}}
is the rest, which will happen with very low probability.

Since the advantage is not concentrated on any small probability in
U
, then (at least) one of
S_{\textnormal{high-cost}}
or
S_{\textnormal{low-cost}}
will have advantage about as high as the advantage of
U
.
If
S_{\textnormal{high-cost}}
has the advantage as high as
U
, then we prove that by the pointwise equality for the costs,
\pi_{<n}\mid S_{\textnormal{high-cost}}
must have a much smaller cost than
\pi\mid U
, while they have roughly the same advantage (Section
6.2
).
If
S_{\textnormal{low-cost}}
has the advantage as high as

has high advantage, then we obtain a desired generalized protocol for

with low costs and high advantage; otherwise we prove that

has a much higher advantage than

(as the advantage of

is roughly evenly distribution within

).

To summarize the above argument, if we don’t already find a desired generalized protocol for
f
, then when decrementing
n
to
n-1
, we first condition on an event

, increasing costs and advantage simultaneously by about the same (while arbitrary) factor, then either we reduce the
\theta
-cost by a factor of
\geq 1/\alpha
, or we reduce the
\chi^{2}
-costs by a factor of
\geq 2^{C}
, or we increase the advantage by a factor of
\geq 1/\alpha
.
Since we start with
\chi^{2}
-costs
2^{o(nC)}
,
\theta
-cost
1
and advantage
\alpha^{o(n)}
, we cannot repeat this for
n

.
More formally, we will measure the progress by using a potential function that depends on the costs and advantage of the current protocol, and show that each time we decrement from
k
to

, how much the potential must decrease (Section
4
).

2.6
Convert a generalized protocol to a standard protocol

Finally, we need to show that the existence of a good generalized protocol implies the existence of a good standard protocol.
We prove that if an
r
-round generalized protocol
\rho
has
\chi^{2}
-costs
2^{C}
,
\theta
-cost
1/\alpha
and advantage
\alpha
, then there is an
r
-round standard protocol
\tau
with communication cost
\approx C
and advantage
\approx\alpha^{3}
.
Together with what we summarized in the last subsection, we obtain the strong XOR lemma for
r
-round communication.

[
BR11
]
converts a
standard
protocol
\rho
with constant rounds to a standard protocol with communication matching the internal information cost of
\rho
.
Using a similar argument, we can convert
\rho
to a standard protocol with communication
\approx C
.
By the convexity of
2^{x}
,
\chi^{2}
-cost of
2^{C}
implies internal information cost of at most
C
.
It turns out that the (almost) same argument applies in our case, for generalized protocol
\rho
.

Then the next crucial observation is that we can ensure the generalized protocol
\rho
that we obtain from the arguments in the previous subsection has the
rectangle property
with respect to
\mu
.
Roughly speaking, it means that for all transcripts
\mathbf{M}
, if we look at the ratio of the probabilities
\frac{\rho(X,Y\mid\mathbf{M})}{\mu(X,Y)}
, it is a product function of
X
and
Y
, i.e., it is equal to
g_{A}(X)\cdot g_{B}(Y)
for some functions
g_{A},g_{B}
that may depend on
\mathbf{M}
.
Note that a standard protocol has the rectangle property, since each message depends only on either
X
or
Y
, and the same property holds even conditioned on any prefix of the transcript
M_{<i}
.
A generalized protocol may not have this property in general, but we can ensure that the protocol we obtain has this product structure conditioned on any
complete
transcript
\mathbf{M}
.

After generating a transcript
\mathbf{M}
using
[
BR11
]
, the rectangle property allows the players to locally “re-adjust” the probabilities (via rejection sampling) so that after the readjustment, the probability of a triple
(X,Y,\mathbf{M})
is proportional to the “right” probability
\rho(X,Y,\mathbf{M})
, which in turn, gives the advantage proportional to that of
\rho
.

The probability that is sacrificed in the rejection sampling depends on how far
\rho
is from a standard protocol, i.e., the
\theta
-cost of
\rho
.
It turns out that the above argument gives an overall advantage of at least
\alpha^{2}
divided by the
\theta
-cost of
\rho
.
See Section
7
for the formal proof.

Lemma 10

By definition, we have

\displaystyle\kern-20.00003pt\pi(W_{1})\cdot\mathop{\mathbb{E}}_{\pi\mid W_{1}}\left[\mathrm{adv}(f(X,Y)\mid\mathbf{R},W_{1})\right]+\pi(W_{2})\cdot\mathop{\mathbb{E}}_{\pi\mid W_{2}}\left[\mathrm{adv}(f(X,Y)\mid\mathbf{R},W_{2})\right]

\displaystyle=\pi(W_{1})\cdot\sum_{\mathbf{R}}\pi(\mathbf{R}\mid W_{1})\cdot\left|2\pi(f(X,Y)=1\mid\mathbf{R},W_{1})-1\right|

\displaystyle\qquad+\pi(W_{2})\cdot\sum_{\mathbf{R}}\pi(\mathbf{R}\mid W_{2})\cdot\left|2\pi(f(X,Y)=1\mid\mathbf{R},W_{2})-1\right|

\displaystyle=\pi(W_{1}\cup W_{2})\cdot\mathop{\mathbb{E}}_{\pi\mid W_{1}\cup W_{2}}\left[\mathrm{adv}(f(X,Y)\mid\mathbf{R},W_{1}\cup W_{2})\right].

∎

The following proposition states that knowing more could only increase the expected advantage.

Proposition 11

Let
\mathbf{R}_{1},\mathbf{R}_{2}
be two random variables, then

\mathop{\mathbb{E}}_{\mathbf{R}_{1}\sim\pi}\left[\mathrm{adv}(f\mid\mathbf{R}_{1})\right]\leq\mathop{\mathbb{E}}_{\mathbf{R}_{1},\mathbf{R}_{2}\sim\pi}\left[\mathrm{adv}(f\mid\mathbf{R}_{1},\mathbf{R}_{2})\right].

Proof.

We have

\displaystyle\kern-20.00003pt\mathop{\mathbb{E}}_{\mathbf{R}_{1},\mathbf{R}_{2}\sim\pi}\left[\mathrm{adv}(f\mid\mathbf{R}_{1},\mathbf{R}_{2})\right]

\displaystyle=\sum_{\mathbf{R}_{1},\mathbf{R}_{2}}\pi(\mathbf{R}_{1},\mathbf{R}_{2})\cdot\left|2\pi(f=1\mid\mathbf{R}_{1},\mathbf{R}_{2})-1\right|

\displaystyle=\sum_{\mathbf{R}_{1}}\pi(\mathbf{R}_{1})\sum_{\mathbf{R}_{2}}\pi(\mathbf{R}_{2}\mid\mathbf{R}_{1})\cdot\left|2\pi(f=1\mid\mathbf{R}_{1},\mathbf{R}_{2})-1\right|

\displaystyle\geq\sum_{\mathbf{R}_{1}}\pi(\mathbf{R}_{1})\cdot\left|\sum_{\mathbf{R}_{2}}\pi(\mathbf{R}_{2}\mid\mathbf{R}_{1})\cdot 2\pi(f=1\mid\mathbf{R}_{1},\mathbf{R}_{2})-\sum_{\mathbf{R}_{2}}\pi(\mathbf{R}_{2}\mid\mathbf{R}_{1})\right|

\displaystyle=\sum_{\mathbf{R}_{1}}\pi(\mathbf{R}_{1})\cdot\left|2\pi(f=1\mid\mathbf{R}_{1})-1\right|

\displaystyle=\mathop{\mathbb{E}}_{\mathbf{R}_{1}\sim\pi}\left[\mathrm{adv}(f\mid\mathbf{R}_{1})\right].

∎

3.3
The
\theta
-cost and
\chi^{2}
-costs

In a standard protocol, Alice’s message must be independent of Bob’s input conditioned on Alice’s input and the previous messages, and vice versa, while we allow arbitrary correlation in a generalized protocol.
The
\theta
-cost
of a generalized protocol measures this correlation.

Definition 12

(
\theta
-cost)
.

The
\theta
-cost of
\pi
with respect to
\mu
at
(X,Y,\mathbf{M})
is

\displaystyle\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})

\displaystyle:=\frac{\pi(X,Y\mid M_{0})}{\mu(X,Y)}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{\pi(M_{i}\mid X,Y,M_{<i})}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{\pi(M_{i}\mid X,Y,M_{<i})}{\pi(M_{i}\mid Y,M_{<i})}

\displaystyle=\frac{\pi(X,Y,\mathbf{M})}{\pi(M_{0})\cdot\mu(X,Y)\cdot\prod_{\mathrm{odd}\,i\in[r]}\pi(M_{i}\mid X,M_{<i})\cdot\prod_{\mathrm{even}\,i\in[r]}\pi(M_{i}\mid Y,M_{<i})}.

The
\theta
-cost of
\pi
with respect to
\mu
is

\displaystyle\theta_{\mu}(\pi)

\displaystyle:=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi}\left[\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})\right].

For an event
W
, the
\theta
-cost of
\pi
respect to
\mu
conditioned on
W
is

\displaystyle\theta_{\mu}(\pi\mid W):=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi\mid W}\left[\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})\right].

Remark
.

We emphasize that
\theta_{\mu}(\pi\mid W)
is different from
\theta_{\mu}(\pi_{W})
for
\pi_{W}
being the distribution of
\pi
conditioned on
W
.
According to the definitions, although
(X,Y,\mathbf{M})
is sampled from
\pi\mid W
in both cases, the quantity inside the expectation is different.
For
\theta_{\mu}(\pi\mid W)
, we still measure the
\theta
-cost at
(X,Y,\mathbf{M})
according to distribution
\pi
, while for
\theta_{\mu}(\pi_{W})
, we measure the
\theta
-cost at
(X,Y,\mathbf{M})
according to
\pi_{W}
.

Remark
.

Let
\tau
be the protocol obtained by “making
\pi
standard.”
That is,
\tau(X,Y)
is equal to
\mu(X,Y)
;
\tau(M_{0})
is
\pi(M_{0})
, independent of
(X,Y)
.
Each odd
M_{i}
is sampled according to
\pi(M_{i}\mid X,M_{<i})
independent of
Y
, and each even
M_{i}
is sampled according to
\pi(M_{i}\mid Y,M_{<i})
independent of
X
.
Then
\tau
is a standard protocol such that

\tau(X,Y,\mathbf{M})={\pi(M_{0})\cdot\mu(X,Y)\cdot\prod_{\mathrm{odd}\,i\in[r]}\pi(M_{i}\mid X,M_{<i})\cdot\prod_{\mathrm{even}\,i\in[r]}\pi(M_{i}\mid Y,M_{<i})}.

The
\theta
-cost of
\pi
is simply the
\chi^{2}
-divergence from
\tau
to
\pi
plus one.

By the above connection to
\chi^{2}
-divergence, we have the following proposition.

Proposition 13
.

For any protocol
\pi
, we have

\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]=1.

Proof.

Let
\tau
be the protocol by making
\pi
standard as described in the remark above.
Then we have

\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})=\frac{\pi(X,Y,\mathbf{M})}{\tau(X,Y,\mathbf{M})}.

Therefore,

\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]=\sum_{(X,Y,\mathbf{M})}\pi(X,Y,\mathbf{M})\cdot\frac{\tau(X,Y,\mathbf{M})}{\pi(X,Y,\mathbf{M})}=1.

∎

By standard bounds on conditional probabilities, we have the following bound on the conditional cost.

Proposition 14
.

For events
W_{1},W_{2}
, we have

\theta_{\mu}(\pi\mid W_{1}\cap W_{2})\leq\frac{\theta_{\mu}(\pi\mid W_{1})}{\pi(W_{2}\mid W_{1})}.

Proof.

Since
\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})
is nonnegative, we have

\displaystyle\theta_{\mu}(\pi\mid W_{1}\cap W_{2})

\displaystyle=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi\mid W_{1}\cap W_{2}}\left[\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})\right]

\displaystyle=\sum_{(X,Y,\mathbf{M})}\pi(X,Y,\mathbf{M}\mid W_{1}\cap W_{2})\cdot\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})

\displaystyle\leq\sum_{(X,Y,\mathbf{M})}\frac{\pi(X,Y,\mathbf{M}\mid W_{1})}{\pi(W_{2}\mid W_{1})}\cdot\theta_{\mu}(\pi\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\theta_{\mu}(\pi\mid W_{1})}{\pi(W_{2}\mid W_{1})}.

∎

Next, the
\chi^{2}
-cost
measures the “communication cost” of a protocol: how different Alice’s input becomes in Bob’s view at the end of the communication compared to that in the input distribution.

Definition 15

(
\chi^{2}
-cost)
.

Let
\pi
be a generalized protocol, and
\mu
be a distribution over the inputs.
The
\chi^{2}
-cost of
\pi
by Alice with respect to
\mu
at
(X,Y,\mathbf{M})
is

\displaystyle\chi^{2}_{\mu,A}(\pi\,@\,X,Y,\mathbf{M})

\displaystyle:=\frac{\pi(X\mid\mathbf{M},Y)}{\mu(X\mid Y)};

the
\chi^{2}
-cost of
\pi
by Bob with respect to
\mu
at
(X,Y,\mathbf{M})
is

\displaystyle\chi^{2}_{\mu,B}(\pi\,@\,X,Y,\mathbf{M})

\displaystyle:=\frac{\pi(Y\mid\mathbf{M},X)}{\mu(Y\mid X)}.

The
\chi^{2}
-costs of
\pi
with respect to
\mu
are

\displaystyle\chi^{2}_{\mu,A}(\pi)

\displaystyle:=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi}\left[\chi^{2}_{\mu,A}(\pi\,@\,X,Y,\mathbf{M})\right],

\displaystyle\chi^{2}_{\mu,B}(\pi)

\displaystyle:=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi}\left[\chi^{2}_{\mu,B}(\pi\,@\,X,Y,\mathbf{M})\right].

For an event
W
, the
\chi^{2}
-costs of
\pi
with respect to
\mu
conditioned on
W
are

\displaystyle\chi^{2}_{\mu,A}(\pi\mid W)

\displaystyle:=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi\mid W}\left[\chi^{2}_{\mu,A}(\pi\,@\,X,Y,\mathbf{M})\right],

\displaystyle\chi^{2}_{\mu,B}(\pi\mid W)

\displaystyle:=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi\mid W}\left[\chi^{2}_{\mu,B}(\pi\,@\,X,Y,\mathbf{M})\right].

Remark
.

Similar to the
\theta
-cost,
\chi^{2}_{\mu,A}(\pi\mid W)
is also different from
\chi^{2}_{\mu,A}(\pi_{W})
.
The
\chi^{2}
-cost of
\pi
by Alice is the expected
\chi^{2}
-divergence from
\mu_{X\mid Y}
to
\pi_{X\mid Y,\mathbf{M}}
plus one.
Similarly, the
\chi^{2}
-cost of
\pi
by Bob is the expected
\chi^{2}
-divergence from
\mu_{Y\mid X}
to
\pi_{Y\mid X,\mathbf{M}}
plus one.
Observe that for standard protocols, if we measure the expected KL-divergence instead of the
\chi^{2}
-divergence, then we obtain the internal information costs:

\sum_{\mathrm{odd}\,i}I(X;M_{i}\mid Y,M_{<i})\qquad\textrm{and}\qquad\sum_{\mathrm{even}\,i}I(Y;M_{i}\mid X,M_{<i}).

Similar proofs to Proposition
13
and Proposition
14
give us the following two propositions.

Proposition 16
.

For any protocol
\pi
, we have

\mathop{\mathbb{E}}_{\pi}\left[\chi^{2}_{\mu,A}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]=1,

and

\mathop{\mathbb{E}}_{\pi}\left[\chi^{2}_{\mu,B}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]=1.

Proposition 17
.

For any events
W_{1},W_{2}
, we have

\chi^{2}_{\mu,A}(\pi\mid W_{1}\cap W_{2})\leq\frac{\chi^{2}_{\mu,A}(\pi\mid W_{1})}{\pi(W_{2}\mid W_{1})},

and

\chi^{2}_{\mu,B}(\pi\mid W_{1}\cap W_{2})\leq\frac{\chi^{2}_{\mu,B}(\pi\mid W_{1})}{\pi(W_{2}\mid W_{1})}.

3.4
Rectangle properties in generalized protocols

We will maintain the
rectangle property
for the generalized protocols throughout the proof.

Definition 18

(Rectangle property)
.

A generalized protocol
\pi
has the
rectangle property
with respect to
\mu
, if there exists nonnegative functions
g_{1}:\mathcal{X}\times\mathcal{M}\rightarrow\mathbb{R},g_{2}:\mathcal{Y}\times\mathcal{M}\rightarrow\mathbb{R}
such that

\pi(X,Y,\mathbf{M})={\mu(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})}.

Let
W
be an event,
(\pi\mid W)
has the rectangle property with respect to
\mu
if there exists nonnegative functions
g_{1}:\mathcal{X}\times\mathcal{M}\rightarrow\mathbb{R},g_{2}:\mathcal{Y}\times\mathcal{M}\rightarrow\mathbb{R}
such that

\pi(X,Y,\mathbf{M}\mid W)=\mu(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M}).

Equivalently,
\pi
has the rectangle property if for every transcript
\mathbf{M}
, the posterior distribution
\pi_{X,Y\mid\mathbf{M}}
is equal to
\mu
rescaled by some product function with one factor depending only on
X
and another factor depending only on
Y
.
Note that this property holds for any standard protocol, since each message
M_{i}
conditioned on
M_{<i}
only depends on one of
X
and
Y
.
Hence, for standard protocols, we have such product structure even conditioned on any prefix
M_{<i}
.

When decomposing a protocol for
k
instances, we need the following definition of the
partial rectangle property
.

Definition 19

(Partial rectangle property)
.

Let
\pi
be a generalized protocol such that
X=(X_{1},\ldots,X_{k})
and
Y=(Y_{1},\ldots,Y_{k})
.

\pi
satisfies the
partial rectangle property
with respect to
\mu^{k}
if there exists nonnegative functions
g_{1},g_{2},g_{3}
such that

\pi(X,Y,\mathbf{M})=\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M}).

Let
W
be an event,
(\pi\mid W)
has the partial rectangle property with respect to
\mu^{k}
if there exists nonnegative functions
g_{1},g_{2},g_{3}
such that

\pi(X,Y,\mathbf{M}\mid W)=\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M}).

Proposition 20
.

If
\pi
has the partial rectangle property, then
X_{<k}
and
Y_{k}
are independent conditioned on
X_{k},Y_{<k},\mathbf{M}
;
If
\pi\mid W
has the partial rectangle property, then
X_{<k}
and
Y_{k}
are independent conditioned on
X_{k},Y_{<k},\mathbf{M},W
.

Proof.

If
\pi
has the partial rectangle property, then

\displaystyle\kern-20.00003pt\pi(X_{<k},Y_{k}\mid X_{k},Y_{<k},\mathbf{M})

\displaystyle=\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})\cdot\pi(X_{k},Y_{<k},\mathbf{M})^{-1}

\displaystyle=\left(\mu^{k-1}(X_{<k},Y_{<k})\cdot g_{1}(X,\mathbf{M})\right)\cdot\left(\mu(X_{k},Y_{k})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})\cdot\pi(X_{k},Y_{<k},\mathbf{M})^{-1}\right).

Note that given
(X_{k},Y_{<k},\mathbf{M})
, the first factor only depends on
X_{<k}
, and the second factor only depends on
Y_{k}
.
By normalizing the two factors, we obtain that

\pi(X_{<k},Y_{k}\mid X_{k},Y_{<k},\mathbf{M})=\pi(X_{<k}\mid X_{k},Y_{<k},\mathbf{M})\cdot\pi(Y_{k}\mid X_{k},Y_{<k},\mathbf{M}).

The proof for
\pi\mid W
is almost identical.
We omit the details.
∎

For a protocol
\pi
, we define the follow sets that are related to the rectangle property and the partial rectangle property.

Definition 21
.

Let
\mathcal{U}_{X,M}(\pi)
be the set consisting of all possible pairs
(X,\mathbf{M})
.
Let
\mathcal{U}_{Y,M}(\pi)
be the set consisting of all possible pairs
(Y,\mathbf{M})
.
Let
\mathcal{U}_{X_{k},Y_{<k},M}(\pi)
be the set consisting of all possible triples
(X_{k},Y_{<k},\mathbf{M})
.

Let
\mathcal{S}_{\mathrm{rec}}(\pi)
be the collection of all possible events
S
such that there exist
S_{X,M}\subseteq\mathcal{U}_{X,M},S_{Y,M}\subseteq\mathcal{U}_{Y,M}
, and

S=\{(X,Y,\mathbf{M}):(X,\mathbf{M})\in S_{X,M}\wedge(Y,\mathbf{M})\in S_{Y,M}\}.

Let
\mathcal{S}_{\mathrm{pt}}(\pi)
be the collection of all possible events
S
such that there exist
S_{X,M}\subseteq\mathcal{U}_{X,M},S_{Y,M}\subseteq\mathcal{U}_{Y,M},S_{X_{k},Y_{<k},M}\subseteq\mathcal{U}_{X_{k},Y_{<k},M}
, and

S=\{(X,Y,\mathbf{M}):(X,\mathbf{M})\in S_{X,M}\wedge(Y,\mathbf{M})\in S_{Y,M}\wedge(X_{k},Y_{<k},\mathbf{M})\in S_{X_{k},Y_{<k},M}\}.

We may omit
\pi
and use
\mathcal{S}_{\mathrm{rec}}
,
\mathcal{S}_{\mathrm{pt}}
when there is no ambiguity.

Intuitively,
\mathcal{S}_{\mathrm{rec}}(\pi)
is the collection of events conditioned on which,
\pi
remains to have the rectangle property.
Similarly,
\mathcal{S}_{\mathrm{pt}}(\pi)
is the collection of events conditioned on which,
\pi
remains to have the partial rectangle property.

Proposition 22
.

We have the following properties about
\mathcal{S}_{\mathrm{rec}}
and
\mathcal{S}_{\mathrm{pt}}
:

(i)

if
\pi
has the rectangle property, then for any
S\in\mathcal{S}_{\mathrm{rec}}
,
(\pi\mid S)
has the rectangle property;

(ii)

if
\pi
has the partial rectangle property, then for any
S\in\mathcal{S}_{\mathrm{pt}}
,
(\pi\mid S)
has the partial rectangle property;

(iii)

\mathcal{S}_{\mathrm{rec}}\subseteq\mathcal{S}_{\mathrm{pt}}
;

(iv)

both
\mathcal{S}_{\mathrm{rec}}
and
\mathcal{S}_{\mathrm{pt}}
are closed under intersection.

Proof.

For (i), suppose
S=\{(X,Y,\mathbf{M}):(X,\mathbf{M})\in S_{X,M}\wedge(Y,\mathbf{M})\in S_{Y,M}\}
.
Then

\pi(X,Y,\mathbf{M}\mid S)=\pi(X,Y,\mathbf{M})\cdot\mathbf{1}_{S_{X,M}}(X,\mathbf{M})\cdot\mathbf{1}_{S_{Y,M}}(Y,\mathbf{M})\cdot\pi(S)^{-1}.

Thus, if
\pi
has the rectangle property, then
(\pi\mid S)
has the rectangle property.

Similarly for (ii), suppose

S=\{(X,Y,\mathbf{M}):(X,\mathbf{M})\in S_{X,M}\wedge(Y,\mathbf{M})\in S_{Y,M}\wedge(X_{k},Y_{<k},\mathbf{M})\in S_{X_{k},Y_{<k},M}\}.

Then

\pi(X,Y,\mathbf{M}\mid S)=\pi(X,Y,\mathbf{M})\cdot\mathbf{1}_{S_{X,M}}(X,\mathbf{M})\cdot\mathbf{1}_{S_{Y,M}}(Y,\mathbf{M})\cdot\mathbf{1}_{S_{X_{k},Y_{<k},M}}(X_{k},Y_{<k},\mathbf{M})\cdot\pi(S)^{-1}.

Thus, if
\pi
has the partial rectangle property, then
(\pi\mid S)
has the partial rectangle property.

(iii) and (iv) follow from the definitions.
∎

4
Main Setup

In this section, we set up the main framework for proving our main theorems.

Theorem
1
(restated).

For any
\{0,1\}
-valued function
f
, we have

\mathbf{R}^{(r)}_{1/2+2^{-n}}(f^{\oplus n})\geq n\cdot\left(r^{-O(r)}\cdot\mathbf{R}^{(r)}_{2/3}(f)-1\right).

Theorem
2
(restated).

Let
c>0
be a sufficiently large constant.
Fix
\alpha\in(0,r^{-cr})
and
C_{A},C_{B}\geq 2c\log(r/\alpha)
.
Let
f:\mathcal{X}\times\mathcal{Y}\rightarrow\{0,1\}
be a function, and
\mu
be a distribution over
\mathcal{X}\times\mathcal{Y}
.
Suppose
f
satisfies

\mathrm{suc}_{\mu}({f;C_{A},C_{B},r})\leq 1/2+\alpha/2,

then for any integer
n\geq 2
, we have

\mathrm{suc}_{\mu^{n}}(f^{\oplus n};2^{-8}r^{-1}n\cdot C_{A},2^{-8}r^{-1}n\cdot C_{B},r)\leq\frac{1}{2}+\frac{\alpha^{2^{-12}n}}{2}.

We first show that Theorem
2
implies Theorem
1
.

Proof of Theorem
1
.

Fix a function
f
, suppose there is an
r
-round protocol
\pi
for
f^{\oplus n}
with communication cost
T
and success probability
1/2+2^{-n}
.
Let
\alpha=r^{-2cr}
for a sufficiently large
c
, then
\pi
has success probability more than
1/2+\alpha^{2^{-12}n}/2
.
By setting
C_{A}=C_{B}=2^{8}r\cdot T/n+2c\log(r/\alpha)=O(r\cdot T/n+r\log r)
, Theorem
2
implies
\mathrm{suc}_{\mu}(f;C_{A},C_{B},r)>1/2+\alpha/2
, i.e., for distribution
\mu
, there is an
r
-round protocol with communication cost at most
O(r\cdot T/n+r\log r)
in each round and success probability at least
1/2+r^{-O(r)}
.

Since this holds for
any

\mu
, by Yao’s minimax lemma, there is an
r
-round randomized protocol with
O(r\cdot T/n+r\log r)
communication in each round and success probability at least
1/2+r^{-O(r)}
for all inputs.
By simply running such a protocol
r^{O(r)}
times in parallel and outputting the majority, we obtain an
r
-round protocol with
r^{O(r)}\cdot(T/n+1)
total communication and success probability
2/3
.
Thus, we obtain
\mathbf{R}_{2/3}^{(r)}(f)\leq r^{O(r)}\cdot(\mathbf{R}_{1/2+2^{-n}}(f^{\oplus n})/n+1)
.
Rearranging the terms gives Theorem
1
.
∎

In the rest of the paper, we will focus on proving Theorem
2
.
Let us fix a sufficiently large constant
c>0
, parameters
C_{A},C_{B},r,\alpha
, function
f
and input distribution
\mu
satisfying its premises.
As mentioned in Section
2
, we will first define a potential function based on the costs and advantage, and then show that the potential function value decreases as we decrement
n
.

Definition 23

(Potential functions)
.

For an
r
-round generalized protocol
\pi
for
f^{\oplus n}
and an event
W
, we define the potential function
\phi_{n}(\pi\mid W)
(and
\phi_{n}^{\mathrm{cost}},\phi_{n}^{\mathrm{adv}}
) as follows:

\displaystyle\phi_{n}(\pi\mid W)

\displaystyle=\underbrace{\log\theta_{\mu^{n}}(\pi\mid W)+\frac{\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu,A}(\pi\mid W)+\frac{\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu,B}(\pi\mid W)}_{\phi_{n}^{\mathrm{cost}}(\pi\mid W)}

\displaystyle\qquad+\underbrace{32\log\left(\mathop{\mathbb{E}}_{\pi\mid W}\left[\mathrm{adv}_{\pi}(f^{\oplus n}(X,Y)\mid\mathbf{M},W)\right]^{-1}\right)}_{\phi_{n}^{\mathrm{adv}}(\pi\mid W)}.

We also define
\phi_{n,\mathrm{pt}}(\pi\mid W)
(and
\phi_{n,\mathrm{pt}}^{\mathrm{adv}}
) as follows:

\displaystyle\phi_{n,\mathrm{pt}}(\pi\mid W)

\displaystyle=\log\theta_{\mu^{n}}(\pi\mid W)+\frac{\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu,A}(\pi\mid W)+\frac{\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu,B}(\pi\mid W)

\displaystyle\qquad+\underbrace{32\log\left(\mathop{\mathbb{E}}_{\pi\mid W}\left[\mathrm{adv}_{\pi}(f^{\oplus n}(X,Y)\mid X_{n},Y_{<n},\mathbf{M},W)\right]^{-1}\right)}_{\phi_{n,\mathrm{pt}}^{\mathrm{adv}}(\pi\mid W)}.

When
W
is the whole sample space, we may simply write
\phi_{n}(\pi)
or
\phi_{n,\mathrm{pt}}(\pi)
.

The first three terms in both potential functions
\phi_{n}^{\mathrm{cost}}
are the (normalized) costs of
\pi
.
They are small if
\pi
has low
\theta
-cost and low
\chi^{2}
-costs.
The last term in both potential functions depends on the expected advantage.

\phi_{n}
uses the standard advantage, while
\phi_{n,\mathrm{pt}}
uses the advantage conditioned not only on the transcript, but also
X_{n}
and
Y_{<n}
.
As we will see later, it is used when decomposing
\pi
.
The last term is small if the protocol has high advantage.
By Proposition
11
, knowing more could only increase the expected advantage.
Hence,
\phi_{n,\mathrm{pt}}(\pi)
is always at most
\phi_{n}(\pi)
.

We have the following lower bound on the potential of
\pi
conditioned on
W
.
In particular, when
W
is the whole sample space, the potential function is nonnegative.

Lemma 24
.

For any
\pi
, event
W
and any
n\geq 1
, we must have

\phi_{n}(\pi\mid W)\geq-3\log(1/\pi(W)).

Proof.

For the
\theta
-cost, by the convexity of
1/x
, we have

\displaystyle\theta_{\mu^{n}}(\pi\mid W)^{-1}

\displaystyle=\mathop{\mathbb{E}}_{\pi\mid W}\left[\theta_{\mu^{n}}(\pi\,@\,X,Y,\mathbf{M})\right]^{-1}

\displaystyle\leq\mathop{\mathbb{E}}_{\pi\mid W}\left[\theta_{\mu^{n}}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]

which by the fact that
\theta_{\mu^{n}}(\pi\,@\,X,Y,\mathbf{M})
is nonnegative, is

\displaystyle\leq\pi(W)^{-1}\cdot\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu^{n}}(\pi\,@\,X,Y,\mathbf{M})^{-1}\right]

which by Proposition
13
, is

\displaystyle=\pi(W)^{-1}.

Hence,
\log\theta_{\mu^{n}}(\pi\mid W)\geq-\log(1/\pi(W))
.
Similarly, we also have
\log\chi^{2}_{\mu^{n},A}(\pi\mid W)\geq-\log(1/\pi(W))
, and
\log\chi^{2}_{\mu^{n},B}(\pi\mid W)\geq-\log(1/\pi(W))
.
By the fact that
\log(1/\alpha)\leq C_{A}-c\log(r/\alpha)
and
\log(1/\alpha)\leq C_{B}-c\log(r/\alpha)
, we have

\phi_{n}^{\mathrm{adv}}(\pi\mid W)\geq-3\log(1/\pi(W)).

The advantage is always at most
1
.
Therefore, the last term is nonnegative.
Hence,
\phi_{n}(\pi\mid W)\geq-3\log(1/\pi(W))
.
∎

The following lemma shows an upper bound on the potential of a
deterministic
standard protocol
\pi
computing
f^{\oplus n}
.

Lemma 25
.

Let
\pi
be a
deterministic
standard protocol where Alice sends at most
T_{A}
bits in each (odd) round and Bob sends at most
T_{B}
bits in each (even) round.
If it computes
f^{\oplus n}
with probability
\frac{1}{2}+\frac{\sigma}{2}
under input distribution
\mu^{n}
, then

\phi_{n}(\pi)\leq\lceil r/2\rceil\cdot\frac{T_{A}\cdot\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}+\lfloor r/2\rfloor\cdot\frac{T_{B}\cdot\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}+32\log(1/\sigma).

Proof.

By the property of a standard protocol,
\theta_{\mu^{n}}(\pi\,@\,X,Y,\mathbf{M})=1
for any
X,Y,\mathbf{M}
in the support of
\pi
.
Hence,
\log\theta_{\mu^{n}}(\pi)=0
.

For the
\chi^{2}
-cost by Alice, we have

\displaystyle\chi^{2}_{\mu^{n},A}(\pi)

\displaystyle=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi}\left[\frac{\pi(X\mid\mathbf{M},Y)}{\mu^{n}(X\mid Y)}\right]

\displaystyle=\mathop{\mathbb{E}}_{(X,Y,\mathbf{M})\sim\pi}\left[\frac{\pi(X\mid\mathbf{M},Y)}{\pi(X\mid Y)}\right]

\displaystyle=\sum_{(X,Y,\mathbf{M})}\frac{\pi(X,Y,\mathbf{M})\pi(X\mid\mathbf{M},Y)}{\pi(X\mid Y)}

\displaystyle=\sum_{(X,Y,\mathbf{M})}\pi(\mathbf{M}\mid X,Y)\pi(X\mid Y,\mathbf{M})\pi(Y).

Since
\pi
is a
deterministic
standard protocol,
M_{0}
is fixed.
All even messages
(M_{2},M_{4},\ldots)
are sent by Bob such that each
M_{i}
is determined by
M_{<i}
and
Y
.
Therefore,
(M_{2},M_{4},\ldots)
are determined by all odd messages
(M_{1},M_{3},\ldots)
and
Y
.
Denote
(M_{2},M_{4},\ldots)
by
M_{\mathrm{even}\,}
and
(M_{1},M_{3},\ldots)
by
M_{\mathrm{odd}\,}
, we have

\displaystyle\quad\,\,\sum_{(X,Y,\mathbf{M})}\pi(\mathbf{M}\mid X,Y)\pi(X\mid Y,\mathbf{M})\pi(Y)

\displaystyle=\sum_{(X,Y,\mathbf{M})}\pi(M_{\mathrm{even}\,}\mid X,Y,M_{\mathrm{odd}\,})\pi(M_{\mathrm{odd}\,}\mid X,Y)\pi(X\mid Y,M_{\mathrm{odd}\,},M_{\mathrm{even}\,})\pi(Y)

\displaystyle=\sum_{(X,Y,\mathbf{M})}\pi(M_{\mathrm{even}\,}\mid X,Y,M_{\mathrm{odd}\,})\pi(M_{\mathrm{odd}\,}\mid X,Y)\pi(X\mid Y,M_{\mathrm{odd}\,})\pi(Y)

\displaystyle=\sum_{(X,Y,\mathbf{M})}\pi(M_{\mathrm{odd}\,}\mid X,Y)\pi(X,M_{\mathrm{even}\,}\mid Y,M_{\mathrm{odd}\,})\pi(Y)

\displaystyle\leq\sum_{(X,Y,\mathbf{M})}\pi(X,M_{\mathrm{even}\,}\mid Y,M_{\mathrm{odd}\,})\pi(Y)

\displaystyle=\sum_{(Y,M_{\mathrm{odd}\,})}\pi(Y)

\displaystyle=\sum_{M_{\mathrm{odd}\,}}1

\displaystyle\leq 2^{\lceil r/2\rceil T_{A}},

where the last inequality uses the fact that Alice’s messages have at most
T_{A}
bits in each (odd) round.
Similarly, we have
\chi^{2}_{\pi}(\mu,B)\leq 2^{\lfloor r/2\rfloor T_{B}}
.

Finally, by the connection between advantage and success probability,
\mathop{\mathbb{E}}_{\pi}\left[\mathrm{adv}_{\pi}(f^{\oplus n}(X,Y)\mid\mathbf{M})\right]\geq\sigma
.
Hence,

\phi_{n}(\pi)\leq\lceil r/2\rceil\cdot\frac{T_{A}\cdot\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}+\lfloor r/2\rfloor\cdot\frac{T_{B}\cdot\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}+32\log(1/\sigma).

∎

In the rest of the paper, we will prove the following lemma, which shows that given a protocol for
f^{\oplus k}
, we can construct a protocol for
f^{\oplus k-1}
with a lower potential.

Lemma 26
.

For
k\geq 2
,

if
there is a generalized protocol
\pi
for
f^{\oplus k}
with the rectangle property with respect to
\mu^{k}
and an event
V\in\mathcal{S}_{\mathrm{rec}}(\pi)
such that
\pi(V)\geq 2^{-12}
,

then
there is a generalized protocol
\pi_{\mathrm{new}}
for
f^{\oplus k-1}
with the rectangle property with respect to
\mu^{k-1}
and an event
V_{\mathrm{new}}\in\mathcal{S}_{\mathrm{rec}}(\pi_{\mathrm{new}})
such that
\pi_{\mathrm{new}}(V_{\mathrm{new}})\geq 2^{-12}
, and

\phi_{k-1}(\pi_{\mathrm{new}}\mid V_{\mathrm{new}})\leq\phi_{k}(\pi\mid V)-\frac{1}{16}\log(1/\alpha).

Our main theorem is a direct corollary of Lemma
24
,
25
and
26
.

Proof of Theorem
2
.

Since
C_{A},C_{B}\geq 2c\log(r/\alpha)
,
C_{A}/2\leq C_{A}-c\log(r/\alpha)
and
C_{B}/2\leq C_{B}-c\log(r/\alpha)
.
Suppose there exists an
r
-round protocol
\pi^{(n)}
where Alice sends at most

2^{-8}r^{-1}n\cdot C_{A}\leq 2^{-7}r^{-1}n(C_{A}-c\log(r/\alpha))

bits in each round and Bob sends at most

2^{-8}r^{-1}n\cdot C_{B}\leq 2^{-7}r^{-1}n(C_{B}-c\log(r/\alpha))

in each round, which computes
f^{\oplus n}
correctly with probability
1/2+\sigma/2
when the input is sampled from
\mu^{n}
.
By fixing the randomness, we may assume that
\pi^{(n)}
is deterministic.
Then by Lemma
25
, we have

\phi_{n}(\pi^{(n)})\leq 2^{-7}n\log(1/\alpha)+32\log(1/\sigma).

Now we set
V^{(n)}
to be the whole sample space of
\pi^{(n)}
.
Clearly,
\pi^{(n)}
and
V^{(n)}
satisfy the premise of Lemma
26
.
By inductively applying Lemma
26
a total of
n-1
times, we obtain a protocol
\pi^{(1)}
for
f
and event
V^{(1)}
such that
\pi^{(1)}(V^{(1)})\geq 2^{-12}
and

\phi_{1}(\pi^{(1)}\mid V^{(1)})\leq\phi_{n}(\pi^{(n)})-\frac{n-1}{16}\cdot\log(1/\alpha).

On the other hand, Lemma
24
implies that the LHS is at least
-3\log(1/\pi^{(1)}(V^{(1)}))\geq-36
, implying that

\phi_{n}(\pi^{(n)})\geq\frac{n-1}{16}\cdot\log(1/\alpha)-36\geq 2^{-6}n\log(1/\alpha),

since
n\geq 2
and
\alpha<r^{-cr}
for a sufficiently large
c
.

Combining the above upper and lower bounds on
\phi_{n}(\pi^{(n)})
, we obtain

2^{-7}n\log(1/\alpha)+32\log(1/\sigma)\geq 2^{-6}n\log(1/\alpha),

implying that
\log(1/\sigma)\geq 2^{-12}n\log(1/\alpha)
, i.e.,

\sigma\leq\alpha^{2^{-12}n}.

This proves the theorem.
∎

5
Decomposition of Generalized Protocols

To prove Lemma
26
, we will decompose a generalized protocol
\pi
for
f^{\oplus k}
into a protocol
\pi_{<k}
for
f^{\oplus k-1}
and a protocol
\pi_{k}
for
f
such that the costs of
\pi_{<k}
and
\pi_{k}
“add up” to the costs of
\pi
pointwisely.
For simplicity of notations, we will assume that
r
is even
from now on, the case of odd
r
is similar.

5.1
Definition of
\pi_{<k}
and
\pi_{k}

Fix a generalized protocol
\pi
with the rectangle property with respect to
\mu^{k}
.
Let
(X,Y,\mathbf{M})\sim\pi
.
We view the following tuple as the
r
-round generalized protocol
\pi_{<k}
on inputs
(X_{<k},Y_{<k})

\left(X_{<k},Y_{<k},\left(M_{0}\circ X_{k},M_{1},M_{2},\ldots,M_{r-1},M_{r}\right)\right),

where we append
X_{k}
to
M_{0}
.
We view the following tuple as the
r
-round generalized protocol
\pi_{k}
on inputs
(X_{k},Y_{k})

\left(X_{k},Y_{k},\left(M_{0},Y_{<k}\circ M_{1},M_{2},\ldots,M_{r-1},M_{r}\right)\right),

where we prepend
Y_{<k}
to
M_{1}
.

It is useful to think that
\pi_{<k}
,
\pi_{k}
and
\pi
are the
same
distribution over the
same
sample space, only their inputs and transcripts are defined in different ways.
Therefore, we may use
\pi_{<k}(W),\pi_{k}(W),\pi(W)
interchangeably when measuring the probability of an event
W
.

For simplicity of notations, we use
\mathbf{M}^{(\pi_{<k})}
to denote
\left(M_{0}\circ X_{k},M_{1},M_{2},\ldots,M_{r}\right)
, the transcript of
\pi_{<k}
, and use
\mathbf{M}^{(\pi_{k})}
to denote
\left(M_{0},Y_{<k}\circ M_{1},M_{2},\ldots,M_{r}\right)
, the transcript of
\pi_{k}
.

M_{i}^{(\pi_{<k})}
and
M_{i}^{(\pi_{k})}
are defined similarly.
Since
(X,Y,\mathbf{M})
determines
(X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})})
, we define
\theta
-cost of
\pi_{<k}
at
(X,Y,\mathbf{M})
as

\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y,\mathbf{M}):=\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})}),

where
(X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})})
is the triple determined by
(X,Y,\mathbf{M})
.
Note that this cost does not depend on
Y_{k}
given the other parts of
(X,Y,\mathbf{M})
.
The
\chi^{2}
-costs of
\pi_{<k}
and the costs of
\pi_{k}
at
(X,Y,\mathbf{M})
are defined similarly.

In the remainder of this section, we will analyze
\pi_{<k}
and
\pi_{k}
.
First, we observe that the partial rectangle property of
\pi
implies the rectangle properties of
\pi_{<k}
and
\pi_{k}
.

Proposition 27
.

Let
W
be an event such that
\pi\mid W
has the partial rectangle property with respect to
\mu^{k}
.
Then
\pi_{<k}\mid W
has the rectangle property with respect to
\mu^{k-1}
, and
\pi_{k}\mid W
has the rectangle property with respect to
\mu
.

Proof.

Since
\pi\mid W
has the partial rectangle property, there exists
g_{1},g_{2},g_{3}
such that

\pi(X,Y,\mathbf{M}\mid W)=\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M}).

Thus,

\displaystyle\pi_{<k}(X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})}\mid W)

\displaystyle=\pi(X,Y_{<k},\mathbf{M}\mid W)

\displaystyle=\sum_{Y_{k}}\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})

\displaystyle=\mu^{k-1}(X_{<k},Y_{<k})\cdot g_{1}(X,\mathbf{M})\cdot\left(\sum_{Y_{k}}\mu(X_{k},Y_{k})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})\right).

Note that the second factor is a function of only
X_{<k}
and
\mathbf{M}^{(\pi_{<k})}
, the third factor is a function of only
Y_{<k}
and
\mathbf{M}^{(\pi_{<k})}
.

For
\pi_{k}
, we have

\displaystyle\pi_{k}(X_{k},Y_{k},\mathbf{M}^{(\pi_{k})}\mid W)

\displaystyle=\pi(X_{k},Y,\mathbf{M}\mid W)

\displaystyle=\sum_{X_{<k}}\mu^{k}(X,Y)\cdot g_{1}(X,\mathbf{M})\cdot g_{2}(Y,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})

\displaystyle=\mu(X_{k},Y_{k})\cdot\left(\sum_{X_{<k}}g_{1}(X,\mathbf{M})\cdot g_{3}(X_{k},Y_{<k},\mathbf{M})\right)\cdot g_{2}(Y,\mathbf{M}).

The second factor depends only on
X_{k}
and
\mathbf{M}^{(\pi_{k})}
, and the third factor depends only on
Y_{k}
and
\mathbf{M}^{(\pi_{k})}
.
This proves the lemma.
∎

Similarly, we have the following relation between
\mathcal{S}_{\mathrm{rec}}(\pi_{<k}),\mathcal{S}_{\mathrm{rec}}(\pi_{k})
and
\mathcal{S}_{\mathrm{pt}}(\pi)
.

Proposition 28
.

We have
\mathcal{S}_{\mathrm{rec}}(\pi_{<k})\subseteq\mathcal{S}_{\mathrm{pt}}(\pi)
and
\mathcal{S}_{\mathrm{rec}}(\pi_{k})\subseteq\mathcal{S}_{\mathrm{pt}}(\pi)
.

Proof.

Let
S\in\mathcal{S}_{\mathrm{rec}}(\pi_{<k})
be an event such that

S=\{(X,Y,\mathbf{M}):(X_{<k},\mathbf{M}^{(\pi_{<k})})\in S_{X,M}\wedge(Y_{<k},\mathbf{M}^{(\pi_{<k})})\in S_{Y,M}\},

for sets
S_{X,M}\in\mathcal{U}_{X,M}(\pi_{<k})
and
S_{Y,M}\in\mathcal{U}_{Y,M}(\pi_{<k})
.
Hence,

S=\{(X,Y,\mathbf{M}):(X,\mathbf{M})\in S_{X,M}\wedge(X_{k},Y_{<k},\mathbf{M})\in S_{Y,M}\}

is a set in
\mathcal{S}_{\mathrm{pt}}(\pi)
.

The proof of
\mathcal{S}_{\mathrm{rec}}(\pi_{k})\subseteq\mathcal{S}_{\mathrm{pt}}(\pi)
is similar, and we omit the details.
∎

5.2
Decomposition of the costs

Below is the first main lemma of the decomposition, stating that the product of
\theta
-costs of
\pi_{<k}
and
\pi_{k}
is equal to that of
\pi
pointwisely.

Lemma 29
.

The product of the
\theta
-costs of
\pi_{<k}
and
\pi_{k}
at
(X,Y,\mathbf{M})
is
\theta
-cost of
\pi
at
(X,Y,\mathbf{M})
,

\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\theta_{\mu}(\pi_{k}\,@\,X,Y,\mathbf{M})=\theta_{\mu^{k}}(\pi\,@\,X,Y,\mathbf{M}).

Proof.

By definition, we have

\displaystyle\kern 12.50002pt\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi_{<k}(X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})}\mid M_{0}^{(\pi_{<k})})}{\mu^{k-1}(X_{<k},Y_{<k})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi_{<k}(M_{i}^{(\pi_{<k})}\mid X_{<k},M_{<i}^{(\pi_{<k})})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi_{<k}(M_{i}^{(\pi_{<k})}\mid Y_{<k},M_{<i}^{(\pi_{<k})})}

\displaystyle=\frac{\pi(X,Y_{<k},\mathbf{M}\mid X_{k},M_{0})}{\mu^{k-1}(X_{<k},Y_{<k})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}

\displaystyle=\frac{\pi(X_{<k},Y_{<k},\mathbf{M}\mid X_{k},M_{0})}{\mu^{k-1}(X_{<k},Y_{<k})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}.

(2)

Similarly,

\displaystyle\kern 12.50002pt\theta_{\mu}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi_{k}(X_{k},Y_{k},\mathbf{M}^{(\pi_{k})}\mid M_{0}^{(\pi_{k})})}{\mu(X_{k},Y_{k})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi_{k}(M_{i}^{(\pi_{k})}\mid X_{k},M_{<i}^{(\pi_{k})})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi_{k}(M_{i}^{(\pi_{k})}\mid Y_{k},M_{<i}^{(\pi_{k})})}

\displaystyle=\frac{\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu(X_{k},Y_{k})}\cdot\frac{1}{\pi(Y_{<k},M_{1}\mid X_{k},M_{0})}\cdot\prod_{\mathrm{odd}\,i\in[3,r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}

\displaystyle=\frac{\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu(X_{k},Y_{k})\cdot\pi(Y_{<k}\mid X_{k},M_{0})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}.

(3)

Combining Equation (
2
) and (
3
), we have

\displaystyle\kern 12.50002pt\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\theta_{\mu}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi(X_{<k},Y_{<k},\mathbf{M}\mid X_{k},M_{0})}{\mu^{k-1}(X_{<k},Y_{<k})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}

\displaystyle\qquad\qquad\cdot\frac{\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu(X_{k},Y_{k})\cdot\pi(Y_{<k}\mid X_{k},M_{0})}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X_{k},Y_{<k},M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}

\displaystyle=\frac{\pi(X_{<k},Y_{<k},\mathbf{M}\mid X_{k},M_{0})\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu^{k}(X,Y)\pi(Y_{<k}\mid X_{k},M_{0})}\cdot\frac{1}{\pi(\mathbf{M}\mid X_{k},Y_{<k},M_{0})}

\displaystyle\qquad\qquad\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{i})}

\displaystyle=\frac{\pi(X_{<k}\mid X_{k},Y_{<k},\mathbf{M})\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu^{k}(X,Y)}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}.

Then by the rectangle property of
\pi
and Proposition
20
,
Y_{k}
is independent of
X_{<k}
conditioned on
(X_{k},Y_{<k},\mathbf{M})
.
It is equal to

\displaystyle\kern-20.00003pt\frac{\pi(X_{<k}\mid X_{k},Y,\mathbf{M})\pi(X_{k},Y,\mathbf{M}\mid M_{0})}{\mu^{k}(X,Y)}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}

\displaystyle=\frac{\pi(X,Y,\mathbf{M}\mid M_{0})}{\mu^{k}(X,Y)}\cdot\prod_{\mathrm{odd}\,i\in[r]}\frac{1}{\pi(M_{i}\mid X,M_{<i})}\cdot\prod_{\mathrm{even}\,i\in[r]}\frac{1}{\pi(M_{i}\mid Y,M_{<i})}

\displaystyle=\theta_{\mu^{k}}(\pi\,@\,X,Y,\mathbf{M}).

This proves the lemma.

The second main lemma of the decomposition states that the product of the
\chi^{2}
-costs of
\pi_{<k}
and
\pi_{k}
is also equal to that of
\pi
pointwisely.

Lemma 30
.

The product of the
\chi^{2}
-costs of
\pi_{<k}
and
\pi_{k}
at
(X,Y,\mathbf{M})
is the
\chi^{2}
-cost of
\pi
at
(X,Y,\mathbf{M})
by Alice and Bob respectively,

\displaystyle\chi^{2}_{\mu^{k-1},A}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\chi^{2}_{\mu,A}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\chi^{2}_{\mu^{k},A}(\pi\,@\,X,Y,\mathbf{M}),

\displaystyle\chi^{2}_{\mu^{k-1},B}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\chi^{2}_{\mu,B}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\chi^{2}_{\mu^{k},B}(\pi\,@\,X,Y,\mathbf{M}).

Proof.

For the
\chi^{2}
-cost by Alice, by definition, we have

\displaystyle\chi^{2}_{\mu^{k-1},A}(\pi_{<k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi_{<k}(X_{<k}\mid Y_{<k},\mathbf{M}^{(\pi_{<k})})}{\mu^{k-1}(X_{<k}\mid Y_{<k})}

\displaystyle=\frac{\pi(X_{<k}\mid X_{k},Y_{<k},\mathbf{M})}{\mu^{k-1}(X_{<k}\mid Y_{<k})},

and

\displaystyle\chi^{2}_{\mu,A}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi_{k}(X_{k}\mid Y_{k},\mathbf{M}^{(\pi_{k})})}{\mu(X_{k}\mid Y_{k})}

\displaystyle=\frac{\pi(X_{k}\mid Y,\mathbf{M})}{\mu(X_{k}\mid Y_{k})}.

Hence, by partial rectangle property of
\pi
and Proposition
20
, their product is equal to

\displaystyle\kern 12.50002pt\chi^{2}_{\mu^{k-1},A}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\chi^{2}_{\mu,A}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi(X_{<k}\mid X_{k},Y_{<k},\mathbf{M})}{\mu^{k-1}(X_{<k}\mid Y_{<k})}\cdot\frac{\pi(X_{k}\mid Y,\mathbf{M})}{\mu(X_{k}\mid Y_{k})}

\displaystyle=\frac{\pi(X_{<k}\mid X_{k},Y,\mathbf{M})\cdot\pi(X_{k}\mid Y,\mathbf{M})}{\mu^{k}(X\mid Y)}

\displaystyle=\frac{\pi(X\mid Y,\mathbf{M})}{\mu^{k}(X\mid Y)}

\displaystyle=\chi^{2}_{\mu^{k},A}(\pi\,@\,X,Y,\mathbf{M}).

The
\chi^{2}
-cost for Bob is similar,

\displaystyle\kern 12.50002pt\chi^{2}_{\mu^{k-1},B}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\chi^{2}_{\mu,B}(\pi_{k}\,@\,X,Y,\mathbf{M})

\displaystyle=\frac{\pi(Y_{<k}\mid X,\mathbf{M})}{\mu^{k-1}(Y_{<k}\mid X_{<k})}\cdot\frac{\pi(Y_{k}\mid X_{k},Y_{<k},\mathbf{M})}{\mu(Y_{k}\mid X_{k})}

\displaystyle=\frac{\pi(Y_{<k}\mid X,\mathbf{M})\cdot\pi(Y_{k}\mid X,Y_{<k},\mathbf{M})}{\mu^{k}(Y\mid X)}

\displaystyle=\chi^{2}_{\mu^{k},B}(\pi\,@\,X,Y,\mathbf{M}).

This proves the lemma.
∎

Lemma 31
.

\pi\mid U
has the
partial rectangle property
with respect to
\mu^{k}
, and

\phi_{k,\mathrm{pt}}(\pi\mid U)\leq\phi_{k}(\pi\mid V)-13\log(1/\pi(U\mid V)).

Proof.

By definition, we have

\displaystyle\phi_{k,\mathrm{pt}}(\pi\mid U)

\displaystyle=\log\theta_{\mu^{k}}(\pi\mid U)+\frac{\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu^{k},A}(\pi\mid U)+\frac{\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu^{k},B}(\pi\mid U)

\displaystyle\qquad+32\log\left(\mathop{\mathbb{E}}_{\pi\mid U}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},U)\right]^{-1}\right).

By Proposition
14
, Proposition
17
and the fact that
U\subseteq V
, we have

\displaystyle\log\theta_{\mu^{k}}(\pi\mid U)

\displaystyle\leq\log\theta_{\mu^{k}}(\pi\mid V)+\log(1/\pi(U\mid V))

\displaystyle\log\chi^{2}_{\mu^{k},A}(\pi\mid U)

\displaystyle\leq\log\chi^{2}_{\mu^{k},A}(\pi\mid V)+\log(1/\pi(U\mid V))

\displaystyle\log\chi^{2}_{\mu^{k},B}(\pi\mid U)

\displaystyle\leq\log\chi^{2}_{\mu^{k},B}(\pi\mid V)+\log(1/\pi(U\mid V)).

Then since
U
is the maximizer of Equation (
4
) and
V\in\mathcal{S}_{\mathrm{rec}}(\pi)\subseteq\mathcal{S}_{\mathrm{pt}}(\pi)
,

\displaystyle\kern-20.00003pt\mathop{\mathbb{E}}_{\pi\mid U}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},U)\right]

\displaystyle\geq\pi(U)^{-1/2}\cdot\pi(V)^{1/2}\cdot\mathop{\mathbb{E}}_{\pi\mid V}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},V)\right]

\displaystyle=\pi(U\mid V)^{-1/2}\cdot\mathop{\mathbb{E}}_{\pi\mid V}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},V)\right].

Since knowing less could only decrease the advantage (Proposition

),

\mathop{\mathbb{E}}_{\pi\mid V}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},V)\right]\geq\mathop{\mathbb{E}}_{\pi\mid V}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid\mathbf{M},V)\right].

Combining the inequalities and using the fact that
\log(1/\alpha)<C_{A}-c\log(r/a)
and
\log(1/\alpha)<C_{B}-c\log(r/a)
, we have

\displaystyle\phi_{k,\mathrm{pt}}(\pi\mid U)

\displaystyle\leq\log\theta_{\mu^{k}}(\pi\mid V)+\frac{\log(1/\alpha)}{C_{A}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu^{k},A}(\pi\mid V)+\frac{\log(1/\alpha)}{C_{B}-c\log(r/\alpha)}\cdot\log\chi^{2}_{\mu^{k},B}(\pi\mid V)

\displaystyle\qquad+32\log\left(\mathop{\mathbb{E}}_{\pi\mid V}\left[f^{\oplus k}(X,Y)\mid\mathbf{M},V\right]^{-1}\right)+3\log(1/\pi(U\mid V))-16\log(1/\pi(U\mid V))

\displaystyle=\phi_{k}(\pi\mid V)-13\log(1/\pi(U\mid V)).

This proves the lemma.
∎

Lemma 33

\{(X,Y,\mathbf{M}):(X_{k},Y_{<k},\mathbf{M})\in S\}

Proof.

By Lemma
29
, we have

\displaystyle\quad\,\,\theta_{\mu^{k}}(\pi\mid S\cap U)

\displaystyle=\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu^{k}}(\pi\,@\,X,Y,\mathbf{M})\mid S\cap U\right]

\displaystyle=\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y,\mathbf{M})\cdot\theta_{\mu}(\pi_{k}\,@\,X,Y,\mathbf{M})\mid S\cap U\right].

\pi_{k}

.
Thus, it is equal to

\mathop{\mathbb{E}}_{\pi}\left[\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y_{<k},\mathbf{M})\cdot\theta_{\mu}(\pi_{k}\,@\,X_{k},Y,\mathbf{M})\mid S\cap U\right].

Since

.

(ii).

and

\displaystyle\kern 12.50002pt\mathop{\mathbb{E}}_{(X_{k},Y_{<k},\mathbf{M})\sim\pi\mid S\cap U}\left[\mathop{\mathbb{E}}_{X_{<k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},S\cap U}[\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X,Y_{<k},\mathbf{M})]\cdot\mathop{\mathbb{E}}_{Y_{k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},S\cap U}[\theta_{\mu}(\pi_{k}\,@\,X_{k},Y,\mathbf{M})]\right]

\displaystyle=\mathop{\mathbb{E}}_{(X_{k},Y_{<k},\mathbf{M})\sim\pi\mid S\cap U}\left[\mathop{\mathbb{E}}_{X_{<k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},S\cap U}[\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})})]\right.

\displaystyle\hskip 150.0pt\times\left.\mathop{\mathbb{E}}_{Y_{k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},S\cap U}[\theta_{\mu}(\pi_{k}\,@\,X_{k},Y_{k},\mathbf{M}^{(\pi_{k})})]\right].

S

(\pi\mid X_{k},Y_{<k},\mathbf{M},U)
(for

It is equal to

\displaystyle\kern 12.50002pt\mathop{\mathbb{E}}_{(X_{k},Y_{<k},\mathbf{M})\sim\pi\mid S\cap U}\left[\mathop{\mathbb{E}}_{X_{<k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},S\cap U}[\theta_{\mu^{k-1}}(\pi_{<k}\,@\,X_{<k},Y_{<k},\mathbf{M}^{(\pi_{<k})})]\right.

\displaystyle\hskip 150.0pt\times\left.\mathop{\mathbb{E}}_{Y_{k}\sim\pi\mid X_{k},Y_{<k},\mathbf{M},U}[\theta_{\mu}(\pi_{k}\,@\,X_{k},Y_{k},\mathbf{M}^{(\pi_{k})})]\right]

Lemma 35

such that
\pi(S\cap U)>0

\eta^{1/4}\leq\frac{1}{2}\cdot\frac{\pi(S\cap U)^{1/2}\cdot\mathop{\mathbb{E}}_{\pi\mid S\cap U}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\right]}{\pi(U)^{1/2}\cdot\mathop{\mathbb{E}}_{\pi\mid U}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},U)\right]},

then we have

\displaystyle\kern-20.00003pt\mathop{\mathbb{E}}_{\pi\mid S\cap U}\left[\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid\mathbf{M}^{(\pi_{<k})},S\cap U)\right]

\displaystyle\geq\frac{1}{2}\eta^{-1/2}\cdot\mathop{\mathbb{E}}_{\pi\mid S\cap U}\left[\mathrm{adv}_{\pi}(f^{\oplus k}(X,Y)\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\right].

The first condition
\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\geq 1/2

(\mathbf{M}^{(\pi_{<k})},S\cap U)

Proof.

We have

\displaystyle\kern 12.50002pt\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid\mathbf{M}^{(\pi_{<k})},S\cap U)

\displaystyle=\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid X_{k},\mathbf{M},S\cap U)

\displaystyle=\left|2\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},\mathbf{M},S\cap U)-1\right|

\displaystyle=\left|2\sum_{Y_{<k}}\pi(Y_{<k}\mid X_{k},\mathbf{M},S\cap U)\cdot\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)-1\right|

\displaystyle=\left|\sum_{Y_{<k}}\pi(Y_{<k}\mid X_{k},\mathbf{M},S\cap U)\cdot(2\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)-1)\right|.

By the assumption that
\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\geq 1/2
, the absolute value of the sum is equal to the sum of absolute values:

\displaystyle\kern-20.00003pt\left|\sum_{Y_{<k}}\pi(Y_{<k}\mid X_{k},\mathbf{M},S\cap U)\cdot(2\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)-1)\right|

\displaystyle=\sum_{Y_{<k}}\pi(Y_{<k}\mid X_{k},\mathbf{M},S\cap U)\cdot\left|2\pi(f^{\oplus k-1}(X_{<k},Y_{<k})=b\mid X_{k},Y_{<k},\mathbf{M},S\cap U)-1\right|

\displaystyle=\mathop{\mathbb{E}}_{Y_{<k}\sim\pi\mid X_{k},\mathbf{M},S\cap U}\left[\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\right].

\displaystyle\kern-20.00003pt\mathop{\mathbb{E}}_{\pi\mid{S\cap U}}\left[\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid\mathbf{M}^{(\pi_{<k})},S\cap U)\right]

\displaystyle=\mathop{\mathbb{E}}_{\pi\mid S\cap U}\left[\mathrm{adv}_{\pi}(f^{\oplus k-1}(X_{<k},Y_{<k})\mid X_{k},Y_{<k},\mathbf{M},S\cap U)\right].

(5)

Lemma 44
.

Let
\rho
be an
r

W
be an event such that
(\rho\mid W)
has the rectangle property with respect to
\mu

(X,Y,\mathbf{M})\sim\rho\mid W

•

\frac{\rho(M_{i}\mid X,M_{<i})}{\rho(M_{i}\mid Y,M_{<i})}>T\cdot\chi^{2}_{\mu,A}(\rho\mid W),

i\in[r]

\frac{\rho(M_{i}\mid Y,M_{<i})}{\rho(M_{i}\mid X,M_{<i})}>T\cdot\chi^{2}_{\mu,B}(\rho\mid W),

6r\cdot T^{-1/5}\cdot\rho(W)^{-1}
.

Proof.

We first fix an odd
i\in[r]
, and upper bound the probability that
\frac{\rho(M_{i}\mid X,M_{<i})}{\rho(M_{i}\mid Y,M_{<i})}>T\cdot\chi^{2}_{\mu,A}(\rho\mid W)

Recall that

\chi^{2}_{\mu,A}(\rho\mid W)=\mathop{\mathbb{E}}_{\rho\mid W}\left[\frac{\rho(X\mid Y,\mathbf{M})}{\mu(X\mid Y)}\right],

and we have

\displaystyle\frac{\rho(X\mid Y,\mathbf{M})}{\mu(X\mid Y)}

\displaystyle=\frac{\rho(X\mid Y,\mathbf{M})}{\rho(X\mid Y)}\cdot\frac{\rho(X\mid Y)}{\mu(X\mid Y)}

\displaystyle=\frac{\rho(\mathbf{M}\mid X,Y)}{\rho(\mathbf{M}\mid Y)}\cdot\frac{\rho(X\mid Y)}{\mu(X\mid Y)}

\displaystyle=\frac{\rho(M_{<i}\mid X,Y)}{\rho(M_{<i}\mid Y)}\cdot\frac{\rho(M_{i}\mid M_{<i},X,Y)}{\rho(M_{i}\mid M_{<i},Y)}\cdot\frac{\rho(M_{>i}\mid M_{\leq i},X,Y)}{\rho(M_{>i}\mid M_{\leq i},Y)}\cdot\frac{\rho(X\mid Y)}{\mu(X\mid Y)}

\displaystyle=\frac{\rho(M_{i}\mid M_{<i},X)}{\rho(M_{i}\mid M_{<i},Y)}\cdot\left(\frac{\rho(M_{<i}\mid X,Y)}{\rho(M_{<i}\mid Y)}\cdot\frac{\rho(M_{i}\mid M_{<i},X,Y)}{\rho(M_{i}\mid M_{<i},X)}\cdot\frac{\rho(M_{>i}\mid M_{\leq i},X,Y)}{\rho(M_{>i}\mid M_{\leq i},Y)}\cdot\frac{\rho(X\mid Y)}{\mu(X\mid Y)}\right)

\displaystyle=:\frac{\rho(M_{i}\mid M_{<i},X)}{\rho(M_{i}\mid M_{<i},Y)}\cdot\left(F_{1}\cdot F_{2}\cdot F_{3}\cdot F_{4}\right),

For

\displaystyle\mathop{\mathbb{E}}_{\rho}\left[1/F_{1}\right]

\displaystyle=\mathop{\mathbb{E}}_{\rho}\left[\frac{\rho(M_{<i}\mid Y)}{\rho(M_{<i}\mid X,Y)}\right]

\displaystyle=\sum_{X,Y,M_{<i}}\rho(X,Y,M_{<i})\cdot\frac{\rho(M_{<i}\mid Y)}{\rho(M_{<i}\mid X,Y)}

\displaystyle=\sum_{X,Y,M_{<i}}\rho(X,Y)\cdot\rho(M_{<i}\mid Y)

\displaystyle=\sum_{X,Y}\rho(X,Y)

\displaystyle=1.

Similarly, we can show that

\mathop{\mathbb{E}}_{\rho}\left[1/F_{2}\right]=\mathop{\mathbb{E}}_{\rho}\left[1/F_{3}\right]=1,

and

\mathop{\mathbb{E}}_{\rho}\left[1/F_{4}\right]=\sum_{X,Y}\rho(X,Y)\cdot\frac{\mu(X\mid Y)}{\rho(X\mid Y)}=\sum_{X,Y}\rho(Y)\mu(X\mid Y)=1.

Thus by union bound over all odd
i\in[r]

\Pr_{\rho\mid W}\left[\exists\mathrm{odd}\,i\in[r],\frac{\rho(M_{i}\mid M_{<i},X)}{\rho(M_{i}\mid M_{<i},Y)}\geq\delta^{-4}\cdot\frac{\rho(X\mid Y,\mathbf{M})}{\mu(X\mid Y)}\right]\leq 4\lceil r/2\rceil\cdot\delta/\rho(W).

By Markov’s inequality again, we have

\Pr_{\rho\mid W}\left[\frac{\rho(X\mid Y,\mathbf{M})}{\mu(X\mid Y)}\geq\delta^{-1}\cdot\chi^{2}_{\mu,A}(\rho\mid W)\right]\leq\delta.

Combining the two inequalities, we obtain

\Pr_{\rho\mid W}\left[\exists\mathrm{odd}\,i\in[r],\frac{\rho(M_{i}\mid M_{<i},X)}{\rho(M_{i}\mid M_{<i},Y)}\geq\delta^{-5}\cdot\chi^{2}_{\mu,A}(\rho\mid W)\right]\leq 4\lceil r/2\rceil\cdot\delta/\rho(W)+\delta.

Similarly, for even

\Pr_{\rho\mid W}\left[\exists\mathrm{even}\,i\in[r],\frac{\rho(M_{i}\mid M_{<i},Y)}{\rho(M_{i}\mid M_{<i},X)}\geq\delta^{-5}\cdot\chi^{2}_{\mu,B}(\rho\mid W)\right]\leq 4\lfloor r/2\rfloor\cdot\delta/\rho(W)+\delta.

Finally, by setting

This proves the lemma.
