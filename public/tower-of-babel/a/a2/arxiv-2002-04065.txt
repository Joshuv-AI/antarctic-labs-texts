Preliminary

Denote by
\mathbb{N}_{+}
the set of positive integers,
\mathbb{N}:=\mathbb{N}_{+}\cup\{0\}.
Let
m:=(m_{0,}

m_{1},...)
be a sequence of positive integers not less than 2. Denote by

Z_{m_{k}}:=\{0,1,\ldots,m_{k}-1\}

the additive group of integers modulo
m_{k}
.

Define the group
G_{m}
as the complete direct product of the groups
Z_{m_{i}}
with the product of the discrete topologies of
Z_{m_{j}}`
s.

In this paper we discuss bounded Vilenkin groups, i.e. in the case when
\sup_{n\in\mathbb{N}}m_{n}<\infty.

The direct product
\mu
of the measures

\mu_{k}\left(\{j\}\right):=1/m_{k},\ (j\in Z_{m_{k}})

is the Haar measure on
G_{m_{\text{ }}}
with
\mu\left(G_{m}\right)=1.

The elements of
G_{m}
are represented by sequences

x:=\left(x_{0},x_{1},\ldots,x_{j},\ldots\right),\ \left(x_{j}\in Z_{m_{j}}\right).

It is easy to give a base of neighbourhoods of
G_{m}:

\text{ }I_{0}\left(x\right):=G_{m},\text{ \ }I_{n}(x):=\{y\in G_{m}\mid y_{0}=x_{0},\ldots,y_{n-1}=x_{n-1}\}\,\,\left(x\in G_{m},\text{ }n\in\mathbb{N}\right).

Denote
I_{n}:=I_{n}\left(0\right),
for
n\in\mathbb{N}_{+}
and

e_{n}:=\left(0,\ldots,0,x_{n}=1,0,\ldots\right)\in G_{m},\text{ \ }\left(n\in\mathbb{N}\right).

It is evident that

(4)

\overline{I_{N}}=\overset{N-1}{\underset{s=0}{\bigcup}}I_{s}\backslash I_{s+1}.

If we define the so-called generalized number system based on
m
in the following way :

M_{0}:=1,\ M_{k+1}:=m_{k}M_{k}\,\,\,\ \ (k\in\mathbb{N}),

then every
n\in\mathbb{N}
can be uniquely expressed as

n=\sum_{j=0}^{\infty}n_{j}M_{j},\text{ \ where \ \ }n_{j}\in Z_{m_{j}}\text{\ }(j\in\mathbb{N})

and only a finite number of
n_{j}`
s differ from zero. Let
|n|
denote the
largest integer
j
for which
n_{j}\neq 0
.

Denote by
\mathbb{N}_{n_{0}}
the subset of positive integers
\mathbb{N}_{+},
for which
n_{0}=1.
Then for every
n\in\mathbb{N}_{n_{0}},

M_{k}<n<
where
M_{k+1}
can be written as

n=1+\sum_{j=1}^{k}n_{j}M_{j},

where

n_{j}\in\left\{0,\ldots{},m_{j}-1\right\},\ \ \ (j=1,\ldots,k-1)\text{ and \ }n_{k}\in\left\{1,\ldots{},m_{k}-1\right\}.

For any
\alpha>0
we get that

(5)

\underset{\left\{n:M_{k}\leq n\leq 2^{\alpha}M_{k},\text{ }n\in\mathbb{N}_{n_{0}}\right\}}{\sum}1=\frac{2^{\alpha}M_{k}-M_{k}}{m_{0}}\geq cM_{k},

where
c
is an absolute constant.

The norms (quasi-norm) of the spaces
L_{p}(G_{m}^{2})
and
weak-L_{p}\left(G_{m}^{2}\right)
are respectively defined by

\left\|f\right\|_{p}:=\left(\int_{G_{m}^{2}}\left|f\right|^{p}d\mu\times d\mu\right)^{1/p},\ \ \ \ \ \ \ \left\|f\right\|_{weak-L_{p}}:=\underset{\lambda>0}{\sup}\lambda\mu\left(f>\lambda\right)^{1/p}\ \ \ \ \ \ \left(0<p<\infty\right).

Next, we introduce on
G^{2}_{m}
an orthonormal system which is called the
Vilenkin system.

At first, we define the complex-valued function
r_{k}\left(x\right):G_{m}\rightarrow\mathbb{C},
the generalized Rademacher functions by

r_{k}\left(x\right):=\exp\left(2\pi ix_{k}/m_{k}\right),\text{ }\left(i^{2}=-1,x\in G_{m},\text{ }k\in\mathbb{N}\right).

Now, define the Vilenkin system
\psi:=(\psi_{n}:n\in\mathbb{N})
on
G_{m}
as:

\psi_{n}(x):=\prod\limits_{k=0}^{\infty}r_{k}^{n_{k}}\left(x\right),\ \ \left(n\in\mathbb{N}\right).

We define the two-dimesional Vilenkin system as a kronecker product of two Vilenkin systems. The Vilenkin system is orthonormal and complete in
L_{2}\left(G_{m}^{2}\right)
(for details see
[
1
]
and
[
42
]
).
Specifically, we call this system the Walsh-Paley system, when
m\equiv 2.

The rectangular partial sum of the 2-dimensional Vilenkin-Fourier series of function
f\in L_{2}\left(G_{m}^{2}\right)
is defined as follows:

S_{M,N}f\left(x,y\right):=\sum\limits_{i=0}^{M-1}\sum\limits_{j=0}^{N-1}\widehat{f}\left(i,j\right)\psi_{i}\left(x\right)\psi_{j}\left(y\right),

where the numbers

\widehat{f}\left(i,j\right)=\int\limits_{G_{m}^{2}}f\left(x,y\right)\bar{\psi}_{i}\left(x\right)\bar{\psi}_{j}\left(y\right)d\mu\left(x\right)d\mu\left(y\right)

is said to be the
\left(i,j\right)
-th Vilenkin-Fourier coefficient of the function
f.

It is well-known that (for details see e.g.
[
25
]
)

S_{M,N}f\left(x,y\right)=\int_{G^{2}_{m}}f(x,y)D_{M}(x-t)D_{N}(y-s)d\mu\left(x\right)d\mu\left(y\right),

where

D_{n}(x)=\sum\limits_{i=0}^{n-1}\psi_{i}(x)

is called as
n
-th Dirichlet Kernel. Recall that

(6)

D_{M_{n}}\left(x\right)=\left\{\begin{array}[]{ll}M_{n},&\text{if}\ \ x\in I_{n},\\
0,&\text{if}\ \ x\notin I_{n}.\end{array}\right.

It is also known that (see
[
1
]
)

(7)

D_{sM_{n}}=D_{M_{n}}\sum_{k=0}^{s-1}\psi_{kM_{n}}=D_{M_{n}}\sum_{k=0}^{s-1}r_{n}^{k}\ \ \ \ \ \ \ \text{and}\ \ \ \ \ \ \ D_{n}=\psi_{n}\left(\sum_{j=0}^{\infty}D_{M_{j}}\sum_{u=m_{j}-n_{j}}^{m_{j}-1}r_{j}^{u}\right).

Moreover, the following estimation holds true:

(8)

\int_{I_{N}}\left|D_{n}\left(x-t\right)\right|d\mu\left(t\right)\leq\frac{cM_{s}}{M_{N}},\ \ \ \ \ x\in I_{s}\backslash I_{s+1},\ \ s=0,...,N-1.

For our investigation we need the following estimates of the two-dimensional Dirichlet kernels of independent interest:

Lemma 1
.

Let
m,n\in\mathbb{N}
. Then, for every
0<\varepsilon\leq 1
, there exists an absolute constant
c,
such that

\int_{I_{N}\times I_{N}}\left|D_{m}\left(x-t\right)D_{n}\left(y-s\right)\right|d\mu\left(t\right)d\mu\left(s\right)\leq\frac{cm^{\varepsilon}M_{s}}{M_{N}^{1+\varepsilon}},\ \ \ (x,y)\in{I_{N}}\times\left(I_{s}\backslash I_{s+1}\right),\ \ s=0,...,N-1

and

\int_{I_{N}\times I_{N}}\left|D_{m}\left(x-t\right)D_{n}\left(y-s\right)\right|d\mu\left(t\right)d\mu\left(s\right)\leq\frac{cn^{\varepsilon}M_{s}}{M_{N}^{1+\varepsilon}},\ \ \ (x,y)\in\left(I_{s}\backslash I_{s+1}\right)\times{I_{N}},\ \ \ s=0,...,N-1.

Moreover, let
(x,y)\in\left(I_{s_{1}}\backslash I_{s_{1}+1}\right)\times\left(I_{s_{2}}\backslash I_{s_{2}+1}\right),

s_{1},s_{2}=0,...,N-1.
Then there exists an absolute constant
c,
such that

\int_{I_{N}}\left|D_{n}\left(x-t\right)D_{m}\left(y-s\right)\right|d\mu\left(t\right)d\mu\left(s\right)\leq\frac{cM_{s_{1}}M_{s_{2}}}{M_{N}^{2}}.

Proof.

Since
\left|D_{m}(x)\right|\leq m
and

\left|D_{m}(x)\right|\leq M_{s},\ \ \text{for }\ \ x\in I_{s}\backslash I_{s+1},
by using (
8
) we obtain that

\displaystyle\int_{I_{N}}\left|D_{m}\left(x-t\right)\right|d\mu\left(t\right)\leq m^{\varepsilon}\overset{\infty}{\underset{s=N}{\sum}}\int_{I_{s}\backslash I_{s+1}}\left|D_{m}\left(x-t\right)\right|^{1-\varepsilon}d\mu\left(t\right)

\displaystyle\leq

\displaystyle cm^{\varepsilon}\overset{\infty}{\underset{s=N}{\sum}}\int_{I_{s}\backslash I_{s+1}}M_{s}^{1-\varepsilon}d\mu\left(t\right)\leq cm^{\varepsilon}\overset{\infty}{\underset{s=N}{\sum}}M_{s}^{-\varepsilon}\leq\frac{cm^{\varepsilon}}{M_{N}^{\varepsilon}}.

Therefore, by using inequality (
8
) we obtain that

\displaystyle\int_{I_{N}\times I_{N}}\left|D_{m}\left(x-t\right)D_{n}\left(y-s\right)\right|d\mu\left(t\right)d\mu\left(s\right)

\displaystyle\leq

\displaystyle\int_{I_{N}}\left|D_{m}\left(x-t\right)\right|d\mu\left(t\right)\int_{I_{N}}\left|D_{n}\left(y-s\right)\right|d\mu\left(s\right)\leq\frac{cm^{\varepsilon}M_{s}}{M_{N}^{1+\varepsilon}}.

The proof of the second estimation is quite analogical to the proof of Lemma
1
. So, we leave out the details.

To prove the third estimate we apply inequality (
8
) to obtain that

\displaystyle\int_{I_{N}\times I_{N}}\left|D_{m}\left(x-t\right)D_{n}\left(y-s\right)\right|d\mu\left(t\right)d\mu\left(s\right)

\displaystyle\leq

\displaystyle\int_{I_{N}}\left|D_{m}\left(x-t\right)\right|d\mu\left(t\right)\int_{I_{N}}\left|D_{n}\left(y-s\right)\right|d\mu\left(s\right)\leq\frac{cM_{s_{1}}M_{s_{2}}}{M_{N}^{2}}.

The proof is complete.

Proposition 1
.

Let

are the same as those of the martingale

\left(S_{M_{n},M_{n}}f:n\in\mathbb{N}\right)
obtained from

Moreover,
{H_{p}^{\square}(G_{m}^{2})}\text{ }(0<p\leq 1)
norm is calculated by

\left\|f\right\|_{H_{p}^{\square}(G_{m}^{2})}=\left\|\sup\limits_{n\in\mathbb{N}}|S_{M_{n},M_{n}}g|\right\|_{p}.

A bounded measurable function

p

\int_{I^{2}}ad\mu=0,\text{ \ \ \ \ \ }\left\|a\right\|_{\infty}\leq\mu(I^{2})^{-1/p},\text{ \ \ \ \ \ supp}\left(a\right)\subset I^{2}.

Moreover,

\left\|f\right\|_{H_{p}^{\square}(G_{m}^{2})}\backsim\inf\left(\sum_{k=0}^{\infty}\left|\mu_{k}\right|^{p}\right)^{1/p},

where the infimum is taken over all decompositions of

Our first main result reads:

Theorem 1

b) (Sharpness) Let

be a non-decreasing function, satisfying the condition

{\sup_{m,n\in\mathbb{N}}}\frac{{(m+n)}^{2/p-2}}{\varphi\left(m,n\right)}=+\infty.

Then

\sup_{m,n\in\mathbb{N}}\left\|\frac{S_{m,n}f}{\varphi\left(m,n\right)}\right\|_{weak-L_{p}(G_{m}^{2})}=\infty.

Proof.

Since
\overset{\sim}{S}_{p}^{\ast}
is bounded from
L_{\infty}
to
L_{\infty}
by using Proposition
2
we
conclude that the proof of part a) will be complete, if we show that

\int\limits_{\overline{{I}\times{I}}}\left|\overset{\sim}{S}_{p}^{\ast}a\left(x,y\right)\right|^{p}d\mu\left(x\right)d\mu\left(y\right)\leq c<\infty,\text{ \ \ as \ \ }0<p<1,

for every
p
-atom
a,
where

denotes the support of the atom
.

Let
a
be an arbitrary
p
-atom with support

and
\mu\left(I\times I\right)=M_{N}^{-2}.
We may assume that

where

It is easy to see that

and

Therefore we can suppose that either

or

we find that

(12)

\displaystyle\left|S_{m,n}a\right|

\displaystyle\leq

\displaystyle\int_{I_{N}\times I_{N}}\left|a\left(t_{1},t_{2}\right)\right|\left|D_{m,n}\left(x+t_{1},y+t_{2}\right)\right|d\mu\left(t_{1}\right)d\mu\left(t_{2}\right)

\displaystyle\leq

\displaystyle\left\|a\right\|_{\infty}\int_{I_{N}\times I_{N}}\left|D_{m,n}\left(x+t_{1},y+t_{2}\right)\right|d\mu\left(t_{1}\right)d\mu\left(t_{2}\right)

\displaystyle\leq

\displaystyle M_{N}^{2/p}\int_{I_{N}\times I_{N}}\left|D_{m,n}\left(x+t_{1},y+t_{2}\right)\right|d\mu\left(t_{1}\right)d\mu\left(t_{2}\right).

Let

(x,y)\in I_{N}\times(I_{s_{2}}\backslash I_{s_{2}+1}).
We choose
