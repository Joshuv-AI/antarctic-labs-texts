Multiple Kernel-Based Online Federated Learning
Jeongmin Chae, and Songnam Hong

Abstract
Online federated learning (OFL) becomes an emerging learning framework, in which edge nodes perform online learning with continuous streaming local data and a server constructs a global model from the aggregated local models. Online multiple kernel learning (OMKL), using a preselected set of P P kernels, can be a good candidate for OFL framework as it has provided an outstanding performance with a low-complexity and scalability. Yet, an naive extension of OMKL into OFL framework suffers from a heavy communication overhead that grows linearly with P P . In this paper, we propose a novel multiple kernel-based OFL (MK-OFL) as a non-trivial extension of OMKL, which yields the same performance of the naive extension with 1 / P 1/P communication overhead reduction. We theoretically prove that MK-OFL achieves the optimal sublinear regret bound when compared with the best function in hindsight. Finally, we provide the numerical tests of our approach on real-world datasets, which suggests practicality.



I
Introduction

Federated learning is an emerging distributed learning framework, in which distributed nodes (e.g., mobile phones, wearable devices, etc.) train a model collaboratively under the coordination of a central server without centralizing the training data
[
6
,
9
]
. To be specific, federated learning optimizes a global model by repeating the two operations: i) local model optimizations at edge nodes; ii) global model update (e.g., model averaging) at the server
[
24
]
. This approach has received tremendous attention due to the myriad of applications: activities of mobile phone users, predicting a low blood sugar, heart attack risk from wearable devices, or detecting burglaries within smart homes
[
1
,
14
,
16
]
.

In many real-world applications, machine learning tasks are expected to be operated in an online fashion. For example, online learning is required when data is generated as a function of time (i.e., time-series predictions)
[
17
,
20
]
and when the large number of data makes it impossible to carry out data analytic in batch form
[
11
]
. This challenging problem has been successfully addressed via online multiple kernel learning (OMKL)
[
19
,
21
,
8
]
. OMKL learns a sequence of functions (or models) which predicts the label of a newly incoming data. In particular, it seeks the optimal combination of a pool of
P
single kernel functions in an online fashion. With the use of multiple kernels, OMKL can provide a superior accuracy and enjoy a great flexibility compared with single-kernel online learning
[
21
,
8
]
. In spite of these merits, OMKL is restricted to a centralized online learning and an extension to a federated learning is still open problem.

In this paper, we consider an online federated learning (OFL) problem. The objective of OFL is to learn a sequence of global models using continuous streaming data across a large number of distributed nodes. At every time, specifically, OFL optimizes a global model by repeating two operations: i) edge nodes updates local models using their own incoming data; ii) the server constructs an improved global model by averaging the them. The construction of a single kernel-based OFL (named SK-OFL) is rather straightforward, where the parameter of a kernel function (defined by a
2D
-dimensional vector) is simply exchanged between every node and the server. As in the centralized counterpart
[
21
,
8
]
, the use of multiple kernels (i.e., a preselected set of
P
kernels) is necessary to enhance a learning accuracy. However, a naive extension of SK-OFL into a multiple kernel setting suffers from a heavy communication overhead that increases linearly with
P
. This is because the parameters of all
P
kernels should be exchanged. In this paper, we propose a novel multiple-kernel OFL (named MK-OFL) which can achieve the same performance of the naive extension and outperforms SK-OFL considerably with the same communication overhead with SK-OFL. To this end, our major contributions are summarized as follows.

•

In the proposed MK-OFL, every node selects one kernel index out of
P
kernels randomly according to its own probability mass function (PMF). Then, it sends one local model corresponding to the selected index, thus having the same communication overhead with SK-OFL. With high probability, this randomized algorithm chooses the best kernel only after a certain convergence time, thus being able to yield an attractive performance.

•

Leveraging the martingale argument, we theoretically prove that MK-OFL achieves the optimal sublinear regret bound
{\cal O}(\sqrt{T})
when compared wit the best kernel function in hindsight. This implies that MK-OFL achieves the same accuracy of the centralized OMKL asymptotically by preserving an edge-node privacy.

•

Via numerical tests on real-world datasets, we demonstrate the effectiveness of the proposed MK-OFL in various online learning tasks such as online regressions and time-series predictions. Remarkably, it is shown that MK-OFL significantly outperforms SK-OFL and almost achieves the performance of the best kernel function in hindsight.

II
Preliminaries

We briefly review the kernel-based online learning framework (named OMKL) in
[
8
]
, and describe the problem setting of an online federated learning (OFL). To simplify the notation, we let
[N]=\{1,2,...,N\}
for some positive integer
N
. Also,
t
,
k
,
p
represent the indices of time, node, and kernel, respectively.

II-A

Overview of a kernel-based online learning

The main objective of an online learning is to learn a sequence of functions
\{\hat{f}_{t}:t\in[T]\}
such that the cumulative regret is minimized:

{\cal R}_{T}=\sum_{t=1}^{T}{\cal L}(\hat{f}_{t}({\bf x}_{t}),y_{t})-\sum_{t=1}^{T}{\cal L}(f^{\star}({\bf x}_{t}),y_{t}),

(1)

where
{\cal L}(\cdot,\cdot)
and
f^{\star}(\cdot)
denote a cost function and the best function in hindsight, respectively. Specifically, at every time
t-1
,
\hat{f}_{t}(\cdot)
is estimated from the received data
\{({\bf x}_{\tau},y_{\tau}):\tau\in[t-1]\}
. The above challenging problem has been efficiently solved via a kernel-based online learning
[
21
,
8
]
. In this approach, a function space for an optimization is restricted to a reproducing Hilbert kernel space (RKHS)
{\cal H}_{p}
, defined as

{\cal H}_{p}\stackrel{{\scriptstyle\Delta}}{{=}}\left\{f:f({\bf x})=\sum_{t}\alpha_{t}\kappa_{p}({\bf x},{\bf x}_{t})\right\}
,
where
\kappa_{p}({\bf x},{\bf x}_{t}):{\cal X}\times{\cal X}\rightarrow{\cal Y}
is a symmetric positive semidefinite basis function (called kernel)
[
23
]
. Moreover, the representer theorem
[
22
]
and random-feature approximation
[
15
]
shows that each kernel function in an optimal solution of (
1
) can be well-approximated with a model parameter
\hat{{\bf w}}_{t}^{p}
, i.e.,

\hat{f}_{t}({\bf x})=\left(\hat{{\bf w}}_{t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}),

(2)

where
{\bf z}_{p}({\bf x})
denotes a non-linear function defined by a kernel
\kappa_{p}
, i.e.,

\displaystyle{\bf z}_{p}({\bf x})=

(3)

\displaystyle\frac{1}{\sqrt{D}}[\sin{\bf v}_{1}^{{\sf T}}{\bf x},\dots,\sin{\bf v}_{D}^{{\sf T}}{\bf x},\cos{\bf v}_{1}^{{\sf T}}{\bf x},\dots,\cos{\bf v}_{D}^{{\sf T}}{\bf x}]^{{\sf T}},

and where
\{{\bf v}_{i}:i\in[D]\}
denotes an independent and identically distributed (i.i.d.) samples from the Fourier transform of a given kernel function
\kappa_{p}(\cdot,\cdot)
. Note that the hyper-parameter
D
can be chosen independently from the size of data
T
. The accuracy of the above kernel-based online learning fully relies on a preselected kernel
\kappa_{p}
, which is chosen manually either by a task-specific priori knowledge or by some intensive cross-validation process. Online multiple kernel learning (OMKL), using a predetermined set of
P
kernels (called a kernel dictionary), is more powerful
[
21
,
8
]
. Namely, OMKL seeks a sequence of best kernel functions, each of which has the following form:

\displaystyle\hat{f}_{t}({\bf x})=\sum_{p=1}^{P}\hat{q}_{t}^{p}\left(\hat{{\bf w}}_{t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x})\in\bar{{\cal H}},

(4)

where
\bar{{\cal H}}\stackrel{{\scriptstyle\Delta}}{{=}}{\cal H}_{1}+{\cal H}_{2}+\cdots+{\cal H}_{P}
is again RKHS
[
23
]
and
\hat{q}_{t}^{p}\in[0,1]
denotes the combination weight (or reliability) of the associated kernel function
\hat{f}_{t}^{p}({\bf x})=\left(\hat{{\bf w}}_{t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x})
.
We remark that the optimization of OMKL can be solved using the powerful tool boxes from online convex optimization and online learning techniques developed over vector spaces.

Fig. 1:
Description of the proposed online federated learning with multiple kernels at time
t
, in which
\hat{{\bf w}}_{k,t+1}
and
\hat{{\bf w}}_{t+1}

k
and the global model, respectively. The estimated label
\hat{y}_{k,t}
at each node
k
is determined as
\hat{y}_{k,t}=\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{\hat{p}_{t}}({\bf x}_{k,t})
.

II-B

Problem Formulation

We define the problem setting of an online federated learning (OFL). The objective of OFL is to learn a sequence of functions (i.e., global models) from sequentially incoming data across a large number of distributed nodes. In detail, at each time
t
, the server distributes the current global model
\hat{{\bf w}}_{t}\in\mbox{\bb R}^{r}
(the parameter of a learned function) to the distributed
K
nodes, where
r
denotes a communication overhead. Every nodes
k
updates the local model independently from the current global model and incoming data
({\bf x}_{k,t},y_{k,t})
, where
{\bf x}_{k,t}\in{\cal X}\subseteq\mbox{\bb R}^{d}
and
y_{k,t}\in{\cal Y}\subseteq\mbox{\bb R}
represent the feature and the label, respectively. Hereinafter, the corresponding local model are denoted as
\hat{{\bf w}}_{k,t+1}
for
k\in[K]
. Then, the
K
nodes send it back to the server, from which the server constructs an improved global model as

\hat{{\bf w}}_{t+1}=h\left(\hat{{\bf w}}_{1,t+1},...,\hat{{\bf w}}_{K,t+1}\right),

(5)

for some function
h:\mbox{\bb R}^{r}\times\cdots\times\mbox{\bb R}^{r}\rightarrow\mbox{\bb R}^{r}
. In this paper, it is assumed that
h
is the popular
averaging function
(FedAvg)
[
12
]
, i.e.,
\hat{{\bf w}}_{t+1}=\frac{1}{K}\sum_{k=1}^{K}\hat{{\bf w}}_{k,t+1}
.
These two-step procedures will be repeated.

III
Methods

We first present a single kernel-based OFL (SK-OFL) and then extend it into a multiple kernel setting. The resulting method is named MK-OFL. To meet the communication overhead, in both methods, the messages exchanged between a server and edge nodes are constructed as
r
-dimensional real-valued vectors (see Fig.
1
). The detailed algorithms of SK-OFL and MK-OFL are described in Section
III-A
and Section
III-B
, respectively.

III-A

The Proposed SK-OFL

The objective of SK-OFL is to seek a sequence of functions
\hat{f}_{1}({\bf x}),...,\hat{f}_{T}({\bf x})
under the OFL framework in Section
II-B
. Following the structure of a kernel-based online learning
[
8
]
, each function is fully defined with a single parameter
\hat{{\bf w}}_{t}\in\mbox{\bb R}^{2D}
, i.e.,

\hat{f}_{t}({\bf x})=\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{p}({\bf x}),

(6)

where
{\bf z}_{p}({\bf x})
is defined in (
3
) and a preselected kernel
\kappa_{p}
is assumed. In SK-OFL,
\hat{{\bf w}}_{t}
is considered as a global model and by setting
D=\lfloor r/2\rfloor
, the communication overhead is met. At every time
t
, SK-OFL performs a distributed model training iteratively with the two steps: i) local model update at the edge nodes; ii) global model update at the server. Focusing on time
t
, we provide the specific procedures of these steps below.

(i) Local model update:
Given the current global model
\hat{{\bf w}}_{t}
and an incoming data
({\bf x}_{k,t},y_{k,t})
, each node
k
updates its local model
\hat{{\bf w}}_{k,t+1}
via online gradient descent (OGD)
[
7
]
:

\hat{{\bf w}}_{k,t+1}=\hat{{\bf w}}_{t}-\eta_{\ell}\nabla{\cal L}\left(\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right),

(7)

with step size
\eta_{l}>0
, where
\nabla{\cal L}\left(\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)
stands for the gradient at the point
\hat{{\bf w}}_{t}
. Then, it sends the updated local model
\hat{{\bf w}}_{k,t+1}
to the server.

(ii) Global model update:
Given the received local models

\{\hat{{\bf w}}_{k,t+1}:k\in[K]\}
, the server updates the global model by averaging them:

\hat{{\bf w}}_{t+1}=\frac{1}{K}\sum_{k=1}^{K}\hat{{\bf w}}_{k,t+1}.

(8)

Then, it distributes the updated global model
\hat{{\bf w}}_{t+1}\in\mbox{\bb R}^{r}
to the
K
nodes.

Remark 1

The proposed SK-OFL can be immediately extended into a multiple kernel setting, in which every node transmits the
P
local models and the corresponding weights as in (
4
) to the server, and vice versa. This naive extension suffers from an expensive communication overhead as it linearly increases with the size of a kernel dictionary
P
(i.e., equals to
P\times r
). In the following section, we will present a novel MK-OFL as a non-trivial extension of SK-OFL into a multiple kernel setting. It is noticeable that MK-OFL can achieve the performance of the naive extension and significantly improve the performance of SK-OFL while having the communication overhead
r
irrespective of
P
.

III-B

The Proposed MK-OFL

In the proposed MK-OFL, the central server broadcasts the global information
(\hat{p}_{t+1},\hat{{\bf w}}_{t})\in[P]\times\mbox{\bb R}^{2D}
at time
t
over
t=1,...,T
, where the initial values are assigned as

\hat{{\bf w}}_{1}={\bf 0}
and
\hat{p}_{2}=1
. Regarding the communication overhead, compared with SK-OFL a kernel index is additionally transmitted.
Taking this into account,
(\hat{p}_{t+1},\hat{{\bf w}}_{t})
is considered as a global model and by setting
D=\lfloor r/2\rfloor-1
, the communication overhead is satisfied. Then, a common learned (or estimated) function at the current time
t
is fully determined by the parameters
\hat{p}_{t}
(obtained at time
t-1
) and
\hat{{\bf w}}_{t}
, i.e.,

\hat{f}_{t}({\bf x})=\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{\hat{p}_{t}}({\bf x}).

(9)

The key idea of MK-OFL is following: it is allowed to choose a different kernel at every time, while as
t
grows, a selected kernel can converge to the best kernel in hindsight. Furthermore, we verified that the convergence speed is quite fast. In contrast, SK-OFL should choose one kernel before receiving data and thus, the predetermined kernel is unlikely to be the best one. For these reasons, MK-OFL can significantly outperform SK-OFL without sacrificing the communication overhead and by enjoying the use of multiple kernels. Focusing on time
t
, we provide the detailed algorithm of MK-OFL below (see Fig.
1
).

(i) Local model update:
At time
t
, each node
k
has its own local information as
\{\tilde{{\bf w}}_{k,t}^{p}:p\in[P]\}
and receives the global model
(\hat{p}_{t+1},\hat{{\bf w}}_{t})
from the server. Using the
\hat{p}_{t}
(observed at time
t-1
) and
\hat{{\bf w}}_{t}
, it first updates the parameters of the
P
local kernel functions:

\hat{{\bf w}}_{k,t}^{p}=\begin{cases}\tilde{{\bf w}}_{k,t}^{p},\mbox{ if }p=\hat{p}_{t}\\
\hat{{\bf w}}_{t},\mbox{ if }p\neq\hat{p}_{t},\end{cases}

(10)

for
\forall p\in[P]
. Then, every node
k
updates the local information via OGD:

\tilde{{\bf w}}_{k,t+1}^{p}=\hat{{\bf w}}_{k,t}^{p}-\eta_{\ell}\nabla{\cal L}\left((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right),

(11)

for
\forall p\in[P]
, where
\eta_{\ell}>0
is the step size. Given the received parameter
\hat{p}_{t+1}
, set

\hat{{\bf w}}_{k,t+1}=\tilde{{\bf w}}_{k,t+1}^{\hat{p}_{t+1}},

(12)

which will be transmitted to the server as the updated local model.

We next explain how each node
k
selects the candidate of the best kernel at time
t+2
(denoted by
\hat{p}_{k,t+2}
).
The weights for combining the
P
kernel functions are determined on the basis of the past local losses, i.e.,

\hat{{\bf q}}_{k,t+2}(p)=\frac{\hat{{\bf m}}_{k,t+2}(p)}{\sum_{p=1}^{P}\hat{{\bf m}}_{k,t+2}(p)},\;\;\forall p\in[P],

(13)

where the initial values
\hat{{\bf m}}_{k,2}(p)=1,\forall p\in[P]
and for a learning rate
\eta_{g}>0
,

\displaystyle\hat{{\bf m}}_{k,t+2}(p)=\hat{{\bf m}}_{k,t+1}(p)

\displaystyle\;\;\;\;\;\times\exp\left(-\eta_{g}K{\cal L}\left((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)\right).

(14)

In the context of online learning, the above weight update is known as
exponential strategy
(or Hedge algorithm)
[
2
]
. From (
13
), the following probability mass function (PMF) is defined

\hat{{\bf q}}_{k,t+2}=(\hat{{\bf q}}_{k,t+2}(1),...,\hat{{\bf q}}_{k,t+2}(P)).

(15)

Then, it selects one kernel index
\hat{p}_{k,t+2}\in[P]
according to the PMF
\hat{{\bf q}}_{k,t+2}
and transmits the updated local model
(\hat{p}_{k,t+2},\hat{{\bf w}}_{k,t+1}=\tilde{{\bf w}}_{k,t+1}^{\hat{p}_{t}})
to the server.

(ii) Global model update:
The server receives the updated local models
\{(\hat{p}_{k,t+2},\hat{{\bf w}}_{k,t+1}):k\in[K]\}
from the
K
nodes. First, the global parameter is updated by averaging the local parameters such as

\hat{{\bf w}}_{t+1}=\frac{1}{K}\sum_{k=1}^{K}\hat{{\bf w}}_{k,t+1}.

(16)

Also, each kernel
k
chooses one kernel index
\hat{p}_{t+2}
from
\{\hat{p}_{k,t+2}:k\in[K]\}
randomly according to the PMF
\hat{\hbox{\boldmath$\alpha$}}_{t+2}=(\hat{\alpha}_{1,t+2},...,\hat{\alpha}_{K,t+2})
, where

\displaystyle\alpha_{k,t+2}

\displaystyle=\frac{|\{k\in[K]:\hat{p}_{k,t+1}=p\}|^{K-1}}{\sum_{p=1}^{P}{|\{k\in[K]:\hat{p}_{k,t+1}=p\}|^{K}}}.

(17)

Naturally, this PMF construction aims at assigning a higher probability to a more frequent index from
\{\hat{p}_{k,t+2}:k\in[K]\}
. The resulting index
\hat{p}_{t+2}
represents the kernel index to be globally updated at the next time slot
t+2
. The server distributes the updated global model
(\hat{p}_{t+2},\hat{{\bf w}}_{t+1})
to the
K
nodes.

IV
Regret Analysis

We analyze the cumulative regret of the proposed MK-OFL. As usually considered for the analysis of online convex optimizations and online learning frameworks
[
2
,
7
,
21
,
8
]
, the following conditions are also assumed.

Assumption 1.

For any fixed
{\bf z}_{p}({\bf x}_{t})
and
y_{t}
, the loss function
{\cal L}({\bf w}^{{\sf T}}{\bf z}_{p}({\bf x}_{t}),y_{t})
is convex with respect to
{\bf w}
, and is bounded as
{\cal L}({\bf w}^{{\sf T}}{\bf z}_{p}({\bf x}_{t}),y_{t})\in[0,1]
.

Assumption 2.

For any kernel
\kappa_{p}
,
{\bf w}_{k,t}^{p}
belongs to a bounded set
{\cal B}
, i.e.,
\|{\bf w}_{k,t}^{p}\|\leq C
for any
t\in[T]
.

Assumption 3.

The loss function is
L
-Lipschitz continuous, i.e.,
\|\nabla{\cal L}({\bf w}^{{\sf T}}{\bf z}_{p}({\bf x}_{t}),y_{t})\|\leq L
.

Let
f_{p}^{\star}({\bf x})=({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x})
denote the best function in the kernel
\kappa_{p}
with respect to the distributed data

\{({\bf x}_{k,t},y_{k,t}):k\in[K],t\in[T]\}
:

{\bf w}_{p}^{\star}\stackrel{{\scriptstyle\Delta}}{{=}}{\hbox{arg}}\min_{{\bf w}\in{\cal B}}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left({\bf w}^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right).

(18)

Before stating our main results, we will give some intuitions behind the proposed MK-OFL. It is a
randomized
algorithm due to the randomness of the best kernel selection at every time
t
(denoted by
\hat{p}_{t}
in our algorithm). By integrating randomness at the distributed edges and the server, it can be understood that
\hat{p}_{t}
is chosen from
[P]
randomly according to the following PMF:

\hat{{\bf q}}_{t}=\sum_{k=1}^{K}\alpha_{k,t}\hat{{\bf q}}_{k,t},

(19)

where
\alpha_{k,t}
, defined in (
17
), can capture the reliabilities of the
K
nodes at the current time
t
. To evaluate the accuracy of
\hat{{\bf q}}_{t}
, we introduce the corresponding network-wise (or centralized) PMF
\bar{{\bf q}}_{t}
, which is determined on the basis of the entire losses of the
K
nodes:

\bar{{\bf q}}_{t}(p)=\frac{\bar{{\bf m}}_{t}(p)}{\sum_{p=1}^{P}\bar{{\bf m}}_{t}(p)},\;\;\forall p\in[P],

(20)

with the initial values
\bar{{\bf m}}_{1}(p)=1,\forall p\in[P]
, where

\bar{{\bf m}}_{t}(p)=\bar{{\bf m}}_{t-1}(p)\times L_{t-1}^{p},

(21)

and for some parameter
\eta_{g}>0

L_{t-1}^{p}=\prod_{k=1}^{K}\exp\left(-\eta_{g}{\cal L}\left((\hat{{\bf w}}_{k,t-1}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t-1}),y_{k,t-1}\right)\right).

In general, the data available locally fail to estimate the overall distribution
\bar{{\bf q}}_{t}
. Obviously MK-OFL can approach the performance of the centralized OMKL
[
8
]
(i.e., the performance limit), provided that our PMF
\hat{{\bf q}}_{t}
, which is constructed in a decentralized way, is sufficiently close to
\bar{{\bf q}}_{t}
. In fact, an exact gap between them relies on the characteristics (e.g., heterogeneity) of real datasets. Nevertheless, in our theoretical analysis, it is proved that regardless of datasets, the above gap only leads to a bounded performance loss, which is less than
{\cal O}(\sqrt{T})
. Namely, the loss is small enough to guarantee the optimal sublinear regret
{\cal O}(\sqrt{T})
of the proposed MK-OFL. Beyond the asymptotic analysis, our experiments in Fig. 2 demonstrate that the impact of the above gap is negligible.

IV-A

Main results

Note that in the proposed MK-OFL, the server broadcasts the current estimate
\hat{wv}_{t}
at time
t
to the
K
nodes and each node
k
estimates the label of a newly incoming data
{\bf x}_{k,t}
as
\hat{y}_{k,t}=\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{\hat{p}_{t}}({\bf x}_{k,t})
. Also,
{\bf w}_{p}^{\star}
denotes the optimal parameter defined in (
18
). Under the Assumption 1 - Assumption 3, we state the main result of this section:

Theorem 1

The proposed MK-OFL with

\eta_{\ell}=\eta_{g}={\cal O}(1/\sqrt{T})
guarantees the sublinear regret
{\cal O}(\sqrt{T})
with high probability:

\displaystyle{\cal R}_{T}

\displaystyle=\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{\hat{p}_{t}}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle-\min_{1\leq p\leq P}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\Big(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\Big)\leq{\cal O}(\sqrt{T}).

From the fact that SK-OFL is a deterministic algorithm with a preselected kernel
\kappa_{p}
, we can immediately get:

Corollary 1

For a predetermined kernel
\kappa_{p}
, SK-OFL with
\eta_{\ell}=\eta_{g}={\cal O}(1/\sqrt{T})
guarantees the sublinear regret as

\displaystyle{\cal R}_{T}

\displaystyle=\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\hat{{\bf w}}_{t}^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle\;\;\;\;\;\;-\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\Big(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\Big)\leq{\cal O}(\sqrt{T}).

Theorem
1
and Corollary
1
reveal that MK-OFL and SK-OFL can achieve the optimal sublinear regret bounds when compared with the respective best functions in hindsight. However, it is noticeable that the best functions as to MK-OFL and SK-OFL are from
\bar{{\cal H}}={\cal H}_{1}+\cdots+{\cal H}_{P}
and
{\cal H}_{p}\subset\bar{{\cal H}}
for a preselected
p\in[P]
, respectively.
Consequently, the former tends to be much better than the latter. For this reason, MK-OFL can considerably outperform SK-OFL, which will be demonstrated in Section
V
via online learning tasks with real-world datasets.

IV-B

Proof of Theorem 1

To capture the randomness of kernel selections in MK-OFL, we introduce a random variable
I_{t}
which indicates a selected kernel index at time
t
in the server. As in the description of MK-OFL, the realization of
I_{t}
is denoted as
\hat{p}_{t}
. The parameters of
P
kernel functions and the local PMFs are also random variables, which are determined as a function of random variables
I_{1},...,I_{t-1}
. Without loss of generality, their realizations at time
t
are denoted as

\{\hat{q}_{k,t}(p):p\in[P],k\in[K]\}
and
\{\hat{{\bf w}}_{k,t}^{p}:p\in[P],k\in[K]\}
, respectively. Also, the realizations of the PMFs are denoted as
\hat{{\bf q}}_{t}(p)
and
\bar{{\bf q}}_{t}(p)
. With these notations, we first provide key lemmas for this proof. Lemma
1
are immediately obtained following the proof of OGD convergence
[
7
]
with the Assumption 2 and Assumption 3. The proofs of Lemma
2
and Lemma
3
are provided in the appendices.

Lemma 1

For any
p\in[P]
and step size
\eta_{l}>0
, the following upper bound is hold:

\displaystyle\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\left(\hat{{\bf w}}_{k,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\Big(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\Big)

\displaystyle\leq\frac{KC^{2}}{2\eta_{l}}+\frac{3\eta_{l}KL^{2}T}{2}.

Proof:
The proof is provided in Appendix
A
.

Lemma 2

For any fixed parameter
\eta_{g}>0
, we have:

\displaystyle\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\sum_{p=1}^{P}\hat{q}_{t}(p)\left(\hat{{\bf w}}_{k,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;-\min_{1\leq p\leq P}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\left(\hat{{\bf w}}_{k,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{j,t}\right)

\displaystyle\leq\frac{1}{\eta_{g}}\log{P}+\frac{9\eta_{g}KT}{8}.

Proof:
The proof is provided in Appendix
B
.

It is remarkable that Lemma 1 and Lemma 2 hold for any realization of our randomized algorithm. Setting
\eta_{l}={\cal O}(1\sqrt{T})
, the upper bound of Lemma
1
is bounded by
{\cal O}(\sqrt{T})
. Also, setting
\eta_{g}={\cal O}(1/\sqrt{T})
, the upper bound of Lemma
2
is bounded by
{\cal O}(\sqrt{T})
. We next show that our randomized algorithm, choosing one kernel at every time instead of using the combination of all
P
kernels, only leads to a bounded loss
{\cal O}(\sqrt{T})
.

Lemma 3

For some
\delta>0
, the following bound holds with at least probability
1-\delta
:

\displaystyle\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\Big(W_{t}^{{\sf T}}{\bf z}_{I_{t}}({\bf x}_{k,t}),y_{k,t}\Big)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;-\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\sum_{p=1}^{P}\hat{q}_{t}(p)\left(\hat{{\bf w}}_{k,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle\leq K\sqrt{\frac{\log(\delta^{-1})}{2}T}.

Proof:
The proof is provided in Appendix
C
.

Finally, from Lemma
1
, Lemma
2
and Lemma

with the parameters
\eta_{l}=\eta_{g}={\cal O}(1/\sqrt{T})

We evaluate the accuracy performances of the proposed MK-OFL for various online learning tasks such as online regressions and time-series predictions. The OFL system with

These choices are based on anytime strategy
[

]
, which is widely used in the context of online learning when

[

VI
Conclusion

We have proposed a novel online federated learning (OFL) framework with multiple kernels. The proposed method is dubbed multiple kernel-based OFL (MK-OFL). In the proposed MK-OFL, one kernel index is random selected from a predetermined set of
P
kernels at every time according to a carefully designed probability distribution. Also, the chosen index quickly converges to the best kernel in hindsight. Thus, our algorithm indeed exploits the advantage of using multiple kernels while having the same communication overhead with a single kernel-based OFL (SK-OFL). The asymptotic optimality of MK-OFL is proved using a martingale argument. Beyond the asymptotic analysis, we demonstrated the effectiveness of our algorithm in various online learning tasks with real-world datasets, which suggests practicality. One interesting future work is to extend MK-OFL into a wireless OFL framework, in which a distributed optimization at edge nodes and an optimal estimation at a server will be incorporated. Another interesting future work is to construct the so-called
collaborative OFL
by integrating collaborating learning with OFL so as to enable edge nodes to engage in OFL without directly connecting a server.

Appendix A
Proof of Lemma 1

Given the parameters
\hat{p}_{t}\in[P]
and
\hat{{\bf w}}_{t}
, the OGD update for any fixed
p\in[P]
is given as

\tilde{{\bf w}}_{k,t+1}^{p}=\hat{{\bf w}}_{k,t}^{p}-\eta_{\ell}\nabla{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}),

(28)

where

\hat{{\bf w}}_{k,t}^{p}=\begin{cases}\tilde{{\bf w}}_{k,t}^{p}&\mbox{ if }\hat{p}_{t}\neq p\\
\hat{{\bf w}}_{t}=\frac{1}{K}\sum_{k=1}^{K}\tilde{{\bf w}}_{k,t}^{p}&\mbox{ if }\hat{p}_{t}=p.\end{cases}

(29)

Our analysis is based on the regret analysis of OGD but carefully considering the above cases. From (
28
) and following the analysis of OGD, we have that for any
k\in{\cal V}
:

\displaystyle\|\tilde{{\bf w}}_{k,t+1}^{p}-{\bf w}_{p}^{\star}\|^{2}

\displaystyle=\|\hat{{\bf w}}_{k,t}^{p}-\eta_{\ell}\nabla{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t})-{\bf w}_{p}^{\star}\|^{2}

\displaystyle=\|\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}+\eta_{\ell}^{2}\|\nabla{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t})\|^{2}

\displaystyle-2\eta_{\ell}\nabla{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t})^{{\sf T}}(\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}).

(30)

Foe ease of exposition, throughout the proof, we let

\nabla_{k,t}^{p}\stackrel{{\scriptstyle\Delta}}{{=}}\nabla{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}).

(31)

According to the two cases in (
29
), we can get:

i) For
\hat{{\bf w}}_{k,t}^{p}=\tilde{{\bf w}}_{k,t}^{p}
(i.e.,
p\neq\hat{p}_{t}
), we have:

\displaystyle\|\tilde{{\bf w}}_{k,t+1}^{p}-{\bf w}_{p}^{\star}\|^{2}=\|\tilde{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}

\displaystyle\;\;\;\;\;\;\;\;\;\;\;+\eta_{\ell}^{2}\|\nabla_{k,t}^{p}\|^{2}-2\eta_{\ell}(\nabla_{k,t}^{p})^{{\sf T}}(\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}).

(32)

ii) For
\hat{{\bf w}}_{k,t}^{p}=\frac{1}{K}\sum_{k=1}^{K}\tilde{{\bf w}}_{k,t}^{p}
(i.e.,
p=\hat{p}_{t}
), we have:

\displaystyle\sum_{k\in[K]}\|\tilde{{\bf w}}_{k,t+1}^{p}-{\bf w}_{p}^{\star}\|^{2}\stackrel{{\scriptstyle(a)}}{{\leq}}\sum_{k\in[K]}\|\tilde{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}

\displaystyle+\eta_{\ell}^{2}\sum_{k\in[K]}\|\nabla_{k,t}^{p}\|^{2}-2\eta_{\ell}\sum_{k\in[K]}(\nabla_{k,t}^{p})^{{\sf T}}(\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}),

(33)

where (a) is due to the following fact:

\displaystyle\sum_{k\in[K]}\|\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}=\frac{1}{K^{2}}\sum_{k\in[K]}\left\|\sum_{\ell\in[K]}\tilde{{\bf w}}_{\ell,t}^{p}-{\bf w}_{p}^{\star}\right\|^{2}

\displaystyle\leq\frac{1}{K}\sum_{k\in[K]}\|\tilde{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}\leq\sum_{k\in[K]}\|\tilde{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}.

Leveraging the convexity of a loss function, we obtain that for any
k\in{\cal V}
:

\displaystyle{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})-{\cal L}(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})

\displaystyle\leq(\nabla_{k,t}^{p})^{{\sf T}}(\hat{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}).

(34)

Plugging (
34
) into (
32
) and (
33
) separately, and combining these two cases, we can get

\displaystyle\sum_{k=1}^{K}{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})-{\cal L}(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})

\displaystyle\leq\sum_{k=1}^{K}\frac{\|\tilde{{\bf w}}_{k,t}^{p}-{\bf w}_{p}^{\star}\|^{2}-\|\tilde{{\bf w}}_{k,t+1}^{p}-{\bf w}_{p}^{\star}\|^{2}}{2\eta_{\ell}}

\displaystyle+\frac{\eta_{\ell}}{2}\sum_{k=1}^{K}\|\nabla_{k,t}^{p}\|^{2}.

(35)

Summing (
35
) over
t=1,...,T
, we obtain that for any fixed
p\in[P]
,

\displaystyle\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}((\tilde{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})-{\cal L}(({\bf w}_{p}^{\star})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{t})

\displaystyle\stackrel{{\scriptstyle(a)}}{{\leq}}\sum_{t=1}^{T}\sum_{k=1}^{K}\frac{\|\tilde{{\bf w}}_{k,1}^{p}-{\bf w}_{p}^{\star}\|^{2}}{2\eta_{\ell}}+\frac{\eta_{\ell}}{2}\sum_{t=1}^{T}\sum_{k=1}^{K}\|\nabla_{k,t}^{p}\|^{2}

\displaystyle\stackrel{{\scriptstyle(b)}}{{\leq}}\frac{KC^{2}}{2\eta_{\ell}}+\frac{\eta_{\ell}KL^{2}T}{2},

(36)

where (a) is due to the telescoping sum and (b) is from the Assumption 2 and Assumption 3. This completes the proof of Lemma 1.

Proof of Lemma 2

Recall that

L_{t}^{p}=\exp\left(-\eta_{g}\sum_{k=1}^{K}{\cal L}((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t})\right).

(37)

Also, to simplify the expressions, we let

\hat{f}_{k,t}^{p}({\bf x})\stackrel{{\scriptstyle\Delta}}{{=}}(\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}).

(38)

Then, the proof will be completed by comparing the upper and lower bounds of
\zeta
, which is defined below:

\displaystyle\zeta=\sum_{t=1}^{T}\log\left(\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)\exp\left(-\eta_{g}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{p}({\bf x}_{k,t}),y_{k,t})\right)\right).

We first derive the upper bound on
\zeta
such as

\displaystyle\zeta

\displaystyle=\sum_{t=1}^{T}\log\left(\mbox{\bb E}_{I_{t}}\left[\exp\left(-\eta_{g}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{I_{t}}({\bf x}_{k,t}),y_{k,t})\right)\right]\right)

\displaystyle\stackrel{{\scriptstyle(a)}}{{\leq}}-\eta_{g}\sum_{t=1}^{T}\sum_{k=1}^{K}\mbox{\bb E}_{I_{t}}\left[{\cal L}(\hat{f}_{k,t}^{I_{t}}({\bf x}_{k,t}),y_{k,t})\right]+\frac{\eta_{g}^{2}KT}{8}

{\cal L}(\hat{f}_{k,t}^{I_{t}}({\bf x}_{k,t}),y_{k,t})\in[0,1]
and (b) is from Assumption 1 (i.e., the convexity of a loss function). We next derive the lower bound on
\zeta
as follows:

\displaystyle\zeta=\sum_{t=1}^{T}\log\left(\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)\exp\left(-\eta_{g}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{p}({\bf x}_{k,t}),y_{k,t})\right)\right)

\displaystyle\stackrel{{\scriptstyle(a)}}{{=}}\sum_{t=1}^{T}\log\left(\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)\exp\left(-\eta_{g}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{p}({\bf x}_{k,t}),y_{k,t})\right)\right)

\displaystyle\;\;\;\;\;+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle\stackrel{{\scriptstyle(b)}}{{=}}\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\bar{{\bf m}}_{t+1}(p)}{\sum_{p=1}^{P}\bar{{\bf m}}_{t}(p)}\right)+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle\stackrel{{\scriptstyle(c)}}{{=}}\log\left(\sum_{p=1}^{P}\bar{{\bf m}}_{T+1}(p)\right)-\log\left(\sum_{p=1}^{P}\bar{{\bf m}}_{1}(p)\right)

\displaystyle\;\;\;\;\;+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle\geq\log\left(\max_{1\leq p\leq P}\bar{{\bf m}}_{T+1}\right)-\log{P}

\displaystyle\;\;\;\;\;+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle=-\eta_{g}\min_{1\leq p\leq P}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{p}({\bf x}_{k,t}),y_{k,t})-\log{P}

\displaystyle\;\;\;\;\;+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right),

where (a) follows the definition of
L_{t}^{p}
in the main document, (b) is from the definitions of
\bar{{\bf q}}_{t}(p)
and
\bar{w}_{t}(p)
, and (c) is due to the telescoping sum. From the upper and lower bounds, we can get

\displaystyle-\eta_{g}\min_{1\leq p\leq P}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}(\hat{f}_{k,t}^{p}({\bf x}_{k,t}),y_{k,t})-\log{P}

\displaystyle+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle\leq-\eta_{g}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\mbox{\bb E}_{I_{t}}[\hat{f}_{k,t}^{I_{t}}({\bf x}_{k,t})],y_{k,t}\right)+\frac{\eta_{g}^{2}KT}{8}.

By rearranging them, we have:

\displaystyle\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left(\sum_{p=1}^{P}\hat{q}_{t}(p)\left(\hat{{\bf w}}_{k,t}^{p}\right)^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right)

\displaystyle-\min_{1\leq p\leq P}\sum_{t=1}^{T}\sum_{k=1}^{K}{\cal L}\left((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{j,t}\right)

\displaystyle\leq\frac{1}{\eta_{g}}\log{P}+\frac{\eta_{g}KT}{8}+\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right).

Also, we have the following inequality:

\displaystyle\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)L_{t}^{p}}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)L_{t}^{p}}\right)

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\stackrel{{\scriptstyle(a)}}{{\leq}}\sum_{t=1}^{T}\log\left(\frac{\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p)}{\sum_{p=1}^{P}\bar{{\bf q}}_{t}(p)}\right)+\eta_{g}KT

where (a) is due to the fact that

\mbox{\bb E}[X_{j,t}|{\cal F}_{t-1}]=0,

because

\displaystyle\mbox{\bb E}\left[{\cal L}\left(W_{t}^{{\sf T}}{\bf z}_{I_{t}}({\bf x}_{k,t}),y_{k,t}\right)\Big|{\cal F}_{t-1}\right]

\displaystyle\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;=\sum_{p=1}^{P}\hat{{\bf q}}_{t}(p){\cal L}\left((\hat{{\bf w}}_{k,t}^{p})^{{\sf T}}{\bf z}_{p}({\bf x}_{k,t}),y_{k,t}\right).

Thus,
\{X_{k,t}:t\in[T]\}
is a martingale difference sequence and
X_{k,t}\in[B_{t},B_{t}+c_{t}]
is bounded, where
B_{t}=-U_{t}
is a random variable and
{\cal F}_{t-1}
measurable, and
c_{t}=1
. From Azuma-Hoeffding’s inequality, the following bound holds for some
\delta>0
with at least probability
1-\delta
:

\displaystyle\sum_{t=1}^{T}X_{k,t}\leq\sqrt{\frac{\log{\delta^{-}1}}{2}T}.

(39)

Since this is true for any
k\in{\cal V}
, we have:

\sum_{t=1}^{T}\sum_{k=1}^{K}X_{k,t}\leq K\sqrt{\frac{\log{\delta^{-}1}}{2}T}.

(40)

This completes the proof.
