Randomize the Future: Asymptotically Optimal Locally Private Frequency Estimation Protocol for Longitudinal Data CCS: Security and privacy Privacy-preserving protocols
Olga Ohrimenko, Anthony Wirth, Hao Wu

Abstract
. Longitudinal data tracking under Local Differential Privacy ( LDP ) is a challenging task. Baseline solutions that repeatedly invoke a protocol designed for one-time computation lead to linear decay in the privacy or utility guarantee with respect to the number of computations. To avoid this, the recent approach of Erlingsson et al. 2019 ( ( Úlfar Erlingsson et al. 2020 ) ) exploits the potential sparsity of user data that changes only infrequently. Their protocol targets the fundamental problem of frequency estimation for longitudinal binary data, with ℓ ∞ \ell_{\infty} error of O ⁡ ( ( 1 / ε ) ⋅ ( log ⁡ d ) 3 / 2 ⋅ k ⋅ n ⋅ log ⁡ ( d / β ) ) O((1/\varepsilon)\cdot(\log d)^{3/2}\cdot k\cdot\sqrt{n\cdot\log(d/\beta)}) , where ε \varepsilon is the privacy budget, d d is the number of time periods, k k is the maximum number of changes of user data, and β \beta is the failure probability. Notably, the error bound scales polylogarithmically with d d , but linearly with k k . In this paper, we break through the linear dependence on k k in the estimation error. Our new protocol has error O ⁡ ( ( 1 / ε ) ⋅ ( log ⁡ d ) ⋅ k ⋅ n ⋅ log ⁡ ( d / β ) ) O((1/\varepsilon)\cdot(\log d)\cdot\sqrt{k\cdot n\cdot\log(d/\beta)}) , matching the lower bound up to a logarithmic factor. The protocol is an online one, that outputs an estimate at each time period. The key breakthrough is a new randomizer for sequential data, FutureRand , with two key features. The first is a composition strategy that correlates the noise across the non-zero elements of the sequence. The second is a pre-computation technique which, by exploiting the symmetry of input space, enables the randomizer to output the results on the fly, without knowing future inputs. Our protocol closes the error gap between existing online and offline algorithms.



1.
Introduction

Frequency estimation underlines a wide range of applications in data mining and machine learning (for example, learning users’ preferences, uncovering commonly used phrases, and finding popular URLs).
However, the data collected for the frequency analysis can contain sensitive personal information such as income, gender, health information, etc.
To protect this information from the data collector, the local model of differential privacy (
LDP
) has been deployed by companies including Google
(
Erlingsson
et al. 2014
;
Fanti
et al. 2016
)
, Apple
(
Team 2017
)
and Microsoft
(
Ding
et al. 2017
)
.
In
LDP
, each user perturbs their data locally before reporting it to the (untrusted) data collector (aka server) for analysis.

Existing solutions typically focus on one-time computation.
However practical applications often involve continuous monitoring in order to discover trends over time.
For example, search-engine providers keep track of popular URLs. The naive solution of repeated computation leads to a rapid degradation of privacy guarantee, that scales linearly with the number of computations
(
Dwork and Roth 2014
)
.
But such degradation is unnecessary, when users’ data changes infrequently.
For example, a list of frequently visited URLs by a user changes little everyday.

The observation of infrequent data changes is captured by
Erlingsson et al. 2019

(
Úlfar Erlingsson et al. 2020
)
.
Noting that many
LDP
algorithms
(
Bun
et al. 2019
;
Bassily et al. 2020
;
Erlingsson
et al. 2014
;
Nguyên et al. 2016
)
require each client to send just one bit to the server, they formulated the following longitudinal data tracking problem for Boolean data.

Research Problem:

Given a set of
n
users, each holding a Boolean value that changes at most
k
times across
d
time periods; the server needs to report the number of users holding Boolean value
1
at each time period.

The problem is presented in an online setting; in an offline setting, the server reports an estimate only after
d
time periods.
Though here we study the problem over Boolean data, our algorithm
can be adapted to solve frequency estimation and heavy hitter problems in richer domains via existing techniques
(
Bun
et al. 2019
;
Bassily et al. 2020
;
Joseph
et al. 2018
;
Erlingsson
et al. 2014
;
Fanti
et al. 2016
)
.

For privacy budget
\varepsilon
and failure probability
\beta
,
Erlingsson et al. 2019
described a protocol that achieves maximum estimation error
O((1/\varepsilon)\cdot(\log d)^{3/2}\cdot k\cdot\sqrt{n\cdot\log(d/\beta)})

(
Úlfar Erlingsson et al. 2020
)
, and scales only linearly with
k
and not
d
.
In this paper we study the following question:

Research Question:

Can the estimation error for the (online) longitudinal data tracking problem above be reduced to sub-linear in
k
?

Besides improvement on previous work in terms of the error, answering this question can
close the gap between error guarantees of the online algorithm and the lower bound
of
\Omega((1/\varepsilon)\cdot\sqrt{k\cdot n\cdot\log(d/k)})

that was recently presented in
(
Zhou
et al. 2021
)
.

Our Contributions.

In this work, we provide a new
LDP
protocol whose error scales with the square root of the number of data changes.
Specifically, it achieves error

O\big((1/\varepsilon)\cdot(\log d)\cdot\sqrt{k\cdot n\cdot\log(d/\beta)}\big).

Our protocol builds on a standard technique for converting the original data sequence into a sparse one
(
Úlfar Erlingsson et al. 2020
)
, hierarchical aggregation scheme for releasing continual data
(
Dwork
et al. 2010
)
, and a new randomizer,
FutureRand
, for sequential data.
The
FutureRand
has two key components, a composed randomizer
\tilde{\mathcal{R}}:\left\{{-1,1}\right\}^{k}\rightarrow\left\{{-1,1}\right\}^{k}
for the non-zero coordinates of the input sequence, and a pre-computation technique that enables
\tilde{\mathcal{R}}
to handle online inputs.
The main properties of
\tilde{\mathcal{R}}
, which play vital role in establishing privacy guarantee and achieving a
\sqrt{k}
estimation error, are stated below: assuming that
\varepsilon\leq 1

•

There exit
p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}\in{({0,1})}
with
p_{\text{max}}^{\prime}\leq e^{\varepsilon}\cdot p_{\text{min}}^{\prime}
, such that for each input sequence
b\in\left\{{-1,1}\right\}^{k}
, and each sequence
s\in\left\{{-1,1}\right\}^{k}
, then

\Pr[\tilde{\mathcal{R}}(b)=s]\in{[{p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}}]}.

•

For a given input
b
, denote
\tilde{b}\doteq\tilde{\mathcal{R}}(b)
the output of
\tilde{\mathcal{R}}
.
There exists some
c_{\text{gap}}\in\Omega{({\varepsilon/\sqrt{k}})}
, such that for each input
b\in\left\{{-1,1}\right\}^{k}
, and for each
i\in{[{k}]}
,

\Pr[\tilde{b}_{i}=b_{i}]-\Pr[\tilde{b}_{i}=-b_{i}]=c_{\text{gap}}\in\Omega{({\varepsilon/\sqrt{k}})}.

\tilde{\mathcal{R}}
builds on the composed randomizer proposed by
Bun
et al. 2019

(
Bun
et al. 2019
)
.
The design in
(
Bun
et al. 2019
)
focused on preserving the statistical distance between the distribution of the output of the composed randomizer, and joint distribution of
k
independent randomized responses.
This difference in the problem setting requires non-trivial changes in terms of parameters, assumptions and analysis.
The proof in
(
Bun
et al. 2019
)
relies extensively on the concentration and anti-concentration inequalities;
in comparison, our proof avoids this and investigates the inherent structure of the problem.
Finally,
Bun
et al. 2019
’s original design
(
Bun
et al. 2019
)
applies only to offline inputs.
Our paper develops the pre-computation technique for converting it into an online one.

2.
Problem Definition

We present formally the longitudinal data tracking problem first introduced by
Erlingsson et al. 2019

(
Úlfar Erlingsson et al. 2020
)
.
There is a server and a set of
n
users, each holding a Boolean data item that changes at most
k
times across the
d
time periods.
Without loss of generality, we assume that
d
is a power of
2
.
For user
u\in[n]
, denote the value sequence of its Boolean data across the
d
time periods as

{\text{st}}_{u}=({\text{st}}_{u}[1],\ldots,{\text{st}}_{u}[d])\in\left\{{0,1}\right\}^{d}\,.

For each time
t\in[d]
, denote the number of users with value
1
by

(1)

{a}[t]\doteq\sum_{u\in[n]}{\text{st}}_{u}[t].

Definition 2.1 (
(\alpha,\beta)
-Accurate Protocol).

Given
\alpha>0
, and
\beta\in(0,1)
, a server-side algorithm is called an
(\alpha,\beta)
-accurate protocol for longitudinal data collection if it outputs at each time
t\in[d]
, an estimate
\hat{{a}}[t]
of
{a}[t]
, such that

\begin{array}[]{c}\Pr[\max_{t\in[d]}\left|\hat{{a}}[t]-{a}[t]\right|>\alpha]\leq\beta\,.\end{array}

Definition 2.2 (Differential Privacy
(
Dwork and Roth 2014
)
).

Let
\mathcal{A}:\mathcal{D}\rightarrow\mathcal{Y}
be a randomized algorithm.
Algorithm
\mathcal{A}
is called
\varepsilon
-differentially private if for all
v,v^{\prime}\in\mathcal{D}
and all (measurable)
Y\subseteq\mathcal{Y}
,

(2)

\Pr[\mathcal{A}(v)\in Y]\leq e^{\varepsilon}\cdot\Pr[\mathcal{A}(v^{\prime})\in Y]\,.

The parameter
\varepsilon
characterizes the similarity of the output distributions of
\mathcal{A}(v)
and
\mathcal{A}(v^{\prime})
, and is called the
privacy budget
.

A data-collecting protocol is called
\varepsilon{}
-locally differentially private (
LDP
) if each user reports only a version of their data perturbed locally by an
\varepsilon{}
-differentially private algorithm.

Problem 2.3 (Private Longitudinal Data Collection).

Given privacy parameter
\varepsilon{}
, and failure probability
\beta
, design an
\varepsilon
-locally differentially private
(\alpha,\beta)
-accurate protocol for longitudinal data collection, that minimizes
\alpha
.

Our goal is to achieve an
\alpha\in O((1/\varepsilon)\cdot(\log d)\cdot\sqrt{k\cdot n\cdot\log(d/\beta)})
.

Preliminaries

We use the following notation.
For every
i,j\in\mathbb{N}
, such that
i\leq j
,
[{i}\,.\,.\,{j}]
denotes the set of integers
\left\{{i,\ldots,j}\right\}
.
For each
j\in\mathbb{N}^{+}
, set
{[{j}]}
refers to
[{1}\,.\,.\,{j}]
.

As the data of each user
u
changes at most
k
times, we introduce the following transformation of
X_{u}
into a sparse vector, which has at most
k
non-zero coordinates.

Definition 3.1 (Data Derivative
(
Úlfar Erlingsson et al. 2020
)
).

For each user
u
and for all
t\in{[{d}]}
, let
X_{u}{[{t}]}\doteq{\text{st}}_{u}{[{t}]}-{\text{st}}_{u}{[{t-1}]}
, where for convenience, we assume that
{\text{st}}_{u}{[{0}]}=0
, so that
X_{u}{[{1}]}
is well defined.
The discrete derivative of user data is

X_{u}={({X_{u}{[{1}]},\ldots,X_{u}{[{d}]}})}\in\left\{{-1,0,1}\right\}^{d}.

For example, if
{\text{st}}_{u}={({0,1,1,0})}
, then
X_{u}={({0,1,0,-1})}
.
Observe that for each
t\in{[{d}]}
,

{\text{st}}_{u}{[{t}]}=\sum_{t^{\prime}\in{[{t}]}}X_{u}{[{t^{\prime}}]}.

We are interested in the cumulative data changes over intervals whose length is a power of
2
: such intervals are called

.

Definition 3.2 (Dyadic Intervals).

For each
h\in[{0}\,.\,.\,{\log d}]
, and each
j\in{[{d/2^{h}}]}
, define the dyadic interval
\mathcal{I}_{h,j}\doteq\{(j-1)\cdot 2^{h}+1,\ldots,j\cdot 2^{h}\}
, where
h
is called its

.
Denote the collection of dyadic intervals of order
h
by

\textit{ISet}[{h}]\doteq\left\{{\mathcal{I}_{h,j}:j\in{[{d/2^{h}}]}}\right\}\,,

and the collection of all dyadic intervals by

\textit{ISet}\doteq\cup_{h\in[{0}\,.\,.\,{\log d}]}\textit{ISet}[{h}]\,.

Interval
\mathcal{I}
represents an element from

.

For each

Example 3.5.

Suppose that

.
The possible partial sums are

For each

Recall that
{\text{st}}_{u}{[{t}]}=\sum_{t^{\prime}\in{[{t}]}}X_{u}{[{t^{\prime}}]}

It can be viewed as the cumulative data change from time

If we decompose the interval

Fact 3.8.

(Dyadic Decomposition)
For each

{[{t}]}
can be decomposed into a minimum collection,

For example, the dyadic decomposition of the interval

\left\{{\left\{{2}\right\},\left\{{3}\right\}}\right\}

For each time

4.
Framework

In this section, we introduce an
LDP
protocol
that achieves our proposed error guarantee.
It improves the previously known bound
(
Úlfar Erlingsson et al. 2020
)
by a factor of
\sqrt{k}
. The main result of the paper is summarized as follows:

Theorem 4.1.

Assuming that
\varepsilon\leq 1
, and
\varepsilon^{-1}\cdot{({\log d})}\cdot\sqrt{k\cdot\ln{({d/\beta})}}

\leq\sqrt{n}
, there is an
\varepsilon
-local differentially private protocol, such that, with probability at least
1-\beta
, its
d
estimates
\{\hat{{a}}[t]\}
of
\{{a}[t]\}
satisfy

\max_{t\in[d]}\left|{\hat{{a}}[t]-{a}[t]}\right|\in O\left(\frac{\log d}{\varepsilon}\cdot\sqrt{k\cdot n\cdot\ln\frac{d}{\beta}}\right)\,.

The assumption
\varepsilon^{-1}\cdot{({\log d})}\cdot\sqrt{k\cdot\ln{({d/\beta})}}\leq\sqrt{n}
ensures that
\varepsilon^{-1}\cdot{({\log d})}\cdot\sqrt{k\cdot n\cdot\ln{({d/\beta})}}\leq n
, avoiding a trivial bound.

4.1.
Overview

Our framework is split between the user (or client) and the server.
Each user reports perturbed data to the server, who aggregates
the data from all users and computes the required statistics while adjusting for the noise in the reports.

As a warm up consider the following (non-private) naive protocol.
Here, each user
u\in{[{n}]}
computes and reports (to the server) each partial sum
S_{u}({\mathcal{I}_{h,j}})
immediately after it has all the data needed for the computation.
In particular, since the last number in the dyadic interval
\mathcal{I}_{h,j}
is
j\cdot 2^{h_{u}}
, the last data point needed to compute
S_{u}({\mathcal{I}_{h,j}})
is
X_{u}{[{j\cdot 2^{h_{u}}}]}
.
Based on the reports of the partial sums, according to Equation (
6
), the server can obtain for each
t\in[d]
a precise value of
{a}[t]
.

The naive protocol does not provide LDP guarantees. To this end, our algorithms build on a combination of the following two reporting techniques.

Reporting based on Sampling.

Suppose, instead of reporting every
partial sum, each user
u\in{[{n}]}
samples an integer
h_{u}\in[{0}\,.\,.\,{\log d}]
uniformly at random, and reports only the partial sums with order
h_{u}
.
The server no longer has exact values of the
{a}[t],\forall t\in{[{d}]}
.
However, the server can easily construct an unbiased estimate.
For each
h\in[{0}\,.\,.\,{\log d}]
, and each
j\in{[{d/2^{h}}]}
, let
z_{u}[h,j]
be the server’s estimate of
S_{u}({\mathcal{I}_{h,j}})
.
If it sets
z_{u}[h,j]=(1+\log d)\cdot\mathds{1}_{\left[h_{u}=h\right]}\cdot S_{u}({\mathcal{I}_{h,j}})
, where
\mathds{1}_{\left[h_{u}=h\right]}
is the indicator for the event
h_{u}=h
,
then

z_{u}[h,j]
is an unbiased estimate of
S_{u}({\mathcal{I}_{h,j}})
.
Via linearity of expectation, replacing
S_{u}({\mathcal{I}_{h,j}})
in Equation (
6
) with
z_{u}[h,j]
gives an unbiased estimator
{a}[t]
.

Reporting with Perturbation.

In the previous paragraph, conditioned on
h_{u}=h
, user
u\in{[{n}]}
reports a sequence of
L\doteq d/2^{h}
partial sums with order
h
to the server, each taking value in
\left\{{-1,0,1}\right\}
according to Equation (
5
).
To achieve
LDP
with this approach, the user
u
should invoke some randomizer
\mathcal{M}
, to perturb their partial sums before reporting.
This also requires a change in computing the estimators
z_{u}[h,j]
with respect to
\mathcal{M}
.
Our randomizer,
\mathcal{M}
, exploits sparsity: there are at most
k
non-zero partial sums with order
h

(Observation
3.6
).

4.2.
Client Side

Randomizer.

Let
\mathcal{M}
be a client-side randomizer. Our protocol relies on a randomizer

\mathcal{M}
that provides the following functionalities and has three properties described below.

\mathcal{M}
has an (optional) initialization phase
\mathcal{M}.\textit{init}(L,k,\varepsilon)
, with parameters the length of the input
L
, the maximum number of non-zero elements in the input
k
, and the privacy budget
\varepsilon
.
In this phase,
\mathcal{M}
can perform some pre-computation whose result is kept for reference later.

During the protocol,
\mathcal{M}
takes as input a sequence
v_{1},\ldots,v_{L}
where each value is in
\{-1,0,1\}
, corresponding to user’s data, and outputs a sequence
\mathcal{M}^{(1)}(v_{1}),\ldots,\mathcal{M}^{(L)}(v_{L})\in\{-1,1\}
.
The output of
\mathcal{M}^{(j)}(v_{j})
may depend not only on the input
v_{j}
and the randomness of
\mathcal{M}^{(j)}
, but also on the pre-computation result, the past inputs
v_{1},\dots,v_{j-1}
and outputs
\mathcal{M}^{(1)}(v_{1}),\ldots,\mathcal{M}^{(j-1)}(v_{j-1})
.

Finally,
\mathcal{M}
should satisfy the following three properties.

Property I.:

Given
L
,
k
and
\varepsilon\leq 1
, there exists
p_{\text{min}},p_{\text{max}}\in{({0,1})}
, such that
p_{\text{max}}/p_{\text{min}}\leq e^{\varepsilon}
, and that for each
k
-sparse input sequence
v_{1},\ldots,v_{L}\in\left\{{-1,0,1}\right\}
, and each sequence
w_{1},\ldots,

w_{L}\in\left\{{-1,1}\right\}
,

(7)

\hskip-2.84526pt\Pr[M^{(1)}(v_{1})=w_{1},\ldots,M^{(L)}(v_{L})=w_{L}]\in{[{p_{\text{min}},p_{\text{max}}}]}\,.

Property II. :

There exits
c_{\text{gap}}\in{({0,1})}
, such that for all
j\in{[{L}]}
, if
v_{j}\neq 0
,

(8)

\Pr[\mathcal{M}^{(j)}(v_{j})=v_{j}]-\Pr[\mathcal{M}^{(j)}(v_{j})=-v_{j}]=c_{\text{gap}}\,.

Property III.:

For all
j\in{[{L}]}
, if
v_{j}=0
,

(9)

\Pr[\mathcal{M}^{(j)}(v_{j})=1]=\Pr[\mathcal{M}^{(j)}(v_{j})=-1]=\frac{1}{2}\,.

Example 4.2.

The following randomizer
(
Warner 1965
)
satisfies these three properties.
Suppose that
\mathcal{M}
perturbs each coordinate independently such that: if
v_{j}\neq 0
, then
\Pr[\mathcal{M}^{(j)}(v_{j})=v_{j}]=e^{\varepsilon/k}/{({e^{\varepsilon/k}+1})}
and
\Pr[\mathcal{M}^{(j)}(v_{j})=-v_{j}]=1/{({e^{\varepsilon/k}+1})}
; if
v_{j}=0
, then
\mathcal{M}^{(j)}(v_{j})
outputs
-1
or
1
, uniformly at random.
Now,
Property II
and
Property III
are clearly satisfied with
c_{\text{gap}}={({e^{\varepsilon/k}-1})}/{({e^{\varepsilon/k}+1})}
.
Finally, it can be verified that
Property I
is satisfied, with
p_{\text{min}}=2^{-(L-k)}\cdot{({e^{\varepsilon/k}+1})}^{-k}
and

Intuitively,

is the common difference between the coordinate preservation and reversal probabilities.

Property III
requires that
\mathcal{M}
outputs

-1

Based on

and

Observation 4.3.

For

\Expectation\left[{({c_{\text{gap}}})}^{-1}\cdot\mathcal{M}^{(j)}(v_{j})\right]=v_{j}.

Finally, the procedure creates a variable
\mathsf{nnz}
with value
0
; the variable
\mathsf{nnz}
is shared by other procedures, to keep track of the support of the input sequence received so far.

\mathcal{M}^{(j)}{({v_{j}})}
.

For all
j\in{[{L}]}
,
\mathcal{M}^{(j)}{({v_{j}})}
shares the same pseudo-codes. If
v_{j}=0
, the procedure outputs
-1
or
+1
, uniformly at random.
Otherwise, it increases
\mathsf{nnz}
by
1
, indicating that
v_{j}
is the
{({\mathsf{nnz}})}^{(th)}
non-zero entry processed by the procedure.
Then it outputs the value of
v_{j}
multiplied by
\tilde{b}_{\mathsf{nnz}}
.

Analysis.

We need to prove that
Property I
and
Property II
hold.
Consider the events
E_{1}
and
E_{2}
defined as before.
We see that
\Pr[E_{1}]
remains the same.
Denote the indices in
\text{supp}(v)
as
j_{1}<\cdots<j_{k}
.
Based on our modification, for each
i\in{[{k}]}
, we have

\mathcal{M}^{(j_{i})}(v_{j_{i}})=\tilde{b}_{i}\cdot v_{j_{i}}
.
Hence, event
E_{2}
holds only if for each
i\in{[{k}]}
,

\tilde{b}_{i}\cdot v_{j_{i}}=w_{j_{i}}
, equivalently,
\tilde{b}_{i}=w_{j_{i}}/v_{j_{i}}
.
Since
\tilde{b}=\tilde{\mathcal{R}}(1^{k})
, applying Lemma
5.2
with
s={({w_{j_{1}}/v_{j_{1}},\ldots,w_{j_{k}}/v_{j_{k}}})}
,
it holds that

\Pr[E_{2}]=\Pr[\tilde{b}=s]=\Pr[\tilde{\mathcal{R}}(1^{k})=s]\in{[{p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}}]}\,.

It follows that Inequality (
18
) still holds, and therefore
Property I
.

Finally, observe that
\mathcal{M}^{(j_{i})}(v_{j_{i}})=v_{j_{i}}
if
\tilde{b}_{i}=1
; and
\mathcal{M}^{(j_{i})}(v_{j_{i}})=-v_{j_{i}}
if
\tilde{b}_{i}=-1
.
Since
\tilde{b}=\tilde{\mathcal{R}}{({1^{k}})}
, we have
\Pr[\tilde{b}_{i}=1]-\Pr[\tilde{b}_{i}=-1]=c_{\text{gap}}
.
Therefore,
Property II
holds with
c_{\text{gap}}\in\Omega{({\varepsilon/\sqrt{k}})}
.

5.4.
Online Input with Bounded Support Size

In this step, we relax the constraint that vector
v
contains exactly
k
non-zero coordinates.
In particular, we show that
Property I
and
Property II
still hold, if the same protocol discussed in Section
5.3
acts on input with support less than
k
.
In the case
\left|{\text{supp}(v)}\right|=k
, each bit of the pre-generated vector
\tilde{b}=\tilde{\mathcal{R}}(1^{k})
is used to multiply some non-zero coordinate of
v
.
In the case
\left|{\text{supp}(v)}\right|<k
, however, only the first
\left|{\text{supp}(v)}\right|
bits of
\tilde{b}
are used.

Analysis.

With a similar argument as previous section,
Property II
holds with
c_{\text{gap}}\in\Omega{({\varepsilon/\sqrt{k}})}
.
To verify
Property I
, we prove that Inequality (
18
) still holds.
Consider the events
E_{1}
and
E_{2}
defined as before.
We have
\Pr[E_{1}]=2^{-(L-\left|{\text{supp}(v)}\right|)}
as the
\mathcal{M}^{(j)}(v_{j})
variables are independent in
\{-1,1\}
random variables for
j\notin\text{supp}(v)
.
The event
E_{2}
happens if only for each
i\in{[{\left|{\text{supp}(v)}\right|}]}
, it holds that
\tilde{b}_{i}={w_{j_{i}}}/{v_{j_{i}}}
.
Let
\mathcal{G}
be the subset of sequence
s\in\left\{{-1,1}\right\}^{k}
which satisfies
s_{i}={w_{j_{i}}}/{v_{j_{i}}}
, for each
i\in{[{\left|{\text{supp}(v)}\right|}]}
.
There are
2^{k-\left|{\text{supp}(v)}\right|}
such possible sequences, each being outputted by
\tilde{\mathcal{R}}{({1^{k}})}
with probability between
{[{p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}}]}
(by Lemma
5.2
).
Therefore,

\Pr[E_{2}]=\Pr[\tilde{b}\in\mathcal{G}]\in 2^{k-\left|{\text{supp}(v)}\right|}\cdot{[{p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}}]}.

Multiplying it by
\Pr[E_{1}]=2^{-(L-\left|{\text{supp}(v)}\right|)}
proves Inequality (
18
).

Sketch Proofs

We conclude the technical presentation with outlines of our proofs for Lemma
5.2
and
5.3
.
The complete proofs for Lemma
5.2
and
5.3
are included in Appendix
A.1.1
and
A.1.2
, respectively.

We use the following notation.
As before, denote
p=1/(e^{\tilde{\varepsilon}}+1)
.
Note that
1-p=e^{\tilde{\varepsilon}}p
.
For each
i\in[{0}\,.\,.\,{k}]
, define

g(i)\doteq p^{i}(1-p)^{k-i}=p^{k}\cdot e^{\tilde{\varepsilon}\cdot(k-i)}\,.

We see that
g
is a decreasing function with respect to
i
.
For each
b\in\left\{{-1,1}\right\}^{k}
, denote the result of applying
\mathcal{R}
independently to each of its coordinates as
\mathcal{R}(b)\doteq{({\mathcal{R}(b_{1}),\ldots,\mathcal{R}(b_{k})})}
.
For each
s\in\left\{{-1,1}\right\}^{k}
, it is easy to verify that
\Pr[\mathcal{R}(b)=s]=g{({\left\|{s-b}\right\|_{0}})}
,
where
\left\|{\cdot}\right\|_{0}
is the
\ell_{0}
norm, and therefore
\left\|{b-s}\right\|_{0}
is the number of coordinates in which
s
differs from
b
.
Since in expectation,
\left\|{\mathcal{R}(b)-b}\right\|=kp
,
we define

\displaystyle p_{\text{avg}}\doteq g(kp)=p^{kp}(1-p)^{k-kp}=p^{k}\cdot e^{\tilde{\varepsilon}\cdot(k-kp)}.

Proof Outline for Lemma
5.2
.

Let
b\in\left\{{-1,1}\right\}^{k}
be an input to
\tilde{\mathcal{R}}
.
Recall that
\tilde{\mathcal{R}}
first computes
b^{\prime}=\mathcal{R}(b)\doteq{({\mathcal{R}(b_{1}),\ldots,\mathcal{R}(b_{k})})}
.
If
b^{\prime}\in\textbf{Ann}(b)
,
\tilde{\mathcal{R}}
outputs it directly.
Otherwise,
\tilde{\mathcal{R}}
outputs a uniform sample from
\left\{{-1,1}\right\}^{k}\setminus\textbf{Ann}(b)
.
At a high level,
\textbf{Ann}(b)
consists of the
s\in\left\{{-1,1}\right\}^{k}
for which
\Pr[\mathcal{R}(b)=s]
is close to
p_{\text{avg}}
, and
\tilde{\mathcal{R}}
keeps their output probabilities.
On the other hand,
\left\{{-1,1}\right\}^{k}\setminus\textbf{Ann}(b)
consists of the
s
for which
\Pr[\mathcal{R}(b)=s]
is much higher or lower than
p_{\text{avg}}
, and
\tilde{\mathcal{R}}
averages their output probabilities by uniform sampling.
We will show that in both cases,
\Pr[\tilde{\mathcal{R}}(b)=s]\approx p_{\text{avg}}
.
Formally,

(19)

\displaystyle\Pr[\tilde{\mathcal{R}}(b)=s]

\displaystyle\in\left[1/2^{k},e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}\right],\,\quad\forall s\in\textbf{Ann}(b)\,,

(20)

\displaystyle\Pr[\tilde{\mathcal{R}}(b)=s]

\displaystyle\in\left[e^{-3\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}},1/2^{k}\right],\,\quad\forall s\notin\textbf{Ann}(b)\,.

Let
p_{\text{min}}^{\prime}=e^{-3\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}
and
p_{\text{max}}^{\prime}=e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}
.
Since
\tilde{\varepsilon}=\varepsilon/{({5\sqrt{k}})}
,
p_{\text{max}}^{\prime}=e^{\varepsilon}\cdot p_{\text{min}}
.
Combing Inequality (
19
) and Inequality (
20
), we know that for all
s\in\left\{{-1,1}\right\}^{k}
,
\Pr[\tilde{\mathcal{R}}(b)=s]\in{[{p_{\text{min}}^{\prime},p_{\text{max}}^{\prime}}]}
, which proves Lemma
5.2
.
We now prove these two inequalities separately.

Bounding
\Pr[\tilde{\mathcal{R}}(b)=s]
for
s\in\textbf{Ann}(b)
.

The design of
\tilde{\mathcal{R}}
ensures that
for each
s\in\textbf{Ann}(b)
, we have
\Pr[\tilde{\mathcal{R}}(b)=s]=\Pr[\mathcal{R}(b)=s]=g(\left\|{b-s}\right\|_{0})
.
Our choices of
UB
and
LB
in Equation (
15
) guarantee that
\left\|{b-s}\right\|_{0}
is close to
kp
if
s\in\textbf{Ann}(b)
, and therefore

\Pr[\tilde{\mathcal{R}}(b)=s]
is close to
p_{\text{avg}}
.
Next, we justify these choices.

Choice of
UB
.

We set
\text{UB}=\frac{k}{\tilde{\varepsilon}}\cdot\ln\frac{2e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}
so that
g(\text{UB})=2^{-k}
.
Such
UB
is close to
kp
;
indeed, we have
\text{UB}\in[kp,k/2]
.
As
g
is a decreasing function, this can be proven by showing that

(21)

g(kp)\geq 2^{-k}=g(\text{UB})\geq g(k/2)\,.

Since
\left\|{b-s}\right\|_{0}\leq\text{UB}
for each
s\in\textbf{Ann}(b)
, we have

(22)

\Pr[\tilde{\mathcal{R}}(b)=s]\geq g(\text{UB})=2^{-k}\,.

As will be discussed, this property also plays an important role in upper bounding
\Pr[\tilde{\mathcal{R}}(b)=s]
for
s\notin\textbf{Ann}(b)
.

Choice of
LB
.

We pick
\text{LB}=kp-2\sqrt{k}
so that it is not much smaller than
kp
, and that
g(\text{LB})=e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}
.
Since
\left\|{b-s}\right\|_{0}\geq\text{LB}
for each
s\in\textbf{Ann}(b)
,

(23)

\Pr[\tilde{\mathcal{R}}(b)=s]=g(\left\|{b-s}\right\|_{0})\leq g(\text{LB})=e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}\,.

Bounding
\Pr[\tilde{\mathcal{R}}(b)=s]
for
s\notin\textbf{Ann}(b)
.

We discuss first the upper bound for this case, which is the easy part.

Upper Bound.

As discussed, our choice of
UB
guarantees that each
s\in\textbf{Ann}(b)
is assigned with output probability at least
2^{-k}
.
Since there are
2^{k}
elements in the output space
\left\{{-1,1}\right\}^{k}
of
\tilde{\mathcal{R}}(b)
, and since
\Pr[\tilde{\mathcal{R}}(b)=s]
equals a common probability for each
s\notin\textbf{Ann}(b)
, we have

\Pr[\tilde{\mathcal{R}}(b)=s]\leq 2^{-k},\quad\forall s\notin\textbf{Ann}(b).

Lower Bound.

Let
\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}\doteq[{0}\,.\,.\,{k}]\setminus[{\text{LB}}\,.\,.\,{\text{UB}}]
, and
\mathcal{R}(b)={({\mathcal{R}(b_{1}),\ldots,\mathcal{R}(b_{k})})}
.
First, observe that

\begin{array}[]{c}\Pr[\mathcal{R}(b)\notin\textbf{Ann}(b)]=\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}g(i).\end{array}

As
\tilde{\mathcal{R}}
assigns equal probability to each
s\notin\textbf{Ann}(b)
,
it holds that

(24)

P_{\text{out}}^{*}\doteq\Pr[\tilde{\mathcal{R}}(b)=s]=\frac{\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}g(i)}{\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}}\,.

To lower bound
P_{\text{out}}^{*}
, we will partition
\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}
into three subsets, which consist of the
i
for which
g(i)
is significantly higher, lightly lower than, and significantly lower than
p_{\text{avg}}
, respectively.

In particular, since
\text{LB}<k/2
and
\text{UB}\leq k/2
, it holds that
k-\text{LB}>\text{UB}
.
Hence, we can partition the set
\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}
into three subsets
[{0}\,.\,.\,{\text{LB}-1}]
,
[{\text{UB}+1}\,.\,.\,{k-\text{LB}}]
and
[{k-\text{LB}+1}\,.\,.\,{k}]
.
Note that the size of the first subset equals the size of the third one.
Correspondingly, we can decompose the numerator and denominator of
P_{\text{out}}^{*}
into three parts:

\mathcal{N}_{1}\doteq\sum_{i=0}^{\text{LB}-1}\binom{k}{i}g(i),\mathcal{N}_{2}\doteq\sum_{i=\text{UB}+1}^{k-\text{LB}}\binom{k}{i}g(i),\mathcal{N}_{3}\doteq\sum_{i=k-\text{LB}+1}^{k}\binom{k}{i}g(i)\,.

\displaystyle\mathfrak{D}_{1}\doteq\sum_{i=0}^{\text{LB}-1}\binom{k}{i},\,\mathfrak{D}_{2}\doteq\sum_{i=\text{UB}+1}^{k-\text{LB}}\binom{k}{i},\,\mathfrak{D}_{3}\doteq\sum_{i=k-\text{LB}+1}^{k}\binom{k}{i}\,.

We lower bound the ratios of
{\mathcal{N}_{2}}/{\mathfrak{D}_{2}}
and
{({\mathcal{N}_{1}+\mathcal{N}_{3}})}/{({\mathfrak{D}_{1}+\mathfrak{D}_{3}})}
separately.

Lower bounding
{\mathcal{N}_{2}}/{\mathfrak{D}_{2}}\geq p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot{({k(1-2p)+2\sqrt{k}})}}
.

This follows from that
g(i)
is a decreasing function, and therefore the smallest
g(i)
in the summands of
\mathcal{N}_{2}
is lower bounded by
g(k-\text{LB})=p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot{({k(1-2p)+2\sqrt{k}})}}
.

Lower bounding
{({\mathcal{N}_{1}+\mathcal{N}_{3}})}/{({\mathfrak{D}_{1}+\mathfrak{D}_{3}})}\geq p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot k(1-2p)}
.

Observe that for each
i\in[{0}\,.\,.\,{\text{LB}-1}]
, we have
k-i\in[{k-\text{LB}+1}\,.\,.\,{k}]
.
The lower bound follows by pairing up each summand
\binom{k}{i}g(i)
in
\mathcal{N}_{1}
with
\binom{k}{k-i}g(k-i)
in
\mathcal{N}_{3}
, and by proving that
g(i)+g(k-i)\geq p_{\text{avg}}\cdot 2\cdot e^{-\tilde{\varepsilon}\cdot k(1-2p)}
,
details in the Appendix.

Putting Together.

Based on the lower bounds of
{\mathcal{N}_{2}}/{\mathfrak{D}_{2}}
and
{({\mathcal{N}_{1}+\mathcal{N}_{3}})}

/{({\mathfrak{D}_{1}+\mathfrak{D}_{3}})}
, we have

(25)

\displaystyle P_{\text{out}}^{*}=\frac{\mathcal{N}_{1}+\mathcal{N}_{2}+\mathcal{N}_{3}}{\mathfrak{D}_{1}+\mathfrak{D}_{2}+\mathfrak{D}_{3}}\geq p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot{({k(1-2p)+2\sqrt{k}})}}\,.

Since
p=1/(e^{\tilde{\varepsilon}}+1)
, we have
(1-2p)=(e^{\tilde{\varepsilon}}-1)/(e^{\tilde{\varepsilon}}+1)
.
Via the inequality
{({e^{x}-1})}/{({e^{x}+1})}\leq x/2
for all
x\geq 0
, we have
k(1-2p)\leq k\cdot\tilde{\varepsilon}/2
.
Via the assumption that
\varepsilon\leq 1
, we get
\tilde{\varepsilon}=\varepsilon/{({5\sqrt{k}})}\leq 1/\sqrt{k}
, and
k(1-2p)\leq k\cdot\tilde{\varepsilon}/2\leq\sqrt{k}
.
Therefore,

P_{\text{out}}^{*}\geq e^{-\tilde{\varepsilon}\cdot{({3\sqrt{k}})}}\cdot p_{\text{avg}}
.

\square

Proof Outline for Lemma
5.3
.

By symmetry of
\tilde{\mathcal{R}}
, it suffices to prove Lemma
5.3
for the first coordinate of
\tilde{b}
.
We first prove that

\displaystyle\Pr[\tilde{b}_{1}=b_{1}]

\displaystyle=\sum_{i=\text{LB}}^{\text{UB}}\binom{k}{i}g(i)\frac{k-i}{k}+P_{\text{out}}^{*}\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}\frac{k-i}{k},\,

\displaystyle\Pr[\tilde{b}_{1}=-b_{1}]

\displaystyle=\sum_{i=\text{LB}}^{\text{UB}}\binom{k}{i}g(i)\frac{i}{k}+P_{\text{out}}^{*}\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}\frac{i}{k}.

Since
c_{\text{gap}}=\Pr[\tilde{b}_{1}=b_{1}]-\Pr[\tilde{b}_{1}=-b_{1}]
, we have

c_{\text{gap}}=\sum_{i=\text{LB}}^{\text{UB}}\binom{k}{i}g(i)\frac{k-2i}{k}+P_{\text{out}}^{*}\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}\frac{k-2i}{k}.

Note that for each
i\in[{0}\,.\,.\,{k}]
,

\binom{k}{i}\frac{k-2i}{k}+\binom{k}{k-i}\frac{k-2(k-i)}{k}=0.

For each
i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}
, if

i\notin[{k-\text{UB}}\,.\,.\,{k-\text{LB}}]
, then it holds that
k-i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}
.
Therefore,

\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}\setminus[{k-\text{UB}}\,.\,.\,{k-\text{LB}}]}\binom{k}{i}\frac{k-2i}{k}=0
, and

\displaystyle c_{\text{gap}}

\displaystyle=\sum_{i=\text{LB}}^{\text{UB}}\binom{k}{i}g(i)\frac{k-2i}{k}+P_{\text{out}}^{*}\sum_{i\in[k-\text{UB},k-\text{LB}]}\binom{k}{i}\frac{k-2i}{k}

\displaystyle=\sum_{i=\text{LB}}^{\text{UB}}\binom{k}{i}{\left({g(i)-P_{\text{out}}^{*}}\right)}\frac{k-2i}{k}.

where the second equality follows from that for each
i\in[{\text{LB}}\,.\,.\,{\text{UB}}]
,
k-i\in[{k-\text{UB}}\,.\,.\,{k-\text{LB}}]
, and that
\binom{k}{i}=\binom{k}{k-i}
.
Since
\text{LB}=kp-2\sqrt{k}<kp\leq\text{UB}
,
it holds that
[{\text{UB}-2\sqrt{k}}\,.\,.\,{\text{UB}-\sqrt{k}/2}]\subset[{\text{LB}}\,.\,.\,{\text{UB}}]
.
Combing with that
P_{\text{out}}^{*}\leq 2^{-k}
(Inequality (
20
)), we see

(26)

c_{\text{gap}}\geq\sum_{i=\text{UB}-2\sqrt{k}}^{\text{UB}-\sqrt{k}/2}\binom{k}{i}{\left({g(i)-\frac{1}{2^{k}}}\right)}\frac{k-2i}{k}.

It is left to prove that the right hand side is lower bounded by
\Omega(\tilde{\varepsilon})=\Omega(\varepsilon/\sqrt{k})
.
We will show that for each
i\in[{\text{UB}-2\sqrt{k}}\,.\,.\,{\text{UB}-\sqrt{k}/2}]
,

(27)

{\left({g(i)-\frac{1}{2^{k}}}\right)}\frac{k-2i}{k}\in\Omega{\left({\frac{\tilde{\varepsilon}}{2^{k}}}\right)}.

Further,

(28)

\sum_{i=\text{UB}-2\sqrt{k}}^{\text{UB}-\sqrt{k}/2}\binom{k}{i}\in\Omega{\left({2^{k}}\right)}.

Combining Inequalities (
26
), (
27
), and (
28
) proves
c_{\text{gap}}\in\Omega(\tilde{\varepsilon})
.

Proving Inequalities (
27
).

Observe that

g(i)\geq g(\text{UB}-\sqrt{k}/2)=e^{\tilde{\varepsilon}\cdot\sqrt{k}/2}\cdot 2^{-k}.

Since
\text{UB}\leq k/2
,

\frac{k-2i}{k}\geq\frac{k-2(\text{UB}-\sqrt{k}/2)}{k}\geq\frac{k-2(k/2-\sqrt{k}/2)}{k}

=\frac{1}{\sqrt{k}}.

Combined, we obtain

(29)

\left(g(i)-\frac{1}{2^{k}}\right)\frac{k-2i}{k}\geq\left(e^{\tilde{\varepsilon}\cdot\sqrt{k}/2}-1\right)\cdot{\left({\frac{1}{2}}\right)}^{k}\cdot\frac{1}{\sqrt{k}}\geq\frac{\tilde{\varepsilon}}{2}\cdot{\left({\frac{1}{2}}\right)}^{k}.

Proving Inequalities (
28
).

At a high level, the claim follows from that the summation consists of
\Omega{({\sqrt{k}})}
terms, each of size
\Omega{({2^{k}/\sqrt{k}})}
,
details in the Appendix.

\square

6.
Related Works

Central Model
.
Data analysis under
continual observation
has been studied in the central model of differential privacy
(
Dwork
et al. 2010
;
Chan
et al. 2011
)
. Here, a trusted curator, to which the clients report their true data, perturbs and releases the aggregated data.
Given a stream of Boolean (
0
-
1
) values, differentially private frequency estimation algorithms were independently proposed by both
Dwork
et al. 2010

(
Dwork
et al. 2010
)
and
Chan
et al. 2011

(
Chan
et al. 2011
)
: at each time period, they an estimate of the number of
1
s appearing so far.
These algorithms guarantee an error of
O{({1/\varepsilon\cdot\log^{1.5}t})}
(omitting failure probability) at each time
t
.

Local Model
.
To avoid naively repeating algorithms designed for one-time computation, the
memoization
technique was proposed and deployed for continual collection of counter data
(
Erlingsson
et al. 2014
;
Ding
et al. 2017
)
, where noisy answers for all elements in the domain are memoized.
However, as pointed out by
(
Ding
et al. 2017
)
, this technique can violate differential privacy.
Recent works
(
Úlfar Erlingsson et al. 2020
;
Joseph
et al. 2018
;
Zhou
et al. 2021
)
also propose to exploit the potential sparsity of users’ data, if it changes infrequently.
They differ in the frequency
when the algorithm needs to give a prediction.

Online Setting
.
Our algorithmic framework is inspired by the work of
Erlingsson et al. 2019

(
Úlfar Erlingsson et al. 2020
)
for the online setting, where the server is required to report the estimate at each time step.
Here we provide a succinct description of their protocol, in the notation and framework of our paper.
The protocol by
Erlingsson et al. 2019
requires
an additional sampling step: each user
u
samples uniformly and keeps only one non-zero coordinate of
X_{u}
, and sets all other non-zero coordinates to
0
.
Therefore, there can be at most one non-zero partial sum with sampled order
h_{u}
.
This partial sum is perturbed by the basic randomizer
\mathcal{R}
(Equation (
14
)) with
\tilde{\varepsilon}=\varepsilon/2
, resulting in a
{({c_{\text{gap}}})}^{-1}\in\Omega{({1/\varepsilon})}
.
However, due to the additional sampling step, the server side estimator of
\hat{S}({\mathcal{I}_{h,j}})
(Algorithm
2
, line
6
) needs to be multiplied by an additional factor of
k
.
Via similar analysis to Lemma
4.6
,
the error guarantee of their protocol involves a factor of
k
, instead of
\sqrt{k}
.

Offline Setting
.
The recent independent parallel work by
Zhou
et al. 2021

(
Zhou
et al. 2021
)

considers the problem in the offline setting, where the server is required to report only after it has collected all the data.
They describe a protocol that provides error guarantee of
O((1/\varepsilon)\cdot\sqrt{k\cdot(\log n/\beta)\cdot n\cdot\log(d/\beta)})
.
Their client-side algorithm involves hashing the coordinates of user data into a table, and reporting a perturbed version of the hash table to the server.
Since the value of the entries of the hash table depends on all coordinates of the user data, it is unclear how to convert this algorithm into an online one.

Batch Reporting
. The work by
Joseph
et al. 2018

(
Joseph
et al. 2018
)
lies between the online and offline settings: time steps are batched into
epochs
, and the server is required to report at each epoch.
Further, it assumes that users’ data are sampled from some (unknown) distributions,
and analyzes its protocol’s performance based on this assumption.
Due to this difference in the problem setting, the performance guarantees of the protocol in
(
Joseph
et al. 2018
)

cannot be compared directly to those provided in
(
Úlfar Erlingsson et al. 2020
;
Zhou
et al. 2021
)
and our paper.
However, the performance in
(
Joseph
et al. 2018
)
also degrades only linearly, instead of sub-linearly, with the number of changes in the underlying data distributions.

Composed Randomizer
.
The composed randomizer,
\tilde{\mathcal{R}}
, presented in this paper builds on the composed randomizer proposed by
Bun
et al. 2019

(
Bun
et al. 2019
)
.
Their design
focused on preserving the statistical distance between the distribution of the output of the composed randomizer, and joint distribution of
k
independent randomized responses.
This difference in the problem setting prompts the non-trivial changes in parameters, assumptions and analysis.
The
Bun
et al. 2019
proof
(
Bun
et al. 2019
)
relies extensively on concentration and anti-concentration inequalities.
Their design can only achieve

c_{\text{gap}}\in O\Big({\varepsilon}/{\sqrt{k\ln(k/\varepsilon)}}+\big(\frac{\varepsilon}{k\ln(k/\varepsilon)}\big)^{2/3}\Big)

(detailed discussion and proof are in Appendix
A.2
).
When the first term dominates (e.g, when
k\geq 1/\varepsilon^{2}
), this simplifies to
c_{\text{gap}}\in O({\varepsilon}/{\sqrt{k\ln(k/\varepsilon)}})
, which implies that
(c_{\text{gap}})^{-1}\in\Omega({\sqrt{k\ln(k/\varepsilon)}}/{\varepsilon})
.
If we apply this composed randomizer to our framework, according to Lemma
4.6
, this leads to an error that scales at least with
{\sqrt{k\ln(k/\varepsilon)}}/\varepsilon
.
In comparison, our composed randomizer reduces this to at most
\sqrt{k}/\varepsilon
.
Further,
Bun
et al. 2019
’s original design
(
Bun
et al. 2019
)
applies only to offline inputs.
We overcome this limitation by including our pre-computation technique so the algorithm becomes online.

Fact A.1 (Hoeffding’s Inequality

Let

\displaystyle\leq\exp\left(-\frac{2\eta^{2}}{\sum_{i\in[n]}(b_{i}-a_{i})^{2}}\right)\,,\text{ and}

\displaystyle\Pr[\Expectation\left[Y\right]-Y\geq\eta]

\displaystyle\leq\exp\left(-\frac{2\eta^{2}}{\sum_{i\in[n]}(b_{i}-a_{i})^{2}}\right)\,.

with probability one.

Proof of Lemma

Recall that
p=1/(e^{\tilde{\varepsilon}}+1)
,

,

(32)

g(i)\doteq p^{i}(1-p)^{k-i}=p^{k}\cdot e^{\tilde{\varepsilon}\cdot(k-i)},\forall i\in[{0}\,.\,.\,{k}],

and

\displaystyle p_{\text{avg}}\doteq p^{kp}(1-p)^{k-kp}=g(kp)=p^{k}\cdot e^{\tilde{\varepsilon}\cdot(k-kp)}.

By definitions of
g
and
p_{\text{avg}}
, for each
j\in\mathbb{Z}
, it holds that

(33)

\begin{array}[]{rll}g(kp+j)&=p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot j},&\text{if}\,0\leq kp+j\leq k,\\
g(kp-j)&=p_{\text{avg}}\cdot e^{\tilde{\varepsilon}\cdot j},&\text{if}\,0\leq kp-j\leq k.\end{array}

To prove the lemma, we consider
s\in\textbf{Ann}(b)
and
s\in\left\{{-1,1}\right\}^{k}\setminus\textbf{Ann}(b)
separately.
We show that for each
b\in\left\{{-1,1}\right\}^{k}

(34)

\displaystyle\Pr[\tilde{\mathcal{R}}(b)=s]

\displaystyle\in\left[1/2^{k},e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}\right],\,\quad\forall s\in\textbf{Ann}(b),

(35)

\displaystyle\Pr[\tilde{\mathcal{R}}(b)=s]

\displaystyle\in\left[e^{-3\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}},1/2^{k}\right],\,\quad\forall s\notin\textbf{Ann}(b).

Proof of Inequality (
34
).

Since
\text{LB}=kp-2\sqrt{k}
,

g(\text{LB})=e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}}.

We will also prove that

(36)

g(kp)\geq 2^{-k}\geq g(k/2).

and that
g(\text{UB})=2^{-k}
.
As
g
is a decreasing function, it follows that
\text{UB}\in[kp,k/2]
.

Recall that for an input
b\in\left\{{-1,1}\right\}^{k}
,
\tilde{\mathcal{R}}
first generates
b^{\prime}=\mathcal{R}(b)\doteq{\left({\mathcal{R}(b_{1}),\ldots,\mathcal{R}(b_{k})}\right)}
.
If
b^{\prime}\in\textbf{Ann}(b)
,
\tilde{\mathcal{R}}
outputs it directly.
Therefore, for each
s\in\textbf{Ann}(b)
, it holds that

\Pr[\tilde{\mathcal{R}}(b)=s]=\Pr[\mathcal{R}(b)=s]=g(\left\|{b-s}\right\|_{0}).

Noting that
\left\|{b-s}\right\|_{0}\in[{\text{LB}}\,.\,.\,{\text{UB}}]
, we obtain

2^{-k}=g(\text{UB})\leq\Pr[\tilde{\mathcal{R}}(b)=s]=g(\left\|{b-s}\right\|_{0})\leq g(\text{LB})=e^{2\tilde{\varepsilon}\sqrt{k}}\cdot p_{\text{avg}},

which proves Inequality (
34
).

Proving
g(kp)\geq 1/2^{k}\geq g(k/2)
.

Via convexity of the function
y=-\log x
, we have

\displaystyle\frac{\log(g(kp))}{k}

\displaystyle=-p\log\frac{1}{p}-(1-p)\log\frac{1}{1-p}

\displaystyle\geq-\log\left(p\cdot\frac{1}{p}+(1-p)\cdot\frac{1}{1-p}\right)=-1.

Via concavity of the function
y=\log x
, we have

\displaystyle\frac{\log g(k/2)}{k}

\displaystyle=\frac{1}{2}\cdot\log p+\frac{1}{2}\cdot\log(1-p)

\displaystyle\leq\log\left(\frac{1}{2}\cdot p+\frac{1}{2}\cdot(1-p)\right)=-1.

It follows that

(37)

p_{\text{avg}}=g(kp)\geq 1/2^{k}\geq g(k/2).

Proving
g(\text{UB})=1/2^{k}
.

Via Equation (
32
) and the definitions of
p
and
UB

\displaystyle g(\text{UB})

\displaystyle=p^{k}\cdot\exp{\left({\tilde{\varepsilon}\cdot{\left({k-\frac{k}{\tilde{\varepsilon}}\cdot\ln\frac{2e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}}\right)}}\right)}

\displaystyle={\left({\frac{1}{e^{\tilde{\varepsilon}}+1}}\right)}^{k}\cdot\exp{\left({\tilde{\varepsilon}\cdot{\left({k-\frac{k}{\tilde{\varepsilon}}\cdot\ln\frac{2e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}}\right)}}\right)}

\displaystyle=\exp{\left({k\ln{\left({\frac{1}{e^{\tilde{\varepsilon}}+1}}\right)}+k\tilde{\varepsilon}-k\cdot\ln\frac{2e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}}\right)}

\displaystyle=\exp{\left({k\ln{\left({\frac{e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}}\right)}-k\cdot\ln\frac{2e^{\tilde{\varepsilon}}}{e^{\tilde{\varepsilon}}+1}}\right)}=1/2^{k}.

Therefore,
\text{UB}\in[kp,k/2]
.

Proof of Inequality (
35
).

Let
\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}\doteq[{0}\,.\,.\,{k}]\setminus[{\text{LB}}\,.\,.\,{\text{UB}}]
.
Denote
\mathcal{R}(b)\doteq{\left({\mathcal{R}(b_{1}),\ldots,\mathcal{R}(b_{k})}\right)}

First, observe

As each

is outputted uniformly at random by

when

(38)

\Pr[\tilde{\mathcal{R}}(b)=s]=P_{\text{out}}^{*}\doteq\frac{\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}g(i)}{\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}}.

We upper bound and lower bound

separately.

Upper Bound For

As

\displaystyle\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}g(i)\leq\sum_{i\in\overline{[{\text{LB}}\,.\,.\,{\text{UB}}]}}\binom{k}{i}\cdot 1/2^{k}.

It concludes that

.

Lower Bound For
P_{\text{out}}^{*}

Since

Hence, we can partition the numerator and denominator of

We will prove that

and

(40)

It follows that

\displaystyle P_{\text{out}}^{*}=\frac{\mathcal{N}_{1}+\mathcal{N}_{2}+\mathcal{N}_{3}}{\mathfrak{D}_{1}+\mathfrak{D}_{2}+\mathfrak{D}_{3}}\geq p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot{\left({k(1-2p)+2\sqrt{k}}\right)}}.

Since
{\left({e^{x}-1}\right)}/{\left({e^{x}+1}\right)}\leq x/2
for all

, we have

k(1-2p)=k\cdot(e^{\tilde{\varepsilon}}-1)/(e^{\tilde{\varepsilon}}+1)\leq k\cdot\tilde{\varepsilon}/2.

Via the assumption that
\varepsilon\leq 1
, we get
\tilde{\varepsilon}=\varepsilon/{({5\sqrt{k}})}\leq 1/\sqrt{k}
, and
k(1-2p)\leq\sqrt{k}
.
Therefore,

P_{\text{out}}^{*}\geq e^{-\tilde{\varepsilon}\cdot{\left({3\sqrt{k}}\right)}}\cdot p_{\text{avg}}.

Proof For Inequality (

Via Equation (

),

\displaystyle g(k-\text{LB})

\displaystyle=g(k-kp+2\sqrt{k})=g(kp+(k-2kp)+2\sqrt{k})

On the other hand, as

\displaystyle\mathcal{N}_{2}\geq\sum_{i=\text{UB}+1}^{k-\text{LB}}\binom{k}{i}g(k-\text{LB})\geq\mathfrak{D}_{2}\cdot p_{\text{avg}}\cdot e^{-\tilde{\varepsilon}\cdot{\left({k(1-2p)+2\sqrt{k}}\right)}}.

Proof For Inequality (

Both

and
\mathcal{N}_{3}
contain

We pair up these terms in

\displaystyle\sum_{j=1}^{\text{LB}}\left(\binom{k}{\text{LB}-j}g(\text{LB}-j)+\binom{k}{k-\text{LB}+j}g(k-\text{LB}+j)\right)

\displaystyle=

\displaystyle\sum_{j=1}^{\text{LB}}\binom{k}{\text{LB}-j}\cdot{\left({g(\text{LB}-j)+g(k-\text{LB}+j)}\right)}.

Via Equation (

) and the definition of

,

g(\text{LB}-j)=g(kp-2\sqrt{k}-j)=p_{\text{avg}}\cdot e^{\tilde{\varepsilon}\cdot{\left({2\sqrt{k}+j}\right)}}.

Similarly, using that

\displaystyle=g(kp+k(1-2p)+2\sqrt{k}+j)

\displaystyle\geq p_{\text{avg}}\cdot{\left({e^{\tilde{\varepsilon}\cdot(2\sqrt{k}+j)}+e^{-\tilde{\varepsilon}\cdot(2\sqrt{k}+j)}}\right)}\cdot e^{-\tilde{\varepsilon}\cdot k(1-2p)}

It concludes that

\displaystyle\mathcal{N}_{1}+\mathcal{N}_{3}

\displaystyle\geq\sum_{j=1}^{\text{LB}}\binom{k}{\text{LB}-j}\cdot p_{\text{avg}}\cdot 2\cdot e^{-\tilde{\varepsilon}\cdot k(1-2p)}.

Noting that

\displaystyle\,+\sum_{i=1}^{\sqrt{k}}\binom{k}{k/2-\sqrt{k}}\prod_{j\in[i]}\frac{k/2-\sqrt{k}-i+j}{k+1-{\left({k/2-\sqrt{k}-i+j}\right)}}

\displaystyle\geq\sum_{i=0}^{\sqrt{k}}\binom{k}{k/2-\sqrt{k}}\left(\frac{k/2-\sqrt{k}-i+1}{k+1-{\left({k/2-\sqrt{k}-i+1}\right)}}\right)^{i}

\displaystyle\geq\sum_{i=0}^{\sqrt{k}}\binom{k}{k/2-\sqrt{k}}\left(\frac{k/2-\sqrt{k}-\sqrt{k}+1}{k+1-{\left({k/2-\sqrt{k}-\sqrt{k}+1}\right)}}\right)^{i}

\displaystyle=\sum_{i=0}^{\sqrt{k}}\binom{k}{k/2-\sqrt{k}}\left(1-\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}\right)^{i}

\displaystyle=\binom{k}{k/2-\sqrt{k}}\cdot\frac{1-\left(1-\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}\right)^{\sqrt{k}+1}}{1-\left(1-\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}\right)}.

Via that
1-x\leq e^{x},\forall x\in\mathbb{R}
, we get

\displaystyle\frac{1-\left(1-\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}\right)^{\sqrt{k}+1}}{1-\left(1-\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}\right)}

\displaystyle\geq\frac{1-\exp{\left({-\frac{{\left({4\sqrt{k}-1}\right)}\cdot{\left({\sqrt{k}+1}\right)}}{k/2+2\cdot\sqrt{k}}}\right)}}{\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}}.

When
k\geq 4\sqrt{k}
, we see

\exp{\left({-\frac{{({4\sqrt{k}-1})}\cdot{({\sqrt{k}+1})}}{k/2+2\cdot\sqrt{k}}}\right)}=\exp{\left({-\frac{4k+3\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}}\right)}

\leq\exp{\left({-\frac{19\sqrt{k}-1}{4\sqrt{k}}}\right)}\leq\exp{\left({-\frac{18}{4}}\right)},

and

\frac{4\sqrt{k}-1}{k/2+2\cdot\sqrt{k}}=\frac{8-2/\sqrt{k}}{\sqrt{k}+4}\leq 8/\sqrt{k}.

Hence,

\displaystyle\sum_{i=k/2-2\sqrt{k}}^{k/2-\sqrt{k}}\binom{k}{i}

\displaystyle=\binom{k}{k/2-\sqrt{k}}\frac{\sqrt{k}}{8}{\left({1-e^{-\frac{18}{4}}}\right)}\geq\binom{k}{k/2-\sqrt{k}}\frac{\sqrt{k}}{9}.

Using the Stirling’s approximation (Fact
A.3
), we get

\displaystyle\binom{k}{k/2-\sqrt{k}}

\displaystyle\geq e^{-1/6}\cdot\sqrt{\frac{k}{2\cdot\pi\cdot(k/2-\sqrt{k})\cdot(k/2+\sqrt{k})}}

\displaystyle\quad\cdot\frac{k^{k}}{(k/2-\sqrt{k})^{(k/2-\sqrt{k})}\cdot(k/2+\sqrt{k})^{(k/2+\sqrt{k})}}

\displaystyle\geq e^{-1/6}\cdot\frac{1}{\sqrt{k-4}}\cdot\sqrt{\frac{2}{\pi}}\cdot 2^{k\cdot H(1/2-1/\sqrt{k})},

where
H(\cdot)
is the entropy function.
We obtain that

\displaystyle\sum_{i=k/2-2\sqrt{k}}^{k/2-\sqrt{k}}\binom{k}{i}\left(\frac{1}{2}\right)^{k}

\displaystyle\geq\frac{1}{9}\sqrt{\frac{k}{k-4}}\cdot e^{-1/6}\cdot\sqrt{\frac{2}{\pi}}\cdot 2^{k\cdot{\left({H(1/2-1/\sqrt{k})-1}\right)}}

Via the inequality (Corollary
A.5
) that
H(1/2-x)\geq 1-4x^{2},\forall x\in[-1/2,1/2]
,

\displaystyle\sum_{i=k/2-2\sqrt{k}}^{k/2-\sqrt{k}}\binom{k}{i}\left(\frac{1}{2}\right)^{k}

\displaystyle\geq\frac{1}{9}\sqrt{\frac{k}{k-4}}\cdot e^{-1/6}\cdot\sqrt{\frac{2}{\pi}}\cdot 2^{k\cdot{\left({-4/k}\right)}}\in\Omega(1),

which finishes the proof.
∎
