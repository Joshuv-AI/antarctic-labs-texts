Adaptive Regulation with Global KL Guarantees
Iasson Karafyllis, Alexandros Aslanidis, Miroslav Krstic

Abstract
In the absence of persistency of excitation (PE), referring to adaptive control systems as “asymptotically stable” typically indicates insufficient understanding of stability concepts. While the state is indeed regulated to zero and the parameter estimate has some limit, namely, the overall state converges to some equilibrium, the equilibrium reached is not unique (and not even necessarily stable) but is dependent on the initial condition. The equilibrium set in the absence of PE is not uniformly attractive (from an open set containing the equilibrium set); hence, asymptotic stability does not hold and KL estimates are unavailable for the full state. In this paper we pursue adaptive control design with KL guarantees on the regulated state, something that is possible but previously unachieved with smooth, time-invariant and non-hybrid adaptive controllers. This property is referred to as Uniform Global Asymptotic Output Stability, where the regulated state is thought of as a system output. We provide designs for (i) systems with a matched uncertainty and (ii) systems in the parametric strict feedback form. To guarantee KL estimates in the absence of PE, our designs employ time-invariant nonlinear damping terms, which depend both on the state and the parameter estimate. With an example, we illustrate the theory.

Introduction

The problem of adaptive control arises naturally as it is rare (or even impossible) to know exactly the system parameters. Thus, it is of great interest to regulate a system in the presence of unknown parameters. The literature on adaptive control is huge, spanning over sixty years. It is well known that adaptive control does not guarantee uniform attractivity and/or KL-estimates for the solution of the closed-loop system (see
[
16

[
17

Systems satisfying the matching condition

Consider the following finite-dimensional control system

\dot{x}=f(x)+g(x)u+g(x)(\varphi(x))^{\prime}\theta

(4)

where
f,g:\mathbb{R}^{n}\rightarrow\mathbb{R}^{n},\varphi:\mathbb{R}^{n}\rightarrow\mathbb{R}^{p}
are locally Lipschitz vector fields with
f(0)=0
and
\varphi(0)=0
,

,

is the control input and
\theta\in\mathbb{R}^{p}
is the constant vector of unknown parameters. The control system (

The following assumption is used for the control system (

Assumption 1
.

There exist functions
P\in C^{2}\left(\mathbb{R}^{n};\mathbb{R}_{+}\right),Q\in C^{0}\left(\mathbb{R}^{n};\mathbb{R}_{+}\right)

\nabla P(x)f(x)+\nabla P(x)g(x)k(x)\leq-Q(x),\text{for all }x\in\mathbb{R}^{n}

When Assumption
1
holds then it is possible to regulate the state to zero by applying a standard adaptive control scheme. To see this, consider the adaptive controller

\displaystyle u

\displaystyle=k(x)-\left(\varphi(x)\right)^{\prime}\hat{\theta}

(6)

\displaystyle\dfrac{d\hat{\theta}}{dt}

\displaystyle=\Gamma\nabla P(x)g(x)\varphi(x)

(7)

where
\Gamma\in\mathbb{R}^{p\times p}
is a positive definite matrix. The closed-loop system (
4
), (
6
), (
7
) with output

has the following stability properties:

i)

the set
\left\{\left(0,\hat{\theta}\right):\hat{\theta}\in\mathbb{R}^{p}\right\}
(i.e., the set where

) is the set of equilibrium points for the closed-loop system (
4
),(
7
)

ii)

the equilibrium point
\left(x,\hat{\theta}\right)=\left(0,\theta\right)
is Lyapunov stable

iii)

for every initial condition, the solution
\left(x(t),\hat{\theta(t)}\right)
of the closed-loop system (
4
),(
7
) is bounded and the closed-loop system is Lagrange stable

iv)

the closed-loop system (
4
),(
7
),(
8
) is GAOS and every solution of the closed-loop system (
4
),(
7
) satisfies
\lim_{t\rightarrow+\infty}\left(x(t)\right)=0

The proof of the above facts follows the analysis given in
[
16
]
using the Lyapunov function
V(x,\hat{\theta}):=P(x)+\dfrac{1}{2}\left(\hat{\theta}-\theta\right)^{\prime}\Gamma^{-1}\left(\hat{\theta}-\theta\right)
, which (by virtue (
4

5

\dfrac{d}{dt}V(x,\hat{\theta})\leq-Q(x)

However, the convergence rate of

In order to be able to guarantee a KL-estimate we need an additional assumption.

Assumption 2
.

There exists a locally Lipschitz, positive function
\mu\in C^{0}\left(\mathbb{R}^{n};(0,+\infty)\right)
such that the following inequality holds:

|\varphi(x)|^{2}\leq\mu(x)Q(x),\text{ for all }x\in\mathbb{R}^{n}

Assumption
2
is automatically guaranteed if there exists a constant

such that the inequality

holds for all

in a neighbourhood of
0\in\mathbb{R}^{n}
. Both Assumption

and Assumption

are automatically guaranteed if the feedback law

achieves global asymptotic stabilization and local exponential stabilization of

When Assumption
1
and Assumption
2
hold then it is possible to modify the adaptive control scheme (
6
), (
7
) so that we can obtain two different KL-estimates: a "perfect" KL-bound when

and a "practical" KL-bound when

, where

is a parameter of the controller. More specifically, the adaptive control scheme (

) is modified in the following way:

\displaystyle u=

\displaystyle k(x)-(\varphi(x))^{\prime}\hat{\theta}\left(\dfrac{\delta}{2}|\varphi(x)|^{2}+\mu(x)\left(r+|\hat{\theta}|^{2}\right)\right)\left(\nabla P(x)g(x)\right)

(11)

\displaystyle\dfrac{d\hat{\theta}}{dt}=

\displaystyle\Gamma\nabla P(x)g(x)\varphi(x)

(12)

where
\Gamma\in\mathbb{R}^{p\times p}
is a positive definite matrix and

,

are constants. The term

It should be noticed that all properties (i), (ii), (iii) and (iv) hold for the closed-loop system (

Theorem 1

Suppose that Assumptions
1

\rho\left(P(x)\right)\leq Q(x)\text{ for all }x\in\mathbb{R}^{n}

\alpha:=\rho^{-1}\left((1-\lambda)^{-1}\delta^{-1}\left(|\theta|^{2}-r\right)^{+}\right)

Remarks:

(a)

Since
P\in C^{2}(\mathbb{R}^{n};\mathbb{R}_{+})
and

are positive definite and radially unbounded functions, there exists
\rho\in K_{\infty}
such that inequality (

\rho\in K_{\infty}
for which (
13

(b)

Since
P\in C^{2}(\mathbb{R}^{n};\mathbb{R}_{+})
is a positive definite and radially unbounded function, there exist functions
b_{1},b_{2}\in K_{\infty}
such that

b_{1}(|x|)\leq P(x)\leq b_{2}(|x|),\text{for all x}\in\mathbb{R}^{n}

The proof of Theorem
1
and inequality (

) shows that the following global KL-estimate holds for all

:

b_{1}(|x(t)|)\leq\tilde{\sigma}\left(\left(b_{2}(|x(0)|)-\alpha\right)^{+},t\right)+\alpha

(17)

for appropriate
\tilde{\sigma}\in KL
. It should be noticed that the functions
b_{1},b_{2}\in K_{\infty}
and
\tilde{\sigma}\in KL
are independent of
\theta
. Only
\alpha:=\rho^{-1}\left((1-\lambda)^{-1}\delta^{-1}\left(|\theta|^{2}-r\right)^{+}\right)
depends on
\theta
. Furthermore, notice that by increasing
\delta>0
or
r>0
(which are parameters of the controller), we can decrease the value of
\alpha
.

(c)

The KL-estimate (
14
) guarantees UGAOS with any output
Y=h(x,\theta)
with
h(0,\theta)=0
for all
\theta\in\mathbb{R}^{p}
for which there exists a function
b\in K_{\infty}
with
|h(x,\theta)|\leq b\left(\left(P(x)-\alpha\right)^{+}\right)
for all
(x,\theta)\in\mathbb{R}^{n}\times\mathbb{R}^{p}
.

(d)

Estimate (
17
) guarantees UGAOS for the output
Y=x
when
|\theta|\leq\sqrt{r}
. On the other hand, estimate (
17
) is a practical KL-bound when
|\theta|>\sqrt{r}
: it guarantees that

will approach a neighbourhood of radius

in a uniform (with to the initial conditions) rate.

Inequality (
17
) shows the process of ”simultaneous learning and doing”. Getting to the vicinity of the ball
|x|\leq b^{-1}_{1}(\alpha)
can be fast and occurs in a uniform (with respect to the initial conditions) rate. However, if the system is unstable and highly uncertain (large
|\theta|
), this vicinity will be large, and the remaining task (getting to
x=0
) will occur at an unquantified rate. This happens because when we approach the set
x=0
there is no excitation to learn, and to then speed up the remainder of the convergence as a result of learning.

6
Conclusions

In this paper we considered nonlinear adaptive control systems satisfying a matching condition. We designed controllers with nonlinear damping terms depending both on the state and the parameter estimate and derived KL-estimates of the performance of the closed-loop system that guarantees Global Uniform Output Asymptotic Stability for a class of Output functions in the absence of PE. We compare the proposed controller with the existing one in the literature. The new design enhances the robustness and the convergence speed of the closed-loop system but presents a higher overshoot. Further study would be at the direction of improving the performance of the proposed controller in the parameter estimation convergence at its true value. To this end, employing delayed measurements of the state would prove to be sufficient.

This paper should be properly situated within the literature. The paper, and its contribution, should be viewed in the context of of the papers
[
15
]
and
[
17
]
, which dealt, for the first time, with, respectively,
transient performance
and
asymptotic performance
in adaptive control. The present paper also deals with improving transient performance, for the plant/regulated state. The difference from
[
15
]
is that
[
15
]
deals with “overshoot performance” (mainly in the
L_{\infty}
, but also in the
L_{2}
temporal norms, without guarantees on the rate of decay), whereas the present paper deals with ensuring a “decay rate performance”, in the sense of a KL estimate. Both
[
15
]
and the present paper improve the transient performance by strengthening the non-adaptive controller, without significant alterations in the update law. The difference is that
[
15
]
merely employs a robust linear controller to ensure overshoot performance, whereas the present paper goes a step further with nonlinear damping in both the plant and estimator states to improve the
decay rate performance
.
