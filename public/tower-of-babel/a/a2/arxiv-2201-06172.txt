On the c c -differential spectrum of power functions over finite fields
Kun Zhang, Haode Yan

Abstract
Recently, a new concept called multiplicative differential was introduced by Ellingsen et al . Inspired by this pioneering work, power functions with low c c -differential uniformity were constructed. Wang et al. defined the c c -differential spectrum of a power function wang2021several . In this paper, we present some properties of the c c -differential spectrum of a power function. Then we apply these properties to investigate the c c -differential spectra of some power functions. A new class of AP c c N function is also obtained.

Differential cryptanalysis
1991Differential

(2)

(4)

\displaystyle\sum\limits_{i=0}^{{}_{c}{\Delta_{F}}}{i\cdot{{}_{c}\omega_{i}}}

\displaystyle=\sum\limits_{i=0}^{{}_{c}{\Delta_{F}}}{i\cdot\#\left\{{b\in{\mathbb{F}}_{q}:{{}_{c}{\Delta_{F}}(1,b)=i}}\right\}}

\displaystyle=\sum_{b\in{\mathbb{F}}_{q}}\#\{x\in{\mathbb{F}}_{q}:(x+1)^{d}-cx^{d}=b\}

\displaystyle=q.
