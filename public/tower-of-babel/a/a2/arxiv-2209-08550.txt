Abstract
An investigation about localized CP asymmetries for the processes of B ¯ s 0 → π + ​ π − ​ π 0 ​ ( K 0 ) \bar{B}_{s}^{0}\rightarrow\pi^{+}\pi^{-}\pi^{0}(K^{0}) is presented in this paper. The innovation of this paper is that there is a consideration of three-particle ρ 0 ​ ( 770 ) \rho^{0}(770) , ω ⁡ ( 782 ) \omega(782) and ϕ ⁡ ( 1020 ) \phi(1020) interferences effect. Generally, ω ⁡ ( 782 ) \omega(782) and ϕ ⁡ ( 1020 ) \phi(1020) both can decay into π + ​ π − \pi^{+}\pi^{-} pair where can cause extremely small contribution from isospin symmetry breaking. Nevertheless, our analysis shows that B ¯ s 0 → π + ​ π − ​ π 0 ​ ( K 0 ) \bar{B}_{s}^{0}\rightarrow\pi^{+}\pi^{-}\pi^{0}(K^{0}) decay process can bring differential CP asymmetry about 65 % 65\% ( 36 % 36\% ) because of isospin symmetry breaking. To better compared with the data from experimental in the future, we integrate CP asymmetry over the invariant mass and obtain localized CP asymmetry value for the decay B ¯ s 0 → π + ​ π − ​ π 0 ​ ( K 0 ) \bar{B}_{s}^{0}\rightarrow\pi^{+}\pi^{-}\pi^{0}(K^{0}) . We find that there is an evident signal about CP asymmetry at invariant mass value m ⁡ ( π + ​ π − ) m(\pi^{+}\pi^{-}) below the mass of ρ ​ ( 770 ) 0 \rho(770)^{0} with the decay B ¯ s 0 → π + ​ π − ​ π 0 \bar{B}_{s}^{0}\rightarrow\pi^{+}\pi^{-}\pi^{0} .

CALCULATION

In this paper, we take the perturbative QCD (PQCD) method to work out, which is obtained by applying the
k_{T}
factorization formalism to the decay process of two-body. Hadrons have a transverse momentum
k_{T}
, which we must take into account to calculate its transverse momentum. Besides, it introduces an additional energy scale that produces double logarithms in the QCD corrections.
