The Riemannian curvature identities for the torsion connection on S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifold and generalized Ricci solitons


Abstract
Curvature properties of the torsion connection preserving a given S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –structure are investigated. It is observed that a compact S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifold has closed torsion if and only if the Ricci tensor of the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –torsion connection is determined by the covariant derivative of the Lee form.It is shown, that a compact S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifold with closed torsion is Ricci flat if and only if either the norm of the torsion or the Riemannian scalar curvature are constants. It is proved that any compact S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifold with closed torsion 3-form is a generalized gradient Ricci soliton and this is equivalent to a certain vector field to be parallel with respect to the torsion connection. In particular, this vector field is an infinitesimal authomorphism of the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –strucure. Compact examples with bi- S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –structures or generalized S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifolds are given. It is shown that on compact S ​ p ​ i ​ n ​ ( 7 ) Spin(7) –manifold with exterior derivative of the Lee form lying in the Lie algebra s ​ p ​ i ​ n ​ ( 7 ) spin(7) the curvature of the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) -torsion connection R ∈ S 2 ​ Λ 2 R\in S^{2}\Lambda^{2} with vanishing Ricci tensor if and only if the 3 3 -form torsion is parallel with respect to the Levi-Civita connection. It is also proved that the curvature of the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) -torsion connection satisfies the Riemannian first Bianchi identity if and only if the 3 3 -form torsion is parallel with respect to the Levi-Civita and to the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) -torsion connections simultaneously. In this case the Lee form is also parallel with respect to the Levi-Civita and to the S ​ p ​ i ​ n ​ ( 7 ) Spin(7) -torsion connections. In particular, the torsion and the Lee form are harmonic.
