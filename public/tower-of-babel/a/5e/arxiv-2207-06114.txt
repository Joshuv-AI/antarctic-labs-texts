Automatic Differentiation: Theory and Practice
Mario Lezcano-Casado

Abstract
We present the classical coordinate-free formalism for forward and backward mode ad in the real and complex setting. We show how to formally derive the forward and backward formulae for a number of matrix functions starting from basic principles.



Contents

This document is aimed at a reader who has some experience with auto-differentiation (

We do not assume any previous mathematical knowledge, but some mathematical maturity, as we will present the necessary results from different areas of mathematics in the text. That said, some familiarity with linear algebra and multivariate calculus would be helpful.

1
Coordinate-free Linear Algebra

In this section we answer the question: What is a coordinate-free approach and why do we care? With this objective in mind, we define abstract vector spaces, bases, and linear maps.
A secondary objective of this section is to show that thinking of a linear map as something that preserves the operations of a vector space is easier than thinking about it as a matrix.

1.3
Linear maps

The other object that linear algebra studies are linear maps. These are maps between vector spaces that respect the vector space structure.

Definition 1.10
.

A map
T\colon V\to W
between vector spaces over a field
\mathbb{K}
is said to be
\mathbb{K}

T(u+v)=T(u)+T(v)\qquad T(av)=aT(v)\mathrlap{\qquad\forall u,v\in V,a\in\mathbb{K}.}

The following lemma shows that there is a very close connection between linear maps and bases.

Lemma 1.11
(A linear map is defined by its values on a basis).

Let
V
be a vector space with a basis
B_{V}=\{v_{1},\dots,v_{n}\}
. If we choose
w_{1},\dots,w_{n}\in W
, there exists a unique linear map
T\colon V\to W
such that
T(v_{i})=w_{i}
.

Proof.

Since
B_{V}
is a basis, there exists a unique representation of an arbitrary element
v\in V
as
v=a_{1}v_{1}+\dots+a_{n}v_{n}
.
We can define
T
on an arbitrary vector
v
as

T(v)=T(a_{1}v_{1}+\dots+a_{n}v_{n})=a_{1}T(v_{1})+\dots+a_{n}T(v_{n}).

so
T
exists. To show that it is unique, suppose that there is another linear map
T^{\prime}
that takes the same values on
B_{V}
. We then have that they are equal

T(v)=a_{1}T(v_{1})+\dots+a_{n}T(v_{n})=a_{1}T^{\prime}(v_{1})+\dots+a_{n}T^{\prime}(v_{n})=T^{\prime}(a_{1}v_{1}+\dots+a_{n}v_{n})=T^{\prime}(v)

where we have used that
T(v_{i})=T^{\prime}(v_{i})
and the fact that both
T
and
T^{\prime}
are linear.
∎

The best linear maps are those that map bases to bases.

Definition 1.12
.

A linear map

is a basis of

This definition packs quite a bit of information. First, it says that

It also says that this representation of a vector in terms of

is unique, as that is the other property that bases have. In summary, we can represent any vector in

and

T^{\prime}(T(v))=v\quad\text{and}\quad T(T^{\prime}(w))=w\mathrlap{\qquad\forall v\in V,w\in W.}

It should be clear now that a better name for this linear map would be

1

.

1.4
Differences between a real vector space and
\mathbb{R}^{n}

For now, we have set up the basic ideas of linear algebra: We have a vector space, which is an abstract space in which we can add vectors and multiply vectors by scalars, we can encode most of the information of a vector space into a basis, and we can map vector spaces to other vector spaces via linear maps. In particular, if we have a linear isomorphism between vector spaces, this allows us to translate operations on one to operations on the other and back, rendering them somewhat equivalent.

On the other hand, while doing all this, we have barely talked about
\mathbb{R}^{n}
. This is a bit odd given that it is the main space that we want to study. The only thing that we have mentioned is that “real vector spaces model
\mathbb{R}^{n}
” and that, as one could expect,

is a real vector space. But why would we care about real vector spaces in the abstract? Why not simply work on

There are two main differences between real vector spaces and
\mathbb{R}^{n}
. One huge and one subtler.

The huge one is that a general vector space may have infinite dimensions. We put an example of such a vector space in
Example

Now, a real vector space

.

In the same way, if we have a linear map between vector spaces, and we have bases for these vector spaces, we can write this map in coordinates, giving raise to the following well-known concept.

Given a linear map between real vector spaces

Matrices are representations of linear maps, and any

The other rule that we will use repeatedly is a more abstract version of the derivative of the product. This roughly says that “differentiating a function of two variables accounts for differentiating the first variable fixing the second one plus differentiating the second variable fixing he first one”.

Proposition 2.3
(Leibnitz rule).

Let

\lparen\mathrm{d}f\rparen_{(x,y)}\lparen e_{1},e_{2}\rparen=\lparen\mathrm{d}f_{2,y}\rparen_{x}(e_{1})+\lparen\mathrm{d}f_{1,x}\rparen_{y}(e_{2})

The formula in this proposition may look quite difficult to parse, but it will be much easier to understand when we use it in the next section to compute the differential of some matrix functions.

Proposition 3.2
(Differential of a linear map).

Let
T\colon\mathbb{R}^{m}\to\mathbb{R}^{n}
be a linear map, we have that

\lparen\mathrm{d}T\rparen_{x}(v)=T(v)\mathrlap{\qquad\forall x,v\in\mathbb{R}^{m}.}

Proof.

Plugging
\lparen\mathrm{d}T\rparen_{x}(v)=T(v)
into the definition of the differential we get

\lim_{h\to 0_{\mathbb{R}^{m}}}\frac{T(x+h)-T(x)-T(h)}{\lVert h\rVert_{\mathbb{R}^{m}}}=\lim_{h\to 0_{\mathbb{R}^{m}}}\frac{T(x)+T(h)-T(x)-T(h)}{\lVert h\rVert_{\mathbb{R}^{m}}}=\lim_{h\to 0_{\mathbb{R}^{m}}}\frac{0_{\mathbb{R}^{n}}}{\lVert h\rVert_{\mathbb{R}^{m}}}=0_{\mathbb{R}^{n}}.\qed

We can use this to compute the differential of a number of functions widely used in machine learning.

Example 3.3
(Differential of a linear layer. Trailing batch dimension).

Fix

A&\mapsto AX\end{aligned}\mathrlap{\qquad\qquad X\in\mathbb{R}^{m\times b}.}

This is just the usual definition of a linear layer depending on the parameter and with fixed inputs. We do this because we want to differentiate with respect to the parameters. It is clear that

f(A+B)=f(A)+f(B)\qquad f(cA)=cf(A)\mathrlap{\qquad\forall A,B\in\mathbb{R}^{n\times m},c\in\mathbb{R}.}

\lparen\mathrm{d}f\rparen_{A}(E)=EX\mathrlap{\qquad{\text{for }E\in\mathbb{R}^{n\times m}}.}

Example 3.4
(Differential of a linear layer. Front batch dimension).

The batch dimension in machine learning is often the first dimension of the tensor due to the layout of matrices in memory. For this reason, it is common to write a batch

\lparen\mathrm{d}f\rparen_{A}(E)=\mathrm{d}\lparen h\circ g\rparen_{A}(E)=[\lparen\mathrm{d}h\rparen_{g(A)}\circ\lparen\mathrm{d}g\rparen_{A}](E)=\lparen\mathrm{d}h\rparen_{A^{\intercal}}(g(E))=h(E^{\intercal})=XE^{\intercal}.

Theorem 3.11
(Differential a Matrix Function

Let

Proof.

Differentiating the series term by term and using

\lparen\mathrm{d}f\rparen_{A}(E)=\sum_{k=0}^{\infty}c_{k}\sum_{i=0}^{k-1}A^{i}EA^{k-i-1}.

(3)

Remark
(Motivating the concept of gradient).

For a function

Let

Remark
.

A number of remarks are in order.

•

As

•

The gradient of a function depends on the choice of inner product, the differential on finite-dimensional spaces does not, since all the norms are equivalent.

Remark
(Gradient of a composition).

Consider a function

defined as a composition

with

and

and fix inner products on
\mathbb{R}^{m}
and

. How do we compute the gradient of

to the left-hand side of the inner product. This is exactly what the adjoint of a linear map achieves.

Definition 4.5
.

Let

be a linear map between real finite-dimensional vector spaces with inner products
\langle-,-\rangle_{V},\langle-,-\rangle_{W}

as the linear map

\langle w,T(v)\rangle_{W}=\langle T^{\ast}(w),v\rangle_{V}\mathrlap{\qquad\forall v\in V,w\in W.}

Before giving examples of the adjoint of some linear maps, we formalise the motivation that led to the definition of the adjoint.

Proposition 4.6
(Gradient of a composition).

Let

\nabla\lparen f\circ g\rparen(x)=\lparen\mathrm{d}g\rparen^{\ast}_{x}\lparen\nabla f(y)\rparen

Proof.

We finish the computation that we started before

\mathrm{d}\lparen f\circ g\rparen_{x}(v)=\lparen\mathrm{d}f\rparen_{g(x)}[\lparen\mathrm{d}g\rparen_{x}(v)]=\langle\nabla f(y),\lparen\mathrm{d}g\rparen_{x}(v)\rangle_{\mathbb{R}^{n}}=\langle\lparen\mathrm{d}g\rparen^{\ast}_{x}\lparen\nabla f(y)\rparen,v\rangle_{\mathbb{R}^{m}}.\qed

Example 4.7

Consider the linear map of multiplying on the right by a matrix

5.1
Forward mode
ad

When we derived the formulae for forward mode
ad
, they all followed from the definition of differential (
Definition

2.1
) and the formula differential of a linear map (
Proposition

3.2
). As such, if we can generalise these two to complex maps, we should be able to generalise all the forward mode
ad
to complex numbers.

In order to do this, we recall the point that we made in
Example

1.3
,
\mathbb{C}^{n}
is a
real
vector space of dimension
2n
. This means that for
a\in\mathbb{R}
,

u+v\in\mathbb{C}^{n}\qquad au\in\mathbb{C}^{n}\mathrlap{\qquad\qquad\forall u,v\in\mathbb{C}^{n}.}

Furthermore, it means that these operations—again, with
a\in\mathbb{R}
,
not

a\in\mathbb{C}
—satisfy all the axioms of a real vector space in
Definition

1.1
.

This real vector space structure treats the
n
real components and
n
imaginary components as independent, as if they were two parts of a vector of size
2n
in
\mathbb{R}^{2n}=\mathbb{R}^{n}\times\mathbb{R}^{n}
. As such, the norm of a vector in
\mathbb{C}^{n}
as a real vector space is given by

\lVert v\rVert^{2}_{\mathbb{C}^{n}}=\sum_{k=1}^{n}a_{k}^{2}+b_{k}^{2}\mathrlap{\qquad\text{for }v=\lparen a_{1}+ib_{1},\dots,a_{n}+ib_{n}\rparen.}

Using this norm, we can extend the definition of a differential of a real map to complex maps.

Definition 5.1
.

A map
f\colon\mathbb{C}^{m}\to\mathbb{C}^{n}
is
real differentiable
at a point
x\in\mathbb{C}^{m}
if there exists a map
\lparen\mathrm{d}f\rparen_{x}\colon\mathbb{C}^{m}\to\mathbb{C}^{n}
which is linear over the real numbers (cf.,
Definition

1.10
) such that

\lim_{h\to 0_{\mathbb{C}^{m}}}\frac{f(x+h)-f(x)-\lparen\mathrm{d}f\rparen_{x}(h)}{\lVert h\rVert_{\mathbb{C}^{m}}}=0_{\mathbb{C}^{n}}.

Remark
(Real differentiable vs. complex differentiable).

Here we have defined the real differential as an
\mathbb{R}
-linear map, that is, a map such that
\lparen\mathrm{d}f\rparen_{x}(av)=a\lparen\mathrm{d}f\rparen_{x}(v)
for
a\in\mathbb{R}
. If we require the differential to be
\mathbb{C}
-linear—that is,
\lparen\mathrm{d}f\rparen_{x}(av)=a\lparen\mathrm{d}f\rparen_{x}(v)
for
a\in\mathbb{C}
—we get the definition of a complex differentiable map, often called
holomorphic map
.

It should be clear that, if a complex map is complex differentiable, it is also real differentiable, but the opposite is not true. Consider for example
f(z)=\overline{z}
for
z\in\mathbb{C}
. We have that
f(az)=\overline{a}f(z)
for
a\in\mathbb{C}
, so it is not
\mathbb{C}
-linear, but it is
\mathbb{R}
-linear as
f(az)=af(z)
for
a\in\mathbb{R}
. Luckily, we will not need to use holomorphic maps, as real differentiable maps will be enough to compute differentials and gradients.

The chain rule (
Theorem

2.2
) and the Leibnitz rule (
Proposition

2.3
) also hold verbatim for real differentiable maps. We also have the following equivalent to
Proposition

3.2
.

Proposition 5.2
(Differential of a linear map).

Let
T\colon\mathbb{C}^{m}\to\mathbb{C}^{n}
be an
\mathbb{R}
-linear map, we have that

\lparen\mathrm{d}T\rparen_{x}(v)=T(v)\mathrlap{\qquad\forall x,v\in\mathbb{C}^{m}.}

Proof.

The proof is the same as in the real case.
∎

Having this, we can compute the differential of many maps, as we did in the real case.
