Study of the B c B_{c} → {\to} B s ​ π B_{s}{\pi} decay with the perturbative QCD approach
SUN Junfeng, YANG Yueling, LU Gongru

Abstract
The B c B_{c} → {\to} B s ​ π B_{s}{\pi} decay is studied with the perturbative QCD approach. Three types of wave functions for B s B_{s} meson are considered. The transition form factor F 0 B c → B s ​ ( 0 ) F_{0}^{B_{c}{\to}B_{s}}(0) and the branching ratio ℬ ​ r ​ ( B c → B s ​ π ) {\cal B}r(B_{c}{\to}B_{s}{\pi}) are sensitive to the model of the B s B_{s} meson wave functions. With appropriate inputs, our estimate on ℬ ​ r ​ ( B c → B s ​ π ) {\cal B}r(B_{c}{\to}B_{s}{\pi}) is comparable with the recent LHCb measurement. A clear signal of B c B_{c} → {\to} B s ​ π B_{s}{\pi} decay should be easily observed at the Large Hadron Collider. Keywords: B c B_{c} meson, weak decay, the perturbative QCD approach, branching ratio.
