A note on error analysis for a nonconforming discretisation of the tri-Helmholtz equation with singular data
Andreas Bock and Colin Cotter

Abstract
We apply the nonconforming discretisation of [ WX19 ] to the tri-Helmholtz equation on the plane where the source term is a functional evaluating the test function on a one-dimensional mesh-aligned embedded curve. We present error analysis for the convergence of the discretisation and linear convergence as a function of mesh size is recovered almost everywhere away from the embedded curve which aligns with classic regularity theory. Elliptic PDE; Nonconforming method; Finite element method.

\displaystyle a(u,u)-2a_{h}(u,u)+\int_{S^{1}}\tilde{f}\cdot u\circ g\;\textnormal{d}{\theta}=0

∎

\displaystyle\leq b_{3}\big(\sum_{i=1}^{2}\sum_{e\in\mathring{\mathcal{E}}_{h}\setminus{g\circ S^{1}}}\min_{K\in\mathcal{K}_{e}}h_{K}^{-2}\|D^{3}u^{i}-c_{e}\|_{0,K}^{2}+|D^{3}u^{i}|_{1,K}^{2}\big)^{1/2}

\displaystyle\quad\times\big(h_{K}^{2}|D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{1,K}^{2}\big)^{1/2}

\displaystyle\lesssim b_{3}\big(\sum_{i=1}^{2}\sum_{e\in\mathring{\mathcal{E}}_{h}\setminus{g\circ S^{1}}}|D^{3}u^{i}|_{1,K}^{2}\big)^{1/2}\big(h_{K}^{2}|D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{1,K}^{2}\big)^{1/2}.

Using the trace theorem we get:

\displaystyle|\sum_{i=1}^{2}\int_{\mathring{\mathcal{E}}_{h}\setminus{g\circ S^{1}}}b_{3}\langle D^{3}u^{i},\llbracket D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\rrbracket\rangle\;\textnormal{d}s|

\displaystyle\lesssim b_{3}h\big(\sum_{i=1}^{2}\sum_{K\in\Omega_{h}}|D^{3}u^{i}|_{1,K}^{2}\big)^{1/2}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{m,\Omega_{h}}

\displaystyle=b_{3}h\|D^{4}u^{i}\|_{0,\Omega_{h}}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{m,\Omega_{h}}

\displaystyle\lesssim b_{3}h\|D^{4}u^{i}\|_{0,\Omega_{h}}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

Estimating (
25d
), (
25e
) and (
25f
) relies on the trace
theorem and a property of the conforming relatives operator in
(
22
). For (
25d
) we have:

\displaystyle\sum_{i=1}^{2}\int_{g\circ S^{1}}-b_{2}\langle\llbracket D^{3}u^{i}\rrbracket,\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\rangle\;\textnormal{d}s

\displaystyle\leq

\displaystyle b_{2}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}\rrbracket\|_{0,e}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{0,e}.

By the trace theorem we have
\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{0,e}\lesssim\sum_{K\in\mathcal{K}_{e}}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{1,K}
. Using this and
(
22
) in the above estimate gives us:

\displaystyle|\sum_{i=1}^{2}\int_{g\circ S^{1}}-b_{2}\langle\llbracket D^{3}u^{i}\rrbracket,\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\rangle\;\textnormal{d}s|

\displaystyle\lesssim

\displaystyle b_{2}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}\rrbracket\|_{0,e}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{1,\Omega_{h}}

\displaystyle\lesssim

\displaystyle b_{2}h^{2}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}\rrbracket\|_{0,e}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

By a similar argument for (
25e
):

\displaystyle|\sum_{i=1}^{2}\int_{g\circ S^{1}}-b_{3}\langle\llbracket D^{5}u^{i}\rrbracket,\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\rangle\;\textnormal{d}s|

\displaystyle\lesssim

\displaystyle b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{5}u^{i}\rrbracket\|_{0,e}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{1,\Omega_{h}}

\displaystyle\lesssim

\displaystyle b_{2}h^{2}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{5}u^{i}\rrbracket\|_{0,e}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

Term (
25f
) is estimated similarly:

\displaystyle\sum_{i=1}^{2}\int_{g\circ S^{1}}b_{3}\llbracket D^{4}u^{i}D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\rrbracket\;\textnormal{d}s

\displaystyle=

\displaystyle b_{3}\sum_{i=1}^{2}\int_{g\circ S^{1}}\langle\eta_{K_{e}^{+}}D^{4}u^{i}|_{K_{e}^{+}},D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{K_{e}^{+}}\rangle

\displaystyle\qquad\quad\quad\;\;+\langle\eta_{K_{e}^{-}}D^{4}u^{i}|_{K_{e}^{-}},D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{K_{e}^{-}}\rangle\;\textnormal{d}s.

Using Cauchy-Schwartz twice, the trace theorem and (
22
) we proceed
as previously:

\displaystyle\sum_{i=1}^{2}\int_{g\circ S^{1}}b_{3}\llbracket D^{4}u^{i}D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\rrbracket\;\textnormal{d}s

\displaystyle\leq

\displaystyle b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\eta_{K_{e}^{+}}D^{4}u^{i}|_{K_{e}^{+}}\|_{0,e}\|D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{K_{e}^{+}}\|_{0,e}

\displaystyle\qquad\quad\quad\;\;+\|\eta_{K_{e}^{-}}D^{4}u^{i}|_{K_{e}^{-}}\|_{0,e}\|D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})|_{K_{e}^{-}}\|_{0,e}

\displaystyle\lesssim

\displaystyle b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\big(\|\eta_{K_{e}^{+}}D^{4}u^{i}|_{K_{e}^{+}}\|_{0,e}+\|\eta_{K_{e}^{-}}D^{4}u^{i}|_{K_{e}^{-}}\|_{0,e}\big)\|D(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\|_{1,\Omega_{h}}

\displaystyle\lesssim

\displaystyle b_{3}h\Big(\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\big(\|\eta_{K_{e}^{+}}D^{4}u^{i}|_{K_{e}^{+}}\|_{0,e}+\|\eta_{K_{e}^{-}}D^{4}u^{i}|_{K_{e}^{-}}\|_{0,e}\big)\Big)\|\mathsf{w}_{h}\|_{m,\Omega_{h}}

\displaystyle\leq

\displaystyle b_{3}h\|D^{4}u\|_{0,\Omega_{h}}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

Finally we estimate (
25g
):

\displaystyle|\sum_{i=1}^{2}\int_{g\circ S^{1}}-b_{3}\llbracket D^{3}u^{i}D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\rrbracket\;\textnormal{d}s|

\displaystyle=

\displaystyle|-b_{3}\sum_{i=1}^{2}\int_{g\circ S^{1}}\{D^{3}u^{i}\}\cdot\llbracket D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\rrbracket+\llbracket D^{3}u^{i}\rrbracket\{D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\}\;\textnormal{d}s|

\displaystyle=

\displaystyle T_{1}+T_{2}.

We estimate
T_{1}
using the same method as for the term (
25c
). The only
difference is the presence of the averaging operator, but we can write
\{D^{3}u^{i}\}=\frac{1}{2}D^{3}u^{i}|_{K_{e}^{-}}+\frac{1}{2}D^{3}u^{i}|_{K_{e}^{+}}
, and since the
restrictions of
D^{3}u^{i}
to
{K_{e}^{+}}
and
{K_{e}^{-}}
are smooth there are no
changes to the procedure for the term (
25c
).

\displaystyle T_{1}\lesssim b_{3}h\|D^{4}u\|_{0,\Omega_{h}}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

Obtaining a convergence rate for
T_{2}
is more difficult owing to the presence
of the
\{D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\}
term. It is easy to see why, since for an
arbitrary edge
e\in\mathring{\mathcal{E}}_{h}
,
\|D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\|_{0,e}\lesssim\|D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\|_{1,K}
for some
K\in\Omega_{h}
with
e
as an edge. Then by
(
22
) we know:

\displaystyle(\sum_{i=1}^{2}\sum_{K\in\Omega_{h}}\|D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\|_{1,K}^{2})^{1/2}\lesssim\|\mathsf{w}_{h}\|_{m,\Omega_{h}},

but we do not recover a factor of
h
in this bound. We can however bound
(
25g
) as follows using an averaging operator over a neighbourhood near
an edge (see also
[
WX19
, Equation 3.12]
for an example). We
define
P_{\mathcal{K}_{e}}
as the projection operator on
L^{2}(\mathcal{K}_{e})

defined by:

\displaystyle P_{\mathcal{K}_{e}}v=(\sum_{K\in\mathcal{K}_{e}}|K|)^{-1}\sum_{K\in\mathcal{K}_{e}}\int_{K}v\;\textnormal{d}x,\qquad v\in L^{2}(\Omega).

Then,

\displaystyle T_{2}

\displaystyle=|b_{3}\sum_{i=1}^{2}\int_{g\circ S^{1}}\llbracket D^{3}u^{i}\rrbracket\{D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\}\;\textnormal{d}s|

\displaystyle=|b_{3}\sum_{i=1}^{2}\int_{g\circ S^{1}}\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\{D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\}\;\textnormal{d}s|

\displaystyle\leq b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}\|\{D^{2}(\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i})\}\|_{0,e}.

Now using the trace theorem and (
22
):

\displaystyle T_{2}

\displaystyle\lesssim b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}\|\mathsf{w}_{h}^{i}-\big[\Pi^{c}_{h}\mathsf{w}_{h}\big]^{i}\|_{m,\Omega_{h}}

\displaystyle\lesssim b_{3}\sum_{i=1}^{2}\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}\|\mathsf{w}_{h}\|_{m,\Omega_{h}}.

Collecting the bounds we have for (
25
) so far and dividing by

\|\mathsf{w}_{h}\|_{m,\Omega_{h}}
yields:

\displaystyle\frac{a_{h}(u-u_{h},\mathsf{w}_{h})}{\|\mathsf{w}_{h}\|_{m,\Omega_{h}}}\lesssim

\displaystyle h\Big(\sum_{i=1}^{2}\|D^{3}u^{i}\|_{0,\Omega_{h}}+\|D^{5}u^{i}\|_{0,\Omega_{h}}+\|D^{4}u^{i}\|_{0,\Omega_{h}}

\displaystyle+h\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}\rrbracket\|_{0,e}

\displaystyle+h\sum_{e\in g\circ S^{1}}\|\llbracket D^{5}u^{i}\rrbracket\|_{0,e}+2\|D^{4}u^{i}\|_{0,\Omega_{h}}\Big)

\displaystyle+\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}

Using Strang’s lemma
11
and corollary
16
we can
therefore say:

\displaystyle\|u-u_{h}\|_{m,\Omega_{h}}

\displaystyle\lesssim h\Big(\|\tilde{f}\|_{0,S^{1}}+\sum_{i=1}^{2}\|D^{3}u^{i}\|_{0,\Omega_{h}}+\|D^{5}u^{i}\|_{0,\Omega_{h}}+\|D^{4}u^{i}\|_{0,\Omega_{h}}

\displaystyle+h\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}\rrbracket\|_{0,e}

\displaystyle+h\sum_{e\in g\circ S^{1}}\|\llbracket D^{5}u^{i}\rrbracket\|_{0,e}+2\|D^{4}u^{i}\|_{0,\Omega_{h}}\Big)

\displaystyle+\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}

\displaystyle+h^{s}|u|_{m+s,\Omega_{h}},

for any
s\geq 0
, so the result follows.
∎

Remark 25

(Conforming reconstruction operator)
.

In the analysis above we make heavy use of the projection operator

P_{\mathcal{K}_{e}}
as it is constructed in such a way as to be continuous over the
edge
e
(trivially so as the range of this operator is the space of constants).

[
GP17
]
proposes a
\mathsf{C}^{1}
reconstruction operator
with attractive properties (see e.g. equation (16) in the reference) that could
be explored instead. These properties concern error estimation of the projection
error on elements
K
of the triangulation. However, convergence in terms of
h

is not readily obtained using such operators as the preceding analysis deals
with terms of like
\sum_{e\in g\circ S^{1}}\|\llbracket D^{3}u^{i}-P_{\mathcal{K}_{e}}\big[D^{3}u^{i}\big]\rrbracket\|_{0,e}
concerning the jump over edges. By
using a trace inequality to pull the estimate to
K
we lose an order of
differentiation which is reflected in the estimation properties of the
aforementioned operator (roughly speaking: the
L^{2}
norm on
\partial K
can be
bounded by the
H^{1}
norm on
K
). It is therefore not certain that such a
conforming reconstruction operator yields estimates that scale well with
h
.

In summary, the finite element discretisation in (
16
) is convergent for
\tilde{f}\in L^{2}(S^{1})^{d}
and mesh-aligned curve
g\in\mathsf{C}^{0}(S^{1})^{d}
.
We saw that the presence of the singular curve integral as a source term prohibits global regularity, and that despite recovering almost everywhere
\mathsf{C}^{\infty}
regularity we cannot attain linear convergence as a function of
h
using the conforming relatives used in corollary
23
.

3
Summary

We have presented error analysis for a higher-order nonconforming finite element method with singular data. In doing so we have confirmed a standard result: nonconforming finite elements are well-suited, in terms of proving convergence results for the discretisation, to problems with smooth data. The lack of at least global
L^{2}
regularity of the source terms considered here prohibits the discovery of convergence rate across the singularity. We therefore emphasise the need for higher-order conforming finite element methods as this would greatly simplify the analysis carried out in section
2
.
