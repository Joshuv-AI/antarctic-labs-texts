Generalized Leverage Score Sampling for Neural Networks Thanks: The authors would like to thank Michael Kapralov for suggestion of this topic.
Jason D. Lee, Ruoqi Shen, Zhao Song, Mengdi Wang, Zheng Yu

Abstract
Leverage score sampling is a powerful technique that originates from theoretical computer science, which can be used to speed up a large number of fundamental questions, e.g. linear regression, linear programming, semi-definite programming, cutting plane method, graph sparsification, maximum matching and max-flow. Recently, it has been shown that leverage score sampling helps to accelerate kernel methods [Avron, Kapralov, Musco, Musco, Velingker and Zandieh 17]. In this work, we generalize the results in [Avron, Kapralov, Musco, Musco, Velingker and Zandieh 17] to a broader class of kernels. We further bring the leverage score sampling into the field of deep learning theory. • We show the connection between the initialization for neural network training and approximating the neural tangent kernel with random features. • We prove the equivalence between regularized neural network and neural tangent kernel ridge regression under the initialization of both classical random Gaussian and leverage score sampling.

Introduction

Kernel method is one of the most common techniques in various machine learning problems. One classical application is the kernel ridge regression (KRR). Given training data
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
, corresponding labels
Y=[y_{1},\cdots,y_{n}]\in\mathbb{R}^{n}
and regularization parameter
\lambda>0
, the output estimate of KRR for any given input
z
can be written as:

\displaystyle f(z)=\mathsf{K}(z,X)^{\top}(K+\lambda I_{n})^{-1}Y,

(1)

where
\mathsf{K}(\cdot,\cdot)
denotes the kernel function and
K\in\mathbb{R}^{n\times n}
denotes the kernel matrix.

Despite being powerful and well-understood, the kernel ridge regression suffers from the costly computation when dealing with large datasets, since generally implementation of Eq. (
1
) requires
O(n^{3})
running time. Therefore, intensive research have been dedicated to the scalable methods for KRR
[
Bac13
,
AM15
,
ZDW15
,
ACW17
,
MM17
,
ZNV+20
]
. One of the most popular approach is the random Fourier features sampling originally proposed by
[
RR08
]
for shift-invariant kernels. They construct a finite dimensional random feature vector
\phi:\mathbb{R}^{d}\to\C^{s}
through sampling that approximates the kernel function
\mathsf{K}(x,z)\approx\phi(x)^{*}\phi(z)
for data
x,z\in\mathbb{R}^{d}
. The random feature helps approximately solves KRR in
O(ns^{2}+n^{2})
running time, which improves the computational cost if
s\ll n
. The work
[
AKM+17
]
advanced this result by introducing the leverage score sampling to take the regularization term into consideration.

In this work, we follow the the approach in
[
AKM+17
]
and naturally generalize the result to a broader class of kernels, which is of the form

\displaystyle\mathsf{K}(x,z)=\E_{w\sim p}[\phi(x,w)^{\top}\phi(z,w)],

where
\phi:\mathbb{R}^{d}\times\mathbb{R}^{d_{1}}\to\mathbb{R}^{d_{2}}
is a finite dimensional vector and
p:\mathbb{R}^{d_{1}}\to\mathbb{R}_{\geq 0}
is a probability distribution. We apply the leverage score sampling technique in this generalized case to obtain a tighter upper-bound on the dimension of random features.

Further, We discuss the application of our theory in neural network training. Over the last two years, there is a long line of over-parametrization theory works on the convergence results of deep neural network
[
LL18
,
DZPS19
,
AZLS19b
,
AZLS19a
,
DLL+19
,
ADH+19b
,
ADH+19a
,
SY19
,
BPSW20
]
, all of which either explicitly or implicitly use the property of neural tangent kernel
[
JGH18
]
. However, most of those results focus on neural network training without regularization, while in practice regularization (which is originated from classical machine learning) has been widely used in training deep neural network. Therefore, in this work we rigorously build the equivalence between training a ReLU deep neural network with
\ell_{2}
regularization and neural tangent kernel ridge regression.
We observe that the initialization of training neural network corresponds to approximating the neural tangent kernel with random features, whose dimension is proportional to the width of the network. Thus, it motivates us to bring the leverage score sampling theory into the neural network training. We present a new equivalence between neural net and kernel ridge regression under the initialization using leverage score sampling, which potentially improves previous equivalence upon the upper-bound of network width needed.

We summarize our main results and contribution as following:

•

Generalize the leverage score sampling theory for kernel ridge regression to a broader class of kernels.

•

Connect the leverage score sampling theory with neural network training.

•

Theoretically prove the equivalence between training regularized neural network and kernel ridge regression under both random Gaussian initialization and leverage score sampling initialization.

Given a

3.1
Kernel approximation with leverage score sampling

In this section, we generalize the leverage score theory in
[
AKM+17
]
, which analyzes the number of random features needed to approximate kernel matrix under leverage score sampling regime for the kernel ridge regression task. In the next a few paragraphs, we briefly review the settings of classical kernel ridge regression.

Given training data given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
, corresponding labels
Y=[y_{1},\cdots,y_{n}]^{\top}\in\mathbb{R}^{n}
and feature map
\phi:\mathbb{R}^{d}\to\mathcal{F}
, a classical kernel ridge regression problem can be written as
1
1

1

Strictly speaking, the optimization problem should be considered in a hypothesis space defined by the reproducing kernel Hilbert space associated with the feature/kernel. Here, we use the notation in finite dimensional space for simplicity.

\displaystyle\min_{\beta}\frac{1}{2}\|Y-\phi(X)^{\top}\beta\|_{2}^{2}+\frac{1}{2}\lambda\|\beta\|_{2}^{2}

where
\lambda>0
is the regularization parameter. By introducing the corresponding kernel function
\mathsf{K}(x,z)=\langle\phi(x),\phi(z)\rangle
for any data
x,z\in\mathbb{R}^{d}
, the output estimate of the kernel ridge regression for any data
x\in\mathbb{R}^{d}
can be denoted as
f^{*}(x)=\mathsf{K}(x,X)^{\top}\alpha
,
where
\alpha\in\mathbb{R}^{n}
is the solution to

\displaystyle(K+\lambda I_{n})\alpha=Y.

Here
K\in\mathbb{R}^{n\times n}
is the kernel matrix with
K_{i,j}=\mathsf{K}(x_{i},x_{j})
,
\forall i,j\in[n]\times[n]
.

Note a direct computation involves
(K+\lambda I_{n})^{-1}
, whose
O(n^{3})
running time can be fairly large in tasks like neural network due to the large number of training data. Therefore, we hope to construct feature map
\phi:\mathbb{R}^{d}\to\mathbb{R}^{s}
, such that the new feature approximates the kernel matrix well in the sense of

\displaystyle(1-\epsilon)\cdot(K+\lambda I_{n})\preceq\Phi\Phi^{\top}+\lambda I_{n}\preceq(1+\epsilon)\cdot(K+\lambda I_{n}),

(2)

where
\epsilon\in(0,1)
is small and
\Phi=[\phi(x_{1}),\cdots,\phi(x_{n})]^{\top}\in\mathbb{R}^{n\times s}
. Then by Woodbury matrix equality, we can approximate the solution by
u^{*}(z)=\phi(z)^{\top}(\Phi^{\top}\Phi+\lambda I_{s})^{-1}\Phi^{\top}Y
, which can be computed in
O(ns^{2}+n^{2})
time. In the case
s=o(n)
, computational cost can be saved.

In this work, we consider a generalized setting of
[
AKM+17
]
as a kernel ridge regression problem with positive definite kernel matrix
\mathsf{K}:\mathbb{R}^{d}\times\mathbb{R}^{d}\to\mathbb{R}
of the form

\displaystyle\mathsf{K}(x,z)=\E_{w\sim p}[\phi(x,w)^{\top}\phi(z,w)],

(3)

where
\phi:\mathbb{R}^{d}\times\mathbb{R}^{d_{1}}\to\mathbb{R}^{d_{2}}
denotes a finite dimensional vector and
p:\mathbb{R}^{d_{1}}\to\mathbb{R}_{\geq 0}
denotes a probability density function.

Due to the regularization
\lambda>0
in this setting, instead of constructing the feature map directly from the distribution
q
, we consider the following ridge leveraged distribution:

Definition 3.1

(Ridge leverage function)
.

Given data
x_{1},\cdots,x_{n}\in\mathbb{R}^{d}
and parameter
\lambda>0
, we define the ridge leverage function as

\displaystyle q_{\lambda}(w)=p(w)\cdot\Tr[\Phi(w)^{\top}(K+\lambda I_{n})^{-1}\Phi(w)],

where
p(\cdot)
,
\phi
are defined in Eq. (
3
), and
\Phi(w)=[\phi(x_{1},w)^{\top},\cdots,\phi(x_{n},w)^{\top}]^{\top}\in\mathbb{R}^{n\times d_{2}}
. Further, we define statistical dimension
s_{\lambda}(K)
as

\displaystyle s_{\lambda}(K)=\int q_{\lambda}(w)\mathrm{d}w=\Tr[(K+\lambda I_{n})^{-1}K].

(4)

The leverage score sampling distribution
q_{\lambda}/s_{\lambda}(K)
takes the regularization term into consideration and achieves Eq. (
2
) using the following modified random features vector:

Definition 3.2

(Modified random features)
.

Given any probability density function
q(\cdot)
whose support includes that of
p(\cdot)
. Given
m
vectors
w_{1},\cdots,w_{m}\in\mathbb{R}^{d_{1}}
, we define modified random features
\overline{\Psi}\in\mathbb{R}^{n\times md_{2}}
as

\overline{\Psi}:=[\overline{\varphi}(x_{1}),\cdots,\overline{\varphi}(x_{n})]^{\top},

where

\displaystyle\overline{\varphi}(x)=\frac{1}{\sqrt{m}}\left[\frac{\sqrt{p(w_{1})}}{\sqrt{q(w_{1})}}\phi(x,w_{1})^{\top},\cdots,\frac{\sqrt{p(w_{m})}}{\sqrt{q(w_{m})}}\phi(x,w_{m})^{\top}\right]^{\top}.

Now we are ready to present our result.

Theorem 3.3

(Kernel approximation with leverage score sampling, generalization of Lemma 8 in
[
AKM+17
]
)
.

Given parameter
\lambda\in(0,\|K\|)
. Let
q_{\lambda}:\mathbb{R}^{d_{1}}\to\mathbb{R}_{\geq 0}
be the leverage score defined in Definition
3.1
. Let
\widetilde{q}_{\lambda}:\mathbb{R}^{d_{1}}\rightarrow\mathbb{R}
be any measurable function such that
\widetilde{q}_{\lambda}(w)\geq q_{\lambda}(w)
holds for all
w\in\mathbb{R}^{d_{1}}
. Assume
s_{\widetilde{q}_{\lambda}}=\int_{\mathbb{R}^{d_{1}}}\widetilde{q}_{\lambda}(w)\mathrm{d}w
is finite. Let
\overline{q}_{\lambda}(w)=\widetilde{q}_{\lambda}(w)/s_{\widetilde{q}_{\lambda}}
. Given any accuracy parameter
\epsilon\in(0,1/2)
and failure probability
\delta\in(0,1)
. Let
w_{1},\cdots,w_{m}\in\mathbb{R}^{d}
denote
m
samples draw independently from the distribution associated with the density
\overline{q}_{\lambda}(\cdot)
, and construct the modified random features
\overline{\Psi}\in\mathbb{R}^{n\times md_{2}}
as in Definition
3.2
with
q=\overline{q}_{\lambda}
. Let
s_{\lambda}(K)
be the statistical dimension defined in (
4
).
If
m\geq 3\epsilon^{-2}s_{\widetilde{q}_{\lambda}}\ln(16s_{\widetilde{q}_{\lambda}}\cdot s_{\lambda}(K)/\delta)
, then we have

\displaystyle(1-\epsilon)\cdot(K+\lambda I_{n})\preceq\overline{\Psi}\overline{\Psi}^{\top}+\lambda I_{n}\preceq(1+\epsilon)\cdot(K+\lambda I_{n})

(5)

holds with probability at least
1-\delta
.

Remark 3.4
.

Above results can be generalized to the complex domain
\C
. Note for the random Fourier feature case discussed in
[
AKM+17
]
, we have
d_{1}=d
,
d_{2}=1
,
\phi(x,w)=e^{-2\pi\mathbf{i}w^{\top}x}\in\C
and
p(\cdot)
denotes the Fourier transform density distribution, which is a special case in our setting.

3.2
Application in training regularized neural network

In this section, we consider the application of leverage score sampling in training
\ell_{2}
regularized neural networks.

Past literature such as
[
DZPS19
]
,
[
ADH+19a
]
have already witnessed the equivalence between training a neural network and solving a kernel regression problem in a broad class of network models. In this work, we first generalize this result to the regularization case, where we connect regularized neural network with kernel ridge regression. Then we apply the above discussed the leverage score sampling theory for KRR to the task of training neural nets.

3.2.1
Equivalence I, training with random Gaussian initialization

To illustrate the idea, we consider a simple model two layer neural network with ReLU activation function as in
[
DZPS19
,
SY19
]
2
2

2

Our results directly extends to multi-layer deep neural networks with all layers trained together
.

\displaystyle f_{\nn}(W,a,x)=\frac{1}{\sqrt{m}}\sum_{r=1}^{m}a_{r}\sigma(w_{r}^{\top}x)\in\mathbb{R},

where
x\in\mathbb{R}^{d}
is the input,
w_{r}\in\mathbb{R}^{d},\penalty\ r\in[m]
is the weight vector of the first layer,
W=[w_{1},\cdots,w_{m}]\in\mathbb{R}^{d\times m}
,
a_{r}\in\mathbb{R},\penalty\ r\in[m]
is the output weight,

and

is the ReLU activation function:

Here we consider only training the first layer

Definition 3.5

(Training neural network with regularization)
.

Let
\kappa\in(0,1]
be a small multiplier
3
3

3

To establish the training equivalence result, we assign
\kappa=1
back to the normal case. For the training equivalence result, we pick
\kappa>0
to be a small multiplier only to shrink the initial output of the neural network. The is the same as what is used in
[
AKM+17
]
.
. Let
\lambda\in(0,1)
be the regularization parameter. We initialize the network as
a_{r}\overset{i.i.d.}{\sim}\unif[\{-1,1\}]

w_{r}(0)\overset{i.i.d.}{\sim}\mathcal{N}(0,I_{d})
. Then we consider solving the following optimization problem using gradient descent:

\displaystyle\min_{W}\frac{1}{2}\|Y-\kappa f_{\nn}(W,X)\|_{2}+\frac{1}{2}\lambda\|W\|_{F}^{2}.

(6)

Let
w_{r}(t),r\in[m]
be the network weight at iteration
t
. We denote the training data predictor at iteration

u_{\nn}(t)=\kappa f_{\nn}(W(t),X)\in\mathbb{R}^{n}
.
Further, given any test data
x_{\test}\in\mathbb{R}^{d}

u_{\nn,\test}(t)=\kappa f_{\nn}(W(t),x_{\test})\in\mathbb{R}

.

On the other hand, we consider the following neural tangent kernel ridge regression problem:

\displaystyle\min_{\beta}\frac{1}{2}\|Y-\kappa f_{\ntk}(\beta,X)\|_{2}^{2}+\frac{1}{2}\lambda\|\beta\|_{2}^{2},

(7)

where
\kappa,\lambda
are the same parameters as in Eq. (
6
),

\displaystyle\mathsf{K}_{\ntk}(x,z)=\E\left[\left\langle\frac{\partial f_{\nn}(W,x)}{\partial W},\frac{\partial f_{\nn}(W,z)}{\partial W}\right\rangle\right]

where

for the test data

(Equivalence between training neural net with regularization and kernel ridge regression for training data prediction)
.

\epsilon\in(0,1/10)
and failure probability
\delta\in(0,1/10)
. Let multiplier
\kappa=1

\displaystyle\|u_{\nn}(T)-u^{*}\|_{2}\leq\epsilon.

\widetilde{O}(\cdot)

.

Theorem 3.7

(Equivalence between training neural net with regularization and kernel ridge regression for test data prediction)

\epsilon\in(0,1/10)
and failure probability

. Let multiplier

and regularization parameter
\lambda\leq\widetilde{O}(\frac{1}{\sqrt{m}})
. Then with probability at least

\displaystyle\|u_{\nn,\test}(T)-u_{\test}^{*}\|_{2}\leq\epsilon.

3.2.2
Equivalence II, training with leverage scores

To apply the leverage score theory discussed in Section
3.1
, Note the definition of the neural tangent kernel is exactly of the form:

\displaystyle\mathsf{K}_{\ntk}(x,z)=\E\left[\left\langle\frac{\partial f_{\nn}(W,x)}{\partial W},\frac{\partial f_{\nn}(W,z)}{\partial W}\right\rangle\right]=\E_{w\sim p}[\phi(x,w)^{\top}\phi(z,w)]

where
\phi(x,w)=x\sigma^{\prime}(w^{\top}x)\in\mathbb{R}^{d}
and
p(\cdot)
denotes the probability density function of standard Gaussian distribution
\mathcal{N}(0,I_{d})
. Therefore, we try to connect the theory of training regularized neural network with leverage score sampling. Note the width of the network corresponds to the size of the feature vector in approximating the kernel. Thus, the smaller feature size given by the leverage score sampling theory helps us build a smaller upper-bound on the width of the neural nets.

Specifically, given regularization parameter
\lambda>0
, we can define the ridge leverage function with respect to neural tangent kernel

defined in Definition

\displaystyle q_{\lambda}(w)=p(w)\Tr[\Phi(w)^{\top}(H^{\cts}+\lambda I_{n})^{-1}\Phi(w)]

where

(Training reweighed neural network with regularization)
.

Generalization of leverage score theory

To prove Theorem
3.3
, we follow the similar proof framework as Lemma 8 in
[
AKM+17
]
.

Let
K+\lambda I_{n}=V^{\top}\Sigma^{2}V
be an eigenvalue decomposition of
K+\lambda I_{n}
. Then conclusion (
5
) is equivalent to

\displaystyle\|\Sigma^{-1}V\overline{\Psi}\overline{\Psi}^{\top}V^{\top}\Sigma^{-1}-\Sigma^{-1}VKV^{\top}\Sigma^{-1}\|\leq\epsilon

(11)

Let random matrix
Y_{r}\in\mathbb{R}^{n\times n}
defined as

\displaystyle Y_{r}:=\frac{p(w_{r})}{\overline{q}_{\lambda}(w_{r})}\Sigma^{-1}V{\Phi}(w_{r}){\Phi}(w_{r})^{\top}V^{\top}\Sigma^{-1}.

where
\Phi(w)=[\phi(x_{1},w),\cdots,\phi(x_{n},w)]^{\top}\in\mathbb{R}^{n\times d_{2}}
.
Then we have

\displaystyle\E_{\overline{q}_{\lambda}}[Y_{l}]=\E_{\overline{q}_{\lambda}}\left[\frac{p(w_{r})}{\overline{q}_{\lambda}(w_{r})}\Sigma^{-1}V{\Phi}(w_{r})\overline{\Phi}(w_{r})^{\top}V^{\top}\Sigma^{-1}\right]=\Sigma^{-1}VKV^{\top}\Sigma^{-1},

and

\displaystyle\frac{1}{m}\sum_{r=1}^{m}Y_{r}=\frac{1}{m}\sum_{r=1}^{m}\frac{p(w_{r})}{\overline{q}_{\lambda}(w_{r})}\Sigma^{-1}V{\Phi}(w_{r})\overline{\Phi}(w_{r})^{\top}V^{\top}\Sigma^{-1}=\Sigma^{-1}V\overline{\Psi}\overline{\Psi}^{\top}V^{\top}\Sigma^{-1}.

Thus, it suffices to show that

\displaystyle\left\|\frac{1}{m}\sum_{r=1}^{m}Y_{r}-\E_{\overline{q}_{\lambda}}[Y_{l}]\right\|\leq\epsilon

(12)

holds with probability at least
1-\delta
, which can be shown by applying matrix concentration results. Note

\displaystyle\|Y_{l}\|\leq s_{\overline{q}_{\lambda}}\penalty\ \penalty\ \text{and}\penalty\ \E_{\overline{q}_{\lambda}}[Y_{r}^{2}]\preceq s_{\widetilde{q}_{\lambda}}\cdot\diag\{\lambda_{1}/(\lambda_{1}+\lambda),\cdots,\lambda_{n}/(\lambda_{n}+\lambda)\}.

Applying matrix concentration Lemma 7 in

Equivalence between regularized neural network and kernel ridge regression

To establish the equivalence between training neural network with regularization and neural tangent kernel ridge regression, the key observation is that the dynamic kernel during the training is always close to the neural tangent kernel.

Specifically, given training data
x_{1},\cdots,x_{n}\in\mathbb{R}^{d}
, we define the dynamic kernel matrix
H(t)\in\mathbb{R}^{n\times n}
along training process as

\displaystyle[H(t)]_{i,j}=\left\langle\frac{\mathrm{d}f_{\nn}(W(t),x_{i})}{\mathrm{d}W(t)},\frac{\mathrm{d}f_{\nn}(W(t),x_{j})}{\mathrm{d}W(t)}\right\rangle

Then we can show the gradient flow of training regularized neural net satisfies

\displaystyle\frac{\mathrm{d}\|u^{*}-u_{\nn}(t)\|_{2}^{2}}{\mathrm{d}t}=

\displaystyle-2(u^{*}-u_{\nn}(t))^{\top}(H(t)+\lambda I)(u^{*}-u_{\nn}(t))

(13)

\displaystyle+2(u_{\nn}(t)-u^{*})^{\top}(H(t)-H^{\cts})(Y-u^{*})

(14)

where term (
13
) is the primary term characterizing the linear convergence of
u_{\nn}(t)
to
t^{*}
, and term (
14
) is the additive term that can be well controlled if
H(t)
is sufficiently close to
H^{\cts}
. We argue the closeness of
H(t)\approx H^{\cts}
as the consequence of the following two observations:

•

Initialization phase: At the beginning of the training,
H(0)
can be viewed as approximating the neural tangent kernel
H^{\cts}
using finite dimensional random features. Note the size of these random features corresponds to the width of the neural network (scale by the data dimension
d
). Therefore, when the neural network is sufficiently wide, it is equivalent to approximate the neural tangent kernel using sufficient high dimensional feature vectors, which ensures
H(0)
is sufficiently close to
H^{\cts}
.

In the case of leverage score initialization, we further take the regularization into consideration. We use the tool of leverage score to modify the initialization distribution and corresponding network parameter, to give a smaller upper-bound of the width of the nets needed.

•

Training phase: If the net is sufficiently wide, we can observe the over-parametrization phenomenon such that the weight estimate
W(t)
at time
t
will be sufficiently close to its initialization
W(0)
, which implies the dynamic kernel
H(t)
being sufficiently close to
H(0)
. Due to the fact
H(0)\approx H^{\cts}
argued in initialization phase, we have
H(t)\approx H^{\cts}
throughout the algorithm.

Combining both observations, we are able to iteratively show the (nearly) linear convergence property of training the regularized neural net as in following lemma:

Lemma 4.1

(Bounding kernel perturbation, informal)
.

For any accuracy
\Delta\in(0,1/10)
. If the network width
m=\poly(1/\Delta,1/T,1/\epsilon_{\train},n,d,1/\kappa,1/\Lambda_{0},\log(1/\delta))
and
\lambda=O(\frac{1}{\sqrt{m}})
, with probability
1-\delta
, there exist
\epsilon_{W},\penalty\ \epsilon_{H}^{\prime},\penalty\ \epsilon_{K}^{\prime}\in(0,\Delta)
that are independent of
t
, such that the following hold for all
0\leq t\leq T
:

1.

\|w_{r}(0)-w_{r}(t)\|_{2}\leq\epsilon_{W}
,
\forall r\in[m]

2.

\|H(0)-H(t)\|_{2}\leq\epsilon_{H}^{\prime}

3.

\|u_{\nn}(t)-u^{*}\|_{2}^{2}\leq\max\{\epsilon_{\train}^{2},e^{-(\kappa^{2}\Lambda_{0}+\lambda)t/2}\|u_{\nn}(0)-u^{*}\|_{2}^{2}\}

Given arbitrary accuracy
\epsilon\in(0,1)
, if we choose
\epsilon_{\train}=\epsilon
,
T=\widetilde{O}(\frac{1}{\kappa^{2}\Lambda_{0}})
and
m
sufficiently large in Lemma
D.14
, then we have
\|u_{\nn}(t)-u^{*}\|_{2}\leq\epsilon
, indicating the equivalence between training neural network with regularization and neural tangent kernel ridge regression for the training data predictions.

To further argue the equivalence for any given test data
x_{\test}
, we observe the similarity between the gradient flows of neural tangent kernel ridge regression
u_{\ntk,\test}(t)
and regularized neural networks
u_{\nn,\test}(t)
as following:

\displaystyle\frac{\mathrm{d}u_{\ntk,\test}(t)}{\mathrm{d}t}=

\displaystyle\penalty\ \kappa^{2}\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot u_{\ntk,\test}(t).

(15)

\displaystyle\frac{\mathrm{d}u_{\nn,\test}(t)}{\mathrm{d}t}=

\displaystyle\penalty\ \kappa^{2}\mathsf{K}_{t}(x_{\test},X)^{\top}(Y-u_{\nn}(t))-\lambda\cdot u_{\nn,\test}(t).

(16)

By choosing the multiplier
\kappa>0
small enough, we can bound the initial difference between these two predictors. Combining with above similarity between gradient flows, we are able to show
|u_{\nn,\test}(T)-u_{\ntk,\test}(T)|\geq\epsilon/2
for appropriate
T>0
. Finally, note the linear convergence property of the gradient of the kernel ridge regression, we can prove
|u_{\nn,\test}(T)-u^{*}_{\ntk,\test}|\geq\epsilon
.

Using the similar idea, we can also show the equivalence for test data predictors and the case of leverage score initialization. We refer to the Appendix for a detailed proof sketch and rigorous proof.

Remark 4.2
.

Our results can be naturally extended to multi-layer ReLU deep neural networks with all parameters training together. Note the core of the connection between regularized NNs and KRR is to show the similarity between their gradient flows, as in Eq. (
15
), (
16
). The gradient flows consist of two terms: the first term is from normal NN training without regularizer, whose similarity has been shown in broader settings, e.g.
[
DZPS19
,
SY19
,
ADH+19a
,
AZLS19b
,
AZLS19a
]
; the second term is from the
\ell_{2}
regularizer, whose similarity is true for multi-layer ReLU DNNs if the regularization parameter is divided by the number of layers of parameters trained, due to the piecewise linearity of the output with respect to the training parameters.

5
Conclusion

In this paper, we generalize the leverage score sampling theory for kernel approximation. We discuss the interesting application of connecting leverage score sampling and training regularized neural networks. We present two theoretical results: 1) the equivalence between the regularized neural nets and kernel ridge regression problems under the classical random Gaussian initialization for both training and test predictors; 2) the new equivalence under the leverage score initialization. We believe this work can be the starting point of future study on the use of leverage score sampling in neural network training.

\displaystyle\mathsf{K}_{\ntk}(x,z)=\E\left[\left\langle\frac{\partial f_{\nn}(W,x)}{\partial W},\frac{\partial f_{\nn}(W,z)}{\partial W}\right\rangle\right]

where
x,z\in\mathbb{R}^{d}
are any input data, and the expectation is taking over
w_{r}\overset{i.i.d.}{\sim}\mathcal{N}(0,I),\penalty\ r=1,\cdots,m
. Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
, we define
H^{\cts}\in\mathbb{R}^{n\times n}
as the kernel matrix between training data as

\displaystyle[H^{\cts}]_{i,j}=\mathsf{K}_{\ntk}(x_{i},x_{j})\in\mathbb{R}.

We denote the smallest eigenvalue of
H^{\cts}
as
\Lambda_{0}>0
, where we assume
H^{\cts}
is positive definite. Further, given any data
z\in\mathbb{R}^{d}
, we write the kernel between test and training data
\mathsf{K}_{\ntk}(z,X)\in\mathbb{R}^{n}
as

\displaystyle\mathsf{K}_{\ntk}(z,X)=[\mathsf{K}_{\ntk}(z,x_{1}),\cdots,\mathsf{K}_{\ntk}(z,x_{n})]^{\top}\in\mathbb{R}^{n}.

We denote the feature function corresponding to the kernel
\mathsf{K}_{\ntk}
as we defined above as
\Phi:\mathbb{R}^{d}\rightarrow\mathcal{F}
, which satisfies

\displaystyle\langle\Phi(x),\Phi(z)\rangle_{\mathcal{F}}=\mathsf{K}_{\ntk}(x,z),

for any data
x
,
z\in\mathbb{R}^{d}
. And we write
\Phi(X)=[\Phi(x_{1}),\cdots,\Phi(x_{n})]^{\top}
.

Definition B.5

(Neural tangent kernel ridge regression)
.

Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}

\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
\mathsf{K}_{\ntk}
,
H^{\cts}\in\mathbb{R}^{n\times n}
and
\Phi
be the neural tangent kernel and corresponding feature functions defined as in Definition
B.4
. Let
\kappa\in(0,1)
be a small multiplier. Let
\lambda\in(0,1)
be the regularization parameter. Then we consider the following neural tangent kernel ridge regression problem:

\displaystyle\min_{\beta}\frac{1}{2}\|Y-\kappa f_{\ntk}(\beta,X)\|_{2}^{2}+\frac{1}{2}\lambda\|\beta\|_{2}^{2}.

(20)

where
f_{\ntk}(\beta,x)=\Phi(x)^{\top}\beta\in\mathbb{R}
denotes the prediction function is corresponding RKHS and
f_{\ntk}(\beta,X)=[f_{\ntk}(\beta,x_{1}),\cdots,f_{\ntk}(\beta,x_{n})]^{\top}\in\mathbb{R}^{n}
. Consider the gradient flow of solving problem (
20
) with initialization
\beta(0)=0
.
We denote
\beta(t)
as the variable at iteration
t
. We denote

\displaystyle u_{\ntk}(t)=\kappa\Phi(X)\beta(t)\in\mathbb{R}^{n}

(21)

as the training data predictor at iteration
t
. Given any test data
x_{\test}\in\mathbb{R}^{d}
, we denote

\displaystyle u_{\ntk,\test}(t)=\kappa\Phi(x_{\test})^{\top}\beta(t)\in\mathbb{R}

(22)

as the test data predictor at iteration
t
. Note the gradient flow converge the to optimal solution of problem (
20
) due to the strongly convexity of the problem. We denote

\displaystyle\beta^{*}=\lim_{t\to\infty}\beta(t)=\kappa(\kappa^{2}\Phi(X)^{\top}\Phi(X)+\lambda I)^{-1}\Phi(X)^{\top}Y

(23)

and the optimal training data predictor

\displaystyle u^{*}=\lim_{t\to\infty}u_{\ntk}(t)=\kappa\Phi(X)\beta^{*}=\kappa^{2}H^{\cts}(\kappa^{2}H^{\cts}+\lambda I)^{-1}Y\in\mathbb{R}^{n}

(24)

and the optimal test data predictor

\displaystyle u_{\test}^{*}=\lim_{t\to\infty}u_{\ntk,\test}(t)=\kappa\Phi(x_{\test})^{\top}\beta^{*}=\kappa^{2}\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(\kappa^{2}H^{\cts}+\lambda I)^{-1}Y\in\mathbb{R}.

(25)

Definition B.6

(Dynamic kernel)
.

Given
W(t)\in\mathbb{R}^{d\times m}
as the parameters of the neural network at training time

. For any data

\mathsf{K}_{t}(x,z)\in\mathbb{R}

\displaystyle\mathsf{K}_{t}(x,z)=\left\langle\frac{\mathrm{d}f_{\nn}(W(t),x)}{\mathrm{d}W(t)},\frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}W(t)}\right\rangle

Given training data matrix

\displaystyle[H(t)]_{i,j}=\mathsf{K}_{t}(x_{i},x_{j})\in\mathbb{R}.

Further, given a test data

\mathsf{K}_{t}(x_{\test},X)\in\mathbb{R}^{n}

Gradient, gradient flow, and linear convergence

Lemma B.7

(Gradient flow of kernel ridge regression)
.

Given training data matrix
X\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
f_{\ntk}
be defined as in Definition
B.5
. Let
\beta(t)
,
\kappa\in(0,1)
and
u_{\ntk}(t)\in\mathbb{R}^{n}
be defined as in Definition
B.5
. Let
\mathsf{K}_{\ntk}:\mathbb{R}^{d}\times\mathbb{R}^{n\times d}\to\mathbb{R}^{n}
be defined as in Definition
B.4
. Then for any data
z\in\mathbb{R}^{d}
, we have

\displaystyle\frac{\mathrm{d}f_{\ntk}(\beta(t),z)}{\mathrm{d}t}=\kappa\cdot\mathsf{K}_{\ntk}(z,X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot f_{\ntk}(\beta(t),z).

Proof.

Denote
L(t)=\frac{1}{2}\|Y-u_{\ntk}(t)\|_{2}^{2}+\frac{1}{2}\lambda\|\beta(t)\|_{2}^{2}
. By the rule of gradient descent, we have

\displaystyle\frac{\mathrm{d}\beta(t)}{\mathrm{d}t}=-\frac{\mathrm{d}L}{\mathrm{d}\beta}=\kappa\Phi(X)^{\top}(Y-u_{\ntk}(t))-\lambda\beta(t),

where
\Phi
is defined in Definition
B.4
.
Thus we have

\displaystyle\frac{\mathrm{d}f_{\ntk}(\beta(t),z)}{\mathrm{d}t}=

\displaystyle\penalty\ \frac{\mathrm{d}f_{\ntk}(\beta(t),z)}{\mathrm{d}\beta(t)}\frac{\mathrm{d}\beta(t)}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ \Phi(z)^{\top}(\kappa\Phi(X)^{\top}(Y-u_{\ntk}(t))-\lambda\beta(t))

\displaystyle=

\displaystyle\penalty\ \kappa\mathsf{K}_{\ntk}(z,X)^{\top}(Y-u_{\ntk}(t))-\lambda\Phi(z)^{\top}\beta(t)

\displaystyle=

\displaystyle\penalty\ \kappa\mathsf{K}_{\ntk}(z,X)^{\top}(Y-u_{\ntk}(t))-\lambda f_{\ntk}(\beta(t),z),

where the first step is due to chain rule, the second step follows from the fact
\mathrm{d}f_{\ntk}(\beta,z)/\mathrm{d}\beta=\Phi(z)
, the third step is due to the definition of the kernel
\mathsf{K}_{\ntk}(z,X)=\Phi(X)\Phi(z)\in\mathbb{R}^{n}
, and the last step is due to the definition of
f_{\ntk}(\beta(t),z)\in\mathbb{R}
.
∎

Corollary B.8

(Gradient of prediction of kernel ridge regression)
.

Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Given a test data
x_{\test}\in\mathbb{R}^{d}
. Let
f_{\ntk}
be defined as in Definition
B.5
. Let
\beta(t)
,
\kappa\in(0,1)
and
u_{\ntk}(t)\in\mathbb{R}^{n}
be defined as in Definition
B.5
. Let
\mathsf{K}_{\ntk}:\mathbb{R}^{d}\times\mathbb{R}^{n\times d}\rightarrow\mathbb{R}^{n},\penalty\ H^{\cts}\in\mathbb{R}^{n\times n}
be defined as in Definition
B.4
. Then we have

\displaystyle\frac{\mathrm{d}u_{\ntk}(t)}{\mathrm{d}t}

\displaystyle=\kappa^{2}H^{\cts}(Y-u_{\ntk}(t))-\lambda\cdot u_{\ntk}(t)

\displaystyle\frac{\mathrm{d}u_{\ntk,\test}(t)}{\mathrm{d}t}

\displaystyle=\kappa^{2}\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot u_{\ntk,\test}(t).

Proof.

Plugging in
z=x_{i}\in\mathbb{R}^{d}
in Lemma
B.7
, we have

\displaystyle\frac{\mathrm{d}f_{\ntk}(\beta(t),x_{i})}{\mathrm{d}t}=\kappa\mathsf{K}_{\ntk}(x_{i},X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot f_{\ntk}(\beta(t),x_{i}).

Note
[u_{\ntk}(t)]_{i}=\kappa f_{\ntk}(\beta(t),x_{i})
and
[H^{\cts}]_{:,i}=\mathsf{K}_{\ntk}(x_{i},X)
, so writing all the data in a compact form, we have

\displaystyle\frac{\mathrm{d}u_{\ntk}(t)}{\mathrm{d}t}=\kappa^{2}H^{\cts}(Y-u_{\ntk}(t))-\lambda\cdot u_{\ntk}(t).

Plugging in data
z=x_{\test}\in\mathbb{R}^{d}
in Lemma
B.7
, we have

\displaystyle\frac{\mathrm{d}f_{\ntk}(\beta(t),x_{\test})}{\mathrm{d}t}=\kappa\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot f_{\ntk}(\beta(t),x_{\test}).

Note by definition,
u_{\ntk,\test}(t)=\kappa f_{\ntk}(\beta(t),x_{\test})\in\mathbb{R}
, so we have

\displaystyle\frac{\mathrm{d}u_{\ntk,\test}(t)}{\mathrm{d}t}=\kappa^{2}\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(Y-u_{\ntk}(t))-\lambda\cdot u_{\ntk,\test}(t).

∎

Lemma B.9

(Linear convergence of kernel ridge regression)
.

Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
\kappa\in(0,1)
and
u_{\ntk}(t)\in\mathbb{R}^{n}
be defined as in Definition
B.5
. Let
u^{*}\in\mathbb{R}^{n}
be defined in Definition
B.5
. Let
\Lambda_{0}>0
be defined as in Definition
B.4
. Let
\lambda>0
be the regularization parameter. Then we have

\displaystyle\frac{\mathrm{d}\|u_{\ntk}(t)-u^{*}\|_{2}^{2}}{\mathrm{d}t}\leq-2(\kappa^{2}\Lambda_{0}+\lambda)\|u_{\ntk}(t)-u^{*}\|_{2}^{2}.

Further, we have

\displaystyle\|u_{\ntk}(t)-u^{*}\|_{2}\leq e^{-(\kappa^{2}\Lambda_{0}+\lambda)t}\|u_{\ntk}(0)-u^{*}\|_{2}.

Proof.

Let
H^{\cts}\in\mathbb{R}^{n\times n}
be defined as in Definition
B.4
. Then

\displaystyle\kappa^{2}H^{\cts}(Y-u^{*})=

\displaystyle\penalty\ \kappa^{2}H^{\cts}(Y-\kappa^{2}H^{\cts}(\kappa^{2}H^{\cts}+\lambda I_{n})^{-1}Y)

\displaystyle=

\displaystyle\penalty\ \kappa^{2}H^{\cts}(I_{n}-\kappa^{2}H^{\cts}(\kappa^{2}H^{\cts}+\lambda I)^{-1})Y

\displaystyle=

\displaystyle\penalty\ \kappa^{2}H^{\cts}(\kappa^{2}H^{\cts}+\lambda I_{n}-\kappa^{2}H^{\cts})(\kappa^{2}H^{\cts}+\lambda I_{n})^{-1}Y

\displaystyle=

\displaystyle\penalty\ \kappa^{2}\lambda H^{\cts}(\kappa^{2}H^{\cts}+\lambda I_{n})^{-1}Y

\displaystyle=

\displaystyle\penalty\ \lambda u^{*},

(26)

where the first step follows the definition of
u^{*}\in\mathbb{R}^{n}
, the second to fourth step simplify the formula, and the last step use the definition of
u^{*}\in\mathbb{R}^{n}
again.
So we have

\displaystyle\frac{\mathrm{d}\|u_{\ntk}(t)-u^{*}\|_{2}^{2}}{\mathrm{d}t}=

\displaystyle\penalty\ 2(u_{\ntk}(t)-u^{*})^{\top}\frac{\mathrm{d}u_{\ntk}(t)}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(u_{\ntk}(t)-u^{*})^{\top}H^{\cts}(u_{\ntk}(t)-Y)-2\lambda(u_{\ntk}(t)-u^{*})^{\top}u_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(u_{\ntk}(t)-u^{*})^{\top}H^{\cts}(u_{\ntk}(t)-u^{*})+2\kappa^{2}(u_{\ntk}(t)-u^{*})^{\top}H^{\cts}(Y-u^{*})

\displaystyle\penalty\ -2\lambda(u_{\ntk}(t)-u^{*})^{\top}u_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(u_{\ntk}(t)-u^{*})^{\top}H^{\cts}(u_{\ntk}(t)-u^{*})+2\lambda(u_{\ntk}(t)-u^{*})^{\top}u^{*}

\displaystyle\penalty\ -2\lambda(u_{\ntk}(t)-u^{*})^{\top}u_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2(u_{\ntk}(t)-u^{*})^{\top}(\kappa^{2}H^{\cts}+\lambda I)(u_{\ntk}(t)-u^{*})

\displaystyle\leq

\displaystyle\penalty\ -2(\kappa^{2}\Lambda_{0}+\lambda)\|u_{\ntk}(t)-u^{*}\|_{2}^{2},

(27)

where the first step follows the chain rule, the second step follows Corollary
B.8
, the third step uses basic linear algebra, the fourth step follows Eq. (
B.3
), the fifth step simplifies the expression, and the last step follows the definition of
\Lambda_{0}
.
Further, since

\displaystyle\penalty\ \frac{\mathrm{d}(e^{2(\kappa^{2}\Lambda_{0}+\lambda)t}\|u_{\ntk}(t)-u^{*}\|_{2}^{2})}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ 2(\kappa^{2}\Lambda_{0}+\lambda)e^{2(\kappa^{2}\Lambda_{0}+\lambda)t}\|u_{\ntk}(t)-u^{*}\|_{2}^{2}+e^{2(\kappa^{2}\Lambda_{0}+\lambda)t}\cdot\frac{\mathrm{d}\|u_{\ntk}(t)-u^{*}\|_{2}^{2}}{\mathrm{d}t}

\displaystyle\leq

\displaystyle\penalty\ 0,

where the first step calculates the gradient, and the second step follows from Eq. (
B.3
). Thus,
e^{2(\kappa^{2}\Lambda_{0}+\lambda)t}\|u_{\ntk}(t)-u^{*}\|_{2}^{2}
is non-increasing, which implies

\displaystyle\|u_{\ntk}(t)-u^{*}\|_{2}\leq e^{-(\kappa^{2}\Lambda_{0}+\lambda)t}\|u_{\ntk}(0)-u^{*}\|_{2}.

∎

Lemma B.10

(Gradient flow of neural network training)
.

Given training data matrix
X\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
f_{\nn}:\mathbb{R}^{d\times m}\times\mathbb{R}^{d}\rightarrow\mathbb{R}

\displaystyle\frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}t}=\kappa\mathsf{K}_{t}(z,X)^{\top}(Y-u_{\nn}(t))-\lambda\cdot f_{\nn}(W(t),z).

Proof.

Denote

. By the rule of gradient descent, we have

\displaystyle\frac{\mathrm{d}w_{r}}{\mathrm{d}t}=-\frac{\partial L}{\partial w_{r}}=(\frac{\partial u_{\nn}}{\partial w_{r}})^{\top}(Y-u_{\nn})-\lambda w_{r}.

(28)

Also note for ReLU activation

\displaystyle\penalty\ \sum_{r=1}^{m}\Big(\frac{1}{\sqrt{m}}a_{r}z\sigma^{\prime}(w_{r}(t)^{\top}z)\Big)^{\top}(\lambda w_{r}(t))

\displaystyle=

\displaystyle\penalty\ \frac{\lambda}{\sqrt{m}}\sum_{r=1}^{m}a_{r}w_{r}(t)^{\top}z\sigma^{\prime}(w_{r}(t)^{\top}z)

\displaystyle=

\displaystyle\penalty\ \frac{\lambda}{\sqrt{m}}\sum_{r=1}^{m}a_{r}\sigma(w_{t}(t)^{\top}z)

\displaystyle=

\displaystyle\penalty\ \lambda f_{\nn}(W(t),z),

(29)

where the first step calculates the derivatives, the second step follows basic linear algebra, the third step follows the property of ReLU activation:
\sigma(l)=l\sigma^{\prime}(l)
, and the last step follows from the definition of
f_{\nn}
.
Thus, we have

\displaystyle\penalty\ \frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ \Big\langle\frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}W(t)},\frac{\mathrm{d}W(t)}{\mathrm{d}t}\Big\rangle

\displaystyle\penalty\ \sum_{j=1}^{n}(y_{j}-\kappa f_{\nn}(W(t),x_{j}))\Big\langle\frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}W(t)},\frac{\mathrm{d}\kappa f_{\nn}(W(t),x_{j})}{\mathrm{d}W(t)}\Big\rangle-\Big\langle\frac{\mathrm{d}f_{\nn}(W(t),z)}{\mathrm{d}W(t)},\lambda W(t)\Big\rangle

\displaystyle=

\displaystyle\penalty\ \kappa\sum_{j=1}^{n}(y_{j}-\kappa f_{\nn}(W(t),x_{j}))\mathsf{K}_{t}(z,x_{j})-\lambda\cdot f_{\nn}(W(t),z)

\displaystyle=

\displaystyle\penalty\ \kappa\mathsf{K}_{t}(z,X)^{\top}(Y-u_{\nn}(t))-\lambda\cdot f_{\nn}(W(t),z),

where the first step follows from chain rule, the second step follows from Eq. (
28
), the third step follows from the definition of
\mathsf{K}_{t}
and Eq. (
B.3
), and the last step rewrites the formula in a compact form.
∎

B.4
Proof sketch

Our goal is to show with appropriate width of the neural network and appropriate training iterations, the neural network predictor will be sufficiently close to the neural tangent kernel ridge regression predictor for any test data. We follow similar proof framework of Theorem 3.2 in
[
ADH+19a
]
. Given any accuracy
\epsilon\in(0,1)
, we divide this proof into following steps:

1.

Firstly, according to the linear convergence property of kernel ridge regression shown in Lemma
B.9
, we can choose sufficiently large training iterations
T>0
, so that
|u_{\test}^{*}-u_{\ntk,\test}(T)|\leq\epsilon/2
, as shown in Lemma
B.13
.

2.

Once fix training iteration
T
as in step 1, we bound
|u_{\nn,\test}(T)-u_{\ntk,\test}(T)|\leq\epsilon/2
by showing the following:

(a)

Due to the similarity of the the gradient flow of neural network training and neural tangent kernel ridge regression, we can reduce the task of bounding the prediction perturbation at time
T
, i.e.,
|u_{\nn,\test}(T)-u_{\ntk,\test}(T)|
, back to bounding

i.

the initialization perturbation
|u_{\nn,\test}(0)-u_{\ntk,\test}(0)|
and

ii.

kernel perturbation
\|H(t)-H^{\cts}\|
,
\|\mathsf{K}_{\ntk}(x_{\test},X)-\mathsf{K}_{t}(x_{\test},X)\|_{2}
, as shown in Lemma
B.14
.

(b)

According to concentration results, we can bound the initialization perturbation
|u_{\nn,\test}(0)-u_{\ntk,\test}(0)|
small enough by choosing sufficiently small
\kappa\in(0,1)
, as shown in Lemma
B.20
.

(c)

We characterize the over-parametrization property of the neural network by inductively show that we can bound kernel perturbation
\|H(t)-H^{\cts}\|
,
\|\mathsf{K}_{\ntk}(x_{\test},X)-\mathsf{K}_{t}(x_{\test},X)\|_{2}
small enough by choosing network width
m>0
large enough, as shown in Lemma
B.21
.

3.

Lastly, we combine the results of step 1 and 2 using triangle inequality, to show the equivalence between training neural network with regularization and neural tangent kernel ridge regression, i.e.,
|u_{\nn,\test}(T)-u_{\test}^{*}|\leq\epsilon
, as shown in Theorem
B.28
.

D.3
Leverage score sampling, gradient flow, and linear convergence

Recall in the main body we connect the leverage score sampling theory and convergence theory of the neural network training by observing

\displaystyle\mathsf{K}_{\ntk}(x,z)

\displaystyle=\E\left[\left\langle\frac{\partial f_{\nn}(W,x)}{\partial W},\frac{\partial f_{\nn}(W,z)}{\partial W}\right\rangle\right]

\displaystyle=\E_{w\sim p}[\phi(x,w)^{\top}\phi(z,w)]

where
\phi(x,w)=x\sigma^{\prime}(w^{\top}x)\in\mathbb{R}^{d}
and
p(\cdot)
denotes the probability density function of standard Gaussian distribution
\mathcal{N}(0,I_{d})
.
Thus, given regularization parameter
\lambda>0
, we can define the ridge leverage function with respect to
H^{\cts}
defined in Definition
B.4
as

\displaystyle q_{\lambda}(w)=p(w)\Tr[\Phi(w)^{\top}(H^{\cts}+\lambda I_{n})^{-1}\Phi(w)]

and corresponding probability density function

\displaystyle q(w)=\frac{q_{\lambda}(w)}{s_{\lambda}(H^{\cts})}

(72)

where
\Phi(w)=[\phi(x_{1},w)^{\top},\cdots,\phi(x_{n},w)^{\top}]^{\top}\in\mathbb{R}^{n\times d_{2}}
.

Lemma D.5

(property of leverage score sampling distribution)
.

Let
p(\cdot)
denotes the standard Gaussian distribution
\mathcal{N}(0,I_{d})
. Let
q(\cdot)
be defined as in (
72
). Assume
\Tr[\Phi(w)\Phi(w)^{\top}]=O(n)
and
\lambda\leq\Lambda_{0}/2
. Then for all
w\in\mathbb{R}^{d}
we have

\displaystyle c_{1}p(w)\leq q(w)\leq c_{2}p(w)

where
c_{1}=O(\frac{1}{n})
and
c_{2}=O(\frac{1}{\Lambda_{0}})
.

Proof.

Note by assumption
s_{\lambda}(H^{\cts})=\Tr[(H^{\cts}+\lambda I_{n})^{-1}H^{\cts}]=O(n)
. Further, note for any
w\in\mathbb{R}^{d}
,

\displaystyle q_{\lambda}(w)=

\displaystyle\penalty\ p(w)\Tr[\Phi(w)^{\top}(H^{\cts}+\lambda I_{n})^{-1}\Phi(w)]

\displaystyle\leq

\displaystyle\penalty\ p(w)\Tr[\Phi(w)^{\top}\Phi(w)]\cdot\frac{1}{\Lambda_{0}+\lambda}

\displaystyle=

\displaystyle\penalty\ p(w)\Tr[\sum_{i=1}^{n}\phi(x_{i},w)\phi(x_{i},w)^{\top}]\cdot\frac{1}{\Lambda_{0}+\lambda}

\displaystyle=

\displaystyle\penalty\ p(w)\sum_{i=1}^{n}\Tr[\phi(x_{i},w)\phi(x_{i},w)^{\top}]\cdot\frac{1}{\Lambda_{0}+\lambda}

\displaystyle=

\displaystyle\penalty\ p(w)\sum_{i=1}^{n}\Tr[\phi(x_{i},w)^{\top}\phi(x_{i},w)]\cdot\frac{1}{\Lambda_{0}+\lambda}

\displaystyle=

\displaystyle\penalty\ p(w)\sum_{i=1}^{n}\|x_{i}\|_{2}^{2}\sigma^{\prime}(w^{\top}x_{i})^{2}\cdot\frac{1}{\Lambda_{0}+\lambda}

\displaystyle\leq

\displaystyle\penalty\ p(w)\frac{n}{\Lambda_{0}+\lambda}

where the first step follows from
H^{\cts}\succeq\Lambda_{0}I_{n}
, the second step follows from the definition of
\Phi
, the third step follows from the linearity of trace operator, the fourth step follows from
\Tr(AB)=\Tr(BA)
, the fifth step follows from the definition of
\phi
, and the last step follows from
\|x_{i}\|_{2}=1
and
\sigma^{\prime}(\cdot)\leq 1
.

Thus, combining above facts, we have

\displaystyle q(w)=\frac{q_{\lambda}(w)}{s_{\lambda}(H^{\cts})}\leq p(w)\frac{n}{(\Lambda_{0}+\lambda)s_{\lambda}(H^{\cts})}=c_{2}p(w)

hold for all
w\in\mathbb{R}^{d}
, where
c_{2}=O(\frac{1}{\Lambda_{0}})
.

Similarly, note
H^{\cts}\preceq nI_{n}
, we have

\displaystyle q_{\lambda}(w)\geq p(w)\Tr[\Phi(w)^{\top}\Phi(w)]\cdot\frac{1}{n+\lambda}

which implies

\displaystyle q(w)=\frac{q_{\lambda}(w)}{s_{\lambda}(H^{\cts})}\geq p(w)\frac{\Tr[\Phi(w)^{\top}\Phi(w)]}{(n+\lambda)s_{\lambda}(H^{\cts})}=c_{1}p(w)

hold for all
w\in\mathbb{R}^{d}
, where
c_{1}=O(\frac{1}{n})
. Combining above results, we complete the proof.
∎

Lemma D.6

(leverage score sampling)
.

Let
\overline{H}(t)
,
H^{\cts}
be the kernel defined as in Definition
D.3
and Definition
B.4
. Let
\Lambda_{0}>0
be defined as in Definition
B.4
. Let
p(\cdot)
denotes the probability density function for Gaussian
\mathcal{N}(0,I_{d})
. Let
q(\cdot)
denotes the leverage sampling distribution with respect to
p(\cdot)
,
\overline{H}(0)
and
\lambda
defined in Definition
C.6
. Let
\Delta\in(0,1/4)
. Then we have

\displaystyle\E_{q}[\overline{H}(0)]=H^{\cts}.

By choosing
m\geq\widetilde{O}(\Delta^{-2}s_{\lambda}(H^{\cts})
, with probability at least
1-\delta
,

\displaystyle(1-\Delta)(H^{\cts}+\lambda I)\preceq\overline{H}(0)+\lambda I\preceq(1+\Delta)(H^{\cts}+\lambda I)

Further, if
\lambda\leq\Lambda_{0}
, we have with probability at least
1-\delta
,

\displaystyle\overline{H}(0)\succeq\frac{\Lambda_{0}}{2}I_{n}.

Here
\widetilde{O}(\cdot)
hides
\poly\log(s_{\lambda}(\overline{H}(0))/\delta)
.

Proof.

Note for any
i,j\in[n]
,

\displaystyle[\E_{q}[\overline{H}(0)]]_{i,j}=

\displaystyle\penalty\ \E_{q}[\overline{\Phi}(x_{i})^{\top}\overline{\Phi}(x_{j})]

\displaystyle=

\displaystyle\penalty\ \E_{q}[\langle\frac{\mathrm{d}\overline{f}_{\nn}(W(0),x_{i})}{\mathrm{d}W},\frac{\mathrm{d}\overline{f}_{\nn}(W(0),x_{j})}{\mathrm{d}W}\rangle]

\displaystyle=

\displaystyle\penalty\ \E_{p}[\langle\frac{\mathrm{d}{f}_{\nn}(W(0),x_{i})}{\mathrm{d}W},\frac{\mathrm{d}{f}_{\nn}(W(0),x_{j})}{\mathrm{d}W}\rangle]

\displaystyle=

\displaystyle\penalty\ [H^{\cts}]_{i,j}

where the first step follows from the definition of
\overline{H}(0)
, the second step follows the definition of
\overline{\Phi}
, the third step calculates the expectation, and the last step follows the definition of
H^{\cts}
.

Also, by applying Theorem
C.7
directly, we have with probability at least
1-\delta
,

\displaystyle(1-\Delta)(H^{\cts}+\lambda I)\preceq\overline{H}(0)+\lambda I\preceq(1+\Delta)(H^{\cts}+\lambda I)

if
m\geq\widetilde{O}(\Delta^{-2}s_{\lambda}(\overline{H}(0))
.

Since

\overline{H}(0)+\lambda I\succeq(1-\Delta)(H^{\cts}+\lambda I)\succeq(1-\Delta)(\Lambda_{0}+\lambda)I_{n},

we have

\overline{H}(0)\succeq[(1-\Delta)(\Lambda_{0}+\lambda)-\lambda]I_{n}\succeq\frac{\Lambda_{0}}{2}I_{n},

which completes the proof.
∎

Lemma D.7

(Gradient flow of kernel ridge regression, parallel to Lemma
B.7
)
.

Given training data matrix
X\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
\overline{f}_{\ntk}
,
\beta(t)\in\mathbb{R}^{md}
,
\kappa\in(0,1)
and
\overline{u}_{\ntk}(t)\in\mathbb{R}^{n}
be defined as in Definition
D.4
. Let
\overline{\Phi},\penalty\ \overline{\mathsf{K}}_{t}
be defined as in Definition
D.3
. Then for any data
z\in\mathbb{R}^{d}
, we have

\displaystyle\frac{\mathrm{d}\overline{f}_{\ntk}(\beta(t),z)}{\mathrm{d}t}=\kappa\cdot\overline{\mathsf{K}}_{0}(z,X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\cdot\overline{f}_{\ntk}(\beta(t),z).

Proof.

Denote
L(t)=\frac{1}{2}\|Y-\overline{u}_{\ntk}(t)\|_{2}^{2}+\frac{1}{2}\lambda\|\beta(t)\|_{2}^{2}
. By the rule of gradient descent, we have

\displaystyle\frac{\mathrm{d}\beta(t)}{\mathrm{d}t}=-\frac{\mathrm{d}L}{\mathrm{d}\beta}=\kappa\overline{\Phi}(X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\beta(t).

Thus we have

\displaystyle\frac{\mathrm{d}\overline{f}_{\ntk}(\beta(t),z)}{\mathrm{d}t}=

\displaystyle\penalty\ \frac{\mathrm{d}\overline{f}_{\ntk}(\beta(t),z)}{\mathrm{d}\beta(t)}\frac{\mathrm{d}\beta(t)}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ \overline{\Phi}(z)^{\top}(\kappa\overline{\Phi}(X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\beta(t))

\displaystyle=

\displaystyle\penalty\ \kappa\overline{\mathsf{K}}_{0}(z,X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\overline{\Phi}(z)^{\top}\beta(t)

\displaystyle=

\displaystyle\penalty\ \kappa\overline{\mathsf{K}}_{0}(z,X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\overline{f}_{\ntk}(\beta(t),z),

where the first step is due to chain rule, the second step follows from the fact
\mathrm{d}\overline{f}_{\ntk}(\beta,z)/\mathrm{d}\beta=\overline{\Phi}(z)
, the third step is due to the definition of the kernel
\overline{\mathsf{K}}_{0}(z,X)=\overline{\Phi}(X)\overline{\Phi}(z)\in\mathbb{R}^{n}
, and the last step is due to the definition of
\overline{f}_{\ntk}(\beta(t),z)\in\mathbb{R}
.
∎

Corollary D.8

)
.

Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}

. Given a test data

\overline{f}_{\ntk}
,
\beta(t)\in\mathbb{R}^{md}
,

\overline{u}_{\ntk}(t)\in\mathbb{R}^{n}

be defined as in Definition
D.4
. Let
\overline{\mathsf{K}}_{t},\penalty\ \overline{H}(0)\in\mathbb{R}^{n\times n}
be defined as in Definition

. Then we have

\displaystyle\frac{\mathrm{d}\overline{u}_{\ntk}(t)}{\mathrm{d}t}

\displaystyle=\kappa^{2}\overline{H}(0)(Y-\overline{u}_{\ntk}(t))-\lambda\cdot\overline{u}_{\ntk}(t)

\displaystyle\frac{\mathrm{d}\overline{u}_{\ntk,\test}(t)}{\mathrm{d}t}

and
[\overline{H}(0)]_{:,i}=\overline{\mathsf{K}}_{0}(x_{i},X)
, so writing all the data in a compact form, we have

\displaystyle\frac{\mathrm{d}\overline{u}_{\ntk}(t)}{\mathrm{d}t}=\kappa^{2}\overline{H}(0)(Y-\overline{u}_{\ntk}(t))-\lambda\cdot\overline{u}_{\ntk}(t).

Note by definition,
\overline{u}_{\ntk,\test}(t)=\kappa\overline{f}_{\ntk}(\beta(t),x_{\test})\in\mathbb{R}
, so we have

\displaystyle\frac{\mathrm{d}\overline{u}_{\ntk,\test}(t)}{\mathrm{d}t}=\kappa^{2}\overline{\mathsf{K}}_{0}(x_{\test},X)^{\top}(Y-\overline{u}_{\ntk}(t))-\lambda\cdot\overline{u}_{\ntk,\test}(t).

∎

Lemma D.9

(Linear convergence of kernel ridge regression, parallel to Lemma
B.9
)
.

Given training data matrix
X=[x_{1},\cdots,x_{n}]^{\top}\in\mathbb{R}^{n\times d}
and corresponding label vector
Y\in\mathbb{R}^{n}
. Let
\kappa\in(0,1)
,
\overline{u}_{\ntk}(t)\in\mathbb{R}^{n}
and
\overline{u}^{*}\in\mathbb{R}^{n}
be defined as in Definition
D.4
. Let
\Lambda_{0}>0
be defined as in Definition
B.4
. Let
\lambda>0
be the regularization parameter. Then we have

\displaystyle\frac{\mathrm{d}\|\overline{u}_{\ntk}(t)-\overline{u}^{*}\|_{2}^{2}}{\mathrm{d}t}\leq-(\kappa^{2}\Lambda_{0}+\lambda)\|\overline{u}_{\ntk}(t)-\overline{u}^{*}\|_{2}^{2}.

Further, we have

\displaystyle\|u_{\ntk}(t)-u^{*}\|_{2}\leq e^{-(\kappa^{2}\Lambda_{0}+\lambda)t/2}\|u_{\ntk}(0)-u^{*}\|_{2}.

Proof.

Let
\overline{H}(0)\in\mathbb{R}^{n\times n}
be defined as in Definition
D.3
. Then

\displaystyle\kappa^{2}\overline{H}(0)(Y-\overline{u}^{*})=

\displaystyle\penalty\ \kappa^{2}\overline{H}(0)(Y-\kappa^{2}\overline{H}(0)(\kappa^{2}\overline{H}(0)+\lambda I_{n})^{-1}Y)

\displaystyle=

\displaystyle\penalty\ \kappa^{2}\overline{H}(0))(I_{n}-\kappa^{2}\overline{H}(0))(\kappa^{2}\overline{H}(0)+\lambda I)^{-1})Y

\displaystyle=

\displaystyle\penalty\ \kappa^{2}\overline{H}(0)(\kappa^{2}\overline{H}(0)+\lambda I_{n}-\kappa^{2}\overline{H}(0))(\kappa^{2}\overline{H}(0)+\lambda I_{n})^{-1}Y

\displaystyle=

\displaystyle\penalty\ \kappa^{2}\lambda\overline{H}(0)(\kappa^{2}\overline{H}(0)+\lambda I_{n})^{-1}Y

\displaystyle=

\displaystyle\penalty\ \lambda\overline{u}^{*},

(73)

where the first step follows the definition of
\overline{u}^{*}\in\mathbb{R}^{n}
, the second to fourth step simplify the formula, and the last step use the definition of
\overline{u}^{*}\in\mathbb{R}^{n}
again.
So we have

\displaystyle\frac{\mathrm{d}\|\overline{u}_{\ntk}(t)-\overline{u}^{*}\|_{2}^{2}}{\mathrm{d}t}=

\displaystyle\penalty\ 2(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\frac{\mathrm{d}\overline{u}_{\ntk}(t)}{\mathrm{d}t}

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{H}(0)(\overline{u}_{\ntk}(t)-Y)-2\lambda(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{u}_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{H}(0)(\overline{u}_{\ntk}(t)-\overline{u}^{*})+2\kappa^{2}(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{H}(0))(Y-\overline{u}^{*})

\displaystyle\penalty\ -2\lambda(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{u}_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2\kappa^{2}(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{H}(0)(\overline{u}_{\ntk}(t)-\overline{u}^{*})+2\lambda(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{u}^{*}

\displaystyle\penalty\ -2\lambda(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}\overline{u}_{\ntk}(t)

\displaystyle=

\displaystyle\penalty\ -2(\overline{u}_{\ntk}(t)-\overline{u}^{*})^{\top}(\kappa^{2}\overline{H}(0)+\lambda I)(\overline{u}_{\ntk}(t)-\overline{u}^{*})

D.4
Proof sketch

We introduce a new kernel ridge regression problem with respect to
\overline{H}(0)
to decouple the prediction perturbation resulted from initialization phase and training phase. Specifically, given any accuracy
\epsilon\in(0,1)
, we divide this proof into following steps:

1.

Firstly, we bound the prediction perturbation resulted from initialization phase
\|u^{*}-\overline{u}^{*}\|_{2}\leq\epsilon/2
by applying the leverage score sampling theory, as shown in Lemma
D.13
.

2.

Then we use the similar idea as section B to bound the prediction perturbation resulted from training phase
\|\overline{u}_{\nn}(T)-\overline{u}^{*}\|_{2}\leq\epsilon/2
by showing the over-parametrization and convergence property of neural network inductively, as shown in Lemma
D.14
and Corollary
D.20
.

3.

Lastly, we combine the results of step 1 and 2 using triangle inequality to show
\|\overline{u}_{\nn}(T)-u^{*}\|_{2}\leq\epsilon
, as shown in Theorem
D.21
.

Remark D.22
.

Despite our given upper-bound of network width under leverage score sampling is asymptotically the same as the Gaussian initialization, we point out the potential benefits of introducing leverage score sampling to training regularized neural networks.

Note the bound for the width consists of two parts: 1) initialization and 2) training. Part 1, requires the width to be large enough, so that the initialized dynamic kernels
H(0)
and
\overline{H}(0)
are close enough to NTK by concentration, see Lem
B.20
and
D.13
. Part 2, requires the width to be large enough, so that the dynamic kernels
H(t)
and
\overline{H}(t)
are close enough to the NTK during the training by the over-parameterization property, see Lem
B.21
and
D.14
. Leverage score sampling optimizes the bound for part 1 while keeping the bound for part 2 the same. The current state-of-art analysis gives a tighter bound in part 2, so the final bound for width is the same for both cases. If analysis for part 2 can be improved and part 1 dominates, then initializing using leverage score will be beneficial in terms of the width needed.

Appendix E
Extension to other neural network models

In previous sections, we discuss a simple neural network model: 2-layer ReLu neural network with first layer trained. We remark that our results can be naturally extended to multi-layer ReLU deep neural networks with all parameters training together.

Note the core of the connection between regularized NNs and KRR is to show the similarity between their gradient flows, as shown in Corollary
B.8
and Corollary
B.11
: their gradient flow are given by

\displaystyle\frac{\mathrm{d}u_{\ntk,\test}(t)}{\mathrm{d}t}

\displaystyle=-\kappa^{2}\mathsf{K}_{\ntk}(x_{\test},X)^{\top}(u_{\ntk}(t)-Y)-\lambda u_{\ntk,\test}(t)

\displaystyle\frac{\mathrm{d}u_{\nn,\test}(t)}{\mathrm{d}t}

\displaystyle=-\kappa^{2}\mathsf{K}_{t}(x_{\test},X)^{\top}(u_{\nn}(t)-Y)-\lambda u_{\nn,\test}(t)

Note these gradient flows consist of two terms: the first term
-\kappa^{2}\mathsf{K}(x_{\test},X)^{\top}(u(t)-Y)
comes from the normal neural network training without
\ell_{2}
regularization, the second term
-\lambda u_{\test}(t)
comes from the regularizer and can be directly derived using the piece-wise linearity property of the 2-layer ReLu NN (in this case, with respect to the parameters in the first layer).

Now consider the case of training multi-layer ReLu neural network with regularization. We claim above similarity between the gradient flows of NN and KRR still holds as long as we scale up the network width by the number of layers trained: as 1) the similarity of the first term
-\kappa^{2}\mathsf{K}(x_{\test},X)^{\top}(u(t)-Y)
has already been shown in previous literature
[
ADH+19a
,
AZLS19a
]
, and 2) the similarity of the second term
-\lambda u_{\test}(t)
comes from the piece-wise linearity property of deep ReLu neural network with respect to all training parameters. In the common case where we train all the parameters together, the equivalence still holds as long as we scale up the network width by the number of layers, as shown in the following theorem:

Theorem E.1
.

Consider training a
L
-layer ReLU neural network with
\ell_{2}
regularization. Let
u_{\nn,\test}(t)
denote the neural network predictor at time
t
, and
u_{\test}^{*}
denote the kernel ridge regression predictor. Then Given any accuracy
\epsilon\in(0,1/10)
and failure probability
\delta\in(0,1/10)
.
Let multiplier
\kappa=\poly(\epsilon,\Lambda_{0},1/n,1/L)
, number of iterations
T=\poly(1/\epsilon,1/\Lambda_{0},n,L)
, network width
m\geq\poly(n,d,1/\epsilon,1/\Lambda_{0},L)
and regularization parameter
\lambda\leq\poly(1/n,1/d,\epsilon,\Lambda_{0},1/L)
. Then with probability at least
1-\delta
over random initialization, we have

\displaystyle\|u_{\nn,\test}(T)-u_{\test}^{*}\|_{2}\leq\epsilon.

Here we omit
\poly\log(n/(\epsilon\delta\Lambda_{0}))
factors.

The results under leverage score sampling can be argued in the same way.

We also remark that it is possible to extend our results further to the model of convolutional neural network (CNN) by making use the convolutional neural tangent kernel (CNTK) discussed in
[
ADH+19a
]
, and to the case using stochastic gradient descent in training rather than gradient descent. However, these discussion require more detailed proof and is out of the scope of this work.
