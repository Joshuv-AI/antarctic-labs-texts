New subclass of the class of close-to-convex harmonic mappings defined by a third-order differential inequality
Serkan Çakmak, Elif Yaşar, Sibel Yalçın

Abstract
In this paper, we introduce a new subclass of harmonic functions 𝔣 = 𝔰 + 𝔱 ¯ \mathfrak{f}=\mathfrak{s}+\overline{\mathfrak{t}} in the open unit disk 𝒰 = { z ∈ ℂ : | z | < 1 } \mathcal{U}=\left\{z\in\mathbb{C}:\left|z\right|<1\right\} satisfying Re ​ [ γ ​ 𝔰 ′ ​ ( z ) + δ ​ z ​ 𝔰 ′′ ​ ( z ) + ( δ − γ 2 ) ​ z 2 ​ 𝔰 ′′′ ​ ( z ) − λ ] > | γ ​ 𝔱 ′ ​ ( z ) + δ ​ z ​ 𝔱 ′′ ​ ( z ) + ( δ − γ 2 ) ​ z 2 ​ 𝔱 ′′′ ​ ( z ) | , {\text{Re}}\left[\gamma\mathfrak{s}^{\prime}(z)+\delta z\mathfrak{s}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{s}^{\prime\prime\prime}\left(z\right)-\lambda\right]>\left|\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right|, where 0 ≤ λ < γ ≤ δ , z ∈ 𝒰 . 0\leq\lambda<\gamma\leq\delta,z\in\mathcal{U}. We determine several properties of this class such as close-to-convexity, coefficient bounds, and growth estimates. We also prove that this class is closed under convex combination and convolution of its members. Furthermore, we investigate the properties of fully starlikeness and fully convexity of the class. Keywords: harmonic, univalent, close-to-convex, coefficient estimates, convolution.

Lemma 1

Suppose

and
\mathfrak{t}

\mathcal{U}

Theorem 2

The harmonic mapping
\mathfrak{f}=\mathfrak{s}+\overline{\mathfrak{t}}\in\mathcal{R}_{H}^{0}(\gamma,\delta,\lambda)
if and only if
\ F_{\epsilon}=\mathfrak{s}+\epsilon\mathfrak{t}\in\mathcal{R}(\gamma,\delta,\lambda)

Proof.
Suppose

For each

\displaystyle{\text{Re}}\left\{\gamma F_{\epsilon}^{\prime}(z)+\delta zF_{\epsilon}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}F_{\epsilon}^{\prime\prime\prime}(z)\right\}

\displaystyle={\text{Re}}\left\{\gamma\mathfrak{s}^{\prime}(z)+\delta z\mathfrak{s}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{s}^{\prime\prime\prime}\left(z\right)\right.

\displaystyle+\left.\epsilon\left(\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right)\right\}

\displaystyle-\left|\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right|

Conversely,

then

\displaystyle{\text{Re}}\left\{\gamma\mathfrak{s}^{\prime}(z)+\delta z\mathfrak{s}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{s}^{\prime\prime\prime}\left(z\right)\right\}

\displaystyle>

\displaystyle{\text{Re}}\left\{-\epsilon\left(\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right)\right\}+\lambda\text{ }\left(z\in\mathcal{U}\right).

\displaystyle{\text{Re}}\left\{\gamma\mathfrak{s}^{\prime}(z)+\delta z\mathfrak{s}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{s}^{\prime\prime\prime}\left(z\right)-\lambda\right\}

\displaystyle>

\displaystyle\left|\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right|\text{ }\left(z\in\mathcal{U}\right),

Lemma 4

If
F\in\mathcal{R}(\gamma,\delta,\lambda)
then
{\text{Re}}\{F^{\prime}(z)\}>0,
and hence

is close-to-convex in
\mathcal{U}.

Proof.
Suppose
F\in\mathcal{R}(\gamma,\delta,\lambda)
and
\frac{2\gamma F^{\prime}(z)+2\delta zF^{\prime\prime}(z)+\left(\delta-\gamma\right)z^{2}F^{\prime\prime\prime}(z)-2\lambda}{2\left(\gamma-\lambda\right)}=:\Psi(z).
Then
{\text{Re}}\{\Psi(z)\}>0
for
z\in\mathcal{U}.

Consider an analytic function
w
in
\mathcal{U}
with
w(0)=0
and

F^{\prime}(z)=\frac{1+w(z)}{1-w(z)},~\ w(z)\neq 1.

We need to prove that
|w(z)|<1
for all
z\in\mathcal{U}.
Then we have

\displaystyle\Psi(z)

\displaystyle=

\displaystyle\frac{2\gamma F^{\prime}(z)+2\delta zF^{\prime\prime}(z)+\left(\delta-\gamma\right)z^{2}F^{\prime\prime\prime}(z)-2\lambda}{2\left(\gamma-\lambda\right)}

\displaystyle=

\displaystyle\frac{\gamma}{\gamma-\lambda}\frac{1+w(z)}{1-w(z)}+\frac{2\delta}{\gamma-\lambda}\frac{zw^{\prime}(z)}{(1-w(z))^{2}}

\displaystyle+\frac{\delta-\gamma}{\gamma-\lambda}\frac{z^{2}\left[w^{\prime\prime}\left(z\right)\left(1-w(z)\right)+2\left(w^{\prime}\left(z\right)\right)^{2}\right]}{(1-w(z))^{3}}-\frac{\lambda}{\gamma-\lambda}

\displaystyle=

\displaystyle\frac{1}{\gamma-\lambda}\left(\gamma\frac{1+w(z)}{1-w(z)}+2\delta\frac{zw^{\prime}(z)}{(1-w(z))^{2}}\right.

\displaystyle\left.+\left(\delta-\gamma\right)\frac{zw^{\prime}(z)}{(1-w(z))^{2}}\frac{zw^{\prime\prime}\left(z\right)}{w^{\prime}(z)}+2\left(\delta-\gamma\right)\frac{\left(zw^{\prime}(z)\right)^{2}}{(1-w(z))^{3}}-\lambda\right).

Since

is analytic in
\mathcal{U}
and

if there are

such that

For such a point

, we obtain

\displaystyle{\text{Re}}\{\Psi(z_{0})\}

\displaystyle=

\displaystyle\frac{1}{\gamma-\lambda}\text{Re}\left(\gamma\frac{1+w(z_{0})}{1-w(z_{0})}+2\delta\frac{z_{0}w^{\prime}(z_{0})}{(1-w(z_{0}))^{2}}\right.

\displaystyle\left.+\left(\delta-\gamma\right)\frac{z_{0}w^{\prime}(z_{0})}{(1-w(z_{0}))^{2}}\frac{z_{0}w^{\prime\prime}\left(z_{0}\right)}{w^{\prime}(z_{0})}+2\left(\delta-\gamma\right)\frac{\left(z_{0}w^{\prime}(z_{0})\right)^{2}}{(1-w(z_{0}))^{3}}-\lambda\right)

\displaystyle=

\displaystyle\frac{1}{\gamma-\lambda}\left[-\frac{\delta k}{1-\cos\theta}-\frac{\left(\delta-\gamma\right)k}{2\left(1-\cos\theta\right)}\text{Re}\left\{\frac{zw^{\prime\prime}\left(z_{0}\right)}{w^{\prime}(z_{0})}\right\}+\frac{\left(\delta-\gamma\right)k^{2}}{2\left(1-\cos\theta\right)}-\lambda\right]

\displaystyle\leq

\displaystyle\frac{1}{\gamma-\lambda}\left[-\frac{\delta k}{1-\cos\theta}+\frac{\left(\delta-\gamma\right)k}{2\left(1-\cos\theta\right)}\left(1-k\right)+\frac{\left(\delta-\gamma\right)k^{2}}{2\left(1-\cos\theta\right)}-\lambda\right]

\displaystyle=

\displaystyle-\frac{1}{\gamma-\lambda}\left[\frac{\left(\delta+\gamma\right)k}{2\left(1-\cos\theta\right)}+\lambda\right]<0,

which contradicts our assumption. Hence, there is no
z_{0}\in\mathcal{U}

such that
|w(z_{0})|=1,
which means that
|w(z)|<1
for all
z\in\mathcal{U}.
Therefore, we obtain that
{\text{Re}}\{F^{\prime}(z)\}>0.

Theorem 6

Let

Suppose that

\displaystyle\gamma-\lambda.

\displaystyle\left|\gamma\mathfrak{t}^{\prime}(z)+\delta z\mathfrak{t}^{\prime\prime}(z)+\left(\frac{\delta-\gamma}{2}\right)z^{2}\mathfrak{t}^{\prime\prime\prime}\left(z\right)\right|
