Abstract
. We give sufficient conditions allowing one to build a C ∗ \mathrm{C}^{*} -algebraic structure on a self-adjoint linear subspace of a C ∗ \mathrm{C}^{*} -algebra in such a way that the subspace is naturally identified with the resulting C ∗ \mathrm{C}^{*} -algebra via a completely positive order zero map. This leads to necessary and sufficient conditions to realize a self-adjoint linear subspace of a C ∗ \mathrm{C}^{*} -algebra as the image of an order zero map from a C ∗ \mathrm{C}^{*} -algebra and to determine whether it is completely order isomorphic to a C ∗ \mathrm{C}^{*} -algebra via an order zero map.

Next we highlight a few relevant properties and observations for completely positive maps and completely positive order zero maps. For a full introduction to completely positive and completely bounded maps and see

Definition 1.1
.

Let
A

B
be
\mathrm{C}^{*}
-algebras with self-adjoint linear subspaces

,
Y\subset B
, and
\theta\colon X\longrightarrow Y
a linear map. We say

\theta(x)\in Y\cap B_{+}
for all

. We say it is

\theta^{(r)}\colon\mathrm{M}_{r}(X)\longrightarrow\mathrm{M}_{r}(Y)

We say
\theta

completely contractive
if
\sup_{r\geq 1}\|\theta^{(r)}\|\leq 1
. We say a map is c.p.c. when it is completely positive and (completely) contractive.

We say
\theta
is a
complete order embedding
if
\theta
is c.p. and completely isometric
with c.p. inverse
\theta^{-1}\colon\theta(A)\longrightarrow A
. A surjective complete order embedding is a
complete order isomorphism

We say
\theta
is
bounded below
if there exists
R>0
so that
\|\theta(x)\|\geq R\|x\|
for all
x\in X
.

Remarks 1.2
.

(i) Under certain assumptions, some of the properties of a complete order embedding are implied by the others, which is why this term tends to have varying definitions in the literature. Many of these require that the map is unital, but even in the nonunital setting,
if the domain of an isometric c.p. map is a (not-necessarily unital)
\mathrm{C}^{*}
-algebra, then the map is automatically a complete order embedding if it is completely isometric or order zero
(see
[
9
, Remark 1.7(ii)]
and

[
9
, Proposition 1.8]
,
respectively).

(ii) Complete order isomorphisms between
\mathrm{C}^{*}
-algebras are automatically
∗
-homomorphisms (see e.g.,
[
1
, Theorem II.6.9.17]
). It follows that a self-adjoint linear subspace
X
of a
\mathrm{C}^{*}
-algebra
B
which is completely order isomorphic to a
\mathrm{C}^{*}
-algebra
A
captures the isomorphism class of
A
in that another
\mathrm{C}^{*}
-algebra
C
is
∗
-isomorphic to
A
if and only if it is completely order isomorphic to
X
.

(iii)
Bounded below maps are exactly the invertible bounded linear maps with bounded linear inverses (defined on the image).
A linear map between Banach spaces is bounded below if and only if it is injective with closed range.
It follows that all matrix amplifications of a bounded below map
\theta\colon X\longrightarrow Y
between closed self-adjoint linear subspaces of
\mathrm{C}^{*}
-algebras are bounded below.

Example 1.3

We construct a map

is a homogeneous
\mathrm{C}^{*}
-algebra, such that

We claim that

Then

,

\displaystyle s^{*}s

\displaystyle=e_{22}\otimes e_{33}\ \text{ and }

Definition 1.4
.

A c.p. map
\theta\colon A\longrightarrow B
between
\mathrm{C}^{*}
-algebras is

if for any

,

While by Stinespring’s Theorem, every c.p. map can be written as a compression of a
∗
-homomorphism, order zero maps are characterized in
[

as compressions of
∗
-homomorphisms by commuting positive elements.

Theorem 1.5
.

(Structure theorem for order zero maps)

Let

and

be
\mathrm{C}^{*}
-algebras,

a c.p. order zero map,

an increasing approximate identity for

, and

, and there exists a
∗
-homomorphism

\theta(a)=h\pi_{\theta}(a)=h^{1/2}\pi_{\theta}(a)h^{1/2}.

(i) (

Proposition 1.7
.

Suppose

(ii)

\theta
is isometric.

\displaystyle\|\theta(a)\|^{2}

2.
Order Units

Drawing inspiration from order units for abstract operator systems,
we study local order units for a
(not-necessarily-unital)
self-adjoint linear subspace
X
of a
\mathrm{C}^{*}
-algebra
B
. Using the ambient
\mathrm{C}^{*}
-algebraic structure, we can place more sophisticated assumptions on our local order unit, in particular that
e\in X^{\prime}
, and then take full advantage of the functional calculus in
B
to draw conclusions about
X
and the pair
(X,e)
.

Definition 2.1
.

Let
B
be a
\mathrm{C}^{*}
-algebra and
X\subset B
a self-adjoint linear subspace. We say
e\in B^{1}_{+}
is a
local order unit
for
X
if for any self-adjoint element
x\in X
, there exists an
R>0
so that
Re\geq x
. We call
e
a
commuting local order unit
for
X
if
e
is a local order unit for
X
and
e\in X^{\prime}
.

Remarks 2.2
.

(i) We can view a self-adjoint linear subspace
X\subset B
of a
\mathrm{C}^{*}
-algebra as a matrix ordered
∗
-vector space as in
[
14
, Chapter 13]

by endowing it with the matrix ordering
\{\mathrm{M}_{r}(X)\cap\mathrm{M}_{r}(B)_{+}\}_{r}
it inherits from
B
. In this setting a local order unit for a self-adjoint linear subspace of a
\mathrm{C}^{*}
-algebra
B

is a local order unit in the sense of Choi and Effros (see
[
14
, Chapter 13]
)
for the matrix ordered
∗
-vector space
(X,\{\mathrm{M}_{r}(X)\cap\mathrm{M}_{r}(B)_{+}\}_{r})
.
(Note that if
e
is a local order unit for
X\subset B
, then it is automatically a matrix local order unit, i.e.,
e^{(r)}
is a local order unit for
\mathrm{M}_{r}(X)
for all
r\geq 1
. It is also Archimedean in the sense of
[
14
, Chapter 13]
since
\mathrm{M}_{r}(B)_{+}
is closed.)

(ii) A novelty of our definition is that we do not require that
e\in X
, in which case it is possible that
X\cap B_{+}=\{0\}
with
X\neq\{0\}
, and we are only guaranteed that
X
contains nontrivial self-adjoint elements. (This problem will disappear when we incorporate the further assumption that
X^{2}\subseteq eX
, see
Section

3
.)

Examples 2.3
.

(i)
Let
X
be a self-adjoint linear subspace of a unital
\mathrm{C}^{*}
-algebra
B
with
1_{B}\in X
. Then any local order unit of
X
must be invertible in
B
by virtue of dominating
1_{B}
up to some scalar factor, and so the collection of local order units for
X
is exactly
\text{GL}(B)\cap B^{1}_{+}
.

(ii) The subspace
C_{c}((0,1])
of the non-unital
\mathrm{C}^{*}
-algebra
C_{0}((0,1])
has local order unit

\mathrm{id}_{(0,1]}
.

(iii)
If
\theta\colon A\longrightarrow B
is a c.p.c. map from a unital
\mathrm{C}^{*}
-algebra, then
\theta(1_{A})
is a local order unit for
\theta(A)
.

(iv) It follows from
Theorem

1.5
that if
\theta\colon A\longrightarrow B
is a c.p.c. order zero map from a unital
\mathrm{C}^{*}
-algebra, then
\theta(1_{A})
is a commuting local order unit for the self-adjoint linear subspace
\theta(A)\subset B
.
Even if
A
is non-unital, we can, in some cases (see for example
Corollary

5.3
), leverage the structure theorem for c.p. order zero maps (as in Remark
1
(i)) to find a c.p.c. order zero extension
\theta^{\sim}\colon A^{\sim}\longrightarrow B
with
\theta^{\sim}(1_{A^{\sim}})=h
(with
h
as in Remark
1
(i)). In this case
\theta^{\sim}(1_{A^{\sim}})\in B^{1}_{+}\cap\theta(A)^{\prime}
is a commuting local order unit that is typically
not
in
\theta(A)
.

The following two propositions give technical facts for commuting local order units which will be used throughout the paper.

Proposition 2.4
.

Let
B
be a
\mathrm{C}^{*}
-algebra.

(i)

For
y,z\in B
such that
z\geq 0
and
yz=zy
,

(2.1)

\displaystyle z\geq|y|\ \Longleftrightarrow\ z|y|\geq y^{*}y.

(ii)

If
X\subset B
is a self-adjoint linear subspace, then the following are equivalent for

e\in B^{1}_{+}\cap X^{\prime}
:

(a)

e
is a local order unit for
X
.

(b)

For each
x\in X
, there exists an
R>0
so that
Re\geq|x|
.

(iii)

When either of the equivalent conditions in
(ii)
hold, the
\mathrm{C}^{*}
-algebra
\mathrm{C}^{*}(X)
generated by
X
in
B
is contained in the hereditary
\mathrm{C}^{*}
-algebra
\overline{eBe}
generated by
e
. In particular, for any
a\in\mathrm{C}^{*}(X)
,
\lim_{j}\|h_{j}(e)ea-a\|=0
, where
\{h_{j}\}_{j}
are as in (
1
).

Proof.

(i) For
s,t\in[0,\infty)
, we have
s\geq t\longleftrightarrow st\geq t^{2}
. Hence (

) follows from the fact that there is an isomorphism
\mathrm{C}^{*}(z,y^{*}y)\cong C_{0}(\Omega)
for some locally compact

which sends

and
|y|
to the functions
((s,t)\mapsto s)
and
((s,t)\mapsto t)
, respectively.

(ii)
(b)
\Longrightarrow
(a) since
|x|\geq x
for all self-adjoint

. To see that (a)
\Longrightarrow
(b), fix

. Then there exists
R>0
so that

and

. Since

commute, we also obtain

.

(iii) To see that

∎

Proposition 2.5
.

Let
B
be a
\mathrm{C}^{*}
-algebra and

a self-adjoint linear subspace with local order unit

.
Then the following hold for all

.

(i)

If

for some

, then
x=0
. (Nondegeneracy)

(ii)

If
ex=(ex)^{*}
, then
x=x^{*}
.

(iii)

If
ex\geq 0
, then
x\geq 0
.

Moreover, these claims hold for all matrix amplifications
\mathrm{M}_{r}(X)
with order units

Proof.

Note that if
e
is a commuting local order unit for
X
, then it will also be a commuting local order unit for
\textrm{span}\{X,e\}
.
Hence, for notational simplicity,
we reduce to the assumption
X=\textrm{span}\{X,e\}
.
Fix

.

For (i), we first handle the case where

. Since

, we may identify
\mathrm{C}^{*}(e,x)
with

for some locally compact Hausdorff space

. If

for some

either

or

. Since

such that

for all

. Together these imply that

, and so

.

, and so

For (iii), assume

\displaystyle=e(x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y)z

\displaystyle=e^{2}((x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y){\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}z).

By nondegeneracy of

(or actually

in this case), it follows that
x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(y{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}z)=(x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y){\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}z
.

To see that
(X,{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})
is a
∗
-algebra, we compute for

Then it follows from nondegeneracy that
(x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y)^{*}=y^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x^{*}
.

When

, nondegeneracy also gives

0=ex-ex=e(e{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x)-ex=e(e{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x-x)\Longrightarrow e{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x=x,

and similarly
x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}e=x
.
Hence

becomes the unit for
(X,{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})
.

From
Proposition

3.2
, we know that
\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}\colon X\longrightarrow[0,\infty)
defines a norm on
X
.
It remains to show that it
is a pre-
\mathrm{C}^{*}
-norm on
(X,{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})
.
We begin by checking that
\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}
is a algebra norm with respect to
{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}\colon X\times X\longrightarrow X
(i.e., it is submultiplicative). Let
x,y\in X
. With (
3.3
) we have that

\displaystyle\|x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}

\displaystyle=\lim_{j}\|h_{j}(e)^{2}e(x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y)\|

\displaystyle=\lim_{j}\|h_{j}(e)^{2}xy\|

\displaystyle\leq(\lim_{j}\|h_{j}(e)x\|)(\lim_{j}\|h_{j}(e)y\|)

\displaystyle=\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}\|y\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}.

Likewise we check the
\mathrm{C}^{*}
-identity for each

again using (
3.3
)

\displaystyle\|x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}

\displaystyle=\lim_{j}\|h_{j}(e)^{2}e(x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x)\|

\displaystyle=\lim_{j}\|h_{j}(e)^{2}x^{*}x\|

\displaystyle=\lim_{j}\|h_{j}(e)x\|^{2}

\displaystyle=\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}^{2}.

Hence
\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}
is a pre-
\mathrm{C}^{*}
-norm on
(X,\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,)
.
∎

Definition 3.3
.

Let
B

\mathrm{C}^{*}
-algebra and

{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}\colon X\times X\longrightarrow X

Examples 3.4

Proposition 3.5
.

Let
B
be a
\mathrm{C}^{*}
-algebra and

.

with respect to the product

(i)

(ii)

x{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y=y{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x

(iii)

Proof.

Set

2.5

If

and likewise

.

Fix

for both products.

4.
A c.p.c. order zero map

We now turn our attention to the map

\mathrm{id}_{X}:(X,\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})\longrightarrow(X,\|\cdot\|)
between the normed linear spaces
(X,\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})
and
(X,\|\cdot\|)
(where
\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}
is as defined in (

) and
\|\cdot\|
is the norm inherited from the
\mathrm{C}^{*}
-algebra

as before), which we want to extend to a c.p.c. order zero map
\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)\longrightarrow B
. The map
\mathrm{id}_{X}
is already a linear
∗
-preserving bijection, but in order to extend it to
\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)
, we need to show that it is bounded. In fact, it is completely contractive as the following proposition shows.

Proposition 4.1
.

Let
B
be a
\mathrm{C}^{*}
-algebra and
X\subset B
a self-adjoint linear subspace with local order unit
e\in B_{+}^{1}\cap X^{\prime}
, and let
\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}
be as defined in (
3.2
).
Then for each
r\geq 1
and
x\in\mathrm{M}_{r}(X)
,

\|x\|\leq\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}.

Moreover, if we assume that
X
is closed in
\|\cdot\|
, then there exists an
R\geq 1
such that for all
x\in X
,

\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}\leq R\|x\|.

In particular, if
X=\overline{X}^{\|\cdot\|}
, then
X=\overline{X}^{\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}}
.

Proof.

Let
\{h_{j}\}_{j}
be as defined (
1
), and fix
r\geq 1
and
x\in\mathrm{M}_{r}(X)
.
Since
e^{(r)}
is still a local order unit for
\mathrm{M}_{r}(X)
,
\{h_{j}(e^{(r)})e^{(r)}\}_{j}\subset X^{\prime}
forms an increasing approximate identity for
X
by
Proposition

2.4
(iii). Combining this with
Corollary

3.7
and (
3.3
), we have

(4.1)

\displaystyle\|x\|

\displaystyle=\lim_{j}\|h_{j}(e^{(r)})e^{(r)}x\|

\displaystyle=\sup_{j}\|h_{j}(e^{(r)})e^{(r)}x\|

\displaystyle\leq\sup_{j}\|e^{(r)}\|\|h_{j}(e^{(r)})x\|

\displaystyle\leq\|e^{(r)}\|\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}

\displaystyle\leq\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}.

If
X
is closed in
\|\cdot\|
, then
X
is a Banach space with respect to
\|\cdot\|
, and the maps
H_{j}\colon X\longrightarrow B
given for each
j\geq 1
for all
x\in X
by

(4.2)

\displaystyle H_{j}(x)=h_{j}(e)x

are bounded linear maps. Since
\sup_{j}\|H_{j}(x)\|=\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}<\infty
for each
x\in X
(by
Proposition

3.2
), the Banach–Steinhaus theorem (or Uniform Boundedness Principle)
guarantees that
0\leq\sup_{j}\|H_{j}\|=:R<\infty
.
Thus we have for all
x\in X

(4.3)

\displaystyle\|x\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}

\displaystyle=\lim_{j}\|h_{j}(e)x\|

\displaystyle=\sup_{j}\|h_{j}(e)x\|

\displaystyle=\sup_{j}\|H_{j}(x)\|

\displaystyle\leq\sup_{j}\|H_{j}\|\|x\|

\displaystyle=R\|x\|.

Moreover, (
4.1
) tells us
R\geq 1
.
∎

Theorem 4.2
.

Let
B
be a
\mathrm{C}^{*}
-algebra and
X\subset B
a self-adjoint linear subspace with local order unit
e\in B_{+}^{1}\cap X^{\prime}
with
X^{2}\subset eX
. Let
\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)
be the associated
\mathrm{C}^{*}
-algebra as in Definition
3.3
.
Then the map

\mathrm{id}_{X}:(X,\|\cdot\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})\longrightarrow(X,\|\cdot\|)
extends to a c.p.c. order zero map

\Phi\colon\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)\longrightarrow B
with
\Phi(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))\subset\overline{X}^{\|\cdot\|}
.

If
\Phi
is injective, then
\Phi^{(r)}(x)\geq 0
if and only if
x\geq 0
for any
r\geq 1
and
x\in\mathrm{M}_{r}(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))
.
Moreover

is closed in
\|\cdot\|
if and only if
\Phi=\mathrm{id}_{X}
and
\Phi
is bounded below.

Proof.

It follows from
Proposition

4.1
that the map
\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)\supset X\xlongrightarrow{\mathrm{id}_{X}}X\subset B
is completely contractive and hence extends to a completely contractive map
\Phi\colon\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)\longrightarrow B
with
\Phi(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))\subset\overline{X}^{\|\cdot\|}
. To see that
\Phi
is completely positive, fix
r\geq 1
.
By
Corollary

3.7
,
we may apply
Proposition

3.5
(iii)

and conclude that for each
x\in\mathrm{M}_{r}(X)
,

\Phi^{(r)}(x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x)=x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x\in\mathrm{M}_{r}(B)_{+}.

Since
(\mathrm{M}_{r}(X),{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,})
is a dense
∗
-subalgebra of
\mathrm{M}_{r}(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))=\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(\mathrm{M}_{r}(X))
, it follows that
\{x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x\ :\ x\in\mathrm{M}_{r}(X)\}
is dense in
\mathrm{M}_{r}(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))_{+}
, and so
we have

\displaystyle\Phi^{(r)}(\mathrm{M}_{r}(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))_{+})

\displaystyle\subset\overline{\Phi^{(r)}(\{x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x\ :\ x\in\mathrm{M}_{r}(X)\})}^{\|\cdot\|}

\displaystyle=\overline{\{x^{*}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}x\ :\ x\in\mathrm{M}_{r}(X)\}}^{\|\cdot\|}\subset\mathrm{M}_{r}(B)_{+}.

To see that
\Phi
is order zero, suppose
a,b\in\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)_{+}
with
a{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}b=0
, and let
(x_{n})_{n},(y_{n})_{n}\subset X
such that
\lim_{n}\|x_{n}-a\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}=0
and
\lim_{n}\|y_{n}-b\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}=0
. Then
\lim_{n}\|x_{n}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y_{n}\|_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}=0
and so

\displaystyle 0

\displaystyle=\lim_{n}\|e\Phi(x_{n}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y_{n})\|

\displaystyle=\lim_{n}\|e(x_{n}{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}y_{n})\|

\displaystyle=\lim_{n}\|x_{n}y_{n}\|

\displaystyle=\lim_{n}\|\Phi(x_{n})\Phi(y_{n})\|

\displaystyle=\|\Phi(a)\Phi(b)\|,

using continuity of
\Phi
for the first and last equalities.

Remark
1
(iii) tells us that
if
\Phi
is injective, then for any
r\geq 1
and
x\in\mathrm{M}_{r}(\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X))
, we have

if and only if

.

If
X
is closed in
\|\cdot\|
, then

4.1
tells us that
X
is already complete with respect to

. Hence
\mathrm{C}^{*}_{\,\begin{picture}(-1.0,-2.5)\circle*{3.0}\end{picture}\,\,\,}(X)=X

. In particular,

is injective with closed range and hence bounded below. On the other hand, if

, and so

. If moreover

is closed in

.
∎

Recall from Example
3
(ii) that for a given a c.p.c. order zero map
\theta\colon A\longrightarrow B
from a unital
