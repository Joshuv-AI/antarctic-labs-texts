Kernel-Based Identification with Frequency Domain Side-Information
M. Khosravi and R. S. Smith

Abstract
In this paper, we discuss the problem of system identification when frequency domain side information is available on the system. Initially, we consider the case where the prior knowledge is provided as being the ℋ ∞ {\mathcal{H}}_{\infty} -norm of the system bounded by a given scalar. This framework provides the opportunity of considering various forms of side information such as the dissipativity of the system as well as other forms of frequency domain prior knowledge. We propose a nonparametric identification method for estimating the impulse response of the system under the given side information. The estimation problem is formulated as an optimization in a reproducing kernel Hilbert space (RKHS) endowed with a stable kernel. The corresponding objective function consists of a term for minimizing the fitting error, and a regularization term defined based on the norm of the impulse response in the employed RKHS. To guarantee the desired frequency domain features defined based on the prior knowledge, suitable constraints are imposed on the estimation problem. The resulting optimization has an infinite-dimensional feasible set with an infinite number of constraints. We show that this problem is a well-defined convex program with a unique solution. We propose a heuristic that tightly approximates this unique solution. The proposed approach is equivalent to solving a finite-dimensional convex quadratically constrained quadratic program. The efficiency of the discussed method is verified by several numerical examples.

{\mathcal{H}}_{\infty}
-norm of the system bounded by a given scalar. This framework provides the opportunity of considering various forms of side information such as the dissipativity of the system as well as other types of frequency domain prior knowledge like the DC-gain of the system. We propose a nonparametric identification method for estimating the impulse response of the system under the given side information. Since kernel-based approach provides a powerful framework, the identification problem is formulated as a constrained regularized optimization problem regression in an RKHS endowed with a stable kernel
[

,

The objective function of the optimization problem consists of a term for minimizing the fitting error, and a regularization term defined based on the norm of the impulse response in the employed RKHS. Accordingly, we obtain a regularized optimization problem in an infinite-dimensional space with an infinite number of constraints. Then, towards deriving a tractable scheme, we consider a suitable finite set of frequencies, and subsequently, a new optimization is formulated as an approximate estimation problem with the same objective function but with constraints defined on the given finite set. We show that the new problem attains a unique solution with an especial parametric form. Subsequently, an equivalent finite-dimensional convex optimization is derived as a convex quadratically constrained quadratic program (QCQP). More precisely, by solving this optimization problem, the coefficients in the parametric form are estimated, and hence, the solution of the approximate problem is obtained. We derive suitable bounds on the tightness of this approximation. Moreover, we provide theoretical guarantees on the convergence of the approximate solution to the solution of the original problem. The efficiency of the discussed method is verified by several numerical examples.

respectively for
{\mathbb{T}}={\mathbb{Z}}_{+}
and
{\mathbb{T}}={\mathbb{Z}}_{+}
.
Note that since each element of
{\mathscr{G}}
belongs to
{\mathscr{L}}_{1}
the summation in (
9
) and the integration in (
10
) are well-defined.
Accordingly, in order to address Problem
1
, it is enough to solve the following optimization problem

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{F}}}&{\mathcal{L}}_{{\mathscr{D}}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})\\
\mathrm{s.t.}&{\mathrm{g}}\in{\mathscr{G}},\end{array}

(11)

where
{\mathcal{R}}:{\mathscr{F}}\to{\mathbb{R}}_{+}
is a suitable regularization function and

\lambda>0
is the regularization weight.
Due to the definition of set
{\mathscr{G}}
in (
9
) and (
10
), the constraint in (
11
) is essentially equivalent to uncountably infinite number of inequalities. Consequently, the optimization problem (
11
) is an infinite-dimensional program with uncountably infinite number of constraints which is not tractable at the current form.
Therefore, we should address the following questions:

1.

What is a suitable candidate for hypothesis set
{\mathscr{F}}
?

2.

Does optimization problem (
11
) admit an optimal solution? Is this solution unique?

3.

How can we obtain the solution of (
11
) or a tight approximation for it?

In the remainder of this section, we address these questions except the last one which is postponed to Section
V
.

IV-A

Stable Reproducing Kernel Hilbert Spaces

The hypothesis space taken for estimating the unknown impulse response is a type of Hilbert spaces known as
reproducing kernel Hilbert spaces
(RKHS) which
are introduced briefly below (see
[
38
,
56
]
for more details).
The structure of RKHS provides a suitable framework for investigating the problem and obtaining a tractable scheme for solving (
11
).

Definition 1

(
[
56
]
)
.

Let
{\mathscr{H}}\subseteq{\mathbb{R}}^{{\mathbb{T}}}
be a Hilbert space endowed with inner product
{\langle{\cdot,\cdot}\rangle}_{{\mathscr{H}}}
and induced norm
\|\cdot\|_{{\mathscr{H}}}
. Then,
{\mathscr{H}}
is a reproducing kernel Hilbert space (RKHS) if for any
t\in{\mathbb{T}}
,
we have

\sup\big\{|g_{t}|\ \big|\ {\mathrm{g}}:=(g_{t})_{t\in{\mathbb{T}}}\in{\mathscr{H}},\|{\mathrm{g}}\|_{{\mathscr{H}}}\leq 1\big\}<\infty
.

Along with the RKHS, the notion of Mercer kernel is introduced which is provided in the next definition.

Definition 2

(
[
56
]
)
.

The continuous function
\mathbbm{k}:{\mathbb{T}}\times{\mathbb{T}}\to{\mathbb{R}}
is a Mercer kernel or positive-definite kernel when for any
m\in{\mathbb{N}}
,
t,s,t_{1},\ldots,t_{m}\in{\mathbb{T}}
and
a_{1},\ldots,a_{m}\in{\mathbb{R}}
, we have
\mathbbm{k}(t,s)=\mathbbm{k}(s,t)
and
\sum_{1\leq i,j\leq m}a_{i}a_{j}\mathbbm{k}(t_{i},t_{j})\geq 0
.
For each
t\in{\mathbb{T}}
,
the section of kernel
\mathbbm{k}
at
t
is defined as the function
\mathbbm{k}(t,\cdot):{\mathbb{T}}\to{\mathbb{R}}
and denoted by
\mathbbm{k}_{t}
.

The next theorem shows the connection between RKHS introduced in Definition
1
and the notion of Mercer kernel defined in Definition
2
.

Theorem 1

(
[
56
]
)
.

Given Mercer kernel
\mathbbm{k}:{\mathbb{T}}\times{\mathbb{T}}\to{\mathbb{R}}
, there exists a RKHS
{\mathscr{H}}_{\mathbbm{k}}\subseteq{\mathrm{g}}\in{\mathbb{R}}^{{\mathbb{T}}}
, endowed with inner product
{\langle{\cdot,\cdot}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}
and norm
\|\cdot\|_{{\mathscr{H}}_{\mathbbm{k}}}
, such that for any
t\in{\mathbb{T}}
, we have

\mathbbm{k}_{k}\in{\mathscr{H}}_{\mathbbm{k}}
, and
{\langle{{\mathrm{g}},\mathbbm{k}_{t}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}=g_{t}
, for all
{\mathrm{g}}=(g_{t})_{t\in{\mathbb{T}}}\in{\mathscr{H}}_{\mathbbm{k}}
.
The second feature is called reproducing property.

Based on Theorem
1
, we know that a RKHS is uniquely characterized with a Mercer kernel.
Therefore, in the current context, the kernel
\mathbbm{k}
is supposed to be chosen suitably such that each impulse response
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
represents a stable system in the bounded-input-bounded-output (BIBO) sense. More precisely, we should have
{\mathscr{H}}_{\mathbbm{k}}\subseteq{\mathscr{L}}^{1}
. When kernel
\mathbbm{k}
satisfies this feature, it is called a
stable kernel

[
51
]
. The following theorem provides a necessary and sufficient condition for the stability of a given kernel.

Theorem 2

(
[
51
,
57
]
)
.

Let
\mathbbm{k}:{\mathbb{T}}\times{\mathbb{T}}\to{\mathbb{R}}
be a Mercer kernel. Then,
\mathbbm{k}
is stable if and only if,
when
{\mathbb{T}}={\mathbb{Z}}_{+}
, we have

\sum_{t\in{\mathbb{Z}}_{+}}\big|\sum_{s\in{\mathbb{Z}}_{+}}u_{s}\mathbbm{k}(t,s)\big|<\infty
, and, when
{\mathbb{T}}={\mathbb{R}}_{+}
, we have

\int_{{\mathbb{R}}_{+}}\big|\int_{{\mathbb{R}}_{+}}u_{s}\mathbbm{k}(t,s)\mathrm{d}s\big|\mathrm{d}t<\infty
,
for any
{\mathrm{u}}=(u_{t})_{t\in{\mathbb{T}}}\in{\mathscr{L}}^{\infty}
.

The most common stable kernel in the literature
[
35
]
is the
tuned/correlated
(TC) kernel defined as follows

\mathbbm{k}(s,t)=\begin{cases}\alpha^{\max(s,t)}&\text{ if ${\mathbb{T}}={\mathbb{Z}}_{+}$,}\\
\mathrm{e}^{-\beta\max(s,t)}&\text{ if ${\mathbb{T}}={\mathbb{R}}_{+}$,}\end{cases}

(12)

where
\alpha\in[0,1)
and
\beta>0
. By setting
\alpha
as
\mathrm{e}^{-\beta}
, one can obtain same definition for both cases in (
12
).
This is the default kernel employed in
impulseest
function of

Matlab
’s
System Identification Toolbox
.
One can easily see that if for kernel
\mathds{h}
is
dominated
by TC kernel
\mathbbm{k}
, i.e., there exists
\gamma\in{\mathbb{R}}_{+}
such that for any
s,t\in{\mathbb{T}}
we have
|\mathds{h}(s,t)|\leq\gamma\mathbbm{k}(s,t)
, then
\mathds{h}
is a stable kernel.
This highlights the importance of TC kernels.

IV-B

The Estimation Problem in Stable Reproducing Kernel Hilbert Spaces

Let
\mathbbm{k}
be a stable kernel and
{\mathscr{H}}_{\mathbbm{k}}
be the corresponding RKHS.
Motivated by
[
33
,
35
,
34
]
and the above discussion, we set
{\mathscr{H}}_{\mathbbm{k}}
as the hypothesis space for the estimation problem, i.e.,
{\mathscr{F}}={\mathscr{H}}_{\mathbbm{k}}
.
Subsequently, we can introduce a suitable kernel-based regularization. More precisely, let the regularization function
{\mathcal{R}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}_{+}
be defined as
{\mathcal{R}}({\mathrm{g}}):=\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2}
.
Therefore, in correspondence with the estimation Problem
1
, we have the following optimization problem:

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}&\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2},\\
\mathrm{s.t.}&|G(\mathrm{j}\omega)|\leq\rho,\quad\forall\omega\in\Omega_{{\mathbb{T}}},\end{array}

(13)

where
G
denotes the transfer function corresponding to the impulse response
{\mathrm{g}}
,
\Omega_{{\mathbb{T}}}:=[0,\pi]
when
{\mathbb{T}}={\mathbb{Z}}_{+}
, and
\Omega_{{\mathbb{T}}}:={\mathbb{R}}_{+}
when
{\mathbb{T}}={\mathbb{R}}_{+}
.
Note that by abuse of notation, for both cases of discrete-time and continuous-time, we employ same expression
G(\mathrm{j}\omega)
for the transfer function of the system.

The constraints introduced in (
13
) are the Fourier transform of the impulse response
{\mathrm{g}}
at different frequencies.
Since
{\mathrm{g}}
belongs to RKHS
{\mathscr{H}}_{\mathbbm{k}}
, one should study the corresponding notion and its properties in the domain of RKHS
{\mathscr{H}}_{\mathbbm{k}}
.

Definition 3
.

With respect each
\omega\in\Omega_{{\mathbb{T}}}
, we define maps
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
and
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
such that for any
{\mathrm{g}}=(g_{t})_{t\in{\mathbb{T}}}\in{\mathscr{H}}_{\mathbbm{k}}
, we have

\!\!\!\!\!\!\!\!{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})\!:=\!\sum_{t\in{\mathbb{Z}}_{+}}\!g_{t}\cos(\omega t),\quad{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})\!:=\!-\!\!\sum_{t\in{\mathbb{Z}}_{+}}\!g_{t}\sin(\omega t),\!\!\!\!

(14)

when
{\mathbb{T}}={\mathbb{Z}}_{+}
, and

\!\!\!\!\!\!{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})\!:=\!\!\int_{{\mathbb{R}}_{+}}\!\!\!g_{t}\cos(\omega t)\mathrm{d}t,\quad{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})\!:=\!-\!\!\int_{{\mathbb{R}}_{+}}\!\!\!g_{t}\sin(\omega t)\mathrm{d}t,\!\!

(15)

when
{\mathbb{T}}={\mathbb{R}}_{+}
.
Also
{\mathcal{F}}_{\omega}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{C}}
is defined as
{\mathcal{F}}_{\omega}({\mathrm{g}})={\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})+\mathrm{j}{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})
, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
.

Based on the definition of
{\mathcal{F}}_{\omega}
, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
and
\omega\in\Omega_{{\mathbb{T}}}
, we have
G(\mathrm{j}\omega)={\mathcal{F}}_{\omega}({\mathrm{g}})
, where
G
is the transfer function corresponding to the impulse response
{\mathrm{g}}
.
Accordingly, the problem (
13
) can be re-written in the following form

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}&\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2},\\
\mathrm{s.t.}&|{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq\rho,\quad\forall\omega\in\Omega_{{\mathbb{T}}}.\end{array}

(16)

Remark 1
.

One can see that
{\mathcal{F}}_{\omega}
is the Fourier transform restricted on the RKHS
{\mathscr{H}}_{\mathbbm{k}}
evaluated for the frequency
\omega\in\Omega_{{\mathbb{T}}}
.
However, we should note that it does not necessarily inherit the same properties of standard Fourier transform. More precisely, the structure of
{\mathscr{H}}_{\mathbbm{k}}
plays a key role.

Before proceeding further, we need to introduce a notion based on the kernel
\mathbbm{k}
. For any
n\in{\mathbb{Z}}_{+}
, define
\mu_{n}\in[0,\infty]
as

\mu_{n}:=\begin{cases}\operatornamewithlimits{\sum}\limits_{t\in{\mathbb{Z}}_{+}}t^{n}\ \!\mathbbm{k}(t,t)^{\frac{1}{2}},&\text{ if }{\mathbb{T}}={\mathbb{Z}}_{+},\\
\int_{{\mathbb{R}}_{+}}t^{n}\ \!\mathbbm{k}(t,t)^{\frac{1}{2}}\ \!\mathrm{d}t,&\text{ if }{\mathbb{T}}={\mathbb{R}}_{+}.\end{cases}

(17)

The next lemma introduces properties of
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}{}
,
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}{}
and
{\mathcal{F}}_{\omega}{}
.

Lemma 3
.

Let
\mu_{0}<\infty
.
Then, the followings hold:

1) The maps
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}},{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
and
{\mathcal{F}}_{\omega}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{C}}
are linear continuous with

\|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}\|_{{\mathcal{L}}({\mathscr{H}}_{\mathbbm{k}},{\mathbb{R}})},\|{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}\|_{{\mathcal{L}}({\mathscr{H}}_{\mathbbm{k}},{\mathbb{R}})}\ \leq\ \mu_{0}.

2) There exist unique elements
\varphi_{\omega}^{\text{\rm{(r)}}}=(\varphi_{\omega,t}^{\text{\rm{(r)}}})_{t\in{\mathbb{T}}}
and
\varphi_{\omega}^{\text{\rm{(i)}}}=(\varphi_{\omega,t}^{\text{\rm{(i)}}})_{t\in{\mathbb{T}}}
in
{\mathscr{H}}_{\mathbbm{k}}
such that, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
, we have

{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})={\langle{\varphi_{\omega}^{\text{\rm{(r)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}},\qquad{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})={\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}},

(18)

3) For any
t\in{\mathbb{T}}
, when
{\mathbb{T}}={\mathbb{Z}}_{+}
, we have

\!\!\!\!\!\!\varphi_{\omega,t}^{\text{\rm{(r)}}}\!=\!\!\!\sum_{s\in{\mathbb{Z}}_{+}}\mathbbm{k}(t,s)\cos(\omega s),\ \varphi_{\omega,t}^{\text{\rm{(i)}}}\!=\!-\!\!\sum_{s\in{\mathbb{Z}}_{+}}\mathbbm{k}(t,s)\sin(\omega s),\!\!

(19)

and, when
{\mathbb{T}}={\mathbb{R}}_{+}
, we have

\!\!\!\!\!\!\varphi_{\omega,t}^{\text{\rm{(r)}}}\!=\!\!\!\int_{{\mathbb{R}}_{+}}\!\!\!\!\!\mathbbm{k}(t,s)\cos(\omega s)\mathrm{d}s,\ \varphi_{\omega,t}^{\text{\rm{(i)}}}\!=\!-\!\!\int_{{\mathbb{R}}_{+}}\!\!\!\!\!\mathbbm{k}(t,s)\sin(\omega s)\mathrm{d}s,\!\!

(20)

Proof.

See Appendix
A-A
.
∎

Let
\Omega\subseteq\Omega_{{\mathbb{T}}}
and
\eta\in{\mathbb{R}}_{+}
.
Define set
{\mathscr{G}}_{\mathbbm{k}}(\rho,\Omega)
as

{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega):=\bigg\{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\ \bigg|\ |{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq\eta,\forall\omega\in\Omega\bigg\}.

(21)

One can see that the feasible set in (
16
) is an especial case of this set.
Based on Lemma
3
, we study the main properties of
{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)
in the next theorem.

Theorem 4
.

Let
\mu_{0}<\infty
. Then,
{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)
is non-empty, closed and convex.

Proof.

From (
21
), one can see that

\begin{split}&{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)=\{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\ |\ |{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq\eta,\forall\omega\in\Omega\}\\
&=\bigcap\limits_{\omega\in\Omega}\ \{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\ |\ |{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq\eta\}=\bigcap\limits_{\omega\in\Omega}\ {\mathscr{G}}_{\mathbbm{k}}(\eta,\{\omega\}).\end{split}

Therefore, it is enough to show that, for any
\omega\in\Omega_{{\mathbb{T}}}
,
{\mathscr{G}}_{\mathbbm{k}}(\eta,\{\omega\})
is a closed and convex subset of
{\mathscr{H}}_{\mathbbm{k}}
.
Since
|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}=|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})|^{2}+|{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})|^{2}
, we have that

{\mathcal{G}}_{\mathbbm{k}}(\eta,\{\omega\})=\bigg\{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\ \bigg|\ |{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})|^{2}+|{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})|\leq\eta^{2}\bigg\}.

(22)

Due to Lemma
3
, we know that
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})={\langle{\varphi_{\omega}^{\text{\rm{(r)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}
and
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})={\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}
, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
.
With respect to each
\theta\in[0,\frac{\pi}{2}]
, define set
{\mathcal{G}}_{\mathbbm{k}}(\eta,\omega,\theta)
as

{\mathcal{G}}_{\mathbbm{k}}(\eta,\omega,\theta)\!:=\!\big\{\!{\mathrm{g}}\!\in\!{\mathscr{H}}_{\mathbbm{k}}\big||{\langle{\varphi_{\omega}^{\text{\rm{(r)}}},{\mathrm{g}}}\rangle}|\!\leq\!\eta\cos\theta,|{\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}|\!\leq\!\eta\sin\theta\big\}.

Note that
{\mathscr{G}}_{\mathbbm{k}}(\eta,\omega,\theta)

is the intersection of

\vskip-5.69054pt\begin{split}&\{{\mathrm{g}}\!\in\!{\mathscr{H}}_{\mathbbm{k}}|{\langle{\varphi_{\omega}^{\text{\rm{(r)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}\!\leq\!\eta\cos\theta\},\\
&\{{\mathrm{g}}\!\in\!{\mathscr{H}}_{\mathbbm{k}}|{\langle{\varphi_{\omega}^{\text{\rm{(r)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}\!\geq\!-\eta\cos\theta\},\\
&\{{\mathrm{g}}\!\in\!{\mathscr{H}}_{\mathbbm{k}}|{\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}\!\leq\!\eta\sin\theta\},\\
&\{{\mathrm{g}}\!\in\!{\mathscr{H}}_{\mathbbm{k}}|{\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}\!\geq\!-\eta\sin\theta\},\end{split}

(23)

which are closed half-spaces in
{\mathscr{H}}_{\mathbbm{k}}
.
Therefore,
{\mathcal{G}}_{\mathbbm{k}}(\eta,\omega,\theta)
is a closed and convex set.
Since we have

{\mathcal{G}}_{\mathbbm{k}}(\eta,\{\omega\})=\bigcap_{\theta\in[0,\frac{\pi}{2}]}{\mathcal{G}}_{\mathbbm{k}}(\eta,\omega,\theta),
the set
{\mathcal{G}}_{\mathbbm{k}}(\eta,\{\omega\})
is closed and convex as well.
Note that for
\mathbf{0}\in{\mathscr{H}}_{\mathbbm{k}}
and any
\omega\in\Omega
, we have
{\mathcal{F}}_{\omega}(\mathbf{0})=0
.
Therefore,
|{\mathcal{F}}_{\omega}(\mathbf{0})|=0\leq\eta
and subsequently,
\mathbf{0}\in{\mathscr{G}}(\eta,\Omega)
.
This shows that
{\mathscr{G}}(\eta,\Omega)
is a non-empty set and concludes the proof.
∎

.

\end{cases}

Theorem 6
.

Let
\mu_{0}>0
and consider the following program

\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)}\ \operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2}.

(25)

Then, (
25
) is a convex optimization problem with a
unique
solution
{\mathrm{g}}^{\star}_{\Omega}
.
Moreover, we have

\|{\mathrm{g}}^{\star}_{\Omega}\|_{{\mathscr{H}}_{\mathbbm{k}}}\ \!\leq\ \!\big(\frac{1}{\lambda}\sum_{t\in{\mathscr{T}}}y_{t}^{2}\big)^{\frac{1}{2}}.

(26)

Proof.

Define
{\mathcal{J}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}\cup\{+\infty\}
such that for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
we have

{\mathcal{J}}({\mathrm{g}})=\sum_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\|g\|^{2}_{{\mathscr{H}}_{\mathbbm{k}}}+\delta_{{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)}({\mathrm{g}}).

(27)

Since
\mathbf{0}\in{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)
, we have
\delta_{{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)}(\mathbf{0})=0
.
Due to the definition of
{\mathrm{L}}^{\!{\mathrm{u}}}_{t}
in (
1
) and (
2
), one has that
{\mathrm{L}}^{\!{\mathrm{u}}}_{t}(\mathbf{0})=0
, for each
t\in{\mathscr{T}}
, and subsequently, we have

{\mathcal{J}}(\mathbf{0})=\sum_{t\in{\mathscr{T}}}y_{t}^{2}<\infty.
From Theorem
4
, we know that
{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)
is a convex and closed set, and consequently,
\delta_{{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)}
is a proper lower semi-continuous convex function
[
58
]
.
Due to Lemma
5
, we know that
{\mathrm{L}}^{\!{\mathrm{u}}}_{t}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
is a continuous linear map, for each

. Therefore, function
{\mathcal{L}}_{{\mathscr{D}}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
, defined in (

), is a convex and continuous function.
Since
\lambda>0
, we know that
{\mathcal{J}}
is a proper and lower semi-continuous strongly convex function.
Therefore,
\min_{g\in{\mathscr{H}}_{\mathbbm{k}}}{\mathcal{J}}(g)
has a unique (finite) solution
[
58
]
, and subsequently, (
25
) is a convex program with a unique solution
{\mathrm{g}}^{\star}_{\Omega}
with finite cost.

\mathbf{0}\in{\mathscr{G}}_{\mathbbm{k}}(\eta,\Omega)
and due to optimality of
{\mathrm{g}}^{\star}_{\Omega}
, we have
{\mathcal{J}}({\mathrm{g}}^{\star}_{\Omega})\leq{\mathcal{J}}(\mathbf{0})
.
Subsequently, one can see

\lambda\|{\mathrm{g}}^{\star}_{\Omega}\|^{2}\leq\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}}^{\star}_{\Omega})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}^{\star}_{\Omega}\|^{2}\leq{\mathcal{J}}(\mathbf{0})=\sum_{t\in{\mathscr{T}}}y_{t}^{2},

which induces (
26
).
This concludes the proof.
∎

.

) is a convex optimizations with a unique solution denoted by

In Theorem

, set
\Omega
and
\eta

.

In the above discussion, we have assumed that

Based on Corollary

, we know that the optimization problem (

.
Since this optimization problem is defined over an infinite-dimensional space with uncountably infinite number of constraints, obtaining this solution does not seem to be tractable at the current form.

V
Towards a Tractable Scheme

In this section, we present a tractable approach to derive the solution of the nonparametric estimation problem introduced in Section
IV
.

Consider optimization problem (
16
). For the ease of discussion and without loss of generality, we assume
\rho=1
.
More precisely, one can use a change of variable and replace
y_{t}
with
\rho^{-1}y_{t}
in
{\mathscr{D}}
and then, set
\rho=1
in Problem
1
as well as in (
16
), or equivalently in (
13
).
With respect to each
\omega\in\Omega_{{\mathbb{T}}}
, there exists a constraint in (
16
).
Thus, we have uncountably infinite number of constraints which makes the problem intractable.
One possible approach to resolve this issue is approximating the problem by considering a only a suitable finite subset of
\Omega_{{\mathbb{T}}}
.
In order to investigate this possibility, we need the notion of
partition
introduced in the next definition.

Definition 4
.

We say
{\mathscr{P}}
is a partition of interval
[a,b]
if
{\mathscr{P}}
is a finite subset of
[a,b]
as
{\mathscr{P}}=\{\omega_{i}\ |\ i=0,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}\}
where

a=\omega_{0}<\omega_{1}<\ldots<\omega_{n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}}=b.

(28)

With respect to partition
{\mathscr{P}}
, the mesh of
{\mathscr{P}}
, denoted by
\mathrm{mesh}({\mathscr{P}})
, is defined as

\mathrm{mesh}({\mathscr{P}}):=\max\{|\omega_{i}-\omega_{i-1}|\ |\ i=1,2,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}\}.

(29)

Now, let
{\mathscr{P}}=\{\omega_{i}\ |\ i=0,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}\}
be a given partition.
One can see that satisfying the constraints
|{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq 1
, for all
w\in{\mathscr{P}}
, does not necessarily imply that the desired feature
\sup_{\omega\in\Omega_{{\mathbb{T}}}}|{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq 1
.
More precisely, these constraints do not guarantee that for all
\omega\in\Omega_{{\mathbb{T}}}\backslash{\mathscr{P}}
we have
|{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq 1
as well.
Accordingly, in order to approximate problem (
16
),
we take
\epsilon>0
and consider the following problem as our approximation

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}&\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2},\\
\mathrm{s.t.}&|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}\leq 1-\epsilon,\quad\forall\omega\in{\mathscr{P}}.\end{array}

(30)

In the following, we provide appropriate conditions on partition
{\mathscr{P}}
and
\epsilon>0

for ensuring that the solution of (
30
) satisfies
\sup_{\omega\in\Omega_{{\mathbb{T}}}}|{\mathcal{F}}_{\omega}({\mathrm{g}})|\leq 1
.
These conditions depend on the bandwidth of system
{\mathrm{g}}
and the rate of changes for
|{\mathcal{F}}_{\omega}({\mathrm{g}})|
with respect to
\omega
.
Accordingly, first we need to introduce necessary definitions and preliminaries.

Definition 5
.

Let
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
be a given impulse response. With respect to
{\mathrm{g}}
, we define magnitude function
m_{{\mathrm{g}}}:\Omega_{{\mathbb{T}}}\to{\mathbb{R}}
as
m_{{\mathrm{g}}}(\omega)=|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}
.

Given impulse response
{\mathrm{g}}
, the function
m_{{\mathrm{g}}}
shows the squared magnitude of transfer function corresponding to
{\mathrm{g}}
at different frequencies. The following lemma introduces a bound for the rate of changes of
m_{{\mathrm{g}}}
in terms of its Lipschitz constant. This will be used later in the analysis of problem (
30
).

Lemma 9
.

Let
\mu_{1},\mu_{2}<\infty
. Then, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
and
\omega_{1},\omega_{2}\in\Omega_{{\mathbb{T}}}
, we have

|m_{{\mathrm{g}}}(\omega_{2})-m_{{\mathrm{g}}}(\omega_{1})|\leq L_{{\mathrm{g}}}|\omega_{2}-\omega_{1}|,

(31)

where
L_{{\mathrm{g}}}:=4\mu_{1}\mu_{2}\|{\mathrm{g}}\|^{2}
.

Proof.

See Appendix
A-D
.
∎

For the case of discrete-time systems, i.e.,
{\mathbb{T}}={\mathbb{Z}}_{+}
, the frequency range
\Omega_{{\mathbb{T}}}
is the bounded interval
[0,\omega_{\mathrm{max}}]
, where
\omega_{\mathrm{max}}=\pi
.
In order to introduce analogous of
\omega_{\mathrm{max}}
for the continuous-time systems, we need the next assumption.

Assumption 1
.

For the case
{\mathbb{T}}={\mathbb{R}}_{+}
, we have

\lim_{\omega\to\infty}\int_{{\mathbb{R}}_{+}}\int_{{\mathbb{R}}_{+}}\mathbbm{k}(s,t)\mathrm{e}^{-\mathrm{j}\omega(s-t)}\mathrm{d}s\mathrm{d}t=0.

(32)

This assumption says that the bandwidth of kernel
\mathbbm{k}
is bounded. Moreover, from (
32
), we know that there exists
\omega_{\mathrm{max}}\in{\mathbb{R}}_{+}
such that

\bigg|\int_{{\mathbb{R}}_{+}}\int_{{\mathbb{R}}_{+}}\mathbbm{k}(s,t)\mathrm{e}^{-\mathrm{j}\omega(s-t)}\mathrm{d}s\mathrm{d}t\bigg|\leq\frac{\lambda}{\sum_{t\in{\mathscr{T}}}y_{t}^{2}},

(33)

for all
\omega>\omega_{\mathrm{max}}
.
In the followings, it is shown that the frequency value
\omega_{\mathrm{max}}
plays the role of an upper bound for the bandwidth of the system of interest.
The next theorem shows that for TC kernels Assumption
1
holds. One may show similar result for other stable kernels in the literature.

Theorem 10
.

Let
\beta>0
and
\mathbbm{k}:{\mathbb{R}}_{+}\times{\mathbb{R}}_{+}\to{\mathbb{R}}_{+}
be the TC kernel
\mathbbm{k}(s,t)=\mathrm{e}^{-\beta\max(s,t)}
. Then, we have

\int_{{\mathbb{R}}_{+}}\int_{{\mathbb{R}}_{+}}\mathbbm{k}(s,t)\mathrm{e}^{-\mathrm{j}\omega(s-t)}\mathrm{d}s\mathrm{d}t=\frac{2}{\omega^{2}+\beta^{2}}.

(34)

Proof.

See Appendix
A-E
.
∎

Based on the introduced notions and facts, we can present the main theorem of this section.

Theorem 11
.

Let
\mu_{0},\mu_{1}<\infty
,
{\mathscr{P}}
be a given partition of
[0,\omega_{\mathrm{max}}]
and
\epsilon>0
. Then, optimization problem (
30
) is a convex program with a unique solution
{\mathrm{g}}^{(\star,\epsilon)}
. For
{\mathrm{g}}^{(\star,\epsilon)}
, we have

\|{\mathrm{g}}^{(\star,\epsilon)}\|_{{\mathscr{H}}_{\mathbbm{k}}}\ \!\leq\ \!\Big(\frac{1}{\lambda}\sum_{t\in{\mathscr{T}}}y_{t}^{2}\Big)^{\frac{1}{2}}.

(35)

Moreover, if
\mathrm{mesh}({\mathscr{P}})\leq\frac{2\epsilon}{L}
where

L:=\frac{1}{\lambda}4\mu_{0}\mu_{1}\sum_{t\in{\mathscr{T}}}y_{i}^{2}
,
then we have

\|G^{(\star,\epsilon)}\|_{{\mathcal{H}}_{\infty}}=\sup_{\omega\in\Omega_{{\mathbb{T}}}}|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|\leq 1.

(36)

where
G^{(\star,\epsilon)}
is the transfer function corresponding to
{\mathrm{g}}^{(\star,\epsilon)}
.

Proof.

Due to the definition of set
{\mathscr{G}}_{\mathbbm{k}}
in (
21
), we know that the feasible set of optimization problem (
30
) is
{\mathscr{G}}_{\mathbbm{k}}((1-\epsilon)^{\frac{1}{2}},{\mathscr{P}})
.
Subsequently, problem (
30
) can be written as

\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathcal{G}}_{\mathbbm{k}}((1-\epsilon)^{\frac{1}{2}},{\mathscr{P}})}\ \ \operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{i}({\mathrm{g}})-y_{i})^{2}+\lambda\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2}.

(37)

Then, according to Theorem
6
, the optimization problem (
37
) as well as (
30
), is a convex program with unique solution, denoted by
{\mathrm{g}}^{(\star,\epsilon)}
, which satisfies (
35
).

Let
\omega\in[0,\omega_{\mathrm{max}}]
.
If
\omega\in{\mathscr{P}}
, then
|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|\leq(1-\epsilon)^{\frac{1}{2}}\leq 1
.
If
\omega\notin{\mathscr{P}}
, then there exists
i\in\{1,\ldots,n\}
, such that
\omega\in(\omega_{i-1},\omega_{i})
.
If
|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|>1
, then, due to Lemma
9
and
|{\mathcal{F}}_{\omega_{i-1}}({\mathrm{g}}^{(\star,\epsilon)})|^{2},|{\mathcal{F}}_{\omega_{i}}({\mathrm{g}}^{(\star,\epsilon)})|^{2}\leq 1-\epsilon
, we know that

\begin{split}\epsilon&<\Big|\ |{\mathcal{F}}_{\omega_{i}}({\mathrm{g}}^{(\star,\epsilon)})|^{2}-|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|^{2}\Big|\\
&\ \ =|m_{{\mathrm{g}}^{(\star,\epsilon)}}(\omega_{i})-m_{{\mathrm{g}}^{(\star,\epsilon)}}(\omega)|\!\leq\!L_{{\mathrm{g}}^{(\star,\epsilon)}}|\omega_{i}-\omega|,\\
\epsilon&<\Big|\ |{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|^{2}-|{\mathcal{F}}_{\omega_{i-1}}({\mathrm{g}}^{(\star,\epsilon)})|^{2}\Big|\\
&\ \ =|m_{{\mathrm{g}}^{(\star,\epsilon)}}(\omega)-m_{{\mathrm{g}}^{(\star,\epsilon)}}(\omega_{i-1})|\!\leq\!L_{{\mathrm{g}}^{(\star,\epsilon)}}|\omega-\omega_{i-1}|,\end{split}

(38)

where
L_{{\mathrm{g}}^{(\star,\epsilon)}}=4\mu_{0}\mu_{1}\|{\mathrm{g}}^{(\star,\epsilon)}\|^{2}
.
Therefore, since
|\omega_{i}-\omega_{i-1}|\leq\mathrm{mesh}({\mathscr{P}})
, we have that
2\epsilon<L_{{\mathrm{g}}^{(\star,\epsilon)}}\mathrm{mesh}({\mathscr{P}})
.
Subsequently, it follows that

\!\mathrm{mesh}({\mathscr{P}})\!>\!\frac{2\epsilon}{L_{{\mathrm{g}}^{(\epsilon)}}}\!=\!\frac{2\epsilon}{4\mu_{0}\mu_{1}\|{\mathrm{g}}^{(\epsilon)}\|^{2}}\!\geq\!\frac{2\epsilon\lambda}{4\mu_{0}\mu_{1}\!\sum_{t\in{\mathscr{T}}}\!y_{t}^{2}}\!=\!\frac{2\epsilon}{L},\!

which contradicts with
\mathrm{mesh}({\mathscr{P}})\leq\frac{2\epsilon}{L}
.
Therefore, we have
|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\epsilon)})|\leq 1
. This shows that
\|G^{(\star,\epsilon)}\|_{{\mathcal{H}}_{\infty}}=\sup_{\omega\in[0,\omega_{\mathrm{max}}]}|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|\leq 1
, which concludes the proof for the case
{\mathbb{T}}={\mathbb{Z}}_{+}
where we have
\omega_{\mathrm{max}}=\pi
.
Now, we consider the case
{\mathbb{T}}={\mathbb{R}}_{+}
and let
\omega>\omega_{\mathrm{max}}
.
Due to Lemma
3
and the Cauchy-Schwartz inequality, we know that

\begin{split}|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|^{2}&=|{\langle{{\mathrm{g}}^{(\star,\epsilon)},\varphi_{\omega}^{\text{\rm{(r)}}}}\rangle}|^{2}+|{\langle{{\mathrm{g}}^{(\star,\epsilon)},\varphi_{\omega}^{\text{\rm{(i)}}}}\rangle}|^{2}\\
&\leq\|{\mathrm{g}}^{(\star,\epsilon)}\|^{2}\ \Big[\|\varphi_{\omega}^{\text{\rm{(r)}}}\|^{2}+\|\varphi_{\omega}^{\text{\rm{(i)}}}\|^{2}\Big].\end{split}

(39)

On other hand, from (
18
), (
15
), and
(
33
), we have

\begin{split}\|\varphi_{\omega}^{\text{\rm{(r)}}}&\|^{2}+\|\varphi_{\omega}^{\text{\rm{(i)}}}\|^{2}={\langle{\varphi_{\omega}^{\text{\rm{(r)}}},\varphi_{\omega}^{\text{\rm{(r)}}}}\rangle}^{2}+{\langle{\varphi_{\omega}^{\text{\rm{(i)}}},\varphi_{\omega}^{\text{\rm{(i)}}}}\rangle}^{2}\\
&=\int_{{\mathbb{R}}_{+}}\!\!\!\varphi_{\omega,t}^{\text{\rm{(r)}}}\cos(\omega t)\mathrm{d}t+\int_{{\mathbb{R}}_{+}}\!\!\!\varphi_{\omega,t}^{\text{\rm{(i)}}}\sin(\omega t)\mathrm{d}t\\
&=\int_{{\mathbb{R}}_{+}}\!\int_{{\mathbb{R}}_{+}}\!\mathbbm{k}(t,s)\cos(\omega s)\cos(\omega t)\mathrm{d}s\mathrm{d}t\\
&\qquad+\int_{{\mathbb{R}}_{+}}\!\int_{{\mathbb{R}}_{+}}\!\mathbbm{k}(t,s)\sin(\omega s)\sin(\omega t)\mathrm{d}s\mathrm{d}t\\
&=\int_{{\mathbb{R}}_{+}}\!\int_{{\mathbb{R}}_{+}}\!\mathbbm{k}(t,s)\mathrm{e}^{-\mathrm{j}\omega(s-t)}\mathrm{d}s\mathrm{d}t\leq\frac{\lambda}{\sum_{t\in{\mathscr{T}}}y_{t}^{2}},\end{split}

(40)

where the last equality is due to the fact that
\int_{{\mathbb{R}}_{+}}\!\int_{{\mathbb{R}}_{+}}\!\mathbbm{k}(t,s)\sin(\omega(s-t))\mathrm{d}s\mathrm{d}t=0
which is a result of
\mathbbm{k}(t,s)=\mathbbm{k}(s,t)
and
\sin(\omega(s-t))=-\sin(\omega(t-s))
.
Accordingly, due to
(
39
) and (
35
), we have

|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|^{2}\leq 1
. This shows that

\|G^{(\star,\epsilon)}\|_{{\mathcal{H}}_{\infty}}=\sup_{\omega\in\Omega_{{\mathbb{T}}}}|{\mathcal{F}}_{\omega}({\mathrm{g}}^{(\star,\epsilon)})|\leq 1
and concludes the proof.
∎

Due to Theorem
11
, we know that (
30
) admits a unique solution.
While this optimization problem is defined over the infinite-dimensional Hilbert space
{\mathscr{H}}_{\mathbbm{k}}
, we can find its unique solution
{\mathrm{g}}^{(\star,\epsilon)}
by solving an equivalent convex finite-dimensional program.
This feature which makes (
30
) a tractable problem, is due to the structure of the RKHS
{\mathscr{H}}_{\mathbbm{k}}
and the
Representer Theorem
,
provided below.

Theorem 12

(Representer Theorem,
[
59
,
60
]
)
.

Let
e:{\mathbb{R}}^{m}\to{\mathbb{R}}\cup\{+\infty\}
and
r:{\mathbb{R}}_{+}\to{\mathbb{R}}
be functions such that
r
is an increasing function. Also, let
{\mathcal{H}}
be a Hilbert space with inner product
{\langle{\cdot,\cdot}\rangle}_{{\mathcal{H}}}
. Consider the optimization problem

\min_{{\mathrm{w}}\in{\mathcal{H}}}\ e({\langle{{\mathrm{w}}_{1},{\mathrm{w}}}\rangle}_{{\mathcal{H}}},\ldots,{\langle{{\mathrm{w}}_{m},{\mathrm{w}}}\rangle}_{{\mathcal{H}}})+r(\|{\mathrm{w}}\|_{{\mathcal{H}}}),

(41)

where
{\mathrm{w}}_{1},\ldots,{\mathrm{w}}_{m}\in{\mathcal{H}}
are given vectors. Then, if (
41
) admits a solution, it has also a solution in
{\mathscr{W}}:=\mathrm{span}\{{\mathrm{w}}_{i}\}_{i=1}^{m}
.

In order to present the tractable finite-dimensional optimization problem equivalent to (
30
), additional definitions are required. Define
m:=n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}+2
and the index sets

{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}:=\{0,1,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}-1\}
,

{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}:=\{0,1,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}\}
,
and
{\mathcal{I}}:=\{0,1,\ldots,m-1\}
.
Let

\{\varphi_{i}\}_{i=0}^{m-1}

be vectors defined as

\begin{cases}\varphi_{i}:=\varphi_{t_{i}}^{\text{\rm{(u)}}},&\text{ for }i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}},\\
\varphi_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j}:=\varphi_{\omega_{j}}^{\text{\rm{(r)}}},&\text{ for }j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}},\\
\varphi_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+1}:=\varphi_{\omega_{j}}^{\text{\rm{(i)}}},&\text{ for }j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}.\end{cases}

(42)

Let
\Phi\in{\mathbb{R}}^{m\times m}
be a symmetric matrix such that its entry at
the
i^{\text{\tiny{th}}}
row and
the
j^{\text{\tiny{th}}}
column is
{\langle{\varphi_{i-1},\varphi_{j-1}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}
, for
i,j=1,\ldots,m
.
One can see that
\Phi
is the Gram matrix of vectors
\varphi_{0},\ldots,\varphi_{m-1}
.
Moreover, for
i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}
, we define vector
{\mathrm{a}}_{i}\in{\mathbb{R}}^{m}
as
the
(i+1)^{\text{\tiny{th}}}
column of
\Phi
.
Similarly, vectors
{\mathrm{b}}_{j}\in{\mathbb{R}}^{m}
and
{\mathrm{c}}_{j}\in{\mathbb{R}}^{m}
are defined respectively as the

(n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+1)^{\text{\tiny{th}}}
and the

(n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+2)^{\text{\tiny{th}}}
column of
\Phi
, for
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
.
In the followings, without loss of generality, we assume that
\varphi_{0},\ldots,\varphi_{m-1}
are linearly independent. Indeed, if for some
i\in{\mathcal{I}}
, the vector
\varphi_{i}
belongs to
\mathrm{span}\{\varphi_{j}|j\in{\mathcal{I}}\backslash\{i\}\}
, it does not have any additional information and one can replace it with a linear combination of
\{\varphi_{j}|j\in{\mathcal{I}}\backslash\{i\}\}
.

Based on the introduced notations, we can present the theorem on the equivalent tractable finite-dimensional program.

Theorem 13
.

The unique solution of optimization problem (
30
),
{\mathrm{g}}^{(\star,\epsilon)}
, is in the following linear form

{\mathrm{g}}^{(\star,\epsilon)}=\sum_{i=0}^{m-1}x_{i}\varphi_{i},

(43)

where
{\mathrm{x}}:=\begin{bmatrix}x_{0}&x_{1}&\ldots&x_{m-1}\end{bmatrix}^{\mathsf{\scriptscriptstyle T}}\in{\mathbb{R}}^{m}
is the unique solution of the following convex program

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{x}}\in{\mathbb{R}}^{m}}&\sum_{i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}}({\mathrm{a}}_{i}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}-y_{i})^{2}+\lambda{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\Phi{\mathrm{x}}\\
\mathrm{s.t.}&({\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}+({\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}\leq 1-\epsilon,\quad\forall j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}.\end{array}

(44)

Proof.

Define
{\mathcal{E}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}\cup\{+\infty\}
as

{\mathcal{E}}({\mathrm{g}}):=\sum_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\sum_{\omega\in{\mathscr{P}}}\delta_{\{|{\mathcal{F}}_{\omega}|^{2}\leq 1-\epsilon\}}({\mathrm{g}}).

(45)

Since
{\mathscr{P}}=\{\omega_{0},\ldots,\omega_{n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}}\}
is a finite set, the summation in (
45
) is well-defined.
We know that optimization problem (
30
)
is equivalent to
\min_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}{\mathcal{E}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})
,
where
{\mathcal{R}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}
is defined as
{\mathcal{R}}({\mathrm{g}})=\|{\mathrm{g}}\|^{2}
(see Section
IV-B
).
Let function

e:{\mathbb{R}}^{m}\to{\mathbb{R}}\cup\{+\infty\}
be defined such that for any
{\mathrm{z}}=(z_{i})_{i=0}^{m-1}\in{\mathbb{R}}^{m}
we have

e({\mathrm{z}}):=\sum_{i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}}(z_{i}-y_{t_{i}})^{2}+\sum_{j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}}\delta_{{\mathscr{A}}_{j}}({\mathrm{z}}),

(46)

where, for each
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
,
{\mathscr{A}}_{j}\subseteq{\mathbb{R}}^{m}
is the following set

{\mathscr{A}}_{j}:=\bigg\{(z_{i})_{i=0}^{m-1}\in{\mathbb{R}}^{n}\bigg|z_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j}^{2}+z_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+1}^{2}\leq 1-\epsilon\bigg\},

(47)

Also, let
r:{\mathbb{R}}_{+}\to{\mathbb{R}}
be a function defined as
r(z)=\lambda z^{2}
, which is an increasing function.
For
i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}
and

j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
, we know that
{\mathrm{L}}^{\!{\mathrm{u}}}_{t_{i}}({\mathrm{g}})={\langle{\varphi_{i},{\mathrm{g}}}\rangle}
,
{\mathcal{F}}_{\omega_{j}}^{\text{\rm{(r)}}}({\mathrm{g}})={\langle{\varphi_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j},{\mathrm{g}}}\rangle}

and

{\mathcal{F}}_{\omega_{j}}^{\text{\rm{(r)}}}({\mathrm{g}})={\langle{\varphi_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+1},{\mathrm{g}}}\rangle}
.
Accordingly, we have

{\mathcal{E}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})=e({\langle{\varphi_{0},{\mathrm{g}}}\rangle},\ldots,{\langle{\varphi_{m-1},{\mathrm{g}}}\rangle})+r(\|{\mathrm{g}}\|).

From Theorem
11
, it follows that

\min_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}{\mathcal{E}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})
has a unique solution denoted by
{\mathrm{g}}^{(\star,\epsilon)}
.
Therefore, due to Theorem
12
, it has a solution which belongs to
{\mathscr{W}}=\ \mathrm{span}\{\varphi_{i}\}_{i=0}^{m-1}
.
From the uniqueness of the solution of (
30
), it follows that
{\mathrm{g}}^{(\star,\epsilon)}
belongs to
{\mathscr{W}}
.
Therefore, in order to find
{\mathrm{g}}^{(\star,\epsilon)}
, we need to obtain the corresponding coefficients in linear representation (
43
).
Accordingly, we replace
{\mathrm{g}}
in
\min_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}{\mathcal{E}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})
, or equivalently in (
30
), by
{\mathrm{g}}=\sum_{i=0}^{m-1}x_{i}\varphi_{i}
, and solve the problem for
{\mathrm{x}}:=[x_{i}]_{i=0}^{m-1}\in{\mathbb{R}}^{m}
.
Due to the linearity of inner product and the definition of matrix
\Phi
,
we have

\begin{split}{\mathcal{R}}({\mathrm{g}})={\langle{{\mathrm{g}},{\mathrm{g}}}\rangle}=\sum_{i=0}^{m-1}\sum_{j=0}^{m-1}x_{i}x_{j}{\langle{\varphi_{i},\varphi_{j}}\rangle}={\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\Phi{\mathrm{x}}.\end{split}

(48)

Also, for each
i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}
, due to the definition of
{\mathrm{a}}_{i}
, one has

{\mathrm{L}}^{\!{\mathrm{u}}}_{t_{i}}({\mathrm{g}})\!=\!\langle{\varphi_{i}},{\sum_{k=0}^{m-1}\!x_{k}\varphi_{k}}\rangle\!=\!\sum_{k=0}^{m-1}\!x_{k}{\langle{\varphi_{i},\varphi_{k}}\rangle}\!=\!{\mathrm{a}}_{i}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}.

(49)

Similarly, from the definition of vectors
{\mathrm{b}}_{j}
and
{\mathrm{c}}_{j}
, one has

{\mathcal{F}}_{\omega_{j}}^{\text{\rm{(r)}}}({\mathrm{g}})={\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}
and
{\mathcal{F}}_{\omega_{j}}^{\text{\rm{(i)}}}({\mathrm{g}})={\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}
,
for each
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
.
Therefore, from (
45
), it follows that

{\mathcal{E}}({\mathrm{g}})={\mathcal{E}}(\sum_{k=0}^{m-1}x_{k}\varphi_{k})=\sum_{i=0}^{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}-1}({\mathrm{a}}_{i}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}-y_{i})^{2}+\sum_{j=0}^{n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}}\delta_{{\mathscr{B}}_{j}}({\mathrm{x}}),

where, for each
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
,
{\mathscr{B}}_{j}\subseteq{\mathbb{R}}^{m}
is the set defined as

\!\!{\mathscr{B}}_{j}:=\bigg\{{\mathrm{x}}\!=\!(x_{i})_{i=0}^{m-1}\in{\mathbb{R}}^{m}\ \!\bigg|\ \!({\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}+({\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}\leq 1-\epsilon\bigg\}.

Accordingly, solving

\min_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}{\mathcal{E}}({\mathrm{g}})+\lambda{\mathcal{R}}({\mathrm{g}})

reduces to

\min_{{\mathrm{x}}\in{\mathbb{R}}^{m}}\sum_{i=0}^{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}-1}({\mathrm{a}}_{i}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}-y_{i})^{2}+\sum_{j=0}^{n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}}\delta_{{\mathscr{B}}_{j}}({\mathrm{x}})+\lambda{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\Phi{\mathrm{x}},

(50)

which is equivalent to (
44
).
Since
{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\Phi{\mathrm{x}}=\|\sum_{i=0}^{m-1}x_{i}\varphi_{i}\|^{2}
and
\{\varphi_{i}\}_{i=0}^{m-1}
are linearly independent,
\Phi
is a positive definite matrix. Therefore, the cost function in
(
44
)
is strongly convex.
Also, for each
j=0,\ldots,n_{{\scalebox{.5}{$\!{\mathscr{P}}$}}}
, we have

({\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}+({\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}={\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}({\mathrm{b}}_{j}{\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}+{\mathrm{c}}_{j}{\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}){\mathrm{x}},

(51)

and
{\mathrm{b}}_{j}{\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}+{\mathrm{c}}_{j}{\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}
is a positive semi-definite matrix.
Consequently, the feasible set in
(
44
)
is a convex and closed set.
Moreover, since
\epsilon<1
, we know that
{\mathrm{g}}=\mathbf{0}
is a feasible point of
(
44
).
Therefore, the optimization problem
(
44
)
is a convex program with a unique solution.
This concludes the proof.
∎

Before proceeding further, we present a corollary which is useful in the implementation of the proposed approach.
Let
\overline{{\mathscr{P}}}:=\{\overline{\omega}_{i}\}_{i=0}^{n_{{{\scalebox{.5}{$\overline{{\mathscr{P}}}$}}}}}\subseteq{\mathscr{P}}
,
{\mathcal{I}}^{{\scalebox{.63}{$(\overline{\mathscr{P}})$}}}:=\{0,1,\ldots,n_{{{\scalebox{.5}{$\overline{{\mathscr{P}}}$}}}}\}
and
\overline{m}:=n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2n_{{{\scalebox{.5}{$\overline{{\mathscr{P}}}$}}}}+2
.
Accordingly, similar to
\Phi
and
\{\varphi_{i}\}_{i=0}^{m-1}
, we define
\overline{\Phi}
and
\{\overline{\varphi}_{i}\}_{i=0}^{\overline{m}-1}
.
Also, for
i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}
and
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\overline{\mathscr{P}})$}}}
, let
\overline{{\mathrm{a}}}_{i}
,
\overline{{\mathrm{b}}}_{j}
and
\overline{{\mathrm{c}}}_{j}
be defined similar to

{\mathrm{a}}_{i}
,
{\mathrm{b}}_{j}
and
{\mathrm{c}}_{j}
, respectively.

Corollary 14
.

Consider the following optimization problem

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}&\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2},\\
\mathrm{s.t.}&|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}\leq 1-\epsilon,\quad\forall\omega\in\overline{{\mathscr{P}}}.\end{array}

(52)

Then, (
52
) has a unique solution denoted by
\overline{{\mathrm{g}}}^{(\star,\epsilon)}
.
This solution satisfies (
35
), and admits
a parametric form as
\overline{{\mathrm{g}}}^{(\star,\epsilon)}=\sum_{i=0}^{\overline{m}-1}x_{i}\overline{\varphi}_{i}

where
{\mathrm{x}}=[x_{i}]_{i=0}^{\overline{m}-1}
is the solution of the following convex program

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{x}}\in{\mathbb{R}}^{\overline{m}}}&\sum_{i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}}(\overline{{\mathrm{a}}}_{i}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}}-y_{i})^{2}+\lambda{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\overline{\Phi}{\mathrm{x}}\\
\mathrm{s.t.}&(\overline{{\mathrm{b}}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}+(\overline{{\mathrm{c}}}_{j}^{\mathsf{\scriptscriptstyle T}}{\mathrm{x}})^{2}\leq 1-\epsilon,\quad\forall j\in{\mathcal{I}}^{{\scalebox{.63}{$(\overline{\mathscr{P}})$}}}.\end{array}

(53)

Moreover, if
|{\mathcal{F}}_{\omega}(\overline{{\mathrm{g}}}^{(\star,\epsilon)})|^{2}\leq 1-\epsilon
, for all
\omega\in{\mathscr{P}}
, then

\overline{{\mathrm{g}}}^{(\star,\epsilon)}
coincides with
{\mathrm{g}}^{(\star,\epsilon)}
.

Proof.

Using similar lines of arguments for the proof of Theorem
11
, one can show the existence and uniqueness of the solution of (
52
).
The parametric form of
\overline{{\mathrm{g}}}^{(\star,\epsilon)}
and the fact that
{\mathrm{x}}
is the solution of (
53
) can be concluded based on a proof similar to the proof of Theorem
13
.

Since, for each
\omega\in{\mathscr{P}}
, one has
|{\mathcal{F}}_{\omega}(\overline{{\mathrm{g}}}^{(\star,\epsilon)})|^{2}\leq 1-\epsilon
, we know that
\overline{{\mathrm{g}}}^{(\star,\epsilon)}
is feasible for optimization (
30
). Therefore, being
{\mathrm{g}}^{(\star,\epsilon)}
the optimal solution of (
30
), it follows that

{\mathcal{L}}_{{\mathscr{D}}}({\mathrm{g}}^{(\star,\epsilon)})+\lambda{\mathcal{R}}({\mathrm{g}}^{(\star,\epsilon)})\leq{\mathcal{L}}_{{\mathscr{D}}}(\overline{{\mathrm{g}}}^{(\star,\epsilon)})+\lambda{\mathcal{R}}(\overline{{\mathrm{g}}}^{(\star,\epsilon)}),
where
{\mathcal{L}}_{{\mathscr{D}}}
is defined in (
8
). Also, we know that the feasible set in (
30
) is a subset of feasible set of (
52
). Accordingly, since
\overline{{\mathrm{g}}}^{(\star,\epsilon)}
is the optimal solution for (
52
), we have

{\mathcal{L}}_{{\mathscr{D}}}(\overline{{\mathrm{g}}}^{(\star,\epsilon)})+\lambda{\mathcal{R}}(\overline{{\mathrm{g}}}^{(\star,\epsilon)})\leq{\mathcal{L}}_{{\mathscr{D}}}({\mathrm{g}}^{(\star,\epsilon)})+\lambda{\mathcal{R}}({\mathrm{g}}^{(\star,\epsilon)}).
Therefore,
\overline{{\mathrm{g}}}^{(\star,\epsilon)}
is an optimizer of (
30
). Consequently, from the uniqueness of the solution of (
30
), we have
\overline{{\mathrm{g}}}^{(\star,\epsilon)}={\mathrm{g}}^{(\star,\epsilon)}
, and concludes the proof.

Theorem

Accordingly, in order to solve (

Nevertheless, first we should verify that solving optimization problem (

).
This is addressed by the next theorem.

Theorem 15
.

Let

{\mathrm{L}}^{\!{\mathrm{u}}}:{\mathscr{H}}_{\mathbbm{k}}\to{\mathbb{R}}^{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}}

Moreover, we have
\operatornamewithlimits{lim}\limits_{\epsilon\to\mathbf{0}}{\mathrm{g}}^{(\star,\epsilon)}={\mathrm{g}}^{\star}
in

.
Furthermore, if
\sup_{t\in{\mathbb{T}}}\mathbbm{k}(t,t)^{\frac{1}{2}}\!<\!\infty

.

Proof.

See Appendix
A-F
.

Remark 2
.

The property
\sup_{t\in{\mathbb{T}}}\mathbbm{k}(t,t)^{\frac{1}{2}}<\infty
is satisfied
by the TC kernel and other common kernels in the literature, such as the

[

]
.

Remark 3
.

In the case of incorrect side-information, we have
{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}\notin{\mathscr{G}}_{\mathbbm{k}}(1,\Omega_{{\mathbb{T}}})
.
Let
{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}_{\perp}\in{\mathscr{H}}_{\mathbbm{k}}
be the projection of
{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}
on
{\mathscr{G}}_{\mathbbm{k}}(1,\Omega_{{\mathbb{T}}})
, i.e.,

{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}_{\perp}
is defined as

{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}_{\perp}:={\mathrm{argmin}}_{{\mathrm{g}}\in{\mathscr{G}}_{\mathbbm{k}}(1,\Omega_{{\mathbb{T}}})}\|{\mathrm{g}}-{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}\|_{{\mathscr{H}}_{\mathbbm{k}}},

(55)

which exists uniquely (due to Theorem
4
and
[
58
]
).
Due to the definition of
{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}_{\perp}
and since
{\mathrm{g}}^{\star},{\mathrm{g}}^{(\star,\epsilon)}\in{\mathscr{G}}_{\mathbbm{k}}(1,\Omega_{{\mathbb{T}}})
(see Theorem
11
), we have

0<\|{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}-{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}_{\perp}\|_{{\mathscr{H}}_{\mathbbm{k}}}\leq\|{\mathrm{g}}^{{\scalebox{.5}{$({\mathcal{S}})$}}}-{\mathrm{g}}^{\star}\|_{{\mathscr{H}}_{\mathbbm{k}}},

(56)

and

In other words, we have a systematic bias in the estimated impulse response
{\mathrm{g}}^{\star}
, and also, in its approximation

, for all

.
Accordingly, in this situation, not including the side-information may result in a more accurate identified model.

VI
Optimization Algorithm

Due to Theorem
13
, the problem to be solved is

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{x}}\in{\mathbb{R}}^{m}}&\|{\mathrm{A}}{\mathrm{x}}-{\mathrm{y}}\|^{2}+\lambda{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}\Phi{\mathrm{x}}\\
\mathrm{s.t.}&{\mathrm{x}}^{\mathsf{\scriptscriptstyle T}}({\mathrm{b}}_{j}{\mathrm{b}}_{j}^{\mathsf{\scriptscriptstyle T}}+{\mathrm{c}}_{j}{\mathrm{c}}_{j}^{\mathsf{\scriptscriptstyle T}}){\mathrm{x}}\leq 1-\epsilon,\quad\forall j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}},\end{array}

(58)

where
{\mathrm{A}}:=[{\mathrm{a}}_{0},\ldots,{\mathrm{a}}_{n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}-1}]^{\mathsf{\scriptscriptstyle T}}
and

{\mathrm{y}}:=[y_{t}]_{t\in{\mathscr{T}}}
.
From the definition of matrix
{\mathrm{A}}
, we know that
{\mathrm{A}}
is the first
n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}
rows of
\Phi
. Also,
{\mathrm{b}}_{j}
and
{\mathrm{c}}_{j}
are respectively
the
(n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+1)^{\text{\tiny{th}}}
and
the
(n_{{\scalebox{.5}{$\!{\mathscr{D}}$}}}+2j+2)^{\text{\tiny{th}}}
column of
\Phi
, for
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathscr{P})$}}}
.
Therefore, being matrix
\Phi
given is sufficient for setting up the optimization problem (
58
). To this end, for each
i,j\in{\mathcal{I}}
, we need to obtain the value of
{\langle{\varphi_{i},\varphi_{j}}\rangle}_{{\mathscr{H}}_{\mathbbm{k}}}
, which demands calculating an infinite double summation, when
{\mathbb{T}}={\mathbb{Z}}_{+}
, or an improper double integral, when
{\mathbb{T}}={\mathbb{R}}_{+}
.
In general, to obtain these values one should employ numerical methods which are essentially inexact and also computationally demanding.
Meanwhile, one can derive these values analytically in specific but rather general situations, e.g., when the TC kernel is employed (see Appendix
A-G
for more details).
Note that (
58
) is a convex
quadratically constrained quadratic program
program, for which there exist various efficient methods
[
61
]
.
For example, we can utilize methods which are based on
log-barrier functions

[
61
]
and adapt them suitably to the current settings (see Appendix
A-H
for more details).

In many situations, such as in the example given in Section
III
, the constraint
|G(\mathrm{j}\omega)|=|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}\leq 1-\epsilon
is not binding on the whole frequency range
\Omega_{{\mathbb{T}}}
. Accordingly, it is not required to impose this constraint for each
\omega\in{\mathscr{P}}
. Motivated by this fact and Corollary
14
, we can introduce an iterative scheme. More precisely, let
\overline{{\mathscr{P}}}_{0}:=\emptyset
, and at iteration
k
, let
\overline{{\mathscr{P}}}_{k}
be a given subset of
{\mathscr{P}}
.
Consider the optimization problem (
30
) where only the constraints corresponding to the frequencies in
\overline{{\mathscr{P}}}_{k}
are imposed, i.e., we have the following program

\begin{array}[]{cl}\operatornamewithlimits{min}\limits_{{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}}&\operatornamewithlimits{\sum}\limits_{t\in{\mathscr{T}}}({\mathrm{L}}^{\!{\mathrm{u}}}_{t}({\mathrm{g}})-y_{t})^{2}+\lambda\ \!\|{\mathrm{g}}\|_{{\mathscr{H}}_{\mathbbm{k}}}^{2},\\
\mathrm{s.t.}&|{\mathcal{F}}_{\omega}({\mathrm{g}})|^{2}\leq 1-\epsilon,\quad\forall\omega\in\overline{{\mathscr{P}}}_{k}.\end{array}

(59)

Due to Corollary
14
, we know that (
59
) has a unique solution, denoted by
{\mathrm{g}}_{k}
, which can be obtained by solving an equivalent finite-dimensional convex program as in (
53
).
Given
{\mathrm{g}}_{k}
, one can check whether the constraint
|{\mathcal{F}}_{\omega}({\mathrm{g}}_{k})|^{2}\leq 1-\epsilon
is violated on the remaining frequencies in
{\mathscr{P}}
. Accordingly, one can obtain the following set

\Delta_{k}{\mathscr{P}}:=\Big\{\omega\in{\mathscr{P}}\backslash\overline{{\mathscr{P}}}_{k}\ \Big|\ |{\mathcal{F}}_{\omega}({\mathrm{g}}_{k})|^{2}>1-\epsilon\Big\},

(60)

Subsequently, we update the frequency set as
\overline{{\mathscr{P}}}_{k+1}:=\overline{{\mathscr{P}}}_{k}\cup\Delta_{k}{\mathscr{P}}
, and proceed to the iteration
k+1
.
The iterative scheme stops when
\Delta_{k}{\mathscr{P}}=\emptyset
.
This happens either when
\overline{{\mathscr{P}}}_{k}={\mathscr{P}}
or the solution
{\mathrm{g}}_{k}
satisfies the constraint
|{\mathcal{F}}_{\omega}({\mathrm{g}}_{k})|^{2}\leq 1-\epsilon
for all
\omega\in{\mathscr{P}}
.
Consequently, due to Corollary
14
, we have
{\mathrm{g}}_{k}={\mathrm{g}}^{(\star,\epsilon)}
when the stopping condition is met.
It is noteworthy that given matrix
\Phi
, one can extract
\overline{\Phi}_{k}
as a sub-matrix of
\Phi
, and subsequently, the corresponding vectors
\overline{{\mathrm{a}}}_{i}
,
\overline{{\mathrm{b}}}_{j}
and
\overline{{\mathrm{c}}}_{j}
in (
53
) are obtained as columns of
\overline{\Phi}_{k}
.
This fact improves the computational tractability of the proposed approach.
The Algorithm
1
summarizes the introduced iterative scheme.

Algorithm 1

Kernel-Based Identification with Frequency Domain Side Information

\|G^{({\mathcal{S}})}\|_{{\mathcal{H}}_{\infty}}\leq 1

1:

input:
data set
{\mathscr{D}}
, partition set
{\mathscr{P}}
, kernel
\mathbbm{k}
,
\epsilon\in(0,1)
, matrix
\Phi
, unconstrained estimation
{\mathrm{g}}_{0}

2:

k\leftarrow 0
and
{\mathrm{g}}_{k}\leftarrow{\mathrm{g}}_{0}
.

3:

\overline{{\mathscr{P}}}_{k}\leftarrow\emptyset
and get
\Delta_{k}{\mathscr{P}}
due to (
60
).

4:

while

\Delta_{k}{\mathscr{P}}\neq\emptyset

do

5:

\overline{{\mathscr{P}}}\leftarrow\overline{{\mathscr{P}}}_{k}\cup\Delta{\mathscr{P}}_{k}
.

6:

update
\overline{\Phi}
,
\overline{{\mathrm{a}}}_{i}
for
i\in{\mathcal{I}}^{{\scalebox{.63}{$(\mathrm{u})$}}}
,
\overline{{\mathrm{b}}}_{j}
and
\overline{{\mathrm{c}}}_{j}
, for
j\in{\mathcal{I}}^{{\scalebox{.63}{$(\overline{\mathscr{P}})$}}}
.

7:

solve optimization problem (
53
) and
{\mathrm{g}}_{k}\leftarrow\sum_{i}x_{i}\overline{\varphi}_{i}
.

8:

{\mathscr{P}}_{k}\leftarrow\overline{{\mathscr{P}}}
and get
\Delta_{k}{\mathscr{P}}
due to (
60
).

9:

end

10:

Output:

{\mathrm{g}}^{(\star,\epsilon)}

This procedure generates
a strictly increasing sequence of sets
\emptyset=\overline{{\mathscr{P}}}_{0}\subset\overline{{\mathscr{P}}}_{1}\subset\overline{{\mathscr{P}}}_{2}\subset\ldots\subset{\mathscr{P}}
. Since
{\mathscr{P}}
is a finite set, this sequence needs to be finite and therefore, Algorithm
1
stops after finite number of iterations.

VIII
Conclusion

The problem identification with side information on the dissipativity of the system has been studied in this paper.
We have employed a RKHS frame work allowing considering both of the discrete-time and continuous-time dynamics.
The problem is initially formulated as an infinite-dimensional optimization problem estimating a stable impulse response fitting to the data and satisfying an
{\mathcal{H}}_{\infty}
-norm constraint.
We have shown that the problem is well-defined and convex with a unique solution.
To obtain the solution, we have proposed a heuristic tightly approximating the solution. It is shown that the proposed approach is equivalent to solve a finite-dimensional convex quadratically constrained quadratic programming.
The efficiency of the discussed method is verify by several numerical examples.

Proof of Lemma
3

Consider the case
{\mathbb{T}}={\mathbb{R}}_{+}
and let

{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}:=(g^{{\scalebox{.5}{$(1)$}}}_{t})_{t\in{\mathbb{R}}_{+}},{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}:=(g^{{\scalebox{.5}{$(2)$}}}_{t})_{t\in{\mathbb{R}}_{+}}\in{\mathscr{H}}_{\mathbbm{k}}
and

\alpha_{1},\alpha_{2}\in{\mathbb{C}}
.
Since
{\mathscr{H}}_{\mathbbm{k}}\subseteq{\mathscr{L}}_{1}
, we know that
\|{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}\|_{1}
and
\|{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}\|_{1}
are finite.
Also, for any
t\in{\mathbb{R}}_{+}
and any
\omega\in{\mathbb{R}}_{+}
, from triangle inequality, we have

|(\alpha_{1}g^{{\scalebox{.5}{$(1)$}}}_{t}+\alpha_{2}g^{{\scalebox{.5}{$(2)$}}}_{t})\ \mathrm{e}^{-\mathrm{j}\omega t}|\leq|\alpha_{1}||g^{{\scalebox{.5}{$(1)$}}}_{t}|+|\alpha_{2}||g^{{\scalebox{.5}{$(2)$}}}_{t}|
.
Hence,

\big((\alpha_{1}g^{{\scalebox{.5}{$(1)$}}}_{t}+\alpha_{2}g^{{\scalebox{.5}{$(2)$}}}_{t})\ \mathrm{e}^{-\mathrm{j}\omega t}\big)_{t\in{\mathbb{R}}_{+}}
is absolutely integrable. Therefore, the improper integral

{\mathcal{F}}_{\omega}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}):=\int_{{\mathbb{R}}_{+}}(\alpha_{1}g^{{\scalebox{.5}{$(1)$}}}_{t}+\alpha_{2}g^{{\scalebox{.5}{$(2)$}}}_{t})\ \mathrm{e}^{-\mathrm{j}\omega t}\mathrm{d}t

converges and we have

{\mathcal{F}}_{\omega}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}):=\alpha_{1}{\mathcal{F}}_{\omega}({\mathrm{g}}^{{\scalebox{.5}{$(1)$}}})+\alpha_{2}{\mathcal{F}}_{\omega}({\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}).

(64)

Therefore,
{\mathcal{F}}_{\omega}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}})
is a well-defined
{\mathbb{C}}
-valued linear map.
Moreover, from
\mathrm{e}^{-\mathrm{j}\omega t}=\cos(\omega t)-\mathrm{j}\sin(\omega t)
, one can easily see that

{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})=\mathrm{real}({\mathcal{F}}_{\omega}({\mathrm{g}}))
,

{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})=\mathrm{imag}({\mathcal{F}}_{\omega}({\mathrm{g}}))
, and

{\mathcal{F}}_{\omega}({\mathrm{g}})={\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})+\mathrm{j}{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})
, for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
.
Let
\alpha_{1},\alpha_{2}\in{\mathbb{R}}
and compare the real and imaginary parts of the left-hand side and right-hand side of (
64
). Hence, we have

\begin{array}[]{ccl}{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}})&=&\alpha_{1}{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}}^{{\scalebox{.5}{$(1)$}}})+\alpha_{2}{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}),\\
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}})&=&\alpha_{1}{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}}^{{\scalebox{.5}{$(1)$}}})+\alpha_{2}{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}}^{{\scalebox{.5}{$(2)$}}}),\end{array}

and also
|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}})|,|{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}(\alpha_{1}{\mathrm{g}}^{{\scalebox{.5}{$(1)$}}}+\alpha_{2}{\mathrm{g}}^{{\scalebox{.5}{$(2)$}}})|<\infty
.
This shows that
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}
and
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}
are well-defined linear maps.

Since
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})=\mathrm{real}({\mathcal{F}}_{\omega}({\mathrm{g}}))
, from triangle inequality and the definition of
{\mathcal{F}}_{\omega}
, one can see

\begin{split}|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}&({\mathrm{g}})|=|\mathrm{real}({\mathcal{F}}_{\omega}({\mathrm{g}}))|\\
&\leq|{\mathcal{F}}_{\omega}({\mathrm{g}})|=\bigg|\int_{{\mathbb{R}}_{+}}g_{t}\mathrm{e}^{-\mathrm{j}\omega t}\mathrm{d}t\bigg|\leq\int_{{\mathbb{R}}_{+}}|g_{t}|\mathrm{d}t,\end{split}

(65)

for any
{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}
.
Subsequently, due to the reproducing property and the Cauchy-Schwartz inequality, we have

|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})|\leq\int_{{\mathbb{R}}_{+}}|{\langle{{\mathrm{g}},\mathbbm{k}_{t}}\rangle}|\mathrm{d}t\leq\int_{{\mathbb{R}}_{+}}\|{\mathrm{g}}\|\|\mathbbm{k}_{t}\|\mathrm{d}t
.
From
\|\mathbbm{k}_{t}\|^{2}={\langle{\mathbbm{k}_{t},\mathbbm{k}_{t}}\rangle}=\mathbbm{k}(t,t)
and the definition of
\mu_{0}

|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})|\leq\mu_{0}\|{\mathrm{g}}\|
,
and hence, we have

\|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}\|_{{\mathcal{L}}({\mathscr{H}}_{\mathbbm{k}},{\mathbb{R}})}:=\sup_{\begin{subarray}{c}{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\\
\|{\mathrm{g}}\|\leq 1\end{subarray}}|{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}({\mathrm{g}})|\leq\sup_{\begin{subarray}{c}{\mathrm{g}}\in{\mathscr{H}}_{\mathbbm{k}}\\
\|{\mathrm{g}}\|\leq 1\end{subarray}}\mu_{0}\|{\mathrm{g}}\|=\mu_{0}.

Similarly, one can show that

\|{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}\|_{{\mathcal{L}}({\mathscr{H}}_{\mathbbm{k}},{\mathbb{R}})}\leq\mu_{0}
.
Therefore,
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}
and
{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}
are linear bounded functionals, i.e.,
{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}},{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}\in{\mathcal{L}}({\mathscr{H}}_{\mathbbm{k}},{\mathbb{R}})

Since
{\mathscr{H}}_{\mathbbm{k}}

\varphi_{\omega}^{\text{\rm{(r)}}}:=(\varphi_{\omega,t}^{\text{\rm{(r)}}})_{t\in{\mathbb{R}}_{+}}\in{\mathscr{H}}_{\mathbbm{k}}

\varphi_{\omega}^{\text{\rm{(i)}}}:=(\varphi_{\omega,t}^{\text{\rm{(i)}}})_{t\in{\mathbb{R}}_{+}}\in{\mathscr{H}}_{\mathbbm{k}}

and

{\mathcal{F}}_{\omega}^{\text{\rm{(i)}}}({\mathrm{g}})={\langle{\varphi_{\omega}^{\text{\rm{(i)}}},{\mathrm{g}}}\rangle}
.
Subsequently, from the reproducing property of kernel, for any
t\in{\mathbb{R}}_{+}
, we have that

\begin{array}[]{ll}&\varphi_{\omega,t}^{\text{\rm{(r)}}}={\langle{\varphi_{\omega}^{\text{\rm{(r)}}},\mathbbm{k}_{t}}\rangle}={\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}(\mathbbm{k}_{t})=\int_{{\mathbb{R}}_{+}}\!\!\!\mathbbm{k}(t,s)\cos(\omega s)\mathrm{d}s,\\
&\varphi_{\omega,t}^{\text{\rm{(i)}}}={\langle{\varphi_{\omega}^{\text{\rm{(i)}}},\mathbbm{k}_{t}}\rangle}\!=\!{\mathcal{F}}_{\omega}^{\text{\rm{(r)}}}(\mathbbm{k}_{t})=-\!\int_{{\mathbb{R}}_{+}}\!\!\!\mathbbm{k}(t,s)\sin(\omega s)\mathrm{d}s.\end{array}

This concludes the proof for the case
{\mathbb{T}}={\mathbb{R}}_{+}
.
Similar lines of arguments hold when

and the proof is concluded.
