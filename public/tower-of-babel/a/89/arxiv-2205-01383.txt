Enumeration of partial Łukasiewicz paths
Jean-Luc Baril, Helmut Prodinger

Abstract
Łukasiewicz paths are lattice paths in ℕ 2 \mathbb{N}^{2} starting at the origin, ending on the x x -axis, and consisting of steps in the set { ( 1 , k ) , k ≥ − 1 } \{(1,k),k\geq-1\} . We give generating function and exact value for the number of n n -length prefixes (resp. suffixes) of these paths ending at height k ≥ 0 k\geq 0 with a given type of step. We make a similar study for prefixes of height at most t ≥ 0 t\geq 0 . Using the explicit forms for the paths of bounded height, we evaluate the average height asymptotically. For fixed k k and n → ∞ n\to\infty , this quantity behaves as π ​ n \sqrt{\pi n} . Finally we study (in the same way) prefixes of alternate Łukasiewicz paths, i.e., Łukasiewicz paths that do contain two consecutive steps with the same direction.

In this paper, we provide enumerating results for several classes of partial Łukasiewicz paths (prefixes and suffixes of Łukasiewicz paths, partial alternate Łukasiewicz paths). More precisely, in Sections 2 and 3, we give generating functions and exact values for the number of

k\geq 0

t\geq 0

Section 5 deals with the average height of various families of the Łukasiewicz type.

6
The average height of Łukasiewicz paths

6.1
The left-to-right model

We can simplify the expressions given in the previous section using the (magic) substitution
z=\frac{u}{(1+u)^{2}}
, first used in
[
2
]
. Then we find

\displaystyle D_{t}=(-1)^{t+3}\frac{1-u^{t+3}}{(1-u)(1+u)^{t+2}},

\displaystyle N_{2}^{t}=\frac{(-1)^{t+1}u^{2}(1-u^{t})}{(1+u)^{t+3}(1-u)},

\displaystyle N_{3}^{t}=\frac{(-1)^{t+1}u(1-u^{t+2})}{(1-u)(1+u)^{t+3}}.

We start with paths that return to the
x
-axis, as the formula is (slightly) different. We
have

\mathscr{L}^{[\leq t]}=\frac{D_{t}+N_{2}^{t}+N_{3}^{t}}{D_{t}}=\frac{(1+u)-u^{t+2}(1+u^{2})}{1-u^{t+3}}

for the generating function of paths bounded by
t
. From this we see the limit for
t\to\infty

\mathscr{L}^{[\leq\infty]}=1+u=\frac{1-\sqrt{1-4z}}{2z},

as expected. From this

\mathscr{L}^{[>t]}=\mathscr{L}^{[\leq\infty]}-\mathscr{L}^{[\leq t]}=\frac{u^{t+2}(1-u^{2})}{1-u^{t+3}}.

We refer to
[
9
]
where a similar instance is worked out with an extensive amount of detail. For the average height we have
(before normalizing by the Catalan numbers) to compute

\sum_{t\geq 0}\mathscr{L}^{[>t]}=\frac{1-u^{2}}{u}\sum_{t\geq 3}\frac{u^{t}}{1-u^{t}}.

The goal is to find the local behaviour of
u\sim 1
since it translates to the local behaviour of
z\sim\frac{1}{4}
. To find this, we set

u=e^{-t}
and use the Mellin transform; we don’t need to do the actual computation, since we just cite the result from
[
9
]
. First, the factor is simple;

\frac{1-u^{2}}{u}\sim 2(1-u).

Since we only compute the leading term of the asymptotic expansion, we use

\sum_{t\geq 1}\frac{u^{t}}{1-u^{t}}\sim-\frac{\log(1-u)}{1-u},

found e.g. in
[
9
]
, so in total

-2\log(1-u)\sim-2\log(2\sqrt{1-4z})\sim-\log(1-4z).

Singularity analysis of generating functions
[
5
]
allows to translate this to the coefficients of
z^{n}
, with the result
\sim\frac{4^{n}}{n}
. For Catalan numbers, we have
the well-known

\frac{1}{n+1}\binom{2n}{n}\sim\frac{4^{n}}{n^{3/2}\sqrt{\pi}}.

The quotient is then the average height (leading term only):

\frac{\frac{4^{n}}{n}}{\frac{4^{n}}{n^{3/2}\sqrt{\pi}}}=\sqrt{\pi n}.

For path ending at
k\geq 1
we have to compute

(-1)^{k-1}\frac{N_{3}^{t-k+1}-N_{2}^{t-k}+N_{2}^{t-k+1}}{D_{t}}=u(1+u)^{k}\frac{1-u^{t-k+1}}{1-u^{t+3}}.

The limit for
t\to\infty
(no boundary) is
u(1+u)^{k}
and the difference is

u(1+u)^{k}-u(1+u)^{k}\frac{1-u^{t-k+1}}{1-u^{t+3}}=u^{-k-1}(1+u)^{k}(1-u^{k+2})\frac{u^{t+3}}{1-u^{t+3}}.

Locally we have (
u\sim 1
)

u^{-k-1}(1+u)^{k}(1-u^{k+2})\sim 2^{k}(k+2)(1-u).

For the average height (leading term only, before normalization) we need to compute

2^{k}(k+2)(1-u)\sum_{t\geq 1}\frac{u^{t}}{1-u^{t}}\sim-2^{k}(k+2)\log(1-u),

and

[z^{n}]-2^{k}(k+2)\log(1-u)\sim 2^{k-1}(k+2)\frac{4^{n}}{n}.

For the total numbers, we have

[z^{n}]u(1+u)^{k}=\binom{2n-1+k}{n-1}-\binom{2n-1+k}{n-2}\sim\frac{4^{n}}{\sqrt{\pi}n^{3/2}}(k+2)2^{k-1},

and the average height (
k
fixed,
n\to\infty
) is asymptotic to

\frac{2^{k-1}(k+2)\frac{4^{n}}{n}}{\frac{4^{n}}{\sqrt{\pi}n^{3/2}}(k+2)2^{k-1}}=\sqrt{\pi n},

as before.

To compute the average height of paths with unspecified endpoint makes no sense in this model since the number of such paths of length
n
is infinite.

6.2
The right-to left model

We have to analyze

(-1)^{k}z^{k}\frac{N_{1}^{t-k}+N_{2}^{t-k}+N_{3}^{t-k}}{D_{t}}.

It translates into

\mathscr{R}^{\leq t}=\frac{u^{k}}{(1+u)^{k-1}}\frac{1-u^{t+2-k}}{1-u^{t+3}}.

Furthermore

\mathscr{R}^{\leq\infty}=\frac{u^{k}}{(1+u)^{k-1}}

and

\mathscr{R}^{>t}=\mathscr{R}^{\leq\infty}-\mathscr{R}^{\leq t}=\frac{u^{t+2}(1-u^{k+1})}{(1+u)^{k-1}(1-u^{t+3})}.

For the average, we must compute

\frac{(k+1)(1-u)}{2^{k-1}}\sum_{t\geq 1}\frac{u^{t}}{1-u^{t}}

where we took liberties about two missing terms, which does not influence the main term of the average height.

As before, we get the asymptotic behaviour

\frac{(k+1)}{2^{k}}\frac{4^{n}}{n}.

For the total number we get

\frac{k+1}{2^{k}}\frac{4^{n}}{\sqrt{\pi}n^{3/2}},

and the quotient is again
\sqrt{\pi n}
.

Now we move to the Łukasiewicz paths with unspecified end and have to consider

\frac{D_{t-2}}{D_{t}}

which is also

\frac{(1+u)^{3}(1-u)}{u^{2}}\frac{u^{t+3}}{1-u^{t+3}}.

The fact that the formula is different for small values of
t
and that we start the sum at 1 and not at 3, does not change the main term.
We get

\frac{(1+u)^{3}(1-u)}{u^{2}}\sum_{t\geq 1}\frac{u^{t}}{1-u^{t}}\sim-8\log(1-u),

and the coefficient of
z^{n}
in it is asymptotic to

\frac{4^{n+1}}{n};

for the total number of objects we get the asymptotic formula

\frac{4^{n+1}}{\sqrt{\pi}n^{3/2}}

and the quotient (average height) is again asymptotic to
\sqrt{\pi n}
.
