Abstract
. Given 0 < p , q , r < ∞ 0<p,q,r<\infty and q < r ≤ ∞ q<r\leq\infty we consider the natural embedding ℓ p , q ↪ ℓ p , r \ell_{p,q}\hookrightarrow\ell_{p,r} between Lorenz sequence spaces. We prove that this non-compact embedding is always strictly singular but not finitely strictly singular.



2000 Mathematics Subject Classification
Primary 47G10, Secondary 47B10

1.
Introduction

Let
T:X\to Y
be a linear operator between Banach spaces, we recall that
T
is a strictly singular if there is no infinite dimensional closed subspace
Z
of
X
such that
T:Z\to T(Z)
, the restriction of
T
to
Z
, is an isomorphism. More over we say that
T
is finitely strictly singular if: for every
\varepsilon>0
, there exists
n_{\varepsilon}\geq 1
such that every subspace
E
of
X
with dimension greater that
n_{\varepsilon}
, there exists
x
in the unit sphere of
E
such that
\|T(x)\|_{Y}\leq\varepsilon.

Strictly singular operators and finitely strictly singular operators, which encompass compact operators, possess same properties which are habitually connected with compact operators. For example it is well know that Fredholm operators are invariant when perturbed by strictly singular operators
(i.e. if
T
is Fredholm and
S
is strictly singular then
T+S
is Fredholm, see
[
1
, Therem 4.63]
).

Many of non-compact operators in Analysis are strictly singular or finitely strictly singular.
For example Fourier transform, which is obviously non-compact, when is considered as a map from
L^{p}
into
L^{p^{\prime}}
, is finitely strictly singular for
1<p<2
and strictly singular when
p=1
(see
[
6
]
).

The natural embedding of sequence spaces

I:l^{p}\to l^{q},\quad\mbox{ for }p<q,

which is non-compact is finitely strictly singular (see
[
8
]
).

Also the limiting optimal Sobolev embedding
E_{d}
into continuous functions

(1.1)

\displaystyle E_{d}:W^{1}_{0}L^{d,1}((0,1)^{d})\hookrightarrow C((0,1)^{d}),

(where
W^{1}_{0}L^{d,1}((0,1)^{d})
denote a space of all functions
u
for which
|\nabla u|
belongs to Lorentz space
L^{d,1}
and
u
has a zero trace), is non-compact but finitely strictly singular (see
[
4
]
).

From the above examples arises a natural and quite intrigue question: Whether all limiting Sobolev embeddings on bounded smooth domain are strictly singular or finitely strictly singular?

Since the optimal target spaces for Sobolev embeddings are quite often Lorentz spaces then in order to investigate the above question, one needs to get more information about natural embedding between Lorentz sequence spaces:

I:l_{p,q}\to l_{r,s}.

This paper continues an investigation started in
[
5
]
where was proved that the natural embedding
l_{p}\to l_{p,\infty}
for
p>1
is strictly singular.

The paper is structured as follows. In Sect. 2, we recall the definitions we use,
and we collect all necessary later-needed material and technical lemmas. In Sect. 3 is proved that embedding
l_{p,q}\to l_{p,r}
is strictly singular for
q<r\leq\infty
and in Sect. 4 we showed that this embedding is not finitely strictly singular.

2.
preliminaries

In this section we recall definitions, notations and some technical lemmas needed in Sections 3 and 4.
We start by recalling definition of strictly singular and finitely strictly singular operators.

Definition 2.1
.

A bounded operator
T:X\to Y
between Banach spaces is said to be strictly singular if there is no infinite dimensional closed subspace
Z
of
X
such that
T:Z\to T(Z)
, the restriction of
T
to
Z
, is an isomorphism.

See
[
1
, section 4.5]
for more about strictly singular operators.

Definition 2.2
.

An operator
T
from a Banach space
X
into a Banach space
Y
is finitely strictly singular if: for every
\varepsilon>0
, there exists
n_{\varepsilon}\geq 1
such that every subspace
E
of
X
with dimension greater that
n_{\varepsilon}
, there exists
x
in the unit sphere of
E
such that
\|T(x)\|_{Y}\leq\varepsilon.

Let
T:X\to Y
be a linear map between Banach spaces then the
n
-th Bernstein numbers (or Bernstein widths) is defined by

b_{n}(T)=\sup_{E\subset X,\dim(E)=n}\inf_{f\in E,\|f\|_{X}=1}\|T(f)\|_{Y}.

It is not too hard to see that the operator
T
is finitely strictly singular if and only if
b_{n}(T)\to 0
and that we have the following relations:

\mbox{compact}\quad\Rightarrow\quad\mbox{finitely strictly singular}\quad\Rightarrow\quad\mbox{strictly singular.}

We consider in this paper a little more general concept of quasi-Banach spaces which satisfy the ”triangle” inequality with a constant.
Denote for
u=(u(1),u(2),\dots)
the modulus sequence
|u|=(|u(1)|,|u(2)|,\dots)
. We say that
|u|\leq|v|
if
|u(i)|\leq|v(i)|
for each
i\in\mathbb{N}
.

Definition 2.3
.

Let
\mathcal{S}
be a a set of all sequences of real numbers and
\|.\|:\mathcal{S}\rightarrow[0,\infty]
. Assume that
\|.\|
satisfies for all
u,v\in\mathcal{S}
and
\alpha\in\mathbb{R}
we have

(i)

\|u+v\|\leq T(\|u\|+\|v\|)
for some
T\geq 1
,

(ii)

\|\alpha u\|=|\alpha|\ \|u\|
,

(iii)

\|u\|\geq 0
and
\|u\|=0
if and only if
u=0
,

(iv)

\|u\|=\|\ |u|\ \|
,

(v)

if
|u|\leq|v|
then
\|u\|\leq\|v\|
,

(vi)

if
0\leq u_{n}\nearrow u
then
\|u_{n}\|\nearrow\|u\|
,

(vii)

if
\#\{i;u(i)\neq 0\}<\infty
then
\|u\|<\infty
.

Define
X:=\{u;\|u\|<\infty\}
. Then we call
X
a sequence quasi-Banach function space.

By an analogous way we could define a quasi-Banach function space of functions on a domain
\Omega
.
Remark that each quasi-Banach function space is complete (for details see for instance
[
7
]
, Corollary 3.7).

We can extend the definition of strictly singular operators on quasi-Banach spaces by the following alternative definition:

Definition 2.4
.

Let
X,Y
be quasi-Banach spaces and assume that
T:X\rightarrow Y
be a linear bounded operator. We say that
T
is strictly singular operator if

\displaystyle\inf\{\|Tx\|_{Y};\|x\|_{X}=1,x\in Z\}=0

for each infinite dimensional subspace
Z\subset X
.

For a finite set
F
denote by
\#(F)
the number of elements of
F
.

Definition 2.5
.

Given a sequence
a=(a(1),a(2),\dots)\in c_{0}
we set for
\lambda>0

\displaystyle\mu_{a}(\lambda)=\#\{i;|a(i)|>\lambda\}

and

\displaystyle a^{*}(j)=\min\{\lambda>0;\mu_{a}(\lambda)\leq j\}.

Define
a^{*}=(a^{*}(1),a^{*}(2),\dots)
a non-increasing rearrangement of
a
.

For a sequence
a=(a(1),a(2),\dots)\in c_{0}
denote

\displaystyle\textup{supp }a=\{j\in\mathbb{N};a(j)\neq 0\}.

Definition 2.6
.

Given a sequence
u=(u(1),u(2),\dots)\in c_{0}
with
\textup{supp }u=\{n_{1},n_{2},...,n_{k}\}\subset\mathbb{N}
and
n_{1}<n_{2}<\dots n_{k}
. Define a non-increasing rearrangement
u^{\diamond}
of
u
with respect to
\textup{supp }u
by

\displaystyle\begin{cases}u^{\diamond}(n_{j})=u^{*}(j)&\ j\in\{1,2,\dots,k\},\\
u^{\diamond}(i)=0&\ i\notin\{n_{1},n_{2},...,n_{k}\}.\end{cases}

Remark 2.7
.

If
\textup{supp }u:=\{n+1,n+2,\dots,m\}
then

(2.1)

\displaystyle u^{\diamond}(j)=u^{*}(j-n).

In the next we recall the definition of sequence Lorentz spaces.

Definition 2.8
.

Let
p\in(0,\infty),q\in(0,\infty]
. Define for a sequence
u

\displaystyle\|u\|_{p,q}=\begin{cases}\Big(\sum\limits_{j=1}^{\infty}j^{q/p-1}(u^{*}(j))^{q}\Big)^{1/q}&\ \ \text{if}\ \ q<\infty,\\
\sup\{j^{1/p}\ u^{*}(j);j=1,2\dots\}&\ \ \text{if}\ \ q=\infty.\end{cases}

We define Lorentz space
l_{p,q}
as a collection of all sequences
u
for which the norm
\|u\|_{p,q}
is finite.

Given
u\in\ell_{p,q}
we will write
u(i)
for the value of
u
at the index
i
.

Lemma 2.9
.

Let
0<p<\infty,0<q\leq\infty
.
The space
l_{p,q}
is a quasi-Banach function space.

Proof.

As in
[
3
]
(see (1.16) in Proposition 1.7) we can prove

\displaystyle(u+v)^{*}(i+j)\leq u^{*}(i)+v^{*}(j).

Split the sum

\displaystyle\sum\limits_{j=1}^{\infty}j^{q/p-1}(u+v)^{*}(j))^{q}

into two sums, the first one is over odd numbers, the second one is over even numbers. For both sums we can easily prove the quasi-triangle inequality. The other properties are easy.
∎

Lemma 2.10
.

Let
0<p<\infty,0<q<\infty
. Then we have for all
n\in\mathbb{N}

\displaystyle\Big(\sum_{j=1}^{n}j^{q/p-1}\Big)^{1/q}\approx n^{1/p}.

Proof.

For all
n
we have

\displaystyle\sum_{j=1}^{n}j^{q/p-1}\approx\int_{0}^{n}t^{q/p-1}\ dt=\frac{p}{q}n^{q/p}\approx n^{q/p}.

∎

Proposition 2.11
.

Let
0<p<\infty,0<q<r\leq\infty
. Then
\ell^{p,q}\hookrightarrow\ell^{p,r}
. Denote by
D_{p,q}
the norm of this embedding, i.e.

(2.2)

\displaystyle\|a\|_{p,r}\leq D_{q,r}\|a\|_{p,q}

for all sequences
a
.

Definition 2.12
.

Let
X
be a quasi-Banach function space of functions defined over
\Omega
. We say that
f\in X
has an absolutely continuous norm in
X
, written
f\in X_{a}
, if for every non-increasing sequence of measurable sets
G_{n}\subset\Omega
with
|G_{n}|\searrow 0
we have
\|f\chi_{G_{n}}\|\searrow 0
. We say that
X
has an absolutely continuous norm if
X_{a}=X
.

Lemma 2.13
.

Let
0<p<\infty,0<q<\infty
. Then
\ell_{p,q}
has an absolutely continuous norm.

Proof.

Take
u\in\ell_{p,q}
. Set

\displaystyle u_{n}(j)=\begin{cases}0&1\leq j\leq n,\\
u(j)&n+1\leq j.\end{cases}

Since
\|u\|_{p,q}\leq K<\infty
we have by (
2.2
) for each
n

\displaystyle K\geq\Big(\sum\limits_{j=1}^{\infty}j^{q/p-1}(u^{*}(j))^{q}\Big)^{1/q}\gtrsim n^{1/p}u^{*}(n)

and so

\displaystyle u^{*}(n)\lesssim n^{-1/p}.

It implies for any
j\in\mathbb{N}
that
\lim_{n\rightarrow\infty}u_{n}^{*}(j)=0
and consequently, due to the Lebesgue dominated convergence theorem we obtain

\displaystyle\|u_{n}\|_{p,q}=\Big(\sum\limits_{j=1}^{\infty}j^{q/p-1}(u_{n}^{*}(j))^{q}\Big)^{1/q}\rightarrow 0\ \ \text{for}\ \ n\rightarrow\infty.

∎

For a sequence
b=(b(1),b(2),\dots)
and
m\in\mathbb{N}

set

\displaystyle P_{m}(b)=(b(1),b(2),\dots,b(m),0,0,\dots)

\displaystyle R_{m}(b)=b-P_{m}b=(0,0,\dots,0,b(m+1),b(m+2),\dots).

Let
X\subset\ell_{p,q}
be a closed subspace with
\dim X=\infty
. Define
X_{m}=R_{m}(X)
. It is easy to see that
X_{m}
is a closed subspace with
\dim X_{m}=\infty
.

Let
0<p<\infty,0<q\leq\infty
. Since
\ell_{p,q}
is a sequence Banach function space we have
T\geq 1
such that

\displaystyle\|u+v\|_{p,q}\leq T(\|u\|_{p,q}+\|u\|_{p,q}).

Remark that it implies directly

(2.3)

\displaystyle u=v+w\ \Rightarrow\ \|v\|_{p,q}\geq\frac{1}{T}\|u\|_{p,q}-\|w\|_{p,q},

(2.4)

\displaystyle\Big\|\sum_{j=1}^{n}u_{j}\Big\|_{p,q}\leq\sum_{j=1}^{n}T^{j}\|u_{j}\|_{p,q}.

Lemma 2.14
.

Let
0<p<\infty,0<q<\infty
and
\alpha>0
. Assume
v_{j}\in\ell_{p,q}
have pairwise disjoint supports and
\|v_{j}\|_{p,q}\geq\alpha
.
Then

\displaystyle\lim_{k\rightarrow\infty}\Big\|\sum_{j=1}^{k}v_{j}\Big\|_{p,q}=\infty.

Proof.

Since
v_{j}
have pairwise disjoint supports we can write

\displaystyle\Big\|\sum_{j=1}^{k}v_{j}\Big\|_{p,q}=\Big\|\sum_{j=1}^{k}|v_{j}|\Big\|_{p,q}.

Assume that there exists a positive constant
C
independent of
k
such that

\displaystyle C\geq\Big\|\sum_{j=1}^{k}v_{j}\Big\|_{p,q}=\Big\|\sum_{j=1}^{k}|v_{j}|\Big\|_{p,q}.

Since

\displaystyle\Big\|\sum_{j=1}^{k}|v_{j}|\Big\|_{p,q}\nearrow\Big\|\sum_{j=1}^{\infty}|v_{j}|\Big\|_{p,q}

we have

\displaystyle C\geq\Big\|\sum_{j=1}^{\infty}|v_{j}|\Big\|_{p,q}.

By the absolute continuity of
\|.\|_{p,q}
we obtain

\displaystyle\alpha\leq\|v_{n}\|_{p,q}=\|\ |v_{n}|\ \|_{p,q}\leq\Big\|\sum_{j=n}^{\infty}|v_{j}|\Big\|_{p,q}\rightarrow 0

which is a contradiction.
∎

3.
The embedding is strictly singular

We prove in this section that the embedding
\ell_{p,q}\hookrightarrow\ell_{p,r}
is strictly singular for
0<p<\infty
,
q<r\leq\infty
. First we prove this assertion for
q<\infty
.

Theorem 3.1
.

Let
0<p,q,r<\infty
,
q<r
. Then the embedding
\ell_{p,q}\hookrightarrow\ell_{p,r}
is strictly singular.

Proof.

Let
X\subset\ell_{p,q}
be a closed subspace with
\dim X=\infty
and fix a sequence
\widetilde{a}\in\ell^{p,q}
,
\widetilde{a}(1)\geq\widetilde{a}(2)\geq\dots>0

(3.1)

\displaystyle 0<\|\widetilde{a}\|_{p,q}\leq 1.

Having a sequence
0=n_{0}<n_{1}<n_{2}<\dots
and
u_{k}\in X_{n_{k-1}}=R_{n_{k-1}}(X)
we denote for
k\geq 1

\displaystyle v_{k}=P_{n_{k}}u_{k},\ w_{k}=R_{n_{k}}u_{k},

\displaystyle I_{k}=\{n_{k-1}+1,n_{k-1}+2,\dots,n_{k}\},

\displaystyle b_{k}=\min\{|v_{k}(j)|;v_{k}(j)\neq 0,j\in I_{k}\}.

Choose
0<\delta<1/T
.

We will construct by mathematical induction a sequence of integers

\displaystyle\|u_{k}\|_{p,q}=1,

(3.4)

\displaystyle 2n_{k-1}<n_{k}.

(3.5)

\displaystyle\textup{supp }v_{k}\subset I_{k},

(3.6)

\displaystyle\varepsilon_{k+1}\leq\min\{b_{k},c_{k}^{1/q},a(n_{k})\}

\displaystyle\varepsilon_{k+1}n_{k}^{1/p}\leq 1,

(3.8)

\displaystyle|v_{k}(j)|\leq\varepsilon_{k}\ \text{for}\ j\in\mathbb{N},

(3.9)

\displaystyle a(j)\leq\widetilde{a}(j)\ \text{for}\ j\in\mathbb{N},

(3.10)

\displaystyle a(n_{k}+1)\leq b_{k},

(3.11)

\displaystyle\frac{1}{T}-\delta\leq\|v_{k}\|_{p,q}\leq 1,

(3.12)

\displaystyle\|w_{k}\|_{p,q}\leq\frac{\delta}{(2T)^{k}}.

Consider first

with
\|u_{1}\|_{p,q}=1
a nd set
\varepsilon_{1}=1
. There exists

such that

Lemma 4.3

\displaystyle\|A\|_{L^{p,q}(0,1)}=\Big\|\sum_{i=1}^{2^{n}}a_{i}\chi_{I_{i}}(t)\Big\|_{L^{p,q}(0,1)}=\Big\|\sum_{i=1}^{2^{n}}a_{i}^{*}\chi_{I_{i}}(t)\Big\|_{L^{p,q}(0,1)}

\displaystyle=\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}\int_{\frac{i-1}{2^{n}}}^{\frac{i}{2^{n}}}t^{\frac{q}{p}-1}dt\Big)^{1/q}.

Clearly,

\displaystyle\|A\|_{L^{p,q}(0,1)}=\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}\int_{\frac{i-1}{2^{n}}}^{\frac{i}{2^{n}}}t^{\frac{q}{p}-1}dt\Big)^{1/q}\leq\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}\frac{1}{2^{n}}\Big(\frac{i}{2^{n}}\Big)^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle=\frac{1}{2^{n/p}}\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}i^{\frac{q}{p}-1}\Big)^{1/q}=\frac{1}{2^{n/p}}\|a\|_{\ell^{p,q}}

which proves the inequality

\displaystyle 2^{\frac{n}{p}}\|A\|_{L^{p,q}(0,1)}\leq\|a\|_{\ell^{p,q}}.

Estimate the second inequality. We have

\displaystyle\|A\|_{L^{p,q}(0,1)}=\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}\int_{\frac{i-1}{2^{n}}}^{\frac{i}{2^{n}}}t^{\frac{q}{p}-1}dt\Big)^{1/q}

\displaystyle=\Big((a_{1}^{*})^{q}\int_{0}^{\frac{1}{2^{n}}}t^{\frac{q}{p}-1}dt+\sum_{i=2}^{2^{n}}(a_{i}^{*})^{q}\int_{\frac{i-1}{2^{n}}}^{\frac{i}{2^{n}}}t^{\frac{q}{p}-1}dt\Big)^{1/q}

\displaystyle\geq\Big(\frac{p}{q}\Big(\frac{1}{2^{n}}\Big)^{\frac{q}{p}}(a_{1}^{*})^{q}+\sum_{i=2}^{2^{n}}(a_{i}^{*})^{q}\frac{1}{2^{n}}\Big(\frac{i-1}{2^{n}}\Big)^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle=\frac{1}{2^{n/p}}\Big(\frac{p}{q}(a_{1}^{*})^{q}+\sum_{i=2}^{2^{n}}(a_{i}^{*})^{q}\Big(\frac{i-1}{i}\Big)^{\frac{q}{p}-1}i^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle\geq\frac{1}{2^{n/p}}\Big(\frac{p}{q}(a_{1}^{*})^{q}+\sum_{i=2}^{2^{n}}(a_{i}^{*})^{q}\Big(\frac{1}{2}\Big)^{\frac{q}{p}-1}i^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle\geq\frac{1}{2^{n/p}}\min\Big\{\Big(\frac{p}{q}\Big)^{1/q},\Big(\frac{1}{2}\Big)^{\frac{1}{p}-\frac{1}{q}}\Big\}\Big((a_{1}^{*})^{q}+\sum_{i=2}^{2^{n}}(a_{i}^{*})^{q}i^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle=\frac{1}{2^{n/p}}\min\Big\{\Big(\frac{p}{q}\Big)^{1/q},2^{\frac{1}{q}-\frac{1}{p}}\Big\}\Big(\sum_{i=1}^{2^{n}}(a_{i}^{*})^{q}i^{\frac{q}{p}-1}\Big)^{1/q}

\displaystyle=\frac{1}{2^{n/p}}\min\Big\{\Big(\frac{p}{q}\Big)^{1/q},2^{\frac{1}{q}-\frac{1}{p}}\Big\}\|a\|_{\ell^{p,q}}

which proves the inequality

\displaystyle\min\Big\{\Big(\frac{p}{q}\Big)^{1/q},2^{\frac{1}{q}-\frac{1}{p}}\Big\}\|a\|_{\ell^{p,q}}\leq 2^{\frac{n}{p}}\|A\|_{L^{p,q}(0,1)}.

∎

Lemma 4.4
.

Let
0<p<\infty
. Then for all
a=(a_{1},a_{2},\dots,a_{2^{n}})\in\mathbb{R}^{2^{n}}
we have

\displaystyle\|a\|_{\ell^{p,\infty}}=2^{n/p}\|A\|_{L^{p,\infty}(0,1)}.

Proof.

Fix
a=(a_{1},a_{2},\dots,a_{2^{n}})\in\mathbb{R}^{2^{n}}
. Consider the function
A
. Then

\displaystyle\|A\|_{L^{p,\infty}(0,1)}=\Big\|\sum_{i=1}^{2^{n}}a_{i}\chi_{I_{i}}(t)\Big\|_{L^{p,\infty}(0,1)}=\Big\|\sum_{i=1}^{2^{n}}a_{i}^{*}\chi_{I_{i}}(t)\Big\|_{L^{p,\infty}(0,1)}

\displaystyle=\sup_{t\in(0,1)}t^{1/p}\sum_{i=1}^{2^{n}}a_{i}^{*}\chi_{I_{i}}(t)=\max_{i=1,2,\dots,2^{n}}\Big(\frac{i}{2^{n}}\Big)^{1/p}a_{i}^{*}=2^{-n/p}\max_{i=1,2,\dots,2^{n}}i^{1/p}a_{i}^{*}

\displaystyle=2^{-n/p}\|a\|_{\ell^{p,\infty}}.

∎

The next lemma is an easy modification of Khintchine’s inequality for Lorentz spaces.

Lemma 4.5
.

Let
0<p<\infty,0<q\leq\infty
. Then there is a constant
C_{p,q}
such that
for all
N\in\mathbb{N}
and
a=(a_{1},a_{2},\dots,a_{N})\in\mathbb{R}^{N}
we have

\displaystyle C_{p,q}^{-1}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p,q}(0,1)}\leq\|a\|_{\ell^{2}}\leq C_{p,q}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p,q}(0,1)}.

Proof.

Take
p_{1}<p<p_{2}
. Then
L^{p_{2}}(0,1)\hookrightarrow L^{p,q}(0,1)\hookrightarrow L^{p_{1}}(0,1)
. Then there is
K>0
such that for all
u
we have

\displaystyle K^{-1}\|u\|_{L^{p_{1}}(0,1)}\leq\|u\|_{L^{p,q}(0,1)}\leq K\|u\|_{L^{p_{2}}(0,1)}.

Consider a function
\sum_{i=1}^{N}a_{i}R_{i}
. By Theorem
4.2
we have

\displaystyle\frac{A_{p_{2}}}{K}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p,q}(0,1)}\leq A_{p_{2}}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p_{2}}(0,1)}\leq\|a\|_{\ell^{2}}

\displaystyle\leq B_{p_{1}}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p_{1}}(0,1)}\leq KB_{p_{1}}\Big\|\sum_{i=1}^{N}a_{i}R_{i}\Big\|_{L^{p,q}(0,1)}.

∎

Consider an embedding
\ell_{p,q}\rightarrow\ell_{p,r}
with
q<r
. Given
L_{n}\subset\subset\ell_{p,q}
with
\dim L_{n}=n
set

b_{n}(L_{n})=\inf_{u\in L_{n}}\frac{\|u\|_{p,r}}{\|u\|_{p,q}}.

Say that
M\subset\mathbb{N}
is an interval if for all
i<j<k
we have
j\in M
provided
i,k\in M
. Let
M_{1},M_{2}\subset\mathbb{N}
. Say that
M_{1}\prec M_{2}
if for all
i\in M_{1},j\in M_{2}
we have
i<j
.

Let
n\in\mathbb{N}
and let
1\leq i\leq 2^{n}
. Split a set on indices
1,2,\dots,2^{n}
into
2^{i}
pairwise disjoint intervals
M_{k}
,
k=1,2,\dots,2^{i}
such that

\#M_{k}=2^{n-i}
,
M_{k}\prec M_{l}
provided
k<l
. Define now sequences
r_{i,n}
by

\displaystyle r_{i,n}(j)=\begin{cases}(-1)^{k+1}&\ j\in M_{k}\\
0&\ j>2^{n}.\end{cases}

For given
n
we can see

\displaystyle r_{n,n}

\displaystyle=\overbrace{1,-1,\ \ 1,-1,\ \ 1,-1,\ \ 1,-1,\dots,-1,}^{2^{n-1}}\overbrace{\ \ 1,\dots,\ \ 1,-1,\ \ 1,-1,\ \ 1,-1}^{2^{n-1}},0,0,\dots

\displaystyle r_{n-1,n}

\displaystyle=1,\ \ 1,-1,-1,\ \ 1,\ \ 1,-1,-1,\dots,-1,\ \ 1,\dots,-1,-1,\ \ 1,\ \ 1,-1,-1,0,0,\dots

\displaystyle r_{n-2,n}

\displaystyle=1,\ \ 1,\ \ 1,\ \ 1,-1,-1,-1,-1,\dots,-1,\ \ 1,\dots,\ \ 1,\ \ 1,-1,-1,-1,-1,0,0,\dots

\displaystyle r_{1,n}

\displaystyle=1,\ \ 1,\ \ 1,\ \ 1,\ \ 1,\ \ 1,\ \ 1,\ \ 1,\dots,\ \ \ 1,-1,\dots,-1,-1,-1,-1,-1,-1,0,0,\dots.

It is a analogous system to Rademacher functions. We can write also

\displaystyle r_{i,n}(j)

\displaystyle=\begin{cases}\textup{sign}\sin 2^{i-n}\pi j&\ 1\leq j\leq 2^{n}\\
0&\ j>2^{n}.\end{cases}

Remark that the appropriate function to
r_{i,n}

Theorem 4.6
.

Let
0<p<\infty,0<q<r\leq\infty
. Then there is
\alpha>0
such that for all
n\in\mathbb{N}

\displaystyle b_{n}:=b_{n}(\textup{id}:\ell^{p,q}\hookrightarrow\ell^{p,r})\geq\alpha.

Proof.

Consider
\mathcal{R}_{n}=\textup{span}(r_{1,n},r_{2,n},\dots,r_{n,n})
. Then
\dim(\mathcal{R}_{n})=n
. Moreover, the appropriate function to a linear combination
\sum_{i=1}^{n}a_{i}r_{i,n}
is a function
A=\sum_{i=1}^{n}a_{i}R_{i}(.)
.
Clearly, by Lemma
4.4
and Lemma
4.3

\displaystyle b_{n}=\sup_{L_{n}}\inf_{a\in L_{n}}\frac{\|a\|_{\ell^{p,r}}}{\|a\|_{\ell^{p,q}}}\geq\inf_{a\in\mathcal{R}_{n}}\frac{\|a\|_{\ell^{p,r}}}{\|a\|_{\ell^{p,q}}}\geq\inf_{a\in\mathcal{R}_{n}}\min\Big\{\Big(\frac{p}{q}\Big)^{1/q},2^{\frac{1}{q}-\frac{1}{p}}\Big\}\frac{2^{\frac{n}{p}}\|A\|_{L^{p,r}(0,1)}}{2^{\frac{n}{p}}\|A\|_{L^{p,q}(0,1)}}.

Using Lemma
4.5
we obtain

\displaystyle b_{n}\geq C\inf_{a\in\mathcal{R}_{n}}\frac{\|A\|_{L^{p,r}(0,1)}}{\|A\|_{L^{p,q}(0,1)}}=C\frac{\|\sum_{i=1}^{n}a_{i}R_{i}\|_{L^{p,r}(0,1)}}{\|\sum_{i=1}^{n}a_{i}R_{i}\|_{L^{p,q}(0,1)}}

\displaystyle\geq C\frac{C_{p,r}^{-1}\|a\|_{\ell^{2}}}{C_{p,q}\|a\|_{\ell^{2}}}=\frac{C}{C_{p,r}C_{p,q}}:=\alpha.

∎
