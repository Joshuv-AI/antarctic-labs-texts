A matrix
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
with real coordinates is

nonnegative

if
p_{i,j}\geq 0
for all
i
and
j
.
A nonnegative
n\times n
matrix
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
is

column stochastic
if its column sums satisfy

\colsum_{j}(P)=\sum_{i=1}^{n}p_{i,j}=1\qquad\text{for all $j\in\{1,\ldots,n\}$.}

A nonnegative
n\times n
matrix
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
is

row stochastic
if its row sums satisfy

\rowsum_{i}(P)=\sum_{j=1}^{n}p_{i,j}=1\qquad\text{for all $i\in\{1,\ldots,n\}$}.

A nonnegative
n\times n
matrix
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
is

doubly stochastic
if
it is both column stochastic and row stochastic.

We begin with some simple lemmas.

Lemma 1
.

Let
P
and
Q
be
n\times n
matrices.
If
P
and
Q
are column stochastic, then
PQ
is column stochastic.
If
P
and
Q
are row stochastic, then
PQ
is row stochastic.
If
P
and
Q
are doubly stochastic, then
PQ
is doubly stochastic.

Proof.

Let
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
and
Q=\left(\begin{matrix}q_{i,j}\end{matrix}\right)
.
If
P
and
Q
are column stochastic
n\times n
matrices, then for all
j\in\{1,\ldots,n\}
we have

\displaystyle\colsum_{j}(PQ)

\displaystyle=\sum_{i=1}^{n}(PQ)_{i,j}=\sum_{i=1}^{n}\sum_{k=1}^{n}p_{i,k}q_{k,j}

\displaystyle=\sum_{k=1}^{n}q_{k,j}\sum_{i=1}^{n}p_{i,k}=\sum_{k=1}^{n}q_{k,j}\colsum_{k}(P)

\displaystyle=\sum_{k=1}^{n}q_{k,j}=\colsum_{j}(Q)=1

and so
PQ
is column stochastic.

Similarly, if
P
and
Q
are row stochastic
n\times n
matrices,
then for all
i\in\{1,\ldots,n\}
we have

\displaystyle\rowsum_{i}(PQ)

\displaystyle=\sum_{j=1}^{n}(PQ)_{i,j}=\sum_{j=1}^{n}\sum_{k=1}^{n}p_{i,k}q_{k,j}

\displaystyle=\sum_{k=1}^{n}p_{i,k}\sum_{j=1}^{n}q_{k,j}=\sum_{k=1}^{n}p_{i,k}\rowsum_{k}(Q)

\displaystyle=\sum_{k=1}^{n}p_{i,k}=\rowsum_{i}(P)=1

and so
PQ
is row stochastic.

It follows that
PQ
is doubly stochastic if
P
and
Q
are doubly stochastic.
This completes the proof.
∎

Let
\mathcal{E}=\{\mathbf{e}_{1},\ldots,\mathbf{e}_{n}\}
be the standard basis for
V=\mathbf{R}^{n}
.
For every permutation
\sigma
in the symmetric group
S_{n}
, define the linear transformation

P_{\sigma}:V\rightarrow V
by

P_{\sigma}(\mathbf{e}_{j})=\mathbf{e}_{\sigma(j)}

for all
j\in\{1,\ldots,n\}
.
If
\mathbf{x}=\sum_{j=1}^{n}x_{j}\mathbf{e}_{j}\in V
, then

\displaystyle P_{\sigma}(\mathbf{x})

\displaystyle=P_{\sigma}\left(\sum_{j=1}^{n}x_{j}\mathbf{e}_{j}\right)=\sum_{j=1}^{n}x_{j}P_{\sigma}\left(\mathbf{e}_{j}\right)

\displaystyle=\sum_{j=1}^{n}x_{j}\mathbf{e}_{\sigma(j)}=\sum_{j=1}^{n}x_{\sigma^{-1}(j)}\mathbf{e}_{j}.

Equivalently,

P_{\sigma}\left(\begin{matrix}x_{1}\\
\vdots\\
x_{n}\end{matrix}\right)=\left(\begin{matrix}x_{\sigma^{-1}(1)}\\
\vdots\\
x_{\sigma^{-1}(n)}\end{matrix}\right).

We also denote by
P_{\sigma}
the matrix of this linear transformation
with respect to the standard basis
\mathcal{E}
.
The
n\times n
matrix
P_{\sigma}
is called a

permutation matrix
.
Its
(i,j)
th coordinate is

\left(P_{\sigma}\right)_{i,j}=\delta_{i,\sigma(j)}=\begin{cases}1&\text{if $i=\sigma(j)$}\\
0&\text{if $i\neq\sigma(j)$}\end{cases}

where
\delta_{i,j}
is the Kronecker delta.
For all
j\in\{1,\ldots,n\}
we have

\colsum_{j}(P_{\sigma})=\sum_{i=1}^{n}\left(P_{\sigma}\right)_{i,j}=\sum_{i=1}^{n}\delta_{i,\sigma(j)}=1.

For all
i\in\{1,\ldots,n\}
we have

\rowsum_{i}(P_{\sigma})=\sum_{j=1}^{n}\left(P_{\sigma}\right)_{i,j}=\sum_{j=1}^{n}\delta_{i,\sigma(j)}=1.

Thus, the permutation matrix
P_{\sigma}
is doubly stochastic for all
\sigma\in S_{n}
.

For example, if
\sigma=(1,2,3)\in S_{3}
, then

P_{\sigma}=\left(\begin{matrix}0&0&1\\
1&0&0\\
0&1&0\end{matrix}\right).

Lemma 2
.

For all permutations
\sigma,\tau\in S_{n}
,

P_{\sigma}P_{\tau}=P_{\sigma\tau}.

Proof.

For all
j\in\{1,\ldots,n\}
we have

\displaystyle\left(P_{\sigma}P_{\tau}\right)(\mathbf{e}_{j})

\displaystyle=P_{\sigma}\left(P_{\tau}(\mathbf{e}_{j})\right)=P_{\sigma}\left(\mathbf{e}_{\tau(j)}\right)=\mathbf{e}_{\sigma(\tau(j))}

\displaystyle=\mathbf{e}_{(\sigma\tau)(j)}=P_{\sigma\tau}(\mathbf{e}_{j}).

Equivalently, for all
i,j\in\{1,\ldots,n\}
we have

\left(P_{\sigma}P_{\tau}\right)_{i,j}=\sum_{k=1}^{n}\left(P_{\sigma}\right)_{i,k}\left(P_{\tau}\right)_{k,j}=\sum_{k=1}^{n}\delta_{i,\sigma(k)}\delta_{k,\tau(j)}=\delta_{i,\sigma\tau(j)}=\left(P_{\sigma\tau}\right)_{i,j}.

This completes the proof.
∎

The classical

is the convex hull of the set
of
n!
lattice points in
\mathbf{R}^{n}
whose coordinates are the permutations of the set
\{1,2,3,\ldots,n\}
,
that is, the convex hull of the set

\left\{P_{\sigma}\left(\begin{matrix}1\\
2\\
\vdots\\
n\end{matrix}\right):\sigma\in S_{n}\right\}=\left\{\left(\begin{matrix}{\sigma^{-1}(1)}\\
{\sigma^{-1}(2)}\\
\vdots\\
{\sigma^{-1}(n)}\end{matrix}\right):\sigma\in S_{n}\right\}\\
=\left\{\left(\begin{matrix}{\sigma(1)}\\
{\sigma(2)}\\
\vdots\\
{\sigma(n)}\end{matrix}\right):\sigma\in S_{n}\right\}.

Every vector in this set lies on the hyperplane

x_{1}+x_{2}+\cdots+x_{n}=1+2+\cdots+n=\frac{n(n+1)}{2}.

For example, the classical permutohedron in
\mathbf{R}^{2}
is the convex hull of the set

\left\{P_{\sigma}\left(\begin{matrix}1\\
2\end{matrix}\right):\sigma\in S_{2}\right\}

The classical permutohedron in

\left\{P_{\sigma}\left(\begin{matrix}1\\
2\\
3\end{matrix}\right):\sigma\in S_{3}\right\}=\left\{\left(\begin{matrix}1\\
2\\
3\end{matrix}\right),\left(\begin{matrix}1\\

2\end{matrix}\right),\left(\begin{matrix}2\\

2\end{matrix}\right),\left(\begin{matrix}3\\

2.
Decreasing and increasing vectors

For every permutation
\sigma\in S_{n}
we have the permutation matrix
P_{\sigma}
and
for every vector
\mathbf{a}=\vectorsmallan\in\mathbf{R}^{n}
we have the vector

P_{\sigma}(\mathbf{a})=\left(\begin{matrix}a_{\sigma^{-1}(1)}\\
\vdots\\
a_{\sigma^{-1}(n)}\end{matrix}\right)\in\mathbf{R}^{n}.

The vector
P_{\sigma}(\mathbf{a})
is called a

of the vector in
\mathbf{a}

Of special interest are vectors with decreasing coordinates
and vectors with increasing coordinates.

Let
\mathbf{x}=\left(\begin{smallmatrix}x_{1}\\
\vdots\\
x_{n}\end{smallmatrix}\right)\in\mathbf{R}^{n}
.
The vector
\mathbf{x}
is
decreasing

x_{1}\geq x_{2}\geq\cdots\geq x_{n}.

Associated to every vector
\mathbf{a}=\vectorsmallan\in\mathbf{R}^{n}

\mathbf{a}^{\downarrow}=\left(\begin{smallmatrix}a_{1}^{\downarrow}\\
\vdots\\
a_{n}^{\downarrow}\end{smallmatrix}\right)\in\mathbf{R}^{n}

\mathbf{a}
by a rearrangement of coordinates.
For every vector
\mathbf{a}\in\mathbf{R}^{n}
there is a permutation
\sigma\in S_{n}

such that
P_{\sigma}(\mathbf{a})=\mathbf{a}^{\downarrow}
.
This permutation is unique if and only if the vector
\mathbf{a}
has distinct coordinates.

The vector
\mathbf{x}=\left(\begin{smallmatrix}x_{1}\\
\vdots\\
x_{n}\end{smallmatrix}\right)\in\mathbf{R}^{n}
is

if

x_{1}\leq x_{2}\leq\cdots\leq x_{n}.

Associated to every vector

\mathbf{a}=\vectorsmallan\in\mathbf{R}^{n}

\mathbf{a}^{\uparrow}=\left(\begin{smallmatrix}a_{1}^{\uparrow}\\
\vdots\\
a_{n}^{\uparrow}\end{smallmatrix}\right)\in\mathbf{R}^{n}

\mathbf{a}
by a rearrangement of coordinates.
For every vector
\mathbf{a}\in\mathbf{R}^{n}

.

has distinct coordinates.

For all

\mathbf{b}\in\mathbf{R}^{n}

Theorem 1
.

For all vectors

By Lemma
4
, there is a finite sequence of vectors

\mathbf{b}=\mathbf{b}_{0},\mathbf{b}_{1},\ldots,\mathbf{b}_{r}=\mathbf{b}^{\uparrow}

\tau_{1},\tau_{2},\ldots,\tau_{r}\in S_{n}

\mathbf{b}_{i-1}

\displaystyle\left(\mathbf{a}^{\uparrow},\mathbf{b}^{\uparrow}\right)-\left(\mathbf{a}^{\uparrow},\mathbf{b}\right)

Theorem 2

and

\mathbf{e}_{1}\prec\mathbf{a}\quad\text{implies $\mathbf{a}=\mathbf{e}_{k}$
for some $k\in\{1,\ldots,n\}$.}

Proof.

Let
\mathbf{a}^{\downarrow}=\left(\begin{smallmatrix}a_{1}^{\downarrow}\\
\vdots\\
a_{n}^{\downarrow}\end{smallmatrix}\right)
,

a_{1}^{\downarrow}\geq\cdots\geq a_{n}^{\downarrow}\geq 0

\sum_{i=1}^{n}a_{i}^{\downarrow}=1

Lemma 9
.

Let
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
be a column stochastic

\mathbf{a}=\vectorsmallan\in\mathbf{R}^{n}_{\geq 0}

\sum_{i=1}^{n}b_{i}=\sum_{i=1}^{n}\sum_{j=1}^{n}p_{i,j}a_{j}=\sum_{j=1}^{n}a_{j}\sum_{i=1}^{n}p_{i,j}=\sum_{j=1}^{n}a_{j}\colsum_{j}(P)=\sum_{j=1}^{n}a_{j}.

Theorem 3
.

Let
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
be a nonnegative
n\times n
matrix.
The following are equivalent:

(i)

P(\mathbf{a})\prec\mathbf{a}
for all vectors
\mathbf{a}\in\mathbf{R}^{n}_{\geq 0}
.

(ii)

P(\mathbf{e}_{j})\prec\mathbf{e}_{j}
for all
j\in\{1,\ldots,n\}
and
P(\mathbf{f}_{n})\prec\mathbf{f}_{n}
.

(iii)

The matrix
P=\left(\begin{matrix}p_{i,j}\end{matrix}\right)
is doubly stochastic.

Proof.

Clearly, (i) implies (ii).

Assume (ii). For all
j\in\{1,\ldots,n\}
, the
j
th column of the matrix
P
is

\col_{j}(P)=\left(\begin{matrix}p_{1,j}\\
\vdots\\
p_{n,j}\end{matrix}\right)=P(\mathbf{e}_{j}).

If
P(\mathbf{e}_{j})\prec\mathbf{e}_{j}
, then

1=\colsum(\mathbf{e}_{j})=\colsum_{j}(P)=\sum_{i=1}^{n}p_{i,j}

and so
P
is column stochastic.

By Theorem
2
, the majorization relation

P(\mathbf{f}_{n})\prec\mathbf{f}_{n}
implies
P(\mathbf{f}_{n})=\mathbf{f}_{n}
.
The
i
th coordinate of the vector
\mathbf{f}_{n}
is
1/n

and the
i
th coordinate of the vector
\mathbf{f}_{n}
is
\sum_{j=1}^{n}\frac{p_{i,j}}{n}
.
Therefore,

\frac{1}{n}=\sum_{j=1}^{n}\frac{p_{i,j}}{n}=\frac{1}{n}\rowsum_{i}(P)

and so
\rowsum_{i}(P)=1
for all
i\in\{1,\ldots,n\}

and the matrix
P
is also row stochastic.
Thus, (ii) implies (iii).

Let
P
be a doubly stochastic matrix.
Let
\mathbf{a}\in\mathbf{R}^{n}_{\geq 0}
and
\mathbf{b}=P(\mathbf{a})
.
We shall prove that
\mathbf{b}^{\downarrow}\prec\mathbf{a}^{\downarrow}
.

There exist permutations
\sigma
and
\tau
in
S_{n}
such that

P_{\sigma}(\mathbf{a})=\mathbf{a}^{\downarrow}\qqand P_{\tau}(\mathbf{b})=\mathbf{b}^{\downarrow}

and so

\mathbf{b}^{\downarrow}=P_{\tau}(\mathbf{b})=P_{\tau}P(\mathbf{a})=P_{\tau}PP_{\sigma^{-1}}\left(\mathbf{a}^{\downarrow}\right)=Q\mathbf{a}^{\downarrow}.

The matrices
P_{\tau}
and
P_{\sigma^{-1}}
are doubly stochastic
and so the matrix

is doubly stochastic.

For
k\in\{1,\ldots,n-1\}
and
j\in\{1,\ldots,n\}
, define the partial column sums

c_{j}^{(k)}=\sum_{i=1}^{k}q_{i,j}.

We have

0\leq c_{j}^{(k)}\leq\sum_{i=1}^{n}q_{i,j}=\colsum_{j}(Q)=1

and

\sum_{j=1}^{n}c_{j}^{(k)}=\sum_{j=1}^{n}\sum_{i=1}^{k}q_{i,j}=\sum_{i=1}^{k}\sum_{j=1}^{n}q_{i,j}=\sum_{i=1}^{k}\rowsum_{i}(Q)=k.

Let

\mathbf{a}^{\downarrow}=\left(\begin{matrix}a_{1}^{\downarrow}\\
\vdots\\
a_{n}^{\downarrow}\end{matrix}\right)\qqand\mathbf{b}^{\downarrow}=\left(\begin{matrix}b_{1}^{\downarrow}\\
\vdots\\
b_{n}^{\downarrow}\end{matrix}\right).

From Lemma
9
we obtain

\sum_{i=1}^{n}b_{i}^{\downarrow}=\sum_{i=1}^{n}a_{i}^{\downarrow}

The inequalities

a_{1}^{\downarrow}\geq a_{2}^{\downarrow}\geq\cdots\geq a_{n}^{\downarrow}

For all

we have

\displaystyle\sum_{i=1}^{k}b_{i}^{\downarrow}

\displaystyle=\sum_{i=1}^{k}\sum_{j=1}^{n}q_{i,j}a_{j}^{\downarrow}=\sum_{j=1}^{n}a_{j}^{\downarrow}\sum_{i=1}^{k}q_{i,j}=\sum_{j=1}^{n}a_{j}^{\downarrow}c_{j}^{(k)}

\displaystyle\leq\sum_{j=1}^{k-1}c_{j}^{(k)}a_{j}^{\downarrow}+a_{k}^{\downarrow}\sum_{j=k}^{n}c_{j}^{(k)}=\sum_{j=1}^{k-1}c_{j}^{(k)}a_{j}^{\downarrow}+a_{k}^{\downarrow}\left(k-\sum_{j=1}^{k-1}c_{j}^{(k)}\right)

\displaystyle=\sum_{j=1}^{k-1}c_{j}^{(k)}(a_{j}^{\downarrow}-a_{k}^{\downarrow})+ka_{k}^{\downarrow}\leq\sum_{j=1}^{k-1}(a_{j}^{\downarrow}-a_{k}^{\downarrow})+ka_{k}^{\downarrow}

\displaystyle=\sum_{j=1}^{k}a_{j}^{\downarrow}.

Therefore,
\mathbf{b}\prec\mathbf{a}
and (iii) implies (i).
This completes the proof.

4.
The Hardy-Littlewood-Pólya
T
-transformation

Let
\mathbf{a},\mathbf{b}\in\mathbf{R}^{n}
.
In Theorem
3

we proved that if
P
is an
n\times n
doubly stochastic matrix, then

\mathbf{a}
majorizes
P(\mathbf{a})
, that is, if
\mathbf{b}=P(\mathbf{a})
, then

\mathbf{b}\prec\mathbf{a}
.
In this section we prove the converse:
If
\mathbf{b}\prec\mathbf{a}
,
then there is a doubly stochastic matrix
P
such that
\mathbf{b}=P(\mathbf{a})
.
The proof is based on the following elementary lemma.

Lemma 10
.

Let
a_{k},a_{\ell},c_{k}
, and
c_{\ell}
be real numbers such that

(1)

a_{\ell}+a_{k}=c_{\ell}+c_{k}

and

(2)

a_{\ell}<c_{\ell}\leq c_{k}<a_{k}.

There is a unique
2\times 2
doubly stochastic matrix
T_{k,\ell}
such that

T_{k,\ell}\left(\begin{matrix}a_{k}\\
a_{\ell}\end{matrix}\right)=\left(\begin{matrix}c_{k}\\
c_{\ell}\end{matrix}\right).

Moreover,

T_{k,\ell}=\left(\begin{matrix}\lambda&1-\lambda\\
1-\lambda&\lambda\end{matrix}\right)

where

\lambda=\frac{c_{k}-a_{\ell}}{a_{k}-a_{\ell}}=\frac{a_{k}-c_{\ell}}{a_{k}-a_{\ell}}.

Proof.

Every
2\times 2
doubly stochastic matrix is of the form

\left(\begin{matrix}\lambda&1-\lambda\\
1-\lambda&\lambda\end{matrix}\right)

for some
\lambda\in[0,1]
. We have

\left(\begin{matrix}\lambda&1-\lambda\\
1-\lambda&\lambda\end{matrix}\right)\left(\begin{matrix}a_{k}\\
a_{\ell}\end{matrix}\right)=\left(\begin{matrix}c_{k}\\
c_{\ell}\end{matrix}\right)

if and only if

\lambda a_{k}+(1-\lambda)a_{\ell}=c_{k}

and

(1-\lambda)a_{k}+\lambda a_{\ell}=c_{\ell}.

The unique solution of the first equation is

\lambda_{1}=\frac{c_{k}-a_{\ell}}{a_{k}-a_{\ell}}

and the unique solution of the second equation is

\lambda_{2}=\frac{a_{k}-c_{\ell}}{a_{k}-a_{\ell}}.

Equation (
1
) implies that

\lambda_{1}=\lambda_{2}=\lambda
.
Inequality (
2
) implies that
0<\lambda<1
.
This completes the proof.
∎

For example, if
\left(\begin{matrix}a_{2}\\
a_{5}\end{matrix}\right)=\left(\begin{matrix}4\\

\left(\begin{matrix}c_{2}\\
c_{5}\end{matrix}\right)=\left(\begin{matrix}1\\
-7\end{matrix}\right)

\lambda=11/14

Lemma 12
.

For all vectors
\mathbf{a},\mathbf{b},\mathbf{c}\in\mathbf{R}^{n}

(iii)

(iv)

(v)

Properties (i), (ii), and (iii) are immediate.

To prove (iv), which is the triangle inequality for vectors
\mathbf{a},\mathbf{b},\mathbf{c}
, let

\displaystyle I

\displaystyle=\{i\in\{1,\ldots,n\}:a_{i}\neq c_{i}\}

\displaystyle J

\displaystyle=\{j\in\{1,\ldots,n\}:c_{j}\neq b_{j}\}

\displaystyle K

\displaystyle=\{k\in\{1,\ldots,n\}:a_{k}\neq b_{k}\}

\displaystyle L

\displaystyle=\{1,\ldots,n\}\setminus(I\cup J).

If
\ell\in L
, then
\ell\notin I
and
\ell\notin J
, and so
a_{\ell}=c_{\ell}
and
c_{\ell}=b_{\ell}
,

a_{\ell}=b_{\ell}
.
If

To prove (v), we observe that if
\mathbf{a}\neq\mathbf{b}

a_{i_{1}}\neq b_{i_{1}}

\sum_{i=1}^{n}a_{i}=\sum_{i=1}^{n}b_{i}

\sum_{\begin{subarray}{c}i=1\\
i\neq i_{1}\end{subarray}}^{n}a_{i}\neq\sum_{\begin{subarray}{c}i=1\\
i\neq i_{1}\end{subarray}}^{n}b_{i}

a_{i_{2}}\neq b_{i_{2}}

Theorem 7
.

Let
\mathbf{a}
and
\mathbf{b}
be vectors in
\mathbf{R}^{n}_{\geq 0}
.
Let
K(\mathbf{a})
be the
S_{n}
-permutohedron generated by
\mathbf{a}
.
The vector
\mathbf{a}
majorizes
\mathbf{b}
if and only if
\mathbf{b}\in K(\mathbf{a})
.

Proof.

Let
P_{\sigma}
be the permutation matrix constructed from the permutation
\sigma\in S_{n}
.
The permutohedron
K(\mathbf{a})
is the convex hull of the set of vectors

\{P_{\sigma}(\mathbf{a}):\sigma\in S_{n}\}
.
By Theorem
7
,
if
\mathbf{a}
majorizes
\mathbf{b}
, then there is a doubly stochastic matrix
P
such that
P(\mathbf{a})=\mathbf{b}
.
The Birkhoff-von Neumann theorem in convexity theory states that every doubly stochastic matrix
is a convex combination of permutation matrices.
It follows that there are permutations
\sigma_{1},\ldots,\sigma_{k}\in S_{n}

and positive numbers
\lambda_{1},\ldots,\lambda_{k}
such that

\sum_{i=1}^{k}\lambda_{i}=1

and

P=\sum_{i=1}^{k}\lambda_{i}P_{\sigma_{i}}.

Therefore,

\mathbf{b}=P(\mathbf{a})=\sum_{i=1}^{k}\lambda_{i}P_{\sigma_{i}}(\mathbf{a})

is a vector in
K(\mathbf{a})
.

Conversely, if
\mathbf{b}\in K(\mathbf{a})
, then there exist permutations
\sigma_{1},\ldots,\sigma_{k}\in S_{n}

and positive numbers
\lambda_{1},\ldots,\lambda_{k}
such that

\sum_{i=1}^{k}\lambda_{i}=1

and

\mathbf{b}=\sum_{i=1}^{k}\lambda_{i}P_{\sigma_{i}}(\mathbf{a})=P(\mathbf{a})

where the matrix
P=\sum_{i=1}^{k}\lambda_{i}P_{\sigma_{i}}
is doubly stochastic.
Theorem
3

implies that
\mathbf{a}
majorizes
\mathbf{b}
. This completes the proof.

b_{i}=\sum_{j=1}^{n}p_{i,j}a_{j}

for all
i\in\{1,\ldots,n\}
.
Because
P
is doubly stochastic, we have

\rowsum_{i}(P)=\sum_{j=1}^{n}p_{i,j}=1

for all
i\in\{1,\ldots,n\}
and

\colsum_{j}(P)=\sum_{i=1}^{n}p_{i,j}=1

for all
j\in\{1,\ldots,n\}
.
The convexity of the function
f
implies that

f(b_{i})=f\left(\sum_{j=1}^{n}p_{i,j}a_{j}\right)\leq\sum_{j=1}^{n}p_{i,j}f\left(a_{j}\right)

for all
i\in\{1,\ldots,n\}
and so

\sum_{i=1}^{n}f(b_{i})\leq\sum_{i=1}^{n}\sum_{j=1}^{n}p_{i,j}f\left(a_{j}\right)=\sum_{j=1}^{n}\left(\sum_{i=1}^{n}p_{i,j}\right)f\left(a_{j}\right)=\sum_{j=1}^{n}f\left(a_{j}\right).

This completes the proof.
∎
