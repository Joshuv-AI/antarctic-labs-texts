Abstract
. In this paper we derive converge of T T means of Vilenkin-Fourier series with monotone coefficients of integrable functions in Lebesgue and Vilinkin-Lebesgue points. Moreover, we discuss pointwise and norm convergence in L p L_{p} norms of such T T means.

Denote by

\mathbb{N}:=\mathbb{N}_{+}\cup\{0\}.

The elements of

It is easy to give a basis for the neighborhoods of

I_{0}\left(x\right):=G_{m},\text{ \ }I_{n}(x):=\{y\in G_{m}\mid y_{0}=x_{0},...,y_{n-1}=x_{n-1}\},\ \text{ where }\ x\in G_{m},\ n\in\mathbb{N}.

If we define the so-called generalized number system based on

M_{0}:=1,\ M_{k+1}:=m_{k}M_{k}\,\,\,\ \ (k\in\mathbb{N}),

then every

where

We introduce on
G_{m}
an orthonormal system which is called the Vilenkin
system. First, we define complex-valued function

r_{k}\left(x\right):G_{m}\rightarrow\mathbb{C},
the generalized Rademacher functions, by

r_{k}\left(x\right):=\exp\left(2\pi ix_{k}/m_{k}\right),\text{ }\left(i^{2}=-1,x\in G_{m},\text{ }k\in\mathbb{N}\right).

Next, we define the Vilenkin system

\,\,\,\psi:=(\psi_{n}:n\in\mathbb{N})
on
G_{m}
by:

\psi_{n}(x):=\prod\limits_{k=0}^{\infty}r_{k}^{n_{k}}\left(x\right),\,\,\ \ \,\left(n\in\mathbb{N}\right).

Specifically, we call this system the Walsh-Paley system when
m\equiv 2.

The norms (or quasi-norms) of the spaces
L_{p}(G_{m})
and
weak-L_{p}\left(G_{m}\right)

\left(0<p<\infty\right)
are
respectively defined by

\left\|f\right\|_{p}^{p}:=\int_{G_{m}}\left|f\right|^{p}d\mu,\text{ }\left\|f\right\|_{weak-L_{p}}^{p}:=\underset{\lambda>0}{\sup}\lambda^{p}\mu\left(f>\lambda\right)<+\infty.

The Vilenkin system is orthonormal and complete in
L_{2}\left(G_{m}\right)
(see
[
46
]
).

Now, we introduce analogues of the usual definitions in Fourier-analysis. If

f\in L_{1}\left(G_{m}\right)
we can define Fourier coefficients, partial
sums and Dirichlet kernels with respect to the Vilenkin system in the usual manner:

\widehat{f}\left(n\right):=\int_{G_{m}}f\overline{\psi}_{n}d\mu,\ \ \ \ \ \ \ S_{n}f:=\sum_{k=0}^{n-1}\widehat{f}\left(k\right)\psi_{k},\text{ \ \ }D_{n}:=\sum_{k=0}^{n-1}\psi_{k\text{ }},\text{ \ \ }\left(n\in\mathbb{N}_{+}\right).

Recall that

(3)

\displaystyle\int_{G_{m}}D_{n}(x)dx=1,

(4)

\displaystyle D_{M_{n}-j}(x)=D_{M_{n}}(x)-\psi_{M_{n}-1}(x)\overline{D}_{j}(x),\ j<M_{n}.

The convolution of two functions

is defined by

\left(f\ast g\right)\left(x\right):=\int_{G_{m}}f\left(x-t\right)g\left(t\right)dt\text{ \ \ }\left(x\in G_{m}\right).

It is easy to see that if

\displaystyle\frac{1}{Q_{n}}\left(\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\int_{G_{m}}\left|K_{j}\right|d\mu+q_{n-1}(n-1)\int_{G_{m}}|K_{n-1}|d\mu\right)

\displaystyle\leq

\displaystyle\frac{c}{Q_{n}}\left(\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j+q_{n-1}(n-1)\right)\leq c<\infty,

so also (
25
) is proved.
By using (
22
) and inequalities (
13
) and (
15
) we can conclude that

\displaystyle\int_{G_{m}\backslash I_{N}}\left|F^{-1}_{n}\right|d\mu

\displaystyle\leq

\displaystyle\frac{1}{Q_{n}}\overset{n-1}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\int_{G_{m}\backslash I_{N}}\left|K_{j}\right|d\mu+\frac{q_{n-1}(n-1)}{Q_{n}}\int_{G_{m}\backslash I_{N}}|K_{n-1}|

\displaystyle\leq

\displaystyle\frac{1}{Q_{n}}\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\alpha_{j}+\frac{q_{n-1}(n-1)\alpha_{n-1}}{Q_{n}}=I+II,

where
\alpha_{n}\to 0,\ \ \text{as}\ \ n\to\infty.
Since sequence is non-increasing we can conclude that

II=\frac{q_{n-1}(n-1)\alpha_{n-1}}{Q_{n}}\leq\alpha_{n-1}\to 0,\ \ \text{as}\ \ n\to\infty.

Moreover, for any
\varepsilon>0
there exists
N_{0}\in\mathbb{N},
such that
\alpha_{n}<\varepsilon
when
n>N_{0}.
Furthermore,

\displaystyle I=\frac{1}{Q_{n}}\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\alpha_{j}=\frac{1}{Q_{n}}\overset{N_{0}}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j\alpha_{j}+\frac{1}{Q_{n}}\overset{n-2}{\underset{j=N_{0}+1}{\sum}}\left(q_{j}-q_{j+1}\right)j\alpha_{j}:=I_{1}+I_{2}.

The sequence
\{q_{k}:k\in\mathbb{N}\}
is non-increasing and therefore
|q_{j}-q_{j+1}|<2q_{0},

I_{1}\leq\frac{2q_{0}N_{0}}{Q_{n}}\to 0,\ \ \ \text{as}\ \ \ n\to\infty

and

\displaystyle I_{2}=\frac{1}{Q_{n}}\overset{n-2}{\underset{j=N_{0}+1}{\sum}}\left(q_{j}-q_{j+1}\right)j\alpha_{j}\leq\frac{\varepsilon}{Q_{n}}\overset{n-2}{\underset{j=N_{0}+1}{\sum}}\left(q_{j}-q_{j+1}\right)j\leq\frac{\varepsilon}{Q_{n}}\overset{n-2}{\underset{j=0}{\sum}}\left(q_{j}-q_{j+1}\right)j<\varepsilon.

and we can conclude that
I_{2}\to 0
so proof is complete.
∎
