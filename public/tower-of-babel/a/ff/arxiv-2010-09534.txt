Proximal-ADMM Decoder for Nonbinary LDPC Codes
Yongchao Wang

Abstract
In this paper, we develop an efficient decoder via the proximal alternating direction method of multipliers (proximal-ADMM) technique for nonbinary linear block codes in the Galois field. Its main contents are as follows: first, exploiting the decomposition technique based on the three-variables check equation, we formulate the maximum likelihood (ML) decoding problem approximately to a non-convex quadratic program; second, an efficient algorithm based on the proximal-ADMM technique is proposed to solve the formulated QP problem. Exploiting the QP problem’s inherent structures, its variables can be updated in parallel; third, we prove that the proposed decoding algorithm can converge to some stationary point of the formulated QP problem. Moreover, we also show, for nonbinary low-density parity-check (LDPC) codes, its computational complexity in each proximal-ADMM iteration scales linearly with block length and the size of the considered Galois field. Simulation results demonstrate that the proposed proximal-ADMM decoder outperforms state-of-the-art nonbinary LDPC decoders in terms of either error correction performance or computational complexity.

In this paper, we focus on designing a convergence-guaranteed decoder with low complexity and favourable error correction performance for nonbinary LDPC codes.
Specifically, the main contributions of this paper are summarized as follows.

•

Based on the check-equation decomposition method, we first decompose a general multi-variables check equation into a set of three-variables check equations.
Then, by exploiting the equivalent binary parity-check formulation of every three-variables check equation, we transform the nonbinary ML decoding problem to an equivalent linear integer program (LIP).
Finally, by adding the quadratic penalty term into the objective of the LIP model, relaxing binary constraints to box constraints, and introducing extra linear constraints, a new quadratic programming (QP) decoding model is established for nonbinary LDPC codes.

•

We develop a proximal-ADMM algorithm to solve the resulting QP decoding problem. By exploiting the inherent structures of the QP problem, variables in one ADMM update step are updated by blocks, but all of the blocks can be calculated in parallel.
Meanwhile, variables in other ADMM update steps are computed in parallel.
Moreover, the complexity of our proposed QP decoding algorithm is cheap in comparison with the state-of-the-art nonbinary ADMM-based decoders since it eliminates time-consuming Euclidean projections onto check polytopes.

•

We theoretically prove that the proposed proximal-ADMM decoding algorithm converges to a stationary point of the formulated QP decoding problem. In addition, a complexity analysis
shows that the proposed algorithm scales linearly with block length and the size of the considered Galois field.

. So the ML decoding problem can be formulated as

\mathbf{u}^{*}=\underset{\mathbf{u}\in\mathcal{C}}{\rm argmax}\hskip 5.69046ptp(\mathbf{r}|\mathbf{u}),

(1)

where codeword set
\mathcal{C}
can be expressed as

\mathcal{C}\!=\!\bigg\{\!\mathbf{u}|\big(\mathbf{h}_{j}^{T}\mathbf{u}\big)\oplus 2^{q}=0,j\in\mathcal{J},\!\mathbf{u}\in\!\{0,1,\!\dotsb,\!2^{q}-1\}^{n}\!\bigg\}.

(2)

According to the mapping rule (
3
), any nonzero element
u_{i}\in\mathbf{u}
can be one-to-one correspondent to a
(2^{q}-1)
-length binary vector
\mathbf{x}_{i}=[x_{i,1},\dotsb,x_{i,\sigma},\dotsb,x_{i,2^{q}-1}]^{T}
, where

x_{i,\sigma}=\begin{cases}1,&\ \sigma=u_{i},\\
0,&\ \sigma\neq u_{i}.\end{cases}

(3)

Besides, we map the zero element to a
(2^{q}-1)
-length all-zeros vector. Then, codeword
{\mathbf{u}}
can be mapped one-to-one correspondent to a binary vector
\mathbf{x}=[\mathbf{x}_{1}^{T},\dotsb,\mathbf{x}_{n}^{T}]^{T}\in\{0,1\}^{n(2^{q}-1)}
. Here, we call

as the equivalent binary codeword to the nonbinary codeword

. Let

denote the set consisting of all of the equivalent binary codewords. Then, the ML decoding problem (
1
) is equivalent to

\mathbf{x}^{*}=\underset{\mathbf{x}\in\mathcal{X}}{\rm argmax}\hskip 5.69046ptp(\mathbf{r}|\mathbf{x}),

(4)

which can be further derived as

\begin{split}\underset{\mathbf{x}\in\mathcal{X}}{\rm argmax}\hskip 5.69046ptp(\mathbf{r}|\mathbf{x})&=\underset{\mathbf{x}\in\mathcal{X}}{\rm argmax}\hskip 2.84544pt\prod_{i=1}^{n}\prod_{\sigma=1}^{2^{q}-1}p(r_{i}|x_{i,\sigma})\\
&=\underset{\mathbf{x}\in\mathcal{X}}{\rm argmin}\hskip 2.84544pt\sum_{i=1}^{n}\sum_{\sigma=1}^{2^{q}-1}-p(r_{i}|x_{i,\sigma}).\end{split}

(5)

Plugging constant
\displaystyle\sum_{i=1}^{n}\sum_{\sigma=1}^{2^{q}-1}\log p(r_{i}|x_{i,\sigma}=0)
into (
5
), we have the following derivations

\begin{split}\underset{\mathbf{x}\in\mathcal{X}}{\rm argmax}\ p(\mathbf{r}|\mathbf{x})\!\!&=\underset{\mathbf{x}\in\mathcal{X}}{\rm argmin}\displaystyle\sum_{i=1}^{n}\sum_{\sigma=1}^{2^{q}-1}\log\frac{p(r_{i}|x_{i,\sigma}=0)}{p(r_{i}|x_{i,\sigma})}\\
\!\!\!\hskip-2.84544pt&=\!\!\underset{\mathbf{x}\in\mathcal{X}}{\rm argmin}\!\displaystyle\sum_{i=1}^{n}\sum_{\sigma=1}^{2^{q}-1}\!\!x_{i,\sigma}\!\log\frac{p(r_{i}|x_{i,\sigma}=0)}{p(r_{i}|x_{i,\sigma}=1)}\\
&=\underset{\mathbf{x}\in\mathcal{X}}{\rm argmin}\ \boldsymbol{\gamma}^{T}\mathbf{x},\end{split}

(6)

where
\boldsymbol{\gamma}\in\mathbf{R}^{n(2^{q}-1)}
is called a cost vector defined by

\begin{split}{\boldsymbol{\gamma}}=\bigg[&\log\frac{p(r_{1}|x_{1,1}=0)}{p(r_{1}|x_{1,1}=1)},\dotsb,\log\frac{p(r_{1}|x_{1,2^{q}-1}=0)}{p(r_{1}|x_{1,2^{q}-1}=1)},\\
\dotsb,&\log\frac{p(r_{n}|x_{n,1}=0)}{p(r_{n}|x_{n,1}=1)},\dotsb,\log\frac{p(r_{n}|x_{n,2^{q}-1}=0)}{p(r_{n}|x_{n,2^{q}-1}=1)}\bigg].\end{split}

(7)

Then, the ML decoding problem can be cast as the following standard optimization model

\displaystyle\underset{\mathbf{x}}{\rm min}\hskip 8.82028pt\boldsymbol{\gamma}^{T}\mathbf{x},

(8a)

\displaystyle\hskip 2.84544pt{\rm s.t.}\hskip 10.1006pt\mathbf{x}\in\mathcal{X}.

(8b)

Problem (
8
) is a binary integer program. The difficulty of solving it lies in how to formulate and handle the constraint
\mathbf{x}\in\mathcal{X}
. In the following sections, we first decompose check equations in (
2
) into a series of three-variables check equations and second transform the resulting constraints to binary constraints and show analytical expressions for
\mathbf{x}\in\mathcal{X}
, which leads (

\boldsymbol{\lambda}^{T}\mathbf{v}-\frac{\alpha}{2}\|\mathbf{v}-0.5\|_{2}^{2}

IV

IV-A

Proximal-ADMM algorithm framework

By introducing two auxiliary variables,
\mathbf{e}_{1}
and
\mathbf{e}_{2}
, we transform the decoding problem (

\displaystyle\hskip 0.0pt\underset{\mathbf{v},\mathbf{e}_{1},\mathbf{e}_{2}}{\min}\hskip 7.11317pt\boldsymbol{\lambda}^{T}\mathbf{v}-\frac{\alpha}{2}\|\mathbf{v}-0.5\|_{2}^{2}

(35a)

\displaystyle\ \ {\rm s.\ t.}\hskip 7.96674pt\mathbf{A}\mathbf{v}+\mathbf{e}_{1}=\mathbf{b},\ \mathbf{e}_{1}\succeq\mathbf{0},

(35b)

\displaystyle\hskip 34.14322pt\mathbf{v}=\mathbf{e}_{2},~~\mathbf{0}\preceq\mathbf{e}_{2}\preceq\mathbf{1}.

(35c)

where symbol “
\mathbf{0}
” in (
35b
) is a length-
(4(2^{q}-1)\Gamma_{c}+n+\Gamma_{a})
all-zeros vector, and symbols “
\mathbf{1}
” and “
\mathbf{0}
” in (

) are length-
(2^{q}-1)(n+\Gamma_{a})
all-ones vector and length-
(2^{q}-1)(n+\Gamma_{a})
all-zeros vector, respectively.
The augmented Lagrangian function for problem (
35

\begin{split}\mathcal{L}_{\mu}\!(\mathbf{v},\!\mathbf{e}_{1},\!\mathbf{e}_{2},\!\mathbf{y}_{1},\!\mathbf{y}_{2})\!\!=\boldsymbol{\lambda}^{T}\!\mathbf{v}\!\!-\!\!\frac{\alpha}{2}\|\mathbf{v}\!\!-\!\!0.5\|_{2}^{2}\!+\!\mathbf{y}_{1}^{T}\!(\mathbf{A}\mathbf{v}\!\!+\!\!\mathbf{e}_{1}\!\!-\!\!\mathbf{b})\!\\
+\mathbf{y}_{2}^{T}(\mathbf{v}-\mathbf{e}_{2})+\frac{\mu}{2}\|\mathbf{A}\mathbf{v}+\mathbf{e}_{1}-\mathbf{b}\|_{2}^{2}+\frac{\mu}{2}\|\mathbf{v}-\mathbf{e}_{2}\|_{2}^{2},\end{split}

(36)

where
\mathbf{y}_{1}
and
\mathbf{y}_{2}
are Lagrangian multipliers corresponding to the two equality constraints in (
35
) respectively and
\mu>0
is a penalty parameter.
Based on (
36
), the proximal-ADMM iteration algorithm for solving (
35
) can be described as follows

\displaystyle\mathbf{v}^{k+1}\!=\!\mathop{\arg\min}\limits_{\mathbf{v}}\mathcal{L}_{\mu}(\mathbf{v},{\mathbf{e}}_{1}^{k},{\mathbf{e}}_{2}^{k},{\mathbf{y}}_{1}^{k},{\mathbf{y}}_{2}^{k})+\frac{\rho}{2}\|\mathbf{v}\!-\!\mathbf{p}^{k}\|_{2}^{2},

(37a)

\displaystyle{\mathbf{e}}_{1}^{k+1}\!\!=\!\mathop{\arg\min}\limits_{{\mathbf{e}}_{1}\succeq\mathbf{0}}\mathcal{L}_{\mu}(\!\mathbf{v}^{k\!+\!1}\!,{\mathbf{e}}_{1},\!{\mathbf{e}}_{2}^{k},{\mathbf{y}}_{1}^{k},{\mathbf{y}}_{2}^{k})\!\!+\!\!\frac{\rho}{2}\|{\mathbf{e}}_{1}\!-\!{\mathbf{z}}_{1}^{k}\|_{2}^{2},

(37b)

\displaystyle{\mathbf{e}}_{2}^{k+1}\!\!=\!\mathop{\arg\min}\limits_{\mathbf{0}\preceq\mathbf{e}_{2}\preceq\mathbf{1}}\mathcal{L}_{\mu}(\!\mathbf{v}^{k\!+\!1},{\mathbf{e}}_{1}^{k},{\mathbf{e}}_{2},{\mathbf{y}}_{1}^{k},{\mathbf{y}}_{2}^{k})\!\!+\!\!\frac{\rho}{2}\|{\mathbf{e}}_{2}\!\!-\!\!{\mathbf{z}}_{2}^{k}\|_{2}^{2},

(37c)

\displaystyle\mathbf{p}^{k+1}=\mathbf{p}^{k}+\beta(\mathbf{v}^{k+1}-\mathbf{p}^{k}),

\displaystyle{\mathbf{z}}_{1}^{k+1}={\mathbf{z}}_{1}^{k}+\beta({\mathbf{e}}_{1}^{k+1}-{\mathbf{z}}_{1}^{k}),

(37d)

\displaystyle{\mathbf{z}}_{2}^{k+1}={\mathbf{z}}_{2}^{k}+\beta({\mathbf{e}}_{2}^{k+1}-{\mathbf{z}}_{2}^{k}),

\displaystyle{\mathbf{y}}_{1}^{k+1}={\mathbf{y}}_{1}^{k}+\mu({\mathbf{A}}\mathbf{v}^{k+1}+{\mathbf{e}}_{1}^{k+1}-\mathbf{b}),

\displaystyle{\mathbf{y}}_{2}^{k+1}={\mathbf{y}}_{2}^{k}+\mu(\mathbf{v}^{k+1}-{\mathbf{e}}_{2}^{k+1}),

(37e)

where
k
is the iteration number,
\|\mathbf{v}-\mathbf{p}^{k}\|_{2}^{2}
,
\|{\mathbf{e}}_{1}\!-\!{\mathbf{z}}_{1}^{k}\|_{2}^{2}

\|{\mathbf{e}}_{2}-{\mathbf{z}}_{2}^{k}\|_{2}^{2}

\rho
is the corresponding penalty parameter, and
\beta
belongs to
(0,1]

IV-B

Solving subproblem (
37a
)

Obviously, choosing their values of parameters
\rho
,
\mu
, and

properly, problem (

\mathbf{v}
.
In this case, its solving procedure can be described as follows:
by setting the gradient of the function
\mathcal{L}_{\mu}(\mathbf{v},{\mathbf{u}}_{1}^{k},{\mathbf{u}}_{2}^{k},{\mathbf{y}}_{1}^{k},{\mathbf{y}}_{2}^{k})+\frac{\rho}{2}\|\mathbf{v}-{\mathbf{r}}^{k}\|_{2}^{2}
to be zero and solving the corresponding linear equation,
we update
\mathbf{v}

\begin{split}&\hskip 0.0pt\mathbf{v}^{k+1}=\big({\mathbf{A}}^{T}{\mathbf{A}}+\epsilon{\mathbf{I}}\big)^{-1}\boldsymbol{\varphi}^{k}\\
\end{split}

(38)

where “
\mathbf{I}

\begin{split}&\epsilon=1+\frac{\rho}{\mu}-\frac{\alpha}{\mu},\\
&\boldsymbol{\varphi}^{k}\!\!=\!\!{\mathbf{A}}^{T}\!\Big({\mathbf{b}}\!-\!{\mathbf{e}}_{1}^{k}\!-\!\frac{{\mathbf{y}}_{1}^{k}}{\mu}\!\Big)\!+\!\big(\!{\mathbf{e}}_{2}^{k}\!-\!\frac{{\mathbf{y}}_{2}^{k}}{\mu}\!\big)\!+\!\frac{\rho}{\mu}\mathbf{p}^{k}\!-\!\frac{\boldsymbol{\lambda}\!+\!0.5\alpha}{\mu}.\end{split}

(39)

Note that

\mathcal{O}\big((2^{q}-1)^{2}(n+\Gamma_{a})^{2}\big)

which is prohibitive for large-scale problems. In the following, we show a much more efficient way to perform the computational procedure. Firstly, we present the following lemma.

Lemma 2

Matrix
\big({\mathbf{A}}^{T}{\mathbf{A}}+\epsilon{\mathbf{I}}\big)^{-1}
is a block diagonal. Specifically, it can be denoted by

\begin{split}&\big({\mathbf{A}}^{T}{\mathbf{A}}+\epsilon{\mathbf{I}}\big)^{-1}\\
=&{\rm diag}\Big(\!\big({{\mathbf{A}}}_{1}^{T}{\mathbf{A}}_{1}\!\!+\!\epsilon{\mathbf{I}}\big)\!^{-1}\!,\ldots,\!\big({\mathbf{A}}_{n+\Gamma_{a}}^{T}{\mathbf{A}}_{n+\Gamma_{a}}\!\!+\!\epsilon{\mathbf{I}}\big)\!^{-1}\!\Big),\end{split}

(40)

where sub-matrix
\mathbf{A}_{i}
,
i=1,\ldots,n+\Gamma_{a}

to
(2^{q}-1)i
in matrix

and “
\mathbf{I}
” is a
(2^{q}-1)\times(2^{q}-1)
identity matrix. Moreover,

\big({\mathbf{A}}_{i}^{T}{\mathbf{A}}_{i}+\epsilon{\mathbf{I}}\big)^{-1}=\left[\begin{array}[]{cccc}\theta_{i}&\omega_{i}&\cdots&\omega_{i}\\
\omega_{i}&\theta_{i}&\cdots&\omega_{i}\\
\vdots&\vdots&\vdots&\vdots\\
\omega_{i}&\omega_{i}&\cdots&\theta_{i}\\
\end{array}\right],

(41)

where

\begin{split}&\theta_{i}\!=\!\omega_{i}+\frac{1}{2^{m}d_{i}+\epsilon},\\
&\displaystyle\omega_{i}\!=\!\frac{\!-\!2^{m}d_{i}}{(2^{m}d_{i}\!+\!\epsilon)[(2^{m+1}d_{i}\!+\!\epsilon\!+\!1)\!+\!(2^{m}d_{i}\!+\!1)(2^{m}\!-\!2)]}.\end{split}

(42)

Here,

denotes the degree of the

th information symbol, i.e., the number of check equations which it participates in.

Proof:

V-A

Convergence

Before presenting the main convergence result, we have the following lemma to show that the gradient of the considered augmented Lagrangian
\mathcal{L}_{\mu}(\cdot)
is Lipschitz continuous.

Lemma 3

Suppose
\alpha>0
and
\mu>0
and let
X:=\{\mathbf{v}|{\mathbf{A}}\mathbf{v}\preceq{\mathbf{b}},\mathbf{0}\preceq\mathbf{v}\preceq\mathbf{1}\}

\mathcal{L}_{\mu}
with respect to variable
\mathbf{v}
is Lipschitz continuous,
i.e., for any
\mathbf{v},\mathbf{v}^{\prime}\in X
,

\begin{split}&\|\nabla_{\mathbf{v}}\mathcal{L}_{\mu}(\mathbf{v},\!{\mathbf{e}}_{1},\!{\mathbf{e}}_{2},\!{\mathbf{y}}_{1},\!{\mathbf{y}}_{2})\!-\!\nabla_{\mathbf{v}}\mathcal{L}_{\mu}(\mathbf{v}^{\prime},\!{\mathbf{e}}_{1},\!{\mathbf{e}}_{2},\!{\mathbf{y}}_{1},\!{\mathbf{y}}_{2})\|_{2}\\
\leq&L\|\mathbf{v}-\mathbf{v}^{\prime}\|_{2},\end{split}

(49)

where
L\geq\alpha+\mu+\mu\delta_{{\mathbf{A}}}^{2}
and “
\delta_{{\mathbf{A}}}
” denotes the spectral norm of matrix
{\mathbf{A}}
.

Proof:

See Appendix
C
.
∎

3
, we have the following theorem to characterize the convergence property of the proposed proximal-ADMM decoding algorithm.

\rho>\alpha>0
and

\frac{\alpha}{\lambda_{\min}({\mathbf{A}}^{T}{\mathbf{A}})}\leq\mu\leq\frac{\rho(\rho-\alpha)^{2}}{4\delta_{{\mathbf{A}}{\mathbf{I}}}^{2}(\rho+L+2)^{2}-(\rho-\alpha)^{2}}
,
where

\left[\!\!\!\!\begin{array}[]{ccc}{{\mathbf{A}}}&\!\!{{\mathbf{I}}_{M}}&\!\!\!{\mathbf{0}}\\

.

In this section, several numerical results are presented for the proposed proximal-ADMM decoder in

VI-A

Performance of the proposed proximal-ADMM decoder

We consider two codes, named
\mathcal{C}_{1}
and
\mathcal{C}_{2}
, which are Tanner (1055,424) LDPC code and Tanner [155,64] LDPC code respectively
[

For

For

VI-B

Parameter choices of the proposed proximal-ADMM decoder

There are several parameters in the proposed proximal-ADMM decoding
Algorithm
1
, including the penalty parameter
\mu
, the 2-norm penalty parameter
\alpha
, the ending tolerance
\xi
, the maximum number of iterations
t_{\rm max}
, and parameters
\rho
and
\beta
.
Proper parameters can make
Algorithm
1
achieve favourable error-correction performance and reduce the iteration number.
However, an exhaustive search over all possible parameters is not practical and necessary.
First, it is easy to see that a sufficiently large
t_{\rm max}
and sufficiently small
\xi
can lead to good error-correction performance for
Algorithm
1
.
Thus, we fix the ending tolerance
\xi=10^{-5}
and the maximum number of iterations
t_{max}=500
in the simulations.
Moreover, a large
\beta
parameter is favorable because it can make the updates for variables
\mathbf{v}
,
\mathbf{e}_{1}
, and
\mathbf{e}_{2}
in every proximal-ADMM iteration not deviate too much from the stabilized iterate
\mathbf{p}
,
\mathbf{z}_{1}
, and
\mathbf{z}_{2}
respectively (c.f.
[
41
]
). Therefore, we set
\beta
to be 0.9 in the simulations.
Moreover,
Algorithm
1
is sensitive to the settings of parameters
\mu
,
\alpha
and
\rho
.
In order to guarantee that subproblem (
37a
) is strongly convex with respect to variable
{\mathbf{x}}

\rho>\alpha

VII
Conclusion

In this paper, we propose an efficient proximal-ADMM decoding algorithm for nonbinary LDPC codes in
\mathbb{F}_{2^{q}}
.
We prove that the proposed decoding algorithm is guaranteed to converge to some stationary point of the formulated QP decoding problem.
Moreover, it is shown that the complexity of the proposed decoder in each iteration is roughly
\mathcal{O}(2^{q}n)
.
Simulation results demonstrate that the proposed proximal-ADMM decoding algorithm attains better error-correction performance and decoding efficiency than state-of-the-art nonbinary LDPC decoders.
