Partition genericity and pigeonhole basis theorems
Benoit Monin, Ludovic Patey

Abstract
There exist two notions of typicality in computability theory, namely, genericity and randomness. In this article, we introduce a new notion of genericity, called partition genericity , which is at the intersection of these two notions of typicality, and show that many basis theorems apply to partition genericity. More precisely, we prove that every co-hyperimmune set and every Kurtz random is partition generic, and that every partition generic set admits a weak infinite subsets. In particular, we answer a question of Kjos-Hanssen and Liu by showing that every Kurtz random admits an infinite subset which does not compute any set of positive Hausdorff dimension. Partition genericty is a partition regular notion, so these results imply many existing pigeonhole basis theorems.



1
Introduction

The infinite pigeonhole principle can be considered as the most basic statement from Ramsey’s theory. The infinite pigeonhole principle for 2 colors can be formulated as “for every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
.” From a combinatorial viewpoint, the infinite pigeonhole principle is trivial. On the other hand, the computational analysis of this principle is very subtle and received the attention of the computability community for decades, motivated by the reverse mathematics of Ramsey’s theorem for pairs.

1.1
Pigeonhole basis theorems

The computability-theoretic analysis of a mathematical problem consists in understanding, given an instance, how computably complicated are its solutions. From this perspective, a lower bound is a statement of the form “There exists an instance such that every solution is computationally strong”, while an upper bound is of the form “For every instance, there is a computationally weak solution.” Here, the notions of strength and weaknesses range over many computability-theoretic properties.

A
pigeonhole basis theorem
is an upper bound for the pigeonhole principle, that is, a statement of the form: “For every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
which is computationally weak”. Several pigeonhole basis theorems have been proven:

1.

If
B
is a non-computable set, then for every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
such that
B\not\leq_{T}H
(Dzhafarov and Jockusch
[
3
]
).

2.

If
B
is a non-
\Sigma^{0}_{1}
set, then for every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
such that
B
is not
\Sigma^{0}_{1}(H)
(Wang
[
20
]
).

3.

If
f
is hyperimmune, then for every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
such that
f
is
H
-hyperimmune (Patey
[
15
]
).

4.

For every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
of non-PA degree (Liu
[
11
]
).

5.

For every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
of non-random degree, and which does not compute any set of positive Hausdorff dimension (Liu
[
12
]
).

Asking for an infinite subset of
A
or of
\overline{A}
is important, as there exist sets
A
such that every infinite subset is arbitrarily strong. For example, if
A
is the set of all initial segments of a set
B
, then every infinite subset of
A
computes
B
. In some cases however, one can fix the side of the subset. This happens in particular when the set
A
is sufficiently typical, where typicality means either randomness or genericity.

1.2
Randomness subset basis theorems

Randomness is a notion of typicality which was originally defined using measure theory. More recently, Algorithmic Randomness gave a formal meaning to the notion of
random sequence
using effective measure theory and Kolmogorov complexity. This yielded a hierarchy randomness notions, among which we should mention (in increasing order) Kurtz randomness, Schnorr randomness, Martin-Löf randomness, Schnorr 2-randomness, and 2-randomness.

A
Randomness subset basis theorem
is a statement of the form: “For every sufficiently random sequence
A\subseteq\omega
, there is an infinite subset set
H\subseteq A
which is computationally weak”. Here, by “sufficiently random”, we mean that the class of all such sets
A
has positive measure. One can then quantify the amount of randomness needed for such statement, and obtain a theorem of the form “For every
\boxdot
random sequence
A\subseteq\omega
, there is an infinite subset set
H\subseteq A
which is computationally weak”, where “
\boxdot
random” should be replaced by the right notion of randomness, such as Martin-Löf randomness for example. Subsets of random sequences were mainly studied as mass problems. For example, the Muchnik degree of the class of infinite subsets of Martin-Löf random sequences (seen as set of numbers), is the Muchnik degree of DNC functions (Kjos-Hanssen
[
9
]
, Greenberg and Miller
[
4
]
). However, a few randomness subset basis theorems appeared in the literature:

1.

Every 2-random (or even Schnorr 2-random) has an infinite subset which does not compute a 1-random (Kjos-Hanssen
[
7
]
).

2.

Every 1-random has an infinite subset which does not compute a 1-random, or even which does not compute any set with positive Hausdorff dimension (Kjos-Hanssen and Liu
[
8
]
).

Kjos-Hanssen and Liu
[
8
]
asked whether these results could be improved to weaker notions of randomness, such as Schnorr randomness.
In this article, we give a strong positive answer by showing that these results can be improved to Kurtz randomness.

1.3
Genericity subset basis theorems

Genericity is a notion of typicality which can be defined in terms of co-meager sets. The default notion of genericity considered is Cohen genericity. Later, Jockusch studied effectivizations of Cohen genericity, yielding again a hierarchy genericity notions, among which we mention in increasing order bi-hyperimmunity, weak 1-genericity and 1-genericity.
A
genericity subset basis theorem
is a statement of the form: “For every sufficiently Cohen generic set
A\subseteq\omega
, there is an infinite subset set
H\subseteq A
which is computationally weak”. Genericity subset basis theorems were not specifically studied per se. One can however mention one such result:

1.

If
B
is a non-computable set, then every co-hyperimmune set has an infinite subset which does not compute
B
(Hirschfeldt et al.
[
5
]
).

1.4
Partition genericity

In this article, we define a new notion of genericity, called
partition genericity
, and prove many statements of the form “Every partition generic set
A
has an infinite computationally weak subset.” We call these statements
partition genericity subset basis theorems
. Contrary to Martin-Löf randomness and Cohen genericity, this notion of partition genericity enjoys a property that one would expect of a subset basis theorem, that is, partition genericity is closed under supersets.

Theorem 1.1

1.

If
B
is a non-computable set, and
A
is partition generic, then there is an infinite set
H\subseteq A
such that
B\not\leq_{T}H
.

2.

If
B
is a non-
\Sigma^{0}_{1}
set, and
A
is partition generic relative to
B
, then there is an infinite set
H\subseteq A
such that
B
is not
\Sigma^{0}_{1}(H)
.

3.

If
f
is hyperimmune, and
A
is partition generic relative to
f
, then there is an infinite set
H\subseteq A
such that
f
is
H
-hyperimmune.

4.

If
A
is partition generic, then there is an infinite set
H\subseteq A
of non-PA degree.

5.

If
A
is partition generic, then there is an infinite set
H\subseteq A
of non-random degree, and furthermore, which does not compute any set of positive Hausdorff dimension.

In particular, every co-hyperimmune set and every Kurtz random is partition generic. Moreover, we show that partition genericity is almost a partition regular notion (see
Corollary

2.33
). It follows that all these partition genericity subset basis theorems imply all the pigeonhole basis theorems mentioned above.

Organization of this paper

Notation

We use lower case letters
a,b,c
for integers, upper case letters for sets of integers, and rounded letters
\mathcal{A},\mathcal{B}
for classes.

A
k
-cover
of a set
X
is a
k
-tuple of sets
X_{0},\dots,X_{k-1}

such that
X_{0}\cup\dots\cup X_{k-1}\supseteq X

X_{i}

Given a set
X\subseteq\omega

n\in\omega
, we let
[X]^{n}
denote the set of all subsets of
X

n
. Accordingly, we write
[X]^{\omega}

X
.
We write
2^{=n}

n

A

\min X>|\sigma|
.

2
Partition regularity

In this section, we conduct a general study of partition regularity from a computability-theoretic viewpoint. We introduce several related concepts, including the central notion of partition genericity, which will be justified by the constructions of
Section

3
.

2.1
Partition regularity

The central notion we are going to consider in this article is the one of partition regularity.
This concept comes from Ramsey theory and can be considered as a generalization of the infinite pigeonhole principle.

Definition 2.1
.

A
partition regular
class is a collection of sets
\mathcal{L}\subseteq 2^{\omega}
such that:

1.

\mathcal{L}
is not empty

2.

If
X\in\mathcal{L}
and
X\subseteq Y
, then
Y\in\mathcal{L}

3.

For every
k
, if
X\in\mathcal{L}
and
Y_{0}\cup\dots\cup Y_{k}\supseteq X
, then there is
i\leq k
such that
Y_{i}\in\mathcal{L}

Ramsey’s theory is sometimes characterized as the study of which classes are partition regular.
There are many well-known examples of partition regular classes in combinatorics:

Example 2.2
.

The following classes are partition regular.

1.

\{X\subseteq\omega:X\mbox{ is infinite}\}
by the infinite pigeonhole principle ;

2.

\{X\subseteq\omega:\ n\in X\}
for a fixed
n
;

3.

\{X\subseteq\omega:\limsup_{n\rightarrow\infty}\frac{|\{1,2,\ldots,n\}\cap X|}{n}>0\}
;

4.

\{X\subseteq\omega:\ \sum_{n\in X}\frac{1}{n}=\infty\}
.

In the computability-theoretic realm, many pigeonhole basis theorems can be rephrased as statements about partition regularity.

Example 2.3
.

The following classes are partition regular.

1.

\{X\subseteq\omega:\exists Y\in[X]^{\omega}\ Y\not\geq_{T}C\}
for any
C\not\leq_{T}\emptyset
(see Dzhafarov and Jockusch
[
3
]
)

2.

\{X\subseteq\omega:\exists Y\in[X]^{\omega}\ Y\mbox{ is not of PA degree}\}
(see Liu
[
11
]
)

3.

\{X\subseteq\omega:\exists Y\in[X]^{\omega}\ Y^{(n)}\not\geq_{T}C\}
for any non-
\Delta^{0}_{n+1}
set
C
(see Monin and Patey
[
14
]
) ;

4.

\{X\subseteq\omega:\exists Y\in[X]^{\omega}\ \omega_{1}^{Y}=\omega_{1}^{ck}\}
(see Monin and Patey
[
14
]
).

Dorais
[
1
]
was the first to use partition regular classes in the context of reverse mathematics. More precisely, he worked with a variant of Mathias forcing whose reservoirs avoid a
\Sigma^{0}_{2}
free ideal over
2^{\omega}
. A class is a free ideal iff it is the complement of a partition regular class.

2.2
Non-trivial classes

A partition regular class can be though of as a notion of largeness. Indeed, if we interpret
X\in\mathcal{L}
as “
X
is large”, then the axioms of partition regularity say that if a set is large, then any superset of it is large, and if we split a large set into two (or finitely many) parts, then at least one of the parts is large. There exist however a family of partition regular classes that fails this intuition. We call them principal classes.

Definition 2.4
.

A partition regular class
\mathcal{L}\subseteq 2^{\omega}
is
principal
if
\mathcal{L}=\{X\in 2^{\omega}\ :\ n\in X\}
for some
n
. A partition regular class
\mathcal{L}
is
non-trivial
if it contains only infinite sets, otherwise it is
trivial
.

The following proposition shows that once one excludes the principal partition regular classes, then the remaining partition regular classes satisfy at least one enjoyable property of largeness, namely, having only infinite elements.

Proposition 2.5

A partition regular class
\mathcal{L}
is non-trivial iff it contains no principal partition regular subclass.

Proof.

It is clear that if
\mathcal{L}
is non-trivial, it does not contain a principal partition regular subclass. Suppose now
\mathcal{L}
is trivial, that is,
\mathcal{L}
contains a finite set
X=\{n_{1},\dots,n_{k}\}
. Then in particular we have
\{n_{1}\}\cup\dots\cup\{n_{k}\}\supseteq X
. It follows that we must have
\{n_{i}\}\in\mathcal{L}
for some
i\leq k
. Then any set
X
containing
n_{i}
is in
\mathcal{L}
, that is, we have
\{X\in 2^{\omega}\ :\ n_{i}\in X\}\subseteq\mathcal{L}
.
∎

Non-trivial partition regular classes admit a simple characterization, which will be later used to generalize the concept of non-triviality to arbitrary classes.

Proposition 2.6

A partition regular class
\mathcal{L}
is non-trivial iff
\mathcal{L}
is included in the
\Sigma^{0}_{1}
class
\mathcal{U}_{2}
of sets containing at least two distinct elements.

Proof.

If
\mathcal{L}
is non-trivial then every member of
\mathcal{L}
is infinite and clearly
\mathcal{L}\subseteq\mathcal{U}_{2}
. If
\mathcal{L}
is trivial then by
Proposition

2.5
, it contains
\{n\}
for some
n\in\omega
and thus we do not have
\mathcal{L}\subseteq\mathcal{U}_{2}
.
∎

The following proposition says that any non-trivial partition regular class must contain many elements, in a measure-theoretic sense. All the partition regular classes we are going to consider in the applications are Borelian, hence measurable.

Proposition 2.7

Let
\mathcal{L}
be a non-trivial partition regular class. Then
\mathcal{L}
is closed by finite change of its elements. Furthermore if
\mathcal{L}
is measurable it has measure
1
.

Proof.

Let
X\in\mathcal{L}
. By definition, any
Y\supseteq X
also belongs to
\mathcal{L}
. Thus
\mathcal{L}
is closed by finite addition of elements. Consider now any
Y\subseteq X
such that
|X-Y|
is finite. In particular,
X=Y\cup\{n_{0},\dots,n_{k}\}
for some elements
n_{0},\dots,n_{k}
. As
\mathcal{L}
contains only infinite elements, we must have
Y\in\mathcal{L}
. Thus
\mathcal{L}
is closed by finite suppression. We easily conclude that
\mathcal{L}
is closed by finite changes.

If
\mathcal{L}
is measurable, by Kolmogorov 0-1 law,
\mathcal{L}
is either of measure
0
or of measure
1
. Suppose for contradiction that
\mathcal{L}
is of measure
0
. As
\mathcal{L}
is measurable, if must be included in some Borel set
\mathcal{A}
of measure
0
. Let
O
be an oracle such that
\mathcal{A}
is included in a
\Pi^{0}_{2}(O)
set effectively of measure
0
. Then no element of
\mathcal{L}
is
O
-Martin-Löf random. Let
Z
be any
O
-Martin-Löf random set. We also have that
\overline{Z}
is
O
-Martin-Löf random. Also
\omega\subseteq Z\cup\overline{Z}
. As
\omega\in\mathcal{L}
we must have
Z\in\mathcal{L}
or
\overline{Z}\in\mathcal{L}
, which is a contradiction. Thus
\mathcal{L}
is not of measure
0
and therefore it is of measure
1
.
∎

2.3
Closure properties

We now study some good closure properties enjoyed by the collection of all partition regular classes. A superclass of partition regular class is not partition regular in general, even when the superclass is closed under superset. For example, let
A
be a bi-infinite set, and let
\mathcal{L}_{A}=\{X\in 2^{\omega}:|A\cap X|=\infty\}
. Then
\mathcal{L}_{A}
is a partition regular class, but
\mathcal{L}=\mathcal{L}_{A}\cup\{X\in 2^{\omega}:X\supseteq\overline{A}\}
is not. Indeed, let
x_{0}=\min\overline{A}
and
B=\overline{A}\setminus\{x_{0}\}
. Then
\{x_{0}\}\cup B=\overline{A}\in\mathcal{L}
, but neither
\{x_{0}\}
, nor
B
belong to
\mathcal{L}
.
On the other hand, an arbitrary union of partition regular classes is partition regular.

Proposition 2.8

Suppose
\{\mathcal{L}_{i}\}_{i\in I}
is an arbitrary non-empty collection of partition regular classes. Then
\bigcup_{i\in I}\mathcal{L}_{i}
is a partition regular class.

Proof.

It is clear that
\bigcup_{i\in I}\mathcal{L}_{i}
is not empty. Let
X\in\bigcup_{i\in I}\mathcal{L}_{i}
. Let
Y\supseteq X
. There is some
i\in I
such that
X\in\mathcal{L}_{i}
. As
\mathcal{L}_{i}
is partition regular,
Y\in\mathcal{L}_{i}\subseteq\bigcup_{i\in I}\mathcal{L}_{i}
.

Let
X\in\bigcup_{i\in I}\mathcal{L}_{i}
. Let
Y_{0}\cup\dots\cup Y_{k}\supseteq X
. There is some
i\in I
such that
X\in\mathcal{L}_{i}
. As
\mathcal{L}_{i}
is partition regular,
Y_{j}\in\mathcal{L}_{i}\subseteq\bigcup_{i\in I}\mathcal{L}_{i}
for some
j\leq k
.
∎

In particular for every class
\mathcal{A}
containing a partition regular class, there is a largest partition regular class included in
\mathcal{A}
.

Definition 2.9
.

Given a class
\mathcal{A}\subseteq 2^{\omega}
, let
\mathcal{L}(\mathcal{A})
denote the largest partition regular subclass of
\mathcal{A}
. If
\mathcal{A}
does not contain a partition regular class, let
\mathcal{L}(\mathcal{A})
be the empty set.

The largest partition regular class included in
\mathcal{A}
admits a simple explicit definition that we shall use to analyse the definitional complexity of the partition regular classes we consider.

Proposition 2.10

Let
\mathcal{A}\subseteq 2^{\omega}
be any class. Then

\mathcal{L}(\mathcal{A})=\{X\in 2^{\omega}\ :\ \forall k\ \forall X_{0}\cup\dots\cup X_{k}\supseteq X\ \exists i\leq k\ X_{i}\in\mathcal{A}\}

Proof.

Note that by definition,
\mathcal{L}(\mathcal{A})\subseteq\mathcal{A}
, as if
X\notin\mathcal{A}
then itself as a
1
-cover is not in
\mathcal{A}
, so
X\notin\mathcal{L}(\mathcal{A})
.
Let us show that
\mathcal{L}(\mathcal{A})
contains every partition regular class included in
\mathcal{A}
. Suppose
\mathcal{L}\subseteq\mathcal{A}
is partition regular. Then given
X\in\mathcal{L}
, for every
k
and every
X_{0}\cup\dots\cup X_{k}\supseteq X
we have
X_{i}\in\mathcal{L}\subseteq\mathcal{A}
for some
i\leq k
. It follows that
X\in\mathcal{L}(\mathcal{A})
and thus that
\mathcal{L}\subseteq\mathcal{L}(\mathcal{A})
.

Assume
\mathcal{L}(\mathcal{A})\neq\emptyset
. Let us show that
\mathcal{L}(\mathcal{A})
is partition regular.
Suppose
X\in\mathcal{L}(\mathcal{A})
. Let
Y\supseteq X
. Then for every
k
, every
k
-cover of
Y
is also a
k
-cover of
X
. As
X\in\mathcal{L}(\mathcal{A})
, one element of the
k
-cover belongs to
\mathcal{A}
. Thus for every
k
and every
k
-cover of
Y
, one element of the
k
-cover belongs to
\mathcal{A}
. It follows that
Y\in\mathcal{L}(\mathcal{A})
.
Let
X\in\mathcal{L}(\mathcal{A})
and let
Y_{0}\cup\dots\cup Y_{k}\supseteq X
for some
k
. Let us show there is some
i\leq k
such that
Y_{i}\in\mathcal{L}(\mathcal{A})
. Suppose for contradiction that this is not the case. In particular for every
i\leq k
there are sets
Y^{i}_{0},\dots Y^{i}_{k_{i}}\supseteq Y_{i}
such that
\forall j\leq k_{i}
, we have
Y^{i}_{j}\notin\mathcal{A}
. In particular the sets
\{Y^{i}_{j}\}_{i\leq k,j\leq k_{i}}
are a finite cover of
X
such that for every
i\leq k
and every
j\leq k_{i}
we have
Y^{i}_{j}\notin\mathcal{A}
. This contradicts that
X\in\mathcal{L}(\mathcal{A})
. Thus there must exists
i\leq k
such that
Y_{i}\in\mathcal{L}(\mathcal{A})
.
So if
\mathcal{L}(\mathcal{A})
is non-empty, it is partition regular.
∎

Last, partition regular classes enjoy a very useful property: the intersection of an infinite decreasing sequence of partition regular classes is again partition regular. This property will be used to propage properties of
\Pi^{0}_{2}
partition regular classes to arbitrary intersections of
\Sigma^{0}_{1}
partition large classes.

Proposition 2.11

Suppose
\{\mathcal{L}_{n}\}_{n\in\omega}
is a collection of partition regular classes with
\mathcal{L}_{n+1}\subseteq\mathcal{L}_{n}
. Then
\bigcap_{n\in\omega}\mathcal{L}_{n}
is partition regular.

Proof.

For every
n
,
\omega\in\mathcal{L}_{n}
because
\mathcal{L}_{n}
is partition regular. It follows that
\omega\in\bigcap_{n\in\omega}\mathcal{L}_{n}
. In particular
\bigcap_{n\in\omega}\mathcal{L}_{n}
is not empty.

Suppose
X\in\bigcap_{n\in\omega}\mathcal{L}_{n}
. Let
Y\supseteq X
. For every
n
, since
X\in\mathcal{L}_{n}
then
Y\in\mathcal{L}_{n}
as
\mathcal{L}_{n}
is partition regular. Thus
Y\in\bigcap_{n\in\omega}\mathcal{L}_{n}
.

Suppose
X\in\bigcap_{n\in\omega}\mathcal{L}_{n}
. Let
Y_{0}\cup\dots\cup Y_{k}\supseteq X
. Suppose for contradiction that for every
i\leq k
the set
Y_{i}
is not in
\bigcap_{n\in\omega}\mathcal{L}_{n}
. For every
i\leq k
, let
n_{i}
be such that
Y_{i}\notin\mathcal{L}_{n_{i}}
. Let
n
be larger than these numbers. For every
i\leq k
, since
\mathcal{L}_{n_{i}}\supseteq\mathcal{L}_{n}
, the set
Y_{i}
is not in
\mathcal{L}_{n}
. As
X\in\mathcal{L}_{n}
, it follows that
\mathcal{L}_{n}
is not partition regular, which contradicts our hypothesis. Thus for every
X\in\bigcap_{n\in\omega}\mathcal{L}_{n}
and for every
Y_{0}\cup\dots\cup Y_{k}\supseteq X
, there is some
i\leq k
such that
Y_{i}\in\bigcap_{n\in\omega}\mathcal{L}_{n}
.
∎

2.4
\Pi^{0}_{2}
Partition regular classes

The most basic non-trivial partition regular class, the class of all infinite sets, is
\Pi^{0}_{2}
. In this section, we study a few specific
\Pi^{0}_{2}
partition regular classes and show that there is no non-trivial
\Sigma^{0}_{2}
partition regular class.

Proposition 2.12

Let
\mathcal{U}
be an upward-closed
\Sigma^{0}_{1}
class. Then
\mathcal{L}(\mathcal{U})
is
\Pi^{0}_{2}
.

Proof.

By
Proposition

2.10
, the largest partition regular subclass of
\mathcal{U}
is defined by

\mathcal{L}(\mathcal{U})=\{X\in 2^{\omega}\ :\ \forall k\ \forall X_{0}\cup\dots\cup X_{k}\supseteq X\ \exists i\leq k\ X_{i}\in\mathcal{U}\}

which is clearly
\Pi^{0}_{2}
.
∎

The previous proposition will be very useful for our computational analysis of partition regularity, as shows the following corollary.

Corollary 2.13

Let
\mathcal{U}
be a
\Sigma^{0}_{1}
class. The sentence “
\mathcal{U}
contains a partition regular class” is
\Pi^{0}_{2}
.

Proof.

By
proposition

2.10
, the class
\mathcal{U}
contains a partition regular class iff
\omega\in\mathcal{L}(\mathcal{U})
, which is a
\Pi^{0}_{2}
sentence.
∎

The partition regular class of all infinite sets can be generalized to a whole family of non-trivial partition regular classes in the following way.

Definition 2.14
.

For any infinite set
X
we define
\mathcal{L}_{X}
as the
\Pi^{0}_{2}(X)
partition regular class of the sets that intersect
X
infinitely often.

In particular,
\mathcal{L}_{\omega}
is the class of all infinite sets. It is not the only possible kind of
\Pi^{0}_{2}
partition regular class. There are examples of
\Pi^{0}_{2}
partition regular classes
\mathcal{L}
such that
\mathcal{L}_{X}\nsubseteq\mathcal{L}
for any
X\in[\omega]^{\omega}
. Consider for instance the class
\{X\subseteq\omega:\ \sum_{n\in X}\frac{1}{n}=\infty\}
.

We finish this section by proving that there the only
\mathbf{\Sigma^{0}_{2}}
partition regular classes are the trivial ones.

Proposition 2.15

There are no non-trivial
\mathbf{\Sigma^{0}_{2}}
partition regular classes.

Proof.

Fix a set
Z
.
If a
\Sigma^{0,Z}_{1}
class contains all the finite sets, then by Mileti
[
13
]
, it also contains all the
Z
-hyperimmune sets : Let
\mathcal{U}
be such a
\Sigma^{0,Z}_{1}
class. Let
X\not\in\mathcal{U}
. For any
n
and every string
\sigma
of length
n
we have
\sigma 0^{\infty}\in\mathcal{U}
. Let then
Z
-compute
f(n)
such that for any
\sigma
of length
n
we have
[\sigma 0^{f(n)}]\subseteq\mathcal{U}
.
It must be that
X\upharpoonright_{n+f(n)}
contains at least a
1
at a position greater than
n
. By repeating this we see that we can
Z
-computably bound
p_{X}
.

Suppose now for contradiction that there exists a non-trivial
\mathbf{\Sigma^{0}_{2}}
partition regular class
\mathcal{C}
. Let
Z
be such that
\mathcal{C}
is
\Sigma^{0,Z}_{2}
. In particular,
2^{\omega}\setminus\mathcal{C}
contains all the hyperimmune sets. Consider now any set
X
such that both
X
and
\overline{X}
are
Z
-hyperimmune. By partition regularity, at least one of them belongs to
\mathcal{C}
, which is a contradiction.
∎

2.5
Partition largeness

As mentioned earlier, a partition regular class represents a notion of largeness. However, a class containing a partition regular class is not necessarily itself partition regular. These classes admit a nice characterization.

Definition 2.16
.

A
partition large class
is a non-empty collection of sets
\mathcal{A}\subseteq 2^{\omega}
such that

(a)

If
X\in\mathcal{A}
and
Y\supseteq X
, then
Y\in\mathcal{A}

(b)

For every
k
, if
Y_{0}\cup\dots\cup Y_{k}\supseteq\omega
, there is some
j\leq k
such that
Y_{j}\in\mathcal{A}
.

Proposition 2.17

A class
\mathcal{A}\subseteq 2^{\omega}
is partition large iff it is upward-closed and contains a partition regular subclass.

Proof.

Suppose
\mathcal{A}
is upward-closed and contains a partition regular subclass
\mathcal{L}\subseteq\mathcal{A}
.
(a) is trivially satisfied by hypothesis. By partition regularity of
\mathcal{L}
,
\omega\in\mathcal{L}
and for every
k
and every
Y_{0}\cup\dots\cup Y_{k}\supseteq\omega
, there is some
j\leq k
such that
Y_{j}\in\mathcal{L}\subseteq\mathcal{A}
. So
\mathcal{A}
is partition large.

Suppose now
\mathcal{A}
is partition large. By (a), it is upward-closed. We claim that
\mathcal{L}(\mathcal{A})
is partition regular. By (b) and
Proposition

2.10
,
\omega\in\mathcal{L}(\mathcal{A})
, so
\mathcal{L}(\mathcal{A})\neq\emptyset
. By definition of
\mathcal{L}(\mathcal{A})
, it is partition regular, hence
\mathcal{A}
contains a partition regular subclass.
∎

Lemma 2.18

Let
\mathcal{L}\subseteq 2^{\omega}
be a non-trivial partition regular class and
X\in\mathcal{L}
. Then
\mathcal{L}\cap\mathcal{L}_{X}
is partition large.

Proof.

Let
Y_{0}\cup\dots\cup Y_{k}\supseteq\omega
. In particular we have
Y_{0}\cap X\cup\dots\cup Y_{k}\cap X\supseteq X
. As
X\in\mathcal{L}
we must have
Y_{j}\cap X\in\mathcal{L}
for some
j\leq k
. In particular, since
\mathcal{L}
is non-trivial,
Y_{j}\cap X
is infinite, so
Y_{j}\cap X\in\mathcal{L}_{X}
. Therefore, there is some
j\leq k
such that
Y_{j}\cap X\in\mathcal{L}\cap\mathcal{L}_{X}
.
∎

The following proposition yields another definition of
\mathcal{L}(\mathcal{A})
which will be very useful.

Proposition 2.19

Let
\mathcal{A}\subseteq\mathcal{U}_{2}
be a partition large class. Then

\mathcal{L}(\mathcal{A})=\{X:\mathcal{A}\cap\mathcal{L}_{X}\mbox{ is partition large}\}

Proof.

Let
\mathcal{L}=\{X:\mathcal{A}\cap\mathcal{L}_{X}\mbox{ is partition large}\}
.
Since
\mathcal{A}
is partition large, then by
Proposition

2.17
,
\mathcal{L}(\mathcal{A})
is the largest partition regular subclass of
\mathcal{A}
. Moreover, by
Proposition

2.6
,
\mathcal{L}(\mathcal{A})
is non-trivial since
\mathcal{L}(\mathcal{A})\subseteq\mathcal{U}_{2}
. Thus, by
Lemma

2.18
, for every
X\in\mathcal{L}(\mathcal{A})
,
\mathcal{L}(\mathcal{A})\cap\mathcal{L}_{X}
is partition large. In particular,
\mathcal{A}\cap\mathcal{L}_{X}
is partition large, hence
X\in\mathcal{L}
. It follows that
\mathcal{L}(\mathcal{A})\subseteq\mathcal{L}
.

Let us show that
\mathcal{L}
is partition regular. First,
\mathcal{A}\cap\mathcal{L}_{\omega}=\mathcal{A}
is partition large, so
\omega\in\mathcal{L}
.
Let
X\in\mathcal{L}
and
Y_{0}\cup\dots\cup Y_{k}\supseteq X
. In particular,
\mathcal{A}\cap\mathcal{L}_{X}
is partition large, so by
Proposition

2.17
,
\mathcal{L}(\mathcal{A}\cap\mathcal{L}_{X})
is partition regular. Moreover,
X\in\mathcal{L}(\mathcal{A}\cap\mathcal{L}_{X})
, so there is some
i\leq k
such that
Y_{i}\in\mathcal{L}(\mathcal{A}\cap\mathcal{L}_{X})
. By
Lemma

2.18
,
\mathcal{L}(\mathcal{A}\cap\mathcal{L}_{X})\cap\mathcal{L}_{Y_{i}}
is partition large. Since
\mathcal{L}(\mathcal{A}\cap\mathcal{L}_{X})\cap\mathcal{L}_{Y_{i}}\subseteq\mathcal{A}\cap\mathcal{L}_{Y_{i}}
, then
\mathcal{A}\cap\mathcal{L}_{Y_{i}}
is partition large, so
Y_{i}\in\mathcal{L}
.

Last, let us show that
\mathcal{L}\subseteq\mathcal{A}
. Indeed, if
\mathcal{A}\cap\mathcal{L}_{X}
is partition large, then since
X\cup\overline{X}=\omega
, either
X
, or
\overline{X}
belongs to
\mathcal{A}\cap\mathcal{L}_{X}
. However,
\overline{X}\not\in\mathcal{L}_{X}
, so
X\in\mathcal{A}\cap\mathcal{L}_{X}
. In particular,
X\in\mathcal{A}
.
It follows that
\mathcal{L}
is a partition regular subclass of
\mathcal{A}
, so by maximality of
\mathcal{L}(\mathcal{A})
,
\mathcal{L}\subseteq\mathcal{L}(\mathcal{A})
.
∎

Recall that
Proposition

2.6
characterizes non-trivial partition regular classes as those which are included in the
\Sigma^{0}_{1}
class
\mathcal{U}_{2}
of sets containing at least two distinct elements. Since there is no non-empty
\Sigma^{0}_{1}
class containing only infinite sets, we take this characterization as the natural generalization of non-triviality to arbitrary classes.

Definition 2.20
.

A class
\mathcal{A}\subseteq 2^{\omega}
is
non-trivial
if it is included in the
\Sigma^{0}_{1}
class
\mathcal{U}_{2}
of sets containing at least two distinct elements.

2.6
Partition genericity

Given a
\Pi^{0}_{2}
partition regular class
\mathcal{L}
and a set
X
, then either
X\in\mathcal{L}
, or
\overline{X}\in\mathcal{L}
. In general, whether the first or the second case holds depends on the choice of
\mathcal{L}
. For some sets however, the same case always holds. This yields the notion of partition genericity.

Definition 2.21
.

Let
\mathcal{A}\subseteq 2^{\omega}
be a class. We say that
X
is
partition generic in
\mathcal{A}
if
X
belongs to every non-trivial
\Pi^{0}_{2}
partition regular subclass of
\mathcal{A}
. If
X
is partition generic in
2^{\omega}
we simply say that
X
is
partition generic
.

The first and most trivial example of partition generic set is
\omega
.
First, note that partition genericity is closed under finite changes.

Proposition 2.22

If
X
is partition generic in
\mathcal{A}
and
Y=^{*}X
, then
Y
is partition generic in
\mathcal{A}
.

Proof.

Let
\mathcal{L}\subseteq\mathcal{A}
be any non-trivial
\Pi^{0}_{2}
partition regular subclass of
\mathcal{A}
.
Since
X
is partition generic in
\mathcal{A}
, then
X\in\mathcal{L}
. Since
Y=^{*}X
, by
Proposition

2.7
,
Y\in\mathcal{L}
.
Therefore
Y
is partition generic in
\mathcal{A}
.
∎

It follows that every co-finite set is partition generic. Actually, this characterizes the computable partition generic sets. Indeed, if
A
is a co-infinite computable set, then
\mathcal{L}_{\overline{A}}
is a non-trivial
\Pi^{0}_{2}
partition regular class which does not contain
A
.

Definition 2.23
.

Let
\mathcal{A}\subseteq 2^{\omega}
be a class. We say that
X
is
bi-partition generic in
\mathcal{A}
if
X
and
\overline{X}
are both partition generic in
\mathcal{A}
. If
X
is bi-partition generic in
2^{\omega}
we simply say that
X
is
bi-partition generic
.

The existence of bi-partition generic sets follows from
Proposition

2.7
. Note that, contrary to partition genericity, no computable set is bi-partition generic.

Proposition 2.24

Every bi-partition generic set is bi-immune.

Proof.

Let
A
be bi-partition generic. Let
X
be an infinite subset of
A
.
Then
\mathcal{L}_{X}
is a partition regular class such that
\overline{A}\not\in\mathcal{L}_{X}
.
Since
\overline{A}
is partition generic,
\mathcal{L}_{X}
is not
\Pi^{0}_{2}
, so
X
is not computable.
Similarly,
\overline{A}
has no infinite computable subset.
∎

In particular, every bi-partition generic set is bi-infinite. We now prove that every typical set is bi-partition generic, that is, every sufficiently random or generic set is bi-partition generic.

Proposition 2.25

Every Kurtz random is bi-partition generic.

Proof.

By
Proposition

2.7
, every non-trivial measurable partition regular class is of measure
1
. It follows that any Kurtz-random belongs to every
\Pi^{0}_{2}
partition regular class and thus that any Kurtz-random is bi-partition generic.
∎

In particular, one can be bi-hyperimmune and bi-partition generic.
The following proposition shows that is actually always the case,
in the sense that every bi-hyperimmune set is bi-partition generic.

Proposition 2.26

Every co-hyperimmune set is partition generic.

Proof.

Let
A
be a co-hyperimmune set.
Suppose for the contradiction that
A\not\in\mathcal{L}

for some non-trivial
\Pi^{0}_{2}
partition regular class
\mathcal{L}\subseteq 2^{\omega}
. In particular, there is a partition large
\Sigma^{0}_{1}
class
\mathcal{U}\supseteq\mathcal{L}
such that
A\not\in\mathcal{U}
.
Since
\mathcal{U}
is partition large, for every
t\in\omega
, there is some
\rho\in 2^{<\omega}
with
\min\rho>t
such that
\rho\in\mathcal{U}
.
In particular, for every such
\rho
, we have
\rho\cap\overline{A}\neq\emptyset
. Moreover, such a string
\rho
can be found computably uniformly in
t
. We can therefore compute an array tracing
\overline{A}
, contradicting hyperimmunity of
\overline{A}
.
∎

Corollary 2.27

Every bi-hyperimmune set is bi-partition generic.

Proof.

Immediate by
Proposition

2.26
.
∎

As mentioned earlier, every sufficiently random set is bi-partition generic. Moreover, every sufficiently random set is effectively bi-immune. It is natural to wonder whether every effectively co-immune set is partition generic. The following proposition answers negatively.

Proposition 2.28

There is an effectively co-immune set which is not partition generic.

Proof.

Consider the following
\Pi^{0}_{2}
class
\mathcal{L}=\{X\ :\ \forall k\ \exists n\ |X\upharpoonright_{n^{2}}|\geq nk\}
. Let us prove it is partition regular : Let
X\in\mathcal{L}
and
Y_{1}\cup\dots Y_{m}\supseteq X
. For
k\in\omega
there is some
n
such that
|X\upharpoonright_{n^{2}}|\geq nmk
. Then, there is some
e_{k}\leq m
such that
|Y_{e_{k}}\upharpoonright_{n^{2}}|\geq nk
. Let
e\leq m
be such that
e=e_{k}
for infinitely many
k
. We then have for infinitely many
k
that there exists
n
such that
|Y_{e}\upharpoonright_{n^{2}}|\geq nk
. This is therefore true in particular for every
k
. Thus
Y_{e}\in\mathcal{L}
, so
\mathcal{L}
is partition regular.

It suffices to construct an effectively co-immune set
A
such that for every
n
,
|A\upharpoonright_{n^{2}}|<n
for every
n
. Then
A\not\in\mathcal{L}
, hence
A
is not partition generic.
To construct such a set, for every
e
, let
x_{e}
be the
e^{2}
th element of
W_{e}
(in the
<_{\omega}
order), if it exists. Assume by convention that
W_{0}=\emptyset
, so
e_{0}
does not exist. Let
A=\{x_{e}:e\in\omega\}
. Then
A
is an infinite set, which is effectively co-immune, as witnessed by the fonction
n\mapsto n^{2}
. Last, for every
n
,
A\upharpoonright_{n^{2}}\subseteq\{x_{e}:e<n\}
, so
|A\upharpoonright_{n^{2}}|<n
.
∎

We have seen so far three classes of partition generic sets: co-finite sets, co-hyperimmune sets and Kurtz randoms. Let us construct a bi-partition generic set which belongs to none of these categories.

Proposition 2.29

There is a bi-partition generic set
A
such that for every
n
,
A(2n)\neq A(2n+1)
.

Proof.

Consider the notion of forcing whose conditions are strings
\sigma
of even length, such that for every
n<|\sigma|/2
,
\sigma(2n)\neq\sigma(2n+1)
. The conditions are partially ordered by the suffix relation. Let us show that every sufficiently generic set
G
is bi-partition generic.

Let
\sigma
be a condition, and let
\mathcal{U}
be a non-trivial
\Sigma^{0}_{1}
partition large class. Let
X_{0}=\{2n:2n>|\sigma|\}
and
X_{1}=\{2n+1:2n+1>|\sigma|
. Since
\{0\}\cup\dots\cup\{|\sigma|\}\cup X_{0}\cup X_{1}\supseteq\omega
, then either
X_{0}\in\mathcal{U}
, or
X_{1}\in\mathcal{U}
. Say the former case holds as the other case is symmetric. Since
\mathcal{U}
is
\Sigma^{0}_{1}
, then there is some
k
such that
[X_{0}\upharpoonright_{2k}]\subseteq\mathcal{U}
. Let
\tau=\sigma\cup X_{0}\upharpoonright_{2k}
. Note that
\tau
is a valid condition. Moreover, since
\mathcal{U}
is closed under superset, then
[\tau]\subseteq\mathcal{U}
. Therefore, every sufficiently generic set
G
for this notion of forcing belongs to every non-trivial
\Sigma^{0}_{1}
partition large class. By symmetric, so does the complement of
G
, so
G
is bi-partition generic.
∎

Corollary 2.30

There is a bi-partition generic set which is neither co-hyperimmune, nor Kurtz random.

Proof.

Consider the set
A
of
Proposition

2.29
.
It is clearly neither hyperimmune nor co-hyperimmune since
F_{0},F_{1},\dots
defined by
F_{n}=\{2n,2n+1\}
is a c.e. array tracing both
A
and
\overline{A}
.
Furthermore,
A
is not Kurtz random, since
A\in\{X:\forall nX(2n)\neq X(2n+1)\}
which is a
\Pi^{0}_{1}
class of measure 0.
∎

The following lemma is a sort of pigeonhole principle, from which we will derive partition regularity of the class of sets which are partition generic in some non-trivial
\Sigma^{0}_{1}
partition large class.

Lemma 2.31

Let
\mathcal{A}\subseteq 2^{\omega}
be a class and
X
be a set which is partition generic in
\mathcal{A}
. For every
Y_{0}\cup Y_{1}\supseteq X
, if
Y_{0}\notin\mathcal{L}(\mathcal{A})
then
Y_{1}
is partition generic in
\mathcal{A}
.

Proof.

Suppose for contradiction that there is a non-trivial
\Pi^{0}_{2}
partition regular class
\mathcal{V}\subseteq\mathcal{A}
such that
Y_{1}\notin\mathcal{V}
. In particular,
\mathcal{V}\subseteq\mathcal{L}(A)
, so
Y_{0}\notin\mathcal{V}
. By partition regularity of
\mathcal{V}
, since
Y_{0}\cup Y_{1}\supseteq X
, then
X\notin\mathcal{V}
, which contradicts partition genericity of
X
in
\mathcal{A}
.
∎

Proposition 2.32

Let
\mathcal{A}
be a partition large class. Suppose
X
is partition generic in
\mathcal{A}
. Let
Y_{0}\cup\dots\cup Y_{k}\supseteq X
. Then there is a
\Sigma^{0}_{1}
class
\mathcal{U}
such that
\mathcal{U}\cap\mathcal{A}
is partition large, together with some
i\leq k
such that
Y_{i}
is partition generic in
\mathcal{U}\cap\mathcal{A}
.

Proof.

We prove the statement by the lemma by induction on
k
.
For
k=0
,
Y_{0}\supseteq X
so
Y_{0}
is partition generic in
\mathcal{A}
by upward-closure of partition genericity. Take
\mathcal{U}=2^{\omega}
and we are done.

Suppose now that the property holds for
k-1
. Suppose
Y_{k}
is not partition generic in
\mathcal{A}
.
Thus there is a non-trivial
\Pi^{0}_{2}
partition regular class
\bigcap_{e\in C}\mathcal{U}_{e}\subseteq\mathcal{A}
such that
Y_{k}\not\in\bigcap_{e\in C}\mathcal{U}_{e}
. In particular, there is some
e\in\mathcal{C}
such that
Y_{k}\notin\mathcal{U}_{e}
. Note that
\bigcap_{e\in C}\mathcal{U}_{e}\subseteq\mathcal{A}\cap\mathcal{U}_{e}
, so
\mathcal{A}\cap\mathcal{U}_{e}
is partition large. By
Lemma

2.31
,
Y_{0}\cup\dots\cup Y_{k-1}
is partition generic in
\mathcal{U}_{e}\cap\mathcal{A}
. By induction hypothesis on
\mathcal{U}_{e}\cap\mathcal{A}
and
Y_{0}\cup\dots\cup Y_{k-1}
, there is a
\Sigma^{0}_{1}
class
\mathcal{V}
such that
\mathcal{V}\cap\mathcal{U}_{e}\cap\mathcal{A}
is partition large, together with some
i<k
such that
Y_{i}
is partition generic in
\mathcal{V}\cap\mathcal{U}_{e}\cap\mathcal{A}
. The property therefore holds with the
\Sigma^{0}_{1}
class
\mathcal{V}\cap\mathcal{U}_{e}
.
∎

Corollary 2.33

The following class is partition regular :

\mathcal{P}=\{X:X\mbox{ is partition generic in some non-trivial }\Sigma^{0}_{1}\mbox{ partition large class}\}

Proof.

First,
\omega
is partition generic in
\mathcal{U}_{2}=\{X:|X|\geq 2\}
.
Suppose
X\in\mathcal{P}
and let
Y_{0}\cup\dots\cup Y_{k}\supseteq X
. Let
\mathcal{U}\subseteq 2^{\omega}
be a non-trivial
\Sigma^{0}_{1}
partition large class in which
X
is partition generic. By
Proposition

2.32
, there is a
\Sigma^{0}_{1}
class
\mathcal{V}
such that
\mathcal{U}\cap\mathcal{V}
is partition large, together with some
i\leq k
such that
Y_{i}
is partition generic in
\mathcal{U}\cap\mathcal{V}
. Note that
\mathcal{U}\cap\mathcal{V}\subseteq\mathcal{U}
, hence is non-trivial. It follows that
Y_{i}\in\mathcal{P}
.
∎

Partition genericity within a large class is not an interesting notion of typicality whenever one does not put effectiveness restrictions on the large classes. Indeed, we shall see that every infinite set is partition generic relative to itself within a large class.
Given an infinite set
X
, let
\mathcal{U}_{X,2}=\{Y:|Y\cap X|\geq 2\}
.

Lemma 2.34

For every set
X
,
\mathcal{L}(\mathcal{U}_{X,2})=\mathcal{L}_{X}
.

Proof.

First, let us show that
\mathcal{L}_{X}\subseteq\mathcal{L}(\mathcal{U}_{X,2})
.
Suppose that
Y\in\mathcal{L}_{X}
. By definition,
|Y\cap X|=\infty
, so
Y\in\mathcal{U}_{X,2}
.
So
\mathcal{L}_{X}
is a partition regular subclass of
\mathcal{U}_{X,2}
. Since
\mathcal{L}(\mathcal{U}_{X,2})
is the largest partition regular subclass of
\mathcal{U}_{X,2}
, then
\mathcal{L}_{X}\subseteq\mathcal{L}(\mathcal{U}_{X,2})
.

Then, let us show that
\mathcal{L}(\mathcal{U}_{X,2})\subseteq\mathcal{L}_{X}
.
Let
Y\in\mathcal{L}(\mathcal{U}_{X,2})
. We claim that
|Y\cap X|=\infty
. Indeed, otherwise, consider the
|Y\cap X|
-cover of
Y\cap X
made of singletons. By partition regularity of
\mathcal{L}(\mathcal{U}_{X,2})
, one of the parts belongs to
\mathcal{U}_{X,2}
, but
\mathcal{U}_{X,2}
contains no singleton, contradiction. Therefore
|Y\cap X|=\infty
, so
Y\in\mathcal{L}_{X}
.
∎

Lemma 2.35

For every infinite set
X
,
\mathcal{U}_{X,2}
is a non-trivial
\Sigma^{0}_{1}(X)
partition large class.

Proof.

\mathcal{U}_{X,2}
is clearly non-trivial, upward-closed and
\Sigma^{0}_{1}(X)
.
By
Lemma

2.34
,
\mathcal{L}(\mathcal{U}_{X,2})=\mathcal{L}_{X}
. Since
X
is infinite,
X\in\mathcal{L}_{X}
, so
\mathcal{L}(\mathcal{U}_{X,2})\neq\emptyset
. By
Proposition

2.17
,
\mathcal{U}_{X,2}
is large.
∎

The following lemma shows, as promised, that every infinite set is partition generic relative to itself within a large class.

Lemma 2.36

For every set
X
,
X
belongs to any large subclass of
\mathcal{U}_{X,2}
.

Proof.

Let
\mathcal{V}
be a large subclass of
\mathcal{U}_{X,2}
.
Suppose for the contradiction that
X\not\in\mathcal{V}
. By largeness of
\mathcal{V}
,
\overline{X}\in\mathcal{V}\subseteq\mathcal{U}_{X,2}
. Then
|\overline{X}\cap X|\geq 2
, contradiction.
∎

By Patey
[
16
]
, if
f
is a hyperimmune function, then for every set
A
, there is an infinite subset
H\subseteq A
or
H\subseteq\overline{A}
such that
f
is
H
-hyperimmune. Is it also the case if one replaces hyperimmunity by partition genericity? We answer negatively by constructing a specific bi-partition generic set which is neither Kurtz random, nor bi-hyperimmune.

Lemma 2.37

For every set
A
and every infinite set
H\subseteq\overline{A}
, then
A
is not
H
-partition generic.

Proof.

By
Lemma

2.35
,
\mathcal{U}_{H,2}
is a non-trivial
\Sigma^{0}_{1}(A)
partition large class. In particular,
\mathcal{L}(\mathcal{U}_{H,2})
is a non-trivial
\Pi^{0}_{2}(H)
partition generic class.
However,
A\not\in\mathcal{U}_{H,2}\supseteq\mathcal{L}(\mathcal{U}_{H,2})
, so
A
is not
H
-partition generic.
∎

Proposition 2.38

There is a bi-partition generic set
A
such that for every infinite set
H\subseteq A
and
H\subseteq\overline{A}
, neither
A
nor
\overline{A}
is
H
-partition generic.

Proof.

Let
A
be the bi-partition generic set of
Proposition

2.29
.
Let

. By
Lemma

2.37
,
\overline{A}
is not

3
Applications

We now justify the study of partition genericity by proving several partition genericity subset basis theorems.
All these basis theorems are proven with the same notion of forcing, that we call
partition generic Mathias forcing
. A
condition
is a tuple
(\sigma,X,\mathcal{U})
, where
(\sigma,X)
is a Mathias condition, that is,
\sigma
is a finite string and
X
is an infinite set such that
\min X>|\sigma|
. Moreover,
\mathcal{U}
is a non-trivial large
\Sigma^{0}_{1}
class within which
X
is partition generic. A condition
(\tau,Y,\mathcal{V})

extends
another condition
(\sigma,X,\mathcal{U})
if
(\tau,Y)
Mathias extends
(\sigma,X)
, that is,
\sigma\prec\tau
,
Y\subseteq X
and
\tau\setminus\sigma\subseteq X
. Moreover, we require that
\mathcal{V}\subseteq\mathcal{U}
.

Note that we do not impose any effectivity restriction to the reservoir
X
. In particular, if
A
is a set which is partition generic in a non-trivial
\Sigma^{0}_{1}
large class
\mathcal{U}
, then we will consider sufficiently generic filters containing the condition
(\emptyset,A,\mathcal{U})
. Indeed, any such filter
\mathcal{F}
induces a subset
G_{\mathcal{F}}=\bigcup_{(\sigma,X,\mathcal{V})\in\mathcal{F}}\sigma
of
A
.

The first property we prove is that
G_{\mathcal{F}}
is an infinite set.

Lemma 3.1

Let
\mathcal{F}
be a sufficiently generic filter. Then
G_{\mathcal{F}}
is infinite.

Proof.

Let us show that for any
n
, the set of conditions
(\tau,Y,\mathcal{U})
such that
\tau(x)=1
for some
x>n
is dense.
Let
(\sigma,X,\mathcal{U})
be a condition. Since
X
is partition generic in
\mathcal{U}
and
\mathcal{U}
is non-trivial, then
X\in\mathcal{L}(\mathcal{U})
, hence
X
is infinite. Let
x\in X
be greater than
n
, let
\tau
be string
\sigma\cup\{x\}
and let
Y=X\setminus\{0,\dots,|\rho|\}
. By
Proposition

2.22
,
Y
is partition generic in
\mathcal{U}
. Therefore,
(\tau,Y,\mathcal{U})
is a valid extension of
(\sigma,X,\mathcal{U})
.
∎

We now turn to the various partition genericity subset basis theorems.

3.1
Cone avoidance

The first one is the
cone avoidance partition genericity subset basis theorem
. Recall that Dzhafarov and Jockusch
[

]
proved that if

or

such that

Lemma 3.2

Let
B
be a non-computable set and let

be a Turing functional.
Then for every condition
(\sigma,X,\mathcal{U})
, there is an extension
(\tau,Y,\mathcal{U})

forcing

Proof.

A

\rho_{0},\rho_{1}
such that there is an input

for which
\Phi_{e}^{\sigma\cup\rho_{0}}(x)\downarrow\neq\Phi_{e}^{\sigma\cup\rho_{1}}(x)\downarrow

Case 1: the following class is large:

\mathcal{A}=\{Y\in\mathcal{U}:Y\emph{containsasplitpair}\}

Since
\mathcal{A}
is a non-trivial
\Pi^{0}_{2}
large subclass of
\mathcal{U}
and

is partition generic in
\mathcal{U}
, then
X\in\mathcal{A}
. Let
\rho_{0},\rho_{1}\subseteq X
be a split pair, with witness

.
In particular, there is some
i<2
such that
\Phi_{e}^{\sigma\cup\rho_{i}}(x)\neq B(x)

Let
Y=X\setminus\{0,\dots,|\rho_{i}|\}
. By
Proposition

2.22
,
Y
is partition generic in
\mathcal{U}
.
Then
(\sigma\cup\rho_{i},Y,\mathcal{U})
is an extension of
(\sigma,X,\mathcal{U})
forcing
\Phi_{e}^{G}(x)\neq B(x)
.

Case 2: there is some
k\in\omega
such that the following class is non-empty:

\mathcal{C}=\{Z_{0}\oplus\dots\oplus Z_{k-1}:Z_{0}\cup\dots\cup Z_{k-1}=\omega\wedge\forall i<k\ Z_{i}\,\not\in\mathcal{U}\mbox{ or }Z_{i}\mbox{ contains no split pair }\}

Note that
\mathcal{C}
is a
\Pi^{0}_{1}
class. By the cone avoidance basis theorem
[
6
]
, there is an element

such that

. By
Proposition

2.32
, there is a
\Sigma^{0}_{1}
class
\mathcal{V}
such that
\mathcal{V}\cap\mathcal{U}
is large and some

such that
Z_{i}\cap X
is partition generic in
\mathcal{V}\cap\mathcal{U}
. Note that in particular,
Z_{i}\cap X\in\mathcal{V}\cap\mathcal{U}
, so
Z_{i}\in\mathcal{U}
, hence
Z_{i}
contains no split pair.

The condition
(\sigma,Z_{i}\cap X,\mathcal{V}\cap\mathcal{U})
is a valid extension of
(\sigma,X,\mathcal{U})
.

We claim that
(\sigma,Z_{i}\cap X,\mathcal{V}\cap\mathcal{U})
forces
\Phi^{G}_{e}\neq B
.
Suppose for the contradiction that
\Phi^{G_{\mathcal{F}}}_{e}=B
for some generic filter
\mathcal{F}
.
Let

be the partial
Z_{i}
-computable function which on input

searches for some
\rho\subseteq Z_{i}
such that
\Phi^{\sigma\cup\rho}_{e}(x)\downarrow
. If such a

is found, then

.
Since
\Phi^{G_{\mathcal{F}}}_{e}=B
, then

is total. Since

contains no split pair, then

, which contradicts the assumption that

.
∎

3.3
Constant-bound trace avoidance

Soon after proving his PA avoidance pigeonhole basis theorem, Liu proved a constant bound trace avoidance pigeonhole basis theorem, with several consequences, such as the existence, for every set
A\subseteq\omega

H\subseteq A
or

which does not compute any Martin-Löf random, or even no set of positive Hausdorff dimension.

Definition 3.9
.

A
k
-trace
is a sequence of finite sets of strings
F_{0},F_{1},\dots
such that for every
n

|F_{n}|=k
and every string

-trace

[

proved that if

or

3.4
Lowness

It is clearly not the case that for every set
A\subseteq\omega
, there is an infinite subset
H\subseteq A
or
H\subseteq\overline{A}
of low degree. One can simply pick
A
to be any bi-immune set relative to
\emptyset^{\prime}
. Then
A
has no even
\Delta^{0}_{2}
infinite subset in it or its complement. Therefore, there is no low or even
\Delta^{0}_{2}
partition genericity subset basis theorem. More interestingly, Downey, Hirschfeldt, Lempp and Solomon
[
2
]
constructed a
\Delta^{0}_{2}
set with no low infinite subset in it or its complement, using a very involved infinite injury priority argument. Thus, there no hope of proving that every
\Delta^{0}_{2}
partition generic sets has a low subset. On the other hand, if
A
is a
\Delta^{0}_{2}
set such that
\overline{A}
is not partition generic, then
A
is partition generic in a non-trivial
\Sigma^{0}_{1}
partition large class in a strong sense, in which case
A
admits an infinite low subset.

Theorem 3.15

Let
A
be a
\Delta^{0}_{2}
set such that
\overline{A}
is not partition generic.
Then there is an infinite subset
G\subseteq A
of low degree.

Proof.

Let
\bigcap_{n}\mathcal{V}_{n}
be a
\Pi^{0}_{2}
partition regular class such that
\overline{A}\not\in\bigcap_{n}\mathcal{V}_{n}
. In particular, there is some
m\in\omega
such that
\overline{A}\not\in\mathcal{V}_{m}
.
Define a
\Delta^{0}_{2}
decreasing sequence of Mathias conditions
(\sigma_{0},X_{0})\geq(\sigma_{1},X_{1})\geq\dots
such that for every
s\in\omega

(1)

\sigma_{s}\subseteq A
;
X_{s}
is low ;
X_{s}\in\bigcap_{n}\mathcal{V}_{n}
;

(2)

\sigma_{s+1}\in\mathcal{V}_{e}
if
s=2e
;

(3)

(\sigma_{s+1},X_{s+1})\Vdash\Phi^{G}_{e}(e)\downarrow
or
(\sigma_{s+1},X_{s+1})\Vdash\Phi^{G}_{e}(e)\uparrow
if
s=2e+1

Start with the condition
(\emptyset,\omega)
.

Satisfying (2)
:
Given a condition
(\sigma_{s},X_{s})
at a stage

, search
\emptyset^{\prime}
-computably for some finite

such that
\rho\in\mathcal{V}_{s}
. We claim that such a
\rho
must exist. Indeed, since
X
belongs to the partition regular class
\bigcap_{n}\mathcal{V}_{n}
, then either
X\cap A
or
X\cap\overline{A}
belongs to
\bigcap_{n}\mathcal{V}_{n}
. However,
\overline{A}\not\in\mathcal{V}_{m}
, so by upward-closure of partition regular classes,
X\cap\overline{A}\not\in\bigcap_{n}\mathcal{V}_{n}
, hence
X\cap A\in\bigcap_{n}\mathcal{V}_{n}
. The condition

Satisfying (3)

-computably if

-computably for some

4
Preservation of hyperimmunity

The purpose of this section is to find the right genericity notion admitting a preservation of hyperimmunity genericity basis theorem, implying the preservation of hyperimmunity pigeonhole basis theorem. More precisely, the following theorem was proven by Patey

Partition genericity is not the right notion to reprove this pigeonhole basis theorem. Indeed, the following proposition shows that there is no preservation of hyperimmunity partition genericity basis theorem.

Then,

is an infinite subset of

is not

-hyperimmune.
∎

The remainder of this section is devoted to the design of a notion of genericity which admits a preservation of hyperimmunity basis theorem, implying

5
Preservation of non-
\Sigma^{0}_{1}
definitions

The purpose of this section is to find the right genericity notion admitting a preservation of non-
\Sigma^{0}_{1}
definitions genericity basis theorem, implying the preservation of non-
\Sigma^{0}_{1}
definitions pigeonhole basis theorem. More precisely, the following theorem was proven by Wang
[
20
]
:

Theorem 5.1

(Wang
[
20
]
)

If
B
is a non-
\Sigma^{0}_{1}
set, then for every set
A\subseteq\omega
, there is an infinite set
H\subseteq A
or
H\subseteq\overline{A}
such that
B
is not
\Sigma^{0}_{1}(H)
.

Partition genericity is not the right notion to reprove this pigeonhole basis theorem. Indeed, the following proposition shows that there is no preservation of non-
\Sigma^{0}_{1}
definitions partition genericity basis theorem.

Proposition 5.2

There is a non-
\Sigma^{0}_{1}
set
B
and a partition generic set
A
such that
B
is
\Sigma^{0}_{1}
in every infinite subset of
A
.

Proof.

Fix any computable linear order
L=(\omega,<_{L})
of order type
\omega+\omega^{*}
with no infinite computable ascending or descending sequence (see Rosenstein
[
17
]
). Let
A
be the
\omega
part of this order. Note that
\overline{A}
is the
\omega^{*}
part of this order.
First, note that
A
is bi-hyperimmune. Indeed, suppose
F_{0},F_{1},\dots
is a c.e. array such that for every
n
,
F_{n}\cap A\neq\emptyset
. Then the set
X=\{\min_{<_{L}}F_{n}:n\in\omega\}
is an infinite c.e. subset of
A
. By thinning out the set
X
, one can compute an infinite increasing sequence, contradicting our assumption. Thus
A
is hyperimmune.
By a symmetric argument,
A
is co-hyperimmune.

By
Proposition

2.26
, since
A
is co-hyperimmune, it is partition generic. Let
B=A
. Since
A
is hyperimmune, then it is not c.e. Let
H
be any infinite subset of
A
.
Then
B=\{x\in\omega:\exists n\in H,\ x<_{L}n\}
. Thus
B
is c.e. in every infinite subset of
A
.
∎

The remainder of this section is devoted to the design of a notion of genericity which admits a preservation of non-c.e. definitions basis theorem, implying
Theorem

5.1
.

5.1

From now on, fix a set
B\subseteq\omega

5.4
, the only interesting case is when the set

is non-
\Sigma^{0}_{1}

Definition 5.3
.

A class
\mathcal{A}\subseteq 2^{\omega}\times\omega

\mathfrak{E}(B)
-large

1.

If
(X,n)\in\mathcal{A}

Suppose

Suppose

\mathfrak{E}(B)
-large
\Sigma^{0}_{1}

6
Partition genericity and computability

We conclude this study of partition regularity and partition genericity by considering the corresponding notions of lowness, and constructing a partition generic set which is both computably dominated and of non-DNC degree.

Definition 6.1
.

1.

A set
X
is
low for partition genericity
if every partition generic set is partition
X
-generic.

2.

A set
X
is
low for partition regularity
if for every
\Pi^{0}_{2}(X)
partition regular class
\mathcal{L}
, there is a
\Pi^{0}_{2}
partition regular subclass
\mathcal{M}\subseteq\mathcal{L}

3.

A set
X
is
low for partition largeness
if for every
\Sigma^{0}_{1}(X)
partition large class
\mathcal{U}
, there is a
\Sigma^{0}_{1}
large subclass
\mathcal{V}\subseteq\mathcal{U}
.

It is clear that if
X
is low for partition regularity or low for partition largeness, then it is low for partition genericity. Actually, all three notions are trivial, in the sense that the only degree which is low for partition genericity is the computable one.

Proposition 6.2

If
X
is low for partition genericity, then
X
is computable.

Proof.

Let
X
be a non-computable set. Let
A=\{\sigma\in 2^{<\omega}:\sigma\prec X\}
. Then
A\equiv_{T}X
and every infinite subset of
A
computes
A
.
Either
A
is partition generic in a non-trivial partition large
\Sigma^{0}_{1}
class, or
\overline{A}
is partition generic in
2^{\omega}
. In the first case, by
Theorem

3.3
, there is an infinite subset of
A
which does not compute
A
, contradiction. Therefore

is partition generic.

Let us show that
\overline{A}
is not partition generic relative to

Since

is a non-trivial

The degrees of partition generic sets are not fully understood. In
Section

2.6
, we proved that every co-hyperimmune set and every Kurtz random is partition generic. By the computably dominated basis theorem, there are Kurtz randoms of computably dominated degree. Since every weakly 1-generic is Kurtz random, there are Kurtz randoms of non-DNC degree. On the other hand, Stephan and Yu
[
18
]
proved that the degrees which are low for Kurtz-randomness are precisely the computably dominated non-DNC degrees, which implies that no Kurtz random is of both degrees simultaneously. We now prove the existence of a partition generic set which is low for Kurtz-randomness. This is done using a perfect tree forcing starting from a suitable tree.

Definition 6.3

Fix a canonical coding of all finite sets

Proposition 6.4

There is a partition generic set which is computably traceable and of minimal degree.

Proof.

A
function tree
is a function
T:2^{<\omega}\to 2^{<\omega}
such that for every
\sigma\in 2^{<\omega}
,
T(\sigma 0)
and
T(\sigma 1)
are incompatible extensions of
T(\sigma)
.
Any such function
T:2^{<\omega}\to 2^{<\omega}
induces a function
T:2^{\omega}\to 2^{\omega}
by defining
T(X)=\bigcup_{\sigma\prec X}T(\sigma)
. We then write
[T]=\{f(X):X\in 2^{\omega}\}
. A function tree
S

extends
a function tree
T
(written

) if
[S]\subseteq[T]
.

Lemma 6.5

There is a computable function tree
T_{0}
such that for every
X,Y\in 2^{\omega}
with
X\neq Y
,
then
T_{0}(X)\cup T_{0}(Y)=^{*}\omega

Proof.

Let
T_{0}(\epsilon)=\epsilon
. Suppose
T_{0}
is defined on
2^{\leq n}

n
.
Let
\sigma_{0},\sigma_{1},\dots,\sigma_{2^{n+1}-1}
be the list of all strings of length
n+1

For every
i<2^{n+1}

\tau_{i}
be the string of length
2^{n+1}
which has a 0 at position
i

T_{0}(\sigma_{i})=T_{0}(\sigma_{i}\upharpoonright_{n})^{\frown}\tau_{i}
.
For instance,
T_{0}(0)=01
,
T_{0}(1)=10
,
T(00)=010111
,
T(01)=011011
,
T(10)=101101
,
T(11)=101110
. Note that every two strings of same length is sent to strings of same length.

Let
X,Y\in\omega
be such that
X\neq Y
, and let
\sigma
be the longest common substring.
We claim that for every
n>|T_{0}(\sigma)
, then either
n\in T_{0}(X)
, or
n\in T_{1}(Y)
.
Indeed, let
t
be the smallest length such that
n<|T_{0}(X\upharpoonright_{t})|

n<|T_{0}(Y\upharpoonright_{t})|
. Let
i
and

be such that
X\upharpoonright_{t}
and

are respectively the

X\upharpoonright_{t}
and

By definition,

By choice of

.
∎

Consider the notion of forcing
