Abstract
. We consider a parabolic equation in a bounded domain Ω \Omega over a time interval ( 0 , T ) (0,T) with the homogeneous Neumann boundary condition. We arbitrarily choose a subboundary Γ ⊂ ∂ Ω \Gamma\subset\partial\Omega . Then, we discuss an inverse problem of determining a zeroth-order spatially varying coefficient by extra data of solution u u : u | Γ × ( 0 , T ) u|_{\Gamma\times(0,T)} and u ⁡ ( ⋅ , t 0 ) u(\cdot,t_{0}) in Ω \Omega with t 0 = 0 t_{0}=0 or t = T t=T . First we establish a conditional Lipschitz stability estimate as well as the uniqueness for the case t 0 = T . t_{0}=T. Second, under additional condition for Γ \Gamma , we prove the uniqueness for the case t 0 = 0 t_{0}=0 . The second result adjusts the uniqueness by M.V. Klibanov (Inverse Problems 8 (1992) 575-596) to the inverse problem in a bounded domain Ω \Omega . We modify his method which reduces the inverse parabolic problem to an inverse hyperbolic problem, and so even for the inverse parabolic problem, we have to assume conditions for the uniqueness for the corresponding inverse hyperbolic problem. Moreover we prove the uniqueness for some inverse source problem for a parabolic equation for t 0 = 0 t_{0}=0 without boundary condition on the whole ∂ Ω \partial\Omega .

[formula]

\left\|u\left(\frac{3T}{4},\cdot\right)\right\|_{L^{2}(\Omega)}\leq C(\|S\|_{L^{2}(Q_{3})}+\|u\|_{H^{1}(\Sigma)}).

In view of (2.6),
the standard a priori estimate for the initial value problem with

[

Combining this estimate with (2.3), we complete the proof of (2.4).

Proof of (2.7).

Since

\displaystyle=

\displaystyle\int_{\Omega}\sum_{k>j}a_{jk}((\partial_{k}u)\partial_{j}\partial_{t}u+(\partial_{j}u)\partial_{k}\partial_{t}u)dx+\int_{\Omega}\sum_{j=1}^{n}a_{jj}(\partial_{j}u)\partial_{j}\partial_{t}udx

\displaystyle=

\displaystyle\int_{\Omega}\sum_{k>j}a_{jk}\partial_{t}((\partial_{j}u)\partial_{k}u)dx+\frac{1}{2}\int_{\Omega}\sum_{j=1}^{n}a_{jj}\partial_{t}((\partial_{j}u)^{2})dx

\displaystyle=

\displaystyle\frac{1}{2}\int_{\Omega}\partial_{t}\left(\sum_{j,k=1}^{n}a_{jk}(\partial_{j}u)\partial_{k}u\right)dx.

Taking the scalar products of equation (2.2) by

\left(t-\frac{T}{4}\right)\partial_{t}u
in

and integrating by parts, we obtain

\displaystyle\int_{\frac{T}{4}}^{T}\int_{\Omega}\biggl((t-\frac{T}{4})(\partial_{t}u)^{2}+\frac{1}{2}\partial_{t}\left((t-\frac{T}{4})a(x,\nabla u,\nabla u)\right)-\frac{1}{2}a(x,\nabla u,\nabla u)

\displaystyle+

\displaystyle\left(\sum_{j=1}^{n}b_{j}(x)\partial_{j}u+p(x)u\right)(t-\frac{T}{4})\partial_{t}u\biggr)dxdt

\displaystyle=

\displaystyle\int_{\frac{T}{4}}^{T}\int_{\Omega}((t-\frac{T}{4})(\partial_{t}u)^{2}-\frac{1}{2}a(x,\nabla u,\nabla u)+\left(\sum_{j=1}^{n}b_{j}(x)\partial_{j}u+p(x)u\right)(t-\frac{T}{4})\partial_{t}u)dxdt

\displaystyle+

\displaystyle\frac{3T}{8}\int_{\Omega}a(x,\nabla u(T,x),\nabla u(T,x))dx

\displaystyle=

\displaystyle\int_{\frac{T}{4}}^{T}\int_{\Omega}(t-\frac{T}{4})(\partial_{t}u)S\,dxdt.

Hence, by

\displaystyle\int_{\frac{T}{4}}^{T}\int_{\Omega}(t-\frac{T}{4})(\partial_{t}u)^{2}dxdt\leq\int_{\frac{T}{4}}^{T}\int_{\Omega}\left(\frac{1}{2}a(x,\nabla u,\nabla u)+\left(\sum_{j=1}^{n}b_{j}(x)\partial_{j}u+p(x)u\right)(t-\frac{T}{4})\partial_{t}u\right)dxdt

\displaystyle+

\displaystyle\int_{\frac{T}{4}}^{T}\int_{\Omega}(t-\frac{T}{4})(\partial_{t}u)S\,dxdt.

Here for any

[formula]

\leq C(\|u\|^{2}_{L^{2}(\frac{T}{4},T;H^{1}(\Omega))}+\|S\|^{2}_{L^{2}(Q_{3})})\leq C(\|S\|^{2}_{L^{2}(Q_{3})}+\|u\|^{2}_{H^{1}(\Sigma)}).

In order to estimate the second space derivatives of

\displaystyle\left\|-\sum_{j,k=1}^{n}\partial_{j}(a_{jk}(x)\partial_{k}u(t,\cdot))\right\|_{L^{2}(\Omega)}

\displaystyle\leq

\displaystyle C(\|\partial_{t}u(t,\cdot)\|_{L^{2}(\Omega)}+\|\nabla u(t,\cdot)\|_{L^{2}(\Omega)}+M\|u(t,\cdot)\|_{L^{2}(\Omega)}+\|S(t,\cdot)\|_{L^{2}(\Omega)}),\quad\frac{T}{4}\leq t\leq T.

)
that the function

is analytic
in

Let

We note that after the extensions,

w(t,\cdot)\in L^{2}(\widetilde{\Omega})
for

for

.
Moreover, the function

is analytic in

Hence, the function

Next we extend

on

&0,\quad x\not\in\Omega.\end{array}\right.

Consider an initial boundary value problem

[formula]

\left\{\begin{array}[]{rl}&P\widetilde{w}:=\partial_{t}\widetilde{w}-A\widetilde{w}+p(x)\widetilde{w}=r(x)\chi_{\Omega}(x)u_{q,b}(t,x)\quad\mbox{in $(3\varepsilon,2T)\times\widetilde{\Omega}$},\\
&\partial_{\nu_{A}}\widetilde{w}=0\quad\mbox{on $(3\varepsilon,2T)\times\partial\widetilde{\Omega}$},\quad\widetilde{w}(3\varepsilon,\cdot)=w(3\varepsilon,\cdot)\quad\mbox{in $\widetilde{\Omega}$},\end{array}\right.

\mbox{\bf w=}0

On the other hand

Therefore

and

\partial_{\nu_{A}}\mbox{\bf w}=0\quad\mbox{on}\quad(3\varepsilon,T)\times\partial\widetilde{\Omega},\quad\mbox{\bf w}(3\varepsilon,\cdot)=w(3\varepsilon,\cdot)\quad\mbox{in $\widetilde{\Omega}$}.

3.
Proof of Theorem 2

We rely on what is called the Reznitskaya transform (e.g., Romanov
[
23
]
),
which is the
main idea for a similar inverse problem solved by Klibanov
[
18
]
.

Since function
t\rightarrow u(p)(t,\cdot)|_{\partial\Omega}
and

t\rightarrow u(q)(t,\cdot)|_{\partial\Omega}
are analytic in
t>0

(see e.g., Pazy
[
22
]
, Tanabe
[
25
]
) in view of

u(p)=u(q)
on
(0,T)\times\Gamma_{0}
, we obtain

[formula]

u(p)=u(q)\quad\mbox{on $(0,\infty)\times\Gamma_{0}$}.

Consider an initial-boundary value problem for a hyperbolic equation:

[formula]

\partial_{t}^{2}w(t,x)-\Delta w+p(x)w=0\quad\mbox{in $(0,\infty)\times\Omega$},

[formula]

\partial_{\nu_{A}}w=0\quad\mbox{on $(0,\infty)\times\partial\Omega$}

and

[formula]

w(\cdot,0)=u_{0},\quad\partial_{t}w(\cdot,0)=0\quad\mbox{in $\Omega$}.

By
u_{0}\in H^{3}(\Omega)
and
\partial_{\nu_{A}}u_{0}=0
on
\partial\Omega
,
and
p,q\in W^{1,\infty}(\Omega)
, we can verify

[formula]

w(p),\,w(q)\in C^{k}([0,\infty);H^{3-k}(\Omega)),\quad k=0,1,2,3.

We can prove (3.5) by Theorem 8.2 (p.275) in
[
20
]
.
Indeed in that theorem, setting
V:=H^{1}(\Omega)=\mathcal{D}((-\Delta_{N})^{\frac{1}{2}})
where

\Delta_{N}v=\sum_{j=1}^{n}\partial_{j}^{2}v
with

\mathcal{D}(\Delta_{N})=\{v\in H^{2}(\Omega);\,\partial_{\nu}v|_{\partial\Omega}=0\}
, we can accomplish the proof of (3.5) by the theorem and
the elliptic regularity.

Moreover we apply a standard energy estimate and, in view of (1.12), we have

\|w(p)(\cdot,s)\|_{L^{2}(\Omega)}\leq C_{1}\|\nabla w(p)\|_{L^{2}(\Omega)},

and we can find a constant
C_{2}>0
such that

\|w(p)(\cdot,s)\|_{H^{1}(\Omega)}\leq C_{2}e^{C_{2}s}\quad\mbox{for all $s>0$},

where
C_{2}>0
depends on
p,u_{0}
. Therefore there exists

\widetilde{u}(p)(t,x):=\int^{\infty}_{0}\frac{1}{\sqrt{\pi t}}e^{-\frac{s^{2}}{4t}}w(p)(s,x)ds,\quad t>0,\,x\in\Omega,

which is called the Reznitskaya transform in the context of
inverse problems.

We can prove (e.g., Section 3 of Chapter 6 of Romanov
[
23
]
) that

\widetilde{u}(p)
satisfies first two equations of (1.11) in

(0,\infty)\times\Omega
. Let us show that the initial condition also
holds true.
we remind that
w(p)\in C(\mathbb{R}^{1};L^{2}(\Omega))
.

\|\widetilde{u}(p)(t,\cdot)-u_{0}(0,\cdot)\|_{L^{2}(\Omega)}=\left\|\int_{0}^{\infty}\frac{1}{\root \of{\pi t}}e^{-\frac{\tau^{2}}{4t}}(w(p)(\tau,\cdot)-u_{0}(\cdot))d\tau\right\|_{L^{2}(\Omega)}

\leq\int_{0}^{\infty}\frac{1}{\root \of{\pi t}}e^{-\frac{\tau^{2}}{4t}}\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}d\tau.

For any
\varepsilon>0
, there exists a constant
\delta(\varepsilon)>0
such that

\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}\leq\frac{\varepsilon}{2}\quad\mbox{for all $0<\tau<\delta(\varepsilon)$}.

Therefore

\displaystyle\int_{0}^{\infty}\frac{1}{\sqrt{t}}e^{-\frac{\tau^{2}}{4t}}\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}d\tau

\displaystyle=

\displaystyle\int_{\delta(\varepsilon)}^{\infty}\frac{1}{\sqrt{t}}e^{-\frac{\tau^{2}}{4t}}\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}d\tau+\int_{0}^{\delta(\varepsilon)}\frac{1}{\root \of{\pi t}}e^{-\frac{\tau^{2}}{4t}}\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}d\tau.

We can estimate

\displaystyle\int_{\delta(\varepsilon)}^{\infty}\frac{1}{\sqrt{t}}e^{-\frac{\tau^{2}}{4t}}\|w(p)(\tau,\cdot)-u_{0}\|_{L^{2}(\Omega)}d\tau\leq C_{2}\int_{\delta(\varepsilon)}^{\infty}\frac{1}{\sqrt{t}}e^{-\frac{\tau^{2}}{4t}}e^{C_{2}\tau}d\tau

\displaystyle=

\displaystyle C_{2}\int_{\delta(\varepsilon)}^{\infty}2e^{C_{2}^{2}t}e^{-\frac{1}{4t}(\tau-2tC_{2})^{2}}\frac{d\tau}{2\sqrt{t}}\leq 2C_{2}e^{C_{2}^{2}t}\int_{\frac{1}{2\sqrt{t}}(\delta(\varepsilon)-2tC_{2})}^{\infty}e^{-\eta^{2}}d\eta=o(1)\quad\mbox{as $t\to 0$}.

Consequently we can choose a constants
t_{0}(\varepsilon)>0
sufficiently small, so that

\|\widetilde{u}(p)(t,\cdot)-u_{0}\|_{L^{2}(\Omega)}\leq\varepsilon\quad\mbox{if $0<t<t_{0}(\varepsilon)$}.

Thanks to the uniqueness of solution of (1.11), we obtain

u(p)(t,x)=\int^{\infty}_{0}\frac{1}{\sqrt{\pi t}}e^{-\frac{s^{2}}{4t}}w(p)(s,x)ds,\quad u(q)(t,x)=\int^{\infty}_{0}\frac{1}{\sqrt{\pi t}}e^{-\frac{s^{2}}{4t}}w(q)(s,x)ds,\quad t>0,\,x\in\Omega.

By (3.1), we reach

\int^{\infty}_{0}\frac{1}{\sqrt{\pi t}}e^{-\frac{s^{2}}{4t}}(w(p)(s,x)-w(q)(s,x))ds=0\quad t>0,\,x\in\Gamma_{0}.

Making the change of variables
\widetilde{s}=e^{-\frac{s^{2}}{4}}
,
we have

\int_{0}^{1}\tilde{s}^{\frac{1}{t}-1}\frac{(w(p)-w(q))(2\,\root \of{-\log\widetilde{s}},x)}{\root \of{-\log\widetilde{s}}}d\widetilde{s}=0\quad\mbox{for all $t>0$}.

Setting in the above formula
t=\frac{1}{n}
, choosing
t>0
such that

\frac{1}{t}-1
can cover
\mathbb{N}\cup\{0\}
, we obtain
that the function
\frac{(w(p)-w(q))(2\,\root \of{-\log\widetilde{s}},x)}{\root \of{-\log\widetilde{s}}}
is orthogonal to all the polynomials
on the interval
[0,1]
.
Therefore it is identically equal to zero by the Weierstrass’ polynomial
approximation theorem. This implies

w(p)(\sqrt{\eta},x)-w(q)(\sqrt{\eta},x)=0\quad\mbox{for all
$\eta>0$ and $x\in\Gamma_{0}$.}

Hence,

[formula]

w(p)(t,x)=w(q)(t,x)\quad\mbox{for all $t>0$ and $x\in\Gamma_{0}$}.

Now we reduced the inverse parabolic problem to an inverse hyperbolic problem
for (3.2) - (3.4) with (3.6).
Setting
y:=w(p)-w(q)
,
f:=q-p
and
R(t,x):=w(q)(t,x)
, we have

[formula]

\left\{\begin{array}[]{rl}&\partial_{t}^{2}y=\Delta y-p(x)y+f(x)R(t,x),\quad t>0,\,x\in\Omega,\\
&\partial_{\nu_{A}}y=0\quad\mbox{on $(0,\infty)\times\partial\Omega$},\\
&y(0,\cdot)=\partial_{t}y(0,\cdot)=0\quad\mbox{in $\Omega$}\end{array}\right.

and

[formula]

y=0\quad\mbox{on $(0,\infty)\times\Gamma_{0}$.}

For direct application of Imanuvilov and Yamamoto
[
12
]
, we
will make an extension of
y
to a wider spatial domain.
First we choose an open smooth domain
\omega\subset\mathbb{R}^{n}\setminus\overline{\Omega}
such that
\overline{\omega}\cap\partial\Omega\subset\Gamma_{0}
.
We fix
T>0
satisfying
T>\sup_{x\in\Omega}|x-x_{0}|
.
Over
\Gamma_{0}\subset\partial\Omega
, we take the zero extensions of both

y
and
f
to
\widetilde{\Omega}:=\Omega\cup\omega\cup(\partial\omega\cap\Gamma_{0})
.
By
\partial_{\nu_{A}}y=y=0
on
(0,T)\times\Gamma_{0}
, we can readily see that

[formula]

y\in C^{1}([0,T];H^{2}(\widetilde{\Omega}))\cap C^{2}([0,T];H^{1}(\widetilde{\Omega}))\cap C^{3}([0,T];L^{2}(\widetilde{\Omega})).

We can extend also
R
to
\widetilde{\Omega}
such that

[formula]

|R(0,x)|=|u_{0}(x)|\geq\delta>0\quad\mbox{on $\overline{\widetilde{\Omega}}$},\quad R\in H^{1}(0,T;L^{\infty}(\widetilde{\Omega})).

Therefore, we can obtain

\left\{\begin{array}[]{rl}&\partial_{t}^{2}y=\Delta y-p(x)y+f(x)R(t,x),\quad t>0,\,x\in\widetilde{\Omega},\\
&\partial_{\nu_{A}}y=0\quad\mbox{on $(0,\infty)\times\partial\widetilde{\Omega}$},\\
&y(0,\cdot)=\partial_{t}y(0,\cdot)=0\quad\mbox{in $\widetilde{\Omega}$},\\
&y=0\quad\mbox{in $(0,T)\times\omega$}.\end{array}\right.

In view of the construction of
\omega
and (1.13), we note that

\{x\in\partial{\widetilde{\Omega}};\,(x-x_{0})\cdot\nu(x)\geq 0\}\subset\partial\omega.

Hence, in terms of (3.9) and (3.10),
we can apply the uniqueness for an inverse hyperbolic problem
(e.g., Corollary 3.1 in
[
12
]
) to conclude that
f=0
in
\widetilde{\Omega}
,
that is,
p=q
in
\Omega
. Thus the proof of Theorem 2 is complete.
\blacksquare

4.
Proof of Theorem 3

We define an operator by

[formula]

(Kv)(t):=\mu(0)v(t)+\int^{t}_{0}\mu^{\prime}(t-s)v(s)ds,\quad 0<t<T.

Let
y
satisfy (1.14) and
y(0,\cdot)=0
in
\Omega
and

y=|\nabla y|=0
on
(0,T)\times\Gamma
.
Consider an equation with respect to
z(t,x)
:

[formula]

\partial_{t}y(t,x)=(Kz)(t,x),\quad 0<t<T,\,x\in\Omega.

Since
\mu(0)\neq 0
, the operator
K
is a Volterra operator of the second
kind, and we see that
K^{-1}:H^{1}(0,T)\longrightarrow H^{1}(0,T)
exists and
is bounded. Therefore,
z(\cdot,x)\in L^{2}(0,T)
is well defined for each

x\in\Omega
, and

[formula]

\partial_{t}y(t,x)=\mu(0)z(t,x)+\int^{t}_{0}\mu^{\prime}(t-s)z(s,x)ds,\quad 0<t<T,\,x\in\Omega

by
\partial_{t}y\in H^{1,2}(Q)
.

Since
y(0,\cdot)=0
in
\Omega
and

\mu(0)z(t,x)+\int^{t}_{0}\mu^{\prime}(t-s)z(s,x)ds=\partial_{t}\left(\int^{t}_{0}\mu(t-s)z(s,x)ds\right),

we obtain

y(t,x)=\int^{t}_{0}\mu(t-s)z(s,x)ds,\quad 0<t<T,\,x\in\Omega,

that is,

[formula]

y(t,x)=\int^{t}_{0}\mu(s)z(t-s,x)ds,\quad 0<t<T,\,x\in\Omega.

We will prove that
z\in H^{1,2}(Q)
satisfies

[formula]

\partial_{t}z(t,x)=Az(t,x)-p(x)z\quad\mbox{in $(0,\,t_{*})\times\Omega$},

where
t_{*}\in(0,T)
is some constant, and

[formula]

z=|\nabla z|=0\quad\mbox{on $(0,T)\times\Gamma$}.

We can readily verify (4.6), because
\partial_{t}y=|\nabla\partial_{t}y|=0
on
(0,T)\times\Gamma
implies

Kz=|K(\nabla z)|=0
on
(0,T)\times\Gamma
, so that
the injectivity of
K
directly yields (4.6).

Using
\partial_{t}y\in H^{1,2}(Q)\subset C([0,T];L^{2}(\Omega))
by (4.3), we have

\partial_{t}y(0,x)=\mu(0)z(0,x),\quad x\in\Omega.

On the other hand, substituting
t=0
in (1.14) and applying (1.15), we obtain

\partial_{t}y(0,x)=\mu(0)f(x),\quad x\in\Omega.

Hence
\mu(0)z(0,x)=\mu(0)f(x)
for
x\in\Omega
. By
\mu(0)\neq 0
, we
reach

[formula]

z(0,x)=f(x),\quad x\in\Omega.

Now we will prove (4.5). In terms of (4.4) and (4.7), we have

\displaystyle\partial_{t}y(t,x)=\mu(t)z(0,x)+\int^{t}_{0}\mu(s)\partial_{t}z(t-s,x)ds

\displaystyle=

\displaystyle\mu(t)f(x)+\int^{t}_{0}\mu(s)\partial_{t}z(t-s,x)ds

and

(A-p(x))y(t,x)=\int^{t}_{0}\mu(s)(A-p(x))z(t-s,x)ds,\quad 0<t<T,\,x\in\Omega.

Consequently (1.14) implies

\displaystyle\mu(t)f(x)=(\partial_{t}y-(Ay-p(x)y)(t,x)

\displaystyle=

\displaystyle\mu(t)f(x)+\int^{t}_{0}\mu(s)(\partial_{t}z-(A-p(x))z)(t-s,x)ds,

that is,

\int^{t}_{0}\mu(s)(\partial_{t}z-(A-p(x))z)(t-s,x)ds=0,\quad 0<t<T,\,x\in\Omega.

Hence, setting
Z(s):=\|(\partial_{s}z-(A-p(x))z)(s,\cdot)\|_{L^{2}(\Omega)}

for
0<t<T
, we reach

\int^{t}_{0}\mu(s)Z(t-s)ds=0,\quad 0<t<T.

By the Titchmarsh convolution theorem (e.g., Titchmarsh
[
26
]
),
there exists
t_{*}\in[0,T]
such that

\mu(s)=0\quad\mbox{for $0<s<T-t_{*}$},\quad Z(s)=0\quad\mbox{for $0<s<t_{*}$}.

Since
\mu\not\equiv 0
in
[0,T]
, we see that
T-t_{*}<T
, that is,

t_{*}>0
. Thus the verification of (4.5) is complete.

\blacksquare

Applying the classical unique continuation by (4.5) and (4.6),
we obtain
z=0
in
(0,t_{*})\times\Omega
. As for the unique continuation, we can refer for example to
Mizohata
[
21
]
, Saut-Scheurer
[
24
]
and see also Yamamoto
[
28
]
,
[
29
]
.
Thus (4.7) implies
f=0
in
\Omega.
The proof of Theorem 3 is complete.

\blacksquare

5.
Concluding remarks

5.1.

In this article, we consider two types of inverse problems for parabolic
equations:

•

Inverse coefficient problem of determining a
spatially varying
p(x)
in

\left\{\begin{array}[]{rl}&\partial_{t}u(t,x)=Au(t,x)-p(x)u(t,x),\quad 0<t<T,\,x\in\Omega,\\
&\partial_{\nu_{A}}z=0\quad\mbox{on $(0,T)\times\partial\Omega$},\\
&u(t_{0},\cdot)=u_{0}:\,\,\mbox{given in $\Omega$},\end{array}\right.

by
u|_{(0,T)\times\Gamma}
with subboundary
\Gamma\subset\partial\Omega
.
Here
t_{0}\in(0,T)
is given.

•

Inverse source problem of determining a spatial factor
f(x)
of
source terms in

\left\{\begin{array}[]{rl}&\partial_{t}y(t,x)=Ay(t,x)-p(x)y(t,x)+\mu(t)f(x),\quad 0<t<T,\,x\in\Omega,\\
&y(t_{0},\cdot)=u_{0}:\,\,\mbox{given in $\Omega$},\end{array}\right.

by
y,\nabla y
on
(0,T)\times\Gamma
.

We summarize our results and the existing results.

Inverse coefficient problems:

(1)

Case
0<t_{0}<T
: there have been many works and among them we can refer for
example to Beilina and Klibanov
[
3
]
,
Bukhgeim and Klibanov
[
4
]
, Klibanov
[
18
]
,
Imanuvilov and Yamamoto
[
11
]
and the references therein.
We refer to Yamamoto
[
28
,
29
]
for the stability.
The main method is based on Carleman estimates.

(2)

Case
t_{0}=T
: The current article solved and established the global
Lipschitz stability. We should remark that the uniqueness and also
Hölder stability can be proved by means of the time analyticity
of solution
u
.
Our method can be extended in the case where the coefficients
of the parabolic operator depends on time analytically.

(3)

Case
t_{0}=0
: By an integral transform,
we can obtain the uniqueness,
once we have uniqueness for the corresponding hyperbolic
inverse coefficient problems. This idea can be found in the book by
Romanov
[
23
]
, Klibanov
[
18
]
.
By this method, it is impossible to choose any small subboundary where
additional
data are taken, which seems to be unnatural for the inverses parabolic problem.
One could prove conditional stability, but it is expected to be of rather weak
rate, which is subject to the transformation method,
and we do not know whether such
stability is reasonable by the nature of the inverse problem.

Inverse source problems:

The main concern is the uniqueness and we should expect
the uniqueness without boundary condition on the whole
lateral boundary
(0,T)\times\partial\Omega
.

(1)

Case
0<t_{0}<T
: The method by Carleman estimate gives the uniqueness and also
conditional stability in some subdomain
\subset\Omega
if
\mu(t_{0})\neq 0
.

(2)

Case
t_{0}=T
: still open.

(3)

Case
t_{0}=0
: The current article establishes the uniqueness if

\mu(0)\neq 0
. However under more generous but reasonable condition

\mu\not\equiv 0
on
[0,T]
, we do not know the uniqueness in general.

5.2.

For the case
t_{0}=0
, our available method seems only the Reznitskaya
transform. Within adequate regularities, the transform transfers
the uniqueness for inverse hyperbolic problems to the uniqueness for
inverse parabolic problem.
Thus the primary technical highlight is inverse hyperbolic problems.

When one can obtain the uniqueness
for more general inverse hyperbolic problems, we can make it
produce the uniqueness for the corresponding inverse parabolic problems
not only in the case of
A=\Delta
.

In order to treat general
A
, we need some restrictive assumptions for
the principal coefficients
a_{jk}
of
A
.
Now we formulate such assumptions as follows.
We set
i:=\sqrt{-1}
,
Q:=(0,T)\times\Omega
,

\nabla:=(\partial_{1},...,\partial_{n})
,

\nabla_{t,x}:=(\partial_{t},\partial_{1},...,\partial_{n})
,

\nabla_{\xi}:=(\frac{\partial}{\partial\xi_{0}},\frac{\partial}{\partial\xi_{1}},...,\frac{\partial}{\partial\xi_{n}})
for
\xi:=(\xi_{0},...,\xi_{n})
. For any
C^{1}
functions
g(x,\xi)
and
f(x,\xi)
we introduce the Poisson bracket of these functions

\{f,g\}=\sum_{j=1}^{n}\partial_{\xi_{j}}f\partial_{x_{j}}g-\partial_{x_{j}}f\partial_{\xi_{j}}g+\partial_{\xi_{0}}f\partial_{t}g-\partial_{t}f\partial_{\xi_{0}}g.

For the hyperbolic operator:

\widetilde{P}(x,D)v:=\partial^{2}_{t}v-\sum_{j,k=1}^{n}\partial_{j}(a_{jk}(x)\partial_{k}v)+\sum_{j=1}^{n}b_{j}(x)\partial_{j}v+p(x)v

we define principal symbol of this operator
\widetilde{p}(x,\xi)
by formula

\widetilde{p}(x,\xi):=\xi_{0}^{2}-a(x,\xi,\xi),\quad x\in\Omega,\,\xi=(\xi_{0},\dots,\xi_{n}).

First we
assume that a function
\widetilde{\psi}(t,x)
is pseudo-convex with respect to

\widetilde{P}
in
