Extension of Bressoud’s generalization of Borwein’s conjecture and some exact results
Alexander Berkovich, Aritram Dhar

Abstract
. In this paper, we conjecture an extension to Bressoud’s 1996 generalization of Borwein’s famous 1990 conjecture. We then state a few infinite hierarchies of non-negative q q -series identities which are interesting examples of our proposed conjecture and Bressoud’s generalized conjecture. Finally, using certain positivity-preserving transformations for q q -binomial coefficients, we prove the non-negativity of the infinite families.

In this section, we state some positivity-preserving transformations for certain

Theorem 3.1
.

(Berkovich
[
5
,
6
, Theorem
2.1
]
)
For
L\in\mathbb{N}
and
a\in\mathbb{Z}
, we have

(3.1)

\sum\limits_{k\geq 0}C_{L,k}(q)\left[\begin{matrix}k\\
\left\lfloor\frac{k-a}{2}\right\rfloor\end{matrix}\right]_{q}=q^{T(a)}\left[\begin{matrix}2L+1\\
L-a\end{matrix}\right]_{q},

where
T(j):=\binom{j+1}{2}
and

(3.2)

C_{L,k}(q)=\sum\limits_{m=0}^{L}q^{T(m)+T(m+k)}\left[\begin{matrix}L\\
m,k\end{matrix}\right]_{q},\\

where

(3.3)

\left[\begin{matrix}L\\
m,k\end{matrix}\right]_{q}=\left[\begin{matrix}L\\
m\end{matrix}\right]_{q}\left[\begin{matrix}L-m\\
k\end{matrix}\right]_{q}=\left[\begin{matrix}L\\
k\end{matrix}\right]_{q}\left[\begin{matrix}L-k\\
m\end{matrix}\right]_{q}\geq 0.

Now, note that
C_{L,k}(q)\geq 0
. It is then easy to verify that for any identity of the form

(3.4)

F_{C}(L,q)=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)\left[\begin{matrix}L\\
\left\lfloor\frac{L-j}{2}\right\rfloor\end{matrix}\right]_{q},

using transformation (
3.1
), the following identity holds

(3.5)

\sum\limits_{k\geq 0}C_{L,k}(q)F_{C}(k,q)=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)\sum\limits_{k\geq 0}C_{L,k}(q)\left[\begin{matrix}k\\
\left\lfloor\frac{k-j}{2}\right\rfloor\end{matrix}\right]_{q}=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)q^{T(j)}\left[\begin{matrix}2L+1\\
L-j\end{matrix}\right]_{q}.

Hence, if
F_{C}(L,q)\geq 0
, then

(3.6)

\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)q^{T(j)}\left[\begin{matrix}2L+1\\
L-j\end{matrix}\right]_{q}\geq 0.

So, we say that the transformation (
3.1
) is positivity-preserving.

(3.23)

\sum\limits_{r=0}^{\left\lfloor\frac{L}{3}\right\rfloor}\tilde{A}_{L,r}(q)\left[\begin{matrix}2r+1\\
r-j\end{matrix}\right]_{q^{3}}=q^{3j^{2}+3j}\left[\begin{matrix}2L+1\\
L-3j-1\end{matrix}\right]_{q},

where

(3.24)

\tilde{A}_{L,r}(q)=\dfrac{q^{3r^{2}+3r}(q^{3};q^{3})_{L-r-1}(1-q^{2L+1})}{(q^{3};q^{3})_{2r+1}(q;q)_{L-3r-1}}.

It is then evident from (
3.19
) and (
3.24
) that

\tilde{A}_{L,r}(q)=q^{3r^{2}+3r}f_{2L+1,2r+1}(q)\\

has non-negative coefficients.

It is then easy to verify that for any identity of the form

(3.25)

F_{\tilde{A}}(L,q)=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)\left[\begin{matrix}2L+1\\
L-j\end{matrix}\right]_{q^{3}},

using transformation (
3.23
), the following identity holds

(3.26)

\sum\limits_{r\geq 0}\tilde{A}_{L,r}(q)F_{\tilde{A}}(r,q)=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)\sum\limits_{r\geq 0}\tilde{A}_{L,r}(q)\left[\begin{matrix}2r+1\\
r-j\end{matrix}\right]_{q^{3}}=\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)q^{3j^{2}+3j}\left[\begin{matrix}2L+1\\
L-3j-1\end{matrix}\right]_{q}.

Hence, if
F_{\tilde{A}}(L,q)\geq 0
, then

(3.27)

\sum\limits_{j\in\mathbb{Z}}\alpha(j,q)q^{3j^{2}+3j}\left[\begin{matrix}2L+1\\
L-3j-1\end{matrix}\right]_{q}\geq 0.

So, again transformation (
3.23
) is positivity-preserving.
