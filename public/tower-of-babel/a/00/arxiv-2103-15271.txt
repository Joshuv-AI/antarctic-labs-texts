A Note on Global Optimization for Max-Plus Linear Systems
Cailu WANG, Yuegang TAO

Abstract
This note further addresses the global optimization problem for max-plus linear systems considered in [Automatica 119 (2020) 109104]. Firstly, the operations between ± ∞ \pm\infty and real numbers involved in the formulas of solving global optimization problems are explained explicitly. Secondly, the formula of the greatest lower bound and the criterion of solvability of globally optimal solutions are simplified. Thirdly, the criterion of uniqueness of globally optimal solutions and the set of all globally optimal solutions are presented.

Global optimization is to find the global minimizer of a
function or a set of functions over a given set, which has been
a basic tool in all areas of engineering, medicine, economics,
and other sciences. The
global optimization for max-plus linear systems has been considered in
[

This note is a further explanation and extension of the results in
[

Some formulas for globally optimal solutions in

[

1

This note will present a necessary and sufficient condition for the uniqueness and construct the set of all globally optimal solutions.

2
Preliminaries

Let us introduce some basic definitions and notations from the max-plus algebra, which can
be consulted for more details in
[
3
,
2
,
1
]
.

Let
\mathbb{R}
be the set of real numbers,
\mathbb{N}
be the set of natural numbers and
\mathbb{N}^{+}
be the set of positive integers. For
n\in\mathbb{N}^{+}
,
denote by
\mathbb{N}_{n}
the set
\{1,2,\ldots,

n\}
.
Let
\mathbb{R}_{\max}
be the set
\mathbb{R}\cup\{-\infty\}
with max and
\mathbb{+}
as two binary operations
\oplus
and
\otimes
, respectively, i.e., for
a,b\in\mathbb{R}_{\max}
,

a\oplus b=\max\{a,b\}\text{\ and\ }a\otimes b=a+b.

\left(\mathbb{R}_{\max},\oplus,\otimes\right)
is called the
max-plus algebra
, in whi- ch
-\infty
is the zero element denoted by
\varepsilon
, and 0 is the identity element denoted by
e
.
For
a,b\in\mathbb{R}_{\max}
,
a\leqslant b
if
a\oplus b=b
.

Let
\mathbb{R}_{\max}^{n}
and
\mathbb{R}_{\max}^{m\times n}
be the set of
n
-dimensional vectors and
m\times n
matrices with entries in
\mathbb{R}_{\mathrm{max}}
, respectively.
The vectors and matrices are represented by bold-type letters.
The addition and multiplication
can be extended to the vector-matrix algebra over
\mathbb{R}_{\max}
by
the direct analogy to the con- ventional linear algebra: For
\bm{A}=(a_{ij}),\ \bm{B}=(b_{ij})

\in\mathbb{R}_{\max}^{m\times n}
,

(\bm{A}\oplus\bm{B})_{ij}=a_{ij}\oplus b_{ij};

for
\bm{A}=(a_{ij})\in

\mathbb{R}_{\max}^{m\times p}
and

\bm{B}=(b_{ij})\in\mathbb{R}_{\max}^{p\times n}
,

(\bm{A}\otimes\bm{B})_{ij}=\bigoplus_{k=1}^{p}a_{ik}\otimes b_{kj}.

For

\bm{A},\bm{B}

\in\mathbb{R}_{\max}^{m\times n}
,

\bm{A}\leqslant\bm{B}
if
\bm{A}\oplus\bm{B}=\bm{B}
.
For
\bm{A},

\bm{B}\in\mathbb{R}_{\max}^{m\times n}
and
\bm{x},\bm{y}\in\mathbb{R}_{\max}^{n}
,
if
\bm{A}\leqslant\bm{B}
and
\bm{x}\leqslant\bm{y}
, then
\bm{A}\otimes\bm{x}

\leqslant\bm{B}\otimes\bm{y}.

For
\bm{A}\in\mathbb{R}_{\max}^{m\times n}
and
\bm{x}\in\mathbb{R}_{\max}^{n}
,

F(\bm{x})=\bm{A}\otimes\bm{x}
is called a
max-plus function
of type
(n,m)
.
Denoted by
F_{i}(\bm{x})

the
i
th component of
F(\bm{x})
.
A
max-plus linear system
is a system that can be described by using max-plus functions.

Given
\bm{A}=(a_{ij})\in\mathbb{R}_{\max}^{m\times n}
and

\bm{b}=(b_{i})\in\mathbb{R}_{\max}^{m}
,
a
system of max-plus linear equations
is defined as

\bm{A}\otimes\bm{x}=\bm{b},

(1)

where
\bm{x}=(x_{j})
is considered in
\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}(=\mathbb{R}_{\max}\cup\{+\infty\})
, rather than in
\mathbb{R}_{\max}
.
System (
1
) is said to be
solvable

if there exists
\tilde{\bm{x}}\in

\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}^{n}
such that
\bm{A}\otimes\tilde{\bm{x}}=\bm{b}
, and
\tilde{\bm{x}}
is called a
solution
of system (
1
). For
\tilde{\bm{x}}\in\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}^{n}
,
\tilde{\bm{x}}
is called a
subsolution
of system (
1
) if
\bm{A}\otimes\tilde{\bm{x}}\leqslant\bm{b}
.

Lemma 2.1
.

[
3
]

For system (
1
), let
\bm{x}^{*}(\bm{A},\bm{b})\in\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}^{n}
be defined by

x_{j}^{*}(\bm{A},\bm{b})=\min\limits_{i\in\mathbb{N}_{m}}\{b_{i}-a_{ij}\},\ j\in\mathbb{N}_{n}.

(2)

Then,
\bm{x}^{*}(\bm{A},\bm{b})
is the greatest subsolution of system (
1
), i.e.,

1)

\bm{A}\otimes\bm{x}^{*}(\bm{A},\bm{b})\leqslant\bm{b}
;

2)

if
\tilde{\bm{x}}
is a subsolution of system (
1
), then
\tilde{\bm{x}}\leqslant\bm{x}^{*}(\bm{A},\bm{b})
. In particular, if
\tilde{\bm{x}}
is a solution,
then
\tilde{\bm{x}}\leqslant\bm{x}^{*}(\bm{A},\bm{b})
.

System (
1
) is solvable if and only if the greatest subsolution is a solution, i.e.,
\bm{A}\otimes\bm{x}^{*}(\bm{A},\bm{b})=\bm{b}
.

3
Global optimization

Consider the
global optimization problem

\min_{\bm{x}\in\mathcal{X}}F(\bm{x}),

(3)

where the optimization variable is
\bm{x}=(x_{j})\in\mathbb{R}^{n}
;
the objective function is
F(\bm{x})=\bm{A}\otimes\bm{x}
, in which
\bm{A}=(a_{ij})\in\mathbb{R}_{\max}^{m\times n}
;
the constraint set is

\mathcal{X}=\left\{\bm{x}\,\Big|\displaystyle\sum\limits_{j=1}^{n}{k_{j}x_{j}}=c,\ k_{j}\geqslant 0,\ k_{j}\text{\,are not all 0}\right\},

in which
c\in\mathbb{R}
is a constant.

Definition 3.1
.

[
20
]

Problem (
3
) is said to be solvable
if there exists
\tilde{\bm{x}}\in\mathcal{X}
such that
F(\bm{x})\geqslant F(\tilde{\bm{x}})
for any
\bm{x}

\in\mathcal{X}
, and

\tilde{\bm{x}}
is called a globally optimal solution of problem (
3
). Otherwise, problem (
3
) is said to be unsolvable.

Note that, for problem (
3
), an
\bm{\varepsilon}
row in
\bm{A}
has no affect on globally optimal solutions.
In addition, if the
j_{0}
th column of
\bm{A}
is
\bm{\varepsilon}
and meanwhile
k_{j_{0}}=0
,
then
x_{j_{0}}
disappears from both the objective function and the constraint function of problem (
3
).
Consequently, problem (
3
) becomes into the optimization of variables
\{x_{j}\,|\,j\neq j_{0}\}
.
Without loss of generality, let us make the following assumptions:

1)

\bm{A}
is row
\mathbb{R}
-astic, i.e.,
\bm{A}
has no
\bm{\varepsilon}
row.

2)

k_{j}
\neq
0 if the
j
th column of
\bm{A}
is
\bm{\varepsilon}
.

Theorem 3.2
.

[
20
]

For problem (
3
), let
\bm{b}=(b_{i})\in\mathbb{R}_{\max}^{m}
be defined by

b_{i}=\frac{\sum_{j=1}^{n}k_{j}a_{ij}+c}{\sum_{j=1}^{n}k_{j}},\ i\in{\mathbb{N}_{m}}.

(4)

Then,
\bm{b}
is the greatest lower bound of problem (
3
):

1)

F(\bm{x})\geqslant\bm{b}
for any
\bm{x}\in\mathcal{X}
;

2)

if
\bm{y}
is a lower bound of problem (
3
), then
\bm{y}\leqslant\bm{b}
.

The calculation of (
4
) may refer to some opera- tions between elements
\pm\infty
in
\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}
and real numbers in
\mathbb{R}
.
To compute the greatest lower bound by (
4
),
one needs to make the following statements: For
r,p\in\mathbb{R}
and
p>0
,

\max\{r,-\infty\}=r
,

\max\{r,+\infty\}=+\infty
,

r+(-\infty)=-\infty
,

r+(+\infty)=+\infty
,

r-(-\infty)=+\infty
,

r-(+\infty)=-\infty
,

(-\infty)-r=-\infty
,

(+\infty)-r=+\infty
,

p\times(-\infty)=-\infty
,

p\times(+\infty)=+\infty
,

0\times(-\infty)=0
,

0\times(+\infty)=0
,

(+\infty)+(-\infty)=-\infty
,

(-\infty)-(-\infty)=+\infty
.

Considering that
0
coefficients in the constraint function have no function in calculating the greatest lower bound, formula (
4
) can equivalently be simplified as

b_{i}=\frac{\sum_{j\in\mathcal{J}}k_{j}a_{ij}+c}{\sum_{j\in\mathcal{J}}k_{j}},\ i\in{\mathbb{N}_{m}},

(5)

where

\mathcal{J}=\{j\in\mathbb{N}_{n}\,|\,k_{j}>0\}.

The formula above avoids the multiplication
\times
between
0
and infinity elements in
\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathbb{R}}_{\max}
.

4
Optimal solutions

Let us provide two necessary conditions for the existence of globally optimal solutions.

Lemma 4.1
.

If problem (
3
) is solvable, then

1)

the greatest lower
bound
\bm{b}
given in (
5
) is finite;

2)

\bm{x}^{*}(\bm{A},\bm{b})
is finite.

Proof.
1) Suppose that there exists
i_{0}\in\mathbb{N}_{m}
such that
b_{i_{0}}=\varepsilon
.
Since
\bm{A}
is row
\mathbb{R}
-astic, there exists
j_{0}\in

\mathbb{N}_{n}
such that
a_{i_{0}j_{0}}\neq\varepsilon
.
Let
\tilde{\bm{x}}=(\tilde{x}_{j})
be a globally optimal solution of problem (
3
).
Then,

\varepsilon=b_{i_{0}}=F_{i_{0}}(\tilde{\bm{x}})=\max_{j\in\mathbb{N}_{n}}\{a_{i_{0}j}+\tilde{x}_{j}\}\geqslant a_{i_{0}j_{0}}+\tilde{x}_{j_{0}}.

This implies that
\tilde{x}_{j_{0}}=\varepsilon
, and hence
\tilde{\bm{x}}\notin\mathcal{X}
.
This contradiction indicates that
\bm{b}
is finite.

2) Since
\bm{b}
is finite,
{x}_{j}^{*}(\bm{A},\bm{b})\neq\varepsilon
for any
j\in\mathbb{N}_{n}
.
Suppose that
there exists
j_{0}\in\mathbb{N}_{n}
such that

{x}_{j_{0}}^{*}(\bm{A},\bm{b})=\min\limits_{i\in\mathbb{N}_{m}}\{b_{i}-a_{ij_{0}}\}=+\infty.

This implies that
a_{ij_{0}}=\varepsilon
for any
i\in\mathbb{N}_{m}
.
Assum- ption 2) ensures that
k_{j_{0}}>0
, i.e,
j_{0}\in\mathcal{J}
.
According to (
5
),
\bm{b}=\bm{\varepsilon}
, and hence problem (
3
) is unsolvable. This contradiction indicates that
\bm{x}^{*}(\bm{A},\bm{b})
is finite.

\Square

It can be inferred from the lemma above that if

\sum_{j\in\mathcal{J}}k_{j}x_{j}^{*}(\bm{A},\bm{b})\big(=\sum_{j=1}^{n}k_{j}x_{j}^{*}(\bm{A},\bm{b})\big)=c,

(6)

then
\bm{x}^{*}(\bm{A},\bm{b})
is finite and
\bm{x}^{*}(\bm{A},\bm{b})\in\mathcal{X}
.
The cri-

teria of solvability given in
[
20
]
can be then represented as follows.

Theorem 4.2
.

[
20
]

For problem (
3
), the following statements are equivalent:

1)

Problem (
3
) is solvable.

2)

Equation (
6
) holds.

3)

\bm{x}^{*}(\bm{A},\bm{b})
is a globally optimal solution.

Let us see a numerical example of global optimization problem that contains
\varepsilon
coefficients in the objective function and
0
coefficients in the constraint function.

Example 4.3
.

Consider the global optimization

problem

\min_{\bm{x}\in\mathcal{X}}F(\bm{x}),

(7)

where the objective function is
F(\bm{x})=\bm{A}\otimes\bm{x}
,

\bm{A}=\begin{pmatrix}1&2&-2\\
-1&e&\varepsilon\\
e&1&3\end{pmatrix},

and the constraint set is
\mathcal{X}=\{\bm{x}\,|\,2x_{1}+x_{2}=2\}.

By (
5
),
\bm{b}=(2\ \,e\ \,1)^{\intercal}.

By (
2
),
\bm{x}^{*}(\bm{A},\bm{b})=(1\ \,e\ -2)^{\intercal}.

Then,

2x_{1}^{*}(\bm{A},\bm{b})+x_{2}^{*}(\bm{A},\bm{b})=2=c.

It follows from
Theorem

4.2
that problem (
7
) is solvable, and

(1\ \,e

-2)^{\intercal}
is a globally optimal solution.

If the constraint set of problem (
7
) is replaced by
\accentset{{\cc@style\underline{\mskip 10.0mu}}}{\mathcal{X}}=\{\bm{x}\,|\,2x_{1}+x_{2}+x_{3}=2\}
, then
b_{2}=\varepsilon
. It can be obtained from
Lemma

4.1
that such a problem has no globally optimal solution.

Note that, the globally optimal solution introduced in
Definition

3.1
may be not unique.
According to
[
20
, Theorem 3]
, if problem (
3
) is solvable, then

k_{j}>0
for any
j\in\mathbb{N}_{n}
is a sufficient condition for the uniqueness of
globally optimal solutions.
In fact, such a condition is also necessary.

Theorem 4.4
.

Let problem (
3
) be solvable. Problem (
3
) has a unique
globally optimal solution if and only if
k_{j}>0
for any
j\in\mathbb{N}_{n}
.

Proof.

The sufficiency can be obtained from the proof of
[
20
, Theorem 3]
.
Let us now prove the ne-

cessity. Since problem
(
3
) is solvable, equation (
6
) holds.
Suppose that there exists
j_{0}\in\mathbb{N}_{n}
such that

k_{j_{0}}=0
,
i.e.,
j_{0}\notin{\mathcal{J}}
.
Let
\tilde{\bm{x}}

=(\tilde{x}_{j})\in\mathbb{R}_{\max}^{n}
be defined by

\tilde{x}_{j}=\left\{\begin{array}[]{ll}\varepsilon,&j=j_{0};\\
x^{*}_{j}(\bm{A},\bm{b}),&j\neq j_{0}.\end{array}\right.

(8)

It can be known from
Lemma

4.1
that
\bm{x}^{*}(\bm{A},\bm{b})
is finite.
Then,
\tilde{\bm{x}}<\bm{x}^{*}(\bm{A},\bm{b})
and

\displaystyle\sum_{j\in\mathcal{J}}k_{j}\tilde{x}_{j}

\displaystyle=\sum_{j\in\mathcal{J}}k_{j}x^{*}_{j}(\bm{A},\bm{b})=c,

i.e.,
\tilde{\bm{x}}\in\mathcal{X}
. By
Theorem

3.2
,
F(\tilde{\bm{x}})\geqslant\bm{b}
.
In addition,

\displaystyle F(\tilde{\bm{x}})

\displaystyle\leqslant F(\bm{x}^{*}(\bm{A},\bm{b}))=\bm{A}\otimes\bm{x}^{*}(\bm{A},\bm{b})\leqslant\bm{b}.

Hence,
F(\tilde{\bm{x}})=\bm{b}
. This implies that
\tilde{\bm{x}}
is also a globally optimal solution, which contradicts with the uniqueness.
Hence,
k_{j}>0
for any
j\in\mathbb{N}_{n}
.

\Square

The proof of Theorem
4.4
is constructive and
formula (
8
) can be extended to find all globally optimal
solutions as follows.

Theorem 4.5
.

If problem (
3
) is solvable, then the set of all globally optimal solutions is

\displaystyle\mathcal{S}=\left\{\tilde{\bm{x}}\ \Bigg|\begin{array}[]{l}\tilde{x}_{j}\leqslant x^{*}_{j}(\bm{A},\bm{b})\text{\ if\ }k_{j}=0;\\
\tilde{x}_{j}=x^{*}_{j}(\bm{A},\bm{b})\text{\ if\ }k_{j}>0.\end{array}\right\}.

Proof.

Since problem (
3
) is solvable, equation (
6
) holds.
On the one hand, for any
\tilde{\bm{x}}\in\mathcal{S}
,

\displaystyle\sum_{j\in\mathcal{J}}k_{j}\tilde{x}_{j}

\displaystyle=\sum_{j\in\mathcal{J}}k_{j}x^{*}_{j}(\bm{A},\bm{b})=c,

i.e.,
\tilde{\bm{x}}\in\mathcal{X}
. By
Theorem

3.2
,
F(\tilde{\bm{x}})\geqslant\bm{b}
.
In addition,

\displaystyle F(\tilde{\bm{x}})

\displaystyle\leqslant F(\bm{x}^{*}(\bm{A},\bm{b}))=\bm{A}\otimes\bm{x}^{*}(\bm{A},\bm{b})\leqslant\bm{b}.

Hence,
F(\tilde{\bm{x}})=\bm{b}
. This implies that
\tilde{\bm{x}}
is a globally optimal solution.
On the other hand, let
\tilde{\bm{x}}
be a globally optimal solution.
Then,
\tilde{\bm{x}}\in\mathcal{X}
and
F(\tilde{\bm{x}})

=\bm{A}\otimes\tilde{\bm{x}}=\bm{b}.

By
Lemma

2.1
,
\tilde{\bm{x}}\leqslant\bm{x}^{*}(\bm{A},\bm{b})
.
Suppose that there exists

j_{0}\in{\mathcal{J}}
such that

\tilde{x}_{j_{0}}<x^{*}_{j_{0}}(\bm{A},\bm{b})
. Then,

\displaystyle c

\displaystyle=\sum_{j\in\mathcal{J}\setminus\{j_{0}\}}k_{j}\tilde{x}_{j}+k_{j_{0}}\tilde{x}_{j_{0}}

\displaystyle<\sum_{j\in\mathcal{J}\setminus\{j_{0}\}}k_{j}x^{*}_{j}(\bm{A},\bm{b})+k_{j_{0}}x^{*}_{j_{0}}(\bm{A},\bm{b})

\displaystyle=\sum_{j\in\mathcal{J}}k_{j}x^{*}_{j}(\bm{A},\bm{b})=c.

This contradiction implies that
\tilde{x}_{j}=x^{*}_{j}(\bm{A},\bm{b})
for any

j

\in{\mathcal{J}}
, and so
\tilde{\bm{x}}\in\mathcal{S}
. Hence,
\mathcal{S}
is the set of all
globally optimal solutions.

\Square

Owing to the theorem above,
\bm{x}^{*}(\bm{A},\bm{b})
is referred to as the
greatest globally optimal solution
of problem (
3
) if equation (
6
) holds.

Example 4.6
.

Find all globally optimal solutions of problem (
7
). It has been calculated in
Example

4.3
that
\bm{x}^{*}(\bm{A},\bm{b})=(1\ \,e\ -2)^{\intercal}.
By
Theorem

4.5
, the set of all globally optimal solutions is

\mathcal{S}=\left\{\,\left(1\ \ 0\ \ a\right)^{\intercal}\Big|\,a\leqslant-2\right\}.
