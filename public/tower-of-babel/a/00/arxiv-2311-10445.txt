Some functionals for random walks and critical branching processes in extreme random environment
Congzao Dong, Elena Dyakonova, Vladimir Vatutin

Abstract
Let { S n , n ≥ 0 } \left\{S_{n},n\geq 0\right\} be a random walk whose increment distribution belongs without centering to the domain of attraction of an α \alpha -stable law, i.e., there are some scaling constants a n a_{n} such that the sequence S n / a n , n = 1 , 2 , … , S_{n}/a_{n},n=1,2,..., weakly converges, as n → ∞ n\rightarrow\infty to a random variable having an α \alpha -stable distribution. Let S 0 = 0 , S_{0}=0, L n := min ⁡ ( S 1 , … , S n ) , τ n := min ⁡ { 0 ≤ k ≤ n : S k = min ⁡ ( 0 , L n ) } . L_{n}:=\min\left(S_{1},...,S_{n}\right),\tau_{n}:=\min\left\{0\leq k\leq n:S_{k}=\min(0,L_{n})\right\}. Assuming that S n ≤ h ⁡ ( n ) , S_{n}\leq h(n), where h ⁡ ( n ) h(n) is o ⁡ ( a n ) o(a_{n}) and lim n → ∞ h ⁡ ( n ) ∈ [ − ∞ , + ∞ ] \lim_{n\rightarrow\infty}h(n)\in[-\infty,+\infty] exists we prove several limit theorems describing the asymptotic behavior of the functionals 𝐄 ⁡ [ e S τ n ; S n ≤ h ⁡ ( n ) ] \mathbf{E}\left[e^{S_{\tau_{n}}};S_{n}\leq h(n)\right] as n → ∞ n\rightarrow\infty . We consider some functionals specified on the trajectories of a random walk

S_{0}=0,\quad S_{n}=X_{1}+...+X_{n},\ n\geq 1,

\displaystyle\qquad\qquad\leq\mathbf{P}\left(L_{t}\geq 0\right)\int_{-\infty}^{-H}e^{\theta x}\frac{\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)}{b_{n}}

\displaystyle\leq

\displaystyle\mathbf{P}\left(L_{t}\geq 0\right)\sum_{k=H}^{\infty}e^{-\theta k}\frac{\mathbf{P}\left(S_{j}\in[-k-1,-k),\tau_{j}=j\right)}{b_{n}}

\displaystyle\qquad\qquad\leq C_{1}\mathbf{P}\left(L_{t}\geq 0\right)\sum_{k=H}^{\infty}e^{-\theta k}U(k+1)

is vanishing as
H\rightarrow\infty
. Thus, we are left with

\int_{-H}^{K\wedge 0}e^{\theta x}\frac{\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)}{b_{n}}\mathbf{P}\left(S_{t}\leq K-x,L_{t}\geq 0\right).

To evaluate this term we use Theorem 5.1 in
[
3
]
(rewritten in our
notation) according to which

\frac{\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)}{b_{n}dx}\sim g_{\alpha,-\beta}(0)U(-x)

as
n\rightarrow\infty
uniformly in
x<0,\ x=o(a_{n})
if Condition A2 is
valid. Thus,

\displaystyle\lim_{n\rightarrow\infty}\int_{-H}^{K\wedge 0}e^{\theta x}\frac{\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)}{b_{n}}\mathbf{P}\left(S_{t}\leq K-x,L_{t}\geq 0\right)

\displaystyle\qquad=g_{\alpha,-\beta}(0)\int_{-H}^{K\wedge 0}e^{\theta x}U(-x)\mathbf{P}\left(S_{t}\leq K-x,L_{t}\geq 0\right)dx.

(35)

Combining (
34
) and (
35
) we deduce that, for fixed
t=n-j\in[0,J]

\lim_{n\rightarrow\infty}\frac{\mathbf{E}\left[e^{\theta S_{j}};S_{n}\leq K,\tau_{n}=j\right]}{b_{n}}=g_{\alpha,-\beta}(0)\int_{-\infty}^{K\wedge 0}e^{\theta x}U(-x)\mathbf{P}\left(S_{t}\leq K-x,L_{t}\geq 0\right)dx.

Summing with respect to
t
from
0
to
\infty
we get

\lim_{J\rightarrow\infty}\lim_{n\rightarrow\infty}\frac{R(n-J+1,n)}{b_{n}}=g_{\alpha,-\beta}(0)\int_{-\infty}^{K\wedge 0}e^{\theta x}U(-x)V_{0}(K-x)dx<\infty.

(36)

Thus,

\displaystyle\lim_{n\rightarrow\infty}\frac{\mathbf{E}\left[e^{\theta S_{\tau_{n}}};S_{n}\leq K\right]}{b_{n}}

\displaystyle=

\displaystyle g_{\alpha,\beta}(0)\int_{-\infty}^{K\wedge 0}e^{\theta x}U(-dx)\int_{0}^{K-x}V(-w)dw

\displaystyle+g_{\alpha,-\beta}(0)\int_{-\infty}^{K\wedge 0}e^{\theta x}U(-x)V_{0}(K-x)dx,

as desired.

7
Survival probability for branching processes evolving in extremely
unfavorable random environment

In this section we apply the results obtained for random walks to study the
population size of a critical branching process evolving in unfavorable
random environments. To describe the problems we plan to consider we denote
by
\mathfrak{F}

=\left\{\mathfrak{f}\right\}
the space of all
probability measures on
\mathbb{N}_{0}:=\{0,1,2,...\}
. For notational
reason, we identify a measure
\mathfrak{f}=\left\{\mathfrak{f}(\left\{0\right\}),\mathfrak{f}(\left\{1\right\}),...\right\}\in

\mathfrak{F}

with the respective probability generating function

f(s)=\sum_{k=0}^{\infty}\mathfrak{f}(\left\{k\right\})s^{k},\quad s\in[0,1],

and make no difference between
\mathfrak{f}
and
f
. Equipped with the
metric of total variation,
\mathfrak{F}

=\left\{\mathfrak{f}\right\}=\left\{f\right\}
becomes a Polish space. Let

F(s)=\sum_{j=0}^{\infty}F\left(\left\{j\right\}\right)s^{j},\quad s\in[0,1],

be a random variable taking values in
\mathfrak{F}
, and let

F_{n}(s)=\sum_{j=0}^{\infty}F_{n}\left(\left\{j\right\}\right)s^{j},\quad s\in[0,1],\quad n\in\mathbb{N},

be a sequence of independent probabilistic copies of
F
. The infinite
sequence
\mathcal{E}=\left\{F_{n},n\in\mathbb{N}\right\}
is called a
random environment.

A sequence of nonnegative random variables
\mathcal{Z}=\left\{Z_{n},\ n\in\mathbb{N}_{0}\right\}
specified on a probability space
(\Omega,\mathcal{F},\mathbf{P})
is called a branching process in random environment
(BPRE), if
Z_{0}
is independent of
\mathcal{E}
and, given
\mathcal{E}

the process
\mathcal{Z}
is a Markov chain with

\mathcal{L}\left(Z_{n}|Z_{n-1}=z_{n-1},\mathcal{E}=(f_{1},f_{2},...)\right)=\mathcal{L}(\xi_{n1}+\ldots+\xi_{ny_{n-1}})

for all
n\in\mathbb{N}
,
z_{n-1}\in\mathbb{N}_{0}
and
f_{1},f_{2},...\in\mathfrak{F}
, where
\xi_{n1},\xi_{n2},\ldots
is a
sequence of i.i.d. random variables with distribution
f_{n}.
Thus,
Z_{n-1}
is the
(n-1)
th generation size of the population of the
branching process and
f_{n}
is the offspring distribution of an individual
at generation
n-1
.

The sequence

S_{0}=0,\quad S_{n}=X_{1}+...+X_{n},\ n\geq 1,

where
X_{i}=\log F_{i}^{\prime}(1),i=1,2,...,
is called the associated
random walk for the process
\mathcal{Z}
.

We assume below that
Z_{0}=1
and impose the following restrictions on the
properties of the BPRE.

Condition B1.

The elements of the associated random walk satisfy Conditions A1 and
A2.

According to the classification of BPRE’s (see, for instance,
[
1
]

and
[
7
]
), Condition B1 means that we consider the critical BPRE’s.

Our second assumption on the environment concerns reproduction laws of
particles. Set

\gamma(b)=\frac{\sum_{k=b}^{\infty}k^{2}F\left(\left\{k\right\}\right)}{\left(\sum_{i=0}^{\infty}iF\left(\left\{i\right\}\right)\right)^{2}}.

Condition B2.

There exist
\varepsilon>0
and
b\in\,
\mathbb{N}

such
that

\mathbf{E}[(\log^{+}\gamma(b))^{\alpha+\varepsilon}]\ <\ \infty,

where
\log^{+}x=\log(x\vee 1)
.

It is known (see
[
1
, Theorem 1.1 and Corollary 1.2]
) that if
Conditions B1 and B2 are valid, then there exist a number
\theta\in(0,\infty)
and a sequence
l(1),l(2),...,
slowly varying at infinity such
that, as
n\rightarrow\infty

\mathbf{P}\left(Z_{n}>0\right)\sim\theta n^{-(1-\rho)}l(n),

(37)

and for any
x\geq 0

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq xa_{n}\right)

\displaystyle=

\displaystyle\mathbf{P}\left(S_{n}\leq xa_{n}|Z_{n}>0\right)\mathbf{P}\left(Z_{n}>0\right)

(38)

\displaystyle\sim

\displaystyle\mathbf{P}\left(Y_{1}^{+}\leq x\right)\mathbf{P}\left(Z_{n}>0\right),

where
\mathcal{Y}^{+}=\left\{Y_{t}^{+},0\leq t\leq 1\right\}
denotes the
meander of the strictly stable process
\mathcal{Y}
with index
\alpha
.

Thus, if a BPRE is critical, then, given
Z_{n}>0
the random variable
S_{n},
the value of the associated random walk that provides survival of
the population to a distant moment
n
, grows like
a_{n}
times a random
positive multiplier. Since
\mathbf{P}\left(Y_{1}^{+}\leq 0\right)=0
it
follows that if
\varphi(n)
satisfies the restriction

\limsup_{n\rightarrow\infty}\frac{\varphi(n)}{a_{n}}\leq 0,

(39)

then

\mathbf{P}\left(Z_{n}>0,S_{n}\leq\varphi(n)\right)=\mathbf{P}\left(S_{n}\leq\varphi(n)|Z_{n}>0\right)\mathbf{P}\left(Z_{n}>0\right)=o\left(\mathbf{P}\left(Z_{n}>0\right)\right)

as
n\rightarrow\infty
.

It is natural to consider the environment meeting condition (
39
)
as unfavorable for the development of the critical BPRE.

An important case of the unfavorable random environment was considered in

[
10
]
, where was shown that if
\varphi(n)\rightarrow\infty
as
n\rightarrow\infty
in such a way that
\varphi(n)=o(a_{n})
then

\mathbf{P}\left(Z_{n}>0,S_{n}\leq\varphi(n)\right)\sim\Theta b_{n}\int_{0}^{\varphi(n)}V(-w)dw,

where
\Theta\in(0,\infty)
is a known constant and
V(x)
is the same as
in (
2
).

In this paper we complement the results of
[
10
]
by imposing even
more severe restrictions on the environment. Namely, we assume that the
environment meets the assumption
S_{n}\leq K
for a fixed constant
K
and
call such an environment as extremely unfavorable.

Here is the main result of this section.

Theorem 11

Let Conditions B1 and B2 be valid. Then, for any fixed
K

\lim_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K\right)}{b_{n}}=G_{left}(K)+G_{right}(K),

where the constants
G_{left}(K)\in(0,\infty)
and
G_{right}(K)\in(0,\infty)
are specified below by formulas (
42
) and (
46
), respectively.

To prove the theorem we introduce two new probability measures
\mathbf{P}^{+}
and
\mathbf{P}^{-}
using the identities

\begin{array}[]{rl}\mathbf{E}[U(x+X);X+x\geq 0]\ =\ U(x)\ ,&x\geq 0\ ,\\
\mathbf{E}[V(x+X);X+x<0]\ =\ V(x)\ ,&x\leq 0\ ,\end{array}

valid for any oscillating random walk (see
[
7
]
, Chapter 4.4.3).
The construction procedure of these measures is standard and is explained
for
\mathbf{P}^{+}
and
\mathbf{P}^{-}
in detail in
[
1
]
and
[
2
]
(see also
[
7
]
, Chapter 5.2). We recall here only some
basic definitions related to this construction.

Let
\mathcal{F}_{n},n\geq 0,
be the
\sigma
-field of events generated by
random variables
F_{1},F_{2},...,F_{n}
and
Z_{0},Z_{1},...,Z_{n}
. These
\sigma
-field form a filtration
\mathcal{F}
. We assume that the random
walk
\mathcal{S=}\left\{S_{n},n\geq 0\right\}
with the inital value
S_{0}=x,x\in\mathbb{R}
, is adapted to filtration
\mathcal{F}
and
construct probability measures
\mathbf{P}_{x}^{+}
,
x\geq 0,
as follows.
For every sequence
T_{0},T_{1},...
of random variables with values in some
space
\mathcal{T}
and adopted to
\mathcal{F}
and for any bounded and
measurable function
g:\mathcal{T}^{n+1}\rightarrow\mathbb{R}
,
n\in\mathbb{N}_{0}
, we set

\mathbf{E}_{x}^{+}[g(T_{0},\ldots,T_{n})]\ :=\ \frac{1}{U(x)}\mathbf{E}_{x}[g(T_{0},\ldots,T_{n})U(S_{n});L_{n}\geq 0].\

Similarly,
V
gives rise to probability measures
\mathbf{P}_{x}^{-}
,
x\leq 0
, characterized for each
n\in\mathbb{N}_{0}
by the equation

\mathbf{E}_{x}^{-}[g(T_{0},\ldots,T_{n})]\ :=\ \frac{1}{V(x)}\mathbf{E}_{x}[g(T_{0},\ldots,T_{n})V(S_{n});M_{n}<0]\ .

The following two lemmas provide the major steps for proving Theorem
11
.

Lemma 12

(see Lemma 4 in
[
10
]
) Assume Condition
B1
. Let
H_{1},H_{2},...,
be a uniformly bounded sequence of real-valued random
variables adapted to some filtration
\mathcal{\tilde{F}=}\left\{\mathcal{\tilde{F}}_{k},k\in\mathbb{N}\right\}
, which converges
\mathbf{P}^{+}
-a.s. to a random variable
H_{\infty}
. Suppose that
\varphi(n),

n\in\mathbb{N},
is a real-valued function such that
\inf_{n\in\mathbb{N}}\varphi(n)\geq C>~0
and
\varphi(n)=o(a_{n})
as
n\rightarrow\infty
.
Then

\lim_{n\rightarrow\infty}\frac{\mathbf{E}\left[H_{n};S_{n}\leq\varphi(n),L_{n}\geq 0\right]}{\mathbf{P}\left(S_{n}\leq\varphi(n),L_{n}\geq 0\right)}=\mathbf{E}^{+}\left[H_{\infty}\right].

The statement of the following lemma uses sequences
F_{1},\ldots,F_{n}
of
probability generating functions.

Lemma 13

Let
0<\delta<1
. Let

W_{n}=g_{n}(F_{1},\ldots,F_{\lfloor\delta n\rfloor},Z_{0},Z_{1},...,Z_{\lfloor\delta n\rfloor}),n\geq 1,

(40)

be random variables with values in an Euclidean (or polish) space
\mathcal{W}
such that

W_{n}\ \rightarrow\ W_{\infty}\quad\mathbf{P}_{x}^{+}\text{-a.s.}

for some
\mathcal{W}
-valued random variable
W_{\infty}
and for all
x\geq 0
. Also let
B_{n}=h_{n}(F_{1},\ldots,F_{\lfloor\delta n\rfloor}),n\geq 1
, be random variables with values in an Euclidean (or polish)
space
\mathcal{B}
such that

B_{n}\ \rightarrow\ B_{\infty}\quad\mathbf{P}^{-}\text{-a.s.}

for some
\mathcal{B}
-valued random variable
B_{\infty}.
Denote

\tilde{B}_{n}\ :=\ h_{n}(F_{n},\ldots,F_{n-\lfloor\delta n\rfloor+1})\ .

Then for any bounded, continuous function
\Psi:\mathcal{W}\times\mathcal{B}\times\mathbb{R}\rightarrow\mathbb{R}
and for
\theta>0
as
n\rightarrow\infty

\displaystyle\mathbf{E}[\Psi(W_{n},

\displaystyle\tilde{B}_{n},S_{n})e^{\theta S_{n}}\;;\;\tau_{n}=n]\;\big/\;\mathbf{E}[e^{\theta S_{n}};\tau_{n}=n]

\displaystyle\rightarrow\ K_{1}\iiint\Psi(w,b,-z)\,\mathbf{P}_{z}^{+}\left(W_{\infty}\in dw\right)\mathbf{P}^{-}\left(B_{\infty}\in db\right)U(z)e^{-\theta z}dz\ ,

where

K_{1}^{-1}=K_{1\theta}^{-1}=\int_{0}^{\infty}e^{-\theta z}U(z)\,dz.

Remark.
The statement of the lemma almost literally coincides with
the statement of Theorem 2.8 in
[
2
]
. The only difference is that
the sequence
\left\{W_{n},n\geq 1\right\}
in
[
2
]
has the
form

W_{n}=g_{n}(F_{1},\ldots,F_{\lfloor\delta n\rfloor}),n\geq 1.

However, the analysis of the arguments used in
[
2
]
to check the
validity of Theorem 2.8 shows that they are still valid for
\left\{W_{n},n\geq 1\right\}
specified by (
40
).

Proof of Theorem
11
. First observe that

\displaystyle\mathbf{P}\left(Z_{n}>0|\mathcal{E}\right)

\displaystyle\leq

\displaystyle\min_{0\leq k\leq n}\mathbf{P}\left(Z_{k}>0|\mathcal{E}\right)

\displaystyle\mathbf{\leq}

\displaystyle\min_{0\leq k\leq n}\mathbf{E}\left[Z_{k}|\mathcal{E}\right]=\min_{0\leq k\leq n}e^{S_{k}}=e^{S_{\tau_{n}}}.

This estimate combined with the arguments used in the proof of Theorem
5
implies

\displaystyle\limsup_{J\rightarrow\infty}\limsup_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}\in\left[J+1,n-J\right]\right)}{b_{n}}

\displaystyle\quad=\limsup_{J\rightarrow\infty}\limsup_{n\rightarrow\infty}\frac{\mathbf{E}\left[\mathbf{P}\left(Z_{n}>0|\mathcal{E}\right);S_{n}\leq K,\tau_{n}\in\left[J+1,n-J\right]\right]}{b_{n}}

\displaystyle\quad\leq\limsup_{J\rightarrow\infty}\limsup_{n\rightarrow\infty}\frac{\mathbf{E}\left[e^{S_{\tau_{n}}};S_{n}\leq K,\tau_{n}\in\left[J+1,n-J\right]\right]}{b_{n}}=0.

(41)

Thus, it remains to analyse the case

\tau_{n}\in[0,J]\cup[n-J+1,n].

We fix sufficiently large positive integers
J
and
N>\left|K\right|
and, for
j\in[0,J]
consider the chain of estimates

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,S_{j}<-N\right)

\displaystyle\qquad\leq\mathbf{E}\left[e^{S_{j}};S_{n}\leq K,\tau_{n}=j,S_{j}<-N\right]

\displaystyle\qquad=\int_{-\infty}^{-N}e^{\theta x}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)\mathbf{P}\left(S_{n-j}\leq K-x,L_{n-j}\geq 0\right)

\displaystyle\qquad\leq\int_{-\infty}^{-N}e^{\theta x}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)\mathbf{P}\left(S_{n-j}\leq-2x,L_{n-j}\geq 0\right).

Since
V(-w),w\geq 0,
is a renewal function, there is a constant
C\in(0,\infty)
such that
V(-w)\leq C\left(w+1\right)
. In view of (
16
), for any
\varepsilon>0
one can find sufficiently large
N=N(\varepsilon)
such that

\displaystyle\int_{-\infty}^{-N}e^{\theta x}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)\mathbf{P}\left(S_{n-j}\leq-2x,L_{n-j}\geq 0\right)

\displaystyle\qquad\leq Cb_{n-j}\int_{-\infty}^{-N}e^{\theta x}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)\int_{0}^{-2x}V(-w)dw

\displaystyle\qquad\leq C_{1}b_{n-j}\int_{-\infty}^{-N}e^{\theta x}(\left|x\right|^{2}+1)\mathbf{P}\left(S_{j}\in dx\right)\leq\varepsilon b_{n-j}

for all
n-j\geq 0.
Thus,

\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,S_{j}<-N\right)\leq\varepsilon b_{n-j}

for sufficiently large
N
.

Further, for any
Q\in\mathbb{N}
and
N>K
we get by (
16
) and (
8
):

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,S_{j}\geq-N,Z_{j}>Q\right)

\displaystyle\quad\leq\mathbf{P}\left(S_{n}\leq K,\tau_{n}=j,S_{j}\geq-N,Z_{j}>Q\right)

\displaystyle\quad=\int_{-N}^{K\wedge 0}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j,Z_{j}>Q\right)\mathbf{P}\left(S_{n-j}\leq K-x,L_{n-j}\geq 0\right)

\displaystyle\quad\leq\int_{-N}^{0}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j,Z_{j}>Q\right)\mathbf{P}\left(S_{n-j}\leq 2N,L_{n-j}\geq 0\right)

\displaystyle\quad\leq\mathbf{P}\left(\tau_{j}=j,Z_{j}>Q\right)\mathbf{P}\left(S_{n-j}\leq 2N,L_{n-j}\geq 0\right)

\displaystyle\quad\leq Cb_{n-j}\mathbf{P}\left(\tau_{j}=j,Z_{j}>Q\right)\int_{0}^{2N}V(-w)dw

\displaystyle\quad\leq C_{1}b_{n-j}\mathbf{P}\left(\tau_{j}=j,Z_{j}>Q\right)N^{2}.

Clearly,

\lim_{Q\rightarrow\infty}\mathbf{P}\left(\tau_{j}=j,Z_{j}>Q\right)\leq\lim_{Q\rightarrow\infty}Q^{-1}\mathbf{E}\left[e^{S_{j}};\tau_{j}=j\right]=0.

Therefore, we can select a sufficiently large
Q
such that

\mathbf{P}\left(\tau_{j}=j,Z_{j}>Q\right)N^{2}\leq\varepsilon

and obtain the estimate

\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,Z_{j}>Q\right)\leq C_{1}\varepsilon b_{n-j}.

We now consider the term

\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,S_{j}\geq-N,Z_{j}\leq Q\right).

Introduce the event

A_{u.s}:=\left\{Z_{n}>0\text{ for all }n\geq 0\right\}

and for
0\leq s\leq 1
define iterations

F_{k,n}(s):=F_{k+1}(F_{k+2}(\ldots F_{n}(s)\ldots))\text{ if }0\leq k<n\text{ and }F_{n,n}(s):=s.

Since the limit

\lim_{n\rightarrow\infty}\mathbf{P}\left(Z_{n}>0|\mathcal{E},Z_{0}=q\right)=\lim_{n\rightarrow\infty}\left(1-F_{0,n}^{q}(0)\right)=:1-F_{0,\infty}^{q}(0)

exists
\mathbf{P}^{+}
-a.s. by monotonicity of the extinction probability
of the branching process, it follows from Lemma
12
that

\mathbf{E}\left[1-F_{0,n}^{q}(0)|S_{n}\leq y_{n},L_{n}\geq 0\right]\rightarrow\mathbf{E}^{+}\left[1-F_{0,\infty}^{q}(0)\right]=\mathbf{P}_{q}^{+}\left(A_{u.s}\right)>0

as
n\rightarrow\infty
if
y_{n}=o(a_{n})
. Besides,
\mathbf{P}_{q}^{+}\left(A_{u.s}\right)>0
according to Proposition 3.1 in
[
1
]
.

Now Corollary
8
gives that, for fixed
q\leq Q
and
x\in[-N,K]

\displaystyle\mathbf{P}\left(Z_{n-j}>0,S_{n-j}\leq K-x,L_{n-j}\geq 0,Z_{0}=q\right)

\displaystyle\qquad=\mathbf{E}\left[1-F_{0,n-j}^{q}(0);S_{n-j}\leq K-x,L_{n-j}\geq 0\right]

\displaystyle\qquad\sim\mathbf{P}_{q}^{+}\left(A_{u.s}\right)\mathbf{P}\left(S_{n-j}\leq K-x,L_{n-j}\geq 0\right)

\displaystyle\qquad\sim g_{\alpha,\beta}(0)\mathbf{P}_{q}^{+}\left(A_{u.s}\right)b_{n-j}\int_{0}^{K-x}V(-w)dw

as
n-j\rightarrow\infty
. Hence, using estimate (
16
) once again
and applying the dominated convergence theorem we conclude that

\displaystyle\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j,S_{j}\geq-N,Z_{j}=q\right)}{b_{n-j}}

\displaystyle=

\displaystyle\int_{-N}^{K\wedge 0}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j,Z_{j}=q\right)\frac{\mathbf{E}\left[1-F_{0,n-j}^{q}(0);S_{n-j}\leq K-x,L_{n-j}\geq 0\right]}{b_{n-j}}

\displaystyle\sim

\displaystyle g_{\alpha,\beta}(0)\mathbf{P}_{q}^{+}\left(A_{u.s}\right)\int_{-N}^{K\wedge 0}\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j,Z_{j}=q\right)\int_{0}^{K-x}V(-w)dw

as
n-j\rightarrow\infty
.

Combining all these estimates, letting
Q
and
N
tend to infinity and
using the equivalence
b_{n-j}\sim b_{n}
valid for each fixed
j
as
n\rightarrow\infty
, we see that, for any fixed
j\in[0,J]

\displaystyle m_{j}:=

\displaystyle\lim_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j\right)}{b_{n}}

\displaystyle=

\displaystyle g_{\alpha,\beta}(0)\int_{-\infty}^{K\wedge 0}\mathbf{E}\left[\mathbf{P}_{Z_{j}}^{+}\left(A_{u.s}\right)\mathbf{P}\left(S_{j}\in dx,\tau_{j}=j\right)\int_{0}^{K-x}V(-w)dw\right].

Thus,

G_{left}(K):=\lim_{J\rightarrow\infty}\lim_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}\in[0,J]\right)}{b_{n}}=\sum_{j=0}^{\infty}m_{j}.

(42)

Clearly,

G_{left}(K)\geq m_{0}=g_{\alpha,\beta}(0)\mathbf{P}^{+}\left(A_{u.s}|Z_{0}=1\right)\int_{0}^{K}V(-w)dw>0.

The inequality
G_{left}(K)<\infty
follows from (
33
) and the
estimate

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}\in[0,J]\right)

\displaystyle=

\displaystyle\mathbf{E}\left[1-F_{0,n}(0);S_{n}\leq K,\tau_{n}\in[0,J]\right]

\displaystyle\leq

\displaystyle\mathbf{E}\left[e^{S_{\tau_{n}}};S_{n}\leq K,\tau_{n}\in[0,J]\right]=R(0,J).

We now assume that
n-j=t\in[0,J]
and, using the independency of
F_{1},\ldots,F_{j}
and
F_{j+1},\ldots,F_{n}
, write

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}=j\right)=\mathbf{E}\left[1-F_{0,n}(0);S_{n}\leq K,\tau_{n}=j\right]

\displaystyle=

\displaystyle\mathbf{E}\left[1-F_{0,j}(F_{j,n}(0));S_{j}\leq K-(S_{n}-S_{j}),\tau_{n}=j\right]

\displaystyle=

\displaystyle\int_{K}^{\infty}\int_{0}^{1}\mathbf{P}\left(F_{0,t}(0)\in ds,S_{t}\in dx,L_{t}\geq 0\right)\mathbf{E}\left[1-F_{0,j}(s);S_{j}\leq K-x,\tau_{j}=j\right].

Our aim is to investigate the quantity

\mathbf{E}\left[1-F_{0,j}(s);S_{j}\leq K-x,\tau_{j}=j\right]

for fixed
s\in\left[0,1\right]
and
x\geq K
.

Clearly,

\displaystyle\mathbf{E}\left[1-s^{Z_{j}}|\mathcal{E}\right]

\displaystyle=

\displaystyle\mathbf{E}\left[\mathbf{E}\left[1-s^{Z_{j}}|Z_{[j/2]}\right]\mathcal{E}\right]=\mathbf{E}\left[1-\left(F_{\left[j/2\right],j}(s)\right)^{Z_{[j/2]}}|\mathcal{E}\right]

\displaystyle=

\displaystyle\mathbf{E}\left[1-\left(F_{\left[j/2\right],j}(s)\right)^{\exp\left\{S_{\left[j/2\right]}-S_{j}\right\}Z_{[j/2]}\exp\left\{-S_{\left[j/2\right]}\right\}\exp\left\{S_{j}\right\}}|\mathcal{E}\right].

Define

\Psi_{K-x}(w,b,z)=\left(1-b^{w\exp\left\{z\right\}}\right)e^{-z}I\left\{z\leq K-x\right\}

for
w\geq 0,0\leq b\leq 1,z\in\mathbb{R}
with
0^{0}=1
and continue
\Psi_{K-x}
to the other values of
w,b,z
to a bounded smooth function. In
doing so, points of discontinuity in
(0,0,z)
and
(w,b,K-x)
are
unavoidable, which will be bypassed later on.

With this notation in view, we write

\mathbf{E}\left[1-F_{0,j}(s);S_{j}\leq K-x,\tau_{j}=j\right]=\mathbf{E}\left[\Psi_{K-x}(W_{j},\tilde{B}_{j}(s),S_{j})e^{S_{j}};\tau_{j}=j\right],

where

W_{j}:=Z_{[j/2]}e^{-S_{\left[j/2\right]}},\quad\tilde{B}_{j}(s):=\left(F_{\left[j/2\right],j}(s)\right)^{\exp\left\{S_{\left[j/2\right]}-S_{j}\right\}}.

Since
\left\{W_{j},j\geq 1\right\}
is a martingale,

W_{j}=Z_{[j/2]}e^{-S_{\left[j/2\right]}}\rightarrow W_{\infty}\qquad\mathbf{P}_{z}^{+}\text{- a.s.}

as
j\rightarrow\infty
. Moreover, it follows from Proposition 3.1 in
[
1
]
that

\mathbf{P}_{z}^{+}\left(W_{\infty}>0\right)>0

(43)

for any
z\geq 0
(In fact, (
43
) was proved in
[
1
]
for
\mathbf{P}_{0}^{+}
only. However, the analysis of the proof given in the
mentioned proposition shows that (
43
) is valid for any
z>0
as
well.). Further, according to Lemma 3.2 in
[
2
]
the sequence
B_{j}(s):=\left(F_{\left[j/2\right],0}(s)\right)^{\exp\left\{-S_{\left[j/2\right]}\right\}},j=1,2,...
is nondecreasing and
B_{j}(s)\geq s^{\exp\left\{-S_{0}\right\}}
. Thus,

B_{j}(s)\rightarrow B_{\infty}(s)\geq s^{\exp\left\{-S_{0}\right\}}=s\qquad\mathbf{P}^{-}\text{- a.s.}

as
j\rightarrow\infty
. In view of

\mathbf{P}\left(\tilde{B}_{j}(s)\geq s\right)=\mathbf{P}\left(B_{j}(s)\geq s\right)=1,

the second random variable in
\Psi_{K-x}(W_{j},\tilde{B}_{j}(s),S_{j})
is
separated from zero with probability one.

Thus, we may restrict
\Psi_{K-x}
to the domain
(w,b,z\neq K-x)
with
b>0,
where it is continuous. Finally, the additional discontinuity at
z=K-x
has probability
0
with respect to the measure

\mu\left(dz\right):=K_{1}e^{-z}U(z)I\left\{z\geq 0\right\}dz,

where
K_{1}^{-1}:=\int_{0}^{\infty}e^{-z}U(z)dz
.

As a result, we may apply Lemma
13
to conclude that, as
j\rightarrow\infty

\frac{\mathbf{E}\left[\Psi_{K-x}(W_{j},\tilde{B}_{j}(s),S_{j})e^{S_{j}};\tau_{j}=j\right]}{\mathbf{E}\left[e^{S_{j}};\tau_{j}=j\right]}\rightarrow h(s,K-x),

(44)

where

h(s,K-x):=K_{1}\int\int\int\Psi_{K-x}(w,b,-z)\mathbf{P}_{z}^{+}\left(W_{\infty}\in dw\right)\mathbf{P}^{-}\left(B_{\infty}(s)\in db\right)e^{-z}U(z)dz

is a bounded function.

It was shown in the proof of Lemma 3.4 in
[
2
]
that
B_{\infty}(s)<1

\mathbf{P}^{-}
-a.s. under our conditions. Alltogether this implies
that the right-hand side of (
44
) is positive. Using now the
inequality

\mathbf{E}\left[1-F_{0,j}(s);S_{j}\leq K-x,\tau_{j}=j\right]\leq\mathbf{E}\left[e^{S_{j}};\tau_{j}=j\right]

and the dominated convergence theorem we conclude that

\displaystyle\lim_{j\rightarrow\infty}\int_{K}^{\infty}\int_{0}^{1}\mathbf{P}\left(F_{0,t}(0)\in ds,S_{t}\in dx,L_{t}\geq 0\right)\frac{\mathbf{E}\left[1-F_{0,j}(s);S_{j}\leq K-x,\tau_{j}=j\right]}{\mathbf{E}\left[e^{S_{j}};\tau_{j}=j\right]}

\displaystyle\qquad\qquad=\int_{K}^{\infty}\int_{0}^{1}\mathbf{P}\left(F_{0,t}(0)\in ds,S_{t}\in dx,L_{t}\geq 0\right)h(s,K-x).

(45)

According to (
6
)

\mathbf{E}\left[e^{S_{j}};\tau_{j}=j\right]=\mathbf{E}\left[e^{S_{j}};M_{j}<0\right]\sim g_{\alpha,\beta}(0)b_{j}\int_{0}^{\infty}e^{-w}U(w)dw

as
j\rightarrow\infty
. Using this fact and summing (
45
) over
t
from
0
to
\infty
we get

\displaystyle G_{right}(K):=\lim_{J\rightarrow\infty}\lim_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0;S_{n}\leq K,\tau_{n}\in[n-J+1,n]\right)}{b_{n}}

\displaystyle\quad=g_{\alpha,\beta}(0)\int_{0}^{\infty}e^{-w}U(w)dw\times

\displaystyle\quad\times\int_{K}^{\infty}\int_{0}^{1}\sum_{t=0}^{\infty}\mathbf{P}\left(F_{0,t}(0)\in ds,S_{t}\in dx,L_{t}\geq 0\right)h(s,K-x)>0.

(46)

The inequality
G_{right}(K)<\infty
follows from (
36
) and the
estimate

\displaystyle\mathbf{P}\left(Z_{n}>0,S_{n}\leq K,\tau_{n}\in[n-J+1,n]\right)

\displaystyle\qquad\quad=\mathbf{E}\left[1-F_{0,n}(0);S_{n}\leq K,\tau_{n}\in[n-J+1,n]\right]

\displaystyle\qquad\quad\leq\mathbf{E}\left[e^{S_{\tau_{n}}};S_{n}\leq K,\tau_{n}\in[n-J+1,n]\right]=R(n-J+1,n).

Combining (
41
) with (
42
) and (
46
) we get

\lim_{n\rightarrow\infty}\frac{\mathbf{P}\left(Z_{n}>0,S_{n}\leq K\right)}{b_{n}}=G_{left}(K)+G_{right}(K),

as desired.
