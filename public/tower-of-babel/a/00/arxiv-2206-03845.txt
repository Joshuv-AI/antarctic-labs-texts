A Flat System Possessing no (x,u)-Flat Output
Conrad Gstöttner Bernd Kolar Markus Schöberl

Abstract
In general, flat outputs of a nonlinear system may depend on the system’s state and input as well as on an arbitrary number of time derivatives of the latter. If a flat output which also depends on time derivatives of the input is known, one may pose the question whether there also exists a flat output which is independent of these time derivatives, i.e., an (x,u)-flat output. Until now, the question whether every flat system also possesses an (x,u)-flat output has been open. In this contribution, this conjecture is disproved by means of a counterexample. We present a two-input system which is differentially flat with a flat output depending on the state, the input and first-order time derivatives of the input, but which does not possess any (x,u)-flat output. The proof relies on the fact that every (x,u)-flat two-input system can be exactly linearized after an at most dim(x)-fold prolongation of one of its (new) inputs after a suitable input transformation has been applied.

II
PRELIMINARIES

In this section, we summarize some results regarding flatness of two-input systems. Throughout, all functions and vector fields are assumed to be smooth and all distributions are assumed to have locally constant dimension, we consider generic points only.

Consider a nonlinear two-input system of the form

\displaystyle\begin{aligned} \dot{x}_{i}&=f_{i}(x,u)\,,&i=1,\ldots,n\end{aligned}

(5)

with the state
x
being defined on an n-dimensional manifold
\mathcal{X}
and with the input
u
taking values in a two-dimensional manifold
\mathcal{U}
.

Definition 2

The two-input system (
5
) is called flat if there exist two functions
y_{j}=\varphi_{j}(x,u,\dot{u},\ldots,u^{(q)})
,
j=1,2
and smooth functions
F_{x_{i}}
and
F_{u_{j}}
such that locally

\displaystyle\begin{aligned} x_{i}&=F_{x_{i}}(\varphi,\dot{\varphi},\ldots,\varphi^{(r-1)})\,,&i&=1,\ldots,n\\
u_{j}&=F_{u_{j}}(\varphi,\dot{\varphi},\ldots,\varphi^{(r)})\,,&j&=1,2\,.\end{aligned}

The functions
y_{j}=\varphi_{j}(x,u,\dot{u},\ldots,u^{(q)})
,
j=1,2
are called the components of the
(x,u,\dot{u},\ldots,u^{(q)})
-flat output
y=\varphi(x,u,\dot{u},\ldots,u^{(q)})
.

An important implication of Definition
2
is that the time derivatives
\varphi,\dot{\varphi},\ldots,\varphi^{(\beta)}
of a flat output are functionally independent for arbitrary
\beta
, which means that there does not exist any nontrivial function
\chi:\mathbb{R}^{2\beta+2}\mapsto\mathbb{R}
such that
\chi(\varphi,\dot{\varphi},\ldots,\varphi^{(\beta)})=0
. (This property reflects the fact that there are no constraints on the time evolution of a flat output.) As a consequence of that, it can be shown that there exist unique minimal integers
r_{1}
,
r_{2}
and unique maps
F_{x}
,
F_{u}
such that

\displaystyle\begin{aligned} x&=F_{x}(\varphi_{1},\dot{\varphi}_{1},\ldots,\varphi_{1}^{(r_{1}-1)},\varphi_{2},\dot{\varphi}_{2},\ldots,\varphi_{2}^{(r_{2}-1)})\\
u&=F_{u}(\varphi_{1},\dot{\varphi}_{1},\ldots,\varphi_{1}^{(r_{1})},\varphi_{2},\dot{\varphi}_{2},\ldots,\varphi_{2}^{(r_{2})})\,.\end{aligned}

(6)

For
(x,u)
-flat outputs
y=\varphi(x,u)
, we define the integers
\rho_{1}
,
\rho_{2}
where
\rho_{j}
is the relative degree of the component
\varphi_{j}
of the flat output, i.e.,
\rho_{j}
is the smallest integer such that
\varphi_{j}^{(\rho_{j})}
explicitly depends on
u
(note that
\rho_{j}
may be zero).

Flat systems can be exactly linearized by means of an endogenous dynamic feedback, see e.g.
[
6
]
for the systematic construction of such a linearizing feedback. An important
subclass of flat systems are those which are exactly linearizable by static feedback, i.e., which can be transformed into a linear controllable system, in particular the Brunovský normal form

\displaystyle\begin{aligned} \dot{\bar{x}}_{1,1}&=\bar{x}_{1,2}\\
\dot{\bar{x}}_{1,2}&=\bar{x}_{1,3}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\dot{\bar{x}}_{1,\rho_{1}}&=\bar{u}_{1}\end{aligned}\qquad\begin{aligned} \dot{\bar{x}}_{2,1}&=\bar{x}_{2,2}\\
\dot{\bar{x}}_{2,2}&=\bar{x}_{2,3}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\dot{\bar{x}}_{2,\rho_{2}}&=\bar{u}_{2}\end{aligned}

where
\rho_{1}+\rho_{2}=n
, by means of an invertible state- and input transformation
\bar{x}=\Phi_{x}(x)
,
\bar{u}=\Phi_{u}(x,u)
. A system which is static feedback linearizable is obviously flat with
y=(\bar{x}_{1,1},\bar{x}_{2,1})
as a flat output. The flat parameterization (
6
) with respect to this flat output is a diffeomorphism and conversely, if a system possesses a flat output for which the corresponding flat parameterization is a diffeomorphism, then it is static feedback linearizable. We refer to these particular flat outputs as linearizing outputs. The relative degrees
\rho_{1}
,
\rho_{2}
of the components of linearizing outputs sum to
n
(a linearizing output is an output with a vector relative degree of
n
, see e.g.
[
26
]
). The static feedback linearization problem has been solved completely, see
[
18
]
,
[
19
]
and
[
27
]
,
[
26
]
. In the following we recall necessary and sufficient conditions for static feedback linearizability of systems of the form (
5
), for a proof we refer to
[
27
]
.
For (
5
), define the distributions
\mathcal{D}^{0}=\mathrm{span}\{\partial_{u_{1}},\partial_{u_{2}}\}
and
\mathcal{D}^{i}=\mathcal{D}^{i-1}+[f,\mathcal{D}^{i-1}]
,
i\geq 1
on the state and input manifold
\mathcal{X}\times\mathcal{U}
, where
f=f_{i}(x,u)\partial_{x_{i}}
.

Theorem 3

The two-input system (
5
) is linearizable by static feedback if and only if all the distributions
\mathcal{D}^{i}
are involutive and
\mathrm{dim}(\mathcal{D}^{n})=n+2
.

The following proposition states that two-input
(x,u)
-flat systems can be exactly linearized by a special kind of endogenous dynamic feedback, namely prolongations of inputs. Based on this result, we will prove that (
3
) cannot admit any
(x,u)
-flat output.

Proposition 4

Every
(x,u)
-flat two-input system (
5
) can be rendered static feedback linearizable by
\mathrm{dim}(x)=n
-fold prolonging a suitably chosen input after a suitable invertible input transformation has been applied.

Proof.
Let
y=\varphi(x,u)
be an
(x,u)
-flat output of (
5
) and let
r_{1}
,
r_{2}
be the unique smallest integers such that (
6
) holds. The derivatives
\varphi_{1},\dot{\varphi}_{1},\ldots,\varphi_{1}^{(\rho_{1}-1)},\varphi_{1},\dot{\varphi}_{2},\ldots,\varphi_{2}^{(\rho_{2}-1)}
yield in total
\rho_{1}+\rho_{2}
independent functions of
x
only. Apply the invertible input transformation
\bar{u}_{1}=\varphi_{1}^{(\rho_{1})}(x,u)
,
\bar{u}_{2}=u_{2}
(permute if necessary
u_{1}
and
u_{2}
). After applying this transformation, we clearly have
\varphi_{2}^{(\rho_{2})}=\varphi_{2}^{(\rho_{2})}(x,\bar{u}_{1})
. Otherwise, the flat output and its derivatives up to arbitrary orders would only yield
\rho_{1}+\rho_{2}
independent functions of
x
and we could not express all states in terms of the flat output and its derivatives, which contradicts flatness. (An exception is of course
\varphi
being a linearizing output, i.e.,
\rho_{1}+\rho_{2}=n
, in which case the proposition clearly holds, since
n
-fold prolonging an input of a system in Brunovský normal form again yields a system in Brunovský normal form.) So we have
\varphi_{2}^{(\rho_{2})}=\varphi_{2}^{(\rho_{2})}(x,\bar{u}_{1})
, and it follows that

\displaystyle\begin{aligned} \varphi_{1}&=\varphi_{1}(x)&&&\varphi_{2}&=\varphi_{2}(x)\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}&&&&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\varphi_{1}^{(\rho_{1}-1)}&=\varphi_{1}^{(\rho_{1}-1)}(x)&&&\varphi_{2}^{(\rho_{2}-1)}&=\varphi_{2}^{(\rho_{2}-1)}(x)\\
\varphi_{1}^{(\rho_{1})}&=\bar{u}_{1}&&&\varphi_{2}^{(\rho_{2})}&=\varphi_{2}^{(\rho_{2})}(x,\bar{u}_{1})\\
\varphi_{1}^{(\rho_{1}+1)}&=\dot{\bar{u}}_{1}&&&\varphi_{2}^{(\rho_{2}+1)}&=\varphi_{2}^{(\rho_{2}+1)}(x,\bar{u}_{1},\dot{\bar{u}}_{1})\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}&&&&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\varphi_{1}^{(r_{1})}&=\bar{u}_{1}^{(r_{1}-\rho_{1})}&&&\varphi_{2}^{(r_{2})}&=\varphi_{2}^{(r_{2})}(x,\bar{u}_{1},\dot{\bar{u}}_{1},\ldots,\\
&&&&&\hskip 50.00008pt\bar{u}_{1}^{(r_{2}-\rho_{2})},\bar{u}_{2})\end{aligned}

(7)

with
\varphi_{2}^{(\rho_{2}+k)}
explicitly depending on
\bar{u}_{1}^{(k)}
. To show that
\varphi_{2}^{(r_{2})}
explicitly depends on
\bar{u}_{2}
but no lower order time derivative of
\varphi_{2}
can depend on
\bar{u}_{2}
, recall that
r_{2}
is by assumption the minimal integer for which (
6
) holds. If
\bar{u}_{2}
would occur in
\varphi_{2}^{(s)}
for some
s<r_{2}
, then
r_{2}
could not be minimal since
\varphi_{2}^{(s+1)},\ldots,\varphi_{2}^{(r_{2})}
would be useless for constructing functions of
x
and
\bar{u}
only. On the other hand,
\bar{u}_{2}
must explicitly occur in
\varphi_{2}^{(r_{2})}
, since otherwise
\bar{u}_{2}
could not be expressed in terms of
\varphi_{1},\ldots,\varphi_{1}^{(r_{1})},\varphi_{2},\ldots,\varphi_{2}^{(r_{2})}
. Furthermore, it follows that the explicit dependence of
\varphi_{2}^{(r_{2})}
on
\bar{u}_{1}^{(r_{2}-\rho_{2})}
and the minimality of
r_{1}
imply that
r_{1}-\rho_{1}=r_{2}-\rho_{2}
. From the functions (
7
), we obtain exactly
\rho_{1}+r_{2}
independent functions of
x
only, and by the flatness assumption this must be equal to
n
, i.e.,
\rho_{1}+r_{2}=n
. Therefore, the
r_{1}+r_{2}+2
functions (
7
) depend on the
n+2+(r_{1}-\rho_{1})=r_{1}+r_{2}+2
variables
x,\bar{u}_{1},\dot{\bar{u}}_{1},\ldots,\bar{u}_{1}^{(r_{1}-\rho_{1})},\bar{u}_{2}
, and since the time derivatives of a flat output up to an arbitrary order are functionally independent, it follows that conversely the variables
x,\bar{u}_{1},\dot{\bar{u}}_{1},\ldots,\bar{u}_{1}^{(r_{1}-\rho_{1})},\bar{u}_{2}
can be expressed in terms of the functions (
7
). In other words, (
7
) describes a diffeomorphism. Above, we noted that
r_{1}-\rho_{1}=r_{2}-\rho_{2}
and
\rho_{1}+r_{2}=n
. We thus also have
\rho_{2}+r_{1}=n
, and since
\rho_{1},\rho_{2}\geq 0
, we clearly have
r_{1},r_{2}\leq n
and in particular
r_{1}-\rho_{1}\leq n
. Therefore, we may extend (
7
) by adding

\displaystyle\begin{aligned} \varphi_{1}^{(r_{1}+1)}&=\bar{u}_{1}^{(r_{1}-\rho_{1}+1)}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\varphi_{1}^{(n+\rho_{1})}&=\bar{u}_{1}^{(n)}\end{aligned}

(8)

and still have a diffeomorphism (note that in case of
r_{1}-\rho_{1}=n
there are no equations added). Now consider the prolonged system

\displaystyle\begin{aligned} \dot{x}&=f(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{\bar{u}}_{1}&=\bar{u}_{1,1}\\
\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\\
\dot{\bar{u}}_{1,n-1}&=\bar{u}_{1,n}\\
\end{aligned}

(9)

with the state
(x,\bar{u}_{1},\bar{u}_{1,1},\ldots,\bar{u}_{1,n-1})
and the input
(\bar{u}_{1,n},\bar{u}_{2})
. The flat parameterization of (
9
) with respect to the flat output
\varphi
is a diffeomorphism (the inverse of which is given by (
7
) extended by (
8
) with
\bar{u}_{1}^{(\alpha)}
replaced by
\bar{u}_{1,\alpha}
), and thus (
9
) it is static feedback linearizable with
\varphi
as a linearizing output.
\square

In

Consider again the system (
3
)

Proposition 6

The system (

(x,u)
-flat output.

Proof.
We prove this proposition by contradiction. Assume that (
3
) is
(x,u)
-flat. Then, according to Proposition
4
, the system can be rendered static feedback linearizable by

-fold prolonging a suitable input after a suitable invertible input transformation has been applied. The most general form of such an input transformation is

\displaystyle\begin{aligned} \bar{u}_{1}&=g_{1}(x,u_{1},u_{2})\\
\bar{u}_{2}&=g_{2}(x,u_{1},u_{2})\,,\end{aligned}

(10)

with an inverse of the general form

\displaystyle\begin{aligned} u_{1}&=h_{1}(x,\bar{u}_{1},\bar{u}_{2})\\
u_{2}&=h_{2}(x,\bar{u}_{1},\bar{u}_{2})\,.\end{aligned}

(11)

By assumption, there exists a transformation of the form (
10
) with inverse (
11
) such that the prolonged system

\displaystyle\begin{aligned} \dot{x}_{1}&=h_{1}(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{2}&=h_{2}(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{3}&=x_{1}+\tfrac{(h_{2}(x,\bar{u}_{1},\bar{u}_{2}))^{2}}{2h_{1}(x,\bar{u}_{1},\bar{u}_{2})}\\
\dot{\bar{u}}_{1}&=\bar{u}_{1,1}\\
\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
\dot{\bar{u}}_{1,2}&=\bar{u}_{1,3}\end{aligned}

is static feedback linearizable. By the regularity of (

\displaystyle\begin{aligned} \dot{x}_{1}&=\bar{u}_{2}\\
\dot{x}_{2}&=h(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{3}&=x_{1}+\tfrac{(h(x,\bar{u}_{1},\bar{u}_{2}))^{2}}{2\bar{u}_{2}}\\

\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
\dot{\bar{u}}_{1,2}&=\bar{u}_{1,3}\end{aligned}

\displaystyle\begin{aligned} \dot{x}_{1}&=h(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{2}&=\bar{u}_{2}\\
\dot{x}_{3}&=x_{1}+\tfrac{\bar{u}_{2}^{2}}{2h(x,\bar{u}_{1},\bar{u}_{2})}\\
\dot{\bar{u}}_{1}&=\bar{u}_{1,1}\\
\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
\dot{\bar{u}}_{1,2}&=\bar{u}_{1,3}\,,\end{aligned}

Case 1.
Let us first consider the prolonged system

\displaystyle\begin{aligned} \dot{x}_{1}&=\bar{u}_{2}\\
\dot{x}_{2}&=h(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{3}&=x_{1}+\tfrac{(h(x,\bar{u}_{1},\bar{u}_{2}))^{2}}{2\bar{u}_{2}}\\
\dot{\bar{u}}_{1}&=\bar{u}_{1,1}\\
\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
\dot{\bar{u}}_{1,2}&=\bar{u}_{1,3}\,,\end{aligned}

(13)

where the corresponding input transformation reads as

\displaystyle\begin{aligned} u_{1}&=\bar{u}_{2}\\
u_{2}&=h(x,\bar{u}_{1},\bar{u}_{2})\,.\end{aligned}

(14)

By assumption, the prolonged system (

) is static feedback linearizable. Thus, according to Theorem

, the distributions

\displaystyle\begin{aligned} \mathcal{D}_{p}^{0}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{2}}\}\\
\mathcal{D}_{p}^{1}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{2}},\partial_{x_{1}}\!\!+\!\tfrac{\partial h}{\partial\bar{u}_{2}}\partial_{x_{2}}\!\!+\!\tfrac{2h\tfrac{\partial h}{\partial\bar{u}_{2}}\bar{u}_{2}-h^{2}}{2\bar{u}_{2}^{2}}\partial_{x_{3}}\}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\end{aligned}

are involutive. The latter implies that

h=a(x,\bar{u}_{1})+b(x,\bar{u}_{1})\bar{u}_{2}
. The second condition then yields

\displaystyle\begin{aligned} \tfrac{\partial}{\partial\bar{u}_{2}}\left(\frac{b^{2}\bar{u}_{2}^{2}-a^{2}}{2\bar{u}_{2}^{2}}\right)&=0\end{aligned}

which simplifies to
\tfrac{a^{2}}{\bar{u}_{2}^{3}}=0
and thus
a=0
. The distribution
\mathcal{D}_{p}^{1}
thus simplifies to

\displaystyle\begin{aligned} \mathcal{D}_{p}^{1}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{2}},\partial_{x_{1}}+b\partial_{x_{2}}+\tfrac{b^{2}}{2}\partial_{x_{3}}\}\,,\end{aligned}

and for the next distribution we obtain

\displaystyle\begin{aligned} \mathcal{D}_{p}^{2}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{1,1}},\partial_{\bar{u}_{2}},\partial_{x_{1}}+b\partial_{x_{2}}+\tfrac{b^{2}}{2}\partial_{x_{3}},\\
&\hskip 1.72218pt(x_{1}\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})\partial_{x_{2}}+(x_{1}b\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}b\tfrac{\partial b}{\partial\bar{u}_{1}}-1)\partial_{x_{3}}\}\,,\end{aligned}

which of course must again be involutive. The latter in particular implies that

\displaystyle[\partial_{\bar{u}_{1,1}},(x_{1}\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})\partial_{x_{2}}+

\displaystyle\hskip 50.00008pt(x_{1}b\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}b\tfrac{\partial b}{\partial\bar{u}_{1}}-1)\partial_{x_{3}}]\in\mathcal{D}_{p}^{2}\,,

i.e.,
\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{2}}+b\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{3}}\in\mathcal{D}_{p}^{2}
, which can only hold if the vector field

\displaystyle\begin{aligned} \tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{2}}+b\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{3}}\end{aligned}

is collinear with the vector field

\displaystyle\begin{aligned} (x_{1}\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})\partial_{x_{2}}+(x_{1}b\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}b\tfrac{\partial b}{\partial\bar{u}_{1}}-1)\partial_{x_{3}}\,.\end{aligned}

Therefore, we obtain the condition

\displaystyle\begin{aligned} \tfrac{\partial b}{\partial\bar{u}_{1}}(x_{1}b\tfrac{\partial b}{\partial x_{3}}\!+\!\bar{u}_{1,1}b\tfrac{\partial b}{\partial\bar{u}_{1}}\!-\!1)-b\tfrac{\partial b}{\partial\bar{u}_{1}}(x_{1}\tfrac{\partial b}{\partial x_{3}}\!+\!\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})&=0\,,\end{aligned}

which simplifies to
\tfrac{\partial b}{\partial\bar{u}_{1}}=0
. However,
\tfrac{\partial b}{\partial\bar{u}_{1}}=0
together with
a=0
from above is a contradiction to the regularity of the transformation (
14
), which would then read as

\displaystyle\begin{aligned} u_{1}&=\bar{u}_{2}\\
u_{2}&=b(x)\bar{u}_{2}\,.\end{aligned}

Hence, the required transformation cannot be of the form (
14
).

Case 2.
The second case can be handled analogously. In this case, we have to consider the prolonged system

\displaystyle\begin{aligned} \dot{x}_{1}&=h(x,\bar{u}_{1},\bar{u}_{2})\\
\dot{x}_{2}&=\bar{u}_{2}\\
\dot{x}_{3}&=x_{1}+\tfrac{\bar{u}_{2}^{2}}{2h(x,\bar{u}_{1},\bar{u}_{2})}\\
\dot{\bar{u}}_{1}&=\bar{u}_{1,1}\\
\dot{\bar{u}}_{1,1}&=\bar{u}_{1,2}\\
\dot{\bar{u}}_{1,2}&=\bar{u}_{1,3}\,,\end{aligned}

(15)

and the corresponding input transformation reads as

\displaystyle\begin{aligned} u_{1}&=h(x,\bar{u}_{1},\bar{u}_{2})\\
u_{2}&=\bar{u}_{2}\,.\end{aligned}

(16)

By assumption, the prolonged system (
15
) is static feedback linearizable. Thus, the distributions

\displaystyle\begin{aligned} \mathcal{D}_{p}^{0}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{2}}\}\\
\mathcal{D}_{p}^{1}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{2}},\tfrac{\partial h}{\partial\bar{u}_{2}}\partial_{x_{1}}\!\!+\!\partial_{x_{2}}\!\!+\!\tfrac{2\bar{u}_{2}h-\bar{u}_{2}^{2}\tfrac{\partial h}{\partial\bar{u}_{2}}}{2h^{2}}\partial_{x_{3}}\}\\
&\mathmakebox[\widthof{{}={}}][c]{\vdots}\end{aligned}

are involutive. The involutivity of
\mathcal{D}_{p}^{1}
implies that

\displaystyle\begin{aligned} \tfrac{\partial^{2}h}{\partial\bar{u}_{2}^{2}}&=0&\text{and}&&\tfrac{\partial}{\partial\bar{u}_{2}}(\tfrac{2\bar{u}_{2}h-\bar{u}_{2}^{2}\tfrac{\partial h}{\partial\bar{u}_{2}}}{2h^{2}})&=0\,.\end{aligned}

The first condition implies that
h
is affine with respect to
\bar{u}_{2}
, i.e., we actually have
h=a(x,\bar{u}_{1})+b(x,\bar{u}_{1})\bar{u}_{2}
. The second condition then yields

\displaystyle\begin{aligned} \tfrac{\partial}{\partial\bar{u}_{2}}\left(\frac{2a\bar{u}_{2}+b\bar{u}_{2}^{2}}{2(a+b\bar{u}_{2})^{2}}\right)&=0\,,\end{aligned}

which simplifies to

\displaystyle\begin{aligned} \frac{a^{2}}{(a+b\bar{u}_{2})^{3}}&=0\,.\end{aligned}

Thus, we must have
a=0
. As a consequence, the distribution
\mathcal{D}_{p}^{1}
simplifies to

\displaystyle\begin{aligned} \mathcal{D}_{p}^{1}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{2}},b\partial_{x_{1}}+\partial_{x_{2}}+\tfrac{1}{2b}\partial_{x_{3}}\}\,,\end{aligned}

and for the next distribution we obtain

\displaystyle\begin{aligned} \mathcal{D}_{p}^{2}&=\mathrm{span}\{\partial_{\bar{u}_{1,3}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{1,1}},\partial_{\bar{u}_{2}},\partial_{\bar{u}_{1,2}},\partial_{\bar{u}_{2}},\\
&\hskip 3.99994ptb\partial_{x_{1}}+\partial_{x_{2}}+\tfrac{1}{2b}\partial_{x_{3}},\\
&\hskip 3.99994pt(x_{1}\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})\partial_{x_{1}}-(\tfrac{x_{1}}{2b^{2}}\tfrac{\partial b}{\partial x_{3}}+\tfrac{\bar{u}_{1,1}}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}+b)\partial_{x_{3}}\}\,,\end{aligned}

which must again be involutive. The involutivity implies that

\displaystyle\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{1}}-\tfrac{1}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{3}}

\displaystyle\in\mathcal{D}_{p}^{2}\,,

which can only hold if the vector field

\displaystyle\begin{aligned} \tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{1}}-\tfrac{1}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}\partial_{x_{3}}\end{aligned}

is collinear with the vector field

\displaystyle\begin{aligned} (x_{1}\tfrac{\partial b}{\partial x_{3}}+\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})\partial_{x_{1}}-(\tfrac{x_{1}}{2b^{2}}\tfrac{\partial b}{\partial x_{3}}+\tfrac{\bar{u}_{1,1}}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}+b)\partial_{x_{3}}\,.\end{aligned}

Therefore, we obtain the condition

\displaystyle\tfrac{\partial b}{\partial\bar{u}_{1}}(\tfrac{x_{1}}{2b^{2}}\tfrac{\partial b}{\partial x_{3}}\!+\!\tfrac{\bar{u}_{1,1}}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}\!+\!b)-\tfrac{1}{2b^{2}}\tfrac{\partial b}{\partial\bar{u}_{1}}(x_{1}\tfrac{\partial b}{\partial x_{3}}\!+\!\bar{u}_{1,1}\tfrac{\partial b}{\partial\bar{u}_{1}})

\displaystyle=0

which simplifies to
\tfrac{\partial b}{\partial\bar{u}_{1}}b=0
. Thus, either
\tfrac{\partial b}{\partial\bar{u}_{1}}=0
or
b=0
. Since we already have
a=0
,
b=0
would imply
h=0
, and hence the transformation would not be invertible. However, the other possibility, i.e.,
\tfrac{\partial b}{\partial\bar{u}_{1}}=0
, is in combination with
a=0
also a contradiction to the regularity of the transformation (
16
), which would then read as

\displaystyle\begin{aligned} u_{1}&=b(x)\bar{u}_{2}\\
u_{2}&=\bar{u}_{2}\,.\end{aligned}

In conclusion, there cannot exist an invertible input transformation (
11
) which generates an input such that a three-fold prolongation of this input renders the system (
3
) static feedback linearizable. The system is thus not linearizable by a three-fold prolongation, and as a consequence of Proposition
4
the system (
3
) cannot be
(x,u)
-flat.
\square

IV
CONCLUSIONS

We have proven that there exist systems which are flat but do not admit any
(x,u)
-flat output. It thus seems reasonable to conjecture that there also exist systems which are flat but do not admit any
(x,u,\dot{u})
-flat output, and so on. Further research will be devoted to proving this conjecture.
