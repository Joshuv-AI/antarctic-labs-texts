Exponential stabilization on infinite dimensional system with impulse controls Thanks: This work was supported by the National Natural Science Foundation of China under grant 11701138, 11601137 and the Natural Science Foundation of Hebei Province, China under grant A2020202033.
Qishu Yan, Huaiqiang Yu

Abstract
This paper studies the exponential stabilization on infinite dimensional system with impulse controls, where impulse instants appear periodically. The first main result shows that exponential stabilizability of the control system with a periodic feedback law is equivalent to one kind of weak observability inequalities. The second main result presents that, in the setting of a discrete LQ problem, the exponential stabilizability of control system with a periodic feedback law is equivalent to the solvability of an algebraic Riccati-type equation which was built up in [Qin, Wang and Yu, SIAM J. Control Optim., 59 (2021), pp. 1136-1160] for finite dimensional system. As an application, some sufficient and necessary condition for the exponential stabilization of an impulse controlled system governed by coupled heat equations is given.



Keywords.

Exponential stabilization, Infinite dimensional system, Impulse control, Periodic feedback

\end{cases}

Definition 1.1

The system

is called exponentially

\begin{cases}\displaystyle x^{\prime}(t)=Ax(t),&t\in\mathbb{R}^{+}\backslash\Lambda_{\hbar},\\

\end{cases}

(1.3)

i.e., there are constants

so that any solution of (

,
satisfies that

\|x_{\mathcal{F}}(t)\|_{H}\leq C\mathrm{e}^{-\mu t}\|x_{\mathcal{F}}(0)\|_{H}\;\;\mbox{for any}\;\;t\in\mathbb{R}^{+}.

If the system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]

is exponentially

Aim.
In this paper, we shall mainly present some equivalence criteria for the exponential stabilization of the system

1.3
Main results

The first main result can be stated as follows.

Theorem 1.2
.

Given
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
. The following statements are equivalent:

(i)

The system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.

(ii)

For each
\sigma\in(0,1)
, there are
k=k(\sigma)\in\mathbb{N}^{+}
and

C(\sigma)>0
so that

\|e^{A^{*}t_{k}}\varphi\|_{H}\leq C(\sigma)\left(\sum_{j=1}^{k}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k}-t_{j})}\varphi\|_{U}^{2}\right)^{\frac{1}{2}}+\sigma\|\varphi\|_{H}\;\;\mbox{for any}\;\;\varphi\in H.

(1.4)

(iii)

There are
\sigma\in(0,1)
,
k\in\mathbb{N}^{+}
and
C>0
so that

\|\mathrm{e}^{A^{*}t_{k\hbar}}\varphi\|_{H}\leq C\left(\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{k\hbar}-t_{j})}\varphi\|_{U}^{2}\right)^{\frac{1}{2}}+\sigma\|\varphi\|_{H}\;\;\mbox{for any}\;\;\varphi\in H.

(1.5)

(iv)

There are
\sigma\in(0,1)
,
k\in\mathbb{N}^{+}
and
C>0
so that, for any
x_{0}\in H
, there is a control
u\in l^{2}(\mathbb{N}^{+};U)
so that

\|x(t_{k\hbar};x_{0},u)\|_{H}\leq\sigma\|x_{0}\|_{H}\;\;\mbox{and}\;\;\|u\|_{l^{2}(\mathbb{N}^{+};U)}\leq C\|x_{0}\|_{H}.

(1.6)

Remark 1.3
.

It is well known that, on
[0,t_{k}]

(k\in\mathbb{N}^{+})
, the dual-observe system of
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
is given by

\begin{cases}y^{\prime}(t)+A^{*}y(t)=0,&t\in[0,t_{k}],\\
y(t_{k})=\varphi\in H,\\
z(t_{j})=B^{*}_{\nu(j)}y(t_{j}),&j\in\{1,2,\ldots,k\}.\end{cases}

We denote this observe system by
[A^{*},\mathcal{B}^{*}_{\hbar},\Lambda_{\hbar}]
.
From the viewpoint of observability, the inequality (
1.4
) is called a weak observability of
[A^{*},\mathcal{B}^{*}_{\hbar},\Lambda_{\hbar}]
on
[0,t_{k}]
.
It should be noted that, in
infinite dimensional setting, the strong observability inequality (i.e.,
\sigma=0
in (
1.4
)),
which means the corresponding control system is null controllable, does not hold generally (see, for instance,
[
17
]
).

The proof of Theorem
1.2
is based on the study of a discrete LQ problem associated with the system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
.
We now introduce this problem and present another equivalence criterion for the exponential stabilization of the system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
.

We arbitrarily fix
\Lambda_{\hbar}=\{t_{j}\}_{j\in\mathbb{N}}\in\mathcal{J}_{\hbar}
,

(Q_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(H)
and
(R_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(U)
.
For each
x_{0}\in H
, define the admissible control set:

\mathcal{U}_{ad}(x_{0}):=\{u=(u_{j})_{j\in\mathbb{N}^{+}}\in l^{2}(\mathbb{N}^{+};U):\,\left(x(t_{j};x_{0},u)\right)_{j\in\mathbb{N}^{+}}\in l^{2}(\mathbb{N}^{+};H)\}

(1.7)

and the cost functional:

\begin{split}J(u;x_{0}):=\sum_{j=1}^{+\infty}\left(\langle Q_{j}x(t_{j};x_{0},u),x(t_{j};x_{0},u)\rangle_{H}+\langle R_{j}u_{j},u_{j}\rangle_{U}\right)\textrm{ for any }u=(u_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{U}_{ad}(x_{0}).\end{split}

(1.8)

Consider the following optimal control problem:

(I-I-LQ)
: Given
x_{0}\in H
. Find a control
u^{*}=(u_{j}^{*})_{j\in\mathbb{N}^{+}}\in\mathcal{U}_{ad}(x_{0})
so that

J(u^{*};x_{0})=\inf_{u\in\mathcal{U}_{ad}(x_{0})}J(u;x_{0}).

The problem
(I-I-LQ)
is a kind of discrete LQ problems associated with the system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
.
For solving it, we first introduce the following operator-valued algebraic equation:

\begin{cases}P_{k-1}-\mathrm{e}^{A^{*}(t_{k}-t_{k-1})}P_{k}\mathrm{e}^{A(t_{k}-t_{k-1})}=\mathrm{e}^{A^{*}(t_{k}-t_{k-1})}Q_{k}\mathrm{e}^{A(t_{k}-t_{k-1})}\\
\qquad\qquad-\mathrm{e}^{A^{*}(t_{k}-t_{k-1})}P_{k}B_{k}(R_{k}+B_{k}^{*}P_{k}B_{k})^{-1}B^{*}_{k}P_{k}\mathrm{e}^{A(t_{k}-t_{k-1})},&k\in\{1,2,\ldots,\hbar\},\\
P_{0}=P_{\hbar}.\end{cases}

(1.9)

We call (
1.9
) a Riccati-type equation, in which unknowns
P_{k}
(
k=1,\ldots,\hbar
) are in
\mathcal{SL}_{+}(H)
. The solution to (
1.9
), if exists, is denoted by
\{P_{k}\}_{k=0}^{\hbar}
.

The second main result of this paper is given as follows.

Theorem 1.4
.

Given
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
. The following statements are equivalent:

(i)

The system
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.

(ii)

For each
x_{0}\in H
, the set
\mathcal{U}_{ad}(x_{0})
is not empty.

(iii)

For any
(Q_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(H)
and
(R_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(U)
, the
Riccati-type equation (
1.9
) has a unique solution.

(iv)

There are
(Q_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(H)
and
(R_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(H)
so that the
Riccati-type equation (
1.9
) has a unique solution.

Moreover, when the system (
1.9
) is exponentially
\hbar
-stabilizable, the feedback law
\mathcal{F}=\{F_{k}\}_{k=1}^{\hbar}

can be chosen as

F_{k}:=-(R_{k}+B_{k}^{*}P_{k}B_{k})^{-1}B_{k}^{*}P_{k}\textrm{ for each }k=1,...,\hbar,

where
\{P_{k}\}_{k=0}^{\hbar}
is the solution of (
1.9
) with arbitrarily fixed
(Q_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(H)
and

(R_{j})_{j\in\mathbb{N}^{+}}\in\mathcal{M}_{\hbar,\gg}(U)
.

1.4
Novelties of this paper

•

As an important control system, there is very little literature considering
the stabilization problem with impulse controls in infinite dimensional setting.
In essence, the controllers in the impulse control system are time-varying. Thus, the classic strategies (for instance, frequency domain method) do not work.
Indeed, Theorem
1.2
can be regarded as a time domain method (for the time domain method in continous control system, one can refer to
[
22
,
14
]
).

•

It seems for us that the equivalence characterization on the exponential stabilization for impulse control systems in infinite dimensional setting has not been touched upon (at least, we do not find any such literature). Thus, the equivalence results in Theorem
1.2
and Theorem
1.4
are new.

•

In infinite dimensional setting, the discrete LQ problem used in our paper seems new for us. Although many literatures used LQ problem to consider the stabilizability of infinite dimensional systems (for instance,
[
7
,
11
]
), but our LQ problem is discrete. It is completely different from continuous time horizon LQ problems.

Plan of this paper

The rest of this paper is organized as follows: In section 2, we present some preliminaries. In section 3, we give the proof of our main results. In Section 4, we apply our main results to the system of heat equations coupled by constant matrices with impulse controls.

\displaystyle J(v;x_{0},\widehat{k}-1,\widehat{k})

\displaystyle\geq

\displaystyle-\langle(R_{\widehat{k}}+B_{\nu(\widehat{k})}^{*}MB_{\nu(\widehat{k})})^{-1}B_{\nu(\widehat{k})}^{*}M\mathrm{e}^{A(t_{\widehat{k}}-t_{\widehat{k}-1})}x_{0},B_{\nu(\widehat{k})}^{*}M\mathrm{e}^{A(t_{\widehat{k}}-t_{\widehat{k}-1})}x_{0}\rangle_{U}

C_{4}:=C_{3}\left(\frac{1}{2\mu}\max_{1\leq k\leq\hbar}\frac{1}{|t_{k}-t_{k-1}|}\right)^{\frac{1}{2}}
. Moreover, one can easily check that

x(t_{k}^{+};x_{0},u(x_{0}))=x_{\mathcal{F}}(t_{k}^{+};x_{0})\;\;\mbox{for each}\;\;k\in\mathbb{N}^{+}.

This, together with (
3.25
) and (
3.26
), implies that

\|x(t_{\widehat{k}}^{+};x_{0},u(x_{0}))\|_{H}\leq\sigma\|x_{0}\|_{H}.

(3.29)

Furthermore, it is obvious that

x(t_{\widehat{k}}^{+};x_{0},u(x_{0}))=\mathrm{e}^{At_{\widehat{k}}}x_{0}+\sum_{j=1}^{\widehat{k}}\mathrm{e}^{A(t_{\widehat{k}}-t_{j})}B_{\nu(j)}u_{j}(x_{0}).

Hence,

\langle x(t^{+}_{\widehat{k}};x_{0},u(x_{0})),\varphi\rangle_{H}=\langle x_{0},\mathrm{e}^{A^{*}t_{\widehat{k}}}\varphi\rangle_{H}+\sum_{j=1}^{\widehat{k}}\langle u_{j}(x_{0}),B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{\widehat{k}}-t_{j})}\varphi\rangle_{U}\;\;\mbox{for any}\;\;\varphi\in H.

This, along with (
3.28
) and (
3.29
), yields that

\langle x_{0},\mathrm{e}^{A^{*}t_{\widehat{k}}}\varphi\rangle_{H}\leq\sigma\|x_{0}\|_{H}\|\varphi\|_{H}+C_{4}\|x_{0}\|_{H}\left(\sum_{j=1}^{\widehat{k}}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{\widehat{k}}-t_{j})}\varphi\|_{H}^{2}\right)^{\frac{1}{2}}\;\;\mbox{for any}\;\;\varphi\in H.

This, together with the arbitrariness of
x_{0}\in H
, implies (
1.4
) with
C(\sigma):=C_{4}
. Therefore, the claim
(ii)
is true.

Step 2. The proof of
(ii)\Rightarrow(iii)
.

Suppose that the claim
(ii)
is true.
We take
\widehat{\sigma}\in(0,\min\{1,(\max_{0\leq\ell\leq\hbar-1}\|e^{A^{*}(t_{\hbar}-t_{\ell})}\|_{\mathcal{L}(H)})^{-1}\})
arbitrarily.
By the claim
(ii)
, there are
\widehat{k}=\widehat{k}(\widehat{\sigma})\in\mathbb{N}^{+}
and
C(\widehat{\sigma})>0

so that (
1.4
) holds with
\sigma=\widehat{\sigma}
and
C(\sigma)=C(\widehat{\sigma})
.
We take
k^{*}\in\mathbb{N}^{+}
so that
(k^{*}-1)\hbar\leq\widehat{k}<k^{*}\hbar
.
Thus, by (
1.4
), we have

\displaystyle\|\mathrm{e}^{A^{*}t_{k^{*}\hbar}}\varphi\|_{H}

\displaystyle\leq

\displaystyle C(\widehat{\sigma})\left(\sum_{j=1}^{\widehat{k}}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{k^{*}\hbar}-t_{j})}\varphi\|_{U}^{2}\right)^{\frac{1}{2}}+\widehat{\sigma}\|\mathrm{e}^{A^{*}(t_{k^{*}\hbar}-t_{\widehat{k}})}\varphi\|_{H}

\displaystyle\leq

\displaystyle C(\widehat{\sigma})\left(\sum_{j=1}^{k^{*}\hbar-1}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{k^{*}\hbar}-t_{j})}\varphi\|_{U}^{2}\right)^{\frac{1}{2}}+\widehat{\sigma}\max_{0\leq\ell\leq\hbar-1}\|\mathrm{e}^{A^{*}(t_{\hbar}-t_{\ell})}\|_{\mathcal{L}(H)}\|\varphi\|_{H}

\displaystyle\leq

\displaystyle C(\widehat{\sigma})\left(\sum_{j=1}^{k^{*}\hbar-1}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{k^{*}\hbar}-t_{j})}\varphi\|_{U}^{2}\right)^{\frac{1}{2}}+\sigma\|\varphi\|_{H},

where
\sigma:=\widehat{\sigma}\max_{0\leq l\leq\hbar-1}\|\mathrm{e}^{A^{*}(t_{\hbar}-t_{\ell})}\|_{\mathcal{L}(H)}
. It is clear that

\sigma\in(0,1)
. Thus, the claim
(iii)
is true with
k=k^{*}
and
C=C(\widehat{\sigma})
.

Step 3. The proof of
(iii)\Rightarrow(iv)
.

Assume that
(iii)
holds. We take
\sigma\in(0,1)
,
k\in\mathbb{N}^{+}
and
C>0
so that (
1.5
) holds. Now, we prove
(iv)
is true. We take

x_{0}\in H
arbitrarily and, for each
\varepsilon>0
, introduce a functional
\mathcal{J}_{\varepsilon}:H\to\mathbb{R}
as follows:

\mathcal{J}_{\varepsilon}(\varphi):=\frac{1}{2}\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\varphi\|_{U}^{2}+\langle\varphi,e^{A^{*}t_{k\hbar}}x_{0}\rangle_{H}+(\sigma\|x_{0}\|_{H}+\varepsilon)\|\varphi\|_{H}\textrm{ \,\,for each }\varphi\in H.

First, we show that
\mathcal{J}_{\varepsilon}
is coercive. For this purpose, given any sequence
\{\varphi_{n}\}_{n\in\mathbb{N}^{+}}\subset H\setminus\{0\}
with
\|\varphi_{n}\|_{H}\to+\infty
as
n\to+\infty
, we only need to prove that

\liminf_{n\to+\infty}\frac{\mathcal{J}_{\varepsilon}(\varphi_{n})}{\|\varphi_{n}\|_{H}}\geq\varepsilon.

(3.30)

Indeed, let
\widehat{\varphi}_{n}:=\varphi_{n}/\|\varphi_{n}\|_{H}
. Then we have

\frac{\mathcal{J}_{\varepsilon}(\varphi_{n})}{\|\varphi_{n}\|_{H}}=\frac{1}{2}\|\varphi_{n}\|_{H}\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\widehat{\varphi}_{n}\|_{U}^{2}+\langle\widehat{\varphi}_{n},e^{A^{*}t_{k\hbar}}x_{0}\rangle_{H}+\sigma\|x_{0}\|_{H}+\varepsilon

(3.31)

for each
n\in\mathbb{N}^{+}
. There are only two cases may happen.

Case 1.

\liminf_{n\to+\infty}\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\widehat{\varphi}_{n}\|_{U}^{2}>0
. In this case, by (
3.31
), it is clear that

\liminf_{n\to+\infty}\frac{\mathcal{J}_{\varepsilon}(\varphi_{n})}{\|\varphi_{n}\|_{H}}=+\infty.

Thus, (
3.30
) is true.

Case 2.

\liminf_{n\to+\infty}\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\widehat{\varphi}_{n}\|_{U}^{2}=0
. Since
\|\widehat{\varphi}_{n}\|_{H}=1
for each
n\in\mathbb{N}^{+}
, there is a subsequence of
\{\widehat{\varphi}_{n}\}_{n\in\mathbb{N}^{+}}
, still denoted by the same way, and
\widehat{\varphi}
so that

\widehat{\varphi}_{n}\to\widehat{\varphi}\;\;\mbox{weakly in}\;\;H\;\;\mbox{as}\;\;n\to+\infty.

(3.32)

It is obvious that
\|\widehat{\varphi}\|_{H}\leq 1
. This, together with
the assumption that
\liminf_{n\to+\infty}\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\widehat{\varphi}_{n}\|_{U}^{2}=0
, yields that

\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\widehat{\varphi}\|_{U}^{2}=0.

Hence, by (
1.5
), we have

0\leq(-\|e^{A^{*}t_{k\hbar}}\widehat{\varphi}\|_{H}+\sigma\|\widehat{\varphi}\|_{H})\|x_{0}\|_{H}\leq\langle\widehat{\varphi},e^{At_{k\hbar}}x_{0}\rangle_{H}+\sigma\|\widehat{\varphi}\|_{H}\|x_{0}\|_{H}.

This, along with (
3.31
) and (
3.32
), gives that (
3.30
) holds in this case.

In summary, we have proved that

\mathcal{J}_{\varepsilon}
is coercive for any
\varepsilon>0
. It is obvious that
\mathcal{J}_{\varepsilon}
is continuous and convex.
Thus, for each
\varepsilon>0
,
\mathcal{J}_{\varepsilon}
has a minimizer
\varphi^{*}_{\varepsilon}\in H
. Therefore,
after some simple calculations, we have that for any
\xi\in H
,

\displaystyle 0\leq\lim_{\lambda\to 0^{+}}\frac{\mathcal{J}_{\varepsilon}(\varphi^{*}_{\varepsilon}+\lambda\xi)-\mathcal{J}_{\varepsilon}(\varphi^{*}_{\varepsilon})}{\lambda}

\displaystyle=

\displaystyle\langle e^{At_{k\hbar}}x_{0},\xi\rangle_{H}+\sum_{j=1}^{k\hbar-1}\left\langle B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\varphi^{*}_{\varepsilon},B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\xi\right\rangle_{U}

(3.33)

\displaystyle+\begin{cases}(\sigma\|x_{0}\|_{H}+\varepsilon)\left\langle\frac{\varphi^{*}_{\varepsilon}}{\|\varphi^{*}_{\varepsilon}\|_{H}},\xi\right\rangle_{H}&\mbox{if}\;\;\varphi^{*}_{\varepsilon}\neq 0,\\
(\sigma\|x_{0}\|_{H}+\varepsilon)\|\xi\|_{H}&\mbox{if}\;\;\varphi^{*}_{\varepsilon}=0.\end{cases}

Let
u^{*}_{\varepsilon}:=(B^{*}e^{A^{*}(t_{k\hbar}-t_{1})}\varphi^{*}_{\varepsilon},B^{*}e^{A^{*}(t_{k\hbar}-t_{2})}\varphi^{*}_{\varepsilon},\cdots,B^{*}e^{A^{*}(t_{k\hbar}-t_{k\hbar-1})}\varphi^{*}_{\varepsilon},0,\cdots)
. One can easily check that

\langle x(t_{k\hbar};x_{0},u^{*}_{\varepsilon}),\xi\rangle_{H}=\langle e^{At_{k\hbar}}x_{0},\xi\rangle_{H}+\sum_{j=1}^{k\hbar-1}\left\langle B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\varphi^{*}_{\varepsilon},B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\xi\right\rangle_{U}

(3.34)

for any
\xi\in H
. This, together with (
3.33
), yields that

|\langle x(t_{k\hbar};x_{0},u^{*}_{\varepsilon}),\xi\rangle_{H}|\leq(\sigma\|x_{0}\|_{H}+\varepsilon)\|\xi\|_{H}\;\;\mbox{for any}\;\;\xi\in H,

which implies that

\|x(t_{k\hbar};x_{0},u^{*}_{\varepsilon})\|_{H}\leq\sigma\|x_{0}\|_{H}+\varepsilon.

(3.35)

Moreover, by the definition of
u^{*}_{\varepsilon}
, it is obvious that

\|u^{*}_{\varepsilon}\|_{l^{2}(\mathbb{N}^{+};U)}^{2}=\sum_{j=1}^{k\hbar-1}\|B^{*}_{\nu(j)}e^{A^{*}(t_{k\hbar}-t_{j})}\varphi^{*}_{\varepsilon}\|_{U}^{2}.

(3.36)

Thus, by (
1.5
), we have

-C\|u_{\varepsilon}^{*}\|_{l^{2}(\mathbb{N}^{+};U)}\|x_{0}\|_{H}\leq(\sigma\|\varphi^{*}_{\varepsilon}\|_{H}-\|e^{A^{*}t_{k\hbar}}\varphi_{\varepsilon}^{*}\|_{H})\|x_{0}\|_{H}\leq\sigma\|\varphi^{*}_{\varepsilon}\|_{H}\|x_{0}\|_{H}+\langle\varphi_{\varepsilon}^{*},e^{At_{k\hbar}}x_{0}\rangle_{H}.

This, together with (
3.36
) and the facts that
\varepsilon>0
and
\mathcal{J}_{\varepsilon}(\varphi^{*}_{\varepsilon})\leq\mathcal{J}_{\varepsilon}(0)=0
, implies that

\|u^{*}_{\varepsilon}\|^{2}_{l^{2}(\mathbb{N}^{+};U)}-2C\|u^{*}_{\varepsilon}\|_{l^{2}(\mathbb{N}^{+};U)}\|x_{0}\|_{H}\leq 0.

Hence, by the arbitrariness of
\varepsilon>0
, we get

\|u^{*}_{\varepsilon}\|_{l^{2}(\mathbb{N}^{+};U)}\leq 2C\|x_{0}\|_{H}\;\;\mbox{for any}\;\;\varepsilon>0.

(3.37)

It follows that, there is a sequence
\{\varepsilon_{n}\}_{n\in\mathbb{N}^{+}}\subset(0,+\infty)
with
\varepsilon_{n}\to 0
as
n\to+\infty
, and
u^{*}\in l^{2}(\mathbb{N}^{+};U)

so that

u^{*}_{\varepsilon_{n}}\to u^{*}\;\;\mbox{weakly in}\;\;l^{2}(\mathbb{N}^{+};U)\;\;\mbox{as}\;\;n\to+\infty.

(3.38)

By (
3.37
), it is clear that

\|u^{*}\|_{l^{2}(\mathbb{N}^{+};U)}\leq 2C\|x_{0}\|_{H}.

(3.39)

Moreover, by (
3.38
), one can easily check that

x(t_{k\hbar};x_{0},u^{*}_{\varepsilon_{n}})\to x(t_{k\hbar};x_{0},u^{*})\;\;\mbox{weakly in}\;\;H\;\;\mbox{as}\;\;n\to+\infty.

This, along with (
3.35
), yields that

\|x(t_{k\hbar};x_{0},u^{*})\|_{H}\leq\sigma\|x_{0}\|_{H}.

(3.40)

Therefore, by (
3.39
) and (
3.40
), we conclude that (
1.6
) is true with
u=u^{*}
. Thus
(iv)
holds.

Step 4. The proof of
(iv)\Rightarrow(i)
.

To this end, by Theorem
1.4
, we only need to show

\mathcal{U}_{ad}(x_{0})\neq\emptyset\;\;\mbox{for any}\;\;x_{0}\in H,

(3.41)

where
\mathcal{U}_{ad}(\cdot)
is defined by (
1.7
). Let
\sigma\in(0,1)
,
k\in\mathbb{N}^{+}
and
C>0
be such that the claim
(iv)
holds.

Let
x_{0}\in H
be arbitrarily fixed. Write
U^{k\hbar}:=\underbrace{U\times U\times\cdots\times U}_{k\hbar}
.
It is clear that, for any
w=(w_{1},\cdots,w_{k\hbar})\in U^{k\hbar}
,

x(t_{j};x_{0},w)=\mathrm{e}^{A(t_{j}-t_{j-1})}x(t_{j-1};x_{0},w)+\mathrm{e}^{A(t_{j}-t_{j-1})}B_{j-1}w_{j-1}\;\;\mbox{for each}\;\;j\in\{1,2,\ldots,k\hbar\}.

Here and in what follows we agree that
B_{0}=0
and
w_{0}=0
. It follows that

\|x(t_{j};x_{0},w)\|_{H}^{2}\leq C_{A}\|x(t_{j-1};x_{0},w)\|_{H}^{2}+C_{A,\mathcal{B}_{\hbar}}\|w_{j-1}\|_{U}^{2}\;\;\mbox{for each}\;\;j\in\{1,2,\ldots,k\hbar\},

where

C_{A}:=\max\left\{1,2\max_{1\leq l\leq\hbar}\|\mathrm{e}^{A(t_{l}-t_{l-1})}\|_{\mathcal{L}(H)}^{2}\right\}\textrm{ and }C_{A,\mathcal{B}_{\hbar}}:=2\max_{1\leq l\leq\hbar}\left(\|\mathrm{e}^{A(t_{l}-t_{l-1})}\|_{\mathcal{L}(H)}^{2}\|B_{\ell}\|_{\mathcal{L}(U;H)}^{2}\right).

Therefore, for each
j\in\{1,2,\ldots,k\hbar\}
,

\displaystyle\|x(t_{j};x_{0},w)\|_{H}^{2}

\displaystyle\leq

\displaystyle C_{A}^{j}\|x_{0}\|^{2}+C_{A,\mathcal{B}_{\hbar}}\left(\sum_{\ell=1}^{j-1}C_{A}^{j-1-\ell}\|w_{\ell}\|_{U}^{2}\right)

(3.42)

\displaystyle\leq

\displaystyle C_{A}^{k\hbar}\|x_{0}\|^{2}+C_{A,\mathcal{B}_{\hbar}}C_{A}^{k\hbar-1}\left(\sum_{\ell=1}^{k\hbar-1}\|w_{\ell}\|_{U}^{2}\right).

(Here, we used the fact
C_{A}\geq 1
.)

By the claim
(iv)
, there is a control
u=(u_{j})_{j\in\mathbb{N}}\in l^{2}(\mathbb{N}^{+};U)
so that (
1.6
) is true.
Define
v^{1}:=(v_{1}^{1},v_{2}^{1},...,v_{k\hbar}^{1})\in U^{k\hbar}
by

v^{1}_{j}=u_{j}\;\;\mbox{for each}\;\;j\in\{1,2,\ldots,k\hbar-1\}\textrm{ and }v^{1}_{k\hbar}=0.

This, together with (
1.6
), yields that

\|x(t_{k\hbar}^{+};x_{0},v^{1})\|_{H}=\|x(t_{k\hbar};x_{0},v^{1})\|_{H}=\|x(t_{k\hbar};x_{0},u)\|_{H}\leq\sigma\|x_{0}\|_{H}

(3.43)

and

\|v^{1}\|_{U^{k\hbar}}\leq\|u\|_{l^{2}(\mathbb{N}^{+};U)}\leq C\|x_{0}\|_{H}.

(3.44)

By (
3.44
) and (
3.42
), it is obvious that

\sum_{j=1}^{k\hbar}\|x(t_{j};x_{0},v^{1})\|_{H}^{2}\leq C_{A,\mathcal{B}_{\hbar},k}\|x_{0}\|^{2}_{H},

where
C_{A,\mathcal{B}_{\hbar},k}:=k\hbar\left(C_{A}^{k\hbar}+C^{2}C_{A,\mathcal{B}_{\hbar}}C_{A}^{k\hbar-1}\right)
.

Replacing
x_{0}
by
x(t^{+}_{k\hbar};x_{0},v^{1})
in the above arguments, we can show that
there exists
v^{2}:=(v_{1}^{2},v_{2}^{2},\cdots,v_{k\hbar}^{2})\in U^{k\hbar}
so that

\|v^{2}\|_{U^{k\hbar}}\leq C\|x(t^{+}_{k\hbar};x_{0},v^{1})\|_{H}

and

\sum_{j=1}^{k\hbar}\|x(t_{j};x(t_{k\hbar}^{+};x_{0},v^{1}),v^{2})\|^{2}_{H}\leq C_{A,\mathcal{B}_{\hbar},k}\|x(t^{+}_{k\hbar};x_{0},v^{1})\|_{H}^{2}.

These, along with (
3.43
), imply that

\|v^{2}\|_{U^{k\hbar}}\leq C\sigma\|x_{0}\|_{H}

and

\sum_{j=1}^{k\hbar}\|x(t_{j};x(t_{k\hbar}^{+};x_{0},v^{1}),v^{2})\|_{H}\leq C_{A,\mathcal{B}_{\hbar},k}\sigma^{2}\|x_{0}\|^{2}_{H}.

By the same way, we can deduce that, for each
l\in\mathbb{N}^{+}
with
l\geq 2
, there is

v^{l}:=(v_{1}^{l},v_{2}^{l},\cdots,v_{k\hbar}^{l})\in U^{k\hbar}
so that

\|v^{l}\|_{U^{k\hbar}}\leq C\sigma^{l-1}\|x_{0}\|_{H}

(3.45)

and

\sum_{j=1}^{k\hbar}\|x(t_{j};x_{l-1}(t_{k\hbar}^{+}),v^{l})\|^{2}_{H}\leq C_{A,\mathcal{B}_{\hbar},k}\sigma^{2(l-1)}\|x_{0}\|^{2},

(3.46)

where

\begin{cases}x_{1}(t_{k\hbar}^{+}):=x(t_{k\hbar}^{+};x_{0},v^{1}),\\
x_{l}(t_{k\hbar}^{+})=x(t_{k\hbar}^{+};x_{l-1}(t_{k\hbar}^{+}),v^{l})\;\;\mbox{for each}\;\;l\geq 2.\end{cases}

(3.47)

Define

v:=(v_{1}^{1},v_{2}^{1},\cdots,v_{k\hbar}^{1},v_{1}^{2},v_{2}^{2},\cdots,v_{k\hbar}^{2},\cdots).

Since
\sigma\in(0,1)
, by (
3.44
) and (
3.45
), we obtain

\|v\|^{2}_{l^{2}(\mathbb{N}^{+};U)}\leq\sum_{l=1}^{\infty}\|v^{l}\|_{U^{k\hbar}}^{2}\leq C^{2}\left(\sum_{l=1}^{+\infty}\sigma^{2(l-1)}\right)\|x_{0}\|_{H}^{2}<+\infty.

(3.48)

Moreover, by (
3.47
), for any
l\in\mathbb{N}^{+}
, one can easily check that

x(t_{j};x_{0},v)=x(t_{j};x_{l-1}(t_{k\hbar}^{+}),v^{l})\;\;\mbox{for each}\;\;j\in\{(l-1)\hbar+1,\ldots,l\hbar\}.

This, together with (
3.46
), yields that

\sum_{j=1}^{+\infty}\|x(t_{j};x_{0},v)\|_{H}^{2}\leq\sum_{l=1}^{+\infty}\sum_{j=1}^{k\hbar}\|x(t_{j};x_{l-1}(t_{k\hbar}^{+}),v^{l})\|_{H}^{2}\leq C_{A,\mathcal{B}_{\hbar},k}\left(\sum_{l=1}^{\infty}\sigma^{2(l-1)}\right)\|x_{0}\|_{H}^{2}<+\infty.

(3.49)

Thus, by (
3.48
) and (
3.49
), we conclude that

v\in l^{2}(\mathbb{N}^{+};U)
and
(x(t_{j};x_{0},v))_{j\in\mathbb{N}^{+}}\in l^{2}(\mathbb{N}^{+};H)
,
i.e.,
v\in\mathcal{U}_{ad}(x_{0})
. This, along with the arbitrariness of
x_{0}
, implies that (
3.41
) is true. Hence, the claim
(i)
is true.

In summary, we complete our proof.

4
Application to the coupled heat system with impulse controls

In this section, we consider the system of heat equations coupled by constant matrices, which is a special case of (
1.2
).
Let

\Omega\subset\mathbb{R}^{N}(N\in\mathbb{N}^{+})
be a bounded domain with a
smooth boundary
\partial\Omega
.
Let
\omega_{k}\subset\Omega

(1\leq k\leq\hbar)
be an open and nonempty subset of
\Omega

with
\omega:=\displaystyle{\cap_{k=1}^{\hbar}}\omega_{k}\not=\emptyset
.
Denote by
\chi_{E}
the characteristic function of the set
E\subset\mathbb{R}^{N}
.
Write
\triangle_{n}:=I_{n}\triangle=\mbox{diag}(\underbrace{\triangle,\triangle,\cdots,\triangle}_{n})
, where

I_{n}
is the identity matrix in
\mathbb{R}^{n\times n}
and

\triangle
is the Laplace operator with domain
D(\triangle):=H_{0}^{1}(\Omega)\cap H^{2}(\Omega)
.
In this section, we consider the system (
1.2
) with

A:=\triangle_{n}+S,\;\;D(A):=(H_{0}^{1}(\Omega)\cap H^{2}(\Omega))^{n}\textrm{ and }B_{k}:=\chi_{\omega_{k}}D_{k}\textrm{ for each }1\leq k\leq\hbar,

where
S\in\mathbb{R}^{n\times n}
and
\{D_{k}\}_{k=1}^{\hbar}\subset\mathbb{R}^{n\times m}\,(n,m\in\mathbb{N}^{+})
.
We let
\mathcal{D}:=(D_{1},D_{2},\cdots,D_{\hbar})
. It is obvious that if we let
H:=(L^{2}(\Omega))^{n}

and
U:=(L^{2}(\Omega))^{m}
, then
H=H^{*}
and
U=U^{*}
. Moreover,

(A,D(A))
generates a
C_{0}
-semigroup
\{\mathrm{e}^{At}\}_{t\in\mathbb{R}^{+}}

over
(L^{2}(\Omega))^{n}
.
For simplicity, we denote the system

\begin{cases}x_{t}-\triangle_{n}x-Sx=0,&\textrm{ in }\Omega\times(\mathbb{R}^{+}\backslash\Lambda_{\hbar}),\\
x=0,&\textrm{ on }\partial\Omega\times\mathbb{R}^{+},\\
x(t_{j}^{+})=x(t_{j})+\chi_{\omega_{\nu(j)}}D_{\nu(j)}u_{j},&\textrm{ in }\Omega,\,j\in\mathbb{N}^{+}\end{cases}

(4.1)

by
[S,\{\chi_{\omega_{k}}D_{k}\}_{k=1}^{\hbar},\Lambda_{\hbar}]
instead of
[A,\mathcal{B}_{\hbar},\Lambda_{\hbar}]
in this section,
where
\Lambda_{\hbar}:=\{t_{j}\}_{j\in\mathbb{N}}\in\mathcal{J}_{\hbar}
.
We will prove the following stabilization results for the system (
4.1
), which is an application of Theorem
1.2
.

Theorem 4.1
.

Given
S\in\mathbb{R}^{n\times n}
and
\{D_{k}\}_{k=1}^{\hbar}\subset\mathbb{R}^{n\times m}
. The following statements are equivalent.

(i)

There exists
\Lambda_{\hbar}\in\mathcal{J}_{\hbar}
so that the system
[S,\{\chi_{\omega_{k}}D_{k}\}_{k=1}^{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.

(ii)

\textrm{rank}\,(\lambda I_{n}-S,\mathcal{D})=n\textrm{ for any }\lambda\in\mathbb{C}\textrm{ with }\textrm{Re}(\lambda)\geq\lambda_{1}.

(iii)

\textrm{rank}\,(\lambda I_{n}-S,\mathcal{D})=n\textrm{ for any }\lambda\in\mathbb{\sigma}(S)\textrm{ with }\textrm{Re}(\lambda)\geq\lambda_{1}.

Here and throughout this section,
\lambda_{1}
denotes the first eigenvalue of
-\triangle
and
\sigma(S)
the spectrum of the matrix
S
.

In order to prove Theorem
4.1
, we first introduce some definitions and two lemmas.
For any
E\in\mathbb{R}^{k\times k}
,
F\in\mathbb{R}^{k\times\ell}
(
k,\ell\in\mathbb{N}^{+}
), we define (see
[
17
]
and
[
18
]
)

d_{E}:=\min\left\{\frac{\pi}{\textrm{Im}(\lambda)}:\,\lambda\in\sigma(E)\right\}\textrm{ and }q(E,F):=\max\{\textrm{dim}\mathcal{V}_{E}(f):\,f\textrm{ is a column of }F\},

(4.2)

where
\mbox{Im}(\lambda)=\lambda_{2}
if
\lambda=\lambda_{1}+i\lambda_{2}
,
\mathcal{V}_{E}(f):=\textrm{ span}\{f,Ef,\cdots,E^{k-1}f\}
and we agree that
\frac{1}{0}=+\infty
.
Moreover, we define

\begin{split}\mathcal{L}_{E,F,\hbar}:=\big\{\{\tau_{j}\}_{j\in\mathbb{N}}:\;0=\tau_{0}<\tau_{1}<\cdots<\tau_{n}<\cdots,\qquad\qquad\qquad\qquad\qquad\qquad\qquad\quad\\
\,\textrm{Card}((s,s+d_{E})\cap\{\tau_{j}\}_{j\in\mathbb{N}})\geq\hbar q(E,F)+2\textrm{ for any }s\in\mathbb{R}^{+}\big\}.\end{split}

The following result can be found in the proof of Theorem 2.2 in
[
17
]
.

Lemma 4.2
.

Let
E\in\mathbb{R}^{k\times k}
,
F\in\mathbb{R}^{k\times\ell}
(
k,\ell\in\mathbb{N}^{+}
).
For each strictly increasing sequence

\{\tau_{i}\}_{i=1}^{q(E,F)}
with

\tau_{q(E,F)}-\tau_{1}<d_{E}
, we have that

Lemma 4.3
.

Let
\Lambda_{\hbar}=\{t_{j}\}_{j\in\mathbb{N}}\in\mathcal{J}_{\hbar}
and
\widehat{k}\in\mathbb{N}^{+}
be fixed. The following two claims are equivalent:

\text{rank}\,\left(\mathrm{e}^{-St_{1}}D_{\nu(1)},\mathrm{e}^{-St_{2}}D_{\nu(2)},\cdots,\mathrm{e}^{-St_{\widehat{k}}}D_{\nu(\widehat{k})}\right)=n
.

(ii)

There are two constants

(independent of
\widehat{k}
) and

so that

\displaystyle\|\mathrm{e}^{A^{*}t_{\widehat{k}+1}}\varphi\|_{(L^{2}(\Omega))^{n}}

(4.3)

\displaystyle\leq

\displaystyle C(\widehat{k})\left(\displaystyle{\sum_{j=1}^{\widehat{k}}}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{\widehat{k}+1}-t_{j})}\varphi\|_{(L^{2}(\Omega))^{m}}\right)^{\theta}\|\varphi\|^{1-\theta}_{(L^{2}(\Omega))^{n}}\;\;\mbox{for all}\;\;\varphi\in(L^{2}(\Omega))^{n}.

Based on Lemma
4.2

Lemma 4.4
.

Let
\Lambda_{\hbar}=\{t_{j}\}_{j\in\mathbb{N}}\in\mathcal{J}_{\hbar}\cap\mathcal{L}_{S,\mathcal{D},\hbar}
. Suppose that

\text{rank}\,\left(\mathcal{D},S\mathcal{D},\cdots,S^{n-1}\mathcal{D}\right)=n.

Then
the system
[S,\{\chi_{\omega_{k}}D_{k}\}_{k=1}^{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.

Proof.

Since
\Lambda_{\hbar}\in\mathcal{L}_{S,\mathcal{D},\hbar}
, by the definition of
q(S,\mathcal{D})
(see (
4.2
)) and the fact that
\mathcal{D}=(D_{1},\cdots,D_{\hbar})
, it is easy to see

t_{j+q(S,D_{j})\hbar}-t_{j}\leq t_{j+q(S,\mathcal{D})\hbar}-t_{j}<d_{S}\,\textrm{ for each }j\in\{1,\ldots,\hbar\}.

This, along with Lemma
4.2
, shows that

\textrm{span}\,\{\mathrm{e}^{-St_{j}}D_{j},\cdots,\mathrm{e}^{-St_{j+q(H,D_{j})\hbar}}D_{j}\}=\textrm{span}\,\{D_{j},SD_{j},\cdots,S^{n-1}D_{j}\}\textrm{ for each }j\in\{1,\ldots,\hbar\}.

From this, we obtain that

\displaystyle\sum_{j=1}^{\hbar}\textrm{span}\,\{\mathrm{e}^{-St_{j}}D_{j},\cdots,\mathrm{e}^{-St_{j+q(S,D_{j})\hbar}}D_{j}\}

\displaystyle=

\displaystyle\sum_{j=1}^{\hbar}\textrm{span}\,\{D_{j},SD_{j},\cdots,S^{n-1}D_{j}\}

(4.4)

\displaystyle=

\displaystyle\textrm{span}\;\{\mathcal{D},S\mathcal{D},\cdots,S^{n-1}\mathcal{D}\}.

Here, for two linear spaces
V_{1}
and
V_{2}
, we let
V_{1}+V_{2}=\mbox{span}\{V_{1},V_{2}\}
. Noting that for each
j\in\{1,\ldots,\hbar\}
,
\nu(j)=\nu(j+\ell\hbar)
for any
\ell\in\mathbb{N}
, (
4.4
) implies that

\textrm{span}\,\{\mathrm{e}^{-St_{1}}D_{\nu(1)},\cdots,\mathrm{e}^{-St_{\hbar+q(S,\mathcal{D})\hbar}}D_{\nu\left(\hbar+q(S,\mathcal{D})\hbar\right)}\}=\textrm{span}\,\{\mathcal{D},S\mathcal{D},\cdots,S^{n-1}\mathcal{D}\}.

(4.5)

Denote
\widehat{n}=\hbar+q(S,\mathcal{D})\hbar
. By (
4.5
) and our assumption, we have that

\textrm{rank}\,(\mathrm{e}^{-St_{1}}D_{\nu(1)},\cdots,\mathrm{e}^{-St_{\widehat{n}}}D_{\nu(\widehat{n})})=n.

This, along with Lemma
4.3
, shows that there exists
\theta\in(0,1)
and
C(\widehat{n})>0

so that (
4.3
) stands with
\widehat{k}
replaced by
\widehat{n}
.
Then for each
\alpha>0
, there exists a constant
C(\widehat{n},\alpha)>0
so that

\|\mathrm{e}^{A^{*}t_{\widehat{n}+1}}\varphi\|_{(L^{2}(\Omega))^{n}}\leq C(\widehat{n},\alpha)\left(\displaystyle{\sum_{j=1}^{\widehat{n}}}\|B^{*}_{\nu(j)}\mathrm{e}^{A^{*}(t_{\widehat{n}+1}-t_{j})}\varphi\|^{2}_{(L^{2}(\Omega))^{m}}\right)^{\frac{1}{2}}+\alpha\|\varphi\|_{(L^{2}(\Omega))^{n}}\;\;\mbox{for all}\;\;\varphi\in(L^{2}(\Omega))^{n}.

This, along with Theorem
1.2
, completes the proof.

.

rank
\,(\mathcal{D},S\mathcal{D},\cdots,S^{n-1}\mathcal{D})=n_{1}<n

(4.6)

Proposition 4.6
.

Let
\Lambda_{\hbar}=\{t_{j}\}_{j\in\mathbb{N}}\in\mathcal{J}_{\hbar}\cap\mathcal{L}_{S,\mathcal{D},\hbar}
. Suppose that

\textrm{ rank}(\lambda I-S,\mathcal{D})=n\textrm{ for any }\lambda\in\mathbb{C}\textrm{ with }\textrm{Re}(\lambda)\geq\lambda_{1}.

(4.7)

Then
the system
[S,\{\chi_{\omega_{k}}D_{k}\}_{k=1}^{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.

Proof.

Without loss of generality, we assume that
\textrm{rank}\,(\mathcal{D},S\mathcal{D},\cdots,S^{n-1}\mathcal{D})=n_{1}
with
1\leq n_{1}<n
,
since when
n_{1}=n
the conclusion follows from Lemma
4.4
at once.
By Lemma
4.5
, there exists an invertible matrix
J\in\mathbb{R}^{n\times n}
so that
(
4.6
) holds with
S_{1}\in\mathbb{R}^{n_{1}\times n_{1}}
,
\widetilde{\mathcal{D}}\in\mathbb{R}^{n_{1}\times m\hbar}
and

\textrm{rank}\,(\widetilde{\mathcal{D}},S_{1}\widetilde{\mathcal{D}},\cdots,S_{1}^{n_{1}-1}\widetilde{\mathcal{D}})=n_{1}.

(4.8)

Denote

J^{-1}D_{1}=\left(\begin{array}[]{c}\widetilde{D}_{1}\\
0\\
\end{array}\right),\textrm{...},J^{-1}D_{\hbar}=\left(\begin{array}[]{c}\widetilde{D}_{\hbar}\\
0\\
\end{array}\right),

where
\widetilde{D}_{j}\in\mathbb{R}^{n_{1}\times m}
. Then

\widetilde{\mathcal{D}}=(\widetilde{D}_{1},\cdots,\widetilde{D}_{\hbar}).

(4.9)

First, we show that

\textrm{Re}(\lambda)<\lambda_{1}\textrm{ for any }\lambda\in\sigma(S_{3}).

(4.10)

For otherwise, there would exist
\lambda_{0}\in\sigma(S_{3})
so that Re
(\lambda_{0})\geq\lambda_{1}
.
It follows that

\textrm{rank}(\lambda_{0}I-S,\mathcal{D})=\textrm{rank}(\lambda_{0}I-J^{-1}SJ,J^{-1}\mathcal{D})=\textrm{rank}\left(\begin{array}[]{ccc}\lambda_{0}I-S_{1}&S_{2}&\widetilde{\mathcal{D}}\\
0&\lambda_{0}I-S_{3}&0\end{array}\right)<n,

which contradicts (
4.7
). Thus (
4.10
) stands.
Therefore, there exist constants
M_{0}>0
and
\varepsilon_{0}>0
so that the solution
\widetilde{y}(\cdot)
of system

\begin{cases}\widetilde{y}_{t}-\triangle_{n-n_{1}}\widetilde{y}-S_{3}^{\top}\widetilde{y}=0,&\textrm{ in }\Omega\times\mathbb{R}^{+},\\
\widetilde{y}=0,&\textrm{ on }\partial\Omega\times\mathbb{R}^{+}\end{cases}

(4.11)

satisfies that

\|\widetilde{y}(t)\|_{(L^{2}(\Omega))^{n-n_{1}}}\leq M_{0}\mathrm{e}^{-\varepsilon_{0}t}\|\widetilde{y}(0)\|_{(L^{2}(\Omega))^{n-n_{1}}}\textrm{ for any }t>0.

(4.12)

Second, by the definitions of
d_{S}
and
q(S,\mathcal{D})
(see (
4.2
)), we obtain that

d_{S}\leq d_{S_{1}}

and

q(S_{1},\widetilde{\mathcal{D}})\leq q(S,\mathcal{D}).

This, along with the fact that
\Lambda_{\hbar}\in\mathcal{J}_{\hbar}\cap\mathcal{L}_{S,\mathcal{D},\hbar}
, shows that

\Lambda_{\hbar}\in\mathcal{J}_{\hbar}\cap\mathcal{L}_{S_{1},\widetilde{\mathcal{D}},\hbar}
. Then, by
(
4.8
), (
4.9
) and Lemma
4.4
, we have that the system

[S_{1},\{\chi_{\omega_{k}}\widetilde{D}_{k}\}_{k=1}^{\hbar},\Lambda_{\hbar}]
is exponentially
\hbar
-stabilizable.
Thus there exists a feedback control law
\widehat{\mathcal{F}}=\{\widehat{F}_{j}\}_{j=1}^{\hbar}\subset\mathcal{L}((L^{2}(\Omega))^{n_{1}};(L^{2}(\Omega))^{m})
so that the system

\begin{cases}z_{t}-\triangle_{n_{1}}z-S_{1}z=0,&\textrm{ in }\Omega\times(\mathbb{R}^{+}\backslash\Lambda_{\hbar}),\\
z=0,&\textrm{ on }\partial\Omega\times\mathbb{R}^{+},\\
z(t_{j}^{+})=z(t_{j})+\chi_{\omega_{\nu(j)}}\widetilde{D}_{\nu(j)}\widehat{F}_{\nu(j)}z_{1}(t_{j}),&\textrm{ in }\Omega,j\in\mathbb{N}^{+}\end{cases}

(4.13)

is stable, i.e., if we denote the solution of the system (
4.13
) by
z(t)=S_{\widehat{\mathcal{F}}}(t)z(0)
, then there
exist constants
M_{1}>0
and
\varepsilon_{1}\in(0,\varepsilon_{0})

\|z(t)\|_{(L^{2}(\Omega))^{n_{1}}}=\|S_{\widehat{\mathcal{F}}}(t)z(0)\|_{(L^{2}(\Omega))^{n_{1}}}\leq M_{1}\mathrm{e}^{-\varepsilon_{1}t}\|z(0)\|_{(L^{2}(\Omega))^{n_{1}}}\textrm{ for any }t\geq 0.

This indicates that

\|S_{\widehat{\mathcal{F}}}(t)\|_{\mathcal{L}((L^{2}(\Omega))^{n_{1}})}\leq M_{1}\mathrm{e}^{-\varepsilon_{1}t}\textrm{ for any }t\geq 0.

(4.14)

Third, we consider the system

\begin{cases}\widehat{y}_{t}-\triangle_{n_{1}}\widehat{y}-S_{1}\widehat{y}=S_{2}\widetilde{y},&\textrm{ in }\Omega\times(\mathbb{R}^{+}\backslash\Lambda_{\hbar}),\\
\widehat{y}=0,&\textrm{ on }\partial\Omega\times\mathbb{R}^{+},\\

This, combined with (
4.14
) and (

\|\widehat{y}(t)\|_{(L^{2}(\Omega))^{n_{1}}}\leq M_{2}\mathrm{e}^{-\varepsilon_{1}t}\left(\|\widehat{y}(0)\|_{(L^{2}(\Omega))^{n_{1}}}+\|\widetilde{y}(0)\|_{(L^{2}(\Omega))^{n-n_{1}}}\right)\textrm{ for any }t\geq 0,

(4.16)

Moreover, from (

\|x(t)\|_{(L^{2}(\Omega))^{n}}\leq\|J\|_{\mathcal{L}(\mathbb{R}^{n};\mathbb{R}^{n})}\cdot\|y(t)\|_{(L^{2}(\Omega))^{n}}\leq M_{3}\mathrm{e}^{-\varepsilon_{1}t}\|x(0)\|_{(L^{2}(\Omega))^{n}}\textrm{ for any }t\geq 0,
