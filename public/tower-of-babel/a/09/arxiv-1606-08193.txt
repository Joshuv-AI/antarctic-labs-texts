From Chio Pivotal Condensation to the Matrix-Tree theorem
Darij Grinberg, Karthik Karnik, Anya Zhang

Abstract
We show a determinant identity which generalizes both the Chio pivotal condensation theorem and the Matrix-Tree theorem.

2.1
Chio Pivotal Condensation

We begin with a statement of the Chio Pivotal Condensation theorem (see, e.g.,

[
KarZha16
, Theorem 0.1]
and the reference therein):

Theorem 2.1
.

Let
n\geq 2
be an integer. Let
A=\left(a_{i,j}\right)_{1\leq i\leq n,\ 1\leq j\leq n}\in\mathbb{K}^{n\times n}
be a matrix. Then,

\det\left(\left(a_{i,j}a_{n,n}-a_{i,n}a_{n,j}\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\right)=a_{n,n}^{n-2}\cdot\det\left(\left(a_{i,j}\right)_{1\leq i\leq n,\ 1\leq j\leq n}\right).

Example 2.2
.

If
n=3

A=\left(\begin{array}[c]{ccc}a&a^{\prime}&a^{\prime\prime}\\

2.1

\det\left(\begin{array}[c]{cc}ac^{\prime\prime}-a^{\prime\prime}c&a^{\prime}c^{\prime\prime}-a^{\prime\prime}c^{\prime}\\

2.2
Generalization, step 1

Our generalization will proceed in two steps. In the first step, we shall
replace some of the
n
’s on the left hand side by
f\left(i\right)
’s
(see Theorem
2.9
below). We first define some notations:

Definition 2.3
.

Let
n
be a positive integer. Let
f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\}
be any map such that
f\left(n\right)=n
.

We say that the map
f
is
n
-potent
if for every
i\in\left\{1,2,\ldots,n\right\}
, there exists some
k\in\mathbb{N}
such that

f^{k}\left(i\right)=n
. (In less formal terms,
f
is
n
-potent if and
only if every element of
\left\{1,2,\ldots,n\right\}
eventually arrives
at
n
when being subjected to repeated application of
f
.)

(Note that, by definition, any
n
-potent map
f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\}
must satisfy
f\left(n\right)=n
.)

Example 2.4
.

For this example, let
n=3
. The map
\left\{1,2,3\right\}\rightarrow\left\{1,2,3\right\}
sending
1,2,3
to
2,1,3
, respectively, is not

n
-potent (because applying it repeatedly to
1
can only give
1
or
2
,
but never
3
). The map
\left\{1,2,3\right\}\rightarrow\left\{1,2,3\right\}
sending
1,2,3
to
3,3,2
, respectively, is not
n
-potent
(since it does not send
n
to
n
). The map
\left\{1,2,3\right\}\rightarrow\left\{1,2,3\right\}
sending
1,2,3
to
3,1,3
, respectively,
is
n
-potent (indeed, every element of
\left\{1,2,3\right\}
goes to
3

after at most two applications of this map).

Remark 2.5
.

Given a positive integer
n
, the
n
-potent maps

f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\}

are in 1-to-1 correspondence with the trees with vertex set
\left\{1,2,\ldots,n\right\}
. Namely, an
n
-potent map
f
corresponds to the tree
whose edges are
\left\{i,f\left(i\right)\right\}
for all

i\in\left\{1,2,\ldots,n-1\right\}
. If we regard the tree as a rooted
tree with root
n
, and if we direct every edge towards the root, then the
edges are
\left(i,f\left(i\right)\right)
for all
i\in\left\{1,2,\ldots,n-1\right\}
.

Remark 2.6
.

Let
n\geq 2
be an integer. Let
f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\}
be any

n
-potent map. Then:

(a)
There exists some
g\in\left\{1,2,\ldots,n-1\right\}
such
that
f\left(g\right)=n
.

(b)
We have
\left|f^{-1}\left(n\right)\right|\geq 2
.

The (very simple) proof of Remark
2.6
can be found in
the Appendix (Section
4
).

Definition 2.7
.

Let
n\geq 2
be an integer. Let
A=\left(a_{i,j}\right)_{1\leq i\leq n,\ 1\leq j\leq n}\in\mathbb{K}^{n\times n}
be
an
n\times n
-matrix. Let

be any
n
-potent map.

(a)
We define an element

of

by

\operatorname*{weight}\nolimits_{f}A=\prod\limits_{i=1}^{n-1}a_{i,f\left(i\right)}.

(b)
We define an element
\operatorname*{abut}\nolimits_{f}A
of

by

\operatorname*{abut}\nolimits_{f}A=a_{n,n}^{\left|f^{-1}\left(n\right)\right|-2}\prod\limits_{\begin{subarray}{c}i\in\left\{1,2,\ldots,n-1\right\};\\
f\left(i\right)\neq n\end{subarray}}a_{f\left(i\right),n}.

(This is well-defined, since Remark

(b)

shows that
\left|f^{-1}\left(n\right)\right|-2\in\mathbb{N}
.)

Remark 2.8
.

Let

and

be as in Definition

(a)
If

is invertible, then

\dfrac{1}{a_{n,n}}\prod\limits_{i\in\left\{1,2,\ldots,n-1\right\}}a_{f\left(i\right),n}

(b)

Theorem 2.9
.

Let
n
be a positive integer. Let
A=\left(a_{i,j}\right)_{1\leq i\leq n,\ 1\leq j\leq n}\in\mathbb{K}^{n\times n}

be any map such that

.

Let

\left(n-1\right)\times\left(n-1\right)

\left(a_{i,j}a_{f\left(i\right),n}-a_{i,n}a_{f\left(i\right),j}\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\in\mathbb{K}^{\left(n-1\right)\times\left(n-1\right)}.

(a)
If the map

is not
n

\det B=0
.

(b)
Assume that
n\geq 2
. Assume that the map
f
is
n

Then,

\det B=\left(\operatorname*{abut}\nolimits_{f}A\right)\cdot\det A.

.

For this example, let

.

If

. Since this map

On the other hand, if

\left(\begin{array}[c]{cc}a_{1,1}a_{1,3}-a_{1,3}a_{1,1}&a_{1,2}a_{1,3}-a_{1,3}a_{1,2}\\

until later; first, let us
see how it can be generalized a bit further (not substantially, anymore) and
how this generalization also encompasses the matrix-tree theorem.

2.3
The matrix-tree theorem

Definition 2.11
.

For any two objects
i
and
j
, we define an element
\delta_{i,j}\in\mathbb{K}
by
\delta_{i,j}=\begin{cases}1,&\text{if }i=j;\\
0,&\text{if }i\neq j\end{cases}
.

Let us first state the matrix-tree theorem.

To be honest, there is no “the matrix-tree
theorem”, but rather a network of “matrix-tree theorems” (some less, some more general), each
of which has a reasonable claim to this name. Here we shall prove the
following one:

Theorem 2.12
.

Let
n\geq 1
be an integer. Let
W:\left\{1,2,\ldots,n\right\}\times\left\{1,2,\ldots,n\right\}\rightarrow\mathbb{K}
be any
function. For every
i\in\left\{1,2,\ldots,n\right\}
, set

d^{+}\left(i\right)=\sum\limits_{j=1}^{n}W\left(i,j\right).

Let
L
be the matrix
\left(\delta_{i,j}d^{+}\left(i\right)-W\left(i,j\right)\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\in\mathbb{K}^{\left(n-1\right)\times\left(n-1\right)}
. Then,

\det L=\sum\limits_{\begin{subarray}{c}f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\};\\
f\left(n\right)=n;\\
f\text{ is }n\text{-potent}\end{subarray}}\prod\limits_{i=1}^{n-1}W\left(i,f\left(i\right)\right).

(1)

and
one of its better-known avatars: The version of the matrix-tree theorem stated
in
[

W\left(k,m\right)
, the determinant
\det L
, and the sum over all

n
-potent maps
f
in our Theorem

part of this correspondence is the bijection between the trees in

and the
n
-potent maps
f
over which the sum in

introduced in Remark

.

5

Generalization, step 2

Now, as promised, we will generalize Theorem

Theorem 2.13

\det G=\left(\sum\limits_{\begin{subarray}{c}f:\left\{1,2,\ldots,n\right\}\rightarrow\left\{1,2,\ldots,n\right\};\\

\left(\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}}\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\in\mathbb{K}^{\left(n-1\right)\times\left(n-1\right)}.

Thus, Lemma
3.20
(applied to

,

,
\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}}
and

a_{i,n}a_{f\left(i\right),n}
instead of

,

and

\displaystyle\det\left(\left(a_{i,n}a_{f\left(i\right),n}\left(\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}}\right)\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\right)

\displaystyle=\left(\prod\limits_{i=1}^{n-1}\left(a_{i,n}a_{f\left(i\right),n}\right)\right)\det C.

Comparing this with

\displaystyle\det\left(\left(\underbrace{a_{i,n}a_{f\left(i\right),n}\left(\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}}\right)}_{=a_{i,j}a_{f\left(i\right),n}-a_{i,n}a_{f\left(i\right),j}}\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}\right)

\displaystyle=\det\left(\underbrace{\left(a_{i,j}a_{f\left(i\right),n}-a_{i,n}a_{f\left(i\right),j}\right)_{1\leq i\leq n-1,\ 1\leq j\leq n-1}}_{=B}\right)=\det B,

It remains to compute

For every
\left(i,j\right)\in\left\{1,2,\ldots,n\right\}^{2}
, define
an element

by

d_{i,j}=\begin{cases}\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}},&\text{if }i<n;\\
\dfrac{a_{i,j}}{a_{i,n}},&\text{if }i=n\end{cases}.

For every
i\in\left\{1,2,\ldots,n-1\right\}
, the definition of
d_{i,n}

yields

\displaystyle d_{i,n}

\displaystyle=\begin{cases}\dfrac{a_{i,n}}{a_{i,n}}-\dfrac{a_{f\left(i\right),n}}{a_{f\left(i\right),n}},&\text{if }i<n;\\
\dfrac{a_{i,n}}{a_{i,n}},&\text{if }i=n\end{cases}=\underbrace{\dfrac{a_{i,n}}{a_{i,n}}}_{=1}-\underbrace{\dfrac{a_{f\left(i\right),n}}{a_{f\left(i\right),n}}}_{=1}\ \ \ \ \ \ \ \ \ \ \left(\text{since }i<n\right)

\displaystyle=1-1=0.

Moreover, the definition of

yields

\displaystyle d_{n,n}

\displaystyle=\begin{cases}\dfrac{a_{n,n}}{a_{n,n}}-\dfrac{a_{f\left(n\right),n}}{a_{f\left(n\right),n}},&\text{if }n<n;\\
\dfrac{a_{n,n}}{a_{n,n}},&\text{if }n=n\end{cases}=\dfrac{a_{n,n}}{a_{n,n}}\ \ \ \ \ \ \ \ \ \ \left(\text{since }n=n\right)

\displaystyle=1.

Finally, every
i\in\left\{1,2,\ldots,n-1\right\}
and
j\in\left\{1,2,\ldots,n\right\}
satisfy

d_{i,j}=\begin{cases}\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}},&\text{if }i<n;\\
\dfrac{a_{i,j}}{a_{i,n}},&\text{if }i=n\end{cases}=\dfrac{a_{i,j}}{a_{i,n}}-\dfrac{a_{f\left(i\right),j}}{a_{f\left(i\right),n}}

(20)

(since

\displaystyle\det B

\displaystyle=\left(\prod\limits_{i=1}^{n-1}\left(a_{i,n}a_{f\left(i\right),n}\right)\right)\underbrace{\det C}_{=\det D}

\displaystyle=\left(\prod\limits_{i=1}^{n-1}\left(a_{i,n}a_{f\left(i\right),n}\right)\right)\det D.

Compared with

n\times n
