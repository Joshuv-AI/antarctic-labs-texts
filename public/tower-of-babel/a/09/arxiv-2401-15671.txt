The Regular Element Property in Constructive Mathematics
Thierry Coquand

Abstract




Introduction

The goal of this note is to present Kaplansky’s proof of the Regular Element Property
[
5
]
and to explain
how this argument can be adapted to the case of a coherent, strongly discrete and Noetherian (with an inductive
definition of Noetherian
[
4
]
) rings in a constructive setting. We thus get, in this setting, an algorithm
which given a f.g. regular ideal
I={\langle a_{1},\dots,a_{n}\rangle}
, build a regular element in
I
.
This complements in a way the previous treatment by Richman
[
6
]
.

One maybe interesting feature of the constructive reformulation is that it uses the technique of point-free open
induction
[
2
,
1
]
. (A previous inductive proof of the nilregular element property
[
3
]
used a
simpler form of induction.)

1
Classical Proof

We recall that
incomparable
prime ideals
P_{1},\dots,P_{m}
are
independent
: we cannot have
\cap_{i\neq k}P_{i}\subseteq P_{k}

since this would imply that we have
i\neq k
such that
P_{i}\subseteq P_{k}
.

Let
{v}^{\perp}
be the ideal of elements
x
such that
vx=0
. An ideal of the from
{v}^{\perp}
for
v\neq 0

is called
orthogonal
ideal.

Each
maximal
orthogonal ideal
{v}^{\perp}
is a
prime
ideal: if
ab
in
{v}^{\perp}
then

abv=0
and
av\neq 0
then
{(av)}^{\perp}={v}^{\perp}
by maximality and hence
b
in
{v}^{\perp}
.

So if we have
v_{1},\dots,v_{m}
non zero elements such that each

{v_{i}}^{\perp}
is orthogonal
and
maximal, they are necessarily incomparable and prime
and so the ideals
{v_{i}}^{\perp}
are independent:
\cap_{i\neq k}{v_{i}}^{\perp}
is not
a subset of
{v_{k}}^{\perp}
.

Using Noetherianity, we see that the set of maximal orthogonal ideals has to be finite: if
v_{m+1}
is in

{\langle v_{1},\dots,v_{m}\rangle}
then
\cap_{i\leqslant m}{v_{i}}^{\perp}
is a subset of
{v_{m+1}}^{\perp}

and then
v_{1},\dots,v_{m},v_{m+1}
cannot be independent.

We consider then the finite set
{v_{1}}^{\perp},\dots,{v_{m}}^{\perp}
of
all
maximal orthogonal ideals. It is an independent set.
So, for each
k
, we have
u_{k}
such that
u_{k}v_{k}\neq 0
and
u_{k}v_{i}=0
if
i\neq k
.

Let
I={\langle a_{1},\dots,a_{n}\rangle}
be a regular ideal. For each
k
we have
i_{k}
such that
u_{k}v_{k}a_{i_{k}}\neq 0
since
u_{k}v_{k}\neq 0
.
Let
a=\Sigma_{k}u_{k}a_{i_{k}}
element of
I
. We have
av_{k}=u_{k}v_{k}a_{i_{k}}\neq 0
. I claim that
a
is regular.
Indeed if
va=0
and
v\neq 0
we have
a
in
{v}^{\perp}
and
a
is not in any
{v_{1}}^{\perp},\dots,{v_{m}}^{\perp}
which
contradicts the fact that this is a list of all maximal orthogonal ideals.

2
Constructive Version

We are going to see that the classical argument of the first section can be read as an algorithm. The idea is to proceed

dynamically
: we use a finite set
{v_{1}}^{\perp},\dots,{v_{m}}^{\perp}
which is an approximation of the set of all maximal orthogonal
ideals to compute a candidate for a regular element in a given regular ideal. If it is not regular, we use this to compute
a better approximation. The problem is then reduced to showing that this process will end eventually.

If
S
is a relation on a set
X
, we say that
x
is
S
-accessible if, and only if, all
y
such that
S(x,y)
are

S
-accessible. The relation
S
is well-founded if, and only if, all elements are accessible.

We assume now that the ring
R
is
coherent
and
strongly discrete
. Each ideal
{v}^{\perp}
is then a f.g. ideal.

We can then decide inclusion between f.g. ideals. We write
I<J
for the fact that
I
is a
strict
subset of
J
.

We assume that
<
is well-founded.

We consider then following relation:
v_{1},\dots,v_{n}\prec w_{1},\dots,w_{m}

(for
m\leqslant n
) if, and only if,
v_{i}=w_{i}
for
i<m
and
{v_{m}}^{\perp}<{w_{m}}^{\perp}
.

A list
v_{1},\dots,v_{n}
is called independent if the corresponding ideals
{v_{i}}^{\perp}
are independent.
It is non decreasing if
{v_{i}}^{\perp}\subseteq{v_{j}}^{\perp}
implies
i\leqslant j
. Clearly any independent list is
non decreasing.

If
\alpha,v
is independent then so is
\alpha
. So the independent lists form a tree, and the branching of
the tree is given by a decidable subset of the set
R
.

Lemma 2.0.1
.

The relation
\prec
is well-founded.

Proof.

We show by induction on
v
and the length of
\alpha
that any element
v\alpha
if
\prec
-accessible.
Indeed,
we have
v\alpha\prec\beta
if, and only if,
\beta=w
for some
w>v
or
\beta=v\gamma
with
\alpha\prec\gamma
.
∎

Corollary 2.0.1
.

If
\alpha
is a non decreasing list, there exists an independent
\beta
such that
\alpha\prec^{*}\beta
.

Proof.

Indeed if
\alpha
non decreasing is not independent, we find
\beta
non decreasing such
that
\alpha\prec\beta
. We conclude by Lemma
2.0.1
.
∎

We now consider the lexicographic
ordering
\alpha<\beta
if, and only if,
\beta
is an extension of some
\gamma
such that
\alpha\prec\gamma

or a strict extension of
\alpha
.

Lemma 2.0.2
.

The ordering
<
is well-founded on independent lists.

Proof.

We use the point-free technique of open induction
[
2
]
.

If
\alpha
is a list, let
{\langle\alpha\rangle}
the f.g. ideal it generates.

Let
M
be the set of independent
\alpha
such that

\alpha\prec\beta
implies that
\beta
is
<
-accessible.
If
\alpha\rightarrow\alpha v
and
\alpha v
is in
M
then so is
\alpha
since

\alpha\prec\beta
implies
\alpha v\prec\beta
. So
M
defines a subtree in the tree of
independent sequences.

This tree has a complex branching structure, since the branching is now given by the
predicate of being
\prec
-accessible

the argument is a priori in ID

.

The relation of adding one element

\alpha\rightarrow\alpha v
is well-founded on the set
M
, since
we then have
{\langle\alpha\rangle}<{\langle\alpha v\rangle}
and the ring
R
is Noetherian.

This means that the following induction principle holds: is
\psi(\alpha)
is such that

\psi(\alpha)
holds whenever
\psi(\alpha v)
holds for all
\alpha v
in
M
, then

\psi
holds for the empty sequence.

We apply this for the case where
\psi(\alpha)
expresses that
\alpha
is accessible
for the lexicographic ordering.

We take
\alpha
in
M
and assume that
\alpha v
in
M
implies
\alpha v
accessible.

Then we show that
\alpha
is accessible. For this we show that
\alpha v
is accessible whenever

\alpha v
is independent by induction on
v
.

Let
v
be such that
\alpha w
is accessible for each
w>v
. We show that
\alpha v
is accessible.

It is enough to show that
\alpha v
is in
M
.
Assume
\alpha v\prec\beta
then either
\alpha\prec\beta
(and then
\beta
is accessible since

\alpha
is in
M
) or
\beta=\alpha w
with

, and it is accessible by hypothesis.

By the induction principle on
M
, it follows that the empty sequence is accessible.
∎

We can also extract from the classical section the following algorithm, which holds for any ring with a decidable equality.
Given
I={\langle a_{1},\dots,a_{m}\rangle}
which is regular.

Lemma 2.0.3
.

If
\alpha=v_{1},\dots,v_{n}
if an independent sequence, then we can build
a\neq 0
in
I
such that

av_{i}\neq 0
for each
i
.

We deduce from all this the following algorithm for computing a regular element in a coherent, strongly discrete
and inductive Noetherian rings.

We start from the empty sequence
\alpha_{0}=()
. Since
I
is regular we can find
u_{0}
in
I
which is
\neq 0
.
Then either

u_{0}
is regular or we find
\alpha_{1}>\alpha_{0}
such that
\alpha_{1}
is independent. Using Lemma
2.0.3
, we compute

u_{1}\neq 0
in
I
such that
u_{1}v\neq 0
for each
v
in
\alpha_{1}
. Either
u_{1}
is regular, or we find
v\neq 0

such that
u_{1}v=0
and
\alpha_{2}>\alpha_{1}v

which is independent, using Corollary of Lemma
2.0.1
, and so on.

This process should eventually produces a regular element in
I
using Lemma
2.0.2
.
