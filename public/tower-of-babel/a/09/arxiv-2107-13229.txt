Feller’s upper-lower class test in Euclidean space
Uwe Einmahl

Abstract
We provide an extension of Feller’s upper-lower class test for the Hartman-Wintner LIL to the LIL in Euclidean space. We obtain this result as a corollary to a general upper-lower class test for Γ n ​ T n \Gamma_{n}T_{n} where T n = ∑ j = 1 n Z j T_{n}=\sum_{j=1}^{n}Z_{j} is a sum of i.i.d. d-dimensional standard normal random vectors and Γ n \Gamma_{n} is a convergent sequence of symmetric non-negative definite ( d , d ) (d,d) -matrices. In the process we derive new bounds for the tail probabilities of d d -dimensional normally distributed random vectors.

60F15.

Hartman-Wintner LIL, Euclidean space, upper-lower class test, Gaussian random vectors.

Introduction

Let
X_{1},X_{2},\ldots
be independent identically distributed (= i.i.d.)
d
-dimensional random vectors and set
S_{n}=\sum_{j=1}^{n}X_{j},n\geq 1.
Denote the Euclidean norm by
|\cdot|
and set
Lt=\log_{e}(t\vee e),LLt=L(Lt),t\geq 0.
Let
\mathcal{N}(\mu,\Sigma)
be the
d
-dimensional normal distribution with mean
\mu
and non-negative definite covariance matrix
\Sigma.

Assuming that
\mathbb{E}|X_{1}|^{2}<\infty
and
\mathbb{E}X_{1}=0,
it follows from the
d
-dimensional version of the Hartman-Wintner law of the iterated logarithm (LIL) that with probability one,

\limsup_{n\to\infty}|S_{n}|/\sqrt{2nLLn}=\sigma,

(1.1)

where
\sigma^{2}
is the largest eigenvalue of
\mathrm{Cov}(X_{1})
(= covariance matrix of
X_{1}
).

A substantial refinement of this result is given by an upper-lower class test. We say that a non-decreasing sequence
\{a_{n}\}
of positive real numbers belongs to the upper class (lower class) for
|S_{n}|
if we have with probability one,

|S_{n}|\leq a_{n}
eventually (
|S_{n}|>a_{n}
infinitely often). By the 0-1 law of Kolmogorov any such sequence
\{a_{n}\}
has to be in one of these two classes.

The above LIL result then only implies that

a\sqrt{2nLLn}
belongs to the upper (lower) class if
a>\sigma
(
a<\sigma
), but, for instance, it is not clear from the LIL to what class the sequence
\sigma\sqrt{2nLLn}
belongs.
If one has normally distributed random vectors this sequence belongs to the lower class for
|S_{n}|
. This easily follows from the subsequent upper-lower class test which is part of a more general result in
[
13
]
.

Theorem A (
[
13
]
)
If
X_{n},n\geq 1
is a sequence of independent
\mathcal{N}(0,\Sigma)
-distributed random vectors we have for any non-decreasing sequence
\phi_{n}
of positive real numbers,

\mathbb{P}\{|S_{n}|\leq\sigma\sqrt{n}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }0

according as

\sum_{n=1}^{\infty}n^{-1}\phi_{n}^{d_{1}}\exp(-\phi_{n}^{2}/2)<\infty\mbox{ or}=\infty,

where
d_{1}
is the multiplicity of the largest eigenvalue
\sigma^{2}
of
\Sigma
.

It is natural now to ask whether this result also holds for arbitrary mean zero random vectors satisfying the minimal condition
\mathbb{E}|X_{1}|^{2}<\infty.

In the
1
-dimensional case this problem was investigated by Feller
[
12
]
in 1946 who showed that the classical Kolmogorov-Erdős-Petrowski integral test (= the 1-dimensional version of the above upper-lower class test) remains valid if

\mathbb{E}X_{1}^{2}I\{|X_{1}|\geq t\}=O((LLt)^{-1})\mbox{ as }t\to\infty.

(1.2)

Moreover, he proved that this upper-lower class test holds in general if one replaces
\sqrt{n}
by
\sqrt{B_{n}}
where
B_{n}=\sum_{j=1}^{n}\sigma_{j}^{2}
and
\sigma_{j}^{2}=\mathbb{E}X_{1}^{2}I\{|X_{1}|\leq\sqrt{j}/(LLj)^{4}\},j\geq 1
, that is, we have

\mathbb{P}\{|S_{n}|\leq\sqrt{B_{n}}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }0

according as

\sum_{n=1}^{\infty}n^{-1}\phi_{n}\exp(-\phi_{n}^{2}/2)<\infty\mbox{ or}=\infty.

Feller’s proof was based on a skilful truncation argument which unfortunately only worked for random variables having distributions which are symmetric about zero. It was an open problem for quite some time whether Feller’s results also hold in the non-symmetric case. This question was settled in
[
6
]
where an extension of Feller’s truncation arguments to the non-symmetric case was found.

Feller also stated an interesting conjecture in his paper
[
12
]
, namely that the above upper-lower class test still holds if one replaces
B_{n}
by
n\sigma_{n}^{2}
.

This conjecture has finally been proven in
[
4
]
leading to the following result in dimension 1,

\mathbb{P}\{|S_{n}|\leq\sigma_{n}\sqrt{n}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }0

(1.3)

according as

\sum_{n=1}^{\infty}n^{-1}\phi_{n}\exp(-\phi_{n}^{2}/2)<\infty\mbox{ or}=\infty.

Moreover, it was shown in
[
4
]
that (
1.3
) holds if

\sigma_{n}^{2}=\mathbb{E}X_{1}^{2}I\{|X_{1}|\leq c_{n}\}

where
c_{n}
can be any non-decreasing sequence of positive real numbers satisfying for a suitable sequence
\epsilon_{n}\to 0
and large
n,

\exp(-(Ln)^{\epsilon_{n}})\leq c_{n}/\sqrt{n}\leq\exp((Ln)^{\epsilon_{n}})

(1.4)

From this result (and also from Feller’s original result) it easily follows that the Kolmogorov-Erdős-Petrowski upper-lower class test is applicable for sums
S_{n}
of i.i.d. random variables which satisfy condition (
1.2
). If this condition is not satisfied the sums
S_{n}
are in a certain sense
smaller
than sums of i.i.d normal random variables. There are examples where, for instance, the sequence
\sigma\sqrt{2nLLn}

belongs to the upper class for
|S_{n}|.

We return to the
d
-dimensional case:

Feller’s upper-lower class test (
1.3
) was actually obtained in
[
4
]
as a corollary to a
d
-dimensional result. To formulate this result we need some extra notation: we are now assuming that
X_{n}=(X_{n}^{(1)},\ldots,X_{n}^{(d)})
are i.i.d. mean zero random vectors such that
\mathbb{E}|X_{1}|^{2}<\infty
and we define a sequence
\Gamma_{n}
of symmetric non-negative definite matrices as follows,

\Gamma_{n}^{2}=\left[\mathbb{E}X_{1}^{(i)}X_{1}^{(j)}I\{|X_{1}|\leq c_{n}\}\right]_{1\leq i,j\leq d},

(1.5)

where again
c_{n},n\geq 1
is a non-decreasing sequence of positive real numbers satisfying condition (
1.4
) for some sequence
\epsilon_{n}\to 0.

Then we clearly have
\Gamma_{n}^{2}\to\mathrm{Cov}(X_{1})
and assuming that this latter matrix is positive definite we can assume w.l.o.g. that this is also the case for the matrices
\Gamma_{n}
.

Theorem B (
[
4
]
)

Let
X_{n},n\geq 1
be i.i.d. mean zero random vectors in
\mathbb{R}^{d}
with
\mathbb{E}|X_{1}|^{2}<\infty
and
\mathrm{Cov}(X_{1})=\Gamma^{2},
where
\Gamma
is a symmetric positive definite (d,d)-matrix.
Let
c_{n}
be a non-decreasing sequence of positive real-numbers satisfying condition (
1.4
) for large
n
and let
\Gamma_{n}
be defined as in (
1.5
).
Then we have for any non-decreasing sequence
\phi_{n}
of positive numbers,

\mathbb{P}\{|\Gamma_{n}^{-1}S_{n}|\leq\sqrt{n}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }=0

according as

\sum_{n=1}^{\infty}n^{-1}\phi^{d}_{n}\exp(-\phi_{n}^{2}/2)<\infty\mbox{ or}=\infty.

Letting
\lambda_{n}(\Lambda_{n})
be the smallest (largest) eigenvalue of
\Gamma_{n},n\geq 1
we can infer from Theorem B,

\sum_{n=1}^{\infty}n^{-1}\phi^{d}_{n}\exp(-\phi_{n}^{2}/2)<\infty\Rightarrow\mathbb{P}\{|S_{n}|\leq\Lambda_{n}\sqrt{n}\phi_{n}\mbox{ eventually}\}=1

(1.6)

and

\sum_{n=1}^{\infty}n^{-1}\phi^{d}_{n}\exp(-\phi_{n}^{2}/2)=\infty\Rightarrow\mathbb{P}\{|S_{n}|>\lambda_{n}\sqrt{n}\phi_{n}\mbox{ infinitely often}\}=1,

(1.7)

which clearly implies the upper-lower class test (
1.3
) in the 1-dimensional case.

In the higher-dimensional case this result provides however only a partial answer. Though the lower class part of this result holds for any covariance matrix, it is only interesting if the covariance matrix
\Sigma=\Gamma^{2}
of
X_{1}
is a multiple of the identity matrix. Otherwise,
\lambda_{n}
will converge to the smallest eigenvalue of the matrix
\Gamma
which is strictly smaller then the largest eigenvalue of
\Gamma
. In this case (
1.7
) gives us less information than (
1.1
).

This has been remedied in
[
3
]
where the following result was proven:

Let
\Lambda_{n}=\lambda_{n,1}\geq\ldots\geq\lambda_{n,d}=\lambda_{n}
be the
the eigenvalues of
\Gamma_{n}
arranged in a non-decreasing order and taking into account the multiplicities. If
d_{1}
denotes the multiplicity of the largest eigenvalue of
\Gamma,

we have

\sum_{n=1}^{\infty}n^{-1}\phi^{d_{1}}_{n}\exp(-\phi_{n}^{2}/2)<\infty\Rightarrow\mathbb{P}\{|S_{n}|\leq\lambda_{n,1}\sqrt{n}\phi_{n}\mbox{ eventually}\}=1

(1.8)

and

\sum_{n=1}^{\infty}n^{-1}\phi^{d_{1}}_{n}\exp(-\phi_{n}^{2}/2)=\infty\Rightarrow\mathbb{P}\{|S_{n}|>\lambda_{n,d_{1}}\sqrt{n}\phi_{n}\mbox{ infinitely often}\}=1.

(1.9)

If
d_{1}=1
this gives a complete upper-lower class test for
|S_{n}|.
Moreover, it implies the
d
-dimensional version of Feller’s result under condition (
1.2
) which is due to
[
5
]
, namely that the upper-lower class test of Theorem A applies if

\mathbb{E}\langle v,X_{1}\rangle^{2}I\{|\langle v,X_{1}\rangle|>t\}=O((LLt)^{-1})\mbox{ as }t\to\infty

(1.10)

for all vectors
v
in the eigenspace of
\Sigma
determined by its largest eigenvalue
\sigma^{2}.

The purpose of the present paper is to completely solve the problem by establishing a general upper-lower class test for the
d
-dimensional version of the Hartman-Wintner LIL.

As in
[
3
]

a crucial tool for proving this upper-lower class test is the following strong invariance principle (see Theorem 2.3 in
[
4
]
).

Theorem C

Let
\{X_{n}:n\geq 1\}
and
\Gamma_{n},n\geq 1
be as in Theorem B. If the underlying p-space
(\Omega,\mathcal{F},\mathbb{P})
is rich enough, one can construct independent
\mathcal{N}(0,I)
-distributed random vectors
Z_{n},n\geq 1
such that we have for the sums

T_{n}=\sum_{j=1}^{n}Z_{j},

(a)

S_{n}-\Gamma\;T_{n}=o(\sqrt{nLLn})\mbox{ as }n\to\infty\mbox{ with prob. 1}

(b)

\mathbb{P}\{|S_{n}-\Gamma_{n}\;T_{n}|\geq 2\sqrt{n}/LLn,|S_{n}|\geq\frac{4}{3}\|\Gamma\|\sqrt{nLLn}\mbox{ infinitely often}\}=0

(c)

\mathbb{P}\{|S_{n}-\Gamma_{n}\;T_{n}|\geq 2\sqrt{n}/LLn,|\Gamma\,T_{n}|\geq\frac{4}{3}\|\Gamma\|\sqrt{nLLn}\mbox{ infinitely often}\}=0

From Theorem C it follows that
the lower (upper) class of
|S_{n}|
matches the lower (upper) class of
|\Gamma_{n}T_{n}|
.

By definition of
\Gamma_{n}
we have
\Gamma^{2}_{n}\to\mathrm{Cov}(X_{1})=\Gamma^{2}
where
\Gamma
is symmetric and non-negative definite. This implies via Theorem X.1.1 in
[
2
]
that
\Gamma_{n}\to\Gamma
.

Further note that we have with probability one,

\limsup_{n\to\infty}|\Gamma_{n}T_{n}|/\sqrt{2nLLn}=\sigma.

whenever
\Gamma_{n}
converges to
\Gamma
with largest eigenvalue
\sigma.

So it is natural to ask whether one can prove an upper-lower class test for
|\Gamma_{n}T_{n}|
where
\Gamma_{n}
is a general convergent sequence and not only
one of the particular sequences determined by (
1.5
).

This is indeed the case, but we have to impose an extra condition on the sequence
\Gamma_{n}
to make sure that it does not fluctuate too much.

We
set for any
\alpha>0
and
k\geq 1,

\Delta_{k}(\alpha):=\max_{n_{k}(\alpha)\leq m\leq n\leq n_{k+1}(\alpha)}\|\Gamma^{2}_{n}-\Gamma^{2}_{m}\|,

(1.11)

where
n_{k}(\alpha)=[\exp(\alpha k/Lk)],k\geq 1
,
[x]
is the integer part of
x\in\mathbb{R}
and
\|\cdot\|
denotes the Euclidean matrix norm, that is
\|A\|=\sup_{|v|\leq 1}|Av|
.

Theorem 1.1
.

Assume that
d\geq 2.
Let
\Gamma_{n}
be a sequence of symmetric non-negative definite
(d,d)
-matrices which converges to a symmetric non-negative definite
(d,d)
-matrix
\Gamma\neq 0
. Assume that for any
\alpha>0,

\sum_{k=1}^{\infty}k^{-\delta}\Delta_{k}(\alpha)<\infty,\;\forall\delta>0.

(1.12)

If
T_{n}=\sum_{j=1}^{n}Z_{j},n\geq 1
where
\{Z_{n}\}
is a sequence of independent
\mathcal{N}(0,I)
-distributed random vectors, we have for any non-decreasing sequence
\phi_{n}
of positive real numbers,

\mathbb{P}\{|\Gamma_{n}T_{n}|\leq\sqrt{n}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }=0

according as

\sum_{n=1}^{\infty}\frac{\phi_{n}}{n\lambda_{n,1}}\prod_{i=2}^{d_{1}}\left(\frac{\lambda_{n,1}}{(\lambda_{n,1}^{2}-\lambda_{n,i}^{2})^{1/2}}\wedge\frac{\phi_{n}}{\lambda_{n,1}}\right)\exp\left(-\frac{\phi_{n}^{2}}{2\lambda_{n,1}^{2}}\right)<\infty\mbox{ or }=\infty,

where
\lambda_{n,1}\geq\ldots\geq\lambda_{n,d}
are the eigenvalues of
\Gamma_{n}
and
d_{1}
is the multiplicity of the largest eigenvalue of the matrix
\Gamma
.

As usual, we set
a/0=\infty,a>0
and
\prod_{i=2}^{1}a_{i}=1.

Combining Theorem
1.1
and Theorem C, we obtain the following multi-dimensional version of Feller’s upper-lower class test (
1.3
).

Corollary 1.1
.

Assume that
d\geq 2.
Let
X_{n},n\geq 1
be a sequence of i.i.d. random vectors with
\mathbb{E}|X_{1}|^{2}<\infty,

\mathbb{E}X_{1}=0
and non-negative definite covariance matrix
\Gamma^{2}\neq 0.
Then we have

\mathbb{P}\{|S_{n}|\leq\lambda_{n,1}\sqrt{n}\phi_{n}\mbox{ eventually}\}=1\mbox{ or }=0

according as

\sum_{n=1}^{\infty}\frac{\phi_{n}}{n}\prod_{i=2}^{d_{1}}\left(\frac{\lambda_{n,1}}{(\lambda_{n,1}^{2}-\lambda_{n,i}^{2})^{1/2}}\wedge\phi_{n}\right)\exp\left(-\frac{\phi_{n}^{2}}{2}\right)<\infty\mbox{ or }=\infty,

where
\lambda_{n,1}\geq\ldots\geq\lambda_{n,d}
are the eigenvalues of the matrices
\Gamma_{n},n\geq 1
defined as in (
1.5
) and
d_{1}
is the multiplicity of the largest eigenvalue of
\Gamma^{2}
.

Corollary
1.1
immediately implies an improved version of (
1.8
). Likewise, one can infer (
1.9

1.1

2
Some results on Gaussian random vectors

2.1
Bounds related to Zolotarev’s result

Let
Z:\Omega\to\mathbb{R}^{d}
be a
d
-dimensional
\mathcal{N}(0,I)
-distributed random vector. Then
|Z|^{2}
has a
a chi-square distribution with
d
degrees of freedom and we have an explicit formula for the
density
f_{d}
of
|Z|^{2}
, namely,

f_{d}(z)=C_{0}z^{d/2-1}\exp(-z/2),z>0,

(2.1)

where
C_{0}=C_{0}(d)=2^{-d/2}\Gamma(d/2)^{-1}.

This implies via partial integration that there exist positive constants
C_{1}
and
C_{2}
depending on
d
only such that

C_{1}t^{d-2}\exp(-t^{2}/2)\leq\mathbb{P}\{|Z|\geq t\}\leq C_{2}t^{d-2}\exp(-t^{2}/2),t\geq 2d.

(2.2)

Consider now more generally a random vector
Y:\Omega\to\mathbb{R}^{d}
having an
\mathcal{N}(0,\Gamma^{2})
-distribution where
\Gamma\neq 0
is a general non-negative definite matrix.
Let
\{e_{1},\ldots,e_{d}\}
be an orthonormal basis of
\mathbb{R}^{d}
consisting of eigenvectors corresponding to the eigenvalues
\lambda_{1}\geq\lambda_{2}\geq\ldots\geq\lambda_{d}
of
\Gamma
. Then we clearly have

Y=\sum_{i=1}^{d}\langle Y,e_{i}\rangle e_{i}:=\sum_{i=1}^{d}\lambda_{i}\eta_{i}e_{i},

(2.3)

where
\eta_{i},1\leq i\leq d
are independent 1-dimensional standard normal random variables.
Moreover it follows that

|Y|^{2}=\sum_{i=1}^{d}\lambda_{i}^{2}\eta_{i}^{2}

(2.4)

Due to a classical result of Zolotarev
[
14
]
we have for the density
h
of
|Y|^{2}

h(z)\sim K(\Gamma^{2})\lambda_{1}^{-2}f_{d_{1}}(z/\lambda_{1}^{2})\mbox{ as }z\to\infty,

(2.5)

where

K(\Gamma^{2})=\prod_{i=d_{1}+1}^{d}(1-\lambda_{i}^{2}/\lambda_{1}^{2})^{-1/2}

and
d_{1}
is the multiplicity of the largest eigenvalue
\lambda_{1}
of
\Gamma
. If
\Gamma^{2}
is a diagonal matrix, we set
K(\Gamma^{2})=1
.

In view of (
2.5
) it is clear that the tail probabilities
\mathbb{P}\{|Y|\geq t\}
are of the same order as
\mathbb{P}\{|Z^{\prime}|\geq t/\lambda_{1}\}
for large
t
, where
Z^{\prime}
is a
d_{1}
-dimensional
\mathcal{N}(0,I)
-distributed random vector.

In order to obtain concrete bounds for
\mathbb{P}\{|Y|\geq t\}
, Einmahl (
[
7
]
) derived
the following inequalities for
h
(see Lemma 1 and Lemma 3(b) in
[
7
]
)

h(z)\geq\frac{1}{4}K(\Gamma^{2})f_{d_{1}}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z\geq 2d_{1}\mathbb{E}[|Y|^{2}]/(1-\lambda_{d_{1}+1}^{2}/\lambda_{1}^{2})

(2.6)

and moreover if
d_{1}\geq 2,

h(z)\leq K(\Gamma^{2})f_{d_{1}}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0.

(2.7)

We still need an upper bound for
h
if
d_{1}=1
. The bound given in Lemma 3(a) of
[
7
]
is not sufficient for our present purposes.

Lemma 2.1
.

Assume that
d\geq 2
and let
Y
be an
\mathcal{N}(0,\Gamma^{2})
-distributed random vector
where the largest eigenvalue
\lambda_{1}^{2}
of
\Gamma^{2}
has multiplicity 1. Then we have for the density
h
of
|Y|^{2}
,

h(z)\leq C_{3}K(\Gamma^{2})f_{1}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0,

(2.8)

where
C_{3}=C_{3}(d)>1
is a constant depending on
d
only.

Proof.

To simplify notation we set
\rho_{i}^{2}=\lambda_{i}^{2}/\lambda_{1}^{2}<1,2\leq i\leq d.

(i) We first look at the case where the eigenvalue
\lambda_{2}^{2}
has multiplicity
d-1
so that there are only two different eigenvalues.
In this case it follows from (
2.4
) that

|Y|^{2}/\lambda_{1}^{2}=\eta^{2}_{1}+\rho_{2}^{2}R_{2},

where the random variables
\eta_{1}^{2}
and
R_{2}=\sum_{i=2}^{d}\eta_{i}^{2}
are independent and
have chi-square distributions with
1
and
d_{2}:=d-1
degrees of freedom, respectively.

Consequently,
\eta_{1}^{2}
and
\rho_{2}^{2}R_{2}
have densities
f_{1}
and
y\mapsto f_{d_{2}}(y/\rho_{2}^{2})/\rho_{2}^{2}
, respectively.

Applying the convolution formula we see that the density of
|Y|^{2}/\lambda_{1}^{2}
is equal to

g(z,\rho_{2},d_{2}):=\rho_{2}^{-2}\int_{0}^{z}f_{1}(z-y)f_{d_{2}}(y/\rho_{2}^{2})dy,z\geq 0.

We can infer that

\displaystyle\frac{g(z,\rho_{2},d_{2})}{f_{1}(z)}=\frac{z^{d_{2}/2-1}}{2^{d_{2}/2}\Gamma(d_{2}/2)\rho_{2}^{d_{2}}}\int_{0}^{z}(1-y/z)^{-1/2}(y/z)^{d_{2}/2-1}e^{-(\rho_{2}^{-2}-1)y/2}dy

\displaystyle\leq

\displaystyle\frac{1}{2^{d_{2}/2}\Gamma(d_{2}/2)\rho_{2}^{d_{2}}}\bigg[\sqrt{2}\int_{0}^{z/2}\frac{y^{d_{2}/2-1}}{e^{(\rho_{2}^{-2}-1)y/2}}dy

\displaystyle\hskip 85.35826pt+\frac{z^{d_{2}/2}}{e^{(\rho_{2}^{-2}-1)z/4}}\int_{1/2}^{1}t^{d_{2}/2-1}(1-t)^{-1/2}dt\bigg]

\displaystyle\leq

\displaystyle\frac{1}{2^{d_{2}/2}\Gamma(d_{2}/2)\rho_{2}^{d_{2}}}\left[\sqrt{2}\int_{0}^{\infty}\frac{y^{d_{2}/2-1}}{e^{(\rho_{2}^{-2}-1)y/2}}dy+\frac{z^{d_{2}/2}}{e^{(\rho_{2}^{-2}-1)z/4}}B(1/2,d_{2}/2)\right]

\displaystyle=

\displaystyle(1-\rho_{2}^{2})^{-d_{2}/2}\left[\sqrt{2}+\left(z(\rho_{2}^{-2}-1)/2\right)^{d_{2}/2}e^{-(\rho_{2}^{-2}-1)z/4}\frac{\Gamma(1/2)}{\Gamma((d_{2}+1)/2)}\right]

Recall that we have for the beta function

B(\alpha_{1},\alpha_{2}):=\int_{0}^{1}t^{\alpha_{1}-1}(1-t)^{\alpha_{2}-2}dt=\frac{\Gamma(\alpha_{1})\Gamma(\alpha_{2})}{\Gamma(\alpha_{1}+\alpha_{2})},\alpha_{1},\alpha_{2}>0.

Using that
\Gamma(1/2)=\sqrt{\pi}
and

t^{d_{2}/2}e^{-t/2}\leq(d_{2}/e)^{d_{2}/2},t>0
,
we find that

g(z,\rho_{2},d_{2})\leq C_{4}(d_{2})(1-\rho_{2}^{2})^{-d_{2}/2}f_{1}(z),

where
C_{4}(d_{2})=\sqrt{2}+\sqrt{\pi}(d_{2}/e)^{d_{2}/2}/\Gamma((d_{2}+1)/2).

As we have
h(z)=g(z/\lambda_{1}^{2},\rho_{2},d_{2})/\lambda_{1}^{2},z>0
and
K(\Gamma^{2})=(1-\rho_{2}^{2})^{-d_{2}/2}
in this case, we obtain the assertion if there are only two different eigenvalues.

(ii) Suppose now that there are three different eigenvalues
\lambda_{1}^{2}>\lambda_{2}^{2}>\lambda_{d}^{2}
with respective multiplicities
1,d_{2}
and
d_{3}
so that
d_{2}+d_{3}=d-1.
Then:

|Y|^{2}/\lambda_{1}^{2}=\eta_{1}^{2}+\rho_{2}^{2}\sum_{i=2}^{d_{2}+1}\eta_{i}^{2}+\rho_{d}^{2}\sum_{i=d_{2}+2}^{d}\eta_{i}^{2}=:(\eta^{2}_{1}+\rho_{2}^{2}R_{2})+\rho_{d}^{2}R_{3},

where we already know by (i) that the density
h_{1}
of
\eta^{2}_{1}+\rho_{2}^{2}R_{2}
satisfies

h_{1}(z)\leq C_{4}(d_{2})(1-\rho_{2}^{2})^{-d_{2}/2}f_{1}(z),z>0.

Denoting the density of
|Y|^{2}/\lambda_{1}^{2}
by
h_{2}
, we have,

\displaystyle h_{2}(z)/f_{1}(z)

\displaystyle=

\displaystyle\rho_{d}^{-2}\int_{0}^{z}h_{1}(z-y)f_{d_{3}}(y/\rho_{d}^{2})dy/f_{1}(z)

\displaystyle\leq

\displaystyle C_{4}(d_{2})(1-\rho_{2}^{2})^{-d_{2}/2}g(z,\rho_{d},d_{3})

\displaystyle\leq

\displaystyle C_{4}(d_{2})C_{4}(d_{3})(1-\rho_{2}^{2})^{-d_{2}/2}(1-\rho_{d}^{2})^{-d_{3}/2}.

It follows that

h(z)=h_{2}(z/\lambda_{1}^{2})/\lambda_{1}^{2}\leq C_{4}(d_{2})C_{4}(d_{3})K(\Gamma^{2})f_{1}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0.

(iii) If
\Gamma^{2}
has
r
different eigenvalues
\lambda^{2}_{i}
with multiplicities
d_{1}=1
and
d_{i},2\leq i\leq r
we get via induction:

h(z)\leq\prod_{i=2}^{r}C_{4}(d_{i})K(\Gamma^{2})f_{1}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0.

Setting
C_{3}(d)=\max\{\prod_{i=2}^{r}C_{4}(d_{i}):d_{2}+\ldots+d_{r}=d-1\}
the assertion of the lemma follows.
∎

Integrating the inequalities (
2.6
), (
2.7
) and (
2.8
), one obtains upper and lower bounds for the probabilities
\mathbb{P}\{|Y|\geq t\}
, but the lower bound is only valid if

|t|\geq\sqrt{2d_{1}}\mathbb{E}[|Y|^{2}]^{1/2}/(1-\lambda_{d_{1}+1}^{2}/\lambda_{1}^{2})^{1/2}.

This can be a problem if one looks at a sequence
Y_{n}:\Omega\to\mathbb{R}^{d}
of random vectors such that
Y_{n}
is
\mathcal{N}(0,\Gamma_{n}^{2})
-distributed and where

\Gamma_{n}\to\Gamma

for non-negative definite symmetric matrices
\Gamma_{n},n\geq 1
and
\Gamma
.

Let
\lambda_{n,1}\geq\ldots\geq\lambda_{n,d}
be the eigenvalues of
\Gamma_{n},n\geq 1
.
Then we have as
n\to\infty,

\lambda_{n,i}\to\lambda_{i},1\leq i\leq d,

(2.9)

where
\lambda_{1}\geq\ldots\geq\lambda_{d}
are the eigenvalues of
\Gamma
. (For a proof see, for instance, Lemma A.1 in
[
7
]
.)

The multiplicity
d_{n,1}
of the largest eigenvalue of
\Gamma_{n}
can be different from the multiplicity
d_{1}
of the largest eigenvalue
\lambda_{1}
of
\Gamma
and we do not have necessarily that
d_{n,1}\to d_{1}
.
Moreover, it is possible that
(1-\lambda_{n,d_{n,1}+1}^{2}/\lambda_{n,1}^{2})\to 0
so that we do not always have a lower bound for
\mathbb{P}\{|Y_{n}|\geq t\}
if
t
is small.

2.2
Better bounds

To overcome this difficulty we define for any given
t\geq 3d\lambda_{1}
a regularized version
Y_{t}:\Omega\to\mathbb{R}^{d}
of the random vector
Y:\Omega\to\mathbb{R}^{d}
where we merge all eigenspaces determined by the eigenvalues of
\Gamma
which are sufficiently close to the largest eigenvalue of
\Gamma
.

Let
\{e_{1},\ldots,e_{d}\}\subset\mathbb{R}^{d}
and
\eta_{1},\ldots,\eta_{d}:\Omega\to\mathbb{R}
be defined as in (
2.3
).

We set

Y_{t}=\sum_{i=1}^{\tilde{d}}\lambda_{1}\eta_{i}e_{i}+\sum_{i=\tilde{d}+1}^{d}\lambda_{i}\eta_{i}e_{i},

(2.10)

where

\tilde{d}=\tilde{d}(t)=\max\{1\leq i\leq d:\lambda_{1}^{2}-\lambda_{i}^{2}\leq 4d^{2}\lambda_{1}^{4}t^{-2}\}.

Since we are assuming that
t\geq 3d\lambda_{1},
we have in particular

\lambda^{2}_{\tilde{d}}\geq\lambda^{2}_{1}/2.

(2.11)

It is easy to see from the above definition that
Y_{t}
is normally distributed with mean zero.
Writing the covariance matrix of
Y_{t}
as
\Gamma_{t}^{2}
, where
\Gamma_{t}
is symmetric and non-negative definite, the eigenvalues
\lambda_{t,1}\geq\ldots\geq\lambda_{t,d}
of the matrix
\Gamma_{t}
are related to the eigenvalues of
\Gamma
as follows,

\lambda_{t,i}=\lambda_{1},1\leq i\leq\tilde{d}

and if
\tilde{d}<d
, we further have

\lambda_{t,i}=\lambda_{i},\tilde{d}<i\leq d.

Note in particular that the largest eigenvalue of
\Gamma_{t}
has multiplicity
\tilde{d}
.

Moreover, we trivially have,

|Y|^{2}\leq|Y_{t}|^{2}

(2.12)

Letting
h
and
h_{t}
be the densities of
|Y|^{2}
and
|Y_{t}|^{2},
respectively,
we can infer from Lemma 2(b) in
[
7
]
and (
2.11
) that

h(z)\geq h_{t}(z)\exp(-8d^{3}z/t^{2}),z>0.

(2.13)

Lemma 2.2
.

Assume that
t\geq 3d\lambda_{1}
and that
Y_{t}
is defined as above. Then the following holds:

(i)

If
0<\delta\leq t/4,

we have:

\mathbb{P}\{|Y_{t}|\geq t+\delta\}\leq 4C_{3}e^{d/4}\exp(-t\delta/\lambda_{1}^{2})\mathbb{P}\{|Y_{t}|\geq t\}

(2.14)

\mathbb{P}\{|Y_{t}|\geq t-\delta\}\leq 6C_{3}\exp(t\delta/\lambda_{1}^{2})\mathbb{P}\{|Y_{t}|\geq t\}

(2.15)

(ii)

If
t\geq C_{5}\lambda_{1}
, where
C_{5}=4\log(8C_{3})^{1/2}\vee 3d
and
\beta=\lambda_{1}^{2}(\log(8C_{3})+d/4),
we have:

\mathbb{P}\{|Y_{t}|\geq t\}\leq 2\mathbb{P}\{t\leq|Y_{t}|\leq t+\beta/t\}

(2.16)

Proof.

(i)
If
\tilde{d}<d

we have by (
2.7
) and Lemma
2.1
,

h_{t}(z)\leq C_{3}(\tilde{d})K(\Gamma_{t}^{2})f_{\tilde{d}}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0.

(2.17)

This is also correct if
d=\tilde{d}
and
\Gamma_{t}
is a diagonal matrix. Then we have
K(\Gamma_{t}^{2})=1
and the inequality is trivial since
C_{3}(d)>1
and
h_{t}(z)=f_{\tilde{d}}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z>0.

If
\tilde{d}<d
we have,

2\tilde{d}\mathbb{E}[|Y_{t}|^{2}]/(1-\lambda^{2}_{\tilde{d}+1}/\lambda^{2}_{1})\leq 2d^{2}\lambda_{1}^{4}/(\lambda_{1}^{2}-\lambda_{\tilde{d}+1}^{2})\leq t^{2}/2

so that

h_{t}(z)\geq(K(\Gamma_{t}^{2})/4)f_{\tilde{d}}(z/\lambda_{1}^{2})/\lambda_{1}^{2},z\geq t^{2}/2

(2.18)

which of course also holds if
\tilde{d}=d.

Further note that

\mathbb{P}\{|Y_{t}|\geq t+\delta\}\leq\mathbb{P}\{|Y_{t}|^{2}\geq t^{2}+2t\delta\}=\int_{t^{2}}^{\infty}h_{t}(z+2t\delta)dz.

Combining inequalities (
2.17
) and (
2.18
), we get for
z\geq t^{2},

\displaystyle h_{t}(z+2\delta t)/h_{t}(z)

\displaystyle\leq

\displaystyle 4C_{3}(\tilde{d})(1+2\delta/t)^{d/2}\exp(-t\delta/\lambda_{1}^{2})

\displaystyle\leq

\displaystyle 4C_{3}(\tilde{d})\exp(d/4)\exp(-t\delta/\lambda_{1}^{2}).

C_{3}(d)
is monotone in
d
by definition and we see that (
2.14
) holds.

To prove (
2.15
) we note that

\mathbb{P}\{|Y_{t}|\geq t-\delta\}\leq\mathbb{P}\{|Y_{t}|^{2}\geq t^{2}-2t\delta\}=\int_{t^{2}}^{\infty}h_{t}(z-2t\delta)dz.

Since
\delta\leq t/4,
we get for
z\geq t^{2},

h_{t}(z-2\delta t)/h_{t}(z)\leq 4C_{3}(\tilde{d})(1-2\delta/t)^{-1/2}\exp(t\delta/\lambda_{1}^{2})\leq 6C_{3}(d)\exp(t\delta/\lambda_{1}^{2})

and we see that (
2.15
) holds as well.

(ii) Applying (
2.14
) with
\delta=\beta/t=\lambda_{1}^{2}(\log(8C_{3})+d/4)/t
, we see that

\mathbb{P}\{|Y_{t}|\geq t\ +\beta/t\}\leq\mathbb{P}\{|Y_{t}|\geq t\}/2,

where
\delta\leq t/4
since we are assuming that
t\geq C_{5}\lambda_{1}.

∎

Lemma 2.3
.

Let
Y
be an
\mathcal{N}(0,\Gamma^{2})
-distributed random vector and let for any given
t\geq C_{5}\lambda_{1}
the random vector
Y_{t}
be defined as in (
2.10
).

(i)

We have for any

\mathbb{P}\{|Y|\geq t-\gamma\lambda_{1}^{2}/t\}\leq 6C_{3}e^{\gamma}\mathbb{P}\{|Y_{t}|\geq t\}.

(ii)

Let
\beta
be chosen as in Lemma
2.2
(ii). Then we also have:

\mathbb{P}\{|Y_{t}|\geq t\}\leq 2\exp(16d^{3})\mathbb{P}\{t\leq|Y|\leq t+\beta/t\}.

Proof.

(i) By relation (
2.12
) we trivially have
for any

\mathbb{P}\{|Y|\geq y\}\leq\mathbb{P}\{|Y_{t}|\geq y\}.

Applying inequality (
2.15
) with
\delta=\gamma\lambda_{1}^{2}/t,
we can conclude that

\mathbb{P}\{|Y_{t}|\geq t-\gamma\lambda_{1}^{2}/t\}\leq 6C_{3}e^{\gamma}\mathbb{P}\{|Y_{t}|\geq t\}.

(ii) Observe that we have by (

)

\mathbb{P}\{|Y_{t}|\geq t\}\leq 2\mathbb{P}\{t\leq|Y_{t}|\leq t+\beta/t\}.

Recalling that
\beta/t\leq t/4
we see that
(t+\beta/t)^{2}\leq 2t^{2}
if
t\geq C_{5}\lambda_{1}.

Finally, relation (
2.13
) implies that

\displaystyle\mathbb{P}\{t\leq|Y_{t}|\leq t+\beta/t\}

\displaystyle\leq

\displaystyle\int_{t^{2}}^{(t+\beta/t)^{2}}h_{t}(z)dz\leq\exp(16d^{3})\int_{t^{2}}^{(t+\beta/t)^{2}}h(z)dz

\displaystyle=

\displaystyle\exp(16d^{3})\mathbb{P}\{t\leq|Y|\leq t+\beta/t\}.

and the lemma has been proven.
∎

Combining the two above lemmas, we obtain the main result of this section:

Theorem 2.1
.

Let
Y:\Omega\to\mathbb{R}^{d}
be an
\mathcal{N}(0,\Gamma^{2})
-distributed random vector where
\Gamma
is a symmetric non-negative definite matrix with eigenvalues
\lambda_{1}\geq\ldots\geq\lambda_{d}
.

Then we have for any
t\geq\tilde{C}_{1}\lambda_{1}

(i)

\mathbb{P}\{\left|Y\right|\geq t\}\leq\tilde{C}_{2}\prod_{i=2}^{d}\left\{\frac{\lambda_{1}}{(\lambda_{1}^{2}-\lambda_{i}^{2})^{1/2}}\wedge\frac{t}{\lambda_{1}}\right\}\frac{\lambda_{1}}{t}\exp\left(-\frac{t^{2}}{2\lambda_{1}^{2}}\right)

(ii)

\mathbb{P}\{|Y|\geq t\}\geq\tilde{C}_{3}\prod_{i=2}^{d}\left\{\frac{\lambda_{1}}{(\lambda_{1}^{2}-\lambda_{i}^{2})^{1/2}}\wedge\frac{t}{\lambda_{1}}\right\}\frac{\lambda_{1}}{t}\exp\left(-\frac{t^{2}}{2\lambda_{1}^{2}}\right)

(iii)

\mathbb{P}\{|Y|\geq t-\gamma\lambda_{1}^{2}/t\}\leq\tilde{C}_{4}e^{\gamma}\mathbb{P}\{t\leq|Y|\leq t+\tilde{C}_{5}\lambda_{1}^{2}/t\}
if
0\leq\gamma<t^{2}/(4\lambda_{1}^{2})

(iv)

\mathbb{P}\{t\leq|Y|\leq\ t+\tilde{C}_{5}\lambda_{1}^{2}/t\}\geq\tilde{C}_{6}\prod_{i=2}^{d}\left\{\frac{\lambda_{1}}{(\lambda_{1}^{2}-\lambda_{i}^{2})^{1/2}}\wedge\frac{t}{\lambda_{1}}\right\}\frac{\lambda_{1}}{t}\exp\left(-\frac{t^{2}}{2\lambda_{1}^{2}}\right)

where
\tilde{C}_{i}
,
1\leq i\leq 6
are positive constants depending on
d
only.

Proof.

To verify (i) we first note that

\mathbb{P}\{|Y|\geq t\}\leq\mathbb{P}\{|Y_{t}|\geq t\}=\int_{t^{2}}^{\infty}h_{t}(z)dz.

If
\tilde{d}<d
, it follows from Lemma
2.1
, (
2.7
) and (
2.2
) that the last integral is

\leq C_{2}C_{3}K(\Gamma_{t}^{2})(t/\lambda_{1})^{\tilde{d}-2}\exp(-t^{2}/2\lambda_{1}^{2}).

If
\tilde{d}=d
, the above bound follows directly from (
2.2
). (Recall that
K(\Gamma^{2})=1
if
\Gamma
is a diagonal matrix.)

By definition of
\tilde{d}
we further have,

K(\Gamma^{2}_{t})(t/(2d\lambda_{1}))^{\tilde{d}-1}=\prod_{i=2}^{d}\{\lambda_{1}/(\lambda_{1}^{2}-\lambda_{i}^{2})^{-1/2}\wedge t/(2d\lambda_{1})\},

(2.19)

which is

\leq\prod_{i=2}^{d}\{\lambda_{1}/(\lambda_{1}^{2}-\lambda_{i}^{2})^{-1/2}\wedge t/\lambda_{1}\}.

(ii) Combining relations (
2.18
) and (
2.2
), we can conclude that

\mathbb{P}\{|Y_{t}|\geq t\}\geq\frac{C_{1}}{4}K(\Gamma^{2}_{t})(t/\lambda_{1})^{\tilde{d}-2}\exp(-t^{2}/2\lambda_{1}^{2}).

where we assume w.l.o.g. that
C_{1}=C_{1}(d)
is non-increasing in
d
.

In view of (
2.19
) we have,

K(\Gamma^{2}_{t})(t/(2d\lambda_{1}))^{\tilde{d}-1}\geq 2^{-d}d^{-d}\prod_{i=2}^{d}\{\lambda_{1}/(\lambda_{1}^{2}-\lambda_{i}^{2})^{-1/2}\wedge t/\lambda_{1}\}.

Combining this inequality with the fact that

2\mathbb{P}\{|Y|\geq t\}\geq\exp(-16d^{3})\mathbb{P}\{|Y_{t}|\geq t\},

which follows from Lemma
2.3
(ii), we readily obtain (ii).

(iii) This part follows directly combining parts (i) and (ii) of Lemma
2.3
.

(iv) Set
\gamma=0
in (iii) and apply the lower bound given in (ii).
∎
