Abstract
We examine different generalizations of checking stack automata by allowing multiple input heads and multiple stacks, and characterize their computing power in terms of two-way multi-head finite automata and space-bounded Turing machines. For various models, we obtain hierarchies in terms of their computing power. Our characterizations and hierarchies expand or tighten some previously known results. We also discuss some decidability questions and the space/time complexity of the models.

Example 2.1

A classical example of a

Example 2.2

Proof 3.8

Call the

.

Let
S(n)
be a non-zero function.
A language

is accepted by a
2
-stack

-limited

{\mathsf{NTM}}
.

Proof 5.4
.

Let

space-bounded
{\mathsf{NTM}}
. We can assume without loss of

is an
{\mathsf{NTM}}
with a single read/write worktape that initially contains the input of size
n
, and can only grow to the right, since

allows at least linear space. Construct
a 2-stack
S(n)
-limited
2{\mathsf{NCSA}}

M
with stacks
S_{1}
(the unbounded stack)
and
S_{2}
(the
S(n)
-bounded stack) which,
when given an input

of length
n
, operates as follows:

1.

M
writes
ID_{1}\#\cdots\#ID_{s}
on stack
S_{1}
for some
nondeterministically
chosen configurations

of the worktape of
Z
(a configuration is a string

uqv
, where

is a string over the worktape alphabet of
Z

and

is a state and also the position of the read/write head), and
ID_{1}
is
an initial ID starting with the input encoded, and
ID_{s}

is an accepting

. It is clear that we can assume each ID is of the same length
m\leq nS(n)

by padding with blanks and later

2.

M
writes a unary string

on
S_{2}
, where

is nondeterministically
guessed.

3.

M
checks that each
ID
on
S_{1}
is of length
nt
.
This can be
done using the input of length
n
and stack
S_{2}
of length
t

to count up to
nt
.

4.

Finally,
M
checks that

is a valid successor of

of
Z

, again using the input
and stack
S_{2}
to repeatedly count to

thereby enabling the ability to check
that positions of ID

match ID

except close to the read/write head where it verifies that it is changing via a transition of

.

Note that if

It follows that in step (2) above, there is an

.

To prove the converse, we will use Proposition

(with

) and translation.

.

(this has only

), which operates as follows when given input

of

5.2

-Bounded Multi-Stack

In this subsection, we will consider

-bounded

-bounded machines, we also refer to these as linear-bounded.

Proposition 5.10
.

Let

. For every
(k+1)
-head
2{\mathsf{NFA}}

M
,
there is a
k
-stack linear-bounded
2{\mathsf{NCSA}}

such that

.

Proof 5.11
.

M^{\prime}
copies the input
x
into the
k
stacks and then simulates
M

using one head on the input and
k
heads on the
k
stacks.

This result holds for the deterministic case as well.

Unfortunately, the converse of Proposition
5.10

is unlikely, since multi-head
2{\mathsf{NFA}}
languages are
in
{\mathsf{NLOG}}
(which is a subset of
{\mathsf{P}}
)
but linear-bounded
{\mathsf{NCSA}}
s can accept
{\mathsf{NP}}
-complete
languages
[
20
]
(see also Proposition

involving homomorphisms.

A

is a homomorphism where for all

,

is in
\Gamma
.
A
\lambda
-free homomorphism

is one where

for all

.

Proposition 5.12
.

1.

Let
k\geq 2
. For every
k
-head
2{\mathsf{NFA}}

M

and letter-to-letter homomorphism

,
there is a
k
-stack linear-bounded
{\mathsf{NCSA}}

M^{\prime}
such that

.
(Note that if

,

accepts a regular set
and regular sets are closed under homomorphism, so

does not need a stack.)

2.

Let
k\geq 1
. For every
k
-stack linear-bounded
2{\mathsf{NCSA}}

M
,
there is a
(k+1)
-head
2{\mathsf{NFA}}

M^{\prime}
and a letter-to-letter

such that

.

Proof 5.13
.

For the first part,

when given input

,
guesses an input

to

(symbol-by-symbol)
and writes

into the
k

. Then

simulates

on

the

Note that

is a
k
-stack linear-bounded

(i.e., one-way).

For the second part, let

be a positive integer
such that the heights of the

is the input length.
Let
\Sigma
be the input alphabet of
M
. Assume that
the stacks have a common stack alphabet

.
The input to

will have

Clearly, we can partition each string

, where

.

We can then define a
(k+1)
-track of symbols
of the form

is in
\Sigma
and each

is
a string in
\Gamma^{*}
of length at most

.
Denote the set of all such symbols by

.

Now construct a
(k+1)
-head
2{\mathsf{NFA}}
which,
when given a string

in
\Gamma^{*}
,
first checks that the strings on tracks

1
to

Then

simulates the

using
one head to simulate the input head of

and the remaining

the
k

contains exactly the string

accepts if

Now let

to

.
It is straightforward to verify that

.

A letter-to-letter homomorphism is a special

\lambda
-free homomorphism. Clearly, Proposition

still holds if we replace letter-to-letter homomorphism to

\lambda
-free homomorphism.

[

({\mathsf{NSA}})

[

6
Conclusions

We studied several generalizations of checking stack automata
and characterized their computing power in terms of
two-way multi-head finite automata and space-bounded Turing machines.
Further, we proved hierarchies of these models with respect to their
recognition power in terms of the number of input heads and the number of checking stacks.
Our characterizations and hierarchy results expanded/tightened
some previously known results. We also investigated some space
complexity and decidability questions for the models introduced. Some
questions remain open, e.g., improving the stack-head trade-offs in the
conversions for some of the results.
