Abstract
We study two classic variants of block-structured integer programming. Two-stage stochastic programs are integer programs of the form { A i 𝐱 + D i 𝐲 i = 𝐛 i for all i = 1 , … , n } \{A_{i}{\mathbf{x}}+D_{i}{\mathbf{y}}_{i}={\mathbf{b}}_{i}\textrm{ for all }i=1,\ldots,n\} , where A i A_{i} and D i D_{i} are bounded-size matrices. Intuitively, this form corresponds to the setting when after setting a small set of global variables 𝐱 {\mathbf{x}} , the program can be decomposed into a possibly large number of bounded-size subprograms. On the other hand, n n -fold programs are integer programs of the form { ∑ i = 1 n C i 𝐲 i = 𝐚 and D i 𝐲 i = 𝐛 i for all i = 1 , … , n } \{{\sum_{i=1}^{n}C_{i}{\mathbf{y}}_{i}={\mathbf{a}}}\textrm{ and }D_{i}{\mathbf{y}}_{i}={\mathbf{b}}_{i}\textrm{ for all }i=1,\ldots,n\} , where again C i C_{i} and D i D_{i} are bounded-size matrices. This form is natural for knapsack-like problems, where we have a large number of variables partitioned into small-size groups, each group needs to obey some set of local constraints, and there are only a few global constraints that link together all the variables. A line of recent work established that the optimization problem for both two-stage stochastic programs and n n -fold programs is fixed-parameter tractable when parameterized by the dimensions of relevant matrices A i , C i , D i A_{i},C_{i},D_{i} and by the maximum absolute value of any entry appearing in the constraint matrix. A fundamental tool used in these advances is the notion of the Graver basis of a matrix, and this tool heavily relies on the assumption that all the entries of the constraint matrix are bounded. In this work, we prove that the parameterized tractability results for two-stage stochastic and n n -fold programs persist even when one allows large entries in the global part of the program. More precisely, we prove the following: • The feasibility problem for two-stage stochastic programs is fixed-parameter tractable when parameterized by the dimensions of matrices A i , D i A_{i},D_{i} and by the maximum absolute value of the entries of matrices D i D_{i} . That is, we allow matrices A i A_{i} to have arbitrarily large entries. • The linear optimization problem for n n -fold integer programs that are uniform – all matrices C i C_{i} are equal – is fixed-parameter tractable when parameterized by the dimensions of matrices C i C_{i} and D i D_{i} and by the maximum absolute value of the entries of matrices D i D_{i} . That is, we require that C i = C C_{i}=C for all i = 1 , … , n i=1,\ldots,n , but we allow C C to have arbitrarily large entries. In the second result, the uniformity assumption is necessary; otherwise the problem is 𝖭𝖯 \mathsf{NP} -hard already when the parameters take constant values. Both our algorithms are weakly polynomial: the running time is measured in the total bitsize of the input. In both results, we depart from the approach that relies purely on Graver bases. Instead, for two-stage stochastic programs, we devise a reduction to integer programming with a bounded number of variables using new insights about the combinatorics of integer cones. For n n -fold programs, we reduce a given n n -fold program to an exponential-size program with bounded right-hand sides, which we consequently solve using a reduction to mixed integer programming with a bounded number of integral variables.

All the abovementioned works, be it on two-stage stochastic or

•

The drawback of the Graver-based approach is that it heavily relies on the assumption that all the entries of the input matrices are (parametrically) bounded. Indeed, the norms of the elements of the Graver basis are typically at least as large as the entries, so lacking any upper bound on the latter renders the methodology inapplicable. This is in stark contrast with the results on fixed-parameter tractability of integer programming parameterized by the number of variables

The goal of this paper is to understand to what extent one can efficiently solve two-stage stochastic and

-fold programs
while allowing large entries on input.

Our contribution.

We prove that both the feasibility problem for two-stage stochastic programs and the optimization problem for uniform
n
-fold programs (that is, where
C_{1}=C_{2}=\ldots=C_{n}
) can be solved in fixed-parameter time when parameterized by the dimensions of the blocks and the maximum absolute value of any entry appearing in the diagonal blocks
D_{i}
. That is, we allow the entries of the global blocks (
A_{i}
and
C_{i}
, respectively) to be arbitrarily large, and in the case of
n
-fold programs, we require that all blocks
C_{i}
are equal. The statements below summarize our results. (
\|P\|
denotes the total bitsize of a program
P

Theorem 1
.

The feasibility problem for two-stage stochastic programs

can be solved in time
f(k,\max_{i}\|D_{i}\|_{\infty})\cdot\|P\|
for a computable function

, where
k
is the dimension of all the blocks

.

\lrcorner

Theorem 2
.

The optimization problem for
n
-fold programs

♣

that are uniform (that is, satisfy

for a computable function
f
, where

is the dimension of all the blocks
C_{i},D_{i}
.

\lrcorner

4
-block programs.

Finally, we would like to discuss another motivation for investigating two-stage stochastic and

-fold programs with large entries, namely the open question about the parameterized complexity of

-fold programs. It is an important problem in the area to determine whether the feasibility problem for

We observe that in the context of the feasibility problem for uniform

Observation 3
.

Suppose the feasibility problem for uniform

\lrcorner

Consequently, to approach the problem of fixed-parameter tractability of

We believe that the next natural step towards understanding the complexity of

Overview

In this section, we provide a technical overview of our results aimed at presenting the main ideas and new conceptual contributions.

2.1
Two-stage stochastic programming

We start with an overview on the proof of
theorem

1
. We will heavily rely on the combinatorics of integer and polyhedral cones, so let us recall basic definitions and properties.

Cones.

Consider an integer matrix
D
with
t
columns and
k
rows. The
polyhedral cone
spanned by
D
is the set
\mathsf{cone}(D)\coloneqq\{D{\mathbf{y}}\colon{\mathbf{y}}\in\mathbb{R}_{\geqslant 0}^{t}\}\subseteq\mathbb{R}_{\geqslant 0}^{k}
, or equivalently, the set of all vectors in
\mathbb{R}_{\geqslant 0}^{k}
expressible as nonnegative combinations of the columns of
D
. Within the polyhedral cone, we have the
integer cone
where we restrict attention to nonnegative integer combinations:
\mathsf{intCone}(D)\coloneqq\{D{\mathbf{y}}\colon{\mathbf{y}}\in\mathbb{Z}_{\geqslant 0}^{t}\}\subseteq\mathbb{Z}^{k}
. Finally, the
integer lattice
is the set
\mathsf{lattice}(D)\coloneqq\{D{\mathbf{y}}\colon{\mathbf{y}}\in\mathbb{Z}^{t}\}\subseteq\mathbb{Z}^{k}
which comprises all integer combinations of columns of
D
with possibly negative coefficients.

Clearly, not every integer vector in
\mathsf{cone}(D)
has to belong to
\mathsf{intCone}(D)
. It is not even necessarily the case that
\mathsf{intCone}(D)=\mathsf{cone}(D)\cap\mathsf{lattice}(D)
, as there might be vectors that can be obtained both as a nonnegative combination and as an integer combination of columns of
D
, but every such integer combination must necessarily contain negative coefficients. To see an example, note that in dimension
k=1
, this is the Frobenius problem: supposing all entries of
D
are positive integers, the elements of
\mathsf{intCone}(D)
are essentially all nonnegative numbers divisible by the gcd (greatest common divisor) of the entries of
D
, except that for small numbers there might be some aberrations: a positive integer of order
{\mathcal{O}}(\|D\|_{\infty}^{2})
may not be presentable as a nonnegative combination of the entries of
D
, even assuming it is divisible by the gcd of the entries of
D
.

However, the Frobenius example suggests that the equality
\mathsf{intCone}(D)=\mathsf{cone}(D)\cap\mathsf{lattice}(D)
is almost true, except for aberrations near the boundary of
\mathsf{cone}(D)
. We forge this intuition into a formal statement presented below that says roughly the following: if one takes a look at
\mathsf{intCone}(D)
at a large scale, by restricting attention to integer vectors
{\mathbf{v}}\in\mathbb{Z}^{k}
with fixed remainders of entries modulo some large integer
B
, then
\mathsf{intCone}(D)
behaves like a polyhedron. In the following, for a positive integer
B
and a vector
{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{k}
, we let
\Lambda_{\mathbf{r}}^{B}
be the set of all vectors
{\mathbf{v}}\in\mathbb{Z}^{k}
such that
{\mathbf{v}}\equiv{\mathbf{r}}\bmod B
, which means
v_{i}\equiv r_{i}\bmod B
for all
i\in\{1,\ldots,k\}
.

Theorem 4
(Reduction to Polyhedral Constraints, see
theorem

19
).

Let
D
be an integer matrix with
t
columns and
k
rows. Then there exists a positive integer
B
, computable from
D
, such that for every
{{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{k}}
, there exists a polyhedron
\mathcal{Q}_{\mathbf{r}}
such that

\Lambda_{\mathbf{r}}^{B}\cap\mathsf{intCone}(D)=\Lambda_{\mathbf{r}}^{B}\cap\mathcal{Q}_{\mathbf{r}}.

Moreover, a representation of such a polyhedron
\mathcal{Q}_{\mathbf{r}}
can be computed given
D
and
{\mathbf{r}}
.

\lrcorner

In other words,
theorem

4
states that if one fixes the remainders of entries modulo
B
, then membership in the integer cone can be equivalently expressed through a finite system of linear inequalities. Before we sketch the proof of
theorem

4
, let us discuss how to use this to solve two-stage stochastic programs.

The algorithm.

Consider a two-stage stochastic program
P=(A_{i},D_{i},{\mathbf{b}}_{i}\colon i\in\{1,\ldots,n\})
such that blocks
A_{i},D_{i}
are integer
k\times k
matrices and all entries of blocks
D_{i}
are bounded in absolute value by
\Delta
. The feasibility problem for
P
can be understood as the question about satisfaction of the following sentence, where all quantifications range over
\mathbb{Z}_{\geqslant 0}^{k}
:

\exists_{{\mathbf{x}}}\ \left(\bigwedge_{i=1}^{n}\exists_{{\mathbf{y}}_{i}}\ A_{i}{\mathbf{x}}+D_{i}{\mathbf{y}}_{i}={\mathbf{b}}_{i}\right),\quad\textrm{or equivalently,}\quad\exists_{{\mathbf{x}}}\ \left(\bigwedge_{i=1}^{n}\ {\mathbf{b}}_{i}-A_{i}{\mathbf{x}}\in\mathsf{intCone}(D_{i})\right).

(1)

Applying
theorem

4
to each matrix
D_{i}
yields a positive integer
B_{i}
. Note that there are only at most
(2\Delta+1)^{k^{2}}
different matrices
D_{i}
appearing in
P
, which also bounds the number of different integers
B_{i}
. By replacing all
B_{i}
s with their least common multiple, we may assume that
B_{1}=B_{2}=\ldots=B_{n}=B
. Note that
B
is bounded by a computable function of
\Delta
and
k
.

Consider a hypothetical solution
{\mathbf{x}},({\mathbf{y}}_{i}\colon i\in\{1,\ldots,n\})
to
P
.
We guess, by branching into
B^{k}
possibilities, a vector
{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{k}
such that
{\mathbf{x}}\equiv{\mathbf{r}}\bmod B
. Having fixed
{\mathbf{r}}
, we know how the vectors
{\mathbf{b}}_{i}-A_{i}{\mathbf{x}}
look like modulo
B
, hence by
theorem

4
, we may replace the assertion
{\mathbf{b}}_{i}-A_{i}{\mathbf{x}}\in\mathsf{intCone}(D_{i})
with the assertion
{\mathbf{b}}_{i}-A_{i}{\mathbf{x}}\in\mathcal{Q}_{{\mathbf{r}}_{i}}
, where
{\mathbf{r}}_{i}\in\{0,1,\ldots,B-1\}^{k}
is the unique vector such that
{\mathbf{b}}_{i}-A_{i}{\mathbf{r}}\equiv{\mathbf{r}}_{i}\bmod B
. Thus, (
1
) can be rewritten to the sentence

\bigvee_{{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{k}}\exists_{{\mathbf{x}}}\ \left({\mathbf{x}}\equiv{\mathbf{r}}\bmod B\right)\wedge\left(\bigwedge_{i=1}^{n}{\mathbf{b}}_{i}-A_{i}{\mathbf{x}}\in\mathcal{Q}_{{\mathbf{r}}_{i}}\right),

which is equivalent to

\bigvee_{{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{k}}\exists_{{\mathbf{x}}}\exists_{{\mathbf{z}}}\ \left({\mathbf{x}}=B\cdot{\mathbf{z}}+{\mathbf{r}}\right)\wedge\left(\bigwedge_{i=1}^{n}{\mathbf{b}}_{i}-A_{i}{\mathbf{x}}\in\mathcal{Q}_{{\mathbf{r}}_{i}}\right).

(2)

Verifying satisfiability of (
2
) boils down to solving
B^{k}
integer programs on
2k
variables
{\mathbf{x}}
and
{\mathbf{z}}
and linearly FPT many constraints, which can be done in linear fixed-parameter time using standard algorithms, for instance that of Kannan
[
26
]
.

We remark that the explanation presented above highlights that
theorem

4
can be understood as a quantifier elimination result in the arithmetic theory of integers. This may be of independent interest, but we do not pursue this direction in this work.

Reduction to polyhedral constraints.

We are left with sketching the proof of
theorem

4
. Let
\mathcal{Z}\coloneqq\Lambda_{\mathbf{r}}^{B}\cap\mathsf{intCone}(D)
. Our goal is to understand that
\mathcal{Z}
can be expressed as the points of
\Lambda_{\mathbf{r}}^{B}
that are contained in some polyhedron
\mathcal{Q}=\mathcal{Q}_{\mathbf{r}}
.

The first step is to understand
\mathsf{cone}(D)
itself as a polyhedron. This understanding is provided by a classic theorem of Weyl
[
45
]
: given
D
, one can compute a set of integer vectors
\mathcal{F}\subseteq\mathbb{Z}^{k}
such that

\mathsf{cone}(D)=\{{\mathbf{v}}\in\mathbb{R}^{k}\penalty\ |\penalty\ \langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant 0\textrm{ for all }{\mathbf{f}}\in\mathcal{F}\}.

Here,
\langle\cdot,\cdot\rangle
denotes the scalar product in
\mathbb{R}^{k}
. We will identify vectors
{\mathbf{f}}\in\mathcal{F}
with their associated linear functionals
{\mathbf{v}}\mapsto\langle{\mathbf{f}},{\mathbf{v}}\rangle
. Thus,
\mathsf{cone}(D)
comprises all vectors
{\mathbf{v}}
that have nonnegative evaluations on all functionals in
\mathcal{F}
. It is instructive to also think of the elements of
\mathcal{F}
as of the facets of
\mathsf{cone}(D)
understood as a polyhedron, where the functional associated with
{\mathbf{f}}\in\mathcal{F}
measures the distance from the corresponding facet.

Recall that in the context of
theorem

4
, we consider vectors of
\Lambda_{\mathbf{r}}^{B}
, that is, vectors
{\mathbf{v}}\in\mathbb{Z}^{k}
such that
{\mathbf{v}}\equiv{\mathbf{r}}\bmod B
. Then
\langle{\mathbf{f}},{\mathbf{v}}\rangle\equiv\langle{\mathbf{f}},{\mathbf{r}}\rangle\bmod B
for every
{\mathbf{f}}\in\mathcal{F}
, hence we can find a unique integer
p_{\mathbf{f}}\in\{0,1,\ldots,B-1\}
,
p_{\mathbf{f}}\equiv\langle{\mathbf{f}},{\mathbf{r}}\rangle\bmod B
, such that
\langle{\mathbf{f}},{\mathbf{v}}\rangle\equiv p_{\mathbf{f}}\bmod B
for all
{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}
. Now
\langle{\mathbf{f}},{\mathbf{v}}\rangle
is also nonnegative provided
{\mathbf{v}}\in\mathsf{cone}(D)
, hence

\langle{\mathbf{f}},{\mathbf{v}}\rangle\in\{p_{\mathbf{f}},p_{\mathbf{f}}+B,p_{\mathbf{f}}+2B,\ldots\}\qquad\textrm{for all }{\mathbf{f}}\in\mathcal{F}\textrm{ and }{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}\cap\mathsf{cone}(D).

Now comes the key distinction about the behavior of
{\mathbf{v}}\in\Lambda_{{\mathbf{r}}}^{B}\cap\mathsf{cone}(D)
with respect to
{\mathbf{f}}\in\mathcal{F}
: we say that
{\mathbf{f}}
is
tight
with respect to
{\mathbf{v}}
if
\langle{\mathbf{f}},{\mathbf{v}}\rangle=p_{\mathbf{f}}
, and is
not tight
otherwise, that is, if
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant p_{\mathbf{f}}+B
. Recall that in the context of
theorem

4
, we are eventually free to choose
B
to be large enough. Intuitively, this means that if
{\mathbf{f}}
is not tight for
{\mathbf{v}}
, then
{\mathbf{v}}
lies far from the facet corresponding to
{\mathbf{f}}
and there is a very large slack in the constraint posed by
{\mathbf{f}}
understood as a functional. On the other hand, if
{\mathbf{f}}
is tight with respect to
{\mathbf{v}}
, then
{\mathbf{v}}
is close to the boundary of
\mathsf{cone}(D)
at the facet corresponding to
{\mathbf{f}}
, and there is a potential danger of observing Frobenius-like aberrations at
{\mathbf{v}}
.

Thus, the set
\mathcal{R}\coloneqq\Lambda_{\mathbf{r}}^{B}\cap\mathsf{cone}(D)
can be partitioned into subsets
\{\mathcal{R}_{\mathcal{G}}\colon\mathcal{G}\subseteq\mathcal{F}\}
defined as follows:
\mathcal{R}_{\mathcal{G}}
comprises all vectors
{\mathbf{v}}\in\mathcal{R}
such that
\mathcal{G}
is exactly the set of functionals
{\mathbf{f}}\in\mathcal{F}
that are tight with respect to
{\mathbf{v}}
. Our goal is to prove that each set
\mathcal{R}_{\mathcal{G}}
behaves uniformly with respect to
\mathcal{Z}
: it is either completely disjoint or completely contained in
\mathcal{Z}
. To start the discussion, let us look at the particular case of
\mathcal{R}_{\mathcal{G}}
for
\mathcal{G}=\emptyset
. These are vectors that are deep inside
\mathsf{cone}(D)
, for which no functional in
\mathcal{F}
is tight. For these vectors, we use the following lemma, which is the cornerstone of our proof.

Lemma 5
(Deep-in-the-Cone Lemma, simplified version of
lemma

16
).

There exists a constant
M
, depending only on
D
, such that the following holds.
Suppose
{\mathbf{v}}\in\mathsf{cone}(D)\cap\mathbb{Z}^{k}
is such that
\langle{\mathbf{f}},{\mathbf{v}}\rangle>M
for all
{\mathbf{f}}\in\mathcal{F}
. Then
{\mathbf{v}}\in\mathsf{intCone}(D)
if and only if
{\mathbf{v}}\in\mathsf{lattice}(D)
.

\lrcorner

Proof
.

The left-to-right implication is obvious, hence let us focus on the right-to-left implication. Suppose then that
{\mathbf{v}}\in\mathsf{lattice}(D)
.

Let
{\mathbf{w}}=\sum_{{\mathbf{d}}\in D}L\cdot{\mathbf{d}}
, where the summation is over the columns of
D
and
L
is a positive integer to be fixed later. Observe that for every
{\mathbf{f}}\in\mathcal{F}
, we have
\langle{\mathbf{f}},{\mathbf{v}}-{\mathbf{w}}\rangle>M-L\cdot\sum_{{\mathbf{d}}\in D}\langle{\mathbf{f}},{\mathbf{d}}\rangle
. Therefore, if we choose
M
to be not smaller than
L\cdot\max_{{\mathbf{f}}\in\mathcal{F}}\|{\mathbf{f}}\|_{1}\cdot\|D\|_{\infty}
, then we are certain that
\langle{\mathbf{f}},{\mathbf{v}}-{\mathbf{w}}\rangle\geqslant 0
for all
{\mathbf{f}}\in\mathcal{F}
, and hence
{\mathbf{v}}-{\mathbf{w}}\in\mathsf{cone}(D)
. Consequently, we can write
{\mathbf{v}}-{\mathbf{w}}=D{\mathbf{y}}
for some
{\mathbf{y}}\in\mathbb{R}_{\geqslant 0}^{t}
. Let
{\mathbf{y}}^{\prime}\in\mathbb{Z}_{\geqslant 0}^{t}
be such that
y^{\prime}_{i}=\lfloor y_{i}\rfloor
for all
i\in\{1,\ldots,t\}
, and let
{\mathbf{v}}^{\prime}={\mathbf{w}}+D{\mathbf{y}}^{\prime}
. Then

\|{\mathbf{v}}-{\mathbf{v}}^{\prime}\|_{\infty}=\|D({\mathbf{y}}-{\mathbf{y}}^{\prime})\|_{\infty}\leqslant t\cdot\|D\|_{\infty}.

On the other hand, we clearly have
{\mathbf{v}}^{\prime}\in\mathsf{intCone}(D)
and by assumption,
{\mathbf{v}}\in\mathsf{lattice}(D)
. It follows that
{\mathbf{v}}-{\mathbf{v}}^{\prime}\in\mathsf{lattice}(D)
. From standard bounds, see e.g.
[
41
]
, it follows that there exists
{\mathbf{z}}\in\mathbb{Z}^{t}
with
{\mathbf{v}}-{\mathbf{v}}^{\prime}=D{\mathbf{z}}
such that
\|{\mathbf{z}}\|_{1}
is bounded by a function of
D
and
\|{\mathbf{v}}-{\mathbf{v}}^{\prime}\|_{\infty}
, which in turn is again bounded by a function of
D
as explained above. (Note here that
t
is the number of columns of
D
, hence it also depends only on
D
.) This means that if we choose
L
large enough depending on
D
, we are certain that
\|{\mathbf{z}}\|_{1}\leqslant L
. Now, it remains to observe that

{\mathbf{v}}={\mathbf{w}}+D{\mathbf{y}}^{\prime}+({\mathbf{v}}-{\mathbf{v}}^{\prime})=D(L\cdot\boldsymbol{1}+{\mathbf{y}}^{\prime}+{\mathbf{z}}),

where
\boldsymbol{1}
denotes the vector of
t
ones, and that all the entries of
L\cdot\boldsymbol{1}+{\mathbf{y}}^{\prime}+{\mathbf{z}}
are nonnegative integers. This proves that
{\mathbf{v}}\in\mathsf{intCone}(D)
.

\lrcorner

We remark that the statement of Lemma
5
actually follows from results present in the literature, concerning the notion of
diagonal Frobenius numbers
. See the work of Aliev and Henk
[
1
]
for a broader discussion and pointers to earlier works. As we will discuss in a moment, in this work we actually use a generalization of Lemma
5
.

Consider any
{\mathbf{u}},{\mathbf{v}}\in\mathcal{R}
. Since all the entries of
{\mathbf{u}}-{\mathbf{v}}
are divisible by
B
, it is not hard to prove the following: if we choose
B
to be a large enough factorial, then
{\mathbf{u}}\in\mathsf{lattice}(D)
if and only if
{\mathbf{v}}\in\mathsf{lattice}(D)
. Hence, from Lemma
5
it follows that
\mathcal{R}_{\emptyset}
is either entirely disjoint or entirely contained in
\mathcal{Z}
.

A more involved reasoning based on the same fundamental ideas, but using a generalization of Lemma
5
, yields the following lemma, which tackles also the case when some functionals of
\mathcal{F}
are tight with respect to the considered vectors.

Lemma 6
(see
2
).

Suppose
{\mathbf{u}},{\mathbf{v}}\in\mathcal{R}
are such that for every
{\mathbf{f}}\in\mathcal{F}
, if
{\mathbf{f}}
is tight with respect to
{\mathbf{u}}
, then
{\mathbf{f}}
is also tight with respect to
{\mathbf{v}}
. Then
{\mathbf{u}}\in\mathcal{Z}
implies
{\mathbf{v}}\in\mathcal{Z}
.

\lrcorner

We remark that the proof of
lemma

6
actually requires more work and more ideas than those presented in the proof of
lemma

5
. In essence, one needs to partition functionals that are tight with respect to
{\mathbf{u}}
into those that are very tight (have very small
p_{\mathbf{f}}
) and those that are only slightly tight (have relatively large
p_{\mathbf{f}}
) in order to create a sufficient gap between very tight and slightly tight functionals. Having achieved this, a delicate variant of the reasoning from the proof of
lemma

5
can be applied. It is important that whenever a functional
{\mathbf{f}}\in\mathcal{F}
is tight with respect to both
{\mathbf{u}}
and
{\mathbf{v}}
, we actually know that
\langle{\mathbf{f}},{\mathbf{u}}\rangle=\langle{\mathbf{f}},{\mathbf{v}}\rangle=p_{\mathbf{f}}
. Note that this is exactly the benefit achieved by restricting attention to the vectors of
\Lambda_{\mathbf{r}}^{B}
.

Using
lemma

6
, we can immediately describe how the structure of
\mathcal{Z}
relates to that of
\mathcal{R}
.

Corollary 7
(see
3
).

For every
\mathcal{G}\subseteq\mathcal{F}
, either
\mathcal{R}_{\mathcal{G}}\cap\mathcal{Z}=\emptyset
or
\mathcal{R}_{\mathcal{G}}\subseteq\mathcal{Z}
. Moreover, if
\mathcal{R}_{\mathcal{G}}\subseteq\mathcal{Z}
and
\mathcal{R}_{\mathcal{G}}
is non-empty, then
\mathcal{R}_{\mathcal{G}^{\prime}}\subseteq\mathcal{Z}
for all
\mathcal{G}^{\prime}\subseteq\mathcal{G}
.

\lrcorner

corollary

7
suggests now how to define the polyhedron
\mathcal{Q}
. Namely,
\mathcal{Q}
is defined as the set of all
{\mathbf{v}}\in\mathbb{R}^{k}
satisfying the following linear inequalities:

•

inequalities
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant 0
for all
{\mathbf{f}}\in\mathcal{F}
that define
\mathsf{cone}(D)
; and

•

for every
\mathcal{G}\subseteq\mathcal{F}
such that
\mathcal{R}_{\mathcal{G}}
is nonempty and
\mathcal{R}_{\mathcal{G}}\cap\mathcal{Z}=\emptyset
, the inequality

\sum_{{\mathbf{g}}\in\mathcal{G}}\langle{\mathbf{g}},{\mathbf{v}}\rangle\geqslant 1+\sum_{{\mathbf{g}}\in\mathcal{G}}p_{{\mathbf{g}}}.

In essence, the inequalities from the second point “carve out” those parts
\mathcal{R}_{\mathcal{G}}
that should not be included in
\mathcal{Z}
. We note that computing the inequalities defining
\mathcal{Q}
requires solving several auxiliary integer programs to figure out for which
\mathcal{G}\subseteq\mathcal{F}
the corresponding inequality should be included.

It is now straightforward to verify, using all the accumulated observations, that indeed
\mathcal{Z}=\mathcal{R}\cap\mathcal{Q}
as required. This concludes a sketch of the proof of
theorem

4
.

2.2
n
-fold programming

We now give an overview of the proof of
theorem

2
. For simplicity, we make the following assumptions.

•

We focus on the feasibility problem instead of optimization. At the very end, we will remark on what additional ideas are needed to also tackle the optimization problem.

•

We assume that all the diagonal blocks
D_{i}
are equal:
D_{i}=D
for all
i\in\{1,\ldots,n\}
, where
D
is a
k\times k
integer matrix with
\|D\|_{\infty}\leqslant\Delta
. This is only a minor simplification because there are only
(2\Delta+1)^{k^{2}}
different matrices
D_{i}
with
\|D_{i}\|_{\infty}\leqslant\Delta
, and in the general case, we simply treat every such possible matrix “type” separately using the reasoning from the simplified case.

Breaking up bricks.

Basic components of the given
n
-fold program
P=(C,D,{\mathbf{a}},{\mathbf{b}}_{i}\colon i\in\{1,\ldots,n\})
are
bricks
: programs
D{\mathbf{y}}_{i}={\mathbf{b}}_{i}
for
i\in\{1,\ldots,n\}
that encode local constraints on the variables
{\mathbf{y}}_{i}
. While the entries of
D
are bounded in absolute values by the parameter
\Delta
, we do not assume any bound on the entries of vectors
{\mathbf{b}}_{i}
. This poses an issue, as different bricks may possibly have very different behaviors.

The key idea in our approach is to simplify the program
P
by iteratively breaking up every brick
D{\mathbf{y}}={\mathbf{b}}
into two bricks
D{\mathbf{y}}={\mathbf{b}}^{\prime}
and
D{\mathbf{y}}={\mathbf{b}}^{\prime\prime}
with strictly smaller right-hand sides
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}
, until eventually, we obtain an equivalent
n
-fold program
P^{\prime}
in which all right-hand sides have
\ell_{\infty}
-norms bounded in terms of the parameters. The following lemma is the crucial new piece of technology used in our proof. (Here, we use the
conformal order
on
\mathbb{Z}^{k}
: we write
{\mathbf{u}}\sqsubseteq{\mathbf{v}}
if
|{\mathbf{u}}[i]|\leqslant|{\mathbf{v}}[i]|
and
{\mathbf{u}}[i]\cdot{\mathbf{v}}[i]\geqslant 0
for all
i\in\{1,\ldots,k\}
.)

Lemma 8
(Brick Decomposition Lemma, see
lemma

23
).

There exists a function
g(k,\Delta)\in 2^{(k\Delta)^{{\mathcal{O}}(k)}}
such that the following holds. Let
D
be an integer matrix with
t
columns and
k
rows and all absolute values of its entries bounded by
\Delta
. Further, let
{\mathbf{b}}\in\mathbb{Z}^{k}
be an integer vector such that
\|{\mathbf{b}}\|_{\infty}>g(k,\Delta)
. Then there are non-zero vectors
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\in\mathbb{Z}^{k}
such that:

•

{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\sqsubseteq{\mathbf{b}}
and
{\mathbf{b}}={\mathbf{b}}^{\prime}+{\mathbf{b}}^{\prime\prime}
; and

•

for every
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
satisfying
D{\mathbf{v}}={\mathbf{b}}
, there exist
{\mathbf{v}}^{\prime},{\mathbf{v}}^{\prime\prime}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
such that

{\mathbf{v}}={\mathbf{v}}^{\prime}+{\mathbf{v}}^{\prime\prime},\qquad D{\mathbf{v}}^{\prime}={\mathbf{b}}^{\prime},\qquad\textrm{and}\qquad D{\mathbf{v}}^{\prime\prime}={\mathbf{b}}^{\prime\prime}.

\lrcorner

In other words,
lemma

8
states that the brick
D{\mathbf{y}}={\mathbf{b}}
can be broken into two new bricks
D{\mathbf{y}}^{\prime}={\mathbf{b}}^{\prime}
and
D{\mathbf{y}}^{\prime\prime}={\mathbf{b}}^{\prime\prime}
with conformally strictly smaller
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}
so that
every
potential solution
{\mathbf{v}}
to
D{\mathbf{y}}={\mathbf{b}}
can be decomposed into solutions
{\mathbf{v}}^{\prime},{\mathbf{v}}^{\prime\prime}
to the two new bricks. It is easy to see that this condition implies that in
P
, we may replace the brick
D{\mathbf{y}}={\mathbf{b}}
with
D{\mathbf{y}}^{\prime}={\mathbf{b}}^{\prime}
and
D{\mathbf{y}}^{\prime\prime}={\mathbf{b}}^{\prime\prime}
without changing feasibility or, in the case of the optimization problem, the minimum value of the optimization goal. In the latter setting, both new bricks inherit the optimization vector
{\mathbf{c}}_{i}
from the original brick.

Before we continue, let us comment on the proof of
lemma

8
. We use two ingredients. The first one is the following fundamental result of Klein
[
27
]
. (Here, for a multiset of vectors
A
, by
\sum A
we denote the sum of all the vectors in
A
.)

Lemma 9
(Klein Lemma, variant from
[
11
]
).

Let
T_{1},\ldots,T_{n}
be non-empty multisets of vectors in
\mathbb{Z}^{k}
such that
\sum T_{1}=\sum T_{2}=\ldots=\sum T_{n}
and all vectors contained in all multisets
T_{1},\ldots,T_{n}
have
\ell_{\infty}
-norm bounded by
\Delta
. Then there are non-empty multisets
S_{1}\subseteq T_{1},\ldots,S_{n}\subseteq T_{n}
, each of size at most
2^{{\mathcal{O}}(k\Delta)^{k}}
, such that
\sum S_{1}=\sum S_{2}=\ldots=\sum S_{n}
.

\lrcorner

In the context of the proof of
lemma

8
, we apply
lemma

9
to the family of all multisets
T
that consist of columns of
D
and satisfy
\sum T={\mathbf{b}}
. By encoding multiplicities, such multisets correspond to vectors
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{k}
satisfying
D{\mathbf{v}}={\mathbf{b}}
. (We hide here some technicalities regarding the fact that this family is infinite.) By
lemma

9
, from each such multiset
T
, we can extract a submultiset
S
of bounded size such that all the submultisets
S
sum up to the same vector
{\mathbf{b}}^{\prime}
. Denoting
{\mathbf{b}}^{\prime\prime}={\mathbf{b}}-{\mathbf{b}}^{\prime}
, this means that every vector
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{k}
satisfying
D{\mathbf{v}}={\mathbf{b}}
can be decomposed as
{\mathbf{v}}={\mathbf{v}}^{\prime}+{\mathbf{v}}^{\prime\prime}
with
{\mathbf{v}}^{\prime},{\mathbf{v}}^{\prime\prime}\in\mathbb{Z}_{\geqslant 0}^{k}
so that
D{\mathbf{v}}^{\prime}={\mathbf{b}}^{\prime}
and
D{\mathbf{v}}^{\prime\prime}={\mathbf{b}}^{\prime\prime}
. Namely,
{\mathbf{v}}^{\prime}
corresponds to the vectors contained in
S
and
{\mathbf{v}}^{\prime\prime}
corresponds to the vectors contained in
T-S
, where
T
is the multiset corresponding to
{\mathbf{v}}
.

There is an issue in the above reasoning: we do not obtain the property
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\sqsubseteq{\mathbf{b}}
, which will be important in later applications of
lemma

8
. To bridge this difficulty, we apply the argument above exhaustively to decompose
{\mathbf{b}}
as
{\mathbf{b}}_{1}+\ldots+{\mathbf{b}}_{m}
, for some integer
m
, so that every vector
{\mathbf{b}}_{i}
has the
\ell_{\infty}
-norm bounded by
2^{{\mathcal{O}}(k\Delta)^{k}}
and every vector
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{k}
satisfying
D{\mathbf{v}}={\mathbf{b}}
can be decomposed as
{\mathbf{v}}={\mathbf{v}}_{1}+\ldots+{\mathbf{v}}_{m}
where
{\mathbf{v}}_{i}\in\mathbb{Z}_{\geqslant 0}^{k}
satisfies
D{\mathbf{v}}_{i}={\mathbf{b}}_{i}
. Then, we treat vectors
{\mathbf{b}}_{1},\ldots,{\mathbf{b}}_{m}
with the following lemma.

Lemma 10
(see
lemma

25
).

Let
{\mathbf{u}}_{1},\ldots,{\mathbf{u}}_{m}
be vectors in
\mathbb{Z}^{k}
of
\ell_{\infty}
-norm bounded by
\Xi
, and let
{\mathbf{b}}=\sum_{i=1}^{m}{\mathbf{u}}_{i}
. Then the vectors
{\mathbf{u}}_{1},\ldots,{\mathbf{u}}_{m}
can be grouped into non-empty groups
U_{1},\ldots,U_{\ell}
, each of size at most
{\mathcal{O}}(\Delta)^{2^{k-1}}
, so that
\sum U_{i}\sqsubseteq{\mathbf{b}}
for all
i=1,\ldots,\ell
.

\lrcorner

More precisely,
lemma

10
allows us to group vectors
{\mathbf{b}}_{1},\ldots,{\mathbf{b}}_{m}
into groups of bounded size so that the sum within each group is sign-compatible with
{\mathbf{b}}
. Assuming
\|{\mathbf{b}}\|_{\infty}
is large enough, there will be at least two groups. Then, any non-trivial partition of the groups translates into a suitable decomposition
{\mathbf{b}}={\mathbf{b}}^{\prime}+{\mathbf{b}}^{\prime\prime}
with
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\sqsubseteq{\mathbf{b}}
.

The proof of
lemma

10
is by induction on
k
and uses arguments similar to standard proofs of Steinitz Lemma. This concludes a sketch of the proof of
lemma

8
.

Once
lemma

8
is established, it is natural to use it iteratively: break
{\mathbf{b}}
into
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}
, then break
{\mathbf{b}}^{\prime}
into two even smaller vectors, and so on. By applying the argument exhaustively, eventually we obtain a collection of vectors
{\mathbf{b}}_{1},\ldots,{\mathbf{b}}_{m}\sqsubseteq{\mathbf{b}}
such that
{\mathbf{b}}={\mathbf{b}}_{1}+\ldots+{\mathbf{b}}_{m}
,
\|{\mathbf{b}}_{i}\|_{\infty}\leqslant 2^{(k\Delta)^{{\mathcal{O}}(k)}}
for all
i\in\{1,\ldots,m\}
, and every
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{k}
satisfying
D{\mathbf{v}}={\mathbf{b}}
can be decomposed as
{\mathbf{v}}={\mathbf{v}}_{1}+\ldots+{\mathbf{v}}_{m}
with
{\mathbf{v}}_{i}\in\mathbb{Z}_{\geqslant 0}^{k}
and
D{\mathbf{v}}_{i}={\mathbf{b}}_{i}
for all
i\in\{1,\ldots,m\}
. We call such a collection a
faithful decompostion
of
{\mathbf{b}}
of
order

2^{(k\Delta)^{{\mathcal{O}}(k)}}
.

There is an important technical caveat here. Observe that the size
m
of a faithful decomposition of a right-hand side
{\mathbf{b}}
can be as large as
\Omega(\|{\mathbf{b}}\|_{1})
, which is
exponential
in the bitsize of the program
P
. So we cannot hope to compute a faithful decomposition explicitly within the target time complexity. However, observe that all vectors
{\mathbf{b}}_{i}
in a faithful decomposition
\mathcal{B}
are bounded in
\ell_{\infty}
-norm by
\Xi\coloneqq 2^{(k\Delta)^{{\mathcal{O}}(k)}}
, and there are only at most
(2\Xi+1)^{k}
different such vectors. Therefore,
\mathcal{B}
can be encoded by storing, for each vector
{\mathbf{b}}^{\prime}
present in
\mathcal{B}
, the multiplicity of
{\mathbf{b}}^{\prime}
in
\mathcal{B}
. Thus, describing
\mathcal{B}
takes
2^{(k\Delta)^{{\mathcal{O}}(k)}}\cdot\log\|{\mathbf{b}}\|_{\infty}
bits.

With this encoding scheme in mind, we show that a faithful decomposition
\mathcal{B}
of a given vector
{\mathbf{b}}
of order at most
\Xi
can be computed in fixed-parameter time
f(\Delta,k)\cdot(\log\|{\mathbf{b}}\|_{\infty})^{{\mathcal{O}}(1)}
, for a computable function
f
. For this, we show that one can extract parts of the decomposition in “larger chunks”, at each step reducing the
\ell_{1}
-norm of the decomposed vector by a constant fraction; this gives a total number of steps logarithmic in
\|{\mathbf{b}}\|_{1}
. In each step, to extract the next large chunk of the decomposition, we use the fixed-parameter algorithm for optimization problems definable in Presburger arithmetic, due to Koutecký and Talmon
[
38
]
. We remark that in our context, this tool could be also replaced by the fixed-parameter algorithm of Eisenbrand and Shmonin
[
18
]
for
\forall\exists
integer programming.

Reduction to (mixed) integer programming with few variables.

With faithful decompositions understood, we can compute, for every right-hand side
{\mathbf{b}}_{i}
part of
P
, a faithful decomposition
\{{\mathbf{b}}^{1}_{i},\ldots,{\mathbf{b}}_{i}^{m_{i}}\}
of
{\mathbf{b}}_{i}
. This allows us to construct an equivalent (in terms of feasibility and optimization)
n
-fold program
P^{\prime}
by replacing each brick
D{\mathbf{y}}_{i}={\mathbf{b}}_{i}
with bricks
D{\mathbf{y}}_{i}^{j}={\mathbf{b}}_{i}^{j}
for
j\in\{1,\ldots,m_{i}\}
. Thus, the program
P^{\prime}
has an exponential number of bricks, but can be computed and described concisely: all right-hand sides are bounded in the
\ell_{\infty}
-norm by at most
\Xi
, so for every potential right-hand side
{\mathbf{b}}
, we just write the multiplicity in which
{\mathbf{b}}
appears in
P^{\prime}
. We remark that such
high-multiplicity encoding
of
n
-fold integer programs has already been studied by Knop et al.
[
32
]
.

For convenience, let
\mathsf{RHS}\coloneqq\{-\Xi,\ldots,\Xi\}^{k}
be the set of all possible right-hand sides, and for
{\mathbf{b}}\in\mathsf{RHS}
, by
\mathsf{count}[{\mathbf{b}}]
we denote the multiplicity of
{\mathbf{b}}
in
P^{\prime}
.

It is now important to better understand the set of solutions to a single brick
D{\mathbf{y}}={\mathbf{b}}
present in
P^{\prime}
. Here comes a key insight stemming from the theory of Graver bases: as (essentially) proved by Pottier
[
41
]
, every solution
{\mathbf{w}}\in\mathbb{Z}_{\geqslant 0}^{k}
to
D{\mathbf{w}}={\mathbf{b}}
can be decomposed as
{\mathbf{w}}={\widehat{{\mathbf{w}}}}+{\mathbf{g}}_{1}+\ldots+{\mathbf{g}}_{\ell}
, where

•

{\widehat{{\mathbf{w}}}}\in\mathbb{Z}_{\geqslant 0}^{k}
is a
base solution
that also satisfies
D{\widehat{{\mathbf{w}}}}={\mathbf{b}}
, but
\|{\widehat{{\mathbf{w}}}}\|_{\infty}
is bounded by a function of
\Delta
and
\|{\mathbf{b}}\|_{\infty}
, and

•

{\mathbf{g}}_{1},\ldots,{\mathbf{g}}_{\ell}\in\mathbb{Z}_{\geqslant 0}^{k}
are elements of the Graver basis of
D
.

Here, the
Graver basis
of
D
consists of all conformally-minimal non-zero vectors
{\mathbf{g}}
satisfying
D{\mathbf{g}}=\mathbf{0}
. In particular, it is known that the Graver basis is always finite and consists of vectors of
\ell_{\infty}
norm bounded by
(2k\Delta+1)^{k}

[
16
]
. The decomposition explained above will be called a
Graver decomposition
of
{\mathbf{w}}
.

For
{\mathbf{b}}\in\mathsf{RHS}
, let
\mathsf{Base}[{\mathbf{b}}]
be the set of all possible base solutions
{\widehat{{\mathbf{w}}}}
to
D{\mathbf{y}}={\mathbf{b}}
. As
\|{\mathbf{b}}\|_{\infty}\leqslant\Xi
and
\Xi
is bounded by a function of the parameters under consideration, it follows that
\mathsf{Base}[{\mathbf{b}}]
consists only of vectors of bounded
\ell_{\infty}
-norms, and therefore it can be efficiently constructed.

Having this understanding, we can write an integer program
M
with few variables that is equivalent to
P^{\prime}
. The variables are as follows:

•

for every
{\mathbf{b}}\in\mathsf{RHS}
and
{\widehat{{\mathbf{w}}}}\in\mathsf{Base}[{\mathbf{b}}]
, we introduce a variable
\zeta^{\mathbf{b}}_{\widehat{{\mathbf{w}}}}\in\mathbb{Z}_{\geqslant 0}
that signifies how many times in total
{\widehat{{\mathbf{w}}}}
is used in the Graver decompositions of solutions to individual bricks.

•

for every nonnegative vector
{\mathbf{g}}
in the Graver basis of
D
, we introduce a variable
\delta_{\mathbf{g}}\in\mathbb{Z}_{\geqslant 0}
signifying how many times in total
{\mathbf{g}}
appears in the Graver decompositions of solutions to individual bricks.

Note that since program
P^{\prime}
is uniform, the guessed base solutions and elements of the Graver basis can be assigned to
any
brick with the same effect on the linking constraints of
P^{\prime}
. Hence, it suffices to verify the cardinalities and the total effect on the linking constrains of
P^{\prime}
, yielding the following constraints of
M
:

•

the translated linking constraints:
\sum_{{\mathbf{b}}\in\mathsf{RHS}}\sum_{{\widehat{{\mathbf{w}}}}\in\mathsf{Base}[{\mathbf{b}}]}\zeta^{{\mathbf{b}}}_{\widehat{{\mathbf{w}}}}\cdot C{\widehat{{\mathbf{w}}}}+\sum_{{\mathbf{g}}\in\mathsf{Graver}(D),{\mathbf{g}}\geqslant 0}\delta_{\mathbf{g}}\cdot C{\mathbf{g}}={\mathbf{a}}
.

•

for every
{\mathbf{b}}\in\mathsf{RHS}
, the cardinality constraint
\sum_{{\widehat{{\mathbf{w}}}}\in\mathsf{Base}[{\mathbf{b}}]}\zeta^{\mathbf{b}}_{\widehat{{\mathbf{w}}}}=\mathsf{count}[{\mathbf{b}}]
.

Noting that the number of variables of
M
is bounded in terms of the parameters, we may apply any fixed-parameter algorithm for integer programming parameterized by the number of variables, for instance that of Kannan
[
26
]
, to solve
M
. This concludes the description of the algorithm for the feasibility problem.

In the case of the optimization problem, there is an issue that the optimization vectors
{\mathbf{c}}_{i}
may differ between different bricks, and there may be as many as
n
different such vectors. While the Graver basis elements can be always greedily assigned to bricks in which their contribution to the optimization goal is the smallest, this is not so easy for the base solutions, as every brick may accommodate only one base solution.
We may enrich
M
by suitable assignment variables
\omega^{{\mathbf{b}},i}_{{\widehat{{\mathbf{w}}}}}
to express how many base solutions of each type are assigned to bricks with different optimization vectors; but this yields as many as
\Omega(n)
additional variables. Fortunately, we observe that in the enriched program
M
, if one fixes any integral valuation of variables
\zeta^{{\mathbf{b}}}_{{\widehat{{\mathbf{w}}}}}
and
\delta_{\mathbf{g}}
, the remaining problem on variables
\omega^{{\mathbf{b}},i}_{{\widehat{{\mathbf{w}}}}}
corresponds to a flow problem, and hence its constraint matrix is totally unimodular. Thus, we may solve
M
as a mixed integer program where variables
\omega^{{\mathbf{b}},i}_{{\widehat{{\mathbf{w}}}}}
are allowed to be fractional. The number of integral variables is bounded in terms of parameters, so we may apply the fixed-parameter algorithm for mixed integer programming of Lenstra
[
40
]
.

3
Preliminaries

We write
\mathbb{Z}_{\geqslant 0}
and
\mathbb{R}_{\geqslant 0}
for the sets of nonnegative integers and nonnegative reals, respectively.

Linear algebra.

In the technical part of this paper we choose to use a somewhat unorthodox notation for linear algebra, which we introduce now. The correspondence between this notation and the standard notation used in the previous sections is straightforward.

A
tuple of variables
is just a finite set of variable names. We use the convention that tuples of variables are denoted
{\mathbf{x}},{\mathbf{y}},{\mathbf{z}},
etc., while individual variable names are
x,y,z,
etc. For a set
A
and a tuple of variables
{\mathbf{x}}
, an
{\mathbf{x}}
-vector
over
A
is a function
{\mathbf{u}}\colon{\mathbf{x}}\to A
.
The value of
{\mathbf{u}}
on a variable
x\in{\mathbf{x}}
will be denoted by
{\mathbf{u}}[x]
, and we call it the
x
-entry
of
{\mathbf{u}}
.
Vectors will be typically denoted by
{\mathbf{a}},{\mathbf{b}},{\mathbf{c}},{\mathbf{u}},{\mathbf{v}},{\mathbf{w}}
and so on. We write
A^{{\mathbf{x}}}
for the set of all
{\mathbf{x}}
-vectors over
A
.
We can also apply arithmetics to vectors coordinate-wise in the standard manner, whenever the set
A
is endowed with a structure of a ring. When
A=\mathbb{R}
, as usual we write

\|{\mathbf{u}}\|_{\infty}\coloneqq\max_{x\in{\mathbf{x}}}|{\mathbf{u}}[x]|
and
\|{\mathbf{u}}\|_{1}\coloneqq\sum_{x\in{\mathbf{x}}}|{\mathbf{u}}[x]|
.

For a ring
R
(typically
\mathbb{Z}
or
\mathbb{R}
) and tuples of variables
{\mathbf{x}}
and
{\mathbf{y}}
, an
{\mathbf{x}}\times{\mathbf{y}}
-matrix
is an
{\mathbf{x}}
-vector of
{\mathbf{y}}
-vectors, that is, an element of
(R^{{\mathbf{y}}})^{{\mathbf{x}}}
; we denote the latter set as
R^{{\mathbf{x}}\times{\mathbf{y}}}
for convenience.
The reader should think of the individual
{\mathbf{y}}
-vectors comprised in a matrix as of the columns of the said matrix. We use capital letters
A,B,C,
etc. for matrices. For
x\in{\mathbf{x}}
and
y\in{\mathbf{y}}
, we write
A[x,y]\coloneqq(A[x])[y]
, that is,
A[x,y]
is the
y
-entry of the column of
A
corresponding to variable
x
. As for vectors, by
\|A\|_{\infty}\coloneqq\max_{x\in{\mathbf{x}},y\in{\mathbf{y}}}|A[x,y]|
we denote the maximum absolute value of an entry of
A
.

For a matrix
A\in R^{{\mathbf{x}}\times{\mathbf{y}}}
and a vector
{\mathbf{u}}\in R^{{\mathbf{x}}}
,
A{\mathbf{u}}
is the vector
{\mathbf{v}}\in R^{{\mathbf{y}}}
satisfying

{\mathbf{v}}[y]=\sum_{x\in{\mathbf{x}}}A[x,y]\cdot{\mathbf{u}}[x]\qquad\textrm{for all }y\in{\mathbf{y}}.

For vectors
{\mathbf{u}},{\mathbf{v}}\in R^{{\mathbf{x}}}
, the
inner product
of
{\mathbf{u}}
and
{\mathbf{v}}
is

\langle{\mathbf{u}},{\mathbf{v}}\rangle\coloneqq\sum_{x\in{\mathbf{x}}}{\mathbf{u}}[x]\cdot{\mathbf{v}}[x].

All-zero vectors are denoted by
{\mathbf{0}}
and their domains will be always clear from the context.

Conformal order.

Let
{\mathbf{x}}
be a tuple of variables. Vectors
{\mathbf{u}},{\mathbf{v}}\in\mathbb{Z}^{{\mathbf{x}}}
are
sign-compatible
if
{\mathbf{u}}[x]\cdot{\mathbf{v}}[x]\geqslant 0
for all
x\in{\mathbf{x}}
; that is, on every coordinate
{\mathbf{u}}
and
{\mathbf{v}}
must have the same sign, where
0
is assumed to be compatible with both signs.
The
conformal order

\sqsubseteq
on vectors in
\mathbb{Z}^{{\mathbf{x}}}
is defined as follows: For two vectors
{\mathbf{u}},{\mathbf{v}}\in\mathbb{Z}^{{\mathbf{x}}}
, we have
{\mathbf{u}}\sqsubseteq{\mathbf{v}}
if
{\mathbf{u}}
and
{\mathbf{v}}
are sign-compatible and

|{\mathbf{u}}[x]|\leqslant|{\mathbf{v}}[x]|\qquad\textrm{for all }x\in{\mathbf{x}}.

Note that thus,
\sqsubseteq
is a partial order on
\mathbb{Z}^{{\mathbf{x}}}
.

Collections.

A
collection
over a set
A
is a function
C\colon I\to A
, where
I
is the
index set
of
C
.
We often use notation
C=\left\langle c_{i}\colon i\in I\right\rangle
to enumerate the elements of a collection with the elements of its index set, where formally
c_{i}
is the value of
C
on
i
. Note that syntactically, a collection with index set
I
is just an
I
-vector, but we will use collections and vectors in different ways. Typically, when speaking about collections we are not really interested in the index set, and the reader can always assume it to be a prefix of natural numbers. However, in notation it will be convenient to consider various index sets.

Standard set theory notation can be used in the context of collections in the natural manner, by applying it to the index sets. In particular, a
subcollection
of a collection
C=\left\langle c_{i}\colon i\in I\right\rangle
is any collection
C^{\prime}=\left\langle c_{i}\colon i\in I^{\prime}\right\rangle
for
I^{\prime}\subseteq I
.

Block-structured integer programming.

We now introduce the two variants of block-structured integer programming problems that we are interested in: two-stage stochastic integer programming and
n
-fold integer programming.

A
two-stage stochastic integer program
consists of three collections:

•

\left\langle A_{i}\colon i\in I\right\rangle
is a collection of matrices in
\mathbb{Z}^{{\mathbf{x}}\times{\mathbf{t}}}
;

•

\left\langle D_{i}\colon i\in I\right\rangle
is a collection of matrices in
\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
; and

•

\left\langle{\mathbf{b}}_{i}\colon i\in I\right\rangle
is a collection of vectors in
\mathbb{Z}^{{\mathbf{t}}}
.

Here,
{\mathbf{x}},{\mathbf{y}},{\mathbf{t}}
are tuples of variables and
I
is the index set of the program. A
solution
to such a program consists of a vector
{\mathbf{u}}\in\mathbb{Z}_{\geqslant 0}^{\mathbf{x}}
and vectors
\left\langle{\mathbf{v}}_{i}\colon i\in I\right\rangle
in
\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
such that

\displaystyle A_{i}{\mathbf{u}}+D_{i}{\mathbf{v}}_{i}={\mathbf{b}}_{i}\quad\textrm{for all }i\in I.

In the
Two-Stage Stochastic ILP Feasability
problem, we are given a two-stage stochastic integer program in the form described above, and the task is to decide whether this program has a solution.

An
n
-fold integer program
consists of the following components:

•

\left\langle C_{i}\colon i\in I\right\rangle
is a collection of matrices in
\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{s}}}
;

•

\left\langle D_{i}\colon i\in I\right\rangle
is a collection of matrices in
\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
;

•

{\mathbf{a}}
is a vector in
\mathbb{Z}^{{\mathbf{s}}}
; and

•

\left\langle{\mathbf{b}}_{i}\colon i\in I\right\rangle
is a collection of vectors in
\mathbb{Z}^{{\mathbf{t}}}
.

Again,
{\mathbf{y}},{\mathbf{s}},{\mathbf{t}}
are tuples of variables and
I
is the index set of the program. A
uniform
program is one where
C_{i}=C_{j}
for all
i,j\in I
.
A
solution
to the program described above consists of vectors
\left\langle{\mathbf{v}}_{i}\colon i\in I\right\rangle
in
\mathbb{Z}_{\geqslant 0}^{\mathbf{y}}
such that

\sum_{i\in I}C_{i}{\mathbf{v}}_{i}={\mathbf{a}}\qquad\textrm{and}\qquad D_{i}{\mathbf{v}}_{i}={\mathbf{b}}_{i}\quad\textrm{for all }i\in I.

The
n
-fold ILP Feasability
problem asks for the existence of a solution to a given
n
-fold integer program, while in the
n
-fold ILP Optimization
problem, the task is to minimize
\sum_{i\in I}\langle{\mathbf{c}}_{i},{\mathbf{v}}_{i}\rangle
among the solutions, for additionally given vectors
\left\langle{\mathbf{c}}_{i}\colon i\in I\right\rangle
in
\mathbb{Z}^{\mathbf{y}}
. A prefix
Uniform
may be added to the problem name to specify that we speak about uniform programs. (Note that only the matrices
C_{i}
have to be equal, and not necessarily the optimization goal vectors
{\mathbf{c}}_{i}
.)

For an integer program
P
, be it a two-stage stochastic or an
n
-fold program, by
\|P\|
we denote the total bitsize of the encoding of
P
, where all numbers are encoded in binary.

4
Two-stage stochastic integer programming

Our main result for two-stage stochastic integer programs is captured in the following statement, which is
theorem

1
with adjusted notation.

Theorem 11
.

An instance
P=\left\langle A_{i},D_{i},{\mathbf{b}}_{i}\colon i\in I\right\rangle
of
Two-Stage Stochastic ILP Feasability
can be solved in time
f(\Delta,|{\mathbf{x}}|,|{\mathbf{t}}|)\cdot\|P\|
for some computable function
f
, where
\Delta=\max_{i\in I}\|D_{i}\|_{\infty}
.

\lrcorner

Note that importantly, the absolute values of the entries of matrices
A_{i}
are
not
assumed to be bounded in terms of the considered parameters. Also, in
theorem

11
the parameters do not include
|{\mathbf{y}}|
, the number of columns of each block
D_{i}
. This is because by removing equal columns in those blocks (which does not affect the feasibility of the program), we may always assume
|{\mathbf{y}}|\leqslant(2\Delta+1)^{|{\mathbf{t}}|}
.

The proof of
theorem

11
spans the entirety of this section.

4.1
Cones

In our proof we will rely on the geometry of polyhedral and integer cones. For this, we introduce the following notation. Let
{\mathbf{t}}
be a tuple of variables and
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
be a finite set of vectors.
For
S\in\{\mathbb{R},\mathbb{R}_{\geqslant 0},\mathbb{Z},\mathbb{Z}_{\geqslant 0}\}
, we define the
S
-span of
\mathcal{D}
as

\mathsf{span}^{S}(\mathcal{D})\coloneqq\left\{\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}\penalty\ \colon\penalty\ \left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle\textrm{ is a collection of elements of }S\right\}\subseteq\mathbb{R}^{{\mathbf{t}}}.

In other words,
\mathsf{span}^{S}(\mathcal{D})
are all vectors that can be expressed as a linear combination of vectors in
\mathcal{D}
with coefficients belonging to
S
.
For clarity, we write

\displaystyle\mathsf{span}(\mathcal{D})

\displaystyle\coloneqq\mathsf{span}^{\mathbb{R}}(\mathcal{D}),

\displaystyle\qquad\mathsf{cone}(\mathcal{D})

\displaystyle\coloneqq\mathsf{span}^{\mathbb{R}_{\geqslant 0}}(\mathcal{D}),

\displaystyle\mathsf{lattice}(\mathcal{D})

\displaystyle\coloneqq\mathsf{span}^{\mathbb{Z}}(\mathcal{D}),

\displaystyle\qquad\mathsf{intCone}(\mathcal{D})

\displaystyle\coloneqq\mathsf{span}^{\mathbb{Z}_{\geqslant 0}}(\mathcal{D}).

Thus,
\mathsf{span}(\mathcal{D})
is just the usual linear space spanned of
\mathcal{D}
. Next,
\mathsf{cone}(\mathcal{D})
is the standard
polyhedral cone
: it consists of all vectors expressible as nonnegative linear combinations of vectors in
\mathcal{D}
. Similarly,
\mathsf{intCone}(\mathcal{D})
is the
integer cone
, where we restrict attention to nonnegative integer combinations of vectors in
\mathcal{D}
. Finally,
\mathsf{lattice}(\mathcal{D})
is the
integer lattice
consisting of all vectors that can be reached from
{\mathbf{0}}
by adding and subtracting vectors of
\mathcal{D}
.

We remark that while the reader may think of
\mathcal{D}
as of a matrix whose columns are the vectors of
\mathcal{D}
, ordered arbitrarily, in the notation we will consistently treat
\mathcal{D}
as a set of vectors. Consequently,
|\mathcal{D}|
denotes the number of vectors in
\mathcal{D}
(or, the number of columns of
\mathcal{D}
treated as a matrix), and the same also applies to all subsets of
\mathcal{D}
.

4.1.1
Dual representation of cones

We will use the classic result of Weyl about representing polyhedral cones as intersections of half-spaces.

Theorem 12
(Weyl,
[
45
]
).

For every set of vectors
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
there exists a finite set of vectors
\mathcal{F}\subseteq\mathbb{Z}^{\mathbf{t}}
such that

\mathsf{cone}(\mathcal{D})=\{{\mathbf{v}}\in\mathbb{R}^{{\mathbf{t}}}\penalty\ |\penalty\ \langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant 0\textrm{ for all }{\mathbf{f}}\in\mathcal{F}\}.

Moreover, such a set
\mathcal{F}
can be computed given
\mathcal{D}
.

\lrcorner

A set
\mathcal{F}
satisfying the outcome of
theorem

12
will be called a
dual representation
of
\mathsf{cone}(\mathcal{D})
. Here is a simple observation about how elements of the dual representation relate to the elements of
\mathcal{D}
.

Observation 13
.

Suppose
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
for a set of vectors
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
. Then

\langle{\mathbf{f}},{\mathbf{d}}\rangle\geqslant 0\quad\textrm{ for all }\ {\mathbf{f}}\in\mathcal{F}\textrm{ and }\ {\mathbf{d}}\in\mathcal{D}.

\lrcorner

Proof
.

Clearly
{\mathbf{d}}\in\mathsf{cone}(\mathcal{D})
, so
\langle{\mathbf{f}},{\mathbf{d}}\rangle\geqslant 0
because
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
.

\lrcorner

For a subset
\mathcal{G}\subseteq\mathcal{F}
, we define

\mathcal{D}_{\mathcal{G}}\coloneqq\{{\mathbf{d}}\in\mathcal{D}\penalty\ |\penalty\ \langle{\mathbf{g}},{\mathbf{d}}\rangle=0\textrm{ for all }{\mathbf{g}}\in\mathcal{G}\}.

In other words,
\mathcal{D}_{\mathcal{G}}
consists of those vectors of
\mathcal{D}
that are orthogonal to all vectors in
\mathcal{G}
. The next lemma expresses the following intuition: the facet of
\mathsf{cone}(\mathcal{D})
corresponding to
\mathcal{G}
is spanned by the vectors of
\mathcal{D}_{\mathcal{G}}
.

Lemma 14
.

Suppose
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
for a set of vectors
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
. Then for every subset
\mathcal{G}\subseteq\mathcal{F}
we have

\mathsf{cone}(\mathcal{D}_{\mathcal{G}})=\mathsf{cone}(\mathcal{D})\cap\{{\mathbf{v}}\in\mathbb{R}^{{\mathbf{t}}}\penalty\ |\penalty\ \langle{\mathbf{g}},{\mathbf{v}}\rangle=0\textrm{ for all }{\mathbf{g}}\in\mathcal{G}\}.

\lrcorner

Proof
.

Note that
\mathcal{D}_{\mathcal{G}}\subseteq\mathcal{D}
entails
\mathsf{cone}(\mathcal{D}_{\mathcal{G}})\subseteq\mathsf{cone}(\mathcal{D})
. Further, since
\langle{\mathbf{g}},{\mathbf{d}}\rangle=0
for all
{\mathbf{g}}\in\mathcal{G}
and all
{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}
, the same also holds for all linear combinations of vectors in
\mathcal{D}_{\mathcal{G}}
, implying that
\langle{\mathbf{g}},{\mathbf{v}}\rangle=0
for all
{\mathbf{g}}\in\mathcal{G}
and
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}})
. This proves inclusion
\subseteq
.

For the converse inclusion, consider any
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D})
such that
\langle{\mathbf{g}},{\mathbf{v}}\rangle=0
for all
{\mathbf{g}}\in\mathcal{G}
. As
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D})
, there is a collection of nonnegative reals
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that

{\mathbf{v}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}.

Consider any
{\mathbf{e}}\in\mathcal{D}-\mathcal{D}_{\mathcal{G}}
. By the definition of
\mathcal{D}_{\mathcal{G}}
and
13
, there exists
{\mathbf{g}}\in\mathcal{G}
such that
\langle{\mathbf{g}},{\mathbf{e}}\rangle>0
. As all coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
are nonnegative, by
13
we have

0=\langle{\mathbf{g}},{\mathbf{v}}\rangle=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot\langle{\mathbf{g}},{\mathbf{d}}\rangle\geqslant\lambda_{\mathbf{e}}\cdot\langle{\mathbf{g}},{\mathbf{e}}\rangle.

As
\langle{\mathbf{g}},{\mathbf{e}}\rangle>0
, we necessarily have
\lambda_{\mathbf{e}}=0
; and this holds for every
{\mathbf{e}}\in\mathcal{D}-\mathcal{D}_{\mathcal{G}}
. So in fact
{\mathbf{v}}
is a nonnegative linear combination of vectors in
\mathcal{D}_{\mathcal{G}}
, or equivalently
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}})
. This proves inclusion
\supseteq
.

\lrcorner

4.1.2
Membership in integer cones and in integer lattices

First, we need a statement that membership in an integer lattice can be witnessed by a vector with small entries. The following lemma follows from standard bounds given by Pottier
[
41
, Corollary 4]
(c.f.
lemma

22
).

Lemma 15
.

For every set of vectors
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
and a vector
{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D})
, there exist integer coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that

{\mathbf{v}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}\qquad\textrm{and}\qquad\sum_{{\mathbf{d}}\in\mathcal{D}}|\lambda_{\mathbf{d}}|\leqslant\left(2+\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}+\|{\mathbf{v}}\|_{\infty}\right)^{2|{\mathbf{t}}|}.

\lrcorner

We now proceed to a technical statement that is crucial in our approach. Intuitively, it says that if a vector lies “deep” in the polyhedral cone, then its membership in the integer cone is equivalent to the membership in the integer lattice.

Lemma 16
(Deep-in-the-Cone Lemma).

Let
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
be a set of vectors and
\mathcal{F}\subseteq\mathbb{Z}^{\mathbf{t}}
be a dual representation of
\mathsf{cone}(\mathcal{D})
. Then there is a positive integer
M
, computable from
\mathcal{D}
and
\mathcal{F}
, such that for every
\mathcal{G}\subseteq\mathcal{F}
and every
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}})
satisfying
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant M
for all
{\mathbf{f}}\in\mathcal{F}-\mathcal{G}
, we have

{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})\quad\textrm{if and only if}\quad{\mathbf{v}}\in\mathsf{intCone}(\mathcal{D}_{\mathcal{G}}).

\lrcorner

Proof
.

We set

M\coloneqq L\cdot|\mathcal{D}|\cdot\max_{{\mathbf{f}}\in\mathcal{F}}\|{\mathbf{f}}\|_{1}\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty},\qquad\textrm{where}\qquad L\coloneqq\left(2+(|\mathcal{D}|+1)\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}\right)^{2|{\mathbf{t}}|}

is the bound provided by
lemma

15
for vectors of
\ell_{\infty}
-norm bounded by
|\mathcal{D}|\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}
.

As
\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})\subseteq\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})
, it suffices to prove the following: if
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}})\cap\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})
satisfies
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant M
for all
{\mathbf{f}}\in\mathcal{F}-\mathcal{G}
, then in fact
{\mathbf{v}}\in\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})
. Let

{\mathbf{w}}\coloneqq\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}L\cdot{\mathbf{d}}.

As both
{\mathbf{v}}
and
{\mathbf{w}}
are linear combinations of vectors in
\mathcal{D}_{\mathcal{G}}
, we have

\langle{\mathbf{g}},{\mathbf{v}}-{\mathbf{w}}\rangle=0\qquad\textrm{for all }{\mathbf{g}}\in\mathcal{G}.

Further, for each
{\mathbf{f}}\in\mathcal{F}-\mathcal{G}
we have

\langle{\mathbf{f}},{\mathbf{v}}-{\mathbf{w}}\rangle=\langle{\mathbf{f}},{\mathbf{v}}\rangle-\langle{\mathbf{f}},{\mathbf{w}}\rangle\geqslant M-L\cdot\sum_{{\mathbf{d}}\in\mathcal{D}}|\langle{\mathbf{f}},{\mathbf{d}}\rangle|\geqslant M-L\cdot|\mathcal{D}|\cdot\max_{{\mathbf{f}}\in\mathcal{F}}\|{\mathbf{f}}\|_{1}\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}=0.

As
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
, the two assertions above together with
lemma

14
imply that
{\mathbf{v}}-{\mathbf{w}}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}})
. Consequently, there is a collection of nonnegative reals
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}\right\rangle
such that

{\mathbf{v}}-{\mathbf{w}}=\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}.

Now, consider the vector

{\mathbf{v}}^{\prime}\coloneqq{\mathbf{w}}+\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}\lfloor\lambda_{\mathbf{d}}\rfloor\cdot{\mathbf{d}}=\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}(L+\lfloor\lambda_{\mathbf{d}}\rfloor)\cdot{\mathbf{d}}.

Clearly
{\mathbf{v}}^{\prime}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})
. As
{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})
by assumption, we have
{\mathbf{v}}-{\mathbf{v}}^{\prime}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})
as well. Furthermore,

\|{\mathbf{v}}-{\mathbf{v}}^{\prime}\|_{\infty}=\left\|\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}(\lambda_{\mathbf{d}}-\lfloor\lambda_{\mathbf{d}}\rfloor)\cdot{\mathbf{d}}\right\|_{\infty}\leqslant|\mathcal{D}_{\mathcal{G}}|\cdot\max_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}\|{\mathbf{d}}\|_{\infty}\leqslant|\mathcal{D}|\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}.

By
lemma

15
we conclude that there exist integer coefficients
\left\langle\mu_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}\right\rangle
such that

{\mathbf{v}}-{\mathbf{v}}^{\prime}=\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}\mu_{\mathbf{d}}\cdot{\mathbf{d}}\qquad\textrm{and}\qquad\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}|\mu_{\mathbf{d}}|\leqslant L.

Hence,

{\mathbf{v}}={\mathbf{v}}^{\prime}+({\mathbf{v}}-{\mathbf{v}}^{\prime})=\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}(L+\lfloor\lambda_{\mathbf{d}}\rfloor+\mu_{\mathbf{d}})\cdot{\mathbf{d}}.

It now remains to observe that each coefficient
L+\lfloor\lambda_{\mathbf{d}}\rfloor+\mu_{\mathbf{d}}
is a nonnegative integer, because
\lambda_{\mathbf{d}}\geqslant 0
and
|\mu_{\mathbf{d}}|\leqslant L
. This shows that
{\mathbf{v}}\in\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})
, thereby completing the proof.

\lrcorner

4.2
Regular lattices

As mentioned in
section

1
, the key idea in our approach is to guess the remainders of the entries of the sought solution modulo some large integer. To describe this idea formally, we consider regular lattices defined as follows.

Let
K
be a positive integer. For a vector of residues
{\mathbf{r}}\in\{0,1,\ldots,K-1\}^{\mathbf{t}}
, where
{\mathbf{t}}
is a tuple of variables, we define the
regular lattice

\Lambda^{K}_{{\mathbf{r}}}
:

\Lambda^{K}_{{\mathbf{r}}}\coloneqq\{{\mathbf{v}}\in\mathbb{Z}^{{\mathbf{t}}}\penalty\ |\penalty\ {\mathbf{v}}(t)\equiv{\mathbf{r}}(t)\bmod K\textrm{ for all }t\in{\mathbf{t}}\}.

In other words,
\Lambda^{K}_{\mathbf{r}}
comprises all integer vectors in which the remainders mod
K
on all coordinates are exactly as specified in
{\mathbf{r}}
. Note that regular lattices are affine rather than linear. In particular,
{\mathbf{0}}\in\Lambda^{K}_{\mathbf{r}}
if and only if
{\mathbf{r}}={\mathbf{0}}
, and hence a regular lattice
\Lambda^{K}_{\mathbf{r}}
is not the form
\mathsf{lattice}(\mathcal{D})
for a multiset of vectors
\mathcal{D}
, unless
{\mathbf{r}}={\mathbf{0}}
.

We will need the following simple claim about fractionality of solutions to systems of equations.

Lemma 17
.

Let
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
be a set of vectors, where
{\mathbf{t}}
is a tuple of variables. Then there is a positive integer
C
, computable from
\mathcal{D}
, satisfying the following: for every
{\mathbf{v}}\in\mathsf{span}(\mathcal{D})\cap\mathbb{Z}^{\mathbf{t}}
there exist coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that

{\mathbf{v}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}\qquad\textrm{and}\qquad C\lambda_{\mathbf{d}}\textrm{ is an integer for every }{\mathbf{d}}\in\mathcal{D}.

\lrcorner

Proof
.

Let
{\mathbf{z}}
be a tuple of variables containing one variable
z_{\mathbf{d}}
for each
{\mathbf{d}}\in\mathcal{D}
, and let
D
be the
{\mathbf{z}}\times{\mathbf{t}}
matrix such that the column of
D
corresponding to
z_{\mathbf{d}}\in{\mathbf{z}}
is
{\mathbf{d}}
. Thus, collections of coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
as in the lemma statement correspond to solutions
\boldsymbol{\lambda}\in\mathbb{Z}^{\mathbf{z}}
of the system of equations
D{\mathbf{z}}={\mathbf{v}}
. By first restricting the rows of
D
to a linearly independent set of rows, and then adding some
\{0,1\}
row vectors together with zeroes on the right hand side, we can obtain a system of equations
\widetilde{D}{\mathbf{z}}=\widetilde{{\mathbf{v}}}
such that every solution to
\widetilde{D}{\mathbf{z}}=\widetilde{{\mathbf{v}}}
is also a solution to
D{\mathbf{z}}={\mathbf{v}}
, and
\widetilde{D}
is a non-singular square matrix. It now follows from Cramer rules that if
\boldsymbol{\lambda}\in\mathbb{Z}^{\mathbf{z}}
is the unique solution to
\widetilde{D}{\mathbf{z}}=\widetilde{{\mathbf{v}}}
, then
\det\widetilde{D}\cdot{\boldsymbol{\lambda}}
is an integer. Therefore, we may set
C\coloneqq\det\widetilde{D}
, where
\widetilde{D}
is any non-singular square matrix that can be obtained from
D
by first restricting it to a linearly independent set of rows, and then extending this set of rows to a row basis using
\{0,1\}
row vectors. Note that
C
is clearly computable from
D
.

\lrcorner

We now use
lemma

17
to prove the following statement that relates regular lattices with integer lattices generated by sets of vectors.

Lemma 18
.

Let
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
be a set of vectors, where
{\mathbf{t}}
is a tuple of variables. Then there is a positive integer
K
, computable from
\mathcal{D}
, satisfying the following: for every positive integer
K^{\prime}
divisible by
K
and every vector of residues
{\mathbf{r}}\in\{0,1,\ldots,K^{\prime}-1\}^{\mathbf{t}}
,

\mathsf{span}(\mathcal{D})\cap\Lambda^{K^{\prime}}_{\mathbf{r}}\subseteq\mathsf{lattice}(\mathcal{D})\qquad\textrm{or}\qquad\mathsf{lattice}(\mathcal{D})\cap\Lambda^{K^{\prime}}_{\mathbf{r}}=\emptyset.

\lrcorner

Proof
.

We set
K\coloneqq C
, where
C
is the integer provided by
lemma

17
for
\mathcal{D}
. Fix any positive integer
K^{\prime}
divisible by
K
and
{\mathbf{r}}\in\{0,1,\ldots,K^{\prime}-1\}^{\mathbf{t}}
.
It suffices to prove that if there exists
{\mathbf{u}}\in\mathsf{lattice}(\mathcal{D})\cap\Lambda^{K^{\prime}}_{\mathbf{r}}
, then in fact
\mathsf{span}(\mathcal{D})\cap\Lambda^{K^{\prime}}_{\mathbf{r}}\subseteq\mathsf{lattice}(\mathcal{D})
. Consider any
{\mathbf{v}}\in\mathsf{span}(\mathcal{D})\cap\Lambda^{K^{\prime}}_{\mathbf{r}}
. Since
{\mathbf{u}},{\mathbf{v}}\in\Lambda^{K^{\prime}}_{\mathbf{r}}
, every entry of the vector
{\mathbf{u}}-{\mathbf{v}}
is divisible by
K^{\prime}
, so also by
K
. It follows that

{\mathbf{u}}-{\mathbf{v}}=K\cdot{\mathbf{w}}\quad\textrm{for some }{\mathbf{w}}\in\mathbb{Z}^{{\mathbf{t}}}.

Since
{\mathbf{u}},{\mathbf{v}}\in\mathsf{span}(\mathcal{D})
, we also have
{\mathbf{w}}\in\mathsf{span}(\mathcal{D})
. By
lemma

17
, there exist coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that

{\mathbf{w}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}\qquad\textrm{and}\qquad K\lambda_{\mathbf{d}}\textrm{ is an integer for all }{\mathbf{d}}\in\mathcal{D}.

Therefore, we have

{\mathbf{u}}-{\mathbf{v}}=K\cdot{\mathbf{w}}=\sum_{{\mathbf{d}}\in\mathcal{D}}(K\lambda_{\mathbf{d}})\cdot{\mathbf{d}},

where coefficients
K\lambda_{\mathbf{d}}
are integral. So
{\mathbf{u}}-{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D})
. As
{\mathbf{u}}\in\mathsf{lattice}(\mathcal{D})
by assumption, we conclude that
{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D})
as well; this concludes the proof.

\lrcorner

4.3
Reduction to polyhedral constraints

We proceed to the cornerstone of our approach: the theorem stated below, which was presented in
section

2
as
theorem

4
. Intuitively, it says that under fixing residues modulo a large integer, membership in an integer cone is equivalent to membership in a carefully crafted polyhedron.

Theorem 19
(Reduction to Polyhedral Constraints).

Let
\mathcal{D}\subseteq\mathbb{Z}^{\mathbf{t}}
be a set of vectors, where
{\mathbf{t}}
is a tuple of variables. Then there exists a positive integer
B
, computable from
\mathcal{D}
, satisfying the following: for every vector of residues
{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{\mathbf{t}}
, there is a finite set
\mathcal{Q}\subseteq\mathbb{Z}^{\mathbf{t}}\times\mathbb{Z}
such that

\Lambda^{B}_{\mathbf{r}}\cap\mathsf{intCone}(\mathcal{D})=\Lambda^{B}_{\mathbf{r}}\cap\left\{{\mathbf{v}}\in\mathbb{R}^{\mathbf{t}}\penalty\ |\penalty\ \langle{\mathbf{q}},{\mathbf{v}}\rangle\geqslant a\textrm{ for all }({\mathbf{q}},a)\in\mathcal{Q}\right\}.

Moreover, there is an algorithm that given
\mathcal{D}
and
{\mathbf{r}}
, computes
\mathcal{Q}
satisfying the above.

\lrcorner

Proof
.

Let
\mathcal{F}
be a dual representation of
\mathsf{cone}(\mathcal{D})
, computed from
\mathcal{D}
using
theorem

12
. Further, let

•

K
be the least common multiple of all integers
K_{\mathcal{G}}
obtained by applying
lemma

18
to
\mathcal{D}_{\mathcal{G}}
for every
\mathcal{G}\subseteq\mathcal{F}
, and

•

M
be the integer obtained by applying
lemma

16
to
\mathcal{D}
and
\mathcal{F}
.

We define

\widehat{M}\coloneqq M+|\mathcal{D}|\cdot\max_{{\mathbf{f}}\in\mathcal{F}}\|{\mathbf{f}}\|_{1}\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty},

and set

B_{0}\coloneqq K,\qquad B_{i}\coloneqq\widehat{M}\cdot B_{i-1}\quad\textrm{for }i=1,2,\ldots,|\mathcal{F}|,\qquad\textrm{and}\qquad B\coloneqq 2\cdot B_{|\mathcal{F}|}.

We are left with constructing a suitable set
\mathcal{Q}
for a given
{\mathbf{r}}\in\{0,1,\ldots,B-1\}^{{\mathbf{t}}}
.

For convenience, denote

\mathcal{R}\coloneqq\Lambda_{\mathbf{r}}^{B}\cap\mathsf{cone}(\mathcal{D})\qquad\textrm{and}\qquad\mathcal{Z}\coloneqq\Lambda_{\mathbf{r}}^{B}\cap\mathsf{intCone}(\mathcal{D}).

For every
{\mathbf{f}}\in\mathcal{F}
, let
p_{\mathbf{f}}
be the unique integer in
\{0,1,\ldots,B-1\}
such that

p_{\mathbf{f}}\equiv\langle{\mathbf{f}},{\mathbf{r}}\rangle\mod B.

Observe the following.

Claim 1
.

For every
{\mathbf{f}}\in\mathcal{F}
and
{\mathbf{v}}\in\mathcal{R}
, we have

\langle{\mathbf{f}},{\mathbf{v}}\rangle\in\{p_{\mathbf{f}},p_{\mathbf{f}}+B,p_{\mathbf{f}}+2B,\ldots\}.

\lrcorner

Proof
.

As
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D})
and
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
, we have
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant 0
. As
{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}
, we also have
\langle{\mathbf{f}},{\mathbf{v}}\rangle\equiv\langle{\mathbf{f}},{\mathbf{r}}\rangle\equiv p_{\mathbf{f}}\bmod B
. The claim follows.

\lrcorner

For a given vector
{\mathbf{v}}\in\mathcal{R}
, call

{\mathbf{f}}\in\mathcal{F}

tight
for
{\mathbf{v}}
if
\langle{\mathbf{v}},{\mathbf{f}}\rangle=p_{\mathbf{f}}
. Importantly,
1
implies the following: if
{\mathbf{f}}
is not tight for
{\mathbf{v}}
, then
\langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant p_{\mathbf{f}}+B
. Futher, let

\mathsf{Tight}({\mathbf{v}})\coloneqq\{{\mathbf{f}}\in\mathcal{F}\penalty\ |\penalty\ {\mathbf{f}}\textrm{ is tight for }{\mathbf{v}}\}.

The next claim is the key step. Its proof relies on a carefully crafted application of the Deep-in-the-Cone Lemma (
lemma

16
).

Claim 2
.

Suppose
{\mathbf{u}}\in\mathcal{Z}
and
{\mathbf{v}}\in\mathcal{R}
are such that
\mathsf{Tight}({\mathbf{u}})\supseteq\mathsf{Tight}({\mathbf{v}})
. Then
{\mathbf{v}}\in\mathcal{Z}
as well.

\lrcorner

Proof
.

Denote
\ell\coloneqq|\mathcal{F}|
for brevity.
Enumerate
\mathcal{F}
as
\{{\mathbf{f}}_{1},{\mathbf{f}}_{2},\ldots,{\mathbf{f}}_{\ell}\}
so that

\langle{\mathbf{f}}_{1},{\mathbf{v}}\rangle\leqslant\langle{\mathbf{f}}_{2},{\mathbf{v}}\rangle\leqslant\langle{\mathbf{f}}_{3},{\mathbf{v}}\rangle\leqslant\ldots\leqslant\langle{\mathbf{f}}_{\ell},{\mathbf{v}}\rangle,

and recall that all these values are nonnegative integers due to
{\mathbf{v}}
being an integer vector in
\mathsf{cone}(\mathcal{D})
and
\mathcal{F}
being the dual representation of
\mathsf{cone}(\mathcal{D})
. Let
k\in\{0,1,\ldots,\ell\}
be the largest index such that

\langle{\mathbf{f}}_{i},{\mathbf{v}}\rangle\leqslant B_{i}\qquad\textrm{for all }i\in\{1,2,\ldots,k\},

and denote

\mathcal{G}\coloneqq\{{\mathbf{f}}_{1},{\mathbf{f}}_{2},\ldots,{\mathbf{f}}_{k}\}\qquad\textrm{and}\qquad\widehat{B}\coloneqq B_{k}.

By the maximality of
k
it follows that either
k=\ell
, or
k<\ell
and
\langle{\mathbf{f}}_{k+1},{\mathbf{v}}\rangle>B_{k+1}
. In any case, by the choice of the sequence
B_{0},B_{1},\ldots,B_{\ell}
we have

\langle{\mathbf{g}},{\mathbf{v}}\rangle\leqslant\widehat{B}\quad\textrm{for all }{\mathbf{g}}\in\mathcal{G}\qquad\textrm{and}\qquad\langle{\mathbf{f}},{\mathbf{v}}\rangle>\widehat{M}\widehat{B}\quad\textrm{for all }{\mathbf{f}}\in\mathcal{F}-\mathcal{G}.

(3)

Since
\widehat{B}<B
, all vectors of
\mathcal{G}
are tight for
{\mathbf{v}}
; see
1
. As
\mathsf{Tight}({\mathbf{u}})\supseteq\mathsf{Tight}({\mathbf{v}})
, these vectors are tight for
{\mathbf{u}}
as well. We conclude that

\langle{\mathbf{g}},{\mathbf{u}}\rangle=\langle{\mathbf{g}},{\mathbf{v}}\rangle=p_{{\mathbf{g}}}\qquad\textrm{for all }{\mathbf{g}}\in\mathcal{G}.

(4)

Since
{\mathbf{u}}\in\mathcal{Z}
by assumption, there is a collection of nonnegative integers
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that

{\mathbf{u}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}.

Define now a collection of nonnegative integers
\left\langle\mu_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
as follows:

•

if
{\mathbf{d}}\notin\mathcal{D}_{\mathcal{G}}
, then
\mu_{\mathbf{d}}=\lambda_{\mathbf{d}}
; and

•

otherwise, if
{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}
, then
\mu_{\mathbf{d}}
is the unique integer in
\{0,1,\ldots,K-1\}
such that
\lambda_{\mathbf{d}}\equiv\mu_{\mathbf{d}}\bmod K
.

Consider now any
{\mathbf{e}}\in\mathcal{D}-\mathcal{D}_{\mathcal{G}}
. By the definition of
\mathcal{D}_{\mathcal{G}}
, there exists
{\mathbf{g}}\in\mathcal{G}
such that
\langle{\mathbf{g}},{\mathbf{e}}\rangle>0
, which by integrality entails
\langle{\mathbf{g}},{\mathbf{e}}\rangle\geqslant 1
. By
13
,
eq.

3
, and
eq.

4
, we have

\widehat{B}\geqslant\langle{\mathbf{g}},{\mathbf{v}}\rangle=\langle{\mathbf{g}},{\mathbf{u}}\rangle=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot\langle{\mathbf{g}},{\mathbf{d}}\rangle\geqslant\lambda_{{\mathbf{e}}}\cdot\langle{\mathbf{g}},{\mathbf{e}}\rangle\geqslant\lambda_{\mathbf{e}}=\mu_{\mathbf{e}}.

Together with the straightforward inequality
\mu_{\mathbf{d}}\leqslant K\leqslant\widehat{B}
for all
{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}
, we conclude that

\mu_{\mathbf{d}}\leqslant\widehat{B}\qquad\textrm{for all }{\mathbf{d}}\in\mathcal{D}.

(5)

Let

{\mathbf{u}}^{\prime}\coloneqq\sum_{{\mathbf{d}}\in\mathcal{D}}\mu_{\mathbf{d}}\cdot{\mathbf{d}}.

Clearly
{\mathbf{u}}^{\prime}\in\mathsf{intCone}(\mathcal{D})
. Our goal is to show that
lemma

16
can be applied to
{\mathbf{v}}-{\mathbf{u}}^{\prime}
.

First, consider any
{\mathbf{f}}\in\mathcal{F}-\mathcal{G}
. Then by
eq.

3
and
eq.

5
, we have

\displaystyle\langle{\mathbf{f}},{\mathbf{v}}-{\mathbf{u}}^{\prime}\rangle

\displaystyle=\langle{\mathbf{f}},{\mathbf{v}}\rangle-\langle{\mathbf{f}},{\mathbf{u}}^{\prime}\rangle>\widehat{M}\widehat{B}-\sum_{{\mathbf{d}}\in\mathcal{D}}\mu_{\mathbf{d}}\cdot\langle{\mathbf{f}},{\mathbf{d}}\rangle

\displaystyle\geqslant\widehat{M}\widehat{B}-|\mathcal{D}|\cdot\max_{{\mathbf{f}}\in\mathcal{F}}\|{\mathbf{f}}\|_{1}\cdot\max_{{\mathbf{d}}\in\mathcal{D}}\|{\mathbf{d}}\|_{\infty}\cdot\widehat{B}=M\widehat{B}\geqslant M.

(6)

Next, consider any
{\mathbf{g}}\in\mathcal{G}
. Then

\langle{\mathbf{g}},{\mathbf{v}}-{\mathbf{u}}^{\prime}\rangle=\sum_{{\mathbf{d}}\in\mathcal{D}}(\lambda_{\mathbf{d}}-\mu_{\mathbf{d}})\cdot\langle{\mathbf{g}},{\mathbf{d}}\rangle=\sum_{{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}}(\lambda_{\mathbf{d}}-\mu_{\mathbf{d}})\cdot\langle{\mathbf{g}},{\mathbf{d}}\rangle+\sum_{{\mathbf{d}}\in\mathcal{D}-\mathcal{D}_{\mathcal{G}}}(\lambda_{\mathbf{d}}-\mu_{\mathbf{d}})\cdot\langle{\mathbf{g}},{\mathbf{d}}\rangle.

(7)

Note that for
{\mathbf{d}}\in\mathcal{D}-\mathcal{D}_{\mathcal{G}}
we have
\lambda_{\mathbf{d}}=\mu_{\mathbf{d}}
, while for
{\mathbf{d}}\in\mathcal{D}_{\mathcal{G}}
we have
\langle{\mathbf{g}},{\mathbf{d}}\rangle=0
. So both summands on the right hand side of
eq.

7
are equal to
0
, implying that

\langle{\mathbf{g}},{\mathbf{v}}-{\mathbf{u}}^{\prime}\rangle=0\qquad\textrm{for all }{\mathbf{g}}\in\mathcal{G}.

(8)

Observe that since
\mathcal{F}
is the dual representation of
\mathsf{cone}(\mathcal{D})
,
eq.

6
and
eq.

8
together imply that

{\mathbf{v}}-{\mathbf{u}}^{\prime}\in\mathsf{cone}(\mathcal{D}).

(9)

Then by combining
eq.

8
,
eq.

9
, and
lemma

14
we conclude that

{\mathbf{v}}-{\mathbf{u}}^{\prime}\in\mathsf{cone}(\mathcal{D}_{\mathcal{G}}).

(10)

Finally, observe that for every
{\mathbf{d}}\in\mathcal{D}
,
\lambda_{\mathbf{d}}-\mu_{\mathbf{d}}
is an integer divisible by
K
. Therefore,
{\mathbf{u}}-{\mathbf{u}}^{\prime}=K\cdot{\mathbf{w}}
for some integer vector
{\mathbf{w}}
, implying that
{\mathbf{u}}-{\mathbf{u}}^{\prime}\in\Lambda_{{\mathbf{0}}}^{K}
.
As
{\mathbf{u}},{\mathbf{v}}\in\Lambda_{{\mathbf{r}}}^{B}
and
K
divides
B
, we also have
{\mathbf{v}}-{\mathbf{u}}\in\Lambda_{{\mathbf{0}}}^{K}
. Combining these two observations yields

{\mathbf{v}}-{\mathbf{u}}^{\prime}\in\Lambda_{{\mathbf{0}}}^{K}.

(11)

Noting that
{\mathbf{0}}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}})\cap\Lambda_{\mathbf{0}}^{K}
and
K
is divisible by
K_{\mathcal{G}}
, by applying
lemma

18
to
\mathcal{D}_{\mathcal{G}}
we infer that

\mathsf{span}(\mathcal{D}_{\mathcal{G}})\cap\Lambda_{{\mathbf{0}}}^{K}\subseteq\mathsf{lattice}(\mathcal{D}_{\mathcal{G}}).

Combining this with
eq.

10
and
eq.

11
yields

{\mathbf{v}}-{\mathbf{u}}^{\prime}\in\mathsf{lattice}(\mathcal{D}_{\mathcal{G}}).

(12)

Now, assertions
eq.

6
,
eq.

10
, and
eq.

12
show that we can use
lemma

16
to conclude that

{\mathbf{v}}-{\mathbf{u}}^{\prime}\in\mathsf{intCone}(\mathcal{D}_{\mathcal{G}}).

Since
{\mathbf{u}}^{\prime}=\sum_{{\mathbf{d}}\in\mathcal{D}}\mu_{\mathbf{d}}\cdot{\mathbf{d}}
and
\left\langle\mu_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
are nonnegative integers, we have
{\mathbf{u}}^{\prime}\in\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})
as well. So as a sum of two vectors from
\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})
,
{\mathbf{v}}
also belongs to
\mathsf{intCone}(\mathcal{D}_{\mathcal{G}})
and we are done.

\lrcorner

For every
\mathcal{G}\subseteq\mathcal{F}
, let

\mathcal{R}_{\mathcal{G}}\coloneqq\{{\mathbf{v}}\in\mathcal{R}\penalty\ |\penalty\ \mathsf{Tight}({\mathbf{v}})=\mathcal{G}\}.

In other words,
\mathcal{R}_{\mathcal{G}}
comprises all vectors in
\mathcal{R}
for which
\mathcal{G}
is exactly the set of tight vectors in
\mathcal{F}
. Thus,
\{\mathcal{R}_{\mathcal{G}}\colon\mathcal{G}\subseteq\mathcal{F}\}
is a partition of
\mathcal{R}
.

Let
\mathscr{L}
be the family of subsets of
\mathcal{F}
consisting of all
\mathcal{G}\subseteq\mathcal{F}
such that
\mathcal{R}_{\mathcal{G}}\cap\mathcal{Z}\neq\emptyset
. Further, let
\mathscr{L}^{\downarrow}
be the downward closure of
\mathscr{L}
: a set
\mathcal{G}\subseteq\mathcal{F}
belongs to
\mathscr{L}^{\downarrow}
if and only if there exists
\mathcal{G}^{\prime}\supseteq\mathcal{G}
such that
\mathcal{G}^{\prime}\in\mathscr{L}
.
The following statement is an immediate corollary of
2
.

Claim 3
.

Suppose
\mathcal{G}\subseteq\mathcal{F}
. If
\mathcal{G}\in\mathscr{L}^{\downarrow}
then
\mathcal{R}_{\mathcal{G}}\subseteq\mathcal{Z}
, and if
\mathcal{G}\notin\mathscr{L}^{\downarrow}
then
\mathcal{R}_{\mathcal{G}}\cap\mathcal{Z}=\emptyset
. Consequently,

\mathcal{Z}=\bigcup_{\mathcal{G}\in\mathscr{L}^{\downarrow}}\mathcal{R}_{\mathcal{G}}.

\lrcorner

Next, we show that the characterization of
3
can be expressed through linear inequalities.

Claim 4
.

For every
{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}
, the following conditions are equivalent:

(1)

{\mathbf{v}}\in\mathsf{intCone}(\mathcal{D})
; and

(2)

{\mathbf{v}}\in\mathsf{cone}(\mathcal{D})
and

\sum_{{\mathbf{g}}\in\mathcal{G}}\langle{\mathbf{g}},{\mathbf{v}}\rangle\geqslant 1+\sum_{{\mathbf{g}}\in\mathcal{G}}p_{\mathbf{g}}\qquad\textrm{for all }\mathcal{G}\subseteq\mathcal{F}\textrm{ such that }\mathcal{G}\notin\mathscr{L}^{\downarrow}.

\lrcorner

Proof
.

We first prove implication
(1)
\Rightarrow
(2)
. Since
{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}\cap\mathsf{intCone}(\mathcal{D})=\mathcal{Z}
, by
3
we have that
{\mathbf{v}}\in\mathcal{R}_{\mathcal{G}}
for some
\mathcal{G}\in\mathscr{L}^{\downarrow}
. In particular, for every
\mathcal{G}^{\prime}\subseteq\mathcal{F}
with
\mathcal{G}^{\prime}\notin\mathscr{L}^{\downarrow}
,
\mathcal{G}^{\prime}
is not a subset of
\mathcal{G}
, implying that there exists some
{\mathbf{h}}\in\mathcal{G}^{\prime}-\mathcal{G}
. As
\mathcal{G}=\mathsf{Tight}({\mathbf{v}})
,
{\mathbf{h}}
is not tight for
{\mathbf{v}}
, hence
\langle{\mathbf{h}},{\mathbf{v}}\rangle\geqslant p_{\mathbf{h}}+B
by
1
. Hence, by
1
again,

\sum_{{\mathbf{g}}\in\mathcal{G}^{\prime}}\langle{\mathbf{g}},{\mathbf{v}}\rangle\geqslant B+\sum_{{\mathbf{g}}\in\mathcal{G}^{\prime}}p_{\mathbf{g}}\geqslant 1+\sum_{{\mathbf{g}}\in\mathcal{G}^{\prime}}p_{\mathbf{g}};

and this holds for each
\mathcal{G}^{\prime}\subseteq\mathcal{F}
with
\mathcal{G}^{\prime}\notin\mathscr{L}^{\downarrow}
.
As
{\mathbf{v}}\in\mathsf{intCone}(\mathcal{D})
entails
{\mathbf{v}}\in\mathsf{cone}(\mathcal{D})
, this proves
(2)
.

We now move to the implication
(2)
\Rightarrow
(1)
. Since
{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}\cap\mathsf{cone}(\mathcal{D})=\mathcal{R}
, by
3
it suffices to show that the unique
\mathcal{G}\subseteq\mathcal{F}
for which
{\mathbf{v}}\in\mathcal{R}_{\mathcal{G}}
satisfies
\mathcal{G}\in\mathscr{L}^{\downarrow}
. Note
{\mathbf{v}}\in\mathcal{R}_{\mathcal{G}}
is equivalent to
\mathcal{G}=\mathsf{Tight}({\mathbf{v}})
. Therefore
\langle{\mathbf{g}},{\mathbf{v}}\rangle=p_{\mathbf{g}}
for all
{\mathbf{g}}\in\mathcal{G}
, implying that

\sum_{{\mathbf{g}}\in\mathcal{G}}\langle{\mathbf{g}},{\mathbf{v}}\rangle=\sum_{{\mathbf{g}}\in\mathcal{G}}p_{\mathbf{g}}.

Hence we necessarily must have
\mathcal{G}\in\mathscr{L}^{\downarrow}
, for otherwise
(2)
would not be satisfied.

\lrcorner

We may now define
\mathcal{Q}
to be the set of the following pairs:

•

({\mathbf{f}},0)
for all
{\mathbf{f}}\in\mathcal{F}
; and

•

\left(\sum_{{\mathbf{g}}\in\mathcal{G}}{\mathbf{g}},1+\sum_{{\mathbf{g}}\in\mathcal{G}}p_{\mathbf{g}}\right)
for all
\mathcal{G}\subseteq\mathcal{F}
with
\mathcal{G}\notin\mathscr{L}^{\downarrow}.

As
\mathcal{F}
is a dual representation of
\mathsf{cone}(\mathcal{D})
, we have
\mathsf{cone}(\mathcal{D})=\{{\mathbf{v}}\in\mathbb{R}^{\mathbf{t}}\penalty\ |\penalty\ \langle{\mathbf{f}},{\mathbf{v}}\rangle\geqslant 0\textrm{ for all }{\mathbf{f}}\in\mathcal{F}\}
. Hence,
4
directly implies that

\Lambda_{\mathbf{r}}^{B}\cap\mathsf{intCone}(\mathcal{D})=\Lambda_{\mathbf{r}}^{B}\cap\left\{{\mathbf{v}}\in\mathbb{R}^{\mathbf{t}}\penalty\ |\penalty\ \langle{\mathbf{q}},{\mathbf{v}}\rangle\geqslant a\textrm{ for all }({\mathbf{q}},a)\in\mathcal{Q}\right\},

as required.

It remains to argue that the set
\mathcal{Q}
can be computed given
\mathcal{D}
and
{\mathbf{r}}
. For this, it suffices to distinguish which sets
\mathcal{G}\subseteq\mathcal{F}
belong to
\mathscr{L}
and which not, because based on this knowledge we may compute
\mathscr{L}^{\downarrow}
and then construct
\mathcal{Q}
right from the definition. (Recall here that by
theorem

12
,
\mathcal{F}
can be computed from
\mathcal{D}
.) Testing whether given
\mathcal{G}\subseteq\mathcal{F}
belongs to
\mathscr{L}
boils down to verifying whether there exists
{\mathbf{v}}\in\mathbb{Z}^{\mathbf{t}}
such that

•

{\mathbf{v}}\in\Lambda_{\mathbf{r}}^{B}
, or equivalently,
{\mathbf{v}}=B\cdot{\mathbf{w}}+{\mathbf{r}}
for some
{\mathbf{w}}\in\mathbb{Z}^{\mathbf{t}}
;

•

\langle{\mathbf{g}},{\mathbf{v}}\rangle=p_{\mathbf{g}}
for all
{\mathbf{g}}\in\mathcal{G}
; and

•

\langle{\mathbf{g}},{\mathbf{v}}\rangle\geqslant p_{\mathbf{g}}+1
for all
{\mathbf{g}}\in\mathcal{F}-\mathcal{G}
; and

•

{\mathbf{v}}\in\mathsf{lattice}(\mathcal{D})
, or equivalently, there exist nonnegative integer coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
such that
{\mathbf{v}}=\sum_{{\mathbf{d}}\in\mathcal{D}}\lambda_{\mathbf{d}}\cdot{\mathbf{d}}
.

These conditions form an integer program with
2|{\mathbf{t}}|+|\mathcal{D}|
variables:
|{\mathbf{t}}|
variables for
{\mathbf{v}}
,
|{\mathbf{t}}|
variables for
{\mathbf{w}}
, and
|\mathcal{D}|
variables for the coefficients
\left\langle\lambda_{\mathbf{d}}\colon{\mathbf{d}}\in\mathcal{D}\right\rangle
. Hence we may just check the feasibility of this program using any of the standard algorithms for integer programming, e.g. the algorithm of Kannan
[
26
]
.

4.4
Algorithm for two-stage stochastic integer programming

With all the tools prepared, we are ready to give a proof of
theorem

11

Proof
(of
theorem

11
).

For each matrix
D_{i}
, let
\mathcal{D}_{i}
be the set of columns of
D_{i}
. Since every member of
\mathcal{D}_{i}
is a vector in
\mathbb{Z}^{\mathbf{t}}
with all entries of absolute value at most
\Delta
, and there are
(2\Delta+1)^{|{\mathbf{t}}|}
different such vectors, we have
|\mathcal{D}_{i}|\leqslant(2\Delta+1)^{|{\mathbf{t}}|}

2^{(2\Delta+1)^{|{\mathbf{t}}|}}
distinct sets

.

Now, the feasibility of the program

is equivalent to the following assertion: there exist
{\mathbf{u}}\in\mathbb{Z}_{\geqslant 0}^{\mathbf{x}}
such that

(13)

For each

apply
theorem

19
to
\mathcal{D}_{i}
, yielding a positive integer

, computable from
\mathcal{D}_{i}
. Let

for

is bounded by

and

Towards verification of assertion

Or equivalently,

Apply the algorithm of

19
to
\mathcal{D}_{i}
and
{\mathbf{r}}_{i}

The conditions above form an integer program with

5.1
Graver bases

One ingredient that we will repeatedly use in our proofs is the notion of the Graver basis of a matrix, which consists of
\sqsubseteq
-minimal integral elements of the kernel. Formally, the
integer kernel
of a matrix
D\in\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
, denoted
\ker^{\mathbb{Z}}(D)
, is the set of all integer vectors
{\mathbf{u}}\in\mathbb{Z}^{{\mathbf{t}}}
such that
D{\mathbf{u}}=\mathbf{0}
. The
Graver basis
of
D
is the set
\mathsf{Graver}(D)
of all
\sqsubseteq
-minimal non-zero elements of
\ker^{\mathbb{Z}}(D)
. In other words, a vector
{\mathbf{u}}\in\ker^{\mathbb{Z}}(D)-\{\mathbf{0}\}
belongs to
\mathsf{Graver}(D)
if there is no
{\mathbf{u}}^{\prime}\sqsubseteq{\mathbf{u}}
,
{\mathbf{u}}^{\prime}\notin\{\mathbf{0},{\mathbf{u}}\}
, such that
{\mathbf{u}}^{\prime}\in\ker^{\mathbb{Z}}(D)
as well.

Note that since
\mathsf{Graver}(D)
is an antichain in the
\sqsubseteq
order, which is a well quasi-order on
\mathbb{Z}^{\mathbf{t}}
by Dickson’s Lemma,
\mathsf{Graver}(D)
is always finite. There are actually many known bounds on the norms of the elements of the Graver basis under different assumptions about the matrix. We will use the following one tailored to matrices with few rows.

Lemma 21
(Lemma 2 of
[
16
]
).

Let
D\in\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
be an integer matrix, and let
\Delta=\|D\|_{\infty}
. Then for every
{\mathbf{g}}\in\mathsf{Graver}(D)
, it holds that

\displaystyle\|{\mathbf{g}}\|_{1}\leqslant(2|{\mathbf{t}}|\Delta+1)^{|{\mathbf{t}}|}

\lrcorner

We will also use the fact that every solution to an integer program can be decomposed into some solution of bounded norm and a multiset consisting of elements of the Graver basis. This fact was observed by Pottier in
[
41
, Corollary 1]
, we recall his proof for completeness.

Lemma 22
.

Let
D\in\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
be an integer matrix and
{\mathbf{b}}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{t}}}
be an integer vector. Then for every
{\mathbf{w}}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
such that
D{\mathbf{w}}={\mathbf{b}}
, there exists a vector
{\widehat{{\mathbf{w}}}}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
and a multiset
\mathcal{G}
consisting of nonnegative elements of
\mathsf{Graver}(D)
such that

D{\widehat{{\mathbf{w}}}}={\mathbf{b}},\qquad\|{\widehat{{\mathbf{w}}}}\|\leqslant(2|{\mathbf{t}}|(\|D\|_{\infty}+\|{\mathbf{b}}\|_{\infty})+1)^{|{\mathbf{t}}|},\qquad\textrm{and}\qquad{\mathbf{w}}={\widehat{{\mathbf{w}}}}+\sum_{{\mathbf{g}}\in\mathcal{G}}{\mathbf{g}}.

\lrcorner

Proof
.

Let
z
be a fresh variable that does not belong to
{\mathbf{y}}
and let
{\mathbf{z}}\coloneqq{\mathbf{y}}\cup\{z\}
. Further, let
D^{\prime}\in\mathbb{Z}^{{\mathbf{z}}\times{\mathbf{t}}}
be the matrix obtained from
D
by adding column
D^{\prime}[z]=-{\mathbf{b}}
, and
{\mathbf{w}}^{\prime}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{z}}}
be the vector obtained from
{\mathbf{w}}
by adding the entry
{\mathbf{w}}^{\prime}[z]=1
. Observe that
D{\mathbf{w}}={\mathbf{b}}
entails
D^{\prime}{\mathbf{w}}^{\prime}=\mathbf{0}
, which means that
{\mathbf{w}}^{\prime}\in\ker^{\mathbb{Z}}(D^{\prime})
. Every element of the integer kernel can be decomposed into a sign-compatible sum of elements of the Graver basis; see e.g.
[
14
, Lemma 3.2.3]
. Therefore, there is a multiset
\mathcal{G}^{\prime}
consisting of nonnegative elements of
\mathsf{Graver}(D^{\prime})
such that
\sum_{{\mathbf{g}}^{\prime}\in\mathcal{G}^{\prime}}{\mathbf{g}}^{\prime}={\mathbf{w}}^{\prime}
.
Due to the sign-compatibility, exactly one element
{\widehat{{\mathbf{w}}}}^{\prime}\in\mathcal{G}^{\prime}
has
{\widehat{{\mathbf{w}}}}[z]=1
, and all the other elements
{\mathbf{g}}^{\prime}\in\mathcal{G}^{\prime}-\{{\widehat{{\mathbf{w}}}}^{\prime}\}
satisfy
{\mathbf{g}}^{\prime}[z]=0
. We can now obtain
{\widehat{{\mathbf{w}}}}
and
\mathcal{G}
from
{\widehat{{\mathbf{w}}}}^{\prime}
and
\mathcal{G}^{\prime}-\{{\widehat{{\mathbf{w}}}}^{\prime}\}
, respectively, by stripping every vector from the coordinate corresponding to variable
z
(formally, restricting the domain to
{\mathbf{y}}
). As
{\mathbf{g}}^{\prime}[z]=0
for all
{\mathbf{g}}^{\prime}\in\mathcal{G}^{\prime}-\{{\widehat{{\mathbf{w}}}}^{\prime}\}
, it follows that all elements of
\mathcal{G}
belong to
\mathsf{Graver}(D)
. Finally, from
lemma

21
applied to
D^{\prime}
we conclude that
\|{\widehat{{\mathbf{w}}}}\|_{\infty}\leqslant\|{\widehat{{\mathbf{w}}}}^{\prime}\|_{\infty}\leqslant(2|{\mathbf{t}}|(\|D\|_{\infty}+\|{\mathbf{b}}\|_{\infty})+1)^{|{\mathbf{t}}|}
.

5.2
Decomposing bricks

As explained in
section

2
, the key idea in the proof of
theorem

20
is to decompose right-hand sides of the program (that is, vectors
{\mathbf{b}}_{i}
) into smaller and smaller vectors while preserving the optimum value of the program. The next lemma is the key observation that provides a single step of the decomposition.

Lemma 23
(Brick Decomposition Lemma).

There exists a function
g(k,\Delta)\in 2^{(k\Delta)^{{\mathcal{O}}(k)}}
such that the following holds.
Let
D\in\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
be a matrix and
{\mathbf{b}}\in\mathbb{Z}^{{\mathbf{t}}}
be a vector such that
\|{\mathbf{b}}\|_{\infty}>g(k,\Delta)
,
where
k=|{\mathbf{t}}|
and
\Delta=\|D\|_{\infty}
. Then there are non-zero vectors
{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\in\mathbb{Z}^{\mathbf{t}}
such that the following conditions hold:

•

{\mathbf{b}}^{\prime},{\mathbf{b}}^{\prime\prime}\sqsubseteq{\mathbf{b}}
and
{\mathbf{b}}={\mathbf{b}}^{\prime}+{\mathbf{b}}^{\prime\prime}
; and

•

for every
{\mathbf{v}}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
satisfying
D{\mathbf{v}}={\mathbf{b}}
, there exist
{\mathbf{v}}^{\prime},{\mathbf{v}}^{\prime\prime}\in\mathbb{Z}_{\geqslant 0}^{{\mathbf{y}}}
such that

{\mathbf{v}}={\mathbf{v}}^{\prime}+{\mathbf{v}}^{\prime\prime},\qquad D{\mathbf{v}}^{\prime}={\mathbf{b}}^{\prime},\qquad\textrm{and}\qquad D{\mathbf{v}}^{\prime\prime}={\mathbf{b}}^{\prime\prime}.

\lrcorner

Throughout this section, for a multiset
V
of vectors or numbers, we denote by
\sum V
the sum of the elements in
V
.

The crucial ingredient to prove

is the following result of Klein
[
27
]

[
11
]

[

Lemma 24
(Klein Lemma, Theorem 4.1 of
[
11
]
for
\epsilon=1
and with adjusted notation).

Let
{\mathbf{t}}
be a tuple of variables with
|{\mathbf{t}}|=k
and let
T_{1},\ldots,T_{n}
be non-empty multisets of vectors in
\mathbb{Z}^{{\mathbf{t}}}
such that for all

and

, and the sum of all elements in each multiset is the same:

\displaystyle\sum T_{1}=\sum T_{2}=\ldots=\sum T_{n}.

Then there exist non-empty submultisets

, each of size bounded by

\displaystyle\sum S_{1}=\sum S_{2}=\ldots=\sum S_{n}.

\lrcorner

We also need the following lemma about partitioning a multiset of vectors into small submultisets with sign-compatible sums.

Lemma 25
.

Let
U
be a multiset of vectors in
\mathbb{Z}^{\mathbf{t}}
with
\|{\mathbf{u}}\|_{\infty}\leqslant\Delta
for all
{\mathbf{u}}\in U
, where
{\mathbf{t}}
is a tuple of variables with
|{\mathbf{t}}|=k
. Further, let
{\mathbf{b}}=\sum U
. Then one can partition
U
into a collection of non-empty submultisets
\left\langle U_{i}\colon i\in I\right\rangle
so that for every
i\in I
, we have
|U_{i}|\leqslant{\mathcal{O}}(\Delta)^{2^{k-1}}
and
\sum U_{i}\sqsubseteq{\mathbf{b}}
.

\lrcorner

Proof
.

We prove the statement for a bound
|U_{i}|\leqslant\tau_{k}
, where
\left\langle\tau_{k}\colon k=1,2,3,\ldots\right\rangle
is a sequence defined recursively as follows:

\displaystyle\tau_{1}

\displaystyle\coloneqq 3\Delta+1,\qquad\qquad\qquad\ \ \ \,\textrm{and}

\displaystyle\tau_{k}

\displaystyle\coloneqq(3\Delta\tau_{k-1}+1)\cdot\tau_{k-1}\qquad\textrm{for }k\geqslant 2.

It is easy to verify that
\tau_{k}\in{\mathcal{O}}(\Delta)^{2^{k-1}}
.

We proceed by induction on
k
. Let us start with the base case
k=1
.

Claim 5
.

For
|{\mathbf{t}}|=k=1
,
lemma

25
holds.

\lrcorner

Proof
.

We can simplify the notation by just considering
U
to be a mulitset of integers bounded in absolute value by
\Delta
and summing up to
b
. By changing every number to its opposite if necessary, without loss of generality, we may assume that
b\geqslant 0
. Observe that it suffices to prove the following: if
|U|>\tau_{1}=3\Delta+1
, then
U
can be partitioned into non-empty submultisets
U^{\prime},U^{\prime\prime}
with
0\leqslant\sum U^{\prime},\sum U^{\prime\prime}\leqslant b
. Indeed, if we achieve this, then we can apply the same reasoning to
U^{\prime}
and
U^{\prime\prime}
recursively to eventually obtain a suitable partition of
U
into submultisets with sizes bounded by
3\Delta+1
.

Suppose
n\coloneqq|U|>3\Delta+1
. We make the following case distinction: either
b>\Delta
or
b\leqslant\Delta
.

Suppose first that
b>\Delta
. Let
u_{1},\ldots,u_{n}
be an arbitrary enumeration of the elements of
U
. Since
\sum U=b>\Delta
and
u\leqslant\Delta
for all
u\in U
, there exists an integer
m\in\{1,\ldots,n-1\}
such that

\sum_{i=1}^{m}u_{i}\in\{1,\ldots,\Delta\}.

Then letting

U^{\prime}\coloneqq\{u_{1},\ldots,u_{m}\}\qquad\textrm{and}\qquad U^{\prime\prime}\coloneqq\{u_{m+1},\ldots,u_{n}\},

we observe that
1\leqslant\sum U^{\prime},\sum U^{\prime\prime}\leqslant b-1
; in particular both
U^{\prime}
and
U^{\prime\prime}
are non-empty. Hence,
U^{\prime}
and
U^{\prime\prime}
satisfy all the required properties.

Now suppose that
b\leqslant\Delta
. Starting with
U_{1}\coloneqq U
, we iteratively remove numbers from
U
in
n
rounds according to the following rules. In round
i
, we do the following:

•

If
\sum U_{i}>0
, then in
U_{i}
there must be a positive number. Pick any such number
u_{i}
and set
U_{i+1}\coloneqq U_{i}-\{u_{i}\}
.

•

If
\sum U_{i}<0
, then in
U_{i}
there must be a negative number. Pick any such number
u_{i}
and set
U_{i+1}\coloneqq U_{i}-\{u_{i}\}
.

•

If
\sum U_{i}=0
, pick
u_{i}
to be any number in
U_{i}
and set
U_{i+1}\coloneqq U_{i}-\{u_{i}\}
.

Thus, we obtain an ordering
u_{1},\ldots,u_{n}
of the elements of
U
. We claim that

-\Delta\leqslant\sum_{i=1}^{m}u_{i}\leqslant b+\Delta\qquad\textrm{for all }i\in\{0,\ldots,m\}.

This can be verified by a straightforward induction on
m
. The base case
m=0
holds trivially, and for the induction step, observe that:

•

If
-\Delta\leqslant\sum_{i=1}^{m}u_{i}<0
, then
\sum U_{m+1}=b-\sum_{i=1}^{m}u_{i}>b\geqslant 0
, so the next picked element
u_{m+1}
is positive. Consequently
-\Delta\leqslant\sum_{i=1}^{m+1}u_{i}<\Delta\leqslant b+\Delta
, because
0<u_{i}\leqslant\Delta
.

•

Analogously, if
b<\sum_{i=1}^{m}u_{i}\leqslant b+\Delta
, then
\sum U_{m+1}=b-\sum_{i=1}^{m}u_{i}<0
, so the next picked element
u_{m+1}
is negative. Consequently
-\Delta\leqslant b-\Delta\leqslant\sum_{i=1}^{m+1}u_{i}\leqslant b+\Delta
, because
-\Delta\leqslant u_{i}<0
.

•

Finally, if
0\leqslant\sum_{i=1}^{m}u_{i}\leqslant b
, then
-\Delta\leqslant\sum_{i=1}^{m}u_{i}\leqslant b+\Delta
due to
|u_{m+1}|\leqslant\Delta
.

Note that the set
\{-\Delta,\ldots,b+\Delta\}
contains
2\Delta+b+1\leqslant 3\Delta+1
distinct numbers.
Since
n>3\Delta+1
, by pigeonhole principle, there exist numbers
0\leqslant m<m^{\prime}<3\Delta+2
such that

\sum_{i=1}^{m}u_{i}=\sum_{i=1}^{m^{\prime}}u_{i},\qquad\textrm{implying that}\qquad\sum_{i=m+1}^{m^{\prime}}u_{i}=0.

Therefore, if we set

U^{\prime}\coloneqq\{u_{m+1},\ldots,u_{m^{\prime}}\}\qquad\textrm{and}\qquad U^{\prime\prime}\coloneqq U-U^{\prime},

then we have
\sum U^{\prime}=0
and
\sum U^{\prime\prime}=b
. As
m<m^{\prime}<3\Delta+2\leqslant n
, both
U^{\prime}
and
U^{\prime\prime}
are non-empty. Hence
U^{\prime}
and
U^{\prime\prime}
satisfy all the required properties.

This concludes the proof of the base case
k=1
.

\lrcorner

Let us proceed to the induction step for
k>1
. Let
t\in{\mathbf{t}}
be an arbitrarily selected variable of

Our next goal is to prove that the faithful decomposition of

can be computed algorithmically, in fixed-parameter time when parameterized by
|{\mathbf{y}}|
,

, and

, assuming

is given on input in binary. The idea is to iteratively extract a large fraction of the elements of the decomposition, so that the whole process finishes after a number of steps that is logarithmic in

. Each extraction step will be executed using a fixed-parameter algorithm for deciding Presburger Arithmetic. Let us give a brief introduction.

Presburger Arithmetic is the first-order theory of the structure
\langle\mathbb{Z}_{\geqslant 0},+,0,1,2,\ldots\rangle
, that is, of nonnegative integers equipped with addition (treated as a binary function) and all elements of the universe as constants. More precisely, a
term
is an arithmetic expression using the binary function
+
, variables (meant to be evaluated to nonnegative integers), and constants (nonnegative integers). Formulas considered in Presburger Arithmetic are constructed from atomic formulas — equalities of terms — using the standard syntax of first-order logic, including standard boolean connectives, negation, and both existential and universal quantification (over nonnegative integers). The semantics is as expected. Note that while comparison is not directly present in the signature, it can be easily emulated by existentially quantifying a slack variable: for two variables
x,y
, the assertion
x\leqslant y
is equivalent to
\exists_{z}\ x+z=y
. As usual,
\varphi({\mathbf{x}})
denotes a formula with a tuple of free variables
{\mathbf{x}}
, while a
sentence
is a formula without free variables. The
length
of a formula
\varphi({\mathbf{x}})
, denoted
\|\varphi\|
, is defined in a standard way by structural induction on the formula and the terms contained within. Here, all constants are deemed to have length
1
.

Presburger
[
42
]
famously proved that Presburger Arithmetic is decidable: there is an algorithm that given a sentence
\varphi
of first-order logic over
\langle\mathbb{Z}_{\geqslant 0},+,0,1,2,\ldots\rangle
, decides whether
\varphi
is true. As observed by Koutecký and Talmon
[
38
]
, known algorithms for deciding Presburger Arithmetic can be understood as fixed-parameter algorithms in the following sense.

Theorem 27
(follows from
[
38
, Theorem 1]
).

Given a first-order sentence
\varphi
over
\langle\mathbb{Z}_{\geqslant 0},+,0,1,2,\ldots\rangle
, with constants encoded in binary, one can decide whether
\varphi
is true in time
f(\|\varphi\|)\cdot(\log\Delta)^{{\mathcal{O}}(1)}
, where
\Delta\geqslant 3
is an upper bound on all the constants present in
\varphi
and
f
is a computable function.

\lrcorner

We remark that Koutecký and Talmon discuss a more general setting where formulas are written in a more concise form, including allowing a direct usage of modular arithmetics, and one considers minimization of convex functions over tuples of variables satisfying constraints expressible in Presburger Arithmetic. Nevertheless,

. For a proof of

Lemma 28
.

Suppose
A\in\mathbb{Z}^{{\mathbf{x}}\times{\mathbf{y}}}
and
B\in\mathbb{Z}^{{\mathbf{y}}\times{\mathbf{t}}}
are matrices and
{\mathbf{d}}\in\mathbb{Z}^{\mathbf{t}}
is a vector. Then the satisfaction of the following sentence

\forall_{{\mathbf{v}}\in\mathbb{Z}^{\mathbf{y}}}\left[(B{\mathbf{v}}\leqslant{\mathbf{d}})\implies\exists_{{\mathbf{u}}\in\mathbb{Z}^{\mathbf{x}}}\,(A{\mathbf{u}}\leqslant{\mathbf{v}})\right]

can be verified in time
f(\Delta,|{\mathbf{x}}|,|{\mathbf{y}}|,|{\mathbf{t}}|)\cdot\left(\log\|{\mathbf{d}}\|_{\infty}\right)^{{\mathcal{O}}(1)}
, where
\Delta=\max(\|A\|_{\infty},\|B\|_{\infty})
and
f
is a computable function.

\lrcorner

Proof
.

It suffices to combine
theorem

27
with the observation that the considered sentence can be easily rewritten to an equivalent first-order sentence over
\langle\mathbb{Z}_{\geqslant 0},+,0,1,2,\ldots\rangle
, whose length depends only on
\Delta,|{\mathbf{x}}|,|{\mathbf{y}}|,|{\mathbf{t}}|
and whose constants are bounded by
\|{\mathbf{d}}\|_{\infty}
. Indeed, every inequality present in the constraint
B{\mathbf{v}}\leqslant{\mathbf{d}}
can be rewritten to an equality of two terms as follows:

•

Every summand on the left hand side with a negative coefficient is moved to the right hand side. Also, if the constant on the right hand side is negative, it is moved to the left hand side. Thus, after this step, every side is a sum of variables multiplied by positive coefficients and positive constants.

•

Every summand of the form
\alpha v
, where
\alpha
is a positive coefficient and
v={\mathbf{v}}[y]
for some
y\in{\mathbf{y}}
, is replaced by
\underbrace{v+v+\ldots+v}_{\alpha}
. Note here that
\alpha\leqslant\Delta
.

•

Inequality is turned into an equality by existentially quantifying a nonnegative slack variable.

We apply a similar rewriting to the constraints present in
A{\mathbf{u}}\leqslant{\mathbf{v}}
. After these steps, the sentence is a first-order sentence over
\langle\mathbb{Z}_{\geqslant 0},+,0,1,2,\ldots\rangle
.

\lrcorner

c_{ij}z_{ij}
. It is easy to see that after this modification, only
\{0,1\}
entries will appear in the blocks
C
. This comes at the price of increasing the number of global variables and the number of linking constraints by
k^{2}
, and possibly adding some large (but bounded by
n
in absolute value) entries to the block
B
.

Next, we remove large entries in
A
. Suppose then
a_{ij}>1
for some
i,j\in[k]
; recall that we assume also that
a_{ij}\leqslant n
. In program
P
, entry
a_{ij}
occurs in summands of the form
a_{ij}x_{j}
; every group of local constraints contains one such summand. Therefore, the idea is to (i) copy the variable
x_{j}
to
a_{i}
new local variables, (ii) use one new linking constraint to define a new global variable
z^{\prime}_{ij}
equal to the sum of the copies, and hence equal to
a_{ij}x_{j}
, and (iii) replace each usage of the summand
a_{ij}x_{j}
in local constraints with just the variable
z^{\prime}_{ij}
. This idea can be executed as follows:

(i)

For every
t=1,\ldots,n
, introduce two new local variables
p_{ij,t},p^{\prime}_{ij,t}
together with two new local constraints:

\displaystyle-x_{j}+p^{\prime}_{ij,t}=0;\qquad\textrm{and}

\displaystyle p_{ij,t}-p^{\prime}_{ij,t}=0\textrm{\, when \,}t\leqslant a_{ij}\qquad\textrm{and}\qquad p_{ij,t}=0\textrm{\, when \,}t>a_{ij}.

(ii)

Add a new global variable
z^{\prime}_{ij}
together with a new linking constraint

-z^{\prime}_{ij}+\sum_{t=1}^{n}p_{ij,t}=0.

(iii)

Replace every usage of summand
a_{ij}x_{ij}
with variable
z^{\prime}_{ij}
in every local constraint within
P
.

Entries
a_{ij}\in\{-n,\ldots,-2\}
can be removed similarly: we perform the above construction for
|a_{ij}|
, and then replace each summand
a_{ij}x_{ij}
with
-z^{\prime}_{ij}
instead of
z^{\prime}_{ij}
. Entries with large absolute values in
B
can be removed in exactly the same way.

It is straightforward to see that by applying all the modifications presented above, we obtain a uniform
4
-block program with
{\mathcal{O}}(k^{2})
global variables,
{\mathcal{O}}(k^{2})
linking constraints,
{\mathcal{O}}(k^{2})
local variables in each group of local variables, and
{\mathcal{O}}(k^{2})
local constraints in each group of local constraints. Moreover, all entries in the blocks
A,B,C
belong to
\{-1,0,1\}
, while blocks
D_{i}
got modified only by adding some
\{-1,0,1\}
entries. Hence, we can just solve the modified program using the assumed fixed-parameter algorithm for feasibility of uniform
4
-block programs parameterized by the dimensions of the block and the maximum absolute value of any entry appearing in the constraint matrix.
