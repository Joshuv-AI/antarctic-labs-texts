The 1.5 Order Formalism does not Generate
a Valid BRS Transformation for Supergravity

Abstract




\proofmodefalse

The 1.5 order formalism (sometimes called a ‘trick’) is the cornerstone of modern supergravity. In this paper, the free massive Wess Zumino theory is used as a simple toy model to look at the BRS symmetry of the first, second and 1.5 order formalisms. This easily shows that the 1.5 order formalism is flawed for all theories. The 1.5 algebra naively appears to close.
However, when it is analyzed in detail, in a simple model, where easy calculations are available, the 1.5 formalism always generates an invalid BRS operator, which is not even nilpotent.
This clearly is also the case for supergravity. It follows that a revised and completed set of nilpotent first order supergravity transformations is needed to properly understand 3+1 dimensional supergravity. Such a set seems easy to write down, by simply adding two more auxiliary fields so that the spin connection becomes part of a super–YM multiplet.

First, second and 1.5 order formalisms for supergravity:

In supergravity, it appears that one could choose to use the first order formalism, the second order formalism or the 1.5 order formalism. They differ by their treatment of the spin connection field
w_{\mu ab}
. This field
w_{\mu ab}
seems to be an auxiliary in the theory, and so it can be removed in various ways, or left in place. The only formalism that is actually used at present is the 1.5 order formalism, because it is the simplest. However, as is shown here, it is also fundamentally flawed.

First Order Formalism for supergravity:
In the first order formalism, the vierbein, the spin connection and the gravitino are all considered to be fundamental variables, and the equations of motion are obtained by varying each of them independently. It is called first order because it turns out that the equations of motion here for the fields
e_{\mu a}
and
w_{\mu ab}
are of first order in the derivatives.

The first order identity for supergravity

{\cal M}_{\rm Sugra}=\int d^{4}x\left\{\frac{\delta{\cal A}_{\rm Sugra}}{\delta e_{\mu a}}\Delta_{1}e_{\mu a}+\frac{\delta{\cal A}_{\rm Sugra}}{\delta\Psi_{\mu}}\Delta_{1}\Psi_{\mu}+\frac{\delta{\cal A}_{\rm Sugra}}{\delta\Psi_{\mu}}\Delta_{1}{\overline{\Psi}}_{\mu}\right.

(3)

\left.+\frac{\delta{\cal A}_{\rm Sugra}}{\delta M}\Delta_{1}M+\frac{\delta{\cal A}_{\rm Sugra}}{\delta{\overline{M}}}\Delta_{1}{\overline{M}}+\frac{\delta{\cal A}_{\rm Sugra}}{\delta B^{\mu}}\Delta_{1}B^{\mu}+\frac{\delta{\cal A}_{\rm Sugra}}{\delta w_{\mu ab}}\Delta_{1}w_{\mu ab}\right\}=0

(4)

This identity would summarize all the invariances of the action.
The variations

e_{\mu a},\Psi_{\mu},\cdots

To close the algebra we also need the variations of the ghosts

In the second order formalism,

The 1.5 order formalism tries to take advantage
of the merits of both the first order formalism, and the second order formalism.
The action is expressed as a function of the same variables as in the first order formulation (because that is the simplest formulation). {\cal M}_{\rm Sugra\;With\;1.5\;Trick}=\int d^{4}x\left\{\frac{\delta{\cal A}}{\delta e_{\mu a}}\Delta_{1.5}e_{\mu a}+\frac{\delta{\cal A}}{\delta\Psi_{\mu}}\Delta_{1.5}\Psi_{\mu}+\frac{\delta{\cal A}}{\delta\Psi_{\mu}}\Delta_{1.5}{\overline{\Psi}}_{\mu}\right.

The three kinds of order formalisms in the WZ multiplet:
We can easily analyze the basic features of the three kinds of order formalism in a very much simpler model. Instead of dealing with the spin connection in supergravity we will deal with the auxiliary fields
F,{\overline{F}}
in the WZ model. The same idea applies to any auxiliary field in any theory. For the WZ multiplet, we will start with the first order, then generate the second order, and then contemplate the 1.5 order.
Then we will return to the situation in supergravity.

Here is the action for the WZ model,
including a simple mass term of the chiral type. We use two component complex spinors, because the theory is naturally adapted to them.

{\cal A}_{\rm Fields}=\int d^{4}x\left\{\partial_{\mu}A\partial^{\mu}{\overline{A}}+\chi^{\alpha}\sigma^{\mu\dot{\beta}}_{\alpha}\partial_{\mu}{\overline{\chi}}_{\dot{\beta}}+F{\overline{F}}\right.

(19)

\left.+m\left(AF-\frac{1}{2}\chi^{\alpha}\chi_{\alpha}\right)+m\left({\overline{A}}{\overline{F}}-\frac{1}{2}{\overline{\chi}}^{\dot{\alpha}}{\overline{\chi}}_{\dot{\alpha}}\right)\right\}

(20)

This action obeys an identity that arises from supersymmetry. We define the following variations:

\Delta_{1}A=C^{\alpha}\chi_{\alpha};\;\Delta_{1}\chi_{\alpha}=\sigma^{\mu\dot{\beta}}_{\alpha}\partial_{\mu}A{\overline{C}}_{\dot{\beta}}+FC_{\alpha};\;\Delta_{1}F={\overline{C}}_{\dot{\beta}}\overline{\sigma}^{\mu\dot{\beta}}_{\alpha}\partial_{\mu}\chi^{\alpha}

(21)

\Delta_{1}{\overline{A}}={\overline{C}}^{\dot{\alpha}}{\overline{\chi}}_{\dot{\alpha}};\;\Delta_{1}{\overline{\chi}}_{\dot{\alpha}}=\overline{\sigma}^{\mu\beta}_{\dot{\alpha}}\partial_{\mu}{\overline{A}}C_{\beta}+{\overline{F}}C_{\dot{\alpha}};\;\Delta_{1}{\overline{F}}=C_{\beta}\sigma^{\mu\beta}_{\dot{\alpha}}\partial_{\mu}{\overline{\chi}}^{\dot{\alpha}}

(22)

This is rigid supersymmetry, so we assume that the ghosts
C_{\alpha},{\overline{C}}_{\dot{\alpha}}
are constants, independent of the coordinates, so that

\Delta_{1}C_{\alpha}=\Delta_{1}{\overline{C}}_{\dot{\alpha}}=0;\;\partial_{\mu}C_{\alpha}=\partial_{\mu}{\overline{C}}_{\dot{\alpha}}=0

(23)

The First Order Identity:
The following is the identity in this theory that is generated by its supersymmetry:

{\cal M}_{\rm WZ}=\int d^{4}x\left\{\frac{\delta{\cal A}}{\delta A}\Delta_{1}A+\frac{\delta{\cal A}}{\delta\chi_{\alpha}}\Delta_{1}\chi_{\alpha}+\frac{\delta{\cal A}}{\delta F}\Delta_{1}F\right.

(24)

By saying that this is an identity, we mean that adding all the terms together gives us exactly zero, without imposing any equation that is assumed to be satisfied by the fields. Formula (
24
