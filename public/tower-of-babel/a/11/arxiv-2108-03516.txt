A Geometric Interpretation to Fixed-Point Theory on S b S_{b} -Metric Spaces
Hülya AYTİMUR, Nihal TAŞ

Abstract
. In this paper we present some fixed-figure theorems as a geometric approach to the fixed-point theory when the number of fixed points of a self-mapping is more than one. To do this, we modify the Jleli-Samet type contraction and define new contractions on S b S_{b} -metric spaces. Also, we give some necessary examples to show the validity of our theoretical results. Keywords: Fixed figure, fixed disc, fixed ellipse, fixed hyperbola, fixed Cassini curve, fixed Apollonius circle. MSC(2010): 54H25; 47H09; 47H10.

Introduction and Background

Classical fixed-point theory started with the Banach fixed-point theorem

and is an applicable area to topology, analysis, geometry, applied
mathematics, engineering etc. Metric fixed-point theory has been studied and
generalized with various aspects. One of these aspects is to generalize the
used contractive condition (for example, see
[

aspect is to generalize the used metric space such as, a
b

Definition 1.1
.

[
1
]
Let
X
be a nonempty set,
b\geq 1
a given
real number and
d:X\times X\rightarrow[0,\infty)
a function
satisfying the following conditions for all
x,y,z\in X:

(b1)

d(x,y)=0
if and only if
x=y
.

(b2)

d(x,y)=d(y,x)
.

(b3)

d(x,z)\leq b[d(x,y)+d(y,z)]

Then the function

is called a
b
-metric on
X
and the pair
(X,d)
is
called a
b
-metric space.

Definition 1.2
.

[
17
]
Let
X
be a nonempty set and
S:X\times X\times X\rightarrow[0,\infty)
be a function satisfying the following
conditions for all
x,y,z,a\in X:

(S1)

S(x,y,z)=0
if and only if
x=y=z
,

(S2)

S(x,y,z)\leq S(x,x,a)+S(y,y,a)+S(z,z,a)

Then
S
is called an
S
-metric on
X
and the pair
(X,S)

S
-metric space.

Definition 1.3
.

[
18
]
Let

be a
given real number. A function

(S_{b}1)

(S_{b}2)

The notion of a fixed figure was defined as a generalization of the notions
of a fixed circle and a fixed disc as follows:

A geometric figure
\mathcal{F}

Cassini curve etc.) contained in the fixed point set
Fix\left(T\right)=\left\{x\in X:x=Tx\right\}
is called a

(a fixed

[

[

By the above motivation, the main of this paper is to obtain some
fixed-figure results on an
S_{b}
-metric space. To do this, we define new
Jleli-Samet type contractions. Using these new contractions, we prove
fixed-disc results, fixed-ellipse results, fixed-hyperbola results,
fixed-Cassini curve results and fixed-Apollonius circle results on an
S_{b}
-metric space. Also, we give an example to show the validity of our
obtained theorems.

Main Results

In this section, we present some fixed-figure results on an
S_{b}
-metric space. Before these results, we give the following definitions:

Definition 2.1
.

Let
(X,S_{b})
be an
S_{b}
-metric space with
b\geq 1
and
x_{0},x_{1},x_{2}\in X
,
r\in[0,\infty)

(1)

The disc centered at
x_{0}
with radius
r
is defined by

D_{x_{0},r}^{S_{b}}=\left\{x\in X:S_{b}(x,x,x_{0})\leq r\right\}\text{.}

(2)

The ellipse
E_{r}^{S_{b}}(x_{1},x_{2})
is defined by

E_{r}^{S_{b}}(x_{1},x_{2})=\left\{x\in X:S_{b}\left(x,x,x_{1}\right)+S_{b}\left(x,x,x_{2}\right)=r\right\}\text{.}

(3)

The hyperbola
H_{r}^{S_{b}}(x_{1},x_{2})
is defined by

H_{r}^{S_{b}}(x_{1},x_{2})=\left\{x\in X:\left|S_{b}\left(x,x,x_{1}\right)-S_{b}\left(x,x,x_{2}\right)\right|=r\right\}\text{.}

(4)

The Cassini curve
C_{r}^{S_{b}}(x_{1},x_{2})
is defined by

C_{r}^{S_{b}}(x_{1},x_{2})=\left\{x\in X:S_{b}\left(x,x,x_{1}\right)S_{b}\left(x,x,x_{2}\right)=r\right\}\text{.}

(5)

The Apollonius circle
A_{r}^{S_{b}}(x_{1},x_{2})
is defined by

A_{r}^{S_{b}}(x_{1},x_{2})=\left\{x\in X-\{x_{2}\}:\frac{S_{b}\left(x,x,x_{1}\right)}{S_{b}\left(x,x,x_{2}\right)}=r\right\}\text{.}

Definition 2.3
.

Let
\left(X,S_{b}\right)
be an
S_{b}
-metric space and
f:X\rightarrow X

S_{b}\left(x,x,fx\right)>0\Rightarrow\varphi\left(S_{b}\left(x,x,fx\right)\right)\leq\left[\varphi\left(S_{b}\left(x,x,x_{0}\right)\right)\right]^{\alpha}

is
such that
\varphi

is called Jleli-Samet type
D_{x_{0}}
-
S_{b}

Theorem 2.1
.

Let
\left(X,S_{b}\right)
be an
S_{b}
-metric space and
f:X\rightarrow X
Jleli-Samet type

-contraction with

Then
f

Proof.

At first, we show
fx_{0}=x_{0}
. On the contrary, let
fx_{0}\neq x_{0}.

Using the Jleli-Samet type
D_{x_{0}}
-

-contraction hypothesis, we get

\displaystyle\varphi\left(S_{b}\left(x_{0},x_{0},fx_{0}\right)\right)

\displaystyle\leq

\displaystyle\left[\varphi\left(S_{b}\left(x_{0},x_{0},x_{0}\right)\right)\right]^{\alpha}

\displaystyle=

\displaystyle\left[\varphi\left(0\right)\right]^{\alpha},

a contradiction. So we get

(2.5)

To show that

r=0.
Then we have

fx_{0}=x_{0}.

Case 2

Let
r>0

Using the hypothesis, we obtain

\displaystyle\varphi\left(S_{b}\left(x,x,fx\right)\right)

\displaystyle\left[\varphi\left(S_{b}\left(x,x,x_{0}\right)\right)\right]^{\alpha}

\displaystyle\leq

\displaystyle\left[\varphi\left(r\right)\right]^{\alpha}

\displaystyle\left[\varphi\left(S_{b}\left(x,x,fx\right)\right)\right]^{\alpha}

Hence, it should be

In this paper, we present some new contractions and some fixed-figure
