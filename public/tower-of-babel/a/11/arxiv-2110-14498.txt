Structural Parameterizations of Budgeted Graph Coloring
Susobhan Bandopadhyay, Suman Banerjee, Aritra Banik, Venkatesh Raman

Abstract
We introduce a variant of the graph coloring problem, which we denote as Budgeted Coloring Problem ( BCP ). Given a graph G G , an integer c c and an ordered list of integers { b 1 , b 2 , … , b c } \{b_{1},b_{2},\ldots,b_{c}\} , BCP asks whether there exists a proper coloring of G G where the i i -th color is used to color at most b i b_{i} many vertices. This problem generalizes two well-studied graph coloring problems, Bounded Coloring Problem ( BoCP ) and Equitable Coloring Problem ( ECP ) and as in the case of other coloring problems, it is NP -hard even for constant values of c c . So we study BCP under the paradigm of parameterized complexity, particularly with respect to (structural) parameters that specify how far (the deletion distance) the input graph is from a tractable graph class. • We show that BCP is FPT (fixed-parameter tractable) parameterized by the vertex cover size. This generalizes a similar result for ECP and immediately extends to the BoCP , which was earlier not known. • We show that BCP is polynomial time solvable for cluster graphs generalizing a similar result for ECP . However, we show that BCP is FPT , but unlikely to have polynomial kernel, when parameterized by the deletion distance to clique, contrasting the linear kernel for ECP for the same parameter. • While the BoCP is known to be polynomial time solvable on split graphs, we show that BCP is NP -hard on split graphs. As BoCP is hard on bipartite graphs when c > 3 c>3 , the result follows for BCP as well. We provide a dichotomy result by showing that BCP is polynomial time solvable on bipartite graphs when c = 2 c=2 . We also show that BCP is NP -hard on co-cluster graphs, contrasting the polynomial time algorithm for ECP and BoCP . Finally we present an 𝒪 ∗ ​ ( 2 | V ⁡ ( G ) | ) \mathcal{O}^{*}(2^{|V(G)|}) algorithm for the BCP , generalizing the known algorithm with a similar bound for the standard chromatic number.

Graph Classes

A graph is said to be

A parameterization of a problem is assigning an integer

Known Results for Coloring

It is a well-known fact that a bipartite graph is
2

Note that split graphs are a sub-class of chordal graphs. The classical coloring problem can be solved in polynomial time. 3.2
On Co-Cluster Graphs

In this section we present another contrasting result. While
ECP
is known to be polynomial time solvable on co-cluster graphs, we prove that
BCP
is
NP
-hard on this class of graphs. It is not hard to verify that
BoCP
can also be solved in polynomial time. Now, we prove the following theorem by showing a reduction from
3
-Partition Problem
.

Theorem 2
.

BCP
on co-cluster graphs is
NP
-hard.

Proof.

Let
\mathcal{I}=(S,w)
be a
3
-Partition Problem
problem instance, where
S=\{x_{1},x_{2},x_{2},\cdots,x_{3c}\}
and
w=\frac{n}{c},~n=\sum x_{i}
. We create an instance
\mathcal{I}^{\prime}=(G,3c,\mathcal{B})
of
BCP
as follows. Here
G
is a co-cluster graph with
c
parts, where each part has
3n+w
many vertices and
\mathcal{B}=\{n+x_{1},n+x_{2},n+x_{3},\cdots,n+x_{3c}\}
. Next, we show that
\mathcal{I}
is a YES instance if and only if
\mathcal{I}^{\prime}
is a YES instance.

Let
\mathcal{I}
is a YES instance, then there are
c
sets containing three elements each, adding up to
w
. We can color each part of G by using the corresponding three colors whose budgets add up to
3n+w
. Thus
\mathcal{I}^{\prime}
is also a YES instance.

Now, assume that
\mathcal{I}^{\prime}
is a YES instance. Observe that, one color can be used in only one part. If each part gets exactly three colors then we have nothing to prove. Therefore we consider the case when there exists at least one part that gets at most two colors or at least four colors. For the first case, say
i
and
j
be that two colors. As
2n+x_{i}+x_{j}<3n+w
, all the vertices in that part is not colored with color
i
and
j
. For the second case, observe that as
4n>3n+w
, some color is not fully used to color that part. Also observe that the budgets add up to the number of the vertices in
G
. As a result, there is at least one part that contains some uncolored vertices, which is contradiction.

Note that,
3
-Partition Problem
is
NP
-hard even when all the elements are polynomial in the number of elements in the set
[
17
]
. Thus, we can safely assume that each
x_{i}
is polynomial in
3c
. Hence, the reduction is also polynomial time.
∎

I
is adjacent to some vertex
d
of
D
in
G
, and hence is non-adjacent to that vertex in
G^{\prime}
, and so can be colored with the color of
d
. Thus we can color every vertex in
I
with the first
k
colors. Now, we have only
n-k
uncolored vertices in
C
. Color them with the last
n-k
colors. Hence we have a proper budgeted coloring of
G^{\prime}
.

To prove the converse, note that in any proper budgeted coloring of
G^{\prime}
, all
n
colors must be used to color the vertices in
C
.
Without loss of generality assume that
u_{i}
gets the color
i
, for
i=1
to
n
.
Therefore the vertices in
I
are colored with the first
k
colors (as only they have budgets more than
1
).
Thus
\cup_{i\in[k]}\overline{N}(u_{i})=I
. Hence
\{w_{1},w_{2},\ldots,w_{k}\}
forms a dominating set in
G
. This completes the proof. ∎

It is known that the dominating set problem is
W[2]
-hard with respect to the solution size (
k
) as a parameter. In the reduction described in Theorem
3
, the number of colors having a budget greater than one is also
k
. Hence, this reduction is parameter preserving for the parameter ‘number of colors with a budget greater than one’ leading to the following corollary.

Corollary 3
.

BCP
parameterized by the number of colors with a budget greater than one is
W[2]
-hard.

3.4
On Bipartite Graphs

It was known that the bounded coloring problem is
NP
-hard on bipartite graphs when
c\geq 3

[
3
]
. We extend this result for
ECP
thus proving hardness for
ECP
as well as
BCP
(the later result follows from Corollary

.)

Theorem 4
.

ECP
on Bipartite Graphs is
NP
-hard even when
c=3
.

Proof.

We show a reduction from the biclique problem. Given a biclique problem instance
\mathcal{I}=(G(V_{1}\cup V_{2},E),k)
where,
|V_{1}|=|V_{2}|=n
, the question is whether
G
has
\mathcal{K}_{k,k}
as a subgraph? We construct a
ECP
instance
\mathcal{I}^{\prime}=(G^{\prime}(V^{\prime}_{1}\cup V^{\prime}_{2},E^{\prime}),3)
as follows.
V^{\prime}_{1}=V_{1}\cup\{a\}
,
V^{\prime}_{2}=V_{1}\cup W\cup\{b\}
where
a
,
b
are two new vertices and
|W|=n-3k+1
. The edge set
E^{\prime}=\{E_{1}\cup E_{2}\cup E_{3}\}
where,
E_{1}=\{(u,v)|u\in V_{1},v\in V_{2}\ \text{and}\ (u,v)\notin E\}
,
E_{2}=\{(a,v)|v\in V^{\prime}_{2}\}
and
E_{3}=\{(b,u)|u\in V^{\prime}_{1}\}
. Also we have three colors
1,2
and
3
. Since
|V(G^{\prime})|=3n-3k+3
, to achieve proper equitable coloring we must use each color exactly
n-k+1
times.

Claim 1
.

\mathcal{I}
is a YES instance iff
\mathcal{I^{\prime}}
is a YES instance.

Proof.

Let
\mathcal{I}
be a YES instance, i.e.
G
has a
\mathcal{K}_{k,k}
as a subgraph. Without loss of generality let
\{u_{1},u_{2},u_{3},\cdots,u_{k}\}\in V_{1}
and
\{v_{1},v_{2},v_{3},\cdots,v_{k}\}\in V_{2}
form the
\mathcal{K}_{k,k}
in
G
. Thus in
G^{\prime}
,
(u_{i},v_{j})\notin E^{\prime},~\forall i,j\in[k]
. Use color
1
to color all these vertices and the vertices in
W
. Color remaining
n-k+1
vertices in both
V_{1}^{\prime}
and
V_{2}^{\prime}
with color
2
and color
3
, respectively. Observe that we have a proper equitable coloring of
G^{\prime}
.

Next, assume that
G^{\prime}
admits a proper equitable coloring. Without loss of generality, assume color
1
and
2
are used to color the vertices
a
and
b
. Since
a
is adjacent to all the vertices in
V_{2}^{\prime}
, color
1
must be entirely used at vertices in
V_{1}^{\prime}
. Also, color
2
can color at most
n-k+1
many vertices of
V_{2}^{\prime}
, more precisely, at most
n-k
many vertices of
V_{2}
. Thus at least
k
vertices from both the parts
V_{1}
and
V_{2}
must be colored with color
3
. Hence they are forming a
\mathcal{K}_{k,k}
in
G
. This completes the proof.
∎

∎

3.4.1
When
c=2
.

While the
BoCP
has been known to be hard for bipartite graphs when
c\geq 3

[
3
]
, its complexity for
c=2
(especially in disconnected bipartite graphs) doesn’t seem obvious. We show that even the more general
BCP
is polynomial time solvable when
c=2

by a suitable reduction to the
subset sum problem
to prove the following.

Theorem 5
.

The
BCP
on the class of bipartite graphs can be solved in polynomial time when
c=2
.

Proof.

Let,
G(V_{1}\cup V_{2},E)
be the given bipartite graph where
|V_{1}\cup V_{2}|=n
,
b_{1}
and
b_{2}
be the budgets associated with the two colors.
Observe that,
BCP
is polynomial time solvable when the
G
is connected as we just have to ensure that the two parts of the partition satisfy the budget constraints.
When
G
is disconnected, let
P_{1},P_{2},P_{3},\cdots,P_{\ell},\ell\geq 2
be the connected components in
G
where each connected component in the graph
P_{i}=(V^{i}_{1}\cup V^{i}_{2},E_{i})
. Without loss of generality assume that
|V^{i}_{1}|\geq|V^{i}_{2}|
for all
i
. In any proper coloring, at least budget
\sum_{i\in[\ell]}V^{i}_{2}=x
is required for both the colors. Thus we can subtract
x
from the budgets
b_{1}
and
b_{2}
(and if any of the budgets is less than
x
, then the problem is a NO instance). Let,
b^{\prime}_{1}=b_{1}-x
and
b^{\prime}_{2}=b_{2}-x
be the modified budgets for the colors
1
and
2
respectively.
Let
y_{i}=|V^{i}_{1}|-|V^{i}_{2}|
for all
i\in[\ell]
. Now, each component
P_{i}
has
y_{i}
many uncolored vertices that can be colored with any of the two colors.

Let
S=\{y_{1},y_{2},y_{3},\cdots,y_{\ell}\}
and we would like to find
X\subseteq S
such that the sum of the elements of
X
is at most
b^{\prime}_{1}
and the sum of the elements of
S\setminus X
is at most
b^{\prime}_{2}
. Observe that, this is exactly the subset sum problem where each
y_{i}
is upper bounded by
n
.
It is known (see, for example
[
21
]
) that subset sum problem can be solved in time
\mathcal{O}(nw)
where
n
is the number of elements in the given set when each element is bounded by
w
. Applying that algorithm for our problem proves the theorem.
∎

3.5
On Paths Graphs

As the
BCP
is
NP
-hard on bipartite graphs when
c>2
, we study the problem on a sub-class. Here we study the problem on the class of paths and show that the problem is polynomial time solvable even when
c>2
in the following lemma.

Lemma 4
.

The problem instance
(G(V,E),\mathcal{C},\mathcal{A})
is polynomial time solvable for the family
\mathcal{P}
of paths.

Proof.

We are given with a path
P
of
n
vertices. A necessary condition is that there are at least two colors. If any color has a budget of more than
\lceil\frac{n}{2}\rceil
, truncate to
\lceil\frac{n}{2}\rceil

(as we can not use more colors than this). Now we claim that if the total budget (after truncation) is at least
n
, then the path is two colorable and it can not be otherwise. The algorithm in details as follows:

First we sort the colors in descending order based on their budgets and let the sorted list be
\mathcal{C^{\prime}}
. The content of
\mathcal{C}^{\prime}
are as follows:
\mathcal{C}^{\prime}=\{(i,b_{i}):\forall i\in[c]\}
Now we have the following two cases:

Case1:
The budget
b_{i}\leq\left\lceil\frac{n}{2}\right\rceil,\forall i\in[c]
.

The given instance is a trivial NO instance if total budgets of available color is less than
n
. Now we check for the
\left\lceil\frac{n}{2}\right\rceil
-th entry in
\mathcal{C^{\prime}}
. Then we color the odd vertices of the path
P
with first
\left\lceil\frac{n}{2}\right\rceil
-th color in
\mathcal{C^{\prime}}
and even vertices with
\left\lceil\frac{n}{2}\right\rceil+1
to
n
-th color in
\mathcal{C^{\prime}}
. As
b_{i}\leq\left\lceil\frac{n}{2}\right\rceil,\forall i\in[c]
, this will return a proper coloring of
P
.

Case2:
There exist an
i\in[c]
such that, the budget
b_{i}>\left\lceil\frac{n}{2}\right\rceil
.

Again we can say that the given instance is a trivial NO instance if total budget of available color is less than
n
. If not then start decreasing the availability of such color let
i
, until
b_{i}\leq\left\lceil\frac{n}{2}\right\rceil
. Do that for all such color. Now the reduced instance is same as the instance given in Case 1.
∎

3.6
On Brooms

In this section we prove that the
BCP
is polynomial time solvable for the class of brooms. Let
G(V,E)
be a broom such that

,
U=\{u_{1},u_{2},\cdots,u_{p}\}
,
W=\{w_{1},w_{2},\cdots,w_{q}\}
and
E=\{(w_{i},w_{i+1})|~i\in[q-1]\}\cup\{(u_{j},w_{1})|~j\in[p]\}
. In other words,

induces a path of length
q-1
,

induces an independent set of cardinality
p
and every vertex in
U
is adjacent to only
w_{1}
in the graph. Let
\mathcal{I}=(G,c,\mathcal{B})
be the given problem instance of the

on brooms. Next, we prove that if the given instance is a YES instance then there exist a coloring that uses the minimum budgeted color at
w_{1}
.

Lemma 5
.

If
\mathcal{I}
be a YES instance then there is coloring
\psi
, such that in
\psi
, the vertex
w_{1}
is colored with minimum budgeted color.

Proof.

Without loss of generality assume that
1
be the minimum budgeted color in the given instance. Let such that
a
is used at
w_{1}
in a proper coloring
\zeta
. Here we give another proper coloring
\psi
, that uses color
1
in then vertex
w_{1}
. We denote
V_{i}
as the set of vertices colored with color
i
and
\zeta(v)
as the color of
v
in the coloring
\zeta
. Observe that for any color
a
, if
|V_{a}|\leq|V_{1}|
then, by switching the color in
V_{a}
and
V_{1}
we can get a new coloring
\psi
, which is a proper coloring. Now, we prove the lemma in the following two cases.

Case 1:
|N(w_{1})\cap V_{1}|=1
.

Without loss of generality assume
N(w_{1})\cap V_{1}=\{u_{1}\}
in the coloring
\zeta
. In the new coloring
\psi
switch the color used at
w_{1}
and
u_{1}
, i.e.,
\psi(w_{1})=1
and
\psi(u_{1})=a
. Observe that
\psi
is also a proper coloring of
G
as only one neighbor of
w_{1}
is colored with
1
.

Case 2:
|N(w_{1})\cap V_{1}|\geq 2
.

Without loss of generality assume
|N(w_{1})\cap V_{1}|=k,~2\leq k\leq p+1
in the coloring
\zeta
. As
|V_{a}|>|V_{1}|
, there is at least
k
many vertices in
W\cap V_{a}
such that no neighbors of them is colored with color
1
. Let the set be
W^{\prime}
. Now, in the new coloring
\psi
, we color
N(w_{1})\cap V_{1}
with color
a
,
w_{1}
and any
k-1
many vertices from
W^{\prime}
with color
1
. Observe that, in both the cases

is a proper coloring of
G
respecting the budgets.

Case 3:
|N(w_{1})\cap V_{1}|=0
.

If the color
1
is not used in the coloring
\zeta
of
G
, then color
w_{1}
with
1
. Otherwise, pick arbitrarily one vertex from
U
, say
u_{1}
. Observe that
\zeta(u_{1})
and
\zeta(w_{1})
both can not be the same as
\zeta(w_{q})
. If
\zeta(u_{1})\neq\zeta(w_{q})
then, perform circular shifting of color starting from

to
w_{q}
. In the new coloring
\psi(u_{1})=\zeta(w_{1}),\psi(w_{1})=\zeta(w_{2}),\cdots,\psi(w_{q-1})=\zeta(w_{q}),\psi(w_{q})=\zeta(u_{1})

\psi(w_{1})=1
. If
\zeta(u_{1})=\zeta(w_{q})
and

then perform the similar circular shifting starting from

to
w_{q}
till

. Observe that

gives us proper coloring of

. This completes the proof.

∎

Now, we describe a coloring scheme using the fact that the minimum budgeted color is used to color the vertex

. Note that, we use a color at most
\lceil\frac{q}{2}\rceil
many times to color the vertices in

. Color
\min(b_{1},\lceil\frac{q}{2}\rceil)
many odd vertices of the path using the color

and color the remaining odd vertices in the path until we use that color

many times. If the number of remaining odd vertices in the path is less than

then, use the rest budget to color the even vertices in the path. Repeat this process until all the vertices in the path are colored. Observe that any vertex in
U
is non-adjacent to vertices in

. Thus any color other than

can be used to color the vertices in

(if we have not used the budget completely). Use the colors (except

) with the remaining budgets to color the vertices in

Theorem 6
.

The

is polynomial time solvable on the class of Brooms.

4
Structural Parameterization of
BCP

In this section, we address the parameterized complexity of
BCP
with respect to some structural parameters, parameters that measure the (deletion) distance to a tractable graph class.

4.1
BCP
parameterized by Cluster Vertex Deletion Number (CVD)

Recall from Section
3.1
that
BCP
is polynomial time solvable on cluster graphs. So, here we ask what if the input graph is
k
-vertices away from a cluster graph i.e., deleting
k
vertices from the graph makes the graphs a cluster graph? We show that

is
FPT
parameterized by

and an additional parameter which is the number of colors or the number of clusters in the resulting graph.
We remark that we do not need to assume that we are given the deletion set
S
, as we can find it in
\mathcal{O}^{*}(1.9102^{k})
time
[
4
]
.

Consider any instance of
\mathcal{I}=(G,c,\mathcal{B})
of

. Let

be the cluster vertex deletion set of

and
\mathcal{P}=\{P_{1},P_{2},\cdots,P_{\ell}\}
be a partition of
S
. Let
\alpha
be any proper coloring of
S
such that for each part
P_{i}
and any two vertices

,

(

) as follows. Given

asks whether there exists a proper budgeted coloring
\beta
of

such that

. Without loss of generality assume that, in
\alpha
for each
i,~P_{i}
is colored with color
i
. Though the following lemma follows form Lemma 1 and Lemma 2 in
[

]
, we give a slightly different proof just for completeness.

Lemma 6
.

Given a partition
\mathcal{P}
and its coloring
\alpha
of cluster vertex deletion set

,

\mathcal{I}^{\prime}=(G,c,\mathcal{B},\mathcal{P},\alpha)

Proof.

Let
\mathcal{K}=\mathcal{K}_{1}\cup\mathcal{K}_{2}\cup\mathcal{K}_{3}\cup\cdots\cup\mathcal{K}_{m}
be the clusters in
G-S
. Now, we construct a flow network as follows.
For each part
P_{i}
create one vertex

and for each unused color

, where

is the number of parts in
\mathcal{P}
.
For each
(v_{i},\mathcal{K}_{j})

(see Figure

and

for all

4.2
BCP
Parameterized by the Distance to Clique

First, observe that when the number of clusters is one, the problem reduces to the

parameterized by the distance to a clique. Thus from Theorem

we get the following theorem as a corollary.

Theorem 9

parameterized by the distance to clique can be solved in time

Next, we prove that there is no polynomial kernel for

Theorem 10
.

parameterized by the distance to clique does not admit a polynomial kernel unless

\subseteq

.

Proof.

Consider any instance of clique problem parameterized by vertex cover,
\mathcal{I}=(G,X,\ell)
. Here

is a graph,

is a vertex cover and we would like to find out whether there exists a clique of size

in

. Parameter is

. We construct the following instance

of

as follows. Here

and we set the budgets as follows. First

Next, we prove that

Assume that

∎

5
Exact Algorithm for Budgeted Coloring

In this section, we present an exact exponential time algorithm for the
BCP
based on dynamic programming. Let
G[X]
denote the subgraph induced by
X
, for
X\subseteq V(G)
.
A
\mathcal{O}^{*}(3^{n}2^{c})
algorithm is easy by computing a table
T
of size
2^{n}\times 2^{c}
whose entries are as follows. For a subset
X
of vertices, and a subset
C
of colors, the entry
T[X,C]
will contain
1
, if
G[X]
can be colored with the colors in
C
along with their respective budgets and
0
otherwise. Now the recurrence relation for this problem is as follows:

T[S,C]=\underset{I\in G[S],c\in C}{\bigvee}T[S\setminus I,C\setminus\{c\}]

where
I
is an independent set in
G[S]
of size at most
b_{c}
.
Trivially, when both
S
and
C
is
\emptyset
,
T[S,C]=0
. Our algorithm runs on all possible subsets
S
of
V(G)
, and for every subset
S
, it runs on all its independent sets, and all possible colors, which is bounded by
c2^{|S|}
. For every
S
, we have table entries for all possible subset
C
of colors which is bounded by
2^{c}
.
Hence, the total running time of this algorithm can be easily seen to be
\sum_{i=1}^{n}\binom{n}{i}2^{i}\cdot 2^{c}\cdot c
which is
=\mathcal{O}(3^{n}\cdot 2^{c}\cdot c)
.

In what follows we improve the runtime to
\mathcal{O}^{*}(2^{n})
using the principle of inclusion-exclusion, essentially generalizing the known algorithm for the proper
c
-coloring problem
[
15
]

to show the following.

Theorem 12
.

Budgeted
c
-Coloring problem can be solved in
\mathcal{O}^{*}(c2^{n})
time.

Proof.

We give an algorithm with the claimed bound for the more general
Budgeted Set Cover
problem defined as follows.

Input:
A ground set
U
of size
n
, and a family
\mathcal{F}
of
m
subsets of
U
, and a set
b_{1},b_{2},\ldots,b_{c}
of integers for
c\geq 1
.

Question:
Are there subsets
F_{1},F_{2},\ldots,F_{c}
in
\mathcal{F}
such that
|F_{i}|\leq b_{i}
and
\bigcup_{i=1}^{c}F_{i}=U
?

In this problem, we can even assume that the family
\mathcal{F}
is given implicitly in the sense, given a subset
S
of
U
, one can test in time polynomial in
|S|
whether or not
S
is in
\mathcal{F}
. We call a subfamily that witnesses a solution to our problem as a budgeted
c
-cover of
\mathcal{F}
.

Now by treating the family
\mathcal{F}
as the family of independent sets of the input graph of the budgeted
c
-coloring, the claim in the theorem follows.
To design an algorithm for
Budgeted Set Cover
using inclusion-exclusion, we define our object of interest. The object of interest is simply a subfamily

\mathcal{F^{\prime}}=\{F_{1},F_{2},\ldots,F_{c}\}
of
\mathcal{F}
such that
|F_{i}|\leq b_{i}
; observe that in our definition for
i\neq j

F_{i}
and
F_{j}
can be the same.
The subfamily
\mathcal{F^{\prime}}
satisfies property
P(u)
if
u\in\bigcup_{F\in\mathcal{F^{\prime}}}F.

Now it follows that the number of budgeted
c
-covers of
\mathcal{F}
is simply the number of objects that satisfy
P(u)
for every
u\in U
(as our objects are ordered, the same budgeted
c
-cover will be counted a fixed number (
c!)
times, and hence the final number has to be divided by

which we ignore hereafter).

For a subset
W\subseteq U
, let
F(W,b_{i})
be the family of sets in
\mathcal{F}
that avoids
W
(i.e doesn’t have any element of
W
) and are of size at most

, and let
f(W,b_{i})
be the number of such sets.
Then the number of objects that do not satisfy property

for any element

\Pi_{i=1}^{c}f(W,b_{i})
. This is simply because there are
f(W,b_{i})

Hence, by the principle of inclusion-exclusion (see Theorem
4.7
of
[
15
]
), we have that the number of budgeted

-covers of
\mathcal{F}
is given by

\sum_{W\subseteq U}(-1)^{|W|}\Pi_{i=1}^{c}f(W,b_{i})

(1)

For a fixed

is the number of subsets of

of size at most

that are in
\mathcal{F}
and hence can be computed in

which can result in an
\mathcal{O}^{*}(3^{n})
time for all

In the following claim, we show that we can pre-compute and store

for each

Claim 3

Proof.

Let

be the set of elements in

be the number of sets of size at most

in
\mathcal{F}
that avoid

Also

\mathcal{F}

And for a

∎

The theorem follows from the Equation

6
Conclusions and Open Problems

In this paper, we have introduced the
BCP
and obtained hardness results, polynomial time algorithms,
FPT
algorithms and kernelization results.
There are a number of open problems.

•

What is the complexity of the
BCP
on trees when
c\geq 3
? The related
ECP
and
Bounded Coloring Problems
are polynomial time solvable on trees
[
6
,
1
]
.
On the other hand there is a generalization of
BCP
to the list coloring vairant called
Number List Coloring Problem
that is known to be
\textsf{W}[1]
-hard on forests parameterized by the total number of colors that appeares on the lists
[
13
]
.

•

In Section
4.1
, we showed that
BCP
when parameterized by the distance to a cluster graph and the number of colors or the number of clusters, is
FPT
. The parameterized complexity of the problem parameterized just by the distance to a cluster graph is an interesting open problem.
