Collatz Theorem
Dagnachew Jenber Negash

Abstract
This paper studies the proof of Collatz conjecture for some set of sequence of odd numbers with infinite number of elements. These set generalized to the set which contains all positive odd integers. This extension assumed to be the proof of the full conjecture, using the concept of mathematical induction. In section 9, the Collatz conjecture is proved again using mathematical induction. Therefore Collatz conjecture is proved two times. Finally two algorithms with GNU Octave code are given to check the validity of the proof for some particular numbers, code of Algorithm 1 is the restatement of Collatz conjecture function which is used to check the validity of our newly generated Collatz function for some particular terms which is provided by Algorithm 2. Therefore go from Algorithm 2 to Algorithm 1 for checking the sequence of numbers and the number of steps needed to reach to 1 according to the conjecture.



1. Introduction

\justify

The Collatz conjecture is an unsolved conjecture in
mathematics. It is named after Lothar Collatz, who first
proposed it in 1937. The conjecture is also known as the
3n+1
conjecture, the Ulam conjecture (after Stanislaw Ulam), the
Syracuse problem, as the hailstone sequence or hailstone
numbers, or as Wondrous numbers per Godel, Escher, Bach.
It asks whether a certain kind of number sequence always
ends in the same way, regardless of the starting number.
The problem is related to a wide range
of topics in mathematics, including number theory, computability theory, and the analysis of dynamic systems.
Paul Erdos said about the Collatz conjecture, "Mathematics is
not yet ready for such problems." He offered $500 for its
solution. (Lagarias 1985)

2. Statement of the problem

\justify

Consider the following operation on an arbitrary positive integer
[
2
]
[
9
]
:

1.

If the number is even, divide it by two.

2.

If the number is odd, triple it and add one.

f(n)=\left\{\begin{array}[]{ll}n/2&\text{ if }n\text{ is even,}\\
3n+1&\text{ if }n\text{ is odd.}\end{array}\right.

Form a sequence by performing this operation repeatedly, beginning with
any positive integer.

1.

Example: n = 6 produces the sequence

6\text{, }3\text{, }10\text{, }5\text{, }16\text{, }8\text{, }4\text{, }2\text{, }1\text{, }4\text{, }2\text{, }1\text{, }\cdots

1.

The Collatz conjecture is:

This process will eventually reach the number 1, regardless of which
positive integer is chosen initially.

Before the conclusion let’s see some sort of sequence of numbers and Collatz analysis is definitely true for these set of sequence of numbers. 9. An alternative proof of Collatz conjecture

We redefined the Collatz conjecture in the following theorem (
13
) will be used in the algorithm for determining the numbers in the same line or same family of numbers which satisfies the Collatz conjecture. For example, 5,16,8,4,2,1 are in the same family which are obtained by applying Collatz function repeatedly with initial term, 5. Naturally, Collatz conjecture is stated by iteration of the form
y_{(n+1)}=f(y_{(n)})
,
n=1,2,\cdots
, where
f
is defined in the following theorem (
13
) and
y_{(n+1)}
is always converges to
1
as
n\longrightarrow\infty
for any natural number
y_{0}
as an initial term. Theorem (
13
) will be used to proof Collatz conjecture in theorem (
14
).

Theorem 13
.

Collatz conjecture can be redefined as

y_{(n+1)}=f(y_{(n)})
,
n=1,2,\cdots
,
y_{(n+1)}
is always converges to
1
as
n\longrightarrow\infty
for any natural number
y_{0}
as an initial number. Where,

f(n)=\frac{1}{4}\left(7n+2+(5n+2)(-1)^{n+1}\right)

(6)

Proof.

The function,
f(n)
of Collatz conjecture can always be written as

f(n)=3n\sin^{2}\left(\frac{n\pi}{2}\right)+\sin^{2}\left(\frac{n\pi}{2}\right)+\frac{n}{2}\cos^{2}\left(\frac{n\pi}{2}\right),

(7)

but using the trigonometric identity,

\sin^{2}\left(\frac{n\pi}{2}\right)=\frac{1}{2}(1-\cos(n\pi)),\text{ }\cos^{2}\left(\frac{n\pi}{2}\right)=\frac{1}{2}(1+\cos(n\pi)),

then equation (
7
) becomes,

f(n)=\frac{3n}{2}(1-\cos(n\pi))+\frac{1}{2}(1-\cos(n\pi))+\frac{n}{4}(1+\cos(n\pi)),

this implies

f(n)=\frac{1}{4}\left(7n+2-(5n+2)\cos(n\pi)\right),

(8)

this means

f(n)=\frac{1}{4}\left(7n+2+(5n+2)(-1)^{n+1}\right),

and we can directly deduce from the statement of the Collatz conjecture that

y_{(n+1)}=f(y_{(n)})\text{, }y_{0}=m\in\mathbb{Z}^{+},\text{ }n=1,2,\cdots,

(9)

this implies

\begin{split}y_{(n+1)}=\frac{1}{4}\left(7y_{(n)}+2+(5y_{(n)}+2)(-1)^{y_{(n)}+1}\right)\text{, }y_{0}=m\in\mathbb{Z}^{+},\text{ }n=1,2,\cdots,\end{split}

(10)

Therefore Collatz conjecture stated as:
y_{(n+1)}
is always converges to
1
as
n\longrightarrow\infty
for any given positive integer
y_{0}=m
.
∎

In the following theorem (
14
) we prove Collatz conjecture using mathematical induction.

Theorem 14
.

Collatz conjecture stated as: If we define a function
f(n)
by

f(n)=\left\{\begin{array}[]{ll}n/2&\text{ if }n\text{ is even,}\\
3n+1&\text{ if }n\text{ is odd.}\end{array}\right.

Form a sequence by performing this operation repeatedly, beginning with
any positive integer,
y_{0}
, then
f(n)
always converges to 1.

Proof.

Let’s proceed using mathematical induction. From theorem (
13
), Collatz conjecture redefined as

y_{(n+1)}=f(y_{(n)})
,
n=1,2,\cdots
,
y_{(n+1)}
is always converges to
1
as
n\longrightarrow\infty
for any natural number
y_{0}
as an initial number. Where,

f(n)=\frac{1}{4}\left(7n+2+(5n+2)(-1)^{n+1}\right)

Now, let’s suppose that Collatz conjecture is true for some natural number
n=k
, that is,

\begin{split}y_{(k+1)}=\frac{1}{4}\left(7y_{(k)}+2+(5y_{(k)}+2)(-1)^{y_{(k)}+1}\right)\text{, }y_{0}=m\in\mathbb{Z}^{+},\text{ }k=1,2,\cdots,\end{split}

(11)

y_{(k+1)}
is always converges to
1
as
k\longrightarrow\infty
for any given positive integer
y_{0}=m
. Now, let us proof this for
n=k+1
to complete the proof,

\begin{split}y_{(k+2)}=\frac{1}{4}\left(7y_{(k+1)}+2+(5y_{(k+1)}+2)(-1)^{y_{(k+1)}+1}\right)\text{, }y_{0}=m\in\mathbb{Z}^{+},\text{ }k=1,2,\cdots,\end{split}

but from equation (
11
),
y_{(k+1)}
converges to 1 as
k\longrightarrow\infty
for any natural number
y_{0}=m
. Therefore,

\begin{split}y_{(k+2)}\longrightarrow\frac{1}{4}\left(7+2+(5+2)(-1)^{1+1}\right)=4\longrightarrow 1.\end{split}

This completes the proof.
∎
